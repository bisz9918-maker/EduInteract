[图示主题与整合说明]
- 本图示主题：图③和图④侧面展开图变体的 3D 闭合验证
- 整合的步骤/概念：整合了图③（平行四边形侧面）和图④（1+2+2+1 分割侧面）的巧妙折叠闭合过程。通过 3D 动画展示 2D 展开图如何折叠成正三棱柱，验证其正确性。
- 教学价值：帮助学生建立空间想象力，直观理解为什么看似不规则的图③和平分侧面的图④都能完美闭合。特别是图③中倾斜边缘的无缝拼接，是教学的难点和亮点。

[视觉元素清单]
- 3D 场景：包含环境光和平行光，背景色 #ffffff。
- 图③模型 (State 1)：
  - 中间矩形面板 (宽2高4)：蓝色半透明填充 (#1565c0, 30%)，黑色边框。
  - 左侧梯形面板 (底2顶1)：蓝色半透明填充，黑色边框。左侧倾斜边缘附加绿色高亮线 (#2e7d32)。
  - 右侧复合面板 (矩形+三角形)：蓝色半透明填充，黑色边框。右侧倾斜边缘附加绿色高亮线 (#2e7d32)。
  - 上下底面 (正三角形)：绿色半透明填充 (#2e7d32, 30%)，黑色边框。
- 图④模型 (State 2)：
  - 4个矩形面板 (宽1, 2, 2, 1)：蓝色半透明填充，黑色边框。最左和最右边缘附加绿色高亮线。
  - 上下底面 (正三角形)：绿色半透明填充，黑色边框。
- 辅助线：3D 空间中的网格底板 (可选，用于提供空间感，灰色虚线风格)。

[分步序列]
- 初始状态（状态 1 - 图③，展开）：
  - 显示图③的 2D 展开图平铺在 z=0 平面上。
  - 滑块处于 0（展开）。
  - 标签显示在对应面板上。
- 交互 1（折叠图③）：
  - 拖动滑块向右，两侧面板沿折痕向上折起（左侧折起 120°，右侧分两段各折起 120°）。
  - 上下底面分别向下/向上折起 90°。
  - 滑块到达 1 时，模型完全闭合，左右倾斜的绿色高亮边缘在 3D 空间中完美重合。
- 状态 2（切换至图④，展开）：
  - 点击"图④"按钮，隐藏图③模型，显示图④模型平铺在 z=0 平面上。
  - 滑块重置为 0。
- 交互 2（折叠图④）：
  - 拖动滑块向右，4个矩形面板沿折痕折起。
  - 滑块到达 1 时，左右两端宽为 1 的面板在空中相遇，绿色高亮边缘完美拼接成一个宽为 2 的完整侧面。

[标签冲突检查]
- "宽度 1" 与 "宽度 2" 标签：在图④中分别位于不同面板的顶部边缘上方 0.5 单位处。由于面板宽度至少为 1 单位（30px），标签宽度约 40px，水平间距充足，不会重叠。
- "正三角形" 标签：位于上下底面的几何中心。底面折叠时随之移动，始终位于三角形内部，远离侧面标签，无冲突。
- 解决方案：使用 Three.js 的 CSS2DRenderer，确保标签始终面向相机且不被 3D 几何体遮挡。

[交互方案]
- 交互类型：多状态切换（顶部按钮） + 连续拖拽滑块（底部）。
- 控件说明：
  - 顶部按钮组：用于在图③和图④两种展开图方案间切换。
  - 底部滑块：控制折叠动画的进度（0 = 完全展开，1 = 完全闭合）。
  - 鼠标/触摸：在 3D 画布区域拖拽可自由旋转视角，滚轮缩放，方便全方位观察闭合接缝。
- 教师操作流程：教师先选择图③，拖动滑块展示折叠过程，旋转视角让学生观察倾斜边缘如何重合；然后切换到图④，再次拖动滑块，展示 1+1=2 的拼接过程。

[技术实现]
- JS 库选择：Three.js（用于 3D 建模、折叠动画和视角控制），CSS2DRenderer（用于 3D 空间中的 HTML 文本标签）。
- 画布尺寸：800 × 500 px，相对定位容器。
- 布局草图：
  [图示区 800×500 (3D Canvas)]
  [ 顶部按钮: (图③) (图④) ]
  [ 底部滑块: 展开 [--------O--] 折叠 ]
- 关键实现要点：
  - 状态机：维护 current_state (1 或 2) 和 fold_progress (0 到 1)。
  - 3D 坐标系：以中间面板的中心或折痕为原点建立层级结构 (Object3D 作为 Hinge)。
  - 图③的数学处理：为了让平行四边形在 3D 中完美闭合，右侧面板在代码中必须拆分为一个矩形和一个三角形，两者之间有 120° 的相对旋转。这是数学上的必然，动画中将平滑展示这一过程，使得倾斜边缘完美贴合。
  - 材质：使用 `MeshBasicMaterial` 并开启 `transparent: true`，配合 `LineSegments` 绘制黑色边框，确保 3D 结构清晰可见。
  - ID 命名规范：所有 DOM 元素 ID 以 `scene2-` 开头（如 `scene2-btn-state1`, `scene2-slider`）。
  - 隔离：所有代码封装在 `(function() { ... })()` 中。
