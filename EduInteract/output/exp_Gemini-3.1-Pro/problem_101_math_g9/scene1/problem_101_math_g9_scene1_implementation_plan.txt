[图示主题与整合说明]
- 本图示主题：正方形折叠挖洞与展开的对称性分析
- 整合的步骤/概念：将正方形沿对角线折叠、在直角三角形的三个角挖洞、展开后的孔洞位置及对称关系分析。
- 教学价值：通过分步动画，教师可以清晰地向学生展示折叠和展开的物理过程，帮助学生建立空间想象力。最后一步的辅助线直观揭示了折叠问题本质上的轴对称性质，升华理论。

[视觉元素清单]
- 背景：#ffffff
- 左下三角形：`polygon`，点 `250,70 250,370 550,370`，填充 `#1565c0` (opacity 0.2)，描边 `#000000` (stroke-width: 2)
- 右上三角形：`polygon`，点 `250,70 550,70 550,370`，填充 `#1565c0` (opacity 0.2)，描边 `#000000` (stroke-width: 2)。包裹在 `<g>` 中以实现翻折。
- 折痕：`line`，`250,70` 到 `550,370`，描边 `#888888` 虚线 (stroke-dasharray: 5,5)
- 圆洞（左下组）：3个 `circle`，半径 10，填充 `#ffffff`，描边 `#000000` (stroke-width: 1.5)
- 圆洞（右上组）：3个 `circle`，半径 10，填充 `#ffffff`，描边 `#000000` (stroke-width: 1.5)。放在右上三角形的 `<g>` 中。
- 辅助线：2条 `line`，描边 `#c62828` 虚线 (stroke-dasharray: 4,4)
- 直角标记：2个 `polyline`，描边 `#c62828` 实线 (stroke-width: 2)

[分步序列]
- 初始状态（步骤0）：显示完整的正方形（左下三角形 + 右上三角形）及对角线折痕。所有圆洞和辅助线隐藏（opacity: 0）。
- 步骤1（折叠）：右上三角形沿折痕翻折 180 度，与左下三角形重合。圆洞和辅助线保持隐藏。
- 步骤2（挖洞）：在重合的直角三角形上，3 个位置的圆洞显现（opacity 变为 1）。由于右上三角形已翻折，其内部的洞与左下三角形的洞完全重合。
- 步骤3（展开）：右上三角形翻折回原位（0 度）。由于其内部的洞已显现，展开时会带着 3 个洞一起回到右上角，展示出完整的 6 个洞。
- 步骤4（对称分析）：辅助线和直角标记显现（opacity 变为 1），高亮显示成对圆洞关于折痕的轴对称关系。

[标签冲突检查]
- 本场景无文本标签，仅有图形元素。
- 圆洞间距检查：左上角两洞圆心距 28.28px（半径10px），边缘间距 8.28px，无重叠；右下角两洞同理，无重叠。
- 辅助线检查：辅助线起点和终点精确计算在圆洞边缘，不会穿透圆洞内部。
- 直角标记检查：标记位于折痕外侧，不与圆洞重叠。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：底部居中放置两个按钮，控制步骤进度（0~4）。
- 教师操作流程：教师点击“下一步”逐步演示折叠、挖洞、展开的完整物理过程，最后一步展示辅助线进行对称性理论讲解。可随时点击“上一步”回退。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。利用 CSS 3D transform (`rotate3d`) 即可实现完美的平滑翻折动画，无需引入庞大的外部库。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800x500]
      (正方形居中 300x300)
  [控件栏 y=450~490]
      [上一步] [下一步]
  ```
- 关键实现要点：
  - 翻折动画：将右上三角形及其内部的 3 个圆洞包裹在一个 `<g id="scene1-top-right">` 中。设置 `transform-origin: 250px 70px;` 和 `transition: transform 0.8s ease-in-out;`。
  - 翻折触发：通过 JS 修改该 `<g>` 的 `transform` 属性为 `rotate3d(1, 1, 0, 180deg)` 实现沿对角线翻折。
  - 状态机设计：定义 `currentStep` 变量，每次点击按钮更新该变量并调用 `updateState()` 函数，统一控制各元素的 `transform` 和 `opacity`。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-top-right`, `scene1-btn-next`）。
- IIFE 隔离：所有 JS 代码必须包裹在 `(function() { ... })()` 中，避免全局变量污染。
