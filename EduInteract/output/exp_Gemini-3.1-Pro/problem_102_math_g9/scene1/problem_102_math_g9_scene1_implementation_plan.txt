[图示主题与整合说明]
- 本图示主题：抛物线与线段交点的动态分析
- 整合的步骤/概念：直线AB及交点M,N的确定、线段AN与BM的高亮、抛物线恒过定点展示、抛物线经过关键端点（A, B, M）的临界状态分析。
- 教学价值：教师可通过分步导航，引导学生逐步将几何条件（交点在线段上）转化为代数条件（端点处的函数值正负），并通过动态滑块直观展示参数b变化时抛物线的运动规律，加深对临界状态的理解。

[视觉元素清单]
- 坐标系：x轴、y轴、原点O及网格背景（浅灰色 #eeeeee，间距对应1个单位，即100px和62.5px）。
- 直线与点：直线AB（#000000，实线）；点A, B, M, N（#000000，实心圆点）。
- 线段：线段AN（#c62828，加粗实线）；线段BM（#2e7d32，加粗实线）。
- 抛物线与定点：抛物线（#1565c0，实线，线宽2px），定点P（#000000，实心圆点）。
- 动态交点：抛物线与直线AB的交点（#ff9800，实心圆点，仅在交点存在时显示）。
- 标签：点标签 A, B, M, N, P, O；轴标签 x, y；方程标签。
- 颜色/样式沿用 `<SCENE_1>` 规格。

[分步序列]
- 初始状态（步骤0）：显示坐标系、网格、点A(-1,4)、点B(2,1)及直线AB。隐藏M, N, P, 抛物线及滑块。
- 步骤1（找线段）：直线延伸交坐标轴于M(3,0), N(0,3)，显示点M, N及其标签。加粗并高亮线段AN（红色）和BM（绿色）。
- 步骤2（看定点）：引入抛物线（初始设b=2），标记其恒过定点P(0,2)。显示点P及其标签。
- 步骤3（左交点临界）：抛物线平滑过渡到 b=1（经过点A）。显示灰色虚线作为临界参考。右上角方程更新。
- 步骤4（右交点临界）：抛物线平滑过渡到 b=2.5（经过点B），稍作停留后过渡到 b=11/3（经过点M）。显示对应的灰色虚线。
- 步骤5（综合结论）：保留 b=2.5 和 b=11/3 的灰色虚线。底部显示滑块（范围1到5，步长0.01）。教师可拖动滑块，抛物线及交点随之实时更新，方程文本同步更新。

- 标签"B"(510,302.5) 与 标签"M"(580,395)：间距 > 100px → 无冲突。

- 结论：所有标签均已按不同方向错开，且距离充足，无重叠风险。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶） + 步骤5的滑块拖动。
- 控件说明：
  - 「上一步」「下一步」按钮：位于底部控件栏中心，用于控制步骤0-5的切换。
  - 参数b滑块：仅在步骤5显示，位于按钮右侧，范围 [1, 5]，用于动态演示抛物线变化。
- 教师操作流程：教师点击「下一步」逐步展示几何条件的转化过程，最后在步骤5通过拖动滑块，向学生直观展示参数b在不同取值下，抛物线与线段AN, BM的交点情况，验证代数推导的结果。

[技术实现]
- JS 库选择及原因：原生 SVG + Vanilla JS。本题图形均为标准几何图形和函数曲线，原生 SVG 配合 JS 动态生成 `<path>` 的 `d` 属性即可高效实现，无需引入庞大的外部库。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  +------------------------------------------------+
  |                                 y=x²-bx+2      |
  |    A                                           |
  |     \                                          |
  |      N                                         |
  |       \ P                                      |
  |        \                                       |
  |         B                                      |
  | ---------\-O--------M-----------------------   |
  |           \                                    |
  |                                                |
  | [◀上一步] [下一步▶]      b: [====|====] 2.50     |
  +------------------------------------------------+
  ```
- 关键实现要点：
  - 坐标映射函数：`mapX(x) = 300 + x * 100`，`mapY(y) = 375 - y * 62.5`。
  - 抛物线绘制：编写函数 `drawParabola(b)`，在 x ∈ [-3, 5] 范围内以 0.1 为步长计算点，映射后拼接成 SVG path 的 `d` 属性。
  - 动画过渡：使用 `requestAnimationFrame` 实现 b 值的平滑过渡动画（如步骤3和步骤4中的抛物线移动）。
  - 状态机：定义 `currentStep` 变量，每次切换步骤时，根据步骤编号控制各 SVG 元素的 `display` 或 `opacity` 属性，并触发相应的抛物线动画。
  - ID 命名规范：所有元素 ID 以 `scene1-` 开头，如 `scene1-parabola`, `scene1-btn-next`。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
