[图示主题与整合说明]
- 本图示主题：利用面积相减法求解阴影面积
- 整合的步骤/概念：正方形与菱形边长推导、作辅助线求高、勾股定理计算、梯形面积计算、阴影面积求解
- 教学价值：教师可以通过分步导航，引导学生逐步拆解复杂图形。先从已知面积推导边长，再通过辅助线构建直角三角形求解未知线段，最后利用面积相减法得出结论。图示将抽象的推导过程与直观的图形高亮结合，降低理解难度。

[分步序列]
- 初始状态（步骤0）：显示正方形 ABCD、菱形 PQCB、阴影 ABPED，以及点 A, B, C, D, P, Q, E。右侧文字区为空。
- 步骤1（正方形边长）：正方形 ABCD 边框变为蓝高亮（#1565c0，4px）。显示标注 AD=5, CD=5。右侧文字区淡入显示：“正方形 ABCD 面积为 25，故边长 BC = CD = 5”。
- 步骤2（菱形的高）：正方形恢复默认样式，菱形 PQCB 边框变为蓝高亮。显示辅助线 PH、直角标记、点 H。显示标注 BP=5, PH=4。右侧文字区追加显示：“菱形 PQCB 面积为 20，边长 BP = 5。作 PH ⊥ BC，则 BC × PH = 20，得 PH = 4”。
- 步骤3（勾股定理）：菱形恢复默认样式，直角三角形 PBH 边框变为红高亮（#c62828，4px），内部可加极淡红色填充。显示标注 BH=3。右侧文字区追加显示：“在 Rt△PBH 中，由勾股定理得 BH = √(BP² - PH²) = 3”。
- 步骤4（梯形参数）：三角形 PBH 恢复默认样式，直角梯形 BPEC 边框变为蓝高亮。隐藏标注 CD=5，显示标注 PE=2, CE=4。右侧文字区追加显示：“梯形 BPEC 中，PE = HC = BC - BH = 2，CE = PH = 4”。
- 步骤5（得出结论）：梯形恢复默认样式。右侧文字区追加显示：“S_BPEC = 1/2 × (PE + BC) × CE = 14。阴影面积 S_ABPED = S_ABCD - S_BPEC = 25 - 14 = 11”。

[交互方案]
- 交互类型：分步按钮导航
- 控件说明：在 SVG 内部底部（y=450 区域）居中放置两个按钮：“◀ 上一步” 和 “下一步 ▶”。
- 教师操作流程：教师在讲解时，点击“下一步”逐步展示推导过程，右侧文字区会同步显示当前步骤的数学推导，图形区会高亮对应的几何元素，帮助学生建立数形结合的直观理解。

[技术实现]
- JS 库选择及原因：原生 SVG（用于精确绘制几何图形和实现平滑的属性动画） + MathJax（用于右侧文字区的高质量数学公式渲染）。
- 画布尺寸：800 × 500 px。
- 布局草图：
  [图示区 800×500]
  +-------------------+-----------------+
  |                   |                 |
  |    A-------D      |  推导过程区     |
  |    |       |      |                 |
  |    |   P---E---Q  |  S_ABCD = 25    |
  |    |  /    |  /   |  ...            |
  |    | /     | /    |                 |
  |    B---H---C      |                 |
  |                   |                 |
  +-------------------+-----------------+
  [   ◀ 上一步    下一步 ▶   ]
- 关键实现要点：
  1. 状态机设计：使用 `currentStep` 变量（0~5）记录当前状态，每次点击按钮调用 `updateStep()` 函数。
  2. 动画与高亮：通过 CSS `transition` 实现 `stroke`、`stroke-width`、`opacity` 的平滑过渡。高亮时修改对应 polygon 的 class 或直接修改 stroke 属性。
  3. 公式渲染：右侧文字区使用绝对定位的 HTML `div`，每步更新 `innerHTML` 后调用 `MathJax.typesetPromise()` 重新渲染公式。
  4. ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-btn-next`, `scene1-rect-abcd`）。
  5. IIFE 隔离：所有 JS 代码包裹在 `(function() { ... })()` 中，避免全局变量污染。
