[图示主题与整合说明]
- 本图示主题：利用分割法求解阴影面积（一题多解）
- 整合的步骤/概念：作辅助线分割阴影区域、矩形与直角三角形面积计算
- 教学价值：教师可通过分步演示，清晰地向学生展示如何通过作辅助线将不规则的阴影部分转化为规则的矩形和直角三角形，并结合已知条件分布计算面积，降低理解难度。

[技术实现]
- JS 库选择及原因：原生 SVG（适合精确的几何图形绘制和动画过渡） + MathJax（用于右侧文本区数学公式的优雅渲染）。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  +---------------------------------------+
  |                                       |
  |   A       D                           |
  |   +-------+                           |
  |   |       |                           |
  | F +---+---+ E     Q                   |
  |   |   P   +-------+      [文本区]     |
  |   |      /       /       (550~780)    |
  |   |     /       /                     |
  |   +----+-------+                      |
  |   B            C                      |
  |                                       |
  |       [上一步] [下一步]               |
  +---------------------------------------+
  ```
- 关键实现要点：
  - 状态机设计：定义 `currentStep` 变量（0~4），每次点击按钮更新变量并调用 `updateState()` 函数。
  - 动画过渡：为 SVG 元素的 `opacity` 和 `fill` 属性添加 CSS `transition: all 0.5s ease;`，实现平滑的显隐和颜色变化。
  - 文本切换：右侧文本区预先写好 5 个步骤的 HTML 结构（包含 MathJax 公式），通过控制 `display: none` 和 `display: block` 进行切换。
  - 按钮状态：在步骤 0 时禁用「上一步」，在步骤 4 时禁用「下一步」。
- ID 命名规范：所有交互元素 ID 必须以 `scene2-` 为前缀（如 `scene2-btn-next`, `scene2-shadow-afed`）。
- IIFE 隔离：所有 JS 代码包裹在 `(function() { ... })()` 中，避免全局变量污染。
