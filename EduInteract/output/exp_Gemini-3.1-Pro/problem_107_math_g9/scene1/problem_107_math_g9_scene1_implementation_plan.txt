[图示主题与整合说明]
- 本图示主题：屋架几何模型的抽象与直角三角形性质的多解法推导
- 整合的步骤/概念：从实际屋架工程图中抽象出直角三角形几何模型，标注已知条件，并分别通过“小直角三角形性质”和“大直角三角形+中位线定理”两种解法推导立柱 DE 的长度。
- 教学价值：帮助学生建立从实际问题到数学模型的抽象思维，通过分步动画对比两种不同的几何推导路径，加深对直角三角形性质及中位线定理的理解。

[视觉元素清单]
- 背景屋架：包含外轮廓 A-B-A_right 及内部所有支柱（BC, DE, D_right-E_right, DC, D_right-C），初始填充 #fce4b6，线条 #000000 2px。
- 核心几何图形：△ABC 及线段 DE，在步骤1中加粗为 3px。
- 标签文本：A, B, C, D, E（字号 18px，黑色）。
- 条件标注：∠A 弧线及 "30°"、直角符号 C 和 E、等长标记（绿色 #2e7d32）。
- 长度数值："8", "4", "4"（字号 18px，粗体，黑色或跟随高亮颜色）。
- 高亮区域：△ADE（蓝色 #1565c0，透明度 20%），△ABC（红色 #c62828，透明度 20%）。
- 动态符号：平行箭头（红色 #c62828）。

[分步序列]
- 初始状态（步骤0）：显示完整屋架设计图（带浅黄色填充），无任何字母标签和标注。结论文本区为空。
- 步骤1（几何抽象）：右侧屋架（A_right及相关线段）和斜向支柱（DC, D_right-C）透明度降至 0.2。左侧核心图形（△ABC, DE）线条加粗。淡入顶点标签 A, B, C, D, E。
- 步骤2（标注条件）：淡入 ∠A 的 30° 弧线及文本、C 和 E 处的直角符号、AD 和 DB 的等长标记。淡入长度标注 "8"（在 AB 旁）。
- 步骤3（解法一演示）：
  1. 填充 △ADE（蓝色透明）。
  2. 高亮线段 AD（蓝色加粗），淡入数值 "4"（在 AD 旁）。
  3. 闪烁 ∠A 和线段 DE（透明度 1 -> 0.3 -> 1 循环 3 次）。
  4. 结论区打字机效果显示："解法一：在 Rt△ADE 中，∠A=30°，AD = 1/2 AB = 4 ∴ DE = 1/2 AD = 2"。
- 步骤4（解法二演示）：
  1. 取消 △ADE 填充和 AD 高亮，隐藏 AD 旁的 "4"。
  2. 填充 △ABC（红色透明）。
  3. 闪烁 ∠A 和线段 BC，淡入数值 "4"（在 BC 旁）。
  4. 高亮线段 DE 和 BC（红色加粗），淡入平行箭头符号。
  5. 结论区打字机效果显示："解法二：在 Rt△ABC 中，BC = 1/2 AB = 4。∵ DE⊥AC, BC⊥AC ∴ DE // BC。又∵ D是AB中点，∴ DE是中位线 ∴ DE = 1/2 BC = 2"。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：在 SVG 底部 (y=450~490) 居中放置两个按钮。
- 教师操作流程：教师点击“下一步”逐步引导学生从看图、抽象模型、找已知条件，到分别使用两种方法进行推导。步骤内的子动画（如闪烁、依次出现）自动按顺序播放，无需额外点击，减轻教师操作负担。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。SVG 适合精确的几何图形绘制和矢量缩放，原生 JS 配合 CSS transition / keyframes 足以实现高亮和闪烁动画。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```text
  +--------------------------------------------------+
  |                                                  |
  |                      B                           |
  |                     /|\                          |
  |             8      / | \                         |
  |                   /  |  \                        |
  |                  D   |   \                       |
  |             4   /|   |4   \                      |
  |                / |   |     \                     |
  |             30°/ |   |      \                    |
  |              A---E---C-------A_right             |
  |                                                  |
  |  [结论文本区：解法一/二的推导过程...]            |
  |                                                  |
  |             [◀ 上一步] [下一步 ▶]                |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  - 状态机设计：定义 `currentStep` 变量，`updateStep()` 函数根据当前步骤控制各 SVG 元素的 `opacity`, `stroke`, `fill` 属性。
  - 动画序列：步骤 3 和 4 内部的顺序动画（如先高亮再闪烁再出字）使用 `async/await` 配合 `const sleep = ms => new Promise(r => setTimeout(r, ms))` 实现。
  - ID 命名规范：所有元素 ID 必须以 `scene1-` 为前缀（如 `scene1-btn-next`, `scene1-polygon-abc`），使用 `document.getElementById` 获取 DOM。
  - IIFE 隔离：整个脚本包裹在 `(function() { ... })()` 中，避免全局变量污染。
