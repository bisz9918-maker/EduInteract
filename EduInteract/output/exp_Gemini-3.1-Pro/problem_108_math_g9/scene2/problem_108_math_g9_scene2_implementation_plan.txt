[视觉元素清单]
- 基础图形：点 M, N, A, B, C 及线段 MN, MA, NA, MB, NB（主线 #000000，点 r=3 黑色填充）。
- 角度标记：M 处的两个 x，N 处的两个 y（使用 SVG text，斜体 serif 字体）。A, B 处的 α（步骤1出现）。
- 动态文本：N 处的 y 标签在步骤2中更新为 x。
- 高亮区域：△CMN 多边形（#1565c0，透明度 0.2，步骤3出现）。
- 等长标记：CM 和 CN 中点处的双短划线（#1565c0，步骤3出现）。
- 辅助线：MN 的垂直平分线（#888888 虚线，步骤4出现）及直角符号。
- 右侧推导面板：HTML div 容器，内部包含 5 个步骤的文本块（使用 MathJax 渲染公式），按步骤依次淡入。

[分步序列]
- 初始状态（步骤0）：显示基础图形、点标签、M 处的两个 x 标签、N 处的两个 y 标签。右侧面板显示标题“验证选项 A”。
- 步骤1：点击「下一步」→ 右侧淡入条件“已知 ∠A=α, ∠B=β...”，图形中 A、B 处淡入角度弧和 α 标签。
- 步骤2：点击「下一步」→ 右侧淡入代数推导“... ⇒ x=y”，图形中 N 处的两个 y 标签文本变为 x（可伴随短暂的颜色高亮如红色再变回黑色以吸引注意力）。
- 步骤3：点击「下一步」→ 右侧淡入等腰三角形判定“... ⇒ CM=CN”，图形中 △CMN 区域淡入浅蓝色高亮，CM 和 CN 边上淡入双短划线等长标记。
- 步骤4：点击「下一步」→ 右侧淡入最终结论“... 点 C 在 MN 的垂直平分线上”，图形中淡入穿过 C 点的垂直平分线（虚线）和直角符号。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：底部居中放置两个按钮。
- 教师操作流程：教师点击“下一步”逐步展示推导逻辑，右侧文本与左侧图形变化同步，辅助教师进行逻辑严密的讲解。可随时点击“上一步”回退。

[技术实现]
- JS 库选择及原因：原生 SVG 用于精确绘制几何图形和动画；MathJax 用于右侧面板的高质量数学公式渲染。
- 画布尺寸：800 × 500 px（左侧 500px 为图形区，右侧 280px 为文本区）。
- 布局草图：
  ```
  [-------------------------------------------------]
  [  (150,350) M        N (450,350)  |  验证选项 A    ]
  [       \              /           |  已知...       ]
  [        \            /            |  推导...       ]
  [         A(225)    B(375)         |  结论...       ]
  [          \        /              |                ]
  [           \      /               |                ]
  [            C(300)                |                ]
  [-------------------------------------------------]
  [           ◀上一步    下一步▶                    ]
  ```
- 关键实现要点：
  - 状态机设计：使用 `currentStep` 变量（0-4）记录当前状态，`updateScene()` 函数根据状态控制各 SVG 元素的 `opacity` 和文本面板子 div 的 `opacity`。
  - 坐标计算：所有坐标已在计划中硬编码，确保绝对对称（x=y 的特殊情况），从而保证步骤4的垂直平分线完美穿过 C 点。
  - 动画过渡：SVG 元素的显示/隐藏使用 CSS `transition: opacity 0.5s ease` 实现平滑过渡。
- ID 命名规范：所有元素 ID 必须以 `scene2-` 为前缀（如 `scene2-svg`, `scene2-btn-next`, `scene2-text-step1` 等）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
