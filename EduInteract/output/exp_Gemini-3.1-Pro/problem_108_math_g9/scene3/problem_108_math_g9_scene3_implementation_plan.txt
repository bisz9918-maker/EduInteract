[图示主题与整合说明]
- 本图示主题：选项 D 证伪（∠MCN=120° 时的动态反例）
- 整合的步骤/概念：通过动态改变底角参数 x，在保持题设约束（x+y=60°，∠MCN=120°，∠O=60°）的前提下，展示延长线交点 O 及线段 OA、OB 的长度变化。
- 教学价值：教师可拖动滑块连续改变图形形态，直观展示除了 x=30° 的特例外，OA 和 OB 的长度通常不相等，从而极具说服力地证伪选项 D。

[视觉元素清单]
- 几何图形：△OMN 及其内部交线，M、N 固定，O、A、B、C 动态计算。
- 动态虚线：延长线 AO 和 BO 使用虚线（stroke-dasharray="5,5"），颜色随状态变化（相等时绿色 #2e7d32，不等时红色 #c62828）。
- 角度标注：四个关键角（2x, 2y, 60°, 120°）的圆弧和文本标签。
- 长度对比面板：
  - 标题："OA 与 OB 长度对比" (x=625, y=100, 居中)
  - OA 标签与柱状图："OA =" (x=480, y=160)，柱状图起点 (530, 145)，高度 20，宽度动态 (OA长度 * 0.4)，后跟具体数值。
  - OB 标签与柱状图："OB =" (x=480, y=210)，柱状图起点 (530, 195)，高度 20，宽度动态 (OB长度 * 0.4)，后跟具体数值。
  - 结论文本：(x=625, y=280, 居中)，动态显示 "OA ≠ OB"（红色）或 "OA = OB"（绿色）。

[分步序列]
- 初始状态（x=20°）：展示不对称的图形形态。OA 和 OB 长度明显不等，右侧面板柱状图长度差异显著，结论文本显示红色 "OA ≠ OB"，延长线 AO 和 BO 呈红色虚线。
- 交互状态（拖动滑块）：
  - 当 x ≠ 30° 时：图形实时形变，保持红色高亮状态，实时更新柱状图和数值，直观展示 OA ≠ OB。
  - 当 x = 30° 时（即 x=y）：图形变为对称形态。OA 和 OB 长度相等，右侧面板柱状图等长，结论文本变为绿色 "OA = OB"，延长线 AO 和 BO 变为绿色虚线。

[标签冲突检查]
- M(85, 435) 与 2x标签(132, 406)：间距 > 40px，无冲突。
- N(335, 435) 与 2y标签(288, 406)：间距 > 40px，无冲突。
- C(C.x, C.y-15) 与 120°标签(C.x, C.y+30)：分别在 C 点上下方，无冲突。
- O(O.x, O.y-15) 与 60°标签(O.x, O.y+35)：分别在 O 点上下方，无冲突。
- A(A.x-15, A.y-15) 与 B(B.x+15, B.y-15)：A在左，B在右，最小间距 > 60px，无冲突。
- 结论：所有标签均已规划在安全区域，偏移方向合理，无重叠风险。

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：底部居中放置一个 range input 滑块，ID 为 `scene3-slider-x`，范围 15 到 45，步长 1，初始值 20。滑块上方有文本提示 "调节角 x (15° - 45°)"。
- 教师操作流程：教师在讲解选项 D 时，拖动滑块改变 x 的值，引导学生观察右侧面板中 OA 和 OB 的长度变化。特别是在 x=30° 时指出这是特例，而在其他角度时 OA ≠ OB，从而证明选项 D 错误。

[技术实现]
- JS 库选择及原因：原生 SVG。图形由直线和圆弧组成，原生 SVG 配合 JS 动态计算坐标即可高效实现，且 DOM 操作简单，易于实现柱状图的动态绑定。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +-----------------------------------------+-------+
  |                                         |       |
  |         O                               | 对比  |
  |        / \                              | 面板  |
  |       A   B                             |       |
  |      / \ / \                            |       |
  |     /   C   \                           |       |
  |    /___/_\___\                          |       |
  |   M           N                         |       |
  |                                         |       |
  |         [调节角 x 滑块]                 |       |
  +-----------------------------------------+-------+
  ```
- 关键实现要点：
  - 坐标计算：基于 M(100, 420) 和 N(320, 420)，使用直线交点公式动态计算 O, A, B, C 的坐标。注意角度转弧度，以及 SVG 坐标系 y 轴向下的特点。
  - 弧线绘制：封装 `getArcPath(cx, cy, r, startAngle, endAngle)` 函数，使用 SVG 的 `A` 指令生成路径，注意角度系与 SVG 坐标系的转换（y 轴反向导致 sweep-flag 为 0）。
  - 状态联动：在滑块的 `input` 事件中，重新计算所有坐标，更新线段的 `x1, y1, x2, y2`，更新弧线的 `d` 属性，更新标签的 `x, y`，并根据 `Math.abs(OA - OB) < 0.1` 切换颜色和文本。
- ID 命名规范：所有交互元素 ID 必须以 `scene3-` 为前缀（如 `scene3-slider-x`, `scene3-line-ao` 等）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
