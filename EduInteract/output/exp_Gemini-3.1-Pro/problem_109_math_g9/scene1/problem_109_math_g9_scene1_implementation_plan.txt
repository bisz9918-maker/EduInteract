[图示主题与整合说明]
- 本图示主题：利用整体面积相减法求旋转图形的阴影面积
- 整合的步骤/概念：图形旋转生成过程、整体面积拆解、等面积抵消、扇形面积计算
- 教学价值：教师可以通过分步导航，清晰地向学生展示阴影面积是如何通过“整体 - 空白”转化而来的。特别是通过颜色高亮和动画闪烁，直观地证明旋转前后的半圆面积相等且可抵消，最终将复杂的不规则阴影面积转化为简单的扇形面积计算，极大地降低了学生的认知负荷。

[视觉元素清单]
- 基础图形：原半圆弧（黑实线2px）、线段AB（黑实线2px）
- 旋转生成图形：轨迹弧AA'（#888888虚线2px）、新半圆弧（黑实线2px）、线段A'B（黑实线2px）
- 填充区域（置于线条底层）：
  - 初始阴影：#000000，透明度 20%
  - 新半圆高亮：#1565c0 (蓝色)，透明度 30%
  - 扇形ABA'高亮：#2e7d32 (绿色)，透明度 30%
  - 原半圆高亮：#c62828 (红色)，透明度 30%
- 文本标签：A, B, A', 45°, 4（字号 16px，黑色，无衬线字体）
- 角度标注：B点处的45°圆弧（半径30px，黑实线1px）

[分步序列]
- 初始状态（步骤0）：仅显示原半圆弧、线段AB、标签A和B。
- 步骤1（旋转生成）：显示轨迹弧AA'、新半圆弧、线段A'B、标签A'。显示初始灰色阴影填充。
- 步骤2（整体拆解）：灰色阴影消失。显示新半圆填充（蓝色）和扇形填充（绿色）。右侧不显示公式，仅通过视觉展示整体图形由这两部分组成。
- 步骤3（面积相减）：在步骤2基础上，叠加显示原半圆填充（红色）。右侧出现公式区，显示“S_阴影 = S_整体 - S_空白 = (S_新半圆 + S_扇形) - S_原半圆”，并用对应颜色高亮文字。
- 步骤4（等量抵消）：蓝色新半圆填充和红色原半圆填充同时闪烁3次后淡出（透明度变为0）。右侧公式更新，划掉新半圆和原半圆，得出“S_阴影 = S_扇形”。
- 步骤5（计算结果）：仅保留绿色扇形填充。显示角度标注弧、标签“45°”以及两条半径上的长度标签“4”。右侧公式更新为具体的数值代入和最终结果“2π”。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：在 SVG 画布底部（y=450~490 区域）居中放置两个按钮，控制步骤 0 到 5 的切换。
- 教师操作流程：教师点击“下一步”逐步推进图形的旋转、拆解、相减和计算过程，配合右侧的公式变化进行讲解。遇到学生不理解的地方，可随时点击“上一步”回退演示。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS + HTML/CSS。本题图形由标准圆弧和线段组成，原生 SVG 的 `path` 标签配合 `A` (Arc) 指令即可完美实现，无需引入庞大的外部库。公式部分使用 HTML 配合 CSS 即可实现上下标和分数排版。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```text
  +---------------------------------------------------------+
  |                                                         |
  |       [A']                                              |
  |        / \                                              |
  |       /   \  (新半圆)       [公式区]                    |
  |      /     \                S_阴影 = ...                |
  |     /       \               = 2π                        |
  |   [A]-------[B]                                         |
  |      (原半圆)                                           |
  |                                                         |
  |               [◀ 上一步]  [下一步 ▶]                    |
  +---------------------------------------------------------+
  ```
- 关键实现要点：
  1. **SVG Arc 指令**：精确使用 `A rx ry x-axis-rotation large-arc-flag sweep-flag x y`。
     - 原半圆：`M 160 380 A 130 130 0 0 1 420 380`
     - 新半圆：`M 236.2 196.2 A 130 130 0 0 1 420 380`
     - 轨迹弧：`M 160 380 A 260 260 0 0 1 236.2 196.2`
     - 阴影闭合路径：`M 160 380 A 260 260 0 0 1 236.2 196.2 A 130 130 0 0 1 420 380 A 130 130 0 0 0 160 380 Z`
  2. **状态机设计**：定义 `currentStep` (0-5)，每次点击按钮更新变量并调用 `updateState()` 函数。该函数根据当前步骤控制各个 SVG 元素和 HTML 公式块的 `display` 或 `opacity` 属性。
  3. **动画实现**：使用 CSS `@keyframes` 定义闪烁淡出动画。在进入步骤 4 时，通过 JS 为蓝色和红色填充区域添加动画 class；若回退或前进，则移除该 class 并重置透明度。
  4. **层级控制**：在 SVG 内部，先定义所有的 `<path>` 填充区域，再定义线条，最后定义文本标签，确保线条和文字始终在最上层，不被半透明填充遮挡。
- ID 命名规范：所有元素 ID 均以 `scene1-` 开头（如 `scene1-btn-next`, `scene1-fill-shaded`）。
- IIFE 隔离：所有 JS 逻辑封装在 `(function() { ... })();` 中，避免全局变量污染。
