场景导航：Scene 1

题目：如图，△OAB绕点O逆时针旋转70°到△OCD，如果∠A=100°，则∠D=50°，那么∠AOD的度数是（）
A.20°
B.30°
C.40°
D.50°

题目分析：

本题考查了图形的旋转变换性质以及三角形内角和定理。

  1. 旋转前后的图形全等，即 △OAB ≅ △OCD，对应角相等。
  2. 旋转角为对应点与旋转中心连线的夹角，即 ∠AOC = 70°，∠BOD = 70°。
  3. 利用三角形内角和求出 ∠COD，再结合图形中的角度和差关系求出 ∠AOD。

整体讲解思路：

通过动画直观展示旋转过程，帮助学生准确找到对应点和旋转角。然后利用全等性质将已知角转移到同一个三角形（△OCD）中，计算出 ∠COD。最后，通过观察图形中的角度包含关系，利用 ∠AOC 和 ∠COD 的差值求出目标角 ∠AOD。

第一步：旋转角
\(\angle AOC = 70^\circ\)
第二步：旋转全等：
\(\angle C = \angle A = 100^\circ\)
已知：\(\angle D = 50^\circ\)
第三步：\( riangle OCD\) 内角和：
\(\angle COD = 180^\circ - 100^\circ - 50^\circ = 30^\circ\)
结论：
\(\angle AOD = \angle AOC - \angle COD\)
\(= 70^\circ - 30^\circ = 40^\circ\)

教学说明与引导要点：

  1. 引导观察旋转： 点击“下一步”播放旋转动画，让学生直观看到 △OAB 是如何运动到 △OCD 的。提问：旋转中心是哪个点？对应点是哪些？旋转角是哪个角？明确：OA 旋转到了 OC，所以 ∠AOC 就是旋转角，即 ∠AOC = 70°。
  2. 利用全等转移条件： 继续演示，强调旋转不改变图形的形状和大小。推导：因为 △OAB ≅ △OCD，所以对应角相等，即 ∠C = ∠A = 100°。结合已知 ∠D = 50°，现在 △OCD 中已经知道了两个角。
  3. 计算局部角度： 引导学生将视线集中在 △OCD 上。推导：根据三角形内角和定理，∠COD = 180° - ∠C - ∠D = 180° - 100° - 50° = 30°。
  4. 结合图形求目标角： 最后，引导学生观察 ∠AOC、∠COD 和 ∠AOD 之间的位置关系。推导：从图中可以清晰看出 ∠AOC = ∠AOD + ∠COD。因此，∠AOD = ∠AOC - ∠COD = 70° - 30° = 40°。得出最终答案选 C。
