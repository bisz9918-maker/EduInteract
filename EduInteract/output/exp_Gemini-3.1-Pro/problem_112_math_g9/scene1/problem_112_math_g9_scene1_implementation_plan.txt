[图示主题与整合说明]
- 本图示主题：旋转变换与角度和差计算
- 整合的步骤/概念：旋转动画演示、对应角转移、三角形内角和计算、目标角度求解
- 教学价值：教师可通过分步按钮，引导学生先观察旋转过程，再将已知条件转移到同一个三角形中，最后通过内角和与角度差完成求解，完美契合逻辑递进的讲解节奏。

[分步序列]
- 初始状态（步骤0）：显示 △OAB、△OCD 及顶点标签。隐藏所有角度标注和右侧文本。
- 步骤1（旋转变换）：
  - 视觉变化：出现蓝色半透明的 △OAB (`scene1-rot-tri`)，并平滑旋转 -70° 与 △OCD 重合。
  - 标注出现：显示 ∠AOC 的绿色圆弧及 70° 标签。
  - 文本面板：显示“第一步：旋转角 ∠AOC = 70°”。
- 步骤2（转移条件）：
  - 视觉变化：隐藏旋转动画用的蓝色三角形。
  - 标注出现：显示 ∠A=100°、∠C=100°、∠D=50° 的蓝色圆弧及标签。
  - 文本面板：追加显示“第二步：旋转全等：∠C = ∠A = 100°，已知：∠D = 50°”。
- 步骤3（计算内角）：
  - 视觉变化：高亮 △OCD (`scene1-tri-ocd-highlight` 红色半透明显示)。
  - 标注出现：显示 ∠COD 的蓝色圆弧及 30° 标签。
  - 文本面板：追加显示“第三步：△OCD 内角和：∠COD = 180° - 100° - 50° = 30°”。
- 步骤4（求解目标）：
  - 视觉变化：取消 △OCD 的高亮。加粗或闪烁 ∠AOC 和 ∠COD 的圆弧（可选）。
  - 标注出现：显示 ∠AOD 的红色圆弧及 40° 标签。
  - 文本面板：追加显示“结论：∠AOD = ∠AOC - ∠COD = 70° - 30° = 40°”（红色加粗）。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：在画布底部（y=460）居中放置两个按钮，控制 currentStep (0~4)。
- 教师操作流程：教师点击“下一步”逐步展示旋转过程、条件转移、内角和计算、最终角度差计算，配合右侧出现的文字进行讲解。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。图形简单，原生 SVG 的 `<path>` 和 `<polygon>` 足以实现，且易于通过 CSS 控制旋转动画和透明度过渡。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  +-------------------------------------------------+
  |                                                 |
  |                                 [右侧文本面板]  |
  |        C                        第一步：...     |
  |         *                       第二步：...     |
  |          \ * D                  第三步：...     |
  |           \ \                   结论：...       |
  |            \ \    A                             |
  |             \ \  *                              |
  |              \ / \                             |
  |               *----* B                          |
  |               O                                 |
  |                                                 |
  |            [◀ 上一步] [下一步 ▶]                |
  +-------------------------------------------------+
  ```
- 关键实现要点：
  - **坐标系**：SVG 默认 y 轴向下。计算角度时需注意，逆时针旋转 70° 在 SVG 中对应 `transform="rotate(-70, 300, 350)"`。
  - **圆弧绘制**：使用 JS 辅助函数生成 SVG path 的 `d` 属性。例如 `M x1 y1 A r r 0 0 0 x2 y2`。注意 SVG 中 y 轴向下时，`sweep-flag` 为 0 表示数学上的顺时针（即 SVG 中的逆时针）。
  - **状态机设计**：定义 `updateScene()` 函数，根据 `currentStep` 的值（0-4），统一设置所有元素的 `opacity` 和 `transform`。利用 CSS `transition: opacity 0.5s, transform 1s` 实现平滑过渡。
  - **ID 命名规范**：所有元素 ID 必须以 `scene1-` 开头，如 `scene1-btn-next`。
  - **IIFE 隔离**：所有 JS 代码包裹在 `(function() { ... })()` 中，避免全局变量污染。
