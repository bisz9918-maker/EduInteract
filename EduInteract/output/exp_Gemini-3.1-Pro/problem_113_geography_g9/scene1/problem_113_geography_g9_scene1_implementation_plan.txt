[图示主题与整合说明]
- 本图示主题：极地经纬网中的经度推断与方向判定
- 整合的步骤/概念：基础图形识别、经度差推导 P 点经度、0°经线定位、自转方向与极点判定、东西半球划分。
- 教学价值：通过分步动画，帮助学生清晰理解在不同经度差条件下，如何推导未知经度、判定地球自转方向及极点，并最终掌握东西半球的划分方法。分步展示能有效降低认知负荷，符合教师逐步引导的教学节奏。

[视觉元素清单]
- 基础经纬网：极点 O、纬线 L、经线 OP、经线 OQ、交点 P、交点 Q。颜色：#000000，实线，2px。
- 辅助经线：0°经线、20°W经线。颜色：#888888，虚线，2px。
- 动态箭头：向东直线箭头、自转圆弧箭头。颜色：#1565c0（蓝色），2px。
- 动态标签：45°E、45°W、南极(S)、北极(N)、向东。颜色：#1565c0（蓝色），加粗。
- 半球高亮：西半球扇形（#c62828，透明度20%），东半球扇形（#2e7d32，透明度20%）。

[分步序列]
- 初始状态（步骤0）：显示基础经纬网（O, L, OP, OQ, P, Q）及基础标签。P点度数显示为黑色的 "45°"。文本框显示：“已知极地经纬网局部，P、Q所在经线及Q点经度15°E。”
- 步骤1：P点度数更新为蓝色的 "45°E"。文本框更新：“条件一：P、Q经度差为30°。已知Q为15°E，P的度数为45°，因此P点经度必然是45°E（45°E - 15°E = 30°）。”
- 步骤2：出现向左的蓝色直线箭头（向东），出现顺时针的蓝色自转圆弧箭头，显示蓝色标签 "南极(S)"。文本框更新：“经度向东递增。从15°E到45°E为向东方向（图中向左）。顺着向东方向，地球自转呈顺时针，说明O为南极点。”
- 步骤3：隐藏步骤2新增的箭头和极点标签。P点度数更新为蓝色的 "45°W"。文本框更新：“条件二：P、Q经度差为60°。已知Q为15°E，P的度数为45°，因此P点经度必然是45°W（45°W + 15°E = 60°）。”
- 步骤4：出现 0° 经线及标签。出现向右的蓝色直线箭头（向东），出现逆时针的蓝色自转圆弧箭头，显示蓝色标签 "北极(N)"。文本框更新：“从45°W向东到15°E（图中向右），跨越0°经线。顺着向东方向，地球自转呈逆时针，说明O为北极点。”
- 步骤5：在步骤4基础上，出现 20°W 经线及标签。显示红色的西半球扇形及标签，绿色的东半球扇形及标签。文本框更新：“20°W以西为西半球，以东为东半球。如图划分可知，P(45°W)位于西半球，Q(15°E)位于东半球。”

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：在 SVG 底部（y=460区域）居中放置两个按钮，控制 currentStep (0~5) 的增减。
- 教师操作流程：教师首先展示原图，然后点击“下一步”逐步揭示经度差为30°时的推导过程和极点判定；接着继续点击“下一步”切换到经度差为60°的条件，展示新的推导过程、极点判定，并最终展示东西半球的划分。可随时点击“上一步”回退复习。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。图形均为基础几何线段和圆弧，原生 SVG 易于精确控制坐标和样式，无需引入额外库。
- 画布尺寸：800 × 500 px（沿用规格）
- 布局草图：
  ```
  [图示区 800×500]
  +------------------------------------------------+
  | [结论文本框]            向东 ->                 |
  | (20,20)                  (N)                   |
  |                           O                    |
  |                         / | \                  |
  |                       /   |   \                |
  |                     /     |     \              |
  |            L ---- P-------+-------Q ----       |
  |                 /         |         \          |
  |               /           |           \        |
  |             45°W        20°W 0°       15°E     |
  |                                                |
  |               [ ◀ 上一步 ] [ 下一步 ▶ ]        |
  +------------------------------------------------+
  ```
- 关键实现要点：
  - 箭头标记：使用 `<defs><marker>` 定义蓝色箭头样式，通过 `marker-end` 附加到直线和圆弧路径上。
  - 扇形绘制：使用 `<path>` 的 `A` (Arc) 指令绘制。注意 `sweep-flag` 的设置（0为逆时针，1为顺时针）。例如西半球路径为 `M 400 120 L 273.8 300.2 A 220 220 0 0 0 377 338.8 Z`。
  - 状态机设计：定义 `let scene1_currentStep = 0;`，编写 `scene1_updateStep(step)` 函数，内部使用 `switch` 语句统一控制各 SVG 元素的 `display` 属性（'none' 或 'block'）以及文本框的 `innerHTML`。
  - 动画过渡：为需要显示/隐藏的组（`<g>`）添加 CSS `transition: opacity 0.3s`，通过切换类名或直接修改 `opacity` 实现平滑过渡。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-btn-next`, `scene1-p-label`, `scene1-text-box`），避免跨场景污染。
- IIFE 隔离：所有 JS 代码必须包裹在 `(function() { ... })()` 中。
