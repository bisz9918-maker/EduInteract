[图示主题与整合说明]
- 本图示主题：地球自转方向与南北半球的判定
- 整合的步骤/概念：将二维极地俯视图中的顺时针/逆时针自转箭头，与三维地球模型的自转视角（南极/北极俯视）建立直观联系，帮助学生理解“顺南逆北”的判定法则。
- 教学价值：教师可通过分步演示，引导学生从抽象的二维箭头过渡到具象的三维地球自转，最后落实到具体点（B点）的半球判定，化解空间想象的难点。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：在 SVG 底部（y=460）居中放置“上一步”和“下一步”按钮。
- 教师操作流程：教师首先展示二维平面图，提问自转方向代表的半球；点击“下一步”展示南半球的三维旋转，验证顺时针；再次点击展示北半球的三维旋转，验证逆时针；最后点击得出B点所在半球的结论。

[技术实现]
- JS 库选择及原因：使用 D3.js (v7)。D3.js 的 `d3.geoOrthographic` 和 `d3.geoGraticule` 非常适合绘制和旋转 3D 地球网格模型，同时 D3 也方便操作 SVG 元素进行状态切换。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800x500]
  (200,120)左2D图       (600,120)右2D图
  (200,340)左3D地球     (600,340)右3D地球
  [控件栏 y=460 居中]
  ```
- 关键实现要点：
  - 状态机设计：定义 `step` 变量（0-3），每次点击按钮更新 `step` 并调用 `updateState()` 函数。
  - 3D地球绘制：使用 `d3.geoOrthographic().scale(70).translate([x, y])`。左侧南极俯视设置 `.rotate([0, 90])`，右侧北极俯视设置 `.rotate([0, -90])`。
  - 动画实现：使用 `d3.timer`。在 timer 回调中，根据当前步骤，如果 step >= 1，更新左侧地球的 `rotate` 的 lambda 值（减小，实现顺时针）；如果 step >= 2，更新右侧地球的 `rotate` 的 lambda 值（增加，实现逆时针）。每次更新后重新生成 path 并赋给 `<path>` 的 `d` 属性。
  - ID 命名规范：所有交互元素 ID 以 `scene1-` 为前缀，如 `scene1-left-arrow`, `scene1-right-globe`。
  - IIFE 隔离：所有 JS 代码包裹在 `(function() { ... })()` 中。
