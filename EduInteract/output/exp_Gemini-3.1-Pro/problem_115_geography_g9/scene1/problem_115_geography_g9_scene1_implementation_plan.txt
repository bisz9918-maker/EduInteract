[图示主题与整合说明]
- 本图示主题：对跖点（地球对角点）的空间位置与坐标推导
- 整合的步骤/概念：将“穿过地心”的抽象空间想象具象化，分步推导对跖点纬度相反、经度互补的几何规律。
- 教学价值：教师可通过分步演示，先建立3D空间中穿过地心的直线概念，再分别通过侧视剖面和极点俯视图，清晰拆解纬度和经度的计算逻辑，化解学生的空间想象难点。

[分步序列]
- 初始状态（步骤0）：显示3D地球线框（轮廓、赤道、本初子午线）、地心O、点A及其坐标标签。
- 步骤1（遁地路线）：点击「下一步」，出现从A穿过O到达另一侧的灰色虚线，以及红色的点B，标签显示为 B(?, ?)。
- 步骤2（纬度推导）：点击「下一步」，高亮显示A和B所在的经线圈剖面（半透明蓝色椭圆），出现赤道面内部连线，以及两侧的30°对顶角弧线和标签。点B标签更新为 B(30°S, ?)。
- 步骤3（经度推导）：点击「下一步」，右侧淡入2D北极点俯视图，展示0°、120°E和60°W的经线关系，以及跨越北极点的180°灰色弧线。点B标签更新为 B(30°S, 60°W)。
- 步骤4（结论）：点击「下一步」，点B的坐标标签 B(30°S, 60°W) 字体加粗并略微放大，2D视图中的60°W经线加粗，强调最终结论。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。图形均为标准几何体（圆、椭圆、线段、弧线），SVG 能够提供最清晰的渲染和最精确的标签定位，无需引入庞大的 3D 库。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  +-------------------------+--------------------+
  |                         |                    |
  |       3D地球剖面图      |    2D极点俯视图    |
  |       (中心 300,250)    |   (中心 650,250)   |
  |                         |                    |
  +-------------------------+--------------------+
  [控件栏 (y=460)  ◀ 上一步   下一步 ▶ ]
  ```
- 关键实现要点：
  1. **3D投影模拟**：本初子午线使用 JS 预先计算生成 `<path>`。投影公式：`x = 300 + R*cos(lat)*sin(-30°)`，`y = 250 - (R*sin(lat)*cos(15°) - R*cos(lat)*cos(-30°)*sin(15°))`，循环 lat 从 -90 到 90 生成路径。
  2. **状态机设计**：定义 `currentStep` (0-4)，通过 `updateState()` 函数控制各个 SVG `<g>` 组的 `opacity` (0 或 1)，并配合 CSS `transition: opacity 0.5s` 实现平滑过渡。
  3. **动态文本更新**：点B的 `<text>` 标签内容根据步骤动态修改（`B(?, ?)` -> `B(30°S, ?)` -> `B(30°S, 60°W)`）。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-step1-group`, `scene1-label-b`）。
- IIFE 隔离：所有 JS 逻辑封装在 `(function() { ... })()` 中，避免全局变量污染。
