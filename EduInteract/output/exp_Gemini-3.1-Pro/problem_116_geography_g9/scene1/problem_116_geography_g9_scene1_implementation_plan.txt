[图示主题与整合说明]
- 本图示主题：提取A、B两点的经纬度坐标
- 整合的步骤/概念：左图（斜交网格）B点坐标的判读过程与右图（矩形网格）A点坐标的判读过程。
- 教学价值：通过分步高亮特定的网格线和刻度，并配合递增方向的箭头提示，引导学生逐步掌握在不同投影网格下判读经纬度的方法，有效降低认知负荷。

[分步序列]
- 初始状态（步骤0）：显示左右两图的基础网格、刻度标签、A点和B点。隐藏所有高亮线、箭头和结论文本。
- 步骤1（判读B点纬度）：
  - 出现：左图L60纬线高亮（红色）。
  - 出现：左图右侧外侧添加绿色虚线箭头（从y=280指向y=160，x=380），旁边显示垂直文本“向上递增为北纬”（x=400, y=220）。
  - 出现：左图下方显示文本“B点纬度：60°N”（x=200, y=440）。
- 步骤2（判读B点经度）：
  - 保持：步骤1的所有元素。
  - 出现：左图P160L经线高亮（蓝色）。
  - 出现：左图斜边外侧添加绿色虚线箭头（从(30,120)指向(130,220)），旁边显示旋转45度的文本“向180°递增为东经”（x=20, y=180）。
  - 变化：左图下方文本更新为“B(160°E, 60°N)”。
- 步骤3（判读A点坐标）：
  - 保持：步骤1、2的所有元素。
  - 出现：右图y=400水平线高亮（红色），x=640垂直线高亮（蓝色）。
  - 出现：右图顶部添加绿色虚线箭头（从x=480指向x=640，y=70），上方显示文本“向右递增为东经”（x=560, y=55）。
  - 出现：右图右侧添加绿色虚线箭头（从y=400指向y=100，x=750），旁边显示垂直文本“向上递增为北纬”（x=770, y=250）。
  - 出现：右图下方显示文本“A(150°E, 0°)”（x=600, y=440）。

[标签冲突检查]
- B点标签("B")：坐标(170, 100)，位于网格内部靠近顶部，不与任何线段重叠。
- 左图斜边标签：向左下偏移(-25, 10)，完全位于三角形外部，安全。
- 左图右侧标签：向右偏移(10, 5)，x=360，与右侧箭头(x=380)保持20px间距，安全。
- 右图顶部标签：向上偏移(0, -10)，y=90，与顶部箭头(y=70)保持20px间距，安全。
- 右图右侧标签：向右偏移(10, 5)，x=730，与右侧箭头(x=750)保持20px间距，安全。
- 结论文本：位于y=440，远离图形区域(最大y=400)，安全。

[交互方案]
- 交互类型：分步按钮导航
- 控件说明：底部居中放置两个按钮：“◀ 上一步” 和 “下一步 ▶”。
- 教师操作流程：教师点击“下一步”逐步展示B点纬度、B点经度、A点坐标的判读过程，配合箭头提示讲解递增规律。可随时点击“上一步”回退。

[技术实现]
- JS 库选择：原生 SVG。图形由直线和文本构成，SVG 的 `<line>`, `<polygon>`, `<text>` 标签能完美实现，且易于通过 CSS 控制显示/隐藏。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×450]
    (左侧：斜交网格 300x300)      (右侧：矩形网格 240x300)
  [控件栏 800×50]
    [ ◀ 上一步 ] [ 下一步 ▶ ]
  ```
- 关键实现要点：
  - 使用 `<g>` 标签将不同步骤的元素分组（如 `id="scene1-step1-group"`）。
  - 垂直文本可通过在 `<text>` 中嵌套多个 `<tspan x="..." dy="1.2em">` 实现。
  - 旋转文本使用 `transform="rotate(45, x, y)"` 属性。
  - 箭头可通过定义 `<marker>` 并在虚线上使用 `marker-end` 属性实现。
  - 状态机：JS 维护 `currentStep` (0~3) 变量，每次点击按钮更新变量，并遍历所有步骤组，根据 `currentStep` 控制 `display` 属性（或 `opacity`）。
- ID 命名规范：所有交互元素和分组 ID 必须以 `scene1-` 为前缀。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
