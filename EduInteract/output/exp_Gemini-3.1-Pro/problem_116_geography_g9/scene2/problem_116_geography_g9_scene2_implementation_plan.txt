[图示主题与整合说明]
- 本图示主题：在统一经纬度坐标系中判断相对方向
- 整合的步骤/概念：将A、B两点放置在同一个标准直角坐标系中，建立方向标并连线判断方向
- 教学价值：教师可以通过分步演示，引导学生先定位两点坐标，再以参考点建立方向标，最后连线直观得出相对方向，符合地理方向判断的标准逻辑。

[视觉元素清单]
- 坐标系：X轴表示经度（140°E - 170°E），Y轴表示纬度（0° - 70°N）。网格线颜色 #888888 虚线，线宽1px。
- 刻度标签：颜色 #000000，字号 14px。
- 点A、点B：#000000 实心圆点，半径4px。
- 点A、B坐标标签：颜色 #000000，字号 14px，加粗。
- 十字方向标：#1565c0，实线，线宽2px。包含 N, S, W, E 标签，颜色 #1565c0。
- B到A的指示箭头：#c62828，粗实线，线宽3px，带箭头。
- 结论标签“西南方向”：颜色 #c62828，字号 18px，加粗。

[分步序列]
- 初始状态（步骤0）：显示坐标网格、刻度标签、点A、点B及其坐标标签。隐藏方向标、指示箭头和结论标签。
- 步骤1：点击「下一步」→ 在点B处出现十字方向标及 N, S, W, E 标签。
- 步骤2：点击「下一步」→ 从点B向点A绘制动态生长的红色指示箭头。方向标的“W(西)”和“S(南)”标签高亮（变为红色 #c62828 并放大/加粗）。在箭头左侧淡入显示结论标签“西南方向”。

[标签冲突检查]
- A点标签(360,350) vs X轴刻度150°E(350,380)：Y方向错开30px，无冲突。
- B点标签(460,100) vs 方向标N(450,60) / E(510,125)：B点标签在第一象限，N在正上，E在正右，空间充足，无冲突。
- 结论标签(380,240) vs 方向标W(390,125) / S(450,185)：结论标签在第三象限远端，距离方向标较远，无冲突。
- 结论标签(380,240) vs 箭头线段(400,240)：结论标签在箭头左侧20px，无冲突。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：在 SVG 底部（y=460）居中放置两个按钮，控制步骤 0 -> 1 -> 2 的切换。
- 教师操作流程：教师首先展示A、B两点在坐标系中的位置；点击下一步，在B点建立方向标，讲解以B为参考点；再次点击下一步，连线并得出A在B的西南方向，完成解题逻辑演示。

[技术实现]
- JS 库选择及原因：原生 SVG。由于全是规则的几何图形、连线和文本，SVG 能够提供最清晰的渲染和最方便的 DOM 动画控制。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×440]
    (Y轴刻度)
       |
      70 +-----------------------+
         |                       |
         |         B(160°E,60°N) |
         |          +            |
         |         /             |
         |        /              |
         |       /               |
       0 +------+----------------+ (X轴刻度)
               A(150°E,0°)
  [控件栏 800×60 (y=440~500)]
       [◀ 上一步] [下一步 ▶]
  ```
- 关键实现要点：
  - 坐标映射：严格按照 X: 250-550, Y: 80-360 的像素坐标绘制网格。
  - 箭头动画：使用 SVG `stroke-dasharray` 和 `stroke-dashoffset` 实现从 B 到 A 的线条生长动画。
  - 状态机：定义 `currentStep` 变量，通过按钮点击更新，并根据步骤控制对应 SVG 元素的 `opacity` 和 `transition`。
  - ID 命名规范：所有元素 ID 以 `scene2-` 开头，如 `scene2-grid`, `scene2-pointA`, `scene2-arrow` 等。
  - IIFE 隔离：所有逻辑封装在 `(function() { ... })()` 中。
