[图示主题与整合说明]
- 本图示主题：动态电路的等效分析与电表示数关系推导
- 整合的步骤/概念：电路等效简化、滑片移动对电流/电压的影响、各选项表达式的物理意义推导
- 教学价值：教师可通过分步导航，先引导学生进行静态的电路等效分析（明确各电表测量的对象及被短路的部分），再通过动画演示滑片移动带来的动态变化，最后逐一推导各个代数式的物理意义，完美契合剥丝抽茧的讲解节奏。

[分步序列]
- 初始状态（步骤0）：显示原始电路图，无任何高亮。右侧面板显示标题“动态电路分析与电表示数关系推导”及“点击下一步开始分析”。
- 步骤1（等效电路）：
  - 视觉变化：显示红色高亮电流路径（电源 -> S -> R1 -> R2左半段 -> P -> A -> 电源）；R2 右半段变为灰色虚线；显示 V1 蓝色高亮区和 V2 绿色高亮区。
  - 右侧面板：显示“1. 电路等效分析”，说明 R1 与 R2 接入部分串联，R2 右半段被短路，明确 V1 和 V2 的测量对象。
- 步骤2（选项A分析）：
  - 视觉变化：触发动画，滑片 P 从 x=270 平滑移动到 x=210。红色电流路径、灰色虚线、V1蓝色高亮区随之动态更新。
  - 右侧面板：显示“2. 选项 A 分析”，推导 $U_2/I = R_{总}$，得出结论“变小”。
- 步骤3（选项B分析）：
  - 视觉变化：R1 出现橙色高亮边框。
  - 右侧面板：显示“3. 选项 B 分析”，推导 $(U_2 - U_1)/I = R_1$，得出结论“不变”。
- 步骤4（选项C、D分析）：
  - 视觉变化：保持步骤3状态。
  - 右侧面板：显示“4. 选项 C、D 分析”，推导 $|\Delta U_1 / \Delta I| = R_1$ 且 $\Delta U_2 = 0$，得出最终结论。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：底部居中放置两个按钮，控制 step 变量 (0~4)。
- 教师操作流程：教师点击“下一步”逐步揭示电路的等效结构，然后触发滑片移动动画，最后一步步展示各选项的公式推导过程，配合板书或口头讲解。

[技术实现]
- JS 库选择：原生 SVG 绘制电路图（易于实现路径动画和局部高亮），MathJax 渲染右侧面板的数学公式。
- 画布尺寸：800 × 500 px。
- 布局草图：
  [ 左侧 SVG 电路图 420×440 ] [ 右侧 div 推导面板 360×440 ]
  [ 底部控件栏 800×50 (上一步) (下一步) ]
- 关键实现要点：
  1. 状态机：使用 `currentStep` 变量，每次点击按钮调用 `updateScene()` 函数。
  2. 动画实现：步骤2的滑片移动使用 `requestAnimationFrame`。定义 `sliderX` 变量，从 270 渐变到 210（时长约 1 秒）。在动画循环中，实时更新滑片 P 的 `transform`、红色高亮路径的 `d` 属性、灰色虚线的 `x1` 属性、V1 高亮矩形的 `width`。
  3. 右侧面板：预先写好 4 个步骤的 HTML 内容（包含 LaTeX 公式），通过 CSS `display: none/block` 切换显示，并在切换后调用 `MathJax.typesetPromise()` 重新渲染。
  4. ID 命名规范：所有 DOM 元素的 ID 必须以 `scene1-` 开头，例如 `scene1-svg`, `scene1-slider`, `scene1-btn-next`。
  5. IIFE 隔离：整个脚本包裹在 `(function() { ... })();` 中，避免全局变量污染。
