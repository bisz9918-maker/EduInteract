problem_119_physics_g9

场景导航：Scene 1

题目原文：
如图所示的电路中，闭合开关S，当滑动变阻器的滑片P向右滑动时（ ）
A 、灯L$_{1}$变亮，灯L$_{2}$变暗 B 、灯L$_{2}$变亮，灯L$_{1}$亮度不变 C 、灯L$_{1}$和L$_{2}$均变暗 D 、灯L$_{1}$亮度变化，灯L$_{2}$亮度不变

题目分析：

  1. 电路结构分析：闭合开关S后，电流从电源正极流出，在右侧节点分为两路。一路向下经过灯泡L1，另一路向左经过灯泡L2和滑动变阻器。两路在左侧节点汇合，流回电源负极。因此，这是一个并联电路，L1支路与“L2+变阻器”支路并联。
  2. 滑动变阻器分析：滑动变阻器的滑片P与左侧导线相连，右侧接线柱与L2相连。因此，变阻器接入电路的是滑片P到右端的部分。
  3. 动态过程分析：
  • 当滑片P向右滑动时，接入电路的电阻丝长度变短，变阻器接入电路的阻值减小。
  • 对于L2所在支路：支路总电阻减小。因为并联电路各支路两端电压等于电源电压（保持不变），根据欧姆定律 $I =

rac{U}{R}$，该支路电流增大。根据 $P = I^2R$，灯泡L2的实际功率增大，亮度变亮。

  • 对于L1所在支路：两端电压不变，电阻不变，因此电流不变，灯泡L1的亮度不变。

整体讲解思路：

  1. 带领学生识别电路的连接方式（并联）。
  2. 明确滑动变阻器哪一部分接入了电路（右侧部分）。
  3. 分析滑片移动带来的电阻变化。
  4. 分别对两条支路应用欧姆定律，得出电流变化，进而得出亮度变化。

图示规划说明：
设计一个交互式电路图，允许教师拖拽滑片P。通过动态改变变阻器有效部分的颜色高亮、支路电流箭头的粗细以及灯泡的光晕大小，直观展示滑片移动对并联电路各支路的独立影响。

提示：左右拖拽滑块 P，观察各支路电流和灯泡亮度的变化

本图示的教学说明：

  1. 引导观察电路结构：首先让学生观察图示，明确电流的分流和汇合点，确认 L1 与 L2 处于并联状态。
  1. 确认有效电阻：指出滑动变阻器上红色高亮的部分即为接入电路的有效电阻（滑片 P 到右端的部分）。
  1. 演示动态变化：
  • 缓慢向右拖拽滑片 P，引导学生观察红色有效电阻段变短，理解电阻减小。
  • 引导学生观察 L2 支路上的蓝色电流箭头变粗，结合公式 $I =

rac{U}{R}$ 解释电流增大的原因。

  • 观察 L2 灯泡的黄色光晕变大，结合公式 $P = I^2R$ 得出 L2 变亮的结论。
  • 重点引导学生观察 L1 支路：在拖拽过程中，L1 支路的电流箭头和灯泡光晕始终不变，借此强调并联电路中各支路独立工作、互不影响的重要性质。
  1. 得出结论：综合以上观察，得出正确选项 B。
