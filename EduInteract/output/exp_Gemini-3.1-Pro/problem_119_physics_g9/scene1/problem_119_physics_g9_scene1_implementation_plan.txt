[图示主题与整合说明]
- 本图示主题：滑动变阻器对并联电路各支路的影响
- 整合的步骤/概念：电路结构的识别（并联）、滑动变阻器有效阻值变化、各支路电流及灯泡亮度变化。
- 教学价值：教师可通过拖拽滑块，直观展示并联电路中一条支路电阻变化时，该支路电流和灯泡亮度的动态变化，同时验证另一条支路不受影响的物理规律。

[视觉元素清单]
- 导线与节点：黑色 `#000000`，线宽 2px。节点为半径 4px 的黑色实心圆。
- 开关 S：黑色线段连接 (280,100) 和 (340,100)，两端有半径 3px 的黑点。标签 "S" 在 (310,70)。
- 电源：包含两节电池。负极短粗线 (460,85)-(460,115) 宽4px；正极长细线 (475,75)-(475,125) 宽2px；负极短粗线 (490,85)-(490,115) 宽4px；正极长细线 (505,75)-(505,125) 宽2px。内部连接线 (475,100)-(490,100)。
- 变阻器：
  - 底框：白底黑边矩形，`fill="#ffffff" stroke="#000000" stroke-width="2"`。
  - 有效段（右侧部分）：红底红边矩形，`fill="#ffcdd2" stroke="#c62828" stroke-width="2"`，直观显示接入电路的电阻长度。
- 滑块 P：黑色箭头，包含垂直线和箭头头部 `M P_x 220 L P_x 240 M P_x-6 232 L P_x 240 L P_x+6 232`。标签 "P" 在 (P_x+15, 210)。
- 灯泡 L1/L2：白底黑边圆形，内部有交叉线（如 `M 482.4 232.4 L 517.6 267.6`）。
- 光晕：位于灯泡底层，黄色 `#fbc02d`，无边框，通过调整 `opacity` 和 `r` (半径) 表示亮度。
- 电流箭头：蓝色 `#1565c0`，无填充，通过调整 `stroke-width` 表示电流大小。

[分步序列]
本场景为连续拖拽交互，无离散步骤，状态随滑块 P 的位置 (P_x ∈ [250, 400]) 实时变化：
- 初始状态：滑块 P 位于中点 (P_x = 325)。变阻器有效段宽度为 75px。L1 和 L2 均正常发光，各电流箭头显示中等粗细。
- 动态状态（向右拖拽）：P_x 增大，变阻器有效段（红色矩形）变短（电阻减小）。
  - L2 支路：电流增大，L2 支路蓝色箭头变粗，L2 黄色光晕半径增大、透明度提高（变亮）。
  - L1 支路：不受影响，L1 支路蓝色箭头粗细不变，L1 黄色光晕保持不变。
  - 主干路：总电流增大，主干路蓝色箭头变粗。
- 动态状态（向左拖拽）：P_x 减小，变阻器有效段变长（电阻增大）。L2 支路电流减小，箭头变细，光晕变小变暗。L1 支路保持不变。

[标签冲突检查]
- 标签 "S" (310, 70) vs 顶部导线 (y=100)：间距 30px，无冲突。
- 标签 "P" (P_x+15, 210) vs 滑块水平线 (y=220)：间距 10px，且在滑块右侧，无冲突。
- 标签 "L2" (500, 210) vs L2 圆形顶部 (y=225)：间距 15px，无冲突。
- 标签 "L1" (500, 360) vs L1 圆形顶部 (y=375)：间距 15px，无冲突。
- 电流箭头均放置在导线中间空白区域，远离节点和元件，无冲突。

[交互方案]
- 交互类型：连续拖拽。
- 控件说明：在滑块 P 区域覆盖一个透明的拖拽热区（宽40px，高40px，`cursor: ew-resize`）。底部文本提示：“提示：左右拖拽滑块 P，观察各支路电流和灯泡亮度的变化”。
- 教师操作流程：教师在讲解时，直接用鼠标按住滑块 P 左右拖动，引导学生观察 L2 亮度的变化以及 L1 亮度的不变，从而得出并联电路各支路互不影响的结论。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript。电路图由标准几何图形构成，原生 SVG 性能最佳且易于实现拖拽和属性绑定。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  (200,100)-----------------S-----------------电池-----(600,100)
      |                                                  |
      |---(P_x,220)                                      |
      |       |                                          |
      |    [变阻器]---------L2(光晕)---------------------| (y=250)
      |                                                  |
      |---------------------L1(光晕)---------------------| (y=400)
  ```
- 关键实现要点：
  1. 状态映射：定义 `t = (P_x - 250) / 150` (0~1)。
  2. 物理模型：设 L1 和 L2 基础电阻为 R，变阻器最大电阻为 2R。L2 支路电流 `I2 ∝ 1 / (1 + 2*(1-t))`，L1 支路电流 `I1 ∝ 1`（常数）。
  3. 视觉绑定：在 `mousemove` 事件中更新 P_x，并实时计算 I2。将 I2 映射到 L2 光晕的 `r` 和 `opacity`，以及 L2 箭头的 `stroke-width`。
  4. 拖拽边界：严格限制 `P_x` 在 `Math.max(250, Math.min(400, newX))` 范围内。
- ID 命名规范：所有元素 ID 均以 `scene1-` 开头，如 `scene1-slider`, `scene1-l2-halo`, `scene1-arrow-l2`。
- IIFE 隔离：所有逻辑封装在 `(function() { ... })()` 中，避免全局变量污染。
