[图示主题与整合说明]
- 本图示主题：整体法与隔离法受力分析演示
- 整合的步骤/概念：整体受力平衡、摩擦力均摊、局部隔离受力平衡
- 教学价值：教师可通过分步导航，引导学生先将多个物体看作一个整体求出总摩擦力，再根据相同物块的特性均摊摩擦力，最后通过隔离法取部分物块作为新整体，轻松求出内部相互作用力。避免了一次性展示所有力导致的视觉混乱。

[分步序列]
- 步骤0（初始状态）：显示地面、物块1-6、推力F及其标签。顶部无文字。
- 步骤1（整体分析）：显示整体高亮框（框选1-6），显示总摩擦力f_总及其标签。顶部文字显示：“整体分析：匀速直线运动，受力平衡”。
- 步骤2（摩擦力均摊）：隐藏总摩擦力f_总及其标签，显示6个分摩擦力f1-f6及其标签。顶部文字显示：“摩擦力均摊：总摩擦力平分给6个物块”。
- 步骤3（隔离分析）：物块1-3、推力F及其标签、分摩擦力f1-f3及其标签的透明度降至30%。隐藏整体高亮框，显示局部高亮框（框选4-6）。顶部文字显示：“隔离分析：将4-6号物块作为一个新整体”。
- 步骤4（局部平衡）：在局部高亮框左侧显示内部推力F_34及其标签。顶部文字显示：“局部平衡：F_34 = 3 × 1N = 3N”。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：在SVG底部（y=460区域）放置两个按钮，控制步骤0至4的切换。
- 教师操作流程：教师点击“下一步”逐步展示受力分析过程，配合顶部文字进行讲解；可随时点击“上一步”回退。

[技术实现]
- JS 库选择及原因：原生 SVG。图形均为简单几何体和箭头，SVG 易于实现且支持 CSS 动画过渡。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
    (顶部文字区 y=120)
    (物块及推力区 y=200~260)
    (摩擦力区 y=285~305)
  [控件栏（上一步/下一步按钮，在SVG内底部 y=460）]
  ```
- 关键实现要点：
  - 使用 `<g>` 标签对元素进行分组，便于统一控制透明度（如 `scene1-group-blocks123`）。
  - 箭头绘制：使用 `<marker>` 定义箭头头部，复用于所有力向量。
  - 状态机设计：定义 `updateStep(step)` 函数，根据传入的 step 值（0-4），通过修改元素的 `style.opacity` 和 `style.display` 来控制显隐。
  - 动画过渡：为所有 SVG 元素的 `opacity` 属性添加 CSS `transition: opacity 0.5s ease`，实现平滑的淡入淡出效果。
  - ID 命名规范：所有 ID 均以 `scene1-` 开头，如 `scene1-btn-prev`, `scene1-force-f`。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
