[图示主题与整合说明]
- 本图示主题：均匀薄板的等效电路转换与电阻计算
- 整合的步骤/概念：小方块电阻分析、等势线识别、等效电路图转换、挖去方块后的电路变化及计算
- 教学价值：教师可以通过分步动画，清晰地向学生展示如何将一个连续的导电薄板离散化为电阻网络，利用等势线原理简化电路，并直观演示挖去一部分后电路拓扑的变化及总电阻的计算过程。

[分步序列]
- 初始状态（步骤0）：显示带有接线柱A、B的均匀金属薄板（蓝色半透明填充），两侧有黑色接触条，板内有 3×3 灰色虚线网格。底部无文本。
- 步骤1：点击「下一步」→ 左上角的小方块（250,75至350,145）填充变为绿色半透明。底部出现文本：“单个小方块电阻推导：r = ρ·(L/3) / ((W/3)·d) = ρ·L / (W·d) = R”。
- 步骤2：点击「下一步」→ 绿色高亮消失。两条竖直的网格虚线（x=350, x=450）变为红色粗实线，上方出现红色标签“等势线”。底部文本更新为：“在等势线上插入理想导电条不影响总电阻”。
- 步骤3：点击「下一步」→ 金属板的蓝色填充和网格线淡出，平滑过渡为 3×3 的电阻网络（蓝色线条和电阻符号）。等势线变为电阻网络的竖直导线。每个电阻上方出现标签“R”。底部文本更新为：“等效为3组并联电路串联”。
- 步骤4：点击「下一步」→ 中间的电阻（400,180）及其标签“R”透明度降至0.3，并在其上出现一个红色大叉。底部文本更新为：“挖去中间小块，该组变为2个电阻并联”。
- 步骤5：点击「下一步」→ 在电路图下方逐步展示计算公式：第一组下方(300,320)显示“R/3”，第二组下方(400,320)显示“R/2”，第三组下方(500,320)显示“R/3”。底部中心(400,380)出现红色大号加粗文本：“总电阻 R_总 = R/3 + R/2 + R/3 = 7R/6”。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：在 SVG 底部 (y=450~490) 放置两个按钮，控制步骤 0~5 的切换。
- 教师操作流程：教师首先展示原图，然后点击下一步讲解单块电阻，接着引出等势线概念，再转换为等效电路，演示挖去方块的物理意义，最后展示计算过程。每一步都可通过上一步按钮回退复习。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。SVG 非常适合绘制几何图形、电路符号和实现平滑的透明度/颜色过渡动画。无需引入庞大的外部库。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
    (150,180) A --- [ 金属板 / 电阻网络 ] --- B (650,180)
                    (250,75)      (550,285)
    
    [ 底部文本区 y=340~400 ]
  [控件栏 y=450~490, 包含 上一步 / 下一步 按钮]
  ```
- 关键实现要点：
  - 状态机设计：定义 `currentStep` 变量（0-5），编写 `updateStep()` 函数，根据当前步骤控制各 SVG 元素的 `opacity`、`stroke`、`fill` 等属性。
  - 动画过渡：在 SVG 元素上使用 CSS `transition: all 0.5s ease;` 实现平滑的淡入淡出和颜色变化。
  - 电阻符号绘制：使用 `<path>` 绘制锯齿状的电阻符号，例如 `M -20 0 L -15 0 L -10 -5 L 0 5 L 10 -5 L 15 0 L 20 0`，通过 `<use>` 标签复用9次，便于统一管理和定位。
  - 文本更新：底部文本使用 `<text>` 或 `<foreignObject>` 包含 HTML，以便于渲染简单的数学公式。
  - ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-metal-plate`, `scene1-resistor-2-2`）。
  - IIFE 隔离：所有 JS 代码包裹在 `(function() { ... })()` 中。
