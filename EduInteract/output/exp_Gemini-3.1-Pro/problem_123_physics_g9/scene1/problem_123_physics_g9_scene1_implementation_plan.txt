[视觉元素清单]
- 容器与管路：黑色描边 #000000，无填充（中心细管背景为白色以遮挡容器线）。
- 水体：默认填充 #1565c0，透明度 30%。
- 密封塞/支撑柱：灰色填充 #888888。
- 辅助线：灰色虚线 #888888，stroke-dasharray="5,5"。
- 高度差箭头与文本：红色 #c62828。
- 压强公式文本：黑色 #000000，下标使用 `<tspan>` 实现。
- 高亮样式：水体高亮时透明度提升至 60% 并增加 #c62828 描边；气管高亮时描边加粗至 3px 并变为 #c62828。

[分步序列]
- 初始状态（步骤0）：显示所有容器、管路、水体、开关M、密封塞，以及基础标签（甲、乙、丙、M、P_0）。隐藏所有辅助线、高度差箭头和推导公式。
- 步骤1（甲丙连通器）：点击「下一步」。
  - 视觉变化：高亮甲水体、丙水体、右管水体。显示 h_甲丙 辅助线、箭头及标签。显示 P_gas(丙) 公式文本。
- 步骤2（乙丙气体连通）：点击「下一步」。
  - 视觉变化：取消步骤1的水体高亮。高亮左侧气管。保持步骤1的标注显示。显示 P_gas(乙) 公式文本。
- 步骤3（中心细管压强）：点击「下一步」。
  - 视觉变化：取消步骤2的气管高亮。高亮中心细管水体。保持之前的标注显示。显示 h_乙丙 辅助线、箭头及标签。显示 P_M 公式文本。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：在 SVG 底部 (y=450~490) 放置一个绝对定位的 div，包含两个按钮。
- 教师操作流程：教师首先介绍初始装置结构，然后点击「下一步」依次讲解甲丙液面高度差决定的气体压强、气体压强的传递，最后推导中心细管内 M 处的压强，配合高亮引导学生视线。

[技术实现]
- JS 库选择及原因：原生 SVG。图形主要由矩形和多边形构成，原生 SVG 易于实现精确的像素级控制和 DOM 状态切换。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  |  P_M公式       P_0      |
  |         甲容器          |
  | P_gas(乙)      右侧水管 |
  |  h_乙丙 乙容器 h_甲丙   |
  | 左侧气管       P_gas(丙)|
  |         丙容器          |
  [控件栏 (y=450-490)]
  ```
- 关键实现要点：
  - 使用 `<g>` 标签对不同步骤的元素进行分组，通过 JS 控制 `display` 属性或 `opacity` 实现步骤切换。
  - 水体高亮通过切换 CSS class 实现（如 `.highlight-water` 增加透明度和描边）。
  - 下标文本必须使用 `<tspan dy="4" font-size="0.8em">` 并在其后使用 `<tspan dy="-4">` 恢复基线，确保公式排版美观。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-step1-group`, `scene1-btn-next`）。
- IIFE 隔离：所有 JS 代码必须包裹在 `(function() { ... })()` 中，避免全局变量污染。
