[图示主题与整合说明]
- 本图示主题：打开开关后的液面动态变化与体积对比
- 整合的步骤/概念：打开阀门M后，水流方向、各容器液面升降、乙丙气体体积变化量（ΔV_乙 和 ΔV_丙）的可视化对比。
- 教学价值：教师可通过拖拽滑块，连续演示液面平衡的动态过程。通过绿色和红色高亮区域的直观对比，帮助学生轻松理解“ΔV_乙 > ΔV_丙”这一核心难点，避免纯抽象的公式推导。

[视觉元素清单]
- 容器与管道：黑色实线 (#000000)，线宽 2px，无填充。
- 初始液面标记：灰色虚线 (#888888)，线宽 1.5px，贯穿容器。
- 动态水体：蓝色半透明填充 (#1565c0, 30% opacity)，顶部边缘加 1.5px 蓝色实线。右侧水管始终充满水。
- 阀门M：初始为黑色实心矩形，打开后变为空心（白色填充，黑色边框）。
- ΔV_乙高亮区：绿色半透明填充 (#2e7d32, 30% opacity)，分为左右两块避开中心管。
- ΔV_丙高亮区：红色半透明填充 (#c62828, 30% opacity)，完整矩形。
- 标注线与箭头：黑色实线，线宽 1.5px。
- 文本标签：字体大小 14px/16px，颜色与对应元素一致（如 ΔV_乙 为绿色）。

[分步序列]
- 初始状态 (t=0)：
  - 阀门M关闭（实心）。
  - 各液面在初始位置（甲y=80, 乙y=210, 丙y=360, 中心管y=70）。
  - 高亮区域高度为0（不可见）。
  - h_{甲丙} 标注显示初始最大高度差。
- 拖拽滑块 (0 < t < 1)：
  - 阀门M打开（空心）。
  - 甲液面下降 (y: 80 → 100)。
  - 乙液面下降 (y: 210 → 240)。
  - 丙液面上升 (y: 360 → 340)。
  - 中心管液面上升 (y: 70 → 30)。
  - ΔV_乙 绿色区域逐渐向下展开 (高度 0 → 30)。
  - ΔV_丙 红色区域逐渐向上展开 (高度 0 → 20)。
  - h_{甲丙} 箭头动态缩短，位置实时跟随液面。
- 最终状态 (t=1)：
  - 液面到达最终平衡位置。
  - 视觉上清晰呈现：绿色区域高度(30px) > 红色区域高度(20px)，即 ΔV_乙 > ΔV_丙。

[标签冲突检查]
- 标签"甲"(290, 95) vs 左侧气管(x=260~280)：间距 > 10px，无冲突。
- 标签"乙"(290, 225) vs 左侧气管水平段(y=185~205, 315~335)：位于两水平段之间，无冲突。
- 标签"丙"(290, 355) vs 左侧气管底部(y=335)：位于其下方，无冲突。
- 标签"M"(365, 75) vs 容器甲左壁(x=320)：位于容器内左侧空白处，无冲突。
- 标签"ΔV_乙 (增大)"(180, 225) vs 左侧气管(x=260)：位于气管左侧，间距 80px，无冲突。
- 标签"ΔV_丙 (减小)"(180, 350) vs 左侧气管(x=260)：位于气管左侧，间距 80px，无冲突。
- 标签"h_{甲丙} (减小)"(585, 中点) vs 右侧水管(x=540)：位于水管右侧，间距 45px，无冲突。
结论：所有标签均已完美错开，无任何重叠遮挡。

[交互方案]
- 交互类型：连续拖拽滑块。
- 控件说明：在 SVG 内部底部 (y=460) 放置一个 `<input type="range">` 滑块，范围 0 到 1，步长 0.01。
- 教师操作流程：教师在讲解时，缓慢向右拖拽滑块，引导学生观察各个液面的联动变化。特别指出绿色和红色区域的生成过程，最后停在最右侧，让学生直观比较两块颜色的面积大小，得出结论。

[技术实现]
- JS 库选择及原因：原生 SVG。液面变化和高亮区域本质上是矩形的高度和 y 坐标变化，使用原生 SVG 的 `setAttribute` 可以极高效率地实现平滑动画，无需引入庞大的外部库。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
    (左侧标签)   (主容器区)   (右侧标注)
    ΔV_乙 ---    [ 甲 ]      |
                 [ 乙 ]      h_{甲丙}
    ΔV_丙 ---    [ 丙 ]      |
  [控件栏: 滑块 (300, 460, 200x20)]
  ```
- 关键实现要点：
  - 状态映射：在 `input` 事件监听器中，获取滑块值 `t` (0~1)。
  - 坐标计算：
    - `y_甲 = 80 + 20 * t`
    - `y_乙 = 210 + 30 * t`
    - `y_丙 = 360 - 20 * t`
    - `y_center = 70 - 40 * t`
  - 属性更新：根据上述坐标，实时更新对应 SVG `<rect>` 和 `<polygon>` 的 `y` 和 `height` 属性。
  - 避开中心管：甲和乙的动态水体及 ΔV_乙 高亮区，必须用两个 `<rect>` 分别绘制在中心管的左右两侧（左侧宽70，右侧宽70），以防止颜色叠加在中心管上。
- ID 命名规范：所有交互元素 ID 必须以 `scene2-` 为前缀（如 `scene2-slider`, `scene2-water-jia-left`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
