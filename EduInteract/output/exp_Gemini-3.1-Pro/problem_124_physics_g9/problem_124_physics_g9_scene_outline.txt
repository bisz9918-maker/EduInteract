    **题目原文：**
    电磁铁甲和永磁体乙如图放置，开关S闭合后，b、c两端形成的磁感线如图中实线所示，由此可知（  ）
    A 、a、c两端都是N极 B 、a、d两端都是N极 C 、b、c两端都是N极 D 、b、d两端都是N极

    **题目分析与整体讲解思路：**
    本题考查了安培定则（右手螺旋定则）的应用以及磁极间相互作用的规律。讲解时可以分为两个主要逻辑步骤：
    1. **判定电磁铁的磁极**：首先引导学生观察电源的正负极，确定电路中的电流方向。接着，仔细观察电磁铁上线圈的绕向，明确正面线圈中的电流方向。最后，应用安培定则判定电磁铁甲的 a、b 两端的磁极。
    2. **判定永磁体的磁极**：引导学生观察 b、c 两端之间的磁感线形状。由于磁感线向外排斥，说明 b、c 两端为同名磁极。结合第一步得出的 b 端磁极，即可推断出 c 端和 d 端的磁极。

    **图示规划说明：**
    为了直观展示推导过程，我们将设计一个分步交互图示。图示将从初始的电路图开始，逐步叠加电流方向、右手定则手势、磁极判定结果以及磁感线的受力分析，帮助学生建立从条件到结论的完整视觉映射。

    **教学引导与讲解要点：**

    1. **确定电流方向**：
       - 提醒学生复习电源符号：长线代表正极，短线代表负极。
       - 引导学生追踪电流：电流从正极出发，沿着导线流向电磁铁。
       - **关键点**：仔细观察线圈的绕法。电流从左侧导线流入后，是先绕到铁芯后方，再从上方绕到前方并向下走。因此，电磁铁正面线圈中的电流方向是**向下**的。

    2. **应用安培定则（右手螺旋定则）**：
       - 让学生举起右手，跟着图示一起做动作。
       - **口诀**：用右手握住螺线管，让四指弯向螺线管中电流的方向（即四指朝下），则大拇指所指的那端就是螺线管的 N 极。
       - 推导得出：大拇指指向右侧，所以 **b 端是 N 极**，a 端是 S 极。

    3. **分析磁极间的相互作用**：
       - 引导学生观察 b、c 之间的磁感线。这些磁感线没有将 b 和 c 连接起来，而是向外弯曲，这表明它们之间存在**排斥力**。
       - 根据磁极相互作用规律：“同名磁极相互排斥，异名磁极相互吸引”。
       - 推导得出：既然 b 端是 N 极，且 b 与 c 排斥，那么 **c 端也必定是 N 极**。同理，d 端为 S 极。

    4. **总结**：
       - 综合以上推导，b、c 两端都是 N 极。
       - 对照选项，正确答案为 **C**。
