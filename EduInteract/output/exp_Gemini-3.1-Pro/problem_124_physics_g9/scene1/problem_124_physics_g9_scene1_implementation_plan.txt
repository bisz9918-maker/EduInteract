[图示主题与整合说明]
- 本图示主题：电磁铁与永磁体磁极的综合判定
- 整合的步骤/概念：电路闭合 -> 电流方向判定 -> 安培定则（右手螺旋定则）判定电磁铁磁极 -> 磁感线排斥现象 -> 永磁体磁极判定。
- 教学价值：将静态的物理题目转化为动态的逻辑推导过程。教师可以通过分步导航，引导学生一步步观察电流、应用定则、分析磁场，最终得出结论，完美契合课堂讲解节奏。

[分步序列]
- 初始状态（步骤0）：显示题目基础条件。开关处于断开状态。磁感线为灰色。所有电流箭头、磁极标签、右手示意图均隐藏。
- 步骤1（标出电流）：点击「下一步」。开关刀片旋转至闭合状态。电池上方出现红色的 "+" 和 "-" 标签。电路上出现红色的电流箭头（右侧导线向上，线圈正面4个箭头沿线向左下，左侧导线向下，底部导线向右）。
- 步骤2（安培定则）：点击「下一步」。在电磁铁甲上方淡入半透明的右手示意图（四指朝下，拇指朝右）。同时在铁芯甲内部左侧淡入 "S"，右侧淡入 "N"。
- 步骤3（磁感线分析）：点击「下一步」。b、c 之间的排斥状磁感线变为绿色（#2e7d32）并加粗。上方淡入绿色提示文本 "同名磁极相互排斥"。
- 步骤4（得出结论）：点击「下一步」。在磁体乙内部左侧淡入 "N"，右侧淡入 "S"。b 处的 "N" 和 c 处的 "N" 放大 1.3 倍并恢复（或添加黄色发光效果），强调同名磁极。

[交互方案]
- 交互类型：分步按钮导航。
- 控件说明：在 SVG 内部底部（y=450~490）居中放置两个按钮：「◀ 上一步」和「下一步 ▶」。
- 教师操作流程：教师首先展示原图，提问电流方向；点击下一步验证电流；提问电磁铁磁极，点击下一步展示右手定则并验证；提问磁感线形态代表什么，点击下一步高亮排斥并显示提示；最后提问永磁体磁极，点击下一步得出最终结论。

[技术实现]
- JS 库选择：原生 SVG + Vanilla JS。SVG 非常适合绘制清晰的几何图形、贝塞尔曲线和精确控制动画状态。
- 画布尺寸：800 × 500 px。
- 布局草图：
  [图示区 800×440]
  包含左侧电磁铁、右侧永磁体、中间磁感线。
  [控件栏 800×60]
  底部居中放置上一步/下一步按钮。
- 关键实现要点：
  1. 状态机设计：定义 `currentStep` (0-4)，编写 `updateState()` 函数，根据当前步骤控制各 SVG 元素的 `opacity`、`stroke`、`transform` 等属性。
  2. 动画过渡：在 SVG 元素上使用 CSS `transition: all 0.5s ease` 实现平滑的淡入淡出和颜色切换。
  3. 右手绘制：使用 `<g>` 组合多个 `<path>` 和 `<ellipse>`，设置 `fill="#1565c0"` 和 `opacity="0.3"`，通过精确的控制点绘制出拇指朝右、四指朝下的形态。
  4. ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-switch-blade`, `scene1-current-arrows`）。
  5. IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
