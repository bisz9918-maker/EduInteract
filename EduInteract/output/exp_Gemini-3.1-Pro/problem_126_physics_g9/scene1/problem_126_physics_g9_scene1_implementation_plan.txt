[图示主题与整合说明]
- 本图示主题：滑轮组水平拉动物体的受力与做功分析
- 整合的步骤/概念：物体受力分析、有用功判定、滑轮组绳子股数(n=3)识别、位移与速度的倍数关系、总功与机械效率推导。
- 教学价值：教师可通过分步动画，直观展示物体位移与绳端位移的倍数关系，帮助学生理解有用功与总功的来源，从而自然推导出机械效率公式，避免一次性信息过载。

[分步序列]
- 初始状态（步骤0）：显示基础图形（物体A、滑轮组、绳子、拉力F）。文本提示：“本图示用于分析滑轮组水平拉动物体时的受力与做功情况。点击「下一步」开始。”
- 步骤1（有用功分析）：触发平滑动画，物体A和动滑轮向右移动50px，绳子自由端向左上移动150px。动画结束后，显示 G 向量、f 向量、S 标注、v 向量。文本显示有用功公式 $W_{有用} = fS$。
- 步骤2（滑轮组运动学）：将绳段1、2、3的颜色变为绿色并加粗，显示 n=3 标签。显示自由端的 3S 标注和 3v 向量。文本显示运动学关系 $s' = 3S$, $v' = 3v$。
- 步骤3（总功与功率）：将 F 向量及标签加粗放大（或增加阴影）以示高亮。文本显示总功 $W_{总} = 3FS$ 和功率 $P = 3Fv$。
- 步骤4（机械效率）：综合展示机械效率公式推导 $\eta = f / 3F$。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：在 SVG 容器内部底部（y=460~490）放置绝对定位的控制栏，包含两个按钮。
- 教师操作流程：教师点击“下一步”，图示自动播放物体移动动画并逐步叠加受力、运动学标注和公式，配合课堂讲解节奏。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无需外部库，性能最佳，易于控制动画）。
- 画布尺寸：800 × 500 px。
- 布局草图：
  [图示区 800×370] (包含滑轮组、物体、标注)
  [文本区 800×80] (y=380~450，显示公式)
  [控件栏 800×40] (y=460~490，包含上一步/下一步按钮)
- 关键实现要点：
  1. 动画状态机：定义 `currentS` 和 `targetS`，当状态从0切换到1时，`targetS` 设为 50。使用 `requestAnimationFrame` 实现 `currentS` 逼近 `targetS` 的缓动动画。
  2. 坐标动态更新：在动画帧中，根据 `currentS` 实时更新物体A的 `x`、动滑轮的 `cx`、连杆的 `x1/x2`、绳段的端点坐标，以及自由端绳子的端点坐标（`freeEndX = 500 - currentS * 2.91`, `freeEndY = 210 - currentS * 0.72`）。
  3. 绕轮圆弧：动滑轮的半圆弧放在一个 `<g>` 标签中，随动滑轮一起 `transform="translate(currentS, 0)"`，避免复杂的路径重算。
  4. 显隐控制：通过 CSS `transition: opacity 0.3s` 控制各步骤标注（G, f, S, 3S等）的平滑显隐。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-blockA`, `scene1-btn-next`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
