[图示主题与整合说明]
- 本图示主题：光穿过平行玻璃砖的折射过程
- 整合的步骤/概念：空气到玻璃的第一次折射、玻璃到空气的第二次折射、出射光线与入射光线平行的几何关系。
- 教学价值：教师可以通过分步导航，引导学生逐步分析光在两个界面的折射规律（折射角与入射角的大小关系），最终得出光线穿过平行玻璃砖后发生侧移且方向不变的结论。

- 步骤2：点击「下一步」→ 显示法线2、入射角 i₂ 及其标签、出射光线、折射角 r₂ 及其标签，显示结论文本2“折射角 r₂ > 入射角 i₂”。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：底部居中放置两个按钮，控制步骤 0 到 3 的切换。
- 教师操作流程：教师首先介绍入射光线和玻璃砖界面；点击下一步，讲解第一次折射时光线向法线偏折；再次点击，讲解第二次折射时光线远离法线偏折；最后点击，总结出射光线与入射光线平行的规律。

[技术实现]
- JS 库选择及原因：原生 SVG。光路图主要由直线、矩形和圆弧组成，SVG 能够提供高质量的矢量渲染，且通过 DOM 操作控制元素的显示/隐藏非常方便。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×450]
  [控件栏 800×50，包含 上一步、下一步 按钮]
  ```
- 关键实现要点：
  - 使用 `<g>` 标签将不同步骤的元素分组，通过改变 `display` 或 `opacity` 属性实现步骤切换。
  - 光线箭头通过在路径中间截断并添加 `<polygon>` 或使用 `<marker>` 实现。为了精确控制箭头在光线中点，建议直接绘制 `<polygon>`。
  - 角度圆弧使用 `<path>` 的 `A` (椭圆弧) 指令绘制。
  - 状态机设计：定义 `currentStep` 变量（0-3），每次点击按钮更新变量并调用 `updateView()` 函数，该函数根据当前步骤控制各组元素的可见性。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-step1-group`, `scene1-btn-next`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
