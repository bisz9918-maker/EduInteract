[图示主题与整合说明]
- 本图示主题：偏二甲肼-四氧化二氮燃料电池原理动态解析
- 整合的步骤/概念：电子流向与正负极判断、反应物进出口分析、产物分析与电极反应式书写
- 教学价值：教师可通过分步导航，引导学生按照“看电子流向 -> 定正负极 -> 定物质进出 -> 写反应式”的严密逻辑顺序，逐步剖析复杂的燃料电池工作原理，并通过高亮对比帮助学生避开易错点。

[分步序列]
- 初始状态（步骤0）：显示原电池主体（容器、电极A/B、电解质、导线、灯泡、端口a/b/c/d及黑色物质流向箭头）、黑色的 e⁻ 流向箭头。
- 步骤1（判断极性）：点击「下一步」→ 外电路的 e⁻ 流向箭头及文本变为红色（#c62828）并加粗；在电极A左上方(200,120)淡入显示“负极 (失电子, 氧化反应)”；在电极B右上方(600,120)淡入显示“正极 (得电子, 还原反应)”。
- 步骤2（物质输入）：点击「下一步」→ 在端口a左侧(140,345)淡入蓝色文本“C₂H₈N₂”，并触发一次向右滑入端口的动画；在端口b右侧(660,345)淡入绿色文本“N₂O₄”，并触发一次向左滑入端口的动画。
- 步骤3（产物与反应式）：点击「下一步」→ 在电极B右侧(620,270)淡入“N₂O₄ → N₂”，端口d右侧(660,195)淡入“N₂”并触发向右滑出动画；在电极A左侧(180,270)淡入“C₂H₈N₂ → CO₂ + N₂”，端口c左侧(140,195)淡入“CO₂, N₂”并触发向左滑出动画。底部(400,410)弹出正确的负极反应式（高亮系数"2"），下方(400,440)弹出选项D错误反应式（带删除线或下划线标记未配平的碳原子）。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：底部居中放置两个按钮，控制步骤0~3的切换。
- 教师操作流程：教师首先展示初始状态，提问电子流向代表什么；点击下一步，展示正负极判断；再点击下一步，结合极性分析燃料和氧化剂的入口；最后点击下一步，推导产物并展示电极反应式的书写与易错点对比。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。图形均为规则几何体和连线，SVG 易于实现精确布局和 CSS 动画。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×470]
    (顶部) 极性标签、导线、灯泡、e-流向
    (中部左) 端口c、反应式A、端口a、电极A
    (中部中) 电解质、H2SO4
    (中部右) 电极B、端口d、反应式B、端口b
    (下部) 底部解析文本
  [控件栏 800×30]
    ◀上一步 | 下一步▶
  ```
- 关键实现要点：
  - 状态机设计：定义 `currentStep` 变量（0-3），每次点击按钮更新状态，并通过切换 SVG 元素的 `display` 或 `opacity` 属性控制显隐。
  - 动画实现：使用 CSS `@keyframes` 定义 `slideInRight`, `slideInLeft`, `slideOutRight`, `slideOutLeft` 动画类，在进入对应步骤时为文本元素添加该类名触发动画。
  - 坐标计算：严格按照布局坐标表绘制 SVG 路径（`<path>`）和线段（`<line>`），确保无缝拼接。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-btn-next`, `scene1-step1-group`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
