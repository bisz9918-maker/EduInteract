[图示主题与整合说明]
- 本图示主题：罂粟碱分子式的确定及燃烧耗氧量计算
- 整合的步骤/概念：从键线式骨架出发，逐步引导学生识别并计数碳原子、隐藏的氢原子（显式绘制C-H键）、杂原子（N、O），最终推导分子式并进行燃烧耗氧量的代数计算。
- 教学价值：教师可通过分步按钮，带领学生“透视”复杂的有机分子键线式，将抽象的结构转化为具体的原子计数，最后自然过渡到化学方程式的配平与计算，有效降低认知负荷。

[分步序列]
- 初始状态（步骤0）：仅显示黑色分子骨架（含双键内线）、N原子文本、四个甲氧基文本。
- 步骤1（数碳原子）：点击「下一步」，出现 20 个蓝色碳原子圆点及编号 1-20。
- 步骤2（数氢原子）：点击「下一步」，在骨架上显式画出 21 条绿色 C-H 键，出现 21 个绿色氢原子圆点及编号 1-21。
- 步骤3（数杂原子）：点击「下一步」，出现 5 个红色空心圆圈高亮 N 和 O 原子。底部居中浮现红色分子式 $C_{20}H_{21}NO_{4}$。
- 步骤4（耗氧量计算）：点击「下一步」，隐藏步骤3的分子式，在底部居中显示红色燃烧反应方程式 $C_{20}H_{21}NO_{4} + xO_{2} ightarrow 20CO_{2} + 10.5H_{2}O + 0.5N_{2}$，及其下方显示耗氧量计算过程 $x = 20 + 10.5/2 - 4/2 = 23.25$ mol。

[标签冲突检查]
- C8 标签 (323, 230) 与 H(C8) 键 (313, 240)->(313, 210)：C8标签在右侧，H键在正上方，间距充足，无冲突。
- C5 标签 (323, 370) 与 H(C5) 键 (313, 360)->(313, 390)：C5标签在右侧，H键在正下方，无冲突。
- V2 标签 (465, 100) 与 H(V2) 键 (475, 110)->(445, 110)：V2标签在左上，H键在正左，错开角度，无冲突。
- 甲氧基C标签与H键：以 C(C7-OMe) 为例，C点在 (190, 270)，标签在 (205, 255) 右上方。H键分别向正上(190,250)、正下(190,290)、正左(170,270)延伸。标签完美避开H键，无冲突。
- 结论：所有标签偏移方向均经过精心设计，确保与相邻键线和其他标签保持 ≥ 15px 间距。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：在 SVG 内部底部（y=460 区域）居中放置两个按钮，使用绝对定位。
- 教师操作流程：教师首先展示分子骨架，提问分子式；然后依次点击“下一步”带领学生数碳、数氢、数杂原子，验证分子式；最后点击“下一步”展示燃烧计算公式，讲解耗氧量代数计算法。

[技术实现]
- JS 库选择：原生 SVG。分子结构由大量线段和文本构成，SVG 的 `<line>`, `<circle>`, `<text>` 标签最适合精确控制和分组显示。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800x500]
    (100~700, 20~390): 罂粟碱分子结构及高亮标注
    (100~700, 400~440): 分子式与方程式计算文本区
    (300~500, 460~490): [◀上一步] [下一步▶] 按钮区
  ```
- 关键实现要点：
  - 使用 `<g>` 标签对不同步骤的元素进行分组：`id="scene1-step1-group"`, `id="scene1-step2-group"` 等。
  - 状态机设计：维护 `currentStep` 变量（0-4）。点击按钮时更新变量，并通过 JS 遍历所有 group，根据 `currentStep` 动态设置 `display: none` 或 `display: block`。
  - ID 命名规范：所有 DOM 元素的 ID 均以 `scene1-` 开头，例如 `scene1-btn-next`, `scene1-step1-group`。
  - 样式隔离：所有 CSS 规则限定在 `#scene1-container` 内部。
  - IIFE 隔离：所有逻辑代码封装在 `(function() { ... })()` 中，避免全局变量污染。
