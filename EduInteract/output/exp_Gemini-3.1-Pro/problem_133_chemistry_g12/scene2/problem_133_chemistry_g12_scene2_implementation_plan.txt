[图示主题与整合说明]
- 本图示主题：氢气与氧气反应的消耗与过量分类讨论
- 整合的步骤/概念：反应消耗比例、氢气过量情况下的初始比例、氧气过量情况下的初始比例
- 教学价值：教师可以通过切换不同的过量假设，直观地向学生展示剩余气体成分的变化如何影响最终的初始体积比，帮助学生理解分类讨论的思想。

[视觉元素清单]
- 消耗区标注：黑色线段，两端带向下小短线，上方文字“反应消耗 (2份)”
- 剩余区标注：黑色线段，两端带向下小短线，上方文字“剩余气体 (1份)”
- H2消耗色块：矩形，填充 #1565c0，透明度 50%，黑色边框，内部文字“H₂ (4/3)”
- O2消耗色块：矩形，填充 #c62828，透明度 50%，黑色边框，内部文字“O₂ (2/3)”
- 剩余气体色块：矩形，初始填充 #888888，透明度 20%，黑色边框，内部文字“未知 (1)”
- 计算过程面板：带浅灰色背景和圆角的 div，包含多行文本，用于展示计算逻辑和最终比例
- 颜色/样式沿用 `<SCENE_k>` 规格：
  - H2：#1565c0
  - O2：#c62828
  - 剩余未知：#888888
  - 边框与文字：#000000

[分步序列]
- 初始状态（状态1：反应消耗）：
  - 显示完整的柱状图，分为 H2消耗、O2消耗、未知剩余三部分。
  - 剩余气体色块为灰色半透明，标签为“未知 (1)”。
  - 计算面板显示：“反应消耗了 2 份体积的混合气体。<br>根据 2H₂ + O₂ = 2H₂O，消耗的 H₂ 为 4/3，O₂ 为 2/3。<br>剩余 1 份体积的气体，可能是 H₂ 或 O₂。”
- 状态2（情况一：氢气过量）：
  - 点击对应按钮触发。
  - 剩余气体色块变为蓝色 #1565c0 纯色（透明度 100%），标签变为“H₂ (1)”。
  - 计算面板显示：“假设剩余气体为 H₂。<br>H₂ 总量 = 4/3 (消耗) + 1 (剩余) = 7/3<br>O₂ 总量 = 2/3 (消耗)<br>初始体积比 H₂ : O₂ = 7/3 : 2/3 = 7 : 2”
- 状态3（情况二：氧气过量）：
  - 点击对应按钮触发。
  - 剩余气体色块变为红色 #c62828 纯色（透明度 100%），标签变为“O₂ (1)”。
  - 计算面板显示：“假设剩余气体为 O₂。<br>H₂ 总量 = 4/3 (消耗)<br>O₂ 总量 = 2/3 (消耗) + 1 (剩余) = 5/3<br>初始体积比 H₂ : O₂ = 4/3 : 5/3 = 4 : 5”

[标签冲突检查]

[交互方案]
- 交互类型：多状态切换（3个按钮）
- 控件说明：
  - 按钮1：“反应消耗”，位于底部左侧，点击恢复初始状态。
  - 按钮2：“情况一：H₂过量”，位于底部中间，点击展示氢气过量情况。
  - 按钮3：“情况二：O₂过量”，位于底部右侧，点击展示氧气过量情况。
- 教师操作流程：教师首先展示反应消耗的比例，然后分别点击两个情况按钮，引导学生观察剩余气体成分的变化如何影响最终的初始体积比。

[技术实现]
- JS 库选择及原因：原生 SVG + HTML/CSS。SVG 适合绘制精确尺寸的柱状图和标注线，HTML 适合排版多行计算文本和按钮。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
    (上方标注线)
    [H2消耗][O2消耗][剩余气体]
    (计算过程面板)
  [控件栏（3个按钮，在SVG内底部）]
  ```
- 关键实现要点：
  - 使用 SVG `<rect>` 绘制色块，通过改变 `fill` 和 `fill-opacity` 实现状态切换。
  - 使用 SVG `<text>` 绘制标签，通过改变 `textContent` 实现文字更新。
  - 计算面板使用 HTML `<div>` 绝对定位在 SVG 上方，通过 `innerHTML` 更新内容。
  - 状态切换时，可以加入简单的 CSS transition 过渡效果（如颜色渐变）。
- ID 命名规范：所有交互元素 ID 必须以 `scene2-` 为前缀，如 `scene2-rect-remain`, `scene2-text-remain`, `scene2-panel-calc`, `scene2-btn-state1` 等。
- IIFE 隔离：所有 JS 代码包裹在 `(function() { ... })()` 中。
