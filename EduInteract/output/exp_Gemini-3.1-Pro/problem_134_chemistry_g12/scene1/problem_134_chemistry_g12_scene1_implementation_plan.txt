- 步骤2：点击「下一步」→ C-C键高亮为蓝色（提示已形成3个键），向外延伸出C-H虚线键并出现氢原子球，下方淡入显示“氢原子数: 4”、“6”、“8”。
- 步骤3：点击「下一步」→ C-C键恢复黑色，下方淡入显示分子式（C₄H₄等）和最简式（CH），底部淡入结论文本：“选项B: B的分子式为C₆H₁₂ ❌ (应为C₆H₆) | 选项D: 只有C的最简式为CH ❌ (均为CH)”。

[技术实现]
- JS 库选择及原因：使用 `Three.js`（通过 CDN 引入）实现 3D 球棍模型及平滑自转动画；使用原生 DOM 实现文本覆盖层和 UI 交互，确保文字清晰且排版精确。
- 画布尺寸：800 × 500 px，`position: relative`。
- 布局草图：
  ```
  [--------------------------------------------------]
  [       (3D A)         (3D B)         (3D C)       ] y=0~250
  [                                                  ]
  [      A(正四面体)     B(棱柱烷)      C(立方烷)      ] y=270
  [      碳原子数: 4     碳原子数: 6    碳原子数: 8    ] y=300
  [      氢原子数: 4     氢原子数: 6    氢原子数: 8    ] y=330
  [      分子式: C₄H₄    分子式: C₆H₆   分子式: C₈H₈   ] y=360
  [      最简式: CH      最简式: CH     最简式: CH     ] y=390
  [                                                  ]
  [  选项B: B分子式为C₆H₁₂ ❌ | 选项D: 只有C最简式为CH ❌ ] y=430
  [             [◀上一步]       [下一步▶]            ] y=465
  [--------------------------------------------------]
  ```
- 关键实现要点：
  1. **3D坐标构建**：手动定义三种几何体的顶点坐标（正四面体、三棱柱、正方体），确保中心在原点。
  2. **法向量计算**：氢原子的位置通过顶点坐标向量归一化后向外延伸（`v.clone().normalize().multiplyScalar(1.2).add(v)`）计算得出。
  3. **动画循环**：在 `requestAnimationFrame` 中，不仅更新三个 `Group` 的 `rotation.y` 和 `rotation.x` 实现自转，还通过 `lerp` 平滑更新碳原子和氢原子的 `scale`（根据当前步骤控制目标缩放值为 0 或 1）。
  4. **状态机**：根据 `currentStep` (0-3) 更新 DOM 元素的 `opacity` 和 3D 材质的颜色。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-btn-next`, `scene1-text-formula-a`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
