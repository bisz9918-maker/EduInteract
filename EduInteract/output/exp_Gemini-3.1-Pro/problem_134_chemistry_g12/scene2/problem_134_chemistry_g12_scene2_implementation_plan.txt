[图示主题与整合说明]
- 本图示主题：烃A（四面体烷）的二氯代物同分异构体分析
- 整合的步骤/概念：通过3D模型的旋转和重叠动画，直观证明四面体烷的四个顶点完全等价，其二氯代物只有一种结构。
- 教学价值：帮助学生克服空间想象的困难，通过动态重合的视觉冲击，深刻理解“等价位置”的概念，从而准确判断同分异构体的数量。

[视觉元素清单]
- 碳原子(C)：球体(圆)，基础半径16，填充 `#888888`，描边 `#555555`
- 氢原子(H)：球体(圆)，基础半径10，填充 `#ffffff`，描边 `#000000`
- 氯原子(Cl)：球体(圆)，基础半径14，填充 `#2e7d32` (绿高亮)，描边 `#1b5e20`
- 化学键：线段，碳碳键宽6，碳氢键宽4，颜色 `#555555`
- 等价位置高亮：光晕(圆)，半径为对应原子1.8倍，填充 `#1565c0` (蓝高亮)，透明度 0.4，置于原子底层
- 结论文本：颜色 `#c62828` (红高亮)，加粗字体

[分步序列]
- 初始状态（步骤0）：显示正四面体烷完整模型，缓慢自转。标题“正四面体烷 (C4H4)”。
- 步骤1：点击「下一步」。顶部H原子变为Cl原子（绿色）。标题变为“一氯代物：顶部H被Cl取代”。
- 步骤2：点击「下一步」。底部3个C原子及相连的H原子出现蓝色高亮光晕。模型自动绕Y轴旋转120度，展示底部3个位置的对称性。标题变为“底部3个位置完全等价”。
- 步骤3：点击「下一步」。主模型缩小并保持在中央（Cl在位置1）。左右两侧出现另外两种取代情况的模型（Cl分别在位置2和3）。显示对应标签。1.5秒后，左右模型向中心平移，同时分别旋转 -120° 和 +120°。最终三个模型在中心完全重合。重合后显示红色结论文本“三种取代物完全重合，只有1种二氯代物！选项A错误”。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：底部居中放置两个按钮，控制步骤0-3的切换。
- 教师操作流程：教师点击下一步，依次展示一氯取代、等价位置分析、二氯取代的三种可能。在步骤3时，引导学生观察三种模型的不同，随后动画自动演示重合过程，得出结论。

[技术实现]
- JS 库选择：原生 SVG + 原生 JS。无需引入外部 3D 库，通过自定义轻量级 3D 投影算法实现。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
    (400,30) 标题文本
    (400,80) 结论文本 (步骤3显示)
    [左模型 150,260]  [主模型 400,260]  [右模型 650,260]
    (150,380)标签     (400,380)标签     (650,380)标签
  [控件栏 y=450~490]
    [◀ 上一步] [下一步 ▶]
  ```
- 关键实现要点：
  1. **3D 投影引擎**：定义正四面体的精确 3D 坐标。使用 `x' = x*cos - z*sin` 等矩阵变换实现绕轴旋转，通过 `zScale = fov / (distance + z)` 实现透视投影。
  2. **Z-Sorting (深度排序)**：每帧计算所有原子和键的投影 Z 值，按 Z 值降序排序后，更新 SVG DOM 元素的属性，确保正确的遮挡关系。
  3. **DOM 对象池**：为避免频繁创建/销毁 DOM 节点导致性能问题，预先创建若干 `<circle>` 和 `<line>` 元素放入池中，每帧根据排序结果更新对应属性，实现高效渲染。
  4. **重合动画数学逻辑**：正四面体绕中心垂线旋转 120° 具有对称性。步骤3中，左右模型在向中心平移的同时，分别附加 -120° 和 +120° 的旋转，确保到达中心时，取代基位置与主模型完全一致，实现完美的视觉重合。
  5. **ID 命名规范**：所有 DOM 元素 ID 均以 `scene2-` 开头（如 `scene2-svg`, `scene2-btn-next`）。
  6. **IIFE 隔离**：所有逻辑封装在 `(function() { ... })()` 中，避免全局变量污染。
