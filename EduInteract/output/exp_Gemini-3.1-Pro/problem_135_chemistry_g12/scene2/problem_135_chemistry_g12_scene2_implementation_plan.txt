[视觉元素清单]
- 坐标系：X轴、Y轴、原点O、X轴标签、Y轴标签。颜色 #000000。
- 辅助线：x=400处的垂直虚线，表示等当点V0。颜色 #888888，虚线样式（stroke-dasharray="5,5"）。
- 曲线A：红色 #c62828，线宽 3px，实线。起点极低，大幅上升至最高点后缓慢下降。
- 曲线B：蓝色 #1565c0，线宽 2px，实线。起点高，略微上升后下降。
- 曲线C：绿色 #2e7d32，线宽 2px，实线。起点高，单调平缓下降。
- 曲线D：灰色 #888888，线宽 2px，实线。起点高，平缓变化后下降。
- 文本标签：各曲线对应的说明文字，颜色与曲线一致，字号 14px，字体 sans-serif。

[分步序列]
- 初始状态（步骤0）：仅显示坐标系、原点O、等当点虚线及V0标签。所有曲线及对应标签隐藏（透明度为0）。
- 步骤1：点击「下一步」→ 绘制曲线A，显示标签“A: 弱变强”。
- 步骤2：点击「下一步」→ 绘制曲线B，显示标签“B: 强变强”。（曲线A保持显示）
- 步骤3：点击「下一步」→ 绘制曲线C，显示标签“C: 混合稀释”。（曲线A、B保持显示）
- 步骤4：点击「下一步」→ 绘制曲线D，显示标签“D: 强变强”。（所有曲线均显示，形成完整对比）

[标签冲突检查]
- 标签A (400,65) 与 标签B (410,110)：Y轴间距 45px，无冲突。
- 标签B (410,110) 与 标签D (410,175)：Y轴间距 65px，无冲突。
- 标签C (660,235) 与 其他标签：X轴相差 > 200px，无冲突。
- 标签A (400,65) 与 等当点虚线 (400,80)：标签在虚线上方 15px，无冲突。
- 所有曲线标签均位于曲线的极值点或末端外侧，避免与曲线本身交叉重叠。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：在 SVG 容器内底部（y=460 区域）居中放置两个 HTML 按钮，使用 absolute 定位，用于控制步骤的推进和回退。
- 教师操作流程：教师首先介绍坐标系和等当点含义；然后点击“下一步”逐个展示选项A、B、C、D的导电性变化曲线，并结合标签解释其化学原理；最后在所有曲线同框时进行总结对比。

[技术实现]
- JS 库选择及原因：原生 SVG。由于全是简单的几何线条、贝塞尔曲线和文本，原生 SVG 性能好且易于实现路径动画和透明度过渡。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  |      Y轴
  |       |
  |       |   A(最高点)
  |       |   .
  |       |  / \   B
  | B,C,D | /   \ .
  | 起点--|/-----\-\-- C
  |       /       \ \
  |      /         \ \
  | A起点            \
  |____________________ X轴
          V0
  [控件栏：◀上一步 | 下一步▶]
  ```
- 关键实现要点：
  - 使用 `<path>` 标签的 `d` 属性绘制贝塞尔曲线。
  - 动画效果：通过 CSS `transition: opacity 0.5s ease` 控制曲线和标签的淡入淡出显示。
  - 状态机设计：维护一个 `currentStep` 变量（0-4），每次点击按钮更新变量，并根据变量值遍历所有曲线元素，设置其 `opacity`（`index <= currentStep ? 1 : 0`）。
  - 按钮状态：当 `currentStep === 0` 时禁用“上一步”，当 `currentStep === 4` 时禁用“下一步”。
- ID 命名规范：所有交互元素 ID 必须以 `scene2-` 为前缀（如 `scene2-curve-a`, `scene2-btn-next`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
