[图示主题与整合说明]
- 本图示主题：豌豆果实与种子的发育及遗传分析
- 整合的步骤/概念：处理①（生长素诱导无子果实）、处理②（杂交及果实种子发育来源）、F1代种植及F2代基因型概率计算。
- 教学价值：教师可通过分步演示，清晰地向学生展示母本子房壁发育为果皮、受精卵发育为胚的过程，帮助学生理清果皮基因型与母本一致，而胚基因型由双亲决定的核心遗传学概念，并直观推导F2代的概率计算。

- 步骤2（处理②）：点击「下一步」，显示授粉箭头（带路径动画）及处理②标签，接着显示处理②箭头，有子豆荚及内部种子放大出现，显示有子豆荚标签和种子胚标签。
- 步骤3（第二年播种）：点击「下一步」，显示播种箭头及标签，F1植株、F1豆荚出现，显示F1相关标签，强调F1豆荚为绿色，黄色豆荚占0。
- 步骤4（F2代种子）：点击「下一步」，显示自交箭头及标签，F2计算框及内部4行推导文本逐行淡入显示。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：在 SVG 内底部（y=450~490）居中放置「上一步」和「下一步」按钮。
- 教师操作流程：教师首先介绍双亲的基因型和表型（步骤0）；点击下一步，讲解生长素处理得到无子果实，果皮基因型与母本一致（步骤1）；点击下一步，讲解杂交过程，果皮仍与母本一致，但种子胚由受精卵发育而来，基因型为杂合子（步骤2）；点击下一步，讲解F1代植株结出的果实由F1子房壁发育，表现为绿色（步骤3）；最后点击下一步，推导F2代胚的基因型概率（步骤4）。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript。SVG 适合绘制精确的几何图形、路径动画及文本排版，无需引入外部库即可实现高质量的矢量渲染和动画。
- 画布尺寸：800 × 500 px
- 布局草图：
  [图示区 800×500]
  左侧：植株甲(上)、植株乙(下)
  中侧：处理①(上)、处理②(下)
  右侧：F1植株(上)、F2推导(下)
  [控件栏：底部 y=460 居中，上一步/下一步按钮]
- 关键实现要点：
  1. 状态机设计：定义 `currentStep` 变量（0-4），每次点击按钮更新状态，并调用 `updateScene()` 函数。
  2. 动画实现：使用 CSS `transition` 控制元素的 `opacity` 和 `transform`（如豆荚的缩放 `scale`，滴管的平移 `translateY`）。
  3. 路径动画：授粉箭头使用 SVG `<path>` 的 `stroke-dasharray` 和 `stroke-dashoffset` 配合 CSS `animation` 实现线条生长效果。
  4. ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-jia-flower`, `scene1-t1-pod`）。
  5. IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
