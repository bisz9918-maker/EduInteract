[技术实现]
- JS 库选择及原因：原生 SVG。由于本场景主要由静态矢量图形、连线和文本组成，原生 SVG 能够提供最清晰的渲染和最方便的 DOM 显隐控制。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  (70)花药 -> (170)花粉 -> (310)愈伤组织 -> (450)单倍体 -> (700)二倍体
                                           ^
                                      (565)微观气泡
  [控件栏 y=450~490，居中放置上一步/下一步按钮]
  ```
- 关键实现要点：
  - 使用 `<g>` 标签将每个步骤的元素分组（如 `id="scene2-step1-group"`），通过改变 `display` 属性（`none` 或 `block`）来实现分步动画。
  - 染色体和植物组织使用 `<path>` 绘制，确保形状美观且符合生物学特征。
  - 气泡内的红叉使用两条交叉的 `<line>`，设置 `stroke="#c62828"` 和 `stroke-width="4"`。
- ID 命名规范：所有交互元素 ID 必须以 `scene2-` 为前缀（如 `scene2-btn-next`, `scene2-step1-group`）。JS 中用 `document.getElementById` 获取元素。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
