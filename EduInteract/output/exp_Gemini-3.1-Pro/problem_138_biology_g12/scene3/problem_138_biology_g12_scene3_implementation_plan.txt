[视觉元素清单]
- 目的基因DNA：绿色线段（#2e7d32），表示提取出的基因片段。
- 细菌细胞：灰色（#888888）椭圆轮廓，内部填充 rgba(136,136,136,0.1)。
- 质粒：蓝色（#1565c0）圆环，位于细菌内部。
- 重组质粒：蓝色圆环，其中约 60 度的弧段替换为绿色（#2e7d32），表示目的基因已拼接。
- 花菜体细胞：灰色圆角矩形，内部填充 rgba(136,136,136,0.1)，包含一个灰色圆形细胞核。
- 宿主DNA：细胞核内的灰色曲线。
- 过程箭头：灰色（#888888）虚线，带箭头，指示物质转移方向。
- 标签文本：黑色（#000000），字号 14px，无重叠。

[分步序列]
- 初始状态（步骤0）：显示左侧的“目的基因DNA”及其标签，显示左下侧的“细菌细胞”、“质粒”及其标签。显示右侧的“花菜体细胞”、“细胞核”及原始“宿主DNA”及其标签。隐藏所有过程箭头、重组质粒、整合后DNA及整合标签。
- 步骤1（构建载体）：点击「下一步」。出现过程箭头1和过程箭头2；中间位置淡入显示“重组质粒”及其标签，表示目的基因与质粒在体外拼接成功。
- 步骤2（导入细胞）：点击「下一步」。出现过程箭头3；花菜体细胞核内的原始“宿主DNA”淡出，替换为带有绿色片段的“整合后DNA”；淡入显示“整合”标签，表示重组质粒已进入受体细胞并整合到染色体DNA上。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：在 SVG 底部（y=460 区域）居中放置两个按钮。
- 教师操作流程：教师首先介绍左侧的目的基因和运载体来源；点击“下一步”展示体外重组过程，讲解重组质粒的构建；再次点击“下一步”展示重组质粒导入受体细胞并整合的过程。可随时点击“上一步”回顾。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。SVG 适合绘制精确的几何图形和连线，原生 JS 足以处理简单的类名切换和透明度动画。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  (150,100)目的基因       (400,210)重组质粒       (650,210)花菜体细胞
       \                      /                      |
        \                    /                       |
  (150,320)细菌+质粒 ---------------------------------
  
  [控件栏（底部居中，y=460）]
  [ ◀上一步 ] [ 下一步▶ ]
  ```
- 关键实现要点：
  - 使用 `<g>` 标签对不同步骤的元素进行分组，如 `<g id="scene3-step1-elements">`。
  - 通过 JS 维护当前步骤变量 `currentStep` (0, 1, 2)。
  - 点击按钮时，更新 `currentStep`，并通过修改对应 SVG 组的 `opacity` 属性（配合 CSS `transition: opacity 0.5s ease;`）实现平滑的淡入淡出效果。
  - ID 命名规范：所有交互元素 ID 必须以 `scene3-` 为前缀（如 `scene3-btn-next`, `scene3-recombinant-plasmid`）。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
