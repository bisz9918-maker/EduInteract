[图示主题与整合说明]
- 本图示主题：紫花测交计算与白花突变推导
- 整合的步骤/概念：将复杂的遗传学概率计算（测交）与基因突变路径逆推（白花突变为蓝花）分为左右两个逻辑区块，通过分步展示，帮助学生理清计算过程和推导逻辑。
- 教学价值：教师可通过分步按钮，先引导学生完成左侧的测交概率计算，再转向右侧，逐步推导白花突变为蓝花的可能基因型，使抽象的遗传推导过程可视化、步骤化。

[视觉元素清单]
- 测交推导区（左侧）：包含3个带圆角的浅灰色背景框（紫花群体、产生配子、测交后代），以及连接它们的向下箭头。文字颜色主要为黑色 #000000，配子比例和最终结果使用蓝色 #1565c0 高亮。
- 突变推导区（右侧）：包含3个带圆角的浅灰色背景框（目标表型、白花来源、结论），中间展示两条突变路径。突变箭头和突变位点（如 A 变为 a）使用红色 #c62828 加粗高亮。
- 颜色/样式：背景 #ffffff；主线及普通文字 #000000；背景框填充 #f8f9fa，边框 #e0e0e0；测交高亮 #1565c0；突变高亮 #c62828。

[分步序列]
- 初始状态（步骤0）：显示左侧标题、紫花基因型框（包含 "1/3 AAbb" 和 "2/3 Aabb"）。
- 步骤1：点击「下一步」→ 显示左侧箭头1、配子框（包含 "A配子: 2/3" 和 "a配子: 1/3"）、以及测交文本 "测交 × aabb (只产生 a 配子)"。
- 步骤2：点击「下一步」→ 显示左侧箭头2、后代框（包含 "2/3 Aabb (紫花)" 和 "1/3 aabb (白花)"）、以及测交结果 "结果: 2紫 : 1白"。
- 步骤3：点击「下一步」→ 显示右侧标题、目标表型框 "目标表型: 蓝花 (aaB_)"。
- 步骤4：点击「下一步」→ 显示右侧来源表型框、两条突变路径（AaBB/AaBb → aaB_，aabb → aaBb）、以及最终结论框 "可能的突变前基因型: AaBB, AaBb, aabb"。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：在 SVG 底部 (y=460) 居中放置两个按钮，用于控制步骤 (0-4) 的切换。
- 教师操作流程：教师首先展示紫花群体的基因型，点击下一步引导学生计算配子比例，再点击下一步得出测交后代比例。随后点击下一步转向突变问题，展示目标表型，最后点击下一步展示突变路径推导过程并得出结论。

[技术实现]
- JS 库选择及原因：原生 SVG。图形主要由简单的矩形、线条和文本构成，原生 SVG 易于实现且排版精确。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  +-------------------------+-------------------------+
  |      紫花测交计算       |      白花突变推导       |
  |  +-------------------+  |  +-------------------+  |
  |  | 紫花群体基因型... |  |  | 目标表型: 蓝花... |  |
  |  +-------------------+  |  +-------------------+  |
  |            |            |  +-------------------+  |
  |  +-------------------+  |  | 白花来源: A_B_... |  |
  |  | 产生配子及比例... |  |  +-------------------+  |
  |  +-------------------+  |    AaBB/AaBb -> aaB_    |
  |   测交 × aabb (a配子)   |       aabb -> aaBb      |
  |            |            |  +-------------------+  |
  |  +-------------------+  |  | 可能的突变前...   |  |
  |  | 测交后代...       |  |  +-------------------+  |
  |  +-------------------+  |                         |
  |    结果: 2紫 : 1白      |                         |
  +-------------------------+-------------------------+
  [控件栏: ◀上一步  下一步▶]
  ```
- 关键实现要点：
  - 使用 `<g>` 标签将不同步骤的元素分组，并赋予对应的 class（如 `scene3-step-1`）。
  - JS 维护 `currentStep` 变量，根据当前步骤控制各分组的 `display` 或 `opacity` 属性。
  - 突变位点的高亮使用 `<tspan>` 标签嵌套在 `<text>` 中实现，例如 `<tspan fill="#c62828" font-weight="bold">A</tspan>aBB`。
- ID 命名规范：所有交互元素 ID 必须以 `scene3-` 为前缀（如 `scene3-btn-prev`, `scene3-step1-group`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
