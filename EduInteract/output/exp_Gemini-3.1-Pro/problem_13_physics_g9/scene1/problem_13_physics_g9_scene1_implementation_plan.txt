[图示主题与整合说明]
- 本图示主题：隔离法分析木块A与B之间的静摩擦力
- 整合的步骤/概念：通过隔离木块A，展示取下钩码前后A的水平受力平衡状态，直观呈现拉力变化导致静摩擦力随之变化的物理过程。
- 教学价值：教师可利用分步动画，清晰地向学生展示“静摩擦力随外力变化而变化”的特点，帮助学生理解受力分析中的隔离法应用。

[视觉元素清单]

- 木块A、B：黑色边框2px，白色填充
- 滑轮：黑色圆圈2px，中心带小圆点，黑色支架线
- 绳子：黑色实线2px
- 钩码：黑色边框2px，白色填充，内部带有数字标签
- 隔离高亮框：蓝色 #1565c0，虚线 stroke-dasharray: 5,5，填充透明度 10%
- 拉力箭头：蓝色 #1565c0，粗细3px，带箭头
- 摩擦力箭头：红色 #c62828，粗细3px，带箭头
- 文本标签：字体大小16px（结论文本24px），颜色与对应元素一致

[分步序列]
- 初始状态（步骤0）：显示实验台、木块A和B、滑轮、绳子、所有钩码。无受力箭头和隔离框。
- 步骤1：点击「下一步」→ 出现蓝色隔离框包围木块A；背景元素（实验台、木块B、滑轮、右侧绳码、左侧竖直绳及钩码）透明度降至0.3；在木块A上出现向左的蓝色拉力箭头 $T_A$ 和向右的红色摩擦力箭头 $f_{BA}$。
- 步骤2：点击「下一步」→ 钩码5（及其标签）透明度恢复为1.0，并沿路径平滑移动至木块A上方（路径：先向上至y=150，再向右至x=385，最后向下落至木块A顶部y=190）。
- 步骤3：点击「下一步」→ 拉力箭头 $T_A$ 缩短一半变为 $T_A'$，摩擦力箭头 $f_{BA}$ 缩短一半变为 $f_{BA}'$；标签同步更新并移动到新箭头的中心上方；顶部出现红色结论文本“A、B间静摩擦力减小”。

[标签冲突检查]
- "A" (400,225) 与 力标签 (350,235) / (450,235)：Y轴错开10px，X轴错开50px，无冲突。
- 钩码标签 "1"-"5"：均放置在各自矩形内部居中，绝对无冲突。
- $T_A$ 与 $f_{BA}$ 标签：分别在木块A的左右两侧，X轴相距100px，无冲突。
- 结论文本 (400,100)：位于画布顶部空白区域，无冲突。
- 动画过程冲突：钩码5移动路径最高点y=150，避开了所有木块和滑轮，无冲突。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：在SVG底部 (y=450~490) 放置两个按钮，控制步骤0-3的切换。
- 教师操作流程：教师首先展示整体物理情景（步0）；点击下一步，引导学生隔离木块A并进行受力分析（步1）；再次点击，演示取下钩码5的物理过程（步2）；最后点击，展示受力变化及最终结论（步3）。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。图形简单，原生 SVG 配合 CSS transition 即可实现平滑的透明度变化、缩放和路径动画，无需引入庞大的外部库。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```text
  [图示区 800×450]
      (结论文本区 y=100)
      (滑轮及绳索区 y=200~300)
      (木块A、B及桌面区 y=210~320)
      (左右钩码区 y=330~400)
  [控件栏 800×50] 包含 上一步 / 下一步 按钮
  ```
- 关键实现要点：
  - 状态机：使用 `currentStep` 变量记录当前步骤，通过切换 SVG 容器的 class（如 `.step1`, `.step2`）来触发 CSS 样式变化。
  - 动画实现：钩码5的移动使用 CSS `@keyframes` 动画；箭头的缩短使用 `transform: scaleX(0.5)` 配合 `transform-origin` 实现平滑过渡。
  - 标签更新：步骤3的力标签使用两套独立的 `<text>` 元素，通过透明度切换实现内容的无缝更改。
- ID 命名规范：所有元素 ID 均以 `scene1-` 开头，如 `scene1-blockA`, `scene1-weight5`。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
