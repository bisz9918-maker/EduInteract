[图示主题与整合说明]
- 本图示主题：整体法分析实验台与木块B之间的静摩擦力
- 整合的步骤/概念：将A、B视为整体，展示取下钩码前后整体的水平受力平衡及地面摩擦力变化。
- 教学价值：教师可以通过分步动画，清晰地向学生展示“整体法”的应用，以及外力变化时静摩擦力如何自适应调整以维持平衡。

[分步序列]
- 初始状态（步骤0）：显示实验台、木块A和B、滑轮、绳索、钩码1-5。所有元素透明度为100%。无高亮框，无受力箭头。
- 步骤1：点击「下一步」→ 整体高亮框出现。背景元素（实验台、滑轮、绳索、钩码1-5）透明度降至30%。木块A和B保持100%。出现拉力箭头 $T_左$（长度60）、$T_右$（长度90）和摩擦力箭头 $f_{地}$（长度30）。
- 步骤2：点击「下一步」→ 钩码5从左侧(125,340)平滑移动到木块A上方(390,140)。到达后，钩码5的透明度恢复为100%（成为整体的一部分）。受力箭头保持不变。
- 步骤3：点击「下一步」→ 拉力箭头 $T_左$ 缩短为 $T_左'$（长度30），摩擦力箭头 $f_{地}$ 变长为 $f_{地}'$（长度60）。显示结论文本“实验台与B间静摩擦力增大”。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 底部居中放置控制栏（y=450区域）。
  - 包含“上一步”按钮、“步骤 X / 3”指示器、“下一步”按钮。
- 教师操作流程：教师首先展示初始物理情景，然后点击“下一步”引导学生使用整体法进行受力分析，接着点击“下一步”演示取下钩码的物理过程，最后点击“下一步”展示受力变化和最终结论。可随时点击“上一步”回退。

[技术实现]
- JS 库选择及原因：原生 SVG。物理受力图主要由几何图形、直线和箭头组成，SVG 在处理矢量图形、箭头标记（marker）和动画（CSS transition）方面非常方便且清晰。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×440]
    (结论文本区)
    (滑轮、绳索、钩码、木块A/B、受力箭头)
  [控件栏 800×60]
    (◀上一步) (步骤 X / 3) (下一步▶)
  ```
- 关键实现要点：
  - 使用 `<marker>` 定义箭头样式，方便在 `<line>` 中复用。
  - 状态机设计：定义 `currentStep` 变量（0-3），每次点击按钮更新变量并调用 `updateScene()` 函数。
  - `updateScene()` 根据当前步骤控制各 SVG 元素的 `opacity`、`x/y` 属性（用于移动钩码）和 `x2/y2` 属性（用于改变箭头长度）。
  - 使用 CSS `transition: all 0.5s ease` 实现平滑的透明度变化、位置移动和箭头长度变化。
  - ID 命名规范：所有元素 ID 以 `scene2-` 开头，例如 `scene2-blockA`, `scene2-force-T-left`。
  - IIFE 隔离：所有脚本包裹在 `(function() { ... })()` 中。
