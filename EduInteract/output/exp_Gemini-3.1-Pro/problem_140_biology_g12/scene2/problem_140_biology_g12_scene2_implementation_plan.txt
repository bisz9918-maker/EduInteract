[图示主题与整合说明]
- 本图示主题：异常减数分裂产生 $X^E Y$ 精子的过程及受精作用
- 整合的步骤/概念：对比母本正常的减数分裂与父本异常的减数分裂（减数第一次分裂同源染色体未分离），并展示异常精子与正常卵细胞结合形成受精卵的过程。
- 教学价值：教师可通过分步演示，清晰地向学生展示染色体在减数分裂各阶段的走向，特别是异常发生在哪一个分裂时期，帮助学生直观理解基因型 $X^E X^e Y$ 的成因。

[视觉元素清单]
- 细胞轮廓：`stroke="#000000" stroke-width="2" fill="#fafafa"`
- $X^E$ 染色体：红色棒状 `stroke="#c62828" stroke-width="6" stroke-linecap="round"`，路径如 `M x y-12 L x y+12`，上方带红色 "E" 标签（坐标 y-22）。
- $Y$ 染色体：蓝色J型 `stroke="#1565c0" stroke-width="6" stroke-linecap="round" fill="none"`，路径如 `M x y-12 L x y+8 A 5 5 0 0 1 x-10 y+8`（利用圆弧画出底部弯钩）。
- $X^e$ 染色体：绿色棒状 `stroke="#2e7d32" stroke-width="6" stroke-linecap="round"`，路径如 `M x y-12 L x y+12`，上方带绿色 "e" 标签（坐标 y-22）。
- 过程箭头：`stroke="#888888" stroke-width="2" stroke-dasharray="5,5"`，带箭头标记 `marker-end`。
- 文本标签：使用 `#333333`，字号 14px。带有上下标的文本（如 $X^E$）需使用 `<tspan>` 实现，例如 `X<tspan dy="-5" font-size="0.75em">E</tspan>`。

[分步序列]
- 初始状态（步骤0）：显示父本初级精母细胞（含 $X^E$ 和 $Y$）及其标签，母本初级卵母细胞（含两个 $X^e$）及其标签。隐藏其他所有元素。
- 步骤1：点击「下一步」→ 显示母本减数分裂箭头、"正常减数分裂"标签、卵细胞（含一个 $X^e$）及其标签。
- 步骤2：点击「下一步」→ 显示父本减I异常箭头、"减数第一次分裂异常"标签、次级精母细胞（含 $X^E$ 和 $Y$）。
- 步骤3：点击「下一步」→ 显示父本减II正常箭头、"减数第二次分裂正常"标签、异常精子（含 $X^E$ 和 $Y$）及其标签。
- 步骤4：点击「下一步」→ 显示精子和卵细胞指向受精卵的受精箭头、"受精作用"标签、受精卵（含 $X^E$、$X^e$、$Y$）及其标签。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：在画布底部（y=460~490）居中放置两个按钮，中间显示当前步骤（如 "步骤 0 / 4"）。
- 教师操作流程：教师首先介绍初级性母细胞的基因型，然后点击下一步展示母本正常分裂，接着重点点击下一步展示父本减数第一次分裂同源染色体未分离的异常现象，最后展示受精过程，得出子代异常基因型的来源。

[技术实现]
- JS 库选择及原因：原生 SVG。由于全是简单的几何图形（圆形、线条、路径）和连线，SVG 的 DOM 结构非常适合分步控制显示/隐藏（通过 `opacity` 属性切换配合 CSS `transition`）。
- 画布尺寸：800 × 500 px（固定尺寸）。
- 布局草图：
  ```
  [图示区 800×500]
    (初级精母)        (初级卵母)
        |                 |
    (次级精母)            |
        |                 |
    (异常精子)        (卵细胞)
         \              /
          \            /
            (受精卵)
  [控件栏: ◀上一步  步骤 X/4  下一步▶]
  ```
- 关键实现要点：
  - 状态机设计：定义一个变量 `currentStep` (0~4)，每次点击按钮更新该变量，并调用 `updateView()` 函数。
  - `updateView()` 函数根据 `currentStep` 的值，控制各组 SVG 元素（用 `<g>` 标签分组并分配 ID）的 `opacity`，加入 `transition: opacity 0.5s` 实现平滑过渡。
  - 带有上下标的文本需使用 `<tspan>` 调整 `dy` 实现，注意在下一个字符前将 `dy` 恢复。
- ID 命名规范：所有交互元素 ID 必须以 `scene2-` 为前缀（如 `scene2-btn-next`, `scene2-step1-group`）。
- IIFE 隔离：所有 JS 代码必须包裹在 `(function() { ... })()` 中。
