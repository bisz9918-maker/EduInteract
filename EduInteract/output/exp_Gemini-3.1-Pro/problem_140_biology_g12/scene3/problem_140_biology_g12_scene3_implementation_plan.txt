[图示主题与整合说明]
- 本图示主题：F1自由组合配子致死棋盘法推导
- 整合的步骤/概念：将 4×4 正常孟德尔遗传棋盘与假设“雄配子 vR 致死”后的 3×4 棋盘进行对比，通过动态填表、剔除致死列、重新统计表现型比例，直观推导出 7:3:1:1 的特殊比例。
- 教学价值：教师可通过分步演示，引导学生理解配子致死对后代比例的影响，将抽象的逻辑推理转化为直观的表格剔除与数据重组过程，验证题干中的假设。

[分步序列]
- 初始状态（步骤0）：显示 5×5 空白棋盘框架及雌雄配子表头（VR, Vr, vR, vr）。合子单元格为空。右侧统计面板柱状图宽度为 0，数值全为 0，比例显示为空。
- 步骤1（正常情况）：点击「下一步」。16个合子单元格填入对应的基因型（如 VVRR），并根据表现型显示对应的背景色。右侧统计面板柱状图展开，数值分别变为 9, 3, 3, 1，底部显示“比例 = 9 : 3 : 3 : 1”。
- 步骤2（提出假设）：点击「下一步」。棋盘上方出现红色文字“假设雄配子 vR 致死”。雄配子 vR 所在的整列（第3数据列）被灰色斜线阴影覆盖，表头出现大红叉。该列的合子基因型文字变淡。
- 步骤3（重新统计）：点击「下一步」。右侧统计面板更新。长翅细眼柱子缩短至 7，残翅细眼柱子缩短至 1。数值更新为 7, 3, 1, 1。底部比例文字更新为“比例 = 7 : 3 : 1 : 1”。（被剔除的单元格背景色消失，保留阴影）。

[标签冲突检查]
- ♀ 标签 (95,145) 与 ♂ 标签 (125,115)：位于同一单元格对角线两侧，间距充足，无冲突。
- 雄配子表头 (170,135) 等与致死提示文字 (290,85)：Y轴错开 50px，无冲突。
- 统计面板各行标签 (y=155, 215, 275, 335)：Y轴间距 60px，文本高度约 20px，间距充足，无冲突。
- 柱状图数值标签 (610+宽+10)：动态跟随柱状图末端，X轴向右偏移 10px，不会与柱子重叠。最大宽度 9×15=135px，最右侧坐标为 610+135+10=755px，在 800px 画布范围内，无冲突。

[交互方案]
- 交互类型：分步按钮导航。
- 控件说明：底部居中放置两个按钮「◀ 上一步」和「下一步 ▶」。
- 教师操作流程：
  1. 停留在步骤0，引导学生回忆 F1 产生的配子种类。
  2. 点击下一步（步骤1），展示正常的 9:3:3:1 棋盘，作为对照基准。
  3. 点击下一步（步骤2），结合题干“7:3:1:1”的异常比例，引出假设，直观划掉致死配子所在列。
  4. 点击下一步（步骤3），引导学生一起清点剩余格子，得出新比例，验证假设成立。

[技术实现]
- JS 库选择：原生 SVG + 原生 JS。SVG 非常适合绘制精确的网格、文本对齐和斜线阴影图案。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  +-------------------+-------------------------+
  |                   |  表现型统计             |
  |  ♂ VR Vr vR vr    |  长翅细眼 [蓝] ██████ 9 |
  | ♀ +--+--+--+--+   |  长翅粗眼 [绿] ██ 3     |
  | VR|  |  |  |  |   |  残翅细眼 [红] ██ 3     |
  | Vr|  |  |  |  |   |  残翅粗眼 [灰] █ 1      |
  | vR|  |  |XX|  |   |                         |
  | vr|  |  |  |  |   |  比例 = 9 : 3 : 3 : 1   |
  +-------------------+-------------------------+
  [控件栏 y=450~490]
       [◀ 上一步] [下一步 ▶]
  ```
- 关键实现要点：
  - 使用 `<defs>` 定义 `<pattern id="scene3-hatch">` 用于致死列的斜线阴影。
  - 状态机设计：定义 `currentStep` (0-3)，每次点击按钮调用 `updateScene(step)`。
  - 动画过渡：为 SVG 元素的 `opacity`、`width`（柱状图）添加 CSS `transition: all 0.5s ease`，实现平滑的数值变化和元素显隐。
  - 数据绑定：将 16 个格子的基因型、表现型类别预先定义在 JS 数组中，根据步骤状态动态计算统计数据并更新 DOM。
  - ID 命名规范：所有元素 ID 必须以 `scene3-` 开头，如 `scene3-grid`、`scene3-bar-1`。
  - IIFE 隔离：整个脚本包裹在 `(function() { ... })()` 中。
