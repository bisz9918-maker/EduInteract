- 实验②推导树：精子和卵子图形，精子颈部线粒体打 #c62828 (红) 叉号。核遗传路径使用 #c62828 (红)。

- 筛选交集高亮框：#2e7d32 (绿) 粗线框。

- 步骤1：点击「下一步」→ 显示实验①左侧分支（a,b,c含线粒体S基因 -> 母系遗传 -> 100%抗病）。
- 步骤2：点击「下一步」→ 显示实验①右侧分支（d,e无线粒体S基因 -> d(SS) 100%抗病，e(S-) 3:1分离）及“区分出 e”标注。
- 步骤3：点击「下一步」→ 显示实验②精卵结合图，精子线粒体被打红叉，及“精子线粒体丢失”标注。
- 步骤4：点击「下一步」→ 显示实验②核基因传递分支（a,d(SS)->100%抗病，b,e(S-)->1:1分离，c(--)->0%抗病）。
- 步骤5：点击「下一步」→ 显示三个绿色高亮框（圈出两次实验中的100%抗病结果），并显示底部结论文本“交集筛选: 两次实验均表现为 100%抗病 的株系为 a, d”。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：在 SVG 底部 (y=460) 居中放置两个按钮，用于控制步骤的推进和回退。
- 教师操作流程：教师首先介绍实验样本，然后点击下一步逐步讲解实验①的细胞质遗传和核遗传，接着讲解实验②的受精特点和核遗传，最后点击下一步展示双重筛选的交集结果。

[技术实现]
- JS 库选择及原因：原生 SVG。图形主要由基本几何形状、连线和文本构成，SVG 能提供最佳的清晰度和精确的坐标控制。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  顶部: (a)  (b)  (c)  (d)  (e)
  中部左: 实验①推导树
  中部右: 实验②推导树
  底部: 交集筛选结论
  [控件栏: ◀上一步 | 下一步▶]
  ```
- 关键实现要点：
  - 使用 `<g>` 标签将不同步骤的元素分组，如 `<g id="scene2-step1">`。
  - 维护一个 `currentStep` 变量（0-5）。
  - `updateStep()` 函数根据 `currentStep` 控制各组的 `display` 属性（'none' 或 'block'）。
  - 细胞内部的染色体和线粒体使用 `<line>` 和 `<circle>` 绘制，S基因使用实心 `<circle>` 叠加。
  - ID 命名规范：所有元素 ID 必须以 `scene2-` 为前缀。
  - 代码封装在 IIFE 中，避免全局变量污染。
