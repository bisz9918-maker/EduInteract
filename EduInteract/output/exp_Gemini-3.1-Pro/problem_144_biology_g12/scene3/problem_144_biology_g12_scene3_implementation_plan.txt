[视觉元素清单]
- F2代候选亲本框：4个圆角矩形（rx=5），默认边框 #888888，填充 #ffffff。选中状态边框 #1565c0，填充 rgba(21, 101, 192, 0.1)。
- 连线与箭头：使用正交折线（polyline），颜色 #1565c0（亲本连线）和 #000000（子代连线），线宽 2px。
- 文本标签：基因型中的上标使用 `<tspan baseline-shift="super" font-size="0.7em">` 实现。
- 关键结论文本：子代表型结论（如“全为圆眼”、“圆眼 : 棒眼 = 1 : 1”）使用绿色 #2e7d32 加粗显示；总结论使用蓝色 #1565c0 加粗显示。

[分步序列]
- 状态1（组合一：交叉遗传验证）：
  - 顶部资源库高亮选中 框2(♀棒眼) 和 框3(♂圆眼)。
  - 显示状态1专属的亲本连线。
  - 亲本区显示：♀ 棒眼 (X^b X^b) × ♂ 圆眼 (X^B Y)。
  - 显示状态1专属的子代连线。
  - 子代区显示：♀ 圆眼 (X^B X^b) [全为圆眼]，♂ 棒眼 (X^b Y) [全为棒眼]。
  - 底部显示结论：“结论：交叉遗传验证”。
- 状态2（组合二：性状分离验证）：
  - 顶部资源库高亮选中 框1(♀圆眼) 和 框3(♂圆眼)。
  - 显示状态2专属的亲本连线。
  - 亲本区显示：♀ 圆眼 (X^B X^b) × ♂ 圆眼 (X^B Y)。
  - 显示状态2专属的子代连线。
  - 子代区显示：♀ 圆眼 (X^B X^B, X^B X^b) [全为圆眼]，♂ 圆眼 (X^B Y)，♂ 棒眼 (X^b Y) [圆眼 : 棒眼 = 1 : 1]。
  - 底部显示结论：“结论：性状分离验证”。

[交互方案]
- 交互类型：多状态切换（2个按钮）。
- 控件说明：底部居中放置两个按钮：“组合一 (交叉遗传)” 和 “组合二 (性状分离)”。
- 教师操作流程：初始加载显示状态1，教师讲解交叉遗传现象；点击“组合二”按钮，画面平滑切换至状态2，教师对比讲解性状分离现象。

[技术实现]
- JS 库选择：原生 SVG + 原生 JS（无需外部库，纯几何图形和文本排版）。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
    (y=40) 标题
    (y=60-120) 4个候选亲本框
    (y=120-190) 亲本连线区
    (y=215) 亲本基因型及杂交符号
    (y=230-300) 子代连线区
    (y=320-350) 子代基因型及表型结论
    (y=400) 总结论
  [控件栏 y=450-490] 2个切换按钮
  ```
- 关键实现要点：
  - 使用 `<g id="scene3-state1">` 和 `<g id="scene3-state2">` 分组管理不同状态下的连线和文本。
  - 切换状态时，通过修改 `display` 属性（`none` / `block`）控制组的显隐。
  - 动态更新资源框的 CSS class（如 `scene3-box-active`）以改变高亮样式。
  - 基因型文本中的上标必须使用 `<tspan baseline-shift="super" font-size="0.7em">` 确保排版规范。
- ID 命名规范：所有元素 ID 以 `scene3-` 开头（如 `scene3-btn-state1`, `scene3-box2`）。
- IIFE 隔离：所有 JS 逻辑封装在 `(function() { ... })()` 中。
