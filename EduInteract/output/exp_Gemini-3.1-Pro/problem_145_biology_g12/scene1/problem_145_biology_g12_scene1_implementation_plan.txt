[图示主题与整合说明]
- 本图示主题：甲、乙两病遗传类型的推导

- 教学价值：教师可通过分步点击，引导学生逐步观察系谱图中的关键个体（如 I-1、I-2、II-5），通过高亮提示和逻辑文本，清晰展示“无中生有为隐性”及排除伴性遗传的严密推理过程，帮助学生掌握遗传病类型推导的通用方法。

[分步序列]
- 初始状态（步骤0）：显示完整的家族系谱图，无任何高亮。右侧文本区提示“请点击「下一步」开始推导”。
- 步骤1（找隐性）：点击「下一步」。
  - 视觉变化：高亮 I-1、I-2 和 II-5 的边框为红色（#c62828），并加粗连接这三个个体的连线。
  - 文本更新：指出 I-1、I-2 无乙病，但生出患乙病的 II-5，推导“无中生有为隐性”，乙病为隐性遗传。
- 步骤2（定甲乙）：点击「下一步」。
  - 视觉变化：清除所有高亮，恢复正常系谱图。
  - 文本更新：根据题干“一种显性，一种伴性”，既然乙病是隐性，则甲病必然是显性。同时乙病为伴性遗传（伴X隐性）。
- 步骤3（排除伴X显）：点击「下一步」。
  - 视觉变化：高亮 I-1、II-4、II-6 的边框为蓝色（#1565c0），并加粗连接这三个个体的连线。
  - 文本更新：假设甲病为伴X显性，则患病父亲 I-1 的女儿必患病。但 II-4、II-6 正常，产生矛盾。得出甲病为常染色体显性。
- 最终步骤（得出结论）：点击「下一步」。
  - 视觉变化：清除所有高亮。
  - 文本更新：展示最终结论，甲病为常染色体显性遗传，乙病为伴X染色体隐性遗传。

[技术实现]
- JS 库选择及原因：原生 SVG。系谱图由规则的几何图形和连线组成，SVG 的 DOM 结构便于直接通过 CSS 类名控制高亮状态和动画过渡，且文本排版清晰。
- 画布尺寸：800 × 500 px。
- 布局草图：
  [图示区 800×500]
  左侧 (x:50~450)：系谱图绘制区
  右侧上 (x:480~780, y:50~200)：图例区
  右侧下 (x:480~780, y:220~420)：推导文本区 (foreignObject)
  底部 (y:460~490)：控件栏 (上一步/下一步按钮)
- 关键实现要点：
  1. 状态机设计：定义 `currentStep` (0~4)，每次点击按钮更新步骤，并调用 `updateState()` 函数。
  2. 高亮动画：在 CSS 中定义 `.highlight-red` 和 `.highlight-blue` 类，设置 `stroke` 颜色和 `stroke-width: 4px !important`。为所有 SVG 节点和连线添加 `transition: stroke 0.3s, stroke-width 0.3s;` 实现平滑过渡。
  3. 文本更新：在 `foreignObject` 内嵌一个 `<div>`，根据当前步骤直接更新其 `innerHTML`，利用 HTML/CSS 实现文本的换行、加粗和左侧边框颜色变化（对应高亮颜色）。
- ID 命名规范：所有元素 ID 均以 `scene1-` 为前缀（如 `scene1-node-I1`, `scene1-btn-next`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免污染全局变量。
