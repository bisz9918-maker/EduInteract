[视觉元素清单]
- 系谱图：I-1正方形（使用SVG pattern斜线填充），I-2圆形（白色填充），II-5圆形（使用SVG pattern网格填充），连线黑色。
- 细胞轮廓：黑色描边 `stroke="#000000"`，内部填充透明度10% `fill="rgba(0,0,0,0.05)"`。
- 染色体简图（细胞内）：
  - 复制态X（蓝）：交叉线 `X`，`stroke="#1565c0"`
  - 复制态Y（绿）：较小的交叉线 `X`，`stroke="#2e7d32"`
  - 单体X（蓝）：竖线 `|`，`stroke="#1565c0"`
  - 单体Y（绿）：较小的竖线 `|`，`stroke="#2e7d32"`
  - 卵子单体X（红）：竖线 `|`，`stroke="#c62828"`
- 箭头：黑色实线带箭头，溯源箭头为红色曲线带箭头 `stroke="#c62828"`。
- 文本标签：基因型使用 `<tspan baseline-shift="super">` 实现上标。

[分步序列]
- 初始状态（步骤0）：仅显示上方局部系谱图（I-1, I-2, II-5）及个体编号，下方空白。
- 步骤1：显示基因型（X^B Y, X^B X^b, X^b O），出现红色溯源箭头（I-2指向II-5），显示红色结论文字“父亲提供 O 配子”。
- 步骤2：下方出现“减一异常”路径（路径1）。显示初级精母细胞至受精卵的完整分裂过程、细胞内染色体、箭头及标签（XXY）。
- 步骤3：下方出现“减二异常(X不分离)”路径（路径2）。显示该分支的分裂过程、细胞内染色体、箭头及标签（XXX）。
- 步骤4：下方出现“减二异常(Y不分离)”路径（路径3）。显示该分支的分裂过程、细胞内染色体、箭头及标签（XYY）。

[标签冲突检查]
- 卵子标签与受精箭头：卵子位于(110, 365)，受精箭头从(110, 377)向右下指向(145, 395)。若标签放正下方会与箭头冲突。解决方案：卵子标签统一放在左侧(x-20, y+5)处，完美避开箭头。
- 精子标签与受精箭头：精子正下方有指向受精卵的垂直箭头。解决方案：精子标签统一放在外侧（左侧分支放左侧，右侧分支放右侧），避开正下方的垂直箭头。
- 细胞内染色体与标签：染色体绘制在细胞圆心附近，标签放置在细胞外部，互不干扰。

[交互方案]
- 交互类型：分步按钮导航
- 控件说明：在 SVG 底部 (y=460) 居中放置两个按钮「◀ 上一步」和「下一步 ▶」。
- 教师操作流程：教师首先展示系谱图，点击下一步推导基因型并得出父亲提供O配子的结论；随后连续点击下一步，逐一展示三种减数分裂异常路径，对比最终受精卵的性染色体组成（XXY, XXX, XYY），解答题目设问。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript。SVG 非常适合绘制精确的几何图形、连线、Pattern填充和文本上标。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  --------------------------------------------------
  |       I-1(X^BY) ──┬── I-2(X^BX^b)              |
  |                   │                            |
  |               II-5(X^bO)  <--父亲提供O配子       |
  |------------------------------------------------|
  | 行标签 |  减一异常  | 减二异常(X) | 减二异常(Y)  |
  | 1°精母 |     O      |      O      |      O       |
  | 2°精母 |   O   O    |    O   O    |    O   O     |
  | 精子   |   O   O    |    O   O    |    O   O     |
  | 受精卵 |  o-> O     |   o-> O     |   o-> O      |
  --------------------------------------------------
  [控件栏: ◀ 上一步 | 下一步 ▶] (绝对定位在底部)
  ```
- 关键实现要点：
  - 使用 `<g>` 标签对每一步的元素进行分组，如 `<g id="scene2-step1">`。
  - 状态机：维护 `currentStep` (0-4)，点击按钮时更新对应 `<g>` 的 `opacity` 或 `display` 属性，可加入 CSS `transition: opacity 0.3s` 实现平滑过渡。
  - ID 命名规范：所有 ID 必须以 `scene2-` 开头，如 `scene2-btn-next`, `scene2-pattern-diag`，防止跨场景冲突。
  - JS 逻辑封装在 IIFE `(function(){ ... })()` 中，确保变量隔离。
