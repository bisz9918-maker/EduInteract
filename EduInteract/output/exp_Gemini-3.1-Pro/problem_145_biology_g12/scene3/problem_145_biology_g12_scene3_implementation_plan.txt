[图示主题与整合说明]
- 本图示主题：两病兼患概率的拆解与计算
- 整合的步骤/概念：整合了基于人群患病率的基因型频率推导（哈代-温伯格定律应用）、孟德尔分离定律的后代概率计算，以及两大定律的乘法法则。
- 教学价值：教师可以通过分步展示，引导学生将复杂的两病兼患问题拆解为独立的甲病和乙病概率计算，最后再进行综合，避免学生在繁杂的计算中迷失思路。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：底部居中放置两个按钮，控制步骤状态（0~4）。
- 教师操作流程：教师首先介绍甲病的计算思路，点击下一步展示人群频率推导；再点击下一步展示甲病后代概率；接着转到右侧，点击下一步展示乙病的伴性遗传推导和旁氏表；最后点击下一步展示两大定律的综合乘法结果。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。图形均为基础几何形状和文本，原生 SVG 易于实现精确布局和样式控制。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [左侧甲病区 390x340] | [右侧乙病区 390x340]
  [ 10x10方格 + 推导 ] | [ I代系谱图        ]
  [ II代系谱图         ] | [ II代系谱图       ]
  [ 甲病计算公式       ] | [ 旁氏表 + 计算    ]
  -----------------------------------------
  [ 综合公式区 800x50 ]
  [ 控件栏 800x40 ]
  ```
- 关键实现要点：
  - 使用 `<g>` 标签将不同步骤的元素分组，通过 JS 控制 `display` 或 `opacity` 属性实现步骤切换。
  - 基因型中的上标（如 X^B）使用 `<tspan dy="-5" font-size="0.8em">B</tspan><tspan dy="5"> </tspan>` 实现。
  - 斜线填充使用 `<defs><pattern id="hatch"...></pattern></defs>`。
- ID 命名规范：所有交互元素 ID 以 `scene3-` 为前缀（如 `scene3-step1`, `scene3-btn-next`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
