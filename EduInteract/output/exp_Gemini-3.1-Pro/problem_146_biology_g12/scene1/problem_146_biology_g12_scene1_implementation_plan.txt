[图示主题与整合说明]
- 本图示主题：果蝇的染色体组成与XXY异常减数分裂
- 整合的步骤/概念：正常果蝇减数分裂染色体数变化、XXY果蝇的配子形成及杂交后代分析
- 教学价值：教师可通过分步演示，清晰展示正常减数分裂与异常减数分裂（XXY）中染色体的行为差异，特别是性染色体的联会与分离随机性，最后通过测交棋盘直观推导后代基因型，帮助学生突破遗传学难点。

[视觉元素清单]
- 细胞轮廓：圆形 | 黑线描边，无填充
- 常染色体：灰色线段/椭圆 (#999999)，透明度 50%

- 箭头：黑色实线带箭头 (#000000)
- 棋盘高亮：红色填充 (#c62828)，透明度 20%

[分步序列]
- 初始状态（步骤0）：显示正常果蝇体细胞（2n=8），高亮2个染色体组。
- 步骤1：点击「下一步」→ 切换显示减I中期细胞（同源染色体排列在赤道板）和减II后期细胞（着丝粒分裂，8条染色体）。
- 步骤2：点击「下一步」→ 切换显示XXY白眼雌果蝇的性染色体联会（X1, X2, Y）。
- 步骤3：点击「下一步」→ 动画演示分离情况1：X1与X2配对并分离，Y随机移向一极，产生 X^r 和 X^rY 两种配子。
- 步骤4：点击「下一步」→ 动画演示分离情况2：X1与Y配对并分离，X2随机移向一极，产生 X^rX^r 和 Y 两种配子。
- 步骤5：点击「下一步」→ 切换显示测交棋盘，左侧列出4种卵细胞，右侧展示与 X^RY 杂交的棋盘，高亮红眼雌果蝇的基因型。

[技术实现]
- JS 库选择及原因：原生 SVG。图形均为简单几何形状（圆、线段、路径），SVG 易于实现且支持高质量缩放和 CSS 动画。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×440]
  [控件栏 800×60 (y=440~500)，包含 上一步/下一步 按钮]
  ```
- 关键实现要点：
  - 使用 `<g>` 标签对每个步骤的元素进行分组，通过控制 `display` 属性切换步骤。
  - 步骤3和步骤4的动画可通过 CSS `transition` 或 JS `requestAnimationFrame` 实现染色体从母细胞平滑移动到配子细胞中。
  - 文本中的上标使用 `<tspan dy="-5" font-size="0.8em">` 实现，如 `X<tspan dy="-5" font-size="0.8em">r</tspan>`。
  - ID 命名规范：所有元素 ID 以 `scene1-` 为前缀，如 `scene1-step0-group`, `scene1-btn-next`。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
