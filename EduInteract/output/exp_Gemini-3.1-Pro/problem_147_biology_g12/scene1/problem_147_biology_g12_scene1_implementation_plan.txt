- 本图示主题：PCR技术第一轮循环的动态过程
- 整合的步骤/概念：将原图中的变性、复性、延伸三个步骤整合为一个连贯的动态过程，并填补了引物Ⅱ的序列及位置、循环一次后生成的完整DNA分子序列。

[视觉元素清单]
- 模板链（a链、b链）：黑色 #000000，字体大小 16px，等宽字体（monospace）以确保上下对齐。
- 引物Ⅰ及新链：蓝色 #1565c0。
- 引物Ⅱ及新链：绿色 #2e7d32。
- 氢键（省略号部分）：灰色 #888888，使用 stroke-dasharray="4,2" 的虚线表示。
- 高亮框：黄色 #fff59d，透明度 0.6，用于强调引物结合位点。
- 温度标签及箭头：黑色 #000000，箭头使用 marker-end。

[分步序列]
- 初始状态（步骤0）：仅显示 Row 1（初始状态），引物Ⅱ填空处为空白。隐藏其他所有行和箭头。
- 步骤1（变性 95℃）：点击「下一步」。显示 Arrow 1 (95℃) 和 Row 2。展示双链DNA解开为两条单链（a链在左，b链在右）。
- 步骤2（复性 55℃）：点击「下一步」。显示 Arrow 2 (55℃) 和 Row 3 的模板单链。
  - 动画1：引物Ⅱ填空内容 "HO—A—G—5'" 在 Row 1 出现。
  - 动画2：高亮 Row 3 中 a链的 3'端（T—C—3'）。
  - 动画3：引物Ⅱ从 Row 1 飞入 Row 3 的 a链 3'端下方结合。
  - 动画4：引物Ⅰ从 Row 1 飞入 Row 3 的 b链 3'端上方结合。
- 步骤3（延伸 72℃）：点击「下一步」。显示 Arrow 3 (72℃) 和 Row 4 的模板链及引物部分。
  - 动画1（左侧DNA）：从引物Ⅱ（绿色 A—G—5'）开始向左延伸，依次淡入绿色虚线、绿色 "3'—C—C"。
  - 动画2（右侧DNA）：从引物Ⅰ（蓝色 5'—G—G）开始向右延伸，依次淡入蓝色虚线、蓝色 "T—C—3'"。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：底部居中放置两个按钮，控制步骤 0-3 的切换。
- 教师操作流程：教师首先展示初始状态，提问引物Ⅱ的序列；点击下一步展示变性；再次点击展示复性，此时引物Ⅱ序列填补并动态结合到模板链上；最后点击展示延伸过程，动态呈现子链的 5'→3' 合成方向。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。SVG 非常适合精确的文本对齐、虚线绘制和坐标控制；原生 JS 配合 CSS transition 可轻松实现平滑的位移和淡入淡出动画。
- 画布尺寸：800 × 500 px。
- 布局草图：
  [图示区 800×450]
    [Row 1: 初始状态]
       ↓ 95℃
    [Row 2: 变性单链]
       ↓ 55℃
    [Row 3: 引物结合]
       ↓ 72℃
    [Row 4: 子链延伸]
  [控件栏 800×50 (y=450~500)]
- 关键实现要点：
  - 文本对齐：使用 `font-family="monospace"` 确保字符等宽，便于上下链的碱基对齐。
  - 动画实现：飞入动画使用两个绝对定位的 SVG `<text>` 元素（或在 SVG 内部使用 `<g>` 的 `transform` 过渡），从初始坐标平滑移动到目标坐标。
  - 延伸动画：在步骤 3 中，使用 `setTimeout` 依次修改新链各片段（虚线、末端序列）的 `opacity` 从 0 变为 1，模拟链的延伸过程。
  - 状态机：定义 `currentStep` 变量，每次切换步骤时，根据步骤编号统一控制所有元素的 `opacity` 和 `transform` 状态，确保「上一步」也能正确回退状态。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-btn-next`, `scene1-row2`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
