[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：在SVG内部底部（y=450~490）居中放置三个元素：[◀上一步]按钮、[步骤指示器]（如 1/5）、[下一步▶]按钮。
- 教师操作流程：教师首先展示初始状态，让学生观察题目条件；点击下一步，引导学生一起数绳子段数；再次点击，分析受力平衡；接着推导摩擦力；然后计算功率；最后计算有用功。每一步配合顶部出现的解析文本进行讲解。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。本场景主要由基础几何图形、路径和文本组成，原生 SVG 能够完美且高效地实现精确的坐标控制和清晰的渲染，无需引入庞大的外部库。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [顶部文本解析区 (y:40-150)]
  [主图示区：滑轮组与物体A (y:150-400)]
  [控件栏：上一步 / 进度 / 下一步 (y:450-490)]
  ```
- 关键实现要点：
  1. 状态机设计：定义 `currentStep` 变量（0-5），编写 `renderStep(step)` 函数，根据当前步骤控制各 SVG 元素的 `display` 属性和顶部 HTML 文本的内容。
  2. 坐标计算：严格按照布局坐标表绘制 SVG 路径，特别是绳子的路径需使用 `M` (移动), `L` (直线), `A` (圆弧) 指令精确连接滑轮边缘。
  3. 顶部文本：使用一个绝对定位的 HTML `<div>` 覆盖在 SVG 顶部，利用 `innerHTML` 动态更新富文本（包含上下标和颜色高亮），比 SVG `<text>` 更易于排版。
  4. ID 命名规范：所有元素 ID 必须以 `scene1-` 为前缀（如 `scene1-rope-main`, `scene1-btn-next`），确保多场景整合时不冲突。
  5. IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免污染全局变量。
