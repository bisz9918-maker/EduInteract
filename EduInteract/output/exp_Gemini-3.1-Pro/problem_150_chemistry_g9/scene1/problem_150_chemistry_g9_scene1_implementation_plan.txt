[图示主题与整合说明]
- 本图示主题：CO与H2混合还原氧化铁的实验装置连接与气体成分分析
- 整合的步骤/概念：反应原理（图甲）、产物吸收顺序（浓硫酸与氢氧化钠）、尾气处理（酒精灯）的完整实验装置拼接过程。
- 教学价值：教师可通过分步导航，引导学生逐步思考混合气体还原氧化铁后的产物成分，以及如何通过合理的装置连接顺序（先吸水、后吸二氧化碳、最后尾气处理）来分别测定H2和CO的还原量，培养学生的实验逻辑思维。

[视觉元素清单]
- 图甲装置：包含玻璃管、支架、加热用的酒精灯、氧化铁粉末。主线颜色 #000000。
- 装置a（酒精灯）：包含灯体、灯帽/灯芯、火焰。火焰默认颜色 #ff9800，处理尾气时变为绿高亮 #2e7d32。
- 装置b（氢氧化钠浓溶液）：包含洗气瓶、长短导管、液体。液体默认透明，吸收CO2时变为红高亮 #c62828（透明度20%）。
- 装置c（浓硫酸）：包含洗气瓶、长短导管、液体。液体默认透明，吸收水分时变为蓝高亮 #1565c0（透明度20%）。
- 装置d（澄清石灰水）：包含洗气瓶、长短导管、液体。液体默认 #eeeeee（透明度50%）。
- 气体流动标签：使用 #888888 颜色，无边框纯文本。
- 颜色/样式沿用 `<SCENE_k>` 中的配色规格。

[分步序列]
- 初始状态（步骤0）：显示图甲和图乙的四个独立装置（a, b, c, d在下方备选区）。图甲左侧显示输入气体“CO, H2”。提示文本：“实验目的：测定相同条件下CO和H2还原氧化铁的量。请组装实验装置。”
- 步骤1：点击「下一步」→ 图甲上方出现化学方程式（3CO+Fe2O3=2Fe+3CO2, 3H2+Fe2O3=2Fe+3H2O）。右侧导出气体标签1（CO2, H2O, 剩余CO, 剩余H2）出现。提示文本：“加热通入混合气体，发生还原反应生成CO2和H2O。”
- 步骤2：点击「下一步」→ 装置c平滑移动至图甲右侧，连线1出现。装置c液体变为蓝高亮，导出气体标签2出现。提示文本：“先连接装置c（浓硫酸）吸收水分，测定H2的还原量，避免后续溶液带来水分干扰。”
- 步骤3：点击「下一步」→ 装置b平滑移动至装置c右侧，连线2出现。装置b液体变为红高亮，导出气体标签3出现。提示文本：“再连接装置b（NaOH浓溶液）吸收CO2，测定CO的还原量。”
- 步骤4：点击「下一步」→ 装置a平滑移动至装置b右侧，连线3出现。装置a火焰变为绿高亮。提示文本：“最后连接装置a（酒精灯）点燃尾气，处理有毒的CO，防止污染。”

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。

[技术实现]
- JS 库选择及原因：原生 SVG。由于涉及大量几何图形（洗气瓶、导管）和基于坐标的平滑移动动画，SVG 的 `<g>` 标签配合 CSS `transform` 动画是最优选择。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  顶部：提示文本框 (y=40)
  主连接区：图甲(x=120) -> 装置c(x=300) -> 装置b(x=450) -> 装置a(x=600) (y=220)
  备选区：装置a, b, c, d (y=370)
  [控件栏 底部 y=460~490]
  ```
- 关键实现要点：
  - 状态机设计：定义 `currentStep` 变量，`updateStep()` 函数根据当前步骤控制各元素的 `opacity` 和 `transform`。
  - 动画实现：为装置的 `<g>` 标签添加 `style="transition: transform 1s ease-in-out;"`，通过修改 `transform="translate(x, y)"` 实现平滑移动。
  - 连线动画：连线使用 `<path>`，初始 `opacity="0"`，在对应步骤通过 CSS `transition: opacity 0.5s 1s;` 延迟显示，确保在装置移动到位后出现。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-app-c`, `scene1-line-1`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
