- 本图示主题：测定空气中氧气含量实验全过程动态演示

[分步序列]
- 步骤0（初始装置）：显示空集气瓶（无底水、无刻度）、烧杯（有水）、导管、燃烧匙（空）、止水夹（打开状态）。
- 步骤1（实验准备）：集气瓶底部出现底水，左侧出现刻度1-4；燃烧匙内出现红磷及标签；止水夹变为关闭状态（夹紧导管）。
- 步骤2（红磷燃烧）：红磷上方出现火焰，集气瓶内弥漫大量白烟（透明度渐变至0.8），显示“大量白烟”标签。
- 步骤3（冷却室温）：火焰消失，白烟逐渐消散（透明度渐变至0）。
- 步骤4（打开止水夹）：止水夹变为打开状态。导管内出现蓝色水流动画（从烧杯流向集气瓶）。集气瓶内液面从 y=360 上升到 y=320。烧杯液面从 y=250 下降到 y=260。
- 步骤5（得出结论）：液面停在刻度1（y=320）。高亮 y=320~360 区域，显示标签“占空气体积的1/5”。

[交互方案]
- 交互类型：分步按钮导航
- 控件说明：在 SVG 内底部 (y=450~490) 放置一个绝对定位的 `div` 控件栏，包含 [◀ 上一步] 按钮、中央步骤提示文本（如“步骤 2/5：红磷燃烧”）、[下一步 ▶] 按钮。
- 教师操作流程：教师点击“下一步”逐步推进实验过程，在每个现象发生后（如白烟产生、水倒吸）暂停，向学生提问或解释原理。可随时点击“上一步”回退重播动画。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。实验装置主要由规则几何图形和路径组成，SVG 易于绘制且支持高质量缩放。动画可通过 CSS transition 和 SVG 属性动画实现。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×450]
    (集气瓶)        (止水夹)
      |               |
      |---------------|
      |               |
    (刻度)          (烧杯)
    (红磷)          (水)
    (底水)
  [控件栏 800×50]
    [◀ 上一步]  步骤提示文本  [下一步 ▶]
  ```
- 关键实现要点：
  1. 状态机设计：维护 `currentStep` (0-5)，每次步骤变化时调用 `updateScene()`，通过修改 SVG 元素的 `opacity`、`y`、`height` 等属性触发 CSS 过渡动画。
  2. 导管水流动画：在导管内部叠加一条蓝色 `<path>`，使用 `stroke-dasharray` 和 `stroke-dashoffset`，在步骤4时通过改变 offset 实现水流从右向左、向下的流动效果。
  3. 液面升降动画：集气瓶水 `<rect>` 的 `y` 从 360 变到 320，`height` 从 38 变到 78；烧杯水 `<rect>` 的 `y` 从 250 变到 260，`height` 相应减小。配合 `transition: all 2s ease-in-out`。
  4. 白烟效果：使用 `<g>` 包含多个半透明灰色 `<circle>`，并应用 `<filter id="blur"><feGaussianBlur stdDeviation="5"/></filter>`，通过控制 `<g>` 的 `opacity` 实现弥漫和消散。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-bottle`, `scene1-water-bottle`）；JS 中用 `document.getElementById` 获取元素。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
