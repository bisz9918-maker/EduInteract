[视觉元素清单]
- 节点方框：8个 `<rect>`，默认白底黑边，内部居中 `<text>` 显示字母 A-G。
- 反应路径：多条 `<polyline>` 或 `<path>`，末端带 `<marker>` 箭头。默认黑色。
- 反应编号：3个 `<text>`，显示 ①、②、③，带白色背景遮挡线段。
- 推断标签：6个 `<text>`，初始隐藏。A(碱), B(酸), C(CuO), D(H₂O), F(铜盐), G(Cu(OH)₂)。
- 解释文本框：右侧 HTML `<div>`，带淡灰色背景和圆角，用于显示每步的推导逻辑。
- 颜色/样式：
  - 默认：黑色 #000000，白色 #ffffff
  - 蓝高亮（当前焦点）：#1565c0，边框加粗，背景填充 10% 透明度蓝色
  - 绿高亮（已确认）：#2e7d32，边框加粗，背景填充 10% 透明度绿色

[分步序列]
- 初始状态（步骤0）：显示所有节点、路径和编号。解释框提示“请点击「下一步」开始推导。”
- 步骤1：
  - 视觉变化：B、D、G 节点变为蓝高亮。显示 B、D、G 的推断标签（蓝色）。
  - 解释文本：“已知条件突破：
B 为最常见的酸
D 为人体中含量最多的物质，即 H₂O
G 为蓝色不溶物，即 Cu(OH)₂”
- 步骤2：
  - 视觉变化：B、D、G 节点及标签变为绿高亮（锁定）。A、F、E(右)、G 节点及反应③路径变为蓝高亮。
  - 解释文本：“分析反应③：
A + F → E + Cu(OH)₂↓
生成物有 Cu(OH)₂ 沉淀，推断反应物 A 和 F 为可溶性碱和可溶性铜盐。”
- 步骤3：
  - 视觉变化：反应③路径恢复黑色，E(右)、G 恢复绿高亮。A、B、E(上)、D 节点及反应①路径变为蓝高亮。显示 A、F 的推断标签（A为蓝色，F为绿色）。
  - 解释文本：“分析反应①：
A + 酸(B) → E + H₂O(D)
中和反应生成水，故 A 必为碱。
结合上一步，A 为可溶性碱，F 为可溶性铜盐。”
- 步骤4：
  - 视觉变化：反应①路径恢复黑色，A、B、E(上)、D 恢复绿高亮。B、C、D、F 节点及反应②路径变为蓝高亮。显示 C 的推断标签（蓝色）。
  - 解释文本：“分析反应②：
酸(B) + C → H₂O(D) + 铜盐(F)
金属氧化物与酸反应生成盐和水，推断 C 为氧化铜 (CuO)。”
- 步骤5：
  - 视觉变化：所有路径恢复黑色。A、B、C、D、F、G 节点及标签全部变为绿高亮。
  - 解释文本：“推导完成！
(1) C 的化学式为 CuO
(2) 反应③是复分解反应
(3) A 属于碱”

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：底部居中放置两个按钮，控制步骤 0 到 5 的切换。
- 教师操作流程：教师点击“下一步”逐步展示推导逻辑，配合右侧的解释文本进行讲解。可随时点击“上一步”回顾之前的推导过程。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。图形结构固定，连线和高亮状态通过操作 SVG 元素的 class 和 stroke/fill 属性即可轻松实现，无需引入复杂库。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +---------------------------------------------------+
  |  [A]碱       [E]                 [解释文本框]     |
  |   |           ^                  |                |
  |   +--①--+----+                  |                |
  |   |      v                       |                |
  |  [B]酸       [D]H2O      [E]     |                |
  |   |      ^                       |                |
  |   +--②--+----+           ^      |                |
  |   |      v      |        |       |                |
  |  [C]CuO      [F]铜盐--③--+       |                |
  |                        |         |                |
  |                        v         |                |
  |                        [G]Cu(OH)2|                |
  |                                                   |
  |             [◀上一步] [下一步▶]                   |
  +---------------------------------------------------+
  ```
- 关键实现要点：
  - 使用 `<g>` 标签对节点和路径进行分组，方便统一控制。
  - 定义 CSS 类 `.highlight-blue` 和 `.highlight-green`，通过 JS 切换类名实现颜色和透明度填充的动画过渡。
  - 维护一个 `currentStep` 变量，在按钮点击时更新，并调用 `renderStep(step)` 函数更新所有元素的视觉状态和解释文本。
  - ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-node-a`, `scene1-path-1`）。
  - IIFE 隔离：所有 JS 代码包裹在 `(function() { ... })()` 中。
