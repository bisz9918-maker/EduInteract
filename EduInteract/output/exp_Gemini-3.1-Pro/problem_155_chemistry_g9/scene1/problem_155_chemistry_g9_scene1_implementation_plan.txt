[视觉元素清单]
- 玻璃管装置：黑色主线 #000000，线宽2px，无填充。
- 粗钴/纯钴颗粒：蓝色 #1565c0，表示目标提纯物。
- 杂质颗粒：灰色 #888888，表示不参与反应的杂质。
- HCl气流及标签：绿色 #2e7d32，使用带有 stroke-dasharray 动画的虚线箭头表示流动。
- CoCl2+H2混合气流及标签：红色 #c62828，使用带有 stroke-dasharray 动画的虚线箭头表示流动。
- 温度标签：900℃使用红色 #c62828，600℃使用蓝色 #1565c0，带有轻微的 text-shadow 发光效果。

[分步序列]
- 初始状态（步骤0）：显示完整玻璃管装置。容器1底部显示粗Co颗粒（蓝色+灰色混合）。容器2为空。显示“容器1”、“容器2”、“固体X (粗Co)”标签。左侧显示静止的绿色HCl气流箭头及“气体Y (HCl)”标签。
- 步骤1（容器1反应）：点击「下一步」。显示“900℃”标签。左侧绿色HCl气流开始流动（动画）。容器1中的蓝色Co颗粒逐渐变淡（透明度降低至30%）。中间连接管出现红色混合气流并开始流动。显示“CoCl2(气)+H2(气)”标签。灰色杂质颗粒保持不变。
- 步骤2（容器2反应）：点击「下一步」。显示“600℃”标签。中间红色气流继续流动。容器2底部逐渐显现蓝色纯Co颗粒（透明度从0升至100%）。显示“纯净Co”标签。容器2右侧出现绿色HCl气流并开始流动。
- 步骤3（气体导出）：点击「下一步」。右侧绿色HCl气流流出，显示右侧“气体Y (HCl)”标签。容器1中的蓝色Co颗粒完全消失（透明度0%），“固体X (粗Co)”标签变为“杂质”标签。容器2中蓝色纯Co颗粒完全显现。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：在 SVG 内部底部（y=460 区域）居中放置两个按钮，用于控制步骤（0-3）的切换。
- 教师操作流程：教师首先介绍装置初始状态（步骤0）；点击下一步讲解容器1的高温反应和气体生成（步骤1）；再次点击讲解气体流入容器2后的低温沉积（步骤2）；最后点击展示提纯完成和气体循环导出（步骤3）。可随时点击上一步回顾。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。SVG 非常适合绘制玻璃管轮廓和清晰的文本标签，原生 JS 足以处理步骤状态机和颗粒的动态生成及透明度控制。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
    (900℃)         (CoCl2+H2)         (600℃)
    容器1                              容器2
  ===(蓝+灰)=========----->===========(纯蓝)===
    (固体X)                            (纯净Co)
  
  [控件栏 (y=460) ◀上一步  下一步▶]
  ```
- 关键实现要点：
  1. 玻璃管绘制：使用两条 `<path>` 分别绘制上半部分和下半部分轮廓，使用贝塞尔曲线（C或Q）实现膨大部的平滑过渡。
  2. 颗粒生成：在 JS 初始化时，向容器1和容器2的指定矩形区域内随机生成 `<circle>` 元素。容器1包含两组（蓝、灰），容器2包含一组（蓝）。
  3. 气流流动动画：使用 SVG `<line>` 配合 `stroke-dasharray`，通过 CSS `@keyframes` 改变 `stroke-dashoffset` 实现气流持续流动的视觉效果。
  4. 状态机：定义 `currentStep` (0-3)，每次点击按钮时更新该变量，并通过修改对应元素的 `style.opacity` 或 `style.display` 来控制元素的显隐和渐变过渡（配合 CSS `transition: opacity 0.5s`）。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-btn-next`, `scene1-particles-co1`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
