problem_160_math_g6

场景导航：Scene 1

题目：如图是一座楼房的平面图，图中不同字母表示长度不同的各条边长，若b=50米，c=30米，g=10米，则这座楼房平面图的周长是（ ）
A．90米
B．150米
C．180米

题目分析：
本题考查不规则图形的周长计算。直接求出每一条边的长度是不可能的，因为条件不足。我们需要利用“平移法”或“投影法”将未知的边长转化为已知的边长。
观察图形可知，所有的水平线段和垂直线段都相互垂直。

  1. 水平方向上，向右的线段有 $h$、$f$、$d$，向左的线段只有 $b$。因为图形闭合，所以向右的线段长度之和等于向左的线段长度之和，即 $h + f + d = b$。
  2. 竖直方向上，向上的线段有 $a$、$e$，向下的线段有 $g$、$c$。同理，向上的线段长度之和等于向下的线段长度之和，即 $a + e = g + c$。

整体讲解思路：

  1. 首先引导学生观察水平方向的线段，通过动画演示将顶部线段 $h$、$f$、$d$ 向下平移，使它们与底部线段 $b$ 重合，直观得出 $h + f + d = b$。
  2. 接着引导学生观察竖直方向的线段，通过将向上的线段 $a$、$e$ 和向下的线段 $g$、$c$ 投影到侧面的辅助线上，直观得出 $a + e = g + c$。
  3. 最后，将所有边长相加，利用前面得出的等量关系，将未知边长替换为已知边长，计算出最终的周长。

教学总结与课堂讲解建议：

  1. 引入：展示题目后，先让学生思考能否直接求出 $a, d, e, f, h$ 的长度。学生会发现条件不足。此时引出“整体代换”的思想。
  2. 水平方向：利用图示的步骤 1，引导学生观察所有水平线段。提问：“如果把房顶的几段水平线段都‘压’到地面上，会发生什么？”通过动画展示 $h, f, d$ 平移后刚好等于 $b$，让学生直观理解 $h+f+d=b$。
  3. 竖直方向：利用图示的步骤 2，引导学生区分“向上走”和“向下走”的线段。提问：“从左下角出发，沿着边缘走到右下角，总共向上走了多少？向下走了多少？”通过投影动画，证明向上的总高度等于向下的总高度，即 $a+e = g+c$。
  4. 总结计算：最后将周长公式重新分组，把未知的边长用已知的边长替换。
  • 周长 $P = a+b+c+d+e+f+g+h$
  • 重新排列：$P = b + (h+f+d) + (g+c) + (a+e)$
  • 代入等量关系：$P = b + b + (g+c) + (g+c) = 2b + 2(g+c)$
  • 代入数值：$P = 2 imes 50 + 2 imes (10 + 30) = 100 + 80 = 180$（米）。

得出正确选项为 C。
