[图示主题与整合说明]
- 本图示主题：分类按序数长方形
- 整合的步骤/概念：整合了寻找由1个、2个、3个、4个基本单元组成的长方形的完整计数过程，通过颜色和动画将抽象的组合过程具象化。
- 教学价值：教师可以通过分步演示，引导学生观察并掌握“分类计数、不重不漏”的数学思想。动态的高亮色块能让学生清晰地看到每一类长方形是如何由基本图形组合而成的，避免视觉混乱。

[分步序列]
- 初始状态（步骤0）：仅显示基础图形（大长方形和3条竖线），右侧文本全部隐藏。
- 步骤1：点击「下一步」→ 依次用蓝色半透明色块高亮4个基本小长方形（间隔约400ms），右侧淡入显示文本1。
- 步骤2：点击「下一步」→ 清除上一步高亮，依次用绿色半透明色块高亮相邻的2个基本图形组成的长方形（共3个），右侧淡入显示文本2。
- 步骤3：点击「下一步」→ 清除上一步高亮，依次用红色半透明色块高亮相邻的3个基本图形组成的长方形（共2个），右侧淡入显示文本3。
- 步骤4：点击「下一步」→ 清除上一步高亮，用灰色半透明色块高亮整个大长方形（共1个），右侧淡入显示文本4。
- 步骤5：点击「下一步」→ 清除高亮（或保持全图高亮），右侧淡入显示文本5（总计公式）。

[交互方案]
- 交互类型：分步按钮导航（◀ 上一步 / 下一步 ▶）
- 控件说明：底部居中放置两个按钮，ID分别为 `scene1-btn-prev` 和 `scene1-btn-next`。
- 教师操作流程：教师点击“下一步”逐步展示每一类长方形的寻找过程，配合动画讲解“从左到右、有序组合”的方法。可随时点击“上一步”回退重新演示某一步骤的动画。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript。图形简单，原生 SVG 足以实现精确的坐标控制和半透明叠加效果。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +-------------------------------------------------+
  |                                                 |
  |   +-------+---+---------+-------+   由1个...    |
  |   |       |   |         |       |   由2个...    |
  |   |       |   |         |       |   由3个...    |
  |   |       |   |         |       |   由4个...    |
  |   +-------+---+---------+-------+   总计...     |
  |                                                 |
  |             [◀ 上一步] [下一步 ▶]               |
  +-------------------------------------------------+
  ```
- 关键实现要点：
  - 状态机设计：使用变量 `currentStep` (0-5) 记录当前步骤。
  - 动画控制：在 JS 中使用 `async/await` 和 `Promise` 封装的 `sleep` 函数实现依次高亮。为了防止快速点击按钮导致动画错乱，需引入 `animationVersion` 机制，每次切换步骤时递增版本号，异步回调中检查版本号是否匹配，不匹配则中止后续动画。
  - 高亮渲染：预先定义好每一步的高亮矩形数据（x, width, color, opacity），在对应步骤动态创建 `<rect>` 元素追加到 `<g id="scene1-highlights">` 容器中，并添加简单的 CSS `opacity` 过渡动画。
- ID 命名规范：所有元素 ID 必须以 `scene1-` 为前缀，如 `scene1-base-rect`、`scene1-text-1`。
- IIFE 隔离：所有 JS 代码包裹在 `(function() { ... })()` 中。
