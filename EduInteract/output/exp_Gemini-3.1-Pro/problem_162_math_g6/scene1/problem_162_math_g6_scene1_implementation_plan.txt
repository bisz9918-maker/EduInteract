[图示主题与整合说明]
- 本图示主题：利用平移法比较三个图形的周长
- 整合的步骤/概念：通过将不规则图形的边进行平移，将其转化为规则的长方形，从而直观地比较周长大小。图形A展示基准长方形；图形B展示阶梯线段的完全平移；图形C展示凹陷线段平移后仍有多余边，从而得出C周长最长的结论。
- 教学价值：教师可通过分步演示，引导学生观察线段平移的过程，帮助学生理解“周长”的本质，掌握“平移法”在求不规则图形周长中的应用，化抽象为直观。

[分步序列]
- 初始状态（步骤0）：显示图形A、B、C的基础轮廓及所有文本标签（A, B, C, 10, 6）。隐藏所有虚线框和彩色高亮线段。
- 步骤1（分析A）：图形A外围显示灰色虚线框，图形A的黑色轮廓加粗，提示其为一个标准的长方形，周长为 (10+6)×2。
- 步骤2（平移B）：图形B外围显示灰色虚线框。B的4段水平阶梯线段高亮为蓝色，4段竖直阶梯线段高亮为绿色。触发动画：蓝色线段向上平移至 y=180，绿色线段向右平移至 x=475。平移后恰好与虚线框重合，说明B的周长等于A的周长。
- 步骤3（平移C）：图形C外围显示灰色虚线框。C凹陷底部的水平线段高亮为蓝色。触发动画：蓝色线段向上平移至 y=180，补齐顶部的长方形虚线轮廓。
- 步骤4（对比结论）：图形C中未能平移且多出的两条竖直线段高亮为红色，并持续闪烁（透明度 0.2 到 1 往复）。直观显示C的周长等于长方形周长再加上这两段红线的长度，因此C的周长最长。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：在 SVG 内部底部（y=450 区域）居中放置两个按钮：“◀ 上一步” 和 “下一步 ▶”。
- 教师操作流程：教师点击“下一步”逐步展示图形A的基准、图形B的线段平移过程、图形C的线段平移及多余边高亮。在每一步动画完成后，教师可结合视觉变化讲解周长的转化思想。如需复习，可点击“上一步”倒退动画。

[技术实现]
- JS 库选择及原因：使用 D3.js (v7)。D3 提供了强大的 SVG 元素选择、属性修改和过渡动画（transition）功能，非常适合实现线段的平移轨迹和状态切换。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```text
  [图示区 800×500]
  (95,180)      (325,180)      (555,180)
    +----+        +----+         +    +
    | A  |        | B  |         | C  |
    +----+        +----+         +----+
  
        [ ◀ 上一步 ] [ 下一步 ▶ ] (y=450)
  ```
- 关键实现要点：
  1. 状态机设计：维护一个 `currentStep` 变量（0~4）。每次点击按钮更新变量并调用 `renderStep(step)` 函数。
  2. 动画控制：使用 `d3.transition().duration(800)` 实现平移。前进时播放平移动画，后退时播放反向平移动画。
  3. 元素分组：将基础图形、虚线框、动态线段分别放在不同的 `<g>` 标签中，利用 `z-index`（SVG 中的 DOM 顺序）确保动态线段在最上层。
  4. 闪烁效果：对于步骤4的红色线段，使用 `d3.active(this)` 配合循环 transition 实现透明度的往复变化。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀，如 `scene1-btn-prev`, `scene1-shape-a`, `scene1-line-b-h1` 等。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
