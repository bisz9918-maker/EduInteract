[图示主题与整合说明]
- 本图示主题：钝角三角形边上的高的作法
- 整合的步骤/概念：识别三角形、确定底边、延长底边、作垂线找高的完整过程
- 教学价值：教师可通过分步导航，按逻辑顺序引导学生思考：先明确目标三角形，再锁定底边，接着发现钝角三角形的垂足在延长线上，最后完成作高。避免一次性展示所有辅助线导致学生困惑。

[分步序列]
- 初始状态（步骤0）：
  - 显示基础图形（外轮廓、内部连线AC/BC、辅助线BE）。
  - 显示所有标签 A, B, C, D, E。
  - 隐藏所有动态元素（蓝高亮三角形、红高亮底边、红色虚线延长线、绿色高亮高线、直角符号）。
- 步骤1（识别三角形）：
  - 显示蓝高亮三角形（多边形ABC，带填充和加粗边框）。
- 步骤2（确定底边）：
  - 保持步骤1状态。
  - 显示红高亮底边（线段AB，覆盖在原有边框上）。
- 步骤3（延长底边）：
  - 保持步骤2状态。
  - 显示红色虚线延长线（线段BD，覆盖在原有边框上）。
- 步骤4（作垂线）：
  - 保持步骤3状态。
  - 显示绿色高亮高线（线段CD，覆盖在原有边框上）。
  - 显示直角符号。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：
  - 在 SVG 内部底部（y=450 区域）放置一个居中的控制栏。
  - 包含“◀ 上一步”按钮、“步骤指示器 (如 0/4)”和“下一步 ▶”按钮。
- 教师操作流程：
  - 初始展示原图，让学生观察。
  - 点击“下一步”，高亮三角形ABC，明确研究对象。
  - 点击“下一步”，高亮底边AB，提问如何作AB边上的高。
  - 点击“下一步”，展示延长线BD，解释钝角三角形的高在外部。
  - 点击“下一步”，展示高线CD和直角符号，完成作高过程。

[技术实现]
- JS 库选择及原因：原生 SVG。图形由简单的线段和多边形组成，原生 SVG 易于控制图层、样式和动画，无需引入额外库。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
       C
      /|
     / |
  E /  |
  |/   |
  A--B--D
  [控件栏 (y=450)]
  ```
- 关键实现要点：
  - 使用 `<svg>` 元素，设置 `viewBox="0 0 800 500"`。
  - 图层顺序（从下到上）：基础图形 -> 蓝高亮三角形 -> 红高亮底边 -> 红色虚线延长线 -> 绿色高亮高线 -> 直角符号 -> 标签。
  - 状态机设计：定义一个 `currentStep` 变量（0 到 4）。
  - 更新函数 `updateState()`：根据 `currentStep` 的值，修改对应 SVG 元素的 `opacity` 属性（0 或 1）。使用 CSS `transition: opacity 0.3s ease` 实现平滑过渡。
  - 按钮状态：在步骤 0 禁用“上一步”，在步骤 4 禁用“下一步”。
  - ID 命名规范：所有元素 ID 必须以 `scene1-` 为前缀（如 `scene1-btn-prev`, `scene1-triangle-abc`）。JS 中使用 `document.getElementById` 获取元素。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免变量污染全局作用域。
