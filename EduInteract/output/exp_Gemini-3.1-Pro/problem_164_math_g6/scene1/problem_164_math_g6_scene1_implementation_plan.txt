[图示主题与整合说明]
- 本图示主题：立体图形的三视图分析与特征匹配验证
- 整合的步骤/概念：通过 3D 图形展示，结合分步生成的俯视图、主视图、侧视图，与标准三视图进行对比，逐步排除错误选项，最终验证正确选项。
- 教学价值：教师可以通过分步导航，引导学生按照“看上面（俯视筛选） -> 看正面（正视排除） -> 看侧面（侧视验证）”的逻辑顺序，直观地理解 3D 图形到 2D 投影的转换过程，培养空间想象力和逻辑推理能力。

[分步序列]
- 初始状态（步骤0）：显示右上角标准三视图框，显示中央的三个 3D 图形（①、②、③）及其底部标签。隐藏所有 2D 投影视图、虚线、判定符号和结论文本。
- 步骤1（看上面）：
  - 浮现 ①、②、③ 的俯视图（上方）及连接的投影虚线。
  - ①俯视图轮廓变红，显示红色 ✘（顶点朝前，不符）。
  - ②俯视图轮廓变绿，显示绿色 ✔（顶点朝后，符合）。
  - ③俯视图轮廓变红，显示红色 ✘（梯形，不符）。
- 步骤2（看正面）：
  - 保持步骤1内容。浮现 ①、②、③ 的主视图（下方）及连接的投影虚线。
  - ①主视图轮廓变红，中间有竖线，显示红色 ✘（不符）。
  - ②主视图轮廓变绿，单一矩形，显示绿色 ✔（符合）。
  - ③主视图轮廓变绿，单一矩形，显示绿色 ✔（符合，虽已排除但特征吻合）。
- 步骤3（看侧面）：
  - 保持步骤1、2内容。在 ② 的右侧浮现侧视图及连接的投影虚线。
  - ②侧视图轮廓变绿，中间有竖线，显示绿色 ✔（完全吻合）。
  - 底部出现结论文本：“图形②的三视图完全符合，选 B”。

[技术实现]
- JS 库选择及原因：原生 SVG。图形均为简单的多边形和矩形，SVG 的 `<polygon>`、`<rect>` 和 `<line>` 足以完美实现，且易于添加 CSS 过渡动画。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +---------------------------------------------------+
  |                                 [标准三视图框]    |
  |   [①俯视图]       [②俯视图]       [③俯视图]       |
  |                                                   |
  |   [3D图形①]       [3D图形②]  [②侧]  [3D图形③]       |
  |                                                   |
  |   [①主视图]       [②主视图]       [③主视图]       |
  |                  结论文本                         |
  |               [◀ 上一步] [下一步 ▶]               |
  +---------------------------------------------------+
  ```
- 关键实现要点：
  - 状态机设计：定义 `currentState` (0~3)，每次点击按钮更新状态并调用 `updateScene()`。
  - 动画过渡：为所有 2D 视图、虚线和符号添加 `opacity` 和 `stroke` 的 CSS `transition`，实现平滑淡入和颜色渐变。
  - 坐标精确性：严格按照布局坐标表绘制 `<polygon>` 的 `points` 属性，确保 3D 轴测图的视觉正确性。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-btn-next`, `scene1-view-top1`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
