[图示主题与整合说明]
- 本图示主题：局部面积等价替换法（比例思维）
- 整合的步骤/概念：通过在一个固定大小（6dm×6dm）的局部区域内分别铺设两种不同尺寸的地砖，直观展示“4块3dm地砖”与“9块2dm地砖”在覆盖面积上的等价关系，进而利用比例推导出总需求量。
- 教学价值：教师可通过分步动画，引导学生从“面积相等”过渡到“数量成比例”的思维。先建立局部替换的直观印象，再将局部规律放大到整体（100倍），帮助学生跨越抽象的算理障碍。

[分步序列]
- 初始状态（步骤0）：
  - 蓝组显示（仅显示外框和6dm标签，内部蓝砖透明度为0），绿组完全隐藏。
  - 蓝组位置居中：`transform: translate(0px, 0px) scale(1)`。
  - 所有底部说明文本、等号、公式均隐藏。
- 步骤1：点击「下一步」
  - 蓝组内的4块蓝砖及3dm标签淡入（透明度变为1）。
  - 底部淡入文本："4块 3dm地砖"。
- 步骤2：点击「下一步」
  - 蓝组整体淡出（透明度变为0）。
  - 绿组整体淡入（透明度变为1，显示外框、6dm标签、9块绿砖及2dm标签）。
  - 绿组位置居中：`transform: translate(0px, 0px) scale(1)`。
  - 底部文本切换为："9块 2dm地砖"。
- 步骤3（最终步骤）：点击「下一步」
  - 蓝组重新淡入，并与绿组同时执行平移和缩放动画：
    - 蓝组：`transform: translate(-150px, -10px) scale(0.75)`（移至左侧）
    - 绿组：`transform: translate(150px, -10px) scale(0.75)`（移至右侧）
  - 隐藏步骤2的说明文本。
  - 中央淡入等号 "="。
  - 左右两侧缩略图下方分别淡入 "4块" 和 "9块"。
  - 底部淡入推导公式："400块 = 100 × 4块  →  100 × 9块 = 900块"。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：在 SVG 底部 (y=450) 放置两个按钮，控制步骤 0~3 的切换。
- 教师操作流程：教师首先展示空白的6dm区域；点击下一步，演示用3dm地砖铺满需要4块；再点击下一步，演示同样区域用2dm地砖铺满需要9块；最后点击下一步，将两种铺法左右并排对比，引导学生得出“4块3dm地砖等价于9块2dm地砖”的结论，并结合公式完成最终的比例计算。

[技术实现]
- JS 库选择：原生 SVG + CSS Transitions。利用 CSS 的 `transform` 和 `opacity` 实现平滑的位移、缩放和淡入淡出动画。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
       6dm
    +-------+
    |       |
 6dm|  主图 |
    |       |
    +-------+
    (说明文本/公式区)
  [控件栏 ◀上一步 | 下一步▶]
  ```
- 关键实现要点：
  - 状态机设计：维护 `currentStep` 变量，每次点击按钮更新状态，并调用 `updateScene()` 函数统一设置各元素的 `style.opacity` 和 `style.transform`。
  - 动画锚点：蓝组和绿组的 CSS 必须设置 `transform-origin: 400px 180px;`，确保缩放和平移的基准点在画布中心，从而精确到达左右两侧的预定坐标。
  - 组隔离：蓝组和绿组各自包含完整的外框和尺寸标签，这样在步骤3并排显示时，两侧都能保留完整的标注信息。
- ID 命名规范：所有交互元素 ID 必须以 `scene2-` 为前缀（如 `scene2-group-blue`, `scene2-btn-next`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
