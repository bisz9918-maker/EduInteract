[图示主题与整合说明]
- 本图示主题：甲乙阴影面积的计算与比较
- 整合的步骤/概念：甲的底高标注与面积计算、乙的割补平移过程、面积比较结论
- 教学价值：教师可通过分步导航，先引导学生观察并计算甲的面积，再通过割补平移动画直观展示乙的面积计算方法，最后得出两者面积相等的结论，逻辑清晰，互动性强。

[视觉元素清单]
- 网格：6x2 正方形网格，线宽1px，#000000。
- 甲阴影：蓝色 #1565c0，默认透明度 0.2。
- 乙阴影（分左、中、右三部分绘制）：蓝色 #1565c0，默认透明度 0.2。
- 绿色平移块：绿色 #2e7d32，透明度 0.6，用于演示割补平移。
- 甲的底边：红色 #c62828，线宽3px。
- 甲的高：红色 #c62828，虚线，线宽3px。
- 辅助延长线：黑色 #000000，虚线，线宽1px。
- 文本标签：黑色 #000000，字号 16px（结论文本 20px，红色加粗）。

[分步序列]
- 初始状态（步骤0）：显示网格、甲乙阴影（透明度0.2）、“甲”“乙”标签。隐藏其他所有元素。
- 步骤1（分析甲）：甲阴影高亮（透明度0.4）。显示甲的底边、高、辅助延长线。显示标签“底=2”、“高=2”和“甲面积 = 2”。
- 步骤2（分析乙-准备）：甲阴影恢复（透明度0.2），隐藏甲的底高及相关标签。乙阴影高亮（透明度0.4）。隐藏乙右侧阴影，在同位置显示绿色平移块。保持显示“甲面积 = 2”。
- 步骤3（分析乙-平移）：绿色平移块向左平移 160px（刚好填补乙左侧上方的空白）。
- 步骤4（得出结论）：保持平移状态。显示“乙面积 = 2”和结论“甲的面积 = 乙的面积”。高亮“甲面积 = 2”和“乙面积 = 2”文本（变红加粗）。

[标签冲突检查]
- “甲” (240,220) 与 “底=2” (240,155)：y轴间距 65px，无冲突。
- “高=2” (410,255) 与 乙阴影：位于网格线 x=400 右侧，乙阴影在 x=400 右侧，但高=2 标签在空白处，无冲突。
- “甲面积 = 2” (240,380) 与 “乙面积 = 2” (480,380)：x轴间距 240px，无冲突。
- 结论文本 (360,420) 与 面积标签：y轴间距 40px，无冲突。
所有标签均已合理分散，无重叠风险。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：底部居中放置“上一步”、“下一步”按钮及步骤指示器（如 0 / 4）。
- 教师操作流程：教师点击“下一步”逐步揭示甲的面积计算、乙的割补过程及最终结论，可随时点击“上一步”回退。

[技术实现]
- JS 库选择：原生 SVG + 原生 JS。图形简单，SVG 配合 CSS transition 可完美实现平移动画和透明度渐变。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×450]
    (居中显示 480x160 的网格及图形)
    (网格下方显示面积计算和结论)
  [控件栏 800×50]
    (上一步) 0 / 4 (下一步)
  ```
- 关键实现要点：
  - 状态机设计：定义一个包含 5 个状态的数组，每个状态记录各元素的透明度、位移等属性。
  - 动画实现：为 SVG 元素添加 `transition: transform 1s ease-in-out, opacity 0.3s;`，通过修改 `style.transform = 'translateX(-160px)'` 实现平移。
  - ID 命名规范：所有元素 ID 以 `scene1-` 开头（如 `scene1-green-tri`），JS 中使用 `document.getElementById` 获取。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
