[图示主题与整合说明]
- 本图示主题：圆的周长与直径的线性关系及代数推导验证
- 整合的步骤/概念：从几何图形中提取直径的加和关系，代入周长公式进行代数恒等变形，最后通过“化曲为直”将周长展开为线段，直观验证代数推导的结论。
- 教学价值：教师可通过分步导航，先引导学生观察直径关系，再进行严密的代数推导，最后用直观的线段长度对比来验证结论，将抽象的代数公式与直观的几何图形完美结合，加深学生对周长线性关系的理解。

[分步序列]
- 初始状态（步骤0）：显示大圆、两个小圆及贯穿的水平直径（均为黑色）。隐藏所有标注、公式和展开线段。
- 步骤1：点击「下一步」→ 出现直径标注线 d1(蓝)、d2(红)、D(绿)。右侧公式区出现等式：d₁ + d₂ = D。
- 步骤2：点击「下一步」→ 左小圆变蓝并填充淡蓝，出现 C1 标签；右小圆变红并填充淡红，出现 C2 标签；大圆变绿，出现 C 标签。公式区追加显示周长公式：C₁ = πd₁, C₂ = πd₂, C = πD。
- 步骤3：点击「下一步」→ 公式区追加显示代数推导过程：C₁ + C₂ = πd₁ + πd₂ = π(d₁ + d₂)。
- 步骤4：点击「下一步」→ 公式区追加显示最终结论：C₁ + C₂ = πD = C。
- 步骤5：点击「下一步」→ 底部出现展开的线段。绿色长线段(C)在上方，蓝色(C1)和红色(C2)短线段在下方首尾相接。出现灰色虚线辅助对齐，直观证明 C1 + C2 = C。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：底部居中放置两个按钮，控制步骤 0 到 5 的切换。
- 教师操作流程：教师首先展示题目原图（步0），然后点击下一步引导学生观察直径关系（步1），接着引入周长公式（步2），进行代数推导（步3、4），最后展示化曲为直的几何验证（步5），完美闭环。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。SVG 非常适合绘制精确的几何图形（圆、线段）和控制样式状态，公式区使用 HTML `<div>` 绝对定位，方便文本排版和颜色控制。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +-----------------------------------------+
  |                                         |
  |       (D)                               |
  |    +-------+-------+    [公式区]        |
  |   /   (C1)  \ (C2)  \   d1 + d2 = D     |
  |  |  +---+  +---+     |  C1 = πd1 ...    |
  |  |  |d1 |  | d2|     |  C1+C2 = π(d1+d2)|
  |  |  +---+  +---+     |  C1+C2 = C       |
  |   \                 /                   |
  |    +---------------+                    |
  |           (C)                           |
  |                                         |
  |  (C) -----------------------------      |
  |  (C1) ------- (C2) ---------------      |
  |                                         |
  |           [◀上一步] [下一步▶]           |
  +-----------------------------------------+
  ```
- 关键实现要点：
  - 状态机设计：定义 `currentStep` 变量（0-5），每次点击按钮更新变量并调用 `updateState()` 函数。
  - `updateState()` 根据当前步骤控制各 SVG 元素的 `opacity`、`stroke`、`fill` 属性，以及公式区各行文本的 `display` 属性。
  - 展开线段的动画：在步骤 5 时，可以通过设置 `stroke-dasharray` 和 `stroke-dashoffset` 配合 CSS `transition` 实现线段从左向右生长的动画效果，增强“展开”的视觉体验。
  - ID 命名规范：所有元素 ID 必须以 `scene1-` 为前缀（如 `scene1-circle-large`, `scene1-formula-1`）。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
