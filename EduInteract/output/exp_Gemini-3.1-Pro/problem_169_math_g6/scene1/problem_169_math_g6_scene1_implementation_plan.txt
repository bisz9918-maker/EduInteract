[视觉元素清单]
- 坐标轴：黑色实线，带箭头。
- 轴标签：北、南、西、东，黑色文本。
- 关键点：雷达站、巡洋舰，黑色实心圆点。
- 连线及刻度：黑色实线，中点处有垂直短线。
- 角度标注：黑色圆弧，文本"40°"。
- 比例尺：黑色实线及端点短线，文本"50 km"。

[分步序列]
- 初始状态（步骤0）：显示完整的坐标系、雷达站、巡洋舰、连线及中点刻度、40°角、比例尺。隐藏所有高亮和结论文本。
- 步骤1（看方向）：
  - 视觉变化：正北方向射线加粗并高亮为蓝色（#1565c0）；出现一个从正北向东旋转 40° 的蓝色高亮扇形（透明度20%）；“北”、“东”和“40°”标签放大（scale 1.5）并变蓝。
  - 新增元素：右上角出现文本“方向：北偏东40°”（蓝色）。
- 步骤2（算距离）：
  - 视觉变化：取消步骤1的方向高亮和放大效果（保留右上角结论文本）；右下角的比例尺线段及“50 km”高亮为红色（#c62828）并加粗。
  - 新增元素：连线上依次出现两段红色加粗线段（第一段从雷达站到中点，第二段从中点到巡洋舰），并在每段右下方出现红色的“50 km”标签；右上角追加文本“距离：50 + 50 = 100 km”（红色）。
- 步骤3（得结论）：
  - 视觉变化：同时保留方向（蓝色扇形）和距离（红色线段）的关键高亮信息。
  - 新增元素：右上角追加最终结论文本“结论：北偏东40°方向100km”，并在下方醒目提示“选择 C”（红色加粗，字号变大）。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：在 SVG 内部底部（y=460）居中放置两个按钮，用于控制步骤 0 到 3 的切换。

[技术实现]
- JS 库选择及原因：原生 SVG。图形由简单的线段、圆弧和文本组成，SVG 易于实现精确的坐标控制和 DOM 动画（如颜色渐变、透明度变化）。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  左侧/中央：坐标系、雷达站、巡洋舰及连线
  右下角：比例尺
  右上角：结论文本区
  [控件栏（y=460~490，居中）]
  [ ◀ 上一步 ] [ 下一步 ▶ ]
  ```
- 关键实现要点：
  - 状态机设计：定义 `currentStep` 变量（0-3），每次点击按钮更新状态，并调用 `updateScene()` 函数。
  - 坐标计算：使用 SVG 的 `<path>` 绘制圆弧和扇形。扇形路径为 `M 350 230 L 350 70 A 160 160 0 0 1 453 108 Z`。
  - 动画过渡：通过 CSS `transition` 控制 `opacity`、`stroke`、`fill` 和 `transform`，实现平滑的高亮和放大效果。
  - ID 命名规范：所有元素 ID 均以 `scene1-` 开头，如 `scene1-radar-pt`、`scene1-btn-next`。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
