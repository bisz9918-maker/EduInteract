[图示主题与整合说明]
- 本图示主题：实物图转化为等效电路图
- 整合的步骤/概念：主电路追踪、滑动变阻器有效阻值段分析、电压表V1接入点分析、电压表V2接入点分析
- 教学价值：通过分步高亮实物图连线并同步生成标准电路图，帮助学生克服实物图连线复杂的视觉干扰，掌握“先主路、后支路”的电路分析方法，清晰直观地展示电压表的测量对象。

[视觉元素清单]
- **左侧实物组件**：使用 SVG 绘制简化的实物图标（电池组、带闸刀的开关、带灯丝的灯泡、带接线柱的电表和滑动变阻器）。
- **右侧电路符号**：使用标准电路符号（电池长短线、开关断开线、灯泡圆圈加叉、电阻矩形、电表圆圈加字母）。
- **导线**：左侧实物图使用平滑的贝塞尔曲线（`path`），右侧电路图使用正交直线（`path`）。
- **颜色/样式**：
  - 默认状态：所有组件和导线为黑色 `#000000`。
  - 主电路高亮：红色 `#c62828`，线宽 3px。
  - 变阻器有效段：红色 `#c62828`，线宽 6px（加粗）。
  - V1 及其支路高亮：蓝色 `#1565c0`，线宽 2px。
  - V2 及其支路高亮：绿色 `#2e7d32`，线宽 2px。

[分步序列]
- **初始状态（步骤0）**：显示左侧完整的实物连线图（全部为黑色）。右侧电路图区为空白，中心显示提示文字“点击「下一步」开始分析电路”。
- **步骤1（主电路）**：点击「下一步」。左侧主电路导线及组件（E, A, R, L, S）高亮为红色。右侧提示文字消失，同步淡入绘制出红色的串联主电路图（包含 E, S, L, R, A 及主干导线）。
- **步骤2（变阻器接法）**：点击「下一步」。左侧滑动变阻器左半段线圈加粗高亮（红色）。右侧电路图中变阻器符号的左半段加粗，并浮现“有效阻值段”文字标签指向该段。
- **步骤3（电压表V1）**：点击「下一步」。左侧 V1 表盘及其连接到灯泡两端的导线高亮为蓝色。右侧电路图中淡入蓝色的 V1 支路（并联在灯泡 L 两端）。
- **步骤4（电压表V2）**：点击「下一步」。左侧 V2 表盘及其连接到变阻器两端的导线高亮为绿色。右侧电路图中淡入绿色的 V2 支路（并联在滑动变阻器 R 两端）。

[标签冲突检查]
- 左侧标签：各组件分布在画布不同角落，标签均设置在远离中心和其他组件的外侧（如 V1 在上方，V2 在下方），间距均 > 50px，无冲突。
- 右侧主电路标签：L (580, 360) 和 R (680, 360) 间距 100px，标签均在上方，无冲突。S 标签在左侧，A 标签在右侧，完美避开内部导线。
- 右侧并联支路：V1 支路接入点为 (550) 和 (610)，V2 支路接入点为 (650) 和 (710)。V1 右侧接入点与 V2 左侧接入点相距 40px，互不干扰。V1 和 V2 标签均在最下方 (y=465)，无冲突。

[交互方案]
- **交互类型**：分步按钮导航。
- **控件说明**：在 SVG 内部底部（y=460 区域）居中放置两个按钮：「◀ 上一步」和「下一步 ▶」。
- **教师操作流程**：教师在课堂讲解时，首先展示复杂的实物图让学生观察；随后每点击一次「下一步」，图示会自动剥离出一条逻辑线（主路 -> 变阻器细节 -> V1支路 -> V2支路），教师可配合高亮动画同步讲解电路拓扑结构的转化过程。

[技术实现]
- **JS 库选择**：原生 SVG。电路图的连线和符号非常适合用 SVG 矢量绘制，且易于通过 CSS 控制颜色和透明度动画。
- **画布尺寸**：800 × 500 px。
- **布局草图**：
  ```text
  [左侧实物图区 460px] | [右侧电路图区 340px]
  V1(蓝)      R(红)   |    E(红)
    \        /        |  +---+---+
     S(红)-E(红)-A(红) |  S       A
    /        \        |  +--L-R--+
  L(红)       V2(绿)  |   |   |
                      |  V1  V2
  ----------------------------------------
           [◀ 上一步] [下一步 ▶]
  ```
- **关键实现要点**：
  - 状态机：维护 `currentStep` (0~4)，每次点击按钮更新状态并调用 `updateScene()`。
  - 动画过渡：为所有 SVG 元素的 `stroke`, `opacity`, `stroke-width` 属性添加 CSS `transition: all 0.5s ease`，实现平滑的显隐和变色效果。
  - 导线绘制：左侧实物导线使用 `<path d="M... C..."/>` 贝塞尔曲线，调整控制点确保导线不穿过组件图标。
- **ID 命名规范**：所有元素 ID 必须以 `scene1-` 开头，例如 `scene1-btn-next`, `scene1-left-wire-main`, `scene1-right-v1`。
- **作用域隔离**：所有 JavaScript 代码必须包裹在 `(function() { ... })()` 立即执行函数中，避免全局变量污染。
