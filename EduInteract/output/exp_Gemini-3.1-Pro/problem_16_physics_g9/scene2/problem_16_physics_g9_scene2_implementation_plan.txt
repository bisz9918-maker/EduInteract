[图示主题与整合说明]
- 本图示主题：滑片移动时的电路动态变化模拟
- 整合的步骤/概念：电阻变化、电流变化、灯泡亮度变化、电压表示数变化及关系、总功率变化
- 教学价值：教师可通过连续拖拽滑块，直观展示滑动变阻器阻值变化如何引起电路中电流、各部分电压及总功率的连锁反应，特别是直观验证串联电路中 $U_1 + U_2 = U$ 的分压原理。

[分步序列]
- 交互方式为连续拖拽，无离散步骤。定义关键状态如下：
- 初始状态（滑片居中，x=240）：
  - 变阻器有效长度为一半。
  - 电流表指针偏转约中等角度。
  - 灯泡光晕透明度中等。
  - V1指针偏转中等，V2指针偏转中等。
  - 右侧柱状图：V1(蓝)和V2(绿)高度比例约为 3:7。
  - 总功率柱状图高度约为最大值的 30%。
- 状态2（滑片向右拖拽至最右端，x=300）：
  - 变阻器有效长度最长（全黑）。
  - 电流表指针偏转角度最小。
  - 灯泡光晕透明度最低（最暗）。
  - V1指针偏转最小，V2指针偏转最大。
  - 右侧柱状图：V1(蓝)高度极小，V2(绿)高度极大，总高度不变。
  - 总功率柱状图高度降至最低。
- 状态3（滑片向左拖拽至最左端，x=180）：
  - 变阻器有效长度为0。
  - 电流表指针偏转角度最大。
  - 灯泡光晕透明度最高（最亮）。
  - V1指针偏转最大，V2指针偏转为0。
  - 右侧柱状图：V1(蓝)占据全部高度，V2(绿)高度为0。
  - 总功率柱状图高度达到最大（触及基准线）。

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：无需额外底部按钮控件。交互直接在主图区的滑动变阻器滑片上进行。滑片上方有“向右拖拽 ➔”提示。
- 教师操作流程：教师在讲解时，用鼠标或触摸按住变阻器上的滑片，向右缓慢拖动。随着拖动，教师可引导学生观察：1. 变阻器有效黑色部分变长（电阻变大）；2. 电流表指针回退（电流变小）；3. 灯泡光晕变暗；4. V1指针回退，V2指针前进；5. 右侧柱状图中蓝色下降、绿色上升但总高度不变（串联分压原理）；6. 功率柱下降（总功率变小）。

[技术实现]
- JS 库选择及原因：原生 SVG + Vanilla JS。电路图和柱状图均为简单几何图形，原生 SVG 性能好且易于绑定拖拽事件。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +-------------------------+-----------------------+
  |          V2             |  [电压]      [功率]   |
  |       /----(V)----\     |  ---U---    --最大--  |
  |      /      |      \    |  | V2  |    |      |  |
  | +---/-------R-------\-+ |  |     |    |      |  |
  | |                     | |  |-----|    |  P   |  |
  | L(V1)                 A |  | V1  |    |      |  |
  | |                     | |  |     |    |      |  |
  | +----U---------S------+ |  -------    --------  |
  +-------------------------+-----------------------+
  ```
- 关键实现要点：
  - 状态机与物理模型：定义 `sliderX` (180~300)。计算 $R_{slider} = 50 	imes (sliderX-180)/120$。设定 $U=12, R_L=10$。计算 $I = U/(R_L+R_{slider})$, $U_1 = I 	imes R_L$, $U_2 = U - U_1$, $P = U 	imes I$。
  - 拖拽事件绑定：为滑片元素（及扩大的透明感应区）绑定 `mousedown`, `mousemove`, `mouseup` (及 touch 对应事件)。在 `mousemove` 中更新 `sliderX` 并调用 `updateSimulation()`。
  - 动画更新：`updateSimulation()` 中，使用 `setAttribute` 更新滑片 `<polygon>` 的 `points`，有效电阻 `<rect>` 的 `width`，各表盘指针 `<line>` 的 `transform="rotate(...)"`，光晕 `<circle>` 的 `opacity`，以及右侧柱状图 `<rect>` 的 `y` 和 `height`。
  - ID 命名规范：所有元素 ID 必须以 `scene2-` 为前缀，如 `scene2-slider`, `scene2-v1-pointer`。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
