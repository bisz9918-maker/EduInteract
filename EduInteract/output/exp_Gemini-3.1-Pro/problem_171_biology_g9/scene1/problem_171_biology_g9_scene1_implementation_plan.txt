[分步序列]
- 初始状态（步骤0）：显示概念图（A, B, C, D, E框及加号、箭头）。隐藏模式图、所有辅助线、推导标签和选项区。
- 步骤1：点击「下一步」→ E框和D框边框高亮（#1565c0，加粗）。D框下方出现标签“脱氧核苷酸”。左下方出现脱氧核苷酸模式图（碱基、糖、磷酸及内部连线）。
- 步骤2：点击「下一步」→ 移除E、D框高亮。A、B、C框边框高亮（#1565c0，加粗）。出现从A、B、C框分别垂直连接到下方模式图的灰色虚线。在虚线上方浮现标签“含氮碱基”（A下方）和“脱氧核糖”（B下方）。
- 步骤3：点击「下一步」→ 在A标签下方出现“4种 (A, T, C, G)”，在D标签下方出现“4种”。
- 步骤4：点击「下一步」→ 右下角出现选项判定区。A、C、D选项的错误词汇划删除线并显示红色正确词汇，B选项末尾显示绿色打勾。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：在 SVG 内部底部（y=450~490）居中放置两个按钮，控制步骤 0~4 的切换。
- 教师操作流程：教师首先展示题目原图，然后点击下一步引导学生从 DNA 逆推基本单位，再点击下一步拆解基本单位的三个组分，接着点击下一步分析种类数量，最后点击下一步逐一辨析四个选项。

[技术实现]
- JS 库选择及原因：原生 SVG + HTML DOM。图形简单，原生 SVG 易于实现精确布局和连线；选项区包含富文本（删除线、变色），使用 HTML `<div>` 绝对定位覆盖在 SVG 上最为简便且效果最好。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  [A] + [B] + [C]  ->  [   D   ]  ->  [  E  ]     |
  |   |     |     |         |                      |
  |  含氮  脱氧             脱氧核苷酸               |
  |  碱基  核糖             4种                      |
  |  4种                                             |
  |   |     |     |       A. A表示的碱基有5(4)种     |
  | [碱]-[糖]-[磷]        B. D表示脱氧核苷酸 ✔       |
  |                       C. D表示的结构有8(4)种     |
  |                       D. B表示的是核糖(脱氧核糖) |
  |                                                  |
  |             [◀上一步] [下一步▶]                  |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  - 状态机设计：定义 `currentStep` 变量（0-4），每次点击按钮调用 `updateState()` 函数，根据当前步骤控制各元素的 `display` 或 `opacity` 属性。
  - 坐标计算：严格按照布局坐标表绘制 SVG 元素。五边形糖的顶点坐标需精确计算，确保“氧原子”朝上，1'碳朝左（水平翻转以匹配A、B、C顺序，避免连线交叉）。
  - HTML 覆盖层：选项区使用 `<div id="scene1-options" style="position: absolute; left: 450px; top: 230px; ...">`，内部使用 `<p>` 和 `<span>` 实现富文本样式。
  - ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-box-a`, `scene1-model-base`）。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
