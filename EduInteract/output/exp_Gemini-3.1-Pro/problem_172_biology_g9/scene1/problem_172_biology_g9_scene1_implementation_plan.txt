- 教师操作流程：教师首先展示初始概念图，提问学生①和②分别代表什么运输方式；学生回答后，教师点击「下一步」揭晓答案并展示分类依据；接着提问③和④的具体实例，再次点击「下一步」揭晓最终答案。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。概念图由简单的矩形、直线和文本构成，SVG 能够完美保证图形清晰度，且易于通过 DOM 操作实现文本替换和样式过渡动画。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```text
  [图示区 800×500]
          [物质跨膜运输方式]
         /                  \
    [被动运输]              [①]
    /        \               |
[自由扩散]   [②]             |
   |          |              |
[氧气..]     [③]            [④]
  
  [控件栏： ◀上一步  下一步▶ ]
  ```
- 关键实现要点：
  - 使用 `<svg>` 标签构建静态图形，将 `<line>` 元素放在 `<rect>` 元素之前，确保连线在矩形下方。
  - 为需要交互的元素（节点1/2/3/4的矩形和文本、分类依据标签）分配唯一的 ID，如 `scene1-node1-rect`, `scene1-node1-text`。
  - 状态机设计：定义 `currentStep` 变量（0-2），在 `updateState()` 函数中根据当前步骤统一设置各元素的文本内容、颜色、填充透明度和透明度（opacity）。
  - 动画过渡：在 CSS 中为矩形的 `stroke`, `fill` 以及文本的 `opacity`, `fill` 添加 `transition: all 0.3s ease`，实现平滑的高亮和淡入效果。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
