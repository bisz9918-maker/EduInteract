[图示主题与整合说明]
- 本图示主题：物质进出细胞方式的微观机制对比
- 整合的步骤/概念：被动运输（自由扩散、协助扩散）、主动运输、胞吞的微观过程，对比浓度梯度、载体蛋白需求及ATP消耗。
- 教学价值：教师可通过切换不同状态，清晰直观地对比三种跨膜运输方式的核心差异，配合题目选项（如主动运输逆浓度梯度、消耗ATP等）进行针对性讲解。

[分步序列]
- 初始状态（状态1）：被动运输。显示左侧向下浓度梯度（高浓度到低浓度）。显示平直的磷脂双分子层。显示自由扩散（绿色小分子直接穿膜）和协助扩散（绿色小分子通过蓝色通道蛋白穿膜）。
- 状态2：主动运输。点击「主动运输」按钮触发。左侧浓度梯度变为向上（外侧低浓度，内侧高浓度）。显示蓝色载体蛋白，红色小分子逆浓度梯度（从外向内）运输。内侧显示 ATP 转化为 ADP+Pi，并释放能量作用于载体蛋白。
- 状态3：胞吞。点击「胞吞」按钮触发。隐藏浓度梯度。磷脂双分子层变为凹陷形态，下方形成囊泡。橙色大分子物质进入囊泡。内侧显示 ATP 消耗过程。

[交互方案]
- 交互类型：多状态切换（3个按钮）。
- 控件说明：底部水平排列三个按钮「被动运输」、「主动运输」、「胞吞」。
- 教师操作流程：教师点击对应按钮，主图区平滑切换到对应的运输方式示意图，配合讲解题目中选项 A（ATP消耗）、B（逆浓度梯度）、C（大分子运输）的正误。

[技术实现]
- JS 库选择及原因：原生 SVG。由于主要涉及几何图形、路径和简单的透明度切换，原生 SVG 性能好且易于实现响应式和精确坐标控制。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×450]
  左侧：浓度梯度指示
  中右侧：细胞膜及跨膜运输微观示意
  [控件栏 800×50]
  [ 被动运输 ] [ 主动运输 ] [ 胞吞 ]
  ```
- 关键实现要点：
  - 使用 3 个 `<g>` 标签分别包裹三个状态的特有元素，通过 JS 切换其 `style.display` 或 `opacity` 实现状态切换。
  - 磷脂双分子层在状态1、2使用 `<rect>`，在状态3使用 `<path>` 绘制 U 型凹陷（如 `M 200 210 L 380 210 C 410 210, 410 270, 450 270 C 490 270, 490 210, 520 210 ...`）。
  - 囊泡使用两个嵌套的 `<path>` 弧线绘制成环形（Donut shape），模拟膜的截面。
  - 箭头使用 `<marker>` 定义，方便复用。
- ID 命名规范：所有交互元素 ID 必须以 `scene2-` 为前缀（如 `scene2-btn-passive`, `scene2-group-active`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
