[图示主题与整合说明]
- 本图示主题：生态系统碳循环中各成分的推导
- 整合的步骤/概念：整合了原图展示、寻找生产者（双向箭头）、寻找分解者（汇聚箭头）、寻找消费者（捕食箭头）的完整推导过程。
- 教学价值：教师可通过分步导航，引导学生根据箭头方向的拓扑关系，逐步推理出碳循环中甲、乙、丙所代表的生态系统成分，逻辑清晰，视觉反馈直观。

[分步序列]
- 步骤0（初始状态）：
  - 显示所有节点（CO2、甲、乙、丙）和所有箭头，颜色均为默认黑色 #000000。
  - 节点文本分别为“大气中的二氧化碳”、“甲”、“乙”、“丙”。
  - 动态提示文本为空。
- 步骤1（定位生产者）：
  - 高亮“甲”节点及甲与CO2之间的双向箭头（甲->CO2, CO2->甲），颜色变为红色 #c62828。
  - “甲”节点文本更新为“甲 (生产者)”。
  - 动态提示文本显示：“与大气中二氧化碳有双向交换的只有生产者（光合作用吸收，呼吸作用释放）”。
  - 其他元素保持默认状态。
- 步骤2（定位分解者）：
  - 高亮“乙”节点，以及指向乙的箭头（甲->乙, 丙->乙）和乙指出的箭头（乙->CO2），颜色变为蓝色 #1565c0。
  - “乙”节点文本更新为“乙 (分解者)”。
  - 动态提示文本显示：“生产者和消费者都会流向分解者，分解者将其分解为二氧化碳”。
  - 甲节点及相关箭头恢复默认黑色，但保留“甲 (生产者)”文本。
- 步骤3（定位消费者）：
  - 高亮“丙”节点，以及甲指向丙的底部弧形箭头（甲->丙）和丙指出的箭头（丙->CO2），颜色变为绿色 #2e7d32。
  - “丙”节点文本更新为“丙 (消费者)”。
  - 动态提示文本显示：“消费者以生产者为食，并进行呼吸作用”。
  - 乙节点及相关箭头恢复默认黑色，保留“乙 (分解者)”文本。
- 步骤4（总结）：
  - 所有节点显示完整文本（甲 (生产者)、乙 (分解者)、丙 (消费者)）。
  - 所有相关箭头展示对应的高亮颜色（甲相关红色，乙相关蓝色，丙相关绿色）。
  - 动态提示文本显示：“综上所述：甲为生产者，乙为分解者，丙为消费者。对应选项 A”。

[标签冲突检查]
- CO2节点 (400, 100) 与 其他节点 (y=280)：y轴间距 180px，无冲突。
- 甲节点 (200, 280) 与 乙节点 (400, 280)：x轴间距 200px。甲文本最长为“甲 (生产者)”(约100px宽)，乙文本最长为“乙 (分解者)”(约100px宽)。两者边缘间距约 100px，无冲突。
- 乙节点 (400, 280) 与 丙节点 (600, 280)：x轴间距 200px。边缘间距约 100px，无冲突。
- 箭头与节点文本：箭头起点和终点均设置在文本 bounding box 之外（如甲的 x 范围是 150-250，甲->乙 箭头起点设为 260），完美避开文本遮挡，无冲突。
- 底部弧线 (M 200 300 Q 400 380 600 300) 与 乙节点 (400, 280)：弧线在 y=340~380 处经过，乙节点底部在 y=295 处，y轴间距充足，无冲突。
- 动态提示文本 (400, 420) 与 底部弧线 (最大y=340)：提示文本在弧线下方，无冲突。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：在 SVG 底部 (y=450~490) 放置两个按钮，“上一步”和“下一步”，以及步骤指示器（如 0/4）。
- 教师操作流程：教师点击“下一步”按钮，依次展示寻找生产者、分解者、消费者的推理过程，配合动态提示文本进行讲解。可随时点击“上一步”回退。

[技术实现]
- JS 库选择及原因：原生 SVG。由于全是简单的文本、直线和二次贝塞尔曲线，原生 SVG 配合 DOM 操作即可高效实现，无需引入庞大库。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×440]
       (大气中的二氧化碳)
      ↗ ↓      ↑      ↖
    /   ↓      ↑        \
  (甲) →→→ (乙) ←←← (丙)
    \                    /
      ------------------
  [动态提示文本区 y=420]
  [控件栏 y=450-490, 包含 上一步/下一步 按钮]
  ```
- 关键实现要点：
  - 使用 `<marker>` 定义不同颜色的箭头头部（黑色、红色、蓝色、绿色），以便在状态切换时直接更改 `<path>` 或 `<line>` 的 `marker-end` 属性。
  - 状态机设计：定义一个 `step` 变量（0-4），每次点击按钮更新 `step`，并调用 `renderStep(step)` 函数。
  - `renderStep` 函数内，根据当前步骤，重置所有元素的颜色和文本，然后应用当前步骤的高亮颜色、文本更新和提示信息。
  - ID 命名规范：所有元素 ID 必须以 `scene1-` 为前缀，例如 `scene1-node-jia`, `scene1-arrow-jia-co2`。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
