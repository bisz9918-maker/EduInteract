[图示主题与整合说明]
- 本图示主题：植物类群特征与分类树推导
- 整合的步骤/概念：复现原题的植物分类树，并通过分步交互，逐一推导①②③④代表的植物类群（裸子植物、藻类植物、蕨类植物、苔藓植物），并与四个选项进行辨析。
- 教学价值：教师可通过分步导航，引导学生沿着分类树的逻辑分支，逐步鉴定植物类群，并直观展示选项中的易错点（如“只能”、“都很矮小”），帮助学生建立清晰的植物分类知识体系。

[视觉元素清单]
- 树状图节点文本：使用 SVG `<text>`，`text-anchor="middle"`，默认颜色 #000000。
- 树状图连线：使用 SVG `<line>` 或 `<path>`，默认颜色 #000000，线宽 2px。
- 动态信息框：使用 SVG `<rect>` 作为背景（填充 #f8f9fa，边框 #e0e0e0），内部使用 `<foreignObject>` 嵌套 HTML 以实现文本换行和局部高亮。
- 辅助虚线：使用 SVG `<line>`，颜色 #888888，`stroke-dasharray="5,5"`。
- 颜色/样式：
  - 蓝高亮：#1565c0（当前路径连线、节点文本、编号，线宽加粗至 3px，字体加粗）
  - 红高亮：#c62828（错误关键词、✘图标）
  - 绿高亮：#2e7d32（正确关键词、✔图标）

[标签冲突检查]
- “无果实植物”(220,60) 与 “无种子”(120,140)：垂直间距 80px，无冲突。
- “无种子”(120,140) 与 “有种子”(320,140)：水平间距 200px，无冲突。
- “有种子”(320,140) 与 “①”(320,170)：垂直间距 30px，无冲突。
- “无茎叶”(50,220) 与 “有茎叶”(190,220)：水平间距 140px，无冲突。
- “有输导组织”(120,300) 与 “无输导组织”(260,300)：水平间距 140px，无冲突。
- “有茎叶”(190,220) 与 “有输导组织”(120,300)：垂直间距 80px，水平错开 70px，无冲突。
- 结论：所有节点文本和编号均有充足的留白，不会发生重叠。信息框固定在右侧空白区域 (420~770)，完全避开左侧树状图。

[交互方案]
- 交互类型：分步按钮导航。
- 控件说明：底部居中放置两个按钮“◀ 上一步”和“下一步 ▶”，中间显示当前步骤指示器（如“1 / 4”）。
- 教师操作流程：教师点击“下一步”逐步揭示每个编号代表的植物类群，结合右侧弹出的信息框，对比选项中的描述，指出错误关键词，完成逐项排查。

[技术实现]
- JS 库选择：原生 SVG + HTML/CSS。SVG 适合绘制精确的树状图连线和文本，HTML `<foreignObject>` 适合处理信息框内的富文本换行和局部变色。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800x500]
  +-------------------------+-------------------------+
  |       无果实植物        |                         |
  |           |             |                         |
  |     +-----+-----+       |  +-------------------+  |
  |   无种子       有种子   |  | ① 裸子植物      |  |
  |     |            ①      |  | 生殖脱离水...     |  |
  |  +--+--+                |  | A. ... ✔          |  |
  |无茎叶 有茎叶            |  +-------------------+  |
  |  ②     |                |                         |
  |      +-+-+              |                         |
  | 有输导   无输导         |                         |
  |   ③        ④          |                         |
  +-------------------------+-------------------------+
  [控件栏: ◀ 上一步   1 / 4   下一步 ▶]
  ```
- 关键实现要点：
  - 状态机设计：维护一个 `currentStep` 变量（0-4）。
  - 渲染函数：每次步骤切换时，先重置所有连线和文本的颜色为默认值（#000000，font-weight: normal），然后根据 `currentStep` 为特定的连线和文本添加高亮类或直接修改属性。
  - 信息框更新：预先在 JS 中定义好每一步的标题、内容和选项 HTML 字符串，切换步骤时更新 `<foreignObject>` 内部的 `innerHTML`，并更新辅助虚线的 `x1`, `y1` 坐标。
  - ID 命名规范：所有 DOM 元素的 ID 必须以 `scene1-` 开头（如 `scene1-node-root`, `scene1-line-1`, `scene1-btn-next`）。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
