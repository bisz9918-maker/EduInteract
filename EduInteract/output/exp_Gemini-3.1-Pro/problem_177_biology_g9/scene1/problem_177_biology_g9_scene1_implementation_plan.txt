[图示主题与整合说明]
- 本图示主题：染色体、DNA、基因的微观结构与概念包含关系
- 整合的步骤/概念：图甲的生物结构识别、图乙的逻辑包含关系、甲乙两图的映射以及易错选项分析。
- 教学价值：教师可以通过分步导航，先引导学生识别微观结构，再建立宏观的概念层级关系，接着通过连线将两者映射，最后对比蛋白质和基因的遗传信息特征，帮助学生逐个击破考点和易错点。

[分步序列]
- 初始状态（步骤0）：显示图甲和图乙的黑色线稿。标签仅显示数字标号（1、2、3、4和①、②、③），无文字标签。
- 步骤1（解析图甲）：高亮图甲结构并出现文字标签。染色体[1]填充浅蓝色，显示"染色体"；DNA[2]描边变绿，显示"DNA"；蛋白质[3]填充浅灰色，显示"蛋白质"；基因[4]描边加粗变深绿，显示"基因"。
- 步骤2（解析图乙）：高亮图乙圆圈并出现文字标签。大圆①填充浅蓝色，显示"染色体"；中圆②填充浅绿色，显示"DNA"；小圆③填充较深绿色，显示"基因"。
- 步骤3（建立映射）：出现三条灰色虚线，将图甲的标签与图乙的对应标签连接起来（1连①，2连②，4连③），虚线带有 stroke-dashoffset 动画以引导视线。
- 步骤4（突破易错点）：图甲中的蛋白质[3]填充变为红色，并在下方出现红色提示"不含特定遗传信息"；基因[4]上方出现绿色提示"含特定遗传信息"。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：在 SVG 底部（y=450~490）居中放置两个按钮，中间显示当前步骤提示（如"步骤 1 / 4"）。
- 教师操作流程：教师点击"下一步"逐步展示图甲结构、图乙概念、两者映射关系，最后展示易错点对比。可随时点击"上一步"回退。

[技术实现]
- JS 库选择及原因：原生 SVG。本场景主要由几何图形、曲线和文本组成，原生 SVG 对路径动画和层级控制支持极佳，无需引入外部库。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800x450]
  左侧(50-450): 图甲(染色体、DNA等)
  右侧(450-780): 图乙(三个同心圆)
  上方(50-200): 映射连线区
  [控件栏 800x50]
  (◀上一步)  步骤 x / 4  (下一步▶)
  ```
- 关键实现要点：
  - 状态机设计：定义 `currentStep` (0-4)，每次点击按钮更新状态，并调用 `renderStep()` 函数统一控制所有元素的 `opacity`、`fill`、`stroke` 等属性。
  - 坐标计算：图乙的三个圆左侧相切，圆心 Y 坐标相同，X 坐标分别为 630, 580, 530，半径分别为 150, 100, 50。
  - 动画曲线：使用 CSS `transition: all 0.5s ease` 实现颜色和透明度的平滑过渡。连线使用 `stroke-dasharray` 和 `stroke-dashoffset` 配合 CSS `@keyframes` 实现流动效果。
  - ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-btn-next`, `scene1-path-dna`）。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
