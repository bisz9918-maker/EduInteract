[视觉元素清单]
- 杂交节点文本：P, F1, F2, 黄花, 白花, ×。颜色 #000000，字号 16px。
- 连线及编号：①, ②, ③ 及对应线条。颜色 #000000，线宽 1.5px。
- 基因型标注：aa, Aa, AA。颜色 #1565c0（蓝色）。
- 概率与比例数值：1/2, 1/8, 1/4 等。颜色 #2e7d32（绿色）。
- 重点推理高亮：显(A), 隐(a), 测交, 连线③高亮。颜色 #c62828（红色）。
- 推导面板：背景 rgba(21, 101, 192, 0.1)，边框 1px dashed #888888，内边距 15px，字号 14px。
- 对比高亮框：半透明红色填充 rgba(198, 40, 40, 0.2)，红色边框 #c62828。

[分步序列]
- 初始状态（步骤0）：显示基础杂交图解（节点、连线、编号）。推导面板显示“请点击「下一步」开始推导。”
- 步骤1（显隐性）：连线③变红加粗，F1白花、F2黄花2、F2白花文本变红。F1白花旁出现红色“显(A)”，F2黄花2旁出现红色“隐(a)”。面板更新显隐性判断逻辑（无中生有为隐性）。
- 步骤2（推基因型）：连线③及文本恢复黑色。隐藏“显(A)”和“隐(a)”。显示 P 和 F1 的基因型（蓝色），以及 F2 黄花的基因型“aa”。面板更新基因型推导逻辑。
- 步骤3（F1比例）：P代乘号上方出现红色“测交”。F1节点旁出现绿色概率“1/2”。面板更新 F1 比例计算逻辑。
- 步骤4（F2计算）：过程②左侧出现计算式，过程③右侧出现计算式。F2节点下方更新为带概率的完整基因型（如 1/8 AA, 1/4 Aa）。底部出现 F2 比例汇总公式。面板更新 F2 比例计算过程。
- 步骤5（对比结论）：F1白花基因型(Aa) 和 F2白花基因型(1/8 AA, 1/4 Aa) 底部出现红色高亮背景框。面板更新结论，强调两者基因型不完全相同（F2白花中含 1/3 AA, 2/3 Aa）。

[交互方案]
- 交互类型：分步按钮导航
- 控件说明：底部居中放置两个按钮「◀ 上一步」和「下一步 ▶」。
- 教师操作流程：教师点击“下一步”逐步展示推导过程，配合右侧面板的文字进行讲解。可随时点击“上一步”回退解答学生的疑问。

[技术实现]
- JS 库选择：原生 SVG + 原生 JS。SVG 适合绘制连线和精确定位文本，HTML 用于右侧面板的复杂文本排版。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  +-----------------------------------------+--------------------+
  |                                         |                    |
  |   P      黄花(aa) × 白花(Aa)            |  [推导面板]        |
  |                   | ①                   |                    |
  |          +--------+--------+            |  1. 显隐性判断...  |
  |          ↓                 ↓            |                    |
  |   F1 1/2黄花(aa)       1/2白花(Aa)      |  2. 基因型推导...  |
  |          | ②               | ③          |                    |
  |          |          +------+------+     |  3. F1比例计算...  |
  |          ↓          ↓             ↓     |                    |
  |   F2    黄花       黄花          白花   |  4. F2比例计算...  |
  |        1/2 aa     1/8 aa   1/8AA,1/4Aa  |                    |
  |                                         |  5. 结论对比...    |
  |      F2 比例：黄花(5/8) : 白花(3/8)     |                    |
  +-----------------------------------------+--------------------+
  [控件栏 y=450~490: ◀ 上一步 | 下一步 ▶]
  ```
- 关键实现要点：
  - 状态机：定义 `currentStep` 变量，范围 0-5。
  - 视图更新：编写 `updateView()` 函数，根据 `currentStep` 控制各 SVG 元素的 `opacity` 和 `stroke`/`fill` 颜色。
  - 文本排版：右侧面板使用 HTML `<div id="scene1-panel">`，通过 `innerHTML` 切换不同步骤的 HTML 内容，实现图文并茂的排版。
  - 动画过渡：为 SVG 元素添加 `style="transition: all 0.3s ease;"` 实现平滑的出现和颜色切换。
  - ID 命名规范：所有元素 ID 均以 `scene1-` 开头，如 `scene1-line3`, `scene1-f1-white`。
  - IIFE 隔离：整个脚本包裹在 `(function() { ... })()` 中。
