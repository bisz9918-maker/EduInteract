[图示主题与整合说明]
- 本图示主题：探究吸入气与呼出气成分的实验装置动态演示
- 整合的步骤/概念：装置结构认知、吸气时的气体流向与阀门状态、呼气时的气体流向与阀门状态、石灰水遇二氧化碳变浑浊的现象。
- 教学价值：教师可通过分步演示，清晰地向学生展示吸气和呼气时气流的真实路径，以及阀门在控制气流中的关键作用，最后通过直观的颜色变化对比得出实验结论。

[视觉元素清单]
- 试管轮廓：SVG path，黑色 stroke 2px，无填充。
- 液体：SVG path，试管1初始 `#e0f7fa` (透明度0.3)，试管2初始 `#e0f7fa` (透明度0.3)，变浑浊后为 `#cfd8dc` (透明度0.9)。
- 导管：双层 SVG path 模拟空心管。底层黑色 stroke 10px，顶层白色 stroke 6px。
- 橡胶塞：SVG polygon/rect，`#ffcc80` (透明度0.8)。
- 阀门（夹X/Y）：SVG line 组合（T型），stroke 4px。开启为 `#2e7d32`，关闭为 `#c62828`。
- 气流箭头：SVG line 带 marker-end，stroke 3px。吸气蓝色 `#1565c0`，呼气红色 `#c62828`。位于导管中心线上。
- 气泡：SVG circle，无填充，带 stroke。使用 CSS 动画实现上升效果。

[分步序列]
- 初始状态（步骤0）：显示完整装置。夹X和夹Y均为红色（关闭）。两试管液体均为浅青色（澄清）。隐藏所有箭头、气泡和结论标签。
- 步骤1（吸气过程）：点击「下一步」。夹X变为绿色（开启），夹Y保持红色。显示蓝色动态箭头（沿导管A进入，经导管B左侧和导管C排出）。试管1液体中出现蓝色上升气泡。液体保持澄清。
- 步骤2（呼气过程）：点击「下一步」。夹X变为红色（关闭），夹Y变为绿色（开启）。显示红色动态箭头（从导管C进入，经导管B右侧进入试管2，从导管D排出）。试管2液体中出现红色上升气泡。试管2液体平滑过渡为灰白色（浑浊）。
- 步骤3（对比结论）：点击「下一步」。夹X和夹Y均变为红色。隐藏所有箭头和气泡。试管1保持澄清，试管2保持浑浊。在试管下方分别淡入显示“澄清”和“浑浊”文本标签。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：底部居中放置控制栏（y=450区域），包含“上一步”按钮、步骤指示文本（如“1 / 3 : 吸气过程”）、“下一步”按钮。
- 教师操作流程：教师首先介绍装置结构（步骤0），然后点击下一步演示吸气气流（步骤1），接着演示呼气气流及浑浊现象（步骤2），最后展示对比结论（步骤3）以辅助解题。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS + CSS 动画。SVG 非常适合绘制精确的管道和几何图形，CSS 动画可轻松实现气流和气泡的动态效果，无需引入重型库。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
       M
    夹X | 夹Y
  ====+===+====
  |   |   |   |
 [1]  |  [2]  |
  |___|   |___|
  试管1   试管2
  [控件栏 ◀ 1/3 ▶]
  ```
- 关键实现要点：
  1. **空心管道绘制**：使用相同 path 叠加绘制，底层黑色 stroke-width: 10，顶层白色 stroke-width: 6，利用 SVG 叠加特性自动处理 T 型交叉口的连通效果。
  2. **层级控制 (z-index)**：按顺序渲染：液体 -> 气泡 -> 试管轮廓 -> 管道 -> 橡胶塞 -> 箭头 -> 阀门 -> 文本。橡胶塞使用半透明填充，覆盖在管道上，形成真实的穿透视觉效果。
  3. **动画实现**：箭头使用 CSS `@keyframes` 改变 `transform: translate` 和 `opacity` 实现流动感；气泡使用类似动画实现上升；液体浑浊使用 CSS `transition: fill` 实现平滑变色。
  4. **状态机**：JS 维护 `currentStep` 变量，每次切换时统一更新所有元素的 class 或属性，确保状态一致性。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-valveX`, `scene1-liquid2`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
