场景导航：Scene 1

题目：
如图所示的电路中，下列说法中正确的是（ ）
A 、电灯L$_{1}$、L$_{2}$是串联 B 、电流表测L$_{1}$的电流 C 、电流表测L$_{2}$的电流 D 、开关只控制L$_{2}$

题目分析：
这是一道典型的实物电路图分析题，主要考察学生对电路串并联状态的识别、电流表测量对象的判断以及开关控制作用的理解。解题的核心在于准确追踪电流的路径，识别出电路中的“分流点”和“汇流点”。

整体讲解思路：

  1. 采用“电流追踪法”，引导学生从电源正极出发，顺着电流方向逐步分析。
  2. 观察干路：确认开关 S 的位置，判断其控制范围。
  3. 寻找节点：在开关 S 之后找到电流的分流点，明确电路的并联结构。
  4. 追踪支路：分别追踪 L1 和 L2 的电流路径，观察电流表串联在哪条支路中，从而确定其测量对象。
  5. 抽象总结：将实物连线图转化为标准的等效电路图，帮助学生建立直观到抽象的认知连接，最终验证各个选项的对错。

图示规划说明：
设计一个包含分步导航的交互图示。在一个场景内，先展示实物电路，然后通过分步按钮依次高亮干路、L2支路、L1支路（包含电流表），最后在旁边淡入等效电路图进行对比。这种整合设计能让学生连贯地观察电流走向，避免视线频繁跳跃。

教学总结与选项判断：
通过上述图示的逐步推导，我们可以清晰地得出结论：

  1. 判断串并联：电流在开关 S 之后发生分流，分别经过 L1 和 L2，因此 L1 和 L2 是并联关系，选项 A 错误。
  2. 判断开关作用：开关 S 位于干路上（分流点之前），因此它控制整个电路，即同时控制 L1 和 L2，选项 D 错误。
  3. 判断电表测量对象：L2 支路的电流直接回到电源负极；而 L1 支路的电流必须经过电流表才能回到电源负极。电流表与 L1 串联，因此电流表测量的是通过 L1 的电流，选项 B 正确，选项 C 错误。

课堂讲解建议：

  • 强调“节点”的概念：让学生学会寻找多根导线交汇的接线柱，这是判断并联电路的关键。
  • 提醒学生注意电表的接线柱：本题中电流表的负接线柱同时连接了 L2 的导线和电源负极的导线，充当了“汇流点”的角色，这是易错点，需重点点拨。
