[图示主题与整合说明]
- 本图示主题：实物电路电流路径追踪与等效电路图转换
- 整合的步骤/概念：实物电路展示 -> 干路电流追踪 -> 标记分流点 -> L2支路追踪 -> L1支路追踪 -> 等效电路图对比
- 教学价值：帮助学生克服复杂实物连线的视觉干扰，通过“电流追踪法”一步步理清干路与支路的关系，最终自然过渡到抽象的标准电路图，强化对并联电路及电流表接入位置的理解。

[分步序列]
- 初始状态（步骤0）：仅显示左侧物理电路实物图，所有导线为黑色细线。右侧等效电路图隐藏（透明度0）。
- 步骤1（追踪干路）：物理导线1和导线6变为红色加粗，并出现沿路径移动的红色箭头。说明干路电流路径。
- 步骤2（标记分流点）：保持步骤1状态。在物理开关左接线柱(360,140)处出现闪烁的红色光圈，并淡入“分流点”文字标签。
- 步骤3（追踪L2支路）：保持前序状态。物理导线2和导线4变为绿色加粗，出现绿色移动箭头。在电流表负接线柱(75,250)出现闪烁光圈及“汇流点”标签。
- 步骤4（追踪L1支路）：保持前序状态。物理导线3和导线5变为蓝色加粗，出现蓝色移动箭头。直观展示电流表串联在L1支路中。
- 步骤5（等效电路图）：右侧标准电路图淡入。电路图中的干路(红)、L2支路(绿)、L1支路(蓝)同步高亮，并显示对应的移动箭头。完成实物到抽象的映射。

[交互方案]
- 交互类型：分步按钮导航。
- 控件说明：在 SVG 内部底部 (y=460) 居中放置两个按钮：“◀ 上一步” 和 “下一步 ▶”。
- 教师操作流程：教师在讲解时，点击“下一步”逐步引导学生追踪电流路径，从干路到各支路，最后展示等效电路图，帮助学生建立空间映射关系。

[技术实现]
- JS 库选择及原因：原生 SVG。SVG 的 `<path>` 配合 `<animateMotion>` 非常适合实现弯曲导线和电流箭头沿轨迹运动的动画，且无需引入外部庞大库。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  +---------------------------------------------------------+
  | [左侧 480px: 物理电路实物图]     [右侧 320px: 等效电路图] |
  |                                                         |
  |                                                         |
  |                                                         |
  |             [◀ 上一步]      [下一步 ▶]                  |
  +---------------------------------------------------------+
  ```
- 关键实现要点：
  - 物理元件使用 SVG 基础图形（rect, circle, line）组合绘制，保持简洁且具象。
  - 导线使用 `<path>` 绘制，设置 `id`。高亮效果通过 JS 切换 class 实现（改变 stroke 和 stroke-width，并添加 transition 过渡）。
  - 电流箭头使用 `<g>` 包含多边形，内部嵌套 `<animateMotion>` 绑定对应的导线 path ID。通过 JS 控制 `<animateMotion>` 的 `beginElement()` 或控制其 `display` 属性来启停动画。
  - 状态机设计：维护一个 `currentStep` 变量 (0-5)，按钮点击触发 `updateScene()` 函数，根据当前步骤统一设置所有元素的状态（高亮、透明度、动画显示），确保“上一步”和“下一步”都能正确恢复状态。
  - ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-wire-main1`, `scene1-btn-next`）。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
