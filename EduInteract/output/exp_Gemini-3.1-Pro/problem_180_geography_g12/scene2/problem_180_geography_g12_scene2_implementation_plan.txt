[图示主题与整合说明]
- 本图示主题：地方时与区时计算
- 整合的步骤/概念：西半球范围展示、中央经线确定、北京时间计算。
- 教学价值：教师可以通过分步展示经度数轴、半球范围、已知时间与所求时间的经度跨度，帮助学生直观理解“东加西减”的时间计算逻辑，将抽象的地球自转时间差转化为一维数轴上的距离与方向。

[视觉元素清单]
- 经度数轴及刻度：黑色 #000000，线宽2px。
- 经度标签：黑色 #000000，字号14px。
- 西半球范围：矩形色块，填充色 #1565c0，透明度 0.2。标签文字颜色 #1565c0。
- A点及已知条件：红色 #c62828。包含圆点、"A点"标签、"6:00"时间标签。
- 北京及所求条件：绿色 #2e7d32。包含圆点、"北京"标签、时间标签（? 或 20:00）。
- 跨度指示：红色 #c62828。包含水平箭头、垂直虚线、说明文本。
- 计算公式：黑色 #000000，字号20px，加粗。

[分步序列]
- 初始状态（步骤0）：仅显示经度数轴、刻度线及所有经度标签（180°至180°）。
- 步骤1（确定中央经线）：淡入显示西半球色块1和2，以及"西半球"标签；淡入显示A点标记及"A点"标签。
- 步骤2（标记已知与所求）：淡入显示A点时间"6:00"；淡入显示北京标记、"北京"标签及未知时间"?"。
- 步骤3（计算时间差）：绘制跨度辅助线1和2，从左向右生长跨度箭头，淡入跨度文本"经度差 210°，时间差 14小时"。
- 步骤4（得出结论）：淡入底部计算公式"北京时间 = 6:00 + 14小时 = 20:00"；同时将北京下方的"?"更新为"20:00"。

[标签冲突检查]
- 20°W (361,305) 与 0° (400,305)：间距39px。20°W使用text-anchor="end"向左延伸，0°使用text-anchor="start"向右延伸，完美避开。
- 160°E (711,305) 与 180° (750,305)：间距39px。160°E使用end向左，180°使用start向右，完美避开。
- A点标签 (215,270) 与 跨度辅助线1 (x=225)：标签在x=215向左延伸(end)，辅助线在x=225，两者相距10px，无重叠。
- 北京标签 (645,270) 与 跨度辅助线2 (x=633)：标签在x=645向右延伸(start)，辅助线在x=633，两者相距12px，无重叠。
- 经度标签 (y=305) 与 时间标签 (y=330)：y轴间距25px，文字高度约14-16px，上下有足够留白，无重叠。

[交互方案]
- 交互类型：分步按钮导航
- 控件说明：在SVG底部（y=450区域）居中放置两个按钮：「◀ 上一步」和「下一步 ▶」。
- 教师操作流程：教师首先展示全球经度展开图；点击下一步，引导学生观察西半球范围并定位A点；再次点击，标出已知时间和所求地点；第三次点击，展示经度跨度并引导学生计算时间差；最后点击，展示最终计算公式和结果。可随时回退。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript。SVG 非常适合绘制精确的数轴、几何图形和文本排版，且易于通过 CSS 控制动画和状态。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  (y=130)      [跨度箭头及文本]
  (y=200-280)  [西半球色块]
  (y=280)      [经度数轴]
  (y=305-330)  [经度及时间标签]
  (y=400)      [计算公式]
  (y=450-490)  [ ◀ 上一步 ] [ 下一步 ▶ ]
  ```
- 关键实现要点：
  - 使用 `data-step` 属性控制元素的显示与隐藏，配合 CSS `transition: opacity 0.5s` 实现平滑淡入淡出。
  - 跨度箭头的生长动画可以通过 CSS `stroke-dasharray` 和 `stroke-dashoffset` 实现，或者简单地使用 `clip-path` 配合 `transition`。
  - 步骤状态机：维护一个 `currentStep` 变量（0-4），点击按钮时更新变量并遍历所有带有 `data-show-step` 属性的元素，若 `currentStep >= data-show-step` 则设为可见，否则隐藏。
  - 北京时间文本的切换：在步骤4时，通过 JS 修改该文本元素的 `textContent`，从 "?" 变为 "20:00"。
  - ID 命名规范：所有元素 ID 必须以 `scene2-` 开头，例如 `scene2-axis`, `scene2-btn-next`。
  - IIFE 隔离：所有逻辑代码封装在 `(function() { ... })()` 中。
