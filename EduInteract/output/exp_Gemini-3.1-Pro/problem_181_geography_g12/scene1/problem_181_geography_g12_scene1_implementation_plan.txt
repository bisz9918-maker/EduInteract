[图示主题与整合说明]
- 本图示主题：北半球三圈环流与气压带、风带剖面图解析

[视觉元素清单]
- 地球剖面：黑色实线弧线，内侧带短斜线阴影。
- 字母标签：A, B, C, D, E, F, N（黑色，16px）。
- 环流圈箭头：黑色细实线带箭头，表示高空和近地面的气流方向。
- 纬度点：A、E处为红色圆点（上升气流），C、N处为蓝色圆点（下沉气流）。
- 气流成因动画/箭头：
  - N处：蓝色向下箭头（表示冷却下沉）。
  - E处：红色箭头（自南向北）与蓝色箭头（自北向南）在E处相遇并向上抬升。
- 风带高亮区：沿地表弧线的绿色半透明粗线（stroke-width: 12, opacity: 0.4）。
- 颜色规范：背景 #ffffff，主线 #000000，蓝高亮 #1565c0，红高亮 #c62828，绿高亮 #2e7d32，辅助线 #888888。

[分步序列]
- 初始状态（步骤0）：显示地球剖面弧线、阴影、字母A-F及N、三个环流圈的黑色箭头。
- 步骤1（纬度定位）：
  - N点出现蓝色圆点并闪烁，显示标签“90°N”。
  - 依次在A、C、E处出现红、蓝、红色圆点。
  - 显示标签“0°”、“30°N”、“60°N”。
- 步骤2（气压带与成因）：
  - 显示气压带名称：“赤道低气压带”(红)、“副热带高气压带”(蓝)、“副极地低气压带”(红)、“极地高气压带”(蓝)。
  - N处出现蓝色下沉箭头，显示“热力原因：冷却下沉”。
  - E处出现红蓝相遇抬升箭头，显示“动力原因：冷暖交汇抬升”。
- 步骤3（风带分布）：
  - 在B、D、F区域的地表弧线上叠加绿色半透明高亮粗线。
  - 显示风带名称：“东北信风带”、“盛行西风带”、“极地东风带”（绿色）。

[标签冲突检查]
- "赤道低气压带"(120,450) vs "0°"(260,470)：水平间距>100px，无冲突。
- "副热带高气压带"(160,260) vs "30°N"(300,290)：水平间距>100px，无冲突。
- "副极地低气压带"(300,100) vs "60°N"(440,160)：水平间距>100px，无冲突。
- "极地高气压带"(670,50) vs "90°N"(670,90)：垂直间距40px，无冲突。
- "东北信风带"(220,360) vs "副热带高气压带"(160,260)：垂直间距100px，无冲突。
- "盛行西风带"(320,200) vs "30°N"(300,290)：垂直间距90px，无冲突。
- "极地东风带"(500,80) vs "60°N"(440,160)：水平间距60px，垂直间距80px，无冲突。
- 结论：所有标签均分布在弧线外侧的广阔空白区域，方向分散，无任何重叠。

[交互方案]
- 交互类型：分步按钮导航。
- 控件说明：底部居中放置「◀ 上一步」和「下一步 ▶」按钮。
- 教师操作流程：
  1. 初始展示图甲原图，提问各字母代表的含义。
  2. 点击下一步，展示纬度定位，讲解极点与赤道的位置关系。
  3. 点击下一步，结合气流的上升/下沉，推导并展示气压带的分布及其成因（重点讲解热力与动力原因）。
  4. 点击下一步，根据气压带的高低压差，推导并展示近地面风带的分布。

[技术实现]
- JS 库选择：原生 SVG。由于全是几何路径、弧线和文本，SVG 是最精确且易于实现动画的选择。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  (左侧大片空白用于气压带/风带文字)    (右上角极点)
  (左下角赤道)                          (右下角圆心外)
  [控件栏 (300,460)-(500,490)]
  ```
- 关键实现要点：
  - 坐标系：SVG 默认坐标系。地球圆心设在 (650,450)，半径 350px。
  - 弧线计算：利用 SVG `path` 的 `A` (椭圆弧) 指令绘制地表弧线和环流圈。
  - 状态机：定义 `currentStep` (0~3)，每次点击按钮更新状态，通过修改 SVG 元素的 `opacity` 或 `display` 属性实现元素的显隐。
  - 动画：使用 CSS `transition: opacity 0.5s` 实现平滑过渡；N点闪烁使用 CSS `@keyframes`。
- ID 命名规范：所有元素 ID 以 `scene1-` 开头，如 `scene1-btn-next`, `scene1-label-equator`。
- IIFE 隔离：所有逻辑封装在 `(function() { ... })()` 中。
