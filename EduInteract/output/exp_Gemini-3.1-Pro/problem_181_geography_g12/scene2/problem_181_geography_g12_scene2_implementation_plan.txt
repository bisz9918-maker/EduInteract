[图示主题与整合说明]
- 本图示主题：北半球气压带风带俯视图及季节移动判断
- 整合的步骤/概念：半球判断（地转偏向力）、风带对应、季节判断（气压带移动）

[视觉元素清单]
- 极坐标网格：3个同心圆（r=180实线，r=120虚线，r=60虚线），2条正交直线。主线 #000000，虚线 #888888。
- 气压带粗圈：r=105，stroke-width=4，初始 #000000，步骤3高亮为 #1565c0。
- 风带箭头：使用 SVG path 绘制弧线，带 marker-end 箭头。初始 #000000，步骤1高亮为 #1565c0。
- 气压梯度力（PGF）箭头：灰色虚线 #888888，带箭头。
- 偏转指示弧线：红色 #c62828，带箭头。
- 风带高亮区：使用粗边框圆实现（stroke-width=60），颜色 #2e7d32，opacity=0.2。
- 动态平移圆环：黑色 rgba(0,0,0,0.4)，stroke-width=4，使用 CSS transition 实现半径 r 的动画。
- 文本标签：基础标签 #000000，结论文本按步骤分别使用 #c62828 和 #2e7d32。

[分步序列]
- 初始状态（步骤0）：显示极坐标网格、基础标签、黑色的风带箭头和气压带粗圈。隐藏所有推导过程和结论文本。
- 步骤1（半球判断）：点击「下一步」。风带箭头变为蓝色（#1565c0）高亮。在右下角（45°方向）出现气压梯度力灰色虚线箭头和红色偏转指示弧线。右侧弹出红色文本：“风向向右偏转 → 北半球”。
- 步骤2（风带对应）：点击「下一步」。保持步骤1状态。出现两个绿色半透明粗圆环覆盖 a 和 b 区域。右侧弹出绿色文本：“a: 东北信风带 (对应图甲B)”；左侧弹出绿色文本：“b: 盛行西风带 (对应图甲D)”。
- 步骤3（季节判断）：点击「下一步」。保持前序状态。气压带粗圈变为蓝色高亮。出现 30° 红色基准虚线圈（r=120）。一个半透明黑色圆环从 r=120 平滑缩小至 r=105。左上角弹出红色文本：“副热带高气压带位于30°N以北”及“气压带风带北移 → 北半球夏季”。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：在 SVG 底部 (y=450~490) 放置两个按钮，控制 step 变量 (0~3)。
- 教师操作流程：教师首先展示原图，提问半球归属；点击下一步，通过偏转动画讲解地转偏向力；再次点击，结合纬度讲解风带名称；最后点击，通过气压带的动态偏移演示季节判断逻辑。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。SVG 非常适合绘制极坐标系下的同心圆和弧线，且支持 CSS 属性动画（如 r 属性的过渡）。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800x450]
  左上：季节结论      右上：偏转结论
  左下：b风带结论     右下：a风带结论
        (极坐标图居中 400,230)
  [控件栏 800x50 (y=450-500)]
  ```
- 关键实现要点：
  1. **风带箭头生成**：使用 JS 循环生成 SVG path。a风带（4个）：起点 r=120，终点 r=170，角度增加20°，使用 `A 150 150 0 0 1` 绘制顺时针弧线。b风带（4个）：起点 r=120，终点 r=70，角度减少30°，使用 `A 150 150 0 0 0` 绘制逆时针弧线。
  2. **风带高亮区**：巧妙利用 SVG 的 `stroke-width`。a区域用 `r=150, stroke-width=60` 的圆表示；b区域用 `r=90, stroke-width=60` 的圆表示，避免复杂的 Arc 路径计算。
  3. **平移动画**：步骤3的动态圆环使用 `<circle id="scene2-anim-ring" style="transition: r 1s ease-in-out;">`。在 JS 状态机中，当 `step === 3` 时设置 `r = 105`，否则设置 `r = 120`（需使用 setTimeout 确保重绘触发动画）。
  4. **ID 命名规范**：所有元素 ID 必须以 `scene2-` 开头，如 `scene2-btn-next`，避免全局冲突。所有代码包裹在 IIFE 中。
