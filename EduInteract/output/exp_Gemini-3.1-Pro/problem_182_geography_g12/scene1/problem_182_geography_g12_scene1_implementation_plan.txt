[图示主题与整合说明]
- 本图示主题：经纬网空间定位与距离计算
- 整合的步骤/概念：正午太阳高度与直射点判断、方向判断、经线段距离计算、纬线段距离计算
- 教学价值：通过分步动态演示，帮助学生将抽象的经纬网文字描述转化为直观的几何图形，清晰展示方向判断的连线和距离计算的线段，并结合公式加深对经纬度距离换算的理解。

[分步序列]
- 初始状态（步骤0）：显示完整的经纬网底图、点A~E及其标签。解析文本框显示：“本题考查经纬网空间定位与距离计算。请点击「下一步」查看各小题解析。”
- 步骤1（问1）：显示赤道高亮虚线、B到A的红色箭头及“西北”标签。解析文本框显示：“(1) A(30°N)与B(30°S)正午太阳高度相同，直射点在赤道(0°)。从B到A方向为西北。”
- 步骤2（问2）：隐藏步骤1的高亮元素。显示B-C红色高亮线段及“跨纬度30°”标签。解析文本框显示：“(2) 飞机从B向北飞到C，沿经线飞行。跨纬度30°，距离 = 30 × 111km = 3330km。”
- 步骤3（问3）：隐藏步骤2的高亮元素。显示D-E蓝色高亮线段及“跨经度60°”标签。解析文本框显示：“(3) 飞机从D向东飞到E，沿60°N纬线飞行。距离 = 60 × 111km × cos60° = 3330km。飞行时间 = 3330 ÷ 1110 = 3小时。”

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：底部居中放置两个按钮，控制步骤0~3的切换。
- 教师操作流程：教师首先展示完整经纬网，让学生观察各点位置；然后依次点击“下一步”，配合图上出现的高亮线段和箭头，以及下方的计算公式，逐一讲解方向判断、经线距离计算和纬线距离计算。

[技术实现]
- JS 库选择：原生 SVG（适合绘制精确的经纬网格、线段和箭头） + 原生 JS（控制状态和 DOM 更新）。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
    (100,50) ----------------- (700,50)
       |                          |
       |       经纬网格区域       |
       |                          |
    (100,350) ---------------- (700,350)
    
    [解析文本框 600×70, y=370]
    
    [控件栏: 上一步 | 下一步, y=450]
  ```
- 关键实现要点：
  - 使用 SVG `<line>` 绘制网格，`<circle>` 绘制点，`<text>` 绘制标签。
  - 箭头使用 SVG `<marker>` 定义，附加到 `<line>` 上。
  - 状态机设计：定义 `currentStep` 变量（0~3），编写 `updateStep()` 函数。根据当前步骤，修改对应 SVG 元素的 `display` 属性（'none' 或 'block'），并更新 HTML 文本框的 `innerHTML`。
  - 解析文本框使用绝对定位的 `<div>` 覆盖在 SVG 容器上方，方便实现文本自动换行和样式控制。
  - ID 命名规范：所有元素 ID 必须以 `scene1-` 为前缀（如 `scene1-grid`, `scene1-step1-group`）。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
