场景导航：Scene 1 | Scene 2

读地球公转示意图，回答：
（1）图中四点所示节气为：A $\underline{\hspace{5em}}$ C $\underline{\hspace{5em}}$
（2）北半球昼最短、夜最长的时间是 $\underline{\hspace{5em}}$ ，南极圈内出现极夜时间 $\underline{\hspace{5em}}$ ，南回归线以南地区正午太阳高度最大的时间 $\underline{\hspace{5em}}$ （填代号）

题目分析与讲解思路：
这是一道经典的地球公转与节气判定题。解题的核心在于通过地轴的倾斜方向与太阳直射光线的关系，判断出各个位置对应的节气。

  1. 首先引导学生观察图中的地轴倾斜方向。在位置 A，北极（地轴上端）倾向太阳，说明太阳直射北半球（北回归线），因此 A 为夏至。
  2. 在位置 C，北极背向太阳，太阳直射南半球（南回归线），因此 C 为冬至。
  3. 结合地球逆时针公转的方向，可以顺推 B 为秋分，D 为春分。
  4. 针对第二问，需要将宏观的公转位置转化为微观的地球受光情况，分析昼夜长短、极昼极夜和正午太阳高度的变化规律。

图示规划说明：
我们将设计两个图示：

  • 图示1：还原题目原图的宏观公转轨道，通过分步动画引导学生观察地轴倾斜与直射点的关系，完成第一问的节气判定。
  • 图示2：放大展示地球在 A（夏至）和 C（冬至）位置的受光侧面剖视图，直观呈现晨昏线、昼夜长短比例及极昼极夜现象，帮助解答第二问。

教学说明：
在明确了 A 为夏至、C 为冬至后，我们需要进一步分析这两个特殊节气时，地球表面的光照情况。

  1. 北半球昼短夜长：引导学生观察冬至日（C点）的受光图，北半球在晨昏线背光一侧的面积大于向光一侧，即夜长昼短，且达到极值。
  2. 南极圈极夜：观察夏至日（A点）的受光图，南极圈及其以南地区完全处于背光侧，即出现极夜现象。
  3. 正午太阳高度：正午太阳高度由直射点向南北两侧递减。冬至日（C点）太阳直射南回归线，此时南回归线及其以南地区距离直射点最近（或就在直射点上），因此正午太阳高度达到一年中的最大值。

总结：
通过以上两个图示的配合，学生可以清晰地建立起“宏观公转位置 -> 地轴倾斜与直射点关系 -> 微观地表受光情况 -> 昼夜长短与太阳高度变化”的完整空间逻辑链条。

  • 第（1）问答案：夏至，冬至
  • 第（2）问答案：C，A，C
