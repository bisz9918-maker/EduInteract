[图示主题与整合说明]
- 本图示主题：地球公转轨道与二分二至日判定
- 整合的步骤/概念：原图复现、地轴倾斜特征观察、太阳直射点连线、节气推断
- 教学价值：教师可通过分步演示，引导学生观察地轴倾斜方向与太阳直射点的关系，从而科学推断出二分二至日，而非死记硬背。

[视觉元素清单]
- 太阳：中心圆 r=15，填充 #f57f17，外围8条光芒线。
- 公转轨道：椭圆，描边 #000000，无填充。
- 地球（A/B/C/D）：圆 r=40，白底，描边 #000000（高亮时变为 #1565c0，加粗）。
- 地轴：线段，相对于地球中心从 (-22, 50) 到 (22, -50)，描边 #000000。
- 赤道：线段，相对于地球中心从 (-36.7, -16) 到 (36.7, 16)，描边 #000000。
- 北回归线（仅A显示）：虚线，相对于地球A中心从 (-27.2, -29.3) 到 (40, 0)，描边 #f57f17。
- 南回归线（仅C显示）：虚线，相对于地球C中心从 (-40, 0) 到 (27.2, 29.3)，描边 #f57f17。
- 直射光线：粗虚线 #f57f17，从太阳中心到地球表面。
- 公转箭头：逆时针方向，位于轨道上。
- 标签：初始为 A/B/C/D，后续变为带背景色的节气标签（背景 #fff9c4，边框 #f57f17，文字 #000000）。

[分步序列]
- 初始状态（步骤0）：显示太阳、公转轨道、四个地球（含地轴、赤道）、太阳到各地球的灰色细虚线连线。显示基础标签 A、B、C、D。
- 步骤1（观察直射点）：高亮太阳发出的水平光线，变为橙色粗虚线（#f57f17），连接太阳与 A、C 的中心。
- 步骤2（判定A点）：地球 A 轮廓高亮（#1565c0，加粗），在地球 A 上绘制北回归线（橙色虚线），展示水平光线正好直射北回归线。标签 A 变为“A: 夏至”（带黄色背景）。
- 步骤3（判定C点）：地球 C 轮廓高亮，在地球 C 上绘制南回归线（橙色虚线），展示水平光线正好直射南回归线。标签 C 变为“C: 冬至”（带黄色背景）。
- 步骤4（完整周期）：在公转轨道上添加逆时针方向的箭头。标签 D 变为“D: 春分”，标签 B 变为“B: 秋分”（带黄色背景）。

[标签冲突检查]
- 标签A (70, 220) 与 地球A (140, 220)：间距 70px，地球半径 40px，边缘间距 30px，无冲突。
- 标签C (730, 220) 与 地球C (660, 220)：间距 70px，边缘间距 30px，无冲突。
- 标签D (330, 80) 与 地球D (400, 90)：dx=70, dy=10，边缘间距 > 20px，无冲突。
- 标签B (470, 360) 与 地球B (400, 350)：dx=70, dy=10，边缘间距 > 20px，无冲突。
- 结论：所有标签均分布在图形外侧，无重叠冲突。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：底部居中放置两个按钮，控制步骤 0 到 4 的切换。
- 教师操作流程：教师点击“下一步”，依次引导学生观察水平光线、A点直射北半球（夏至）、C点直射南半球（冬至），最后根据逆时针公转得出春分和秋分。

[技术实现]
- JS 库选择及原因：原生 SVG。图形均为标准几何图形（圆、椭圆、线段），SVG 易于实现精确坐标控制和 DOM 元素的状态切换（显示/隐藏/改色）。
- 画布尺寸：800 × 500 px。
- 布局草图：

  A(夏至)  ☼  C(冬至)
       B(秋分)
  [控件栏 800x60]
    ◀上一步  下一步▶
- 关键实现要点：
  - 使用 `<g>` 标签对每个地球及其附属元素（地轴、赤道、回归线）进行分组，通过 `transform="translate(x, y)"` 定位，便于复用内部相对坐标。
  - 地轴和赤道的相对坐标通过三角函数预先计算好，直接写入 SVG 属性。
  - 状态机设计：定义 `currentStep` (0-4)，每次步骤变化时，调用 `updateState()` 函数，根据当前步骤控制各元素的 `display`、`stroke`、`text` 等属性。
  - ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-earth-a`, `scene1-label-a`）。
  - IIFE 隔离：所有 JS 代码封装在 `(function(){ ... })()` 中。
