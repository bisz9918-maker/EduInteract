[图示主题与整合说明]
- 本图示主题：夏至与冬至的地球光照与昼夜长短剖析
- 整合的步骤/概念：晨昏线划分、昼夜半球对比、极昼极夜现象、直射点与太阳高度
- 教学价值：教师可通过切换夏至和冬至两个关键状态，直观对比太阳直射点的移动、晨昏线的变化以及由此产生的昼夜长短和极昼极夜现象，帮助学生理解地球公转的地理意义。

[分步序列]
- 初始状态（状态1 - 位置A 夏至）：
  - 显示从左侧射入的太阳光线。
  - 显示直射点在 (250,250) 即北回归线，标签“直射点”在 (190,245)。
  - 夜半球遮罩覆盖右半圆 (x > 400)。
  - 北极圈高亮区域文字显示为“极昼”，南极圈高亮区域文字显示为“极夜”。
  - 隐藏冬至相关的光线和直射点。
- 状态2（位置C 冬至）：
  - 教师点击“位置C (冬至)”按钮触发。
  - 显示从右侧射入的太阳光线。
  - 显示直射点在 (550,250) 即南回归线，标签“直射点”在 (565,265)。
  - 夜半球遮罩覆盖左半圆 (x < 400)。
  - 北极圈高亮区域文字显示为“极夜”，南极圈高亮区域文字显示为“极昼”。
  - 隐藏夏至相关的光线和直射点。

[交互方案]
- 交互类型：多状态切换（2个按钮）。
- 控件说明：在 SVG 底部 (y=460) 居中放置两个按钮：“位置A (夏至)” 和 “位置C (冬至)”。
- 教师操作流程：默认展示夏至状态，教师讲解北半球昼长夜短及极昼现象；随后点击“位置C (冬至)”按钮，画面平滑切换（或直接切换）至冬至状态，教师对比讲解直射点南移、晨昏线翻转及南半球的极昼现象。

[技术实现]
- JS 库选择及原因：原生 SVG。地球几何图形、光线、遮罩等均可通过 SVG 基础形状和路径轻松实现，且易于通过 JS 修改属性实现状态切换。
- 画布尺寸：800 × 500 px。
- 布局草图：
  [图示区 800×500]
    (左侧光线)    (倾斜地球与晨昏线)    (右侧光线)
    (左侧直射点)  (夜半球遮罩动态切换)  (右侧纬线标签)
  [控件栏 y=460: 按钮"位置A(夏至)" | 按钮"位置C(冬至)"]
- 关键实现要点：
  - 使用 `<path>` 绘制夜半球遮罩，通过修改 `d` 属性中的 `sweep-flag` 或终点坐标实现左右半圆的切换。
  - 极区高亮使用固定的 `<path>`，仅在切换状态时修改其内部 `<text>` 的内容（极昼/极夜）。
  - 将夏至和冬至特有的元素（光线、直射点、直射点标签）分别编组 `<g id="scene2-summer-elements">` 和 `<g id="scene2-winter-elements">`，通过控制 `display` 或 `opacity` 属性实现切换。
- ID 命名规范：所有交互元素 ID 必须以 `scene2-` 为前缀（如 `scene2-btn-summer`，`scene2-night-mask`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
