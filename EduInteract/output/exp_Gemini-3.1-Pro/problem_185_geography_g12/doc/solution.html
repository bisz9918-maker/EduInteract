题目：
图中A、B两点分别是晨线、昏线与30°N纬线圈的交点， 读图完成下列要求。
(1)如果该天晨昏线与70°纬线圈相切，那么该天太阳直射点的地理坐标为 $\underline{\hspace{5em}}$ 。
(2)A点该日地方时 $\underline{\hspace{5em}}$ 时日出。
(3)从A点飞行到达B点，如需距离最短，飞行的方向应为 $\underline{\hspace{5em}}$ 。
(4)假如该天太阳直射点正在向南运动，下列说法可信的是( )
A. 好望角附近海域风高浪急 B. 地球公转到远日点附近
C.澳大利亚的农民正忙于小麦播种 D. 我国北方地区沙尘天气频发
E. 大、小兴安岭防火任务形势严峻 F. 20°S纬线圈上的正午太阳高度大约为46．5°

题目分析：
本题考查地球运动的综合应用。首先需要通过极地俯视图解读出经度信息和昼夜长短。根据“北极上空逆时针自转”和图中经度夹角，推断A、B经度。再结合晨昏线相切条件推断直射点纬度。最后结合季节判断地理现象。

整体讲解思路：

  1. 破解极地俯视图：推导A、B经度，计算昼夜长短，得出直射点经度和日出时间。
  2. 侧视图转换：利用晨昏线相切条件，推导直射点纬度。
  3. 球面最短距离：展示大圆航线的空间特征。
  4. 季节与地理现象：通过直射点移动轨迹确定时间，分析各选项的地理现象。

讲解要点：

  1. 引导学生观察已知经线：上方45°E，右侧45°W，顺着地球自转方向（逆时针）经度减小，说明是西经，因此中心为北极点。
  2. 推导A、B经度：左侧水平线为135°E，下方垂直线为135°W。A点在135°E以西15°，为120°E；B点在45°W以东15°，为30°W。
  3. 昼夜弧与时间：A为晨线交点，B为昏线交点。沿自转方向从A到B为昼弧（210°），从B到A为夜弧（150°）。昼弧中点（135°W）为正午12:00，即直射点经度；夜弧中点（45°E）为子夜0:00。
  4. 日出时间：夜长 = 150° ÷ 15°/h = 10小时。日出时间 = 0:00 + (10/2) = 5:00。

讲解要点：

  1. 晨昏线与纬线圈相切的几何意义：相切纬线的纬度与直射点纬度互余。
  2. 结合第一问得出的“昼长夜短”（昼弧210°），可知北半球处于夏半年，直射点在北半球。
  3. 晨昏线与70°N相切，说明70°N及其以北出现极昼。直射点纬度 = 90° - 70° = 20°N。
  4. 综合第一步得出的直射点经度135°W，得出最终坐标：(20°N, 135°W)。

讲解要点：

  1. 球面两点间的最短距离是过这两点的大圆劣弧。
  2. A点(120°E)和B点(30°W)同在30°N，经度差为150°（小于180°，向东跨越）。
  3. 在北半球，大圆航线会向北极方向凸出。
  4. 飞行方向分析：整体向东飞行，由于向北凸出，前半程向东北，后半程向东南。

讲解要点：

  1. 直射点在20°N且向南移动，说明时间在夏至（6月22日，23.5°N）之后，秋分之前。具体时间约为7月下旬。
  2. 远日点在7月初，此时已过远日点，排除B选项。
  3. 7月下旬，南半球处于冬季。气压带风带北移，南半球的西风带北移控制好望角地区，导致该海域风高浪急，A选项正确。
  4. 其他选项排除：澳大利亚秋季（3-5月）播种小麦；我国北方春季沙尘频发；兴安岭春夏之交或秋季防火严峻；20°S正午太阳高度应为50°。

总结：
本题综合性极强，要求学生具备扎实的空间想象能力和逻辑推理能力。
课堂讲解建议：重点放在极地俯视图的经度推导上，这是后续所有问题的基础。很多学生容易在顺逆时针和东西经的判断上出错。强调大圆航线的通用规律：同在北半球，向北凸；同在南半球，向南凸。季节判断要精确，不仅要知道是夏季，还要能根据20°N向南移动准确估算出7月下旬，从而准确判断远日点和好望角的气候特征。
