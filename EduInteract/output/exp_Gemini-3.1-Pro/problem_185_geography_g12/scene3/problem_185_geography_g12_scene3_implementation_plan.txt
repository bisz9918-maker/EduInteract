[图示主题与整合说明]
- 本图示主题：同纬度两点间的最短航线（大圆劣弧）及其方向变化
- 整合的步骤/概念：将30°N纬线圈路径与大圆路径在3D地球上进行直观对比，展示大圆航线向高纬度（北极）凸出的空间特征，并动态演示飞行方向的连续变化。
- 教学价值：帮助学生克服“同纬度两点间沿纬线飞行最短”的直觉错误，建立大圆航线的空间概念，并掌握飞行方向的判断方法。

[视觉元素清单]
- 3D地球：使用 D3.js `geoOrthographic` 投影，包含浅灰色经纬网（`#e0e0e0`），黑色外边框（`#000000`）。
- A点、B点：黑色实心圆点（`#000000`），带文本标签。
- 30°N纬线圈航线：灰色虚线（`#888888`，`stroke-dasharray="4,4"`），表示易错路径。
- 大圆航线：红色实线（`#c62828`，`stroke-width="3"`），强调最短航线。
- 飞机图标：蓝色（`#1565c0`），使用 SVG Path 绘制。
- 方向箭头：红色（`#c62828`），带文本标签。
*注：大纲中方向描述为“东北/东南”，但根据题意从A(120°E)飞向B(30°W)实际为向西飞行，大圆航线方向应为先西北后西南。本设计已修正为“西北/西南”以保证科学准确性。*

[分步序列]
- 初始状态（步骤0）：展示3D地球、经纬网，以及A点和B点及其标签。
- 步骤1：点击「下一步」→ 绘制30°N纬线路径（灰色虚线），并显示“30°N纬线”标签，展示常规的非最短路径。
- 步骤2：点击「下一步」→ 绘制大圆航线（红色实线），并显示“大圆航线”标签，突出其向北极凸出的特征。
- 步骤3：点击「下一步」→ 飞机图标出现在A点，沿大圆航线向B点移动。当飞机到达最高点前（约1/4处），出现指向西北的箭头及“西北”标签；当飞机越过最高点后（约3/4处），出现指向西南的箭头及“西南”标签。

[标签冲突检查]
- A点标签 "A(120°E, 30°N)"：坐标约(560, 205)，位于地球右侧外部，无冲突。
- B点标签 "B(30°W, 30°N)"：坐标约(240, 205)，位于地球左侧外部，无冲突。
- "30°N纬线"：坐标约(400, 295)，位于纬线弧线下方，无冲突。
- "大圆航线"：坐标约(400, 160)，位于大圆弧线上方，无冲突。
- "西北"：坐标约(485, 175)，位于大圆航线右半段上方，与"大圆航线"标签间距 > 80px，无冲突。
- "西南"：坐标约(315, 175)，位于大圆航线左半段上方，与"大圆航线"标签间距 > 80px，无冲突。
所有文本标签均添加白色文字阴影（text-shadow）以防止与经纬网线条重叠导致难以阅读。

[交互方案]
- 交互类型：分步按钮导航
- 控件说明：底部控件栏包含「◀ 上一步」和「下一步 ▶」按钮。
- 教师操作流程：教师首先展示A、B两点位置；点击下一步，展示学生容易误解的纬线路径；再次点击，展示正确的大圆航线，引导学生观察其向高纬度凸出的特点；最后点击下一步，播放飞行方向动画，配合讲解方向的连续变化（先西北，后西南）。

[技术实现]
- JS 库选择及原因：选择 D3.js (v7)。D3 提供了强大的地理投影（`d3.geoOrthographic`）、经纬网生成（`d3.geoGraticule`）和路径生成（`d3.geoPath`）功能，非常适合处理 3D 地球和球面最短路径（大圆航线）的精确计算与渲染。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
       (北极)
      /  大圆  \
    A -- 纬线 -- B
       (南极)
  [控件栏 ◀ 上一步 | 下一步 ▶]
  ```
- 关键实现要点：
  1. **投影设置**：`d3.geoOrthographic().scale(180).translate([400, 240]).rotate([-45, -45, 0])`，将视角中心定在 (45°E, 45°N)，使A、B两点及北半球的大圆航线完美展示在正面。
  2. **路径生成**：大圆航线直接使用 `d3.geoPath` 渲染 GeoJSON 的 `LineString`（包含A、B两点坐标）；纬线路径则通过生成一系列同纬度点（如每隔2度采样）的 `LineString` 来绘制。
  3. **动画实现**：使用 `d3.transition().attrTween`，通过 `path.node().getPointAtLength(t * length)` 获取飞机在屏幕上的精确坐标，并通过计算相邻两点的差值 `Math.atan2(dy, dx)` 实时更新飞机的旋转角度。
  4. **ID 命名规范**：所有 DOM 元素 ID 均以 `scene3-` 开头（如 `scene3-earth`, `scene3-btn-next`）。
  5. **IIFE 隔离**：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
