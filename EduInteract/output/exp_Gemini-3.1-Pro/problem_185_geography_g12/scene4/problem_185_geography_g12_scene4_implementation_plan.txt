[技术实现]
- JS 库选择及原因：原生 SVG。图形均为基础几何线段、曲线和多边形，SVG 易于实现精确坐标控制和 CSS 动画。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [左侧：直射点曲线 400×400] [右侧：好望角地图 300×400]
  [       控件栏：上一步 / 下一步 (y=450~490)       ]
  ```
- 关键实现要点：
  - 直射点曲线使用 JS 动态生成 `path` 的 `d` 属性：`let d = 'M 60 250 '; for(let x=65; x<=440; x+=5) { let y = 250 - 150 * Math.sin((x-60)/190*Math.PI); d += 'L ' + x + ' ' + y + ' '; }`，确保曲线精确穿过关键点。
  - 非洲海岸线使用 `<polyline>`，点集为 `520,100 540,180 560,250 580,280 620,260 660,200 680,100`。
  - 箭头使用 SVG `<defs>` 中的 `<marker>` 实现，方便复用。
  - 状态机：定义 `currentStep` (0~3)，每次点击按钮更新变量，并通过修改对应 SVG 元素的 `opacity` (配合 `transition: opacity 0.5s`) 实现平滑显隐。
  - ID 命名规范：所有元素 ID 必须以 `scene4-` 开头，如 `scene4-point-current`。
  - IIFE 隔离：所有 JS 代码包裹在 `(function() { ... })()` 中。
