[图示主题与整合说明]
- 本图示主题：四季形成原理的空间演示与逻辑推导联动
- 整合的步骤/概念：将地球公转的几何空间模型（黄赤交角、直射点移动、太阳高度与昼夜变化）与严密的因果逻辑流程图完美结合。
- 教学价值：教师可以通过分步导航，左侧演示空间几何变化，右侧同步推导逻辑结论，帮助学生建立从“空间想象”到“逻辑推理”的完整认知闭环。

[视觉元素清单]
- 空间几何元素：地球轮廓（黑边白底）、夜半球（#000000 30%）、黄道平面（#c62828）、赤道平面（#1565c0）、辅助线（#888888 虚线）。
- 旋转组（`earth-features`）：包含地轴、赤道、回归线、观测点P及其纬线。通过改变该组的 `transform="rotate(angle, 220, 225)"` 来模拟太阳直射点的回归运动。
- 流程图元素：黑色边框矩形（#000000），内部文字默认黑色，填空部分文字使用 #c62828 加粗显示。高亮状态下框体背景变为浅红色（#ffcdd2）。

[分步序列]
- 初始状态（步骤0）：左侧显示基础地球（无倾角，直射赤道），右侧流程图显示所有框体，但括号内为空白 `(    )`。
- 步骤1（自转与公转平面）：左侧地轴倾斜（-23.5°），显现蓝色赤道平面和红色黄道平面；右侧填入“赤道”和“黄道”。
- 步骤2（黄赤交角）：左侧在中心处绘制 23°26' 的夹角弧线和标注；右侧填入“黄赤”。
- 步骤3（直射点回归）：左侧显现南北回归线和直射点红点，启动 JS 动画循环，地轴倾角在 -23.5° 到 23.5° 之间往复摆动（模拟直射点在回归线间移动）；右侧“直射点回归”框高亮。
- 步骤4（两个变化）：左侧显现 40°N 观测点 P 及纬线，左上角出现动态数据面板，实时显示 P 点的“正午太阳高度角”和“昼夜长短”状态（随动画实时更新）；右侧填入“正午太阳高度”和“昼夜长短”。
- 步骤5（受热与四季）：左侧 P 点增加一个颜色光晕，随直射点靠近变红（受热多），远离变蓝（受热少）；右侧填入“气温”，并高亮“四季交替”。

[标签冲突检查]
- “赤道平面”标签：挂载在赤道线右端（旋转组内），随赤道旋转，坐标约 (345, 225)。
- “黄道平面”标签：固定在黄道线右端上方，坐标 (380, 210)。
- 冲突检查：当赤道旋转 -23.5° 时，“赤道平面”标签移动至约 (335, 175)，与“黄道平面” (380, 210) 垂直间距 > 30px，无冲突。
- “黄赤交角”标签：固定在 (270, 210)，远离赤道和黄道末端，无冲突。
- 动态数据面板：放置在左上角 (20, 20) 空白区域，不与地球模型重叠。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：底部居中放置两个按钮，控制步骤 0~5 的切换。
- 教师操作流程：教师点击“下一步”，左侧空间模型发生几何变化或动画，右侧流程图同步填补对应的逻辑节点，教师可借此引导学生观察空间变化并推导逻辑结论。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript。
- 画布尺寸：800 × 500 px。
- 动画实现要点（核心）：
  - 步骤 3 开始，启动 `requestAnimationFrame` 循环，维护一个变量 `delta`（太阳直射点纬度，范围 -23.5 到 23.5）。
  - 旋转组 `earth-features` 的 `transform` 属性实时更新为 `rotate(${-delta}, 220, 225)`。
  - 步骤 4 中，动态计算 P 点的正午太阳高度角 $H = 90^\circ - |40^\circ - \delta|$，并更新左上角文本。
  - 步骤 4 中，根据 `delta` 的正负，动态更新昼夜长短文本（`delta > 0` 为昼长夜短，`delta < 0` 为昼短夜长）。
  - 步骤 5 中，根据 `delta` 映射 P 点光晕的颜色（如 `hsl(${240 - (delta + 23.5)/47 * 240}, 100%, 50%)` 实现蓝到红的渐变）。
- ID 命名规范：所有 DOM 元素 ID 必须以 `scene1-` 开头（如 `scene1-earth-group`, `scene1-flow-box1`）。
- 隔离性：所有 JS 代码封装在 `(function() { ... })()` 中。
