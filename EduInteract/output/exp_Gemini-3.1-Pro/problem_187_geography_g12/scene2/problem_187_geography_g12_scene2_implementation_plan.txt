[图示主题与整合说明]
- 本图示主题：四地经纬度计算与空间定位及地球运动地理意义比较
- 整合的步骤/概念：通过太阳能热水器倾角与世界时，分布计算四地的经度和纬度，在平面经纬网上进行空间定位，并进一步比较正午太阳高度和昼长。
- 教学价值：教师可通过分步演示，清晰地展示“时间差→经度”、“倾角→纬度”的数理逻辑，并将抽象的数据转化为直观的空间位置，最后结合纬度位置推导太阳高度和昼长的分布规律，帮助学生建立完整的空间思维和逻辑链条。

[分步序列]
- 初始状态（步骤0）：显示基础经纬网底图（含赤道和0°经线标度）。右侧面板显示【经度计算】逻辑，图中依次绘制出4条蓝色经线及底部经度标签。
- 步骤1：点击「下一步」。右侧面板更新为【纬度计算】逻辑。图中绘制出4条红色纬线及左侧纬度标签，并在经纬线交点处闪烁出现4个绿色圆点①②③④及点名标签。
- 步骤2：点击「下一步」。右侧面板更新为【正午太阳高度比较】逻辑。图中在4个点右下方出现对应的正午太阳高度H值标签（如 H=83°26'），点按高度从大到小依次轻微放大高亮。
- 步骤3：点击「下一步」。右侧面板更新为【昼长比较】逻辑。隐藏H值标签，在图左侧（X=40）出现向上的橙黄色箭头，标注“昼长逐渐增加”，4个点按纬度从高到低依次高亮。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：底部居中放置两个按钮，控制步骤0~3的切换。
- 教师操作流程：教师首先引导学生根据时间差计算经度（步骤0），接着根据倾角计算纬度并完成空间定位（步骤1），然后基于倾角推导太阳高度（步骤2），最后结合纬度位置复习夏至日昼长分布规律（步骤3）。

[技术实现]
- JS 库选择：原生 SVG（用于绘制经纬网、线段、点和箭头） + 原生 HTML/CSS（用于右侧文本面板和底部按钮）。无需引入外部库，保证加载速度和稳定性。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  +-------------------+-----------------+
  |                   |                 |
  |   [经纬网绘制区]  |  [右侧解说面板] |
  |   (100,80)至      |  (520,80)至     |
  |   (460,380)       |  (760,400)      |
  |                   |                 |
  +-------------------+-----------------+
  |       [ ◀上一步 ] [ 下一步▶ ]       |
  +-------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：定义 `currentStep` 变量（0~3），编写 `updateScene(step)` 函数，根据步骤控制 SVG 元素的 `display` 或 `opacity` 属性，并更新右侧 HTML 面板的 `innerHTML`。
  2. 坐标计算：建立经纬度到像素坐标的映射函数 `lonToX(lon)` 和 `latToY(lat)`，确保点和线的位置精确对应。
  3. 动画过渡：为 SVG 元素添加 CSS `transition: opacity 0.5s ease` 实现平滑的出现/消失效果。
- ID 命名规范：所有交互元素 ID 必须以 `scene2-` 为前缀（如 `scene2-btn-next`, `scene2-point-1`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
