读太阳直射点移动轨迹图（太阳直射点移动方向为：F→E→D→C→B→A），分析回答下列问题。
(1)当太阳直射点位于A点时，北半球节气是，地球上出现极夜的范围是__。
(2)当太阳直射点位于C、D点时，全球正午太阳高度角随纬度变化的规律是_。
(3)本次考试期间，太阳直射点位于图中点和点（填字母）之间。
(4)当地球位于公转轨道远日点附近时，太阳直射点处于图中点和点（填字母）之间。
(5) 图中B点的经度是；当太阳直射点是图中点时（填字母），东半球刚好全部处于黑夜之中，此时北京时间为3月22日时分。

【题目分析与整体讲解思路】
本题以太阳直射点在东西半球的移动轨迹为载体，综合考查了地球运动的地理意义，包括节气判断、极夜范围、正午太阳高度变化规律、公转轨道特征（远日点）以及晨昏线判读和地方时计算。
讲解时可分为两个主要部分：

  1. 直射点回归运动与季节变化（对应第1-4题）：首先引导学生明确图中左右两圆分别代表东半球和西半球，推导出关键经线的度数（如东半球中央经线为70°E，西半球为110°W）。然后梳理直射点F→E→D→C→B→A的移动路径，将其与二十四节气对应。在此基础上，逐一分析直射点在特定位置时引发的极夜范围、正午太阳高度分布及远日点位置。
  2. 晨昏线与地方时计算（对应第5题）：这是一个典型的时空转换问题。需要引导学生将“东半球刚好全部处于黑夜”这一文字条件转化为空间图像，即晨昏线与20°W和160°E重合，从而确定直射点位置并进行时间推算。

【教学要点与讲解步骤】
本图示用于讲解第1至第4题，重点在于经纬网的判读和直射点移动规律的应用。

  1. 半球与经纬度判读：引导学生观察左右两圆。左图为东半球（20°W向东至160°E），其正中央的经线B点经度为 (160°E - 20°W)/2 = 70°E。右图为西半球（160°E向东至20°W），其正中央的经线E点经度为 110°W。
  2. 直射点轨迹与节气（第1题）：观察轨迹方向：F(西半球南回归线) → E(赤道) → D(西半球北回归线) → C(东半球北回归线) → B(赤道) → A(东半球南回归线)。对应节气：F、A为冬至；E为春分；D、C为夏至；B为秋分。当直射点位于A点（冬至）时，北半球节气为冬至，此时北极圈及其以北地区出现极夜（即北极圈及其以北地区）。
  3. 正午太阳高度规律（第2题）：当直射点位于C、D点（夏至，直射北回归线）时，全球正午太阳高度角随纬度变化的规律是：由北回归线向南北两侧递减。
  4. 考试期间的位置（第3题）：教师可根据实际考试日期，在轨迹上指出大致位置。例如，若考试在11月，则直射点位于秋分（B）与冬至（A）之间。
  5. 远日点位置（第4题）：地球位于公转轨道远日点附近时为7月初。7月初位于夏至（6月22日，C/D点）和秋分（9月23日，B点）之间，因此直射点处于图中 C 点和 B 点之间。

【教学要点与讲解步骤】
本图示专门用于讲解第5题，难点在于通过“东半球全黑”推断直射点经度，并进行跨日期的计算。

  1. 确定直射点位置：题目条件“东半球刚好全部处于黑夜之中”。东半球范围是 20°W~160°E。这意味着晨昏线恰好与经线圈（20°W和160°E）重合，说明此时太阳直射赤道（二分日）。
  2. 推断直射经度：既然东半球是黑夜，那么西半球（160°E~20°W）就是白昼。白昼半球的中央经线就是太阳直射的经线。西半球的中央经线是 110°W。因此，太阳直射点位于赤道与 110°W 的交点。结合图示，该点正是 E 点。
  3. 地方时与区时计算：直射点 E（110°W）的地方时为正午 12:00。题目要求计算此时的北京时间（120°E 的地方时）。
  4. 计算经度差与时间差：110°W 与 120°E 之间相差 110° + 120° = 230°。计算时间差：230° ÷ 15°/小时 = 15小时20分钟。
  5. 得出最终时间：由于 120°E 在 110°W 的东侧，时间应加上时间差：12:00 + 15小时20分钟 = 27:20。满24小时进一天，即次日的 03:20。结合直射点 E 为春分（3月21日），次日即为 3月22日 3时 20分。

【总结】
本题完整解答如下：
(1) 冬至；北极圈及其以北地区
(2) 由北回归线向南北两侧递减
(3) 视具体考试日期而定（如11月考则填 B 和 A）
(4) C；B
(5) 70°E；E；3；20
