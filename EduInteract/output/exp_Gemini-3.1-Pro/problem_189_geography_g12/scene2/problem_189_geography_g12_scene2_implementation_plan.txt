[分步序列]
- 初始状态（步骤0）：显示东西半球双圆、经纬网、轨迹线、A-F点。底部显示标签 "东半球" 和 "西半球"。时间轴及遮罩隐藏。
- 步骤1（东半球全黑）：点击「下一步」→ 东半球上方出现黑色半透明遮罩。顶部(260, 20)出现文本 "晨昏线与经线圈重合 (二分日)"。"东半球" 标签更新为 "东半球(黑夜)"。
- 步骤2（确定直射点）：点击「下一步」→ E点变红，出现太阳图标。顶部(520, 20)出现文本 "直射点 E (110°W, 0°)"。"西半球" 标签更新为 "西半球(白昼)"。
- 步骤3（时间推算）：点击「下一步」→ 底部时间轴展开。依次出现 110°W、0°、120°E 的刻度及基础标签。接着出现蓝色计算箭头和文本 "经度差 230°，时间差 15小时20分钟"。最后在 120°E 下方出现蓝色高亮结果 "12:00 + 15h20m = 次日 03:20"。

- 控件说明：在 SVG 内部底部居中 (y=470 区域) 放置两个按钮。

[技术实现]
- JS 库选择及原因：原生 SVG。图形主要由圆、椭圆、线段和路径组成，SVG 能够提供最精确的坐标控制和高质量的矢量渲染，且易于通过 CSS 控制透明度和过渡动画。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```text
  [图示区 800×460]
    (顶部文本区 y=10~40)
    (双半球区 y=40~300)
    (时间轴区 y=320~460)
  [控件栏 800×40] (y=460~500)
  ```
- 关键实现要点：
  - 经纬网绘制：使用 `<clipPath>` 限制在圆形半球内，纬线使用 `<line>`，经线使用 `<ellipse>` (rx=43, rx=86) 模拟正射投影效果。
  - 状态机设计：定义 `currentStep` 变量 (0-3)，每次点击按钮更新状态，通过修改对应 SVG 元素的 `opacity` 属性实现显隐，配合 `transition: opacity 0.5s` 实现平滑动画。
  - 坐标计算：时间轴的 0° 刻度位置严格按经度比例计算 (110°W 到 120°E 跨度 230°，对应 500px，0° 位于 110/230 处，即 x=389)。
- ID 命名规范：所有交互元素 ID 必须以 `scene2-` 为前缀（如 `scene2-east-mask`, `scene2-time-axis`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
