[图示主题与整合说明]
- 本图示主题：四棱锥侧面与底面的线面、面面平行与相交关系探究
- 整合的步骤/概念：整合了四棱锥的基础结构展示，以及命题①（反证法证明线线不平行）、命题③（构造面面交线）、命题②（面内平行线族的性质）的逐步推导和辅助线构造过程。
- 教学价值：教师可通过分步导航引导学生逐步思考，配合 3D 视角的拖拽旋转，直观展示复杂的空间线面关系，突破立体几何中的视觉遮挡和空间想象难点。

[视觉元素清单]
- 基础图形：
  - 可见棱 PA, PB, PC, AB, BC：黑色实线，线宽 2px
  - 不可见棱 PD, AD, CD：灰色虚线，线宽 2px
  - 底面 ABCD：多边形 A-B-C-D，填充颜色 #2e7d32，透明度 10%
- 辅助元素：
  - 平面 PAB：多边形 P-A-B，填充颜色 #1565c0，透明度 20%
  - 平面 PDC：多边形 P-D-C，填充颜色 #c62828，透明度 20%
  - 延长线 BE, CE：红色实线，线宽 2px
  - 交线 PE：红色实线，线宽 3px
  - 假设直线 l：蓝色虚线，线宽 2px
  - 平行线族（平行线1、2）：蓝色虚线，线宽 2px
  - 矛盾标记：红色叉号（❌），HTML 元素实现

[分步序列]
- 初始状态（步骤0）：显示四棱锥基础图形，高亮底面 ABCD（绿色透明）。
- 步骤1：点击「下一步」→ 高亮平面 PAB（蓝色透明）和直线 DC（红色加粗）。显示假设直线 l。延迟 0.5 秒后，在 AB 边上显示红色矛盾标记（❌），表示推导出的矛盾。
- 步骤2：点击「下一步」→ 隐藏直线 l 和矛盾标记。动态绘制延长线 BE、CE 交于点 E。绘制交线 PE 并加粗。高亮平面 PDC（红色透明），说明 PE 为两平面交线。
- 步骤3：点击「下一步」→ 保留交线 PE 和延长线。在平面 PAB 内依次显示平行线1和平行线2，说明平面内存在无数条平行线。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶） + 3D 拖拽旋转。
- 控件说明：
  - 底部控件栏（y=450~490）：包含“上一步”、“下一步”按钮，以及居中的步骤说明文本。
  - 3D 画布：支持鼠标左键拖拽旋转，右键平移，滚轮缩放。
- 教师操作流程：教师首先展示初始图形，随后点击“下一步”逐步演示命题①的反证法、命题③的交线构造、命题②的平行线族，期间可随时拖拽旋转图形，让学生从不同角度观察空间共面与平行关系。

[技术实现]
- JS 库选择及原因：选择 Three.js。本题核心在于空间线面关系，Three.js 提供了完善的 3D 渲染和 OrbitControls 交互，能完美满足“3D 视图居中显示，支持鼠标拖拽旋转”的需求。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500 (Three.js Canvas)]
  [控件栏 (绝对定位在 bottom: 10px, 包含 ◀上一步 | 步骤说明 | 下一步▶)]
  ```
- 关键实现要点：
  - 坐标系：使用右手坐标系，Y轴向上。
  - 材质与线条：使用 `LineBasicMaterial` 绘制实线，`LineDashedMaterial` 绘制虚线（需调用 `computeLineDistances()`）。面使用 `MeshBasicMaterial` 配合 `transparent: true` 和 `side: THREE.DoubleSide`。
  - 标签投影：在 `requestAnimationFrame` 的渲染循环中，使用 `THREE.Vector3.project(camera)` 将 3D 坐标转换为屏幕 2D 坐标，实时更新 HTML 标签的 `left` 和 `top`。
  - 状态机：定义 `currentStep` 变量，在按钮点击时更新，并通过 `switch(currentStep)` 控制各 3D 对象的 `visible` 属性。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-btn-next`, `scene1-label-P`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
