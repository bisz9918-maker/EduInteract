[图示主题与整合说明]
- 本图示主题：利用四点共圆转化角的关系求解
- 整合的步骤/概念：通过添加辅助线 OP 和 OM，利用切线性质和垂径定理得到直角，进而发现 A, P, O, M 四点共圆。利用同弧所对圆周角相等，将 ∠APM 转化为 ∠AOM，最后在直角三角形 △AOM 中利用内角和求出 ∠OAM + ∠APM = 90°。
- 教学价值：教师可以通过分步演示，清晰地展示辅助线的添加动机、四点共圆的判定过程以及角度转化的巧妙之处，帮助学生建立几何直观和逻辑推理链条。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：在 SVG 底部 (y=460) 居中放置两个按钮，分别用于切换到上一个/下一个步骤。
- 教师操作流程：教师首先展示原图，讲解题意；点击“下一步”引导学生作辅助线并发现直角；再次点击展示四点共圆的核心突破口；接着点击展示同弧所对圆周角相等完成等角转化；最后点击展示直角三角形内角和得出最终答案。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript。几何图形简单，SVG 能够提供高质量的矢量渲染，且方便通过 DOM 操作控制元素的显示/隐藏和样式变化。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  (30,50) 结论文本区
  (150,250) A点 ---------------- (550,250) O点及主圆
      \                              /
       \                            /
        \                          /
         (464,334) B点 -- (523,350) M点 -- (581,365) C点
  [控件栏 (y=460~490) 居中：◀上一步 | 下一步▶]
  ```
- 关键实现要点：
  - 使用 IIFE 封装代码 `(function() { ... })()`，避免全局变量污染。
  - 所有元素 ID 均以 `scene1-` 开头。
  - 定义一个 `currentStep` 变量（0~4），编写 `updateStep(step)` 函数。
  - 在 `updateStep` 中，通过 `document.getElementById` 获取元素，根据当前步骤设置 `style.display` (或 `opacity`) 以及点的 `fill` 和 `r` 属性。
  - 扇形和圆弧使用 SVG 的 `<path>` 元素结合 `A` (Arc) 指令精确绘制，确保 sweep-flag 设置正确以匹配所需的内外侧。
  - 直角三角形 △AOM 需在 DOM 树中放置在点和标签之前，避免遮挡交互重点。
