- 初始状态（步骤0）：显示基础线段（DB, BC, CE, DE, DA', EA'）和顶点（B, C, D, E, A'）。隐藏所有角度、虚线、高亮和顶点A。
- 步骤1（还原图形）：显示虚线 AD, AE，顶点 A 及其标签。
- 步骤2（求∠B）：显示 △ABC 蓝色高亮填充。显示 ∠A=26° 和 ∠C=120°。随后显示 ∠B=34°。
- 步骤3（平行性质）：隐藏 △ABC 填充。高亮 DE 和 BC（绿色加粗），显示平行箭头。显示 ∠ADE=34°。
- 步骤4（折叠性质）：隐藏平行高亮和箭头。显示 △ADE 和 △A'DE 红色高亮填充。显示 ∠A'DE=34°。
- 步骤5（终极求解）：隐藏三角形填充。显示直线段 ADB 的黄色底层高亮。显示 D 处平角虚线圆弧。显示最终目标角 ∠A'DB=112°。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无需外部库，性能最佳，易于控制精确的 SVG 路径）。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×450]
       A
      / \
     /   \
    D-----E
   / \   / \
  B---C-----A'
  [控件栏 800×50，包含 上一步 / 文本 / 下一步]
  ```
- 关键实现要点：
  - 使用 IIFE 封装所有逻辑。
  - 维护 `let currentStep = 0;`。
  - 编写 `updateScene()` 函数，根据 `currentStep` 的值（0-5），通过修改 SVG 元素的 `style.display` 或 `style.opacity` 来控制各元素的显隐。
  - 所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-angle-b`）。
  - SVG 路径已在视觉元素清单中精确计算，直接使用即可，无需 JS 动态计算。
