[图示主题与整合说明]
- 本图示主题：四边形PADB面积的逐步求解过程
- 整合的步骤/概念：已知条件标注、切线性质与勾股定理计算、图形对称分割、等面积法求高与最终面积计算
- 教学价值：教师可以通过分步导航，按部就班地引导学生从已知线段长度推导半径，利用切线性质求切线长，再通过对称性将四边形面积转化为三角形面积，最后利用等面积法求高并得出最终结果，逻辑清晰，层层递进。

[分步序列]
- 初始状态（步骤0）：显示圆O，割线PCD，切线PA、PB，线段AD、BD，以及对应的点和点名。说明面板：“已知 PC=CD=1，PA、PB 为切线。”
- 步骤1：高亮线段PC和CD（蓝色粗线），显示标签"1"和"1"。显示圆心O，显示标签"PO=1.5"。说明面板：“PC=1, CD=1 ⇒ 半径 R=0.5 ⇒ PO = PC + R = 1.5”
- 步骤2：显示辅助线OA（虚线），高亮OA和PA（蓝色粗线），显示直角符号∠PAO。显示标签"0.5"和"√2"。说明面板：“连接 OA。PA 为切线 ⇒ ∠PAO=90°。PA = √(PO² - OA²) = √2”
- 步骤3：显示四边形PADB的红色半透明填充。说明面板：“根据对称性，四边形 PADB 面积 S = 2 × S_△PAD”
- 步骤4：将填充切换为仅△PAD（红色半透明）。显示辅助线AH（虚线）及点H，高亮AH（红色粗线），显示直角符号∠AHO。显示标签"√2/3"。说明面板：“作 AH⊥PO。等面积法：AH × PO = OA × PA ⇒ AH = √2/3”
- 步骤5：保留△PAD填充，高亮底边PD和高AH（红色粗线）。说明面板：“S_△PAD = 1/2 × PD × AH = √2/3。总面积 S = 2√2/3”

[交互方案]
- 交互类型：分步按钮导航
- 控件说明：在 SVG 内底部 (y=460) 居中放置三个元素：[◀ 上一步] 按钮、[第 x/5 步] 文本指示器、[下一步 ▶] 按钮。
- 教师操作流程：教师点击“下一步”逐步展示推导过程，配合左上角的说明面板向学生讲解每一步的几何依据和计算公式。可随时点击“上一步”回退。

[技术实现]
- JS 库选择：原生 SVG + 原生 JS。SVG 非常适合精确的几何图形绘制和分层控制。
- 画布尺寸：800 × 500 px。
- 布局草图：
  [图示区 800×500]
  - 左上角：推导公式说明面板 (绝对定位)
  - 中央：几何图形 (SVG)
  - 底部：[◀ 上一步] [第 x/5 步] [下一步 ▶] (绝对定位，y=460)
- 关键实现要点：
  1. 状态机设计：定义一个包含 6 个状态（0-5）的数组，每个状态明确指定需要 `show`（显示）的元素 ID 列表，以及需要 `highlight`（高亮）的元素 ID 列表，并包含对应的说明文本。
  2. 坐标计算：所有坐标已在计划中预先计算完毕，直接硬编码到 SVG 属性中，无需 JS 动态计算。
  3. 直角符号绘制：使用 `<polyline>`，∠PAO 的点为 "452.53,339.28 457.53,325.14 471.67,330.14"，∠AHO 的点为 "466.67,260 476.67,260 476.67,250"。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-btn-next`, `scene1-line-PA`）。
- IIFE 隔离：所有 JS 代码必须包裹在 `(function() { ... })()` 中，避免全局变量污染。
