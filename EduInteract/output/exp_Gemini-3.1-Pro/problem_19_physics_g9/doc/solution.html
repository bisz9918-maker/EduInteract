题目原文：
如图所示，AB为铅笔芯，其电阻与长度成正比，当两个电流表均接0-0.6A量程时，改变滑片P在铅笔芯上的位置，两个电流表示数的最大比值为3：1，滑片P允许滑动的长度范围cd为12cm．当两个电表均接0-3A时，改变滑片P在铅笔芯上的位置，则：（ ）
A．两个电流表示数的最大比值变为19：1
B．两个电流表示数的最大比值变为29：1
C．滑片P允许滑动的长度范围为22.4cm
D．滑片P允许滑动的长度范围为21.6cm

题目分析与整体讲解思路：
本题考查并联电路的电流规律、欧姆定律以及电阻与长度的关系。难点在于正确识别电路的连接方式，并利用电流表的量程限制和电流比值推导出铅笔芯的各段长度关系。
讲解思路分为两步：

  1. 电路简化与定性分析：引导学生观察电流路径，将实物图转化为等效并联电路图，明确两个电流表分别测量哪一段铅笔芯的电流，并理解滑片移动时电阻和电流的变化规律。
  2. 定量计算与状态对比：利用 0-0.6A 量程下的条件（最大比值和滑动范围）求出铅笔芯总长度；然后切换到 0-3A 量程，利用电压不变的条件求出新的滑动范围和电流比值。

图示规划说明：

  • 图示1：用于展示电路的简化过程。通过动态高亮电流路径，帮助学生看懂这是一个并联电路，并提供滑片交互，直观感受滑片位置对两支路电流的影响。
  • 图示2：用于展示铅笔芯上的长度计算。将铅笔芯抽象为线段，在同一根线段上对比 0.6A 和 3A 两种量程下的极限位置，结合公式推导，清晰展示长度关系和比例计算。

教学说明：
完成电路分析后，学生已经明确：$I_1$ 测量 AP 段电流，$I_2$ 测量 BP 段电流。两段并联，电压 $U$ 相等。
接下来进入定量计算，引导学生按以下步骤推导：

  1. 分析 0-0.6A 量程（求总长 L）：
  • 电流表最大允许电流为 0.6A。当滑片 P 移至最左端允许位置 c 时，$I_1$ 达到最大值 0.6A。
  • 此时电流比值最大为 3:1，故 $I_2 = 0.2A$。
  • 根据 $R = U/I$，电阻与电流成反比，所以 $R_{Ac} : R_{cB} = I_2 : I_1 = 1:3$。
  • 由于电阻与长度成正比，得出 $Ac =

rac{1}{4}L$。同理，右侧极限位置 d 满足 $dB =
rac{1}{4}L$。

rac{1}{4}L -
rac{1}{4}L =
rac{1}{2}L$。已知 $cd = 12 ext{cm}$，解得总长 $L = 24 ext{cm}$。此时 $Ac = 6 ext{cm}$。

  1. 分析 0-3A 量程（求新范围和新比值）：
  • 量程变为 3A，滑片移至新极限位置 $c'$ 时，$I_1' = 3A$。
  • 电源电压不变，对 AP 段有 $I \propto 1/R \propto 1/x$。
  • 比较 c 和 $c'$ 两个位置：$I_1' / I_1 = x_c / x_{c'}$，即 $3A / 0.6A = 6 / x_{c'}$，解得 $x_{c'} = 1.2 ext{cm}$。
  • 同理 $d'B = 1.2 ext{cm}$。新滑动范围 $c'd' = 24 - 1.2 imes 2 = 21.6 ext{cm}$（选项D正确）。
  • 在 $c'$ 点求新比值：$R_{c'B} : R_{Ac'} = (24 - 1.2) : 1.2 = 22.8 : 1.2 = 19:1$。
  • 电流比 $I_1' : I_2' = R_{c'B} : R_{Ac'} = 19:1$（选项A正确）。

课堂讲解建议：

  1. 很多学生容易将此电路误认为串联，或者认为电流表串联在干路中。务必利用图示1的动态电流路径，让学生看清电流的分流和汇合点，这是解题的先决条件。
  2. 在图示2的讲解中，要强调“极限位置”的物理意义：电流表满偏时，滑片不能再向该支路对应的端点移动，否则会烧坏电流表。
  3. 两次量程的变化，核心不变量是电源电压。利用 $I \cdot x = ext{常数}$ 这一反比关系，可以非常快捷地求出新的极限位置，避免繁琐的代数方程求解。
