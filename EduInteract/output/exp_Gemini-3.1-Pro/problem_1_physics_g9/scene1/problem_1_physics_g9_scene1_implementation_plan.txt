[图示主题与整合说明]
- 本图示主题：杠杆最小动力及动力臂对比分析
- 整合的步骤/概念：阻力与阻力臂的确定、不同方向动力的力臂作图、最长动力臂的几何证明（斜边大于直角边）。
- 教学价值：教师可通过分步导航，清晰展示“定阻力力矩 -> 画动力臂 -> 几何对比”的逻辑链条，帮助学生直观理解“动力臂最长时动力最小”的原理，并掌握寻找最长动力臂的几何方法。

[分步序列]
- 步骤0（初始状态）：显示杠杆、支点O、重物G、F1~F4（均为黑色）。提示：“如图所示，杠杆在水平位置平衡，分析B点四个力中哪个最小。”
- 步骤1：支点O标红。显示FG（红色箭头）和LG（红色线段）。提示：“阻力 × 阻力臂 = 定值，要使动力最小，需动力臂最大。”
- 步骤2：F1、F2、F4淡化（#888888，透明度0.3）。F3变绿高亮，显示F3作用线和L3（绿色线段）。提示：“F3 的动力臂 L3 恰好等于线段 OB。”
- 步骤3：F4恢复高亮（蓝色，透明度1）。显示F4作用线、L4（蓝色线段）、C点、直角符号C及△OCB。提示：“在 Rt△OCB 中，直角边 L4 < 斜边 OB，故 L4 < L3。”
- 步骤4：F2恢复高亮（蓝色，透明度1）。显示F2作用线、L2（蓝色线段）、D点、直角符号D及△ODB。提示：“同理，在 Rt△ODB 中，直角边 L2 < 斜边 OB，故 L2 < L3。”
- 步骤5：F1恢复（灰色，透明度1）。提示：“F1 和 G 均使杠杆产生顺时针转动趋势，F1 无法使杠杆平衡。总结：F3 的动力臂最长，故 F3 最小。”

[交互方案]
- 交互类型：分步按钮导航
- 控件说明：底部居中放置「◀ 上一步」和「下一步 ▶」按钮。
- 教师操作流程：教师点击“下一步”逐步引导学生分析阻力、最长动力臂、其他动力臂的几何关系，最后得出结论。可随时点击“上一步”回退复习。

[技术实现]
- JS 库选择：原生 SVG。本场景主要由线段、箭头和多边形构成，SVG 能够提供最清晰的渲染效果和最简便的 DOM 状态控制。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [提示文本区 y=20~60]
  [图示区 y=60~450]
  [控件栏 y=450~490]
  ```
- 关键实现要点：
  1. 使用 `<defs><marker>` 定义箭头样式，方便复用。
  2. 状态机设计：定义 `currentStep` (0~5)，编写 `updateState()` 函数，根据当前步骤控制各 SVG 元素的 `opacity` 和 `stroke` 属性。
  3. 动画过渡：为 SVG 元素添加 `style="transition: all 0.3s ease;"` 实现平滑的显隐和颜色切换。
  4. ID 命名规范：所有元素 ID 均以 `scene1-` 为前缀（如 `scene1-btn-next`, `scene1-arrow-f3`）。
  5. IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
