[图示主题与整合说明]
- 本图示主题：初始状态的气体压强分析
- 整合的步骤/概念：展示题目初始条件，通过受力分析逐步推导封闭气体的压强。
- 教学价值：教师可通过分步导航，引导学生观察活塞受力、水银柱产生的压强，最终得出底部封闭气体的压强，帮助学生理清静态平衡下的压强叠加关系。

[视觉元素清单]
- 容器：由多条线段组成的阶梯状圆柱形截面，主线 #000000。
- 活塞：矩形，位于 A 管内水银上方，边框 #000000。
- 水银柱：两个拼接的矩形，填充 #888888（透明度 30%）。
- 尺寸标注：蓝色 #1565c0 的竖直线段（两端有短横线指示范围），及对应的文本标签。
- 压强箭头：红色 #c62828 的带箭头线段，及对应的文本标签。

[分步序列]
- 初始状态（步骤0）：显示容器、活塞、水银柱、空气柱。显示基础标签（A, B, S_A=4S_B）和尺寸标注（h1=5cm, h2=10cm, L=112cm）。隐藏 p0, p1 箭头及 h 标注。
- 步骤1：点击「下一步」→ 活塞边框高亮（变为红色 #c62828，加粗），出现向下的 p0 箭头及标签 "p0 = 75 cmHg"。
- 步骤2：点击「下一步」→ 活塞恢复原样。整段水银柱高亮（透明度提升至 60%），右侧出现总高度 h 标注线及标签 "h = h1 + h2 = 15 cm"。
- 步骤3：点击「下一步」→ 水银柱恢复原样。底部空气柱上方出现向上的 p1 箭头及标签 "p1 = p0 + h = 90 cmHg"。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：在 SVG 底部（y=460 区域）居中放置两个按钮。
- 教师操作流程：教师首先展示初始状态，介绍题目给定的几何尺寸；点击“下一步”分析活塞受力，说明上方大气压的作用；再次点击“下一步”分析水银柱产生的压强；最后点击“下一步”得出底部封闭气体的总压强。

[技术实现]
- JS 库选择及原因：原生 SVG。图形主要由简单的线段、矩形和文本构成，原生 SVG 性能好且易于精确控制坐标和样式。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×450]
    (左侧) A, B 标签
    (中间) 阶梯容器、活塞、水银、压强箭头
    (右侧) h1, h2, L, h 尺寸标注
  [控件栏 800×50] 底部居中放置 上一步/下一步 按钮
  ```
- 关键实现要点：
  - 使用 `<g>` 标签对不同步骤的元素进行分组，通过 JS 控制 `display` 或 `opacity` 属性实现步骤切换。
  - 文本中的下标（如 h1, p0）使用 SVG 的 `<tspan dy="4" font-size="0.8em">` 实现，确保排版美观。
  - 状态机设计：定义 `currentStep` 变量（0~3），每次点击按钮更新变量并调用 `updateView()` 函数刷新各元素的可见性和高亮状态。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-btn-next`, `scene1-p0-group`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
