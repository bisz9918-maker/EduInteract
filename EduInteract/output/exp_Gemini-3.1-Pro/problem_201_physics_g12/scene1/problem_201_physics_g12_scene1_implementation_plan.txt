[图示主题与整合说明]
- 本图示主题：带电粒子在重力场与电场中的运动分解及做功分析
- 整合的步骤/概念：将复杂的曲线运动分解为水平和竖直两个方向的直线运动，分别对应电场力和重力的作用，并直观展示位移与做功的关系。
- 教学价值：教师可通过分步演示，引导学生从受力分析入手，理解运动的独立性，最后将力与对应方向的位移结合，通过悬停高亮清晰讲解做功的计算。

[视觉元素清单]
- 匀强电场：6条水平向右的黑色细线（#000000），带有箭头。
- 粒子及轨迹：黑色实心圆（#000000），轨迹为黑色实线（#000000, stroke-width: 2）。
- 速度矢量：蓝色箭头（#1565c0, stroke-width: 2），表示 v0, vB, vx, vy。
- 受力矢量：红色箭头（#c62828, stroke-width: 2），表示 mg, Fe。
- 位移及辅助线：灰色双向箭头及虚线（#888888, stroke-width: 2, stroke-dasharray: 5,5）。
- 文本标签：使用 SVG `<text>`，字体大小 16px，斜体（除了数字）。下标使用 `<tspan dy="5" font-size="12">` 或直接 Unicode。

[分步序列]
- 初始状态（步骤0 - 题意展示）：显示电场线、A点、B点、轨迹、v0矢量及标签、vB矢量及标签。
- 步骤1（受力分析）：在轨迹中点 M 出现粒子，显示向下的 mg 矢量和向右的 Fe 矢量及标签。说明两个方向受力恒定。
- 步骤2（运动分解）：隐藏 M 点及受力。出现动点 P 从 A 运动到 B（循环动画，周期约 2.5 秒）。P 点上附带 vx 和 vy 矢量，vy 随高度上升逐渐缩短至 0，vx 随水平位移逐渐伸长至 vB。
- 步骤3（位移与做功）：停止动画，隐藏 P 及速度分量。显示 h 和 x 的标注线及辅助虚线。重新显示 M 点的 mg 和 Fe 矢量。
  - **悬停交互**：鼠标悬停在 h 标签或标注线上时，h 线和 mg 矢量高亮（加粗并加阴影），帮助讲解 WG；悬停在 x 标签或标注线上时，x 线和 Fe 矢量高亮，帮助讲解 WE。

[交互方案]
- 交互类型：分步按钮导航 + 悬停高亮。
- 控件说明：SVG 内部底部（y=450~490）居中放置一个 `<div>`，包含：
  - `<button id="scene1-btn-prev">◀ 上一步</button>`
  - `<span id="scene1-step-indicator">步骤 1 / 4</span>`
  - `<button id="scene1-btn-next">下一步 ▶</button>`
- 教师操作流程：点击下一步逐步展示受力、运动分解动画、位移。在最后一步，教师可通过鼠标悬停位移标签，动态高亮对应的力，直观讲解功的公式 W = F * s。

[技术实现]
- JS 库选择：原生 SVG + 原生 JS。无需外部库，SVG 非常适合矢量图形和简单动画。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```text
  [图示区 800x450]
  电场线铺满，A在左下，B在右上。
  轨迹为 A 到 B 的抛物线。
  [控件栏 800x50]
  底部居中，包含上一步/下一步按钮。
  ```
- 关键实现要点：
  - **轨迹方程**：使用 SVG Path `M 200,350 Q 200,150 600,150`，这在数学上完美对应匀变速曲线运动（竖直减速，水平加速）。
  - **动画实现**：在步骤 2 中，使用 `requestAnimationFrame`。设归一化时间 t ∈ [0, 1]。
    - Px = 200 + 400 * t^2
    - Py = 350 - 400 * t + 200 * t^2
    - vx 长度 = 160 * t
    - vy 长度 = 80 * (1 - t)
  - **状态机**：定义 `updateStep(step)` 函数，根据 step 值控制各 SVG `<g>` 元素的 `display` 属性（'none' 或 ''）。
  - **高亮效果**：通过 CSS 类 `.scene1-highlight` 实现，增加 `stroke-width: 4px` 和 `filter: drop-shadow(0 0 4px currentColor)`。为 h 和 x 的标注区域添加透明的粗线条（`stroke-width: 20`, `opacity: 0`）作为悬停触发区，提升交互体验。
  - **ID 命名规范**：所有元素 ID 必须以 `scene1-` 开头，例如 `scene1-traj`, `scene1-btn-next`。
  - **IIFE 隔离**：所有 JS 代码包裹在 `(function() { ... })()` 中，避免全局变量污染。
