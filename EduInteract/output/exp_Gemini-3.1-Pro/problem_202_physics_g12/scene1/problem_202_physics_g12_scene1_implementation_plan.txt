[图示主题与整合说明]
- 本图示主题：粒子A在交变电场中的类平抛运动及电场强度推导
- 整合的步骤/概念：展示粒子在第Ⅱ象限（向下电场）和第Ⅲ象限（向上电场）中的分段抛物线轨迹，通过几何关系（水平位移L和竖直位移L）和速度矢量分解，辅助推导加速度和电场强度E。
- 教学价值：教师可通过分步演示，清晰展示粒子在不同电场区域的受力方向、轨迹弯曲方向及速度变化（特别是竖直分速度的增加与减小），帮助学生直观理解“大小相等、方向相反”的电场对粒子运动的对称性影响。

[分步序列]
- 初始状态（步骤0）：显示坐标系、边界线、电场线及方向、磁场区域。显示粒子A位于起点(200,100)及初速度v0矢量。隐藏所有轨迹、位移标注和后续速度矢量。
- 步骤1：点击「下一步」→ 粒子A沿上半段抛物线运动至x轴交点P(350,250)。显示轨迹段1。高亮显示步1的水平位移L和竖直位移L标注线。在P点出现速度矢量vx、vy及合速度v，展示竖直速度从0增加到最大。
- 步骤2：点击「下一步」→ 粒子从P点沿下半段抛物线运动至y轴交点A'(500,400)。显示轨迹段2。高亮显示步2的水平位移L和竖直位移L标注线。在A'点出现速度矢量v0，展示竖直速度减小至0，粒子水平进入磁场。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：在 SVG 底部（y=450~490 区域）居中放置两个按钮。
- 教师操作流程：教师首先介绍题目初始条件（电磁场分布）；点击“下一步”演示粒子在Ⅱ象限的类平抛运动，结合位移标注讲解时间与加速度关系；再次点击“下一步”演示粒子在Ⅲ象限的减速偏转，强调对称性和竖直速度归零的条件。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。SVG 非常适合绘制精确的几何图形、贝塞尔曲线轨迹和矢量箭头，且易于通过 JS 控制元素的显示与隐藏。
- 画布尺寸：800 × 500 px（固定尺寸）。
- 布局草图：
  ```
  [图示区 800×500]
  -----------------------------------
  | E(向下)      | y                 |
  |    A-->      |   x   x   x   x   |
  |    .         |                   |
  |     .        |   x   x   x   x   |
  |C_____._______O_______x___x___x__x|
  |       .      |                   |
  |        .     |   x   x   x   x   |
  | E(向上) A'-->|                   |
  -----------------------------------
  [控件栏： ◀上一步 | 下一步▶ ] (绝对定位在底部)
  ```
- 关键实现要点：
  1. 状态机设计：定义 `currentState` (0, 1, 2)，根据状态控制各 SVG 组（`<g>`）的 `opacity` 或 `display` 属性。
  2. 动画实现：使用 CSS `transition: opacity 0.5s` 实现元素的平滑淡入淡出。为保证稳定性，建议在步骤切换时直接淡入静态轨迹和最终位置的速度矢量。
  3. 箭头标记：在 `<defs>` 中定义 `<marker>` 用于电场线、坐标轴和速度矢量的箭头，确保代码简洁。
  4. ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-btn-next`, `scene1-traj-1`）。
  5. IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
