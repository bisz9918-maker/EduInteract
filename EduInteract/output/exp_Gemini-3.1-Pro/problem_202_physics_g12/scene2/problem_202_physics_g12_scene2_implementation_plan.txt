[图示主题与整合说明]
- 本图示主题：粒子在磁场中的匀速圆周运动与返回电场的类平抛运动
- 整合的步骤/概念：清晰拆解粒子在不同场区（磁场→电场）的运动阶段，展示洛伦兹力偏转（半圆轨迹）及反向进入电场后的抛物线轨迹及落点计算。
- 教学价值：教师可通过分步演示，引导学生分段进行几何和运动学计算，先分析磁场中的圆周运动求出射点，再分析电场中的类平抛运动求最终落点。

  - 电场线：#aaaaaa 实线，在指定 y 坐标处绘制箭头（Q2向下，Q3向上）。
  - 磁场符号：#888888 的 '×' 符号阵列。

- 轨迹：
  - 磁场中半圆：#c62828 粗实线 (stroke-width: 3)。

[分步序列]
- 初始状态（步骤0）：显示坐标系、边界、电场线、磁场符号。显示入射点 A' 及其标签、向右的速度向量 v₀。隐藏所有轨迹及后续关键点。
- 步骤1：点击「下一步」→ 显示磁场中的半圆轨迹（可使用 stroke-dashoffset 动画展开）。显示圆心 O₁、半径辅助线 R。显示出射点 P 及其标签、向左的速度向量 v₀。
- 步骤2：点击「下一步」→ 显示电场中的抛物线轨迹（动画展开）。显示最终落点 Q 及其坐标标签。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：在 SVG 容器内部底部的 HTML 层 (y=450~490 区域) 居中放置三个元素：
  - `<button id="scene2-btn-prev">◀ 上一步</button>`
  - `<span id="scene2-step-text">初始状态</span>`
  - `<button id="scene2-btn-next">下一步 ▶</button>`
- 教师操作流程：教师首先结合初始状态讲解粒子进入磁场的条件；点击下一步，展示磁场偏转，引导学生计算半径和出射点；再次点击下一步，展示电场中的平抛运动，引导学生计算最终落点。

[技术实现]
- JS 库选择及原因：原生 SVG。场景主要由几何图形、路径和文本构成，原生 SVG 配合 CSS 动画（如 `stroke-dasharray` 动画）即可完美实现，无需引入庞大的外部库。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 SVG 800×500]
  [控件栏 DIV 绝对定位在底部 y=460 处，不撑高容器]
  ```
- 关键实现要点：
  - 状态机设计：定义 `currentStep` (0, 1, 2)，每次点击按钮更新状态并调用 `updateScene()` 函数。
  - 动画实现：对于轨迹路径，预先计算 `getTotalLength()`，通过修改 `stroke-dasharray` 和 `stroke-dashoffset` 实现轨迹的生长动画。
  - 坐标系映射：严格按照布局坐标表中的像素坐标进行绘制，确保图形与物理逻辑一致。特别是抛物线使用二次贝塞尔曲线 `Q 378 132 306 420` 精确拟合。
  - ID 命名规范：所有元素 ID 必须以 `scene2-` 为前缀，例如 `scene2-traj-mag`, `scene2-point-p`。
  - 隔离性：所有 JS 代码封装在 `(function() { ... })()` 中。
