[图示主题与整合说明]
- 本图示主题：不同初始位置粒子在交变电场中运动的周期性规律
- 整合的步骤/概念：展示从不同纵坐标（$y_0=L, L/4, L/9$）出发的粒子，在交变电场中经历不同次数的偏转后，均能在 $x=0$ 处达到竖直速度为零的状态，从而水平射入磁场。
- 教学价值：教师可通过切换不同状态，直观对比粒子轨迹的波动周期。利用精确的抛物线轨迹和顶点高亮，帮助学生归纳出“水平出射的普遍条件是运动时间为半周期的整数倍”，化抽象的公式推导为直观的几何图像。

[视觉元素清单]
- 坐标系：黑色实线，带箭头。
- 电场线：#888888，带方向箭头。
- 磁场符号：#888888，文本 "×"。
- 轨迹线：
  - 当前状态：#1565c0，粗实线 (stroke-width: 3)。
  - 非当前状态：#888888，细虚线 (stroke-width: 1.5, stroke-dasharray: 4 4)。
- 轨迹顶点：#c62828，实心圆点 (r=4)。
- 文本标签：黑色，字号 14px，起点标签使用 `<tspan>` 实现下标。

[分步序列]
- 初始状态（状态1）：默认选中 k=1。显示轨迹1为蓝色粗实线，轨迹2、3为灰色细虚线。显示顶点1（650, 450）。
- 状态2：点击「状态2 (y₀=L/4)」按钮。轨迹2变为蓝色粗实线，轨迹1、3变为灰色细虚线。隐藏顶点1，显示顶点2（450, 300 和 650, 200）。
- 状态3：点击「状态3 (y₀=L/9)」按钮。轨迹3变为蓝色粗实线，轨迹1、2变为灰色细虚线。隐藏顶点2，显示顶点3（383.3, 272.2 等三个点）。

[标签冲突检查]
- "O"标签：原计划在右下角(660,265)，但考虑到轨迹3的顶点在(650,272.2)非常接近，故调整至右上角(660,240)，完美避开所有轨迹和顶点。
- 起点标签：三个起点标签均放置在 $x=-2L$ 直线左侧（X=240，text-anchor="end"）。"y₀=L/4" (Y=195) 与 "y₀=L/9" (Y=235) 垂直间距达 40px，无重叠风险。
- 顶点与坐标轴：顶点2的(650,200)和顶点3的(650,272.2)均在y轴上，但避开了x轴(Y=250)，视觉清晰。

[交互方案]
- 交互类型：多状态切换（3个按钮）。
- 控件说明：在 SVG 底部 (Y=460) 绝对定位一个 `div`，包含三个按钮："k=1 (y₀=L)", "k=2 (y₀=L/4)", "k=3 (y₀=L/9)"。
- 教师操作流程：教师首先展示 k=1 的基础轨迹，然后依次切换到 k=2 和 k=3，引导学生观察轨迹跨越 x 轴的次数增加，但最终都在 x=0 处达到波峰/波谷（即竖直速度为零），从而总结出普遍规律。

[技术实现]
- JS 库选择及原因：原生 SVG。由于轨迹是精确的抛物线，使用 SVG 的二次贝塞尔曲线指令 `Q` 可以完美、精确地绘制，无需引入外部库。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  | (250,30)       (650,30)
  |   |              |
  |   |    E场       |  磁场
  |   |              |
  |---C--------------O------> x
  |   |              |
  |   |              |
  | x=-2L            y
  [控件栏 800×40，位于底部]
  ```
- 关键实现要点：
  - 轨迹路径精确计算（控制点 X 为两端点 X 的中点，Y 为顶点的 Y）：
    - Path 1: `M 250 50 Q 350 50 450 250 Q 550 450 650 450`
    - Path 2: `M 250 200 Q 300 200 350 250 Q 400 300 450 300 Q 500 300 550 250 Q 600 200 650 200`
    - Path 3: `M 250 227.78 Q 283.33 227.78 316.67 250 Q 350 272.22 383.33 272.22 Q 416.67 272.22 450 250 Q 483.33 227.78 516.67 227.78 Q 550 227.78 583.33 250 Q 616.67 272.22 650 272.22`
  - 状态切换逻辑：通过 JS 监听按钮点击，修改对应 `<path>` 和 `<circle>` 的 `class` 或 `style` 属性。使用 CSS `transition` 实现平滑的颜色和粗细过渡。
  - ID 命名规范：所有元素 ID 均以 `scene3-` 开头，如 `scene3-path-k1`, `scene3-btn-k2`。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
