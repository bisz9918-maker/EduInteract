[图示主题与整合说明]
- 本图示主题：各受力大小随角速度平方（$\omega^2$）变化的函数图像及临界点分析。
- 整合的步骤/概念：将圆周运动中复杂的受力变化（静摩擦力、绳子张力）转化为直观的分段函数图像，清晰展示三个关键临界状态（$\omega_0, \omega_1, \omega_2$）的出现条件。
- 教学价值：教师可通过分步导航，配合板书推导，逐步展示每个阶段受力的变化规律。避免一次性展示所有折线导致学生认知过载，帮助学生深刻理解“摩擦力先达到最大，绳子再出现张力”的物理过程。

[分步序列]
- 初始状态（步骤0）：显示空坐标系、水平阈值线（0.5mg, 2.0mg）、左上角图例。隐藏所有折线和临界点。
- 步骤1（求 $\omega_0$）：点击「下一步」。
  - 显示 $f_A$ 段1 和 $f_B$ 段1。
  - 显示临界点 $\omega_0$（圆点）、对应垂线及横轴标签 "25"。
- 步骤2（求 $\omega_1$）：点击「下一步」。
  - 保持步骤1元素。
  - 显示 $f_A$ 段2、$f_B$ 段2、$T_{AB}$ 段2。
  - 显示临界点 $\omega_1$（圆点）、对应垂线及横轴标签 "33.3"。
- 步骤3（求 $\omega_2$）：点击「下一步」。
  - 保持步骤2元素。
  - 显示 $f_A$ 段3、$f_B$ 段3、$T_{AB}$ 段3、$T_{OB}$ 段3。
  - 显示临界点 $\omega_2$（圆点）、对应垂线及横轴标签 "100"。

[标签冲突检查]
- Y轴标签 "0.5" (75,345) 与 "2.0" (75,165)：垂直间距 180px，无冲突。
- X轴标签 "25" (225,420) 与 "33.3" (267,420)：水平间距 42px。文本 "25" 宽约 20px，"33.3" 宽约 32px，边缘间距约 16px，无冲突。
- X轴标签 "33.3" (267,420) 与 "100" (600,420)：水平间距 333px，无冲突。
- 图例框 (120,40)-(230,180) 与折线：折线主要分布在 x>225 或 y>170 的区域，左上角完全空白，无冲突。
- $f_A$ 与 $f_B$ 水平段重叠：在 $\omega^2 > 33.3$ 后，两者理论上都在 y=340。设计中将 $f_A$ 设为 y=339，$f_B$ 设为 y=341，利用 2px 的微小错位确保实线和虚线同时可见，避免视觉遮挡。

[交互方案]
- 交互类型：分步按钮导航（◀ 上一步 / 下一步 ▶）。
- 控件说明：在 SVG 底部（y=450~490 区域）居中放置两个按钮。
- 教师操作流程：教师首先介绍坐标系和阈值线；点击“下一步”展示第一阶段（仅有摩擦力），讲解 A 先达到最大静摩擦力；再次点击展示第二阶段，讲解 AB 绳开始有张力且 B 摩擦力加速增大；最后点击展示第三阶段，讲解 OB 绳出现张力直至达到极限。

[技术实现]
- JS 库选择：原生 SVG。适合绘制精确的折线图和几何图形，且方便通过 DOM 操作控制各线段的显示/隐藏。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  +------------------------------------------------+
  |  Y(F/mg)                                       |
  |  ^                                             |
  |  | [图例框]                                    |
  |  | fA ---                                      |
  |  | fB - -                                      |
  | 2.0+ - - - - - - - - - - - - - - - - - - - *(100)
  |  |                                        /  |
  |  |                                       /   |
  |  |                                      /    |
  | 0.5+ - - - - *(25)- *(33.3)- - - - - - - - - |
  |  |          /      /                       | |
  |  |         /      /                        | |
  |  O---------+------+------------------------+-+-> X(w^2)
  |           25     33.3                     100  |
  |                                                |
  |            [◀ 上一步]  [下一步 ▶]              |
  +------------------------------------------------+
  ```
- 关键实现要点：
  - 使用 `<g>` 标签将每个步骤新增的元素分组（如 `id="scene2-step1-group"`），便于统一控制显示状态。
  - 状态机设计：定义 `currentStep` 变量（0~3），点击按钮时更新变量，并遍历所有步骤组，若 `step <= currentStep` 则设为 `display: block` 或 `opacity: 1`，否则隐藏。
  - 动画过渡：可为组添加 `transition: opacity 0.3s ease`，实现平滑的淡入淡出效果。
  - ID 命名规范：所有元素 ID 必须以 `scene2-` 开头，避免全局冲突。
  - IIFE 隔离：所有逻辑代码封装在 `(function() { ... })()` 中。
