problem_205_physics_g12

场景导航：Scene 1

如图所示，现在有一个小物块，质量为m=80g，带正电荷q=2×10$^{-4}$C，放在水平轨道上M点，物块与水平轨道之间的滑动摩擦系数μ=0.2，轨道处在一个水平向左的匀强电场中，E=10$^{3}$V/m，在水平轨道的末端N处，连接一个光滑的半圆形轨道，半径为R=40cm，取g=10m/s$^{2}$，求：
（1）要使小物块能够运动到轨道的最高点L，那么M、N间的距离S至少多大？
（2）如果在（1）题的位置释放小物块，当它运动到P（轨道中点）点时对轨道的压力等于多少？

题目分析：
本题考查带电物块在复合场（重力场和匀强电场）中的运动。核心考点包括：

  1. 竖直面内圆周运动的临界条件（最高点L）。
  2. 动能定理在多阶段运动（直线+圆周）中的应用。
  3. 圆周运动特定点（P点）的向心力分析。

整体讲解思路：

  1. 首先分析物块在最高点L的临界条件，得出到达L点的最小速度。
  2. 接着对M到L的过程应用动能定理，找出电场力、摩擦力、重力做功与动能变化的关系，从而解出最小距离S。
  3. 然后分析物块在P点的受力，明确水平方向的合力提供向心力。
  4. 最后对M到P的过程应用动能定理求出P点速度，代入向心力公式解出轨道对物块的弹力，并根据牛顿第三定律得出压力。

图示规划说明：
我们将通过一个整合的分步交互图示，完整演示物块从M点出发，经过N点，到达P点和L点的全过程。图示将动态展示物块在不同关键位置的受力情况、位移关系以及速度方向，帮助学生直观理解做功过程和向心力来源。

教学说明与推导过程：

第一问：求M、N间的最小距离S

  1. 引导观察L点临界状态（对应图示步骤1）：

要使物块能够到达最高点L，在L点的速度必须满足临界条件。此时物块只受重力（临界状态下轨道对物块向下的弹力 $N=0$），重力提供向心力。
$$mg = m rac{v_L^2}{R}$$
解得：$v_L = \sqrt{gR} = \sqrt{10 imes 0.4} = 2 ext{ m/s}$

  1. 应用动能定理（对应图示步骤2）：

分析物块从M运动到L的全过程。

  • 电场力做正功：电场力向左，水平总位移为 $S$（注意N和L在同一竖直线上），$W_E = qES$
  • 摩擦力做负功：只在MN段有摩擦力，$W_f = -\mu mgS$
  • 重力做负功：竖直位移为 $2R$，$W_G = -mg(2R)$

根据动能定理：
$$qES - \mu mgS - mg(2R) = rac{1}{2}mv_L^2 - 0$$
代入数据：$qE = 2 imes 10^{-4} imes 10^3 = 0.2 ext{ N}$，$\mu mg = 0.2 imes 0.08 imes 10 = 0.16 ext{ N}$
$$(0.2 - 0.16)S - 0.08 imes 10 imes 0.8 = rac{1}{2} imes 0.08 imes 2^2$$
$$0.04S - 0.64 = 0.16$$
解得：$S = 20 ext{ m}$

第二问：求P点对轨道的压力

  1. 分析P点受力（对应图示步骤3）：

在P点，物块在水平方向受向左的电场力 $qE$ 和向右的轨道弹力 $N_P$。这两个力的合力提供水平方向的向心力。
$$N_P - qE = m rac{v_P^2}{R}$$

  1. 应用动能定理求P点速度（对应图示步骤4）：

分析物块从M运动到P的过程。

  • 水平位移为 $S + R$（向左），电场力做功 $W_E = qE(S + R)$
  • 摩擦力做负功 $W_f = -\mu mgS$
  • 竖直位移为 $R$（向上），重力做负功 $W_G = -mgR$

根据动能定理：
$$qE(S + R) - \mu mgS - mgR = rac{1}{2}mv_P^2 - 0$$
代入已知数据：
$$0.2 imes (20 + 0.4) - 0.16 imes 20 - 0.08 imes 10 imes 0.4 = rac{1}{2} imes 0.08 imes v_P^2$$
$$4.08 - 3.2 - 0.32 = 0.04v_P^2$$
$$0.56 = 0.04v_P^2 \implies v_P^2 = 14 ext{ (m/s)}^2$$

代入向心力公式：
$$N_P = qE + m rac{v_P^2}{R} = 0.2 + 0.08 imes rac{14}{0.4} = 0.2 + 2.8 = 3.0 ext{ N}$$

根据牛顿第三定律，物块对轨道的压力大小为 $3.0 ext{ N}$，方向水平向左。
