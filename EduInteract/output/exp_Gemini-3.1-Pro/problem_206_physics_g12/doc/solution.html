problem_206_physics_g12

场景导航：Scene 1 | Scene 2

在光滑绝缘的水平面上，存在平行于水平面向右的匀强电场，电场强度为E．水平面上放置两个静止的小球A和B（均可看作质点），两小球质量均为m，A球带电荷量为+q，B球不带电，A、B连线与电场线平行．开始时两球相距L，在电场力作用下，A球开始运动（此时为计时零点，即t=0），后与B球发生对心碰撞，碰撞过程中A、B两球总动能无损失．设在各次碰撞过程中，A、B两球间无电量转移，且不考虑两球碰撞时间及两球间的万有引力．求：
（1）第一次碰撞结束瞬间A、B两球的速度各为多大？
（2）从计时零点到即将发生第三次碰撞这段过程中，共经过多长时间？
（3）从计时零点到即将发生第n次碰撞这段过程中，小球A经过的位移大小为多少？

【题目分析】
本题考查带电粒子在匀强电场中的加速运动以及两个等质量物体的完全弹性碰撞。
核心突破点在于：

  1. 完全弹性碰撞且质量相等：每次碰撞后，A和B交换速度。
  2. 追及相遇条件：碰撞后，B做匀速直线运动，A做初速度小于B的匀加速直线运动。当A的位移等于B的位移时，发生下一次碰撞。
  3. 周期性规律：通过分析前几次碰撞，可以发现碰撞时间间隔、碰撞前后的速度以及两球位移的等差/等比规律。

【整体讲解思路】
建议分两步进行讲解：
第一步，通过物理过程图示，直观展示前两次碰撞的过程，帮助学生理解“速度交换”和“加速追及”的物理情景。
第二步，引入速度-时间(v-t)图像，将复杂的追及相遇问题转化为简单的几何图形面积问题。通过v-t图像中A、B图线的交替和图线下的面积，轻松推导出第n次碰撞的时间和位移规律。

初始状态

【教学说明：v-t图像分析】
在理解了物理过程后，我们用 v-t 图像来定量分析。

  1. 0 ~ $t_1$ 阶段：A球做匀加速运动，加速度 $a =

rac{qE}{m}$。到达B球时位移为 $L$，由 $L =
rac{1}{2}at1^2$ 得 $t1 = \sqrt{
rac{2mL}{qE}}$，此时 $vA = at1 = v_1$。

  1. 第一次碰撞：质量相等，弹性碰撞，速度交换。$v_A$ 变为0，$v_B$ 变为 $v_1$。
  1. $t_1$ ~ $t_2$ 阶段：A从静止加速，B以 $v_1$ 匀速。在 v-t 图中，当A的图线与B的图线围成的面积相等时（即追及位移相等），发生第二次碰撞。由几何关系易得，经过时间 $\Delta t = 2t_1$，A的位移（三角形面积）等于B的位移（矩形面积），均为 $4L$。此时 $v_A = a(2t_1) = 2v_1$。
  1. 规律总结：
  • 第n次碰撞前，历经的总时间 $t_n = t_1 + (n-1) \cdot 2t_1 = (2n-1)t_1$。
  • 每次碰撞间隔内，A球的位移依次为 $L, 4L, 8L, \dots, 4(n-1)L$。
  • 第n次碰撞前A的总位移 $x_n = L + 4L + 8L + \dots + 4(n-1)L = (2n^2 - 2n + 1)L$。

【总结与课堂讲解建议】

  1. 第一问：第一次碰撞结束瞬间，A球速度为0，B球速度为 $v_1 = \sqrt{

rac{2qEL}{m}}$。

  1. 第二问：从计时零点到即将发生第三次碰撞，总时间为 $t3 = 5t1 = 5\sqrt{

rac{2mL}{qE}}$。

  1. 第三问：从计时零点到即将发生第n次碰撞，A的总位移为 $x_n = (2n^2 - 2n + 1)L$。

讲解建议：本题代数运算并不复杂，难点在于对物理过程的想象。强烈建议教师在黑板上推导公式的同时，利用 SCENE_2 的 v-t 图像进行对照。学生一旦看懂了 v-t 图像中“面积相等”的几何意义，就能立刻明白为什么每次碰撞的时间间隔都是 $2t_1$，从而将复杂的运动学问题降维打击。
