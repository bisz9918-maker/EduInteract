- 本图示主题：滑块A在斜面上的受力与加速运动
- 整合的步骤/概念：斜面几何条件、A的受力分析、匀加速运动过程及末速度计算

[视觉元素清单]
- 地面：水平黑线，下方带短斜线表示粗糙地面。
- 斜面：闭合多边形，边框 #000000，内部填充 rgba(0,0,0,0.05)。
- 木板B：矩形，边框 #000000，内部填充 rgba(0,0,0,0.1)，标签 "B" 居中。
- 滑块A：30x30 矩形，边框 #000000，填充 #ffffff，标签 "A" 在其左下方。
- 几何标注：
  - 倾角：圆弧及水平虚线（#888888），标签 "α=37°"。
  - 位移：平行于斜面的虚线（#888888），两端带垂直短线，标签 "s=9m"。
- 受力矢量（红色 #c62828）：mg（竖直向下）、F_N（垂直斜面向上）、f（沿斜面向上）。
- 运动矢量：
  - 加速度 a_1（绿色 #2e7d32）：沿斜面向下，放置在滑块右下方。
  - 末速度 v_1（蓝色 #1565c0）：沿斜面向下，在斜面底端。
  - 运动轨迹：蓝色虚线，连接初始与终点中心。

[分步序列]
- 初始状态（步骤0）：显示地面、斜面、木板B、滑块A（位于初始位置）、倾角α、位移s及对应标签。隐藏所有受力、加速度和速度矢量。
- 步骤1：点击「下一步」→ 滑块A保持静止。淡入显示受力分析矢量（mg, F_N, f）及加速度矢量（a_1），配合标签出现。
- 步骤2：点击「下一步」→ 受力分析和加速度矢量淡出隐藏。滑块A沿斜面匀加速下滑至底端（动画持续约1.5秒），同时绘制蓝色虚线轨迹。到达底端后，末速度矢量 v_1 及其标签 "v_1=6m/s" 淡入显示。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：在 SVG 内部底部（y=450~490 区域）居中放置两个按钮，控制步骤 0 -> 1 -> 2 的切换。
- 教师操作流程：教师首先展示初始几何条件（步骤0）；点击下一步，展示受力分析并讲解牛顿第二定律求加速度（步骤1）；再次点击下一步，演示加速运动过程并得出末速度（步骤2）。可随时点击上一步回退。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript。物理过程为简单的直线运动和矢量显隐，原生 SVG 的 `<animateTransform>` 或 JS `requestAnimationFrame` 即可完美实现，无需引入外部库，保证加载速度和稳定性。
- 画布尺寸：800 × 500 px（固定尺寸）。
- 布局草图：
  ```
  [图示区 800×450]
  斜面在左，木板B在右，滑块A从左上滑至右下。
  [控件栏 800×50]
  居中放置 [◀ 上一步] [下一步 ▶] 按钮
  ```
- 关键实现要点：
  - 坐标计算：严格按照布局坐标表中的绝对像素坐标绘制 SVG 元素。
  - 状态机设计：定义 `currentState` (0, 1, 2)，每次状态切换时调用 `updateScene()` 函数，通过修改 SVG 元素的 `opacity` 属性实现淡入淡出。
  - 动画实现：步骤2的运动动画可通过 JS `requestAnimationFrame` 动态更新滑块A的 `transform="translate(x, y) rotate(37)"` 属性，同时动态更新轨迹线的 `x2, y2` 属性。
  - ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-blockA`, `scene1-btn-next`）。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
