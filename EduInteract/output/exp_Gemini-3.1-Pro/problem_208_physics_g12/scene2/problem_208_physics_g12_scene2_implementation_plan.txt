[图示主题与整合说明]
- 本图示主题：电场中的类平抛运动与磁场中的圆周运动几何关系
- 整合的步骤/概念：将粒子在电场中的偏转（抛物线）、出射速度的分解、以及在磁场中的偏转（圆弧）结合，通过几何辅助线（半径、弦、垂线）推导出圆周运动的半径与磁场宽度的几何关系。
- 教学价值：帮助教师逐步展示复杂的物理过程，从运动轨迹的演变自然过渡到纯几何关系的求解，化抽象为直观，降低学生理解几何找圆心和计算半径的难度。

[视觉元素清单]
- 极板与电场：黑色粗实线极板，黑色细实线带箭头表示电场 E。
- 磁场区域：#888888 虚线框 MNPQ，内部均匀分布 #888888 小圆点表示向外的磁场 B。
- 粒子轨迹：#c62828（红高亮）实线，包含板间的二次贝塞尔曲线和磁场中的圆弧。
- 速度矢量：#1565c0（蓝高亮）带箭头实线，包含合速度 v 及分速度 v0, vy，辅助虚线构成平行四边形。
- 几何辅助线：#2e7d32（绿高亮）虚线，包含半径 OM, OP 和高亮的弦 MP。
- 角度与标注：蓝色圆弧表示速度 30° 角；绿色圆弧表示几何 30° 和 120° 角。所有文本标签使用对应颜色。

[分步序列]
- 初始状态（步骤0）：显示极板、电场 E、抛物线轨迹、磁场边界 MNPQ 及顶点标签。展示粒子在电场中的类平抛运动。
- 步骤1：点击「下一步」→ 在 M 点出现速度矢量 v、v0、vy 及 30° 角度标注，展示出射速度的分解。
- 步骤2：点击「下一步」→ 磁场区域出现 B 场圆点阵，同时画出从 M 到 P 的红色圆弧轨迹，展示洛伦兹力作用下的偏转。
- 步骤3：点击「下一步」→ 出现半径 OM、OP 及圆心 O，并在 M 点标出 v 与 OM 的直角符号，展示如何通过垂线寻找圆心。
- 步骤4：点击「下一步」→ 绿色高亮弦 MP，出现几何角度（∠OMP=30°，∠MOP=120°）及长度标注（R, d），展示最终的几何求解条件。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：底部居中放置两个按钮及步骤指示器（如“步骤 2 / 4”）。
- 教师操作流程：教师首先讲解电场中的平抛运动（步骤0）；点击下一步讲解速度分解（步骤1）；再点击下一步引入磁场并展示圆弧轨迹（步骤2）；接着引导学生寻找圆心（步骤3）；最后展示几何关系进行数学求解（步骤4）。可随时回退复习。

[技术实现]
- JS 库选择及原因：原生 SVG。本场景主要由直线、圆弧、贝塞尔曲线和文本构成，原生 SVG 的 `path` 和 `g` 标签配合 CSS opacity 过渡即可完美实现，无需引入外部库，性能高且代码轻量。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  (左上) 极板与电场抛物线
  (右下) 磁场区域与圆弧
  (左下) 圆心 O 及辅助线
  [控件栏] 底部 y=460 区域，绝对定位
  ```
- 关键实现要点：
  - 坐标计算：圆弧使用 SVG `A` 指令 `M 400 200 A 115.47 115.47 0 0 1 400 400`。
  - 状态机设计：定义 `currentStep` 变量（0-4），每次点击按钮更新变量，并通过修改对应 `<g>` 标签的 `opacity` 属性（0 或 1）来控制元素的显隐。
  - 动画曲线：在 CSS 中为所有带有 `.scene2-fade` 类的 `<g>` 元素添加 `transition: opacity 0.5s ease;` 实现平滑过渡。
  - ID 命名规范：所有元素 ID 均以 `scene2-` 开头（如 `scene2-step1`、`scene2-btn-next`），确保全局唯一。
  - IIFE 隔离：所有 JS 逻辑封装在 `(function() { ... })()` 中。
