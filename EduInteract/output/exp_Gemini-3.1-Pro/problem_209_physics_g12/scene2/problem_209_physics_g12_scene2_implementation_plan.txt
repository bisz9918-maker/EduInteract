[图示主题与整合说明]
- 本图示主题：物块受力分析与牛顿第二定律方程
- 整合的步骤/概念：将斜面物理模型与上滑、下滑两个过程的受力分析结合，通过分步展示受力矢量和对应的动力学方程，最终联立求解动摩擦因数。
- 教学价值：教师可通过分步按钮，清晰地对比物块在上滑和下滑时摩擦力方向的改变，以及由此导致的加速度差异，帮助学生直观理解牛顿第二定律在不同运动状态下的应用。

[分步序列]
- 初始状态（步骤0）：显示斜面、物块、倾角 	heta、坐标系（x轴、y轴）。右侧显示提示文字“请点击「下一步」查看受力分析”。
- 步骤1（上滑受力）：点击「下一步」。
  - 视觉变化：出现重力 mg、支持力 N、沿斜面向下的摩擦力 f_{up}、沿斜面向上的速度 v_{up}、沿斜面向下的加速度 a_1。
  - 右侧变化：隐藏提示文字，淡入显示“1. 上滑过程受力分析”及方程 $$mg\sin	heta + \mu mg\cos	heta = ma_1$$。
- 步骤2（下滑受力）：点击「下一步」。
  - 视觉变化：重力 mg、支持力 N 保持不变。隐藏 f_{up}, v_{up}, a_1。出现沿斜面向上的摩擦力 f_{down}、沿斜面向下的速度 v_{down}、沿斜面向下的加速度 a_2。
  - 右侧变化：保持步骤1方程可见，淡入显示“2. 下滑过程受力分析”及方程 $$mg\sin	heta - \mu mg\cos	heta = ma_2$$。
- 步骤3（联立求解）：点击「下一步」。
  - 视觉变化：左侧受力图保持步骤2状态不变。
  - 右侧变化：淡入显示“3. 联立求解”，代入 a_1, a_2 表达式，展示最终结果 $$\mu = rac{2v_0 - v_1}{2v_0 + v_1} 	an	heta$$。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：在 SVG 底部 (y=450~490) 放置两个按钮，水平居中，间距 20px。
- 教师操作流程：教师首先展示初始物理模型，点击“下一步”讲解上滑时的受力与方程，再次点击讲解下滑时的受力变化（重点强调摩擦力方向反转），最后点击展示联立求解过程。可随时点击“上一步”对比上下滑受力差异。

[技术实现]
- JS 库选择及原因：原生 SVG 用于绘制几何图形和矢量箭头（清晰且易于控制坐标），MathJax 用于渲染右侧的数学方程和左侧的标签。
- 画布尺寸：800 × 500 px（左侧 SVG 占 480x500，右侧 HTML 占 320x500）。
- 布局草图：
  ```
  [----------------- 800x500 -----------------]
  [       左侧 SVG 受力图       |  右侧 HTML 方程 ]
  [       (x: 0~480)          |  (x: 480~800) ]
  [                           |               ]
  [          [◀上一步] [下一步▶]              ]
  [-------------------------------------------]
  ```
- 关键实现要点：
  - 状态机设计：定义 currentStep (0~3)，每次点击按钮更新状态，并调用 updateScene() 函数。
  - 动画与切换：使用 CSS opacity 和 transition: opacity 0.3s 实现矢量和文本的平滑淡入淡出。
  - 箭头绘制：在 SVG 中定义 <marker> 用于绘制力、速度、加速度的箭头，确保箭头样式统一。
  - ID 命名规范：所有元素 ID 必须以 scene2- 为前缀（如 scene2-btn-next, scene2-vec-mg），避免全局冲突。
  - IIFE 隔离：所有 JS 代码封装在 (function() { ... })() 中。
