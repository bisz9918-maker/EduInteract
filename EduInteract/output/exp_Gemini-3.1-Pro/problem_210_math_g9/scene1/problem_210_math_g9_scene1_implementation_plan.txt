[图示主题与整合说明]
- 本图示主题：三角形穿过正方形的动态过程及面积函数图像
- 整合的步骤/概念：将几何图形的动态平移过程（四个阶段）与分段函数 $S(t)$ 的图像生成完美结合。通过 SVG 的 clip-path 技术精确提取重叠多边形，并在下方坐标系中同步绘制出对应的面积变化曲线。
- 教学价值：教师可通过拖动滑块，在 $t=0.5, 1, 1.5$ 等关键转折点暂停，直观展示“图形特征变化”如何导致“函数解析式及曲线凹凸性”的改变，帮助学生深刻理解数形结合思想。

[视觉元素清单]
- 几何基础：黑色实线绘制地平线、正方形边框。
- 动态三角形：黑色实线边框，顶点坐标随 t 实时计算：A(220+120t, 200), B(340+120t, 200), C(280+120t, 96.08)。
- 重叠高亮区：使用 SVG `<clipPath>`（路径为正方形）裁剪动态三角形，填充 #1565c0 (透明度 0.3)，完美实现复杂多边形交集的渲染。
- 动态标注：在 0 < t < 0.5 阶段，显示红高亮 #c62828 的尺寸线和文本（t 和 √3t），带有端点短划线。
- 坐标系：黑色实线绘制带有箭头的 t 轴和 S 轴，灰色虚线绘制三个关键转折点的垂直分割线。
- 函数曲线：蓝高亮 #1565c0 粗实线，根据 t 的值动态生成路径 `d` 属性，表现为曲线随时间逐渐画出。
- 追踪动点：红高亮 #c62828 实心圆，始终位于曲线的最前端，指示当前 (t, S) 坐标。

[分步序列]
本场景为连续滑块交互，以下为关键状态说明：
- 初始状态 (t=0)：三角形右顶点刚接触正方形左边缘。重叠面积为0，下方坐标系中动点位于原点 O。
- 阶段一 (0 < t ≤ 0.5)：三角形逐渐进入，重叠部分为小直角三角形。显示底边 t 和高 √3t 的标注。下方绘制出开口向上的抛物线段（凸函数）。
- 阶段二 (0.5 < t ≤ 1)：三角形上顶点进入正方形，重叠部分变为四边形。标注消失。下方绘制出开口向下的抛物线段（凹函数），在 t=1 时达到最高点 √3/4。
- 阶段三 (1 < t ≤ 1.5)：三角形开始穿出正方形，重叠部分仍为四边形。下方继续绘制开口向下的抛物线段，面积逐渐减小。
- 阶段四 (1.5 < t ≤ 2)：三角形即将完全穿出，重叠部分变为左侧的小直角三角形。下方绘制出开口向上的抛物线段，直至 t=2 时面积归零。

[标签冲突检查]
- 移动标签 A, B 与 固定标签 D, E：D, E 固定在 y=220（地平线下方），A, B 移动在 y=190（地平线上方）。完美错开，无冲突。
- 移动标签 C 与 正方形顶部标签 G, F：C 的 y 坐标为 80，G, F 的 y 坐标为 70。C 在 x 轴上从 280 移动到 520。当 t=0.5 时，C(340, 80) 接近 G(330, 70)；当 t=1.5 时，C(460, 80) 接近 F(470, 70)。由于 y 轴有 10px 错位且 x 轴方向相反，不会发生严重遮挡。
- 尺寸标注与图形：高度标注线固定在 x=325，文本在 x=305。三角形左边缘在 t=0.5 时会扫过该区域，但由于三角形内部无填充，红色文本在黑色线框上依然清晰可读。

[交互方案]
- 交互类型：连续拖拽滑块。
- 控件说明：在 SVG 底部 (y=460) 放置一个 `<input type="range">` 滑块，范围 0 到 2，步长 0.01。滑块左侧显示当前 t 的数值（保留两位小数）。
- 教师操作流程：教师可缓慢拖动滑块，引导学生观察上方重叠图形的形状变化（三角形 -> 四边形 -> 四边形 -> 三角形），并同步观察下方 S-t 曲线的生成过程和凹凸性转折，在 t=0.5, 1, 1.5 处可松开滑块进行重点讲解。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript。SVG 的 `<clipPath>` 是解决本题多边形交集渲染的最优解，避免了复杂的几何求交算法。
- 画布尺寸：800 × 500 px。SVG 实际占用 800 × 450，底部 50px 留给绝对定位的 HTML 控件栏。
- 关键实现要点：
  1. 面积函数计算：
     - `t <= 0.5`: `S = (Math.sqrt(3)/2) * t * t`
     - `t <= 1.5`: `S = Math.sqrt(3)/4 - (Math.sqrt(3)/2) * (t - 1) * (t - 1)` (此公式巧妙统一了中间两个阶段)
     - `t <= 2.0`: `S = (Math.sqrt(3)/2) * (2 - t) * (2 - t)`
  2. 曲线动态绘制：在滑块 `input` 事件中，使用 `for` 循环从 0 到当前 t，步长 0.02，计算对应的 (x, y) 坐标，拼接成 SVG 的 `d` 属性字符串（`M ... L ...`）。
  3. 坐标映射：t 轴缩放比例为 200px/单位，S 轴缩放比例为 `400/Math.sqrt(3)` px/单位。
- ID 命名规范：所有元素 ID 均以 `scene1-` 开头，如 `scene1-slider`, `scene1-triangle`, `scene1-curve`。
- IIFE 隔离：所有逻辑封装在 `(function() { ... })()` 中，通过 `document.getElementById` 获取 DOM 元素。
