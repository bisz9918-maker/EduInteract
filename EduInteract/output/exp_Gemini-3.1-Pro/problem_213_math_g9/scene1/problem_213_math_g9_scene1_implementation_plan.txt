[图示主题与整合说明]
- 本图示主题：链条拼接与长度计算规律演示
- 整合的步骤/概念：从1节链条的基础长度开始，逐步展示2节、3节链条拼接时的重叠现象，最后推广到100节及n节链条的通用长度计算规律。
- 教学价值：教师可通过分步点击，引导学生直观观察到“每增加1节链条，就增加1个重叠部分”，从而自然推导出重叠次数与链条节数的关系（n-1），帮助学生从具象图形过渡到抽象代数公式。

[视觉元素清单]
- 链条 (Link)：由上下两条微弧线（或直线）、左右两个圆（填充白色，覆盖底层线条）、圆心黑点组成。主线 #000000，线宽 2px。
- 尺寸标注线：#1565c0（蓝色）双向箭头线段，配合 #888888 垂直虚线辅助线。
- 重叠高亮：#c62828（红色），透明度 30% 填充，边框红色，用于突出重叠的圆。
- 底部大括号：黑色路径，带向下的小尖角，用于指示总长度范围。
- 文本标签：黑色或蓝色字体，通用公式使用红色加粗突出。

[分步序列]
- 初始状态（步骤0）：显示链条1、2.5cm标注线、1节大括号、1节公式（1节链条长度 = 2.5 cm）。
- 步骤1：点击「下一步」→ 显示链条2、重叠高亮1、0.8cm标注线1、2节大括号、2节公式（2节链条长度 = 2.5 × 2 - 0.8 × 1 = 4.2 cm）。隐藏1节大括号和公式。
- 步骤2：点击「下一步」→ 显示链条3、重叠高亮2、0.8cm标注线2、3节大括号、3节公式（3节链条长度 = 2.5 × 3 - 0.8 × 2 = 5.9 cm）。隐藏2节大括号和公式。
- 最终步骤（步骤3）：点击「下一步」→ 显示省略号、链条100、重叠高亮3、0.8cm标注线3、100节大括号、100节公式（100节链条长度 = 2.5 × 100 - 0.8 × 99 = 170.8 cm）及通用公式（n节链条长度 = 2.5n - 0.8(n-1) cm）。隐藏3节大括号和公式。

[交互方案]
- 交互类型：分步按钮导航（◀ 上一步 / 下一步 ▶）
- 控件说明：在 SVG 内底部（y=450）居中放置两个按钮，控制步骤变量 currentStep (0~3)。
- 教师操作流程：教师首先展示单节链条，然后点击“下一步”逐步增加链条，引导学生观察重叠部分的增加规律，最后点击到最后一步展示100节的计算和通用公式。可随时点击“上一步”回退复习。

[技术实现]
- JS 库选择及原因：原生 SVG。图形由规则的几何形状（圆、线段、路径）组成，SVG 能够完美保证缩放清晰度，且通过 DOM 操作控制各元素的显隐非常方便。
- 画布尺寸：800 × 500 px
- 布局草图：
  [图示区 800×500]
  (y=80)  0.8cm标注区
  (y=130) 2.5cm标注区
  (y=200) 链条图形区 (x=100~700)
  (y=270) 底部大括号及节数标签
  (y=360) 具体计算公式
  (y=400) 通用公式
  [控件栏 y=450，居中两个按钮]
- 关键实现要点：
  - 链条绘制技巧：在 <g> 组中，先绘制上下连线，再绘制左右两个圆并设置 fill="white"。这样拼接时，后一节的左圆会自然覆盖前一节的右圆及连线端点，实现无缝拼接效果。
  - 状态机设计：定义 currentStep 变量，在 updateScene() 函数中根据步骤值，通过 style.display 控制各组元素的显隐。
  - ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀（如 scene1-link1, scene1-dim-2.5），JS 中用 document.getElementById 获取。
  - IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染。
