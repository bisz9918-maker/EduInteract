场景导航：Scene 1

题目：如图所示，直线$a$经过正方形$ABCD$的顶点$A$，分别过顶点$D$，$B$作$DEot a$于点$E$，$BFot a$于点$F$，若$DE=4$，$BF=3$，则$EF$的长为（ ）
A．1 B．5 C．7 D．12

题目分析与整体讲解思路：
这是一道经典的“一线三直角”（或称“K字型”）全等三角形证明题。解题的核心在于利用正方形的性质（边长相等、内角为直角）和垂直条件，通过“同角的余角相等”进行角度转换，进而证明 $ riangle ADE \cong riangle BAF$。

教学引导步骤：

  1. 审题与条件梳理：引导学生观察图形，明确已知条件：正方形的边 $AD=AB$，$\angle DAB=90^\circ$；两个直角 $\angle DEA = \angle AFB = 90^\circ$；已知线段 $DE=4, BF=3$。
  2. 角度转换：重点讲解平角中的直角拆分。因为 $\angle DAE + \angle DAB + \angle BAF = 180^\circ$，且 $\angle DAB = 90^\circ$，所以 $\angle DAE + \angle BAF = 90^\circ$。又因为在 $Rt riangle ADE$ 中，$\angle DAE + \angle ADE = 90^\circ$，根据同角的余角相等，可得 $\angle BAF = \angle ADE$。
  3. 全等证明与线段转化：利用 AAS（角角边）证明 $ riangle ADE \cong riangle BAF$。由此得出对应边相等：$AE = BF = 3$，$AF = DE = 4$。
  4. 计算结果：观察图形可知 $EF = AE + AF$，代入数值即可求出 $EF = 3 + 4 = 7$。
1. 正方形性质
因为四边形 $ABCD$ 是正方形，
所以 $AD = AB$，
且 $\angle DAB = 90^\circ$。
2. 角度转换
因为 $\angle DAB = 90^\circ$，
所以 $\angle DAE + \angle BAF = 90^\circ$。
又因为 $DE \perp a$，即 $\angle DEA = 90^\circ$，
所以 $\angle DAE + \angle ADE = 90^\circ$。
因此，$\angle ADE = \angle BAF$。
3. 全等证明
在 $ riangle ADE$ 和 $ riangle BAF$ 中：
$egin{cases} \angle DEA = \angle AFB = 90^\circ \ \angle ADE = \angle BAF \ AD = AB \end{cases}$
所以 $ riangle ADE \cong riangle BAF$ (AAS)。
4. 计算求解
由全等可知：
$AE = BF = 3$
$AF = DE = 4$
所以 $EF = AE + AF = 3 + 4 = 7$。

教学总结与板书建议：

本题是中考常见的几何综合基础题，核心模型是“一线三直角”（或“K字型”全等）。教师在讲解时，可以通过图示的步骤2着重强调角度的转换过程，这是学生最容易卡壳的地方。
