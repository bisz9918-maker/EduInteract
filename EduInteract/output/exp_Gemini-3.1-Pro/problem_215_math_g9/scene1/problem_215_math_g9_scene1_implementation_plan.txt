[图示主题与整合说明]
- 本图示主题：利用“一线三直角”模型证明 $	riangle ADE \cong 	riangle BAF$ 并求解 $EF$
- 整合的步骤/概念：整合了已知条件标注、正方形性质提取、角度等量代换推导、全等三角形判定以及最终线段长度的计算。
- 教学价值：教师可以通过分步导航，引导学生逐步观察图形特征，从正方形的性质出发，利用“一线三直角”模型进行角度转换，最终完成全等证明和线段计算，逻辑清晰，节奏可控。

[视觉元素清单]
- 基础图形：正方形 ABCD、直线 a、垂线段 DE 和 BF（#000000，2px 实线）
- 顶点标签：A, B, C, D, E, F 及直线 a（#000000，16px，斜体）
- 已知条件标注：DE=4, BF=3（#000000，16px）
- 直角符号：∠DEA, ∠AFB（#000000，1px 实线）
- 正方形性质高亮：AD, AB 边（#1565c0，4px），等长短划线（#1565c0），∠DAB 直角符号（#1565c0）
- 角度弧线：∠DAE（#c62828），∠BAF（#c62828），∠ADE（#1565c0 转 #c62828）
- 三角形填充：△ADE（#1565c0，透明度 20%），△BAF（#c62828，透明度 20%）
- 结果标注：AE=3, AF=4（#2e7d32，16px），EF 线段高亮（#2e7d32，4px）

[分步序列]
- 初始状态（步骤0）：显示正方形 ABCD、直线 a、垂线 DE 和 BF，标注 DE=4, BF=3 及 E, F 处的直角符号。右侧文本区为空。
- 步骤1（正方形性质）：点击「下一步」，高亮边 AD 和 AB（蓝色加粗），添加蓝色等长短划线，显示 A 处蓝色直角符号。右侧浮现步骤1推导文字。
- 步骤2（角度转换）：点击「下一步」，高亮 ∠DAE 和 ∠BAF（红色弧线），右侧浮现互余文字；接着高亮 ∠ADE（蓝色弧线），右侧浮现互余文字；最后 ∠ADE 弧线变为红色并带等角短划线，表示 ∠ADE = ∠BAF。
- 步骤3（全等证明）：点击「下一步」，填充 △ADE（蓝色半透明）和 △BAF（红色半透明）。闪烁相等的三个条件（∠DEA/∠AFB, ∠ADE/∠BAF, AD/AB）。右侧浮现全等证明文字。
- 步骤4（计算求解）：点击「下一步」，在图形上浮现 AE=3 和 AF=4（绿色文本）。高亮整条线段 EF（绿色加粗）。右侧浮现最终计算式 EF = 3 + 4 = 7。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：在 SVG 容器内部底部（y=460 区域）居中放置两个按钮。
- 教师操作流程：教师点击“下一步”逐步展示正方形性质、角度转换、全等证明和最终计算，配合右侧同步出现的推导文字进行讲解。可随时点击“上一步”回退。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。图形由简单线段和多边形构成，原生 SVG 足以精确控制坐标和样式；右侧推导文字使用绝对定位的 HTML div 叠加在 SVG 上，便于文本排版。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +---------------------------------------------------------+
  |                                  [文本区 x=520, y=80]   |
  |          E a                     1. 正方形性质          |
  |         /                        ...                    |
  |    A   /___ D                    2. 角度转换            |
  |   /|  |    |                     ...                    |
  |  / |  |    |                     3. 全等证明            |
  | F  |  |    |                     ...                    |
  |  \_|  |____|                     4. 计算求解            |
  |    B       C                     ...                    |
  |                                                         |
  |             [ ◀ 上一步 ] [ 下一步 ▶ ]                   |
  +---------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：定义 `currentStep` 变量（0-4），编写 `updateStep()` 函数，根据当前步骤控制 SVG 元素的 `opacity`、`stroke` 等属性，以及右侧各步骤文本 div 的 `opacity`。
  2. 动画效果：使用 CSS `transition: all 0.5s ease` 实现元素的平滑显隐和颜色渐变。
  3. 闪烁效果：通过注入 CSS `@keyframes`，在步骤3为特定元素添加闪烁 class。
  4. 文本排版：右侧推导过程分为 4 个 div，分别对应步骤 1-4，按顺序垂直排列，初始透明度为 0，随步骤逐步显示。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-btn-next`, `scene1-line-ad`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
