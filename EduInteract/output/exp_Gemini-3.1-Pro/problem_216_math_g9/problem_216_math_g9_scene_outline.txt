    题目原文：
    如图，抛物线y＝ax$^{2}$+bx+c（a≠0）的对称轴为直线x＝1，与x轴的一个交点坐标为（﹣1，0），其部分图象如图所示，下列结论：①4ac＜b$^{2}$；、②3a+c＞0；③当x＞0时，y随x的增大而减小；④当y＞0时，x的取值范围是﹣1＜x＜3；⑤方程ax$^{2}$+bx+c＝0的两个根是x$_{1}$＝﹣1，x$_{2}$＝3；其中结论正确的个数是（  ）
    A．4个
    B．3个
    C．2个
    D．1个

    题目分析与整体讲解思路：
    本题考查二次函数的图象与系数的关系。通过观察图象，我们可以提取出以下关键几何与代数信息：开口向下（$a<0$），对称轴为 $x=1$（$b=-2a$），过点 $(-1,0)$，以及与 y 轴交于正半轴（图中标识了交点纵坐标为 3，即 $c=3$）。
    
    讲解时，建议按照各个结论的逻辑顺序逐一验证：
    1. 判断 ①：观察抛物线与 x 轴的交点个数，联系判别式 $\Delta$。
    2. 判断 ⑤：利用二次函数的对称性，由对称轴 $x=1$ 和一个交点 $(-1,0)$ 求出另一个交点。
    3. 判断 ④：结合求出的交点，观察图象在 x 轴上方的部分，得出对应的 x 取值范围。
    4. 判断 ③：利用对称轴 $x=1$ 划分增减区间，观察 $x>0$ 时的单调性变化。
    5. 判断 ②：利用代数推导，将点 $(-1,0)$ 代入解析式得到 $a-b+c=0$，结合对称轴 $b=-2a$，推导出 $3a+c$ 的确切值。

    **教学讲解建议：**

    1. **引入与识图**：
       引导学生观察初始图象，提取显性条件：抛物线开口向下、对称轴为 $x=1$、经过点 $(-1,0)$ 和 $(0,3)$。这些是后续推理的基石。

    2. **验证结论 ①**：
       - 提问：抛物线与 x 轴有几个交点？
       - 讲解：图象明显穿过 x 轴两次，说明方程 $ax^2+bx+c=0$ 有两个不相等的实数根。
       - 结论：判别式 $\Delta = b^2 - 4ac > 0$，移项得 $4ac < b^2$。结论 ① 正确。

    3. **验证结论 ⑤**：
       - 提问：已知一个交点是 $(-1,0)$，对称轴是 $x=1$，如何求另一个交点？
       - 讲解：利用抛物线的轴对称性。点 $(-1,0)$ 到直线 $x=1$ 的距离是 $1 - (-1) = 2$。因此，另一个交点在对称轴右侧距离为 2 的位置，即 $x = 1 + 2 = 3$。
       - 结论：方程的两个根是 $x_1=-1, x_2=3$。结论 ⑤ 正确。

    4. **验证结论 ④**：
       - 提问：当 $y>0$ 时，图象在 x 轴的上方还是下方？
       - 讲解：$y>0$ 对应 x 轴上方的抛物线部分。观察图象，这部分曲线位于两个交点 $(-1,0)$ 和 $(3,0)$ 之间。
       - 结论：对应的 x 取值范围是 $-1 < x < 3$。结论 ④ 正确。

    5. **验证结论 ③**：
       - 提问：在 $x>0$ 的区域，图象的走势是怎样的？
       - 讲解：抛物线的增减性以对称轴 $x=1$ 为分界。在 $0 < x < 1$ 时，图象是上升的（y 随 x 增大而增大）；在 $x > 1$ 时，图象是下降的（y 随 x 增大而减小）。
       - 结论：当 $x>0$ 时，y 先增大后减小。结论 ③ 错误。

    6. **验证结论 ②**：
       - 提问：如何将已知点和对称轴转化为代数式？
       - 推导步骤：
         1. 将点 $(-1,0)$ 代入解析式：$a(-1)^2 + b(-1) + c = 0 \Rightarrow a - b + c = 0$。
         2. 利用对称轴公式：$-rac{b}{2a} = 1 \Rightarrow b = -2a$。
         3. 将 $b = -2a$ 代入第一个式子：$a - (-2a) + c = 0 \Rightarrow 3a + c = 0$。
       - 结论：$3a+c=0$，所以 $3a+c>0$ 是错误的。结论 ② 错误。

    **总结**：正确的结论有 ①、④、⑤，共 3 个，故选 B。
