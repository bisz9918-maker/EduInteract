[图示主题与整合说明]
- 本图示主题：二次函数图象与系数关系的综合分析
- 整合的步骤/概念：抛物线与x轴的交点及判别式、对称性与根的求解、函数值的正负区间、函数的单调性、系数的代数关系推导。
- 教学价值：教师可以通过分步导航，逐一验证题目中的5个独立结论。每一步图象会自动高亮相关的几何特征（如交点、对称轴、特定区间），并在右侧同步展示代数推导过程，帮助学生建立“数”与“形”的直观联系，避免一次性展示过多信息导致认知超载。

[分步序列]
- 初始状态（步骤0）：显示坐标系、基础抛物线、对称轴及所有基础刻度标签。右侧文本区显示：“请点击「下一步」逐一验证结论”。
- 步骤1（验证①）：显示步骤1高亮交点。右侧文本显示：“① 抛物线与x轴有两个交点 ⇒ b² - 4ac > 0 ⇒ 4ac < b²。结论①正确”。
- 步骤2（验证⑤）：显示步骤2距离动画，箭头从左侧 (250,330)-(350,330) 平移至右侧 (350,330)-(450,330)。右侧文本显示：“⑤ 对称轴为 x=1，左交点为 x=-1。由对称性，右交点为 x = 1 + (1 - (-1)) = 3。结论⑤正确”。
- 步骤3（验证④）：显示步骤3正值区间（红色曲线和x轴红色线段）。右侧文本显示：“④ 当 y > 0 时，图象在x轴上方，对应的x取值范围是 -1 < x < 3。结论④正确”。
- 步骤4（验证③）：显示步骤4单调性（红色上升段，蓝色下降段）。右侧文本显示：“③ 当 x > 0 时，在 0 < x < 1 区间，y随x增大而增大；在 x > 1 区间，y随x增大而减小。结论③错误”。
- 步骤5（验证②）：显示步骤5代数标签。右侧文本显示：“② 图象过(-1,0) ⇒ a-b+c=0；对称轴x=1 ⇒ b=-2a。代入得：a-(-2a)+c=0 ⇒ 3a+c=0。结论②错误”。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：底部控件区包含两个按钮，居中排列，间距 20px。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。本场景主要为几何图形的高亮和简单平移动画，原生 SVG 的 `<path>` 和 `<circle>` 足以精确绘制，且性能最佳。右侧文本区使用 HTML `<div>` 绝对定位。
- 画布尺寸：800 × 500 px。
- 布局草图：
  [图示区 550×450] [文本区 220×300]
  [控件栏 800×40 底部居中]
- 关键实现要点：
  1. 状态机设计：定义 `currentStep` (0-5)，每次点击按钮更新状态，调用 `updateScene()` 函数。
  2. 元素显隐：将每步特有的 SVG 元素放入独立的 `<g>` 标签中（如 `<g id="scene1-step1-elements">`），通过修改 `display` 属性控制显隐。
  3. 动画实现：步骤2的平移使用 CSS `transition: transform 0.5s ease`。每次进入步骤2时，先将 `transform` 设为 `translateX(0)`，使用 `setTimeout` 延迟 50ms 后设为 `translateX(100px)` 触发动画。
  4. 文本更新：预先在 JS 中定义好每步的 HTML 字符串，状态切换时通过 `innerHTML` 更新右侧文本区。
- ID 命名规范：所有交互元素和组 ID 必须以 `scene1-` 为前缀（如 `scene1-btn-next`, `scene1-step2-anim`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
