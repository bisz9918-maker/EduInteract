[图示主题与整合说明]
- 本图示主题：二次函数 $y=x^2-2x-3$ 的综合性质分析
- 整合的步骤/概念：整合了求 x 轴交点及线段长度、等腰直角三角形的判定及角度计算、特定区间内的函数值域分析、以及对称轴与函数单调性的关系。
- 教学价值：教师可通过分步导航，引导学生按照逻辑顺序逐一验证四个结论，避免初始状态信息过载，清晰呈现每个推导步骤的视觉焦点。

[分步序列]
- 初始状态（步骤0）：显示坐标系、抛物线、点 A, B, C, O 及基础标签，线段 BC。
- 步骤1（验证①）：点击「下一步」→ 高亮点 A, B，标签更新为 A(-1,0), B(3,0)；高亮线段 AB，上方出现尺寸线及长度标注 "4"。
- 步骤2（验证②）：点击「下一步」→ 隐藏步骤1特有标注；高亮线段 OB, OC，显示长度标注 "3"；显示 O 处直角标记；填充三角形 OBC；在 B 点显示 45° 圆弧及标签 "45°"。
- 步骤3（验证③）：点击「下一步」→ 隐藏步骤2特有标注；高亮 x 轴区间 (0,2) 和 y 轴区间 [-4,-3)；高亮对应的抛物线段；显示顶点 V(1,-4) 和端点 D(2,-3) 及其坐标标签；C 点标签更新为 C(0,-3)；显示连接 V、D 到坐标轴的绿色虚线。
- 步骤4（验证④）：点击「下一步」→ 隐藏步骤3特有标注；绘制对称轴 x=1；高亮 x>1 区域的抛物线；显示一个沿该曲线向右上滑动的蓝色箭头动画，并显示文本 "y随x增大而增大"。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：在 SVG 内部底部（y=460 区域）居中放置一个绝对定位的 div，包含「◀ 上一步」按钮、当前步骤指示文本（如"步骤 1/4: 结论①"）和「下一步 ▶」按钮。
- 教师操作流程：教师在讲解时，首先展示题目基础图形。讲解第一个结论时点击「下一步」，图示高亮 AB 线段并显示坐标，辅助教师说明 AB=4。随后依次点击「下一步」验证后续结论，图示会动态切换高亮区域和标注，完美配合教师的推导节奏。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。SVG 非常适合精确的几何图形绘制和高质量的矢量显示，且易于通过 DOM 操作实现分步显示和隐藏。
- 画布尺寸：800 × 500 px。
- 布局草图：
  [图示区 800×500]
  [控件栏（y=460，居中，包含上一步/下一步按钮）]
- 关键实现要点：
  1. 坐标映射：定义逻辑坐标到屏幕坐标的转换函数 `sx(x) = 400 + x * 50`, `sy(y) = 200 - y * 50`。
  2. 抛物线绘制：在 JS 中循环生成 x 从 -2.2 到 4.2（步长 0.1）的坐标点，拼接成 SVG 的 `path` 元素的 `d` 属性。
  3. 状态机设计：定义 `currentStep` 变量（0~4）。编写 `updateScene(step)` 函数，根据 step 值控制各个 `<g>` 组的 `display` 属性（'none' 或 ''），并动态更新 A, B, C 点的文本内容和位置。
  4. 动画实现：步骤4的滑动箭头使用 SVG `<animateMotion>` 元素，绑定到 x>1 的曲线 path 上，设置 `rotate="auto"` 和 `repeatCount="indefinite"`，无需 JS 介入即可实现平滑动画。
  5. ID 命名规范：所有元素 ID 必须以 `scene1-` 开头，如 `scene1-btn-next`, `scene1-group-step1`。
  6. IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
