[图示主题与整合说明]
- 本图示主题：利用直角三角板的隐含角度和三角形内角和求解
- 整合的步骤/概念：等腰直角三角形内角、平角计算、30度直角三角形内角、普通三角形内角和
- 教学价值：教师可以通过分步导航，控制解题节奏，逐步引导学生从已知条件出发，依次求出中间角∠ACB、∠ACF、∠F，最终利用三角形内角和求出目标角∠CDF。图示的高亮和动态公式能有效降低学生的认知负荷。

[视觉元素清单]
- 几何图形：多边形ABC、多边形DEF、线段EF（底线）
- 角度标记：∠A直角符号、∠EDF直角符号、∠E(30°)、∠BCE(40°)、∠ACB(45°)、∠ACF(95°)、∠F(60°)、∠CDF(25°)
- 边长标记：AB和AC上的等长短划线
- 文本标签：顶点字母 A, B, C, D, E, F
- 颜色/样式：
  - 背景 #ffffff
  - 主线 #000000（2px宽）
  - 蓝高亮 #1565c0（用于步骤1高亮△ABC及∠ACB，填充透明度20%，线条透明度100%）
  - 绿高亮 #2e7d32（用于步骤2和3高亮∠ACF和∠F，及△DEF填充，透明度20%）
  - 红高亮 #c62828（用于步骤4高亮△CDF及∠CDF，填充透明度20%）
  - 辅助线 #888888（步骤2高亮平角底线EF时加粗）

[分步序列]
- 初始状态（步骤0）：显示基础线段、点标签、直角符号、∠E=30°、∠BCE=40°、等长标记。公式区显示已知条件。
- 步骤1（计算∠ACB）：高亮△ABC（蓝色填充），显示∠ACB弧线及"45°"（蓝色）。公式区更新推导过程。
- 步骤2（计算∠ACF）：取消△ABC高亮，高亮底线EF（加粗），显示∠ACF弧线及"95°"（绿色）。公式区更新平角计算过程。
- 步骤3（计算∠F）：取消底线高亮，高亮△DEF（绿色填充），显示∠F弧线及"60°"（绿色）。公式区更新直角三角形锐角互余计算。
- 步骤4（计算∠CDF）：取消△DEF高亮，高亮△CDF（红色填充），显示目标角∠CDF弧线及"25°"（红色）。公式区更新三角形内角和计算得出最终结果。

[交互方案]
- 交互类型：分步按钮导航
- 控件说明：底部控件栏包含「◀ 上一步」和「下一步 ▶」两个按钮，居中排列。
- 教师操作流程：教师点击“下一步”逐步展示每个中间角的计算过程，配合左上角的动态公式区进行讲解；可随时点击“上一步”回退复习。

[技术实现]
- JS 库选择及原因：原生 SVG + HTML DOM。几何图形简单，原生 SVG 易于实现精确的坐标控制和高质量渲染；公式区使用 HTML div 绝对定位，方便文本排版。
- 画布尺寸：800 × 500 px
- 布局草图：
  [图示区 800×450]
    (280,30) [动态公式区]
    (233,116) B --- A (545,88)
                   /
                  D (550,140)
                 / \
                /   \
  E (100,400) - C --- F (700,400)
  [控件栏 800×50] (上一步 / 下一步)
- 关键实现要点：
  - 状态机设计：定义 `currentStep` (0-4)，编写 `updateScene()` 函数，根据 step 控制各 SVG 元素的 `display`、`opacity` 和 `fill` 属性。
  - 角度弧线绘制：使用 SVG `<path>` 的 `A` (椭圆弧) 指令精确绘制圆弧。
  - 动态公式区：预定义 5 段 HTML 字符串，在 `updateScene()` 中通过 `innerHTML` 切换，使用简单的 HTML 实体（如 `&ang;`, `&deg;`, `&there4;`, `&because;`）实现数学符号排版。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-btn-next`, `scene1-angle-acb`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
