[视觉元素清单]
- 基础装置：烧杯、稀硫酸液面、锌电极、铜电极、椭圆形滤纸、石墨棒a和b、连接导线。
- 步骤1元素：蓝色文本“原电池”(225,390)、“电解池”(530,390)，灰色虚线分界线(x=365, y=40-420)。
- 步骤2元素：蓝色文本“负极”(160,100)、“正极”(290,100)、“阳极”(440,100)、“阴极”(620,100)。

- 步骤4元素：绿色气泡及气体标签（Cu极(260,280)“H₂↑”，a极(470,270)“Cl₂↑”，b极(590,270)“H₂↑”），红色径向渐变晕影及“变红”标签（b极(590,280)），红色反应式文本（Cu极(225,430)，a极(470,430)，b极(620,450)）。

[分步序列]
- 初始状态（步骤0）：显示基础装置（烧杯、溶液、电极、滤纸、导线）及基础标签（锌、铜、a、b、稀硫酸、滤纸）。
- 步骤1（装置识别）：点击「下一步」，出现灰色虚线分界线，左侧下方出现“原电池”，右侧下方出现“电解池”（蓝色高亮）。
- 步骤2（电极判断）：点击「下一步」，各电极上方出现极性标注（负极、正极、阳极、阴极，蓝色高亮）。
- 步骤3（电子流向）：点击「下一步」，导线上出现红色电子流向箭头及“e⁻”，溶液和滤纸中央出现红色叉号及“无电子通过”。
- 步骤4（反应与现象）：点击「下一步」，Cu极、a极、b极出现绿色气泡及气体标签，b极周围出现红色晕影及“变红”标签，底部出现各极反应式（红色高亮）。

[技术实现]
- JS 库选择及原因：原生 SVG。电化学装置主要由规则几何图形（矩形、多边形、路径）组成，SVG 能够完美实现高质量的矢量绘制，且方便通过 DOM 操作实现分步显示和样式控制。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×450]
  左侧：原电池装置 (x:150-300)
  右侧：电解池装置 (x:400-660)
  上方：导线连接
  下方：反应式展示
  [控件栏 800×50] 底部居中按钮
  ```
- 关键实现要点：
  - 使用 `<g>` 标签将不同步骤的元素分组，通过控制 `display` 属性（'none' 或 'block'）实现分步显示。
  - 气泡效果可以使用多个小圆形 `<circle>` 组合，红色晕影使用 `<radialGradient>` 实现。
  - 导线折线使用 `<polyline>`，箭头使用 `<marker>` 定义。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-step1-group`, `scene1-btn-next`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
