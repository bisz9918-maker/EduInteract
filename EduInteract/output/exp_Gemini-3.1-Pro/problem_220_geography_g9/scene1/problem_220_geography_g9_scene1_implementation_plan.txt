[分步序列]
- 初始状态（步骤0）：显示基础底座、循环箭头①②③④、节点标签a/b/c/d。顶部提示：“请点击下一步，逐步推导环流模型”。
- 步骤1（热力环流-温度）：点击「下一步」。顶部提示：“若为热力环流：b处受热膨胀上升，a处冷却收缩下沉。近地面温度：b > a（选项A错误）”。显示“受热”和“冷却”标签，箭头②高亮为红色，箭头④高亮为蓝色。
- 步骤2（热力环流-气压）：点击「下一步」。顶部提示：“若为热力环流：近地面受热处形成低压，冷却处形成高压；高空相反。气压：a > b > c > d（选项B错误）”。显示a/c处的“H”和b/d处的“L”，箭头③和①加粗高亮（表示风从高压吹向低压）。
- 步骤3（中纬环流-定位与成因）：点击「下一步」。顶部提示：“若为北半球中纬环流：a处下沉为30°N，b处上升为60°N。④为动力原因下沉（选项D错误）”。清除热力环流的所有标注（H/L/受热/冷却及红蓝高亮）。显示“30°N”和“60°N”标签，在④左侧显示“动力原因下沉”。
- 步骤4（中纬环流-极锋）：点击「下一步」。顶部提示：“若为北半球中纬环流：60°N处冷暖气流相遇，暖气流爬升形成极锋（选项C正确）”。显示右侧来的蓝色“极地东风”箭头，在③下方显示红色“盛行西风”标签并高亮③为红色，高亮②为红色（暖气流爬升），显示极锋面斜线及“极锋”标签。

[交互方案]
- 交互类型：分步按钮导航。
- 控件说明：在 SVG 底部（y=450~490）放置三个元素：左侧「◀ 上一步」按钮，中间「步骤 X / 4」文本，右侧「下一步 ▶」按钮。
- 教师操作流程：教师在讲解时，首先展示原图（步骤0），然后点击下一步代入热力环流模型讲解温度（步骤1）和气压（步骤2），接着点击下一步切换到三圈环流模型讲解纬度定位（步骤3）和极锋成因（步骤4）。可随时点击上一步回退。

[技术实现]
- JS 库选择：原生 SVG。由于本场景主要由直线、多边形、箭头和文本构成，SVG 能提供最精确的像素级定位和清晰的渲染，且易于通过 DOM 操作修改颜色和透明度来实现动画状态切换。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
    (400,60) [顶部提示文字]

         d(220,120) <-------①------- c(520,120)
             |                          ^
             |                          |
             ④                         ②
             |                          |
             v                          |
         a(220,320) -------③-------> b(520,320)  <--极地东风(Step4)
            /                          /
           /                          / (虚线)
          /                          /
      (120,430) ---------------- (420,430)

  [控件栏 450~490]
      [◀ 上一步]  [ 步骤 1 / 4 ]  [下一步 ▶]
  ```
- 关键实现要点：
  - 状态机设计：维护一个 `currentStep` 变量（0-4）。编写 `updateScene()` 函数，根据 `currentStep` 的值，通过修改 SVG 元素的 `display`、`stroke`、`fill` 属性来控制元素的显隐和高亮。
  - 箭头绘制：使用 `<marker>` 定义箭头样式，附加到 `<line>` 元素上。
  - 动画过渡：可以为 SVG 元素的 `stroke` 和 `opacity` 添加 CSS `transition`，使状态切换更平滑。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-arrow2`、`scene1-btn-next`）。
- IIFE 隔离：所有 JS 代码必须包裹在 `(function() { ... })()` 中，避免全局变量污染。
