[图示主题与整合说明]
- 本图示主题：满月升起时间与地球自转的俯视几何关系
- 整合的步骤/概念：太阳、地球、月球的相对位置，地方时分布，地球自转与月出的动态过程
- 教学价值：教师可通过分步演示，将复杂的空间时间转换拆解为定位直射点、定位月出、定位观察者、计算差值四个逻辑步骤，帮助学生直观理解地球自转带来的时间变化和天体视运动。

- 初始状态（步骤0）：显示太阳光线、地球（昼夜半球、N极）、满月。隐藏所有经线、扇形和计算公式。
- 步骤1：点击「下一步」→ 显示 60°E 经线及标签，显示 150°E 经线及标签（红色高亮）。
- 步骤2：点击「下一步」→ 显示 120°E 经线及标签（蓝色高亮）。
- 步骤3：点击「下一步」→ 显示自转方向弧线箭头，显示 30° 扇形高亮区域及 "30°" 标签，显示右下角的计算公式文本。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：底部居中放置两个按钮，控制步骤 0 到 3 的切换。
- 教师操作流程：
  1. 初始展示太阳、地球、月球的相对位置，讲解俯视图的基本方位。
  2. 点击下一步，定位直射点（12:00）和昏线（18:00），说明满月升起的时间和位置。
  3. 点击下一步，定位上海（16:00）的当前位置。
  4. 点击下一步，展示地球自转方向和需要转过的角度（30°），推导出等待时间（2小时）。

[技术实现]
- JS 库选择及原因：原生 SVG。适合绘制几何图形、弧线，且通过控制 DOM 元素的 `opacity` 属性可以非常方便地实现分步平滑动画，文本渲染清晰。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  (左侧:太阳光)  (中间:地球及经线)  (右侧:满月)
  [控件栏（y=450~490，◀上一步 下一步▶）]
  ```
- 关键实现要点：
  - 使用 `<path>` 的 `A` 指令绘制昼夜半球、自转箭头和 30° 扇形。
  - 昼半球路径：`M 400 100 A 150 150 0 0 0 400 400 Z`
  - 夜半球路径：`M 400 100 A 150 150 0 0 1 400 400 Z`
  - 30° 扇形路径：`M 400 250 L 325 380 A 150 150 0 0 0 400 400 Z`
  - 自转箭头路径：`M 520.2 129.8 A 170 170 0 0 0 279.8 129.8`，配合 `<marker>` 实现箭头。
  - 状态机设计：定义 `currentStep` 变量（0-3），每次点击按钮更新变量，并调用 `updateView()` 函数，根据当前步骤控制各 SVG 组（如 `<g id="scene2-step1">`）的 `opacity` 和 `transition`，实现平滑过渡。
  - ID 命名规范：所有元素 ID 必须以 `scene2-` 为前缀，如 `scene2-btn-next`，避免全局冲突。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
