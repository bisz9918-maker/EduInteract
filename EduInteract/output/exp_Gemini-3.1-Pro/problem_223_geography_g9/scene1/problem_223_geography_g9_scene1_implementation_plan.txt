[图示主题与整合说明]
- 本图示主题：地球公转轨道及二分二至日的地理现象特征
- 整合的步骤/概念：地球公转的椭圆轨道与逆时针方向；四个关键节点（a冬至, b春分, c夏至, d秋分）的太阳直射点位置；昼夜长短变化与极昼极夜现象；南北半球季节相反的特征。
- 教学价值：通过左侧全局轨道图与右侧局部特写图的联动，帮助学生建立从宏观宇宙视角到微观地球受热视角的空间转换能力，直观理解太阳直射点移动与季节变化的因果关系。教师可利用分步导航逐一破解题目中的5个小问。

[视觉元素清单]
- 太阳：橙黄色填充 `#f57f17`，带有光芒射线，中心文字“太阳”。
- 公转轨道：黑色虚线 `#000000`，带有逆时针箭头。
- 小地球 (a,b,c,d)：包含地轴（倾斜23.5°）、赤道、回归线、极圈。带有半透明黑色阴影 `#000000` (opacity: 0.3) 表示夜半球。
- 高亮标识：当前选中的小地球外围显示红色光晕或粗边框 `#c62828`。
- 特写大地球：
  - 基础轮廓：黑色描边，白色填充。
  - 纬线：赤道、南北回归线、南北极圈（虚线）。
  - 地轴：贯穿南北极的直线。
  - 太阳光线：橙黄色 `#f57f17` 的水平直线，带箭头，指向地球。
  - 夜半球阴影：半透明黑色填充。
- 颜色/样式沿用：背景 `#ffffff`，主线 `#000000`，高亮 `#c62828`，文本 `#1565c0`。

[分步序列]
- 初始状态（步骤0）【认识公转轨道】：左侧显示完整的公转轨道、太阳、四个位置的地球(a,b,c,d)及逆时针箭头。右侧特写面板显示占位提示文字“请点击下一步查看各位置特征”。
- 步骤1【夏至日特征 (位置c)】：
  - 左侧：高亮地球 c。
  - 右侧：显示大地球。地轴向右倾斜23.5°。太阳光线从右侧水平射入，中心光线直射北回归线。左半球显示夜阴影。
  - 文本：“直射北回归线”、“北半球昼长夜短，北极圈极昼”。
- 步骤2【冬至日特征 (位置a)】：
  - 左侧：高亮地球 a。
  - 右侧：显示大地球。地轴向右倾斜23.5°。太阳光线从左侧水平射入，中心光线直射南回归线。右半球显示夜阴影。
  - 文本：“直射南回归线”、“北极圈极夜，南极圈极昼”。
- 步骤3【秋分日特征 (位置d)】：
  - 左侧：高亮地球 d。
  - 右侧：显示大地球。为清晰展示直射赤道，地轴竖直（倾斜0°）。太阳光线从左侧水平射入，中心光线直射赤道。右半球显示夜阴影。
  - 文本：“9月22日或23日前后”、“太阳光线直射赤道”。
- 步骤4【季节过渡 (b→c)】：
  - 左侧：高亮轨道上 b 到 c 的圆弧段（加粗红色），并显示一个移动的箭头动画。
  - 右侧：隐藏大地球，居中显示大号文本：“b(春分) → c(夏至)”、“北半球由春季过渡到夏季”。
- 步骤5【南北半球季节相反】：
  - 左侧：高亮地球 c。
  - 右侧：恢复步骤1的大地球（夏至日）。在北半球区域添加标签“中国 (夏季/暑假)”，在南半球区域添加标签“澳大利亚 (冬季)”。
  - 文本：“同一时间，南北半球受热不同，季节相反”。

[交互方案]
- 交互类型：分步按钮导航。
- 控件说明：在 SVG 底部 (y=450) 居中放置三个元素：
  - `<button id="scene1-btn-prev">◀ 上一步</button>`：位置 (300, 450)
  - `<span id="scene1-step-indicator">步骤 0 / 5</span>`：位置 (400, 450)，居中对齐
  - `<button id="scene1-btn-next">下一步 ▶</button>`：位置 (460, 450)
- 教师操作流程：教师点击“下一步”按钮，图示依次展示夏至、冬至、秋分、季节过渡及南北半球差异，配合题目的5个小问进行逐一讲解。

[技术实现]
- JS 库选择：原生 SVG。地球公转和几何光照图非常适合使用 SVG 的 `transform` 属性来实现。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  +-------------------------+-------------------+
  |                         |                   |
  |          b              |   [特写面板]      |
  |       /     \           |                   |
  |      /       \          |    (大地球)       |
  |    c    太阳   a        |    光线/阴影      |
  |      \       /          |                   |
  |       \     /           |    [结论文本]     |
  |          d              |                   |
  |                         |                   |
  +-------------------------+-------------------+
  |        [◀ 上一步]  步骤 1/5  [下一步 ▶]       |
  +---------------------------------------------+
  ```
- 关键实现要点：
  - **大地球的倾斜**：将大地球的轮廓、经纬线、地轴放入一个 `<g id="scene1-big-earth-group">` 中。在步骤1、2、5中，应用 `transform="rotate(23.5, 640, 220)"` 使其向右倾斜；在步骤3中，应用 `transform="rotate(0, 640, 220)"` 使其竖直。
  - **光线与直射点**：由于地球组整体旋转了23.5°，水平光线 `y=220` 射入时，在视觉上会自动精确对准旋转后的回归线（数学上完美契合）。无需手动计算倾斜后的交点坐标。
  - **夜半球阴影**：阴影 `<path>` 不放入旋转组中，而是固定在外部。步骤1（光从右来）阴影在左半边 `M 640 140 A 80 80 0 0 0 640 300 Z`；步骤2、3（光从左来）阴影在右半边 `M 640 140 A 80 80 0 0 1 640 300 Z`。
  - **状态机**：使用一个 `currentStep` 变量记录当前步骤 (0-5)，每次点击按钮更新变量并调用 `updateScene()` 函数，该函数通过修改 SVG 元素的 `display`、`opacity`、`transform` 和文本内容来切换状态。
  - **ID 命名规范**：所有元素 ID 严格以 `scene1-` 开头。
  - **IIFE 隔离**：所有 JS 代码封装在 `(function() { ... })()` 中。
