- 步骤2：点击「下一步」→ 在EDF曲线上方区域（多边形）填充斜线阴影，明确表示夜半球范围。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：在SVG底部（y=460）居中放置两个按钮："上一步"和"下一步"，用于控制步骤切换。
- 教师操作流程：教师首先展示基础图形，提问晨昏线的性质；点击下一步，展示晨线和自转方向，讲解昼夜交替；再次点击，展示夜半球范围，帮助学生建立空间感；最后点击，展示极圈内的极昼极夜现象，推导出冬至日结论。

[技术实现]
- JS 库选择及原因：原生 SVG。图形主要由直线、多边形和文本组成，SVG的DOM操作和`<pattern>`填充非常适合实现斜线阴影和高亮动画。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×450]
    (顶部) 节气结论
    (中间) 经纬网及昼夜半球图示
    (底部) 自转箭头
  [控件栏 800×50]
    [上一步] [下一步]
  ```
- 关键实现要点：
  - 使用 `<pattern>` 定义夜半球的斜线阴影。
  - 状态机设计：定义 `currentStep` 变量（0-3），每次点击按钮更新变量并调用 `updateScene()` 函数。
  - `updateScene()` 根据当前步骤控制各元素的 `opacity` 或 `display` 属性，实现平滑过渡（可添加 `transition: opacity 0.3s`）。
  - ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-night-shadow`、`scene1-btn-next`）。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
