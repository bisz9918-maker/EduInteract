[图示主题与整合说明]
- 本图示主题：经纬网图的半球定位与方向判断
- 整合的步骤/概念：纬度/经度判读、东西半球划分、经纬网上的方向变化（特别是大圆航线/直线在投影图上的方向连续变化）。
- 教学价值：教师可通过分步导航，先引导学生根据数值递增方向判断南北半球和东西经，再通过展开的数轴直观判断东西半球。最后，通过在关键点引入局部方向坐标系，完美破解“水平直线为何是先东北再东南”的视觉难点，将抽象的投影变形具象化。

[视觉元素清单]
- 基础经纬网：5条经线（直线），3条纬线（以(400,-100)为圆心的圆弧）。颜色 #000000，线宽 1px。
- 关键点：A, B, C, D 四个实心圆点（#000000），及对应字母标签。
- 虚线 BD：连接 B 和 D 的水平虚线（#000000，线宽 2px，stroke-dasharray="5,5"）。
- 递增箭头：蓝色（#1565c0），带有文本标签。
- 东西半球数轴：底部水平线，包含刻度（160°E, 180°, 160°W），西半球区间加粗标蓝（#1565c0）。
- 辅助方向系：灰色虚线箭头（#888888），用于在 B 点和 M 点（180°交点）指示局部的正北/正南/正东。
- 主方向箭头：红色实线箭头（#c62828），覆盖在虚线 BD 上。
- 结论文本：分布在顶部和底部空白区域。

[分步序列]
- 初始状态（步骤0）：显示基础经纬网、A/B/C/D四个点及其标签、虚线BD。隐藏所有辅助线、箭头和结论文本。
- 步骤1（南北半球）：高亮纬度标签（20°, 30°, 40°）为蓝色。右侧出现向上的蓝色箭头，标签“N (北纬)”。顶部出现文本“纬度向北递增 → 北半球”。
- 步骤2（经度判读）：高亮经度标签（170°, 180°, 170°）为蓝色。底部出现向左的“向东递增 (E)”和向右的“向西递增 (W)”蓝色箭头。
- 步骤3（东西半球）：底部出现半球数轴。160°E 到 160°W 区间高亮为蓝色，标注“西半球”。170°E 和 170°W 的标签向下引出虚线投影到数轴上。显示结论“A,B,C,D 均位于西半球，【小题1】错误 ❌”（红色）。
- 步骤4（方向-前半程）：在 B 点出现灰色辅助坐标系（向北、向东）。虚线 BD 的前半段（B 到 180°经线交点 M）被红色主箭头覆盖，标签“东北”。（视觉上水平向右的箭头正好位于向北和向东的辅助线之间）。
- 步骤5（方向-后半程）：在 M 点（400, 286.4）出现灰色辅助坐标系（向南直线、向东沿纬线弯曲的曲线）。虚线 BD 的后半段（M 到 D）被红色主箭头覆盖，标签“东南”。（视觉上水平向右的箭头正好位于向东上弯曲线和向南直线之间）。顶部出现结论“前进方向：先向东北，再向东南。【小题2】正确 ✔️”（绿色）。

[标签冲突检查]
- 40°标签 (515, 75) vs 顶部结论文本 (400, 40)：文本居中，y轴错开，无冲突。
- A标签 (310, 180) vs B点辅助北箭头 (296.5, 286.4 至 312, 228)：箭头最高点在 y=228，A标签在 y=180，垂直间距充足，无冲突。
- 180°标签 (400, 340) vs M点辅助南箭头 (400, 286.4 至 400, 325)：箭头最低点在 y=325，标签在 y=340，无冲突。
- E/W 递增箭头 (y=370) vs 数轴 (y=430)：垂直间距 60px，无冲突。
- 东北标签 (350, 275) vs 主箭头 (y=286.4)：标签在箭头上方，无冲突。

[交互方案]
- 交互类型：分步按钮导航。
- 控件说明：在 SVG 容器底部（y=460~490 区域）居中放置两个按钮：“◀ 上一步” 和 “下一步 ▶”。
- 教师操作流程：教师点击“下一步”逐步揭示南北半球判断、东西经判断、半球定位数轴，最后分两步拆解复杂的方向变化，利用局部坐标系化解视觉错觉。

[技术实现]
- JS 库选择：原生 SVG。经纬网的圆弧、直线以及辅助曲线箭头均可通过精确的 SVG `<path>` 和 `<line>` 实现，无需引入庞大的外部库。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  (400, 40): 步骤1/5 结论文本区
  (200~600, 60~300): 主经纬网图及方向箭头
  (150~650, 430): 步骤3 东西半球数轴区
  (400, 475): [◀ 上一步] [下一步 ▶] 控件区
  ```
- 关键实现要点：
  1. 纬线弧使用 SVG Path 的 `A` (Arc) 指令或直接计算多点连线，为简便且精确，建议使用 `A` 指令：`M x1 y1 A r r 0 0 0 x2 y2`（注意 sweep-flag 的设置以确保弧线向下凸出，即开口向上）。
  2. 步骤5的“向东辅助曲线”使用二次贝塞尔曲线 `Q` 指令：`M 400 286.4 Q 430 286.4 460 281.7`，完美模拟纬线在该点的切线弯曲趋势。
  3. 状态机设计：定义 `currentStep` (0-5)，每次点击按钮更新变量并调用 `updateScene()`，通过修改 SVG 元素的 `opacity` 或 `display` 属性控制元素的显隐。
  4. ID 命名规范：所有元素 ID 必须以 `scene1-` 开头（如 `scene1-grid-lat20`，`scene1-btn-next`），确保多场景整合时不冲突。所有 JS 代码封装在 IIFE 中。
