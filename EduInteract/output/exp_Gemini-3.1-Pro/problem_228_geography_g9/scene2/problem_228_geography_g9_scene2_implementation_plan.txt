[图示主题与整合说明]
- 本图示主题：直射点纬度与昼夜长短计算
- 整合的步骤/概念：极昼范围判断、直射点纬度计算、日落时间与昼夜长短关系
- 教学价值：教师可以通过分步演示，引导学生从晨昏线的空间几何特征（相切点纬度）推导直射点纬度，再将二维地图上的单点（A点）提取为一维时间轴，直观计算昼夜长短，化抽象为具象。

[分步序列]
- 初始状态（步骤0）：显示主图网格、阴影区、黑夜区、晨昏线、点A/B/O及基础标签。高亮O点（红色填充）及70°S纬线（红色虚线加粗）。
- 步骤1：点击「下一步」→ 出现极昼区高亮（70°S以南矩形），显示标签“极昼区”。
- 步骤2：点击「下一步」→ 在主图下方出现直射点计算公式“直射点纬度 = 90° - 70° = 20°S”，并在主图左侧出现红色箭头和“直射点 20°S”标记。
- 步骤3：点击「下一步」→ 在下方出现“A点(23.5°S)”的时间轴（0:00至24:00），标出4:00、12:00、20:00的刻度。同时主图中的A点及20:00标签产生闪烁或高亮，建立空间到时间的联系。
- 步骤4：点击「下一步」→ 时间轴上高亮昼弧（红色）和夜弧（蓝色），出现半昼长方形括号及“半个昼长 = 8h”，并在底部显示最终结论“昼长 = 8h × 2 = 16h”和“夜长 = 24h - 16h = 8h”。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：底部居中放置两个按钮，控制步骤0-4的切换。
- 教师操作流程：教师首先引导学生观察O点特征，点击下一步展示极昼区；再点击下一步推导直射点纬度；接着点击下一步将视线转移到A点并展开时间轴；最后点击下一步完成昼夜长短的计算。

[技术实现]
- JS 库选择及原因：原生 SVG。地理图形和线段图均为规则几何图形，SVG 易于实现精确的坐标控制、样式修改和动画过渡。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  |------------------------------------------------|
  |               20:00   0:00   6:00              |
  | 直射点 20°S -> +-------+------+------+ 0°      |
  |                |   A   | Night|      | 23.5°S  |
  |                |    \  |  /   |      |         |
  |                +-------O------+------+ 70°S    |
  |                |    极昼区           |         |
  |                                                |
  |          直射点纬度 = 90° - 70° = 20°S         |
  |                                                |
  | A点(23.5°S):                                   |
  |      0:00   4:00    12:00   20:00   24:00      |
  |       |------|--------|-------|-------|        |
  |                                                |
  |               昼长 = 16h, 夜长 = 8h            |
  |------------------------------------------------|
  [控件栏 y=450~490, 包含 上一步/下一步 按钮]
  ```
- 关键实现要点：
  - 状态机设计：定义 `currentStep` 变量，通过 `updateStep()` 函数控制各元素的 `display` 或 `opacity` 属性。
  - 坐标计算：严格按照布局坐标表中的像素值绘制 SVG 元素，确保无重叠。
  - 动画过渡：为极昼区高亮、时间轴展开等元素添加 CSS `transition: opacity 0.5s ease` 实现平滑过渡。
  - ID 命名规范：所有交互元素 ID 必须以 `scene2-` 为前缀（如 `scene2-polar-day`, `scene2-time-axis`）。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
