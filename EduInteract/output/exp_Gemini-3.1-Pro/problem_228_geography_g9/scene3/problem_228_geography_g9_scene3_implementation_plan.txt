[图示主题与整合说明]
- 本图示主题：正午太阳高度角的周年变化
- 整合的步骤/概念：太阳直射点在南北回归线间的连续移动，以及特定纬度（23.5°S）正午太阳高度角的动态变化关系。
- 教学价值：教师可通过拖动滑块，直观演示太阳直射点纬度变化时，阳光入射角度与地平面的夹角（正午太阳高度角）如何随之改变，帮助学生理解直射点移动与高度角变化的几何关系。

[视觉元素清单]
- 地球半圆：`fill="none" stroke="#000000" stroke-width="2"`
- 纬线及地轴：`stroke="#000000"`，回归线及地轴使用 `stroke-dasharray="4,4"`
- A点及地平面：`fill="#1565c0"` (点)，`stroke="#1565c0" stroke-width="3"` (地平面)
- 太阳光线：`stroke="#c62828" stroke-width="2"`，末端使用 `<marker>` 箭头
- 高度角圆弧及文本：`stroke="#2e7d32" fill="none"` (圆弧)，`fill="#2e7d32"` (文本)
- 文本标签：字体大小 14px-16px，颜色与对应元素一致。

[分步序列]
- 交互状态：连续拖拽滑块（值 0~100，对应直射点纬度 23.5°N ~ 23.5°S）
- 初始状态（状态A，滑块值100）：直射点在 23.5°S。太阳光线自右向左上方倾斜入射，南光线直射A点，高度角圆弧最大，显示 H = 90.0°。
- 滑动过程：向左拖动滑块，直射点北移。太阳光线倾角逐渐改变，A点高度角圆弧逐渐变小，H数值实时减小。
- 最终状态（状态B，滑块值0）：直射点在 23.5°N。太阳光线自右向左下方倾斜入射，A点高度角圆弧最小，显示 H = 43.0°。

[标签冲突检查]
- "0°" (170,225) / "23.5°N" (140,161) / "23.5°S" (140,288)：位于地轴左侧空白区，互不干扰。
- "A" (325,295)：位于地球内部，南回归线下方，地平面左侧，无冲突。
- "太阳光线"标签：绑定在中间光线起点左上方 (x-20, y-10)，随光线移动，始终位于画布右侧空白区，无冲突。
- "H = ..." 文本：位于 A 点右上角角平分线上 (距离60px)，始终处于中间光线与南光线之间，完美避开光线与地平面，无冲突。

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：在 SVG 底部 (y=450) 放置一个 `<input type="range">` 滑块，范围 0-100，初始值 100。
- 教师操作流程：教师在讲解时，缓慢拖动底部滑块，引导学生观察太阳光线倾斜角度的变化，以及 A 点正午太阳高度角 H 的同步变化，直观得出直射点距离 A 点越远、高度角越小的结论。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。几何图形简单，原生 SVG 的 `<path>` 和 `<line>` 配合 JS 即可实现高效的 DOM 属性更新，无需引入庞大库。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  左侧：地球右半圆及纬线
  右侧：三条平行的红色太阳光线射向地球
  A点：南回归线与地球边缘交点，带有蓝色地平面和绿色角度标注
  左上角：动态信息面板
  [控件栏]
  底部居中：直射点纬度调节滑块
  ```
- 关键实现要点：
  1. 坐标系与角度：SVG 中 y 轴向下。直射点纬度 δ 范围 [23.5, -23.5]。光线方向向量为 (-cosδ, sinδ)，起点坐标需根据终点反推。
  2. 圆弧绘制：使用 SVG `<path>` 的 `A` 指令。起点固定为地平面方向 -66.5°，终点方向为 -δ。由于角度差始终在 [43°, 90°] 范围内，`large-arc-flag` 始终为 0，`sweep-flag` 始终为 1。
  3. 动态更新：监听滑块的 `input` 事件，实时计算 δ、光线起点坐标、圆弧终点坐标及 H 值，并更新对应 DOM 元素的属性。
  4. ID 命名规范：所有交互元素 ID 必须以 `scene3-` 为前缀（如 `scene3-slider`, `scene3-ray-a`）。
  5. IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
