[视觉元素清单]
- 基础经纬网：黑色 2px 线条，包含5条经线（直线）和4条纬线（圆弧）。
- 经纬度标签：黑色文本，14px。
- 关键点：黑色圆点，半径 4px，附带黑色点名标签。
- 动态箭头：红色 #c62828，2px，带箭头端点。
- 坐标提示文本：红色 #c62828，14px，带圆角背景框。
- 十字方向标：灰色 #888888，虚线，附带 N/S/W/E 灰色小标签。
- 区域填充：东半球绿色 #2e7d32 (20%透明度)，西半球蓝色 #1565c0 (20%透明度)。
- 范围边框：东经度红色 #c62828，3px 粗实线。

[分步序列]
- 初始状态（步骤0）：显示基础经纬网、已知标签（140°E, 180°, 140°W, 60°N, 40°N）和点 A, D, E, F。动态浮现隐藏的经纬度数值（160°E, 160°W, 50°N, 70°N）。出现红色纬度递增箭头及文本“向北度数增大为北纬(N)”，出现红色经度递减弧形箭头及文本“向东越过180°经线度数减小”。
- 步骤1（读取坐标）：隐藏步骤0的红色箭头和文本。高亮 D, E, F 所在的经纬线（加粗并变为红色）。在 D, E, F 点旁边浮现坐标值文本框：D(60°N, 140°E), E(40°N, 160°E), F(50°N, 160°W)。
- 步骤2（判断方向）：隐藏步骤1的坐标文本框，恢复经纬线默认样式。在 A 点和 F 点出现灰色十字方向标。绘制从 A 指向 D 的红色虚线箭头，显示“西北”；绘制从 F 指向 E 的红色虚线箭头，显示“西南”。
- 步骤3（经线圈）：隐藏步骤2的方向标和箭头。高亮 180° 经线（红色加粗），旁边出现文字提示“对立经线为0°”。
- 步骤4（半球与范围）：隐藏步骤3的提示。用绿色半透明色块覆盖东半球部分（140°E-160°E），用蓝色半透明色块覆盖西半球部分（160°E-140°W），显示文本“大部分位于西半球”。然后用红色粗边框框出东经度范围（140°E-180°），在重叠区域显示文本“交集：160°E - 180°”。

[交互方案]
- 交互类型：分步按钮导航
- 控件说明：在 SVG 内部底部（y=450~490）居中放置两个按钮：“◀ 上一步” 和 “下一步 ▶”。
- 教师操作流程：教师点击“下一步”依次展示读图规律、坐标读取、方向判断、经线圈概念、半球与范围的交集。每一步都配合图形变化进行讲解，可随时点击“上一步”回退。

[技术实现]
- JS 库选择：原生 SVG。经纬网的圆弧和直线非常适合用 SVG 的 `<path>` 和 `<line>` 标签实现，且易于应用 CSS 动画和透明度填充。
- 画布尺寸：800 × 500 px。
- 布局草图：
  [图示区 800×450]
  [控件栏 800×50，包含上一步/下一步按钮]
- 关键实现要点：
  1. 坐标系映射：以 (400, -50) 为极点圆心，使用极坐标公式 `x = cx + r * cos(angle)`, `y = cy + r * sin(angle)` 计算所有交点坐标。
  2. SVG 路径构建：使用 `M x y A rx ry x-axis-rotation large-arc-flag sweep-flag x y` 构建纬线圆弧。注意 sweep-flag 的设置以确保圆弧方向正确。
  3. 状态机设计：定义 `currentStep` 变量（0-4），编写 `updateStep()` 函数，根据当前步骤控制各个 SVG 元素的 `display` 或 `opacity` 属性，实现平滑过渡。
  4. 区域填充：步骤4中的色块使用 `<path>` 闭合路径实现，例如东半球区域路径由 70°N 圆弧、160°E 直线、40°N 圆弧（反向）、140°E 直线组成。
  5. ID 命名规范：所有元素 ID 必须以 `scene1-` 为前缀，例如 `scene1-grid-140e`, `scene1-btn-next`。
  6. IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
