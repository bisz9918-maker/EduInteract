[图示主题与整合说明]
- 本图示主题：不同连接方式下的电化学装置动态演示
- 整合的步骤/概念：整合了原电池（导线连接）、电解池（Fe作阳极）、电解池（Cu作阳极）三种情况的微观原理。
- 教学价值：教师可以通过切换不同的电路连接状态，直观地向学生展示电子流向、溶液中离子的迁移方向、电极反应以及溶液颜色的变化，帮助学生深刻理解原电池与电解池的本质区别及工作原理。

[视觉元素清单]
- 烧杯：黑色实线轮廓，带杯沿。
- 溶液：初始为蓝色（#1565c0，透明度20%），状态1和2变为浅绿色（#2e7d32，透明度20%），状态3保持蓝色。
- 电极：Cu电极填充浅铜色（#bcaaa4），Fe电极填充浅灰色（#9e9e9e），黑色边框。
- 外部电路：黑色实线，中央包含一个可切换的组（电流计A 或 直流电源符号）。
- 离子及箭头：
  - Cu²⁺：蓝色（#1565c0），带移动方向箭头。
  - SO₄²⁻：红色（#c62828），带移动方向箭头。
  - Fe²⁺：绿色（#2e7d32），带移动方向箭头。
- 电子e⁻：红色（#c62828），带水平箭头指示流向。
- 文本标签：黑色，字体大小适中，反应式使用较大字号。

[分步序列]
- 初始状态（步骤0）：显示烧杯、溶液（蓝色）、两电极、断开的导线。离子在溶液中静止，无反应式和电子流向。
- 状态1（点击「导线连接 (原电池)」）：
  - 仪表变为电流计（圆圈内加A）。
  - 电子e⁻箭头向左（Fe流向Cu）。
  - Cu²⁺向左移动至Cu极，SO₄²⁻向右移动至Fe极，Fe²⁺在Fe极生成并向左移动。
  - 溶液颜色平滑过渡为浅绿色。
  - 左侧显示：正极: Cu²⁺ + 2e⁻ = Cu，状态"析出 Cu"。
  - 右侧显示：负极: Fe - 2e⁻ = Fe²⁺，状态"溶解"。
- 状态2（点击「b接正极 (电解池)」）：
  - 仪表变为直流电源，b侧长线（+），a侧短线（-）。显示"+"在(480,25)，"-"在(320,25)。
  - 电子e⁻箭头向左（Fe流向正极，负极流向Cu）。
  - 离子移动、溶液颜色变化、右侧生成Fe²⁺同状态1。
  - 左侧显示：阴极: Cu²⁺ + 2e⁻ = Cu，状态"析出 Cu"。
  - 右侧显示：阳极: Fe - 2e⁻ = Fe²⁺，状态"溶解"。
- 状态3（点击「a接正极 (电解池)」）：
  - 仪表变为直流电源，a侧长线（+），b侧短线（-）。显示"+"在(320,25)，"-"在(480,25)。
  - 电子e⁻箭头向右（Cu流向正极，负极流向Fe）。
  - Cu²⁺向右移动至Fe极，SO₄²⁻向左移动至Cu极，新生Cu²⁺在Cu极生成并向右移动。
  - 溶液颜色恢复/保持蓝色。
  - 左侧显示：阳极: Cu - 2e⁻ = Cu²⁺，状态"溶解"。
  - 右侧显示：阴极: Cu²⁺ + 2e⁻ = Cu，状态"析出 Cu"。

[标签冲突检查]
- "a"标签(300,50) 与 电源"-"标签(320,25)：间距约32px，无冲突。
- "b"标签(500,50) 与 电源"+"标签(480,25)：间距约32px，无冲突。
- 左侧反应式(130,250) 与 烧杯左壁(250)：间距充足，无重叠。
- 右侧反应式(670,250) 与 烧杯右壁(550)：间距充足，无重叠。
- 溶液中离子：Cu²⁺(y=260)、Fe²⁺(y=280)、SO₄²⁻(y=320)，垂直方向错开20-40px，水平移动时不会相互遮挡。

[交互方案]
- 交互类型：多状态切换（3个按钮）。
- 控件说明：在SVG底部（y=460）放置三个按钮："导线连接 (原电池)"、"b接正极 (电解池)"、"a接正极 (电解池)"。
- 教师操作流程：教师点击不同按钮，图示平滑切换到对应状态，动态展示微观粒子的运动和宏观颜色的变化，辅助讲解不同电路条件下的电极反应差异。

[技术实现]
- JS 库选择：原生 SVG + CSS Transitions + 原生 JavaScript。SVG 适合绘制清晰的几何图形和文本，CSS Transitions 可以轻松实现离子平移和溶液颜色的平滑过渡。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×450]
    (左侧反应式)    (外部电路及电子)    (右侧反应式)
                    (烧杯及电极)
                    (溶液及离子)
  [控件栏 800×50，3个按钮居中排列]
  ```
- 关键实现要点：
  - 使用 `<g>` 标签对离子和箭头进行分组，通过修改 `transform="translate(x, y)"` 和 `opacity` 来控制离子的位置和显示/隐藏。
  - 溶液颜色使用 `<rect>` 的 `fill` 属性，并添加 `style="transition: fill 1s ease;"` 实现平滑变色。
  - 状态切换时，先重置所有元素的初始位置和透明度，然后根据目标状态设置新的属性，触发 CSS 动画。
  - ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-solution`, `scene1-ion-cu2`）。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
