[分步序列]
- 初始状态（步骤0）：显示主晶胞（边长160，原点280,340），8个顶点交替分布A、B离子。右侧显示图例。
- 步骤1：点击「下一步」→ 8个顶点出现红色高亮光晕，各顶点外侧淡入"1/8"标签。右侧文本面板淡入均摊法计算过程，得出红色结论“化学式: AB”。
- 步骤2：点击「下一步」→ 隐藏Step1高亮与标签。左下角A离子(V0)出现红色轮廓，当前晶胞内与其相连的3个B离子(V1,V2,V4)出现蓝色轮廓，3条连接棱加粗变蓝。右侧文本更新为“当前晶胞内：与A直接相连的B离子有 3 个”。
- 步骤3：点击「下一步」→ 触发平滑3D动画，主晶胞缩小至0.6倍并向右上平移（原点移至400,220）。淡入左、下、后三个方向的相邻晶胞虚线框，淡入沿坐标轴负方向的3个新B离子。这3个新B离子出现蓝色轮廓，新增3条蓝色连接棱。右侧文本更新为“空间扩展后：新增 3 个B离子，配位数 = 6”。

[标签冲突检查]
- 标签"A" (V0) 与 棱：V0在Step3有6条相连棱，标签设于右下(15,15)，完美避开所有棱。
- 标签"B" (V1) 与 棱：V1标签设于右下(15,15)，避开左、上、右上三条棱。
- 标签"1/8" (V1) 与 标签"B"：若"1/8"设于右下会与"B"重叠。解决方案：将V1的"1/8"移至左下(-20,20)。
- 标签"1/8" (V3) 与 棱：V3有右上(+z)走向的棱，若标签设于右上会与棱重叠。解决方案：将V3的"1/8"移至右下(20,20)。
- 其他"1/8"标签：V0左下(-20,20)、V2左上(-20,-20)、V4左上(-20,-20)、V5右下(20,20)、V6左上(-20,-20)、V7右上(20,-20)，均已避开各自相连的棱，无冲突。
- 扩展晶胞 与 控件区：Step3扩展后最低点y坐标为316，远高于控件区(y=440)，无冲突。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：底部居中放置两个按钮，控制 step 变量 (0~3)。
- 教师操作流程：教师首先展示单晶胞结构，点击下一步讲解均摊法计算化学式；再点击下一步聚焦中心A离子，数出晶胞内的3个近邻；最后点击下一步，通过震撼的3D扩展动画，展示完整的6配位空间结构。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。SVG 极适合绘制带层级的几何线框和节点，原生 JS 可轻松实现 3D 坐标到 2D 的投影计算与平滑动画。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +-------------------------------------------------+
  |                                                 |
  |           [主晶胞/扩展晶胞区]      [图例区]     |
  |                (动态3D投影)        [文本面板]   |
  |                                                 |
  |                                                 |
  |                                                 |
  |             [ ◀上一步 ] [ 下一步▶ ]             |
  +-------------------------------------------------+
  ```
- 关键实现要点：
  1. 3D投影函数：`px = originX + (x + z*0.5)*scale`, `py = originY - (y + z*0.5)*scale`。
  2. 状态驱动渲染：定义 `state = { step: 0, scale: 1.0, originX: 280, originY: 340 }`。
  3. 动画引擎：使用 `requestAnimationFrame` 实现 `tween` 函数，在 Step2 和 Step3 切换时，平滑插值 `scale`, `originX`, `originY`，每帧调用 `updatePositions()` 更新所有 SVG 元素的坐标，实现丝滑的 3D 视角变换。
  4. DOM层级：严格控制 SVG 内部元素的先后顺序：扩展虚线框 < 主晶胞黑线 < 高亮蓝/红粗线 < 高亮光晕 < 黑白球体 < 文本标签，确保视觉遮挡关系正确。
  5. ID 命名规范：所有元素 ID 均以 `scene2-` 开头。
  6. IIFE 隔离：所有逻辑封装在 `(function() { ... })()` 中。
