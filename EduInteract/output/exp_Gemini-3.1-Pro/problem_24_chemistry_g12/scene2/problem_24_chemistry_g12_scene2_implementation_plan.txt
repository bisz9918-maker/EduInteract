[图示主题与整合说明]
- 本图示主题：甲与乙的恒容与恒压平衡对比
- 整合的步骤/概念：展示恒容与恒压条件下的反应过程，通过“等效加压”的思维模型，将恒压过程拆解为恒容反应加压的过程，从而直观推导出平衡移动的结果及各物理量的对比。
- 教学价值：帮助学生建立“等效平衡”的动态思维，将复杂的恒压问题转化为熟悉的恒容问题加压，直观理解体积、压强、浓度和转化率之间的逻辑关系。

[分步序列]
- 初始状态（步骤0）：显示甲、乙容器初始状态。甲指针竖直，乙活塞在y=90。内部填充红色透明，文本为"0.2 mol NO₂"。隐藏步骤2-4元素。
- 步骤1：点击「下一步」→ 反应进行。甲指针逆时针旋转30°，内部变为蓝色透明(0.1)，文本变"平衡状态 A"。乙活塞下移至y=130，重物下移至y=114，内部变为蓝色透明(0.15)，文本下移至y=194并变"平衡状态 B"。
- 步骤2：点击「下一步」→ 等效加压。显示乙容器原高度的虚线(y=98)，右侧出现向下箭头及"加压"字样。中央出现绿色结论"等效分析：乙的过程 = 先达到甲的平衡，再加压压缩至恒压"。
- 步骤3：点击「下一步」→ 平衡移动。甲下方依次淡入显示："加压导致平衡正向移动"、"N₂O₄%：乙 > 甲"、"平均相对分子质量 M：乙 > 甲"。
- 步骤4：点击「下一步」→ 浓度对比。乙下方依次淡入显示："体积缩小导致浓度整体上升"、"c(NO₂)：乙 > 甲"。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：底部居中放置两个按钮，控制 currentStep (0~4)。

[技术实现]
- JS 库选择及原因：原生 SVG。图形简单，原生 SVG 配合 CSS transition 可完美实现平滑动画（如活塞下移、指针旋转、颜色渐变）。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
         (方程式)
   [甲容器]      [乙容器] <-(加压)
    (标签)        (标签)
           (等效说明)
   [结论3]       [结论4]
  [控件栏 ◀上一步 下一步▶]
  ```
- 关键实现要点：
  - 使用 `style="transition: all 0.8s ease;"` 实现 SVG 属性的平滑过渡。
  - 状态机设计：定义 `updateStep(step)` 函数，根据 step 值更新各元素的 `opacity`, `y`, `height`, `transform`, `fill` 等属性。
  - ID 命名规范：严格使用 `scene2-` 前缀，如 `scene2-jia-fill`, `scene2-yi-piston`。
  - IIFE 隔离：所有逻辑封装在 `(function() { ... })()` 中。
