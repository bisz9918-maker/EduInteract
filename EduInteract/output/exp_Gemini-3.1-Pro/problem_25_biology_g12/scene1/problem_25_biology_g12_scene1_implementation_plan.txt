[分步序列]
- 初始状态（步骤0）：显示 P 世代（图标、表现型、杂交符号）、P 到 F1 的连线、F1 世代（图标、表现型），以及右侧结论框 1（"直刚毛为显性，卷刚毛为隐性"）。
- 步骤1：点击「下一步」→ 显示 F1 的杂交符号、F1 到 F2 的连线、F2 世代（图标、表现型及比例）。
- 步骤2：点击「下一步」→ 出现雌性高亮框（框住 F2 直雌）和雄性高亮框（框住 F2 直雄和卷雄），同时显示右侧结论框 2（"性状表现与性别相关，基因位于X染色体上"）。
- 步骤3：点击「下一步」→ 补全所有个体（P, F1, F2）下方的基因型文本，完成完整的遗传图解。

[交互方案]
- 交互类型：分步按钮导航
- 控件说明：在 SVG 内部底部 (y=460) 居中放置两个按钮：「◀ 上一步」和「下一步 ▶」。
- 教师操作流程：教师首先展示亲本杂交产生 F1 的现象，引导学生得出显隐性结论；点击下一步展示 F2 结果；再次点击下一步高亮雌雄差异，引导学生推断伴性遗传；最后点击下一步展示基因型，完成微观机制的解释。

[技术实现]
- JS 库选择：原生 SVG。遗传图解主要由简单的几何图形（圆、线、文本）构成，原生 SVG 性能好且易于精确控制坐标和样式。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  左侧：世代标签 (P, F1, F2)
  中部：杂交树状图 (P -> F1 -> F2)
  右侧：结论框
  底部：[◀ 上一步] [下一步 ▶] (y=460)
  ```
- 关键实现要点：
  1. 状态机设计：定义全局变量 `currentStep = 0`，最大值为 3。
  2. 元素分组：将属于不同步骤的 SVG 元素放入对应的 `<g>` 标签中，并分配特定的 class（如 `step1-element`, `step2-element`）。
  3. 动画与过渡：通过 JS 修改元素的 `opacity` 属性，配合 CSS `transition: opacity 0.5s ease` 实现平滑的淡入淡出效果。
  4. 上标实现：基因型中的上标使用 `<tspan baseline-shift="super" font-size="10">` 实现，并通过 `fill` 属性对显隐性基因进行红蓝染色。
  5. ID 命名规范：所有交互元素和分组 ID 必须以 `scene1-` 为前缀（如 `scene1-btn-next`, `scene1-group-step1`）。
  6. IIFE 隔离：所有 JS 逻辑封装在 `(function() { ... })()` 中，避免全局变量污染。
