[图示主题与整合说明]
- 本图示主题：学生测交实验方案的局限性分析
- 整合的步骤/概念：将题目原图的伴X染色体遗传测交图解，与常染色体遗传假说下的测交图解进行平行对比。
- 教学价值：教师可通过切换两种假说的推导过程，直观展示无论基因在X染色体还是常染色体上，该测交实验（F1直雌 × F2卷雄）的后代均会出现 1:1:1:1 的性状分离比。从而引导学生得出结论：该实验方案无法验证基因的具体位置，具有局限性。

[视觉元素清单]
- 伴X假说组（左侧）：包含标题、行标签、亲本、配子、子代及连线。文字和连线主色调为 #1565c0（蓝色）。
- 常染色体假说组（右侧）：包含标题、行标签、亲本、配子、子代及连线。文字和连线主色调为 #2e7d32（绿色）。
- 连线箭头：从亲本到配子（短直线），从配子到子代（交叉线）。使用带有 `marker-end` 的 SVG `<line>` 绘制。
- 对比高亮框：两个无填充、红色边框（#c62828, stroke-width: 2）的矩形，用于强调相同的比例。
- 结论文本：红色（#c62828），居中显示“结论：两种假说下，测交后代均出现 1:1:1:1 的性状分离比，因此该测交实验无法区分基因位置。”

[分步序列]
- 初始状态（状态1）：仅显示“伴X假说组”（左侧）。右侧内容、红框、结论文本均隐藏。底部“伴X假说”按钮高亮。
- 状态2：点击“常染色体假说”按钮。隐藏左侧内容，仅显示“常染色体假说组”（右侧）。红框、结论文本隐藏。底部“常染色体假说”按钮高亮。
- 状态3：点击“对比结论”按钮。同时显示左侧和右侧内容，出现左右两个红色高亮框框住底部的“1:1:1:1”，并在下方弹出结论文本。底部“对比结论”按钮高亮。

[标签冲突检查]
- 左侧配子间距：85, 165, 235, 315。相邻间距 70-80px。配子文本宽度约 30px，间距充足，无冲突。
- 左侧子代表现型间距：同上。表现型文本（如“直刚毛”）宽度约 45px，间距 70-80px，无冲突。
- 左右两侧间距：左侧最右元素 x=315，右侧最左元素 x=430。中间留白 115px，无冲突。
- 连线与文本冲突：连线起点和终点均避开文本的 bounding box（如起点 y=120，终点 y=165，文本在 y=110 和 y=180），无遮挡。

[交互方案]
- 交互类型：多状态切换（3个状态按钮）。
- 控件说明：在 SVG 底部（y=460）放置三个 HTML `<button>`，分别为“伴X假说”、“常染色体假说”、“对比结论”。
- 教师操作流程：教师首先展示原题的伴X假说推导（状态1）；然后切换到常染色体假说（状态2），引导学生进行平行推导；最后点击对比结论（状态3），将两者并排展示，高亮相同的比例，得出实验方案存在局限性的结论。

[技术实现]
- JS 库选择：原生 SVG。遗传图解包含大量精确的文本定位和连线，SVG 是最合适的选择。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  |  伴X染色体假说 (左侧)   |   常染色体假说 (右侧)  |
  | 测交: X^AX^a × X^aY     | 测交: AaXX × aaXY      |
  | 配子: X^A X^a  X^a Y    | 配子: AX aX  aX aY     |
  | 后代: ...               | 后代: ...              |
  | 比例: [1 : 1 : 1 : 1]   | 比例: [1 : 1 : 1 : 1]  |
  |          结论：无法区分基因位置                |
  [控件栏：[伴X假说] [常染色体假说] [对比结论]]
  ```
- 关键实现要点：
  - 使用 `<g>` 标签将左侧元素、右侧元素、高亮结论元素分别编组，赋予 ID（如 `scene2-group-x`, `scene2-group-auto`, `scene2-group-conclusion`）。
  - 状态切换时，通过修改对应 `<g>` 标签的 `display` 属性（'none' 或 'block'）来实现显示/隐藏。
  - 上标文本（如 $X^A$）使用 SVG 的 `<tspan baseline-shift="super" font-size="0.7em">A</tspan>` 实现。
  - 连线箭头使用 `<defs>` 定义 `<marker id="scene2-arrow">`，并在 `<line>` 中通过 `marker-end="url(#scene2-arrow)"` 引用。
- ID 命名规范：所有交互元素和组 ID 必须以 `scene2-` 为前缀。
- IIFE 隔离：所有 JS 逻辑封装在 `(function() { ... })()` 中。
