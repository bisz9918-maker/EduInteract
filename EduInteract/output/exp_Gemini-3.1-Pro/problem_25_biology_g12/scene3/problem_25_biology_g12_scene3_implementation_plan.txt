[图示主题与整合说明]
- 本图示主题：设计验证伴X隐性遗传的正确测交实验
- 整合的步骤/概念：展示纯合卷雌与纯合直雄的测交方案，并分别推导在“伴X隐性遗传”和“常染色体隐性遗传”两种假说下的预期结果，通过对比子代表现型差异，验证该测交方案的有效性。
- 教学价值：教师可通过多状态切换，引导学生逐步推导不同假说下的遗传图解，最后通过高亮对比，直观展示伴X遗传特有的“交叉遗传”和“性别差异”特征，从而证明该实验设计的合理性。

[分步序列]
- 状态1（实验方案）：仅显示顶部的“实验方案：纯合卷刚毛雌果蝇 × 纯合直刚毛雄果蝇”。
- 状态2（伴X假说预期）：在状态1基础上，显示左侧的“伴X假说预期”完整遗传推导图解，并用蓝色虚线框出子代结果。
- 状态3（常染色体假说预期）：在状态2基础上，显示右侧的“常染色体假说预期”完整遗传推导图解，并用绿色虚线框出子代结果。
- 状态4（对比结论）：在状态3基础上，将左右两边的子代结果框变为红色加粗实线框，并在底部弹出红色结论文本“结论：伴X遗传子代有性别差异，常染色体遗传无差异，此方案可有效验证！”。

[交互方案]
- 交互类型：多状态切换（4个按钮）。
- 控件说明：在 SVG 底部 (y=460) 放置 4 个按钮：“1. 实验方案”、“2. 伴X假说预期”、“3. 常染色体预期”、“4. 对比结论”。
- 教师操作流程：教师首先点击状态1展示实验设计；接着点击状态2引导学生推导伴X假说下的结果；然后点击状态3推导常染色体假说下的结果；最后点击状态4，高亮对比两种结果的差异，得出结论。

[技术实现]
- JS 库选择及原因：原生 SVG。遗传图解主要由文本和直线箭头组成，原生 SVG 能够精确控制坐标和排版，且无需引入外部库，加载快，稳定性高。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
    (实验方案标题)
  (伴X推导区)    (常染色体推导区)
  [蓝框结果]      [绿框结果]
       (结论文本)
  [控件栏：4个状态切换按钮]
  ```
- 关键实现要点：
  - 使用 `<g>` 标签将不同状态的元素分组（如 `id="scene3-group-x-linked"`, `id="scene3-group-autosomal"`, `id="scene3-group-conclusion"`）。
  - 状态切换时，通过 JS 控制对应 `<g>` 组的 `display` 属性（'none' 或 'block'）。
  - 基因型中的上标直接使用 Unicode 字符（如 Xᵃ, Xᴬ），避免复杂的 tspan 定位。
  - 箭头使用 `<marker>` 定义箭头样式，附加在 `<line>` 元素上。
  - ID 命名规范：所有交互元素 ID 必须以 `scene3-` 为前缀（如 `scene3-btn-state1`）。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
