[视觉元素清单]

- 组合基因型与表现型：8行文本，对应分支结果
- 统计大括号：使用 SVG `<path>` 绘制平滑的贝塞尔曲线大括号

  - 辅助线（分支线）：#888888

  - 残翅相关高亮（表现型5-8，统计残翅，残翅大括号）：#2e7d32（绿色）

[分步序列]
- 初始状态（步骤0）：显示 P 世代标签、亲本基因型（残翅♀ aaX^BX^B、小翅♂ AAX^bY）及交配符号。
- 步骤1：点击「下一步」→ 显示配子标签及配子（aX^B、AX^b, AY），显示 F1 世代标签、F1 基因型（长翅♀ AaX^BX^b、长翅♂ AaX^BY）及交配符号。
- 步骤2：点击「下一步」→ 显示 F2 世代标签，以及常染色体分离结果（"3/4 A_" 和 "1/4 aa"）。
- 步骤3：点击「下一步」→ 显示分支线，以及性染色体分离结果（8个 "1/4 X..."）。
- 步骤4：点击「下一步」→ 显示等号、组合基因型、表现型、大括号及最终统计比例。表现型和统计文本按对应颜色高亮（蓝、红、绿），完美对应表格数据。

[标签冲突检查]
- P 雌性亲本 (200, 30) vs P 交配符号 (400, 30)：间距 200px，文本宽约 120px，无冲突。
- F2 常染色体 1 (100, 200) vs F2 性染色体 1 (250, 140)：X 间距 150px，分支线有充足空间，无冲突。
- 组合基因型 1 (370, 140) vs 表现型 1 (510, 140)：X 间距 140px，基因型文本宽约 100px，间距 40px，无冲突。
- 表现型 1 (510, 140) vs 统计长翅 (610, 180)：X 间距 100px，且 Y 轴错开，无冲突。
- F2 性染色体相邻行 (y=260 vs y=310)：Y 间距 50px，文本高约 20px，间距 30px，无冲突。
结论：所有元素均已分配独立区域，无重叠风险。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：在 SVG 底部（y=450~490）居中放置两个按钮，控制步骤 0~4 的切换。
- 教师操作流程：教师首先展示亲本，点击下一步推导配子和 F1；再点击下一步展示 F2 常染色体分离比；接着展示性染色体分离比；最后展示组合结果和表现型统计，并强调高亮颜色与题目表格数据的对应关系。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。遗传图解主要是文本和简单连线，SVG 的 `<text>` 和 `<path>` 能完美实现精确布局和高质量渲染。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  P:    残翅♀ aaX^BX^B      ×      小翅♂ AAX^bY
  配子:        aX^B                 AX^b, AY
  F1:   长翅♀ AaX^BX^b      ×      长翅♂ AaX^BY
  F2:
        3/4 A_  --- 1/4 X^BX^B  =  3/16 A_X^BX^B  长翅♀ }
                --- 1/4 X^BX^b  =  3/16 A_X^BX^b  长翅♀ } 9/16 长翅
                --- 1/4 X^BY    =  3/16 A_X^BY    长翅♂ }
                --- 1/4 X^bY    =  3/16 A_X^bY    小翅♂   3/16 小翅
        1/4 aa  --- 1/4 X^BX^B  =  1/16 aaX^BX^B  残翅♀ }
                --- 1/4 X^BX^b  =  1/16 aaX^BX^b  残翅♀ } 4/16 残翅
                --- 1/4 X^BY    =  1/16 aaX^BY    残翅♂ }
                --- 1/4 X^bY    =  1/16 aaX^bY    残翅♂ }
  [控件栏 ◀上一步 | 下一步▶]
  ```
- 关键实现要点：
  - 使用 `<g>` 标签将不同步骤的元素分组（如 `id="scene2-step1"`, `id="scene2-step2"` 等），通过 JS 控制 `display` 或 `opacity` 属性实现分步显示。
  - 文本中的上下标使用 `<tspan baseline-shift="super" font-size="0.7em">` 实现，确保基因型（如 X^B）显示专业美观。
  - 大括号使用 SVG `<path>` 的三次贝塞尔曲线（C 指令）绘制，确保平滑。
  - ID 命名规范：所有交互元素和分组 ID 必须以 `scene2-` 为前缀，避免冲突。
  - 脚本封装在 IIFE 中，确保变量不污染全局作用域。
