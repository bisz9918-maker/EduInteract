[视觉元素清单]
- 细胞轮廓：`stroke="#000000" stroke-width="2" fill="none"`
- 纺锤丝：`stroke="#888888" stroke-width="1"`，外侧两条加 `stroke-dasharray="4,4"`
- 染色体基础结构：使用两条二次贝塞尔曲线表示两条染色单体，底层粗线（`stroke-width="12"`）作为轮廓，顶层细线（`stroke-width="8"`）作为内部填充。
  - 白染色体内部：`stroke="#ffffff"`
  - 黑染色体内部：`stroke="#333333"`
- 基因标签（A, a, B）：初始 `fill="#000000" font-size="14"`，高亮时 `fill="#c62828" font-size="20" font-weight="bold"`
- SRY片段：初始 `stroke="#000000" stroke-width="2" fill="#ffffff"`，高亮时 `stroke="#c62828" stroke-width="3"`
- 左侧面板：背景 `#f1f8e9`，边框 `#2e7d32`
- 右侧面板：背景 `#e3f2fd`，边框 `#1565c0`

[分步序列]
- 初始状态（步骤0）：显示细胞轮廓、纺锤丝、4条染色体（黑色轮廓）、所有基因标签（黑色正常大小）。左右面板和底部结论隐藏。
- 步骤1：点击「下一步」→ 大白和大黑染色体轮廓变为绿色（`#2e7d32`），基因A和a放大并变红（`#c62828`）。左侧面板出现，显示“常染色体”、“等位基因: A, a”、“基因型: Aa”。
- 步骤2：点击「下一步」→ 小白和小黑染色体轮廓变为蓝色（`#1565c0`）。右侧面板出现，仅显示“性染色体”和“形态不同 (X 和 Y)”。
- 步骤3：点击「下一步」→ 基因B放大并变红，SRY片段边框变红加粗。右侧面板追加显示“X染色体: B基因”、“Y染色体: 睾丸发育基因”和“基因型: X^BY”。
- 最终步骤（步骤4）：点击「下一步」→ 底部出现红色加粗大字结论：“该个体基因型为：AaX^BY”。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：在 SVG 内部底部 (y=460) 放置两个按钮，用于控制步骤 0-4 的切换。
- 教师操作流程：教师首先展示原始细胞图，让学生观察；点击下一步，引导学生识别常染色体并推断甲病基因型；再次点击，识别性染色体；第三次点击，定位性染色体上的基因并推断乙病基因型；最后一步展示完整结论。

[技术实现]
- JS 库选择及原因：原生 SVG。图形主要由简单的几何路径和文本构成，原生 SVG 易于实现精确的坐标控制和样式切换。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +---------------------------------------------------+
  |               精原细胞有丝分裂中期图象            |
  |  +--------+           ( | )           +--------+  |
  |  | 常染色 |         (  \|/  )         | 性染色 |  |
  |  | 体 Aa  |       ( A\ B| a/ ▫ )      | 体 XBY |  |
  |  +--------+         (  /|\  )         +--------+  |
  |                       ( | )                       |
  |                                                   |
  |               该个体基因型为：AaX^BY              |
  |                                                   |
  |               [◀上一步]   [下一步▶]               |
  +---------------------------------------------------+
  ```
- 关键实现要点：
  - 染色体绘制：使用 `<g>` 组合底层粗线（轮廓）和顶层细线（内填），通过修改底层粗线的 `stroke` 属性实现高亮效果。
  - 状态机设计：定义 `currentStep` 变量（0-4），在 `updateStep()` 函数中根据当前步骤控制各元素的 `opacity`、`stroke`、`fill` 和 `font-size`。
  - 文本上标：使用 `<tspan dy="-5" font-size="0.8em">B</tspan><tspan dy="5">Y</tspan>` 实现 X^BY 的排版。
- ID 命名规范：所有交互元素 ID 必须以 `scene2-` 为前缀（如 `scene2-chr-lw-out`, `scene2-panel-left`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
