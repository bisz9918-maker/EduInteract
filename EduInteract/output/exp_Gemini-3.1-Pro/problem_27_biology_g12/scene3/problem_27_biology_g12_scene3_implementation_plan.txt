[分步序列]
- 初始状态（步骤0）：仅显示左侧 Ⅰ2 的初级精母细胞，包含正常的 X 和 Y 染色体，SRY 片段位于 Y 染色体上。
- 步骤1：点击「下一步」→ 触发易位动画，SRY 片段从 Y 染色体平移并连接到 X 染色体顶部，显示“易位”箭头和提示文字。
- 步骤2：点击「下一步」→ 显示“减数分裂”箭头，中间区域淡入异常精子（含 X^R+SRY），右侧上方淡入 Ⅰ1 的两种卵细胞（含 X^R 和 X^r）。
- 步骤3：点击「下一步」→ 显示受精箭头，右侧下方淡入两个受精卵及其内部染色体组合。底部显示基因型结论，并用红高亮框标出受精卵中来自父亲的 X^R 基因，得出患病概率为 0 的结论。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：底部居中放置两个按钮，控制步骤 0 到 3 的切换。
- 教师操作流程：教师首先介绍正常男性的性染色体（步0）；点击下一步，演示易位过程，强调异常染色体的形成（步1）；再次点击，展示减数分裂产生的异常精子和正常卵细胞（步2）；最后点击，展示受精结果，引导学生观察子代必然获得父亲的 X^R 基因，从而得出不患色盲的结论（步3）。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。SVG 非常适合绘制染色体等几何图形，且易于通过 CSS `transform` 实现平滑的平移动画（如 SRY 片段的易位）。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  | 左侧：Ⅰ2精母细胞 | 中间：异常精子 | 右侧：卵细胞与受精卵 |
  | (易位动画)        | (减数分裂)     | (受精过程与概率推导) |
  [控件栏 800×40，包含 上一步/下一步 按钮]
  ```
- 关键实现要点：
  - 使用 `<g>` 标签对不同步骤的元素进行分组，通过 JS 修改组的 `opacity` 或 `display` 属性实现步骤切换。
  - SRY 片段的易位动画通过修改其 `transform` 属性（如 `translate(-50px, -60px)`）配合 CSS `transition: transform 1s ease` 实现。
  - 步骤状态机：定义 `currentStep` 变量，每次点击按钮更新变量并调用 `updateScene()` 函数，集中管理所有元素的可见性和位置状态。
- ID 命名规范：所有交互元素 ID 必须以 `scene3-` 为前缀（如 `scene3-sry-segment`, `scene3-step-btn`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
