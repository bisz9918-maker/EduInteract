[图示主题与整合说明]
- 本图示主题：体细胞基因导入与生殖细胞遗传的区别
- 整合的步骤/概念：整合题目第(5)(6)问，展示基因导入肌肉细胞的过程，对比生殖细胞，说明体细胞突变/基因导入的不可遗传性。
- 教学价值：教师可通过此图示分步对比体细胞与生殖细胞在基因治疗前后的状态差异，直观解释为何注射了R基因提高了短跑成绩，但后代具有R基因的概率仍为0。

[视觉元素清单]
- 基因型列表：虚线框包围，列出RR、RE、EE三种基因型。
- 肌肉细胞（体细胞）：红色高亮轮廓（#c62828），10%透明度填充，内部包含细胞核。
- 生殖细胞（精子/卵子）：蓝色高亮轮廓（#1565c0），10%透明度填充。
- 基因注射器：主线（#000000）绘制的针筒形状。
- DNA片段：R基因用红色（#c62828），E基因用绿色（#2e7d32）。
- 箭头与连线：主线（#000000）。

[分步序列]
- 初始状态（状态1）：仅显示左侧的“跑步能力基因型 (3种)”列表（RR, RE, EE）。中间和右侧隐藏。
- 状态2（点击“2. 基因导入体细胞”）：左侧保持显示。中间上方出现肌肉细胞和注射器，动画展示R基因从注射器移动进入肌肉细胞核；中间下方出现生殖细胞（精子和卵子），显示其内部仅有E基因。右侧隐藏。
- 状态3（点击“3. 生殖细胞遗传”）：左侧、中间保持显示。中间下方的精子向右移动与卵子结合。右侧出现受精箭头、受精卵（子代细胞），显示内部基因为EE。底部淡入红色加粗结论：“具有R基因的概率：0”。

[交互方案]
- 交互类型：多状态切换（3个按钮）。
- 控件说明：
  - 按钮1：“1. 基因型种类”
  - 按钮2：“2. 基因导入体细胞”
  - 按钮3：“3. 生殖细胞遗传”
  - 控件栏位于 SVG 内部底部 (y=450~490) 居中排列。
- 教师操作流程：教师首先点击状态1讲解基因型种类；接着点击状态2，展示体细胞被改造但生殖细胞未受影响；最后点击状态3，展示受精过程，得出后代不携带导入基因的结论。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。图形均为基础几何图形和文本，原生 SVG 性能好且易于实现动画。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  +-----------------+-------------------------+-----------------+
  |                 |      [肌肉细胞]         |                 |
  |  [基因型列表]   |      (注入R基因)        |                 |
  |                 |                         |                 |
  |                 |      [生殖细胞] ------> |   [子代细胞]    |
  |                 |      (仅含E基因)        |   (概率: 0)     |
  +-----------------+-------------------------+-----------------+
  [控件栏： 按钮1 | 按钮2 | 按钮3 ]
  ```
- 关键实现要点：
  - 使用 `<g>` 标签对不同状态的元素进行分组，通过 JS 修改 `display` 或 `opacity` 属性控制显隐。
  - 动画实现：使用 CSS `transition` 控制 `transform` 和 `opacity`。状态切换时，通过移除并重新添加 class 来重置和触发动画（如 R 基因的注入平移、精子的受精平移）。
  - ID 命名规范：所有交互元素 ID 必须以 `scene4-` 为前缀（如 `scene4-btn-state1`, `scene4-muscle-cell`）。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
