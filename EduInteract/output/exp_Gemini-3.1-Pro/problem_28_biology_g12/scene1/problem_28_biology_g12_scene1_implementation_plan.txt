[视觉元素清单]
- 数据表格：使用 SVG `line` 绘制网格，`text` 填充数据。
- 高亮框：SVG `rect`，`fill="#1565c0"`，`fill-opacity="0.15"`，`stroke="#1565c0"`。
- 遗传图解：使用 SVG `text` 排版，配合简单的 `line` 或箭头字符。
- 结论框：SVG `rect`，`fill="#e8f5e9"`，`stroke="#2e7d32"`，`rx="5"`。
- 颜色/样式：
  - 主线/普通文字：#000000
  - 蓝高亮（有毛/隐性结论）：#1565c0
  - 红高亮（无毛/矛盾点）：#c62828
  - 绿高亮（最终结论）：#2e7d32

[分步序列]
- 初始状态（步骤0）：
  - 显示左侧完整数据表格。
  - 显示第3组高亮框。
  - 右侧推导区域为空。
- 步骤1：点击「下一步」
  - 右侧出现“1. 判断显隐性”及推导过程。
  - 表格中第3组的“有毛”(♀)、“有毛”(♂) 文字变为蓝色 #1565c0，子代无毛的“29”及“(14+15)”变为红色 #c62828。
- 步骤2：点击「下一步」
  - 右侧出现“2. 假设伴X隐性遗传”及完整的遗传图解（P代、配子、F1代）。
  - 强调 F1 代雌性“全为有毛”。
- 步骤3：点击「下一步」
  - 右侧出现“3. 验证假设”。
  - 出现红色的实际数据对比（无毛♀ 14只）和矛盾提示。
  - 出现底部的最终结论框：“结论：常染色体隐性遗传”。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：在 SVG 底部 (y=450~490) 放置绝对定位的 HTML `div`，包含两个 `button`。
- 教师操作流程：教师首先引导学生观察高亮的第3组数据；点击“下一步”展示显隐性判断；再次点击展示伴X遗传的假设推导；最后点击展示矛盾点并得出最终结论。可随时点击“上一步”回退。

[技术实现]
- JS 库选择及原因：原生 SVG。本场景主要为表格绘制和文本排版，原生 SVG 的 `text` 和 `line` 标签足以高效实现，无需引入额外库。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [左侧：交配数据表格 406x190]  [右侧：动态推导区]
  [第3组数据高亮显示]           [1. 判断显隐性...]
  [                       ]  [2. 假设伴X隐性...]
  [                       ]  [3. 验证假设...]
  [                       ]  [结论：常染色体...]
  [控件栏：◀上一步  下一步▶ (y=450~490)]
  ```
- 关键实现要点：
  - 使用 JS 数组配置表格数据，通过循环生成 SVG 的 `line` 和 `text` 元素，减少冗余代码。
  - 状态机设计：定义 `currentStep` (0~3)，在 `updateStep()` 函数中根据当前步骤控制右侧各组 SVG 元素（使用 `<g>` 标签分组）的 `display` 或 `opacity` 属性。
  - 颜色渐变/切换：在步骤1时，通过 JS 修改表格中特定 `text` 元素的 `fill` 属性，实现高亮效果。
  - ID 命名规范：所有元素 ID 以 `scene1-` 开头，如 `scene1-table-group3-female`，避免冲突。
  - IIFE 隔离：整个脚本包裹在 `(function() { ... })()` 中。
