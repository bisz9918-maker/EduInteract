[图示主题与整合说明]
- 本图示主题：PCR单次循环过程及引物结合机制
- 整合的步骤/概念：整合了题目中的变性、复性、延伸三个核心步骤，动态推导引物Ⅱ的序列与结合位置，并展示最终生成的两个DNA分子。
- 教学价值：教师可通过分步导航，清晰地讲解在不同温度下DNA分子的状态变化（解链、引物结合、延伸），特别是通过精确的等宽字符对齐，直观展示反向平行和碱基互补配对原则，帮助学生深刻理解引物的设计与作用。

[视觉元素清单]
- 字体统一使用 `Courier New, monospace`，确保等宽对齐。SVG text 必须加 `xml:space="preserve"`。
- 颜色/样式：
  - 模板链（a链、b链）：黑色 `#000000`
  - 引物及新合成链：蓝色 `#1565c0`
  - 氢键及重点高亮：红色 `#c62828`
  - 箭头及温度标签：黑色 `#000000`

[分步序列]
- 初始状态（步骤0）：仅显示 Row 0（初始双链及引物Ⅰ，引物Ⅱ位置显示下划线 `_________ (引物Ⅱ)`）。
- 步骤1（95℃ 变性）：点击「下一步」，显示 95℃ 箭头及 Row 1（两条单链分离）。
- 步骤2（55℃ 复性）：点击「下一步」，显示 55℃ 箭头及 Row 2（引物结合）。同时，Row 0 中的引物Ⅱ下划线更新为蓝色答案 `5'-G-A-OH (引物Ⅱ)`。Row 2 中显示红色的氢键 `| |` 强调互补配对。
- 步骤3（72℃ 延伸）：点击「下一步」，显示 72℃ 箭头及 Row 3（形成两个完整的双链DNA分子，新链用蓝色表示）。

[标签冲突检查]
- 标签"95 ℃"：坐标(390, 112)，text-anchor="end"。
- 序列"Row1_a链"：坐标(160, 150)，向右延伸至约340。
- 冲突检查：水平方向在 340-390 之间有充足空白，垂直方向相差 38px。无冲突。
- 其他温度标签同理，均位于左右两列序列之间的空白区域（340~520），无任何重叠风险。
- 氢键与序列文本：通过精确计算 y 坐标（如 225, 237, 250），确保氢键恰好位于两条链的中间，不遮挡字母。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：底部居中放置两个按钮，控制状态机（0~3）。
- 教师操作流程：教师点击“下一步”逐步展示PCR的三个温度阶段，在55℃时重点讲解引物Ⅱ的序列推导（3'端结合、反向平行），在72℃时总结半保留复制的结果。

[技术实现]
- JS 库选择及原因：原生 SVG。由于全是文本和简单的直线箭头，原生 SVG 的 `<text>` 和 `<path>` 足以完美实现，且性能最佳，易于精确控制等宽字符的对齐。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  Row 0: a链/b链 (左)          引物I/引物II (右)
           | 95℃
  Row 1: a单链 (左)            b单链 (右)
           | 55℃
  Row 2: a链+引物II (左)       引物I+b链 (右)
           | 72℃
  Row 3: a链+新b链 (左)        新a链+b链 (右)
  [控件栏: 上一步 | 下一步]
  ```
- 关键实现要点：
  - **等宽对齐**：必须在 CSS 中设置 `font-family: 'Courier New', Courier, monospace; white-space: pre;`，并在 SVG `<text>` 中使用 `xml:space="preserve"`，确保空格不被压缩，实现碱基的绝对垂直对齐。
  - **状态机**：维护 `currentState` (0-3)，每次状态改变时，遍历所有需要控制显示的元素的 ID，根据当前状态决定 `display: none` 或 `display: block`。
  - **ID 命名规范**：所有元素 ID 以 `scene1-` 开头，如 `scene1-r0-aseq`，`scene1-arrow-95` 等。
  - **IIFE 隔离**：所有逻辑封装在 `(function() { ... })()` 中。
