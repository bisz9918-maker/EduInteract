[图示主题与整合说明]
- 本图示主题：小车下滑及撞击木块的物理过程与受力分析
- 整合的步骤/概念：将题目四个选项（A、B、C、D）对应的物理过程整合在一个连贯的动画场景中。包括小车下滑时的能量转化、木块与木板的相互作用力分析、以及木块在光滑平面上的匀速直线运动。
- 教学价值：教师可以通过分步导航，逐一展示每个选项对应的物理情境。动态的能量柱状图直观破解“机械能守恒”的误区；原位受力分析清晰区分平衡力与相互作用力；碰撞后的匀速运动动画帮助学生理解牛顿第一定律的应用。

[分步序列]
- 初始状态（步骤0）：显示斜面、木板、小车（位于斜面上方）、木块（位于水平木板上）。能量柱状图显示重力势能满（h=180），动能为0，机械能满（h=180）。
- 步骤1（分析选项A、B）：点击「下一步」。小车沿斜面下滑至底端 (250,320)。小车上出现速度矢量箭头并逐渐变长。右侧能量柱状图动态变化：重力势能柱降至0，动能柱升至160，机械能柱略降至160。顶部出现提示文字“克服摩擦做功，机械能微小减小”。
- 步骤2（分析选项C）：点击「下一步」。小车停在底端。画面重点转移到木块。在木块与木板接触处出现受力箭头：红色的支持力 N 向上，蓝色的压力 N' 向下。出现提示文字“作用在不同物体上，是相互作用力”。
- 步骤3（分析选项D）：点击「下一步」。受力箭头消失。动画分两阶段：首先小车向右移动至 (320,320) 撞击木块；然后小车停止，木块向右滑动至 (530,320)。木板下方出现“光滑”字样。木块上出现长度保持不变的速度箭头。能量柱状图的动能柱保持不变。出现提示文字“不受水平外力，做匀速直线运动，动能不变”。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：在 SVG 内底部（y=460）居中放置两个按钮。
- 教师操作流程：教师首先展示初始状态，让学生观察装置；点击下一步，播放下滑动画，结合右侧能量柱讲解动能与势能转化及机械能不守恒（选项A、B）；再次点击下一步，展示受力分析，强调作用点不同（选项C）；最后点击下一步，展示碰撞后木块在光滑表面的匀速运动（选项D）。可随时点击上一步回退重新讲解。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS (`requestAnimationFrame`)。SVG 适合绘制清晰的几何图形和矢量箭头，原生 JS 动画足以处理简单的平移和高度变化，无需引入额外库。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×450]
  左侧：斜面与水平木板 (x:50~600)
  右侧：能量柱状图 (x:600~800)
  [控件栏 800×50] (y:450~500)
  包含：◀上一步 | 下一步▶
  ```
- 关键实现要点：
  - 状态机设计：定义 `currentStep` (0~3)，每次点击按钮更新状态并触发对应的动画函数。
  - 坐标计算：小车在斜面上的运动通过插值计算 (x, y)，并根据位置决定是否旋转 (`transform="rotate(45)"` 或 `rotate(0)`)。为方便旋转，小车的 SVG `<g>` 元素原点应设在底边中点。
  - 动画曲线：使用简单的线性或 ease-out 插值更新小车坐标和能量柱的 `height` 与 `y` 属性。
  - 箭头绘制：使用 SVG `<marker>` 定义箭头样式，方便在 `<line>` 中复用。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-cart`, `scene1-bar-ke`）；JS 中用 `document.getElementById` 获取元素。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
