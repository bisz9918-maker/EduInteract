[图示主题与整合说明]
- 本图示主题：易错选项（C、D）的化学方程式及反应类型剖析
- 整合的步骤/概念：整合了氧化铁还原反应的分类对比（置换与非置换），以及三种物质两两反应的复分解反应特征验证（离子交换过程）。
- 教学价值：教师可通过切换两个独立的状态，分别针对选项 C 和 D 进行深度剖析。状态 1 通过对比 CO 和 C 还原氧化铁的方程式，直观打破“生成铁必为置换反应”的思维定势；状态 2 通过三角形关系图结合带有离子交换动态连线的方程式，清晰展示复分解反应的本质，帮助学生彻底理解易错点。

[视觉元素清单]
- 状态 1 元素：
  - 标题：“选项 C 分析：N(Fe₂O₃) 转化为 Fe”
  - 方程式 1：“Fe₂O₃ + 3CO ═ 2Fe + 3CO₂”（CO 和 CO₂ 标红 #c62828）
  - 方程式 2：“2Fe₂O₃ + 3C ═ 4Fe + 3CO₂↑”（C 和 Fe 标蓝 #1565c0）
  - 标签与箭头：指向对应物质的“化合物”（红）和“单质”（蓝）标签及细实线箭头。
  - 结论：“结论：N 转化为铁的反应不一定是置换反应，选项 C 错误”
- 状态 2 元素：
  - 标题：“选项 D 分析：X, Y, M 两两反应”
  - 关系图：三个带黑边白底的圆（X, Y, M），下方标注具体化学式，两两之间用灰色实线连接。
  - 方程式组：三个复分解反应方程式，使用分段 `<text>` 渲染。
  - 离子交换连线：6 条蓝色（#1565c0）二次贝塞尔曲线，连接发生交换的阴阳离子，线宽 2px，`fill="none"`。
  - 结论：“结论：X、Y、M 两两之间均发生复分解反应，选项 D 正确”
- 颜色/样式：
  - 背景：#ffffff
  - 主文本/主线：#000000
  - 红高亮（#c62828）：用于强调反例（CO、CO₂ 及对应标签）。
  - 蓝高亮（#1565c0）：用于强调置换反应的单质，以及复分解反应中交换的离子连线。
  - 绿高亮（#2e7d32）：用于强调正确的结论（状态 2 结论及复分解反应标签）。

[分步序列]
- 初始状态（状态 1）：默认显示“分析选项 C”的内容。展示方程式 1 和 2，高亮 CO 和 CO2 为化合物，得出不一定是置换反应的结论。底部“分析选项 C”按钮处于激活高亮状态。
- 状态 2：点击「分析选项 D」按钮 → 隐藏状态 1 的所有元素，显示状态 2 的所有元素。左侧出现 X-Y-M 三角形关系图，右侧出现三个方程式，并带有蓝色的离子交换动态连线。底部“分析选项 D”按钮处于激活高亮状态。
（教师可随时点击底部按钮在两个状态间自由切换）

[交互方案]
- 交互类型：多状态切换（2 个状态按钮）。
- 控件说明：SVG 内部底部 (y=460) 放置两个 HTML `<button>`，分别为“分析选项 C”和“分析选项 D”。
- 教师操作流程：教师首先结合状态 1 讲解选项 C 的错误原因，打破学生“生成单质即为置换反应”的误区；随后点击“分析选项 D”，结合左侧物质关系图和右侧带有离子交换连线的方程式，直观证明三个反应均为复分解反应。

[技术实现]
- JS 库选择及原因：原生 SVG。本场景主要由文本、基本几何图形和贝塞尔曲线构成，原生 SVG 对文本的精确定位和曲线绘制支持最佳，且易于实现状态切换的显示/隐藏。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                   [标题区]                       |
  |                                                  |
  |  (状态1)                        (状态2)          |
  |  Fe₂O₃ + 3CO ═ 2Fe + 3CO₂     (X)-----(Y)        |
  |    ↑             ↑             \       /         |
  |  化合物        化合物           \     /          |
  |                                  (M)             |
  |                                                  |
  |  [结论文本]                     [方程式及连线]   |
  |                                                  |
  |          [分析选项 C] [分析选项 D]               |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  - **状态机设计**：将状态 1 和状态 2 的 SVG 元素分别包裹在 `<g id="scene2-state1">` 和 `<g id="scene2-state2">` 中。点击按钮时，通过修改 `display` 属性（`""` 或 `"none"`）实现切换。
  - **文本精确定位**：方程式中的化学式和加号等符号需要拆分为多个 `<text>` 或 `<tspan>` 元素，以便准确获取离子所在位置的坐标，从而绘制精确的离子交换曲线。
  - **曲线绘制**：使用 SVG `<path>` 的二次贝塞尔曲线指令 `Q` 绘制离子交换连线。例如 `M x1 y1 Q cx cy x2 y2`，控制点 `cy` 根据需要向上或向下偏移 25px。
- **ID 命名规范**：所有交互元素 ID 必须以 `scene2-` 为前缀（如 `scene2-btn-c`, `scene2-state1`）；JS 中用 `getElementById` 获取元素。
- IIFE 隔离：所有 JS 代码包裹在 `(function() { ... })()` 中，避免变量污染。
