[图示主题与整合说明]
- 本图示主题：910℃以下纯铁晶体（体心立方）的配位数与边长
- 整合的步骤/概念：体心立方晶胞结构展示、配位数观察、体对角线原子接触关系及边长计算
- 教学价值：教师可以通过分步演示和3D拖拽旋转，帮助学生直观理解体心立方的空间结构，清晰展示配位数为8的几何特征，并逐步推导出晶胞边长与原子半径（最近距离）的数学关系，有效降低空间几何的认知负荷。

[视觉元素清单]
- 3D场景容器：包含 Three.js Canvas 和 HTML 标签层。
- 晶胞线框：12条边，颜色 #000000。
- 原子球体：9个，半径15。普通原子 #888888，中心原子高亮 #c62828，配位原子高亮 #1565c0。
- 配位连线：8条从中心到顶角的虚线，颜色 #1565c0。
- 对角面：多边形 V0-V3-V6-V5，颜色 #1565c0，透明度 20%，双面渲染。
- 直角三角形边：V0-V5, V5-V6, V6-V0，加粗实线，颜色 #c62828。

[分步序列]
- 初始状态（步骤0）：显示完整的体心立方线框（12条边），8个顶角原子（灰色），1个中心原子（灰色）。隐藏其他辅助线、面和公式。
- 步骤1（配位数）：点击「下一步」。中心原子变为红色，8个顶角原子变为蓝色。出现8条从中心指向顶角的蓝色虚线。显示标签"中心原子"和"配位原子"（指向V6）。
- 步骤2（几何关系）：点击「下一步」。隐藏6个顶角原子及其相连的虚线，仅保留中心原子、V0(左下后)和V6(右上前)原子。显示对角面（半透明蓝色）。连接V0-中心-V6形成体对角线（红色实线）。显示标注 $d$ 和 $2d$。
- 步骤3（边长推导）：点击「下一步」。在对角面上，高亮直角三角形 V0-V5-V6 的三边（红色加粗）。显示底面对角线 V0-V5。显示边长标注 $a_1$ 和 $\sqrt{2}a_1$。在左上角显示推导公式：$(\sqrt{2}a_1)^2 + a_1^2 = (2d)^2 \Rightarrow \sqrt{3}a_1 = 2d$。

[标签冲突检查]
- 标签"中心原子"：3D坐标(0,0,0)，2D偏移(+20, -20)
- 标签"配位原子"：3D坐标(100,100,100)，2D偏移(+20, -20)
- 标签"d"：3D坐标(50,50,50)，2D偏移(-15, -15)
- 标签"2d"：3D坐标(-50,-50,-50)，2D偏移(+15, +15)
- 标签"a1"：3D坐标(100,0,100)，2D偏移(+20, 0)
- 标签"\sqrt{2}a_1"：3D坐标(0,-100,0)，2D偏移(0, +20)
冲突检查：
- "中心原子"与"d"：3D距离86，2D投影后"中心原子"向右上偏移，"d"向左上偏移，方向错开，无冲突。
- "a1"与"配位原子"：分别在V5-V6中点和V6点，Y轴相差100，无冲突。
- "\sqrt{2}a_1"在底部，向下偏移，远离其他中心标签，无冲突。
- 解决方案：所有标签采用 3D 到 2D 的实时投影，并在 `requestAnimationFrame` 中更新，确保在拖拽旋转时标签始终跟随且保持设定的偏移方向。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶） + 3D拖拽旋转
- 控件说明：
  - 底部居中放置两个按钮：「◀ 上一步」和「下一步 ▶」。
  - 3D 画布支持鼠标左键拖拽旋转，滚轮缩放。
- 教师操作流程：教师首先展示初始晶胞，拖拽旋转让学生看清体心结构；点击下一步展示配位数8；再次点击展示对角面和体对角线，解释最近距离 $d$；最后点击展示直角三角形，结合公式推导边长 $a_1$。

[技术实现]
- JS 库选择及原因：Three.js（CDN引入，用于3D建模和拖拽旋转），MathJax（用于渲染数学公式）。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  +--------------------------------------------------+
  | [公式区] (\sqrt{2}a_1)^2 + ...                   |
  |                                                  |
  |                                                  |
  |               [ Three.js 3D Canvas ]             |
  |               (支持鼠标拖拽旋转)                 |
  |                                                  |
  |                                                  |
  |                                                  |
  |             [ ◀ 上一步 ]  [ 下一步 ▶ ]           |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  - 场景初始化：设置 `THREE.PerspectiveCamera`，初始位置设为 `(250, 200, 350)` 看向 `(0,0,0)`，以获得良好的等轴测视角。
  - 标签投影：不依赖额外的 CSS2DRenderer，直接在 `render` 循环中使用 `Vector3.project(camera)` 将 3D 坐标转换为 2D 屏幕坐标，并更新对应 HTML 元素的 `left` 和 `top` 样式。
  - 状态机设计：定义 `currentStep` (0-3)，在 `updateStep()` 函数中根据当前步骤设置各 3D 对象（如原子、线段、平面）的 `visible` 属性和材质颜色。
  - 动画过渡：步骤切换时直接切换可见性，保持交互的干脆利落。
- ID 命名规范：所有 DOM 元素 ID 以 `scene1-` 开头，如 `scene1-container`, `scene1-canvas`, `scene1-btn-prev`, `scene1-btn-next`, `scene1-formula`。
- IIFE 隔离：所有逻辑封装在 `(function() { ... })()` 中，避免全局变量污染。
