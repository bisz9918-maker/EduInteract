[图示主题与整合说明]
- 本图示主题：910℃以上纯铁晶体（面心立方）的配位数与边长
- 整合的步骤/概念：面心立方晶胞结构展示、配位数观察、面对角线原子接触关系及边长计算
- 教学价值：教师可通过 3D 视角的自由旋转，帮助学生直观建立面心立方配位数为 12 的空间想象；随后通过视角的自动切换与多余原子的剥离，将复杂的 3D 结构降维至 2D 平面，清晰推导出原子半径与晶胞边长的几何关系。

[分步序列]
- 初始状态（步骤0）：显示主晶胞线框及14个原子（8顶角+6面心），全为灰色。相机处于等轴测视角（OrthographicCamera，位置 300,300,400，看向 0,0,0）。
- 步骤1：点击「下一步」→ 显示辅助晶胞线框及部分相邻原子。目标面心原子高亮为红色，12个最近邻原子高亮为蓝色，并显示12条蓝色连线。右上角显示文本“配位数 = 12”。
- 步骤2：点击「下一步」→ 隐藏辅助晶胞、连线及非目标面的所有原子。仅保留Z=120面上的5个原子及该面的正方形线框。相机平滑动画至正视图（位置 0,0,500，看向 0,0,120）。显示目标面半透明填充、面对角线。显示“面心原子”、“顶角原子”标签，以及两个“$d$”标签。
- 步骤3：点击「下一步」→ 保持步骤2状态。显示左侧和下方边长的“$a_2$”标签。高亮左下角的直角三角形（加粗边框）。在三角形内部显示公式“$\sqrt{2}a_2 = 2d$”。

[标签冲突检查]
- 顶角原子标签 (240,110) vs d(上半) (355,175)：间距 > 100px → 无冲突。
- 面心原子标签 (430,270) vs d(下半) (475,295)：间距 ≈ 51px → 无冲突。
- a2(左) (260,250) vs 公式 (340,310)：间距 > 80px → 无冲突。
- a2(下) (400,390) vs 公式 (340,310)：间距 > 80px → 无冲突。
- 解决方案：所有标签均通过 CSS2D 绑定到 3D 坐标，并设置了明确的 CSS transform 偏移量（如右上偏移、左侧偏移），在正视图下完全无重叠，且在 3D 旋转时也能保持相对位置不遮挡原子。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：底部控件栏（y=440~490），包含“上一步”按钮、步骤指示器（如“1 / 4”）、“下一步”按钮。居中排列。
- 教师操作流程：教师首先展示 3D 晶胞并自由旋转；点击下一步展示 12 配位，旋转视角证实距离相等；再次点击下一步，系统自动将视角切为 2D 正视图并剥离多余原子，教师借此讲解平面几何关系；最后一步展示边长计算公式。

[技术实现]
- JS 库选择及原因：Three.js（处理 3D 晶胞及相机动画）、CSS2DRenderer（实现不随 3D 缩放变形且支持 MathJax 的高清文本标签）。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×440 (Three.js Canvas + CSS2D)]
  [控件栏 800×60 (上一步 | 步骤 1/4 | 下一步)]
  ```
- 关键实现要点：
  1. 使用 `OrthographicCamera` 确保正视图时没有透视变形，完美契合 2D 几何推导。
  2. 状态机设计：定义 0-3 四个状态，每个状态对应一个函数，控制物体的 `visible` 属性和材质颜色。
  3. 相机动画：在步骤 1 到 2 切换时，使用 `requestAnimationFrame` 配合简单的插值（lerp）平滑过渡 `camera.position` 和 `controls.target`。
  4. 标签跟随：使用 `CSS2DObject` 将 DOM 元素绑定到 3D 坐标，利用 CSS `transform: translate(...)` 实现精确的像素级偏移。
- ID 命名规范：所有交互元素 ID 必须以 `scene2-` 为前缀（如 `scene2-btn-next`、`scene2-step-text`）。
- IIFE 隔离：所有 JS 代码必须包裹在 `(function() { ... })()` 中。
