[图示主题与整合说明]
- 本图示主题：晶胞微粒数与密度之比计算
- 整合的步骤/概念：均摊法计算BCC和FCC晶胞的原子数，结合边长比推导密度比。
- 教学价值：教师可通过多状态切换，直观展示晶胞切割后的微粒形态（1/8球、1/2球），帮助学生理解均摊法原理，并清晰展示密度比的推导过程。

[交互方案]
- 交互类型：多状态切换（3个按钮）。
- 控件说明：
  - 按钮1：「BCC微粒数」，位于(250, 465)，点击进入状态1。
  - 按钮2：「FCC微粒数」，位于(400, 465)，点击进入状态2。
  - 按钮3：「密度对比」，位于(550, 465)，点击进入状态3。
- 教师操作流程：教师依次点击三个按钮，先讲解BCC的均摊法计算，再讲解FCC的均摊法计算，最后展示两者密度的综合比值计算。3D模型支持鼠标拖拽旋转，方便全方位观察切割情况。

[技术实现]
- JS 库选择及原因：Three.js（用于3D晶胞及切割球体的精确渲染），MathJax（用于复杂数学公式渲染）。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  +--------------------------------------------------+
  |                   [3D视图区]                     |
  |                                                  |
  |      (BCC模型)                  (FCC模型)        |
  |                                                  |
  |                                                  |
  +--------------------------------------------------+
  |                   [公式面板]                     |
  |      Z1 = ..., Z2 = ..., ρ1/ρ2 = ...             |
  +--------------------------------------------------+
  |  [BCC微粒数]     [FCC微粒数]      [密度对比]     |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  - 开启 Three.js 的 `renderer.localClippingEnabled = true`。使用 `THREE.Plane` 实现球体的精确切割。对于顶角原子，设置3个正交的裁剪平面（与晶胞面重合，保留晶胞内部）；对于面心原子，设置1个裁剪平面。这比手动旋转 1/8 球体几何体更简便且精确。
  - 状态切换时，通过修改模型的 `position.x` 实现平移（状态3时将两个模型分别移至左右两侧），并控制模型的 `visible` 属性。
  - HTML 标签使用 `position: absolute` 叠加在 Canvas 容器上，状态切换时更新 `display` 属性。引线可以使用绝对定位的 SVG 线条连接 3D 坐标投影到 2D 屏幕的坐标。
  - 开启 `OrbitControls` 允许教师旋转视角，但限制缩放 (`enableZoom = false`) 和平移 (`enablePan = false`) 以防破坏布局。
- ID 命名规范：所有交互元素 ID 必须以 `scene3-` 为前缀（如 `scene3-btn-bcc`，`scene3-formula`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
