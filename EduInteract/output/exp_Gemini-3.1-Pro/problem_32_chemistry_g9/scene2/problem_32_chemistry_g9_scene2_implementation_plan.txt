[图示主题与整合说明]
- 本图示主题：氨气溶解引发的喷泉实验
- 整合的步骤/概念：挤压胶头滴管使氨气溶解，导致B瓶内压强减小，打开活塞后烧杯中的水倒吸入B瓶并变红的过程。
- 教学价值：教师可以通过分步演示，清晰地向学生展示喷泉实验中每一步的操作及其引发的物理气压变化和化学颜色变化，帮助学生理解压强差是形成喷泉的动力，以及氨水显碱性使酚酞变红的化学性质。

[分步序列]
- 初始状态（步骤0）：活塞a、b、c的把手垂直于导管（关闭状态）。烧杯中显示浅蓝色水。B瓶中显示"NH3"文本。隐藏压强箭头、水流和喷泉。
- 步骤1（挤压滴管）：点击「下一步」。胶头滴管的胶头发生Y轴缩放动画（模拟挤压）。B瓶内滴管尖端(563, 120)出现几滴蓝色水滴向下掉落并消失。
- 步骤2（气体溶解）：点击「下一步」。B瓶内的"NH3"文本淡出消失。在B瓶中心(550, 90)出现红色的向下箭头，并伴随持续的上下浮动动画，提示气压降低。
- 步骤3（打开活塞）：点击「下一步」。活塞a和b的把手旋转90度，变为平行于导管（打开状态）。
- 步骤4（形成喷泉）：点击「下一步」。
  1. 蓝色水流沿导管从烧杯(400, 390)迅速上升，经过(400, 260)向右，再沿(545, 260)向上到达B瓶内(545, 140)。
  2. 水流到达B瓶后，在(545, 140)处触发喷泉动画：动态生成多个红色小圆点向上抛射并散开落下。
  3. B瓶底部(y=160至180)逐渐出现红色液体积聚。
  4. 显示"红色喷泉"标签。

[技术实现]
- JS 库选择及原因：使用原生 SVG 进行图形绘制，原生 JavaScript 控制状态机和动画。SVG 适合绘制清晰的化学仪器线条，且易于通过 CSS 和 JS 操作 DOM 属性实现动画，无需引入庞大的外部库。
- 画布尺寸：800 × 500 px，相对定位容器。
- 布局草图：
  ```
  [图示区 800×440]
    (A瓶)       (B瓶)
      |           |
      +----(T)----+
           |
         [烧杯]
  [控件栏 800×60，包含 上一步/下一步 按钮]
  ```
- 关键实现要点：
  - 状态机：定义 `let scene2_currentStep = 0;`，每次点击按钮更新步骤，并调用对应的渲染函数。
  - 水流动画：使用 SVG 的 `<path>` 元素，设置 `stroke-dasharray` 和 `stroke-dashoffset`，通过 CSS `transition` 实现水流沿导管前进的效果。
  - 喷泉粒子动画：在步骤4触发时，使用 `requestAnimationFrame` 动态更新一组 SVG `<circle>` 元素的 `cx` 和 `cy` 坐标，模拟重力抛物线运动。
  - 状态回退：在「上一步」逻辑中，需重置对应步骤的动画状态（如清除粒子、重置水流 offset、恢复文本透明度等）。
- ID 命名规范：所有 DOM 元素的 ID 必须以 `scene2-` 为前缀（如 `scene2-flask-a`, `scene2-btn-next`）。
- IIFE 隔离：所有 JS 代码必须包裹在 `(function() { ... })()` 中，防止变量污染全局作用域。
