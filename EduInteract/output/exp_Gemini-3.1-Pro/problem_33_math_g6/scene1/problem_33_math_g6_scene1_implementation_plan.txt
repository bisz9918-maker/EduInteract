[图示主题与整合说明]
- 本图示主题：甲乙图形周长比较（数格法与平移法）
- 整合的步骤/概念：整合了网格尺寸读取、数格法计算周长、平移法动态演示及最终比较结论。
- 教学价值：教师可通过分步导航，先引导学生用基础的数格法计算周长，再通过生动的平移法动画，启发学生发现图形周长与外接矩形的关系，直观对比得出结论，加深对周长概念及平移巧算的理解。

[分步序列]
- 初始状态（步骤0）：显示背景网格、甲乙图形填充及黑色实线边界、中心标签“甲”“乙”。隐藏所有边长数值、辅助线和底部公式。
- 步骤1（数格法）：显示甲、乙所有边长数值标签。底部显示公式“甲的周长 = 4+5+4+1+2+3+2+1 = 22”和“乙的周长 = 2+5+2+1+2+3+2+1 = 18”。
- 步骤2（平移法-乙）：隐藏所有边长数值标签。显示乙的外接矩形虚线。乙的四条内凹边（左上水平、右上水平、内左竖直、内右竖直）变为蓝色并平移至外接矩形边框重合。乙公式更新为蓝色：“乙的周长 = 外接矩形周长 = (5+4)×2 = 18”。
- 步骤3（平移法-甲）：显示甲的外接矩形虚线。甲的内下水平边变为蓝色并向上平移至外接矩形顶边重合。甲公式更新为：“甲的周长 = 外接矩形周长 + 2条竖直边”（“2条竖直边”用红色）。
- 步骤4（对比结论）：甲内部剩余的两条竖直边高亮为红色。甲公式更新为：“甲的周长 = 18 + 2 + 2 = 22”（数字用红色）。底部中央显示红色粗体结论：“甲 > 乙”。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。图形由简单线段组成，SVG 原生支持高质量渲染，且利用 CSS `transform` 配合 `transition` 即可实现流畅的平移线段动画，无需引入额外库。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
    (网格及图形区 120~680, 80~320)
    (公式及结论区 y=370~430)
  [控件栏 y=450~490]
  ```
- 关键实现要点：
  1. 图形边界拆分为独立的 `<line>` 元素，便于单独控制样式和动画。
  2. 动画实现：为需要平移的线段添加 CSS 类，利用 `transform: translateX/Y(...)` 和 `transition: all 1s ease` 实现平滑移动。例如乙的左上水平边向上平移 80px (`transform: translateY(-80px)`)。
  3. 状态机设计：定义 `currentStep` (0~4)，在 `updateState()` 函数中根据当前步骤统一控制所有元素的显示/隐藏（`opacity`）、文本内容更新及 CSS 类的添加/移除。
  4. ID 命名规范：所有元素 ID 均以 `scene1-` 开头（如 `scene1-jia-left`, `scene1-btn-next`），避免全局冲突。代码包裹在 IIFE 中。
