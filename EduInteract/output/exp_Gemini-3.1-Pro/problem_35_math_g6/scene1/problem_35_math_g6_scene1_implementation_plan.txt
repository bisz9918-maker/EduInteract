[图示主题与整合说明]
- 本图示主题：圆剪拼成长方形的过程及周长对应关系演示
- 整合的步骤/概念：将圆等分为16个扇形，交错拼接成近似的长方形。通过动画演示圆周长的一半对应长方形的长，圆的半径对应长方形的宽，从而推导出长方形的周长公式。
- 教学价值：教师可通过分步控制，引导学生观察图形变换前后的边长对应关系，将抽象的公式推导过程具象化，帮助学生深刻理解 $C = 2\pi r + 2r$ 的来源。

[视觉元素清单]
- 16个扇形：使用 SVG `path` 绘制，半径 100。上半部分（8个）填充 `#ffffff`，下半部分（8个）填充 `#cccccc`（透明度 0.5），描边 `#000000`。
- 半径标注：黑色线段及文本 `r=10`。
- 幽灵圆：`#888888` 虚线圆（`stroke-dasharray: 5,5`），无填充。
- 红色高亮线：`#c62828`，线宽 3px。包含顶部和底部两条，由半圆弧平移形变而来。
- 蓝色高亮线：`#1565c0`，线宽 3px。包含左右两条，由半径平移旋转而来。
- 文本标签：字体 sans-serif，黑色 `#000000`。公式使用较大字号加粗。

[分步序列]
- 初始状态（步骤0）：显示完整的圆（16个扇形组合）在左侧 (200, 240)，显示半径线及 `r=10` 标签。右侧空白。
- 步骤1（剪切）：16个扇形沿各自中心角向外平移 10px，呈微微散开状。半径标签淡出。
- 步骤2（拼接）：扇形平移并旋转至右侧长方形位置。白色扇形弧朝上，灰色扇形弧朝下，交错咬合。左侧原位置淡入显示“幽灵圆”。
- 步骤3（高亮长边）：在左侧幽灵圆上出现上下两个红色半圆弧，随后动画平移并“拉直”为长方形的上下两条红色长边。同时淡入上下方的 `πr` 标签。
- 步骤4（高亮宽边）：在左侧幽灵圆上出现左右两条水平蓝色半径线，随后动画平移并旋转，贴合到长方形的左右两侧斜边上。同时淡入左右两侧的 `r` 标签。
- 步骤5（结论）：在画布底部 (400, 420) 淡入结论公式文本：`长方形周长 = 2πr + 2r`。

[交互方案]
- 交互类型：分步按钮导航
- 控件说明：在 SVG 内部底部 (y=460 区域) 居中放置两个按钮 `[◀ 上一步]` 和 `[下一步 ▶]`。
- 教师操作流程：教师点击“下一步”逐步演示剪开、拼接、长边对应、宽边对应、得出结论的过程。可随时点击“上一步”回退动画，反复讲解对应关系。

[技术实现]
- JS 库选择：D3.js (用于便捷的 SVG 路径生成、属性插值动画和状态管理)。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  (200,240)初始圆区域        (420~753, 190~290)长方形区域
           ↓平移/形变动画→
  
  [结论公式区 y=420]
  [控件栏 y=460: ◀ 上一步 | 下一步 ▶]
  ```
- 关键实现要点：
  1. **扇形生成与定位**：以扇形顶点为原点 (0,0) 绘制 path。初始状态通过 `translate(200, 240) rotate(0)` 定位。
  2. **拼接坐标计算**：
     - 白色扇形 (k=0..7)：目标顶点 `x = 420 + k*w + w/2`, `y = 290`，目标旋转角使角平分线垂直向上。
     - 灰色扇形 (k=8..15)：目标顶点 `x = 420 + (15-k)*w + w`, `y = 190`，目标旋转角使角平分线垂直向下。（其中 $w = \pi 	imes 100 / 8 \approx 39.27$）
  3. **红线形变动画 (Polyline Morphing)**：使用 50 个点的折线 (`polyline` 或 `path`)。初始状态点分布在半圆弧上，目标状态点线性分布在水平直线上。D3 的 `.transition().attr('d', ...)` 可实现完美的平滑拉直动画。
  4. **状态机设计**：定义 `currentState` (0~5)，封装 `renderState(state)` 函数。每次状态切换时，根据目标状态应用对应的 `.transition()`，确保正向和逆向操作动画均流畅自然。
- ID 命名规范：所有元素 ID 均以 `scene1-` 开头，如 `scene1-btn-prev`, `scene1-sector-0`。
- IIFE 隔离：所有逻辑封装在 `(function() { ... })()` 中。
