[图示主题与整合说明]
- 本图示主题：小旗绕点O顺时针旋转90°的过程与坐标变化
- 整合的步骤/概念：网格坐标系的推断、点O坐标的确定、绕定点顺时针旋转90°的动画演示、旋转后顶点坐标的读取。
- 教学价值：教师可通过分步导航，引导学生先观察原图确定旋转中心O的坐标，再通过动画直观展示旋转过程，最后利用辅助线读取新顶点的坐标，将抽象的几何变换与直观的坐标系完美结合。

[视觉元素清单]
- 背景网格：#e0e0e0 实线，线宽1px。
- 坐标轴：#000000 实线，线宽2px，带箭头。原点标"0"，x轴标"x"，y轴标"y"。
- 初始小旗：主线 #000000 粗实线(3px)，旗面填充 #000000 透明度 10%。
- 旋转后小旗：主线 #1565c0（蓝高亮）粗实线(3px)，旗面填充 #1565c0 透明度 20%。
- 初始虚影：主线 #888888 虚线(2px)，无填充。

- 辅助线：#c62828（红高亮）虚线，线宽2px。

- 长度标注括号及数字：#000000。

[分步序列]
- 初始状态（步骤0）：显示网格、坐标轴、初始小旗。高亮显示顶点A（红点）及标签“(5, 7)”，显示点O（黑点）及标签“O”。
- 步骤1（确定点O）：点击「下一步」。初始旗杆高亮（加粗或变色），右侧出现大括号和长度标签“4”。点O变为红点，标签“O”更新为“O(5, 3)”。
- 步骤2（旋转演示）：点击「下一步」。原小旗变为灰色虚线虚影。播放小旗绕点O顺时针旋转90°的动画（耗时约1秒）。旋转完成后，显示绿色旋转圆弧箭头和“90°”标签。
- 步骤3（读取新坐标）：点击「下一步」。高亮旋转后小旗的新顶点A'（红点）。从A'向x轴、y轴方向绘制红色虚线辅助线。A'点右侧出现标签“(9, 3)”。

[标签冲突检查]
- 标签 A(5,7) (375,140) vs 初始旗面 (360,150)-(280,190)：A在右侧，旗面在左侧，无冲突。
- 标签 O(5,3) (360,335) vs 长度标注"4" (385,235)：y轴相差100px，无冲突。
- 长度标注"4" (385,235) vs 标签 90° (395,285)：y轴相差50px，且90°偏右下，无冲突。
- 标签 (9,3) (540,315) vs 旋转后旗面 (520,310)-(480,230)：标签在右侧，旗面在左上侧，无冲突。
- 标签 (9,3) (540,315) vs A'辅助线(x轴) (520,310)-(520,430)：标签在辅助线右侧20px，无冲突。
结论：所有标签位置规划合理，无重叠风险。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：底部居中放置两个按钮，控制步骤0~3的切换。
- 教师操作流程：教师首先展示原图（步0），引导学生观察旗杆长度；点击下一步（步1）验证旗杆长度为4，得出O点坐标；点击下一步（步2）演示旋转过程，强调绕定点、方向和角度；最后点击下一步（步3）引导学生通过网格或辅助线读出新顶点的坐标。

[技术实现]
- JS 库选择：原生 SVG。SVG 非常适合几何图形的精确绘制、DOM 节点的分步显示控制以及基于 `transform` 的旋转动画。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  +--------------------------------------------------+
  |                                                  |
  |       y                                          |
  |       ^                                          |
  |       |   A(5,7)                                 |
  |       |   /|                                     |
  |       |  /-| } 4                                 |
  |       | /  |                                     |
  |       |    O(5,3) --90°--> A'(9,3)               |
  |       |    |               |                     |
  |       +----|---------------|--------> x          |
  |            5               9                     |
  |                                                  |
  |             [◀上一步] [下一步▶]                  |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 坐标系映射：定义函数 `mapX(x)` 和 `mapY(y)`，将数学坐标 (0~12, 0~9) 映射到 SVG 像素坐标 (160~640, 430~70)。
  2. 动画实现：步骤2的旋转动画通过 CSS `transition: transform 1s ease-in-out;` 实现，设置 `transform-origin: 360px 310px;`，初始状态 `transform: rotate(0deg);`，目标状态 `transform: rotate(90deg);`。
  3. 状态机：使用一个变量 `currentStep` (0~3) 记录当前状态，每次点击按钮更新变量，并调用 `updateScene()` 函数。该函数通过修改 SVG 元素的 `display` 或 `opacity` 属性来控制元素的显隐。
  4. ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-flag-initial`, `scene1-btn-next`）。
  5. 作用域隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
