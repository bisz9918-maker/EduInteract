[图示主题与整合说明]
- 本图示主题：三种滑轮拉动物体的受力分析与对比
- 整合的步骤/概念：三种滑轮装置的识别、物体与滑轮的受力分析、拉力与摩擦力的定量关系推导
- 教学价值：教师可以通过分步导航，引导学生逐一攻克三种滑轮情况的受力分析，通过隔离法（虚线框）清晰展示受力平衡关系，最后汇总对比得出结论，有效突破教学重难点。

[分步序列]
- 初始状态（步骤0）：显示图1、图2、图3的基础装置及拉力 F1, F2, F3。右侧空白。
- 步骤1：三个物体下方均出现红色摩擦力 f 箭头。右侧显示前提条件文本。
- 步骤2：图2、图3透明度降至 0.3。图1保持高亮，出现蓝色张力 T1 箭头。右侧显示图1受力分析及公式 F1 = f。
- 步骤3：图1、图3透明度降至 0.3。图2恢复高亮，出现灰色虚线框（框住滑轮和物体）及下方绳子的蓝色 F2 箭头。右侧显示图2受力分析及公式 F2 = 0.5f。
- 步骤4：图1、图2透明度降至 0.3。图3恢复高亮，出现灰色虚线框（仅框住滑轮）及三个蓝色 T3 箭头。右侧显示图3受力分析及公式 F3 = 2f。
- 步骤5：所有图形恢复正常透明度（1.0），隐藏中间分析的虚线框和 T 箭头（仅保留 F 和 f）。右侧显示最终结论 F2 < F1 < F3，并高亮选项 D。

[交互方案]
- 交互类型：分步按钮导航（◀ 上一步 / 下一步 ▶）
- 控件说明：
  - "◀ 上一步" 按钮：位于 (150, 460)，点击回退到上一个分析状态。
  - "下一步 ▶" 按钮：位于 (280, 460)，点击推进到下一个分析状态。
- 教师操作流程：教师首先展示三种滑轮的初始状态，点击“下一步”引入摩擦力前提；随后依次点击“下一步”逐个分析定滑轮、动滑轮（省力）、动滑轮（费力）的受力情况，配合右侧推导公式进行讲解；最后点击“下一步”展示总结论。

[技术实现]
- JS 库选择及原因：原生 SVG。图形均为基础几何形状和路径，原生 SVG 性能好且易于通过 DOM 操作实现状态切换和动画过渡。
- 画布尺寸：800 × 500 px
- 布局草图：
  [图示区 800×500]
  左侧 (x:50-400)：纵向排列图1、图2、图3
  右侧 (x:480-780)：纵向排列各步骤的推导公式
  底部 (x:150-350, y:460)：导航按钮
- 关键实现要点：
  - 状态机设计：定义 `let currentState = 0; const maxState = 5;`，通过 `updateState()` 函数统一管理各元素的 `display` 和 `opacity` 属性。
  - 动画过渡：为所有 `<g>` 元素添加 `style="transition: opacity 0.3s ease;"`，实现高亮和淡出的平滑过渡。
  - 箭头绘制：在 `<defs>` 中定义 `<marker id="scene1-arrow-blue">` 和 `<marker id="scene1-arrow-red">`，在 `<line>` 中通过 `marker-end` 引用，确保箭头样式统一。
  - ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-btn-next`, `scene1-setup2`），避免全局污染。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
