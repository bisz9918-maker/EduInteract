[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：底部居中放置两个按钮（y=460区域），用于切换步骤 (0~4)。
- 教师操作流程：教师首先结合左侧正方体讲解题目条件，然后依次点击“下一步”展示每个选项的展开图，利用高亮和连线引导学生观察相对面是否相同，最终得出正确答案。

[技术实现]
- JS 库选择：原生 SVG。最适合绘制几何图形、网格和精确的折线连线，且易于通过 DOM 操作实现高亮和图案切换。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  左侧：3D正方体 (x:120-210)
  右侧：展开图网格 (x:450-650)
  [控件栏 底部 y:450-490]
  ```
- 关键实现要点：
  - 模式复用：在 `<defs>` 中定义心形、笑脸、星形的 `<g>` 模板，通过 `<use href="#scene1-pat-heart" x="..." y="..."/>` 在正方体和展开图中复用，极大简化代码。
  - 统一网格：四个选项的展开图形状完全一致（均为1-4-1型，顶在Col2，底在Col1），因此只需在 DOM 中创建一组6个方块，切换步骤时通过 JS 修改每个方块内 `<use>` 的 `href` 属性即可切换图案。
  - 高亮与连线：预先在 SVG 中定义高亮色块（`<rect>`）和连线（`<path>`），默认 `display="none"`。
  - 状态机设计：使用 `currentStep` (0-4) 变量，编写 `updateScene()` 函数集中处理所有元素的显示/隐藏、图案更新和文本更新。
  - ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-btn-next`, `scene1-sq1-use`）。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
