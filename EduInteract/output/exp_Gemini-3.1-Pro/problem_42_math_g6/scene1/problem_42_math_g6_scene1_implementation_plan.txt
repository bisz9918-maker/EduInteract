[图示主题与整合说明]
- 本图示主题：利用“俯视图标数法”推导各位置正方体数量
- 整合的步骤/概念：整合了三视图的观察、主视图定列高、左视图定行高、综合推导具体数量的过程。
- 教学价值：教师可以通过分步演示，清晰地向学生展示如何从主视图和左视图中提取高度信息，并将其映射到俯视图的对应行列中，最终通过逻辑推理得出每个位置的正方体数量，有效降低学生的空间想象难度。

[视觉元素清单]
- 主视图网格：黑色边框 2px，白色填充。包含3列，高度分别为2,1,1。
- 左视图网格：黑色边框 2px，白色填充。包含2列，高度分别为2,1。
- 俯视图网格：黑色边框 2px，白色填充。包含3列2行，其中第2行只有第1列有方格。
- 蓝色引导线（主视图到俯视图）：#1565c0 虚线，带箭头。
  - 线1：(215,145) -> (215,180) -> (340,180) -> (340,235)
  - 线2：(245,145) -> (245,190) -> (400,190) -> (400,235)
  - 线3：(275,145) -> (275,200) -> (460,200) -> (460,235)
- 红色引导线（左视图到俯视图）：#c62828 虚线，带箭头。
  - 线1：(515,145) -> (515,270) -> (495,270)
  - 线2：(545,145) -> (545,330) -> (375,330) （巧妙穿过俯视图右下角空白区域，无遮挡）
- 高亮遮罩：对应颜色 20% 透明度填充，覆盖在网格上方。

[分步序列]
- 初始状态（步骤0）：显示主视图、左视图、俯视图的基础网格及黑色标题标签。隐藏所有高亮、引导线、彩色数值和公式。
- 步骤1（主视图定列高）：显示主视图蓝色高亮遮罩。显示蓝色引导线。显示俯视图下方的蓝色“列高：2, 1, 1”文本。
- 步骤2（左视图定行高）：隐藏主视图高亮遮罩（保留蓝色引导线和文本）。显示左视图红色高亮遮罩。显示红色引导线。显示俯视图左侧的红色“行高：2, 1”文本。
- 步骤3（推导右侧）：隐藏左视图高亮遮罩（保留红色引导线和文本）。显示俯视图 R1C2 和 R1C3 的绿色高亮遮罩。显示这两个方格内的绿色数字“1”、“1”。
- 步骤4（推导左侧）：隐藏上一步高亮遮罩（保留已填数字）。显示俯视图 R1C1 和 R2C1 的绿色高亮遮罩。显示这两个方格内的绿色数字“2”、“1”。
- 步骤5（求和）：隐藏所有高亮遮罩（保留所有已填数字和辅助线）。在底部显示绿色求和公式“2 + 1 + 1 + 1 = 5”。

- 红色引导线2 (y=330) 与 俯视图网格：引导线从右侧进入，停在 x=375，俯视图第2行仅在 x=310~370 有方格，引导线完美穿过空白区，无冲突。
- “行高”标签 (250,240) 与 俯视图网格左边缘 (x=310)：间距 60px，无冲突。
- “列高”标签 (270,390) 与 俯视图网格下边缘 (y=360)：间距 30px，无冲突。
- 求和公式 (400,430) 与 控件栏 (y=450)：间距 20px，无冲突。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：在 SVG 内底部 (y=450~490) 放置两个按钮，用于控制步骤 0 到 5 的前后切换。
- 教师操作流程：教师首先展示题目给出的三视图（步骤0）；点击“下一步”引导学生观察主视图得出每列最高层数（步骤1）；再次点击得出左视图每行最高层数（步骤2）；接着引导学生先确定只有一行的列的方块数（步骤3）；再利用行高限制确定剩余复杂位置的方块数（步骤4）；最后点击展示总和计算（步骤5）。

[技术实现]
- JS 库选择及原因：原生 SVG。本场景主要由简单的矩形网格、直线和文本构成，原生 SVG 能够提供最精确的像素级控制，且易于实现透明度动画和虚线样式。
- 画布尺寸：800 × 500 px
- 布局草图：
  [顶部：主视图(左) 左视图(右)]
  [中部：俯视图(居中放大)]
  [底部：求和公式]
  [最底部：控件栏]
- 关键实现要点：
  - 使用 `<g>` 标签对不同步骤的元素进行分组（如 `scene1-step1-elements`），通过控制组的 `opacity` 或 `display` 属性来实现步骤切换。
  - 引导线使用 `<path>` 或 `<polyline>`，设置 `stroke-dasharray="5,5"` 实现虚线效果，末端可使用 `<marker>` 定义箭头。
  - 状态机设计：定义一个 `currentStep` 变量（0-5），每次点击按钮更新变量，并调用 `updateScene()` 函数，该函数根据当前步骤显隐对应的 SVG 组。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-front-view`，`scene1-btn-next`）。
- IIFE 隔离：所有 JS 代码必须包裹在 `(function() { ... })()` 中，避免全局变量污染。
