problem_45_biology_g9

场景导航：Scene 1

下图是血液流经某器官的示意图，下列表述正确的是（ ）
A．b表示心脏，则C血管里流的是静脉血
B．b表示肺，则C血管里流的是静脉血
C．b表示小肠，则C血管里流的是动脉血
D．b表示组织细胞，则C血管里流的是静脉血

题目分析
本题考查人体不同器官或结构中血液成分的变化规律。解题的关键是明确血管 a（流入）、结构 b（毛细血管网或器官）、血管 c（流出）的对应关系，以及血液流经特定器官时发生的气体交换或物质交换。

整体讲解思路

  1. 首先明确图示的基本模型：a 为流入血管，b 为器官/毛细血管网，c 为流出血管。
  2. 逐一分析四个选项，将 b 代入具体器官，推导 a 和 c 的血管类型及血液成分（动脉血/静脉血）。
  3. 重点利用颜色对比（红色代表动脉血，蓝色代表静脉血）直观展示血液流经肺部、小肠、组织细胞等部位前后的成分变化。

图示规划说明
设计一个分步导航的动态图示，以原图为基础骨架，通过分步点击，依次将 b 替换为心脏、肺、小肠、组织细胞，并用红蓝两色动态填充血管 a 和 c，直观呈现各选项的对错，最后得出正确答案。

教师在讲解时，可按照以下步骤引导学生：

  1. 引入模型：首先让学生观察初始图示，明确血液流动的基本方向是 a → b → c。通常 a 代表动脉（或流入心脏的静脉），b 代表毛细血管网（或心脏），c 代表静脉（或流出心脏的动脉）。
  2. 分析选项A（心脏）：点击进入步骤1。引导学生回忆心脏的结构。如果 b 是心脏，那么 a 是静脉，c 是动脉。但心脏分为左右两半，左心房、左心室流动脉血（主动脉流出动脉血），右心房、右心室流静脉血（肺动脉流出静脉血）。因此，c 血管里流的不一定是静脉血，A错误。
  3. 分析选项B（肺）：点击进入步骤2。引导学生思考肺循环的特点。血液流经肺部毛细血管时，发生气体交换，血液中的二氧化碳进入肺泡，肺泡中的氧气进入血液。因此，流入的 a（肺动脉）是静脉血（蓝色），流出的 c（肺静脉）是动脉血（红色）。B错误。
  4. 分析选项C（小肠）：点击进入步骤3。小肠是体循环的一部分，也是消化吸收的主要场所。流入小肠的 a 血管是动脉，流动脉血（红色）。在小肠毛细血管处，血液不仅将氧气供给组织细胞，还吸收了大量营养物质。流出的 c 血管是静脉，流静脉血（蓝色）。C错误。
  5. 分析选项D（组织细胞）：点击进入步骤4。组织细胞进行呼吸作用需要消耗氧气，产生二氧化碳。因此，当血液流经组织细胞周围的毛细血管 b 时，血液中的氧气扩散给细胞，细胞产生的二氧化碳扩散入血液。流入的 a 血管流动脉血（红色），流出的 c 血管流静脉血（蓝色）。D正确。

完整解答：

  • 若 b 为心脏，则 a 为静脉，c 为动脉。若为左侧心脏，c（主动脉）流动脉血；若为右侧心脏，c（肺动脉）流静脉血。A错误。
  • 若 b 为肺，则 a 为肺动脉（流静脉血），c 为肺静脉（流动脉血）。B错误。
  • 若 b 为小肠，则 a 为肠动脉（流动脉血），c 为肠静脉/肝门静脉（流静脉血）。C错误。
  • 若 b 为组织细胞，则 a 为体动脉（流动脉血），c 为体静脉（流静脉血）。D正确。

正确答案：D

课堂讲解建议：

  • 强调“动脉血”和“静脉血”的概念区分：动脉血是含氧丰富、颜色鲜红的血；静脉血是含氧较少、颜色暗红的血。不要将“动脉血/静脉血”与“动脉/静脉”血管绝对等同（如肺循环中的特例）。
  • 借助红蓝颜色的视觉冲击，帮助学生建立“耗氧器官（如小肠、组织细胞）使动脉血变静脉血”和“吸氧器官（如肺）使静脉血变动脉血”的直观印象。
