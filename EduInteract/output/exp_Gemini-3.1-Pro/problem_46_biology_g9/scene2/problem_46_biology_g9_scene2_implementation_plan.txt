[图示主题与整合说明]
- 本图示主题：DNA单链突变后的复制传递规律
- 整合的步骤/概念：单点突变（选项C），突变基因在多次复制中的比例
- 教学价值：教师可以通过分步演示，清晰地向学生展示DNA单链突变后，经过半保留复制，突变链和正常链各自的后代情况，从而直观得出突变基因在后代中的比例恒为1/2，帮助学生理解选项C的错误原因。

[视觉元素清单]
- 初始DNA：两条水平线段（#1565c0），中间用垂直短线连接代表碱基对（x=320,340,360,380,420,440,460,480）。x=400处不画短线，直接在线段上下方写字母。
- 突变碱基：步骤1中，上方的'T'变为'A'，颜色变为 #c62828，同时上链颜色变为 #c62828。
- 复制箭头：带箭头的实线（#888888）。
- 子代DNA：结构同初始DNA，长度减半。左侧全为 #1565c0，右侧全为 #c62828。
- 树状分支图：使用虚线三角形（stroke-dasharray: 5,5），左侧边框和填充为 #1565c0（透明度10%），右侧边框和填充为 #c62828（透明度10%）。
- 文本标签：字体大小 14px，结论文本 18px 加粗。

[分步序列]
- 初始状态（步骤0）：显示初始DNA（上链T，下链A，均为蓝色 #1565c0），显示"初始DNA"标签。隐藏其他所有元素。
- 步骤1：点击「下一步」→ 发生单点突变。初始DNA上链的'T'变为'A'，颜色变为红色 #c62828。上链线段颜色也变为红色。显示"单点突变"标签。
- 步骤2：点击「下一步」→ 第1次复制。显示向下左右分叉的箭头和"第1次复制"标签。显示左侧子代DNA（正常，全蓝，上T下A）和右侧子代DNA（突变，全红，上A下T）。
- 步骤3：点击「下一步」→ 第n次复制。显示两个虚线三角形和"第n次复制"标签。显示"正常DNA"和"突变DNA"标签。显示底部结论文本："经过 n 次复制，突变DNA占总数的 1/2，选项C错误"（其中"1/2"和"C错误"标红）。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：底部居中放置两个按钮，控制步骤0~3的切换。
- 教师操作流程：教师首先展示初始DNA，点击下一步展示突变过程，强调A-A错配；再次点击展示第1次复制，解释半保留复制导致突变链和正常链分离；最后点击展示第n次复制，通过树状图直观得出1/2的比例结论。

[技术实现]
- JS 库选择及原因：原生 SVG。图形主要由线段、文本和简单多边形组成，SVG 能够方便地控制 DOM 元素的显示/隐藏和颜色变化，非常适合实现分步动画。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
    (300,80)  初始DNA  (500,110)
         ↙ 第1次复制 ↘
  (150,200)左子代   右子代(550,200)
      △ 第n次复制 △
    正常DNA       突变DNA
         结论文本 (400,410)
  [控件栏 ◀上一步 下一步▶ (y=460)]
  ```
- 关键实现要点：
  - 状态机设计：定义 `currentStep` 变量（0-3），每次点击按钮更新变量并调用 `updateScene()` 函数。
  - `updateScene()` 函数根据 `currentStep` 控制各 SVG 元素的 `display` 属性（'none' 或 'block'）以及颜色属性。
  - 步骤1的突变动画可以通过直接修改文本内容（'T' -> 'A'）和 `fill` / `stroke` 颜色实现。
  - ID 命名规范：所有元素 ID 以 `scene2-` 开头，例如 `scene2-init-dna`, `scene2-btn-next`。
  - IIFE 隔离：整个脚本包裹在 `(function() { ... })()` 中，避免全局变量污染。
