[图示主题与整合说明]
- 本图示主题：地球经纬网空间关系与大圆航线、对跖点演示
- 整合的步骤/概念：平面经纬网判读 -> 三维球面坐标映射 -> 最短航线（大圆劣弧）轨迹与方向 -> 对跖点空间连线
- 教学价值：帮助学生克服从二维地图到三维球面的空间想象困难，直观理解“大圆劣弧”为何向高纬度凸出，以及对跖点的严格空间对称关系。分步演示完美契合教师的讲解节奏。

[视觉元素清单]
- 2D经纬网：SVG线段，颜色 #888888，线宽 2px。
- 2D点 M, N：SVG实心圆，颜色 #1565c0。
- 3D地球：Three.js `SphereGeometry`，材质 `MeshBasicMaterial`，颜色 #1565c0，透明度 0.1（开启 transparent）。附加经纬线网格（wireframe 球体，颜色 #888888，透明度 0.3）。
- 3D点 M, N, M', O：Three.js `SphereGeometry`，颜色 #1565c0。
- 纬线弧 M-N：Three.js `Line`，虚线材质 `LineDashedMaterial`，颜色 #888888。
- 大圆劣弧 M-N：Three.js `Line`，实线材质 `LineBasicMaterial`，颜色 #c62828，线宽 2px。
- 飞机/箭头：Three.js `ConeGeometry`，颜色 #c62828，沿大圆弧移动。
- 对跖点连线 M-O-M'：Three.js `Line`，虚线，颜色 #2e7d32。
- 动态文本：在 SVG 层顶部居中显示，如“大圆劣弧航向：先东北，后东南”。

[分步序列]
- 初始状态（步骤0）：显示 2D SVG 经纬网，3D Canvas 隐藏（opacity: 0）。高亮向东、向北递增的箭头，帮助学生判读 M (60°N, 80°E) 和 N (60°N, 120°E)。
- 步骤1（球面映射）：点击「下一步」。2D SVG 渐隐（opacity: 0），3D Canvas 渐显（opacity: 1）。展示半透明 3D 地球。相机初始位置设为 (341, 200, -60)，即看向 30°N, 100°E 方向，清晰展示 M 和 N 的空间位置。3D 点 M、N 及其标签出现。
- 步骤2（最短航线）：点击「下一步」。在 3D 球面上同时绘制 M 到 N 的纬线弧（灰色虚线）和大圆劣弧（红色实线）。红色箭头沿大圆劣弧从 M 滑行至 N，循环动画。顶部出现文字提示“最短航线（大圆劣弧）：先东北，后东南”。
- 步骤3（对跖点）：点击「下一步」。隐藏航线和箭头。相机平滑移动至 (-70, 0, 394)，即看向 0°N, 10°W 方向。此时 M (80°E) 位于地球右侧边缘，M' (100°W) 位于左侧边缘。绘制穿过球心 O 的绿色虚线 M-O-M'。显示 M' 和 O 的点及标签。高亮赤道和本初子午线（黑色粗实线）辅助定位。

[标签冲突检查]
- 2D 标签：M (310,170) 与 80° (300,130) 纵向错开 40px，无冲突。N (510,170) 与 120° (500,130) 无冲突。
- 3D 标签（投影到 2D）：
  - 步骤1&2：相机看向 100°E，M (80°E) 在左，N (120°E) 在右。M 标签向左上偏移，N 标签向右上偏移，两者相距约 100px，无冲突。
  - 步骤3：相机看向 10°W，M 在右侧，M' 在左侧，O 在中心。M 标签向右上，M' 标签向左下，O 标签向右下。三者在屏幕上水平相距极远（>100px），绝对无冲突。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：底部居中放置两个按钮，ID 分别为 `scene1-btn-prev` 和 `scene1-btn-next`。
- 教师操作流程：教师首先引导学生观察二维图，判断 M、N 坐标；点击下一步，展示其在地球上的真实位置；再点击下一步，对比纬线与大圆航线，讲解最短航线方向；最后点击下一步，展示对跖点的空间对称关系。支持鼠标拖拽 3D 地球自由旋转观察（OrbitControls）。

[技术实现]
- JS 库选择：Three.js (3D 渲染) + OrbitControls (交互旋转)。CDN 引入。
- 画布尺寸：800 × 500 px。外层容器 `position: relative; overflow: hidden;`。
- 布局草图：
  ```
  [图示区 800×500]
   - 绝对定位的 3D Canvas (z-index: 1, 宽高 800x500)
   - 绝对定位的 SVG 覆盖层 (z-index: 2, pointer-events: none, 用于 2D 网格和 3D 投影标签)
  [控件栏 800×40，位于 y=450~490]
   - ◀上一步 | 下一步▶ (z-index: 3)
  ```
- 关键实现要点：
  - 坐标转换：经纬度转 3D 笛卡尔坐标公式 `x = R * cos(lat) * sin(lon)`, `y = R * sin(lat)`, `z = R * cos(lat) * cos(lon)`。注意 Three.js 中 y 是向上轴。
  - 3D 标签投影：在 `requestAnimationFrame` 循环中，使用 `vector.clone().project(camera)` 将 3D 坐标转换为 NDC [-1, 1]，再映射到 800x500 的 SVG 坐标 `screenX = (ndc.x + 1)/2 * 800`, `screenY = -(ndc.y - 1)/2 * 500`，实时更新 SVG text 元素的 x, y 属性。
  - 大圆插值：使用向量插值 `v = vM.clone().lerp(vN, t).normalize().multiplyScalar(R)` 生成大圆弧的顶点。箭头方向通过 `vNext.clone().sub(v).normalize()` 计算并使用 `lookAt` 设置朝向。
  - 动画状态机：使用 `currentStep` 变量。步骤切换时，使用简单的插值动画（如 `camera.position.lerp`）实现平滑过渡。
  - ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-svg-layer`）。
  - IIFE 隔离：所有 JS 代码包裹在 `(function() { ... })()` 中。
