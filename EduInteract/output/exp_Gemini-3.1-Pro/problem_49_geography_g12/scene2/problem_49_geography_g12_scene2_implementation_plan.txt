[图示主题与整合说明]
- 本图示主题：目标地点的正午太阳高度与地方时计算
- 整合的步骤/概念：将正午太阳高度角的计算（H = 90° - 纬度差）转化为直观的地球侧视几何模型；将地方时的计算转化为一维经度数轴上的距离与时间换算。
- 教学价值：教师可以通过切换两个独立的状态，分别清晰地讲解高度角的空间几何意义和地方时的线性代数关系，避免将两个不同维度的计算混杂在一起，降低学生的认知负荷。

[分步序列]
- 状态1（默认）：展示正午太阳高度计算。显示地球侧视剖面、赤道、直射点与目标地连线、地平面、平行太阳光。通过圆弧标出纬度差（20°和30.5°）以及高度角H（39.5°），左侧显示计算公式。
- 状态2：展示地方时计算。隐藏状态1元素，显示水平经度数轴。标出直射点（60°E, 12:00）和目标地（114.5°E, 15:38）。上方用绿色双向箭头展示经度差（Δλ=54.5°），下方用绿色双向箭头展示时间差（Δt=3h38m），左侧上下方显示计算公式。

[交互方案]
- 交互类型：多状态切换（2个状态）
- 控件说明：在 SVG 底部（y=450 区域）放置两个按钮：「正午太阳高度计算」和「地方时计算」。
- 教师操作流程：教师首先在默认状态下结合几何图形讲解高度角公式的推导；然后点击「地方时计算」按钮，画面切换为数轴，教师借此讲解经度差到时间差的线性换算逻辑。

[技术实现]
- JS 库选择：原生 SVG。由于涉及大量精确的几何线段、圆弧和文本定位，SVG 是最可靠且清晰的实现方式。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800x450]
  (状态1: 左侧公式，右侧地球剖面)
  (状态2: 上下公式，中间贯穿数轴)
  [控件栏 800x50 (y=450~500)]
  [ 按钮: 正午太阳高度计算 ] [ 按钮: 地方时计算 ]
  ```
- 关键实现要点：
  - 使用两个 `<g>` 标签分别包裹状态1和状态2的所有元素，通过修改 `display` 属性实现切换。
  - 状态1中的圆弧使用 SVG `<path>` 的 `A` 指令精确绘制，确保与线段完美贴合。
  - 箭头使用 `<defs>` 中的 `<marker>` 实现，保证箭头方向自动对齐线段。
  - ID 命名规范：所有元素 ID 以 `scene2-` 为前缀（如 `scene2-state1`, `scene2-btn-height`）。
  - JS 逻辑封装在 IIFE 中，通过 `document.getElementById` 绑定按钮点击事件，切换对应 `<g>` 元素的显示状态，并更新按钮的高亮样式。
