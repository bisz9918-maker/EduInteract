[图示主题与整合说明]
- 本图示主题：实物电路状态与电流路径动态分析

[视觉元素清单]
- 电池组：灰色底座，深灰色电池体，黑色接线柱。
- 开关S：灰色底座，黑色接线柱，黑色粗线表示闸刀（可旋转闭合）。
- 灯泡L1/L2：灰色底座，黑色接线柱，圆形玻璃泡，内部交叉灯丝。发光时叠加黄色半透明圆（#fbc02d，透明度30%）。
- 导线：黑色实线（stroke-width: 3）。导线b在状态2变为灰色虚线（#888888）。
- 高亮路径：在原导线下方叠加粗线（stroke-width: 8），通过透明度和颜色变化表示电流。红色（#c62828）、蓝色（#1565c0）、绿色（#2e7d32）。
- 标签：黑色文本，字号16px，无衬线字体。

[分步序列]
- 初始状态（步骤0）：开关S断开（闸刀翘起），所有导线为黑色实线，灯泡不亮，无高亮路径。
- 步骤1（原图闭合S）：点击「下一步」。开关S闭合。导线pos、导线b、导线M、开关、导线neg 底部出现红色高亮路径。灯泡不亮。中央显示红色文字“电源短路”。
- 步骤2（验证选项C）：点击「下一步」。导线b变为灰色虚线（表示去掉）。导线pos、L2内部、导线a、L1内部、导线M、开关、导线neg 底部出现蓝色高亮路径。L1、L2亮起（黄色光晕）。中央显示蓝色文字“串联”。
- 步骤3（验证选项D）：点击「下一步」。导线b恢复黑色实线。导线M的终点从B平滑移动到A，标签M跟随移动至(430,395)。导线pos、导线M、开关、导线neg 出现绿色高亮（干路）；导线a、L2内部、导线b、L1内部 出现蓝色高亮（支路）。L1、L2亮起。中央显示绿色文字“并联”。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：在SVG内部底部（y=460）居中放置两个按钮。
- 教师操作流程：教师首先展示原图，点击“下一步”演示闭合开关后的短路现象；再次点击演示去掉导线b后的串联通路；最后点击演示改接导线M后的并联通路。可随时点击“上一步”回退对比。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。电路图由标准几何图形和贝塞尔曲线构成，原生SVG配合CSS transition即可完美实现路径形变（导线M移动）和颜色渐变，无需引入外部库。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×440]
  电源(左上)       L2(右上)
  
        状态提示(居中)
  
  开关(左下)       L1(右下)
  [控件栏 800×60 (y=440~500)]
    [◀上一步]  [下一步▶]
  ```
- 关键实现要点：
  1. 状态机设计：定义 currentState (0~3)，每次按钮点击更新状态并调用 updateScene()。
  2. 动画实现：为所有高亮路径的 opacity、stroke，以及导线M的 d 属性添加 CSS transition: all 0.5s ease。
  3. 导线M形变：状态3时，将导线M的 d 属性从 M 300 350 C 400 420, 600 420, 650 300 修改为 M 300 350 C 400 380, 480 380, 550 300，SVG会自动进行平滑插值动画。
  4. 高亮层级：高亮路径必须在 <g id="scene1-highlights"> 中，且位于普通导线 <g id="scene1-wires"> 之下，避免遮挡黑色主线。
- ID 命名规范：所有元素ID以 scene1- 开头（如 scene1-wire-m, scene1-btn-next）。
- IIFE 隔离：所有JS逻辑封装在 (function() { ... })() 中，避免全局变量污染。
