[技术实现]
- JS 库选择及原因：原生 SVG。由于全是规则的几何图形（圆、线段、二次贝塞尔曲线）和文本，原生 SVG 能够提供最清晰的渲染和最方便的 DOM 操作。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
    (400,190) 昼半球圆
    (400,420) 时间轴
  [控件栏 y=460~490]
    [上一步] [下一步]
  ```
- 关键实现要点：
  - 使用 <path> 绘制赤道和纬线，使用 Q 指令实现二次贝塞尔曲线。
  - 状态机设计：定义 let currentState = 0，在 updateState() 函数中根据当前状态控制各 SVG 元素的 display 属性或 stroke/fill 颜色。
  - 动画过渡：可以为颜色变化和透明度变化添加 CSS transition 以提升视觉体验。
  - ID 命名规范：所有元素 ID 均以 scene1- 开头，如 scene1-circle, scene1-point-a, scene1-label-a-coords 等。
  - IIFE 隔离：整个脚本包裹在 (function() { ... })() 中。
