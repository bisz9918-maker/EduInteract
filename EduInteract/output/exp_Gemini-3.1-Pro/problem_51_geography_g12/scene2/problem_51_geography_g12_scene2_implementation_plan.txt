[图示主题与整合说明]
- 本图示主题：纬度与地转偏向力、线速度的关系对比
- 整合的步骤/概念：将地球自转的两个重要物理量（地转偏向力、自转线速度）与纬度（赤道、回归线、极圈）的关系整合在同一剖面图中，通过多状态切换进行直观对比。
- 教学价值：教师可通过切换按钮，分别展示同一组点在不同物理量下的相对大小关系，帮助学生直观理解“地转偏向力向两极递增”和“自转线速度向两极递减”的核心规律。

[分步序列]
- 初始状态（状态1：地转偏向力）：
  - 显示基础经纬网、夜半球、点A/B/C/O及基础标签。
  - 显示状态1专属元素：A点旁的蓝色"0"、B点和C点向右的蓝色箭头及标签（C箭头最长）。
  - 右侧面板显示蓝色标题"地转偏向力大小对比"及递增规律。
  - 底部"地转偏向力"按钮呈激活态（蓝底白字）。
- 状态2（自转线速度）：
  - 点击"自转线速度"按钮触发。
  - 隐藏状态1专属元素。
  - 显示状态2专属元素：A、B、C点向右的绿色箭头及标签（A箭头最长，C箭头最短）。
  - 右侧面板显示绿色标题"自转线速度大小对比"及递减规律。
  - 底部"自转线速度"按钮呈激活态（绿底白字）。

[交互方案]
- 交互类型：多状态切换（2个状态按钮）。
- 控件说明：在 SVG 容器底部（y=450区域）绝对定位一个 HTML div，包含"地转偏向力"和"自转线速度"两个按钮。
- 教师操作流程：图示加载后默认展示地转偏向力状态，教师可结合右侧规律文字讲解。随后点击"自转线速度"按钮，图示瞬间切换箭头方向和长度，教师可直观对比同一组点在不同物理量下的相反变化趋势。

[技术实现]
- JS 库选择及原因：原生 SVG + HTML DOM。图形由简单的几何路径和圆组成，原生 SVG 足以实现精确绘制和高质量渲染，且易于通过 DOM 操作切换状态。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  +-----------------------------------------+-------------------------+
  |                                         |                         |
  |    自转方向                             |  [地转偏向力大小对比]   |
  |      /                                  |                         |
  |     /   A(赤道)                         |  规律：由赤道向两极递增 |
  |    |   ● 0                              |                         |
  |    |    \                               |  A(赤道)：最小 (0)      |
  |    |     \ B(南回归线)                  |  B(南回归线)：较小      |
  |    |      ●-----> 较小                  |  C(南极圈)：最大        |
  |    |       \                            |                         |
  |    |        \                           |                         |
  |    |         \ C(南极圈)                |                         |
  |    |          ●------------> 最大       |                         |
  |    |           \                        |                         |
  |    +------------● O                     |                         |
  |                                         |                         |
  +-----------------------------------------+-------------------------+
  |        [ 地转偏向力 ]   [ 自转线速度 ]                            |
  +-------------------------------------------------------------------+
  ```
- 关键实现要点：
  - SVG 结构分为基础层 `<g id="scene2-base">`、状态1层 `<g id="scene2-state1">`、状态2层 `<g id="scene2-state2">`。
  - 使用 `<defs>` 定义三种颜色的箭头 marker（`scene2-arrow-blue`, `scene2-arrow-green`, `scene2-arrow-black`）。
  - 状态切换逻辑：点击按钮时，修改对应 `<g>` 的 `display` 属性，并更新按钮的 CSS 样式（背景色和文字颜色）。
- ID 命名规范：所有交互元素和分组 ID 必须以 `scene2-` 为前缀（如 `scene2-btn-coriolis`）。
- IIFE 隔离：所有 JS 逻辑必须包裹在 `(function() { ... })()` 中，避免全局变量污染。
