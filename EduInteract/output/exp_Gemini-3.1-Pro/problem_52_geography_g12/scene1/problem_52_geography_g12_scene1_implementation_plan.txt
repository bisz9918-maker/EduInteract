[图示主题与整合说明]
- 本图示主题：解析“8字形”半球展开图，确定各点经纬度
- 整合的步骤/概念：通过已知半球的经度跨度（180°）和等份数（6份），推导出每格经度差（30°），进而逐步确定图中各个关键点（甲、B、C、乙、A）的经度。
- 教学价值：教师可利用分步动画，引导学生先观察西半球（南半球），计算出经度间隔，再将此规律应用到东半球（北半球），清晰展示经度推导的逻辑过程。

[分步序列]
- 初始状态（步骤0）：显示基础网格、阴影区域、赤道、所有基础点（S, N, 甲, B, C, 乙, A）及基础点名标签。隐藏所有推导文本、经度数值和高亮。
- 步骤1：点击「下一步」→ 高亮南半球（西半球）的外圆、赤道段和经线（蓝色）。显示左侧边界经度 "160°E" 和 "20°W"（蓝色）。在南半球上方空白区显示推导文本 "西半球: 180°跨度, 6等份 → 30°/格"（绿色）。
- 步骤2：点击「下一步」→ 保持步骤1状态。将甲点和B点高亮为红色。在甲点下方显示 "140°W"（红色），在B点下方显示 "80°W"（红色）。
- 步骤3：点击「下一步」→ 保持之前状态。高亮北半球（东半球）的外圆、赤道段和经线（蓝色）。显示右侧边界经度 "20°W" 和 "160°E"（蓝色）。在北半球下方空白区显示推导文本 "东半球: 180°跨度, 6等份 → 30°/格"（绿色）。
- 步骤4（最终步骤）：点击「下一步」→ 保持之前状态。将C点、乙点、A点高亮为红色。在C点下方显示 "70°E"（红色），在乙点右下方显示 "100°E"（红色）。A点处的 "160°E" 标签加粗或添加红色下划线以示强调。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：底部居中放置两个按钮，控制状态机（0~4）。
- 教师操作流程：教师首先展示原图，然后点击“下一步”引导学生观察西半球并计算每格经度，再次点击得出甲和B的经度；接着点击进入东半球的分析，最后得出C、乙、A的经度。可随时点击“上一步”回退。

[技术实现]
- JS 库选择及原因：原生 SVG。图形由标准的圆弧、直线和虚线构成，SVG 的 `<path>` 和 `<text>` 标签能完美实现精确控制和高质量渲染。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  (上方空白) 西半球推导文本
  (左侧) 南半球图形       (右侧) 北半球图形
  (下方空白) 东半球推导文本
  [控件栏 (y=460~490) ◀上一步  下一步▶]
  ```
- 关键实现要点：
  - 使用 `M x y A rx ry x-axis-rotation large-arc-flag sweep-flag x y` 绘制经线椭圆弧。
  - 阴影区域使用 `<pattern>` 定义斜线，并应用到 `<path>` 的 `fill` 属性。
  - 状态切换通过修改对应 SVG 组（`<g>`）的 `opacity` 或 `display` 属性实现，配合 CSS `transition: opacity 0.3s` 实现平滑过渡。
  - ID 命名规范：所有元素 ID 均以 `scene1-` 开头（如 `scene1-btn-next`, `scene1-group-step1`）。
  - IIFE 隔离：所有逻辑封装在 `(function() { ... })()` 中。
