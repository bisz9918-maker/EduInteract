[图示主题与整合说明]
- 本图示主题：推导并绘制北半球的阴影（黑夜）部分
- 整合的步骤/概念：对应题目(3)，将抽象的昏线推导和阴影绘制过程拆解为“找直射点经线 -> 推导昏线与赤道交点 -> 结合极昼画昏线 -> 填充阴影”四个步骤。
- 教学价值：教师可通过分步演示，帮助学生建立正确的空间作图思路，理解地方时计算与晨昏线绘制的几何关系。

[视觉元素清单]
- 基础网格：黑色 `#000000` 线条，纬线为灰色 `#888888` 虚线。
- 直射点经线 (10°E) 及北极圈：蓝色 `#1565c0`，加粗突出。
- 昏线推导元素 (100°E高亮、交点、箭头、昏线)：红色 `#c62828`。
- 时间标签 (12:00, 18:00)：绿色 `#2e7d32`。
- 阴影填充：黑色 `#000000`，`opacity: 0.2`。
- 文本标签：字体大小 14px，时间标签 12px。

[分步序列]
- 初始状态（步骤0）：显示基础网格、蓝色10°E经线及时间标签(12:00)、蓝色北极圈及"极昼"标签。隐藏推导过程和阴影。
- 步骤1：点击「下一步」→ 100°E经线变为红色，赤道交点出现红点，显示红色推导箭头及"+90° (+6小时)"标签，显示100°E及"18:00"标签。
- 步骤2：点击「下一步」→ 出现红色昏线曲线，显示"昏线"标签。
- 步骤3：点击「下一步」→ 昏线以东区域填充半透明黑色阴影，显示"黑夜"标签。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：在 SVG 容器底部 (y=460~490 区域) 居中放置两个按钮。
- 教师操作流程：教师首先指出直射点经线和极昼区域，点击下一步推导昏线与赤道的交点，再点击下一步连接交点与极昼边缘画出昏线，最后点击下一步填充阴影完成作图。

[技术实现]
- JS 库选择及原因：原生 SVG。地理网格和投影曲线可通过精确的 SVG Path (Arc 和 Bezier) 实现，无需引入庞大的外部库。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×450]
  [控件栏 800×50，包含 上一步/下一步 按钮]
  ```
- 关键实现要点：
  - 投影计算：经线使用椭圆弧 `A` 指令，昏线使用三次贝塞尔曲线 `C` 指令拟合，确保地理空间关系的视觉准确性。
  - 状态机：使用 `currentStep` (0~3) 变量，通过 `updateState()` 函数统一控制各组 SVG 元素的 `display` 属性。
  - 动画：可为阴影填充和昏线添加简单的 CSS `transition: opacity 0.5s` 实现平滑过渡。
- ID 命名规范：所有元素 ID 以 `scene3-` 为前缀，如 `scene3-dusk-line`, `scene3-btn-next`。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
