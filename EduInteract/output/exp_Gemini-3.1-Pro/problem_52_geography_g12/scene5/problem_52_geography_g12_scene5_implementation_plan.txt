[图示主题与整合说明]
- 本图示主题：正午太阳高度计算与地球公转轨道位置
- 整合的步骤/概念：将题目(5)的正午太阳高度角几何计算与题目(6)的地球公转轨道宏观位置通过分步平滑串联。
- 教学价值：教师可先通过侧视剖面图引导学生理解“直射点”、“当地纬度”与“太阳高度角”的几何关系并推导公式；随后视角拉远切换至公转轨道俯视图，直观展示夏至日地球在轨道上的位置，帮助学生建立从微观几何到宏观天体运动的空间认知。

[分步序列]
- 初始状态（步骤0）：显示阶段1的地球侧视剖面图，包含赤道、北回归线和北京纬度。隐藏太阳光线、切线、角度和公式。隐藏阶段2。
- 步骤1：点击「下一步」→ 出现平行的太阳光线（红）、直射点切线与90°符号、北京点切线与高度角H弧线。
- 步骤2：点击「下一步」→ 在右下方淡入显示计算公式：`正午太阳高度 H = 90° - (39° - 23°26') = 74°26'`（绿）。
- 步骤3：点击「下一步」→ 阶段1整体淡出，阶段2（公转轨道俯视图）淡入。显示轨道、太阳、近日点、远日点及其标签。隐藏夏至日地球。
- 步骤4：点击「下一步」→ 在轨道右下方出现夏至日地球（红），并绘制连接太阳的红色虚线，显示结论文本“接近远日点，公转速度较慢”。

[交互方案]
- 交互类型：分步按钮导航
- 控件说明：底部居中（y=460）放置控件栏，包含「◀ 上一步」按钮、「步骤 X / 4」文本指示器、「下一步 ▶」按钮。
- 教师操作流程：教师首先停留在步骤0介绍地球基础纬线；点击进入步骤1，结合光线讲解高度角的几何定义；进入步骤2展示计算结果；随后进入步骤3切换宏观视角，最后在步骤4点出夏至日的轨道位置特征。

[技术实现]
- JS 库选择：原生 SVG。场景主要由标准几何图形（圆、椭圆、线段、圆弧）构成，原生 SVG 配合 CSS transition 能完美实现平滑的淡入淡出动画。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×450]
  (阶段1和阶段2的SVG元素分别放在 <g id="scene5-phase1"> 和 <g id="scene5-phase2"> 中，绝对定位重叠)
  [控件栏 800×50 (y=450~500)]
  [ ◀ 上一步 ]  [ 步骤 X / 4 ]  [ 下一步 ▶ ]
  ```
- 关键实现要点：
  1. 状态机设计：定义 `currentStep` (0~4)，每次点击按钮更新步数并调用 `updateScene()`。
  2. 视图切换：通过修改 `<g>` 标签的 `opacity` 属性实现阶段1和阶段2的平滑切换，同时设置 `pointer-events: none` 防止隐藏元素遮挡交互。
  3. 坐标系：SVG 默认坐标系（左上角为原点，向下为Y正轴），所有坐标已按此标准计算。
- ID 命名规范：所有元素 ID 均以 `scene5-` 开头（如 `scene5-phase1`, `scene5-btn-next`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
