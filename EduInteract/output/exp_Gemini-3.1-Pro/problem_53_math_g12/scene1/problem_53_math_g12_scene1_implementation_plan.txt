[图示主题与整合说明]
- 本图示主题：线面平行性质定理的应用及三角形相似比例关系
- 整合的步骤/概念：四棱锥基础结构、线面平行推导线线平行、三角形内的平行线分线段成比例
- 教学价值：通过分步动画，教师可以引导学生逐步剥离复杂的3D几何背景，将空间线面平行问题转化为平面三角形内的相似比例问题，清晰展示“降维”的数学思想。

[视觉元素清单]
- 顶点：P, A, B, C, D, M, N (黑色圆点，半径4px，#000000)
- 标签：对应字母，16px Arial，#000000
- 可见边：PA, PB, PC, AB, BC (实线，#000000，2px)
- 不可见边：PD, AD, CD (虚线，#000000，2px，stroke-dasharray="5,5")
- 辅助线：AC, MN (虚线，初始#1565c0，2px，stroke-dasharray="5,5")
- 平面PAC：多边形 P-A-C，填充 #1565c0，透明度 0 (初始)
- 平面PAD：多边形 P-A-D，填充 #c62828，透明度 0 (初始)
- 比例数值：1, 4 (16px Arial，粗体，#2e7d32)
- 平行箭头：在PA和MN中点处，#c62828，初始透明度0

[分步序列]
- 初始状态（步骤0）：显示四棱锥P-ABCD，点M, N，线段AC, MN（蓝色虚线）。显示CM和MA旁的比例"1"和"4"。
- 步骤1：点击「下一步」→ 平面PAC（蓝色，透明度0.2）和平面PAD（红色，透明度0.2）高亮显示。交线PA加粗（红色 #c62828，4px）。
- 步骤2：点击「下一步」→ 线段MN加粗（红色 #c62828 虚线，4px）。在PA和MN中点处出现红色同向平行箭头（>），表示MN || PA。
- 步骤3：点击「下一步」→ 降维转化。点B, D及线段PB, AB, BC, PD, AD, CD颜色变为#888888，透明度降至0.2。平面PAD填充消失。视觉聚焦于△PAC。
- 步骤4：点击「下一步」→ 在CN和NP旁淡入比例数值"1"和"4"。在右上角淡入结论文本 "NC : NP = 1 : 4"（绿色 #2e7d32，加粗，20px）。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：底部居中放置两个按钮，控制步骤0-4的切换。
- 教师操作流程：教师首先展示题目条件（步0），然后点击下一步引导学生找交线（步1），再点击下一步得出线线平行（步2），接着点击下一步剥离立体背景聚焦平面（步3），最后点击下一步得出比例结论（步4）。

[技术实现]
- JS 库选择及原因：原生 SVG。因为本题主要是简单的点、线、多边形绘制，SVG的DOM操作配合CSS transition可以非常方便地实现颜色、透明度、粗细的动画过渡，无需引入复杂的Canvas库。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800x500]
    (350,100) P
       /|\
      / | \
     /  |  \ N(590,228)
    /  D|...\... C(650,260)
   / /  |   / M(550,292)
  A(150,420)--- B(500,420)
  [控件栏 y=450~490]
    [◀上一步] [下一步▶]
  ```
- 关键实现要点：
  - 使用 `<svg>` 元素，内部按层级分组：`<g id="scene1-planes">` (面), `<g id="scene1-lines-bg">` (背景线), `<g id="scene1-lines-fg">` (前景线), `<g id="scene1-points">` (点), `<g id="scene1-labels">` (文本)。
  - 状态机设计：定义 `currentStep` 变量（0-4），每次点击按钮更新变量并调用 `updateScene()` 函数。
  - `updateScene()` 中根据 `currentStep` 设置各元素的 `stroke`, `stroke-width`, `opacity`, `fill-opacity` 等属性。
  - CSS 过渡：为所有 SVG 元素添加 `transition: all 0.5s ease;`，实现平滑的动画效果。
  - 平行箭头可以使用 `<path d="M -6 -6 L 6 0 L -6 6" fill="none" stroke="#c62828" stroke-width="2"/>` 绘制，通过 `transform="translate(x, y) rotate(angle)"` 定位到线段中点并对齐线段方向。PA和MN的方向角约为122度。
  - ID 命名规范：所有 ID 以 `scene1-` 开头。
  - IIFE 隔离：整个脚本包裹在 `(function() { ... })()` 中。
