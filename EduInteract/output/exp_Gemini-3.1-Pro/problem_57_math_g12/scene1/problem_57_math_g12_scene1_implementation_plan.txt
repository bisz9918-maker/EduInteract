[图示主题与整合说明]
- 本图示主题：3D空间中的圆锥面与平面交线（轨迹生成）
- 整合的步骤/概念：将抽象的空间几何问题转化为直观的动态3D模型。通过改变圆锥轴线与平面的夹角（α）以及圆锥的半顶角（β），动态展示圆锥面与平面相交生成的五种不同轨迹（空集、直线、抛物线、双曲线、椭圆），逐一验证题目中的5个命题。
- 教学价值：教师可通过分步按钮，平滑过渡不同的角度条件，让学生直观看到“圆锥曲线”在3D空间中的真实截口生成过程，深刻理解角度条件与轨迹类型的对应关系。

[视觉元素清单]
- 3D场景：使用 Three.js，相机位置 (20, 15, 25)，看向 (0, 0, 0)。
- 平面 M：`GridHelper` (60, 60, #000000) 透明度 0.1，叠加 `PlaneGeometry` 透明度 0.05。
- 点 O, P, A：`SphereGeometry`，黑色 #000000。
- 线段 PO：`LineDashedMaterial`，#888888。
- 线段 PA：`LineBasicMaterial`，#000000。
- 圆锥面：两个 `CylinderGeometry` (上下两支)，`MeshBasicMaterial`，蓝高亮 #1565c0，透明度 0.2，双面渲染。
- 轨迹交线：`LineBasicMaterial`，蓝高亮 #1565c0，线宽 3。
- 角度 α 弧及标签：`LineBasicMaterial`，红高亮 #c62828。
- 角度 β 弧及标签：`LineBasicMaterial`，绿高亮 #2e7d32。
- 标签：使用 HTML 绝对定位，通过 `vector.project(camera)` 实时将 3D 坐标映射为 2D 屏幕坐标并加上偏移量。

[分步序列]
- 初始状态（步骤1）：题意演示 (α=30°, β=20°)。展示动直线PB绕PA旋转生成圆锥面，交线为椭圆。
- 步骤2：验证② (α=30°, β=90°)。圆锥面展开为平面，轨迹是一条直线。
- 步骤3：验证③ (α=30°, β=60°)。α+β=90°，圆锥母线平行于平面M，轨迹是抛物线。
- 步骤4：验证④ (α=30°, β=75°)。α+β=105°>90°，圆锥面两支均与平面相交，轨迹是双曲线。
- 步骤5：验证⑤ (α=30°, β=45°)。α+β=75°<90°，圆锥面仅一支与平面相交，轨迹是椭圆。
- 步骤6：验证① (α=0°, β=90°)。PA与PO重合，圆锥面平行于平面M，无交线。

[标签冲突检查]
- P(0,-20) 与 α(-15,10)：P在上方，α在下方，无冲突。
- O(10,15) 与 A(10,15)：O在中心，A在右侧(x>0)，两者在屏幕上水平错开，无冲突。
- α(-15,10) 与 β(15,15)：α在PA左侧，β在PA右侧，方向相反，无冲突。
- M(0,0) 位于网格边缘，远离中心图形，无冲突。
- 所有标签均通过 3D 到 2D 投影计算，随视角变化自动保持相对偏移，确保不重叠。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 底部居中放置两个按钮和状态文本（如“步骤 1/6：题意演示...”）。
  - 教师点击按钮时，触发 `targetAlpha` 和 `targetBeta` 的改变。
- 教师操作流程：教师点击“下一步”，3D场景中的 α 和 β 角度平滑过渡（动画），圆锥面形态和底面交线随之动态变形，直观展示不同角度条件下的轨迹变化。支持鼠标拖拽旋转视角（OrbitControls）。

[技术实现]
- JS 库选择：Three.js (3D渲染核心)
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500 (Three.js Canvas)]
  [控件栏 (y=440~490) ◀上一步  步骤文本  下一步▶]
  ```
- 关键实现要点：
  1. **状态机与动画**：在 `requestAnimationFrame` 中使用线性插值 `currentAlpha += (targetAlpha - currentAlpha) * 0.1` 实现角度的平滑过渡。
  2. **圆锥面动态更新**：为避免每帧重建几何体，初始化一个底面半径为1、高度为60的 `CylinderGeometry` (顶点在原点)。每帧根据 `currentBeta` 更新 `scale.set(R, 1, R)` (其中 `R = 60 * Math.tan(currentBeta)`)，并根据 `currentAlpha` 更新 `quaternion` 使其轴线对齐 PA。当 β=90° 时，隐藏圆锥，显示一个大圆盘表示平面。
  3. **解析法生成轨迹**：在 y=0 平面上，交线满足方程 `A x^2 + B x + C = z^2 cos^2 β`。
     - `A = sin^2 α - cos^2 β`, `B = 2H sin α cos α`, `C = H^2 (cos^2 α - cos^2 β)`
     - 根据 A 的正负及判别式，动态计算 x 的有效范围，生成点集 `(x, 0, ±z)`。
     - 使用 `THREE.Line` 绘制轨迹。椭圆闭合绘制，抛物线/双曲线分段绘制。β=90° 时特判绘制直线 `x = -H cot α`。
  4. **HTML标签映射**：在渲染循环中，使用 `vector.project(camera)` 将 3D 坐标转换为屏幕像素坐标，更新对应 HTML 元素的 `left` 和 `top` 样式。
- ID 命名规范：所有 DOM 元素 ID 必须以 `scene1-` 为前缀（如 `scene1-btn-next`, `scene1-label-p`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
