[图示主题与整合说明]
- 本图示主题：2D主截面下的角度剖析与轨迹判定
- 整合的步骤/概念：将 3D 圆锥截面问题降维至 2D 平面（POA截面），通过母线与平面 M 的夹角关系，严格证明 α+β 与 90° 的关系如何决定圆锥曲线的类型。
- 教学价值：教师可通过分步演示不同 β 角度下母线与平面的交点情况，直观解释抛物线、双曲线、椭圆及直线的形成条件，将抽象的代数关系（α+β与90°的大小）转化为可见的几何相交关系。

[分步序列]
- 初始状态（步骤1）：建立主截面。显示 P, O, A, M, PO, PA, 直角标记, α角。隐藏 L1, L2, B1, B2, β角。
- 步骤2：绘制母线（β = 15°）。显示 L1, L2, B1(543,350), B2(736,350), β1, β2。展示母线与平面相交的基本形态。
- 步骤3：验证③抛物线（β = 50°，α+β=90°）。L1 交M于 B1(415,350)。L2 水平向右，不交M。隐藏 B2。
- 步骤4：验证④双曲线（β = 85°，α+β>90°）。L1 交M于 B1(250,350)。L2 向上倾斜。显示反向L2，交M于 B2(164,350)。
- 步骤5：验证⑤椭圆（β = 15°，α+β<90°）。状态同步骤2，L1, L2 均向下倾斜并交于 M。
- 步骤6：验证①与②（β = 90°）。L1 交M于 B1(212,350)。L2 向上倾斜。反向L2 与 L1 重合，交M于 B1。β角变为直角标记。

[交互方案]
- 交互类型：分步按钮导航。
- 控件说明：在 SVG 内部底部 (y=450~490) 放置绝对定位的 HTML 控件栏。包含 `<button id="scene2-btn-prev">◀ 上一步</button>`、`<span id="scene2-step-indicator">步骤 1 / 6</span>`、`<button id="scene2-btn-next">下一步 ▶</button>`。
- 教师操作流程：教师点击“下一步”逐步推进，图示平滑过渡到对应的 β 角度，直观展示母线交点的变化，配合讲解圆锥曲线判定定理。

[技术实现]
- JS 库选择：原生 SVG。场景由直线、圆弧和点构成，SVG 的 `transition` 配合 JS 状态机能完美实现平滑的几何变换动画。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×450]
    P(450,150)
      |\
      | \ PA
   PO |  \
      |   \
  ----O----A---- M (y=350)
  [控件栏 800×50 (y=450~500)]
    [◀ 上一步]  步骤 X / 6  [下一步 ▶]
  ```
- 关键实现要点：
  - 角度定义：以水平向右为0°，顺时针为正。PO角度=90°，PA角度=50° (α=40°)。
  - 动态坐标计算公式（β为当前步骤角度）：
    - L1 角度 = 50° + β
    - L2 角度 = 50° - β
    - L1 终点：x = 450 + 230 / tan(L1角度), y = 380
    - L2 终点：
      - 若 β < 50°：x = 450 + 230 / tan(L2角度), y = 380
      - 若 β = 50°：x = 780, y = 150
      - 若 β > 50°：x = 450 - 100 / tan(L2角度), y = 50
    - 反向L2 终点：x = 450 + 230 / tan(L2角度 + 180°), y = 380
    - 交点 B1_x = 450 + 200 / tan(L1角度)
    - 交点 B2_x = 450 + 200 / tan(L2角度) (β<50°) 或 450 + 200 / tan(L2角度+180°) (β>50°)
  - 动画过渡：使用 CSS `transition: all 0.5s ease-in-out;` 应用于 SVG 元素的 `d`, `cx`, `cy`, `x`, `y`, `opacity` 属性。
  - ID 命名规范：所有元素 ID 必须以 `scene2-` 为前缀，如 `scene2-line-l1`。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
