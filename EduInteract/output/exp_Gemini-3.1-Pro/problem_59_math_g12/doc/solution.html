场景导航：Scene 1

(2010•肥城市模拟)如图，为了测量河的宽度，在河的一岸边选取两点A，B，观察对岸的点C，测得∠CAB=75°，∠CBA=45°，且AB=96米，则河的宽度为 $\underline{\hspace{2em}}\underline{\hspace{2em}}\underline{\hspace{2em}}$．
$(\sqrt{2}=1.4，\sqrt{3}=1.7，精确到米)．$

题目分析与整体讲解思路：
本题是解三角形在实际测量中的经典应用。目标是求河的宽度，即点 $C$ 到直线 $AB$ 的垂直距离。
讲解时可以分为以下几个层次：

  1. 几何建模：将实际问题转化为几何图形，明确已知量（两角一边）和未知量（高）。
  2. 求第三角：利用三角形内角和求出 $\angle C = 60^\circ$。
  3. 正弦定理求边：在 $ riangle ABC$ 中，利用正弦定理求出边 $AC$。
  4. 解直角三角形求高：在直角 $ riangle ACD$ 中，利用三角函数求出高 $h$，并代入近似值进行计算。

图示规划将通过分步导航，逐步引导学生完成从条件标注到公式推导的整个思维过程。

教学说明与推导过程：
在图示的辅助下，教师可按以下步骤带领学生完成计算：

  1. 求 $\angle C$：

在 $ riangle ABC$ 中，已知 $\angle A = 75^\circ$ 和 $\angle B = 45^\circ$。
$\angle C = 180^\circ - (75^\circ + 45^\circ) = 60^\circ$

  1. 利用正弦定理求 $AC$：

根据正弦定理 $
rac{AC}{\sin B} =
rac{AB}{\sin C}$，代入数据：
$
rac{AC}{\sin 45^\circ} =
rac{96}{\sin 60^\circ}$
$AC =
rac{96 imes
rac{\sqrt{2}}{2}}{
rac{\sqrt{3}}{2}} =
rac{96\sqrt{2}}{\sqrt{3}} = 32\sqrt{6}$

  1. 求河宽 $h$：

在直角 $ riangle ACD$ 中，$h = AC \cdot \sin A = 32\sqrt{6} \cdot \sin 75^\circ$。
其中 $\sin 75^\circ = \sin(45^\circ + 30^\circ) = \sin 45^\circ \cos 30^\circ + \cos 45^\circ \sin 30^\circ =
rac{\sqrt{2}}{2} \cdot
rac{\sqrt{3}}{2} +
rac{\sqrt{2}}{2} \cdot
rac{1}{2} =
rac{\sqrt{6} + \sqrt{2}}{4}$。
代入得：
$h = 32\sqrt{6} \cdot
rac{\sqrt{6} + \sqrt{2}}{4} = 8\sqrt{6}(\sqrt{6} + \sqrt{2}) = 48 + 16\sqrt{3}$

  1. 近似计算：

题目给出 $\sqrt{3} = 1.7$。
$h = 48 + 16 imes 1.7 = 48 + 27.2 = 75.2$
精确到米，最终结果为 $75$ 米。

总结与课堂讲解建议：
本题最终答案为 $75$ 米。

  • 重点难点：本题的难点在于计算 $\sin 75^\circ$ 以及无理数的化简。教师应提醒学生注意两角和的正弦公式 $\sin 75^\circ = \sin(45^\circ + 30^\circ)$ 的熟练应用。
  • 拓展思考：也可以引导学生思考另一种代数解法：设 $CD = h$，在 $ riangle ACD$ 和 $ riangle BCD$ 中分别用 $h$ 和余切函数表示 $AD$ 和 $BD$，利用 $AD + BD = 96$ 即 $h \cdot \cot 75^\circ + h \cdot \cot 45^\circ = 96$ 列方程求解。这种方法可以作为拓展，锻炼学生的一题多解能力。
