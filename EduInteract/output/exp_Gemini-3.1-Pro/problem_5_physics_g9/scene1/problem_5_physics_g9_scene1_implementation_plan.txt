[分步序列]
- 初始状态（步骤0）：实物图居中显示，所有导线为黑色默认状态，无高亮，无流动箭头。电路图及辅助虚线隐藏（opacity: 0）。
- 步骤1：点击「下一步」→ 实物导线 W1, W2 变红加粗，显示红色动态流动箭头。实物分流点红点出现，标签“分流点”淡入。
- 步骤2：点击「下一步」→ 实物导线 W3 变绿加粗，显示绿色动态流动箭头。
- 步骤3：点击「下一步」→ 实物导线 W4, W5 变蓝加粗，显示蓝色动态流动箭头。实物汇流点蓝点出现，标签“汇流点”淡入。
- 步骤4：点击「下一步」→ 实物导线 W6 变红加粗，显示红色动态流动箭头。
- 步骤5：点击「下一步」→ 实物图组平滑左移（`transform: translate(-150px, 0)`）；右侧标准电路图组淡入，其导线按对应颜色（红、绿、蓝）高亮并显示流动箭头；底部辅助虚线淡入，连接实物图与电路图的对应节点。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：在 SVG 内部底部（y=460 区域）居中放置两个按钮，控制 `currentStep` (0-5) 的增减。
- 教师操作流程：教师点击“下一步”，逐步引导学生观察电流从正极出发、在分流点分开、在汇流点汇合、回到负极的完整路径；最后一步展示标准电路图，通过颜色和辅助线帮助学生建立实物与抽象符号的对应关系。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript。SVG 极其适合绘制精确的电路连线和节点。
- 画布尺寸：800 × 500 px。
- 布局草图：
  [图示区 800×450]
  [控件栏 y=460~490，居中按钮]
- 关键实现要点：
  1. 使用 `<g id="scene1-physical-group">` 包裹实物图所有元素，便于在步骤5统一执行 `transform="translate(-150, 0)"` 动画。
  2. 动态流动箭头可通过 `<animateMotion>` 实现，定义一个箭头 `<polygon>`，让其沿着对应的 `<path>` 运动。
  3. 状态机：定义 `renderStep(step)` 函数，根据 step 值控制各导线的 `stroke`、`stroke-width`，箭头元素的 `display`，以及组的 `transform` 和 `opacity`。
  4. 辅助虚线路径经过精心计算（y=390 和 y=420），完美避开所有实物组件和电路符号，确保画面整洁。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-btn-next`, `scene1-wire-w1`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
