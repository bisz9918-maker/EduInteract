[分步序列]
- 初始状态（步骤0）：显示透明球体、赤道、球心 $O$、点 $A, B, C$ 以及虚线 $	riangle ABC$。
- 步骤1（截面与距离）：显示截面小圆（蓝色半透明）、圆心 $O'$。连接 $OO'$ 并显示标签 $d=rac{3\sqrt{2}}{2}$。连接 $OA$ 并显示标签 $R=3$。
- 步骤2（小圆半径）：高亮直角 $	riangle OO'A$（蓝色填充）。连接 $O'A$ 并显示标签 $r=rac{3\sqrt{2}}{2}$。
- 步骤3（求弦长）：连接 $AC$（穿过 $O'$）。显示标签 $AC=3\sqrt{2}$。基于已知 $BA=BC$ 且 $\angle ABC=90^\circ$，显示标签 $BC=3$。
- 步骤4（大圆球心角）：连接 $OB, OC$。高亮 $	riangle OBC$（红色填充）。显示角度弧线及标签 $60^\circ$。
- 步骤5（球面距离）：绘制经过 $B, C$ 的红色粗弧线（模拟大圆劣弧）。显示标签 $\pi$。

[交互方案]
- 交互类型：分步按钮导航。
- 控件说明：底部居中放置两个按钮「◀ 上一步」和「下一步 ▶」。
- 教师操作流程：教师点击「下一步」逐步推进逻辑链，每点击一次，图示增加相应的辅助线、高亮面和计算结果标签，配合口头讲解。

[技术实现]
- JS 库选择：原生 SVG（用于绘制几何图形，易于控制层级和样式） + MathJax（用于渲染 HTML 标签中的数学公式）。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  +------------------------------------------------+
  |                                                |
  |                  [球体区域]                    |
  |                                                |
  |                                                |
  |                                                |
  |                                                |
  |                                                |
  |                                                |
  |                                                |
  |           [ ◀ 上一步 ]   [ 下一步 ▶ ]          |
  +------------------------------------------------+
  ```
- 关键实现要点：
  1. **状态机设计**：定义 `currentStep` (0-5)，每次点击按钮更新状态，并调用 `renderStep()` 函数。
  2. **SVG 元素控制**：预先在 SVG 中定义好所有图形元素（线、面、弧），通过 CSS class (如 `.step-hidden`, `.step-visible`) 控制显示/隐藏。
  3. **HTML 标签层**：在 SVG 上方叠加一个 `div` 容器用于放置绝对定位的 HTML 标签，标签内容使用 `\( ... \)` 包裹供 MathJax 渲染。同样通过 class 控制显隐。
  4. **3D 弧线模拟**：球面距离弧线使用 SVG `<path>` 的二次贝塞尔曲线 `Q` 模拟，控制点设在弦 BC 的中垂线下方，以产生贴合球面的立体感。
  5. **ID 命名规范**：所有元素 ID 均以 `scene1-` 开头（如 `scene1-btn-next`, `scene1-path-arc`），确保独立性。
  6. **IIFE 隔离**：整个脚本包裹在 `(function(){ ... })();` 中。
