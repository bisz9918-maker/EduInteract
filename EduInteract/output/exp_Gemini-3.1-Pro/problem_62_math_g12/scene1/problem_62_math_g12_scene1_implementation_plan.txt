[分步序列]
本场景为连续状态切换，主要包含以下关键状态：
- 初始状态（λ = 0.2）：显示四面体、截面 EGFH。GF 和 EH 的延长线交于 BD 上的点 P。
- 拖拽状态（λ ≠ 0.5）：随着滑块拖动，G 在 BC 上移动，H 在 AD 上移动，截面形状连续变化，交点 P 在直线 BD 上动态滑动。
- 临界状态（λ = 0.5）：G、H 移动到中点位置。交点 P 消失（延长线不绘制）。高亮显示文本提示“GF ∥ BD, EH ∥ BD”（可在画布顶部居中显示，颜色 #c62828，字号 20px，加粗）。

[标签冲突检查]
- 标签 A (400, 60) 与 H (480, 108)：间距 > 80px，无冲突。
- 标签 B (180, 360) 与 G (235, 390)：间距 > 60px，无冲突。
- 标签 E (280, 200) 与其他点：周围空白充足，无冲突。
- 标签 P (30, 340) 与 B (180, 360)：间距 > 150px，无冲突。
- 结论：初始状态下各标签分布在图形外侧，偏移方向已做分散处理，无重叠冲突。3D 旋转时由于是动态交互，允许合理的视觉透视重叠。

[交互方案]
- 交互类型：连续拖拽滑块 + 鼠标拖拽旋转视角
- 控件说明：
  - 底部滑块 `<input type="range">`：ID `scene1-slider`，范围 [-0.5, 1.5]，步长 0.01，默认值 0.2。控制截面位置参数 λ。
  - 画布拖拽：在 Canvas 上按下并移动鼠标，可绕 X 轴和 Y 轴旋转整个 3D 图形。
- 教师操作流程：
  1. 教师首先展示初始状态，指出截面与 BD 的交点 P。
  2. 教师拖动滑块，让学生观察 P 点的移动规律。
  3. 教师将滑块拖至 0.5（代码需实现吸附效果，当 |λ - 0.5| < 0.05 时自动吸附到 0.5），展示交点 P 消失，引导学生得出线面平行的结论。
  4. 教师可随时在画布上拖拽鼠标旋转四面体，从不同视角观察共面与相交关系。

[技术实现]
- JS 库选择及原因：原生 Canvas 2D。由于需要精确控制虚线样式、动态计算交点 P 并绘制延长线，且 3D 结构仅为简单的线框四面体，使用原生 Canvas 结合简单的 3D 投影矩阵实现最为轻量且可控。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500 (Canvas)]
  [控件栏 800×50 (绝对定位在底部 y=450~500)]
    [ 滑块：截面位置参数 λ (250~550) ]
  ```
- 关键实现要点：
  1. **3D 投影与旋转**：维护 A, B, C, D 的 3D 坐标。监听鼠标事件更新 `angleX` 和 `angleY`。渲染时，先对 3D 坐标应用旋转矩阵，再进行正交投影 `X = x + 400`, `Y = y + 250`。
  2. **向量计算**：
     - E = (A+B)/2, F = (C+D)/2
     - G = B + λ(C-B), H = A + λ(D-A)
     - P = ((λ-1)/(2λ-1)) * B + (λ/(2λ-1)) * D
  3. **吸附逻辑**：在 slider 的 `input` 事件中，判断 `Math.abs(val - 0.5) < 0.05`，若成立则强制设为 0.5。
  4. **绘制顺序**：先绘制四面体背面的线，再绘制截面（带透明度填充），最后绘制前面的线和点、标签，确保视觉层次正确（由于是线框+半透明截面，直接按固定顺序绘制即可：四面体边 -> 截面填充 -> 截面边 -> 延长线 -> 点 -> 标签）。
- ID 命名规范：`scene1-canvas`, `scene1-slider`, `scene1-controls` 等。
- IIFE 隔离：所有逻辑封装在 `(function() { ... })()` 中。
