problem_65_math_g12

场景导航：Scene 1

如图，已知Rt△ABC的两条直角边AC，BC的长分别为6cm，8cm，以AC为直径的圆与AB交于点D则BD=$\underline{\hspace{5em}}$cm．

题目分析：
本题考查了圆的基本性质（直径所对的圆周角是直角）、勾股定理以及相似三角形的性质（或射影定理）。
解题的关键在于识别出隐藏的几何关系：

  1. 利用勾股定理求出直角三角形斜边 AB 的长度。
  2. 观察到 D 在以 AC 为直径的圆上，连接 CD 即可构造出直角 $\angle ADC$。
  3. 利用 $ riangle BCD$ 与 $ riangle BAC$ 相似，或者直接使用直角三角形的射影定理，建立关于 BD 的方程。

整体讲解思路：
通过分步动画引导学生逐步剖析图形：首先从宏观的直角三角形出发求出斜边；接着关注圆的局部特征，通过作辅助线 CD 揭示隐含的直角；最后利用相似三角形的比例关系求出目标线段 BD 的长度。

教学说明与引导要点：

在课堂讲解时，教师可以按以下步骤引导学生：

  1. 第一步：基础计算 引导学生观察最大的直角 $ riangle ABC$，已知两直角边，首先利用勾股定理求出斜边：$AB = \sqrt{AC^2 + BC^2} = \sqrt{6^2 + 8^2} = 10$。
  2. 第二步：挖掘隐含条件 提问学生：“题目中‘以 AC 为直径’这个条件有什么用？”引导学生作辅助线 CD，并回忆圆的性质：直径所对的圆周角是直角。由此得出 $CD \perp AB$，即 $\angle BDC = 90^\circ$。
  3. 第三步：建立关系求解 引导学生观察 $ riangle BCD$ 和 $ riangle BAC$，由于 $\angle BDC = \angle BCA = 90^\circ$ 且 $\angle B$ 为公共角，因此 $ riangle BCD \sim riangle BAC$。根据相似三角形对应边成比例得到 $

rac{BD}{BC} =
rac{BC}{AB}$，即 $BC^2 = BD \cdot AB$ （这也是直角三角形的射影定理）。代入数据：$8^2 = BD \cdot 10$，解得 $BD = 6.4$ cm。

拓展思考（备选解法）：

教师也可启发学生使用切割线定理：因为 $\angle ACB = 90^\circ$，所以 BC 垂直于圆的半径 OC，即 BC 是圆 O 的切线。而 BDA 是圆的割线，根据切割线定理直接得到 $BC^2 = BD \cdot BA$，同样可以快速解得 $BD = 6.4$。这种解法无需作辅助线，更为巧妙，可作为一题多解的拓展。
