[图示主题与整合说明]
- 本图示主题：辅助线构造与相似三角形/射影定理推导
- 整合的步骤/概念：展示初始条件、计算斜边、添加辅助线构造直角、利用相似三角形比例关系求解

[分步序列]
- 初始状态（步骤0）：显示基础图形（△ABC, 圆O, 点A/B/C/O/D及标签），显示已知条件（AC=6, BC=8, 直角C）。隐藏其他所有元素。
- 步骤1（求斜边）：点击「下一步」。显示AB标注线和"AB=10"。将△ABC的三边（AB, BC, CA）高亮为蓝色（#1565c0，线宽3）。
- 步骤2（辅助线与直角）：点击「下一步」。取消步骤1的高亮。显示辅助线CD（虚线动画出现）。显示直角D标记。将直径AC、线段AD和CD高亮为蓝色（#1565c0，线宽3），突出直径所对圆周角。
- 步骤3（相似求解）：点击「下一步」。取消步骤2的高亮。将△BCD填充蓝色（#1565c0，透明度0.2）。将整体△BAC的轮廓加粗（#000000，线宽3）。显示角B弧线（绿色）。显示"BD=?"和相似结论文本"△BCD ∼ △BAC"。

[交互方案]
- 交互类型：分步按钮导航
- 控件说明：在SVG底部（y=460区域）居中放置两个按钮：「◀ 上一步」和「下一步 ▶」。
- 教师操作流程：教师首先展示初始题目条件，讲解勾股定理后点击「下一步」展示斜边长度；接着引导学生思考圆周角性质，点击「下一步」作辅助线并标出直角；最后引导学生观察相似三角形，点击「下一步」展示相似关系并引出最终求解目标。

- 关键实现要点：
  - 使用 `scene1-` 作为所有元素 ID 的前缀，防止跨场景冲突。
  - 状态机设计：定义 `currentStep` (0~3)，编写 `updateState()` 函数，根据当前步骤控制各 SVG 元素的 `display`、`stroke`、`stroke-width`、`fill` 等属性。
  - 动画实现：辅助线 CD 的出现可以使用 CSS `stroke-dasharray` 和 `stroke-dashoffset` 实现简单的线条生长动画。
  - 模块隔离：所有逻辑封装在 IIFE `(function(){ ... })()` 中。
