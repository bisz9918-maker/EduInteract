[图示主题与整合说明]
- 本图示主题：椭圆切线性质与角度、线段关系的动态探究
- 整合的步骤/概念：将题目中的四个结论（角度平分、切线判定、线段相等）整合在一个动态几何场景中。通过拖拽点P，实时计算并展示角度和线段长度，验证结论的正确性。
- 教学价值：教师可通过分步导航，逐一引导学生观察和验证四个结论。动态拖拽功能打破了静态图形的局限，帮助学生建立“动中有静”的几何直观，完美契合“先猜想后证明”的教学逻辑。

[分步序列]
- 初始状态（步骤0）：显示坐标系、椭圆、直线l、点A/B/F/P/D/M、射线AP、线段BD。数据面板提示“拖拽点P，观察各点联动”。
- 步骤1：点击「下一步」→ 连接并高亮线段PM（蓝色）。数据面板显示结论②，提示观察PM始终为切线。
- 步骤2：点击「下一步」→ 连接线段FM（红色），显示∠PFM和∠BFM的红色角弧。数据面板实时显示两角度数，验证结论①（始终相等）。
- 步骤3：点击「下一步」→ 连接线段PF（红色），显示∠FPM和∠DPM的绿色角弧。数据面板实时显示两角度数，验证结论③（不相等）。
- 步骤4：点击「下一步」→ 加粗高亮线段PM和BM（蓝色）。数据面板实时显示PM和BM的长度，验证结论④（不相等）。

- 标签"O" (335,265) 与 标签"A" (135,265)：间距 200px → 无冲突。
- 标签"F" (495,265) 与 标签"B" (565,265)：间距 70px → 无冲突。
- 标签"B" (565,265) 与 标签"M" (565,181)：间距 84px（初始状态） → 无冲突。拖拽限制 t≥30° 确保最小间距 >30px。
- 标签"M" (565,181) 与 标签"D" (565,111)：间距 70px（初始状态） → 无冲突。拖拽限制 t≥30° 确保最小间距 >30px。
- 标签"P" (435,130) 与 标签"F" (495,265)：间距 >100px → 无冲突。
- 标签"l" (565,440) 与 标签"B" (565,265)：间距 175px → 无冲突。
- 数据面板 (580,20) 与 标签"D" (565,y_D)：面板在 x=580 以右，D 标签在 x=565，左右错开 → 无冲突。
解决方案：通过严格限制点P的拖拽范围（参数角 t ∈ [30°, 80°]），从根本上避免了右侧 D、M、B 三点过于靠近导致的标签重叠。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶） + 拖拽交互
- 控件说明：
  - 底部居中放置「上一步」和「下一步」按钮，以及当前步骤指示器（如 1 / 5）。
  - 点P支持鼠标拖拽，拖拽时实时更新所有依赖点的坐标、线段、角弧及数据面板中的数值。
- 教师操作流程：教师首先在步骤0讲解题目基础条件，拖拽P点让学生理解联动关系；然后逐次点击「下一步」，在每个步骤中结合动态显示的辅助线和实时计算的数据，拖拽P点，直观验证四个结论的真伪。

[技术实现]
- JS 库选择及原因：D3.js (v7)。D3 提供了强大的数据绑定、拖拽行为（d3.drag）和 DOM 操作能力，非常适合处理本场景中复杂的依赖计算和高频的 DOM 属性更新。
- 画布尺寸：800 × 500 px，SVG 元素占满容器。
- 布局草图：
  ```
  [图示区 800×500]
  +-------------------------------------------------+
  |                                 [ 数据面板 ]    |
  |                                 [ 180x200  ]    |
  |        P*                       [          ]    |
  |       /  \                      [          ]    |
  | A----O----F----B                l               |
  |                                                 |
  |                                                 |
  |             [ ◀上一步 | 1 / 5 | 下一步▶ ]       |
  +-------------------------------------------------+
  ```
- 关键实现要点：
  - 坐标计算：基于椭圆参数方程，设P点参数角为 `t`。拖拽时，通过 `Math.atan2` 将鼠标坐标转换为角度 `t`，并限制 `t` 在 `[30°, 80°]` 范围内（转换为弧度计算）。
  - 依赖更新：在 `update()` 函数中，统一计算 x_P, y_P, y_D, y_M，并更新所有相关 SVG 元素的 x, y, cx, cy, d 属性。
  - 角弧绘制：封装 `getArcPath(center, p1, p2, radius)` 函数，利用 `Math.atan2` 计算两向量角度，处理跨越 0 度的差值，生成正确的 SVG `path` 字符串（使用 `A` 指令，确保 `sweep-flag` 正确，始终绘制劣角）。
  - 状态机：维护 `currentStep` (0~4)，在 `update()` 中根据步骤控制各辅助线和角弧的 `opacity`，并动态生成数据面板的 HTML 内容。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-svg`, `scene1-p`, `scene1-panel`）；JS 中用 `d3.select('#scene1-...')` 获取元素。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
