[图示主题与整合说明]
- 本图示主题：直三棱柱外接球的球心定位与半径计算
- 整合的步骤/概念：直三棱柱的几何特征、底面直角三角形的外心、外接球球心的空间位置、半径的勾股定理推导及外接球展示。
- 教学价值：通过分步动画，帮助学生将复杂的 3D 空间问题降维分解。先找底面外心，再沿法线平移找球心，最后在空间直角三角形中计算半径，逻辑清晰，有效突破空间想象的难点。

[技术实现]
- JS 库选择及原因：原生 SVG（用于绘制几何图形，易于控制样式和动画，且在 2D 投影下表现优异） + MathJax（用于右侧面板的数学公式渲染）。
- 画布尺寸：800 × 500 px。
- 布局草图：
  [图示区 800×500]
  +---------------------------------------------------------+
  |  [3D图形区 450x400]             [公式面板 260x370]      |
  |       C1-------A1               已知条件:               |
  |       / \     / |               AA1 = 8                 |
  |      /   B1  /  |               ...                     |
  |     /    |  /   |                                       |
  |    C-----|-A    |                                       |
  |     \    |/     |                                       |
  |      \   B      |                                       |
  |                                                         |
  |            [ ◀ 上一步 ] [ 下一步 ▶ ]                    |
  +---------------------------------------------------------+
- 关键实现要点：
  - 使用 SVG `<g>` 标签对不同步骤的元素进行分组，通过控制 `opacity` 或 `display` 实现步骤切换。
  - 右侧面板使用 HTML `<div>`，通过 CSS `position: absolute` 放置在右侧，内部使用多个子 `<div>` 对应不同步骤的公式，按步骤显示。
  - 使用 CSS `transition: opacity 0.5s ease-in-out` 实现平滑的淡入淡出动画。
  - ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-btn-next`, `scene1-step2-group`）。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
