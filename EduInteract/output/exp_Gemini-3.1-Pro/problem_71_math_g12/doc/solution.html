场景导航：Scene 1

题目：已知正六边形A$_{1}$A$_{2}$⋅⋅⋅A$_{6}$内接于圆O，点P为圆O上一点，向量$\overrightarrow{OP}$与$\overrightarrow{OA_{i}}$的夹角为θ$_{i}$（i=1，2，⋅⋅⋅，6），若将θ$_{1}$，θ$_{2}$，⋅⋅⋅，θ$_{6}$从小到大重新排列后恰好组成等差数列，则该等差数列的第3项为$\underline{\hspace{5em}}$.

题目分析与整体讲解思路

  1. 理解对称性：正六边形将圆分为六等份，每份圆心角为 $60^\circ$（即 $\pi/3$）。由于圆的对称性，点 $P$ 在圆上的任何位置，其与六个顶点的夹角集合，在本质上是周期性重复的。因此，我们只需研究点 $P$ 在一段圆弧（例如 $A_1$ 到 $A_2$ 之间）上的情况即可。
  2. 夹角表达式：设 $\overrightarrow{OA_1}$ 为极轴，点 $P$ 的极角为 $\alpha \in [0, \pi/3]$。此时，向量 $\overrightarrow{OP}$ 与六个向量 $\overrightarrow{OA_i}$ 的夹角分别为：$\alpha$, $\pi/3 - \alpha$, $\pi/3 + \alpha$, $2\pi/3 - \alpha$, $2\pi/3 + \alpha$, $\pi - \alpha$。
  3. 排序与等差数列条件：将这六个角从小到大排序。由于 $\alpha \in [0, \pi/3]$，我们可以假设 $\alpha \le \pi/6$（另一半对称）。排序后的六个角为：$\alpha, \pi/3-\alpha, \pi/3+\alpha, 2\pi/3-\alpha, 2\pi/3+\alpha, \pi-\alpha$。
  4. 求解：若它们成等差数列，则相邻两项差相等。由第2、3项的差等于第1、2项的差，可得 $(\pi/3+\alpha) - (\pi/3-\alpha) = (\pi/3-\alpha) - \alpha$，解得 $\alpha = \pi/12$。此时数列为 $\pi/12, 3\pi/12, 5\pi/12, 7\pi/12, 9\pi/12, 11\pi/12$，第3项为 $5\pi/12$。

课堂讲解建议

  1. 引入与观察：
  • 首先让学生观察正六边形的对称性。指出不论点 $P$ 在圆上何处，其与六个顶点的夹角集合在每 $60^\circ$ 的区间内是重复的。
  • 引导学生将研究范围缩小到一段圆弧，例如点 $P$ 在 $A_1$ 和 $A_2$ 之间，即夹角 $\alpha \in [0^\circ, 60^\circ]$。
  1. 代数表达：
  • 设 $\angle A_1OP = \alpha$。带领学生逐一写出 $\overrightarrow{OP}$ 与六个向量的夹角表达式：
  1. $ heta_1 = \alpha$
  2. $ heta_2 = 60^\circ - \alpha$
  3. $ heta_3 = 60^\circ + \alpha$
  4. $ heta_4 = 120^\circ - \alpha$
  5. $ heta_5 = 120^\circ + \alpha$
  6. $ heta_6 = 180^\circ - \alpha$
  1. 排序与推理：
  • 提问：如何将这六个角从小到大排序？
  • 假设 $\alpha \in [0^\circ, 30^\circ]$，比较大小可得排序为：$\alpha, 60^\circ-\alpha, 60^\circ+\alpha, 120^\circ-\alpha, 120^\circ+\alpha, 180^\circ-\alpha$。
  • 利用等差数列的性质：相邻两项之差相等。
  • 列方程：$(60^\circ+\alpha) - (60^\circ-\alpha) = (60^\circ-\alpha) - \alpha$
  • 解得：$2\alpha = 60^\circ - 2\alpha \implies 4\alpha = 60^\circ \implies \alpha = 15^\circ$。
  1. 验证与结论：
  • 将 $\alpha = 15^\circ$ 代入，得到六个角为：$15^\circ, 45^\circ, 75^\circ, 105^\circ, 135^\circ, 165^\circ$。
  • 验证公差为 $30^\circ$，确实是等差数列。
  • 找出第3项，即 $75^\circ$，转化为弧度制为 $5\pi/12$。
  • 结合图示的柱状图，直观展示当 $\alpha=15^\circ$ 时，柱子顶端连成一条直线，完美验证了代数推导。
