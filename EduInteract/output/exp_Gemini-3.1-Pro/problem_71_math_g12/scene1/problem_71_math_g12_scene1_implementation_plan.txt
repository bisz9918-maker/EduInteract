[图示主题与整合说明]
- 本图示主题：动点P的夹角变化与等差数列的形成
- 整合的步骤/概念：正六边形与向量的几何关系、动点P的夹角动态计算、夹角排序与等差数列条件的直观验证
- 教学价值：教师可通过拖拽滑块，连续改变点P的位置，直观展示六个夹角大小的动态变化及排序过程。当点P到达特定位置（15°或45°）时，柱状图呈现完美的阶梯状（等差数列），帮助学生将抽象的代数条件转化为直观的视觉规律，轻松找到第3项的值。

[分步序列]
- 初始状态：滑块值为0（α=0°），点P与A1重合。左侧显示几何图形，右侧柱状图显示此时的六个夹角（0°, 60°, 60°, 120°, 120°, 180°）并排序。
- 交互状态（拖拽中）：拖动滑块，α在0°~60°间变化。左侧OP向量随之转动，α弧线动态更新。右侧柱状图实时计算六个夹角（OP与OA_i的夹角，范围0°~180°），从小到大排序后更新柱子高度，柱顶实时显示角度数值。
- 等差数列状态（α=15°或45°）：当滑块拖动到15°（或45°）时，六个夹角恰好为15°, 45°, 75°, 105°, 135°, 165°。此时触发高亮：
  1. 柱状图颜色变为绿色（#2e7d32）。
  2. 第3项（75°）柱子变为红色（#c62828），其顶部数值加粗放大。
  3. 出现一条灰色虚线穿过所有柱子的顶端，直观显示等差数列的线性特征。

[标签冲突检查]
- 点O (185,235) 与 A4 (45,220)：间距>100px，无冲突。
- 点A1 (355,220) 与 A2 (285,83.7)：间距>100px，无冲突。
- 动点P标签：沿半径向外35px。当α=0°时，P标签在(375,220)，A1标签在(355,220)。为避免重叠，P标签设为红色，并在SVG中后渲染（层级更高），确保可读性。
- 柱状图顶部数值：柱子宽度30，间距20。数值文本居中于柱子上方（y - 10）。相邻数值横向间距50px，文本宽度约30px，不会重叠。
- 坐标轴标签：Y轴刻度在左侧，X轴序号在下方，互不干扰。

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：底部居中放置一个 `<input type="range">` 滑块，范围 `min="0" max="60" step="1"`，初始值 `0`。滑块左侧显示文本“点P位置 (α):”，右侧实时显示当前角度值（如“15°”）。
- 教师操作流程：教师在讲解时，缓慢拖动底部滑块，引导学生观察右侧柱状图的高低变化。当拖动到15°时，指出柱状图顶端平齐（形成直线），说明此时构成了等差数列，并引导学生读出第3项的值（75°）。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。SVG 适合绘制几何图形和柱状图，DOM 操作简单，性能足以应对简单的拖拽动画。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [左侧几何区 400×440] | [右侧图表区 400×440]
  -----------------------------------------
  [控件栏： 滑块 α: 0°~60° ] (y=440~500)
  ```
- 关键实现要点：
  1. 坐标计算：左侧极坐标转直角坐标，圆心(200,220)，半径140。注意SVG中y轴向下，角度逆时针增加时，y = 220 - 140 * sin(α)。
  2. 夹角计算：对于每个顶点A_i，其极角为 `angle_i = (i-1) * 60°`。OP极角为 `α`。夹角 `theta_i = |angle_i - α|`。由于夹角范围是0~180°，若 `theta_i > 180°`，则 `theta_i = 360° - theta_i`。
  3. 排序与渲染：每次滑块滑动（`input` 事件），计算6个夹角，存入数组并按从小到大排序。遍历数组更新右侧6个 `<rect>` 的 `height` 和 `y` 属性，以及顶部 `<text>` 的数值。
  4. 状态判断：判断 `α == 15` 或 `α == 45`。若是，则修改柱子 `fill` 颜色，显示虚线 `<line>`，高亮第3个柱子；否则恢复默认蓝色，隐藏虚线。
  5. ID 命名规范：所有元素ID以 `scene1-` 开头，如 `scene1-slider`, `scene1-bar-1`, `scene1-point-p` 等。
  6. IIFE 隔离：所有逻辑封装在 `(function() { ... })()` 中。
