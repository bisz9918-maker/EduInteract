[图示主题与整合说明]
- 本图示主题：从三视图还原四棱锥并分步计算表面积
- 整合的步骤/概念：三视图投影对应关系、几何体还原、各面高/斜高的推导、直角三角形的证明及面积计算
- 教学价值：教师可通过分步导航，引导学生从2D三视图逐步构建3D几何体，并通过旋转全方位观察。随后按底面、后面、前面、侧面的顺序，逐步剖析各个面的高和斜高，利用辅助直角三角形进行计算，最终汇总表面积，有效突破空间想象和计算难点。

[视觉元素清单]
- 3D坐标系：隐藏坐标轴，仅通过投影面暗示空间。
- 投影面（3个）：#888888，透明度 0.1，带黑色边框和内部2D视图线条。
- 投影连线：#888888 虚线，连接2D视图顶点与3D几何体顶点。
- 四棱锥 V-ABCD：主轮廓线 #000000，粗细 2px。
- 辅助线：VM, VN, MN, VD，#888888 或 #c62828 虚线。
- 直角标记：在 M 点（VM⊥MN, VM⊥MD）和 D 点（VD⊥AD）绘制3D直角折线，#c62828。
- 面高亮：
  - 底面 ABCD、后面 VCD：#2e7d32（绿色），透明度 0.2。
  - 前面 VAB、左面 VAD、右面 VBC：#1565c0（蓝色），透明度 0.2。
  - 辅助直角三角形 VMN, VMD：#c62828（红色），透明度 0.2。
- 文本标签：HTML div 绝对定位，跟随3D坐标投影更新。字体 14px，黑色，带白色半透明背景防遮挡。

[分步序列]
- 初始状态（步骤0）：展示3个投影面及上面的2D三视图。3D空间中心为空。信息面板提示：“观察三视图，想象几何体形状”。
- 步骤1（还原几何体）：点击「下一步」，出现从投影面到3D空间的灰色虚线，生成3D四棱锥 V-ABCD。显示顶点标签 V, A, B, C, D, M。信息面板提示：“还原为四棱锥 V-ABCD，M为CD中点”。
- 步骤2（底面与后侧面）：高亮底面 ABCD 和后面 VCD（绿色）。标注 AB=6, BC=2, VM=4。信息面板显示：“S_底 = 6 × 2 = 12<br>S_后 = 1/2 × 6 × 4 = 12”。
- 步骤3（前侧面斜高）：高亮前面 VAB（蓝色）。添加 N 点，连接 VN, MN。高亮直角 △VMN（红色），显示直角标记。标注 MN=2, VN=2√5。信息面板追加：“S_前 = 1/2 × 6 × 2√5 = 6√5”。
- 步骤4（左右侧面）：高亮左右侧面 VAD, VBC（蓝色）。连接 VD，高亮直角 △VMD（红色）。显示直角标记（M处和D处）。标注 MD=3, VD=5。信息面板追加：“S_左 = S_右 = 1/2 × 2 × 5 = 5”。
- 步骤5（表面积汇总）：所有面微微高亮。信息面板显示最终汇总：“总表面积 S = 12 + 12 + 6√5 + 5 + 5 = 34 + 6√5”。

[标签冲突检查]
- 标签"V" (0,-25) 与 "VM=4" (-20,0)：V在上方，VM在左侧，无冲突。
- 标签"M" (15,-15) 与 "MN=2" (20,10)：M在右上，MN在右下，无冲突。
- 标签"D" (-20,-20) 与 "MD=3" (0,20)：D在左上，MD在下方，无冲突。
- 标签"A" (-20,20) 与 "AB=6" (0,25)：A在左下，AB在正下，间距足够，无冲突。
- 标签"N" (0,-20) 与 "AB=6" (0,25)：N在上方，AB在下方，完美错开，无冲突。
- 标签"VN=2√5" (25,0) 与 "BC=2" (25,0)：VN在空间上方(y=2)，BC在下方(y=0)，3D投影后y坐标错开，无冲突。
- 结论：通过3D投影和2D偏移方向的精细规划，结合相机的初始俯仰角，标签分布均匀，无严重遮挡。用户亦可旋转视角解决任何偶然重叠。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶） + 3D鼠标拖拽旋转。
- 控件说明：
  - 底部居中：上一步、下一步按钮。
  - 3D画布：支持鼠标左键拖拽旋转，滚轮缩放。
  - 右上角：信息面板（动态更新计算过程）。
- 教师操作流程：教师首先展示三视图，让学生思考；点击下一步还原几何体并旋转展示；接着按步骤依次点击，逐步推导各个面的面积，配合高亮和辅助线讲解直角三角形的勾股定理应用；最后展示总面积。

[技术实现]
- JS 库选择及原因：Three.js（用于3D几何体构建、投影面展示及鼠标交互旋转），MathJax（用于信息面板中的数学公式渲染）。
- 画布尺寸：800 × 500 px，相对定位容器。
- 布局草图：
  ```
  [图示区 800×500 (Three.js Canvas)]
  [右上角绝对定位: 信息面板 200x150]
  [底部绝对定位: 控件栏 (上一步 | 下一步), y=450]
  ```
- 关键实现要点：
  1. **坐标系与相机**：使用 `THREE.PerspectiveCamera`，初始位置设为 `(8, 6, 10)`，`lookAt(0, 1.5, 0)`，确保初始视角能清晰看到所有面和投影。
  2. **2D标签投影**：在 `requestAnimationFrame` 循环中，使用 `vector.project(camera)` 将3D坐标转换为2D屏幕坐标，加上预设的偏移量，更新 HTML 标签的 `left` 和 `top`。
  3. **状态机设计**：定义 `currentStep` (0-5)，每次步骤切换时，遍历场景中的对象（通过 `name` 或 `userData` 标识），根据当前步骤控制其 `visible` 属性。
  4. **材质与渲染**：面使用 `MeshBasicMaterial` (transparent: true, side: THREE.DoubleSide)，线使用 `LineBasicMaterial`。虚线需调用 `computeLineDistances()`。
  5. **ID 命名规范**：所有 DOM 元素 ID 以 `scene1-` 开头（如 `scene1-canvas`, `scene1-btn-next`, `scene1-info-panel`）。
  6. **IIFE 隔离**：整个 Three.js 逻辑封装在 `(function() { ... })()` 中，避免全局变量污染。
