[分步序列]
- 初始状态（步骤0）：显示上方 v-t 图像及渐近线，下方左侧显示斜面及处于初始位置的导体棒。隐藏位移x、高度h标注及所有公式。
- 步骤1：点击「下一步」→ 导体棒平滑移动至末位置，同时淡入显示位移x和高度h的标注。右侧公式区淡入显示动能定理公式：mgx sinθ - Q_电 = (1/2)mv_m^2。
- 步骤2：点击「下一步」→ 右侧公式区淡入显示代入数据求解位移的过程及结果：x = 4 m。
- 步骤3：点击「下一步」→ 右侧公式区淡入显示电量推导公式及最终计算结果：q = 4 C。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：底部居中放置两个按钮，分别用于控制步骤的推进和回退。
- 教师操作流程：教师首先结合 v-t 图像讲解最大速度的获取；点击“下一步”展示导体棒下滑过程及动能定理公式，讲解能量转化；再次点击展示位移的计算结果；最后点击展示电量的推导和计算，完成整个解题逻辑的闭环。

[技术实现]
- JS 库选择及原因：原生 SVG 用于绘制几何图形和曲线（性能好，易于实现 CSS 过渡动画）；MathJax 用于渲染复杂的物理公式。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800x500]
    (250,50) v-t图像区 (550,200)
    (60,250) 斜面区 (340,420) | (400,240) 公式区 (780,420)
  [控件栏 800x40 (y=450~490)]
  ```
- 关键实现要点：
  - 状态机设计：维护 `currentStep` 变量（0~3），每次点击按钮更新变量并调用 `updateScene()` 函数。
  - 动画实现：导体棒的移动通过修改 SVG `<circle>` 的 `cx` 和 `cy` 属性，并结合 CSS `transition: all 1s ease-in-out` 实现平滑过渡；标注和公式的显示/隐藏通过修改 `opacity` 属性并结合 CSS `transition` 实现淡入淡出。
  - 公式排版：使用绝对定位的 `<div>` 容器放置 MathJax 公式，按步骤分块显示，确保排版整齐。
- ID 命名规范：所有交互元素 ID 必须以 `scene2-` 为前缀（如 `scene2-rod`, `scene2-btn-next`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
