[图示主题与整合说明]
- 本图示主题：线圈穿越磁场全过程的受力与运动分析
- 整合的步骤/概念：装置结构展示、匀速进入磁场时的受力平衡、h=l临界状态分析、穿出磁场时的受力与全程能量转化。
- 教学价值：通过分步动画，教师可以引导学生清晰地观察线圈在进入、完全进入（临界点）和穿出磁场三个关键阶段的受力变化，直观理解安培力方向的保持以及位移与能量转化的几何关系。

[分步序列]
- 初始状态（步骤0）：
  - 线圈组平移至 `translate(0, 260)`（ab边刚好在磁场下边界 y=260）。
  - 砝码组平移至 `translate(0, 160)`。
  - 左右竖直细线 y2 分别连接至 260 和 160。
  - 隐藏所有受力箭头、速度箭头和 2l 位移标注。
  - 高亮显示 h 和 l 标注（可通过透明度脉冲动画强调 h=l）。
- 步骤1（受力平衡）：
  - 线圈组平移至 `translate(0, 210)`（进入磁场一半）。
  - 砝码组平移至 `translate(0, 210)`。
  - 左右竖直细线 y2 分别更新至 210 和 210。
  - 显示受力：T1, m1g, FA(ab), T2, m2g。
  - 显示速度：线圈 v，砝码 v。
- 步骤2（临界状态）：
  - 线圈组平移至 `translate(0, 160)`（ab边在磁场上边界，cd边在下边界）。
  - 砝码组平移至 `translate(0, 260)`。
  - 左右竖直细线 y2 分别更新至 160 和 260。
  - 保持显示步骤1的受力与速度。
  - 高亮线圈的 ab 边和 cd 边（变为红色加粗），强调几何重合关系。
- 步骤3（穿出过程）：
  - 线圈组平移至 `translate(0, 110)`（cd边在磁场中）。
  - 砝码组平移至 `translate(0, 310)`。
  - 左右竖直细线 y2 分别更新至 110 和 310。
  - 隐藏 FA(ab)，显示 FA(cd)（方向依然向下）。其他受力和速度保持显示。
  - 取消 ab/cd 边的高亮。
- 步骤4（能量转化）：
  - 线圈组平移至 `translate(0, 60)`（完全穿出磁场）。
  - 砝码组平移至 `translate(0, 360)`。
  - 左右竖直细线 y2 分别更新至 60 和 360。
  - 隐藏所有受力箭头和速度箭头，减少视觉干扰。
  - 显示线圈和砝码的 2l 位移标注线及文本，展示全程位移。

- 全局绝对坐标与相对坐标的冲突检查：

  - 砝码 2l 标注绝对坐标 (600, 260)。砝码 v 标签在各步骤的最大 X 坐标为 575，水平错开 25px，无冲突。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：在 SVG 内部底部（y=450~490 区域）居中放置一个半透明的控制面板，包含“上一步”按钮、步骤指示器（如“步骤 1 / 4”）和“下一步”按钮。
- 教师操作流程：教师点击“下一步”逐步推进物理过程，配合动画讲解每个阶段的受力特点和几何关系；可随时点击“上一步”回退对比。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript。SVG 的 `<g>` 标签配合 `transform` 属性非常适合实现本场景中刚体（线圈、砝码）及其附着受力的整体平移。
- 画布尺寸：800 × 500 px 固定尺寸。
- 布局草图：
  ```text
  [图示区 800×500]
  +---------------------------------------------------+
  |  ////天花板////                                   |
  |       (滑轮)              (滑轮)                  |
  |         |                   |                     |
  |  2l     |                   |                     |
  |  |   - -|- - - - - - -      |                     |
  |  h  | x | x   x   x   |     |                     |
  |  |  | x | x B x   x   |    [m2]                   |
  |     | x | x   x   x   |                         2l|
  |      - -|- - - - - - -                            |
  |        [m1]                                       |
  |                                                   |
  |             [ ◀上一步 | 步骤 0 / 4 | 下一步▶ ]      |
  +---------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：定义一个包含 5 个状态（0-4）的数组，每个状态记录 `coilY`, `weightY`, `showForces`, `activeFA`, `showV`, `show2l`, `highlightEdges` 等参数。
  2. 动画实现：使用 CSS `transition: transform 0.5s ease, y2 0.5s ease, opacity 0.3s` 实现平滑过渡。通过 JS 切换 SVG 元素的 class 或直接修改属性来触发动画。
  3. 坐标计算：充分利用 SVG 的 `<g>` 编组特性，将线圈及其标签、受力箭头放在一个 `<g id="scene1-coil-group">` 中，只需通过 JS 修改该 group 的 `transform="translate(0, y)"` 即可实现整体移动，极大简化坐标计算。
- ID 命名规范：所有交互元素和需要 JS 控制的图形元素 ID 必须以 `scene1-` 为前缀（如 `scene1-coil-group`, `scene1-btn-next`）。
- IIFE 隔离：所有 JS 代码必须包裹在 `(function() { ... })()` 中，避免全局变量污染。
