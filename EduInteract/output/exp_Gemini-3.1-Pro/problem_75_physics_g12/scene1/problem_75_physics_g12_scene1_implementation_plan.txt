[视觉元素清单]
- 电容器极板：黑色实线，线宽2px。
- 初始状态（小球+连杆）：黑色实线，小球白底黑边。步骤1及之后变为透明度0.3的虚影。
- 末态状态（小球+连杆）：黑色实线，小球白底黑边。
- 重力做功分析：红色（#c62828）箭头与文本。
- 电场力做功分析：蓝色（#1565c0）箭头、文本与辅助虚线。
- 辅助虚线：灰色（#888888），用于极板延伸线等。

[分步序列]
- 步骤0（初始状态）：显示电容器极板、极板间距标注（d=3L）、初始状态的三个小球及连杆（实心）。
- 步骤1（最终状态）：初始状态变为半透明虚影，显示末态的三个小球及连杆（实心），展示系统整体下落3L的过程。
- 步骤2（重力做功）：保持步骤1，新增红色箭头（从初始质心y=140到末态质心y=320），高亮标注"总位移 3L"和"总重力 3mg"。
- 步骤3（电场力做功）：重力箭头变为半透明（0.2），新增右侧三条蓝色箭头，分别表示球1、球2、球3在电场（y=200~380）内的有效位移（3L, 2L, L），并用蓝色虚线将末态小球位置与箭头对齐。

[标签冲突检查]
- 极板间距"d=3L" (40,290) 与 左侧极板 (100,200) 间距 > 50px。无冲突。
- 连杆标签"L" (230,115/175) 与 小球标签"1/2/3" (270,85/145/205) 分布在系统左右两侧。无冲突。
- 重力标签"总位移 3L" (350,230) 与 末态小球 (250,260) 间距 > 80px。无冲突。
- 电场位移标签"球1位移 3L" (510,290)、"球2位移 2L" (610,260)、"球3位移 L" (710,230) 均在各自箭头右侧，且x坐标间隔100px。无冲突。
- 结论：所有标签均已精确规划偏移方向，相互之间间距 ≥ 30px，无任何重叠风险。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：底部居中放置两个按钮及状态指示文本（如"步骤 0 / 3: 初始状态"）。
- 教师操作流程：教师点击"下一步"逐步展示系统下落、重力做功位移、电场力做功位移，配合板书列出动能定理方程。

[技术实现]
- JS 库选择：原生 SVG。适合精确的几何图形、连线和箭头绘制，DOM操作简单。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  | (左侧) 电容器与小球运动 | (右侧) 电场力有效位移分析 |
  |                         |  ↓球1(3L)  ↓球2(2L)  ↓球3(L) |
  [控件栏 y=450~490，包含上一步/下一步按钮]
  ```
- 关键实现要点：
  - 使用 `<marker>` 定义红色和蓝色的箭头样式，方便复用。
  - 将不同步骤的元素分组（`<g id="scene1-group-initial">`, `<g id="scene1-group-final">`, `<g id="scene1-group-gravity">`, `<g id="scene1-group-efield">`）。
  - 状态机设计：定义 `currentStep` (0~3)，每次点击按钮更新变量并调用 `updateState()`，通过修改各 `<g>` 的 `opacity` 和 `transition` 实现平滑过渡。
- ID 命名规范：所有元素 ID 均以 `scene1-` 开头（如 `scene1-btn-next`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
