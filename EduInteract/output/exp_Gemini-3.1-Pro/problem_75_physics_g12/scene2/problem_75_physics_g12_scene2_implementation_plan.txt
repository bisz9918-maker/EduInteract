[视觉元素清单]

- 电场力箭头 (qE/2qE/3qE)：蓝色 (#1565c0)，长度随位移阶跃变化 (30px/60px/90px)，方向向上，附着于中间小球左侧。
- 合力箭头 (F_合)：橙色 (#f57c00)，长度 30px，方向随阶段改变（向下 -> 消失 -> 向上），附着于重力箭头右侧。
- 速度箭头 (v)：绿色 (#2e7d32)，长度非线性变化 (0 -> 100px -> 100px -> 0)，方向向下，附着于最下方小球右侧。
- v-x 图表：坐标轴黑色 (#000000)，曲线及当前点绿色 (#2e7d32)，辅助线灰色虚线 (#888888)。

[分步序列]
本场景为连续拖拽交互，核心状态分为三个阶段（位移 x 从 0 到 180px）：
- 阶段一 (0 <= x < 60)：1个小球进入电场。电场力为 qE (30px)，合力向下 (30px)。速度箭头逐渐变长，v-x 曲线呈开口向右的抛物线。
- 阶段二 (60 <= x < 120)：2个小球进入电场。电场力突变为 2qE (60px)，合力为 0（箭头消失）。速度箭头保持最长 (100px)，v-x 曲线呈水平直线。
- 阶段三 (120 <= x <= 180)：3个小球进入电场。电场力突变为 3qE (90px)，合力向上 (30px)。速度箭头逐渐变短至 0，v-x 曲线呈开口向左的抛物线。

[标签冲突检查]
- 极板间距 "d=3L" (90, 270) 与 电场力 "qE" (155, y)：水平间距 65px，无冲突。
- 电场力 "qE" (155, y) 与 小球系统 (200, y)：水平间距 45px，无冲突。
- 重力 "3mg" (235, y) 与 速度 "v" (255, y')：重力附着于中间小球，速度附着于下方小球，y 坐标天然错开 60px 以上，且水平错开 20px，无冲突。
- 速度 "v" (255, y') 与 合力 "F_合" (275, y)：合力附着于中间小球，y 坐标错开，水平错开 20px，无冲突。
- v-x 图表标签："L", "2L", "3L" 均在 X 轴下方 (y=380)，"v" 在 Y 轴左侧 (y=135)，互不干扰。
结论：所有标签均已通过防重叠检查，位置规划安全。

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：在 SVG 底部 (y=460) 放置一个 `<input type="range">` 滑块，范围 0~180，代表位移 x。
- 教师操作流程：教师缓慢向右拖动滑块，引导学生观察左侧电场力箭头的阶跃变化、合力方向的反转，以及右侧 v-x 图像的实时生成过程。可随时左右拖动以反复对比不同阶段的受力与速度关系。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript。物理过程的几何变换和路径绘制用原生 SVG 非常高效且易于控制。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [左侧：物理动画区 0~400]      [右侧：v-x图表区 450~750]
  上极板 ---       ---           ^ v
            | 小球3              |
            | 小球2 + 受力箭头    |       /-----\
            | 小球1 + 速度箭头    |      /       \
  下极板 -----------------       +------|---|---|---> x
                                       L   2L  3L
  [底部控件栏：位移滑块 -----------------------------]
  ```
- 关键实现要点：
  1. 状态映射：监听滑块 `input` 事件，获取位移 `x` (0~180)。
  2. 坐标计算：小球系统整体 `transform="translate(0, x)"`。
  3. 物理逻辑：
     - `x <= 60`: v = 100 * sqrt(x/60), F_e = 30, F_net = 30 (向下)
     - `60 < x <= 120`: v = 100, F_e = 60, F_net = 0
     - `x > 120`: v = 100 * sqrt((180-x)/60), F_e = 90, F_net = -30 (向上)
  4. 动态路径：v-x 曲线的 `d` 属性通过 JS 循环 `0` 到 `x` 实时拼接生成，确保曲线随滑块“生长”。
  5. ID 命名规范：所有交互元素严格使用 `scene2-` 前缀（如 `scene2-slider`, `scene2-system`, `scene2-force-e`）。
  6. IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免变量污染。
