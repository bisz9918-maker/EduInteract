[图示主题与整合说明]
- 本图示主题：多物体多阶段动量守恒过程演示
- 整合的步骤/概念：整合了初始状态、C滑离A瞬间（中间状态）和最终状态，展示不同阶段的速度变化及动量守恒系统。
- 教学价值：物理过程包含明确的先后阶段和关键状态，分步导航能让教师控制节奏，逐个状态进行受力分析和动量守恒方程的讲解。

[分步序列]

  - A绝对x=100，B绝对x=260，C绝对x=100
  - 显示：C的v0箭头、系统框0
  - 隐藏：其他速度箭头、系统框2
- 步骤1（C滑离A瞬间）：
  - A绝对x=180，B绝对x=340，C绝对x=340
  - 显示：A的vA箭头、B的vA箭头、C的vC箭头
  - 隐藏：v0箭头、v箭头、系统框0、系统框2
- 步骤2（最终状态）：
  - A绝对x=260，B绝对x=500，C绝对x=560
  - 显示：A的vA箭头、B的v箭头、C的v箭头、系统框2
  - 隐藏：v0箭头、vC箭头、B的vA箭头、系统框0

[标签冲突检查]
- 步骤0：v0标签(绝对x=150, y=245) 在系统框0(y=220~360)内部，不与框线重叠。各物体内部标签无冲突。
- 步骤1：C的vC标签(绝对x=380, y=245)，A的vA标签(绝对x=260, y=285)，B的vA标签(绝对x=420, y=285)。y轴错开，且x轴分散，无冲突。
- 步骤2：C的v标签(绝对x=595, y=245)，B的v标签(绝对x=590, y=285)。两者x接近但y相差40px，无冲突。系统框2(y=220~360)包围所有标签，不与框线重叠。

[交互方案]
- 交互类型：分步按钮导航
- 控件说明：底部居中放置「◀ 上一步」按钮、状态指示文本（如"状态 1 / 3：初始状态"）、「下一步 ▶」按钮。
- 教师操作流程：教师点击下一步，物体平滑移动到新位置，对应的速度箭头和系统框淡入淡出，配合讲解动量守恒的阶段。

[技术实现]
- JS 库选择：原生 SVG + 原生 JS + CSS Transitions（无需外部库，性能最佳，加载最快）。
- 画布尺寸：800 × 500 px。
- 布局草图：
  [图示区 800×440]
  [控件栏 800×60，y=440~500]
- 关键实现要点：
  - 使用 `<g>` 标签将木块、内部文本、速度箭头组合在一起。
  - 通过修改 `<g>` 的 `transform="translate(x, 0)"` 实现平移，配合 CSS `transition: transform 1s ease-in-out` 实现平滑动画。
  - 速度箭头和系统框通过修改 `opacity` 配合 `transition: opacity 0.5s` 实现淡入淡出。
  - 文本下标使用 `<tspan baseline-shift="sub" font-size="0.7em">` 实现，避免引入 MathJax。
- ID 命名规范：所有元素 ID 以 `scene1-` 为前缀（如 `scene1-group-A`, `scene1-btn-next`）。
- IIFE 隔离：所有 JS 逻辑封装在 `(function() { ... })()` 中。
