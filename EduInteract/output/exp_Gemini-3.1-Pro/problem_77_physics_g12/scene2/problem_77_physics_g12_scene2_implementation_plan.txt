[图示主题与整合说明]
- 本图示主题：粒子轨迹、打靶范围与极板限制
- 整合的步骤/概念：整合了不同时刻射入的粒子轨迹推导、打靶范围的确定，以及粒子不打在极板上的临界条件。
- 教学价值：教师可以通过分步演示，清晰地展示不同初始时刻粒子的运动轨迹差异，直观呈现打靶范围的形成过程，并自然引出极板间距对轨迹的限制条件，帮助学生建立动态的物理图像。

[视觉元素清单]
- 极板A、B：黑色实线，线宽4px。
- 靶MN：黑色实线，线宽6px，带有阴影或斜线纹理表示靶。
- 中心线OO'：灰色虚线 (#888888)，线宽2px。
- 轨迹1 ($t_0=0$)：蓝色实线 (#1565c0)，线宽3px。由两段抛物线平滑连接。
- 轨迹2 ($t_0=2T/3$)：红色实线 (#c62828)，线宽3px。由两段抛物线平滑连接。
- 打靶范围：绿色实线 (#2e7d32)，线宽6px，叠加在靶MN上。
- 辅助线及标注：灰色虚线 (#888888)，用于连接轨迹终点和右侧标签。
- 文本标签：字体大小 16px，使用 SVG `<text>` 渲染。上标使用 `<tspan dy="-5" font-size="12">2</tspan>` 实现。

[分步序列]
- 初始状态（步骤0）：显示极板A、B，靶MN，中心线OO'，以及基础标签 A, B, M, N, O, O'。
- 步骤1：点击「下一步」→ 动态绘制轨迹1（蓝色），从 O 点延伸至 (600,355)。随后在右侧淡入虚线和终点纵坐标标签 `7/18 aT²`。
- 步骤2：点击「下一步」→ 动态绘制轨迹2（红色），从 O 点延伸至 (600,235)。随后在右侧淡入虚线和终点纵坐标标签 `-1/18 aT²`。
- 步骤3：点击「下一步」→ 在靶MN上淡入绿色高亮线段（y=235 到 y=355），表示打靶范围。
- 步骤4：点击「下一步」→ 高亮轨迹1的终点（在 (600,355) 处闪烁一个小圆点），淡入左侧的 `d/2` 标注箭头和标签，同时在底部中心淡入不等式文本 `7/18 aT² < d/2`。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：在 SVG 底部 (y=450~490) 居中放置两个按钮，控制步骤 0~4 的切换。
- 教师操作流程：教师首先介绍物理模型（步骤0）；点击下一步展示 t=0 时刻的粒子轨迹并讲解其偏转最大（步骤1）；再次点击展示 t=2T/3 时刻的轨迹并讲解其偏转最小（步骤2）；点击下一步总结打靶范围（步骤3）；最后点击下一步引出不打在极板上的临界条件（步骤4）。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。SVG 非常适合绘制精确的几何图形和抛物线轨迹，且易于实现线条动画（stroke-dasharray）。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×450]
  [控件栏 800×50，包含 上一步 / 下一步 按钮]
  ```
- 关键实现要点：
  - 轨迹生成：在 JS 中预先计算轨迹的离散点（每隔 5px 计算一个 y 值），生成 SVG `<polyline>` 的 `points` 属性。
    - 轨迹1：x在[150,450]时 y = 250 + (x-150)² / 1500；x在[450,600]时 y = 310 + 0.4(x-450) - (x-450)² / 1500。
    - 轨迹2：x在[150,300]时 y = 250 - (x-150)² / 1500；x在[300,600]时 y = 235 - 0.2(x-300) + (x-300)² / 1500。
  - 动画实现：利用 CSS `transition` 控制元素的 `opacity` 实现淡入淡出；利用 `stroke-dasharray` 和 `stroke-dashoffset` 实现轨迹的动态绘制效果。
  - 状态机设计：定义一个 `currentStep` 变量，每次点击按钮更新该变量，并调用 `updateScene()` 函数，根据当前步骤控制各 SVG 元素的可见性和动画状态。
  - ID 命名规范：所有交互元素 ID 必须以 `scene2-` 为前缀（如 `scene2-traj1`, `scene2-btn-next`）。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
