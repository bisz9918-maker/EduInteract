[图示主题与整合说明]
- 本图示主题：双棒下落的运动学过程演示
- 整合的步骤/概念：整合了a、b两棒从静止释放、b进入磁场匀速、a继续自由落体、b出磁场且a进磁场的完整动态过程。
- 教学价值：教师可通过分步演示，清晰展示两根导体棒在不同时间节点的相对位置、速度变化及运动状态（自由落体与匀速运动的对比），帮助学生直观理解复杂的物理过程和临界状态。

[视觉元素清单]

[分步序列]
- 初始状态（步骤0）：两棒静止。棒a在y=33（M处），棒b在y=150（N处）。隐藏速度箭头。
- 步骤1（b刚入磁场）：点击「下一步」。棒a下落至y=183，棒b下落至y=300（L1处）。在棒b右侧显示向下的速度箭头vb。
- 步骤2（b在磁场中）：点击「下一步」。棒a加速下落至y=237，棒b匀速下落至y=350。隐藏vb箭头。
- 步骤3（b出a入）：点击「下一步」。棒a下落至y=300（L1处），棒b下落至y=400（L2处）。在棒a右侧显示向下的速度箭头va，高亮显示位移d。

[交互方案]
- 交互类型：分步按钮导航。
- 控件说明：在SVG底部（y=460区域）居中放置两个按钮：「◀ 上一步」和「下一步 ▶」。
- 教师操作流程：教师点击「下一步」逐步推进物理过程，配合CSS过渡动画（transition），平滑展示导体棒的位移过程。可随时点击「上一步」回退到上一状态进行对比讲解。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript。SVG 非常适合绘制精确的几何图形和连线，且易于通过 CSS 实现平滑动画。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  |      [ R ]      |
  |------- a -------| M
  |                 |
  |------- b -------| N
  |                 |
  | - - - - - - - - | L1
  |   x   x   x   x |
  d   x   B   x   x |
  |   x   x   x   x |
  | - - - - - - - - | L2
  |                 |
  [ ◀ 上一步 | 下一步 ▶ ]
  ```
- 关键实现要点：
  1. 状态机设计：定义 `currentStep` 变量（0~3），点击按钮时更新该变量并调用 `updateScene()` 函数。
  2. 动画实现：为棒a、棒b的 `<line>` 和 `<text>` 元素添加 `style="transition: all 0.5s ease-in-out;"`，通过 JS 修改 `y1`, `y2`, `y` 属性即可实现平滑的下落动画。
  3. 速度箭头控制：使用 `opacity` 属性配合 transition 实现箭头的淡入淡出。
  4. ID 命名规范：所有元素 ID 均以 `scene1-` 开头（如 `scene1-rod-a`, `scene1-btn-next`），确保全局唯一性。
  5. IIFE 隔离：所有逻辑代码封装在 `(function() { ... })()` 中，避免变量污染。
