[图示主题与整合说明]
- 本图示主题：两棒分别在磁场中时的等效电路与受力分析
- 整合的步骤/概念：整合了棒b在磁场中和棒a在磁场中两种状态下的实物位置、等效电路图以及受力平衡关系。
- 教学价值：教师可以通过切换两种状态，直观对比展示“谁在磁场中谁就是电源，另一根棒作为外电路并联”的核心易错点，帮助学生建立正确的等效电路模型并结合受力平衡进行分析。

[交互方案]
- 交互类型：多状态切换（2个按钮）
- 控件说明：底部居中放置两个按钮，分别为「状态1：b在磁场中」和「状态2：a在磁场中」。
- 教师操作流程：教师首先展示状态1，讲解b在磁场中切割磁感线充当电源，a和R为外电路并联；然后点击状态2按钮，画面切换，展示a进入磁场充当电源，b和R为外电路并联。通过对比加深学生对等效电路的理解。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。SVG 非常适合绘制精确的几何图形、电路符号和箭头，且易于通过 DOM 操作切换显示状态。MathJax 用于渲染标签中的数学公式（如带有下标的变量）。
- 画布尺寸：800 × 500 px。
- 布局草图：
  [左侧 400x450：实物与受力分析图] [右侧 400x450：等效电路图]
  [底部 800x50：控件栏，包含两个切换按钮]
- 关键实现要点：
  1. 使用 `<g>` 标签将公共元素、状态1特有元素、状态2特有元素分别编组。
  2. 初始加载时，状态1的 `<g>` 设为可见，状态2的 `<g>` 设为隐藏（`display: none`）。
  3. 按钮点击事件中，切换对应 `<g>` 的 `display` 属性，并更新按钮的激活样式（如改变背景色）。
  4. 箭头绘制可使用 SVG 的 `<marker>` 元素定义箭头头部，方便复用。
  5. 电池符号通过两条不同长度和粗细的 `<line>` 实现，长线在上表示正极。
- ID 命名规范：所有交互元素和组 ID 必须以 `scene2-` 为前缀（如 `scene2-state1-group`, `scene2-btn-state1`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
