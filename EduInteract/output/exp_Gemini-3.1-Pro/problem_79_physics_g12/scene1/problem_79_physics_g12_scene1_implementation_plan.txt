[图示主题与整合说明]
- 本图示主题：受力分析与发生相对滑动的临界条件
- 整合的步骤/概念：物块与木板的受力分析、静摩擦力与滑动摩擦力的转换、加速度随拉力F变化的规律。
- 教学价值：教师可以通过拖动滑块连续改变拉力F，直观展示摩擦力和加速度的动态变化过程，清晰呈现从相对静止到相对滑动的临界状态，帮助学生理解牛顿第二定律在多体系统中的应用。

[视觉元素清单]
- 地面：黑色实线，下方附加多条短斜线表示粗糙/固定地面。
- 木板 M：矩形，填充 #1565c0（透明度 10%），边框 #000000。
- 物块 m：矩形，填充 #c62828（透明度 10%），边框 #000000。
- 拉力 F 箭头：#1565c0，带有箭头标记。
- 摩擦力 f, f' 箭头：#c62828，带有箭头标记。
- 长度 L 标注：#888888 虚线及端点短竖线。
- 数据面板：浅灰色背景 #f8f9fa，边框 #dee2e6，包含 F, f, a_m, a_M 及系统状态的文本。

[分步序列]
- 初始状态：F = 0 N。M 和 m 静止。F, f, f' 箭头长度为 0（隐藏）。数据面板显示全为 0，状态为"相对静止"。
- 拖动滑块 (0 < F < 4 N)：F 箭头随 F 增大而变长。f 和 f' 箭头随 F 增大而变长（f = F/4）。数据面板实时更新 a_m = a_M = F/4。状态保持"相对静止"。
- 临界状态 (F = 4 N)：f 和 f' 箭头达到最大长度（对应 1 N）。数据面板显示 a_m = a_M = 1.00 m/s²。状态文本高亮显示"临界状态"（橙色）。
- 相对滑动 (F > 4 N)：F 箭头继续变长。f 和 f' 箭头长度保持不变（对应 1 N）。数据面板显示 a_m 保持 1.00 m/s²，a_M 继续增大。状态文本显示"相对滑动"（红色）。

[标签冲突检查]

- 标签"m"：(470, 250)
- 标签"F"：(500 + F*15 + 15, 325)，最小 x=515。
- 标签"f"：(470 + f*40 + 10, 275)，最大 x=520。
- 标签"f'"：(470 - f*40 - 10, 305)，最小 x=420。

冲突检查：
- "m" (y=250) 与 "f" (y=275)：垂直间距 25px，无冲突。
- "f" (y=275) 与 "f'" (y=305)：垂直间距 30px，无冲突。
- "f'" (y=305) 与 "M" (y=320)："f'" 最大 x=460，"M" x=300，水平间距 160px，无冲突。
- "F" (y=325) 与 "M" (y=320)："F" 最小 x=515，"M" x=300，水平间距 215px，无冲突。
所有标签均有充足的安全间距，无重叠风险。

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：底部中央放置一个 `<input type="range">` 滑块，ID 为 `scene1-slider-F`。左侧配有文本"拉力 F (N):"，右侧配有实时数值显示。
- 教师操作流程：教师在讲解时，缓慢向右拖动滑块，引导学生观察摩擦力 f 随拉力 F 的同步增长，以及两物体加速度的相同。当到达 4N 时，强调这是最大静摩擦力临界点。继续拖动超过 4N，展示摩擦力不再增加，而木板加速度超过物块加速度，发生相对滑动。

[技术实现]
- JS 库选择及原因：原生 SVG。物理模型为简单的矩形和箭头，原生 SVG 易于实现精确的 DOM 操作和属性绑定，性能好且无需外部依赖。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +---------------------------------------------------+
  |                                     [数据面板]    |
  |                                     F = ...       |
  |                                     f = ...       |
  |                        [ m ]-> f    a_m = ...     |
  |            [      M    <-- f']-----> F            |
  |  ///////////////////////////////////////////////  |
  |             |------- L -------|                   |
  |                                                   |
  |    拉力 F (N): [========O-----------] 4.0         |
  +---------------------------------------------------+
  ```
- 关键实现要点：
  - 状态机设计：在 `input` 事件监听器中，根据 `F` 的值判断处于哪个区间（<=4 或 >4），分别计算 `f`, `a_m`, `a_M`。
  - 坐标计算：箭头长度使用线性映射，F 箭头长度为 `F * 15`，f 箭头长度为 `f * 40`。
  - 动态更新：每次滑动时，更新箭头的 `x2` 属性和对应标签的 `x` 属性。更新数据面板的 `textContent`。
  - 箭头标记：使用 `<defs><marker>` 定义箭头样式，通过 `marker-end` 属性应用到 `<line>` 元素上。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀，如 `scene1-arrow-F`, `scene1-text-am`。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
