[分步序列]
- 初始状态（步骤0）：显示水体、甲物块（淡化）、连接绳（淡化）、乙物块。受力向量和右侧公式全部隐藏。
- 步骤1（乙受力分析）：点击「下一步」。
  - 视觉变化：淡入显示 $G_乙$、$F_{浮乙}$、$T$ 三个向量及其标签。
  - 公式区：淡入显示步骤1的受力平衡方程 $G_乙 = F_{浮乙} + T$。
- 步骤2（密度推导）：点击「下一步」。
  - 视觉变化：拉力 $T$ 向量添加缩放呼吸动画（强调 $T > 0$）。
  - 公式区：淡入显示步骤2的密度推导过程及结论“选项C错误”。
- 步骤3（质量推导）：点击「下一步」。
  - 视觉变化：移除 $T$ 的动画，为浮力 $F_{浮乙}$ 向量添加缩放呼吸动画（强调 $F_{浮乙} > 0$）。
  - 公式区：淡入显示步骤3的质量推导过程及结论“选项D正确”。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：底部居中放置两个按钮，ID 分别为 `scene2-btn-prev` 和 `scene2-btn-next`。
- 教师操作流程：教师首先展示乙物块的受力情况，点击下一步展示平衡方程；接着点击下一步，结合拉力存在的条件推导密度关系；最后点击下一步，引入情境一的结论推导质量关系。可随时点击上一步回退。

[技术实现]
- JS 库选择及原因：原生 SVG 用于绘制左侧图形和向量（易于控制坐标和动画），MathJax 用于右侧公式渲染（数学公式排版最佳）。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```text
  +---------------------------------------+
  |       [水面]       |  [步骤1 公式]        |
  |    +----+         |  G_乙 = F_浮 + T    |
  |    | 甲 |         |                     |
  |    +----+         |  [步骤2 公式]        |
  |      | T, F_浮    |  T > 0 => 密度推导  |
  |    +----+         |                     |
  |    | 乙 |         |  [步骤3 公式]        |
  |    +----+         |  F_浮 > 0 => 质量推导|
  |      | G_乙       |                     |
  +---------------------------------------+
  |       [ ◀ 上一步 ] [ 下一步 ▶ ]         |
  +---------------------------------------+
  ```
- 关键实现要点：
  - 状态机设计：定义 `currentStep` 变量（0~3），通过 `updateStep()` 函数统一管理各元素的 `opacity` 和 `animation` 样式。
  - 动画曲线：使用 CSS `@keyframes` 实现向量的呼吸动画（`transform: scale(1.1)`），注意设置 `transform-origin` 为向量的起点。
  - 公式渲染：由于 MathJax 渲染需要时间，建议在初始加载时即渲染所有公式，通过控制父容器的 `opacity` 来实现显示/隐藏，避免动态渲染导致的闪烁。
  - ID 命名规范：所有元素 ID 均以 `scene2-` 开头。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
