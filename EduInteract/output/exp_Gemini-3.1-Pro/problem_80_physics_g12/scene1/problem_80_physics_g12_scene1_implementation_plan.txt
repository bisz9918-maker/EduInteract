[图示主题与整合说明]
- 本图示主题：选手飞越水面的完整物理过程及几何关系分析
- 整合的步骤/概念：将复杂的连续运动拆解为初始状态、圆周摆动过程、最低点受力分析、平抛运动轨迹，以及最终的水平距离几何关系。
- 教学价值：教师可以通过分步导航，引导学生按时间顺序（摆动 -> 最低点 -> 平抛）和逻辑顺序（受力分析 -> 运动学计算 -> 几何关系）逐步剖析题目，避免一次性展示过多信息导致学生认知超载。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：在 SVG 底部（y=450区域）居中放置两个按钮。
- 教师操作流程：教师首先结合步骤0讲解题目已知条件；点击下一步展示摆动过程并引导学生计算最低点速度；再次点击展示受力分析并计算拉力；点击下一步展示平抛过程并计算水平位移；最后点击展示完整的几何距离关系，得出最终答案。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript。本场景全为标准几何图形、路径和文本，原生 SVG 能够提供最清晰的渲染和最精确的坐标控制，无需引入外部库。
- 画布尺寸：800 × 500 px（固定尺寸）。
- 布局草图：
  ```
  [图示区 800×440]
    (顶部 O点及绳子)
    (左侧岸边，右侧水面及浮台)
    (中间轨迹及受力分析)
    (底部尺寸标注)
  [控件栏 800×60]
    [ ◀ 上一步 ] [ 下一步 ▶ ]
  ```
- 关键实现要点：
  1. 状态机设计：定义一个 `currentStep` 变量（0~4）。编写 `updateState(step)` 函数，根据当前步骤控制各 SVG 元素的 `opacity` 属性。
  2. 元素分组与 ID 命名：为每个逻辑组（如 `scene1-step1-elements`, `scene1-mass0`）分配明确的 ID。所有 ID 必须以 `scene1-` 开头。
  3. 残影效果：在步骤切换时，不要直接隐藏前一步的运动主体（质点和绳子），而是将其 `opacity` 设置为 `0.3`，这在物理教学中非常有助于学生理解运动的全过程。
  4. 箭头标记：使用 `<defs><marker>` 定义统一的箭头样式，应用于矢量和标注线。
- IIFE 隔离：所有 JS 逻辑必须包裹在 `(function() { ... })()` 中，避免全局变量污染。
