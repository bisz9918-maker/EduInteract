[图示主题与整合说明]
- 本图示主题：初始静止状态的受力分析与振幅求解
- 整合的步骤/概念：物体B的受力平衡、物体A的受力平衡、弹簧初始伸长量与振幅的关系
- 教学价值：教师可以通过分步展示，引导学生逐步完成复杂系统的受力分析，清晰展示从受力平衡到简谐运动初始状态（振幅）的逻辑推导过程，避免一次性呈现过多信息导致认知超载。

[分步序列]
- 初始状态（步骤0）：显示基础场景（墙壁、地面、滑轮、弹簧、细线、物块A和B）及30°角度标注。系统处于静止状态。
- 步骤1（B受力分析）：点击「下一步」。高亮物块B（边框加粗）。出现B的重力 $mg$（向下）和拉力 $T_{拉}$（向上）。在右侧空白区(650, 280)显示结论公式：$T_{拉} = mg$。
- 步骤2（A受力分析）：点击「下一步」。取消B的高亮，高亮物块A。出现A的重力 $mg$（向下）、支持力 $N$（向上）、弹簧拉力 $F_k$（向左）、绳拉力 $T_{拉}$（向右上方30°）。
- 步骤3（A水平平衡）：点击「下一步」。将A的绳拉力 $T_{拉}$ 分解，出现水平分力 $T_x$ 和竖直分力（虚线箭头）。在左上角空白区(150, 120)显示水平方向平衡方程：$F_k = T_{拉} \cos 30^\circ = rac{\sqrt{3}}{2}mg$。
- 步骤4（确定振幅）：点击「下一步」。在A下方出现"原长位置"和"初始位置"的竖直虚线辅助线，以及它们之间的双向箭头标注。在左上角(150, 80)追加显示公式：$x_0 = rac{F_k}{k} = rac{\sqrt{3}mg}{2k}$。并在底部(400, 420)居中显示提示文字："剪断细线后，A从静止释放，此初始伸长量即为简谐运动的振幅 A"。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：在 SVG 底部 (y=450~490) 居中放置两个按钮。
- 教师操作流程：教师首先展示初始物理场景，讲解题意。然后点击“下一步”逐步引导学生分析B的受力、A的受力、A的平衡方程，最后得出振幅的结论。每一步配合讲解，逻辑清晰。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。SVG 非常适合绘制清晰的几何图形、矢量箭头和虚线，且易于通过 DOM 操作实现元素的显示/隐藏动画。MathJax 用于渲染公式。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800x450]
  包含墙壁、地面、滑轮、物块、弹簧及所有受力分析箭头。
  左上角留白用于显示推导公式。
  [控件栏 800x50]
  底部居中放置 ◀上一步 / 下一步▶ 按钮。
  ```
- 关键实现要点：
  - 使用 `<g>` 标签将不同步骤的元素分组（如 `id="scene1-step1-elements"`），通过改变 `display` 或 `opacity` 属性实现步骤切换。
  - 弹簧可以使用 `<polyline>` 绘制锯齿状路径。
  - 箭头可以使用 `<marker>` 定义，方便复用。
  - 状态机：定义一个 `currentStep` 变量（0-4），点击按钮时更新变量并调用 `updateView()` 函数，根据当前步骤控制各组元素的可见性。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-btn-next`, `scene1-block-a`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
