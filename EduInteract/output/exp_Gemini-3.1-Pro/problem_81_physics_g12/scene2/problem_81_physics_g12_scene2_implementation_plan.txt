[图示主题与整合说明]
- 本图示主题：细线断开后的运动学关联
- 整合的步骤/概念：A的简谐运动过程（水平）、B的自由落体过程（竖直）、两者的时间同步关系
- 教学价值：教师可通过拖动时间滑块，直观展示在相同的时间流逝下，A从最大位移处运动到压缩最短处，同时B刚好落地。帮助学生建立“A压缩最短”与“B落地”共时性的直观物理图像。

[视觉元素清单]
- 墙壁、平台、悬崖、地面：#000000，线宽2。阴影线（Hatching）为 #888888。
- 弹簧：#000000，线宽2，绘制为8段连续折线（Zigzag）。
- 物块A、B：填充 #1565c0（透明度 20%），边框 #1565c0，线宽2。内部文字 "A", "B" 居中。
- 标记线：#888888 虚线，线宽1.5。
- 标记文本：#000000，14px，无衬线字体。
- 速度矢量：#2e7d32，线宽2，带箭头。
- 状态面板：绝对定位的 HTML div，背景半透明白，带边框。

[分步序列]
- 初始状态 (s=0, t=0)：
  - A在最右端 (x=330)，弹簧处于最大伸长状态。
  - B在初始高度 (y=150)。
  - 速度矢量 v_B 长度为0（隐藏）。
  - 状态面板显示：t = 0, v_B = 0。
- 拖动滑块 (0 < s < 1)：
  - A向左运动，速度先增后减，位置 x_A = 250 + 80 * cos(π * s)。
  - B向下加速掉落，位置 y_B = 150 + 240 * s²。
  - 速度矢量 v_B 随时间变长，长度 = 50 * s。
  - 状态面板实时更新 t 和 v_B 的比例数值。
- 终点状态 (s=1, t=T/2)：
  - A到达最左端 (x=170)，弹簧压缩最短。
  - B刚好接触地面 (y=390，底部y=410)。
  - 状态面板高亮显示结论：t = T/2, v_B = gT/2（文字变为 #c62828 并加粗）。

[标签冲突检查]
- `x=-A` (170,90), `x=0` (250,90), `x=A` (330,90)：三者Y坐标相同，X坐标间距80px，文本宽度约40px，间距充足，无冲突。
- `v_B` 标签 (545, y_B+25s)：y_B 范围为 150~390。状态面板位于 Y=50~110。`v_B` 标签始终在状态面板下方，无垂直冲突。
- `v_B` 矢量与物块B：矢量X=530，物块B右边缘X=520，间距10px，无重叠。
- 弹簧与物块A：弹簧终点为 x_A-20，恰好连接物块A左边缘，无穿透重叠。

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：底部居中放置一个 `<input type="range">` 滑块，范围 0 到 100，代表参数 s 从 0 到 1。
- 教师操作流程：教师在讲解时，缓慢向右拖动滑块，引导学生同时观察A的水平简谐运动和B的竖直自由落体运动。当滑块拖到最右侧时，指出A刚好到达最左端，B刚好落地，从而得出时间相等的结论。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。图形简单，原生 SVG 易于实现参数化动态更新。
- 画布尺寸：800 × 500 px。
- 布局草图：
  [图示区 800×450]
  [控件栏 800×50 (y=450~500)，包含居中滑块]
- 关键实现要点：
  - 状态机/更新函数：定义 `updateScene(s)` 函数，根据参数 `s` (0~1) 计算所有动态元素的坐标并更新 SVG 属性。
  - 弹簧绘制：根据起点 (100, 150) 和终点 (x_A-20, 150) 动态生成 `d` 属性字符串，保持折线段数不变，仅改变水平跨度。
  - 文本更新：使用 `innerHTML` 更新状态面板中的公式，终点状态通过修改 `style.color` 和 `style.fontWeight` 实现高亮。
- ID 命名规范：所有交互元素和动态图形 ID 必须以 `scene2-` 为前缀（如 `scene2-slider`, `scene2-block-a`, `scene2-spring`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
