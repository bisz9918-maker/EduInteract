[图示主题与整合说明]
- 本图示主题：金属棒的动力学过程与受力平衡分析
- 整合的步骤/概念：初始状态、感应电流方向判断、受力分析（恒力、摩擦力、安培力）、动态加速过程、最终匀速稳定状态。
- 教学价值：教师可通过分步动画，引导学生直观观察并理解电磁感应中的动态反馈过程（速度增加 → 感应电动势增加 → 电流增加 → 安培力增加 → 合力减小），最终达到受力平衡的稳态。

[分步序列]
- 初始状态（步骤0）：棒位置 x=600。显示导轨、磁场、棒ab、恒力F（长100）。隐藏 v, F_A, f, I。顶部文本：“初始状态：金属棒在恒力F作用下静止，即将开始运动。”
- 步骤1：点击「下一步」→ 棒移动至 x=520。显示速度v（长30）、电流I（棒内向下，回路逆时针）。顶部文本：“运动与感应：棒向左切割磁感线，产生感应电动势。回路中产生逆时针感应电流。”
- 步骤2：点击「下一步」→ 棒移动至 x=440。速度v变长（长50）。显示摩擦力f（长40）、安培力F_A（长20）。顶部文本：“受力分析：棒受恒力F、滑动摩擦力f和安培力F_A。安培力向右，阻碍相对运动。”
- 步骤3：点击「下一步」→ 棒移动至 x=340。速度v变长（长70），安培力F_A变长（长40）。顶部文本：“动态变化：加速阶段。速度 v 增大 → 电流 I 增大 → 安培力 F_A 增大。合力逐渐减小。”
- 步骤4：点击「下一步」→ 棒移动至 x=220。速度v达最大（长90），安培力F_A达最大（长60）。顶部文本：“匀速稳定：当 F_A 增大到使合力为零时，棒达到最大速度并做匀速直线运动。此时 F = F_A + f。”

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：在 SVG 内底部 (y=460) 居中放置两个按钮。
- 教师操作流程：教师点击“下一步”逐步展示物理过程，配合顶部文本提示讲解因果关系。可随时点击“上一步”回退复习。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript。SVG 适合绘制几何图形和矢量箭头，且易于通过 CSS `transition` 实现平滑的位移和长度变化动画。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  (顶部 400,60: 状态文本提示)
  (中部 100~700, 150~350: U形导轨、磁场、金属棒及受力箭头)
  [控件栏 (底部 y=460): ◀上一步 | 下一步▶]
  ```
- 关键实现要点：
  - 状态机设计：定义 `currentStep` 变量 (0-4) 和 `stepData` 数组，存储每步的棒 x 坐标、各箭头长度、透明度及文本内容。
  - 动画实现：为 SVG 中的移动元素（棒、箭头、标签）添加 CSS `transition: all 0.8s ease-in-out;`。JS 仅需更新 DOM 属性（如 `x1`, `x2`, `transform`），浏览器自动处理补间动画。
  - 箭头绘制：使用 `<defs>` 定义 `<marker>` 作为箭头末端，简化路径绘制。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-rod`, `scene1-arrow-v`）；JS 中用 `document.getElementById` 获取元素。
- IIFE 隔离：所有 JS 代码包裹在 `(function() { ... })()` 中，避免全局变量污染。
