[图示主题与整合说明]
- 本图示主题：位移与能量转化分析
- 整合的步骤/概念：电荷量与位移的关系（扫过面积）、能量守恒关系（做功与能量转化柱状图）。
- 教学价值：教师可以通过分步演示，先引导学生从几何位移推导出电荷量，再基于位移进行全局的能量守恒分析，最后将总焦耳热按电阻比例分配，逻辑递进清晰，帮助学生建立完整的能量转化图像。

[分步序列]
- 初始状态（步骤0）：显示U形导轨、电阻R、磁场B，以及位于 x=350 处的初始棒（实线）。
- 步骤1：点击「下一步」→ 初始棒变为虚线，最终棒在 x=150 处出现（实线）。扫过面积 $\Delta S$ 高亮显示。下方出现位移标注 $x$。显示电荷量公式 $q = rac{\Delta \Phi}{R+r}$。
- 步骤2：点击「下一步」→ 在最终棒上出现拉力 $F$（向左）和摩擦力 $f$（向右）的箭头及标签。
- 步骤3：点击「下一步」→ 右侧出现能量转化柱状图的坐标轴、$W_F$ 柱、以及由 $\Delta E_k, Q_f, Q_{总}$ 组成的堆叠柱。上方出现能量等式 $W_F = \Delta E_k + Q_f + Q_{总}$。
- 步骤4：点击「下一步」→ 堆叠柱中的 $Q_{总}$ 柱分裂为 $Q_R$ 和 $Q_r$ 两部分，颜色区分，标签更新。能量等式下方追加 $Q_{总} = Q_R + Q_r$。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：底部居中放置「上一步」和「下一步」按钮。
- 教师操作流程：教师首先展示初始状态，点击下一步演示棒的运动和面积扫过，讲解电荷量推导；再次点击展示受力做功；第三次点击展示宏观能量守恒柱状图；最后点击展示焦耳热在内外电阻上的分配。

[技术实现]
- JS 库选择及原因：原生 SVG 配合 MathJax。SVG 适合绘制几何图形和柱状图，易于实现动画和精确坐标控制；MathJax 用于渲染公式。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  左侧：导轨与面积 (50~450)    右侧：能量柱状图 (450~750)
  底部：控件栏 (y=450~490)
  ```
- 关键实现要点：
  - 状态机设计：定义 `currentStep` 变量（0-4），每次点击按钮更新状态并调用 `render()` 函数。
  - 动画过渡：使用 CSS `transition: opacity 0.5s, transform 0.5s` 实现元素的平滑显示和隐藏。
  - 柱状图绘制：使用 SVG `<rect>` 元素，通过调整 `height` 和 `y` 属性实现堆叠效果。
  - ID 命名规范：所有交互元素 ID 必须以 `scene2-` 为前缀（如 `scene2-rod-initial`, `scene2-bar-wf`）。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
