[图示主题与整合说明]
- 本图示主题：双气缸系统中气体的等压膨胀与等温压缩过程演示
- 整合的步骤/概念：初始状态的几何与物理量关系、活塞b上升的等压膨胀过程、活塞a上升的等温压缩过程。

[分步序列]
- 初始状态（步骤0）：活塞a在y=168，活塞b在y=232。左右面板显示初始压强和体积。加热丝黑色。
- 步骤1（加热过程1）：点击「下一步」，加热丝变红，活塞b平滑上升至B气缸顶部(y=104)，活塞a保持不动。氮气区域随之扩大。右侧面板更新为等压膨胀状态。
- 步骤2（状态2结算）：点击「下一步」，加热丝恢复黑色，氮气区域闪烁高亮（透明度0.2->0.5->0.2），右侧面板追加结论文本“活塞b升至顶部”。
- 步骤3（加热过程2）：点击「下一步」，加热丝再次变红，活塞a平滑上升至y=152（上升H/16）。氧气和氮气区域随之更新。左侧高度标注更新为"3H/16"。左侧面板更新为等温压缩状态。
- 步骤4（状态3结算）：点击「下一步」，加热丝恢复黑色，氧气区域闪烁高亮，左侧面板追加结论文本“活塞a上升H/16”。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：底部居中放置两个按钮，ID分别为 `scene1-btn-prev` 和 `scene1-btn-next`。
- 教师操作流程：教师点击“下一步”触发动画，动画过程中讲解物理过程；动画结束后再次点击“下一步”显示该过程的结论和高亮，帮助学生巩固。

[技术实现]
- JS 库选择：原生 SVG（用于几何图形和动画） + HTML/CSS（用于绝对定位的文本面板） + MathJax（用于数学公式渲染，需在每次更新 innerHTML 后调用 `MathJax.typesetPromise()`）。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```text
  [左侧面板 150px] [气缸A 200px] [连通管] [气缸B 50px] [右侧面板 150px]
  [---------------------- 控件栏 (y=460-490) ----------------------]
  ```
- 关键实现要点：
  - 状态机：维护 `currentStep` (0-4)，根据步骤更新目标坐标。
  - 动画：使用 `requestAnimationFrame` 实现活塞y坐标的平滑插值（lerp），并在每帧更新氧气 `<rect>` 的 height 和氮气 `<path>` 的 d 属性。
  - 绝热壁图案：在 `<defs>` 中定义 `<pattern id="scene1-adiabatic-pattern">`，用于填充绝热壁矩形。
  - ID 命名规范：所有元素 ID 必须以 `scene1-` 为前缀，避免全局冲突。
  - IIFE 隔离：所有 JS 代码包裹在 `(function() { ... })()` 中。
