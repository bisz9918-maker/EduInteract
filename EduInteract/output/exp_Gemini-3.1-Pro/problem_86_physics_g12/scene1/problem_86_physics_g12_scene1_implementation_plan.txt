[图示主题与整合说明]
- 本图示主题：带电微粒在极板间的运动轨迹及临界状态分析
- 整合的步骤/概念：无电场时的平抛运动、加电场后的两种临界出射状态（从下边缘出射、从上边缘出射）及有效出射区域。
- 教学价值：教师可通过分步导航，先引导学生分析纯重力下的平抛运动求得初速度，再逐步引入电场力，分别分析上下两个临界状态的受力与运动，最后直观展示粒子能射出的有效区域，完美契合循序渐进的授课节奏。

[分步序列]
- 步骤0（初始状态）：显示极板A/B、接地符号、L和d标注、入射微粒及v0、中线辅助线。显示轨迹0（平抛）、点O、轨迹0的水平(L/2)和竖直(d/2)位移辅助线及标签。
- 步骤1（下临界状态）：保留步骤0。新增轨迹1（蓝色）、轨迹1的竖直位移(d/2)及标签。在轨迹1上(x=500处)显示受力分析微粒，附加向下的mg箭头和向上的Fe1箭头（较短）。
- 步骤2（上临界状态）：保留步骤1。新增轨迹2（红色）、轨迹2的竖直位移(d/2)及标签。在轨迹2上(x=500处)显示受力分析微粒，附加向下的mg箭头和向上的Fe2箭头（较长）。
- 步骤3（有效出射区域）：保留步骤2的所有轨迹和辅助线。隐藏轨迹1和轨迹2上的受力分析微粒及箭头（避免画面过于杂乱）。在轨迹1和轨迹2之间填充半透明绿色区域，直观展示有效出射范围。

[标签冲突检查]
- `L/2` 标签 (300,340) 与 极板A (y=300)：位于极板下方40px，无冲突。
- `O` 标签 (400,320) 与 `L/2` 标签 (300,340)：x坐标相差100px，无冲突。
- 轨迹0 `d/2` 标签 (415,250) 与 轨迹1受力微粒 (500,256)：x坐标相差85px，无冲突。
- 轨迹1 `d/2` 标签 (615,250) 与 `d` 标签 (655,200)：x坐标相差40px，y坐标相差50px，无冲突。
- 轨迹2 `d/2` 标签 (615,150) 与 `d` 标签 (655,200)：x坐标相差40px，y坐标相差50px，无冲突。
- 受力分析标签 `mg` (510,286) 与 轨迹1 `d/2` (615,250)：x坐标相差105px，无冲突。
- 结论：所有标签均已通过错开x/y坐标或分布在不同区域，确保无重叠。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：在SVG内部底部（y=460区域）居中放置两个按钮。
- 教师操作流程：
  1. 初始展示平抛运动，讲解重力作用下的运动规律，求出初速度。
  2. 点击“下一步”，展示下临界状态，讲解电场力较小时的类平抛运动及受力关系。
  3. 点击“下一步”，展示上临界状态，讲解电场力较大时的类平抛运动及受力关系。
  4. 点击“下一步”，展示有效出射区域，总结电势范围。

[技术实现]
- JS 库选择：原生 SVG。抛物线轨迹使用 SVG `<path>` 的二次贝塞尔曲线 `Q` 指令实现，控制点 x 坐标设为起点和终点 x 坐标的中点，y 坐标设为顶点 y 坐标。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  (60)       |---------- L ----------|
  (100)  === B板 -------------------------   |
  (200)  v0 -> .    轨迹2(红) /              |
                   .         /               d
  (300)      A板 ------.------------------   |
                     O    轨迹1(蓝) \        |
  [控件栏 y=460]
           < 上一步 | 下一步 >
  ```
- 关键实现要点：
  - 轨迹路径生成：
    - 轨迹0: `d="M 200 200 Q 300 200 400 300"`
    - 轨迹1: `d="M 200 200 Q 400 200 600 300"`
    - 轨迹2: `d="M 200 200 Q 400 200 600 100"`
    - 有效区域: `d="M 200 200 Q 400 200 600 100 L 600 300 Q 400 200 200 200 Z"`
  - 状态机设计：定义 `currentStep` 变量（0~3），点击按钮时更新变量并调用 `updateScene()` 函数。
  - 动画过渡：为所有 SVG 元素的 `opacity` 属性添加 CSS `transition: opacity 0.4s ease`，在 `updateScene()` 中通过修改元素的 `style.opacity` 或 `style.display` 实现平滑的显隐切换。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-btn-next`, `scene1-path-traj1`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
