[图示主题与整合说明]
- 本图示主题：金属棒切割磁感线的动态过程与速度分解
- 整合的步骤/概念：将3D空间结构与2D侧视图结合，通过连续拖拽滑块，动态展示金属棒在四分之一圆弧轨道上运动时，其切线速度 $v_0$ 的水平分量 $v_x$ 和竖直分量 $v_y$ 的实时变化。
- 教学价值：帮助学生直观理解金属棒在圆弧轨道上运动时，有效切割磁感线的速度（即水平分速度 $v_x$）随角度 $	heta$ 增大的减小规律，从而深刻理解瞬时感应电动势 $E = BLv_x$ 的变化过程。

[分步序列]
- 初始状态：滑块位于 $	heta = 30^\circ$ 处。3D图中金属棒位于偏下位置，2D图中显示对应的点P及速度分解矩形。此时 $v_x$ 较大，$v_y$ 较小。
- 交互状态（拖动滑块）：
  - 随着 $	heta$ 从 $0^\circ$ 增大到 $90^\circ$：
  - 3D图中金属棒沿轨道从底端平滑移动到顶端。
  - 2D图中点P同步沿圆弧移动。
  - 速度矢量 $v_0$ 方向随之改变，始终保持与圆弧相切。
  - 水平分速度 $v_x$ 的长度逐渐缩短（从100减小到0）。
  - 竖直分速度 $v_y$ 的长度逐渐增加（从0增大到100）。
  - 速度分解矩形实时形变。

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：在 SVG 底部 (x=250, y=460) 放置一个 `<input type="range">`，范围 0 到 90，默认值 30。上方 (x=400, y=440) 放置提示文本“拖动滑块改变金属棒位置 (θ = 30°)”。
- 教师操作流程：教师在讲解时，缓慢拖动滑块，引导学生观察右侧2D图中红色水平箭头（$v_x$）长度的变化，直观得出“随着角度增大，有效切割速度减小”的结论。

[技术实现]
- JS 库选择及原因：使用原生 SVG 配合原生 JavaScript。本场景主要为几何图形和矢量计算，原生 SVG 的 DOM 操作足以实现高性能的平滑动画，无需引入庞大的外部库。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  |---------------------------------------|
  |      3D透视图       |      2D侧视图     |
  |                     |                 |
  |  (轨道、磁场、金属棒) |  (速度分解、角度) |
  |                     |                 |
  |---------------------------------------|
  [控件栏（SVG内底部 y=440~490）]
         拖动滑块改变金属棒位置 (θ = 30°)
         [========O-----------------]
  ```
- 关键实现要点：
  - 坐标计算：在 JS 中定义 `update(theta)` 函数，将角度转为弧度后，利用三角函数实时计算 3D 金属棒两端点 $P_1, P_2$ 的坐标，以及 2D 图中点 $P$ 的坐标。
  - 速度分解：$v_0$ 长度固定为 100，$v_x = 100\cos	heta$，$v_y = 100\sin	heta$。根据这些值动态更新速度矢量 `<path>` 的 `d` 属性。
  - 边界处理：当 $	heta=0^\circ$ 或 $90^\circ$ 时，某些分速度长度为 0，需确保 SVG path 渲染正常（如直线退化为点时不报错）。
  - ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-slider-theta`, `scene1-rod-3d`, `scene1-vector-vx`）。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
