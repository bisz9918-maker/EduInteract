[分步序列]
- 初始状态（步骤0）：显示居中的电路图，电源标签为 $e = E_m \cos	heta$。隐藏其他元素。
- 步骤1（求初始电压）：电源标签更新为 $E_m = BLv_0$。外电阻 $R$ 边框变蓝加粗，右侧出现蓝色括号和 $U_{cd}$ 标签。下方淡入分压公式 $U_{cd} = rac{R}{R+r} E_m = rac{3}{4} BLv_0$。
- 步骤2（求热量）：电路图整体平移至左侧（X坐标-200）。右侧淡入 $e-t$ 坐标系、红色余弦曲线、蓝色 $E_{rms}$ 虚线。下方淡入热量计算公式 $Q_{总} = rac{E_{rms}^2}{R+r} \cdot rac{T}{4}$ 和 $Q_R = rac{3}{4} Q_{总}$。
- 步骤3（求拉力功）：电路图和坐标系整体淡出。居中淡入能量转化流向图（四个方块节点和灰色箭头），展示拉力做功转化为重力势能和焦耳热的全局关系。

[技术实现]
- JS 库选择：原生 SVG（用于绘制图形和动画） + MathJax（用于公式渲染，通过 foreignObject 嵌入 SVG）。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  [控件栏 绝对定位在底部 y=450 处，不占文档流]
  ```
- 关键实现要点：
  - 状态机设计：定义 `currentStep` 变量（0~3），每次点击按钮更新状态并调用 `updateScene()` 函数。
  - 动画实现：电路图的平移使用 `<g id="scene2-circuit-group">` 配合 CSS `transform: translateX(-200px)` 和 `transition: transform 0.8s ease` 实现平滑过渡。元素的显隐使用 `opacity` 配合 `transition: opacity 0.5s ease`。
  - 曲线绘制：余弦曲线使用 JS 循环生成点集，赋值给 `<polyline>` 的 `points` 属性，确保四分之一周期曲线的精确度。
  - 箭头绘制：使用 SVG `<marker>` 定义箭头样式，应用于折线和线段的 `marker-end` 属性。
  - ID 命名规范：所有交互元素 ID 必须以 `scene2-` 为前缀（如 `scene2-circuit-group`, `scene2-btn-next`）。
  - 隔离性：所有 JS 代码必须包裹在 `(function() { ... })()` 中，避免变量污染。
