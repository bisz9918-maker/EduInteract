[图示主题与整合说明]
- 本图示主题：串联电路故障分析（断路与短路排查）
- 整合的步骤/概念：通过动态演示正常电路、L1断路、L2短路、L1短路四种状态下的电流路径、灯泡亮暗及电压表示数变化，帮助学生直观理解电路故障现象。
- 教学价值：教师可利用分步导航，引导学生逐一假设故障情况，观察现象并与题目已知条件（一灯亮、一灯不亮、电压表有示数）进行对比，从而培养逻辑推理和排除法解题能力。

[视觉元素清单]
- 电路导线：黑色实线，#000000，stroke-width: 2
- 电源：长线(460,300)-(460,340)，短粗线(440,310)-(440,330)
- 开关S：闭合状态，实线连接(430,120)与(470,120)

- 电压表V：圆形 r=20，内部文字"V"。包含表盘刻度弧线和动态指针。
- 动态电流：蓝色虚线，#1565c0，stroke-width: 4，stroke-dasharray: 10,10。通过 CSS 动画 `stroke-dashoffset` 实现流动效果。
- 故障短路线：绿色实线，#2e7d32，stroke-width: 4
- 故障断路叉：红色叉号，#c62828，stroke-width: 4
- 标签文本：黑色，#000000，font-size: 16px

[分步序列]
- 初始状态（步骤0）：正常状态。L1、L2 均亮（黄色）。电压表指针指向正中（0度，表示有示数 V/2）。显示主回路电流动画。短路线和断路叉隐藏。
- 步骤1：假设 L1 断路。L1、L2 均灭（灰色）。电压表指针归零（-40度，无示数）。电流动画隐藏。L1 上方显示红色断路叉。
- 步骤2：假设 L2 短路。L2 旁出现绿色短路线。L1 亮（黄色），L2 灭（灰色）。电压表指针归零（-40度，被短路无示数）。电流动画沿 L2 短路线绕行。
- 步骤3：假设 L1 短路。L1 旁出现绿色短路线。L1 灭（灰色），L2 亮（黄色）。电压表指针大幅偏转（+40度，测电源电压）。电流动画沿 L1 短路线绕行。符合题目所有条件。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：在 SVG 内部底部 (y=460) 放置两个按钮，中间放置状态说明文本。
- 教师操作流程：教师点击“下一步”依次展示断路、L2短路、L1短路三种假设情况，引导学生观察灯泡亮暗和电压表示数，与题目条件比对，最终得出正确答案。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。电路图由标准几何图形构成，SVG 易于绘制和控制样式；电流流动效果可通过 SVG 的 `stroke-dasharray` 和 CSS 动画轻松实现。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800x440]
       S
  +----/ ----+
  |          |
  V--L2      L1
  |          |
  +---电池---+
  [控件栏 800x60] (上一步 / 状态文本 / 下一步)
  ```
- 关键实现要点：
  1. 状态机设计：定义 `currentStep` (0-3)，每次切换步骤时调用 `updateScene()` 函数。
  2. 电流动画：预定义三条 `<path>`（正常、L2短路、L1短路），根据当前步骤控制其 `display` 属性。使用 CSS `@keyframes` 改变 `stroke-dashoffset` 实现流动。
  3. 电压表指针：使用 `transform="rotate(angle, 200, 225)"` 控制指针旋转，配合 CSS `transition` 实现平滑偏转动画。
  4. ID 命名规范：所有元素 ID 均以 `scene1-` 开头，如 `scene1-bulb-l1`, `scene1-current-path-normal`。
  5. IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
