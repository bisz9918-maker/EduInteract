[图示主题与整合说明]
- 本图示主题：玻璃管中封闭气体的等温变化及受力分析
- 整合的步骤/概念：整合了图甲（开口向上）、图乙（开口向下）、图丙（塞入活塞）三个状态的转换过程，以及对应的压强受力分析和几何长度推导。
- 教学价值：教师可以通过分步导航，清晰地展示玻璃管旋转、活塞压缩过程中气体状态的变化，引导学生逐步进行受力平衡分析和玻意耳定律的应用。

[分步序列]
- 初始状态（步骤0）：展示图甲（开口向上）。显示玻璃管、水银柱、底部空气柱。右侧显示 L, l1, h 的标注。左侧显示 P0, Ph, P1 箭头，及公式 `P1 = P0 + Ph`。
- 步骤1：点击「下一步」→ 切换至图乙（开口向下）。水银柱下移，上方空气柱变长。右侧更新为 l2, h 的标注。左侧显示 P2, Ph, P0 箭头，及公式 `P2 = P0 - Ph`。
- 步骤2：点击「下一步」→ 在图乙基础上，高亮下端空气柱（透明度加深）。右侧新增 l_下2 的标注。右侧空白处显示公式 `l_下2 = L - l2 - h = 17cm`。
- 步骤3：点击「下一步」→ 切换至图丙。活塞从底部推入，水银柱上移，上方空气柱恢复为 l1。高亮下端被封闭的空气柱。左侧显示 P1, Ph, P_下3 箭头，及公式 `P_下3 = P1 + Ph`。
- 步骤4：点击「下一步」→ 在图丙基础上，右侧展开完整的长度结构标注：l1, h, l_下3, d。右侧空白处显示公式 `L = l1 + h + l_下3 + d` 和 `d = 7cm`。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：在 SVG 底部 (y=460) 居中放置两个按钮，用于切换步骤 0 到 4。
- 教师操作流程：教师首先展示初始状态，讲解受力平衡求 P1；点击下一步展示倒置状态，讲解受力平衡求 P2 并利用等温变化求 P0；继续点击高亮下部空气，讲解其初始状态；点击下一步展示塞入活塞，讲解下部空气的等温压缩；最后点击展示几何关系求出 d。

[技术实现]
- JS 库选择及原因：原生 SVG。图形主要由矩形、折线和箭头组成，SVG 易于实现精确的坐标控制和 DOM 元素的显示/隐藏切换。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  左侧 (0-300): 公式和受力箭头
  中间 (380-420): 玻璃管及内部气液柱
  右侧 (440-800): 长度标注线和几何公式
  底部 (460-490): ◀上一步 / 下一步▶ 按钮
  ```
- 关键实现要点：
  - 使用 `<g>` 标签将不同步骤的元素分组，通过控制 `display` 属性（'none' 或 'block'）来实现步骤切换。
  - 箭头可以使用 `<marker>` 定义，或者直接用 `<path>` 绘制简单的箭头。
  - 虚线对齐线使用 `stroke-dasharray="4 4"`。
  - 状态切换时，可以加入简单的 CSS `transition: opacity 0.3s` 实现淡入淡出效果，提升视觉体验。
  - ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-btn-next`, `scene1-step0-group`）。
  - IIFE 隔离：所有 JS 代码包裹在 `(function() { ... })()` 中。
