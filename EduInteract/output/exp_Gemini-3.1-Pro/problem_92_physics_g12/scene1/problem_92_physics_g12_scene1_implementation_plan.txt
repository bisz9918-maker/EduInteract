[图示主题与整合说明]
- 本图示主题：粒子在偏转电场、无电场区及点电荷电场中的完整运动轨迹与几何关系
- 整合的步骤/概念：类平抛运动、匀速直线运动、匀速圆周运动的轨迹拼接，以及速度偏向角与圆心角的几何推导。
- 教学价值：帮助教师分阶段展示粒子的复杂运动过程。通过精确的轨迹拼接和辅助线，直观揭示速度偏向角与圆心角的相等关系，从而突破 $r = y / \cos	heta$ 的教学难点。

[分步序列]
- 初始状态（步骤0）：显示极板A/B、界面MN/PS、中心线、点电荷O、荧光屏EF及对应标签。粒子位于R点。
- 步骤1（偏转电场）：点击「下一步」→ 粒子沿抛物线运动至M'。显示抛物线轨迹、速度 $v$ 及其分量 $v_x, v_y$、偏转角 $	heta$ (M'处)、偏转位移 $y_1$。
- 步骤2（无电场区）：点击「下一步」→ 粒子沿直线运动至C。显示直线轨迹、竖直位移 $y_2$、总偏转距离 $y$。
- 步骤3（点电荷电场）：点击「下一步」→ 粒子沿圆弧运动至D。显示圆弧轨迹、C点速度 $v$、半径OC、垂直符号、半径标签 $r$。
- 步骤4（几何分析）：点击「下一步」→ 高亮直角三角形OCC'，显示圆心角 $	heta$ (O处)，展示公式 $r = y / \cos	heta$ (绿色文本，位于(420, 280))。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：底部居中放置两个按钮，控制步骤 0-4 的切换。
- 教师操作流程：教师点击“下一步”逐步展示粒子的运动阶段，配合讲解每个阶段的受力与运动学特征；最后一步展示几何关系，推导半径公式。可随时点击“上一步”回退复习。

[技术实现]
- JS 库选择及原因：原生 SVG。SVG 适合精确的几何图形、路径（特别是圆弧 `A` 和贝塞尔曲线 `Q`）以及动画控制，且无需引入外部库。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×440]
  [控件栏 800×60 (y=440~500)，包含 上一步/下一步 按钮]
  ```
- 关键实现要点：
  - 状态机设计：定义 `currentStep` (0-4)，通过 `updateStep()` 函数根据当前步骤控制各 SVG 元素的 `opacity` 或 `display`。
  - 坐标计算：严格按照布局坐标表中的数值硬编码。抛物线使用 `M 50 130 Q 110 130 170 175`，直线使用 `M 170 175 L 350 310`，圆弧使用 `M 350 310 A 225 225 0 0 0 710 130`。这组坐标保证了轨迹在连接点处的一阶导数（斜率）完全连续。
  - 动画：使用 CSS `transition: opacity 0.5s` 实现元素的平滑淡入淡出。
  - ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-btn-next`, `scene1-traj-para`）。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
