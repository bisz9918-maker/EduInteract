    题目原文：
    如图1，已知线段AB=8，点C是AB上的一动点（不包括A、B），在AB同侧作两个等边三角形ACD和BCE，连DE，点P、F分别是DE和BE的中点，连接AF，分别交DC、CE于G、H．
    （1）写出图中所有的相似三角形（除等边三角形ACD和BCE外）；
    （2）当点C在AB中点时，如图2，求CP的长及AG：GH：HF；
    （3）点M、N是线段AB上两点，且AM=BN=2，当点C从点M向点N运动时，求点P所经过的路径长．

    题目分析与整体讲解思路：
    本题是一道经典的几何综合题，融合了等边三角形的性质、平行线的判定、相似三角形的判定与性质以及动点轨迹问题。
    - 第（1）问的核心在于利用等边三角形的 60° 角寻找平行线。通过同位角和内错角相等，可以得出 DC || BE 和 AD || CE，进而找到两对相似三角形。
    - 第（2）问考察特殊位置（中点）下的计算。首先发现 $	riangle DCE$ 也是等边三角形，从而求出高 CP；接着利用第（1）问的相似三角形比例关系，结合线段长度，推导出 AG、GH、HF 的比例。
    - 第（3）问是动点轨迹问题。需要引导学生观察 P 点的运动规律，通过代数坐标法或几何投影法，证明 P 点的高度恒定，且水平位移是 C 点位移的一半，从而求出路径长。

    图示规划说明：
    本题将通过三个图示进行讲解：
    1. 第一个图示用于第（1）问，通过分步高亮角和平行线，引导学生找出相似三角形。
    2. 第二个图示用于第（2）问，展示 C 为中点时的特殊图形，分步推导 CP 的长度和线段比。
    3. 第三个图示用于第（3）问，提供动态拖拽功能，直观展示 C 点运动时 P 点的水平轨迹，辅助讲解轨迹长度的推导。

    2. 观察 $	riangle DCE$，DC = 4，CE = 4，且 $\angle DCE = 180^\circ - 60^\circ - 60^\circ = 60^\circ$，所以 $	riangle DCE$ 也是等边三角形。
    3. 因为 P 是 DE 的中点，所以 CP 是等边 $	riangle DCE$ 的高，计算得出 $CP = 4 	imes rac{\sqrt{3}}{2} = 2\sqrt{3}$。
    4. **求 AG:GH:HF**：利用图 1 中的相似关系 $	riangle ACG \sim 	riangle ABF$，相似比为 AC:AB = 4:8 = 1:2。
    5. 由此得出 AG = GF（即 AG = $rac{1}{2}$AF），且 CG = $rac{1}{2}$BF。因为 F 是 BE 中点，BE=4，所以 BF=2，CG=1。
    6. 进而求出 DG = DC - CG = 4 - 1 = 3。
    7. 利用第二对相似关系 $	riangle ADG \sim 	riangle CHG$，相似比为 AD:CH = DG:CG = 3:1。
    8. 由此得出 AG:GH = 3:1，即 GH = $rac{1}{3}$AG。
    9. 最后计算 HF = GF - GH = AG - $rac{1}{3}$AG = $rac{2}{3}$AG。
    10. 综合得出 AG:GH:HF = 1 : $rac{1}{3}$ : $rac{2}{3}$ = 3:1:2。

    教学说明：
    本图示用于讲解第（3）问，通过动态演示化抽象为直观，帮助学生理解 P 点的运动轨迹。

    讲解要点与推导步骤：
    1. **观察轨迹**：教师拖动滑块，让学生直观看到 P 点的轨迹是一条水平线段。
    2. **证明高度不变**：设 A 为原点，AB 所在直线为 x 轴。
    3. D 点的纵坐标为 $y_D = AC \cdot rac{\sqrt{3}}{2}$，E 点的纵坐标为 $y_E = CB \cdot rac{\sqrt{3}}{2}$。
    4. 因为 P 是 DE 的中点，所以 P 点的纵坐标 $y_P = rac{y_D + y_E}{2} = rac{(AC + CB)\sqrt{3}}{4} = rac{8\sqrt{3}}{4} = 2\sqrt{3}$。
    5. 这说明 P 点的高度是一个常数，因此其轨迹平行于 AB。
    6. **计算路径长**：P 点的横坐标 $x_P = rac{x_D + x_E}{2} = rac{rac{AC}{2} + (AC + rac{CB}{2})}{2} = rac{AC}{2} + 2$。
    7. 当 C 点从 M 运动到 N 时，AC 的长度从 2 增加到 6，变化量为 4。
    8. 因此，$x_P$ 的变化量为 $rac{4}{2} = 2$，即点 P 所经过的路径长为 2。
