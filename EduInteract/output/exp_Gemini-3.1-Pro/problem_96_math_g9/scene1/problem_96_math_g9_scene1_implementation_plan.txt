[视觉元素清单]
- 2D正方体展开图：外轮廓为实线（#000000, 2px），内部折痕为虚线（#888888, 2px, stroke-dasharray="5,5"）。
- 阴影填充：使用 SVG `<pattern>` 实现斜线纹理（#000000, 30%透明度）。
- 圆圈：黑色实线，无填充，线宽 2px。
- 文本标签：字体颜色 #1565c0，加粗，字号 16px（结论文本 18px）。
- 步骤高亮框：#1565c0，填充透明度 10%，边框 2px 实线。
- 最终高亮面：#1565c0，填充透明度 20%。

[分步序列]
- 初始状态（步骤0）：仅显示纯净的2D正方体展开图（含阴影和圆圈），无任何标签和高亮。
- 步骤1：点击「下一步」→ 显示中间四个正方形的高亮框（x:235, y:205, w:330, h:90），并在左上方 (280, 170) 淡入标签“侧面展开”。
- 步骤2：点击「下一步」→ 在中间四个正方形内依次淡入显示标签“左(1)”、“前(2)”、“右(3)”、“后(4)”。
- 步骤3：点击「下一步」→ 显示上下两个正方形的高亮框（顶：x:395, y:125, w:90, h:90；底：x:315, y:285, w:90, h:90），并淡入标签“顶”和“底”。
- 步骤4：点击「下一步」→ 隐藏之前的高亮框。使用蓝色（#1565c0, 20%透明度）高亮“左(1)”(Sq1) 和“后(4)”(Sq4) 两个面。在底部 (400, 420) 淡入结论文本：“折叠后，左(1)与后(4)在空间中相邻”。

[标签冲突检查]
- "左(1)" (290,240) vs 阴影1：阴影在左下，标签在右上空白处，无冲突。
- "后(4)" (510,240) vs 阴影2：阴影在右下，标签在左上空白处，无冲突。
- "顶" (440,145) vs 圆圈 (440,170, r=15)：标签在圆圈上方，间距 10px，无冲突。
- "侧面展开" (280,170) vs 展开图：位于 Sq1 上方的空白区域，远离 SqTop，无冲突。
- 各个面中心标签之间间距 80px，无冲突。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：底部居中放置两个按钮，用于控制步骤的前进与后退。
- 教师操作流程：教师点击“下一步”逐步引导学生观察展开图的不同部分，先定义侧面，再定义顶底，最后得出特定面的相邻关系结论。可随时点击“上一步”回退。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。SVG 非常适合绘制精确的几何图形、斜线纹理填充（pattern）以及实现简单的透明度动画。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
    (侧面展开)    [顶]
  [左1][前2][右3][后4]
            [底]
  [结论文本]
  [控件栏（上一步/下一步）]
  ```
- 关键实现要点：
  - 使用 SVG `<pattern>` 定义斜线阴影纹理。
  - 使用 `<path>` 或 `<polygon>` 绘制外轮廓和阴影三角形，使用 `<line>` 绘制内部虚线折痕。
  - 状态机设计：定义 `currentStep` 变量（0-4），通过 `updateStep()` 函数根据当前步骤控制各个 SVG 元素（高亮框、标签、高亮面）的 `opacity` 属性，配合 CSS `transition` 实现平滑过渡。
  - ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-btn-next`, `scene1-label-left`）。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
