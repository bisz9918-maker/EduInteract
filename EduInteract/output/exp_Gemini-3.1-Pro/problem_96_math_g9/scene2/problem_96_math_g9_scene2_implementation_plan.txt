[图示主题与整合说明]
- 本图示主题：阴影面的空间拼接特征
- 整合的步骤/概念：展示从2D展开图折叠成3D正方体的连续过程，通过滑块控制折叠进度，特写两个阴影面的拼接细节。
- 教学价值：教师可以通过拖动滑块，让学生直观地观察到二维平面图形如何通过折叠转化为三维立体图形，特别是面上图案（阴影三角形）在空间中的相对位置变化和最终的拼接效果，有效帮助学生建立空间映射和立体几何思维。

[视觉元素清单]
- 3D正方体面（6个）：
  - 面2（前面）：空白，固定在中心。
  - 面1（左面）：带左下阴影三角形纹理（从左上到右下的对角线）。
  - 面3（右面）：空白。
  - 面4（后面）：带右下阴影三角形纹理（从左下到右上的对角线），作为面3的子元素。
  - 面5（上面）：带中心圆圈纹理。
  - 面6（下面）：空白。
- 阴影纹理：使用 Canvas 动态生成，黑色斜线，30%透明度（rgba(0,0,0,0.3)）。
- 边框线：每个面带有 2px 的黑色轮廓线（#000000）。
- 公共棱高亮：红色圆柱体（#c62828），半径 0.05（相对边长 2），仅在折叠完成时显示。
- 标签：黑色文字，白色半透明背景，圆角，仅在折叠完成时显示。

[分步序列]
- 初始状态（0%）：滑块在最左侧。显示完全平铺的2D展开图。摄像机正对 XY 平面（俯视展开图）。
- 折叠过程（1%-99%）：拖动滑块。
  - 面1、3、5、6 围绕各自与面2的交线旋转。
  - 面4 围绕与面3的交线旋转。
  - 摄像机位置和观察目标平滑插值，从正视 2D 展开图过渡到侧视 3D 正方体的“左后”视角。
- 最终状态（100%）：滑块在最右侧。
  - 正方体完全闭合。
  - 摄像机停留在最佳视角（能清晰看到左面和后面的交线）。
  - 红色高亮线出现，精确覆盖在“左后”公共棱上。
  - “左侧面”、“后侧面”、“公共拼接棱”三个标签淡入显示，指示对应位置。

[标签冲突检查]
- 标签"左侧面"：投影自面1中心，附加向左上偏移。
- 标签"后侧面"：投影自面4中心，附加向右上偏移。
- 标签"公共拼接棱"：投影自左后棱中点，附加向左下偏移。
- 冲突分析：在最终的 3D 视角中，面1中心在左侧，面4中心在右侧，公共棱在中间偏前。三个投影点本身在屏幕上就有至少 50px 的间距。通过分别向左上、右上、左下三个不同方向添加 margin 偏移，进一步拉开了距离，确保任意两个标签之间的间距 ≥ 30px，绝对不会发生重叠。

[交互方案]
- 交互类型：拖拽滑块
- 控件说明：
  - 折叠进度滑块（`scene2-slider`）：位于底部，范围 0-100。
- 教师操作流程：教师在讲解时，缓慢向右拖动滑块，引导学生观察面1和面4是如何在空间中逐渐靠近的。当滑块拖到 100% 时，重点指出两条阴影边完美重合，形成公共拼接棱，并结合高亮线和标签进行总结。

[技术实现]
- JS 库选择及原因：使用 Three.js (CDN 引入) 处理 3D 几何体的折叠动画和摄像机视角的平滑过渡，这是实现 2D 到 3D 连续映射的最佳选择。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  +------------------------------------------------+
  |                                                |
  |                                                |
  |                  [3D 渲染区]                   |
  |           (正方体及动态投影的 HTML 标签)       |
  |                                                |
  |                                                |
  |                                                |
  |        [======O----------------------]         |
  |                  (折叠滑块)                    |
  +------------------------------------------------+
  ```
- 关键实现要点：
  - **层级结构**：构建合理的 3D Object3D 层级。Front 面为根，Left/Right/Top/Bottom 为子节点，Back 面为 Right 面的子节点。这样只需简单旋转局部坐标系的轴即可实现正确的折叠。
  - **纹理生成**：使用离屏 Canvas 绘制阴影斜线和圆圈，转换为 `THREE.CanvasTexture` 应用到材质上，避免外部图片加载问题。
  - **摄像机动画**：在 `slider.oninput` 事件中，根据进度值 `t` (0~1)，使用 `Vector3.lerp` 在初始摄像机位置（正视）和目标摄像机位置（侧视）之间插值，同时插值 `controls.target`，实现视角的平滑跟随。
  - **2D 标签投影**：在 `requestAnimationFrame` 渲染循环中，使用 `vector.project(camera)` 将 3D 坐标转换为屏幕 2D 坐标，更新 HTML 标签的 `left` 和 `top` 样式。
- ID 命名规范：滑块 `scene2-slider`，标签容器 `scene2-labels`，标签项 `scene2-label-left` 等。
- IIFE 隔离：所有逻辑封装在 `(function() { ... })()` 中。
