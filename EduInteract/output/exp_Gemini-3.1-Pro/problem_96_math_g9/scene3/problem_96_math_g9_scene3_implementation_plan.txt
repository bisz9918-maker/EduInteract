[图示主题与整合说明]
- 本图示主题：选项验证与3D旋转对比
- 整合的步骤/概念：通过 3D 正方体的平滑旋转，直观展示不同视角下的图案特征。逐一验证四个选项，通过对比正面、顶面、右侧面的图案方向和组合，排除错误选项，最终确认正确选项。
- 教学价值：帮助学生建立空间想象力，理解 2D 展开图与 3D 立体图形之间的映射关系，掌握通过特征面（如圆圈面、特定方向的阴影面）的相对位置来排除错误选项的解题技巧。

[视觉元素清单]
- 3D正方体：使用 Three.js 渲染，尺寸 100×100×100。各面贴图通过 Canvas 动态生成，确保旋转后与大纲逻辑完美契合。
- 选项参考图：使用 SVG 绘制的 2D 等距视角正方体，精确还原 A、B、C、D 四个选项的图案特征。
- 判定图标：SVG 绘制的粗线条 ❌（#c62828）和 ✅（#2e7d32），初始透明度为 0。
- 标签文本：选项A、选项B、选项C、选项D，字体大小 16px，颜色 #333333。

[分步序列]
- 初始状态（步骤0）：3D 正方体处于初始姿态（欧拉角 0,0,0），展示正面（空白）、顶面（圆圈）、右侧面（空白）。右侧显示四个选项的缩略图，无判定图标。
- 步骤1（排除A和B）：点击「下一步」，3D 正方体绕 Y 轴旋转 180°。展示正面（阴影）和右面（阴影），指出顶面是圆圈（排除B的空白顶面），且正面阴影方向与A不同（排除A）。选项 A、B 上浮现红色 ❌。
- 步骤2（排除C）：点击「下一步」，3D 正方体平滑旋转至正面为圆圈、右面为阴影的姿态（欧拉角 x=PI/2, y=0, z=-PI/2）。指出此时右侧面的阴影方向与选项C不符。选项 C 上浮现红色 ❌。
- 步骤3（验证D）：点击「下一步」，3D 正方体平滑旋转至最终姿态（欧拉角 x=-PI/2, y=PI/2, z=0），即原后侧面转至顶面，原左侧面转至正面。定格画面与选项D的图案完美重合。选项 D 上浮现绿色 ✅。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：底部居中放置两个按钮。点击触发状态机切换，驱动 Three.js 摄像机/物体旋转动画及 SVG 图标的淡入淡出。
- 教师操作流程：教师首先引导学生观察初始正方体和四个选项；点击“下一步”演示排除 A 和 B 的逻辑；再次点击演示排除 C 的逻辑；最后点击验证 D 是唯一完美重合的正确选项。可随时点击“上一步”回退重播动画。

[技术实现]
- JS 库选择：Three.js（用于 3D 正方体渲染和旋转）、GSAP（用于平滑的 3D 旋转动画和 UI 淡入淡出）。
- 画布尺寸：800 × 500 px。左侧 400×450 为 Three.js 容器，右侧 400×450 为 SVG 容器。
- 布局草图：
  ```
  [ Three.js 3D展示区 ] [ 选项A ] [ 选项B ]
  [    (400x450)    ] [ 选项C ] [ 选项D ]
  [ ◀ 上一步           下一步 ▶ ]
  ```
- 关键实现要点：
  1. 贴图生成：使用 Canvas 2D API 动态生成 6 个面的贴图（CanvasTexture）。为了使步骤3的旋转结果与选项D完美重合，左侧面贴图设为“左下到右上，右下阴影”，后侧面贴图设为“左上到右下，左下阴影”，顶面为圆圈，其余为空白。
  2. 3D 旋转动画：使用 `gsap.to(cube.rotation, {x: targetX, y: targetY, z: targetZ, duration: 1.5, ease: "power2.inOut"})` 实现平滑过渡。
  3. SVG 等距视角绘制：利用多边形 `<polygon>` 精确计算等距视角下的顶点坐标（如 dx=39, dy=22.5），绘制选项的 2D 简图，避免引入外部图片，确保高清和样式统一。
  4. 状态机：维护 `currentState` (0~3)，每次按钮点击更新状态，并集中调用一个 `renderState()` 函数同步 3D 姿态和 2D UI 状态。
- ID 命名规范：所有 DOM 元素 ID 以 `scene3-` 为前缀（如 `scene3-container`, `scene3-next-btn`）。
- IIFE 隔离：所有逻辑封装在 `(function() { ... })()` 中，防止变量污染。
