[图示主题与整合说明]
- 本图示主题：利用圆周角定理和直角三角形性质求解线段长度
- 整合的步骤/概念：等腰三角形底角计算、同弧所对圆周角相等、直径所对圆周角为直角、含30°角的直角三角形性质
- 教学价值：教师可通过分步导航，引导学生一步步完成从已知条件到最终结果的几何推理过程，视觉上的高亮和颜色变化能有效强化“同弧所对圆周角”和“直角三角形”等关键几何关系。

[视觉元素清单]
- 基础图形：圆O，线段AB, BC, CA, AD, BD, CD（黑色 #000000，线宽2px）
- 基础标注：点A, B, C, D, O及对应字母标签，长度标签"6"，角度标签"120°"，AB和BC上的等距短划线标记
- 交互图形（按步骤显示/变色）：
  - △ABC 填充多边形：蓝高亮 #1565c0，透明度20%
  - ∠ACB 弧线及文字"30°"：初始隐藏，步骤1为蓝高亮 #1565c0，步骤2变为红高亮 #c62828
  - 弧AB：初始为普通黑线，步骤2叠加红高亮 #c62828（加粗，线宽4px，fill none）
  - ∠ADB 弧线及文字"30°"：红高亮 #c62828
  - 直径AD：初始为普通黑线，步骤3叠加绿高亮 #2e7d32（加粗，线宽4px）
  - ∠ABD 直角符号：绿高亮 #2e7d32（线宽2px，fill none）
  - Rt△ABD 填充多边形：黄高亮 #f9a825，透明度20%
  - 结论文字 "AB = 3"：红高亮 #c62828，粗体

[分步序列]
- 初始状态（步骤0）：显示所有基础图形、点、字母标签、等距标记、∠ABC的120°标注、AD的长度"6"标注。隐藏所有高亮和推导结论。
- 步骤1：点击「下一步」→ 高亮△ABC（蓝色半透明填充），显示∠ACB的弧线和"30°"（蓝色）。
- 步骤2：点击「下一步」→ 高亮弧AB（红色加粗），∠ACB的弧线和文字变为红色，同时显示∠ADB的弧线和"30°"（红色）。
- 步骤3：点击「下一步」→ 高亮直径AD（绿色加粗），显示∠ABD的直角符号（绿色）。
- 步骤4：点击「下一步」→ 高亮Rt△ABD（黄色半透明填充），在AB线段左下方显示结论文字 "AB = 3"（红色粗体）。

[交互方案]
- 交互类型：分步按钮导航（◀ 上一步 / 下一步 ▶）
- 控件说明：在SVG内部底部（y=460区域）居中放置两个按钮，用于控制步骤（0-4）的切换。
- 教师操作流程：教师首先展示题目初始条件（步骤0），然后点击“下一步”依次讲解等腰三角形底角（步骤1）、同弧所对圆周角（步骤2）、直径所对圆周角（步骤3），最后在直角三角形中计算出AB长度（步骤4）。可随时点击“上一步”回退。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。图形均为标准几何图形（圆、线段、多边形、路径），原生 SVG 能够提供最精确的坐标控制和最佳的渲染性能。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×450]
      (圆O及内部几何图形居中)
  [控件栏 800×50]
      [◀ 上一步] [下一步 ▶]
  ```
- 关键实现要点：
  - 使用 `<path>` 绘制圆弧（如弧AB、角度弧线），利用 `A` 指令精确控制半径和起止点。
  - 使用 CSS `transition` 实现颜色和透明度的平滑过渡（如∠ACB从蓝变红，填充区域的淡入淡出）。
  - 状态机设计：维护一个 `currentStep` 变量（0-4），每次点击按钮更新该变量，并调用 `updateScene()` 函数。该函数根据当前步骤为各个 SVG 元素添加/移除特定的 CSS class（如 `.visible`, `.highlight-red` 等）来控制显隐和样式。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-polygon-abc`, `scene1-btn-next`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
