题目原文：
如图，D是等边△ABC边AB上的一点，且AD=1，BD=2，现将△ABC折叠，使点C与D重合，折痕EF，点E、F分别在AC和BC上，若BF=1.25，则CE=（ ）
A．7/5 B．2/3 C．5/6 D．1/2

题目分析与整体讲解思路：
本题是一道经典的几何折叠与相似三角形结合的综合题。
讲解思路分为三个阶段：

  1. 利用基本图形和折叠性质转化条件：首先根据等边三角形的性质得出边长为3。然后利用折叠的轴对称性质，明确△CEF≌△DEF，从而得到线段相等（CE=DE, CF=DF）和角度相等（∠EDF=∠C=60°）。
  2. 通过角度转换发现相似三角形：这是解题的核心突破口。利用平角定义（∠ADE+∠EDF+∠BDF=180°）和三角形内角和定理（∠B+∠BFD+∠BDF=180°），结合∠EDF=∠B=60°，通过等量代换推导出∠ADE=∠BFD。
  3. 利用相似三角形对应边成比例求解：得出△ADE∽△BFD后，利用已知边长建立比例关系（AD/BF = DE/DF 或 AE/BD = AD/BF），设CE=x，代入即可解出x的值。

图示规划说明：
为了保持几何图形的连贯性，避免视觉焦点频繁切换，我们将整个推导过程整合在一个交互式图示中。通过“分步按钮导航”，教师可以从初始条件出发，逐步演示折叠动画，依次高亮边长关系、角度转换过程，最后展示相似三角形并得出结论。

已知条件：
等边 $ riangle ABC$ 中，
$AD = 1$
$BD = 2$
$BF = rac{5}{4}$
求 $CE$ 的长度。
步骤 1：折叠性质
将 $ riangle CEF$ 沿 $EF$ 折叠，点 $C$ 与点 $D$ 重合。
根据折叠全等性质：
$ riangle CEF \cong riangle DEF$
$\angle EDF = \angle C = 60^\circ$
步骤 2：边长代换
设 $CE = x$，则 $DE = x$。
等边三角形边长 $AB = AD + BD = 3$。
$AE = AC - CE = 3 - x$
$CF = BC - BF = 3 - rac{5}{4} = rac{7}{4}$
$DF = CF = rac{7}{4}$
步骤 3：角度转换
在平角 $\angle ADB$ 中：
$\angle ADE + \angle BDF = 180^\circ - \angle EDF = 120^\circ$
在 $ riangle ADE$ 中：
$\angle ADE + \angle AED = 180^\circ - \angle A = 120^\circ$
因此，$\angle AED = \angle BDF$。
步骤 4：相似求解
由于 $\angle A = \angle B = 60^\circ$，且 $\angle AED = \angle BDF$，
所以 $ riangle ADE \sim riangle BFD$。
对应边成比例：
$ rac{AE}{BD} = rac{DE}{FD}$
$ rac{3-x}{2} = rac{x}{7/4}$
解得：$x = rac{7}{5}$

教学总结与课堂讲解建议：

  1. 引入阶段：
  • 引导学生观察图形，明确已知条件。
  • 提问：等边三角形的边长是多少？（由AD=1, BD=2得到AB=3，进而AC=BC=3）。
  1. 折叠分析：
  • 强调“折叠即全等”。
  • 引导学生列出折叠前后的对应相等关系：边（CE=DE, CF=DF）和角（∠C=∠EDF=60°）。
  • 顺势完成已知线段的转化：由BF=5/4求出CF=7/4，即DF=7/4。将未知的CE设为x，则DE=x，AE=3-x。
  1. 突破核心难点（角度转换）：
  • 提示学生关注点D处的平角。∠ADE + ∠EDF + ∠BDF = 180°，已知∠EDF=60°，所以∠ADE + ∠BDF = 120°。
  • 再看△BDF，内角和180°，已知∠B=60°，所以∠BFD + ∠BDF = 120°。
  • 引导学生发现“同角的补角相等”（或等量代换），得出关键结论：∠ADE = ∠BFD。
  1. 得出结论：
  • 结合∠A = ∠B = 60°，证明 △ADE ∽ △BFD。
  • 列出相似三角形对应边成比例的等式：AD / BF = DE / DF。
  • 代入数据：1 / (5/4) = x / (7/4)。
  • 解方程得出 x = 7/5，即 CE = 7/5，选择A。
