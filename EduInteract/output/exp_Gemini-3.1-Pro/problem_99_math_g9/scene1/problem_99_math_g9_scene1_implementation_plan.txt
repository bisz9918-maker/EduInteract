[图示主题与整合说明]
- 本图示主题：折叠性质与相似三角形综合推导
- 整合的步骤/概念：等边三角形边长计算、折叠全等性质动画、角度转换证明相似、比例求解
- 教学价值：本图示通过动态折叠演示和分步高亮，帮助教师引导学生将复杂的几何综合题拆解为直观的步骤。从折叠前后的全等关系，到平角中的角度代换，再到相似三角形的比例计算，逻辑链条清晰，极大地降低了学生的认知负荷。

[视觉元素清单]
- 基础图形：
  - `scene1-tri-abc-base`：多边形 ABFEA，黑色实线，无填充。
  - `scene1-tri-cef-dashed`：多边形 CEFC，#888888 虚线，无填充。
  - `scene1-line-ef`：线段 EF，黑色实线。
- 动画折叠图形：
  - `scene1-moving-triangle`：多边形，初始顶点为 C,E,F，填充 #ffffff，边框 #000000。折叠后顶点变为 D,E,F，填充变为 #e3f2fd，边框变为 #1565c0。
- 角度标记：
  - 绿色高亮 (#2e7d32)：∠A, ∠B, ∠C, ∠EDF 的圆弧及 60° 文本。
  - 红色高亮 (#c62828)：∠ADE, ∠BFD 的圆弧。
- 相似三角形高亮：
  - `scene1-tri-ade-highlight`：多边形 ADE，红色填充 (#c62828)，透明度 20%，初始隐藏。
  - `scene1-tri-bfd-highlight`：多边形 BFD，红色填充 (#c62828)，透明度 20%，初始隐藏。
- 文本面板：右侧 HTML div，包含 5 个子 div 对应 5 个步骤的推导过程。

[分步序列]
- 初始状态（步骤0）：
  - 显示基础图形、折痕 EF。
  - `scene1-moving-triangle` 位于 C,E,F 位置，遮挡虚线。
  - 显示已知条件标签：AD=1, BD=2, BF=5/4。
  - 右侧文本面板显示已知条件。
- 步骤1（折叠性质）：
  - 动画：`scene1-moving-triangle` 的顶点 C 平滑移动到 D 点（耗时约 0.8 秒）。
  - 样式变化：移动完成后，边框变为蓝色 (#1565c0)，填充变为浅蓝 (#e3f2fd)。
  - 显现元素：∠C 和 ∠EDF 的绿色 60° 标记。
  - 右侧文本面板更新为折叠性质推导。
- 步骤2（边长代换）：
  - 显现元素：边长标签 CE=x, DE=x, AE=3-x, CF=7/4, DF=7/4。
  - 右侧文本面板更新为边长计算过程。
- 步骤3（角度转换）：
  - 显现元素：∠ADE 和 ∠BFD 的红色圆弧标记。
  - 右侧文本面板更新为角度转换逻辑（平角 180° 减去 60°）。
- 步骤4（相似求解）：
  - 显现元素：△ADE 和 △BFD 的红色半透明填充高亮。
  - 右侧文本面板更新为相似三角形比例式及最终结果 x=7/5。

[交互方案]
- 交互类型：分步按钮导航。
- 控件说明：底部居中放置两个按钮「◀ 上一步」和「下一步 ▶」。

[技术实现]
- JS 库选择：原生 SVG + 原生 JS。无需外部库，保证加载速度和稳定性。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  +-------------------------------------------------+
  |  [SVG 图示区 550x450]      [HTML 文本区 230x350] |
  |         C                  已知条件：            |
  |        / \                 ...                   |
  |       E---F                                     |
  |      / \ / \                                    |
  |     A---D---B                                   |
  |                                                 |
  |  [HTML 控件区 800x40 底部居中: ◀ 上一步 | 下一步 ▶] |
  +-------------------------------------------------+
  ```
- 关键实现要点：
  - 状态机：使用 `currentStep` 变量记录当前步骤 (0-4)，通过 `updateState()` 函数统一管理各元素的 `display`、`opacity` 和文本面板的切换。
  - 动画实现：使用 `requestAnimationFrame` 实现 C 点到 D 点的平滑插值动画。插值变量 `progress` 从 0 到 1，动态更新 `scene1-moving-triangle` 的 `points` 属性。
  - 样式隔离：所有 CSS 类和 DOM ID 均以 `scene1-` 开头。
  - 脚本封装：所有 JS 代码包裹在 `(function() { ... })()` 中，避免全局变量污染。
