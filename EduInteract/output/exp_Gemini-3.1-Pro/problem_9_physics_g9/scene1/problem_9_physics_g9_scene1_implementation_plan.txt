[图示主题与整合说明]
- 本图示主题：开关状态变化引起的动态电路分析与功率比较
- 整合的步骤/概念：通过分步交互，展示不同开关组合下的电路拓扑结构（单灯、串联、并联），并结合电阻和功率公式，直观对比灯泡的实际功率与亮度。
- 教学价值：帮助学生克服“动态电路路径追踪”的难点，将抽象的电路图转化为直观的电流路径高亮，同时将计算结果与视觉亮度（光晕大小/透明度）绑定，建立“开关状态→电路结构→电学计算→物理现象”的完整认知链条。

[分步序列]
- 初始状态（步骤0）：
  - 视觉：S2 断开（刀片指向(320,70)），S1 断开（刀片指向(415,300)）。全电路黑色实线。无光晕。
  - 面板：显示题目初始条件，计算并显示两灯电阻：$R_1=6\Omega$, $R_2=3\Omega$。
- 步骤1（分析选项A）：
  - 视觉：S2 断开，S1 接 b（刀片连至(380,300)）。
  - 高亮路径：电源正极(左)→(150,380)→(150,220)→L1→(300,220)→(300,300)→b→S1→电源负极。
  - 置灰路径：S2支路、L2支路、a触点支路。
  - 光晕：L1 亮起（r=30, opacity=0.4），L2 无光晕。
  - 面板：说明单灯电路，计算 $P_1 = 1.5W < 6W$，结论：L1不能正常发光，A错。
- 步骤2（分析选项B和C）：
  - 视觉：S2 断开，S1 接 a（刀片连至(450,300)）。
  - 高亮路径：电源正极→(150,380)→(150,220)→L1→(300,220)→L2→(450,220)→a→S1→电源负极。
  - 置灰路径：S2支路、b触点支路。
  - 光晕：L1 亮起（r=25, opacity=0.3），L2 微亮（r=22, opacity=0.15）。
  - 面板：说明串联电路，计算 $P_1 \approx 0.67W$, $P_2 \approx 0.33W$，结论：$P_1 > P_2$，L1更亮，B、C错。
- 步骤3（分析选项D）：
  - 视觉：S2 闭合（刀片水平连至(340,100)），S1 接 b。
  - 高亮路径：干路及两条并联支路（L1支路向右，L2支路向左汇聚于节点M）。
  - 置灰路径：a触点支路。
  - 光晕：L1 亮起（r=30, opacity=0.4），L2 极亮（r=35, opacity=0.8）。
  - 面板：说明并联电路，计算 $P_1 = 1.5W$, $P_2 = 3W$，结论：$P_2 > P_1$，L2更亮，D对。

[交互方案]
- 交互类型：分步按钮导航（◀ 上一步 / 下一步 ▶）
- 控件说明：底部居中放置两个按钮，控制 currentStep (0~3) 的切换。
- 教师操作流程：教师首先展示初始电路和电阻计算（步0）；点击下一步，动态切换开关状态，引导学生观察电流路径的高亮变化，识别电路拓扑（单灯/串联/并联），并结合右侧面板的计算结果，解释灯泡亮度的变化原因，逐一排除或确认选项。

[技术实现]
- JS 库选择：原生 SVG（绘制电路图和光晕） + MathJax（渲染右侧面板的物理公式）。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [------------------------------------------------]
  [  (150,100)----S2----(450,100)                  ]
  [      |                  |       [ 解析面板 ]   ]
  [      +---L1---+---L2----+       [ 520x80   ]   ]
  [      |        |         |       [          ]   ]
  [      |        b         a       [          ]   ]
  [      |         \       /        [          ]   ]
  [  (150,380)---电池-------S1(450,360)            ]
  [------------------------------------------------]
  [             ◀ 上一步   下一步 ▶                ]
  ```
- 关键实现要点：
  - 状态机：定义一个包含 4 个状态对象的数组，每个对象存储 S1/S2 的路径 `d` 属性、各段导线的 class（高亮/置灰/默认）、光晕的 `r` 和 `opacity`，以及右侧面板的 HTML 内容。
  - 导线分段：为了实现精准的高亮和置灰，必须将电路导线拆分为独立的 `<path>` 或 `<line>` 元素（如：干路左、干路右、L1支路、L2支路、S2支路、a支路、b支路），并赋予独立的 ID。
  - 动画过渡：为 SVG 的 `stroke`、`stroke-dasharray`、`opacity`、`d` 属性添加 CSS `transition: all 0.5s ease`，使开关切换和电流路径变化平滑自然。
  - ID 命名规范：所有元素 ID 必须以 `scene1-` 开头（如 `scene1-wire-l1`, `scene1-bulb-glow1`）。
  - IIFE 隔离：所有逻辑代码封装在 `(function() { ... })()` 中。
  - MathJax 渲染：每次更新右侧面板的 innerHTML 后，调用 `MathJax.typesetPromise([document.getElementById('scene1-panel')])` 重新渲染公式。
