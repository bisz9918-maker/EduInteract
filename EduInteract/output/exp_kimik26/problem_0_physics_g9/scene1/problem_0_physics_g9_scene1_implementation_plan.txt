[图示主题与整合说明]
- 本图示主题：杠杆动态平衡过程分析（初中物理·杠杆平衡条件应用）
- 整合的步骤/概念：初始平衡状态 → 力臂大小关系推导 → 两人同步向支点移动过程 → 移动后的力矩公式比较 → 最终倾斜结论
- 教学价值：教师通过分步导航控制讲解节奏，引导学生从直观观察（谁离支点近）过渡到抽象推理（力矩代数比较），完成认知跃迁。图示将题目静态图扩展为可交互的动态推导过程，特别适合课堂投影逐步展开。

[分步序列]
- 步骤0「初始平衡」（状态 1/5）：
  • 显示杠杆水平、支点、大人(脚x=180)、小孩(脚x=520)
  • 显示 G大箭头+标签(140,195)、G小箭头+标签(550,210)
  • 显示初始力臂线：L大(180~320,290) 蓝色、L小(320~520,290) 红色，标签 L大(250,305)、L小(420,305)

  • 右栏显示四个选项（灰色背景，无高亮）
  • 底部按钮可用：上一步（禁用灰显）、下一步（可用）

- 步骤1「力臂关系」（状态 2/5）：
  • 保留步骤0所有视觉元素（杠杆、人物、箭头、力臂线、选项区）
  • 左栏公式更新为三行：
    - 行1 (215,345)："∵ G大 > G小"（G大蓝、G小红）
    - 行2 (215,375)："∴ L大 < L小"（L大蓝、L小红）
    - 行3 (215,405)："大人离支点更近"（绿色 #2e7d32）
  • 视觉强调：将 L大 线段加粗至 3px，或给大人/支点间区域加 10% 蓝色半透明遮罩，强化"更近"印象

- 步骤2「同步移动」（状态 3/5）：
  • 动画：大人和小孩同时向支点平移 60px（持续 800ms，ease-in-out）
    - 大人脚从 (180,240) → (240,240)；小孩脚从 (520,240) → (460,240)
    - 人物所有子元素（头、身、臂、腿）同步平移；重力箭头同步平移
  • 动画期间显示：
    - 移动轨迹虚线（大人：180~240,y=265；小孩：460~520,y=265）
    - 移动方向箭头（大人头顶 y=175 向右；小孩头顶 y=190 向左）
    - s 标注：(210,260) 与 (490,260)
    - v 标注：(400,165) "v"
  • 力臂线同步更新：L大线变为 (240~320,290)，L小线变为 (320~460,290)；标签位置不变（仍居中于各自线段）
  • 左栏文本 (215,360)："两人同时以速度 v 向支点移动距离 s"
  • 选项区保持显示，无高亮

- 步骤3「力矩比较」（状态 4/5）：
  • 人物停留在移动后位置（大人 x=240，小孩 x=460）
  • 保留更新后的力臂线、G大/G小箭头
  • 隐藏移动轨迹、方向箭头、s、v 标注
  • 左栏公式区显示四行推导：
    - 行1 (215,345)："M大' = G大(L大 − s)" 蓝色
    - 行2 (215,375)："M小' = G小(L小 − s)" 红色
    - 行3 (215,405)："M大' − M小' = (G小 − G大)·s < 0" 黑色（关键推导式）

    - 人物组整体平移至新脚底坐标，保持竖直不旋转

[交互方案]
- 交互类型：分步按钮导航（◀ 上一步 / 下一步 ▶）
- 控件说明：
  1. 「◀ 上一步」按钮：位于 (280,455)-(380,485)，步骤0 时禁用（opacity 0.4，pointer-events none），其他步骤可点击，回退到上一状态
  2. 「下一步 ▶」按钮：位于 (420,455)-(520,485)，步骤4 时禁用或变为「完成」，其他步骤可点击，前进到下一状态
  3. 步骤指示器：位于 (400,445)，显示 "1 / 5" ~ "5 / 5"，仅作提示不可点击
- 教师操作流程：
  1. 教师点击「下一步」进入步骤0，展示题目原图，提问"观察图片，杠杆平衡时谁离支点更近？"
  2. 进入步骤1，引导学生由 G大>G小 和平衡等式推出 L大<L小，确认"大人离支点更近"
  3. 进入步骤2，播放同步移动动画，强调"等速→等距"，但两侧剩余力臂仍不等（80 vs 140）
  4. 进入步骤3，展示力矩公式推导，重点讲解代数变形 (G小−G大)·s < 0
  5. 进入步骤4，播放倾斜动画，得出"小孩那端下沉"，高亮选项 B；教师可点击「上一步」随时回退复习关键推导

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无需外部库）。理由：本场景以几何图形、路径、文本、简单平移/旋转动画为主，SVG 的 transform 属性与 requestAnimationFrame 完全足够，引入 D3 等库反而增加包体积与合并复杂度。
- 画布尺寸：800 × 500 px（SVG viewBox="0 0 800 500"）
- 布局草图（ASCII）：
  ```
  0    100        320        520       700   800
  ├────┬──────────┬──────────┬─────────┤
  │    │  大人    │   支点   │   小孩  │   y=40~310 主图区
  │    │  (蓝)    │    O     │   (红)  │
  │    │          │    △     │         │
  │    └──────────┴──────────┘         │
  │  [公式推导区]        [选项区 A/B/C/D]│   y=320~430
  │                                    │
  │      [◀ 上一步]  1/5  [下一步 ▶]   │   y=440~490 控件栏
  └────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `let currentStep = 0;`（范围 0~4），数组 `stepConfigs` 定义每步的显示/隐藏元素 ID 列表。点击按钮时调用 `renderStep(newStep)`，先隐藏所有 step-specific 元素，再根据配置显示当前步元素。
  2. 坐标计算：
     - 大人初始脚点 (180,240)，移动后 (240,240)；小孩初始 (520,240)，移动后 (460,240)。平移动画使用 `requestAnimationFrame` 插值 x 坐标，人物所有子元素统一加 `transform="translate(dx,0)"`。
     - 步骤4 倾斜：杠杆组（含杠杆、支点）加 `transform="rotate(4, 320, 246)"`；人物不旋转，仅计算脚底新坐标（大人约 240.6,234.4；小孩约 460.1,249.8）后整体 `translate` 到该位置。
  3. 动画曲线：
     - 平移动画使用 easeInOutQuad：`t < 0.5 ? 2*t*t : -1+(4-2*t)*t`
     - 旋转动画使用 easeOutQuad：`t*(2-t)`
     - 动画时长：平移 800ms，旋转 600ms
  4. 事件绑定：按钮绑定 `click` 事件，内部检查 `currentStep` 边界。动画期间设置 `isAnimating = true` 并禁用按钮，防止连续点击导致状态混乱。
  5. 公式显示策略：左栏所有公式文本预先在 SVG 中定义，默认 `visibility="hidden"`，`renderStep` 时仅切换当前步所需文本的 visibility，避免频繁创建/销毁 DOM。
  6. 力臂线更新：步骤2 时，将初始 L大线 (180~320) 通过 SVG animate 或 JS 插值缩短为 (240~320)，L小线 (320~520) 缩短为 (320~460)，与人物平移动画同步。

  - 支点：`scene1-pivot`
  - 大人组：`scene1-adult-group`
  - 小孩组：`scene1-child-group`
  - G大箭头：`scene1-arrow-g1`
  - G小箭头：`scene1-arrow-g2`
  - 力臂线L大：`scene1-arm-left`
  - 力臂线L小：`scene1-arm-right`
  - 步骤0公式：`scene1-formula-eq0`
  - 步骤1推导1：`scene1-formula-eq1a`
  - 上一步按钮：`scene1-btn-prev`
  - 下一步按钮：`scene1-btn-next`
