[图示主题与整合说明]
- 本图示主题：正方形沿对角线折叠后在三角形的三个角上打孔，展开后洞的位置分布验证
- 整合的步骤/概念：原始正方形与顶点标注 → 对角线折痕标识 → 折叠动画（B与D重合） → 折叠后等腰直角三角形的角度分析（45° vs 90°） → 三个角打孔位置与颜色编码 → 展开过程与洞的位置映射 → 最终展开图案 → 与四个选项对比验证正确答案A
- 教学价值：教师通过分步导航，可逐层引导学生理解"折痕端点打孔只穿透一层纸，重合点打孔穿透两层纸"这一核心原理，并通过颜色编码和映射箭头建立直观认知

[分步序列]
- 步骤0「原始正方形」：显示正方形ABCD（黑框）及四个顶点标签A、B、C、D。其余元素隐藏。
- 步骤1「画出折痕」：在步骤0基础上，新增对角线AC（灰色虚线），并在AC中点上方显示"折痕"标签。
- 步骤2「折叠过程」：保留正方形轮廓和AC折痕。新增三角形ABC，填充半透明蓝色 rgba(21,101,192,0.15)。启动JS动画：B点从(500,120)沿直线向(300,320)移动（用时800ms，ease-in-out），三角形path的d属性随B点坐标实时更新，模拟翻折效果。动画结束后B与D重合。
- 步骤3「折叠结果」：隐藏原始正方形和动态三角形。显示等腰直角三角形 A(320,130)-C(320,310)-DB(410,220)，直角在右。标注三个顶点：左侧A、左侧C、右侧D/B（红色）。在角内侧标注角度：A处"45°"、C处"45°"、DB处"90°"（DB顶点用红色高亮）。
- 步骤4「打孔位置」：在步骤3基础上，在三角形三个角内侧绘制圆洞：A洞(330,140)蓝色、C洞(330,300)蓝色、DB洞(400,220)红色。右上角显示图例：蓝点="折痕端点（1个洞）"，红点="重合点（2个洞）"。
- 步骤5「展开映射」：左侧显示小三角形（缩小版，顶点A_s(200,170)、C_s(200,290)、DB_s(280,230)）及其三个洞（蓝/红）。右侧显示原始正方形ABCD及四个洞：A(310,130)蓝色、B(490,130)红色、C(490,310)蓝色、D(310,310)红色。用四条灰色虚线箭头连接映射关系：小A洞→大A洞，小C洞→大C洞，小DB洞→大B洞，小DB洞→大D洞。在箭头旁标注"×1"或"×2"说明数量。
- 步骤6「最终图案」：隐藏小三角形和映射箭头。仅显示正方形ABCD及四个绿色圆洞（A、B、C、D各一个）。四个洞统一为绿色 #2e7d32，表示展开后的最终结果。
- 步骤7「选项对比」：保留步骤6的正方形和绿洞（整体位置上移或缩小，为选项腾出空间）。在下方y=360~440横向排列四个选项小图（各80×80）：选项A（四角各1个洞，共4个，正确）、选项B（四角各1个+中心2个，错误）、选项C（左下和右上各2个，错误）、选项D（四角各2个，错误）。选项A用绿色高亮边框，其余选项用#cccccc灰度显示。选项A下方标注"正确答案"标签。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位置(310, 460)，宽80×高30。点击后currentStep减1，回退到上一步，所有元素状态重置为上一步对应状态。
  - 「下一步 ▶」按钮：位置(410, 460)，宽80×高30。点击后currentStep加1，进入下一步，触发该步骤的入场动画（如步骤2的折叠动画、步骤5的箭头淡入）。
  - 按钮在步骤0时禁用「上一步」，步骤7时禁用「下一步」。
- 教师操作流程：教师点击「下一步」逐层展示折叠打孔展开的全过程。在关键步骤（步骤2折叠动画、步骤5映射箭头）可暂停讲解。若学生理解有困难，点击「上一步」回退复习。步骤7展示选项对比，教师可提问学生为何其他选项错误。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本题为纯2D几何图形，无复杂函数图或3D需求。SVG的path、line、circle元素配合JS的setAttribute即可实现所有图形和动画，无需引入重量级库。
- 画布尺寸：800×500px（SVG viewBox="0 0 800 500"）
- 布局草图：
  ```
  [图例区: 右上角 (520,20) ~ (680,90)]
  
  [主图示区 y=100~340]
  +----------------------------------------+
  |    A+----------+B                      |
  |     |          |                       |
  |     |    折痕  |     [折叠三角形]       |
  |     |          |        (步骤3-4)       |
  |    D+----------+C                      |
  |         [映射箭头]                     |
  |              (步骤5)                   |
  +----------------------------------------+
  
  [选项区 y=360~440] (仅步骤7)
  +----+  +----+  +----+  +----+
  | A  |  | B  |  | C  |  | D  |
  +----+  +----+  +----+  +----+
  
  [控件区 y=450~490]
       [◀ 上一步] [下一步 ▶]
  ```
- 关键实现要点：
  1. 状态机设计：用变量 `let currentStep = 0;` 维护当前步骤。`render()`函数根据currentStep设置所有SVG元素的display属性（"block"/"none"）。
  2. 折叠动画（步骤2）：使用 `requestAnimationFrame` 实现B点插值。B点坐标公式：`Bx = 500 - 200 * t`, `By = 120 + 200 * t`, t∈[0,1]（ease-in-out曲线：`t = t < 0.5 ? 2*t*t : -1+(4-2*t)*t`）。三角形path字符串：`M 300 120 L ${Bx} ${By} L 500 320 Z`。动画时长800ms。
  3. 展开映射（步骤5）：小三角形固定显示。四个映射箭头使用SVG `<line>` 元素，在步骤5时通过CSS transition或JS设置opacity从0到1，持续600ms。箭头末端添加 `<marker>` 定义箭头head。
  4. 选项小图绘制：每个选项使用 `<g>` 分组，内部包含 `<rect>`（80×80）和若干 `<circle>`（洞）。选项A画4个洞在四角；选项B画4个角洞+2个中心洞；选项C画4个洞（左下和右上各2个重叠）；选项D画8个洞（四角各2个）。
  5. 颜色切换：步骤5中正方形四个洞初始为蓝/红（与来源对应），步骤6时通过JS将四个洞的fill属性统一改为 `#2e7d32`（绿色），并添加CSS transition过渡效果。
  6. 事件绑定：按钮绑定click事件，调用 `prevStep()` 和 `nextStep()`。在动画播放期间（步骤2）禁用按钮，防止重复触发。
- ID命名规范：所有SVG元素ID必须以 `scene1-` 为前缀。例如：`scene1-square`、`scene1-vertex-a`、`scene1-fold-tri`、`scene1-hole-a`、`scene1-arrow-1`、`scene1-option-a`、`scene1-btn-prev`、`scene1-btn-next`。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免全局变量污染。
