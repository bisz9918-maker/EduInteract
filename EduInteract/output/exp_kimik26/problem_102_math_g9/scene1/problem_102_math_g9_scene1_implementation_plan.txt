[图示主题与整合说明]
- 本图示主题：平面直角坐标系中的直线 AB 基础几何 setup 与目标区间标注
- 整合的步骤/概念：
  1. 建立直角坐标系（x∈[-2,5], y∈[-1,5]），标注原点 O；
  2. 定位已知点 A(-1,4)、B(2,1)；
  3. 绘制直线 AB（方程 y=-x+3）并适当延长；
  4. 标出直线与坐标轴交点 M(3,0)、N(0,3)；
  5. 高亮目标线段 AN 与 BM，建立"目标区间"直观印象，为后续抛物线交点分析做铺垫。
- 教学价值：教师通过分步导航逐层引入几何元素，避免信息过载。学生可清晰看到 AN、BM 分别位于 y 轴左侧和 x 轴右侧，形成"两段分离区间"的空间直觉，便于理解后续抛物线参数 b 的约束条件。

[分步序列]
- 初始状态（步骤0）：显示空白坐标系
  → 可见元素：背景网格、x轴、y轴、轴线箭头、x/y轴刻度线与数字、原点 O 及标签 O
  → 隐藏元素：点 A/B/M/N、直线 AB、高亮线段、所有区间说明
  → 目的：建立坐标系框架，让学生熟悉坐标范围

- 步骤1：点击「下一步」→ 出现点 A 与点 B
  → 新增可见：点 A 圆点(170,170)、标签 A(-1,4)(140,155)；点 B 圆点(320,320)、标签 B(2,1)(335,345)
  → 其余元素保持隐藏
  → 目的：定位已知条件，建立 A 在第二象限、B 在第一象限的空间印象

- 步骤2：点击「下一步」→ 画出直线 AB 并标注方程
  → 新增可见：直线 AB 线段(120,120)-(420,420)；方程标签 "y=-x+3"(340,300)
  → 目的：展示两点确定一条直线，方程为后续求交点做铺垫

- 步骤3：点击「下一步」→ 标出坐标轴交点 M、N
  → 新增可见：点 M 圆点(370,370)、标签 M(3,0)(370,405)；点 N 圆点(220,220)、标签 N(0,3)(205,205)
  → 目的：明确直线与 x 轴、y 轴的交点位置，完善四边形/线段关系

- 步骤4（最终步骤）：点击「下一步」→ 高亮目标线段 AN 与 BM
  → 新增可见：高亮线段 AN（绿色粗线）、高亮线段 BM（绿色粗线）；绿色端点圆环×4（A、N、B、M）；AN区间说明文字(120,200)；BM区间说明文字(380,340)
  → 目的：直观呈现"目标区间"——AN 位于 y 轴左侧（x∈[-1,0]），BM 位于 x 轴右下方（x∈[2,3]），为后续抛物线交点必须分别落在这两段上做视觉锚定

- 教师可随时点击「上一步」回退到任意步骤复习。

- "M(3,0)"(370,405) 与 x轴数字 "3"(370,390)：同 x，间距 15px → 无冲突（M在数字下方，垂直排列不重叠）

[交互方案]
- 交互类型：分步按钮导航（◀ 上一步 / 下一步 ▶）
- 控件说明：
  1. 「上一步」按钮：位置 (280, 452)，尺寸 100×34px。点击后回退一个步骤，state > 0 时生效，state = 0 时禁用（置灰）。
  2. 「下一步」按钮：位置 (420, 452)，尺寸 100×34px。点击后前进一个步骤，state < 4 时生效，state = 4 时禁用（置灰）。
  3. 步骤计数文本：位于两按钮之间下方 (400, 472)，显示当前步骤编号（如 "步骤 1/5"），帮助学生定位当前讲解进度。
- 教师操作流程：
  1. 教师打开图示，首先展示步骤0（空白坐标系），询问学生坐标范围；
  2. 点击「下一步」进入步骤1，引导学生定位 A、B 两点，观察其象限位置；
  3. 点击「下一步」进入步骤2，画出直线 AB，让学生口算或验证直线方程；
  4. 点击「下一步」进入步骤3，让学生求 M、N 坐标，验证截距；
  5. 点击「下一步」进入步骤4，高亮 AN、BM，强调"抛物线与直线的两个交点必须分别落在这两条绿色线段上"，从而引出对参数 b 的约束讨论；
  6. 讲解中可随时回退到任意步骤，针对学生疑问反复强化。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无需外部库）。理由：本场景为静态几何图形与简单的显示/隐藏状态切换，SVG 路径、线段、圆、文本即可满足，引入 D3 等库反而增加体积。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |                                                  |
  |   [y轴↑]                                    |    |
  |      |                                      |    |
  |   A(-1,4) ●                                |    |
  |      |    \                                |    |
  |      N(0,3)●\                              |    |
  |      |      \                              |    |
  |      |       \  B(2,1)                     |    |
  |      |        \ ●                          |    |
  |      |         \                           |    |
  |      |          M(3,0)●                   |    |
  |      +-------------------→ [x轴]          |    |
  |     O                                          |
  |                                                  |
  |        (主图区 y=40~430)                       |
  |                                                  |
  +--------------------------------------------------+
  |    [◀ 上一步]   步骤 X/5   [下一步 ▶]          |  <- 控件区 y=440~490
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `let state = 0;` 表示当前步骤（0~4）。每次点击按钮更新 state，调用 `render()` 函数根据 state 值设置各 SVG 元素的 `display` 属性（或 `visibility`）以及控件禁用状态。
  2. 坐标计算：所有几何元素坐标按上述映射公式硬编码，确保 1:1 比例。直线 AB 延长线端点通过数学边界计算得出（x=-2→y=5；y=-1→x=4）。
  3. 动画曲线：无需复杂动画。步骤切换时，新增元素可直接显示；如需柔和过渡，可为相关元素添加 CSS `transition: opacity 0.2s ease;`，通过切换 `opacity` 实现淡入。
  4. 事件绑定：按钮使用 `onclick` 绑定 `prevStep()` 和 `nextStep()` 函数。所有 JS 代码包裹在 IIFE 中，避免全局污染。
  5. 控件栏定位：使用一个绝对定位的 `div`（`position: absolute; bottom: 10px; left: 0; width: 800px; text-align: center;`）覆盖在 SVG 底部，不撑高容器。
  6. 步骤4高亮：绿色线段使用 SVG `<line>` 元素，置于黑色直线 AB 之上（后定义覆盖先定义，或显式设置 z-index 通过 DOM 顺序控制）。绿色端点圆环使用 `<circle>`，fill="none"，stroke="#2e7d32"，stroke-width="2"。
- ID 命名规范：所有 SVG 元素及控件 ID 必须以 `scene1-` 为前缀。例如：
  - `scene1-x-axis`, `scene1-y-axis`
  - `scene1-point-a`, `scene1-point-b`, `scene1-point-m`, `scene1-point-n`, `scene1-point-o`
  - `scene1-label-a`, `scene1-label-b`, `scene1-label-equation`
  - `scene1-line-ab`
  - `scene1-segment-an`, `scene1-segment-bm`
  - `scene1-highlight-a`, `scene1-highlight-b`, `scene1-highlight-m`, `scene1-highlight-n`
  - `scene1-label-an-range`, `scene1-label-bm-range`
  - `scene1-btn-prev`, `scene1-btn-next`, `scene1-step-text`
  JS 中通过 `document.getElementById('scene1-xxx')` 精确获取元素，禁止跨场景选择器。
- IIFE 隔离：所有 JavaScript 代码必须包裹在 `(function() { ... })();` 中，确保变量与函数不泄漏到全局作用域，避免多场景合并时产生命名冲突。
