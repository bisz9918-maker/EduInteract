[图示主题与整合说明]
- 本图示主题：正方形与菱形组合图形中阴影部分面积的求解
- 整合的步骤/概念：
  1. 由正方形面积25推导边长为5；由菱形面积20及底边5推导高为4。
  2. 在直角三角形BFP中应用勾股定理，已知BP=5（菱形边长）、PF=4，求得BF=3。
  3. 识别矩形PFCE，推导PE=FC=2，EC=PF=4。
  4. 将梯形PBCE分解为三角形BFP与矩形PFCE，或用梯形公式直接求面积得14。
  5. 阴影面积 = 正方形面积 − 梯形面积 = 25 − 14 = 11，对应选项A。
- 教学价值：教师可通过分步导航，逐步呈现辅助线（PF）的添加、勾股定理的应用、以及“整体减空白”的面积转化思想，引导学生建立几何推导的完整逻辑链。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本场景为静态几何图形与状态切换，无需复杂图表库；原生SVG对多边形、填充、虚线支持直接且性能高。
- 画布尺寸：800×500 px（SVG viewBox="0 0 800 500"）。
- 布局草图：
  ```
  +--------------------------------------------------+
  |  A+--------+D                                     |
  |   | 阴影   | E+-------+Q                          |
  |   |   P----+--+       |      [右侧说明区]          |
  |   |  /     |  |       |      x=520~780            |
  |   | /      |  |       |                           |
  |   |/       |  |       |                           |
  |  B+---F----+C |       |                           |
  |   |        |  |       |                           |
  |   +--------+  |       |                           |
  |               |       |                           |
  |  [主图区]     |       |                           |
  |  x=50~500     |       |                           |
  |               |       |                           |
  |               |       |                           |
  +--------------------------------------------------+
  |        [◀ 上一步]  [步骤 1/6]  [下一步 ▶]         |
  |        y=440~490  控件栏                          |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `let currentStep = 0;`（范围0~5）。每步切换时调用 `renderStep()`，根据 `currentStep` 值显隐元素。
  2. 元素显隐：所有步骤专属元素（辅助线、填充区、标注、右侧文字）初始 `display:none` 或 `opacity:0`。`renderStep()` 通过 `element.classList.add('active')` 控制显示。使用CSS transition: opacity 0.3s ease 实现淡入。
  3. 高亮切换：给正方形、菱形、阴影多边形、梯形多边形预先绑定高亮class（如 `.hl-blue-stroke`、`.hl-red-stroke`）。切换步骤时先清除所有高亮，再给当前步骤对应元素添加高亮class。
  4. 右侧文字：使用一个绝对定位的 `<div>` 或 `<g>` 容器，内部包含6组 `<g class="step-text" data-step="N">`，每组包含该步骤的 `<text>` 或 `<tspan>`。`renderStep()` 只显示对应 `data-step` 的组。
  5. 坐标计算：所有坐标硬编码于SVG属性中，不依赖动态计算，确保代码agent可直接复制坐标值。
  6. 按钮事件：上一步/下一步绑定 `click` 事件，修改 `currentStep` 后调用 `renderStep()`，并更新按钮禁用状态（`disabled` 属性）和步骤指示器文本。
- ID命名规范：所有SVG元素及JS访问的DOM节点ID必须以 `scene1-` 为前缀。
  - 示例：`scene1-square-abcd`、`scene1-rhombus-pqcb`、`scene1-shadow-abped`、`scene1-line-pf`、`scene1-tri-bfp`、`scene1-rect-pfce`、`scene1-trap-pbce`、`scene1-label-a`、`scene1-anno-side-5`、`scene1-text-step0`、`scene1-btn-prev`、`scene1-btn-next`、`scene1-step-indicator`。
  - JS中严格使用 `document.getElementById('scene1-xxx')`，禁止使用 `querySelectorAll` 配合全局class查询，避免多场景合并时跨场景污染。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，不暴露全局变量（除必要的DOM事件外）。
