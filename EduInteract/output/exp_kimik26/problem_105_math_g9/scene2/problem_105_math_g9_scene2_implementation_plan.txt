[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：本场景为静态几何图形分步高亮，无复杂动画或函数绘图，原生SVG足以满足需求，且便于精确控制每个元素的颜色、透明度和显隐状态。
- 画布尺寸：800×500 px（viewBox="0 0 800 500"）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  A                                                 |
  |   \                                              |
  |    \    F                                        |
  |     \  /                                         |
  |      \/                                          |
  |      /\                                          |
  |     /  \                                         |
  |    /    \                                        |
  |   B---E--D-------C                               |
  |                                                  |
  |   [① △AED ≌ △AEF]          [结论列表区]         |
  |   [② △ABE ∽ △ACD]                               |
  |   [③ BE + DC > DE]                              |
  |   [④ BE² + DC² = DE²]                           |
  |                                                  |
  |        [◀上一步]  步骤X/5  [下一步▶]              |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `currentStep`（0~5），每个步骤对应一个渲染函数 `renderStep(n)`，该函数根据步骤索引设置所有SVG元素的显隐、颜色、填充属性。
  2. 元素显隐控制：所有可能高亮的元素（三角形填充path、角度弧、推导文本等）初始 `display:none` 或 `opacity:0`，在对应步骤中通过 `setAttribute('display', 'block')` 或修改 `opacity` 显示。
  3. 三角形填充：使用SVG `<path>` 定义三个三角形（△AED、△AEF、△FBE），初始 `fill-opacity:0`，步骤中设置为0.2并赋予对应颜色。
  4. 等长标记：使用 `<g>` 包含两条平行短线段，垂直于AD/AF放置，步骤1中显示。
  5. 角度弧：使用SVG `<path>` 画圆弧（A点附近，半径18或25），配合 `<text>` 显示角度数值。
  6. 直角符号：使用 `<path>` 画L形（两条垂直短线，长度12px），放置在B点内侧（方向：向右和向上）。
  7. 结论标记：四个√/×标记使用 `<text>` 元素，初始隐藏，在对应步骤后显示。
  8. 按钮事件：「上一步」和「下一步」绑定click事件，更新 `currentStep` 后调用 `renderStep()`，并更新按钮禁用状态和步骤指示器文本。
  9. 动画曲线：本场景为即时切换（无过渡动画），确保教师讲解时视觉变化清晰直接。如需柔和过渡，可在CSS中设置 `transition: opacity 0.3s`。
- ID命名规范：所有交互元素ID必须以 `scene2-` 为前缀。例如：
  - 三角形填充：`scene2-tri-aed`、`scene2-tri-aef`、`scene2-tri-fbe`
  - 边线：`scene2-line-ab`、`scene2-line-ae`、`scene2-line-ad` 等
  - 角度弧：`scene2-arc-bac`、`scene2-arc-daf`、`scene2-arc-dae`、`scene2-arc-fae`
  - 结论文本：`scene2-concl-1`、`scene2-concl-2`、`scene2-concl-3`、`scene2-concl-4`
  - 结论标记：`scene2-mark-1`、`scene2-mark-2`、`scene2-mark-3`、`scene2-mark-4`
  - 推导文本：`scene2-deduce-step1`、`scene2-deduce-step2` 等
  - 按钮：`scene2-btn-prev`、`scene2-btn-next`
  - 步骤指示器：`scene2-step-indicator`
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })()` 中，避免全局变量污染，确保多场景合并时互不干扰。
