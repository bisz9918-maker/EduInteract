    **完整题目**

    如图，已知⊙O是等腰Rt△ABC的外接圆，点D是$\stackrel{\frown}{AC}$上一点，BD交AC于点E，若BC=4，AD=$\frac{4}{5}$，则AE的长是（　　）

    A．3　　B．2　　C．1　　D．1.2

    **题目分析**

    本题核心是利用圆的性质和相似三角形求解线段长度。关键突破口：

    1. 等腰Rt△ABC的外接圆 → AB必为直径，∠C = 90°，∠A = ∠B = 45°
    2. AB为直径 → 圆周角∠ADB = 90°（同弧AB所对）
    3. 在Rt△ADB中，已知AB和AD，可求BD
    4. 观察△ADE与△BCE，发现相似关系，建立比例方程

    **整体讲解思路**

    建议先带领学生回顾"直角三角形外接圆"的性质，确认AB为直径；再通过圆周角定理得到∠ADB = 90°，计算出BD的长度；最后引导学生观察相交弦形成的两个三角形，利用相似比和BD的已知长度建立方程求解AE。

    **图示规划说明**

    - Scene 1：展示完整图形，分步标注已知条件，推导AB为直径，计算BD = $\frac{28}{5}$
    - Scene 2：聚焦交点E处的两个三角形，分步展示相似关系的识别、比例建立、方程列写与求解

    **Scene 2 教学说明：相似三角形的识别与方程求解**

    本图示聚焦交点E处的两个三角形△ADE和△BCE，教师应引导学生按以下步骤思考：

    1. **找角关系**：
       - ∠DAE 与 ∠DBC 都是弧DC所对的圆周角，因此相等
       - ∠AED 与 ∠BEC 是对顶角，因此相等
       - 两角对应相等 → △ADE ~ △BCE（AA相似）

    2. **建立比例**：
       - 相似比 = AD : BC = $\frac{4}{5}$ : 4 = **1 : 5**
       - 因此 AE : BE = DE : CE = 1 : 5

    3. **设未知数列方程**：
       - 设 AE = x，则 BE = 5x
       - 因为 AC = 4，所以 CE = 4 - x
       - 由 DE : CE = 1 : 5，得 DE = $\frac{4-x}{5}$
       - 又 BD = BE + DE = $\frac{28}{5}$（来自Scene 1的结论）
       - 列方程：$5x + \frac{4-x}{5} = \frac{28}{5}$

    4. **求解**：
       - 两边同乘5：$25x + 4 - x = 28$
       - $24x = 24$，得 **x = 1**
       - 所以 **AE = 1**，选 **C**

    **讲解要点**

    - 强调"同弧所对圆周角相等"这一性质的应用，这是发现相似的关键
    - 提醒学生注意BD被点E分成两段BE和DE，而这两段分别与两个相似三角形的边相关
    - 方程的建立需要综合Scene 1的BD长度和Scene 2的相似比，体现"前后联系"的解题思想

    **完整解答总结**

    1. 由等腰Rt△ABC外接于⊙O，得∠C=90°，故AB为直径，AC=BC=4，AB=$4\sqrt{2}$
    2. AB为直径 → ∠ADB=90°（圆周角定理）
    3. 在Rt△ADB中，BD=$\sqrt{AB^2-AD^2}=\sqrt{32-\frac{16}{25}}=\frac{28}{5}$
    4. ∠DAE=∠DBC（同弧DC所对圆周角），∠AED=∠BEC（对顶角）
    5. △ADE~△BCE（AA），相似比AD:BC=$\frac{4}{5}$:4=1:5
    6. 设AE=x，则BE=5x，CE=4-x，DE=$\frac{4-x}{5}$
    7. BD=BE+DE → $5x+\frac{4-x}{5}=\frac{28}{5}$
    8. 解得x=1，即**AE=1**，答案选**C**

    **课堂讲解建议**

    - **时间分配**：Scene 1约5分钟（回顾性质+计算BD），Scene 2约8分钟（发现相似+列方程求解）
    - **互动提问**：在Scene 1步骤2可提问"为什么AB是直径？"；在Scene 2步骤1可让学生自己找相等的角
    - **易错点提醒**：学生容易忽略BD=BE+DE这一线段和关系，导致无法建立方程；教师应在Scene 2步骤4特别强调
    - **方法拓展**：可简要提及本题也可用托勒密定理或坐标法求解，作为课后思考
