[图示主题与整合说明]
- 本图示主题：利用相似三角形△ADE~△BCE建立比例方程求AE
- 整合的步骤/概念：
  1) 从图形中识别相交弦构成的两个三角形△ADE与△BCE；
  2) 通过"同弧所对圆周角相等"和"对顶角相等"证明AA相似；
  3) 利用已知边AD=4/5、BC=4得出相似比1:5；
  4) 设AE=x，用相似比表示BE=5x、CE=4-x、DE=(4-x)/5；
  5) 利用弦BD=BE+DE=28/5建立方程；
  6) 解方程得AE=1，对应选项C。
- 教学价值：教师可通过分步导航，逐步揭示"发现相似→建立比例→设元列方程→求解"的完整思维链。每步仅呈现当前推理所需的视觉信息，避免信息过载；可随时回退，强化关键角度关系与比例转化。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本场景为纯几何图形（圆、三角形、角度弧、文本标注），无复杂函数绘图或3D需求，原生SVG足以精确控制每个元素的位置、显隐和样式，且无需引入外部库，减少加载开销。
- 画布尺寸：800×500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |  标题区（如有，外部HTML）                         |
  +--------------------------------------------------+
  |                                                  |
  |     C(400,100)                                   |
  |      /\                                          |
  |     /  \                                         |
  |  D /    \                                        |
  |   /  E   \                                       |
  |  /   .    \                                      |
  | A/_________\B         [右侧面板：方程与推导]      |
  |   O                                              |
  |  (圆，淡化)                                       |
  |                                                  |
  |                                                  |
  +--------------------------------------------------+
  |      [◀上一步]  [下一步▶]     步骤 n/6           |  y=440~490
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：定义常量STEP_COUNT=6，当前状态currentStep∈[0,5]。每个状态维护一个可见元素ID列表（includeList）和样式覆盖列表（styleOverrides）。切换状态时，先隐藏所有动态元素，再按当前状态的includeList显示对应元素，并应用styleOverrides。
  2. 角度弧坐标计算：在JS初始化时，用辅助函数getAngleArc(cx, cy, r, p1, p2)计算两点相对于圆心的标准数学角度，生成SVG path的d属性。标准数学角度转SVG坐标公式：x=cx+r·cos(θ), y=cy−r·sin(θ)（θ为弧度，0=右，逆时针增加；SVG中y向下，故sin前取负）。弧路径使用A命令，小弧标志根据角度差自动判断。
  3. 右侧面板文本管理：使用6组<g>元素（id=scene2-panel-step0~5），每组包含该步骤应显示的<text>列表。切换状态时仅显示当前步骤对应的<g>，其余display=none。避免逐行控制，降低复杂度。
  4. 动画曲线：本场景以静态分步为主，无需复杂动画。步骤切换时，新增元素使用CSS transition opacity 0→1，持续200ms，提升视觉流畅感。高亮边线使用CSS transition stroke-width 0.2s。
  5. 事件绑定：上一步/下一步按钮绑定click事件，调用setStep(newStep)函数。setStep内部更新currentStep、控制按钮disabled状态、更新步骤指示器文本、切换元素显隐。
  6. 填充多边形绘制：△ADE和△BCE使用<polygon>，顶点顺序按A→D→E和B→C→E。步骤0即显示，全程保持，仅在不同步骤中调整fill-opacity以配合高亮需求。
  7. 选项C高亮：步骤5在"答案：C"文本后方添加一个<rect>背景框，fill=#2e7d32，opacity=0.15，rx=4，尺寸略大于文本bounding box（可通过固定值估算：x=578, y=238, width=80, height=28）。
- ID命名规范：所有SVG元素和HTML控件ID必须以scene2-为前缀。例如：
  - 圆：scene2-circle
  - 点A：scene2-point-a
  - ∠DAE弧：scene2-arc-dae
  - 右侧面板步骤3组：scene2-panel-step3
  - 上一步按钮：scene2-btn-prev
  - 下一步按钮：scene2-btn-next
  - 步骤指示器：scene2-step-indicator
  JS中严格使用document.getElementById获取元素，禁止用querySelectorAll配合全局class，避免多场景合并时跨场景样式污染。
- IIFE隔离：所有JavaScript代码包裹在 (function() { ... })() 中，内部变量不污染全局作用域。对外仅暴露必要的初始化入口（如window.initScene2，若容器需要主动调用）。
