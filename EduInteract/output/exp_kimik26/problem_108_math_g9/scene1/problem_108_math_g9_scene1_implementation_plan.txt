[分步序列]
- 步骤0（初始状态）：显示基础图形（△AMN、△BMN、线段MN、交点C、五个点标签M/N/A/B/C），无角平分线标记，无角度标注，无方程
- 步骤1：点击「下一步」→ 显示α（∠MAN）、β（∠MBN）标注；显示蓝色角平分线弧线+双短杠在∠AMN内（BM平分∠AMN）；显示红色角平分线弧线+双短杠在∠BNM内（AN平分∠BNM）
- 步骤2：点击「下一步」→ 显示x标注在M点∠BMN区域（蓝色），显示y标注在N点∠ANM区域（红色）；表示设∠AMB=∠BMN=x，∠BNA=∠ANM=y
- 步骤3：点击「下一步」→ △AMN淡蓝填充高亮，△BMN淡红填充高亮；右侧显示方程①"α+2x+y=180°"（蓝色）和方程②"β+x+2y=180°"（红色）；下方显示推导"x+y=120°-(α+β)/3"
- 步骤4：点击「下一步」→ △CMN淡绿填充高亮；在C点下方显示"∠MCN=180°-(x+y)"；右侧显示绿色边框结论框"∠MCN=(α+β)/3+60°"，验证选项C正确
- 步骤5：点击「下一步」→ 隐藏步骤3的方程①②及x+y推导；显示"α=β"、"∴x=y"、"CM=CN"、"C在MN中垂线上"；画出MN中垂线（灰色虚线x=400）；在CM、CN上画等长标记；验证选项A正确
- 教师可随时点击「上一步」回退复习

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  1. 「上一步」按钮：位置(280,455)，尺寸80×32，点击回退到上一步骤，步骤0时禁用
  2. 「下一步」按钮：位置(440,455)，尺寸80×32，点击前进到下一步骤，步骤5时禁用
  3. 步骤指示器：位置(380,471)，显示当前步骤"步骤 X/6"
- 教师操作流程：教师打开图示后从步骤0开始，每点击一次「下一步」展示新的推导层次；讲解过程中可随时回退到任意步骤复习；步骤4重点强调∠MCN公式，步骤5重点强调对称性与中垂线关系

[技术实现]
- JS库选择：原生SVG（简单几何图形、路径、文本，无需外部库）
- 画布尺寸：800×500px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------------+
  |    A                    B                              |
  |     \                  /                               |
  |      \      C        /                                 |
  |       \     ·       /                                  |
  |        \   / \     /                                   |
  |         \ /   \   /                                    |
  |    x     ·-----·     y                                 |
  |         M       N                                      |
  |              [右侧方程/结论区]                          |
  |                                                        |
  |  [上一步]  步骤X/6  [下一步]                            |
  +--------------------------------------------------------+
  [控件栏 y=440~490，HTML按钮absolute叠在SVG上]
  ```
- 关键实现要点：
  1. 状态机设计：变量currentStep（0~5），updateDisplay()函数根据currentStep控制各group的display属性
  2. 元素分组：按步骤将新增元素包裹在<g id="scene1-step{k}">中（k=1~5），基础图形始终显示
  3. 步骤5特殊处理：步骤5显示时需隐藏步骤3的方程组（scene1-step3-eq group），显示步骤5推导组（scene1-step5-derivation group）
  4. 动画曲线：无需复杂动画，直接使用display切换实现瞬间切换，符合教学演示节奏
  5. 事件绑定：为scene1-btn-prev和scene1-btn-next绑定click事件，修改currentStep后调用updateDisplay()
  6. 按钮状态：步骤0禁用「上一步」，步骤5禁用「下一步」，通过disabled属性控制
- ID命名规范：所有交互元素ID必须以`scene1-`为前缀，如scene1-step1、scene1-btn-prev、scene1-step-indicator、scene1-eq1、scene1-conclusion-box等；JS中使用getElementById获取元素
- IIFE隔离：所有JavaScript代码包裹在`(function() { ... })()`中，避免多场景合并时全局变量污染
