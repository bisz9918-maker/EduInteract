    **完整题目原文**

    如图，AB为半圆的直径，且AB=4，半圆绕点B顺时针旋转45°，点A旋转到A′的位置，则图中阴影部分的面积为（）
    A. π  B. 2π  C. 3π  D. 4π

    **题目分析**

    本题考查图形旋转的性质与不规则图形面积的转化。阴影部分是一个由半圆旋转产生的新月形区域，直接计算其面积较为困难。关键思路是利用"旋转不改变图形面积"这一性质，将阴影面积转化为规则扇形的面积。

    **核心推导**

    1. 设原半圆面积为 $S_{半圆}$，旋转后半圆面积仍为 $S_{半圆}$（旋转保面积）。
    2. 观察图形可知：阴影部分面积 + 两半圆重叠部分面积 = 旋转后半圆面积。
    3. 同时：扇形 $ABA'$ 面积 + 两半圆重叠部分面积 = 原半圆面积。
    4. 由于两个半圆面积相等，因此 **阴影部分面积 = 扇形 $ABA'$ 面积**。
    5. 扇形 $ABA'$ 的半径 $R = AB = 4$，圆心角 $\theta = 45°$。
    6. $S_{阴影} = S_{扇形} = \dfrac{45°}{360°} \times \pi \times 4^2 = \dfrac{1}{8} \times 16\pi = 2\pi$。

    **整体讲解思路**

    - 先让学生观察原图，确认已知条件（直径AB=4，旋转中心B，旋转角45°）。
    - 通过动态旋转展示A→A′的过程，帮助学生建立空间直觉。
    - 引导学生发现：阴影面积难以直接计算，但可以通过面积加减进行转化。
    - 重点揭示"两个半圆面积相等"这一隐藏条件，从而将阴影面积等价转化为扇形面积。
    - 最后代入扇形面积公式得出答案 $2\pi$，对应选项B。

    **图示规划说明**

    本题仅需一个核心图示，整合"原图展示→旋转过程→阴影标注→面积转化→公式计算"的完整认知链条。通过分步按钮导航，教师可逐步推进，学生能清晰看到每一步的几何变化与面积关系。

    **教学说明：如何引导学生观察与思考**

    1. **步骤0（初始状态）**：让学生确认已知条件——AB是直径，长度为4。提问："如果要求阴影面积，我们学过哪些求面积的方法？"引导学生发现阴影是不规则图形，直接计算困难。

    2. **步骤1（旋转过程）**：强调旋转的三要素——旋转中心B、旋转方向（顺时针）、旋转角度（45°）。让学生观察A′的位置，验证BA′=BA=4（旋转保距）。可追问："旋转后的半圆和原来的半圆大小有什么关系？"（面积相等）

    3. **步骤2（阴影高亮）**：让学生明确阴影区域的边界——由旋转后的半圆弧和原半圆弧共同围成。引导学生思考："阴影面积能不能用我们熟悉的图形面积相加或相减得到？"

    4. **步骤3（面积转化）—— 本图核心**：这是最关键的一步。建议教师在黑板上同步写出两个等式：
       - $S_{阴影} + S_{重叠} = S_{旋转半圆}$
       - $S_{扇形ABA'} + S_{重叠} = S_{原半圆}$
       由于 $S_{旋转半圆} = S_{原半圆}$，两边同时减去 $S_{重叠}$，立即得到 $S_{阴影} = S_{扇形ABA'}$。这种"补形法"或"面积割补"的思想是初中几何的重要方法，务必让学生理解。

    5. **步骤4（计算结论）**：代入扇形面积公式时，提醒学生注意圆心角与半径的对应关系。计算：$\dfrac{45}{360} \times \pi \times 16 = 2\pi$。最终答案为选项B。

    **课堂提示**

    - 本题易错点：学生可能试图直接积分或拆分阴影为多个不规则部分，导致计算复杂。教师要引导学生树立"转化思想"——将不规则图形转化为规则图形。
    - 可以拓展提问：如果旋转角度改为60°或90°，阴影面积如何变化？（答案分别为 $\dfrac{8\pi}{3}$ 和 $4\pi$，帮助学生巩固扇形面积公式与旋转角度的关系。）
