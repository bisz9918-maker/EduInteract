problem_110_math_g9

场景导航：Scene 1

题目原文

如图，∠3=30°，为了使白球反弹后能将黑球直接撞入袋中，那么击打白球时，必须保证∠1的度数为（）

A. 30°
B. 60°
C. 90°
D. 45°

题目分析

本题以台球运动为背景，考查光的反射定律在几何问题中的应用。核心物理原理是：台球撞击边框时，入射角等于反射角（相对于法线）。题目给出黑球被撞后需直接进入右下角袋中，因此黑球的运动方向被唯一确定，进而可以求出入射角∠1。

整体讲解思路

  1. 先让学生观察台球桌的几何布局，明确白球、黑球、袋口三者的位置关系。
  2. 引导学生识别图中的三个关键角：∠1（入射角）、∠2（反射角）、∠3（黑球入袋方向与边框的夹角）。
  3. 利用反射定律建立∠1与∠2的等量关系。
  4. 利用法线垂直于边框的几何关系，建立∠2与∠3的互余关系。
  5. 联立求解得出∠1的度数。

图示规划说明

本题仅需一个交互式图示即可覆盖全部讲解需求。图示以台球桌为载体，通过分步导航的方式，从题目原始条件逐步推进到结论，整合了几何布局展示、反射定律说明、角度关系推导和最终计算四个认知阶段。

步骤 0/4

本图示的教学说明

教师在使用本图示时，建议按照分步顺序引导学生观察，每步停留时间根据学生反应灵活调整。

步骤0：理解题意

让学生先观察台球桌的整体布局，明确三个关键对象：白球（起点）、黑球（中间目标）、右下角袋（最终目标）。重点指出∠3=30°是已知条件，它决定了黑球被撞后必须沿什么方向运动才能入袋。

步骤1：引入法线与入射角

点击下一步后，入射路径和法线出现。教师需要强调：法线是过撞击点垂直于边框的直线，这是应用反射定律的前提。∠1是入射光线（白球运动方向）与法线的夹角，而非与边框的夹角——这是学生最容易混淆的地方。

步骤2：反射定律

反弹路径出现后，引导学生回忆物理中的反射定律：入射角等于反射角。在图中即∠1 = ∠2。教师可以提问："如果∠1改变，∠2会如何变化？"帮助学生建立因果联系。

步骤3：建立几何关系

这是解题的关键一步。教师需要引导学生发现：法线垂直于边框，因此法线与边框成90°角。观察∠2和∠3的位置关系，可以发现它们共同构成了这个90°角，因此：

$$\angle 2 + \angle 3 = 90^\circ$$

代入已知条件∠3 = 30°：

$$\angle 2 = 90^\circ - 30^\circ = 60^\circ$$

步骤4：得出结论

结合反射定律∠1 = ∠2，直接得到：

$$\angle 1 = 60^\circ$$

因此正确答案是 B. 60°。

常见误区提醒

  • 学生容易将∠1误认为是与边框的夹角（而非与法线的夹角），教师需特别强调法线的作用。
  • 学生可能误认为∠1 + ∠3 = 90°，需要引导他们通过法线作为桥梁建立正确关系。

完整解答

  1. 根据题意，黑球被撞后需直接进入右下角袋中，因此黑球的运动方向沿黑球与袋口的连线，该连线与边框夹角∠3 = 30°。
  2. 过撞击点作边框的法线，法线垂直于边框，故法线与边框成90°角。
  3. 由图可知，反射角∠2与∠3互余：

$$\angle 2 = 90^\circ - \angle 3 = 90^\circ - 30^\circ = 60^\circ$$

  1. 根据反射定律（入射角等于反射角）：

$$\angle 1 = \angle 2 = 60^\circ$$

  1. 故选 B。

课堂讲解建议

  • 若学生物理基础较弱，可先简要回顾光的反射定律，再迁移到台球问题。
  • 讲解完本题后，可拓展提问：如果∠3变为45°，∠1应为多少？（答案45°）如果黑球要进入右腰中点的袋口，角度关系会如何变化？以此强化学生对几何关系的理解。
  • 本题也可与数学中的轴对称知识联系：白球关于上边框的对称点与黑球、袋口共线，可作为另一种解法介绍给学有余力的学生。
