[图示主题与整合说明]
- 本图示主题：等腰三角形中的垂直平分线性质与相似关系求 cosA
- 整合的步骤/概念：题目基础条件 → 垂直平分线性质（EA=EB）→ 角度推导（36°/72°）→ 等腰△EBC与相似△ABC∽△BEC → 设元列方程求AE → Rt△ADE中求cosA得选项C
- 教学价值：教师通过分步导航控制节奏，逐步展示几何推导与代数求解的完整链条，学生可清晰看到从已知条件到最终结论的每一步可视化依据

[分步序列]
- 初始状态（步骤0）「题目条件」：
  显示△ABC黑色边线；AB=AC=4标注蓝色；∠C=72°标注蓝色及角度弧；D为中点（中点标记灰色）；DE⊥AB（DE黑色、直角符号蓝色）。右侧无推导文本。
  
- 步骤1「垂直平分线」：
  新增：BE线段（红色#c62828，线宽2.5px）、EA=EB文字标注（红色，385,320）。
  高亮：DE线段变为红色，直角符号变为红色。
  右侧无推导文本。
  
- 步骤2「角度推导」：
  新增：5个角度弧与标注（全部红色）——∠A=36°(400,160)、∠ABC=72°(341,367)、∠ABE=36°(328,370)、∠EBC=36°(350,378)、∠BEC=72°(442,305)。
  BE线段保持红色。
  
- 步骤3「相似与等腰」：
  新增：△EBC红色填充20%、△ABC蓝色填充10%；EB=BC标注(400,410)红色；△ABC∽△BEC文字(620,280)红色。
  角度标注保持显示。
  
- 步骤4「设元列方程」：
  新增：AE=x(413,218)、EB=x(370,318)、EC=4-x(474,330)、BC=x(400,392)全部红色；右侧比例式"x/4 = (4-x)/x"(620,200)及方程"x² = 16-4x"(620,240)红色。
  步骤3的EB=BC保持显示。
  
- 步骤5「求解cosA」：
  新增：△ADE绿色填充20%；AD=2标注(369,204)绿色；右侧推导链(620,200)~(620,340)绿色，其中"(√5+1)/4"与"选项 C"加粗放大。
  前序元素保持显示（可适当降低非关键元素透明度至40%，但计划保持原样以保留完整推导链）。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「◀ 上一步」按钮：位于(310,448)，宽90高36，点击回退到前一步，隐藏当前步骤新增的元素，恢复前一步状态
  2. 「下一步 ▶」按钮：位于(480,448)，宽90高36，点击前进到下一步，显示下一步新增的元素并应用高亮
  3. 步骤提示文字：位于(400,435)，显示当前步骤名称（如"步骤2/5：角度推导"）
- 教师操作流程：
  1. 教师打开图示，默认显示步骤0（题目基础条件），向学生介绍已知条件
  2. 点击「下一步」进入步骤1，讲解DE是AB的垂直平分线，得出EA=EB
  3. 继续点击「下一步」逐步展示角度、相似、方程、最终结论
  4. 可随时点击「上一步」回退复习关键步骤
  5. 按钮在步骤0时「上一步」禁用（opacity 0.3），步骤5时「下一步」禁用

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：纯几何图形，无复杂函数绘图或3D，原生SVG路径、文本、填充控制足够，无需引入外部库，减少依赖。
- 画布尺寸：800 × 500 px（SVG viewBox="0 0 800 500"）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                    A(400,140)                      |
  |                   /\                             |
  |                  /  \                            |
  |                 /    \                           |
  |                /      \                          |
  |              D/        \E                        |
  |              /          \                        |
  |             /            \                       |
  |            /              \                      |
  |           B----------------C                     |
  |         (322,380)      (478,380)                 |
  |                                                  |
  |    [右侧推导文本区 x=560~780]                     |
  |                                                  |
  |         [步骤提示文字]                            |
  |    [◀ 上一步]      [下一步 ▶]                    |
  +--------------------------------------------------+
  控件区 y=440~490
  ```
- 关键实现要点：
  1. 状态机设计：用变量 `currentStep`（0~5）控制当前步骤。每一步定义一个配置对象，包含 `show`（显示的元素ID列表）、`highlight`（高亮元素ID列表及颜色类）、`fill`（填充多边形ID及颜色类）。
  2. 元素显隐：所有可选元素初始 `display:none` 或 `opacity:0`，根据 `currentStep` 切换。使用CSS transition实现0.3s淡入淡出。
  3. 角度弧绘制：使用SVG `<path>` 的arc命令（A），通过JavaScript计算起点、终点及sweep-flag。例如∠C弧：圆心C，半径18，起点(460,380)（CB方向），终点通过三角函数计算CA方向。
  4. 坐标计算：AB中点D、DE与AC交点E的坐标在JS中预计算（基于A/B/C坐标），确保几何关系准确。
  5. 事件绑定：按钮点击更新 `currentStep`，调用 `renderStep()` 函数统一更新所有元素的class和style。
  6. 防重叠：所有文本标签使用 `text-anchor:middle` 或 `start/end` 根据位置调整，确保不压线。
- ID命名规范：所有元素ID必须以 `scene1-` 为前缀。例如：`scene1-tri-abc`、`scene1-point-a`、`scene1-label-ab4`、`scene1-angle-c`、`scene1-btn-prev`、`scene1-btn-next`、`scene1-step-text`。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })()` 中，避免全局变量污染。
