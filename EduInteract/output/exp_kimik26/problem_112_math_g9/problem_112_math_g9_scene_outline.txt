    题目原文：如图，△OAB绕点O逆时针旋转70°到△OCD，如果∠A=100°，则∠D=50°，那么∠AOD的度数是（）
    A.20°  B.30°  C.40°  D.50°

    **题目分析**

    本题考查旋转的性质与三角形内角和定理的综合应用。核心在于理解旋转的三要素（旋转中心、旋转方向、旋转角度），以及旋转前后图形全等这一关键性质。

    **整体讲解思路**

    1. 引导学生观察图形，识别旋转中心O、原三角形OAB和旋转后的三角形OCD
    2. 强调旋转性质：旋转前后图形全等，对应角相等、对应边相等
    3. 明确旋转角：∠AOC = ∠BOD = 70°
    4. 由全等关系推出∠B = ∠D = 50°
    5. 在△OAB中利用内角和定理求出∠AOB = 30°
    6. 通过角度位置关系计算∠AOD = ∠BOD − ∠AOB = 40°

    **图示规划说明**

    本题仅需一个核心图示即可覆盖完整讲解。图示以题目原图为基础，通过分步导航的方式，从展示已知条件开始，逐步叠加旋转性质、全等关系、内角和计算，最终推导出∠AOD的度数。所有步骤围绕同一组几何图形展开，保持视觉一致性。

    **本图示的教学说明**

    教师使用本图示时，建议按以下方式引导学生：

    1. **步骤0——建立直观印象**
       让学生观察两个三角形的相对位置，提问："哪个是原图形？旋转中心在哪里？向什么方向旋转？"确认学生能识别O为旋转中心，△OAB逆时针旋转得到△OCD。

    2. **步骤1——理解旋转角**
       强调旋转角的概念：对应点与旋转中心连线的夹角就是旋转角。因此∠AOC和∠BOD都是旋转角，都等于70°。可以追问："如果连接O和AB的中点，这个中点旋转后的对应点与O的连线，和原中点连线的夹角是多少？"巩固旋转角概念。

    3. **步骤2——应用全等性质**
       旋转前后图形全等，因此对应角相等。已知∠D=50°，其对应角是∠B，所以∠B=50°。这一步是解题的关键桥梁。

    4. **步骤3——计算∠AOB**
       在△OAB中，利用三角形内角和定理：

       ∠AOB = 180° − ∠A − ∠B = 180° − 100° − 50° = 30°

       教师可让学生先口算，再点击下一步验证。

    5. **步骤4——计算∠AOD并确定答案**
       观察图形中三个角的位置关系：∠BOD是旋转角（70°），∠AOB在∠BOD内部（30°），因此：

       ∠AOD = ∠BOD − ∠AOB = 70° − 30° = 40°

       答案选 **C**。

    **易错点提醒**

    - 学生可能错误地认为∠AOD = ∠AOC + ∠COD = 70° + 30° = 100°。这是因为没有仔细观察OD的实际位置（OD在OA和OB之间，从角度位置上看）。教师应强调必须结合图形判断角的和差关系，不能仅凭字母顺序臆断。
    - 注意区分"旋转角"（∠AOC = ∠BOD = 70°）和"三角形内角"（∠AOB = ∠COD = 30°），避免混淆。

    **课堂互动建议**

    - 每步点击后先停顿3-5秒，让学生独立思考后再揭示标注
    - 步骤2可提问："已知∠D=50°，△OAB中哪个角也等于50°？为什么？"
    - 步骤4可提问："∠AOD、∠BOD、∠AOB这三个角在图中是什么位置关系？应该用加法还是减法？"
    - 讲解结束后，可让学生口述完整解题过程，强化逻辑链条
