problem_114_geography_g9

场景导航：Scene 1

完整题目原文

读图，完成1-2题。

根据此图判断正确的一项是（ ）

A. A点一年只有一次太阳直射
B. B点一年可能有两次直射现象
C. 从南北半球位置看，B点在南半球
D. 从东西半球位置看，A点在东半球，B点在西半球

题目分析

本题考查极地投影图（极视图）的综合判读，核心知识点包括：

  1. 地球自转方向与南北极的对应关系（北极俯视逆时针，南极俯视顺时针）；
  2. 极地经纬网图中经度、纬度的判读方法；
  3. 东西半球的划分界线（20°W 与 160°E 组成的经线圈）；
  4. 太阳直射点的移动范围（南北回归线之间，即 23.5°N—23.5°S）。

整体讲解思路

建议教师按"先定南北、再定坐标、最后综合判断"的顺序讲解：

  1. 利用"北逆南顺"口诀，根据自转方向判断左图为北极、右图为南极，从而确定 A 在北半球、B 在南半球，直接锁定选项 C；
  2. 为严谨起见，继续带领学生判读 A、B 的经纬度：根据 0° 与 180° 经线位置及自转方向定东西经，得出 A（约 45°N，135°W）、B（约 45°S，45°W）；
  3. 结合东西半球划分与太阳直射范围，逐一排除 A、B、D 三个错误选项；
  4. 最后总结极地投影图判读的一般步骤，强化读图能力。

图示规划说明

本题所有读图与推理步骤整合为 1 个交互式分步图示。教师通过底部的「上一步 / 下一步」按钮控制讲解节奏，从原题呈现逐步推进到南北极判断、经纬度判读、东西半球划分、太阳直射范围分析，最终完成四个选项的正误判断。整个图示左右双图并列，与题目原图保持一致，确保学生建立清晰的视觉对应关系。

步骤 0/6

本图示的教学说明与讲解要点

教师在使用本图示时，建议按照分步顺序引导学生观察，每一步停留时间根据学生反应灵活调整。

步骤 0—1：建立"北逆南顺"直观印象

先让学生独立观察左右两图的自转方向箭头，提问："哪幅图是北极？哪幅图是南极？" 引导学生发现"逆时针—北极—北半球"、"顺时针—南极—南半球"的对应关系。此口诀是解一切极地投影图的基础，务必让学生当场复述。

步骤 2：快速锁定正确选项 C

一旦确定左图为北极、右图为南极，A 点位于北半球、B 点位于南半球即成立。此时可以告诉学生：在考试中，如果选项 C 表述为"B 点在南半球"，已经可以确定其正确性。但为了培养严谨思维，仍需继续判读其他选项以排除干扰。

步骤 3：经度判读的核心方法

经度判读是学生的易错点，讲解时强调以下步骤：

  1. 先找 0° 和 180° 经线（本题已标注，0° 在下、180° 在上）；
  2. 根据自转方向定东西：北极俯视"逆时针为东"，南极俯视"顺时针为东"；
  3. 按 45° 间隔推算各条经线度数；
  4. 确定 A 位于 135°W，B 位于 45°W。

可让学生动手在草稿纸上画箭头，标注"东"的方向，避免东西经混淆。

步骤 4：东西半球的划分与判断

东西半球的分界线不是 0° 和 180°，而是 20°W 与 160°E 组成的经线圈。需要特别强调：

  • 东半球范围：20°W → 0° → 160°E
  • 西半球范围：160°E → 180° → 20°W

A 点（135°W）位于 20°W 以西，属于西半球；B 点（45°W）同样位于 20°W 以西，也属于西半球。因此选项 D 中"A 点在东半球"的表述错误，整个选项 D 不成立。

步骤 5：纬度判读与太阳直射范围

图中同心圆为等纬度间隔（外圈赤道 0°、中圈 45°、中心极点 90°），A、B 均位于 45° 纬线上。太阳直射点始终在 南北回归线之间（23.5°N—23.5°S） 移动，因此：

  • 只有南北回归线上的地点一年有 1 次直射；
  • 南北回归线之间的地点一年有 2 次直射；
  • 回归线以外的地点没有直射。

A（45°N）和 B（45°S）均远在回归线之外，不存在直射现象，故选项 A、B 均错误。

步骤 6：课堂总结建议

最后一步呈现四个选项的正误一览，教师可带领学生总结极地投影图判读的"三步法"：

  1. 定南北：看自转方向（北逆南顺）；
  2. 定坐标：找 0°/180°，按自转方向定东西经，看同心圆定纬度；
  3. 定归属：结合半球划分、五带范围等知识综合判断。

建议留 1-2 分钟让学生用此方法快速回顾整道题的推理链条，巩固读图技能。
