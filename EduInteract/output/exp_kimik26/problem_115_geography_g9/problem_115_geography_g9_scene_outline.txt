    读图，回答1-4题。

    1. 咸蛋超人住在（30°N，120°E），有一天他想拜访住在地球另一端的面包超人，并决定"遁地"前去，于是他从家中钻入地底，始终保持直线前进并穿过地心到面包超人家。请你判断面包超人家的具体位置（  ）

    2. 有关咸蛋超人和面包超人家的叙述，正确的是（  ）

    3. 判断图中E点位于F点什么方向（  ）

    4. 图中各点符合下列条件：它的东部是东半球，西部是西半球，北部四季变化明显，南部有太阳直射现象的是（  ）
    A. 甲点  B. 乙点  C. 丙点  D. 丁点

    **题目分析：**

    本题是一道初中地理经纬网综合读图题，核心考查以下知识点：
    1. **对跖点（地球对称点）计算**：纬度数值相等、南北纬相反；经度之和为180°、东西经相反。
    2. **经纬网方向判断**：经线指示南北，纬线指示东西。
    3. **东西半球划分**：20°W向东至160°E为东半球，20°W向西至160°E为西半球。
    4. **五带划分与特征**：热带（南北回归线之间，有太阳直射）、北温带（北回归线至北极圈，四季分明）、北寒带（北极圈以北，有极昼极夜）。

    **图示规划说明：**

    本题设计2个教学图示：
    - **图示1（经纬网综合读图）**：以题目原图为基础，整合方向判断、东西半球分界线、五带范围三个知识模块，通过分步导航逐一呈现，帮助学生建立"经纬网是地理定位基础"的认知。
    - **图示2（对跖点与遁地原理）**：用地球截面示意图直观展示"穿过地心"的几何含义，将抽象的坐标计算转化为可视化的对称关系，帮助学生理解对跖点的推导过程。

    教师应引导学生按以下逻辑观察：

    1. **先建立网格意识**：让学生说出图中横向是纬线（指示东西）、纵向是经线（指示南北），并读出各点坐标。强调"横纬竖经"的判读口诀。

    2. **方向判断要点**：在步骤1中，引导学生发现判断E在F的什么方向，需要分别比较经度和纬度。
       - 纬度比较：23.5°N < 66.5°N，所以E在F的南侧。
       - 经度比较：20°E < 40°E，所以E在F的西侧。
       - 综合：E在F的**西南方向**。
       - 提醒学生：方向判断可以画"十字方向标"，以F为原点建立方向坐标系。

    3. **东西半球分界线**：步骤2中强调**20°W和160°E**组成的经线圈是东西半球的分界线，而非0°经线。
       - 20°W以东→东半球；20°W以西→西半球。
       - 图中20°W恰好是左侧第一条经线，这是第4题的关键线索。

    4. **五带划分与特征**：步骤3中结合图中特殊纬线讲解：
       - 23.5°N（北回归线）和23.5°S（南回归线）之间为热带，有太阳直射。

    **本图示教学说明（对应SCENE_2）：**

    教师应利用此图帮助学生建立"对跖点"的空间概念，避免死记公式：

    1. **建立几何直观**：步骤0-1中，让学生理解"地球另一端"在几何上就是"过地心的直径与地表的另一个交点"。强调这是球体最重要的对称性。

    2. **纬度推导**：步骤2中引导学生观察A、B两点关于赤道对称。
       - A在北半球30°，B就在南半球30°。
       - 规律：纬度数值不变，南北纬相反。
       - 即：30°N → 30°S。

    3. **经度推导**：步骤3中引导学生思考经度关系。
       - 两点在同一直径上，经度相差180°。
       - 规律：经度之和为180°，东西经相反。
       - 计算：180° − 120° = 60°，所以是60°W。

    4. **公式总结**：步骤4中给出通用公式，帮助学生迁移：
       - 对跖点公式：**(φ, λ) → (−φ, λ ± 180°)**
       - 注意：若原经度 > 180°，则减去180°并变号；若原经度 < 180°，则用180°减去原经度并变号。

    5. **易错提醒**：
       - 不要与"关于地轴对称"混淆（关于地轴对称只改变经度，纬度不变）。
       - 不要与"关于赤道对称"混淆（关于赤道对称只改变纬度，经度不变）。
       - 对跖点是同时关于赤道和地心对称，纬度和经度都变。
