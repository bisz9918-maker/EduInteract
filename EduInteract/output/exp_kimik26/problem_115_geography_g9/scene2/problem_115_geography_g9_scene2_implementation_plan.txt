[图示主题与整合说明]
- 本图示主题：对跖点坐标计算与地球对称性
- 整合的步骤/概念：
  1. 建立地球圆形截面模型，标注赤道、地心、南北极；
  2. 在截面中标出咸蛋超人位置 A(30°N, 120°E)；
  3. 用动画展示穿过地心的遁地直线 A→O→B；
  4. 揭示纬度对称关系（30°N ↔ 30°S，南北纬相反）；
  5. 揭示经度互补关系（120°E + 60°W = 180°，东西经相反）；
  6. 总结对跖点通用公式并给出本题结论。
- 教学价值：教师通过分步导航，从三维地球抽象为二维截面，先建立几何直观（穿地心直线），再归纳代数规律（纬度取反、经度互补），降低学生认知负荷。可随时回退复习。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：本场景为几何图形与分步状态切换，无复杂数据绑定或3D，原生SVG性能最优且无需额外库。
- 画布尺寸：800 × 500 px（沿用规格）。
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  N                                                 |
  |   ●                                                |
  |    \                                               |
  |     \    咸蛋超人 A                                 |
  |      \   ● 30°N                                    |
  |       \  |                                         |
  |        \ | 120°E                                   |
  |  面包超人 B ●----O----● A  对跖点坐标计算          |
  |  30°S   /|         \    [步骤说明文字框]            |
  |        / |          \                              |
  |       /  |           \   [公式总结框，步骤4显示]   |
  |      ●   |            \                            |
  |     S    赤道          \                           |
  |                         \                          |
  |  +------------------------------------------------+|
  |  |      [◀ 上一步] [步骤 2/5] [下一步 ▶]         ||
  |  +------------------------------------------------+|
  +--------------------------------------------------+
  ```
  （注：草图为示意，实际A在右侧、B在左侧，遁地线穿过地心O）

- 关键实现要点：
  1. 状态机设计：使用变量 `currentStep`（0~4），数组 `stepElements` 记录每步应显示/隐藏的SVG元素ID列表。切换步骤时遍历对应列表设置 `display` 属性。
  2. 遁地线动画：步骤1中，使用SVG的 `stroke-dasharray` 等于路径总长度，`stroke-dashoffset` 从总长度动画到0。路径总长度通过 `getTotalLength()` 获取，使用 `requestAnimationFrame` 或CSS transition实现800ms ease-out动画。
  3. 坐标计算：A、B点坐标基于圆心(250,250)与半径170，利用三角函数精确计算：A(250+170·cos30°, 250−170·sin30°)≈(397,165)，B为对跖点(250−170·cos30°, 250+170·sin30°)≈(103,335)。
  4. 箭头实现：SVG `<marker>` 定义在 `<defs>` 中，id="scene2-arrow-red"，附着于遁地线末端。
  5. 按钮状态：步骤0时禁用「上一步」（opacity 0.4，pointer-events none）；步骤4时禁用「下一步」。
  6. 右侧文字切换：每步预定义字符串，切换步骤时更新对应 `<text>` 或 `<foreignObject>` 中的内容。建议使用 `<foreignObject>` 包裹HTML `<div>` 以便多行文本自动换行。
  7. 公式框：步骤4前设置 `display:none`，步骤4时设置为 `display:block`。

- ID命名规范：所有交互元素ID必须以 `scene2-` 为前缀。
  - 示例：`scene2-earth-circle`、`scene2-equator-line`、`scene2-point-a`、`scene2-point-b`、`scene2-tunnel-line`、`scene2-radius-oa`、`scene2-radius-ob`、`scene2-label-a`、`scene2-label-b`、`scene2-label-lat-n`、`scene2-label-lat-s`、`scene2-label-lon-e`、`scene2-label-lon-w`、`scene2-info-box`、`scene2-formula-box`、`scene2-btn-prev`、`scene2-btn-next`、`scene2-step-indicator`、`scene2-arrow-marker`。
  - JS中严格使用 `document.getElementById` 获取元素，禁止全局class查询，避免多场景合并时跨场景污染。

- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，内部变量不泄漏全局作用域。
