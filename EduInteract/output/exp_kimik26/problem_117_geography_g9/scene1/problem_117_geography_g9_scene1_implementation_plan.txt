- 本图示主题：经纬网坐标判读与两地相对方位判断

  1. 甲地经纬度判读（西经、南纬的判定）

[技术实现]
- JS库选择：原生 SVG（通过JavaScript动态操作DOM）。理由：本场景为静态几何图形（经纬线、矩形、文字、箭头），无复杂动画或函数绘图，原生SVG足够轻量且精确。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  0    100  200  300  400  500  600  700  800
  +----+----+----+----+----+----+----+----+  y=0
  |  60°  50°  30°    30°  40°  50°       |  y=65  上方标注区
  |  +-----------+    +-----------+       |  y=80
  |30°|     甲    |    |     乙    | 30°   |  y=170 主图区
  |40°|           |    |           | 20°   |  y=260
  |   +-----------+    +-----------+       |
  |  [坐标框]          [坐标框]            |  y=280 坐标/对比区
  |      [步骤3-4中间对比文字]              |  y=320~380
  |  [A]  [B]  [C]  [D]                   |  y=400~430 选项区
  |      ◀上一步  步骤X/5  下一步▶         |  y=460~490 控件区
  +----+----+----+----+----+----+----+----+  y=500
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `let currentStep = 0;` 记录当前步骤（0~4）。每次点击按钮时更新 `currentStep`，调用 `renderStep()` 函数重新渲染。
  2. 渲染策略：`renderStep()` 先隐藏所有步骤专属元素（通过预设的 class 如 `step1-only`, `step2-only` 等设置 `display: none`），再根据 `currentStep` 值显示对应元素（设置 `display: block` 或 `display: inline`）。固定元素（经纬网、基础标注、选项框）始终显示。
  3. 坐标计算：所有坐标硬编码在 SVG 元素的 x/y/x1/y1 属性中，严格按本计划坐标表实现，确保无重叠。
  4. 动画曲线：本场景无需复杂动画，步骤切换采用即时显示/隐藏（display切换）。如需柔和过渡，可对 opacity 做 200ms CSS transition。
  5. 事件绑定：上一步/下一步按钮通过 `document.getElementById('scene1-btn-prev')` 和 `document.getElementById('scene1-btn-next')` 获取，绑定 `click` 事件。步骤0禁用「上一步」，步骤4禁用「下一步」。
  6. 选项状态控制：步骤3时，通过修改选项A/B的 `fill` 为 `#888888` 和 `opacity` 为 `0.5` 实现置灰；步骤4时，给选项C添加绿色背景 rect，选项D置灰。
