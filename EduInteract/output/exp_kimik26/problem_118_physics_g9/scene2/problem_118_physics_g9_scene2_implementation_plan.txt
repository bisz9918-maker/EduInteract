[图示主题与整合说明]
- 本图示主题：各选项比值的物理意义与推导验证（串联电路动态分析）
- 整合的步骤/概念：
  1) 建立简化串联等效电路（R1与R2接入串联）；
  2) 选项A：U2/I 的物理意义等于总电阻 R1+R2接入，随滑片左移而变小；
  3) 选项B：(U2−U1)/I 的物理意义等于 R1 两端电压除以电流，即定值电阻 R1；
  4) 选项C：ΔU1/ΔI 的推导链，利用 U1=U2−I·R1 得到 |ΔU1/ΔI|=R1；
  5) 选项D：ΔU2=0（电源电压恒定）而 ΔU1≠0，两者大小不同。
- 教学价值：教师通过分步导航，可聚焦单个选项的公式推导与物理意义，左侧电路高亮与右侧公式同步配合，帮助学生建立“比值即电阻/电压关系”的直觉。

[分步序列]
- 初始状态（步骤0）：显示简化串联电路模型（R1、R2接入、I、U1、U2），右侧显示基本关系式：U₂ = I(R₁ + R₂接入)、U₁ = I·R₂接入、U₂ − U₁ = I·R₁，以及提示"滑片P左移 → R₂接入减小"。无高亮框。
- 步骤1（选项A）：点击「下一步」→ 右侧标题变为"选项 A：U₂/I 的变化"；显示公式"U₂/I = R₁ + R₂接入"；说明"电源电压 U₂ 恒定，R₂接入 减小"；推导结论"R₂接入 ↓ → U₂/I ↓"；左侧同步显示R1高亮框(绿)与R2接入高亮框(蓝)；底部结论标记"√ 正确"（绿色）。
- 步骤2（选项B）：点击「下一步」→ 右侧标题变为"选项 B：(U₂−U₁)/I 的变化"；显示公式"(U₂−U₁)/I = U_R₁/I = R₁"；说明"U₂−U₁ 为 R₁ 两端电压"、"R₁ 是定值电阻"；左侧仅保留R1高亮框(绿)，隐藏R2高亮框；底部结论标记"√ 正确，比值 = R₁ 不变"（绿色）。
- 步骤3（选项C）：点击「下一步」→ 右侧标题变为"选项 C：ΔU₁/ΔI 的变化"；显示推导链："U₁ = U₂ − I·R₁" → "ΔU₁ = −R₁·ΔI" → "|ΔU₁/ΔI| = R₁"；说明"比值的绝对值等于定值电阻 R₁"；左侧保留R1高亮框(绿)；底部结论标记"√ 正确"（绿色）。
- 步骤4（选项D）：点击「下一步」→ 右侧标题变为"选项 D：ΔU₁ 与 ΔU₂ 的比较"；显示"ΔU₂ = 0（U₂ 为电源电压，恒定）"、"ΔU₁ = −R₁·ΔI ≠ 0"；对比"|ΔU₁| > 0 = |ΔU₂|"；说明"两者大小不同"；左侧隐藏所有电阻高亮框（可高亮V1、V2以示对比）；底部结论标记"× 错误"（红色）。
- 教师可随时点击「上一步」回退复习，步骤指示器实时更新。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「上一步」按钮：位置(280,455)，宽80高30；点击回退到上一状态，步骤0时禁用。
  2. 步骤指示器：位置(380,455)，宽140高30；显示当前步骤文字如"步骤 2/5"，不可点击。
  3. 「下一步」按钮：位置(540,455)，宽80高30；点击前进到下一状态，步骤4时禁用。
- 教师操作流程：
  1. 教师展示步骤0，讲解简化电路与基本关系；
  2. 点击「下一步」进入选项A，配合左侧总电阻高亮讲解U2/I的物理意义；
  3. 继续点击「下一步」逐条讲解B、C、D；
  4. 可随时点击「上一步」回退到某选项重新讲解；
  5. 步骤指示器帮助学生定位当前正在分析的选项。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：本场景以静态几何图形、文本标签和显隐切换为主，无需复杂数据绑定或3D渲染，原生SVG性能最优且零依赖。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  0    100   200   300   400   500   600   700   800
  +----------------------------------------------------------+
  |                                                          |
  |   U1,V1                                    标题(480,80)  |
  |      |                                    -------------- |
  |  R1  |  R2接入                             公式推导区    |
  |      |                                    (x=300~780)    |
  |      |    I                                text-anchor   |
  |      |                                     = middle      |
  |      |                                                   |
  |   U2,V2                                                  |
  |                                                          |
  |   (左侧 x=20~280)                                        |
  |                                                          |
  |                                                          |
  |----------------------------------------------------------| y=430
  |                                                          |
  |     [上一步]      步骤 X/5        [下一步]               | y=455-485
  |                                                          |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：维护变量 `currentStep`（取值0~4）。每步对应一个SVG `<g>` 分组（id如 `scene2-step-0` 到 `scene2-step-4`），通过设置 `display="none"` 或 `display="block"` 切换可见性。
  2. 高亮同步：步骤切换时同步更新高亮框的display属性。步骤1显示R1和R2高亮；步骤2/3仅显示R1高亮；步骤4隐藏所有电阻高亮。
  3. 按钮状态：在`updateStep()`函数中检查边界，`currentStep===0`时禁用「上一步」，`currentStep===4`时禁用「下一步」。
  4. 公式下标：使用SVG `<tspan>` 实现下标，例如 `U<tspan dy="4" font-size="0.7em">2</tspan>`。
  5. 结论标记：使用独立 `<text>` 元素，步骤1/2/3设置 fill="#2e7d32"，步骤4设置 fill="#c62828"。
  6. 事件绑定：按钮通过 `document.getElementById('scene2-btn-prev').addEventListener('click', ...)` 绑定。
  7. 初始调用：DOM加载完成后调用 `updateStep(0)` 渲染初始状态。
- ID命名规范：所有交互元素ID必须以 `scene2-` 为前缀。例如：
  - 电路分组：`scene2-circuit-group`
  - R1电阻：`scene2-resistor-r1`
  - R2电阻：`scene2-resistor-r2`
  - V1电压表：`scene2-voltmeter-v1`
  - V2电压表：`scene2-voltmeter-v2`
  - 步骤0内容组：`scene2-step-0`
  - 步骤1内容组：`scene2-step-1`
  - ...
  - 步骤4内容组：`scene2-step-4`
  - R1高亮框：`scene2-highlight-r1`
  - R2高亮框：`scene2-highlight-r2`
  - 上一步按钮：`scene2-btn-prev`
  - 下一步按钮：`scene2-btn-next`
  - 步骤指示器：`scene2-step-indicator`
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免全局命名空间污染，确保多场景合并时互不干扰。
