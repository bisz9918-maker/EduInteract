[图示主题与整合说明]
- 本图示主题：动态电路分析——滑片P移动对并联支路灯泡亮度的影响
- 整合内容：电路结构识别 → 电流路径可视化 → 滑片移动与电阻变化 → L₁支路分析（亮度不变） → L₂支路分析（亮度变亮） → 结论展示（选项B）
- 教学价值：教师通过分步导航，按认知节奏逐步讲解。每步聚焦一个核心判断点（识图→判电阻→分路分析→得结论），学生不易信息过载。电流箭头与公式标注将抽象电学规律可视化，便于学生建立直观认知。

[分步序列]
- 步骤0「题图还原」（初始状态）：
  显示完整电路图（电源、开关S、滑动变阻器及滑片P、L₁、L₂、全部导线）。
  所有元件标签显示（S、P、L₁、L₂、+、-）。

  右侧面板显示："请观察电路，判断各元件连接方式"。
  导航栏步骤0圆点高亮。

- 步骤1「电流路径」：
  点击「下一步」后，蓝色箭头从(160,260)画向(280,260)表示L₁支路电流；红色箭头从(160,140)画向(280,140)表示L₂支路电流。
  新增标签I₁(220,275)、I₂(220,125)。
  右侧面板更新："L₁单独一条支路；L₂与滑动变阻器串联后构成另一条支路；两支路并联"。

- 步骤2「滑片移动」：
  滑片P从x=210动画平移到x=250（向右滑动），标签P同步移至(250,95)。
  滑动变阻器接入段（P到右端）以橙色粗线高亮，长度从50px缩短到10px。
  新增标签R变(235,170)标注"R变↓"。
  右侧面板更新："滑片P向右滑动 → 接入电阻丝变短 → 接入电阻减小"。

- 步骤3「L₁支路分析」：
  L₁支路保持蓝色高亮（导线、灯泡边框加粗/变色）。
  L₂支路及滑动变阻器淡化至透明度30%。
  公式框(420,170)出现，显示："U₁ = U电源"、"P₁ = U₁² / R₁"。
  引线从公式框指向L₁。
  右侧面板更新："并联电路：各支路电压 = 电源电压；L₁电阻不变 → 功率不变 → 亮度不变"。

- 步骤4「L₂支路分析」：
  L₂支路恢复红色高亮，L₁支路淡化至透明度30%。
  公式框(420,170)更新为："R总 = R变 + R_L₂ ↓"、"I₂ = U / R总 ↑"、"P₂ = I₂²·R_L₂ ↑"。
  引线指向L₂。
  L₂光晕透明度从30%动画增至60%，表示变亮。
  右侧面板更新："R变减小 → 支路总电阻减小 → 电流增大 → L₂实际功率增大 → L₂变亮"。

- 步骤5「得出结论」：
  全电路恢复正常透明度，L₂光晕保持60%。
  电路图下方(200,350)出现绿色大字："灯L₂变亮，灯L₁亮度不变"。
  右侧面板更新："正确答案：B"，并以绿色高亮选项B文字。
  导航栏步骤5圆点高亮。

- 回退机制：教师可随时点击「◀ 上一步」回退到任意步骤复习，所有视觉状态同步恢复。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：电路图由标准几何图形（线段、圆、矩形、折线）构成，SVG的矢量特性保证缩放清晰；交互逻辑简单（状态切换），无需引入D3/Three.js等重型库。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图：
  ```
  +--------------------------------------------------+
  |  电路图区（x:50-480）        |  右侧面板（x:500-780） |
  |                              |                      |
  |    [电源+]—[S]—+             |  分析面板            |
  |              |               |  ————————————        |
  |    [变阻器P]—[L₂]            |  每步文字说明...      |
  |              |               |                      |
  |           [L₁]               |                      |
  |              |               |                      |
  |            [电源-]           |                      |
  |                              |                      |
  |  ◄────────────────────────►  |                      |
  +--------------------------------------------------+
  |        ○ ○ ○ ○ ○ ○  （步骤指示器）                  |
  |     [◀ 上一步]      [下一步 ▶]                     |
  +--------------------------------------------------+
  导航栏区域 y:440-490
  ```

- 关键实现要点：
  1. 状态机设计：使用变量currentStep（0~5），每次切换时调用renderStep()函数，根据currentStep值显示/隐藏/修改对应SVG元素的属性（opacity、stroke-width、transform等）。
  2. 滑片动画：步骤2中滑片P平移使用SVG transform属性配合CSS transition（transform 0.5s ease），从translate(0,0)到translate(40,0)。
  3. 光晕动画：步骤4中L₂光晕透明度从0.3到0.6，使用CSS transition（opacity 0.8s ease）。
  4. 电流箭头：使用SVG <marker>定义箭头头部，步骤1时设置opacity从0到1的过渡。
  5. 公式框：使用<foreignObject>或SVG <rect>+<text>组合，步骤3/4动态替换内部text内容。
  6. 高亮效果：通过修改元素的stroke（边框色）、stroke-width（线宽）、opacity（透明度）实现，全部使用CSS transition保证平滑。
  7. 右侧面板文字：使用HTML div覆盖在SVG上方（position:absolute），通过JS动态更新innerText。

- ID命名规范：所有SVG元素和HTML控件ID必须以scene1-为前缀。
  示例：scene1-wire-top（上方导线）、scene1-switch-s（开关）、scene1-lamp-l1（L₁灯泡）、scene1-btn-prev（上一步按钮）、scene1-step-dot-0（步骤0圆点）。
  JS中使用document.getElementById('scene1-xxx')获取元素，禁止querySelectorAll配合全局class。

- IIFE隔离：所有JavaScript代码包裹在 (function() { ... })() 中，避免多场景合并时变量污染。

- 事件绑定：按钮点击绑定updateStep(delta)函数，圆点点击绑定goToStep(index)函数。更新currentStep后边界检查（0≤currentStep≤5），然后调用renderStep()同步所有视觉状态。
