# Scene 1 Implementation Plan

<SCENE_VISION_STORYBOARD_AND_TECHNICAL_PLAN>

[图示主题与整合说明]
- 本图示主题：电路动态分析与电磁相互作用综合演示（初中物理：滑动变阻器动态电路 + 安培定则 + 磁极间相互作用 + 受力分析）
- 整合的步骤/概念：电路结构识别 → 滑动变阻器阻值变化 → 电流/电压表示数变化 → 安培定则判断螺线管磁极 → 同名磁极相互排斥 → 磁铁受力分析 → 弹簧测力计示数变化 → 结论判定
- 教学价值：教师可按照“电路→磁学→力学”的递进逻辑链逐步展开，每步聚焦单一核心知识点；学生能直观看到“滑片移动→电表示数变化→磁极判定→斥力变化→测力计读数变化”的完整因果链，避免信息过载。

[技术实现]
- JS库选择及原因：原生SVG + 原生JavaScript。理由：本场景以电路图、几何图形和简单状态切换为主，无复杂函数绘图或3D需求；原生SVG可精确控制每个元件的坐标、stroke、fill和transform，且便于通过class/ID控制显隐；无需引入D3/Three.js等重型库，减少加载开销。
- 画布尺寸：800 × 500 px（SVG viewBox="0 0 800 500"）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------------+
  |  左侧电路区(40~420)        |    右侧电磁区(560~760)     |
  |  [电池]-[S]-[R0]-[A]-------|    天花板                 |
  |    |         |             |      |                    |
  |   [R]--[V]   |             |   [弹簧测力计]            |
  |    |         |             |      |                    |
  |    +---------+--->[螺线管B] |   [磁铁A] S/N            |
  |                            |      |                    |
  |                            |   [螺线管B] N/S           |
  |                            |                            |
  |  公式/选项区(左下)          |   受力分析(步骤5,右中)      |
  +--------------------------------------------------------+
  |          [◀ 上一步]    [下一步 ▶]    步骤 X/6           |  y=440~490
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量`currentStep`（0~6），每步维护一个显隐元素ID列表。点击按钮时，先隐藏所有"步骤专属"元素，再根据目标步的列表显示对应元素。避免逐个硬编码，使用`data-step`属性标记。
  2. 坐标计算：所有导线连接点使用绝对坐标，确保接头无空隙。螺线管线圈用`<path>`绘制锯齿线：从(560,220)开始，每次x+40, y+20, x-40, y+20循环6次。
  3. 动画曲线：滑片移动使用CSS `transition: transform 0.5s ease-out`；电表指针旋转使用`transition: transform 0.6s cubic-bezier(0.34, 1.56, 0.64, 1)`（带轻微回弹，更直观）；电流路径高亮使用SVG `<animate>`或CSS stroke-dashoffset动画实现流动效果。
  4. 事件绑定：按钮绑定`click`事件，内部调用`goToStep(n)`。在`goToStep`中先`event.preventDefault()`，然后更新`currentStep`，同步更新按钮disabled状态（步骤0时禁用"上一步"，步骤6时禁用"下一步"）。
  5. 电流路径高亮：用一条与导线完全重合的`<path>`，设置`stroke:#1565c0`、`stroke-width:4`、`opacity:0.5`、`stroke-dasharray:10 5`，并通过CSS动画移动`stroke-dashoffset`产生流动感。
  6. 右手模型：使用简化SVG path绘制手掌和五指的轮廓，设置`fill:#ffdbac`、`fill-opacity:0.3`、`stroke:#888888`、`stroke-dasharray:4 2`；步骤3时改变`opacity`从0到1。
  7. 受力分析箭头：使用`<line>`+`<polygon>`箭头，或`<path>`+`marker-end`。三个力箭头水平错开（G在x=680，F_斥在x=680，F_拉在x=710），标签分别位于(690,250)、(690,190)、(720,200)。
  8. 弹簧测力计指针：用`<line>`元素，步骤5时通过JS修改其y2属性或应用`transform: translateY(8px)`，配合`transition`实现示数减小动画。
- **ID命名规范**：所有交互元素ID必须以`scene1-`为前缀。例如：
  - 电池：`scene1-battery`
  - 开关：`scene1-switch`
  - 电流表指针：`scene1-ammeter-needle`
  - 滑片：`scene1-rheostat-slider`
  - 步骤1电流路径：`scene1-step1-current-path`
  - 步骤3右手模型：`scene1-step3-right-hand`
  - 步骤5受力分析组：`scene1-step5-force-diagram`
  - 按钮：`scene1-btn-prev`、`scene1-btn-next`
  JS中严格使用`document.getElementById('scene1-xxx')`获取元素，禁止全局class查询，避免多场景合并时跨场景污染。
- IIFE隔离：所有JavaScript代码包裹在`(function() { ... })();`中，不暴露全局变量。如需暴露接口，挂载到`window.scene1 = { goToStep: ... }`单一命名空间下。
