题目原文

如图所示，电源电压不变，灯的电阻不变，滑动变阻器的滑片P在移动过程中，电流表的最小示数为0.2A，电压表的最大示数为4V，当滑片P滑到中点时，灯L的功率达到最大，且灯的最大功率与最小功率之比为9：4．下列结论正确的是（ ）

A．电源电压为10V
B．灯的电阻为20Ω
C．滑动变阻器的最大电阻为40Ω
D．电路消耗的最大功率为1.8W

题目分析

本题是初中电学综合计算题，核心考查串联电路动态分析、欧姆定律及电功率极值问题。解题关键在于识别电路结构、抓住三个特殊状态（电流最小/电压最大端、中点功率最大端、电流最大端），并利用比例关系建立方程。

整体讲解思路

  1. 先带学生识别电路：灯泡L与滑动变阻器串联，电流表测电路电流，电压表测滑动变阻器两端电压。
  2. 分析滑片移动时的两个端点状态：
  • 一端（如左端）：滑动变阻器接入电阻为0，电流最大，灯泡功率最大；
  • 另一端（如右端）：滑动变阻器接入电阻最大，电流最小，电压表示数最大。
  1. 利用题目给出的极值数据（Imin=0.2A，Uvmax=4V）求出滑动变阻器最大阻值。
  2. 利用功率比 PLmax : PLmin = 9 : 4，结合 PL = I²RL，得到电流比 Imax : Imin = 3 : 2，从而求出 I_max = 0.3A。
  3. 列方程组求解电源电压U和灯泡电阻R_L，最后验证四个选项。

步骤 0/4

本图示的教学说明

教师在使用SCENE_1时，应引导学生按以下顺序观察：

  1. 识别电路（步骤0）：让学生说出各元件名称及仪表测量对象。强调电压表并联在滑动变阻器两端，测的是滑动变阻器分得的电压，而非电源电压或灯泡电压。
  1. 左端极端状态（步骤1）：当滑片P移到使接入电阻为0的一端时，电路总电阻最小，电流最大。此时灯泡两端电压等于电源电压，灯泡最亮，功率最大。这是后续建立方程的关键状态之一。
  1. 右端极端状态（步骤2）：当滑片P移到另一端，滑动变阻器全部接入，总电阻最大，电流最小（Imin=0.2A）。根据串联分压，滑动变阻器两端电压也达到最大（Uvmax=4V）。由此可直接算出滑动变阻器最大阻值：

Rmax = Uvmax / I_min = 4V / 0.2A = 20Ω

  1. 中点状态（步骤3）：滑片在中点时，接入电阻为Rmax/2 = 10Ω。题目给定此时灯L功率最大。教师可在此向学生说明：在标准串联电路中，灯的功率随滑动变阻器阻值减小而增大，理论上在Rslide=0时最大；但本题以给定条件为准，我们将"中点功率最大"作为已知约束用于后续推导（或引导学生讨论题目条件的物理含义）。
  1. 三状态对比（步骤4）：通过表格并列展示三种状态下的电流、电压、电阻、功率关系，帮助学生建立"电阻→电流→电压→功率"的因果链条。
核心公式
I = U / R
P = U I = I² R = U² / R

步骤 1/5

本图示的教学说明

SCENE_2是本题的计算核心，教师应带领学生一步步完成推导，强调"比例关系"在电学计算中的妙用。

  1. 步骤0（公式准备）：先让学生回顾串联电路特点和三个功率公式。提醒学生：因为灯泡电阻R_L不变，所以功率比可以直接转化为电流平方比，这是本题的突破口。
  1. 步骤1（求R_max）：强调"电流最小"与"电压最大"是同一个状态（滑动变阻器全部接入）。直接用欧姆定律变形式R=U/I即可，计算简单但容易因状态对应错误而出错。
  1. 步骤2（求Imax）：这是本题的技巧点。由PL = I²RL，且RL不变，得：

PLmax / PLmin = Imax² / Imin² = 9/4
开方得 Imax / Imin = 3/2，因此 I_max = 0.3A。
教师应追问：为什么可以直接开方？因为比例两边都是正数，且R_L约掉了。

  1. 步骤3（列方程组）：
  • 状态一（Rslide=0，电流最大）：电源电压 U = Imax · RL = 0.3 RL
  • 状态二（Rslide=Rmax=20Ω，电流最小）：电源电压 U = Imin · (RL + Rmax) = 0.2(RL + 20)

联立得：0.3 RL = 0.2 RL + 4，解得 R_L = 40Ω，代回得 U = 12V。

  1. 步骤4（选项验证）：
  • A. 电源电压为10V → 实际12V，错误
  • B. 灯的电阻为20Ω → 实际40Ω，错误
  • C. 滑动变阻器最大电阻为40Ω → 实际20Ω，错误
  • D. 电路消耗的最大功率为1.8W → 实际Pmax = U·Imax = 12V×0.3A = 3.6W，错误

课堂讲解建议：若按上述标准推导，本题四个选项均不成立。教师可在此设置讨论环节，引导学生检查是否题目条件存在特殊理解方式（例如"中点功率最大"是否暗示了某种非标准接法或定义域限制），或作为"无正确选项"的批判性思维训练。若教学中需要给出"最接近"的答案，可重点分析选项B和C的数值互换陷阱（RL=40Ω与Rmax=20Ω）。
