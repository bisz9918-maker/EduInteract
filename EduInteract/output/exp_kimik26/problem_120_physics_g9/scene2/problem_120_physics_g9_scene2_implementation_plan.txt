[图示主题与整合说明]
- 本图示主题：功率比例推导与选项验证（物理·九年级·电学综合计算）
- 整合的步骤/概念：①已知条件汇总与公式回顾；②由极值条件求 R_max；③由功率比 9:4 建立电流比并求 I_max；④列方程组求解 U 和 R_L；⑤四个选项逐一验证
- 教学价值：教师可使用此图示进行课堂讲解，通过分步导航严格控制信息呈现节奏，每一步聚焦一个推导目标，学生不易迷失在冗长公式中；可随时回退重讲某一步

[分步序列]
- 初始状态（步骤0）：显示完整电路图（无高亮）+ 左侧已知条件列表（4条）+ 右侧"核心公式"标题 + 公式卡片（I=U/R，P=UI=I²R=U²/R）+ 提示文本"点击「下一步」开始推导"。教师可在此回顾题目条件和所需公式。
- 步骤1：点击「下一步」→ 右侧切换为"步骤1：求滑动变阻器最大阻值"；显示推导式 R_max=U_Vmax/I_min = 4V/0.2A = 20Ω（结果绿色加粗）；左侧电路图中电压表V和滑动变阻器用红色#c62828描边高亮（stroke-width增至2.5px）；变阻器下方出现绿色标注"R_max = 20Ω"。
- 步骤2：点击「下一步」→ 右侧切换为"步骤2：由功率比求最大电流"；显示 P_L=I²R_L → P_Lmax/P_Lmin = I_max²/I_min² = 9/4 → I_max/I_min=3/2（蓝色）→ I_max=0.3A（绿色加粗）；左侧电路图中灯泡L用蓝色#1565c0描边高亮。
- 步骤3：点击「下一步」→ 右侧切换为"步骤3：列方程组求解电源电压与灯阻"；显示状态A（R_slide=0，蓝色方程① U=0.3R_L）和状态B（R_slide=R_max，蓝色方程② U=0.2(R_L+20)）；显示联立过程；结果 R_L=40Ω、U=12V 绿色加粗显示；左侧电路图整体用蓝色#1565c0轻描边高亮，表示全电路分析。
- 步骤4（最终步骤）：点击「下一步」→ 右侧切换为"步骤4：选项验证"，显示4行4列表格；四行分别验证选项A/B/C/D，判断列均显示红色"×"，计算值列显示正确值（U=12V、R_L=40Ω、R_max=20Ω、3.6W），结论列均显示"错误"；左侧电路图恢复无高亮状态。教师可随时点击「上一步」回退复习。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 步骤指示器 / 下一步▶）
- 控件说明：
  1. 「上一步」按钮：位置(280,455)，宽80×高32，步骤0时禁用（opacity 0.4，cursor not-allowed）
  2. 步骤指示器：位置(370,455)，宽60×高32，显示文本"步骤 1/5"~"步骤 5/5"，font-size 13px，颜色#666666
  3. 「下一步」按钮：位置(440,455)，宽80×高32，步骤4时禁用
- 教师操作流程：
  1. 教师打开图示，默认显示步骤0（已知条件+公式），向学生说明题目条件。
  2. 点击「下一步」进入步骤1，讲解如何利用I_min和U_Vmax求R_max，观察电路图上电压表和变阻器的红色高亮。
  3. 点击「下一步」进入步骤2，讲解功率比与电流比的关系，得出I_max。
  4. 点击「下一步」进入步骤3，建立两种状态的方程组，联立求解U和R_L，强调蓝色方程的物理意义。
  5. 点击「下一步」进入步骤4，展示选项验证表格，逐一分析四个选项为何错误，强化正确数值记忆。
  6. 如需回退，随时点击「上一步」重新讲解某一步。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript（无需外部库）。理由：本场景以静态几何图形、文本标签和简单状态切换为主，原生SVG足以精确控制电路图和表格；分步导航逻辑简单，无需D3/React等重型框架。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------------+
  |  +-------------------+  +-----------------------------+ |
  |  |   [电路示意图]     |  |      【步骤标题】            | |
  |  | 电池-A-变阻器-L-S |  |                             | |
  |  |    V跨变阻器      |  |      【推导内容/表格】        | |
  |  +-------------------+  |      （随步骤切换）           | |
  |  | 已知条件           |  |                             | |
  |  | I_min=0.2A        |  |                             | |
  |  | U_Vmax=4V         |  |                             | |
  |  | P_Lmax:P_Lmin=9:4 |  |                             | |
  |  | 中点时P_L最大      |  |                             | |
  |  +-------------------+  +-----------------------------+ |
  |                                                        |
  |       [◀ 上一步]    步骤 X/5    [下一步 ▶]              |
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 currentStep（0~4），数组 stepGroups 存储5个 SVG <g> 元素的引用。showStep(n) 函数遍历数组，将目标组 display 设为 block 并 opacity 1，其余 display none。步骤切换时添加 200ms 的 opacity 过渡动画（CSS transition: opacity 0.2s）。
  2. 电路图高亮：为电压表、变阻器、灯泡、整体电路分别设置 ID（scene2-voltmeter、scene2-rheostat、scene2-lamp、scene2-circuit-group）。showStep 中根据步骤索引调用 setAttribute('stroke', color) 和 setAttribute('stroke-width', width) 实现高亮，切回其他步骤时恢复默认值（#000000，1px）。
  3. 坐标计算：所有坐标已在布局坐标表中精确到像素，代码 agent 直接按表实现。文本使用 SVG <text> 的 x/y 属性定位，多行推导通过多个 <text> 元素实现（不用 tspan 换行，降低复杂度）。
  4. 动画曲线：步骤切换使用 CSS transition: opacity 0.2s ease-in-out；无其他复杂动画，保持教学图示的清晰和稳重。
  5. 事件绑定：在 IIFE 内部为按钮绑定 click 事件；上一步按钮 ID scene2-prev-btn，下一步按钮 ID scene2-next-btn；指示器 ID scene2-step-indicator。
  6. 表格实现：使用 SVG <rect> 画单元格背景，<line> 画边框，<text> 填充文字。表头和数据行垂直居中计算：行中心 y = 行顶 + 27.5，文字基线 y = 行中心 + 5。
- ID命名规范：所有交互元素和可操控图形元素 ID 必须以 scene2- 为前缀。例如：scene2-circuit、scene2-voltmeter、scene2-rheostat、scene2-lamp、scene2-step0~scene2-step4、scene2-table、scene2-prev-btn、scene2-next-btn、scene2-step-indicator、scene2-formula-card、scene2-rmax-label。
- IIFE隔离：所有 JavaScript 代码包裹在 (function() { ... })() 中，避免全局变量污染，确保多场景合并时互不干扰。
