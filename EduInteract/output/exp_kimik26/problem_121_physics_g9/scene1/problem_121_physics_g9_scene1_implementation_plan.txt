[图示主题与整合说明]
- 本图示主题：整体法与隔离法分析六物块连接体的水平受力
- 整合的步骤/概念：题目情景 → 整体法求总摩擦 → 均摊求单块摩擦 → 隔离法求3-4间压力 → 结论
- 教学价值：教师通过分步导航，可线性递进地展示从宏观整体到局部隔离的受力分析过程，每步可随时回退，契合课堂讲解节奏

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「◀ 上一步」按钮：位于底部x=250~350，点击回退到上一认知步骤
  2. 步骤名称标签：位于底部x=340~460居中，显示当前步骤名称（如"步骤2：单个摩擦力"）
  3. 「下一步 ▶」按钮：位于底部x=450~550，点击前进到下一步骤
- 教师操作流程：教师打开图示后处于步骤0（题意），点击「下一步」依次展示整体法→单个摩擦→隔离法→结论；可随时点击「上一步」回退到任意阶段重新讲解；步骤4时「下一步」禁用或循环回步骤0。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript（本场景为简单几何图形与显隐切换，无需引入外部库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------------+
  |                                                        |
  |     1    2    3    4    5    6          [公式区]       |
  |    +----+----+----+----+----+----+                     |
  |    |    |    |    |    |    |    |    整体法/隔离法    |
  |    +----+----+----+----+----+----+    推导文字...      |
  |  ====F====>                                          |
  |  ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~ 地面        |
  |       f  f  f  f  f  f                                 |
  |                                                        |
  |              [◀ 上一步]  [步骤名]  [下一步 ▶]          |
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量currentStep（0~4）管理5个步骤，每步对应一个SVG <g>组（scene1-step0 ~ scene1-step4），通过设置display属性切换显隐。
  2. 元素分组：将每步新增元素分别包裹在独立的<g>中，如scene1-group-overall（整体框+f_total）、scene1-group-singlef（6个f）、scene1-group-isolate（隔离框+高亮+N+3f）、scene1-group-conclusion（绿色结论）。基础元素（物块、地面、F、编号）始终显示。
  3. 箭头绘制：使用SVG <line>+<polygon>（箭头三角形）组合，或<path>带marker-end。推荐marker-end定义箭头头部，便于统一修改。
  4. 虚线框：使用stroke-dasharray="5,5"实现虚线效果。
  5. 高亮填充：使用fill="#1565c0" fill-opacity="0.15"，注意设置pointer-events="none"避免阻挡交互。
  6. 动画曲线：本场景为即时切换（无补间动画），教师点击按钮后立即显示/隐藏对应元素组，保证课堂讲解节奏。
  7. 事件绑定：上一步/下一步按钮绑定click事件，更新currentStep后调用render()函数，根据步骤索引控制各<g>的display属性（block/none）。
  8. 按钮状态：步骤0时禁用「上一步」，步骤4时禁用「下一步」（或变为「重新开始」）。
- ID命名规范：所有SVG元素及JS引用ID必须以scene1-为前缀，例如：
  - scene1-block-1 ~ scene1-block-6
  - scene1-arrow-f
  - scene1-arrow-ftotal
  - scene1-group-overall
  - scene1-group-singlef
  - scene1-group-isolate
  - scene1-btn-prev, scene1-btn-next
  JS中严格使用getElementById获取元素，禁止querySelectorAll配合全局class。
- IIFE隔离：所有JavaScript代码包裹在 (function() { ... })() 中，避免多场景合并时变量污染。
