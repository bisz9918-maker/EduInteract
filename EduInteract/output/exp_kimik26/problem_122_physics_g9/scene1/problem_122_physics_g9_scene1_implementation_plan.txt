[图示主题与整合说明]
- 本图示主题：均匀金属薄板 3×3 分块电阻建模与挖去中间块过渡
- 整合的步骤/概念：
  1. 原薄板整体及 A、B 接线柱位置；
  2. 以虚线将薄板均匀划分为 3×3 共 9 个小矩形块；
  3. 3 条水平电流通道（每通道 3 块串联）及每小块阻值 R 的标注；
  4. 右侧公式卡片推导：每行 3R 串联 → 三行并联 → 总电阻 R → 每小块电阻 = R；
  5. 挖去正中间一小块后的薄板形态（红色半透明填充表示缺失）。
- 教学价值：教师可按照"整体→分块→电流路径→公式推导→挖去"的递进逻辑逐步讲解，配合分步按钮控制课堂节奏，每步只呈现当前所需信息，避免信息过载。

[分步序列]
- 步骤0（初始状态）：显示完整矩形薄板（外框+左右电极）、A/B接线柱及标签、总电阻R标注(230,110)。隐藏网格、电流箭头、R/3R标注、公式卡片、中间块缺失区。教师可在此介绍题目原始条件。
- 步骤1（分块）：点击「下一步」→ 3×3虚线网格以淡入动画出现（opacity 0→1，300ms）。其余元素保持不变。教师讲解均匀分块。
- 步骤2（电流通道与单块电阻）：点击「下一步」→ 
  1) 3条蓝色水平电流箭头从左电极指向右电极（位于每行中心）淡入；
  2) 9个蓝色"R"标注在每块中心同时淡入；
  3) 3个蓝色"3R"标注在每行右侧(410,y)同时淡入。
  教师讲解电流沿3条水平通道流动，每通道3块串联。
- 步骤3（并联推导与结论）：点击「下一步」→ 
  1) 右侧公式卡片(460,120)-(760,380)淡入；
  2) 卡片内6行推导文字逐行淡入（每行间隔150ms）；
  3) 最后一行结论"⇒ 每小块电阻 = R"以绿色(#2e7d32)加粗显示。
  教师讲解串联→并联→总电阻R→每小块电阻=R的推导。
- 步骤4（挖去中间块）：点击「下一步」→ 
  1) 中间块区域(180,210)-(280,290)填充变为#c62828，透明度30%，以200ms淡入；
  2) 中间块中心的"R"标注(230,255)淡出隐藏；
  3) 其余8块及所有标注保留。
  教师说明中间块被挖去，为后续计算新电阻做铺垫。
- 教师可随时点击「上一步」回退，所有动画反向执行（淡出或隐藏）。

[技术实现]
- JS库选择：原生 SVG + 原生 JavaScript。原因：本场景为静态几何图形与分步显隐，无需复杂图表库；SVG的group和class便于批量控制显隐。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +----------------------------------------------------------+
  |                                                          |
  |                    R总                                   |
  |    A  +-----------------------------+  B                 |
  |       | +-----+-----+-----+         |                    |
  |       | |  R  |  R  |  R  |         | 3R   [=========]  |
  |       | +-----+-----+-----+         |      [ 公式卡片 ]  |
  |       | |  R  |  R  |  R  |         | 3R   [ 推导过程 ]  |
  |       | +-----+-----+-----+         |      [ 结论...  ]  |
  |       | |  R  |  R  |  R  |         | 3R   [=========]  |
  |       | +-----+-----+-----+         |                    |
  |       +-----------------------------+                    |
  |                                                          |
  |              [上一步]    步骤 X/5    [下一步]             |
  +----------------------------------------------------------+
  薄板区(80,130)-(390,370)    公式区(460,120)-(760,380)    控件区y=440~490
  ```
- 关键实现要点：
  1. 状态机设计：用变量 `currentStep`（0~4）记录当前步骤，每次点击按钮时更新状态并调用 `renderStep()`。
  2. 元素分组：将每步新增的元素分别包裹在 SVG `<g>` 组中，赋予 id 如 `scene1-step1-grid`、`scene1-step2-arrows`、`scene1-step2-rlabels`、`scene1-step3-formula`、`scene1-step4-missing`，通过设置 group 的 `display` 或 `opacity` 控制整组显隐。
  3. 动画曲线：使用 CSS transition `opacity 0.3s ease` 实现淡入淡出；电流箭头可额外添加 `stroke-dasharray` + `stroke-dashoffset` 动画模拟绘制效果（0.5s）。
  4. 事件绑定：按钮通过 `addEventListener('click', ...)` 绑定，上一步/下一步分别执行 `currentStep--` 或 `currentStep++`，并更新按钮禁用状态。
  5. 中间块挖去效果：步骤4中，中间块缺失区使用一个绝对定位的 `<rect>`，初始 `opacity:0`，步骤4时变为 `opacity:0.3`，同时隐藏 `scene1-r-22`（中间R标签）。
  6. 公式卡片文字逐行显示：可在步骤3进入后，用 `setTimeout` 依次给每行文字添加 `visible` class，间隔150ms。
- ID命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀。例如：
  - 薄板外框：`scene1-plate-outline`
  - 左电极：`scene1-electrode-left`
  - A接线柱：`scene1-terminal-a`
  - 网格组：`scene1-step1-grid`
  - 电流箭头组：`scene1-step2-arrows`
  - R标注组：`scene1-step2-rlabels`
  - 中间R标签：`scene1-r-22`
  - 公式卡片：`scene1-step3-formula`
  - 中间缺失区：`scene1-step4-missing`
  - 上一步按钮：`scene1-btn-prev`
  - 下一步按钮：`scene1-btn-next`
  - 步骤文字：`scene1-step-indicator`
- IIFE隔离：所有 JavaScript 代码包裹在 `(function() { ... })()` 中，避免多场景合并时全局变量污染。
