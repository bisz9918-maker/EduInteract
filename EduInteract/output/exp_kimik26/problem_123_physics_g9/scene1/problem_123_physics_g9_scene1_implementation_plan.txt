[图示主题与整合说明]
- 本图示主题：连通器装置的气体压强平衡与体积变化分析
- 整合的步骤/概念：装置结构空间认知 → 初始状态压强推导（P_丙 = P₀ + ρgΔh） → 开关M打开后的水流动态 → 乙丙液面变化与体积变化 → 最终平衡结论（ΔV_乙 > ΔV_丙，选项A）
- 教学价值：教师通过分步导航，可按照“识别装置→分析初态→展示过程→得出结论”的递进逻辑讲解；支持随时回退复习，适合课堂节奏控制；右侧公式面板与左侧装置图同步联动，降低学生空间想象难度。

[分步序列]
- 步骤0（装置认知）：显示完整装置图（三容器、三管路、开关M、水/气填充、初始液面虚线）。显示标签：甲、乙、丙、M、大气。右侧面板标题“装置结构”，文字说明三条连接关系（甲-丙液体连通、乙-丙气体连通、竖直管连通大气与乙）。无公式，无高亮。
- 步骤1（初始压强分析）：
  → 左侧液体连通管与甲丙水区添加黄色高亮衬底；甲液面旁P₀标注以绿色高亮框衬底。
  → 右侧气体连通管与乙丙气区添加黄色高亮衬底；P_乙、P_丙标注以红色高亮框衬底。
  → 中间竖直管与开关M添加黄色高亮衬底。
  → 显示标签：P₀（绿）、P_乙（红）、P_丙（红）、h_甲、h_乙、h_丙。
  → 右侧面板标题“初始压强分析”，展示公式 P_丙 = P₀ + ρg(h_甲 − h_丙) > P₀ 与 P_乙 = P_丙，文字提示M处上方受P₀、下方水柱与乙内气压关联。
- 步骤2（打开开关M）：
  → 开关M由红(#c62828)变绿(#2e7d32)。
  → 竖直管内M上方（y=30~65）出现蓝色水柱，以CSS动画从height=0增长到height=35px，持续0.6s，ease-out；配合管内向上蓝色箭头。
  → 右侧面板标题“打开开关M”，提示“乙内气压大于大气压，水被压入竖直管”。
  → 隐藏步骤1的h_甲、h_乙、h_丙及大部分高亮衬底（保留竖直管高亮）。
- 步骤3（液面与体积变化）：
  → 乙液面原虚线(y=210)保留，新增末态实线(y=230，#1565c0)；乙水填充更新为y=230~240；乙气填充更新为y=160~230；乙容器右侧显示绿色“+ΔV_乙”；乙内画向下箭头(310,212)→(310,228)。
  → 丙液面原虚线(y=320)保留，新增末态实线(y=310，#1565c0)；丙水填充更新为y=310~360；丙气填充更新为y=280~310；丙容器右侧显示红色“−ΔV_丙”；丙内画向上箭头(310,318)→(310,312)。
  → 右侧气体连通管以透明度0.5→0.2→0.5的轻微呼吸动画暗示气体膨胀/收缩。
  → 右侧面板标题“液面与体积变化”，文字描述乙液面下降、丙液面上升。
  → 隐藏步骤2的竖直管水柱与箭头。
- 步骤4（最终平衡与结论）：
  → 显示最终液面位置（乙y=230、丙y=310），标注h_乙末(335,235)、h_丙末(335,315)。
  → 隐藏+ΔV_乙、−ΔV_丙及液面变化箭头。
  → 右侧面板标题“最终平衡与结论”，展示逻辑链：P_总减小 → 玻意耳定律V_总增大 → ΔV_乙 − ΔV_丙 > 0 → ΔV_乙 > ΔV_丙；底部高亮显示正确选项A（背景#ffeb3b衬底）。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「◀ 上一步」按钮：位于(290,452)，宽100×高36；点击回退到前一步，步骤0时disabled（透明度0.4）。
  2. 「下一步 ▶」按钮：位于(410,452)，宽100×高36；点击前进到后一步，步骤4时disabled。
- 教师操作流程：
  1. 教师加载图示，默认步骤0，让学生观察装置结构，确认甲、乙、丙位置及三条管路连接关系。
  2. 点击「下一步」进入步骤1，讲解初始压强平衡，配合左侧高亮看液体连通管，配合右侧高亮看气体连通管，读右侧面板公式 P_丙 = P₀ + ρgΔh。
  3. 点击「下一步」进入步骤2，观察开关变绿、竖直管内水柱上升动画，建立“乙内气压大于大气压”的直观印象。
  4. 点击「下一步」进入步骤3，观察乙液面下降（虚线保留对比）、丙液面上升，配合ΔV标注和箭头方向，理解体积迁移。
  5. 点击「下一步」进入步骤4，阅读右侧面板逻辑链，确认ΔV_乙 > ΔV_丙，高亮选项A。若学生有疑问，可随时点击「上一步」回退到对应阶段复习。

[技术实现]
- JS库选择：原生 SVG + 原生 JavaScript。理由：本场景以静态几何图形、分步显隐、简单CSS动画为主，无需复杂数据绑定或3D渲染；原生方案加载最快，与SVG DOM操作最直接。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图（ASCII）：
  ```
  0    220    320    350   520   530        780   800
  +------+------+------+-----+-----+----------+-----+  0
  |      |  甲  |      |     |     | 右侧面板 |     |  20
  | 大气 |~~~~~~|      |     |     | 标题/公式|     |  60
  |      |  竖  |      |右侧 |     |          |     | 120
  |      |  直  |  乙  |气管 |     |          |     | 160
  |      |  管  |~~~~~~|     |     |          |     | 210
  |      |      |      |     |     |          |     | 240
  |      |  丙  |      |     |     |          |     | 280
  |      |~~~~~~|      |     |     |          |     | 320
  |      |      |      |     |     |          |     | 360
  ```

- 关键实现要点：
  1. 状态机设计：维护变量 `currentStep`（0~4）。`updateStep(n)` 函数先隐藏所有带 `data-step` 属性的元素，再显示 `data-step="n"` 的元素，并更新右侧面板 HTML 内容。
  2. 元素显隐：所有步骤专属 SVG 元素（标签、高亮衬底、箭头、末态液面）初始 `display: none`；通过 JS 设置 `display: block` 或 `visibility: visible` 切换。避免使用 opacity 0 造成鼠标事件残留。
  3. 步骤2动画：竖直管 M 上方水柱使用 SVG `<rect id="scene1-water-rise" x="298" y="30" width="4" height="0"/>`，步骤2进入时添加 CSS 类 `.rise-animate { transition: height 0.6s ease-out; height: 35px; }`。向上箭头使用 SVG `<marker>` 定义 arrowhead。
  4. 步骤3液面变化：乙/丙的末态液面线、新水/气填充 rect、箭头、ΔV 标签统一绑定 `data-step="3"`。初始液面虚线始终显示（步骤3不隐藏），形成新旧对比。
  5. 步骤3气体管呼吸动画：使用 CSS `@keyframes breathe { 0%,100%{opacity:0.5} 50%{opacity:0.2} }`，步骤3时给右侧气体连通管添加动画类。
  6. 右侧面板：使用绝对定位的 HTML div 覆盖在 SVG 上方（`position: absolute; left:530px; top:20px; width:250px; height:410px`），便于排版多行文字与公式。面板内容随步骤切换整体替换 innerHTML。
  7. 按钮状态：步骤0时 `scene1-btn-prev.disabled = true`；步骤4时 `scene1-btn-next.disabled = true`。
  8. 事件绑定：按钮点击绑定 `updateStep(currentStep ± 1)`。所有事件监听器在 IIFE 内注册，避免全局污染。
- ID命名规范：所有 SVG/JS 交互元素 ID 必须以 `scene1-` 为前缀。例如：`scene1-container-jia`、`scene1-valve-m`、`scene1-water-rise`、`scene1-highlight-left`、`scene1-label-p0`、`scene1-btn-prev`、`scene1-btn-next`、`scene1-panel`。
- IIFE隔离：全部 JavaScript 包裹在 `(function() { ... })()` 中，内部变量与函数不暴露全局作用域，确保多场景合并时无交叉污染。
