[图示主题与整合说明]
- 本图示主题：凸透镜成倒立缩小实像的光路分析（含选项A验证）
- 整合的步骤/概念：题目装置展示 → 平行于主光轴的特殊光线绘制 → 过光心的特殊光线绘制 → 两条折射光线交点确定像的位置 → 物距/像距范围高亮与成像性质标注 → 蜡烛变短时像向上移动的动态验证
- 教学价值：教师可按照光路图的认知顺序逐步呈现，避免一次性展示全部信息造成学生视觉过载；分步演示特殊光线的作图法，强化"两条光线确定像点"的作图技能；最后通过动态箭头直观验证"倒立→物下移则像上移"，帮助学生理解选项A的正确性。

[视觉元素清单]
- 主光轴：水平虚线，贯穿画面中央 y=250，#888888，stroke-dasharray
- 凸透镜：垂直粗线段 x=400, y=210~290，#000000，stroke-width=4，象征凸透镜
- 蜡烛（物侧）：蓝色 #1565c0，烛身为矩形，烛焰为泪滴形 path，底部在光轴上，顶部 y=180，物高 70px
- 光屏：垂直矩形框 x=550~580, y=190~310，#000000，表示承接实像的光屏
- 焦点/光心标记：绿色 #2e7d32 实心圆 r=6，分别位于左2F(200,250)、左F(300,250)、O(400,250)、右F(500,250)、右2F(600,250)
- 特殊光线①（步骤1）：蓝色入射光线水平向右，红色折射光线从透镜顶端出发经过右焦点到达像点(567,297)，两端带箭头
- 特殊光线②（步骤2）：蓝色入射光线从烛焰顶端过光心直达像点，两端带箭头
- 倒立实像（步骤3）：红色 #c62828 倒立烛焰，位于光屏上，像高 47px（缩小），像点精确坐标由透镜公式计算得出
- 物距/像距高亮（步骤4）：光轴上下各 15px 的半透明带状矩形，物距区蓝色 15% 透明度，像距区红色 15% 透明度
- 移动箭头（步骤5）：蓝色向下箭头表示蜡烛缩短（物点下移），红色向上箭头表示像点同步上移
- 标签：仅点名（O、F、2F）、器件名（蜡烛、凸透镜、光屏）、数值范围（u>2f、f<v<2f）、性质（倒立·缩小·实像）、结论（物下移→像上移）
- 配色严格沿用 scene_outline 规格，不新增颜色

[分步序列]
- 初始状态（步骤0）「题目装置」：显示主光轴、凸透镜、蜡烛、光屏、五个绿色标记点（左2F、左F、O、右F、右2F）及全部常驻标签。此时光路尚未画出，光屏上无像。教师可在此介绍实验装置各部件名称及位置关系，提问学生物距与像距的大致范围。
- 步骤1「特殊光线①」：新增蓝色入射光线（蜡烛顶端水平射向透镜）和红色折射光线（经透镜后过右焦点射向光屏）。教师讲解"平行于主光轴的入射光线，折射后必过焦点"。
- 步骤2「特殊光线②」：新增蓝色入射光线（从蜡烛顶端过光心O直达光屏）。教师讲解"过光心的光线传播方向不变"。
- 步骤3「确定像点」：两条折射光线交点处出现红色倒立烛焰像（比原蜡烛小）。教师强调"两条折射光线的交点就是像点"，并引导学生观察像的倒立、缩小特征。
- 步骤4「标注范围」：物距区域（蜡烛到透镜）高亮蓝色半透明填充，标注"u > 2f"；像距区域（透镜到光屏）高亮红色半透明填充，标注"f < v < 2f"；光屏右侧标注"倒立、缩小、实像"。教师总结成像规律，对应选项C的辨析（此装置是照相机原理，非投影仪）。
- 步骤5「验证A选项」：蜡烛顶端旁出现蓝色向下箭头（表示蜡烛越烧越短，物点下移），像点旁出现红色向上箭头（表示像上移），画面下方标注"物下移→像上移"。教师据此验证选项A正确，并说明B（蜡烛靠近透镜像变大）、C（投影仪成放大像）、D（光屏应粗糙）的错误原因。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「上一步」按钮：位于控件区左侧 (310,460)，宽70px，高28px，圆角矩形，背景#1565c0，文字白色。点击后退一个步骤，步骤0时禁用（透明度降低）。
  2. 「步骤指示器」：位于 (400,445)，显示"步骤 X/6"，灰色小字，居中。
  3. 「下一步」按钮：位于控件区右侧 (420,460)，宽70px，高28px，样式同上。点击前进一个步骤，步骤5时禁用。
- 教师操作流程：
  1. 教师打开图示，默认显示步骤0（装置图），向学生介绍实验装置。
  2. 点击「下一步」依次呈现两条特殊光线，讲解作图原理。
  3. 继续点击「下一步」呈现像点、范围标注，总结成像规律。
  4. 最后一步呈现A选项验证，用箭头动态说明物像移动关系。
  5. 可随时点击「上一步」回退到任意步骤复习。

[技术实现]
- JS库选择：原生 SVG（简单几何与光路图首选，无需引入外部库，marker箭头、path火焰、半透明填充均可原生实现）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  800×500 画布
  +--------------------------------------------------------+
  |  蜡烛标签(130,160)          光屏标签(545,170)           |
  |     [蜡烛]        [凸透镜]        [光屏]                |
  |      ↑               |              ↑                  |
  |  左2F  左F    O    右F  右2F  ← 主光轴 y=250           |
  |  (标记点均在光轴上，标签在下方y=270分散排列)            |
  |                                                        |
  |  步骤4标注: u>2f(220,220)  f<v<2f(460,220)             |
  |            倒立缩小实像(630,250)                       |
  |  步骤5标注: 物下移→像上移(400,350)                     |
  |                                                        |
  |  --------------------------------------------------    |
  |              [◀上一步]  步骤 X/6  [下一步▶]            |  y=440~490 控件区
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：变量 `currentStep` 取值 0~5，初始化 0。`render()` 函数根据 `currentStep` 遍历所有步骤相关元素，设置 `opacity` 为 1 或 0。使用 CSS `transition: opacity 0.3s` 实现淡入淡出。
  2. 坐标计算：像点坐标严格按透镜公式计算。物距 u=250px（蜡烛x=150，透镜x=400），焦距 f=100px（F距透镜100px），像距 v=uf/(u-f)=166.67px，像点 x=566.67px；放大率 m=v/u=0.667，像高 46.67px，像顶端 y=296.67px。所有光线均通过此精确坐标，确保折射光线①严格经过右焦点(500,250)。
  3. 箭头实现：使用 SVG `<marker>` 定义蓝色和红色箭头头部，分别绑定到光线线段的 `marker-end`。
  4. 蜡烛/烛焰与像的绘制：使用 `<path>` 绘制泪滴形火焰，像为同一 path 的垂直翻转+缩小+红色版本。
  5. 事件绑定：按钮绑定 `click` 事件，修改 `currentStep` 后调用 `render()`，并更新按钮禁用状态与步骤指示器文字。
- ID命名规范：所有交互元素与SVG元素ID必须以 `scene1-` 为前缀。例如：`scene1-axis`、`scene1-lens`、`scene1-ray1-incident`、`scene1-ray1-refracted`、`scene1-image`、`scene1-highlight-u`、`scene1-btn-prev`、`scene1-btn-next`、`scene1-step-indicator`。JS中严格使用 `document.getElementById` 获取元素，禁止全局 class 选择，避免多场景合并时跨场景污染。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，变量不泄露全局作用域。
