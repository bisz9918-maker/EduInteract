**题目原文**

如图所示，在拉力F作用下，物体A在水平桌面上以速度υ向右匀速运动了距离S，已知A的重力为G，桌面对A的摩擦力为f（滑轮及绳重不计）。则下列说法不正确的是（  ）

A、有用功为GS
B、拉力做功为3FS
C、拉力做功的功率为3Fυ
D、装置的机械效率为$\\frac{f}{3F}$

**题目分析**

本题考查水平滑轮组的有用功、总功、功率及机械效率。关键在于：
1. 正确判断承担摩擦力的绳子段数 $n=3$；
2. 理解水平滑轮组中有用功是克服摩擦力做的功 $W_{有}=fS$，而非重力相关的功；
3. 绳端移动距离为物体移动距离的3倍，即 $s_{绳}=3S$；
4. 利用 $W_{总}=Fs_{绳}$、$P=Fv_{绳}$、$\\eta=\\frac{W_{有}}{W_{总}}$ 进行推导。

**整体讲解思路**

建议按"结构分析→运动关系→功与功率→机械效率→选项判断"的顺序讲解。先通过图示帮助学生建立 $n=3$ 的直观认识，再逐步推导各物理量，最后对比选项得出结论。

**图示规划说明**

- 图示1：滑轮组结构及运动关系（数绳子段数、位移与速度关系）
- 图示2：功、功率与机械效率的综合推导（有用功判定、总功计算、效率公式）

**教学说明：滑轮组结构分析**

教师应引导学生按以下顺序观察：

1. **识别装置类型**：首先明确这是"水平滑轮组"，与竖直滑轮组（提升重物）的区别在于：这里的"阻力"是摩擦力f，而不是重力G。

2. **数绳子段数**：让学生观察连接动滑轮和物体的绳子段数。从固定端（墙）开始，逐段追踪绳子路径，确认直接承担拉力的绳子有3段，因此 $n=3$。强调：数绳子段数时，只看连接动滑轮（或物体）的段数，定滑轮只改变方向不改变段数。

3. **建立运动关系**：由于 $n=3$，绳端移动距离是物体移动距离的3倍，即 $s_{绳}=nS=3S$；同理，绳端速度是物体速度的3倍，即 $v_{绳}=n\\upsilon=3\\upsilon$。这是后续计算总功和功率的基础。

4. **常见误区提醒**：学生容易将竖直滑轮组的思维定势带过来，误认为水平滑轮组也与重力G直接相关。此处应强调：物体在水平方向运动，竖直方向受力平衡，重力G与支持力平衡，但重力不做功。

**教学说明：功、功率与机械效率推导**

教师应引导学生按以下逻辑链进行推导：

1. **判定有用功**：提问"什么力在阻碍物体运动？"——摩擦力f。因此有用功是克服摩擦力做的功：
   $$W_{有} = f \\cdot S = fS$$
   紧接着追问"重力G做功吗？"——重力方向竖直向下，位移方向水平向右，两者垂直，所以重力做功为0。因此选项A（有用功为GS）是错误的。这是本题的核心陷阱。

2. **计算总功**：绳端移动距离 $s_{绳} = 3S$（由Scene 1已得），所以：
   $$W_{总} = F \\cdot s_{绳} = F \\cdot 3S = 3FS$$
   选项B正确。

3. **计算功率**：利用 $P = \\frac{W_{总}}{t}$，且 $\\frac{S}{t} = \\upsilon$（物体速度），则绳端速度为 $3\\upsilon$，因此：
   $$P = \\frac{3FS}{t} = F \\cdot 3\\upsilon = 3F\\upsilon$$
   选项C正确。

4. **推导机械效率**：
   $$\\eta = \\frac{W_{有}}{W_{总}} = \\frac{fS}{3FS} = \\frac{f}{3F}$$
   选项D正确。

**课堂讲解建议**

- 重点突破：学生最容易错选A，原因是将竖直滑轮组的"有用功=Gh"惯性迁移到水平情景。教师应通过图示强调"有用功取决于实际目的"——本题目的是让物体水平运动，所以有用功与水平方向的摩擦力相关，与竖直方向的重力无关。
- 公式对比：建议教师在黑板上（或图示旁）并列写出竖直滑轮组和水平滑轮组的公式对比，帮助学生建立清晰的知识网络。
- 互动提问：在展示Scene 2步骤1时，先不揭示答案，让学生判断"有用功是GS还是fS"，制造认知冲突后再揭示正确答案。

**完整解答**

由图可知，承担摩擦力的绳子段数 $n=3$。

- 有用功：$W_{有} = fS$（克服摩擦力做功），故A错误。
- 总功：$W_{总} = F \\cdot 3S = 3FS$，故B正确。
- 功率：$P = \\frac{W_{总}}{t} = \\frac{3FS}{t} = 3F\\upsilon$，故C正确。
- 机械效率：$\\eta = \\frac{W_{有}}{W_{总}} = \\frac{fS}{3FS} = \\frac{f}{3F}$，故D正确。

本题选 **A**。
