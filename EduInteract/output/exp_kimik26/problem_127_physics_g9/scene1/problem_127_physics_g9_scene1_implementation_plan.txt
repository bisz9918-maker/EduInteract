[图示主题与整合说明]
- 本图示主题：平行平面玻璃砖的完整折射光路原理
- 整合的步骤/概念：
  1. 入射光线与法线的建立；
  2. 空气→玻璃的第一次折射（向法线偏折）；
  3. 光在玻璃内部的直线传播；
  4. 玻璃→空气的第二次折射（远离法线偏折）；
  5. 侧向位移的标注与出射光∥入射光结论；
  6. 两次折射的角度关系总结。
- 教学价值：教师通过分步导航控制讲解节奏，从入射到出射逐步揭示光路规律，可随时回退复习关键步骤，帮助学生建立“入射光∥出射光+侧向位移”的核心结论。

[分步序列]
- 初始状态（步骤0）：显示矩形玻璃砖、空气中的入射光线（带箭头）、上表面第一条法线N1（虚线）。其余元素隐藏。结论框隐藏。
- 步骤1：点击「下一步」→ 高亮入射角∠i（红色弧线出现），标注"界面①"、"空气"（上）、"n_空"。教师讲解入射光线与法线夹角为入射角。
- 步骤2：点击「下一步」→ 绘制第一次折射光线（进入玻璃，从(380,160)到(416,260)），折射角∠r₁ < ∠i（红色弧线出现），光线向法线偏折；标注"玻璃"、"n_玻"、"∠r₁"。教师讲解光从光疏→光密介质向法线偏折。
- 步骤3：点击「下一步」→ 延长玻璃内光线至下表面（已自然到达），绘制下表面第二条法线N2（虚线出现）；标注"界面②"。教师讲解玻璃内直线传播至第二个界面。
- 步骤4：点击「下一步」→ 绘制第二次折射光线（射出玻璃，从(416,260)到(486,380)），折射角∠r₂ > ∠r₁（红色弧线出现），光线远离法线偏折；标注"空气"（下）、"∠r₂"。教师讲解光从光密→光疏介质远离法线偏折，且出射光与入射光平行。
- 步骤5：点击「下一步」→ 绘制入射光延长线（虚线，从(380,160)经(450,260)至(486,320)），绘制侧向位移双箭头（绿虚线，(451,320)-(468,310)），标注"d"；结论框显示文字"入射光 ∥ 出射光"（高亮）。教师讲解侧向位移概念。
- 步骤6：点击「下一步」→ 结论框更新为完整公式"n_空·sin i = n_玻·sin r₁ = n_空·sin r₂" 与 "入射光 ∥ 出射光，存在侧向位移 d"，结论框边框加粗高亮。教师总结两次折射定律关系。
- 教师可随时点击「上一步」回退复习，点击「重置」回到步骤0。

  4. 讲解结束后点击「重置」可重新开始新一轮讲解

[技术实现]
- JS库选择：原生 SVG + 原生 JavaScript。原因：本场景为简单几何图形（线段、矩形、弧线、文本），无需复杂坐标系或3D，原生SVG性能最优且控制精确。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |  n_空                                              |
  |     \ 入射光                                       |
  |      \    空气  界面①                             |
  |       \∠i  |                                       |
  |        \   | N1                                    |
  |         \  |    玻璃                               |
  |  +-------P1|--------P2----------+                 |
  |  |        | \      |            |                 |
  |  |        |  \∠r₁  | N2         |                 |
  |  |        |   \    |            |                 |
  |  |        |    \   |            |                 |
  |  +--------|-----\--|------------+                 |
  |           |      \∠r₂  空气                      |
  |           |       \    界面②                     |
  |           |        \ 出射光                      |
  |           | 延长线  \                            |
  |           |          \                           |
  |           +--d--------+                          |
  |                                                  |
  |     [ 入射光 ∥ 出射光，存在侧向位移 d ]          |
  |                                                  |
  |        [上一步] [下一步] [重置]                  |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `currentStep`（0-6），每步对应一个显示元素集合。定义 `stepElements` 数组，每个元素记录该步应显示/隐藏的SVG元素ID列表。
  2. 坐标计算：入射角约30°（cos⁻¹(120/√(70²+120²))），折射角约19.6°（由斯涅尔定律 n=1.5 计算），玻璃内光线终点(416,260)由 100×tan(19.6°)≈36px 水平偏移确定。出射光与入射光方向向量相同(70,120)，确保视觉平行。
  3. 动画曲线：元素出现使用 CSS transition opacity 0→1，时长 300ms，ease-out。光线绘制使用 SVG stroke-dasharray + stroke-dashoffset 动画，时长 500ms，模拟光线"射出"效果。
  4. 事件绑定：按钮点击事件更新 `currentStep`，调用 `renderStep()` 函数，该函数遍历所有交互元素，根据当前步骤设置 `display` 或 `opacity` 属性。
  5. 箭头标记：使用 SVG `<marker>` 定义箭头，id="scene1-arrow"，应用于所有光线线段。
  6. 角度弧线：使用 SVG `<path>` 绘制圆弧，通过 `d="M x y A r r 0 0 1 x2 y2"` 实现。
- ID命名规范：所有交互元素ID必须以 `scene1-` 为前缀。例如：
  - 玻璃砖：scene1-glass-block
  - 入射光：scene1-ray-incident
  - 法线N1：scene1-normal-1
  - 法线N2：scene1-normal-2
  - 玻璃内光线：scene1-ray-internal
  - 出射光：scene1-ray-exit
  - 入射光延长线：scene1-ray-extended
  - 侧向位移：scene1-displacement
  - 角度弧线i：scene1-angle-i
  - 角度弧线r1：scene1-angle-r1
  - 角度弧线r2：scene1-angle-r2
  - 标签：scene1-label-air-top、scene1-label-glass、scene1-label-d 等
  - 结论框：scene1-conclusion-box
  - 按钮：scene1-btn-prev、scene1-btn-next、scene1-btn-reset
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })()` 中，避免全局命名空间污染，确保多场景合并时互不干扰。
