[图示主题与整合说明]
- 本图示主题：正三棱柱晶胞的三维结构与微粒分布
- 整合的步骤/概念：正三棱柱线框展示 → A（顶点）位置标注 → B（棱上）位置标注 → C（内部）位置标注 → 整体分布确认与图例说明
- 教学价值：教师通过分步导航依次揭示三种微粒的位置，配合拖拽旋转从不同角度观察空间分布，帮助学生建立晶胞的三维空间感，最终理解 A:B:C = 1:4:2 的数目比例

[分步序列]
步骤0（初始状态）：
- 显示：正三棱柱线框（上底面实线、下底面虚线、3条侧棱实线）
- 隐藏：所有微粒及标签
- 图例框：显示但图例项置灰（opacity 0.3）
- 提示文字："正三棱柱晶胞 — 拖拽旋转观察结构"
- 按钮：「上一步」禁用，「下一步」可用

步骤1（顶点微粒 A）：
- 变化：6个A微粒（蓝色大球）及"A"标签出现，A微粒高亮（emissive #1565c0，intensity 0.4，scale 1.15）
- 图例框：A项高亮（opacity 1），B/C项置灰
- 提示文字："步骤 1/4：顶点微粒 A × 6（每个被6个晶胞共享）"
- 按钮：「上一步」「下一步」均可用

步骤2（棱上微粒 B）：
- 变化：A微粒恢复普通状态（scale 1.0，无emissive）；9个B微粒（红色小球）及"B"标签出现，B微粒高亮（emissive #c62828，intensity 0.4，scale 1.15）
- 图例框：B项高亮，A/C项置灰
- 提示文字："步骤 2/4：棱上微粒 B × 9（侧棱×3 + 底面棱×6）"
- 按钮：「上一步」「下一步」均可用

步骤3（内部微粒 C）：
- 变化：B微粒恢复普通状态；2个C微粒（绿色空心圆）及"C"标签出现，C微粒高亮（Sprite scale 1.2，添加绿色 drop-shadow）
- 图例框：C项高亮，A/B项置灰
- 提示文字："步骤 3/4：内部微粒 C × 2（上下两点，投影可能重合）"
- 按钮：「上一步」「下一步」均可用

步骤4（整体分布与结论）：
- 变化：所有微粒同时显示，均恢复普通状态，无高亮；图例框三项全部高亮（opacity 1）
- 提示文字："步骤 4/4：晶胞中 A:B:C = 1:4:2"
- 按钮：「上一步」可用，「下一步」禁用

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）+ 连续拖拽旋转
- 控件说明：
  1. 「上一步」按钮 (295,458)：回退到上一分步，步骤0时禁用
  2. 「下一步」按钮 (410,458)：前进到下一分步，步骤4时禁用
  3. 画布拖拽：鼠标按下并移动时，相机绕原点旋转（水平移动改变方位角，垂直移动改变极角，极角限制在15°~165°避免翻转到底部）
- 教师操作流程：
  1. 加载后展示步骤0，教师可拖拽旋转让学生观察三棱柱整体形状
  2. 点击「下一步」进入步骤1，揭示顶点A，讲解顶点共享
  3. 点击「下一步」进入步骤2，揭示棱上B，讲解棱上微粒分布
  4. 点击「下一步」进入步骤3，揭示内部C，强调上下两点投影重合现象
  5. 点击「下一步」进入步骤4，展示全部微粒与比例结论 1:4:2
  6. 可随时点击「上一步」回退复习，任何步骤均可拖拽旋转观察

[技术实现]
- JS库选择：Three.js（r160，CDN）+ 原生鼠标事件实现拖拽旋转。不引入 OrbitControls 以减少模块依赖，自行实现球坐标相机旋转（代码量<50行）。使用 CSS2DRenderer（Three.js 内置 examples/jsm/renderers/CSS2DRenderer.js）渲染 HTML 标签跟随 3D 物体。
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +----------------------------------------+
  |         步骤提示（顶部中央）              |
  |                                        |
  |      [3D正三棱柱模型，可拖拽旋转]         |
  |                                        |
  |                    [图例框 右下角]       |
  |                                        |
  |         [◀ 上一步] [下一步 ▶]           |  ← y=458，控件区
  +----------------------------------------+
  ```
- 关键实现要点：
  1. 状态机：currentStep 变量 0~4，数组 stepConfig 定义每步的 visibleGroups、highlightGroups、tipText、buttonStates
  2. 相机旋转：鼠标拖拽时，根据 deltaX/deltaY 调整 spherical 坐标 theta（方位角）和 phi（极角），每帧更新 camera.position，camera.lookAt(0,0,0)
  3. 微粒高亮：高亮时设置 mesh.material.emissive = color, emissiveIntensity = 0.4, scale.set(1.15,1.15,1.15)；恢复时 emissiveIntensity = 0, scale.set(1,1,1)
  4. C微粒空心效果：创建 Canvas(64×64)，绘制白色填充圆+绿色边框，作为 SpriteMaterial 的 map，Sprite 始终面向相机（billboard 效果天然满足）
  5. 标签跟随：使用 CSS2DObject，将 div 元素绑定到对应 Sphere/Sprite 的 position，通过 CSS margin 实现屏幕偏移（如 margin-top: -20px）
  6. 图例框状态：通过 CSS opacity 控制置灰/高亮，步骤4时全部 opacity=1
  7. 下底面虚线：使用 LineDashedMaterial，dashSize=5, gapSize=5，渲染前调用 computeLineDistances()
- ID命名规范：
  - 步骤提示：scene1-step-text
  - 图例框：scene1-legend-box
  - 图例项：scene1-legend-a, scene1-legend-b, scene1-legend-c
  - 上一步按钮：scene1-btn-prev
  - 下一步按钮：scene1-btn-next
  - Canvas容器：scene1-container
- IIFE隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免多场景合并时全局变量污染
