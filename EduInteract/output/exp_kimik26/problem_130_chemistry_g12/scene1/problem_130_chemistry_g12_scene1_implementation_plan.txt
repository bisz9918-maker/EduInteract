[分步序列]
- 初始状态（步骤0）「基团与价键」：
  - 显示6张基团卡片（2行×3列），全部不透明
  - 显示标题"基团与价键"
  - 隐藏中心节点、组合区、标记、说明文字
  - 教师讲解每种基团的自由价键数

- 步骤1「确定分支点」：
  - 6张卡片保留，—CH—卡片（card-ch-1）高亮：边框线宽3px，加drop-shadow(#ef6c00, blur=8px)，其余5张opacity=0.3
  - 在中区显示—CH—中心节点（400,245）及三向插槽
  - 左侧显示说明文字S1/S2/S3
  - 教师强调：只有—CH—有3个自由键，必须作为骨架中心

- 步骤2「枚举五种组合」：
  - 6张卡片隐藏（opacity=0）
  - 中心节点缩小并上移至(400,160)，插槽同步调整
  - 在下区显示5种组合框（每组3个小图标），分别对应：
    ① CH₃+CH₃+Cl  ② CH₃+CH₃+CH₂  ③ CH₂+CH₂+Cl  ④ CH₂+CH₂+CH₃  ⑤ CH₃+CH₂+Cl
  - 显示组合编号L1~L5
  - 教师引导学生思考：从剩余5个基团选3个连接到—CH—，有哪些可能

- 步骤3「排除无效方案」：
  - 保留步骤2所有元素
  - 在5组组合上方显示标记：组合①红色叉号，其余4组绿色对勾
  - 组合①框叠加红色半透明遮罩（#c62828, opacity=0.15）
  - 底部显示说明气泡，解释排除理由：—CH—已连满（2个CH₃+1个Cl），剩余2个—CH₂—无法接入分子
  - 教师讲解：组合①虽然满足—CH—的三价，但剩余基团无法成链，分子不完整

- 步骤4「确认四种方案」：
  - 组合①隐藏（opacity=0），其编号和标记消失，说明气泡消失
  - 中心节点opacity降至0.4（退为背景参考）
  - 剩余4种组合保持原位，对勾保留
  - 在有效组合框内底部显示"一种结构"
  - 标题变为"四种有效方案"
  - 教师总结：因此答案为4种，对应选项C

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于(300,455)，宽80高32，点击回退到上一状态
  - 「下一步」按钮：位于(420,455)，宽80高32，点击前进到下一状态
  - 步骤指示器：位于(400,450)，显示当前步骤编号"步骤 X/5"
  - 步骤0时「上一步」禁用（opacity=0.4, pointer-events=none），步骤4时「下一步」禁用
- 教师操作流程：
  1. 教师打开图示，默认进入步骤0，讲解6种基团及其自由键数
  2. 点击「下一步」进入步骤1，高亮—CH—，说明其为唯一分支点
  3. 点击「下一步」进入步骤2，展示5种数学组合，让学生思考
  4. 点击「下一步」进入步骤3，揭示组合①的排除理由
  5. 点击「下一步」进入步骤4，确认4种有效方案，得出答案C
  6. 可随时点击「上一步」回退到任意步骤复习

[技术实现]
- JS库选择：原生SVG + 原生JavaScript（无外部库）。理由：本场景以静态几何图形和状态切换为主，不涉及复杂函数绘图、3D或数据可视化，原生SVG足以高效实现，且无需加载外部CDN资源。
- 画布尺寸：800 × 500 px（SVG viewBox="0 0 800 500"）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  [标题区 y=0~40]                                  |
  |  [卡片区 y=55~205]  6张基团卡片（步骤0-1）         |
  |  [中区 y=160~340]   中心节点+插槽（步骤1-4）       |
  |  [组合区 y=235~320] 5/4种组合框（步骤2-4）         |
  |  [提示区 y=350~405] 说明气泡（步骤3）              |
  |  [控件区 y=440~490] ◀上一步 | 步骤X/5 | 下一步▶   |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：定义常量STEP_COUNT=5，currentStep变量记录0~4。每次切换步骤时调用renderStep()函数，根据currentStep设置各元素的display/opacity属性。
  2. 元素显隐策略：使用SVG的`display`属性（none/block）控制完全隐藏，使用`opacity`控制半透明效果，配合CSS transition实现300ms淡入淡出。
  3. 坐标计算：所有坐标硬编码于SVG元素属性中，不依赖动态计算，确保代码agent可直接复制坐标值。
  4. 动画曲线：opacity变化使用CSS `transition: opacity 0.3s ease-in-out`。
  5. 事件绑定：按钮绑定click事件，调用prevStep()/nextStep()，内部做边界检查（currentStep>0和currentStep<4）。
  6. 组合内容渲染：5种组合的3个小图标分别用3个<rect>+<text>表示，步骤2一次性创建，后续通过display控制显隐。
  7. 对勾/叉号绘制：使用<path>绘制简单对勾和叉号路径，包裹在<g>中，通过display控制。
- ID命名规范：所有交互元素ID必须以`scene1-`为前缀。例如：
  - 卡片：`scene1-card-ch3-1`、`scene1-card-ch2-1`、`scene1-card-ch-1`、`scene1-card-ch3-2`、`scene1-card-ch2-2`、`scene1-card-cl-1`
  - 中心节点：`scene1-center-node`、`scene1-slot-left`、`scene1-slot-right`、`scene1-slot-bottom`
  - 组合框：`scene1-combo-1`~`scene1-combo-5`
  - 标记：`scene1-mark-1`~`scene1-mark-5`
  - 按钮：`scene1-btn-prev`、`scene1-btn-next`、`scene1-step-indicator`
  - 说明气泡：`scene1-bubble-invalid`
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })()` 中，避免全局变量污染，确保多场景合并时互不干扰。
