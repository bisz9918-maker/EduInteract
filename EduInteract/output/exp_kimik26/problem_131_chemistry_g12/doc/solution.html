完整题目

如图所示，将两烧杯用导线如图相连，Pt、Cu、Zn、C分别为四个电极，当闭合开关后，则以下叙述正确的是（　　）

A. C电极为电解池的阳极
B. Cu电极附近OH⁻浓度增大
C. Na⁺移向Pt电极
D. Pt电极上有O₂生成

题目分析

本题属于电化学综合题，核心在于判断两个烧杯分别构成原电池还是电解池，并正确判定四个电极的极性。

  1. 右侧烧杯为Zn、C插入稀H₂SO₄，Zn能与稀硫酸自发发生氧化还原反应，故右侧为原电池。
  2. 左侧烧杯为Pt、Cu插入NaCl溶液，本身不能自发进行氧化还原反应，但通过与右侧原电池串联获得电能，故左侧为电解池。
  3. 在原电池中，活泼金属Zn为负极（失电子），C为正极（得电子）。
  4. 电解池的阴极与原电池负极（Zn）相连，即Cu为阴极；电解池的阳极与原电池正极（C）相连，即Pt为阳极。

整体讲解思路

建议教师按"先判装置类型 → 再定电极极性 → 后写电极反应 → 最后验证选项"的顺序讲解。图示配合分为两大部分：第一部分帮助学生建立装置整体认知并判定电极极性；第二部分深入微观电极反应与离子迁移，并图示化验证四个选项。

步骤 1/6

本图示的教学说明

教师应引导学生按以下逻辑观察Scene 1：

  1. 首先观察右侧烧杯——Zn与稀H₂SO₄能自发反应，故右侧是原电池。Zn比C活泼，Zn失电子作负极，C作正极。
  2. 再观察导线连接——Cu通过开关与Zn相连，Pt通过电流表与C相连。因此Cu是电解池的阴极，Pt是电解池的阳极。
  3. 强调电子流向规律：电子从原电池负极（Zn）流出，经导线进入电解池阴极（Cu）；电子从电解池阳极（Pt）流出，经导线回到原电池正极（C）。电流方向与电子流向相反。

这是整道题的"突破口"，务必让学生先牢固掌握装置类型和电极极性，再进入微观反应分析。

步骤 1 / 8

本图示的教学说明

教师使用Scene 2时，建议按"先写反应 → 再看离子 → 最后验选项"的顺序讲解：

  1. 原电池反应：
  • 负极（Zn）：Zn - 2e⁻ → Zn²⁺（氧化）
  • 正极（C）：2H⁺ + 2e⁻ → H₂↑（还原）
  1. 电解池反应（NaCl溶液，Pt为惰性阳极，Cu为阴极）：
  • 阳极（Pt）：2Cl⁻ - 2e⁻ → Cl₂↑（Cl⁻比OH⁻更易放电）
  • 阴极（Cu）：2H₂O + 2e⁻ → H₂↑ + 2OH⁻（或理解为H⁺放电，剩余OH⁻）
  • 强调Cu电极附近OH⁻浓度增大，溶液碱性增强。
  1. 离子移动规律：
  • 电解池中，阳离子（Na⁺）向阴极（Cu）移动，阴离子（Cl⁻）向阳极（Pt）移动。
  • 原电池中，阳离子（H⁺）向正极（C）移动，阴离子（SO₄²⁻）向负极（Zn）移动。
  1. 选项验证要点：
  • A错：C是原电池正极，不是电解池阳极。
  • B对：Cu为阴极，H⁺放电后OH⁻浓度增大。
  • C错：Na⁺移向阴极Cu，不是Pt。
  • D错：Pt为惰性阳极，Cl⁻放电生成Cl₂，不是O₂（O₂一般在OH⁻放电或电解水时生成）。

完整解答：本题正确答案为 B。

课堂讲解建议：

  • 先让学生独立判断哪个是原电池、哪个是电解池，再展示Scene 1验证。
  • 强调"先定极性，再写反应"的解题程序，避免学生未判断极性就直接写反应。
  • 对于D选项，可补充说明：若阳极是惰性电极且溶液中无Cl⁻（如电解Na₂SO₄溶液），则可能是OH⁻放电生成O₂；但本题有Cl⁻且浓度较高，故生成Cl₂。
