[图示主题与整合说明]
- 本图示主题：原电池-电解池组合装置的电极极性判定
- 整合的步骤/概念：装置结构展示 → 闭合开关 → 原电池判定与极性标注 → 电解池判定与极性标注 → 电子流向与电流方向示意
- 教学价值：教师可通过分步导航，引导学生从宏观装置识别到微观电极反应，逐步建立"先找自发电池、再定电解池极性"的解题思维模型

[分步序列]
- 步骤0（初始状态）：显示完整串联装置，两个烧杯、四个电极、导线、电流表A、开关（断开状态）。显示基础标签：Pt、Cu、Zn、C、NaCl溶液、稀H₂SO₄、A、开关。溶液填充可见。
- 步骤1（闭合开关）：中间导线间隙消失，显示连通桥（开关闭合）。右侧烧杯出现绿色高亮边框，显示"原电池"标签（绿色）。提示右侧为自发氧化还原反应区域。
- 步骤2（原电池极性）：Zn电极描边变红（#c62828），显示"负极"标签（红色）在Zn左上方。C电极描边变蓝（#1565c0），显示"正极"标签（蓝色）在C右上方。
- 步骤3（电解池判定）：左侧烧杯出现绿色高亮边框，显示"电解池"标签（绿色）在左侧烧杯左方。提示左侧依靠外接电源驱动。
- 步骤4（电解池极性）：Pt电极描边变蓝（#1565c0），显示"阳极"标签（蓝色）在Pt左上方。Cu电极描边变红（#c62828），显示"阴极"标签（红色）在Cu右上方。
- 步骤5（电子与电流方向）：上方导线显示红色电子箭头（Pt→C，向右，y=130）及e⁻标签(430,125)；上方导线显示蓝色电流箭头（C→Pt，向左，y=150）及I标签(370,158)。中间导线显示红色电子箭头（Zn→Cu，向左，y=190）及e⁻标签(370,198)；中间导线显示蓝色电流箭头（Cu→Zn，向右，y=170）及I标签(430,165)。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：位于(280,455)，宽80高30，点击回退到上一状态
  - "下一步 ▶"按钮：位于(440,455)，宽80高30，点击推进到下一状态
  - 步骤指示文本：位于(380,475)，显示当前步骤编号如"步骤 1/6"
- 教师操作流程：
  1. 教师展示步骤0，让学生观察装置组成和开关断开状态
  2. 点击"下一步"进入步骤1，讲解右侧为原电池（自发反应）
  3. 点击"下一步"进入步骤2，标注Zn为负极、C为正极
  4. 点击"下一步"进入步骤3，讲解左侧为电解池（外接驱动）
  5. 点击"下一步"进入步骤4，标注Pt为阳极、Cu为阴极
  6. 点击"下一步"进入步骤5，用动画箭头展示电子和电流方向，总结规律
  7. 可随时点击"上一步"回退复习

[技术实现]
- JS库选择：原生SVG + 原生JavaScript（无外部库）。理由：本场景为静态几何图示与分步显隐，SVG路径和原生DOM操作足够，无需引入D3等重型库。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |                                                  |
  |      Pt ———— A ———— C         [上方导线 y=140]   |
  |       |          |                               |
  |      Cu — 开关 — Zn          [中间导线 y=180]    |
  |       |          |                               |
  |    +------+    +------+                          |
  |    |NaCl  |    |H₂SO₄ |     [烧杯 y=240~350]     |
  |    |Pt Cu |    |Zn  C |                          |
  |    +------+    +------+                          |
  |    NaCl溶液    稀H₂SO₄      [溶液标签 y=375]     |
  |                                                  |
  |  [◀上一步]  步骤 X/6  [下一步▶]  [控件 y=455~475]|
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量currentStep（0~5），共6个状态。每个状态对应一组元素的显隐配置。
  2. 元素显隐：所有可能动态显示的元素初始opacity=0（或display:none），通过CSS transition: opacity 0.3s ease实现平滑出现。
  3. 开关状态：步骤0显示两段分离的导线和间隙；步骤1+隐藏间隙，显示连通桥线段。
  4. 电极高亮：步骤2/4通过改变电极矩形的stroke属性（从none变为红/蓝，stroke-width=3）实现高亮。
  5. 烧杯高亮：步骤1/3显示包围烧杯的矩形框（fill=none, stroke=#2e7d32, stroke-width=3, rx=4）。
  6. 箭头绘制：使用SVG <path> 画带箭头的线段，箭头用marker-end定义。电子箭头红色，电流箭头蓝色。
  7. 事件绑定：上一步/下一步按钮绑定click事件，更新currentStep后调用updateScene()函数，该函数根据步骤号设置各元素的opacity和样式。
  8. 边界处理：上一步在currentStep=0时禁用，下一步在currentStep=5时禁用（按钮变灰）。
- ID命名规范：所有交互元素ID必须以scene1-为前缀，例如：
  - scene1-beaker-left, scene1-beaker-right
  - scene1-electrode-pt, scene1-electrode-cu, scene1-electrode-zn, scene1-electrode-c
  - scene1-wire-top, scene1-wire-mid-left, scene1-wire-mid-right
  - scene1-ammeter, scene1-switch-open, scene1-switch-closed
  - scene1-label-pt, scene1-label-negative, scene1-label-primary-battery 等
  - scene1-arrow-e-top, scene1-arrow-i-bottom 等
  - scene1-btn-prev, scene1-btn-next, scene1-step-text
  - JS中严格使用document.getElementById获取元素，禁止querySelectorAll配合全局class。
- IIFE隔离：所有JavaScript代码包裹在 (function() { ... })() 中，避免多场景合并时变量污染。
