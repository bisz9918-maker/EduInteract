[图示主题与整合说明]
- 本图示主题：三种笼状烃（正四面体烷A、正三棱柱烷B、立方烷C）的骨架结构与分子式推导
- 整合的步骤/概念：多面体顶点识别→碳原子数确定→氢原子数确定（每个顶点连1个H）→分子式书写→最简式比较→选项B和D的正误判断
- 教学价值：教师通过分步导航，引导学生从几何结构出发，利用"每个顶点对应1个碳原子、每个碳连1个氢"的规则推导分子式，进而判断选项正误。分步回退功能便于教师针对某一步骤重点讲解或复习。

[分步序列]
- 初始状态（步骤0）：显示三个线框多面体（A正四面体、B正三棱柱、C立方体），可见棱实线、被遮挡棱虚线。显示结构标签"A""B""C"。隐藏所有顶点圆点、数值标注和结论文本。教师可在此步骤引导学生观察三种笼状烃的空间骨架形状。
- 步骤1：点击「下一步」→ 18个顶点圆点以蓝色渐显（opacity 0→1, 200ms）。在三个结构下方分别显示蓝色文本"4个顶点""6个顶点""8个顶点"（fade-in, 200ms）。教师讲解：每个顶点代表1个碳原子，因此A含4个C、B含6个C、C含8个C。
- 步骤2：点击「下一步」→ 在顶点数下方显示分子式文本"C₄H₄""C₆H₆"C₈H₈"（黑色粗体，fade-in, 200ms）。教师讲解：笼状烃中每个碳原子只连1个氢原子（顶点只连1个H），因此氢原子数等于顶点数。
- 步骤3：点击「下一步」→ 在画面中部显示"最简式均为CH"（黑色粗体）。在右下区域显示选项D判断："D. 只有C为CH"（红色）+ 红色"✗"，下方显示"实际：A、B、C均为CH"（绿色）+ 绿色"✓"。教师讲解：三者最简式都是CH，因此选项D错误。
- 步骤4：点击「下一步」→ 在左下区域显示选项B判断："B. C₆H₁₂"（红色）+ 红色"✗"，下方显示"实际：C₆H₆"（绿色）+ 绿色"✓"。教师讲解：B的实际分子式是C₆H₆而非C₆H₁₂，因此选项B错误。
- 教师可随时点击「上一步」回退到任意步骤复习。上一步在步骤0时禁用，下一步在步骤4时禁用。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「◀ 上一步」按钮：位于SVG底部x=255,y=444，宽90×高32。点击后当前步骤减1，隐藏当前步骤特有的视觉元素，显示上一步的内容。步骤0时禁用。
  2. 「下一步 ▶」按钮：位于SVG底部x=455,y=444，宽90×高32。点击后当前步骤加1，显示下一步特有的视觉元素。步骤4时禁用。
  3. 步骤指示器：位于SVG底部x=400,y=485，显示"步骤 X / 5"，居中。
- 教师操作流程：
  1. 教师打开图示，学生看到三种笼状烃的线框结构（步骤0）。教师提问：观察这三种结构，它们分别是什么多面体？
  2. 教师点击「下一步」，顶点圆点和顶点数出现（步骤1）。教师引导学生数顶点，得出C原子数。
  3. 教师点击「下一步」，分子式出现（步骤2）。教师讲解每个顶点连1个H，推导分子式。
  4. 教师点击「下一步」，最简式和选项D判断出现（步骤3）。教师引导学生计算最简式，发现三者均为CH，判断D错误。
  5. 教师点击「下一步」，选项B判断出现（步骤4）。教师对比选项B给出的C₆H₁₂与实际C₆H₆，判断B错误。
  6. 教师可随时点击「上一步」回退，针对薄弱步骤重复讲解。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：本场景为静态线框几何图，无复杂动画、函数绘图或3D需求，原生SVG足以高效绘制多面体棱线、圆点和文本，无需引入外部库。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  0    100  200  300  400  500  600  700  800
  +----+----+----+----+----+----+----+----+----+
  |                    标题                      | 20
  |                                              | 50
  |      [A-四面体]    [B-三棱柱]    [C-立方体]  | 150
  |         /\           /\\                     | 180
  |        /  \         /  \\                    | 210
  |       /____\       /____\\                   | 240
  |                                              | 250
  |        A              B            C         | 260
  |      4个顶点       6个顶点        8个顶点     | 280
  |       C₄H₄         C₆H₆          C₈H₈       | 305
  |                                              | 320
  |           最简式均为 CH                       | 340
  |                                              | 360
  |  B.C₆H₁₂ ✗        D.只有C为CH ✗              | 380
  |  实际:C₆H₆ ✓      实际:均为CH ✓              | 405
  |                                              | 430
  |         [◀上一步]  步骤X/5  [下一步▶]         | 460
  |                                              | 490
  +----+----+----+----+----+----+----+----+----+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 `currentStep`（0~4）记录当前步骤。定义每个步骤的显示/隐藏元素列表。`renderStep()`函数根据currentStep设置对应元素的display属性（或opacity动画）。
  2. 坐标计算：所有顶点、棱线、标签坐标硬编码在SVG中（使用`<line>`, `<circle>`, `<text>`, `<polygon>`元素），无需动态计算。
  3. 动画曲线：步骤切换时使用CSS transition（opacity 0.2s ease-in-out）实现淡入淡出，避免突兀出现。
  4. 事件绑定：上一步/下一步按钮绑定click事件，更新currentStep后调用renderStep()，并更新按钮disabled状态和步骤指示器文本。
  5. 元素分组：使用`<g>`元素按步骤分组（如`<g id="scene1-step1-group">`），便于批量控制显示/隐藏。
  6. 下标处理：分子式中的下标数字（如C₄H₄）使用Unicode下标字符（₄, ₆, ₈, ₁₂）直接显示，避免引入MathJax。
- ID命名规范：所有交互元素ID必须以 `scene1-` 为前缀。例如：
  - 结构线框：`scene1-poly-A-solid`, `scene1-poly-A-dashed`
  - 顶点圆点：`scene1-vertex-A-1`, `scene1-vertex-B-1` 等
  - 文本标签：`scene1-label-A`, `scene1-label-vert-A`, `scene1-label-formula-A`
  - 选项判断：`scene1-label-optB-wrong`, `scene1-label-optB-check`
  - 按钮：`scene1-btn-prev`, `scene1-btn-next`
  - 分组：`scene1-group-step0`, `scene1-group-step1` 等
  - JS中获取元素严格使用 `document.getElementById()`，避免querySelectorAll跨场景污染。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免全局变量污染。
