[分步序列]
- 初始状态（步骤0）：显示正四面体线框（6条棱）、4个蓝色顶点圆点、4个顶点编号标签。右侧无结论文字。教师可在此介绍正四面体烷A的基本结构。
- 步骤1：点击「下一步」→ 顶点①处出现绿色大圆点（Cl原子）覆盖原蓝点，右侧显示"一氯代物：1种"（绿色）和"（4个顶点完全等价）"（灰色）。教师讲解：4个顶点完全等价，一氯代物只有1种。
- 步骤2：点击「下一步」→ 保持顶点①绿色Cl；顶点②③④处各出现红色大圆点（候选第二个Cl），并显示对应"Cl"标签；右侧显示"固定Cl在①，第二个Cl可在②③④"。教师引导学生思考：第二个Cl似乎有3种位置。
- 步骤3：点击「下一步」→ 显示旋转轴（竖直虚线x=300，从y=70到y=260）及"旋转轴"标签；显示底面外侧弧形箭头（从220,290经300,350到380,290）及"120°"标注；右侧显示"绕轴旋转120°"和"②→③→④ 完全等价"。教师讲解：绕通过顶点①和对面的轴旋转120°，②③④循环重合，三个位置完全等价。
- 步骤4（最终步骤）：点击「下一步」→ 移除旋转轴、弧形箭头、120°标注；移除顶点③④的红色圆点及标签（保留顶点②红色圆点表示唯一的二氯代物结构）；右侧显示"二氯代物：1种"（绿色粗体）和"选项A：二氯代物有两种 ✗"（红色）。教师总结：二氯代物只有1种，选项A错误。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：本场景为简单几何图形（线段、圆点、路径、文字），无需复杂图表库；原生SVG可精确控制每个元素的显隐和样式，性能轻量。
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  ①                                               |
  |  |\                                              |
  |  | \        右侧结论文字区                        |
  |  |  \       一氯代物：1种                         |
  | ④-②-③     二氯代物：1种                         |
  |    弧形箭头  选项A：有两种 ✗                      |
  |                                                  |
  |  [◀上一步]  1 / 5  [下一步▶]                     |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：定义常量 `const TOTAL_STEPS = 5;`，变量 `let currentStep = 0;`，范围0~4。每一步对应一个状态对象，记录应显示/隐藏的元素ID列表。
  2. 元素分组：使用SVG `<g>` 元素按步骤分组，如 `scene2-step1-group`、`scene2-step2-group` 等，通过设置 `display: none/block` 或 `opacity: 0/1` 切换。初始状态仅显示步骤0分组。
  3. 坐标计算：正四面体顶点坐标固定为 (300,90)、(200,260)、(400,260)、(300,190)。对面中心为 (300, 236.7)，旋转轴为竖直线 x=300。
  4. 动画曲线：步骤切换时，新增元素使用 CSS `transition: opacity 0.3s ease-in-out` 淡入；红色候选圆点（步骤2）可添加轻微缩放动画（scale 0→1）吸引注意力。
  5. 弧形箭头：使用 `<path d="M 220 290 Q 300 350 380 290" fill="none" stroke="#000" stroke-width="2" marker-end="url(#arrowhead)"/>`，在 `<defs>` 中定义箭头标记。
  6. 旋转轴标签"120°"：放在弧线中点正下方 (300,365)。
  7. 事件绑定：按钮点击事件更新 `currentStep`，调用 `renderStep()` 函数，该函数遍历所有步骤分组，根据当前步骤索引设置显隐。
  8. 按钮状态：步骤0时禁用「上一步」（opacity 0.4, pointer-events none）；步骤4时禁用「下一步」。
- ID命名规范：所有交互元素ID必须以 `scene2-` 为前缀。例如：`scene2-vertex-1`、`scene2-cl-green`、`scene2-cl-red-2`、`scene2-step-1-group`、`scene2-btn-prev`、`scene2-btn-next`、`scene2-step-indicator`。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免全局命名空间污染，确保多场景合并时互不干扰。
