    **题目原文**

    用如图所示装置分别进行如下实验，测定溶液导电性变化。以下哪个选项为导电性先增大后减弱的是（  ）

    A．向醋酸溶液中加入氨水
    B．向AgNO₃溶液中加入HCl
    C．向盐酸溶液中加入NaCl溶液
    D．向H₂SO₄溶液中加入BaCl₂溶液

    **题目分析**

    本题考查溶液导电性与离子浓度、离子所带电荷的关系。溶液的导电性取决于单位体积内自由移动离子的数目（离子浓度）以及离子所带电荷数。分析各选项时，需同时关注"反应前后电解质强弱的变化"和"溶液体积增大带来的稀释效应"两个因素。

    **整体讲解思路**

    1. 先通过装置图回顾实验原理，明确"灯泡亮度↔导电性↔离子浓度"的对应关系。
    2. 重点剖析选项A：弱酸与弱碱中和生成强电解质盐，再因过量弱碱稀释而导致导电性先增后减。
    3. 利用四条导电性变化曲线进行横向对比，用排除法快速定位正确答案。
    4. 总结规律：若反应由"弱电解质→强电解质"，导电性先增强；若持续加入弱电解质溶液，稀释效应占主导后导电性减弱，则出现"先增后减"。

    **本图示的教学说明（对应图示2）**

    本图示聚焦选项A的完整反应过程，教师应引导学生建立"微观离子变化—宏观灯泡亮度—定量曲线"的三重对应关系。

    讲解要点：
    1. **初始状态**：醋酸（CH₃COOH）是弱电解质，在水中仅部分电离，溶液中主要以分子形式存在，自由离子（CH₃COO⁻、H⁺）稀少，因此灯泡较暗，导电性弱。
    2. **加入氨水**：氨水（NH₃·H₂O）也是弱电解质。两者发生中和反应：CH₃COOH + NH₃·H₂O → CH₃COONH₄ + H₂O。生成的醋酸铵（CH₃COONH₄）是强电解质，在水中完全电离为CH₃COO⁻和NH₄⁺，溶液中离子浓度显著增大，灯泡明显变亮。
    3. **恰好中和**：此时溶液中溶质几乎全部转化为CH₃COONH₄，离子浓度达到最大值，灯泡最亮，导电性最强。
    4. **过量氨水**：继续加入氨水，由于氨水是弱电解质，电离程度很小，且溶液体积不断增大，离子浓度被稀释而下降，灯泡变暗，导电性减弱。
    5. **曲线总结**：导电性随加入氨水体积的变化呈"先上升后下降"的抛物线型（或倒U型），峰值出现在恰好中和点。

    关键公式：
    - 中和反应：CH₃COOH + NH₃·H₂O → CH₃COONH₄ + H₂O
    - 完全电离：CH₃COONH₄ → CH₃COO⁻ + NH₄⁺

    本图示用于四个选项的横向对比，帮助学生在同一坐标系下直观区分各选项的导电性变化趋势，强化排除法的应用。

    讲解要点：

    **总结：完整解答与课堂讲解建议**

    **正确答案：A**

    完整分析：
    1. **选项A**：醋酸为弱电解质，初始离子浓度低，导电性弱。加入氨水后生成醋酸铵（强电解质），离子浓度显著增大，导电性增强；恰好中和时达到峰值。继续加入氨水，弱电解质电离有限，稀释效应使离子浓度下降，导电性减弱。符合"先增大后减弱"。
    2. **选项B**：AgNO₃与HCl反应生成AgCl沉淀和HNO₃，反应前后均为强电解质溶液，离子浓度变化不大，导电性基本不变；若HCl过量，导电性反而增大。
    3. **选项C**：盐酸和NaCl均为强电解质，混合后离子浓度增加，导电性逐渐增大。
    4. **选项D**：H₂SO₄与BaCl₂反应生成BaSO₄沉淀和HCl，沉淀带走大量离子，且溶液体积不断增大，离子浓度逐渐降低，导电性减弱。

    **课堂讲解建议**：
    - 抓住核心判断依据：①反应前后电解质的强弱变化；②溶液体积变化引起的稀释效应。
    - 强调"弱电解质反应生成强电解质"是导电性增强的典型情景，而"过量加入弱电解质溶液"是导电性随后减弱的常见原因。
    - 建议将"恰好完全反应点"作为分析导电性变化的关键节点，帮助学生建立"反应进程—离子浓度—导电性"的三维分析框架。
