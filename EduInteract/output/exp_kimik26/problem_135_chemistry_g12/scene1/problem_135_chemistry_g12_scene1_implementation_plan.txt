[图示主题与整合说明]
- 本图示主题：溶液导电性实验装置与导电原理
- 整合的步骤/概念：
  1) 实验装置结构识别（电池、导线、灯泡、烧杯、电极、溶液）；
  2) 溶液导电的微观本质——离子定向移动（外电路电子流动 + 内电路离子迁移）；
  3) 影响导电性的两大因素：离子浓度与离子所带电荷。
- 教学价值：教师可先让学生观察装置，再逐步揭示“为什么溶液能导电”以及“导电性强弱由什么决定”，从宏观现象递进到微观本质，再上升到定量影响因素，符合认知顺序。

[技术实现]
- JS库选择：原生 SVG + 原生 JavaScript。理由：本场景以静态几何图形、路径、文本和显隐切换为主，无需复杂数据绑定或3D渲染，原生SVG足够轻量且可控。
- 画布尺寸：800 × 500 px（SVG viewBox="0 0 800 500"）。
- 布局草图（ASCII）：
  ```
  0    100  200  300  400  500  600  700  800
  +----+----+----+----+----+----+----+----+----+
  |         标题区(如有)                        |  y=0~40
  |    [电池]                                   |
  |      |                                      |
  |   [灯泡]         [烧杯/溶液/电极]     | 右侧原理区  |  y=40~430
  |      |               |                 | (步骤说明/   |
  |      +---------------+                 |  对比框)      |
  |                                        |              |
  |  左侧实验装置区(60%)                   |  右侧原理区(40%) |
  +----+----+----+----+----+----+----+----+----+
  |        [◀ 上一步]  [下一步 ▶]  步骤 X/3    |  y=440~500
  +----+----+----+----+----+----+----+----+----+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 `let currentStep = 0;` 维护当前步骤（0/1/2）。每次点击按钮时更新状态，调用 `renderStep()` 统一控制所有元素的显隐、样式与内容。
  2. 元素显隐：所有可能切换的元素均设置 `id`，通过 `document.getElementById('scene1-xxx').setAttribute('visibility', currentStep>=1 ? 'visible' : 'hidden')` 控制。禁止用 CSS class 批量切换，避免多场景合并时污染。
  3. 导线高亮：步骤1中通过 JS 修改导线元素的 `stroke` 为 `#1565c0`、`stroke-width` 为 3；回退时恢复为 `#000000`、2。
  4. 灯泡亮度：通过修改灯泡填充圆的 `fill-opacity`（0.3/0.8）实现；步骤1可额外添加 SVG `<filter>`（feGaussianBlur）制作弱发光效果，通过 `filter` 属性绑定/解绑控制。
