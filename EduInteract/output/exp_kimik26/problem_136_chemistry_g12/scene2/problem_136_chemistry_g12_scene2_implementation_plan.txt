[图示主题与整合说明]
- 本图示主题：碳四价规则与碳链键型逐步推导
- 整合内容：碳四价原理、逐键推导、单键与三键交替规律、①处键型判定（否定B）、②处键型判定（确认C）、③处原子成键数推断（否定D）
- 教学价值：教师通过分步导航，引导学生从分子左端开始，严格按碳四价规则逐步计算每个碳原子的剩余价键，亲眼见证"单键-三键交替"规律的形成，最终完成三个选项的判定。分步节奏可控，避免信息过载，适合课堂边讲边推。

[分步序列]
- 步骤0（初始状态）：展示完整碳链骨架H-C1-C2-C3-C4-C5-C6-C7-C8-C9-X，所有球之间用灰色#cccccc细线连接（表示待推导）。每个碳球（C1~C9）正上方显示灰色文字"需4键"。分析面板显示"从分子左端开始，利用碳四价规则逐步推导每个碳原子的键型"。四个选项卡片均显示为白底黑字，未判定。底部控件显示"步骤 0/7"。
- 步骤1（推导C1）：C1球外圈出现蓝色高亮圆（r=17px，描边#1565c0，线宽3px）。C1上方标签变为蓝色"已连1键，剩3价"。H-C1键变为黑色实线（单键，已确定）。C1-C2键变为蓝色三键（3条#1565c0线，线宽3px，当前推导）。C1上方标签更新为蓝色"4/4"。分析面板显示"C1已连接1个H原子（单键），剩余3个价键 → 与C2形成三键"。
- 步骤2（推导C2）：C2球外圈蓝色高亮。C2上方标签变为蓝色"已用3键，剩1价"。C1-C2键从蓝色变为黑色（已完成）。C2-C3键变为蓝色单键（当前推导）。C2上方标签更新为蓝色"4/4"。C1上方标签变为黑色"4/4"。分析面板显示"C2已用3键（与C1三键），剩余1个价键 → 与C3形成单键"。
- 步骤3（推导C3）：C3球外圈蓝色高亮。C3上方标签变为蓝色"已用1键，剩3价"。C2-C3键从蓝色变为黑色。C3-C4键（①处）变为蓝色三键。C3上方标签更新为蓝色"4/4"。C2上方标签变为黑色"4/4"。分析面板显示"C3已用1键（与C2单键），剩余3个价键 → 与C4形成三键（①处）"。
- 步骤4（自动推导C4~C9，展示规律）：依次快速高亮C4、C5、C6、C7、C8、C9（每碳0.4秒）。C4：已用3键剩1价→C4-C5单键，C4标"4/4"。C5：已用1键剩3价→C5≡C6三键，C5标"4/4"。C6：已用3键剩1价→C6-C7单键，C6标"4/4"。C7：已用1键剩3价→C7≡C8三键，C7标"4/4"。C8：已用3键剩1价→C8-C9单键（②处），C8标"4/4"。C9：已用1键剩3价→C9≡X三键，C9标"4/4"。所有键变为黑色，所有碳球上方显示黑色"4/4"。分析面板显示"规律：单键-三键交替出现，所有碳原子均满足四价"。
- 步骤5（判定①处，否定B）：①处化学键（C3≡C4）加蓝色外框高亮（在键线周围画矩形框或加粗发光）。从①处向下画#888888虚线引线至分析面板右侧放大区。放大区显示C3≡C4放大图（两球半径8px，三键线宽3px），旁标注"三键"。选项B卡片背景变为#c62828透明度20%，文字变#c62828，右侧标注"× 双键错误"。分析面板显示"①处实际为三键，不是双键 → 选项B错误"。
- 步骤6（判定②处，确认C）：②处化学键（C8-C9）加蓝色外框高亮。从②处向下画虚线引线至放大区。放大区显示C8-C9放大图（单键），旁标注"单键"。选项C卡片背景变为#2e7d32透明度20%，文字变#2e7d32，右侧标注"✓ 正确"。分析面板显示"②处为单键 → 选项C正确"。
- 步骤7（判定③处，否定D）：C9-X键加蓝色外框高亮。从X球向下画虚线引线至放大区。放大区显示C9≡X放大图（三键），旁标注"三键"。分析面板显示"C9剩余3价，与X形成三键。Cl/F只能形成单键 → 选项D错误。该分子含X原子，不属于烃类（A也错误）"。选项D卡片背景变红，文字变红，标注"× 只能单键"。选项A卡片也同步变红，标注"× 含X非烃"。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「上一步」按钮：位置(290,455)，宽90高32，灰色背景#e0e0e0，点击回退到上一状态，步骤0时禁用（透明度50%）。
  2. 「步骤指示」文本：位置(400,476)，显示当前步骤编号如"步骤 3/7"，黑色文字，居中。
  3. 「下一步」按钮：位置(480,455)，宽90高32，蓝色背景#1565c0，白色文字，点击前进到下一状态，步骤7时变为"重新开始"或禁用。
- 教师操作流程：
  1. 教师打开图示，学生看到完整碳链和"需4键"提示（步骤0）。
  2. 教师点击「下一步」，进入步骤1，讲解C1的成键情况，引导学生推导C1≡C2。
  3. 依次点击「下一步」，跟随推导C2、C3，观察单键-三键交替。
  4. 步骤4自动快速完成剩余推导，教师可点击「上一步」回到步骤3再进入步骤4，让学生预测C4的键型。
  5. 步骤5~7进行选项判定，教师可点击「上一步」回顾键型推导过程，强化逻辑链条。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript（无需外部库）。原因：本场景为简单的几何图形（圆、线、文本）和状态切换，原生SVG足以高效实现；动画通过CSS transition或requestAnimationFrame控制。
- 画布尺寸：800 × 500 px（SVG viewBox="0 0 800 500"）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------------+
  |                                                        |
  |   需4键  需4键  需4键 ... 需4键  需4键                  |  y=160

  |      H    C1    C2    C3    C4    C5    C6    C7    C8    C9    X    |  y=220
  |              ①              ②        ③                |  y=245

  |   +----------------------------------------------+     |  y=330
  ```

- 关键实现要点：
  1. 状态机设计：定义全局变量 `currentStep`（0~7），每次点击按钮时更新状态，调用 `renderStep()` 函数根据状态显示/隐藏/修改元素。
  2. 键线绘制：单键用1条`<line>`，三键用3条`<line>`（y坐标分别为中心y-3、y、y+3）。为每个键组包裹`<g>`，通过添加/移除class控制颜色（待推导gray、当前推导blue、已完成black）。
  3. 碳球高亮：在每个碳球`<circle>`上方叠加一个同心的`<circle class="highlight-ring">`，默认`opacity:0`，当前步骤时通过CSS设置为`opacity:1`，配合`transition: all 0.3s`实现平滑出现。
  4. 价键标签更新：每个碳球对应一个`<text>`元素，步骤切换时修改其`textContent`和`fill`颜色（当前碳蓝色，已完成黑色，待分析灰色）。
  5. 步骤4自动动画：使用`setTimeout`链或`async/await`实现6个碳原子（C4~C9）的依次高亮，每个持续400ms。为避免与按钮点击冲突，在自动播放期间禁用按钮（加`disabled`类和指针事件屏蔽）。
  6. 放大示意图：在分析面板右侧预留`<g id="scene2-zoom-view">`，步骤5~7时显示，其他步骤隐藏。内部用固定坐标绘制两个小球和键线，通过JS动态修改键型（单键/三键）和标签。
  7. 选项卡片样式：使用CSS类`.option-card`、`.option-wrong`、`.option-correct`，步骤切换时通过`classList.add/remove`改变背景色和文字色。错误/正确背景使用`rgba()`实现20%透明度。
  8. 虚线引线：步骤5~7时，从①/②/③位置到放大区绘制`<line stroke-dasharray="4,2">`，使用CSS控制显示/隐藏。
  9. 动画曲线：所有颜色、透明度、位置变化使用CSS `transition: all 0.3s ease-out`；步骤4的依次高亮使用JS定时器，间隔400ms。
  10. 事件绑定：上一步/下一步按钮绑定`click`事件，直接操作`currentStep`并调用`renderStep()`。
- ID命名规范：所有交互元素ID必须以`scene2-`为前缀。例如：`scene2-atom-c1`、`scene2-bond-c1-c2-group`、`scene2-label-c1-valence`、`scene2-highlight-c1`、`scene2-option-b`、`scene2-btn-prev`、`scene2-btn-next`、`scene2-panel-analysis`、`scene2-zoom-view`、`scene2-lead-line-1`等。JS中使用`document.getElementById`获取元素。
- IIFE隔离：所有JavaScript代码包裹在`(function() { ... })();`中，避免全局变量污染。
- CSS类命名：使用`scene2-`前缀，如`.scene2-highlight-ring`、`.scene2-bond-pending`、`.scene2-bond-current`、`.scene2-bond-done`、`.scene2-option-wrong`、`.scene2-option-correct`。
