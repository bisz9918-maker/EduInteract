[图示主题与整合说明]
- 本图示主题：单倍体育种过程（处理③花药离体培养与处理④染色体加倍）
- 整合的步骤/概念：
  1. 植株乙（基因型AABB，2n=14）作为起始材料，取其花药；
  2. 花药离体培养：花粉（AB，n=7）在培养基上经脱分化形成愈伤组织，再分化成单倍体植株（矮小、高度不育，n=7）；
  3. 秋水仙素处理：抑制纺锤体形成，导致染色体复制后不能分离；
  4. 染色体数目加倍：单倍体n=7→二倍体2n=14，获得纯合二倍体植株（AABB，可育）。
- 教学价值：教师通过分步导航，可逐层展示单倍体育种从取材→培养→加倍→获得纯合子的完整流程，配合下部染色体数目对比，直观呈现n→2n的动态变化，帮助学生理解"单倍体高度不育"与"秋水仙素使染色体加倍"两个核心概念。

[分步序列]
- 初始状态（步骤0）：显示植株乙完整图形、花药位置高亮、标签"植株乙"和"2n=14"。其余元素隐藏。教师可讲解起始材料为纯合二倍体植株乙（AABB），体细胞染色体数2n=14。
- 步骤1：点击「下一步」→ 显示箭头①从花药指向培养皿，培养皿图形出现，内部散布5粒蓝色花粉，标签"花粉"、"AB"、"n=7"出现。教师讲解花药离体培养的第一步：取出花药，花粉基因型为AB，染色体数n=7。
- 步骤2：点击「下一步」→ 隐藏花粉及"花粉"/"AB"/"n=7"(花粉)标签；培养皿内出现绿色愈伤组织，标签"愈伤组织"出现；培养皿右侧出现矮小单倍体植株，标签"单倍体植株"、"n=7"、"高度不育"出现；下部左区出现7条单倍体染色体棒，标签"单倍体 n=7"出现。教师讲解脱分化与再分化过程，强调单倍体植株矮小且高度不育。
- 步骤3：点击「下一步」→ 显示箭头②从单倍体植株指向烧杯，烧杯出现并填充浅红色秋水仙素溶液，标签"秋水仙素"出现；烧杯左下方出现细胞分裂放大图（圆形细胞，内部染色体已复制但散乱无纺锤丝），标签"无纺锤体形成"出现。教师讲解秋水仙素作用于分裂前期，抑制纺锤体形成。
- 步骤4：点击「下一步」→ 烧杯右侧出现正常高度二倍体植株，标签"二倍体植株"、"纯合体AABB"、"2n=14"、"可育"出现；下部右区出现14条成对染色体，标签"二倍体 2n=14"出现；中间显示"染色体加倍"箭头。教师讲解染色体复制后不能分离，细胞染色体加倍为2n=14，最终获得纯合可育植株。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本场景以静态几何图形和分步显隐为主，无复杂函数绘图或3D需求，原生SVG即可精确控制每个元素的位置和样式，且便于教师后续修改。
- 画布尺寸：800 × 500 px（固定），控件栏位于SVG内底部y=440~490区域，使用HTML绝对定位覆盖于SVG上方，不撑高容器。
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------------+
  | 主题：单倍体育种过程（处理③→处理④）                    |
  |                                                        |
  |  植株乙      培养皿        单倍体    [秋水仙素]  二倍体 |
  |    |       /--------\       |         [烧杯]      |     |
  |   \*/      | 花粉/  |      \|/        细胞图     \*/    |
  |    |       |愈伤组织|       |         (散乱)      |     |
  |  2n=14      \--------/     n=7     无纺锤体    AABB    |
  |                         高度不育            可育 2n=14 |
  |                                                        |
  |  单倍体 n=7   | 染色体棒×7  →  染色体棒×14(成对)       |
  |               |         染色体加倍                     |
  +--------------------------------------------------------+
  |      [◀ 上一步]      步骤 X/5      [下一步 ▶]          |
  [控件栏 y=440~490]                                      |
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `let currentStep = 0;` 控制0~4共5个状态。每个状态对应一个显隐配置数组，数组元素为 `{id, display, opacity}`。
  2. 元素显隐：使用CSS类 `.scene2-hidden { opacity: 0; pointer-events: none; }` 和 `.scene2-visible { opacity: 1; transition: opacity 0.3s ease; }` 实现淡入淡出，避免display:none导致布局抖动。
  3. 坐标计算：所有图形使用SVG的 `path`、`rect`、`circle`、`ellipse` 绘制，坐标严格按布局坐标表执行。植株使用简笔画路径（贝塞尔曲线模拟叶形），染色体使用圆角矩形 `<rect rx="3" ry="3">`。
  4. 动画曲线：仅使用CSS `transition: opacity 0.3s ease, transform 0.3s ease;`。步骤切换时，新元素淡入，旧元素淡出，无复杂位移动画，确保教学演示清晰稳定。
  5. 事件绑定：按钮绑定 `click` 事件，调用 `goToStep(n)` 函数。函数内先检查边界（0≤n≤4），更新 `currentStep`，然后遍历所有带 `data-step` 属性的元素，根据当前步骤决定添加/移除显隐类。
  6. 染色体绘制：单倍体7条染色体使用 `<g id="scene2-chromosomes-haploid">` 包裹，内部7个 `<rect>`；二倍体14条使用 `<g id="scene2-chromosomes-diploid">` 包裹，14个 `<rect>` 按7列2行排列。颜色通过class `.scene2-chr-blue` 和 `.scene2-chr-red` 控制。
  7. 植株图形复用：单倍体植株和二倍体植株使用相同路径数据，通过SVG `transform="scale(0.6)"` 和 `transform="scale(1.0)"` 区分高度，避免重复定义路径。
- ID命名规范：所有交互元素ID必须以 `scene2-` 为前缀。例如：
  - 植株乙组：`id="scene2-plant-b"`
  - 花粉组：`id="scene2-pollen-group"`
  - 单倍体植株：`id="scene2-haploid-plant"`
  - 愈伤组织：`id="scene2-callus"`
  - 烧杯：`id="scene2-colchicine-cup"`
  - 细胞分裂图：`id="scene2-cell-division"`
  - 二倍体植株：`id="scene2-diploid-plant"`
  - 单倍体染色体组：`id="scene2-chromosomes-haploid"`
  - 二倍体染色体组：`id="scene2-chromosomes-diploid"`
  - 上一步按钮：`id="scene2-btn-prev"`
  - 下一步按钮：`id="scene2-btn-next"`
  - 步骤指示器：`id="scene2-step-indicator"`
  JS中严格使用 `document.getElementById('scene2-xxx')` 获取元素，禁止跨场景选择器。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免全局变量污染，确保多场景合并时互不干扰。
