[技术实现]
- JS库选择：原生SVG（简单几何图形、流程图首选，无需引入外部库，减少依赖）
- 画布尺寸：800×500px（SVG viewBox="0 0 800 500"）
- 布局草图：
  ```
  +--------------------------------------------------+
  |  基因工程基本操作流程（场景3）                    |
  |  [步骤标题：步骤X：...]                           |
  |                                                   |
  |  +---------------------------------------------+  |
  |  |  上部/左部：分子操作区（DNA、酶、质粒）      |  |
  |  |                                             |  |
  |  +---------------------------------------------+  |
  |                                                   |
  |  +---------------------------------------------+  |
  |  |  下部/右部：细胞与植株表现区                 |  |
  |  |  （步骤3-4出现花菜细胞/植株）                |  |
  |  +---------------------------------------------+  |
  |                                                   |
  |     [上一步]        步骤 X / 5      [下一步]      |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：变量 `scene3CurrentStep`（0~4），每个步骤对应一个 `<g id="scene3-step-N">` 组。切换步骤时，将当前组 `display="none"`，目标组 `display="block"`，并配合 `opacity` 过渡动画（0→1，300ms，ease-out）。
  2. 坐标计算：所有元素使用绝对像素坐标，以SVG viewBox为基准，确保在不同屏幕尺寸下缩放一致。
  3. 动画曲线：步骤切换使用淡入淡出（opacity transition）；步骤3的导入箭头可使用 `stroke-dasharray` + `stroke-dashoffset` 动画模拟绘制效果（可选增强）。
  4. 事件绑定：上一步/下一步按钮绑定 `click` 事件，更新 `scene3CurrentStep` 后调用 `scene3Render()` 刷新视图。
  5. 按钮状态：步骤0时禁用「上一步」（fill改为#cccccc，pointer-events:none）；步骤4时禁用「下一步」。
  6. 步骤指示器：动态更新文本内容 `"步骤 " + (currentStep + 1) + " / 5"`。
- ID命名规范：
  - 步骤组：`scene3-step-0` ~ `scene3-step-4`
  - 按钮：`scene3-btn-prev`、`scene3-btn-next`
  - 指示器：`scene3-step-indicator`
  - 内部元素：`scene3-dna-top`、`scene3-plasmid-ring`、`scene3-enzyme-scissor`、`scene3-recombinant-plasmid`、`scene3-cell-wall`、`scene3-plant-stem` 等
  - JS中严格使用 `document.getElementById()` 获取元素，禁止全局class选择，避免多场景合并时跨场景污染。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，变量不污染全局作用域。
