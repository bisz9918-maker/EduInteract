[图示主题与整合说明]
- 本图示主题：两对等位基因控制花色合成的生化途径与基因型-表现型对应关系
- 整合的步骤/概念：①转录与翻译过程的标注（①②合称基因的表达）；②A和B同时存在时mRNA结合抑制机制；③四种基因型对应的表现型总结（A_bb紫花、aaB_蓝花、A_B_白花、aabb白花）
- 教学价值：教师通过分步导航，先让学生识别基础生化途径（基因→mRNA→酶→色素），再理解转录翻译的合称，接着揭示上位抑制机制，最后总结基因型与表现型的对应关系，符合从具体到抽象的认知递进

[分步序列]
- 步骤0（初始状态）：显示完整生化途径图的所有基础元素（基因框、转录/翻译箭头及①②标注、mRNA文本、酶框、酶作用线及作用点、色素框及连接箭头、中央mRNA结合说明框及文字）。无任何高亮，不显示结论文字和基因型表。教师可在此步骤让学生观察并描述图中信息。
- 步骤1（点击下一步）：左侧路径（基因B→mRNA_B→酶B→蓝色色素）整体高亮为红色(#c62828)，包括基因B框边框、转录箭头B、标注①左、mRNA_B文本、翻译箭头B、标注②左、酶B框边框、酶B作用线、作用点B、前体→蓝色箭头、蓝色色素框边框。右侧路径（基因A→mRNA_A→酶A→紫色色素）整体高亮为蓝色(#1565c0)，包括基因A框边框、转录箭头A、标注①右、mRNA_A文本、翻译箭头A、标注②右、酶A框边框、酶A作用线、作用点A、前体→紫色箭头、紫色色素框边框。在y=345处显示结论文字"①、②过程合称基因的表达"。教师讲解转录和翻译的定义及合称。
- 步骤2（点击下一步）：取消步骤1的路径高亮（恢复默认黑色/灰色）。高亮中央mRNA结合区域：mRNA结合说明框边框变为绿色(#2e7d32)实线且线宽加粗到3px，框内填充rgba(46,125,50,0.15)，mRNA_B结合线和mRNA_A结合线变为绿色实线且线宽3px。在y=365处显示结论文字"基因通过控制酶的合成来控制代谢过程，进而控制生物性状"。隐藏步骤1的结论文字。教师讲解上位抑制机制：A、B同时存在时两种mRNA结合，导致酶A和酶B均不能合成，白色前体物质无法转化为有色色素，表现为白花。
- 步骤3（点击下一步）：取消步骤2的绿色高亮（恢复默认）。隐藏步骤2的结论文字。在y=380~454区域显示基因型-表现型对应表（两列：基因型/表现型，四行数据A_bb紫花、aaB_蓝花、A_B_白花、aabb白花）。教师总结四种基因型与表现型的对应关系，为后续计算F2株系比例做铺垫。

[技术实现]
- JS库选择：原生SVG（简单几何图形、文本、箭头，无需复杂图表库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------------+
  |  [基因B]              [mRNA结合说明框]            [基因A] |
  |    ↓①                   (虚线框)                   ↓①  |
  |  mRNA_B  ←- - - - - - - - - - - - -→  mRNA_A          |
  |    ↓②                                              ↓②  |
  |  [酶B]                                              [酶A] |
  |    |                                                |    |
  |    |                                                |    |
  | [蓝色色素] ←—— [白色前体物质] ——→ [紫色色素]            |
  |                                                         |
  |              (步骤1~2结论文字 / 步骤3基因型表)            |
  |                                                         |
  |              [◀上一步]  [下一步▶]     步骤 X/4           |
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `currentStep`（0~3），初始化值为0。`updateStep(newStep)` 函数负责切换状态：先移除所有高亮CSS类，再根据newStep添加对应高亮类，控制结论文字和基因型表的display属性。
  2. 高亮实现：定义CSS类 `.highlight-red`（stroke:#c62828; fill:rgba(198,40,40,0.15)）、`.highlight-blue`（stroke:#1565c0; fill:rgba(21,101,192,0.15)）、`.highlight-green`（stroke:#2e7d32; fill:rgba(46,125,50,0.15)）。步骤1时给左侧路径元素添加.highlight-red，右侧路径元素添加.highlight-blue；步骤2时给结合区域元素添加.highlight-green。
  3. 坐标计算：所有SVG元素使用绝对坐标（px）定位，确保左右对称（以x=400为对称轴）。箭头使用 `<marker>` 定义箭头头部。
  4. 动画曲线：步骤切换不使用动画，直接切换状态（教师课堂讲解需要快速响应，避免动画延迟）。
  5. 事件绑定：上一步/下一步按钮绑定click事件，调用updateStep(currentStep-1)或updateStep(currentStep+1)，并做边界检查（0≤step≤3）。
  6. 结论文字和基因型表使用SVG `<text>` 或 `<g>` 元素，通过设置 `visibility` 或 `display` 属性控制显示/隐藏。
- **ID命名规范**：所有交互元素ID必须以 `scene1-` 为前缀。例如：
  - 基因B框：`scene1-gene-b-box`
  - 基因A框：`scene1-gene-a-box`
  - 转录箭头B：`scene1-arrow-transcript-b`
  - 标注①左：`scene1-label-one-left`
  - mRNA_B：`scene1-mrna-b`
  - mRNA结合说明框：`scene1-mrna-bind-box`
  - 翻译箭头B：`scene1-arrow-translate-b`
  - 标注②左：`scene1-label-two-left`
  - 酶B框：`scene1-enzyme-b-box`
