[图示主题与整合说明]
- 本图示主题：叠放木块系统静摩擦力变化分析（物理·九年级力学）
- 整合内容：将原题的"初始装置→隔离A→隔离B→整体→变化装置→变化隔离A→变化隔离B→变化整体→对比总结"九步分析链整合为单幅交互式SVG，教师可逐层展开受力分析。
- 教学价值：教师通过分步导航控制课堂节奏，左侧装置图与右侧隔离体受力图同步联动，非研究对象自动淡化，避免视觉干扰；最终对比表格直接呈现摩擦力变化趋势，帮助学生建立"整体法与隔离法"的解题框架。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「◀ 上一步」按钮：位于控件栏左侧(250,465)，宽90，高28；点击后回退到上一分析步骤，所有视觉状态同步回退。
  2. 「下一步 ▶」按钮：位于控件栏右侧(460,465)，宽90，高28；点击后前进到下一分析步骤，显示新的受力图并更新左侧高亮对象。
  3. 步骤标题文本：位于(400,452)，居中显示当前步骤编号与名称（如"步骤 2/9：隔离体A受力分析（初始）"）。
- 教师操作流程：
  1. 教师打开图示，先展示步骤0（初始装置），让学生观察装置结构。
  2. 点击「下一步」进入步骤1，讲解隔离体A的4个力，强调f_BA=2G的方向与大小来源。
  3. 继续点击「下一步」进入步骤2，讲解隔离体B的6个力，强调台面摩擦力f_台=G如何通过平衡求出。
  4. 步骤3用整体法验证，说明内力不出现，外力平衡直接得f_台=G。
  5. 步骤4展示变化后装置，让学生预判变化。
  6. 步骤5~7重复隔离法与整体法，得出变化后的两个摩擦力。
  7. 步骤8展示对比表格，总结"台面-B摩擦力增大、A-B摩擦力减小"，对应选项B与D。
  8. 可随时点击「上一步」回退到任意步骤重新讲解。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本场景为静态几何图形与简单显隐切换，无需D3/Canvas/Three.js；SVG的marker可复用箭头，group可批量控制显隐。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图：
  ```
  0   +--------------------------------------------------------+
      |  左侧装置区 (x:20-420)      右侧受力图区 (x:460-780)    |
      |                                                            |
      |    ○←══A                 ┌───┐                          |
      |    │    B═══→○           │ A │  ←T左=2G                  |
      |    4 5      1 2 3         └───┘                          |
      |    ↓                      ↓G_A  ↑N_BA  →f_BA=2G         |
      |                                                            |
      |  (非当前对象透明度30%)      (隔离体虚线框)                 |
  440 |                                                            |
      |         步骤 2/9：隔离体A受力分析（初始）                 |
      |       [◀ 上一步]              [下一步 ▶]                 |
  500 +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 `scene1-currentStep`（0~8）记录当前步骤。每步对应一个右侧 `<g id="scene1-force-stepN">` 的显隐；左侧高亮通过给A/B/台面对象添加/移除CSS类 `.scene1-highlight`（fill:#1565c0;fill-opacity:0.2）和 `.scene1-dim`（opacity:0.3）实现。
  2. 坐标计算：所有箭头使用SVG `<line>` + `<marker>` 定义箭头head；受力图箭头长度按力的大小比例绘制（2G arrow长60px，3G长60px，G长40px，保持视觉区分）。
  3. 动画曲线：步骤切换时无需复杂动画，直接显隐（display:none/block）即可；若需柔和过渡，可对opacity加0.2s CSS transition。
  4. 事件绑定：按钮绑定click事件，调用 `scene1-goStep(n)` 函数，内部先隐藏所有右侧受力图group，再显示目标group，同时更新左侧对象classList。
  5. 钩码状态切换：步骤4时，通过JS将左侧5号钩码的 `<rect>` 移动/隐藏，并在A顶面显示新的5号 `<rect>`；或预先绘制两组钩码（初始组+变化后组），通过display切换。
  6. 表格绘制：步骤9使用SVG `<rect>`、`<line>`、`<text>` 手动绘制表格，确保在SVG内完整呈现，不依赖HTML表格。
- ID命名规范：所有SVG元素及JS变量均以 `scene1-` 为前缀。例如：
  - 木块A：`id="scene1-block-a"`
  - 木块B：`id="scene1-block-b"`
  - 步骤2受力图group：`id="scene1-force-a-init"`
  - 上一步按钮：`id="scene1-btn-prev"`
  - 下一步按钮：`id="scene1-btn-next"`
  - 步骤标题：`id="scene1-step-title"`
  - JS中获取：`document.getElementById('scene1-block-a')`
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免全局变量污染，确保多场景合并时互不干扰。
