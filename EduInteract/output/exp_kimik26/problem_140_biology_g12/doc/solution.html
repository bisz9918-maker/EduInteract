完整题目原文

果蝇是遗传学研究的实验材料，其四对相对性状中红眼（E）对白眼（e）、灰身（B）对黑身（b）、长翅（V）对残翅（v）、细眼（R）对粗眼（r）为显性。雄果蝇M的基因在染色体上的分布如图所示。

（1）摩尔根的果蝇实验验证了萨顿提出的假说，即_。
（2）1号和2号染色体__（填"是"或"不是"）一对同源染色体。
（3）果蝇M与另一只白眼的正常果蝇杂交，产生子代中出现基因型为X$^{E}$X$^{e}$Y个体，推测原因是__。
（4）选取长翅细眼和残翅粗眼的雌雄果蝇杂交，F$_{1}$代均为长翅细眼，经多次重复实验发现F$_{2}$中表现型与比例均接近于长翅细眼：长翅粗眼：残翅细眼：残翅粗眼=7:3:1：1，他们提出一种假设：基因型为的雄或雌配子致死。

题目分析与整体讲解思路

本题是一道遗传学综合题，以雄果蝇M的染色体基因分布图为切入点，综合考查以下核心知识点：基因与染色体的关系、同源染色体的概念、伴性遗传与减数分裂异常、基因的自由组合定律与配子致死现象。

讲解时应遵循"先读图、再破题"的思路：

  1. 首先引导学生仔细观察染色体分布图，准确判断四对染色体的类型及对应基因，写出果蝇M的完整基因型，特别注意3号与4号染色体上的连锁关系。
  2. 第（1）（2）问为基础概念填空，可结合Scene 1的图示直接得出。
  3. 第（3）问需结合减数分裂过程，利用Scene 2的动态图解分析异常配子的成因。
  4. 第（4）问是难点，需借助Scene 3的棋盘格对比，从理论比例与实际比例的差异入手，逆向推导致死的配子类型。

图示规划说明

  • Scene 1：果蝇M染色体组与基因定位——整合四对染色体的识别、性染色体判定、连锁基因标注与完整基因型书写。
  • Scene 2：伴性遗传与减数分裂异常——展示正常杂交与异常减数分裂（X、Y未分离）的对比，解释X$^{E}$X$^{e}$Y的形成原因。
  • Scene 3：自由组合与配子致死推导——通过正常9:3:3:1与实际7:3:1:1的棋盘格对比，推导并验证vR配子致死的假设。
步骤0：整体概览

Scene 1 教学说明：染色体基因定位与基因型判读

教师应引导学生按"先认形状、再找基因、最后写型"的顺序观察图示：

  1. 识别染色体对：果蝇体细胞含4对染色体。图中1号较大、2号较小且形态不同，为性染色体；3/4号、5/6号形态相同，为两对常染色体；7/8号为点状染色体（第4染色体），本题不涉及。
  2. 读取基因位置：1号（X）携带E基因，2号（Y）无对应等位基因；3号同时携带V和B，4号同时携带v和b，说明V与B连锁、v与b连锁；5号携带R，6号携带r。
  3. 判定同源染色体：1号与2号虽形态大小不同，但在减数分裂中能配对，属于异型同源染色体，故第（2）问答案为"是"。
  4. 书写完整基因型：综合以上信息，果蝇M的基因型为 BbVvRrX$^{E}$Y，且需注明V与B连锁在同一条染色体上，v与b连锁在另一条同源染色体上。

关键提醒：学生易忽略3号与4号上的连锁关系，误将V/v与B/b当作独立遗传。教师应强调图中两基因位于同一染色体上，用虚线连锁标注帮助学生建立直观印象。

步骤 1/5

Scene 2 教学说明：减数分裂异常与子代基因型分析（第3问）

本图示用于讲解第（3）问：子代出现X$^{E}$X$^{e}$Y的原因分析。

  1. 确定亲本基因型：由Scene 1可知，M的基因型为X$^{E}$Y；白眼雌果蝇为隐性纯合子，基因型为X$^{e}$X$^{e}$。
  2. 正常情况分析：M经正常减数分裂产生含X$^{E}$的精子和含Y的精子，比例1:1；雌蝇只产生含X$^{e}$的卵细胞。正常子代应为X$^{E}$X$^{e}$（红眼雌）和X$^{e}$Y（白眼雄）。
  3. 异常子代溯源：目标子代X$^{E}$X$^{e}$Y含有两条X和一条Y。其中X$^{e}$只能来自母方，X$^{E}$和Y只能来自父方。这说明父方M提供了一个同时含有X$^{E}$和Y的异常精子。
  4. 异常原因定位：父方M在减数第一次分裂时，X与Y这对同源染色体未发生分离，共同进入同一个次级精母细胞，最终形成基因型为X$^{E}$Y的精子。该精子与正常卵细胞X$^{e}$受精，即得X$^{E}$X$^{e}$Y。

常见学生误区：学生可能误认为异常来自母方。教师应强调母方基因型为X$^{e}$X$^{e}$，不可能提供Y染色体，因此异常一定发生在父方。同时需区分"减数第一次分裂同源染色体未分离"与"减数第二次分裂姐妹染色单体未分离"，本题属于前者。

步骤 1/6

Scene 3 教学说明：自由组合异常比例与配子致死推导（第4问）

本图示用于突破第（4）问的比例分析难点，核心思路是"理论作对照、差异找线索、假设再验证"。

  1. 确定遗传方式：由Scene 1可知，V/v位于第2对常染色体，R/r位于第3对常染色体，两对基因独立遗传，符合自由组合定律。
  2. 确定亲本与F$_{1}$基因型：长翅细眼亲本与残翅粗眼亲本杂交，F$_{1}$全为长翅细眼，说明亲本为显性纯合VVRR和隐性纯合vvrr，F$_{1}$为VvRr。
  3. 理论比例锚定：正常F$_{1}$自交，F$_{2}$应为9 VR : 3 Vrr : 3 vvR : 1 vvrr。
  4. 对比找差异：实际比例为7:3:1:1。与理论值对比：
  • 长翅细眼 9 → 7（减少2）
  • 长翅粗眼 3 → 3（不变）
  • 残翅细眼 3 → 1（减少2）
  • 残翅粗眼 1 → 1（不变）

减少的是长翅细眼和残翅细眼，二者共同点是都含有vR配子来源的个体。

  1. 假设与验证：假设基因型为vR的雄配子致死（或雌配子致死），则该方配子只有VR、Vr、vr三种。用3×4棋盘格重新统计，恰好得到7:3:1:1，假设成立。

关键公式与推导：

若雄配子vR致死：

  • 雄配子种类及比例：VR : Vr : vr = 1 : 1 : 1
  • 雌配子种类及比例：VR : Vr : vR : vr = 1 : 1 : 1 : 1
  • F$_{2}$表现型及比例：
  1. 长翅细眼（VR）= 7/12
  2. 长翅粗眼（V_rr）= 3/12
  3. 残翅细眼（vvR_）= 1/12
  4. 残翅粗眼（vvrr）= 1/12
  • 即 7:3:1:1，与题意完全吻合。

教学提示：可让学生思考"如果是VR配子致死，比例会是多少？"，通过课堂小练习巩固配子致死的推导方法。同时强调题目中"雄或雌配子致死"意味着只要雌雄一方vR配子致死即可，不必双方同时致死。

完整解答与课堂讲解建议

各问答案：

  1. （1）基因在染色体上（或"基因位于染色体上"）
  2. （2）是
  3. （3）果蝇M在减数第一次分裂时，X与Y染色体（1号与2号染色体）未分离，产生了基因型为X$^{E}$Y的精子，该精子与含X$^{e}$的正常卵细胞结合
  4. （4）vR

课堂讲解节奏建议：

  1. 导入（3分钟）：展示Scene 1，让学生自主读图，写出果蝇M的基因型。教师巡视，收集典型错误（如忽略连锁、写错性染色体基因型），集中订正。
  2. 概念突破（5分钟）：结合Scene 1讲解第（1）（2）问。强调萨顿的假说与摩尔根实验的验证关系；强调X与Y是异型同源染色体，这是学生易错点。
  3. 异常分析（7分钟）：用Scene 2分步演示第（3）问。先走一遍正常流程，再展示异常流程，形成强烈对比。让学生口述异常发生的时期（减Ⅰ）和原因（同源染色体未分离）。
  4. 难点攻坚（10分钟）：用Scene 3讲解第（4）问。先让学生独立计算正常比例，再呈现实际比例，制造认知冲突。引导学生从"差2份"入手，逆向锁定vR配子。建议让学生动手在草稿纸上画3×4棋盘格，验证7:3:1:1。
  5. 总结（5分钟）：回归题目图像，总结本题核心能力——"读图获取信息+减数分裂图像分析+比例异常逆向推导"。布置变式：若F$_{2}$比例为5:3:3:1，推测何种配子致死？（答案：VR雌配子和VR雄配子均致死，或类似变式）
