[图示主题与整合说明]
- 本图示主题：果蝇M四对染色体上的基因分布、连锁关系与完整基因型判定
- 整合的步骤/概念：①四对染色体形态识别（3对常染色体+1对性染色体+点状染色体）；②1号（X^E）与2号（Y）性染色体的判定及同源染色体关系；③3号与4号常染色体上V-B、v-b的连锁关系展示；④5号与6号常染色体上R/r的独立遗传关系；⑤果蝇M完整基因型BbVvRrX^E Y的书写与标注
- 教学价值：教师通过"整体→局部→综合"的分步呈现，引导学生逐步识别染色体形态、判断同源关系、理解基因连锁与独立遗传，最终综合写出果蝇M的完整基因型。分步导航支持随时回退，便于教师针对学生疑点重复讲解。

[分步序列]
- 步骤0（初始状态/整体概览）：显示全部8条染色体轮廓及序号标签（1–8），无基因标注，无高亮，无提示文字。建立果蝇染色体组的整体空间印象。
- 步骤1（性染色体）：点击「下一步」→ 1号与2号染色体叠加蓝色高亮层（#1565c0, opacity:0.2）；显示X、Y类型标签；显示E基因标签；在1号与2号之间显示双向箭头及"可配对"文字提示。引导学生判定1号与2号为一对同源染色体（性染色体）。
- 步骤2（连锁基因）：点击「下一步」→ 3号与4号染色体叠加红色高亮层（#c62828, opacity:0.2）；显示V、B、v、b基因标签；在3号左侧与4号右侧分别显示连锁虚线（连接同一条染色体上的两个基因）。强调V与B连锁、v与b连锁。步骤1的X、Y、E标签保持显示，但1、2号蓝色高亮移除（仅保留当前步骤高亮）。
- 步骤3（独立遗传）：点击「下一步」→ 5号与6号染色体叠加绿色高亮层（#2e7d32, opacity:0.2）；显示R、r基因标签；在5号与6号下方显示"独立遗传"提示。强调R/r位于另一对同源染色体上，与V/v独立遗传。之前所有基因标签保持显示。
- 步骤4（完整基因型）：点击「下一步」→ 所有染色体恢复无高亮（或全部轻微描边高亮）；在图示下方中央显示完整基因型"BbVvRrX^E Y"（X的E为上标）；在基因型下方显示连锁说明"（V与B连锁，v与b连锁）"。综合呈现果蝇M的全部遗传信息。
（教师可随时点击「上一步」回退至任意步骤复习。）

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「上一步」按钮：位于画布底部(300, 450)，宽80×高32px，点击回退到上一分步，步骤0时禁用（opacity:0.4）
  2. 「下一步」按钮：位于画布底部(460, 450)，宽80×高32px，点击前进到下一分步，步骤4时禁用（opacity:0.4）
  3. 步骤指示文本：位于画布底部中央(400, 490)，显示当前步骤名称（如"步骤2：连锁基因"）
- 教师操作流程：
  1. 教师加载图示，首先呈现步骤0（整体概览），询问学生"图中共有几对染色体？"
  2. 点击「下一步」进入步骤1，引导学生观察1号与2号的形态差异，确认X与Y为性染色体且为同源染色体
  3. 点击「下一步」进入步骤2，引导学生观察3号与4号上的基因位置关系，理解连锁遗传
  4. 点击「下一步」进入步骤3，引导学生对比5号/6号与3号/4号，理解独立遗传
  5. 点击「下一步」进入步骤4，综合写出完整基因型。若学生某步有疑问，随时点击「上一步」回退复习

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本场景为静态几何图形（染色体、标签、虚线）的分步显隐控制，无需复杂数据绑定或3D渲染，原生SVG足以高效实现，且便于教师后续直接修改。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |  [3:V,B]        [7][8]        [5:R]             |  y=100~280
  |  [4:v,b]                        [6:r]             |
  |                                                   |
  |           [1:E-X]  [2:Y]                         |  y=300~400
  |                                                   |
  |              BbVvRrX^E Y                          |  y=420
  |         （V与B连锁，v与b连锁）                    |  y=445
  |                                                   |
  |   [◀上一步]    步骤指示    [下一步▶]              |  y=450~490
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `currentStep`（0~4），每次点击按钮时更新状态，调用 `renderStep()` 函数根据状态显隐元素。
  2. 元素显隐控制：所有SVG元素初始绘制完成，通过设置 `display: none` 或 `visibility: hidden` 隐藏非当前步骤元素，避免频繁DOM操作造成闪烁。
  3. 高亮切换：每步仅当前聚焦的染色体对显示高亮path（opacity:0.2），其余高亮path隐藏。高亮path使用与染色体相同的d属性，但stroke-width:34、opacity:0.2，叠在染色体path下方（SVG绘制顺序：先高亮层，后染色体层）。
  4. 动画曲线：分步切换不使用动画，直接瞬时显隐，确保教学节奏由教师完全掌控。如需柔和过渡，可添加0.2s的opacity过渡（CSS transition）。
  5. 事件绑定：按钮点击事件在IIFE内绑定，更新currentStep后调用renderStep()，并更新按钮禁用状态（步骤0禁用「上一步」，步骤4禁用「下一步」）。
  6. 上标实现：基因型中的X^E使用SVG <tspan>的baseline-shift属性实现上标效果，避免引入MathJax增加加载负担。
  7. 箭头标记：配对箭头使用SVG <marker>定义箭头头部，在<line>或<path>上通过marker-start/marker-end引用。
- ID命名规范：所有交互元素ID必须以 `scene1-` 为前缀。例如：
  - 染色体：`scene1-chr-1`、`scene1-chr-2`、...、`scene1-chr-8`
  - 基因标签：`scene1-gene-E`、`scene1-gene-V`、...、`scene1-gene-r`
  - 高亮层：`scene1-hl-1`、`scene1-hl-2`（1、2号共用同类型高亮，但分别控制）、`scene1-hl-3`、`scene1-hl-4`、`scene1-hl-5`、`scene1-hl-6`
  - 提示元素：`scene1-tip-pair`、`scene1-tip-linkage-3`、`scene1-tip-linkage-4`、`scene1-tip-independent`
  - 基因型：`scene1-genotype`、`scene1-genotype-note`
  - 按钮：`scene1-btn-prev`、`scene1-btn-next`
  - 步骤文本：`scene1-step-label`
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免全局变量污染，确保多场景合并时互不干扰。
