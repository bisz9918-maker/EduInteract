[图示主题与整合说明]
- 本图示主题：两对独立遗传基因（长翅/残翅 V/v、细眼/粗眼 R/r）的 F₂ 比例异常（7:3:1:1）与 vR 配子致死推导
- 整合的步骤/概念：①P 代杂交与 F₁ 基因型确定；②正常 F₁ 自交的理论 4×4 Punnett 棋盘格（9:3:3:1）；③理论值与观察值 7:3:1:1 的并列对比；④假设雄配子 vR 致死的修正 3×4 棋盘格；⑤修正后统计验证 7:3:1:1；⑥得出结论
- 教学价值：教师通过"理论→冲突→假设→验证"的递进分步，引导学生发现配子致死导致比例偏离，培养逆向推理与假说演绎能力

[分步序列]
- 初始状态（步骤0）：显示标题、左侧P代杂交流程（VVRR × vvrr → F₁ VvRr）、独立遗传说明、右侧F₁自交引导箭头。棋盘格与比例区隐藏。
- 步骤1：点击「下一步」→ 左侧收缩为简化信息行；中间显示完整4×4棋盘格（雄配子VR/Vr/vR/vr × 雌配子VR/Vr/vR/vr），每个格子标注基因型并按表现型着色；右侧显示理论比例汇总（长翅细眼9、长翅粗眼3、残翅细眼3、残翅粗眼1）。
- 步骤2：点击「下一步」→ 中间4×4棋盘格保留但透明度降至40%；右侧改为"理论→实际"对比表，显示长翅细眼9→7（少2）、长翅粗眼3→3（不变）、残翅细眼3→1（少2）、残翅粗眼1→1（不变）；底部出现红色提示"含vR的个体减少"。
- 步骤3：点击「下一步」→ 中间切换为3×4修正棋盘格：雄配子vR标红色删除线与"致死"，仅保留VR、Vr、vr三列；雌配子仍为VR/Vr/vR/vr四行；12个格子重新计算基因型并着色；右侧对比表隐藏。
- 步骤4：点击「下一步」→ 3×4修正棋盘格保持；右侧显示修正后的统计验证：长翅细眼7、长翅粗眼3、残翅细眼1、残翅粗眼1，下方高亮绿色"7:3:1:1"与"验证成立"。
- 步骤5（最终）：点击「下一步」→ 棋盘格透明度降至30%；画面底部弹出结论条："结论：基因型为vR的雄或雌配子致死"。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「上一步」按钮：位置(260, 455)，宽100高32；点击回退到前一步，步骤0时禁用（opacity 0.4）。
  2. 步骤指示器：位置(400, 470)；显示当前步骤编号（如"步骤 2/6"）。
  3. 「下一步」按钮：位置(540, 455)，宽100高32；点击前进到下一步，步骤5时禁用（opacity 0.4）。
- 教师操作流程：
  1. 教师打开图示，首先讲解P代杂交与F₁基因型确定（步骤0）。
  2. 点击「下一步」进入步骤1，展示正常9:3:3:1棋盘格，让学生回顾独立遗传规律。
  3. 点击「下一步」进入步骤2，呈现理论与实际的数字冲突（9→7，3→1），提问"什么类型个体减少了？"
  4. 点击「下一步」进入步骤3，揭示vR配子致死假设，展示修正棋盘格。
  5. 点击「下一步」进入步骤4，带领学生逐格统计修正后的表现型数量，验证7:3:1:1。
  6. 点击「下一步」进入步骤5，弹出结论条，完成假说演绎闭环。
  7. 可随时回退到任意步骤复习。

[技术实现]
- JS库选择：原生 SVG + 原生 JavaScript。理由：本场景以几何网格、文本标签、简单矩形为主，无需复杂图表库；原生SVG可精确控制每个格子、标签的坐标与显隐，避免引入不必要的依赖。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图（ASCII）：
  ```
  +----------------------------------------------------------+
  |              标题：两对基因F₂比例异常推导                  | y=20-40
  |                                                          |
  |  +----------+  +--------------------+  +---------------+ |
  |  | P代杂交  |  |    Punnett棋盘格    |  |  比例统计/对比 | |
  |  | 流程     |  |   4×4 或 3×4       |  |  理论/实际/验证| |
  |  | (左20%)  |  |    (中50%)         |  |   (右30%)     | |
  |  +----------+  +--------------------+  +---------------+ |
  |                                                          |
  |           [结论条：基因型为vR的雄或雌配子致死]            | y=395-435 (仅步骤5)
  |                                                          |
  |       [◀上一步]      步骤 X/6      [下一步▶]             | y=445-485
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `let currentStep = 0;` 控制6个状态（0~5）。每步对应一个SVG `<g>` 分组（id="scene3-step0-group" 至 "scene3-step5-group"），通过设置 `display: none/block` 切换。避免频繁创建/销毁DOM。
  2. 坐标计算：棋盘格采用固定网格。4×4时列中心x=[290,350,410,470]，行中心y=[150,210,270,330]；3×4时列中心x=[290,350,470]（跳过vR列），行中心y不变。格子背景使用 `<rect>`，基因型使用 `<text>`。
  3. 动画曲线：步骤切换时，使用CSS transition（opacity 0.2s ease-in-out）。 outgoing组opacity→0，incoming组opacity→1，通过setTimeout同步display属性，实现淡入淡出。
  4. 事件绑定：上一步/下一步按钮绑定click事件，调用 `goToStep(n)` 函数。函数内先检查边界（n<0或n>5则return），再更新currentStep、切换分组显示、更新指示器文本、禁用/启用按钮。
  5. 表现型着色：预先定义颜色映射对象 `const phenotypeColor = { 'blue':'#1565c0', 'red':'#c62828', 'green':'#2e7d32', 'gray':'#888888' };`，每个格子rect设置 `fill-opacity="0.15"`。
  6. 致死标记：步骤3中vR标签使用 `<text text-decoration="line-through" fill="#c62828">vR</text>`，并在其右侧(450,80)添加红色"致死"文本。对应列不绘制格子rect，保持空白。
  7. 结论条：步骤5显示，使用绝对定位的div或SVG rect+text覆盖在底部中央，背景#e8f5e9，边框#2e7d32。
- ID命名规范：所有交互元素ID必须以 `scene3-` 为前缀。例如：
  - 分组：`scene3-step0-group`, `scene3-step1-group`, ..., `scene3-step5-group`
  - 按钮：`scene3-btn-prev`, `scene3-btn-next`
  - 指示器：`scene3-step-indicator`
  - 棋盘格：`scene3-punnett-grid-normal`, `scene3-punnett-grid-modified`
  - 结论条：`scene3-conclusion-box`
  - JS中严格使用 `document.getElementById('scene3-xxx')` 获取元素，禁止querySelectorAll配合全局class，防止多场景合并时跨场景污染。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，变量不泄露全局作用域。
