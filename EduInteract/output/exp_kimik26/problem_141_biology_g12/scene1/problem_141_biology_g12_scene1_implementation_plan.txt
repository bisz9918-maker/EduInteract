[图示主题与整合说明]
- 本图示主题：六种转基因幼苗类型识别与长期种植筛选
- 整合的步骤/概念：题目原图解析 → 核基因型与线粒体状态标注 → 第一问长期种植要求分析
- 教学价值：教师通过分步导航，引导学生先识别图例、再区分核遗传与细胞质遗传标记，最终理解"核基因纯合SS才能稳定遗传"这一核心结论；线粒体S基因虽能表达抗性但会逐代减弱，因此不能作为长期唯一依据。

[分步序列]
- 步骤0（初始状态）：展示完整原图（a-f六种类型的染色体与线粒体示意图）+ 顶部图例说明；所有基因型标签、线粒体状态标签隐藏；无高亮。
- 步骤1（核基因标注）：点击「下一步」→ b、c、e、f中含有蓝色箭头的染色体加粗高亮（stroke-width由3→5，可添加淡蓝背景光晕）；显示核基因型标签（a:ss, b:Ss, c:SS, d:ss, e:Ss, f:SS，蓝色，位于各圆正上方）；说明文字更新为核遗传分析要点。
- 步骤2（线粒体标注）：点击「下一步」→ d、e、f的线粒体红色高亮（添加红色描边加粗或外发光）；显示线粒体状态标签"S+"（红色，位于d/e/f圆的右下方外侧）；说明文字更新为细胞质遗传特点及逐代减弱提示。
- 步骤3（综合筛选）：点击「下一步」→ c和f的圆轮廓变为绿色#2e7d32（stroke-width=4），内部填充浅绿（opacity=0.12），表示符合长期种植要求；说明文字展示结论：核基因纯合SS可稳定遗传，线粒体S会逐代减弱，因此c、f符合要求。
（教师可随时点击「上一步」回退复习，步骤指示器同步更新。）

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「上一步」按钮：位于(310,445)，宽80高28；点击后currentStep减1，回退到前一状态，更新视觉元素显示/隐藏及样式。
  2. 「下一步」按钮：位于(410,445)，宽80高28；点击后currentStep加1，进入下一状态。
  3. 步骤指示器：位于(400,485)，显示"步骤 X/4"，随按钮点击同步更新。
- 教师操作流程：
  1. 教师展示步骤0，让学生观察六种类型原图，识别图例含义；
  2. 点击「下一步」进入步骤1，引导学生关注核基因整合状态，区分SS/Ss/ss；
  3. 点击「下一步」进入步骤2，引导学生关注线粒体整合状态，强调细胞质遗传及逐代减弱；
  4. 点击「下一步」进入步骤3，让学生自主判断符合长期种植的类型，教师用绿色高亮揭示答案c和f，讲解核基因纯合稳定遗传的核心逻辑；
  5. 可随时点击「上一步」回退，强化学生对核基因型与线粒体状态双重标注的记忆。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：图形为简单几何形状（圆、线段、箭头、文本），无需复杂图表库；原生SVG可精确控制每个元素的显示/隐藏与样式变化，且便于教师直接嵌入课件。
- 画布尺寸：800 × 500 px（固定画布规则）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  | [图例区]  未整合染色体 | 已整合染色体 | 未整合线粒体 | 已整合线粒体  |
  |                                                  |
  |     ○a          ○b          ○c                   |
  |    ss          Ss           SS      ← 步骤1显示   |
  |                                                  |
  |     ○d          ○e          ○f                   |
  |    ss          Ss           SS      ← 步骤1显示   |
  |     S+         S+           S+      ← 步骤2显示   |
  |                                                  |
  |        [步骤说明文字区，随步骤切换]                  |
  |                                                  |
  |           [◀上一步]  步骤 X/4  [下一步▶]           |
  +--------------------------------------------------+
  画布 800×500，控件栏在底部 y=445~490
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `let currentStep = 0;` 记录当前步骤（0~3）。每次点击按钮时更新currentStep，调用 `renderStep()` 函数根据状态控制所有元素的显示、隐藏及样式。
  2. 元素显隐控制：为每组元素（基因型标签、线粒体状态标签、高亮层）设置统一的class，通过 `document.getElementById` 获取具体元素后设置 `style.display = 'block'/'none'` 或切换class。
  3. 高亮实现：
     - 核基因高亮（步骤1）：给b/c/e/f的蓝色箭头元素添加class `highlight-nuclear`，CSS中定义stroke-width加粗或添加filter: drop-shadow。
     - 线粒体高亮（步骤2）：给d/e/f的线粒体元素添加class `highlight-mito`，CSS中定义stroke-width加粗及外发光。
     - 筛选高亮（步骤3）：给c/f的细胞圆添加class `highlight-selected`，改变stroke和fill。
  4. 动画曲线：无需复杂动画，步骤切换时直接显示/隐藏（瞬时切换），保证教学节奏清晰；如需柔和过渡，可使用CSS transition: opacity 0.2s ease。
  5. 事件绑定：在IIFE内部为按钮绑定click事件，`document.getElementById('scene1-btn-prev').addEventListener('click', ...)`。
  6. 边界处理：currentStep为0时禁用「上一步」按钮（降低透明度或置灰）；currentStep为3时「下一步」按钮可循环回0或禁用（建议循环回0以便重复演示）。
- **ID命名规范**：所有交互元素ID必须以 `scene1-` 为前缀。例如：
  - 细胞圆：`scene1-cell-a` ~ `scene1-cell-f`
  - 染色体：`scene1-chr-a-left`, `scene1-chr-a-right` 等
  - 箭头：`scene1-arrow-b-left` 等
  - 线粒体：`scene1-mito-a` ~ `scene1-mito-f`
  - 标签：`scene1-label-a` ~ `scene1-label-f`，`scene1-genotype-a` ~ `scene1-genotype-f`，`scene1-mitolabel-d` 等
  - 按钮：`scene1-btn-prev`, `scene1-btn-next`
  - 说明文字：`scene1-desc-text`
  - 步骤指示器：`scene1-step-indicator`
  JS中严格使用 `document.getElementById` 获取元素，避免使用 `querySelectorAll` 配合全局class导致多场景合并时跨场景污染。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，确保变量不污染全局作用域。
