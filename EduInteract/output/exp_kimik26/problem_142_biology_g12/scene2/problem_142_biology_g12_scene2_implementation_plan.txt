# Scene 2 Implementation Plan

<SCENE_VISION_STORYBOARD_AND_TECHNICAL_PLAN>

[图示主题与整合说明]
- 本图示主题：三种黑青毛突变体的染色体组成、配子形成及杂交鉴定
- 整合的步骤/概念：
  1) 图2三种突变体染色体组成并排对比（步骤0）
  2) 实验设计展示——待鉴定突变体（aaBbCcc）与纯种棕色猪（aaBBcc）杂交（步骤1）
  3) 突变体甲（C/c/c）减数分裂随机分离 → 配子1:2:2:1 → 子代黑色:黑青色:棕色=1:2:3（步骤2）
  4) 突变体乙（Cc/c）减数分裂分离 → 配子1:1 → 子代黑青色:棕色=1:1（步骤3）
  5) 突变体丙（C/cc）减数分裂分离 → 配子1:1 → 子代黑色:棕色=1:1（步骤4）
  6) 三种突变体杂交结果汇总对比表（步骤5）
- 教学价值：教师可按照"认识染色体组成差异→理解减数分裂行为→推导配子比例→预测杂交结果→汇总对比"的完整认知链条逐步展开讲解。分步导航使教师能控制信息呈现节奏，三种突变体的并列对比帮助学生抓住鉴定依据的核心差异（子代表现型种类及比例）。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：本场景以静态几何图形和文字标签为主，分步导航仅需显示/隐藏SVG组，无需复杂动画或数据驱动绘图，原生SVG性能最优且无需额外CDN依赖。
- 画布尺寸：800 × 500 px（固定画布，SVG viewBox="0 0 800 500"）。
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  标题区 (y=0~60)                                  |
  |  主图区 (y=60~430)  ← 各步骤视觉元素在此区域切换   |
  |                                                   |
  |                                                   |
  |                                                   |
  |  控件栏 (y=440~490)  [上一步] [下一步]            |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `currentStep`（范围0~5），每个步骤对应一个SVG `<g>` 组（id="scene2-step0-group" 至 "scene2-step5-group"）。初始化时仅显示步骤0组，其余组设置 `display="none"`。
  2. 步骤切换：点击按钮时，隐藏当前组，显示目标组。可添加CSS过渡效果（opacity 0→1，transition: opacity 0.25s ease-in）实现淡入淡出。
  3. 按钮状态管理：在步骤0时禁用「上一步」（设置disabled属性及#cccccc填充），在步骤5时禁用「下一步」。
  4. 坐标计算：所有坐标已在布局坐标表中精确规划，代码中直接使用绝对坐标（px）绘制，无需动态计算。
  5. 事件绑定：使用 `document.getElementById('scene2-btn-prev').addEventListener('click', ...)` 和 `document.getElementById('scene2-btn-next').addEventListener('click', ...)` 绑定按钮事件。
  6. 表格绘制：步骤5的表格使用SVG `<rect>`、`<line>` 和 `<text>` 组合绘制，表头背景用 `<rect>` 填充#e3f2fd，文字使用 `<tspan>` 实现换行（如"C:c:Cc:cc"和"(1:2:2:1)"分两行）。
  7. 纺锤丝：使用 `<line>` 元素，设置 `stroke="#888888" stroke-dasharray="4,3"`。
  8. 透明度处理：表现型色块和配子椭圆使用 `fill-opacity="0.3"` 或 `fill-opacity="0.15"`，边框保持不透明以维持边界清晰。
- ID命名规范：所有交互元素ID必须以 `scene2-` 为前缀。例如：
  - 步骤组：scene2-step0-group, scene2-step1-group, ..., scene2-step5-group
  - 按钮：scene2-btn-prev, scene2-btn-next
  - 步骤指示器：scene2-step-indicator
  - 各步骤内部元素：scene2-s0-chr1, scene2-s2-gamete-C 等
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免全局命名空间污染，确保多场景合并时互不干扰。
