[图示主题与整合说明]
- 本图示主题：草原生态系统食物网的结构识别与营养级分析
- 整合的步骤/概念：食物网基础结构展示、五条食物链逐条高亮、狮子多营养级身份标注
- 教学价值：教师通过分步导航逐条呈现食物链，避免多条连线同时高亮造成的视觉混乱；学生可清晰观察同一生物（狮子）在不同食物链中处于不同营养级，建立"营养级是相对于具体食物链而言"的核心概念

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位置(280,465)，宽80高32，点击后退到上一分步，步骤0时禁用（opacity 0.4，pointer-events none）
  - 「步骤指示器」文本：位置(400,465)，显示当前步骤如"步骤 2/6"，居中
  - 「下一步」按钮：位置(520,465)，宽80高32，点击前进到下一分步，步骤6时禁用
- 教师操作流程：
  1. 教师展示步骤0完整食物网，让学生观察整体结构
  2. 点击「下一步」进入步骤1，讲解食物链①及营养级1→2→3→4
  3. 逐次点击「下一步」依次展示食物链②至⑤，每步强调不同路径和营养级变化
  4. 到达步骤6，恢复全图并标注狮子多营养级身份，引导学生总结"营养级取决于具体食物链"
  5. 可随时点击「上一步」回退复习某条食物链

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（原因：食物网为静态几何图形和简单状态切换，无需复杂数学计算或3D渲染，原生SVG路径和marker即可实现带箭头的贝塞尔曲线，原生JS状态机足以管理7个步骤的切换）
- 画布尺寸：800 × 500 px（SVG viewBox="0 0 800 500"）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------------+
  |                                                        |
  |    ①(草)        ②(羚羊)        ③(野狗)                |
  |   (80,210)     (220,90)       (420,150)                |
  |      ○──────────▭────────────▭──────────────────▭      |
  |     / 草      / 羚羊        / 野狗              / 狮子  |
  |    /        /             /                   /        |
  |   /   ②   /             /                   /  ③/④/⑤ |
  |  /  (220,280)           /                   / (720,210)|
  | ○──────────▭───────────/───────────────────▭          |
  |  草        斑马        /                   狮子        |
  |   \                  /                                 |
  |    \   ②           /                                   |
  |     \ (220,410)   /                                    |
  |      ○──────────▭──────────▭───────────────/          |
  |       草        鼠         蛇          食蛇动物        |
  |                        ③(420,410)   ④(560,410)        |
  |                                                        |
  |  [控件栏 y=440~490]                                    |
  |       [◀上一步]    步骤 X/6    [下一步▶]               |
  |       (280,465)    (400,465)   (520,465)               |
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 `currentStep`（0~6）记录当前步骤，每次点击按钮时更新状态并调用 `renderStep()` 重绘
  2. 连线高亮逻辑：为每条连线（SVG `<path>`）设置 `id="scene1-edge-XX"`，在 `renderStep()` 中根据当前步骤设置 `stroke` 和 `stroke-width` 属性。定义每条边所属的食物链映射表：`edgeMap = { '草-羚羊': [1,2], '羚羊-野狗': [1], ... }`，高亮时检查当前步骤是否在该边的映射数组中
  3. 营养级标签显示：为每个营养级标签设置 `id="scene1-level-N"`，在 `renderStep()` 中根据当前步骤设置 `display` 属性（block/none）。注意狮子在不同步骤显示不同数字（步骤2显示3，步骤4显示3，步骤1/3显示4，步骤5显示5），使用同一个DOM元素修改textContent即可
  4. 动画曲线：状态切换不使用动画（瞬间切换），确保教师课堂讲解时响应迅速，避免学生等待
  5. 事件绑定：按钮通过 `getElementById('scene1-btn-prev')` 和 `getElementById('scene1-btn-next')` 获取，绑定 `click` 事件。步骤0时禁用「上一步」，步骤6时禁用「下一步」
  6. 箭头实现：使用SVG `<marker>` 定义箭头，markerWidth="10" markerHeight="7" refX="9" refY="3.5"，在路径末端引用
  7. 贝塞尔曲线：使用 `<path d="M x1 y1 C cx1 cy1, cx2 cy2, x2 y2" />`，单控制点用Q指令或C指令令两个控制点重合
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀，例如：
  - 节点：`scene1-node-grass`、`scene1-node-antelope`、`scene1-node-lion` 等
  - 连线：`scene1-edge-grass-antelope`、`scene1-edge-antelope-wilddog` 等
  - 营养级标签：`scene1-level-grass`、`scene1-level-antelope`、`scene1-level-lion` 等
  - 按钮：`scene1-btn-prev`、`scene1-btn-next`
  - 指示器：`scene1-step-indicator`
  - 狮子多营养级标注：`scene1-lion-levels`
- IIFE 隔离：所有 JS 代码包在 `(function() { ... })()` 中，避免全局变量污染，确保多场景合并时互不干扰
