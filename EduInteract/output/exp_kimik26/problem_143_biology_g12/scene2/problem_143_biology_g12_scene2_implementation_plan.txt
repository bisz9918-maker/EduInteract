# Scene 2 Implementation Plan

<SCENE_VISION_STORYBOARD_AND_TECHNICAL_PLAN>

[图示主题与整合说明]
- 本图示主题：草原生态系统食物网能量流动的干预前/后定量对比
- 整合的步骤/概念：
  1) 干预前能量逐级分配（第2问）：草300万→第二营养级30万→第三营养级（羚羊/斑马/鼠各10万）→第四营养级（野狗/蛇各1万）→第五营养级（食蛇动物0.1万）→狮子汇总1.11万；
  2) 干预后能量重新分配（第3问）：鼠爆发占2/3（20万），羚羊/斑马各5万→第三营养级重新分配→狮子总能量降至0.57万；
  3) 结论推导：维持原种群所需捕食面积倍数≈2倍，草原面积有限时狮子种群密度下降。
- 教学价值：教师通过分步导航，可严格按"营养级逐级递减"顺序讲解10%传递效率的定量计算；干预前后的视觉对比（狮子能量从1.11万→0.57万）直观呈现鼠类爆发对顶级捕食者的级联影响；可随时回退复习某一步骤的能量分配细节。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：食物网为静态几何图形与简单状态切换，无需复杂数学计算或3D渲染；原生SVG可精确控制每个节点、连线、标签的显隐与样式，避免引入重型库。
- 画布尺寸：800×500px（SVG viewBox="0 0 800 500"）。
- 布局草图（ASCII）：

  +-----+-----+-----+-----+-----+-----+-----+-----+  0
  |     |     |     |     |     |     |     |     |

  |  (50,250)   |(170,120)  |(330,150)  |     |     |

- 关键实现要点：
  1) 状态机设计：用变量 `currentStep`（0~7）控制当前步骤。每一步定义一个配置对象，包含：高亮连线ID数组、显示数值框ID数组、显示标签ID数组、狮子是否高亮、结论框是否显示。切换步骤时先执行hideAll()清除上一步动态元素，再按配置显示当前步骤元素。
  2) 坐标计算：所有节点、数值框、标签坐标硬编码于配置对象中，SVG元素使用绝对坐标（x,y）定位，确保代码agent无需动态计算。
  3) 动画曲线：数值框/标签的显隐使用CSS transition（opacity 0→1，duration 300ms，ease-out）；狮子放大使用CSS transform scale(1.25) + transition 400ms ease-in-out；连线高亮使用stroke-width和stroke的transition 250ms。
  4) 事件绑定：上一步/下一步按钮绑定click事件，更新currentStep后调用renderStep()。按钮禁用状态通过class控制（添加.disabled）。
  5) 多步骤标签复用：如"平均摄食：1/2"标签在步骤2和步骤6复用同一组SVG text元素，仅更新内容（步骤6数值不变，文字相同，直接复用）。旁注标签(120,90)使用同一个text元素，通过textContent切换内容。
  6) 间接来源虚线：步骤3使用SVG <line> stroke-dasharray="4,3" 从狮子节点右边缘(600,250)分别连接到(640,270)和(640,290)文字左侧，步骤4时移除。
