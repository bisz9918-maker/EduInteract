[图示主题与整合说明]
- 本图示主题：果蝇眼型遗传杂交实验的完整遗传图解（P → F₁ → F₂）
- 整合的步骤/概念：
  1. P代亲本杂交组合（纯种♀棒眼 × 纯种♂圆眼）及其基因型；
  2. F₁代基因型与表现型的推导（♀圆眼 XᴿXʳ、♂棒眼 XʳY），由此确定圆眼为显性、棒眼为隐性；
  3. F₁雌雄交配过程；
  4. F₂代棋盘格（Punnett Square）展开，列出4种基因型及对应表现型；
  5. F₂表现型比例汇总 ♀圆眼:♀棒眼:♂圆眼:♂棒眼 = 1:1:1:1，与题目条件吻合。
- 教学价值：教师通过分步导航控制讲解节奏，学生可跟随图示逐步理解"由F₂反推F₁基因型"的演绎推理过程，以及伴性遗传棋盘格的分析方法。绿色高亮用于标记关键推导节点和与题目一致的结果，降低认知负荷。

  - 「下一步」按钮：位于控件区右侧 (480, 460)，90×30px，点击前进到下一分步，步骤3时禁用。

- 教师操作流程：
  1. 教师打开图示，默认进入步骤0，向学生展示题目给出的P代杂交组合，引导学生观察F₁表现型未知。
  2. 点击「下一步」进入步骤1，图示自动填入F₁基因型与表现型，教师讲解如何由F₂的1:1:1:1比例反推F₁，并强调绿色高亮框标记的关键推导节点。
  3. 点击「下一步」进入步骤2，出现F₁交配箭头与标签，教师讲解配子形成与交配过程。
  4. 点击「下一步」进入步骤3，棋盘格与比例汇总完整展开，教师逐格分析F₂基因型与表现型，验证与题目条件的一致性。
  5. 讲解过程中可随时点击「上一步」回退，复习任意环节。

[技术实现]
- JS库选择及原因：原生 SVG + 原生 JavaScript。本场景以静态几何图形、文本、矩形和箭头为主，无需复杂数学计算或3D渲染，原生SVG足以保证清晰度与轻量性。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------------+
  | P  ♀棒眼(纯种)     ×     ♂圆眼(纯种)                  |  y=40~120
  |        ↓                                               |
  | F₁ ( ____ 眼 ) ♀ ♂   → 步骤1: ♀圆眼    ♂棒眼         |  y=130~210
  |        ↓  F₁雌雄交配                                   |
  | F₂  +---------------------+                            |  y=220~430
  |     | Xᴿ  |  Xʳ          |  棋盘格                    |
  |     |-----|--------------|                            |
  |   Xʳ|XᴿXʳ| XʳXʳ         |                            |
  |     |♀圆眼| ♀棒眼        |                            |
  |   Y |XᴿY  | XʳY          |                            |
  |     |♂圆眼| ♂棒眼        |                            |
  |     +---------------------+                            |
  |     ♀圆眼:♀棒眼:♂圆眼:♂棒眼 = 1:1:1:1                |
  |                                                        |
  |        [◀上一步]  步骤 1/4  [下一步▶]                  |  y=440~490 控件区
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `currentStep`（取值 0~3），每次点击按钮时增减，并调用 `render()` 统一更新所有元素的 `display` / `opacity` 属性。避免分散控制，确保状态一致性。
  2. 显示/隐藏策略：所有步骤相关元素在SVG中预先绘制，初始状态通过 CSS `display: none` 或 `opacity: 0` 隐藏。`render()` 根据 `currentStep` 切换对应元素组的可见性。对高亮框和文字使用 `opacity` 过渡（transition: opacity 0.3s），实现柔和出现效果。
  3. 箭头实现：使用 SVG `<line>` 配合 `<marker>` 定义箭头头部，箭头标记在步骤切换时动态显示或隐藏。
  4. 高亮框实现：使用 SVG `<rect>`，填充色为 `#2e7d32`，填充透明度 `fill-opacity="0.2"`，置于被高亮内容的后方（`z-index` 通过 SVG 绘制顺序控制，先画矩形后画文字）。
  5. 棋盘格绘制：外框用 `<rect>`，内部网格线用 `<line stroke="#888888" stroke-dasharray="4,4">`，确保视觉层级清晰。
  6. 控件布局：在 SVG 外部使用一个绝对定位的 `<div>`（`position: absolute; bottom: 15px; left: 0; width: 800px; text-align: center`），内含两个 `<button>` 和一个 `<span>` 作为步骤指示器，确保不占用 SVG 内部坐标空间且始终位于底部。
  7. 按钮禁用逻辑：`currentStep === 0` 时禁用「上一步」，`currentStep === 3` 时禁用「下一步」，通过设置 `disabled` 属性与灰色样式反馈。
- ID命名规范：所有交互元素与可切换元素的 ID 必须以 `scene1-` 为前缀。示例：
  - `scene1-p-female-symbol`
  - `scene1-f1-placeholder`
  - `scene1-f1-female-genotype`
  - `scene1-f1-highlight-female`
  - `scene1-f2-grid`
  - `scene1-f2-cell-xrxr`
  - `scene1-btn-prev`
  - `scene1-btn-next`
  - `scene1-step-indicator`
  JS中严格使用 `document.getElementById` 获取元素，禁止全局 class 选择，避免多场景合并时跨场景污染。
- IIFE隔离：所有 JavaScript 代码包裹在 `(function() { ... })();` 中，内部状态与函数不暴露到全局作用域。
