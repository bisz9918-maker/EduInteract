[图示主题与整合说明]
- 本图示主题：基因位置与显隐性关系的假设对比分析（果蝇眼型遗传）
- 整合内容：将三种并列的遗传假设（常染色体遗传、X染色体伴性遗传+棒眼显性、X染色体伴性遗传+圆眼显性）整合为可切换的对比视图。每种假设展示完整的P→F₁→F₂遗传图解，并与固定的实验结果（♀圆:♀棒:♂圆:♂棒 = 1:1:1:1）进行对照，标注"符合"或"不符合"。
- 教学价值：教师通过状态切换，带领学生用"假设-演绎法"逐一排除错误假设，最终锁定正确遗传方式（X染色体伴性遗传+圆眼显性），强化对伴性遗传规律与常染色体遗传差异的理解。

[分步序列]
本场景为"多状态切换"交互，共3个状态，无时间轴递进关系，教师可任意切换对比。

- 状态1（常染色体假设）——初始加载默认显示：
  * 状态标题："假设一：常染色体遗传"
  * P代：♀ 棒眼(BB) [蓝] × ♂ 圆眼(bb) [红]
  * F₁：♀ Bb(棒眼) [蓝]、♂ Bb(棒眼) [红]
  * F₂：♀棒眼 3/4 [蓝]、♀圆眼 1/4 [蓝]、♂棒眼 3/4 [红]、♂圆眼 1/4 [红]
  * 预期结果框（灰色背景）："棒眼:圆眼 = 3:1（与性别无关）" / "即 ♀棒:♀圆:♂棒:♂圆 = 3:1:3:1"
  * 实验结果框（固定）："♀圆眼:♀棒眼:♂圆眼:♂棒眼 = 1:1:1:1"
  * 对比标记：灰色"✗"，灰色文字"与实验结果不符"
  * 按钮1高亮（灰色底白字），按钮2/3未激活（白底黑字）

- 状态2（X染色体 + 棒眼显性）：
  * 状态标题："假设二：X染色体伴性遗传（棒眼显性）"
  * P代：♀ XᴮXᴮ(棒眼) [蓝] × ♂ XᵇY(圆眼) [红]
  * F₁：♀ XᴮXᵇ(棒眼) [蓝]、♂ XᴮY(棒眼) [红]
  * F₂：♀棒眼 1/2 [蓝]、（雌无圆眼）、♂棒眼 1/4 [红]、♂圆眼 1/4 [红]
  * 预期结果框（灰色背景）："♀圆:♀棒:♂圆:♂棒 = 0:2:1:1" / "雌全棒眼，雄棒:圆 = 1:1"
  * 实验结果框（固定，同状态1）
  * 对比标记：灰色"✗"，灰色文字"与实验结果不符"
  * 按钮2高亮（灰色底白字），按钮1/3未激活

- 状态3（X染色体 + 圆眼显性）：
  * 状态标题："假设三：X染色体伴性遗传（圆眼显性）"
  * P代：♀ XʳXʳ(棒眼) [蓝] × ♂ XᴿY(圆眼) [红]
  * F₁：♀ XᴿXʳ(圆眼) [蓝]、♂ XʳY(棒眼) [红]
  * F₂：♀圆眼 1/4 [蓝]、♀棒眼 1/4 [蓝]、♂圆眼 1/4 [红]、♂棒眼 1/4 [红]
  * 预期结果框（绿色背景）："♀圆:♀棒:♂圆:♂棒 = 1:1:1:1"
  * 实验结果框（固定，同状态1）
  * 对比标记：绿色"✓"，绿色文字"与实验结果一致"
  * 按钮3高亮（绿色底白字），按钮1/2未激活

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：本场景以文本标签、简单几何图形和状态切换为主，无需复杂绘图库；原生SVG对文本排版和上标支持直接且轻量。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +----------------------------------------------------------+
  |              遗传假设对比分析 (400, 22)                   |  y=10~35
  |         假设一：常染色体遗传 (400, 46) [动态]              |
  +----------------------------------------------------------+
  |  P  ♀ [雌P]        ×        ♂ [雄P]                      |  y=75~90
  |         |                                                  |
  |         v                                                  |
  |  F₁ ♀ [雌F1]              ♂ [雄F1]      F₁雌雄交配       |  y=135~175
  |         |                                                  |
  |         v                                                  |
  |  F₂  雌性      |      雄性                                |  y=205~265
  |      [雌1]     |      [雄1]                               |
  |      [雌2]     |      [雄2]                               |
  +----------------------------------------------------------+
  |  +--------------------+     +--------------------+        |  y=305~415
  |  |   预期结果         |  ✗  |   实验结果         |        |
  |  |   [预期比例]       |     |   ♀圆:♀棒:♂圆:♂棒  |        |
  |  |   [补充说明]       |     |   = 1:1:1:1        |        |
  |  +--------------------+     +--------------------+        |
  |       与实验结果不符                                       |
  +----------------------------------------------------------+
  |  [常染色体假设] [X·棒眼显性] [X·圆眼显性]                  |  y=450~485
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：定义 `state` 变量（1/2/3），点击按钮时更新状态并调用 `render()`。
  2. `render()` 函数职责：根据当前状态，更新所有动态元素的 `textContent`、颜色属性（fill/stroke）、显示/隐藏（display属性）。
  3. 上标实现：基因型中的上标字母（如 Xᴮ）使用 SVG `<tspan>` 元素，设置 `baseline-shift="super"` 和较小的 `font-size`（如主字号14px，上标10px）。
  4. 按钮样式切换：通过修改按钮矩形的 `fill` 和文本的 `fill` 实现激活/未激活样式。激活态：状态1/2按钮 fill="#9e9e9e" 文字 fill="#ffffff"；状态3按钮 fill="#2e7d32" 文字 fill="#ffffff"。未激活态：fill="#ffffff" 文字 fill="#000000"，矩形带 stroke="#000000"。
  5. 预期结果框背景切换：修改矩形 fill 颜色并在 CSS/SVG 中设置 `fill-opacity="0.2"`。
  6. 过渡效果：状态切换时，所有动态文本和颜色变化添加 CSS transition（opacity 0.2s ease），提升视觉流畅度。
  7. 固定元素：实验结果框、实验比例文本、实验图示说明在所有状态下保持不变，仅在初始化时绘制一次。
- ID命名规范：所有交互元素 ID 必须以 `scene2-` 为前缀。例如：
  * `scene2-title-main`
  * `scene2-title-state`
  * `scene2-p-female`
  * `scene2-p-male`
  * `scene2-f1-female`
  * `scene2-f1-male`
  * `scene2-f2-female-1`
  * `scene2-f2-female-2`
  * `scene2-f2-male-1`
  * `scene2-f2-male-2`
  * `scene2-expected-box`
  * `scene2-expected-title`
  * `scene2-expected-ratio`
  * `scene2-expected-note`
  * `scene2-actual-box`
  * `scene2-actual-title`
  * `scene2-actual-ratio`
  * `scene2-actual-note`
  * `scene2-compare-mark`
  * `scene2-compare-text`
  * `scene2-btn-1`
  * `scene2-btn-2`
  * `scene2-btn-3`
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })()` 中，避免全局变量污染，确保多场景合并时互不干扰。
