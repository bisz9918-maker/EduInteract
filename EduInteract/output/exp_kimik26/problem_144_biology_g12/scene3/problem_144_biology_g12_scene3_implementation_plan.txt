[图示主题与整合说明]
- 本图示主题：果蝇眼型伴性遗传的两个独立验证实验设计与预期结果
- 整合的步骤/概念：
  1. 验证实验一（测交思路A）：F₂棒眼雌蝇(XʳXʳ) × F₂圆眼雄蝇(XᴿY)，子代表现型与性别完全关联（交叉遗传），直接证明基因位于X染色体。
  2. 验证实验二（测交思路B）：F₂圆眼雌蝇(XᴿXʳ) × F₂棒眼雄蝇(XʳY)，子代四种表现型比例1:1:1:1且与性别相关，相当于测交验证。
- 教学价值：教师通过状态切换，可分别讲解两个独立验证实验的设计逻辑、遗传图解推导过程和预期结果，对比两种方案的验证角度（交叉遗传 vs 测交比例），帮助学生理解伴性遗传的实验设计方法。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：本场景为静态遗传图解的状态切换，无复杂动画或数据可视化，原生SVG足以满足需求，无需引入额外库。
- 画布尺寸：800 × 500 px（固定画布）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |              验证实验一/二 标题行                   |  y=20~65
  |                                                  |
  |   [♀棒眼 XʳXʳ]      ×      [♂圆眼 XᴿY]          |  y=80~150
  |        |                       |                 |
  |       Xʳ                   Xᴿ/Y                |  y=160~230
  |        |                       |                 |
  |   [♀圆眼 XᴿXʳ]            [♂棒眼 XʳY]          |  y=240~330
  |      1/2                    1/2                 |
  |                                                  |
  |   [========== 结论文字框 ==========]              |  y=390~435
  |                                                  |
  |        [验证实验一]  [验证实验二]                  |  y=445~485
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：定义 state 变量（1或2），按钮点击时更新 state 并调用 render()。
  2. 分组管理：SVG中使用两个 `<g>` 元素，id分别为 `scene3-exp1-group` 和 `scene3-exp2-group`，初始时exp1可见、exp2隐藏（display属性控制）。
  3. 共享元素：箭头、亲本框轮廓、交配符号×在两个状态中位置相同，可放在共享层或分别复制到两个组中。为简化实现，建议每个组独立包含全部元素，避免切换时部分元素残留。
  4. 按钮样式切换：通过JS修改按钮className，激活态添加 `active` class（绿底白字），非激活态移除。
  5. 基因型上标：使用 `<tspan>` 的 `baseline-shift="super"` 或 `dy` 属性实现 Xʳ、Xᴿ 的上标效果，确保可读性。
  6. 性别符号：直接使用Unicode字符 ♀(U+2640) 和 ♂(U+2642)，设置较大字号(18px)和对应颜色。
  7. 箭头端点：使用SVG `<marker>` 定义箭头头部，应用于箭头线段的 `marker-end` 属性。
- ID命名规范：所有SVG元素和HTML控件ID必须以 `scene3-` 为前缀。例如：
  - 状态1组：`scene3-exp1-group`
  - 状态2组：`scene3-exp2-group`
  - 雌亲本框：`scene3-p1-female-box`
  - 雄亲本框：`scene3-p1-male-box`
  - 按钮1：`scene3-btn-exp1`
  - 按钮2：`scene3-btn-exp2`
  - 结论框：`scene3-conclusion-box`
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })()` 中，避免全局变量污染，确保多场景合并时互不干扰。
- 事件绑定：使用 `document.getElementById('scene3-btn-exp1').addEventListener('click', ...)`，禁止用 `querySelectorAll` 配合全局class。
