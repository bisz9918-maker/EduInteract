[图示主题与整合说明]
- 本图示主题：两对相对性状的自由组合遗传与概率计算（果蝇体色A/a与眼色X^R/X^r）
- 整合的步骤/概念：P代双杂交 → F1代基因型与表现型验证 → F1自交分解（分支法） → F2代16格棋盘格 → 灰身红眼与黑身白眼比例统计 → F2随机交配黑身白眼概率推导
- 教学价值：教师通过分步导航，逐步展示双基因自由组合从亲本到F2的完整遗传链条；步骤4通过棋盘格高亮直观呈现3:1比例的来源；步骤5分步拆解条件概率，帮助学生理解"在灰身红眼雌与灰身白眼雄中随机选取"这一条件的数学处理

[分步序列]
- 初始状态（步骤0）：显示P代基础条件。画面中央上方为杂交符号"×"，左侧为黑身白眼雌果蝇（aaXʳXʳ），右侧为灰身红眼雄果蝇（AAXᴿY）。各亲本以圆角矩形框+性别符号呈现，基因型与表现型标注于框下方。底部控件栏显示"步骤 1 / 6"。
- 步骤1：点击「下一步」→ 保留P代（opacity可保持1.0），新增从P代指向F1代的箭头；F1代出现在P代下方，雌蝇AaXᴿXʳ（灰身红眼）在左，雄蝇AaXʳY（灰身白眼）在右，F1框使用浅绿背景填充以突出验证题目条件。步骤指示器更新为"F₁代验证"。
- 步骤2：点击「下一步」→ 切换为分支法分解视图。左侧展示常染色体Aa×Aa的分离（1/4 AA : 2/4 Aa : 1/4 aa），右侧展示性染色体XᴿXʳ×XʳY的配子形成与2×2后代组合。步骤指示器更新为"F₁交配分解"。
- 步骤3：点击「下一步」→ 切换为F2代16格棋盘格（Punnett square）。列标题为雌配子AXᴿ、AXʳ、aXᴿ、aXʳ，行标题为雄配子AXʳ、AY、aXʳ、aY，格内填写完整基因型。步骤指示器更新为"F₂棋盘格"。
- 步骤4：点击「下一步」→ 在步骤3棋盘格基础上，左侧新增统计面板；棋盘格内6格灰身红眼格子填充浅蓝半透明，2格黑身白眼格子填充浅红半透明；左侧面板标注"灰身红眼共6/16"与"黑身白眼共2/16"，底部以绿色大字显示"比例 3 : 1"。步骤指示器更新为"表现型统计"。
- 步骤5：点击「下一步」→ 切换为概率计算视图。上方左侧展示F2灰身红眼雌的组成（1/3 AAXᴿXʳ、2/3 AaXᴿXʳ），上方右侧展示F2灰身白眼雄的组成（1/3 AAXʳY、2/3 AaXʳY），中间以"×"连接；下方左侧推导P(黑身)=1/9，右侧推导P(白眼)=1/2；底部中央以绿色高亮框标注最终结论"P(黑身白眼)=1/9×1/2=1/18"。步骤指示器更新为"概率计算"。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本场景以几何框线、文本标签和简单填充为主，无需复杂数据绑定或3D渲染；原生SVG可精确控制每个元素的坐标与显隐，避免引入不必要的库体积。
- 画布尺寸：800 × 500 px（固定），控件栏位于SVG内底部y=445~490区域。
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +----------------------------------------------------+
  |  主标题（居中）                                     |
  |  步骤指示器（居中）                                 |
  |                                                     |
  |  [主内容区 y=50~430]                                |
  |  步骤0-1: 左P代 =========×========= 右P代          |
  |           ↓                         ↓               |
  |           左F1 =================== 右F1             |
  |  步骤2:   左分支(Aa×Aa)    右分支(X×XY)            |
  |  步骤3-4: [统计面板]        [16格棋盘格]            |
  |  步骤5:   [左亲本] × [右亲本]                       |
  |           [概率公式推导区]                          |
  |           [========= 1/18 ========]                 |
  |                                                     |
  |  [控件栏 y=445~490]                                 |
  |       [上一步]  步骤 n/6  [下一步]                  |
  +----------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `let currentStep = 0;`，定义 `const totalSteps = 6;`。每个步骤对应一个SVG `<g>` 分组（id="scene3-step0" 至 "scene3-step5"），通过设置 `display` 属性（或 `opacity` + CSS transition）控制显隐。
  2. 坐标计算：所有坐标在SVG的viewBox="0 0 800 500"内绝对定位，代码agent严格按布局坐标表实现，不动态计算复杂布局。
  3. 动画曲线：步骤切换时，使用CSS `transition: opacity 0.3s ease-in-out;`。当前步骤group opacity=1，其他opacity=0（或display:none）。
  4. 事件绑定：上一步/下一步按钮使用 `addEventListener('click', ...)`，更新currentStep后调用 `renderStep()`，由该函数遍历所有step group设置显隐。
  5. 棋盘格高亮（步骤4）：预先在棋盘格格子位置放置16个 `<rect>`（与格子同尺寸，初始opacity=0），步骤4时通过JS将对应6格设置为fill="rgba(21,101,192,0.2)"、2格设置为fill="rgba(198,40,40,0.2)"，并赋予opacity=1。
  6. 上标处理：基因型中的上标（如Xᴿ、Xʳ）直接使用Unicode字符ᴿ(U+1D3F)、ʳ(U+02B3)，避免使用tspan baseline-shift以简化实现。
- ID命名规范：所有交互元素ID必须以 `scene3-` 为前缀。例如：
  - 步骤分组：`scene3-step0`, `scene3-step1`, ..., `scene3-step5`
  - 按钮：`scene3-btn-prev`, `scene3-btn-next`
  - 步骤指示器：`scene3-step-label`
  - 棋盘格高亮矩形：`scene3-highlight-blue-1` 至 `scene3-highlight-blue-6`, `scene3-highlight-red-1`, `scene3-highlight-red-2`
  - JS中严格使用 `document.getElementById`，禁止用 `querySelectorAll` 配合全局class，避免多场景合并时跨场景污染。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，不暴露全局变量（除必要的事件监听外）。
