[图示主题与整合说明]
- 本图示主题：产物检验装置的选择与连接顺序
- 整合的步骤/概念：
  1. 认识图乙四个装置（a 酒精灯、b 氢氧化钠浓溶液、c 浓硫酸、d 澄清石灰水）及其核心作用；
  2. 分析 CO/H₂ 还原氧化铁后的混合气体成分（CO₂、H₂O、CO、H₂）与检验目标；
  3. 通过错误顺序「图甲→d→c→a」警示溶液对水蒸气检验的干扰；
  4. 演示正确顺序「图甲→c→b→a」，配合气体流向动画与「长进短出」标注；
  5. 总结顺序不可颠倒的核心原因及尾气处理安全意义。
- 教学价值：教师可逐步点击导航，引导学生从「认识装置」到「逻辑推理」再到「实验安全」，随时回退强调关键逻辑节点（尤其是「先吸水后吸 CO₂」）。

  - 教师操作：介绍四个装置的名称和核心作用

- 步骤1（步骤 2）：分析产物与检验目标
  - 新增显示：信息区四行文字

    - "并处理有毒尾气" (400, 302)
  - 保留步骤0所有装置
  - 教师操作：引导学生明确需要测定 CO₂ 和 H₂O，且尾气有毒需处理

- 步骤2（步骤 3）：错误顺序警示
  - 隐藏步骤1信息文字
  - 新增显示：下部错误流程图「图甲→d→c→a」
    - 图甲在左 (100, 360)，装置1=d (280, 350)，装置2=c (460, 350)，装置3=a (640, 350)
    - 三条导管及装置描边全部变为红色 #c62828，线宽 3px
    - 上部 d、c、a 装置边框同步加粗变红（高亮）
  - 新增警示：红色感叹号 (280, 298) + 红色文字 "溶液会干扰水蒸气检验" (400, 298)
  - 新增水蒸气示意：d 装置出口处红色小水滴/波浪线 (320, 335)，示意为「带出 H₂O」
  - 教师操作：讲解若先通入澄清石灰水，气体从溶液流出会带出水蒸气，导致后续水测量不准确

- 步骤3（步骤 4）：正确顺序演示
  - 隐藏步骤2所有错误流程及警示元素
  - 新增显示：下部正确流程图「图甲→c→b→a」
    - 装置1=c (280, 350)，装置2=b (460, 350)，装置3=a (640, 350)
    - 三条导管及装置描边全部变为蓝色 #1565c0，线宽 3px
    - 上部 c、b、a 装置边框同步加粗变蓝（高亮）
  - 新增气体流向箭头：导管中点放置蓝色箭头，沿导管方向（从左向右），带动画（循环平移或脉动）
  - 新增标注：装置1上方 "长进短出" (280, 310) 蓝色，装置2上方 "长进短出" (460, 310) 蓝色
  - 新增确认：右侧绿色对勾 (690, 350)
  - 教师操作：强调必须先经浓硫酸吸水，再经氢氧化钠吸 CO₂，并指出导管「长进短出」

- 步骤4（步骤 5）：总结与安全
  - 保留步骤3正确流程图，描边改为绿色 #2e7d32（或保持蓝色加绿色高亮）
  - 上部 c、b、a 装置边框变绿
  - 新增总结文字（信息区偏下，避免与流程图重叠）：
    - "先吸水后吸 CO₂" (400, 300) 绿色加粗
    - "避免溶液带水干扰" (400, 325) 绿色
    - "尾气处理：防止 CO/H₂ 污染空气" (400, 350) 红色
  - 上部作用标签字体加粗放大（16px→18px）以强调
  - 教师操作：总结顺序不可颠倒的核心原因，强调尾气处理的安全意义

- 关键实现要点：
  1. **状态机设计**：维护变量 `currentStep`（0~4）。`render()` 函数根据 `currentStep` 设置各 SVG 元素/组的 `display` 属性（`block`/`none`）或 `visibility`，并切换高亮 class。
  2. **动态属性切换**：下部流程图的装置1/2在不同步骤代表不同装置（步骤2: d/c，步骤3: c/b）。通过 JS 动态修改 `<rect>` 的 fill（液体颜色）和对应标签的 textContent，避免重复创建两组几何元素。
  3. **高亮实现**：为上部四个装置 group 添加 class（如 `.scene2-highlight-red`、`.scene2-highlight-blue`、`.scene2-highlight-green`），通过 CSS stroke 变色和 stroke-width 加粗实现高亮，避免 JS 逐元素改样式。
  4. **气体流向动画**：步骤3的三个箭头使用 SVG `<animateTransform>` 或 CSS `@keyframes` 实现水平位移动画（从导管左端移到右端，循环 2s，linear），箭头颜色 #1565c0。
  5. **事件绑定**：上一步/下一步按钮绑定 `click` 事件，更新 `currentStep` 后调用 `render()`。在 `render()` 内同步更新步骤指示器文本。
  6. **文字颜色**：步骤1的混合气体成分使用 SVG `<tspan>` 分别设置 fill（CO₂→#1565c0，H₂O→#2e7d32，H₂→#c62828，其余→#000000），保证单行多色且居中。
- **ID 命名规范**：所有 SVG 元素及 HTML 控件 ID 必须以 `scene2-` 为前缀。示例：
  - `scene2-title`、`scene2-a-group`、`scene2-b-liquid`、`scene2-flow-device1`、`scene2-flow-line1`、`scene2-step1-composition`、`scene2-warning-text`、`scene2-arrow1`、`scene2-btn-prev`、`scene2-btn-next`、`scene2-step-indicator`
- **IIFE 隔离**：所有 JavaScript 逻辑包裹在 `(function() { ... })()` 中，避免多场景合并时变量污染。
- **容器结构**：外层 div 尺寸 800×500，position: relative；内部 SVG 占满；按钮用 absolute 定位在 SVG 上方（bottom: 15px）。
