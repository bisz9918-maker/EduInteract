[图示主题与整合说明]
- 本图示主题：甲烷燃烧微观反应的分步探究与选项辨析
- 整合的步骤/概念：题目原图呈现 → 分子识别与化学式标注 → 原子初算（发现图示未配平） → 配平修正（补充O₂和H₂O数量） → 配平后原子守恒验证 → 正确化学方程式书写 → 四个选项正误判断
- 教学价值：教师通过分步导航，引导学生从"观察图示→发现问题→修正配平→验证规律→得出结论"形成完整认知链，可随时回退重讲关键步骤

[分步序列]
- 初始状态（步骤0）「题目原图」：显示与题目完全一致的反应前后微观示意图。左侧1个CH₄分子和1个O₂分子，右侧1个CO₂分子和1个H₂O分子，中间反应箭头标注"点燃"。显示"反应前"/"反应后"区域标签和右上角图例。隐藏分子字母标签、化学式、计数表、方程式、选项、数量框、追踪线。
- 步骤1「识别分子」：在CH₄、O₂、CO₂、H₂O分子正下方依次弹出A、B、C、D字母标签（坐标分别为(140,162)、(280,162)、(520,162)、(680,162)），并在字母下方弹出化学式标签CH₄、O₂、CO₂、H₂O（坐标分别为(140,180)、(280,180)、(520,180)、(680,180)）。图例框加粗边框高亮。
- 步骤2「原子初算」：在左侧显示原子计数表（框体(40,233)-(280,345)），表头"反应前"(120,250)、"反应后"(220,250)。C行：前1后1；H行：前4后2；O行：前2后3。H行和O行的反应后数值用红色（#c62828）高亮，并在计数表右侧显示"未配平"提示（红色）。
- 步骤3「配平修正」：O₂分子由1个动态变为2个（垂直排列：上组氧原子在(265,95)/(295,95)，下组在(265,135)/(295,135)），H₂O分子由1个变为2个（水平排列：左组氧(640,110)/氢(620,140)/(660,140)，右组氧(720,110)/氢(700,140)/(740,140)）。新增数量框包围O₂组（(248,78)-(312,160)）和H₂O组（(605,85)-(760,150)），上方标注"×2"（(280,72)和(680,72)）。新增9条灰色虚线追踪原子去向（C从(140,115)→(520,115)；4个H从CH₄各氢原子→2个H₂O的氢原子；4个O从2个O₂→CO₂的2个氧和2个H₂O的氧）。初始的单个O₂和H₂O隐藏。
- 步骤4「守恒验证」：原子计数表数值更新为反应前C=1、H=4、O=4；反应后C=1、H=4、O=4。所有数值改为绿色（#2e7d32），并在表下方添加"✓ 反应前后原子数目相等"绿色文本。原子追踪虚线保留但透明度降至0.3。
- 步骤5「正确方程式」：在画布中央偏下位置（(420,295)）展示配平后的化学方程式"CH₄ + 2O₂ → CO₂ + 2H₂O"，箭头上方标注"点燃"(420,278)。方程式中的系数"2"（O₂前和H₂O前）用蓝色（#1565c0）高亮加粗。
- 步骤6「选项辨析」：在右下方显示四个选项卡片（A卡y=348，B卡y=372，C卡y=396，D卡y=420）。A选项文字"A. 反应前后原子数目不变"右侧附绿色"✓"和"正确（原子守恒）"；B选项"B. 质量比8:1 ✗ 应为1:4"红色；C选项"C. 方程式未配平 ✗ 缺系数2"红色；D选项"D. 属于置换反应 ✗ 无单质生成"红色。教师可随时点击"上一步"回退复习。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：本场景以静态几何图形（分子球棍模型、表格、箭头）和显示/隐藏控制为主，无需复杂数据绑定或3D渲染，原生SVG性能最优且文件体积最小。

- 关键实现要点：
  1. 状态机设计：使用变量 `currentStep`（0~6），每次点击按钮时更新状态，调用 `renderStep()` 函数根据状态显示/隐藏对应元素。
  2. 元素显隐控制：为每个步骤相关的SVG元素组设置 `class="scene1-step-X"`，通过 CSS `.scene1-step-X { opacity: 0; pointer-events: none; transition: opacity 0.2s; }` 和 `.scene1-step-X.active { opacity: 1; }` 控制淡入淡出。
  3. 配平动画：步骤3中，初始O₂和H₂O的 `opacity` 从1变为0，配平后的O₂和H₂O的 `opacity` 从0变为1，数量框同步淡入。使用 `setTimeout` 实现100ms间隔的错开动画。
  4. 原子追踪线动画：使用SVG `stroke-dasharray` 和 `stroke-dashoffset` 配合CSS动画，实现虚线"绘制"效果（1s内从0%到100%）。
  5. 碳原子斜线填充：在SVG `<defs>` 中定义 `<pattern id="scene1-carbon-pattern" patternUnits="userSpaceOnUse" width="6" height="6" patternTransform="rotate(45)"><line x1="0" y1="0" x2="0" y2="6" stroke="#888888" stroke-width="1.5"/></pattern>`，碳原子圆 `fill="url(#scene1-carbon-pattern)"`。
  6. 计数表数值更新：步骤2和步骤4共用同一组数值文本元素，通过JS修改 `textContent` 和 `fill` 属性实现切换。
  7. 方程式系数高亮：将两个"2"系数包裹在 `<tspan fill="#1565c0" font-weight="bold">` 中。
  8. 选项卡片判断图标：使用Unicode字符 "✓"(U+2713) 和 "✗"(U+2717)，分别设置绿色和红色。
- ID命名规范：所有SVG元素和JS变量必须以 `scene1-` 为前缀。例如：`scene1-ch4-carbon`、`scene1-o2-group-initial`、`scene1-atom-tracker-1`、`scene1-btn-prev`、`scene1-btn-next`、`scene1-step-indicator`。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })()` 中，避免多场景合并时的全局变量污染。
- 事件绑定：使用 `document.getElementById('scene1-btn-prev').addEventListener('click', ...)` 和 `document.getElementById('scene1-btn-next').addEventListener('click', ...)`，不用 `querySelectorAll` 配合全局class。
