[图示主题与整合说明]
- 本图示主题：红磷燃烧法测定空气中氧气含量的实验装置与完整过程演示

[分步序列]
- 步骤0「装置认知」（初始状态）：
  - 显示完整装置：集气瓶、燃烧匙、红磷、导管、止水夹、烧杯、水
  - 高亮瓶内水（蓝色填充）和5条刻度虚线及数字1-5
  - 显示标签：集气瓶、燃烧匙、红磷、导管、止水夹、烧杯、水（烧杯侧）、水（集气瓶侧，绿色"吸收热量与白烟"）
  - 集气瓶水区域悬停提示："目的：①吸收热量加速冷却 ②吸收五氧化二磷白烟 ③便于观察液面变化"

- 步骤1「点燃红磷」：
  - 新增/高亮：红磷高亮（红色描边加粗），显示"点燃"(220,150)、"足量红磷"(220,200)、"耗尽氧气"(220,270)
  - 说明文字：红磷稍过量的目的是确保集气瓶内氧气被完全消耗，避免因氧气残留导致测定结果偏小
  - 保留步骤0所有装置元素

- 步骤2「燃烧反应」：
  - 新增：燃烧匙周围显示火焰(180,255)和白烟圆点组(170,225)/(190,220)/(180,210)
  - 新增标签：反应文字表达式"红磷+氧气→五氧化二磷"(280,70)，"消耗氧气，生成固体"(280,95)
  - 红磷保持高亮
  - 说明：消耗氧气，生成固体五氧化二磷，瓶内气体减少

- 步骤3「冷却至室温」：
  - 新增：雪花图标(260,200)表示温度下降
  - 新增标签："冷却至室温"(300,160)，"必须冷却至室温再打开止水夹"(300,185)
  - 隐藏火焰和白烟
  - 说明：若未冷却，瓶内气体温度高、压强偏大，会导致进入水量偏少，测定结果偏小

- 步骤4「打开止水夹」：
  - 变化：止水夹图形切换为"打开"状态（夹臂张开示意）
  - 新增：导管内蓝色向左箭头(430,118)表示水流方向；集气瓶水面从y=320动画上升到y=276；烧杯水面从y=310动画下降到y=346
  - 新增标签："打开止水夹"(420,80)
  - 动画时长：800ms，ease-out

- 步骤5「实验结论」：
  - 水面稳定在y=276（上升约1/5体积）
  - 高亮：刻度线2（y=276）及数字"2"用红色加粗显示，表示水面到达位置
  - 新增标签："氧气约占空气体积1/5"(280,300)红色加粗，"剩余气体主要为氮气(约4/5)"(280,200)绿色
  - 集气瓶内水面以上剩余空间标注为氮气区域（可添加淡绿色背景或文字提示）
  - 说明：剩余气体不支持燃烧、难溶于水

[技术实现]
- JS库选择：原生SVG + 原生JavaScript（无外部库）。理由：本场景以静态装置图和简单状态切换为主，SVG原生支持图形绘制、显隐控制和SMIL动画，无需引入重量级库。
- 画布尺寸：800×500 px（SVG viewBox="0 0 800 500"）
- 布局草图：
  ```
  +--------------------------------------------------+
  |  反应式标签区(y=60~100)                           |
  |  止水夹标签(y=80)    导管标签(y=95)               |
  |                                                  |
  |   集气瓶标签(y=240)    燃烧匙标签(y=150)          |
  |      |                  |                        |
  |   [集气瓶]           [燃烧匙+红磷]                |
  |   |1|2|3|4|5|            |                       |
  |   ~~~~~~~~~~  ←水面    [导管]=====[止水夹]===|    |
  |   ~~~~~~~~~~                                |    |
  |   ~~~~~~~~~~                                |    |
  |   ~~~~~~~~~~                             [烧杯]  |
  |   ~~~~~~~~~~                              ~~~~   |
  |                                            ~~~~  |
  |                                             ~~~~ |
  |                                                  |
  |              步骤名称 (y=430)                     |
  |         [◀ 上一步]  [下一步 ▶] (y=455)           |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `let currentStep = 0;` 记录当前步骤（0~5）。每步对应一个显示元素ID列表，通过 `classList.add/remove('hidden')` 控制显隐。
  2. 元素显隐：所有步骤专属元素初始设置 `class="hidden"`（CSS: `.hidden { display: none; }`），切换步骤时先隐藏所有专属元素，再显示当前步对应的元素。
  3. 水面上升动画（步骤4）：使用SVG `<animate>` 元素或JS `requestAnimationFrame` 修改水面矩形的 `y` 和 `height` 属性。集气瓶水面从y=320→276（height从78→122），烧杯水面从y=310→346（height从90→54），动画时长800ms，ease-out曲线。
  4. 水流箭头：步骤4显示，使用SVG `<polygon>` 画三角形箭头，放在导管水平段内(x=430,y=118)，指向左方（朝向集气瓶）。
  5. 火焰/白烟：步骤2显示，火焰用 `<ellipse>` 橙红填充，白烟用多个 `<circle>` 白色半透明。
  6. 悬停提示（步骤0）：集气瓶水区域绑定 `mouseenter/mouseleave` 事件，显示/隐藏一个绝对定位的tooltip div，内容"①吸收热量加速冷却 ②吸收五氧化二磷白烟 ③便于观察液面变化"。
  7. 按钮状态：步骤0时禁用「上一步」，步骤5时禁用「下一步」，通过设置 `disabled` 属性实现。
  8. 刻度高亮（步骤5）：刻度线2和数字"2"添加红色描边/填充，其他刻度恢复灰色。
- ID命名规范：所有SVG元素和交互元素ID必须以 `scene1-` 为前缀。例如：
  - 集气瓶：`scene1-bottle`
  - 瓶内水：`scene1-bottle-water`
  - 燃烧匙：`scene1-spoon`
  - 红磷：`scene1-phosphorus`
  - 导管：`scene1-tube-h` / `scene1-tube-v`
  - 止水夹：`scene1-clamp`
  - 烧杯：`scene1-beaker`
  - 烧杯水：`scene1-beaker-water`
  - 刻度线1~5：`scene1-mark-1` ~ `scene1-mark-5`
  - 数字1~5：`scene1-num-1` ~ `scene1-num-5`
  - 火焰：`scene1-flame`
  - 白烟组：`scene1-smoke-1` 等
  - 步骤标签：`scene1-label-xxx`
  - 按钮：`scene1-btn-prev` / `scene1-btn-next`
