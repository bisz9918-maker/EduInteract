[图示主题与整合说明]
- 本图示主题：可逆反应提纯钴的装置结构与动态过程演示
- 整合的步骤/概念：
  1. 装置整体结构（水平管道、容器1、容器2、气体进出口）
  2. 反应方程式与温度条件的对应关系
  3. 含杂质Co在容器1的初始状态（Co与杂质视觉区分）
  4. 容器1中900℃正向反应：Co(固) + 2HCl(气) → CoCl₂(气) + H₂(气)
  5. 气态产物（CoCl₂ + H₂）通过管道向容器2迁移
  6. 容器2中600℃逆向反应：CoCl₂(气) + H₂(气) → Co(固) + 2HCl(气)
  7. 最终结果：容器2沉积纯净Co，HCl从出口流出可循环，杂质留在容器1
- 教学价值：教师通过分步导航精确控制每个阶段的讲解节奏，学生可跟随物质状态变化（固→气→固）和温度条件理解化学迁移提纯原理，同时直观区分杂质与目标产物的行为差异。

[分步序列]
- 初始状态（步骤0）：显示水平管道装置、容器1、容器2。容器1底部显示棕色Co圆形颗粒（15个）和橙色杂质方形颗粒（5个）。容器2为空。显示"容器1"、"容器2"、"含杂质Co"标签。入口/出口箭头显示。等待教师触发。
- 步骤1（通入气体）：新增左侧蓝色HCl粒子流（约20个蓝色小圆点）从x=100流向x=190，表示HCl气体通入。显示"气体Y：HCl"标签。教师讲解反应物引入。
- 步骤2（容器1高温反应）：高亮容器1（蓝色发光边框）。显示"900℃"标签。容器1内Co颗粒数量减少（隐藏约2/3）。容器1内出现红色CoCl₂粒子（约15个）和绿色H₂粒子（约15个），表示气态产物生成。顶部显示正向反应方程式"Co + 2HCl → CoCl₂ + H₂"（标注900℃）。"含杂质Co"标签切换为"杂质（不参加反应）"。教师讲解正向反应与温度条件。
- 步骤3（气态迁移）：隐藏容器1内大部分粒子。在连接管道（x=310~490, y=250~270）显示红色与绿色混合粒子流（约25个），表示CoCl₂和H₂向容器2迁移。添加虚线流动箭头示意方向。教师讲解物质迁移过程。
- 步骤4（容器2低温逆反应）：高亮容器2（红色发光边框）。显示"600℃"标签。隐藏迁移粒子。容器2内出现红色CoCl₂和绿色H₂粒子（约15个各），同时容器2底部逐渐出现棕色Co颗粒（约10个），表示Co沉积。右侧管道出现蓝色HCl粒子流向出口。顶部显示逆向反应方程式"CoCl₂ + H₂ → Co + 2HCl"（标注600℃）。显示"纯净Co"标签。教师讲解逆反应与沉积原理。
- 步骤5（最终结果与循环）：隐藏所有气态粒子。容器2底部显示完整棕色Co颗粒。右侧出口显示"可循环使用"标签。容器1底部仅残留橙色杂质颗粒。顶部显示"提纯完成——纯净Co在容器2，HCl可循环"。教师总结提纯原理与装置优势。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位置(300, 455)，宽90px，高32px。点击回退到上一步骤，步骤0时禁用。
  - 「下一步 ▶」按钮：位置(410, 455)，宽90px，高32px。点击前进到下一步，步骤5时禁用（或变为「完成」）。
  - 步骤指示器：位置(400, 490)，显示"步骤 X / 5"。
- 教师操作流程：
  1. 教师打开图示，学生看到装置初始状态（步骤0）。
  2. 教师点击「下一步」进入步骤1，讲解HCl气体通入。
  3. 教师点击「下一步」进入步骤2，重点讲解容器1的900℃正向反应，观察Co转化为气态产物。
  4. 教师点击「下一步」进入步骤3，讲解气态产物沿管道迁移。
  5. 教师点击「下一步」进入步骤4，重点讲解容器2的600℃逆反应，观察Co沉积和HCl再生。
  6. 教师点击「下一步」进入步骤5，总结提纯结果和HCl循环使用。
  7. 教师可随时点击「上一步」回退复习关键步骤。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript。理由：本场景以静态几何图形和分步显示/隐藏为主，粒子数量少（每组<30个），无需复杂物理引擎或数据绑定。原生SVG可精确控制每个粒子和标签的显示状态，且便于教师直接修改坐标。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------------+
  |              [反应方程式/提纯完成  顶部居中]              |  y=20~80
  |                                                        |
  |  气体Y:HCl    [容器1]          [容器2]    可循环使用      |  y=200~230
  |      ↓         |                |            ↑          |
  |   [====|======|================|======|====]           |  y=240~280 管道
  |        |      |                |      |                |
  |        |   [Co+杂质]        [纯净Co]  |                |  y=360~390
  |        |      |                |      |                |
  |      900℃   杂质            600℃                      |  y=420
  |                                                        |
  |           [◀ 上一步]  [下一步 ▶]                       |  y=455 控件
  |                  步骤 X / 5                            |  y=490
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `currentStep`（0~5），每次点击按钮更新状态，调用 `renderStep()` 函数根据当前步骤显示/隐藏对应元素组。
  2. 元素分组：所有SVG粒子/标签按步骤分组，赋予 class 如 `scene1-step1-only`、`scene1-step2-only` 等，`renderStep()` 统一设置 `display` 属性。
  3. 坐标计算：容器1/2使用SVG path绘制圆底烧瓶（M→L→A→Z），高亮框使用相同path外扩5px（stroke-width叠加）。
  4. 动画曲线：粒子出现/隐藏使用CSS transition（opacity 0.3s ease），无需复杂动画。固体颗粒的"逐渐减少"通过分批次隐藏（步骤2隐藏2/3，步骤5隐藏全部）实现。
  5. 事件绑定：按钮点击事件在IIFE内绑定，更新 `currentStep` 后调用 `renderStep()` 和 `updateButtons()`。
  6. 固体颗粒随机分布：使用固定seed的伪随机函数生成颗粒坐标，确保每次刷新位置一致。容器1：15个Co圆+5个杂质方；容器2：10个Co圆。
  7. 反应方程式切换：步骤2显示正向方程式（蓝色高亮），步骤4显示逆向方程式（红色高亮），步骤5显示总结文字，其余步骤隐藏。
- ID 命名规范：所有交互元素ID必须以 `scene1-` 为前缀。例如：`scene1-container1`、`scene1-btn-prev`、`scene1-btn-next`、`scene1-step-indicator`、`scene1-equation`、`scene1-highlight-c1`。JS中使用 `document.getElementById` 获取元素。
- IIFE 隔离：所有JavaScript代码包裹在 `(function() { ... })()` 中，避免全局命名空间污染，确保多场景合并时互不干扰。
