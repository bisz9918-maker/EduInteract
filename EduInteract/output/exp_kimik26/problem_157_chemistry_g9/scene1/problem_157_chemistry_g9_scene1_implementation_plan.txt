[图示主题与整合说明]
- 本图示主题：溶解度曲线及溶液状态点认知
- 整合的步骤/概念：
  1. 建立溶解度曲线坐标系（温度-溶解度直角坐标系）；
  2. 识别曲线上A点（t₂, S₂）表示饱和溶液、曲线下B点（t₃, S₁）和M点（t₂, S₁）表示不饱和溶液；
  3. 理解A点饱和溶液的溶质质量分数表达式 w = S₂/(100+S₂) × 100%。
- 教学价值：教师通过分步导航，可按照"认识坐标系→定位饱和点→定位不饱和点→同温对比→导出公式"的认知递进顺序进行课堂讲解，随时回退强化关键概念。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  • 「上一步」按钮：位置(300,455)，宽80×高30，点击回退到上一分步，步骤0时禁用
  • 「步骤指示器」：位置(390,455)，宽60×高30，显示当前步骤文本如"步骤 1/4"
  • 「下一步」按钮：位置(460,455)，宽80×高30，点击前进到下一分步，步骤4时禁用
- 教师操作流程：
  1. 教师打开图示，步骤0展示完整坐标系与曲线，介绍横纵轴含义；
  2. 点击「下一步」进入步骤1，A点高亮为蓝色并显示投影，讲解"曲线上=饱和溶液"；
  3. 点击「下一步」进入步骤2，B点高亮为红色，讲解"曲线下=不饱和溶液"及温度t₃时的状态；
  4. 点击「下一步」进入步骤3，M点高亮为红色，与A点作同温对比（t₂℃下S₁<S₂，故M不饱和）；
  5. 点击「下一步」进入步骤4，展示A点饱和溶液的溶质质量分数公式；
  6. 讲解过程中可随时点击「上一步」回退，强化学生认知。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript（无需外部库，简单几何图形和状态切换用原生实现最轻量）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |  溶解度（克）                                      |
  |     ↑                                              |
  |  S₂ ┤    ● A                                       |
  |     │    │  ... 上升曲线                           |
  |  S₁ ┤────┼───● M        [右侧说明面板]             |
  |     │    │   │ B          步骤动态文本             |
  |     └────┼───┼──────→ 温度（℃）                   |
  |         t₁  t₂  t₃                                |
  |                                                    |
  |         [◀ 上一步] [步骤 1/4] [下一步 ▶]          |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep（0~4）控制当前步骤，所有视觉元素根据currentStep值显示/隐藏/变色
  2. 坐标计算：坐标系原点(120,400)，横轴比例约80px/单位温度，纵轴比例约1px/单位溶解度（相对比例），A(320,180)、B(440,300)、M(320,300)
  3. 动画曲线：状态切换不使用复杂动画，直接改变属性（fill、stroke、display），确保课堂讲解响应迅速；如需过渡可用CSS transition 0.2s
  4. 事件绑定：上一步/下一步按钮绑定click事件，更新currentStep后调用render()函数重绘状态
  5. 投影虚线控制：每条投影线设置独立的SVG line元素，通过设置stroke="none"或display="none"控制显隐，步骤切换时同步更新
  6. 右侧说明面板：使用绝对定位的div覆盖在SVG上方，或直接在SVG内使用foreignObject/text元素；推荐SVG内text元素便于统一管理，步骤切换时更新textContent和fill颜色
  7. 按钮禁用逻辑：currentStep===0时禁用「上一步」，currentStep===4时禁用「下一步」
- ID命名规范：
  • 横轴：scene1-axis-x
  • 纵轴：scene1-axis-y
  • 曲线：scene1-curve
  • A点：scene1-point-a
  • B点：scene1-point-b
  • M点：scene1-point-m
  • A垂直投影：scene1-proj-a-v
  • A水平投影：scene1-proj-a-h
  • B垂直投影：scene1-proj-b-v
  • B水平投影：scene1-proj-b-h
  • M垂直投影：scene1-proj-m-v
  • M水平投影：scene1-proj-m-h
  • 上一步按钮：scene1-btn-prev
  • 下一步按钮：scene1-btn-next
  • 步骤指示器：scene1-step-indicator
  • 右侧说明文本组：scene1-info-title、scene1-info-line1~line4
- IIFE隔离：所有JavaScript代码包裹在 (function() { ... })() 中，避免多场景合并时变量污染
