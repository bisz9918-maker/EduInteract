[图示主题与整合说明]
- 本图示主题：溶液状态变化规律与不饱和溶液的饱和化
- 整合的步骤/概念：
  1. 恒温加水对A、B溶解度与溶质质量分数的影响；
  2. A点饱和溶液降温析出晶体与质量分数变化；
  3. M点不饱和溶液变为饱和溶液的三种途径（降温、增加溶质、蒸发溶剂）。
- 教学价值：教师通过分步导航，按"改变条件→观察点移动/状态变化→得出新状态与数值"的逻辑链逐步讲解，可灵活控制课堂节奏，配合右侧公式面板即时呈现定量结论。

[分步序列]
- 初始状态（步骤0）：显示坐标系、溶解度曲线、A/B/M三点及六条辅助虚线；右侧面板显示三点初始状态（A-蓝色"饱和溶液"，B-红色"不饱和溶液"，M-红色"不饱和溶液"）；控件显示"1/6"。
- 步骤1（恒温加水）：点击「下一步」→ 右侧面板更新为"恒温加水（各+20g）"，显示"溶剂：100g → 120g"、"A状态：不饱和"；展示质量分数公式 wₐ = S₂/(120+S₂) 与 wₑ = S₁/(120+S₁)；绿色高亮结论"前者大"。
- 步骤2（A点降温）：点击「下一步」→ A点沿曲线向左下方动画移动至(220,320)；轨迹蓝色高亮；在(260,280)显示灰色晶体析出符号；右侧面板显示"晶体析出"、降温后质量分数 w' = S₁/(100+S₁)；绿色高亮结论"减小"。
- 步骤3（M降温至饱和）：点击「下一步」→ 显示红色水平箭头从M(300,320)指向(220,320)；标注"恰好饱和"；右侧面板显示"降温至 t₁℃"、"恰好饱和"（填空提示）。
- 步骤4（M增加溶质）：点击「下一步」→ 显示红色垂直实线箭头从M(300,320)指向A(300,240)；旁标注"增加溶质 (S₂-S₁) g"；右侧面板显示对应计算。
- 步骤5（M蒸发溶剂）：点击「下一步」→ 显示红色垂直虚线箭头从M(300,320)指向A(300,240)；旁标注"蒸发溶剂"；右侧面板显示计算式"100(S₂-S₁)/S₂ g水"。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于(320,465)，80×30px，点击回退到上一状态
  - 步骤指示器：位于(400,465)，显示当前步骤/总步骤（如"1/6"）
  - 「下一步」按钮：位于(480,465)，80×30px，点击前进到下一状态
- 教师操作流程：
  1. 教师打开图示，步骤0展示基础溶解度曲线与三点位置，讲解A、B、M的初始状态；
  2. 点击「下一步」进入步骤1，讲解恒温加水后溶剂变化与质量分数对比；
  3. 点击「下一步」进入步骤2，观察A点沿曲线降温移动，讲解晶体析出与质量分数减小；
  4. 依次点击后续步骤，分别讲解M点三种饱和化方法；
  5. 可随时点击「上一步」让学生回顾前一状态，强化因果逻辑。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本场景以几何图形、状态切换和简单路径动画为主，原生SVG足以高效实现，无需引入D3等重型库，保持代码轻量。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------------+
  |  [纵轴标题]                                            |
  |     |  溶解度（克）                                    |
  |     |        /|                                        |
  |    S₂------A |      右侧信息面板                        |
  |     |      / |      (500,60)-(760,400)                  |
  |    S₁----M---B      步骤公式与结论                      |
  |     |    |   |                                         |
  |     +----|---|--- 温度（℃）                             |
  |         t₁ t₂ t₃                                       |
  |                                                        |
  |              [◀ 上一步] [1/6] [下一步 ▶]               |
  +--------------------------------------------------------+
  控件栏区域：y=440~490
  ```
- 关键实现要点：
  1. 状态机设计：定义变量 `let currentStep = 0;`（范围0~5），数组 `stepElements` 存储每步需显示/隐藏的SVG元素ID列表，切换步骤时遍历设置 `display` 属性。
  2. 坐标计算：所有坐标硬编码于SVG的 `d`、`x`、`y`、`cx`、`cy` 属性中，严格遵循布局坐标表。
  3. 动画曲线：步骤2的A点移动使用SVG `<animateMotion>` 沿预定义曲线路径（从A到t₁段）播放，持续时间1s，fill="freeze"；代码中通过JS触发 `beginElement()`。
  4. 事件绑定：上一步/下一步按钮绑定 `click` 事件，调用 `goToStep(n)` 函数，内部先 `hideAllStepElements()` 再 `showElementsForStep(n)`，最后更新指示器文本。
  5. 箭头标记：使用SVG `<marker>` 定义箭头头部，id为 `scene2-arrow-red`，应用于步骤3/4/5的箭头线。
  6. 右侧面板：使用绝对定位的HTML div覆盖在SVG上方（`position:absolute; left:500px; top:60px`），每步切换内部HTML内容；或直接用SVG foreignObject/text元素。推荐用SVG `<text>` 分组管理，避免跨层。
- **ID 命名规范**：所有交互元素ID必须以 `scene2-` 为前缀。例如：
  - 坐标系：`scene2-axis-x`、`scene2-axis-y`
  - 曲线：`scene2-curve`
  - 三点：`scene2-point-a`、`scene2-point-b`、`scene2-point-m`
  - 辅助线：`scene2-guide-a-x`、`scene2-guide-a-y` 等
  - 步骤元素：`scene2-step2-trace`、`scene2-step2-crystal`、`scene2-step3-arrow`、`scene2-step4-arrow-solid`、`scene2-step5-arrow-dashed`
  - 面板内容：`scene2-panel-step0`、`scene2-panel-step1` 等
  - 控件：`scene2-btn-prev`、`scene2-btn-next`、`scene2-step-indicator`
  - JS中严格使用 `document.getElementById('scene2-xxx')` 获取元素，禁止用 `querySelectorAll` 配合全局class。
- IIFE 隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免全局变量污染，确保多场景合并时互不干扰。
