[图示主题与整合说明]
- 本图示主题：三组物质转化关系的分步判断与验证（初中化学推断题）
- 整合的步骤/概念：
  1. ①组钙三角（CaCO₃—CaO—Ca(OH)₂）的转化条件与正误判断
  2. ②组铁及其化合物（Fe—Fe₂O₃—FeSO₄）的转化条件与正误判断，重点揭示Fe₂O₃→FeSO₄不能一步实现的本质原因（生成Fe₂(SO₄)₃而非FeSO₄）
  3. ③组水、氧气与氧化镁（H₂O—O₂—MgO）的转化条件与正误判断
  4. 综合结论确定选项B（①③）
- 教学价值：教师通过分步导航控制讲解节奏，先建立整体结构认知，再逐组聚焦分析反应条件与可行性，最后汇总结论。可随时回退复习，符合化学推导的多步骤认知规律。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  1. 「◀ 上一步」按钮：位于画布底部中央偏左，中心(340,460)，宽90×高32。点击后currentStep减1，回退到上一状态，用于教师复习。
  2. 「下一步 ▶」按钮：位于画布底部中央偏右，中心(460,460)，宽90×高32。点击后currentStep加1，进入下一分析步骤。在步骤4时禁用或隐藏。
  3. 步骤指示文字：位于按钮上方(400,430)，显示"步骤 X / 4：..."，帮助教师定位当前讲解进度。
- 教师操作流程：
  1. 课堂开始，图示处于步骤0（总览），教师引导学生观察三组转化结构。
  2. 点击「下一步」进入步骤1，聚焦①组，教师讲解钙三角的三个一步转化及条件。
  3. 点击「下一步」进入步骤2，聚焦②组，教师讲解铁三角，重点指出Fe₂O₃→FeSO₄不可一步实现的原因（氧化还原与化合价变化），配合红色叉号和说明框。
  4. 点击「下一步」进入步骤3，聚焦③组，教师讲解水氧镁三角的三个一步转化。
  5. 点击「下一步」进入步骤4，三组同时显示，①③绿框、②红框，得出答案B。教师总结。
  6. 可随时点击「上一步」回退到任意步骤重新讲解。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本场景以静态几何图形和状态切换为主，无复杂动画或数据可视化，原生SVG足以高效实现，无需引入D3/Three.js等重型库，保持代码轻量。
- 画布尺寸：800 × 500 px（固定），SVG容器设置viewBox="0 0 800 500"。
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |  [CaCO₃]        [Fe]          [H₂O]              |  y=63~97
  |     ↘            ↘              ↘                |
  |      ↘ 高温      ↘ 缓慢氧化     ↘ 通电           |  y=170
  |  [CaO] → [Ca(OH)₂]  [Fe₂O₃] → [FeSO₄]  [O₂]→[MgO]| y=243~277
  |       +H₂O  +CO₂      +H₂SO₄  +Zn      Mg+点燃 +HCl| y=285
  |  ①              ②  ✗              ③              |  y=295~325
  |       [说明框：Fe₂O₃与稀硫酸反应...]              |  y=355~405（仅步骤2）
  |              [答案：B．①③]                      |  y=395（仅步骤4）
  |              步骤 X / 4：...                     |  y=430
  |         [◀ 上一步]  [下一步 ▶]                   |  y=444~476
  +--------------------------------------------------+
  画布：800×500
  ```
- 关键实现要点：
  1. 状态机设计：用变量 `let currentStep = 0;` 记录当前步骤（0~4）。每次按钮点击更新状态后调用 `render()`。
  2. 分组管理：每个三角图用 `<g id="scene1-group-1">`、`<g id="scene1-group-2">`、`<g id="scene1-group-3">` 包裹，便于整体设置opacity和stroke颜色。
  3. 元素显隐：所有步骤性元素（反应条件、判断文字、叉号、说明框、答案）初始设置 `display: none` 或 `visibility: hidden`，`render()` 中根据currentStep批量切换。
  4. 样式切换：通过切换CSS类实现高亮/淡化：
     - `.dimmed { opacity: 0.5; }` + 子元素stroke=#888888
     - `.highlight-blue { stroke: #1565c0; stroke-width: 3px; }`
     - `.highlight-green { stroke: #2e7d32; stroke-width: 3px; }`
     - `.highlight-red { stroke: #c62828; stroke-width: 3px; }`
  5. 箭头实现：SVG `<path>` 配合 `<marker>` 定义箭头头部，markerUnits="strokeWidth"，orient="auto"。
  6. 按钮状态：步骤0时禁用「上一步」，步骤4时禁用「下一步」（或改为「完成」并禁用）。
  7. 坐标计算：所有坐标硬编码于SVG中，不依赖动态计算，确保代码agent严格按坐标实现。
- ID命名规范：所有交互元素ID必须以 `scene1-` 为前缀。示例：
  - 外边框：`scene1-border-1`、`scene1-border-2`、`scene1-border-3`
  - 物质框：`scene1-box-caco3`、`scene1-box-feo` 等
  - 箭头：`scene1-arrow-1-top`、`scene1-arrow-1-bottom`、`scene1-arrow-1-right`
  - 反应条件：`scene1-cond-1-high`、`scene1-cond-2-h2so4` 等
  - 判断文字：`scene1-result-1`、`scene1-result-2`、`scene1-result-3`
  - 叉号：`scene1-cross-icon`
  - 说明框：`scene1-tooltip-box`、`scene1-tooltip-text`、`scene1-tooltip-line`
  - 答案：`scene1-final-answer`
  - 按钮：`scene1-btn-prev`、`scene1-btn-next`
  - 步骤指示：`scene1-step-label`
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免多场景合并时全局变量污染。
