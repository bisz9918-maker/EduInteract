[图示主题与整合说明]
- 本图示主题：叠放与并排放置木块的受力分析及滑动摩擦力对比
- 整合的步骤/概念：图甲（叠放）物理情景 → 图甲整体四力平衡分析 → 图乙（并排）物理情景 → 图乙整体四力平衡分析 → 压力/摩擦力/接触面积/速度对比 → 结论 F₂ = 100N（选B）
- 教学价值：教师可逐步引导学生从直观情景过渡到抽象受力分析，通过左右对比让学生理解滑动摩擦力仅与压力和动摩擦因数有关，与接触面积、运动速度无关。分步导航支持教师随时回退重讲关键步骤。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「◀ 上一步」按钮：位置(300,460)，宽80高28。作用：回退到上一步骤，隐藏当前步骤新增的元素，恢复前一状态。
  2. 「下一步 ▶」按钮：位置(420,460)，宽80高28。作用：前进到下一步骤，显示该步骤应出现的受力分析箭头、标注或结论卡片。
  3. 步骤指示器：位置(400,452)，显示"步骤 k / 4"（k=1~4，对应步骤0~3）。始终可见，帮助学生定位当前讲解进度。
- 教师操作流程：
  1. 教师打开图示，默认步骤0，让学生观察图甲叠放与图乙并排的情景，读出已知条件 F₁=100N、V₁=1m/s、V₂=2m/s。
  2. 教师点击「下一步」进入步骤1，引导学生对图甲整体进行受力分析，写出平衡方程 F₁=f₁=100N、N₁=2G。
  3. 教师点击「下一步」进入步骤2，引导学生对图乙整体进行受力分析，写出平衡方程 F₂=f₂、N₂=2G。
  4. 教师点击「下一步」进入步骤3，引导学生对比 N₁=N₂=2G、μ相同，得出 f₁=f₂=100N，故 F₂=100N，选B。强调与接触面积、速度无关。
  5. 若学生某步未理解，教师点击「上一步」回退重新讲解。

[技术实现]
- JS 库选择：原生 SVG（通过 JavaScript 操作 DOM 显示/隐藏元素）。原因：本场景为静态几何图示与分步显隐，无复杂动画路径或数据绑定，原生 SVG 足够轻量且可控。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |              标题区 (y=20~50)                      |
  |  +-------------------+    +-------------------+  |
  |  |    图甲情景区      |    |    图乙情景区      |  |
  |  |  [B]              |    |  [A][B]           |  |
  |  |  [A]  F₁→  V₁→    |    |  F₂→ [A][B] V₂→   |  |
  |  |  =================|    |  =================|  |
  |  |    图甲           |    |    图乙           |  |
  |  |  (步骤1+受力箭头) |    |  (步骤2+受力箭头) |  |
  |  +-------------------+    +-------------------+  |
  |         结论卡片区 (步骤3+, y=365~435)            |
  |  [◀ 上一步]  步骤 k/4  [下一步 ▶]                |
  +--------------------------------------------------+
  控件栏在 y=455~490（SVG 内部绝对定位）
  ```

- 关键实现要点：
  1. 状态机设计：使用变量 `let currentStep = 0;` 记录当前步骤（0~3）。定义 `const stepElements = { 0: [...], 1: [...], 2: [...], 3: [...] }`，存储各步骤应显示的元素 ID 列表。切换步骤时，先隐藏所有步骤专属元素，再显示当前步骤对应的元素。
  2. 元素显隐：所有步骤专属元素（受力箭头、重心点、平衡标注、结论卡片）初始 `display: none` 或 `visibility: hidden`。切换时通过 `setAttribute('display', 'block'/'none')` 或修改 CSS class（如 `.hidden` / `.visible`）控制。
  3. 高亮动画：步骤1/2中 F₁/F₂ 箭头的高亮使用 SVG `<animate>` 或 JS 定时器修改 `stroke-width`（2px→3px→2px，持续300ms）。步骤3中结论卡片使用 CSS `transition: opacity 0.4s ease` 淡入。N₁/N₂、f₁/f₂ 的相等提示使用 JS 动态创建临时 rect 背景，设置 `opacity: 0.3`，200ms 后移除。
  4. 箭头绘制：使用 SVG `<marker>` 定义箭头头部（id="scene1-arrow-blue"/"red"/"green"），在 `<line>` 或 `<path>` 上通过 `marker-end` 引用，确保箭头样式统一。
  5. 地面纹理：使用 SVG `<pattern id="scene1-hatch" patternUnits="userSpaceOnUse" width="8" height="8">` 画斜线，填充桌面线下方 rect。
  6. 结论卡片文字高亮：第二行中"100N"和"F₂ = 100N"使用 `<tspan fill="#c62828" font-weight="bold">` 包裹。
  7. 事件绑定：上一步/下一步按钮绑定 `click` 事件，更新 `currentStep` 并调用 `renderStep()`。在 `renderStep()` 中处理边界（currentStep < 0 则设为 0，> 3 则设为 3）。

- ID 命名规范：所有 SVG 元素及控件 ID 必须以 `scene1-` 为前缀。示例：
  - 木块：`scene1-jia-block-a`、`scene1-jia-block-b`、`scene1-yi-block-a`、`scene1-yi-block-b`
