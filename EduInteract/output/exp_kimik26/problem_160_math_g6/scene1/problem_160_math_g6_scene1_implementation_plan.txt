[图示主题与整合说明]
- 本图示主题：平移法求凹字形平面图周长
- 整合内容：原图与已知条件展示 → 水平边分组平移 → 竖直边分组平移 → 周长公式汇总与数值计算
- 教学价值：教师通过分步导航，按课堂节奏引导学生观察凹字形周长的化归思想——将分散的线段通过平移拼接为规则矩形的边长，从而避开未知边长直接求出周长。支持随时回退复习。

[分步序列]
- 步骤0（初始状态）：
  1. 显示完整凹字形图形，所有边为黑色主线，内部淡蓝填充。
  2. 高亮已知三边：b（底边）、c（右侧）、g（凹槽顶）使用蓝高亮 #1565c0，线宽 3px。
  3. 显示已知数值标签 "50米"（b下方）、"30米"（c右侧）、"10米"（g上方）。
  4. 显示所有边字母标签 a,b,c,d,e,f,g,h。
  5. 结论卡片显示标题 "已知条件"，内容 "b=50米, c=30米, g=10米"。
  6. 按钮状态：上一步禁用（灰色），下一步可用。

- 步骤1（水平边平移）：
  1. 点击「下一步」后，所有水平边（h,g,f,d,b）高亮为蓝色 #1565c0（线宽 3px），竖直边退化为黑色细线（线宽 1px）。
  2. 播放平移动画（600ms，ease-out）：
     - ghost h 从原位置 (140,200)-(220,200) 向下平移到 y=320（底边高度），轨迹显示灰色虚线。
     - ghost g 从 (220,170)-(260,170) 向下平移到 y=320。
     - ghost d 从 (300,200)-(340,200) 向下平移到 y=320。
     - ghost f 从 (260,140)-(300,140) 向上平移到 y=170（与 g 同高）。
  3. 动画结束后，显示红色等长标记：在 ghost f 和原 g 之间绘制红色双竖线（#c62828）表示 f=g。
  4. 显示等式标签："h+g+d = b" 在 ghost 下方 (220,345)，红色；"f = g" 在 ghost f 上方 (280,155)，红色。
  5. 结论卡片更新：标题 "水平边分析"，内容 "水平边总长 = 2b + 2g = 2×50 + 2×10 = 120（米）"。

- 步骤2（竖直边平移）：
  1. 点击「下一步」后，所有竖直边（a,c,e,短竖边1,短竖边2）高亮为蓝色 #1565c0，水平边退化为黑色细线。
  2. 播放平移动画（600ms，ease-out）：
     - ghost a 从 (140,200)-(140,320) 向右平移到 x=340（与 c 对齐）。
     - ghost 短竖边1 从 (220,200)-(220,170) 向右平移到 x=340 区域。
     - ghost e 从 (260,140)-(260,170) 向右平移到 x=340 区域。
     - ghost 短竖边2 从 (300,140)-(300,200) 向右平移到 x=340 区域。
  3. 动画结束后，在 x=340 右侧显示拼接示意：ghost 竖直段依次排列，总高度标注为 2c。
  4. 显示等式标签："竖直边之和 = 2c" 在 (360,240)，红色。
  5. 结论卡片更新：标题 "竖直边分析"，内容 "竖直边总长 = 2c = 2×30 = 60（米）"。

- 步骤3（汇总计算）：
  1. 点击「下一步」后，原图形轮廓淡出为半透明（opacity 0.25），所有 ghost 和辅助线隐藏。
  2. 画布中央（x=400, y=250）放大显示最终公式："周长 C = 2(b + c + g)"（24px bold，黑色）。
  3. 500ms 后，公式下方出现代入计算："= 2×(50 + 30 + 10) = 180（米）"（20px，红色 #c62828）。
  4. 结论卡片更新：标题 "最终答案"，内容 "周长 = 180 米"。
  5. 在卡片下方或图形右下方显示选项高亮框：绿色背景 #e8f5e9，边框 #2e7d32，内写 "C．180米"（18px bold，绿色 #2e7d32）。
  6. 按钮状态：下一步禁用，上一步可用。

（教师可随时点击「上一步」回退到任意步骤复习，动画反向播放或瞬间重置。）

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「◀ 上一步」按钮：位置 (300,460)，宽 90×高 36。点击后回退到上一状态，当前步骤动画反向或重置。
  2. 「下一步 ▶」按钮：位置 (410,460)，宽 90×高 36。点击后前进到下一状态，播放对应动画。
  3. 步骤指示器：位置 (360,495)，显示 "步骤 k/4"。
- 教师操作流程：
  1. 教师打开图示，步骤0自动展示原图与已知条件，向学生提问如何求周长。
  2. 点击「下一步」进入步骤1，引导学生观察水平边，播放平移动画，得出水平边总长。
  3. 点击「下一步」进入步骤2，引导学生观察竖直边，播放平移动画，得出竖直边总长。
  4. 点击「下一步」进入步骤3，汇总公式，高亮正确答案。若学生有疑问，随时点击「上一步」回退重讲。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无需外部库）。理由：简单正交多边形、线段平移动画、状态切换，原生 SVG 性能足够，避免引入不必要依赖。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图（ASCII）：
  ```
  0    100  200  300  400  500  600  700  800
  +----+----+----+----+----+----+----+----+
  |                                       | 20
  |    [凹字形图形]        [结论卡片]      | 140
  |    a  h  g  d  c       +-----------+   | 200
  |    |‾‾‾‾‾‾‾‾‾|        | 步骤结论  |   | 260
  |    |    g    |        | 公式/数值 |   | 320
  |    |____f____|        +-----------+   | 380
  |         b                            | 420
  |                                       | 440
  |        [◀上一步] [下一步▶]            | 460
  |              步骤 1/4                 | 495
  +----+----+----+----+----+----+----+----+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `currentStep`（0~3），每次点击按钮时更新状态，调用 `renderStep()` 函数根据状态显示/隐藏元素、触发 CSS transition 动画。
  2. 动画实现：ghost 元素使用 SVG `<line>` 或 `<path>`，通过 CSS `transition: transform 0.6s ease-out` 实现平移。轨迹虚线使用 `<line stroke-dasharray="6 4">`，在动画开始时显示，动画结束后淡出。
  3. 高亮切换：给所有边元素添加 class，步骤切换时通过 JS 修改 class（如 `.highlight-blue`、`.highlight-red`、`.dim`），利用 CSS transition 改变 stroke 颜色和宽度。
  4. 结论卡片内容：使用一个 `<foreignObject>` 或 SVG `<text>` + `<tspan>` 组合，根据 `currentStep` 更新文本内容。
  5. 按钮禁用逻辑：步骤0时禁用「上一步」，步骤3时禁用「下一步」，通过添加/移除 `disabled` class 改变样式（opacity 0.4，pointer-events none）。
  6. 图形淡出：步骤3时给主图形 `<g>` 添加 CSS class `fade-out`（transition: opacity 0.5s），同时显示中央公式 `<text>`。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀。例如：
  - 图形组：`scene1-main-shape`
  - 边 a：`scene1-edge-a`
  - ghost h：`scene1-ghost-h`
  - 结论卡片：`scene1-conclusion-card`
  - 上一步按钮：`scene1-btn-prev`
  - 下一步按钮：`scene1-btn-next`
  - 步骤指示器：`scene1-step-indicator`
  - 中央公式：`scene1-final-formula`
- IIFE 隔离：所有 JavaScript 代码包裹在 `(function() { ... })();` 中，避免多场景合并时的全局变量污染。
- 事件绑定：使用 `document.getElementById('scene1-btn-next').addEventListener('click', ...)`，严禁使用 `querySelectorAll` 配合全局 class。
