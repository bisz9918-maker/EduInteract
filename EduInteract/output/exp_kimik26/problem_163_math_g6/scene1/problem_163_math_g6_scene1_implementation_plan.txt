[图示主题与整合说明]
- 本图示主题：钝角三角形ABC中AB边上高的判定与概念辨析
- 整合的步骤/概念：
  1) 原图背景与三角形ABC的识别；
  2) 三角形高的定义回顾（顶点→对边所在直线→垂足）；
  3) 动态演示从C向AB所在直线作垂线CD；
  4) 钝角三角形高落在延长线上的特点说明；
  5) 干扰项CB的排除（不垂直）；
  6) 干扰项EB的排除（非顶点C出发）；
  7) 正确答案CD的确认。
- 教学价值：教师通过分步导航精确控制课堂节奏，可随时回退到任意概念节点进行强调，帮助学生建立“高必须同时满足：①从顶点出发；②垂直于对边所在直线”的双重判断标准。

[分步序列]
步骤0（初始状态）：
- 显示完整原图：阶梯轮廓、三角形ABC（黑线+蓝色透明填充）、虚线EB、五个点及标签
- 选项区显示A.CB / B.CD / C.EB
- 提示文字："在三角形ABC中，边AB上的高是（ ）"
- 无高亮元素

步骤1（识别目标）：
- 变化：AB边线宽变为3px，颜色变为#1565c0（蓝色）
- 提示文字："找边AB上的高"
- 新增/消失：无

步骤2（回顾定义）：
- 变化：AB恢复常态（1.5px黑色）；C点出现绿色光晕（circle，半径18px，描边#2e7d32 2px）
- 提示文字："从顶点C向AB所在直线作垂线，顶点与垂足之间的线段叫做高。"
- 新增/消失：无

步骤3（动态作高）：
- 变化：C点光晕消失；CD线宽变为3px，颜色变为#2e7d32（绿色）；直角符号在D处出现；BD线保持常态
- 新增：标注"CD ⊥ AD"在(585,300)，绿色
- 提示文字："从C点向AB所在直线作垂线，垂足为D"

步骤4（钝角特点）：
- 变化：CD保持绿色高亮；BD线宽变为2px，颜色变为#1565c0（蓝色），表示延长线部分
- 新增：标注"在AB延长线上"在(500,395)，蓝色
- 提示文字："钝角三角形中，钝角所对边上的高可能落在边的延长线上。"

步骤5（排除CB）：
- 变化：CD恢复常态；BD恢复常态；CB线宽变为3px，颜色变为#c62828（红色）
- 新增：标注"CB与AB不垂直"在(470,310)，红色
- 提示文字："CB是三角形的边，不是AB边上的高"
- 消失："CD ⊥ AD"、"在AB延长线上"

步骤6（排除EB）：
- 变化：CB恢复常态；EB虚线线宽变为3px，颜色变为#c62828（红色）；E点出现红色光晕（半径18px，描边#c62828 2px）；C点出现绿色光晕（半径18px，描边#2e7d32 2px）
- 新增：标注"EB ⊥ AB"在(340,339)，红色
- 提示文字："EB虽垂直于AB，但端点E不是顶点C，因此不是△ABC的高"
- 消失："CB与AB不垂直"

步骤7（确认答案）：
- 变化：EB恢复常态（灰色虚线1.5px）；E点光晕消失；C点光晕消失；CD线宽变为3px，颜色变为#2e7d32（绿色）
- 新增：选项B（B.CD）添加绿色高亮背景（rect，#2e7d32透明度20%）
- 提示文字："正确答案：B．CD"
- 消失："EB ⊥ AB"

（教师可随时点击「上一步」回退到任意步骤复习）

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「上一步」按钮：位置(295,454,90,32)，点击回退到上一状态，步骤0时禁用（灰色）
  2. 「下一步」按钮：位置(415,454,90,32)，点击前进到下一状态，步骤7时禁用（灰色）
  3. 步骤指示器：位置(400,475)，显示当前步骤编号如"步骤 1/8"
- 教师操作流程：
  1. 教师打开图示，学生看到完整原图（步骤0）
  2. 教师点击「下一步」进入步骤1，引导学生聚焦AB边
  3. 继续点击「下一步」依次展示定义回顾、作高演示、钝角特点、干扰项排除、答案确认
  4. 讲解过程中可随时点击「上一步」回退到关键概念节点进行重复强调
  5. 步骤7确认答案后，可点击「上一步」回到步骤3重新演示作高过程

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：本场景为纯几何图形和简单状态切换，无需复杂图表库；原生SVG可精确控制每个元素的坐标、描边、填充和显隐，性能最优。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |  提示文字区 (y=30~80)                              |
  |         "在三角形ABC中，边AB上的高是（ ）"         |
  +--------------------------------------------------+
  |                                                  |
  |    主图区 (y=120~420)                             |
  |                                                  |
  |         C(570,180)                               |
  |         |＼                                       |
  |         |  ＼                                     |
  |    +----+    ＼                                   |
  |    | E  |      ＼                                 |
  |    |    |        ＼                               |
  |    +----+          ＼                             |
  |    A-----B-----------D                           |
  |   (230) (370)       (570)                        |
  |                                                  |
  +--------------------------------------------------+
  |  选项区 (y=425~445)   A.CB    B.CD    C.EB       |
  +--------------------------------------------------+
  |  控件栏 (y=454~490)   [上一步] 步骤1/8 [下一步]  |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：定义常量STEP_COUNT=8，变量currentStep记录当前步骤（0-7）。每步用一个配置对象描述该步应显示的class集合和text内容。
  2. 元素显隐控制：为所有可能动态显示的元素（标注文字、直角符号、光晕、选项高亮背景）设置初始display="none"，通过JS切换display="block"或visibility。
  3. 高亮切换：为线条元素预定义多个class（如.normal, .highlight-blue, .highlight-green, .highlight-red），通过setAttribute('class', ...)切换。
  4. 坐标计算：所有坐标硬编码在SVG中，无需运行时计算。动画效果（如步骤3"动态作高"）通过CSS transition或JS逐帧改变stroke-dashoffset实现，也可简化为直接显示（因分步导航以概念讲解为主，非连续动画）。
  5. 事件绑定：上一步/下一步按钮绑定click事件，调用updateScene(step)函数更新所有元素状态。
  6. 按钮状态：updateScene中检查currentStep，步骤0时给上一步按钮加.disabled class，步骤7时给下一步按钮加.disabled class。
- ID命名规范：所有交互元素ID必须以`scene1-`为前缀。例如：
  - 线段AB: id="scene1-line-ab"
  - 线段CD: id="scene1-line-cd"
  - 虚线EB: id="scene1-line-eb"
  - 直角符号: id="scene1-right-angle-d"
  - 标注"CD ⊥ AD": id="scene1-label-cd-perp"
  - C点光晕: id="scene1-glow-c"
  - 上一步按钮: id="scene1-btn-prev"
  - 下一步按钮: id="scene1-btn-next"
  - 提示文字: id="scene1-hint-text"
  - 选项B背景: id="scene1-option-bg-b"
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })()` 中，避免多场景合并时全局变量污染。
