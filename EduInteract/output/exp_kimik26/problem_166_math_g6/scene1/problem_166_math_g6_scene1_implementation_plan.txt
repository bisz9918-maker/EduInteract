[图示主题与整合说明]
- 本图示主题：等高三角形面积比较
- 整合的步骤/概念：原始图形展示 → 底边长度标注 → 等高关系揭示（垂线+标注h） → 面积公式推导与计算 → 结论高亮
- 教学价值：教师通过分步导航控制课堂节奏，引导学生先观察三个三角形夹在平行线之间，再发现"等高"这一关键隐藏条件，最后通过公式计算比较面积，培养"找不变量"的几何思维

[分步序列]
- 步骤0（初始状态）：显示上下平行线、全部刻度线及刻度标签0-5、三个三角形（含填充、边框、内部标签1/2/3）。隐藏所有辅助标注、公式、结论。教师可引导学生观察图形整体布局。
- 步骤1（标注底边）：点击「下一步」→ 在三个三角形底边中点正下方显示底边长度标注："底=2"（图1）、"底=2"（图2）、"底=1"（图3）。教师引导学生发现三个三角形的底边长度不同。
- 步骤2（标注高）：点击「下一步」→ 从每个三角形顶点向底边作垂线（灰色虚线），在垂足处显示L形标记，并在每条高线右侧显示"h"。教师强调三个三角形夹在平行线之间，高相等。
- 步骤3（公式计算）：点击「下一步」→ 在图形下方显示公式背景框，第一行显示"S = ½ × 底 × 高"，第二行显示三个计算式"S₁ = ½×2×h = h    S₂ = ½×2×h = h    S₃ = ½×1×h = 0.5h"。教师带领学生代入计算。
- 步骤4（得出结论）：点击「下一步」→ 图3（红色三角形）边框加粗至4px、填充加深，图1和图2淡化处理（填充透明度降至10%），并在公式框下方显示红色加粗文字"图3面积最小"。教师总结结论。
- 教师可随时点击「上一步」回退到任意步骤复习。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「上一步」按钮：位于SVG内底部左侧(310,452)，宽70×高30，点击回退到上一分步，步骤0时禁用（opacity 0.4）
  2. 步骤指示文本：位于底部中心(400,472)，显示当前步骤如"步骤 2/4"
  3. 「下一步」按钮：位于SVG内底部右侧(420,452)，宽70×高30，点击前进到下一分步，步骤4时禁用（opacity 0.4）
- 教师操作流程：教师先展示步骤0让学生观察图形→点击下一步进入步骤1标注底边→下一步进入步骤2揭示等高→下一步进入步骤3公式计算→下一步进入步骤4得出结论。讲解中可随时回退复习。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript（场景为简单几何图形和分步显隐，无需引入外部库，减少依赖）
- 画布尺寸：800 × 500 px（固定画布）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  0   1   2   3   4   5    ← 上线刻度标签         |
  |  |   |   |   |   |   |                           |
  |  +---△---+---△---+---△---+  ← 上线+三角形顶点    |
  |      /1\      /2\      /3|                        |
  |     /   \    /   \    /  |  ← 三角形填充区       |
  |    /     \  /     \  /   |                        |
  |   +-------++-------++----+  ← 下线+三角形底边    |
  |  |   |   |   |   |   |                           |
  |  0   1   2   3   4   5    ← 下线刻度标签         |
  |  底=2   底=2   底=1       ← 底边标注(步骤1)      |
  |  +----------------------+  ← 公式背景框(步骤3)   |
  |  | S=½×底×高 ...       |                        |
  |  +----------------------+                        |
  |        图3面积最小        ← 结论(步骤4)          |
  |  [◀上一步] 步骤 2/4 [下一步▶] ← 控件栏          |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `let currentStep = 0;` 记录当前步骤（0~4），每次按钮点击更新状态后调用 `renderStep()` 统一渲染。
  2. 分组显隐：SVG中使用 `<g id="scene1-step1-group">` 等分组包裹各步骤专属元素，通过设置 `display: none/block` 控制显隐。
  3. 步骤4样式切换：不使用CSS类切换，而是直接通过JS修改SVG元素的 `stroke-width`、`fill-opacity`、`stroke` 属性，确保状态可逆（回退时恢复）。
  4. 按钮禁用逻辑：`currentStep === 0` 时禁用「上一步」，`currentStep === 4` 时禁用「下一步」，通过设置按钮 `disabled` 属性和透明度变化反馈。
  5. 动画曲线：本场景为分步显隐，无需复杂动画；元素出现直接使用display切换，保持教学图示的清晰直接。
  6. 事件绑定：按钮使用 `onclick` 属性直接绑定，避免事件委托带来的多场景污染风险。
- ID命名规范：所有SVG元素和JS变量均以 `scene1-` 为前缀。例如：
  - SVG分组：`scene1-step0-group`, `scene1-step1-group`, `scene1-step2-group`, `scene1-step3-group`, `scene1-step4-group`
  - 三角形：`scene1-tri-1`, `scene1-tri-2`, `scene1-tri-3`
  - 按钮：`scene1-btn-prev`, `scene1-btn-next`
  - 步骤文本：`scene1-step-label`
  - JS中通过 `document.getElementById('scene1-tri-1')` 精确获取，禁止跨场景选择器
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免全局变量污染，确保多场景合并时互不干扰。
