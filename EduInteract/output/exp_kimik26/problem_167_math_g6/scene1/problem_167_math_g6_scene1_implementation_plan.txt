[图示主题与整合说明]
- 本图示主题：方格纸上三角形的等底等高面积比较（甲、乙两个阴影三角形）
- 整合的步骤/概念：
  1. 原题完整图示（2×8方格纸上的甲、乙阴影三角形）；
  2. 甲三角形的底边与高标注，及面积公式推导；
  3. 乙三角形的底边与高标注，及面积公式推导；
  4. 等底等高结论与答案揭晓（选项C）。
- 教学价值：教师通过分步导航，引导学生从直观观察→分别计算→对比归纳，理解"等底等高的三角形面积相等"这一核心结论，可随时回退重讲。

[分步序列]
- 初始状态（步骤0）「观察原图」：
  - 显示2×8方格纸、甲三角形（普通阴影+黑色边线）、乙三角形（普通阴影+黑色边线）
  - 显示标签"甲"(275,160)、"乙"(425,160)
  - 隐藏所有标注线、数字、公式、结论、选项C
  - 教师引导学生凭直觉判断面积大小

- 步骤1「分析甲」：
  - 甲三角形边线变为 #1565c0 2.5px（高亮），乙保持普通阴影
  - 显示甲底边标注线(250,105)-(300,105)及数字"1"(275,95)
  - 显示甲高标注线(315,120)-(315,220)及数字"2"(325,170)
  - 显示甲面积公式文本(220,270)："S甲 = 1×2÷2 = 1"
  - 教师讲解甲的底为1格、高为2格，面积为1格²

- 步骤2「分析乙」：
  - 甲恢复普通阴影（边线恢复 #000000 1.5px），甲的标注线和公式隐藏
  - 乙三角形边线变为 #2e7d32 2.5px（高亮）
  - 显示乙底边标注线(400,105)-(450,105)及数字"1"(425,95)
  - 显示乙高标注线(465,120)-(465,220)及数字"2"(475,170)
  - 显示乙面积公式文本(420,270)："S乙 = 1×2÷2 = 1"
  - 教师讲解乙的底为1格、高为2格，面积同样为1格²

- 步骤3「得出结论」：
  - 甲、乙同时高亮（甲边线 #1565c0 2.5px，乙边线 #2e7d32 2.5px）
  - 同时显示甲、乙的全部标注线、数字、面积公式
  - 显示结论文字"等底等高"(400,320)、"面积相等"(400,360)
  - 显示选项C高亮框(370,390)-(430,420)及文字"C"(400,410)
  - 教师总结：两三角形等底等高，故面积相等，答案选C

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于画布底部偏左(300,450)，宽80×高30；点击回退到上一状态，步骤0时禁用
  - 「下一步」按钮：位于画布底部偏右(460,450)，宽80×高30；点击前进到下一状态，步骤3时禁用
  - 步骤指示器：位于两按钮之间(390,445)，显示当前步骤如"1/4"，帮助教师掌握讲解进度
- 教师操作流程：
  1. 加载后进入步骤0，让学生观察原图并猜测；
  2. 点击「下一步」进入步骤1，讲解甲三角形的底、高与面积；
  3. 点击「下一步」进入步骤2，讲解乙三角形的底、高与面积；
  4. 点击「下一步」进入步骤3，同时高亮甲乙，揭示等底等高结论与答案C；
  5. 可随时点击「上一步」回退到任意步骤重新讲解。

[技术实现]
- JS库选择：原生SVG（简单几何与网格首选，无需引入外部绘图库）
- 画布尺寸：800 × 500 px（固定画布，SVG viewBox="0 0 800 500"）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------------+
  |                                                        |
  |     甲 △          乙 △        ← 标签在三角形内部偏上    |
  |   +--+--+--+--+--+--+--+--+                            |
  |   |  |\ |  |  |  |\ |  |  |  ← 2×8方格纸(200,120起)   |
  |   +--+--+--+--+--+--+--+--+                            |
  |   |  | \|  |  |  | \|  |  |                            |
  |   +--+--+--+--+--+--+--+--+                            |
  |      ↑1        ↑1       ← 底边标注在y=105             |
  |      |2        |2       ← 高标注在x=315/465            |
  |                                                        |
  |   S甲=1×2÷2=1    S乙=1×2÷2=1  ← 公式在y=270           |
  |                                                        |
  |        等底等高  ← y=320                               |
  |        面积相等  ← y=360                               |
  |         [ C ]    ← y=400 选项高亮                      |
  |                                                        |
  |   [上一步]  1/4  [下一步]  ← 控件栏 y=440~490          |
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：定义 currentStep 变量（0~3），每一步通过 updateScene() 函数统一控制所有元素的 display/opacity/stroke 属性；
  2. 元素显隐：所有标注线、公式、结论元素初始 display="none"，根据 currentStep 切换为 display="block" 或 opacity 过渡；
  3. 高亮切换：甲/乙三角形的 stroke 和 stroke-width 通过 setAttribute 在步骤切换时更新，可配合 CSS transition 实现 200ms 平滑过渡；
  4. 箭头标记：在 SVG <defs> 中定义两个 marker（id="scene1-arrow-start"、"scene1-arrow-end"），用于底边和高标注线的双向箭头；
  5. 按钮事件：上一步/下一步绑定 click 事件，更新 currentStep 后调用 updateScene()，并同步更新按钮 disabled 状态和步骤指示器文本；
  6. 公式渲染：使用 SVG <text> 元素直接绘制，下标用 <tspan font-size="12" dy="4">实现，避免引入 MathJax 降低加载速度；
  7. 控件定位：按钮和步骤指示器使用 HTML 元素，通过 CSS position:absolute 定位于 SVG 容器内底部（left/top 基于 800×500 画布坐标），不额外撑高容器。
- ID命名规范：所有 SVG 元素和交互元素 ID 必须以 `scene1-` 为前缀，例如：
  - 网格组：scene1-grid-group
  - 甲三角形：scene1-tri-jia
  - 乙三角形：scene1-tri-yi
  - 甲底边标注线：scene1-arrow-jia-base
  - 甲高标注线：scene1-arrow-jia-height
  - 甲面积公式：scene1-formula-jia
  - 结论文字：scene1-conclusion-text
  - 选项C背景：scene1-option-c-bg
  - 上一步按钮：scene1-btn-prev
  - 下一步按钮：scene1-btn-next
  - 步骤指示器：scene1-step-indicator
- IIFE隔离：所有 JavaScript 代码包裹在 `(function() { ... })()` 中，避免多场景合并时的全局变量污染。
