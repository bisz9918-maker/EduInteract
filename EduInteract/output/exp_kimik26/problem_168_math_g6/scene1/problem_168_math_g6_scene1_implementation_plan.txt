[图示主题与整合说明]
- 本图示主题：两小圆周长之和与大圆周长的关系探究
- 整合的步骤/概念：
  1. 观察图形结构（大圆内两小圆沿直径外切、各自与大圆内切）；
  2. 标注直径关系（d₁+d₂=D）；
  3. 公式推导对比（C大=πD 与 C小和=πd₁+πd₂=πD）；
  4. 动态一般性验证（拖动切分点，实时数值始终相等）。
- 教学价值：教师通过「特殊图形→代数推导→任意验证」的递进，帮助学生建立"结论与两圆比例无关"的深刻认知，强化"特殊到一般"的数学思想。

[技术实现]
- JS库选择：原生 SVG + 原生 JavaScript（零外部依赖）。理由：本场景为纯2D几何，无复杂函数绘图或3D，原生SVG性能最优且无需加载CDN。
- 画布尺寸：800×500 px（固定viewBox）
- 布局草图：
  ```
  +--------------------------------------------------+
  |  大圆(350,140,R120)                              |
  |     ___________________________                  |
  |    /    左小圆    右小圆        \                |
  |   /      __      ________        \               |
  |  |      /  \    /        \        |              |
  |  |     |    |  |          |       |              |
  |  +------●----+--●----------+------+  直径线      |
  |        d₁标注  切分点      d₂标注               |
  |         ↓                    ↓                  |
  |  [d₁线]                [d₂线]                   |
  |         ↓                    ↓                  |
  |              [D线（大圆下方）]                   |
  |                                                  |
  |  +------------------------------------------+    |
  |  | 公式/数值面板 (220,305~420)              |    |
  |  |  步骤1: d₁+d₂=D                         |    |
  |  |  步骤2: 推导公式 + "一样长"(绿)          |    |
  |  |  步骤3: d₁=.. d₂=.. C大=.. C小和=..     |    |
  |  +------------------------------------------+    |
  |                                                  |
  |      [◀ 上一步]  步骤 1/4  [下一步 ▶]           |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：全局变量 `state` ∈ {0,1,2,3}，每次点击按钮调用 `render(state)`，通过设置各 SVG 组的 `display` 属性（或透明度）切换可见性。
  2. 拖拽实现：步骤3时给切分点绑定 `mousedown` → 设置全局 `dragging=true`；`document` 监听 `mousemove` 计算新 x 坐标（限制范围[280,420]，保证最小直径50）；`mouseup` 结束拖拽。拖拽过程中实时调用 `updateGeometry(x)` 更新左/右小圆的 cx、r 以及 d₁/d₂ 标注线端点。
  3. 坐标计算（拖拽时）：设切分点 x，左端点 fixed=230，右端点 fixed=470。
     - d₁ = x - 230，r₁ = d₁/2，cx₁ = 230 + r₁
     - d₂ = 470 - x，r₂ = d₂/2，cx₂ = x + r₂
     - C = π × (d₁+d₂) = π × 240（恒定）
  4. 标注线动态更新：d₁线端点更新为 (230,200)-(x,200)，文字位置 ((230+x)/2, 195)；d₂线端点更新为 (x,255)-(470,255)，文字位置 ((x+470)/2, 250)。
  5. 动画曲线：步骤切换时新增元素使用 CSS transition opacity 0.3s ease，避免生硬跳变；几何图形更新不使用动画（拖拽需实时响应）。
  6. 事件绑定：所有按钮与 SVG 元素通过 `getElementById` 获取，禁止 `querySelectorAll` 配合全局 class，防止多场景合并时跨场景污染。
- ID命名规范：所有元素 ID 必须以 `scene1-` 为前缀。示例：
  - `scene1-big-circle`、`scene1-left-circle`、`scene1-right-circle`
  - `scene1-diameter-labels`、`scene1-formula-panel`
  - `scene1-split-point`、`scene1-btn-prev`、`scene1-btn-next`
  - `scene1-val-d1`、`scene1-val-cbig`、`scene1-conclusion`
- IIFE隔离：所有 JavaScript 代码包裹在 `(function() { ... })();` 中，避免全局变量污染。
