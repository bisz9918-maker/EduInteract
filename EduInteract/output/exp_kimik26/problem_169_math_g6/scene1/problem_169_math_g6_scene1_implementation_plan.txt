- 本图示主题：方位角与比例尺的综合应用

[分步序列]
- 初始状态（步骤0）：显示十字方向轴、雷达站（黑圆）、巡洋舰（蓝圆）、目标连线（黑线）、40°角弧线（黑）、比例尺及"50 km"标签、所有方向/点/角度标签。学生可整体感知题目：巡洋舰在雷达站北偏东40°方向，但距离未知。教师可提问"方向是什么？距离可能是多少？"
- 步骤1（方向解析）：点击「下一步」→ 北轴变为蓝色粗线，目标连线变为蓝色粗线，出现红色半透明扇形（40°角区域，r=100px），出现"北偏东40°"标签。教师引导学生确认方向为"北偏东40°"，从而排除选项B（北偏西40°）。
- 步骤2（比例尺测量）：点击「下一步」→ 比例尺变为绿色粗线，在目标连线上出现等长分段垂线标记（距雷达站75px，约(449,223)），出现绿色虚线辅助线连接比例尺中点与分段标记，连线两段旁出现绿色"=50km"标注。教师引导学生发现图上距离恰好为2个比例尺单位，即2×50km。
- 步骤3（结论确认）：点击「下一步」→ 左侧出现选项卡片，列出A/B/C三个选项；C选项（北偏东40°方向100km）高亮红色背景，B选项旁出现红色排除叉号；卡片底部显示算式"实际距离 = 2 × 50km = 100km"（数值为绿色）。教师确认答案为C，完成方向与距离的双重验证。
- 教师可随时点击「上一步」回退到任意步骤复习。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「上一步」按钮：位置(295,448)，宽90px高34px。点击后回退到上一分步，步骤0时禁用（opacity 0.4）。
  2. 「下一步」按钮：位置(415,448)，宽90px高34px，蓝色主按钮样式。点击后前进到下一分步，步骤3时禁用（opacity 0.4）。
  3. 步骤指示器：位置(400,442)，显示"步骤 N / 4"，灰色小字。
- 教师操作流程：
  1. 教师展示步骤0，让学生观察题图并读题。
  2. 点击「下一步」进入步骤1，讲解方向角"北偏东40°"，引导学生排除选项B。
  3. 点击「下一步」进入步骤2，讲解比例尺测量，引导学生发现距离为2个50km。
  4. 点击「下一步」进入步骤3，展示算式和选项高亮，确认答案C。
  5. 讲解过程中可随时点击「上一步」回退复习。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本场景为静态几何图形与分步显隐控制，无复杂动画或数据绑定，原生SVG足够轻量且精确。
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  +--------------------------------------------------+
  |  (30,88) 选项卡片(步骤3)        北               |
  |  +--------------------+          |               |
  |  | 选择答案           |          |               |
  |  | A. ...             |    西 —雷达站— 东        |
  |  | B. ... [叉]        |          | \ 巡洋舰      |
  |  | C. ... [高亮]      |          |  \            |
  |  | 实际距离=...       |          南  40°弧线     |
  |  +--------------------+                          |
  |                              比例尺 [50 km]      |
  |                                         (右下)   |
  |  [◀上一步]        [下一步▶]                      |
  +--------------------------------------------------+
  画布 800×500，控件栏在底部 y=440~490
  ```
- 关键实现要点：
  1. 状态机设计：用变量 `currentStep`（0~3）控制当前步骤。每个SVG交互元素预先在DOM中创建，通过 `display` 或 `visibility` 属性控制显隐。步骤切换时调用 `renderStep()` 函数，根据 `currentStep` 值批量设置各元素显隐。
  2. 坐标计算：巡洋舰坐标(500,165)由雷达站(400,280)出发，沿北偏东40°方向，图上距离约152px（2倍比例尺长度75px）计算得出：dx = 152×sin(40°)≈98, dy = -152×cos(40°)≈-117。分段标记点(449,223)为连线上距雷达站75px处。
  3. 动画曲线：本场景无连续动画，仅为分步显隐切换。元素出现/隐藏使用直接切换（无淡入淡出），确保课堂讲解节奏可控。若需强调，可对高亮元素使用CSS `transition: stroke-width 0.3s`。
  4. 事件绑定：上一步/下一步按钮绑定 `click` 事件，更新 `currentStep` 后调用 `renderStep()`。按钮在边界步骤（0和3）添加 `disabled` 类以降低透明度。
  5. 扇形绘制：使用SVG `<path>` 的 `A` 命令绘制圆弧，配合 `L` 命令回到圆心形成闭合扇形。例如：`M 400 280 L 400 180 A 100 100 0 0 1 464 205 Z`（近似，需按-90°~-50°精确计算起点终点）。
  6. 辅助线绘制：步骤2的虚线从比例尺中点(617,375)到分段标记(449,228)，使用 `stroke-dasharray="5,5"` 和 `opacity="0.6"`。
- ID命名规范：所有交互元素ID必须以 `scene1-` 为前缀。例如：`scene1-axis-north`、`scene1-ship`、`scene1-step1-sector`、`scene1-step2-scale-highlight`、`scene1-btn-prev`、`scene1-btn-next`、`scene1-step-indicator`。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })()` 中，避免多场景合并时变量污染全局作用域。
