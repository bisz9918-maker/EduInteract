    **题目原文**

    如图所示，电源电压恒定，闭合开关后，将滑动变阻器的滑片向右端移动的过程中，下列说法正确的是（  ）

    A．电流表示数变小，电压表V$_{1}$示数变大
    B．小灯泡变暗，电压表V$_{2}$示数变小
    C．电压表V$_{1}$和电压表V$_{2}$示数之和不变
    D．电路的总功率变大

    **题目分析**

    本题是一道典型的串联电路动态分析题，核心考查点包括：
    1. 电路结构识别（串联关系、电表测量对象）
    2. 滑动变阻器的工作原理及滑片移动对电阻的影响
    3. 欧姆定律 $I = \frac{U}{R}$ 在动态电路中的应用
    4. 串联电路的电流、电压、功率规律

    **整体讲解思路**

    讲解应遵循"先识图、再抓变、后用律、最后判"的递进逻辑：
    1. 首先带领学生识别电路为串联电路，明确电流表测电路电流，电压表V$_{2}$测小灯泡电压，电压表V$_{1}$测电源电压（由图示并联位置决定）。
    2. 然后分析滑动变阻器滑片向右移动时，接入电路的电阻丝长度增加，导致接入电阻变大。
    3. 接着根据欧姆定律和串联规律，逐步推导总电阻、电流、灯泡电压、电源电压、总功率的变化。
    4. 最后对照四个选项逐一判断正误，得出正确答案为 B。

    **图示规划说明**

    设计 2 个教学图示：
    - 图示 1（SCENE_1）：电路结构识别与电表测量对象分析。通过分步高亮，帮助学生确认串联关系和各电表的测量范围，解决"测什么"的问题。
    - 图示 2（SCENE_2）：动态电路全流程推导。从滑片移动出发，整合滑动变阻器局部变化、欧姆定律公式推导、各电表示数变化趋势、灯泡亮度变化、总功率变化及选项正误判断，解决"怎么变"的问题。

    本图示用于帮助学生建立"先看结构"的解题习惯。许多学生在动态电路题中出错，根源是没有正确识别电表测量对象。

    教师应引导学生按以下顺序观察：
    1. **判断串并联**：让电流从电源正极"走"一圈，发现只有一条路径，确认是串联电路。
    2. **判断电流表**：电流表串联在电路中，测的是整个电路的电流。
    3. **判断 V$_{2}$**：V$_{2}$ 的两端直接并联在小灯泡两端，测小灯泡电压。
    4. **判断 V$_{1}$**：V$_{1}$ 的两端跨接在电源正负极之间（或整个电路两端），测的是电源电压。这是本题的关键易错点——学生容易误以为 V$_{1}$ 测滑动变阻器电压。

    讲解时要特别强调：电源电压恒定是题目给定的已知条件，因此 V$_{1}$ 的示数在滑片移动过程中保持不变。这一结论将直接影响后续选项判断。

    **本图示的教学说明**

    本图示是解题的核心环节，教师应带领学生严格按照"局部→整体→局部"的逻辑链进行推导，培养因果分析能力。

    **讲解要点与推导步骤：**

    1. **抓变量**：明确本题唯一的变量是"滑片向右移动"。结合 SCENE_1 的电路结构，引导学生观察滑动变阻器的接法（一上一下），判断接入电阻丝长度增加，因此 R$_{滑}$ 变大。

    2. **推电流**：串联电路总电阻 R$_{总}$ = R$_{灯}$ + R$_{滑}$，R$_{滑}$ 变大导致 R$_{总}$ 变大。根据欧姆定律 $I = \frac{U}{R_{总}}$，电源电压 U 恒定，R$_{总}$ 变大，所以电流 I 变小。电流表示数变小。

    3. **推灯泡电压与亮度**：V$_{2}$ = I × R$_{灯}$，灯泡电阻 R$_{灯}$ 不变（初中阶段忽略温度影响），I 变小，所以 V$_{2}$ 变小。灯泡的实际功率 P$_{灯}$ = I²R$_{灯}$ 也变小，因此灯泡变暗。

    4. **推 V$_{1}$**：V$_{1}$ 测电源电压，题目已说明"电源电压恒定"，所以 V$_{1}$ 不变。这是学生最容易出错的地方，必须反复强调。

    5. **推总功率**：P$_{总}$ = U × I，U 不变，I 变小，所以总功率变小。

    6. **判选项**：
       - A：前半句"电流表示数变小"正确，后半句"V$_{1}$ 示数变大"错误（应不变），故 A 错。
       - B："小灯泡变暗"正确，"V$_{2}$ 示数变小"正确，故 B 正确。
       - C：V$_{1}$ 不变、V$_{2}$ 变小，两者之和变小，故 C 错。
       - D：总功率应变小而非变大，故 D 错。

    **课堂互动建议**：在步骤 2~5 的推导过程中，教师可先让学生口头猜测"变大还是变小"，再点击下一步验证，利用认知冲突加深记忆。特别注意提问："为什么 V$_{1}$ 不变？""如果 V$_{1}$ 测的是滑动变阻器电压，答案会有什么不同？"以此拓展思维。

    **总结：完整解答与课堂讲解建议**

    **完整解答**

    电路为串联电路，电流表测电路电流，电压表 V$_{1}$ 测电源电压，电压表 V$_{2}$ 测小灯泡电压。

    当滑动变阻器滑片向右端移动时：
    1. 滑动变阻器接入电路的电阻丝长度增加，R$_{滑}$ 变大；
    2. 串联总电阻 R$_{总}$ = R$_{灯}$ + R$_{滑}$ 变大；
    3. 由 $I = \frac{U}{R_{总}}$，电源电压 U 恒定，电流 I 变小，电流表示数变小；
    4. 由 V$_{2}$ = I·R$_{灯}$，V$_{2}$ 变小，灯泡实际功率变小，灯泡变暗；
    5. 电压表 V$_{1}$ 测电源电压，示数不变；
    6. 总功率 P$_{总}$ = U·I 变小。

    因此：A 错误，B 正确，C 错误，D 错误。正确答案为 **B**。

    **课堂讲解建议**

    1. **时间分配**：电路识别（3 分钟）→ 动态推导（8 分钟）→ 选项判断与拓展（4 分钟）。
    2. **易错点预警**：学生常误认为 V$_{1}$ 测滑动变阻器电压，导致认为 A、C 也正确。务必在 SCENE_1 中花足够时间确认 V$_{1}$ 的测量对象。
    3. **方法提炼**：总结串联动态分析的"口诀"——"滑变电阻看长度，总阻跟着它变化，欧姆定律定电流，分压亮度随后定，电源电压总不变，总功率随电流定"。
    4. **变式拓展**：可追问"若滑片向左移动，各表示数如何变化？""若 V$_{1}$ 改接在滑动变阻器两端，哪个选项正确？"以巩固方法。
