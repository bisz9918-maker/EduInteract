[分步序列]
- 初始状态（步骤0）：显示完整电路图（所有元件、导线、电表、元件名称标签），无任何高亮和步骤标注。教师可在此步让学生先独立观察电路结构。
- 步骤1：点击「下一步」→ 所有串联导线及电源引线高亮为红色（#c62828，线宽3px），在导线关键位置显示电流方向箭头（上横线左段向左、左竖线向下、下横线向右、右竖线向上、电源正极引线向上、负极引线向下、滑动变阻器处向右）；显示标注"串联电路"于(400,80)。引导学生确认电流只有一条路径，各元件串联。
- 步骤2：点击「下一步」→ 移除步骤1的红色电流路径高亮；电流表A圆框显示蓝色高亮（边框#1565c0，填充浅蓝15%）；显示标注"电流表测串联电路电流"于(660,200)。引导学生确认A串联在电路中，测的是串联电路电流。
- 步骤3：点击「下一步」→ 移除步骤2的电流表高亮；电压表V₁圆框显示绿色高亮（边框#2e7d32，填充浅绿15%），V₁两根引线覆盖绿色高亮（线宽3px）；显示标注"电压表V₁测电源电压（电源电压恒定）"于(120,70)。引导学生确认V₁并联在电源两端。
- 步骤4：点击「下一步」→ 移除步骤3的V₁高亮；电压表V₂圆框显示橙色高亮（边框#f57c00，填充浅橙15%），V₂两根引线覆盖橙色高亮（线宽3px）；显示标注"电压表V₂测小灯泡电压"于(340,395)。引导学生确认V₂并联在小灯泡两端。
- 步骤5：点击「下一步」→ 移除步骤4的V₂高亮；在画布中央弹出总结框(220,190)-(580,310)，背景#e3f2fd，内写三条结论：
  ① 电路为串联电路（电流只有一条路径）
  ② 电流表A测串联电路中的电流
  ③ 电压表V₁测电源电压，电压表V₂测小灯泡两端电压
  教师可在此步带领学生整体回顾电路结构。
- 教师可随时点击「上一步」回退到任意步骤复习。

[技术实现]
- JS库选择：原生SVG（使用HTML内嵌SVG元素），原因：电路图由简单几何形状（线段、圆、折线、文本）构成，原生SVG足以满足，无需引入外部库，减少依赖。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------------+
  |  V₁○    串联电路(步骤1)                                 |
  |   |  开关────┬────滑动变阻器────┬────○A  电流表(步骤2)   |
  |   |          |                  |                        |
  |   |        电源                 |                        |
  |   |          |                  |                        |
  |   |  灯泡────┴─────────────────┴────电流表              |
  |   |                                                    |
  |   └────────────────────────────────────┐               |
  |                              V₂○(步骤4)│               |
  |                                        |               |
  |        [总结框 步骤5]                  |               |
  |                                        |               |
  |              [◀上一步] [下一步▶]       |               |
  +--------------------------------------------------------+
  [控件栏 y=440~490]
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `let currentStep = 0;` 记录当前步骤（0~5）。每步切换时，先隐藏所有步骤专属元素（高亮层、标注文字、总结框），再根据currentStep显示对应元素。
  2. 元素分层：SVG内按顺序绘制——底层导线 → 元件符号 → 电表符号 → 高亮层（初始hidden） → 标注文字（初始hidden） → 总结框（初始hidden）。高亮层使用与底层相同路径但不同颜色和线宽，通过CSS `display` 或 `visibility` 控制显隐。
  3. 电流方向箭头（步骤1）：使用SVG `<polygon>` 绘制三角形箭头，放置在导线中点，旋转角度与导线方向一致（水平线箭头0°或180°，竖线箭头90°或270°）。
  4. 电表高亮：使用SVG `<circle>` 的 `stroke` 和 `fill` 属性，步骤切换时修改样式类名。
  5. 引线高亮（步骤3/4）：单独绘制一套与V₁/V₂引线重合的彩色线段，初始 `display:none`，步骤触发时显示。
  6. 按钮状态：步骤0时禁用「上一步」，步骤5时禁用「下一步」，通过设置 `disabled` 属性和CSS透明度区分。
  7. 动画曲线：无需复杂动画，步骤切换直接显隐（瞬时），保证教学节奏可控；如需柔和过渡，可加100ms CSS opacity过渡。
- ID命名规范：所有交互元素ID必须以 `scene1-` 为前缀：
  - 按钮：`scene1-btn-prev`、`scene1-btn-next`
  - 高亮组：`scene1-hl-path`（电流路径）、`scene1-hl-ammeter`（电流表）、`scene1-hl-v1`（V₁表头+引线）、`scene1-hl-v2`（V₂表头+引线）
  - 标注文字：`scene1-label-step1` ~ `scene1-label-step4`
  - 总结框：`scene1-summary-box`
  - 元件：`scene1-part-switch`、`scene1-part-bulb`、`scene1-part-rheostat`、`scene1-part-ammeter`、`scene1-part-v1`、`scene1-part-v2`、`scene1-part-power`
  - JS中获取元素严格使用 `document.getElementById`，禁止querySelectorAll配合全局class
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免多场景合并时变量污染全局作用域。
