[图示主题与整合说明]
- 本图示主题：生物学概念层级关系的视觉化解构——包含关系与并列关系的图式表达
- 整合的步骤/概念：
  1) 原题图式整体感知（大圆套小圆的经典韦恩图结构）；
  2) 上位概念（大类）的识别与高亮；
  3) 下位并列概念（子类）的识别与高亮；
  4) 关系抽象：虚线箭头标注"包含"，文字标注"并列关系（互不交叉）"。
- 教学价值：教师可按照"整体→局部→关系"的认知递进顺序讲解，每步暂停提问，帮助学生将抽象的集合关系转化为可视化的空间结构，为后续判断选项（鱼类/爬行类/鸟类/哺乳类等）奠定图式基础。

[分步序列]

[交互方案]
- 交互类型：分步按钮导航（◀ 上一步 / 下一步 ▶）
- 控件说明：
  · 「上一步」按钮：位置(315, 452)，尺寸90×34 px，步骤0时禁用（opacity 0.4，pointer-events none）
  · 「下一步」按钮：位置(435, 452)，尺寸90×34 px，步骤3时禁用或显示为"完成"
  · 步骤指示器：位置(400, 445)，文字"步骤 n / 4"，font-size 12 px，颜色 #666666
- 教师操作流程：
  1. 教师展示初始图，提问"这幅图表达了什么逻辑关系？"
  2. 点击「下一步」进入步骤1，蓝高亮大圆，讲解"I代表上位概念或大类"
  3. 点击「下一步」进入步骤2，绿高亮三个小圆，讲解"II、III、IV是并列的子类"
  4. 点击「下一步」进入步骤3，出现虚线箭头与关系文字，总结"大类包含子类，子类之间互不交叉"
  5. 可随时点击「上一步」回退，强化学生记忆。

[技术实现]
- JS库选择：原生 SVG（通过 JavaScript 操作 DOM 属性），无需外部库。理由：场景仅涉及圆形、直线、文本和简单样式切换，原生 SVG 性能最优、依赖最少。
- 画布尺寸：800 × 500 px（固定画布，SVG viewBox="0 0 800 500"）
- 布局草图（ASCII）：
  ```
  0    100  200  300  400  500  600  700  800
  +----+----+----+----+----+----+----+----+----+
  0   |          [上位概念标签]                  |
  50  |                   ↓                    |
  100 |         .------------------.           |
  150 |        /   [包含]    [II]   \          |
  200 |       [I]       ↘    ↑      \         |
  250 |        \      [III]←[I]→[IV]  \        |
  300 |         \         ↑           \        |
  350 |          '---------[并列关系]--'        |
  400 |         [下位概念标签]                 |
  450 |              [◀上一步] [下一步▶]        |
  500 +----+----+----+----+----+----+----+----+----+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `let currentStep = 0;`（范围0~3），每次点击按钮时调用 `renderStep(step)`，根据 step 值设置各元素的 display / stroke / fill 属性。
  2. 样式切换：不通过 class 切换，直接操作 SVG 元素的 `setAttribute('stroke', ...)` 和 `setAttribute('fill', ...)`，避免 CSS 优先级问题。
  3. 箭头实现：使用 SVG <defs> 定义 <marker id="scene1-arrowhead">，在步骤3时将三条 <line> 的 `marker-end` 指向该 marker。
  4. 动画曲线：无需复杂动画，元素出现/隐藏使用直接切换（display: none/block），高亮颜色切换瞬时完成，保持教学演示的清晰与即时性。
  5. 事件绑定：按钮绑定 `onclick`，在 IIFE 内部定义函数 `goNext()` 和 `goPrev()`，更新 currentStep 后调用 renderStep。
- ID 命名规范：
  · 大圆：id="scene1-circle-I"
  · 小圆：id="scene1-circle-II"、"scene1-circle-III"、"scene1-circle-IV"
  · 标签：id="scene1-label-I"、"scene1-label-II"、"scene1-label-III"、"scene1-label-IV"
  · 动态标签：id="scene1-tag-super"、"scene1-tag-sub"、"scene1-tag-include"、"scene1-tag-parallel"
  · 箭头线：id="scene1-arrow-II"、"scene1-arrow-III"、"scene1-arrow-IV"
  · 按钮：id="scene1-btn-prev"、"scene1-btn-next"
  · 步骤文本：id="scene1-step-text"
  · JS 中统一使用 `document.getElementById()` 获取元素，禁止 querySelectorAll 配合全局 class。
- IIFE 隔离：所有 JavaScript 代码包裹在 `(function() { ... })();` 中，避免多场景合并时的变量污染。
