[图示主题与整合说明]
- 本图示主题：四个选项的概念层级关系验证与原图结构对比
- 整合内容：将选项 A（脊椎动物并列关系）、选项 B（遗传物质嵌套关系）、选项 C（种子部分包含关系）、选项 D（微生物分类包含关系）逐一图示化，并与原题缩略图结构进行左右对比，引导学生观察"一大类包含三个并列子类"的模型。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「◀ 上一步」按钮：位置 (280,455)，大小 80×28。作用：回退到上一个步骤，步骤0时禁用。
  2. 步骤指示器：位置 (400,470)，文字如"选项 A / 4"。作用：显示当前分析的选项位置。
  3. 「下一步 ▶」按钮：位置 (480,455)，大小 80×28。作用：前进到下一个步骤，步骤4时禁用或变为"完成"。
- 教师操作流程：
  1. 教师打开图示，步骤0显示引导文字和原题缩略图，让学生明确任务目标。
  2. 教师点击「下一步」进入步骤1（选项A），讲解"鱼类、爬行类、鸟类、哺乳类是并列关系，没有包含关系，因此不符合原图"。
  3. 继续点击「下一步」进入步骤2（选项B），讲解"细胞核→染色体→DNA→基因是层层嵌套，而且I不是最大的，不符合"。
  4. 继续点击「下一步」进入步骤3（选项C），讲解"种子虽然最大，但胚内部还包含子叶，不是三个并列子类，不符合"。
  5. 继续点击「下一步」进入步骤4（选项D），讲解"微生物包含病毒、细菌、真菌三个并列子类，与原图结构完全一致，因此选D"。
  6. 教师可随时点击「上一步」回退，让学生重新观察对比。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无需额外库）。理由：本场景以几何图形（矩形、圆、路径）和显隐切换为主，原生 SVG 足以高效实现，避免引入不必要的依赖。
- 画布尺寸：800 × 500 px（沿用规定）
- 布局草图（ASCII）：
  ```
  +----------------------------------------------------------+
  |                                                          |
  |   +------------------------+  +----------------------+   |
  |   |                        |  |  [原题缩略图]        |   |
  |   |   [概念关系图区域]      |  |   I包含II,III,IV    |   |
  |   |   60% 宽度 (x:20-500)   |  |   (x:520-780)       |   |
  |   |                        |  |                      |   |
  |   |   步骤1: 四个并列矩形   |  |  [✗ 或 ✓] 标记      |   |
  |   |   步骤2: 四个嵌套矩形   |  |                      |   |
  |   |   步骤3: 嵌套+并列矩形  |  |  [结论原因文字]      |   |
  |   |   步骤4: 大圆含三小圆   |  |  [结论结果文字]      |   |
  |   |                        |  |                      |   |
  |   +------------------------+  +----------------------+   |
  |                                                          |
  |        [◀ 上一步]  [选项 X/4]  [下一步 ▶]               |
  |        (280,455)   (400,470)   (480,455)                 |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用局部变量 `currentStep`（0~4），每次按钮点击更新状态并重新渲染视图。
  2. 分组管理：每个步骤的视觉元素包裹在独立的 SVG `<g>` 中（id="scene2-step0-group" 至 "scene2-step4-group"），通过添加/移除 CSS class `active` 控制显示（opacity + visibility transition，0.3s ease）。
  3. 缩略图与结论区：缩略图在所有步骤均显示，单独一个 `<g id="scene2-thumbnail-group">`；结论标记和文字按步骤分两组（scene2-conclusion-wrong / scene2-conclusion-correct），根据当前步骤切换。
  4. 按钮状态同步：每次步骤切换后，检查 `currentStep` 值更新按钮 disabled 状态和步骤指示器文字。
  5. 坐标计算：所有概念框/圆均基于左侧区域中心 (260,240) 进行对称或居中计算，确保视觉平衡。
  6. 动画曲线：CSS `transition: opacity 0.3s ease, visibility 0.3s ease;`，步骤切换时旧步骤淡出、新步骤淡入，避免视觉跳跃。
  7. 事件绑定：按钮使用 `addEventListener('click', ...)`，在 IIFE 内部绑定，避免全局污染。
- ID 命名规范：所有交互元素 ID 必须以 `scene2-` 为前缀。例如：
  - 步骤分组：`scene2-step0-group`, `scene2-step1-group`, ..., `scene2-step4-group`
  - 缩略图：`scene2-thumbnail-group`, `scene2-thumb-circle-i`, `scene2-thumb-circle-ii`, ...
  - 结论区：`scene2-conclusion-wrong`, `scene2-conclusion-correct`, `scene2-mark-x`, `scene2-mark-check`
  - 按钮：`scene2-btn-prev`, `scene2-btn-next`
  - 指示器：`scene2-step-indicator`
  - JS 中获取元素使用 `document.getElementById`，禁止跨场景使用全局 class 选择器。
- IIFE 隔离：所有 JavaScript 代码包裹在 `(function() { ... })();` 中，变量不泄露全局作用域。
