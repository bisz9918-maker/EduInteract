[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「◀ 上一步」按钮：位于控件栏左侧（x=270~380, y=445~481），点击后回退到上一个步骤，步骤0时禁用（透明度降低）。
  2. 步骤指示器：位于两按钮之间（x=400, y=467），显示当前步骤编号（如"步骤 1/6"至"步骤 6/6"）。
  3. 「下一步 ▶」按钮：位于控件栏右侧（x=420~530, y=445~481），点击后前进到下一个步骤，步骤5（最后一步）时禁用。
- 教师操作流程：
  1. 教师打开图示，初始显示步骤0（题目原图），向学生展示概念图框架和四个选项。
  2. 点击「下一步」进入步骤1，引导学生确定A/B/C/D/E各代表的物质，同时展示选项正误判断结果。
  3. 继续点击「下一步」依次进入步骤2~5，每步聚焦一个选项的辨析，配合展开的列表或结构图进行讲解。
  4. 讲解过程中可随时点击「上一步」回退，复习前面内容。

[技术实现]
- JS库选择及原因：原生SVG + 原生JavaScript。本场景以几何图形、文本标签和简单显隐切换为主，无需复杂绘图库；原生SVG文本渲染清晰，便于精确控制每个标签坐标和样式。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +----------------------------------------------------------+
  |  +-----+   +-----+   +-----+   +-----+   +-----+        |  y=60-110
  |  |  A  | + |  B  | + |  C  | → |  D  | → |  E  |        |
  |  +-----+   +-----+   +-----+   +-----+   +-----+        |
  |  含氮碱基  脱氧核糖   磷酸    脱氧核苷酸   DNA           |  y=120
  |                                                          |
  |  [动态展开区：碱基列表 / 脱氧核苷酸列表 / 五碳糖对比]      |  y=155-280
  |                                                          |
  |  A．A表示的碱基有5种                           ×         |  y=310-334
  |  B．D表示脱氧核苷酸                            √         |  y=334-358
  |  C．D表示的结构有8种                           ×         |  y=358-382
  |  D．B表示的是核糖                              ×         |  y=382-406
  |                                                          |
  |       [◀ 上一步]   步骤 X/6   [下一步 ▶]                  |  y=430-500
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `currentStep`（范围0~5），`render()`函数根据当前步骤控制所有元素的显隐、文本内容和颜色。所有动态元素初始状态在SVG中定义好，通过修改 `display` 或 `opacity` 属性切换。
  2. 坐标计算：所有矩形框、文本、线条坐标严格采用上述布局坐标表中的数值，确保代码agent可直接复制使用。
  3. 动画曲线：步骤3的D框闪烁使用CSS `@keyframes` 定义（stroke-color和stroke-width交替变化，0.3s/次，共闪烁3次），通过添加/移除class触发；列表展开和选项背景显示使用CSS `transition: opacity 0.3s ease` 实现淡入。
  4. 事件绑定：上一步/下一步按钮绑定click事件，调用 `prevStep()` / `nextStep()`，更新 `currentStep` 后调用 `render()`。按钮禁用状态通过添加/移除 `disabled` class控制样式（opacity: 0.4, pointer-events: none）。
  5. 文本替换策略：B下标和D下标使用同一个 `<text>` 元素，通过JS修改 `textContent` 和 `fill` 属性实现步骤0→1的切换；A下标使用单独的 `<text>` 元素，步骤0时 `opacity=0`，步骤1时 `opacity=1`。
  6. 选项高亮词：使用 `<text>` 内嵌多个 `<tspan>`，通过 `x` 属性精确定位高亮词位置（如"5种"、"8种"、"核糖"），并单独设置 `fill` 颜色。
