[图示主题与整合说明]
- 本图示主题：突触结构识别与神经元关系判断
- 整合的步骤/概念：
  ① 神经元与突触数量统计（判断选项①"3个突触"错误）；

- 教学价值：教师通过分步导航，先让学生识别三个神经元轮廓与电流计位置，再逐步高亮神经元、标注突触结构（前膜/间隙/后膜）并明确突触数量为2，最后区分轴突末梢与树突/胞体，从而理解突触传递的方向性与结构多样性。

[分步序列]
- 步骤0（初始状态）：显示三个神经元轮廓（无填充）、电流计及引线、a/b/c/d 四个黑点及其标签、A/B/C 标签、电流计标签。呈现题目原始结构，等待教师开始讲解。
- 步骤1（识别神经元）：神经元A、B、C的填充色以 opacity 0→0.15 淡入，轮廓线宽由 1.5px 变为 2.5px 高亮，强化学生"图中共有3个神经元"的认知。
- 步骤2（突触结构与数量判断）：两个突触区域出现黄色高亮框；突触小泡显现；突触1下方出现"突触前膜/突触间隙/突触后膜"标签，突触2上方出现对应三标签；主图上方出现红色加粗文字"共2个突触"，明确选项①"3个突触"错误。
- 步骤3（结构类型判断）：A突触小体旁出现引线+"突触小体"标签；B左侧下方出现"树突/胞体"，B右侧上方出现"轴突"；C左侧下方出现"树突或胞体"。通过标注指出B既有树突/胞体也有轴突，因此选项⑤"A、B一定是轴突"错误。

[交互方案]
- 交互类型：分步按钮导航（◀ 上一步 / 下一步 ▶）
- 控件说明：
  1. 「◀ 上一步」按钮：位于控件区左侧 (300,452)，宽80×高32，点击回退到上一状态，步骤0时禁用（opacity 0.4）。
  2. 「下一步 ▶」按钮：位于控件区右侧 (420,452)，宽80×高32，点击推进到下一状态，步骤3时禁用。
  3. 步骤指示器：位于两按钮下方居中 (400,485)，显示当前步骤序号，如"步骤 1 / 4"。
- 教师操作流程：
  1. 教师展示步骤0，让学生观察原始结构并思考选项；
  2. 点击「下一步」进入步骤1，引导学生识别3个神经元；
  3. 再次点击「下一步」进入步骤2，讲解突触的三层结构并指出突触数量实为2个，判断①错误；
  4. 再次点击「下一步」进入步骤3，讲解突触小体、树突/胞体与轴突的区别，判断⑤错误；
  5. 可随时点击「上一步」回退复习。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript。原因：本场景为静态几何图形与分步显隐，无需复杂数学计算或3D渲染，原生SVG路径、椭圆、文本即可满足，减少外部依赖。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图：
  ```
  +--------------------------------------------------+
  |  电流计(430,90)  标签"电流计"                      |
  |     /    \                                       |
  |    /      \                                      |
  |   a        d    "共2个突触"(步骤2)                 |
  |  (305,250) (670,250)                             |
  |   |        |                                     |
  |   A突触小体—B胞体—B突触小体—C胞体                |
  |   /         |          |         \               |
  |  胞体      b          c          轴突            |
  | (150,340) (365,248) (585,248)  (670,250)        |
  |                                                 |
  |  [突触1标注在下]  [突触2标注在上]  [结构标注]      |
  |                                                 |
  |              [◀上一步] [下一步▶]                 |
  |                 步骤 1/4                         |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：维护变量 `currentStep`（0~3）。`render()` 函数根据 `currentStep` 值，遍历各步骤对应的元素ID列表，设置 `display` 或 `opacity` 属性。使用 CSS transition 实现 0.3s 淡入效果。
  2. 元素分组显隐：将每一步新增的视觉元素放入独立的 `<g>` 组（如 `scene1-step1-group`、`scene1-step2-group`），通过控制组的 `display` 属性简化状态切换。
  3. 坐标计算：神经元轴突使用二次贝塞尔曲线（path Q指令）；突触小泡使用 circle 元素随机分布在小体内；引线使用 line 元素配合 `stroke-dasharray="4,2"`。
  4. 动画曲线：仅使用 CSS `transition: opacity 0.3s ease`，避免复杂动画干扰教学节奏。
  5. 事件绑定：为「上一步」「下一步」按钮绑定 `click` 事件，更新 `currentStep` 后调用 `render()` 并更新按钮禁用状态与步骤指示器文本。
- **ID 命名规范**：所有交互及视觉元素ID均以 `scene1-` 为前缀，例如 `scene1-neuron-a-body`、`scene1-btn-prev`、`scene1-step-indicator`。JS 中严格使用 `document.getElementById` 获取元素，禁止跨场景选择器。
- IIFE 隔离：所有 JavaScript 逻辑包裹在 `(function() { ... })()` 中，避免全局变量污染，确保多场景合并时互不干扰。
