[图示主题与整合说明]
- 本图示主题：兴奋传导方向与电流计偏转规律（突触单向传递）
- 整合的步骤/概念：
  1. 刺激b点时，兴奋在B神经元双向传导：向左传至a点（近），电流计第1次偏转；向右经B→C突触传至C神经元，再传至d点（远），电流计第2次偏转。共偏转2次。
  2. 刺激c点时，兴奋在C神经元双向传导：向右传至d点（近），电流计第1次偏转；向左传至B→C突触，因突触传递单向（只能B→C，不能逆传），兴奋无法到达B神经元，a点无电位变化。共偏转1次。
- 教学价值：教师通过状态切换对比两种刺激情境，配合播放动画，直观展示"突触单向传递"如何决定电流计偏转次数，突破学生"兴奋双向传导=指针一定偏转2次"的思维定势。

[分步序列]
本场景采用「多状态切换 + 播放动画」交互模式，共2个互斥状态。

【状态0/初始】加载后默认进入「刺激b点」状态（或静息状态）
- 显示元素：三个神经元轮廓、突触结构、a/b/c/d点、电流计（指针垂直向下）、所有静态标签
- 隐藏元素：闪电、兴奋波、禁止符号、偏转次数标注
- 状态按钮：「刺激b点」高亮（激活态），「刺激c点」普通态

【状态A：刺激b点】
- 点击「播放传导」后动画序列：
  1. t=0.0s：b点上方出现黄色闪电符号；绿色兴奋波1从b(300,250)向左出发传向a；绿色兴奋波2从b向右出发传向B-C突触
  2. t=0.5s：兴奋波1到达a(140,250)，电流计指针从垂直向下(90°)逆时针旋转45°至左偏(135°)，表示第1次偏转
  3. t=0.5s~1.5s：指针保持左偏状态
  4. t=1.5s：兴奋波2到达B-C突触前膜(430,250)，触发递质释放动画（5个蓝色小泡从x=430飞向x=445）
  5. t=1.5s~2.5s：递质释放期间，兴奋波在C神经元内变为红色，从突触后膜(445,250)向右传向d
  6. t=3.0s：红色兴奋波到达d(640,250)，电流计指针从左偏(135°)顺时针旋转90°至右偏(45°)，表示第2次偏转
  7. t=3.0s~4.0s：指针保持右偏状态
  8. t=4.0s~4.5s：指针从右偏回到垂直向下(90°)
  9. t=4.5s：在电流计右侧(460,110)显示绿色文字"偏转2次"；闪电消失；所有兴奋波消失；动画结束
- 动画过程中「播放」按钮禁用，动画结束后恢复

【状态B：刺激c点】
- 点击状态按钮「刺激c点」切换：
  - 重置所有动画元素（指针回中、隐藏所有波和标注）
  - 「刺激c点」按钮高亮，「刺激b点」普通态
- 点击「播放传导」后动画序列：
  1. t=0.0s：c点上方出现黄色闪电符号；红色兴奋波1从c(480,250)向右出发传向d；红色兴奋波2从c向左出发传向B-C突触
  2. t=0.4s：兴奋波1到达d(640,250)，电流计指针从垂直向下(90°)顺时针旋转45°至右偏(45°)，表示第1次偏转
  3. t=0.4s~1.2s：指针保持右偏状态
  4. t=1.2s~1.8s：兴奋波2继续向左传导至B-C突触后膜(445,250)
  5. t=1.8s：在B-C突触上方(437,220)出现红色禁止符号（圆圈内×），表示兴奋无法逆传过突触；a点始终无兴奋波到达
  6. t=1.2s~2.0s：指针从右偏回到垂直向下(90°)
  7. t=2.0s：在电流计右侧(460,110)显示红色文字"仅偏转1次"；闪电与禁止符号消失；所有兴奋波消失；动画结束
- 动画过程中「播放」按钮禁用

【教师回退操作】
- 教师可随时点击另一状态按钮切换，切换时自动重置动画到该状态初始画面
- 同一状态下动画结束后，可再次点击「播放传导」重新观看

[交互方案]
- 交互类型：多状态切换（2个状态按钮）+ 播放动画（单按钮触发）
- 控件说明：
  1. 「刺激b点」按钮：位置(240,12)，宽140高32。点击切换到状态A，重置动画，按钮变为激活样式（填充#e3f2fd，边框#1565c0）。
  2. 「刺激c点」按钮：位置(420,12)，宽140高32。点击切换到状态B，重置动画，按钮变为激活样式。
  3. 「播放传导」按钮：位置(340,455)，宽120高32。点击触发动画序列；动画播放期间禁用（opacity 0.5，不可点击）。
- 教师操作流程：
  1. 教师先点击「刺激b点」→ 点击「播放传导」→ 观察兴奋双向传导及电流计偏转2次的过程。
  2. 讲解完状态A后，点击「刺激c点」切换状态 → 点击「播放传导」→ 观察兴奋在C内传导、突触处被阻断、电流计仅偏转1次的过程。
  3. 通过两个状态的对比，引导学生得出结论：突触单向传递导致刺激c点时兴奋无法逆传，故偏转次数不同。
  4. 可随时切换状态重新播放，配合讲解重点（如突触延搁、递质释放、指针偏转方向等）。

[技术实现]
- JS库选择：原生 SVG + 原生 JavaScript（无需外部库）。理由：场景为2D静态几何图形+简单位移动画，SVG的path/circle/line/text足以表达神经元形态，JS控制属性动画即可，无需引入D3/Three.js等重型库。
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  +--------------------------------------------------+
  |  [刺激b点]        [刺激c点]         y=0~50       |
  |                                                  |
  |         电流计  (380,110)                        |
  |            ◯                                     |
  |           /|\                                    |
  |   a━━━━━━b━━━━━━c━━━━━━━━d   轴线 y=250          |
  |   ↑      ↑      ↑        ↑                       |
  |   A      B━━━━━→C        |   神经元               |
  |   (左下) (中)   (右)     |                       |
  |                          |                       |
  |   突触A-B   突触B-C(禁止×)                       |
  |                                                  |
  |         [  播放传导  ]         y=455             |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：定义 state = { mode: 'b'|'c', isPlaying: false, animationId: null }。mode切换时调用reset()清除所有动态元素、指针回中、隐藏标注。
  2. 指针旋转：使用SVG transform="rotate(angle, 380, 110)"，angle初始90°（垂直向下）。左偏=135°，右偏=45°。旋转动画用requestAnimationFrame插值，避免CSS动画与SVG属性冲突。
  3. 兴奋波移动：创建<circle class="scene2-wave">元素，通过requestAnimationFrame更新cx属性实现平滑移动。绿色波和红色波分别创建、分别管理生命周期。
  4. 递质释放：在突触间隙内创建5个小圆点，给每个圆点随机初始偏移和速度，用JS更新cx/cy模拟小泡扩散过间隙的效果，持续约1秒后移除。
  5. 时间线控制：用performance.now()或Date.now()做时间戳，在动画循环中根据已过去的时间判断触发哪个事件（到达a、指针偏转、递质释放等），避免嵌套setTimeout导致难以取消。
  6. 动画取消：切换状态或重复播放时，先cancelAnimationFrame(animationId)，并移除所有动态创建的SVG元素（wave、flash、particles、resultText）。
  7. 按钮状态：播放期间设置isPlaying=true，按钮添加disabled属性和视觉反馈；动画结束或切换状态时恢复。
- ID命名规范：
  - 静态元素：scene2-neuron-a, scene2-neuron-b, scene2-neuron-c, scene2-synapse-ab, scene2-synapse-bc, scene2-point-a, scene2-point-b, scene2-point-c, scene2-point-d, scene2-ammeter, scene2-ammeter-pointer, scene2-wire-left, scene2-wire-right
  - 动态元素（JS创建）：scene2-wave-left, scene2-wave-right, scene2-flash, scene2-particle-N, scene2-block-sign, scene2-result-text
  - 控件：scene2-btn-mode-b, scene2-btn-mode-c, scene2-btn-play
- IIFE隔离：所有JS代码包裹在 (function() { ... })() 中，避免全局污染。
