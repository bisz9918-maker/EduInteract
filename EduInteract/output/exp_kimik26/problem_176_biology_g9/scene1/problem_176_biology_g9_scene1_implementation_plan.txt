[分步序列]
- 初始状态（步骤0）：显示两条竖直血管（4段，均为2px黑色）、水平丝带、四个编号标签①②③④（带白底黑圈）、丝带文字。隐藏所有箭头、膨胀填充、类型标签。等待教师触发。
- 步骤1（血流方向）：点击「下一步」→ 左血管左侧出现蓝色向上箭头（静脉，向心回流），右血管右侧出现红色向下箭头（动脉，离心输出）。血管本身保持2px黑色不变。
- 步骤2（扎紧效应）：点击「下一步」→ 左血管下段(①区)线宽变为6px并叠加蓝色半透明填充（膨胀）；左血管上段(④区)线宽变为1px（变扁）。右血管上段(③区)线宽变为6px并叠加红色半透明填充（膨胀）；右血管下段(②区)线宽变为1px（变扁）。箭头保持显示。
- 步骤3（类型判断）：点击「下一步」→ 左血管左侧出现"静脉"标签（蓝色文字+绿色半透明背景框+虚线引线），右血管右侧出现"动脉"标签（红色文字+绿色半透明背景框+虚线引线）。明确标注血管类型，高亮正确对应关系。
- 教师可随时点击「上一步」回退到任意步骤复习。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript（无外部库）。理由：本场景为简单几何图形（线段、圆、矩形、箭头），SVG原生支持足够，无需引入D3等重型库。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  [静脉]━━━┓                                      |
  |           ┃ 左血管(300,100~400)                  |
  |      ▲    ┃     ●④(250,175)                     |
  |   左箭头  ┃                                      |
  |           ┃              ●③(550,175)            |
  |  ●①(250,325) ┃        右血管(500,100~400)       |
  |           ┃              ●②(550,325)            |
  | ══════════╪══════════════════════ 丝带(200~600,250)
  |           ┃                                      |
  |           ┃     │ 右箭头                         |
  |           ┃     ▼                                |
  |           ┗━━━[动脉]                             |
  |                                                  |
  |      [◀上一步]  步骤X/3  [下一步▶]               |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：维护变量 `currentStep`（0~3），每步定义显隐元素列表，通过切换 `display` 或 `opacity` 属性实现。
  2. 血管分段：将每条血管拆分为上段和下段两个独立 `<line>` 元素，便于分别控制线宽（stroke-width）和颜色。
  3. 膨胀填充：使用 `<rect>` 圆角矩形(rx=6)覆盖在血管外侧，fill-opacity=0.2，步骤2时显示。
  4. 箭头绘制：在SVG `<defs>` 中定义 `<marker>`（蓝色上箭头、红色下箭头），通过 `marker-end` 属性绑定到箭头线段。
  5. 动画曲线：所有显隐切换使用CSS transition（opacity 0→1，duration 0.3s，ease-in-out），避免生硬跳变。
  6. 事件绑定：按钮点击事件直接修改状态机并调用 `renderStep()` 更新视图。
  7. 边界处理：步骤0时「上一步」禁用，步骤3时「下一步」禁用（或循环）。
- **ID命名规范**：所有SVG元素及控件ID必须以 `scene1-` 为前缀。例如：`scene1-vessel-left-up`、`scene1-vessel-left-down`、`scene1-arrow-left`、`scene1-fill-left-down`、`scene1-type-vein-group`、`scene1-btn-prev`、`scene1-btn-next`。JS中严格使用 `document.getElementById` 获取元素，禁止全局class选择器，避免多场景合并时跨场景污染。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })()` 立即执行函数中，变量不泄露全局作用域。
