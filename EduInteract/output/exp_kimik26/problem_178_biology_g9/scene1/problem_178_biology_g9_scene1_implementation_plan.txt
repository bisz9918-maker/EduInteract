[技术实现]
- JS库选择：原生SVG（使用DOM API操作SVG元素）。理由：本场景为静态几何图形（矩形、线段、文字）的分步显示/隐藏，无复杂动画、无数据可视化、无3D，原生SVG完全满足且零依赖。
- 画布尺寸：800 × 500 px（固定画布，SVG viewBox="0 0 800 500"）
- 布局草图（ASCII）：
  ```
  +----------------------------------------------------------+
  | P  [黄花]×[白花]                                         |
  |       ↓①                                                 |
  | F₁ [黄花]  [白花]              [右侧面板 430×380]        |
  |    ↓②      ↓③                  [步骤标题/内容/表格]      |
  | F₂ [黄花][黄花][白花]            [答案框]                 |
  |                                                          |
  |                                                          |
  | [A][B][C][D]        [◀上一步] 步骤 X/5 [下一步▶]        |
  +----------------------------------------------------------+
  主图解区(左)          辅助面板(右430-780)    控件区(底445-485)
  ```
- 关键实现要点：
  1. 状态机设计：变量 `currentStep`（0~4），`updateScene(step)`函数根据步骤值统一控制所有元素的显示/隐藏/高亮/颜色。
  2. 元素预创建：所有SVG元素（包括各步骤才显示的内容）在初始化时全部创建，默认 `display:none` 或 `opacity:0`，通过切换属性实现步骤过渡，避免DOM频繁创建销毁。
  3. 高亮实现：通过添加/移除CSS类（如 `.highlight-green`、`.highlight-red`）修改 `stroke` 和 `stroke-width`。白花框在步骤1加绿色边框，步骤4加红色边框时，红色覆盖绿色（步骤4优先级更高）。
  4. 右侧面板切换：预先创建5组 `<g>` 元素（每组对应一个步骤的面板内容），通过 `display` 属性切换显示当前步骤的组。
  5. 选项按钮变色：直接修改 `<rect>` 的 `fill` 属性（灰#9e9e9e → 绿#2e7d32 → 红#c62828）。
  6. 过渡动画：对显示/隐藏的元素使用CSS `transition: opacity 0.3s ease`，通过切换 `opacity` 和 `pointer-events` 实现淡入淡出。
  7. 箭头标记：使用SVG `<marker>` 定义箭头头部，在 `<path>` 的 `marker-end` 属性引用。
  8. 分叉箭头③：使用 `<path d="M 235 180 L 235 220 M 235 220 L 190 255 M 235 220 L 275 255" marker-end="url(#arrowhead)"/>` 绘制。
  9. 禁用状态：上一步/下一步按钮在边界步骤时添加 `disabled` 类，降低opacity并禁用点击。
