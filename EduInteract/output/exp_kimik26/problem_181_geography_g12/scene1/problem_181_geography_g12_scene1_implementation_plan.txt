[图示主题与整合说明]
- 本图示主题：北半球三圈环流侧视剖面与气压带风带分布（图甲解析）
- 整合的步骤/概念：
  1. 建立地表剖面空间锚点（A→N，0°→90°N）
  2. 关键纬度定位（0°、30°N、60°N、90°N）
  3. 低纬哈德莱环流（赤道上升→副热带下沉→东北信风）
  4. 中纬费雷尔环流（副热带下沉→副极地上升→盛行西风）
  5. 高纬极地环流（副极地上升→极地下沉→极地东风）
  6. 气压带名称、成因（热力/动力）与填充高亮
  7. 答案高亮框（30°/60°定位、风带气压带名称、成因标签）
- 教学价值：教师通过分步导航，从单环流到三环流逐步叠加，随时回退到任意步骤强化学生记忆；右侧/下方标注区集中呈现名称与成因，避免与图形重叠。

[分步序列]
- 步骤0（基础框架）：显示地表线(A→N)、字母A/B/C/D/E/F/N。不显示环流、箭头、标注。建立"从左下到右上纬度升高"的空间锚点。
- 步骤1（纬度定位）：新增纬度标注0°、30°N、60°N、90°N及四条虚线引出线。教师可强调"A是赤道0°，C是30°N，E是60°N，N是北极点90°"。
- 步骤2（低纬环流）：新增低纬环流圈轮廓、A处红色上升箭头、C处蓝色下沉箭头、低纬高空灰色虚线箭头、绿色东北信风近地面箭头、B处"东北信风带"标签及引出线。教师讲解哈德莱环流与信风形成。
- 步骤3（中纬环流）：新增中纬环流圈轮廓、E处红色上升箭头、中纬高空灰色虚线箭头、紫色盛行西风近地面箭头、D处"盛行西风带"标签及引出线。教师讲解费雷尔环流与西风形成。
- 步骤4（高纬环流）：新增高纬环流圈轮廓、N处蓝色下沉箭头、高纬高空灰色虚线箭头、橙色极地东风近地面箭头、F处"极地东风带"标签及引出线。教师讲解极地环流与东风形成。
- 步骤5（气压带与成因）：新增四个气压带椭圆填充区、四条气压带名称文本（含热力/动力成因）及引出线。教师总结气压带分布规律与成因类型。
- 步骤6（答案高亮）：新增C处"30°"红色高亮框、E处"60°"红色高亮框；所有风带名称、气压带名称、成因标签加粗或变色强调。教师对照题目答案进行总结。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  1. 「◀ 上一步」按钮：位于SVG内底部中心偏左，中心坐标(340,470)，宽80×高30。点击后回退到上一分步，隐藏当前步新增元素。
  2. 「下一步 ▶」按钮：位于SVG内底部中心偏右，中心坐标(460,470)，宽80×高30。点击后进入下一分步，显示该步新增元素。
  3. 步骤指示器：位于两按钮下方(400,495)，显示"步骤 X/7"。
- 状态边界处理：
  - 步骤0时，「上一步」按钮禁用（opacity0.5，pointer-events:none）
  - 步骤6时，「下一步」按钮禁用
- 教师操作流程：
  1. 教师打开图示，学生看到基础框架（地表线+字母），建立空间认知。
  2. 教师点击「下一步」，出现纬度标注，提问"30°和60°在哪里"。
  3. 教师继续点击「下一步」，逐步叠加低纬/中纬/高纬环流，每步讲解气流方向与风带形成。
  4. 到步骤5，教师总结气压带分布与热力/动力成因。
  5. 到步骤6，教师对照题目高亮答案区域，完成讲解。
  6. 讲解中可随时点击「上一步」回退，强化学生记忆薄弱点。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：本场景以静态几何图形（线段、路径、椭圆、文本）和显隐切换为主，无需复杂数据绑定或3D渲染，原生SVG性能最优、依赖最少。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [标题区 y=0~50，可选留空或显示主题]
  
  [主图区 y=50~430]
  +----------------------------------------------------------+
  |                                                          |
  |     高纬环流圈    中纬环流圈      低纬环流圈              |
  |        ↑            ↑              ↑                     |
  |   (极地东风)   (盛行西风)      (东北信风)                |
  |        ↘          ↗              ↗                      |
  |    N═══F════E════D════C════B════A  ← 地表线(倾斜)       |
  |    ↑        ↑        ↑        ↑                        |
  |   90°N    60°N     30°N      0°                        |
  |                                                          |
  |    [气压带名称/风带名称/成因标签 — 分布于地表线下方]      |
  |                                                          |
  +----------------------------------------------------------+
  [控件栏 y=450~490]
       [◀ 上一步]    步骤 X/7    [下一步 ▶]
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `currentStep`（0~6），数组 `stepElements` 记录每步对应的SVG元素ID列表。切换步骤时，遍历所有元素，根据所属步骤决定display属性（"block"/"none"）。
  2. 箭头绘制：使用SVG `<line>` + `<marker>` 定义箭头head（上升红色、下沉蓝色、近地面绿/紫/橙、高空灰），通过marker-end自动添加箭头。
  3. 环流圈绘制：使用SVG `<path>` 配合二次贝塞尔曲线（Q指令）绘制三个闭合圆滑环流圈，填充透明仅描边。
  4. 引出线绘制：使用SVG `<line>` stroke-dasharray="4,3" 实现虚线效果。
  5. 高亮框绘制：使用SVG `<rect>` + `<text>` 组合，步骤6时显示并添加CSS描边动画（可选）。
  6. 按钮禁用逻辑：`currentStep===0` 时禁用「上一步」，`currentStep===6` 时禁用「下一步」，通过设置class `disabled` 控制样式。
  7. 坐标计算：地表线各点按线性插值计算（A到N共7等分，B在A-C间1/3处，D在C-E中点，F在E-N间1/3处），确保视觉均匀。
- ID命名规范：所有交互元素ID必须以 `scene1-` 为前缀。示例：
  - 地表线：`scene1-surface-line`
  - 低纬环流圈：`scene1-hadley-cell`
  - 上升箭头A：`scene1-up-arrow-a`
  - 东北信风带标签：`scene1-wind-ne-label`
  - 上一步按钮：`scene1-btn-prev`
  - 下一步按钮：`scene1-btn-next`
  - 步骤指示器：`scene1-step-indicator`
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })()` 中，避免全局变量污染，确保多场景合并时互不干扰。
- 容器结构：外层div（position:relative, width:800px, height:500px）包裹SVG（width:100%, height:100%）和控件div（position:absolute, bottom:10px, left:0, right:0, text-align:center）。
