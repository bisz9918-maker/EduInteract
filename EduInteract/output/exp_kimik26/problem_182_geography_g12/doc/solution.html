完整题目原文：

如图为世界经纬网示意图。读图回答以下问题。(12分)

(1)若某日A点和B点的正午太阳高度相同，则太阳直射点位于_(纬度)，A点位于 B点的方向。

(2)如果一架飞机从B点上空于地方时12：00出发向北飞行，3小时后到达C点上空。飞机飞行距离约( )
A．2580千米 B．3330千米 C．6660千米 D．2266千米

(3)若另一架飞机同时以相同的速度从D点上空开始沿纬线向E点上空飞行．则该飞机全程飞行需要小时．到达E地上空时，E地的地方时为__。

(4)若A点某日昼夜平分，且时刻为14 :00，在图中用阴影画出这一时刻夜半球的范围。

题目分析与整体讲解思路：

本题是一道经典的经纬网综合应用题，核心考查以下能力：

  1. 经纬网图的准确判读（经纬度定位、相对方位）
  2. 正午太阳高度公式的理解与应用
  3. 经纬线实际距离的计算（经线：1°≈111 km；纬线：1°≈111×cosφ km）
  4. 地方时的换算（经度差→时差：15°/小时）
  5. 昼夜半球的判定与绘图（晨昏线、0时经线、12时经线）

从图中可读取五点坐标：

  • A(60°W, 30°N)
  • B(0°, 30°S)
  • C(0°, 0°)
  • D(60°E, 60°N)
  • E(120°E, 60°N)

图示规划：共设计4个交互式图示，分别对应"定位与方向""太阳高度""飞行计算""昼夜半球"四大核心视觉主题，教师可按课堂节奏分步展开。

步骤 1/4

教学说明：正午太阳高度与直射点推导

本图示服务于第(1)问的后半段——通过正午太阳高度相等反推太阳直射点纬度。

引导学生观察的关键点：

  1. A(30°N)与B(30°S)关于赤道呈南北对称分布。
  2. 正午太阳高度公式：H = 90° − |φ − δ|，其中φ为当地纬度，δ为太阳直射点纬度。
  3. 令HA = HB，即|30° − δ| = |−30° − δ| = |30° + δ|。
  4. 解方程可得唯一合理解：δ = 0°（太阳直射赤道）。
  5. 代入验证：H = 90° − 30° = 60°，A、B两地正午太阳高度均为60°。
  6. 强调结论：只有太阳直射赤道时，南北纬度数相同的两地正午太阳高度才相等。

教师可配合图示中的侧视光线，让学生直观感受太阳光线平行入射时，对称纬度的太阳高度角相等。

教学说明：飞行路径、距离与地方时计算

本图示同时覆盖第(2)问和第(3)问，核心是将经纬线距离计算与地方时换算结合起来。

第(2)问推导：

  1. B(0°, 30°S)向北到C(0°, 0°)，沿经线飞行，纬度差为 30°。
  2. 经线上纬度每差1°，实地距离约为 111 km。
  3. 飞行距离 = 30 × 111 = 3330 km，对应选项 B。
  4. 飞行速度 = 3330 ÷ 3 = 1110 km/h。

第(3)问推导：

  1. D(60°E, 60°N)沿纬线向E(120°E, 60°N)飞行，经度差为 60°。
  2. 纬线上经度每差1°的距离公式：111 × cosφ km。
  3. 60°N处：1°经度 ≈ 111 × cos60° = 111 × 0.5 = 55.5 km。
  4. 飞行距离 = 60 × 55.5 = 3330 km。
  5. 以相同速度1110 km/h飞行，所需时间 = 3330 ÷ 1110 = 3小时。
  6. 地方时换算：题目中"同时"出发，理解为两架飞机均在各自起点的地方时12:00起飞。D点在60°E，E点在120°E，E地比D地早 4小时（60°÷15°/h = 4h）。
  7. 到达时D地地方时为15:00，故E地地方时 = 15:00 + 4h = 19:00。
步骤 1/5

教学说明：昼夜平分时的夜半球范围绘制

本图示服务于第(4)问，是整道题的综合性绘图环节，需要学生将时间计算与空间范围对应起来。

推导步骤：

  1. "A点昼夜平分"说明该日为春分或秋分，太阳直射赤道，全球昼夜等长。
  2. 直射赤道时，晨昏线与经线重合，夜半球为一个以0时经线为中央经线的半圆。
  3. A点位于60°W，此时地方时为14:00。地方时12:00的经线（昼半球中央经线）在A点西侧30°，即 90°W。
  4. 0时经线（夜半球中央经线）与12时经线相差180°，故0时经线为 90°E。
  5. 夜半球范围：从昏线（90°E，18:00）向西跨越180°经度到晨线（90°W，6:00），即 90°E→0°→90°W 的半个地球。
  6. 在矩形经纬网图上，应将90°E经线至90°W经线之间的区域（向西方向）用阴影表示。

教师需提醒学生：在圆柱投影图中，夜半球是连续的一个条带，不要误画成两侧边缘。

步骤 1 / 4

总结：完整解答与课堂讲解建议

完整答案：

  1. (1) 0°（赤道）；西北
  2. (2) B
  3. (3) 3 小时；19:00
  4. (4) 夜半球范围为 90°E 向西至 90°W 之间的半个地球（图中用阴影标出）

课堂讲解节奏建议：

  1. 导入（2分钟）：用Scene 1让学生快速定位五点坐标，建立空间框架，确认A在B的西北方向。
  2. 太阳高度探究（3分钟）：用Scene 2引导学生发现A、B关于赤道对称，结合公式推导直射点必在赤道。
  3. 计算突破（4分钟）：用Scene 3对比经线与纬线距离计算的差异，强调"cosφ"在纬线距离中的关键作用，再串联地方时换算。
  4. 综合绘图（3分钟）：用Scene 4带领学生从时间（14:00）反推空间（0时经线），完成夜半球的规范作图。

易错点提醒：

  • 第(3)问容易忽略60°N纬线上1°经度不是111km，必须乘cos60°。
  • 第(3)问地方时计算中，"同时"出发应理解为各自地方时12:00起飞，而非同一绝对时刻。
  • 第(4)问绘图时，注意90°E和90°W在图中的实际位置，避免将夜半球画到图的最边缘。
