[图示主题与整合说明]
- 本图示主题：昼夜平分时的夜半球范围绘制（第(4)问）
- 整合的步骤/概念：从A点地方时14:00出发，通过经度-时间换算推导昼半球中央经线（90°W，12:00）与夜半球中央经线（90°E，0:00），进而确定昏线（0°，18:00）与晨线（180°，6:00），最终在矩形经纬网图上填充夜半球阴影范围（0°经线向东至180°经线，跨180°经度）。
- 教学价值：教师可通过分步导航，逐步展示"时间推算→中央经线确定→晨昏线定位→夜半球绘图"的完整作图逻辑，帮助学生理解地方时计算与昼夜半球空间范围的对应关系。
- 注：原大纲步骤2、步骤3中的晨昏线经线位置存在笔误（90°W为昼半球中央12:00，不可能同时为晨线6:00；90°E为夜半球中央0:00，不可能同时为昏线18:00）。本计划已按正确地理原理修正：昏线为0°（18:00），晨线为180°（6:00），夜半球范围为0°→90°E→180°（图右半幅）。

[分步序列]
- 步骤0（初始状态）：展示完整矩形经纬网底图；高亮赤道（绿色）；标注所有经度（顶部）和纬度（左侧）；显示A/B/C/D/E五个点（A为红色，其余黑色）；显示辅助文字"太阳直射赤道"。等待教师触发下一步。
- 步骤1（确定中央经线）：在A点旁新增"14:00"与"60°W"标注；将90°W经线高亮为红色，左侧标注"12:00"（昼半球中央经线）；将90°E经线高亮为红色，右侧标注"0:00"（夜半球中央经线）。教师可讲解：60°W为14:00，向西30°（2小时）至90°W为12:00，向东150°（10小时）至90°E为0:00。
- 步骤2（界定夜半球范围）：将0°经线高亮为蓝色，下方标注"18:00 昏线"；将180°E经线（右边界）高亮为蓝色，下方标注"6:00 晨线"；在0°经线以东至180°E经线之间的区域（图右半幅）填充蓝色半透明45°斜线阴影，表示夜半球。教师可讲解：夜半球以90°E(0:00)为中心，向西90°到0°(18:00昏线)，向东90°到180°(6:00晨线)，跨180°经度。
- 步骤3（验证与标注）：在夜半球阴影区中央标注"夜半球"与"跨180°经度"；此时图上完整呈现昼半球（左半幅，白色）与夜半球（右半幅，蓝色斜线）的对照，教师可验证夜半球范围并总结作图方法。
- 回退机制：教师可随时点击「上一步」回退至任意步骤复习。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「上一步」按钮：位于(280,448)，宽90px，高32px；点击回退到上一个步骤，步骤0时禁用。
  2. 「下一步」按钮：位于(430,448)，宽90px，高32px；点击前进到下一个步骤，步骤3时禁用。
  3. 步骤指示器：位于(400,485)，显示当前步骤编号（如"步骤 2 / 4"）。
- 教师操作流程：
  1. 教师展示步骤0，说明题目条件（A点昼夜平分→太阳直射赤道，晨昏线与经线重合）。
  2. 点击「下一步」进入步骤1，讲解地方时推算：从A点(60°W, 14:00)向西推2小时到90°W(12:00昼半球中央)，向东推10小时到90°E(0:00夜半球中央)。
  3. 点击「下一步」进入步骤2，讲解晨昏线定位：从夜半球中央(90°E, 0:00)向西90°到0°(18:00昏线)，向东90°到180°(6:00晨线)；夜半球即昏线至晨线之间的区域，在图上填充阴影。
  4. 点击「下一步」进入步骤3，验证夜半球跨180°经度，完成作图讲解。
  5. 可随时点击「上一步」回退复习。

[技术实现]
- JS库选择：原生SVG（题目为简单几何线条与填充，SVG路径、pattern、显隐控制即可满足，无需引入外部库）
- 画布尺寸：800 × 500 px（固定画布，控件栏位于SVG内底部y=440~490区域）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------------+
  |  180°  120°  60°   0°   60°  120°  180°   ← 顶部经度标注 |
  |90° ┌────────────────────────────────────────┐           |
  |60° │  ·D        ·E                          │  ← D、E点  |
  |30° │     ·A                                 │  ← A点     |
  | 0° │              ·C         [夜半球阴影区]  │  ← C点、赤道|
  |30° │              ·B                        │  ← B点     |
  |60° │                                        │           |
  |90° └────────────────────────────────────────┘           |
  |     ↑ 0°昏线18:00              ↑ 180°晨线6:00           |
  |                                                        |
  |        [◀ 上一步]    [下一步 ▶]    步骤 2/4             |
  +--------------------------------------------------------+
  画布 800×500，主图区 y=50~400，控件区 y=440~490
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `let currentStep = 0;` 记录当前步骤（0~3）。每步对应一组SVG元素的 `display` 属性（`block`/`none`）切换。
  2. 元素显隐：为每步需要显示的元素设置统一class（如 `scene4-step1`、`scene4-step2` 等），通过 `document.getElementsByClassName` 批量控制显隐。
  3. 夜半球填充：使用SVG `<pattern>` 定义45°斜线（patternUnits="userSpaceOnUse"，width="10" height="10"，patternTransform="rotate(45)"，内嵌1px蓝色半透明竖线），然后以该pattern填充 `<rect x="400" y="50" width="300" height="350"/>`。
  4. 按钮状态：步骤0时禁用「上一步」（opacity 0.4，pointer-events none），步骤3时禁用「下一步」。
  5. 动画曲线：无需复杂动画，步骤切换直接显隐（或可选0.3s CSS transition opacity变化）。
  6. 事件绑定：按钮绑定 `click` 事件，调用 `goToStep(step)` 函数更新状态。
- ID命名规范：所有SVG元素及控件ID必须以 `scene4-` 为前缀。例如：`scene4-grid-frame`、`scene4-equator`、`scene4-point-a`、`scene4-meridian-90w`、`scene4-night-fill`、`scene4-btn-prev`、`scene4-btn-next`、`scene4-step-indicator`。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免多场景合并时全局变量污染。
- 坐标计算：经线x坐标 = 100 + index*100（index=0~6）；纬线y坐标 = 50 + index*(350/6)（index=0~6，取整）。
