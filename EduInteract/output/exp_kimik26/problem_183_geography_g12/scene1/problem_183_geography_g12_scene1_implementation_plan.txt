  - 「下一步」按钮：位于(400,460)，宽80×高30，点击前进到下一步，步骤5时禁用（灰色）
  - 「重置」按钮：位于(500,460)，宽60×高30，点击立即回到步骤0
  - 步骤指示器：位于(400,448)，显示当前步骤名称，如「步骤 1/5：A点·夏至」
- 教师操作流程：
  1. 教师加载图示，首先呈现步骤0整体概览，让学生观察轨道、四点位置、地轴倾斜一致性
  2. 点击「下一步」进入步骤1，讲解A点夏至：引导学生观察北极倾向太阳、直射北回归线、北极极昼
  3. 继续点击「下一步」依次讲解春分、冬至、秋分，每步聚焦一个位置，其余位置淡化避免干扰
  4. 到达步骤5，展示回归运动全貌，总结直射点在南北回归线之间的周期性移动
  5. 可随时「上一步」回退复习，或「重置」从头开始

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：本场景以几何图形和状态切换为主，无复杂函数绘图或3D需求，原生SVG性能最佳且无需额外CDN依赖。
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  D标签(400,95)                                     |
  |      D地球(400,130)                                |
  |         /                                          |
  |  A地球(150,250) --- 太阳(400,250) --- C地球(650,250)|
  |  A标签(120,250)         |            C标签(680,250)|
  |                         |                          |
  |      B地球(400,370)     |  回归示意(步骤5,390,295) |
  |  B标签(370,395)         |                          |
  |                         |                          |
  |  [步骤指示器]  [上一步] [下一步] [重置]            |  y=440~490
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `currentStep`（0~5），`renderStep()` 函数根据当前步骤控制所有元素的 `display` 或 `opacity` 属性。
  2. 元素显隐策略：为每个步骤专属元素设置 `class="scene1-step1"`、`class="scene1-step2"` 等，通过 JS 批量切换 `visibility` 或 `opacity`（推荐opacity+transition实现300ms淡入淡出）。
  3. 高亮与淡化：当前步骤对应地球设置 `stroke=#2e7d32 stroke-width=3` 并显示淡绿背景圆；非当前步骤地球设置 `opacity=0.35`。
  4. 地轴箭头：高亮时在北极端附加一个小三角形（path），使用 `marker-end` 或独立path实现。
  5. 极昼/极夜扇形：使用SVG `path` 的 `A` 命令绘制，注意大弧标志为0，角度范围255°~315°。
  6. 动画曲线：所有透明度变化使用 CSS `transition: opacity 0.3s ease` 或 JS `requestAnimationFrame` 插值。
  7. 事件绑定：按钮使用 `onclick` 绑定 `prevStep()`、`nextStep()`、`resetStep()` 函数。
  8. 按钮状态：步骤0时禁用「上一步」（opacity 0.3，pointer-events none），步骤5时禁用「下一步」。
- ID命名规范：所有交互元素ID必须以 `scene1-` 为前缀。例如：
  - `scene1-sun`、`scene1-orbit`、`scene1-earth-a`、`scene1-axis-a`、`scene1-label-a`
  - `scene1-highlight-a`、`scene1-step1-summer`、`scene1-step1-arrow-pole`
  - `scene1-step1-direct-line`、`scene1-step1-direct-label`
  - `scene1-step5-return-line`、`scene1-step5-return-title`
  - `scene1-btn-prev`、`scene1-btn-next`、`scene1-btn-reset`、`scene1-step-text`
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })()` 中，避免全局变量污染，确保多场景合并时互不干扰。
- 坐标计算辅助：地轴倾斜15°的端点、赤道端点、扇形路径等可在JS中预计算，避免硬编码过多小数坐标，但SVG path中仍使用计算后的整数值。
