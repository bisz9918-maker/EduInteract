[分步序列]
状态机共6个状态（0~5），通过「上一步」「下一步」按钮切换。

- 步骤0（初始状态）：
  显示元素：椭圆轨道、太阳（含光芒）、四个地球（正常样式：白填充+蓝轮廓）、四条地轴（含北极点）、四条赤道、位置标签A/B/C/D、太阳标签"太阳"。
  隐藏元素：回归线、直射点、光线、节气标签、日期标签、纬度标签、公转方向箭头。
  教师操作：引导学生观察四位置地轴是否相互平行，倾斜方向是否一致。

- 步骤1（A位置·春分）：
  点击「下一步」进入。
  视觉变化：地球A高亮（填充变为rgba(46,125,50,0.15)，描边加粗至2px）；显示光线SA（虚线从太阳到A中心）；显示直射点A（红色小圆点）；显示节气标签"春分"、日期"3月21日"、纬度"0°"。
  教师讲解：A位置太阳直射赤道，节气为春分。

- 步骤2（B位置·夏至）：
  点击「下一步」进入。
  视觉变化：地球A恢复正常；地球B高亮；显示光线SB；显示直射点B；显示北回归线（B地球内虚线）；显示节气标签"夏至"、日期"6月22日"、纬度"23°26′N"。
  教师讲解：B位置北极朝向太阳，太阳直射北回归线，北半球夏至。

- 步骤3（C位置·秋分）：
  点击「下一步」进入。
  视觉变化：地球B恢复正常；地球C高亮；显示光线SC；显示直射点C；显示节气标签"秋分"、日期"9月23日"、纬度"0°"。
  教师讲解：C位置太阳再次直射赤道，节气为秋分。

- 步骤4（D位置·冬至）：
  点击「下一步」进入。
  视觉变化：地球C恢复正常；地球D高亮；显示光线SD；显示直射点D；显示南回归线（D地球内虚线）；显示节气标签"冬至"、日期"12月22日"、纬度"23°26′S"。
  教师讲解：D位置北极远离太阳，太阳直射南回归线，北半球冬至。

- 步骤5（公转方向总结）：
  点击「下一步」进入。
  视觉变化：地球D恢复正常；显示公转方向箭头（椭圆外侧逆时针绿色弧线箭头）及标签"公转方向"。
  教师讲解：地球公转方向为自西向东，从北极上空看呈逆时针；总结四位置顺序A→B→C→D对应春分→夏至→秋分→冬至的循环。

（教师可随时点击「上一步」回退到任意步骤复习。）

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「◀ 上一步」按钮：位于画布底部左侧（中心约x=310, y=465），宽100×高34。点击后状态减1，回退到上一步视觉状态；当state=0时禁用（置灰）。
  2. 「下一步 ▶」按钮：位于画布底部右侧（中心约x=440, y=465），宽100×高34。点击后状态加1，进入下一步视觉状态；当state=5时禁用（置灰）。
  3. 步骤指示器：位于画布底部居中（x=400, y=490），显示当前步骤文字如"步骤 1/5"。
- 教师操作流程：
  1. 加载后进入步骤0，教师先让学生观察全图，提问"四位置地轴是否平行？"
  2. 点击「下一步」进入步骤1，A地球高亮，教师讲解春分；依此类推直到步骤4。
  3. 步骤5显示公转方向箭头，教师总结循环规律。
  4. 讲解过程中可随时点击「上一步」回退，强化对比（如对比夏至与冬至的直射点差异）。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：本场景为静态几何图形与显隐/高亮切换，无需复杂数学计算或3D渲染，原生SVG性能最优且无需额外CDN依赖。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------------+
  |                    [标题区 y=0~40]                      |
  |                                                        |
  |    B(夏至)              A(春分)                        |
  |      ●                  ●                              |
  |       \                /                               |
  |        \    椭圆轨道   /                                |
  |         \            /                                 |
  |          \          /                                  |
  |           \        /                                   |
  |            \      /        太阳 ☉                      |
  |             \    /         [D冬至]                     |
  |              \  /                                      |
  |               ● C(秋分)                                |
  |                                                        |
  |    [公转方向箭头，步骤5显示]                            |
  |                                                        |
  +--------------------------------------------------------+
  |  [◀ 上一步]      步骤 X/5      [下一步 ▶]   y=430~490  |
  +--------------------------------------------------------+
  画布宽800px，主图区占y=40~420，控件区占y=430~490
  ```

- 关键实现要点：
  1. 状态机设计：使用变量 `let state = 0;` 表示当前步骤（0~5）。每次点击按钮时更新state，调用 `render()` 函数根据state设置各元素的显隐和样式。
  2. 元素显隐控制：所有步骤专属元素（直射点、光线、节气标签、回归线、公转箭头）初始 `display:none` 或 `opacity:0`。`render()` 中通过 `element.style.display = 'block'` 或 `element.classList.add('visible')` 控制。使用CSS transition实现淡入（opacity 0→1，duration 300ms）。
  3. 地球高亮切换：给四个地球<circle>设置class。高亮时添加class `highlighted`，CSS定义 `.highlighted { fill: rgba(46,125,50,0.15); stroke-width: 2px; stroke: #2e7d32; }`。使用CSS transition实现平滑过渡（transition: all 0.3s ease）。
  4. 光线动画：光线<line>使用CSS `stroke-dasharray: 5,5;` 配合 `@keyframes dash` 实现虚线流动效果，增强视觉引导。
  5. 按钮禁用逻辑：`render()` 中检查state值，state===0时禁用「上一步」，state===5时禁用「下一步」。禁用状态通过添加class `disabled` 改变背景色和cursor。
  6. 坐标计算：椭圆轨道、地球位置、地轴端点、赤道端点、回归线端点、直射点坐标均在计划中精确给出，代码中直接使用常量，无需运行时计算。
  7. 公转方向箭头：使用SVG <path> 绘制弧线，例如 `M 580,180 A 280,140 0 0,1 480,120`，并添加marker-end箭头。

- ID命名规范：所有交互元素ID必须以 `scene1-` 为前缀。
  - 地球：scene1-earth-a, scene1-earth-b, scene1-earth-c, scene1-earth-d
  - 直射点：scene1-spot-a, scene1-spot-b, scene1-spot-c, scene1-spot-d
  - 光线：scene1-ray-a, scene1-ray-b, scene1-ray-c, scene1-ray-d
  - 节气标签：scene1-label-spring, scene1-label-summer, scene1-label-autumn, scene1-label-winter
  - 日期标签：scene1-date-spring, scene1-date-summer, scene1-date-autumn, scene1-date-winter
  - 纬度标签：scene1-lat-a, scene1-lat-b, scene1-lat-c, scene1-lat-d
  - 回归线：scene1-tropic-n, scene1-tropic-s
  - 公转箭头：scene1-orbit-arrow, scene1-orbit-label
  - 按钮：scene1-btn-prev, scene1-btn-next
  - 步骤指示器：scene1-step-indicator
  - 获取元素时统一使用 `document.getElementById('scene1-xxx')`，禁止querySelectorAll配合全局class。

- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免多场景合并时变量污染全局作用域。
