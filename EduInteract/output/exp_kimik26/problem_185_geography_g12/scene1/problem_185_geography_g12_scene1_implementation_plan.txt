[图示主题与整合说明]
- 本图示主题：北极俯视图下晨昏线与30°N交点及太阳直射点综合推导
- 整合的步骤/概念：①题目原图还原（30°N纬线圈、四条主经线、A与B位置及15°偏角）；②A/B经度判读（120°E与30°W）；③晨昏线绘制与昼夜弧标注（昼弧210°、夜弧150°、昼长14h、夜长10h）；④70°N纬线圈与晨昏线相切关系及极昼区；⑤太阳直射点纬度（20°N）与经度（135°W）定位；⑥A点日出时间（5:00）的公式推导
- 教学价值：教师可按照"读图→定经度→画晨昏线→求直射点→算日出"的完整逻辑链逐步展开，随时回退重讲关键步骤，适合课堂板书式讲解

[分步序列]
- 初始状态（步骤0）：显示30°N纬线圈、四条主经线（45°E顶、45°W右、135°E左、135°W底）、圆心→A与圆心→B射线、A与B点、两个15°角标注、四条主经线标签、A/B标签。右侧无推导文字。教师可在此讲解原图结构。
- 步骤1（经度判读）：圆心→A、圆心→B射线加粗变为蓝色#1565c0；弹出经度标签"120°E"(115,225)、"30°W"(445,225)；右侧推导文字显示："经度判读："(520,120)、"A：135°E − 15° = 120°E"(520,150)、"B：45°W + 15° = 30°W"(520,180)。教师讲解经度推导。
- 步骤2（晨昏线与昼夜）：新增晨昏线AB（水平直线y=211）；A端左侧标"晨线"蓝(100,240)，B端右侧标"昏线"红(460,240)；新增地球自转逆时针箭头（圆弧R=165, 300°→340°, 蓝色）；昼弧扇形淡黄填充、夜弧扇形浅灰填充；标注"昼弧210°"(280,390)蓝色、"夜弧150°"(280,130)黑色；右侧推导文字："昼夜弧长："(520,120)、"昼弧 = 210°"(520,150)、"夜弧 = 150°"(520,180)、"昼长 = 210°÷15° = 14h"(520,210)、"夜长 = 150°÷15° = 10h"(520,240)。教师讲解晨昏线与昼夜弧。
- 步骤3（70°N切线）：新增70°N同心圆虚线（圆心280,250, R=50, 绿色）；极昼区（70°N圆内部）绿色半透明填充；切点T(280,200)绿色圆点，标签"T"(290,190)；新增20°N同心圆虚线（圆心280,250, R=175, 绿色）；右侧推导文字："晨昏线与70°N相切"(520,120)、"极昼区：70°N以北"(520,150)、"直射纬度 = 90°−70° = 20°N"(520,180)。教师讲解极昼与直射纬度。
- 步骤4（直射点定位）：直射点S(280,425)红色圆点，标签"S(20°N, 135°W)"(300,435)；直射经线135°W从圆心到S红色高亮2px；标注"12:00"(300,405)；右侧推导文字："直射点定位："(520,120)、"昼半球中央经线：135°W"(520,150)、"直射点 S(20°N, 135°W)"(520,180)、"A与135°W经度差 = 105°"(520,210)、"时间差 = 105°÷15° = 7h"(520,240)、"A在135°W西侧"(520,270)、"A的地方时 = 12:00 − 7h = 5:00"(520,300)。教师讲解直射点定位与时间差。
- 步骤5（日出时间）：右侧推导文字更新为："日出时间计算："(520,120)、"昼弧 = 210°"(520,150)、"昼长 = 210° ÷ 15°/h = 14h"(520,180)、"日出 = 12:00 − 昼长/2 = 12:00 − 7h"(520,210)、"日出 = 5:00"(520,240)；并在(520,280)以红色#c62828、18px、加粗显示最终结论"A点日出时间：5:00"。教师总结公式推导。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本场景以几何图形（圆、线段、扇形、路径）为主，无复杂函数图或3D，原生SVG足够且轻量，便于精确控制每个元素的显示/隐藏和坐标。
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  +--------------------------------------------------------+
  |                                                        |
  |           45°E                                         |
  |              |                                         |
  |         A----+----B         推导文字区                  |
  |        15°  |    15°       （x=520~780）                |
  |              |                                         |
  |    135°E  +  45°W                                      |
  |              |                                         |
  |           135°W                                        |
  |                                                        |
  |           [上一步]  步骤  [下一步]                      |
  +--------------------------------------------------------+
  ```
  （注：A、B在30°N圆周上，晨昏线AB为水平线；推导文字区在右侧空白处；控件栏在底部y=455~490）
- 关键实现要点：
  1. 状态机设计：用变量 `currentStep`（0~5）控制当前步骤。每步对应一个 `<g>` 组（如 `scene1-step-0-group` 到 `scene1-step-5-group`），组内包含该步应显示的所有元素。切换步骤时，通过设置对应组的 `display` 属性（或 `opacity` + CSS transition）实现出现/消失。
  2. 坐标计算：A、B坐标基于圆心(280,250)、R=150、角度165°/15°计算得出(135,211)/(425,211)。昼弧/夜弧扇形使用SVG `<path>` 的 `A` 命令绘制，注意 `large-arc-flag` 与 `sweep-flag` 的取值（昼弧A→B经下方为顺时针大弧，sweep=1, large=1；夜弧B→A经上方为逆时针小弧，sweep=0, large=0）。
  3. 动画曲线：元素出现使用CSS `transition: opacity 0.3s ease-in-out`，避免生硬跳变。射线高亮（步骤0→1）通过改变 `stroke` 和 `stroke-width` 实现。
  4. 事件绑定：「上一步」「下一步」按钮绑定 `click` 事件，更新 `currentStep` 后调用 `renderStep()` 函数，该函数遍历所有步骤组，仅显示当前步骤及之前步骤中应保留的元素（如步骤2仍需显示步骤0的基础图形）。为简化，采用"每步独立组叠加"策略：步骤n的组包含该步新增元素，基础元素放在 `scene1-base-group` 中始终显示。
  5. 按钮禁用逻辑：`currentStep === 0` 时禁用「上一步」；`currentStep === 5` 时禁用「下一步」。通过设置 `disabled` 属性并改变按钮透明度（opacity 0.4）提示。
- ID命名规范：所有交互元素ID必须以 `scene1-` 为前缀。例如：`scene1-svg-container`、`scene1-btn-prev`、`scene1-btn-next`、`scene1-step-indicator`、`scene1-base-group`、`scene1-step-1-group`、`scene1-ray-oa`、`scene1-ray-ob`、`scene1-dawn-line`、`scene1-arc-day`、`scene1-arc-night`、`scene1-circle-70n`、`scene1-circle-20n`、`scene1-point-a`、`scene1-point-b`、`scene1-point-t`、`scene1-point-s`、`scene1-arrow-rotation`、`scene1-text-120e`、`scene1-text-deduction` 等。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })()` 中，避免全局变量污染，确保多场景合并时互不干扰。
