[图示主题与整合说明]
- 本图示主题：以地方时正午为基准推算四地经度（北极俯视图 + 经度轴）
- 整合内容：①地方时12:00（太阳在正南方）的地理含义；②世界时与地方时的时差换算；③四地经度的逐步推算
- 教学价值：教师通过分步导航，带领学生从本初子午线基准出发，逐步理解"东加西减"原则，将抽象的时间差转化为直观的空间经度差，降低认知负荷

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  ① "上一步"按钮：位置(260,450)，大小90×32，点击后退一步，步骤0时禁用（灰色）
  ② 步骤指示器：位置(370,450)，大小120×32，显示当前步骤如"步骤 2/7"
  ③ "下一步"按钮：位置(510,450)，大小90×32，点击前进一步，步骤6时禁用（灰色）
- 教师操作流程：
  1. 教师点击"下一步"进入步骤0，讲解本初子午线作为经度基准和世界时（UTC）的关系，配合自转方向说明地球自西向东转。
  2. 进入步骤1，展示换算公式，强调"东加西减"核心原则。
  3. 进入步骤2，以A地（世界时4:00）为例，演示完整推算：时差+8h → 东经 → 120°E。此时北极俯视图中120°E经线出现，底部经度轴出现A标记。
  4. 依次进入步骤3、4、5，分别推算B(60°E)、C(0°)、D(180°)，每步只聚焦一个地点，避免信息过载。
  5. 进入步骤6汇总，四地经度同时呈现，教师可点击"上一步"回退到任意步骤复习。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript（无外部库）。理由：本场景以静态几何图形和状态切换为主，无需复杂动画或数据驱动绘图，原生SVG性能最优且零依赖。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------------+
  |  [标题：以地方时正午推算经度]                            |
  |                                                        |
  |   +------------------+    +-------------------------+  |
  |   |   北极俯视图      |    |    公式/计算区           |  |
  |   |  (圆心215,190)   |    |   经度差=时差×15°/h      |  |
  |   |   0°经线→        |    |   早于世界时→东经(+)     |  |
  |   |   120°E经线↙     |    |   ---------------------   |  |
  |   |   60°E经线↘      |    |   A地：时差+8h           |  |
  |   |   180°经线←      |    |   经度=120°E             |  |
  |   |   自转箭头↑      |    |                         |  |
  |   +------------------+    +-------------------------+  |
  |                                                        |
  |   经度轴：180°W---60°W---0°---60°E---120°E---180°      |
  |            A↑    B↑     C↑                    D↑       |
  |                                                        |
  |        [◀上一步]   步骤 2/7   [下一步▶]                |
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：定义变量 `let currentStep = -1;`（初始-1表示未开始，点击下一步进入步骤0）。总步骤数7步（0~6）。
  2. 元素分组：为每个步骤创建SVG `<g>` 组，如 `<g id="scene2-step0-group">`、`<g id="scene2-step2-only">` 等。使用CSS类 `.scene2-hidden { display: none; }` 控制显隐。
  3. 动态文本更新：右侧计算框内放置一个 `<text id="scene2-calc-content">` 元素，在updateScene()中根据currentStep更新其内容（使用tspan分行）。
  4. 高亮控制：对0°和180°经线，在步骤4/5时通过JS修改stroke颜色和stroke-width实现高亮；对汇总步骤，通过添加CSS类实现所有经线同时高亮。
  5. 扇形填充：使用SVG `<path>` 绘制扇形，初始opacity:0，步骤2/3时通过CSS transition过渡到opacity:0.1。
  6. 按钮状态：updateScene()中检查currentStep，若为0则禁用"上一步"（opacity:0.4, pointer-events:none），若为6则禁用"下一步"。
  7. 坐标计算：北极俯视图各经线端点使用三角函数计算（圆心+半径×cosθ, 圆心+半径×sinθ），其中0°=0rad, 60°E=π/3, 120°E=2π/3, 180°=π。
  8. 经度轴刻度：轴线从x=80到x=680共600px对应360°，每度5/3px。0°在x=380，60°E在x=480，120°E在x=580，180°在x=680。
- ID命名规范：所有交互元素ID必须以 `scene2-` 为前缀。例如：
  - SVG元素：`scene2-earth-circle`, `scene2-meridian-0`, `scene2-meridian-60e`, `scene2-meridian-120e`, `scene2-meridian-180`, `scene2-point-a`, `scene2-point-b`, `scene2-point-c`, `scene2-point-d`, `scene2-rotation-arrow`, `scene2-axis-line`, `scene2-axis-mark-a`, `scene2-formula-box`, `scene2-calc-content`, `scene2-fill-sector-a`, `scene2-fill-sector-b`
  - 按钮：`scene2-btn-prev`, `scene2-btn-next`, `scene2-step-indicator`
  - 步骤组：`scene2-step0-group`, `scene2-step1-group`, ..., `scene2-step6-group`
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免全局命名空间污染，确保多场景合并时互不干扰。
- 事件绑定：使用 `document.getElementById('scene2-btn-prev').addEventListener('click', ...)` 和 `document.getElementById('scene2-btn-next').addEventListener('click', ...)`。
