[图示主题与整合说明]
- 本图示主题：四地纬度推算、全球空间定位与区域地理特征（高中地理·地球运动）
- 整合的步骤/概念：①夏至日太阳直射点与全球光照；②正午太阳高度纬度计算公式推导；③利用热水器倾角与世界时推算四地经纬度；④世界地图空间定位；⑤夏至日北半球昼长纬度规律；⑥基于经纬度差的相对方位判断；⑦著名工业基地、渔场与洋流的区域地理标注
- 教学价值：教师通过分步导航，从天文计算（太阳高度→纬度）到时间计算（世界时→经度），再到地图定位与区域地理，完整呈现第(1)-(4)问的解题认知链。每步可独立讲解，也可快速跳转，适合课堂节奏控制。

[分步序列]
- 初始状态（步骤0）「直射点」：显示夏至日太阳直射北回归线的全球侧视光照图。地球倾斜侧视图（地轴、赤道、北回归线）、右侧太阳光线水平入射、晨昏线垂直于光线。右侧信息框列出夏至日全球特征（直射23°26′N、北半球昼最长、北极圈极昼）。底部控件栏显示「下一步」。
- 步骤1「公式推导」：切换为公式推导页。顶部大公式框显示 H = 90° − |φ − δ|；下方依次呈现条件（太阳在正南方→φ>δ）、简化式 H = 90° − (φ − δ)、推导式 φ = δ + (90° − H)、热水器倾角关系 α = 90° − H；底部绿色结论框高亮 φ = 23°26′N + α。
- 步骤2「纬度计算」：四列并排卡片。每列顶部为地点字母（A/B/C/D），下方绘制微型热水器倾角示意图（水平基座+倾斜板），再下方列出倾角数值、算式 23°26′N + α，最终结果（30°N/50°N/50°N/37°N）以绿色加粗高亮。B与C倾角相同，图示相同，强化记忆。
- 步骤3「坐标汇总」：中央表格呈现四地完整地理坐标。表头「地点|纬度|经度」，四行数据：A(30°N,120°E)、B(50°N,60°E)、C(50°N,0°)、D(37°N,180°)。经度由世界时与正午的时差推算得出（隐含在教学中）。
- 步骤4「地图定位」：下半部世界矩形简图（墨卡托示意），含简化大陆轮廓与经纬网（50°N、30°N、赤道；0°、60°E、120°E、180°）。四地以彩色圆点标注：A红（中国东部）、B绿（中亚）、C蓝（西欧/英国附近）、D红（北太平洋日界线附近）。字母标签向空白侧偏移避免压线。
- 步骤5「昼长排序」：水平条形图。标题说明「北半球纬度越高，昼越长」。以12h虚线为基准，向右绘制四条昼长条：B/C最长且等长（绿，约16h）、D次之（蓝，约14.5h）、A最短（红，约13.5h）。左侧地点标签，右侧数值标签。底部结论文字「B = C > D > A」。
- 步骤6「方向判断」：以A(30°N,120°E)为原点的平面直角坐标系（横轴东西、纵轴南北）。A点红圆在原点，D点红圆在右上方（经度差+60°→东，纬度差+7°→北）。粗红箭头从A指向D，旁注「东北方向」。底部说明框列出经度差与纬度差计算过程。
- 步骤7「地理事物」：复用步骤4世界地图。在A地附近红色标注「沪宁杭工业基地」；在C地附近蓝色标注「北海渔场」，并绘制蓝色箭头表示「北大西洋暖流」自西南向东北流经英国附近。底部文字说明英国温带海洋性气候深受北大西洋暖流影响。本步直接对应题目第(3)(4)问答案。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript。理由：本场景以几何图形、地图轮廓、文本标签和简单条形图为主，无复杂函数绘图或3D需求，原生SVG足以保证清晰度与性能，且便于通过g元素的display/opacity控制分步显隐。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图：
  ```
  +--------------------------------------------------+
  |  [步骤标题区]  y=10~60                           |
  |                                                  |
  |  [主内容区]  y=60~440                            |
  |  （步骤0:地球侧视图+信息框 / 步骤1:公式 /         |
  |   步骤2:四列卡片 / 步骤3:表格 / 步骤4/7:世界地图 / |
  |   步骤5:昼长条 / 步骤6:方向坐标系）               |
  |                                                  |
  |  [控件栏]  y=440~490                             |
  |       [◀ 上一步]  [步骤 X/8]  [下一步 ▶]         |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `let currentStep = 0;` 控制0~7共8个状态。每步对应一个 `<g id="scene3-step-N">` 容器，切换时通过设置 `display: none/block` 或 `opacity` + CSS transition 实现淡入淡出（建议200ms）。
  2. 地图绘制：世界简图使用 SVG `<path>` 绘制简化大陆轮廓（欧亚非、北美、南美、澳洲），无需精确国界，仅需 recognizable 的大陆形状。经纬网用 `<line>` 绘制虚线。
  3. 坐标映射：地图区域(120,60)-(680,340)对应经度60°W~180°、纬度0°~70°N。四地坐标按线性投影换算为SVG坐标（见坐标表）。
  4. 动画曲线：步骤切换使用 ease-in-out 过渡，opacity 0→1 耗时200ms，避免生硬跳转。
  5. 事件绑定：上一步/下一步按钮绑定 click 事件，更新 currentStep 后调用 `renderStep()` 函数，该函数负责隐藏所有 step 组、显示当前组、更新按钮禁用状态与步骤指示器文字。
  6. 按钮禁用逻辑：currentStep === 0 时禁用「上一步」；currentStep === 7 时「下一步」文字变为「完成」或禁用。
  7. 大陆轮廓路径（简化示意，代码 agent 可用以下近似坐标绘制 path）：
     - 欧亚非：从(220,340)向北到(220,130)，向东到(340,130)，向东北到(520,150)，向南到(560,220)，向西到(480,280)，向南到(420,340)，闭合。
     - 北美：从(120,260)向北到(160,120)，向东到(260,120)，向南到(280,200)，向西到(240,260)，闭合。
     - 南美：从(240,280)向南到(260,340)，向东到(300,340)，向北到(280,280)，闭合。
     - 澳洲：从(520,300)向东到(580,300)，向南到(580,340)，向西到(520,340)，闭合。
  8. 热水器倾角示意图：用一条水平线（基座）和一条倾斜线（集热板）表示，倾角通过斜率模拟（A约5px高差、B/C约21px、D约11px），非精确比例但直观可辨。
- ID 命名规范：所有交互元素与可视化元素 ID 必须以 `scene3-` 为前缀。
  - 按钮：`scene3-btn-prev`、`scene3-btn-next`
  - 指示器：`scene3-step-indicator`
  - 步骤组：`scene3-step-0` ~ `scene3-step-7`
  - 地图元素：`scene3-map-frame`、`scene3-map-land`、`scene3-marker-a` 等
  - 公式元素：`scene3-formula-box`、`scene3-formula-main` 等
  - JS 中严格使用 `document.getElementById('scene3-xxx')` 获取元素，禁止全局 class 选择器，避免多场景合并时污染。
- IIFE 隔离：所有 JavaScript 代码包裹在 `(function() { ... })();` 中，变量不泄露全局作用域。
