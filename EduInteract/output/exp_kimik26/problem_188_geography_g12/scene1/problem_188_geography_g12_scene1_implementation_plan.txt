[图示主题与整合说明]
- 本图示主题：太阳直射点回归运动轨迹与关键节点

[分步序列]
- 初始状态（步骤0）：显示三条纬线（北回归线、赤道、南回归线）及其右侧文字标签，建立空间坐标框架。隐藏轨迹、点、日期、节气、方向箭头。
- 步骤1：点击「下一步」→ 蓝色折线轨迹出现（①→②→③→④→①），四个红色关键点①②③④以高亮形式（r=9px，#000000描边1.5px）出现，对应点标签①②③④显示。教师可讲解回归运动的周期性路径。
- 步骤2：点击「下一步」→ 四个关键点恢复常规尺寸（r=6px）。各点日期标签出现：①"3月21日"、②"6月22日"、③"9月23日"、④"12月22日"。教师可讲解直射点到达各纬线的公历时间。
- 步骤3：点击「下一步」→ 各点节气标签出现：①"春分"、②"夏至"、③"秋分"、④"冬至"。教师可关联二十四节气与直射点位置。
- 步骤4（最终步骤）：点击「下一步」→ 四条轨迹线段上分别出现绿色方向箭头及文字：①→②"向北移动"、②→③"向南移动"、③→④"向南移动"、④→①"向北移动"。教师可总结直射点的周年移动规律。
- 教师可随时点击「上一步」回退至任意步骤复习。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于(280,455)，宽80高30，点击回退到上一分步，步骤0时禁用
  - 「下一步」按钮：位于(440,455)，宽80高30，点击前进到下一分步，步骤4时禁用
  - 步骤指示器：位于(400,485)，显示当前步骤编号（如"步骤 2/5"）
- 教师操作流程：教师根据课堂讲解节奏点击「下一步」逐步揭示轨迹→日期→节气→方向，每步可停留讲解；学生有疑问时可随时点击「上一步」回退复习已展示内容。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本场景为简单几何图形（线段、圆、折线、文字、箭头），无需复杂图表库，原生SVG即可精确控制每个元素的坐标与显隐，且性能最优。
- 画布尺寸：800 × 500 px（沿用规定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------------+
  |  6月22日   夏至                                        |
  |      ② ←北回归线(虚线)                                |
  |     / \                                                |
  |    /   \                                               |
  |3月21日  9月23日                                        |
  |春分    秋分                                            |
  |  ①-----③ ←赤道(实线)                                  |
  |   \     /                                              |
  |    \   /                                               |
  |     \ /                                                |
  |      ④ ←南回归线(虚线)                                |
  |   12月22日 冬至                                        |
  |                                                        |
  |  [上一步]  步骤 X/5  [下一步]                          |  y=440~490 控件区
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  - 状态机设计：变量 `currentStep`（0~4），每步对应一个显隐配置数组，记录各元素组的显示状态。
  - 元素分组：将视觉元素按步骤分为5组——group-step0（纬线+标签）、group-step1（轨迹+点+点标签）、group-step2（日期标签）、group-step3（节气标签）、group-step4（方向箭头+方向文字）。通过切换各组的 `display` 或 `visibility` 属性实现分步。
  - 高亮动画：步骤1中四个点使用 r=9 + stroke-width=1.5 的高亮样式；进入步骤2时通过JS将属性恢复为 r=6 + 无描边，无需CSS过渡。
  - 箭头绘制：使用SVG `<marker>` 定义绿色箭头头部，在四条线段上通过 `marker-mid` 或单独 `<line>` + `<polygon>` 实现方向指示。
  - 事件绑定：上一步/下一步按钮绑定 `click` 事件，更新 `currentStep` 后调用 `renderStep()` 重绘界面。
  - 按钮状态：步骤0禁用「上一步」，步骤4禁用「下一步」，通过设置 `disabled` 属性实现。
- **ID 命名规范**：所有交互元素 ID 必须以 `scene1-` 为前缀。例如：`scene1-line-tropic-north`、`scene1-line-equator`、`scene1-line-tropic-south`、`scene1-path-orbit`、`scene1-point-1`、`scene1-point-2`、`scene1-point-3`、`scene1-point-4`、`scene1-label-point-1`、`scene1-label-date-1`、`scene1-label-solar-term-1`、`scene1-arrow-segment-1`、`scene1-text-direction-1`、`scene1-btn-prev`、`scene1-btn-next`、`scene1-step-indicator`。
- IIFE 隔离：所有 JavaScript 代码包裹在 `(function() { ... })()` 中，避免多场景合并时的全局变量污染。
