[图示主题与整合说明]
- 本图示主题：关键节气太阳直射位置对应的全球地理意义（地球侧视光照图）
- 整合内容：基于题目中的太阳直射点回归运动示意图（四点①②③④），将夏至（②）、春秋分（①③）、冬至（④）三个关键状态转化为地球侧视光照图，展示各状态下的太阳直射点位置、晨昏线走向、极昼极夜范围、昼夜半球分布及正午太阳高度规律。
- 教学价值：教师可通过底部三状态按钮快速切换夏至/春秋分/冬至，进行横向对比讲解，突出昼夜长短和极昼极夜的极端差异，帮助学生建立"太阳直射点位置—晨昏线—全球昼夜分布"的综合思维链条。

[分步序列]

- 初始状态（状态A / 夏至 / ②）：
  * 显示地球、地轴、5条太阳光线（左侧水平入射）

  * 太阳直射点在北回归线左端点(205,138)，红色圆点

  * 南极圈以南填充极夜范围（红色25%透明）

[交互方案]
- 交互类型：多状态切换（3个状态按钮）
- 控件说明：
  * 「夏至 ②」按钮：位置(260,460)，大小100×30。切换至夏至状态，太阳直射北回归线，北极圈极昼，南极圈极夜。
  * 「春秋分 ①③」按钮：位置(370,460)，大小100×30。切换至春秋分状态，太阳直射赤道，全球昼夜平分，无极昼极夜。
  * 「冬至 ④」按钮：位置(480,460)，大小100×30。切换至冬至状态，太阳直射南回归线，南极圈极昼，北极圈极夜。
- 教师操作流程：
  1. 初始加载显示夏至状态，教师可先讲解夏至的极昼现象与北回归线直射。
  2. 点击「春秋分」按钮，观察晨昏线变为竖直、直射点移至赤道、极昼极夜消失，讲解全球昼夜平分。
  3. 点击「冬至」按钮，观察直射点移至南回归线、晨昏线反向倾斜、极昼极夜半球互换，讲解南北半球季节相反。
  4. 可反复切换三个状态，让学生对比晨昏线角度、直射点位置、极昼极夜范围的变化规律。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript（无需外部库）。原因：本场景以几何图形、路径填充、简单属性动画为主，原生SVG SMIL或JS操作DOM属性即可满足，无需引入D3/Three.js等重型库。
- 画布尺寸：800×500 px（SVG viewBox="0 0 800 500"）
- 布局草图（ASCII）：
  ```
  0    100  200  300  400  500  600  700  800
  +----+----+----+----+----+----+----+----+
  | 标题/标签区（北极、昼半球等）          |  右侧信息面板
  |    [太阳光线]  ← ← ← ←               |  ┌────────────┐
  |         \                            |  │ 状态标题   │ y=70
  |    北极● \  北回归线                 |  │ 直射点...  │ y=115
  |         \ \                          |  │ 昼夜长短...│ y=155
  |  直射点●  \  地球圆                  |  │ 极昼...    │ y=195
  |         / \  晨昏线                  |  │ 极夜...    │ y=235
  |  赤道──/   \                         |  │ 正午太阳...│ y=285
  |       /     \  南回归线              |  │ 图例...    │ y=340~
  |  南极●       \                       |  └────────────┘
  |    [夜半球]   \                      |
  |              极夜范围                |
  +----+----+----+----+----+----+----+----+
       [夏至②] [春秋分①③] [冬至④]      ← 控件栏 y=460
  ```
- 关键实现要点：
  1. 状态机设计：定义state对象{current: 'summer'|'equinox'|'winter'}，点击按钮时调用switchTo(stateName)。
  2. 动画实现：使用requestAnimationFrame对以下属性做插值动画（时长400ms，ease-out）：
     - 太阳直射点cx/cy：从当前值线性插值到目标值。
     - 晨昏线：通过旋转其<g>容器实现角度变化（初始角度-23.5°→0°→+23.5°，以地心为旋转中心）。或更简单地，直接计算两端点新坐标并插值x1/y1/x2/y2。
     - 极昼/极夜path：预定义三组path d属性，切换时通过JS更换d属性并配合opacity过渡（200ms淡入淡出）。
     - 夜半球path：同样预定义三组d属性，切换时更换。
     - 右侧文字：直接替换textContent，无需动画。
  3. 晨昏线与地球圆交点计算函数：给定角度theta（从x轴正方向逆时针），交点为(300+140*cos(theta), 240+140*sin(theta))及其对径点。夏至theta=156.5°（或-23.5°+180°），春秋分theta=180°（竖直上），冬至theta=23.5°。
  4. 夜半球path公式：M 300 240 L x1 y1 A 140 140 0 1 1 x2 y2 Z，其中(x1,y1)和(x2,y2)为晨昏线两端点，large-arc-flag=1确保取右侧大弧。
  5. 极昼/极夜path（以夏至极昼为例）：M 300 100 A 140 140 0 0 1 402 145 L 355 112 Z。这里使用地球轮廓小弧（从北极圈端点300,100到402,145经过北极点附近，sweep-flag=1，large-arc-flag=0）。
  6. 事件绑定：按钮绑定click事件，切换状态前检查current是否相同，避免重复动画。
  7. 响应式：SVG设置width:100%, max-width:800px, height:auto，保持比例。
- ID命名规范：所有SVG元素及按钮ID必须以scene2-为前缀。例如：
  - scene2-earth-circle
  - scene2-axis-line
  - scene2-sunray-1 ~ scene2-sunray-5
  - scene2-terminator-line
  - scene2-sunspot
  - scene2-night-hemisphere
