    读太阳直射点移动轨迹图（太阳直射点移动方向为：F→E→D→C→B→A），分析回答下列问题。

    (4) 当地球位于公转轨道远日点附近时，太阳直射点处于图中________点和________点（填字母）之间。

    **教学说明：正午太阳高度角纬度分布规律**

    本图示用于讲解第(2)题，也可辅助学生理解正午太阳高度角（h）的纬度分布本质。

    核心公式（教师可在讲解时板书）：
    $$ h = 90° - |\varphi - \delta| $$
    其中 $\varphi$ 为当地纬度，$\delta$ 为太阳直射点纬度。

    讲解要点：
    1. **夏至日（C、D点）**：$\delta = 23°26′N$。北回归线上 $h = 90°$，向南北两侧对称递减。北极圈及其以北 $h \geq 0°$（极昼区），南极圈及其以南出现极夜。
    2. **冬至日（A、F点）**：$\delta = 23°26′S$。南回归线上 $h = 90°$，向南北两侧对称递减。
    3. **春秋分（B、E点）**：$\delta = 0°$（赤道）。赤道上 $h = 90°$，向南北两极对称递减至0°。

    引导学生观察：
    - 三条曲线的共同特征——直射点所在纬度 $h = 90°$，向两侧递减。
    - 第(2)题答案："由北回归线向南北两侧递减"（夏至日规律）。

    **教学说明：东西半球、晨昏线与经度时间计算**

    本图示用于讲解第(5)题，是整道题的难点，涉及空间想象与定量计算。

    **关键前提**：
    - 东西半球分界线：20°W 和 160°E。
    - 东半球范围：20°W → 0° → 160°E。
    - 西半球范围：160°E → 180° → 20°W。
    - 原题双半球图的经线按30°间隔绘制，因此可判定：B点位于东半球第3条内部经线，经度为 **70°E**；E点位于西半球第3条内部经线，经度为 **110°W**。两经线相差180°，互为对跖经线。

    **东半球全部黑夜的推导**：
    1. 东半球全部处于黑夜，意味着整个东半球（20°W—160°E）都位于夜半球。
    2. 因此，晨昏线必须与东西半球分界线重合：20°W为昏线（日落，地方时18:00），160°E为晨线（日出，地方时6:00）。
    3. 夜半球的中央经线为70°E（地方时0:00）。
    4. 太阳直射点（地方时12:00）应在70°E的对跖经线 **110°W** 上，即图中的 **E点**。
    5. 此时晨昏线与经线重合，说明太阳直射赤道，对应春分或秋分日。题目给定日期为3月22日，与春分（3月21日前后）吻合。

    **北京时间计算**：
    - 太阳直射E点：110°W地方时为3月21日12:00。
    - 北京时间为120°E的地方时。
    - 经度差：120°E 与 110°W 相差 $120° + 110° = 230°$。
    - 时间差：$230° \times 4\text{分钟/°} = 920\text{分钟} = 15\text{小时}20\text{分钟}$。
    - 120°E在110°W的东侧，时间更早：$12:00 + 15\text{小时}20\text{分钟} = 27:20$，即 **3月22日3时20分**。

    引导学生先建立"东半球全黑夜→晨昏线与分界线重合→直射点在对面半球中央"的空间逻辑，再进行定量计算。
    </TEXT_3>

    **总结：完整解答与课堂讲解建议**

    **完整答案**：
    1. (1) 冬至；北极圈及其以北地区（或 66°34′N 及其以北地区）
    2. (2) 由北回归线向南北两侧递减
    3. (3) A；E（以1月冬季考试为例）或 E；D（以6月夏季考试为例）
    4. (4) C；B
    5. (5) 70°E；E；3；20

    **课堂讲解建议**：
    1. **先整体后局部**：先用图示1带学生走一遍 F→E→D→C→B→A 的完整轨迹，建立"时间—节气—纬度"三维对应关系。
    2. **强调双半球图的经度判读**：很多学生会忽略图中经线的等间距分布，要引导他们数格子推出B=70°E、E=110°W，这是突破第(5)题的关键。
    3. **对比讲解极昼极夜与正午太阳高度角**：用图示1的极昼极夜填充和图示2的曲线做联动对比，让学生理解"夏至日北回归线h=90°"与"北极圈极昼"是同一时刻的两个表现。
    4. **空间想象突破**：第(5)题的"东半球全黑夜"是空间难点，建议教师在图示3的步骤2暂停，让学生先自己画晨昏线位置，再揭示答案。
    5. **时间计算易错点**：提醒学生120°E与110°W的经度差是230°（不是10°），且东侧经线时间更早，注意日期进位到3月22日。
