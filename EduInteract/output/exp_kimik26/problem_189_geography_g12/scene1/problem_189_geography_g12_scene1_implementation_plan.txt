[视觉元素清单]
- 左/右半球轮廓：圆形（正射投影示意），线宽1.5px，#000000
- 经线：7条/半球，中央为直线，其余为二次贝塞尔曲线汇聚于两极，线宽1px，#000000
- 纬线：北极圈/北回归线/赤道/南回归线/南极圈，赤道实线1.5px，其余虚线1px，#000000
- 轨迹折线：A(112,291)-B(230,235)-C(348,179)-D(452,179)-E(570,235)-F(688,291)，线宽2px，#000000
- 移动方向箭头：5段轨迹中点处的小三角箭头，指向F→E→D→C→B→A方向，#000000
- A-F圆点标记：半径6px，#000000填充，默认无描边
- 极昼/极夜填充：弓形SVG path，北极圈（y=107）以北的圆内区域，透明度20%
- 高亮轨迹：覆盖在原轨迹上的粗线（4px），对应情境区段
- 固定标签：N/S、东半球/西半球、A-F点名字母、纬度标注、经度标注、方向总标注
- 动态信息标签：各步骤弹出的节气/日期/纬度说明文字
- 配色规则：
  - 背景 #ffffff
  - 主线 #000000
  - 蓝高亮 #1565c0（春分/秋分节点B/E、考试期间高亮区段）
  - 红高亮 #c62828（冬至节点A/F、极夜填充）
  - 绿高亮 #2e7d32（夏至节点C/D、极昼填充）
  - 辅助线 #888888 虚线
  - 极昼填充 #2e7d32 opacity 0.2
  - 极夜填充 #c62828 opacity 0.2

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：本场景以几何图形（圆、贝塞尔曲线、折线、弓形填充）为主，无复杂函数图或3D，原生SVG足以精确控制每个元素的坐标、描边、填充和显隐，且无需引入外部库，加载轻量。
- 画布尺寸：800 × 500 px（固定）
- 布局草图：

- 关键实现要点：
  1. 状态机设计：维护两个变量 `currentStep`（0~7）和 `examMode`（'jan'|'jun'）。`updateView()`函数根据状态统一控制所有SVG元素的显隐（通过设置class或style.display）。
  2. 经线绘制：使用SVG `<path>` 的二次贝塞尔曲线（Q命令），确保所有经线汇聚于两极。左半球中央经线为直线，其余6条为曲线；右半球同理。
  3. 弓形填充（极昼/极夜）：使用SVG `<path>` 绘制。以左半球北极圈极夜为例：计算圆(230,235,140)与水平线y=107的交点（约173和287），path为 `M 173,107 L 287,107 A 140,140 0 0,1 173,107 Z`（小弧在上）。右半球同理。
  4. 轨迹高亮：步骤6/7使用单独的`<polyline>`或`<path>`元素，设置较粗线宽（4px）和对应颜色，默认隐藏，通过JS控制显隐。
  5. 动画曲线：不使用CSS动画，直接切换显隐（或0.2s的opacity过渡），保证教师控制精确、无等待。
  6. 事件绑定：上一步/下一步按钮绑定click事件修改currentStep并调用updateView()；1月/6月按钮修改examMode并调用updateView()。
- ID命名规范：所有SVG元素和控件ID必须以 `scene1-` 为前缀。例如：`scene1-hemi-left`、`scene1-point-a`、`scene1-btn-prev`、`scene1-label-tropic-n`、`scene1-fill-polarnight-left`、`scene1-track-highlight`。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })()` 中，避免全局变量污染，确保多场景合并时互不干扰。
