[图示主题与整合说明]
- 本图示主题：东西半球晨昏线关系与经度、地方时计算
- 整合的步骤/概念：
  1) 春秋分侧视光照图基础（晨昏线与经线重合、太阳光线水平入射）；
  2) 东西半球分界线（20°W / 160°E）在光照图中的空间定位；
  3) "东半球全黑夜"特殊状态的半球填充与晨昏线标注；
  4) 夜半球中央经线（70°E = 0:00）与太阳直射点对跖经线（110°W = 12:00）的推导；
  5) B点（70°E）与E点（110°W）对跖关系（经度相差180°）；
  6) 北京时间（120°E）由太阳直射点地方时推算的完整流程。
- 教学价值：教师通过分步导航，可逐层揭开"东半球全黑夜→太阳直射点在西半球中央→对跖经线相差180°→北京时间计算"的完整逻辑链，避免信息过载，方便回退复习。

[分步序列]
- 步骤0（初始状态）：展示标准春秋分侧视光照图基础元素。
  显示：地球圆、地轴（N/S标签）、赤道（标签）、北回归线、南回归线、太阳光线（5条箭头+标签）。
  隐藏：所有经线标注、东西半球文字、夜半球填充、晨昏线标注、太阳标记、B/E标记、对跖连线、时间面板。
  教学意图：建立"春秋分、太阳光线水平入射、地轴直立"的基础认知。

- 步骤1（下一步）：叠加东西半球分界线与关键经线。
  新增显示：0°经线(x=120)、70°E经线(蓝粗线,x=280)、120°E经线(x=410)；20°W标注(圆左边缘)、160°E标注(圆右边缘上方)；圆下方"东半球"(蓝)、"西半球（背面）"(绿)文字。
  教学意图：让学生明确东半球范围20°W→160°E，B点位于东半球中央经线70°E。

- 步骤2（下一步）：切换为"东半球全黑夜"状态。
  变化：地球圆整体填充蓝色透明（夜半球）；20°W标注替换为"昏线 18:00"（左侧）；160°E标注替换为"晨线 6:00"（右侧偏下）；晨昏线概念通过东西半球边界经线呈现。
  教学意图：建立"东半球全黑夜 = 晨昏线与东西半球分界线重合"的关键空间关系。

- 步骤3（下一步）：标注夜半球中央经线与太阳直射点。
  新增显示：70°E经线旁标注"午夜 0:00"（圆内右上）；地球右侧外部太阳标记(540,220)；太阳标记上方标注"110°W"和"太阳直射 12:00"；太阳标记下方标注"E点"；从圆右边缘(450,220)到太阳标记的灰色引导虚线。
  教学意图：推导夜半球中央经线70°E为0:00，其对跖经线110°W为太阳直射点（12:00），对应图中E点。

- 步骤4（下一步）：标注B/E对跖关系。
  新增显示：圆心(280,220)蓝色B点标记，下方标注"B点 70°E"；太阳标记中心红色E点标记；B-E水平虚线连接；连线上方标注"对跖经线 相差180°"。
  教学意图：直观展示B(70°E)与E(110°W)经度和为180°，互为对跖点。

- 步骤5（下一步）：展开右侧时间计算面板。
  新增显示：右侧时间计算面板(550,80)-(780,400)，内含7步计算流程：
    ① E点：110°W（太阳直射）
    ② 直射点地方时：12:00
    ③ 北京经度：120°E
    ④ 经度差 = 230°
    ⑤ 时差 = 15小时20分钟
    ⑥ 120°E在东侧，时间更早
    ⑦ 12:00 + 15h20m = 3月22日 3:20（红色高亮）
  教学意图：将空间推导转化为完整的时间计算流程，得出最终答案。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「◀ 上一步」按钮：位于底部(280,454)宽80高28，点击回退到上一状态，步骤0时禁用。
  2. 「下一步 ▶」按钮：位于底部(440,454)宽80高28，点击推进到下一状态，步骤5时禁用。
  3. 步骤指示器：位于底部(400,473)，显示当前步骤编号"步骤 X/6"。
- 教师操作流程：
  1. 教师点击「下一步」进入步骤1，讲解东西半球分界线与B点经度；
  2. 继续点击「下一步」进入步骤2，讲解"东半球全黑夜"时晨昏线与东西半球分界线重合；
  3. 进入步骤3，引导学生推导夜半球中央经线70°E为0:00，其对跖经线110°W为太阳直射点12:00；
  4. 进入步骤4，强调B(70°E)与E(110°W)对跖关系；
  5. 进入步骤5，展示完整时间计算流程，得出北京时间3:20；
  6. 可随时点击「上一步」回退，复习任意环节。

[技术实现]
- JS库选择：原生 SVG + 原生 JavaScript。原因：本场景以几何图形、线段、标注和简单填充为主，无需复杂数据绑定或3D渲染，原生SVG性能最佳且可控性最强。
- 画布尺寸：800 × 500 px（SVG viewBox="0 0 800 500"）。
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------------+
  |  N                                                       |
  |   +-------------------+         +--------------------+   |
  |   |    地球圆         |         | 时间计算面板       |   |
  |   |  (280,220) R=170  |         | (步骤5展开)        |   |
  |   |                   |         |                    |   |
  |   |   太阳光线 →→→    |         | ① E点:110°W       |   |
  |   |                   |         | ② 直射点:12:00     |   |
  |   |   夜半球填充      |         | ...                |   |
  |   |   B点 ●           |         | ⑦ = 3月22日 3:20  |   |
  |   +-------------------+         +--------------------+   |
  |  S                                                       |
  |              [◀ 上一步]  步骤 X/6  [下一步 ▶]            |
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：定义常量 STEP_MAX=5，变量 currentStep 初始为0。每一步对应一个显示配置数组 stepVisibility[6]，数组内记录该步骤应显示的元素ID列表。切换步骤时，先隐藏所有动态元素，再显示当前步骤对应的元素。
  2. 元素分层：静态基础元素（地球圆、地轴、N/S、赤道、回归线、太阳光线）在所有步骤均显示；动态元素（经线、标注、填充、标记、面板）按步骤显隐。
  3. 坐标计算：地球圆内垂直经线的y截断使用公式 y = 220 ± √(170² − (x−280)²)。已预计算：x=120→y∈[163,277]；x=410→y∈[111,330]；x=280→y∈[50,390]。
  4. 动画曲线：本场景为静态分步切换，无需CSS动画或JS插值。步骤切换直接改变 display 属性，确保教师控制节奏。
  5. 事件绑定：上一步/下一步按钮绑定 click 事件，调用 setStep(currentStep ± 1)。按钮在边界步骤禁用（disabled 属性 + 透明度0.4）。
  6. 时间计算面板：步骤5时显示 SVG <g id="scene3-time-panel">，内含 <rect> 背景和多行 <text>。面板位置固定，不随步骤动画。
  7. 颜色管理：严格使用 spec 指定色值：背景#ffffff、主线#000000、蓝高亮#1565c0、红高亮#c62828、绿高亮#2e7d32、辅助线#888888、太阳光线#f9a825、夜半球填充#1565c0@15%。
- ID命名规范：所有交互与可显隐元素ID必须以 `scene3-` 为前缀。例如：
  - 地球圆：scene3-earth
  - 地轴：scene3-axis
  - 70°E经线：scene3-meridian-70e
  - 夜半球填充：scene3-night-fill
  - B点标记：scene3-point-b
  - E点标记：scene3-point-e
  - 时间面板：scene3-time-panel
  - 上一步按钮：scene3-btn-prev
  - 下一步按钮：scene3-btn-next
  - 步骤文本：scene3-step-label
  JS中严格使用 document.getElementById 获取元素，禁止 querySelectorAll 配合全局 class，避免多场景合并时跨场景污染。
- IIFE隔离：所有 JavaScript 代码包裹在 (function() { ... })() 中，不暴露全局变量（除必要的DOM事件监听外）。
