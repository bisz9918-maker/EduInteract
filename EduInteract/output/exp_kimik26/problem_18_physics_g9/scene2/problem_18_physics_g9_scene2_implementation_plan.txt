[图示主题与整合说明]
- 本图示主题：定量计算与四个选项正误验证（物理九年级·浮力与平衡）
- 整合的步骤/概念：重力计算（G=mg）→ 弹簧测力计示数确认 → 浮力计算（F_浮=G_A−T）→ 排开体积计算（V_排=F_浮/(ρ_水·g)）→ 选项A/B/C/D逐一正误判断 → 结论汇总
- 教学价值：教师可通过分步按钮严格跟随"先算基本量→再代入选项验证"的逻辑链，每一步的数值来源与公式推导均以卡片+箭头流程可视化呈现；选项区四张卡片始终可见，便于学生随时对照题干，最终汇总步骤强化"仅A正确"的结论。

[分步序列]
- 初始状态（步骤0）：显示已知条件板（大卡片居中，列明m_A、m_B、ρ_水、g及静止状态）；下方四张选项卡片仅显示标题与选项原文，无判断图标，边框均为1px黑色；控件栏显示"上一步"（禁用态/灰色）、"步骤 1 / 6"、"下一步"。
- 步骤1：点击「下一步」→ 已知条件板淡出；上方出现左右两张流程卡片，左卡计算G_B=19.6N，箭头指向右卡"T=G_B=19.6N"；下方选项A卡片边框变绿（2px #1565c0），背景淡蓝，内部出现绿色对勾图标；底部出现绿色结论"✓ 选项A正确"。
- 步骤2：点击「下一步」→ 步骤1流程淡出；上方出现左中右三张流程卡片，分别计算G_A=29.4N、F_浮=9.8N、V_排=1000cm³，箭头串联；下方选项B卡片内出现红色叉号；底部出现对比文字"选项B：500 cm³"（红色删除线）与"实际：1000 cm³"（绿色），以及红色结论"✗ 选项B错误"。
- 步骤3：点击「下一步」→ 步骤2流程淡出；上方左侧显示"物体A静止"，箭头指向右侧"处于平衡状态"（绿色）；下方选项C卡片内出现红色叉号；底部出现红色"选项C：非平衡状态"与红色结论"✗ 选项C错误"。
- 步骤4：点击「下一步」→ 步骤3流程淡出；上方左侧为B物体受G_B示意图，中间列明"平衡力条件：同体、等大、反向、共线"，右侧为绳子受F_拉示意图；下方选项D卡片内出现红色叉号；底部出现红色结论"✗ 选项D错误（作用对象不同）"。
- 步骤5（最终）：点击「下一步」→ 上方显示大标题"结论汇总"与"正确答案：A"（36px绿色）；四张选项卡片保持最终状态（A绿勾，B/C/D红叉）；教师可点击「上一步」回退至任意步骤重新讲解。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「上一步」按钮：位置(260,448)，宽120×高36；点击回退到上一状态，步骤0时禁用（opacity 0.4，pointer-events none）。
  2. 「下一步」按钮：位置(420,448)，宽120×高36；点击前进到下一状态，步骤5时禁用。
  3. 步骤指示器：位置(400,492)，文字如"步骤 1 / 6"，仅显示，不可点击。
- 教师操作流程：
  1. 教师打开图示，先展示步骤0的已知条件，让学生朗读并确认已知量。
  2. 点击「下一步」进入步骤1，讲解G_B的计算过程，确认弹簧测力计示数，观察选项A变绿。
  3. 继续点击「下一步」依次验证B、C、D，每步停留讲解对应公式与判断依据；若学生某步未理解，点击「上一步」回退重讲。
  4. 到达步骤5后，整体回顾，强调仅A正确。

[技术实现]
- JS库选择：原生SVG（所有元素为几何图形、文本、箭头与简单示意图，无需复杂图表库；SVG的g分组天然适合按步骤显隐）。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图：
  ```
  +--------------------------------------------------+
  |  计算推导流程区 (y=20~210)                        |
  |  [步骤0:已知条件板] 或 [步骤1~4:公式卡片+箭头]    |
  |                                                  |
  +--------------------------------------------------+
  |  选项判断区 (y=230~435)                           |
  |  [A卡]   [B卡]   [C卡]   [D卡]                   |
  |  180w    180w    180w    180w                    |
  +--------------------------------------------------+
  |  控件栏 (y=440~490)                               |
  |      [上一步]   步骤 X/6   [下一步]               |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：变量currentStep∈[0,5]，每次点击按钮先执行exit动画（当前步骤组opacity→0，200ms），再执行enter动画（下一步组opacity→1，200ms），使用setTimeout衔接。
  2. 选项卡片状态：四张卡片始终存在于DOM，通过JS动态修改class。例如步骤1时给cardA添加class"scene2-card-correct"（绿边框+淡蓝背景），并在iconA组内绘制对勾path；步骤2时给cardB添加class"scene2-card-wrong"并在iconB组内绘制叉号path。
  3. 公式推导区：每一步对应一个SVG <g id="scene2-step{k}-group">，初始display:none；切换步骤时仅显示目标组。
  4. 删除线动画：步骤2的"500 cm³"删除线使用SVG line，初始stroke-dasharray=0，进入步骤2时通过CSS transition将stroke-dasharray设为实际长度，实现划线动画。
  5. 箭头绘制：使用SVG <marker>定义箭头头部，path不填充仅描边，确保缩放清晰。
  6. 按钮禁用态：步骤0时prev按钮置disabled并加class"scene2-btn-disabled"；步骤5时next按钮同理。
- ID命名规范：所有交互元素ID必须以"scene2-"为前缀。例如：
  - SVG容器：scene2-svg
  - 步骤组：scene2-step0-group ~ scene2-step5-group
  - 选项卡片：scene2-card-a、scene2-card-b、scene2-card-c、scene2-card-d
  - 判断图标：scene2-icon-a、scene2-icon-b、scene2-icon-c、scene2-icon-d
  - 按钮：scene2-btn-prev、scene2-btn-next
  - 指示器：scene2-step-indicator
  - 流程卡片：scene2-flow-card-s1-left、scene2-flow-card-s2-left等
- IIFE隔离：所有JS逻辑包裹在 (function() { ... })() 中，避免多场景合并时变量污染。
