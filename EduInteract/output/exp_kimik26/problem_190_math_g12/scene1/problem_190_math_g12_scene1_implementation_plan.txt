[分步序列]
- 步骤0（初始状态）：显示四棱锥P-ABCD全部棱线（PA/PB/PC实线、PD/AD虚线、AB/BC/CD实线），5个顶点标签P/A/B/C/D按坐标表位置显示，无高亮无额外标注，等待教师开始讲解
- 步骤1：点击「下一步」→ 底面四边形ABCD四边线条加粗至2px并变色为#1565c0；在底面中下方(300,430)显示标注"AB与DC不平行"；教师讲解底面已知条件
- 步骤2：点击「下一步」→ 保持底面高亮；从E(50,200)到A(215,295)绘制灰色虚线延长线，从E(50,200)到D(262,248)绘制灰色虚线延长线；在(50,200)显示绿色圆点E及标签；在(80,250)显示标注"E为AB、DC延长线交点"；教师定位辅助交点

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：本场景为简单几何图形与分步显隐，无需复杂图表库，原生SVG可精确控制每条棱、每个标签的坐标和样式，且便于分步控制显隐
- 画布尺寸：800×500px（SVG viewBox="0 0 800 500"）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  P(400,80)                                       |
  |   /|\                                             |
  |  / | \                                            |
  | /  |  \                                           |
  |A   |   C(580,320)        [右侧标注区]            |
  | \  |  /            E∈... / DC∩... / ∴...         |
  |  \ | /                                            |
  |   \|/                                             |
  |    B(380,390)                                     |
  |         D(262,248)                                |
  |  E(50,200)                                        |
  |                                                   |
  |  [底面标注：AB与DC不平行]                         |
  |                                                   |
  |              [◀上一步]  步骤X/4  [下一步▶]       |
  +--------------------------------------------------+
  控件栏区域：y=440~490
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `currentStep`（0~4），每次点击按钮时更新状态并调用 `renderStep()` 函数，该函数根据 currentStep 值设置各SVG元素的 `display` 或 `visibility` 属性
  2. 坐标计算：所有顶点坐标硬编码为常量对象 `VERTICES = {P:[400,80], A:[215,295], ...}`，延长线交点E坐标通过几何共线关系预先计算确定为(50,200)，无需运行时计算
  3. 动画曲线：分步切换不使用动画，直接显隐，保证课堂讲解时响应迅速；如需柔和过渡，可对透明度使用CSS transition（0.2s ease）
  4. 事件绑定：按钮绑定 `onclick` 事件，更新 currentStep 后调用 renderStep
  5. 元素显隐策略：为每个分步特有的元素组分配class（如 `step1-only`, `step2-only` 等），renderStep 中统一控制；也可为每个元素单独设置ID，按需控制
- ID命名规范：所有交互元素ID以 `scene1-` 为前缀。例如：`scene1-vertex-P`, `scene1-edge-PA`, `scene1-point-E`, `scene1-label-AB-DC`, `scene1-plane-PAB`, `scene1-btn-prev`, `scene1-btn-next`
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })()` 中，避免全局变量污染，确保多场景合并时互不干扰
- 额外注意：平面PAB填充使用 `<polygon>` 元素，置于棱线图层下方（SVG中先定义先绘制，后被覆盖）；所有文字标签使用 `<text>` 元素，设置 `font-family="Arial, sans-serif" font-size="14px"`；虚线使用 `stroke-dasharray="5,5"`
