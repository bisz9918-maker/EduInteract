[图示主题与整合说明]
- 本图示主题：四面体ABCD的已知条件与几何转化
- 整合的步骤/概念：
  1) 原始四面体ABCD的空间结构（与原题图视角一致）；
  2) 关键垂直条件AD⊥BC的识别与高亮；
  3) 定长条件BC=2、AD=2c的标注；
  4) 和为定值AB+BD=AC+CD=2a的几何意义——以A、D为焦点的旋转椭球轨迹示意；
  5) 体积公式的几何转化：引入公垂线EF，将体积最大值问题转化为EF最大值问题。
- 教学价值：教师通过分步递进，引导学生先从空间图形中识别已知条件，再理解"定和→椭球"的轨迹思想，最后完成"体积→公垂线"的关键转化，为后续求EF_max做好铺垫。

[分步序列]
- 步骤0（初始状态）：展示原始四面体ABCD。AD、BD、CD为黑色实线；AB、BC为黑色虚线（被遮挡）。显示顶点标签A、B、C、D。右侧无标注。
- 步骤1（点击下一步）：棱AD变为蓝色（#1565c0），棱BC变为红色（#c62828）。从AD中点和BC中点引出两条灰色虚线引导线至右侧。右侧显示直角符号及文本"AD ⊥ BC"，强调异面垂直关系。
- 步骤2（点击下一步）：在BC下方新增红色标注"BC = 2"；在AD左侧新增蓝色标注"AD = 2c"。
- 步骤3（点击下一步）：以A、D为焦点，绘制绿色虚线旋转椭球轮廓（椭圆中心(220,240)，rx=280，ry=180，旋转-5°，半透明填充15%）。从B、C引出引导线至右侧，标注"AB + BD = 2a"和"AC + CD = 2a"（绿色），说明B、C位于该椭球面上。
- 步骤4（点击下一步）：在AD上标记点E(220,322)，在BC上标记点F(382,322)，连接绿色公垂线段EF。在E点旁画直角符号表示EF⊥AD，并标注"EF ⊥ AD"、"EF ⊥ BC"。右侧出现公式框，展示：
  体积公式：
  V = (1/6) · AD · BC · EF
  = (2c/3) · EF
  ∴ 求 V_max ⇔ 求 EF_max
  完成关键几何转化。
- 教师可随时点击「上一步」回退至任意步骤复习。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于控件栏左侧（x=300, y=465, 80×30px），点击回退到上一状态，步骤0时禁用。
  - 「下一步」按钮：位于控件栏右侧（x=420, y=465, 80×30px），点击推进到下一状态，步骤4时禁用。
  - 步骤指示文本：位于两按钮上方居中（x=400, y=452），显示当前步骤名称，如"步骤 1/5：原始四面体"。
- 教师操作流程：
  1. 教师展示步骤0，让学生观察四面体结构；
  2. 点击「下一步」进入步骤1，引导学生发现AD与BC的垂直关系；
  3. 继续点击「下一步」依次展示长度条件、椭球轨迹意义、体积公式转化；
  4. 讲解过程中可随时回退复习。

[技术实现]
- JS库选择：原生SVG（简单几何与分步显隐，无需复杂3D或图表库）
- 画布尺寸：800 × 500 px（SVG），控件栏为HTML绝对定位覆盖在SVG底部
- 布局草图（ASCII）：
  ```
  [图示区 800×440]
  +--------------------------------------------------------+
  |                                                        |
  |    D                                                   |
  |    |\                                                  |
  |    | \  C                                              |
  |    |  \                                                |
  |    |   \                                               |
  |    |    B                                              |
  |    |   /                                               |
  |    |  /                                                |
  |    | /                                                 |
  |    A                                                   |
  |                                                        |
  |              [右侧标注区: 公式/结论]                   |
  |                                                        |
  +--------------------------------------------------------+
  [控件栏 800×60, y=440~500]
       [上一步]   步骤 1/5   [下一步]
  ```
- 关键实现要点：
  1. 状态机设计：定义currentStep变量（0~4），每步维护一个显隐配置表，记录哪些元素显示/隐藏、哪些属性变更（如stroke颜色）。
  2. 元素分层：SVG中按"底层→顶层"顺序绘制：椭球（步骤3）→ 四面体棱 → 公垂线EF（步骤4）→ 点/标签/引导线/公式框。确保四面体始终清晰。
  3. 颜色切换：步骤1将scene1-edge-ad的stroke设为#1565c0、scene1-edge-bc的stroke设为#c62828；回退到步骤0时恢复为#000000。
  4. 椭球绘制：使用SVG `<ellipse>`，设置transform="rotate(-5, 220, 240)"制造轻微透视感，fill-opacity="0.15"。
  5. 公式框：使用SVG `<rect>` + 多行`<text>`实现，避免引入额外排版库。
  6. 事件绑定：为「上一步」「下一步」按钮绑定click事件，调用updateScene(step)函数统一更新视图。
- ID命名规范：所有SVG元素ID必须以`scene1-`为前缀，例如：
  - scene1-edge-ad, scene1-edge-bc, scene1-edge-ab, scene1-edge-bd, scene1-edge-cd
  - scene1-vertex-a, scene1-vertex-b, scene1-vertex-c, scene1-vertex-d
  - scene1-guide-1, scene1-guide-2, scene1-guide-3, scene1-guide-4
  - scene1-perp-label, scene1-length-bc, scene1-length-ad
  - scene1-ellipsoid
  - scene1-point-e, scene1-point-f, scene1-segment-ef
  - scene1-formula-box, scene1-formula-title, scene1-formula-line1, scene1-formula-line2, scene1-formula-line3
  - HTML控件：scene1-prev-btn, scene1-next-btn, scene1-step-text
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })()` 中，避免多场景合并时变量污染。
