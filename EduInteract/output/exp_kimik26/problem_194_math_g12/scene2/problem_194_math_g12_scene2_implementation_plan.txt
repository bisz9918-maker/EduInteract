[分步序列]
步骤0（初始状态）：显示空间直角坐标系
- 显示：x轴、y轴（灰色）、z轴（蓝色），原点A，z轴上端D
- 标签：A、D、x、y、z
- 右侧公式："A(0,0,0), D(0,0,2c)，z轴沿AD"

步骤1：引入B、C与高亮AD⊥BC条件
- 新增：B、C点（z₀=0.5位置），AB、AC（黑色虚线）、BD、CD（黑色实线）、BC（红色实线）
- 高亮：AD（蓝色）与BC（红色）垂直关系，可在交点附近标注垂直符号（若投影中两线段相交）
- 标签：B、C、BC=2
- 右侧公式："AD·BC=0 ⇒ z₁=z₂=z₀"

步骤2：展示水平平面与截面圆
- 新增：水平平面z=z₀（蓝色半透明四边形），截面圆（绿色椭圆），圆心O_z
- 标签：O_z、z=z₀、ρ
- 右侧公式："B,C在椭球面上，截面为圆，圆心O_z(0,0,z₀)，半径ρ(z₀)"

步骤3：弦心距与直角三角形
- 新增：F（BC中点），O_zF（红色线段），O_zB（绿色半径，示意）
- 右侧新增：直角三角形示意图（O_zFB）
- 标签：F、O_zF
- 右侧公式："BC=2, FB=1, O_zF=√(ρ²-1)"

步骤4：公垂线与体积公式
- 新增：E标签（投影点，与O_z同坐标），EF线段（绿色，与O_zF同线段）
- 高亮：EF=O_zF
- 标签：E、EF
- 右侧公式："V=(1/3)·S△BCD·AD=(2c/3)·√(ρ²-1)"

步骤5：ρ²(z₀)的抛物线图像
- 右侧新增：ρ²-z₀抛物线图（开口向下，顶点在z₀=c）
- 高亮：抛物线顶点（红色圆点）
- 标签：顶点标注"(c,b²)"
- 右侧公式："ρ²=(b²/a²)[a²-(z₀-c)²], b²=a²-c²"

步骤6：最大值结论
- 3D主图更新：B、C、F、O_z、E、平面、截面圆切换到z₀=c位置（几何配置变化）
- 高亮：z₀=c（AD中垂面），最大半径圆（绿色）
- 右侧抛物线保持，高亮顶点
- 右侧公式："z₀=c时，ρ²_max=b², V_max=(2c/3)·√(a²-c²-1)"

[技术实现]
- JS库选择：原生SVG（所有几何元素直接用SVG绘制），无需额外库。公式文本使用SVG foreignObject嵌入HTML div以实现多行文本和自动换行。
- 画布尺寸：800×500 px（固定）
- 布局草图：
  ```
  [主3D图区 520×410]          [右侧面板 240×410]
  +------------------------+ +------------------------+
  |  z轴(D)                | |  公式文本              |
  |   |                    | |  （所有步骤）          |
  |   |    C----B          | |                        |
  |   |   / \  /|          | |  [示意图 步骤3-4]      |
  |   |  /   \/ |          | |  O_z-F-B直角三角形     |
  |   | /    /\ |          | |                        |
  |   |/    /  \|          | |  [抛物线图 步骤5-6]    |
  |  (A)---x   y           | |  ρ²-z₀开口向下抛物线   |
  +------------------------+ +------------------------+
  |        [◀上一步] [步骤k/7] [下一步▶]              |
  +--------------------------------------------------+
  控件栏 y=455~485
  ```
- 关键实现要点：
  1. 状态机设计：用变量currentStep（0~6）控制当前步骤，每步定义显示元素ID集合，切换步骤时遍历显示/隐藏对应元素组。
  2. 步骤6几何切换：步骤6需要更换B、C、F、O_z、平面、截面圆到新的坐标位置。实现方式：准备两套元素（步骤0-5组和步骤6组），步骤6时隐藏前者、显示后者。
  3. 椭圆绘制：使用SVG ellipse元素配合transform="rotate(angle, cx, cy)"实现旋转椭圆。
  4. 抛物线绘制：使用SVG path配合多段L命令连接预计算的关键点（z₀从0到2，步长0.25）。
  5. 颜色切换：O_zF与EF在投影中为同一条线段，步骤4通过改变线段stroke颜色（红→绿）和标签内容实现语义切换。
  6. 事件绑定：按钮绑定click事件，更新currentStep后调用render()函数重新渲染可见性。
- ID命名规范：所有交互元素ID必须以scene2-为前缀。例如：scene2-point-a, scene2-edge-ad, scene2-plane-z0, scene2-circle-section, scene2-label-oz, scene2-formula-panel, scene2-parabola-graph, scene2-btn-prev, scene2-btn-next, scene2-step-indicator。
- IIFE隔离：所有JavaScript代码包裹在 (function() { ... })() 中，避免多场景合并时全局变量污染。
