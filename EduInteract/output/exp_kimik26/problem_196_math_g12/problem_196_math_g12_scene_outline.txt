**题目原文**

如图所示，已知AP是圆O的切线，P为切点，AC是圆O的割线，与圆O交于B，C两点，圆心O在∠PAC的内部，点M是BC的中点．则∠OAM+∠APM的大小为________．

**题目分析**

本题是一道平面几何证明题，核心元素为圆的切线与割线。点M是弦BC的中点，这一条件自然导向垂径定理；切线AP则导向切线性质（半径垂直于切线）。两个直角的存在是发现隐藏辅助圆的关键。

**整体讲解思路**

1. 引导学生识别图形中的基本元素：圆O、圆外点A、切线AP、割线AC、弦BC及其中点M。
2. 通过切线性质得到第一个直角∠OPA = 90°。
3. 通过垂径定理得到第二个直角∠OMA = 90°。
4. 发现O、P、A、M四点共圆（以OA为直径），这是本题的突破口。
5. 利用圆周角定理进行角度等量代换，将∠OAM转化为∠OPM。
6. 得出结论：∠OAM + ∠APM = ∠OPA = 90°。

**图示规划说明**

采用单图示分步导航，从原始图形逐步添加辅助线与标注，完整呈现“发现两个直角→识别四点共圆→角度代换得结论”的认知链条。教师可通过底部按钮控制讲解节奏，随时回退重讲。

**本图示的教学说明**

本图示通过六步递进，完整呈现了从已知条件到最终结论的推导链条。教师可按以下要点引导学生：

1. **聚焦已知条件（步骤0）**
   让学生指出图中所有元素：圆O、圆外一点A、切线AP、割线AC、弦BC、中点M。提问：“看到中点M，你能想到什么定理？”（垂径定理）

2. **发现第一个直角（步骤1）**
   连接OP，强调“见切线，连半径，得垂直”。在图中标注∠OPA = 90°，并用蓝色高亮。这是后续四点共圆的第一个直角依据。

3. **发现第二个直角（步骤2）**
   连接OM，由垂径定理直接得到OM⊥BC。因为B、M、C都在直线AC上，所以OM⊥AC，即∠OMA = 90°。用蓝色高亮第二个直角。

4. **识别隐藏的四点共圆（步骤3）**
   这是本题的难点和突破口。提示学生：“线段OA同时对着两个直角∠OPA和∠OMA，这意味着什么？”引导学生回忆：若线段同侧两点对该线段张角相等且为直角，则四点共圆，且该线段为直径。因此O、P、A、M四点共圆，OA为直径。此时画出辅助圆并轻微填充，增强视觉冲击。

5. **角度等量代换（步骤4）**
   在辅助圆中，∠OAM和∠OPM都是弧OM所对的圆周角，因此∠OAM = ∠OPM。用相同颜色的角弧标注这两个角，帮助学生建立对应关系。

6. **得出结论（步骤5）**
   将待求式进行代换：
   $$\\angle OAM + \\angle APM = \\angle OPM + \\angle APM = \\angle OPA = 90^\\circ$$
   强调“分散的两个角通过四点共圆，被‘收拢’到了一个已知的直角中”。

**课堂讲解建议**

- 在步骤2到步骤3之间建议停顿，让学生自己尝试寻找四点共圆，培养几何直觉。
- 若学生基础较弱，可在步骤3前补充提问：“直角三角形斜边中点到三顶点距离相等，这里OA是斜边，中点是什么？”帮助理解为什么OA是直径。
- 讲完后可总结方法论：本题属于“双直角→四点共圆→角度转移”的经典模型，遇到切线+弦中点的组合可优先考虑此路线。
