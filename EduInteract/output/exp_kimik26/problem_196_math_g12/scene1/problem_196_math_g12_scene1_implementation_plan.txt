[图示主题与整合说明]
- 本图示主题：切线-割线构型中四点共圆的发现与角度推导
- 整合的步骤/概念：题目原始图形 → 切线性质（OP⊥AP）→ 垂径定理（OM⊥AC）→ 以OA为直径的辅助圆（O、P、A、M四点共圆）→ 同弧OM所对圆周角相等（∠OAM=∠OPM）→ 角度代换求出∠OAM+∠APM=90°
- 教学价值：教师可按照“条件→性质→辅助圆→代换→结论”的严格逻辑递进展开讲解，每步只聚焦一个认知点，且可随时回退重复关键步骤。

[交互方案]

- 控件说明：
  1. 「◀ 上一步」按钮：位于底部(290,458)，宽100×高32。点击后回退到上一推导步骤，隐藏当前步骤新增的视觉元素。
  2. 「下一步 ▶」按钮：位于底部(410,458)，宽100×高32。点击后进入下一推导步骤，显示该步骤新增的视觉元素。

- 教师操作流程：教师先展示步骤0（题目原图）让学生观察已知条件；点击"下一步"依次揭示切线性质、垂径定理、辅助圆、圆周角相等关系、最终代换结论；在关键步骤（如步骤3出现辅助圆、步骤4出现等角关系）可停留讲解；若学生有疑问，随时点击"上一步"回退重复。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本场景为纯2D几何图形，无复杂函数绘图或3D需求，原生SVG足以精确控制圆、线、路径、文本，且无需引入外部库，减少依赖。
- 画布尺寸：800 × 500 px（固定viewBox="0 0 800 500"）
- 布局草图：
  ```
  +--------------------------------------------------+
  | 步骤说明文字 (20,25)                              |
  |                                                  |
  |        P(479,149)                                |
  |       /                                          |
  |      /  主圆O(520,240) r=100                     |
  |     A(140,300)-------B(440,300)-M(520,300)-C(600,300)
  |                         辅助圆(330,270) r=192    |
  |                                                  |
  | 等式文字(100,410) [步骤5出现]                     |
  |                                                  |
  |        [◀ 上一步]  1 / 5  [下一步 ▶]             |
  +--------------------------------------------------+
  控件栏区域：y=440~490
  ```
- 关键实现要点：
  1. 状态机设计：维护变量currentStep（0~5）。render()函数根据currentStep遍历元素显隐映射表，设置对应SVG元素的display属性（或opacity过渡）。
  2. 元素显隐映射：为每一步定义需显示的元素ID列表。例如step1显示scene1-line-op、scene1-rightangle-p、scene1-step-desc；step3额外显示scene1-aux-circle并放大四点。
  3. 坐标计算：辅助圆半径通过OA中点(330,270)与半长192.4精确计算；角弧使用SVG path的A命令（arc）按计算出的起止角度绘制。
  4. 动画曲线（可选增强）：线条出现建议使用CSS transition（stroke-dasharray + stroke-dashoffset）实现0.3s的"画出"效果；辅助圆使用opacity 0→1过渡0.4s；角弧直接显示或短暂延迟出现。
  5. 事件绑定：上一步/下一步按钮绑定click事件，更新currentStep后调用render()。在render()中处理边界（currentStep<0则置0，>5则置5）。
  6. 几何自洽验证：本计划坐标已严格满足AP⊥OP（切线）、B/C在圆上、OM⊥AC（垂径）、∠OPA=∠OMA=90°（四点共圆依据），代码实现时直接使用给定坐标即可，无需运行时计算。
- ID命名规范：所有交互元素ID必须以scene1-为前缀。例如：scene1-circle-main、scene1-point-a、scene1-line-op、scene1-rightangle-p、scene1-aux-circle、scene1-angle-oam、scene1-step-desc、scene1-btn-prev、scene1-btn-next。
- IIFE隔离：所有JavaScript代码包裹在 (function() { ... })() 中，避免多场景合并时的全局变量污染。
