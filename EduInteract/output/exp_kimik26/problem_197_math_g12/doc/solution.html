problem_197_math_g12

场景导航：Scene 1

题目原文

如图，将△ABC沿着它的中位线DE折叠后，点A落到点A′，若∠C=120°，∠A=26°，则∠A′DB的度数是__．

题目分析

本题核心考查三角形中位线性质、图形折叠的对称性，以及角度计算。解题的关键在于发现"中位线平行于底边"这一性质，从而将折叠前后的角度关系与平角建立联系，快速求出目标角。此外，折叠后点A′恰好落在直线BC上，这一深层几何性质可用于多角度验证结论。

整体讲解思路

  1. 先引导学生利用三角形内角和求出∠B。
  2. 回顾中位线性质：DE ∥ BC，且D、E分别为AB、AC中点。
  3. 利用平行线同位角相等，得到∠ADE = ∠B。
  4. 分析折叠对称性：△A′DE ≌ △ADE，故∠A′DE = ∠ADE。
  5. 利用A、D、B三点共线（平角180°），计算∠A′DB。
  6. （拓展）引导学生观察A′的位置，发现A′落在直线BC上，进而用等腰三角形性质验证答案，加深对折叠本质的理解。

图示规划说明

采用一个综合交互图示，通过分步按钮导航，将"原图→中位线→平行关系→折叠→角度推导→拓展验证"的完整认知过程整合在同一画布中，避免相似图形的重复拆分。

步骤0：原题条件——已知∠A=26°，∠C=120°

教学说明：如何引导学生完成推导

本图示将完整的推导链条整合在一个交互场景中，教师可通过底部按钮逐步释放信息，建议每走一步停顿提问，让学生先猜想再验证。

关键引导提问：

  1. 看到∠A=26°、∠C=120°，第一步应该求什么？（求∠B=34°，为后续铺垫）
  2. DE是中位线，除了"D、E是中点"，还有什么更重要的性质？（DE ∥ BC，且长度为BC的一半）
  3. 因为DE ∥ BC，∠ADE与∠B是什么关系？（同位角，均为34°）
  4. 折叠后，哪些量保持不变？（△A′DE ≌ △ADE，所以∠A′DE = ∠ADE = 34°，A′D = AD）
  5. 观察点A、D、B的位置，它们在同一直线上意味着什么？（∠ADB是平角，等于180°）
  6. 因此∠A′DB = 180° − 34° − 34° = 112°。

拓展验证（步骤5）：

如果课堂时间允许，建议进入步骤5，引导学生发现A′落在直线BC上这一美妙性质。

  • 因为DE ∥ BC，且DE是A与BC之间的"等距中线"（A到DE的距离 = BC到DE的距离 = 高的一半），折叠后A′到DE的距离与A相等，故A′必落在直线BC上。
  • 由此得到△A′DB是等腰三角形：AD = DB（中点定义），A′D = AD（折叠对称），所以A′D = DB。
  • 因为A′在直线BC上，∠DBA′ = ∠ABC = 34°，故底角∠DA′B = 34°，再次算出∠A′DB = 180° − 2×34° = 112°。

两种方法殊途同归，既能训练学生的"平行+平角"思维，也能训练"对称+等腰"思维，实现一题多解的课堂效果。
