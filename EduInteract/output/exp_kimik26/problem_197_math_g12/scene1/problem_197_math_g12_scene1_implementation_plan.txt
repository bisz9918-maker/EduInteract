[图示主题与整合说明]
- 本图示主题：三角形中位线折叠的角度推导与性质验证
- 整合的步骤/概念：原题条件展示 → 求∠B并标出中位线DE → 展示DE∥BC及同位角∠ADE=34° → 沿DE折叠A→A′并展示对称角 → 利用平角推导∠A′DB=112° → 拓展验证A′落在直线BC上及等腰△A′DB性质
- 教学价值：教师可按照严格的几何逻辑链分步讲解，每步聚焦一个知识点，随时回退复习；折叠动画帮助学生建立直观的空间想象，拓展验证强化结论的可靠性。

[分步序列]
- 步骤0「原题条件」：显示△ABC（AB、BC、CA三线段），标注顶点A、B、C；标注∠A=26°（绿色弧线+文字于A左侧）、∠C=120°（绿色弧线+文字于C上方）；步骤提示文字"步骤0：原题条件——已知∠A=26°，∠C=120°"。
- 步骤1「求∠B与中位线」：新增∠B=34°（绿色弧线+文字于B右侧）；标出D（AB中点）和E（AC中点），显示中位线DE（蓝色）；在AD和DB中点处画黑色等长标记；步骤提示"步骤1：求∠B=34°，标出中位线DE"。
- 步骤2「平行关系」：DE和BC线宽加粗至3px（蓝色高亮）；在BC和DE旁添加蓝色平行箭头标记；新增∠ADE=34°（绿色弧线+文字于D右下方，同位角）；步骤提示"步骤2：DE ∥ BC，同位角∠ADE=34°"。
- 步骤3「折叠演示」：显示△A′DE（蓝色边线+半透明蓝色填充），A′点及标签（蓝色）；画灰色虚线圆弧表示A沿DE翻折到A′的轨迹（圆心H(406,276)，半径100）；新增∠A′DE=34°（蓝色弧线+文字于D上方）；将BC显示为向两端延长的直线（(120,60)到(360,380)），使A′明显落在延长线上；步骤提示"步骤3：沿DE折叠，A→A′，∠A′DE=∠ADE=34°"。
- 步骤4「角度结论」：新增∠A′DB=112°（红色粗弧线+红色粗体文字于D左上方）；在画面右侧显示红色算式"180° − 34° − 34° = 112°"；将∠A′DB区域用红色描边高亮；步骤提示"步骤4：平角180°−34°−34°=112°，即∠A′DB"。
- 步骤5「拓展验证」：新增A′D上的蓝色等长标记（表明A′D=AD=DB）；新增∠DBA′=34°（绿色弧线+文字于B右侧偏上）和∠DA′B=34°（绿色弧线+文字于A′右侧偏上）；显示蓝色文字"A′落在直线BC上"于A′右下方；高亮等腰△A′DB（蓝色描边加粗）；步骤提示"步骤5：A′在直线BC上，△A′DB为等腰三角形，底角34°验证112°"。

[交互方案]

- 控件说明：
  1. 「上一步」按钮：位于(300, 460)，宽80px，高30px，点击回退到上一分步状态
  2. 「下一步」按钮：位于(420, 460)，宽80px，高30px，点击前进到下一分步状态

- 教师操作流程：教师点击「下一步」依次呈现推导链条；在关键步骤（如步骤3折叠、步骤4结论）可停留讲解；若学生有疑问，点击「上一步」回退复习；步骤0为初始状态，步骤5为完整结论状态。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本题为纯几何图形与分步状态切换，无需复杂数据可视化或3D，原生SVG路径、弧线、文本控制足够；状态切换通过classList控制display/opacity即可。
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [标题/步骤提示  y=20~40  居中]
  [主图区        y=40~430  △ABC、DE、A′、角度弧线、标注]
  [控件栏        y=440~490  ◀上一步  下一步▶]
  ```
- 关键实现要点：
  1. 状态机设计：用变量currentStep（0~5）控制当前步骤，每步定义showElements和hideElements数组，存放对应SVG元素的ID。
  2. 角度弧线绘制：使用SVG `<path>` 的A指令（arc）绘制。例如∠A′DB的112°大弧：圆心D(318,158)，半径30，起始角度从DA′方向（约87°）到DB方向（约200°），sweep-flag=1（大弧）。
  3. 折叠动画：步骤3中，灰色虚线圆弧使用stroke-dasharray和CSS动画（或requestAnimationFrame）实现从A到A′的绘制动画，时长800ms，ease-out。
  4. 等长标记：每组为两条平行短斜线，使用`<line>`元素，垂直于所在线段，通过计算线段垂线方向向量定位端点。
  5. 平行标记：在BC和DE中点附近各画一个同向小箭头（`<path>`画箭头），表示平行关系。
  6. 事件绑定：上一步/下一步按钮绑定click事件，调用updateScene(step)函数，该函数遍历所有元素设置display属性（或opacity过渡）。
- ID命名规范：所有SVG元素ID必须以`scene1-`为前缀。例如：`scene1-tri-abc`、`scene1-line-de`、`scene1-angle-a`、`scene1-btn-prev`、`scene1-btn-next`。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })()` 中，避免多场景合并时变量污染。
- 颜色常量定义（IIFE内部）：
  ```javascript
  const COLORS = {
    main: '#000000',
    blue: '#1565c0',
    red: '#c62828',
    green: '#2e7d32',
    gray: '#888888',
    fillBlue: 'rgba(21,101,192,0.15)'
  };
  ```
