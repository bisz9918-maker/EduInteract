**题目原文**

如图，在直角坐标平面内有一个边长为 $a$，中心在原点 $O$ 的正六边形 $ABCDEF$，$AB \parallel Ox$。直线 $L: y = kx + t$（$k$ 为常数）与正六边形交于 $M$、$N$ 两点，记 $\triangle OMN$ 的面积为 $S$，则函数 $S = f(t)$ 的奇偶性为 ______。

**题目分析**

本题的核心是判断面积函数 $S = f(t)$ 的奇偶性。直接计算 $f(t)$ 的解析式虽然可行，但过程繁琐（需要分段讨论直线与正六边形不同边的交点）。更优雅的方法是利用**正六边形的中心对称性**与**直线关于原点的对称性**，从几何直观上直接得到 $f(-t) = f(t)$。

**整体讲解思路**

1. 先带领学生回顾正六边形的中心对称性，明确其关于原点 $O$ 对称。
2. 再引导学生观察直线 $y = kx + t$ 与 $y = kx - t$ 的位置关系：两者关于原点对称。
3. 结合以上两点，说明当 $t$ 变为 $-t$ 时，交点 $M$、$N$ 也关于原点对称，从而 $\triangle OMN$ 的面积不变。
4. 得出结论：$f(t)$ 为偶函数。

**图示规划说明**

- 图示 1：正六边形的几何结构与中心对称性（为后续证明做铺垫）。
- 图示 2：直线截正六边形与面积函数 $S = f(t)$ 的奇偶性（核心图示，通过动态调节 $t$ 并对比 $t$ 与 $-t$ 的情形，直观呈现 $f(-t) = f(t)$）。
</TEXT_1>

**教学说明：面积函数奇偶性的判定**

本图示是讲解本题的核心环节。建议教师按以下顺序引导学生：

1. **观察直线平移**：拖动 $t$ 滑块，让学生观察直线 $L$ 如何上下平移、交点 $M$、$N$ 如何移动、面积 $S$ 如何变化。这一步帮助学生建立"$S$ 是 $t$ 的函数"这一认知。

2. **提出核心问题**："如果我把 $t$ 换成 $-t$，面积会怎么变？"先让学生猜想，再点击"显示对称直线"按钮验证。

3. **对称性分析**：
   - 直线 $L: y = kx + t$ 与 $L': y = kx - t$ 关于原点对称。验证方法：若 $(x_0, y_0)$ 在 $L$ 上，则 $y_0 = kx_0 + t$，于是 $-y_0 = k(-x_0) - t$，即 $(-x_0, -y_0)$ 在 $L'$ 上。
   - 正六边形关于原点对称（已在 SCENE_1 中建立）。
   - 因此 $L'$ 与正六边形的交点 $M'$、$N'$ 分别是 $M$、$N$ 关于原点的对称点。

4. **面积关系推导**：
   - $\triangle OM'N'$ 可以看作是 $\triangle OMN$ 绕原点 $O$ 旋转 $180^\circ$ 得到的。
   - 旋转不改变图形的形状和大小，故 $S_{\triangle OM'N'} = S_{\triangle OMN}$。
   - 即 $f(-t) = f(t)$。

5. **强调定义域对称性**：由于正六边形关于原点对称，当直线 $y = kx + t$ 与正六边形有两个交点时，$y = kx - t$ 也必然与正六边形有两个交点，因此 $f(t)$ 的定义域关于原点对称，满足偶函数的定义。

**关键公式**

$$S = f(t) = \frac{1}{2} |OM| |ON| \sin\angle MON$$

虽然不需要具体计算，但可以告诉学生：当 $t \to -t$ 时，$OM \to OM' = OM$，$ON \to ON' = ON$，$\angle MON \to \angle M'ON' = \angle MON$，因此 $S$ 不变。
</TEXT_3>

<TEXT_4>
**完整解答**

**结论**：$f(t)$ 是**偶函数**。

**证明过程**：

1. 正六边形 $ABCDEF$ 中心在原点 $O$，故正六边形关于原点中心对称。

2. 设直线 $L: y = kx + t$ 与正六边形交于 $M$、$N$ 两点，则面积 $S = f(t) = S_{\triangle OMN}$。

3. 考虑 $t$ 取相反数的情形，即直线 $L': y = kx - t$。若点 $P(x, y)$ 在 $L$ 上，则 $y = kx + t$，从而 $-y = k(-x) - t$，即点 $P'(-x, -y)$ 在 $L'$ 上。因此直线 $L'$ 是直线 $L$ 关于原点 $O$ 的对称直线。

4. 由于正六边形关于原点对称，直线 $L'$ 与正六边形的交点 $M'$、$N'$ 分别是 $M$、$N$ 关于原点 $O$ 的对称点。

5. 于是 $\triangle OM'N'$ 与 $\triangle OMN$ 关于原点对称，两三角形全等，面积相等：

$$f(-t) = S_{\triangle OM'N'} = S_{\triangle OMN} = f(t)$$

6. 又因为正六边形的对称性保证了 $f(t)$ 的定义域关于原点对称，故 $f(t)$ 为偶函数。

**课堂讲解建议**

- **避免直接计算**：本题若试图求出 $f(t)$ 的分段解析式再判断奇偶性，计算量极大且容易出错。应引导学生优先观察图形的对称性，培养"几何直观优先"的解题意识。
- **强调方法迁移**：类似地，对于中心对称图形（如圆、椭圆、矩形等），若直线方程中参数以 $t$ 的奇数次幂出现，则对应的弦长、面积等函数往往具有奇偶性，可类比分析。
- **互动提问**：在展示 SCENE_2 时，可先让学生猜测 $f(t)$ 是奇函数还是偶函数，再通过图示验证，增强课堂参与感。
</TEXT_4>
