[图示主题与整合说明]
- 本图示主题：铅笔芯并联电路的电流分配规律与量程约束分析
- 整合的步骤/概念：电路结构识别 → 滑片位置与电流反比规律探索 → 0-0.6A量程边界分析（c点、d点）→ 铅笔芯总长度L推导 → 0-3A量程新边界与范围计算 → 最大比值与结论
- 教学价值：教师通过分步导航，按课堂节奏逐步展开。步骤2支持自由拖动滑片，让学生直观感受电流与电阻的反比关系；后续步骤通过自动定位边界，将抽象的“量程约束”转化为可视化的满偏闪烁与范围高亮，降低认知负荷。

[分步序列]
- 步骤0（初始状态）：展示完整电路。P位于中点x=230（12cm处）。右侧面板所有数值显示"--"，量程显示"--"。无高亮。
- 步骤1（并联路径）：点击下一步→左侧电流路径出现3个蓝色箭头（左上向左、左中向下、左下向右），右侧出现3个红色箭头（右上向右、右中向下、右下向左）。面板显示公式"I₁ = U/R₁"、"I₂ = U/R₂"。
- 步骤2（自由探索）：点击下一步→电流路径箭头保留（变淡）或隐藏。教师可自由拖动滑片P（沿AB，x∈[80,380]）。右侧面板实时更新：位置x（cm）、R₁=x·r、R₂=(24-x)·r、I₁=3.6/x、I₂=3.6/(24-x)、电流比值I₁:I₂（保留1位小数）。量程显示"不限"。
- 步骤3（0.6A左边界c）：点击下一步→P自动动画移动到x=155（6cm，c点）。量程切换为"0-0.6A"。A1表盘满偏高亮（I₁=0.6A，指针指3点钟，外圈蓝色发光），I₂=0.2A。面板显示比值"3:1"。c标记出现并闪烁（opacity 0.3↔1，周期800ms）。
- 步骤4（0.6A右边界d）：点击下一步→P自动动画移动到x=305（18cm，d点）。A2表盘满偏高亮（I₂=0.6A，外圈红色发光），I₁=0.2A。面板显示比值"1:3"（或当前比值）。d标记出现并闪烁。铅笔芯上cd段（155~305）显示绿色半透明覆盖。面板范围值显示"12cm"。
- 步骤5（推导总长度）：点击下一步→P动画回到中点x=230（或保持静止）。cd高亮与d标记隐藏，c标记常亮。面板公式区显示推导：
  "c点：I₁:I₂ = 3:1 → (L-x):x = 3:1 → x_c = L/4"
  "d点：I₂ = 0.6A → x_d = 3L/4"
  "cd = x_d - x_c = L/2 = 12cm"
  "∴ L = 24cm，U/r = 3.6 A·cm"
  关键数字用绿色#2e7d32加粗。
- 步骤6（3A新边界）：点击下一步→量程切换为"0-3A"。P移动到x=95（c'点，1.2cm）。c'标记出现，d'标记出现。A1表盘满偏（I₁=3A，外圈蓝色发光），I₂≈0.16A。随后P快速移动到x=365（d'点，22.8cm），A2满偏（I₂=3A）。面板范围值显示"21.6cm"。铅笔芯上c'd'段（95~365）显示绿色半透明覆盖。c/d标记隐藏。
- 步骤7（结论）：点击下一步→P回到c'点（或保持d'点，显示最大比值场景）。面板显示：
  "最大比值 = 3 : 3.6/22.8 = 19 : 1"
  "允许范围 c'd' = 21.6cm"
  底部高亮显示答案"A、D"（绿色24px加粗）。

教师可随时点击「上一步」回退，回退时所有元素状态反向恢复。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：本场景以几何电路图和状态切换为主，无复杂函数绘图或3D，原生SVG足够且轻量。
- 画布尺寸：800 × 500 px（SVG viewBox="0 0 800 500"）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------------+
  |  +------------------------+  +----------------------+  |
  |  |      电源(220,60)       |  |     数据面板          |  |
  |  |         |               |  |  量程: 0-0.6A        |  |
  |  |    开关S(220,120)       |  |  x = 12.0 cm         |  |
  |  |         |               |  |  R₁=12  R₂=12        |  |
  |  |   A1 -- 顶部导线 -- A2  |  |  [A1表盘] I₁=0.30A   |  |
  |  |   |              |      |  |  [A2表盘] I₂=0.30A   |  |
  |  |   A====P=========B      |  |  比值 1:1            |  |
  |  |   0   6   12  18  24    |  |  范围 12cm           |  |
  |  +------------------------+  +----------------------+  |
  |           [◀ 上一步]  步骤 2/7  [下一步 ▶]              |
  +--------------------------------------------------------+
  左侧电路区 x:20~420    右侧面板区 x:440~780    控件区 y:440~500
  ```
- 关键实现要点：
  1. 状态机设计：维护全局变量 `currentStep`（0~7）。`updateScene(step)`函数根据步骤号统一控制所有元素的显隐、位置、文本内容。禁止分散在多个事件监听器中直接操作DOM。
  2. P的位置动画：使用 `requestAnimationFrame` 对 `x_p` 进行线性插值。目标位置根据步骤映射：step2自由拖动无目标；step3→155；step4→305；step5→230；step6先→95再→365（可用setTimeout串行）；step7→95。动画时长400ms，ease-out。
  3. 表盘指针旋转：指针元素使用SVG `transform="rotate(angle, cx, cy)"`。角度公式：`angle = 180 - (I / I_max) * 180`。0-0.6A量程时I_max=0.6；0-3A量程时I_max=3。满偏时给表盘圆添加class `glow`，CSS定义filter: drop-shadow。
  4. 探索模式拖拽：仅在 `currentStep === 2` 时启用。监听SVG的mousedown→mousemove→mouseup（及touch事件）。计算鼠标x坐标映射到SVG坐标系，限制x_p∈[80,380]。拖动时实时调用 `updatePanel(x_p)` 更新右侧面板数值。
  5. 边界标记闪烁：使用CSS `@keyframes blink { 0%,100%{opacity:1} 50%{opacity:0.3} }`，步骤切换时添加/移除class。
  6. 公式区显隐：步骤5、7时显示 `<g id="scene1-formula">`，其他步骤隐藏。公式文本使用SVG `<text>` 多行通过多个 `<tspan>` 实现。
  7. 坐标映射：铅笔芯物理长度24cm对应像素300px（x:80~380）。换算函数：`pxToCm(px) = (px - 80) / 12.5`。反向：`cmToPx(cm) = 80 + cm * 12.5`。
- ID命名规范：所有交互元素ID必须以 `scene1-` 为前缀。例如：`scene1-slider-p`、`scene1-pointer-a1`、`scene1-panel-ratio`、`scene1-btn-prev`、`scene1-mark-c`、`scene1-range-cd` 等。JS中严格使用 `document.getElementById` 获取，禁止全局class选择器，避免多场景合并时跨场景污染。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，不暴露全局变量。事件监听通过 `addEventListener` 绑定到具名函数。
