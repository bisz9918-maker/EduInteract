[图示主题与整合说明]
- 本图示主题：动能定理与电势差计算（带电粒子在匀强电场中的能量分析）
- 整合的步骤/概念：
  1. 回顾 A→B 的类斜抛轨迹与初末速度方向；
  2. 计算初末动能及动能增量；
  3. 分析重力做功（负功）；
  4. 分析电场力做功（待求量）；
  5. 应用动能定理联立求解电场力做功；
  6. 由电场力做功求 A、B 两点电势差。
- 教学价值：教师通过分步按钮控制公式呈现节奏，先建立物理图景（轨迹+速度），再逐层展开能量分析，最后聚焦动能定理的联立求解，避免一次性呈现大量公式造成学生认知过载。蓝色结论框在最终步骤强化记忆点。

[分步序列]
- 步骤0（轨迹回顾·初始状态）：
  显示电场线、E标注、A点、B点、轨迹曲线、v₀箭头、v_B箭头、A/B/v₀/v_B标签。
  推导区仅显示三栏分隔线，所有卡片隐藏。
  目的：建立完整物理情景，让学生看到粒子从A到B的速度方向变化。

- 步骤1（初末动能）：
  点击「下一步」→ 左栏动能卡片淡入（opacity 0→1，0.4s）。
  卡片内依次显示：
  · 初动能 E_kA = ½mv₀²（y=285）
  · 末动能 E_kB = ½m(2v₀)² = 2mv₀²（y=340）
  · 动能增量 ΔE_k = E_kB − E_kA = ³⁄₂mv₀²（y=410，红色加粗）
  目的：量化初末状态，得到ΔE_k为后续定理做铺垫。

- 步骤2（重力做功）：
  点击「下一步」→ 
  · 轨迹区：竖直虚线(200,160)→(200,60)与绿色双向箭头(170,160)→(170,60)淡入，h标签(155,110)出现；
  · 中栏上：绿色重力功卡片淡入，显示"重力做功 W_g"（y=245，绿色）、"W_g = −mgh = −½mv₀²"（y=280）、"（负功）"（y=310，绿色小字）。
  目的：分析竖直方向重力做负功，数值为−½mv₀²。

- 步骤3（电场力做功）：
  点击「下一步」→ 
  · 轨迹区：水平虚线(200,160)→(600,160)与蓝色双向箭头(200,190)→(600,190)淡入，x标签(400,205)出现；
  · 中栏下：蓝色电场力功卡片淡入，显示"电场力做功 W_E"（y=365，蓝色）、"W_E = qEx"（y=400）、"（待求）"（y=425，蓝色小字）。
  目的：提出待求量W_E，营造认知冲突。

- 步骤4（动能定理）：
  点击「下一步」→ 右栏蓝色定理卡片淡入。
  卡片内显示：
  · "动能定理"（y=250）
  · "W_E + W_g = ΔE_k"（y=300）
  · "W_E − ½mv₀² = ³⁄₂mv₀²"（y=340，代入数值）
  · "∴ W_E = 2mv₀²"（y=390，蓝色加粗，高亮结论）
  目的：联立求解，得到电场力做功。

- 步骤5（电势差结论）：
  点击「下一步」→ 右栏内容替换为结论框（可先做0.2s淡出再0.2s淡入）。
  结论框内显示：
  · "A、B两点电势差"（y=260）
  · "U_AB = W_E / q"（y=320）
  · "= 2mv₀² / q"（y=380，蓝色加粗，字号略大）
  目的：给出本问最终结论，蓝色结论框强化记忆。

- 回退机制：教师可随时点击「上一步」，当前步骤新增元素淡出，回到前一步状态。

[技术实现]
- JS库选择：原生 SVG + 原生 JavaScript。理由：本场景以几何图形、箭头、卡片、公式为主，无复杂数据可视化或3D，原生SVG路径、marker、text即可满足；原生JS状态机轻量可控。
- 画布尺寸：800 × 500 px（固定），控件栏在SVG内底部y=460~490区域，使用foreignObject或SVG text+rect绘制按钮，position:absolute叠在SVG上。
- 布局草图（ASCII）：
  ```
  0    100  200       400       600       700    800
  ┌──────────────────────────────────────────────────┐ 0
  │  ────→  ────→  ────→  E                         │
  │         ●B (v_B=2v₀→)                            │
  │          ╲                                       │
  │           ╲      轨迹区 (y=20~210)                │
  │            ╲                                     │
  │    (↑v₀)    ●A                                   │
  │    h↑↓      ───────→x                            │
  ├──────────┬──────────┬────────────────────────────┤ 210
  │ 动能分析  │ 重力做功  │     动能定理 / 电势差        │
  │ E_kA=... │ W_g=...  │     W_E+W_g=ΔE_k           │
  │ E_kB=... │ （负功）  │     ∴ W_E=2mv₀²            │
  │ ΔE_k=... ├──────────┤     ─────────────────      │

  │         [◀ 上一步] [下一步 ▶]                    │ 490
  └──────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：变量 `scene2_currentStep`（0~5）。每步一个配置对象，记录该步应显示的元素ID列表。点击按钮时更新状态，遍历所有元素，在列表内的移除 `scene2-hidden` 添加 `scene2-visible`，否则反向操作。
  2. 元素分组管理：用 `<g>` 包裹各步骤元素，如 `scene2-step1-group`、`scene2-step2-trajectory`、`scene2-step2-work` 等，通过控制组的class统一显隐。
  3. 动画曲线：CSS transition `opacity 0.4s ease` 实现淡入淡出；步骤5替换内容时先加 `scene2-hidden`（0.2s）再切换内部text内容，再移除 `scene2-hidden`（0.2s）。
  4. 双向箭头实现：SVG line配两端marker（marker-start、marker-end），marker内为三角形path；竖直箭头绿色，水平箭头蓝色。
  5. 抛物线轨迹：`<path d="M200,160 Q400,20 600,60" />`，控制点(400,20)使曲线经过B点上方最高点，符合B为竖直速度零点的物理意义。
  6. 公式排版：SVG `<text>` 内直接使用Unicode上标/下标字符（v₀、½、²、³），确保跨浏览器兼容；关键结论字重用 `font-weight:bold` + `font-size` 略大。
  7. 按钮状态：步骤0禁用「上一步」，步骤5禁用「下一步」，通过JS设置 `disabled` 属性并修改 `fill-opacity`。
- ID命名规范：所有SVG元素及JS变量均以 `scene2-` 为前缀。例如：
  · `scene2-trajectory-path`
  · `scene2-point-a`
  · `scene2-arrow-v0`
  · `scene2-step1-card`
  · `scene2-step2-work-gravity`
  · `scene2-btn-prev`
  · `scene2-btn-next`
  JS中严格使用 `document.getElementById('scene2-xxx')`，禁止全局class选择器，避免多场景合并时跨场景污染。
- IIFE隔离：所有JS逻辑包裹在 `(function() { ... })()` 中，对外仅暴露必要的全局状态变量（若需要）。
