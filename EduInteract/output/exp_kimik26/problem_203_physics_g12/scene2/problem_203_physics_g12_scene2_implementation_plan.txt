[图示主题与整合说明]
- 本图示主题：类平抛运动分解——分运动独立性与等时性原理
- 整合的步骤/概念：
  1. 在入射点建立平面直角坐标系（x轴沿初速度v₀方向，y轴沿加速度a方向）；
  2. 水平方向为匀速直线分运动，相等时间内位移相等；
  3. 竖直方向为初速为零的匀加速直线分运动，相等时间内位移比为1:3:5；
  4. 利用等时性将同一时刻的水平、竖直分位移合成，得到合运动位置；
  5. 用平滑曲线连接合位置，揭示轨迹为抛物线，并给出轨迹方程。
- 教学价值：教师可通过分步导航，先让学生分别观察两个简单直线分运动的规律，再通过辅助虚线直观感受"独立进行、等时合成"的物理本质，最后由实验点连成抛物线，完成从现象到方程的升华。

[分步序列]
- 初始状态（步骤0）「坐标系」：
  显示坐标系（x轴、y轴、原点O）、v₀箭头（蓝色）、a箭头（红色）。其余元素隐藏。
  教师讲解：建立坐标系，明确初速度沿x轴、电场力（加速度）沿y轴。

- 步骤1「水平分运动」：
  新增：x轴上三个蓝色等距圆点 B1、B2、B3；x轴下方标注 t₁、t₂、t₃；蓝色文本 "x = v₀t"。
  视觉特征：相邻蓝点水平间距相等（100px），直观体现匀速直线运动规律。
  教师讲解：水平方向不受力，粒子以v₀做匀速直线运动，x = v₀t。

- 步骤2「竖直分运动」：
  新增：y轴上三个红色圆点 R1、R2、R3；y轴左侧标注 t₁、t₂、t₃；红色文本 "y = ½at²"。
  视觉特征：相邻红点竖直间距递增（20px→60px→100px，符合1:3:5），与水平点对应相同时刻，强调等时性。
  教师讲解：竖直方向初速为零、受恒力作用，做匀加速直线运动；与水平分运动时间完全相同。

- 步骤3「合运动轨迹」：
  新增：6条灰色辅助虚线（从x轴蓝点向上、从y轴红点向右，交汇于P1、P2、P3）；三个绿色合点 P1、P2、P3；绿色抛物线轨迹连接 O→P1→P2→P3；P3处绿色合速度切线箭头 v。
  视觉特征：虚线构成"矩形网格"，交点即为同一时刻的合位置；平滑曲线清晰展示抛物线轨迹。
  教师讲解：两个分运动独立进行、同时发生，合位置由分位移矢量合成；连接各时刻合位置得到抛物线轨迹。

- 步骤4「公式总结」：
  新增：画布右侧文本块，依次列出：
    x = v₀t
    y = ½at²
    消去 t 得：y = (a / 2v₀²)·x²
    轨迹为抛物线
  所有前期几何元素保持显示，形成完整知识图景。
  教师讲解：联立分运动方程消去时间t，得到轨迹方程，从数学上证明合运动为抛物线。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「上一步」按钮：位于画布底部 (260,452)，宽100×34px；点击回退到上一分步，步骤0时禁用。
  2. 「下一步」按钮：位于画布底部 (420,452)，宽100×34px；点击前进到下一分步，步骤4时禁用。
  3. 步骤指示文本：位于画布底部 (340,488)，显示当前步骤名称及序号（如"步骤 3/4：合运动轨迹"）。
- 教师操作流程：
  1. 课堂开始时点击「下一步」进入步骤0，展示坐标系与初速度、加速度方向，建立物理情景；
  2. 点击「下一步」进入步骤1，引导学生观察水平匀速特征；
  3. 点击「下一步」进入步骤2，引导学生观察竖直匀加速特征，并强调等时性；
  4. 点击「下一步」进入步骤3，通过辅助虚线合成合位置，连线形成抛物线，突破认知难点；
  5. 点击「下一步」进入步骤4，总结公式，完成从几何直观到代数抽象的过渡；
  6. 可随时点击「上一步」回退，针对学生疑惑反复讲解。

[技术实现]
- JS库选择：原生 SVG + 原生 JavaScript。理由：本场景以静态几何图形和分步显隐为主，无需复杂数据绑定或3D渲染；原生SVG可精确控制每个元素的坐标、颜色和显隐状态，轻量且兼容性好。
- 画布尺寸：800 × 500 px（固定画布，控件栏位于SVG内底部 y=440~490 区域）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------------+
  |  y                                                     |
  |  ^  a↑                                                 |
  |  |  O----->x  v₀                                       |
  |  |      ·  ·  ·   (蓝点 B1 B2 B3)                       |
  |  |      |  |  |                                        |
  |  |  R1·-P1  |  |        抛物线（绿色）                  |
  |  |  |   \   |  |       /                               |
  |  |  R2·--P2 |  |      /                                |
  |  |  |      \|  |     /                                 |
  |  |  R3·-----P3     /                                   |
  |  |            \   /                                    |
  |  |             \ /                                     |
  |  |              v                                      |
  |  |    [公式总结：x=v₀t, y=½at², 轨迹方程]（右侧）       |
  |  +---------------------------------------------------> |
  |                                                        |
  |    [◀ 上一步]   步骤 X/4   [下一步 ▶]                  |
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `currentStep`（取值 0~4），每次点击按钮时更新状态，调用 `renderStep()` 根据状态显隐元素。
  2. 元素显隐控制：所有可切换元素初始 `display: none` 或 `opacity: 0`，在对应步骤中通过 `setAttribute('display', 'block')` 或添加/移除 CSS class 显示。建议使用 CSS transition 实现 200ms 淡入效果，增强视觉连贯性。
  3. 抛物线绘制：使用 JavaScript 计算路径点，公式为 `y = 100 + 0.002 * (x - 120)^2`，x 从 120 到 420 以步长 5 迭代，拼接成 SVG path 的 `d` 属性（M 起始 + L 连接）。
  4. 箭头绘制：使用 SVG `<marker>` 定义箭头头部，分别绑定蓝色、红色、绿色三种箭头样式，供 v₀、a、v 三个箭头复用。
  5. 辅助虚线：使用 `stroke-dasharray="4,4"` 实现虚线效果，步骤3出现时统一淡入。
  6. 按钮禁用逻辑：步骤0时禁用「上一步」，步骤4时禁用「下一步」，通过修改 `disabled` 属性与透明度（如 opacity: 0.4）提示用户。
  7. 步骤指示文本：使用一个 `<text>` 元素，在 `renderStep()` 中更新其 `textContent` 为对应步骤标题。
- **ID 命名规范**：所有交互元素 ID 必须以 `scene2-` 为前缀。例如：
  - 坐标轴：`scene2-axis-x`、`scene2-axis-y`
  - 点：`scene2-dot-x1`、`scene2-dot-y1`、`scene2-dot-p1`
  - 标签：`scene2-label-t1x`、`scene2-label-p1`
  - 箭头：`scene2-arrow-v0`、`scene2-arrow-a`、`scene2-arrow-v`
  - 辅助线：`scene2-aux-v1`、`scene2-aux-h1`
  - 轨迹：`scene2-trajectory`
  - 公式：`scene2-formula-x`、`scene2-formula-summary`
  - 控件：`scene2-btn-prev`、`scene2-btn-next`、`scene2-step-text`
  JS 中严格使用 `document.getElementById` 获取元素，禁止全局 class 选择，避免多场景合并时跨场景污染。
- IIFE 隔离：所有 JavaScript 代码包裹在 `(function() { ... })()` 立即执行函数中，变量与函数不污染全局作用域。
