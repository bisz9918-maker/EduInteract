[图示主题与整合说明]
- 本图示主题：绳张力与静摩擦力随角速度平方的变化规律（F–ω² 关系图）
- 整合的步骤/概念：将圆盘转动问题中 A、B 两物体的静摩擦力 f_A、f_B 以及两根细绳张力 T_AB、T_OB 随 ω²/g 变化的四条分段线性曲线整合在同一坐标系中；叠加最大静摩擦 f_max=0.5mg 与最大绳张力 T_max=2mg 的限制线；用三条临界垂线标出 ω₀²、ω₁²、ω₂² 三个关键转折点。
- 教学价值：教师可按照"先摩擦后张力、先 A 后 B"的顺序逐条揭示曲线，帮助学生理解各力出现的先后顺序、增长斜率的物理含义（由转动半径决定），以及最终系统失稳的临界条件（T_OB 先触及上限）。

[交互方案]
- 交互类型：分步按钮导航（◀ 上一步 / 下一步 ▶）。
- 控件说明：
  * 「◀ 上一步」按钮：位于 SVG 内底部 (310,462)，宽 90×28 px；点击后回退一个步骤，隐藏当前步骤新增的元素，支持教师随时回退复习。
  * 「下一步 ▶」按钮：位于 SVG 内底部 (440,462)，宽 90×28 px；点击后前进一步，按序揭示新的曲线或限制线。
  * 步骤计数器（可选）：在双按钮之间显示 "步骤 k/5"，帮助教师掌握节奏。
- 教师操作流程：
  1. 教师展示步骤 0，讲解坐标系含义与三个临界垂线的物理意义（ω₀²、ω₁²、ω₂²）。
  2. 点击「下一步」进入步骤 1，揭示 f_A 曲线，说明 A 的静摩擦力先达到上限（因 r_A 最大）。
  3. 继续点击「下一步」依次揭示 T_AB、f_B、T_OB，每步配合讲解该力何时出现、斜率为何是 0.2 或 0.3。
  4. 最后进入步骤 5，叠加限制线，高亮 (10,2) 失稳点，总结：T_OB 先达到 2mg，故 ω₂=√(10g) 为系统临界角速度。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript。理由：本场景为静态折线图的分步揭示，无需复杂数学计算或 3D 渲染；SVG 的 polyline/line/text 配合 stroke-dashoffset 动画即可实现流畅的"画线"效果，性能高且依赖零。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  图例(右上)    Y轴                                |
  |  ┌──────┐      |                                 |
  |  │ f_A  │      |    曲线绘图区                     |
  |  │ f_B  │      |    (80,60)–(700,440)             |
  |  │ T_AB │      |                                 |
  |  │ T_OB │      |                                 |
  |  └──────┘      |                                 |
  |                |                                 |
  |  X轴原点(80,440)–X轴终点(700,440)                 |
  |  刻度标签在轴外侧                                |
  |                                                  |
  |        [◀ 上一步]  [下一步 ▶]                    |  ← y=462 控件区
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 `currentStep`（0–5）控制当前步骤。每一步对应一组 SVG 元素的 `display` 或 `opacity` 切换。建议给每个元素设置 `data-step="k"`，表示该元素在第 k 步首次出现；步骤回退时隐藏 step > currentStep 的所有元素。
  2. 画线动画：对每条折线/线段使用 SVG `stroke-dasharray` + `stroke-dashoffset` 动画。初始设 dasharray 为路径总长度，dashoffset 为总长度；通过 CSS transition 或 requestAnimationFrame 将 dashoffset 降至 0，实现从左到右的"绘制"效果，时长 600ms，缓动 ease-out。
  3. 坐标计算：在 JS 中定义函数 `toPxX(v)` 与 `toPxY(v)`，分别返回 80+v*62 与 440-v*152，避免硬编码坐标错误。
  4. 事件绑定：按钮绑定 click 事件，更新 currentStep 后调用 `renderStep()`。在 renderStep 中遍历所有带 data-step 的元素，根据 step <= currentStep 显示/隐藏。上一步按钮在 step=0 时禁用，下一步按钮在 step=5 时禁用。
  5. 高亮圆点动画：步骤 5 中圆点使用 scale 动画（从 r=0 到 r=5，300ms，ease-out）吸引学生注意力。
  6. 限制线绘制：y=2 的蓝色与红色限制线完全重合，通过分别绘制两条虚线（颜色不同）实现；视觉上可能呈现混色，但左右两侧的彩色标注可明确区分含义。
- ID 命名规范：所有 SVG 元素及控件 ID 必须以 `scene2-` 为前缀。例如：
  * 轴线：`scene2-axis-x`、`scene2-axis-y`
  * 曲线：`scene2-line-fA`、`scene2-line-fB`、`scene2-line-TAB`、`scene2-line-TOB`
  * 垂线：`scene2-vline-omega0`、`scene2-vline-omega1`、`scene2-vline-omega2`
  * 标签：`scene2-label-fA`、`scene2-label-TAB-start` 等
  * 按钮：`scene2-btn-prev`、`scene2-btn-next`
  * 在 JS 中统一使用 `document.getElementById` 获取，禁止跨场景 querySelector。
- IIFE 隔离：所有 JavaScript 逻辑包裹在 `(function() { ... })();` 中，避免全局变量污染，确保多场景合并时互不干扰。
