[图示主题与整合说明]
- 本图示主题：动能定理与功-能关系（带电物块在复合轨道中的运动）
- 整合的步骤/概念：
  1. 第一问 M→L 全过程的动能定理：电场力正功、摩擦力负功、重力负功，临界条件 v_L²=gR；
  2. 第二问 M→P 过程的动能定理：电场力做功路径变为 S+R，重力做功变为 −mgR；
  3. 通过状态切换在同一视觉框架下对比两个过程的做功差异，强化“功是过程量、动能定理是同一原理”的认识。
- 教学价值：教师可先讲解状态1（第一问）的完整推导，再点击切换至状态2，让学生观察“哪些功变了、哪些没变”，从而对比理解电场力做功与路径的关系，以及重力做功与高度的关系。

[分步序列]
本场景采用“多状态切换”交互，仅有两个状态，无分步导航序列。

- 初始状态（状态1 — 第一问 M→L）：
  - 路径图：MN 水平轨道 + NL 左半圆弧以黑色粗线（3px）显示；NP 弧段以灰色细线（1px, #cccccc）显示；L 标签显示，P 标签隐藏。
  - 功的卡片：W_E = +qES（蓝），W_f = −μmgS（红），W_g = −mg·2R（红）。
  - 右式：ΔE_k = ½mv_L²（绿）。
  - 底部方程："(qE − μmg)S − 2mgR = ½mv_L²" 与 "v_L² = gR"（绿）。
  - 状态按钮1 为激活样式（蓝底白字），按钮2 为未激活样式（白底红边黑字）。

- 状态2（第二问 M→P）— 点击「第二问 M→P」按钮触发：
  - 路径图：MN 水平轨道 + NP 弧段以黑色粗线（3px）显示；NL 弧段以灰色细线（1px, #cccccc）显示；P 标签显示，L 标签隐藏；P 点标记 circle 显示。
  - 功的卡片：W_E 文字变为 "W_E = +qE(S+R)"（蓝，强调电场力做功路径增加 R）；W_f 不变；W_g 文字变为 "W_g = −mgR"（红，强调重力做功减半）。
  - 右式：ΔE_k 文字变为 "ΔE_k = ½mv_P²"（绿）。
  - 底部方程："qE(S+R) − μmgS − mgR = ½mv_P²" 与 "v_P² = 14 m²/s²"（绿）。
  - 状态按钮2 为激活样式（红底白字），按钮1 为未激活样式（白底蓝边黑字）。

- 点击「第一问 M→L」按钮可回退到状态1，所有元素恢复状态1的显示内容。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript。理由：本场景以静态几何图形、文本标签和简单状态切换为主，无需复杂绘图库；原生 SVG 对文本和路径支持良好，且便于通过 ID 精确控制元素属性。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------------+
  |      [第一问 M→L]  [第二问 M→P]         y=10~45        |
  |  ←←←← E                                                |
  |         .----.                                         |
  |        /      \                                        |
  |       P        L         m                             |
  |        \      /         [■]                            |
  |         '----'           |                             |
  |          N---------------M                             |
  |  y=55~185  简化路径图区                                 |
  |                                                        |
  |  +------------------+        +---------------------+   |
  |  | W_E = +qES       |        |                     |   |
  |  +------------------+   =    |  ΔE_k = ½mv_L²      |   |
  |  | W_f = -μmgS      |        |                     |   |
  |  +------------------+        +---------------------+   |
  |  | W_g = -mg·2R     |                                  |
  |  +------------------+                                  |
  |                                                        |
  |    (qE-μmg)S - 2mgR = ½mv_L²                           |
  |    v_L² = gR                                           |
  |  y=195~430  公式推导区                                  |
  |                                                        |
  |              [重置]                          y=455     |
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `let scene2State = 1;` 记录当前状态（1 或 2）。
  2. 状态切换函数 `scene2SetState(s)`：根据 s 值更新所有相关元素的 `textContent`、`setAttribute('visibility', ...)`、`stroke`、`stroke-width` 以及按钮的 className。
  3. 路径高亮：通过改变弧线路径的 stroke-width 和 stroke 颜色实现当前过程段高亮、非当前段淡化。
  4. 按钮样式切换：通过添加/移除 CSS class（如 `.active-blue`、`.active-red`）改变背景色与文字色。
  5. 动画曲线：状态切换无需复杂动画，直接瞬时切换；若需柔和过渡，可对 opacity 和 transform 使用 CSS transition（0.2s ease）。
  6. 事件绑定：按钮的 `onclick` 绑定到 `scene2SetState`；重置按钮绑定到 `scene2SetState(1)`。
- **ID 命名规范**：所有交互元素 ID 必须以 `scene2-` 为前缀。例如：
  - 路径：scene2-path-mn、scene2-arc-nl、scene2-arc-np
  - 标签：scene2-label-m、scene2-label-n、scene2-label-p、scene2-label-l
  - 卡片：scene2-card-we、scene2-card-wf、scene2-card-wg、scene2-card-ek
  - 文字：scene2-text-we、scene2-text-wf、scene2-text-wg、scene2-text-ek
  - 方程：scene2-eq-line1、scene2-eq-line2
  - 按钮：scene2-btn-state1、scene2-btn-state2、scene2-btn-reset
- IIFE 隔离：所有 JavaScript 代码包裹在 `(function() { ... })();` 中，避免全局污染及多场景合并时的变量冲突。
- 数值常量（便于维护）：在 IIFE 顶部定义 `const SCENE2_QE = 0.2, SCENE2_UMG = 0.16, SCENE2_MG = 0.8, SCENE2_R = 0.4, SCENE2_S = 20, SCENE2_VP2 = 14;`，但图示以展示公式为主，数值仅用于最终结果标注。
