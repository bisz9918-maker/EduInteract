[图示主题与整合说明]
- 本图示主题：圆周运动临界条件与动力学分析（带电物块在复合场中的竖直半圆轨道运动）
- 整合的步骤/概念：
  1. L 点（圆弧最高点）临界条件：轨道支持力 N=0，仅重力提供向心力，推导最小速度 v_L²=gR；
  2. P 点（圆弧最左点）动力学分析：重力 mg（竖直向下）、电场力 qE（水平向左）、轨道支持力 N（水平向右指向圆心）三力合成提供向心力，计算支持力并由牛顿第三定律得压力。
- 教学价值：教师通过两个空间位置的独立放大视图，分别讲解“临界条件”与“三力向心力”两种典型圆周运动模型，避免两图混杂；状态切换按钮便于课堂即时对比。

[分步序列]
本场景采用“多状态切换”交互，仅含两个互斥状态，无逐步动画序列。
- 初始状态（状态1）：
  - 显示状态1组（L点临界）：顶部圆弧、物块、重力mg箭头（红）、向心力F_向虚线箭头（绿）、半径OL、圆心O、R标签、N=0临界标注、方程框及文本。
  - 隐藏状态2组。
  - 按钮样式：「L点临界」为红底白字（激活），「P点受力」为白底黑字（非激活）。
  - 状态标题显示：“状态1：L点临界条件（N = 0）”。
- 切换至状态2（点击「P点受力」按钮）：
  - 隐藏状态1组。
  - 显示状态2组（P点受力）：左部圆弧、物块、重力mg箭头（红）、电场力qE箭头（蓝）、支持力N箭头（绿）、向心力F_向虚线箭头（绿）、半径OP、圆心O、R标签、右侧方程文本、结论框。
  - 按钮样式：「L点临界」为白底黑字（非激活），「P点受力」为蓝底白字（激活）。
  - 状态标题显示：“状态2：P点受力分析”。
- 回退：点击「L点临界」按钮，恢复至初始状态。

[交互方案]
- 交互类型：多状态切换（2 个状态按钮）。
- 控件说明：
  1. 「L点临界」按钮：位置(260,452)，尺寸130×36。作用：切换至状态1，展示L点临界条件。
  2. 「P点受力」按钮：位置(410,452)，尺寸130×36。作用：切换至状态2，展示P点三力受力分析与计算结论。
- 教师操作流程：
  1. 页面加载后默认显示状态1，教师讲解L点临界条件（N=0，重力完全提供向心力，推导v_L最小值）。
  2. 点击「P点受力」按钮，图示切换至状态2，教师讲解P点三力方向（注意电场力水平向左、支持力水平向右指向圆心），列向心力方程，得出支持力N=3.0N，再由牛顿第三定律得压力N'=3.0N方向水平向左。
  3. 可随时点击「L点临界」回退复习，两状态对比强化“不同位置受力图景不同”的核心概念。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript。理由：场景为静态几何图形与矢量箭头，无复杂函数绘图或3D，原生SVG性能最优，且便于通过`<g>`分组控制显隐。
- 画布尺寸：800 × 500 px（SVG 容器固定宽高）。
- 布局草图：
  ```
  +--------------------------------------------------+
  |              状态标题 (y=32)                      |
  |                                                  |
  |     [主图区 y=50~430]                            |
  |     状态1: 圆弧顶部 + 物块 + 向下力箭头 + 方程     |
  |     状态2: 圆弧左部 + 物块 + 三力箭头 + 右侧方程   |
  |                                                  |
  |                                                  |
  |  +------------------+------------------+          |
  |  | [L点临界]        | [P点受力]        | 控件区   |
  |  | (260,452)        | (410,452)        | y=440~490|
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：定义变量 `currentState`，取值 1 或 2。初始值 1。
  2. 分组显隐：SVG 内使用两个 `<g>` 元素，id 分别为 `scene3-state1-group` 和 `scene3-state2-group`。切换时设置 `display` 属性为 `block` 或 `none`。
  3. 按钮样式同步：切换状态时，同步更新两个按钮的 class（`active` / `inactive`），通过 CSS 控制背景色与文字色。
  4. 状态标题同步：切换时更新 id 为 `scene3-state-title` 的 textContent。
  5. 箭头 marker：在 `<defs>` 中定义三个 arrow marker（黑、红、蓝、绿可共用同一形状，仅 fill/stroke 不同），供各箭头 line 元素引用。
  6. 坐标计算：圆弧 path 使用 `A` 指令绘制，状态1圆弧参数 `M 485 255 A 120 120 0 0 1 315 255`；状态2圆弧参数 `M 435 215 A 120 120 0 0 1 435 385`（需根据实际角度校验起点终点）。
  7. 动画曲线：无动画，状态切换为即时显隐（display切换），确保课堂讲解节奏可控。
  8. 事件绑定：按钮通过 `getElementById` 获取，绑定 `click` 事件，在 IIFE 内完成。
- ID 命名规范：
  - 状态1组：`scene3-state1-group`
  - 状态2组：`scene3-state2-group`
  - 状态标题：`scene3-state-title`
  - 按钮1：`scene3-btn-l`
  - 按钮2：`scene3-btn-p`
  - 所有内部元素均以 `scene3-` 为前缀（如 `scene3-s1-arc`、`scene3-s2-mg-arrow` 等）。
- IIFE 隔离：所有 JavaScript 代码包裹在 `(function() { ... })();` 中，避免全局污染及多场景合并时的变量冲突。
