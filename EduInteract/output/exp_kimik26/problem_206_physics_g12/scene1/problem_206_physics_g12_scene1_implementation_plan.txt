[图示主题与整合说明]
- 本图示主题：带电小球在匀强电场中的运动与多次弹性碰撞过程演示
- 整合的步骤/概念：初始静止状态 → A球在电场力作用下匀加速追B球 → 第一次弹性碰撞及速度交换 → A重新加速追匀速B球 → 第二次弹性碰撞及速度交换 → 直至第三次碰撞前的运动规律总结
- 教学价值：教师可通过分步导航逐帧讲解每一阶段的受力、运动学关系和弹性碰撞规律，让学生直观理解"A每次从静止（或某初速）重新匀加速，B以碰后速度匀速，碰撞间隔恒为2t₁"这一核心规律，并可随时回退重讲。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于(280,460)，宽100px，高32px。点击后回退到上一个步骤，隐藏当前步骤特有元素，显示上一步元素。
  - 「下一步 ▶」按钮：位于(420,460)，宽100px，高32px。点击后前进到下一个步骤，显示下一步特有元素。
  - 步骤计数：位于(400,445)，显示当前步骤编号（如"步骤 1/6"）。
- 教师操作流程：
  1. 教师打开图示，首先呈现步骤0（初始状态），向学生说明已知条件：匀强电场E、A带电+q、B不带电、质量均为m、初始间距L。
  2. 点击「下一步」进入步骤1，观察A球匀加速过程，强调A受电场力F=qE，加速度a=qE/m，运动时间t₁=√(2mL/qE)，末速度v₁=√(2qEL/m)。
  3. 点击「下一步」进入步骤2，讲解弹性碰撞规律：质量相等两球弹性碰撞交换速度，因此碰后A静止、B以v₁匀速。
  4. 点击「下一步」进入步骤3，引导学生分析：A从静止重新以a=qE/m加速，B以v₁匀速，相对位移再次为L时发生第二次碰撞，时间间隔为2t₁，A末速度增至2v₁。
  5. 点击「下一步」进入步骤4，再次强调速度交换：碰前v_A=2v₁、v_B=v₁，碰后v_A=v₁、v_B=2v₁。
  6. 点击「下一步」进入步骤5，总结规律：每次碰撞间隔均为2t₁，A的末速度依次为v₁、2v₁、3v₁…，为后续求第n次碰撞的总时间和A的总位移做铺垫。
  7. 可随时点击「上一步」回退到任意步骤重新讲解。

[技术实现]
- JS库选择：原生 SVG（使用 Vanilla JS 操作 DOM）。理由：本场景为简单几何图形（圆、线段、箭头、文本）的状态切换，无需复杂绘图库，原生 SVG 性能最佳且易于精确控制坐标。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |  E →   →   →   →   →                             |  y=50~110 电场区
  |                                                  |
  |         A  ●────L────●  B                         |  y=180~320 主图区
  |            ~  ~  ~  ~  ~  ~  ~  ~  ~  ~           |  （虚线y=250，基线y=280）
  |                                                  |
  |  步骤说明文字                                     |  y=430~440
  |      [◀ 上一步]  步骤 1/6  [下一步 ▶]            |  y=440~490 控件区
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `currentStep`（0~5）记录当前步骤。每个步骤对应一个数据对象，包含该步骤所有可见元素的坐标、文本内容、显示/隐藏状态。
  2. 元素更新函数：`renderStep(stepIndex)` 根据步骤索引更新所有 SVG 元素的属性（cx/cy、x/y、d、textContent、display）。
  3. 坐标计算：球体位置、箭头起点/终点、标签位置均按布局坐标表硬编码，避免运行时计算误差。
  4. 动画曲线：球体移动使用 CSS transition（transform 或 cx/cy 过渡，duration=400ms，ease-out），速度箭头使用 opacity + scale 过渡（200ms），确保视觉流畅但不拖沓。
  5. 事件绑定：上一步/下一步按钮绑定 click 事件，更新 `currentStep` 后调用 `renderStep`，并更新按钮禁用状态（步骤0时禁用「上一步」，步骤5时禁用「下一步」）。
  6. 轨迹线处理：轨迹线采用「累积显示」策略，即进入步骤k时，显示从步骤0到步骤k的所有已走过轨迹，帮助学生建立完整运动路径印象。
  7. 碰撞说明文字：仅在步骤2和步骤4显示，使用绝对定位文本，带轻微上浮动画（translateY -5px，opacity 0→1，300ms）。
- ID命名规范：所有 SVG 元素和 HTML 控件 ID 必须以 `scene1-` 为前缀。例如：
  - A球：`scene1-ball-a`
  - B球：`scene1-ball-b`
  - A速度箭头：`scene1-arrow-va`
  - B速度箭头：`scene1-arrow-vb`
  - 上一步按钮：`scene1-btn-prev`
  - 下一步按钮：`scene1-btn-next`
  - 步骤说明：`scene1-step-desc`
  - 步骤计数：`scene1-step-counter`
- IIFE隔离：所有 JavaScript 代码包裹在 `(function() { ... })();` 中，避免全局变量污染，确保多场景合并时互不干扰。
