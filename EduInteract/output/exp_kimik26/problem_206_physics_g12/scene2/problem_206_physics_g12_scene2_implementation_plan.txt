[图示主题与整合说明]
- 本图示主题：带电小球A与不带电小球B在匀强电场中多次弹性碰撞的v-t图像及碰撞时间规律
- 整合的步骤/概念：v-t坐标系建立 → A的第一段匀加速直线 → 第一次碰撞（速度交换） → A的第二段匀加速直线 → 第二次碰撞（速度交换） → A的第三段匀加速直线 → 时间间隔规律总结
- 教学价值：教师通过分步导航，逐步揭示A球在电场中反复加速、碰撞、再加速的过程，以及B球获得速度后匀速运动的阶梯特征，最终引导学生发现第n次碰撞时刻的等差规律 t_n=(2n-1)t₁

[分步序列]
- 步骤0（初始状态）：显示完整坐标系（横轴t、纵轴v、箭头、网格线）、所有刻度标签（0,t₁,3t₁,5t₁,v₁,2v₁,3v₁）、轴名（t,v）、右侧图例区（图例标题+A/B/碰撞时刻线型说明）。隐藏所有运动曲线、碰撞垂线、斜率标注和规律文字。教师可讲解坐标系物理意义。
- 步骤1（A的第一段加速）：在步骤0基础上，绘制A的第一段蓝色斜线从(100,420)到(190,310)，并显示斜率三角形及标注"a=qE/m"。教师讲解A在电场中从静止开始匀加速，斜率代表加速度a=qE/m。
- 步骤2（第一次碰撞）：新增绿色虚垂线x=190贯穿全图；绘制A的蓝色垂直突降线从(190,310)到(190,420)；绘制B的红色垂直突升线从(190,420)到(190,310)；绘制B的第一段红色水平线从(190,310)到(370,310)。教师讲解弹性碰撞、质量相等交换速度，A速度归零、B获得速度v₁。
- 步骤3（第二段加速）：新增A的第二段蓝色斜线从(190,420)到(370,200)。教师讲解A从静止再次匀加速，B以v₁匀速运动，A的速度再次追上B。
- 步骤4（第二次碰撞）：新增绿色虚垂线x=370；绘制A的蓝色垂直突降线从(370,200)到(370,310)；绘制B的红色垂直突升线从(370,310)到(370,200)；绘制B的第二段红色水平线从(370,200)到(550,200)。教师讲解第二次碰撞再次交换速度，A速度变为v₁，B速度变为2v₁。
- 步骤5（第三段与规律总结）：新增A的第三段蓝色斜线从(370,310)到(550,90)；新增绿色虚垂线x=550；右侧规律区显示"Δt₁=t₁"、"Δt₂=2t₁"、"Δt₃=2t₁"及绿色加粗公式"tₙ=(2n-1)t₁"。教师引导学生观察相邻碰撞时间间隔规律，总结通项公式。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「上一步」按钮：位于(300,458)，宽90px高32px，点击回退到上一分步，步骤0时禁用
  2. 步骤指示器：位于(400,478)，显示当前步骤文字如"步骤 2/6"
  3. 「下一步」按钮：位于(490,458)，宽90px高32px，点击前进到下一分步，步骤5时禁用
- 教师操作流程：教师先展示步骤0讲解坐标系；点击「下一步」依次展示A的加速、碰撞、再加速过程；在步骤2和步骤4重点讲解弹性碰撞速度交换；在步骤5引导学生发现时间间隔规律。可随时点击「上一步」回退复习关键步骤。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本场景为折线、线段、文本的静态/分步显示，无需复杂数学计算或3D渲染，原生SVG足以保证清晰度且便于逐元素控制显隐。
- 画布尺寸：800×500 px（SVG viewBox="0 0 800 500"）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  v↑  图例                                         |
  |   |   ━━━ A球                                      |
  |   |   ━━━ B球                                      |
  |3v₁├─ - - - - - - - - - - - - - - - - - - - -      |
  |   |                    ╱  A第三段                   |
  |2v₁├─ - - - - - - - - ╱ - - - - - - B第二段        |
  |   |      ╱           ●                             |
  | v₁├─ - -╱ - - B第一段 - - - - - - - - - - -       |
  |   |    ●                                           |
  |  O+----+----+----+----+----+----+----+--→ t        |
  |   0   t₁   3t₁   5t₁                              |
  |                                                    |
  |        [◀上一步]  步骤 X/6  [下一步▶]              |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 `currentStep`（0~5）控制当前步骤，每步对应一个元素显隐配置数组 `stepVisibility[6]`，数组每项记录该步应显示的元素ID列表。
  2. 元素显隐：所有可能动态显示的元素初始 `opacity: 0` 或 `display: none`，切换步骤时通过 `setAttribute('opacity', '1')` 或CSS class控制显示。建议使用CSS transition实现0.3s淡入效果。
  3. 折线绘制动画：对斜线段使用SVG `stroke-dasharray` + `stroke-dashoffset` 动画，模拟"绘制"效果。线宽2.5px，dasharray等于路径总长度，通过JS计算或预估长度。
  4. 突变线段（垂直速度跳变）：直接淡入显示，时长0.2s，表示碰撞瞬间完成。
  5. 碰撞垂线：绿色虚线使用 `stroke-dasharray="5,5"`，淡入显示。
  6. 坐标计算：t轴每单位t₁对应90px，v轴每单位v₁对应110px。所有关键点坐标硬编码，避免运行时计算误差。
  7. 按钮状态：步骤0禁用「上一步」，步骤5禁用「下一步」，通过添加/移除 `disabled` class改变样式（透明度0.4，cursor:not-allowed）。
  8. 右侧规律区：步骤5时整体淡入显示，公式"tₙ=(2n-1)t₁"使用绿色加粗字体（font-weight:bold, fill:#2e7d32）。
- ID命名规范：所有交互元素ID以 `scene2-` 为前缀。例如：
  - 坐标轴：`scene2-axis-x`、`scene2-axis-y`
  - A曲线段：`scene2-curve-a-seg1`、`scene2-curve-a-seg2`、`scene2-curve-a-seg3`
  - A突变线：`scene2-jump-a-1`、`scene2-jump-a-2`
  - B曲线段：`scene2-curve-b-seg1`、`scene2-curve-b-seg2`
  - B突变线：`scene2-jump-b-1`、`scene2-jump-b-2`
  - 碰撞垂线：`scene2-collision-line-1`、`scene2-collision-line-2`、`scene2-collision-line-3`
  - 斜率标注：`scene2-slope-tri-h`、`scene2-slope-tri-v`、`scene2-slope-label`
  - 规律文字：`scene2-rule-dt1`、`scene2-rule-dt2`、`scene2-rule-dt3`、`scene2-rule-formula`
  - 按钮：`scene2-btn-prev`、`scene2-btn-next`、`scene2-step-indicator`
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })()` 中，避免全局变量污染，确保多场景合并时互不干扰。
- 事件绑定：按钮点击事件直接通过 `document.getElementById('scene2-btn-prev').addEventListener('click', ...)` 绑定，不使用内联onclick。
