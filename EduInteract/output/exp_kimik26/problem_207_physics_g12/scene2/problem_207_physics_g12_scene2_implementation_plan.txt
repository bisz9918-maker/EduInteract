[图示主题与整合说明]
- 本图示主题：A 与 B 在不同阶段的隔离体受力分析
- 整合内容：将题目中三个关键力学情境（A 沿斜面下滑、A 在 B 上表面滑行、木板 B 受地面作用）整合为同一画布下的分步隔离体图。通过分步导航，教师可逐一展示各阶段研究对象的受力，避免所有力同时出现造成视觉混乱。
- 教学价值：教师可先引导学生回顾斜面受力，再隔离 A 分析水平段受力，最后转换研究对象到 B，逐步建立牛顿第二定律方程。分步回退功能便于教师随时返回某一步追问学生力的方向与大小。

[视觉元素清单]
- 几何图形：地面水平线、斜面线段、滑块 A（矩形）、木板 B（矩形）、角度弧
- 力箭头：共 11 支力箭头（3 步合计），均带箭头头部（marker-end）
  - 重力：竖直向下，黑色 #000000，线宽 2px
  - 支持力/压力：垂直接触面向上或向下，蓝色 #1565c0，线宽 2px
  - 摩擦力：沿接触面，红色 #c62828，线宽 2px（f₂′ 线宽 3px 以突出相互作用）
- 辅助线：重力分解两虚线箭头，灰色 #888888，stroke-dasharray="4,3"，线宽 1px
- 标注框：两步的加速度旁注，绿色 #2e7d32 虚线矩形，内文字绿色
- 文字标签：仅含符号与数值，黑色 #000000，字号 13~14px，无解释性句子
- 背景：纯白 #ffffff
- 地面纹理：SVG pattern 绘制 45° 细斜线，表示粗糙地面

[分步序列]
- 初始状态（步骤 1，index 0）：显示斜面、地面、滑块 A 及 A 所受三力（mg、N₁、f₁），并画出重力沿斜面/垂直斜面的分解虚线，标注 α=37°。教师讲解 A 在斜面上的正交分解。
- 步骤 2（index 1）：点击「下一步」→ 步骤 1 元素淡出，步骤 2 元素淡入。显示水平地面、木板 B、滑块 A，画出 A 在 B 上表面时的三力（mg、N₂、f₂），右侧出现绿色虚线框标注 aₐ = 5 m/s²。教师讲解隔离 A 后的水平方向牛顿定律。
- 步骤 3（index 2）：点击「下一步」→ 步骤 2 元素淡出，步骤 3 元素淡入。显示地面、B、A（A 用浅灰填充示意非分析主体），画出 B 所受五力（B 自身 mg、N₂′、f₂′、N₃、f₃），右侧绿色虚线框标注 aʙ = (5−20μ₂) m/s²。教师讲解转换研究对象到 B，并对比 f₂ 与 f₂′ 的作用力反作用力关系。
- 回退：教师可随时点击「上一步」返回前两步复习，按钮在边界步骤自动禁用。

[标签冲突检查]
步骤 1 标签坐标及检查：
- "mg"：(178, 350)
- "N₁"：(200, 275)
- "f₁=μ₁N₁"：(115, 300)
- "mg sin α"：(200, 345)
- "mg cos α"：(135, 348)
- "α=37°"：(305, 395)
逐对检查：
- "mg" 与 "mg sin α"：间距 √(22²+5²) ≈ 23 px ≥ 20 px，无冲突
- "mg" 与 "mg cos α"：间距 √(43²+2²) ≈ 43 px，无冲突
- "N₁" 与 "mg sin α"：间距 70 px，无冲突
- "f₁=μ₁N₁" 与 "mg cos α"：间距 √(20²+48²) ≈ 52 px，无冲突
- "mg sin α" 与 "mg cos α"：间距 √(65²+3²) ≈ 65 px，无冲突
- 其余各对间距均 > 70 px

步骤 2 标签坐标及检查：
- "mg"：(340, 390)
- "N₂"：(335, 300)
- "f₂=μ₁mg"：(255, 355)
- "aₐ = μ₁g = 5 m/s²"：(615, 365)
逐对检查：
- "mg" 与 "N₂"：间距 90 px，无冲突
- "mg" 与 "f₂=μ₁mg"：间距 √(85²+35²) ≈ 92 px，无冲突
- "N₂" 与 "f₂=μ₁mg"：间距 √(80²+55²) ≈ 97 px，无冲突
- 加速度文字在右侧框内，与左侧各标签间距 > 130 px

步骤 3 标签坐标及检查：
- "mg"（B 重力）：(385, 415)
- "N₂′=mg"：(335, 405)
- "f₂′=μ₁mg"：(425, 365)
- "N₃=2mg"：(385, 330)
- "f₃=2μ₂mg"：(185, 395)
- "aʙ = (5-20μ₂) m/s²"：(620, 365)
逐对检查：
- "mg" 与 "N₂′=mg"：间距 √(50²+10²) ≈ 51 px，无冲突
- "N₂′=mg" 与 "f₂′=μ₁mg"：间距 √(90²+40²) ≈ 98 px，无冲突
- "f₂′=μ₁mg" 与 "N₃=2mg"：间距 √(40²+35²) ≈ 53 px，无冲突
- "N₃=2mg" 与 "mg"：同 x 间距 85 px，无冲突
- "f₃=2μ₂mg" 与其余左侧标签间距均 > 100 px
- 加速度文字在右侧框内，与其余标签间距 > 130 px

结论：所有步骤内部标签间距均 ≥ 20 px，无重叠风险。

[交互方案]
- 交互类型：分步按钮导航（◀ 上一步 / 下一步 ▶）
- 控件说明：
  1. 「上一步」按钮：位于画布底部偏左 (250, 455)，宽 100×32 px。点击回退一步，当前为第 1 步时禁用（opacity 0.4）。
  2. 「下一步」按钮：位于画布底部偏右 (450, 455)，宽 100×32 px。点击前进一步，当前为第 3 步时禁用。
  3. 步骤指示文本：位于两按钮之间 (400, 475)，显示 "1/3"、"2/3"、"3/3"。
- 教师操作流程：
  1. 教师打开图示，默认显示步骤 1（A 在斜面），配合讲解重力分解与支持力、摩擦力方向。
  2. 点击「下一步」进入步骤 2，强调隔离 A 后水平方向仅受摩擦力，引出加速度 5 m/s²。
  3. 点击「下一步」进入步骤 3，转换研究对象为 B，逐一确认 N₂′ 与 f₂′ 是 A 对 B 的作用力，并对比 N₃、f₃ 与 B 重力的关系，列出 B 的加速度表达式。
  4. 可随时点击「上一步」回退，让学生复述某一步的受力个数与方向。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript。理由：本场景为静态几何图形与箭头，无复杂函数绘图或 3D，原生 SVG 足以保证清晰度且无需额外库加载。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图：
  ```
  +--------------------------------------------------+
  |  隔离体受力分析                     (总标题)       |  y=0~80
  |  步骤 1/3：A 在斜面上的受力          (步骤标题)    |
  |                                                  |
  |         [主图区：斜面/水平面/滑块/力箭头]          |  y=80~420
  |                                                  |
  |                                                  |
  +--------------------------------------------------+
  |    [◀ 上一步]      1/3      [下一步 ▶]           |  y=440~490
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机：用变量 `currentStep`（0~2）记录当前步骤。初始化显示步骤 1。
  2. 分组管理：每一步的所有 SVG 元素包在一个 `<g id="scene2-step1-group">`（及 step2、step3）中。切换时设置对应组的 `display: block` 与 `display: none`，或 `opacity` 过渡（transition: opacity 0.25s ease）。
  3. 箭头头部：在 `<defs>` 中定义三个 marker（黑色 arrow-black、蓝色 arrow-blue、红色 arrow-red），供各力箭头引用。
  4. 地面粗糙纹理：在 `<defs>` 中定义 pattern，用 45° 细斜线填充地面矩形（y=400 以下薄层或直接用线纹理）。
  5. 按钮禁用逻辑：`currentStep === 0` 时禁用「上一步」；`currentStep === 2` 时禁用「下一步」。
  6. 坐标计算：斜面倾角 37°（sin≈0.6，cos≈0.8），所有箭头终点严格按方向向量与长度计算，确保视觉方向正确。
  7. 作用力与反作用力提示：步骤 3 中 f₂′ 使用线宽 3px，并在教师讲解时可通过短暂高亮（如改变 stroke-opacity 或添加发光 filter）与步骤 2 的 f₂ 建立隐性对应（若未来需跨步高亮可扩展）。
- ID 命名规范：所有 SVG 元素及控件 ID 必须以 `scene2-` 为前缀。示例：
  - `scene2-title`、`scene2-step-title`、`scene2-step-indicator`
  - `scene2-btn-prev`、`scene2-btn-next`
  - `scene2-step1-group`、`scene2-step2-group`、`scene2-step3-group`
  - `scene2-slope`、`scene2-ground`、`scene2-block-a`、`scene2-plank-b`
  - `scene2-arrow-mg-s1`、`scene2-label-mg-s1`、`scene2-arrow-n1`、`scene2-arrow-f1`
  - `scene2-arrow-mg-s2`、`scene2-arrow-n2`、`scene2-arrow-f2`、`scene2-accel-box-s2`
  - `scene2-arrow-mg-b`、`scene2-arrow-n2p`、`scene2-arrow-f2p`、`scene2-arrow-n3`、`scene2-arrow-f3`、`scene2-accel-box-s3`
  JS 中严格使用 `document.getElementById` 获取，禁止全局 class 选择，避免多场景合并时污染。
- IIFE 隔离：所有本场景 JavaScript 代码包在 `(function() { ... })();` 中，变量不泄漏全局作用域。
