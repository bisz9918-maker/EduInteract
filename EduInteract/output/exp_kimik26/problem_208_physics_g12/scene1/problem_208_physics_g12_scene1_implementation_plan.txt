[图示主题与整合说明]
- 本图示主题：平行板间带电粒子的匀速直线运动与类平抛运动对比分析
- 整合的步骤/概念：
  1) 板间同时存在匀强电场E与匀强磁场B₀，正离子受力平衡做匀速直线运动（速度选择器原理，qE = qv₀B₀）；
  2) 撤去B₀后，正离子仅在电场力作用下做类平抛运动，从下极板右边缘M点射出；
  3) 在M点进行速度分解，出射方向与水平成30°角，建立速度三角形关系（tan30° = v_y/v₀，v = v₀/cos30°）。
- 教学价值：教师通过分步导航，可逐层展开"平衡态→偏转态→速度分析"的认知递进，随时回退强调受力平衡或速度分解的关键关系。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「上一步」按钮：位置(280,455)，大小80×30，点击回退到上一分步；在步骤0时禁用（gray样式）。
  2. 「下一步」按钮：位置(400,455)，大小80×30，点击前进到下一分步；在步骤3时禁用。
  3. 步骤指示器：位置(360,485)，显示当前步骤文字如"步骤 1/4"。
- 教师操作流程：
  1. 教师打开图示，先展示步骤0，介绍平行板电容器与下方磁场区域的几何关系；
  2. 点击「下一步」进入步骤1，讲解速度选择器原理，强调F_E与F_B二力平衡；
  3. 点击「下一步」进入步骤2，对比撤去磁场后的类平抛轨迹，强调电场力导致的偏转；
  4. 点击「下一步」进入步骤3，在M点进行速度分解，建立30°角与速度分量的定量关系；
  5. 讲解中可随时回退，强化学生记忆。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本场景为静态几何图形与分步显隐，无需复杂数据绑定或3D渲染，原生SVG性能最优、可控性最强。
- 画布尺寸：800×500 px（固定）。
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  [+] 上板                                        |
  |   | 电场线(E)                                    |
  |  --v₀----->  轨迹(直线/抛物线)                   |
  |   |                                              |
  |  [-] 下板 ---M┌──────────────────N               |
  |             │  · · · · · · · · · │ d             |
  |             │  · 磁场区域 · · ·  │               |
  |             │  · · · · · · · · · │               |
  |             P──────────────────Q                 |
  |                                                  |
  |        [◀上一步]  步骤 x/4  [下一步▶]            |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 `scene1_step`（0~3）记录当前步骤。每次点击按钮时更新状态，调用 `scene1_render()` 根据状态显隐元素。
  2. 显隐控制：所有分步专属元素设置 `display:none`（初始），在对应步骤通过 `getElementById` 获取并设置 `display:block` 或 `visibility:visible`。禁止用 `querySelectorAll` 配合全局class，避免多场景合并污染。
  3. 坐标计算：抛物线轨迹使用SVG `<path d="M 120 125 Q 285 220 450 180"/>`；角度弧使用SVG `<path>` 的arc命令（A指令），中心(450,180)，半径20，从0°到30°。
  4. 动画曲线：本场景为分步切换，无需连续动画；步骤切换为即时显隐（无淡入淡出），确保教学节奏紧凑。
  5. 事件绑定：按钮 `onclick` 直接绑定IIFE内部函数 `scene1_prev()` 与 `scene1_next()`。
  6. 箭头marker：在SVG `<defs>` 中定义通用箭头marker（id="scene1-arrow-black"、"scene1-arrow-blue"、"scene1-arrow-red"），供轨迹、受力、速度箭头复用。
  7. 磁场点阵：用JavaScript循环生成圆点，x从465到685步进30，y从195到375步进30，插入到SVG组 `<g id="scene1-dots">` 中。
- ID命名规范：所有交互元素ID必须以 `scene1-` 为前缀。例如：
  - 图形：`scene1-plate-top`、`scene1-plate-bottom`、`scene1-mag-region`、`scene1-trajectory-line`、`scene1-trajectory-parabola`
  - 受力：`scene1-force-fe`、`scene1-force-fb`
  - 速度：`scene1-vel-v0`、`scene1-vel-vy`、`scene1-vel-v`
  - 角度：`scene1-angle-arc`
  - 标签：`scene1-label-E`、`scene1-label-B0`、`scene1-label-delta-y` 等
  - 控件：`scene1-btn-prev`、`scene1-btn-next`、`scene1-step-indicator`
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免全局变量污染。
