[图示主题与整合说明]
- 本图示主题：斜面物块受力分析与动摩擦因数推导（对应图(a)斜面场景）
- 整合的步骤/概念：固定斜面与物块示意图 → 上滑阶段三力受力分析（含重力正交分解） → 下滑阶段三力受力分析（摩擦力反向） → 牛顿第二定律列方程 → 联立消元求解μ的完整代数推导
- 教学价值：教师可先让学生观察斜面几何与v-t图背景，再分步揭示上滑/下滑的摩擦力方向差异，建立"方向决定符号"的直观印象；随后通过受力的定量分解过渡到方程联立，最终得到μ的表达式。分步导航让教师完全掌控课堂节奏，每步聚焦一个认知层次。

[分步序列]
- 初始状态（步骤0）：
  - 左侧显示：斜面三角形、水平地面、物块（含"m"标签）、角度弧线（含"θ"标签）
  - 右侧公式区显示：标题"已知条件"，三行文本——"斜面倾角：θ"、"初速度：v₀"、"上滑时间t₁，下滑时间2t₁，末速度大小v₁"
  - 所有受力矢量、分解虚线、公式均隐藏
  - 步骤指示器："步骤 1/4"

- 步骤1（上滑受力分析）：
  - 点击「下一步」进入
  - 左侧新增：重力mg（黑色竖直向下）、支持力N（蓝色垂直斜面向上）、摩擦力f（红色沿斜面向下）
  - 左侧新增：重力分解虚线（沿斜面向下分量+垂直斜面向下分量+两条辅助虚线）
  - 左侧新增标签："mg"、"N"、"f"、"mg sinθ"、"mg cosθ"
  - 右侧公式区切换为：标题"上滑阶段受力分析"（红色），公式"mg sinθ + μmg cosθ = ma₁"（红色高亮），标注"...(1)"
  - 步骤指示器："步骤 2/4"

- 步骤2（下滑受力分析）：
  - 点击「下一步」进入
  - 左侧变化：摩擦力f箭头方向反向（改为蓝色沿斜面向上），"f"标签移至箭头右侧(235,295)
  - 左侧保持：重力mg、支持力N、重力分解虚线、其余标签不变
  - 右侧公式区切换为：标题"下滑阶段受力分析"（蓝色），公式"mg sinθ − μmg cosθ = ma₂"（蓝色高亮），标注"...(2)"
  - 步骤指示器："步骤 3/4"

- 步骤3（联立推导）：
  - 点击「下一步」进入
  - 左侧保持：步骤2的受力图（或可选择性淡化分解虚线，仅保留mg、N、f以不分散注意力）
  - 右侧公式区扩展为完整推导：
    - 行1: "(1): mg sinθ + μmg cosθ = ma₁"
    - 行2: "(2): mg sinθ − μmg cosθ = ma₂"
    - 行3: "(1) − (2):"（绿色高亮背景）
    - 行4: "2μmg cosθ = m(a₁ − a₂)"
    - 行5: "μ = (a₁ − a₂) / (2g cosθ)"
    - 行6: "其中 a₁ = v₀/t₁ ,  a₂ = v₁/(2t₁)"（灰色辅助说明）
    - 行7: "μ = [v₀/t₁ − v₁/(2t₁)] / (2g cosθ)"
    - 行8: "μ = (2v₀ − v₁) / (4g t₁ cosθ)"（绿色高亮背景+加粗，最终答案）
  - 步骤指示器："步骤 4/4"

- 教师可随时点击「上一步」回退到任意步骤复习。

[交互方案]
- 交互类型：分步按钮导航（◀ 上一步 / 下一步 ▶）
- 控件说明：
  - 「上一步」按钮：位于画布底部偏左 (260,455)，宽80×高30，点击回退到上一状态
  - 「下一步」按钮：位于画布底部偏右 (440,455)，宽80×高30，点击前进到下一状态
  - 步骤指示器：位于两按钮之间 (360,460)，显示当前步骤编号如"步骤 2/4"
  - 初始状态步骤0时，「上一步」禁用；步骤3时，「下一步」禁用（或循环回步骤0，建议禁用更明确）
- 教师操作流程：
  1. 教师打开图示，学生看到斜面物块与已知条件（步骤0）
  2. 教师点击「下一步」，出现上滑三力与分解，讲解"为什么摩擦力向下"，配合右侧红色公式
  3. 教师点击「下一步」，摩擦力反向变蓝，讲解"下滑时摩擦力向上"，配合右侧蓝色公式
  4. 教师点击「下一步」，进入联立推导，逐行讲解消元过程，最终聚焦绿色高亮的μ表达式
  5. 讲解中可随时回退复习受力方向或公式来源

[技术实现]
- JS库选择：原生 SVG + 原生 JavaScript（无需外部库）。理由：场景以静态几何图形、矢量箭头、文本标签为主，SVG的marker、path、polygon、text完全满足需求；公式为纯文本线性方程，无需MathJax。
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  +--------------------------------------------------+
  |  [左侧图示区 ~480px]        [右侧公式区 ~280px]   |
  |                                                  |
  |      斜面△                                        |
  |       /                                          |
  |      /  物块□              公式推导文本            |
  |     /   ↓mg                （按步骤切换）          |
  |    /    ↑N                                       |
  |   /_____↗f（方向切换）                             |
  |   θ                                               |
  |                                                  |
  |                                                  |
  +--------------------------------------------------+
  |      [◀ 上一步]  步骤 k/4  [下一步 ▶]            |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. **状态机设计**：定义 state = 0|1|2|3，每步对应一个显示配置对象，记录各SVG元素的visibility属性。
  2. **矢量箭头**：使用SVG `<marker>` 定义黑/红/蓝三种箭头端点，在 `<defs>` 中预定义，通过 `marker-end="url(#arrow-black)"` 等方式引用。
  3. **重力分解虚线**：使用 `<line>` 或 `<path>` 设置 `stroke-dasharray="5,5"`，颜色 `#888888`。
  4. **公式区切换**：每步预先创建所有公式文本元素（或按步动态创建），通过 `display` 或 `visibility` 属性控制显示；步骤3的8行公式使用同一个容器，通过显示/隐藏整组元素实现切换。
  5. **颜色高亮**：通过给文本元素设置 `fill` 属性（红/蓝/绿）或给 `<tspan>` / `<rect>` 背景高亮实现。
  6. **按钮禁用逻辑**：state===0时禁用「上一步」，state===3时禁用「下一步」，通过添加/移除 `disabled` 属性或改变透明度表示。
  7. **动画曲线**：本场景以瞬间切换为主（无平滑动画），若需增强可读性，可在步骤切换时给新增元素添加0.2s的fade-in（opacity 0→1）。
  8. **事件绑定**：按钮点击事件直接修改state并调用 `render()` 函数重新应用显示配置。
- **ID命名规范**：所有SVG元素及JS访问的DOM节点ID必须以 `scene2-` 为前缀。例如：
  - 斜面：`scene2-slope`
  - 物块：`scene2-block`
  - 重力箭头：`scene2-force-mg`
  - 上滑摩擦力：`scene2-force-f-up`
  - 下滑摩擦力：`scene2-force-f-down`
  - 公式行1：`scene2-formula-line1`
  - 上一步按钮：`scene2-btn-prev`
  - 下一步按钮：`scene2-btn-next`
  - JS中严格使用 `document.getElementById('scene2-xxx')`，禁止用 `querySelectorAll` 配合全局class。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免多场景合并时的变量污染。
