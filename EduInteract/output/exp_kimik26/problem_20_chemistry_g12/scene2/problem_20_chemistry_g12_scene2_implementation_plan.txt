# Scene 2 Implementation Plan

<SCENE_VISION_STORYBOARD_AND_TECHNICAL_PLAN>

[图示主题与整合说明]
- 本图示主题：饱和NaCl溶液中C棒-Fe棒体系的原电池与电解池双模式电极反应
- 整合内容：
  1. 步骤0展示静态离子分布（Na⁺、Cl⁻、O₂、H⁺、OH⁻在溶液中的初始均匀分布）；
  2. 步骤1展示原电池模式（断开K₂、闭合K₁）：Fe负极氧化、C正极吸氧还原、电子流向、离子定向迁移；
  3. 步骤2展示电解池模式（断开K₁、闭合K₂）：电源接入、Fe阳极溶解、C阴极析氢、电子流向、离子定向迁移。
- 教学价值：教师可通过「上一步/下一步」逐层揭示微观粒子行为，先建立离子分布图景，再分别呈现两种电化学模式的电极反应、电子转移与离子迁移，避免信息过载，便于学生对比记忆。

[分步序列]
- 初始状态（步骤0）：静态离子分布
  → 显示元素：烧杯轮廓、溶液填充、C棒、Fe棒、C/Fe标签、溶液名称、基础导线（C导线、Fe导线、水平导线，K1断开）、全部Na⁺(8个)、全部Cl⁻(8个)、O₂(2个，液面附近)、H⁺(2个)、OH⁻(2个)
  → 隐藏元素：电源、K2、电子箭头、离子移动箭头、反应式、Fe²⁺、OH⁻生成、H₂气泡
  → 教学意图：建立溶液中初始离子分布的宏观图景

- 步骤1：原电池反应（断开K₂，闭合K₁）
  → 点击「下一步」后视觉变化：
    1. K1由断开变为闭合（水平导线连通）
    2. 隐藏H⁺(2个)、OH⁻(2个)（步骤0的原有微量离子，避免与生成物混淆）
    3. 显示电子箭头1、2（水平导线上从Fe→C的红色箭头）
    4. 显示e⁻标注(410,115)
    5. 显示Fe反应式框+文（Fe棒右侧）
    6. 显示C反应式框1+文（C棒左侧，吸氧还原）
    7. 显示Fe²⁺生成1、2（Fe棒左侧附近，棕色）
    8. 显示OH⁻生成1、2（C棒右侧附近，紫色）
    9. 显示Na⁺移动箭头1、2（蓝色，指向C棒）
    10. 显示Cl⁻移动箭头1、2（绿色，指向Fe棒）
  → 教学意图：讲解原电池原理，Fe为负极发生氧化，C为正极发生吸氧还原，阳离子向正极、阴离子向负极迁移

- 步骤2：电解池反应（断开K₁，闭合K₂）
  → 点击「下一步」后视觉变化：
    1. K1断开（水平导线出现间隙）
    2. 显示电源符号（烧杯上方居中）
    3. 显示电源左引线、右引线
    4. 显示K2闭合
    5. 显示电源+、电源−标签
    6. 隐藏步骤1的C反应式框1+文、电子箭头1、2
    7. 显示电子箭头3（右引线，电源正极→Fe，向下）、电子箭头4（左引线，C→电源负极，向上）
    8. 显示C反应式框2+文（C棒左侧，析氢还原）
    9. 保留Fe反应式框+文（Fe棒右侧，阳极溶解）
    10. 保留Fe²⁺生成1、2、OH⁻生成1、2
    11. 保留Na⁺移动箭头1、2、Cl⁻移动箭头1、2（方向与步骤1相同，因C仍为阴极、Fe为阳极）
    12. 显示H₂标注(350,230)
    13. 显示H₂气泡1-4（C棒附近浅灰圆圈）
  → 教学意图：讲解电解池原理，外接电源后Fe作阳极溶解、C作阴极析氢，对比原电池与电解池的电极反应差异

- 最终步骤：即步骤2，展示完整电解池图景，所有结论已呈现
- 教师可随时点击「上一步」回退到步骤0或步骤1复习

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「◀ 上一步」按钮：位置(300,455)，宽90×高32，点击回退到上一状态，步骤0时禁用
  2. 「下一步 ▶」按钮：位置(430,455)，宽90×高32，点击推进到下一状态，步骤2时禁用
  3. 步骤指示文本：位置(400,448)，显示"步骤 1 / 3"等，随状态更新
- 教师操作流程：
  1. 教师展示步骤0，讲解饱和NaCl溶液中存在的离子与溶解氧；
  2. 点击「下一步」进入步骤1，讲解原电池模式：Fe为负极失电子，C为正极O₂得电子，电子经导线从Fe流向C，Na⁺向C移动、Cl⁻向Fe移动；
  3. 点击「下一步」进入步骤2，讲解电解池模式：外接电源后Fe为阳极失电子溶解，C为阴极H₂O得电子析氢，Na⁺向C（阴极）移动、Cl⁻向Fe（阳极）移动；
  4. 可随时点击「上一步」回退对比两种模式的异同。

- 关键实现要点：
  1. 状态机设计：定义 `state = 0|1|2`，数组 `stepConfig[3]` 存储每步应显示/隐藏的元素ID列表。切换步骤时遍历列表设置 `style.display = 'block'/'none'`。
  2. 元素分组：用 `<g id="scene2-step0-group">`、`<g id="scene2-step1-group">`、`<g id="scene2-step2-group">` 包裹各步骤专属元素，通过控制组的显示实现批量切换。
  3. 箭头标记：在 `<defs>` 中定义 `<marker id="scene2-arrow-red">`、`<marker id="scene2-arrow-blue">`、`<marker id="scene2-arrow-green">`，供电子箭头和离子箭头复用。
  4. 开关状态：K1断开时水平导线画为两段短线，中间留10px间隙；K1闭合时画为连续线段。K2仅在步骤2显示为闭合线段。
  5. 电源符号：步骤2时显示电池组（上横线、下横线、左短竖线负极蓝、右长竖线正极红）。
  6. 按钮禁用逻辑：state===0时禁用「上一步」，state===2时禁用「下一步」，通过设置 `disabled` 属性和透明度0.4表示。
  7. 坐标计算：所有坐标硬编码，严格遵循布局坐标表，确保代码agent可直接复制使用。
- ID命名规范：所有交互元素ID必须以 `scene2-` 为前缀。例如：`scene2-beaker-left-wall`、`scene2-electrode-c`、`scene2-reaction-fe-box`、`scene2-btn-prev`、`scene2-step-indicator`。JS中使用 `document.getElementById` 获取元素，禁止用 `querySelectorAll` 配合全局class，避免多场景合并时跨场景污染。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，变量不泄露全局作用域。
- 事件绑定：按钮点击直接绑定 `onclick` 属性或 `addEventListener`，在IIFE内部执行状态切换函数 `scene2GoToStep(n)`。
