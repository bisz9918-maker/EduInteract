    **题目原文**

    如图，边长都是1的正方形和正三角形，其一边在同一水平线上，三角形沿该水平线自左向右匀速穿过正方形．设穿过的时间为t，正方形与三角形重合部分的面积为S（空白部分），那么S关于t的函数大致图象为（　　）

    **整体分析**

    本题的核心是建立重叠面积 S 关于时间 t 的分段函数，并判断其图象形状。由于正三角形与正方形底边等长（均为1），且正三角形的高为 √3/2 < 1，因此三角形在竖直方向上始终不会超出正方形，但在水平方向上，两者宽度相同意味着三角形几乎不存在“完全进入后保持不动”的平台期。

    运动全过程可分为四个阶段：

    1. **进入初期（0 ≤ t ≤ 0.5）**：正方形左边界切割三角形的右腰，重叠区域是一个逐渐变大的小三角形，面积按二次函数增长。
    2. **进入后期（0.5 ≤ t ≤ 1）**：三角形顶点已进入正方形，左边界开始切割左腰，面积继续增大但增速减缓，直至 t=1 时达到最大值（整个正三角形的面积 √3/4）。
    3. **离开初期（1 ≤ t ≤ 1.5）**：三角形右腰开始超出正方形右边界，重叠面积从最大值逐渐减小。
    4. **离开后期（1.5 ≤ t ≤ 2）**：三角形左腰被右边界切割，重叠区域迅速缩小至0。

    关键几何特征是：在原点 t=0 和终点 t=2 处，重叠面积 S 的变化率均为0（切线水平），因此图象在这两处应与横轴光滑相切；而在 t=0.5 和 t=1.5 处，曲线的凹凸性发生转变（二阶导数不连续），形成肉眼可见的“拐点”。

    **图示规划说明**

    - Scene 1 用于动态演示三角形穿过正方形的全过程，并通过滑块交互实时生成 S-t 曲线，帮助学生从直观几何过渡到抽象函数。
    - Scene 2 用于对比四个选项，通过分步排除法确认正确答案为 B。

    **Scene 1 教学说明：如何引导学生观察与推导**

    教师在使用 Scene 1 时，建议按照“整体感知 → 局部分析 → 公式验证 → 图象特征”的递进顺序讲解：

    1. **整体感知**：先将滑块从 0 缓慢拖到 2，让学生直观看到“重叠区域从无到有、从小到大、再从大到无”的全过程，建立动态表象。
    2. **局部分析**：回到 t≈0.2 的位置，让学生观察重叠区域的形状——它是一个直角三角形吗？不，它的左边是正方形的垂直边界，右边是三角形的斜腰，底边在水平线上。引导学生发现：由于正三角形底角为 60°，当水平进入深度为 t 时，重叠三角形的高为 √3·t，因此面积 S 与 t² 成正比，而非与 t 成正比。这是排除选项 A 的关键。
    3. **关键位置定格**：
       - 停在 **t=0.5**：此时三角形顶点刚好到达正方形左边界。让学生注意，在此之前曲线是“凹向上”的（增速越来越快），在此之后进入第二阶段，曲线变为“凹向下”（增速越来越慢）。
       - 停在 **t=1**：三角形底边与正方形底边完全重合，重叠面积达到最大值，即正三角形的总面积 S_max = √3/4。强调：由于两者等宽，不存在“完全进入后还保持一段时间”的平台期，因此排除选项 C。
       - 停在 **t=1.5**：与 t=0.5 对称，开始离开后期。
    4. **公式验证**：在信息面板中展示分段公式，带领学生计算：
       - 当 0 ≤ t ≤ 0.5 时，S = (√3/2) t²；
       - 当 0.5 ≤ t ≤ 1 时，S = √3/4 − (√3/2)(1−t)²；
       - 当 1 ≤ t ≤ 1.5 时，S = √3/4 − (√3/2)(t−1)²；
       - 当 1.5 ≤ t ≤ 2 时，S = (√3/2)(2−t)²。
    5. **图象特征总结**：强调 S(0)=0 且 S′(0)=0，S(2)=0 且 S′(2)=0，所以曲线在原点和终点都与横轴**光滑相切**（水平切线），整体呈圆顶状，而非尖顶。这为 Scene 2 排除选项 D 埋下伏笔。

    **Scene 2 教学说明：选项排除的逻辑链**

    教师在讲解 Scene 2 时，应带领学生形成“由几何特征否定图象特征”的推理链条，而非凭感觉猜测：

    1. **否定 A（线性）**：从 Scene 1 已经看到，进入阶段重叠区域是一个相似小三角形，其面积与边长的平方成正比，而边长又与时间 t 成正比，因此 S ∝ t²，图象必然是曲线而非直线。

    2. **否定 C（梯形）**：梯形意味着存在一段“面积恒定不变”的平台期。这要求三角形完全进入正方形后，还能在内部保持一段时间。但正方形与正三角形底边等长（均为1），三角形完全进入正方形仅发生在底边恰好对齐的一个瞬间（t=1），随后立即开始离开。因此平台期不存在。

    3. **否定 D（尖峰）**：尖峰图象通常在起点处斜率不为零，且顶点处不可导（尖锐）。但从 Scene 1 的分段公式可知，S′(0)=0（水平相切），S′(1)=0（顶部圆滑可导），因此 D 与实际计算矛盾。

    4. **确认 B（光滑曲线）**：B 满足所有几何约束：起点和终点与横轴光滑相切；上升过程先凹向上、后凹向下（存在拐点）；关于 t=1 对称；最大值在 t=1 处取得且顶部圆滑。

    **课堂讲解建议**

    - 建议先使用 Scene 1 花 5–8 分钟让学生自主拖动滑块、观察规律，再引导学生猜测图象大致形状。
    - 然后切换到 Scene 2，用 3–5 分钟进行选项排除，强调“计算先行、选项后验”的解题策略。
    - 最后可让学生思考：若将正三角形改为等腰直角三角形（直角边为1），答案会变成哪个选项？（提示：此时高为0.5，进入过程仍分两段，但图象形状类似，仍选 B 型曲线。）以此进行变式拓展。
