场景导航：Scene 1

完整题目原文：

如图，四边形ABCD中，AB∥CD，AB=CD，E、F是对角线BD上的两点，如果再添加一个条件，使△ABE≌△CDF，则添加的条件不能是（ ）

A．AE=CF
B．BE=FD
C．BF=DE
D．∠1=∠2

题目分析：

由AB∥CD且AB=CD，可知四边形ABCD是平行四边形。BD为对角线，E、F为BD上两点。

关键隐含条件：因为AB∥CD，BD是截线，所以内错角∠ABE = ∠CDF。

因此，在△ABE与△CDF中，已经具备：

  1. AB = CD（已知，一组对应边相等）
  2. ∠ABE = ∠CDF（由AB∥CD推出的内错角相等，一组对应角相等）

现有"一边一角"，还需一个条件才能判定全等。本题要求找出不能判定全等的选项。

整体讲解思路：

  1. 先引导学生识别图形结构，确认平行四边形及点E、F的位置。
  2. 强调挖掘隐含条件——由平行得到内错角相等，这是解题的突破口。
  3. 将四个选项逐一与已知条件组合，对照全等判定定理（SAS、ASA、SSS、AAS、HL）。
  4. 对选项C，重点讲解线段和差的转化思想（BF=DE → BE=DF）。
  5. 对选项A，重点辨析SSA（边边角）为何不能作为一般三角形全等的判定依据。

本图示的教学说明：

步骤0（基础图形）：让学生观察图形，确认ABCD是平行四边形，E、F在对角线BD上的位置关系。不要急于给条件，先建立空间印象。

步骤1（挖掘隐含条件）：这是最关键的一步。很多学生只看到AB=CD，忽略AB∥CD的价值。引导学生回忆"两直线平行，内错角相等"，在图中找出截线BD，从而得到∠ABE = ∠CDF。此时板书：已知 = 一边一角。

步骤2（选项B · BE=FD）：引导学生将三个条件组合：AB=CD（边），∠ABE=∠CDF（角），BE=FD（边）。提问：角是不是两边的夹角？明确∠ABE夹在AB与BE之间，∠CDF夹在CD与DF之间，完全符合SAS。两三角形可填充绿色，强化"全等成立"的直观印象。

步骤3（选项C · BF=DE）：这是易错点。学生常因BF、DE不是三角形的边而困惑。在图中高亮BF和DE，然后用虚线标出公共段EF，演示：

  • BF = BE + EF
  • DE = DF + EF
  • 由BF = DE，两边同减EF，得 BE = DF

转化为选项B的情形，仍是SAS。此处强调"转化思想"。

步骤4（选项D · ∠1=∠2）：明确图中∠1=∠BAE，∠2=∠DCF。此时三个条件为：∠BAE=∠DCF（角），AB=CD（边），∠ABE=∠CDF（角）。对应ASA（两角及其夹边对应相等）。注意说明AB是∠BAE与∠ABE的夹边，CD是∠DCF与∠CDF的夹边。

步骤5（选项A · AE=CF）：三个条件为：AB=CD（边），∠ABE=∠CDF（角），AE=CF（边）。这是典型的SSA（边边角）。关键提问：相等的角∠ABE是不是AB与AE的夹角？不是——∠ABE是AB与BE的夹角，AE是∠ABE的对边。因此SSA不成立。可补充说明：在非直角三角形中，SSA可能出现"边边角"两种不同图形（锐角/钝角），无法唯一确定三角形形状。此处用红色高亮和浅红填充制造认知冲突，加深印象。

完整解答与课堂总结：

  1. 由AB∥CD且AB=CD，得四边形ABCD为平行四边形，且内错角∠ABE = ∠CDF。
  2. 在△ABE与△CDF中，已有AB = CD，∠ABE = ∠CDF。
  3. 选项B：添加BE = FD，由SAS可判定△ABE≌△CDF。
  4. 选项C：添加BF = DE，可推得BE = FD，转化为SAS，可判定全等。
  5. 选项D：添加∠1 = ∠2（即∠BAE = ∠DCF），由ASA可判定△ABE≌△CDF。
  6. 选项A：添加AE = CF，构成SSA，不能判定△ABE≌△CDF。

答案：A

课堂讲解建议：

  • 先给学生1-2分钟独立判断，再使用图示分步讲解。讲解时频繁使用"上一步"回退，强化条件之间的组合关系。
  • 对SSA的讲解，如果时间允许，可在黑板上快速手绘一个反例：画一个角和一条邻边固定，对边长度取某值时，三角形可能有两种形状（一锐一钝），让学生直观感受"不唯一"。
  • 总结时强调两个思想：挖掘隐含条件（平行→内错角）和转化思想（BF=DE → BE=DF）。这两个思想在后续几何证明中反复出现。
