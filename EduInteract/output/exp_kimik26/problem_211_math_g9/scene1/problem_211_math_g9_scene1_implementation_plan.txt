[图示主题与整合说明]
- 本图示主题：平行四边形中三角形全等条件的判定分析
- 整合内容：以平行四边形ABCD为基础，E、F为对角线BD上两点，已知AB=CD且AB∥CD。按逻辑顺序逐一分析四个选项（B→C→D→A），展示SAS、ASA判定过程及SSA不能判定的结论。
- 教学价值：教师通过分步导航控制课堂节奏，逐步揭示隐含条件、可判定路径与常见误区（SSA陷阱），便于学生跟随推理链条，随时回退复习关键步骤。

- 状态：纯图形，等待教师开始讲解。

步骤1（已知条件与隐含条件）：
- 点击「下一步」进入。
- 视觉变化：
  - AB边线、CD边线变为蓝色（#1565c0），线宽增至2.5px。
  - 显示AB等长标记（蓝色，中点(210,225)）。
  - 显示CD等长标记（蓝色，中点(530,225)）。
  - 显示∠ABE角弧线（蓝色，圆心B）。
  - 显示∠CDF角弧线（蓝色，圆心D）。
  - 判定文字显示："已知：AB = CD，AB ∥ CD → 内错角 ∠ABE = ∠CDF"。
- 教学点：建立已知条件和隐含的内错角相等。

步骤2（选项B：BE = FD，SAS判定）：
- 点击「下一步」进入。
- 视觉变化：
  - 保持步骤1所有蓝色高亮。
  - BE线段、FD线段变为绿色（#2e7d32），线宽2.5px。
  - 显示BE等长标记（绿色，中点(209,285)）。
  - 显示FD等长标记（绿色，中点(531,166)）。
  - △ABE与△CDF填充浅绿色（#2e7d32, opacity 0.2）。
  - 判定文字更新为："SAS：两边及其夹角对应相等 → △ABE ≌ △CDF"。
  - 选项B框高亮（绿色背景或边框）。
- 教学点：直接添加BE=FD，结合已知AB=CD和内错角，用SAS判定全等。

步骤3（选项C：BF = DE，转化为BE = FD）：
- 点击「下一步」进入。
- 视觉变化：
  - 保持步骤1蓝色高亮；取消BE/FD线段的绿色高亮（恢复黑色），但保留BE=FD等长标记（表示推导结论）。
  - BF线段、DE线段变为绿色（#2e7d32），线宽2.5px。
  - 显示BF等长标记（绿色，中点(201,251)）。
  - 显示DE等长标记（绿色，中点(431,196)）。
  - 在BD中点上方显示"EF"标注（灰色，(370,215)）。
  - △ABE与△CDF保持浅绿色填充。
  - 判定文字更新为："BF = DE → BF − EF = DE − EF → BE = FD → SAS"。
  - 选项B框取消高亮；选项C框高亮（绿色）。
- 教学点：通过和差消去公共段EF，将BF=DE转化为BE=FD，再用SAS判定。

步骤4（选项D：∠1 = ∠2，ASA判定）：
- 点击「下一步」进入。
- 视觉变化：
  - 保持步骤1蓝色高亮；取消BF/DE线段的绿色高亮（恢复黑色），保留BF=DE和BE=FD等长标记或仅保留必要标记（建议保留BE=FD标记以呼应ASA的夹边）。
  - 显示∠BAE角弧线（绿色，圆心A），标注∠1（(255,165)）。
  - 显示∠DCF角弧线（绿色，圆心C），标注∠2（(475,295)）。
  - △ABE与△CDF保持浅绿色填充。
  - 判定文字更新为："ASA：两角及其夹边对应相等 → △ABE ≌ △CDF"。
  - 选项C框取消高亮；选项D框高亮（绿色）。
- 教学点：添加∠1=∠2，结合内错角∠ABE=∠CDF和夹边AB=CD，用ASA判定全等。

步骤5（选项A：AE = CF，SSA不能判定）：
- 点击「下一步」进入。
- 视觉变化：
  - 保持步骤1蓝色高亮；取消所有绿色角弧线和等长标记（恢复初始状态）。
  - AE线段、CF线段变为红色（#c62828），线宽2.5px。
  - 显示AE等长标记（红色，中点(279,200)）。
  - 显示CF等长标记（红色，中点(461,251)）。
  - △ABE与△CDF填充浅红色（#c62828, opacity 0.2）。
  - 判定文字更新为："SSA不能判定全等 ⚠"（红色，加警示符号）。
  - 选项D框取消高亮；选项A框高亮（红色背景或边框）。
- 教学点：强调AE=CF是SSA情形，属于常见陷阱，不能作为判定条件。此为最终结论。

[交互方案]
- 交互类型：分步按钮导航（◀ 上一步 / 下一步 ▶）
- 控件说明：
  - 「◀ 上一步」按钮：位置(290,450)，宽85px，高34px。点击回退到上一状态，步骤0时禁用。
  - 「步骤 X/5」文本显示：位置(400,472)，居中显示当前步骤编号（步骤1~5对应分析状态，步骤0显示"初始"）。

- 教师操作流程：
  1. 教师打开图示，学生看到步骤0的纯图形，建立几何直观。
  2. 教师点击「下一步」进入步骤1，讲解已知条件AB=CD、AB∥CD，引导学生发现内错角∠ABE=∠CDF。
  3. 依次点击「下一步」进入步骤2~4，分别分析选项B、C、D，观察绿色高亮与全等填充，理解SAS和ASA判定路径。

  5. 讲解过程中可随时点击「上一步」回退，复习关键推导（如步骤3的EF消去过程）。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：本场景为纯几何图形与状态切换，无需复杂坐标计算或3D渲染，原生SVG性能最优，且便于精确控制每个图形元素的显隐与颜色。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------------+
  |  A标签                                                  |
  |    A(280,140)---------------------------D(600,140)  D标签 |
  |      / \                                 / \            |
  |     /   \                               /   \           |
  |    /     \         EF标注(370,215)     /     \          |
  |   /       \           |               /       \         |
  |  B(140,310)-E(278,259)-F(462,191)-D(600,140)对角线      |
  |    \       /           |             \       /          |
  |     \     /            |              \     /           |
  |      \   /             |               \   /            |
  |       \ /              |                \ /             |
  |        C(460,310)      |                 C标签          |
  |  B标签                 |                                |
  |                        |                                |
  |  判定说明文字(400,365)   |   [A] [B] [C] [D] 选项框      |
  |                        |                                |
  |  +--------------------------------------------------+  |
  |  |  [◀ 上一步]      步骤 X/5      [下一步 ▶]        |  |
  |  +--------------------------------------------------+  |
  |              控件栏 y=440~490                          |
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：定义变量 `currentStep`（0~5）。`updateScene(step)` 函数根据步骤值统一控制所有元素的显隐、颜色class和文本内容。
  2. 元素组织：SVG中使用 `<g>` 分组，如 `<g id="scene1-group-step1">` 包含步骤1新增元素，便于批量控制。但每个独立交互元素仍需单独ID。
  3. 颜色与显隐切换：使用 CSS class（如 `.scene1-blue`, `.scene1-green`, `.scene1-red`, `.scene1-hidden`）配合 SVG 元素的 `class` 属性。过渡动画使用 CSS `transition: all 0.3s ease`。
  4. 三角形填充：使用 `<polygon>` 定义 △ABE 和 △CDF，初始 `opacity: 0`，步骤2/3/4时变为 `opacity: 0.2`（绿色），步骤5时变为 `opacity: 0.2`（红色）。
  5. 等长标记：用 `<line>` 绘制，通过计算线段中点和垂直方向得到端点坐标。在计划中已给出中点和方向，代码中按"中点±垂直单位向量×6px"计算端点。
  6. 角弧线：使用 SVG `<path>` 的 `A` 命令绘制圆弧。需预计算起始角和终止角（已在坐标表中给出）。
  7. 事件绑定：上一步/下一步按钮绑定 `click` 事件，更新 `currentStep` 后调用 `updateScene`。按钮禁用状态通过检查 `currentStep` 边界（0或5）动态设置 `disabled` class。
  8. 选项框高亮：四个选项框使用 `<rect>` + `<text>` 组合，高亮时切换 `stroke` 和 `fill` 颜色（绿色/红色/默认灰色）。
- ID命名规范：所有交互及图形元素ID必须以 `scene1-` 为前缀。示例：
  - 图形：`scene1-poly-abcd`, `scene1-line-bd`, `scene1-line-ae`, `scene1-line-cf`
