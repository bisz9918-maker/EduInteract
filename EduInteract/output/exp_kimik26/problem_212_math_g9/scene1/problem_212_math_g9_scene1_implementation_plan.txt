[图示主题与整合说明]
- 本图示主题：三角形个数的系统枚举与常见错误辨析
- 整合的步骤/概念：
  1. 原图全貌展示与顶点标注（步骤0）
  2. 四个小三角形的逐一高亮计数：△ADE、△BDF、△CEF、△DEF（步骤1–4）
  3. 大三角形 △ABC 的高亮计数（步骤5）
  4. 常见错误辨析：用虚线标出未连接的 AF、BE、CD，说明对应三角形不存在（步骤6）
- 教学价值：教师通过「上一步/下一步」控制节奏，逐步揭示每个三角形，避免学生遗漏或重复；最后一步集中展示常见错误（虚线误导），强化正确枚举策略。

[交互方案]
- 交互类型：分步按钮导航（◀ 上一步 / 下一步 ▶）
- 控件说明：
  – 「◀ 上一步」按钮：位于 (280,456)，宽 100×34。点击后 currentStep 减 1，回退到上一视觉状态；当 currentStep=0 时置灰。
  – 「下一步 ▶」按钮：位于 (420,456)，宽 100×34。点击后 currentStep 加 1，进入下一视觉状态；当 currentStep=6 时置灰。
- 教师操作流程：
  1. 教师展示步骤0，让学生观察原图并尝试自行计数。
  2. 点击「下一步」依次揭示 △ADE、△BDF、△CEF、△DEF，每步停顿讲解。
  3. 点击「下一步」到步骤5，强调整体 △ABC，强调"4 个小三角形 + 1 个大三角形 = 5 个"。
  4. 点击「下一步」到步骤6，展示虚线 AF/BE/CD 与 "×" 标记，说明"若误连这些线段，会错误数出更多三角形，但原图中它们并不存在"。
  5. 随时点击「上一步」回退，针对学生薄弱环节重复强调。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无外部库）。理由：本场景为静态几何图形与显隐切换，SVG 的 path/polygon/text 即可满足，无需引入 D3/Canvas 等重型库，保持代码轻量。
- 画布尺寸：800 × 500 px（SVG 容器固定宽高）。
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |                                                  |
  |        A                                         |
  |       / \                                        |
  |      D---E      | 计数器面板                     |
  |     / \ / \     | 已发现三角形：n 个              |
  |    /   X   \    |                                |
  |   B----F----C   | 步骤说明                       |
  |                 |                                |
  |   [主图区]      |  [缩略图区，仅步骤6]            |
  |                 |                                |
  |                 |                                |
  +--------------------------------------------------+
  |        [◀ 上一步]      [下一步 ▶]                |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `let currentStep = 0;`（范围 0~6）。每次点击按钮时更新变量，调用 `renderStep()` 统一渲染。
  2. 渲染函数 `renderStep()`：根据 currentStep 值，显式设置各 SVG 元素/组的 `display` 属性（或 CSS class `.hidden`）。禁止依赖全局样式，必须对每个元素单独控制。
  3. 高亮层管理：每个三角形的高亮填充与边框放在独立 `<g>` 组内（如 `scene1-highlight-ade`），通过 class 切换显示。步骤5 时同时显示 4 个小三角形的半透明填充组与 △ABC 的紫色边框组。
  4. 步骤6 元素：虚线、× 标记、引线、标注文字、缩略图统一放在 `<g id="scene1-step6-group">` 内，步骤6 时整体显示，其他步骤隐藏。
  5. 缩略图实现：使用 5 个独立的 `<svg>` 或 `<g>` 元素，viewBox 各自定义简化坐标，避免与主图坐标系耦合。
  6. 按钮状态：在 `renderStep()` 内同步更新两按钮的 `disabled` 属性与透明度（currentStep===0 时上一步禁用；currentStep===6 时下一步禁用）。
  7. 动画曲线：本场景无需复杂动画，显隐切换使用即时渲染；如需柔和过渡，可对 opacity 设置 CSS transition 0.2s。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀。例如：
  – `scene1-tri-abc`（大三角形路径）
  – `scene1-highlight-ade`（△ADE 高亮组）
  – `scene1-counter-text`（计数器文字）
  – `scene1-btn-prev`（上一步按钮）
  – `scene1-btn-next`（下一步按钮）
  – `scene1-step6-group`（步骤6 总组）
  JS 中统一使用 `document.getElementById` 获取元素，禁止 `querySelectorAll` 配合全局 class，防止多场景合并时跨场景污染。
- IIFE 隔离：所有 JavaScript 代码包裹在 `(function() { ... })();` 中，变量与函数不暴露到全局作用域。
