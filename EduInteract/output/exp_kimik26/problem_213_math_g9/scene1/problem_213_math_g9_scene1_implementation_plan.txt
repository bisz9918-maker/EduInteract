[图示主题与整合说明]
- 本图示主题：自行车链条节数与总长度的规律推导
- 整合的步骤/概念：单节结构展示 → 两节重叠分析 → 三节规律验证 → n节公式归纳 → 100节代入求解
- 教学价值：教师通过分步导航精确控制认知节奏，学生能清晰看到从具体链条图形到抽象代数公式的递进过程，理解"每增1节增加1.7cm"的核心规律，以及重叠部分为何是(n-1)个而非n个。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「上一步」按钮：位置(320,455)，宽80×高30，圆角矩形。点击后currentStep减1，切换至前一步视觉状态。步骤0时禁用（透明度0.3，不响应点击）。
  2. 「步骤指示器」：位置(400,485)，显示"步骤 X/5"，灰色文字，仅作状态提示不可点击。
  3. 「下一步」按钮：位置(460,455)，宽80×高30，圆角矩形。点击后currentStep加1，切换至下一步视觉状态。步骤4时文字变为"完成"，点击后无动作或提示已到最后一步。
- 教师操作流程：
  1. 教师打开图示，学生看到步骤0的1节链条基础结构。
  2. 教师讲解单节长度2.5cm后，点击「下一步」进入步骤1，引导学生观察2节链条中的重叠圆。
  3. 教师指着红色高亮的重叠圆和算式"-0.8"，解释为何2节不是5cm而是4.2cm。
  4. 点击「下一步」进入步骤2，验证3节规律，强化"每多1节只多1.7cm"。
  5. 点击「下一步」进入步骤3，从具体图形过渡到抽象公式，强调(n-1)个重叠。
  6. 点击「下一步」进入步骤4，展示完整计算和正确选项C。
  7. 若学生某步未理解，教师随时点击「上一步」回退重新讲解。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript，无需外部库。理由：本场景仅涉及简单几何图形（圆、线、路径、文本）和显隐切换，原生SVG完全足够，引入D3等库反而增加体积。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |                                                  |
  |              [链条图形区 y=110~240]               |
  |         圆 + 链板 + 标注线 + 省略号               |
  |                                                  |
  |                                                  |
  |              [算式推导区 y=250~430]               |
  |              公式文本 + 选项（步骤4）              |
  |                                                  |
  |    [上一步]        步骤 X/5        [下一步]      |
  |              [控件栏 y=440~490]                   |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `let currentStep = 0;` 控制5个步骤（0~4）。每步对应一个SVG `<g>` 分组（id="scene1-step-0" 至 "scene1-step-4"），分组内包含该步所有视觉元素。切换步骤时，通过设置 `display: none/block` 或 `opacity: 0/1` 控制显隐。
  2. 坐标计算：圆半径r=12px，圆心距d=51px（比例1cm=30px，0.8cm→24px直径，1.7cm→51px圆心距）。n节链条总像素宽 = 24 + n×51。每步根据节数计算起始x使链条水平居中：startX = (800 - (24 + n×51)) / 2。
  3. 动画曲线：使用CSS transition `opacity 0.3s ease-in-out`。切换步骤时，旧分组opacity设为0，新分组opacity设为1。确保两组元素在过渡期间不重叠占用同一空间（通过display:none在transitionend后清理，或直接用opacity控制）。
  4. 事件绑定：为「上一步」「下一步」按钮绑定click事件。按钮状态同步更新：步骤0禁用「上一步」，步骤4「下一步」文字变"完成"。
  5. 算式颜色：使用SVG `<text>` 内嵌多个 `<tspan>`，通过 `fill` 属性分别设置黑/红/蓝/绿，通过 `dx` 或绝对 `x` 控制位置。
  6. 大括号绘制：使用SVG path命令 `M 268 210 Q 268 230 340 230 Q 415 230 415 250` 类似贝塞尔曲线绘制向下开口的大括号，左右对称。
  7. 箭头标记：在 `<defs>` 中定义 `<marker>`（id="scene1-arrow-start" 和 "scene1-arrow-end"），用于尺寸标注线两端。
- ID命名规范：所有交互元素ID必须以 `scene1-` 为前缀。例如：
  - 分组：`scene1-step-0`, `scene1-step-1`, ..., `scene1-step-4`
  - 图形元素：`scene1-circle-1`, `scene1-link-plate-top-1`, `scene1-overlap-circle`
  - 文本：`scene1-label-length`, `scene1-formula-line1`
  - 按钮：`scene1-btn-prev`, `scene1-btn-next`, `scene1-step-indicator`
  - 标记定义：`scene1-arrow-start`, `scene1-arrow-end`
  - JS中获取元素严格使用 `document.getElementById('scene1-xxx')`，禁止用 `querySelectorAll` 配合全局class。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免多场景合并时变量污染全局作用域。场景内状态变量（currentStep等）全部用let/const声明在IIFE内部。
