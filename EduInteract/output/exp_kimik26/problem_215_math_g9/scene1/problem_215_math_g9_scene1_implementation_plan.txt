[图示主题与整合说明]
- 本图示主题：正方形"一线三垂直"模型的全等证明与线段计算
- 整合的步骤/概念：原题图形展示 → 直角高亮认知 → 角度关系推导（同角余角相等） → 三角形全等证明（AAS） → 线段EF长度计算
- 教学价值：教师通过分步按钮精确控制课堂节奏，逐步添加辅助标注，引导学生发现图中两个直角三角形的全等关系，最终得出EF = AE + AF = BF + DE = 7 的结论。可随时回退重讲关键步骤。

[分步序列]
- 步骤0（初始状态）：显示正方形ABCD、直线a（两端延伸）、垂线段DE和BF、三个直角符号（细线1px）、顶点标签A/B/C/D、垂足标签E/F、直线标签a、长度标注"DE=4"和"BF=3"。等待教师点击「下一步」。
- 步骤1（直角高亮）：三个直角符号线宽从1px加粗至3px（可保持黑色或加深为#333333），引导学生发现图中存在三个直角、两个直角三角形。其余元素同步骤0。
- 步骤2（角度推导）：在步骤1基础上，添加三个角度弧（∠DAE蓝色、∠BAF红色、∠ADE绿色）及对应标签"∠1""∠2""∠3"；添加文字"∠1+∠3=90°"在△ADE内侧(450,285)、"∠1+∠2=90°"在A点左上方(365,265)、"∴ ∠2=∠3"在图形右侧(520,245)。展示同角余角相等的推导逻辑。
- 步骤3（全等证明）：在步骤2基础上，△ADE填充蓝色（20%透明度）、△BAF填充红色（20%透明度）；添加对应顶点虚线连接D-B和偏移虚线E'-F'（灰色#888888）；添加边长标注"AE=3"和"AF=4"；在右侧添加全等标注"△ADE ≌ △BAF (AAS)"。对应边AE=BF=3、AF=DE=4的关系通过数值标注和虚线连线呈现。
- 步骤4（结论计算）：在步骤3基础上，直线a上的线段EF以绿色#2e7d32高亮（线宽4px覆盖）；在A点左上方(375,250)标注"EF=7"；在图形右侧(580,320)标注最终答案"EF = AE + AF = 3 + 4 = 7，选 C"。展示完整计算链条。
- 教师可随时点击「◀ 上一步」回退到任意步骤复习。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「◀ 上一步」按钮：位于画布底部(280,460)，宽90px高30px，点击后回退到上一状态，步骤0时禁用。
  2. 「下一步 ▶」按钮：位于画布底部(430,460)，宽90px高30px，点击后前进到下一状态，步骤4时禁用。
  3. 步骤指示器：位于画布底部中央(400,450)，显示当前步骤编号"步骤 X/5"。
- 教师操作流程：
  1. 课堂开始时展示步骤0，让学生观察图形和已知条件（DE=4，BF=3）。
  2. 点击「下一步」进入步骤1，引导学生发现三个直角，建立直角三角形认知。
  3. 点击「下一步」进入步骤2，通过角度弧和等式标注，推导∠ADE=∠BAF。
  4. 点击「下一步」进入步骤3，展示三角形全等（AAS），强调对应边相等。
  5. 点击「下一步」进入步骤4，得出EF=AE+AF=3+4=7，点明答案选C。
  6. 讲解中可随时回退重讲关键步骤。

[技术实现]
- JS库选择：原生SVG（简单几何图形、路径、文本，无需引入外部库，减少依赖）
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  标签a(478,215)                                  |
  |         E(454,242)                               |
  |        /  标签E                                  |
  |       / ∠AED□   D(505,314) 标签D                 |
  |      /         / |                               |
  |     /    A(400,280)标签A   △ADE填充(蓝)          |
  |    /   ∠DAB□  /  |                               |
  |   /          /   |         全等标注(570,270)      |
  |  F(328,331) /    |         答案C(580,320)        |
  |  标签F     /     |                               |
  |   □∠BFA  B(366,385)标签B   △BAF填充(红)          |
  |           |      |                               |
  |           C(471,419)标签C                        |
  |                                                  |
  |  [◀ 上一步]    步骤 X/5    [下一步 ▶]            |
  +--------------------------------------------------+
  控件栏 y=440~490
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `currentStep`（0~4），每次点击按钮时更新状态，调用 `renderStep()` 函数根据状态显示/隐藏元素。
  2. 元素显隐控制：为每个步骤特有的元素设置 `display: none` / `display: block`（或SVG的 `visibility` / `opacity`）。建议用CSS类控制，如 `.step1-only`、`.step2-only` 等，通过父容器添加/移除类名实现批量控制。
  3. 角度弧绘制：使用SVG `<path>` 的 `A` 命令（椭圆弧）或分段 `<line>`/`<polyline>` 逼近。提供圆心、半径、起止角度（见坐标表）。
  4. 直角符号绘制：以角顶点为起点，沿两边方向各取8px得到两点P1、P2，再画P1→(P1+P2-顶点)→P2的path形成小方块。
  5. 三角形填充：使用 `<polygon>` 或 `<path>`，设置 `fill-opacity="0.2"`。
  6. 对应顶点虚线：使用 `<line>` 设置 `stroke-dasharray="6,4"`。
  7. 结论EF高亮：在步骤4时，于直线a的E-F段上方绘制一条绿色粗线（`<line>`，线宽4px，颜色#2e7d32），覆盖原黑线。
  8. 动画曲线：无需复杂动画，步骤切换直接显隐即可（0.2s的opacity过渡可选，增强平滑感）。
  9. 事件绑定：按钮绑定 `click` 事件，更新 `currentStep` 后调用渲染函数。
- ID命名规范：所有SVG元素和控件ID必须以 `scene1-` 为前缀。例如：
  - 正方形边：`scene1-square-ab`、`scene1-square-bc`、`scene1-square-cd`、`scene1-square-da`
  - 直线a：`scene1-line-a`
  - 垂线：`scene1-de`、`scene1-bf`
  - 顶点标签：`scene1-label-a`、`scene1-label-b` 等
  - 直角符号：`scene1-right-dab`、`scene1-right-aed`、`scene1-right-bfa`
  - 角度弧：`scene1-arc-dae`、`scene1-arc-baf`、`scene1-arc-ade`
  - 三角形填充：`scene1-fill-ade`、`scene1-fill-baf`
  - 虚线连线：`scene1-dash-db`、`scene1-dash-ef`
  - 结论高亮：`scene1-highlight-ef`
  - 按钮：`scene1-btn-prev`、`scene1-btn-next`
  - 步骤指示：`scene1-step-indicator`
  - JS中严格使用 `document.getElementById` 获取元素，禁止全局class选择器，避免多场景合并时跨场景污染。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，变量不泄露全局作用域。
- 坐标计算说明：本题几何关系经推导满足 AE=3、AF=4（单位长度），正方形边长=5（单位长度），与已知 DE=4、BF=3 及全等结论完全自洽。视觉比例按 1单位≈22px 绘制，确保图形美观且所有标注有充足留白。
