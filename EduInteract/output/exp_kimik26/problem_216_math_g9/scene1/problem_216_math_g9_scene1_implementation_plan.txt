[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  1. 「◀ 上一步」按钮：位于(290,465)，宽90px，高28px。点击后currentStep减1，回退到前一步状态，隐藏当前步新增元素，显示前一步元素。当currentStep=0时禁用（变灰）。
  2. 「下一步 ▶」按钮：位于(420,465)，宽90px，高28px。点击后currentStep加1，进入下一步状态，显示该步新增元素。当currentStep=6时禁用（变灰）。
  3. 步骤提示文字：位于(400,455)，显示当前步骤名称（如"步骤3：验证结论①"），蓝色#1565c0，14px，居中。
- 教师操作流程：教师打开图示后，先向学生展示步骤0的题目基础条件（抛物线、对称轴、已知交点）；点击「下一步」依次展开各结论的验证过程，每步配合面板上的图标和推导提示进行讲解；在步骤4（错误结论）和步骤5（错误结论）处可重点强调反例；到达步骤6后总结正确答案；可随时点击「上一步」回退到任意步骤复习。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：本场景以静态几何图形和分步显示/隐藏为主，无需复杂数据绑定或3D渲染，原生SVG足够轻量且可控。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------------+
  | 坐标系区(0~544)            | 结论面板(544~800)         |
  |                            |                           |
  |    y                       |  ① 4ac<b²            [ ]  |
  |    |  D ●                  |  ② 3a+c>0            [ ]  |
  |  4-|- ●-●-● 抛物线         |  ③ x>0时y减小...     [ ]  |
  |  3-C ●                     |  ④ y>0时-1<x<3      [ ]  |
  |    |    \                  |  ⑤ 两根为-1和3       [ ]  |
  |    O--A|--B---> x          |                           |
  |      -1 1 3                |                           |
  |                            |                           |
  |                            |                           |
  +--------------------------------------------------------+
  | [控件栏 y=440~490]  ◀ 上一步    步骤提示    下一步 ▶   |
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 `currentStep`（0~6）记录当前步骤。每步对应一个显示元素ID列表。`goToStep(n)` 函数遍历所有元素，根据步骤映射表设置 `display` 属性（或 visibility）。
  2. 坐标计算：定义 `toScreenX(x)` 和 `toScreenY(y)` 函数，将数学坐标转换为屏幕坐标。scaleX=74px/单位，scaleY=57px/单位，原点O在(208,343)。
  3. 抛物线路径：用 `d="M x1 y1 L x2 y2 ..."` 连接采样点（x从-1.236到3.236，步长0.25），生成平滑曲线。
  4. y>0区域填充：用 `<path>` 的 `d="M 134 343 [抛物线弧到430,343] L 430 343 L 134 343 Z"` 实现。
  5. 箭头绘制：用 `<path>` 画线段 + `<marker>` 定义箭头头部，或直接用短路径加三角箭头。
  6. 按钮交互：SVG `<rect>` + `<text>` 组合，绑定 `click` 事件。禁用状态通过修改 `fill` 为 `#f5f5f5` 和 `pointer-events: none` 实现。
  7. 面板边框颜色：通过修改对应结论项 `<rect>` 或 `<div>` 的 `border-left-color` 实现（绿/红/灰）。
- ID命名规范：所有交互元素ID必须以 `scene1-` 为前缀。例如：`scene1-parabola`、`scene1-axis-x`、`scene1-point-a`、`scene1-conclusion-1`、`scene1-btn-prev`、`scene1-btn-next`、`scene1-step-label`。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })()` 中，避免全局变量污染，确保多场景合并时互不干扰。
- 元素显示/隐藏：优先使用 `style.display = 'none' / 'block'` 控制，避免频繁操作DOM。在初始化时将所有步骤专属元素设为 `display:none`，进入对应步骤时设为 `display:block`（或SVG的等价方式）。
