[图示主题与整合说明]
- 本图示主题：双三角板摆放中的角度链推导（等腰直角三角板与30°-60°-90°三角板共线摆放）
- 整合的步骤/概念：
  1. 识别两个三角板及其已知条件（AB=AC、∠A=90°、∠EDF=90°、∠E=30°、∠BCE=40°）
  2. 等腰直角三角形ABC中推导∠ACB=45°
  3. 利用平角关系推导∠ACF=95°
  4. 在△CDF中利用内角和推导∠CDF=25°
- 教学价值：教师可按认知顺序逐步呈现条件、中间结论和最终答案，分步按钮可随时回退重讲，符合课堂讲解节奏。

[分步序列]
- 初始状态（步骤0）：显示两个三角板的基础图形——所有顶点字母A/B/C/D/E/F、六条边线AB/BC/CA/ED/DF/EF、A点和D点的直角符号。不显示任何角度数值、等长标记、公式或填充色。让学生先整体观察图形结构。
- 步骤1（标注已知）：点击「下一步」→ 
  * △ABC边线变为蓝高亮#1565c0（线宽2.5px），填充rgba(21,101,192,0.15)
  * △EDF边线变为红高亮#c62828（线宽2.5px），填充rgba(198,40,40,0.15)
  * 显示AB与AC上的等长标记，显示AB=AC文本标签(270,140)
  * 显示∠A=90°标签(370,155)、∠EDF=90°标签(405,245)
  * 显示∠E=30°红弧及标签(240,300)、∠F=60°红弧及标签(445,295)
  * 显示∠BCE=40°红弧及标签(300,330)
- 步骤2（求∠ACB）：点击「下一步」→ 
  * △ABC蓝色填充加深（rgba(21,101,192,0.25)）
  * 在C点显示∠ACB=45°蓝弧及标签(350,310)
  * 右侧公式区显示：∠ACB = (180°−90°)/2 = 45°（蓝高亮#1565c0，16px）
- 步骤3（求∠ACF）：点击「下一步」→ 
  * 高亮直线ECF为灰色虚线#888888 1px，辅助强调平角
  * 在C点依次展示三个相邻角：∠BCE=40°（红弧）、∠ACB=45°（蓝弧）、∠ACF=95°（绿弧，大弧），三者合成平角180°
  * 显示∠ACF=95°绿弧及标签(440,325)
  * 右侧公式区显示：∠ACF = 180°−40°−45° = 95°（绿高亮#2e7d32，16px）
- 步骤4（结论∠CDF）：点击「下一步」→ 
  * △CDF高亮填充rgba(46,125,50,0.20)
  * 标注∠DFC=60°红弧（继承三角板EDF的角，F点）
  * 标注∠DCF=95°绿弧（即∠ACF，C点）
  * 推导并高亮∠CDF=25°蓝弧（D点，线宽3px）及标签(380,270)
  * 右侧公式区显示：∠CDF = 180°−60°−95° = 25°（蓝高亮#1565c0，16px）
  * 最终答案以醒目样式显示：B．25°（#1565c0，18px加粗，带浅蓝背景高亮框，位置(640,370)）
- 教师可随时点击「上一步」回退到任意步骤复习。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  * 「上一步」按钮：位置(280,455)，大小80×30，点击回退到上一状态
  * 「步骤指示器」文本：位置(400,470)，显示当前步骤编号（如"步骤 1/4"）
  * 「下一步」按钮：位置(520,455)，大小80×30，点击前进到下一状态
  * 步骤0时「上一步」禁用（或隐藏），步骤4时「下一步」禁用（或隐藏）
- 教师操作流程：
  1. 教师展示步骤0，让学生观察双三角板摆放结构
  2. 点击「下一步」进入步骤1，引导学生识别已知条件（等腰直角、30°角、40°角）
  3. 继续点击「下一步」，逐步呈现∠ACB=45°、∠ACF=95°的推导
  4. 最后一步呈现∠CDF=25°的结论和答案
  5. 讲解中可随时回退到某一步重新强调

[技术实现]
- JS库选择：原生SVG（简单几何、角度弧、路径绘制首选，无需引入外部库）
- 画布尺寸：800 × 500 px（固定画布规则）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  B*          *A                                  |
  |    \        / \                                  |
  |     \      /   \*D                               |
  |      \    /     \|                               |
  |       \  /       \                               |
  |        \/         \                              |
  |  E-----*----------*-------F                      |
  |        C                                          |
  |                                                   |
  |  [公式区: x=620~780]                              |
  |  ∠ACB=(180-90)/2=45°                             |
  |  ∠ACF=180-40-45=95°                              |
  |  ∠CDF=180-60-95=25°                              |
  |  B. 25°                                          |
  |                                                   |
  |  [控件栏 y=440~490]                               |
  |    [上一步]  步骤 X/4  [下一步]                   |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `currentStep`（0~4），每一步对应一个渲染函数 `renderStep(n)`，通过设置各SVG元素的 `display` 或 `opacity` 属性控制显隐。
  2. 分组管理：使用 `<g id="scene1-step1-group">` 等分组包裹每步新增元素，便于批量控制。
  3. 角度弧绘制：使用SVG `<path>` 的Arc命令（A）。需计算每条射线的单位方向向量，确定弧的起点、终点和sweep-flag。例如∠ACF=95°为大弧（sweep-flag根据y向下坐标系取1或0，代码中实测调整）。
  4. 高亮切换：通过修改元素的 `stroke`、`stroke-width`、`fill-opacity` 实现。步骤切换时先移除旧高亮类名，再添加新类名。
  5. 公式区动画：公式文本初始 `opacity:0`，步骤进入时使用CSS transition `opacity 0.3s ease` 淡入。
  6. 按钮状态：步骤0时禁用「上一步」（`disabled`+灰色样式），步骤4时禁用「下一步」。
  7. 事件绑定：按钮点击事件直接调用 `setStep(currentStep ± 1)`，更新指示器文本和渲染。
- ID命名规范：所有交互元素ID必须以 `scene1-` 为前缀。例如：
  * 顶点：`scene1-pt-a`、`scene1-pt-b` 等
  * 边线：`scene1-seg-ab`、`scene1-seg-ed` 等
  * 角度弧：`scene1-arc-bce`、`scene1-arc-acb` 等
  * 公式文本：`scene1-formula-step2`、`scene1-formula-step3` 等
  * 按钮：`scene1-btn-prev`、`scene1-btn-next`
  * 分组：`scene1-group-step1`、`scene1-group-step2` 等
  * JS中严格使用 `document.getElementById` 获取元素，禁止全局class选择器，避免多场景合并时跨场景污染。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，变量不污染全局作用域。
- 坐标精确性：代码agent必须严格按本计划中的像素坐标实现所有顶点、标签和控件位置，确保无重叠。
