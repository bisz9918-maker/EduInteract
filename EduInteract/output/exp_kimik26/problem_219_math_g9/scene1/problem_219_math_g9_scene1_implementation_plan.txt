[图示主题与整合说明]
- 本图示主题：反比例函数图像中梯形与三角形面积关系的分步推导
- 整合的步骤/概念：直角坐标系与反比例函数曲线 → 曲线上两点及垂线构造梯形 → 两个目标面积区域高亮对比 → 反比例函数k的几何意义（½k） → 面积割补公式推导 → 结论S₁:S₂=1:1
- 教学价值：教师通过分步导航精确控制课堂节奏，从直观图形认知逐步过渡到代数推导，揭示反比例函数中"k的几何意义"这一核心考点，学生可清晰看到S₁与S₂为何必然相等

[分步序列]
- 初始状态（步骤0）：显示直角坐标系（x轴、y轴、原点O及标签x、y、O）；显示反比例函数曲线y=k/x及其标签；隐藏所有点、线段、填充、面积标签。步骤提示："观察反比例函数y=k/x在第一象限的图像"。
- 步骤1：点击「下一步」→ 显示点A(260,150)、B(460,310)（蓝色圆点）；显示垂线AD、BC（水平线段）；显示线段AB；显示垂足C、D（小圆点）及标签A、B、C、D；形成梯形ABCD轮廓。步骤提示："在曲线上取两点A、B，作AD⊥y轴，BC⊥y轴"。
- 步骤2：点击「下一步」→ 显示线段OA、OB；填充梯形ABCD（蓝色透明）并标注S₁(260,230)；填充△OAB（红色透明）并标注S₂(293,283)。步骤提示："梯形ABCD的面积为S₁，△OAB的面积为S₂"。
- 步骤3：点击「下一步」→ 填充△OAD（绿色透明）并标注½k(193,230)；填充△OBC（绿色透明）并标注½k(260,337)；显示"面积相等"提示文字(600,200)。步骤提示："△OAD与△OBC的面积都等于½k，即反比例函数中k的几何意义"。
- 步骤4：点击「下一步」→ 显示割补关系公式文字(620,250)："S△OAB = S梯形ABCD + S△OBC − S△OAD"；可用虚线箭头辅助指示三个区域的加减关系。步骤提示："利用面积割补法，△OAB可看作梯形加上△OBC再减去△OAD"。
- 步骤5（最终）：点击「下一步」→ 显示推导文字(620,265)："∵ S△OBC = S△OAD = ½k  ∴ S△OAB = S梯形ABCD"；高亮显示结论文字(600,140)："S₁ : S₂ = 1 : 1"（红色粗体）；显示答案(600,170)："答案：A"。步骤提示："代入相等的三角形面积，得到S₁=S₂，比值为1:1"。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「上一步」按钮：位置(320,450)，70×30px，点击回退到上一状态
  2. 「下一步」按钮：位置(410,450)，70×30px，点击推进到下一状态
  3. 步骤提示面板：位置(200,422)-(600,442)，显示当前步骤讲解文字
  4. 步骤计数：位置(400,488)，显示"步骤 n/6"
- 教师操作流程：教师点击「下一步」逐步展示推导过程，每步配合面板文字讲解；可随时点击「上一步」回退复习；步骤0和步骤5为起始和结束状态，按钮相应禁用（步骤0禁用上一步，步骤5禁用下一步）

[技术实现]
- JS库选择：原生SVG + 原生JavaScript（理由：本场景为静态几何图形与分步显示/隐藏，无需复杂动画或数据驱动，原生SVG性能最优，代码最轻量）
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [图示区 800×430]
  +--------------------------------------------------+
  |  y↑  y=k/x                                       |
  |   |    ●A                                        |
  |   D----+                                         |
  |   |    | \                                       |
  |   C----+--●B                                     |
  |   |   /    \                                     |
  |   O--+-------→x                                  |
  |                                                  |
  |  [步骤提示面板  底部中央]                         |
  +--------------------------------------------------+
  [控件区 y=440~490]
  +--------------------------------------------------+
  |      [◀上一步]  [下一步▶]                        |
  |              步骤 n/6                            |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：变量`currentStep`∈[0,5]，每步定义一个显示元素ID数组，切换步骤时遍历所有元素设置`display`或`opacity`
  2. 坐标计算：反比例曲线用20个采样点连线段近似，公式为`px=160+x*50, py=390-(12/x)*40`，x∈[1.5,12]
  3. 动画曲线：分步切换使用CSS transition（opacity 0.3s ease），无位移动画，避免视觉干扰
  4. 事件绑定：上一步/下一步按钮绑定click事件，更新currentStep后调用`renderStep()`函数
  5. 步骤提示文字：使用数组`stepTexts`存储6条提示语，根据currentStep索引更新
  6. 按钮状态：步骤0时禁用上一步（opacity 0.4, pointer-events none），步骤5时禁用下一步
- ID命名规范：所有交互元素ID必须以`scene1-`为前缀，例如：
  - `scene1-axis-x`, `scene1-axis-y`, `scene1-curve`
  - `scene1-point-a`, `scene1-point-b`, `scene1-point-c`, `scene1-point-d`
  - `scene1-line-ad`, `scene1-line-bc`, `scene1-line-ab`, `scene1-line-oa`, `scene1-line-ob`
  - `scene1-fill-trapezoid`, `scene1-fill-oab`, `scene1-fill-oad`, `scene1-fill-obc`
  - `scene1-label-s1`, `scene1-label-s2`, `scene1-label-halfk-oad`, `scene1-label-halfk-obc`
  - `scene1-formula-1`, `scene1-formula-2`, `scene1-conclusion`, `scene1-answer`
  - `scene1-btn-prev`, `scene1-btn-next`, `scene1-step-text`, `scene1-step-panel`
- IIFE隔离：所有JavaScript代码包裹在`(function() { ... })()`中，避免全局命名空间污染
