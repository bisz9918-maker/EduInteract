[图示主题与整合说明]
- 本图示主题：动态验证反比例函数图像上任意两点构成的梯形面积 S₁ 与三角形面积 S₂ 之比恒为 1:1
- 整合内容：反比例函数 y=k/x 的图像、双点拖拽交互、实时面积计算、比值不变性验证、k 的几何意义（S△OAD=S△OBC=k/2）
- 教学价值：教师可现场拖拽点 A、B 沿曲线移动，让学生直观观察无论两点位置如何变化，S₁:S₂ 始终为 1:1，从而深刻理解"任意性"结论与 k 的几何意义

[分步序列]
本场景为连续拖拽交互，无分步导航，按状态描述如下：
- 初始状态：
  - 显示完整坐标系、曲线 y=4/x、点 A(1,4) 与 B(4,1)、垂线 AD 与 BC、梯形 ABCD、△OAB、△OAD、△OBC
  - 数值面板显示初始面积：S₁=7.50，S₂=7.50，S△OAD=2.00，S△OBC=2.00，S₁:S₂=1:1，k=4
  - 底部显示 k 滑块，当前值 4
- 交互过程（教师拖拽点 A）：
  - 鼠标按下点 A → A 半径放大至 6px，cursor 变为 grabbing
  - 鼠标水平移动 → A 沿曲线 y=k/x 约束移动（x∈[0.8, x_B−0.3]），AD 垂线、梯形、△OAB、△OAD 实时重绘
  - 数值面板实时更新：S₁、S₂ 同步变化但始终保持相等，S△OAD 与 S△OBC 恒等于 k/2，S₁:S₂ 始终显示 1:1
  - 鼠标释放 → A 恢复半径 4px
- 交互过程（教师拖拽点 B）：
  - 与拖拽 A 对称，B 沿曲线约束移动（x∈[x_A+0.3, 5.5]），BC 垂线及相关图形实时重绘
- 交互过程（教师拖动 k 滑块）：
  - k 值在 [1, 8] 范围内变化
  - 曲线形状改变，A、B 的 y 坐标按新 k 值重新计算（x 坐标保持不变）
  - 若某点 y 值超过坐标系上限（y>6），自动将其 x 调整为 k/6 以确保可见
  - 所有面积数值实时更新，S₁:S₂ 仍保持 1:1
- 重置操作：
  - 点击「重置」→ A 恢复至 (1,4)，B 恢复至 (4,1)，k 恢复至 4，所有图形与数值复位

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无需额外库，SVG 适合几何图形，原生 JS 足以处理拖拽与实时更新）
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  y↑                                              |
  |   |    y=k/x    A●──────D                        |
  |   |          ／  │      │     数值面板            |
  |   |        ／    │ 梯形 │     +--------------+    |
  |   |      B●──────C      │     | 面积实时计算 |    |
  |   |     /  △OAB         │     | S₁ = 7.50   |    |
  |   |    /  △OAD △OBC     │     | S₂ = 7.50   |    |
  |   |   O──────────────→x │     | S₁:S₂ = 1:1 |    |
  |   |                     │     | [  重置  ]   |    |
  |   +---------------------+     +--------------+    |
  |        k = [━━━━●━━━━] 4                         |
  +--------------------------------------------------+
  [控件栏 y=440~490：k滑块]
  ```
- 关键实现要点：
  1. 坐标映射系统：
     - dataToPixel(x, y): px = 80 + x * 80, py = 420 - y * 60（x 轴 80px/单位，y 轴 60px/单位）
     - pixelToData(px, py): x = (px - 80) / 80, y = (420 - py) / 60
  2. 曲线路径生成：根据当前 k 值，采样 x∈[max(0.1,k/6), 5.5] 范围内若干点，用 L 命令连接成 SVG path
  3. 拖拽约束逻辑：
     - 拖拽 A 时：根据鼠标 x 像素计算 dataX，限制在 [max(0.8, k/6+0.1), dataX_B - 0.3]，然后 y = k / x
     - 拖拽 B 时：dataX 限制在 [dataX_A + 0.3, 5.5]，然后 y = k / x
     - 确保 A 始终在 B 的左上方，维持梯形不翻转
  4. 面积实时计算（使用数据坐标，非像素）：
     - S₁ = (x_A + x_B) * (y_A - y_B) / 2 = k * (x_B² - x_A²) / (2 * x_A * x_B)
     - S₂ = |x_A * y_B - x_B * y_A| / 2 = k * (x_B² - x_A²) / (2 * x_A * x_B)
     - S△OAD = x_A * y_A / 2 = k / 2
     - S△OBC = x_B * y_B / 2 = k / 2
  5. k 滑块实现：
     - 轨道 (150,460) 宽 150px，映射到 k∈[1,8]
     - thumb 位置 = 150 + (k-1)/7 * 150
     - 改变 k 后：若当前 A、B 的 y=k/x > 6，则将其 x 调整为 k/6（保证在可视区）
  6. 动画与过渡：拖拽时图形实时更新（无缓动，直接跟随鼠标）；数值变化直接更新 innerText
  7. 事件绑定：
     - mousedown 在点 A/B 上 → 记录拖拽起点与当前数据坐标
     - mousemove 在 SVG 上 → 若处于拖拽状态，更新点坐标并重绘相关元素
     - mouseup / mouseleave → 结束拖拽
     - input/change 在滑块上 → 更新 k 值并重绘
     - click 在重置按钮 → 恢复初始值
- ID 命名规范：所有交互元素 ID 必须以 `scene2-` 为前缀，例如：
  - `scene2-point-a`, `scene2-point-b`
  - `scene2-trapezoid-abcd`, `scene2-triangle-oab`, `scene2-triangle-oad`, `scene2-triangle-obc`
  - `scene2-curve-path`
  - `scene2-value-s1`, `scene2-value-s2`, `scene2-value-ratio`
  - `scene2-slider-track`, `scene2-slider-thumb`, `scene2-slider-value`
  - `scene2-btn-reset`
  - JS 中使用 `document.getElementById` 获取元素，禁止跨场景选择器
- IIFE 隔离：所有 JavaScript 代码包裹在 `(function() { ... })()` 中，避免全局变量污染
