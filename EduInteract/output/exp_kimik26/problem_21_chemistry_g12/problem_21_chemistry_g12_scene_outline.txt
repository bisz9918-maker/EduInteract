    **完整题目原文：**

    如图所示，a、b是两根石墨棒。下列叙述正确的是（  ）

    A．a为阳极，发生氧化反应：锌为负极被还原
    B．电路中电子流动方向：锌→b→a→铜
    C．电路中通过0.2mol电子，铜片上产生2.24L气体
    D．往滤纸上滴加酚酞，b极附近颜色变红

    **题目分析：**

    本题是一道原电池与电解池组合装置的电化学选择题。左侧为Zn−Cu−稀硫酸构成的原电池，右侧为浸有饱和食盐水的滤纸与两根石墨棒(a、b)构成的电解池。解题关键在于：
    1. 正确判断原电池的正负极
    2. 根据导线连接确定电解池的阴阳极
    3. 准确书写两极半反应并分析产物
    4. 明确电子只能在导线中流动，不能在电解质溶液中流动

    **整体讲解思路：**

    先通过装置图引导学生识别左侧为原电池、右侧为电解池；再根据金属活泼性判断Zn为负极、Cu为正极；进而由导线连接推出a为阳极、b为阴极；随后分析各电极反应式；最后逐一判断四个选项的正误，重点剖析B选项（电子流向）和C选项（气体体积条件）两个易错点。

    **本图示教学说明：**

    本图示（SCENE_2）用于在学生明确装置和电极名称后，进一步推导各电极的半反应式，并据此逐一分析四个选项的正误。

    **电极反应推导：**

    1. 原电池负极(Zn)：Zn − 2e⁻ → Zn²⁺（氧化反应）
    2. 原电池正极(Cu)：2H⁺ + 2e⁻ → H₂↑（还原反应）
    3. 电解池阳极(a)：2Cl⁻ − 2e⁻ → Cl₂↑（氧化反应，Cl⁻放电优先于OH⁻）
    4. 电解池阴极(b)：2H₂O + 2e⁻ → H₂↑ + 2OH⁻（还原反应，H⁺/H₂O放电）

    **选项分析要点：**

    - **A选项**：前半句"a为阳极，发生氧化反应"正确；后半句"锌为负极被还原"错误——锌作为负极失去电子，发生的是氧化反应（被氧化）。
    - **B选项**：电子在外电路中从Zn经导线流向b（阴极），从a（阳极）经导线流向Cu；但电子**不能**在电解质溶液中流动，溶液中靠离子定向移动导电。因此"锌→b→a→铜"的连续流向表述错误。
    - **C选项**：Cu片上反应为2H⁺ + 2e⁻ → H₂↑，通过0.2mol电子确实生成0.1mol H₂。但题目未指明"标准状况"，气体体积不一定为2.24L。这是常见陷阱。
    - **D选项**：b极为阴极，反应生成OH⁻，使附近溶液呈碱性。酚酞遇碱变红，因此D正确。

    **课堂建议：** 讲解B选项时，务必强调"电子不下水，离子不上岸"；讲解C选项时，提醒学生气体体积计算必须满足标准状况（0℃、101kPa）。

    **总结：完整解答与课堂讲解建议**

    **正确答案：D**

    **完整推导回顾：**

    1. 左侧Zn−Cu−稀硫酸构成原电池：Zn更活泼，作负极；Cu作正极。
    2. 右侧饱和食盐水滤纸与石墨棒构成电解池：a与Cu（正极）相连，作阳极；b与Zn（负极）相连，作阴极。
    3. 负极(Zn)：Zn − 2e⁻ → Zn²⁺（氧化）
    4. 正极(Cu)：2H⁺ + 2e⁻ → H₂↑（还原）
    5. 阳极(a)：2Cl⁻ − 2e⁻ → Cl₂↑（氧化）
    6. 阴极(b)：2H₂O + 2e⁻ → H₂↑ + 2OH⁻（还原）
    7. b极生成OH⁻，附近呈碱性，滴加酚酞变红，故D正确。

    **课堂讲解建议：**

    - **引入环节**：先让学生观察装置图，判断有几个池子、分别是什么类型。
    - **推导环节**：用SCENE_1分步展示电极判断和电子/离子流向，强调"电子只在导线走，离子只在溶液动"。
    - **深化环节**：用SCENE_2展示半反应，特别指出电解饱和食盐水时阴极产生H₂和OH⁻（不是Cl⁻放电）。
    - **辨析环节**：重点讨论B、C两个易错选项。B错在电子流经溶液；C错在未给标准状况。
    - **记忆口诀**：可总结"活泼金属作负极，失电子被氧化；连正极为阳极，阴离子来放电"。
