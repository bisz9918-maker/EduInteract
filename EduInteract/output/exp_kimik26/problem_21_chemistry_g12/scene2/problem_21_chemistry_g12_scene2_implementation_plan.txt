[图示主题与整合说明]
- 本图示主题：电极反应式与选项正误分析（原电池-电解池串联装置）
- 整合的步骤/概念：
  1) 原电池（Zn-Cu/稀硫酸）两极半反应与电子流向；
  2) 电解池（石墨a、b/饱和食盐水滤纸）两极半反应与产物判断；
  3) 选项A/B/C/D逐一正误辨析；
  4) D选项b极附近酚酞变红的微观原理特写。
- 教学价值：教师可通过分步导航，先让学生判断电极极性，再写出半反应，随后逐一分析选项，最后聚焦D选项的微观本质（阴极区OH⁻富集使酚酞变红），随时可回退强调易错点（如电子不经过溶液、未指明标况等）。

[分步序列]
- 步骤0（装置简图）：显示标题、烧杯、Zn/Cu电极、滤纸、a/b电极、导线、全部基础标签（Zn/Cu/a/b/稀硫酸/滤纸）。无反应式、无选项、无气泡。等待教师点击「下一步」。
- 步骤1（原电池反应）：
  → 显示 Zn反应框（x=20, y=295）及引线，文本"Zn − 2e⁻ → Zn²⁺"，红字红框，下方标注"氧化"（红）。
  → 显示 Cu反应框（x=210, y=295）及引线，文本"2H⁺ + 2e⁻ → H₂↑"，绿字绿框，下方标注"还原"（绿）。
  → Zn电极描边变红（stroke=#c62828, stroke-width=3），Cu电极描边变绿（stroke=#2e7d32, stroke-width=3）。
  → Cu极右上方出现气泡图标（cx=210, cy=90, r=7, #90caf9）。
- 步骤2（电解池反应）：
  → 保留步骤1所有元素。
  → 新增 a反应框（x=400, y=295）及引线，文本"2Cl⁻ − 2e⁻ → Cl₂↑"，红字红框，下方标注"氧化"（红）。
  → 新增 b反应框（x=590, y=295）及引线，文本"2H₂O + 2e⁻ → H₂↑ + 2OH⁻"，绿字绿框，下方标注"还原"（绿）。
  → a电极描边变红，b电极描边变绿。
  → a极左上方出现黄绿色气泡（cx=500, cy=90, r=7, #cddc39）；b极右上方出现浅蓝气泡（cx=655, cy=90, r=7, #90caf9）。
- 步骤3（选项分析）：
  → 隐藏全部反应框、引线、气泡、电极高亮描边（恢复默认黑色描边）。
  → 显示 A/B/C/D 四个选项卡片（y=300，横向等间距）。
  → A、B、C卡片右侧绘红色叉号（×），边框红色#c62828；D卡片右侧绘绿色对勾（✓），边框绿色#2e7d32。
  → A下方显示错误原因"锌被氧化而非还原"；B下方显示"电子不经过溶液"；C下方显示"未指明标准状况"；D下方显示高亮文本"b极附近OH⁻↑，酚酞变红"（绿色）。
- 步骤4（D选项特写）：
  → 隐藏选项卡片及对错标记。
  → 在下半部分（y=280~430）显示 b极特写：大滤纸椭圆（cx=400, cy=350, rx=130, ry=55），b极插入其中（x=395~405, y=290~360）。

  → 显示标注"碱性增强 → 酚酞变红"（x=520, y=340）。
  → 显示特写滤纸标签"饱和食盐水滤纸"（x=400, y=420）。
  → 上半部分装置图保持可见，但电极高亮描边恢复默认。

[交互方案]
- 交互类型：分步按钮导航（◀ 上一步 / 下一步 ▶）
- 控件说明：
  1. 「上一步」按钮：位于 SVG 内底部 (280,455)，宽80高30。点击后 currentStep 减1，回退到前一步状态，所有视觉元素按步骤定义显示/隐藏。
  2. 「下一步」按钮：位于 SVG 内底部 (440,455)，宽80高30。点击后 currentStep 加1，推进到下一步状态。
  3. 步骤指示器：位于两按钮中间上方 (400,450)，显示"步骤 X/5"。
- 教师操作流程：
  1. 教师展示步骤0，让学生观察装置并判断哪边是原电池、哪边是电解池；
  2. 点击「下一步」进入步骤1，引导学生写出原电池两极反应，注意Zn为负极发生氧化；
  3. 点击「下一步」进入步骤2，引导学生写出电解池两极反应，注意a接正极为阳极、b接负极为阴极；
  4. 点击「下一步」进入步骤3，让学生先自行判断A/B/C/D正误，再揭示答案与错因；
  5. 点击「下一步」进入步骤4，聚焦D选项，放大b极附近微观过程，讲解OH⁻生成与酚酞变色原理；
  6. 可随时点击「上一步」回退，复习易错点（如B选项电子不经过溶液、C选项标况问题）。

[技术实现]
- JS库选择：原生 SVG + 原生 JavaScript（无外部库）。理由：本场景以静态几何图形、文本框、简单显隐切换为主，无需复杂数据绑定或3D渲染，原生SVG性能最优、依赖最少。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |              标题区 (y=0~40)                       |
  |  原电池侧 (x=80~280)        电解池侧 (x=420~720)   |
  |  +--------+                  +----------+          |
  |  | 稀硫酸  |                  |  滤纸    |          |
  |  |  Zn Cu |                  |   a  b   |          |
  |  +--------+                  +----------+          |
  |       \                        /                   |
  |        \______ 导线 __________/                    |
  |                                                    |
  |  内容区 (y=290~430)：反应式 / 选项卡片 / 特写图    |
  |  [反应框] [反应框] [反应框] [反应框]   或          |
  |  [A][B][C][D] 卡片              或                 |
  |  [      b极特写滤纸图       ]                      |
  |                                                    |
  |  [◀上一步]    步骤 X/5    [下一步▶]  (y=455~485)  |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `let currentStep = 0;`（范围0~4）。每步定义一个配置对象数组 `stepConfig`，每个元素记录该步应 `show` 的 ID 列表和应 `hide` 的 ID 列表。点击按钮时调用 `renderStep()`，遍历配置切换 `display` 属性（或 CSS class `.hidden`）。
  2. 坐标计算：所有坐标硬编码于 SVG 的 `x/y/cx/cy` 属性中，确保与布局坐标表完全一致。反应框使用 `<g>` 分组，内部包含 `<rect>`、`<text>`、引线 `<polyline>`，通过组的 ID 统一显隐。
  3. 动画曲线：本场景以即时切换为主，无需复杂动画。气泡出现可辅以 CSS `transition: opacity 0.3s ease`；步骤4的酚酞渐变使用 SVG `<radialGradient>` 静态呈现，无需帧动画。
  4. 事件绑定：按钮使用 `onclick` 属性绑定 IIFE 内部函数 `prevStep()` / `nextStep()`，并做边界检查（currentStep<=0 时禁用上一步，currentStep>=4 时禁用下一步）。
  5. 电极高亮：通过动态修改对应电极 `<rect>` 的 `stroke` 和 `stroke-width` 实现，步骤切换时恢复默认值。
  6. 选项卡片对错标记：使用 SVG `<text>` 绘制"×"和"✓"，置于卡片右侧内部（x+140, y+28），颜色分别为 #c62828 和 #2e7d32。
  7. 引线绘制：使用 `<polyline>`，点坐标严格按布局坐标表，描边 #999999，线宽 1.5，仅在对应步骤显示。
- ID 命名规范：所有交互元素 ID 必须以 `scene2-` 为前缀。例如：
  - 电极：`scene2-zn-rod`、`scene2-cu-rod`、`scene2-rod-a`、`scene2-rod-b`
  - 反应框组：`scene2-rxn-zn`、`scene2-rxn-cu`、`scene2-rxn-a`、`scene2-rxn-b`
  - 选项卡片：`scene2-opt-a`、`scene2-opt-b`、`scene2-opt-c`、`scene2-opt-d`
  - 特写元素：`scene2-closeup-group`、`scene2-closeup-paper`、`scene2-closeup-rod-b`
  - 按钮：`scene2-btn-prev`、`scene2-btn-next`
  - JS 中统一使用 `document.getElementById()` 获取，禁止 `querySelectorAll` 配合全局 class。
- IIFE 隔离：所有 JavaScript 包在 `(function() { ... })();` 中，避免多场景合并时变量污染。
