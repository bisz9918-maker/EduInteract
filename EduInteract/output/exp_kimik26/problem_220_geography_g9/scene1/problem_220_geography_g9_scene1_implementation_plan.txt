[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「上一步」按钮：位于(280,455)，宽80×高32，点击回退到上一状态，第一步时禁用
  2. 「下一步」按钮：位于(440,455)，宽80×高32，点击推进到下一状态，最后一步时禁用
  3. 步骤指示器：位于(370,490)，显示"步骤 X/5"，提示当前进度
- 教师操作流程：
  1. 教师打开图示，学生看到初始环流侧视图（步骤0）
  2. 教师点击「下一步」进入步骤1，讲解"热升冷降"原理，观察冷区蓝、热区红及垂直箭头高亮
  3. 教师点击「下一步」进入步骤2，讲解温度分布规律，观察T标注和选项A错误标记
  4. 教师点击「下一步」进入步骤3，讲解气压分布与等压面弯曲，观察绿色等压面和选项B错误标记
  5. 教师点击「下一步」进入步骤4，展示正确结论，完成讲解
  6. 讲解过程中可随时点击「上一步」回退，强化学生记忆薄弱点

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：本场景为静态几何图形与分步显隐控制，无复杂动画或数据可视化，原生SVG足以精确绘制平行四边形、箭头、贝塞尔曲线等压面，原生JS状态机即可管理分步逻辑，无需引入外部库。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------------+
  |  d ←——————①——————→ c                                  |
  |  ↑                  ↑                                   |
  | ④|                  |②                                  |
  |  ↓                  ↓                                   |
  |  a ←——————③——————→ b    [选项A/B标记区]                |
  |  /=====================/                                |
  | /   地面平行四边形    /                                 |
  |/_____________________/                                  |
  |                                                         |
  |              [控件栏：◀上一步  步骤X/5  下一步▶]        |
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：定义常量STATE_COUNT=5，当前状态currentState从0到4。每一步切换时，根据状态索引显示/隐藏对应元素组（给元素分组添加data-step属性）。
  2. 箭头实现：使用SVG <marker>定义箭头头部，在<path>或<line>的marker-end属性引用。
  3. 等压面曲线：使用SVG <path>的Cubic Bezier曲线（C命令）绘制平滑上凸/下凹形态。近地面等压面控制点设计为在a处上凸（y=270）、在b处下凹（y=380）；高空等压面在d处下凹（y=210）、在c处上凸（y=100）。
  4. 动画曲线：分步切换不使用复杂动画，采用直接显隐（display/visibility切换），保证教师控制节奏时的即时响应。如需柔和过渡，可添加0.2s的opacity过渡。
  5. 事件绑定：上一步/下一步按钮绑定click事件，更新currentState后调用render()函数，render函数遍历所有带data-step属性的元素，根据元素step值与currentState的关系决定显示或隐藏。
  6. 按钮状态管理：currentState===0时禁用「上一步」，currentState===STATE_COUNT-1时禁用「下一步」，通过添加/移除disabled类实现视觉反馈。
- **ID命名规范**：所有SVG元素及交互控件ID必须以`scene1-`为前缀。例如：地面平行四边形id="scene1-ground"，箭头①id="scene1-arrow-1"，冷区填充id="scene1-cold-zone"，上一步按钮id="scene1-btn-prev"，下一步按钮id="scene1-btn-next"。JS中严格使用document.getElementById获取元素，禁止querySelectorAll配合全局class，避免多场景合并时跨场景污染。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })()` 立即执行函数中，变量与函数不污染全局作用域。
