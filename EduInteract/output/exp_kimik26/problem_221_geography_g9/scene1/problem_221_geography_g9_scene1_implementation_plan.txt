[图示主题与整合说明]
- 本图示主题：光照图综合判读——从晨昏线到地方时、直射点与昼长
- 整合的步骤/概念：
  1. 原始光照图基础判读（经纬网、晨昏线、昼夜分布）
  2. 东西半球划分与甲地地方时确定（赤道晨线6:00）
  3. 太阳直射点经度推导（30°W→60°E，向东90°）与南北半球判断（直射北半球）
  4. 乙地日出时刻与昼长计算（经度差7.5°→时差30min→日出6:30→昼长11h）
  5. 农历十五满月升起等待时间（东八区16:00→月出18:00，等待约2h）
- 教学价值：教师通过分步导航控制课堂节奏，每步聚焦一个知识点，可随时回退强化。图示将抽象经度计算与直观光照图结合，降低学生空间思维门槛。

- "直射北半球"(400,90) 与 "30°W"(350,50)：差√(50²+40²)=64px → 无冲突

- "乙"(515,285) 与 "23.5°S"(190,285)：差325px → 无冲突
- "日出6:30"(500,300) 与 "乙"(515,285)：差√(15²+15²)=21px → 无冲突（略上调"日出6:30"至(500,305)，差√(15²+20²)=25px）

- "满月18:00"(600,430) 与 "等待约2h"(550,445)：差√(50²+15²)=52px → 无冲突

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  · 「上一步」按钮：位置(280,460)，宽80×高30，灰色底。点击后currentStep减1，回退到上一步视觉状态。
  · 步骤指示器：位置(400,480)，显示"当前步 / 总步数"（如"2 / 5"）。
  · 「下一步」按钮：位置(440,460)，宽80×高30，蓝色底(#1565c0)白字。点击后currentStep加1，进入下一步视觉状态。
  · 边界处理：currentStep=0时「上一步」禁用；currentStep=4时「下一步」禁用（或变为「完成」）。
- 教师操作流程：
  1. 教师打开图示，学生观察步骤0的基础光照图，建立空间印象。
  2. 教师点击「下一步」进入步骤1，讲解东西半球划分（20°W以西为西半球）和赤道晨线地方时6:00。
  3. 点击「下一步」进入步骤2，引导学生从30°W向东推90°得到直射经线60°E，结合乙地位置判断直射北半球。
  4. 点击「下一步」进入步骤3，计算乙地经度差7.5°→时差30min→日出6:30→昼长11h。
  5. 点击「下一步」进入步骤4，通过时间轴展示区时换算与月相等待时间。
  6. 讲解中可随时回退到任意步骤提问或复习。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript（无外部库）。理由：本场景为静态几何图形与分步显隐，SVG路径、文本、填充即可满足，无需引入D3/Three.js等重型库，保持代码轻量。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  800×500 画布
  +--------------------------------------------------------+
  |  37.5°W    30°W      22.5°W                           |
  |     |       |          |      西半球  直射北半球  东半球 |
  |  +--|-------|----------|--+    [推导框，步骤2-3显示]    |
  | 0°-+   甲 ● |          |  |    太阳直射点经度推导       |
  |    |  黑夜  |          |  |    乙地昼长计算             |
  |    |  填充  |          |  |                             |
  |23.5°S------|----------|--┘                             |
  |     \      乙 ●        /                               |
  |      \  晨昏线        /                                |
  |       +--------------+                                 |
  |                                                        |
  |  [时间轴区，步骤4显示]                                  |
  |  30°W 6:00 ---- 上海16:00 === 满月18:00                |
  |              [等待约2h]                                |
  |                                                        |
  |      [上一步]  2 / 5  [下一步]                         |
  |       280,460        440,460                           |
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用currentStep变量（0~4），showStep(n)函数统一控制。所有步骤专属元素按<g id="scene1-step-N">分组，通过设置display属性显隐。
  2. 推导框内容切换：步骤2和步骤3共用同一个推导框背景，但内部文字分为两个<g>组（scene1-derive-step2、scene1-derive-step3），根据currentStep切换显隐。
  3. 坐标计算：晨昏线端点(294,60)和(500,280)通过两点式确定，确保过甲(350,120)和乙(500,280)。黑夜多边形顶点按顺时针排列。
  4. 动画曲线：本场景为分步切换，无需连续动画。步骤切换时直接显隐（duration=0），保证教师控制即时响应。如需柔和过渡，可在CSS中设置transition: opacity 0.2s。
  5. 事件绑定：上一步/下一步按钮绑定click事件，更新currentStep后调用showStep()。按钮在边界步骤禁用（opacity 0.4，pointer-events none）。
  6. 时间轴绘制：步骤4单独控制显隐。等待高亮块使用半透明绿色rect覆盖500~600区间。
  7. 箭头绘制：使用SVG <path> + marker-end定义箭头符号，颜色#1565c0。
- ID命名规范：
  · 所有SVG元素ID必须以scene1-为前缀
  · 示例：scene1-grid-frame、scene1-dawn-line、scene1-point-jia、scene1-step1-group、scene1-prev-btn、scene1-next-btn、scene1-derive-box、scene1-timeline-axis
  · JS中获取元素使用document.getElementById，禁止使用querySelectorAll配合全局class
- IIFE隔离：所有JavaScript代码包裹在 (function() { ... })() 中，避免多场景合并时变量污染。
