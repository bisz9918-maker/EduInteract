[图示主题与整合说明]
- 本图示主题：正午太阳高度角的几何意义与太阳能电池板安装角
- 整合的步骤/概念：
  1. 从晨昏线与经线夹角提取太阳直射点纬度（10°N）；
  2. 利用正午太阳高度公式计算上海（31°N）的正午太阳高度 H = 69°；
  3. 将三维空间关系（垂直墙面、电池板平面、太阳光线）转化为二维剖面；
  4. 通过法线与太阳光线平行的几何关系，推导电池板与墙面的最佳夹角 θ = H = 69°。
- 教学价值：教师可借助分步导航，引导学生从地理条件（晨昏线夹角）逐步过渡到物理几何（电池板安装角），建立跨学科知识链条。每一步均可回退，便于复习巩固。

[分步序列]
- 步骤0（条件解读）：
  - 显示元素：纬度轴线、31°N/10°N/0°刻度、上海红点、直射点蓝点、全部纬度标签。
  - 顶部文字："晨昏线与经线夹角 = 太阳直射点纬度 = 10°"。
  - 目的：建立已知条件，说明10°N直射纬度的来源。

- 步骤1（太阳高度计算）：
  - 保留步骤0所有元素（纬度轴可适度降 opacity 至0.4，避免喧宾夺主）。
  - 新增：地面线、地面填充、太阳光线、H角度弧、"地面"/"太阳光线"/"H = 69°"标签。
  - 顶部文字："正午太阳高度角 H = 90° - |φ - δ|"；第二行公式："H = 90° - (31° - 10°) = 69°"。
  - 目的：展示公式代入与几何化（光线与地面69°）。

- 步骤2（几何剖面）：
  - 保留步骤1所有元素。
  - 新增：墙面、电池板、θ角度弧、"墙面"/"电池板"/"θ = 69°"标签。
  - 顶部文字："电池板平面与太阳光线垂直时，接收效率最高"。
  - 目的：引入垂直墙面与倾斜电池板，建立待求角θ。

- 步骤3（结论推导）：
  - 保留步骤2所有元素。
  - 新增：法线（绿色虚线）、"法线"标签。
  - 顶部文字："电池板法线 ∥ 太阳光线 → θ = H = 69°"。
  - 目的：通过法线辅助说明电池板与墙面夹角等于太阳高度角，得出最佳安装角约为69°。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：本场景为静态几何图形与分步显隐，无需复杂数据绑定或3D渲染，原生SVG即可精确控制每个元素的坐标、旋转和透明度。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图：
  ```
  [800×500 画布]
  +--------------------------------------------------+
  |  顶部说明/公式区 (y=15~60)                        |
  |  +----------------------------------------------+ |
  |  | 左侧纬度轴 (x=30~100, y=100~340)              | |
  |  |  · 31°N 上海(红)                              | |
  |  |  · 10°N 直射点(蓝)                            | |
  |  |  · 0° 赤道                                    | |
  |  +----------------------------------------------+ |
  |  |        中央主图区 (x=250~650, y=80~420)       | |
  |  |           太阳光线 ↘                          | |
  |  |    地面 ======================== 墙面 |       | |
  |  |                          电池板∠θ   |       | |
  |  |                              ↗ 法线 |       | |
  |  +----------------------------------------------+ |
  |  [控件栏: ◀上一步  步骤k/4  下一步▶]  (y=450~490) |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 `currentStep`（0~3）控制当前步骤。每步用一个配置对象描述应显示的元素ID列表、应隐藏的元素ID列表、顶部文字内容。
  2. 坐标计算：
     - 太阳光线斜率：tan(69°)≈2.605，端点(620,52)到(494,380)，确保经过墙面顶端(540,260)。
     - 电池板旋转：`<rect transform="rotate(-21, 540, 260)"/>`，-21° = -(90°-69°)，确保与光线垂直。
     - H角度弧：SVG path使用A指令，从(494+35,380)到(494+35*cos69°,380-35*sin69°)。
     - θ角度弧：从(540,260-30)到(540+30*cos21°,260-30*sin21°)，大弧标志为0。
  3. 动画曲线：分步切换不使用动画，直接显隐（opacity或display），保证教师点击后瞬间呈现完整图形，不拖沓。若需柔和过渡，可使用CSS transition: opacity 0.2s ease。
  4. 事件绑定：按钮绑定click事件，更新`currentStep`后调用`renderStep()`，遍历所有元素按配置设置`display`或`opacity`。
  5. 元素分层（SVG绘制顺序）：地面填充 → 地面线 → 墙面 → 电池板 → 太阳光线 → 法线 → 角度弧 → 标签文字。确保线条压在填充上，标签在最上层。
- ID命名规范：所有SVG元素及控件ID必须以`scene2-`为前缀。例如：
  - `scene2-lat-axis`（纬度轴线）
  - `scene2-sun-ray`（太阳光线）
  - `scene2-panel`（电池板）
  - `scene2-btn-prev`（上一步按钮）
  - `scene2-btn-next`（下一步按钮）
  - `scene2-step-text`（顶部说明文字）
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免全局变量污染，确保多场景合并时互不干扰。
