[图示主题与整合说明]
- 本图示主题：太阳直射点回归运动与南北半球季节对比
- 整合内容：将地球公转轨道图中抽象的字母位置（a/b/c/d）转化为直观的直射点纬度年变化折线、小地球侧视光照图、以及南北半球季节对照信息，覆盖题目中全部5个小问涉及的知识点（夏至光热最多、a位置极昼极夜、秋分赤道直射、b→c季节过渡、澳大利亚季节相反）。
- 教学价值：教师可先展示全景建立"回归"概念，再分步点击四个节气节点，配合中间小地球的晨昏线与直射光线变化，让学生建立"日期—直射纬度—昼夜长短—季节"的完整因果链；最后一步集中呈现季节过渡与南北半球对比，直接回应题目(4)(5)。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：
  1. 「◀ 上一步」按钮：绝对定位 (300,455)，宽 80×高 30。点击后 currentStep 减 1，更新所有视觉元素。步骤0 时禁用（opacity 0.4，pointer-events none）。
  2. 「下一步 ▶」按钮：绝对定位 (420,455)，宽 80×高 30。点击后 currentStep 加 1，更新所有视觉元素。步骤5 时禁用。
  3. 步骤指示器：SVG text 元素 (660,470)，显示 "步骤 X/5"，字体 14px，#666。
- 教师操作流程：
  1. 课堂开始时保持步骤0，教师讲解"回归运动"全景概念，指出四个关键节点。
  2. 点击「下一步」进入步骤1（春分），配合讲解赤道直射、全球昼夜平分。
  3. 继续点击到步骤2（夏至），强调北回归线、北半球夏季、光热最多，可让学生观察晨昏线倾斜与北极圈极昼。
  4. 步骤3（秋分）与步骤1对照，强化"回归"概念。
  5. 步骤4（冬至）与步骤2对照，强调南北半球相反。
  6. 步骤5 集中讲解题目(4)(5)：b→c过渡、澳大利亚季节，用对比条强化记忆。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript。理由：本场景以静态几何图形和状态切换为主，无复杂动画或数据可视化，原生 SVG 足以精确控制每个元素的坐标、颜色、显隐；无需引入 D3/Three.js 等重型库，保持代码轻量。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图（ASCII）：
  ```
  800×500 画布
  +--------------------------------------------------------+
  | 左侧回归运动图(20~280)   | 中间地球(300~520) | 右侧信息(540~780) |
  |  纬度轴+轨迹折线+节点    |   地球圆+地轴+    |   季节/对比文字    |
  |  23.5°N ─────────       |   晨昏线+直射光线 |                  |
  |     · 夏至              |                  |                  |
  |  0° ────────────        |                  |                  |
  |     · 春分      · 秋分  |                  |                  |
  |  23.5°S ─────────       |                  |                  |
  |     · 冬至              |                  |                  |
  |  时间轴                 |                  |                  |
  |                         |                  |                  |
  |--------------------------------------------------------|
  |        [◀ 上一步]  [下一步 ▶]          步骤 X/5         |
  +--------------------------------------------------------+
  y=20~435 主图区    y=445~485 控件区（绝对定位按钮）
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `let currentStep = 0;`（范围 0~5）。每次点击按钮时更新 `currentStep`，调用 `renderStep()` 统一更新所有 SVG 元素属性（显隐、颜色、坐标、文本内容）。
  2. 节点高亮逻辑：在 `renderStep()` 中遍历四个节点，根据 `currentStep` 设置对应节点的 fill（#c62828 或 #1565c0）、r（6 或 4）、以及光晕圆的显隐。
  3. 地球状态切换：预定义三个地球配置对象（springAutumn / summer / winter），包含地轴端点坐标、直射y坐标、夜半球 path d 属性。`renderStep()` 根据步骤选择对应配置，直接设置 SVG 元素的 d、x1/y1/x2/y2、cy 等属性。
  4. 右侧文本切换：右侧所有 text 元素预先在 SVG 中创建好，但初始 `display:none`。`renderStep()` 中先隐藏所有右侧文本组（step0-group、step14-group、step5-group），再显示当前步骤对应的组，并填充对应文本内容。
  5. 步骤5轨迹段高亮：可通过在折线上方叠加一条粗线段（stroke-width 4px，#c62828）或改变整条折线颜色实现。建议叠加一条独立 polyline 连接春分-夏至，默认 hidden，步骤5 时显示。
  6. 动画曲线：状态切换不使用复杂动画，仅使用 CSS transition（opacity 0.3s ease）实现文本淡入淡出，确保课堂切换流畅不拖沓。
  7. 事件绑定：按钮使用 `onclick` 绑定，`scene2-btn-prev` 与 `scene2-btn-next`。
- ID 命名规范：所有 SVG 元素与 HTML 控件 ID 必须以 `scene2-` 为前缀。例如：
  - 轨迹折线：`scene2-track-line`
  - 春分节点：`scene2-node-spring`
  - 地球圆：`scene2-earth-ocean`
  - 地轴：`scene2-earth-axis`
  - 夜半球：`scene2-earth-night`
  - 直射光线：`scene2-sunray`
  - 上一步按钮：`scene2-btn-prev`
  - 下一步按钮：`scene2-btn-next`
  - 步骤指示器：`scene2-step-indicator`
  - 右侧信息组：`scene2-info-step0`、`scene2-info-step1` 等
  JS 中严格使用 `document.getElementById('scene2-xxx')` 获取元素，禁止 querySelectorAll 配合全局 class。
- IIFE 隔离：所有 JavaScript 代码包裹在 `(function() { ... })();` 中，避免全局变量污染，确保多场景合并时互不干扰。
- SVG 结构建议：使用 `<g>` 分组管理，如 `<g id="scene2-left-panel">`、`<g id="scene2-earth-panel">`、`<g id="scene2-right-panel">`，便于整体显隐控制。
- clipPath 定义：在 `<defs>` 中定义 `<clipPath id="scene2-earth-clip"><circle cx="410" cy="200" r="55"/></clipPath>`，夜半球 path 使用 `clip-path="url(#scene2-earth-clip)"`。
