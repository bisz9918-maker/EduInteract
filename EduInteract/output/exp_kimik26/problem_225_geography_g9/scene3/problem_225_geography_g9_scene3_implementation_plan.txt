- 本图示主题：半球分界线与纬度带划分

[分步序列]
- 初始状态（步骤0）：显示完整经纬网底图（外框、经线、纬线、经纬度标注）和A/B/C/D四点及点标签。教师可讲解经纬网读图基础。
- 步骤1（点击下一步）：叠加赤道线（绿色粗实线）和"赤道0°"标签；北半球区域填充蓝色半透明，南半球填充绿色半透明；在A/B/C旁出现"北半球"标签（蓝色），D旁出现"南半球"标签（绿色）。教师讲解赤道划分南北半球。
- 步骤2（点击下一步）：叠加160°E经线（红色虚线，x=240）和20°W经线（红色虚线，x=60），配标签；东半球区域（20°W→160°E）填充蓝色半透明，西半球填充红色半透明；在A/C旁出现"东半球"标签（蓝色），B/D旁出现"西半球"标签（红色）。教师讲解东西半球分界线。
- 步骤3（点击下一步）：叠加30°N、30°S、60°N、60°S四条紫色虚线，配标签；低纬区（0°-30°）填充黄色半透明，中纬区（30°-60°）填充橙色半透明，高纬区（60°-90°）填充紫色半透明；在C/D旁出现"低纬度"标签，B旁出现"中纬度"标签，A旁出现"高纬度"标签。教师讲解低/中/高纬度划分。
- 步骤4（点击下一步）：所有半透明填充区域淡出隐藏，半球/纬度文字标注隐藏，仅保留所有分界线和四点；右侧弹出汇总表格，列出A/B/C/D三列归类结果。教师带领学生从直观色块过渡到表格归纳。
- 步骤5（点击下一步/自动进入）：表格各行变为可点击状态。教师点击某一行（如A行），对应点A在图上高亮闪烁（半径放大+颜色高亮），实现表图联动复习。点击不同行可切换高亮点。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本场景以静态几何图形和状态切换为主，无需复杂数据绑定或3D渲染，原生SVG性能最优且文件体积最小。
- 画布尺寸：800×500px（固定）。SVG viewBox="0 0 800 500"，嵌入HTML容器。
- 布局草图（ASCII）：
  ```
  0    80   160  240  320  400  480  520       780  800
  +----+----+----+----+----+----+----+---------+----+
  | 120°E 140°E 160°E 180° 160°W 140°W | 汇总表格  |
  | 80°N ·A···························· | [步骤4-5] |
  | 60°N ······························ |         |
  | 40°N ····························B· |         |
  | 20°N ·C···························· |         |
  |  0°  ·········赤道················· |         |
  | 20°S ····························D· |         |
  |      [主图区：经纬网+分界线+填充]    |         |
  |                                    |         |
  +------------------------------------+---------+
  |         [上一步]  [下一步]                   |  y=455
  +----------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `currentStep`（0~5）。每步用一个配置对象定义该步应显示的元素ID数组。`renderStep()`函数根据currentStep设置对应元素的 `display` 或 `opacity`。
  2. 元素分层：SVG中按"底图→填充→线条→点→标签→表格"顺序绘制，确保点和标签始终在线条上方。
  3. 动画曲线：步骤切换时，填充区域使用CSS transition（opacity 0.3s ease），线条使用stroke-dasharray动画（可选），表格使用淡入（opacity 0→1，0.3s）。
  4. 表格行点击：为4个表格行组（g元素）绑定click事件，点击时先清除所有点的高亮类，再给对应点添加高亮类。高亮使用CSS `@keyframes pulse` 实现半径缩放和颜色闪烁（0.6s无限循环）。
  5. 20°W经线处理：该经线在图外（x=60），从y=60画到y=360，用红色虚线表示，配"20°W"标签在(40,200)，教学中强调其位于图外左侧。
  6. 60°S纬线处理：该纬线在网格下方（y=420），从x=80画到x=480，配"60°S"标签在(485,420)。
- ID命名规范：所有交互元素ID必须以 `scene3-` 为前缀。例如：
  - 底图：`scene3-grid-frame`, `scene3-meridian-120e` 等
  - 点：`scene3-point-a`, `scene3-point-b`, `scene3-point-c`, `scene3-point-d`
  - 步骤元素：`scene3-equator-line`, `scene3-north-fill`, `scene3-east-fill`, `scene3-line-20w`, `scene3-lat-fill-low1` 等
  - 表格：`scene3-summary-table`, `scene3-table-row-a` 等
  - 控件：`scene3-btn-prev`, `scene3-btn-next`, `scene3-step-text`
  - JS中严格使用 `document.getElementById` 获取元素，禁止全局class选择器。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免多场景合并时的变量污染。
