[图示主题与整合说明]
- 本图示主题：地球侧视光照图综合判读（节气、太阳直射点、昼夜长短、地方时）
- 整合的步骤/概念：①太阳光线与昼夜半球分布（题目原图完整呈现）；②太阳直射点位置与节气日期判断；③极昼、极夜范围标注；④晨昏线性质判读（晨线/昏线）与地球自转方向示意；⑤A、B、C三点地方时与昼夜状况分析；⑥北半球昼夜长短特征总结
- 教学价值：教师通过分步导航控制信息呈现节奏，从"读图→抓关键特征→得出结论"逐层递进，可随时回退复习，适合课堂讲解与学生跟随思考

[分步序列]
- 步骤0（初始状态）：显示地球圆、地轴(N/S标签)、5条纬线及右侧标注、晨昏线、5条太阳光线及"太阳光线"文字、昼/夜半球填充、A/B/C三点及标签。无高亮，无额外标注。教师引导学生观察原图整体特征。
- 步骤1（太阳直射点与节气）：新增①北回归线变为红色实线（线宽2px）高亮；②太阳直射点红色圆点(250,200)；③左侧红色文字组"太阳直射点"/"23°26′N"/"夏至"/"6月22日"。教师讲解直射点位置与节气判断依据。
- 步骤2（极昼极夜范围）：新增①北极圈以内弓形填充绿色半透明（极昼区）；②南极圈以内弓形填充蓝色半透明（极夜区）；③"极昼"标签(470,140)；④"极夜"标签(330,370)。教师讲解极昼极夜范围与纬度关系。
- 步骤3（晨昏线与自转）：新增①晨昏线变为红色实线（线宽2.5px）高亮；②北极附近蓝色逆时针弧线箭头；③"晨线"标签(340,120)。教师讲解晨昏线判读与地球自转方向。
- 步骤4（地方时分析）：新增①A点地方时框(260,235)文字"12:00 正午"；②B点地方时框(375,110)文字"6:00 日出"；③C点地方时框(490,315)文字"0:00 深夜"。教师讲解三点地方时差异与昼夜状况。
- 步骤5（昼夜长短总结）：新增画面顶部中央文字"北半球：昼最长，夜最短"(320,80)。教师总结北半球夏至日昼夜长短特征，完成全题讲解。
- 教师可随时点击「◀上一步」回退，点击「下一步▶」前进，步骤指示器实时更新。

  4. 点击「下一步」进入步骤3，高亮晨昏线与自转方向，教师讲解晨线判读

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本scene为静态几何图形与分步显隐，无复杂动画或数据可视化，原生SVG足以高效绘制地球、经纬线、填充区域；原生JS即可实现状态机与DOM显隐控制，无需引入外部库减少加载开销。
- 画布尺寸：800×500px（固定SVG画布）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------------+
  |  [总结文字区 y=80]                                     |
  |                                                        |
  |   太阳光线  地球球体(居中偏右)                    C    |
  |      ↓↓   /  N  \                                .     |
  |      ↓↓  /  .B   \                                \    |
  |      ↓↓ |  .A      |                                \  |
  |      ↓↓  \        /                                  | |
  |      ↓↓   \  S  /                                   | |
  |            -----                                    | |
  |   [直射点标注区]         [晨线/极昼标签]             | |
  |                                                        |
  |   [极夜标签]                                           |
  |                                                        |
  |        [◀ 上一步]   [步骤指示]   [下一步 ▶]          |  y=460
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：变量`currentStep`（0~5），每步对应一个元素显隐组。使用数组`stepElements`存储每步应显示/隐藏的DOM ID列表。
  2. 坐标计算：地球圆(400,250,R150)；晨昏线通过圆与直线交点公式计算得(344,111)和(456,389)；昼/夜半球使用SVG path + Arc命令绘制；极昼/极夜区使用弓形path（北极圈y=160、南极圈y=340与圆的交集）。
  3. 动画曲线：步骤切换时，新增元素使用CSS transition `opacity 0→1, 300ms ease-out`淡入；高亮元素（如北回归线、晨昏线）使用CSS transition `stroke-width 1px→2.5px, 200ms ease`。
  4. 事件绑定：上一步/下一步按钮绑定click事件，调用`updateScene(step)`函数，该函数遍历所有步骤相关元素，设置`display`或`opacity`属性。
  5. 夜半球斜线阴影：SVG `<pattern id="scene1-night-pattern" patternUnits="userSpaceOnUse" width="8" height="8"><path d="M0,8 L8,0" stroke="#000" stroke-width="0.5" opacity="0.1"/></pattern>`，夜半球path填充此pattern。
  6. 地球自转箭头：SVG path画圆弧`M 425 130 A 25 25 0 0 1 475 130`，末端用`<marker>`定义箭头，方向表示逆时针。
  7. 地方时标注框：`<rect>`白底黑框，内部`<text>`居中，整体作为一个group控制显隐。
- ID命名规范：所有SVG元素与交互元素ID必须以`scene1-`为前缀。例如：`scene1-earth`、`scene1-axis`、`scene1-sunray-group`、`scene1-step1-highlight`、`scene1-step2-polar-day`、`scene1-btn-prev`、`scene1-btn-next`。JS中严格使用`document.getElementById`获取元素，禁止全局class选择器，避免多场景合并时跨场景污染。
- IIFE隔离：所有JavaScript代码包裹在`(function() { ... })();`中，内部变量与函数不污染全局作用域。
