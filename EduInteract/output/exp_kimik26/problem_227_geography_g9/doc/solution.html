场景导航：Scene 1 | Scene 2

题目原文

读"经纬网图"（下图），判断下列各题。

【小题1】ABCD四点都位于北半球、东半球。（）

【小题2】若沿虚线由B点去D点，前进方向的变化过程是：先向东北，再向东南。（）

题目分析

本题考查经纬网判读、半球划分和球面方向判断，包含两个核心易错点：

  1. 东西半球的划分界线：学生容易误认为0°和180°经线是东西半球的分界，实际上分界是 20°W 和 160°E 组成的经线圈。
  2. 球面最短路径的方向变化：在平面地图上沿纬线看是"正东"，但球面上两点间的最短路径（大圆航线）在北半球会向北凸出，导致前进方向发生变化。

整体讲解思路

先通过经纬网图判读A、B、C、D四点的经纬度坐标；再利用东西半球划分界线判断小题1；最后通过对比"沿纬线直走"与"球面最短路径"的差异，理解方向变化规律，判断小题2。

图示规划说明

设计两个独立图示。图示1用于展示半球划分，在经纬网上叠加东西半球界线（20°W、160°E），直观显示170°E和170°W均位于西半球。图示2用于展示B到D的方向变化，对比平面圆柱投影上的直线路径与球面最短路径（大圆航线），分解"东北→东南"的方向变化过程。

步骤 1/5

本图示教学说明

教师使用此图时，应重点引导学生完成"判读坐标→定位半球"的推理链条。

引导学生观察的要点：

  1. 先让学生独立判读四点纬度：A、C约在35°N，B、D在20°N，全部位于赤道以北，因此都在北半球。
  2. 再让学生判读经度：A、B在170°E，C、D在170°W。此时提问"它们在东半球还是西半球？"引出东西半球划分界线的知识点。
  3. 强调易错点：东西半球的分界线不是0°和180°，而是20°W和160°E。可以让学生在图上找到160°E的位置，观察170°E在其东侧，因此属于西半球。

关键知识点：

  • 东半球范围：20°W 向东至 160°E
  • 西半球范围：160°E 向东至 20°W（即160°E以西、20°W以东）
  • 170°E 位于 160°E 以东 → 西半球
  • 170°W 位于 160°E 以东（沿经度圈）→ 西半球

推导步骤：

  1. 四点纬度均在20°N~40°N之间 → 全部位于北半球
  2. A、B经度为170°E，C、D经度为170°W
  3. 160°E 是东半球最东界，170°E 在其东侧 → 西半球
  4. 170°W 同样位于160°E以东的经度区间 → 西半球
  5. 结论：四点都在西半球，并非都在东半球，小题1判断为 错误（×）
步骤 1/6

本图示教学说明

教师使用此图时，应重点帮助学生建立"平面地图"与"球面实际"的差异意识。

引导学生观察的要点：

  1. 先让学生观察B、D两点的坐标：同在20°N，经度分别为170°E和170°W。在平面地图上，两点在同一纬线上，学生容易直觉认为"向正东走"。
  2. 展示步骤1的"沿纬线正东"路径，确认学生的直觉；然后展示步骤2的"最短路径"弧线，制造认知冲突。
  3. 解释原因：球面上两点之间的最短路径是大圆航线（过地心的平面与地球表面的交线）。在北半球，同纬度（非赤道）两点间的大圆航线会向北凸出。
  4. 配合步骤3的方向箭头，让学生看到：从B出发时朝向东北，路径逐渐转向正东（最高点），最后转向东南到达D。

关键知识点：

  • 球面上两点间的最短路径是大圆航线，不是沿纬线的直线
  • 北半球同纬度两点间的大圆航线向北凸出（偏向北极）
  • 南半球同纬度两点间的大圆航线向南凸出（偏向南极）
  • 因此从B到D，前进方向变化为：东北 → 东南

推导步骤：

  1. B（170°E，20°N）、D（170°W，20°N）位于同一纬线，经度差40°
  2. 若沿20°N纬线行走，方向始终为正东
  3. 但球面上最短路径为大圆航线，北半球同纬度两点间大圆航线向北凸出
  4. 从B出发需先向东北方向前进，到达最高纬度点后转向东南
  5. 结论：前进方向变化是"先东北，再东南"，小题2判断为 正确（√）

课堂讲解建议

  • 建议配合地球仪实物演示：在地球仪上找到北半球同纬度的两点，用细线绷紧连接，让学生直观看到细线向北凸出，而非沿纬线。
  • 强调"东北→东南"是北半球大圆航线的典型方向特征，可类比飞机航线（如北京飞往纽约的航线向北凸）加深理解。
  • 提醒学生注意题目中"沿虚线"的表述，在经纬网题中虚线通常指最短路径（大圆航线）在地图上的投影，而非沿纬线直走。
