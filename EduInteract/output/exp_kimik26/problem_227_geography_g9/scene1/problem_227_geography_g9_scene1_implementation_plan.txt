[图示主题与整合说明]
- 本图示主题：经纬网半球判定（地理九年级）
- 整合的步骤/概念：经纬度坐标判读 → 南北半球判定（赤道为界） → 东西半球划分界线（20°W与160°E） → 四点经度定位 → 小题1结论推导
- 教学价值：教师通过分步导航，逐层叠加地理界线与填充区域，引导学生从"已知经纬网"到"半球归属"再到"命题判断"的完整思维链，避免信息一次性呈现造成的认知负荷。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 内 (300,460)，宽80×高30，点击回退到上一状态，步骤0时禁用（opacity 0.4）
  - 「下一步」按钮：位于 SVG 内 (500,460)，宽80×高30，点击前进到下一状态，步骤4时禁用（opacity 0.4）
  - 步骤指示器：位于 (400,460)，显示"步骤 X/5"
- 教师操作流程：
  1. 教师展示步骤0，让学生观察A/B/C/D四点的经纬度位置
  2. 点击「下一步」进入步骤1，讲解赤道与北半球概念，观察蓝色填充
  3. 点击「下一步」进入步骤2，讲解20°W/160°E界线，观察红绿填充分区
  4. 点击「下一步」进入步骤3，强调170°E/170°W均落在红色西半球区域
  5. 点击「下一步」进入步骤4，得出小题1结论（×）
  6. 可随时回退到任意步骤复习

[技术实现]
- JS库选择：原生 SVG + 原生 JavaScript（无外部库）。理由：本场景为简单几何图形（线段、矩形、圆、文字）的组合与显隐切换，SVG原生API完全满足，无需引入D3等重型库，保持代码轻量。
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  +----------------------------------------------------------+
  |  北半球(420,85) / 经度说明(400,85)                        |
  |                                                          |
  |  东半球(90,220)                                          |
  |    |  A(260,150)•    |    C(580,150)•    |      40°(620,115)|
  |160°E|       |       |       |       |20°W    30°(620,195)|
  |    |       |       |       |       |        20°(620,275)|
  |    |  B(260,270)•---•---•D(580,270)  |                 |
  |    |       |       |       |       |                 |
  |    +-------+-------+-------+-------+                 |
  |           赤道(0°) y=350                                |
  |                                                          |
  |           结论文字(400,420)                              |
  |       [上一步]  步骤 X/5  [下一步]                       |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `currentStep`（0~4），`updateScene(step)` 函数根据步骤索引控制各 SVG 组的显隐（display: block/none）。每个步骤对应一个 `<g>` 分组（如 `scene1-step1-group`），便于批量控制。
  2. 坐标计算：经纬网区域宽600px（x=120~720），高240px（y=110~350）。纬线等距分布（间距80px），经线170°E/180°/170°W间距160px/160px，辅助线160°E和20°W分别位于区域两侧边界。
  3. 动画曲线：无需复杂动画，步骤切换使用直接显隐（无过渡），确保教学演示响应迅速。如需柔和过渡，可对填充区域使用 CSS `transition: opacity 0.3s`。
  4. 事件绑定：上一步/下一步按钮绑定 `click` 事件，调用 `prevStep()` / `nextStep()`，更新 `currentStep` 后调用 `updateScene()` 并刷新按钮禁用状态。
  5. 高亮经线覆盖：步骤3的170°E/170°W高亮线（红色2.5px）与默认黑色经线使用相同坐标，但位于更高 SVG 层级（后绘制），实现视觉覆盖效果。
  6. 填充区域层级：填充矩形应绘制在经纬线之下（先绘制），避免遮挡黑色经线。使用 SVG 的绘制顺序控制：先填充 → 再经纬线 → 再点与标注。
- ID命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀。例如：
  - 经线：`scene1-meridian-170e`、`scene1-meridian-180`、`scene1-meridian-170w`
  - 高亮经线：`scene1-highlight-170e`、`scene1-highlight-170w`
  - 填充：`scene1-fill-north`、`scene1-fill-west`、`scene1-fill-east`
  - 按钮：`scene1-btn-prev`、`scene1-btn-next`
  - 步骤组：`scene1-step0-group`、`scene1-step1-group`、...、`scene1-step4-group`
  - JS中严格使用 `document.getElementById`，禁止 `querySelectorAll` 配合全局 class，避免多场景合并时跨场景污染。
- IIFE隔离：所有 JavaScript 代码包裹在 `(function() { ... })();` 中，变量与函数不污染全局作用域。
