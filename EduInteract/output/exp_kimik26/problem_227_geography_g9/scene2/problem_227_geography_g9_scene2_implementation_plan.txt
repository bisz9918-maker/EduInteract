[图示主题与整合说明]
- 本图示主题：球面最短路径与方向变化（经纬网大圆航线）
- 整合的步骤/概念：
  1) 建立B(170°E, 20°N)与D(170°W, 20°N)的平面位置关系；
  2) 对比沿20°N纬线的"正东"路径与向北凸出的球面最短路径（大圆航线）；
  3) 分解最短路径上的方向变化：起点东北→弧顶正东→终点前东南；
  4) 动画演示移动点沿大圆航线前进，直观呈现"先东北，再东南"；
  5) 得出小题2结论。
- 教学价值：教师通过分步对比，引导学生从平面直觉（沿纬线正东）过渡到球面抽象（大圆航线方向变化），用动画强化空间认知。

[分步序列]
- 步骤0（初始状态）：显示完整经纬网、A/B/C/D四点、B→D灰色虚线路径、所有经纬度标注。等待教师触发。
- 步骤1（沿纬线路径）：点击「下一步」→ 20°N纬线高亮（橙色加粗）；出现水平向右灰色箭头及"正东"标注(445,280)；出现"沿20°N纬线"标注(320,300)。讲解：沿纬线走方向始终是正东。
- 步骤2（最短路径）：点击「下一步」→ 叠加蓝色弧线（大圆航线）及标注"最短路径（大圆航线）"(400,90)。讲解：球面上B到D的最短路径不是直线，而是向北凸出的大圆航线。
- 步骤3（方向分解）：点击「下一步」→ 在弧线上出现3个红色方向箭头及标注：起点处"东北"(270,205)、弧顶处"正东"(445,170)、终点前"东南"(535,250)。讲解：方向先东北，再正东，再东南。
- 步骤4（动态演示）：点击「下一步」→ 绿色圆点从B沿蓝色弧线动画移动到D（约2秒），同时实时显示红色方向箭头指示当前前进方向；动画期间「下一步」按钮禁用，完成后启用，圆点停留在D点。讲解：直观观察方向变化过程。
- 步骤5（得出结论）：点击「下一步」→ 显示结论文字"沿最短路径从B到D，方向先东北后东南，故小题2正确（√）"于(400,400)。讲解：总结判断结果。
- 教师可随时点击「上一步」回退到任意步骤复习。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：本场景为2D几何图示，以路径、线段、箭头为主，无需复杂数据绑定或3D渲染；原生SVG路径（<path>、<line>、<text>）配合JS状态机即可高效实现，避免引入冗余库。
- 画布尺寸：800×500 px（固定）。
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  40°  A-----------------------C                   |  y=120
  |       |       |       |       |                  |
  |  30°  |       |       |       |   东北  正东      |  y=200
  |       |       |       |       |      ↗   →       |
  |  20°  B=======D       ↑       |         ↘ 东南   |  y=280
  |       |       |       |       |                  |
  |      170°E   180°   170°W     |                  |
  |                               |                  |
  |         [结论文字区域]        |                  |  y=400
  |                               |                  |
  |    [◀上一步] [步骤X/6] [下一步▶]                |  y=452
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1) 状态机设计：定义全局变量 `let currentStep = 0;`，共6个状态（0~5）。每个状态对应一个 `renderStep(n)` 函数，函数内先清空/隐藏所有步骤专属元素（通过设置 `display: none` 或移除），再按状态创建/显示对应元素。
  2) 贝塞尔曲线计算：定义函数 `bezierPoint(t, p0, p1, p2)` 和 `bezierTangent(t, p0, p1, p2)`，用于计算二次贝塞尔曲线上任意点的坐标和切线向量。切线向量归一化后用于绘制方向箭头。
  3) 箭头绘制：封装 `drawArrow(x1, y1, x2, y2, color, width)`，计算线段角度，在终点处用三角函数绘制箭头翼（翼长10px，翼角30°）。
  4) 动画曲线（步骤4）：使用 `requestAnimationFrame`，定义 `animateDot(startTime)`，计算已过去时间 `elapsed`，t = elapsed / 2000（2秒完成），t 用 `Math.min(t, 1)` 截断。每帧：
     - 计算当前点坐标和切线方向；
     - 更新移动点 `<circle>` 的 cx/cy；
     - 更新动画箭头 `<line>` 和箭头翼的坐标；
     - 当 t >= 1 时，动画结束，恢复「下一步」按钮。
  5) 事件绑定：上一步/下一步按钮绑定 `click` 事件，调用 `setStep(currentStep ± 1)`。`setStep` 内先检查边界（0~5），若进入步骤4则自动触发 `playAnimation()` 并禁用下一步按钮。
  6) 元素ID规范：所有SVG元素和HTML控件ID必须以 `scene2-` 为前缀，例如 `scene2-grid-line-40n`、`scene2-arc-shortest`、`scene2-btn-next`、`scene2-label-northeast`。禁止用 `querySelectorAll` 配合全局class，一律用 `getElementById` 获取元素。
  7) IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免多场景合并时变量污染。
  8) 按钮样式：圆角4px，背景#e0e0e0，边框1px solid #bdbdbd，hover时背景#bdbdbd；禁用状态背景#f5f5f5，文字#9e9e9e。
