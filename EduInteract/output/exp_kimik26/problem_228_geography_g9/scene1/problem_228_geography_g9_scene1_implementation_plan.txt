[图示主题与整合说明]
- 本图示主题：晨昏线光照图中的日期界线判定与太阳直射点定位
- 整合的步骤/概念：
  1. 原图基础条件展示（上南下北矩形经纬网、纬度0°/23.5°N/70°N、AO昏线/BO晨线、阴影日期变更区）
  2. 日期界线判定（阴影区边界为180°经线与0时经线，O点切点所在经线即为0时经线90°W）
  3. 地方时推算链（B点赤道晨线6:00→O点切点0:00→A点地方时约20:00→夜长约8h）
  4. 太阳直射点定位（12时经线90°E与0时经线90°W相对；夏至日直射23.5°N）
  5. 极昼区判定与结论汇总（北极圈66.5°N以北极昼、夏至日、五问答案汇总）
- 教学价值：教师可先让学生观察原图，再逐步揭示日期界线、地方时推算、直射点定位的完整推理链，支持随时回退复习。

[分步序列]
- 步骤0「原图条件」：显示经纬网格、0°/23.5°N/70°N纬线、6条经线（细线）、AO昏线（红）、BO晨线（绿）、阴影区斜线填充、A/B/O三点及标签、右侧纬度标签（0°、23.5°N、70°N）。不显示经度数值、时间、日期界线、直射点、极昼区。教师可让学生先观察原图，思考阴影区含义。
- 步骤1「日期界线」：新增阴影区蓝色半透明填充；180°经线（x=120）加粗变红并标注"180°经线"；90°W经线（x=320）加粗变蓝并标注"0时经线 90°W"；底部显示6个经度标签。教师讲解：阴影区日期与其他地区不同→边界必为180°经线与0时经线→O为切点，地方时0:00→O所在经线即0时经线。
- 步骤2「地方时推算」：B点旁绿色标注"6:00"；O点旁蓝色标注"0:00"；A点旁黑色标注"日落约20:00"及"夜长约8h"；网格下方O到B之间画辅助双向箭头标注"90°→6h"。教师讲解：B在赤道晨线上为6:00；O与B差90°→6小时；O为0:00；A在昏线上，经度约150°W，地方时约20:00，夜长约8小时。
- 步骤3「直射点定位」：右上角出现太阳符号及"太阳直射点 90°E, 23.5°N"；标注"夏至日"；从90°W经线引虚线箭头指向太阳符号，标注"相对经线 12时"。教师讲解：0时经线90°W→12时经线90°E；夏至日直射北回归线23.5°N。
- 步骤4「结论汇总」：网格底部y=365~380填充金色半透明表示极昼区；左下角标注"极昼区 北极圈66.5°N以北"；右侧显示结论汇总框，内含五问关键答案：①夏至日/北极圈以北极昼 ②B:6:00 O:0:00 ③A:~150°W 夜长~8h ④90°E,23.5°N ⑤47°。教师可对照汇总完整回顾。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位置(300,465)，宽90×高28，圆角矩形，主色#1565c0，白色文字。点击回退到上一步骤，步骤0时禁用（opacity:0.4）。
  - 「下一步 ▶」按钮：位置(460,465)，宽90×高28，样式同上。点击前进到下一步，步骤4时禁用。
  - 步骤标题文本：位置(400,445)，居中显示当前步骤名称（如"步骤2/5：地方时推算"），字体14px，颜色#333。
- 教师操作流程：
  1. 加载后处于步骤0，展示原图，教师提问学生观察到了哪些信息。
  2. 点击「下一步」进入步骤1，揭示日期界线，教师讲解阴影区与日期变更的关系。
  3. 点击「下一步」进入步骤2，显示地方时推算链，教师引导学生从B点6:00推算到O点0:00再到A点日落时间。
  4. 点击「下一步」进入步骤3，定位太阳直射点，教师讲解0时经线与12时经线的相对关系。
  5. 点击「下一步」进入步骤4，展示极昼区和结论汇总，教师对照答案完整梳理五问。
  6. 可随时点击「上一步」回退到任意步骤复习。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本场景为静态几何图形与分步状态切换，无需复杂数据绑定或3D渲染，原生SVG性能最优且文件体积最小。
- 画布尺寸：800×500 px（SVG viewBox="0 0 800 500"）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  太阳符号(步骤3)                                   |
  |                                          0°      |
  |    B●                                    23.5°N  |
  |     \                                    70°N    |
  |      \    阴影区(斜线+蓝半透明)                   |
  |       \  /                                         |
  |        O●(70°N)                                   |
  |  极昼区(金色,步骤4)                                |
  |  结论汇总框(步骤4)                                 |
  |  180°  135°W  90°W  45°W  0°  45°E               |
  |  [◀ 上一步]  步骤标题  [下一步 ▶]                 |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  - 状态机设计：用变量currentStep（0~4）控制当前步骤，所有视觉元素初始opacity:0或display:none，根据currentStep值通过setAttribute切换显示。
  - 元素分组：按步骤将元素包裹在<g id="scene1-step1-group">等容器中，切换时直接控制组的display属性，简化状态管理。
  - 阴影区斜线填充：使用SVG <pattern id="scene1-hatch" patternUnits="userSpaceOnUse" width="8" height="8"><path d="M0,8 L8,0" stroke="#1565c0" stroke-width="1"/></pattern>。
  - 极昼区y坐标计算：66.5°N在0°~70°N之间的比例为66.5/70，y=80+(66.5/70)*300≈365.7，取366px。
  - 动画曲线：步骤切换时，新增元素使用CSS transition: opacity 0.3s ease-in-out，避免突兀出现。
  - 按钮状态：步骤0时「上一步」disabled=true；步骤4时「下一步」disabled=true；通过JS动态更新disabled属性和opacity。
  - 辅助引线：步骤2的"90°→6h"双向箭头使用SVG <path>画弧线（d="M320,390 Q420,420 520,390"），文字用<text>居中于(420,405)。
  - 结论汇总框内容：使用5个<text>元素垂直排列，行距20px，x=715居中（text-anchor:middle）。
- ID命名规范：所有元素ID必须以scene1-为前缀。例如：scene1-grid、scene1-lat-0、scene1-ao-line、scene1-point-o、scene1-step2-time-b、scene1-btn-prev、scene1-btn-next。
- IIFE隔离：所有JavaScript代码包裹在(function() { ... })()中，避免全局变量污染。
