[图示主题与整合说明]
- 本图示主题：A地（23.5°N）正午太阳高度的夏至与冬至对比
- 整合内容：
  1. 夏至状态：太阳直射北回归线，A地正午太阳高度90°（阳光垂直入射）
  2. 冬至状态：太阳直射南回归线，A地正午太阳高度43°（阳光斜射）
  3. 差值计算：90° - 43° = 47°
- 教学价值：教师通过一键切换夏至/冬至两种状态，让学生直观对比同一地点在不同节气的正午太阳高度差异，理解太阳直射点季节移动对太阳高度的影响，并引出公式 H = 90° - |φ - δ|。

[分步序列]
本场景为「多状态切换」交互，两个状态：

- 状态A「夏至」（初始状态）：
  - 显示元素：地球、地轴、赤道、A点、太阳(620,240)、3条水平光线（中红色直射A点）、直角符号+90°标注、夏至公式、差值结论、夏至按钮高亮（红色背景）
  - 隐藏元素：S点、冬至光线、43°标注、冬至公式、冬至太阳
  - 公式显示：H = 90° - |23.5° - 23.5°| = 90°

- 状态B「冬至」（点击「冬至状态」按钮切换）：
  - 显示元素：地球、地轴、赤道、A点、S点、太阳(482,120)、3条倾斜光线（中蓝色直射方向）、43°角弧线+标注、冬至公式、差值结论、冬至按钮高亮（蓝色背景）
  - 隐藏元素：夏至太阳、水平光线、直角符号、90°标注、夏至公式
  - 公式显示：H = 90° - |23.5° - (-23.5°)| = 43°
  - 动画：太阳光线角度从水平平滑过渡到倾斜（约300ms），太阳位置从(620,240)移动到(482,120)，A点标注从90°切换到43°

- 两种状态始终显示：
  - 差值结论：一年中正午太阳高度最大值与最小值之差 = 90° - 43° = 47°

  - 「冬至状态」按钮：位置(460, 460)，宽140×高36。点击切换到冬至状态，按钮背景变为#1565c0（蓝），文字白色。
- 教师操作流程：
  1. 初始加载为夏至状态，教师讲解太阳直射北回归线时A地太阳高度90°
  2. 点击「冬至状态」按钮，图示平滑过渡到冬至状态，教师讲解太阳直射南回归线时A地太阳高度43°
  3. 引导学生观察差值47°，理解正午太阳高度年变化幅度
  4. 可反复切换两个状态，强化对比印象

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：本场景为静态几何图示加状态切换，无需复杂图表库，原生SVG即可精确控制所有图形元素的位置和样式。
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [标题区 y=0~60]
        A地（23.5°N）正午太阳高度对比
  
  [主图区 y=60~370]
   地球(左)          太阳(右)
   圆心(250,240)     夏至(620,240)
   半径120           冬至(482,120)
   A点(370,240)      光线→
   S点(332,328)      
   
  [公式区 y=375~440]
   ┌─────────────────────────────┐
   │  H = 90° - |φ - δ| = ...    │
   │  差值 = 47°                  │
   └─────────────────────────────┘
  
  [控件区 y=440~500]
     [夏至状态]    [冬至状态]
     (300,460)    (460,460)
  ```
- 关键实现要点：
  1. 状态机设计：用变量 `currentState` 记录当前状态（'summer'/'winter'），点击按钮时调用 `setState(state)` 函数。
  2. 元素显隐控制：所有状态专属元素（光线、太阳、角度标注、S点等）初始按夏至状态设置。切换时通过 `setAttribute('display', 'none'/'block')` 或 CSS opacity 过渡控制显隐。
  3. 动画曲线：状态切换时，太阳位置移动和光线角度变化使用 CSS transition（300ms ease-in-out）或 JS requestAnimationFrame 实现平滑过渡。若用SVG原生动画，可用 `<animate>` 元素的 `begin` 触发。
  4. 按钮高亮：当前激活按钮添加 class `active-summer` 或 `active-winter`，设置对应背景色和白色文字。
  5. 公式切换：公式文字使用同一个 `<text>` 元素，切换时修改其 `textContent`。
  6. 角度弧线绘制：
     - 夏至直角符号：SVG path `M 370 240 L 385 240 L 385 225`
     - 冬至角弧线：SVG path 使用 arc 命令，圆心(370,240)，半径25，从竖直方向（角度90°）到光线方向（角度约137°，即90°+47°）
  7. 光线箭头：在光线末端（地球端）添加 `<polygon>` 箭头，方向与光线一致。
- ID命名规范：
  - 地球圆：`scene2-earth`
  - 地轴：`scene2-axis`
  - A点：`scene2-point-a`
  - S点：`scene2-point-s`
  - 夏至太阳：`scene2-sun-summer`
  - 冬至太阳：`scene2-sun-winter`
  - 夏至光线组：`scene2-rays-summer`
  - 冬至光线组：`scene2-rays-winter`
  - 直角符号：`scene2-angle-90`
  - 角弧线：`scene2-angle-43`
  - 公式文字：`scene2-formula`
  - 差值文字：`scene2-diff`
  - 夏至按钮：`scene2-btn-summer`
  - 冬至按钮：`scene2-btn-winter`
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免全局变量污染。
