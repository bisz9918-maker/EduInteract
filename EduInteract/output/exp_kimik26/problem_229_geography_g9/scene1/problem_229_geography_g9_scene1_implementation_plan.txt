[图示主题与整合说明]
- 本图示主题：经纬网经纬度判读与方向判断
- 整合的步骤/概念：
  (1) 认识原始经纬网底图与已标注的经纬度；
  (2) 补全缺失的 160°E、160°W、50°N 标注，并同步呈现判读规则；
  (3) 依次高亮 D、E、F 三点，弹出各自的经纬度坐标；
  (4) 以 A 点为原点建立方向十字，配合 D→A 示意线得出"西北方向"结论；
  (5) 以 F 点为原点建立方向十字，沿 50°N 劣弧高亮 E→F 路径，得出"正东方向"结论。
- 教学价值：教师可按照"识图→补全→判读→应用"的递进逻辑分步讲解，每步只呈现当前所需信息，避免信息过载；学生能直观看到"同经线正南正北、同纬线正东正西"的规律。

[分步序列]
- 步骤0（基础图）：显示完整经纬网底图（5经3纬）、已标注经度（140°E、180°、140°W）、已标注纬度（60°N、40°N）、四个黑点及字母标签 D/A/E/F。隐藏所有补全标注、坐标、辅助线、结论。
- 步骤1（补全标注）：自动显示 160°E（蓝）、160°W（红）、50°N（蓝）；在图下方弹出规则提示"纬度向北增大→北纬"和"180°以西为东经，以东为西经"。
- 步骤2（D点坐标）：隐藏规则提示；D点高亮（蓝圈放大）；在 D 点右下方弹出绿色坐标标签 "D (60°N, 140°E)"。
- 步骤3（E点坐标）：D点恢复常态；E点高亮；在 E 点右下方弹出 "E (50°N, 140°E)"。
- 步骤4（F点坐标）：E点恢复常态；F点高亮；在 F 点右下方弹出 "F (50°N, 160°W)"。
- 步骤5（D在A的方向）：F点恢复常态；保留所有坐标标签；以 A(400,230) 为中心绘制虚线方向十字（北南各50px、东西各50px）；绘制 D→A 灰色虚线示意线（带箭头指向A）；在图下方显示绿色结论 "D在A的西北方向"。
- 步骤6（E在F的方向）：移除 A 点方向十字与 D→A 示意线；以 F(477,230) 为中心绘制虚线方向十字；沿 50°N 纬线从 E(246,230) 到 F(477,230) 绘制红色粗线劣弧（带向东箭头）；在图下方显示绿色结论 "E在F的正东方向"。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「上一步」按钮：位于 SVG 内底部左侧 (250,460)，宽80高30；点击回退到上一教学步骤。
  2. 「步骤指示」文本：位于底部中央 (400,475)，显示当前步骤序号与总步数，如"步骤 3/7"。
  3. 「下一步」按钮：位于 SVG 内底部右侧 (470,460)，宽80高30；点击前进到下一教学步骤。
- 教师操作流程：
  1. 教师打开图示，学生看到原始经纬网（步骤0）。
  2. 教师点击「下一步」，补全标注与规则出现，讲解判读方法（步骤1）。
  3. 教师继续点击「下一步」，依次高亮 D→E→F 并弹出坐标，讲解经纬度书写格式（步骤2-4）。
  4. 教师继续点击，进入方向判断环节，先以 A 为原点看 D 的相对方位，再以 F 为原点看 E 的相对方位（步骤5-6）。
  5. 教师可随时点击「上一步」回退复习。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript。理由：本场景为静态几何图示与分步显隐控制，无需复杂数据绑定或 3D 渲染，原生 SVG 性能最佳且文件体积最小。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图：
  ```
  +--------------------------------------------------+
  |  140°E  160°E  180°  160°W  140°W               |  <- 经度标注区 (y=75)
  |      \    |    |    |    /                        |
  |  60°N ---D----+----+----|--- 60°N                |  <- 60°N纬线 (y=100)
  |       \   |    A   |   /  \                      |
  |  50°N --E-+----+----F----|-- 50°N                |  <- 50°N纬线 (y=230)
  |         \ |    |    |  /                         |
  |  40°N ----+----+----+----|-- 40°N                |  <- 40°N纬线 (y=360)
  |                                                  |
  |  [规则提示/坐标结论 区域]         (y=390)        |
  |                                                  |
  |  [◀上一步]    步骤 X/7    [下一步▶]  (y=460~490) |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 `currentStep`（0~6）控制当前步骤。每步对应一个显隐配置数组，记录各元素（经度标注、纬度标注、点位高亮、坐标标签、规则提示、方向十字、示意线、劣弧、结论）的显示/隐藏状态。
  2. 坐标计算：经线采用从汇聚点(400,40)到各底部端点的直线方程，通过线性插值计算 60°N(y=100)、50°N(y=230)处的 x 坐标，确保点位精确落在经线与纬线交点。
  3. 动画曲线：元素显隐使用 CSS transition（opacity 0→1，duration 300ms，ease-in-out），点位高亮使用 r 属性过渡（4→6，duration 200ms）。
  4. 事件绑定：上一步/下一步按钮绑定 click 事件，调用 `renderStep(step)` 函数，该函数根据步骤配置批量设置各元素的 `display` 或 `opacity` 属性。
  5. 箭头实现：D→A 示意线与 E→F 劣弧使用 SVG `<marker>` 定义箭头，id 分别为 `scene1-arrow-gray` 和 `scene1-arrow-red`，在对应 line 的 marker-end 属性中引用。
  6. 方向十字：使用 stroke-dasharray="5,5" 实现虚线效果，长度各 50px，确保不超出主图区。
- ID 命名规范：所有 SVG 元素及控件 ID 必须以 `scene1-` 为前缀。例如：
  - 经线：`scene1-meridian-140e`、`scene1-meridian-180` 等
  - 纬线：`scene1-parallel-60n`、`scene1-parallel-50n` 等
  - 点位：`scene1-point-d`、`scene1-point-a` 等
  - 标签：`scene1-label-d`、`scene1-coord-d` 等
  - 按钮：`scene1-btn-prev`、`scene1-btn-next`
  - 箭头标记：`scene1-arrow-gray`、`scene1-arrow-red`
- IIFE 隔离：所有 JavaScript 代码包裹在 `(function() { ... })()` 中，避免多场景合并时的全局变量污染。
