[图示主题与整合说明]
- 本图示主题：经线圈与东西半球划分
- 整合的步骤/概念：
  (3) 与180°经线组成经线圈的经线（0°/本初子午线）及其几何关系；

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：本场景以静态几何图形、区域填充和分步显隐为主，无需复杂动画库；SVG的path可精确绘制扇形经纬网和区域填充，DOM操作即可实现分步状态切换。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图：
  ```
  +----------------------------------------------------------+
  |  140°E    180°     140°W          [第(5)题选项]          |
  |     \       |       /              A、140°E向东至180°     |
  |      D      A      F               B、140°W向东至180°     |
  |       \     |     /                C、160°E向东至180°     |
  |        \    |    /                 D、160°W向西至180°     |
  |         \   |   /                                        |
  |          \  |  /                                         |
  |           \ | /                                          |
  |            E|                                            |
  |  [图例: 蓝=东半球 红=西半球 绿=交集]                      |
  |                                                          |
  |       [◀ 上一步]   步骤 X / 6   [下一步 ▶]               |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `let currentStep = 0;`（范围0~5），对应6个状态。每步切换时调用 `renderStep()` 函数，根据 `currentStep` 值设置各SVG元素的 `display` 属性（`display: block` 或 `display: none`）。
  2. 元素分组：将每步新增的元素包在 `<g id="scene2-step1-group">` 等组中，通过控制组的显隐简化状态切换。
  3. 区域填充path：东半球区(140°E-160°E)、西半球区(160°E-140°W)、交集区(160°E-180°)均使用四边形path（直线近似，因纬线曲率小，视觉上可接受）。坐标使用预计算值，避免运行时复杂计算。
  4. 选项C高亮：使用 `<rect>` 作为背景，圆角rx=5，fill=#2e7d32，fill-opacity=0.3，位于选项C文字后方（z-index通过DOM顺序控制，先画rect后画text）。
  5. 按钮状态：当 `currentStep === 0` 时禁用「上一步」；当 `currentStep === 5` 时禁用「下一步」。
  6. 动画曲线：本场景无需复杂动画，元素直接显隐即可；若需柔和过渡，可对填充区域使用CSS `transition: opacity 0.3s ease`。
- ID命名规范：所有交互元素ID必须以 `scene2-` 为前缀。例如：
  - 180°经线：`scene2-meridian-180`
  - 0°经线组：`scene2-step1-group`
  - 东半球填充：`scene2-region-east`
  - 西半球填充：`scene2-region-west`
  - 交集填充：`scene2-region-intersection`
  - 选项C高亮：`scene2-option-c-highlight`
  - 上一步按钮：`scene2-btn-prev`
  - 下一步按钮：`scene2-btn-next`
  - 步骤指示器：`scene2-step-indicator`
  JS中严格使用 `document.getElementById` 获取元素，禁止全局class选择，避免多场景合并时跨场景污染。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，变量不泄露全局作用域。
- CDN引入：无需外部JS库，仅使用原生SVG和Vanilla JS。若需数学公式渲染，可引入MathJax，但本场景标签均为纯文本，无需公式库。
