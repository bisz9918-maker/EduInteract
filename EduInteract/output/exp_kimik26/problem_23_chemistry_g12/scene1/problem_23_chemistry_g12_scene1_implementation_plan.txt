[图示主题与整合说明]
- 本图示主题：H₂O₂分子的立体书页型构型、化学键类型识别、分子极性判断及晶体中分子间作用力示意
- 整合的步骤/概念：
  1. H₂O₂分子的立体骨架（二面角构型）
  2. 极性键（O-H）与非极性键（O-O）的识别与电子对偏移
  3. 分子极性判断——正负电荷中心不重合
  4. H₂O₂晶体中的氢键与范德华力
- 教学价值：教师通过分步导航，由浅入深引导学生观察分子结构、分析键型、理解极性成因，最后拓展到晶体中的作用力，可随时回退复习。

[分步序列]
- 步骤0（基础构型）：
  显示元素：O1、O2、H1、H2原子球；O-O、O1-H1、O2-H2三条键（均为黑色）；O、H原子标签。
  隐藏元素：所有分析标注、电荷符号、箭头、结论、下方晶体阵列。
  教学意图：让学生先识别H₂O₂的立体书页型骨架，注意二面角非平面特征。

- 步骤1（键型分析）：
  视觉变化：
  1. O-O键变为红色（#c62828），下方出现"非极性键"标签(360,235)。
  2. 两条O-H键变为蓝色（#1565c0），左外侧出现"极性键"(230,185)，右外侧出现"极性键"(510,245)。
  3. O1、O2正上方出现δ⁻(340,170)、δ⁻(420,170)。
  4. H1左下方出现δ⁺(245,155)，H2右下方出现δ⁺(505,285)。
  5. 两条O-H键上分别出现指向O的电子偏移箭头。
  教学意图：区分非极性键与极性键，强调电子对偏向电负性大的O原子。

- 步骤2（极性判断）：
  视觉变化：
  1. 在分子右上方出现蓝色"+"正电荷中心标记(420,140)。
  2. 在O原子区域下方出现红色"−"负电荷中心标记(380,250)。
  3. 两中心之间绘制灰色虚线连接。
  4. 虚线中点偏右出现"不重合"标签(450,210)。
  5. 画面右侧出现大字号结论"极性分子"(520,140)。
  教学意图：通过正负电荷中心的空间分离，直观得出极性分子结论。

- 步骤3（晶体作用力）：
  视觉变化：
  1. 主分子保持显示于上方。
  2. 画面下方出现两个缩小的H₂O₂分子（分子1中心约300,360；分子2中心约380,360）。
  3. 两分子间出现两条灰色虚线表示氢键（(340,380)-(360,360) 与 (340,340)-(320,360)）。
  4. 氢键虚线旁标注"氢键"(350,365)。
  5. 每个小分子外围出现绿色半透明椭圆表示范德华力范围。
  6. 范围圈下方标注"范德华力"(340,410)。
  教学意图：拓展到凝聚态，说明H₂O₂晶体中除化学键外还存在氢键与范德华力。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「上一步」按钮：位于(280,460)，宽80×高30，点击回退到上一状态。
  2. 「下一步」按钮：位于(440,460)，宽80×高30，点击推进到下一状态。
  3. 步骤指示文本：位于(360,465)，显示当前步骤编号（如"步骤 2/4"）。
- 教师操作流程：
  1. 教师打开图示，默认显示步骤0（分子骨架），向学生提问"观察H₂O₂的空间构型有什么特点"。
  2. 点击「下一步」进入步骤1，讲解非极性键与极性键的区别，引导学生注意电子对偏移方向。
  3. 点击「下一步」进入步骤2，让学生判断正负电荷中心是否重合，得出极性分子结论。
  4. 点击「下一步」进入步骤3，拓展讲解H₂O₂晶体中的分子间作用力，呼应选项B。
  5. 可随时点击「上一步」回退，复习前面任一环节。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：球棍模型由简单几何图形（圆、线、路径）构成，无需复杂图表库；原生JS即可实现分步状态切换。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图（ASCII）：
  ```
  0    100   200   300   400   500   600   700   800
  +-----+-----+-----+-----+-----+-----+-----+-----+  0
  |                                               |  |
  |          H₁(280,140)                          |  |
  |            ●                                  |  |
  |             \                                 |  |
  |              O₁(340,200)——O₂(420,200)         |  |
  |             /          非极性键               |  |
  |            /                                   |  |
  |          ●                                    |  |
  |        H₂(480,260)    +正电荷中心   极性分子   |  |
  |                       |                       |  |
  |                     不重合                     |  |
  |                       |                       |  |
  |                     −负电荷中心                |  |
  |                                               |  |
  |    分子1阵列      分子2阵列  (步骤3显示)        |  |
  |     ◯◯            ◯◯                          |  |
  |      氢键  范德华力                            |  |
  |                                               |  |
  |         [上一步]  步骤X/4  [下一步]            | 440
  +-----+-----+-----+-----+-----+-----+-----+-----+ 500
  ```
- 关键实现要点：
  1. 状态机设计：定义变量 `let currentStep = 0;`（范围0~3）。每步对应一个显示元素ID集合。
  2. 元素显隐：为每组步骤相关元素设置 `class="scene1-step1"` 等，通过 `document.getElementsByClassName` 批量控制 `display` 或 `visibility` 属性。步骤0元素默认显示，其余步骤默认隐藏。
  3. 键颜色切换：O-O键与O-H键在步骤0为黑色，步骤1分别切换为红色与蓝色。通过修改 `stroke` 属性实现。
  4. 坐标计算：所有原子、标签坐标已精确规划，代码中直接使用上述坐标值，无需动态计算。
  5. 动画曲线：分步切换无需复杂动画，直接显隐即可；如需柔和过渡，可对透明度使用CSS transition（0.2s ease）。
  6. 事件绑定：上一步/下一步按钮绑定 `click` 事件，更新 `currentStep` 后调用 `renderStep()` 刷新视图。
  7. 边界处理：当currentStep为0时禁用「上一步」；为3时禁用「下一步」。
- ID命名规范：所有SVG元素及控件ID必须以 `scene1-` 为前缀。例如：`scene1-atom-o1`、`scene1-bond-oo`、`scene1-label-nonpolar`、`scene1-btn-prev`、`scene1-btn-next`。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免全局变量污染，确保多场景合并时互不干扰。
