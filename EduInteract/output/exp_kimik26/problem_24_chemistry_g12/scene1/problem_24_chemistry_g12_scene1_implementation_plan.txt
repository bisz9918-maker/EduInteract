[图示主题与整合说明]
- 本图示主题：三容器初始条件与反应原理
- 整合的步骤/概念：
  1) 展示甲、乙、丙三个并排圆柱形容器及其内部初始物质的量；
  2) 高亮并连接"容积相等、温度相同"的共性条件；
  3) 引入可逆反应方程式 2NO₂ ⇌ N₂O₄，用颜色区分反应物与产物；
  4) 标注容器类型差异——甲、丙为恒容（固定活塞），乙为恒压（可滑动活塞）。
- 教学价值：教师通过分步导航，从直观容器到抽象反应原理递进展示，帮助学生先建立物理图景，再理解化学平衡问题的核心变量（体积、压强、浓度）。

[分步序列]
- 初始状态（步骤0）：
  - 显示三个容器（甲、乙、丙）及其活塞
  - 显示各容器内气体填充色块
  - 显示甲、乙、丙点名标签
  - 显示各容器内物质的量标签（"0.2 mol NO₂"×2，"0.1 mol N₂O₄"×1）
  - 隐藏：条件标注文字、三条虚线连接、反应方程式、容器类型标签
  - 按钮状态：上一步禁用，下一步可用

- 步骤1（点击下一步）：
  - 新增：画面上方中央显示绿色文字"容积相等、温度相同"
  - 新增：从该文字向三个容器顶部引出三条灰色虚线箭头
  - 视觉强调：条件文字以淡入动画出现（opacity 0→1，300ms）
  - 按钮状态：上一步可用，下一步可用

- 步骤2（点击下一步）：
  - 新增：容器下方中央显示反应方程式"2NO₂ ⇌ N₂O₄"
  - 颜色区分："2NO₂"为红色，"⇌"为黑色，"N₂O₄"为蓝色
  - 视觉强调：方程式从下方滑入（translateY +20px→0，opacity 0→1，300ms）
  - 按钮状态：上一步可用，下一步可用

- 步骤3（点击下一步）：
  - 新增：甲、丙顶部显示"恒容"（绿色），乙顶部显示"恒压"（绿色）
  - 新增：乙活塞上方显示双向滑动箭头符号（若步骤0未显示则此时显示）
  - 视觉强调：三个类型标签依次淡入（各间隔100ms）
  - 高亮：乙容器描边变为红色#c62828（stroke-width=3），持续500ms后恢复，强调乙与甲丙的差异
  - 按钮状态：上一步可用，下一步禁用（或循环回步骤0）

- 教师可随时点击「上一步」回退到任意步骤复习。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于控件栏左侧(300,455)，80×32px，点击回退到上一状态，步骤0时禁用
  - 「下一步」按钮：位于控件栏右侧(420,455)，80×32px，点击前进到下一状态，最终步骤时禁用
  - 步骤指示器：位于按钮下方中央(400,495)，显示当前步骤编号"步骤 X / 4"
- 教师操作流程：
  1. 教师打开图示，学生看到三个容器及初始物质的量（步骤0）
  2. 教师点击「下一步」，引出"容积相等、温度相同"条件，讲解三容器初始状态的一致性
  3. 教师点击「下一步」，展示反应方程式，建立化学变化的方向
  4. 教师点击「下一步」，标注容器类型，强调乙的恒压条件与甲丙恒容条件的差异，为后续平衡比较做铺垫
  5. 教师可随时回退到任意步骤，针对学生疑问反复讲解

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（场景为静态几何图形与分步显隐，无需复杂图表库）
- 画布尺寸：800 × 500 px（SVG 固定尺寸）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |              容积相等、温度相同                    |  y=20~80
  |                 (条件标注区)                       |
  |    - - - - - - - - - - - - - - - - - - - -       |
  |   +------+       +------+       +------+         |  y=100~350
  |   | 恒容 |       | 恒压 |       | 恒容 |         |  (主图区)
  |   |=======|      |<====>|      |=======|        |
  |   |       |      |       |      |       |        |
  |   |0.2 mol|      |0.2 mol|      |0.1 mol|        |
  |   | NO₂   |      | NO₂   |      | N₂O₄  |        |
  |   +------+       +------+       +------+         |
  |     甲              乙              丙            |
  |                                                  |
  |          2NO₂  ⇌  N₂O₄                          |  y=360~420
  |                                                  |
  |      [◀上一步]        [下一步▶]                  |  y=440~490
  |              步骤 X / 4                          |  (控件区)
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 `currentStep`（0~3）记录当前步骤，数组 `stepElements` 存储每步对应的SVG元素ID列表，通过显隐控制分步展示。
  2. 坐标计算：三容器水平居中，间距220px（容器宽120px + 间隙100px），起始x=120。
  3. 动画曲线：使用 CSS transition（opacity + transform），时长300ms，ease-out，保证流畅且不拖沓。
  4. 事件绑定：按钮点击事件更新 `currentStep`，调用 `renderStep()` 函数，该函数遍历所有步骤相关元素，根据当前步骤设置 `display` 或 `opacity`。
  5. 容器绘制：圆柱体用 rect + path（底部半圆）组合，气体填充用 rect 覆盖容器下半部分。
  6. 活塞绘制：恒容用粗横线+两侧短竖线表示固定；恒压用横线+上方双向箭头（SVG path绘制箭头）。
  7. 方程式分色：使用 SVG `<text>` 内嵌多个 `<tspan>`，分别设置 fill 属性实现混色文本。
