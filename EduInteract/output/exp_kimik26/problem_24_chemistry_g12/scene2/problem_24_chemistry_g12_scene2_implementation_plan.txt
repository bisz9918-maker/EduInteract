[图示主题与整合说明]
- 本图示主题：甲与丙的等效平衡及转化率关系（2NO₂ ⇌ N₂O₄）
- 整合内容：甲从 0.2 mol NO₂ 开始的平衡状态；丙从 0.1 mol N₂O₄ 开始的平衡状态；"一边倒"等效转化思想；转化率 α 与 β 的定量关系推导 α+β=1
- 教学价值：教师通过左右容器对比，配合中间代数推导，逐步建立"恒温恒容下 0.1 mol N₂O₄ 与 0.2 mol NO₂ 互为等效起始态"的核心概念，并用 α+β=1 直接说明 C 选项错误

[分步序列]
- 初始状态（步骤0）：显示甲容器+甲气体填充（红）+甲初始标签+甲名称；显示丙容器+丙气体填充（蓝）+丙初始标签+丙名称。中间及两侧平衡式均隐藏。教师可在此说明左右起始态。
- 步骤1：点击「下一步」→ 甲容器右侧出现甲平衡式组（α、n(NO₂)=0.2(1−α)、n(N₂O₄)=0.1α），配合讲解甲中NO₂转化率为α时的平衡组成。
- 步骤2：点击「下一步」→ 丙容器左侧出现丙平衡式组（β、n(N₂O₄)=0.1(1−β)、n(NO₂)=0.2β），配合讲解丙中N₂O₄转化率为β时的平衡组成。
- 步骤3：点击「下一步」→ 中间区域自上而下依次出现：等效平衡标题、双向箭头、一边倒标注、等式1、等式2、推导结论α+β=1。配合讲解"恒温恒容等效平衡"意味着各组分平衡量相等，从而建立方程并化简。
- 步骤4：点击「下一步」→ 推导结论α+β=1保持高亮，下方出现步骤4结论"α=β=0.5时两者转化率相同，C选项错误"，绿色高亮。教师可据此说明当两转化率均为0.5时恰好相同，故C选项"不可能相同"错误。
- 教师可随时点击「上一步」回退复习任意步骤。

[技术实现]
- JS 库选择：原生 SVG（简单几何与文本首选）+ 原生 JavaScript 状态机。不使用 MathJax，化学下标通过 SVG <tspan baseline-shift="sub" font-size="10"> 实现，避免外部依赖并保证渲染速度。
- 画布尺寸：800 × 500 px（固定），控件栏以 HTML 绝对定位覆盖在 SVG 内底部 y=455~487，不额外撑高容器。
- 布局草图（ASCII）：
  ```
  800×500 画布
  +----------------------------------------------------------+
  |                                                          |
  |    0.2 mol NO₂              0.1 mol N₂O₄                 |
  |        ↓                         ↓                       |
  |    [甲容器]    恒温恒容等效平衡    [丙容器]               |
  |    (红填充)  ←----------------→  (蓝填充)               |
  |        ↓         一边倒...           ↓                   |
  |        甲      0.2(1−α)=0.2β       丙                   |
  |               0.1α=0.1(1−β)                              |
  |                  α+β=1                                   |
  |              α=β=0.5时相同,C错                           |
  |                                                          |
  |        [◀上一步]  步骤 3/4  [下一步▶]                    |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：IIFE 内维护 `let currentStep = 0; const totalSteps = 4;`，每步对应一个元素 ID 数组（`stepElements[step]`），切换时遍历设置 `display = 'block'/'none'` 或 `opacity` 动画。
  2. 坐标计算：所有 SVG 元素使用绝对坐标（viewBox="0 0 800 500"），文本统一 `text-anchor="middle"` 便于居中，化学式下标用 `<tspan>` 嵌套。
  3. 动画曲线：步骤切换时，新增元素使用 CSS transition `opacity 0.3s ease-out`，从 opacity 0 到 1，提升课堂演示流畅感。
  4. 事件绑定：按钮绑定 `click` 事件，更新 `currentStep` 后调用 `renderStep()`，由该函数统一控制所有元素的显隐及按钮禁用状态。
  5. 双向箭头：使用 SVG `<defs>` 定义 `marker`（箭头头），路径使用 `stroke-dasharray="4,2"` 实现虚线。
  6. 气体填充：使用独立 `<path>` 层叠在容器路径下方（SVG 绘制顺序），fill-opacity="0.2"，不与容器轮廓重叠。
- ID 命名规范：所有交互元素 ID 必须以 `scene2-` 为前缀。例如：
  - 容器：`scene2-container-jia`、`scene2-container-bing`
  - 气体：`scene2-gas-jia`、`scene2-gas-bing`
  - 分步元素组：`scene2-step1-group`、`scene2-step2-group`、`scene2-step3-group`、`scene2-step4-conclusion`
  - 按钮：`scene2-btn-prev`、`scene2-btn-next`、`scene2-step-label`
- IIFE 隔离：所有 JavaScript 代码包裹在 `(function() { ... })();` 中，避免多场景合并时的全局变量污染。
