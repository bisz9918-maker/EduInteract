[图示主题与整合说明]
- 本图示主题：F₂表型数据统计与遗传方式推断
- 整合的步骤/概念：①原始F₂数据表格展示；②按性别分类汇总与差异高亮（关键发现"小翅♀=0"）；③翅型总计与9:3:4比例计算；④遗传定律与伴性遗传结论
- 教学价值：教师通过分步导航引导学生从原始数据出发，先观察性别差异（小翅仅雄性），再抽象出9:3:4比例（9:3:3:1变式），最终得出自由组合定律+伴X遗传的结论，符合"数据→差异→比例→结论"的认知链条

[分步序列]
- 初始状态（步骤0，显示"1 / 4"）：
  - 显示完整F₂数据表格（表头+6行数据，含小计与翅型比合并单元格）
  - 隐藏所有分析区元素（汇总框、比例式、结论框）
  - 教师讲解：引导学生观察原始数据，注意小翅♀数量为0

- 步骤1（点击"下一步"，显示"2 / 4"）：
  - 保持表格显示
  - 新增：左右性别汇总框（左雌蓝框、右雄红框），虚线连接表格与汇总框
  - 高亮："小翅♀=0"用红色矩形框标注，该数值标红
  - 教师讲解：对比雌雄数据，发现小翅仅出现于雄性，提示伴性遗传

- 步骤2（点击"下一步"，显示"3 / 4"）：
  - 保持表格显示，隐藏步骤1汇总框
  - 新增："翅型总计"标题 + 三色块（长翅804蓝/小翅239红/残翅321绿）
  - 新增：比例计算式三行——原始值"804:239:321"→小数比"≈9.43:2.81:3.76"→整数比"≈9:3:4"
  - 教师讲解：忽略性别汇总为三种翅型，比例接近9:3:4，即9:3:3:1变式，说明两对基因自由组合

- 步骤3（点击"下一步"，显示"4 / 4"）：
  - 保持表格显示，隐藏步骤2比例区
  - 新增：左右结论栏（左栏蓝：遗传定律；右栏灰：判断理由列表）
  - 理由②"小翅仅出现于雄性"及"为伴X遗传"标红
  - 教师讲解：总结定律与遗传方式，完成题目第(1)问推理

- 教师可随时点击"上一步"回退至任意步骤复习

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「上一步」按钮：位置(270, 460)，宽100×高30，点击回退到上一状态，状态0时禁用（透明度50%）
  2. 「下一步」按钮：位置(430, 460)，宽100×高30，点击前进到下一状态，状态3时禁用（透明度50%）
  3. 步骤指示器：位置(400, 452)，显示当前步骤"1 / 4"~"4 / 4"
- 教师操作流程：
  1. 加载后呈现步骤0（原始表格），教师引导学生读表
  2. 点击「下一步」进入步骤1，呈现性别汇总，教师点出"小翅♀=0"
  3. 点击「下一步」进入步骤2，呈现比例计算，教师推导9:3:4
  4. 点击「下一步」进入步骤3，呈现结论，教师总结定律与遗传方式
  5. 可随时「上一步」回退，重复讲解关键推理节点

[技术实现]
- JS库选择：原生SVG（表格、矩形、文本、直线均为SVG基础元素，无需引入外部库，减少依赖）
- 画布尺寸：800 × 500 px（固定画布，SVG viewBox="0 0 800 500"）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |              F₂表型统计 (400,28)                  |  标题区 y=0~40
  |  +------------------------------------------+    |  
  |  | 表现型 | 数量 | 小计 | 翅型比 |           |    |  表格区 y=45~221
  |  | 长翅♀  | 548  | 804  | 9.43   |           |    |
  |  | 长翅♂  | 256  |      |        |           |    |
  |  | 小翅♀  | 0    | 239  | 2.81   |           |    |
  |  | 小翅♂  | 239  |      |        |           |    |
  |  | 残翅♀  | 153  | 321  | 3.76   |           |    |
  |  | 残翅♂  | 168  |      |        |           |    |
  |  +------------------------------------------+    |
  |                                                  |
  |  [动态分析区：步骤1左右汇总 / 步骤2三色块比例 /   |  分析区 y=248~430
  |   步骤3左右结论栏]                               |
  |                                                  |
  |       [上一步]  2 / 4  [下一步]                  |  控件区 y=440~490
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：变量`currentStep`取值为0~3，对应4个状态。每步切换时，先隐藏所有分析区group，再显示当前步对应的group。
  2. 表格合并单元格实现：不画完整网格，而是精确绘制线段——小计列和翅型比列只在合并行底部画横线（y=149, 201），表现型和数量列每行都画横线。
  3. 步骤1红框标注：使用`<rect>`覆盖在"小翅♀"和"0"文本外围，fill="none"，stroke="#c62828"，stroke-width="2"。
  4. 按钮禁用状态：当currentStep===0时，给上一步按钮加`opacity: 0.5`并忽略点击；当currentStep===3时，给下一步按钮同样处理。
  5. 所有分析区元素按步骤包裹在`<g id="scene1-step1-group">`等容器中，通过`style.display = 'none'/'block'`切换。
- ID命名规范：
  - 表格相关：`scene1-table`、`scene1-table-header`、`scene1-row1`等
  - 步骤组：`scene1-step0-group`（仅表格，可省略）、`scene1-step1-group`、`scene1-step2-group`、`scene1-step3-group`
  - 控件：`scene1-btn-prev`、`scene1-btn-next`、`scene1-step-indicator`
  - 所有ID必须以`scene1-`为前缀
- IIFE隔离：所有JavaScript代码包裹在`(function() { ... })()`中，避免全局变量污染，确保多场景合并时互不干扰。
