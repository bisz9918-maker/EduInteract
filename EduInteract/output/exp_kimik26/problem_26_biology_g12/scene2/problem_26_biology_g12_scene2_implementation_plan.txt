[图示主题与整合说明]
- 本图示主题：黑腹果蝇翅型遗传（正交与反交遗传图解）
- 整合的步骤/概念：
  ① 正交 P（残翅♀ × 小翅♂）及配子形成；
  ② 正交 F₁ 基因型与表现型；
  ③ 正交 F₂ 双分支法推导（常染色体 A/a + 性染色体 Xᴮ/Xᵇ）及 9∶3∶4 汇总；
  ④ 反交 P（小翅♀ × 残翅♂）及配子形成；
  ⑤ 反交 F₁ 基因型与表现型（出现性状分离）；
  ⑥ 反交 F₂ 双分支法预测及 3∶3∶2 汇总。
- 教学价值：教师通过分步导航，按世代递进展示基因的自由组合定律与伴性遗传的综合分析。正交与反交对比呈现，帮助学生理解"小翅仅伴X隐性、残翅为常染色体隐性"的遗传机制，并掌握分支法在双因子杂交中的规范书写。

[交互方案]

- 控件说明：
  1. 「上一步」按钮：位于(250,455)，宽70高32。点击后 currentStep 减1，切换至上一世代的SVG组，同时更新步骤指示器文本。当 currentStep===0 时禁用（fill 变灰）。

- 教师操作流程：
  1. 教师打开图示，首先呈现步骤1（正交P世代），讲解亲本基因型如何根据"F₁全为长翅"及"F₂ 9∶3∶4"反推得到残翅♀为aaXᴮXᴮ、小翅♂为AAXᵇY。
  2. 点击「下一步」进入步骤2，展示F₁基因型AaXᴮXᵇ与AaXᴮY，强调"全为长翅"说明长翅为显性。

  4. 继续点击「下一步」进入步骤4~6，完成反交讲解。步骤5是关键对比点（反交F₁即分离），步骤6预测3∶3∶2。
  5. 讲解中可随时点击「上一步」回退，对比正交与反交的F₁差异。

[技术实现]
- JS库选择：原生 SVG + 原生 JavaScript。理由：本场景以静态几何图形、文本标签和分组显隐为主，无需复杂数学计算或3D渲染；原生SVG可精确控制文本上标（<tspan>）和虚线箭头（<marker>），且分步切换仅涉及DOM显隐，性能最优。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |  [步骤标题: 正交 F₂ 分支法推导]        (y=20~60)  |
  |  P/F1/F2  ♀(240,130)    ×    ♂(560,130)          |
  |           表现型            表现型    (y=160~200) |
  |           基因型            基因型    (y=200~240) |
  |  配子箭头/分支法树状图        (y=240~380)         |
  |              [汇总框] (690,240)                   |
  |                                                  |
  |  +--------------------------------------------+  |
  |  |  [◀上一步]   步骤 3/6   [下一步▶]         |  |  y=440~490
  |  +--------------------------------------------+  |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `let currentStep = 0;`（范围0~5）。每一步对应一个SVG `<g id="scene2-step-N">` 组。切换时，先将所有 step 组的 `display` 设为 `none`，再将当前 step 组的 `display` 设为 `block`。配合 CSS `transition: opacity 0.3s` 实现淡入（若需动画，可在切换前设置 opacity 0，然后 requestAnimationFrame 设为1）。
  2. 上标实现：所有含Xᴮ/Xᵇ/Y的基因型文本，使用 `<tspan baseline-shift="super" font-size="11px">B</tspan>` 等方式书写，确保在任何浏览器中基线一致。
  3. 箭头标记：在 `<defs>` 中定义 `<marker id="scene2-arrow" ...>`，用于配子虚线和分支连线，保证箭头方向正确。
  4. 按钮状态：在 `updateUI()` 函数中检查 `currentStep`，若 `===0` 则给「上一步」按钮添加 `disabled` class（fill #bdbdbd，pointer-events none）；若 `===5` 则给「下一步」按钮添加 `disabled` class。
  5. 坐标计算：分支法中的斜线使用 `<line x1 y1 x2 y2>`，坐标严格采用布局坐标表中的数值，避免动态计算带来的累积误差。
  6. 汇总框位置固定于(690,240)，不随步骤改变位置，仅在步骤3和步骤6中改变内部文本内容（通过ID选择器替换 textContent）。
