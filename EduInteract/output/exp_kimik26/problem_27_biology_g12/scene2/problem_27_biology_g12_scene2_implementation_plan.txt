[图示主题与整合说明]
- 本图示主题：两对婚配组合的遗传概率计算图解（Ⅱ5×Ⅱ6 与 Ⅲ2×Ⅲ3）
- 整合的步骤/概念：
  1. Ⅱ5×Ⅱ6 再生正常男孩的概率（甲病常隐 Aa×Aa + 乙病双假设）
  2. Ⅲ2×Ⅲ3 生正常孩子的概率（在Ⅰ3=AA、Ⅱ7=AA 条件下推导基因型后计算）
  3. 乙病两种遗传方式（常隐 / X隐）的对比分析
- 教学价值：教师通过分步导航，引导学生严格遵循"拆分为单病→分别计算→组合相乘"的递进逻辑，看清每一步的条件与公式来源；乙病模式切换按钮支持课堂实时对比两种假设。

[视觉元素清单]
- 信息框（Ⅱ5、Ⅱ6、Ⅲ2、Ⅲ3）：圆角矩形，描边#000，填充#fff，用于固定展示亲代基因型与表型
- 推导框（Ⅰ3、Ⅰ4、Ⅱ7、Ⅱ8、Ⅱ9、Ⅲ3推导）：圆角矩形，描边#000，填充#fff或条件高亮色
- 棋盘格（Punnett square）：2×2方格，外框+内部横竖线，正常子代格子填充#e3f2fd（蓝10%），患病子代格子填充#ffcdd2（红10%）
- 箭头：带箭头端的 path，#000，用于连接亲代与计算区
- 结果高亮框：圆角矩形，填充#e8f5e9，描边#2e7d32，用于突出最终概率
- 按钮：圆角矩形，默认填充#fff，描边#ccc；激活态填充#1565c0（常隐/X隐当前选中）或#e0e0e0（导航按钮hover）
- 文本标签：仅基因型、概率、编号、公式，禁止解释性句子
- 配色沿用：
  - 背景 #ffffff
  - 主线 #000000（边框、连线、棋盘格外框，1px）
  - 蓝高亮 #1565c0（正常路径、正常等位基因、当前激活步骤、正常子代标注）
  - 红高亮 #c62828（患病路径、致病等位基因、排除组合、乙病切换按钮激活态边框）
  - 绿高亮 #2e7d32（最终概率结果、乘法公式等号与结果数字、正确路径终点）
  - 辅助线 #888888（模块分隔虚线、概率相乘跨模块虚线、配子到子代虚线映射）
  - 填充透明度：正常子代高亮背景10%，患病子代淡化背景10%

[分步序列]
- 初始状态（步骤1）：显示上半区Ⅱ5×Ⅱ6亲代信息框（基因型 Aa + 乙病根据模式显示），中央大"×"与箭头，底部乙病模式切换按钮可用，分步导航显示"步骤 1/7"
- 步骤2（点击下一步）：中央切换为甲病 Aa×Aa 的 Punnett square，四个格子分别标注 AA/Aa/Aa/aa，正常三格蓝底高亮，患病一格红底，右侧标注 P(甲病正常)=3/4（蓝）、P(甲病患病)=1/4（红）
- 步骤3（点击下一步）：中央切换为乙病分支。若当前为常隐模式，显示 Bb×Bb 棋盘格，正常3/4蓝底，患病1/4红底；若当前为X隐模式，显示 XᴮY × XᴮXᵇ 的性别分离棋盘格（女正常2/4、男正常1/4、男患病1/4），右侧同样标注乙病正常/患病概率。教师可随时点击底部"常隐"/"X隐"按钮实时切换本步骤显示内容。
- 步骤4（点击下一步）：中央显示组合计算公式，左对齐展示 P(正常男孩) = P(甲病正常) × P(乙病正常) × P(男) = 3/4 × 3/4 × 1/2 = 9/32，最终结果"9/32"用绿色大号字体并外加浅绿高亮框。
- 步骤5（点击下一步）：上半区保持步骤4结果但透明度降至0.25作为背景参考；下半区激活，中央显示Ⅲ2×Ⅲ3的大"×"与箭头，标注双方表型。
- 步骤6（点击下一步）：下半区中央显示Ⅲ3甲病基因型推导树：Ⅰ3(AA) × Ⅰ4(Aa) → Ⅱ7(AA)、Ⅱ8(Aa)、Ⅱ9(aa)；Ⅱ7=AA以蓝色高亮；因Ⅲ3患甲病(aa)，故Ⅱ8必为Aa，Ⅲ3=aa以红色高亮；右侧附文字说明推导逻辑。
- 步骤7（点击下一步）：下半区中央显示Ⅲ2×Ⅲ3的概率计算：甲病 P(正常)=⅔（⅓AA×aa + ⅔Aa×aa）、乙病 P(正常)=1（bb×BB 或 XᵇY×XᴮXᴮ 均全正常），组合得 P(正常孩子)=⅔×1=⅔，最终结果绿色高亮。
- 教师可随时点击"◀ 上一步"回退至任意步骤复习；在步骤1~4期间可自由切换乙病假设模式，已访问过的步骤会自动更新为当前模式的内容。

[技术实现]
- JS库选择：原生 SVG + 原生 JavaScript。原因：本场景以几何图形（矩形、线段、文本）和状态切换为主，无复杂函数绘图或3D需求，原生SVG足够轻量且可控。
- 画布尺寸：800 × 500 px（SVG viewBox="0 0 800 500"）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  [婚配一：Ⅱ5 × Ⅱ6]          (y=0~235)           |
  |  [Ⅱ5框]        [中央展示区：步骤1~4内容]          |
  |  [Ⅱ6框]                              [右侧结果]   |
  |  ------------------------------------------------  |  ← 分隔虚线 y=235
  |  [婚配二：Ⅲ2 × Ⅲ3]          (y=240~435)          |
  |  [条件]  [Ⅲ2框]   [中央展示区：步骤5~7内容]       |
  |          [Ⅲ3框]                                  |
  |  ------------------------------------------------  |  ← 控件区上界 y=442
  |  [常隐] [X隐]      [◀上一步] [步骤1/7] [下一步▶]  |  (y=442~490)
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：
     - `currentStep`：整数 1~7，记录当前步骤。
     - `diseaseMode`：字符串 'AR'（常隐）或 'XR'（X隐），记录乙病假设模式。
     - `visitedSteps`：Set，记录已访问过的步骤，用于在切换乙病模式时仅更新已访问步骤的显示内容（或简单处理为切换模式时若当前步骤是步骤3或4，立即刷新显示）。
  2. 步骤切换逻辑：
     - 每个步骤的中央内容包装在一个独立的 `<g id="scene2-step-N-group">` 中（N=1~7）。
     - 切换步骤时，隐藏所有 step-group，显示当前 step-group（通过 `display: none` / `display: block`）。
     - 步骤5~7显示时，步骤4的中央内容可选择性保留但设置 `opacity: 0.25` 作为背景参考（通过给步骤4 group 单独加 class 控制）。
  3. 乙病模式切换逻辑：
     - 切换时更新：Ⅱ5乙病基因型文本、Ⅱ6乙病基因型文本、步骤1的乙病说明文本、步骤3的棋盘格内容（常隐/X隐两套SVG预置在同一group内，通过display切换）、步骤4公式行2（若需注明乙病来源）。
     - 预置两套文本元素，通过 `display: none/block` 切换，避免运行时频繁创建DOM。
  4. 坐标计算：
     - 所有坐标严格采用布局坐标表中的绝对像素坐标，不依赖动态计算，确保代码agent可直接硬编码。
     - 棋盘格内部格子坐标基于外框左上角 (330, 78) 偏移计算，已在前文给出绝对坐标。
  5. 动画曲线：
     - 步骤切换不使用复杂动画，直接显示/隐藏，保证课堂讲解的即时响应。
     - 乙病模式切换时，若需要平滑过渡，可对受影响的文本元素使用 150ms 的 opacity 过渡（CSS transition）。
  6. 事件绑定：
     - 四个按钮分别绑定 `click` 事件。
     - 上一步/下一步按钮在边界步骤时禁用（`disabled` 属性 + 视觉透明度变化）。
  7. 上标处理：
     - 基因型上标（如 Xᴮ、Xᵇ）使用 Unicode 上标字符（ᴮ、ᵇ、ᴬ、ᵃ）直接写入文本节点，避免使用 `<tspan>` 的 dy 偏移带来的布局不确定性。
- ID命名规范：
  - 所有SVG元素ID必须以 `scene2-` 为前缀。
  - 示例：`scene2-title-upper`、`scene2-box-ii5`、`scene2-text-ii5-b-ar`、`scene2-text-ii5-b-xr`、`scene2-step-2-group`、`scene2-grid-aa-cell`、`scene2-btn-mode-ar`、`scene2-btn-prev`、`scene2-formula-result`。
  - JS中严格使用 `document.getElementById` 获取元素，禁止全局class选择，避免多场景合并时跨场景污染。
- IIFE隔离：
  - 所有JavaScript代码包裹在 `(function() { ... })();` 中，内部状态（currentStep、diseaseMode等）不暴露到全局作用域。
  - 事件处理函数定义在IIFE内部，通过闭包访问状态。
