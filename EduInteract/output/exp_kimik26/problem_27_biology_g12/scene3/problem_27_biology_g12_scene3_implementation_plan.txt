[图示主题与整合说明]
- 本图示主题：Ⅱ4的染色体结构变异（Y片段易位）与红绿色盲伴性遗传概率分析
- 整合的步骤/概念：
  1. 正常男性（44+XY）与正常女性（44+XX）核型对比；
  2. Ⅱ4为XX男性的染色体组成——Y染色体上睾丸发育基因片段易位至常染色体；
  3. 变异类型判定：染色体结构变异（易位），区别于基因突变；
  4. 红绿色盲伴X隐性遗传的系谱标注与配子形成图解；
  5. Ⅱ4基因型推导（X^B X^B 或 X^B X^b）及患病概率计算（概率=0）。
- 教学价值：教师通过分步导航，先从细胞学层面建立"XX男性"的染色体结构表象，再迁移到系谱遗传规律，帮助学生跨越细胞学与遗传学两个知识模块，理解染色体结构变异对伴性遗传分析的影响。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript。理由：本场景以静态几何图形、简单描边动画和分步显隐为主，无需复杂数据绑定或3D，原生SVG性能最优且可控性最高。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图（ASCII）：
  ```
  [800×500 画布]
  +--------------------------------------------------------+
  |  [染色体核型对比]        [系谱与遗传分析]              |
  |  正常男 44+XY            Ⅰ1 ○---□ Ⅰ2                  |
  |   常 常  X  Y[红]              |                       |
  |                                ○ Ⅱ4 (斜线)             |
  |  正常女 44+XX                                          |
  |   常 常  X  X                                          |
  |                                                        |
  |  Ⅱ4 (XX男性)              母亲 Ⅰ1    父亲 Ⅰ2          |
  |   常 常[红] X  X           ○ X^B      ○ X^B [常^Y]    |
  |   ↑<--虚线箭头-->          ○ X^b      ○ Y (半透明)    |
  |  [变异标签]                  \  \      /  /            |
  |                             [合子1] [合子2]  结论      |
  |                             X^B X^B  X^B X^b  概率=0   |
  ```

- 关键实现要点：
  1. 状态机设计：定义 `const steps = 6; let currentStep = 0;`。每步用一个函数 `renderStep(index)` 控制所有元素的显隐与高亮。显隐统一用 `element.style.display = 'none' / 'block'`（或 `opacity` + `transition` 实现淡入）。
  2. 坐标计算：所有SVG元素使用绝对像素坐标（viewBox="0 0 800 500"），确保代码agent可直接复制坐标。
  3. 动画曲线：
     - 易位箭头动画：使用CSS `@keyframes dash` 对 `stroke-dasharray` 和 `stroke-dashoffset` 做描边绘制动画，时长1s，ease-in-out。
     - 标签弹出：使用CSS `transition: opacity 0.3s ease, transform 0.3s ease`，初始 `opacity:0; transform:translateY(-5px)`，显示时恢复。
     - 高亮框：使用 `transition: stroke-width 0.3s ease`。
  4. 事件绑定：按钮绑定 `click` 事件，修改 `currentStep` 后调用 `renderStep`。按钮禁用状态通过添加/移除 `disabled` class控制。
  5. 上标实现：基因型中的上标（如X^B）使用SVG `<tspan>` 的 `baseline-shift="super"` 和 `font-size="10px"` 实现，避免引入MathJax增加复杂度。
  6. 图例符号：XX男性圆圈内的斜线使用 `<line>` 绘制；易位片段使用红色小矩形叠加在常染色体上。
- **ID 命名规范**：所有交互元素ID必须以 `scene3-` 为前缀。例如：
  - 图形：`scene3-chrom-male-x`, `scene3-chrom-ii4-trans`, `scene3-pedigree-i1`, `scene3-pedigree-ii4`

  - JS中严格使用 `document.getElementById('scene3-xxx')` 获取元素，禁止全局class选择器，避免多场景合并时污染。
- IIFE 隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，变量不泄露全局作用域。
