[图示主题与整合说明]
- 本图示主题：精原细胞减数分裂图像解析与基因型推导
- 整合的步骤/概念：
  1. 图2细胞分裂时期的判断（通过观察同源染色体、四分体、姐妹染色单体等关键特征，区分有丝分裂中期、减数第一次分裂中期、减数第二次分裂中期）
  2. 有丝分裂中期、减Ⅰ中期、减Ⅱ中期的三时期特征对比
  3. Ⅱ10个体完整基因型的推导（结合系谱表型与细胞分裂图特征）
- 教学价值：教师可使用此图示引导学生逐步观察细胞分裂图的关键特征，通过排除法确定分裂时期，再结合系谱信息推导个体基因型。分步导航允许教师控制课堂节奏，每步聚焦一个知识点，避免信息过载。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript。原因：本场景以静态几何图形和状态切换为主，无需复杂数据绑定或3D渲染，原生SVG可精确控制每条染色体、每个标签的绘制，原生JS状态机足以管理分步逻辑。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +----------------------------------------------------------+
  |  [标题：图2 细胞分裂时期判断与基因型推导]        [系谱图]  |
  |                                                            |
  |  +----------------+  +----------------------+  +----------+|
  |  | 时期特征对比   |  |                      |  | 四分体   ||
  |  | 有丝分裂中期   |  |    细胞分裂大图      |  | 结构放大 ||
  |  | 减Ⅰ中期       |  |    (圆心400,230)     |  |          ||
  |  | 减Ⅱ中期       |  |                      |  +----------+|
  |  +----------------+  |  [同源染色体/四分体] |  +----------+|
  |                      |  [性染色体 X/Y]      |  | Ⅱ10基因型||
  |                      +----------------------+  | 推导区   ||
  |                       减数第一次分裂中期       |          ||
  |                       (四分体时期)             +----------+|
  |                                                            |
  |              [◀上一步]  步骤 X/6  [下一步▶]                |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `let currentStep = 0;` 记录当前步骤（0~6）。定义 `updateScene(step)` 函数，根据步骤值控制所有元素的显示/隐藏、颜色、文本内容。使用 `data-step` 属性标记各元素的出现步骤范围。
  2. 坐标计算：细胞圆心(400,230)，染色体位置相对于圆心计算，便于后续如需动画移动时统一变换。
  3. 动画曲线：状态切换不使用复杂动画，仅使用CSS transition（opacity 0.3s, fill 0.3s, stroke 0.3s）实现淡入淡出和颜色渐变，保持教学图示的清晰性。
  4. 事件绑定：上一步/下一步按钮绑定click事件，调用 `updateScene(currentStep ± 1)`，并更新按钮禁用状态。
  5. 染色体绘制：每条染色体用 `<g>` 包裹，内含两条 `<line>`（姐妹染色单体）和一个 `<circle>`（着丝点）。同源染色体对再用外层 `<g>` 包裹，便于整体高亮。
  6. 对比表实现：每行用一个 `<g>`，内含 `<rect>` 背景和三个 `<text>` 特征项。勾/叉用 `<text>` 或 `<path>` 绘制，通过切换 `display` 或 `opacity` 控制显示。
  7. 标签指引线：从标签到目标元素的虚线用 `<line>` 绘制，初始隐藏，在对应步骤显示。
- ID 命名规范：所有交互元素ID必须以 `scene4-` 为前缀。例如：
  - 细胞圆：`scene4-cell-membrane`
  - 染色体组：`scene4-chr-pair1`，`scene4-chr-x`，`scene4-chr-y`
  - 对比表行：`scene4-row-mitosis`，`scene4-row-meiosis1`，`scene4-row-meiosis2`
  - 按钮：`scene4-btn-prev`，`scene4-btn-next`
  - 基因型区：`scene4-genotype-panel`
  - JS中严格使用 `document.getElementById('scene4-xxx')` 获取元素，禁止全局class选择。
- IIFE 隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免与其他场景的脚本冲突。
