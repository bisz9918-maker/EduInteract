[图示主题与整合说明]
- 本图示主题：六组交配实验数据与无毛基因遗传方式推断
- 整合的步骤/概念：
  1) 第(1)问：利用第1组"无毛×无毛→有毛"判断无中生有，确定无毛为显性基因；
  2) 第(3)问：根据6组数据表格，通过第4组与第6组正反交结果不同推断基因位于性染色体，再结合第2组与第4组子代雌雄分布确认伴X染色体显性遗传；
  3) 第(4)问关联：甲状腺激素功能（促进生长发育、提高新陈代谢）与无毛基因使受体功能下降的联系。
- 教学价值：教师通过分步导航控制推理节奏，每步聚焦一组关键数据，避免6组数据同时呈现造成信息过载。学生可跟随教师点击逐步建立"显隐性→伴性遗传→伴X显性"的完整证据链。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无外部库）。原因：本场景以表格、文字标签和简单线段为主，SVG 原生元素即可满足，无需引入 D3 等重型库，保持代码轻量。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图（ASCII）：
  ```
  +----------------------------------------------------------+
  |                                                          |
  |  +------------------------+  +-------------------------+  |
  |  |                        |  |                         |  |
  |  |      数据表格           |  |      结论推断区          |  |
  |  |   (25,65)-(450,375)    |  |   (470,65)-(780,430)    |  |
  |  |  6组交配数据+柱状图     |  |  步骤1~4动态文字/简图    |  |
  |  |                        |  |                         |  |
  |  +------------------------+  +-------------------------+  |
  |                                                          |
  |       [◀ 上一步]        [下一步 ▶]                        |
  |            ●  ●  ●  ●  ●   (步骤指示器)                    |
  |                      控件区 y=440~490                     |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `currentStep`（0~4），每次点击按钮时更新状态，调用 `renderStep()` 统一渲染。
  2. 表格列高亮：为每列预定义一个背景 rect（id: scene1-col-highlight-1~6），默认 `display:none`。`renderStep()` 中根据当前步骤设置对应列显示，并设置其他列 text 的 opacity。
  3. 右侧结论区：为每步骤预定义一组 SVG group（id: scene1-conclusion-step0~4），默认隐藏，仅显示当前步骤对应的 group。
  4. 柱状图高度计算：在初始化时根据6组数据预计算每根柱子有毛/无毛分段高度（总高30px按数量比例分配），避免运行时重复计算。
  5. 动画曲线：步骤切换时，高亮列背景使用 200ms ease-in-out 淡入（opacity 0→0.15）；非聚焦列文字使用 200ms ease-in-out 淡化（opacity 1→0.35）。使用 CSS transition 实现。
  6. 事件绑定：按钮点击绑定 `scene1-btn-prev` 和 `scene1-btn-next` 的 onclick，内部做边界检查（currentStep<=0 或 >=4 时禁用对应按钮）。
  7. 按钮禁用样式：禁用状态添加 `disabled` class，背景色 #e0e0e0，文字色 #9e9e9e，cursor:not-allowed。
- ID 命名规范：
  - 表格元素：`scene1-table-*`
  - 列高亮：`scene1-col-highlight-{n}`（n=1~6）
  - 结论区组：`scene1-conclusion-step{n}`（n=0~4）
  - 按钮：`scene1-btn-prev`, `scene1-btn-next`
  - 指示器圆点：`scene1-dot-{n}`（n=0~4）
  - 所有交互元素均使用 `getElementById` 获取，禁止 querySelectorAll 配合全局 class。
- IIFE 隔离：所有 JavaScript 代码包裹在 `(function() { ... })();` 中，避免多场景合并时变量污染。
