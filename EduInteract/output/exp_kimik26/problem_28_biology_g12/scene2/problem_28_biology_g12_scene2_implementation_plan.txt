[图示主题与整合说明]
- 本图示主题：伴X显性遗传的染色体传递与正反交差异分析（第2问）
- 整合的步骤/概念：
  1) 无毛基因（A）位于X染色体上，有毛基因（a）为隐性；
  2) 题干情形：杂合无毛雌（X^A X^a）× 无毛雄（X^A Y）→ 子代无毛个体既有雌性也有雄性；
  3) 第2问情形：有毛雌（X^a X^a）× 无毛雄（X^A Y）→ 子代雌性全无毛、雄性全有毛；
  4) 对比总结：两种情形结果差异的关键在于母本基因型不同，因此与题干“无毛既有雌性也有雄性”并不矛盾。
- 教学价值：教师通过分步导航，先展示基因在性染色体上的位置，再分别演示两种亲本组合的配子形成、Punnett方格受精结果，最后左右对比突出“母本基因型决定子代性别分布”这一核心逻辑，帮助学生理解伴X显性遗传中杂合雌性与纯合隐性雌性产生截然不同的子代表现型比例。

[视觉元素清单]
- 染色体：用圆角矩形（rx=5~6）模拟X/Y染色体轮廓，X为蓝色(#1565c0)，Y为红色(#c62828)且长度约为X的80%。
- 基因标记：在染色体中段外侧画小圆（r=6~8），内写单字母"A"/"a"，A用蓝底白字或蓝边，a用红底白字或红边。
- 配子：圆形（r=20），描边颜色对应基因类型（A蓝色、a/Y红色），内部居中写基因型文字。
- 箭头：从亲本染色体组指向配子圆的虚线路径（stroke-dasharray="4,3"），颜色#888888。
- Punnett方格：2×2方格，外框线宽2，内部线宽1。无毛个体格填充淡蓝(#1565c0, opacity=0.15)，有毛个体格填充淡红(#c62828, opacity=0.15)。
- 标签文字：
  - 基因型标签（如X^A X^a）：字号14px，黑色，位于亲本/格子中心。
  - 表现型标签（如无毛♀）：字号13px，黑色，位于基因型下方偏移约18px。
  - 步骤结论：字号14px，黑色，位于Punnett方格下方约25px。
  - 步骤3结论"不矛盾"：字号28px，绿色(#2e7d32)，font-weight:bold。
- 配色沿用规则：
  - 背景 #ffffff
  - 主线/文字 #000000
  - 蓝高亮 #1565c0：雌性X染色体、显性基因A、配子X^A、无毛格填充
  - 红高亮 #c62828：雄性Y染色体、隐性基因a、配子X^a与Y、有毛格填充
  - 绿高亮 #2e7d32：结论"不矛盾"
  - 辅助线 #888888 虚线：配子箭头

[分步序列]
- 初始状态（步骤0）：显示题目基础条件
  - 显示雌雄染色体示意图（左雌XX，右雄XY）。
  - X染色体为蓝色，Y染色体为红色且较短。
  - X染色体中段标注基因位点（雌左A/雌右a示意杂合，雄X上A）。
  - 下方文字说明："无毛基因(A)位于X染色体上"、"有毛基因(a)为隐性"。
  - 底部控件栏可用，点击"下一步"进入步骤1。

- 步骤1：点击「下一步」→ 题干情形（杂合无毛雌 × 无毛雄）
  - 隐藏步骤0内容，显示步骤1组。
  - 上部：左侧母本（X^A X^a，无毛♀），右侧父本（X^A Y，无毛♂），中央"×"。
  - 中部：虚线箭头从亲本指向各自配子。母本产生X^A（左）和X^a（右）两种配子；父本产生X^A（左）和Y（右）两种配子。
  - 下部：2×2 Punnett方格，列标题为父本配子（X^A、Y），行标题为母本配子（X^A、X^a）。
    - 左上：X^A X^A，无毛♀（淡蓝）
    - 右上：X^A Y，无毛♂（淡蓝）
    - 左下：X^A X^a，无毛♀（淡蓝）
    - 右下：X^a Y，有毛♂（淡红）
  - 底部结论文字："子代中无毛个体既有雌性也有雄性"。

- 步骤2：点击「下一步」→ 第2问情形（有毛雌 × 无毛雄）
  - 隐藏步骤1内容，显示步骤2组。
  - 上部：左侧母本改为（X^a X^a，有毛♀），右侧父本不变（X^A Y，无毛♂）。
  - 中部：母本只产生X^a一种配子（居中）；父本仍产生X^A和Y两种配子。
  - 下部：Punnett方格行标题两行均为X^a。
    - 左上/左下：X^A X^a，无毛♀（淡蓝）
    - 右上/右下：X^a Y，有毛♂（淡红）
  - 底部结论文字："子代雌性全为无毛，雄性全为有毛"。

- 步骤3：点击「下一步」→ 对比总结
  - 隐藏步骤2内容，显示步骤3组。
  - 左右分栏：

[交互方案]

- 控件说明：
  1. 「上一步」按钮：位于控件栏左侧 (260,452)，90×32。点击后回退到上一状态，步骤0时禁用（opacity=0.4，pointer-events=none）。

- 教师操作流程：

  2. 点击「下一步」进入步骤1，讲解题干中"无毛既有雌性也有雄性"对应的亲本组合（杂合雌×无毛雄），配合Punnett方格说明子代同时出现无毛雌、无毛雄、有毛雄。

[技术实现]
- JS库选择：原生 SVG + 原生 JavaScript。理由：本场景以静态几何图形（染色体、方格、圆形、文字）为主，无复杂函数曲线或3D模型，SVG的矢量特性可确保文字和边框在任何缩放比例下清晰，且无需引入外部库，减少加载依赖。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图：
  ```
  +--------------------------------------------------+
  |  [步骤标题区] y=10~45                             |
  |        "步骤X：XXXXXXXX" 居中                      |
  +--------------------------------------------------+
  |  [主图区] y=50~430                                |
  |                                                   |
  |   步骤0: 左[XX蓝]      右[XY蓝红]                 |
  |                                                   |
  |   步骤1/2: 左亲本        ×       右亲本           |
  |              ↓                   ↓                |
  |            配子圆              配子圆             |
  |              +------------------+                 |
  |              |   Punnett方格    |                 |
  |              +------------------+                 |
  |            "结论文字"                             |
  |                                                   |
  |   步骤3: [左栏Punnett] VS [右栏Punnett]           |
  |                 "不矛盾"                          |
  +--------------------------------------------------+
  |  [控件栏] y=440~490 绝对定位叠在SVG上             |
  |    [◀上一步]    步骤 X / 4    [下一步▶]           |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：定义变量 `let currentStep = 0;`，共4个状态（0~3）。每个状态对应一个SVG `<g>` 组（id="scene2-step0-group" 至 "scene2-step3-group"）。切换状态时，将当前组的 `display` 设为 `"block"`，其余设为 `"none"`。
  2. 坐标计算：所有坐标采用绝对像素值，以(0,0)为左上角。Punnett方格采用固定原点(320,255)，格子宽80、高60，便于批量生成或手动定位。
  3. 动画曲线：本场景以分步切换为主，无需复杂动画。状态切换时可直接显示（瞬时切换），若需柔和过渡，可对 `<g>` 添加 CSS `transition: opacity 0.2s ease;` 并配合 opacity 变化（但需确保交互响应迅速，教育场景不推荐过长动画）。
  4. 事件绑定：在 IIFE 内部，通过 `document.getElementById('scene2-btn-prev').addEventListener('click', ...)` 和 `document.getElementById('scene2-btn-next').addEventListener('click', ...)` 绑定按钮事件。每次点击更新 `currentStep`，调用 `renderStep()` 函数更新各组 display 属性及按钮禁用状态。
  5. 上标处理：基因型文字如 X^A X^a 在 SVG 中可用 `<text>` 嵌套 `<tspan>` 实现上标效果，例如：
     ```xml
     <text x="200" y="155" font-size="14">
       X<tspan dy="-5" font-size="10">A</tspan>
       X<tspan dy="-5" font-size="10">a</tspan>
     </text>
     ```
     若代码实现中上标排版复杂，允许使用 "X^A X^a" 字符串作为 fallback，但优先推荐 tspan 上标以符合生物学书写规范。
  6. 填充层顺序：Punnett方格的背景填充矩形（淡蓝/淡红）必须位于方格边框 `<rect>` 和内部文字 `<text>` 的底层，即先写填充 `<rect>`，再写边框 `<line>` 和 `<rect>`，最后写 `<text>`，避免文字被半透明色块覆盖导致可读性下降。
  7. 按钮禁用逻辑：`renderStep()` 中判断：若 `currentStep === 0`，给上一步按钮添加 `disabled` 类（降低透明度并移除事件响应）；若 `currentStep === 3`，给下一步按钮添加 `disabled` 类。
- ID命名规范：所有交互元素及SVG子元素ID必须以 `scene2-` 为前缀。示例：
  - 步骤组：`scene2-step0-group`, `scene2-step1-group`, `scene2-step2-group`, `scene2-step3-group`
  - 按钮：`scene2-btn-prev`, `scene2-btn-next`
  - 指示器：`scene2-step-indicator`
  - 染色体：`scene2-chrom-female-left`, `scene2-chrom-male-y`
  - Punnett方格：`scene2-punnett-s1-frame`, `scene2-punnett-s1-cell1-genotype`
  - 结论文字：`scene2-conclusion-s1`, `scene2-conclusion-final`
  JS中严格使用 `getElementById` 获取元素，禁止全局 class 选择，避免多场景合并时跨场景污染。
- IIFE隔离：所有 JavaScript 代码包裹在 `(function() { ... })();` 中，内部变量与函数不泄露到全局作用域。
