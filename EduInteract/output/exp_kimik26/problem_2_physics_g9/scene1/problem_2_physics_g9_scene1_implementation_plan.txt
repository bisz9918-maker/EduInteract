[图示主题与整合说明]
- 本图示主题：斜面小车下滑过程的能量转化与机械能变化
- 整合的步骤/概念：实验装置展示 → 顶端势能/动能/机械能初始状态 → 下滑中点能量转化 → 底端能量转化结论（判析A选项） → 摩擦生热与机械能损失（判析B选项）
- 教学价值：教师通过分步控制，从"位置→速度→能量条变化"逐步建立学生的直观认知；能量条将抽象的机械能变化可视化，便于讲解能量转化方向和摩擦导致的机械能损失

[分步序列]
- 步骤0（初始状态）：显示完整实验装置。元素：斜面、水平木板、小车（斜面顶端，中心150,112）、木块、标签"小车"/"木块"/"木板"/"斜面"。无能量标注，建立实验情境。
- 步骤1（顶端能量状态）：点击"下一步"。新增：高度h虚线标注（两端加横线）及"h"标签；右侧能量条组出现——E_p条高100%（满格，红）、E_k条高0%（零格，蓝）、E_机条高100%（满格，绿）；新增标签"E_p"/"E_k"/"E_机"。小车保持在顶端。
- 步骤2（下滑中点）：点击"下一步"。小车从(150,112)动画移动至(225,200)（斜面中点，耗时600ms，ease-in-out）；新增速度箭头沿斜面向下及"v"标签；能量条动画变化：E_p条降至50%，E_k条升至40%，E_机条降至95%。
- 步骤3（底端与A选项判析）：点击"下一步"。小车从(225,200)动画移动至(300,287)（斜面底端/木板上，耗时600ms）；速度箭头变为水平向右，"v"标签移至(362,283)；能量条动画：E_p条降至0%，E_k条升至80%，E_机条降至90%；新增红色转化箭头从E_p上方指向E_k上方；画面顶部(400,55)显示结论文字"A 错误：重力势能转化为动能"（绿色）。
- 步骤4（摩擦与B选项判析）：点击"下一步"。小车保持底端位置；新增橙色摩擦力箭头沿斜面向上（标注"f"）；新增橙色波浪线表示内能Q（标注"Q"）；能量条保持步骤3状态（E_p=0%, E_k=80%, E_机=90%），但可在E_机条旁用虚线框标出"损失10%"；画面顶部结论文字替换为"B 错误：机械能因摩擦而减小"（绿色）。
- 教师可随时点击"上一步"回退至任意步骤复习。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「上一步」按钮：位于底部控件区左侧，中心(320,465)，宽70×高28。点击后当前步骤减1，回退到前一步状态，所有元素/标签/动画反向恢复。
  2. 「下一步」按钮：位于底部控件区右侧，中心(480,465)，宽70×高28。点击后当前步骤加1，触发该步骤的元素出现/移动/变化动画。
  3. 步骤指示器：位于两按钮之间，中心(400,465)，显示"步骤 X/4"，随按钮点击同步更新。
- 教师操作流程：
  1. 教师展示步骤0，说明实验装置；
  2. 点击「下一步」进入步骤1，讲解小车在顶端具有重力势能；
  3. 点击「下一步」进入步骤2，观察小车下滑、速度出现、能量条变化；
  4. 点击「下一步」进入步骤3，强调势能归零、动能最大，得出A选项错误结论；
  5. 点击「下一步」进入步骤4，补充摩擦力与内能，得出B选项错误结论；
  6. 可随时点击「上一步」回退重讲关键步骤。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：本场景以简单几何图形（线段、矩形、圆形、箭头）为主，无需复杂图表库；SVG的SMIL或JS控制属性即可实现小车位移动画和能量条高度动画。
- 画布尺寸：800×500 px（固定）
- 布局草图：
  ```
  [800×500 SVG画布]
  +--------------------------------------------------+
  |  结论文字区 (y=40~70)                              |
  |                                                  |
  |  斜面区(左)        能量条区(中右)     木板区(右)    |
  |  +--------+        +-----------+      +----------+ |
  |  | 斜面    |        | E_p E_k E_机 |      | 木块     | |
  |  |   小车  |        |  能量条     |      |        | |
  |  |        |        |            |      | 木板    | |
  |  +--------+        +-----------+      +----------+ |
  |                                                  |
  |  [上一步]  步骤 X/4  [下一步]  (y=440~490 控件区)  |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 `currentStep`（0~4）记录当前步骤。`goToStep(n)`函数统一处理状态切换，先隐藏所有步骤专属元素，再显示目标步骤的元素并触发动画。
  2. 小车位置动画：使用SVG的`<animateTransform>`或JS的`requestAnimationFrame`修改`<g>`的`transform="translate(x,y)"`。三目标位置：步骤1(150,112)、步骤2(225,200)、步骤3/4(300,287)。
  3. 能量条高度动画：通过JS在300ms内线性插值改变`<rect>`的`height`和`y`属性（底边固定y=240，height从当前值过渡到目标值）。各步骤目标值：步骤1(E_p=100,E_k=0,E_机=100)、步骤2(E_p=50,E_k=40,E_机=95)、步骤3/4(E_p=0,E_k=80,E_机=90)。
  4. 速度箭头切换：步骤2显示斜向箭头(225,200)-(244,221)，步骤3/4显示水平箭头(320,287)-(358,287)。通过切换两个`<line>`/`<path>`元素的`display`属性实现。
  5. 结论文字：使用一个`<text>`元素，步骤3和步骤4分别设置不同内容并显示，其他步骤隐藏。
  6. 事件绑定：按钮绑定`click`事件调用`prevStep()`和`nextStep()`，并做边界检查（步骤0时禁用上一步，步骤4时禁用下一步）。
- ID命名规范：所有SVG元素和JS变量必须以`scene1-`为前缀。例如：
  - 小车组：`scene1-car-group`
  - 斜面线：`scene1-slope-line`
  - E_p条：`scene1-ep-bar`
  - 上一步按钮：`scene1-btn-prev`
  - 下一步按钮：`scene1-btn-next`
  - 步骤指示器：`scene1-step-indicator`
  - 结论文字：`scene1-conclusion-text`
  JS中获取元素严格使用`document.getElementById`，禁止用`querySelectorAll`配合全局class。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免多场景合并时的全局变量污染。
