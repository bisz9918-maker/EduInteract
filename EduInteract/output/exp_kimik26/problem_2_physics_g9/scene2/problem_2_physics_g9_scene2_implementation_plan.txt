[图示主题与整合说明]
- 本图示主题：木块受力分析与平衡力、相互作用力的辨析（覆盖 C 选项）
- 整合的步骤/概念：木块静止受力图 → 重力与支持力的二力平衡 → 木块对木板的压力及施力物体 → 压力与支持力作用在不同物体上 → 平衡力与相互作用力四条件对比
- 教学价值：教师通过分步导航，逐步在木块-木板装置上添加力矢量，最后以对比表格强化"同体/异体"这一关键差异，帮助学生辨析易混淆概念

[分步序列]
- 步骤0（初始状态）：显示木块、木板、木块标签、木板标签。装置静止，无受力箭头。
- 步骤1（点击下一步）：新增重力G箭头（红色，重心向下）和支持力N箭头（蓝色，底面向上），显示G标签、N标签，右侧显示说明"二力平衡"。讲解：木块静止是因为重力与支持力大小相等、方向相反、作用在同一物体上。
- 步骤2（点击下一步）：新增压力F_压箭头（红色，从接触面向下指向木板），显示F_压标签，右侧显示说明"施力物体：木块"。讲解：木块对木板有向下的压力，受力物体是木板。
- 步骤3（点击下一步）：新增木块受力虚线框（圈住木块）和木板受力虚线框（圈住接触区域），显示绿色说明"作用在不同物体上"。讲解：N作用在木块上，F_压作用在木板上，二者作用在不同物体上，因此不是平衡力，C选项错误。
- 步骤4（点击下一步）：右侧弹出对比表格，列出平衡力与相互作用力的四条件对比，最后一行"同一物体/不同物体"用绿色高亮背景及文字。讲解：平衡力与相互作用力仅"同体/异体"一字之差。
- 教师可随时点击「上一步」回退复习，所有已显示元素保持可见（累积式显示）。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「上一步」按钮：位置(280,455)，宽100×高35，点击回退到上一步骤，步骤0时禁用
  2. 「下一步」按钮：位置(480,455)，宽100×高35，点击前进到下一步，步骤4时禁用
  3. 步骤指示器：位置(400,475)，显示当前步骤如"步骤 2/5"
- 教师操作流程：教师点击「下一步」逐步展示受力分析与概念辨析，配合讲解；可随时「上一步」回退强调关键概念；对比表格在步骤4弹出后，教师可指向绿色高亮的"同一物体/不同物体"行，强化记忆点。

[技术实现]
- JS库选择：原生 SVG（简单几何、箭头、矩形、表格线条，SVG最为直接，无需引入外部库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +----------------------------------------------------------+
  |                                                          |
  |        木块                                              |
  |    +------+                          +----------------+  |
  |    |      | ← 虚线框(步骤3)          |  对比表格      |  |
  |    |  ●   |  G↓ N↑                   |  (步骤4显示)   |  |
  |    |      |                          |                |  |
  |    +------+                          +----------------+  |
  |    ↑  F_压↓(步骤2)                                       |
  |    +------------------------+                            |
  |    |        木板            | ← 木板                    |
  |    +------------------------+                            |
  |                                                          |
  |       [◀ 上一步]  步骤 X/5  [下一步 ▶]                  |
  +----------------------------------------------------------+
  [控件栏 y=440~490]
  ```
- 关键实现要点：
  1. 状态机设计：用变量 `currentStep`（0~4），初始化显示步骤0元素，其余设 `display:none` 或 `visibility:hidden`。
  2. 箭头实现：在 `<defs>` 中定义两个 `<marker>`（id="scene2-arrow-red"、id="scene2-arrow-blue"），分别填充红/蓝色，供力矢量线引用。
  3. 步骤切换函数 `setStep(n)`：根据步骤索引，批量控制各元素显隐。使用 `getElementById` 获取元素，避免跨场景污染。
  4. 动画曲线：步骤切换不使用复杂动画，直接显隐（或辅以 200ms opacity 过渡），保证课堂讲解节奏可控。
  5. 事件绑定：上一步/下一步按钮绑定 `click` 事件，调用 `setStep(currentStep - 1)` / `setStep(currentStep + 1)`，并更新按钮禁用状态。
  6. 对比表格绘制：用 `<rect>` 做外框和单元格背景，`<line>` 画分隔线，`<text>` 填内容。最后一行背景 `<rect>` 单独设 fill="#e8f5e9" fill-opacity="0.4"，文字 fill="#2e7d32"。
  7. 虚线框：`<rect>` 设 stroke="#888888" stroke-dasharray="5,5" fill="none"。
- ID命名规范：所有交互元素 ID 必须以 `scene2-` 为前缀，例如：
  - `scene2-block`（木块矩形）
  - `scene2-board`（木板矩形）
  - `scene2-arrow-g`（重力箭头）
  - `scene2-arrow-n`（支持力箭头）
  - `scene2-arrow-f`（压力箭头）
  - `scene2-label-g`、`scene2-label-n`、`scene2-label-f`
  - `scene2-frame-block`、`scene2-frame-board`（受力框）
  - `scene2-table`（对比表格组）
  - `scene2-btn-prev`、`scene2-btn-next`（按钮）
- IIFE隔离：所有 JavaScript 代码包在 `(function() { ... })()` 中，避免全局变量污染。
