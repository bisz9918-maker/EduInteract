[图示主题与整合说明]
- 本图示主题：五种物质（铁、氧化铁、稀盐酸、氢氧化钙溶液、碳酸钠溶液）反应网络与题目关系图推断
- 整合的步骤/概念：
  1) 统计五种物质两两反应数，发现稀盐酸反应数=4；
  2) 对照题目关系图，Y的连线数=4，锁定Y为稀盐酸；
  3) N能转化为铁，在五种物质中只有氧化铁可被还原为铁，且氧化铁反应数=1，与N的连线情况匹配，锁定N为氧化铁；
  4) 剩余氢氧化钙、碳酸钠、铁三者中，铁不与氢氧化钙/碳酸钠反应，而X-M-Y构成两两相连的三角形，故铁不可能是X或M，X和M只能是氢氧化钙与碳酸钠（可互换）；
  5) 完整映射：Y→稀盐酸，N→氧化铁，X/M→氢氧化钙/碳酸钠。
- 教学价值：教师通过分步导航控制课堂节奏，每步聚焦一个推断逻辑，可随时回退复习。左侧完整网络提供全局反应数证据，右侧题目关系图提供待推断结构，左右对照直观呈现“统计—匹配—排除—确定”的化学推断思维过程。

  ```
  |                                                  |
  |         [◀ 上一步]  [下一步 ▶]                   |
  |                    步骤 1 / 5                     |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `currentStep`（范围 0~4），每次点击按钮时更新状态并调用 `renderStep()` 函数。`renderStep()` 内使用 `switch(currentStep)` 或查表法，设置各元素的 className 和 textContent。
  2. 高亮实现：为 SVG 元素预定义 CSS class（如 `.hl-blue-node`、`.hl-blue-line`、`.hl-green-node`、`.hl-red-node` 等），通过 JS 切换 class 实现高亮，配合 CSS `transition: all 0.3s ease` 实现平滑过渡。
  3. 提示文字管理：每个步骤的提示文字使用独立的 SVG `<text>` 或 `<g>` 元素，默认 `display: none`，在对应步骤中设为 `display: block`。
  4. 节点文字替换：步骤4时，通过 JS 修改右侧节点内的 `<text>` 的 `textContent`，将字母替换为物质名。X和M节点文字较长（"氢氧化钙/碳酸钠"），需确保节点宽度100px内能容纳，建议字体缩小至12px或允许文字溢出显示（SVG text 不受矩形边界限制，视觉上可接受）。
  5. 箭头实现：N→铁连线在 SVG `<defs>` 中定义 `<marker id="scene1-arrow">`，设置 `markerWidth="10" markerHeight="7" refX="9" refY="3.5" orient="auto"`，内部画三角形箭头，填充 #000000（高亮时通过CSS无法直接改变marker颜色，需在JS中切换marker的id或预先定义黑色/蓝色/绿色/红色四种marker）。
  6. 按钮禁用逻辑：步骤0时上一步按钮添加 `disabled` class；步骤4时下一步按钮添加 `disabled` class。
  7. 坐标计算：所有连线端点使用节点边缘中点坐标（已在布局坐标表中给出），避免线条穿过矩形内部。
- ID 命名规范：
  - 所有 SVG 元素 ID 必须以 `scene1-` 为前缀；
  - 节点示例：`scene1-node-fe`、`scene1-node-hcl`、`scene1-node-x`、`scene1-node-y`；
  - 连线示例：`scene1-line-fe-hcl`、`scene1-line-x-y`、`scene1-line-n-fe`；
  - 提示示例：`scene1-hint-step1`、`scene1-hint-step2`；
  - 按钮示例：`scene1-btn-prev`、`scene1-btn-next`；
  - JS 中严格使用 `document.getElementById()` 获取元素，禁止用 `querySelectorAll` 配合全局 class，避免多场景合并时跨场景污染。
- IIFE 隔离：所有 JavaScript 代码包裹在 `(function() { ... })();` 中，内部变量不污染全局作用域。
