[图示主题与整合说明]
- 本图示主题：氨气与氯化氢的扩散反应及白烟位置判断
- 整合的步骤/概念：
  1. 实验装置结构认知（A瓶HCl、B瓶NH₃、活塞a/b/c、胶头滴管、烧杯）
  2. 观察白烟所需的操作步骤（打开a、c，关闭b）
  3. 两种气体分子的扩散运动动画（NH₃速率 > HCl速率）
  4. 白烟生成位置（靠近A端）
  5. 分子运动速率与分子质量的反比关系
- 教学价值：教师通过分步导航，按"装置→操作→运动→反应→结论"的认知递进展开讲解，可随时回退重讲关键步骤。学生可直观看到NH₃分子运动更快、白烟靠近A端，从而理解"分子质量越小，运动速率越快"的微观本质。

[分步序列]
- 初始状态（步骤0）「装置认知」：
  - 显示完整实验装置：A瓶、B瓶、导管、活塞a/b/c、烧杯、胶头滴管
  - 所有部件标注名称：A、B、HCl（蓝）、NH₃（红）、a、b、c、水、装有水的胶头滴管
  - 活塞均为默认黑色描边、白色填充
  - 步骤标题：「装置认知」

- 步骤1「操作示意」：
  - 点击「下一步」进入
  - 活塞a、c变为绿色描边（#2e7d32，2px），旁标注绿色"打开"（a旁580,225；c旁200,225）
  - 活塞b变为灰色填充（#bdbdbd），旁标注灰色"关闭"（420,305）
  - 步骤标题变为：「操作示意：打开活塞a、c，关闭活塞b」
  - 其他装置元素保持不变

- 步骤2「分子运动」：
  - 点击「下一步」进入
  - 保留步骤1的活塞状态提示
  - 从A瓶底部(220,210)释放HCl分子（蓝色圆点），沿导管向右运动，速度1px/帧
  - 从B瓶底部(580,210)释放NH₃分子（红色圆点），沿导管向左运动，速度2px/帧
  - 分子运动轨迹显示灰色虚线（#888888）
  - 各释放5个分子，间隔30帧，形成连续流动效果
  - 分子到达相遇点(340,210)后淡出消失
  - 步骤标题变为：「分子运动：NH₃与HCl相向扩散」
  - 运动结束后在装置下方显示提示"分子在不断运动"（如需要，可省略避免与控件冲突）

- 步骤3「白烟生成」：
  - 点击「下一步」进入
  - 分子动画结束，隐藏所有分子点
  - 在(340,210)处显示白烟区域（白色半透明椭圆，rx=35，ry=25）
  - 白烟上方标注"NH₄Cl白烟"(340,170)
  - 白烟下方标注"靠近A端"(340,250)
  - 步骤标题变为：「白烟生成：NH₄Cl白烟靠近A端」

- 步骤4「原理总结」：
  - 点击「下一步」进入
  - 保留白烟及位置标注
  - 右侧显示质量信息框(680,180)-(780,320)
  - 框内自上而下标注：
    - "M(NH₃)=17"(700,220)
    - "M(HCl)=36.5"(700,250)
    - "分子质量越小"(700,285)
    - "运动速率越快"(700,310)
  - 从信息框左侧(680,250)到白烟区域(375,210)绘制箭头，指示因果关系
  - 步骤标题变为：「原理总结：分子运动速率与质量成反比」

- 教师可随时点击「上一步」回退到任意步骤复习。

  6. 可随时点击「上一步」回退到分子运动或白烟步骤，强化学生记忆

[技术实现]
- JS库选择：原生SVG + 原生JavaScript（无需额外库）。理由：本场景以简单几何图形（圆、线、矩形、椭圆）为主，分子运动动画可通过requestAnimationFrame直接操作SVG属性实现，引入D3等库反而增加复杂度。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------------+
  |  步骤标题（顶部居中）                                    |
  |                                                        |
  |    A瓶          导管连接           B瓶      胶头滴管    |
  |   (HCl)        (活塞c,a,b)       (NH₃)    +标签       |
  |     \              |               /                   |
  |      \             |              /                    |
  |       +------------+-------------+                     |
  |                    |                                   |
  |                   烧杯(水)                              |
  |                                                        |
  |              [白烟区域(步骤3)]                          |
  |                                                        |
  |    [质量信息框(步骤4)]                                  |
  |                                                        |
  |  [◀上一步]    步骤 X/5    [下一步▶]                    |
  +--------------------------------------------------------+
  [控件栏 y=440~490]
  ```
- 关键实现要点：
  1. 状态机设计：使用变量`currentStep`（0~4），每次点击按钮时更新状态，调用`renderStep()`函数根据状态显示/隐藏元素。
  2. 元素显隐控制：为每个步骤相关的SVG元素或HTML元素设置`display`属性（或CSS class `.hidden`），在`renderStep()`中统一切换。
  3. 分子运动动画：使用requestAnimationFrame循环，维护分子对象数组`{id, x, y, vx, vy, element}`。HCl分子vx=+1px/帧，NH₃分子vx=-2px/帧。分子到达相遇点x=340后设置opacity渐隐并从DOM移除。
  4. 分子释放策略：在步骤2进入时启动动画，每30帧从两端各释放1个分子，共释放5组（各5个分子），确保运动连续感。
  5. 相遇点计算：A端(220,210)到相遇点(340,210)距离120px，B端(580,210)到相遇点距离240px，速度比2:1，符合"靠近A端"的定性结论（简化自实际质量比36.5:17≈2.15:1）。
  6. 白烟脉动效果：步骤3显示白烟后，使用requestAnimationFrame对白烟椭圆施加scale正弦波动（1.0~1.1），周期2秒，增强视觉表现。
  7. 按钮禁用逻辑：步骤0时禁用「上一步」，步骤4时禁用「下一步」，通过添加/移除`disabled`属性和CSS样式实现。
  8. 事件绑定：按钮点击事件在IIFE内绑定，避免全局污染。
- ID命名规范：所有交互元素ID必须以`scene1-`为前缀。例如：
  - SVG元素：`scene1-flask-a`、`scene1-flask-b`、`scene1-piston-a`、`scene1-piston-b`、`scene1-piston-c`、`scene1-molecule-hcl-1`、`scene1-molecule-nh3-1`、`scene1-smoke`、`scene1-info-box`
  - HTML控件：`scene1-btn-prev`、`scene1-btn-next`、`scene1-step-indicator`
  - JS中严格使用`document.getElementById`获取元素，禁止querySelectorAll配合全局class。
- IIFE隔离：所有JavaScript代码包裹在`(function() { ... })()`中，确保变量和函数不污染全局作用域，便于多场景合并。
- 容器结构：外层div固定宽高800×500，position:relative；SVG绝对定位填满容器；HTML按钮绝对定位在底部控件区。
