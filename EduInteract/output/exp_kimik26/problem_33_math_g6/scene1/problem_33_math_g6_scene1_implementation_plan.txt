[图示主题与整合说明]
- 本图示主题：平移法解析甲、乙两图形的周长构成
- 整合的步骤/概念：
  1. 原图观察：展示甲（双凹槽，深度各为d）与乙（单凹槽，深度为2d）的原始图形及外框虚线，建立直观印象。
  2. 水平边平移：利用平移思想，将顶部所有水平段（含凹槽底边）向上平移至同一水平线，证明甲、乙水平边总长均等于2倍长。
  3. 竖直边分析：高亮所有竖直边，标注凹槽深度，证明甲竖直边总长为2×宽+4d，乙竖直边总长为2×宽+2×(2d)=2×宽+4d，二者相等。
  4. 得出结论：汇总周长公式，高亮选项C（甲＝乙）。
- 教学价值：教师通过分步导航控制课堂节奏，从直观图形→线段平移→深度分析→公式汇总，层层递进，帮助学生理解"看似不同实则相等"的周长比较问题。

[分步序列]
- 初始状态（步骤0）「原图观察」：
  - 显示元素：甲/乙图形（斜线填充+黑色轮廓）、甲/乙外框虚线、"甲""乙"内部标签、"长""宽"尺寸标注。
  - 隐藏元素：所有高亮边、平移箭头、深度箭头、公式、结论框。
  - 教师引导：观察两图外框相同，凹槽数量与深度不同。

- 步骤1「水平边平移」：
  - 视觉变化：
    - 所有水平边加粗并变为蓝色（#1565c0）。
    - 显示平移目标虚线：甲(100,125)-(300,125)、乙(450,125)-(650,125)。
    - 显示8条蓝色虚线箭头，从各水平段中点垂直向上指向目标线。
    - 显示公式1："水平边总长 = 2×长"（位于两图下方中央）。
  - 教师讲解：顶部各段水平边平移后拼接，总长等于底边，即2倍长（上下两边）。

- 步骤2「竖直边分析」：
  - 视觉变化：
    - 隐藏步骤1的所有水平边高亮、平移箭头、目标线、公式1。
    - 所有竖直边加粗并变为红色（#c62828）。
    - 显示深度双向箭头及标签：甲左凹槽旁标注"d"（深度35px），乙凹槽旁标注"2d"（深度70px）。
    - 显示公式2甲："竖直边 = 2×宽 + 4d"（甲图下方）。
    - 显示公式2乙："竖直边 = 2×宽 + 4d"（乙图下方）。
  - 教师讲解：甲有2个凹槽，每个深度d，共4条竖边，总长=两侧边2×宽+4d；乙有1个凹槽，深度2d，共2条竖边，总长=2×宽+2×(2d)=2×宽+4d。

- 步骤3「得出结论」：
  - 视觉变化：
    - 隐藏步骤2的竖直边高亮、深度箭头、公式2。
    - 显示公式3："周长 = 2×长 + 2×宽 + 4d"（两图下方中央，绿色#2e7d32）。
    - 显示结论背景框（绿色圆角矩形）及结论标签"C．甲＝乙"（白色文字）。
  - 教师讲解：甲、乙周长公式完全相同，因此甲＝乙，答案选C。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位置(310,462)，90×28px。点击后回退到上一步骤，步骤0时禁用（opacity 0.4，pointer-events none）。
  - 「下一步 ▶」按钮：位置(420,462)，90×28px。点击后前进到下一步，步骤3时禁用。
  - 步骤指示器：位置(400,442)，显示当前步骤名称（如"步骤 1/4：水平边平移"）。
- 教师操作流程：
  1. 教师打开图示，默认进入步骤0，引导学生观察甲、乙图形外观差异。
  2. 点击「下一步」进入步骤1，讲解水平边平移思想，观察蓝色高亮与平移箭头。
  3. 点击「下一步」进入步骤2，讲解竖直边构成，观察红色高亮与深度标注。
  4. 点击「下一步」进入步骤3，展示最终公式与结论，高亮选项C。
  5. 可随时点击「上一步」回退复习，适合课堂提问或学生未理解时重复演示。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本场景为简单几何图形、线段高亮、分组显隐，无需引入D3/Three等重型库，原生SVG性能最优且文件体积最小。
- 画布尺寸：800 × 500 px（SVG viewBox="0 0 800 500"）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  甲外框(虚线)          乙外框(虚线)               |
  |  +-----------+         +-----------+              |
  |  |  ┌┐  ┌┐   |         |   ┌───┐   |              |
  |  |  │甲│  │   |         |   │ 乙│   |              |
  |  |  └┘  └┘   |         |   └───┘   |              |
  |  +-----------+         +-----------+              |
  |     长                    长                      |
  |  宽                  宽                           |
  |                                                   |
  |        [公式推导区：步骤1/2/3动态显示]             |
  |                                                   |
  |              步骤指示器                            |
  |        [◀ 上一步]  [下一步 ▶]                     |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：变量 `let currentStep = 0;`（范围0~3）。每次点击按钮时更新currentStep，调用 `renderStep()` 函数。
  2. renderStep() 逻辑：根据currentStep，设置各SVG `<g>` 组的 `display` 属性（或CSS opacity + transition）。
     - scene1-step0-group：步骤0基础元素（始终显示，但步骤1-3中部分子元素可能覆盖）。
     - scene1-step1-group：步骤1专属（水平边高亮、平移箭头、公式1）。
     - scene1-step2-group：步骤2专属（竖直边高亮、深度箭头、公式2）。
     - scene1-step3-group：步骤3专属（公式3、结论框）。
  3. 边高亮实现：为甲、乙的所有水平边和竖直边分别设置class（如scene1-h-edge、scene1-v-edge），步骤切换时通过JS批量修改stroke和stroke-width。
  4. 平移箭头动画：使用CSS `@keyframes dash` 对 stroke-dashoffset 进行动画，营造流动感；或直接静态显示虚线箭头。
  5. 按钮状态：在renderStep()中检查currentStep，设置`scene1-btn-prev`和`scene1-btn-next`的disabled属性及样式。
  6. 公式区位置固定：所有公式文本使用同一坐标(400,345)（步骤1/3）或分散坐标（步骤2），通过显隐切换避免重叠。
- ID命名规范：
  - 所有SVG元素ID前缀：`scene1-`
  - 示例：`scene1-jia-shape`（甲图形）、`scene1-yi-shape`（乙图形）、`scene1-jia-outline`（甲外框）、`scene1-step1-group`（步骤1组）、`scene1-btn-prev`（上一步按钮）、`scene1-formula-h`（水平边公式）、`scene1-formula-final`（最终公式）、`scene1-conclusion-bg`（结论背景）、`scene1-conclusion-text`（结论文字）
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免多场景合并时变量污染全局作用域。
