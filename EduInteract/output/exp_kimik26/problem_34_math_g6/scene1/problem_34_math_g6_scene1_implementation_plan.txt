[图示主题与整合说明]
- 本图示主题：长方形右侧剪去正方形后的周长变化与平移法推导
- 整合的步骤/概念：①原长方形与周长公式回顾；②剪去正方形后的凹字形图形展示；③内外边界线段高亮与分类；④平移法动画（竖边平移填补右侧缺口）；⑤周长计算与结论
- 教学价值：教师可使用分步导航按课堂节奏逐步揭示关键关系。步骤0建立已知条件，步骤1呈现变化后的图形，步骤2通过颜色区分新旧边界，步骤3用动画直观展示“平移法”核心思想，步骤4得出答案。可随时回退重讲。

[分步序列]
- 初始状态（步骤0）「原长方形」：
  - 显示完整长方形 rect (100,150)-(400,350)，stroke=#000000，stroke-width=2
  - 显示四边中的顶边、右侧完整边、底边、左侧（或用rect统一绘制）
  - 显示标签「6cm」(250,372)、「4cm」(70,255)
  - 文本框显示：标题「原长方形」；内容「长 = 6 cm，宽 = 4 cm」「原周长 = 2×(6+4) = 20 cm」
  - 隐藏所有缺口相关元素、剪去区域、被剪去边

- 步骤1「剪去正方形」：
  - 隐藏原长方形rect和右侧完整边
  - 显示剪后8段轮廓（顶边、右侧上段、缺口上横、缺口左竖、缺口下横、右侧下段、底边、左侧），均为黑色实线2px
  - 显示被剪去边(400,200)-(400,300)，灰色虚线1.5px
  - 显示剪去区域填充rect(300,200)-(400,300)，#e0e0e0 opacity 0.2
  - 显示缺口标签「2cm」(350,175)深度、「2cm」(275,255)高度
  - 文本框更新：标题「剪去正方形」；内容「缺口：2 cm × 2 cm」「观察：哪些边消失了？」「哪些边是新出现的？」

- 步骤2「边界分析」：
  - 缺口上横(300,200)-(400,200)、缺口左竖(300,200)-(300,300)、缺口下横(300,300)-(400,300)变为红色实线，stroke-width=2.5px
  - 其余保留边界保持黑色实线2px
  - 被剪去边保持灰色虚线
  - 文本框更新：标题「边界分析」；内容「上：6 + 下：6 + 左：4」「右上：1 + 右下：1」「内上：2 + 内左：2 + 内下：2」「周长 = 24 cm」

- 步骤3「平移法」：
  - 显示平移轨迹：蓝色虚线(300,250)-(400,250)，线宽2px，带箭头
  - 创建平移动画线段anim-line，初始与缺口左竖重合(300,200)-(300,300)，红色2.5px
  - 启动动画：在800ms内将anim-line的x1、x2从300匀速（ease-out）增加到400，最终位置(400,200)-(400,300)
  - 动画完成后：anim-line变为黑色2px；隐藏被剪去边(400,200)-(400,300)；隐藏原缺口左竖(300,200)-(300,300)
  - 缺口上横、缺口下横保持红色2.5px
  - 文本框更新：标题「平移法」；内容「将内左竖边（2cm）」「向右平移填补缺口」「→ 右侧竖直总长不变」「新增水平边：2 + 2 = 4 cm」

- 步骤4「得出结论」：
  - 所有边界线段恢复为黑色实线2px（缺口上横、缺口下横、anim-line均变黑）
  - 隐藏平移轨迹
  - 文本框更新：标题「得出结论」（绿色#2e7d32）；内容「周长 = 原周长 + 新增」「= 20 + 4」「= 24（厘米）」（绿色加粗）「答案：D．24」（绿色加粗16px）

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位置(290,450)，宽100×高30。点击后currentStep减1，调用renderStep()回退到上一步。
  - 「下一步 ▶」按钮：位置(410,450)，宽100×高30。点击后currentStep加1，调用renderStep()进入下一步。
  - 按钮间距20px，画布底部居中。
  - 步骤0时「上一步」禁用（opacity 0.4，pointer-events none）；步骤4时「下一步」禁用。
- 教师操作流程：
  1. 教师打开图示，步骤0展示原长方形与周长公式，口头回顾已知条件。
  2. 点击「下一步」进入步骤1，展示剪后图形，引导学生观察缺口位置。
  3. 点击「下一步」进入步骤2，红色高亮新增三条内边界，带领学生逐段累加周长。
  4. 点击「下一步」进入步骤3，播放平移动画，解释“竖边平移后右侧总长不变，但多了两条横边”。
  5. 点击「下一步」进入步骤4，绿色高亮答案D，总结公式。
  6. 可随时点击「上一步」回退到任意步骤重新讲解。

[技术实现]
- JS库选择：原生SVG（使用<svg>、<line>、<rect>、<text>、<polygon>元素）。原因：本题全部为基本几何线段与简单填充，无需复杂图表库；原生SVG配合DOM操作即可实现颜色切换、显示/隐藏、属性动画，且矢量清晰。
- 画布尺寸：800 × 500 px（viewBox="0 0 800 500"）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------------+
  |                                                        |
  |   100  300  400                      460           760 |
  |    |    |    |                        |             |  |
  |    +------------------+   +----------------------+  |  |
  |    |                  |   |                      |  |  |
  |150 |   长方形 300×200  |   |   文本说明区          |  |  |
  |    |                  |   |   x=460~760          |  |  |
  |    |    +--------+    |   |   y=140~380          |  |  |
  |200 |    | 缺口   |    |   |                      |  |  |
  |    |    |100×100 |    |   |                      |  |  |
  |300 |    +--------+    |   |                      |  |  |
  |    | (300,200)        |   |                      |  |  |
  |350 +------------------+   +----------------------+  |  |
  |    6cm标注                                          |  |
  |                                                     |  |
  |        [◀ 上一步]    [下一步 ▶]                      |  |
  |        x:290~390     x:410~510                      |  |
  |        y:450~480     y:450~480                      |  |
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `let currentStep = 0;`，共5步（0~4）。`renderStep()` 函数根据currentStep统一控制所有SVG元素的display、stroke、stroke-width属性。
  2. 元素显隐：步骤0使用一个`<rect id="scene1-original-rect">`绘制完整长方形；步骤1起隐藏该rect，改为显示8段`<line>`轮廓。通过设置`display: none / inline`切换。
  3. 步骤3动画：使用`requestAnimationFrame`实现。动画开始前创建`<line id="scene1-anim-line">`与缺口左竖重合。动画函数计算进度t（0→1），应用easeOut：`t = 1 - Math.pow(1 - t, 3)`。每帧更新x1、x2为`300 + 100 * t`。800ms后结束，将anim-line的stroke改为#000000，stroke-width改为2，并隐藏`scene1-removed-edge`和原`scene1-notch-left`。
  4. 文本更新：文本框内使用`<text>`元素或foreignObject内的HTML。为简化多行控制，建议使用foreignObject包裹一个`<div id="scene1-text-content">`，通过innerHTML直接写入带样式的HTML段落，避免手动计算<tspan>的dy偏移。
  5. 按钮事件：为`scene1-btn-prev`和`scene1-btn-next`绑定click事件，修改currentStep并调用renderStep()。在renderStep()内更新按钮disabled状态。
  6. 防重叠：所有标签使用text-anchor=middle或end，确保文字向空白区域延伸；文本框与图形区间保持≥60px间隙；控件区严格限制在y=440~490，主图区最高到y=400。
- ID命名规范：所有SVG元素及JS变量均以`scene1-`为前缀。例如：`scene1-original-rect`、`scene1-edge-top`、`scene1-notch-left`、`scene1-anim-line`、`scene1-trace-line`、`scene1-text-panel`、`scene1-text-content`、`scene1-btn-prev`、`scene1-btn-next`。JS中使用`document.getElementById`获取元素，禁止全局class选择器，避免多场景合并时污染。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，不暴露全局变量。
