[图示主题与整合说明]
- 本图示主题：圆剪拼近似长方形——分割份数对近似程度的影响及周长普适性验证
- 整合的步骤/概念：
  1. 将半径 r=10cm 的圆进行 n 等分（n 取 4,8,16,32,64）
  2. 上半圆扇形与下半圆扇形交错拼合，形成近似长方形
  3. 观察 n 增大时锯齿边缘逐渐平滑、图形趋近长方形的极限过程
  4. 验证拼合图形的长≈πr=31.4cm、宽=r=10cm、周长=82.8cm 不随 n 变化
- 教学价值：教师通过拖动滑块实时改变分割份数，让学生直观感受"分的份数越多越接近长方形"的极限思想，同时通过底部不变的数值面板理解周长公式的普适性，避免学生误以为近似程度会影响周长计算结果。

[视觉元素清单]
- 圆：左侧，圆心(200,185)，半径80px（比例8px/cm），黑色描边2px
- 圆分割线：从圆心到圆周，n条，角度间隔360°/n，灰色#888888虚线（stroke-dasharray="4,4"），描边1px
- 扇形填充：n个SVG path扇形，统一填充浅蓝#1565c015%（15%不透明度蓝色）
- 半径线段：从圆心水平向右到圆周，黑色1px，末端可画小箭头示意
- 拼合图形外框：长方形，位置(440,145)宽251高80，黑色描边2px
- 上边缘弧：n/2条二次贝塞尔曲线，连接偶数分点，控制点向上偏移A=256/n px，描边蓝色#1565c0，2px
- 下边缘弧：n/2条二次贝塞尔曲线，连接奇数分点，控制点向下偏移A=256/n px，描边红色#c62828，2px
- 内部锯齿线：连续折线，连接(x_i,y0)与(x_{i+1},y1)交替，黑色1px
- 拼合图形填充：与外框同范围，填充浅蓝#1565c015%
- 滑块：HTML range input，范围4-64，步进4，自定义样式
- 数值面板：三行文字，长/宽为黑色，周长为绿色加粗

[分步序列]
本场景为连续滑块交互，无离散步骤按钮。以下列出关键状态及视觉特征：

- 初始状态（n=16，页面加载默认）：
  * 左侧圆显示16条分割线，16个扇形浅蓝填充
  * 右侧拼合图形显示8个上弧（蓝）和8个下弧（红），锯齿线16条
  * 波浪边缘明显但较细密，已能辨认长方形轮廓
  * 底部面板显示长≈31.4cm、宽=10cm、周长=82.8cm
  * 滑块按钮位于轨道中间偏右（对应n=16）

- 状态 n=4（滑块拖至最左）：
  * 圆只有4条分割线，4个大扇形
  * 拼合图形仅2个上弧和2个下弧，波浪非常粗大，锯齿线4条
  * 图形明显偏离长方形，呈大波浪状
  * 底部数值保持不变

- 状态 n=8：
  * 圆8条分割线，8个扇形
  * 拼合图形4个上弧和4个下弧，波浪仍明显但较n=4细密
  * 锯齿线8条
  * 底部数值保持不变

- 状态 n=32：
  * 圆32条分割线，扇形很细
  * 拼合图形16个上弧和16个下弧，波浪很细密，肉眼接近直线
  * 锯齿线32条，非常密集
  * 底部数值保持不变

- 状态 n=64（滑块拖至最右）：
  * 圆64条分割线，扇形极细
  * 拼合图形32个上弧和32个下弧，波浪几乎不可见，非常接近标准长方形
  * 锯齿线64条，极密集
  * 底部数值保持不变

教师可随时拖动滑块在任意n值停留观察，形成连续渐变认知。

逐对检查（距离<20px视为需关注）：
- "O"(205,190) 与 "r = 10cm"(265,170)：水平距60px，垂直距20px，欧氏距63px → 无冲突
- "n = 16"(200,90) 与 圆上边缘(y=105)：垂直距15px → 无冲突（文字在图形外侧）
- "近似长方形"(555,130) 与 拼合图形上边缘(y=145)：垂直距15px → 无冲突
- "长 = πr = 31.4cm"(555,240) 与 拼合图形下边缘(y=225)：垂直距15px → 无冲突
- "宽 = r = 10cm"(695,185) 与 拼合图形右边缘(x=681)：水平距14px → 文字左边缘在x=695，图形右边缘在x=681，间距14px，文字向右延伸不重叠 → 可接受（≥12px）
- "宽 = r = 10cm"右边缘(x≈795) 与 画布右边缘(x=800)：距5px → 文字宽100px起点695，实际右边缘795，距画布边缘5px。调整：将起点从(695,185)改为(690,185)，文字范围690~790，距边缘10px。同时与图形间距变为9px，略紧但可接受。或者保持695，因文字实际渲染宽度可能<100px，通常不会触边。计划采用(695,185)，代码实现时确保overflow:hidden或微调。
- "份数 n："(150,360) 与 滑块轨道(x=200)：水平距50px → 无冲突
- 滑块刻度"4"(200,375) 与 "64"(600,375)：水平距400px → 无冲突
- 面板内三行文字：y间距20px，在同一面板内 → 无冲突
- 滑块当前值(400,335) 与 "近似长方形"(555,130)：y差205px → 无冲突

解决方案："宽 = r = 10cm"标签若渲染偏宽，可微调至(690,185)或缩小字体至12px。计划中按(695,185)实现，字体14px，预计实际宽度约90px，右边缘785，距画布边缘15px，安全。

[交互方案]
- 交互类型：连续拖拽/滑块（HTML input type="range"）
- 控件说明：
  * 滑块轨道：位于画布底部y=352~358，x=200~600，灰色圆角条
  * 滑块按钮：蓝色圆形，直径20px，随拖动水平移动

  * 当前n值显示：紧跟滑块按钮上方，实时更新"n = XX"
  * 数值面板：滑块正下方，固定显示长/宽/周长，始终不变
- 教师操作流程：
  1. 教师向学生展示初始状态（n=16），说明圆如何被分割拼合成近似长方形
  2. 教师将滑块向左拖至n=4，让学生观察粗大的波浪边缘，强调"此时不太像长方形"
  3. 教师缓慢向右拖动滑块，学生观察波浪逐渐变细、边缘趋近直线
  4. 教师拖至n=64，让学生确认图形已非常接近长方形
  5. 教师引导学生注意底部面板：无论n如何变化，长、宽、周长始终不变
  6. 教师可反复拖动，强化"分的份数越多越接近长方形，但周长公式始终适用"的结论

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无需外部库）。理由：本场景以动态几何图形为主，SVG的path、line、circle元素配合JS动态更新属性即可完美实现，引入D3等库反而增加体积。
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [画布 800×500]
  +--------------------------------------------------+
  |  标题区(y=20~60)                                  |
  |  左侧: 圆(圆心200,185,r=80)   右侧: 拼合图形      |
  |         ↑ n=16标签                   (440,145)    |
  |         O 圆心标记                  251×80        |
  |    ←r=10cm→ 半径标注              近似长方形      |
  |                                    长=πr=31.4cm   |
  |                                    宽=r=10cm      |
  |  中间过渡区(空白)                                 |
  |--------------------------------------------------|
  |  控件区(y=330~390)                                |
  |     份数 n： [====●====] 4          64            |
  |              n=16 (滑块上方)                      |
  |--------------------------------------------------|
  |  面板区(y=400~490)                                |
  |     +------------------------------+              |
  |     |  长 ≈ πr = 31.4 cm          |              |
  |     |  宽 = r = 10 cm             |              |
  |     |  周长 = 82.8 cm             |              |
  |     +------------------------------+              |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 比例换算：1cm = 8px，故 r=80px，半周长πr=251px，拼合图形尺寸251×80px
  2. 圆绘制：用SVG circle画轮廓，用JS循环生成n条line作为分割线（角度2πi/n）
  3. 扇形填充：用SVG path画n个扇形，d="M cx,cy L x1,y1 A r,r 0 0,1 x2,y2 Z"，统一fill="#1565c015%"
  4. 拼合图形绘制：
     - 段宽 seg_w = w / n = 251 / n
     - 上边缘弧（i为偶数0,2,4...）：二次贝塞尔曲线，起点(x0+i*seg_w,y0)，控制点(x0+(i+1)*seg_w, y0-A)，终点(x0+(i+2)*seg_w,y0)，其中A=256/n
     - 下边缘弧（i为奇数1,3,5...）：起点(x0+i*seg_w,y1)，控制点(x0+(i+1)*seg_w, y1+A)，终点(x0+(i+2)*seg_w,y1)
     - 内部锯齿线：连续path，命令序列 M x0,y0 L x0+seg_w,y1 L x0+2*seg_w,y0 L x0+3*seg_w,y1 ...
     - 外框：rect元素覆盖最底层
  5. 滑块位置计算：滑块轨道宽400px（x=200~600），n范围4~64共60个单位，步进4。按钮x = 200 + (n-4)/60 * 400
  6. 实时更新：监听input事件，每次n变化时清空并重绘圆的分割线、扇形填充、拼合图形的所有path
  7. 性能优化：n最大64，path数量约200个，现代浏览器完全流畅，无需复杂优化
