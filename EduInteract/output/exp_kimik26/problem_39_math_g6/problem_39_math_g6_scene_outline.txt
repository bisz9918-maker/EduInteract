    **题目原文**

    如图，小旗的顶点用数对表示为（5，7），现在将小旗绕点O，顺时针方向旋转90°，现在小旗的顶点可以用数对（   ）表示。

    A．（7，5）　B．（10，3）　C．（9，3）　D．（1，3）

    **题目分析**

    本题考查平面直角坐标系中图形绕定点顺时针旋转90°的坐标变换。关键在于：
    1. 从图中读出旋转中心O的坐标。观察原图，小旗顶点为（5，7），竖直杆向下延伸4个单位到达点O，因此O的坐标为（5，3）。
    2. 理解“绕点旋转”不是绕原点旋转，而是绕任意定点旋转。需先将顶点平移至以O为原点的相对坐标系，执行旋转后再平移回去。
    3. 顺时针旋转90°的坐标变换规则：若点P相对于旋转中心O的坐标为（x, y），则旋转后相对坐标变为（y, -x）。

    **整体讲解思路**

    1. 先带领学生读图，确认O点坐标（5，3）。
    2. 引导学生计算顶点（5，7）相对于O的相对位置：向上4个单位，即相对坐标（0，4）。
    3. 应用顺时针旋转90°规则：相对坐标（0，4）→（4，0）。
    4. 将相对坐标加回O点坐标，得到绝对坐标（5+4，3+0）=（9，3）。
    5. 验证选项，答案为C。

    **图示规划说明**

    本题为单一坐标系内的旋转变换问题，所有视觉元素（原图、旋转中心、辅助线、旋转后图形）均属于同一类视觉对象，因此整合为一个交互式图示，通过分步按钮导航完成从读图到结论的完整认知过程。

    **本图示的教学说明**

    教师在讲解时应充分利用分步导航，引导学生逐步建立“绕定点旋转”的空间观念：

    1. **读图阶段（步骤0-1）**：先让学生观察原图，说出O点的位置。教师可提问：“小旗顶点在（5，7），O点在它的正下方几格？”引导学生发现O点坐标为（5，3）。

    2. **向量分析阶段（步骤2）**：强调“绕O旋转”不等于“绕原点旋转”。教师可引导学生画出O到顶点的连线，计算相对坐标：
       - 横坐标差：5 − 5 = 0
       - 纵坐标差：7 − 3 = 4
       - 相对位置是（0，4），即O点正上方4个单位。

    3. **旋转变换阶段（步骤3-4）**：讲解顺时针旋转90°的坐标变换规则。对于相对坐标（x, y），顺时针转90°后变为（y, −x）。因此：
       - （0，4）→（4，0）
       - 新绝对坐标 = O点坐标 + 新相对坐标 = （5，3）+（4，0）=（9，3）

       教师可在网格上带领学生用手指或教鞭模拟旋转：从O点向上4格，顺时针转90°后指向O点右侧4格。

    4. **验证阶段（步骤5）**：展示四个选项，让学生独立判断。教师可追问：“如果误把O当成原点，会得到什么答案？”（绕原点顺时针转90°：（5，7）→（7，−5），不在选项中，说明必须注意旋转中心。）

    **关键公式**

    设旋转中心为 O(a, b)，点 P(x, y) 绕 O 顺时针旋转90°得到 P'(x', y')：
    1. 相对坐标：Δx = x − a，Δy = y − b
    2. 旋转后相对坐标：Δx' = Δy，Δy' = −Δx
    3. 新绝对坐标：x' = a + Δy，y' = b − Δx

    代入本题：a=5, b=3, x=5, y=7
    - Δx = 0，Δy = 4
    - x' = 5 + 4 = 9，y' = 3 − 0 = 3
    - 答案为 **C. （9，3）**
