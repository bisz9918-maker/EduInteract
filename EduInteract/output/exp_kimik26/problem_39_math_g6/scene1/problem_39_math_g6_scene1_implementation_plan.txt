[图示主题与整合说明]
- 本图示主题：小旗绕点O顺时针旋转90°的坐标变换

[分步序列]
- 步骤0（初始状态）：显示坐标网格、坐标轴及刻度标签、原始小旗（黑色轮廓+浅灰填充）、顶点标注"(5,7)"、O点标注"O"。右侧信息面板空白。等待教师点击下一步。
- 步骤1（识别中心）：新增：O到P的蓝色实线段（与旗杆重合高亮）、O坐标标注"(5,3)"（蓝色，O点右下方）、O点蓝色描边高亮、顶点P旁加蓝色小圆点高亮。右侧信息标题"步骤1：识别旋转中心"，内容"旋转中心 O(5,3)""顶点 P(5,7)"。
- 步骤2（相对向量）：新增：局部虚线坐标系（以O为中心，蓝色虚线十字）、向量标注"OP→=(0,4)"（线段OP右侧）、右侧信息更新为标题"步骤2：分析相对位置"，内容"Δx = 5−5 = 0""Δy = 7−3 = 4"。
- 步骤3（旋转变换）：新增：O到P'的蓝色虚线（水平向右）、旋转弧线箭头（圆心O，半径40，顺时针90°）、向量标注"OP'→=(4,0)"（虚线段上方）、右侧信息更新为标题"步骤3：顺时针旋转90°"，内容"旋转规则：(x,y)→(y,−x)""(0,4) → (4,0)"。
- 步骤4（得出新坐标）：新增：旋转后小旗（红色轮廓+浅红填充）、新顶点标注"(9,3)"（红色，P'右下方）、右侧信息更新为标题"步骤4：计算新坐标"，内容"O(5,3) + (4,0)""= (9,3)"。原始小旗仍显示（可降为30%透明度或保持原样以便对比）。
- 步骤5（验证选项）：右侧显示四个选项A.(7,5)、B.(10,3)、C.(9,3)、D.(1,3)。正确答案C用绿色#2e7d32高亮（背景框或粗体），左侧加绿色"✓"。错误选项A/B/D左侧加红色"×"。右侧信息标题"步骤5：选择答案"，内容"正确答案是 C"。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  1. 「◀ 上一步」按钮：位置(300,455)，大小80×30。作用：回退到上一步骤，所有该步骤新增元素隐藏，前一步元素恢复。
  2. 「下一步 ▶」按钮：位置(420,455)，大小80×30。作用：推进到下一步骤，显示该步骤新增元素。
  3. 步骤提示文字：位置(400,490)居中。作用：显示当前步骤编号与名称，如"步骤2/5：分析相对位置"。
- 教师操作流程：教师点击「下一步」逐步展示解题过程，每步可停留讲解；可随时点击「上一步」回退复习；步骤0为题目初始状态，步骤5为最终结论。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：本场景为简单几何图形与分步显隐，无需复杂图表库；SVG矢量图形适合坐标网格与几何变换的精确绘制。
- 画布尺寸：800×500 px（固定）
- 布局草图：
  ```
  +--------------------------------------------------+
  |  [坐标网格 300×300]        [右侧信息面板]          |
  |  x:100~400, y:120~420      x:450~750             |
  |  含原始小旗、旋转后小旗    含公式/选项            |
  |                                                   |
  |                                                   |
  |                                                   |
  |  [◀ 上一步]  [下一步 ▶]                          |
  |  x:300~380   x:420~500    y:455                  |
  |  步骤提示文字 (400,490)                           |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：定义currentStep变量（0~5），每步用一个配置对象描述应显示的元素ID列表。
  2. 元素显隐：所有可切换元素初始display:none，通过JS设置display属性或CSS类控制显隐。避免使用opacity造成遮挡。
  3. 坐标计算：统一函数gridToCanvas(x,y)将网格坐标转为画布坐标：cx=100+x*30, cy=420-y*30。
  4. 旋转弧线：使用SVG path绘制，命令为"M 250 290 A 40 40 0 0 1 290 330"，箭头用marker-end实现。
  5. 选项高亮：步骤5时给正确选项添加class="correct"（绿色背景框或文字加粗），错误选项添加class="wrong"（红色文字+×号）。
  6. 动画：本场景以静态分步为主，无需复杂动画；步骤3的旋转弧线可直接显示，如需动画可用CSS stroke-dasharray/stroke-dashoffset实现绘制动画（可选）。
- ID命名规范：所有交互元素ID必须以`scene1-`为前缀。例如：
  - 原始小旗组：id="scene1-flag-original"
  - 旋转后小旗组：id="scene1-flag-rotated"
  - O点：id="scene1-point-o"
  - P点标签：id="scene1-label-p"
  - 步骤1连线：id="scene1-line-op"
  - 上一步按钮：id="scene1-btn-prev"
  - 下一步按钮：id="scene1-btn-next"
  - JS中严格使用document.getElementById获取元素，禁止querySelectorAll配合全局class。
- IIFE隔离：所有JavaScript代码包裹在`(function() { ... })()`中，避免全局变量污染。
