[图示主题与整合说明]
- 本图示主题：三种水平滑轮装置的隔离受力分析与拉力大小比较
- 整合的步骤/概念：原题三装置并列展示 → 定滑轮隔离受力分析（F₁=f） → 动滑轮省力分析（F₂=f/2） → 倒置动滑轮费力分析（F₃=2f） → 三力汇总结论（F₂＜F₁＜F₃，选项D）
- 教学价值：教师通过分步导航，按"观察结构→逐个隔离分析→汇总比较"的递进逻辑讲解，可随时回退复习，帮助学生建立"先看结构、再画受力、最后比较"的解题思维。

[视觉元素清单]
- 滑轮：圆形轮廓(r=14或18)，内部轮轴十字线（水平+竖直直径），定滑轮与动滑轮视觉样式相同，通过上下文区分
- 绳子：粗实线段(stroke-width=3)，绕滑轮部分用SVG path弧线绘制，颜色#000000
- 物体：水平地面上的矩形方块，fill=#e0e0e0，stroke=#000000，stroke-width=1.5
- 地面：水平实线，下方加3条斜向阴影线（间隔6px，斜率-1）表示地面
- 墙面：竖直实线，右侧加3条斜向阴影线（间隔6px，斜率-1）表示墙体
- 力箭头：带arrowhead的线段，箭头大小8px，颜色按类型区分
- 隔离框：虚线矩形(stroke=#888888, stroke-dasharray=5,5)，包围待分析对象
- 高亮框：蓝色矩形框(stroke=#1565c0, stroke-width=2)，fill=#1565c0，fill-opacity=0.2，用于聚焦当前装置
- 淡化遮罩：非聚焦装置整体opacity降至0.3（通过父g元素的opacity属性控制）
- 配色规则：
  - 背景#ffffff，主线#000000
  - 蓝高亮#1565c0：当前装置高亮框、绳张力T箭头、隔离框标签、步骤指示器当前项、结论区选项背景
  - 红高亮#c62828：人所施加的拉力F₁/F₂/F₃箭头及标签
  - 绿高亮#2e7d32：滑动摩擦力f箭头及标签
  - 辅助线#888888：隔离框虚线

- 关键实现要点：
  1. 状态机设计：用变量`currentStep`（0~4）记录当前步骤，每次按钮点击更新状态后调用`renderStep()`统一渲染。
  2. 分组管理：将三装置分别放在`<g id="scene1-device-1">`、`<g id="scene1-device-2">`、`<g id="scene1-device-3">`中；将每步隔离分析图放在`<g id="scene1-step-0">`~`<g id="scene1-step-4">`中。渲染时通过设置`display: none/block`或`visibility`控制显隐。
  3. 装置聚焦逻辑：步骤1~3时，当前装置组opacity=1并叠加蓝色高亮框，其余两组opacity=0.3；步骤0和4时，三组opacity均为1，高亮框隐藏。
  4. 高亮框实现：用绝对坐标矩形（如步骤1框(75,35)-(285,145)），步骤切换时设置其`display`属性。
  5. 步骤指示器：5个`<circle>`元素，根据`currentStep`设置对应索引的fill为#1565c0，其余为#cccccc。
  6. 按钮边界处理：上一步按钮在currentStep=0时disabled（opacity=0.5，pointer-events=none），下一步按钮在currentStep=4时disabled。
  7. 动画曲线：本场景无需复杂动画，步骤切换直接瞬时切换（无淡入淡出），保证课堂讲解节奏紧凑。如需柔和过渡，可给opacity变化加0.2s CSS transition。
