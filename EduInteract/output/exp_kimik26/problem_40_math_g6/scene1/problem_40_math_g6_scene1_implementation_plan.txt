[视觉元素清单]
- 正方体立体图：等轴测投影，三个可见面（正面、左面、上面），边框1.5px #000，填充#fff
- 1-4-1十字展开图：6个正方形，每格60×60px，间距10px，通过foreignObject内嵌HTML div实现以支持CSS 3D折叠动画
- 图案：
  · 心形：SVG path绘制，红色#c62828，位于左面/①/③
  · 笑脸：SVG circle+path绘制，蓝色#1565c0，位于正面/②/④
  · 太阳花：SVG circle+line绘制，绿色#2e7d32，位于上面/⑤/⑥
- 虚线连线：连接相对面中心，①-③红色、②-④蓝色、⑤-⑥绿色，stroke-dasharray="4,4"
- 高亮背景：每对相对面正方形覆盖半透明色块（红#ffcdd2、蓝#bbdefb、绿#c8e6c9，opacity 0.3）
- 口诀框：圆角矩形背景#f5f5f5，内文字"中间一行隔一个，上下两个是一对"
- 配色严格沿用spec：背景#fff，主线#000，三色主题（红/蓝/绿）分别对应三对相对面

[分步序列]
- 步骤0「题目条件」：显示正方体立体图（左面♥、正面☺、上面☀），下方标注"对面图案相同"。展开图、序号、连线、高亮、口诀均隐藏。左侧正方体为视觉焦点。
- 步骤1「展开结构」：右侧出现1-4-1十字展开图（6个正方形，带对应图案），标注序号①②③④⑤⑥。左侧正方体保留但透明度降至0.3作为参考。连线、高亮、口诀仍隐藏。
- 步骤2「规律标注」：在展开图上用虚线连接相对面（①-③红、②-④蓝、⑤-⑥绿），三对相对面正方形分别覆盖同色半透明高亮。右下方出现口诀框"中间一行隔一个，上下两个是一对"。
- 步骤3「折叠验证」：右侧展开图通过CSS 3D transform动态折叠成正方体（各面绕公共边旋转90°，translateZ拼合成边长60px立方体），折叠完成后正方体缓慢旋转展示。左侧原正方体恢复不透明，与右侧折叠结果对照。可附加文字"①与③相对不相邻，②与④相对不相邻，⑤与⑥相对不相邻"强化结论。
- 教师可随时点击「上一步」回退到任意步骤复习。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  · 「上一步」按钮：位置(300,455)，90×32px，点击后currentStep减1（下限0），回退到上一状态
  · 「下一步」按钮：位置(420,455)，90×32px，点击后currentStep加1（上限3），前进到下一状态
  · 步骤指示文本：位置(540,475)，显示"步骤 X/4"
- 教师操作流程：
  1. 加载后处于步骤0，教师讲解题目条件（正方体三可见面及"对面相同"约束）
  2. 点击「下一步」进入步骤1，引导学生观察1-4-1展开图结构，认识6个面的序号
  3. 点击「下一步」进入步骤2，教师指着虚线和高亮讲解"中间隔一个、上下是一对"的规律，朗读口诀
  4. 点击「下一步」进入步骤3，播放折叠动画，验证相对面在折叠后确实不相邻，强化空间观念
  5. 讲解中可随时回退到步骤2或步骤1复习关键概念

[技术实现]
- JS库选择：原生SVG + 原生CSS 3D Transforms（无需外部库）。展开图折叠动画依赖CSS transform-style: preserve-3d，通过foreignObject将HTML div嵌入SVG实现。
- 画布尺寸：800×500px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------------+
  |                                                        |
  |   +------------+          +--------------------+       |
  |   |  正方体    |          |     ⑤ ☀            |       |
  |   |   ☀        |          |   +----+           |       |
  |   |  ♥ ☺       |          | ①♥|②☺|③♥|④☺|      |       |
  |   |            |          |   +----+           |       |
  |   |            |          |     ⑥ ☀            |       |
  |   +------------+          +--------------------+       |
  |                              [口诀框]                  |
  |                                                        |
  |              [◀上一步]  [下一步▶]  步骤 1/4             |
  +--------------------------------------------------------+
  [控件栏 y=440~490]
  ```
- 关键实现要点：
  1. 状态机：用变量scene1_currentStep（0~3）管理四步状态，每次切换时调用scene1_render()更新所有元素的显隐/样式。
  2. 元素显隐：通过添加/移除CSS类（如.scene1-hidden { display: none; } 或 opacity: 0; transition: opacity 0.3s）实现平滑过渡。
  3. 展开图实现：在SVG内使用<foreignObject x="380" y="120" width="360" height="280">嵌入一个HTML div容器（id="scene1-fold-container"），设置perspective: 800px; transform-style: preserve-3d;。容器内6个div（id="scene1-face-1"~"scene1-face-6"）初始通过绝对定位摆成1-4-1展开图。
  4. 折叠动画：步骤3时，通过JS给scene1-fold-container添加.scene1-folded类，触发CSS transition（transition: transform 1s ease-in-out）。各面的transform从展开图位置切换为立方体面位置（例如面②正面translateZ(30px)，面①左面rotateY(-90deg) translateZ(30px)等）。同时容器整体添加旋转动画（rotateX(-20deg) rotateY(30deg)）并持续旋转，展示三对相对面不相邻。
  5. 图案绘制：心形用SVG path（贝塞尔曲线），笑脸用circle+两个ellipse眼睛+path嘴巴，太阳花用circle中心+8条放射line。展开图内图案可用SVG背景或直接用div内嵌SVG。
  6. 事件绑定：document.getElementById('scene1-btn-prev').addEventListener('click', ...) 和 scene1-btn-next。
  7. 初始状态：页面加载后自动执行scene1_render(0)，仅显示正方体和"对面图案相同"文字。
- ID命名规范（严格前缀scene1-）：
  · 正方体面：scene1-cube-front, scene1-cube-left, scene1-cube-top
  · 展开图容器：scene1-fold-container
  · 展开图各面：scene1-face-1 ~ scene1-face-6
  · 连线：scene1-line-1-3, scene1-line-2-4, scene1-line-5-6
  · 高亮：scene1-highlight-1-3, scene1-highlight-2-4, scene1-highlight-5-6
  · 按钮：scene1-btn-prev, scene1-btn-next
  · 其他：scene1-step-indicator, scene1-rhyme-box, scene1-rhyme-text
- IIFE隔离：所有JS逻辑包裹在 (function() { ... })() 中，避免多场景合并时全局变量污染。
