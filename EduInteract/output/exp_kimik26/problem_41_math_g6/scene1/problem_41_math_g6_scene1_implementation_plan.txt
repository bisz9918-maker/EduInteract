[图示主题与整合说明]
- 本图示主题：路灯下小亮由A点走向B点过程中影子长度的动态变化
- 整合的步骤/概念：中心投影原理、光线追踪、影长实时计算、相似三角形铺垫（辅助线）、"先变短后变长"结论的直观验证
- 教学价值：教师通过拖动滑块，让学生自主发现影长随位置连续变化的规律；在路灯正下方影长为0是直观记忆点；辅助线开关为后续讲解相似三角形做视觉铺垫

动态坐标公式（val为滑块值0–100）：
- px = 140 + 5.2 × val        // 人底部中心x，范围140(A)~660(B)
- sx = 480 + (26/19) × (px − 480)   // 影子顶端x（光线与地面的交点）
- mx = (px + sx) / 2          // 影子中点x，用于影长标签
- cx = 150 + 4 × val          // 滑块thumb中心x，范围150~550
- 影长 L = |sx − px| = (7/19) × |px − 480|   // 实时影长数值

[分步序列]
本场景为连续滑块交互，无分步导航。以下列出教学讲解中的关键观察状态：

- 初始状态（val=0）：人在A点(px=140)。光线从灯泡(480,100)穿过人头顶(140,290)延长至地面交于x≈15。影子从(140,360)到(15,360)，影长≈125，为全程最长。影长标签显示"影长 l≈125"。
- 中间状态（val≈65，人在路灯正下方）：px=480，人位于灯杆正下方。光线竖直向下，与地面交点即人脚底，影子长度收缩为0。影长标签显示"影长 l=0"。这是"先变短"的终点。
- 中间状态（val>65，人走过路灯）：px>480，影子出现在人右侧（远离路灯方向）。随滑块继续右移，影子逐渐变长。例如val=85(px=582)时，影长≈37；此阶段演示"后变长"。
- 最终状态（val=100）：人在B点(px=660)。影子从(660,360)到(726,360)，影长≈66。影长标签显示"影长 l≈66"。对比初始状态，B点影长短于A点，但趋势是"先变短后变长"。

教师可随时拖动滑块到任意位置观察，也可点击「显示辅助线」按钮，在灯杆与人头顶之间添加水平/竖直虚线，为讲解相似三角形（△灯泡-灯杆底部-影子顶端 ∽ △灯泡-人头顶-影子顶端）做铺垫。

[标签冲突检查]
所有标签预计坐标及冲突检查：
- "路灯"：(500, 85)
- "灯高 H"：(495, 230)
- "人高 h"：(px+20, 325) — 动态，px∈[140,660]，故x∈[160,680]
- "影长 l=xx"：(mx, 345) — 动态，mx=(px+sx)/2。px=140时mx≈77；px=660时mx≈693；px=480时mx=480
- "A"：(140, 380)
- "B"：(660, 380)
- "小亮位置"：(80, 470)
- "百分比"：(570, 470)
- "显示辅助线"按钮文字：(685, 468)

逐对检查（间距<20px视为冲突）：
1. "路灯"(500,85) 与 "灯高H"(495,230)：y差145px → 无冲突
2. "灯高H"(495,230) 与 动态标签（最低y=325）：y差95px → 无冲突
3. "A"(140,380) 与 "影长"(77,345)：距离√(63²+35²)≈72px → 无冲突
4. "B"(660,380) 与 "影长"(693,345)：距离√(33²+35²)≈48px → 无冲突
5. "人高h"(160~680,325) 与 "影长"(77~693,345)：
   - px=480时：人高(500,325)，影长(480,345)，距离√(20²+20²)≈28px → 无冲突
   - px=660时：人高(680,325)，影长(693,345)，距离√(13²+20²)≈24px → 无冲突
   - px=140时：人高(160,325)，影长(77,345)，距离√(83²+20²)≈85px → 无冲突
6. 控件区标签（y=468~470）与主图区最低标签（y=380）：y差≥88px → 无冲突
7. 滑块"百分比"(570,470) 与 按钮文字(685,468)：x差115px → 无冲突

结论：所有标签间距均≥20px，无重叠冲突。

[交互方案]
- 交互类型：连续滑块 + 双状态切换按钮
- 控件说明：
  1. 滑块（范围0–100）：位于底部y=465，轨道x=150~550。拖动时人水平移动、光线实时重绘、影子长度连续更新、影长数值标签同步刷新。滑块thumb为绿色圆点，轨道已滑过段为绿色进度条。
  2. 「显示辅助线」按钮：位于底部右侧(620,450)，宽130高35。点击切换辅助线（水平虚线+竖直虚线）的显示/隐藏。初始状态为隐藏。
- 教师操作流程：
  1. 教师将滑块置于0（A点），让学生观察此时影长最长；
  2. 教师缓慢向右拖动滑块，引导学生观察影子逐渐变短；
  3. 当滑块到达约65%（路灯正下方），强调影长为0的关键瞬间；
  4. 继续向右拖动，引导学生观察影子重新变长；
  5. 到达100%（B点），总结规律"先变短后变长"；
  6. 点击「显示辅助线」，展示水平/竖直虚线，为后续用相似三角形定量计算影长做铺垫。

[技术实现]
- JS库选择：原生SVG（场景为简单几何图形与线段，SVG的line/circle/rect/text元素可直接操作，无需引入外部库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  路灯标签(500,85)                                 |
  |       ●灯泡(480,100)                              |
  |       | 灯杆                                      |
  |       |         人高h(px+20,325)                  |
  |       |         ┌───┐ 人头                        |
  |       |         │   │ 身体                        |
  |       |         └───┘                             |
  |       |                                           |
  |  A    |                    影长l(mx,345)          |
  +-------+--------------------===--------------------+ 地面线 y=360
  |  (140,380)                                        |
  |                                                   |
  |  [位置] [====滑块轨道====] [65%]  [显示辅助线]    | 控件区 y=440~490
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：仅两个状态变量——`val`（滑块值0~100）和`showAux`（布尔值，辅助线显示状态）。无复杂状态机。
  2. 坐标计算：在滑块input事件中，按公式实时计算px、sx、mx、cx，更新所有SVG元素的x/x1/x2/cx/cy属性。避免使用CSS transform，直接操作SVG属性以保证精确像素控制。
  3. 影长数值：计算L=Math.abs(sx-px)，取整后更新影长标签文本。当L<1时显示"l=0"。
  4. 辅助线切换：通过修改辅助线元素的`display`属性（'none'/'inline'）实现，避免重绘开销。
  5. 动画曲线：滑块原生拖动即为连续变化，无需额外动画曲线。若需平滑过渡，可在input事件中直接响应（原生浏览器滑块已具备连续触发能力）。
  6. 事件绑定：滑块`input`事件绑定更新函数；按钮`click`事件切换`showAux`状态并更新辅助线显示。
  7. 人移动时，身体矩形通过setAttribute('x', px-12)更新，头部圆通过setAttribute('cx', px)更新，确保与人脚底同步。
  8. 光线线段更新：setAttribute('x2', sx)；影子线段更新：setAttribute('x1', px), setAttribute('x2', sx)。
- ID命名规范：所有交互元素及需JS操作的SVG元素ID必须以`scene1-`为前缀。例如：
  - 地面线：scene1-ground
  - 灯杆：scene1-lamp-pole
  - 灯泡：scene1-lamp-bulb
  - 人身体：scene1-person-body
  - 人头：scene1-person-head
  - 光线：scene1-light-ray
  - 影子：scene1-shadow
  - 影长标签：scene1-shadow-label
  - 人高标签：scene1-height-label
  - 辅助线水平：scene1-aux-h
  - 辅助线竖直：scene1-aux-v
  - 滑块：scene1-slider
  - 辅助线按钮：scene1-aux-btn
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免全局变量污染，确保多场景合并时互不干扰。
