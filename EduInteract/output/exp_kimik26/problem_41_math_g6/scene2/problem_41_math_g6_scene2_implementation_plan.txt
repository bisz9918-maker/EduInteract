[图示主题与整合说明]
- 本图示主题：利用相似三角形解释路灯下影长变化规律
- 整合的步骤/概念：实物抽象为几何图形 → 光线与影子构造 → 相似三角形识别与标注 → 比例关系与公式推导 → 变化趋势分析与结论
- 教学价值：教师通过分步导航，从生活场景逐步抽象出数学模型，帮助学生理解"为什么影子先变短后变长"的几何本质，强化相似三角形的应用意识

[分步序列]
- 步骤0（初始状态）：显示地面线、灯杆PO、人RQ、直角符号（O点和Q点）、点标签P/O/Q/R。呈现题目基础几何抽象，等待教师讲解。
- 步骤1：点击「下一步」→ 添加光线PS（蓝色斜线，从灯泡P经过人顶R到地面影子顶端S），添加影子QS（红色粗线），添加S点标签，高亮两个直角三角形（△POS蓝色填充15%，△RQS红色填充15%）。教师可讲解光线传播与影子形成。
- 步骤2：点击「下一步」→ 添加辅助线RT（灰色虚线，从人顶R水平到灯杆T），添加T点标签，添加长度标注H（灯杆右侧）、h（人右侧）、d（地面OQ段下方）、l（地面QS段下方）。教师可讲解两个三角形的边长对应关系。
- 步骤3：点击「下一步」→ 添加相似符号∽（绿色，位于两三角形之间），在右侧显示比例式 "H : (d+l) = h : l"。教师可讲解相似三角形对应边成比例。
- 步骤4（最终步骤）：点击「下一步」→ 在右侧显示推导公式 "l = h·d / (H−h)"，显示分析文字"靠近路灯：d↓ → l↓"和"远离路灯：d↑ → l↑"，显示绿色结论"结论：先变短后变长"。教师可总结影长变化规律，回扣题目选项C。
- 教师可随时点击「上一步」回退复习任意步骤。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  1. 「◀ 上一步」按钮：位于控件区左侧，中心坐标(300,470)，宽100px高30px。点击后回退到上一步骤，隐藏当前步骤新增元素。
  2. 「下一步 ▶」按钮：位于控件区右侧，中心坐标(500,470)，宽100px高30px。点击后进入下一步骤，显示对应新元素。
  3. 步骤指示器：位于两按钮上方，(400,445)，显示当前步骤编号如"步骤 1/5"。
- 教师操作流程：
  1. 教师加载图示，步骤0显示基础几何图，向学生提问影子如何变化。
  2. 点击「下一步」进入步骤1，讲解光线与影子构造。
  3. 继续点击「下一步」依次展示辅助线、边长标注、相似关系、比例式、公式推导和最终结论。
  4. 讲解过程中可随时点击「上一步」回退，强化关键几何关系。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript（无需额外库）。理由：本场景为静态几何图形分步显示，无复杂动画、函数绘图或3D需求，原生SVG性能最优且依赖最少。
- 画布尺寸：800 × 500 px（固定画布，SVG viewBox="0 0 800 500"）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |                                                  |
  |     P(灯泡)                                      |
  |     |                                            |
  |     | H                                          |
  |     |        R(人顶)                             |
  |     |        | h                                 |
  |     |        |                                   |
  |     T--------+                                   |
  |     |        |        Q(人底)                    |
  |     |        |        |                          |
  |     O---d----+---l----S          [右侧公式区]    |
  |    (灯底)   (影子顶)      比例式/公式/结论        |
  |                                                  |
  |        [◀ 上一步]  步骤 1/5  [下一步 ▶]          |
  +--------------------------------------------------+
  画布 800×500，控件栏在 y=440~490（SVG内底部）
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 currentStep（0~4），每次点击按钮时更新状态，调用 renderStep() 函数根据当前步骤控制各元素的显示/隐藏。
  2. 显示/隐藏控制：为每个步骤依赖的元素组分配 data-step 属性或独立ID，通过添加/移除 CSS 类名（如 .scene2-hidden { display: none; }）实现切换。禁止直接操作 style.display，确保可维护性。
  3. 坐标计算：光线PS必须经过R点。验证共线：P(560,120)、R(340,240)、S(120,360) 斜率均为 -6/11，确保几何正确性。
  4. 动画曲线：本场景为分步切换，无需复杂动画。步骤切换时直接显示/隐藏元素，过渡时间为0，保证教学节奏由教师掌控。
  5. 事件绑定：为「上一步」「下一步」按钮绑定 click 事件，同时更新步骤指示器文本和按钮禁用状态（步骤0时禁用「上一步」，步骤4时禁用「下一步」）。
  6. 按钮样式：使用 CSS 美化按钮（圆角、悬停效果），确保与教学图示风格协调。
- ID命名规范：所有交互元素ID必须以 scene2- 为前缀。例如：scene2-ground、scene2-pole、scene2-light-ray、scene2-triangle-pos、scene2-label-p、scene2-btn-prev、scene2-btn-next 等。JS中使用 document.getElementById 获取元素，禁止 querySelectorAll 配合全局 class，避免多场景合并时跨场景污染。
- IIFE隔离：所有JavaScript代码必须包裹在 (function() { ... })() 立即执行函数表达式中，确保变量不污染全局作用域。
