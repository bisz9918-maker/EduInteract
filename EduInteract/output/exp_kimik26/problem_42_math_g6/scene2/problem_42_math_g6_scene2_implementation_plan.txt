[图示主题与整合说明]
- 本图示主题：由三视图推断正方体个数的"俯视图标高法"
- 整合的步骤/概念：俯视图底面布局 → 主视图列高约束 → 左视图行高约束 → 行列交叉定各位置高度 → 关键位置(行1,列1)的推理 → 求和得总数
- 教学价值：教师通过分步导航，引导学生理解"俯视图定地基、主/左视图定高度上限、交叉取值得实际高度"的完整逻辑链，尤其突出(行1,列1)这一关键格子的推理过程

[技术实现]
- JS库选择：原生SVG（场景为静态几何图形与文本，无需复杂图表库，原生SVG即可精确控制每个元素）
- 画布尺寸：800×500px（SVG viewBox="0 0 800 500"）
- 布局草图：
  ```
  +--------------------------------------------------+
  |                                                  |
  |     ≤2      ≤1      ≤1     [列约束区，y≈105]      |
  |       |       |       |                          |
  |     第1列   第2列   第3列   [列号区，y≈145]       |
  |       |       |       |                          |
  |  ≤2---+-------+-------+-------+                  |
  |       | ■■■■■ | ■■■■■ | ■■■■■ |  [行1，y=160~240] |
  |第1行  | ■■■■■ | ■■■■■ | ■■■■■ |                  |
  |  ≤1---+-------+-------+-------+                  |
  |       | ■■■■■ |       |       |  [行2，y=240~320] |
  |第2行  | ■■■■■ |       |       |                  |
  |       +-------+-------+-------+                  |
  |            [推理提示区，x=550起]                  |
  |                                                  |
  |           2+1+1+1=  5   [算式区，y≈370]          |
  |              答案：B                             |
  |                                                  |
  |  [上一步]    步骤 X/5    [下一步]  [控件栏y=450]  |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：变量 `currentStep` 取值0~4。每个步骤对应一组SVG `<g>` 元素，初始 `display="none"`。步骤切换时，遍历所有带 `data-step` 属性的元素，若 `data-step <= currentStep` 则显示，否则隐藏。
  2. 分组结构：
     - `<g id="scene2-group-0">`：网格、填充、行列号（始终显示）
     - `<g id="scene2-group-1" data-step="1">`：列约束+列指示线
     - `<g id="scene2-group-2" data-step="2">`：行约束+行指示线
     - `<g id="scene2-group-3" data-step="3">`：格子数字+关键格外框+推理提示
     - `<g id="scene2-group-4" data-step="4">`：求和算式+答案
  3. 按钮事件：上一步 `currentStep--`，下一步 `currentStep++`，边界值钳制。更新后调用 `updateVisibility()` 和 `updateButtons()`。
  4. 动画：无需复杂动画，直接切换display即可；如需柔和过渡，可在CSS中设置 `transition: opacity 0.3s`。
  5. 推理提示文字换行：使用SVG `<foreignObject>` 嵌入HTML `<div>`，设置宽度220px，自动换行；或使用多个 `<tspan>` 手动分行。推荐foreignObject方案，便于中文排版。
- ID命名规范：所有交互元素ID必须以 `scene2-` 为前缀。例如：`scene2-grid`、`scene2-group-1`、`scene2-btn-prev`、`scene2-btn-next`、`scene2-text-step`。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免多场景合并时的全局变量污染。
