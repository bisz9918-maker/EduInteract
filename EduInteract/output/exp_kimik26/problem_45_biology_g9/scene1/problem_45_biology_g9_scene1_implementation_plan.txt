[图示主题与整合说明]
- 本图示主题：血液流经不同器官的血管类型与血液性质变化对比
- 整合的步骤/概念：题目原图框架 → 选项A（心脏）双路径分析 → 选项B（肺）肺循环分析 → 选项C（小肠）体循环分析 → 选项D（组织细胞）体循环分析 → 三条规律总结
- 教学价值：教师通过分步导航，逐一验证四个选项，直观对比动脉血/静脉血在不同器官中的变化，最终归纳体循环、肺循环和心脏的特殊规律。固定原图始终保留在顶部，便于学生随时对照题目。

[分步序列]
- 初始状态（步骤0）：显示固定原图（a→b→c框架、箭头、标签）+ 动态区显示"题目原图"标题与四个选项文本（A/B/C/D）。教师可先让学生回顾题目。
- 步骤1：点击「下一步」→ 动态区切换为心脏四腔简图。显示两条并行路径：上方蓝色静脉血路径（腔静脉→RA→RV→肺动脉c），下方红色动脉血路径（肺静脉→LA→LV→主动脉c）。高亮提示"c血管性质取决于具体心腔"。教师讲解心脏作为特殊器官，流出血管性质由流入心腔决定。
- 步骤2：点击「下一步」→ 动态区切换为肺循环图。a肺动脉（蓝色，静脉血）流入肺泡毛细血管，c肺静脉（红色，动脉血）流出。在c旁标注红色"×"，表示选项B错误。教师讲解肺循环中静脉血变动脉血。
- 步骤3：点击「下一步」→ 动态区切换为小肠循环图。a肠动脉（红色，动脉血）流入小肠绒毛毛细血管，c肠静脉（蓝色，静脉血）流出。在c旁标注红色"×"，表示选项C错误。教师讲解体循环中组织器官消耗氧气，动脉血变静脉血。
- 步骤4：点击「下一步」→ 动态区切换为组织细胞循环图。a小动脉（红色，动脉血）流入组织毛细血管，c小静脉（蓝色，静脉血）流出。在c旁标注绿色"√"，表示选项D正确。教师再次确认体循环规律。
- 步骤5：点击「下一步」→ 动态区切换为总结页，列出三条规律：①体循环动脉血→静脉血；②肺循环静脉血→动脉血；③心脏流出性质取决于流入心腔。教师带领学生归纳记忆。
- 教师可随时点击「上一步」回退到任意步骤复习对比。

[交互方案]
- 交互类型：分步按钮导航（◀ 上一步 / 下一步 ▶）
- 控件说明：
  1. 「◀ 上一步」按钮：位于底部(300,455)，宽90×高30。点击后回退到上一步骤，步骤0时禁用。
  2. 「下一步 ▶」按钮：位于底部(410,455)，宽90×高30。点击后前进到下一步，步骤5时禁用（或变为不可点击）。
  3. 步骤指示器：位于底部(400,490)，显示"步骤 X / 6"，随导航实时更新。
- 教师操作流程：
  1. 课堂开始，图示停留在步骤0，教师让学生观察原图并读题。
  2. 教师点击「下一步」进入步骤1，结合心脏四腔图讲解选项A为何不确定。
  3. 依次点击「下一步」进入步骤2~4，每步对比动脉血/静脉血颜色变化，引导学生判断对错。
  4. 进入步骤5总结规律，教师可点击「上一步」多次回退到步骤2/3/4，强化体循环与肺循环的区别。

[技术实现]
- JS库选择：原生 SVG + 原生 JavaScript。理由：本场景以几何图形（线段、矩形、圆、椭圆、路径）和文本为主，无复杂函数图或3D，原生SVG足以高效实现，且无需引入外部库，减少加载依赖。

- 关键实现要点：
  1. 状态机设计：维护变量 `currentStep`（0~5）。`updateScene()` 函数负责：① 遍历所有步骤 `<g>` 节点，仅当前步骤 `display: block`，其余 `display: none`；② 更新按钮 `disabled` 状态（步骤0禁用上一步，步骤5禁用下一步）；③ 更新指示器文本。
  2. 分组管理：固定原图元素放入 `<g id="scene1-fixed-group">`；每个步骤的动态元素分别放入 `<g id="scene1-step0-group">` ~ `<g id="scene1-step5-group">`，通过 CSS `display` 控制显隐。
  3. 坐标计算：所有坐标已在布局坐标表中精确到像素，代码 agent 直接复用。血管粗线使用 `stroke-width` 实现；颜色变化通过 `stroke` / `fill` 属性直接赋值。
  4. 动画曲线：本场景为静态分步切换，无需 CSS 动画或 JS 动画库。若需增强体验，可在步骤切换时给当前显示的 `<g>` 添加 150ms 的 `opacity` 淡入（可选，计划内不强制）。
  5. 事件绑定：在 IIFE 内通过 `document.getElementById('scene1-btn-prev').addEventListener('click', ...)` 和 `next` 按钮绑定点击事件。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀。例如：
  - SVG 容器：`scene1-svg`
  - 固定原图组：`scene1-fixed-group`
  - 步骤组：`scene1-step0-group` ~ `scene1-step5-group`
  - 按钮：`scene1-btn-prev`、`scene1-btn-next`
  - 指示器：`scene1-step-indicator`
  - 内部元素：`scene1-vessel-a`、`scene1-organ-b`、`scene1-step1-ra`、`scene1-step2-lung-left` 等
- IIFE 隔离：所有 JavaScript 代码包裹在 `(function() { ... })();` 中，避免多场景合并时变量污染全局作用域。
