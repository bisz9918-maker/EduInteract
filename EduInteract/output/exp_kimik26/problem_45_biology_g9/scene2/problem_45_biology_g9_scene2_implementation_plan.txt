[图示主题与整合说明]
- 本图示主题：血液与器官间物质交换的微观机制
- 整合的步骤/概念：体循环中的物质交换（以组织细胞为例）、肺循环中的气体交换（以肺泡为例）、血液性质变化的根本原因
- 教学价值：教师通过两种状态的并列切换，引导学生观察"体循环出静脉血、肺循环出动脉血"的本质原因——物质交换方向与气体浓度差决定血液颜色变化。配合动态分子流动，建立宏观循环与微观交换的联系。

[交互方案]
- 交互类型：多状态切换（2个状态按钮）
- 控件说明：
  1. 「体循环交换」按钮：位置(240, 22)，尺寸150×36。点击后切换到状态1，展示血液与组织细胞的物质交换。
  2. 「肺循环交换」按钮：位置(410, 22)，尺寸150×36。点击后切换到状态2，展示血液与肺泡的气体交换。
- 教师操作流程：
  1. 页面加载后默认显示状态1（体循环），教师讲解："血液从左端流入，富含氧气和营养，经过组织细胞时，氧气和营养进入细胞，同时带走二氧化碳和废物，血液变成静脉血从右端流出。"
  2. 教师点击「肺循环交换」按钮，图示切换为状态2，讲解："在肺部则相反，静脉血流入，二氧化碳排出到肺泡，同时吸收氧气，变成动脉血流出。"
  3. 教师可反复点击两个按钮，让学生对比两种循环中物质交换方向的差异，理解"为何体循环出静脉血、肺循环出动脉血"。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript + CSS动画。原因：本场景为简单几何图形（线段、圆、多边形、文本）和显隐切换，无需复杂数据绑定或3D渲染，原生SVG性能最优；分子流动用CSS @keyframes实现，轻量且流畅。
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  [体循环交换]    [肺循环交换]         <- 顶部按钮  |
  |                                                  |
  |       ◯ ◯          <- 肺泡（状态2）              |
  |  静脉血 → [====血球====] → 动脉血   <- 状态2      |
  |       ↑ ↓          <- 交换箭头（状态2）           |
  |                                                  |
  |  动脉血 → [====血球====] → 静脉血   <- 状态1      |
  |       ↓ ↑          <- 交换箭头（状态1）           |
  |      ▭▭▭▭          <- 组织细胞（状态1）           |
  |                                                  |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 `currentState` 记录当前状态（'systemic' 或 'pulmonary'）。点击按钮时，若目标状态与当前不同，则执行切换。
  2. 切换逻辑：通过给SVG内各组元素（g标签）添加/移除CSS类 `.scene2-hidden`（display: none）控制显隐。血球颜色通过切换CSS类（如 `.scene2-oxygenated` / `.scene2-deoxygenated`）改变fill属性。
  3. 分子动画：每条箭头上放置3个circle元素，使用CSS变量 `--dx`、`--dy` 控制流动方向，animation 为 2s linear infinite，通过 animation-delay（0s / 0.7s / 1.4s）错开，形成连续流动感。状态切换时，隐藏旧状态的分子组，显示新状态的分子组，动画自动播放。
  4. 左右血液标签：使用同一个text元素，切换状态时通过 JS 修改 `textContent`。
  5. 按钮选中态：切换时移除两个按钮的选中类，再给当前按钮添加选中类（改变fill和stroke）。
  6. 坐标计算：所有坐标为绝对像素值，直接写入SVG属性，无需动态计算。
- ID命名规范：所有交互元素ID必须以 `scene2-` 为前缀。例如：
  - 体循环按钮：`scene2-btn-systemic`
  - 肺循环按钮：`scene2-btn-pulmonary`
  - 组织细胞组：`scene2-organ-cells`
  - 肺泡组：`scene2-alveoli`
  - 血球1：`scene2-rbc-1`
  - O₂箭头（状态1）：`scene2-arrow-o2-sys`
  - O₂分子组（状态1）：`scene2-molecules-o2-sys`
  - 左侧血液标签：`scene2-label-left-blood`
  - 右侧血液标签：`scene2-label-right-blood`
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })()` 中，避免全局命名空间污染，确保多场景合并时互不干扰。
- 容器结构：外层div固定宽高800×500，内部嵌入SVG（viewBox="0 0 800 500"）。状态按钮作为SVG内部的foreignObject或SVG rect+text元素实现，保持单文件SVG+JS结构。
