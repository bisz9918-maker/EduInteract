[图示主题与整合说明]
- 本图示主题：真核细胞基因(DNA双链片段)的结构识别、化学键辨析与碱基比例推导
- 整合的步骤/概念：
  1. 题目原图还原（DNA双链平面图、碱基序列、标记①②）；
  2. 磷酸二酯键(①处)与氢键的位置对比及酶作用位点辨析（解旋酶 vs DNA聚合酶/限制酶）；
  3. 碱基互补配对原则可视化（C≡G三条氢键、A=T两条氢键）；
  4. 由双链C占30%推导G、A、T比例；
  5. 证明双链与单链的(C+G)/(A+T)均为3∶2，确认选项B正确。
- 教学价值：教师通过分步导航控制讲解节奏，从结构识别→概念辨析→定量推导层层递进，可随时回退强调磷酸二酯键与氢键的空间位置差异，以及单双链比例关系的推导逻辑。

- 新增：上链C(左1)与T(左2)之间的磷酸二酯键高亮（红色粗线，覆盖骨架段x=112~138,y=80，线宽6px，带光晕）

- 教师操作：引导学生观察①处是什么化学键，对比磷酸二酯键（同一链上相邻核苷酸之间）与氢键（双链互补碱基之间）的空间位置差异

- 保持步骤1的所有高亮和面板

- 新增：结论文字"解旋酶作用于氢键，不作用于① → 选项A错误"显示在左侧面板底部（y=395）
- 教师操作：明确三种酶的作用位点，得出选项A错误

步骤3——碱基比例计算：
- 隐藏：左侧面板、步骤1-2的酶标签和结论文字、磷酸二酯键红色高亮
- 恢复：氢键为普通蓝色虚线（取消高亮）
- 新增：右侧面板显示"碱基互补配对与比例"，顶部红色文字"已知：C = 30%"
- 新增：比例条依次展开——C条(72px)、G条(72px)、A条(48px)、T条(48px)，右侧标注百分比
- 动画：比例条从宽度0px以300ms ease-out展开至目标宽度
- 教师操作：引导学生根据C=G、A=T推导各碱基比例

步骤4——双链比例验证：
- 保持右侧面板
- 更新：标题变为"双链比例验证"
- 新增：C条与G条合并为高条(144px,y=315)，A条与T条合并为高条(96px,y=350)，半透明覆盖原条

- 教师操作：直观展示双链中(C+G)与(A+T)的长度比为3∶2

步骤5——单链推导与结论：
- 保持右侧面板
- 更新：标题变为"单链推导"
- 新增：公式面板显示三行推导——

  第2行："∵ C₂=G₁, G₂=C₁, A₂=T₁, T₂=A₁"

[技术实现]
- JS库选择：原生SVG + 原生JavaScript（无外部库）。原因：本场景以静态几何图形、文字标签和简单显隐切换为主，无需复杂动画或数据驱动绘图，原生SVG性能最优且零依赖。
- 画布尺寸：800 × 500 px（固定画布，SVG viewBox="0 0 800 500"）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------------+
  |  ①                                                     |
  |  5'-C-T-G-C- - - - - - -C-T-T-A-3'    (上链)           |
  |     | | | |             | | | |                        |
  |     ≡ = ≡ ≡             ≡ = = =     (氢键)             |
  |     | | | |             | | | |                        |
  |  3'-G-A-C-G- - - - - - -G-A-A-T-5'    (下链)           |
  |       ②→                                               |
  |                                                        |
  |  +--------------------+  +------------------------+    |
  |  | 左侧面板(步骤1-2)  |  | 右侧面板(步骤3-5)      |    |
  |  | 化学键放大对比图   |  | 碱基比例条/推导公式    |    |
  |  +--------------------+  +------------------------+    |
  |                                                        |
  |       [◀ 上一步]        [下一步 ▶]                     |
  |              步骤 1 / 6                                |
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `let currentStep = 0;`（范围0~5），每次点击按钮时更新状态并调用 `renderStep()`。
  2. 元素分组：将每步新增/高亮的元素用 `<g id="scene1-step-N-xxx">` 分组，通过设置 `display: none/block` 或 `visibility: hidden/visible` 控制显隐。
  3. 坐标计算：所有坐标硬编码于SVG属性中，无需动态计算；仅比例条动画需JS动态修改 `width` 属性。
  4. 动画曲线：比例条展开使用 `requestAnimationFrame` + `easeOutQuad`（t*(2-t)），时长300ms。
  5. 事件绑定：按钮使用 `addEventListener('click', ...)`，在IIFE内部绑定，避免全局污染。
  6. 高亮实现：磷酸二酯键高亮使用红色粗线覆盖原骨架；氢键高亮使用更粗的蓝色虚线（stroke-width从2px增至3px）并添加 `filter="url(#glow-blue)"`。
  7. 步骤0初始化：页面加载时调用 `renderStep(0)`，仅显示DNA主图元素，隐藏所有面板和辅助标签。
- ID命名规范：所有交互元素ID必须以 `scene1-` 为前缀。示例：
  - `scene1-dna-upper-backbone`
  - `scene1-base-upper-1`
  - `scene1-mark-1-circle`
  - `scene1-panel-left`
  - `scene1-phosphodiester-highlight`
  - `scene1-btn-prev`
  - `scene1-btn-next`
  - `scene1-step-1-group`（步骤1所有新增元素的父组）
  - JS中获取元素严格使用 `document.getElementById('scene1-xxx')`，禁止使用 `querySelectorAll` 配合全局class。
- IIFE隔离：所有JavaScript代码包裹在立即执行函数表达式中：
  ```javascript
  (function() {
    'use strict';
    // 状态变量
    // DOM引用
    // render函数
    // 事件绑定
  })();
  ```
