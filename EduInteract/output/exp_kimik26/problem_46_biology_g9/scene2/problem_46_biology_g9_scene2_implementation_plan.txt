[图示主题与整合说明]
- 本图示主题：DNA 半保留复制中的同位素标记传递与单碱基突变传递规律
- 整合的步骤/概念：
  1. ¹⁵N 标记 DNA 在 ¹⁴N 培养液中连续复制 3 次的链来源与分子类型统计（选项 D 分析）
  2. 单链 T→A 突变后在复制中的传递比例推导（选项 C 分析）
  3. 同位素掺入（物理改变）与序列突变（化学改变）在复制中传递规律的差异对比
- 教学价值：教师通过分步导航，逐步展开复制过程，在关键步骤（复制 3 次后统计、突变 n 次推导）停留强调，帮助学生理解"含 ¹⁴N"与"只含 ¹⁴N"的措辞差异，以及突变链作为模板时突变信息必然传递 1/2 的规律。

[分步序列]
步骤 0（初始状态）：

步骤 1（复制 1 次）：

步骤 2（复制 2 次）：

- 右侧统计更新："复制 2 次后"；总 DNA=4；杂合 DNA=2；全轻 DNA=2；含 ¹⁴N=4；比例=100%。

步骤 3（复制 3 次）：
- 新增元素：第3代上行 4 个 DNA 在 y=303（x=30/140/250/360）；第3代下行 4 个 DNA 在 y=333（x=30/140/250/360）；其中 DNA1、DNA3 为杂合，其余 6 个为全轻；连接线从第2代分叉到第3代（每代 2 个 DNA 垂直向下连到上行和下行各 1 个）。
- 右侧统计更新："复制 3 次后"；总 DNA=8；杂合 DNA=2；全轻 DNA=6；含 ¹⁴N=8；比例=100%。

- 图例：红条+"¹⁵N 链"、蓝条+"¹⁴N 链"。

步骤 4（突变场景初始）：
- 场景切换：清空左侧所有同位素 DNA 与连接线；标题变为"单碱基突变的复制传递"。
- 显示元素：第0代全重 DNA（上链红/下链红）在 (185, 83)；上链约 1/3 处（x=215）有紫色突变圆（半径 8px，opacity 0.3）；标签"突变位点"在 (215, 58)、"T→A"在 (215, 72)、"原始（突变）"在 (230, 118)。
- 右侧统计更新："突变初始状态"；"突变类型：T→A"；"位置：①处后"；"状态：单链突变"。

步骤 5（突变复制 1 次）：
- 新增元素：第1代 2 个 DNA 在 (100, 153) 和 (270, 153)；DNA1 为突变 DNA（上链含突变圆在 x=145，下链蓝）；DNA2 为正常 DNA（上蓝下蓝）；连接线从第0代分叉到第1代。
- 右侧统计更新："突变 DNA 复制 1 次"；总 DNA=2；突变 DNA=1；正常 DNA=1；比例=1/2。

步骤 6（突变复制 2 次）：
- 新增元素：第2代 4 个 DNA 在 y=223（x=30/140/250/360）；DNA1、DNA2 为突变 DNA（上链含突变圆在 x=75、x=185，下链蓝）；DNA3、DNA4 为正常 DNA（上蓝下蓝）；连接线从第1代分叉到第2代。
- 右侧统计更新："突变 DNA 复制 2 次"；总 DNA=4；突变 DNA=2；正常 DNA=2；比例=2/4 = 1/2。

步骤 7（推导 n 次）：
- 无新增 DNA 元素，保持第0代~第2代显示。
- 右侧统计更新："复制 n 次推导"；总 DNA=2ⁿ；突变 DNA=2ⁿ⁻¹；正常 DNA=2ⁿ⁻¹；突变比例=2ⁿ⁻¹/2ⁿ = 1/2。
- 高亮结论（红色加粗）："发生改变的基因占 1/2，而非 1/4"；"→ 选项 C 错误"。

  2. 「下一步 ▶」按钮：位置 (530, 458)，宽 90×28。点击前进到下一步，步骤 7 时禁用。

- 教师操作流程：

  6. 在步骤 7 停留，展示 n 次复制的通用公式，强调突变基因占 1/2 而非 1/4，指出选项 C 错误。
  7. 可随时点击「上一步」回退复习。

[技术实现]
- JS 库选择：原生 SVG（通过 JavaScript 操作 DOM 显示/隐藏元素）。理由：本场景以静态几何图形（矩形、线段、圆形、文本）为主，无复杂函数绘图或 3D，原生 SVG 足够且轻量。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------------+
  |                      [标题区]                            |
  |  DNA 半保留复制（同位素标记）                             |
  +------------------------------+---------------------------+
  |                              |                           |
  |   [DNA 过程图区]              |   [统计与结论面板]         |
  |                              |                           |
  |    第0代 DNA                  |   +-------------------+   |
  |       |                      |   | 复制 3 次后统计    |   |
  |    第1代 DNA  DNA            |   | 总 DNA：8         |   |
  |       |        |             |   | 杂合 DNA：2       |   |
  |    第2代 DNA DNA DNA DNA     |   | 全轻 DNA：6       |   |
  |       |   |    |   |         |   | 含 ¹⁴N：8         |   |
  |    第3代 DNA... (8个)        |   | 比例：100%        |   |
  |    上行 / 下行               |   | → 选项 D 错误      |   |
  |                              |   +-------------------+   |
  |                              |                           |
  +------------------------------+---------------------------+
  |        [控件栏：y=440~490]                               |
  |   [◀ 上一步]   场景：同位素标记   [下一步 ▶]              |
  |              步骤 3 / 7                                  |
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：定义全局变量 `currentStep`（0~7）。每步用一个配置对象描述应显示的元素 ID 列表和统计面板文本内容。
  2. 元素显示/隐藏：所有 SVG 元素默认 `display: none`（或 `visibility: hidden`），根据 `currentStep` 切换为 `display: block`。使用 CSS transition: opacity 0.3s 实现淡入效果。
  3. 场景切换：步骤 3→4 时，隐藏所有同位素场景元素（class="scene2-isotope"），显示突变场景元素（class="scene2-mutant"）。
  4. 坐标计算：所有 DNA 链、连接线坐标硬编码在 SVG 中，按布局坐标表精确实现。
  5. 统计面板更新：每步切换时，通过 `textContent` 更新统计面板内的文本节点。
  6. 按钮状态：步骤 0 时禁用「上一步」，步骤 7 时禁用「下一步」，通过添加/移除 `disabled` class 实现样式变化。
  7. 事件绑定：按钮绑定 `click` 事件，更新 `currentStep` 后调用 `renderStep()` 重绘。
- ID 命名规范：所有交互元素 ID 必须以 `scene2-` 为前缀。示例：
  - DNA 元素：`scene2-dna-gen0-top`、`scene2-dna-gen1-1-top`、`scene2-dna-gen3-up-4-bottom`
  - 连接线：`scene2-link-g0-g1`、`scene2-link-g1-g2-left`
  - 统计文本：`scene2-stat-title`、`scene2-stat-line1`
  - 按钮：`scene2-btn-prev`、`scene2-btn-next`
  - 容器组：`scene2-group-isotope`、`scene2-group-mutant`
- IIFE 隔离：所有 JavaScript 代码包裹在 `(function() { ... })();` 中，避免全局变量污染，确保多场景合并时互不干扰。
- 数学公式显示：使用 Unicode 上标（如 ¹⁵N、¹⁴N、2ⁿ、2ⁿ⁻¹）直接嵌入 SVG `<text>` 元素，无需引入 MathJax。
