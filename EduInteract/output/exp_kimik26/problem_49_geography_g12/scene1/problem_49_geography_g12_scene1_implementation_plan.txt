[图示主题与整合说明]
- 本图示主题：南极点俯视图中的晨昏线、日期分界线与太阳直射点定位
- 整合的步骤/概念：①南极俯视基础（顺时针自转方向）；②70°S纬线与晨昏线切点M；③阴影区与日期分界线（0时经线120°W、180°经线）；④太阳直射纬度推导（20°S）；⑤太阳直射经线推导（60°E）；⑥标注直射点
- 教学价值：教师可使用分步导航，按“空间定向→切点与纬线→日期分界→直射纬度→直射经线→最终坐标”的认知递进讲解，随时回退复习关键推导环节。

[分步序列]
- 步骤0（初始状态/原图条件）：显示南极点O、经线网（7条）、外框半圆、晨昏线MA（蓝色）、阴影扇形（淡红）、点A/M/B、基础标签（O、A、M、B、70°）。教师可在此步让学生读图，识别已知条件。
- 步骤1（自转方向）：新增顺时针自转箭头（O点右侧小弧线）及"顺时针"标签。强化南极俯视"顺时针为东"的空间定向。教师讲解地球自转方向。
- 步骤2（切点与纬线）：新增70°S灰色虚线圆弧（过M点，半径90px）、"晨昏线与70°S相切"标签、右侧"90° - 70° = 20°"推导式。教师讲解切点含义及纬度互余关系。
- 步骤3（日期分界线）：新增0时经线（120°W，红色高亮）和180°经线（红色高亮）覆盖层，阴影区加深，"0时经线"与"180°经线"标签，扇形内弧线箭头及"旧的一天"标签。教师讲解日期分界线的判定。
- 步骤4（直射纬度）：新增"太阳直射 20°S"（右侧）和"南极附近极昼"（左侧阴影区旁）。教师讲解由切点纬度推导直射纬度，并确认南半球极昼。
- 步骤5（直射经线与坐标）：新增M附近"0时"标签、O点右下方60°E虚线及"12时经线(60°E)"标签、右侧绿色五角星及"太阳直射点 (20°S, 60°E)"标签。教师讲解0时经线与12时经线相对关系，得出最终直射点坐标。
- 教师可随时点击「上一步」回退，点击「下一步」前进，步骤指示器实时显示当前步骤编号。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「上一步」按钮：位于控件栏左侧(280,460)，尺寸80×30，点击回退到上一分步，隐藏当前步新增元素，显示前一步元素。
  2. 「下一步」按钮：位于控件栏右侧(440,460)，尺寸80×30，点击前进到下一分步，显示下一步新增元素。
  3. 步骤指示器：位于两按钮之间(400,475)，显示"步骤 X/5"，随当前步骤实时更新。
- 教师操作流程：
  1. 加载后处于步骤0，展示题目原图基础条件，教师引导学生读图。
  2. 点击「下一步」进入步骤1，出现顺时针箭头，教师讲解南极俯视自转方向。
  3. 继续点击「下一步」依次进入步骤2~5，每步出现新的推导要素（纬线、日期分界线、直射纬度、直射经线与坐标）。
  4. 讲解中如需回退复习，点击「上一步」即可返回。
  5. 步骤5为最终结论页，展示太阳直射点完整坐标。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：本场景为静态几何图形与分步显隐，无复杂动画或数据可视化，原生SVG足以精确控制各元素坐标与样式，无需引入外部库。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |     B  阴影区        90°W        A               |
  |      \  /\          |          /                 |
  |       \/  \         |         /                  |
  |        M   \        |        /                   |
  |         \   \       |       /                    |
  |          \   \      |      /                     |
  |           \   \     |     /                      |
  |            \   \    |    /                       |
  |             \   \   |   /                        |
  |              \   \  |  /                         |
  |               \   \ | /                          |
  |                \   \|/                           |
  |                 \  O  70°                        |
  |                  \ | /                           |
  |                   \|/                            |
  |              [右侧标注区]                        |
  |                                                  |
  |  [◀上一步]   步骤 X/5   [下一步▶]               |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 `currentStep`（0~5）记录当前步骤。初始化 `currentStep = 0`。
  2. 元素分组：每步新增元素用独立的 `<g id="scene1-step-X">` 包裹（X=1~5）。步骤0的基础元素放在 `<g id="scene1-step-0">` 或不包裹（始终显示）。
  3. 显隐控制：切换步骤时，遍历所有步骤组，仅显示 `id <= currentStep` 的组（或仅显示当前步新增组，视教学设计而定）。本设计采用“累积显示”模式：步骤N显示所有0~N的元素，回退时隐藏>N的元素。
  4. 坐标计算：
     - 经线终点用三角函数计算：x = 350 + R*cos(θ), y = 380 - R*sin(θ)，θ从0°到180°，间隔30°。
     - M点位于120°W、距O 90px：θ=120°，d=90。
     - A点位于30°W、距O 220px：θ=30°，d=220。
     - B点位于150°W、距O 220px：θ=150°，d=220。
     - 阴影扇形path使用A命令画弧：从120°W终点(230,172)到180°终点(110,380)，大弧标志为0（60°<180°）。
  5. 动画曲线：分步切换不使用过渡动画，直接显隐（或可选0.2s淡入淡出，通过CSS transition控制opacity）。建议直接显隐以保持教学节奏清晰。
  6. 事件绑定：为「上一步」「下一步」按钮绑定click事件，更新`currentStep`后调用`renderStep()`函数，该函数控制各g组的`display`属性（或`visibility`）。
  7. 按钮状态：当`currentStep===0`时禁用「上一步」；当`currentStep===5`时禁用「下一步」。
- ID命名规范：所有SVG元素及控件的ID必须以`scene1-`为前缀。例如：`scene1-point-o`、`scene1-line-ma`、`scene1-step-3`、`scene1-btn-prev`、`scene1-btn-next`、`scene1-step-indicator`。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免多场景合并时的全局变量污染。
- 颜色/样式严格沿用spec配色：背景#ffffff、经线#000000、晨昏线#1565c0、70°S虚线#888888、阴影/日期分界线#c62828、直射点#2e7d32、文字#000000。
