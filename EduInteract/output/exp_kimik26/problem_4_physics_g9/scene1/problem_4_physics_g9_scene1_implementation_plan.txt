[图示主题与整合说明]
- 本图示主题：电路连接方式分析与选项验证（初中物理·九年级·电路）
- 整合的步骤/概念：
  1. 原电路结构识别（开关断开，识别元件与连接关系）
  2. 短路路径分析（S闭合，电流经D→b→B→M直接回负极，验证选项A正确、B错误）
  3. 串联电路验证（去掉导线b，电流依次经过L₂→L₁，验证选项C正确）
  4. 并联电路验证（导线M从B改接A，电流分两支在A点汇合，验证选项D正确）
- 教学价值：教师通过分步导航，按"原电路→短路→串联→并联"的逻辑递进讲解，可随时前进或回退，配合课堂讲解节奏。电流路径的动态高亮与箭头动画直观展示电流走向，帮助学生理解短路、串联、并联的本质区别。

[分步序列]
- 初始状态（步骤0）：原电路结构识别
  - 显示所有元件（电源、开关S断开、L₁、L₂）和全部导线（黑色实线）
  - 开关闸刀呈断开姿态（倾斜向上）
  - 两灯泡填充浅灰色（不发光）
  - 无电流路径高亮
  - 状态提示框内容："步骤0：原电路\n开关S断开。请识别电路中的电源、开关、灯泡及导线连接关系。"
  - 步骤描述："原电路：开关S断开，识别电路元件与连接关系"

- 步骤1：短路分析（点击「下一步」）
  - 开关闸刀切换为闭合姿态（水平）
  - 红色高亮短路路径：正极→D→导线b→B→M→S→负极
    - 高亮段1：正极导线(180,100)→(540,140)
    - 高亮段2：导线b(540,140)→(540,320)
    - 高亮段3：M导线(540,320)→(130,340)
    - 高亮段4：开关到负极(130,340)→(80,340)→(80,100)→(60,100)
  - 红色箭头沿路径循环流动动画（duration=2s，linear，infinite）
  - 灯泡L₁、L₂保持浅灰填充，旁边显示"无电流通过"
  - 状态提示框内容："步骤1：短路分析\nS闭合后，电流经D→b→B→M直接回到负极，不经过任何灯泡，电路发生短路。\n✓ 选项A正确（发生短路）\n✗ 选项B错误（L₁、L₂不亮）"
  - 步骤描述："S闭合后发生短路，L₁、L₂被短路不亮"

- 步骤2：串联验证（点击「下一步」）
  - 开关保持闭合
  - 导线b变为灰色虚线（表示已去掉）
  - 红色短路路径消失
  - 绿色高亮串联电流路径：正极→D→L₂→C→导线a→A→L₁→B→M→S→负极
    - 高亮段1：正极导线(180,100)→(540,140)
    - 高亮段2：经过L₂（从D到C，沿灯泡上边缘内侧示意）
    - 高亮段3：导线a(460,140)→(460,320)
    - 高亮段4：经过L₁（从A到B，沿灯泡下边缘内侧示意）
    - 高亮段5：M导线(540,320)→(130,340)
    - 高亮段6：开关到负极(130,340)→(80,340)→(80,100)→(60,100)
  - 绿色箭头沿路径循环流动动画
  - 灯泡L₁、L₂切换为浅黄填充（发光状态）
  - "无电流通过"标注消失
  - 状态提示框内容："步骤2：串联验证\n去掉导线b后，电流只有一条路径，依次经过L₂和L₁，两灯串联。\n✓ 选项C正确（去掉导线b后L₁、L₂串联）"
  - 步骤描述："去掉导线b后，电流依次经过L₂、L₁，两灯串联发光"

- 步骤3：并联验证（点击「下一步」）
  - 开关保持闭合
  - 导线b恢复黑色实线
  - M导线（连B）变为灰色虚线，表示原连接已改接
  - M导线（连A）显示为黑色实线
  - 绿色串联路径消失
  - 蓝色高亮两条并联支路：
    - 支路1（L₁支路）：正极→D→b→B→L₁→A→M→S→负极
      - 高亮：正极导线→D→导线b→B→经过L₁→A→M导线→S→负极
    - 支路2（L₂支路）：正极→D→L₂→C→a→A→M→S→负极
      - 高亮：正极导线→D→经过L₂→C→导线a→A→M导线→S→负极
  - 两条支路分别用蓝色箭头动画（可错开相位，如支路1延迟0.5s）
  - 在A点旁标注"汇合点"
  - 灯泡L₁、L₂保持浅黄填充（发光状态）
  - 状态提示框内容："步骤3：并联验证\n导线M从B改接到A后，电流分两条支路：\n① 经L₁回A\n② 经L₂→C→a回A\n两条支路在A点汇合。\n✓ 选项D正确（L₁、L₂并联）"
  - 步骤描述："M改接A后，电流分两支在A点汇合，L₁、L₂并联发光"

- 教师可随时点击「上一步」回退到任意步骤复习

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  1. 「◀ 上一步」按钮：位置(280,455)，宽90×高35，点击后退到上一状态（步骤0时禁用）
  2. 「下一步 ▶」按钮：位置(430,455)，宽90×高35，点击前进到下一状态（步骤3时禁用）
  3. 步骤指示器：两按钮之间，显示"步骤 X/4"
- 教师操作流程：
  1. 教师展示步骤0，让学生观察原电路结构，识别各元件和接线柱
  2. 点击「下一步」进入步骤1，讲解短路概念：电流优先走无电阻路径，两灯被短路不亮，验证A正确、B错误
  3. 点击「下一步」进入步骤2，讲解串联：去掉导线b后电流只有一条路径，依次经过两灯，验证C正确
  4. 点击「下一步」进入步骤3，讲解并联：M改接A后电流分两支在A点汇合，验证D正确
  5. 讲解过程中可随时点击「上一步」回退，强化学生理解

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：电路图为简单几何图形（线段、圆、矩形、折线），无需复杂图表库；原生SVG配合JS状态机即可实现分步切换和路径高亮动画。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------------+
  |  电源(+/-)                              L₂(C   D)       |  y=80~170
  |    |                                      |  b  |       |
  |    |                                      |     |       |
  |   S(断开/闭合)    M------------------------A  L₁  B       |  y=300~360
  |                                            a            |
  |                                                         |
  |  [状态提示框: 当前分析]                                  |  y=120~360
  |  [步骤描述文字]                                         |  y=420~440
  |       [◀ 上一步]  步骤 X/4  [下一步 ▶]                  |  y=455~490
  +--------------------------------------------------------+
  ```

- 关键实现要点：
  1. **状态机设计**：定义全局变量 `currentStep`（0~3），每次点击按钮时更新状态，调用 `renderStep()` 函数根据当前状态显示/隐藏/修改元素。
  2. **元素分层管理**：
     - 底层：静态电路元件（电源、开关底座、灯泡轮廓、常态导线）
     - 中层：动态导线（M导线连A/连B、导线b实线/虚线）
     - 上层：电流路径高亮（红/绿/蓝线段，带arrow marker）
     - 顶层：标签文字、状态提示、按钮
  3. **电流路径动画**：使用SVG的`<animate>`元素或CSS `@keyframes`实现`stroke-dashoffset`循环动画，dasharray设为路径长度的1/3，offset从0到路径长度循环，duration=2s，营造流动效果。
  4. **开关状态切换**：步骤0显示断开闸刀（线段倾斜），步骤1~3显示闭合闸刀（线段水平），通过切换两个SVG线段的`display`属性实现。
  5. **灯泡发光状态**：通过切换圆形填充色和透明度实现（浅灰#e0e0e0 opacity0.2 ↔ 浅黄#fff9c4 opacity0.3）。
  6. **导线b状态**：步骤2时切换为灰色虚线，其他步骤为黑色实线。
  7. **M导线改接**：步骤3时显示连A的M导线（黑色实线）和连B的M导线（灰色虚线），其他步骤只显示连B的M导线（黑色实线）。
  8. **事件绑定**：按钮点击事件更新currentStep并重新渲染，同时更新按钮禁用状态（步骤0禁用「上一步」，步骤3禁用「下一步」）。

- **ID命名规范**：所有交互元素ID必须以 `scene1-` 为前缀：
  - 元件：`scene1-power`, `scene1-switch`, `scene1-lamp-l1`, `scene1-lamp-l2`
  - 导线：`scene1-wire-m-b`, `scene1-wire-m-a`, `scene1-wire-a`, `scene1-wire-b`, `scene1-wire-pos`, `scene1-wire-neg`
  - 路径高亮：`scene1-path-short`, `scene1-path-series`, `scene1-path-parallel-1`, `scene1-path-parallel-2`
  - 标签：`scene1-label-s`, `scene1-label-l1`, `scene1-label-l2`, 等
  - 按钮：`scene1-btn-prev`, `scene1-btn-next`
  - 提示框：`scene1-info-box`, `scene1-info-text`
  - JS中严格使用 `document.getElementById()` 获取元素，禁止用 `querySelectorAll` 配合全局class。

- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免全局变量污染，确保多场景合并时互不干扰。
