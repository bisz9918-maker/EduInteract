[图示主题与整合说明]
- 本图示主题：太阳直射点经度推算与北京时间、新一天范围计算
- 整合的步骤/概念：
  1) 在冬至日侧视光照图上叠加经线网格，建立空间基准；
  2) 以0°经线为夜半球中央经线（子夜线），判读其地方时为0:00；
  3) 依据太阳直射经线与夜半球中央经线经度差180°，推算180°经线地方时为12:00；
  4) 书写太阳直射点完整地理坐标P(23°26′S, 180°)；
  5) 利用东加西减原则，计算120°E的区时（北京时间8:00）；
  6) 以0:00经线（0°）和180°日期变更线为界，划分全球日期范围；
  7) 得出新一天占全球1/2的结论。
- 教学价值：教师可通过分步导航，逐步揭示"夜半球中央经线→太阳直射经线→所求经线区时→日期范围"的完整推理链，确保学生跟上经度转换逻辑。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「上一步」按钮：位于(280,450)，宽80×高30。点击后回退一个步骤，隐藏当前步骤新增的元素，恢复上一步状态。
  2. 「下一步」按钮：位于(440,450)，宽80×高30。点击后前进一步，按序列显示对应元素。
  3. 步骤指示器：位于(360,485)，显示"步骤 X / 7"，随按钮点击同步更新。
- 教师操作流程：
  1. 教师展示步骤0，说明图示为冬至日侧视光照图（北极圈极夜，太阳直射南回归线），引导学生观察经线网格；
  2. 点击「下一步」进入步骤1，强调0°经线恰好位于夜半球正中央，地方时为0:00（子夜线）；
  3. 点击「下一步」进入步骤2，引导学生推算：太阳直射经线（12:00）与0:00经线相差180°，故为180°经线；
  4. 点击「下一步」进入步骤3，在180°经线与南回归线交点标出直射点，书写完整坐标；
  5. 点击「下一步」进入步骤4，计算120°E区时：0:00 + 8h = 8:00，标注北京时间；
  6. 点击「下一步」进入步骤5，在底部建立日期范围条，建立0:00经线与180°日期变更线的空间对应；
  7. 点击「下一步」进入步骤6，填充新一天（0°向东至180°）与旧一天范围，得出占比1/2的结论。
  教师可随时点击「上一步」回退，复习某一步的推理逻辑。

[技术实现]
- JS库选择：原生 SVG + 原生 JavaScript。理由：本场景以静态几何图形、路径填充、线条高亮和分步显隐为主，无需复杂数学计算或3D渲染，原生SVG性能最优且可控性最高。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图（ASCII）：
  ```
  0      100    200    280    350    420    500         700    800
  +------+------+------+------+------+------+-----------+------+
  |      |      |      |      |      |      | 右侧信息   |      |  y=50
  |      |  ~夜半球~  |      | ~昼半球~ |      |  面板      |      |
  |      |      |0°    |      |      |180°  |  步骤1-4   |      |  y=140
  |      |      |      | 地轴 |      |      |  文字说明  |      |  y=220
  |      |      |      |      |      |  P点  |            |      |  y=286
  |      |      |      |      |      |      |            |      |  y=370
  |      +------日期范围条(步骤5-6)------------------------+      |  y=405
  |      0°0:00        新一天1/2        180°日期变更线           |  y=435
  |           [◀上一步]    步骤X/7    [下一步▶]                 |  y=450
  +-------------------------------------------------------------+  y=500
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `let currentStep = 0;`（范围0~6）。每次点击按钮时更新 `currentStep`，调用 `renderStep()` 函数，根据步骤值设置各元素的 `display` 或 `visibility` 属性。
  2. 经线高亮实现：每条高亮经线（0°、180°、120°E）单独绘制 `<line>` 元素，初始 `display: none`，步骤触发时设为 `display: block` 并置于淡灰网格上层（SVG绘制顺序靠后即可）。
  3. 180°经线虚线样式：使用 SVG `stroke-dasharray="8,4"` 实现虚线效果。
  4. 夜半球填充：使用 `<path>` 绘制弓形。路径命令：从晨昏线左交点(154.8,292.6)沿圆弧（大弧，经过北极方向）到右交点(405.2,167.4)，再沿直线回到左交点。使用 `A` 命令绘制圆弧，半径140。
  5. 日期条新一天/旧一天填充：使用两个 `<rect>` 元素，步骤6时设置 `fill-opacity` 动画（CSS transition 0.3s）。
  6. 动画曲线：所有显隐过渡使用 CSS `transition: opacity 0.3s ease`，初始 `opacity: 0`，步骤触发时 `opacity: 1`。
  7. 事件绑定：按钮使用 `onclick` 绑定 `prevStep()` 和 `nextStep()` 函数，并在函数内做边界检查（currentStep ≤ 0 时禁用上一步，currentStep ≥ 6 时禁用下一步）。
- ID命名规范：所有交互元素ID必须以 `scene2-` 为前缀。例如：
  - `scene2-earth-circle`
  - `scene2-meridian-highlight-0`
  - `scene2-meridian-highlight-180`
  - `scene2-meridian-highlight-120e`
  - `scene2-p-dot`
  - `scene2-info-0`
  - `scene2-info-180`
  - `scene2-info-120e`
  - `scene2-date-bar-new`
  - `scene2-date-bar-old`
  - `scene2-btn-prev`
  - `scene2-btn-next`
  - `scene2-step-text`
  JS中严格使用 `document.getElementById` 获取元素，禁止全局 class 选择，避免多场景合并时跨场景污染。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，变量不泄露全局作用域。
