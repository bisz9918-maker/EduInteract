[图示主题与整合说明]
- 本图示主题：地转偏向力与自转线速度的纬度规律对比
- 整合的步骤/概念：
  1) 建立 A（北极点 90°N）、B（北极圈 66°34′N）、C（南回归线 23°26′S）三点的空间位置与纬度数值认知；
  2) 推导地转偏向力纬度规律（北半球右偏、南半球左偏、赤道无偏转），对比三点相对大小；
  3) 推导自转线速度纬度规律（赤道最大、两极最小为零），对比三点相对大小；
  4) 分别得出"地转偏向力最小的是 C"与"自转线速度最快的是 C"两个结论。
- 教学价值：教师通过分步导航，先让学生定位三点纬度，再分别呈现两种地球自转规律的示意与定量对比柱状图，最后汇总结论，递进关系清晰，便于课堂逐步引导。

[分步序列]
- 步骤0（初始状态）：显示地球圆、地轴、赤道、北极圈、南回归线（虚线）；显示夜半球阴影（左侧半圆淡灰）；显示A、B、C三点彩色圆点及点名标签A/B/C；显示"地轴""赤道""北极圈""南回归线"文字标注；右侧对比区留白。教师可在此步讲解晨昏线与三点大致位置。
- 步骤1（纬度定位）：在步骤0基础上，新增A(90°N)、B(66°34′N)、C(23°26′S)纬度数值标注（淡入动画，duration 300ms）；右侧上栏出现"纬度位置对比"柱状图（A柱高90px红色、B柱高66.5px蓝色、C柱高23.5px绿色，带X轴A/B/C标签）。教师可在此步确认三点的精确纬度。
- 步骤2（地转偏向力规律）：右侧上栏标题变为"地转偏向力"；新增规律示意区——北半球水平基线+红色向右箭头标注"向右偏"，南半球水平基线+蓝色向左箭头标注"向左偏"，赤道标注"无偏转"（灰色）；新增地转偏向力柱状图（A柱高80px、B柱高50px、C柱高5px，对应最大/中等/最小）。左侧A、B点添加脉冲高亮圈（stroke=#c62828/#1565c0，r=10px，opacity 0.3，持续1s）。教师讲解"北右南左赤道无"规律。
- 步骤3（地转偏向力结论）：地转偏向力柱状图中C柱加粗描边（stroke=#2e7d32, stroke-width=2px）并短暂放大1.1倍后恢复；右侧上栏中央滑入结论文字"地转偏向力最小的是 C"（绿色粗体16px，slideIn from right 300ms）；其他规律示意适当淡化（opacity 0.4）。教师强调答案。
- 步骤4（自转线速度规律）：右侧下栏标题"自转线速度"出现；新增规律示意区——A点处红色极短横线（长度5px，表示≈0），B点处蓝色中等箭头（长度30px，切线方向水平），C点处绿色长箭头（长度50px，切线方向水平）；新增自转线速度柱状图（A柱高5px、B柱高50px、C柱高80px，对应0/中等/最大）。左侧C点添加脉冲高亮圈（stroke=#2e7d32，r=10px，opacity 0.3，持续1s）。教师讲解线速度由赤道向两极递减规律。
- 步骤5（自转线速度结论）：自转线速度柱状图中C柱加粗描边（stroke=#2e7d32, stroke-width=2px）并短暂放大1.1倍后恢复；右侧下栏中央滑入结论文字"自转线速度最快的是 C"（绿色粗体16px，slideIn from right 300ms）；其他规律示意适当淡化（opacity 0.4）。教师汇总结论，完成本scene讲解。
- 教师可随时点击「上一步」/「下一步」回退或前进，状态切换无动画冲突。

  7. 讲解过程中可随时点击「上一步」回退复习。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript（无外部库）。原因：本scene以几何图形、线段、柱状图、文字标签为主，SVG原生元素即可完整表达，无需引入D3/Three.js等重型库，保持代码轻量。
- 画布尺寸：800 × 500 px（固定viewBox="0 0 800 500"）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------------+
  |                                                        |
  |  +------------------+   +----------------------------+ |
  |  |    A ●           |   | 地转偏向力                 | |
  |  |  B ●      C ●    |   | [北右][南左][赤道无]  柱状图| |
  |  |  [夜半球]        |   |----------------------------| |
  |  |   地球圆         |   | 自转线速度                 | |
  |  |                  |   | [箭头示意]            柱状图| |
  |  +------------------+   +----------------------------+ |
  |                                                        |
  |         [◀ 上一步]  步骤 2/5  [下一步 ▶]               |
  +--------------------------------------------------------+
  [控件栏 y=440~490，主图区 y=0~430]
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `let currentStep = 0;` 控制当前步骤（范围0~5）。每一步对应一个SVG `<g id="scene3-step-X">` 组，组内包含该步所有新增/高亮元素。初始时仅 `step-0` 显示（display="block"），其余组 display="none"。
  2. 切换逻辑：`updateStep(newStep)` 函数先隐藏所有step组，再显示目标step组；同时更新步骤指示器文字。按钮绑定 `onclick` 事件，做边界检查（currentStep>0 才允许减，currentStep<5 才允许加）。
  3. 坐标计算：地球圆上A/B/C三点坐标通过三角函数精确计算（圆心180,240，半径126，地轴倾斜18.4°），确保B(96,146)对应北极圈66.5°N、C(306,251)对应南回归线23.5°S。赤道与纬线均通过方向向量旋转求得，保证几何一致性。
  4. 动画曲线：标签与柱状图出现使用CSS `transition: opacity 0.3s ease`；结论文字使用CSS `@keyframes slideInRight`（从translateX(20px)到0，opacity 0→1，duration 300ms）；点脉冲高亮使用CSS `@keyframes pulse`（scale 1→1.3→1，opacity 0.3→0，duration 1s）。
  5. 柱状图绘制：使用`<rect>`元素，通过计算`height`与`y`属性（y = 基线y - 高度）实现自下而上生长效果，可在CSS中添加`transition: height 0.4s ease`增强视觉。
  6. 事件绑定：按钮使用`document.getElementById('scene3-btn-prev')`与`scene3-btn-next`获取，绑定`addEventListener('click', ...)`。
  7. 所有视觉元素（包括按钮）均放在SVG内部或绝对定位覆盖层上，确保不撑高容器；控件栏背景使用SVG内`<rect y="440" width="800" height="60" fill="#f5f5f5"/>`实现。
- **ID命名规范**：所有交互元素与分组ID必须以 `scene3-` 为前缀。例如：`scene3-earth-circle`、`scene3-point-a`、`scene3-step-2`、`scene3-btn-prev`、`scene3-btn-next`、`scene3-conclusion-1`。JS中严格使用 `document.getElementById` 获取元素，禁止全局class选择，避免多场景合并时跨场景污染。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 立即执行函数中，内部变量与函数不暴露到全局作用域。
