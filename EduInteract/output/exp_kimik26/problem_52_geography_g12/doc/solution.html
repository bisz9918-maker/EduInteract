完整题目原文

图1-9中，北半球是东半球，南半球是西半球，回答下列问题：(10分）

(1) 写出A,B的经度数：A ，B 。
(2) 根据图中阴影（黑夜）位置，判断这一天的日期为 。
(3) 在北半球上，画出恰当的阴影（黑夜）部分。
(4) 当甲地是22日16点时，乙地是 月日时，C点昼长 小时。
(5) 此时，太阳直射的纬度是 ，该日北京（39°N, 116°E）的正午太阳高度是 。
(6) 此时，地球距太阳远近情况是 。

题目分析

本题是一道经典的地球光照图综合题，核心考查东西半球划分、晨昏线判读、地方时计算、正午太阳高度计算及地球公转位置判断。解题的关键突破口有三：

  1. 利用"北半球是东半球，南半球是西半球"及图中20°W标注，确定A、B的经度及图中各经线的经度值；
  2. 通过南半球阴影区与晨昏线的相对位置，判断极昼极夜范围，进而确定节气与日期；
  3. 在确定的经纬网框架下，完成地方时、昼长、正午太阳高度的定量计算。

整体讲解思路

建议按照"先定框架→再判日期→最后计算"的三段式逻辑展开：

  1. 先用东西半球划分图建立经度坐标系，让学生明确A、B及甲、乙、C的经度；
  2. 再通过晨昏线与极圈的切点关系判断6月22日（夏至），并在北半球补画阴影；
  3. 最后以经度差→时间差→昼长→正午太阳高度的链条完成定量推导。

初始

教学说明：晨昏线与日期判读

本图示的核心是让学生从"看图"过渡到"读图"——即通过阴影区的边界形态判断节气。教师应引导学生关注以下观察要点：

  1. 阴影区的范围：南半球斜线阴影覆盖了绝大部分区域，说明南半球以夜半球为主；关键是观察南极点（S）附近是否被阴影覆盖。
  2. 晨昏线与极圈的关系：图中晨昏线（阴影边界）与南极圈（66°34′S）相切，且南极圈以内全部为阴影区，即南极圈内出现极夜。
  3. 节气判定：南极圈极夜 ⇨ 太阳直射北回归线 ⇨ 6月22日（北半球夏至日）。
  4. 北半球阴影绘制：6月22日北极圈以内为极昼（不画阴影）；夜半球位于晨昏线西侧，教师需指导学生在北半球左侧（西侧）画出斜线阴影，但北极圈以内留白。

关键公式与结论

  • 极昼极夜判读：晨昏线与极圈相切 + 极圈内为阴影 ⇨ 该半球冬至/另一半球夏至
  • 日期：6月22日（夏至日）
  • 太阳直射点：23°26′N（北回归线）

步骤 1/5

教学说明：地方时、昼长与正午太阳高度综合计算

本图示覆盖第(4)(5)(6)三问，教师应引导学生建立"经度差→时间差→日期变更→昼长→太阳高度→公转位置"的完整计算链条。

第(4)问：地方时与昼长计算

  1. 确定经度：根据SCENE_1的经度框架，甲地位于140°W，乙地位于130°E，C点位于赤道（0°纬线）约70°E经线上。
  2. 计算经度差：140°W与130°E的短弧经度差为90°（向西方向），时间差为 90° ÷ 15°/h = 6小时。
  3. 判断东西：130°E位于140°W的西边90°（短弧向西），故乙地时间比甲地晚6小时。
  4. 计算乙地时间：16时 − 6小时 = 10时。向西计算不跨越国际日期变更线（180°），日期保持22日不变。故乙地为6月22日10时。
  5. C点昼长：C点位于赤道上，赤道全年昼夜平分，昼长为12小时。

第(5)问：太阳直射纬度与北京正午太阳高度

  1. 由SCENE_2已判定日期为6月22日（夏至），太阳直射23°26′N（北回归线）。
  2. 北京位于39°N，正午太阳高度角公式：

H = 90° − |φ − δ|
其中 φ = 39°N，δ = 23°26′N。

  1. 代入得：H = 90° − (39° − 23°26′) = 74°26′。

第(6)问：地球距太阳远近

  1. 6月22日靠近远日点（7月初），地球公转轨道上距离太阳较远。
  2. 结论：距太阳较远（或"处于远日点附近"）。

总结：完整解答与课堂讲解建议

完整解答

  1. A为 160°E，B为 160°W。
  2. 日期为 6月22日（夏至日）。
  3. 北半球阴影绘制要点：晨昏线与北极圈相切，北极圈以内为极昼（留白），晨昏线西侧（左侧）为夜半球（画斜线阴影）。
  4. 乙地为 6月22日10时；C点昼长为 12小时。
  5. 太阳直射 23°26′N；北京正午太阳高度为 74°26′。
  6. 地球距太阳 较远（处于远日点附近）。

课堂讲解建议

  1. 重视经度坐标系的建立：很多学生出错并非因为不会算时间，而是经度判断错误。建议用SCENE_1反复强化"20°W是东西半球分界线"这一空间概念，让学生亲手指出A、B应该在哪个方向。
  2. 光照图判读抓"切点+极点"：只要晨昏线与极圈相切，立刻联想到二至日；再看极圈内是阴影还是空白，即可秒判夏至或冬至。
  3. 时间计算强调"东西判断"：计算地方时时，务必先判断两地的东西相对位置（用短弧），再决定加减。本题130°E在140°W的西边（短弧向西90°），故用减法，这是易错点。
  4. 正午太阳高度公式要画图：H = 90° − |φ − δ| 中的绝对值符号容易让学生混淆加减。建议结合SCENE_3中的示意图，让学生看到"同半球相减、异半球相加"的几何意义。
  5. 公转位置建立时间轴记忆：让学生记住"1月初近日点、7月初远日点"，6月22日自然对应"较远"。
