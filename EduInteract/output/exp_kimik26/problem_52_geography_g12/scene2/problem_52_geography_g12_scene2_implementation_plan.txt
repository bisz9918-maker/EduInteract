[分步序列]
- 步骤0（初始状态）：显示南北半球轮廓、经线、赤道、基础标签（N,S,A,B,C,甲,乙,20°W,赤道,北极圈标签,南极圈标签）、南半球左侧斜线阴影、太阳直射光线。晨昏线、极圈线（除标签外）、结论卡片、北半球阴影均隐藏。
- 步骤1（晨昏线识别）：在步骤0基础上，南半球阴影右边界（三次贝塞尔曲线）高亮为#c62828粗线（3px），显示"晨昏线"标签(430,320)。教师讲解：阴影与白昼的边界即为晨昏线。
- 步骤2（极夜判断）：在步骤1基础上，显示南极圈虚线(360,402)-(440,402)，晨昏线保持红色粗线，在南半球切点(400,402)处显示红色高亮小圆（r=5px），显示"相切"标签(430,385)和"南极圈内极夜"标签(420,410)。教师讲解：晨昏线与南极圈相切，南极圈以内全部为阴影覆盖→极夜。
- 步骤3（日期确定）：在步骤2基础上，右侧弹出结论卡片(540,140,220,160)，内部自上而下显示："日期判读结论"（蓝）→"南极圈出现极夜"→"↓"→"太阳直射北回归线"→"↓"→"6月22日（夏至）"（绿，加粗）。教师讲解：南极圈极夜→太阳直射北回归线→夏至日。
- 步骤4（北半球补画）：在步骤3基础上（卡片可保留或淡化），北半球绘制晨昏线（红色粗线，三次贝塞尔曲线M320,220 C360,-36 440,-36 480,220），显示北极圈虚线(360,28)-(440,28)，北半球晨昏线西侧填充斜线阴影（夜半球），北极圈以上弓形区域填充#fff3e0浅黄（极昼），显示"晨昏线"(310,180)、"极昼"(400,38)、"夜半球"(340,125)、"昼半球"(460,125)标签。教师讲解：北半球对称处理，北极圈极昼，左侧夜半球阴影。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「◀ 上一步」按钮：位于SVG内(300,460)，宽100高28，蓝色圆角矩形，白色文字。点击回退到上一状态。
  2. 「下一步 ▶」按钮：位于SVG内(460,460)，宽100高28，蓝色圆角矩形，白色文字。点击前进到下一状态。
  3. 步骤指示器：位于(400,455)，显示"步骤 X/5"，灰色12px文字，居中。
- 教师操作流程：
  1. 加载后呈现步骤0（题目原图简化版），教师引导学生观察南半球阴影分布。
  2. 点击「下一步」进入步骤1，高亮晨昏线，教师提问：阴影与白昼的分界线是什么？
  3. 点击「下一步」进入步骤2，出现南极圈与切点，教师引导学生发现南极圈极夜现象。
  4. 点击「下一步」进入步骤3，弹出结论卡片，教师总结日期推导逻辑。
  5. 点击「下一步」进入步骤4，北半球补画完成，教师验证学生绘图并讲解极昼原理。
  6. 可随时点击「上一步」回退，重新观察关键特征。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：本场景以静态几何图形和分步显示/隐藏为主，无需复杂动画或数据驱动绘图，原生SVG性能最优且可控性最高。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------------+
  |                          N                             |  y=10~20
  |                     [北半球半圆]                        |  y=20~220
  |                    经线  乙  极昼                       |  
  |              夜半球 /   昼半球   \ A                    |  
  |    20°W    B(南)  C------------赤道--------A(北)       |  y=210~220
  |                     [南半球半圆]                        |  y=210~410
  |    甲    斜线阴影区    晨昏线    白昼                   |  
  |                          S                             |  y=410~425
  |  [太阳直射光线] <===========  结论卡片(步骤3)           |  右侧空白区
  |                                                        |  
  |              [◀ 上一步]  步骤 X/5  [下一步 ▶]           |  y=455~490
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `let currentStep = 0;` 控制5个状态（0-4）。每次点击按钮时更新状态，调用 `renderStep()` 函数根据状态设置各元素的 `display` 或 `visibility` 属性。
  2. 斜线阴影实现：使用SVG `<pattern>` 定义斜线图案（patternUnits="userSpaceOnUse", width=6, height=6, patternTransform="rotate(45)"），内部画一条对角线。阴影区域用 `<path>` 绘制闭合区域并填充该pattern。
  3. 北半球阴影区路径：需精确构造"晨昏线左侧+半圆边界"的闭合路径，并通过clipPath或叠加极昼区确保北极圈以内不被阴影覆盖。推荐做法：先画北半球阴影路径（整个夜半球），再在其上方叠加极昼弓形区域（fill:#fff3e0, opacity:0.4），利用层级关系自然覆盖。
  4. 晨昏线三次贝塞尔曲线：南半球 `M320,210 C360,460 440,460 480,210`；北半球 `M320,220 C360,-36 440,-36 480,220`。确保控制点坐标精确以实现与极圈的视觉相切。
  5. 切点高亮：步骤2在(400,402)处动态插入一个 `<circle>` 元素（r=5, fill:#c62828, stroke:#fff, stroke-width:2），并添加"相切"文字标签。
  6. 结论卡片：使用 `<g>` 包裹 `<rect>` 和多个 `<text>`，步骤3时设置 `display: block`，其他步骤 `display: none`。卡片内文字使用 `text-anchor="middle"` 居中。
  7. 动画曲线：分步切换无需平滑动画，直接显示/隐藏即可。若需柔和过渡，可对透明度使用CSS transition（0.2s ease）。
  8. 事件绑定：按钮使用 `onclick` 绑定 `prevStep()` 和 `nextStep()` 函数，内部做边界检查（currentStep >= 0 且 <= 4）。
- **ID 命名规范**：所有交互元素和可切换元素ID必须以 `scene2-` 为前缀。例如：
  - 南半球晨昏线：`scene2-terminator-south`
  - 北半球晨昏线：`scene2-terminator-north`
  - 结论卡片：`scene2-conclusion-card`
  - 上一步按钮：`scene2-btn-prev`
  - 下一步按钮：`scene2-btn-next`
  - 极夜标签：`scene2-label-polar-night`
  - 极昼标签：`scene2-label-polar-day`
  - 切点高亮圆：`scene2-tangent-dot`
  JS中严格使用 `document.getElementById('scene2-xxx')` 获取元素，禁止全局class选择，避免多场景合并时跨场景污染。
- IIFE 隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，状态变量和函数均为局部作用域。
