[图示主题与整合说明]
- 本图示主题：地方时、昼长与正午太阳高度综合计算
- 整合的步骤/概念：
  1) 甲乙两地经度差（甲140°W、乙130°E）与地方时换算；
  2) 赤道C点昼夜平分（昼长12小时）；
  3) 夏至日太阳直射北回归线（23°26′N）；
  4) 北京（39°N）正午太阳高度角推导 H = 74°26′；
  5) 6月22日地球在公转轨道上的位置及与远日点（7月初）的关系。
- 教学价值：教师可通过分步导航逐层展开四组独立计算，随时回退至学生薄弱步骤重复讲解；三栏并列布局使时间计算、太阳高度推导、公转位置三者可视对比，避免信息混杂。

[分步序列]
- 步骤0（初始状态）：显示三栏基础框架。左栏展示甲乙经度位置（甲140°W、乙130°E）及90°短弧向西标注；中栏显示地平面、铅垂线、北京39°N标签；右栏显示公转椭圆、太阳、6月22日地球点（蓝色）。其余元素隐藏。

- 步骤2（地方时结果）：点击「下一步」→ 左栏新增计算结果"16时 − 6时 = 10时"及绿色结论"乙地：6月22日 10时"。中栏、右栏保持不变。
- 步骤3（赤道昼长）：点击「下一步」→ 中栏下部新增赤道小圆（左半圆阴影）、"C点 赤道"标签及绿色"昼长 12 小时"。左栏、右栏保持步骤2状态。
- 步骤4（太阳直射点）：点击「下一步」→ 中栏上部新增红色太阳直射点圆点(360,180)及红色标签"23°26′N"。左栏、右栏保持。
- 步骤5（正午太阳高度）：点击「下一步」→ 中栏新增红色太阳光线（从直射点到北京）、角度弧线（74°）、"H=74°26′"标注，顶部公式卡片淡入显示完整推导公式，关键数值红色高亮。左栏、右栏保持。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「◀ 上一步」按钮：位于画布底部(280,455)，宽100×高32，点击回退至上一状态，隐藏当前步骤新增元素。
  2. 「下一步 ▶」按钮：位于画布底部(420,455)，宽100×高32，点击推进至下一状态，显示对应步骤新增元素。
  3. 步骤指示器：位于(400,38)，显示"步骤 X / 7"，随按钮点击同步更新。
- 教师操作流程：
  1. 教师加载图示，学生看到步骤0的基础条件（甲乙位置、北京标记、公转轨道）；
  2. 教师点击「下一步」进入步骤1，讲解经度差与时间换算关系；
  3. 继续点击推进，每步聚焦一组计算；若学生某步未理解，点击「上一步」回退重新讲解；
  4. 步骤6展示完整结论后，可快速回退至步骤3/5针对性复习昼长或太阳高度。

[技术实现]
- JS库选择：原生 SVG + 原生 JavaScript。理由：本场景以静态几何图形、文本标签和显隐控制为主，无需复杂图表库；原生SVG可精确控制每个元素的坐标、stroke、fill及CSS类切换。
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  主标题（居中）                                    |
  |  步骤指示器                                        |
  |  +----------------+----------------+----------------+ |
  |  | 左栏：地方时    | 中栏：正午太阳  | 右栏：公转轨道 | |
  |  |  计算           |  高度示意图    |                | |
  |  |                 |                |                | |
  |  |                 |                |                | |
  |  +----------------+----------------+----------------+ |
  |              [◀ 上一步]  [下一步 ▶]                 |
  +--------------------------------------------------+
  控件栏位于 y=440~490，按钮绝对定位叠在SVG上。
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `currentStep`（范围0~6），数组 `stepElements` 记录每步应显示/高亮的元素ID列表。点击按钮时更新 `currentStep`，遍历所有元素按所属步骤设置 `display` 或 `opacity`。
  2. 元素显隐：所有可能新增的元素初始 `display: none` 或 `opacity: 0`；进入对应步骤时切换为 `display: block` / `opacity: 1`，并添加200ms CSS transition实现淡入。
  3. 高亮切换：步骤6中6月22日地球点和远日点标记的颜色切换，通过更换CSS类（如 `.highlight-red`）实现。
  4. 公式卡片：使用 `<foreignObject>` 或SVG `<rect>` + `<text>` 实现；若用 `<foreignObject>` 可内嵌HTML实现更灵活的文本高亮，但为保证兼容性，建议纯SVG `<text>` 配合 `<tspan fill="#c62828">` 实现红色高亮。
  5. 角度弧线：使用SVG `<path>` 的A命令绘制，精确计算起点（水平向左30px偏移，即(370,320)）和终点（沿74°顺时针方向，约(408,291)）。
  6. 椭圆轨道：使用SVG `<ellipse cx="660" cy="260" rx="100" ry="70"/>`。
  7. 太阳位置计算：焦点偏移量 c = √(a²−b²) ≈ 71，故右焦点在 x = 660+71 = 731。
- ID命名规范：所有交互元素ID必须以 `scene3-` 为前缀。例如：
  - 左栏标题：`scene3-left-title`
  - 甲点：`scene3-point-jia`
  - 乙点：`scene3-point-yi`
  - 时间换算公式：`scene3-formula-step1`
  - 红色箭头：`scene3-arrow-west`
  - 结果文字：`scene3-result-time`
  - 赤道小圆：`scene3-equator-circle`
  - 昼长标注：`scene3-equator-hours`
  - 太阳直射点：`scene3-sunspot`
  - 直射点标签：`scene3-sunspot-label`
  - 太阳光线：`scene3-sunray`
  - 角度弧线：`scene3-angle-arc`
  - H标注：`scene3-h-label`
  - 公式卡片：`scene3-formula-card`
  - 公式文字：`scene3-formula-text`
  - 远日点标记：`scene3-aphelion-dot`
  - 远日点标签：`scene3-aphelion-label`
  - 6月22日地球点：`scene3-earth-jun22`
  - 远日点结论：`scene3-aphelion-conclusion`
  - 上一步按钮：`scene3-btn-prev`
  - 下一步按钮：`scene3-btn-next`
  - 步骤指示器：`scene3-step-indicator`
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })()` 中，避免多场景合并时全局变量污染。
