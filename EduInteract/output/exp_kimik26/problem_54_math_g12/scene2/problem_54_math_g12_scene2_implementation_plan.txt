[图示主题与整合说明]
- 本图示主题：长方体表面从顶点 A 到顶点 F 的最短路径问题（四种展开方案对比）
- 整合的步骤/概念：将四种表面展开方案（前面+右面、底面+右面、底面+后面、左面+后面）整合为分步导航序列；每步展示一种展开方式的平面直角坐标、勾股定理计算与结果；最后以 2×2 网格对比四种结果，突出最小值
- 教学价值：教师可逐步点击「下一步」，按逻辑顺序逐一讲解每种展开方案，随时回退复习；学生能直观看到为何最短距离为 10 cm，避免遗漏展开方案

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「上一步」按钮：位于 (310,455,80,30)，点击后回退到上一状态；在步骤0时禁用（opacity 0.4）
  2. 「下一步」按钮：位于 (410,455,80,30)，点击后进入下一状态；在步骤5时禁用或变为「重新开始」
  3. 步骤指示器：位于 (400,495)，显示当前步骤名称/编号，如「步骤 1 / 5」
- 教师操作流程：
  1. 页面加载后显示步骤0（题目条件），教师讲解长方体已知边长
  2. 点击「下一步」进入步骤1，讲解前面+右面展开，指出 A-F 直线为最短路径，计算得 10
  3. 继续点击「下一步」依次讲解步骤2、3、4，分别得到 √130、√106、10
  4. 进入步骤5，四种方案并列对比，绿色框突出最小值 10，给出最终答案
  5. 讲解中可随时点击「上一步」回退到任意步骤复习

[技术实现]
- JS 库选择：原生 SVG（所有图形均为基本几何形状与文本，SVG 的 group 显隐切换最适合分步导航；无需引入外部库）
- 画布尺寸：800 × 500 px（SVG viewBox="0 0 800 500"）
- 布局草图：
  ```
  [主图区 800×440]
    步骤0：中央斜二测长方体 + 四周标注
    步骤1~4：中央展开双矩形 + 尺寸标注 + 下方计算式
    步骤5：2×2 缩略图网格 + 底部最终答案
  [控件栏 800×50，y=440~490]
    [◀ 上一步] [下一步 ▶]
         步骤指示器
  ```
- 关键实现要点：
  1. 状态机：变量 `currentStep` 取值为 0~5；每个步骤对应一个 SVG `<g>` 分组（id="scene2-step-0" 到 "scene2-step-5"），初始仅 step-0 的 `display="block"`，其余 `display="none"`
  2. 切换逻辑：点击按钮时，隐藏当前分组，显示目标分组，更新 `currentStep`，同步更新步骤指示器文本与按钮禁用状态
  3. 坐标计算：所有矩形、点、标签坐标已在坐标表中精确给出，直接按像素值写入 SVG 属性；缩略图在步骤5中按比例缩放，保持与步骤1~4相同的相对比例
  4. 动画曲线：无需平滑动画，直接切换 display 属性即可，保证课堂讲解时响应即时
  5. 事件绑定：为「上一步」「下一步」按钮绑定 click 事件；所有逻辑封装在 IIFE 中
- ID 命名规范：
  - 步骤分组：`scene2-step-0` ~ `scene2-step-5`
  - 按钮：`scene2-btn-prev`、`scene2-btn-next`
  - 指示器：`scene2-step-indicator`
  - 内部元素（如路径线、计算式）均加前缀 `scene2-`，例如 `scene2-path-af`、`scene2-formula-1`
  - JS 中统一使用 `document.getElementById` 获取元素，禁止跨场景的全局 class 选择
- IIFE 隔离：所有 JavaScript 代码包裹在 `(function() { ... })();` 中，避免多场景合并时的变量污染
