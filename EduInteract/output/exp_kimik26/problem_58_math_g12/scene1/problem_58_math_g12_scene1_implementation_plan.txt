[分步序列]
- 初始状态（步骤0）：显示圆O、弦AB/AC/BC、点A/B/C/O、C点蓝色高亮（描边或填充色#1565c0）、∠ACB蓝色角度弧（带15%透明度扇形填充）、标签AB=4、∠ACB=37°、点标签O/A/B/C。推导面板显示"已知：AB = 4，∠ACB = 37°"。所有元素饱和度正常。
- 步骤1（圆周角定理）：点击「下一步」→ OA、OB以opacity从0到1淡入（0.3s）。∠ACB弧保持蓝色高亮。∠AOB红色角度弧淡入。标签∠AOB=74°在(325,210)淡入（红色）。推导面板追加红色文本"∠AOB = 2∠ACB = 74°"。非当前核心元素（C点、∠ACB弧、AB弦等）添加dimmed类（opacity降至0.4，或filter:saturate(0.3)）。
- 步骤2（垂径定理）：点击「下一步」→ OD（绿色）从O向D以绘制动画（stroke-dasharray技巧或逐帧延伸，0.4s）出现。D点(384,240)以绿色淡入。直角符号在D点左下象限淡入。等长标记AD/DB淡入。标签AD=2、DB=2分别于(404,279)、(404,201)淡入。推导面板追加绿色文本"OD ⊥ AB，AD = DB = 2"。前一步的OA、OB、∠AOB弧转为dimmed状态。
- 步骤3（直角三角形求解）：点击「下一步」→ Rt△AOD三边（OA、OD、AD）加粗或颜色变为绿色高亮。∠AOD绿色角度弧在O点右下方淡入。标签∠AOD=37°在(320,255)淡入（绿色）。推导面板追加绿色文本"在 Rt△AOD 中：sin37° = AD/OA = 2/r"。垂线OD、D点等转为dimmed状态。
- 步骤4（最终结果）：点击「下一步」→ 几何区无新元素，圆O可轻微脉冲高亮（可选）以暗示结论归属。推导面板追加黑色加粗文本"r = 2/sin37°"和"S = πr² = 4π/sin²37°"。所有先前几何元素保持dimmed可见，仅推导面板结论为最醒目状态。
- 回退规则：点击「上一步」时，反向隐藏当前步骤新增元素，恢复前一步的高亮状态，推导面板移除对应行。动画反向或瞬时切换均可，以流畅为准。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于(285,460)，宽110px高36px。点击后回退到前一步状态，隐藏当前步新增元素，恢复前一步高亮。
  - 「下一步 ▶」按钮：位于(405,460)，宽110px高36px。点击后前进到下一步状态，以淡入/绘制动画呈现新元素，旧元素降低饱和度。
- 教师操作流程：
  1. 教师展示初始图，讲解已知条件AB=4和圆周角∠ACB=37°。
  2. 点击「下一步」，引导学生发现圆心角与圆周角关系，强调∠AOB=74°。
  3. 点击「下一步」，引入垂径定理辅助线OD，说明AD=DB=2。
  4. 点击「下一步」，聚焦Rt△AOD，建立sin37°=2/r的方程。
  5. 点击「下一步」，得出半径和面积结论，完成推导。
  6. 可随时点击「上一步」回退，重新强调某一步的逻辑。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本场景为静态几何图形与分步显隐，无复杂函数绘图或3D，原生SVG足以精确控制每个几何元素和路径动画，且无需引入外部库，减少加载开销。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  +--------------------------------------------------------+
  |                                                        |
  |   几何图形区（0≤x≤520, 0≤y≤440）                        |
  |   +--------------------------------+  +---------------+|
  |   |      B(右上)                   |  |  推导面板     ||
  |   |       •                        |  |  （520~780）  ||
  |   |      /|                        |  |  逐步公式     ||
  |   |     / | \  圆O                 |  |  显示区       ||
  |   |  O •--•--• D                   |  |               ||
  |   |     \ | / A(右下)              |  |               ||
  |   |      \|/                       |  |               ||
  |   |       • C(底部)                |  |               ||
  |   +--------------------------------+  +---------------+|
  |                                                        |
  |        [◀ 上一步]    [下一步 ▶]                         |
  |        (底部控件区 y=440~490)                           |
  +--------------------------------------------------------+
- 关键实现要点：
  1. 状态机设计：使用变量 `let currentStep = 0;`（范围0~4）。定义 `stepElements` 数组，每个元素记录该步应显示/高亮的元素ID列表。切换步骤时，先给所有已出现元素添加 `.dimmed` 类（opacity:0.4, filter:saturate(0.3)），再给当前步元素移除 `.dimmed` 并添加 `.highlight` 类（对应蓝/红/绿颜色）。
  2. 坐标计算：圆上三点A、B、C基于圆心(280,240)和半径130px，使用三角函数预计算坐标（A: angle=37°, B: angle=-37°, C: angle=100°），确保几何关系准确。
  3. 动画曲线：新元素使用CSS `transition: opacity 0.3s ease, stroke-dashoffset 0.4s ease`。OD线段绘制动画使用stroke-dasharray（总长→0）实现。
  4. 事件绑定：按钮绑定click事件，内部判断 `if (currentStep < 4) { currentStep++; renderStep(); }`。`renderStep()` 函数统一处理所有显隐和样式切换。
  5. 推导面板文本：使用多个 `<text>` 元素预置在面板内，初始 `opacity:0`，每步到达时对应文本淡入。避免动态计算文本位置。
- ID命名规范：所有交互元素ID必须以 `scene1-` 为前缀。例如：
  - `scene1-circle-o`
  - `scene1-point-a`
  - `scene1-line-oa`
  - `scene1-line-od`
  - `scene1-angle-acb`
  - `scene1-angle-aob`
  - `scene1-angle-aod`
  - `scene1-label-ab`
  - `scene1-panel-step2`
  - `scene1-btn-prev`
  - `scene1-btn-next`
  JS中严格使用 `document.getElementById('scene1-xxx')` 获取元素，禁止全局class选择，避免多场景合并时跨场景污染。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，变量不泄露全局作用域。
