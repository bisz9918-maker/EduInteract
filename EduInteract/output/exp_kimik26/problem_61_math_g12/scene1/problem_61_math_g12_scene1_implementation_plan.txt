[图示主题与整合说明]
- 本图示主题：球体截面与平面ABC几何关系分析
- 整合的步骤/概念：
  1. 建立球体、球心O、球面上三点A/B/C的空间位置；
  2. 揭示平面ABC截球所得小圆（截面圆）；
  3. 引入球心O到平面ABC的垂距 d = 3√2/2；
  4. 计算截面圆半径 r = 3√2/2；
  5. 利用圆周角定理判定AC为截面圆直径，得AC = 3√2；
  6. 在等腰直角三角形ABC中求得BC = 3。
- 教学价值：教师通过分步导航，按“空间→截面→三角形”的认知递进顺序逐步揭示信息，避免一次性展示过多空间线条造成学生认知负荷。每步可暂停讲解，支持回退复习。

[分步序列]
- 步骤0（初始状态）：显示球体轮廓、球心O及标签、A/B/C三点及标签、AB与BC黑色实线、AC灰色虚线、球半径标注线及R=3标签、左侧已知条件文字“∠ABC=90°”(260,280)与“BA=BC”(260,320)。右侧推导文字均隐藏。截面小圆、平面、垂线、H点均隐藏。
- 步骤1（平面与截面）：点击「下一步」→ 新增平面ABC（浅蓝半透明椭圆填充）和截面小圆（灰色虚线椭圆）。说明A、B、C三点共面于截面小圆上。
- 步骤2（垂距）：点击「下一步」→ 新增垂线OH（蓝色虚线）及垂足H（黑点+标签），在OH右侧标注“d = OH = 3√2/2”。展示球心到平面的距离。
- 步骤3（截面圆半径）：点击「下一步」→ 高亮截面小圆（绿色描边+10%绿色填充），新增从H到椭圆右侧边缘的水平半径线及“r = 3√2/2”绿色标注，右侧显示推导公式“r = √(R²−d²) = 3√2/2”。
- 步骤4（直径与圆周角）：点击「下一步」→ 三角形ABC三边全部高亮为红色实线（AC由灰虚线变红实线），在B点绘制红色直角符号，B点左上方显示红色“∠ABC=90°”，AC中点附近上方标注红色“AC = 3√2”，右侧显示红色推导文字“AC为直径，AC = 2r = 3√2”。强调圆周角定理。
- 步骤5（边长结论）：点击「下一步」→ BC边高亮为绿色（加粗），在BC中点上方标注绿色“BC = 3”，AB与BC边上新增黑色等长标记（短线段），右侧显示绿色推导文字“BC = AC/√2 = 3”。得出关键结论。
- 教师可随时点击「◀ 上一步」回退至任意步骤复习。

- 教师操作流程：

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本场景为静态几何示意图，无复杂函数绘图或3D渲染，原生SVG足以精确控制椭圆、路径、虚线、填充透明度；原生JS避免引入不必要依赖，保证多场景合并时轻量且无污染。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  球体(圆)居中偏上                                  |
  |       O●                                         |
  |    /    \                                        |
  |   A      \    右侧推导文字区                        |
  |   |\      \   (步骤3/4/5公式)                      |
  |   | \      |                                     |
  |   B--C     |  截面小圆(椭圆)在下半部               |
  |       \    |                                     |
  |        \   |                                     |
  |         H--|                                     |
  |            |                                     |
  |  [◀ 上一步] [下一步 ▶]  步骤指示                   |
  +--------------------------------------------------+
  控件栏在 y=440~490（SVG内部绝对定位）
  ```
- 关键实现要点：
  1. 状态机设计：维护变量 `currentStep`（0~5）。每步用一个配置对象描述该步应显示的元素ID列表、各元素的目标样式（stroke、stroke-width、fill-opacity等）。`renderStep()` 函数根据当前步数遍历所有元素，设置 `display` 或 `visibility` 及样式属性。
  2. 坐标计算：A/B/C/H四点严格共椭圆关系：中心H(400,330)，长半轴130，短半轴48。A(316,367)、B(300,299)、C(484,293) 由参数角约130°、230°、310°取整得到，确保AC关于H中心对称（直径）。代码中硬编码坐标即可。
  3. 直角符号：通过向量计算绘制。取 BA = (16,68)，BC = (184,-6)，分别归一化后乘以8px得到P1、P2，再求P3 = P1 + 8·unit(BC) = P2 + 8·unit(BA)，绘制 path "M P1 L P3 L P2"。
  4. 等长标记：AB中点(308,333)，垂直方向单位向量(-0.973,0.229)，向两侧各延伸4px画线；BC中点(392,296)，垂直方向单位向量(0.033,0.999)，向两侧各延伸4px画线。
  5. 动画曲线：无位移动画，仅显隐切换（opacity或display）与颜色过渡（CSS transition 0.2s），保持教学图示的清晰与稳定。
  6. 事件绑定：上一步/下一步按钮绑定 `click` 事件，更新 `currentStep` 后调用 `renderStep()`。边界处理：currentStep<0时置0，>5时置5。
- ID命名规范：所有SVG元素及控件ID必须以 `scene1-` 为前缀。例如：`scene1-ball-outline`、`scene1-point-a`、`scene1-line-ab`、`scene1-btn-prev`、`scene1-step-text`。JS中严格使用 `document.getElementById` 获取，禁止全局class查询，避免多场景合并时跨场景污染。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，内部变量与函数不泄漏全局作用域。若需暴露接口，仅挂载到特定命名空间（如 `window.Scene1 = { init: ... }`）。
