[图示主题与整合说明]
- 本图示主题：四面体ABCD中过对棱中点E、F的动平面α截面性质综合分析
- 整合的步骤/概念：
  1) 四面体基础结构与中点标注；
  2) 动平面α与截面四边形EFGH的形成；
  3) 一般情形下GF、EH、BD三线共点；
  4) 特殊平行构型GF∥EH∥BD（否定①、肯定②）；
  5) G在线段BC上且H在AD延长线上的存在性演示（肯定③）；
  6) △EFG与△EFH同底等高、面积恒等（肯定④）。
- 教学价值：教师通过分步导航控制课堂节奏，从基础结构逐步过渡到四个结论的验证，每一步可回退重讲，适合空间几何的课堂推演。

[分步序列]
- 初始状态（步骤0）：展示四面体ABCD六条棱（AC虚线），标注顶点A/B/C/D，标注中点E（AB中点）、F（CD中点），中点用黑色圆点标记。无G/H/α。步骤提示"步骤0：四面体基础结构"。

- 步骤1：点击「下一步」→ 出现动平面α（半透明紫色填充四边形EFGH），G落在线段BC上(G₁=360,383)、H落在线段AD上(H₁=588,205)，连线EF（紫色虚线）、FG₁、G₁H₁、H₁E形成截面四边形。标注G、H。步骤提示"步骤1：截面四边形EFGH的形成"。

- 步骤2：点击「下一步」→ G移动到BC延长线C外侧(G₂=523,423)，H移动到AD延长线D外侧(H₂=733,310)。高亮GF₂（红色）、EH₂（蓝色）、BD（绿色），三线交于共点P(550,266)，标注P。添加CG₂红色虚线延长段、DH₂蓝色虚线延长段。步骤提示"步骤2：一般情形——GF、EH、BD三线共点"。

- 步骤3：点击「下一步」→ G移动到BC中点(G₃=290,365)，H移动到AD中点(H₃=525,160)。GF₃∥EH₃∥BD，三线高亮并添加平行符号"∥"。右上角显示"① ✗"（红色）、"② ✓"（绿色）。步骤提示"步骤3：特殊情形——GF∥EH∥BD"。

- 步骤5：点击「下一步」→ G移动到线段BC上(G₅=318,372)，H移动到线段AD上(H₅=550,178)。高亮△EFG₅（红色填充20%）和△EFH₅（蓝色填充20%）。从G₅、H₅分别向EF作垂线段（绿色虚线），垂足Q_G(376,248)、Q_H(491,302)，标注直角符号和等长标记。标注S△EFG=S△EFH。右上角显示"④ ✓"（绿色）。步骤提示"步骤5：面积恒等——同底等高"。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：本场景以静态几何图形、线段、填充为主，无需复杂3D渲染或函数绘图，原生SVG即可精确控制所有元素的位置、颜色、显隐，且性能最优。
- 画布尺寸：800 × 500 px（沿用规格）。
- 布局草图：
  ```
  [图示区 800×500]
  A(400,70)          D(650,250)
     \              /
      E(275,200)  H(随步骤)
       \          /
        \        /
  B(150,330)---F(540,325)
     \          /
      G(随步骤)
       \      /
        C(430,400)
  
  右上角：结论标记（步骤3/4/5）
  底部中央：步骤提示文字
  底部中央偏左/偏右：◀ 上一步 / 下一步 ▶
  ```
- 关键实现要点：
  1. 状态机设计：用变量currentStep（0~5）管理当前步骤。每一步定义一个配置对象，包含该步应显示的元素ID列表、各元素的坐标/颜色/透明度属性。
  2. 坐标计算：所有顶点、中点、动点坐标硬编码在配置对象中（见布局坐标表）。步骤切换时，通过setAttribute更新circle的cx/cy、line的x1/y1/x2/y2、polygon的points。
  3. 动画曲线：无需复杂动画，步骤切换时直接更新属性（瞬时切换）。如需平滑过渡，可对cx/cy使用CSS transition（0.3s ease）。
  4. 事件绑定：上一步/下一步按钮绑定click事件，调用updateScene(step)函数。updateScene内先隐藏所有动态元素，再根据配置显示当前步骤元素。
  5. 元素显隐控制：所有动态元素（G/H/P、截面边、高亮线、填充、垂线、符号、结论标记）初始display:none。updateScene通过设置display/visibility或opacity控制显隐。
  6. 延长线处理：BC/AD的实线段始终显示；延长线段（CG₂、DH₂、DH₄）仅在对应步骤显示，颜色与所属棱一致（红/蓝），dasharray 3,3。
  7. 垂线与直角符号：步骤5中，垂足Q_G、Q_H坐标通过硬编码给出（已预计算）。直角符号用path画L形（两条垂直短线，长8px）。
  8. 平面α填充：用polygon元素，points为四边形EFGH的四个顶点坐标（随步骤更新）。
  9. 结论标记：步骤3同时显示①✗和②✓；步骤4显示③✓；步骤5显示④✓。使用绝对定位text元素，x=720,y=50/80。
- ID命名规范：所有SVG元素ID必须以scene1-为前缀。例如：
  - 顶点：scene1-vertex-A, scene1-vertex-B, ...
  - 棱：scene1-edge-AB, scene1-edge-BC, ...
  - 中点：scene1-midpoint-E, scene1-midpoint-F
  - 动点：scene1-point-G, scene1-point-H
  - 共点：scene1-point-P
  - 截面边：scene1-section-EF, scene1-section-FG, ...
  - 高亮线：scene1-highlight-GF, scene1-highlight-EH, scene1-highlight-BD
  - 填充：scene1-fill-alpha, scene1-fill-EFG, scene1-fill-EFH
  - 标签：scene1-label-A, scene1-label-G, ...
  - 控件：scene1-btn-prev, scene1-btn-next, scene1-step-text
  - JS中严格使用document.getElementById('scene1-xxx')获取元素，禁止querySelectorAll配合全局class。
- IIFE隔离：所有JavaScript代码包裹在 (function() { ... })() 中，避免多场景合并时变量污染。
- 代码结构建议：
  ```javascript
  (function() {
    var currentStep = 0;
    var steps = [

    document.getElementById('scene1-btn-prev').addEventListener('click', function() { ... });
    document.getElementById('scene1-btn-next').addEventListener('click', function() { ... });
  ```
