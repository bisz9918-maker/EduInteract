    **题目原文**

    如图，F 为双曲线 $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$（$b > a > 0$）的右焦点，过 F 作直线 $l$ 与圆 $x^2 + y^2 = b^2$ 切于点 M，与双曲线交于点 P，且 M 恰为线段 PF 的中点，则双曲线的渐近线方程是 $\underline{\hspace{5em}}$。

    **题目分析**

    本题将双曲线的定义、圆的切线性质、三角形中位线定理整合在同一图形中。学生需要从"切线"想到 $OM \perp l$，从"中点"想到构造中位线，最终通过双曲线定义建立 $a$ 与 $b$ 的关系。

    **整体讲解思路**

    建议教师按以下逻辑引导学生观察与推导：

    1. **识别切线性质**：连接圆心 O 与切点 M，则 $OM \perp l$。在 Rt△OMF 中，$|OM| = b$（半径），$|OF| = c$（焦距），由勾股定理得 $|MF| = \sqrt{c^2 - b^2} = a$。
    2. **利用中点构造中位线**：M 是 PF 中点，O 是 FF' 中点（F' 为左焦点），因此 OM 是 △PFF' 的中位线。
    3. **转化长度与垂直关系**：由中位线性质得 $|PF'| = 2|OM| = 2b$，且 $PF' \parallel OM$。结合 $OM \perp l$ 可得 $PF' \perp PF$，即 △PFF' 为直角三角形。
    4. **应用双曲线定义**：点 P 在双曲线右支上，满足 $|PF'| - |PF| = 2a$。代入 $|PF| = 2|MF| = 2a$ 与 $|PF'| = 2b$，得 $2b - 2a = 2a$，即 $b = 2a$。
    5. **写出渐近线方程**：由 $\frac{b}{a} = 2$，得渐近线方程为 $y = \pm 2x$。

    **图示规划说明**

    本题所有核心推导均围绕同一幅坐标系几何图展开，无需拆分为多个相似图示。采用分步导航式交互，从基本图形开始，逐步添加辅助线、标注和高亮，最终呈现完整推导链，便于教师控制课堂节奏。

    **课堂讲解建议**

    教师在讲解时应特别注意以下细节：

    1. **强调隐藏条件**：很多学生看到"中点"只会想到坐标公式，要引导他们联想到"中位线"。关键提问："O 是谁的中点？"——O 是 FF' 的中点，这是双曲线焦点关于原点对称的天然性质。
    2. **几何法的优越性**：本题若用坐标法设直线方程，计算量较大。通过 Rt△OMF 直接得到 $|MF|=a$，是几何法的巧妙之处，应让学生体会数形结合的优势。
    3. **验证 $b > a$**：求得 $b=2a$ 后，可回头验证满足题设 $b > a > 0$，且右焦点 F 在圆外（$c = \sqrt{5}a > b = 2a$），确保切线存在。
    4. **完整解答书写**：
       - 设左焦点为 $F'$，连接 $PF'$、$OM$。
       - 因为 $l$ 切圆于 M，所以 $OM \perp l$，且 $|OM| = b$。
       - 在 Rt△OMF 中，$|OF| = c$，故 $|MF| = \sqrt{c^2 - b^2} = a$。
       - 又 M 为 PF 中点，O 为 FF' 中点，所以 $|PF'| = 2|OM| = 2b$，且 $PF' \parallel OM$，从而 $PF' \perp PF$。
       - 由双曲线定义，$|PF'| - |PF| = 2a$，即 $2b - 2a = 2a$，得 $b = 2a$。
       - 因此渐近线方程为 $y = \pm \frac{b}{a}x = \pm 2x$。
