[图示主题与整合说明]
- 本图示主题：底面ABCD满足条件的多种情形对比
- 整合的步骤/概念：在四棱柱ABCD-A₁B₁C₁D₁（侧棱垂直底面）中，要使得AC⊥B₁D₁，只需底面满足AC⊥BD即可。本图示通过三种状态并列对比，展示"AC⊥BD"、"菱形"、"正方形"这三个由弱到强的条件均可作为答案，帮助学生理解答案不唯一及条件间的包含关系。
- 教学价值：教师点击不同按钮切换三种底面形状，让学生直观看到：只要底面对角线垂直，无论是一般四边形、菱形还是正方形，都能推出AC⊥B₁D₁；同时理解条件的强弱层次（正方形⇒菱形⇒AC⊥BD）。

[交互方案]
- 交互类型：多状态切换（3个按钮）
- 控件说明：
  * 按钮1 "AC⊥BD"：位置(200,465)，宽120高25。点击切换到状态1（一般对角线垂直四边形）。
  * 按钮2 "菱形"：位置(340,465)，宽120高25。点击切换到状态2（菱形）。
  * 按钮3 "正方形"：位置(480,465)，宽120高25。点击切换到状态3（正方形）。
- 教师操作流程：
  1. 页面加载后默认显示状态1，教师可先讲解"只要AC⊥BD，就能推出AC⊥B₁D₁"的基本原理。
  2. 点击"菱形"按钮，切换到状态2，说明"菱形是对角线互相垂直平分的特殊四边形，当然也满足AC⊥BD，因此也是正确答案"。
  3. 点击"正方形"按钮，切换到状态3，说明"正方形是更特殊的菱形，对角线既垂直又相等，同样满足条件"。
  4. 通过来回切换，让学生体会"答案不唯一"，以及三个条件之间的包含关系（正方形⇒菱形⇒AC⊥BD）。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本场景为纯平面几何图形，无复杂动画、无函数图像、无3D，原生SVG足以高效实现；无需引入D3/Three.js等重型库，减少加载开销。
- 画布尺寸：800×500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------------+
  |  [顶部说明文字：底面ABCD满足以下条件时，均有AC⊥B₁D₁]      |  y=0~70
  |  [补充说明：三种条件由弱到强均可...]                     |
  |                                                        |
  |              A                                         |  y=70~120
  |              |                                         |
  |         B----O----D    ← 四边形+对角线+直角标记         |  y=120~400
  |              |                                         |
  |              C                                         |
  |                                                        |
  |         [条件：AC⊥BD / 菱形 / 正方形]                   |  y=420~450
  |                                                        |
  |    [AC⊥BD]  [菱形]  [正方形]   ← 切换按钮               |  y=455~490
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. **状态机设计**：维护变量 `currentState`（1/2/3）。点击按钮时调用 `switchState(n)`，先隐藏所有状态组（`display:none`），再显示目标状态组（`display:block`），最后更新按钮样式。
  2. **SVG分组结构**：
     ```svg
     <g id="scene2-state1" display="block">...</g>
     <g id="scene2-state2" display="none">...</g>
     <g id="scene2-state3" display="none">...</g>
     <g id="scene2-shared-labels">A/B/C/D/O标签</g>
     ```
     每个状态组内包含：四边形polygon、对角线line、交点circle、直角标记path、等长标记line（如有）、状态说明text、填充polygon、对角线等长文字（如有）。共享标签层始终显示。
  3. **按钮样式切换**：选中按钮添加class `scene2-btn-active`（背景#1565c0，文字#fff），其余按钮移除该class。
  4. **双色文字实现**：状态说明文字使用`<text><tspan fill="#2e7d32">条件：</tspan><tspan fill="#c62828">...</tspan></text>`。
  5. **等长标记计算**：每条边的中点 + 垂直于边方向的单位向量 × 6px（半长），方向取四边形外侧（通过中心点到中点向量的点积判断）。
  6. **无动画设计**：状态切换直接显示/隐藏，无过渡动画，确保课堂讲解时响应即时、清晰。
- **ID命名规范**：所有SVG元素ID以 `scene2-` 为前缀，例如 `scene2-state1`、`scene2-poly-s1`、`scene2-diag-ac-s1`、`scene2-btn-rhombus` 等。JS中严格使用 `document.getElementById` 获取元素，禁止全局class选择器，避免多场景合并时跨场景污染。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，变量不泄露全局作用域。
