[图示主题与整合说明]
- 本图示主题：垂直于 DE 的截面分析与命题 (1)(2)(3) 验证
- 整合的步骤/概念：
  1. 建立平面 A'GF 的 2D 截面图（AF 为竖直直径，G 为圆心，A' 在圆上运动）；
  2. 命题 (3)：通过 DE ⊥ AF 且 DE ⊥ A'G 推出 DE ⊥ 平面 A'GF，从而面面垂直；
  3. 命题 (1)：利用面面垂直性质，A' 在底面的射影落在交线 GF 上，即在线段 AF 上；
  4. 命题 (2)：体积 V = (1/3)·S△FED·h，h 为 A' 到直线 GF 的距离，当 A'G ⊥ AF 时 h_max = AG，体积取得最大值。
- 教学价值：教师通过分步导航，引导学生从线面垂直→面面垂直→射影定位→最值分析，层层递进，建立完整的空间推理链条。2D 截面图将三维旋转问题降维，降低学生空间想象难度。

[交互方案]
- 交互类型：分步按钮导航（◀ 上一步 / 下一步 ▶）
- 控件说明：
  - 「◀ 上一步」按钮：位置 (300,455)，宽 90px，高 30px；点击回退到上一状态，步骤0 时回到步骤3（循环）
  - 「下一步 ▶」按钮：位置 (410,455)，宽 90px，高 30px；点击前进到下一状态，步骤3 时回到步骤0（循环）
  - 步骤指示器：位置 (520,460)，显示当前步骤编号如"步骤 1/4"（步骤0 显示"步骤 1/4"或"基础截面"，建议显示"1/4、2/4、3/4、4/4"对应步骤0~3）
- 教师操作流程：
  1. 教师展示步骤0，介绍正三角形旋转问题的截面化方法，指出 A' 的运动轨迹是圆；
  2. 点击「下一步」进入步骤1，讲解 DE 与 AF、A'G 的垂直关系，引导学生发现 DE 垂直于整个平面 A'GF；

  5. 可随时点击「上一步」回退复习，或循环播放强化理解。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无外部库）。理由：本场景为简单几何图形（线段、圆、点、虚线、文字），SVG 原生支持足够；无需复杂数学计算或 3D 渲染。
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  +----------------------------------------------------------+
  |                                                          |
  |    A(280,140)                                            |
  |     |                                                    |
  |     |                                                    |
  |     |         A'(351,311)                                |
  |     |        /                                           |
  |     |       /                                            |
  |     |      /         [右侧说明文字区]                     |
  |     |     G●(280,240)                                    |
  |     |     |                                              |
  |     |     |                                              |
  |     |     |                                              |
  |     |     |                                              |
  |     |     F●(280,340)                                    |
  |     |     |  ++++++++++++++++++                          |
  |     |     |  +  平面 BCED    +                          |
  |     |     |  ++++++++++++++++++                          |
  |                                                          |
  |         [◀ 上一步]  [下一步 ▶]   步骤 X/4                 |
  +----------------------------------------------------------+
  画布 800×500，主图区 y=40~430，控件栏 y=440~490（SVG 外绝对定位 HTML 按钮）
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `let currentStep = 0;`（范围 0~3），每次点击按钮后 `currentStep = (currentStep + delta + 4) % 4;`，然后调用 `renderStep(currentStep)`。
  2. 元素显隐控制：为每个步骤特有的 SVG 元素组设置 `class="scene2-step1"` 等，通过 CSS 或 JS 控制 `display` / `opacity`。基础元素（AF、G、圆、平面BCED、基础标签）始终显示。
  3. A' 点位置动画：步骤3 中 A' 从 (351,311) 移动到 (380,240)。使用 SVG 的 `<animate>` 元素或 JS 的 `requestAnimationFrame` 插值。建议用 JS 插值实现更灵活的控制：在 400ms 内线性插值 x、y 坐标，同时改变颜色从 #1565c0 到 #2e7d32。
  4. 右侧文字切换：使用 4 组 `<g>` 包裹的 `<text>` 元素，每组对应一个步骤，通过 `display: none/block` 切换。
  5. 坐标计算：圆上点验证——A'(351,311) 到 G(280,240) 的距离 = √(71²+71²) ≈ 100.4 ≈ 半径 100（允许 1px 绘图误差）。A'最大(380,240) 到 G 距离 = 100，精确。
  6. h 双向箭头：使用 SVG `<marker>` 定义左右箭头，应用到 `<line>` 的 `marker-start` 和 `marker-end`。
  7. 圆的分半绘制：使用 `<path d="M 380 240 A 100 100 0 0 0 180 240" />` 画下半圆弧（y>240），`<path d="M 180 240 A 100 100 0 0 0 380 240" />` 画上半圆弧（y<240）。注意 SVG 圆弧参数调整。
- ID 命名规范：所有交互元素 ID 必须以 `scene2-` 为前缀。例如：
  - `scene2-line-af`、`scene2-point-g`、`scene2-circle-upper`、`scene2-circle-lower`、`scene2-point-aprime`、`scene2-line-ag`、`scene2-de-symbol`、`scene2-de-leader`、`scene2-line-ap`、`scene2-point-p`、`scene2-h-arrow`、`scene2-label-a`、`scene2-label-f`、`scene2-label-g`、`scene2-label-aprime`、`scene2-label-p`、`scene2-label-h`、`scene2-label-ag`、`scene2-label-gf`、`scene2-label-de`、`scene2-label-bced`、`scene2-text-group-0`、`scene2-text-group-1`、`scene2-text-group-2`、`scene2-text-group-3`、`scene2-btn-prev`、`scene2-btn-next`、`scene2-step-indicator`。
- IIFE 隔离：所有 JavaScript 代码包裹在 `(function() { ... })();` 中，避免多场景合并时的全局变量污染。
- 事件绑定：使用 `document.getElementById('scene2-btn-prev').addEventListener('click', ...)`，禁止用 `querySelectorAll` 配合全局 class。
