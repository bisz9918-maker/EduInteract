[图示主题与整合说明]
- 本图示主题：椭圆几何性质多结论验证
- 整合的步骤/概念：在统一构图中，通过分步导航依次验证四个结论——①FM平分∠PFB、②PM与椭圆Γ相切、③PM平分∠FPD、④PM=BM的存在性。每步聚焦单一结论，通过高亮线段、等角弧线标记、切线示意、虚线圆等视觉手段，将抽象的几何证明转化为可观察的图形特征。
- 教学价值：教师可在基础构图上，按课堂节奏逐步推进，每步仅呈现当前结论所需的视觉标注，避免信息过载；支持随时回退复习，适合探究式教学。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「◀ 上一步」按钮：位于(280,455)，宽90×高32。点击后currentStep减1（最小为0），回退到上一步视觉状态。
  2. 「下一步 ▶」按钮：位于(430,455)，宽90×高32。点击后currentStep加1（最大为4），推进到下一步视觉状态。
  3. 步骤指示器：位于(380,448)，显示"步骤 X/4"，随按钮点击同步更新。
- 教师操作流程：
  1. 加载后显示步骤0（基础构图），教师讲解题目初始条件。
  2. 点击「下一步」进入步骤1，观察FM高亮与等角弧，讲解结论①。
  3. 继续点击「下一步」依次验证结论②③④，每步聚焦单一结论。
  4. 可随时点击「上一步」回退，复习已讲结论。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：本场景为二维几何图形，以路径、线段、椭圆、文本为主，无需复杂数据绑定或3D渲染，原生SVG性能最优且可控性高。
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  结论标注框(620,50)                               |
  |                                                  |
  |        P(450,167)                                |
  |       /  \                                       |
  |      /    \                                      |
  |  A(170,250)----O(350,250)---F(500,250)-B(530,250)|
  |      \    / |                         |          |
  |       \  /  |                         |          |
  |        D(530,143)                     l          |
  |        |                              |          |
  |        M(530,197)                    (530,400)   |
  |                                                  |
  |  [◀ 上一步]  步骤 X/4  [下一步 ▶]               |
  +--------------------------------------------------+
  控件栏：y=440~490
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `let currentStep = 0;` 记录当前步骤（0~4）。每步对应一个视觉状态数组，定义该步应显示/隐藏的元素ID列表。
  2. 元素显隐控制：为所有步骤相关元素（高亮线、角弧、标注、虚线圆等）设置初始 `display: none`（或 `visibility: hidden`），在状态切换时通过 `setAttribute('display', 'block'/'none')` 控制。
  3. 结论框更新：步骤切换时同步更新结论框内的 `<text>` 内容。
  4. 按钮状态：当currentStep=0时，「上一步」按钮置灰（disabled样式）；当currentStep=4时，「下一步」按钮置灰。
  5. 等角弧线绘制：使用SVG `<path>` 的A命令。以F为圆心的弧，计算两边方向角（Math.atan2），取小弧（sweep-flag根据角度差正负确定）。例如∠PFM弧：起点为F沿FP方向外移20px，终点为F沿FM方向外移20px。
  6. 切线直角标记：在P点，沿PM方向（向量归一化×6px）得点T1，沿椭圆外法线方向（梯度归一化×6px）得点T2，再计算T3使PT1T2构成直角，用polyline或path绘制。
  7. 坐标计算：椭圆上P点坐标通过参数方程计算（a=180,b=100,θ≈1.1rad），确保P在椭圆上；D点通过直线AP与x=530求交；M为BD中点。
- ID命名规范：所有交互元素ID必须以 `scene2-` 为前缀。例如：`scene2-ellipse`、`scene2-point-a`、`scene2-fm-highlight`、`scene2-arc-pfm`、`scene2-step-text`、`scene2-btn-prev`、`scene2-btn-next`。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免多场景合并时的全局变量污染。
- 事件绑定：使用 `document.getElementById('scene2-btn-prev').addEventListener('click', ...)`，禁止用 `querySelectorAll` 配合全局class。
