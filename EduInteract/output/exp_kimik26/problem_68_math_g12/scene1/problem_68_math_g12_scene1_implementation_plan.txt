[图示主题与整合说明]
- 本图示主题：圆切线问题中利用直角三角形面积法求斜边上的高
- 整合的步骤/概念：
  1. 基础图形与已知条件识别（圆O、直径AB、延长线BP、切线PC、垂线CD）
  2. 切线性质可视化（连接半径OC，OC⊥PC）
  3. 直角三角形OCP三边计算（OP=4，PC=2√3）
  4. 面积法求高（OC·PC = OP·CD）
  5. 结论标注（CD=√3）
- 教学价值：教师通过分步导航精确控制课堂节奏，从识图→性质→计算→结论线性递进，可随时回退到任意认知阶段重复讲解

- 圆O：圆心(300,250)，半径90px，黑色轮廓

- 延长线BP：水平线段(390,250)-(480,250)，黑色

- 垂线CD：竖直线段(345,172)-(345,250)，步骤0为黑色实线，步骤3变为灰色虚线(#888888)
- 半径OC：斜线段(300,250)-(345,172)，步骤1以动画方式画出，蓝色(#1565c0)

- 直角标记：CD⊥AB在D点（黑色L形，8px）；OC⊥PC在C点（黑色，沿CO/CP方向8px短线）

- 长度标注：PB=2、BO=2（蓝，已知）；OC=2（蓝，已知）；OP=4、PC=2√3（红，推导）；CD=√3（绿，结论）
- 面积公式：步骤3显示"OC · PC = OP · CD"，步骤4显示"2 × 2√3 = 4 × CD"及"CD = √3"（绿色高亮）
- 配色规则沿用scene_outline：背景#ffffff，主线#000000，已知蓝#1565c0，推导红#c62828，结论绿#2e7d32，辅助虚线#888888

[分步序列]
- 步骤0（初始状态）：显示圆O、直径AB、延长线BP、切线PC、垂线CD；显示点标签A、O、D、B、P、C；显示已知标注PB=2（蓝）、BO=2（蓝）；显示直角标记CD⊥AB；等待教师触发
- 步骤1（切线性质）：点击下一步→半径OC以描边动画方式从O画向C（持续400ms，蓝色）；出现OC=2蓝色标注；在C点出现OC⊥PC直角标记
- 步骤2（直角三角形三边）：点击下一步→Rt△OCP区域以红色20%透明度填充，三角形边框加粗（红色）；依次弹出OP=4（红，位于OP上方）、PC=2√3（红，位于PC右上）标注，弹出间隔150ms
- 步骤3（面积法求高）：点击下一步→垂线CD线型变为灰色虚线(#888888)，强调"高"的几何角色；在图形正下方(400,360)淡入面积公式"OC · PC = OP · CD"；公式中OC、PC、OP、CD以对应颜色高亮
- 步骤4（结论）：点击下一步→在CD右侧出现CD=√3标注（绿色）；公式更新为"2 × 2√3 = 4 × CD"，随后"CD = √3"以绿色高亮显示；完成推导闭环
- 回退机制：教师可随时点击「上一步」回退，对应元素反向隐藏/恢复，便于重复讲解关键步骤

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  * 「◀ 上一步」按钮：位于底部(330,465)，点击回退到上一步骤，隐藏当前步骤新增元素
  * 「下一步 ▶」按钮：位于底部(470,465)，点击推进到下一步骤，按序列显示新元素/动画
- 教师操作流程：
  1. 教师展示步骤0，让学生识别图形和已知条件（PB=BO=2）
  2. 点击「下一步」进入步骤1，讲解切线性质（OC⊥PC）
  3. 点击「下一步」进入步骤2，引导学生计算Rt△OCP三边（OP=4，PC=2√3）
  4. 点击「下一步」进入步骤3，引入面积法思想（OC·PC = OP·CD）
  5. 点击「下一步」进入步骤4，得出CD=√3结论
  6. 讲解过程中可随时「上一步」回退，重复关键推理环节

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本题为纯2D几何图形，元素为圆、线段、多边形、文本，分步显示/隐藏逻辑简单，无需引入D3/Three.js等重型库
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  +--------------------------------------------------+
  |                                                  |
  |              C(345,172)                          |
  |             /  \                                 |
  |            /    \ PC                             |
  |           /      \                               |
  |    A-----O---D---B----P                          |
  |   (210) (300)(345)(390)(480)  y=250              |
  |                                                  |
  |    [长度标注区: y=200~290]                       |
  |                                                  |
  |         [面积公式区: y=360]                      |
  |                                                  |
  |         [◀ 上一步]  [下一步 ▶]   y=465           |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `currentStep`（0~4），每步定义显示元素ID列表，切换时遍历显示/隐藏
  2. OC动画：使用SVG stroke-dasharray/stroke-dashoffset实现描边画出效果，duration 400ms，easing ease-out
  3. 标注弹出：步骤2中OP=4、PC=2√3使用CSS opacity过渡，间隔150ms依次淡入
  4. 公式更新：步骤3和步骤4共用同一文本元素，步骤4时替换内容并给CD=√3添加绿色span
  5. 颜色高亮：通过添加/移除CSS类实现（如 .highlight-blue, .highlight-red, .highlight-green）
  6. 事件绑定：上一步/下一步按钮绑定click事件，根据currentStep调用对应enterStep/leaveStep函数
- ID命名规范：所有元素ID必须以 `scene1-` 为前缀，例如：
  * 圆：`scene1-circle-o`
  * 线段AB：`scene1-line-ab`
  * 标签A：`scene1-label-a`
  * 标注PB：`scene1-anno-pb`
  * 按钮：`scene1-btn-prev`、`scene1-btn-next`
  * 公式：`scene1-formula`
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })()` 中，避免多场景合并时全局变量污染
- 坐标计算说明：
  * 圆心O(300,250)，半径90px
  * C点坐标：(300+90·cos60°, 250-90·sin60°) = (345, 172)
  * D点坐标：(345, 250)（C在AB上的垂足）
  * P点坐标：(480, 250)（BP=BO=90px）
  * 直角标记OC⊥PC：从C沿CO方向取8px得(341,179)，沿CP方向取8px得(352,176)，画直角符号
