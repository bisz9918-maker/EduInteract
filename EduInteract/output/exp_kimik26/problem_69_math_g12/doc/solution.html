题目原文

如图，已知三棱柱 $ABC-A_1B_1C_1$ 的六个顶点都在球 $O$ 的球面上，若 $AA_1 \perp$ 平面 $A_1B_1C_1$，$A_1B_1 \perp B_1C_1$，$AA_1=8$，$A_1B_1=6$，$A_1C_1=2\sqrt{34}$，则球 $O$ 的体积为 $\underline{\hspace{5em}}$．

题目分析

本题考查直三棱柱的外接球问题，核心在于将立体几何问题转化为平面几何问题求解。已知条件表明该三棱柱为直三棱柱（侧棱垂直于底面），且底面为直角三角形。求解外接球体积的关键是确定球心位置和球半径。

整体讲解思路

  1. 先引导学生识别几何体类型：由 $AA_1 \perp$ 平面 $A_1B_1C_1$ 可知为直三棱柱；由 $A_1B_1 \perp B_1C_1$ 可知底面为直角三角形。
  2. 利用底面直角三角形的勾股定理求出未知直角边 $B_1C_1$。
  3. 讲解直三棱柱外接球的重要性质：球心位于上下底面外接圆圆心连线的中点。
  4. 底面为直角三角形，其外接圆圆心为斜边中点，半径为斜边的一半。
  5. 通过勾股定理求出球的半径 $R$，进而计算体积。

图示规划说明

  • 图示 2：构建外接球模型，定位球心，通过关键直角三角形推导球半径，最终求得体积。
步骤 1/4

教学说明：外接球模型的构建与球心定位

在确认底面是直角三角形且三边长分别为 $6, 10, 2\sqrt{34}$ 后，教师应引导学生思考外接球的核心性质。

关键提问

  1. "直三棱柱六个顶点都在球面上，这个球的球心会在哪里？"——引导学生回忆：直棱柱外接球的球心在两底面外接圆圆心连线的中点。
  2. "底面是直角三角形，它的外接圆有什么特殊性？"——引导学生发现：直角三角形外接圆圆心在斜边中点，半径等于斜边的一半。

推导要点

  1. 底面 $\triangle A_1B_1C_1$ 为直角三角形，斜边 $A_1C_1 = 2\sqrt{34}$，因此底面外接圆半径 $r = \dfrac{A_1C_1}{2} = \sqrt{34}$，外心 $O_1$ 为 $A_1C_1$ 中点。
  2. 上底面 $\triangle ABC$ 与下底面全等且平行，外心 $O_2$ 为 $AC$ 中点，$O_1O_2 \parallel AA_1$ 且 $O_1O_2 = AA_1 = 8$。
  3. 球心 $O$ 为线段 $O_1O_2$ 的中点，故球心到下底面的距离 $d = OO_1 = \dfrac{8}{2} = 4$。
  4. 取底面圆周上一点（如 $B_1$），则 $OB_1 = R$（球半径）。在 Rt$\triangle OO_1B_1$ 中，由勾股定理：

$$R^2 = r^2 + d^2 = (\sqrt{34})^2 + 4^2 = 34 + 16 = 50$$
所以 $R = \sqrt{50} = 5\sqrt{2}$。

  1. 球体积 $V = \dfrac{4}{3}\pi R^3 = \dfrac{4}{3}\pi (5\sqrt{2})^3 = \dfrac{4}{3}\pi \cdot 250\sqrt{2} = \dfrac{1000\sqrt{2}}{3}\pi$。

讲解建议

建议教师在图示 2 中配合分步动画，每出现一条新的辅助线或标注，都先让学生猜测其几何意义，再揭示答案。特别注意强调"球心到所有顶点距离相等"这一性质如何转化为"球心在两底面外心连线的中点"。

总结：完整解答与课堂建议

完整解答过程

  1. 由 $AA_1 \perp$ 平面 $A_1B_1C_1$ 且 $A_1B_1 \perp B_1C_1$，知三棱柱 $ABC-A_1B_1C_1$ 是底面为直角三角形的直三棱柱。
  2. 在 Rt$\triangle A_1B_1C_1$ 中：

$$B_1C_1 = \sqrt{A_1C_1^2 - A_1B_1^2} = \sqrt{(2\sqrt{34})^2 - 6^2} = \sqrt{136 - 36} = \sqrt{100} = 10$$

  1. 直角三角形的外接圆圆心为斜边中点，故下底面外心 $O_1$ 为 $A_1C_1$ 中点，外接圆半径 $r = \dfrac{A_1C_1}{2} = \sqrt{34}$。
  2. 直三棱柱外接球的球心 $O$ 位于上下底面外心连线 $O_1O_2$ 的中点，因此球心到下底面的距离 $d = OO_1 = \dfrac{AA_1}{2} = 4$。
  3. 在 Rt$\triangle OO_1B_1$ 中，由勾股定理：

$$R = \sqrt{r^2 + d^2} = \sqrt{34 + 16} = \sqrt{50} = 5\sqrt{2}$$

  1. 球 $O$ 的体积：

$$V = \frac{4}{3}\pi R^3 = \frac{4}{3}\pi (5\sqrt{2})^3 = \frac{4}{3}\pi \cdot 250\sqrt{2} = \frac{1000\sqrt{2}}{3}\pi$$

课堂讲解建议

  • 易错点提醒：学生常误认为球心在底面三角形内部（如重心或垂心），需特别强调直角三角形外心在斜边中点这一性质。
  • 方法迁移：可引导学生总结"直棱柱外接球半径公式"——若底面外接圆半径为 $r$，高为 $h$，则 $R = \sqrt{r^2 + (h/2)^2}$。本题正是该公式的直接应用。
  • 空间想象辅助：对于空间感较弱的学生，建议教师在图示 2 中反复切换"显示/隐藏外接球"和"显示/隐藏三棱柱"，帮助学生分离出关键直角三角形 $OO_1B_1$。
  • 变式拓展：可追问"若底面不是直角三角形，外心如何确定？"——引导学生思考一般三角形外心的作法，完善知识体系。
