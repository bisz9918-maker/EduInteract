[图示主题与整合说明]
- 本图示主题：直三棱柱 ABC-A₁B₁C₁ 的外接球构造、球心定位与半径体积计算
- 整合的步骤/概念：
  1) 直三棱柱与外接球的相对位置（所有顶点在球面上）；
  2) 上下底面外接圆及其外心 O₁、O₂ 的标注；
  3) 球心 O 为 O₁O₂ 中点的定位；
  4) 关键直角三角形 OO₁B₁ 的构造与勾股定理推导 R = 5√2；
  5) 球体积公式计算 V = 1000√2π/3。
- 教学价值：教师通过分步导航，逐层揭示“直棱柱外接球球心在两底面外心连线的中点”这一核心结论，右侧平面展开图将空间问题降维为平面直角三角形问题，降低学生空间想象门槛。

[分步序列]
- 初始状态（步骤0）：显示半透明线框三棱柱（6顶点+9棱）及其外接球（球壳网格+轮廓），标注 6 个顶点字母 A、B、C、A₁、B₁、C₁。球心 O 尚未标注，外接圆尚未显示。教师可在此步让学生观察“所有顶点都在球面上”的几何直观。
- 步骤1：点击「下一步」→ 在上底面位置添加虚线外接圆（中心 O₁），标注外心 O₁，添加半径标注 r = √34（位于 O₁B₁ 连线附近）。教师讲解：上底面为直角三角形，斜边 A₁C₁ 为外接圆直径，故外心 O₁ 为 A₁C₁ 中点，半径 r = A₁C₁/2 = √34。
- 步骤2：点击「下一步」→ 在下底面位置添加虚线外接圆（中心 O₂），标注外心 O₂，连接 O₁O₂（灰色虚线），标注 O₁O₂ = 8。教师讲解：下底面与上底面全等，外心 O₂ 为 AC 中点；O₁O₂ 平行于侧棱 AA₁，长度等于棱柱高 8。
- 步骤3：点击「下一步」→ 标注球心 O 为 O₁O₂ 中点，标注 OO₁ = 4；高亮显示球心到各顶点的半径连线 OA₁、OB₁、OC₁（蓝色实线），并在 OB₁ 附近标注 R = 5√2。教师讲解：球心必在两底面外心连线的中点；球半径 R 为球心到任一顶点的距离。
- 步骤4：点击「下一步」→ 在右侧区域出现关键直角三角形 OO₁B₁ 的放大平面示意图（直角在 O₁），标注两直角边 O₁B₁ = √34、OO₁ = 4，斜边 OB₁ = R = 5√2，并绘制绿色直角符号。教师讲解：将空间三角形 OO₁B₁ 摊平，用勾股定理求 R。
- 步骤5：点击「下一步」→ 在右侧三角形下方出现体积计算公式推导：V = 4/3 πR³ = 4/3 π(5√2)³ = 1000√2π/3，最终结果红色高亮。教师讲解：代入 R = 5√2 计算体积，得出最终答案。
- 教师可随时点击「上一步」回退复习，点击「重置」回到步骤0。

[交互方案]
- 交互类型：分步按钮导航（◀ 上一步 / 下一步 ▶ / 重置）
- 控件说明：
  1. 「上一步」按钮：位于控件栏左侧 (310, 460)，宽 100×30；点击回退到上一状态，步骤0 时禁用（opacity 0.4）。
  2. 「下一步」按钮：位于控件栏中间 (430, 460)，宽 100×30；点击推进到下一状态，步骤5 时禁用。

- 教师操作流程：
  1. 课堂开始时点击「重置」确保在步骤0，引导学生观察三棱柱与外接球的位置关系；
  2. 每讲解完一个子概念，点击「下一步」揭示新的辅助线/标注；
  3. 若学生某步未理解，点击「上一步」回退重新讲解；
  4. 步骤4 时重点讲解右侧平面展开图，将空间勾股定理转化为平面问题；
  5. 步骤5 时强调最终体积结果的推导过程。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript。理由：本场景以 3D 线框投影、分步显隐控制为主，无需复杂数据绑定或 3D 引擎；原生 SVG 的 path、circle、ellipse、line 足以绘制所有几何元素，且便于通过 class 切换显隐。
- 画布尺寸：800 × 500 px（固定），控件栏在 SVG 内底部 y=440~490 区域，通过 HTML absolute positioning 叠加于 SVG 上方。
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------------+
  |                                                        |
  |   主图区（三棱柱+外接球）      右侧区（步骤4/5使用）     |
  |   x:50~420                    x:460~780               |
  |   y:50~430                    y:50~430                |
  |                                                        |
  |    C₁•                  A₁•        [右侧三角形]         |
  |      \                /           O•                   |
  |       \    B₁•------/            /|                    |
  |        \  /       /             / |                    |
  |         •/       /             O₁•-•B₁                 |
  |        / \      /                  √34                 |
  |       /   \    /                                       |
  |    C•     A•                                [公式]      |
  |      \   /                                             |

  +--------------------------------------------------------+
  ```

- 关键实现要点：
  1. **3D 投影函数**：定义 project(x, y, z) → {sx, sy}，采用斜二测投影：
     - sx = 220 + 11*x - 3.85*z
     - sy = 360 - 11*y - 2.5*z
     所有顶点、圆心、球心均通过此函数统一计算，确保投影一致。
  2. **绘制顺序（Painter's Algorithm）**：
     - 第1层：外接球填充（半透明蓝色）+ 球网格线；
     - 第2层：三棱柱隐藏棱（灰色虚线）；
     - 第3层：三棱柱可见棱（黑色实线，opacity 0.4）；
     - 第4层：外接圆椭圆（灰色虚线）、辅助连线 O₁O₂；
     - 第5层：高亮半径连线（蓝色实线）；
     - 第6层：顶点/外心/球心圆点 + 所有文字标签。
  3. **外接圆椭圆绘制**：上/下底面外接圆在投影中为旋转椭圆。使用 SVG `<ellipse>` 近似：中心在 O₁/O₂ 投影坐标，rx=64，ry=27，transform="rotate(33, cx, cy)"，stroke-dasharray="5,3"。若浏览器兼容性有顾虑，可用 `<path>` 绘制参数方程椭圆。
  4. **状态机设计**：
     - 变量 `scene2_step` ∈ [0, 5]；
     - 每个几何元素/标签设置 `data-step-from` 和 `data-step-to` 属性（或使用 class 如 `scene2-s1` 表示步骤1显示）；
     - `renderStep()` 函数遍历所有元素，根据当前 step 设置 `display` 或 `visibility`；
     - 按钮禁用状态同步更新。
  5. **动画曲线**：分步切换不使用过渡动画（避免拖堂），直接显隐；若需柔和效果，可加 150ms 的 opacity transition。
  6. **事件绑定**：按钮通过 `onclick` 绑定 `scene2Prev()`、`scene2Next()`、`scene2Reset()`。
  7. **下标处理**：顶点标签 A₁、B₁、C₁ 使用 SVG `<tspan>` 设置 `baseline-shift="sub"` 和较小字号实现下标效果。
  8. **右侧三角形绘制**：步骤4 时显示右侧组（group id="scene2-right-tri"），步骤5 时在其下方追加公式组（group id="scene2-formula"）。
- **ID 命名规范**：所有 SVG 元素及控件 ID 必须以 `scene2-` 为前缀，例如：
  - `scene2-vertex-A`、`scene2-label-A1`、`scene2-sphere-shell`、`scene2-circle-top`、`scene2-line-OO1`、`scene2-right-tri`、`scene2-formula-line1`、`scene2-btn-prev`、`scene2-btn-next`、`scene2-btn-reset`。
- IIFE 隔离：所有 JavaScript 包在 `(function() { ... })()` 中，避免多场景合并时变量污染。
