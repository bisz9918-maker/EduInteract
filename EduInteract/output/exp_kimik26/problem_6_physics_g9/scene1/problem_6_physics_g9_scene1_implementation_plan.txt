[技术实现]
- JS库选择：原生SVG（使用HTML内嵌SVG标签）。原因：本场景为静态几何图示与简单状态切换，无需复杂数据绑定或3D渲染，原生SVG配合少量JavaScript即可高效实现，且便于教师直接嵌入课件。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------------+
  |  定值电阻                                              |
  |     |                                                  |
  |  电流表                    弹簧测力计                   |
  |     |                         |                        |
  |  滑动变阻器                   |                        |
  |     |                       铁球                       |
  |     |                         |                        |
  |     +-------------------------+ 电磁铁                 |
  |                              |                         |
  |  开关 --- 电源               |                         |
  |                              |                         |
  |  [上一步]  步骤 X/3  [下一步]                           |
  +--------------------------------------------------------+
  控件栏 y=440~490（绝对定位覆盖于SVG上方）
  ```
- 关键实现要点：
  1. 状态机设计：定义变量 `let currentStep = 0;`，取值范围0~3。每次点击按钮时更新状态，并调用 `renderStep()`。
  2. 分组管理：在SVG中使用4个`<g>`分组，id分别为 `scene1-step0-base`（基础图，始终显示）、`scene1-step1-current`（电流路径）、`scene1-step2-rheostat`（变阻器标注）、`scene1-step3-labels`（元件名称）。通过设置 `display: none/block` 控制显隐。
  3. 电流箭头：使用SVG `<marker>` 定义箭头符号，在电流路径 `<line>` 或 `<path>` 上设置 `marker-mid` 或 `marker-end`。由于需要多段箭头，可在每段导线中点单独放置 `<polygon>` 旋转至对应角度（0°, 90°, 180°, 270°）。
  4. 坐标计算：所有坐标严格采用上述布局坐标表，导线均为水平/竖直正交走线，避免斜线导致箭头方向复杂化。
  5. 动画曲线：本场景为即时切换，无需CSS动画或JS插值；若需柔和过渡，可为各`<g>`添加CSS `transition: opacity 0.2s ease`。
  6. 事件绑定：按钮通过 `document.getElementById('scene1-btn-prev').addEventListener('click', ...)` 绑定，直接操作状态机。
  7. 防文字压线：所有标签使用 `paint-order="stroke"`，先描边后填充，描边色`#ffffff`，描边宽度`3px`，确保文字压过黑色导线时仍可辨识。
- ID命名规范：所有SVG元素及交互控件ID必须以 `scene1-` 为前缀。例如：`scene1-resistor`、`scene1-step1-current`、`scene1-btn-prev`、`scene1-btn-next`。JS中严格使用 `document.getElementById` 获取元素，禁止全局class选择，避免多场景合并时跨场景污染。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，变量不泄露全局作用域。
