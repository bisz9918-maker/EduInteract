# Scene 2 Implementation Plan

<SCENE_VISION_STORYBOARD_AND_TECHNICAL_PLAN>

[图示主题与整合说明]
- 本图示主题：利用对称性确定点 P 的位置并推导六个夹角构成的等差数列
- 整合的步骤/概念：
  1. 正六边形内接于圆 O 的基础图形与方向角标注；
  2. 60°旋转对称与关于 OA₁ 的轴对称，将研究范围缩小至 φ∈[0°,30°]；
  3. 六个夹角 θ₁~θ₆ 关于 φ 的代数表达式；
  4. 在 φ∈[0°,30°] 条件下的排序结果；
  5. 等差条件（相邻两项差相等）建立方程并求解；
  6. 得出完整数列并高亮第 3 项 75°。
- 教学价值：教师通过分步按钮控制推导节奏，左侧几何图与右侧代数推导同步呼应，数形结合，便于学生跟随对称性→表达式→排序→方程→结论的完整逻辑链。

[分步序列]
- 初始状态（步骤 0）——基础图形：
  • 几何区显示：圆 O、正六边形 A₁A₂A₃A₄A₅A₆、半径 OA₁~OA₆（带箭头）、圆心 O、六顶点及标签、圆周外侧方向角 0°,60°,120°,180°,240°,300°。
  • 显示 OP 示意线段（到 φ=20° 位置，颜色 #666666）与红色 φ 弧线（r=50，0°→20°），标注 "φ"。
  • 右侧面板显示标题「基础图形」与说明：正六边形内接于圆 O，设 OP 与 OA₁ 的夹角为 φ。
  • 隐藏：对称轴、基本区域、θ₂~θ₆ 弧线、蓝色 OP。

- 步骤 1——对称性分析：
  • 几何区新增：OA₁ 延长线（灰色虚线，向右延伸至 x=440）；0°→30° 基本区域扇形（绿色填充 20%）与绿色弧段（线宽 3px）；30° 分界线（灰色虚线，从圆心到 (376,130)）。
  • 右侧面板切换为标题「对称性分析」，列出：① 60° 旋转对称；② 关于 OA₁ 轴对称；结论「只需研究 φ∈[0°,30°]」（绿色加粗）。
  • 保留步骤 0 的基础图形与 φ 标注；隐藏 θ₂~θ₆ 弧线。

- 步骤 2——列出六式：
  • 几何区隐藏步骤 1 的对称轴、基本区域、30° 分界线，保留基础图形与 OP 示意线段。
  • 新增 θ₁~θ₆ 六条弧线（不同半径、不同颜色，见坐标表），分别标注 θ₁~θ₆（θ₁ 与 φ 同位置，标签切换为 "θ₁"）。
  • 右侧面板切换为标题「六个夹角」，依次写出：
    θ₁ = φ
    θ₂ = |60° − φ|
    θ₃ = |120° − φ|
    θ₄ = |180° − φ|
    θ₅ = arccos(cos(240°−φ))  （取 [0°,180°]）
    θ₆ = arccos(cos(300°−φ))  （取 [0°,180°]）
  • 用颜色对应：θ₁ 红、θ₂ 蓝、θ₃ 绿、θ₄ 橙、θ₅ 紫、θ₆ 青，与几何弧线颜色一致。

- 步骤 3——排序与等差条件：
  • 几何区隐藏 θ₂~θ₆ 弧线，保留基础图形、OP 示意线段、红色 φ 弧线（仅保留最简洁的图，避免干扰）。
  • 右侧面板切换为标题「排序与等差条件」。
  • 先展示前提：当 φ∈[0°,30°] 时，绝对值可去掉，排序后数列为：
    φ,  60°−φ,  60°+φ,  120°−φ,  120°+φ,  180°−φ
  • 用红色高亮两个相邻差值：
    d₁ = (60°−φ) − φ = 60° − 2φ   （红色）
    d₂ = (60°+φ) − (60°−φ) = 2φ   （红色）
  • 展示等差条件：d₁ = d₂，即 60° − 2φ = 2φ。

- 步骤 4——求解与结论：
  • 几何区：隐藏 OP 示意线段（#666666），显示 OP 结论线段（#1565c0，线宽 2px），从圆心到 φ=15° 精确位置 (394,173)；点 P 放大至 r=6 并变为蓝色；φ 弧线更新为 0°→15°（r=50，红色）。
  • 右侧面板切换为标题「求解与结论」。
  • 展示方程：60° − 2φ = 2φ  （红色加粗）
  • 展示解得：φ = 15°  （红色加粗，字号稍大）
  • 展示完整数列：15°, 45°, 75°, 105°, 135°, 165°
  • 高亮第 3 项：用红色粗体 #c62828，背景填充 #ffcdd2，显示「第 3 项 = 75°」。
  • 教师可随时点击「上一步」回退到任意步骤复习。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript。理由：本场景以静态几何图形与分步显隐为主，无复杂函数绘图或 3D，原生 SVG 足以精确控制圆、弧、扇形、箭头；配合原生 JS 状态机即可实现分步切换，无需引入 D3/MathJax 等重型库（公式简单，可用 Unicode 下标与 HTML 文本直接呈现）。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图：
  ```
  +--------------------------------------------------+
  |  [几何图形区 0≤x≤440, 0≤y≤440]    | [推导面板    |
  |                                   |  450≤x≤780   |
  |    圆心 O(220,220) 半径180        |  30≤y≤420]   |
  |    正六边形 + 方向角标注           |              |
  |    OP + φ 弧线 / θ 弧线            |  步骤标题    |
  |    基本区域（步骤1）               |  公式/说明   |
  |                                   |              |
  +--------------------------------------------------+
  |  [控件栏 y=440~490]                              |
  |       ◀ 上一步      步骤 X/5      下一步 ▶       |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：定义变量 `scene2_currentStep`（0~4）。每一步对应一个配置对象 `scene2_steps[step]`，包含 `show` 与 `hide` 两个 ID 数组，以及右侧面板 HTML 内容字符串。点击按钮时更新 `currentStep`，调用 `scene2_render()`。
  2. 渲染函数：`scene2_render()` 遍历当前步骤的 show/hide 数组，通过 `document.getElementById` 获取元素，设置 `display` 或 `visibility` 属性。避免使用 classList 批量操作，防止跨场景污染。
  3. 弧线绘制：SVG 中圆弧使用 `<path d="M x1 y1 A r r 0 large-arc sweep x2 y2" />`。六个 θ 弧线半径从 50px 递增至 150px，确保不重叠；φ 弧线固定 r=50px。
  4. 扇形绘制：基本区域扇形使用 path 的 L→A→Z 命令闭合，fill-opacity=0.2。
  5. 箭头实现：半径 OAᵢ 的箭头使用 SVG `<marker>` 定义，id 为 `scene2-arrowhead`，在步骤 0 初始化时创建。
  6. 步骤 4 的 OP 切换：步骤 4 中隐藏 `scene2-line-op-demo` 与 `scene2-point-p-demo`，显示 `scene2-line-op-final` 与 `scene2-point-p-final`，并更新 φ 弧线 path 数据（从 20° 改为 15°）。直接切换，无需平滑动画，保证分步导航的清晰与即时性。
  7. 按钮状态：`scene2_updateButtons()` 在步骤 0 禁用「上一步」，步骤 4 禁用「下一步」。
  8. 右侧面板：使用绝对定位的 HTML `<div id="scene2-panel">`，每步通过 `innerHTML` 注入对应内容，便于使用 HTML/CSS 排版公式与高亮样式。
