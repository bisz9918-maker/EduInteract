problem_73_physics_g12

场景导航：Scene 1 | Scene 2 | Scene 3

完整题目原文：

如图所示，U形导体框架的宽度为L=1m，其所在平面与水平面夹角θ=30°，其电阻可以忽略不计。设匀强磁场与U形框架的平面垂直，磁感强度B=0.2Wb/m²。今有一条形导体棒MN，其质量m=0.2kg，其电阻R=0.2Ω，跨放在U形框架（足够长）上，并能无摩擦地滑动，求：
（1）导体棒MN下滑过程的最大速度v_m；
（2）在最大速度v_m时，在导体棒MN上释放出来的电功率P；
（3）若导体棒从开始下滑到达到最大速度这一过程中导体棒消耗的电能为Q_电=1.5J，则此过程中通过导体棒横截面积的电量q是多少？

题目分析：

本题是典型的电磁感应"单棒导轨"模型。导体棒在倾斜光滑导轨上由静止开始下滑，切割垂直于导轨平面的磁感线，产生感应电动势和感应电流，进而受到安培力作用。随着速度增大，安培力增大，合力减小，加速度减小，最终达到匀速运动状态（最大速度）。

核心物理链条：v↑ → E=BLv↑ → I=E/R↑ → F安=BIL↑ → F合↓ → a↓ → 最终a=0，v=v_m

第三问涉及能量守恒（重力势能减少量 = 动能增加量 + 电能）和电量计算（q = ΔΦ/R），需要先由能量关系求出下滑位移，再求电量。

整体讲解思路：

  1. 先通过立体装置图帮助学生建立空间情景，明确磁场方向与框架平面的垂直关系
  2. 进行受力分析，推导最大速度（第一问）
  3. 通过v-t图像和因果链，帮助学生理解动态过程的物理本质，并计算功率（第二问）
  4. 利用能量守恒求位移，再结合磁通量变化求电量（第三问）

步骤 1/6

Scene 1 教学说明：装置认知与受力分析

教师应首先引导学生观察立体图，确认三个关键空间关系：

  1. U形框架平面与水平面成θ=30°角
  2. 磁场B垂直于框架平面（不是竖直方向，这是易错点）
  3. 导体棒MN垂直于框架两边，有效切割长度为L=1m

安培力方向判断（重点）：

  • 先用右手定则判断感应电流方向：掌心迎向B（垂直框架平面向里），拇指沿斜面向下（运动方向），四指指向即为电流方向（从M指向N）
  • 再用左手定则判断安培力方向：掌心迎向B，四指沿电流方向（M→N），拇指指向即为安培力方向——沿斜面向上
  • 强调：安培力始终阻碍导体棒的相对运动（楞次定律的力的表现）

受力分析要点：

  • 支持力N垂直斜面向上，与重力垂直斜面的分力mg cosθ平衡（N = mg cosθ）
  • 沿斜面方向：下滑分力mg sinθ向下，安培力F_安向上
  • 初始阶段v较小，F_安 < mg sinθ，合力向下，加速下滑
  • 当F安 = mg sinθ时，合力为零，达到最大速度vm

最大速度推导：

  1. 感应电动势：E = BLv
  2. 感应电流：I = E/R = BLv/R
  3. 安培力：F_安 = BIL = B²L²v/R
  4. 平衡条件：mg sinθ = B²L²v_m/R
  5. 解得：v_m = mgR sinθ/(B²L²) = (0.2×10×0.2×0.5)/(0.2²×1²) = 5 m/s

提醒学生注意：最大速度时导体棒做匀速直线运动，但切割磁感线仍在继续，电路中仍有持续电流。

步骤 0 / 5

Scene 2 教学说明：动态过程与功率分析

本图示的核心目标是帮助学生理解"加速度减小的加速运动"的物理本质，而非仅仅记住结论。

v-t图像的解读：

  • 曲线从原点出发，斜率（加速度）逐渐减小，最终以v_m=5m/s为水平渐近线
  • 强调：这不是匀加速运动，不能用v=at直接求位移
  • 教师可以提问："如果导轨无限长，导体棒最终会不会停下来？"引导学生理解只要v

因果关系链（教学重点）：
引导学生从左到右阅读因果链：

  1. 速度v增大（原因）
  2. 感应电动势E=BLv成正比增大（结果1）
  3. 感应电流I=E/R成正比增大（结果2）
  4. 安培力F_安=BIL成正比增大（结果3）
  5. 沿斜面合力F合=mg sinθ-F安减小（结果4）
  6. 加速度a=F_合/m减小（结果5）

这是一个负反馈机制：速度增大导致阻碍力增大，从而限制速度进一步增大。这是电磁感应单棒模型的核心规律。

功率计算的两种方法（第二问）：

  1. 电路方法：P = E²/R = (BLv_m)²/R = (0.2×1×5)²/0.2 = 5 W
  2. 力学方法：P = F安·vm = mg sinθ·v_m = (0.2×10×0.5)×5 = 5 W

教师应强调两种方法的物理意义：

  • 电路方法从能量输出角度计算
  • 力学方法P=F安·vm体现了"克服安培力做功的功率等于电路中产生的电功率"，这是电磁感应中能量转化的关键桥梁
  • 在最大速度时，重力沿斜面的分力做功功率（mg sinθ·v_m）全部转化为电功率，因为动能不再变化
mgx·sinθ = ½mvₘ² + Q₍电₎
0.2×10×x×0.5 = ½×0.2×5² + 1.5
x = 4 m
电量公式推导：
q = Ī·Δt = (Ē/R)·Δt
= ΔΦ/R = BLx/R
代入数值：
q = 0.2×1×4/0.2
q = 4 C
步骤 1/6

Scene 3 教学说明：能量守恒与电量计算

本图示解决第三问，关键在于"先求位移x，再求电量q"的两步策略。

能量守恒的应用：

  • 明确研究对象：导体棒（从静止下滑到最大速度的过程）
  • 减少的能量：重力势能 ΔE_p = mgx sinθ
  • 增加的能量：动能 ΔEk = ½mvm² 和 电能 Q_电
  • 方程：mgx sinθ = ½mvm² + Q电
  • 代入数据：0.2×10×x×0.5 = ½×0.2×5² + 1.5
  • 计算：x = (2.5 + 1.5)/1 = 4 m

教师需强调：由于框架电阻忽略不计，导体棒消耗的电能Q_电就是整个回路产生的总焦耳热。

电量公式的推导（重点）：

  1. 电流定义：q = Ī·Δt（用平均电流）
  2. 欧姆定律：Ī = Ē/R（用平均电动势）
  3. 法拉第电磁感应定律：Ē = ΔΦ/Δt
  4. 联立得：q = ΔΦ/R

这个公式的优美之处在于：电量q只与磁通量变化量和电阻有关，与下滑快慢无关。即使导体棒做变加速运动，此公式依然成立。

本题中：

  • 初态磁通量：Φ_1 = 0（可从初位置开始计算）
  • 末态磁通量：Φ_2 = BLx
  • 磁通量变化：ΔΦ = BLx = 0.2×1×4 = 0.8 Wb
  • 电量：q = ΔΦ/R = 0.8/0.2 = 4 C

教师可以追问："如果导体棒与导轨间有摩擦，电量公式还成立吗？"引导学生思考：q=ΔΦ/R与力学过程无关，只要有相同的位移x，电量就相同（但此时能量方程需要加入摩擦生热项）。

完整解答与课堂讲解建议

三问完整解答（取g=10m/s²）：

  1. 最大速度v_m：

由平衡条件 mg sinθ = F安 = BIL = B(BLvm/R)L = B²L²v_m/R
解得 v_m = mgR sinθ/(B²L²) = (0.2×10×0.2×0.5)/(0.2²×1²) = 5 m/s

  1. 最大速度时的电功率P：

P = E²/R = (BLv_m)²/R = (0.2×1×5)²/0.2 = 5 W
（或 P = F安·vm = mg sinθ·v_m = 1×5 = 5 W）

  1. 通过导体棒的电量q：

由能量守恒 mgx sinθ = ½mvm² + Q电
代入得 x = (½×0.2×25 + 1.5)/(0.2×10×0.5) = 4 m
由 q = ΔΦ/R = BLx/R = 0.2×1×4/0.2 = 4 C

课堂讲解建议：

  • 核心模型提炼： 讲完后务必总结"单棒+导轨+磁场"模型的通用规律：vm = F外·R/(B²L²)，其中F_外是除安培力外的其他沿运动方向的合力（本题中为mg sinθ）。
  • 易错点提醒：
  1. 磁场B垂直于框架平面，不是竖直方向，计算感应电动势时直接用E=BLv，无需再乘sinθ
  2. 安培力F_安=BIL中的L是有效长度（即框架宽度），与斜面长度无关
  3. 电量公式q=ΔΦ/R中的ΔΦ是磁通量变化量，不是磁通量本身
  • 方法对比： 第二问功率建议同时展示"电路法"和"力学法"，帮助学生建立"克服安培力做功⇔产生电能"的能量转化观念。
  • 拓展思考（可选）： 若导轨粗糙（动摩擦因数μ），最大速度变为v_m = (mg sinθ - μmg cosθ)R/(B²L²)，电量公式q=ΔΦ/R仍然成立，可留作课后思考题。
