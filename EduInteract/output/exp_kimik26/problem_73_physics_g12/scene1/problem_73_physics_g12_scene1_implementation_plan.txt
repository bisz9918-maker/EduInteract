[图示主题与整合说明]
- 本图示主题：倾斜导轨装置立体示意图与导体棒受力分析
- 整合的步骤/概念：装置空间认知 → 已知条件标注 → 重力/支持力/安培力三力分析 → 重力正交分解 → 平衡方程建立 → 最大速度数值求解
- 教学价值：教师通过分步导航，可逐层展开电磁感应与力学综合问题的分析过程。学生能直观看到：导体棒在倾斜导轨上下滑时，重力沿斜面的分力与安培力最终平衡，从而达到最大速度。图示将立体装置、受力分析、公式推导整合在同一画面中，避免教师在黑板多次画图。

[分步序列]
- 步骤0（初始状态）：显示装置基础图。可见元素：U形框架三边、导体棒MN、水平参考虚线、B方向箭头、θ角弧线。标签：M、N、B、θ、L。右侧信息框显示标题"倾斜导轨上的导体棒"。
- 步骤1（已知条件）：点击「下一步」。右侧信息框切换为已知条件列表：L = 1 m、θ = 30°、B = 0.2 T、m = 0.2 kg、R = 0.2 Ω，数值标签以蓝色#1565c0显示。装置上的L标签和θ弧线高亮（加粗或变色）。
- 步骤2（受力分析）：点击「下一步」。在导体棒中心(314,229)处新增三个力矢量箭头：重力mg（竖直向下，黑色）、支持力N（垂直斜面向上，绿色）、安培力F_安（沿斜面向上，红色）。同步显示标签mg、N、F_安。右侧信息框显示"受力分析：三力平衡"。
- 步骤3（重力分解）：点击「下一步」。保留步骤2的三个力。新增重力分解：从中心画mg sinθ（沿斜面向下，灰色虚线）和mg cosθ（垂直斜面向下，灰色虚线），显示对应标签。右侧信息框显示"重力分解：mg sinθ 与 mg cosθ"。
- 步骤4（平衡方程）：点击「下一步」。右侧信息框切换为公式推导内容，逐行显示：mg sinθ = F_安、F_安 = BIL、I = BLv_m / R、mg sinθ = B²L²v_m / R。装置侧mg sinθ与F_安箭头高亮（加粗）。
- 步骤5（代入求解）：点击「下一步」。右侧信息框切换为结果展示：v_m = mgR sinθ / (B²L²) = 5 m/s，其中"5 m/s"以绿色#2e7d32、20px加粗大号高亮显示。装置侧所有力矢量保持可见，最终结果标签v_m = 5 m/s在右侧框底部高亮。教师可随时点击「上一步」回退复习。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「上一步」按钮：位置(300,455)，大小70×30px，点击回退到上一步骤，步骤0时禁用。
  2. 步骤指示器：位置(400,455)，显示当前步骤编号如"步骤 2/6"。
  3. 「下一步」按钮：位置(460,455)，大小70×30px，点击前进到下一步骤，步骤5时禁用。
- 教师操作流程：
  1. 教师打开图示，首先呈现步骤0的装置基础图，讲解U形框架、导体棒、磁场方向与倾角的空间关系。
  2. 点击「下一步」进入步骤1，引导学生读取已知条件，对应数值在装置上高亮。
  3. 点击「下一步」进入步骤2，依次画出三个力，讲解各力的方向与性质（特别指出安培力阻碍相对运动）。
  4. 点击「下一步」进入步骤3，将重力分解，建立沿斜面和垂直斜面的两个方向。
  5. 点击「下一步」进入步骤4，在右侧写出平衡方程，将电磁感应公式（E=BLv、I=E/R、F=BIL）逐一代入。
  6. 点击「下一步」进入步骤5，展示最终数值结果v_m=5m/s，完成讲解。讲解过程中可随时回退到任意步骤复习。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本场景以几何图形、矢量箭头、标签文本为主，无复杂函数图或3D，原生SVG性能最优，无需引入额外库。
- 画布尺寸：800 × 500 px（沿用规格规定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------------+
  |                                                        |
  |   装置图区 (x:50~500, y:50~420)      信息框 (x:520~760) |
  |   +------------------------+        +----------------+ |
  |   |  B↗                  N |        | 已知条件/公式  | |
  |   |   M━━━━━━━棒━━━━━━━━   |        |                | |
  |   |  /                   / |        | L = 1 m        | |
  |   | / 框架            /    |        | θ = 30°        | |
  |   |/                /      |        | ...            | |
  |   A━━━━━━━━━━━━━━C━━←θ     |        | v_m = 5 m/s   | |
  |   - - - - - - - - - -      |        +----------------+ |
  |        ↑mg  ↗F_安          |                          |
  |   +------------------------+                          |
  |                                                        |
  |        [◀上一步]  步骤 2/6  [下一步▶]                  |
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `currentStep`（0~5），每一步定义一个显示元素ID数组。切换步骤时，遍历所有元素，根据当前步骤的显示列表设置 `display` 或 `opacity`。
  2. 坐标计算：所有力矢量从导体棒中心(314,229)出发，方向通过单位向量计算：斜面方向(0.866,-0.5)，垂直斜面向上(-0.5,-0.866)，沿斜面向下(-0.866,0.5)，垂直斜面向下(0.5,0.866)，竖直向下(0,1)。
  3. 动画曲线：元素出现使用CSS transition（opacity 0→1，duration 300ms，ease-in-out），力矢量箭头使用SVG marker实现箭头头部。
  4. 事件绑定：上一步/下一步按钮绑定click事件，更新currentStep后调用 `renderStep()` 函数，该函数根据步骤索引控制所有元素的显隐和右侧信息框的innerHTML。
  5. 右侧信息框：使用SVG foreignObject嵌入HTML div，或使用SVG text/tspan动态更新内容。推荐foreignObject，便于多行文本和样式控制。
  6. 按钮禁用逻辑：currentStep===0时禁用「上一步」，currentStep===5时禁用「下一步」，通过设置disabled属性和透明度0.5表示。
- ID命名规范：所有交互元素ID必须以 `scene1-` 为前缀。例如：
  - 框架边：`scene1-frame-left`、`scene1-frame-right`、`scene1-frame-bottom`
  - 导体棒：`scene1-rod-mn`
  - 力箭头：`scene1-force-mg`、`scene1-force-n`、`scene1-force-fa`
  - 分解箭头：`scene1-decomp-mgsin`、`scene1-decomp-mgcos`
  - 标签：`scene1-label-m`、`scene1-label-n-end`、`scene1-label-b`、`scene1-label-theta`、`scene1-label-l`、`scene1-label-mg`、`scene1-label-force-n`、`scene1-label-fa`、`scene1-label-mgsin`、`scene1-label-mgcos`
  - 信息框：`scene1-info-box`
  - 按钮：`scene1-btn-prev`、`scene1-btn-next`、`scene1-step-text`
  - JS中获取元素严格使用 `document.getElementById`，禁止querySelectorAll配合全局class。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免全局变量污染，确保多场景合并时互不干扰。
