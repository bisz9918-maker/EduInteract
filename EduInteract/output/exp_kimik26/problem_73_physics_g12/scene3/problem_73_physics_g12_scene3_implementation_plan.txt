[图示主题与整合说明]
- 本图示主题：导体棒沿斜面下滑的能量守恒关系与通过导体棒的电量计算
- 整合的步骤/概念：
  1) 建立斜面下滑位移x与竖直下降高度h的几何关系；
  2) 用能量转化箭头展示重力势能减少量转化为动能与电能；
  3) 列能量守恒方程求解位移x；
  4) 切换电磁感应视角，用磁通量变化阴影区展示ΔΦ=BLx；
  5) 推导电量公式q=ΔΦ/R=BLx/R；
  6) 代入数值计算结果q=4C。
- 教学价值：教师通过分步导航，先带领学生从能量观求出关键位移x，再转换到电磁感应观求电量，强化"多视角分析同一物理过程"的解题策略。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「上一步」按钮：位于(280, 458)，宽80px，高30px。点击后回退到前一个步骤，隐藏当前步骤新增的元素，恢复前一步状态。
  2. 步骤指示器：位于(400, 458)，显示当前步骤编号"步骤 k/6"（k=1~6），文字居中，无点击功能。
  3. 「下一步」按钮：位于(520, 458)，宽80px，高30px。点击后前进到下一个步骤，按序列显示对应元素。
- 边界处理：在步骤1/6时「上一步」按钮禁用（opacity 0.4，pointer-events none）；在步骤6/6时「下一步」按钮禁用。
- 教师操作流程：
  1. 教师打开图示，首先呈现步骤1（斜面基础图），讲解导体棒从初位置下滑到末位置的几何关系，指出x与h；
  2. 点击「下一步」进入步骤2，展示能量转化箭头，讲解三种能量的转化关系；
  3. 点击「下一步」进入步骤3，展示能量守恒方程，带领学生代入已知条件解出x=4m；
  4. 点击「下一步」进入步骤4，在斜面图上展示磁通量阴影区，讲解ΔΦ=BLx的物理意义；
  5. 点击「下一步」进入步骤5，展示电量公式推导，建立q与ΔΦ的联系；
  6. 点击「下一步」进入步骤6，展示最终计算结果q=4C，完成讲解；
  7. 可随时点击「上一步」回退到任意步骤复习关键公式或概念。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本场景以2D几何图形、文本标签和简单状态切换为主，无需复杂数据绑定或3D渲染，原生SVG性能最优，且便于精确控制每个元素的显示/隐藏和坐标。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  斜面区 (y=50~310)                                |
  |                                                  |
  |         N /                                      |
  |          / 导体棒初位置(虚线)                     |
  |       M /                                        |
  |        /  x                                      |
  |       /    ΔΦ                                    |
  |      /  h  [阴影区]                               |
  |     /     导体棒末位置(实线)                      |
  |    / N'                                          |
  |   /θ                                             |
  |  /                                               |
  +--------------------------------------------------+
  |  下方区 (y=320~430)                               |
  |  +--------------------+  +--------------------+  |
  |  | 能量转化           |  | 公式推导区          |  |
  |  | ↓ΔEp = ↑ΔEk + →Q_电|  | mgx·sinθ = ...     |  |
  |  |                    |  | q = BLx/R = 4C     |  |
  |  +--------------------+  +--------------------+  |
  +--------------------------------------------------+
  |  控件区 (y=440~490)                               |
  |       [上一步]  步骤 k/6  [下一步]                |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `currentStep`（0~5），每个步骤对应一个显示配置数组，数组元素为需要显示的元素ID列表。切换步骤时，先隐藏所有可选元素，再显示当前步骤对应的元素。
  2. 坐标计算：斜面线方向向量(320,-185)，单位向量(0.865,-0.5)；导体棒垂直向量(0.5,0.865)。所有导体棒端点坐标通过中心点 ± 20×垂直向量计算得出，确保严格垂直于斜面。
  3. 动画曲线：元素显示使用CSS transition `opacity 0.3s ease-in-out`；磁通阴影区使用SVG `<animate>`或CSS `clip-path`动画实现从左到右擦除效果；结果q=4C使用CSS `transform: scale()`动画。
  4. 事件绑定：上一步/下一步按钮绑定click事件，调用`updateScene(step)`函数。函数内根据`currentStep`设置各元素的`display`或`opacity`属性。
  5. 公式区内容切换：步骤2、4、5共用同一个公式文本容器，通过替换innerHTML或切换多个预置的<tspan>组实现，避免布局跳动。
  6. 控件栏使用HTML按钮绝对定位在SVG容器底部（`position: absolute; left: ...; top: ...`），不占用SVG内部坐标空间，但保持在y=440~490视觉区域内。
- ID命名规范：所有交互元素ID必须以`scene3-`为前缀。例如：
  - 斜面线：`scene3-slope-line`
  - 导体棒初位置：`scene3-rod-initial`
  - 导体棒末位置：`scene3-rod-final`
  - θ文字：`scene3-theta-text`
  - x标注：`scene3-label-x`
  - h标注：`scene3-label-h`
  - 能量箭头：`scene3-arrow-ep`、`scene3-arrow-ek`、`scene3-arrow-q`
  - 公式框：`scene3-formula-box`
  - 公式文本组：`scene3-formula-energy`、`scene3-formula-charge`、`scene3-formula-result`
  - 磁通阴影：`scene3-flux-shade`
  - ΔΦ标注：`scene3-label-delta-phi`
  - 按钮：`scene3-btn-prev`、`scene3-btn-next`
  - 步骤指示器：`scene3-step-indicator`
  JS中严格使用`document.getElementById`获取元素，禁止全局class选择，避免多场景合并时跨场景污染。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 立即执行函数中，所有变量和函数均为局部作用域。
