[图示主题与整合说明]
- 本图示主题：平行板电容器中三带电小球连杆下落的分阶段受力分析
- 整合的步骤/概念：
  1. 初始几何条件（d=3L、杆长L、三球竖直静止于上极板小孔）
  2. 分阶段进入电场的过程（0<x<L、L≤x<2L、2L≤x<3L）
  3. 各阶段受力变化（重力3mg恒定，电场力nqE随进入球数增加，合力方向与大小变化）
  4. 末状态条件（x=3L时v=0）及推论（qE=3mg/2、U=9mgL/2q、v_max=√(gL)）
- 教学价值：教师通过分步导航精确控制讲解节奏，逐步揭示"依次进入电场"导致的合力突变，配合右侧面板实时展示表达式与运动状态，帮助学生建立过程分析框架

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「◀ 上一步」按钮：位于底部控件栏左侧 (200,447)，宽100×高36。点击回退到上一阶段，步骤0时禁用（opacity 0.5，pointer-events none）
  2. 步骤指示器：位于底部控件栏中央 (400,465)，显示"步骤 0/4"，文字颜色 #555555
  3. 「下一步 ▶」按钮：位于底部控件栏右侧 (500,447)，宽100×高36。点击前进到下一阶段，步骤4时禁用
- 教师操作流程：
  1. 教师展示步骤0，说明初始几何条件（d=3L、杆长L、三球属性）
  2. 点击"下一步"进入步骤1，讲解仅球1进入电场时的受力，观察合力向下、加速
  3. 点击"下一步"进入步骤2，讲解球1、2进入电场，合力突变为零，速度达到最大
  4. 点击"下一步"进入步骤3，讲解三球均进入电场，合力向上，开始减速
  5. 点击"下一步"进入步骤4，总结末状态条件，推导电场强度、电压和最大速度
  6. 可随时点击"上一步"回退复习关键阶段（尤其是步骤2的合力为零和步骤3的减速转折）

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无外部库）。理由：本场景为静态几何图形与简单状态切换，无需复杂绘图库；原生 SVG 对箭头、圆形、文本支持完善，且便于通过 setAttribute 精确控制坐标。
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  +--------------------------------------------------------+
  | 主视图区 (0≤x≤480, 0≤y≤439)      | 右侧面板           |
  |                                  | (480≤x≤800)        |
  |    [球3] o                       | +----------------+ |
  |          | L                     | |   阶段分析      | |
  |    [球2] o                       | |   阶段名称      | |
  |          | L                     | |   ---------     | |
  | ====[球1]==== 上极板             | |   n = ?         | |
  | | 电场区域  |                    | |   F合 = ...     | |
  | |           |                    | |   合力: ...     | |
  | ============= 下极板             | |   运动状态: ... | |
  |                                  | +----------------+ |
  +--------------------------------------------------------+
  |  [◀ 上一步]      步骤 0/4      [下一步 ▶]              |
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：定义全局变量 `currentStep`（0~4），配置数组 `stepConfig[5]`，每个元素包含该步骤所有视觉元素的坐标、显示/隐藏状态、文本内容。
  2. 坐标计算：三球 x 坐标固定 250，y 坐标按步骤配置；杆通过 `<line>` 连接对应球心 ID，在 update 时同步更新 x1,y1,x2,y2。
  3. 动画曲线：小球位置变化使用 CSS `transition: cy 0.4s ease-in-out, cx 0.4s ease-in-out`；箭头显示/隐藏使用 CSS `transition: opacity 0.3s`；右侧面板文本直接切换（无动画，保证可读性）。
  4. 事件绑定：按钮点击事件在 IIFE 内绑定，更新 currentStep 后调用 `renderStep()` 统一刷新所有元素。
  5. 箭头绘制：使用 `<line>` 作为箭身，`<polygon>` 作为箭头头部（三点坐标根据方向动态计算：向下箭头尖端在 line 终点，向上箭头尖端在 line 起点）。
  6. 合力为零状态：步骤2不绘制箭头，改为在系统右侧显示绿色文字 "F合 = 0"。
  7. 步骤4附加结论：在右侧面板运动状态下方追加三行结论文本，通过额外 `<text>` 元素控制显示（仅在步骤4时 opacity=1）。
- ID 命名规范：所有 SVG 交互元素 ID 必须以 `scene1-` 为前缀。例如：
  - 球1：`scene1-ball-1`
  - 球1重力箭身：`scene1-grav-1-line`
  - 球1重力箭头：`scene1-grav-1-head`
  - 球1重力标签：`scene1-grav-1-text`
  - 右侧面板阶段名：`scene1-panel-stage`
  - 右侧面板n值：`scene1-panel-n`
  - 上一步按钮：`scene1-btn-prev`
  - 下一步按钮：`scene1-btn-next`
- IIFE 隔离：所有 JavaScript 代码包裹在 `(function() { ... })()` 中，避免多场景合并时变量污染。
