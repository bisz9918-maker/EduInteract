    **题目原文**

    如图1所示，平行金属板A和B的距离为d，它们的右端安放着垂直金属板的靶MN。现在A、B板上加上如图2所示的方波形电压，t=0时A板比B板的电势高，电压的正向值为U₀，反向值也为U₀。现有由质量为m的带正电且电荷量为q的粒子组成的粒子束，从AB的中点O以平行于金属板方向OO′的某一初速射入。设粒子能全部打在靶MN上，而且所有粒子在AB间的飞行时间均为T，不计重力影响，试问：

    1. 在距靶MN的中心O′点多远的范围内有粒子击中？
    2. 要使粒子能全部打在靶MN上，电压U₀的数值应满足什么条件？（写出U₀、m、d、q、T的关系式即可）
    3. 电场力对每个击中靶MN的带电粒子所做的总功是否相等？若相等，请证明并求出此功的数值；若不相等，求出此功的数值范围。

    **整体分析**

    本题的核心物理情景是：带电粒子在平行板电容器中运动，板间电场随时间按方波规律变化，且粒子在板间的飞行时间恰好等于电压变化周期T。粒子水平方向做匀速直线运动，竖直方向在交变电场力作用下做分段匀变速运动。

    关键难点在于：粒子束是连续入射的，不同粒子在电压周期的不同相位（入射时刻t₀）进入电场，导致它们在板间经历的正向电压和反向电压的持续时间不同，从而竖直位移不同。但由于电压方波的对称性和粒子飞行时间恰好等于周期，所有粒子的末竖直速度却恰好相同。

    **图示规划说明**

    本教学设计使用3个图示：
    1. 装置与电压波形图：帮助学生建立装置结构与交变电压的对应关系，理解电场方向变化。
    2. 粒子运动动态分析图：通过拖拽入射时刻滑块，实时观察轨迹、v-t图和击中位置的变化，建立直观认知。
    3. 定量结论图：分步展示击中范围、靶条件和功的推导过程。
    </TEXT_1>

    **教学说明：粒子运动动态分析**

    本图示是讲解本题的核心交互工具。教师应引导学生通过拖拽滑块改变入射时刻t₀，观察以下关键现象：

    1. **轨迹形状变化**：当t₀从0增加到T时，粒子轨迹先逐渐向上偏移，在t₀=2T/3时达到最高击中点，之后又向下偏移。让学生思考：为什么轨迹不是单调变化的？

    2. **末速度的不变性**：观察右侧v-t图，无论t₀如何变化，粒子飞出电场时的末竖直速度始终相同（v_y = -qU₀T/(3md)，方向向下）。这是本题最精妙的结论，也是第三问的关键。

    3. **位移的极值**：轨迹在靶上的击中位置有明确范围。最高点对应t₀=2T/3，最低点对应t₀=0（或T）。

    **推导提示（供教师讲解用）**

    设粒子在t=t₀时刻入射，竖直方向初速度为0，加速度大小恒为 a = qU₀/(md)。

    当 0 ≤ t₀ < 2T/3 时，粒子经历三段电场：
    1. t₀ ~ 2T/3：电压+U₀，加速度向下（-a），持续时间 Δt₁ = 2T/3 - t₀
    2. 2T/3 ~ T：电压-U₀，加速度向上（+a），持续时间 Δt₂ = T/3
    3. T ~ t₀+T：电压+U₀，加速度向下（-a），持续时间 Δt₃ = t₀

    末速度：v_y = (-a)Δt₁ + (+a)Δt₂ + (-a)Δt₃ = -a(2T/3 - t₀) + a(T/3) - a(t₀) = -aT/3 = -qU₀T/(3md)

    竖直位移经分段积分可得：y = (qU₀T/(md))(-7T/18 + 2t₀/3)

    当 2T/3 ≤ t₀ < T 时，类似推导得：y = (qU₀T/(md))(17T/18 - 4t₀/3)

    因此：
    - t₀ = 0 或 T 时，y_min = -7qU₀T²/(18md)（O′点下方）
    - t₀ = 2T/3 时，y_max = +qU₀T²/(18md)（O′点上方）
    </TEXT_2>

    **教学说明：定量结论与推导**

    本图示分三步给出问题的定量解答，教师应结合前两图的直观认知，引导学生完成从观察到结论的跃迁。

    **问题1：击中范围**

    由Scene 2的动态观察可知，竖直位移y是入射时刻t₀的分段线性函数：

    1. 当 0 ≤ t₀ ≤ 2T/3 时，y(t₀) = (qU₀T/(md))(-7T/18 + 2t₀/3)，单调递增
    2. 当 2T/3 ≤ t₀ ≤ T 时，y(t₀) = (qU₀T/(md))(17T/18 - 4t₀/3)，单调递减

    因此：
    - 最大值在 t₀ = 2T/3 处：y_max = qU₀T²/(18md)（O′点上方）
    - 最小值在 t₀ = 0 或 T 处：y_min = -7qU₀T²/(18md)（O′点下方）

    击中范围为：O′点上方 qU₀T²/(18md) 到下方 7qU₀T²/(18md)。

    **问题2：全部打在靶上的条件**

    靶MN的长度等于板间距d，O′为靶中心（对应O点位置）。粒子能全部打在靶上的几何约束为：

    |y_max| ≤ d/2 且 |y_min| ≤ d/2

    即：
    - qU₀T²/(18md) ≤ d/2  →  U₀ ≤ 9md²/(qT²)
    - 7qU₀T²/(18md) ≤ d/2  →  U₀ ≤ 9md²/(7qT²)

    第二个条件更严格，故电压应满足 **U₀ ≤ 9md²/(7qT²)**。

    **问题3：电场力做功是否相等**

    由Scene 2的v-t图已观察到，所有粒子的末竖直速度相同：

    v_y = -qU₀T/(3md)

    水平速度始终为v₀（电场力垂直于金属板，不影响水平运动）。根据动能定理，电场力做的总功等于粒子动能的变化：

    W = ΔE_k = ½m(v₀² + v_y²) - ½mv₀² = ½mv_y²

    代入v_y得：

    W = ½m(qU₀T/(3md))² = **q²U₀²T²/(18md²)**

    该结果与入射时刻t₀无关，因此电场力对每个击中靶的粒子所做的总功**相等**。

    **课堂讲解建议**

    建议先让学生猜测第三问答案（相等还是不相等），多数学生可能会因为"轨迹不同"而猜测"做功不等"。此时回到Scene 2的v-t图，让学生观察末速度相同的规律，再用动能定理给出严格证明，形成认知冲突和深化理解。
    </TEXT_3>
