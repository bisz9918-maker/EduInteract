[分步序列]
- 步骤0（初始状态）：显示完整装置示意图（A板、B板、MN靶、O点、O′点、OO′虚线、粒子、v₀箭头、d标注及所有装置侧标签A/B/M/N/O/O′/v₀/d）。右侧仅显示坐标轴框架（U轴、t轴、U/t标签、U₀/-U₀标签），不显示波形折线和时刻刻度标签。
- 步骤1（点击下一步）：右侧叠加显示完整方波波形折线（黑色）和时刻刻度标签（2T/3、T、5T/3、2T）。此时教师可讲解电压随时间的变化规律。
- 步骤2（点击下一步）：波形图0~2T/3段（x=480~573）叠加蓝色半透明填充；装置图叠加3条蓝色竖直电场线（A→B，向下箭头）和蓝色向下受力箭头（从粒子指向B板）；显示E标签（电场）和F标签（电场力）。此时教师讲解正向电压期间电场向下、正电荷受力向下。
- 步骤3（点击下一步）：隐藏步骤2的蓝色电场线、受力箭头和蓝色填充；波形图2T/3~T段（x=573~620）叠加红色半透明填充；装置图叠加3条红色竖直电场线（B→A，向上箭头）和红色向上受力箭头（从粒子指向A板）；显示E标签和F标签。此时教师讲解反向电压期间电场向上、正电荷受力向上。
- 步骤4（点击下一步）：隐藏电场线和受力箭头；保留完整波形图；在波形图t轴下方添加绿色双向箭头标注周期T；在画布中部下方添加绿色说明文字"粒子在板间飞行时间恰为电压周期T，不同时刻t₀进入的粒子，在板间经历的正/反向电压持续时间不同，导致竖直偏移不同"。此时教师总结飞行时间与电压周期的对应关系，为后续计算击中范围做铺垫。
- 教师可随时点击"上一步"回退到任意步骤复习。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「上一步」按钮：位于(260,455)，宽80px高30px，点击回退到上一分步，步骤0时禁用（透明度50%）
  2. 「步骤指示器」：位于(400,475)，显示当前步骤编号（如"步骤 3/5"）
  3. 「下一步」按钮：位于(460,455)，宽80px高30px，点击前进到下一分步，步骤4时禁用（透明度50%）
- 教师操作流程：
  1. 教师打开图示，首先呈现步骤0的装置结构，向学生介绍平行板、靶、粒子入射位置
  2. 点击「下一步」进入步骤1，展示方波电压波形，讲解电压周期性变化
  3. 点击「下一步」进入步骤2，高亮0~2T/3时段，同步展示向下电场和向下电场力，建立"正向电压→A高B低→电场向下→正电荷受力向下"的因果链
  4. 点击「下一步」进入步骤3，高亮2T/3~T时段，同步展示向上电场和向上电场力，建立反向因果链
  5. 点击「下一步」进入步骤4，撤去电场/受力细节，回归整体视角，强调飞行时间T与电压周期的对应关系，引出"不同时刻进入的粒子偏移不同"这一核心结论
  6. 讲解过程中可随时回退复习

[技术实现]
- JS库选择：原生SVG（使用DOM操作控制SVG元素显示/隐藏），无需额外库。理由：本场景以静态几何图形和分步显隐为主，无复杂动画或数据驱动绘图，原生SVG足够且轻量。
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  +----------------------------------------------------------+
  |                                                          |
  |  A板=======================================  M           |
  |  O●→v₀  ..............O′        U ↑                      |
  |  |  [电场线区域]        |          |  ┌──┐    ┌──┐       |
  |  |                     |          |  |  |    |  |       |
  |  B板=======================================  N           |
  |  ↑d                    |          |  |  └────┘  └────   |
  |                        |          |  └────────────────   |
  |                        |          +──────────────────→t  |
  |                        |            2T/3  T  5T/3  2T    |
  |  [步骤4说明文字区域]                                        |
  |                                                          |
  |       [上一步]      步骤 X/5      [下一步]               |
  +----------------------------------------------------------+
  画布 800×500px | 主图区 y=0~440 | 控件栏 y=440~490
  ```
- 关键实现要点：
  1. 状态机设计：使用变量`currentStep`（0~4），每次点击按钮时更新状态，调用`renderStep()`函数。`renderStep()`内先重置所有步骤专属元素为`display:none`，再根据`currentStep`值将对应元素设为`display:inline/block`。
  2. 步骤专属元素分组：
     - Group S1（步骤1）：波形折线、时刻标签（2T/3、T、5T/3、2T）
     - Group S2（步骤2）：蓝色波形填充、蓝色电场线（3条）、蓝色向下受力箭头、E标签、F标签
     - Group S3（步骤3）：红色波形填充、红色电场线（3条）、红色向上受力箭头、E标签、F标签
     - Group S4（步骤4）：绿色周期箭头、周期标注、说明文字
  3. 按钮状态：步骤0时上一步按钮设置`opacity:0.5`并禁用点击；步骤4时下一步按钮同理。
  4. 坐标计算：波形图采用固定像素坐标，t轴方向0~2T映射x=480~760（T=140px，2T/3≈93px）；U轴方向U₀映射y=100，-U₀映射y=300，0映射y=200。
  5. 电场线箭头：使用SVG `<line>` + `<polygon>`箭头，或`<path>`带marker-end。建议用`<defs>`定义蓝色和红色箭头marker，复用于电场线和受力箭头。
  6. 动画曲线：本场景无连续动画，仅分步显隐，无需缓动函数。若需增强体验，可使用CSS transition控制opacity变化（0.2s ease）。
  7. 事件绑定：按钮绑定`click`事件，在IIFE内部使用`document.getElementById`获取按钮元素。
- ID命名规范：所有交互元素ID必须以`scene1-`为前缀。例如：`scene1-plate-a`、`scene1-voltage-wave`、`scene1-field-line-1`、`scene1-btn-prev`、`scene1-step-indicator`等。JS中严格使用`getElementById`获取元素，禁止全局class选择，避免多场景合并时跨场景污染。
- IIFE隔离：所有JavaScript代码包裹在`(function() { ... })()`立即执行函数表达式中，不暴露全局变量。
