[图示主题与整合说明]
- 本图示主题：不同入射时刻粒子的运动轨迹与竖直运动学分析（高中物理·带电粒子在方波电场中的偏转）
- 整合的步骤/概念：
  1. 左侧装置视图展示粒子从O点入射后在A、B板间的分段抛物线轨迹；
  2. 右上v-t图同步展示竖直方向速度随时间（粒子自身飞行时间τ∈[0,T]）的分段线性变化；
  3. 右下y-t图同步展示竖直位移随时间的分段二次曲线变化；
  4. 通过连续滑块改变入射时刻t₀，让学生直观发现"末速度恒定、末位移随t₀变化"的规律。
- 教学价值：教师拖动滑块即可在课堂上实时演示不同入射时刻对应的轨迹形态、v-t图折线形状、y-t图曲线下面积的变化，引导学生观察末速度不变而击中点变化的规律，为后续求极值和做功问题做铺垫。

[分步序列/关键状态]
本场景为连续滑块交互，以下列出教师讲解时应重点停留的4个关键状态（滑块可停在任意位置）：

- 状态A（t₀=0，滑块最左端）：
  · 当前轨迹为红色实线，向下偏转最显著，击中靶上最低点（约y≈270px）
  · v-t图：前两段——0~2T/3红色下降线（a向下），2T/3~T蓝色上升线（a向上），终点落在绿色末速参考线y=200上
  · y-t图：红色曲线整体在y=0线下方，末位移y(T)为负的最大值
  · 参考轨迹1与当前轨迹重合（因为t₀=0是边界情况）

- 状态B（t₀=T/3，滑块中左）：
  · 当前轨迹介于两条参考轨迹之间，击中点明显上移
  · v-t图：出现三段折线（红→蓝→红），终点仍落在绿色末速参考线上
  · y-t图：曲线先下后上再下，末位移负值减小
  · 教师可提示学生观察：末速度没变，但末位移变了

- 状态C（t₀=2T/3，滑块中右）：
  · 当前轨迹达到最高击中点（约y≈160px），向上偏转最显著
  · v-t图：先蓝后红两段，起点0，先上升至最高点，再下降至绿色末速参考线
  · y-t图：红色曲线整体在y=0线上方，末位移y(T)为正的最大值
  · 参考轨迹2与当前轨迹重合（因为t₀=2T/3是另一边界情况）
  · 教师可暂停，让学生记录此时v-t图正面积与负面积的关系

- 状态D（t₀=T，滑块最右端）：
  · 当前轨迹与状态A完全重合，体现周期性
  · v-t图、y-t图均与t₀=0时相同
  · 教师可总结：t₀∈[0,T]内粒子击中范围在两条参考轨迹之间，末速度恒为v_y(T)=-qU₀T/(3md)

[交互方案]
- 交互类型：连续拖拽滑块（单滑块控制入射时刻t₀）
- 控件说明：
  · 滑块轨道：位于底部y=470，x=150~650，范围对应t₀/T∈[0,1]
  · 滑块指针：绿色圆形，随拖动实时水平移动
  · 刻度标注：0、T/3、2T/3、T四个刻度，位于轨道正下方y=490
  · 数值显示："t₀ = 0.00T"，位于滑块轨道正上方y=455，实时更新
- 教师操作流程：
  1. 教师将滑块置于最左端（t₀=0），讲解此时粒子先向下偏转再向上偏转，末速度向下；
  2. 教师缓慢向右拖动滑块，让学生观察轨迹、v-t图、y-t图的联动变化；
  3. 在t₀=2T/3处暂停，让学生发现此时击中点最高，并观察v-t图先正后负、末速度仍不变；
  4. 继续拖至最右端（t₀=T），验证周期性；
  5. 教师可多次往复拖动，强化"末速度恒定、末位移变化"的核心结论。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript（无外部库）。理由：本场景以几何图形、折线、曲线路径为主，SVG的path、polyline、circle即可满足；滑块可用HTML input[type=range]绝对定位覆盖于SVG之上，事件处理简单直接。
- 画布尺寸：800×500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------------+
  |  装置轨迹图(0,0)-(480,440)    |  v-t图(490,30)-(780,230) |
  |  A板========================|  +--------------------+  |
  |  O●·························|  |    v_y ↑           |  |
  |        ↘ 当前轨迹(红)       |  |  末速线━━━━━━(绿)  |  |
  |         ↘                   |  |      /\    / 参考  |  |
  |  B板========================|  |     /  \  /        |  |
  |           |靶MN|            |  |    /    \/ 当前    |  |
  |                             |  |   /                |  |
  |  参考轨迹(灰虚线)            |  +--------------------+  |
  |                             |  y-t图(490,240)-(780,430)|
  |                             |  +--------------------+  |
  |                             |  |    y ↑  参考(灰)   |  |
  |                             |  |  y=0 ━━━━━━(绿)    |  |

  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：仅一个状态变量`currentT0Ratio`（0~1），滑块input事件直接更新该值，触发`updateScene()`重绘所有动态元素。
  2. 物理计算核心：
     · 定义归一化加速度`a0 = qU0/(md)`，时间步长`dt = T/60`。
     · 函数`getAcc(t0, tau)`：根据`(t0+tau)%T`判断电压相位，若落在[0, 2T/3)返回`-a0`（向下），否则返回`+a0`（向上）。
     · 轨迹计算：水平方向`x = 50 + 390*(tau/T)`；竖直方向用数值积分（或分段解析解）求`y_phys(tau)`，再映射为像素`y = 200 - y_phys * (260/d)`。为保持图示清晰，代码中采用归一化绘制：设`k = q*U0*T*T/(m*d*d)`为系统参数，取`k=0.4`使轨迹在板内居中分布且不触碰极板。
     · v-t图映射：v_y=+a0*T/3对应y=80，v_y=-a0*T/3对应y=200，0线y=140。scale_v = 180/(a0*T)。
     · y-t图映射：y=0对应y_canvas=340；y=+a0*T*T/18对应y_canvas≈309；y=-5*a0*T*T/18对应y_canvas≈396。scale_y = 200*a0*T*T/d（归一化后直接用系数映射）。
  3. 路径更新：
     · 装置轨迹：每帧计算约60个采样点，生成`"M x0,y0 L x1,y1 ..."`字符串赋给path的d属性。
     · v-t图：分段线性，直接计算折点坐标生成path；填充区域需构造闭合path（从横轴起点→曲线→横轴终点→闭合）。
     · y-t图：分段二次曲线，用折线近似（每段取15个点）生成path。
  4. 动画曲线：滑块拖动无缓动，实时响应（input事件）；初始页面加载时所有元素opacity从0到1过渡300ms。
  5. 事件绑定：滑块`input`事件绑定`updateScene`；为提升性能，使用`requestAnimationFrame`节流重绘。
- ID命名规范：所有SVG元素及JS变量均以`scene2-`为前缀，例如：
  · `scene2-trajectory-current`
  · `scene2-vt-curve-current`
  · `scene2-yt-curve-ref1`
  · `scene2-hit-point`
  · `scene2-slider-thumb`
  · `scene2-slider-value`
  禁止跨场景使用全局class选择器，统一使用`document.getElementById`获取元素。
- IIFE隔离：所有JavaScript代码包裹在`(function() { ... })();`中，避免全局命名空间污染，确保多场景合并时互不干扰。
