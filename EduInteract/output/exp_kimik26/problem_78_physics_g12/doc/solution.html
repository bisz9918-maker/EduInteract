problem_78_physics_g12

场景导航：Scene 1 | Scene 2 | Scene 3

完整题目原文：

如图所示，电阻忽略不计的、两根平行的光滑金属导轨竖直放置，其上端接一阻值为3Ω的定值电阻R。在水平虚线L₁、L₂间有一与导轨所在平面垂直的匀强磁场B，磁场区域的高度为d=0.5m。导体棒a的质量mₐ=0.2kg、电阻Rₐ=3Ω；导体棒b的质量mb=0.1kg、电阻Rb=6Ω，它们分别从图中M、N处同时由静止开始在导轨上无摩擦向下滑动，且都能匀速穿过磁场区域，当b刚穿出磁场时a正好进入磁场。已知金属棒始终与导轨接触良好且导轨足够长，设重力加速度为g=10m/s²。（不计a、b之间的作用）求：

（1）a、b两棒在磁场中运动的速度大小之比；
（2）b棒穿过磁场过程，电阻R上产生的焦耳热。

题目分析：

本题是一道电磁感应综合题，涉及电磁感应、电路分析、受力平衡和能量守恒。核心条件包括：导轨光滑无摩擦、两棒都能匀速穿过磁场、两棒同时由静止释放且b刚穿出磁场时a正好进入磁场。

关键易错点： 当一根棒在磁场中切割磁感线时，另一根棒虽已穿出（或尚未进入）磁场，但仍作为导体横跨在两根导轨之间，在电路中起到与外电阻R并联的作用。许多学生容易忽略另一根棒的并联电阻效应，错误地认为外电路只有R。

整体讲解思路：

  1. 建立物理情景：通过装置图让学生理解两棒的初始位置、磁场区域和运动顺序（b先进入磁场）。
  2. 分析运动过程：自由落体阶段→匀速穿过磁场阶段，强调"匀速"意味着受力平衡（重力=安培力）。
  3. 突破电路难点：画出两种状态下的等效电路图（b在磁场中、a在磁场中），明确另一根棒的并联作用。
  4. 推导速度比：利用安培力公式和平衡条件列方程，消去未知的B和L，求得速度之比。
  5. 计算焦耳热：利用能量守恒求总热量，再根据串并联电路的功率分配比例求电阻R上的热量。

图示规划说明：

  • Scene 1：装置结构与运动过程——展示完整装置、两棒运动阶段、关键时间位置关系。
  • Scene 2：电路等效与速度比推导——两种状态下的等效电路、受力分析、公式推导。
  • Scene 3：焦耳热计算与能量分配——能量转化关系、功率分配比例、热量计算结果。
步骤 0/4

Scene 1 教学说明：装置与运动过程

本图示旨在帮助学生建立清晰的物理情景。教师应引导学生观察以下要点：

  1. 初始位置关系：a棒在M处，b棒在N处，M在N上方，因此b棒位置更低，会先进入磁场。
  2. 运动阶段划分：每根棒的运动都分为两个阶段——进入磁场前的自由落体（只受重力，匀加速），和进入磁场后的匀速直线运动（重力与安培力平衡）。
  3. 关键时间条件：步骤3展示的核心状态是"当b刚穿出磁场时a正好进入磁场"。这意味着从释放到该时刻，b棒的总运动时间（自由下落时间+匀速穿过磁场时间）等于a棒的自由下落时间（从M到L₁）。教师可写出时间关系式：

$$\frac{v_b}{g} + \frac{d}{v_b} = \frac{v_a}{g}$$
此条件在本题前两问中虽不直接用于求解，但可用于验证结果自洽或求BL的具体值。

  1. "匀速"的物理含义：步骤2和步骤4中标注的受力平衡是后续推导的出发点，教师应强调"匀速"意味着合外力为零，即安培力恰好等于重力。

讲解时建议先让学生描述两棒的运动顺序，再用图示验证，确保每个学生都理解"b先a后"的时间线。

步骤 0 / 3

Scene 2 教学说明：电路分析与速度比推导

本图示是本题的核心和难点，教师应重点引导学生突破电路结构分析。

  1. 提问引导：先让学生独立思考——当b棒在磁场中切割磁感线时，a棒在哪里？它在电路中起什么作用？
  • 正确答案：a棒已穿出磁场，位于下方导轨上，但它作为导体仍然横跨两根导轨，相当于一根阻值为Rₐ=3Ω的导线并联在电阻R两端。
  1. 等效电路画法（b棒在磁场中）：
  • b棒是电源，电动势εb = BLvb，内阻R_b = 6Ω
  • 外电路：R（3Ω）与Rₐ（3Ω）并联，等效电阻R_并 = 1.5Ω
  • 总电阻R_总b = 6 + 1.5 = 7.5Ω
  • 由平衡条件：mbg = F安 = BIL = B²L²vb/R总b
  • 得：B²L²vb = mbgR_总b = 0.1×10×7.5 = 7.5
  1. 等效电路画法（a棒在磁场中）：
  • a棒是电源，电动势ε_a = BLvₐ，内阻Rₐ = 3Ω
  • 外电路：R（3Ω）与Rb（6Ω）并联，等效电阻R并 = (3×6)/(3+6) = 2Ω
  • 总电阻R_总a = 3 + 2 = 5Ω
  • 由平衡条件：mₐg = B²L²vₐ/R_总a
  • 得：B²L²vₐ = mₐgR_总a = 0.2×10×5 = 10
  1. 求速度比：

$$\frac{v_a}{v_b} = \frac{m_a g R_{总a}}{m_b g R_{总b}} = \frac{0.2 \times 5}{0.1 \times 7.5} = \frac{10}{7.5} = \frac{4}{3}$$

  1. 强调易错点：学生常犯的错误是认为外电路只有R，忽略了另一根棒的并联作用。教师可对比两种错误分析，让学生体会差异。
步骤 1/4

Scene 3 教学说明：焦耳热计算

本图示讲解第（2）问，核心是利用能量守恒和电路功率分配求解。

  1. 能量守恒分析：

b棒匀速穿过磁场，下降高度d，动能不变。由功能关系：
$$Q_{总} = m_b g d = 0.1 \times 10 \times 0.5 = 0.5 \text{ J}$$
教师应强调：匀速条件下，重力做的功全部转化为电能，再全部转化为焦耳热。

  1. 功率分配推导（关键步骤）：

当b棒在磁场中时，等效电路为：电源（b棒，内阻R_b=6Ω）串联外电路（R=3Ω与Rₐ=3Ω并联）。
设总电流为I，则并联支路电压相等，因R=Rₐ，故：
$$I_R = I_a = \frac{I}{2}$$
各电阻功率：

  1. $P_R = I_R^2 R = (I/2)^2 \times 3 = \frac{3I^2}{4}$
  2. $P_a = I_a^2 R_a = (I/2)^2 \times 3 = \frac{3I^2}{4}$
  3. $P_b = I^2 R_b = I^2 \times 6 = \frac{24I^2}{4}$

功率比为：
$$P_R : P_b : P_a = 3 : 24 : 3 = 1 : 8 : 1$$

  1. 热量计算：

因通电时间相同，热量比等于功率比：
$$Q_R : Q_b : Q_a = 1 : 8 : 1$$
因此：
$$Q_R = Q_{总} \times \frac{1}{1+8+1} = 0.5 \times \frac{1}{10} = 0.05 \text{ J}$$

  1. 教学提示：可让学生先猜测热量主要产生在哪个电阻上，引导学生发现b棒内阻最大且通过总电流，因此产生热量最多（占80%），培养物理直觉。

总结：完整解答与课堂讲解建议

完整解答：

（1）求a、b两棒在磁场中运动的速度大小之比。

当b棒在磁场中匀速运动时，受力平衡：
$$m_b g = F_{安b} = \frac{B^2 L^2 v_b}{R_{总b}}$$
其中外电路为R与Rₐ并联：$R_{并b} = \frac{R \cdot R_a}{R + R_a} = \frac{3 \times 3}{3 + 3} = 1.5\,\Omega$
总电阻：$R_{总b} = R_b + R_{并b} = 6 + 1.5 = 7.5\,\Omega$
得：$B^2 L^2 v_b = m_b g R_{总b} = 7.5$

当a棒在磁场中匀速运动时，同理：
$$m_a g = \frac{B^2 L^2 v_a}{R_{总a}}$$
其中外电路为R与R_b并联：$R_{并a} = \frac{R \cdot R_b}{R + R_b} = \frac{3 \times 6}{3 + 6} = 2\,\Omega$
总电阻：$R_{总a} = R_a + R_{并a} = 3 + 2 = 5\,\Omega$
得：$B^2 L^2 v_a = m_a g R_{总a} = 10$

两式相比：
$$\frac{v_a}{v_b} = \frac{10}{7.5} = \frac{4}{3}$$

（2）求b棒穿过磁场过程，电阻R上产生的焦耳热。

b棒匀速穿过磁场，重力势能减少全部转化为焦耳热：
$$Q_{总} = m_b g d = 0.1 \times 10 \times 0.5 = 0.5 \text{ J}$$

当b棒在磁场中时，R与Rₐ并联且阻值相等，通过它们的电流均为总电流的一半。
功率分配比：
$$P_R : P_b : P_a = \left(\frac{I}{2}\right)^2 R : I^2 R_b : \left(\frac{I}{2}\right)^2 R_a = 3 : 24 : 3 = 1 : 8 : 1$$

因此：
$$Q_R = Q_{总} \times \frac{1}{10} = 0.5 \times 0.1 = 0.05 \text{ J}$$

课堂讲解建议：

  1. 时间分配建议：Scene 1（装置与运动）约5分钟，Scene 2（电路分析与速度比）约15分钟，Scene 3（焦耳热）约10分钟。
  2. 重点突破：将Scene 2作为课堂核心，务必让学生动手画出等效电路，再与图示对照。可设置互动提问："如果忽略另一根棒的并联作用，速度比会是多少？"（答案是3:2，与正确结果4:3不同），以此强化正确分析的重要性。
  3. 方法归纳：讲完本题后，可引导学生归纳"双棒+外阻"模型的电路分析通法——始终注意导轨上所有导体棒的连接关系。
  4. 拓展思考：可留给学有余力的学生思考——若利用时间条件$\frac{v_b}{g} + \frac{d}{v_b} = \frac{v_a}{g}$，能否求出B和L的具体值？（答案：可以，结合vₐ/vb=4/3可解得vb=1.5m/s，v_a=2m/s，进而求得BL=√5 T·m）
