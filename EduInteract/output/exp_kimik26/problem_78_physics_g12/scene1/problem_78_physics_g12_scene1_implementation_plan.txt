[图示主题与整合说明]
- 本图示主题：双导体棒在竖直光滑导轨上由静止下滑，先后匀速穿过匀强磁场区域的关键运动过程与时空关系
- 整合内容：
  1. 初始装置结构（导轨、电阻R、磁场区L₁-L₂、两棒初始位置M/N及全部已知量）；
  2. 两棒同步自由下落阶段；b棒先到达L₁；
  3. b棒匀速穿过磁场（受力平衡：mg=F_安）；
  4. 关键状态——b棒刚穿出L₂时a棒正好到达L₁的精确时空关系；
  5. a棒随后匀速穿过磁场。
- 教学价值：教师通过分步导航，引导学生按时间顺序建立物理情景，重点突出“b刚穿出时a正好进入”这一临界条件，为后续列方程求速度比和焦耳热做好铺垫。

[分步序列]
- 步骤0（初始状态）：显示完整装置。棒a在y=110(M位)，棒b在y=180(N位)。所有静态标签、磁场区、电阻均显示。轨迹与受力分析隐藏。
- 步骤1（自由下落）：点击"下一步"。棒a下移至y=180，棒b下移至y=250(到达L₁)。左侧显示灰色虚线轨迹。右侧参数标签保持。提示学生观察两棒同步自由下落。
- 步骤2（b匀速穿磁场）：点击"下一步"。棒b继续下移至y=300(磁场中间)，棒a下移至y=215。棒b加粗高亮，右侧出现b的迷你受力分析（mg向下+F_安向上），棒b右侧标注"匀速"。提示b棒受力平衡、匀速穿过。
- 步骤3（关键状态）：点击"下一步"。棒b下移至y=350(刚穿出L₂)，棒a下移至y=250(正好到达L₁)。两棒同时加粗高亮，右侧显示红色"同时刻!"标签。强调"b刚穿出时a正好进入"的精确时间位置关系，为列方程做准备。
- 步骤4（a匀速穿磁场）：点击"下一步"。棒a继续下移至y=300(磁场中间)，棒b下移至y=410(已穿出)。棒a加粗高亮，右侧切换为a的迷你受力分析，棒a右侧标注"匀速"。展示a棒同样匀速穿过磁场。
- 教师可随时点击"上一步"回退复习任一阶段。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「◀ 上一步」按钮：位于底部(300,462)，宽80×高26，点击后currentStep减1（下限0），场景回退。
  2. 步骤指示器：位于底部(390,462)，显示"步骤 X/4"文字，无点击功能。
  3. 「下一步 ▶」按钮：位于底部(460,462)，宽80×高26，点击后currentStep加1（上限4），场景前进。
- 教师操作流程：
  1. 教师打开图示，先展示步骤0完整装置，让学生读取已知条件（质量、电阻、d、R等）。
  2. 点击"下一步"进入步骤1，讲解两棒同步自由下落。
  3. 点击"下一步"进入步骤2，重点讲解b棒进入磁场后匀速运动，配合右侧受力分析说明mg=F_安。
  4. 点击"下一步"进入步骤3，强调关键临界条件"b刚穿出L₂时a正好到达L₁"，可让学生思考时间关系。
  5. 点击"下一步"进入步骤4，说明a棒随后同样匀速穿过磁场。
  6. 可随时回退到步骤3复习临界条件，或回退到步骤2复习受力分析。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本场景为静态几何装置+分步状态切换，无复杂函数绘图或3D，原生SVG足以保证清晰度且无需额外库加载。
- 画布尺寸：800×500 px（SVG viewBox="0 0 800 500"）
- 布局草图：
  ```
  +--------------------------------------------------+
  |                                                  |
  |     R=3Ω                                         |
  |    ┌──┐                                          |
  |    │R │    a  M      mₐ=0.2kg                    |
  |    └──┘    ───       Rₐ=3Ω                       |
  |    |  |    b  N      m_b=0.1kg                   |
  |    |  |    ───       R_b=6Ω                      |
  |    |  |                                          |
  | L₁-+  +----------   B                            |
  |    |××××××××××|      [受力分析区]                |
  |    |××××××××××|       (步骤2/4)                  |
  |    |××××××××××|                                 |
  | L₂-+  +----------   g=10m/s²                     |
  |    |  |                                          |
  |    |  |                                          |
  |    |  |                                          |
  |    |  |                                          |
  |    |  |                                          |
  +--------------------------------------------------+
  |        [◀ 上一步]  步骤 X/4  [下一步 ▶]          |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `let currentStep = 0;`（范围0~4）。`updateScene()`函数根据currentStep统一控制所有SVG元素的显示/隐藏、坐标更新、高亮类名切换。
  2. 坐标计算：棒的位置通过直接修改`<line>`元素的`y1`、`y2`属性实现。为提高性能，所有位置数据预存在配置对象中，如`positions[step].barA = {y: 110}`。
  3. 动画曲线：分步导航以瞬间切换为主，保证教学节奏可控；在棒位置变化时可添加极短CSS transition（transform或opacity仅用于显隐，位置变化不用transition避免延迟）。
  4. 事件绑定：上一步/下一步按钮绑定click事件，更新currentStep后调用updateScene()，并同步更新步骤指示器文字与按钮禁用状态（步骤0时禁用"上一步"，步骤4时禁用"下一步"）。
  5. 受力分析显隐：步骤2显示b的受力分析并隐藏a的；步骤4显示a的受力分析并隐藏b的；其余步骤隐藏整个受力分析组。
  6. 轨迹虚线：步骤1~4均显示，其终点y坐标随当前棒位置实时更新，起点固定为步骤0的初始位置。
  7. 高亮实现：通过切换CSS类名实现stroke-width加粗（5px或6px）及SVG filter(drop-shadow)外发光。
- ID命名规范：所有交互元素ID必须以`scene1-`为前缀。例如：`scene1-rod-left`、`scene1-rod-right`、`scene1-resistor`、`scene1-field-rect`、`scene1-line-l1`、`scene1-line-l2`、`scene1-bar-a`、`scene1-bar-b`、`scene1-trace-a`、`scene1-trace-b`、`scene1-force-group`、`scene1-force-bar`、`scene1-force-gravity`、`scene1-force-ampere`、`scene1-label-ra`、`scene1-label-ma`、`scene1-label-rb`、`scene1-label-mb`、`scene1-label-b`、`scene1-label-g`、`scene1-label-uniform`、`scene1-label-simultaneous`、`scene1-btn-prev`、`scene1-btn-next`、`scene1-step-text`。JS中严格使用`document.getElementById`获取元素，禁止全局class查询。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免多场景合并时的变量污染。
