[图示主题与整合说明]
- 本图示主题：b棒穿过磁场过程的能量转化与焦耳热分配
- 整合内容：重力做功与能量守恒、等效电路功率分配、热量分配可视化、最终结果
- 教学价值：教师通过分步导航，带领学生从物理过程（重力做功）→能量守恒（势能全部转化为焦耳热）→电路功率分配（并联电阻电流分配）→热量分配结果，完整理解"总热量→功率比→各电阻热量"的逻辑链。每步可回退复习，适合课堂逐步讲解。

[分步序列]
- 步骤0（初始状态/物理过程）：显示装置图（b棒在磁场中匀速下降），标注重力做功W=m_bgd=0.5J、磁场高度d=0.5m、速度v_b。能量流程图、电路图、饼图、结果框均隐藏。上一步按钮禁用。
- 步骤1（能量守恒）：装置图保留但透明度降至0.4（淡化）。新增显示能量流程图：势能节点（E_p）→蓝色箭头→电能节点（⚡）→蓝色箭头→热能节点（Q），下方标注ΔE_p=0.5J、匀速→ΔE_k=0、Q_总=0.5J。电路图、饼图、结果框仍隐藏。
- 步骤2（功率分配）：装置图透明度0.3，能量流程图透明度0.4。新增显示等效电路图：b棒为电源（绿色，内阻R_b=6Ω），外电路R（棕色3Ω）与R_a（红色3Ω）并联；标注电流I、I/2、I/2；下方显示功率公式P_R=(I/2)²R、P_b=I²R_b、P_a=(I/2)²R_a及比例1:8:1。饼图、结果框仍隐藏。
- 步骤3（结果展示）：装置图透明度0.2，能量流程图透明度0.3，电路图透明度0.4。新增显示热量分配饼图（三扇区）及标注线标签Q_R=0.05J、Q_b=0.40J、Q_a=0.05J；新增结果高亮框（蓝色边框）内写Q_R = 0.05J，高亮最终答案。下一步按钮禁用（或变为"完成"）。
- 教师可随时点击「上一步」回退，回退时当前步骤新增元素隐藏，前序元素恢复高亮透明度。

[交互方案]

- 控件说明：
  - 「◀ 上一步」按钮：位置(310,455)，大小80×30。点击回退到前一步，隐藏当前步骤元素，恢复前序元素高亮。
  - 「下一步 ▶」按钮：位置(430,455)，大小80×30。点击推进到下一步，显示下一步元素并高亮，前序元素淡化。

[技术实现]
- JS库选择：原生SVG（首选）。本场景以几何图形、电路符号、饼图为主，无复杂函数绘图或3D需求，原生SVG足够且轻量。
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  +----------------------------------------------------------+
  | [装置图]      [能量流程图: E_p → ⚡ → Q]                 | y=35~135
  | 导轨+b棒      ΔE_p=0.5J  匀速→ΔE_k=0  Q_总=0.5J         |
  |                                                          |
  | [等效电路图]              [功率公式]                      | y=145~320
  |  b电源(R_b)               P_R=(I/2)²R  P_b=I²R_b        |
  |   R || R_a                P_a=(I/2)²R_a  1:8:1          |
  |                                                          |
  | [饼图]          [结果框]                                 | y=330~430
  | Q_b=0.40J    Q_R=0.05J    Q_R = 0.05J                   |
  |              Q_a=0.05J                                   |
  |                                                          |
  |        [◀ 上一步]    [下一步 ▶]                          | y=455
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量currentStep（0~3）控制当前步骤。每一步对应一组SVG元素的显示/隐藏及透明度。
  2. 元素分组：将各步骤元素分别包裹在g元素中，赋予id如scene3-step0-group、scene3-step1-group等，通过设置group的display或opacity属性控制整体显隐。
  3. 饼图绘制：使用SVG path的arc命令（A指令）绘制三扇区。中心(300,380)，半径40。角度计算：x=cx+r·cosθ, y=cy−r·sinθ（SVG坐标系）。扇区：Q_R 0°~36°（棕），Q_b 36°~324°（绿），Q_a 324°~360°（红）。
  4. 电阻符号：用polyline或path绘制zigzag锯齿线（5~6个折点）表示电阻，比矩形更专业。
  5. 动画曲线：步骤切换时使用CSS transition或JS定时器改变opacity，持续200ms，实现平滑淡入淡出。
  6. 事件绑定：为scene3-prev-btn、scene3-next-btn绑定click事件，更新currentStep后调用render()函数重新设置各group的opacity和display。
  7. 按钮状态：步骤0时上一步按钮置灰（opacity=0.4，pointer-events=none）；步骤3时下一步按钮置灰。
- ID命名规范：所有交互元素ID必须以scene3-为前缀。例如：scene3-step0-group、scene3-energy-arrow1、scene3-circuit-source、scene3-pie-qr、scene3-prev-btn、scene3-next-btn、scene3-result-box。JS中使用getElementById获取，禁止querySelectorAll配合全局class。
- IIFE隔离：所有JavaScript代码包裹在 (function() { ... })() 中，避免多场景合并时变量污染。
