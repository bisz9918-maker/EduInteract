[图示主题与整合说明]
- 本图示主题：最低点松手后的平抛运动及浮台水平距离计算
- 整合的步骤/概念：松手瞬间状态 → 平抛轨迹 → 运动分解（水平匀速+竖直自由落体） → 几何关系（d的构成） → 联立求解
- 教学价值：教师通过分步导航，逐步揭示平抛运动的分运动独立性、几何量合成与代数求解过程，帮助学生建立"化曲为直"的物理思维。

[分步序列]
- 初始状态（步骤0）「松手瞬间」：
  显示岸边缘、岸面、水面、O点及标签、绳OB（虚线）、B点及标签、速度v箭头及标签、H-l标注线及标签、浮台及标签。
  隐藏抛物线、C点、参考线、箭头、公式区。
  
- 步骤1「平抛轨迹」：
  新增抛物线轨迹（B→C，蓝色绘制动画）、C点圆点及标签。
  其余元素保持。
  
- 步骤2「运动分解」：
  新增水平参考线（B点高度向右延伸，虚线）、竖直参考线（C点向上延伸，虚线）、竖直下落箭头（从B高度向下到C，红色）。
  新增分运动公式标签："x=vt"（蓝色，水平参考线右侧）、"H−l=½gt²"（绿色，竖直参考线右侧）、"t=0.6s"（蓝色，竖直箭头右侧）、"g"（绿色，竖直箭头上部右侧）。
  其余元素保持。
  
- 步骤3「几何关系」：
  新增三条引线（从岸边缘x=184、B点x=280、C点x=424向下到y=385）。
  新增 y=385 水平双向箭头两段：岸边缘→B（黑色，l·sinα=1.6m）、B→C（蓝色，x=2.4m）。
  新增 y=420 总水平双向箭头：岸边缘→C（红色，d=4.0m）。
  其余元素保持。
  
- 步骤4「计算结果」：
  新增右侧公式区背景矩形 (#f5f5f5)。
  新增公式文本（foreignObject 或 text）：
    平抛运动分解
    水平：x = vt
    竖直：H−l = ½gt²
    代入：1.8 = ½ × 10 × t²  →  t = 0.6 s
    x = 4 × 0.6 = 2.4 m
    d = l·sinα + x = 1.6 + 2.4 = 4.0 m
  其中 t=0.6s、x=2.4m 蓝色高亮，d=4.0m 红色高亮加粗。
  其余元素保持。
  
  教师可随时点击「上一步」回退复习。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「上一步」按钮：位于容器底部左侧 (280,460)，100×36px，点击回退到上一状态。
  2. 「下一步」按钮：位于容器底部右侧 (420,460)，100×36px，点击前进到下一状态。
  3. 步骤指示器：位于两按钮之间上方 (360,495)，显示 "步骤 0/4" ~ "步骤 4/4"。
- 教师操作流程：
  教师先展示步骤0，讲解松手瞬间的速度与高度条件；点击「下一步」进入步骤1，展示平抛轨迹；继续点击依次揭示运动分解、几何关系、最终计算结果。讲解过程中可随时回退到任意步骤复习。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript。理由：本场景以静态几何图形、路径、箭头和文本为主，无复杂函数绘图或3D，原生 SVG 足够且轻量。
- 画布尺寸：800 × 500 px（固定画布）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  y=0    +--------------------------------------------------------+
         |                                                        |
  y=130  |              O                                         |
         |              |                                         |
  y=190  |    岸面_____|                                         |
         |    |       |                                          |
  y=250  |    |       B ----> v                                  |
         |    |       |  \                                       |
         |    |       |   \  抛物线                              |
         |    |       |    \                                    |
  y=338  |    |       |     \      [====浮台====]                |
  y=358  |    |       |      \     |           |C               |
         |    |       |       \    |           |                |
         |    |       |        \   |           |                |
  y=385  |    |<--l·sinα-->|<---x--->|         |                |
         |    |           |           |         |                |
  y=420  |    |<----------d---------->|         |                |
         |    |                        |  [公式区]               |
  y=460  |         [上一步]      [下一步]                        |
  y=500  +--------------------------------------------------------+
         x=120   184  280       424    520          780
  ```
  控件栏在 SVG 外通过 absolute 定位叠在底部，不占用 SVG 内部坐标空间。

- 关键实现要点：
  1. 状态机设计：变量 `currentStep` 取 0~4，每步维护一个显示元素 ID 列表。切换步骤时，将目标步骤对应元素设为 `display: block` 或 `opacity: 1`，非目标步骤元素隐藏。
  2. 抛物线轨迹坐标计算：物理映射比例 60px/m。B(280,250)，C(424,358)。轨迹方程 y = 250 + (x−280)²/192。用 JS 循环生成 path 的 `L` 命令点序列（步长 4px），确保曲线精确平滑。
  3. 箭头头部：使用 SVG `<marker>` 定义 arrowhead，分别绑定黑、蓝、红三色。
  4. 动画曲线：步骤切换时，新增元素使用 CSS `transition: opacity 0.3s ease` 淡入；抛物线轨迹可使用 stroke-dasharray + stroke-dashoffset 实现绘制动画。
  5. 事件绑定：上一步/下一步按钮绑定 click 事件，调用 `setStep(n)` 函数。边界处理：步骤0时禁用「上一步」，步骤4时禁用「下一步」。
  6. 公式区：使用 SVG `<foreignObject>` 嵌入 HTML `<div>`，便于排版多行公式与高亮样式。

- ID 命名规范：所有 SVG 元素及控件 ID 必须以 `scene2-` 为前缀，例如 `scene2-point-b`、`scene2-trajectory`、`scene2-btn-next`。JS 中严格使用 `document.getElementById` 获取元素，禁止全局 class 选择，避免多场景合并时跨场景污染。

- IIFE 隔离：所有 JavaScript 代码包裹在 `(function() { ... })()` 立即执行函数中，内部状态与函数不暴露到全局作用域。
