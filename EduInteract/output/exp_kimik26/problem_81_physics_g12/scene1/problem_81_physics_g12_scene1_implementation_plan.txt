[图示主题与整合说明]
- 本图示主题：初始平衡状态下物体A、B的受力分析与弹簧初始伸长量
- 整合的步骤/概念：装置几何结构 → A的四力平衡 → B的两力平衡 → 平衡方程联立 → 胡克定律求弹簧伸长量x₀
- 教学价值：教师可逐步引导学生从直观装置观察过渡到抽象受力分析，最终推导出弹簧初始伸长量x₀ = √3 mg/(2k)，为后续简谐运动振幅做铺垫。分步导航允许教师根据课堂节奏控制信息披露，随时回退复习。

[分步序列]
- 初始状态（步骤0）——装置几何：
  显示完整装置（地面、墙壁、弹簧、A、滑轮、绳子、B、30°角弧），所有静态标签（A、B、m、m、30°、O、k）可见。无受力箭头，无方程，无高亮。教师可讲解装置结构与几何关系。

- 步骤1——A的受力分析：
  点击「下一步」→ 物体A高亮（蓝色填充透明度从20%增至50%，边框加粗至3px）。新增A的四个受力箭头（mg向下、N向上、F_s向左、T向右上30°）及对应标签（mg、N、F_s、T），淡入动画0.3s。教师讲解A处于四力平衡。

- 步骤2——B的受力分析：
  点击「下一步」→ A的高亮取消（恢复初始状态），A的受力箭头保留但透明度降至40%（保持可见作对照）。物体B高亮（红色填充透明度从20%增至50%，边框加粗至3px）。新增B的两个受力箭头（mg向下、T向上）及对应标签，淡入动画0.3s。教师讲解B的两力平衡，并得出T = mg。

- 步骤3——平衡方程：
  点击「下一步」→ B高亮取消。A、B的受力箭头均保留但透明度降至30%。右侧显示平衡方程文本（黑色），逐行淡入：
  第1行："对B：T = mg"
  第2行："对A水平：T·cos30° = F_s"
  第3行："对A竖直：N + T·sin30° = mg"
  第4行："联立得：F_s = mg·cos30°"
  教师引导学生联立方程。

- 步骤4——弹簧伸长量（结论）：
  点击「下一步」→ 右侧方程文本保留但透明度降至50%。新增结论公式（绿色#2e7d32，字号加大）：
  "由胡克定律：F_s = k·x₀"
  "∴ x₀ = √3·mg / (2k)"
  同时在弹簧右侧添加绿色标注"x₀ = √3 mg/(2k)"（坐标260,325），并用细绿线引线指向弹簧中部。教师强调此x₀即为后续简谐运动的振幅。

- 教师可随时点击「上一步」回退，回退时当前步骤新增元素淡出，前一步元素恢复。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「上一步」按钮：位于底部(280,450)-(360,480)，点击回退到前一步，步骤0时禁用（灰色）
  2. 步骤指示器：位于底部(370,450)-(430,480)，显示"步骤 1/5"至"步骤 5/5"文本
  3. 「下一步」按钮：位于底部(440,450)-(520,480)，点击前进到下一步，步骤4（最后一步）时禁用
- 教师操作流程：
  1. 加载后呈现步骤0（纯装置），教师讲解物理情景与几何关系
  2. 点击「下一步」进入步骤1，聚焦A的受力，教师逐一分析四个力的方向与性质
  3. 点击「下一步」进入步骤2，聚焦B的受力，教师利用B的平衡得出T = mg
  4. 点击「下一步」进入步骤3，展示联立方程，教师板书推导F_s = mgcos30°
  5. 点击「下一步」进入步骤4，展示胡克定律应用与最终结论，教师强调x₀即振幅
  6. 可随时点击「上一步」回退复习，形成闭环教学

[技术实现]
- JS库选择：原生SVG + 原生JavaScript（无需额外库）。理由：本场景为静态几何图形与简单状态切换，SVG的marker、path、rect、text足以表达所有元素，原生JS状态机即可控制分步，避免引入不必要依赖。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  0    100  200  300  400  500  600  700  800
  0    +----+----+----+----+----+----+----+----+
  100  |         天花板/滑轮O                  |
  200  |    墙    /    绳子30°                  |
  300  |   [弹簧]-[A]=======\                  |
  350  |__________/__________\__[地面]__________|
  400  |                       [B]    | 公式区  |
  440  |                              |         |
  500  |        [◀上一步] [步骤] [下一步▶]      |
       +----+----+----+----+----+----+----+----+
  ```
  主装置区：x=50~550, y=170~400（占画布左中）
  公式/结论区：x=580~780, y=180~400（占画布右侧）
  控件栏：y=440~490（SVG内底部，不额外占空间）

- 关键实现要点：
  1. 状态机设计：定义常量STEP_COUNT = 5，当前状态currentStep（0~4）。每一步定义可见元素集合（visibleIds）和高亮元素集合（highlightIds）。切换步骤时遍历所有元素，设置display/opacity class。
  2. 坐标计算：绳子角度严格按30°计算，A端(240,340)，滑轮端(500,190)，dx=260, dy=150，tan⁻¹(150/260)≈30°。所有受力箭头方向据此确定。
  3. 动画曲线：使用CSS transition: opacity 0.3s ease-in-out。步骤切换时，新元素从opacity:0到1，退出元素从1到0。
  4. 事件绑定：上一步/下一步按钮绑定click事件，更新currentStep后调用render()。render()根据当前步骤为各元素添加/移除data-step-visible和data-step-highlight属性。
  5. SVG结构：使用<defs>定义箭头marker（id="scene1-arrow-blue"、"scene1-arrow-red"、"scene1-arrow-black"），受力箭头通过marker-end引用。
  6. 弹簧绘制：使用<path>或<polyline>手动计算锯齿节点坐标，8齿，每齿水平跨度15px，竖直振幅±10px。
  7. 公式文本：使用<tspan>或分组<text>实现多行右侧面板，步骤3和步骤4的文本初始display:none，由状态机控制显示。

- ID命名规范：所有交互元素ID必须以`scene1-`为前缀。例如：
  - 图形元素：scene1-ground, scene1-wall, scene1-spring, scene1-block-a, scene1-block-b, scene1-pulley, scene1-rope-a, scene1-rope-b
  - 标签：scene1-label-a, scene1-label-b, scene1-label-m-a, scene1-label-m-b, scene1-label-angle, scene1-label-o, scene1-label-k
  - 受力：scene1-force-a-mg, scene1-force-a-n, scene1-force-a-fs, scene1-force-a-t, scene1-force-b-mg, scene1-force-b-t
  - 公式：scene1-eq-b, scene1-eq-a-h, scene1-eq-a-v, scene1-eq-fs, scene1-conclusion-hooke, scene1-conclusion-x0, scene1-conclusion-spring-label
  - 控件：scene1-btn-prev, scene1-btn-next, scene1-step-indicator
  - JS中严格使用document.getElementById()获取元素，禁止querySelectorAll配合全局class。

- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免多场景合并时变量污染全局作用域。
