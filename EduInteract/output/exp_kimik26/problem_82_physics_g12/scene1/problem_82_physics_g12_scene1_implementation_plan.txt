[视觉元素清单]
- 斜面：直角三角形，直角在右下 D(650,400)，竖直直角边高 200px（对应物理量 L），底边水平长 200√3≈346px，斜边从右上 A(650,200) 到左下 C(304,400)，倾角 30°。
- 三小球：A（蓝 #1565c0，顶端）、B（红 #c62828，中点）、C（绿 #2e7d32，底端），半径 12px，黑色边线。
- 两根轻绳：连接 A-B 与 B-C，黑色 1.5px 实线，长度均等于斜面高 L（200px）。
- 弧形挡板：位于 A 球右上方，灰色 #888 虚线 2px，四分之一圆弧，表示 A 球只能竖直向下运动。
- 地面：斜面下方水平线 y=420，标注"地面"。
- 已知条件标注：质量 3m/2m/m、绳长 L、斜面高 L、倾角 30°。
- 待求量高亮：黄色半透明矩形框 + 问号文字（Step 4 出现）。
- 配色严格沿用 scene_outline：背景 #ffffff，斜面填充 #f5f5f5，角度弧 #1565c0，高亮 #ffeb3b（20% 透明）边线 #f9a825，文字全黑 sans-serif。

逐对检查（间距 < 20px 视为冲突）：
- "A" 与 "3m"：中心距 √(20²+13²)≈24px，字框水平间隙 1px，垂直间隙 3px → 不冲突（已错开）。
- "B" 与 "2m"：中心距 √(25²+10²)≈27px → 不冲突。
- "C" 与 "m"：中心距 √(15²+15²)≈21px → 不冲突（已分散为左上/正上）。
- "m" 与 "30°"：中心距 √(41²+10²)≈42px → 不冲突。
- "竖直向下" 与 "A"：中心距 √(15²+40²)≈43px → 不冲突。
- "v_A = ?" 与 "3m"：中心距 √(5²+28²)≈28px → 不冲突。
- "v_A = ?" 与 "竖直向下"：中心距 √(0²+25²)=25px → 不冲突。
- "v_C = ?" 与 "m"：中心距 √(30²+25²)≈39px → 不冲突。
- "v_C = ?" 与 "C"：中心距 √(45²+40²)≈60px → 不冲突。
- "W = ?" 与 "B"：中心距 √(7²+15²)≈17px → 字框水平间隙 0px（452 vs 463），垂直间隙 1px（273 vs 272）→ 存在轻微重叠风险。
  解决方案：将 "W = ?" 调整为 (477,260)，字框 452–502 × 252–268；与 "B" 字框 463–477 × 272–288 的垂直间隙 4px，水平无重叠 → 安全。
- "W = ?" 与 "2m"：中心距 √(18²+30²)≈35px → 不冲突。
- "地面" 与 高亮框 C（214,385,90,25）底边 410：字框底边 443，间距 33px → 不冲突。
- 所有标签与对应球体：标签均位于球体外侧，最近 "A" 距 A 球顶 13px，"C" 距 C 球顶 28px，无重叠。

结论：经调整后，所有标签间距均满足 ≥ 12px，无重叠。

[交互方案]
- 交互类型：分步按钮导航（◀ 上一步 / 下一步 ▶）
- 控件说明：
  1. 「上一步」按钮：位于控件栏左侧 (280,455)，宽 80×30，点击回退一个步骤，到 0 时禁用。
  2. 「步骤指示」文本：位于控件栏居中 (400,475)，显示当前步骤编号（如"步骤 1 / 5"）。
  3. 「下一步」按钮：位于控件栏右侧 (440,455)，宽 80×30，点击前进一个步骤，到 4 时禁用。
- 教师操作流程：
  1. 教师打开图示，学生看到空白斜面+地面（步骤 0）。
  2. 教师点击「下一步」，出现三球与绳，提问"系统由哪些物体组成？"
  3. 教师点击「下一步」，出现全部已知条件标注，引导学生列出已知量：质量、绳长、斜面高、倾角。
  4. 教师点击「下一步」，出现弧形挡板与竖直向下箭头，强调"A 球只能竖直向下运动"这一关键约束。
  5. 教师点击「下一步」，三个黄色高亮框出现，明确本题的 three 个待求目标，随后可转入公式推导。
  6. 讲解中可随时回退复习。

[技术实现]
- JS 库选择：原生 SVG（简单几何与分步显隐，无需引入外部库，减少依赖）。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图（ASCII）：
  ```
  0    100  200  300  400  500  600  700  800
  +----+----+----+----+----+----+----+----+  0
  |                                    [挡板]  |
  |         A(3m) ●                    [竖直]  |  200
  |              / \                   [向下]  |
  |             /   \                          |
  |    L     B(2m)●  \  L                    |  300
  |           /       \                        |
  |          /         \                       |
  |    30° C(m)●________\_________|          |  400
  |    [地面]__________________________        |  420
  |                                            |
  |    [◀ 上一步]  步骤 X / 5  [下一步 ▶]      |  455
  +----+----+----+----+----+----+----+----+  500
  ```
- 关键实现要点：
  1. 状态机：变量 `currentStep` 取 0–4，初始为 0。
  2. 分组显隐：SVG 中使用 5 个 `<g>` 分组，id 分别为 `scene1-step-0` 到 `scene1-step-4`。每个组包含该步骤应显示的元素。切换步骤时，遍历 5 个组，仅当前步骤组设置 `display: block`，其余 `display: none`。
  3. 按钮状态：`currentStep === 0` 时禁用「上一步」；`currentStep === 4` 时禁用「下一步」。禁用样式为 opacity 0.4 + cursor not-allowed。
  4. 步骤指示器：动态更新文本内容为 `步骤 ${currentStep + 1} / 5`。
  5. 高亮框：使用 `<rect>` 元素，fill="#ffeb3b"，fill-opacity="0.2"，stroke="#f9a825"，stroke-width="1.5"，rx="4"（圆角）。
  6. 箭头：使用 `<marker>` 定义箭头符号，在竖直向下线段上引用。
  7. 角度弧：使用 `<path>` 的 A 命令绘制，确保方向正确（SVG 坐标系 y 向下，sweep-flag=0 表示逆时针）。
  8. 弧形挡板：使用 `<path>` 的 A 命令，M 650 185 A 20 20 0 0 1 665 200，stroke-dasharray="5,3" 实现虚线。
- ID 命名规范：所有 SVG 元素及控件必须以 `scene1-` 为前缀。例如：
  - 斜面：`scene1-slope`
  - A 球：`scene1-ball-a`
  - 绳 AB：`scene1-rope-ab`
  - 步骤 2 分组：`scene1-step-2`
  - 上一步按钮：`scene1-btn-prev`
  - 步骤文本：`scene1-step-text`
  JS 中严格使用 `document.getElementById` 获取，禁止全局 class 查询，避免多场景合并时污染。
- IIFE 隔离：所有 JavaScript 代码包裹在 `(function() { ... })();` 中，不暴露全局变量。
