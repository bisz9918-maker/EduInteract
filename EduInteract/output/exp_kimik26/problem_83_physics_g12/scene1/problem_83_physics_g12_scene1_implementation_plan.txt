[图示主题与整合说明]
- 本图示主题：子弹射入滑块瞬间的动量守恒过程（高中物理力学综合题）
- 整合的步骤/概念：
  1. 初始匀速状态：小车(M)与滑块(m)整体以 v₁=10m/s 向右运动，弹簧原长，子弹(m₀)待射入；
  2. 射入瞬间分析：强调"时间极短"，子弹与滑块组成系统动量守恒，弹簧弹力与摩擦力冲量可忽略；
  3. 共同速度计算：子弹嵌入滑块后，二者以共同速度 v₂=4m/s 向右运动，展示动量守恒方程与代入数值。
- 教学价值：教师可通过分步导航控制讲解节奏，逐步引导学生从情景识别→条件提取→公式应用，强化"瞬间过程动量守恒"的物理观念。

[分步序列]
- 初始状态（步骤0）：显示题目基础条件
  * 可见元素：地面、小车（含轮子、左挡板）、滑块、弹簧（原长）、子弹（滑块右侧圆形）、质量标签（M/m/m₀）、小车上方 v₁ 箭头（蓝色）、"光滑水平面"标签
  * 隐藏元素：滑块v₁箭头、子弹v₀箭头、高亮框、提示框、公式框、滑块v₂箭头、嵌入子弹
  * 教学意图：建立初始情景，明确整体匀速、弹簧原长、子弹待射入

- 步骤1：点击「下一步」→ 聚焦射入瞬间的动量守恒条件
  * 新增/变化：
    - 滑块上方出现 v₁=10m/s 箭头（蓝色，向右）
    - 子弹右侧出现 v₀=50m/s 箭头（红色，向左），箭头长度明显长于 v₁
    - 滑块与子弹外围出现绿色虚线高亮框，强调"子弹+滑块"系统
    - 画面上方弹出提示框："时间极短：弹簧力与摩擦力冲量可忽略"
  * 保留元素：步骤0所有元素（小车v₁箭头仍保留，表示小车速度暂未变化）
  * 教学意图：引导学生识别研究对象与守恒条件，区分内力与外力

- 步骤2：点击「下一步」→ 展示共同速度与动量守恒方程
  * 新增/变化：
    - 滑块v₁箭头与子弹v₀箭头隐藏
    - 子弹外形由右侧圆形变为滑块内部矩形，表示"嵌入"
    - 滑块上方出现 v₂=4m/s 箭头（绿色，向右），长度短于 v₁，直观展示速度减小
    - 小车v₁箭头隐藏（避免与公式区拥挤，且本步重点在滑块+子弹系统）
    - 高亮框与提示框隐藏
    - 画面下方公式框出现：
      第一行：m·v₁ - m₀·v₀ = (m+m₀)·v₂
      第二行：1.8×10 - 0.2×50 = 2.0×4 = 8
  * 保留元素：地面、小车、滑块、弹簧、质量标签、嵌入子弹、光滑水平面标签
  * 教学意图：呈现计算结果与公式，完成从物理情景到数学表达的闭环

- 教师可随时点击「上一步」回退至步骤1或步骤0复习

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无外部库）。理由：本场景为静态几何图示与分步显隐控制，无需复杂数据绑定或3D渲染，原生SVG性能最优、依赖最少。
- 画布尺寸：800 × 500 px（固定画布，SVG viewBox="0 0 800 500"）
- 布局草图：
  ```
  +--------------------------------------------------------+
  |  [提示框 240,100 320x50]  (步骤1)                      |
  |                                                        |
  |       v₁=10m/s (小车箭头)                              |
  |            ↑                                           |
  |  M=2kg   +------------------------------------+        |
  |          | 小车(浅蓝)                         |        |
  |          |    ~~~~弹簧~~~~  [滑块] [子弹○]    |        |
  |          |  ○            ○  (浅橙) (浅红)     |        |
  |          +------------------------------------+        |
  |               v₁=10m/s (滑块,步骤1)                    |
  |                            v₀=50m/s (步骤1)            |
  |  ================================================= 地面 |
  |              光滑水平面                                |
  |  [公式框 140,405 520x50] (步骤2)                       |
  |                                                        |
  |        [◀ 上一步]    [下一步 ▶]                        |
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `let currentStep = 0;` 记录当前步骤（0/1/2）。每次点击按钮时更新状态，调用 `renderStep()` 函数根据状态显隐元素。
  2. 元素显隐控制：为所有步骤相关元素设置 `id`，在 `renderStep()` 中通过 `document.getElementById()` 获取并设置 `display` 属性（'block'/'none'）或 `opacity` + `visibility`。避免使用 CSS class 切换，防止多场景合并时 class 名冲突。
  3. 箭头 Marker：在 SVG `<defs>` 中定义两个 `<marker>`（id="scene1-arrow-blue"、"scene1-arrow-red"、"scene1-arrow-green"），分别对应不同颜色箭头，设置 `marker-end` 引用。
  4. 弹簧绘制：使用 SVG `<path>` 通过多次 `l` 命令绘制锯齿/螺线形，例如 `M 190 315 l 10 -10 l 10 20 l 10 -20 ...` 重复至终点，模拟弹簧外观。
  5. 坐标计算：所有坐标硬编码为常量，不依赖动态计算，确保代码 agent 可直接复制坐标值。
  6. 动画曲线：本场景为分步切换，无需连续动画；步骤切换采用即时显隐（无淡入淡出），保证教学讲解的即时响应。如需柔和过渡，可为 opacity 添加 0.2s CSS transition。
  7. 事件绑定：按钮使用 `onclick` 属性直接绑定 IIFE 内函数，避免全局命名空间污染。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀。示例：
  - 小车：`scene1-cart`
  - 滑块：`scene1-block`
  - 子弹(外)：`scene1-bullet-out`
  - 子弹(内)：`scene1-bullet-in`
  - 弹簧：`scene1-spring`
  - 箭头-小车v₁：`scene1-arrow-v1-cart`
  - 箭头-滑块v₁：`scene1-arrow-v1-block`
  - 箭头-子弹v₀：`scene1-arrow-v0`
  - 箭头-共同v₂：`scene1-arrow-v2`
  - 高亮框：`scene1-highlight-box`
  - 提示框：`scene1-tip-box`
  - 公式框：`scene1-formula-box`
  - 按钮：`scene1-btn-prev`、`scene1-btn-next`
- IIFE 隔离：所有 JavaScript 代码包裹在 `(function() { ... })();` 中，确保变量与函数不泄漏到全局作用域，避免多场景合并时相互污染。
