[图示主题与整合说明]
- 本图示主题：弹簧压缩过程中的动量守恒与能量转化（子弹射入滑块后系统演化）
- 整合的步骤/概念：
  1. 子弹射入后瞬间的初态（滑块与子弹共速、小车原速、弹簧原长）
  2. 弹簧压缩中的受力与相对运动（弹簧弹力+滑动摩擦力，滑块相对小车向左运动）
  3. 弹簧压缩到最短的共速临界状态（三者共速、弹簧锁定、压缩量d=0.50m）
  4. 能量转化分析（动能减少量→弹性势能+摩擦内能）
- 教学价值：教师可逐步展开，先让学生观察速度差异判断相对运动方向，再分析受力，再识别最短临界条件，最后完成能量方程与数值计算

[分步序列]
- 初始状态（步骤0）——子弹射入后瞬间：
  显示元素：地面、小车、滑块（含子弹圆点）、弹簧（原长，稀疏螺线）、v₁=10m/s箭头（小车上）、v₂=4m/s箭头（滑块上）、质量标签M=2kg和m+m₀=2.0kg、μ=0.2、光滑水平面。
  隐藏元素：所有力箭头、压缩量标注、能量分析、共速高亮、相对运动高亮。
  教学要点：强调v₂<v₁，滑块相对小车向左运动，弹簧仍为原长。

- 步骤1——弹簧压缩中：
  变化：滑块从x=330左移至x=310（动画300ms，ease-out），弹簧螺线变密（长度150px）。
  新增：弹簧弹力箭头（向左推滑块、向右推挡板，绿色实线）、摩擦力箭头（向右推滑块、向左推小车，红色虚线）、F_弹标签、f=4N标签、相对运动高亮（黄色半透明覆盖接触面）。
  保留：v₁、v₂箭头及所有质量标签。
  教学要点：分析滑块受向左弹力和向右摩擦力，小车受向右弹力和向左摩擦力；相对运动方向向左。

- 步骤2——弹簧压缩到最短：
  变化：滑块从x=310左移至x=280（动画300ms，ease-out），弹簧螺线最密（长度120px）。移除v₁、v₂箭头及力箭头、F_弹/f标签、相对运动高亮。
  新增：v₃=7m/s绿色箭头（整体上方）、共速高亮框（绿色粗边框包围三者）、压缩量双向箭头及d=0.50m标签。可添加"锁定"文字提示(300,150)。
  保留：质量标签、μ=0.2。
  教学要点：强调"最短"临界条件——三者达到共同速度，相对速度为零，弹簧被锁定。

- 步骤3——能量转化分析：
  变化：力学图保持步骤2最终状态（滑块在x=280，弹簧最密，v₃箭头，共速高亮）。
  新增：能量公式框（展示完整能量方程）+三个能量转化框（ΔE_k=18J→E_p=16J+Q=2J）。
  移除：压缩量双向箭头（避免与能量区拥挤，或保留但移至不冲突位置）。
  教学要点：系统动能减少18J，其中16J转化为弹性势能，2J转化为摩擦内能，验证能量守恒。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：本场景以几何图形、箭头、标签为主，SVG的path/rect/text/line/marker足以绘制弹簧螺线、箭头、矩形，无需引入重量级库。
- 画布尺寸：800×500px（固定）。SVG viewBox="0 0 800 500"。
- 布局草图：
  ```
  +--------------------------------------------------+
  |  图示区 800×500                                   |
  |  +------------------------------------------+    |
  |  |  v₃=7m/s [步骤2]                         |    |
  |  |  v₁=10m/s  v₂=4m/s [步骤0/1]             |    |
  |  |       ↑        ↑                         |    |
  |  |  +----+--------+----+----+  <-- 小车      |    |
  |  |  |挡板|~~~~~~~~|滑块|    |  <-- 弹簧+滑块 |    |
  |  |  +----+--------+----+----+              |    |
  |  |  ←F弹  →F弹   →f   ←f   [步骤1]         |    |
  |  |  ←————d=0.50m———→      [步骤2]         |    |
  |  |  ==========光滑水平面================    |    |
  |  |                                          |    |
  |  |  [ΔE_k=18J]→[E_p=16J]+[Q=2J] [步骤3]    |    |
  |  +------------------------------------------+    |
  |         [◀ 上一步]  步骤 X/4  [下一步 ▶]        |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量`currentStep`（0~3）控制当前步骤。每步定义一个配置对象，包含各元素的`display`（true/false）、`x`/`y`坐标、`opacity`。
  2. 弹簧绘制：用`<path>`的`d`属性生成正弦波螺线。公式：`M startX,220 ` + 循环`q period/4,-amp period/2,0 t period,0`（上半弧）和`q period/4,amp period/2,0 t period,0`（下半弧）。根据步骤改变`endX`即可改变长度和螺线密度。
  3. 箭头标记：使用SVG `<marker>`定义箭头头部（id=`scene2-arrow-blue`/`scene2-arrow-green`/`scene2-arrow-red`），在`<line>`或`<path>`上通过`marker-end`引用。
  4. 动画曲线：滑块移动和弹簧形变使用CSS transition（`transition: all 300ms ease-out`）或JS的`requestAnimationFrame`。为简化实现，推荐用CSS transition直接改变`transform: translateX()`或`x`属性（对SVG元素，若用CSS需确保浏览器支持SVG属性transition，否则用JS插值）。
  5. 事件绑定：按钮绑定`click`事件，调用`goToStep(n)`。函数内先更新`currentStep`，再遍历所有受控元素设置`style.display`或`setAttribute`。禁用状态通过添加/移除`disabled`类改变按钮透明度。
  6. 步骤3能量框：使用`<rect>`+`<text>`组合，text用`dominant-baseline="middle" text-anchor="middle"`实现居中。
- ID命名规范：所有交互元素ID必须以`scene2-`为前缀。例如：`scene2-cart`、`scene2-block`、`scene2-spring`、`scene2-arrow-v1`、`scene2-btn-prev`、`scene2-btn-next`、`scene2-step-indicator`、`scene2-force-spring-block`、`scene2-friction-block`、`scene2-energy-formula`、`scene2-energy-ep`等。
- IIFE隔离：所有JavaScript代码包裹在`(function() { ... })()`中，避免全局变量污染。
- 元素显隐策略：为每个步骤定义显隐列表。例如步骤0只显示`scene2-group-step0`，步骤1显示`scene2-group-step0`+`scene2-group-step1-forces`+`scene2-block-step1`等。或者每个元素单独控制`display`属性。推荐按逻辑分组使用`<g>`包裹，通过控制`<g>`的`display`属性批量显隐。
