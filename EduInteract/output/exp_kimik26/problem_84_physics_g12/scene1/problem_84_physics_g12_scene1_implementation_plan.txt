[分步序列]
- 初始状态（步骤0）「装置结构」：显示U形导轨、金属棒ab、磁场区域与箭头、电阻R、恒力F箭头（无数值标签）。显示标签：a、b、B、R。右侧空白。教师可讲解装置组成与磁场方向。
- 步骤1「条件标注」：在步骤0基础上，新增7个参数标注（L=1m、B=1T、R=0.8Ω、r=0.2Ω、m=0.2kg、μ=0.5、F=3N），各标注带灰色虚线引线指向对应元件；L用左侧竖直双向箭头表示。步骤0的B、R标签可保留或隐藏（建议保留B，R标签与R=0.8Ω同侧上下分布）。教师可引导学生识别已知条件。
- 步骤2「受力分析」：左侧主图力F箭头保持显示；右侧显示受力分析框，画出五个力箭头（F向左红、f向右绿、F_安向右红、mg向下绿、N向上绿）及对应标签，F_安标签外加红色虚线框突出。教师可讲解各力来源与方向。
- 步骤3「稳定条件」：受力分析图保留；高亮水平方向三个力（F、f、F_安箭头加粗或透明度变化）；公式区显示平衡方程："水平方向：F = F_安 + f"、"竖直方向：N = mg"、"滑动摩擦力：f = μN = μmg"。教师可讲解平衡条件与摩擦力计算。
- 步骤4「求解速度」：受力分析图保留；公式区更新为："安培力：F_安 = B²L²v / (R+r)"、"联立代入得：v = 2 m/s"，其中"v = 2 m/s"用蓝色#1565c0、加粗、放大（font-size=16）高亮显示。教师可展示完整推导与最终结果。
- 教师可随时点击「◀ 上一步」「下一步 ▶」回退或前进，步骤指示器同步更新（如"1 / 5"至"5 / 5"）。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本场景以几何图形、箭头、文本标签为主，SVG的矢量渲染最适合精确控制线段、箭头、文本位置；无需复杂数据可视化或3D，原生JS足以实现状态切换与淡入动画。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  0    100  200  300  400  500  600  700  800
  +----+----+----+----+----+----+----+----+  0
  |         [磁场区域 B↑]          |        |  50
  |    ════════════════↗R          |        | 100
  |    a──┬── 棒ab ────┤     [受力分析框]   | 150
  |  F←───┼──          │     F← ● →f        | 200
  |       └──b──       │        ↓mg ↑N      | 250
  |    ════════════════┘     [F_安→]        | 300
  |  L↑  m,μ,r...标注               [公式区]| 350
  |                                      | 400
  |         [◀上一步] [下一步▶]          | 450
  +----+----+----+----+----+----+----+----+ 500
  左侧：装置主图（~x<500）    右侧：受力/公式（x>500）
  底部y=440~490：控件栏
  ```
- 关键实现要点：
  1. 状态机设计：变量 `currentStep` 取值0~4，每步对应一个SVG `<g>` 组（id="scene1-step0-base"、"scene1-step1-labels"、"scene1-step2-forces"、"scene1-step3-formulas"、"scene1-step4-result"），通过设置 `display` 或 `opacity` 控制显隐。步骤切换时，新组执行淡入动画（requestAnimationFrame驱动opacity 0→1，持续300ms）。
  2. 坐标计算：所有坐标硬编码于SVG元素属性中，严格按布局坐标表实现。箭头使用 `<path>` 的marker-end指向箭头head。
  3. 动画曲线：淡入使用 ease-out（opacity线性增加即可，SVG简单过渡）。
  4. 事件绑定：上一步/下一步按钮绑定click事件，更新currentStep后调用 `updateScene()` 函数，该函数遍历所有步骤组设置显隐，并更新按钮禁用状态与步骤指示器文本。
  5. 引线绘制：步骤1的7条引线使用 `<line>` 或 `<path>`，stroke=#888888，stroke-dasharray="4,3"。
  6. 电阻符号：使用 `<path>` 绘制标准锯齿形（5个折点），位于(430,220)水平方向。
  7. 磁场箭头：使用 `<defs>` 定义箭头marker，9个 `<line>` 复用该marker。
  8. 受力分析图F_安虚线框：使用 `<rect>`，stroke=#c62828，stroke-dasharray="3,3"，fill=none，位于标签外围。
- ID命名规范：所有交互元素ID必须以 `scene1-` 为前缀。例如：
  * 导轨：`scene1-rail-top`、`scene1-rail-bottom`、`scene1-rail-right`
  * 棒：`scene1-rod-ab`
  * 电阻：`scene1-resistor`、`scene1-resistor-lead`
  * 磁场：`scene1-field-box`、`scene1-field-arrow-1`~`scene1-field-arrow-9`
  * 力箭头：`scene1-force-F-main`、`scene1-force-F-diag`、`scene1-force-f`、`scene1-force-F-amp`、`scene1-force-mg`、`scene1-force-N`
  * 步骤组：`scene1-step0-base`、`scene1-step1-labels`、`scene1-step2-forces`、`scene1-step3-formulas`、`scene1-step4-result`
  * 按钮：`scene1-btn-prev`、`scene1-btn-next`
  * 文本标签：`scene1-label-a`、`scene1-label-B`、`scene1-label-L` 等
  JS中严格使用 `document.getElementById` 获取元素，禁止全局class选择，避免多场景合并时跨场景污染。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，内部变量与函数不污染全局作用域。
