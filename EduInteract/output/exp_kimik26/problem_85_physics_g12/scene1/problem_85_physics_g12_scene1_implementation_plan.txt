[分步序列]
- 步骤0「装置结构」：显示气缸A/B、U形管、活塞a/b在初始位置（a距顶H/4，b在H/2）、气体填充（氮气蓝、氧气红、大气灰）、电阻丝；A顶部红色粗边框标识导热，侧壁灰色标识绝热；标注直径比2:1、面积4S/S；状态面板显示空框架；尺寸标注H、H/4、H/2。
- 步骤1「初始平衡态」：状态面板填入初始数值——氮气：Pₙ=P₀、Vₙ=7SH/2、T=280K；氧气：Pₒ=P₀、Vₒ=SH、T=280K；所有文字为黑色常规样式；装置与步骤0一致。
- 步骤2「过程(1)加热」：电阻丝高亮闪烁（CSS动画opacity 0.4↔1，周期0.6s）；活塞b从y=270动画上升至y=120（持续时间800ms，ease-out）；活塞a保持静止；装置上方显示「氮气等压膨胀」；状态面板氮气温度旁显示向上箭头示意加热中；氧气参数保持原值。
- 步骤3「过程(1)末态」：活塞b稳定在顶部（y=120）；电阻丝停止闪烁；状态面板更新——氮气体积变为Vₙ=4SH，温度变为T=320K并以#2e7d32绿色高亮；氧气三行保持原值，右侧添加灰色小字「（未变）」；装置上方标注改为「活塞b到达顶部」。
- 步骤4「过程(2)加热」：电阻丝再次高亮闪烁；活塞a从y=195动画上升至y=176（上升H/16≈19px，持续时间600ms，ease-out）；活塞b保持顶部；装置上方显示「氧气等温压缩」；A左侧显示H/16双向箭头标注；氧气区缩小，氮气区A部扩大；状态面板氧气体积旁显示向下箭头示意压缩中。
- 步骤5「过程(2)末态」：活塞a稳定在y=176；电阻丝停止闪烁；状态面板更新——氧气体积Vₒ=3SH/4，压强Pₒ=4P₀/3并以#2e7d32绿色高亮；氮气压强同步更新为Pₙ=4P₀/3，体积Vₙ=17SH/4；面板底部追加两行结论「(1) 氮气温度 T = 320 K」「(2) 氧气压强 Pₒ = 4P₀/3」；装置上方保持「氧气等温压缩」。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于(280,455)，宽110×高30，点击回退到前一步，步骤0时禁用（置灰）。
  - 「下一步 ▶」按钮：位于(410,455)，宽110×高30，点击前进到下一步，步骤5时禁用（置灰）。
  - 步骤指示器：位于(400,445)，显示「步骤 X / 6」。
- 教师操作流程：教师点击「下一步」依次展示装置结构→初态→加热过程1→末态1→加热过程2→末态2；在关键步骤（步骤1、3、5）暂停讲解；可随时点击「上一步」回退复习；步骤2/4的动画自动播放，播放期间按钮暂时禁用防止误触。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript（无需外部库，气缸、活塞、填充区域均为简单几何图形，状态切换通过显隐/改属性实现）
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  +--------------------------------------------------------+
  |  [标注区]  等压膨胀/等温压缩(200,90)                     |
  |                                                        |
  |  +-------------------+       +-----+    +-------------+ |
  |  | 氧气(红)          |       | P₀  |    |  状态参数   | |
  |  |    O₂             |       |     |    |  氮气 N₂    | |
  |  |  +-------------+  |       |     |    |  P=... V=...| |
  |  |  | 活塞a       |  |       |活塞b|    |  T=...      | |
  |  |  +-------------+  |       |     |    |  氧气 O₂    | |
  |  |  氮气(蓝)        |  U形管  |     |    |  P=... V=...| |
  |  |    N₂            |         |     |    |  T=...      | |
  |  |  +-------------+  |         +-----+    +-------------+ |
  |  |  | 电阻丝      |  |                                  |
  |  +--+----------------+----------------------------------+
  |       A(4S)              B(S)                         |
  |  [控件栏 y=440~490]  ◀上一步  步骤X/6  下一步▶         |
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  - 状态机：用变量`currentStep`（0~5），每一步对应一个配置对象，记录各元素的目标坐标、文本内容、显隐状态、颜色类名。
  - 活塞动画：步骤2/4使用`requestAnimationFrame`插值计算活塞y坐标，配合ease-out曲线；动画期间设置`isAnimating`标志禁用按钮。
  - 电阻丝闪烁：通过添加/移除CSS类`.heating`实现，该类定义`animation: pulse 0.6s infinite alternate`。
  - 气体区域高度：随活塞位置动态计算rect的height属性（氧气height=活塞y-120，氮气A部height=420-活塞底部， etc.）。
  - 状态面板更新：使用`textContent`直接替换数值文本，高亮通过添加/移除`.highlight-green`类（color:#2e7d32; font-weight:bold）。
  - 尺寸标注显隐：H/16标注及指引线在步骤4-5显示，其他步骤隐藏；过程标注文字在步骤2显示「等压膨胀」、步骤4-5显示「等温压缩」、其余步骤隐藏。
- ID命名规范：所有交互元素ID以`scene1-`为前缀，例如`scene1-piston-a`、`scene1-gas-n2-a`、`scene1-state-temp-n2`、`scene1-btn-next`等；JS中严格使用`document.getElementById`获取。
- IIFE隔离：所有JavaScript代码包裹在`(function() { ... })();`中，避免全局污染。
