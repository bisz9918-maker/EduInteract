[图示主题与整合说明]
- 本图示主题：不带电平行板电容器中的带电微粒平抛运动与初速度求解
- 整合的步骤/概念：
  1. 装置认知：平行板电容器结构（A板、B板、接地）、已知条件标注（L、d、m、q）
  2. 受力分析：电容器不带电时微粒仅受重力 mg
  3. 运动分解：水平方向匀速直线运动（v₀）、竖直方向自由落体（vᵧ = gt）
  4. 轨迹与位移：蓝色抛物线轨迹、水平位移 L/2、竖直位移 d/2
  5. 结论推导：联立 d/2 = ½gt² 与 L/2 = v₀t，得 v₀ = 2.5 m/s
- 教学价值：教师可按照认知递进顺序逐步展开，从装置到受力、从分解到合成、从几何到代数，随时回退复习关键步骤。

[分步序列]
- 初始状态（步骤0）：展示完整装置图。显示元素：上板B、下板A、接地符号、微粒（含+号）、O点标记、L尺寸标注、d尺寸标注、B/A/O/m/+q/v₀标签、入口v₀箭头。所有元素黑色/灰色，无高亮。教师可在此介绍装置结构与已知条件。
- 步骤1：点击「下一步」→ 高亮受力分析。新增：红色重力箭头mg（从微粒竖直向下）及mg标签。强调此时电容器不带电，微粒仅受重力，无电场力。其余装置元素保持。
- 步骤2：点击「下一步」→ 运动分解与等时性。隐藏mg箭头（避免与分速度重叠）；新增：绿色水平箭头v₀（匀速）、红色竖直箭头vᵧ=gt（匀加速）、灰色虚线矩形辅助线（连接两分速度箭头末端，展示同一时刻的水平与竖直分位移）、标注"t"。教师可讲解两个分运动时间相等。
- 步骤3：点击「下一步」→ 轨迹与总位移。新增：蓝色抛物线轨迹（带方向箭头）、绿色水平位移虚线及"x = L/2"标注（在A板下方）、红色竖直位移虚线及"y = d/2"标注（在O点右侧）。步骤2的分速度箭头保留但透明度降至0.3（作为背景参考），不抢夺视觉焦点。教师可讲解合运动与分运动的关系。
- 步骤4：点击「下一步」→ 公式结论。新增：右下角蓝色公式框，内含三行公式推导与最终结果 v₀ = 2.5 m/s。其余元素保持步骤3状态。教师可在此总结第一问求解过程。
- 教师可随时点击「上一步」回退到任意步骤复习，点击「重置」回到步骤0。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：本场景为静态几何图示与分步显隐控制，无复杂函数绘图、3D或大量数据绑定，原生SVG性能最优、依赖最少。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  L = 0.1 m                                       |
  |    B ┌──────────────────────────────┐  d = 0.4 cm |
  |  ┷   │ 上板B（浅灰填充）            │  │          |
  |      │                              │  │          |
  | +q ● │  微粒（m）  ──→ v₀           │  │          |
  | m    │        （抛物线轨迹）        │  │          |
  |      │                              │  │          |
  |      └──────────────────────────────┘  │          |
  |    A        O                          │          |
  |         x=L/2                          │          |
  |                                        │          |
  |                    [公式框 步骤4显示]              |
  |                                                  |
  |  步骤 1 / 5                                      |
  |  [◀ 上一步]  [下一步 ▶]  [重置]                  |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `let state = 0;` 表示当前步骤（0~4）。定义 `const elementsByState = [...]` 数组，每个状态记录应显示/隐藏的SVG元素ID列表。`updateView()` 函数根据state设置对应元素的 `display` 或 `opacity`。
  2. 坐标计算：轨迹使用二次贝塞尔曲线 `M140,200 Q265,200 390,250`，控制点取水平中点与起点同y坐标，确保中点精确落在(265,212.5)。
  3. 动画曲线：分步切换不使用过渡动画（避免课堂等待），直接显隐。若需柔和效果，可使用CSS transition控制opacity，时长150ms。
  4. 事件绑定：按钮通过 `addEventListener('click', ...)` 绑定，`updateView()` 内同步更新按钮禁用状态（state===0时禁用上一步，state===4时禁用下一步）。
  5. 箭头marker：在SVG `<defs>` 中定义 `<marker id="scene1-arrowhead">`，用于轨迹末端、v₀箭头、mg箭头等，统一箭头样式。
  6. 尺寸标注画法：L和d的标注使用"双箭头线+两端短垂线"的标准工程标注样式，避免与极板重叠。
- ID命名规范：所有SVG元素及控件ID必须以 `scene1-` 为前缀。例如：`scene1-plate-b`、`scene1-plate-a`、`scene1-particle`、`scene1-force-mg`、`scene1-arrow-vx`、`scene1-trajectory`、`scene1-formula-box`、`scene1-btn-prev`、`scene1-btn-next`、`scene1-btn-reset`、`scene1-step-text`。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免多场景合并时的全局变量污染。
- 容器结构：外层div宽800高500，position:relative；内部SVG宽800高500；控件栏为absolute定位的div，bottom:10px，宽800，flex布局居中排列三个按钮。
