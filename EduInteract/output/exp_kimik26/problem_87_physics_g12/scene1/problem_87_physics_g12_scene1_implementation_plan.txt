[图示主题与整合说明]
- 本图示主题：斜面双球在匀强电场中的受力平衡与瞬时加速分析
- 整合的步骤/概念：
  1) 原始装置与已知条件展示（斜面37°、水平向右匀强电场、A负电、B固定、间距L）
  2) A球受力平衡分析（判断B球电性、建立坐标系、分解力、求解电场强度E）
  3) B球释放瞬间受力分析（画B球四力、分解求沿斜面合力）
  4) 关键代换与结论呈现（利用第(1)问结论快速求加速度）
- 教学价值：教师可使用分步导航按课堂节奏逐步揭示受力与方程，随时回退强调关键分解或代换步骤。步骤1通过"假设-排除"动画帮助学生理解B球电性判断的逻辑；步骤4通过代换高亮展示两问之间的内在联系。

[分步序列]
- 初始状态（步骤0）「题意感知」：
  显示元素：斜面三角形、5条电场线及E标签、A球（标"-"）与B球（标"×"）、固定符号、A/B/L/37°/m/q标签。
  公式面板：列出已知条件（光滑绝缘斜面θ=37°、匀强电场E水平向右、A/B质量m电量q、A带负电B固定、间距L、sin37°=0.6 cos37°=0.8）。
  高亮：无。

- 步骤1「A球受力与电性判断」：
  视觉变化：A球填充变蓝（透明度20%）。依次动画出现A球四力矢量：重力mg（深灰竖直向下）、支持力N_A（绿垂直斜面向上）、电场力qE（橙水平向左）。随后同时出现：灰色虚线箭头（假设B带正电，库仑力沿斜面向下，标注"无法平衡"）和紫色实线箭头（实际B带负电，库仑力F_c沿斜面向上）。
  公式面板：显示电性判断逻辑——若B带正电则F_c沿斜面向下，三力同向无法平衡；故B带负电，F_c沿斜面向上与重力、电场力沿斜面向下分量形成平衡。
  动画：力矢量从球心向外延伸绘制，时长300ms，间隔200ms。

- 步骤2「A球平衡方程」：
  视觉变化：保留步骤1所有元素。在A球中心建立灰色虚线坐标系（x沿斜面向上，y垂直斜面向上）。重力mg和电场力F_E出现分解虚线：mg分解为0.6mg（沿斜面向下）和0.8mg（垂直斜面向下）；F_E分解为0.8qE（沿斜面向下）和0.6qE（垂直斜面向下）。分解辅助线构成平行四边形虚线框。
  公式面板：高亮沿斜面方向平衡方程 kq²/L² = mg·sin37° + qE·cos37°，即 kq²/L² = 0.6mg + 0.8qE。下方给出解 E = 5kq/(4L²) − 3mg/(4q)，E的结果用绿色高亮。
  动画：坐标轴淡入200ms，分力矢量从原点画出250ms，辅助虚线随后画出200ms。

- 步骤3「B球受力分析」：
  视觉变化：A球受力矢量淡化（透明度30%，保留可见作参照）。B球填充变红（透明度20%）。在B球中心建立相同方向坐标系。依次动画出现B球四力矢量：重力mg（深灰竖直向下）、支持力N_B（绿垂直斜面向上）、电场力qE（橙水平向左）、库仑力F_c（紫沿斜面向下，A对B排斥）。各力相应分解辅助线同步出现（与A球相同的分解比例）。
  公式面板：说明B球释放瞬间受四力作用，库仑力方向与A球相反（沿斜面向下），大小仍为kq²/L²。
  动画：B球高亮闪烁200ms，力矢量依次画出（间隔200ms）。

- 步骤4「B球加速度」：
  视觉变化：保留步骤3所有元素。高亮B球沿斜面方向所有向下分量：重力沿斜面向下分量（0.6mg）、电场力沿斜面向下分量（0.8qE）、库仑力（kq²/L²，紫色）。三者用红色粗线框或加粗描边强调。在B球旁用红色箭头示意合力方向沿斜面向下。
  公式面板：展示合力方程 F_合 = mg·sin37° + qE·cos37° + kq²/L²。高亮代换步骤：由(1)知 mg·sin37° + qE·cos37° = kq²/L²，代入得 F_合 = 2kq²/L²。最终加速度 a = 2kq²/(mL²)，方向沿斜面向下。结论用绿色高亮。
  动画：三个向下分量依次高亮（各300ms），随后合力结论淡入。

[技术实现]
- JS库选择及原因：原生SVG + 原生JavaScript。理由：本场景以几何图形、矢量箭头和文本标签为主，SVG的path、line、circle、text元素可直接精确控制；无需复杂数据绑定或3D渲染，原生JS足以管理状态机和DOM显隐。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------------+
  |                                                        |
  |  E→ ~~~~ 电场线 ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~  |  <- 标题/电场区 (y=80-340)
  |                                                        |
  |         A- (220,280)                                   |
  |        /                                               |
  |       /  L                                             |
  |      /                                                 |
  |     B× (125,352)                                       |  <- 物理装置区 (y=180-420)
  |    /                                                   |
  |   / 37°                                                |
  |  /_________________________|                           |
  |                            | 公式面板                  |  <- 公式区 (x=500-770)
  |                            |                          |
  |                            |                          |
  +--------------------------------------------------------+
  |        [◀ 上一步]  ● ● ● ● ●  [下一步 ▶]               |  <- 控件栏 (y=440-500)
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：变量 `currentStep` 取值为 0~4。`renderStep(step)` 函数根据步骤值设置所有SVG元素的 `display` 或 `opacity` 属性。使用 `data-step` 属性标记每个元素所属步骤范围（如 `data-step="1-2"` 表示步骤1和2显示）。
  2. 矢量箭头：使用SVG `<marker>` 定义箭头头部，id为 `scene1-arrowhead`，应用于所有力矢量线段的 `marker-end`。
  3. 动画曲线：力矢量出现使用CSS `transition: all 0.3s ease-out` 控制opacity和stroke-dashoffset（可选路径绘制效果）；分步切换时整体使用200ms淡入淡出避免闪烁。
  4. 坐标计算：斜面方向向量(0.8,-0.6)，法向量(0.6,0.8)。所有力分解通过向量投影公式计算终点坐标，确保几何准确。
  5. 公式面板：使用foreignObject嵌入HTML div，便于排版数学公式（可用纯文本+sup/sub标签，或引入MathJax若需更复杂公式）。本场景公式较简单，直接用HTML文本配合span高亮。
  6. 事件绑定：按钮点击绑定 `scene1-prev-btn` 和 `scene1-next-btn`；圆点通过 `scene1-dot-N` id绑定，点击时直接设置 `currentStep = N` 并渲染。
  7. 防污染措施：所有SVG元素id以 `scene1-` 为前缀；JS代码包裹在IIFE中；不使用全局变量暴露状态机，仅通过DOM事件驱动。
