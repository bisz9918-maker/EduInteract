[图示主题与整合说明]
- 本图示主题：金属棒在圆弧轨道上运动的电磁感应动态分析
- 整合的步骤/概念：
  1. 装置结构展示（两根四分之一圆弧轨道、金属棒、竖直向上的匀强磁场、顶端电阻R）
  2. 金属棒位置随圆心角θ变化的几何关系（圆心O、半径r、轨道间距L）
  3. 切向速度v₀分解为水平分量vₓ（有效切割速度）和竖直分量vᵤ
  4. 感应电动势ε=BLv₀cosθ与路端电压U=¾BLv₀cosθ的实时推导
  5. 等效电路（电源ε、内阻R/3、外阻R串联）与实时数据面板
- 教学价值：教师通过拖拽滑块可让金属棒在0°~90°任意位置定格，直观展示"有效切割速度随角度余弦衰减"的规律；初始时刻（θ=0）可直接对应第(1)问路端电压计算，为后续热量与功的积分铺垫。

[分步序列（状态说明）]
本场景为连续滑块交互，无离散分步，定义关键状态如下：

- 初始状态（θ=0°，滑块在最左端）：
  * 金属棒位于最低点cd，坐标从(180,280)到(280,280)
  * 圆心到棒半径竖直向下
  * 速度v₀水平向右，vₓ=v₀（箭头最长），vᵤ=0（隐藏）
  * 角度θ弧线不可见（或显示为0）
  * 实时数据：θ=0°，vₓ=v₀，ε=BLv₀，U=¾BLv₀
  * 等效电路高亮路端电压U

- 交互过程（0°<θ<90°，滑块拖动中）：
  * 金属棒左端：(180+130sinθ, 150+130cosθ)，右端：(280+130sinθ, 150+130cosθ)
  * 圆心到棒左端半径虚线实时更新
  * 角度θ弧线从竖直向下张开到当前半径方向
  * 速度v₀沿切线方向（与水平夹角θ向上），长度恒定50px
  * vₓ长度=50cosθ，vᵤ长度=50sinθ，均从棒中点同一点出发
  * 实时数据随θ更新：vₓ=v₀cosθ，ε=BLv₀cosθ，U=¾BLv₀cosθ
  * 教师可任意定格讲解瞬时状态

- 终止状态（θ=90°，滑块在最右端）：
  * 金属棒位于最高点ab，坐标从(310,150)到(410,150)
  * 圆心到棒半径水平向右
  * 速度v₀竖直向上，vₓ=0（隐藏），vᵤ=v₀（箭头最长）
  * 实时数据：θ=90°，vₓ=0，ε=0，U=0
  * 等效电路显示电动势为0

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：
  * 水平滑块：位于底部y=470，轨道从x=100到x=700，控制圆心角θ从0°到90°线性变化
  * 滑块按钮：圆形，半径12px，#1565c0填充，拖动时实时更新整个场景
  * 滑块两端标签："cd"(左，θ=0°)和"ab"(右，θ=90°)
  * 滑块下方标注"θ"，提示控制变量
- 教师操作流程：
  1. 加载后展示初始状态（θ=0°），教师讲解装置结构和初始条件
  2. 缓慢向右拖动滑块，让学生观察金属棒上移、速度方向转动、vₓ逐渐减小
  3. 定格在θ=0°，讲解第(1)问：此时vₓ=v₀，ε最大，U_cd=¾BLv₀
  4. 继续拖动到任意θ（如30°、45°、60°），讲解一般位置的电动势公式ε=BLv₀cosθ
  5. 拖至θ=90°，说明此时棒水平、速度竖直，有效切割速度为0，ε=0
  6. 强调"余弦规律"：电动势和路端电压都随cosθ衰减，为第(2)问热量积分（对cos²θ积分）做铺垫

[技术实现]
- JS库选择：原生SVG + 原生JavaScript（无外部库）。理由：场景为2D几何图形+简单动画，SVG的path/line/circle/text足以表达所有元素，原生JS通过setAttribute更新坐标即可，无需引入D3等重型库。
- 画布尺寸：800×500 px（SVG viewBox="0 0 800 500"）
- 布局草图：
  ```
  +--------------------------------------------------+
  |  主图区(0,0)-(480,440)        | 右侧面板(480,0)-(800,440) |
  |                               |                         |
  |   O ━━r━━━━ a                 |    等效电路              |
  |   ┃      ╱  ╲                 |   ε  [R/3]  [R]         |
  |   r    ╱      ╲ b━━R          |                         |
  |   ┃  ╱    棒    ┃             |    实时数据              |
  |   c╱            d             |   θ = ...               |
  |   └────L────┘                 |   vₓ = v₀cosθ           |
  |   ↑B 磁场虚线                 |   ε = BLv₀cosθ          |
  |                               |   U = ¾BLv₀cosθ         |
  +--------------------------------------------------+
  |  控件区(y=440~500)                                |
  |      cd ●━━━━━━━━━━━━━━○ ab                       |
  |              θ                                    |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机：仅一个状态变量θ（弧度制，0~π/2），滑块值0~100映射到θ。
  2. 坐标计算（每次滑块input事件触发）：
     - 棒左端：x1=180+130*sin(θ), y1=150+130*cos(θ)
     - 棒右端：x2=x1+100, y2=y1（水平棒，长度L=100）
     - 中点M：((x1+x2)/2, y1)
     - v0方向向量：(cos(θ), -sin(θ))，终点=M+50*(cos(θ), -sin(θ))
     - vₓ终点=(M.x+50*cos(θ), M.y)
     - vᵤ终点=(M.x, M.y-50*sin(θ))
  3. 动画曲线：滑块拖动直接映射，无需缓动；若需平滑过渡可加入requestAnimationFrame插值，但直接响应更利于教师精确控制。
  4. 事件绑定：滑块input事件→更新θ→调用render()→更新所有SVG元素的setAttribute。
  5. 隐藏逻辑：当sin(θ)<0.01时隐藏vᵤ箭头及标签；当cos(θ)<0.01时隐藏vₓ箭头及标签。
  6. 角度弧线：使用SVG arc路径，从(180,150+40)到(180+40*sin(θ),150+40*cos(θ))，大弧标志0， sweep标志0。
  7. 实时数据面板：使用textContent更新数值，角度显示为"θ = 45°"格式，公式行保留符号表达式。
- ID命名规范：所有SVG元素及JS变量以scene1-为前缀。例如：
  - scene1-arc-left, scene1-arc-right, scene1-rod, scene1-v0-arrow, scene1-slider, scene1-panel-epsilon 等。
  - JS中获取元素严格使用document.getElementById('scene1-xxx')，禁止querySelectorAll配合全局class。
- IIFE隔离：所有JavaScript代码包裹在 (function() { ... })() 中，避免多场景合并时变量污染。
- 响应式：容器宽度固定800px，不随窗口缩放（教学图示通常固定尺寸）。
