[图示主题与整合说明]
- 本图示主题：带电粒子在组合电场（E₁水平向右 + E₂竖直向下）中的完整运动轨迹与分区域分析
- 整合的步骤/概念：
  1. 题目初始条件（坐标系、分界面ab、电场分布、已知量）
  2. E₁区域匀加速直线运动（P→ab，水平轨迹，末速度v₁）
  3. E₂区域类平抛运动（ab→Q，抛物线轨迹，末速度v_Q）
  4. 完整运动总结（两段轨迹+三个待求量高亮）
- 教学价值：教师通过分步导航，逐步引导学生从已知条件过渡到运动分析，再建立完整物理图景。每一步聚焦一个物理过程，避免信息过载，符合“从局部到整体”的认知规律。

[分步序列]
- 步骤0（初始条件）：
  显示：坐标系、ab虚线、P点、Q点、E₁/E₂电场箭头及标签、区域淡色填充、L/h/m/q标注。
  隐藏：轨迹、速度矢量、右侧公式/说明。
  状态：呈现题目原始条件，等待教师讲解已知量。

- 步骤1（E₁区域运动）：
  在步骤0基础上新增：
  1. P→ab水平轨迹线段（绿），带右向箭头于(320,190)
  2. v₁速度矢量（蓝箭头，340,190→390,190），标签"v₁"于(400,175)
  3. 右侧公式"qE₁L = ½mv₁²"于(620,200)
  4. E₁区域边框加粗高亮（蓝，stroke-width由1→2）
  状态：聚焦水平方向匀加速，建立动能定理关系。

- 步骤2（E₂区域运动）：
  在步骤1基础上新增：
  1. ab→Q抛物线轨迹（绿，path M340,190 Q460,190 580,430），中点(460,250)带切向箭头
  2. v_Q速度矢量（红箭头，580,430→610,490），标签"v_Q"于(615,495)
  3. 右侧说明文字："水平方向：匀速直线运动"(620,260)、"竖直方向：初速为零的匀加速直线运动"(620,285)
  4. E₂区域边框加粗高亮（红，stroke-width由1→2），E₁边框恢复
  状态：引入类平抛模型，分解两个方向运动。

- 步骤3（完整总结）：
  在步骤2基础上：
  1. 保持所有轨迹、矢量、公式、说明可见
  2. 高亮三个待求量：v₁标签加蓝底框、v_Q标签加红底框、Q点旁新增坐标标注"Q(x_Q, 0)"(620,360)加绿底框
  3. 右侧新增结论性坐标标注
  4. 两段轨迹同时完整呈现，形成全图景
  状态：总览全题，建立完整解题框架。

[交互方案]

  1. 「上一步」按钮：rect(240,450,100,32)，点击回退到上一状态

- 教师操作流程：
  1. 教师展示步骤0，讲解坐标系、电场分布和已知条件（m,q,E₁,E₂,L,h）
  2. 点击「下一步」进入步骤1，讲解E₁区域水平匀加速，引出qE₁L=½mv₁²
  3. 点击「下一步」进入步骤2，讲解E₂区域类平抛，分解水平和竖直运动
  4. 点击「下一步」进入步骤3，总结全题，高亮三个待求量，建立完整解题思路
  5. 可随时点击「上一步」回退复习任一阶段

[技术实现]
- JS库选择：原生SVG（场景为静态几何图形+分步显隐，无需复杂动画库，原生SVG性能最佳）
- 画布尺寸：800×500 px（固定）
- 布局草图：
  ```
  +--------------------------------------------------+
  |  y↑  E₁→  |  a   ↓E₂                              |
  |   P●      |      ↓                                |
  |   →→→     |      ↓                                |
  |           |    ~~~~抛物线~~~~>●Q                   |
  |   ←——L——→ |                                       |
  |  O+———————b——————————————————————→x               |
  |            [公式/说明区域]                         |
  |  [◀上一步]  步骤 k/4  [下一步▶]                   |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机：用变量 `currentStep`（0~3）控制当前步骤，数组 `stepElements` 记录每步应显示/隐藏的元素ID列表
  2. 元素显隐：通过切换CSS类名（如 `.scene1-hidden { display: none; }`）实现，避免频繁DOM操作
  3. 抛物线绘制：SVG path使用二次贝塞尔 `M 340 190 Q 460 190 580 430`，控制点(460,190)确保中点(460,250)与理论抛物线吻合
  4. 方向箭头：轨迹P→ab用marker-end；抛物线中点切向箭头用独立path三角形（顶点466,256，底边中点460,250）
  5. 高亮效果：步骤3待求量高亮使用rect背景框（rx=4, ry=4, fill对应颜色, opacity=0.15, stroke对应颜色, stroke-width=1.5）包裹标签
  6. 区域边框高亮：步骤1/2分别给E₁/E₂填充rect添加stroke并改变stroke-width，步骤切换时恢复
  7. 坐标映射：数学坐标(x,y)↔SVG坐标(100+x, 430-y)，scale=1（L=240px, h=240px）
- ID命名规范：所有元素ID必须以 `scene1-` 为前缀，例如：
  - `scene1-axis-x`, `scene1-axis-y`, `scene1-point-o`, `scene1-point-p`, `scene1-point-q`
  - `scene1-line-ab`, `scene1-arrow-e1-1`, `scene1-arrow-e2-1`
  - `scene1-traj-seg1`, `scene1-traj-seg2`, `scene1-vec-v1`, `scene1-vec-vq`
  - `scene1-formula-1`, `scene1-desc-1`, `scene1-desc-2`
  - `scene1-btn-prev`, `scene1-btn-next`, `scene1-step-indicator`
  JS中严格使用 `document.getElementById` 获取元素，禁止querySelectorAll配合全局class
- IIFE隔离：所有JS代码包裹在 `(function() { ... })()` 中，避免多场景合并时变量污染
- 事件绑定：按钮点击直接绑定 `onclick` 属性或 `addEventListener`，在IIFE内部执行
