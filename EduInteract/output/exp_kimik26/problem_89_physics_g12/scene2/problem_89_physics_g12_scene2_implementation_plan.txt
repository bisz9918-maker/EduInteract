[图示主题与整合说明]
- 本图示主题：E₂区域类平抛运动的位移与速度分解
- 整合的步骤/概念：粒子以水平初速度v₁进入竖直向下的匀强电场E₂后，其运动可分解为"水平匀速直线运动"与"竖直初速为零的匀加速直线运动"。本场景通过局部坐标系聚焦E₂区域，逐步展示位移正交分解、速度矢量合成、以及运动学公式的联立求解过程。
- 教学价值：教师使用此图示时，可在步骤0强调"类平抛"的初始条件（水平v₁、竖直a₂）；在步骤1引导学生观察等时性下两分运动的位移独立关系；在步骤2建立速度矢量三角形，强化矢量合成法则；在步骤3带领学生完成公式联立，得出Q点坐标。分步导航便于教师控制课堂节奏，随时回退重讲关键步骤。

[分步序列]
- 初始状态（步骤0）：显示局部坐标系（x′轴、y′轴、O′标签）、初速度v₁箭头及标签、加速度a₂箭头及标签、公式F0（a₂=qE₂/m，红色）。其余元素隐藏（opacity:0）。
- 步骤1（位移分解）：在步骤0基础上，以0.3s淡入显示：抛物线轨迹（绿色）、Q′点及标签、位移矩形（淡灰填充）、d双向箭头及标签（蓝色）、h双向箭头及标签（红色）、公式F1a（d=v₁t，蓝色）和F1b（h=½a₂t²，红色）。
- 步骤2（速度分解）：在步骤1基础上，以0.3s淡入显示：v_x箭头及标签（蓝色）、v_y箭头及标签（红色）、v_Q箭头及标签（绿色）、速度矢量三角形淡绿填充、公式F2a（v_y=a₂t，红色）和F2b（v_Q=√(v_x²+v_y²)，绿色）。
- 步骤3（联立求解）：在步骤2基础上，以0.3s淡入显示：右侧公式面板切换为完整推导链——F3a（由h=½a₂t²得t=√(2h/a₂)）、F3b（d=v₁√(2h/a₂)，蓝色）、F3c（v_y=√(2a₂h)，红色）、F3d（v_Q=√(v₁²+2a₂h)，绿色）、F3e（Q点坐标结论，绿色）；同时显示三条灰色代入顺序箭头，指示从t→d→v_y→v_Q的推导路径。前序步骤的F0~F2b可保持显示或淡化（建议保持但降低不透明度至0.3，使焦点集中在F3推导链）。
- 教师可随时点击「上一步」回退，回退时当前步骤新增元素以0.2s淡出隐藏。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「上一步」按钮：位于底部控件栏左侧（310,458），80×30px，点击回退到上一分步，若已在步骤0则禁用。
  2. 「步骤指示」文本：位于底部控件栏中央（400,458），显示当前步骤名称（如"初态"/"位移"/"速度"/"求解"）。
  3. 「下一步」按钮：位于底部控件栏右侧（470,458），80×30px，点击前进到下一分步，若已在步骤3则禁用。
- 教师操作流程：
  1. 页面加载后自动呈现步骤0，教师讲解"粒子刚进入E₂区域时的受力与初速度"。
  2. 点击「下一步」进入步骤1，讲解"水平匀速、竖直匀加速导致的位移分解"。
  3. 点击「下一步」进入步骤2，讲解"终点处的速度矢量合成与矢量三角形"。
  4. 点击「下一步」进入步骤3，讲解"联立四个方程求解未知量，最终确定Q点坐标"。
  5. 讲解过程中可随时点击「上一步」让学生回顾前一环节的关键图像。

[技术实现]
- JS库选择：原生SVG（所有元素均为几何图形、矢量箭头、文本标签，SVG的marker、path、polygon、text完全满足需求，无需引入外部库）。
- 画布尺寸：800×500 px（固定）。
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------------+
  |  y′↑                                                   |
  |   |  d ↑                                               |
  |   |   O′+========+                                     |
  |   |    | 轨迹 ↘  |                                     |
  |   |    |         |                                     |
  |   |    +========+Q′                                    |
  |   |   h|        |＼                                    |
  |   |    |        |  ＼ v_Q                              |
  |   +----|--------|----→ x′                              |
  |        |        |                                     |
  |        v_x      v_y                                   |
  |                                                       |
  |   [公式推导区]    a₂=qE₂/m  d=v₁t  v_y=a₂t ...        |
  |                                                       |
  |         [◀上一步]  [步骤]  [下一步▶]                   |
  +--------------------------------------------------------+
  ```
  （注：y′轴实际方向为竖直向下，草图中↑仅为示意坐标轴位置在左上）
- 关键实现要点：
  1. 状态机设计：使用变量 `let currentStep = 0;` 记录当前步骤（0~3）。每步定义一个元素ID数组，记录该步应显示/隐藏的元素。切换步骤时遍历数组设置 `opacity` 和 `pointer-events`。
  2. 抛物线轨迹：使用JavaScript循环生成20个点的坐标 `x = 220 + 240*t, y = 140 + 280*t*t`（t从0到1步长0.05），拼接成SVG polyline的points字符串。
  3. 双向箭头：在SVG defs中定义两个marker（arrow-start、arrow-end），分别用于线段两端。
  4. 动画曲线：所有淡入淡出使用CSS transition `opacity 0.3s ease`，通过添加/移除CSS类（如`.scene2-visible` opacity:1, `.scene2-hidden` opacity:0）控制。
  5. 步骤3公式链：预先在SVG中放置所有F3a~F3e文本和代入箭头，默认隐藏；进入步骤3时统一淡入。前序公式F0~F2b可通过降低opacity至0.3实现"淡化保留"效果。
  6. 事件绑定：上一步/下一步按钮绑定click事件，调用 `setStep(newStep)` 函数，函数内更新按钮禁用状态、步骤指示文本、各元素可见性。
- ID命名规范：所有SVG元素和控件ID必须以 `scene2-` 为前缀。例如：`scene2-axis-x`, `scene2-axis-y`, `scene2-origin`, `scene2-trajectory`, `scene2-arrow-v1`, `scene2-arrow-a2`, `scene2-arrow-vx`, `scene2-arrow-vy`, `scene2-arrow-vq`, `scene2-triangle-velocity`, `scene2-rect-displacement`, `scene2-label-o`, `scene2-label-q`, `scene2-label-d`, `scene2-label-h`, `scene2-formula-f0`, `scene2-formula-f1a`, `scene2-btn-prev`, `scene2-btn-next`, `scene2-step-info`。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免全局变量污染，确保多场景合并时互不干扰。
