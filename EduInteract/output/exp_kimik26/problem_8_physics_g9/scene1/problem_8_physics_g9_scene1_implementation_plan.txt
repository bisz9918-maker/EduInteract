[图示主题与整合说明]
- 本图示主题：串联电路故障诊断与选项验证
- 整合内容：将原题中的串联电路（电源、开关S、灯泡L₁、灯泡L₂、电压表V）以SVG电路图形式呈现，并通过5个分步状态展示"正常电路、L₁短路、L₁断路、L₂短路、L₂断路"五种工况。每一步同步更新电流路径、灯泡亮灭、电压表示数及右侧分析面板，最终只有L₁短路满足"一灯亮一灯不亮且电压表有示数"的题意。
- 教学价值：教师可按照故障排查逻辑逐步切换状态，让学生观察每种故障下电流路径的变化、灯泡状态与电压表示数的对应关系，培养电路分析能力。分步导航支持回退，便于课堂重复讲解与对比。

[分步序列]
- 步骤0（正常电路）：
  * 显示元素：完整电路图、两灯均亮（L₁/L₂填充#ffeb3b+光晕）、蓝色电流路径沿整个回路流动（带方向箭头）、电压表显示"有示数"。
  * 右侧面板：故障类型="正常"，L₁状态="亮"，L₂状态="亮"，电压表示数="有示数"，是否符合题意="—"。
  * 无红色故障标记。

- 步骤1（L₁短路）：
  * 视觉变化：L₁圆内出现红色竖直粗线(380,185)-(380,215)表示短路导线；L₁变为灰色#e0e0e0（不亮），L₂保持黄色发光；电流路径仍完整显示（电流经短路导线绕过L₁）；电压表显示"有示数（U≈U电源）"。
  * 右侧面板：故障类型="L₁短路"（绿色高亮），L₁="不亮"，L₂="亮"，电压表="有示数"，判断="符合题意"（绿色）。

- 步骤2（L₁断路）：
  * 视觉变化：L₁圆内出现红色×形断路标记，L₁和L₂均变为灰色#e0e0e0；电流路径隐藏；电压表显示"0V"。
  * 右侧面板：故障类型="L₁断路"（红色），L₁="不亮"，L₂="不亮"，电压表="0V"，判断="不符合"（红色）。

- 步骤3（L₂短路）：
  * 视觉变化：L₂圆内出现红色竖直粗线(100,265)-(100,295)表示短路导线；L₂变为灰色#e0e0e0，L₁保持黄色发光；电流路径完整显示；电压表并联在短路导线两端，显示"0V"。
  * 右侧面板：故障类型="L₂短路"（红色），L₁="亮"，L₂="不亮"，电压表="0V"，判断="不符合"（红色）。

- 步骤4（L₂断路）：
  * 视觉变化：L₂圆内出现红色×形断路标记，L₁和L₂均变为灰色#e0e0e0；串联电流路径隐藏；电压表通过L₁、开关与电源形成通路，显示"有示数（U≈U电源）"。
  * 右侧面板：故障类型="L₂断路"（红色），L₁="不亮"，L₂="不亮"，电压表="有示数"，判断="不符合"（红色）。

- "+"与"−"：水平距40px，垂直距50px → 间距≈64px → 无冲突
- "L₂"与"V"：水平距165px，垂直距25px → 间距≈167px → 无冲突
- "V"与电压表示数：水平距30px，同y → 间距30px → 可接受（刚好不重叠）
- 面板内相邻行标签：y差50px → 无冲突
- 面板值与电路图：面板x≥500，电路图x≤450 → 水平距≥50px → 无冲突

结论：无冲突，布局安全。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  * 「◀ 上一步」按钮：位于底部左侧(220,440)-(320,480)，点击后退一个步骤，到步骤0时禁用。
  * 「下一步 ▶」按钮：位于底部右侧(480,440)-(580,480)，点击前进一个步骤，到步骤4时禁用。
  * 步骤指示文本：位于两按钮之间(400,465)，显示"步骤 n/5"（n为当前步骤号+1）。
- 教师操作流程：
  1. 加载后显示步骤0（正常电路），教师讲解串联电路基本结构。
  2. 点击「下一步」进入步骤1（L₁短路），观察短路时电流绕过L₁，L₂仍亮，电压表有示数，面板提示"符合题意"。
  3. 继续点击「下一步」依次验证L₁断路、L₂短路、L₂断路，观察每种故障的灯泡状态和电压表示数，面板均提示"不符合"。
  4. 可随时点击「上一步」回退，对比不同故障的差异，强化学生记忆。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：电路图为静态几何图形，状态切换仅需改变SVG元素的属性（visibility、fill、stroke等），无需复杂物理引擎或数据绑定库。
- 画布尺寸：800 × 500 px（SVG viewBox="0 0 800 500"）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------------+
  |  [开关S]                    [L₁]                        |  上横线 y=100
  |     |                        |                         |
  |     |                        | 右竖线                  |
  |  [L₂]---[电压表V]            |                         |
  |     |                        |                         |
  |     |                     [电源]                      |  下横线 y=360
  |                                                        |
  |  +-------------------+  +---------------------------+  |
  |  | 故障分析          |  | 故障类型: L₁短路 [绿]     |  |  右侧面板 x=500
  |  | ----------------  |  | L₁状态: 不亮              |  |
  |  |                   |  | L₂状态: 亮                |  |
  |  |                   |  | 电压表示数: 有示数        |  |
  |  |                   |  | 是否符合题意: 符合题意[绿]|  |
  |  +-------------------+  +---------------------------+  |
  |                                                        |
  |       [◀ 上一步]      步骤 2/5      [下一步 ▶]         |  控件区 y=440~480
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：定义常量STEP_COUNT=5，变量currentStep（0~4）。每一步对应一个配置对象，包含各SVG元素的显隐、颜色、文本内容。
  2. 电流路径绘制：使用SVG `<path>` 预先画好完整回路的电流路径（蓝色），默认hidden。有电流的步骤通过设置`display: block`显示，无电流步骤`display: none`。箭头使用`<marker>`定义。
  3. 故障标记分组：将L₁短路导线、L₂短路导线、L₁断路标记、L₂断路标记分别放在独立的`<g id="scene1-short-l1">`等组中，默认`display: none`，根据步骤切换。
  4. 灯泡状态切换：通过修改circle的fill属性（#ffeb3b / #e0e0e0）和外围光晕circle的opacity（0.2 / 0）实现。
  5. 右侧面板更新：使用`textContent`更新5个值文本，并根据步骤设置`fill`颜色（黑/绿/红）。当前行可附加一个高亮背景rect，通过改变y位置实现。
  6. 按钮状态：在updateScene()函数中检查currentStep，步骤0时禁用「上一步」，步骤4时禁用「下一步】，通过设置disabled类和opacity实现。
  7. 坐标计算：所有坐标硬编码在SVG的d属性或cx/cy属性中，无需运行时计算。
- ID命名规范：所有交互元素ID必须以`scene1-`为前缀。例如：`scene1-switch-s`、`scene1-lamp-l1`、`scene1-current-path`、`scene1-panel-fault-type`、`scene1-btn-prev`、`scene1-btn-next`。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免全局变量污染，确保多场景合并时互不干扰。
