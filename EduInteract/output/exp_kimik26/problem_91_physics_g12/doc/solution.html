题目原文

如图所示，光滑绝缘水平面上固定着A、B、C三个带电小球，它们的质量为m，间距均为r，A、B带正电，电荷量均为q。现对C施一水平力F的同时放开三个小球，欲使三小球在运动过程中保持间距r不变，求：
（1）C球的电性和电荷量；
（2）水平力F的大小。

题目分析与整体思路

本题的核心条件是"保持间距r不变"，这意味着三球在运动过程中相对位置始终不变，可视为一个刚体整体向右做匀加速直线运动。因此，三球具有相同的加速度a，方向与外力F一致（水平向右）。

解题策略采用先整体、后隔离的方法：

  1. 整体法：将A、B、C视为整体，合外力为F，总质量为3m，得到加速度关系 F = 3ma
  2. 隔离法分析A球：通过受力分析和加速度方向，先判断C的电性，再列方程求出C的电荷量大小
  3. 隔离法分析C球：求出A、B对C的库仑合力，结合牛顿第二定律求出F

教学说明：A球受力分析与C球电性判定

教师应引导学生思考：A球的加速度水平向右，那么A球在水平方向必须受到向右的合力。A球受到B球的库仑力方向是确定的（竖直向上，斥力），因此C球对A球的作用力必须提供向右的分量。

关键推理步骤：

  1. 若C球带正电，A受到C的库仑力为斥力，方向沿CA向左上方，其水平分量向左，与向右的加速度矛盾，故排除
  2. 因此C球必带负电，A受到C的引力方向沿AC向右下方，与水平方向夹角30°
  3. 建立坐标系：x轴水平向右，y轴竖直向上
  4. 竖直方向：A球无竖直加速度，故合力为零
  • FBA = FCA · sin30°
  • kq²/r² = kq|Q|/r² · (1/2)
  • 解得 |Q| = 2q，即Q = -2q
  1. 水平方向：由牛顿第二定律
  • F_CA · cos30° = ma
  • kq(2q)/r² · (√3/2) = ma
  • 得 a = √3 kq²/(mr²)

讲解时需注意：强调"保持间距不变"意味着A球加速度也是水平向右，这是判断C球电性的关键依据。

步骤 0/7

教学说明：C球受力分析与外力F计算

在已知C带负电且电荷量为2q的前提下，对C球进行隔离分析。此处应充分利用对称性：A、B关于C的水平中轴线对称，且对C的库仑力大小相等，因此竖直分量必然抵消，只需计算水平分量。

推导步骤：

  1. A对C的引力F_AC方向沿CA（从C指向A，左上30°），大小为kq(2q)/r² = 2kq²/r²
  2. B对C的引力F_BC方向沿CB（从C指向B，左下30°），大小同为2kq²/r²
  3. 竖直方向：两力竖直分量大小相等、方向相反，合力为零
  4. 水平方向：两力水平分量均向左，大小为F_AC·cos30° = 2kq²/r² · √3/2 = √3 kq²/r²
  5. 库仑合力：F_库 = 2 · √3 kq²/r² = 2√3 kq²/r²，方向水平向左
  6. 对C球列牛顿第二定律（向右为正）：F - F_库 = ma
  7. 代入a = √3 kq²/(mr²)和m，得F = 2√3 kq²/r² + m · √3 kq²/(mr²) = 3√3 kq²/r²
  8. 验证：整体法F = 3ma = 3m · √3 kq²/(mr²) = 3√3 kq²/r²，结果一致

讲解建议：强调对称性分析可以大幅简化计算，避免繁琐的竖直方向方程。最后通过整体法进行结果验证，培养学生解题的严谨性。

步骤 0/7

总结：完整解答与课堂讲解建议

最终答案

  1. C球带负电，电荷量大小为 2q（即Q = -2q）
  2. 水平力大小为 F = 3√3 kq²/r²

完整推导回顾

  1. 由"间距不变"得三球相对静止，整体加速度a = F/(3m)，方向水平向右
  2. 隔离A球：
  • 竖直方向平衡：kq²/r² = kq|Q|/r² · sin30°，得|Q| = 2q
  • 水平方向：kq|Q|/r² · cos30° = ma，得a = √3 kq²/(mr²)
  1. 隔离C球：
  • A、B对C的引力竖直分量抵消，水平合力F_库 = 2 · [kq(2q)/r²] · cos30° = 2√3 kq²/r²
  • 由F - F_库 = ma，代入得F = 3√3 kq²/r²

课堂讲解建议

  • 关键突破口：引导学生从"保持间距不变"提炼出"相对静止、共同加速度"这一隐含条件
  • 电性判断：这是本题的易错点。务必让学生先进行方向分析，而不是盲目假设C带正电列方程。可通过Scene 2中的"矛盾试探"步骤强化这一逻辑
  • 对称性意识：分析C球时，提醒学生观察A、B的对称位置，预判竖直分量抵消，从而只需列水平方向方程
  • 双验证：鼓励学生在求出F后，用整体法F=3ma进行快速验证，培养良好的解题检验习惯
  • 拓展思考：可追问学生——若A、B电荷量不相等，或三球质量不同，还能保持间距不变吗？引发对条件的深入理解
