[图示主题与整合说明]
- 本图示主题：A球隔离受力分析与C球电荷量推导
- 整合的步骤/概念：以A为隔离体，逐步添加B对A的库仑斥力、试探C带正电的矛盾、确定C带负电后的库仑引力，建立正交坐标系，进行力的分解，列竖直方向平衡方程得出Q=2q（负电），再列水平方向牛顿第二定律得出加速度表达式。
- 教学价值：教师可按照课堂节奏，逐层展开受力分析、电性判断、正交分解和方程建立，让学生跟随每一步的逻辑推导，理解整体法与隔离法的结合。

[分步序列]
- 初始状态（步骤0）：显示A球（高亮，黑边白底3px）、B球、C球（均透明度30%灰色），以及AB、AC、BC三条灰色虚线连线（透明度30%）。球名标签A、B、C始终显示。右侧无方程。教师可说明：我们以A为研究对象，将其隔离出来。
- 步骤1：点击「下一步」→ 添加B对A的库仑斥力F_BA：红色实线箭头从A竖直向上长度60px，标签"F_BA"在箭头左侧(210,120)。教师讲解：A、B均带正电，B对A的斥力竖直向上，大小为kq²/r²。
- 步骤2：点击「下一步」→ 添加电性试探：若C带正电，则C对A的斥力沿CA延长线向左上方30°（方向角150°），用灰色虚线箭头表示（长度60px，透明度50%），并在箭头旁标注红色"矛盾"。教师讲解：若C带正电，该斥力水平分量向左，无法使A产生向右的加速度，与整体向右加速矛盾，故C不可能带正电。
- 步骤3：点击「下一步」→ 移除错误斥力及"矛盾"标签；添加C对A的库仑引力F_CA：蓝色实线箭头从A向右下方30°长度120px（大小为2kq²/r²），标签"F_CA"在(300,185)。教师讲解：C必带负电，对A为引力，方向沿AC连线指向C。
- 步骤4：点击「下一步」→ 建立正交坐标系：以A为原点，x轴水平向右画至(420,150)，y轴竖直向上画至(250,30)，均为灰色实线带箭头；添加30°角弧（圆心A，半径35，从x轴正方向顺时针到AC方向），标签"30°"在(300,165)。教师讲解：建立坐标系，将F_CA分解。
- 步骤5：点击「下一步」→ 添加投影分解线：从F_CA箭头端点(354,210)分别向x轴作垂线（竖直虚线至(354,150)）、向y轴方向作水平虚线（至(250,210)）；标注水平分量"F_CA·cos30°"在x轴上方(302,140)，标注竖直分量"F_CA·sin30°"在水平投影线下方(265,225)。教师讲解：F_CA分解为水平向右和竖直向下两分量。
- 步骤6：点击「下一步」→ 在画面右侧添加竖直方向平衡方程：标题"竖直方向平衡："(500,130)，方程"F_BA = F_CA·sin30°"(500,160)，结论"Q = 2q（负电）"(500,200)绿色加粗。教师讲解：竖直方向无加速度，合力为零，代入F_BA=kq²/r²、F_CA=k|Q|q/r²，解得|Q|=2q，且C带负电。
- 步骤7：点击「下一步」→ 在画面右侧添加水平方向方程：标题"水平方向："(500,260)，方程"F_CA·cos30° = ma"(500,290)，结论"a = √3 kq²/(mr²)"(500,320)。教师讲解：水平方向由牛顿第二定律，代入Q=2q，得到系统加速度。
- 最终步骤（步骤7）：展示全部受力、坐标系、分解、方程和结论，形成完整推导链。教师可随时点击「上一步」回退复习。

[技术实现]
- JS库选择：原生SVG（简单几何、箭头、虚线首选），无需引入外部重型库。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  y轴↑                                            |
  |   |    A ●←──────────┐                           |
  |   |   /| \           |  右侧方程区                |
  |   |  / |  \          |  [竖直方程]                |
  |   | /  |   \ C ●←F   |  [Q=2q结论]               |
  |   |/   |    /        |  [水平方程]                |
  |  B●    |   /         |  [加速度结论]              |
  |        |  /          |                           |
  |        | / F_CA      |                           |
  |        |/            |                           |
  |        +──────→ x轴  |                           |
  |                      |                           |
  | [◀上一步]  步骤k/7  [下一步▶]                    |
  +--------------------------------------------------+
  控件栏在SVG内底部 y=440~490（HTML absolute覆盖）
  ```
- 关键实现要点：
  1. 状态机设计：定义全局变量 `currentStep`（0~7）。每一步对应一个可见元素ID集合。点击按钮时更新 `currentStep`，遍历所有元素按规则设置 `display` 或 `opacity`。
  2. 坐标计算：等边三角形边长r取150px，A(250,150)、B(250,300)、C(380,225)。力矢量长度按比例：F_BA=60px（kq²/r²），F_CA=120px（2kq²/r²）。角度30°由等边三角形几何确定（cos30°=√3/2，sin30°=1/2）。
  3. 箭头实现：SVG `<defs>` 中定义 `<marker>`（id分别为 `scene2-arrow-red`、`scene2-arrow-blue`、`scene2-arrow-gray`），用于F_BA、F_CA、坐标轴末端。
  4. 虚线样式：`stroke-dasharray="5,5"` 用于连线、错误斥力、投影线。
  5. 透明度控制：B球、C球、三边连线初始 `opacity: 0.3`；错误斥力 `opacity: 0.5`。
  6. 动画曲线：元素出现/消失使用CSS transition `opacity 0.3s ease`，无需复杂动画。
  7. 事件绑定：按钮绑定 `click` 事件，更新状态后调用 `renderStep()` 刷新视图。
- ID命名规范：所有SVG元素及HTML控件ID必须以 `scene2-` 为前缀。例如：`scene2-ball-a`、`scene2-force-fba`、`scene2-btn-prev`、`scene2-btn-next`。JS中严格使用 `document.getElementById` 获取元素，禁止全局class选择，避免多场景合并时跨场景污染。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })()` 立即执行函数中，变量不泄露全局作用域。
