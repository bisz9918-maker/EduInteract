# Scene 1 Implementation Plan

<SCENE_VISION_STORYBOARD_AND_TECHNICAL_PLAN>

[图示主题与整合说明]
- 本图示主题：带电粒子在组合电场中的三段运动轨迹全览
- 整合的步骤/概念：
  1) 平行板电容器内的类平抛偏转（匀强电场）；
  2) 无电场区域的匀速直线运动；
  3) 点电荷电场中的曲线运动直至垂直击中荧光屏。
- 教学价值：教师通过分步导航，引导学生从静止装置认知→电场建立→三段轨迹逐步展开→待求量标注，建立"宏观装置→运动分段→物理量对应"的完整认知链。分步呈现避免信息过载，符合从静态到动态、从已知到未知的教学逻辑。

[分步序列]
步骤0（初始状态）：展示静止装置与全部已知条件
- 显示元素：A/B板、中心线RO、PS线、荧光屏EF、点电荷Q（仅黑点，无电场线）、所有点标签(A,B,R,M,N,P,S,O,E,F)、长度标注(l,d,L)、电势与速度标注(U_AB=300V, v₀)、已知条件框(q,m,k)
- 隐藏元素：粒子⊕、所有轨迹、所有电场线、所有高亮区域、所有待求量标注
- 教师操作：讲解装置结构，让学生识别各区域与已知量

步骤1：高亮平行板区域，建立电场与入射条件
- 新增显示：平行板高亮矩形、3条竖直向下电场线（蓝色箭头，示意A→B电场）、粒子⊕、v₀箭头
- 高亮：平行板区域（#1565c0, 15%透明度）
- 教师操作：讲解A板电势高，电场方向向下，正粒子以v₀垂直入射

步骤2：展示第一段轨迹——平行板内的类平抛运动
- 新增显示：轨迹1（R→飞出点），使用stroke-dashoffset动画从左向右"画出"，持续时间600ms，ease-out
- 飞出点标记：在(240,268)处显示一个小黑点（2px半径）表示飞出位置
- 保持显示：步骤1所有元素
- 教师操作：讲解粒子在匀强电场中受恒定向下电场力，做类平抛运动

步骤3：展示第二段轨迹——无电场区域的匀速直线运动
- 新增显示：轨迹2（飞出点→PS界面），同样使用画出动画（600ms）
- 新增显示：无电场区域高亮矩形（覆盖x=240~480, y=200~320）
- 保持显示：前两步所有元素
- 教师操作：讲解飞出电场后不受力，以飞出时速度做匀速直线运动，穿过MN与PS间区域

步骤4：展示第三段轨迹——点电荷电场中的曲线运动
- 新增显示：轨迹3（PS→荧光屏EF），画出动画（800ms，因路径较长）
- 新增显示：点电荷周围4条蓝色径向电场线（箭头指向Q）、点电荷区域高亮圆形
- 保持显示：前三步所有元素
- 教师操作：讲解粒子进入点电荷电场，受库仑力作用轨迹弯曲，最终垂直打在荧光屏上（速度沿水平方向）

步骤5：完整三段轨迹与待求量标注
- 新增显示：Y偏离标注（PS线右侧双向箭头+红色Y标签）、θ角度弧（飞出点处，水平线与切线夹角，红色θ标签）、Q点电荷电量（红色Q标签）
- 所有三段轨迹同时完整显示（线宽可略微加粗至2px以强调）
- 高亮区域全部淡出（opacity降至5%或隐藏），避免干扰待求量阅读
- 教师操作：总结三段运动，明确三个待求量：PS处偏离距离Y、飞出角度θ、点电荷电量Q

（教师可随时点击「上一步」回退至任意步骤复习）

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「上一步」按钮：位于画布底部x=300, y=460，宽80×高30，背景#1565c0，文字白色，点击回退一个步骤，步骤0时禁用（opacity=0.4）
  2. 「下一步」按钮：位于画布底部x=420, y=460，宽80×高30，背景#1565c0，文字白色，点击前进一个步骤，步骤5时禁用（opacity=0.4）
  3. 步骤指示器：位于两按钮中间x=380, y=455，显示"步骤 X/5"，字体14px，颜色#333
- 教师操作流程：
  1. 教师打开图示，默认步骤0，向学生介绍装置结构与已知量；
  2. 点击「下一步」进入步骤1，讲解电场方向与粒子入射；
  3. 继续点击「下一步」，每步展示一段轨迹，配合讲解该段运动的物理规律；
  4. 到达步骤5，完整轨迹与三个待求量同时呈现，教师引导学生建立求解思路；
  5. 可随时点击「上一步」回退，复习某段运动或重新强调关键条件。

[技术实现]
- JS库选择：原生 SVG + 原生 JavaScript（理由：本场景以静态几何图形、路径轨迹和简单显隐控制为主，无需复杂数据绑定或3D渲染，原生SVG性能最优，路径动画可直接操作stroke-dasharray/stroke-dashoffset）
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  +--------------------------------------------------+
  |  [顶部留白 y=0~60]                                |
  |                                                  |
  |  A板 ===================================== M     |
  |       | 电场线 ↓↓  |                             |
  |  R ⊕  |            |                             |
  |  ----→v₀           |         无电场区            |
  |       |            |                             |
  |       |            |    L    |                  |
  |  B板 ===================================== N     |
  |            l            PS线  |     O ●          |
  |                               |      \           |
  |  [已知框]                     |       \          |
  |  q=... m=... k=...            |        \  轨迹3  |
  |                               |         \        |
  |                               |          → EF    |
  +--------------------------------------------------+
  |  [控件栏 y=440~490]                               |
  |       [◀上一步]  步骤 X/5  [下一步▶]              |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `let currentStep = 0;` 记录当前步骤（0~5）。`render()`函数根据currentStep设置各元素的`style.display`或SVG的`visibility`属性。
  2. 轨迹画出动画：对每条轨迹path，计算`path.getTotalLength()`，设置`stroke-dasharray = length; stroke-dashoffset = length;`，然后用`requestAnimationFrame`或CSS transition在600ms内将dashoffset减至0。动画仅在首次进入该步骤时触发，回退再前进不重复播放（可用`data-animated`标记）。
  3. 高亮区域过渡：使用CSS transition控制opacity，0→0.15用时300ms，步骤切换时平滑淡入淡出。
  4. 角度弧θ：使用SVG path绘制小圆弧，`M250,268 A12,12 0 0,0 262,278`（示意），实际角度需根据切线斜率计算。为简化，固定画一个开口向右下的小扇形弧。
  5. 待求量颜色切换：步骤5时，通过JS将Y、θ、Q标签的`fill`属性设为`#c62828`，并添加`font-weight:bold`（SVG中用`font-weight="bold"`）。
  6. 按钮禁用逻辑：步骤0时「上一步」禁用，步骤5时「下一步」禁用。禁用状态通过添加`.disabled`类降低opacity并阻止点击。
  7. 粒子符号⊕：使用SVG `<text>` 元素在(80,250)绘制"⊕"，字体16px，红色，通过`dominant-baseline="middle" text-anchor="middle"`精确居中于圆点。
  8. 电场线箭头：使用SVG `<marker>` 定义箭头，标记在电场线末端。
- ID命名规范：所有交互元素ID必须以`scene1-`为前缀。例如：
  - 图形：`scene1-plate-a`, `scene1-plate-b`, `scene1-trajectory-1`, `scene1-trajectory-2`, `scene1-trajectory-3`
  - 标签：`scene1-label-a`, `scene1-label-y`, `scene1-label-theta`, `scene1-label-q`
  - 高亮：`scene1-highlight-plate`, `scene1-highlight-free`, `scene1-highlight-charge`
  - 控件：`scene1-btn-prev`, `scene1-btn-next`, `scene1-step-text`
  - 容器：`scene1-svg-container`
  JS中严格使用`document.getElementById()`获取元素，禁止全局class选择，避免多场景合并时跨场景污染。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，变量不泄露全局作用域。
- 数学公式渲染：q、m、k的指数使用SVG `<tspan>` 配合`baseline-shift="super"`实现上标，无需引入MathJax（减少依赖）。
