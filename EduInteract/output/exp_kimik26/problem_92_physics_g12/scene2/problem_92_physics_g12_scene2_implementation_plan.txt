[图示主题与整合说明]
- 本图示主题：平行板类平抛运动与PS界面偏离距离分析
- 整合的步骤/概念：
  1) 平行板电场方向与带电粒子受力分析；
  2) 类平抛运动分解（水平匀速+竖直匀加速）；
  3) 飞出平行板时的速度合成与偏转角θ；
  4) 板内竖直偏转距离y1的标注；
  5) 无电场区域匀速直线运动延伸至PS界面；
  6) 速度反向延长线过水平位移中点C的重要推论；
  7) 利用相似三角形推导PS处总偏离Y；
  8) 完整结果标注（y1=3cm, Y=12cm, tanθ=0.75）。
- 教学价值：教师可通过分步导航精确控制每个推导环节的出现时机，配合课堂讲解实现"受力→分解→合成→推论"的认知递进，相似三角形的几何直观有助于学生理解为何无需计算中间坐标即可求出总偏离。

[分步序列]
- 步骤0（初始状态）：展示题目基础条件
  显示元素：A板、B板、板间高亮区、中心线、R点、v0箭头、3条电场线、MN线、PS线、O点、EF荧光屏、l/d/L双向箭头及标签、A/B/R/v0/M/N/P/S/O/E/F/U_AB标签
  讲解要点：明确已知条件l=8cm, d=8cm, U_AB=300V, v0=2×10^6m/s，电场方向A→B

- 步骤1（受力分析）：点击「下一步」
  新增：F=qE红色箭头（板内，向下）及标签
  讲解要点：正电荷在电场中受力方向与电场方向相同，F=qE=3.75×10^-7N

- 步骤2（运动分解）：点击「下一步」
  新增：vy绿色箭头（板内，向下，表示竖直分速度逐渐增大）及标签
  讲解要点：水平方向不受力→匀速(v0)；竖直方向受恒力→匀加速(vy=at)

- 步骤3（轨迹与合速度）：点击「下一步」
  新增：板内抛物线轨迹（黑色实线）、飞出点合速度v绿色箭头及标签
  讲解要点：运动合成形成类平抛轨迹，飞出时速度为v0与vy的矢量和

- 步骤4（板内偏转与角度）：点击「下一步」
  新增：y1红色双向箭头及标签、θ弧线及标签
  讲解要点：板内竖直偏转y1=3cm，飞出时速度方向与水平夹角θ，tanθ=vy/v0=0.75

- 步骤5（无电场区域延伸）：点击「下一步」
  新增：飞出点至PS的直线轨迹（匀速直线运动）、Y红色双向箭头及标签
  讲解要点：飞出电场后不受力，以速度v做匀速直线运动直至PS界面

- 步骤6（反向延长线推论）：点击「下一步」
  新增：C点标记（水平位移中点，x=180）、速度反向延长线（灰色虚线，过C点）
  讲解要点：类平抛重要推论——速度反向延长线必过水平位移的中点C

- 步骤7（相似三角形）：点击「下一步」
  新增：小三角形（C-垂足-飞出点）与大三角形（C-PS垂足-PS落点）蓝色半透明填充
  讲解要点：两三角形相似，利用相似比Y/y1=(l/2+L)/(l/2)=4，可快速求出Y

- 步骤8（完整结论）：点击「下一步」
  更新：y1标签→"y1=3cm"、Y标签→"Y=12cm"、新增tanθ=0.75标注（红色粗体）
  讲解要点：总结三个待求量（1）Y=12cm；（2）tanθ=0.75（θ≈36.9°）；（3）为后续求点电荷电量奠定基础

[技术实现]
- JS库选择：原生SVG + 原生JavaScript（无外部库）。理由：本场景以静态几何图形和分步显隐为主，无需复杂数学计算或3D渲染，原生SVG路径和JS状态机即可高效实现。
- 画布尺寸：800×500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |  A板                                               |
  |    ⊕ v0→  ↓电场线  ↓电场线  ↓电场线    M          |
  | R·------------------------------------------------ |
  |    ↓F        ↓vy        轨迹曲线→飞出点·v          |
  |  B板              ↑y1    ↘θ                       |
  |    l←────────→    N      ↘                       |
  |  d↑                      ↘ 无电场区               |
  |    L←────────────────────→↓                      |
  |  P                      PS↓Y                     |
  |    ·O    EF屏              ↘                     |
  |  S                                               |
  |                                                  |
  |              [◀上一步] [重置] [下一步▶]            |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：变量 `currentStep`（0~8），数组 `stepElements` 记录每步应显示/隐藏的元素ID集合。点击按钮时更新 `currentStep`，遍历所有元素按规则设置 `display` 属性。
  2. 抛物线轨迹：板内轨迹为类平抛曲线，用SVG二次贝塞尔 `M 100 180 Q 180 180 260 240` 精确表示（控制点取水平位移中点y坐标，可精确拟合y∝x²）。
  3. 双向箭头：SVG `<marker>` 定义箭头头部，对偏转距离和长度标注使用 `marker-start`（反向箭头）和 `marker-end`（正向箭头）组合实现双向效果。
  4. 相似三角形填充：使用 `<polygon>` 元素，填充色 `#1565c0`，`fill-opacity="0.2"`，边框 `stroke="#1565c0" stroke-width="1"`。
  5. 步骤8标签切换：通过JS修改textContent，将 "y1"→"y1=3cm"、"Y"→"Y=12cm"，并添加 "tanθ=0.75" 文本元素，样式设为 `#c62828` + `font-weight:bold`。
  6. 按钮禁用逻辑：步骤0时禁用「上一步」，步骤8时禁用「下一步」，通过设置 `disabled` 属性实现。
  7. 动画曲线：元素出现使用CSS `opacity` 过渡（0→1，duration 200ms），无位移动画，确保布局稳定。
- ID命名规范：所有交互元素ID必须以 `scene2-` 为前缀。例如：
  - 图形：`scene2-plate-a`, `scene2-plate-b`, `scene2-trajectory-in`, `scene2-trajectory-out`
  - 箭头：`scene2-arrow-v0`, `scene2-arrow-vy`, `scene2-arrow-v`, `scene2-arrow-f`
  - 标注：`scene2-label-y1`, `scene2-label-Y`, `scene2-label-theta`
  - 控件：`scene2-btn-prev`, `scene2-btn-next`, `scene2-btn-reset`, `scene2-step-indicator`
  JS中严格使用 `document.getElementById` 获取元素，禁止跨场景选择器。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免全局变量污染，确保多场景合并时互不干扰。
