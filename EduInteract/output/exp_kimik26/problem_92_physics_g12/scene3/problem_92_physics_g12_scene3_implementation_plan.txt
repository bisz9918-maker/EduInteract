[分步序列]
- 步骤0（初始状态）：显示PS界面、中心线、O点、荧光屏EF；显示距离标注s'（PS到O）与D（O到EF）；显示标签P、S、O、E、F、s'、D。建立空间框架。
- 步骤1（初态标注）：新增粒子在PS处的位置（红色圆点，中心线下方Y处）；新增初速度v（绿色箭头，与水平成θ角斜向右下）；新增偏距标注Y（竖直双向箭头）。显示标签Y、v。展示粒子进入点电荷电场前的状态。
- 步骤2（电场分布）：新增点电荷Q标注（O点右侧，红色粗体Q）；新增蓝色径向电场线（8条，指向O）与电场区域浅蓝填充。显示标签Q。强调场源为负电荷，建立受力方向预期。
- 步骤3（轨迹展示）：新增粒子轨迹曲线（黑色实线，从PS处开始向右下方轻微弯曲后向中心线靠拢直至EF）。直观呈现运动路径。
- 步骤4（速度演变）：在轨迹上叠加3个绿色短箭头，分别位于(191,346)右下20°、(306,361)右下10°、(431,364)近似水平，显示速度方向由斜向右下逐渐趋于水平的过程。帮助学生理解切向速度变化。
- 步骤5（末态撞击）：在撞击点(720,260)标注末速度v_f（绿色水平箭头）；高亮撞击点（红色圆点）；可高亮EF屏（加粗或变亮）。显示标签v_f。确认末态条件：垂直打在荧光屏上（速度水平）。
- 步骤6（几何关系）：新增速度v的反向延长线（灰色虚线，从PS处向左上方延伸）；新增角度θ标注弧线（中心(100,320)，半径25px，0°~37°）及标签θ；新增角动量守恒示意（O点处灰色弧形箭头）及标签L。为教师讲解"利用几何相似或角动量守恒求Q"提供视觉锚点。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「上一步」按钮：位于(280,450)-(380,480)，点击回退到上一分步
  2. 「下一步」按钮：位于(420,450)-(520,480)，点击推进到下一分步
  3. 步骤指示器：位于(400,495)，显示当前步骤编号（如"步骤 3/6"）
- 教师操作流程：
  1. 教师加载图示，步骤0自动展示空间框架（PS、中心线、O、EF），讲解区域划分
  2. 点击「下一步」进入步骤1，讲解粒子在PS处的初始状态（位置Y、速度v方向）
  3. 继续点击「下一步」依次展示电场分布→轨迹→速度演变→末态撞击→几何关系
  4. 在任意步骤可点击「上一步」回退复习，强化因果逻辑
  5. 步骤6时教师可结合反向延长线与角动量示意，引导学生建立守恒方程

[技术实现]
- JS库选择：原生SVG（所有元素均为几何图形、路径与文本，SVG最为直接，无需引入外部库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  P                                                |
  |  |  s'标注          D标注          E              |
  |  |  ↕               ↕              |              |
  |  |  ~  ~  ~  ~  ~  ~  ~  ~  ~  ~  |  EF屏        |
  |  |                                 |              |
  |  |    O(●)Q                        |              |
  |  |   /  \                          |              |
  |  |  /电场区\                       |              |
  |  | /         \                     |              |
  |  |/           \                    |              |
  | R●----→v      \                   |              |
  |  |\ θ          \ 轨迹曲线 → → →  ●撞击点        |
  |  | \            \                  |→v_f          |
  |  |  Y↓           \                 |              |
  |  |                \                |              |
  |  S                 \               F              |
  |                     \                             |
  |  [上一步]    步骤 X/6    [下一步]                 |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 `currentStep`（0~6）控制当前步骤；每个SVG元素预设 `display:none`，根据 `currentStep` 值决定显示/隐藏
  2. 元素分组：按步骤将元素包裹在 `<g id="scene3-step-N">` 中（N=0~6），通过切换组的 `display` 属性实现整步显隐；步骤0的基础元素（PS、中心线、O、EF、s'、D）始终显示
  3. 坐标计算：轨迹使用三次贝塞尔路径 `M 100 320 C 200 360, 400 380, 550 350 C 640 332, 700 260, 720 260`；速度箭头方向根据轨迹切线估算并适当夸大以增强教学可读性
  4. 动画曲线：分步切换无需复杂动画，直接显隐即可；若需柔和过渡，可对显隐添加CSS `transition: opacity 0.3s`
  5. 事件绑定：上一步/下一步按钮绑定 `click` 事件，更新 `currentStep` 后调用 `render()` 刷新视图；在边界处禁用对应按钮（步骤0时禁用「上一步」，步骤6时禁用「下一步」）
  6. 电场线绘制：8条线段从四周均匀分布指向O点，使用 `<marker>` 定义箭头，复用于所有电场线与速度箭头
- ID命名规范：所有元素ID必须以 `scene3-` 为前缀，例如 `scene3-ps-line`、`scene3-particle-start`、`scene3-trajectory-path`、`scene3-btn-prev`、`scene3-btn-next`
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })()` 中，避免多场景合并时全局变量污染
