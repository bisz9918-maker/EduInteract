[图示主题与整合说明]
- 本图示主题：三棱柱的立体结构与表面展开过程
- 整合的步骤/概念：
  1) 三棱柱的立体认知（5个面、9条棱、6个顶点）；
  2) 面的组成分类（3个侧面+2个底面）；
  3) 沿侧棱剪开并摊平为展开图的动态过程；
  4) 标准展开图的结构特征总结（3矩形+2三角形+分居两侧）。
- 教学价值：教师通过分步导航，可逐步引导学生从立体到平面建立空间观念，尤其帮助学生理解"为什么B、C、D不是正确展开图"（B两底面同侧重叠、C缺一个底面、D无底面）。

[分步序列]
- 步骤0（初始状态）：
  - 左侧显示完整三棱柱立体图（6顶点、9条棱、5个面轮廓）
  - 实线棱：AB、BC、DE、EF、BE、CF（#000000, 2px）
  - 虚线棱：AC、AD、DF（#888888, 1px dash）
  - 6个顶点标签A-F按坐标表标注
  - 右侧空白，无填充色
  - 控件显示"步骤 1/4"

- 步骤1（面组成认知）：
  - 点击「下一步」触发
  - 5个面从立体图位置向外分离平移：
    * 前面ABED向下偏移(0, 30)
    * 右侧面BCFE向右下偏移(30, 30)
    * 左侧面ACFD向左上偏移(-30, -30)
    * 底面ABC向下偏移(0, 50)
    * 顶面DEF向上偏移(0, -50)
  - 3个侧面填充蓝色高亮（#1565c0, fill-opacity 0.2）
  - 2个底面填充红色高亮（#c62828, fill-opacity 0.2）
  - 原立体图位置保留淡灰轮廓（opacity 0.3）
  - 显示标签："侧面×3"(340,250)、"底面×2"(340,300)、"共 5 个面"(220,80)
  - 控件显示"步骤 2/4"

- 步骤2（展开动画）：
  - 点击「下一步」触发
  - 在立体图BE棱处显示绿色剪开虚线（#2e7d32, 2px, dash 6,4）
  - 5个面从分离位置动画过渡到右侧展开图位置（耗时600ms，ease-out）：
    * 左侧面ACFD → 展开图矩形1 (420,170)-(540,330)
    * 前面ABED → 展开图矩形2 (540,170)-(660,330)

    * 底面ABC → 展开图底面三角 (540,330)-(660,330)-(600,410)
    * 顶面DEF → 展开图顶面三角 (540,170)-(660,170)-(600,90)
  - 动画过程中显示灰色运动轨迹虚线（#888888, 1px dash）
  - 动画完成后，左侧立体图淡出至opacity 0.1
  - 控件显示"步骤 3/4"

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  * 「上一步」按钮：位于SVG内底部(300, 455)，宽80×高30，点击回退到上一状态
  * 「下一步」按钮：位于SVG内底部(420, 455)，宽80×高30，点击进入下一状态
  * 步骤指示文字：位于(400, 475)，显示当前步骤编号（如"步骤 2/4"）
- 教师操作流程：
  1. 教师展示步骤0，让学生观察三棱柱立体图并辨认顶点；
  2. 点击「下一步」进入步骤1，引导学生数出5个面，区分侧面（蓝）与底面（红）；
  3. 点击「下一步」进入步骤2，演示沿侧棱剪开并摊平的过程，强调"剪开→翻开"的动作；
  4. 点击「下一步」进入步骤3，总结展开图三大特征，回扣题目选项A为什么正确、B/C/D为什么错误；
  5. 可随时点击「上一步」回退复习。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript（场景为简单几何图形与分步显隐，无需引入重型库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  步骤0-1: 立体图(左)      步骤2-3: 展开图(右)      |
  |  x=140~310               x=420~780               |
  |  y=120~410               y=90~410                |
  |                                                   |
  |  特征文字(步骤3): y=60~85, x=420~680             |
  |                                                   |
  |  [◀上一步]  步骤 X/4  [下一步▶]                  |
  |  y=440~490  控件栏区域                             |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `scene1_currentStep` ∈ {0,1,2,3}，每次按钮点击更新状态并调用 `scene1_renderStep()`。
  2. 元素分组：每个步骤的视觉元素放入独立的SVG `<g>` 组，如 `scene1-group-step0`、`scene1-group-step1` 等，通过设置 `display` 或 `opacity` 控制显隐。
  3. 步骤1分离动画：使用CSS `transition: transform 0.4s ease-out` 对5个面所在的 `<g>` 或 `<polygon>` 应用 `translate()` 偏移。
  4. 步骤2展开动画：使用JS `requestAnimationFrame` 或CSS `transition` 将5个面从步骤1的分离位置动画过渡到右侧展开图坐标（600ms，ease-out）。动画过程中临时添加灰色虚线作为运动轨迹，动画结束后移除。
  5. 剪开线：在步骤2开始时，在BE棱位置绘制一条与BE重合的绿色虚线（略向外偏移2px避免完全重叠），持续显示到步骤3。
  6. 淡入淡出：步骤2结束时左侧立体图组 `opacity` 过渡到0.1；步骤3时设置为 `display:none`。
  7. 按钮状态：步骤0时「上一步」禁用（disabled），步骤3时「下一步」禁用。
- ID命名规范：
  * 立体图棱：`scene1-edge-ab`、`scene1-edge-ac`（虚线）、`scene1-edge-ad`（虚线）等
  * 立体图面：`scene1-face-abed`、`scene1-face-acfd`、`scene1-face-bcfe`、`scene1-face-abc`、`scene1-face-def`
  * 展开图元素：`scene1-unfold-rect1`、`scene1-unfold-rect2`、`scene1-unfold-rect3`、`scene1-unfold-base`、`scene1-unfold-top`
  * 标签：`scene1-label-a` ~ `scene1-label-f`、`scene1-label-side`、`scene1-label-base`、`scene1-label-total`
  * 特征：`scene1-feature-1`、`scene1-feature-2`、`scene1-feature-3`、`scene1-check-1`、`scene1-check-2`
  * 控件：`scene1-btn-prev`、`scene1-btn-next`、`scene1-step-text`
  * 组容器：`scene1-group-solid`、`scene1-group-unfold`
- IIFE隔离：所有JS代码包裹在 `(function() { ... })();` 中，避免多场景合并时全局变量污染。
