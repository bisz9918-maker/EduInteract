场景导航：Scene 1

完整题目原文

笔直的海岸线上依次有A、B、C三个港口，甲船从A港口出发，沿海岸线匀速驶向C港，1小时后乙船从B港口出发，沿海岸线匀速驶向A港，两船同时到达目的地。甲船的速度是乙船的1.25倍，甲、乙两船与B港的距离y（km）与甲船行驶时间x（h）之间的函数关系如图所示，下列说法：
① A、B港口相距400km；
② 甲船的速度为100km/h；
③ B、C港口相距200km；
④ 乙出发4h时两船相距220km。
其中正确的个数是（ ）
A. 4个 B. 3个 C. 2个 D. 1个

题目分析

本题是一道一次函数图像的实际应用题，核心在于准确读取函数图像中的关键坐标信息，并将图像语言转化为行程问题的数量关系。图像的横轴为甲船行驶时间x（h），纵轴为两船与B港的距离y（km）。图中有两条折线（线段），分别对应甲船和乙船的运动过程。

整体讲解思路

  1. 先带领学生理解坐标系的实际意义：横轴是“甲船行驶时间”，纵轴是“与B港的距离”，明确y=0表示船刚好在B港。
  2. 分步读取甲船折线的关键节点(0,400)和(4,0)，求出AB距离和甲船速度。
  3. 利用速度倍数关系求出乙船速度，再结合乙船出发晚1小时、两船同时到达的条件，求出乙船行驶时间和甲船总行驶时间。
  4. 进而求出BC距离，并验证四个说法的正误。特别注意说法④的陷阱：两船在B港两侧，相距应为各自距B距离之和，而非差。

图示规划说明

本题所有分析均围绕同一幅函数图像展开，因此整合为1个交互式图示。通过分步按钮导航，教师可逐步展示图像解读、信息提取、推导计算和结论验证的完整过程，避免一次性呈现过多信息。

步骤 0/4

本图示的教学说明

教师在使用本图示时，应引导学生遵循“先识图、再读数、后建模”的认知顺序：

  1. 识图阶段（步骤0）：让学生观察图像中有几条线、分别代表什么。强调纵轴y的物理意义是“与B港的距离”，而非“与A港的距离”或“行驶路程”。提问：为什么甲船的线先下降后上升？（答：甲船从A驶向C，先靠近B、再远离B。）为什么乙船的线从x=1开始？（答：乙船晚出发1小时。）
  1. 读数阶段（步骤1-2）：
  • 甲船线经过(0,400)，说明甲船出发时距B港400km，即AB=400km（说法①正确）。
  • 甲船线经过(4,0)，说明4小时后甲船到达B港，因此v甲=400÷4=100km/h（说法②正确）。
  • 由v甲=1.25v乙，得v乙=100÷1.25=80km/h。
  • 乙船从B到A需行驶400km，时间=400÷80=5h。乙船晚1h出发且同时到达，故甲船总行驶时间=1+5=6h。
  1. 建模与验证阶段（步骤3-4）：
  • 甲船前4h走400km到B，后2h（6−4=2）以100km/h继续行驶，故BC=100×2=200km（说法③正确）。
  • 验证说法④时，先确定“乙出发4h时”对应甲船行驶时间x=5h。此时：
  • 甲船已行驶5h，路程500km，过B后100km，故y甲=100km。
  • 乙船已行驶4h，路程4×80=320km，故y乙=320km。
  • 关键辨析：两船分别在B港的两侧（甲在B→C方向，乙在B→A方向），因此两船实际距离为两段距离之和：100+320=420km。220km是两者与B港距离的差值|320−100|，并非两船间距。故说法④错误。
  1. 课堂互动建议：在步骤4可暂停，先让学生投票猜测距离是220还是420，再利用图示动画揭示两船分居B港两侧的几何事实，强化“数形结合”与“分类讨论（同侧/异侧）”的意识。

总结：完整解答与课堂讲解建议

完整解答

由图像可知，甲船折线经过(0,400)和(4,0)。

  1. AB距离 = 400km，甲船速度 = 400÷4 = 100km/h。故①②正确。
  2. 乙船速度 = 100÷1.25 = 80km/h。乙船从B到A行驶400km，需时400÷80 = 5h。乙船晚出发1h且与甲船同时到达，故甲船总行驶时间 = 6h。
  3. 甲船从B到C的行驶时间 = 6−4 = 2h，BC = 100×2 = 200km。故③正确。
  4. 乙出发4h时，甲船已行驶5h。甲船距B港100km（在B、C之间），乙船距B港320km（在A、B之间）。两船分居B港两侧，实际相距100+320 = 420km ≠ 220km。故④错误。

正确的个数为3个，答案选 B。

课堂讲解建议

  • 易错点预警：学生最容易在说法④出错，误将“纵坐标之差的绝对值”当作两船距离。教师应强调：y轴表示的是“与B港的距离”，不是坐标轴上的位置坐标；只有两船在B港同侧时，距离才等于y值之差的绝对值，在异侧时应求和。
  • 方法提炼：讲完本题后，可引导学生总结“一次函数图像应用题”的通用解题框架：
  1. 明确横纵轴实际意义；
  2. 找特殊点（起点、终点、交点、转折点）；
  3. 将点坐标转化为实际路程、时间、速度；
  4. 结合文字条件列方程或算式求解。
  • 拓展思考：可追问学生，如果乙船也是驶向C港（与甲船同向），那么说法④是否成立？（此时两船在B港同侧，距离=|320−100|=220km，④将成立。）以此训练分类讨论思维。
