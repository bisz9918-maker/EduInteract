[图示主题与整合说明]
- 本图示主题：两船与B港距离随甲船行驶时间变化的函数图像分析及四个说法的验证
- 整合的步骤/概念：坐标系与图像物理意义建立 → 甲船前段信息提取（AB距离、甲速） → 乙船信息推导（乙速、行驶时间、甲总时间） → 甲船后段与BC距离 → 说法④辨析（距B距离之差 vs 实际距离）
- 教学价值：教师通过分步导航控制信息呈现节奏，每步聚焦一个认知环节（读图→计算→验证），可随时回退复习。图像动态高亮与辅助虚线帮助学生建立"数形结合"思维，步骤④的辨析动画直击易错点。

  - 「上一步」按钮：位于(280,465)，80×30px，点击回退到上一状态，步骤0时禁用

  3. 点击「下一步」进入步骤2，切换至乙船分析，利用速度比和同时到达条件推导乙速与总时间

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：本场景为静态折线图与简单动画（虚线绘制、标签淡入淡出、线宽变化），无需复杂数学计算或3D渲染，原生SVG性能最优且依赖最少。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------------+
  |  [推导文字区]                    图例: 甲船(蓝) 乙船(红) |
  |                                                        |
  |    y/km                                                |
  |  400 |  * A1(0,400)                                    |
  |      |    \                                            |
  |  200 |     \         * P(6,200)                        |
  |      |      \       /                                  |
  |    0 |  O----*-----*-----*-----> x/h                   |
  |         0    1     4     6   7                         |
  |              Q    B1                                   |
  |                                                        |
  |  [判断结果列表]        [◀上一步] [步骤X/4] [下一步▶]   |
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：定义state变量（0~4），每步对应一个渲染函数renderStep(state)，根据state显示/隐藏元素、设置样式。
  2. 坐标计算：x轴每单位70px（原点x=60），y轴每100单位60px（原点y=420）。映射函数：svgX(x)=60+x*70，svgY(y)=420-y*0.6。
  3. 动画曲线：虚线绘制使用stroke-dasharray和stroke-dashoffset动画（CSS transition 0.5s ease-out）；标签淡入使用opacity transition（0.3s）；线宽变化使用CSS transition（0.3s）。
  4. 事件绑定：上一步/下一步按钮绑定click事件，更新state并调用renderStep。
  5. 元素显隐：所有步骤专属元素（虚线、标签、判断结果）初始display:none或opacity:0，由renderStep控制切换。
  6. 高亮实现：步骤1/2/3的高亮通过给对应线段添加CSS class（如.highlight）实现线宽加粗；填充polygon使用SVG <polygon>元素，初始opacity:0，高亮时opacity:0.15。
  7. 步骤4特殊处理：x=5辨析线使用橙色，点M和N的标注使用橙色文字以突出辨析主题。
- ID命名规范：所有交互元素ID必须以`scene1-`为前缀。例如：`scene1-axis-x`、`scene1-line-jia`、`scene1-line-yi`、`scene1-point-a1`、`scene1-btn-prev`、`scene1-btn-next`、`scene1-text-step`、`scene1-label-0-400`、`scene1-dashed-y400`、`scene1-result-1`等。
- IIFE隔离：所有JavaScript代码包裹在`(function() { ... })()`中，避免全局变量污染。
