[图示主题与整合说明]
- 本图示主题：从抛物线图象提取系数符号（a<0, b<0）
- 整合的步骤/概念：
  1. 观察抛物线开口方向得出 a 的符号；
  2. 观察对称轴与 y 轴的左右位置关系，列出不等式；
  3. 结合 a<0 推导 b 的符号；
  4. 汇总结论。
- 教学价值：教师通过分步导航，可逐层引导学生从直观图象过渡到代数推导，控制课堂节奏，随时回退复习。

[视觉元素清单]
- 坐标系：x轴、y轴、原点O，黑色 #000000，线宽 1.5 px，带箭头。
- 抛物线：y = ax²+bx+1（示例 a=-1, b=-2），开口向下，顶点在第二象限，过 (0,1)。颜色 #1565c0，线宽 2.5 px。
- 交点 (0,1)：红色 #c62828 实心圆，直径 6 px（半径 3 px）。
- 开口方向箭头：绿色 #2e7d32，线宽 1.5 px，位于抛物线右侧，箭头向下，指示开口向下。
- 对称轴：灰色 #888888，虚线（stroke-dasharray: 5,5），线宽 1 px，方程 x = -b/(2a)。
- 推导结论文本：红色 #c62828，font-weight: bold，font-size: 16 px，位于右侧结论区。
- 按钮：背景 #e3f2fd，边框 #1565c0，文字 #1565c0，圆角 4 px。

[分步序列]
- 步骤0（初始状态）：显示坐标系（x轴、y轴、O、x、y、刻度1）、抛物线、交点 (0,1) 红色高亮及其标签。右侧结论区空白。
- 步骤1（开口方向）：抛物线线宽加粗至 4 px 或透明度变化高亮；开口箭头出现（(400,180)-(400,240)）；右侧结论区显示 "a < 0（开口向下）"（(600,150)）。
- 步骤2（对称轴）：对称轴虚线出现（(220,150)-(220,380)）；对称轴标签 "x = -b/(2a)" 出现（(220,135)）；右侧结论区显示 "-b/(2a) < 0"（(600,220)）。
- 步骤3（推导 b）：右侧结论区显示推导链 "-b/(2a) < 0  ⇒  -b > 0  ⇒  b < 0"（(600,290)）；对称轴与 y 轴同时高亮（如加深颜色或加粗）。
- 步骤4（汇总结论）：右侧结论区显示 "a < 0，b < 0"（(600,360)）；前序高亮元素恢复常态，最终结论文本可额外添加背景高亮框（如浅红底色 #ffebee）。

教师可随时点击「◀ 上一步」回退到任意步骤复习。

[交互方案]
- 交互类型：分步按钮导航（◀ 上一步 / 下一步 ▶）。
- 控件说明：
  - 「◀ 上一步」按钮：位于 (300,447)，100×36 px。点击后 currentStep 减 1，回退到上一步视觉状态。
  - 「下一步 ▶」按钮：位于 (420,447)，100×36 px。点击后 currentStep 加 1，进入下一步视觉状态。
  - 按钮在步骤0时「上一步」禁用（opacity 0.4, pointer-events none），在步骤4时「下一步」禁用。
- 教师操作流程：
  1. 教师展示步骤0，让学生观察图象；
  2. 点击「下一步」进入步骤1，引导学生观察开口方向；
  3. 继续点击「下一步」依次呈现对称轴、推导链、汇总结论；
  4. 讲解过程中可随时点击「上一步」回退强调关键特征。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript。理由：本场景为静态几何图形与分步显隐，无需复杂图表库；原生 SVG path 可精确控制抛物线采样点。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图：
  ```
  +--------------------------------------------------+
  |                                                  |
  |   y↑    抛物线（蓝色）                             |
  |    |      ∧                                       |
  |    |     / \    开口箭头（绿，步骤1）               |
  |  1-+----(0,1)                                    |
  |    |      |      对称轴（灰虚线，步骤2）            |
  |    O------+-------→x                             |
  |           |                                      |
  |    [坐标系区域]        [结论面板]                  |
  |                        a<0（步骤1）               |
  |                        -b/2a<0（步骤2）           |
  |                        推导链（步骤3）             |
  |                        a<0,b<0（步骤4）           |
  |                                                  |
  |        [◀ 上一步]  [下一步 ▶]                    |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机：用变量 `currentStep`（0~4）控制当前步骤。每步对应一个显隐配置数组，记录各元素（箭头、对称轴、结论文本等）的 `display` 或 `opacity` 状态。
  2. 抛物线绘制：使用 SVG `<path>`，将上述 15 个采样点用 `L` 命令连接，设置 `fill="none"`。
  3. 对称轴：`<line>` 元素，设置 `stroke-dasharray="5,5"`。
  4. 开口箭头：`<line>` 加 `<marker>` 箭头头部，或使用 `<path>` 画箭头。
  5. 高亮效果：步骤1抛物线高亮可通过切换 CSS class（如 `.highlight { stroke-width: 4px; filter: drop-shadow(...); }`）实现；步骤4结论文本高亮可添加 `<rect>` 背景框。
  6. 动画曲线：元素显隐使用 CSS transition `opacity 0.3s ease`，避免生硬切换。
  7. 事件绑定：按钮点击事件直接修改 `currentStep` 并调用 `renderStep()` 更新视图。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀。例如：
  - 抛物线：`scene1-parabola`
  - x轴：`scene1-axis-x`
  - 开口箭头：`scene1-arrow-open`
  - 对称轴：`scene1-axis-symmetry`
  - 结论1：`scene1-conclusion-1`
  - 结论2：`scene1-conclusion-2`
  - 结论3：`scene1-conclusion-3`
  - 结论4：`scene1-conclusion-4`
  - 上一步按钮：`scene1-btn-prev`
  - 下一步按钮：`scene1-btn-next`
- IIFE 隔离：所有 JavaScript 代码包裹在 `(function() { ... })();` 中，避免多场景合并时全局变量污染。
- 数学公式显示：文本标签直接使用 Unicode 字符（如 `a < 0`、`x = -b/2a`），无需引入 MathJax，保持轻量。
