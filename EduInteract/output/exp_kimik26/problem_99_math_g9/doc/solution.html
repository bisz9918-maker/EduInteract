题目原文

如图，D是等边△ABC边AB上的一点，且AD=1，BD=2，现将△ABC折叠，使点C与D重合，折痕EF，点E、F分别在AC和BC上，若BF=1.25，则CE=（ ）

A．7/5 B．2/3 C．5/6 D．1/2

题目分析

等边△ABC的边长为 AB = AD + BD = 1 + 2 = 3。折叠问题的核心几何性质是：折痕所在直线为对应点连线的垂直平分线。因此EF垂直平分CD，进而得到 EC = ED，FC = FD。这是将折叠条件转化为可计算等量关系的关键。

整体讲解思路

  1. 先让学生确认等边三角形的基本性质：三边相等（均为3），三角均为60°。
  2. 引导学生观察折叠操作的本质：C与D重合，折痕EF是线段CD的垂直平分线。
  3. 由垂直平分线性质得出 EC = ED，设 CE = x，则 AE = 3 − x，ED = x。
  4. 在△ADE中，已知两边及其夹角（AD = 1，∠A = 60°，AE = 3 − x，ED = x），应用余弦定理列方程求解。
  5. （可选验证）利用求得的CF = 7/4，在△BDF中用余弦定理验证FD = CF是否成立，增强结论可信度。

图示规划说明

设计两个图示：第一个图示聚焦“折叠几何关系”，从原始图形出发，分步揭示折痕与垂直平分线的关系，建立 EC = ED、FC = FD 的直观认知；第二个图示聚焦“代数求解”，将△ADE（或△BDF）抽离出来，分步展示余弦定理的列式与求解过程。两个图示视觉主题不同，前者为整体折叠构图，后者为局部三角形计算。

步骤 1 / 5

本图示的教学说明

本图示（SCENE_2）将△ADE从原图中抽离，专门展示如何利用余弦定理建立方程求解CE。教师应引导学生：

  1. 回顾在SCENE_1中得到的结论：EC = ED。设 CE = x，则 ED = x，AE = AC − CE = 3 − x。
  2. 观察△ADE的三要素：AD = 1（已知），∠A = 60°（等边三角形内角），AE = 3 − x，ED = x（待求）。
  3. 这是一个典型的“两边及夹角”结构，适合用余弦定理建立关于x的方程。

推导步骤

  1. 在△ADE中，由余弦定理：

ED² = AD² + AE² − 2·AD·AE·cos∠A

  1. 代入已知量：

x² = 1² + (3 − x)² − 2·1·(3 − x)·cos60°

  1. 由于 cos60° = 1/2，化简得：

x² = 1 + (9 − 6x + x²) − (3 − x)

  1. 继续整理：

x² = 1 + 9 − 6x + x² − 3 + x
x² = 7 − 5x + x²

  1. 消去x²，解得：

5x = 7
x = 7/5

因此 CE = 7/5，对应选项A。

验证思路（课堂拓展）

教师可进一步引导学生验证FC = FD是否成立：

  • 由BC = 3，BF = 5/4，得 CF = 3 − 5/4 = 7/4。
  • 在△BDF中，BD = 2，BF = 5/4，∠B = 60°。
  • 由余弦定理：FD² = 2² + (5/4)² − 2·2·(5/4)·(1/2) = 4 + 25/16 − 5/4 = 49/16。
  • 故 FD = 7/4 = CF，验证成立。
步骤 1/5

总结与课堂讲解建议

本题是一道典型的“折叠+余弦定理”综合题，核心解题链路为：

  1. 折叠性质转化：折叠问题的第一突破口永远是“折痕是对应点连线的垂直平分线”。由此得到 EC = ED 和 FC = FD，将分散的线段关系集中到一个三角形中。
  2. 设元列方程：设 CE = x，利用等边三角形边长为3，将△ADE的三边都用已知数或x表示。
  3. 余弦定理求解：在含60°角的三角形中，cos60° = 1/2 使计算大大简化，这是等边三角形背景题的常见优势。
  4. 验证意识：求出x后，建议教师带领学生用△BDF验证FC = FD，培养“双向验证”的解题习惯。

常见学生误区提醒

  • 误认为折叠后∠CED = 60°或产生其他不存在的角度关系。
  • 忘记垂直平分线性质，试图用相似三角形硬解，导致思路受阻。
  • 计算(3−x)²展开时符号出错，或在消去x²后遗漏常数项。

  • 若课堂时间充裕，可在SCENE_2中展示△BDF的验证，强化折叠性质的对称美感。
