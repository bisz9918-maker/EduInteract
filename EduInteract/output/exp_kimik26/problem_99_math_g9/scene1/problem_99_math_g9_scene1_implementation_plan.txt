[图示主题与整合说明]
- 本图示主题：等边三角形折叠问题的几何本质与垂直平分线性质
- 整合的步骤/概念：
  1. 原始等边三角形及已知条件（AD=1, BD=2, BF=5/4）的空间呈现；
  2. 折痕EF与对应点连线CD的位置关系（垂直平分线）的直观发现；
  3. 折叠操作的轴对称效果（C与D重合）的动态示意；
  4. 垂直平分线性质的推导（EC=ED, FC=FD）与等长标记；
  5. 待求量CE的标注，为代数求解做铺垫。
- 教学价值：教师可按照"原始图形→折叠操作→性质发现→目标聚焦"的认知递进节奏讲解，分步按钮支持随时回退到关键步骤（如步骤2的轴对称示意、步骤3的等量关系）进行反复强调，避免信息过载。

[分步序列]
- 步骤0（初始状态）：显示等边△ABC、点D/E/F、折痕EF（蓝色实线）、所有点标签（A-F）、已知长度标注AD=1（AB下方偏左）、BD=2（AB下方偏右）、BF=5/4（BC右外侧）。不显示辅助线CD、折叠示意、等量关系。教师可在此步引导学生读题并标注已知。
- 步骤1（折痕与对应点连线）：在步骤0基础上，新增辅助线CD（灰色虚线），并将折痕EF加粗至3px或提高不透明度以高亮。教师引导学生观察：折痕EF与线段CD有何位置关系？（为后续发现垂直平分线做铺垫。）
- 步骤2（折叠轴对称效果）：在步骤1基础上，新增淡蓝色半透明虚线△DEF（表示△CEF沿EF翻折后C到达D位置），同时C点保持但可降低不透明度至40%以暗示"原位置"。新增从C到D的灰色虚线弧形箭头（贝塞尔曲线，控制点(480,256)），箭头旁标注"重合"。教师强调：折叠的本质是轴对称，C与D关于EF对称。
- 步骤3（垂直平分线性质）：在步骤2基础上，新增绿色文字标注"EC=ED"（左侧，(295,305)）和"FC=FD"（右侧，(445,315)）。同时在EC、ED、FC、FD四段线段中点处绘制绿色等长标记（垂直于各线段的8px短斜线，成对出现）。教师讲解：折痕上的点到对应点距离相等，因此EF是CD的垂直平分线。
- 步骤4（聚焦待求量）：在步骤3基础上，新增红色标注"CE=x"（或"CE=?"）在AC左上侧(355,192)，并将CE线段高亮为红色（2px）。教师可过渡至代数求解：设CE=x，则ED=x，在△AED中用余弦定理建立方程。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：
  1. 「上一步」按钮：位于底部(280,452)，宽90px，高32px，圆角4px。点击后回退到上一教学步骤，隐藏当前步骤新增元素。
  2. 「下一步」按钮：位于底部(430,452)，宽90px，高32px，圆角4px。点击后进入下一教学步骤，显示对应元素。
  3. 步骤指示器：位于底部(400,488)，显示当前步骤编号（如"步骤 1 / 5"对应步骤0，或直接用"步骤 1/5"~"步骤 5/5"）。
- 教师操作流程：
  1. 教师打开图示，默认显示步骤0（基础图形），向学生介绍已知条件；
  2. 点击「下一步」进入步骤1，引导学生观察折痕EF与CD的关系；
  3. 点击「下一步」进入步骤2，展示折叠后的轴对称效果，强调C与D重合；
  4. 点击「下一步」进入步骤3，揭示垂直平分线性质与等量关系；
  5. 点击「下一步」进入步骤4，聚焦待求量CE，过渡到代数计算；
  6. 讲解过程中可随时点击「上一步」回退，重复强调关键性质。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本场景为纯2D几何图形，元素为线段、多边形、圆、文本，无需复杂数据绑定或3D渲染，原生SVG性能最优且可控性最高。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |                                                  |
  |              C(400,135)                          |
  |             /\                                   |
  |            /  \                                  |
  |    E(325,245)  F(485,275)                        |
  |          /      \                                |
  |         /   DEF  \                               |
  |   A(280,360)---D---B(520,360)                    |
  |    [AD=1]   [BD=2]                               |
  |                                                  |
  |         [ 上一步 ]  [ 下一步 ]                    |
  |              步骤 1 / 5                          |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `let currentStep = 0;` 记录当前步骤（0~4）。每次点击按钮时更新该变量，调用 `renderStep()` 函数根据步骤值控制各元素的 `display` 属性（或 `opacity` + `pointer-events`）。
  2. 元素分组：将每一步新增的元素分别包裹在 `<g id="scene1-stepX-...">` 中，例如：
     - `scene1-step0-base`：基础图形（始终显示）
     - `scene1-step1-cd`：CD辅助线
     - `scene1-step2-fold`：折叠示意△DEF + 箭头 + "重合"标签
     - `scene1-step3-equals`：等长标记 + EC=ED + FC=FD
     - `scene1-step4-target`：CE=x 标注 + CE红线高亮
  3. 坐标计算：等边三角形顶点按边长240px、每单位80px换算；E、F坐标由几何关系精确计算（E对应单位坐标(0.8, 4√3/5)，F对应(2.375, 5√3/8)）。
  4. 动画曲线：本场景无需复杂动画，步骤切换采用直接显示/隐藏（display: block/none）。如需柔和过渡，可在CSS中为相关元素添加 `transition: opacity 0.3s ease;`。
  5. 事件绑定：为「上一步」「下一步」按钮绑定 `click` 事件，在事件处理函数中检查边界（currentStep 不越界0~4），更新按钮可用状态（步骤0时禁用「上一步」，步骤4时禁用「下一步」）。
  6. 等长标记绘制：在SVG中通过计算线段中点和垂直方向向量，使用 `<line>` 绘制8px短斜线。例如EC中点(372,200.5)，EC方向向量(-56,97)，归一化垂直向量取(0.866,0.5)，即可画出垂直于EC的标记。
- ID命名规范：所有SVG元素及控件的ID必须以 `scene1-` 为前缀。例如：`scene1-tri-abc`、`scene1-point-d`、`scene1-crease-ef`、`scene1-btn-prev`、`scene1-btn-next`、`scene1-step1-cd` 等。JavaScript中严格使用 `document.getElementById` 获取元素，禁止全局class选择，避免多场景合并时跨场景污染。
- IIFE隔离：所有JavaScript代码包裹在立即执行函数表达式中：
  ```javascript
  (function() {
    // 本场景全部逻辑
  })();
  ```
- 响应式与容器：SVG设置 `width="800" height="500" viewBox="0 0 800 500"`，确保在不同容器尺寸下保持比例缩放。控件按钮使用HTML绝对定位覆盖在SVG容器底部（`position: absolute; bottom: 10px;`），不撑高容器。
