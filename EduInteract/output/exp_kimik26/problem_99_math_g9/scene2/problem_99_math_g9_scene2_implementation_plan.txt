[图示主题与整合说明]
- 本图示主题：在△ADE中应用余弦定理求解CE
- 整合的步骤/概念：将折叠问题中的关键三角形ADE抽离放大，通过分步展示"公式引入→数值代入→方程化简→得出结论→对侧验证"的完整代数推导链，帮助学生建立几何与代数的视觉关联。
- 教学价值：教师可控制每一步的呈现节奏，让学生先观察图形中的已知与未知关系，再逐步见证余弦定理如何消去二次项、解出一次方程，最后通过对称验证强化折叠性质的理解。

[分步序列]
- 步骤0（初始状态）：
  显示△ADE三边及顶点标签A、D、E。
  标注：AD=1（红色，(225,370)）、AE=3−x（蓝色，(194,237)）、ED=x（红色，(303,243)）。
  显示∠A=60°角弧及标注（(185,330)）。
  右侧公式区空白，仅留淡灰色提示文字"点击下一步开始推导"。
  步骤指示器显示"步骤 1/5"。

- 步骤1（余弦定理公式）：
  点击「下一步」→ 右侧公式区显示余弦定理：
  "ED² = AD² + AE² − 2·AD·AE·cos∠A"
  颜色对应：ED²红色、AD²红色、AE²蓝色、其余黑色。
  同时图中AD边与ED边短暂高亮（stroke-width增至3，持续300ms后恢复），建立公式与图形的视觉关联。
  步骤指示器"步骤 2/5"。

- 步骤2（代入数值）：
  点击「下一步」→ 公式区新增代入行：
  "x² = 1² + (3−x)² − 2·1·(3−x)·½"
  高亮cos60°=1/2的替换过程：公式中的"cos∠A"以淡灰色显示，"½"以黑色加粗显示，并出现短暂淡入动画（opacity 0→1，300ms）。
  图中∠A=60°标注短暂放大至120%后恢复。
  步骤指示器"步骤 3/5"。

- 步骤3（化简方程）：
  点击「下一步」→ 公式区依次显示三行化简（每行间隔150ms淡入）：
  第1行："x² = 1 + 9 − 6x + x² − 3 + x"
  第2行："0 = 7 − 5x"
  第3行（绿色高亮）："5x = 7"
  第3行使用fill=#2e7d32，font-weight=bold。
  步骤指示器"步骤 4/5"。

- 步骤4（得出结论）：
  点击「下一步」→ 公式区显示：
  "x = 7/5"（绿色）
  "∴ CE = 7/5，对应选项 A"（绿色）
  图中ED边标注由"x"动态变为"7/5"，颜色由红变绿，字体轻微放大（scale 1→1.2→1，400ms弹性动画）。
  步骤指示器"步骤 5/5"。

- 步骤5（△BDF验证，可选）：
  点击「下一步」→ 在右下角(450~620, 255~375)区域绘制△BDF。
  标注：BD=2、BF=5/4、FD=7/4（绿色）、∠B=60°。
  右侧公式区追加小字验证："验证：FD² = 2² + (5/4)² − 2·2·(5/4)·½ = 49/16 ∴ FD = 7/4 = CF"（绿色）。
  步骤指示器保持"步骤 5/5"，下一步按钮置灰禁用。

（教师可随时点击「上一步」回退，所有元素按逆序隐藏/恢复。）

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「上一步」按钮：位置(290,452)，大小90×32。作用：回退到上一推导步骤，隐藏当前步骤新增的元素，恢复前一步状态。
  2. 「下一步」按钮：位置(430,452)，大小90×32。作用：推进到下一推导步骤，显示该步骤的公式/图形/高亮。在步骤5时禁用（opacity=0.4, pointer-events=none）。
  3. 步骤指示器：位置(400,485)，文本如"步骤 2/5"。作用：实时反馈当前所处步骤，帮助教师掌握课堂节奏。
- 教师操作流程：
  1. 教师展示步骤0，让学生观察△ADE中的已知条件（AD=1, ∠A=60°, AE=3−x, ED=x）。
  2. 点击「下一步」进入步骤1，引出余弦定理公式，强调三边一角的关系。
  3. 点击「下一步」进入步骤2，将图形中的具体数值代入公式，强调cos60°=1/2。
  4. 点击「下一步」进入步骤3，逐步展示代数化简，观察二次项如何消去。
  5. 点击「下一步」进入步骤4，得出CE=7/5，对应选项A，观察ED标注由红变绿。
  6. （可选）点击「下一步」进入步骤5，展示△BDF验证，强化折叠性质（EC=ED, FC=FD）。
  7. 讲解中可随时点击「上一步」让学生回顾关键步骤。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：本场景以静态几何图形和文本分步显示为主，无需复杂数据绑定或3D渲染，原生SVG足以保证轻量和精确控制，且便于教师直接嵌入课件系统。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |                                                  |
  |   △ADE（主图区）          公式/推导区（右侧）      |
  |   A______D                    步骤1: 余弦定理公式  |
  |    \    /                     步骤2: 代入数值      |
  |     \  /                      步骤3: 化简过程      |
  |      E                        步骤4: 结论          |
  |                                                  |
  |                    △BDF（步骤5，右下角）           |
  |                                                  |
  |  [◀ 上一步]    步骤 1/5    [下一步 ▶]            |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `currentStep`（0~5），每次点击按钮时更新状态，调用 `renderStep()` 函数。`renderStep()` 内部使用 `switch(currentStep)` 控制各元素的 `display` 或 `opacity` 属性。
  2. 坐标计算：△ADE顶点坐标基于实际边长比例计算（AD=1→150px, AE=1.6→240px, ED=1.4→210px），确保图形几何准确。AE与ED的边标注使用法向量偏移公式计算外侧位置，避免压线。
  3. 动画曲线：文本淡入使用 `transition: opacity 300ms ease-in-out`；ED标注变色使用CSS transition（color 400ms, transform 400ms cubic-bezier(0.34, 1.56, 0.64, 1)）实现轻微弹性放大效果；边线高亮使用JS定时器控制stroke-width变化。
  4. 事件绑定：按钮绑定 `click` 事件，在IIFE内部处理。上一步按钮在步骤0时禁用，下一步按钮在步骤5时禁用。
  5. 公式颜色对应：使用SVG `<tspan>` 的 `fill` 属性分别设置红色（#c62828）、蓝色（#1565c0）、绿色（#2e7d32），确保公式项与图形标注严格对应。
  6. 动态文本更新：步骤4时，通过JS修改ED标注的 `textContent`（"x"→"7/5"）和 `setAttribute('fill', '#2e7d32')`。
  7. 验证图显示：步骤5时，将△BDF组元素的 `display` 由 `none` 改为 `block`，并配合300ms淡入。
- ID命名规范：所有交互元素ID必须以 `scene2-` 为前缀。例如：
  - 三角形ADE：`scene2-tri-ade`
  - 顶点A标签：`scene2-label-a`
  - 边AD标注：`scene2-label-ad`
  - 公式步骤1：`scene2-formula-step1`
  - 上一步按钮：`scene2-btn-prev`
  - 下一步按钮：`scene2-btn-next`
  - 步骤指示器：`scene2-step-indicator`
  - △BDF组：`scene2-tri-bdf-group`
  JS中严格使用 `document.getElementById` 获取元素，禁止跨场景选择器。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })()` 中，避免全局变量污染，确保多场景合并时互不干扰。
