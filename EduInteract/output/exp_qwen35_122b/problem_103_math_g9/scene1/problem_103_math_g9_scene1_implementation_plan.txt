[图示主题与整合说明]
- 本图示主题：正方形与菱形的组合图形及阴影区域面积计算
- 整合内容：正方形 ABCD、菱形 PQCB、阴影区域（五边形 ABPED）、关键标注（边长、高、面积）

[分步序列]
步骤 0（初始状态）：
- 显示：正方形 ABCD 边框、菱形 PQCB 边框、所有顶点标签（A/B/C/D/P/Q/E）
- 不显示：阴影填充、辅助垂线、面积标注、边长标注、高标注
- 目的：展示基础图形结构

步骤 1（标注正方形边长）：
- 新增：BC=5 标注（底部中央）、面积=25 标注（正方形上方）
- 视觉变化：BC 边高亮（红色闪烁 1 次）
- 目的：明确正方形边长，推导边长=5

步骤 2（标注菱形高）：
- 新增：辅助垂线 PF（灰色虚线）、垂足 F 及标签、直角符号、高=4 标注（红色，垂线右侧）
- 视觉变化：垂线 PF 高亮（红色闪烁 1 次）
- 目的：展示菱形高，由面积 20÷底 5=高 4

步骤 3（计算空白梯形面积）：
- 新增：梯形 PBCE 边框高亮（橙色虚线）、空白梯形面积=12 标注（梯形内部）
- 视觉变化：梯形 PBCE 区域半透明橙色填充
- 目的：计算空白部分面积 = (PB+EC)×高÷2 = (5+2)×4÷2 = 14... 修正：EC = 250-130 = 120px = 4 单位，梯形面积 = (3+4)×4÷2 = 14
- 更正：PB 在水平方向投影 = 3 单位，EC = 5-3 = 2 单位，梯形面积 = (3+2)×4÷2 = 10
- 再修正：梯形 PBCE 的上底 PE = 300-240 = 60px = 2 单位，下底 BC = 5 单位，高 = 4 单位
- 梯形面积 = (2+5)×4÷2 = 14

步骤 4（显示阴影面积结论）：
- 新增：阴影区域填充蓝色 30% 透明度、阴影面积=11 标注（阴影区域内部中央）
- 视觉变化：阴影区域高亮（蓝色脉冲动画）
- 目的：得出结论 阴影面积 = 正方形面积 - 梯形面积 = 25 - 14 = 11

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 按钮「◀ 上一步」：位置 (280,460)，作用：返回上一步骤，禁用状态在步骤 0
  - 按钮「下一步 ▶」：位置 (500,460)，作用：进入下一步骤，禁用状态在步骤 4
  - 步骤指示器：位置 (370,460)，显示「步骤 1/5」格式
- 教师操作流程：
  1. 初始展示图形结构，让学生观察正方形与菱形的关系
  2. 点击「下一步」揭示正方形边长条件，引导学生计算边长=5
  3. 点击「下一步」揭示菱形高，引导学生由面积÷底=高
  4. 点击「下一步」计算空白梯形面积，演示面积分解方法
  5. 点击「下一步」显示阴影面积结论，验证 25-14=11

- 关键实现要点：
  1. 状态机设计：currentStep 变量 (0-4)，updateScene() 函数根据 currentStep 显示/隐藏元素
  2. 坐标计算：所有元素使用固定像素坐标，按布局坐标表精确实现
  3. 动画曲线：高亮效果使用 CSS transition + keyframe 动画（闪烁/脉冲）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateScene()
  5. 元素分组：使用 SVG <g> 元素按步骤分组，便于批量显示/隐藏

- ID 命名规范：
  - 所有交互元素 ID 以 scene1- 为前缀
  - 示例：scene1-square、scene1-rhombus、scene1-shadow、scene1-btn-prev、scene1-btn-next、scene1-step-indicator
  - 标签 ID：scene1-label-A、scene1-label-B、...、scene1-label-BC、scene1-label-height、scene1-label-area-square、scene1-label-area-rhombus
  - 步骤相关元素：scene1-step0-*、scene1-step1-*、...、scene1-step4-*
