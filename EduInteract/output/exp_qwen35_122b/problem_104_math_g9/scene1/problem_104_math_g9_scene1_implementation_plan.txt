[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 按钮"◀上一步"：位于 SVG 底部左侧 (100,455)，返回上一状态
  - 按钮"下一步▶"：位于 SVG 底部右侧 (650,455)，进入下一状态
  - 步骤指示器：位于底部中央 (350,455)，显示"步骤 k/4"
- 教师操作流程：
  1. 从步骤 0 开始，先介绍坐标系
  2. 点击"下一步"展示正方形序列整体布局
  3. 点击"下一步"标注 x 轴上的关键点
  4. 点击"下一步"高亮平行边，强调平行关系
  5. 点击"下一步"显示已知条件，引导学生观察边长变化规律
  6. 可随时点击"上一步"回退复习

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（几何图形简单，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────┐
  │  y                                                  │
  │  ↑                                                  │
  │  │     A₁                                          │
  │  │    ╱╲      A₂        A₃                         │
  │  │   ╱  ╲    ╱╲        ╱╲                          │
  │  B₁╱____╲D₁ ╱  ╲D₂    ╱  ╲D₃                       │
  │  │      ╲  ╱____╲    ╱____╲                        │
  │  │       ╲╱  □  ╲  ╱  □   ╲                        │
  │  └─────────C₁E₁E₂C₂E₃E₄C₃──────────────────────→ x  │
  │  O                                                  │
  │                                                     │
  │        [◀上一步]    步骤 k/4    [下一步▶]           │
  └─────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-4) 控制显示内容
  2. 元素分组：每个步骤的元素用<g id="scene1-stepN">分组，通过 display 控制显示/隐藏
  3. 坐标计算：所有顶点坐标预先计算好，硬编码在 SVG 中
  4. 角度弧绘制：用 SVG path 绘制 30°圆弧，圆心在 B₁(60,316)，半径 25px
  5. 按钮事件：绑定 click 事件，更新 currentStep 并刷新显示
  6. ID 命名规范：所有元素 ID 以"scene1-"为前缀（如 scene1-square1、scene1-btn-prev）
  7. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中
- 角度弧路径（步骤 4 显示）：
  - 圆心 B₁(60,316)，半径 25px
  - 从 y 轴向下方向（270°）到 B₁C₁方向（300°）
  - path: "M 85,316 A 25,25 0 0,1 78.5,337.5"
