[分步序列]
- 步骤 0（初始状态）：显示坐标系、三个正方形轮廓（无填充）、所有顶点标签、坐标轴标签
- 步骤 1：高亮直角三角形 OB₁C₁（红色填充 15%），标注∠C₁B₁O=30°（红色角度弧线 + 文字）
- 步骤 2：标注 B₁C₁=1，显示辅助线 D₁E₁（灰色虚线），标注 D₁E₁=1/2
- 步骤 3：在右侧公式区显示步骤 1 结论：OC₁ = B₁C₁·cos30° = √3/2
- 步骤 4：高亮第二个正方形 A₂B₂C₂D₂，标注 B₂C₂∥B₁C₁（红色平行标记），显示 B₂C₂ 边长标注
- 步骤 5：在公式区显示递推推导：通过△OB₁C₁∽△D₁E₁B₂，得 a₂/a₁ = D₁E₁/B₁C₁ = (1/2)/1 = 1/2... 修正：a₂/a₁ = √3/3
- 步骤 6：显示第三个正方形，标注 B₃C₃∥B₂C₂，验证递推规律一致性
- 步骤 7（最终）：公式区完整显示通项公式 aₙ = (√3/3)ⁿ⁻¹，关键结论用绿色粗体高亮

  - "◀ 上一步"按钮：位置 (580,450)，作用：返回上一步骤
  - "下一步 ▶"按钮：位置 (680,450)，作用：进入下一步骤

- 教师操作流程：

  3. 在公式区逐步展示推导过程
  4. 最终展示通项公式，引导学生验证答案

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（几何图形简单，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │                        图示区 800×500                        │
  │                                                             │
  │   y                                                         │
  │   ↑                    A₁                                   │
  │   │                  /   \                                 │
  │   │                /       \                               │
  │  B₁--------------A₁         D₁-----B₂----A₂               │
  │   │              |           |      |      |               │
  │   │              |  正方形 1 |      |  正方形 2              │
  │   │              |           |      |      |               │
  │   C₁------------D₁----------E₁-----C₂-----D₂              │
  │   │              |                    |                    │
  │   └──────────────┴────────────────────┴──────────→ x       │
  │   O               正方形 1              正方形 2             │
  │                                                             │
  │                              公式推导区                      │
  │                              a₁ = 1                         │
  │                              a₂/a₁ = √3/3                   │
  │                              aₙ = (√3/3)ⁿ⁻¹                 │
  │                                                             │
  │                    [◀ 上一步]  步骤 k/7  [下一步 ▶]          │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用 currentStep 变量跟踪当前步骤 (0-7)，每一步控制元素的 display/opacity 属性
  2. 坐标计算：所有顶点坐标预先计算好，用 SVG polygon 元素绘制
  3. 动画曲线：步骤切换用 opacity 渐变 (0.3s ease-in-out) 实现平滑过渡
  4. 事件绑定：按钮点击事件监听，更新 currentStep 并调用 updateScene() 函数
  5. ID 命名规范：所有元素 ID 以"scene2-"为前缀（如 scene2-square1、scene2-triangle-obc）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 公式渲染：使用 MathJax 渲染数学公式（√3/3 等），确保显示美观
