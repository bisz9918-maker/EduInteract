[视觉元素清单]
- 三角形ABC：由线段AB、AC、BC组成，等腰直角三角形，A为直角顶点
  - 标签：A(400,60)、B(180,370)、C(670,370)
  - 直角符号：∠BAC处(385,95)，标注"90°"(365,100)
  - 等长标记：AB、AC边中点处双短线
  - 颜色：主线#000000，内部填充#e3f2fd透明度15%

- 三角形ADF：由线段AD、AF、DF组成，等腰直角三角形，A为直角顶点
  - 标签：D(480,370)、F(175,180)
  - 直角符号：∠DAF处(385,130)，标注"90°"(365,135)
  - 等长标记：AD、AF边中点处单短线
  - 颜色：主线#000000，内部填充#e8f5e9透明度15%

- 辅助线段：
  - AE：(400,80)-(300,350)，主线#000000
  - EF：(300,350)-(200,180)，主线#000000
  - BF：(200,350)-(200,180)，主线#000000（垂直）

- 角度标注：
  - ∠DAE=45°：圆弧从AE到AD，圆心A，半径40，标注文字"45°"(445,150)
  - 颜色：#c62828红色高亮

- 点标签：A、B、C、D、E、F，字体16px，黑色#000000

[分步序列]
步骤0（初始状态）：
- 显示：完整图形轮廓（所有线段、顶点）
- 不显示：所有角度标注、等长标记、数值标签
- 目的：让学生先观察整体图形结构

步骤1（点击"下一步"）：
- 新增显示：∠BAC=90°直角符号及标注、AB=AC等长标记
- 高亮：AB、AC边用#2e7d32绿色高亮
- 目的：确认△ABC为等腰直角三角形

步骤2（点击"下一步"）：
- 新增显示：∠DAF=90°直角符号及标注、AD=AF等长标记
- 高亮：AD、AF边用#2e7d32绿色高亮
- 目的：确认△ADF为等腰直角三角形

步骤3（点击"下一步"）：
- 新增显示：∠DAE=45°圆弧标注及文字
- 高亮：∠DAE区域用#c62828红色高亮（圆弧和角内区域）
- 目的：强调关键角度条件

步骤4（点击"下一步"）：
- 新增显示：四个结论关键词高亮框
  - ①"△AED≌△AEF"：在图形下方显示文本框，关键词"≌"用#1565c0蓝色高亮
  - ②"△ABE∽△ACD"：显示文本框，关键词"∽"用#1565c0蓝色高亮
  - ③"BE+DC＞DE"：显示文本框，关键词"＞"用#1565c0蓝色高亮
  - ④"BE²+DC²=DE²"：显示文本框，关键词"²"、"="用#1565c0蓝色高亮
- 目的：引导学生关注待判断的结论

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：位置(280,460)，作用：返回上一步骤
  - "下一步 ▶"按钮：位置(500,460)，作用：进入下一步骤
  - 步骤指示器：位置(370,460)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始展示空白图形，让学生观察整体结构
  2. 点击"下一步"逐步添加已知条件标注
  3. 每添加一个条件，配合讲解该条件的几何意义
  4. 最后展示四个结论，引导学生逐一判断
  5. 可随时点击"上一步"回退复习

- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-4) 跟踪当前步骤
  2. 元素分组：每个步骤新增的元素用 group ID 标识，如 scene1-step1-elements、scene1-step2-elements 等
  3. 高亮切换：通过 CSS class 切换元素样式（.highlight-blue、.highlight-red、.highlight-green）
  4. 坐标计算：所有坐标预先计算好，直接硬编码在 SVG 中
  5. 事件绑定：按钮点击事件绑定到 scene1-prev-btn 和 scene1-next-btn
  6. 步骤指示器：动态更新文本内容

- ID 命名规范：
  - 所有交互元素 ID 以 scene1- 为前缀
  - 线段：scene1-seg-xxx（如 scene1-seg-ab、scene1-seg-ac）
  - 顶点：scene1-vertex-xxx（如 scene1-vertex-a、scene1-vertex-b）
  - 标签：scene1-label-xxx（如 scene1-label-a、scene1-label-b）
  - 角度标注：scene1-angle-xxx（如 scene1-angle-bac、scene1-angle-dae）
  - 等长标记：scene1-mark-xxx（如 scene1-mark-ab-ac、scene1-mark-ad-af）
  - 按钮：scene1-prev-btn、scene1-next-btn
  - 步骤指示器：scene1-step-indicator
  - 元素分组：scene1-step0-group、scene1-step1-group 等

- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染
