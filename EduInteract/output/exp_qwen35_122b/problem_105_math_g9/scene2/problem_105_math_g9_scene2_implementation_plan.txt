[分步序列]
- 步骤 0（初始状态）：
  - 显示：BC 底边、AB、AC、AF、AD、AE、EF、ED 所有边线
  - 显示：A、B、C、D、E、F 所有顶点及标签
  - 显示：△AED 淡蓝填充、△AEF 淡绿填充
  - 隐藏：所有高亮标记、角标、旋转轨迹、结论文本
  - 目的：展示题目基础图形，等待教师开始讲解

- 步骤 1（高亮等长边）：
  - 新增：AF 边和 AD 边高亮为绿色#2e7d32（线宽 4px）
  - 新增：AD=AF 文本标记（绿色，位置 (440,240)）
  - 目的：强调 SAS 的第一组条件——两边相等

- 步骤 2（高亮公共边）：
  - 新增：AE 边高亮为蓝色#1565c0（线宽 4px）
  - 新增：AE(公共) 文本标记（蓝色，位置 (340,260)）
  - 目的：强调 SAS 的第二组条件——公共边 AE

- 步骤 3（高亮夹角）：
  - 新增：∠DAE 角标（红色圆弧，半径 50）
  - 新增：∠FAE 角标（红色圆弧，半径 70）
  - 新增：两个 45°数值标记（红色，分别位于 (360,140) 和 (290,160)）
  - 目的：强调 SAS 的第三组条件——夹角相等（均为 45°）

- 步骤 4（旋转动画）：
  - 新增：灰色虚线旋转轨迹弧（从 D 到 F 的 90°圆弧）
  - 新增：D→F 虚线轨迹线
  - 新增：顺时针旋转方向箭头
  - 动画：△AED 绕 A 点顺时针旋转 90°，D 点沿轨迹移动到 F 点位置
  - 动画过程中：△AED 填充色逐渐与△AEF 重叠，重叠区域颜色加深
  - 目的：直观验证两三角形通过旋转完全重合

- 步骤 5（显示结论）：
  - 新增："△AED≌△AEF (SAS)"结论文本（黑色加粗，位置 (650,120)）
  - 保持：所有之前的高亮标记和角标
  - 目的：总结 SAS 全等判定结论

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮（scene2-prev-btn）：位于 (280,460)，100×30px，点击返回上一步骤
  - 下一步按钮（scene2-next-btn）：位于 (500,460)，100×30px，点击进入下一步骤

  4. 点击"下一步"触发旋转动画，直观验证重合
  5. 最后显示 SAS 结论，完成证明

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何动画无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    图示区 800×500                       │
  │                                                         │
  │                    A(400,100)                           │
  │                   /  \                                  │
  │                  /    \                                 │
  │             F   /      \   D                            │
  │            ●───●        ●───●                           │
  │           /    \        /    \                          │
  │          /      \      /      \                         │
  │         ●────────●────●────────●                        │
  │        B(150)   E(280) D(480)  C(650)                   │
  │              △AEF    △AED                               │
  │                                                         │
  │            [高亮标记/角标/轨迹按需显示]                 │
  │                                                         │
  │  ┌─────────────────────────────────────────────────┐   │
  │  │          控件栏 y=440~490                       │   │
  │  │    [◀上一步]              [下一步▶]             │   │
  │  └─────────────────────────────────────────────────┘   │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：currentStep 变量 (0-5)，updateScene() 函数根据 currentStep 显示/隐藏对应元素
  2. 坐标计算：所有元素使用绝对坐标，通过 SVG transform 实现旋转动画
  3. 动画曲线：旋转动画使用 requestAnimationFrame，从 0°到 90°线性插值，时长 1.5 秒
  4. 事件绑定：按钮点击事件调用 prevStep()/nextStep()，更新 currentStep 后调用 updateScene()
  5. 元素显示控制：通过 setAttribute('display', 'none/block') 控制元素可见性
  6. 旋转动画：对△AED 的 group 元素应用 transform="rotate(angle, 400, 100)"
- ID 命名规范：所有交互元素 ID 以 scene2- 为前缀（如 scene2-tri-aed、scene2-btn-next、scene2-arc-rotation）
- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染
