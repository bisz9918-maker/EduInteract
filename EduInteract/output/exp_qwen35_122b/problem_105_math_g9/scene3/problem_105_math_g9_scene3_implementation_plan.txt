- 画布尺寸：800 × 500 px

  └─────────────────────────────────────────────────────────┘

- 关键实现要点：
  1. 状态机设计：使用变量 currentStep（0-5）记录当前步骤，updateScene() 函数根据 currentStep 控制元素显示/隐藏
  2. 坐标计算：所有元素坐标硬编码在 SVG 中，确保精确到像素级
  3. 动画曲线：使用 CSS transition 实现淡入动画（opacity 0→1，duration 500ms）
  4. 事件绑定：上一步/下一步按钮绑定 click 事件，更新 currentStep 并调用 updateScene()
  5. 边界检查：上一步按钮在 step=0 时禁用，下一步按钮在 step=5 时禁用

- ID 命名规范：所有交互元素 ID 以 scene3- 为前缀
  - 图形元素：scene3-tri-abc、scene3-tri-adf、scene3-seg-be、scene3-seg-dc、scene3-seg-de、scene3-seg-ef、scene3-seg-bf、scene3-rt-ebf
  - 标签元素：scene3-label-a、scene3-label-b、scene3-label-c、scene3-label-d、scene3-label-e、scene3-label-f、scene3-label-be、scene3-label-dc、scene3-label-de、scene3-label-ef、scene3-label-bf
  - 直角符号：scene3-rightangle-bac、scene3-rightangle-daf、scene3-rightangle-ebf
  - 角度弧：scene3-angle-dae
  - 公式元素：scene3-formula-box、scene3-formula-line1、scene3-formula-line2、scene3-formula-line3、scene3-formula-line4
  - 控件元素：scene3-prev-btn、scene3-next-btn、scene3-step-indicator

- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
