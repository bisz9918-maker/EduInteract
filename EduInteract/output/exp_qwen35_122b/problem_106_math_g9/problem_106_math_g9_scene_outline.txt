    **题目原文：**
    如图，已知⊙O是等腰Rt△ABC的外接圆，点D是$\stackrel\frown{AC}$上一点，BD交AC于点E，若BC=4，AD=$\frac{4}{5}$，则AE的长是（  ）
    A．3  B．2  C．1  D．1.2

    **题目分析：**
    本题是圆与相似三角形的综合题，核心考点包括：
    1. 直径所对圆周角为直角（∠ACB = ∠ADB = 90°）
    2. 等腰直角三角形的边长关系（AC = BC = 4，AB = 4√2）
    3. 圆周角定理（同弧所对圆周角相等）
    4. 相似三角形的判定与性质（△ADE ∽ △BCE）

    **整体讲解思路：**
    教师应引导学生从圆的性质出发，逐步发现直角三角形和相似关系，最终通过比例计算求出 AE。图示规划：一个综合图示展示完整几何结构，通过分步导航呈现解题逻辑链。

    **教学说明：**

    本图示通过分步导航完整呈现解题逻辑链，教师应按以下步骤引导学生：

    **步骤 0-1：发现直角**
    引导学生观察 AB 经过圆心 O，确认 AB 是直径。提问："直径所对的圆周角是什么角？"学生回答 90°后，高亮∠ACB 和∠ADB，强调"同一条直径对应两个直角"。

    **步骤 2：计算边长**
    确认△ABC 是等腰直角三角形，AC = BC = 4。引导学生用勾股定理计算 AB = √(4² + 4²) = 4√2。这一步为后续相似比计算提供基础数据。

    **步骤 3-4：判定相似**
    这是解题关键。提问："∠DAE 和∠CBE 有什么关系？"引导学生发现它们同对弧 CD，所以相等。再确认∠ADE = ∠BCE = 90°，从而△ADE ∽ △BCE（AA 相似）。用蓝色框高亮两个三角形，强化视觉记忆。

    **步骤 5-6：比例计算**
    由相似得 $\frac{AE}{BE} = \frac{AD}{BC} = \frac{4/5}{4} = \frac{1}{5}$。设 AE = x，则 BE = 5x，CE = 4 - x。在 Rt△BCE 中用勾股定理：$16 + (4-x)^2 = 25x^2$，展开得 $16 + 16 - 8x + x^2 = 25x^2$，整理得 $24x^2 + 8x - 32 = 0$，即 $3x^2 + x - 4 = 0$，解得 x = 1 或 x = -4/3（舍去）。故 AE = 1。

    **课堂讲解建议：**
    - 强调"直径→直角→相似→比例"的逻辑链条
    - 提醒学生注意圆周角定理的两种应用：同弧相等、直径对直角
    - 计算时注意舍去负根，验证答案合理性
    - 可追问：若 AD 长度变化，AE 如何变化？引导学生思考函数关系
