题目原文：
如图，在 MN 的同侧作△AMN 和△BMN，BM 平分∠AMN，AN 平分∠BNM，AN 交 BM 于点 C．设∠A=α°，∠B=β°，下列结论不正确的是（ ）

A．若α=β，则点 C 在 MN 的垂直平分线上
B．若α+β=180°，则∠AMB=∠NMB
C．∠MCN=(α+β)/3+60°
D．当∠MCN=120°时，延长 MA、NB 交于点 O，则 OA=OB

题目分析：
本题涉及角平分线性质、三角形内角和定理、等腰三角形判定等核心几何知识。

整体讲解思路：

  1. 首先展示基础图形，明确已知条件：BM 平分∠AMN，AN 平分∠BNM
  2. 利用角平分线性质建立角度关系
  3. 逐一验证各选项的正确性
  4. 通过动态调整角度参数，观察图形变化规律

教学说明：

本图示是本题的核心可视化材料，教师应引导学生按以下步骤观察和理解：

步骤 0-1：理解基本图形结构
首先让学生观察基础图形，明确：

  • 两个三角形△AMN 和△BMN 共用底边 MN
  • 点 A 和点 B 在 MN 的同侧
  • 已知∠A=α°，∠B=β°

步骤 2-3：掌握角平分线性质
重点讲解：

  • BM 平分∠AMN ⇒ ∠AMB = ∠NMB = ∠AMN/2
  • AN 平分∠BNM ⇒ ∠BNA = ∠MNA = ∠BNM/2
  • 用相同颜色的弧线标记相等的角，帮助学生直观理解

步骤 4：推导∠MCN 的表达式
关键推导：

  1. 在△AMN 中：∠AMN + ∠ANM + α = 180°
  2. 在△BMN 中：∠BMN + ∠BNM + β = 180°
  3. 由角平分线：∠AMB = ∠NMB = ∠AMN/2，∠BNA = ∠MNA = ∠BNM/2
  4. 在△MCN 中：∠MCN = 180° - ∠CMN - ∠CNM
  5. 其中∠CMN = ∠NMB = ∠AMN/2，∠CNM = ∠MNA = ∠BNM/2
  6. 代入整理可得∠MCN 与α、β的关系

选项验证要点：

  • 选项 A：当α=β时，△AMN≌△BNM（ASA），故 CM=CN，点 C 在 MN 的垂直平分线上 ✓
  • 选项 B：当α+β=180°时，需要验证∠AMB=∠NMB是否成立（实际上这是角平分线的定义，恒成立）✓
  • 选项 C：需要验证∠MCN=(α+β)/3+60°是否正确（通过推导可判断）
  • 选项 D：当∠MCN=120°时，延长 MA、NB 交于 O，验证 OA=OB是否成立

课堂讲解建议：

  1. 先让学生独立思考各选项，再逐步揭示答案
  2. 对于错误选项，要引导学生找出反例或证明其错误
  3. 强调角平分线性质的灵活运用
  4. 提醒学生注意角度计算的准确性

完整解答：

设∠AMN = 2x，∠BNM = 2y

由角平分线性质：

  • ∠AMB = ∠NMB = x
  • ∠BNA = ∠MNA = y

在△AMN 中：2x + y + α = 180° ……①
在△BMN 中：x + 2y + β = 180° ……②

由①+②：3x + 3y + α + β = 360°
⇒ x + y = (360° - α - β)/3 = 120° - (α+β)/3

在△MCN 中：∠MCN = 180° - x - y = 180° - [120° - (α+β)/3] = 60° + (α+β)/3

选项分析：

A．若α=β，由对称性可知 CM=CN，点 C 在 MN 的垂直平分线上 ✓ 正确

B．若α+β=180°，则∠AMB=∠NMB=x，这是角平分线的定义，恒成立 ✓ 正确

C．∠MCN = 60° + (α+β)/3 = (α+β)/3 + 60° ✓ 正确

D．当∠MCN=120°时，60° + (α+β)/3 = 120° ⇒ α+β = 180°
此时延长 MA、NB 交于 O，要证 OA=OB，需△OAB 为等腰三角形
但由已知条件无法推出 OA=OB，此结论不正确 ✗

答案：D

易错点提醒：

  1. 角平分线性质的准确应用
  2. 三角形内角和定理的灵活运用
  3. 代数推导的准确性（特别是分数运算）
  4. 选项 D 需要额外的几何推理，不能仅凭直觉判断
