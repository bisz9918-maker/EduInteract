    重点讲解：
    - BM 平分∠AMN ⇒ ∠AMB = ∠NMB = ∠AMN/2

    **完整解答：**

    设∠AMN = 2x，∠BNM = 2y

    由角平分线性质：
    - ∠AMB = ∠NMB = x
    - ∠BNA = ∠MNA = y

    在△AMN 中：2x + y + α = 180°  ……①
    在△BMN 中：x + 2y + β = 180°  ……②

    由①+②：3x + 3y + α + β = 360°
    ⇒ x + y = (360° - α - β)/3 = 120° - (α+β)/3

    在△MCN 中：∠MCN = 180° - x - y = 180° - [120° - (α+β)/3] = 60° + (α+β)/3

    **选项分析：**

    A．若α=β，由对称性可知 CM=CN，点 C 在 MN 的垂直平分线上 ✓ 正确

    B．若α+β=180°，则∠AMB=∠NMB=x，这是角平分线的定义，恒成立 ✓ 正确

    C．∠MCN = 60° + (α+β)/3 = (α+β)/3 + 60° ✓ 正确

    D．当∠MCN=120°时，60° + (α+β)/3 = 120° ⇒ α+β = 180°
       此时延长 MA、NB 交于 O，要证 OA=OB，需△OAB 为等腰三角形
       但由已知条件无法推出 OA=OB，此结论**不正确** ✗

    **答案：D**

    **易错点提醒：**
    1. 角平分线性质的准确应用
    2. 三角形内角和定理的灵活运用
    3. 代数推导的准确性（特别是分数运算）
    4. 选项 D 需要额外的几何推理，不能仅凭直觉判断
