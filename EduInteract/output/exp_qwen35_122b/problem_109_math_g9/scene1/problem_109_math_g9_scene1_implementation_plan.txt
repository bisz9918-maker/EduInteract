[分步序列]
步骤 0（初始状态）：
- 显示：点 A、B，线段 AB，原半圆弧
- 标注：标签 A、B，标注 AB=4
- 目的：展示题目基础条件

步骤 1（点击"下一步"）：
- 新增：点 A'，线段 A'B，旋转后半圆弧，阴影区域
- 新增标注：标签 A'，标注 阴影部分
- 视觉变化：阴影区域以蓝色半透明填充
- 目的：展示旋转后的图形和待求阴影

步骤 2（点击"下一步"）：
- 新增：线段 AA'（虚线），扇形 ABA'
- 新增标注：标注 ∠ABA'=45°
- 视觉变化：扇形区域以红色半透明填充
- 目的：添加辅助线，展示解题关键——扇形面积

步骤 3（结论，点击"下一步"）：
- 新增：结论文本框
- 显示公式：
  阴影面积 = 旋转后半圆面积 + 扇形 ABA' 面积 - 原半圆面积
  = π×2² + π×2²×(45°/360°) - π×2²
  = π×4×(45/360)
  = π
- 答案高亮：选项 A. π
- 目的：展示面积抵消原理和最终答案

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 理由：几何图形（圆弧、线段、扇形）用 SVG path 绘制最精确，无需额外库
  - 状态管理：用变量 currentStep 记录当前步骤，0~3
  - 元素显示控制：通过 setAttribute('display', 'none/block') 控制各元素可见性

- 画布尺寸：800 × 500 px

- 布局草图（ASCII）：


- 关键实现要点：
  1. 状态机设计：currentStep 变量 (0~3)，每一步定义需要显示的元素 ID 列表
  2. 圆弧绘制：用 SVG path 的 A 命令，参数为 rx ry x-axis-rotation large-arc-flag sweep-flag x y
  3. 扇形绘制：用 path 的 L（直线）和 A（圆弧）组合，形成闭合扇形
  4. 阴影区域：用 path 的复合路径，先画旋转后半圆（顺时针），再画原半圆（逆时针），形成差集
  5. 坐标计算：
     - B 点 (600, 350) 为旋转中心
     - A 点 (200, 350)，AB 长度 400px（比例 100px/单位）
     - A' 点：从 B 点逆时针 135°方向，长度 400px
       x = 600 + 400×cos(135°) = 600 - 283 = 317
       y = 350 + 400×sin(135°) = 350 - 283 = 67（约 66）
  6. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateDisplay()
  7. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-point-A、scene1-arc-original）
  8. IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染

- 元素 ID 列表（scene1- 前缀）：
  - scene1-point-A, scene1-point-B, scene1-point-A'
  - scene1-line-AB, scene1-line-A'B, scene1-line-AA'

- 结论文本内容（步骤 3 显示）：
  阴影面积 = S(旋转后半圆) + S(扇形 ABA') - S(原半圆)
           = π×2² + π×2²×(45°/360°) - π×2²
           = π×4×(45/360)
           = π
  答案：A. π
