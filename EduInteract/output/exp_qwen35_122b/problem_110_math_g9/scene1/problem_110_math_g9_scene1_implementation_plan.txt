[图示主题与整合说明]
- 本图示主题：台球反射路径的几何关系与角度计算
- 整合内容：整合了题目原图展示、法线垂直关系、反射定律（入射角=反射角）、角度计算推导、最终结论五个认知阶段
- 教学价值：教师可通过分步导航引导学生逐步理解反射问题的几何推理过程：从识别已知条件（∠3=30°）→理解法线垂直边框→应用反射定律（∠1=∠2）→利用互余关系计算→得出结论（∠1=60°）

冲突检查：
- "∠1"(420,90)与"∠2"(480,90)：水平间距60px → 无冲突
- "∠1"(420,90)与"∠1 = ∠2 = 60°"(420,115)：垂直间距25px → 无冲突
- "∠2"(480,90)与"法线"(465,140)：距离约53px → 无冲突
- "法线"(465,140)与"∠2 + ∠3 = 90°"(520,200)：距离约72px → 无冲突
- "∠2 + ∠3 = 90°"(520,200)与"∠2 = 90° - 30° = 60°"(520,225)：垂直间距25px → 无冲突
- "∠3=30°"(700,350)与其他标签距离均>100px → 无冲突

结论：所有标签间距均≥20px，无冲突。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：位于(280,455)，点击返回上一状态，步骤0时禁用（灰色）
  - "下一步 ▶"按钮：位于(460,455)，点击进入下一状态，步骤4时变为"完成"并禁用
- 教师操作流程：
  1. 初始展示题目图形，让学生观察已知条件（∠3=30°）
  2. 点击"下一步"，强调法线垂直关系
  3. 点击"下一步"，引入反射定律概念（∠1=∠2）
  4. 点击"下一步"，展示角度计算过程
  5. 点击"下一步"，得出最终答案
  6. 可随时点击"上一步"回退复习难点

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形（矩形、圆形、线段、圆弧）用 SVG 绘制最清晰，无需额外库，代码轻量
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │  800px                                                  │
  │  ┌───────────────────────────────────────────────────┐  │
  │  │                                                   │  │
  │  │     台球桌区域（640×320）                          │  │
  │  │     包含：边框、袋口、白球、黑球、路径、法线       │  │
  │  │     角度标注：∠1、∠2、∠3                          │  │
  │  │                                                   │  │
  │  │                                                   │  │
  │  │                                                   │  │
  │  │        步骤提示框 (150,410)-(650,440)             │  │
  │  │                                                   │  │
  │  │      [◀ 上一步]        [下一步 ▶]                 │  │
  │  │       (280,455)         (460,455)                 │  │
  │  └───────────────────────────────────────────────────┘  │
  │  500px                                                  │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-4) 跟踪当前步骤，updateDisplay() 函数根据 currentStep 显示/隐藏对应元素
  2. 坐标计算：所有元素坐标硬编码在 SVG 中，确保精确位置
  3. 角度弧线：用 SVG <path>的圆弧命令绘制，计算起点和终点坐标
  4. 箭头绘制：用 SVG <marker>定义箭头，应用到路径的 marker-end 属性
  5. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateDisplay()
  6. 禁用状态：步骤0时"上一步"按钮 disabled，步骤4时"下一步"按钮 disabled
  7. ID 命名规范：所有元素 ID 以"scene1-"为前缀（如 scene1-table, scene1-normal, scene1-angle1 等）
  8. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
