[图示主题与整合说明]
- 本图示主题：黄金三角形（36°-72°-72°）的几何性质与cosA值推导
- 整合内容：整合了5个认知步骤——①基础等腰三角形认知 ②垂直平分线性质揭示 ③角度关系推导 ④边长关系建立 ⑤cosA值计算结论
- 教学价值：教师可通过分步导航控制讲解节奏，逐步引导学生从图形观察→性质应用→计算结论的完整推理过程，特别适合讲解黄金三角形的几何特性

[分步序列]
步骤0（初始状态）：
- 显示：三角形ABC（黑边，淡蓝填充）
- 显示：顶点A、B、C、D、E的圆点标记
- 显示：边AB=4、AC=4的长度标注
- 显示：∠B=72°、∠C=72°的角度标注
- 显示：线段DE（蓝色），D点直角符号
- 隐藏：线段BE、∠A、∠EBA、∠EBC、AE=x、EC=4-x、结论

步骤1：
- 高亮：线段DE变为红色（垂直平分线重点）
- 新增标注：DA=DB（等长标记，绿色单短线）
- 显示：∠A=36°（计算得出）
- 其他元素保持步骤0状态

步骤2：

步骤3：

- 新增标注：BE=BC（等腰三角形揭示）
- 新增等长标记：BE=BC（绿色虚线）

步骤4：
- 高亮：边长关系标注

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 按钮"◀ 上一步"：位于(250,455)，点击返回上一步骤，初始步骤0时禁用
  - 按钮"下一步 ▶"：位于(450,455)，点击进入下一步骤，步骤5时变为"完成"
- 教师操作流程：
  1. 初始展示基础三角形，讲解等腰三角形性质
  2. 点击"下一步"，揭示垂直平分线DE，讲解垂直平分线性质
  3. 点击"下一步"，连接BE，讲解等腰三角形EAB
  4. 点击"下一步"，揭示角度关系，讲解黄金三角形特性
  5. 点击"下一步"，建立边长关系方程
  6. 点击"下一步"，展示cosA计算结论，指向正确选项C
  7. 可随时点击"上一步"回退复习关键步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形绘制简单，SVG 适合精确坐标定位和样式控制，无需额外库依赖
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    SVG 画布 800×500                      │
  │                                                         │
  │                    A(400,80)                            │
  │                   /   \                                │
  │                  /     \                               │
  │             D(340,230) E(483,287)                      │
  │              ●───┐     ●                               │
  │             /    │    / \                              │
  │            /     │   /   \                             │
  │           /      │  /     \                            │
  │    B(280,380)────┴─C(520,380)                          │
  │                                                         │
  │  [角度标注]        [边长标注]        [辅助线]           │
  │                                                         │
  │  ┌─────────────────────────────────────────────────┐   │
  │  │          控件栏 y=440~490                        │   │
  │  │    [◀ 上一步]        [下一步 ▶]                  │   │
  │  └─────────────────────────────────────────────────┘   │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-5) 跟踪当前步骤
  2. 元素分组：每个步骤新增的元素用 data-step 属性标记，如 data-step="2"
  3. 坐标计算：预先计算所有点坐标，用 const 常量存储
  4. 高亮切换：用 CSS class "highlight" 控制红色高亮样式
  5. 按钮状态：步骤0禁用"上一步"，步骤5禁用/改文"下一步"
  6. 角度弧线：用 SVG path 绘制圆弧，计算起点终点坐标
  7. 等长标记：用 SVG path 绘制短线/波浪线/虚线标记
- ID 命名规范：所有交互元素 ID 以 scene1- 为前缀
  - 示例：scene1-tri-abc, scene1-line-de, scene1-btn-prev, scene1-btn-next
  - 使用 getElementById('scene1-xxx') 获取元素
- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
