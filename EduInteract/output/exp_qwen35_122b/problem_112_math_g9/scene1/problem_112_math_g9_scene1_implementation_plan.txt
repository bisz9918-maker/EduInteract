[图示主题与整合说明]
- 本图示主题：三角形旋转与角度关系
- 整合内容：①原三角形△OAB与旋转后三角形△OCD的位置关系；②旋转角70°的可视化；③关键角度∠AOB、∠COD、∠AOD的计算推导
- 教学价值：教师可通过分步演示，引导学生理解旋转的性质（对应角相等、旋转角恒定），逐步推导未知角度，建立从已知条件到结论的完整推理链条

[分步序列]
- 步骤0（初始状态）：
  - 显示：△OAB（边+填充）、点O/A/B及标签、∠A弧线

  - 隐藏：△OCD、点C/D、所有其他角度标注、辅助线

  - 新增：△OCD（边+填充）、点C/D及标签、∠C/∠D弧线

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 按钮"◀上一步"：位于(250,455)，100×25px，步骤1后启用，用于回退复习
  - 按钮"下一步▶"：位于(450,455)，100×25px，步骤4后禁用，用于进入下一步
- 教师操作流程：
  1. 初始展示△OAB及已知条件∠A=100°
  2. 点击"下一步"展示旋转后的△OCD及旋转角70°
  3. 点击"下一步"高亮对应角关系，强调旋转性质
  4. 点击"下一步"计算∠AOB=30°，展示三角形内角和定理应用
  5. 点击"下一步"计算∠AOD=40°，得出最终答案
  6. 可随时点击"上一步"回退，让学生复习关键步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形（三角形、圆弧、线段）用 SVG 绘制最精确，动画通过显示/隐藏元素实现，无需复杂动画库
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────┐
  │                                                         │
  │           C(200,180)    D(280,150)                      │
  │              ●──────────●                               │
  │             /│          /│                              │
  │            / │         / │                              │
  │           /  │        /  │                              │
  │          ●───┼──────●   │                              │
  │         O(150,350)    │                              │
  │          │   \       │                              │
  │          │    \      │                              │
  │          │     \     │                              │
  │          │      \    │                              │
  │          │       \   │                              │
  │          │        \  │                              │
  │          │         \ │                              │
  │          │          \│                              │
  │          ●───────────●───────────●                  │
  │         A(400,320)              B(550,350)          │
  │                                                         │
  │         [旋转角弧线 70°] [∠AOD弧线 40°]                 │
  │                                                         │
  │  ┌─────────────────────────────────────────────────┐   │
  │  │      [◀上一步]          [下一步▶]               │   │
  │  └─────────────────────────────────────────────────┘   │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-4) 跟踪当前步骤，updateScene() 函数根据 currentStep 显示/隐藏对应元素
  2. 坐标计算：所有点坐标预先计算好，用 SVG 的 polyline/polygon/circle/text 元素绘制
  3. 圆弧绘制：用 SVG 的 path 元素，d 属性用圆弧命令 A，计算起始角和终止角
  4. 事件绑定：按钮点击事件调用 nextStep() 和 prevStep()，更新 currentStep 后调用 updateScene()
  5. 元素 ID 命名：所有元素 ID 以 scene1- 为前缀，如 scene1-tri-oab、scene1-arc-rotation、scene1-btn-next
  6. IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
- ID 命名规范：
  - 三角形：scene1-tri-oab, scene1-tri-ocd
  - 顶点：scene1-pt-o, scene1-pt-a, scene1-pt-b, scene1-pt-c, scene1-pt-d
  - 弧线：scene1-arc-rotation(旋转角), scene1-arc-aob, scene1-arc-cod, scene1-arc-aod
  - 标签：scene1-label-70deg, scene1-label-aob30, scene1-label-cod30, scene1-label-aod40
  - 按钮：scene1-btn-prev, scene1-btn-next
  - 文本提示：scene1-text-calc1(∠AOB计算), scene1-text-calc2(∠AOD计算), scene1-text-conclusion(结论)
