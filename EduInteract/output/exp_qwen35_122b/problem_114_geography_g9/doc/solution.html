problem_114_geography_g9

场景导航：Scene 1

题目原文：
读图，完成1-2题

根据此图判断正确的一项是（ ）
A. A点一年只有一次太阳直射
B. B点一年可能有两次直射现象
C. 从南北半球位置看，B点在南半球
D. 从东西半球位置看，A点在东半球，B点在西半球

题目分析：
本题考察地球自转方向与半球判断、太阳直射点规律、经纬网定位等地理核心知识。

关键信息提取：

  • 左图：地球自转方向为逆时针 → 北极俯视图 → 北半球
  • 右图：地球自转方向为顺时针 → 南极俯视图 → 南半球
  • A点位于北半球，B点位于南半球
  • 图中有0°和180°经线作为参照

选项分析：

  • A选项：A点在北半球，若在北回归线以北则无直射，若在回归线之间则有两次直射
  • B选项：B点在南半球，同理判断直射次数
  • C选项：根据自转方向判断半球，顺时针=南极=南半球 ✓
  • D选项：需要判断A、B两点的东西半球位置

讲解思路：

  1. 首先引导学生观察两幅图的自转方向差异
  2. 利用"北逆南顺"口诀判断南北半球
  3. 分析各选项的正确性
  4. 总结解题方法

图示规划：

  • Scene 1：地球自转方向与半球判断（核心图示）

教学说明：

本图示是本节课的核心可视化材料，教师应引导学生按以下步骤观察和思考：

1. 观察自转方向（步骤0→步骤1→步骤2）
让学生先独立观察两幅图的自转箭头方向差异，提问："这两幅图的自转方向有什么不同？"引导学生用眼睛跟随箭头方向，感受逆时针和顺时针的区别。

2. 建立半球判断规则（步骤1→步骤2）
强调"北逆南顺"这一核心口诀：

  • 逆时针旋转 = 从北极上空看 = 北半球
  • 顺时针旋转 = 从南极上空看 = 南半球

3. 定位A、B点（步骤3→步骤4）
在明确半球的基础上，标注A、B两点，让学生确认：

  • A点位于北半球
  • B点位于南半球

4. 分析选项（步骤5）
逐一分析四个选项：

  • A选项：A点在北半球，从图上看位于中纬度（非回归线），无直射或两次直射，错误
  • B选项：B点在南半球中纬度，同样无直射或两次直射，错误
  • C选项：B点在南半球，正确 ✓
  • D选项：需要进一步判断东西半球，但从图中无法精确确定经度，且C已确定正确

5. 总结解题方法
强调解题关键：先判断半球（北逆南顺），再分析其他条件。

课堂建议：

  • 可让学生用手势模拟自转方向，加深记忆
  • 追问："如果自转方向反过来，半球会怎样变化？"
  • 延伸：东西半球划分（20°W-160°E为东半球）可作为拓展内容

完整解答：

正确答案：C

解题过程：

  1. 观察左图：地球自转方向为逆时针 → 北极俯视图 → 北半球
  2. 观察右图：地球自转方向为顺时针 → 南极俯视图 → 南半球
  3. 判断A点：位于北半球
  4. 判断B点：位于南半球
  5. 分析选项：
  • A错误：A点在北半球中纬度，无太阳直射
  • B错误：B点在南半球中纬度，无太阳直射
  • C正确：B点确实在南半球
  • D无法确定：从图中无法精确判断东西半球

核心知识点总结：

  • 地球自转方向判断半球：北逆南顺
  • 太阳直射点范围：南北回归线之间（23.5°N-23.5°S）
  • 直射次数规律：
  • 回归线上：一年一次
  • 回归线之间：一年两次
  • 回归线之外：无直射
  • 东西半球划分：20°W向东到160°E为东半球

易错点提醒：

  • 混淆南北半球判断规则
  • 误认为所有点都有太阳直射
  • 东西半球与东西经度混淆
