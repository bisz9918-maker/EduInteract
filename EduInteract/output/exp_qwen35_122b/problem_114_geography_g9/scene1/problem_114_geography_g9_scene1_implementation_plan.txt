[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：ID scene1-prev-btn，位置 (300,450)，作用：返回上一步骤，步骤 0 时禁用
  - "下一步 ▶"按钮：ID scene1-next-btn，位置 (420,450)，作用：进入下一步骤，步骤 5 时禁用
- 教师操作流程：
  1. 初始展示两幅极地投影图，让学生观察自转方向
  2. 点击"下一步"，高亮左图逆时针箭头，引导学生理解"逆时针=北极"
  3. 点击"下一步"，高亮右图顺时针箭头，引导学生理解"顺时针=南极"
  4. 点击"下一步"，标注 A 点，确认其位于北半球
  5. 点击"下一步"，标注 B 点，确认其位于南半球
  6. 点击"下一步"，显示结论"北逆南顺"口诀及正确选项 C
  7. 可随时点击"上一步"回退复习某个环节

- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-5) 跟踪当前步骤
  2. 坐标计算：A 点坐标 (143,193) = (200-80×cos(45°), 250-80×sin(45°))；B 点坐标 (657,307) = (600+80×cos(45°), 250+80×sin(45°))
  3. 元素显示控制：每个步骤通过 setAttribute('display', 'block/none') 控制元素可见性
  4. 高亮效果：步骤 1-2 通过修改 stroke-width 和 stroke 属性实现箭头高亮
  5. 按钮状态：根据 currentStep 值启用/禁用按钮（opacity 和 pointer-events 控制）
  6. 提示文字更新：每次步骤变化时更新提示框内 text 元素内容
  7. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-left-circle-outer, scene1-arrow-left, scene1-point-a 等）
  8. JS 隔离：所有代码包在 (function() { ... })() IIFE 中，避免全局污染
  9. 事件绑定：使用 addEventListener 绑定按钮点击事件，通过 getElementById 获取元素

- 事件处理逻辑：
  ```javascript
  (function() {
    var currentStep = 0;
    var maxStep = 5;
    
    function updateStep() {
      // 根据 currentStep 更新各元素显示状态
      // 更新提示文字
      // 更新按钮状态
    }
    
    document.getElementById('scene1-prev-btn').addEventListener('click', function() {
      if (currentStep > 0) {
        currentStep--;
        updateStep();
      }
    });
    
    document.getElementById('scene1-next-btn').addEventListener('click', function() {
      if (currentStep < maxStep) {
        currentStep++;
        updateStep();
      }
    });
    
    // 初始化
    updateStep();
  })();
  ```
