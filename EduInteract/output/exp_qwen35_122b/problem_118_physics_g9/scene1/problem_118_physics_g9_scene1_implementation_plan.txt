[分步序列]
- 步骤 0（初始状态）：显示完整电路图，所有元件为黑色，无高亮，展示题目基础电路结构
- 步骤 1：高亮主回路（蓝色）— 电源→开关 S→右侧导线→电流表 A→滑片 P→R₂→左侧导线→R₁→电源，用蓝色粗线描边主回路导线，元件填充透明度 20% 蓝色
- 步骤 2：高亮电流表 A（蓝色）— 电流表 A 圆圈加粗蓝色边框，标注"测总电流"，强调其串联在电路中的位置
- 步骤 3：高亮电压表 V₁（蓝色）— V₁圆圈加粗蓝色边框，V₁与 R₂之间的连接线高亮，标注"测 R₂电压"
- 步骤 4：高亮电压表 V₂（蓝色）— V₂圆圈加粗蓝色边框，V₂与电源之间的连接线高亮，标注"测电源电压"
- 步骤 5（结论）：所有电表同时绿色高亮，显示总结文字"V₁测 R₂，V₂测电源，A 测总电流"，用绿色标注各测量关系

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮：ID scene1-prev-btn，位置 (250,455)-(340,475)，点击返回上一步
  - 下一步按钮：ID scene1-next-btn，位置 (430,455)-(520,475)，点击进入下一步
- 教师操作流程：
  1. 初始展示完整电路图，让学生观察整体结构
  2. 点击"下一步"，高亮主回路，引导学生识别电流路径
  3. 点击"下一步"，高亮电流表 A，讲解串联电流表的作用
  4. 点击"下一步"，高亮电压表 V₁，讲解并联电压表的测量对象
  5. 点击"下一步"，高亮电压表 V₂，讲解总电压测量
  6. 点击"下一步"，显示结论，总结各电表测量对象
  7. 可随时点击"上一步"回退复习

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（电路图用 SVG 绘制最合适，元件符号清晰，易于高亮控制）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    图示区 800×440                       │
  │                                                         │
  │     V₁○                    ○A                          │
  │      │                      │                          │
  │  ┌───┴───┐              ┌───┴───┐                      │
  │  │       │              │   P   │                      │
  │  │  R₁   │──────────────┤  R₂   │──────────────────┐   │
  │  │       │              │       │                  │   │
  │  └───┬───┘              └───────┘                  │   │
  │      │                                              │   │
  │  ┌───┴───┐                                      ┌───┴───┐│
  │  │       │                                      │       ││
  │  │  +    │──────── S ───────────────────────────│       ││
  │  │电源   │                                      │       ││
  │  │  -    │                                      │       ││
  │  └───┬───┘                                      └───────┘│
  │      │                                                  │
  │      └───────────────────○V₂────────────────────────────┘
  │                                                         │
  └─────────────────────────────────────────────────────────┘
  ┌─────────────────────────────────────────────────────────┐
  │              控件栏（y=440~490）                        │
  │          [◀上一步]              [下一步▶]               │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用 currentStep 变量跟踪当前步骤（0-5），每一步对应不同的 CSS class 或 SVG 属性
  2. 坐标计算：所有元件坐标按布局表精确实现，使用 SVG 的 line、rect、circle、text 元素
  3. 动画曲线：高亮效果使用 CSS transition（0.3s ease），避免突兀变化
  4. 事件绑定：按钮点击事件监听，更新 currentStep 并调用 updateDisplay() 函数
  5. ID 命名规范：所有交互元素 ID 以 scene1- 为前缀（如 scene1-tri-abc、scene1-prev-btn、scene1-next-btn）
  6. JS 隔离：所有代码包在 (function() { ... })() IIFE 中，避免全局污染
  7. 高亮实现：通过添加/移除 CSS class（如 .highlight-blue、.highlight-red、.highlight-green）控制元件样式
  8. 按钮状态：第一步时"上一步"按钮禁用，最后一步时"下一步"按钮禁用
