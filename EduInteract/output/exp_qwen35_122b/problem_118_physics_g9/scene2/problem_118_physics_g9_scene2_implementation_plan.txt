[分步序列]
本场景采用连续拖拽交互，无分步导航，实时响应滑片位置变化：

- 初始状态（滑片在中间位置，x=375）：
  - 显示完整电路图（电源、R₁、R₂、A、V₁、V₂、开关S）
  - 滑片P位于R₂中间位置
  - 示数框显示初始值：I = 0.6A, U₁ = 6V, U₂ = 12V
  - 趋势箭头显示：I→, U₁→, U₂→（初始无变化）
  - R₂阻值显示：约50%（中间位置）

- 拖拽滑片向左移动（x从375→200）：
  - R₂阻值从50%→0%（逐渐减小）
  - I示数从0.6A→1.2A（逐渐增大，绿色↑）
  - U₁示数从6V→0V（逐渐减小，红色↓）
  - U₂示数保持12V不变（灰色→）
  - 实时更新趋势箭头颜色

- 拖拽到最左端（x=200）：
  - R₂ = 0Ω（最小）
  - I = 1.2A（最大，绿色高亮）
  - U₁ = 0V（最小，红色高亮）
  - U₂ = 12V（不变，灰色）

- 拖回右侧（x从200→550）：
  - R₂阻值从0%→100%（逐渐增大）
  - I示数从1.2A→0.4A（逐渐减小，红色↓）
  - U₁示数从0V→8V（逐渐增大，绿色↑）
  - U₂示数保持12V不变（灰色→）

- 拖拽到最右端（x=550）：
  - R₂ = 最大阻值
  - I = 0.4A（最小，红色高亮）
  - U₁ = 8V（最大，绿色高亮）
  - U₂ = 12V（不变，灰色）

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：
  1. HTML input type="range"滑块控件：位置(200,240)-(550,260)，范围0-100，初始值50
  2. 滑片P：SVG内可拖拽元素，位置随滑块值同步更新
  3. 三个示数框：实时显示I、U₁、U₂的数值，边框颜色随变化趋势改变
  4. 趋势箭头：显示↑(绿色)、↓(红色)、→(灰色)，随滑片移动实时更新

- 教师操作流程：
  1. 初始展示：图示加载后显示滑片在中间位置，各电表示数稳定
  2. 讲解R₂变化：拖动滑块向左，说明滑片左移→R₂接入电阻减小
  3. 讲解I变化：观察I示数增大（绿色↑），说明总电阻减小→总电流增大
  4. 讲解U₁变化：观察U₁示数减小（红色↓），说明R₂分压减小
  5. 讲解U₂不变：观察U₂示数保持12V（灰色→），说明电源电压恒定
  6. 反向验证：拖回右侧，观察反向变化，巩固因果链理解

- 关键实现要点：
  1. 状态机设计：维护滑片位置值(0-100)，据此计算R₂阻值、总电流I、U₁、U₂
  2. 坐标计算：滑片P的x坐标 = 200 + (滑块值/100) × 350
  3. 物理量计算：
     - 假设电源电压U=12V，R₁=10Ω，R₂最大=20Ω
     - R₂当前 = (滑块值/100) × 20
     - 总电阻 R = R₁ + R₂
     - 电流 I = U / R
     - U₁ = I × R₂（R₂两端电压）
     - U₂ = U（电源电压，恒定）
  4. 动画曲线：滑片移动使用 requestAnimationFrame 实现平滑过渡
  5. 事件绑定：滑块 input 事件、滑片 mousedown/mousemove/mouseup 事件
  6. 颜色更新：根据变化趋势（增大/减小/不变）动态更新示数框边框颜色和趋势箭头

- ID 命名规范：所有交互元素 ID 以 scene2- 为前缀
  - scene2-slider（滑块控件）
  - scene2-slider-p（滑片P）
  - scene2-display-i（I示数框）
  - scene2-display-u1（U₁示数框）
  - scene2-display-u2（U₂示数框）
  - scene2-arrow-i（I趋势箭头）
  - scene2-arrow-u1（U₁趋势箭头）
  - scene2-arrow-u2（U₂趋势箭头）
  - scene2-r2-label（R₂阻值标签）

- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局污染

- 数值计算示例（假设参数）：
  - 电源电压 U = 12V（恒定）
  - R₁ = 10Ω（固定）
  - R₂最大 = 20Ω
  - 滑块值 0% → R₂=0Ω → I=1.2A → U₁=0V
  - 滑块值 50% → R₂=10Ω → I=0.6A → U₁=6V
  - 滑块值 100% → R₂=20Ω → I=0.4A → U₁=8V

- 趋势判断逻辑：
  - 滑片左移（滑块值减小）：R₂↓ → I↑(绿) → U₁↓(红) → U₂→(灰)
  - 滑片右移（滑块值增大）：R₂↑ → I↓(红) → U₁↑(绿) → U₂→(灰)
