[分步序列]
本场景采用连续拖拽交互，无分步导航，但有以下状态变化：

- 初始状态（步骤 0）：
  - 滑片 P 位于中间位置 (290,150)-(310,190)
  - 滑动变阻器接入电阻为 R_max/2
  - 灯 L₁ 亮度：绿色填充透明度 20%（恒定）
  - 灯 L₂ 亮度：绿色填充透明度 15%（中等亮度）
  - 电阻变化指示条填充：50% 宽度（红色）
  - 电流箭头 I、I₁、I₂ 均显示，I₂ 箭头长度中等

- 拖动过程中（动态变化）：
  - 滑片 P 向右拖动 → 接入电阻减小 → 电阻指示条填充变短
  - L₂ 支路电流 I₂ 增大 → I₂ 箭头变长，L₂ 亮度增加（透明度增至 30%）
  - L₁ 支路电流 I₁ 不变 → I₁ 箭头长度不变，L₁ 亮度不变（保持 20%）
  - 干路电流 I 增大 → I 箭头变长

- 滑片到最右端 (380,150)-(400,190)：
  - 滑动变阻器接入电阻接近 0
  - 灯 L₂ 最亮：绿色填充透明度 30%
  - 电阻指示条填充：接近 0% 宽度
  - I₂ 箭头最长，I 箭头也相应变长

- 滑片到最左端 (200,150)-(220,190)：
  - 滑动变阻器接入电阻最大
  - 灯 L₂ 最暗：绿色填充透明度 10%
  - 电阻指示条填充：100% 宽度
  - I₂ 箭头最短

[交互方案]
- 交互类型：连续拖拽滑块 — 滑片 P 可左右拖动
- 控件说明：
  1. 滑片 P：可拖动元素，范围 x=200~380，拖动时实时更新电阻、电流、亮度
  2. 重置按钮：点击后将滑片 P 复位到中间位置 (290,150)
- 教师操作流程：
  1. 初始展示电路结构，说明并联电路特点
  2. 拖动滑片 P 向右，演示电阻减小 → L₂ 变亮，L₁ 亮度不变
  3. 拖动滑片 P 向左，演示电阻增大 → L₂ 变暗，L₁ 亮度仍不变
  4. 强调结论：并联电路中各支路独立工作，L₁ 亮度不受 L₂ 支路电阻变化影响

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（电路图适合用 SVG 绘制，交互逻辑简单无需重型库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │                        800px                                │
  │  ┌─────────────────────────────────────────────────────┐    │
  │  │                    电路图区域                        │    │
  │  │   U                                                  │    │
  │  │   ↑↓  电源                                           │    │
  │  │   ───┬──────────────────────────────────────┬────    │    │
  │  │      │ S                                    │        │    │
  │  │      │                                      │        │    │
  │  │      ├─────────[变阻器]──L₂─────────────────┤        │    │
  │  │      │         (可拖动 P)   ↑I₂             │        │    │
  │  │      │                                      │        │    │
  │  │      ├────────────────L₁────────────────────┤   R    │    │
  │  │      │              ↑I₁                [指示条]      │    │
  │  │      │                                      │        │    │
  │  │      └──────────────────────────────────────┘        │    │
  │  │                    ↑I                                 │    │
  │  │                                                       │    │
  │  │  控件区：拖动滑片 P 观察变化  [重置]                   │    │
  │  └─────────────────────────────────────────────────────┘    │
  │                          500px                              │
  └─────────────────────────────────────────────────────────────┘
  ```

- 关键实现要点：
  1. 状态机设计：
     - 滑片位置 x (200~380) 作为唯一状态变量
     - 电阻值 R = R_max × (380 - x) / 180
     - I₂ ∝ 1/R，I₁ 恒定，I = I₁ + I₂
     - L₂ 亮度透明度 = 10% + 20% × (x - 200) / 180
     - L₁ 亮度透明度 = 20%（恒定）

  2. 坐标计算：
     - 滑片拖动范围：x ∈ [200, 380]
     - 电阻指示条填充宽度 = 130 × (380 - x) / 180
     - 电流箭头长度 = 基础长度 × 电流比例

  3. 动画曲线：使用 requestAnimationFrame 实现平滑拖动反馈

  4. 事件绑定：
     - 滑片 P 的 mousedown/mousemove/mouseup 事件
     - 重置按钮的 click 事件
     - 拖动时更新所有相关元素（电阻指示条、电流箭头长度、灯泡透明度）

  5. ID 命名规范：所有元素 ID 以 "scene1-" 为前缀
     - 滑片：scene1-slider-p
     - 灯 L₁：scene1-lamp-l1
     - 灯 L₂：scene1-lamp-l2
     - 电阻指示条填充：scene1-resistor-bar
     - 电流箭头：scene1-current-i, scene1-current-i1, scene1-current-i2
     - 重置按钮：scene1-reset-btn

  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染

  7. 拖拽实现细节：
     - 记录滑片初始点击位置
     - mousemove 时计算新位置，限制在 [200, 380] 范围内
     - 实时更新所有依赖该位置的视觉元素
