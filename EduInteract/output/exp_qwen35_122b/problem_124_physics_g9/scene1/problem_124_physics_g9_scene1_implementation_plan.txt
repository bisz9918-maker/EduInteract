[分步序列]
步骤 0（初始状态）：
- 显示：电磁铁铁芯、线圈（正面实线+背面虚线）、电源（含正负极颜色区分）、开关（闭合）、导线连接
- 标注：标签 a（左端）、标签 b（右端）、电源 + 和 - 标签
- 隐藏：电流箭头、右手示意图、极性标记 N/S
- 状态：等待教师点击"下一步"开始讲解

步骤 1（显示电流方向）：
- 新增：红色电流箭头 I 沿导线显示
  - 导线右段：(195,290) 箭头向上
  - 线圈正面段：每段顶部添加小箭头 (110,190)、(150,190)、(190,190)、(230,190)、(270,190)

- 教学点：电流从电源正极流出，沿线圈从正面向上绕

步骤 2（显示右手定则）：
- 新增：右手示意图在右侧区域
  - 右手轮廓：手掌轮廓 (450,150)-(650,320)
  - 四指：弯曲向上曲线，与线圈绕向对应
  - 四指电流箭头：红色箭头指向电流方向

- 标注：标签"四指"、"大拇指"
- 视觉变化：右侧出现右手握持示意图，四指与电流方向一致
- 教学点：右手握住线圈，四指指向电流方向，大拇指指向 N 极

步骤 3（显示磁极判断结果）：

- 视觉变化：电磁铁两端显示 N/S 极性
- 教学点：根据右手定则，大拇指指向的 b 端为 N 极，另一端 a 为 S 极

结论状态（步骤 3 完成后）：

- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-3) 跟踪当前步骤
  2. 元素 ID 命名：所有元素以 scene1- 为前缀（如 scene1-core、scene1-coil、scene1-current-arrow 等）
  3. 显示控制：每个步骤对应的元素设置 display="none" 或 display="block"
  4. 按钮状态：步骤 0 时上一步按钮 disabled，步骤 3 时下一步按钮 disabled 或隐藏
  5. 坐标计算：所有坐标已在布局表中精确规划，直接按坐标绘制
  6. 动画曲线：步骤切换使用简单的 opacity 过渡（0.3s ease）
  7. 事件绑定：按钮点击事件绑定到 stepChange 函数，根据 currentStep 更新显示
  8. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染

- JS 逻辑：
  ```javascript
  (function() {
    const TOTAL_STEPS = 4;
    let currentStep = 0;
    
    const elements = {
      currentGroup: document.getElementById('scene1-current-group'),
      handGroup: document.getElementById('scene1-hand-group'),
      polarityGroup: document.getElementById('scene1-polarity-group'),
      btnPrev: document.getElementById('scene1-btn-prev'),
      btnNext: document.getElementById('scene1-btn-next')
    };
    
    function updateDisplay() {
      // 步骤 0: 只显示基础电路
      // 步骤 1: 显示电流
      // 步骤 2: 显示右手
      // 步骤 3: 显示极性
      elements.currentGroup.style.display = currentStep >= 1 ? 'block' : 'none';
      elements.handGroup.style.display = currentStep >= 2 ? 'block' : 'none';
      elements.polarityGroup.style.display = currentStep >= 3 ? 'block' : 'none';
      
      // 更新按钮状态
      elements.btnPrev.disabled = currentStep === 0;
      if (currentStep === TOTAL_STEPS - 1) {
        elements.btnNext.textContent = '完成';
        elements.btnNext.disabled = true;
      } else {
        elements.btnNext.textContent = '下一步▶';
        elements.btnNext.disabled = false;
      }
    }
    
    elements.btnPrev.addEventListener('click', () => {
      if (currentStep > 0) {
        currentStep--;
        updateDisplay();
      }
    });
    
    elements.btnNext.addEventListener('click', () => {
      if (currentStep < TOTAL_STEPS - 1) {
        currentStep++;
        updateDisplay();
      }
    });
    
    // 初始化
    updateDisplay();
  })();
  ```
