[分步序列]
- 步骤 0（初始状态）：显示主光轴（50,250)-(750,250），显示所有标记点（2F、F、O、F、2F）及其标签，显示凸透镜及其标签。等待教师点击"下一步"。
- 步骤 1：点击"下一步"→ 添加蜡烛（底座、主体、火焰）及其标签"蜡烛"，添加标注"u > 2f"。蜡烛位于左侧 2F 点外侧（x=100）。
- 步骤 2：点击"下一步"→ 添加光屏（支架、面板）及其标签"光屏"，添加标注"f < v < 2f"。光屏位于右侧 F 与 2F 之间（x=560）。
- 步骤 3：点击"下一步"→ 在图示上方中央显示成像性质标签"倒立、缩小、实像"，同时用虚线箭头从蜡烛火焰顶端指向光屏上像的位置（示意成像光路）。
- 步骤 4（最终状态）：所有元素完整显示，教师可配合讲解选择题各选项：A 选项（蜡烛变短像上移）、B 选项（蜡烛靠近透镜像变大）、C 选项（此规律用于照相机而非投影仪）、D 选项（光屏应粗糙以便漫反射）。

- 标签"u > 2f"：坐标(230,230)
- 标签"f < v < 2f"：坐标(500,230)
- 标签"倒立、缩小、实像"：坐标(400,100)

冲突检查：
- "2F"(左) 与 "F"(左)：间距 124px → 无冲突
- "F"(左) 与 "O"：间距 120px → 无冲突
- "O" 与 "F"(右)：间距 120px → 无冲突
- "F"(右) 与 "2F"(右)：间距 116px → 无冲突
- "蜡烛" 与 "u > 2f"：垂直间距 110px，水平间距 145px → 无冲突
- "凸透镜" 与 "倒立、缩小、实像"：垂直间距 10px，水平间距 40px → 有潜在冲突，解决方案：将"倒立、缩小、实像"上移至(400,90)
- "光屏" 与 "f < v < 2f"：垂直间距 120px，水平间距 45px → 无冲突
- "u > 2f" 与 "f < v < 2f"：水平间距 270px → 无冲突

调整后："倒立、缩小、实像"标签坐标改为(400,90)

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "上一步"按钮：位于 SVG 底部左侧(260,450)，步骤 1-4 时可用，步骤 0 时禁用
  - "下一步"按钮：位于 SVG 底部右侧(460,450)，步骤 0-3 时可用，步骤 4 时禁用
- 教师操作流程：
  1. 初始展示主光轴和凸透镜，讲解实验基本装置
  2. 点击"下一步"添加蜡烛，讲解物距 u>2f 的条件
  3. 点击"下一步"添加光屏，讲解像距 f<v<2f 的范围
  4. 点击"下一步"显示成像性质，总结规律
  5. 可点击"上一步"回退复习任意步骤
  6. 配合选择题讲解：A 选项（像的移动方向）、B 选项（像的大小变化）、C 选项（应用辨析）、D 选项（光屏材质）

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    凸透镜成像实验图示                    │
  │                                                         │
  │    蜡烛        u>2f      凸透镜      f<v<2f      光屏   │
  │      │                    │                    │       │
  │      │                    │                    │       │
  │  ────●──────────●─────────●──────────●─────────●────── │ 主光轴 y=250
  │    2F(左)      F(左)      O          F(右)    2F(右)   │
  │                                                         │
  │                                                         │
  │              [上一步]              [下一步]             │ 控件栏 y=450
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep 记录当前步骤（0-4），根据步骤显示/隐藏对应元素
  2. 元素 ID 命名：所有元素 ID 以 scene1- 为前缀，如 scene1-axis、scene1-lens、scene1-candle 等
  3. 按钮状态管理：根据 currentStep 启用/禁用按钮，步骤 0 禁用"上一步"，步骤 4 禁用"下一步"
  4. 元素显示控制：用 display="none" 或 opacity="0" 控制元素可见性，步骤推进时移除该属性
  5. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染
  6. 坐标计算：所有坐标按布局坐标表精确实现，标签位置经冲突检查后确定
  7. 动画效果：步骤切换时可用 opacity 渐变（0.3s transition）增强视觉效果
