[交互方案]
- 交互类型：多状态切换（3 个按钮）
- 控件说明：
  - 按钮 1（scene3-btn-camera）：位置(150,440)，作用切换到照相机成像状态（u>2f）
  - 按钮 2（scene3-btn-projector）：位置(335,440)，作用切换到投影仪成像状态（f<u<2f）
  - 按钮 3（scene3-btn-magnifier）：位置(520,440)，作用切换到放大镜成像状态（u<f）
- 教师操作流程：
  1. 图示加载后默认显示状态 1（照相机），教师讲解 u>2f 时成倒立缩小实像的应用
  2. 点击"投影仪"按钮，图示切换至状态 2，教师对比讲解 f<u<2f 时成倒立放大实像
  3. 点击"放大镜"按钮，图示切换至状态 3，教师讲解 u<f 时成正立放大虚像
  4. 可反复切换按钮，引导学生对比三种情况的物距、像距、成像性质差异

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │  [照相机图标]        [投影仪图标]        [放大镜图标]    │ y=60~110
  │  照相机 u>2f         投影仪 f<u<2f       放大镜 u<f      │
  │  倒立缩小实像        倒立放大实像        正立放大虚像    │
  │                                                          │
  │                                                          │ y=120~170
  │                                                          │
  │     蜡烛              蜡烛              蜡烛             │
  │       │                │                │               │
  │  ─────┼────────────────┼────────────────┼───────────────│ y=250 主光轴
  │  2F   F       O       F       2F                      │
  │                                                          │
  │                                                          │ y=300~400
  │                                                          │
  │  [照相机]      [投影仪]      [放大镜]                   │ y=440~480 控件区
  └─────────────────────────────────────────────────────────┘
  ```

- 关键实现要点：
  1. 状态机设计：使用变量 `currentState` 记录当前状态（1/2/3），切换时先隐藏所有状态专属元素，再显示目标状态元素
  2. 坐标计算：所有元素坐标已在布局坐标表中精确定义，直接硬编码
  3. 动画曲线：状态切换使用 CSS transition（opacity 0.3s ease）实现淡入淡出效果
  4. 事件绑定：三个按钮分别绑定 click 事件，调用 `switchState(n)` 函数
  5. ID 命名规范：所有元素 ID 以 `scene3-` 为前缀（如 `scene3-lens`、`scene3-candle-1`、`scene3-btn-camera`）
  6. IIFE 隔离：所有 JS 代码包裹在 `(function() { ... })()` 中，避免全局污染
  7. 元素显示控制：使用 `element.style.display = 'none'/'block'` 或 `element.style.opacity` 控制可见性

- JS 核心逻辑：
  ```javascript
  (function() {
    let currentState = 1;
    
    function switchState(newState) {
      // 隐藏所有状态
      document.querySelectorAll('.state-group').forEach(g => {
        g.classList.remove('active');
      });
      // 显示新状态
      document.getElementById('scene3-state-' + newState).classList.add('active');
      // 更新按钮样式
      document.querySelectorAll('.btn').forEach(btn => btn.classList.remove('active'));
      document.getElementById('scene3-btn-' + getStateBtnId(newState)).classList.add('active');
      currentState = newState;
    }
    
    function getStateBtnId(state) {
      return state === 1 ? 'camera' : state === 2 ? 'projector' : 'magnifier';
    }
    
    // 初始化
    document.getElementById('scene3-state-1').classList.add('active');
    document.getElementById('scene3-btn-camera').classList.add('active');
    
    // 绑定事件
    document.getElementById('scene3-btn-camera').addEventListener('click', () => switchState(1));
    document.getElementById('scene3-btn-projector').addEventListener('click', () => switchState(2));
    document.getElementById('scene3-btn-magnifier').addEventListener('click', () => switchState(3));
  })();
  ```
