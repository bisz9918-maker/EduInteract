    **题目原文：**
    如图所示，在拉力F作用下，物体A在水平桌面上以速度υ向右匀速运动了距离S，已知A的重力为G，桌面对A的摩擦力为f（滑轮及绳重不计）．则下列说法不正确的是（  ）

    A、有用功为GS
    B、拉力做功为3FS
    C、拉力做功的功率为3Fυ
    D、装置的机械效率为$\frac{f}{3F}$

    **题目分析：**
    这是一道关于**水平滑轮组**的力学综合题，核心考点包括：
    1. 滑轮组绳子段数n的判断（决定距离和速度关系）
    2. 水平滑轮组与竖直滑轮组的本质区别（有用功是克服摩擦力，而非重力）
    3. 功、功率、机械效率的计算

    **关键识别：**
    - 从图中可看出，有**3段绳子**承担拉力（n=3）
    - 物体水平运动，重力G不做功，克服**摩擦力f**做有用功
    - 绳子自由端移动距离 = n × 物体移动距离 = 3S
    - 绳子自由端速度 = n × 物体速度 = 3υ

    **解题思路：**
    1. 先判断滑轮组绳子段数n
    2. 明确有用功 = f × S（不是G × S）
    3. 计算总功 = F × 3S
    4. 计算功率 = F × 3υ
    5. 机械效率 = 有用功/总功 = fS/(3FS) = f/(3F)

    **图示规划：**
    - Scene 1：滑轮组结构分析（标注绳子段数、力与距离关系）
    - Scene 2：功与效率计算关系图（对比有用功、总功、机械效率）

    本图示用于帮助学生理解水平滑轮组的基本结构和工作原理。教师应按以下步骤引导学生观察：

    1. **第一步（基础结构）**：展示完整的滑轮组装置，让学生识别物体A、滑轮组、拉力F的位置关系

    3. **第三步（距离关系）**：展示当物体移动距离S时，绳子自由端需要移动3S的距离，推导公式：

    4. **第四步（速度关系）**：由距离关系推导速度关系：
       $$v_{绳} = n \times v_{物} = 3v$$

    5. **结论**：总结n=3带来的三种关系（段数、距离、速度），为后续计算奠定基础

    **关键提醒：** 学生常误认为水平滑轮组与竖直滑轮组相同，需强调水平运动中重力G不做功，克服的是摩擦力f。

    **Scene 2 教学说明：**

    本图示用于系统讲解水平滑轮组的功、功率和机械效率计算。教师应引导学生按以下逻辑推导：

    1. **有用功计算**：
       - 水平运动中，重力G不做功
       - 克服摩擦力f做有用功
       - 公式：$$W_{有} = f \times S$$
       - **重点强调**：选项A说"有用功为GS"是错误的，这是竖直滑轮组的公式

    2. **总功计算**：
       - 拉力F作用在绳子自由端
       - 绳子移动距离 = 3S
       - 公式：$$W_{总} = F \times 3S = 3FS$$
       - 选项B正确

    3. **功率计算**：
       - 功率 = 力 × 速度
       - 绳子速度 = 3v
       - 公式：$$P = F \times 3v = 3Fv$$
       - 选项C正确

    4. **机械效率**：
       - 公式：$$\eta = \frac{W_{有}}{W_{总}} = \frac{fS}{3FS} = \frac{f}{3F}$$
       - 选项D正确

    5. **结论**：选项A不正确，答案为A

    **课堂讲解建议：**
    - 先让学生独立判断各选项，再对照图示验证
    - 重点辨析水平滑轮组与竖直滑轮组的区别（有用功的对象不同）
    - 总结水平滑轮组的计算规律：有用功=摩擦力×距离，总功=拉力×n×距离
