[分步序列]
- 步骤0（初始状态）：
  - 显示：左侧已知条件框（含F、v、S、G、f、n=3）
  - 显示：右侧选项A/B/C/D框（A红框带✗，B/C/D绿框带✓）
  - 隐藏：中间所有公式框、结论框
  - 目的：展示题目已知条件和待判断选项

- 步骤1：
  - 新增显示：有用功框（蓝边框）
  - 显示内容："W有 = f × S"，"克服摩擦力做功"
  - 高亮：有用功框边框加粗闪烁2次
  - 目的：讲解有用功定义——克服摩擦力做功，而非克服重力做功（排除选项A错误）

- 步骤2：
  - 新增显示：总功框（红边框）
  - 显示内容："W总 = F × 3S"，"拉力做功，n=3"
  - 高亮：总功框边框加粗
  - 新增：从有用功框到总功框的虚线箭头（灰色#888880），标注"W有 < W总"
  - 目的：讲解总功计算，绳子自由端移动距离为3S（n=3）

- 步骤3：
  - 新增显示：功率框（蓝边框）
  - 显示内容："P = F × 3v"，"拉力功率"
  - 高亮：功率框边框加粗
  - 新增：从总功框到功率框的虚线箭头，标注"P = W总/t"
  - 目的：讲解功率计算，绳子自由端速度为3v

- 步骤4：
  - 新增显示：机械效率框（绿边框）
  - 显示内容："η = f / (3F)"，"W有 / W总"
  - 高亮：机械效率框边框加粗
  - 新增：从有用功框和总功框到机械效率框的虚线箭头，汇聚标注"η = W有/W总"
  - 目的：讲解机械效率定义及计算

- 步骤5（结论）：
  - 新增显示：结论框（蓝边框）
  - 显示内容："正确选项：B、C、D"，"错误选项：A"
  - 高亮：所有公式框同时闪烁1次
  - 目的：总结完整计算逻辑，确认选项A错误（有用功应为fS而非GS）

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮：ID=scene2-prev-btn，位置(280,450)-(360,480)，作用：返回上一状态
  - 下一步按钮：ID=scene2-next-btn，位置(460,450)-(540,480)，作用：进入下一状态
  - 步骤指示器：显示当前步骤/总步骤（如"步骤 1/5"）
- 教师操作流程：
  1. 初始展示题目已知条件和选项，引导学生审题
  2. 点击"下一步"逐步展示有用功、总功、功率、机械效率的计算公式
  3. 每步讲解后，可点击"上一步"回顾前序内容
  4. 最终展示结论，确认选项A错误的原因（有用功是克服摩擦力做功fS，不是克服重力做功GS）

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何和文本展示，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │ 800px                                                          │
  │                                                                │
  │ ┌──────────┐  ┌──────────────────────┐  ┌──────────────────┐  │
  │ │ 已知条件 │  │    公式推导区         │  │   选项判断区     │  │
  │ │ F, v, S  │  │  W有 → W总 → P → η   │  │  A✗ B✓ C✓ D✓   │  │
  │ │ G, f, n=3│  │                      │  │                  │  │
  │ └──────────┘  └──────────────────────┘  └──────────────────┘  │
  │                                                                │
  │              ┌──────────────────────┐                          │
  │              │   控件栏             │                          │
  │              │  ◀上一步  下一步▶    │                          │
  │              └──────────────────────┘                          │
  └────────────────────────────────────────────────────────────────┘
                              500px
  ```
- 关键实现要点：
  1. 状态机设计：用 currentStep 变量跟踪当前步骤（0-5），每一步对应不同的元素显示状态
  2. 坐标计算：所有元素使用绝对定位，坐标严格按照布局坐标表
  3. 动画曲线：高亮闪烁使用 CSS keyframes 动画（opacity 0.5→1 循环2次）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateDisplay() 刷新显示
  5. ID 命名规范：所有元素 ID 以 scene2- 为前缀（如 scene2-known-box, scene2-wyou-box, scene2-prev-btn）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 虚线箭头：用 SVG <line> 元素，stroke-dasharray="5,5" 实现虚线效果
  8. 按钮状态：第一步时"上一步"按钮置灰禁用，最后一步时"下一步"按钮置灰禁用
