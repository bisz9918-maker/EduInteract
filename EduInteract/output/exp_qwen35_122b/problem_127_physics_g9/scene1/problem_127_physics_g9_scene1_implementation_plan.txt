[图示主题与整合说明]
- 本图示主题：光通过平行玻璃砖的完整折射光路
- 整合的内容：整合了光线入射→第一次折射→玻璃内传播→第二次折射→出射的完整过程，以及折射定律的直观展示
- 教学价值：教师可逐步引导学生理解光从空气进入玻璃（向法线偏折）、在玻璃内直线传播、从玻璃射出空气（远离法线偏折）的全过程，最终得出"出射光线与入射光线平行但发生侧移"的结论

[分步序列]
- 步骤 0（初始状态）：显示玻璃砖、标签"空气"上、"玻璃"、"空气"下、入射光线（带箭头）。等待教师点击"下一步"
- 步骤 1：显示法线 1（灰色虚线）、入射角弧线 i₁（蓝色）、标签"i₁"。展示入射光线与法线的夹角
- 步骤 2：显示玻璃内光线（红色，从 (350,180) 到 (450,320)）、折射角弧线 r₁（蓝色）、标签"r₁"。展示光线向法线偏折（r₁ < i₁）
- 步骤 3：显示法线 2（灰色虚线）、入射角弧线 i₂（蓝色）、标签"i₂"。展示玻璃内光线与下表面法线的夹角
- 步骤 4：显示出射光线（红色，从 (450,320) 到 (650,420)）、折射角弧线 r₂（蓝色）、标签"r₂"。展示光线远离法线偏折（r₂ > i₂）
- 步骤 5（最终结论）：显示入射光线延长线（灰色虚线）、侧移量标注线（绿色虚线）、标签"侧移量 d"。高亮显示入射光线与出射光线平行，标注侧移量 d

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 按钮"◀ 上一步"：位于 (280,455)，点击后步骤减 1（步骤 0 时禁用）
  - 按钮"下一步 ▶"：位于 (500,455)，点击后步骤加 1（步骤 5 时禁用）
- 教师操作流程：
  1. 初始展示玻璃砖和入射光线，引出问题"光线会如何传播？"
  2. 点击"下一步"，显示法线和入射角，讲解"入射角 i₁是光线与法线的夹角"
  3. 点击"下一步"，显示折射光线和折射角，讲解"光从空气进入玻璃，向法线偏折，r₁ < i₁"
  4. 点击"下一步"，显示下表面法线和入射角 i₂，讲解"玻璃内光线到达下表面"
  5. 点击"下一步"，显示出射光线和折射角 r₂，讲解"光从玻璃射出空气，远离法线偏折，r₂ > i₂"
  6. 点击"下一步"，显示侧移量，总结"出射光线与入射光线平行，但发生了侧移 d"

[技术实现]
- JS 库选择：原生 SVG（简单几何首选，无需额外依赖，易于控制元素显示/隐藏）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────┐
  │                                                         │
  │                    空气 (400,140)                       │
  │                                                         │
  │         入射光线 ↘                                      │
  │              i₁  │                                      │
  │             ┌────┼────┐ 法线 1                          │
  │             │    │    │                                 │
  │             │ 玻璃│    │                                 │
  │             │    │    │                                 │
  │             └────┼────┘ 法线 2                          │
  │                  │    ↘ 出射光线                       │
  │                  │    r₂                               │
  │                 空气 (400,360)                          │
  │                                                         │
  │  控件栏：[◀ 上一步]        [下一步 ▶]                   │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep 记录当前步骤（0-5），根据 currentStep 控制各元素的 display 属性
  2. 坐标计算：所有元素坐标已在布局坐标表中精确定义，直接使用
  3. 动画曲线：步骤切换使用 CSS transition（opacity 0.3s ease）实现淡入淡出效果
  4. 事件绑定：两个按钮分别绑定 click 事件，更新 currentStep 并调用 updateDisplay() 函数
  5. ID 命名规范：所有交互元素 ID 以 scene1- 为前缀（如 scene1-glass-brick、scene1-incident-ray、scene1-step-prev、scene1-step-next 等）
  6. IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
  7. 元素显示控制：每个可显示/隐藏的元素用 class="scene1-step-X"标记，updateDisplay() 函数根据 currentStep 控制对应 class 的 display 属性
