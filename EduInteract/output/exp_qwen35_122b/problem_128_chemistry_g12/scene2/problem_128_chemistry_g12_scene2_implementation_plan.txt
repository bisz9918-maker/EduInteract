[图示主题与整合说明]
- 本图示主题：均摊法计算晶体结构微粒数目
- 整合内容：正三棱柱晶胞结构可视化、顶点/棱中点/体内微粒的共用情况、各位置微粒贡献计算、最终比例化简
- 教学价值：教师可逐步引导学生理解晶胞均摊法的核心逻辑——不同位置的微粒被多少个相邻晶胞共用，从而计算每个晶胞实际拥有的微粒数目

[交互方案]

- 控件说明：

- 教师操作流程：
  1. 初始展示晶胞结构，引导学生观察三类微粒位置
  2. 点击"下一步"，聚焦顶点，讲解12晶胞共用原理
  3. 点击"下一步"，聚焦棱中点，讲解4晶胞共用原理
  4. 点击"下一步"，聚焦体内，讲解完全属于晶胞
  5. 点击"下一步"，展示完整计算和正确答案

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单，无需复杂动画库；原生实现轻量高效
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │                        标题区 (y=0-50)                          │
  ├──────────────────────┬─────────────────────────────────────────┤
  │                      │                                         │
  │   结构图区           │         计算展示区                       │
  │   (x=0-320)          │         (x=320-800)                     │
  │   y=50-400           │         y=50-440                        │
  │                      │                                         │
  │   [正三棱柱]         │   [步骤内容动态显示]                     │
  │   [微粒点]           │   [答案选项]                            │
  │                      │                                         │
  ├──────────────────────┴─────────────────────────────────────────┤
  │   图例区 (y=400-440)        │      控件区 (y=440-490)           │
  │   A● B● C○                │      ◀上一步  下一步▶              │
  └────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：currentStep变量(0-4)，updateScene()函数根据currentStep更新显示
  2. 坐标计算：所有元素使用绝对定位，SVG元素使用x/y属性
  3. 高亮效果：通过改变fill属性和添加透明度实现
  4. 按钮禁用：步骤0时prev按钮disabled，步骤4时next按钮文字改为"完成"
  5. 动画过渡：使用CSS transition实现高亮颜色渐变(0.3s ease)
- ID 命名规范：所有元素ID以"scene2-"为前缀
  - 微粒点：scene2-vertex-{1-6}, scene2-edge-{1-9}, scene2-body-1
  - 线段：scene2-line-{1-9}
  - 文本：scene2-title, scene2-step-{1-4}-text, scene2-option-{A-D}
  - 按钮：scene2-prev-btn, scene2-next-btn
  - 高亮框：scene2-correct-box
- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
