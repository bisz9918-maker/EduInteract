[分步序列]
- 步骤0（初始状态）：
  - 显示完整原电池装置：电极A、B，电解质H₂SO₄，进出口a、b、c、d，电子流向e⁻箭头，灯泡
  - 所有基础元素可见，无高亮标注
  - 等待教师点击"下一步"

- 步骤1：
  - 高亮电子流向箭头（加粗，#1565c0 蓝色）
  - 在电子箭头旁显示标注文字："电子从 B→A"（位置：400,100）
  - 显示提示文字："电子流出极为负极"（位置：400,480，字体12px）
  - 其他元素保持原样

- 步骤2：
  - 在B极上方(460,120)显示红色标注"负极"
  - 在A极上方(280,120)显示绿色标注"正极"
  - 电极B边框变为红色(#c62828)，线宽3px
  - 电极A边框变为绿色(#2e7d32)，线宽3px
  - 隐藏步骤1的"电子从 B→A"标注

- 步骤3：
  - 在b口上方(580,330)显示蓝色标注"通入燃料 C₂H₈N₂"
  - 在a口上方(180,330)显示红色标注"通入氧化剂 N₂O₄"
  - b口箭头和a口箭头高亮（加粗）
  - 隐藏步骤2的电极边框颜色变化（恢复黑色）

- 步骤4：
  - 在B极下方(480,420)显示氧化反应式：
    "C₂H₈N₂ - 16e⁻ + 4H₂O → 2CO₂ + N₂ + 16H⁺"
  - 在A极下方(260,420)显示还原反应式：
    "N₂O₄ + 8H⁺ + 8e⁻ → N₂ + 4H₂O"
  - 在c、d出口处显示"排出产物"标注（灰色，字体12px）
  - 隐藏步骤3的反应物标注

- 步骤5（结论）：
  - 在底部中央(320,430)显示绿色边框矩形框
  - 框内显示"正确选项：B"
  - 在B极位置再次高亮显示"负极"标注
  - 在b口位置再次高亮显示"通入燃料"标注
  - 用箭头连接"负极"→"b口通入燃料"，说明因果关系
  - 所有其他标注隐藏，仅保留结论

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "上一步"按钮：scene1-btn-prev，位置(280,460)，作用：返回上一步骤
  - "下一步"按钮：scene1-btn-next，位置(520,460)，作用：进入下一步骤
  - 步骤指示器：scene1-step-indicator，位置(350,460)，显示"步骤 k/5"
- 教师操作流程：
  1. 初始展示装置图，让学生观察结构
  2. 点击"下一步"，高亮电子流向，引导学生判断电子流动方向
  3. 点击"下一步"，显示正负极标注，讲解判断依据
  4. 点击"下一步"，显示反应物通入位置，讲解燃料/氧化剂分配原则
  5. 点击"下一步"，显示电极反应式，讲解氧化还原反应
  6. 点击"下一步"，显示结论，确认正确选项B

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │                         800px                                  │
  │  ┌──────────────────────────────────────────────────────────┐  │
  │  │                                                          │  │
  │  │           ○ 灯泡                                         │  │
  │  │          /│\                                             │  │
  │  │    e⁻←───┘ └───→e⁻                                       │  │
  │  │   ┌───────────────┐                                      │  │
  │  │ c←│   A 极   │   B 极  │→d                                │  │
  │  │   │  (正极)  │  (负极) │                                  │  │
  │  │   │  H₂SO₄   │        │                                  │  │

  │  │   →a          →b                                         │  │

  │  └──────────────────────────────────────────────────────────┘  │
  │                              500px                             │
  └────────────────────────────────────────────────────────────────┘
  ```

- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-5) 跟踪当前步骤
  2. 坐标计算：所有元素使用绝对坐标，通过 SVG transform 定位
  3. 动画曲线：使用 SVG <animate> 或 JS requestAnimationFrame 实现高亮过渡
  4. 事件绑定：按钮点击事件监听，更新 currentStep 并重新渲染对应元素
  5. 元素显示/隐藏：通过 CSS display 或 opacity 控制
  6. 高亮效果：通过修改 stroke-width、stroke-color 实现

- ID 命名规范：
  - 所有交互元素 ID 以 scene1- 为前缀
  - 电极：scene1-electrode-A, scene1-electrode-B

  - 灯泡：scene1-bulb

  - 进出口：scene1-port-a, scene1-port-b, scene1-port-c, scene1-port-d
  - 标签：scene1-label-A, scene1-label-B, scene1-label-H2SO4, scene1-label-e
