[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "上一步"按钮：位于控件栏左侧，返回前一步状态
  - "下一步"按钮：位于控件栏右侧，进入下一步状态
  - 步骤指示器：显示当前步骤"步骤 X/5"
- 教师操作流程：
  1. 初始展示题目原图，让学生观察测力计A和B的连接方式
  2. 点击"下一步"，高亮连接处并标注相互作用力，讲解牛顿第三定律
  3. 点击"下一步"，标注手的拉力，说明外部作用力
  4. 点击"下一步"，显示测力计读数，解释读数含义
  5. 点击"下一步"，显示结论等式，总结答案
  6. 可随时点击"上一步"回退复习关键概念

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何形状简单（矩形、折线、箭头、文字），无需复杂绘图库
  - SVG 适合精确坐标绘制和 CSS 动画控制

- 画布尺寸：800 × 500 px

- 布局草图（ASCII）：
```
┌─────────────────────────────────────────────────────────────┐
│                         [图示区 800×500]                     │
│                                                             │
│                    A                    B                   │
│                   ┌───┐              ┌───┐                 │
│     ←─────────────│ A │══════════════│ B │─────────────→   │
│   F_手左          │   │  F_BA←  →F_AB│   │      F_手右     │
│                   └───┘              └───┘                 │
│                    甲                    乙                  │
│                   8N                   8N                   │
│                                                             │
│              F_AB = F_BA = 8N                               │
│              F_手左 = F_手右 = 8N                           │
│                                                             │
│              ┌───────────────────────────────────┐          │
│              │     ◀ 上一步    步骤 X/5   下一步 ▶│          │
│              └───────────────────────────────────┘          │
│                         [控件栏]                             │
└─────────────────────────────────────────────────────────────┘
```

- 关键实现要点：
  1. 状态机设计：用变量 currentStep 记录当前步骤（0-4），每一步对应一个显示配置对象
  2. 坐标计算：所有元素使用绝对定位，SVG 内元素用 x/y 属性精确控制
  3. 动画曲线：使用 CSS transition 实现淡入淡出效果（opacity: 0→1）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 并调用 renderStep() 刷新显示
  5. 高亮效果：步骤1中挂钩连接处用黄色光晕（filter: drop-shadow）
  6. ID 命名规范：所有元素 ID 以"scene1-"为前缀（如 scene1-meter-A、scene1-arrow-F_AB）
  7. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染

  - scene1-meter-A：测力计A外壳
  - scene1-meter-B：测力计B外壳

  - scene1-hook-A：测力计A挂钩
  - scene1-hook-B：测力计B挂钩
  - scene1-arrow-left：左手拉力箭头
  - scene1-arrow-right：右手拉力箭头
  - scene1-arrow-F_AB：A对B的作用力
  - scene1-arrow-F_BA：B对A的作用力
  - scene1-label-A：测力计A名称
  - scene1-label-B：测力计B名称
  - scene1-label-Jia：底部"甲"
  - scene1-label-Yi：底部"乙"
  - scene1-reading-A：测力计A读数

  - scene1-conclusion：结论等式
  - scene1-btn-prev：上一步按钮
  - scene1-btn-next：下一步按钮
  - scene1-step-indicator：步骤指示器

```javascript
  3: { show: [...stepConfig[2].show, 'reading-A', 'reading-B'] },
  4: { show: [...stepConfig[3].show, 'conclusion'] }

```
