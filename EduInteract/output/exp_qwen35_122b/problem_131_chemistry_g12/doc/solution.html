场景导航：Scene 1

题目原文：
如图所示,将两烧杯用导线如图相连,Pt、Cu、Zn、C分别为四个电极,当闭合开关后,则以下叙述正确的是 ( )

A. C电极为电解池的阳极
B. Cu电极附近OH⁻浓度增大
C. Na⁺移向Pt电极
D. Pt电极上有O₂生成

题目分析：
这是一道电化学综合题，考查原电池与电解池的组合装置。题目图片展示了两个烧杯通过导线串联：

  1. 右侧烧杯（原电池）：Zn和C电极插入稀H₂SO₄溶液中
  • Zn为活泼金属，作负极，发生氧化反应
  • C为惰性电极，作正极，发生还原反应
  1. 左侧烧杯（电解池）：Pt和Cu电极插入NaCl溶液中
  • 与原电池负极相连的电极为阴极
  • 与原电池正极相连的电极为阳极

整体讲解思路：
教师应引导学生按以下步骤分析：

  1. 首先识别装置类型：右侧为原电池（自发反应），左侧为电解池（外接电源驱动）
  2. 判断原电池的正负极：根据金属活泼性，Zn比C活泼，Zn为负极
  3. 确定电解池的阴阳极：与原电池负极相连的是阴极，与正极相连的是阳极
  4. 分析各电极反应和离子移动方向
  5. 逐一判断选项正误

图示规划说明：
本套图示包含1个核心场景，整合原电池和电解池的完整分析过程，通过分步按钮导航展示：装置识别→电极判断→反应分析→结论验证。

教学说明：

本图示是讲解电化学组合装置的核心可视化材料，教师应按以下步骤引导学生：

第一步：装置识别（步骤0→步骤1）
引导学生观察两个烧杯的不同：右侧是Zn和C在稀H₂SO₄中，这是典型的原电池配置（活泼金属+稀酸）；左侧是Pt和Cu在NaCl溶液中，这是电解池配置（惰性电极+盐溶液）。

第二步：原电池分析（步骤1）
重点讲解：Zn比C活泼，Zn失去电子作负极，电子从Zn流出；C作正极，H⁺在C表面得电子生成H₂。
反应式：

  • 负极（Zn）：Zn → Zn²⁺ + 2e⁻
  • 正极（C）：2H⁺ + 2e⁻ → H₂↑

第三步：电解池判断（步骤2）
关键概念：与原电池负极相连的是电解池的阴极，与正极相连的是阳极。

  • Zn（负极）→ Cu，所以Cu是阴极
  • C（正极）→ Pt，所以Pt是阳极

第四步：电极反应（步骤3→步骤4）
电解NaCl溶液时：

  • 阴极（Cu）：2H₂O + 2e⁻ → H₂↑ + 2OH⁻（水被还原，产生OH⁻）
  • 阳极（Pt）：2Cl⁻ → Cl₂↑ + 2e⁻（Cl⁻优先于OH⁻放电）

第五步：离子移动（步骤5）
电解池中：阳离子移向阴极，阴离子移向阳极

  • Na⁺移向Cu电极（阴极）
  • Cl⁻移向Pt电极（阳极）

第六步：选项判断（步骤6）

  • A错误：C是原电池的正极，不是电解池的阳极
  • B正确：Cu是阴极，水被还原产生OH⁻，附近OH⁻浓度增大
  • C错误：Na⁺移向阴极Cu，不是Pt
  • D错误：Pt是阳极，Cl⁻放电产生Cl₂，不是O₂

课堂讲解建议：

  1. 使用分步导航时，每步停留约30秒，确保学生理解后再进入下一步
  2. 强调"负极=阴极相连，正极=阳极相连"的记忆规律
  3. 提醒学生注意电解池中离子放电顺序：阳极Cl⁻优先于OH⁻
  4. 可让学生先预测答案，再逐步验证，增强参与感
