[分步序列]
步骤0（初始状态）：
- 显示：两个烧杯轮廓、溶液填充、四个电极、导线连接、电流表、开关（断开状态）、所有电极标签、溶液标签、选项区域
- 隐藏：所有标注框、反应式、离子箭头、选项高亮
- 状态：等待教师点击"下一步"开始讲解

步骤1：
- 视觉变化：右侧烧杯区域高亮，显示"原电池"标注框和标签
- Zn电极显示红色高亮层，标注"负极"（红色）
- C电极显示蓝色高亮层，标注"正极"（蓝色）
- 开关变为闭合状态（视觉变化）
- 教师讲解：识别右侧为原电池，Zn比C活泼，Zn为负极失电子，C为正极得电子

步骤2：
- 视觉变化：左侧烧杯区域高亮，显示"电解池"标注框和标签
- Cu电极显示红色高亮层，标注"阴极"（红色）
- Pt电极显示蓝色高亮层，标注"阳极"（蓝色）
- 显示导线连接关系：原电池负极(Zn)→电解池阴极(Cu)，原电池正极(C)→电解池阳极(Pt)
- 教师讲解：左侧为电解池，与原电池负极相连的为阴极，与正极相连的为阳极

步骤3：
- 视觉变化：显示原电池电极反应式
- 负极反应式框出现："Zn → Zn²⁺ + 2e⁻"
- 正极反应式框出现："2H⁺ + 2e⁻ → H₂↑"
- 教师讲解：原电池中Zn失电子被氧化，H⁺得电子被还原生成氢气

步骤4：
- 视觉变化：显示电解池电极反应式
- 阴极反应式框出现："2H₂O + 2e⁻ → H₂↑ + 2OH⁻"
- 阳极反应式框出现："2Cl⁻ → Cl₂↑ + 2e⁻"
- 教师讲解：电解池中阴极H₂O得电子生成H₂和OH⁻，阳极Cl⁻失电子生成Cl₂

步骤5：
- 视觉变化：显示离子移动方向
- Na⁺移动箭头从溶液中部指向Cu电极，标注"Na⁺"
- Cl⁻移动箭头从溶液中部指向Pt电极，标注"Cl⁻"
- 教师讲解：阳离子移向阴极，阴离子移向阳极

步骤6（结论）：
- 视觉变化：高亮正确选项B，显示绿色高亮框
- 在Cu电极附近显示"OH⁻浓度增大"文字说明
- 教师讲解：Cu电极为阴极，发生2H₂O + 2e⁻ → H₂↑ + 2OH⁻，生成OH⁻使附近OH⁻浓度增大，故选项B正确
- 其他选项错误原因简要说明：A错（C是原电池正极不是电解池阳极）、C错（Na⁺移向阴极Cu而非Pt）、D错（Pt阳极生成Cl₂而非O₂）

- 关键实现要点：
  1. 状态机设计：使用变量 currentStep（0-6）跟踪当前步骤，updateScene() 函数根据 currentStep 显示/隐藏对应元素
  2. 坐标计算：所有元素使用绝对坐标，SVG 元素通过 x、y、width、height 属性精确控制
  3. 动画曲线：元素出现使用 opacity 从 0 到 1 的过渡动画（transition: opacity 0.3s ease）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateScene()
  5. 高亮层实现：使用 <rect> 覆盖在电极上，设置 fill 颜色和 opacity，通过 display 控制显示/隐藏
  6. 开关状态：使用 <path> 绘制开关，断开时线段有间隙，闭合时线段连续
  7. 离子箭头：使用 <line> + <marker> 实现虚线箭头，marker 定义在 <defs> 中

```javascript
(function() {
    'use strict';
    // 所有代码在此 IIFE 内
    const currentStep = 0;
    const totalSteps = 7;
    
    function updateScene() {
        // 根据 currentStep 更新显示
    }
    
    document.getElementById('scene1-prev-btn').addEventListener('click', function() {
        if (currentStep > 0) {
            currentStep--;
            updateScene();
        }
    });
    
    document.getElementById('scene1-next-btn').addEventListener('click', function() {
        if (currentStep < totalSteps - 1) {
            currentStep++;
            updateScene();
        }
    });
    
    // 初始化
    updateScene();
})();
```
