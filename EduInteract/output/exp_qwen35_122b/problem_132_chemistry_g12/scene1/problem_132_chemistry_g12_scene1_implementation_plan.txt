[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：ID=scene1-prev-btn，位置(250,465)，点击返回上一步骤
  - "下一步 ▶"按钮：ID=scene1-next-btn，位置(450,465)，点击进入下一步骤
  - 步骤指示器：ID=scene1-step-indicator，位置(350,465)，显示"步骤 1/6"
- 教师操作流程：
  1. 初始展示分子结构，引导学生识别分子组成
  2. 点击"下一步"逐步展示碳原子计数
  3. 继续点击展示氢、氮、氧原子计数
  4. 展示分子式及燃烧耗氧量计算
  5. 展示苯环上不等效氢位置（同分异构体判断关键）
  6. 最后展示答案及解析
  7. 可随时点击"上一步"回退复习

- 画布尺寸：800 × 500 px

- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-5) 跟踪当前步骤
  2. 坐标计算：分子结构各顶点坐标需精确计算，确保六边形比例正确
  3. 动画曲线：元素显示/隐藏使用 opacity 过渡（0.3s ease）
  4. 事件绑定：按钮点击事件绑定到 scene1-prev-btn 和 scene1-next-btn
  5. 碳原子高亮点坐标（20个）：
     - 左侧苯环：6个（与杂环共用2个）
     - 中间杂环：5个（与苯环共用2个）
     - 右侧苯环：6个
     - 4个甲氧基：4个
     - 1个亚甲基：1个
  6. 氢原子高亮点坐标（21个）：
     - 左侧苯环：2个H
     - 中间杂环：3个H
     - 右侧苯环：3个H
     - 4个甲氧基：12个H（每个3个）
     - 1个亚甲基：2个H
  7. 不等效氢位置（7个）：左侧苯环2个 + 中间杂环2个 + 右侧苯环3个

- ID 命名规范：所有交互元素 ID 以 scene1- 为前缀
  - scene1-prev-btn（上一步按钮）
  - scene1-next-btn（下一步按钮）
  - scene1-step-indicator（步骤指示器）
  - scene1-molecule（分子结构组）
  - scene1-carbon-highlights（碳高亮点组）
  - scene1-hydrogen-highlights（氢高亮点组）
  - scene1-equivalent-h（不等效氢标记组）
  - scene1-formula-box（分子式框）
  - scene1-answer-box（答案框）
  - scene1-label-*（各类标签）

- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
