    **题目原文：**
    标准状况下，密闭容器内分别充入空气和H₂、O₂的混合气体在可移动的活塞两边，充入时体积如图所示，若将装置右边H₂、O₂的混合气体点燃引爆，活塞先左弹，恢复至原温度后，活塞右滑最终停在容器的正中央，则原来H₂、O₂的体积比最接近于（  ）

    ①2：7          ②5：4           ③4：5         ④7：2

    A．①②  B．②④  C．③④  D．①③

    **题目分析：**
    这是一道气体反应与气体定律综合题。核心考点包括：
    1. 理想气体状态方程 PV = nRT 的应用
    2. 氢气与氧气的化学反应：2H₂ + O₂ → 2H₂O(l)
    3. 活塞可移动意味着左右压强始终相等
    4. 标准状况下水为液体，不占气体体积

    **整体讲解思路：**
    1. 首先展示初始状态，明确左右体积比为1:3
    2. 展示反应过程及活塞移动（先左弹后右滑）
    3. 展示最终状态，活塞在中央，左右体积各为2
    4. 通过气体定律推导剩余气体量，计算两种可能情况

    **图示规划说明：**
    - Scene 1：容器状态变化全过程（初始→反应→最终），用分步按钮导航展示活塞移动和体积变化
    - Scene 2：两种反应情况的计算对比，用多状态切换展示H₂过量与O₂过量两种情形

    **图示1教学说明：**

    本图示展示密闭容器活塞系统的完整状态变化过程，教师应引导学生按以下步骤观察：

    1. **初始状态观察**：强调左右体积比为1:3，根据PV=nRT，同温同压下体积比等于物质的量比，即n(空气):n(混合气)=1:3

    2. **反应过程理解**：
    - "活塞先左弹"：反应瞬间产生大量水蒸气，气体总量暂时增加，压强增大推动活塞左移
    - 反应方程式：2H₂ + O₂ → 2H₂O(g)

    3. **冷却过程分析**：
    - "恢复至原温度"：水蒸气凝结为液态水，不占气体体积
    - 气体总量减少，压强降低，活塞右滑

    4. **最终状态推导**：
    - 活塞停在中央，左右体积各为2
    - 左边空气物质的量不变，体积从1→2，说明压强变为原来的一半
    - 右边剩余气体在减半压强下体积为2，其物质的量等于原来空气的物质的量

    **关键公式推导：**
    设原来H₂体积为x，O₂体积为y，则 x + y = 3

    根据气体定律分析，反应后剩余气体物质的量为原来的1/3

    情况1：O₂完全反应
    - 消耗O₂ = y，消耗H₂ = 2y
    - 剩余H₂ = x - 2y = 1
    - 联立 x + y = 3，解得 y = 2/3，x = 7/3
    - H₂:O₂ = 7:2

    情况2：H₂完全反应
    - 消耗H₂ = x，消耗O₂ = x/2
    - 剩余O₂ = y - x/2 = 1
    - 联立 x + y = 3，解得 x = 4/3，y = 5/3
    - H₂:O₂ = 4:5

    因此答案为 ③4:5 和 ④7:2，选C。
    </TEXT_2>

    **图示2教学说明：**

    本图示通过分类讨论展示两种可能的反应情形，教师应引导学生理解：

    1. **分类讨论的必要性**：
    - H₂和O₂反应按2:1的体积比消耗
    - 当混合气体比例不等于2:1时，必有一种气体过量
    - 需要分"O₂完全反应"和"H₂完全反应"两种情况讨论

    2. **情况1详解（O₂完全反应）**：
    - 设O₂体积为y，则消耗H₂为2y
    - 剩余H₂ = x - 2y = 1（剩余气体量）
    - 结合 x + y = 3，解方程组得 x = 7/3，y = 2/3
    - 体积比 H₂:O₂ = 7:2，对应选项④

    3. **情况2详解（H₂完全反应）**：
    - 设H₂体积为x，则消耗O₂为x/2
    - 剩余O₂ = y - x/2 = 1
    - 结合 x + y = 3，解方程组得 x = 4/3，y = 5/3
    - 体积比 H₂:O₂ = 4:5，对应选项③

    4. **答案确认**：
    - 两种情况均符合题意
    - 正确选项为③和④，即C．③④

    **课堂讲解建议：**
    - 先让学生独立思考，尝试列出方程
