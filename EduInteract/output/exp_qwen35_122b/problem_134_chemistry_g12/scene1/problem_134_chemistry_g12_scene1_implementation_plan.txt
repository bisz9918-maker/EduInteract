[分步序列]
- 步骤0（初始状态）：空白画布，仅显示标题区预留位置，等待教师点击"下一步"
- 步骤1：显示分子A（正四面体烷）完整结构
  - 正四面体骨架（实线+虚线）
  - 4个碳原子圆点
  - 4条C-H键及H标签
  - 下方标注"正四面体烷 C₄H₄"
  - 上一步按钮变为可点击，下一步按钮保持激活
- 步骤2：显示分子B（三棱柱烷）完整结构
  - 保留分子A
  - 新增三棱柱骨架（实线+虚线）
  - 6个碳原子圆点
  - 6条C-H键及H标签
  - 下方标注"三棱柱烷 C₆H₆"
- 步骤3：显示分子C（立方烷）完整结构
  - 保留分子A、B
  - 新增立方体骨架（实线+虚线）
  - 8个碳原子圆点
  - 8条C-H键及H标签
  - 下方标注"立方烷 C₈H₈"
- 步骤4（最终步骤）：三结构并列对比状态
  - 三个分子完整显示
  - 可点击上一步回退复习任一分子
  - 下一步按钮变为灰色禁用态

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮：ID=scene1-prevBtn，位置(280,455)，作用：返回上一状态，初始步骤0时禁用
  - 下一步按钮：ID=scene1-nextBtn，位置(520,455)，作用：进入下一状态，最终步骤4时禁用
- 教师操作流程：
  1. 初始展示空白，教师点击"下一步"引入分子A
  2. 讲解正四面体烷结构特点（4个碳、4个氢、正四面体构型）
  3. 点击"下一步"展示分子B，对比三棱柱烷与正四面体烷差异
  4. 讲解三棱柱烷结构（6个碳、6个氢、三棱柱构型）
  5. 点击"下一步"展示分子C，对比立方烷与前两者差异
  6. 讲解立方烷结构（8个碳、8个氢、立方体构型）
  7. 最终三结构并列，引导学生总结规律（碳原子数递增、分子式规律）
  8. 可随时点击"上一步"回退复习任一分子

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何结构，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    800px                                │
  │  ┌───────────────────────────────────────────────────┐  │
  │  │                                                   │  │
  │  │   A正四面体      B三棱柱        C立方体           │  │
  │  │   (180,220)      (400,220)      (620,220)         │  │
  │  │     △              ▽▽▽            ▣▣▣             │  │
  │  │    /│\            ▽  ▽          ▣  ▣             │  │
  │  │   / │ \          ▽    ▽        ▣    ▣            │  │
  │  │  ────           ▽────▽        ▣────▣            │  │
  │  │  正四面体烷     三棱柱烷       立方烷             │  │
  │  │   C₄H₄          C₆H₆          C₈H₈               │  │
  │  │                                                   │  │
  │  │         [◀上一步]      [下一步▶]                  │  │
  │  │            (280,455)    (520,455)                 │  │
  │  └───────────────────────────────────────────────────┘  │
  │                      500px                              │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：currentStep变量(0-4)，控制各元素显示/隐藏
  2. 坐标计算：预先定义各分子顶点坐标数组，动态生成SVG元素
  3. 虚线实现：stroke-dasharray="4,4"表示虚线
  4. 按钮状态：根据currentStep启用/禁用按钮（step=0时prev禁用，step=4时next禁用）
  5. 事件绑定：按钮点击事件更新currentStep并重新渲染可见元素
  6. 动画过渡：元素出现使用 opacity 从0到1的过渡动画（0.3s ease）

- ID 命名规范：所有交互元素 ID 以 scene1- 为前缀
  - scene1-prevBtn：上一步按钮
  - scene1-nextBtn：下一步按钮
  - scene1-molA-*：分子A相关元素（scene1-molA-skeleton, scene1-molA-vertices等）
  - scene1-molB-*：分子B相关元素
  - scene1-molC-*：分子C相关元素

- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局污染

- SVG 结构：
