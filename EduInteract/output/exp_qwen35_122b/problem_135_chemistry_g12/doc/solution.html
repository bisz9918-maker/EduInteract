题目原文：

用如图所示装置分别进行如下实验，测定溶液导电性变化．以下哪个选项为导电性先增大后减弱的为（ ）

A．向醋酸溶液中加入氨水
B．向AgNO₃溶液中加入HCl
C．向盐酸溶液中加入NaCl溶液
D．向H₂SO₄溶液中加入BaCl₂溶液

题目分析：

本题考查溶液导电性的变化规律，核心知识点：

  1. 溶液导电性与离子浓度、离子电荷数成正比
  2. 强电解质完全电离，弱电解质部分电离
  3. 化学反应中离子浓度的变化（沉淀生成、弱电解质生成、稀释效应）

整体讲解思路：

  1. 首先通过实验装置图建立导电性测定的直观认识
  2. 重点分析选项A（醋酸+氨水）的反应过程，展示导电性"先增大后减弱"的原因
  3. 对比分析其他选项，排除干扰项
  4. 总结判断方法

图示规划说明：

  • Scene 1：实验装置与导电性原理（建立基础认知）
  • Scene 2：选项A的详细分析（核心讲解，展示先增大后减弱的完整过程）
  • Scene 3：四选项对比总结（归纳结论，强化记忆）
步骤 1/5

Scene 1 教学说明：

本图示帮助学生理解实验装置的工作原理。教师应按以下步骤引导：

  1. 首先展示完整装置，让学生识别各组成部分
  2. 逐步标注电路路径，强调电流从电池正极→导线→电极→溶液→电极→导线→灯泡→电池负极
  3. 说明灯泡亮度与溶液导电性的关系：灯泡越亮，导电性越强；灯泡越暗，导电性越弱
  4. 强调导电性的本质：溶液中自由移动的离子浓度越高，导电性越强

关键公式：

溶液导电性 ∝ 离子浓度 × 离子电荷数

讲解要点：

  • 强电解质（如NaCl、HCl、H₂SO₄）：完全电离，离子浓度高，导电性强
  • 弱电解质（如CH₃COOH、NH₃·H₂O）：部分电离，离子浓度低，导电性弱
  • 反应过程中离子浓度的变化决定导电性变化趋势
初始状态：醋酸为弱电解质，部分电离，离子浓度低，导电性弱

Scene 2 教学说明：

本图示是本题的核心讲解部分，详细展示选项A的反应过程。教师应引导学生观察：

  1. 初始状态（步骤0）：
  • 醋酸是弱电解质，部分电离：CH₃COOH ⇌ CH₃COO⁻ + H⁺
  • 离子浓度低，导电性弱，灯泡暗
  1. 反应过程（步骤1-2）：
  • 加入氨水后发生反应：CH₃COOH + NH₃·H₂O → CH₃COONH₄ + H₂O
  • 生成的醋酸铵是强电解质，完全电离：CH₃COONH₄ → CH₃COO⁻ + NH₄⁺
  • 离子浓度显著增加，导电性增强，灯泡变亮
  1. 恰好完全反应（步骤2）：
  • 醋酸和氨水恰好完全反应
  • 溶液中主要是醋酸铵（强电解质）
  • 离子浓度最高，导电性最强
  1. 过量氨水（步骤3）：
  • 继续加入氨水，溶液被稀释
  • 虽然氨水也是电解质，但稀释效应占主导
  • 离子浓度下降，导电性减弱

关键反应方程式：

CH₃COOH + NH₃·H₂O → CH₃COONH₄ + H₂O

CH₃COONH₄ → CH₃COO⁻ + NH₄⁺（完全电离）

讲解要点：

  • 弱电解质→强电解质的转化导致离子浓度增加
  • 过量试剂的稀释效应导致离子浓度下降
  • 这就是"先增大后减弱"的原因
选项 反应类型 离子变化 导电性趋势
A 弱→强电解质 先增后减 先增大后减弱 ✓
B 沉淀反应 持续减少 先减弱
C 混合 持续增加 持续增强
D 沉淀反应 先减后稳 先减弱

Scene 3 教学说明：

本图示用于总结对比，帮助学生建立完整的判断框架。

各选项详细分析：

  1. 选项A（正确答案）：
  • 反应：CH₃COOH + NH₃·H₂O → CH₃COONH₄ + H₂O
  • 过程：弱电解质→强电解质→稀释
  • 导电性：弱→强→弱（先增大后减弱）
  1. 选项B（错误）：
  • 反应：AgNO₃ + HCl → AgCl↓ + HNO₃
  • 过程：生成AgCl沉淀，离子减少
  • 导电性：持续减弱
  1. 选项C（错误）：
  • 反应：HCl + NaCl → 混合溶液
  • 过程：两种强电解质混合，离子浓度持续增加
  • 导电性：持续增强
  1. 选项D（错误）：
  • 反应：H₂SO₄ + BaCl₂ → BaSO₄↓ + 2HCl
  • 过程：生成BaSO₄沉淀，离子减少
  • 导电性：先减弱

完整解答：

正确答案是 A。

课堂讲解建议：

  1. 先用Scene 1建立实验装置认知
  2. 重点讲解Scene 2，让学生理解"弱→强→稀释"的过程
  3. 用Scene 3对比总结，强化记忆
  4. 强调判断导电性变化的关键：分析离子浓度的变化趋势
  5. 提醒学生注意沉淀生成、弱电解质生成、稀释效应三种情况
