[图示主题与整合说明]
- 本图示主题：选项 A（醋酸 + 氨水）导电性变化过程分析
- 整合内容：反应前→反应中→恰好完全反应→过量氨水四个阶段的离子浓度变化和导电性变化
- 教学价值：教师可通过分步演示，让学生直观理解弱电解质反应生成强电解质过程中离子浓度的变化规律，以及导电性与离子浓度的关系

[分步序列]
- 初始状态（步骤0）：
  - 显示：烧杯、电极、溶液（浅蓝 15% 透明度）、灯泡（暗 10% 透明度）、完整电路
  - 溶液内标注："CH₃COOH（弱电解质）"
  - 曲线图上：仅显示起点 (470,280)，标注"初始"
  - 阶段说明："初始状态：醋酸为弱电解质，部分电离，离子浓度低，导电性弱"

- 步骤1：
  - 显示：溶液颜色加深（30% 透明度），灯泡变亮（50% 透明度）
  - 溶液内标注："CH₃COOH + NH₃·H₂O → CH₃COO⁻ + NH₄⁺"
  - 曲线图上：显示点 (550,200)，标注"反应中"，曲线从起点延伸到该点
  - 阶段说明："加入氨水：生成强电解质 CH₃COONH₄，离子浓度增加，导电性增强"

- 步骤2：
  - 显示：溶液颜色最深（30% 透明度），灯泡最亮（50% 透明度）
  - 溶液内标注："CH₃COONH₄（强电解质）"
  - 曲线图上：显示最高点 (630,140)，标注"恰好完全"，曲线达到峰值
  - 阶段说明："恰好完全反应：全部生成强电解质，离子浓度最高，导电性最强"

- 步骤3：
  - 显示：溶液颜色变浅（20% 透明度），灯泡变暗（20% 透明度）
  - 溶液内标注："过量 NH₃·H₂O（稀释）"
  - 曲线图上：显示点 (710,200)，标注"过量"，曲线下降
  - 阶段说明："过量氨水：稀释作用使离子浓度降低，导电性减弱"

- 结论（步骤3完成后自动显示）：
  - 曲线图上：完整曲线高亮，标注"导电性：弱 → 强 → 弱"
  - 阶段说明："结论：醋酸与氨水反应，导电性先增大后减弱，符合选项 A"

[交互方案]

- 控件说明：
  - 步骤0按钮（scene2-step0-btn）：位置 (220,435)，点击显示初始醋酸状态
  - 步骤1按钮（scene2-step1-btn）：位置 (320,435)，点击显示反应中状态
  - 步骤2按钮（scene2-step2-btn）：位置 (420,435)，点击显示恰好完全反应状态
  - 步骤3按钮（scene2-step3-btn）：位置 (520,435)，点击显示过量氨水状态
- 教师操作流程：
  1. 点击"初始醋酸"，展示弱电解质初始状态
  2. 点击"反应中"，展示离子浓度增加过程
  3. 点击"恰好完全"，展示导电性峰值
  4. 点击"过量氨水"，展示稀释后导电性下降
  5. 可反复点击各按钮对比不同阶段

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何和动画，无需重型库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │                        800px                                   │
  │  ┌─────────────────┐      ┌─────────────────────────────────┐  │
  │  │                 │      │                                 │  │
  │  │   烧杯装置区     │      │      导电性曲线图区              │  │
  │  │   (80-250,      │      │      (450-750,                  │  │
  │  │   120-350)      │      │       100-350)                  │  │
  │  │   [灯泡][电极]  │      │      /‾‾‾\                      │  │
  │  │   [溶液]        │      │     /     \                     │  │
  │  │   [电池]        │      │    /       \                    │  │
  │  └─────────────────┘      └─────────────────────────────────┘  │
  │                                                                  │
  │  ┌────────────────────────────────────────────────────────────┐ │
  │  │  [初始] [反应中] [恰好完全] [过量]                          │ │
  │  │  阶段说明文字动态显示区域                                    │ │
  │  └────────────────────────────────────────────────────────────┘ │
  │                              500px                               │
  └────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：currentStep 变量跟踪当前步骤（0-3）
  2. 溶液透明度：通过 setAttribute('fill-opacity', value) 动态调整
  3. 灯泡亮度：通过 setAttribute('fill-opacity', value) 动态调整
  4. 曲线显示：使用 path 元素的 stroke-dasharray 实现逐步绘制效果
  5. 按钮高亮：当前步骤按钮添加 active 类，背景色 #1565c0
  6. 阶段说明：动态更新 DOM 元素 innerText
- ID 命名规范：所有元素 ID 以 scene2- 为前缀（如 scene2-solution, scene2-bulb, scene2-curve）
- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
