[分步序列]
- 初始状态（步骤 0）：显示分子骨架（黑色实线），所有原子连接关系清晰可见，无高亮，无标签。学生可观察整体分子结构。
- 步骤 1：点击「下一步」→ 3 个酯基区域以蓝色半透明填充高亮显示，辅助标注线连接至标签"酯基×3"。视觉变化：酯基 1、2、3 区域出现蓝色填充，左侧出现说明标签。
- 步骤 2：点击「下一步」→ 5 个碳碳双键以红色双线高亮显示，每个双键上方出现小标签"C=C"，顶部出现汇总标签"C=C×5"。视觉变化：双键 1-5 变为红色双线，新增双键标签。
- 步骤 3：点击「下一步」→ 2 个手性碳原子以绿色实心圆点标记，旁边出现"*C"标识，左侧出现"手性碳"说明标签。视觉变化：手性碳 1、2 位置出现绿点，新增手性碳标签。
- 步骤 4：点击「下一步」→ 完整标注状态，所有高亮和标签同时显示，辅助标注线连接各标签至对应结构。视觉变化：所有元素同时可见，形成完整分析图。
- 教师可随时点击「◀ 上一步」回退复习，逐步讲解每个官能团的识别方法。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 按钮"◀ 上一步"：位置 (250,450)-(380,480)，作用：返回上一步状态，第一步时禁用
  - 按钮"下一步 ▶"：位置 (420,450)-(550,480)，作用：进入下一步状态，最后一步时变为"完成"
- 教师操作流程：
  1. 初始展示分子骨架，让学生先观察整体结构
  2. 点击"下一步"高亮酯基，讲解酯基结构特征及水解反应
  3. 点击"下一步"高亮双键，讲解不饱和键的加成反应
  4. 点击"下一步"标记手性碳，讲解立体化学概念
  5. 点击"下一步"展示完整标注，引导学生综合判断选项正误

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript。原因：分子结构为几何图形，SVG 适合绘制线条和多边形，无需额外库依赖，性能好且易于控制动画
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：

- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-4) 跟踪当前步骤，每一步对应一个状态对象，存储应显示/高亮的元素 ID 列表
  2. 坐标计算：所有元素坐标硬编码在配置对象中，便于维护和修改
  3. 动画曲线：使用 CSS transition 实现淡入淡出效果（opacity 0→1，duration 0.3s）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateDisplay() 刷新视图
  5. 禁用状态：第一步时"上一步"按钮 disabled，最后一步时"下一步"按钮文字变为"完成"
- ID 命名规范：所有交互元素 ID 以 scene1- 为前缀，如 scene1-mol-skeleton、scene1-ester-1、scene1-btn-prev、scene1-btn-next
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
