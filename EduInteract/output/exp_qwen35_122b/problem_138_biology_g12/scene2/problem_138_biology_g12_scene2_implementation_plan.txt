[图示主题与整合说明]
- 本图示主题：处理②杂交后代的遗传分析（F1 代→F2 代）
- 整合内容：整合处理②的完整遗传分析过程，包括亲本杂交→F1 代基因型与表现型→F2 代性状分离比计算，特别区分豆荚颜色（母本性状）与子叶颜色（F1/F2 代性状）的遗传规律差异

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 按钮"◀ 上一步"：scene2-btn-prev，位于 (320,450)-(390,480)，点击返回上一步骤，步骤 0 时禁用
  - 按钮"下一步 ▶"：scene2-btn-next，位于 (410,450)-(480,480)，点击进入下一步骤，步骤 5 时禁用
  - 步骤指示器：scene2-step-indicator，位于 (380,420)，显示当前步骤"步骤 X/6"
- 教师操作流程：
  1. 初始展示亲本基因型，讲解亲本 aa bb × AA BB 的杂交设置
  2. 点击「下一步」展示 F1 代基因型 AaBb，强调 F1 种子基因型
  3. 点击「下一步」展示 Punnett 方格，讲解 F1 自交产生 F2 代的 16 种组合
  4. 点击「下一步」展示豆荚与子叶的遗传规律差异标注
  5. 点击「下一步」展示 F2 豆荚颜色比例，结合 Punnett 方格高亮 aa 格子
  6. 点击「下一步」展示 F2 胚基因型 AABb 比例，结合 Punnett 方格高亮 AABb 格子
  7. 教师可随时点击「上一步」回退复习，巩固关键概念

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：图示为几何图形和文字标签，无需复杂动画或数据可视化，原生 SVG 足以实现，代码简洁易维护
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：

- 关键实现要点：
  1. 状态机设计：使用变量 currentStep（0-5）跟踪当前步骤，steps 数组存储每步应显示/隐藏的元素 ID 列表
  2. 坐标计算：所有元素使用绝对定位（SVG 内），坐标按布局坐标表精确设置
  3. 动画曲线：元素显示使用 opacity 过渡（0.3s ease-in-out），高亮使用 fill 颜色渐变
  4. 事件绑定：按钮点击事件绑定到 scene2-btn-prev 和 scene2-btn-next，更新 currentStep 后调用 updateStep() 刷新显示
  5. 高亮实现：Punnett 方格格子使用 class 区分基因型，步骤 4 时添加 class="highlight-red"，步骤 5 时添加 class="highlight-green"
  6. ID 命名规范：所有元素 ID 以 scene2- 为前缀，如 scene2-parent-a、scene2-f1-box、scene2-punnett-cell-1 等
  7. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染
  8. 按钮禁用状态：步骤 0 时 scene2-btn-prev 添加 disabled 属性并置灰，步骤 5 时 scene2-btn-next 添加 disabled 属性并置灰
