    **题目原文：**

    长方体木块A、B叠放在水平实验台上，然后用轻线跨过定滑轮分别与钩码相连接，如图所示．不计轻线质量以及线和滑轮之间的摩擦，木块A、B在实验台上静止不动．若将图中5号钩码取下，并将它放在木块A上，木块A、B仍在实验台上静止不动，则以下说法正确的是（  ）

    A．实验台与木块B之间相互作用的静摩擦力减小

    B．实验台与木块B之间相互作用的静摩擦力增大

    C．实验台与木块B之间相互作用的静摩擦力不变

    D．木块A、B之间相互作用的静摩擦力减小

    **题目分析：**

    本题考查静摩擦力的平衡分析，涉及叠放物体的受力分析。关键要点：

    1. **初始状态**：A、B静止，系统处于平衡状态
       - 左侧：4、5号钩码（2个）通过滑轮拉A，向左拉力 F左 = 2mg
       - 右侧：1、2、3号钩码（3个）通过滑轮拉B，向右拉力 F右 = 3mg
       - A、B之间有静摩擦力 f_AB
       - B与实验台之间有静摩擦力 f_B台

    2. **变化后状态**：5号钩码从左侧移到A上
       - 左侧：仅剩4号钩码（1个），向左拉力 F左' = mg
       - A上增加5号钩码，A的重力增加
       - 右侧：1、2、3号钩码不变，向右拉力 F右 = 3mg

    3. **静摩擦力判断**：
       - A、B之间的静摩擦力 f_AB：取决于A的水平受力平衡
       - B与实验台之间的静摩擦力 f_B台：取决于整体（A+B）的水平受力平衡

    **讲解思路：**

    1. 首先展示初始状态的完整受力图，标注所有力和钩码数量
    2. 然后展示变化后的状态，对比力的变化
    3. 引导学生分别对A和整体（A+B）进行受力分析，判断静摩擦力的变化
    4. 关键结论：
       - 对A：f_AB = F左，5号钩码移除后 F左 减小，故 f_AB 减小
       - 对整体（A+B）：f_B台 = F右 - F左，F右不变、F左减小，故 f_B台 增大

    **图示规划：**

    - SCENE_1：初始状态受力分析图（整合A、B叠放系统，标注所有力）
    - SCENE_2：变化后状态受力分析图（5号钩码移到A上，对比力的变化）

    **教学说明：初始状态受力分析**

    本图示展示叠放木块系统的初始平衡状态，教师应引导学生按以下步骤观察和思考：

    1. **识别系统组成**：木块A叠放在B上，B放在实验台上；两侧通过滑轮和轻线连接钩码

    2. **分析左侧拉力**：
       - 左侧钩码为4、5号，共2个
       - 轻线对A的拉力 T_A = 2mg，方向向左

    3. **分析右侧拉力**：
       - 右侧钩码为1、2、3号，共3个
       - 轻线对B的拉力 T_B = 3mg，方向向右

    4. **分析A、B之间的静摩擦力 f_AB**：
       - A静止，水平方向受力平衡
       - A受到向左的拉力 T_A，必须有向右的静摩擦力 f_AB 平衡
       - 故 f_AB = T_A = 2mg，方向向右

    5. **分析B与实验台之间的静摩擦力 f_B台**：
       - 对整体（A+B）分析，水平方向受力平衡
       - 整体受到向左的 T_A 和向右的 T_B
       - 合力为 T_B - T_A = 3mg - 2mg = mg，方向向右
       - 必须有向左的静摩擦力 f_B台 平衡
       - 故 f_B台 = T_B - T_A = mg，方向向左

    **关键公式：**

    对木块A（水平方向）：
    f_AB = T_A = 2mg

    对整体（A+B）（水平方向）：
    f_B台 = T_B - T_A = 3mg - 2mg = mg

    **讲解要点：**

    - 强调静摩擦力的方向判断：静摩擦力总是阻碍相对运动趋势
    - A有向左运动趋势（被T_A拉），故B对A的静摩擦力向右
    - 整体有向右运动趋势（T_B > T_A），故实验台对B的静摩擦力向左
    - 静摩擦力的大小由平衡条件决定，不是固定值

    **教学说明：变化后受力分析及结论**

    本图示展示5号钩码移至A上后的系统状态，教师应引导学生对比初始状态，理解静摩擦力的变化：

    1. **识别变化**：
       - 5号钩码从左侧移除，放在木块A上
       - 左侧钩码从2个变为1个，拉力减小
       - A的重力增加（多了5号钩码），但不影响水平受力分析

    2. **分析新的左侧拉力 T_A'**：
       - 左侧仅剩4号钩码，共1个
       - 轻线对A的新拉力 T_A' = mg，方向向左
       - 对比初始状态：T_A' < T_A（从2mg减为mg）

    3. **分析右侧拉力 T_B**：
       - 右侧钩码仍为1、2、3号，共3个
       - 轻线对B的拉力 T_B = 3mg，方向向右（不变）

    4. **分析新的A、B间静摩擦力 f_AB'**：
       - A仍静止，水平方向受力平衡
       - A受到向左的新拉力 T_A'，必须有向右的静摩擦力 f_AB' 平衡
       - 故 f_AB' = T_A' = mg
       - 对比初始状态：f_AB' < f_AB（从2mg减为mg），**减小**

    5. **分析新的B与实验台间静摩擦力 f_B台'**：
       - 对整体（A+B）分析，水平方向受力平衡
       - 整体受到向左的 T_A' 和向右的 T_B
       - 合力为 T_B - T_A' = 3mg - mg = 2mg，方向向右
       - 必须有向左的静摩擦力 f_B台' 平衡
       - 故 f_B台' = T_B - T_A' = 2mg
       - 对比初始状态：f_B台' > f_B台（从mg增为2mg），**增大**

    **关键公式：**

    对木块A（水平方向）：
    f_AB' = T_A' = mg

    对整体（A+B）（水平方向）：
    f_B台' = T_B - T_A' = 3mg - mg = 2mg

    **变化对比表：**

    | 力 | 初始状态 | 变化后 | 变化 |
    |---|---|---|---|
    | T_A（左拉A） | 2mg | mg | 减小 |
    | T_B（右拉B） | 3mg | 3mg | 不变 |
    | f_AB（A、B间） | 2mg | mg | 减小 |
    | f_B台（B、台间） | mg | 2mg | 增大 |

    **结论：**

    - 选项A错误：实验台与木块B之间的静摩擦力**增大**，不是减小
    - 选项B正确：实验台与木块B之间的静摩擦力**增大**
    - 选项C错误：实验台与木块B之间的静摩擦力**变化**了
    - 选项D正确：木块A、B之间的静摩擦力**减小**

    本题为单选题，正确答案为 **B**（若为多选题则B、D均正确）

    **课堂讲解建议：**

    1. 先用SCENE_1建立初始状态的受力分析框架
    2. 再用SCENE_2展示变化，引导学生对比两个状态的力
    3. 强调"整体法"和"隔离法"的运用：
       - 分析A、B间摩擦力：隔离A分析
       - 分析B与台间摩擦力：整体（A+B）分析
    4. 提醒学生注意：静摩擦力的大小由平衡条件决定，不是由正压力决定（不同于滑动摩擦力）
    5. 最后总结变化规律：左侧拉力减小 → A、B间摩擦力减小 → 整体向右的净拉力增大 → B与台间摩擦力增大
