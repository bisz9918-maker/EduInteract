[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：位置 (280,460)，作用：返回上一步骤，隐藏当前步骤新增元素
  - "下一步 ▶"按钮：位置 (520,460)，作用：进入下一步骤，显示该步骤新增元素
  - 步骤指示器：位置 (380,460)，显示当前步骤"步骤 k/4"
- 教师操作流程：
  1. 初始展示系统结构，让学生观察 5 号钩码位置变化
  2. 点击"下一步"展示左侧拉力变化，引导学生比较 T_A 与 T_A'
  3. 点击"下一步"展示右侧拉力 T_B 不变
  4. 点击"下一步"展示 A、B 间静摩擦力变化，分析 f_AB 为何减小
  5. 点击"下一步"展示 B 与实验台间静摩擦力变化，分析 f_B台 为何增大
  6. 最后总结结论，对应选择题答案

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（矩形、圆形、直线、箭头），无需复杂图表库；原生 SVG 便于精确控制坐标和样式；动画通过 CSS transition 和 JS 状态机实现
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │                        图示区 800×500                          │
  │                                                                │
  │         5 号钩码                                               │
  │           [5]                                                  │
  │            │                                                   │
  │      ┌──────────┐                                             │
  │      │    A     │                                             │
  │      └──────────┘                                             │
  │         │  │                                                   │
  │  ┌────────────────────┐                                       │
  │  │         B          │                                       │
  │  └────────────────────┘                                       │
  │  ═══════════════════════════════════════════════════════════   │
  │  实验台（带斜线阴影）                                          │
  │                                                                │
  │  ○ ←T_A'          ○ →T_B                                      │
  │  │                 │                                          │
  │ [4]              [1][2][3]                                     │
  │                                                                │
  │  ┌────────────────────────────────────────────────────────┐   │
  │  │      ◀ 上一步        步骤 k/4        下一步 ▶           │   │
  │  └────────────────────────────────────────────────────────┘   │
  └────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep 记录当前步骤（0-4），每一步对应一个元素显示配置对象
  2. 坐标计算：所有元素坐标按布局坐标表精确实现，使用 SVG 的 x、y、width、height 属性
  3. 动画曲线：元素出现使用 opacity 从 0 到 1 的 transition（duration: 300ms）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateScene() 刷新显示
  5. ID 命名规范：所有元素 ID 以"scene2-"为前缀，如 scene2-rect-A、scene2-arrow-TA、scene2-btn-next
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染
  7. 箭头绘制：使用 SVG 的 polyline 或 path 元素，箭头头部用 polygon 实现
  8. 虚线样式：stroke-dasharray="5,5"实现虚线效果
  9. 对比显示：初始状态虚线箭头始终显示（opacity: 0.5），变化后实线箭头显示（opacity: 1）
