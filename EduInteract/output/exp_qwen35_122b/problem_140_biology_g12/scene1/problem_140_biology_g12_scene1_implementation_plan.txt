[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮（scene1-btn-prev）：位于控件栏左侧，点击返回上一步状态
  - 下一步按钮（scene1-btn-next）：位于控件栏右侧，点击进入下一步状态
  - 步骤指示（scene1-step-indicator）：位于控件栏中央，显示当前步骤"步骤 X/4"
- 控件位置：SVG内底部，y=450~490区域，水平居中
- 教师操作流程：
  1. 初始展示所有染色体，让学生整体观察果蝇染色体组型
  2. 点击"下一步"高亮性染色体，讲解伴性遗传（E基因在X染色体上）
  3. 继续点击"下一步"依次高亮各对常染色体，讲解等位基因位置
  4. 最后展示点状染色体，完成全部染色体讲解
  5. 可随时点击"上一步"回退复习重点内容

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：染色体为简单几何形状，无需复杂图表库；原生实现轻量、易维护
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    雄果蝇M的染色体组型                  │  y=20
  │                                                         │
  │         7    8                                          │  y=100
  │        (•)  (•)                                         │
  │                                                         │
  │    3              4              5              6       │  y=150-250
  │   ╱  ╲          ╱  ╲          ╱  ╲          ╱  ╲       │
  │  ╱ v  ╲        ╱ V  ╲        ╱  ╲        ╱ R  ╲       │
  │ ╱ B    ╲      ╱ b    ╲      ╱  ╲      ╱      ╲       │
  │                                                 r      │

  │             ┃              ╱                            │
  │             ┃ E          ╱                              │  y=320-400
  │             ┃          ╱                                │

  │                                                         │

  │         │ ◀上一步  步骤 0/4  下一步▶  │                │
  │         └─────────────────────────────┘                │
  └─────────────────────────────────────────────────────────┘
  ```

- 关键实现要点：
  1. 状态机设计：使用变量 currentStep（0-4）跟踪当前步骤
  2. 染色体高亮：通过修改 SVG path 的 fill 属性和 opacity 实现
  3. 基因高亮：通过修改 text 元素的 fill 颜色和 font-weight 实现
  4. 按钮事件：绑定 click 事件，更新 currentStep 后调用 renderStep() 重绘
  5. 边界检查：上一步在 step=0 时禁用，下一步在 step=4 时变为"重播"
  6. 同源连线：使用 SVG path 绘制虚线，高亮时改变 stroke 颜色

- ID 命名规范：
  - 染色体：scene1-chrom-1 ~ scene1-chrom-8
  - 基因标签：scene1-gene-E、scene1-gene-B、scene1-gene-b、scene1-gene-V、scene1-gene-v、scene1-gene-R、scene1-gene-r
  - 染色体编号：scene1-label-1 ~ scene1-label-8
  - 性染色体标识：scene1-sex-X、scene1-sex-Y
  - 同源连线：scene1-link-12、scene1-link-34、scene1-link-56、scene1-link-78
  - 按钮：scene1-btn-prev、scene1-btn-next
  - 步骤指示：scene1-step-indicator

- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染

- 核心代码结构：
  ```javascript
  (function() {
    const currentStep = { value: 0 };
    const totalSteps = 4;
    
    function renderStep(step) {
      // 重置所有高亮
      // 根据 step 高亮对应染色体和基因
      // 更新步骤指示
    }
    
    function prevStep() {
      if (currentStep.value > 0) {
        currentStep.value--;
        renderStep(currentStep.value);
      }
    }
    
    function nextStep() {
      if (currentStep.value < totalSteps) {
        currentStep.value++;
        renderStep(currentStep.value);
      }
    }
    
    // 绑定事件
    document.getElementById('scene1-btn-prev').addEventListener('click', prevStep);
    document.getElementById('scene1-btn-next').addEventListener('click', nextStep);
    
    // 初始渲染
    renderStep(0);
  })();
  ```
