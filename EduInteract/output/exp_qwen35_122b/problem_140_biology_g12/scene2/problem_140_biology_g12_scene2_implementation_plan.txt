[分步序列]
本场景采用多状态切换交互（2个状态按钮），而非分步导航：

- 初始状态（加载后）：
  - 显示左侧雄果蝇M的初始性染色体（X^E和Y）
  - 显示右侧受精区（白眼雌果蝇配子X^e和XXY子代）
  - 中间区域显示两个状态按钮，等待教师选择

- 状态1（点击"正常分裂"按钮）：
  - 中间上部显示正常减数分裂过程
  - 减I后期：X^E移向左极，Y移向右极（蓝色高亮）
  - 形成两种正常配子：X^E和Y
  - 右侧受精区显示：正常配子无法形成XXY个体（灰色显示，说明正常情况不会产生题目中的子代）

- 状态2（点击"异常分裂"按钮）：
  - 中间下部显示异常减数分裂过程
  - 减I后期：X^E和Y移向同一极（红色高亮警示）
  - 形成异常配子：X^E Y和不含性染色体的配子
  - 右侧受精区高亮显示：异常配子X^E Y与X^e结合，形成X^E X^e Y（XXY个体）
  - 用绿色连线标注受精过程

[交互方案]
- 交互类型：多状态切换 — 2个状态按钮（正常分裂/异常分裂）
- 控件说明：
  - 按钮1："正常分裂"，位置(320, 450)，尺寸100×30px，作用：切换到正常减数分裂状态
  - 按钮2："异常分裂"，位置(440, 450)，尺寸100×30px，作用：切换到异常减数分裂状态
- 教师操作流程：
  1. 初始展示雄果蝇M的性染色体组成（X^E和Y）
  2. 点击"正常分裂"按钮，讲解正常减数分裂过程：X^E和Y正常分离，形成两种配子
  3. 说明正常配子与白眼雌果蝇配子结合无法产生XXY个体
  4. 点击"异常分裂"按钮，讲解异常减数分裂过程：减I后期X^E和Y未分离，形成X^E Y异常配子
  5. 展示异常配子X^E Y与X^e结合形成X^E X^e Y（XXY个体）
  6. 引导学生理解题目第（3）问的答案：亲代雄果蝇在减数第一次分裂时X和Y染色体未分离

- 关键实现要点：
  1. 状态机设计：使用变量 `currentState` 跟踪当前状态（0=初始，1=正常分裂，2=异常分裂）
  2. 坐标计算：所有元素使用绝对定位，通过 `setAttribute` 动态更新位置
  3. 状态切换：点击按钮时，先隐藏所有状态相关元素，再显示目标状态元素
  4. 高亮效果：使用 CSS class 切换颜色（正常=#1565c0，异常=#c62828，子代=#2e7d32）
  5. 事件绑定：按钮点击事件使用 `addEventListener`，避免内联事件
  6. 初始状态：加载时显示左侧染色体和右侧受精区，中间区域等待选择

- ID 命名规范：
  - 所有交互元素 ID 以 `scene2-` 为前缀
  - 示例：`scene2-chrom-xe-init`、`scene2-chrom-y-init`、`scene2-cell-normal`、`scene2-cell-abnormal`、`scene2-gamete-xe`、`scene2-gamete-y`、`scene2-gamete-xey`、`scene2-offspring`、`scene2-btn-normal`、`scene2-btn-abnormal`
