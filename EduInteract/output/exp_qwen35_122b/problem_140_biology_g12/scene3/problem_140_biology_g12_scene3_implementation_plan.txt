[图示主题与整合说明]
- 本图示主题：配子致死导致的异常分离比分析（果蝇遗传学）
- 整合内容：亲本基因型确定 → F1 代基因型 → F1 配子类型 → 配子致死假设 → F2 异常分离比验证
- 教学价值：教师可逐步引导学生从亲本杂交推导到 F2 异常比例，通过棋盘格直观展示配子致死如何导致 7:3:1:1 的分离比，帮助学生理解配子致死机制

[分步序列]
- 步骤 0（初始状态）：显示标题、亲本杂交（VVRR × vvrr）、杂交箭头，等待教师点击"下一步"
- 步骤 1：显示 F1 代基因型 VvRr 和表现型"长翅细眼"，F1 自交箭头出现
- 步骤 2：显示 F2 棋盘格框架（4×4 格子），显示配子类型标签（VR、Vr、vR、vr），vr 配子标注"（致死）"红色
- 步骤 3：棋盘格中显示正常配子组合的基因型（除 vr 参与的组合外），正常基因型蓝色 #1565c0
- 步骤 4：棋盘格中 vr 行和 vr 列的格子显示红色叉号，标注"致死"，显示统计区"长翅细眼:7、长翅粗眼:3、残翅细眼:1、残翅粗眼:1"
- 步骤 5（结论）：高亮显示致死配子 vr 的位置（红色边框），在棋盘格下方显示结论文字"假设：基因型为 vr 的配子致死，导致 F2 比例为 7:3:1:1"

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀上一步"按钮：scene3-btn-prev | 位置 (300,450) | 回退到上一步骤
  - "下一步▶"按钮：scene3-btn-next | 位置 (500,450) | 进入下一步骤
  - 步骤指示器：scene3-step-indicator | 位置 (380,450) | 显示"步骤 X/5"
- 教师操作流程：
  1. 从步骤 0 开始，展示亲本杂交，讲解亲本基因型确定
  2. 点击"下一步"到步骤 1，展示 F1 代，讲解 F1 基因型和表现型
  3. 点击"下一步"到步骤 2，展示棋盘格框架和配子类型，讲解 F1 配子产生
  4. 点击"下一步"到步骤 3，展示正常配子组合，讲解正常 9:3:3:1 预期
  5. 点击"下一步"到步骤 4，展示致死标记和实际统计，引导学生发现异常
  6. 点击"下一步"到步骤 5，展示结论，验证配子致死假设

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何和文本，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────┐
  │                    配子致死导致的异常分离比分析          │  y=20
  │                                                         │
  │  P: VVRR ───→ vvrr           F1: VvRr (长翅细眼)        │  y=50-170
  │                    ───→ F2 代（实际比例）                │
  │                                                         │
  │         配子\  VR    Vr    vR    vr(致死)               │  y=220
  │         ┌────┬────┬────┬────┐                          │
  │      VR  │    │    │    │    │                          │  y=240-280
  │         ├────┼────┼────┼────┤                          │
  │      Vr  │    │    │    │    │                          │  y=285-325
  │         ├────┼────┼────┼────┤                          │
  │      vR  │    │    │    │    │                          │  y=330-370
  │         ├────┼────┼────┼────┤                          │
  │      vr  │    │    │    │×   │                          │  y=375-415
  │         └────┴────┴────┴────┘                          │
  │                                                         │

  │                                                         │
  │  [◀上一步]  步骤 X/5  [下一步▶]                          │  y=450
  └─────────────────────────────────────────────────────────┘

- 关键实现要点：
  1. 状态机设计：用变量 currentStep 记录当前步骤（0-5），每个步骤对应一个显示函数
  2. 坐标计算：棋盘格格子坐标 = (240 + 列索引×100, 240 + 行索引×45)
  3. 动画曲线：元素出现用 opacity 从 0 到 1 的过渡动画（0.3s ease）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后重绘
  5. ID 命名规范：所有元素 ID 以 scene3- 为前缀（如 scene3-grid-cell-1-1、scene3-btn-next）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 致死标记：用 SVG path 绘制叉号，覆盖在对应格子上方
  8. 颜色应用：正常基因型用 #1565c0，致死相关用 #c62828，表现型用 #2e7d32
