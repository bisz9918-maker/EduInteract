[图示主题与整合说明]
- 本图示主题：六种幼苗类型的遗传组成对比（陆地棉抗黄萎病基因S整合类型）
- 整合内容：整合了题目图示中a-f六种类型的完整展示，包括染色体状态（是否整合基因S）和线粒体状态（是否整合基因S）的对比识别

[分步序列]
- 步骤0（初始状态）：显示6个细胞轮廓、全部染色体、全部线粒体、全部类型标签、完整图例说明。不显示任何高亮框。教师可先讲解图例含义。
- 步骤1：显示细胞a的高亮绿色外框，步骤指示器显示"步骤 1/7"。教师讲解类型a特征：2条染色体均整合S基因（蓝色带箭头），线粒体整合S基因（红色实心）。
- 步骤2：高亮框移至细胞b，显示"步骤 2/7"。讲解类型b：1条染色体整合S基因，1条未整合，线粒体整合S基因。
- 步骤3：高亮框移至细胞c，显示"步骤 3/7"。讲解类型c：2条染色体均未整合S基因，线粒体整合S基因。
- 步骤4：高亮框移至细胞d，显示"步骤 4/7"。讲解类型d：2条染色体均整合S基因，线粒体未整合S基因。
- 步骤5：高亮框移至细胞e，显示"步骤 5/7"。讲解类型e：1条染色体整合S基因，1条未整合，线粒体未整合S基因。
- 步骤6：高亮框移至细胞f，显示"步骤 6/7"。讲解类型f：2条染色体均未整合S基因，线粒体未整合S基因。
- 步骤7（最终步骤）：同时显示全部6个细胞的高亮框（或全部高亮框消失，用不同方式强调对比），步骤指示器显示"步骤 7/7 总结对比"。教师引导学生对比6种类型的核基因与线粒体基因整合情况，回答问题（1）符合长期种植要求的是类型d（核基因整合、线粒体未整合，避免线粒体基因抗性逐代减弱的问题）。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 按钮"上一步"：位置(280,450)，点击后步骤减1（步骤0时禁用）
  - 按钮"下一步"：位置(440,450)，点击后步骤加1（步骤7时禁用）
  - 步骤指示器：位置(360,410)，显示当前步骤"步骤 X/7"
- 教师操作流程：
  1. 初始展示图例，讲解符号含义
  2. 点击"下一步"依次高亮a-f，每步讲解该类型的染色体和线粒体整合状态
  3. 最后一步总结对比，引导学生识别符合长期种植要求的类型（类型d）
  4. 可随时点击"上一步"回退复习特定类型

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │                        800px                                │
  │  ┌───────────────────────────────────────────────────────┐  │
  │  │                                                       │  │
  │  │    ○    ○    ○    ○    ○    ○    ← 6个细胞(y=180)    │  │
  │  │    a    b    c    d    e    f    ← 类型标签(y=245)   │  │
  │  │                                                       │  │
  │  │  图例说明区域 (y=285-370)                            │  │
  │  │                                                       │  │
  │  │        步骤指示器 (y=410)                            │  │
  │  │      [上一步]  [下一步]  ← 控件按钮(y=450)           │  │
  │  └───────────────────────────────────────────────────────┘  │
  │                        500px                                │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：currentStep变量(0-7)，updateScene()函数根据currentStep显示/隐藏高亮框
  2. 坐标计算：所有元素使用固定像素坐标，按布局表精确实现
  3. 动画曲线：高亮框显示使用opacity过渡(0.3s ease)
  4. 事件绑定：按钮click事件监听，步骤0禁用上一步，步骤7禁用下一步
  5. ID命名规范：所有元素ID以"scene1-"为前缀（如scene1-cell-a、scene1-highlight-a、scene1-btn-prev等）
  6. IIFE隔离：所有JS代码包裹在(function() { ... })()中，避免全局污染
  7. 染色体箭头绘制：使用SVG marker或path绘制带箭头的竖线
  8. 高亮框显示逻辑：仅当前步骤对应的细胞显示绿色外框，步骤7可全部显示或全部隐藏
