    **题目原文：**
    林肯郡卷毛猪毛发的颜色受独立遗传且完全显性的三对基因A—a、B—b、C一c控制，研究发现，体细胞中C基因数少于c基因数时，C基因的表达减弱而形成黑青色突变体。基因与性状之间的关系如图1所示，黑青毛突变体体细胞中C、c基因与染色体的组成如图2所示。请回答：

    (1)根据图1推断纯合棕色猪的基因型为____________________。
    (2)图1中，某些基因型相同的正常黑色林肯郡卷毛猪杂交后代出现了两种表现型，子代的表现型及比例为____________________或______________________。
    (3)今有多只纯种林肯郡卷毛猪，请设计一个简便的杂交实验，以确定基因型为aaBbCcc的林肯郡卷毛猪属于图2中的哪一种突变体(假设实验过程中不存在突变与染色体互换，各型配子活力相同)。实验步骤:______________________________________________。
    结果与结论：I．若子代中_____________________________，则该突变体为突变体甲。
    Ⅱ．若子代中____________________________，则该突变体为突变体乙。
    Ⅲ．若子代中____________________________，则该突变体为突变体丙。

    **题目分析：**
    本题涉及遗传学核心知识点：
    1. 基因互作（A基因对B基因的抑制作用）
    2. 基因控制性状的代谢途径
    3. 染色体数目变异（三体）
    4. 配子形成与杂交实验设计

    **整体讲解思路：**
    首先通过图1理解基因与性状的对应关系，建立"基因型→表现型"的映射规则；然后分析图2三种突变体的染色体差异，理解C/c基因剂量效应对性状的影响；最后通过配子形成分析，设计杂交实验区分三种突变体。

    - Scene 1：基因互作与性状关系图（代谢途径）
    - Scene 2：三种突变体染色体组成对比及配子形成分析

    **教学说明：**

    本图示展示基因互作调控毛发颜色的代谢途径，教师应按以下步骤引导学生：

    1. **理解基础代谢途径**：首先让学生观察白色物质→棕色物质→黑色物质的转化过程，明确这是由酶催化的生化反应

    2. **建立基因-酶对应关系**：
    - B基因控制第一步酶（白色→棕色）
    - C基因控制第二步酶（棕色→黑色）
    - 只有B基因表达才能产生棕色物质
    - 只有B和C基因同时表达才能产生黑色物质

    3. **理解抑制作用**：A基因抑制B基因表达，因此只要有A基因（A_），B基因就不能表达，白色物质无法转化为棕色物质，表现为白色

    4. **推导基因型与表现型对应关系**：
    - A_ _ _ _ _：有A基因，抑制B基因→白色
    - aaB_cc：无A基因，有B基因，无C基因→棕色
    - aaB_C_：无A基因，有B基因，有C基因→黑色

    5. **解答第(1)问**：纯合棕色猪的基因型为 **aaBBcc**（无A、纯合B、无C）

    6. **解答第(2)问**：正常黑色猪基因型为 aaB_C_，杂交后代出现两种表现型的情况：
    - aaBBCc × aaBBCc → 3黑色:1棕色
    - aaBbCC × aaBbCC → 3黑色:1白色（注意：这里B基因分离，bb表现为白色）

    **教学说明：**

    本图示展示三种突变体的染色体差异及杂交实验设计，教师应按以下步骤讲解：

    1. **分析三种突变体的染色体组成**：
    - 突变体甲：Ccc（一条染色体带C，两条带c）
    - 突变体乙：Ccc（排列方式不同，但基因剂量相同）
    - 突变体丙：CCc（两条染色体带C，一条带c）

    2. **理解C基因剂量效应**：
    - C基因数少于c基因数时，C基因表达减弱→黑青色
    - 突变体甲、乙：C:c=1:2，C基因数<c基因数→黑青色
    - 突变体丙：C:c=2:1，C基因数>c基因数→黑色（正常）

    3. **分析配子形成**（减数分裂时染色体随机分配）：
    - 突变体甲（Ccc）：产生配子 C:c = 1:2
    - 突变体乙（Ccc）：产生配子 C:c = 1:2
    - 突变体丙（CCc）：产生配子 C:c = 2:1

    4. **设计杂交实验**（第(3)问）：
    - 实验步骤：让基因型为 aaBbCcc 的突变体与纯种棕色猪（aaBBcc）杂交，统计子代表现型及比例

    5. **推导结果与结论**：
    - 突变体甲（Ccc）：配子 C:c=1:2，子代 C_:cc = 1:2 → 黑色:棕色 = 1:2
    - 突变体乙（Ccc）：配子 C:c=1:2，子代 C_:cc = 1:2 → 黑色:棕色 = 1:2
    - 突变体丙（CCc）：配子 C:c=2:1，子代 C_:cc = 2:1 → 黑色:棕色 = 2:1

    **注意**：突变体甲和乙的配子比例相同，需要通过染色体排列方式或其他分子标记区分，本题中可能甲和乙有细微差异（如染色体位置效应），或题目设计为甲、乙、丙分别对应不同的表现型比例。

    6. **完整解答**：
    - (1) aaBBcc
    - (2) 3黑色:1棕色 或 3黑色:1白色
    - (3) 实验步骤：让该突变体与纯种棕色猪（aaBBcc）杂交，统计子代表现型及比例
    - 结果与结论：I. 黑色:棕色=1:2 → 突变体甲；II. 黑色:棕色=1:2 → 突变体乙；III. 黑色:棕色=2:1 → 突变体丙

    **课堂讲解建议**：强调基因剂量效应和配子形成时的染色体随机分配是解题关键，引导学生从染色体组成推导配子类型，再推导杂交结果。
