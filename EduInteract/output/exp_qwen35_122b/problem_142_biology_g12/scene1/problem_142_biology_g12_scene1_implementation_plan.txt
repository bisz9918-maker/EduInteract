[分步序列]
- 步骤0（初始状态）：显示三个代谢物框（白色→棕色→黑色）和两个代谢箭头，显示"酶"标注。所有基因标签和抑制关系隐藏。对照表隐藏。
- 步骤1：显示B基因标签（位于箭头1上方），用蓝色高亮。其他元素保持步骤0状态。
- 步骤2：显示C基因标签（位于箭头2上方），用蓝色高亮。B基因标签保持显示。
- 步骤3：显示A基因标签和抑制虚线箭头（从A指向B基因位置），用红色高亮。B、C基因标签保持显示。
- 步骤4（最终状态）：显示基因型-表现型对照表（绿色边框），所有基因标签和抑制关系保持显示。完整展示"基因型→表现型"映射关系。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "上一步"按钮：位于(260,455)-(350,480)，点击返回前一个步骤
  - "下一步"按钮：位于(460,455)-(550,480)，点击进入下一个步骤
  - 步骤0时"上一步"按钮置灰不可点击
  - 步骤4时"下一步"按钮置灰不可点击
- 教师操作流程：
  1. 初始展示基础代谢途径（白色→棕色→黑色物质转化）
  2. 点击"下一步"，揭示B基因控制第一步酶
  3. 点击"下一步"，揭示C基因控制第二步酶
  4. 点击"下一步"，揭示A基因对B基因的抑制作用
  5. 点击"下一步"，展示完整基因型-表现型对照表
  6. 可随时点击"上一步"回退复习某个调控层次

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何和动画，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────┐
  │  A基因  ──抑制──→ B基因                                 │
  │   (80,140)        (285,165)                             │
  │       \              ↑                                  │
  │        \             | 酶                               │
  │         \            |                                  │
  │  [白色] ─────→ [棕色] ─────→ [黑色]                     │
  │  (120,180)  (350,180)  (580,180)                        │
  │                    ↑  酶                                │
  │                    |                                    │
  │                   C基因                                 │
  │                  (515,165)                              │
  │                                                         │
  │  ┌─────────────────────────────────────────────────┐   │
  │  │  基因型 → 表现型对照表                          │   │
  │  │  aaB_cc → 棕色    aaB_C_ → 黑色                 │   │
  │  │  A_ _ _ _ _ = 白色                              │   │
  │  └─────────────────────────────────────────────────┘   │
  │                                                         │
  │  [◀上一步]                    [下一步▶]                 │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：currentStep变量(0-4)，控制各元素的display属性
  2. 元素ID命名：所有元素ID以"scene1-"为前缀（如scene1-box-white、scene1-label-B等）
  3. 使用classList.toggle控制元素显示/隐藏
  4. 按钮点击事件绑定到scene1-prev-btn和scene1-next-btn
  5. 步骤0时禁用上一步按钮，步骤4时禁用下一步按钮
  6. IIFE隔离：所有JS代码包裹在(function() { ... })()中
  7. 使用SVG的<line>、<rect>、<text>、<polygon>元素绘制图形
  8. 抑制关系用stroke-dasharray实现虚线效果
