[分步序列]
- 步骤0（初始状态）：
  - 显示标题"三种突变体染色体组成对比"
  - 显示三个突变体框（甲、乙、丙）及其染色体组成
  - 突变体甲：C基因（蓝点）在左侧染色体，c基因（红点）在中间和右侧染色体
  - 突变体乙：C基因（蓝点）在左侧染色体，c基因（红点）在中间和右侧染色体（排列不同）
  - 突变体丙：C基因（蓝点）在左侧和中间染色体，c基因（红点）在右侧染色体
  - 显示配子区标题和四个配子框（空白）
  - 显示杂交结果表标题和表格框架（空白）
  - 无高亮框

- 步骤1：
  - 突变体甲框添加绿色高亮边框（#2e7d32 4px）
  - 在配子区显示突变体甲的配子分析：
    - 配子框1：显示"C"（蓝点）+ "c"（红点）→ 配子类型 Cc
    - 配子框2：显示"c"（红点）→ 配子类型 c
    - 配子框3：显示"c"（红点）→ 配子类型 c
    - 配子框4：显示"C"（蓝点）→ 配子类型 C
  - 配子框下方标注比例：Cc : c : c : C = 1 : 1 : 1 : 1 → 简化为 C : c = 1 : 2
  - 杂交表第一行填充：突变体甲 | C:c=1:2 | 黑色:黑青=1:2

- 步骤2：
  - 移除突变体甲高亮，突变体乙框添加绿色高亮边框
  - 在配子区显示突变体乙的配子分析：
    - 配子框1：显示"C"（蓝点）→ 配子类型 C
    - 配子框2：显示"c"（红点）→ 配子类型 c
    - 配子框3：显示"C"（蓝点）+ "c"（红点）→ 配子类型 Cc
    - 配子框4：显示"c"（红点）→ 配子类型 c
  - 配子框下方标注比例：C : c : Cc : c = 1 : 1 : 1 : 1 → 简化为 C : c = 1 : 2
  - 杂交表第二行填充：突变体乙 | C:c=1:2 | 黑色:黑青=1:2

- 步骤3：
  - 移除突变体乙高亮，突变体丙框添加绿色高亮边框
  - 在配子区显示突变体丙的配子分析：
    - 配子框1：显示"C"（蓝点）+ "c"（红点）→ 配子类型 Cc
    - 配子框2：显示"C"（蓝点）→ 配子类型 C
    - 配子框3：显示"C"（蓝点）+ "c"（红点）→ 配子类型 Cc
    - 配子框4：显示"C"（蓝点）→ 配子类型 C
  - 配子框下方标注比例：Cc : C : Cc : C = 1 : 1 : 1 : 1 → 简化为 C : c = 2 : 1
  - 杂交表第三行填充：突变体丙 | C:c=2:1 | 黑色:黑青=2:1

- 步骤4（最终步骤）：
  - 移除所有突变体框高亮
  - 三个突变体框同时显示（无高亮）
  - 配子区显示三种突变体的配子比例对比：
    - 甲：C:c = 1:2
    - 乙：C:c = 1:2
    - 丙：C:c = 2:1
  - 杂交结果表完整显示三行数据，用不同背景色区分：
    - 突变体甲行：浅蓝背景 #e3f2fd
    - 突变体乙行：浅绿背景 #e8f5e9
    - 突变体丙行：浅黄背景 #fffde7
  - 表格下方添加结论提示："通过子代表现型比例可区分突变体类型"

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "上一步"按钮：位于(300,455)，点击返回上一状态，步骤0时禁用
  - "下一步"按钮：位于(420,455)，点击进入下一状态，步骤4时禁用
- 教师操作流程：
  1. 初始展示三种突变体染色体组成，让学生观察差异
  2. 点击"下一步"逐步展示每种突变体的配子形成过程
  3. 引导学生分析C基因与c基因的数量关系如何影响配子类型
  4. 最终展示杂交结果对比表，总结三种突变体的区分方法

- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-4) 跟踪当前步骤
  2. 坐标计算：所有元素使用绝对定位，基于布局坐标表
  3. 高亮边框：通过添加/移除 class "highlight" 实现绿色加粗边框
  4. 动态内容：使用 innerHTML 或 createElement 动态填充配子框和表格内容
  5. 按钮状态：步骤0时禁用"上一步"，步骤4时禁用"下一步"
  6. 动画曲线：使用 CSS transition 实现边框高亮的平滑过渡（0.3s ease）

- ID 命名规范：所有交互元素 ID 以 "scene2-" 为前缀
  - 突变体框：scene2-mutant-a, scene2-mutant-b, scene2-mutant-c
  - 染色体线：scene2-chrom-a1, scene2-chrom-a2, scene2-chrom-a3 等
  - 基因点：scene2-gene-a-C1, scene2-gene-a-c1, scene2-gene-a-c2 等
  - 配子框：scene2-gamete-1, scene2-gamete-2, scene2-gamete-3, scene2-gamete-4
  - 杂交表：scene2-hybrid-table
  - 按钮：scene2-btn-prev, scene2-btn-next

- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
