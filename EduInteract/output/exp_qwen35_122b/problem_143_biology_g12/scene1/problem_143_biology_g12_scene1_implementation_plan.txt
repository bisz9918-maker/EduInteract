[分步序列]

- 步骤 1：高亮生产者与初级消费者
  - 草节点边框加粗至 3px，填充透明度降至 10%
  - 羚羊、斑马、鼠节点边框加粗至 3px

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀上一步"按钮：位置 (280,455)，作用：返回上一状态
  - "下一步▶"按钮：位置 (500,455)，作用：进入下一状态
  - 步骤指示器：位置 (360,455)，显示"步骤 1/5"
- 教师操作流程：
  1. 初始展示完整食物网，让学生观察整体结构
  2. 点击"下一步"，逐步高亮各营养级，讲解能量从生产者到顶级消费者的流动
  3. 最后一步展示全部 5 条食物链，帮助学生理解食物网的复杂性
  4. 可随时点击"上一步"回退复习特定营养级

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：食物网为简单几何图形（椭圆、线段、文本），原生 SVG 足够且性能最佳
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
```
┌────────────────────────────────────────────────────────────────┐
│                        食物网图示区 800×500                      │
│                                                                 │
│   草      羚羊      野狗                    狮子                │
│  (○)────→(○)────→(○)──────────────────────→(○)                │
│   │        │       ↑                         ↑                 │
│   │        └───────┘                         │                 │
│   ↓                                          │                 │
│  斑马────→┘                                  │                 │
│  (○)─────────────────────────────────────────┘                 │
│   │                                                             │
│   ↓                                                             │
│   鼠────→蛇────→食蛇动物                                        │
│  (○)    (○)    (○)─────────────────────────────────────────────┘
│                                                                 │
│   [◀上一步]  步骤 1/5  [下一步▶]                              │
└────────────────────────────────────────────────────────────────┘
```
- 关键实现要点：
  1. 状态机设计：用 currentStep 变量记录当前步骤（0-4），每一步对应一个状态对象，存储需要高亮的节点和箭头 ID 列表
  2. 坐标计算：所有节点中心点预先计算，箭头起点为源节点右侧边缘，终点为目标节点左侧边缘
  3. 动画曲线：高亮效果使用 CSS transition，0.3s ease-in-out 过渡
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 renderStep() 重绘
  5. ID 命名规范：所有元素 ID 以 scene1- 为前缀，如 scene1-node-grass、scene1-arrow-1、scene1-btn-prev
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 箭头绘制：使用 SVG <line> + <marker> 定义箭头头部，marker 指向右侧
