[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀上一步"按钮：位于 (270,460)，点击后当前步骤减 1（步骤 0 时禁用）
  - "下一步▶"按钮：位于 (470,460)，点击后当前步骤加 1（步骤 3 时禁用）
- 教师操作流程：
  1. 初始展示亲本 P 代，提问学生"预测 F₁代表现型"
  2. 点击"下一步"展示 F₁代全部为圆眼，提问"哪个性状为显性？"
  3. 点击"下一步"说明 F₁雌雄交配过程
  4. 点击"下一步"展示 F₂代分离比，引导学生分析遗传规律
  5. 结合结论框，总结常染色体遗传的判断依据

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │  800px                                                      │
  │                                                             │
  │  P 层  [♀棒眼] × [♂圆眼]                                    │
  │          ↓                                                  │
  │  F₁层        [圆眼]                                         │
  │          ↓                                                  │
  │  F₂层  [♀圆][♀棒][♂圆][♂棒]  结论框                        │
  │          1  :  1  :  1  :  1                                │
  │                                                             │
  │  ┌─────────────────────────────────────────────────────┐   │
  │  │  [◀上一步]              [下一步▶]                   │   │
  │  └─────────────────────────────────────────────────────┘   │
  │                              500px                          │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-3) 跟踪当前步骤
  2. 元素显示控制：每个视觉元素添加 data-step 属性，表示该元素在哪些步骤显示
  3. 坐标计算：所有元素使用绝对坐标，通过 SVG transform 定位
  4. 箭头标记：定义 SVG <marker>元素，用于箭头末端
  5. 按钮禁用状态：步骤 0 时禁用"上一步"，步骤 3 时禁用"下一步"
  6. 透明度控制：使用 fill-opacity 属性控制椭圆填充透明度
  7. ID 命名规范：所有交互元素 ID 以 scene1- 为前缀（如 scene1-prev-btn、scene1-next-btn）
  8. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  9. 事件绑定：使用 addEventListener 绑定按钮点击事件，通过 getElementById 获取元素
