[分步序列]
本场景采用多状态切换交互（非分步导航），通过按钮切换观察两种遗传方式的差异：

- 初始状态（状态1 - 常染色体遗传激活）：
  - 左侧面板高亮显示（绿色边框加粗）
  - 右侧面板正常显示（红色边框）
  - 左侧按钮激活（绿色背景），右侧按钮非激活（灰色背景）
  - 左侧F₂区域显示橙色差异高亮框
  - 显示内容：P(♀棒眼×♂圆眼)→F₁(全圆眼)→F₂(♀圆:♀棒:♂圆:♂棒=1:1:1:1)

- 状态2（点击"X染色体遗传"按钮）：
  - 右侧面板高亮显示（红色边框加粗）
  - 左侧面板正常显示（绿色边框）
  - 右侧按钮激活（红色背景），左侧按钮非激活（灰色背景）
  - 右侧F₂区域显示橙色差异高亮框
  - 显示内容：P(♀棒眼×♂圆眼)→F₁(全圆眼)→F₂(♀圆:♀棒:♂圆:♂棒=1:1:1:1)

- 关键差异标注（静态显示，两面板对比）：
  - 左侧面板F₂：雌雄表现型比例相同（♀圆:♀棒=1:1，♂圆:♂棒=1:1）
  - 右侧面板F₂：雌雄表现型比例相同（♀圆:♀棒=1:1，♂圆:♂棒=1:1）
  - 注：根据题目图片，F₂实际比例为1:1:1:1，两种遗传方式在此情况下预期结果相同，需结合其他实验进一步判断

[交互方案]
- 交互类型：多状态切换（2个状态按钮）
- 控件说明：
  - 按钮1："常染色体遗传" | 位置(300,445)-(395,475) | 切换到常染色体遗传预期显示
  - 按钮2："X染色体遗传" | 位置(405,445)-(500,475) | 切换到X染色体遗传预期显示
- 教师操作流程：
  1. 初始显示常染色体遗传预期，教师讲解常染色体遗传的特点（雌雄表现型比例相同）
  2. 点击"X染色体遗传"按钮，切换显示X染色体遗传预期
  3. 对比两种情况下F₂的表现型分布，引导学生观察差异
  4. 结合题目图片中的实际实验结果，判断基因位置

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形和状态切换，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │                    基因位置判断对比分析                         │
  ├────────────────────────────┬───────────────────────────────────┤
  │   常染色体遗传             │      X染色体遗传                  │
  │   ┌──────────────────┐     │   ┌──────────────────────┐        │
  │   │ P  ♀棒眼×♂圆眼   │     │   │ P  ♀棒眼×♂圆眼       │        │
  │   │      ↓           │     │   │      ↓               │        │
  │   │ F₁  圆眼         │     │   │ F₁  圆眼             │        │
  │   │      ↓           │     │   │      ↓               │        │
  │   │ F₂ ♀圆♀棒♂圆♂棒 │     │   │ F₂ ♀圆♀棒♂圆♂棒     │        │
  │   │    1:1:1:1       │     │   │    1:1:1:1           │        │
  │   └──────────────────┘     │   └──────────────────────┘        │
  ├────────────────────────────┴───────────────────────────────────┤
  │        [常染色体遗传]        [X染色体遗传]                      │
  └────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 currentScene 记录当前激活的面板（1=常染色体，2=X染色体）
  2. 坐标计算：所有元素按布局坐标表精确绘制，使用 SVG 绝对定位
  3. 样式切换：通过切换 CSS class 实现按钮激活/非激活状态、面板边框高亮
  4. 事件绑定：为两个按钮添加 click 事件，切换状态并更新视觉样式
  5. ID 命名规范：所有交互元素 ID 以 scene2- 为前缀（如 scene2-autosome-btn、scene2-xchrom-btn、scene2-autosome-panel、scene2-xchrom-panel）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
