[图示主题与整合说明]
- 本图示主题：验证实验设计 - 证明果蝇眼型基因位于常染色体且圆眼为显性
- 整合内容：整合两种独立的验证杂交实验方案，每种方案都能独立证明基因位于常染色体且圆眼为显性
- 教学价值：教师可通过切换两种方案，向学生展示遗传学验证实验的多种设计思路，帮助学生理解测交验证和自交验证两种经典方法

[分步序列]
本场景采用多状态切换交互，非分步导航：

- 初始状态（状态0）：显示方案一（测交验证）
  - 方案一面板高亮显示
  - 方案二面板半透明显示
  - 展示测交验证的完整流程：F₂圆眼个体 × F₂棒眼个体 → 子代圆眼:棒眼=1:1
  
- 状态1：点击"方案二"按钮 → 显示方案二（自交验证）
  - 方案二面板高亮显示
  - 方案一面板半透明显示
  - 展示自交验证的完整流程：F₂圆眼雌雄个体自交 → 子代出现棒眼（性状分离）

[交互方案]
- 交互类型：多状态切换（2个状态按钮）
- 控件说明：
  - 按钮1："方案一：测交验证" | 位置(250,455) | 切换到测交验证方案
  - 按钮2："方案二：自交验证" | 位置(430,455) | 切换到自交验证方案
- 教师操作流程：
  1. 初始展示方案一（测交验证），讲解测交验证的设计思路
  2. 点击"方案二"按钮，切换到自交验证方案
  3. 讲解自交验证的设计思路，对比两种验证方法的异同
  4. 可反复切换，帮助学生理解两种独立验证方法都能证明同一结论

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何和状态切换，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │                    方案一：测交验证    方案二：自交验证      │
  │  ┌─────────────────────────┐  ┌─────────────────────────┐  │
  │  │   P: ♀棒眼 × ♂圆眼      │  │   P: ♀圆眼 × ♂圆眼      │  │
  │  │         ↓               │  │         ↓               │  │
  │  │        F₁: 圆眼         │  │        F₁: 圆眼         │  │
  │  │         ↓               │  │         ↓               │  │
  │  │   F₂: 圆眼 × 棒眼       │  │   F₂: 圆眼自交          │  │
  │  │         ↓               │  │         ↓               │  │
  │  │  结果: 圆眼:棒眼=1:1    │  │  结果: 出现棒眼(分离)   │  │
  │  └─────────────────────────┘  └─────────────────────────┘  │
  │  ┌───────────────────────────────────────────────────────┐  │
  │  │        [方案一：测交验证]      [方案二：自交验证]      │  │
  │  └───────────────────────────────────────────────────────┘  │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 currentScene 跟踪当前显示的状态（0=方案一，1=方案二）
  2. 坐标计算：所有元素按布局坐标表精确放置
  3. 动画曲线：状态切换时使用 opacity 过渡动画（0.3s ease）
  4. 事件绑定：按钮点击事件切换状态，更新元素可见性
  5. ID 命名规范：所有元素 ID 以 scene3- 为前缀（如 scene3-panel1, scene3-btn1）
  6. IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染

- 状态切换逻辑：
  ```javascript
  function switchScene(sceneIndex) {
    // 更新按钮状态
    // 切换面板透明度：当前状态面板 opacity=1，其他面板 opacity=0.4
    // 更新显示内容
  }
  ```

- 遗传图示元素：
  - 果蝇图标：circle + text（♀/♂符号）
  - 基因型标签：使用等宽字体显示（如 AA, Aa, aa）
  - 箭头：使用 SVG marker 定义箭头标记
  - 结果框：rect + text 组合，展示预期结果
