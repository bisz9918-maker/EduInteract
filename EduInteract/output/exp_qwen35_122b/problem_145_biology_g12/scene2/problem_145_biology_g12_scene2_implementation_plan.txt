[分步序列]
步骤 0（初始状态）：
- 显示：标题、父方体细胞框（含 XY 染色体）、母方体细胞框（含 XX 染色体）
- 标签："Ⅰ-1 父"、"Ⅰ-2 母"
- 隐藏：所有减数分裂区、配子、受精区、结论区、控件栏
- 目的：展示正常体细胞染色体组成，作为后续对比基础

步骤 1：
- 显示：父方减数分裂区、父方正常配子 X 和 Y
- 新增标签："父方减数分裂"、配子内"X"和"Y"
- 添加箭头：从父方体细胞指向父方减数分裂区
- 配子旁标注："正常：减数分裂正常分离"
- 隐藏：其他区域
- 目的：展示父方正常减数分裂产生 X 和 Y 两种配子

步骤 2：
- 显示：母方减数分裂区、母方正常配子 X
- 新增标签："母方减数分裂"、配子内"X"
- 添加箭头：从母方体细胞指向母方减数分裂区
- 配子旁标注："正常：只产生 X 配子"
- 目的：展示母方正常减数分裂只产生 X 配子

步骤 3：
- 显示：异常父方减数分裂区、异常父方配子 XY 和 O
- 新增标签："父方异常"、配子内"XY"和"O"
- 高亮：异常区域用红色填充 30%
- 配子旁标注："异常：减数分裂Ⅰ同源染色体未分离→XY 配子或无性染色体配子"
- 目的：展示父方异常减数分裂产生 XY 和 O 配子

步骤 4：
- 显示：异常母方减数分裂区、异常母方配子 XX 和 O
- 新增标签："母方异常"、配子内"XX"和"O"
- 高亮：异常区域用红色填充 30%
- 配子旁标注："异常：减数分裂Ⅰ或Ⅱ未分离→XX 配子或无性染色体配子"
- 目的：展示母方异常减数分裂产生 XX 和 O 配子

步骤 5：
- 显示：受精区、Ⅱ-5 形成过程
- 添加箭头：异常 O 配子（来自父方或母方）与正常 X 配子（来自另一方）结合
- 受精卵展示：XO 型，标注"Ⅱ-5：XO 型（Turner 综合征）"
- 目的：展示Ⅱ-5 性染色体异常的形成过程

步骤 6（最终步骤）：
- 显示：结论区、所有可能的异常配子结合结果
- 结论文字动态显示：
  - "若Ⅰ-1 产生 XY 配子 +Ⅰ-2 正常 X→XXY（Klinefelter 综合征）"
  - "若Ⅰ-2 产生 XX 配子 +Ⅰ-1 正常 Y→XXX"
  - "若双方均产生 O 配子→OO（致死）"
- 目的：总结所有可能的性染色体异常类型

- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量（0-6）跟踪当前步骤
  2. 元素显示控制：每个元素添加 data-step 属性，根据当前步骤显示/隐藏
  3. 坐标计算：所有元素使用绝对定位，坐标已在布局表中精确定义
  4. 动画曲线：使用 CSS transition 实现淡入淡出效果（opacity: 0→1）
  5. 事件绑定：按钮点击事件监听，更新 currentStep 并刷新显示
  6. ID 命名规范：所有交互元素 ID 以"scene2-"为前缀（如 scene2-prev-btn、scene2-next-btn）
  7. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  8. 配子内部文字居中：使用 text-anchor="middle"和 dominant-baseline="middle"

- 状态切换逻辑：
```javascript
(function() {
  const totalSteps = 7;
  let currentStep = 0;
  
  const stepElements = {
    0: ['scene2-title', 'scene2-father-cell', 'scene2-father-label', 'scene2-father-X', 'scene2-father-Y',
        'scene2-mother-cell', 'scene2-mother-label', 'scene2-mother-X1', 'scene2-mother-X2'],
    1: [...stepElements[0], 'scene2-father-meiosis', 'scene2-gamete-X', 'scene2-gamete-Y', ...],
    // ... 其他步骤元素列表
  };
  
  function updateDisplay() {
    // 隐藏所有步骤相关元素
    // 显示当前步骤元素
    // 更新步骤指示器
  }
  
  document.getElementById('scene2-prev-btn').addEventListener('click', function() {
    if (currentStep > 0) {
      currentStep--;
      updateDisplay();
    }
  });
  
  document.getElementById('scene2-next-btn').addEventListener('click', function() {
    if (currentStep < totalSteps - 1) {
      currentStep++;
      updateDisplay();
    }
  });
  
  // 初始化
  updateDisplay();
})();
```
