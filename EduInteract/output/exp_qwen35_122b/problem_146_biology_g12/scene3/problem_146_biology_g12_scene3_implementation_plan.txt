[图示主题与整合说明]
- 本图示主题：X^rX^rY 雌果蝇异常减数分裂与配子形成

- 控件说明：
  - 按钮"上一步"：ID scene3-prev，位置 (250,455)，作用：返回上一状态，步骤 0 时禁用
  - 按钮"下一步"：ID scene3-next，位置 (470,455)，作用：进入下一状态，步骤 5 时禁用
  - 步骤说明标签：ID scene3-step-label，位置 (400,60)，作用：显示当前步骤名称
- 教师操作流程：
  1. 初始展示 X^rX^rY 细胞，讲解三条性染色体的组成
  2. 点击"下一步"展示减数第一次分裂时 X 染色体联会现象
  3. 点击"下一步"展示第一种分离方式（X 与 XY 分离）
  4. 点击"上一步"复习，再点击"下一步"展示第二种分离方式（XX 与 Y 分离）
  5. 点击"下一步"展示四种配子类型，讲解正常与异常配子的区别
  6. 点击"下一步"展示杂交结果，推导红眼雌果蝇的基因型

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（几何图形简单，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │  步骤说明标签 (400,60)                                  │
  │                                                         │
  │         主细胞区域 (y=100~260)                          │
  │      ┌─────────────────────────────┐                   │
  │      │      X^r  X^r   Y           │                   │
  │      │       \   |   /             │  纺锤体           │
  │      │        \  |  /              │                   │
  │      │         \ | /               │                   │
  │      └─────────────────────────────┘                   │
  │                                                         │
  │         配子细胞区域 (y=300~380)                        │
  │   [X^r]  [X^rX^r]  [X^rY]  [Y]                         │
  │                                                         │
  │                    → [子代]                             │
  │                  X^R X^r / X^R X^rX^r                   │
  │                                                         │
  │  ┌─────────────────────────────────────────────────┐   │
  │  │          [上一步]              [下一步]          │   │
  │  └─────────────────────────────────────────────────┘   │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：currentStep 变量 (0-5)，updateScene() 函数根据 currentStep 显示/隐藏元素
  2. 坐标计算：所有元素使用绝对坐标，通过 SVG transform 实现移动动画
  3. 动画曲线：使用 CSS transition 实现平滑移动 (transition: all 0.5s ease)
  4. 事件绑定：按钮点击事件调用 changeStep(delta)，边界检查防止越界
  5. ID 命名规范：所有元素 ID 以 scene3- 为前缀（如 scene3-cell, scene3-chrom-x1, scene3-prev）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 染色体移动：使用 SVG <line> 和 <rect> 元素，通过 setAttribute('transform', 'translate(x,y)') 实现位置变化
  8. 配子细胞显示：步骤 4 前 display='none'，步骤 4 时 display='block'
  9. 杂交箭头和子代：步骤 5 时显示，之前 display='none'
  10. 按钮状态：步骤 0 时 scene3-prev disabled，步骤 5 时 scene3-next disabled
