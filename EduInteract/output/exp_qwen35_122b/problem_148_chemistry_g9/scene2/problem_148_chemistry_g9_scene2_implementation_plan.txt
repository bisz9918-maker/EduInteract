[分步序列]
本场景采用多状态切换交互，非分步导航：

初始状态（步骤0）：
- 显示化学方程式标题 "CH₄ + H₂O → CO + 3H₂"
- 显示四个选项按钮（A/B/C/D），均为默认浅灰色
- 分析内容区显示提示文字 "请点击选项按钮查看分析"
- 无判断结果显示

状态A（点击A按钮）：
- A按钮高亮为蓝色
- 分析内容区显示化合价变化表：
  | 元素 | 反应前 | 反应后 | 变化 |
  | C | -4 | +2 | → 变化 |
  | H | +1 | +1 | = 不变 |
  | O | -2 | -2 | = 不变 |
- 判断结果显示 "错误"（红色）
- 说明：C元素化合价从-4变为+2，发生变化

状态B（点击B按钮）：
- B按钮高亮为蓝色
- 分析内容区显示含氢物质列表：
  化合物（蓝色高亮）：CH₄、H₂O、CO（共3种含氢化合物？NO！CO不含氢）
  实际含氢化合物：CH₄、H₂O（共2种）
  单质（橙色高亮）：H₂
- 判断结果显示 "错误"（红色）
- 说明：含氢元素的化合物只有2种（CH₄、H₂O），不是3种

状态C（点击C按钮）：
- C按钮高亮为蓝色
- 分析内容区显示质量比计算：
  乙（H₂O）质量 = 18 × 1 = 18
  丁（H₂）质量 = 2 × 3 = 6
  质量比 乙:丁 = 18:6 = 3:1
- 判断结果显示 "正确"（绿色）
- 说明：计算正确，质量比为3:1

状态D（点击D按钮）：
- D按钮高亮为蓝色
- 分析内容区显示分子个数统计：
  丙（CO）：1个分子
  丁（H₂）：3个分子
  分子个数比 丙:丁 = 1:3
- 判断结果显示 "正确"（绿色）
- 说明：从图中可直接数出CO为1个，H₂为3个

[交互方案]
- 交互类型：多状态切换（4个选项按钮）
- 控件说明：
  - 按钮A：位置(80,80)，点击显示化合价分析
  - 按钮B：位置(240,80)，点击显示含氢化合物分析
  - 按钮C：位置(400,80)，点击显示质量比计算
  - 按钮D：位置(560,80)，点击显示分子个数比分析
- 教师操作流程：
  1. 初始显示化学方程式，引导学生观察反应物和生成物
  2. 点击A按钮，讲解化合价变化判断方法
  3. 点击B按钮，讲解化合物与单质的区分
  4. 点击C按钮，讲解质量比的计算方法
  5. 点击D按钮，讲解分子个数比的统计方法
  6. 可反复切换按钮，对比不同选项的分析逻辑

[技术实现]
- JS 库选择：原生 JavaScript + SVG
  - 原因：本场景主要是文本和简单几何图形（按钮、表格），无需复杂绘图库
  - SVG 便于精确控制坐标和样式
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────┐
  │                    CH₄ + H₂O → CO + 3H₂                 │  ← 标题 (y=30)
  │                                                         │
  │  ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐ │
  │  │    A     │  │    B     │  │    C     │  │    D     │ │  ← 选项按钮 (y=80)
  │  └──────────┘  └──────────┘  └──────────┘  └──────────┘ │
  │                                                         │
  │  ┌───────────────────────────────────────────────────┐  │
  │  │              分析内容区（动态切换）                │  │  ← 内容区 (y=160)
  │  │                                                   │  │
  │  │                                                   │  │
  │  │                                                   │  │
  │  │                  判断结果                         │  │  ← 结果 (y=410)
  │  └───────────────────────────────────────────────────┘  │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentOption 记录当前选中的选项（null/A/B/C/D）
  2. 坐标计算：所有元素坐标硬编码，确保精确对齐
  3. 样式切换：点击按钮时，清除所有按钮的 active 类，给当前按钮添加 active 类
  4. 内容切换：根据 currentOption 显示对应的分析内容 div，隐藏其他
  5. 判断结果：根据选项预设正确/错误状态，动态更新颜色
- ID 命名规范：所有交互元素 ID 以 scene2- 为前缀
  - 按钮：scene2-btn-A, scene2-btn-B, scene2-btn-C, scene2-btn-D
  - 分析内容：scene2-content-A, scene2-content-B, scene2-content-C, scene2-content-D
  - 判断结果：scene2-result
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
