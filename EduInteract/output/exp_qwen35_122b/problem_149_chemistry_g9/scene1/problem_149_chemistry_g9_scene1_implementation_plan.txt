[图示主题与整合说明]
- 本图示主题：化学反应微观过程模拟（置换反应）
- 整合内容：整合了反应前粒子状态、反应过程、反应后粒子状态、生成物识别、反应类型判断等完整认知过程

[分步序列]
步骤 0（初始状态）：
- 显示：原子图例（a、b、c）、图甲框内全部粒子（4 个 a₂分子 + 2 个 cb 分子）、图乙框（空）、反应箭头
- 图乙框内显示"?"提示
- 结论区隐藏
- 按钮状态：上一步禁用，下一步启用

步骤 1（反应进行中）：
- 显示：步骤 0 所有元素 + 高亮框
- 高亮框包围图甲中的 2 个 a₂分子（左侧）和 2 个 cb 分子
- a₂分子高亮为蓝色背景（透明度 20%）
- cb 分子高亮为红色背景（透明度 20%）
- 图乙框仍为空
- 新增标签："反应物"（蓝色，在高亮框上方）

步骤 2（反应完成）：
- 显示：图甲框内剩余 2 个 a₂分子变为灰色（剩余物）
- 图乙框内显示：2 个 a₂分子（灰色剩余物）+ 2 个 a₂b 分子 + 2 个 c 原子
- 高亮框消失
- 图乙中的 a₂b 分子和 c 原子暂时不高亮

步骤 3（生成物识别）：
- 显示：步骤 2 所有元素 + 生成物高亮
- 图乙中的 2 个 a₂b 分子和 2 个 c 原子高亮为绿色背景（透明度 20%）
- 新增标签："生成物"（绿色，在图乙框上方）
- 图乙中的 a₂分子保持灰色（剩余物）

步骤 4（反应类型）：
- 显示：步骤 3 所有元素 + 结论区
- 结论区显示反应方程式："a₂ + cb → a₂b + c"
- 结论区显示反应类型："置换反应"
- 结论区用绿色边框高亮

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - scene1-btn-prev：上一步按钮，位于底部左侧，点击返回上一状态
  - scene1-btn-next：下一步按钮，位于底部右侧，点击进入下一状态
  - 步骤 0 时 prev 按钮禁用（灰色），步骤 4 时 next 按钮禁用
- 教师操作流程：
  1. 初始展示反应前粒子分布，引导学生识别 a₂和 cb 分子
  2. 点击下一步，高亮参与反应的粒子，讲解"反应物"概念
  3. 点击下一步，展示反应后粒子分布，对比反应前后变化
  4. 点击下一步，高亮生成物，引导学生识别新生成的 a₂b 和 c
  5. 点击下一步，显示反应方程式和反应类型，总结置换反应特征

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │  [图例]  [图甲框]  →  [图乙框]                                 │
  │   a      反应前          反应后                                 │
  │   b      (4a₂+2cb)  →   (2a₂+2a₂b+2c)                          │
  │   c                                                            │
  │                                                                │
  │                                    [结论区]                    │
  │                                    a₂ + cb → a₂b + c          │
  │                                    置换反应                     │
  │                                                                │
  │              [◀ 上一步]          [下一步 ▶]                    │
  └────────────────────────────────────────────────────────────────┘
  ```

- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量（0-4）跟踪当前步骤，updateScene() 函数根据 currentStep 显示/隐藏对应元素
  2. 坐标计算：所有元素使用绝对坐标，SVG 元素通过 x、y 属性定位
  3. 动画曲线：使用 CSS transition 实现淡入淡出效果（opacity: 0→1）
  4. 事件绑定：按钮点击事件调用 prevStep() 和 nextStep()，更新 currentStep 后刷新视图
  5. 高亮效果：通过添加/移除 CSS class（blue-highlight、red-highlight、green-highlight）实现
  6. 剩余物灰色化：通过修改 fill 属性实现（#000000 → #888888）

- ID 命名规范：所有交互元素 ID 以 scene1- 为前缀
  - scene1-atom-a、scene1-atom-b、scene1-atom-c（原子图例）
  - scene1-box-a、scene1-box-b（反应框）
  - scene1-mol-a2-1~4、scene1-mol-cb-1~2（图甲分子）
  - scene1-mol-a2b-1~2、scene1-mol-c-1~2（图乙生成物）
  - scene1-btn-prev、scene1-btn-next（导航按钮）
  - scene1-conclusion-box（结论区）

- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
