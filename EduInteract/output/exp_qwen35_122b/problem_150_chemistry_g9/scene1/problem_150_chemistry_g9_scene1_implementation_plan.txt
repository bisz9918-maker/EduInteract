[图示主题与整合说明]
- 本图示主题：一氧化碳和氢气还原氧化铁的反应原理对比
- 整合内容：整合了 CO 还原 Fe₂O₃和 H₂还原 Fe₂O₃两个反应方程式的书写、反应物与生成物的对应关系、产物检验方法
- 教学价值：教师可通过分步展示，先让学生观察反应装置，再逐步揭示两个反应的化学方程式，最后对比产物差异，帮助学生理解两种还原剂的反应机理和产物检验方法的区别

[分步序列]
- 步骤 0（初始状态）：
  - 显示：图甲装置完整示意图（玻璃管、氧化铁、酒精灯、铁架台）
  - 显示：右侧两个方程式区域背景框（仅边框，无内容）
  - 显示：结论区域背景框（仅边框，无内容）
  - 隐藏：所有方程式文字、产物标注、反应条件
  - 目的：让学生先观察实验装置，思考气体流向和反应位置

- 步骤 1：
  - 显示：CO 方程式区域完整内容
  - 高亮：Fe₂O₃ + 3CO → 2Fe + 3CO₂（蓝色边框加粗至 3px）
  - 显示：反应条件"高温"（蓝色）
  - 显示：产物标注"生成铁粉和二氧化碳"（绿色）
  - H₂方程式区域：保持仅边框状态
  - 结论区域：保持仅边框状态
  - 目的：展示一氧化碳还原氧化铁的反应原理

- 步骤 2：
  - 显示：H₂方程式区域完整内容
  - 高亮：Fe₂O₃ + 3H₂ → 2Fe + 3H₂O（红色边框加粗至 3px）
  - 显示：反应条件"加热"（红色）
  - 显示：产物标注"生成铁粉和水蒸气"（绿色）
  - CO 方程式区域：保持显示状态
  - 结论区域：保持仅边框状态
  - 目的：展示氢气还原氧化铁的反应原理，与 CO 反应对比

- 步骤 3：
  - 两个方程式区域：均保持显示状态
  - 高亮对比：在两个方程式之间添加对比箭头或标注
  - 显示：结论区域内容"产物检验：CO₂用澄清石灰水，H₂O用浓硫酸"
  - 目的：对比两种反应的产物差异（CO₂ vs H₂O）

- 步骤 4（结论）：
  - 两个方程式区域：均保持显示
  - 结论区域：高亮显示（灰色边框加粗）
  - 添加：产物检验方法说明
    - CO₂检验：通入澄清石灰水，变浑浊
    - H₂O检验：通过浓硫酸，吸收水分
  - 目的：总结产物检验方法，为后续实验装置选择做铺垫

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮（scene1-prev-btn）：位于底部左侧，点击返回上一状态，第一步时禁用
  - 下一步按钮（scene1-next-btn）：位于底部右侧，点击进入下一状态，最后一步时变为"完成"
  - 步骤指示器（scene1-step-indicator）：位于底部中央，显示当前步骤"步骤 X/5"
- 教师操作流程：
  1. 初始展示装置图，引导学生观察实验装置结构
  2. 点击"下一步"，展示 CO 还原反应方程式，讲解反应原理
  3. 点击"下一步"，展示 H₂还原反应方程式，对比两种还原剂
  4. 点击"下一步"，展示产物差异对比
  5. 点击"下一步"，总结产物检验方法
  6. 可随时点击"上一步"回退复习关键步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何和文本，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │                        图甲标题                                │
  │                                                                │
  │  ┌──────────────────────────────────────────────────────────┐  │
  │  │  图甲装置区 (250×350)  │  CO 方程式区 (450×130)           │  │
  │  │                     │  ┌────────────────────────────┐  │  │
  │  │  [玻璃管]           │  │ Fe₂O₃ + 3CO → 2Fe + 3CO₂  │  │  │
  │  │  [氧化铁]           │  └────────────────────────────┘  │  │
  │  │  [酒精灯]           │                                  │  │
  │  │  [铁架台]           │  ┌────────────────────────────┐  │  │
  │  │                     │  │ Fe₂O₃ + 3H₂ → 2Fe + 3H₂O  │  │  │
  │  │                     │  └────────────────────────────┘  │  │
  │  │                     │                                  │  │
  │  │                     │  ┌────────────────────────────┐  │  │
  │  │                     │  │ 结论区域                   │  │  │
  │  │                     │  └────────────────────────────┘  │  │
  │  └──────────────────────────────────────────────────────────┘  │
  │                                                                │
  │              [◀上一步]  [步骤 1/5]  [下一步▶]                  │
  └────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量（0-4），每个步骤对应一个显示配置对象
  2. 坐标计算：所有元素使用绝对定位，通过 CSS transform 或 SVG 坐标系统一管理
  3. 动画曲线：元素出现使用 opacity 淡入动画（0.3s ease-in-out）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 renderStep() 重绘
  5. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-glass-tube、scene1-co-equation、scene1-prev-btn 等）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 使用 SVG 的 <g> 元素分组管理相关元素，便于整体显示/隐藏
  8. 方程式使用 MathJax 渲染（如需数学公式格式），或直接用 text 元素（简单文本）

- 状态配置对象示例：
  ```javascript
  const stepConfig = {
    0: { showCO: false, showH2: false, showConclusion: false },
    1: { showCO: true, showH2: false, showConclusion: false },
    2: { showCO: true, showH2: true, showConclusion: false },
    3: { showCO: true, showH2: true, showConclusion: true },
    4: { showCO: true, showH2: true, showConclusion: true, highlightConclusion: true }
  };
  ```

- 元素显示控制：通过 CSS class "hidden" 控制显示/隐藏，renderStep() 根据当前步骤添加/移除 class
