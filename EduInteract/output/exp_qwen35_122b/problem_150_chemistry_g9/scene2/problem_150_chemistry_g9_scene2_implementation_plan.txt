[图示主题与整合说明]
- 本图示主题：一氧化碳和氢气还原氧化铁实验的装置选择与连接顺序
- 整合内容：整合了图乙四个装置的功能分析、装置连接顺序的逻辑推理、最终答案的验证
- 教学价值：教师可通过分步交互引导学生从实验目的出发，逐步分析每个装置的功能，理解气体检验与吸收的顺序逻辑（先检验/吸收水，再检验/吸收 CO₂），最终确定正确的装置连接顺序

[分步序列]
步骤 0（初始状态）：
- 显示：标题、图乙四个装置（a、b、c、d）及各自功能标签
- 推理文本区显示："观察图乙四个装置，分析每个装置的功能"
- 连接顺序区：隐藏
- 按钮状态：上一步禁用，下一步启用

步骤 1：
- 显示：步骤 0 所有内容
- 推理文本区更新："实验目的：比较 CO 和 H₂还原氧化铁时，哪个产生的 CO₂和 H₂O 更多"
- 高亮：推理文本区淡入动画
- 连接顺序区：隐藏

步骤 2：
- 显示：步骤 1 所有内容
- 推理文本区更新："装置功能分析：b(氢氧化钠) 吸收 CO₂ | c(浓硫酸) 吸收 H₂O | d(澄清石灰水) 检验 CO₂ | a(酒精灯) 处理尾气"
- 高亮：装置 b、c、d、a 依次淡入高亮（蓝色→红色→蓝色→灰色）
- 连接顺序区：隐藏

步骤 3：
- 显示：步骤 2 所有内容
- 推理文本区更新："连接顺序逻辑：气体检验应先检验水（避免后续装置带出水蒸气干扰），再检验 CO₂"
- 高亮：装置 c 红色高亮，装置 b、d 蓝色高亮
- 连接顺序区：显示装置 b、c、d 轮廓（未高亮）

步骤 4：
- 显示：步骤 3 所有内容
- 推理文本区更新："最终连接顺序：混合气体→b(吸收 CO₂)→c(吸收 H₂O)→d(检验 CO₂)→a(尾气处理)"
- 高亮：连接顺序区装置 b→c→d→a 全部绿色高亮，连接箭头显示
- 连接顺序区：完整显示

结论（步骤 5）：
- 显示：步骤 4 所有内容
- 推理文本区更新："答案验证：正确连接顺序为 b→c→d→a（或 c→b→d→a，取决于先吸收水还是先吸收 CO₂）"
- 高亮：整个连接顺序路径绿色闪烁强调
- 按钮状态：上一步启用，下一步禁用（或循环）

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮（scene2-btn-prev）：位于控件栏左侧，点击返回上一推理步骤，步骤 0 时禁用
  - 下一步按钮（scene2-btn-next）：位于控件栏右侧，点击进入下一推理步骤，最终步骤后可循环或禁用
  - 步骤指示器（scene2-step-indicator）：显示当前步骤/总步骤数
- 教师操作流程：
  1. 初始展示四个装置，引导学生观察
  2. 点击"下一步"，展示实验目的
  3. 点击"下一步"，逐一高亮各装置功能
  4. 点击"下一步"，展示连接顺序逻辑
  5. 点击"下一步"，展示完整正确连接顺序
  6. 可点击"上一步"回退复习任意步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    标题 (320,20)                        │
  │                                                         │
  │  a        b        c        d                          │
  │ [酒精] [NaOH] [浓硫酸] [石灰水]                        │
  │ 80,80  200,80  360,80  520,80                          │
  │                                                         │
  │ 推理过程：                                              │
  │ (动态文本区 50,260)                                     │
  │                                                         │
  │ 正确连接顺序：                                          │
  │ →[b]→[c]→[d]→[a]→                                      │
  │ 150,380                                                │
  │                                                         │
  ├─────────────────────────────────────────────────────────┤
  │  步骤指示器 (370,420)                                   │
  │  [◀上一步]  [下一步▶]                                   │
  │  320,455    440,455                                     │
  └─────────────────────────────────────────────────────────┘
  ```

- 关键实现要点：
  1. 状态机设计：currentStep 变量（0-5），根据步骤控制元素显示/隐藏/高亮
  2. 坐标计算：所有元素使用绝对定位（SVG 内），按布局坐标表精确实现
  3. 动画曲线：使用 CSS transition 实现淡入淡出（opacity: 0→1）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 并刷新视图
  5. 高亮逻辑：根据步骤动态添加/移除 CSS class（blue-highlight, red-highlight, green-highlight）

- ID 命名规范：所有交互元素 ID 以 scene2- 为前缀
  - 装置：scene2-device-a, scene2-device-b, scene2-device-c, scene2-device-d
  - 按钮：scene2-btn-prev, scene2-btn-next
  - 文本区：scene2-reasoning-text, scene2-step-indicator
  - 连接顺序：scene2-order-b, scene2-order-c, scene2-order-d, scene2-order-a

- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染

- CSS 类定义：
  .blue-highlight { stroke: #1565c0; stroke-width: 3; }
  .red-highlight { stroke: #c62828; stroke-width: 3; }
  .green-highlight { stroke: #2e7d32; stroke-width: 3; fill: rgba(46,125,50,0.2); }
  .fade-in { animation: fadeIn 0.5s ease-in; }
  @keyframes fadeIn { from { opacity: 0; } to { opacity: 1; } }
