[分步序列]
- 步骤0（初始状态）：
  - 显示：反应前区域背景、A分子(CH₄)、B分子(2O₂)、"反应前"标签、图例框
  - 隐藏：反应后区域、反应箭头、反应后分子、原子计数器
  - 目的：展示反应物初始状态

- 步骤1：
  - 显示：反应箭头、"点燃"标签
  - 高亮：A分子和B分子添加红色边框
  - 新增动画：分子键虚线化，表示化学键断裂
  - 目的：展示反应条件触发，化学键开始断裂

- 步骤2：
  - 显示：反应后区域背景、C分子(CO₂)、D分子(2H₂O)、"反应后"标签
  - 动画：原子从反应前位置移动到反应后位置（原子重组过程）
  - 高亮：C分子和D分子添加红色边框
  - 目的：展示原子重组形成新分子

- 步骤3：
  - 显示：原子计数器背景、反应前原子统计(C=1 H=4 O=4)、反应后原子统计(C=1 H=4 O=4)
  - 高亮：移除所有分子高亮边框
  - 动画：原子统计数字逐个数显示
  - 目的：展示反应前后原子数目对比

- 步骤4（最终状态）：
  - 显示：所有元素完整呈现
  - 高亮：原子统计区域添加绿色高亮边框
  - 文字提示：在原子计数器上方显示"质量守恒定律：反应前后原子种类和数目不变"
  - 目的：总结质量守恒结论

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - scene1-btn-prev：位于(300,455)，80×30px，「◀ 上一步」按钮，点击返回上一步骤，步骤0时禁用
  - scene1-btn-next：位于(420,455)，80×30px，「下一步 ▶」按钮，点击进入下一步骤，步骤4时禁用
- 教师操作流程：
  1. 初始展示反应物（CH₄和O₂），讲解反应物分子结构
  2. 点击"下一步"展示反应条件"点燃"，讲解反应触发条件
  3. 点击"下一步"展示产物（CO₂和H₂O），讲解原子重组过程
  4. 点击"下一步"展示原子统计，引导学生观察原子数目
  5. 点击"下一步"展示完整结论，总结质量守恒定律
  6. 可随时点击"上一步"回退复习某个环节

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：分子结构为简单几何图形（圆、直线），SVG 矢量绘图清晰且易于动画控制，无需引入重型库

- 画布尺寸：800 × 500 px

- 布局草图（ASCII）：
```
┌────────────────────────────────────────────────────────────────┐
│  图例框                                                         │
│  ┌─────────────┐                                               │
│  │ ○ 氢原子    │  反应前区域              反应后区域            │
│  │ ● 氧原子    │  ┌───────────┐    →    ┌───────────┐         │
│  │ ║ 碳原子    │  │ CH₄ + 2O₂ │  点燃   │ CO₂ + 2H₂O│         │
│  └─────────────┘  └───────────┘         └───────────┘         │
│                        反应前              反应后               │
├────────────────────────────────────────────────────────────────┤
│  原子计数器：反应前 C=1 H=4 O=4    反应后 C=1 H=4 O=4           │
│                    [◀ 上一步] [下一步 ▶]                        │
└────────────────────────────────────────────────────────────────┘
```

- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量(0-4)跟踪当前步骤，步骤变化时调用 updateScene() 更新显示
  2. 坐标计算：所有元素坐标已在布局坐标表中精确定义，直接使用
  3. 动画曲线：原子移动使用 SVG SMIL 动画或 requestAnimationFrame 实现平滑过渡
  4. 事件绑定：按钮点击事件绑定到 scene1-btn-prev 和 scene1-btn-next，更新 currentStep 后刷新视图
  5. 高亮边框：使用 CSS class "highlight" 动态添加/移除，边框颜色#c62828
  6. 分子键虚线化：步骤1时将 stroke-dasharray 从"0"改为"5,5"
  7. 原子统计显示：步骤3-4时从 opacity:0 渐变到 opacity:1

- ID 命名规范：所有交互元素 ID 以 scene1- 为前缀
  - scene1-svg：主 SVG 容器
  - scene1-bg-reaction-before：反应前区域背景
  - scene1-bg-reaction-after：反应后区域背景
  - scene1-mol-a：A分子(CH₄)组
  - scene1-mol-b：B分子(2O₂)组
  - scene1-arrow：反应箭头
  - scene1-mol-c：C分子(CO₂)
  - scene1-mol-d：D分子(2H₂O)组
  - scene1-legend：图例框
  - scene1-counter-bg：原子计数器背景
  - scene1-stat-before：反应前原子统计
  - scene1-stat-after：反应后原子统计
  - scene1-btn-prev：上一步按钮
  - scene1-btn-next：下一步按钮

- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染
