[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 按钮"上一步"：位于(260,455)，点击返回上一状态，步骤0时禁用
  - 按钮"下一步"：位于(460,455)，点击进入下一状态，步骤5时禁用
  - 步骤指示器：位于(360,420)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始展示完整装置，让学生观察整体结构
  2. 点击"下一步"逐步标注各部分，每步讲解该部分功能
  3. 步骤1讲解集气瓶和刻度作用（测量氧气体积）
  4. 步骤2讲解燃烧匙和红磷作用（消耗氧气）
  5. 步骤3讲解导管和止水夹作用（控制气体流动）
  6. 步骤4讲解烧杯和水作用（显示进入水的体积）
  7. 步骤5总结各部分协同工作原理
  8. 可随时点击"上一步"回顾重点部分

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：

- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-5) 跟踪当前步骤
  2. 坐标计算：所有元素使用绝对定位，基于布局坐标表精确绘制
  3. 动画曲线：高亮效果使用 CSS transition，0.3s ease-in-out
  4. 事件绑定：按钮点击事件监听，更新 currentStep 并重新渲染标签可见性
  5. 标签可见性控制：每个标签元素设置 data-step 属性，根据 currentStep 控制 display
  6. 高亮效果：使用 class "highlight" 添加黄色边框或闪烁动画
