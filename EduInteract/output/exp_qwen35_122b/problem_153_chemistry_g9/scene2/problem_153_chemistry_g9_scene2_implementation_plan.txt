[图示主题与整合说明]
- 本图示主题：分步除杂过程演示（化学气体净化流程）
- 整合内容：整合四个装置（A 碳酸氢钠、B 氧化铜加热、C 澄清石灰水、D 浓硫酸）依次除去的气体成分及反应原理

[分步序列]
步骤 0（初始状态）：
- 显示：四个装置图标（灰色，未激活）、初始气体框（显示 H₂ N₂ HCl H₂O CO CO₂）、气体分子图例
- 隐藏：所有箭头、中间气体框、反应式文本
- 状态指示："步骤 0/5 - 初始混合气体"
- 按钮状态：上一步禁用，下一步启用

步骤 1（A 装置除 HCl）：
- 高亮：A 装置图标（蓝色边框加粗）
- 显示：箭头 1、A 后气体框（显示 H₂ N₂ H₂O CO CO₂，HCl 被划掉）
- 反应式框显示：HCl + NaHCO₃ → NaCl + H₂O + CO₂
- 状态指示："步骤 1/5 - A 装置除去 HCl"
- 被除去气体：HCl（红色删除线）

步骤 2（B 装置除 H₂、CO）：
- 高亮：B 装置图标（蓝色边框加粗），A 装置恢复灰色
- 显示：箭头 2、B 后气体框（显示 N₂ H₂O CO₂，H₂和 CO 被划掉，新增 H₂O 和 CO₂）
- 反应式框显示：H₂ + CuO → Cu + H₂O；CO + CuO → Cu + CO₂
- 状态指示："步骤 2/5 - B 装置除去 H₂、CO"
- 被除去气体：H₂、CO（红色删除线）

步骤 3（C 装置除 CO₂）：
- 高亮：C 装置图标（蓝色边框加粗），B 装置恢复灰色
- 显示：箭头 3、C 后气体框（显示 N₂ H₂O，CO₂被划掉）
- 反应式框显示：CO₂ + Ca(OH)₂ → CaCO₃↓ + H₂O
- 状态指示："步骤 3/5 - C 装置除去 CO₂"
- 被除去气体：CO₂（红色删除线）

步骤 4（D 装置除 H₂O）：
- 高亮：D 装置图标（蓝色边框加粗），C 装置恢复灰色
- 显示：箭头 4、D 后气体框（显示 N₂，H₂O 被划掉）
- 反应式框显示：H₂O 被浓硫酸吸收（物理吸收）
- 状态指示："步骤 4/5 - D 装置除去 H₂O"
- 被除去气体：H₂O（红色删除线）

步骤 5（最终结果）：
- 高亮：最终气体框（绿色边框加粗），D 装置恢复灰色
- 显示：所有箭头、所有中间气体框（完整流程）
- 反应式框显示：完整反应链总结
- 状态指示："步骤 5/5 - 最终剩余 N₂"
- 最终气体：N₂（绿色高亮）

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮（scene2-btn-prev）：位于 (280, 450)，点击返回上一状态，步骤 0 时禁用
  - 下一步按钮（scene2-btn-next）：位于 (440, 450)，点击进入下一状态，步骤 5 时禁用
- 教师操作流程：
  1. 初始展示混合气体成分
  2. 点击"下一步"逐步演示每个装置的除杂作用
  3. 每步配合讲解反应原理和被除去的气体
  4. 可点击"上一步"回退复习关键步骤
  5. 最终展示完整流程和剩余气体 N₂

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何和状态切换，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │                    气体除杂流程 (标题)                       │
  │  [A]──────[B]──────[C]──────[D]    ← 装置图标顶部           │
  │   ↓        ↓        ↓        ↓                              │
  │ ┌────┐ → ┌────┐ → ┌────┐ → ┌────┐ → ┌────┐                │
  │ │初始│   │ A 后│   │ B 后│   │ C 后│   │最终│                │
  │ └────┘   └────┘   └────┘   └────┘   └────┘                │
  │                                                             │
  │ ┌───────────────────────────────────────────────────────┐  │
  │ │              反应方程式区域（浅黄色背景）               │  │
  │ └───────────────────────────────────────────────────────┘  │
  │                                                             │
  │              [上一步]              [下一步]                 │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：currentStep 变量 (0-5)，updateScene() 函数根据 currentStep 更新显示
  2. 坐标计算：所有元素使用固定像素坐标，SVG 内绝对定位
  3. 高亮逻辑：当前步骤装置添加 class="active"，被除去气体添加 class="removed"
  4. 事件绑定：按钮点击事件监听，边界检查（step 0 时禁用 prev，step 5 时禁用 next）
  5. ID 命名规范：所有元素 ID 以 scene2- 为前缀（如 scene2-rect-a, scene2-text-h2, scene2-btn-prev）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 动画过渡：使用 CSS transition 实现高亮状态平滑切换（0.3s ease）
  8. 文本渲染：反应方程式使用 MathJax 渲染（如需显示化学式下标）
