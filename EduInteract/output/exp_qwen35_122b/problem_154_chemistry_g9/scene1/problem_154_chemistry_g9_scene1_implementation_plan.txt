[分步序列]
- 步骤 0（初始状态）：
  - 显示完整转化关系图（所有物质框、连线、反应标注）
  - 物质框内仅显示字母 A-G，无化学式
  - 右上角显示已知条件说明框（B=酸、D=H₂O、G=蓝色沉淀）
  - 红色高亮框高亮 B、D、G 三个物质框（已知条件）
  - 步骤指示器显示"步骤 1/4"

- 步骤 1：
  - 蓝色高亮框高亮反应③区域（E+F→E+G）
  - 在 G 框右侧显示推理标注："G=Cu(OH)₂（蓝色沉淀）"
  - 在 F 框下方显示推理标注："F=铜盐（如 CuCl₂）"
  - 在 E 框下方显示推理标注："E=碱（如 NaOH）"
  - 灰色虚线连接 G→F→E，表示推理路径
  - 步骤指示器显示"步骤 2/4"

- 步骤 2：
  - 蓝色高亮框高亮反应①和②区域
  - 在 D 框下方显示推理标注："D=H₂O（人体含量最多）"
  - 在 B 框下方显示推理标注："B=酸（如 HCl）"
  - 显示反应规律说明："酸 + 碱/金属氧化物/碳酸盐 → 水"
  - 灰色虚线从 B 指向 D，表示 B 生成 D
  - 步骤指示器显示"步骤 3/4"

- 步骤 3（最终结论）：
  - 绿色高亮框高亮 A 和 C 物质框
  - A 框内显示："A=碱（如 NaOH）"
  - C 框内显示："C=铜盐（如 CuO 或 CuCO₃）"
  - 在底部显示最终答案：
    - "(1) C=CuO 或 CuCO₃"
    - "(2) 反应③：复分解反应"
    - "(3) A：碱"
  - 步骤指示器显示"步骤 4/4"

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "上一步"按钮（scene1-prev-btn）：位于底部左侧，点击返回上一状态，步骤 0 时禁用
  - "下一步"按钮（scene1-next-btn）：位于底部右侧，点击进入下一状态，步骤 3 时禁用
  - 步骤指示器（scene1-step-indicator）：显示当前步骤"步骤 X/4"
- 教师操作流程：
  1. 初始展示完整转化关系图，红色高亮已知条件（B、D、G）
  2. 点击"下一步"→ 分析反应③，推导 G=Cu(OH)₂，进而推出 F 为铜盐、E 为碱
  3. 点击"下一步"→ 分析反应①②，确认 D=H₂O，B=酸
  4. 点击"下一步"→ 得出最终结论 A=碱、C=铜盐，显示完整答案
  5. 可随时点击"上一步"回退复习，巩固推理逻辑

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形和状态切换，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
```
┌────────────────────────────────────────────────────────────────┐
│  物质转化关系推断图                              [已知条件框]   │
│                                                                 │
│  ┌───┐      ┌───┐                    ┌───┐                    │
│  │ A │──────│①  │──────────────────→ │ E │                    │
│  └───┘      └───┘                    └───┘                    │
│    │          │                          │                     │
│    │          ↓                          │                     │
│  ┌───┐      ┌───┐                    ┌───┐                    │
│  │ B │──────│②  │──────────────────→ │ D │                    │
│  └───┘      └───┘                    └───┘                    │
│    │          │                          │                     │
│    │          ↓                          │                     │
│  ┌───┐      ┌───┐                    ┌───┐    ┌───┐          │
│  │ C │──────│   │──────────────────→ │ F │──→ │ G │          │
│  └───┘      └───┘                    └───┘    └───┘          │
│                                                                 │
│                    [◀ 上一步]  步骤 1/4  [下一步 ▶]             │
└────────────────────────────────────────────────────────────────┘
```

- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量（0-3）跟踪当前步骤，每个步骤对应一个状态配置对象
  2. 坐标计算：所有元素使用绝对定位，通过 SVG 的 transform 属性精确控制位置
  3. 高亮效果：使用 SVG 的 <rect> 元素叠加在物质框上，通过 opacity 和 stroke 属性实现高亮
  4. 动画过渡：使用 CSS transition 实现高亮框的淡入淡出（transition: opacity 0.3s）
  5. 事件绑定：按钮点击事件绑定到 scene1-prev-btn 和 scene1-next-btn，更新 currentStep 后调用 renderStep()
  6. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-box-A、scene1-highlight-B、scene1-prev-btn）
  7. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染

- 状态配置数据结构：
```javascript
const stepConfig = {
  0: { highlight: ['B','D','G'], labels: {}, arrows: [] },
  1: { highlight: ['reaction3'], labels: {G:'Cu(OH)₂', F:'铜盐', E:'碱'}, arrows: ['G→F→E'] },
  2: { highlight: ['reaction1','reaction2'], labels: {D:'H₂O', B:'酸'}, arrows: ['B→D'] },
  3: { highlight: ['A','C'], labels: {A:'碱', C:'铜盐'}, arrows: [], answers: true }
};
```

- 渲染函数 renderStep(step)：
  1. 清除所有高亮层
  2. 根据 stepConfig[step] 添加对应高亮框
  3. 显示/隐藏对应推理标注
  4. 更新步骤指示器文本
  5. 启用/禁用上下一步按钮
