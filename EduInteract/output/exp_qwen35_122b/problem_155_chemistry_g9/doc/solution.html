problem_155_chemistry_g9

场景导航：Scene 1

题目原文：

一定温度下，在下图所示装置中，固体X与气体Y反应生成气态产物，当改变温度时该气态产物发生逆向反应，重新生成X和Y．发生的化学反应为：

Co（固）+ 2HCl（气）$\stackrel{900℃}{\underset{600℃}{{⇌}}}$ CoCl$_{2}$（气）+ H$_{2}$（气）

利用上述反应原理和装置，对含杂质的固体Co进行提纯（杂质不参加反应）．

下列说法正确的是（ ）

A．固体Co从容器1到容器2的过程为物理变化

B．容器2中的固体是纯净的Co

C．该装置最终导出的气体是CoCl$_{2}$和H$_{2}$

D．容器1中的温度为900℃，容器2中的温度为600℃

题目分析：

本题考察化学气相传输（Chemical Vapor Transport）原理在物质提纯中的应用。核心知识点包括：

  1. 可逆反应的温度依赖性——温度改变反应方向
  2. 化学变化与物理变化的区分
  3. 物质提纯的基本原理

整体讲解思路：

  1. 首先引导学生观察装置图，理解这是一个串联的双容器系统
  2. 讲解可逆反应的温度控制原理——高温促进正向反应，低温促进逆向反应
  3. 分析提纯过程：杂质留在容器1，纯净Co在容器2沉积
  4. 逐一分析选项，得出正确答案

图示规划说明：

设计一个综合图示，整合以下内容：

  • 装置整体结构（双容器串联）
  • 温度分布（容器1高温900℃，容器2低温600℃）
  • 反应过程（正向反应→气体传输→逆向反应）
  • 物质流向（Co从容器1"迁移"到容器2，HCl循环）
步骤 0/5

教学说明：

本图示是讲解本题的核心可视化材料，教师应按以下步骤引导学生：

步骤0-1：理解装置与反应条件

首先让学生观察装置的整体结构，这是一个串联的双容器系统。强调关键点：

  • 气体从左向右流动
  • 两个容器温度不同（这是反应方向不同的关键）
  • 固体X在两个容器中都有

讲解可逆反应的温度依赖性：
$$\text{Co(固)} + 2\text{HCl(气)} \stackrel{900℃}{\underset{600℃}{\rightleftharpoons}} \text{CoCl}_2\text{(气)} + \text{H}_2\text{(气)}$$

高温（900℃）促进正向反应，低温（600℃）促进逆向反应。

步骤2-3：理解提纯原理

这是化学气相传输的典型应用：

  1. 容器1（900℃）：含杂质的Co与HCl反应，生成气态CoCl₂和H₂，杂质不反应留在容器1
  2. 气体传输：CoCl₂和H₂通过管道进入容器2
  3. 容器2（600℃）：气态产物逆向反应，重新生成固体Co和HCl气体
  4. HCl气体循环使用，从出口导出

关键概念：Co从容器1到容器2经历了化学变化（固→气→固），不是物理变化。

步骤4-5：选项分析

A．错误。Co经历了化学反应（Co→CoCl₂→Co），是化学变化而非物理变化。

B．正确。容器2中沉积的是通过气相传输重新生成的Co，杂质未参与反应，留在容器1中，所以容器2中的固体是纯净的Co。

C．错误。最终导出的气体是HCl（逆向反应生成），不是CoCl₂和H₂。

D．正确。容器1需要900℃促进正向反应，容器2需要600℃促进逆向反应。

正确答案：B、D

课堂讲解建议：

  1. 使用分步导航时，每步停留时间约30-60秒，确保学生理解后再进入下一步
  2. 重点强调"温度控制反应方向"这一核心概念
  3. 对比物理变化与化学变化的区别，这是选项A的考点
  4. 可补充说明：这种提纯方法称为"化学气相传输法"，在工业上用于提纯金属
