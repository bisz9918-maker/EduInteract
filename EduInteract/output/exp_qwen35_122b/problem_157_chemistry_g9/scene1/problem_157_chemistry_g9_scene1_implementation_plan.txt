[分步序列]
步骤 0（初始状态）：
- 显示：坐标系（横轴、纵轴）、溶解度曲线
- 隐藏：所有点、投影线、标签、状态标注、移动箭头
- 说明文字："溶解度曲线图——观察曲线形状和坐标轴含义"

步骤 1：
- 显示：A 点（绿色圆点）、A 点投影线（横、竖）、A 点标签"A"、S₂刻度标签、t₂刻度标签
- A 点状态标注"饱和溶液"显示
- 说明文字："A 点 (t₂,S₂) 在曲线上，表示 t₂℃时的饱和溶液，每 100g 溶剂溶解 S₂g 溶质"

步骤 2：
- 显示：B 点（红色圆点）、B 点投影线（横、竖）、B 点标签"B"、S₁刻度标签、t₃刻度标签
- B 点状态标注"不饱和溶液"显示
- 说明文字："B 点 (t₃,S₁) 在曲线下方，表示 t₃℃时的不饱和溶液，实际溶解量 S₁小于该温度下的溶解度"

步骤 3：
- 显示：M 点（红色圆点）、M 点投影线（横、竖）、M 点标签"M"
- M 点状态标注"不饱和溶液"显示
- 同时高亮显示 (t₁,S₁) 点（绿色圆点）及其投影线
- 说明文字："M 点 (t₂,S₁) 与 A 点同温度、与 B 点同溶解度；(t₁,S₁) 点在曲线上，是 t₁℃时的饱和溶液"

步骤 4：
- 动画效果：A 点、B 点水平向右移动 30px（模拟加水，温度不变）
- 显示移动轨迹箭头（橙色）
- 标注文字："加水→溶解度不变，溶质质量分数减小"
- 说明文字："温度不变时加水，溶解度不变（点沿水平方向移动），溶液变稀，溶质质量分数减小"

步骤 5：
- 动画效果：A 点沿曲线向左下方移动至 (t₁,S₁) 位置（模拟降温）
- 显示移动轨迹箭头（沿曲线方向）
- 标注文字："降温→溶解度减小，有晶体析出，质量分数不变"
- 说明文字："降温时 A 点沿曲线移动，溶解度减小，有晶体析出，剩余溶液仍为饱和溶液，溶质质量分数不变"

步骤 6：
- 动画效果：M 点显示两种转化路径
  - 路径 1：垂直向上移动至曲线（加溶质）
  - 路径 2：水平向左移动至 (t₁,S₁) 点（降温）
- 显示两条移动轨迹箭头（橙色）
- 标注文字："加溶质或降温→变为饱和溶液"
- 说明文字："M 点变为饱和溶液的方法：①加溶质至曲线（垂直向上）②降温至 t₁℃（水平向左至曲线）"

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：位于 (220,455)-(320,480)，点击返回上一状态
  - "下一步 ▶"按钮：位于 (480,455)-(580,480)，点击进入下一状态
  - 步骤说明框：位于 (220,460)-(580,480)，动态显示当前步骤的讲解文字
- 教师操作流程：
  1. 初始展示空白坐标系和曲线，让学生观察整体形状
  2. 逐步点击"下一步"，依次揭示 A、B、M 各点的意义
  3. 通过动画演示加水、降温等操作时点的移动轨迹
  4. 配合说明文字讲解每个知识点，学生可跟随步骤理解
  5. 如需复习某一步，点击"上一步"回退

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（线段、圆点、曲线、虚线），原生 SVG 足以实现，无需引入大型库
  - 动画使用 CSS transition + JavaScript 控制 class 切换
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
```
┌────────────────────────────────────────────────────────────────┐
│                        溶解度曲线图示                           │
│                                                                 │
│   溶  ↑                                                        │
│   解  │           ●A(饱和)                                     │
│   度  │          /│                                            │
│   (   │         / │                                            │
│   克  │        /  │                                            │
│   )   │       /   │                                            │
│       │      /    │                                            │
│   S₂  │-----●-----│--------                                    │
│       │     │     │        ╲                                   │
│       │     │     │         ╲                                  │
│   S₁  │-----●-----●M--------●B                                 │
│       │    (t₁)   │        (t₃)                                │
│       │     │     │                                            │
│       │     │     │                                            │
│       └─────┴─────┴────────────────────→                       │
│            t₁    t₂           t₃      温度（℃）                 │
│                                                                 │
│   [◀ 上一步]                    步骤说明文字...      [下一步 ▶]  │
└────────────────────────────────────────────────────────────────┘
```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-6) 跟踪当前步骤，updateStep() 函数根据 currentStep 显示/隐藏对应元素
  2. 坐标计算：所有元素坐标按布局坐标表精确设置，使用 SVG 的 x、y、cx、cy 属性
  3. 动画曲线：使用 CSS transition 实现平滑移动，transition: all 0.5s ease
  4. 事件绑定：按钮点击事件绑定到 updateStep()，根据方向修改 currentStep 后刷新显示
  5. 投影虚线：使用 SVG <line>元素，stroke-dasharray="5,5"实现虚线效果
  6. 贝塞尔曲线：使用 SVG <path>元素，d="M 120,350 Q 385,235 650,120"实现平滑曲线
- ID 命名规范：所有交互元素 ID 以"scene1-"为前缀
  - 点元素：scene1-point-A、scene1-point-B、scene1-point-M、scene1-point-t1S1
  - 投影线：scene1-proj-A-h、scene1-proj-A-v、scene1-proj-B-h 等
  - 标签：scene1-label-A、scene1-label-B、scene1-label-M 等
  - 按钮：scene1-prev-btn、scene1-next-btn
  - 说明框：scene1-step-text
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
