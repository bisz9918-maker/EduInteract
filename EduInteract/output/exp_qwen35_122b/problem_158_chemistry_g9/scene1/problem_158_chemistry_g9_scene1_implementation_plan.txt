[分步序列]
- 初始状态（步骤0）：显示三个循环基本结构（三角形、顶点化学式、箭头），不显示方程式和结论
- 步骤1：点击「下一步」→ 显示循环①的3个方程式，在循环①周围显示蓝色高亮框，每个方程式旁显示绿色✓，表示循环①可行
- 步骤2：点击「下一步」→ 显示循环②的3个方程式，Fe₂O₃→FeSO₄显示为Fe₂(SO₄)₃（说明产物不符），FeSO₄→Fe旁显示红色✗并标注"不可行"，循环②整体显示红色高亮

- 步骤4（最终步骤）：隐藏方程式，在图示中央显示"正确答案：B．①③"，循环①和③显示蓝色高亮框和绿色✓，循环②显示红色✗

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位置(300,450)，灰色，步骤0时禁用，点击后返回上一状态
  - 「下一步 ▶」按钮：位置(420,450)，蓝色，点击后进入下一状态，步骤4时变为"完成"
- 教师操作流程：
  1. 初始展示三个循环结构，让学生观察
  2. 点击「下一步」逐步展示每个循环的转化方程式
  3. 在步骤2重点讲解循环②的不可行之处（Fe₂O₃与硫酸反应生成Fe₂(SO₄)₃而非FeSO₄）
  4. 步骤4总结正确答案，强化记忆

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无需额外库，图形简单，状态切换为主）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │  循环①              循环②              循环③                  │
  │    CaCO₃              Fe               H₂O                     │
  │     /  \              /  \              /  \                   │
  │    ↓    ↑            ↓    ↑            ↓    ↑                  │
  │  CaO → Ca(OH)₂    Fe₂O₃ → FeSO₄      O₂ → MgO                 │
  │    ①                  ②                  ③                     │
  │                                                                │
  │  [方程式区域 y=240~280]                                        │
  │                                                                │
  │            [正确答案：B．①③] (步骤4显示)                       │
  │                                                                │
  │  ┌────────────────────────────────────────────────────────┐   │
  │  │        ◀ 上一步          下一步 ▶                       │   │
  │  └────────────────────────────────────────────────────────┘   │
  └────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  - 状态机设计：currentStep 变量（0-4），每个步骤对应不同的元素显示/隐藏
  - 坐标计算：所有元素使用绝对坐标，通过 SVG transform 定位
  - 动画曲线：元素出现使用 opacity 渐变（0→1，duration 300ms）
  - 事件绑定：按钮点击事件监听，更新 currentStep 并刷新显示
  - ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-tri-1、scene1-arrow-1-1）
  - IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  - 高亮实现：使用 SVG rect 或 polygon 覆盖循环区域，设置 fill 和 opacity
  - 箭头标记：SVG defs 中定义 arrowhead marker，应用到各路径
