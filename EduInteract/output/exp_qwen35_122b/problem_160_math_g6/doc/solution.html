problem_160_math_g6

场景导航：Scene 1

题目原文：
如图是一座楼房的平面图，图中不同字母表示长度不同的各条边长，若b=50米，c=30米，g=10米，则这座楼房平面图的周长是（ ）
A．90米 B．150米 C．180米

题目分析：
这是一道几何周长计算题，图形是一个不规则的"凹"字形多边形。关键在于利用图形的几何约束关系，将未知边长用已知边长表示。

整体讲解思路：

  1. 首先引导学生观察图形的水平方向和垂直方向的边长关系
  2. 利用"平移法"：将分散的水平边投影到底部，将分散的垂直边投影到两侧
  3. 发现规律：水平边总长 = 2b，垂直边总长 = 2c + 2g
  4. 计算周长 = 2b + 2c + 2g = 2×50 + 2×30 + 2×10 = 180米

图示规划说明：
本道题设计 1 个核心图示，整合以下认知步骤：

  • 步骤 0：展示原图，标注已知边长（b=50, c=30, g=10）
  • 步骤 1：高亮所有水平边，展示它们可以"平移"拼成两条长度为 b 的线段
  • 步骤 2：高亮所有垂直边，展示它们可以"平移"拼成两条长度为 c 的线段，再加上两条长度为 g 的线段
  • 步骤 3：显示周长计算公式和结果

教学说明：

本图示采用"平移法"帮助学生理解不规则图形周长的计算技巧。教师应按以下步骤引导学生：

  1. 步骤 0 - 观察原图

让学生先观察图形结构，识别出这是一个"凹"字形多边形，共有 8 条边。引导学生注意已知条件：b=50米、c=30米、g=10米。

  1. 步骤 1 - 水平边分析

点击"下一步"高亮水平边，引导学生发现：虽然顶部有三段水平边（h、f、d），但它们的总长度等于底部边长 b。这是因为从水平投影角度看，h + f + d = b。因此，所有水平边的总长度为 b + (h + f + d) = 2b。

  1. 步骤 2 - 垂直边分析

再次点击"下一步"高亮垂直边，引导学生发现：左侧边 a 与右侧边 c 等长（a = c = 30米），中间凹陷处的 g 与凸起处的 e 等长（e = g = 10米）。因此，所有垂直边的总长度为 a + c + g + e = 2c + 2g。

  1. 步骤 3 - 计算周长

最后点击"下一步"显示计算过程：

  • 周长 = 水平边总长 + 垂直边总长
  • 周长 = 2b + 2c + 2g
  • 周长 = 2×50 + 2×30 + 2×10
  • 周长 = 100 + 60 + 20 = 180米

关键教学点：

  • 强调"平移法"的核心思想：将分散的边通过平移拼接成规则图形
  • 提醒学生注意图形的几何约束关系（等长、平行等）
  • 引导学生总结规律：对于此类"凹"字形图形，周长 = 2×底边 + 2×高 + 2×凹陷深度

完整解答：
周长 = 2b + 2c + 2g = 2×50 + 2×30 + 2×10 = 180米，故选 C．180米
