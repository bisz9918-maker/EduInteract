[图示主题与整合说明]
- 本图示主题：三图形周长对比展示
- 整合的内容：同时展示A、B、C三个图形（长方形、阶梯形、凹字形），标注尺寸，分步计算各图形周长
- 教学价值：教师可逐步引导学生观察三个图形的周长计算，理解平移法（图形B）和凹槽增加周长（图形C）的概念，最终比较得出周长最长的图形

[分步序列]
- 步骤0（初始状态）：
  - 显示三个图形A、B、C的轮廓（黑色边框）
  - 显示尺寸标注"10"和"6"
  - 显示图形标签"A"、"B"、"C"
  - 周长标签暂不显示或显示"?"

- 步骤1（计算图形A周长）：
  - 图形A边框高亮为蓝色#1565c0
  - 显示图形A周长计算过程：周长 = 2×(10+6) = 32
  - 在图形A下方显示"周长=32"（红色）
  - 辅助线：在图形A内部显示虚线标注长和宽

- 步骤2（计算图形B周长）：
  - 图形A恢复黑色边框
  - 图形B边框高亮为蓝色#1565c0
  - 显示图形B周长计算：通过平移法，水平线段总和=10，垂直线段总和=6
  - 显示辅助虚线：将阶梯线段平移至外侧，形成完整矩形
  - 在图形B下方显示"周长=32"（红色）

- 步骤3（计算图形C周长）：
  - 图形B恢复黑色边框
  - 图形C边框高亮为蓝色#1565c0
  - 显示图形C周长计算：基础周长32 + 凹槽额外边长4 = 36
  - 显示辅助虚线：标注凹槽的额外边长
  - 在图形C下方显示"周长=36"（红色）

- 步骤4（比较得出结论）：
  - 所有图形边框恢复黑色
  - 图形C边框高亮为绿色#2e7d32（表示周长最长）
  - 三个图形下方同时显示周长结果：A=32，B=32，C=36
  - 顶部显示结论："周长最长的是图形C"

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮（scene1-prev-btn）：位于控件栏左侧，点击返回上一状态
  - 下一步按钮（scene1-next-btn）：位于控件栏右侧，点击进入下一状态
  - 步骤指示器（scene1-step-indicator）：位于控件栏中间，显示"步骤 X/5"
- 教师操作流程：
  1. 初始展示三个图形，让学生观察形状差异
  2. 点击"下一步"，逐步展示每个图形的周长计算
  3. 在图形B步骤，引导学生理解平移法
  4. 在图形C步骤，强调凹槽增加周长
  5. 最后一步高亮图形C，得出答案

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：图形为简单几何形状，无需复杂库，原生实现轻量高效
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │                    图形周长对比 (300,40)                        │
  │                                                                 │
  │   A        B        C                                          │
  │  ┌──┐    ┌┐┌┐    ┌┐ ┌┐                                        │
  │  │  │    ││││    │ │ │                                        │
  │  │  │    ││││    │ │ │                                        │
  │  └──┘    └┘└┘    └┘ └┘                                        │
  │  10      10       10                                           │
  │  周长=32  周长=32  周长=36                                      │
  │                                                                 │
  │          [上一步]  步骤 1/5  [下一步]                            │
  └────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用 currentStep 变量（0-4）跟踪当前步骤
  2. 坐标计算：所有元素使用绝对坐标，SVG 内定位
  3. 动画曲线：边框颜色变化使用 CSS transition（0.3s ease）
  4. 事件绑定：按钮点击事件监听，更新状态并重新渲染
  5. 辅助线显示：步骤2和3显示灰色虚线，用 stroke-dasharray 实现
- ID 命名规范：所有交互元素 ID 以 scene1- 为前缀
  - scene1-graph-a, scene1-graph-b, scene1-graph-c（图形轮廓）
  - scene1-perimeter-a, scene1-perimeter-b, scene1-perimeter-c（周长标签）
  - scene1-prev-btn, scene1-next-btn（导航按钮）
  - scene1-step-indicator（步骤指示器）
  - scene1-auxiliary-lines（辅助线组）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局污染
