[分步序列]
本场景采用多状态切换交互（2 个状态），而非分步导航：

- 初始状态（状态 0）：显示完整长方形（灰色虚线参考）+ 凹形图形（黑色实线），凹槽部分红色高亮，显示两个周长数值对比
- 状态 1（点击"完整长方形"按钮）：高亮完整长方形，完整长方形边框加粗显示，周长=32 高亮绿色，凹形图形变淡（透明度 50%）
- 状态 2（点击"凹形图形"按钮）：高亮凹形图形，凹槽部分红色闪烁动画，周长=36 高亮绿色，完整长方形变淡（透明度 50%）

[交互方案]
- 交互类型：多状态切换（2 个按钮）
- 控件说明：
  - 按钮"完整长方形"：位置 (280,450)，点击后高亮左侧完整长方形，显示其周长=32
  - 按钮"凹形图形"：位置 (480,450)，点击后高亮右侧凹形图形，显示其周长=36，凹槽红色闪烁
- 教师操作流程：
  1. 初始展示两个图形对比
  2. 点击"完整长方形"按钮，讲解标准长方形周长计算：(10+6)×2=32
  3. 点击"凹形图形"按钮，讲解凹槽增加周长：凹槽增加两条竖直边（各 3），周长=32+3+3=36
  4. 引导学生理解：凹槽使周长增加，而非减少

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────┐
  │                    凹槽对周长的影响                      │  y=30
  │                                                         │
  │    ┌─────────────┐              ┌─────────────┐         │
  │    │  完整长方形  │              │   凹形图形   │         │
  │    │  (灰色虚线)  │              │  (黑色实线)  │         │  y=150-300
  │    │             │              │  ┌───┐      │         │
  │    └─────────────┘              │  │红色│     │         │
  │         10                       │  └───┘      │         │
  │       周长=32                    │      10     │         │
  │                                  │   周长=36   │         │
  │                                                         │
  │          [完整长方形]          [凹形图形]                │  y=450
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 `currentState` 跟踪当前状态（0=初始，1=完整长方形高亮，2=凹形图形高亮）
  2. 坐标计算：凹形图形路径用 SVG polyline，坐标点依次为 (450,150)-(520,150)-(520,180)-(580,180)-(580,150)-(650,150)-(650,300)-(450,300)-cycle
  3. 动画曲线：凹槽红色闪烁用 CSS keyframe 动画（opacity 0.5→1 循环）
  4. 事件绑定：按钮点击事件更新状态，切换元素样式（opacity、stroke-width、fill）
  5. ID 命名规范：所有交互元素 ID 以 `scene3-` 为前缀（如 `scene3-rect-full`、`scene3-poly-concave`、`scene3-btn-full`、`scene3-btn-concave`）
  6. IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局污染
