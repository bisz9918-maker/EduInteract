[图示主题与整合说明]
- 本图示主题：选项对比与排除——通过三视图判断立体图形
- 整合内容：三个选项的立体图形展示 → 逐一分析每个选项的三视图 → 排除错误选项 → 确定正确答案
- 教学价值：教师可通过点击不同选项按钮，快速对比三个立体图形的俯视图差异，直观展示为什么只有梯形柱（选项③）的俯视图与题目给出的"上面"视图匹配，帮助学生理解三视图判断方法

[分步序列]
多状态切换交互（非分步导航，而是三个独立状态）：

初始状态（状态0）：
- 显示三个立体图形选项（①六棱柱、②五棱柱、③梯形柱）

状态2（点击按钮②）：
- 五棱柱立体图高亮边框（蓝色）
- 三视图区域显示五棱柱的三视图：正面=长方形，侧面=长方形，上面=五边形
- 判断标记显示"×"（红色，坐标520,280）
- 判断原因显示"俯视图=五边形≠梯形"（红色，坐标520,320）

状态3（点击按钮③）：
- 梯形柱立体图高亮边框（蓝色）
- 三视图区域显示梯形柱的三视图：正面=长方形，侧面=长方形，上面=梯形（与题目匹配）
- 判断标记显示"✓"（绿色，坐标520,280）
- 判断原因显示"俯视图=梯形✓ 正确"（绿色，坐标520,320）

[交互方案]
- 交互类型：多状态切换（3个按钮）
- 控件说明：
  - 按钮①：位置(180,450)，作用——显示六棱柱的三视图并判断
  - 按钮②：位置(360,450)，作用——显示五棱柱的三视图并判断
  - 按钮③：位置(540,450)，作用——显示梯形柱的三视图并判断
- 教师操作流程：
  1. 初始展示三个立体图形选项
  2. 点击按钮①，展示六棱柱三视图，指出俯视图是六边形，与题目梯形不符→排除
  3. 点击按钮②，展示五棱柱三视图，指出俯视图是五边形，与题目梯形不符→排除
  4. 点击按钮③，展示梯形柱三视图，指出俯视图是梯形，与题目完全匹配→正确答案

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────┐
  │                    选项对比与排除                        │  y=25
  │                                                         │
  │   ①              ②              ③                       │  y=70
  │  ┌───┐          ┌───┐          ┌───┐                    │
  │  │六棱│          │五棱│          │梯形│                    │  y=80-180
  │  │ 柱 │          │ 柱 │          │ 柱 │                    │
  │  └───┘          └───┘          └───┘                    │
  │  六棱柱          五棱柱          梯形柱                   │  y=195
  │                                                         │
  │         ┌──────────────────────────────────┐            │  y=220
  │         │  正面   侧面   上面    ×/✓        │            │
  │         │  ┌──┐  ┌──┐  ┌──┐                │            │  y=240-340
  │         │  │  │  │  │  │  │                │            │
  │         │  └──┘  └──┘  └──┘                │            │
  │         │  正面   侧面   上面   原因文字     │            │  y=355-360
  │         └──────────────────────────────────┘            │  y=400
  │                                                         │
  │        [ ① ]        [ ② ]        [ ③ ]                  │  y=450
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentOption 记录当前选中选项（1/2/3）
  2. 坐标计算：所有元素坐标按布局坐标表精确实现
  3. 动画曲线：按钮点击后三视图区域淡入淡出（opacity 过渡 0.3s）
  4. 事件绑定：三个按钮分别绑定 click 事件，更新 currentOption 并刷新视图
  5. 高亮边框：当前选中选项的立体图添加蓝色边框（stroke-width=3, stroke=#1565c0）
  6. 三视图动态更新：根据 currentOption 改变上面视图的 polygon 顶点坐标
  7. 判断标记和原因文字根据选项动态改变颜色和内容

- ID 命名规范：所有交互元素 ID 以 scene2- 为前缀
  - scene2-title（标题）
  - scene2-opt1-shape（选项①立体图）
  - scene2-opt2-shape（选项②立体图）
  - scene2-opt3-shape（选项③立体图）
  - scene2-opt1-btn（按钮①）
  - scene2-opt2-btn（按钮②）
  - scene2-opt3-btn（按钮③）
  - scene2-front-view（正面视图）
  - scene2-side-view（侧面视图）
  - scene2-top-view（上面视图）
  - scene2-judge-mark（判断标记）
  - scene2-judge-reason（判断原因）

- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
