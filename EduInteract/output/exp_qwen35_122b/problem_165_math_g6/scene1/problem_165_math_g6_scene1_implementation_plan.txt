[图示主题与整合说明]
- 本图示主题：正方形地砖面积与块数的反比例关系
- 整合内容：整合了两种地砖（2dm 和 3dm）的尺寸对比、单块面积计算、总面积计算、所需块数推导的完整过程
- 教学价值：教师可以通过分步演示，引导学生理解"总面积固定，单块面积越大，所需块数越少"的反比例核心概念，通过可视化对比强化面积计算和比例推理能力

[分步序列]
- 初始状态（步骤 0）：
  - 显示：左侧正方形、右侧正方形、左侧边长标签"2dm"、右侧边长标签"3dm"
  - 隐藏：所有面积标签、总面积标签、块数信息标签、反比例等式标签
  - 上一步按钮：禁用（灰色）
  - 下一步按钮：可用（蓝色）

- 步骤 1：点击「下一步」→
  - 新增显示：右侧面积标签"9dm²"（红高亮）、总面积标签"总面积=3600dm²"
  - 视觉变化：右侧正方形边框短暂闪烁高亮（表示正在计算）
  - 说明：展示 3dm 地砖单块面积=3×3=9dm²，总面积=9×400=3600dm²

- 步骤 2：点击「下一步」→
  - 新增显示：左侧面积标签"4dm²"（红高亮）
  - 视觉变化：左侧正方形边框短暂闪烁高亮（表示正在计算）
  - 说明：展示 2dm 地砖单块面积=2×2=4dm²

- 步骤 3（最终步骤）：点击「下一步」→
  - 新增显示：块数信息标签"需要 900 块"（绿高亮）、反比例等式标签"9×400=4×900=3600"
  - 视觉变化：两个正方形同时闪烁高亮，等式中的数字逐个高亮
  - 说明：验证反比例关系，9×400=3600，4×900=3600，总面积相等

[标签冲突检查]
- 标签"2dm"：坐标 (130,250)
- 标签"3dm"：坐标 (530,275)
- 标签"4dm²"：坐标 (150,320)
- 标签"9dm²"：坐标 (550,365)
- 标签"总面积=3600dm²"：坐标 (350,80)
- 标签"需要 900 块"：坐标 (350,410)
- 标签"9×400=4×900=3600"：坐标 (350,440)

冲突检查：
- "2dm"(130,250) 与 "4dm²"(150,320)：垂直距离 70px → 无冲突
- "3dm"(530,275) 与 "9dm²"(550,365)：垂直距离 90px → 无冲突
- "4dm²"(150,320) 与 "需要 900 块"(350,410)：水平距离 200px，垂直距离 90px → 无冲突
- "9dm²"(550,365) 与 "需要 900 块"(350,410)：水平距离 200px，垂直距离 45px → 无冲突
- "需要 900 块"(350,410) 与 "9×400=4×900=3600"(350,440)：垂直距离 30px → 无冲突（等式较长，上下间距足够）
- "总面积=3600dm²"(350,80) 与其他标签：垂直距离均>100px → 无冲突

结论：所有标签间距均≥20px，无冲突。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - scene1-btn-prev：位于控件栏左侧，点击返回上一步，步骤 0 时禁用
  - scene1-btn-next：位于控件栏右侧，点击进入下一步，始终可用
- 教师操作流程：
  1. 初始展示两种地砖尺寸，引导学生观察大小差异
  2. 点击下一步，计算 3dm 地砖面积和总面积，强调"总面积固定"
  3. 点击下一步，计算 2dm 地砖面积，对比两种地砖的单块面积
  4. 点击下一步，得出答案并验证反比例关系，强化"面积×块数=常数"的概念

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │                        总面积=3600dm²                        │  y=80
  │                                                             │
  │                                                             │
  │   ┌──────────┐                              ┌─────────────┐ │
  │   │          │                              │             │ │
  │2dm│          │                              │             │ │  y=200-350
  │   │          │                              │             │ │
  │   └──────────┘                              └─────────────┘ │
  │      4dm²                                    9dm²           │
  │                                                             │
  │                                                             │
  │                    需要 900 块                                │  y=410
  │                  9×400=4×900=3600                           │  y=440
  │          ┌─────────────────────────────────────┐            │
  │          │  ◀ 上一步      下一步 ▶              │            │  y=455-490
  │          └─────────────────────────────────────┘            │
  └─────────────────────────────────────────────────────────────┘
  ```

- 关键实现要点：
  1. 状态机设计：用变量 currentStep 记录当前步骤（0-3），根据步骤控制元素显示/隐藏
  2. 坐标计算：正方形边长按比例 2:3，左侧 100px，右侧 150px，垂直居中对齐
  3. 动画曲线：使用 CSS transition 实现边框闪烁高亮效果（0.3s ease）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateDisplay() 刷新视图
  5. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-left-square、scene1-btn-next）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染

- 元素显示控制逻辑：
  ```javascript
  function updateDisplay() {
    // 步骤 0：仅显示正方形和边长标签（默认显示）
    // 步骤 1：显示右侧面积标签、总面积标签
    // 步骤 2：显示左侧面积标签
    // 步骤 3：显示块数信息标签、反比例等式标签
    // 根据 currentStep 设置各元素的 display 属性
  }
  ```

- 按钮状态管理：
  - 步骤 0：prev 按钮 disabled=true，next 按钮 disabled=false
  - 步骤 1-2：prev 按钮 disabled=false，next 按钮 disabled=false
  - 步骤 3：prev 按钮 disabled=false，next 按钮 disabled=true（或循环回步骤 0）
