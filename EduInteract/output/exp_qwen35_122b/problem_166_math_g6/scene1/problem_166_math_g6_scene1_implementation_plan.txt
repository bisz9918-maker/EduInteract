[分步序列]
- 步骤0（初始状态）：
  - 显示：上下平行线、所有刻度及数字、三个图形轮廓（无填充）、图1/2/3编号标签、高h标注线及标签
  - 不显示：底边标注、面积公式、控件按钮（或按钮禁用）
  - 目的：展示题目基础图形，让学生先观察整体结构

- 步骤1（高亮图1）：
  - 视觉变化：图1三角形填充#1565c0透明度20%，图1编号标签加粗
  - 新增显示：图1底边标注"底边=2"在(220,375)，图1面积公式"面积=1/2×2×h=h"在(220,405)
  - 目的：引导学生观察第一个三角形的底边和面积计算

- 步骤2（高亮图2）：
  - 视觉变化：图1恢复无填充，图2平行四边形填充#1565c0透明度20%，图2编号标签加粗
  - 新增显示：图2底边标注"底边=1"在(400,375)，图2面积公式"面积=1×h=h"在(400,405)
  - 目的：引导学生观察平行四边形的底边和面积计算

- 步骤3（高亮图3）：
  - 视觉变化：图2恢复无填充，图3三角形填充#1565c0透明度20%，图3编号标签加粗
  - 新增显示：图3底边标注"底边=2"在(580,375)，图3面积公式"面积=1/2×2×h=h"在(580,405)
  - 目的：引导学生观察第三个三角形的底边和面积计算

- 步骤4（对比结论）：
  - 视觉变化：三个图形均无填充，图2平行四边形添加#c62828红色粗边框（线宽3）
  - 显示：所有底边标注和面积公式同时显示
  - 新增显示：结论标签"三个图形面积相等"在(400,435)
  - 目的：总结对比，强调等高图形面积与底边的关系

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：ID=scene1-btn-prev，位置(260,450)-(360,480)，点击返回上一步，步骤0时禁用
  - "下一步 ▶"按钮：ID=scene1-btn-next，位置(440,450)-(540,480)，点击进入下一步，步骤4时禁用
- 教师操作流程：
  1. 初始展示图形，让学生观察整体结构
  2. 点击"下一步"依次高亮每个图形，讲解底边长度和面积计算
  3. 最后展示对比结论，引导学生发现面积关系
  4. 可随时点击"上一步"回退复习某个图形的计算过程

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────┐
  │  上平行线 y=150                                         │
  │  刻度: 0   1   2   3   4   5                            │
  │      \  /      / \                                      │
  │       \/  2   /   \  3                                  │
  │      /  \    /     \                                    │
  │     / 1  \  /       \                                   │
  │  下平行线 y=350                                         │
  │  刻度: 0   1   2   3   4   5                            │
  │                                                         │
  │  底边标注: 底边=2  底边=1  底边=2                       │
  │  面积公式: 面积=h  面积=h  面积=h                       │
  │                                                         │
  │  高h标注线 | h                                          │
  │                                                         │
  │  [◀ 上一步]              [下一步 ▶]                     │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：currentStep变量记录当前步骤(0-4)，updateScene()函数根据currentStep更新显示
  2. 坐标计算：刻度单位=120px，上边y=150，下边y=350，高h=200px
  3. 动画曲线：使用CSS transition实现填充色渐变(0.3s ease)
  4. 事件绑定：按钮点击事件监听，更新currentStep后调用updateScene()
  5. 元素显示控制：通过setAttribute('display','none/block')或opacity控制
  6. 高亮效果：fill属性切换，stroke-width变化
- ID 命名规范：所有交互元素ID以scene1-为前缀（如scene1-tri1, scene1-btn-prev, scene1-btn-next）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局污染
