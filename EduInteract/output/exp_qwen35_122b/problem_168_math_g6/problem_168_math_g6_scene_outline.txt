    **题目原文：**
    图中的两个小圆的周长的和与大圆的周长比较，（  ）
    A．一样长    B．大圆的周长长    C．大圆的周长短    D．无法比较

    **题目分析：**
    本题考察圆的周长公式 C = πd 的应用，以及直径关系的观察。

    **核心知识点：**
    1. 圆的周长公式：C = πd（d 为直径）
    2. 从图中观察直径关系：两个小圆的直径之和等于大圆的直径
    3. 代数推导：πd₁ + πd₂ = π(d₁ + d₂) = πD

    **整体讲解思路：**
    1. 引导学生观察图形，识别大圆和两个小圆的直径关系
    2. 回顾圆的周长公式
    3. 通过代数推导得出结论
    4. 强调"周长与直径成正比"这一核心关系

    **图示规划说明：**
    设计 1 个场景，整合几何图形展示、直径标注、周长计算推导的完整认知过程。通过分步按钮导航，从直观图形到抽象公式，帮助学生逐步理解。

    **教学说明：**

    本图示通过分步交互，引导学生完成从直观观察到代数推导的完整思维过程。

    **步骤引导建议：**

    1. **步骤0（基础图形）**：让学生先观察图形，提问"你看到了什么？"引导学生识别大圆和两个小圆的位置关系。

    2. **步骤1（标注直径）**：点击后显示直径标注。提问"这三个直径之间有什么关系？"引导学生发现 d₁ + d₂ = D。

    3. **步骤2（周长公式）**：回顾圆的周长公式 C = πd。强调周长与直径成正比。

    4. **步骤3（高亮直径关系）**：用颜色高亮 d₁ + d₂ = D，强化这一关键观察。

    5. **步骤4（推导过程）**：展示代数推导：
    C₁ + C₂ = πd₁ + πd₂ = π(d₁ + d₂) = πD = C

    6. **步骤5（结论）**：用绿色高亮"一样长"，强调答案。

    **易错点提醒：**
    - 学生可能误以为大圆周长更长（因为看起来更大）
    - 需要强调周长只与直径有关，与"看起来大小"无关
    - 可以类比：把一根绳子剪成两段，总长度不变

    **完整解答：**
    设大圆直径为 D，两小圆直径分别为 d₁、d₂。
    由图可知：d₁ + d₂ = D
    大圆周长：C = πD
    两小圆周长和：C₁ + C₂ = πd₁ + πd₂ = π(d₁ + d₂) = πD
    因此：C₁ + C₂ = C
    答案：**A．一样长**
