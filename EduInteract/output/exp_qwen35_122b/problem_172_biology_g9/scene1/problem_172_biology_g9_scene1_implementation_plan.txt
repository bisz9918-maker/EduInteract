[分步序列]
- 初始状态（步骤0）：显示完整分类框架，所有框显示，①②③④显示为序号，选项区域隐藏
  - 顶层框、被动运输框（蓝高亮）、①框（红边框）、自由扩散框、②框（绿边框）、④框、氧气框、③框
  - 所有连接线显示
  - 选项区域隐藏

- 步骤1：点击「下一步」→ ①框内文字从"①"变为"主动运输"，红色高亮加强
  - 视觉变化：①框内容更新，提示学生这是需要推断的第一个未知项
  - 新增说明：主动运输特点（逆浓度梯度、消耗ATP）

- 步骤2：点击「下一步」→ ②框内文字从"②"变为"协助扩散"，绿色高亮加强
  - 视觉变化：②框内容更新，提示学生这是被动运输的另一种形式
  - 新增说明：协助扩散特点（顺浓度梯度、需载体、不消耗ATP）

- 步骤3：点击「下一步」→ 显示四个选项A/B/C/D，选项B用红高亮边框，其他选项灰色
  - 视觉变化：选项区域显示，选项B高亮显示为正确答案
  - 选项A：灰色，显示"①和②所示的过程都需要消耗ATP"
  - 选项B：红高亮，显示"只有①所示的过程能逆浓度梯度运输物质" ✓
  - 选项C：灰色，显示"大分子物质只有通过①过程才能进入细胞"
  - 选项D：灰色，显示"葡萄糖进入小肠上皮细胞与过程②有关"

- 教师操作流程：
  1. 初始展示分类框架，引导学生观察已知信息（被动运输、自由扩散）
  2. 点击下一步，揭示①=主动运输，讲解主动运输特点
  3. 点击下一步，揭示②=协助扩散，对比被动运输的两种形式
  4. 点击下一步，显示选项，引导学生分析每个选项，强调正确答案B

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何和文本，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────┐
  │                    物质跨膜运输方式                      │
  │                       ┌─────┐                          │
  │                       │ 顶层 │                          │
  │                       └──┬──┘                          │
  │          ┌───────────────┴───────────────┐             │
  │      ┌───┴───┐                       ┌───┴───┐         │
  │      │被动运输│                       │   ①   │         │
  │      └───┬───┘                       └───┬───┘         │
  │    ┌─────┴─────┐                         │             │
  │ ┌──┴──┐     ┌──┴──┐                   ┌──┴──┐         │
  │ │自由 │     │  ②  │                   │  ④  │         │
  │ │扩散 │     └──┬──┘                   └─────┘         │
  │ └──┬──┘        │                                       │
  │ ┌──┴──┐     ┌──┴──┐                                   │
  │ │氧气 │     │  ③  │                                   │
  │ └─────┘     └─────┘                                   │
  │                                                       │
  │  [选项A]              [选项B] ← 高亮                  │
  │  [选项C]              [选项D]                         │
  │                                                       │
  │        [◀上一步]        步骤 X/3        [下一步▶]     │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：currentStep 变量（0-3），updateScene() 函数根据 currentStep 更新显示
  2. 坐标计算：所有元素使用固定像素坐标，SVG 元素精确绘制
  3. 动画曲线：文字变化使用 opacity 淡入淡出效果（0.3s transition）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateScene()
  5. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-box-top、scene1-text-optionB）
  6. IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局污染
  7. 高亮效果：使用 CSS class 切换（scene1-highlight-red、scene1-highlight-blue、scene1-highlight-green）
  8. 选项显示：步骤3时设置选项元素 display="block"，之前为 display="none"
