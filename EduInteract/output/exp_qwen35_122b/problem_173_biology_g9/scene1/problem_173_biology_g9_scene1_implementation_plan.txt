[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：位于控件栏左侧 (220,455)-(340,485)，点击返回上一步骤，步骤 0 时禁用
  - "下一步 ▶"按钮：位于控件栏右侧 (460,455)-(580,485)，点击进入下一步骤，结论步骤时禁用

- 教师操作流程：
  1. 初始展示碳循环框架，让学生观察各成分位置
  2. 点击"下一步"逐步讲解每个碳流动路径及其生物学意义
  3. 每步讲解后可点击"上一步"回顾重点
  4. 最后展示结论，揭示甲=生产者、乙=分解者、丙=消费者，对应选项 A

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形和箭头，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    大气中的二氧化碳                      │
  │                      (320,40)                           │
  │            ↕ 光合作用/呼吸作用                           │
  │                                                         │
  │    甲                    ↕                    丙        │
  │  (80,180)              分解作用              (600,180)  │
  │    ↓                      ↑                    ↓        │
  │    ↓──────────────────────┼──────────────────→↓        │
  │              摄食关系      │                           │
  │                           ↓                            │
  │                        乙                              │
  │                      (320,340)                         │
  │                                                         │
  │  [生产者]              [分解者]              [消费者]   │
  │                                                         │
  │  ┌─────────────────────────────────────────────────┐   │
  │  │  ◀ 上一步        步骤 2/6         下一步 ▶      │   │
  │  └─────────────────────────────────────────────────┘   │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep 记录当前步骤（0-5），共 6 个状态
  2. 坐标计算：所有元素使用绝对坐标，箭头起点终点精确计算
  3. 箭头绘制：使用 SVG <line> 和 <path>（弧线），带箭头标记 <marker>
  4. 动画曲线：步骤切换时箭头颜色渐变（opacity 过渡 0.3s）
  5. 事件绑定：按钮点击事件更新 currentStep，调用 updateStep() 刷新显示
  6. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-node-jia、scene1-arrow-jia-to-yi）
  7. 使用 getElementById 获取元素，避免 querySelectorAll 全局污染
  8. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中
- 箭头标记定义：
  - 定义 <marker id="scene1-arrowhead"> 用于所有箭头末端
  - 箭头方向：根据起点终点计算，使用 SVG transform 旋转
- 弧线箭头：甲→丙使用 <path d="M 200,260 Q 400,320 600,260"> 贝塞尔曲线
