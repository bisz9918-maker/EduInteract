步骤2（刺激b点传导）：
- 新增：兴奋传导箭头1（蓝色，从b点(260,200)指向A-B突触(200,250)）
- 新增：兴奋传导箭头2（蓝色，从B-C突触(320,250)指向C神经元(380,220)）
- 高亮：b点（红色闪烁）
- 高亮：突触前膜A（红色高亮）→突触后膜B（绿色高亮）
- 高亮：突触前膜B（红色高亮）→突触后膜C（绿色高亮）
- 电流计指针：先向左偏转（兴奋到达a点），再向右偏转（兴奋到达d点）
- 说明：刺激b点，兴奋在B神经元上双向传导，经突触传递到C，电流计偏转2次

步骤3（刺激c点传导）：
- 新增：兴奋传导箭头3（蓝色，从c点(440,180)向右传导）
- 高亮：c点（红色闪烁）
- 电流计指针：仅向右偏转（兴奋只到达d点，不逆向通过突触到a点）
- 说明：刺激c点，兴奋在C神经元上传导，因突触单向传递，不能逆向传到B，电流计偏转1次

步骤4（传导总结）：
- 显示：所有兴奋传导箭头（步骤2和步骤3）
- 显示：所有突触膜标签
- 总结文字区域（底部控件区上方）：
  - ①图示结构包括3个神经元，含有2个突触（非3个突触）
  - ②刺激b点指针偏转2次，刺激c点指针偏转1次（非都偏转2次）
  - ③若B受刺激C兴奋，A、B同时刺激C不兴奋→A释放抑制性递质（正确）
  - ④递质与突触后膜受体结合，受体是糖蛋白（正确）
  - ⑤A、B是轴突末梢，C可能是树突或轴突（正确）
- 正确答案：D．③④

- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-4) 跟踪当前步骤
  2. 元素分组：每个步骤新增的元素用 group ID 标识，如 scene1-step1-groups、scene1-step2-arrows
  3. 坐标计算：所有坐标按布局坐标表精确实现
  4. 动画曲线：兴奋传导箭头使用 CSS transition 实现淡入效果（opacity 0→1）
  5. 电流计指针偏转：使用 transform: rotate() 实现指针旋转动画
  6. 事件绑定：按钮点击事件监听，更新 currentStep 并调用 updateScene() 刷新显示
  7. ID 命名规范：所有元素 ID 以 scene1- 为前缀，如 scene1-neuron-A、scene1-synapse-gap-AB
  8. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
