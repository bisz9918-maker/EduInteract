[分步序列]
- 初始状态（步骤 0）：显示完整突触结构（A、B、C 神经元轮廓，突触小泡，电流计，所有标签），状态说明区显示"请选择状态观察"，递质分子不显示，离子流不显示
- 步骤 1（状态 1：B 单独刺激）：点击「状态 1」按钮 → B 神经元高亮#2e7d32，B 突触小泡释放蓝色兴奋性递质（小圆点从 B 移向 C），C 突触后膜出现绿色 Na+ 内流箭头，C 神经元膜电位变为内正外负（+/- 符号变化），状态说明区显示"状态 1：刺激 B→兴奋性递质释放→Na+内流→C 兴奋"，电流计指针向右偏转
- 步骤 2（状态 2：A+B 同时刺激）：点击「状态 2」按钮 → A 神经元高亮#c62828，A 突触小泡释放红色抑制性递质（小圆点从 A 移向 B），B 突触后膜出现红色 Cl-内流箭头，B 神经元超极化，B 突触小泡不释放递质，C 神经元保持静息电位，电流计指针不偏转，状态说明区显示"状态 2：A+B 同时刺激→A 释放抑制性递质→B 超极化→C 不兴奋"
- 步骤 3（状态 3：机制总结）：点击「状态 3」按钮 → A→B 突触用红色虚线框高亮并标注"抑制性突触"，B→C 突触用绿色虚线框高亮并标注"兴奋性突触"，状态说明区显示"机制总结：抑制性递质使突触后膜超极化，阻断兴奋传递"，所有递质分子和离子流消失

[交互方案]
- 交互类型：多状态切换（3 个状态按钮）
- 控件说明：
  - 按钮「状态 1」：位置 (200,440)，点击显示 B 单独刺激的效果
  - 按钮「状态 2」：位置 (350,440)，点击显示 A+B 同时刺激的效果
  - 按钮「状态 3」：位置 (500,440)，点击显示机制总结
- 教师操作流程：
  1. 初始展示突触结构，讲解 A、B、C 三个神经元及两个突触
  2. 点击「状态 1」，演示 B 单独刺激时兴奋性递质释放、Na+内流、C 兴奋的过程
  3. 点击「状态 2」，对比演示 A+B 同时刺激时抑制性递质阻断兴奋传递的现象
  4. 点击「状态 3」，总结抑制性递质的作用机制

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    抑制性递质作用机制                    │  y=20
  │                                                         │
  │              ┌───────────┐                              │  y=80 电流计
  │              │   电流计   │                              │
  │              └───────────┘                              │
  │                 │     │                                 │
  │       a●────────┘     └────────●d                       │  y=230
  │         │                       │                       │
  │         │    b↑      c↑         │                       │  y=160 刺激点
  │         │    ↓        ↓         │                       │
  │    ┌────┴────┐    ┌──┴──┐    ┌──┴──┐                   │
  │    │   B     │────│ 突触 │────│  C  │                   │  y=230
  │    └────┬────┘    └─────┘    └─────┘                   │
  │         │                                               │
  │    ┌────┴────┐                                          │
  │    │   A     │                                          │  y=350
  │    └─────────┘                                          │
  │                                                         │
  │  ┌───────────────────────────────────────────────────┐  │  y=380
  │  │              状态说明区                            │  │
  │  └───────────────────────────────────────────────────┘  │
  │  [状态 1]        [状态 2]        [状态 3]                │  y=440 控件区
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStatus (0/1/2/3) 跟踪当前状态
  2. 坐标计算：所有元素用绝对坐标，递质分子动画用 requestAnimationFrame 实现
  3. 动画曲线：递质分子从突触前膜到突触后膜用线性插值
  4. 事件绑定：三个按钮分别绑定 click 事件，切换状态并更新显示
  5. ID 命名规范：所有元素 ID 以"scene2-"为前缀（如 scene2-neuron-a、scene2-btn-state1）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中
  7. 状态切换时清除上一状态的动画元素（递质分子、离子流箭头）
  8. 电流计指针偏转用 transform: rotate() 实现，状态 1 偏转 15°，状态 2 不偏转
