[分步序列]
- 步骤 0（初始状态）：
  - 左侧显示图甲染色体结构轮廓（未标注，灰色#888888 细线）
  - 右侧显示图乙三个同心圆轮廓（未标注，灰色#888888 细线）
  - 底部选项分析区空白
  - 等待教师点击"下一步"

- 步骤 1：
  - 图甲中标注 [1] 染色体（X 形结构）高亮为#1565c0，显示标签 [1] 和"染色体"
  - 图甲中标注 [2] 蛋白质（球状）高亮为#888888，显示标签 [2] 和"蛋白质"
  - 图甲中标注 [3]DNA（双螺旋）高亮为#2e7d32，显示标签 [3] 和"DNA"
  - 图甲中标注 [4] 基因（DNA 片段）高亮为#c62828，显示标签 [4] 和"基因"
  - 图乙三个同心圆仍为轮廓状态
  - 底部选项分析区空白

- 步骤 2：
  - 图乙同心圆①填充#1565c0 15% 透明度，显示标签①和"染色体"
  - 图乙同心圆②填充#2e7d32 15% 透明度，显示标签②和"DNA"
  - 图乙同心圆③填充#c62828 15% 透明度，显示标签③和"基因"
  - 显示连接箭头：[1]→①（虚线#888888）
  - 显示连接箭头：[3]→②（虚线#888888）
  - 显示连接箭头：[4]→③（虚线#888888）

- 步骤 3：
  - 高亮显示关键包含关系：
  - 在图甲中，用#1565c0 粗框包围 [1] 染色体，显示文字"包含 [2] 和 [3]"
  - 在图甲中，用#2e7d32 粗框包围 [3]DNA，显示文字"包含 [4]"
  - 在图乙中，用#1565c0 粗边框强调①包含②，用#2e7d32 粗边框强调②包含③

- 步骤 4（最终步骤）：
  - 底部选项分析区显示四个选项：
  - A. 图甲中的 [3] 和 [4] 都含有特定的遗传信息 ✓
  - B. 具有遗传效应的 [2] 的片段叫基因 ✗（红框#c62828 粗边框标记）
  - C. 图乙中的①可以表示图甲中的 [1] ✓
  - D. 每种生物细胞内 [1] 的形态与数目都是一定的 ✓
  - 在 B 选项旁显示纠正说明："正确表述：具有遗传效应的 [3]DNA 的片段叫基因"
  - 图甲 [2] 蛋白质用#888888 虚线框标记，显示"蛋白质不含遗传信息"

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮：scene1-btn-prev，位置 (320,460)，作用：返回上一步骤
  - 下一步按钮：scene1-btn-next，位置 (460,460)，作用：进入下一步骤
  - 步骤指示器：scene1-step-indicator，位置 (370,430)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始展示空白结构，引导学生观察整体布局
  2. 点击下一步，逐步标注图甲各结构，讲解染色体、DNA、蛋白质、基因的定义
  3. 点击下一步，展示图乙集合关系，建立图甲与图乙的概念对应
  4. 点击下一步，高亮包含关系，强化层次认知
  5. 点击下一步，显示选项分析，引导学生判断错误选项并理解原因

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何和动画，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │ 图甲标题                    图乙标题                            │
  │  [1]染色体                    ①染色体                          │
  │    ╱╲                        ╭─────╮                           │
  │   ╱  ╲                       │  ②  │                           │
  │  ╱____╲                      │ ╭─╮ │                           │
  │                            │ │③│ │                           │
  │  [3]DNA                    │ ╰─╯ │                           │
  │  ~~~~~~~~                   │     │                           │
  │                            ╰─────╯                           │
  │  [2]蛋白质  ●                                                    │
  │  [4]基因    ~~~~                                                 │
  │                                                                  │
  │  步骤指示器：步骤 1/5                                            │
  │  [◀上一步]  [下一步▶]                                            │
  └────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量（0-4）跟踪当前步骤，每个步骤对应一个状态对象，包含该步骤应显示/高亮的元素 ID 列表
  2. 坐标计算：所有元素使用绝对坐标，通过 SVG 的 x/y/cx/cy/r 属性精确控制位置
  3. 动画曲线：使用 SVG 的 opacity 和 stroke-width 属性实现淡入淡出和高亮效果，transition 时长 300ms
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateScene() 函数刷新显示
  5. ID 命名规范：所有元素 ID 以 scene1-为前缀，如 scene1-chromosome、scene1-circle1、scene1-btn-prev 等
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染
  7. 选项显示：步骤 4 的选项分析使用 SVG 的 text 元素，动态更新 textContent，错误选项添加 rect 边框元素
