[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 按钮"◀上一步"：位置(300, 455)，作用：返回上一状态，第一步时禁用
  - 按钮"下一步▶"：位置(400, 455)，作用：进入下一状态，最后一步时变为"完成"
  - 按钮"重置"：位置(450, 455)，作用：返回初始状态
- 教师操作流程：
  1. 初始展示杂交图谱，引导学生观察现象
  2. 点击下一步，揭示显隐性判断依据（过程③性状分离）
  3. 点击下一步，标注各代基因型
  4. 点击下一步，展示比例计算过程
  5. 点击下一步，分析选项，标出错误选项D

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │  P代：黄花 × 白花                                       │
  │       │           │                                     │
  │       └────①─────┘                                     │
  │                  │           │                          │
  │  F₁代：黄花     白花                                    │
  │       │           │                                    │
  │       ②           ③                                    │
  │       │         ╱   ╲                                  │
  │  F₂代：黄花   黄花   白花                              │
  │                                                         │
  │  [基因型标注框]  [比例计算框]                          │
  │                                                         │
  │  [选项分析区：A✓ B✓ C✓ D✗]                            │
  │                                                         │
  │            [◀上一步] [下一步▶] [重置]                  │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用currentStep变量(0-4)跟踪当前步骤，steps数组存储每步应显示/高亮的元素ID列表
  2. 坐标计算：所有元素使用绝对定位，SVG元素用x/y属性，文本用text-anchor="middle"居中
  3. 动画曲线：元素出现使用opacity从0到1的过渡动画(transition: opacity 0.3s)
  4. 事件绑定：按钮点击事件监听，更新currentStep后调用updateDisplay()函数
  5. ID命名规范：所有元素ID以"scene1-"为前缀，如scene1-p-yellow、scene1-arrow-1、scene1-btn-next
  6. IIFE隔离：所有JS代码包裹在(function() { ... })()中，避免全局变量污染
  7. 基因型框显示：用display属性控制显示/隐藏，配合opacity过渡
  8. 高亮效果：通过添加/移除CSS类(highlight-blue、highlight-red)实现边框颜色变化
