[分步序列]
步骤0（初始状态）：
- 显示：完整装置结构（试管1、试管2、导管、水平管、呼吸口M、夹子X、夹子Y）
- 夹子状态：X和Y均为灰色（关闭状态）
- 液体状态：两试管石灰水均为浅蓝色透明（#b3d9ff，20%透明度）
- 箭头：不显示
- 目的：展示装置整体结构，让学生熟悉各组件位置

步骤1（吸气过程）：
- 显示：步骤0所有元素 + 吸气路径箭头（蓝色）
- 夹子状态：夹子X变为绿色（开启），夹子Y保持灰色（关闭）
- 吸气路径：外界空气→试管1长导管→试管1短导管→水平管→呼吸口M
- 箭头序列：(40,100)→(120,100)→(130,100)→(130,230)→(130,100)→(150,100)→(150,180)→(400,120)
- 液体状态：试管1石灰水保持澄清（浅蓝色）
- 标签：在吸气路径旁显示"吸气"文字（蓝色）
- 目的：展示吸气时气体流向，理解夹子X开启、Y关闭的通路

步骤2（呼气过程）：
- 显示：步骤0所有元素 + 呼气路径箭头（红色）
- 夹子状态：夹子X变为灰色（关闭），夹子Y变为绿色（开启）
- 呼气路径：呼吸口M→水平管→试管2长导管→试管2短导管→外界
- 箭头序列：(400,120)→(660,120)→(650,100)→(650,230)→(650,100)→(670,100)→(670,180)→(720,100)
- 液体状态：试管1石灰水保持澄清，试管2石灰水开始变化
- 标签：在呼气路径旁显示"呼气"文字（红色）
- 目的：展示呼气时气体流向，理解夹子X关闭、Y开启的通路

步骤3（实验现象）：
- 显示：步骤0所有元素 + 最终状态
- 夹子状态：恢复初始（X、Y均为灰色）
- 箭头：不显示
- 液体状态：试管1石灰水保持浅蓝色澄清，试管2石灰水变为乳白色浑浊（#e8e8e8，60%透明度）
- 标签：试管1旁显示"澄清"（绿色），试管2旁显示"浑浊"（红色）
- 目的：对比展示实验结果，理解吸入气与呼出气CO2含量差异

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮（scene1-prev-btn）：位于控件栏左侧(220,450)，点击返回前一步骤
  - 下一步按钮（scene1-next-btn）：位于控件栏右侧(480,450)，点击进入下一步骤
  - 步骤指示器：显示当前步骤（如"步骤 1/3"）
- 教师操作流程：
  1. 初始展示装置结构，讲解各组件名称和功能
  2. 点击"下一步"进入吸气过程，讲解吸气时气体流向和夹子状态
  3. 点击"下一步"进入呼气过程，讲解呼气时气体流向和夹子状态
  4. 点击"下一步"进入实验现象，对比展示结果并解释原因
  5. 可随时点击"上一步"回退复习某个步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何和状态切换，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    800 × 500 画布                        │
  │                                                         │
  │   夹子X          M           夹子Y                       │
  │    │││           │           │││                        │
  │   ─┴┴────────────┴───────────┴┴─  顶部水平管              │
  │   ││             │           ││                         │
  │  ┌┴┐            │           ┌┴┐                        │
  │  │ │ 试管1       │           │ │ 试管2                   │
  │  │ │  ┌─────┐   │           │ │  ┌─────┐                │
  │  │ │  │石灰水│   │           │ │  │石灰水│                │
  │  │ │  └─────┘   │           │ │  └─────┘                │
  │  └┬┘            │           └┬┘                        │
  │   ││             │           ││                         │
  │  试管1           │           试管2                       │
  │                                                         │
  │          [◀ 上一步]    步骤 1/3    [下一步 ▶]            │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量（0-3）跟踪当前步骤
  2. 元素显示控制：通过 CSS display 或 opacity 控制各步骤元素的显示/隐藏
  3. 夹子状态切换：通过 fill 颜色变化（绿色#2e7d32 开启，灰色#888888 关闭）
  4. 液体状态切换：通过 fill 颜色变化（浅蓝#b3d9ff 澄清，乳白#e8e8e8 浑浊）
  5. 箭头动画：使用 CSS transition 实现箭头渐显效果
  6. 按钮禁用状态：步骤0禁用"上一步"，步骤3禁用"下一步"
  7. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-testtube1, scene1-clip-x, scene1-arrow-inhale）
  8. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  9. 事件绑定：使用 addEventListener 绑定按钮点击事件
  10. 步骤指示器：动态更新显示当前步骤编号
