[图示主题与整合说明]
- 本图示主题：地表三圈环流剖面图（从赤道到北极）
- 整合内容：整合低纬环流、中纬环流、高纬环流的完整结构；气压带（赤道低气压带、副热带高气压带、副极地低气压带、极地高气压带）的位置识别；风带（信风带、西风带、极地东风带）的方向标注；热力成因与动力成因的对比
- 教学价值：教师可逐步展示三圈环流的形成过程，从基础框架到气压带风带命名，再到成因分析，帮助学生理解大气环流的完整机制

[分步序列]
步骤0（初始状态 - 基础框架）：
- 显示：地球表面弧线、4条纬度辅助线、4个气压带位置点（A,C,E,N）、纬度标注（0°,30°,60°,90°）
- 隐藏：所有环流圈、所有风带箭头、所有气压带标签、所有风带标签、成因标注
- 目的：展示基础地理框架，让学生先识别各纬度位置

步骤1（标注气压带）：
- 新增显示：标签A（赤道低气压带）、标签C（副热带高气压带）、标签E（副极地低气压带）、标签N（极地高气压带）
- 保持显示：步骤0所有元素
- 目的：识别四个主要气压带的位置和名称

步骤2（标注风带及风向）：
- 新增显示：风带B箭头及标签（东北信风带）、风带D箭头及标签（盛行西风带）、风带F箭头及标签（极地东风带）
- 保持显示：步骤1所有元素
- 目的：展示近地面风带的分布和风向

步骤3（环流圈高亮）：
- 新增显示：低纬环流圈（0°-30°）、中纬环流圈（30°-60°）、高纬环流圈（60°-90°）
- 保持显示：步骤2所有元素
- 目的：展示完整的三圈环流结构，理解垂直气流运动

步骤4（成因标注 - 最终状态）：
- 新增显示：热力成因标注（对应A赤道低气压带和N极地高气压带）、动力成因标注（对应C副热带高气压带和E副极地低气压带）
- 保持显示：步骤3所有元素
- 目的：总结气压带的成因类型，区分热力成因和动力成因

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮：ID=scene1-btn-prev，位置(250,460)，作用：返回上一状态
  - 下一步按钮：ID=scene1-btn-next，位置(450,460)，作用：进入下一状态
  - 步骤指示器：ID=scene1-step-indicator，位置(350,440)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始展示基础框架，引导学生识别赤道到北极的纬度分布
  2. 点击"下一步"展示气压带，讲解各气压带位置
  3. 点击"下一步"展示风带，讲解风向与气压带关系
  4. 点击"下一步"展示环流圈，讲解垂直气流运动
  5. 点击"下一步"展示成因，总结热力/动力成因区别
  6. 可随时点击"上一步"回退复习

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    图示区 800×500                       │
  │                                                         │
  │     高纬环流圈        中纬环流圈        低纬环流圈       │
  │        ↻                ↺                ↻              │
  │       F↑              D↑              B↑               │
  │    N●──────────────E●──────────────C●──────────────A●  │
  │   90°              60°              30°              0° │
  │                                                         │
  │  热力成因        动力成因                               │
  │                                                         │
  │          [◀上一步]  步骤 X/5  [下一步▶]                │
  │          (控件栏 y=440~490)                            │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量（0-4）跟踪当前步骤，每一步定义 showElements 和 hideElements 数组
  2. 坐标计算：所有元素使用绝对坐标，环流圈用 SVG path 的闭合箭头路径实现
  3. 动画曲线：元素出现使用 opacity 渐变（0→1，duration=300ms）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateScene() 刷新显示
  5. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-arc-earth, scene1-point-A, scene1-loop-low 等）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 环流圈实现：使用 SVG path 元素，d 属性定义闭合路径，末尾添加箭头标记（marker-end）
  8. 风带箭头：使用 SVG line + 箭头标记，或 path 绘制带箭头的线段
