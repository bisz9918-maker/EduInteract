    **题目原文：**
    如图为世界经纬网示意图．读图回答以下问题。(12分)

    (1)若某日A点和B点的正午太阳高度相同，则太阳直射点位于____(纬度)，A点位于 B点的___方向。
    (2)如果一架飞机从B点上空于地方时12：00出发向北飞行，3小时后到达C点上空。飞机飞行距离约(   )
     A．2580千米    B．3330千米    C．6660千米    D．2266千米
    (3)若另一架飞机同时以相同的速度从D点上空开始沿纬线向E点上空飞行．则该飞机全程飞行需要________小时．到达E地上空时，E地的地方时为________________。
    (4)若A点某日昼夜平分，且时刻为14 :00，在图中用阴影画出这一时刻夜半球的范围。

    **题目分析：**
    本题综合考查经纬网的核心知识点：
    1. 正午太阳高度与太阳直射点的关系（对称性原理）
    2. 纬度距离计算（1°纬度≈111km）
    3. 纬线长度与经度距离计算（随纬度变化）
    4. 地方时计算与夜半球范围判定

    **整体讲解思路：**
    通过四个递进式图示，帮助学生建立"读图→定位→计算→应用"的完整认知链条。首先明确各点坐标，然后分别讲解正午太阳高度对称性、距离计算、地方时计算，最后综合应用绘制夜半球范围。

    **图示规划说明：**
    - Scene 1：经纬网基础与点位标注（建立空间认知）
    - Scene 2：正午太阳高度对称性演示（核心概念可视化）
    - Scene 3：距离计算对比演示（经线距离 vs 纬线距离）
    - Scene 4：地方时与夜半球范围（综合应用）

    **Scene 1 教学说明：**

    本图示用于帮助学生建立经纬网的空间认知框架。教师应按以下步骤引导：

    1. **初始状态引导**：展示空白经纬网，提问"这是什么类型的地图？如何确定地球上任意一点的位置？"引导学生回忆经纬度概念。

    2. **刻度标注讲解**：
    - 经度：从0°经线（本初子午线）向东为东经(E)，向西为西经(W)，最大180°
    - 纬度：从0°纬线（赤道）向北为北纬(N)，向南为南纬(S)，最大90°

    3. **点位定位训练**：逐个高亮点位，让学生先尝试读出坐标，再显示答案验证：
    - A点：60°W, 30°N（西经60度，北纬30度）
    - B点：0°, 30°S（本初子午线，南纬30度）
    - C点：0°, 0°（赤道与本初子午线交点）
    - D点：60°E, 60°N（东经60度，北纬60度）
    - E点：120°E, 60°N（东经120度，北纬60度）

    4. **空间关系强化**：最后展示全部点位，引导学生观察：
    - C点是原点，B点在C点正南方
    - D、E两点在同一纬线（60°N）上
    - A、C两点在同一经线（60°W vs 0°）的相对位置

    **关键公式提醒**：
    - 纬度差1°≈111千米（经线距离恒定）
    - 经度差1°的纬线距离=111×cos(纬度)千米（随纬度升高而缩短）

    **Scene 2 教学说明：**

    本图示用于讲解正午太阳高度的对称性原理，这是本题第(1)问的核心考点。

    1. **原理引入**：
    正午太阳高度计算公式：H = 90° - |φ - δ|
    其中φ为当地纬度，δ为太阳直射点纬度

    2. **对称性演示**：
    - 当太阳直射赤道(δ=0°)时：
    - A点(30°N)：HA = 90° - |30° - 0°| = 60°
    - B点(30°S)：HB = 90° - |-30° - 0°| = 60°
    - 两点高度相等！

    3. **规律发现**：
    引导学生拖动滑块观察：只有当太阳直射赤道(0°)时，A、B两点（纬度数值相等、南北半球对称）的正午太阳高度才相等。

    4. **方向判断**：
    - A点(60°W, 30°N) vs B点(0°, 30°S)
    - 经度：A在西(60°W)，B在东(0°) → A在B的西方
    - 纬度：A在北(30°N)，B在南(30°S) → A在B的北方
    - 综合：A在B的**西北方向**

    5. **答案确认**：
    - 太阳直射点位于 **0°(赤道)**
    - A点位于B点的 **西北** 方向

    **Scene 3 教学说明：**

    本图示用于讲解第(2)、(3)问的距离与时间计算，重点区分经线距离和纬线距离的计算方法。

    **第(2)问讲解（B→C距离）：**

    1. **路径分析**：
    - B点(0°, 30°S) → C点(0°, 0°)
    - 沿0°经线向北飞行
    - 纬度差 = 0° - (-30°) = 30°

    2. **经线距离公式**：
    经线上纬度差1°≈111千米（恒定）
    距离 = 纬度差 × 111 = 30 × 111 = **3330千米**

    3. **答案选择**：**B．3330千米**

    **第(3)问讲解（D→E飞行时间）：**

    1. **路径分析**：
    - D点(60°E, 60°N) → E点(120°E, 60°N)
    - 沿60°N纬线向东飞行
    - 经度差 = 120° - 60° = 60°

    2. **纬线距离公式**：
    纬线上经度差1°的距离 = 111 × cos(纬度) 千米
    距离 = 经度差 × 111 × cos(60°) = 60 × 111 × 0.5 = **3330千米**

    3. **速度计算**：
    从第(2)问知：速度 = 距离÷时间 = 3330km ÷ 3h = **1110 km/h**

    4. **时间计算**：
    D→E时间 = 距离÷速度 = 3330km ÷ 1110km/h = **3小时**

    5. **地方时计算**：
    - B点出发时地方时12:00
    - D点与B点经度差 = 60°E - 0° = 60°
    - 地方时差 = 60° ÷ 15°/h = 4小时（D点在东，时间早）
    - D点出发时地方时 = 12:00 + 4:00 = 16:00
    - 飞行3小时后，E地地方时 = 16:00 + 3:00 = **19:00**

    **答案汇总**：
    - 飞行需要 **3** 小时
    - E地地方时为 **19:00**

    **Scene 4 教学说明：**

    本图示用于讲解第(4)问，综合应用昼夜平分、地方时、晨昏线等知识点。

    **条件分析**：
    - A点昼夜平分 → 太阳直射赤道（春秋分）
    - A点时刻为14:00

    **推理过程**：

    1. **昼夜平分的含义**：
    - 全球各地昼夜等长（各12小时）
    - 晨昏线与经线重合
    - 晨线地方时=6:00，昏线地方时=18:00

    2. **晨线位置计算**：
    - A点(60°W)时刻=14:00
    - 晨线时刻=6:00
    - 时间差=14:00-6:00=8小时
    - 经度差=8h×15°/h=120°
    - 晨线在A点西侧（时间晚）
    - 晨线经度=60°W+120°=180°经线

    3. **昏线位置计算**：
    - 昏线时刻=18:00
    - 时间差=18:00-14:00=4小时
    - 经度差=4h×15°/h=60°
    - 昏线在A点东侧（时间早）
    - 昏线经度=60°W-60°=120°W... 等等，重新计算：
    - 昏线在A点东侧6小时=90°
    - 昏线经度=60°W向西90°=30°E（或60°W+90°=30°E，向东为正）

    更正：
    - A点(60°W)为14:00
    - 昏线(18:00)在A点东侧4小时=60°
    - 昏线经度=60°W向东60°=0°经线

    重新计算晨线：
    - 晨线(6:00)在A点西侧8小时=120°
    - 晨线经度=60°W向西120°=180°经线

    4. **夜半球范围**：
    - 夜半球=晨线到昏线之间（按地球自转方向）
    - 从180°经线向东到0°经线（或从180°向西到0°）
    - 即：180°→120°W→60°W→0° 这一半为夜半球

    **作图要点**：
    - 用阴影填充180°经线向东至0°经线之间的区域
    - 阴影应覆盖整个经度范围（从北极到南极）
    - 晨昏线用实线清晰标注

    **完整答案汇总**：
    (1) 太阳直射点位于 **0°**，A点位于B点的 **西北** 方向
    (2) **B．3330千米**
    (3) **3** 小时，E地地方时为 **19:00**
    (4) 夜半球范围：从180°经线向东至0°经线（或从0°经线向西至180°经线）的区域，用阴影填充
