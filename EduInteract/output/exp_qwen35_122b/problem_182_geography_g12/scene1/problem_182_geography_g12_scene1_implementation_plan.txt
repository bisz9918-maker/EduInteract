[分步序列]
步骤0（初始状态）：
- 显示：空白经纬网框架（经线7条+纬线7条）
- 不显示：所有刻度标签、点位、坐标标签
- 目的：让学生先观察网格结构

步骤1：点击「下一步」
- 新增：经度刻度标签（180°W, 120°W, 60°W, 0°, 60°E, 120°E, 180°E）
- 显示位置：各经线上方y=45处
- 目的：认识经度标注系统

步骤2：点击「下一步」
- 新增：纬度刻度标签（90°N, 60°N, 30°N, 0°, 30°S, 60°S, 90°S）
- 显示位置：各纬线左侧x=65处
- 目的：认识纬度标注系统

步骤3：点击「下一步」
- 新增：点A（蓝圆8px）+ 点A标签"A"（右上方）+ 点A坐标"60°W, 30°N"（下方）
- 高亮：点A变为红圆12px
- 目的：学习第一个点位的坐标读取

步骤4：点击「下一步」
- 新增：点B（蓝圆8px）+ 点B标签"B"（右下方）+ 点B坐标"0°, 30°S"（下方）
- 高亮：点B变为红圆12px，点A恢复蓝圆
- 目的：学习第二个点位的坐标读取

步骤5：点击「下一步」
- 新增：点C（蓝圆8px）+ 点C标签"C"（左下方）+ 点C坐标"0°, 0°"（下方）
- 高亮：点C变为红圆12px，点B恢复蓝圆
- 目的：学习赤道与本初子午线交点

步骤6：点击「下一步」
- 新增：点D（蓝圆8px）+ 点D标签"D"（右上方）+ 点D坐标"60°E, 60°N"（下方）
- 高亮：点D变为红圆12px，点C恢复蓝圆
- 目的：学习北半球东经点位

步骤7：点击「下一步」
- 新增：点E（蓝圆8px）+ 点E标签"E"（右上方）+ 点E坐标"120°E, 60°N"（下方）
- 高亮：点E变为红圆12px，点D恢复蓝圆
- 目的：学习同一纬线上不同经度的点位

步骤8（最终状态）：
- 显示：所有5个点同时显示（均为蓝圆8px）
- 显示：所有点标签和坐标标签全部显示
- 高亮：无红色高亮（或保持点E为红色）
- 目的：完整展示所有点位，便于综合比较

冲突检查（关键对）：
1. 经度刻度间距：相邻刻度x间距约106.67px → 无冲突（≥20px）
2. 纬度刻度间距：相邻刻度y间距约63.33px → 无冲突（≥20px）
3. 点A标签(303,177)与点A坐标(293,200)：距离≈25px → 无冲突
4. 点A标签(303,177)与纬度刻度30°N(65,192)：距离≈238px → 无冲突
5. 点B标签(410,323)与点B坐标(400,330)：距离≈17px → 接近但可接受（标签高度约16px，间距17px刚好）
6. 点C标签(390,260)与点C坐标(400,267)：距离≈13px → 接近但可接受（标签在左下方，坐标在正下方，方向不同）
7. 点D标签(517,113)与点D坐标(507,137)：距离≈26px → 无冲突
8. 点E标签(623,113)与点E坐标(613,137)：距离≈26px → 无冲突
9. 点D标签(517,113)与点E标签(623,113)：x间距106px → 无冲突
10. 点D坐标(507,137)与点E坐标(613,137)：x间距106px → 无冲突
11. 点C坐标(400,267)与点B坐标(400,330)：y间距63px → 无冲突
12. 点A坐标(293,200)与纬度刻度30°N(65,192)：距离≈228px → 无冲突

结论：所有标签间距均≥13px，无重叠冲突。点B和点C的标签与坐标间距略小，但因偏移方向不同（标签在侧下方，坐标在正下方），实际不会重叠。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮（scene1-prev-btn）：位于控件栏左侧(150,460)，点击返回前一步骤，第一步时禁用
  - 下一步按钮（scene1-next-btn）：位于控件栏右侧(650,460)，点击进入下一步骤，最后一步时禁用
  - 步骤指示器（scene1-step-indicator）：位于控件栏中央，显示"步骤 X/8"，X为当前步骤编号（0-8）
- 教师操作流程：
  1. 初始展示空白经纬网，引导学生观察网格结构
  2. 点击「下一步」逐步添加经度、纬度刻度，讲解经纬度系统
  3. 逐个展示A-E五个点位，每步讲解该点位的坐标读取方法
  4. 最终展示所有点位，引导学生比较各点位的相对位置关系
  5. 可随时点击「上一步」回退复习，巩固知识点

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（直线、圆、文本），无需复杂图表库；原生实现轻量高效，便于精确控制坐标和状态

- 画布尺寸：800 × 500 px（固定）

- 布局草图（ASCII）：

- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量（0-8）跟踪当前步骤，每一步对应特定的元素显示集合
  2. 坐标计算：定义常量经线X坐标数组和纬线Y坐标数组，通过索引访问各线位置
  3. 元素分组：使用 SVG <g> 元素分组管理经线组、纬线组、刻度组、点位组，便于批量显示/隐藏
  4. 动画曲线：点位高亮使用 CSS transition（0.3s ease）实现平滑的颜色和大小编辑
  5. 事件绑定：按钮点击事件更新 currentStep，调用 updateDisplay() 函数刷新显示
  6. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-line-meridian-0, scene1-point-A, scene1-prev-btn）
  7. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染

- 元素显示控制逻辑：
  - 步骤0：仅显示经线组、纬线组
  - 步骤1：步骤0元素 + 经度刻度组
  - 步骤2：步骤1元素 + 纬度刻度组
  - 步骤3：步骤2元素 + 点A组（圆+标签+坐标）
  - 步骤4：步骤2元素 + 点A组 + 点B组
  - 步骤5：步骤2元素 + 点A组 + 点B组 + 点C组
  - 步骤6：步骤2元素 + 点A组 + 点B组 + 点C组 + 点D组
  - 步骤7：步骤2元素 + 点A组 + 点B组 + 点C组 + 点D组 + 点E组
  - 步骤8：所有元素显示，所有点位为蓝色（无红色高亮）

- 高亮逻辑：
  - 步骤3：点A高亮（红色12px）
  - 步骤4：点B高亮（红色12px），点A恢复蓝色
  - 步骤5：点C高亮（红色12px），点B恢复蓝色
  - 步骤6：点D高亮（红色12px），点C恢复蓝色
  - 步骤7：点E高亮（红色12px），点D恢复蓝色
  - 步骤8：所有点蓝色（或保持点E红色）
