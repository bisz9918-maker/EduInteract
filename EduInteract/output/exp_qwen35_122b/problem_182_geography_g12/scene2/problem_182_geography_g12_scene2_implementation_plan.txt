[图示主题与整合说明]
- 本图示主题：正午太阳高度对称性原理与太阳直射点判定
- 整合内容：太阳直射点位置、A/B 两点正午太阳高度相等条件、方向判断
- 教学价值：教师可通过拖动滑块改变太阳直射点纬度，让学生直观观察 A、B 两点正午太阳高度的变化规律，发现"当两点正午太阳高度相同时，太阳直射点位于两点纬度的中间位置"这一规律，同时结合经纬网进行方向判断练习

[分步序列]
本场景为连续拖拽交互，无分步导航，状态由滑块位置实时决定：

- 初始状态（滑块在中间，直射赤道 0°）：
  - 太阳直射点位于赤道 (350,260)
  - HA = 60°（A 点纬度 30°N，直射 0°，H = 90° - |30-0| = 60°）
  - HB = 60°（B 点纬度 30°S，直射 0°，H = 90° - |30-0| = 60°）
  - HA = HB，太阳直射点高亮显示（红色圆环加粗）
  - 方向箭头显示，标注"A 在 B 的西北方向"

- 拖动过程中（滑块向左/右移动）：
  - 太阳直射点随滑块同步移动（y 坐标映射：滑块 x=50→直射点 y=380(-23.5°)，滑块 x=200→直射点 y=140(+23.5°)）
  - HA、HB 数值实时更新
  - 当 HA ≈ HB（差值<1°）时，自动高亮直射点位置

- 最终状态（任意位置）：
  - 显示当前直射点纬度
  - 显示 HA、HB 数值
  - 当相等时显示结论"太阳直射点位于 A、B 两点纬度的中间位置（赤道 0°）"

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：
  1. 纬度滑块（scene2-slider-track + scene2-slider-handle）：位于画布左下角 (50,450)~(200,450)，拖动范围 x=50~200，对应太阳直射点纬度 -23.5°~+23.5°
  2. 太阳直射点（scene2-sun-point）：随滑块同步移动，在经纬网上 y=140~380 范围内垂直移动
- 教师操作流程：
  1. 初始状态展示：直射赤道，HA=HB=60°，说明"当 A、B 两点正午太阳高度相同时，太阳直射点位于赤道"
  2. 拖动滑块向左（南移）：HA 增大、HB 减小，说明"直射点南移，北半球 A 点高度增大，南半球 B 点高度减小"
  3. 拖动滑块向右（北移）：HA 减小、HB 增大，说明"直射点北移，北半球 A 点高度减小，南半球 B 点高度增大"
  4. 回到中间位置：HA=HB，强调"只有当直射点在 A、B 纬度中间（赤道）时，两点高度才相等"
  5. 结合方向箭头：说明"A 点 (60°W,30°N) 位于 B 点 (0°,30°S) 的西北方向"

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无需第三方库，几何图形简单，交互逻辑清晰）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │                    正午太阳高度对称性演示                    │  y=30
  │                                                             │
  │   180°W  120°W  60°W    0°    60°E  120°E  180°E           │  y=80
  │   ┌──────┬──────┬──────┬──────┬──────┬──────┬──────┐       │
  │ 90°│      │      │      │      │      │      │      │       │  y=80
  │ 60°│      │      │      │      │  D   │      │  E   │       │  y=140
  │ 30°│      │      │  A   │      │      │      │      │       │  y=200
  │  0°│      │      │      │  C   │      │      │      │       │  y=260
  │-30°│      │      │      │  B   │      │      │      │       │  y=320
  │-60°│      │      │      │      │      │      │      │       │  y=380
  │-90°│      │      │      │      │      │      │      │       │  y=420
  │   └──────┴──────┴──────┴──────┴──────┴──────┴──────┘       │
  │                                                             │
  │ HA=60°  [滑块：-23.5°━━━━●━━━━+23.5°]                      │  y=450
  │ HB=60°                                                       │
  └─────────────────────────────────────────────────────────────┘
  ```

- 关键实现要点：
  1. 状态机设计：
     - 状态变量：sunLatitude（直射点纬度，-23.5~+23.5）
     - 派生变量：sunY（直射点 y 坐标）、HA（A 点正午太阳高度）、HB（B 点正午太阳高度）
     - 计算公式：
       - sunY = 260 + sunLatitude * (120 / 23.5)  // 0°对应 y=260，每度约 5.1px
       - HA = 90 - Math.abs(30 - sunLatitude)  // A 点纬度 30°N
       - HB = 90 - Math.abs(-30 - sunLatitude)  // B 点纬度 30°S
  2. 坐标计算：
     - 滑块 x 到纬度的映射：latitude = (sliderX - 125) * (23.5 / 75)  // 125 是中点，75 是半程
     - 直射点 y 到纬度的映射：sunY = 260 - latitude * (120 / 23.5)  // 北移 y 减小
  3. 动画曲线：滑块拖动使用 requestAnimationFrame 实现平滑更新
  4. 事件绑定：
     - scene2-slider-handle 的 mousedown/touchstart → 开始拖动
     - document 的 mousemove/touchmove → 更新滑块位置
     - document 的 mouseup/touchend → 结束拖动
  5. 高亮逻辑：当 Math.abs(HA - HB) < 1 时，给 scene2-sun-point 添加红色光晕效果
  6. ID 命名规范：所有元素 ID 以 scene2- 为前缀，如 scene2-sun-point、scene2-slider-handle、scene2-ha-display、scene2-hb-display
  7. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染
