    读地球公转示意图，回答：

    （1）图中四点所示节气为：A ______     C ______

    （2）北半球昼最短、夜最长的时间是 ______，南极圈内出现极夜时间 ______，南回归线以南地区正午太阳高度最大的时间 ______（填代号）

    **题目分析：**

    本题考察地球公转与季节变化的核心知识点。图示为地球绕太阳公转的椭圆轨道，标注了 A、B、C、D 四个关键位置。

    **关键判断依据：**
    - 观察地轴倾斜方向与太阳光线的关系
    - A 位置：地轴北极倾向太阳，太阳直射北回归线 → 北半球夏至（6 月 22 日前后）
    - C 位置：地轴北极背离太阳，太阳直射南回归线 → 北半球冬至（12 月 22 日前后）
    - B、D 位置：太阳直射赤道 → 分别为秋分和春分

    **解题要点：**
    1. 北半球昼最短夜最长 → 冬至（C 点）
    2. 南极圈出现极夜 → 北半球夏至时南极圈极夜（A 点）

    **教学说明：**

    本图示通过分步导航方式，引导学生逐步判断地球公转轨道上四个位置的节气。教师应按以下步骤讲解：

    **讲解要点：**

    1. **初始观察**：首先让学生观察地轴倾斜方向——地轴始终指向北极星方向，倾斜角度约 23.5°，在公转过程中保持方向不变

    2. **关键判断**：
    - A 位置：地轴北极倾向太阳，北半球获得更多太阳辐射 → 夏至
    - C 位置：地轴北极背离太阳，北半球获得较少太阳辐射 → 冬至
    - D、B 位置：太阳直射赤道，昼夜平分 → 春分、秋分

    3. **记忆口诀**：可帮助学生记忆"左夏右冬，上春下秋"（从图中视角看）

    4. **易错点提醒**：
    - 南极圈极夜发生在北半球夏至时（A 点），因为此时太阳直射北回归线，南极圈完全背离太阳
    - 南回归线以南地区正午太阳高度最大时，是太阳直射南回归线时（C 点）

    **板书配合建议：**
    可在黑板上同步画出简化的公转轨道图，标注四个位置及对应节气，方便学生对照理解。

    **总结与完整解答：**

    **题目答案：**
    （1）A：夏至；C：冬至
    （2）北半球昼最短夜最长：C；南极圈出现极夜：A；南回归线以南正午太阳高度最大：C

    **核心规律总结：**

    1. **太阳直射点移动规律**：
    - 夏至（A）：直射北回归线（23.5°N）
    - 秋分（B）：直射赤道（0°）
    - 冬至（C）：直射南回归线（23.5°S）
    - 春分（D）：直射赤道（0°）

    2. **昼夜长短变化规律（北半球）**：
    - 夏至：昼最长、夜最短
    - 冬至：昼最短、夜最长
    - 春秋分：昼夜等长（各 12 小时）

    3. **极昼极夜现象**：
    - 北半球夏至：北极圈极昼，南极圈极夜
    - 北半球冬至：北极圈极夜，南极圈极昼

    4. **正午太阳高度规律**：
    - 某地正午太阳高度最大时，是太阳直射该地所在纬线时
    - 南回归线以南地区：冬至时正午太阳高度最大

    **课堂讲解建议：**
    1. 先用 Scene 1 的静态分步图帮助学生建立基本认知，记住四个位置的节气
    2. 再用 Scene 2 的动态拖拽图展示变化规律，让学生观察连续变化过程
    3. 引导学生总结规律，形成知识网络
    4. 最后回归题目，用刚学的规律解答具体问题，巩固知识应用
