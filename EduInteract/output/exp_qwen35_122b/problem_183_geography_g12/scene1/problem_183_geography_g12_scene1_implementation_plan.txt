[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：位置 (300,465)，作用：返回上一步骤，步骤 0 时禁用
  - "下一步 ▶"按钮：位置 (420,465)，作用：进入下一步骤，步骤 7 时变为"完成"
  - 步骤指示器：位置 (350,440)，显示"步骤 X/7"
- 教师操作流程：
  1. 初始展示公转轨道图，引导学生观察四个地球位置
  2. 点击"下一步"逐步展示每个位置的太阳直射情况
  3. 每展示一个位置，引导学生判断节气
  4. 最后展示完整答案，进行总结

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：

  ```
  └─────────────────────────────────────────────────────────┘
  ```

- 关键实现要点：
  1. 状态机设计：currentStep 变量 (0-7)，updateScene() 函数根据 currentStep 更新显示
  2. 坐标计算：椭圆轨道使用 SVG path 命令，地球位置通过椭圆参数方程计算
  3. 动画曲线：使用 CSS transition 实现边框高亮变化 (0.3s ease)
  4. 事件绑定：按钮点击事件监听，步骤 0 禁用"上一步"，步骤 7 禁用"下一步"
  5. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-earth-a, scene1-ray-a, scene1-label-a）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 元素显示控制：使用 display: none/block 或 opacity 控制元素显示/隐藏

- 状态更新逻辑：
  ```javascript
  function updateScene() {
    // 重置所有高亮
    resetHighlights();
    
    switch(currentStep) {
      case 0:
        // 初始状态，仅显示基础元素
        break;
      case 1:
        // 高亮 A，显示光线 A 和直射标注
        highlightEarth('a');
        showRay('a');
        showDirectLabel('北回归线');
        break;
      case 2:
        // 显示节气标注 A
        showSolsticeLabel('夏至（6 月 22 日前后）');
        break;
      // ... 其他步骤
      case 7:
        // 显示所有节气标注和结论
        showAllLabels();
        showConclusion();
        break;
    }
    
    updateStepIndicator();
  }
  ```
