[分步序列]
- 步骤0（初始状态）：
  - 显示：椭圆轨道、太阳、四个地球位置（A/B/C/D）、辅助线
  - 隐藏：地轴、太阳光线、直射点、节气标签、控件按钮（仅显示"下一步"）
  - 目的：展示地球公转轨道的基本结构

- 步骤1：
  - 新增显示：四条地轴（穿过每个地球位置）
  - 新增标签：地球A的"北极""南极"标注
  - 视觉变化：地轴以蓝色显示，倾斜方向一致（均向右上方倾斜约23.5°）
  - 目的：强调地轴倾斜方向在公转过程中保持不变

- 步骤2：
  - 新增显示：太阳光线（从太阳射向地球B和D）、直射点标记（地球B和D中心）
  - 新增标签：地球B和D的直射点说明
  - 视觉变化：红色光线突出太阳辐射方向，绿色点标记直射位置
  - 目的：展示太阳直射点在不同位置的变化

- 步骤3：
  - 新增显示：四个节气标签（春分-A、夏至-B、秋分-C、冬至-D）
  - 视觉变化：节气名称以黑色文字显示在各地球位置外侧
  - 目的：完成四个位置对应的节气判断

- 步骤4（结论）：
  - 高亮显示：地球B（夏至，北极倾向太阳，直射北回归线）、地球D（冬至，南极倾向太阳，直射南回归线）
  - 新增文字：底部显示判断规律总结"地轴倾斜方向不变，北极倾向太阳时为夏至，背离时为冬至"
  - 目的：总结二分二至的判断规律

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "上一步"按钮（scene1-prev-btn）：位于控件栏左侧，点击返回上一状态，步骤0时禁用
  - "下一步"按钮（scene1-next-btn）：位于控件栏右侧，点击进入下一状态，步骤4时变为"完成"
  - 步骤指示器：显示当前步骤（如"步骤 1/5"）
- 教师操作流程：
  1. 初始展示轨道结构，引导学生观察地球公转的基本形态
  2. 点击"下一步"，展示地轴，强调地轴倾斜方向不变
  3. 点击"下一步"，展示太阳光线和直射点，分析直射点纬度变化
  4. 点击"下一步"，显示节气名称，完成位置与节气的对应
  5. 点击"下一步"，高亮关键位置，总结判断规律
  6. 可随时点击"上一步"回退复习

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    图示区 800×500                       │
  │                                                         │
  │           A(春分)                                       │
  │            ●                                            │
  │           /│\ 地轴                                      │
  │          / │ \                                          │
  │    B(夏至)│   │C(秋分)                                  │
  │     ●────┼───┼────●                                    │
  │    /│\   │   │  /│\                                    │
  │   / │ \  │   │ / │ \                                   │
  │  ●───┼───┼───●───┼───● D(冬至)                         │
  │      │   │   │   │                                     │
  │      │   ●太阳 │                                     │
  │      │  (550,250)                                     │
  │                                                         │
  │            步骤指示器：步骤 1/5                          │
  │          [◀上一步]  [下一步▶]                          │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 currentStep 记录当前步骤（0-4），根据步骤控制元素显示/隐藏
  2. 坐标计算：椭圆轨道使用 SVG path 的椭圆弧命令，地球位置根据椭圆参数方程计算
  3. 地轴倾斜：所有地轴保持相同倾斜角度（约23.5°），使用固定偏移量实现
  4. 动画曲线：元素出现使用 opacity 过渡（0→1，duration=0.3s）
  5. 事件绑定：按钮点击事件监听，更新 currentStep 后重新渲染可见元素
  6. ID 命名规范：所有元素 ID 以"scene1-"为前缀（如 scene1-orbit、scene1-sun、scene1-earth-a 等）
  7. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  8. 控件区定位：使用 position: absolute，top=450px，left=50%，transform: translateX(-50%)
