[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "上一步"按钮：scene2-prev-btn，位置(250,455)，点击返回上一状态
  - "下一步"按钮：scene2-next-btn，位置(450,455)，点击进入下一状态
  - 步骤 0 时"上一步"按钮禁用，步骤 3 时"下一步"按钮禁用
- 教师操作流程：
  1. 初始展示晨昏线与 70°N 相切的基础图形
  2. 点击"下一步"，展示太阳光线并推导直射点纬度
  3. 点击"下一步"，展示直射点位置和经度推导
  4. 点击"下一步"，展示最终完整坐标结论
  5. 可随时点击"上一步"回退复习关键推导步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │                        图示区 800×500                          │
  │                                                                │
  │    ┌─────────────┐         ┌─────────────────────────────┐    │
  │    │  地球侧视图  │         │      推导说明区              │    │
  │    │  (左侧)     │         │      (右侧)                  │    │
  │    │             │         │  ┌─────────────────────┐     │    │
  │    │   ○ 地球    │  →光线  │  │  推导框 1 (步骤 1)    │     │    │
  │    │   │        │         │  ├─────────────────────┤     │    │
  │    │  /│\       │         │  │  推导框 2 (步骤 2)    │     │    │
  │    │ / │ \      │         │  ├─────────────────────┤     │    │
  │    │   │        │         │  │  推导框 3 (步骤 3)    │     │    │
  │    └─────────────┘         │  └─────────────────────┘     │    │
  │                            └─────────────────────────────┘    │
  │                                                                │
  │              ┌────────────────────────────┐                   │
  │              │    ◀上一步  下一步▶        │                   │
  │              │      (控件栏 y=440~490)    │                   │
  │              └────────────────────────────┘                   │
  └────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-3) 跟踪当前步骤
  2. 元素显示控制：每个推导框和新增元素用 class "step-N"标记，通过 toggleClass 控制显示
  3. 坐标计算：所有元素用绝对坐标，SVG 元素用 x/y/cx/cy 属性精确控制
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后刷新显示状态
  5. 按钮禁用状态：步骤 0 禁用 prev，步骤 3 禁用 next
- ID 命名规范：所有交互元素 ID 以 scene2- 为前缀（如 scene2-earth-ellipse, scene2-prev-btn, scene2-next-btn, scene2-step1-box 等）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局污染
