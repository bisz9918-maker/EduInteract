[图示主题与整合说明]
- 本图示主题：地球运动与平面交角（四季形成原理的第一步）
- 整合内容：自转→赤道平面、公转→黄道平面、两平面交角（黄赤交角）
- 教学价值：教师可通过分步揭示的方式，帮助学生理解地球两种基本运动形式如何产生两个重要平面，以及这两个平面的交角是四季形成的根本原因。逐步展示符合认知规律，避免一次性信息过载。

[分步序列]
- 步骤0（初始状态）：
  - 显示：所有矩形框（自转框、公转框、赤道平面框、黄道平面框、黄赤交角框）
  - 显示：所有向下/汇聚箭头
  - 显示：两个地球辅助示意图（灰色虚线）
  - 隐藏：所有文字标签（自转、公转、( )平面、( )交角）
  - 目的：展示框架结构，让学生先理解整体逻辑关系

- 步骤1：点击「下一步」→
  - 新增显示：顶部"自转"文字（蓝色#1565c0）
  - 新增显示：顶部"公转"文字（蓝色#1565c0）
  - 新增显示：自转→箭头、公转→箭头（高亮）
  - 目的：揭示地球两种基本运动形式

- 步骤2：点击「下一步」→
  - 新增显示：左侧"( )平面"文字（红色#c62828 括号 + 蓝色#1565c0 "平面"）
  - 新增显示：右侧"( )平面"文字（红色#c62828 括号 + 蓝色#1565c0 "平面"）
  - 新增显示：左→箭头、右→箭头（高亮）
  - 目的：揭示运动产生的两个平面，括号提示学生填空

- 步骤3：点击「下一步」→
  - 新增显示：底部"( )交角"文字（红色#c62828 括号 + 蓝色#1565c0 "交角"）

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮（scene1-prev-btn）：位于控件栏左侧，点击返回上一步骤，步骤0时禁用
  - 下一步按钮（scene1-next-btn）：位于控件栏右侧，点击进入下一步骤，步骤3时禁用
- 教师操作流程：
  1. 初始展示框架，提问"这个流程图展示了什么关系？"
  2. 点击下一步，揭示"自转"和"公转"，讲解地球两种运动
  3. 点击下一步，揭示两个平面，提问"这两个括号应该填什么？"
  4. 点击下一步，揭示交角，总结"黄赤交角是四季形成的根本原因"
  5. 可随时点击上一步回顾，巩固因果关系

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：本图示为静态流程图，无需复杂动画或数据可视化，原生实现轻量高效
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │ 800px                                                          │
  │                                                                │
  │    ┌─────────┐              ┌─────────┐                       │
  │    │  自转   │              │  公转   │  50px                 │
  │    └─────────┘              └─────────┘                       │
  │         ↓                    ↓                                │
  │  ┌─────────────┐      ┌─────────────┐                         │
  │  │ ( ) 平面    │      │ ( ) 平面    │  50px                  │
  │  └─────────────┘      └─────────────┘                         │
  │         ↘                  ↙                                  │
  │            ┌─────────────┐                                    │
  │            │ ( ) 交角    │  50px                              │
  │            └─────────────┘                                    │
  │                                                                │
  │  ┌──────────┐                              ┌──────────┐       │
  │  │ 地球示意 │                              │ 地球示意 │       │
  │  │  (自转)  │                              │  (公转)  │ 100px │
  │  └──────────┘                              └──────────┘       │
  │                                                                │
  │                                                                │
  │                                                                │
  │         ┌──────────┐  ┌──────────┐                            │
  │         │◀ 上一步  │  │ 下一步 ▶ │  30px                      │
  │         └──────────┘  └──────────┘                            │
  │                                                                │
  └────────────────────────────────────────────────────────────────┘
  0px                                                            800px
  ```

- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-3) 跟踪当前步骤
  2. 元素分组：每个步骤显示的元素用 data-step 属性标记，如 data-step="1" 表示步骤1显示
  3. 坐标计算：所有元素使用绝对坐标，通过 SVG transform 定位
  4. 动画曲线：元素显示使用 opacity 过渡（0→1，duration 300ms）
  5. 事件绑定：按钮点击事件监听，更新 currentStep 后重新渲染可见元素
  6. 按钮状态：步骤0时禁用上一步，步骤3时禁用下一步（opacity 0.5 + pointer-events: none）

- ID 命名规范：
  - 所有交互元素 ID 以 scene1- 为前缀
  - 示例：scene1-box-rotate（自转框）、scene1-box-revolve（公转框）、scene1-box-equator（赤道平面框）、scene1-box-ecliptic（黄道平面框）、scene1-box-obliquity（黄赤交角框）、scene1-text-rotate（自转文字）、scene1-text-revolve（公转文字）、scene1-prev-btn（上一步按钮）、scene1-next-btn（下一步按钮）

- IIFE 隔离：
  ```javascript
  (function() {
    // 所有代码包在此闭包中
    const currentStep = 0;
    // ... 实现逻辑
  })();
  ```
