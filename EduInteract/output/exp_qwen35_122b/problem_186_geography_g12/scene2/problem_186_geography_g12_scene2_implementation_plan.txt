[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  原因：几何图形为主，无需复杂库，原生实现轻量高效

- 画布尺寸：800 × 500 px

- 布局草图（ASCII）：

  └────────────────────────────────────────────────────────────────┘

- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量（0-3）跟踪当前步骤，每个步骤对应一组可见元素
  2. 坐标计算：所有元素使用绝对坐标，SVG 元素通过 x/y/cx/cy 属性定位
  3. 动画曲线：直射点路径使用 SVG path 元素，通过 SMIL 或 JS requestAnimationFrame 实现圆点沿路径移动
  4. 事件绑定：按钮点击事件监听，更新 currentStep 并调用 updateScene() 刷新显示
  5. ID 命名规范：所有元素 ID 以 scene2- 为前缀（如 scene2-ellipse, scene2-spring-point, scene2-prev-btn）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染

- 元素 ID 命名列表：
  - scene2-title: 标题文本
  - scene2-equator-line: 赤道平面线
  - scene2-ecliptic-line: 黄道平面线
  - scene2-angle-arc: 交角弧线
  - scene2-angle-label: 23°26'标注
  - scene2-orbit-ellipse: 公转轨道椭圆
  - scene2-spring-point: 春分点
  - scene2-summer-point: 夏至点
  - scene2-autumn-point: 秋分点
  - scene2-winter-point: 冬至点
  - scene2-north-回归线: 北回归线
  - scene2-south-回归线: 南回归线
  - scene2-path-curve: 直射点路径
  - scene2-cycle-label: 回归周期标签
  - scene2-prev-btn: 上一步按钮
  - scene2-next-btn: 下一步按钮

- 状态更新逻辑：
  updateScene() 函数根据 currentStep 值：
  - step 0: 显示 title, equator-line, ecliptic-line, angle-arc, angle-label, orbit-ellipse, north-回归线, south-回归线
  - step 1: 新增 spring-point, summer-point, autumn-point, winter-point 及对应标签
  - step 2: 新增 path-curve，启动路径动画
  - step 3: 新增 cycle-label，动画持续循环
