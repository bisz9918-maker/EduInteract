[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（流程图元素简单，无需复杂库）
- 画布尺寸：800 × 560 px（底部预留 40px 给控件栏）
- 布局草图（ASCII）：
  ```
  [图示区 800×520]
  ┌─────────────────────────────────────────────────────────┐
  │     [自转]                    [公转]                    │
  │       ↓                          ↓                      │
  │   [赤道平面]                [黄道平面]                  │
  │       ↘                        ↙                       │
  │        [黄赤交角]                                      │
  │           ↓                                            │
  │      [直射点回归]                                      │
  │         ↙        ↘                                    │
  │  [正午太阳高度]  [昼夜长短]                            │
  │         ↘        ↙                                    │
  │      [地面受热多少变化]                                │
  │           ↓                                            │
  │        [季节变化]                                      │
  │           ↓                                            │
  │        [四季交替]                                      │
  │                                                         │
  │  [◀上一步]  步骤 1/5  [下一步▶]                          │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用 currentStep 变量跟踪当前步骤（0-4），每一步定义需要显示/高亮的元素 ID 列表
  2. 坐标计算：所有矩形框位置已精确规划，确保垂直间距≥50px，水平分支间距≥200px
  3. 动画曲线：答案揭示使用 opacity 从 0→1 的淡入动画（duration: 300ms）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateDisplay() 刷新界面
  5. ID 命名规范：所有元素 ID 以 scene3- 为前缀（如 scene3-box-self-rotate、scene3-arrow-1 等）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 颜色变量：用 CSS 变量定义主题色，便于统一管理和修改
  8. 答案文本存储：用 data-answer 属性存储每个填空的正确答案，点击时动态替换
