[图示主题与整合说明]
- 本图示主题：太阳能热水器倾角与正午太阳高度的互补关系
- 整合内容：整合了四个地点的倾角标注、正午太阳高度计算、太阳光线入射角度展示

[分步序列]
- 步骤0（初始状态）：
  - 显示：四个热水器示意图（地面+集热板）、倾角弧线、倾角数值、地点标签、标题
  - 隐藏：太阳光线、计算框、条形图、排序标签
  - 状态：等待教师点击"下一步"

- 步骤1（高亮A地计算）：
  - 显示：步骤0所有元素 + A地太阳光线 + 计算框
  - 高亮：A地集热板加粗，计算框内显示"θ=6°34′ → H=90°-6°34′=83°26′"
  - 新增：A地太阳光线（橙色）

- 步骤2（依次高亮B、C、D）：
  - 显示：步骤1所有元素 + B、C、D地太阳光线
  - 高亮：依次显示B、C、D的计算结果
  - 计算框内容循环显示：
    - B: "θ=26°34′ → H=90°-26°34′=63°26′"
    - C: "θ=28°34′ → H=90°-28°34′=61°26′"
    - D: "θ=13°34′ → H=90°-13°34′=76°26′"

- 步骤3（太阳高度对比条形图）：
  - 显示：步骤2所有元素 + 底部条形图
  - 新增：四个柱状图（A、D、B、C从左到右按高度降序排列）
  - 柱状图高度比例：A(65px) > D(58px) > B(48px) > C(46px)
  - 每个柱子上方显示对应太阳高度数值

- 步骤4（结论排序）：
  - 显示：步骤3所有元素 + 排序标签
  - 新增：底部绿色排序标签"A > D > B > C"
  - 高亮：条形图按高度从高到低依次闪烁高亮
  - 结论：正午太阳高度排序 = 昼长排序（夏至日北半球）

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：位于(280,450)，点击返回上一状态，第一步时禁用
  - "下一步 ▶"按钮：位于(420,450)，点击进入下一状态，最后一步时变为"完成"
- 教师操作流程：
  1. 初始展示四地热水器倾角，引导学生观察倾角差异
  2. 点击"下一步"，逐步展示每地太阳高度计算过程
  3. 继续点击，展示条形图对比，引导学生理解高度差异
  4. 最后展示排序结论，引导学生推导昼长排序

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    标题 (320,25)                        │
  │                                                         │
  │   A热水器    B热水器    C热水器    D热水器              │
  │   (60,180)  (230,180)  (400,180)  (570,180)            │
  │     │          │          │          │                  │
  │     │倾角      │倾角      │倾角      │倾角               │
  │     ▼          ▼          ▼          ▼                  │
  │                                                         │
  │              计算框 (250,260,300,60)                    │
  │              H = 90° - θ                                │
  │                                                         │
  │   A柱    D柱    B柱    C柱                              │
  │  (120)  (240)  (360)  (480)                            │
  │   │      │      │      │                               │
  │   └──────┴──────┴──────┘                               │
  │              排序标签 (350,420)                         │
  │                                                         │
  │        [◀ 上一步]    [下一步 ▶]                         │
  │          (280,450)    (420,450)                         │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：currentStep变量(0-4)，控制各元素显示/隐藏
  2. 坐标计算：热水器位置等间距排列，条形图高度按比例缩放（最大高度65px对应83°26′）
  3. 动画曲线：元素出现使用 opacity 渐变（0→1，0.3s）
  4. 事件绑定：按钮点击事件更新currentStep，刷新显示状态
  5. 高亮效果：使用 stroke-width 临时加粗（3px→5px）配合颜色变化
- ID 命名规范：所有元素 ID 以"scene1-"为前缀（如 scene1-heater-a, scene1-btn-next）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局污染
