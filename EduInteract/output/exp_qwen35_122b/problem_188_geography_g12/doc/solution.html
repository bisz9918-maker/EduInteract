题目原文：

读太阳直射点的回归运动示意图，完成下列要求

（1）在图上①、②、③、④四点中是12月22日太阳直射点位置，是3月21日太阳直射点位置．

（2）在①、②、③、④四点中，白城日出最早的是；白城白昼最长的是．

（3）在图上④这一天，正午太阳高度由向南北两侧降低；正午太阳高度达一年中最大值的范围是；出现极夜的范围是．

（4）夏至日这一天，在太阳直射点的回归运动示意图上，太阳直射在位置上；该日以后，太阳直射点向（方向）移动．

（5）在①、②、③、④四点中，表示全球昼夜平分的有．

题目分析：

本题围绕太阳直射点的回归运动展开，考查学生对太阳直射点周年变化规律的理解。图中展示了太阳直射点在南北回归线之间的往返运动轨迹，四个关键点分别对应二分二至日。

整体讲解思路：

  1. 首先引导学生识别图中的三条重要纬线：北回归线、赤道、南回归线
  2. 然后分析太阳直射点的移动规律：从赤道→北回归线→赤道→南回归线→赤道
  3. 将四个关键点与二分二至日对应：①春分、②夏至、③秋分、④冬至
  4. 结合太阳直射点位置分析各地昼夜长短、正午太阳高度的变化规律
  5. 最后完成各小题的解答

图示1教学说明：

本图示是讲解太阳直射点回归运动的核心视觉材料，教师应引导学生按以下步骤观察和理解：

第一步：识图
让学生先观察图中的三条水平线，明确它们代表的纬线：

  • 最上方虚线：北回归线（23°26′N）
  • 中间实线：赤道（0°）
  • 最下方虚线：南回归线（23°26′S）

然后观察蓝色曲线，这是太阳直射点在一年中的移动轨迹，在南北回归线之间往返运动。

第二步：定位关键点
引导学生识别四个关键点的位置特征：

  • ①点：位于赤道，曲线向上延伸 → 太阳直射赤道后向北移动
  • ②点：位于北回归线顶点 → 太阳直射北回归线
  • ③点：位于赤道，曲线向下延伸 → 太阳直射赤道后向南移动
  • ④点：位于南回归线谷底 → 太阳直射南回归线

第三步：对应节气
结合太阳直射点位置与节气的关系：

  • 太阳直射赤道且向北移动 → 春分（3月21日前后）→ ①点
  • 太阳直射北回归线 → 夏至（6月22日前后）→ ②点
  • 太阳直射赤道且向南移动 → 秋分（9月23日前后）→ ③点
  • 太阳直射南回归线 → 冬至（12月22日前后）→ ④点

第四步：理解移动规律
强调太阳直射点的周年运动规律：

  • 春分→夏至：直射点从赤道向北回归线移动（北半球昼渐长）
  • 夏至→秋分：直射点从北回归线向赤道移动（北半球昼渐短）
  • 秋分→冬至：直射点从赤道向南回归线移动（北半球昼继续变短）
  • 冬至→春分：直射点从南回归线向赤道移动（北半球昼渐长）

讲解要点：

  1. 太阳直射点在北回归线和南回归线之间往返运动，周期为一年
  2. 直射点所在半球昼长夜短，且纬度越高昼越长（极昼范围从极点向低纬扩展）
  3. 直射点离某地越近，该地正午太阳高度越大
  4. 春分和秋分时，太阳直射赤道，全球昼夜平分

完整解答：

（1）在图上①、②、③、④四点中 ④ 是12月22日太阳直射点位置， ① 是3月21日太阳直射点位置．

（2）在①、②、③、④四点中，白城日出最早的是 ② ；白城白昼最长的是 ② ．

（3）在图上④这一天，正午太阳高度由 南回归线 向南北两侧降低；正午太阳高度达一年中最大值的范围是 南回归线及其以南地区 ；出现极夜的范围是 北极圈及其以北地区 ．

（4）夏至日这一天，在太阳直射点的回归运动示意图上，太阳直射在 ②（北回归线） 位置上；该日以后，太阳直射点向 南 （方向）移动．

（5）在①、②、③、④四点中，表示全球昼夜平分的有 ①和③ ．

课堂讲解建议：

  1. 导入环节（约3分钟）：通过图示1的初始状态，让学生观察太阳直射点回归运动示意图，提问"图中三条线分别代表什么？曲线表示什么？"
  1. 核心讲解（约10分钟）：
  • 使用图示1的分步导航，逐步讲解四个关键点对应的节气和日期
  • 强调记忆口诀："春分赤道向北移，夏至北回归线顶；秋分赤道向南移，冬至南回归线底"
  • 使用图示2的分步导航，讲解太阳直射点位置与地理现象的关系
  1. 巩固练习（约5分钟）：
  • 让学生独立完成题目各小题
  • 对照答案，重点讲解易错点（如第3问中正午太阳高度最大值范围）
  1. 拓展延伸（约2分钟）：
  • 提问：如果太阳直射点移动到赤道以北，北半球各地昼夜长短如何变化？
  • 引导学生理解太阳直射点位置与昼夜长短、正午太阳高度的内在联系

易错点提示：

  • 第（1）问：12月22日是冬至，太阳直射南回归线（④点）；3月21日是春分，太阳直射赤道（①点）
  • 第（2）问：白城位于北半球，夏至日（②点）昼最长、日出最早
  • 第（3）问：冬至日太阳直射南回归线，正午太阳高度由南回归线向南北两侧降低；南回归线及其以南地区正午太阳高度达一年中最大值；北极圈及其以北出现极夜
  • 第（5）问：春分和秋分时太阳直射赤道，全球昼夜平分
