[分步序列]
- 步骤 0（初始状态）：显示完整装置结构（支架、滑轮、绳子、物体 B、弹簧测力计、物体 A、盛水容器、水），所有元素可见但无力的标注，无高亮
- 步骤 1：高亮物体 B（边框加粗至 3px），显示 G_B 箭头（红色）和 T_B 箭头（蓝色），显示标签"G_B"和"T"，文字"m_B=2kg"出现在 B 附近
- 步骤 2：高亮弹簧测力计（外壳边框加粗），显示示数框"19.6N"（从透明变为#fff9c4 背景），文字"T=19.6N"出现在弹簧旁
- 步骤 3：高亮物体 A（边框加粗至 3px），显示 G_A 箭头（红色）、T_A 箭头（蓝色）、F_浮 箭头（绿色），显示对应标签"G_A"、"T"、"F_浮"，文字"m_A=3kg"出现在 A 附近
- 步骤 4：所有力箭头同时显示，用虚线延长线表示力的作用线，显示结论文字"T=G_B=19.6N"、"G_A=T+F_浮"、"A 处于平衡状态"，物体 A 和 B 边框恢复正常

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "上一步"按钮：位于 (280,455)-(360,480)，点击返回前一步骤，第一步时禁用
  - "下一步"按钮：位于 (440,455)-(520,480)，点击进入下一步骤，最后一步时显示"完成"
- 教师操作流程：
  1. 初始展示装置，引导学生识别各部件
  2. 点击"下一步"，分析物体 B 受力（重力与拉力平衡）
  3. 点击"下一步"，说明弹簧测力计示数等于拉力 T
  4. 点击"下一步"，分析物体 A 三力平衡
  5. 点击"下一步"，总结整体平衡关系，引导学生判断选项

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    固定支架 (200,40)                    │
  │                      ╱╱╱╱╱╱╱╱╱╱╱╱╱╱╱                   │
  │                        ○ 定滑轮 (400,100)              │
  │                       ╱ ╲                              │
  │                      ╱   ╲                             │
  │                     ▼     ▼                            │
  │                   ┌───┐  ┌──────┐                      │
  │                   │ B │  │弹簧测│ 19.6N                │
  │                   └───┘  └───┬──┘                      │
  │                              │                         │
  │                              ▼                         │
  │                         ┌─────────┐                    │
  │                         │    A    │  ← 浸在水中       │
  │                         └─────────┘                    │
  │                        ┌───────────┐                   │
  │                        │  ~~~~~~~~ │ 水面              │
  │                        │  ~~~~~~~~ │                   │
  │                        └───────────┘                   │
  │                                                         │
  │              [上一步]                    [下一步]       │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：currentStep 变量 (0-4)，updateScene() 函数根据 currentStep 显示/隐藏对应元素
  2. 坐标计算：所有元素使用绝对坐标，力箭头从物体中心点出发
  3. 动画曲线：元素出现使用 opacity 过渡 (0.3s ease-in-out)
  4. 事件绑定：按钮点击事件更新 currentStep 并调用 updateScene()
  5. ID 命名规范：所有元素 ID 以"scene1-"为前缀（如 scene1-obj-B、scene1-arrow-Gb、scene1-btn-prev）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 力的显示逻辑：步骤 1 显示 B 的力，步骤 2 显示弹簧示数，步骤 3 显示 A 的力，步骤 4 全部显示并加结论
  8. 高亮效果：使用 class"highlight"改变边框线宽和颜色，通过 toggleClass 控制
