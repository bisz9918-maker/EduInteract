[标签冲突检查]
逐一检查所有标签坐标间距：

- 标签"P"：坐标 (390, 45)
- 标签"A"：坐标 (155, 340)
- 标签"B"：坐标 (310, 380)
- 标签"C"：坐标 (595, 360)
- 标签"D"：坐标 (395, 260)

间距计算（欧氏距离）：
- P 与 A：√[(390-155)² + (45-340)²] = √[55225 + 87025] = √142250 ≈ 377px → 无冲突
- P 与 B：√[(390-310)² + (45-380)²] = √[6400 + 112225] = √118625 ≈ 344px → 无冲突
- P 与 C：√[(390-595)² + (45-360)²] = √[42025 + 99225] = √141250 ≈ 376px → 无冲突
- P 与 D：√[(390-395)² + (45-260)²] = √[25 + 46225] = √46250 ≈ 215px → 无冲突
- A 与 B：√[(155-310)² + (340-380)²] = √[24025 + 1600] = √25625 ≈ 160px → 无冲突
- A 与 C：√[(155-595)² + (340-360)²] = √[193600 + 400] = √194000 ≈ 440px → 无冲突
- A 与 D：√[(155-395)² + (340-260)²] = √[57600 + 6400] = √64000 ≈ 253px → 无冲突
- B 与 C：√[(310-595)² + (380-360)²] = √[81225 + 400] = √81625 ≈ 286px → 无冲突
- B 与 D：√[(310-395)² + (380-260)²] = √[7225 + 14400] = √21625 ≈ 147px → 无冲突
- C 与 D：√[(595-395)² + (360-260)²] = √[40000 + 10000] = √50000 ≈ 224px → 无冲突

结论：所有标签间距均远大于 20px 安全阈值，无冲突。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮：id="scene1-btn-prev"，位置 (280, 455)，作用：返回上一状态，步骤 0 时禁用
  - 下一步按钮：id="scene1-btn-next"，位置 (500, 455)，作用：进入下一状态，最终步骤时禁用
  - 步骤指示器：id="scene1-step-indicator"，位置 (360, 460)，显示"步骤 X/4"
- 教师操作流程：
  1. 初始展示四棱锥线框，讲解整体空间结构
  2. 点击"下一步"，高亮平面 PAB，讲解该平面的构成（由 P、A、B 三点确定）
  3. 点击"下一步"，高亮平面 PDC，讲解该平面的构成（由 P、D、C 三点确定）
  4. 点击"下一步"，两平面同时显示，引导学生观察两平面的交线（过 P 点），为分析命题③做准备
  5. 可随时点击"上一步"回退复习某个平面的结构

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：

- 关键实现要点：
  1. 状态机设计：用变量 currentStep（0-3）跟踪当前步骤，updateScene() 函数根据 currentStep 显示/隐藏对应元素
  2. 坐标计算：所有顶点坐标已精确规划，直接用 SVG line/polygon/circle 元素绘制
  3. 动画曲线：步骤切换使用 opacity 渐变（0→1 或 1→0），duration=300ms，ease-in-out
  4. 事件绑定：按钮点击事件 → currentStep 增减 → 调用 updateScene() → 更新 DOM
  5. 禁用状态：步骤 0 时 prevBtn.disabled=true；步骤 3 时 nextBtn.disabled=true

- ID 命名规范：所有交互元素 ID 以 "scene1-" 为前缀
  - 平面填充：scene1-poly-pab、scene1-poly-pdc
  - 按钮：scene1-btn-prev、scene1-btn-next
  - 指示器：scene1-step-indicator
  - 顶点：scene1-vert-p、scene1-vert-a、scene1-vert-b、scene1-vert-c、scene1-vert-d
  - 棱线：scene1-edge-pa、scene1-edge-pb、scene1-edge-pc、scene1-edge-pd、scene1-edge-ab、scene1-edge-bc、scene1-edge-ad、scene1-edge-dc

- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染

- JS 核心逻辑：
  ```javascript
  (function() {
    const currentStep = { value: 0 };
    const totalSteps = 4;
    
    function updateScene() {
      // 更新平面填充显示状态
      document.getElementById('scene1-poly-pab').style.opacity = currentStep.value >= 1 ? '0.2' : '0';
      document.getElementById('scene1-poly-pdc').style.opacity = currentStep.value >= 2 ? '0.2' : '0';
      
      // 更新按钮状态
      document.getElementById('scene1-btn-prev').disabled = currentStep.value === 0;
      document.getElementById('scene1-btn-next').disabled = currentStep.value === totalSteps - 1;
      
      // 更新步骤指示器
      document.getElementById('scene1-step-indicator').textContent = '步骤 ' + (currentStep.value + 1) + '/' + totalSteps;
    }
    
    document.getElementById('scene1-btn-prev').addEventListener('click', function() {
      if (currentStep.value > 0) {
        currentStep.value--;
        updateScene();
      }
    });
    
    document.getElementById('scene1-btn-next').addEventListener('click', function() {
      if (currentStep.value < totalSteps - 1) {
        currentStep.value++;
        updateScene();
      }
    });
    
    // 初始化
    updateScene();
  })();
  ```
