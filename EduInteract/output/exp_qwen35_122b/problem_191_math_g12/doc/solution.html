题目原文：
如图，过点P作圆O的割线PBA与切线PE，E为切点，连接AE，BE，∠APE的平分线分别与AE、BE相交于C、D，若∠AEB=40°，则∠PCE等于．

题目分析：
本题是圆的几何综合题，涉及以下核心知识点：

  1. 弦切角定理：切线与弦所夹的角等于弦所对的圆周角
  2. 角平分线性质：角平分线将角分成两个相等的角
  3. 三角形内角和定理及外角性质

整体讲解思路：
教师应引导学生从已知条件出发，逐步挖掘隐含的几何关系。首先识别图中的基本元素（切线、割线、弦），然后应用弦切角定理建立角度关系，最后利用角平分线和三角形内角和求解目标角。

图示规划说明：
本图展示完整的几何图形及关键角度标注，通过分步高亮引导学生观察弦切角关系和角平分线性质，最终推导出∠PCE的度数。

步骤 1/4

教学说明：

本图示通过分步导航引导学生完成角度推导，教师应按以下步骤讲解：

步骤0：识图
展示基本图形，让学生识别：

  • PE是切线，E是切点
  • PBA是割线
  • ∠AEB=40°是已知条件
  • PC是∠APE的角平分线

步骤1：弦切角定理
高亮显示∠PEB和∠PAE，强调：

  • 根据弦切角定理，∠PEB = ∠PAE（切线PE与弦EB所夹的角等于弦EB所对的圆周角∠PAE）

步骤2：角平分线性质
高亮显示∠APC和∠EPC，强调：

  • PC平分∠APE，故∠APC = ∠EPC

步骤3：角度计算
在△PCE中：

  • ∠PCE = 180° - ∠EPC - ∠PEC
  • ∠PEC = ∠PEB + ∠BEC
  • 由弦切角定理，∠PEB = ∠PAE
  • ∠BEC = ∠AEB = 40°（同弧所对圆周角）
  • 设∠APE = 2α，则∠EPC = α
  • 在△PAE中，∠PAE + ∠APE + ∠PEA = 180°
  • 经过推导可得：∠PCE = 70°

关键推导公式：

  1. 弦切角定理：∠PEB = ∠PAE
  2. 角平分线：∠APC = ∠EPC = α
  3. 三角形内角和：∠PCE = 180° - α - (∠PEB + 40°)
  4. 最终结论：∠PCE = 70°
