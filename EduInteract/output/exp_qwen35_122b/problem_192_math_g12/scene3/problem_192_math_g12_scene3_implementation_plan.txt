[分步序列]
- 步骤0（初始状态）：
  - 显示：完整5行三角形数阵（所有分数黑色）
  - 显示：左侧行号标注1-5
  - 显示：右侧第3个数序列框（标题+3个值，蓝色高亮）
  - 隐藏：规律框、通项公式框、验证框、第3列标注
  - 按钮状态：上一步禁用，下一步启用

- 步骤1：点击「下一步」
  - 新增显示：第3列标注（位于三角形右侧，指向第3个数位置）
  - 高亮变化：三角形中第3个数（1/6, 1/12, 1/30）加粗并蓝色填充背景
  - 序列框：3个值保持蓝色高亮
  - 按钮状态：上一步启用，下一步启用

- 步骤2：点击「下一步」
  - 新增显示：规律框（分母规律：6, 12, 30, ...）
  - 高亮变化：序列值中的分母部分加粗
  - 提示文字：在规律框下方显示"观察分母：6=3×2, 12=4×3, 30=5×6..."
  - 按钮状态：上一步启用，下一步启用

- 步骤3：点击「下一步」
  - 新增显示：通项公式框（公式：第n行第3个数 = 2/[n(n-1)]）
  - 公式文本：红色高亮，字体加大
  - 推导提示：在公式框旁显示推导过程"分母 = n×(n-1)/2 → 倒数 = 2/[n(n-1)]"
  - 按钮状态：上一步启用，下一步启用

- 步骤4（最终步骤）：点击「下一步」
  - 新增显示：验证框（n=6时：2/[6×5] = 2/30 = 1/15... 修正为1/30）
  - 验证内容：绿色高亮"验证成功！n=6时，第3个数 = 1/30"
  - 三角形：第6行第3个数位置显示虚线框，标注"1/30"
  - 按钮状态：上一步启用，下一步禁用（或循环回到步骤0）

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - scene3-btn-prev：位于(320,455)，点击返回上一步，步骤0时禁用
  - scene3-btn-next：位于(500,455)，点击进入下一步，步骤4时禁用
  - scene3-step-indicator：位于(380,465)，显示当前步骤"步骤 X/5"
- 教师操作流程：
  1. 初始展示完整三角形，引导学生观察数阵结构
  2. 点击下一步，高亮第3个数序列，引导学生关注目标位置
  3. 点击下一步，展示分母规律，引导学生发现数值模式
  4. 点击下一步，展示通项公式，讲解公式推导过程
  5. 点击下一步，验证公式正确性，巩固理解
  6. 可随时点击上一步回顾前面内容

[技术实现]
- JS 库选择：原生 SVG + MathJax（数学公式渲染）
  - 原因：三角形数阵为简单文本布局，SVG 易于控制位置和样式；MathJax 用于渲染分数公式
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │                        三角形数阵区                         │
  │                    (第1行)        1/1                       │
  │                  (第2行)    1/2       1/2                   │
  │                (第3行)  1/3   1/6     1/3                   │
  │              (第4行) 1/4  1/12  1/12   1/4                  │
  │            (第5行)1/5 1/20 1/30 1/20   1/5                  │
  │                                                             │
  │  右侧信息区：                                               │
  │  ┌─────────────────┐  ┌─────────────────┐                  │
  │  │ 第3个数序列     │  │ 分母规律        │                  │
  │  │ 1/6 (蓝)        │  │ 6, 12, 30...    │                  │
  │  │ 1/12 (蓝)       │  └─────────────────┘                  │
  │  │ 1/30 (蓝)       │                                       │
  │  └─────────────────┘  ┌─────────────────┐                  │
  │                       │ 通项公式        │                  │
  │                       │ 2/[n(n-1)] (红) │                  │
  │                       └─────────────────┘                  │
  │                       ┌─────────────────┐                  │
  │                       │ 验证：n=6→1/30  │                  │
  │                       └─────────────────┘                  │
  │                                                             │
  ├─────────────────────────────────────────────────────────────┤
  │  控件栏：  [◀ 上一步]  步骤 1/5  [下一步 ▶]                 │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：currentStep变量(0-4)，updateScene()函数根据currentStep显示/隐藏对应元素
  2. 坐标计算：三角形每行y坐标=40+(行号-1)×40，x坐标居中计算
  3. 分数渲染：使用MathJax.tex2svg('\\frac{1}{n}')生成SVG元素
  4. 高亮效果：通过添加/移除CSS类(highlight-blue, highlight-red, highlight-green)实现
  5. 事件绑定：按钮点击事件监听，更新currentStep后调用updateScene()
  6. 按钮状态：currentStep=0时prev按钮disabled，currentStep=4时next按钮disabled
- ID 命名规范：所有元素ID以"scene3-"为前缀
  - 三角形元素：scene3-row-{1-5}-col-{1-5}
  - 高亮框：scene3-highlight-box, scene3-pattern-box, scene3-formula-box, scene3-verify-box
  - 序列值：scene3-seq-{1-3}
  - 标签：scene3-row-label-{1-5}, scene3-col3-label
  - 按钮：scene3-btn-prev, scene3-btn-next
  - 指示器：scene3-step-indicator
- IIFE 隔离：所有 JS 代码包裹在(function() { ... })()中，避免全局污染
