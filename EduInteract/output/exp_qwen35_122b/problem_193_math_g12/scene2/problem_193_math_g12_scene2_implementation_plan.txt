[分步序列]
- 步骤0（初始状态）：显示完整立体图（半圆锥+三棱锥组合），标注高度a，显示底面分解图（半圆+等腰三角形），右侧公式区显示"几何体由半圆锥和三棱锥组成"
- 步骤1：半圆锥部分高亮（蓝色#1565c0填充20%），右侧公式区显示"半圆锥底面：半圆，半径r=1"，底面积公式"S₁ = πr²/2 = π/2"
- 步骤2：保持半圆锥高亮，右侧公式区显示"半圆锥体积：V₁ = (1/3)×S₁×h = (1/3)×(π/2)×a = πa/6"
- 步骤3：三棱锥部分高亮（绿色#2e7d32填充20%），半圆锥取消高亮，右侧公式区显示"三棱锥底面：等腰三角形，底=2，高=1"，底面积公式"S₂ = (1/2)×2×1 = 1"
- 步骤4：保持三棱锥高亮，右侧公式区显示"三棱锥体积：V₂ = (1/3)×S₂×h = (1/3)×1×a = a/3"
- 步骤5：两部分同时高亮，右侧公式区显示"总体积：V = V₁ + V₂ = πa/6 + a/3 = (π+2)a/6"
- 步骤6：立体图恢复常态，右侧公式区显示"已知 V = (π+2)/6，代入得：(π+2)a/6 = (π+2)/6"，下方显示"解得：a = 1"（红色#c62828粗体）

  3. 动画曲线：高亮效果使用CSS transition(0.3s ease)实现平滑过渡
