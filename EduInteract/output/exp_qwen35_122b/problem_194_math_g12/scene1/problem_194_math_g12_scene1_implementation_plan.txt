[分步序列]
- 步骤 0（初始状态）：显示四面体 ABCD 的基本框架，仅标注顶点 A、B、C、D（四个圆点和四条可见棱 AB、AC、AD、BD、CD，以及虚线棱 BC）
- 步骤 1：标注棱长条件 BC=2（在棱 BC 外侧显示蓝色文字），AD=2c（在棱 AD 左侧显示蓝色文字）
- 步骤 2：标注椭圆条件 AB+BD=2a（绿色弧线连接 AB 和 BD，显示绿色文字），AC+CD=2a（绿色弧线连接 AC 和 CD，显示绿色文字）
- 步骤 3：高亮显示 AD⊥BC 的垂直关系（在 AD 与 BC 的公垂线位置添加红色直角符号）
- 步骤 4：显示体积公式提示 V = (1/6)×AD×BC×d（在右下角显示蓝色提示框，d 为 AD 与 BC 的公垂距离）

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 按钮"◀ 上一步"：位置(250,450)，作用：返回上一状态
  - 按钮"下一步 ▶"：位置(550,450)，作用：进入下一状态
  - 步骤指示器：位置(400,450)，显示"步骤 1/5"
- 教师操作流程：
  1. 初始展示四面体框架，让学生识别四个顶点
  2. 点击"下一步"，标注已知棱长 BC=2 和 AD=2c
  3. 点击"下一步"，展示椭圆约束条件 AB+BD=2a 和 AC+CD=2a
  4. 点击"下一步"，强调 AD 与 BC 的垂直关系
  5. 点击"下一步"，给出体积公式提示，引导学生思考如何求公垂距离 d

- 关键实现要点：
  1. 状态机设计：使用变量 currentStep 记录当前步骤（0-4），根据 currentStep 控制各元素的 display 属性
  2. 坐标计算：四面体采用透视投影，A(200,380)、D(200,120) 竖直排列，B(420,360)、C(580,220) 形成底面
  3. 动画曲线：元素出现使用 opacity 渐变（0→1，duration 300ms）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后重新渲染
  5. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-vertex-a、scene1-edge-ab、scene1-btn-prev 等）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 元素分组：使用 SVG <g> 元素按步骤分组，便于批量控制显示/隐藏
