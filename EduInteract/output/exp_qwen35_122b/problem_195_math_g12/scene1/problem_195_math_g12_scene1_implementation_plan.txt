- JS 库选择：原生 SVG + 原生 JavaScript（几何图形简单，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：

  ```
  │                    图示区 800×500                       │

  │           C(550,135)                                    │
  │            ●                                            │

  │  (100,450)        (380,455)       (600,450)             │
  └─────────────────────────────────────────────────────────┘
  ```

- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-4) 跟踪当前步骤
  2. 元素分组：每个步骤的元素用<g id="scene1-stepN">分组，通过 display 控制显示/隐藏
  3. 坐标计算：B 点坐标通过几何关系计算——PC 线段参数方程，B 在圆上且 PB=1
     - PC 长度 = 2√2 ≈ 2.83（从 P(350,350) 到 C(550,150)）
     - B 点位置：从 P 沿 PC 方向移动 1 单位
     - 方向向量：(200, -200)，单位向量：(1/√2, -1/√2)
     - B = P + 1×(1/√2, -1/√2) ≈ (350+0.707, 350-0.707) ≈ (350.7, 349.3)
     - 但 B 也需在圆上，重新计算：
     - 圆方程：(x-550)² + (y-250)² = 100²
     - PC 直线方程：y - 350 = -1(x - 350) → y = -x + 700
     - 代入圆方程：(x-550)² + (-x+700-250)² = 10000
     - (x-550)² + (450-x)² = 10000
     - 解得 x ≈ 430, y ≈ 270
     - B 点坐标：(430, 270)
  4. 动画曲线：元素出现使用 opacity 过渡 (0→1)，时长 300ms
  5. 事件绑定：按钮点击事件绑定到 stepChange() 函数，更新 currentStep 并刷新显示
  6. ID 命名规范：所有元素 ID 以"scene1-"为前缀（如 scene1-circle, scene1-line-pa, scene1-btn-next）
  7. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
