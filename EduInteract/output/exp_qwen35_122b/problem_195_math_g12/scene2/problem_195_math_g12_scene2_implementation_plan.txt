[分步序列]
- 初始状态（步骤0）：显示基础图形——圆O、点P/A/B/C/O、线段PA/AC/PC、长度标注PA=2和PB=1、直角标记∠PAC。等待教师点击"下一步"
- 步骤1：点击「下一步」→ 高亮割线PC（红色4px），右侧出现定理公式框显示"切割线定理：PA² = PB × PC"，同时标注PC=4出现在PC线段上方
- 步骤2：点击「下一步」→ 高亮线段BC（红色4px），标注BC=3出现在BC段上方，公式框更新显示"BC = PC - PB = 4 - 1 = 3"
- 步骤3：点击「下一步」→ 高亮点B和∠ABC，在B点处显示直角标记，公式框显示"直径所对圆周角：∠ABC = 90°"
- 步骤4：点击「下一步」→ 高亮直径AC和△PAC，右侧出现勾股定理框"AC² = PA² + PC² = 2² + 4² = 20"，标注AC=2√3出现在AC右侧
- 步骤5：点击「下一步」→ 高亮圆心O和半径，图形下方显示最终答案"半径 R = AC/2 = √3"（绿色粗体16pt），公式框显示"R = AC/2 = 2√3/2 = √3"

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮（scene2-prev-btn）：位于控件栏左侧，点击返回上一步骤，步骤0时禁用
  - 下一步按钮（scene2-next-btn）：位于控件栏右侧，点击进入下一步骤，步骤5时禁用
  - 步骤指示器（scene2-step-indicator）：位于控件栏中央，显示当前步骤"步骤 X/5"
- 教师操作流程：
  1. 初始展示基础图形，教师介绍题目已知条件（PA=2，PB=1）
  2. 点击"下一步"，引入切割线定理，讲解PA²=PB×PC的应用
  3. 点击"下一步"，计算BC长度，强调线段关系
  4. 点击"下一步"，揭示直径所对圆周角为直角的性质
  5. 点击"下一步"，应用勾股定理求直径AC
  6. 点击"下一步"，得出半径答案，总结解题思路

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（几何图形简单，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │                        图示区 800×500                          │
  │                                                                │
  │           C(445,115)                                           │
  │             ●                                                  │
  │            /│                                                  │
  │           / │                                                  │
  │      B●  /  │                                                  │
  │     (275,265)│                                                 │
  │       /    O●(465,245)                                         │
  │      /    (450,250)                                            │
  │     /       │                                                  │
  │    /        │                                                  │
  │   /         │                                                  │
  │  /          │                                                  │
  │ ●-----------●                                                  │
  │P(125,375)  A(445,390)                                          │
  │                                                                │
  │              [定理公式框]  [勾股定理框]                         │
  │              (550,150)     (550,270)                           │
  │                                                                │
  │         ┌─────────────────────────────────┐                   │
  │         │    ◀上一步  步骤 X/5  下一步▶   │ 控件栏 y=440-490   │
  │         └─────────────────────────────────┘                   │
  │                                                                │
  └────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-5) 跟踪当前步骤，updateScene() 函数根据 currentStep 显示/隐藏对应元素
  2. 坐标计算：所有元素坐标硬编码在布局表中，B点坐标通过几何计算确定（PC线段与圆的交点）
  3. 动画曲线：元素出现使用 opacity 从0到1的过渡动画（0.3s ease-in-out）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateScene()
  5. 元素高亮：通过切换 stroke 颜色和 stroke-width 实现，高亮元素 stroke="#c62828" stroke-width="4"
  6. 公式框内容：根据步骤动态更新 innerHTML 显示不同公式
- ID 命名规范：所有交互元素 ID 以 scene2- 为前缀
  - 图形元素：scene2-circle-O, scene2-line-PA, scene2-line-AC, scene2-line-PC, scene2-point-A, scene2-point-B, scene2-point-C, scene2-point-O, scene2-point-P
  - 标签元素：scene2-label-P, scene2-label-A, scene2-label-B, scene2-label-C, scene2-label-O, scene2-label-PA, scene2-label-PB, scene2-label-PC, scene2-label-BC, scene2-label-AC, scene2-label-R
  - 公式框：scene2-formula-box, scene2-pythagoras-box
  - 直角标记：scene2-rightangle-PAC, scene2-rightangle-ABC
  - 控件：scene2-prev-btn, scene2-next-btn, scene2-step-indicator
- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染
