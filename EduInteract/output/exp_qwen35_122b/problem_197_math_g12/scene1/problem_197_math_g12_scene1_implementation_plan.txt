[分步序列]
步骤0（初始状态）：
- 显示：三角形ABC（边AB、BC、AC）、顶点标签A、B、C
- 隐藏：中位线DE、点D、点E、角度标注、中点标记、平行标记
- 目的：让学生先观察原三角形的基本结构

步骤1（标注已知角度）：
- 新增：角度∠A弧线（蓝）、角度∠A数值"26°"（蓝）、角度∠C弧线（蓝）、角度∠C数值"120°"（蓝）
- 显示：所有步骤0元素
- 目的：标注题目给出的已知角度条件

步骤2（画出中位线DE）：
- 新增：中位线DE（黑实线）、点D、点E、标签"D"、标签"E"、中点标记（AD、DB、AE、EC各一条短横线）
- 显示：所有步骤0、步骤1元素
- 目的：展示中位线的定义——连接两边中点的线段

步骤3（高亮平行关系）：
- 新增：平行标记（DE和BC上的双短线，红色）
- 显示：所有步骤0、1、2元素
- 目的：强调中位线性质——DE∥BC，为后续折叠问题做铺垫

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 按钮"◀ 上一步"：scene1-btn-prev | 位置(250,460) | 回退到上一步骤
  - 按钮"下一步 ▶"：scene1-btn-next | 位置(450,460) | 进入下一步骤
  - 步骤指示器：scene1-step-indicator | 位置(350,430) | 显示"步骤 1/4"
- 教师操作流程：
  1. 初始展示三角形ABC，引导学生识别图形结构
  2. 点击"下一步"，标注∠A=26°和∠C=120°，强调已知条件
  3. 点击"下一步"，画出中位线DE并标注中点，讲解中位线定义
  4. 点击"下一步"，高亮平行关系，引出中位线性质
  5. 可随时点击"上一步"回退复习，巩固知识点

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（线段、点、弧线、文本），原生SVG足以实现，无需引入重型库
  - 动画：使用SVG元素显隐（display/opacity）实现步骤切换

- 画布尺寸：800 × 500 px

- 布局草图（ASCII）：
```

│                    图示区 800×500                        │
```

- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-3) 跟踪当前步骤
  2. 坐标计算：
     - A(400,80) 为顶点
     - B(120,380)、C(680,380) 为底边两端点
     - D为AB中点：((400+120)/2, (80+380)/2) = (260,230)
     - E为AC中点：((400+680)/2, (80+380)/2) = (540,230)
  3. 角度弧线绘制：使用SVG path的arc命令
     - ∠A：从AB方向到AC方向的弧线
     - ∠C：从CB方向到CA方向的弧线
  4. 元素分组：每个步骤的元素用<g id="scene1-step-N">分组，通过切换display控制显示
  5. 事件绑定：按钮点击事件更新currentStep，重新渲染对应元素
  6. IIFE隔离：所有JS代码包裹在(function() { ... })()中

- ID 命名规范：
  - 所有元素ID以 scene1- 为前缀
  - 示例：scene1-tri-abc, scene1-line-de, scene1-ang-a, scene1-btn-next
