场景导航：Scene 1

题目原文：
(2011•江门一模)如图，P是圆O外一点，直线PO与圆O相交于C、D，PA、PB是圆O的切线，切点为A、B．若PC=CD=1，则四边形PADB的面积S=．

题目分析：
本题考察圆的切线性质与几何面积计算。关键信息：

  • P为圆外一点，PA、PB为切线
  • 直线PO过圆心，与圆交于C、D两点
  • PC=CD=1，可推导出圆的半径和PO长度
  • 求四边形PADB的面积

核心几何关系：

  1. 由PC=CD=1，得圆半径 r = CD/2 = 0.5
  2. PO = PC + CO = 1 + 0.5 = 1.5
  3. 切线性质：OA⊥PA，OB⊥PB，且PA=PB
  4. 图形关于直线PO对称

解题思路：
四边形PADB可分解为△PAD + △PBD，或利用对称性计算△PAB + △ABD。关键是求出切线长PA和弦AB的长度。

图示规划：
设计1个主图示，完整展示几何图形、已知条件标注、辅助线及计算关系，通过分步导航引导教师从基础图形逐步展示到完整解题要素。

教学说明：

本图示用于完整讲解圆的切线性质与面积计算问题。教师应按以下步骤引导学生：

步骤0→步骤1：引入切线概念
从基础圆和外部点P开始，逐步添加切线PA、PB。强调切线的定义：与圆只有一个公共点的直线。引导学生观察切点A、B的位置特征。

步骤1→步骤2：揭示切线性质
添加半径OA、OB，展示切线垂直于过切点的半径这一核心性质。直角符号是关键视觉提示，帮助学生识别直角三角形△PAO和△PBO。

关键推导：

  1. 由PC=CD=1，得圆半径 r = CD/2 = 0.5
  2. PO = PC + CO = 1 + 0.5 = 1.5
  3. 在Rt△PAO中，由勾股定理：PA = √(PO² - OA²) = √(1.5² - 0.5²) = √2

步骤2→步骤3：构建目标图形
添加弦AB，完整呈现四边形PADB。利用对称性说明：PA=PB，图形关于PO对称，因此四边形PADB面积 = 2 × △PAD面积。

步骤3→步骤4：面积计算
展示计算所需的辅助线和关键长度。四边形PADB面积计算：

  • 方法一：S = S△PAD + S△PBD = 2 × S△PAD
  • 方法二：S = S△PAB + S△ABD
  • 推荐方法：利用对称性，S = PA × AB / 2 × 2 = PA × AB

课堂讲解建议：

  • 先让学生观察图形对称性
  • 引导发现切线垂直半径的关键性质
  • 逐步推导各线段长度
  • 最后完成面积计算
  • 强调几何问题的"看图找关系"思维
