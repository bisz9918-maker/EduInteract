[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 按钮"◀ 上一步"：位置 (280,460)，作用：返回上一步骤，若已在步骤 0 则禁用
  - 按钮"下一步 ▶"：位置 (520,460)，作用：进入下一步骤，若已在步骤 4 则禁用
- 教师操作流程：
  1. 初始展示基础图形（圆、点 P、直线 PO、已知条件 PC=1、CD=1）
  2. 点击"下一步"添加切线 PA、PB 和切点 A、B，讲解切线定义
  3. 点击"下一步"添加半径 OA、OB，强调切线垂直半径性质
  4. 点击"下一步"添加弦 AB 和四边形 PADB，明确待求面积区域
  5. 点击"下一步"显示关键长度标注，引导学生进行面积计算

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
```
┌─────────────────────────────────────────────────────────────┐
│                        图示区 800×500                        │
│                                                             │
│           B●                                               │
│          / │\                                               │
│         /  │  \                                              │
│        /   │   \                                             │
│       /    │    \                                            │
│  P●─/────C─●O─D●───────> 水平线 PO                           │
│   \  │    │   /                                              │
│    \ │    │  /                                               │
│     \│    │ /                                                │
│      ●A   │                                                  │
│                                                             │
│   [圆 O 居中偏右，P 在左侧，A 下 B 上对称]                      │
│                                                             │
│  ┌───────────────────────────────────────────────────────┐  │
│  │              控件栏（SVG 内底部 y=440~490）              │  │
│  │          [◀ 上一步]              [下一步 ▶]             │  │
│  └───────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────┘
```

- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-4) 跟踪当前步骤，每一步定义要显示/隐藏的元素 ID 列表
  2. 坐标计算：所有几何元素坐标预先计算好，硬编码在 SVG 中
  3. 动画曲线：步骤切换使用 opacity 渐变（0.3s ease-in-out）实现平滑过渡
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateScene() 刷新显示
  5. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-circle-o, scene1-line-pa, scene1-label-a）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染

- SVG 元素 ID 命名示例：
  - 圆：scene1-circle-o
  - 点：scene1-point-p, scene1-point-o, scene1-point-c, scene1-point-d, scene1-point-a, scene1-point-b
  - 线段：scene1-line-po, scene1-line-pa, scene1-line-pb, scene1-line-oa, scene1-line-ob, scene1-line-ab, scene1-line-ad, scene1-line-bd
  - 标签：scene1-label-p, scene1-label-o, scene1-label-c, scene1-label-d, scene1-label-a, scene1-label-b
  - 标注：scene1-annot-pc, scene1-annot-cd, scene1-annot-po, scene1-annot-oa, scene1-annot-pa
  - 直角符号：scene1-rightangle-a, scene1-rightangle-b
  - 四边形填充：scene1-quad-padb
  - 按钮：scene1-btn-prev, scene1-btn-next

- updateScene() 函数逻辑：
  1. 根据 currentStep 确定要显示的元素集合
  2. 遍历所有可显示元素，根据其所属步骤设置 display="block" 或 display="none"
  3. 更新按钮状态（步骤 0 禁用"上一步"，步骤 4 禁用"下一步"）
