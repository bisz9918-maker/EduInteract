[图示主题与整合说明]
- 本图示主题：直线y=kx+t参数t变化对交点M、N位置及△OMN面积的影响
- 整合内容：正六边形几何结构、直线方程动态展示、t参数滑块控制、交点M/N动态追踪、△OMN面积实时计算显示
- 教学价值：教师可通过拖动滑块观察t值变化时交点位置和面积的变化规律，引导学生发现S=f(t)的奇偶性（偶函数），理解参数变化对几何图形面积的影响

[分步序列]
本场景为连续拖拽交互，无分步导航，状态随滑块实时变化：

- 初始状态（t=0）：
  - 显示正六边形ABCDEF（半透明黑色边框）
  - 显示坐标轴x、y
  - 直线L过原点（t=0），M、N重合于O点
  - △OMN面积为0（不可见或极小）
  - 面积显示：S = 0
  - t值显示：t = 0
  - 滑块手柄位于轨道中点

- 拖动滑块t>0（向上）：
  - 直线L向上平移
  - M点出现在左下方边（AF或AB），N点出现在右上方边（ED或DC）
  - △OMN区域出现，蓝色半透明填充
  - 面积S随t增大而增大
  - y轴截距标记显示t值位置
  - 面积显示实时更新

- 拖动滑块t<0（向下）：
  - 直线L向下平移
  - M、N位置关于原点对称变化
  - △OMN面积变化规律与t>0时相同（验证偶函数性质）
  - 面积显示实时更新

[交互方案]
- 交互类型：连续拖拽滑块 — t参数实时控制
- 控件说明：
  1. 滑块轨道：位于(250,460)-(550,460)，绿色，表示t值范围[-80, 80]
  2. 滑块手柄：12px绿色圆，可拖拽，位置对应t值
  3. 面积显示：右上角(620,40)，实时显示S=f(t)值
  4. t值显示：(620,70)，实时显示当前t值
- 教师操作流程：
  1. 初始展示t=0状态，说明直线过原点时M、N重合
  2. 向右拖动滑块（t>0），观察直线向上平移，M、N分离，△OMN面积增大
  3. 向左拖动滑块（t<0），观察直线向下平移，M、N对称变化
  4. 对比t和-t时的面积值，引导学生发现S(t)=S(-t)，得出偶函数结论

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（几何计算简单，无需复杂图表库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │ 800×500 SVG 画布                                          │
  │                                                          │
  │     E(350,163) ───── D(450,163)                         │
  │        ╲              ╱    ╲                              │
  │         ╲            ╱      ╲                             │
  │   F(300,250) ─── O(400,250)  N(动态)                      │
  │         ╱            ╲      ╱                             │
  │        ╱              ╲    ╱                              │
  │     A(350,337) ───── B(450,337)                         │
  │                                                          │
  │     直线L：y=kx+t（蓝色，随t变化）                         │
  │     △OMN（蓝色半透明填充）                                │
  │                                                          │
  │     面积S显示(620,40)  t值显示(620,70)                    │
  │                                                          │
  │     滑块控件(250,460)-(550,460)                          │
  └─────────────────────────────────────────────────────────┘
  ```

- 关键实现要点：
  1. 正六边形顶点坐标计算：边长a=100，中心(400,250)，AB∥x轴
     - 顶点角度：C=0°, D=60°, E=120°, F=180°, A=240°, B=300°
     - 坐标公式：x=400+a×cos(θ), y=250-a×sin(θ)（注意y轴向下为正）
  
  2. 直线与正六边形交点计算：
     - 直线方程：y = kx + t（k固定为0.8，使直线斜穿六边形）
     - 六边形六条边分别用线段方程表示
     - 求直线与各边的交点，筛选在边范围内的交点
     - M为左下方交点，N为右上方交点
  
  3. △OMN面积计算：
     - 使用向量叉积公式：S = 0.5 × |OM × ON|
     - OM = (Mx, My), ON = (Nx, Ny)
     - S = 0.5 × |Mx×Ny - My×Nx|
  
  4. 滑块交互：
     - 监听mousedown、mousemove、mouseup事件
     - 根据鼠标x坐标计算t值：t = (mouseX - 250) × (80/300) - 80
     - 限制t范围[-80, 80]
     - 实时更新直线、交点、面积显示
  
  5. 重绘机制：
     - t值变化时，清除并重新绘制直线L、交点M/N、△OMN、截距标记
     - 使用requestAnimationFrame保证动画流畅
  
  6. ID命名规范：所有元素ID以"scene2-"为前缀
     - 如：scene2-hexagon, scene2-line, scene2-point-m, scene2-point-n, scene2-slider, scene2-area-display
  
  7. IIFE隔离：所有JS代码包裹在(function() { ... })()中，避免全局污染

- 坐标计算细节：
  - 正六边形顶点（以像素为单位，中心(400,250)，边长100）：
    - C: (500, 250)
    - D: (450, 163.4)
    - E: (350, 163.4)
    - F: (300, 250)
    - A: (350, 336.6)
    - B: (450, 336.6)
  
  - 直线L绘制范围：x从200到600，y = 0.8×(x-400) + (250-t)
  
  - 交点计算：遍历六条边，求直线与每条边的交点，保留在边范围内的点
  
  - 面积显示格式："S = " + S.toFixed(2)

- 事件绑定：
  - 滑块手柄：mousedown开始拖拽
  - document：mousemove（拖拽中）、mouseup（结束拖拽）
  - 防止文本选择：e.preventDefault()
