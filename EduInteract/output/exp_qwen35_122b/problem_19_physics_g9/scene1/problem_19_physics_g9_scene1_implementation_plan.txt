[视觉元素清单]
- 电源：电池组符号（顶部中央），正极在上（长线），负极在下（短线）
- 开关：单刀开关符号（电源下方），初始为断开状态
- 铅笔芯 AB：粗黑水平线段（底部），长度 500px，线宽 8px
- 滑片 P：绿色箭头（从开关向下指向铅笔芯）
- 电流表 A₁、A₂：圆形仪表（左右两侧），内部填充 20% 透明度
- 导线：细黑线连接各元件
- 电流方向箭头：蓝色（I₁ 支路）、红色（I₂ 支路）
- 颜色规格：
  - 背景：#ffffff
  - 主线/导线：#000000
  - 蓝高亮（AP 段及 A₁ 支路）：#1565c0
  - 红高亮（PB 段及 A₂ 支路）：#c62828
  - 绿高亮（滑片 P）：#2e7d32
  - 辅助线：#888888 虚线

[分步序列]
- 步骤 0（初始状态）：
  - 显示：电源（电池组）、开关
  - 位置：电源 (390,40)-(410,85)，开关 (395,95)-(405,120)
  - 标签：电源正极"+"、负极"-"

- 步骤 1：
  - 新增：铅笔芯 AB、滑片 P、滑片导线

- 步骤 2：

  - A₁：(100,250) 圆形仪表，蓝色边框

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "上一步"按钮：scene1-btn-prev，位置 (320,460)，作用：返回上一状态
  - "下一步"按钮：scene1-btn-next，位置 (460,460)，作用：进入下一状态
  - 步骤指示器：scene1-step-indicator，位置 (370,465)，显示"步骤 1/5"
- 教师操作流程：
  1. 从步骤 0 开始，先讲解电源和开关的作用
  2. 点击"下一步"展示铅笔芯和滑片，讲解滑动变阻器原理
  3. 继续点击展示导线连接，强调并联支路的形成
  4. 展示电流表，说明测量位置
  5. 最后展示电流流向，讲解并联电路电流分配规律
  6. 可随时点击"上一步"回顾重点

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：电路图属于几何图形，SVG 矢量绘图清晰，易于控制元素显示/隐藏
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────┐
  │                    电源 (+)                             │
  │                      │                                  │
  │                    开关                                  │
  │                      │                                  │
  │         ┌────────────┴────────────┐                     │
  │         │                         │                     │
  │       [A₁]                       [A₂]                   │
  │         │                         │                     │
  │         │                         │                     │
  │    A────┴────c────d────P────B                          │
  │  (铅笔芯 AB，滑片 P 可滑动)                              │
  │                                                         │
  │        [◀上一步]  步骤 1/5  [下一步▶]                   │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：currentStep 变量 (0-4)，控制各元素 display 属性
  2. 坐标计算：所有元素按布局坐标表精确绘制
  3. 动画曲线：元素出现使用 opacity 渐变 (0→1)，0.3s 过渡
  4. 事件绑定：按钮点击事件监听，更新 currentStep 并刷新视图
  5. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-battery、scene1-switch、scene1-wire-left 等）
  6. 使用 getElementById 获取元素，避免 querySelectorAll 全局选择
  7. 所有 JS 代码包在 IIFE (function() { ... })() 中隔离作用域
  8. 步骤 4 的电流箭头使用 animate 属性实现流动效果
