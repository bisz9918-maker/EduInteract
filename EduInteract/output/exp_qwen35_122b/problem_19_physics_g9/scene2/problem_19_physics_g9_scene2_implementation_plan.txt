[图示主题与整合说明]
- 本图示主题：电流比值与滑动范围的关系（物理九年级电路问题）
- 整合内容：并联电路电流分配原理、电流表量程限制、滑动变阻器工作原理、比值计算

[分步序列]
本场景为连续拖拽交互，无分步导航，但有状态变化：

- 初始状态（量程 0-0.6A）：
  - 显示完整电路图（AB、A₁、A₂、电源、开关）
  - 滑片 P 位于中间位置 (x=250px，对应物理位置约 L/2)
  - c、d 标记显示，允许区域高亮（绿色）
  - 禁止区域灰色填充
  - 数据显示：I₁、I₂、I₁/I₂ 实时计算显示
  - 量程按钮 0-0.6A 高亮选中

- 拖拽交互（持续状态）：
  - 拖动滑片 P 时，x 和 L-x 实时变化
  - I₁ = U/(R_AP) = U/(k·x)，I₂ = U/(R_PB) = U/(k·(L-x))
  - 比值 I₁/I₂ = (L-x)/x 实时计算
  - 当 P 超出 c-d 范围时，对应电流表超量程，显示警告
  - 允许区域保持绿色高亮，禁止区域保持灰色

- 量程切换状态（0-3A）：
  - 点击 0-3A 按钮后，c、d 位置重新计算
  - 允许滑动范围扩大（因为量程增大，允许更大电流）
  - 数据显示刷新，最大比值变化
  - 量程按钮 0-3A 高亮选中

[交互方案]
- 交互类型：连续拖拽滑块 + 量程切换按钮
- 控件说明：
  1. 滑片 P 箭头：可直接拖拽，在 AB 线段上移动
  2. 底部滑块：水平滑块，拖动控制 P 位置，与滑片 P 同步
  3. 量程按钮 0-0.6A：点击切换至小量程模式，c-d 范围缩小
  4. 量程按钮 0-3A：点击切换至大量程模式，c-d 范围扩大
- 教师操作流程：
  1. 初始展示 0-0.6A 量程，讲解允许滑动范围 c-d 的含义
  2. 拖动滑片 P，观察 I₁、I₂ 变化，演示当 P 接近 c 或 d 时电流达到最大值
  3. 计算并解释最大比值 3:1 的条件（P 在 c 或 d 处）
  4. 切换至 0-3A 量程，对比新的 c-d 位置和允许范围
  5. 引导学生理解量程增大后，允许通过更大电流，滑动范围扩大

- 画布尺寸：800 × 500 px

- 关键实现要点：
  1. 状态机设计：
     - 状态变量：pPosition（滑片 x 坐标，150-650）、rangeMode（'0.6' 或 '3'）
     - c、d 位置根据 rangeMode 计算：0.6A 时 c=250,d=450；3A 时重新计算
     - 电流计算：I₁ = I_max × (L-x)/L，I₂ = I_max × x/L（简化模型）
     - 比值计算：ratio = I₁/I₂ = (L-x)/x

  2. 坐标计算：
     - 物理位置映射：pPosition (150-650) → x (0-L)
     - L = 500px（AB 线段长度）
     - x = pPosition - 150
     - L-x = 500 - x

  3. 拖拽实现：
     - 滑片 P 和底部滑块手柄绑定 mousedown/mousemove/mouseup 事件
     - 拖动时限制在 AB 线段范围内（150-650）
     - 实时更新所有相关数值和显示

  4. 量程切换：
     - 点击按钮切换 rangeMode
     - 根据量程重新计算 c、d 位置
     - 0.6A 时：I_max = 0.6A，c、d 对应电流达到 0.6A 的位置
     - 3A 时：I_max = 3A，c、d 范围扩大
     - 更新允许/禁止区域填充

  5. 警告提示：
     - 当 P 在禁止区域时，对应电流表显示警告（边框变红闪烁）
     - 数据显示框中超限数值用红色高亮

- ID 命名规范：所有交互元素 ID 以"scene2-"为前缀
  - scene2-p-slider（滑片 P）
  - scene2-range-slider（底部滑块）
  - scene2-btn-0.6（0.6A 按钮）
  - scene2-btn-3（3A 按钮）
  - scene2-display-i1、scene2-display-i2、scene2-display-ratio（数据显示）
  - scene2-allow-zone、scene2-forbid-left、scene2-forbid-right（区域填充）

- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
