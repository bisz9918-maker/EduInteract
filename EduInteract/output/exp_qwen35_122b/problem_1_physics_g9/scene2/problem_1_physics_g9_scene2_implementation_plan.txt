[图示主题与整合说明]
- 本图示主题：四个力的力臂长度对比
- 整合的内容：将杠杆平衡问题中四个候选力的力臂同时展示并进行长度对比，直观呈现 F₃ 力臂最长的结论
- 教学价值：教师可通过状态切换，逐一讲解每个力的力臂定义和长度比较，帮助学生理解"力臂最长则所需力最小"的杠杆原理

[分步序列]
状态0（默认/全部对比）：
- 显示：杠杆、支点、O/A/B标签、重物G、G力箭头、四个力箭头F₁-F₄
- 四个力臂L₁-L₄全部显示为灰色虚线
- 状态提示框显示："F₃的力臂L₃=OB，是最长的"
- 所有力臂末端有长度标记线

状态1（点击F₁按钮）：
- 高亮：F₁箭头变为绿色加粗，L₁力臂变为绿色实线
- 其他力臂L₂/L₃/L₄保持灰色虚线且透明度降低至30%
- 状态提示框显示："L₁ < OB（F₁力臂最短）"

状态2（点击F₂按钮）：
- 高亮：F₂箭头变为绿色加粗，L₂力臂变为绿色实线
- 其他力臂L₁/L₃/L₄保持灰色虚线且透明度降低至30%
- 状态提示框显示："L₂ < OB（F₂力臂较短）"

状态3（点击F₃按钮）：
- 高亮：F₃箭头变为绿色加粗，L₃力臂变为绿色实线
- 其他力臂L₁/L₂/L₄保持灰色虚线且透明度降低至30%
- 状态提示框显示："L₃ = OB（最大）"

状态4（点击F₄按钮）：
- 高亮：F₄箭头变为绿色加粗，L₄力臂变为绿色实线
- 其他力臂L₁/L₂/L₃保持灰色虚线且透明度降低至30%
- 状态提示框显示："L₄ < OB（F₄力臂较短）"

状态5（点击"全部对比"按钮）：
- 四个力臂同时显示，L₃明显最长

[交互方案]
- 交互类型：多状态切换（5个状态按钮）
- 控件说明：
  - 按钮"F₁"：位置(150,450)，切换到F₁力臂高亮状态
  - 按钮"F₂"：位置(230,450)，切换到F₂力臂高亮状态
  - 按钮"F₃"：位置(310,450)，切换到F₃力臂高亮状态
  - 按钮"F₄"：位置(390,450)，切换到F₄力臂高亮状态
  - 按钮"全部对比"：位置(470,450)，切换到全部力臂对比状态
- 教师操作流程：
  1. 初始状态展示所有力臂，让学生观察
  2. 依次点击F₁-F₄按钮，逐一讲解每个力的力臂
  3. 最后点击"全部对比"，总结F₃力臂最长的结论
  4. 可反复切换按钮进行复习对比

[技术实现]
- JS库选择：原生SVG + 原生JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
```
┌─────────────────────────────────────────────────────────┐
│                    状态提示框 (200,100)                  │
│                                                         │
│           F₄ ↖          F₃ ↑          F₂ ↗              │
│                                                         │
│    O━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ B          │
│    △              A              G↓                     │
│                                                         │
│           F₁ ↘                                          │
│                                                         │
│  [F₁]  [F₂]  [F₃]  [F₄]  [全部对比]                     │
│  (150) (230) (310) (390)   (470)                        │
└─────────────────────────────────────────────────────────┘
```

- 关键实现要点：
  1. 状态机设计：用变量currentState记录当前状态(0-5)
  2. 力臂绘制：L₃与杠杆重合，用绿色实线覆盖；其他力臂用虚线
  3. 高亮切换：通过改变stroke和strokeWidth属性实现
  4. 透明度控制：用opacity属性控制非高亮力臂的透明度
  5. 事件绑定：每个按钮绑定click事件，切换状态并更新显示

- ID命名规范：所有交互元素ID以"scene2-"为前缀
  - 力臂：scene2-arm-L1, scene2-arm-L2, scene2-arm-L3, scene2-arm-L4
  - 力箭头：scene2-force-F1, scene2-force-F2, scene2-force-F3, scene2-force-F4
  - 按钮：scene2-btn-F1, scene2-btn-F2, scene2-btn-F3, scene2-btn-F4, scene2-btn-all
  - 提示框：scene2-status-text

- IIFE隔离：所有JS代码包在(function() { ... })()中，避免全局污染
