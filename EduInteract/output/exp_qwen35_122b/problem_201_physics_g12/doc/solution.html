场景导航：Scene 1 | Scene 2

题目原文：
如图所示，质量为 m，带电量为 q 的粒子，以初速度 v₀，从 A 点竖直向上射入真空中的沿水平方向的匀强电场中，粒子通过电场中 B 点时，速率 v_B=2v₀，方向与电场的方向一致，问：
（1）水平方向和竖直方向分别作什么运动？
（2）从 A 到 B 竖直方向位移是多少？
（3）从 A 到 B 重力做的功是多少？
（4）从 A 到 B 电场力做的功是多少？
（5）A，B 两点的电势差是多少？

题目分析：
本题是带电粒子在重力场和匀强电场复合场中的运动问题。粒子同时受到竖直向下的重力 mg 和水平方向的电场力 qE 作用。

关键条件：

  • A 点：初速度 v₀ 竖直向上，水平速度为 0
  • B 点：末速度 v_B = 2v₀ 水平向右，竖直速度为 0

解题思路：

  1. 运动分解：将运动分解为水平和竖直两个方向
  • 竖直方向：只受重力，初速度 v₀ 向上 → 竖直上抛运动（匀减速）
  • 水平方向：只受电场力，初速度为 0 → 匀加速直线运动
  1. 竖直方向分析：
  • 从 A 到 B，竖直速度从 v₀ 减到 0
  • 由 v² = v₀² - 2gh，得 h = v₀²/(2g)
  1. 重力做功：W_G = -mgh = -mg·v₀²/(2g) = -mv₀²/2
  1. 电场力做功：由动能定理
  • ΔE_k = ½m(2v₀)² - ½mv₀² = ½m·4v₀² - ½mv₀² = 3mv₀²/2
  • WE + WG = ΔE_k
  • WE = ΔEk - W_G = 3mv₀²/2 - (-mv₀²/2) = 2mv₀²
  1. 电势差：WE = qUAB，得 UAB = WE/q = 2mv₀²/q

步骤 1/5

Scene 1 教学说明：

本图示展示带电粒子在复合场中的运动分解过程，教师应引导学生按以下步骤观察：

步骤 0-1：初始状态与受力分析

  1. 首先让学生观察 A 点的初始条件：速度 v₀ 竖直向上，水平方向速度为 0
  2. 引导学生分析受力：粒子同时受重力 mg（竖直向下）和电场力 qE（水平向右）
  3. 提问：这两个力分别影响哪个方向的运动？

步骤 2-3：运动分解与轨迹形成

  1. 竖直方向：只受重力，初速度向上 → 竖直上抛运动（匀减速直线运动）
  2. 水平方向：只受电场力，初速度为 0 → 匀加速直线运动
  3. 两个分运动的合成形成抛物线轨迹
  4. 关键观察：到达 B 点时竖直速度减为 0，水平速度达到 2v₀

步骤 4：速度分量对比

  1. A 点：vx = 0，vy = v₀
  2. B 点：vx = 2v₀，vy = 0
  3. 引导学生理解：竖直方向速度从 v₀ 减到 0，水平方向速度从 0 增到 2v₀

关键公式推导：
竖直方向（竖直上抛）：

  • 由 vy² = v₀² - 2gh，B 点 vy = 0
  • 得 h = v₀²/(2g)

重力做功：

  • W_G = -mgh = -mv₀²/2

教学要点：

  • 强调运动的独立性原理：两个方向的运动互不影响
  • 引导学生理解 B 点速度方向水平的物理意义：竖直速度恰好减为 0

Scene 2 教学说明：

本图示展示能量关系和电势差计算，教师应引导学生按动能定理的逻辑顺序进行推导：

步骤 0-1：动能变化计算

  1. A 点动能：E_kA = ½mv₀²
  2. B 点动能：E_kB = ½m(2v₀)² = 2mv₀²
  3. 动能变化：ΔEk = EkB - E_kA = 2mv₀² - ½mv₀² = 3mv₀²/2
  4. 提问：动能增加了，说明合外力做正功

步骤 2：重力做功

  1. 竖直方向是竖直上抛运动，从 A 到 B 竖直速度从 v₀ 减到 0
  2. 由运动学公式：v_y² = v₀² - 2gh，得 h = v₀²/(2g)
  3. 重力做功：W_G = -mgh = -mg·v₀²/(2g) = -mv₀²/2
  4. 强调：重力做负功，因为位移向上，重力向下

步骤 3：电场力做功

  1. 应用动能定理：W合 = ΔEk
  2. WE + WG = ΔE_k
  3. WE = ΔEk - W_G = 3mv₀²/2 - (-mv₀²/2) = 2mv₀²
  4. 强调：电场力做正功，因为电场力方向与水平位移方向一致

步骤 4：电势差计算

  1. 电场力做功与电势差关系：WE = qUAB
  2. UAB = WE/q = 2mv₀²/q
  3. 说明：U_AB > 0，说明 A 点电势高于 B 点（正电荷从高电势到低电势，电场力做正功）

完整解答汇总：
（1）水平方向：初速为 0 的匀加速直线运动；竖直方向：竖直上抛运动（匀减速直线运动）
（2）竖直位移：h = v₀²/(2g)
（3）重力做功：W_G = -mv₀²/2
（4）电场力做功：W_E = 2mv₀²
（5）电势差：U_AB = 2mv₀²/q

课堂讲解建议：

  1. 先让学生独立分析两个方向的运动类型，再展示 Scene 1
  2. 引导学生用动能定理求解，而不是分别求电场强度和位移
  3. 强调能量方法的简洁性：不需要知道电场强度 E 和水平位移 x
  4. 最后总结：复合场问题可以用运动分解或能量方法解决，本题用能量方法更简便
