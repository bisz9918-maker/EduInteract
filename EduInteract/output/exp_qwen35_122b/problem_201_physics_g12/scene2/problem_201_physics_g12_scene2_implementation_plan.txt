[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "上一步"按钮：scene2-btn-prev，位于底部左侧(260,455)，点击返回上一状态
  - "下一步"按钮：scene2-btn-next，位于底部右侧(420,455)，点击进入下一状态
- 教师操作流程：
  1. 初始展示粒子运动情景（步骤0）
  2. 点击"下一步"展示动能计算（步骤1），讲解动能公式
  3. 点击"下一步"展示重力做功（步骤2），讲解重力做负功
  4. 点击"下一步"展示电场力做功和动能定理（步骤3），讲解能量守恒
  5. 点击"下一步"展示电势差计算（步骤4），得出最终结论
  6. 可随时点击"上一步"回顾某一步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形和动画，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    电场线区域 (y=80~360)                │
  │  ────────────────────────────────────────────────────   │
  │  ────────────────────────────────────────────────────   │
  │           B●──────────→v_B=2v₀                          │
  │  ────────────────────────────────────────────────────   │
  │  ────────────────────────────────────────────────────   │
  │  ────────────────────────────────────────────────────   │
  │           A●↑v₀                                         │
  │                                                       │
  │  [动能框]  [做功箭头]  [公式框]  [电势差]              │
  │                                                       │
  │          [◀上一步]        [下一步▶]                    │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量currentStep(0-4)跟踪当前步骤，updateScene()函数根据currentStep显示/隐藏元素
  2. 坐标计算：所有元素使用绝对坐标，通过SVG transform或直接设置x/y属性
  3. 动画曲线：使用CSS transition实现淡入淡出(0.3s ease)，脉冲动画用keyframes
  4. 事件绑定：按钮点击事件绑定到updateScene()，检查边界后改变currentStep
  5. ID命名规范：所有元素ID以scene2-为前缀（如scene2-point-A、scene2-arrow-WG、scene2-btn-next）
  6. IIFE隔离：所有JS代码包裹在(function() { ... })()中，避免全局污染
  7. 元素显示控制：用display属性或opacity控制元素显隐，配合transition实现平滑过渡
