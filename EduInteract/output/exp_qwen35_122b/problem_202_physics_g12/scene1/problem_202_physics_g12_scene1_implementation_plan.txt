[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形为主，无需复杂计算，原生 SVG 清晰且性能好
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    图示区 800×500                       │
  │                                                         │
  │     y                                                  │
  │     ↑                                                  │
  │  E  │  ××××××  B                                       │
  │  ↓  │  ××××××                                          │
  │  ←──┼──→  (电场区域)      (磁场区域)                    │
  │  ↓  │  ××××××                                          │
  │  A  ●─────────→v₀        ××××××                        │
  │  │  ╲            ╲       ××××××                        │
  │  │   ╲  轨迹      ╲      ××××××                        │
  │  L    ╲            ●A'   ××××××                        │
  │  │     ╲           /                                    │
  │  C●─────╲─────────/──────────────────────────→ x        │
  │  │       ╲      ●(OC中点)                               │
  │  │        ╲                                            │
  │  ←─2L─→   ╲                                            │
  │  x=-2L     ╲                                           │
  │             ╲              O                            │
  │              ╲                                         │
  │               ╲                                        │
  │  ─────────────────────────────────────────────────     │
  │  │  ◀上一步  │  步骤 0/5  │  下一步 ▶  │  (控件栏)    │
  │  └─────────────────────────────────────────────────┘  │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：currentStep 变量记录当前步骤（0-5），updateScene() 函数根据 currentStep 显示/隐藏元素
  2. 坐标计算：定义映射函数 mapCoord(x, y) 将物理坐标转换为画布坐标
     - 物理 x → 画布 x = 600 + x * 200/L（L=200px）
     - 物理 y → 画布 y = 250 - y * 200/L
  3. 抛物线绘制：使用 SVG path，根据物理公式 y = L - (qE/2mv₀²)x² 计算控制点
  4. 圆弧绘制：磁场中圆周运动，半径 R = mv₀/qB，用 SVG path 的 A 命令
  5. 事件绑定：按钮点击事件更新 currentStep，调用 updateScene()
  6. ID 命名规范：所有元素 ID 以"scene1-"为前缀（如 scene1-axis-x, scene1-traj-electric）
  7. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  8. 元素分组：使用 SVG <g> 元素按步骤分组，便于批量显示/隐藏
