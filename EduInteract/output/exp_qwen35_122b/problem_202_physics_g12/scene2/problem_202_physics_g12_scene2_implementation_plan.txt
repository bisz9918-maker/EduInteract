[分步序列]

步骤0（初始状态）：
- 显示：坐标系（x轴、y轴、原点O）、电场区域边界、电场箭头（12条）、磁场区域及符号
- 显示：A点(-2L,L)及初速度v₀箭头
- 显示：x=-2L边界线及标签
- 隐藏：粒子轨迹、P点、A'点、速度分解矢量、公式区域
- 目的：展示题目初始条件，粒子从A点以v₀水平射入电场

步骤1：
- 新增：粒子完整轨迹（红色抛物线，从A到A'）
- 新增：P点(-L,0)及标签（轨迹与x轴交点）
- 新增：A'点(0,y_A')及标签（y轴上的进入点）
- 新增：A'点处的水平速度箭头（表明沿x轴正方向进入磁场）
- 目的：展示粒子在电场中的完整运动轨迹

步骤2：
- 新增：A点速度分解矢量
  - v_x分量：从A点(100,100)向右的绿色箭头，长度50px，标签"v_x=v₀"
  - v_y分量：从A点(100,100)向下的红色箭头，长度0（初始为0），标签"v_y=0"
- 新增：P点速度分解矢量
  - v_x分量：从P点(250,250)向右的绿色箭头，长度50px，标签"v_x=v₀"
  - v_y分量：从P点(250,250)向下的红色箭头，长度40px，标签"v_y"
- 新增：A'点速度分解矢量
  - v_x分量：从A'点(500,400)向右的绿色箭头，长度50px，标签"v_x=v₀"
  - v_y分量：从A'点(500,400)向下的红色箭头，长度0（回到0），标签"v_y=0"
- 目的：展示速度矢量的分解，v_x恒定，v_y先增后减

步骤3：
- 高亮：水平方向运动（v_x箭头加粗，轨迹的水平投影线段）
- 新增：水平位移标注
  - A到P的水平位移：从x=-2L到x=-L，标注"L"，下方(175,280)
  - P到A'的水平位移：从x=-L到x=0，标注"L"，下方(375,280)
  - 时间标注：每段耗时t=L/v₀，在对应位移下方
- 目的：强调水平方向匀速直线运动

步骤4：
- 高亮：竖直方向运动（v_y箭头加粗，轨迹的竖直投影线段）
- 新增：竖直位移标注
  - A到P的竖直位移：从y=L到y=0，标注"-L"，左侧(80,175)
  - P到A'的竖直位移：从y=0到y=-L，标注"-L"，左侧(80,325)
  - 加速度标注：第Ⅱ象限"a=qE/m"向下，第Ⅲ象限"a=-qE/m"向上
- 目的：强调竖直方向先加速后减速的对称运动

步骤5：
- 新增：公式推导区域（淡灰色背景矩形）
- 显示公式：
  - 水平方向：x = v₀t
  - 竖直方向（第Ⅱ象限）：y = L - (1/2)at²，v_y = -at
  - 在P点：t₁ = L/v₀，竖直位移L = (1/2)at₁²
  - 解得：a = 2L/t₁² = 2Lv₀²/L² = 2v₀²/L
  - 由a = qE/m得：E = ma/q = 2mv₀²/(qL)
- 目的：完成电场强度E的求解推导

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：位于SVG底部(280,460)，宽100px，高30px，灰色背景
  - "下一步 ▶"按钮：位于SVG底部(420,460)，宽100px，高30px，蓝色背景
  - 步骤指示器：位于SVG底部(350,430)，显示"步骤 0/5"
- 教师操作流程：
  1. 初始展示电场环境和粒子入射条件
  2. 点击"下一步"展示完整轨迹，引导学生观察轨迹形状
  3. 点击"下一步"展示速度分解，强调v_x恒定、v_y变化
  4. 点击"下一步"聚焦水平方向匀速运动
  5. 点击"下一步"聚焦竖直方向对称加速-减速运动
  6. 点击"下一步"展示公式推导，得出E的表达式
  7. 可随时点击"上一步"回退复习关键概念

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 理由：几何图形为主，无需复杂动画库；SVG便于精确控制坐标和样式；原生JS足够实现分步状态切换

- 画布尺寸：800 × 500 px（固定）

- 关键实现要点：
  1. 状态机设计：用变量currentStep(0-5)跟踪当前步骤，每一步对应一个显示配置对象
  2. 坐标计算：定义物理坐标到画布坐标的映射函数mapX(x)、mapY(y)
  3. 元素分组：每个步骤的元素用data-step属性标记，通过CSS类控制显示/隐藏
  4. 动画曲线：粒子轨迹用SVG贝塞尔曲线<path d="M100,100 Q175,200 250,250 T500,400">实现
  5. 事件绑定：按钮点击事件更新currentStep，重新渲染对应步骤的元素
  6. ID命名规范：所有元素ID以"scene2-"为前缀（如scene2-ax、scene2-traj、scene2-btn-next）
  7. IIFE隔离：所有JS代码包裹在(function() { ... })()中，避免全局污染

- 元素ID命名示例：
  - 坐标轴：scene2-xaxis、scene2-yaxis
  - 关键点：scene2-point-A、scene2-point-P、scene2-point-Ap
  - 轨迹：scene2-trajectory
  - 速度矢量：scene2-v0-init、scene2-vx-A、scene2-vy-A等
  - 标签：scene2-label-A、scene2-label-P、scene2-label-Ap等
  - 公式区域：scene2-formula-box
  - 控件：scene2-btn-prev、scene2-btn-next、scene2-step-indicator
