[图示主题与整合说明]
- 本图示主题：磁场中圆周运动轨迹与返回位置
- 整合的内容：磁场区域（第Ⅰ、Ⅳ象限）、粒子进入磁场的状态（A'点入射）、圆周运动轨迹（半圆）、圆心位置、粒子离开磁场后的运动、返回x=-2L的位置
- 教学价值：教师可逐步展示带电粒子在磁场中做圆周运动的完整过程，帮助学生理解：
  1. 如何根据入射条件确定圆心和半径
  2. 磁场中轨迹的几何特征（半圆）
  3. 粒子离开磁场后在电场中的对称运动
  4. 最终返回位置的几何推导

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形（线段、圆弧、箭头）用SVG绘制最清晰，动画用requestAnimationFrame实现平滑效果，无需额外库

- 画布尺寸：800 × 500 px（SVG viewBox="0 0 800 500"）

- 布局草图（ASCII）：
```
┌─────────────────────────────────────────────────────────┐
│                    图示区 800×500                        │
│                                                          │
│   y                                                      │
│   ↑         磁场区域(××××)                               │
│   │        ××××××××                                      │
│   │       ××××××××××                                     │
│   │      ×  B• ←v₀                                       │
│   │     •  ╲                                             │
│   │    O'•   ╲ 半圆轨迹                                   │
│   │     •  ╱                                             │
│   │      •• A' →v₀                                       │
│   │     ╱                                                │
│   │    ╱ 返回轨迹(虚线)                                   │
│   │   • 终点                                             │
│   │  /                                                   │
│   └──┼──┼──┼──┼──┼──┼──┼──→ x                           │

│   (200,450)      (380,450)    (550,450)                  │
└─────────────────────────────────────────────────────────┘
```

- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-5) 跟踪当前步骤，每一步对应一个状态对象，包含该步骤应显示的元素列表
  2. 坐标计算：定义函数 coord(x, y) 将物理坐标转换为画布坐标：
     - canvasX = 500 + x * 100
     - canvasY = 250 - y * 100
  3. 圆弧绘制：使用 SVG <path> 的 A 命令绘制半圆，起点A'(500,350)，终点B(500,415)，圆心(500,382.5)，半径32.5
  4. 动画曲线：使用 requestAnimationFrame 实现轨迹的逐段绘制，每个动画帧增加 path 的 stroke-dashoffset
  5. 事件绑定：按钮点击事件更新 currentStep，调用 renderStep() 重新渲染
  6. ID 命名规范：所有元素 ID 以 scene3- 为前缀，如 scene3-axis-x、scene3-point-A、scene3-arc-half
  7. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染

- 元素显示控制：
  - 每个元素定义 showInSteps 数组，如 [0,1,2,3,4,5] 表示所有步骤都显示
  - 如 [1,2,3,4,5] 表示从步骤1开始显示
  - renderStep() 函数根据 currentStep 控制每个元素的 display 属性

- 动画实现：
  - 半圆轨迹动画：设置 path 的 stroke-dasharray 为轨迹长度，stroke-dashoffset 从轨迹长度渐变到0
  - 返回轨迹动画：同上，使用不同的 path 元素
  - 高亮效果：使用 CSS transition 实现颜色渐变
