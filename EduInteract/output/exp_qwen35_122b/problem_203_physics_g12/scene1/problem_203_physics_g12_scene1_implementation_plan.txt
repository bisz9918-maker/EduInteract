[图示主题与整合说明]
- 本图示主题：带电粒子在平行板电场中的偏转运动全过程
- 整合内容：平行板电场区域、粒子入射路径、电场中抛物线轨迹、无电场区匀速直线轨迹、关键界面位置、两个偏移距离 y₁和 Y

[分步序列]
步骤 0（初始状态）：
- 显示：平行板 A、B，中心线 RD，界面 MN、PS

步骤 1（点击"下一步"）：
- 新增：电场方向箭头（红色，从 A 指向 B），标签"E"

步骤 4（点击"下一步"）：

  - "◀ 上一步"按钮：位置 (280,460)，作用：返回上一状态
  - "下一步 ▶"按钮：位置 (500,460)，作用：进入下一状态
  - 步骤指示器：位置 (380,455)，显示"步骤 0/5"
- 教师操作流程：
  1. 初始展示题目基本结构（平行板、界面、尺寸）

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    图示区 800×500                       │
  │                                                         │
  │   A板 ──────────────────┐                               │
  │        ╲                │ MN                            │
  │         ╲  抛物线       │   │      PS                   │
  │          ╲              │   │       │                   │
  │   R──→v₀ ╲              │   │       │      P●           │
  │           ╲             │   │       │       │ Y         │
  │            ╲            │   │       │       ↓           │
  │             ●───────────┼───┼───────┼───────D───────────│
  │              直线       │   │       │                   │
  │                        │   │       │                   │
  │   B板 ──────────────────┘   │       │                   │
  │                            │       │                   │
  │  ─────────────────────────────────────────────────────  │
  │         控件栏（SVG 内底部 y=440~490）                  │
  │      [◀ 上一步]  [步骤 0/5]  [下一步 ▶]                 │
  └─────────────────────────────────────────────────────────┘
  ```

- 关键实现要点：
  1. 状态机设计：用变量 currentStep(0-5) 跟踪当前步骤，每一步定义 showElements 数组
  2. 坐标计算：使用比例尺 scale=20px/cm，物理量转换为像素坐标
  3. 抛物线绘制：用 SVG path 的 quadraticCurveTo 或贝塞尔曲线近似
  4. 动画曲线：元素出现使用 opacity 渐变 (0→1)，持续 300ms
  5. 事件绑定：按钮点击事件调用 updateScene() 函数刷新显示
  6. ID 命名规范：所有元素 ID 以"scene1-"为前缀（如 scene1-plate-A、scene1-trajectory、scene1-btn-next）
  7. JS 隔离：所有代码包在 (function() { ... })() IIFE 中，避免全局污染

- 元素 ID 命名表：
  - 平行板：scene1-plate-A, scene1-plate-B
  - 中心线：scene1-centerline
  - 界面：scene1-mn, scene1-ps
  - 点：scene1-point-R, scene1-point-D, scene1-point-P
  - 轨迹：scene1-trajectory
  - 速度：scene1-vec-v0, scene1-vec-v

  - 尺寸：scene1-dim-L, scene1-dim-d, scene1-dim-12cm
  - 控件：scene1-btn-prev, scene1-btn-next, scene1-step-indicator
