[分步序列]
- 步骤 0（初始状态）：
  - 显示：圆盘、转轴、物体 A 和 B、细线 OB 和 BA、转动箭头
  - 标签：O、A、B、ω
  - 目的：展示系统基本布局，建立空间认知

- 步骤 1：
  - 新增：距离标注线 r_B、r_A（绿色），标签 r_B=10cm、r_A=20cm
  - 保留：步骤 0 所有元素
  - 目的：标注几何参数，明确物体位置关系

- 步骤 2：
  - 新增：向心力箭头（红色）从 A、B 指向圆心 O，标签 F_n
  - 保留：步骤 1 所有元素
  - 目的：展示向心力方向，理解向心力指向圆心

- 步骤 3：
  - 新增：向心力来源标注 f（静摩擦力）、T_OB（OB 绳张力）、T_AB（AB 绳张力）
  - 保留：步骤 2 所有元素
  - 目的：明确向心力的三个来源，为后续受力分析奠定基础

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 按钮"◀ 上一步"：位置 (320,460)，作用：返回上一状态
  - 按钮"下一步 ▶"：位置 (460,460)，作用：进入下一状态
  - 两个按钮水平居中排列，间距 140px
- 教师操作流程：
  1. 初始展示系统布局，讲解圆盘、转轴、物体位置关系
  2. 点击"下一步"，标注距离参数，强调 r_A=20cm、r_B=10cm 的几何意义
  3. 点击"下一步"，显示向心力箭头，引导学生理解向心力指向圆心
  4. 点击"下一步"，标注向心力来源（静摩擦力 f、张力 T_OB、T_AB），为后续计算做准备

[技术实现]
- JS 库选择：原生 SVG（简单几何首选，无需额外依赖，易于控制元素显示/隐藏）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    图示区 800×500                       │
  │                                                         │
  │           ω                                             │
  │          ↶                                              │
  │         ┌───┐                                           │
  │         │   │                                           │
  │    O────┼───┼────B────────────A                          │
  │   (385) │   │  (475)        (615)                       │
  │         │   │                                           │
  │         └───┘                                           │
  │          │                                              │
  │      ──────────────────────────── 圆盘椭圆              │
  │                                                         │
  │      r_B=10cm        r_A=20cm                          │
  │      ↓↓↓↓↓↓↓↓        ↓↓↓↓↓↓↓↓↓↓↓↓                     │
  │                                                         │
  │  [◀ 上一步]              [下一步 ▶]                     │
  │     (320,460)            (460,460)                      │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-3) 跟踪当前步骤
  2. 坐标计算：所有元素坐标按布局坐标表精确实现
  3. 动画曲线：元素显示使用 opacity 渐变 (0→1)，时长 300ms
  4. 事件绑定：按钮点击事件触发状态更新和元素显示/隐藏
  5. 元素分组：使用 SVG <g> 标签按步骤分组，便于批量控制显示
  6. ID 命名规范：所有交互元素 ID 以 scene1- 为前缀（如 scene1-tri-abc）
  7. IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局污染
