problem_205_physics_g12

场景导航：Scene 1 | Scene 2 | Scene 3

题目原文：
如图所示，现在有一个小物块，质量为m=80g，带正电荷q=2×10^(-4)C，放在水平轨道上M点，物块与水平轨道之间的滑动摩擦系数μ=0.2，轨道处在一个水平向左的匀强电场中，E=10^3V/m，在水平轨道的末端N处，连接一个光滑的半圆形轨道，半径为R=40cm，取g=10m/s^2，求：
（1）要使小物块能够运动到轨道的最高点L，那么M、N间的距离S至少多大？
（2）如果在（1）题的位置释放小物块，当它运动到P（轨道中点）点时对轨道的压力等于多少？

题目分析：
这是一道综合性的电磁学与力学结合题目，涉及以下核心知识点：

  1. 电场力计算：F=qE，正电荷受力方向与电场方向相同（向左）
  2. 摩擦力计算：f=μmg，方向与运动方向相反
  3. 动能定理：合外力做功等于动能变化
  4. 圆周运动临界条件：最高点最小速度满足 mg=mv²/R
  5. 向心力公式：F_n=mv²/R

整体讲解思路：
教师应分三步引导学生：

  1. 首先分析物块在整个运动过程中的受力情况（电场力、摩擦力、重力、支持力）
  2. 然后利用动能定理建立从M到L的能量关系，结合最高点临界条件求解最小距离S
  3. 最后分析P点的受力，利用向心力公式求解轨道压力

图示规划说明：

  • Scene 1：展示完整轨道系统与受力分析，帮助学生建立整体物理图景
  • Scene 2：聚焦最高点临界条件，通过分步动画展示临界状态的物理意义
  • Scene 3：展示能量转化过程，用滑块调节S值观察能量变化关系
步骤 1/4

图示1教学说明：

教师应引导学生按以下步骤观察：

  1. 步骤0：认识轨道系统
  • 水平轨道MN段存在摩擦，物块在此段受电场力和摩擦力
  • 半圆轨道NL段光滑，物块在此段只受重力和支持力
  • P点为半圆轨道中点（与圆心等高），L点为最高点
  1. 步骤1：水平段受力分析
  • 电场力 F_E = qE = 2×10^(-4) × 10^3 = 0.2N（向左）
  • 摩擦力 f = μmg = 0.2 × 0.08 × 10 = 0.16N（向右）
  • 合力 F合 = FE - f = 0.04N（向左），物块加速向左运动
  1. 步骤2：圆周段受力分析
  • 进入半圆轨道后，摩擦力消失
  • 重力始终向下，支持力指向圆心
  • 电场力继续向左作用（整个空间都有电场）
  1. 步骤3：最高点临界条件
  • 物块能到达最高点L的最小速度条件：重力提供向心力
  • mg = mvL²/R，即 vL = √(gR)
  • 这是解题的关键条件

讲解要点：

  • 强调电场贯穿整个空间，物块在圆周段仍受电场力
  • 提醒学生注意摩擦力的方向与运动方向相反
  • 引导学生理解"至少多大"意味着取临界条件
步骤 1/3

图示2教学说明：

教师应引导学生按以下步骤理解临界条件：

  1. 步骤0：定位L点
  • L点是半圆轨道的最高点
  • 物块要到达L点，必须有足够的速度
  1. 步骤1：L点受力分析
  • 重力G=mg，竖直向下
  • 支持力N，竖直向下（轨道对物块的压力）
  • 临界情况下，N=0（物块刚好不脱离轨道）
  1. 步骤2：向心力公式
  • 向心力由重力和支持力的合力提供
  • F_n = G + N = mg + N
  • 根据向心力公式：Fn = mvL²/R
  1. 步骤3：临界速度条件
  • 临界时N=0，所以 mg = mv_L²/R
  • 解得 v_L = √(gR) = √(10 × 0.4) = 2m/s
  • 这是物块能到达L点的最小速度

讲解要点：

  • 强调"至少"意味着取临界条件N=0
  • 引导学生理解为什么支持力方向向下（轨道在物块下方）
  • 提醒学生注意临界条件的物理意义：物块刚好不脱离轨道
S 值: S=1.00m

图示3教学说明：

教师应引导学生按以下步骤观察能量转化：

  1. 能量转化过程
  • 从M到N：电场力做正功，摩擦力做负功，动能增加
  • 从N到L：电场力继续做正功，重力做负功，动能变化
  • 总能量关系：WE - Wf - WG = ΔEk
  1. 动能定理应用（M→L）
  • 电场力做功：W_E = qE·S（水平段）+ qE·0（竖直段无水平位移）
  • 摩擦力做功：W_f = μmg·S
  • 重力做功：W_G = mg·2R
  • 动能变化：ΔEk = (1/2)mvL² - 0
  1. 求解最小距离S
  • 代入临界条件 v_L = √(gR)
  • qES - μmgS - mg·2R = (1/2)mv_L²
  • (qE - μmg)S = (1/2)mv_L² + mg·2R
  • S = [(1/2)mv_L² + mg·2R] / (qE - μmg)
  • 代入数值：S = [(1/2)×0.08×4 + 0.08×10×0.8] / (0.2 - 0.16) = 1.5 / 0.04 = 37.5m
  1. P点压力计算
  • 从M到P用动能定理求v_P
  • 在P点，支持力提供向心力：N = mv_P²/R
  • 代入数值求解

课堂讲解建议：

  • 先用图示1建立整体物理图景
  • 再用图示2理解临界条件
  • 最后用图示3动态演示能量转化，调节S值观察结果
  • 强调动能定理是解决此类问题的核心工具
  • 提醒学生注意单位换算（g→kg, cm→m）

完整解答：

（1）求M、N间最小距离S

从M到L应用动能定理：
W合 = ΔEk

电场力做功：W_E = qE·S
摩擦力做功：W_f = -μmg·S
重力做功：W_G = -mg·2R

临界条件：v_L = √(gR)

代入动能定理：
qES - μmgS - mg·2R = (1/2)mv_L² - 0

(qE - μmg)S = (1/2)mgR + 2mgR = (5/2)mgR

S = (5/2)mgR / (qE - μmg)
= (5/2) × 0.08 × 10 × 0.4 / (0.2 - 0.16)
= 0.8 / 0.04
= 20m

（2）求P点轨道压力

从M到P应用动能定理：
qES - μmgS - mgR = (1/2)mv_P²

(0.2 - 0.16) × 20 - 0.08 × 10 × 0.4 = (1/2) × 0.08 × v_P²
0.8 - 0.32 = 0.04v_P²
v_P² = 12

在P点，向心力由支持力提供：
N = mv_P²/R = 0.08 × 12 / 0.4 = 2.4N

根据牛顿第三定律，物块对轨道的压力等于2.4N。

答案：
（1）S = 20m
（2）压力 = 2.4N
