  - "上一步"按钮：scene1-prev-btn，位于(260,455)-(350,485)，点击返回上一状态

- 教师操作流程：
  1. 初始展示轨道系统和已知条件，让学生理解题目设置
  2. 点击"下一步"展示水平段受力，讲解电场力和摩擦力的方向与大小

  4. 点击"下一步"展示最高点临界条件，讲解临界速度的物理意义
  5. 可随时点击"上一步"回退复习，巩固各阶段知识点

- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量（0-3）跟踪当前步骤，updateScene() 函数根据 currentStep 显示/隐藏对应元素
  2. 坐标计算：所有元素使用绝对像素坐标，SVG 坐标系统原点在左上角
  3. 动画曲线：物块移动使用 SVG SMIL 动画或 requestAnimationFrame 实现平滑过渡
  4. 事件绑定：按钮点击事件绑定到 scene1-prev-btn 和 scene1-next-btn，边界检查防止越界
  5. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-track-horiz, scene1-track-semi, scene1-block, scene1-force-fe, scene1-force-f, scene1-force-g, scene1-force-n, scene1-velocity-v, scene1-btn-prev, scene1-btn-next, scene1-step-indicator）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染
  7. MathJax 用于渲染数学公式（如 q=2×10^(-4)C, E=10^3V/m）

- 初始状态：图示加载后显示轨道系统、电场线、关键点标注和所有已知参数，等待教师点击"下一步"触发交互
