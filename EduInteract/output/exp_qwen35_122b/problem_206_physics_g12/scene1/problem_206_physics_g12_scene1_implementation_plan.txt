[分步序列]
- 步骤 0（初始状态）：
  - 显示：电场线 2 条、运动轨迹线、小球 A(150,250)、小球 B(450,250)
  - 标签：A、B、m(两球)、+q(A)、不带电(B)、L 标注
  - 状态：两球静止，无速度矢量

- 步骤 1（第一次碰撞前）：
  - 新增：A 球速度矢量 v₁（蓝色箭头从 A 球心向右）、位移 S₁ 标注（绿色，从 A 初始位置到 B 位置）
  - 视觉变化：A 球高亮，速度矢量显示
  - 说明：A 在电场力作用下匀加速运动，位移 L，即将碰撞 B

- 步骤 2（第一次碰撞后）：
  - 变化：A 球速度矢量消失（A 静止在碰撞点 450,250），B 球出现速度矢量 v₁（红色箭头从碰撞点向右）
  - 视觉变化：A 球变灰表示静止，B 球高亮并显示速度
  - 说明：弹性碰撞，质量相等，速度交换：A 静止，B 以 v₁匀速向右

- 步骤 3（第二次碰撞前）：
  - 新增：A 球再次从 (450,250) 开始加速，显示新的速度矢量（蓝色，长度递增）、A 的加速位移线（虚线）
  - B 球继续以 v₁匀速向右
  - 说明：A 再次匀加速追赶 B，在 (650,250) 处发生第二次碰撞

- 步骤 4（第二次碰撞后）：
  - 变化：在 (650,250) 处碰撞，速度再次交换
  - A 球以 v₂匀速向右（v₂ > v₁），B 球静止在碰撞点
  - 说明：第二次碰撞后，A 获得更大速度，B 静止

- 步骤 5（规律总结）：
  - 新增：规律总结框显示在第 n 次碰撞时的位移公式
  - 显示公式：Sₙ = n²L（第 n 次碰撞时 A 的总位移）
  - 说明：通过递推可得，第 n 次碰撞时 A 的位移为 n²L

[交互方案]

- 控件说明：
  - 按钮"◀ 上一步"：scene1-prev-btn，位于 (250,455)-(380,485)，点击返回上一步状态
  - 按钮"下一步 ▶"：scene1-next-btn，位于 (420,455)-(550,485)，点击进入下一步状态
- 教师操作流程：
  1. 初始展示两球静止状态，讲解题目条件
  2. 点击"下一步"展示 A 球加速过程，讲解电场力做功
  3. 点击"下一步"展示第一次碰撞后速度交换，讲解弹性碰撞规律
  4. 点击"下一步"展示 A 再次加速追赶 B，讲解运动学递推
  5. 点击"下一步"展示第二次碰撞，强化速度交换概念
  6. 点击"下一步"展示第 n 次碰撞的位移公式总结
  7. 可随时点击"上一步"回退复习关键步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（圆形、线段、箭头、文本），无需复杂图表库，原生实现轻量高效
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │  800px                                                  │
  │  ┌───────────────────────────────────────────────────┐  │
  │  │  E→                                              │  │
  │  │  ────────────────────────────────────────→      │  │ 50px
  │  │                                                  │  │
  │  │                                                  │  │
  │  │  +q  m              m  不带电                   │  │
  │  │   ●─────────────────●                          │  │ 200px
  │  │  A                  B                          │  │
  │  │   │←────── L ──────→│                          │  │
  │  │                                                  │  │
  │  │                                                  │  │
  │  │                                                  │  │
  │  │                                                  │  │ 200px
  │  │  ────────────────────────────────────────→      │  │
  │  │                                              E→ │  │
  │  │                                                  │  │
  │  │        [◀ 上一步]    [下一步 ▶]                 │  │ 50px
  │  └───────────────────────────────────────────────────┘  │
  │  800px                                                  │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-5) 跟踪当前步骤，每个步骤对应一个状态对象，包含该步骤应显示/隐藏/高亮的元素 ID 列表
  2. 坐标计算：所有元素使用绝对坐标，通过 SVG transform 或 CSS position 定位
  3. 动画曲线：使用 CSS transition 实现平滑过渡（opacity、transform），过渡时间 0.3s ease-in-out
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 renderStep() 重绘
  5. ID 命名规范：所有元素 ID 以 scene1- 为前缀，如 scene1-ball-a、scene1-ball-b、scene1-field-line-1、scene1-prev-btn、scene1-next-btn
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染
  7. 箭头绘制：使用 SVG polyline 或 path 绘制带箭头的线段，箭头用 polygon 实现
  8. 虚线样式：SVG stroke-dasharray 实现虚线效果
  9. 透明度控制：SVG fill-opacity 属性
