[分步序列]
- 步骤 0（初始状态）：
  - 显示：斜面三角形、滑块 A、角度弧线、α=37°标签、斜面长度标注线及 9m 标签
  - 隐藏：所有力矢量、计算结果框内容
  - 目的：展示题目基础几何条件

- 步骤 1：
  - 新增：重力 mg 矢量（实线箭头）、mg 标签
  - 高亮：滑块 A 边框加粗
  - 计算结果框显示："已知：α=37°，L=9m，μ₁=0.5，g=10m/s²"
  - 目的：引入重力概念

- 步骤 2：
  - 新增：重力分量 mgsinα（虚线箭头）、mgcosα（虚线箭头）及对应标签
  - 计算结果框追加："重力分解：mgsinα = 0.6mg，mgcosα = 0.8mg"
  - 目的：展示力的分解

- 步骤 3：
  - 新增：支持力 N₁、摩擦力 f₁ 及对应标签
  - 计算结果框追加："支持力 N₁ = mgcosα = 0.8mg，摩擦力 f₁ = μ₁N₁ = 0.4mg"
  - 目的：完整受力分析

- 步骤 4：
  - 新增：速度 v₁ 矢量（在滑块下方独立位置显示运动方向）
  - 计算结果框显示最终结果："加速度 a = g(sinα - μ₁cosα) = 2m/s²，底端速度 v₁ = √(2aL) = 6m/s"
  - 目的：展示运动学计算结果

[标签冲突检查]
- 标签"mg"：坐标 (135,215)
- 标签"mgsinα"：坐标 (175,165)
- 标签"mgcosα"：坐标 (165,160)
- 标签"N₁"：坐标 (165,105)
- 标签"f₁"：坐标 (100,115)

- 标签"α=37°"：坐标 (450,395)
- 标签"9m"：坐标 (300,235)

冲突检查：
- "mg"(135,215) 与 "mgsinα"(175,165)：间距 √(40²+50²)≈64px → 无冲突
- "mgsinα"(175,165) 与 "mgcosα"(165,160)：间距 √(10²+5²)≈11px → 有冲突！解决方案：将 mgcosα标签移至 (170,145)，间距变为 √(5²+20²)≈21px，无冲突
- "mgcosα"(170,145) 与 "N₁"(165,105)：间距 √(5²+40²)≈40px → 无冲突
- "N₁"(165,105) 与 "f₁"(100,115)：间距 √(65²+10²)≈66px → 无冲突
- "mg"(135,215) 与 "v₁"(215,215)：间距 80px → 无冲突
- "α=37°"(450,395) 与其他标签均 >200px → 无冲突
- "9m"(300,235) 与其他标签均 >100px → 无冲突

修正后标签坐标：
- mgcosα标签：(170,145)

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │ 800×500 SVG 画布                                               │
  │                                                                │
  │  ┌─────────────────────────────────────┐                      │
  │  │                                     │                      │
  │  │     斜面三角形                      │   计算结果框         │
  │  │     /│                             │   (550,100)          │
  │  │    / │  滑块 A + 力矢量             │   ┌──────────────┐   │
  │  │   /  │                             │   │ 步骤 0: 几何   │   │
  │  │  /   │                             │   │ 步骤 1: 重力   │   │
  │  │ / α  │                             │   │ 步骤 2: 分解   │   │
  │  │/____│                             │   │ 步骤 3: 受力   │   │
  │  │                                     │   │ 步骤 4: 结果   │   │
  │  └─────────────────────────────────────┘   └──────────────┘   │
  │                                                                │
  │  ┌──────────────────────────────────────────────────────────┐ │
  │  │      [上一步]  步骤 1/5  [下一步]                         │ │
  │  └──────────────────────────────────────────────────────────┘ │
  └────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-4) 跟踪当前步骤
  2. 元素分组：每个步骤新增的元素用 group (<g>) 包裹，通过 display 属性控制显示/隐藏
  3. 坐标计算：斜面斜边方向向量 (400,300)，单位向量 (0.8,0.6)，用于力矢量方向
  4. 箭头绘制：用 marker-end 定义箭头样式，复用所有矢量
  5. 事件绑定：按钮点击事件更新 currentStep，遍历所有元素组根据步骤显示/隐藏
  6. 文本内容：计算结果框内用 <text> 元素，根据步骤动态更新显示内容
- ID 命名规范：所有元素 ID 以 scene1- 为前缀，如 scene1-slope、scene1-block、scene1-gravity、scene1-prev-btn、scene1-next-btn
- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
