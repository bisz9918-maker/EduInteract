[图示主题与整合说明]
- 本图示主题：滑块A滑上木板B后的相互作用与运动状态分析
- 整合的内容：A在B上滑动时的受力分析、B的受力分析（含地面摩擦力）、B是否静止的判断、μ₂的求解
- 教学价值：教师可逐步引导学生分析A对B的摩擦力→地面对B的最大静摩擦力→比较判断→求解μ₂，帮助学生理解多物体系统的受力分析与运动状态判断

[分步序列]
- 步骤0（初始状态）：
  - 显示：地面、木板B、滑块A（位于B左端上方）、L=3m标签、μ₁标签、μ₂标签
  - 隐藏：所有力矢量箭头、右侧文本框内容
  - 文本框显示标题："滑块A滑上木板B后的受力分析"

- 步骤1（显示A对B的摩擦力）：
  - 新增：f_AB箭头（红色，水平向右）、f_AB标签
  - 文本框显示：
    "步骤1：A对B的摩擦力分析
    A相对B向右滑动
    B受到A的摩擦力f_AB方向向右
    f_AB = μ₁·mg = 0.5mg"

- 步骤2（显示B受地面的力）：
  - 新增：f₂箭头（绿色，水平向左）、N₂箭头（竖直向上）、mg_B箭头（竖直向下）、压力箭头（虚线，竖直向下）、mg_A箭头（竖直向下）、f₂标签、N₂标签、mg_B标签、mg_A标签
  - 文本框显示：
    "步骤2：B的受力分析
    竖直方向：N₂ = mg(来自A) + mg(自身) = 2mg
    水平方向：f₂为地面对B的摩擦力
    最大静摩擦力 f_max = μ₂·N₂ = μ₂·2mg"

- 步骤3（比较判断）：
  - 高亮：f_AB箭头和f₂箭头同时加粗闪烁
  - 文本框显示：
    "步骤3：判断B是否滑动
    比较：f_AB = 0.5mg  vs  f_max = μ₂·2mg
    若 f_AB > f_max，则B滑动
    若 f_AB ≤ f_max，则B静止"

- 步骤4（求解μ₂）：
  - 文本框显示最终结论：
    "步骤4：求解μ₂
    由题意，B滑动（因A刚好未从B滑下）
    f_AB > f_max
    0.5mg > μ₂·2mg
    μ₂ < 0.25
    故 μ₂ = 0.25（临界值）"

[技术实现]
- JS库选择：原生SVG + 原生JavaScript（简单几何图形和动画，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │                        图示区 800×500                          │
  │                                                                │
  │    μ₁                                                          │

  │    │  A │                                                      │

  │      │                                                         │
  │      ▼ mg_A        f_AB → → → → → → → → → →                   │
  │    ┌────────────────────────────────────────┐                 │
  │    │              木板 B                     │                 │
  │    └────────────────────────────────────────┘                 │
  │      │           │           │           │                    │
  │      ▼ mg_B      ▼ N₂        ▼ f₂ ← ← ← ←                     │
  ```

- 关键实现要点：
  1. 状态机设计：使用currentStep变量（0-4）跟踪当前步骤，steps数组存储每步应显示/隐藏的element ID列表
  2. 坐标计算：所有元素使用绝对坐标，力矢量箭头使用SVG polyline或path绘制，箭头末端添加marker
  3. 动画曲线：步骤切换时使用opacity渐变（0→1或1→0），持续时间300ms
  4. 事件绑定：按钮点击事件调用updateStep()函数，根据currentStep显示对应元素
  5. 高亮效果：步骤3中f_AB和f₂箭头使用stroke-width从2变为4，配合CSS transition

- ID命名规范：所有交互元素ID以"scene2-"为前缀
  - 木板B：scene2-wood-B
  - 滑块A：scene2-block-A
  - f_AB箭头：scene2-fAB-arrow
  - f₂箭头：scene2-f2-arrow
  - N₂箭头：scene2-N2-arrow
  - mg_B箭头：scene2-mgB-arrow
  - mg_A箭头：scene2-mgA-arrow
  - 压力箭头：scene2-pressure-arrow
  - 文本框：scene2-info-box
  - 上一步按钮：scene2-btn-prev
  - 下一步按钮：scene2-btn-next
  - 步骤指示器：scene2-step-indicator

- IIFE隔离：所有JS代码包裹在(function() { ... })()中，避免全局变量污染
