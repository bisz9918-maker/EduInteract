problem_208_physics_g12

场景导航：Scene 1 | Scene 2 | Scene 3

题目原文：

如图所示，两平行金属板水平放置，板间存在垂直纸面的匀强磁场和电场强度为E的匀强电场。金属板右下方以MN为上边界，PQ为下边界，MP为左边界的区域内，存在垂直纸面向外的匀强磁场，磁场宽度为d，MN与下极板等高，MP与金属板右端在同一竖直线。一个电荷量为q、质量为m的正离子以初速度在两板间沿平行于金属板的虚线射入金属板间。不计粒子重力。

(1)已知离子恰好做匀速直线运动，求金属板间的磁感应强度B₀；

(2)若撤去板间磁场B₀，离子恰好从下极板的右侧边缘射出电场，方向与水平方向成30°角，离子进入磁场运动后从磁场边界点射出，求该磁场的磁感应强度B的大小。

题目分析：

本题涉及带电粒子在复合场（电场+磁场）和单一磁场中的运动，是高中物理电磁学综合题的典型代表。

核心知识点：

  1. 速度选择器原理：当电场力与洛伦兹力平衡时，带电粒子做匀速直线运动
  2. 带电粒子在匀强电场中的类平抛运动
  3. 带电粒子在匀强磁场中的匀速圆周运动
  4. 几何关系在物理问题中的应用

整体讲解思路：

本题分为两个独立的情境：

  • 情境一（第1问）：复合场中匀速直线运动，考查受力平衡条件
  • 情境二（第2问）：先电场偏转后磁场偏转，考查运动分解和几何关系

图示规划说明：

规划3个图示场景：

  • Scene 1：速度选择器原理——展示板间电场、磁场及离子受力平衡
  • Scene 2：电场中的偏转——展示撤去磁场后离子在电场中的偏转轨迹及射出状态
  • Scene 3：磁场中的圆周运动——展示离子进入下方磁场后的圆周运动轨迹及几何关系

Scene 1 教学说明：

教学目标： 帮助学生理解速度选择器的工作原理，掌握电场力与洛伦兹力平衡的条件。

讲解要点：

  1. 电场方向判断：上板带正电，下板带负电，电场方向从上向下。正离子受到的电场力方向与电场方向相同，即向下。
  1. 磁场方向设定：要使离子做匀速直线运动，洛伦兹力必须向上与电场力平衡。根据左手定则（正电荷），速度向右，洛伦兹力向上，则磁场方向垂直纸面向里（用"×"表示）。
  1. 平衡条件推导：
  • 电场力：F_E = qE（方向向下）
  • 洛伦兹力：F_B = qvB₀（方向向上）
  • 平衡条件：FE = FB
  • 即：qE = qvB₀
  • 解得：B₀ = E/v
  1. 物理意义：只有速度满足v = E/B₀的粒子才能沿直线通过速度选择器，这就是"速度选择"的含义。

引导学生观察：

  • 步骤1-2：让学生判断电场力和洛伦兹力的方向
  • 步骤3：观察两个力大小相等、方向相反
  • 步骤4：理解平衡条件的数学表达

易错点提醒：

  • 磁场方向判断容易出错，需强调左手定则的应用
  • 平衡条件是大小相等、方向相反，缺一不可
步骤 1/5

Scene 2 教学说明：

教学目标： 帮助学生理解带电粒子在匀强电场中的类平抛运动，掌握速度分解和偏转角的计算。

讲解要点：

  1. 运动分解：撤去磁场后，离子仅受电场力作用
  • 水平方向：不受力，匀速直线运动，v_x = v（恒定）
  • 竖直方向：受恒定电场力，匀加速直线运动，v_y = at
  1. 偏转角计算：
  • 射出时速度方向与水平方向成θ = 30°
  • tanθ = vy / vx = v_y / v
  • 即：v_y = v·tan30° = v/√3
  1. 运动学关系（为后续计算做准备）：
  • 设板长为L，板间距离为h
  • 水平方向：L = v·t
  • 竖直方向：h/2 = (1/2)·a·t² = (1/2)·(qE/m)·t²
  • 竖直速度：v_y = a·t = (qE/m)·t
  1. 关键结论：射出电场时，离子的速度大小为 v' = v/cos30°，方向与水平成30°角向下。

引导学生观察：

  • 步骤1：观察轨迹向下弯曲，说明有向下的加速度
  • 步骤2：理解速度分解，水平分量不变，竖直分量增加
  • 步骤3：关注射出点的速度方向，这是进入磁场的初速度
  • 步骤4：建立偏转角与速度分量的关系

承上启下：
离子以30°角进入下方磁场区域，这是Scene 3的初始条件。

步骤 0/5

Scene 3 教学说明：

教学目标： 帮助学生掌握带电粒子在匀强磁场中做圆周运动的规律，学会利用几何关系求解磁感应强度。

讲解要点：

  1. 入射条件：
  • 离子从M点进入磁场
  • 入射速度大小：v' = v/cos30° = 2v/√3
  • 入射方向：与水平方向成30°角向下
  1. 圆周运动规律：
  • 洛伦兹力提供向心力：qv'B = mv'²/R
  • 轨迹半径：R = mv'/(qB)
  • 运动周期：T = 2πm/(qB)
  1. 几何关系分析（关键）：
  • 离子从M点入射，从PQ边界射出
  • 磁场宽度为d（MN到PQ的垂直距离）
  • 入射速度与水平成30°，则速度与竖直方向成60°
  • 圆心O在入射速度的垂线上
  • 设射出点为S，OS = OM = R
  • 由几何关系：R·sin30° + R·sinθ = d（θ为射出时速度与水平夹角）
  • 若从PQ边界垂直射出，则θ = 0°，得 R = 2d
  1. 磁感应强度计算：
  • R = mv'/(qB)
  • B = mv'/(qR)
  • 代入v' = 2v/√3 和 R = 2d
  • 得：B = mv/(qd√3)

引导学生观察：

  • 步骤1：观察圆周轨迹，理解洛伦兹力始终垂直于速度
  • 步骤2：学习圆心确定方法——速度垂线的交点
  • 步骤3：关注半径R的物理意义和几何位置
  • 步骤4-5：建立几何关系，完成求解

几何关系推导详解：

  • 入射点M，入射速度与水平成30°
  • 圆心O在M点速度的垂线上，即OM与速度垂直
  • OM与竖直方向成30°
  • M点到PQ的垂直距离为d
  • 设离子从PQ上S点射出，OS = R
  • 由几何关系：R·cos30° = d（若从PQ垂直射出）
  • 即：R = d/cos30° = 2d/√3

易错点提醒：

  • 圆心位置判断：圆心在速度垂线上，不是在速度方向上
  • 几何关系建立：注意角度是速度与边界的夹角，不是与法线的夹角
  • 半径公式：R = mv/(qB)，注意v是入射速度v'，不是初速度v

完整解答总结：

第（1）问解答：
离子在复合场中做匀速直线运动，电场力与洛伦兹力平衡：

  • qE = qvB₀
  • 解得：B₀ = E/v

第（2）问解答：
撤去板间磁场后，离子经历两个阶段：

阶段一：电场中的偏转

  • 离子从下极板右边缘射出，速度方向与水平成30°
  • 射出速度大小：v' = v/cos30° = 2v/√3

阶段二：磁场中的圆周运动

  • 洛伦兹力提供向心力：qv'B = mv'²/R
  • 轨迹半径：R = mv'/(qB)
  • 几何关系：离子从M点入射，从PQ边界射出，磁场宽度为d
  • 由几何关系得：R = 2d/√3
  • 代入半径公式：B = mv'/(qR) = m(2v/√3)/(q·2d/√3) = mv/(qd)

最终答案：

  • （1）B₀ = E/v
  • （2）B = mv/(qd)
