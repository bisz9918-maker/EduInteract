[分步序列]

  - 显示：速度矢量 v（绿色箭头，水平向右）
  - 隐藏：电场 E、磁场 B₀、受力箭头、平衡条件框
  - 说明：展示题目基础条件——离子以速度 v 射入平行金属板间

- 步骤 1：

  - 说明：展示板间匀强电场方向——上正下负，电场强度 E 垂直向下

- 步骤 2：
  - 新增：磁场 B₀符号网格（5×3 个"×"，分布在板间区域）
  - 新增：磁场 B₀标签
  - 说明：展示板间匀强磁场方向——垂直纸面向里，磁感应强度 B₀

- 步骤 3：
  - 新增：电场力 F_E 箭头（红色，从离子位置垂直向下）

  - 新增：洛伦兹力标签"F_B = qvB₀"

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 按钮"◀ 上一步"：位于 (250,455)，作用：返回上一状态，可复习之前内容
  - 按钮"下一步 ▶"：位于 (380,455)，作用：进入下一状态，推进讲解
  - 按钮状态：步骤 0 时"上一步"禁用；步骤 4 时"下一步"禁用
- 教师操作流程：
  1. 初始展示金属板和离子轨迹，介绍题目背景
  2. 点击"下一步"→ 展示电场，讲解电场方向
  3. 点击"下一步"→ 展示磁场，讲解磁场方向
  4. 点击"下一步"→ 展示受力分析，讲解两力方向
  5. 点击"下一步"→ 展示平衡条件，推导公式 B₀ = E/v
  6. 可随时点击"上一步"回退复习，巩固关键概念

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（矩形、圆形、箭头、文本），SVG 矢量绘图清晰，原生 JS 足够实现状态切换，无需引入重型库

- 画布尺寸：800 × 500 px

- 布局草图（ASCII）：
```
┌─────────────────────────────────────────────────────────────┐
│ 速度选择器原理                                               │
│                                                              │
│    +                                                         │
│    │                                                         │
│  ┌──────────────────────────────────────────────────────┐   │
│  │                    上金属板 (+)                       │   │
│  └──────────────────────────────────────────────────────┘   │
│           ×  ×  ×  ×  ×                                      │
│           ×  ×  ×  ×  ×         E↓                           │
│  ───────────────────────────────────────  离子轨迹           │
│      (q) → v                    ×  ×  ×  ×  ×                │
│           ×  ×  ×  ×  ×                                      │
│  ┌──────────────────────────────────────────────────────┐   │
│  │                    下金属板 (-)                       │   │
│  └──────────────────────────────────────────────────────┘   │
│    │                                                         │
│    -                                                         │
│                                                              │
│         F_B↑                    ┌─────────────────────┐     │
│         │                       │  平衡条件：          │     │
│    (离子)                       │  F_E = F_B          │     │
│         │                       │  qE = qvB₀         │     │
│         ↓ F_E                   │  B₀ = E/v          │     │
│                                 └─────────────────────┘     │
│                                                              │
│              [◀ 上一步]    [下一步 ▶]                        │
└─────────────────────────────────────────────────────────────┘
```

- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-4) 跟踪当前步骤，每一步定义要显示/隐藏的 SVG 元素 ID 列表
  2. 坐标计算：所有元素使用绝对坐标，通过 SVG 的 x/y/width/height 属性精确控制位置
  3. 动画曲线：受力箭头出现时使用 opacity 渐变（0→1，时长 300ms），平衡条件框使用 scale 缩放动画
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateScene() 刷新显示
  5. ID 命名规范：所有元素 ID 以"scene1-"为前缀（如 scene1-plate-top、scene1-force-E、scene1-btn-next）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染

- SVG 元素 ID 清单：
  - scene1-title：标题文本
  - scene1-plate-top：上金属板矩形
  - scene1-plate-bottom：下金属板矩形
  - scene1-terminal-top：上接线柱线段
  - scene1-terminal-bottom：下接线柱线段
  - scene1-trajectory：离子轨迹虚线
  - scene1-ion：离子圆形
  - scene1-velocity：速度矢量箭头
  - scene1-field-E：电场箭头（步骤 1 显示）
  - scene1-field-B：磁场×符号组（步骤 2 显示）
  - scene1-force-E：电场力箭头（步骤 3 显示）
  - scene1-force-B：洛伦兹力箭头（步骤 3 显示）
  - scene1-balance-box：平衡条件框（步骤 4 显示）
  - scene1-balance-text：平衡条件公式文本
  - scene1-btn-prev：上一步按钮
  - scene1-btn-next：下一步按钮

- 状态更新逻辑：
  ```
  updateScene() {
    根据 currentStep 显示/隐藏对应元素：
    - step 0: 显示 plate-top, plate-bottom, trajectory, ion, velocity
    - step 1: 新增显示 field-E
    - step 2: 新增显示 field-B
    - step 3: 新增显示 force-E, force-B
    - step 4: 新增显示 balance-box, balance-text，高亮 force-E, force-B
    
    更新按钮状态：
    - currentStep === 0 → btn-prev 禁用
    - currentStep === 4 → btn-next 禁用
  }
  ```
