[图示主题与整合说明]
- 本图示主题：离子在磁场中的圆周运动——几何关系与磁感应强度求解
- 整合的内容：
  1. 离子进入磁场时的速度状态（大小、方向与水平成 30°）
  2. 磁场中的圆周运动轨迹（圆弧）
  3. 圆心位置的几何确定方法
  4. 轨迹半径 R 与磁场宽度 d 的几何关系
  5. 从磁场边界射出的条件分析
- 教学价值：教师可通过分步导航逐步展示离子在磁场中的运动轨迹、圆心确定方法、以及利用几何关系求解磁感应强度的完整过程，帮助学生理解带电粒子在匀强磁场中的圆周运动规律

[分步序列]
- 步骤 0（初始状态）：
  显示：磁场区域矩形边界（MN、PQ、MP、NQ 虚线）、磁场符号阵列、M/N/P/Q 四个顶点标签、磁场宽度 d 标注
  隐藏：运动轨迹、圆心、半径、速度矢量、角度标注、射出点 S
  目的：展示题目基础条件——磁场区域的几何结构

- 步骤 1：
  新增：离子入射点 M（高亮）、入射速度矢量 v'（绿色箭头，与水平成 30°）、入射角 30°标注（红色弧线）
  显示：离子从 M 点以 30°角进入磁场
  目的：明确离子进入磁场时的初始状态

- 步骤 2：
  新增：运动轨迹圆弧（蓝色，从 M 点开始绘制）、射出点 S（在 PQ 边界上）
  显示：离子在磁场中的圆周运动轨迹
  目的：展示离子在磁场中的运动路径

- 步骤 3：
  新增：圆心 O（红色圆点）、半径 OM（灰色虚线）、半径 OS（灰色虚线）
  显示：圆心位置和两条半径连线
  目的：展示圆心的几何确定——过入射点和射出点分别作速度垂线，交点为圆心

- 步骤 4：
  新增：射出速度矢量（绿色箭头，垂直于半径 OS）、轨迹扇形区域填充（蓝色 15% 透明度）
  高亮：半径 R 标注、几何关系（R 与 d 的关系）
  目的：突出几何关系——利用磁场宽度 d 和入射角 30°建立 R 与 d 的关系

- 步骤 5（最终步骤）：
  显示：所有元素完整呈现
  新增：磁感应强度公式 B = mv'/(qR) 的标注
  高亮：关键几何关系和最终公式
  目的：展示最终结论——由 qv'B = mv'²/R 推导 B = mv'/(qR)

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  原因：几何图形（矩形、圆弧、线段、箭头）用 SVG 绘制最精确，动画通过控制元素显示/隐藏实现，无需复杂动画库

- 画布尺寸：800 × 500 px

- 关键实现要点：
  1. 状态机设计：使用变量 currentStep 记录当前步骤（0-5），每一步对应一个状态函数
  2. 坐标计算：
     - 圆心 O(200,100) 通过几何关系确定：OM 垂直于入射速度，OS 垂直于射出速度
     - 半径 R = |OM| = √[(350-200)² + (150-100)²] = √(150² + 50²) ≈ 158px
     - 射出点 S 坐标：根据几何关系，S 在 PQ 上，且 OS = R
  3. 动画曲线：轨迹圆弧使用 SVG path 的 arc 命令绘制，通过控制 startAngle 和 endAngle 实现逐步绘制效果
  4. 事件绑定：按钮点击事件绑定到 stepChange 函数，根据 currentStep 增减更新显示
  5. 元素显示控制：每个步骤对应一组元素的 display 属性切换

- ID 命名规范：所有交互元素 ID 以"scene3-"为前缀
  - scene3-magnet-rect（磁场区域矩形）
  - scene3-magnet-dots（磁场符号阵列）

  - scene3-point-n（N 点）
  - scene3-point-p（P 点）

  - scene3-velocity-in（入射速度）
  - scene3-velocity-out（射出速度）
  - scene3-angle-30（入射角标注）
  - scene3-width-d（磁场宽度标注）
  - scene3-btn-prev（上一步按钮）

  - scene3-step-indicator（步骤指示器）

- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
