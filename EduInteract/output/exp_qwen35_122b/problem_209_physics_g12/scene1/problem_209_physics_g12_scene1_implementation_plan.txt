[图示主题与整合说明]
- 本图示主题：v-t 图线分析——从速度时间图提取运动学信息
- 整合的步骤/概念：整合了上滑阶段（0→t₁）和下滑阶段（t₁→3t₁）的完整运动过程分析，包括速度变化、加速度计算、位移关系
- 教学价值：教师可逐步引导学生读图，先识别上滑减速过程，再分析下滑反向加速过程，通过斜率三角形直观理解加速度计算，最后对比两段加速度大小关系，为后续受力分析做铺垫

[分步序列]
- 步骤 0（初始状态）：
  - 显示：完整坐标系（横轴 t、纵轴 v、原点 O）
  - 显示：完整折线图线（上滑段 + 下滑段，均为黑色#000000）
  - 显示：三个关键点 A、B、C（绿色圆点）
  - 显示：所有坐标轴标签（t、v）和关键点坐标标签（v₀、t₁、3t₁、-v₁）
  - 隐藏：斜率三角形、加速度标签（a₁、a₂）
  - 按钮状态：上一步禁用，下一步启用

- 步骤 1（高亮上滑段，计算 a₁）：
  - 视觉变化：上滑段图线变为蓝色#1565c0（加粗至 3px）
  - 新增：上滑斜率三角形（灰色虚线，直角边沿 t 轴和 v 轴方向）
  - 新增：标签"a₁"显示在斜率三角形内(280,200)
  - 显示公式文本："a₁ = Δv/Δt = (0 - v₀)/t₁ = -v₀/t₁"（显示在斜率三角形旁(280,230)）
  - 按钮状态：上一步启用，下一步启用

- 步骤 2（高亮下滑段，计算 a₂）：
  - 视觉变化：下滑段图线变为红色#c62828（加粗至 3px），上滑段恢复黑色或保持蓝色
  - 新增：下滑斜率三角形（灰色虚线，直角边沿 t 轴和 v 轴方向）
  - 新增：标签"a₂"显示在斜率三角形内(520,350)
  - 显示公式文本："a₂ = Δv/Δt = (-v₁ - 0)/(3t₁ - t₁) = -v₁/(2t₁)"（显示在斜率三角形旁(520,380)）
  - 按钮状态：上一步启用，下一步启用

- 步骤 3（总结两个加速度关系）：
  - 视觉变化：上滑段保持蓝色，下滑段保持红色（两段同时高亮）
  - 新增：对比文本框显示在图线下方(400,410)
  - 显示文本："上滑加速度大小 |a₁| = v₀/t₁"
  - 显示文本："下滑加速度大小 |a₂| = v₁/(2t₁)"
  - 显示文本："由于上滑减速、下滑加速，且|a₁| > |a₂|（因摩擦力方向改变）"
  - 按钮状态：上一步启用，下一步禁用

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：位于(250,450)-(340,480)，点击返回上一状态，步骤 0 时禁用
  - "下一步 ▶"按钮：位于(410,450)-(500,480)，点击进入下一状态，步骤 3 时禁用
- 教师操作流程：
  1. 初始展示完整 v-t 图，让学生识别图线形状和关键点
  2. 点击"下一步"，高亮上滑段并显示斜率三角形，讲解上滑减速过程及加速度计算
  3. 再次点击"下一步"，高亮下滑段并显示斜率三角形，讲解下滑加速过程及加速度计算
  4. 最后一步展示两段加速度对比，引导学生思考摩擦力方向变化对加速度的影响
  5. 可随时点击"上一步"回退复习，巩固关键概念

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │                         v                                   │
  │                         ↑                                   │
  │                   v₀ ● A                                    │
  │                    ╱                                        │
  │                   ╱  a₁                                     │
  │                  ╱  △                                       │
  │                 ╱                                           │
  │                ╱                                            │
  │               ● B                                           │
  │              ╱  t₁              a₂                          │
  │             ╱        △                                      │
  │            ╱                                                │
  │           ╱                                                 │
  │  ────────●──────────────────────────────────────→ t         │
  │         O          t₁              3t₁                      │
  │                                    ╲                        │
  │                                     ╲                       │
  │                                      ● C                    │
  │                                      -v₁                    │
  │                                                           3t₁│
  │                                                             │
  │              ┌─────────────────────────────────┐            │
  │              │  ◀ 上一步      下一步 ▶         │            │
  │              └─────────────────────────────────┘            │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-3) 跟踪当前步骤，updateScene() 函数根据 currentStep 显示/隐藏元素
  2. 坐标计算：所有元素坐标硬编码在布局表中，确保精确到像素级
  3. 动画曲线：使用 SVG 的 stroke-dasharray 和 stroke-dashoffset 实现斜率三角形渐显效果（可选）
  4. 事件绑定：按钮点击事件绑定到 updateScene()，根据 currentStep 更新 DOM
  5. 高亮效果：通过修改 SVG 元素的 stroke 和 stroke-width 属性实现
  6. ID 命名规范：所有交互元素 ID 以"scene1-"为前缀（如 scene1-line-up、scene1-triangle-down、scene1-btn-prev、scene1-btn-next）
  7. JS 隔离：所有代码包在 (function() { ... })() IIFE 中，避免全局污染
  8. 公式渲染：使用 MathJax 渲染数学公式（a₁ = Δv/Δt = ...），确保下标和分数格式正确
