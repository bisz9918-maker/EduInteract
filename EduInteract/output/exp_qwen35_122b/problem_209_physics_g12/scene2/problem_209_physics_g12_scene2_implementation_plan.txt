[图示主题与整合说明]
- 本图示主题：斜面受力分析——上滑与下滑阶段的动力学方程建立
- 整合内容：整合了上滑阶段和下滑阶段的完整受力分析，包括重力分解、摩擦力方向判断、牛顿第二定律方程建立、联立求解动摩擦因数
- 教学价值：教师可通过分步展示，帮助学生理解物块在斜面上运动时摩擦力的方向变化（上滑时沿斜面向下，下滑时沿斜面向上），以及由此导致的加速度差异。通过对比两个阶段的受力图和方程，学生能清晰看到摩擦力方向对合力的影响，最终理解如何联立求解动摩擦因数。

[分步序列]
- 步骤 0（初始状态）：
  - 显示：上滑斜面、上滑物块、下滑斜面、下滑物块
  - 显示：上滑标题"上滑阶段"、下滑标题"下滑阶段"
  - 显示：方程框 1（空）、方程框 2（空）、求解框（空）
  - 隐藏：所有力矢量、所有方程文本、所有加速度标注
  - 目的：展示基础场景，物块在斜面上

- 步骤 1（重力分解）：
  - 新增：上滑重力 mg 矢量及标签、上滑 mg sinθ 矢量及标签、上滑 mg cosθ 矢量及标签
  - 新增：下滑重力 mg 矢量及标签、下滑 mg sinθ 矢量及标签、下滑 mg cosθ 矢量及标签
  - 新增：上滑支持力 N 矢量及标签、下滑支持力 N 矢量及标签
  - 方程框 1 显示：N = mg cosθ
  - 方程框 2 显示：N = mg cosθ
  - 目的：展示重力分解和支持力计算

- 步骤 2（上滑阶段）：
  - 新增：上滑摩擦力 f₁矢量及标签（沿斜面向下）
  - 新增：上滑合力 F₁矢量及标签
  - 新增：上滑加速度标注 a₁
  - 方程框 1 更新显示：
    ```
    上滑阶段：
    F₁ = mg sinθ + f₁ = mg sinθ + μmg cosθ
    ma₁ = mg sinθ + μmg cosθ
    a₁ = g(sinθ + μcosθ)
    ```
  - 目的：展示上滑时摩擦力方向及动力学方程

- 步骤 3（下滑阶段）：
  - 新增：下滑摩擦力 f₂矢量及标签（沿斜面向上，与 f₁方向相反）
  - 新增：下滑合力 F₂矢量及标签
  - 新增：下滑加速度标注 a₂
  - 方程框 2 更新显示：
    ```
    下滑阶段：
    F₂ = mg sinθ - f₂ = mg sinθ - μmg cosθ
    ma₂ = mg sinθ - μmg cosθ
    a₂ = g(sinθ - μcosθ)
    ```
  - 目的：展示下滑时摩擦力方向反转及动力学方程

- 步骤 4（联立求解）：
  - 高亮：上滑摩擦力 f₁和下滑摩擦力 f₂（用闪烁或加粗效果对比方向）
  - 求解框显示：
    ```
    由 v-t 图：a₁ = v₀/t₁，a₂ = v₁/(2t₁)
    联立解得：μ = (v₀ - 2v₁) / [(v₀ + 2v₁)tanθ]
    ```
  - 目的：展示如何从已知量求解动摩擦因数

- 关键实现要点：
  1. 状态机设计：用变量 currentStep 记录当前步骤（0-4），每个步骤定义一个 showElements() 函数控制元素显示/隐藏
  2. 坐标计算：所有元素坐标已在布局坐标表中精确定义，SVG 元素用绝对坐标绘制
  3. 动画曲线：力矢量出现时用 opacity 从 0 到 1 的过渡动画（0.3s ease-in-out）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 renderStep() 重新渲染
  5. 元素 ID 命名：所有元素 ID 以"scene2-"为前缀，如 scene2-ramp-up、scene2-block-up、scene2-mg-up 等
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染
