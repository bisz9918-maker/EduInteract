[图示主题与整合说明]
- 本图示主题：电化学装置双模式对比展示（原电池 vs 电解池）
- 整合内容：同一装置在不同开关状态下的工作原理对比
  - 原电池模式（K₁闭合，K₂断开）：Fe 为负极自发氧化，C 为正极发生还原
  - 电解池模式（K₂闭合，K₁断开）：外接电源驱动，电极极性由电源决定
- 教学价值：教师可通过切换按钮直观对比两种电化学装置的本质区别——原电池是化学能→电能（自发），电解池是电能→化学能（强制）

[分步序列/状态切换]
本场景采用多状态切换交互（3 个状态）：

状态 0（初始状态）：
- 显示：烧杯、溶液、C 电极、Fe 电极、两个断开的开关 K₁和 K₂
- 不显示：电子流向箭头、电极极性标签、离子迁移箭头、电源符号
- 按钮：三个模式按钮均可见，无高亮

状态 1（原电池模式）：
- K₁闭合（开关图形变为闭合状态），K₂保持断开
- 高亮显示：电子流向箭头（Fe→C，蓝色）
- 显示标签：Fe 电极上方"负极"（蓝色），C 电极上方"正极"（蓝色）
- 显示离子迁移：Na⁺向 C 电极迁移（向右箭头），Cl⁻向 Fe 电极迁移（向左箭头）
- 电极高亮：Fe 电极边框蓝色加粗，C 电极边框蓝色加粗
- 按钮："原电池模式"按钮高亮蓝色

状态 2（电解池模式）：
- K₂闭合（开关图形变为闭合状态），K₁保持断开
- 显示电源符号：长端为正极（红色），短端为负极（绿色）
- 高亮显示：C 电极为阳极（红色边框），Fe 电极为阴极（绿色边框）
- 显示标签：C 电极上方"阳极"（红色），Fe 电极上方"阴极"（绿色）
- 显示离子迁移：Cl⁻向 C 电极（阳极）迁移，Na⁺和 H⁺向 Fe 电极（阴极）迁移
- 按钮："电解池模式"按钮高亮红色

[交互方案]
- 交互类型：多状态切换（3 个按钮）
- 控件说明：
  1. "原电池模式"按钮：位于 (300,450)，点击切换至状态 1，显示原电池工作原理
  2. "电解池模式"按钮：位于 (400,450)，点击切换至状态 2，显示电解池工作原理
  3. "重置"按钮：位于 (500,450)，点击回到状态 0，清除所有高亮和标注
- 教师操作流程：
  1. 初始展示装置结构，讲解电极和溶液组成
  2. 点击"原电池模式"，讲解 Fe 作为负极自发失去电子，电子经导线流向 C 正极
  3. 点击"电解池模式"，讲解外接电源如何强制电流方向，电极极性由电源决定
  4. 反复切换对比，强调原电池（化学能→电能）与电解池（电能→化学能）的本质区别

  └─────────────────────────────────────────────────────────┘

- 关键实现要点：
  1. 状态机设计：使用变量 currentMode = 0|1|2 跟踪当前状态
  2. 坐标计算：所有元素使用绝对坐标，通过 SVG transform 控制显示/隐藏
  3. 动画曲线：开关状态切换使用 CSS transition（opacity 0.3s ease）
  4. 事件绑定：三个按钮分别绑定 click 事件，调用 switchMode(mode) 函数
  5. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-electrode-c, scene1-switch-k1）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染

- 状态切换逻辑：
  function switchMode(mode) {
    // 重置所有元素
    resetElements();
    
    if (mode === 1) {
      // 原电池模式
      scene1-switch-k1.setAttribute('class', 'closed');
      scene1-arrow-electron.style.display = 'block';
      scene1-label-negative.textContent = '负极';
      scene1-label-negative.style.fill = '#1565c0';
      scene1-label-positive.textContent = '正极';
      scene1-label-positive.style.fill = '#1565c0';
      scene1-electrode-fe.style.stroke = '#1565c0';
      scene1-electrode-fe.style.strokeWidth = '3';
      scene1-electrode-c.style.stroke = '#1565c0';
      scene1-electrode-c.style.strokeWidth = '3';
      scene1-arrow-na.style.display = 'block';
      scene1-arrow-cl.style.display = 'block';
      scene1-btn-galvanic.style.backgroundColor = '#1565c0';
    } else if (mode === 2) {
      // 电解池模式
      scene1-switch-k2.setAttribute('class', 'closed');
      scene1-power-source.style.display = 'block';
      scene1-label-negative.textContent = '阳极';
      scene1-label-negative.style.fill = '#c62828';
      scene1-label-positive.textContent = '阴极';
      scene1-label-positive.style.fill = '#2e7d32';
      scene1-electrode-c.style.stroke = '#c62828';
      scene1-electrode-c.style.strokeWidth = '3';
      scene1-electrode-fe.style.stroke = '#2e7d32';
      scene1-electrode-fe.style.strokeWidth = '3';
      scene1-arrow-cl.style.display = 'block';
      scene1-btn-electrolytic.style.backgroundColor = '#c62828';
