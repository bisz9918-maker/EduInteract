[图示主题与整合说明]
- 本图示主题：电极反应分步详解（原电池与电解池对比）
- 整合内容：整合原电池和电解池两种模式下各电极的反应式、电子转移、产物标注
- 教学价值：教师可逐步引导学生理解：
  1. 原电池模式下 Fe 为负极（活泼金属失电子），C 为正极（氧气得电子）
  2. 电解池模式下阳极发生氧化（Cl⁻失电子生成 Cl₂），阴极发生还原（H₂O得电子生成 H₂）
  3. 通过颜色编码强化记忆：红色=氧化/失电子，绿色=还原/得电子，蓝色=原电池自发过程

[分步序列]
步骤0（初始状态）：
- 显示：左右栏背景、标题、烧杯、电极、导线、反应区框（空白）
- 隐藏：所有反应式、电极标签、反应类型标签、电子箭头
- 目的：展示基础装置框架，等待开始讲解

步骤1：
- 新增：左栏"负极"标签（蓝色，105,250）、"氧化反应"标签（红色，110,270）
- 高亮：左电极1（Fe）边框变为红色#c62828，粗细3
- 目的：引导学生识别原电池负极（活泼金属 Fe）

步骤2：
- 新增：左反应区显示"Fe - 2e⁻ = Fe²⁺"（红色#c62828）
- 新增：电子箭头从 Fe 电极指向反应式（蓝色#1565c0）
- 目的：展示负极氧化反应式

步骤3：
- 新增：左栏"正极"标签（蓝色，145,250）、"还原反应"标签（绿色，150,270）
- 高亮：左电极2（C）边框变为绿色#2e7d32，粗细3
- 目的：引导学生识别原电池正极

步骤4：
- 新增：左反应区新增"O₂ + 2H₂O + 4e⁻ = 4OH⁻"（绿色#2e7d32）
- 新增：电子箭头从反应式指向 C 电极（蓝色#1565c0）
- 目的：展示正极还原反应式（吸氧腐蚀）

步骤5：
- 新增：右栏"阳极"标签（红色，505,250）、"氧化反应"标签（红色，510,270）
- 高亮：右电极1（阳极）边框变为红色#c62828，粗细3
- 目的：切换到电解池模式，识别阳极

步骤6：
- 新增：右反应区显示"2Cl⁻ - 2e⁻ = Cl₂↑"（红色#c62828）
- 新增：电子箭头从阳极指向反应式（蓝色#1565c0）
- 新增：产物标注"Cl₂↑"（红色，510,360）
- 目的：展示阳极氧化反应式

步骤7：
- 新增：右栏"阴极"标签（绿色，545,250）、"还原反应"标签（绿色，550,270）
- 高亮：右电极2（阴极）边框变为绿色#2e7d32，粗细3
- 目的：识别电解池阴极

步骤8（最终步骤）：
- 新增：右反应区新增"2H₂O + 2e⁻ = H₂↑ + 2OH⁻"（绿色#2e7d32）
- 新增：产物标注"H₂↑"（绿色，550,360）
- 目的：展示阴极还原反应式，完成两种模式对比

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：位于(280,445)，点击返回上一步骤，步骤0时禁用
  - "下一步 ▶"按钮：位于(420,445)，点击进入下一步骤，步骤8时禁用
  - 步骤指示器：位于(360,410)，显示"步骤 X/8"，实时更新
- 教师操作流程：
  1. 展示初始装置框架（步骤0）
  2. 点击"下一步"逐步讲解原电池模式（步骤1-4）
  3. 继续点击"下一步"讲解电解池模式（步骤5-8）
  4. 如需回顾某一步，点击"上一步"返回
  5. 配合颜色编码强调：红色=氧化/失电子，绿色=还原/得电子

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何形状简单（矩形、线段、文本），无需复杂绘图库；原生实现轻量、易维护
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │                    原电池模式        电解池模式              │
  │  ┌──────────────────────────┐  ┌──────────────────────────┐ │
  │  │   [烧杯]  Fe   C         │  │   [烧杯]  阳极 阴极      │ │
  │  │          │    │          │  │          │     │        │ │
  │  │          └────┘          │  │          └──┬──┘        │ │
  │  │                         │  │              │ 电源      │ │
  │  │  负极  正极              │  │  阳极    阴极            │ │
  │  │  氧化  还原              │  │  氧化    还原            │ │
  │  │  ┌──────────────┐       │  │  ┌──────────────┐        │ │
  │  │  │ Fe-2e=Fe²⁺  │       │  │  │2Cl⁻-2e=Cl₂↑ │        │ │
  │  │  │O₂+2H₂O+4e=4OH│       │  │  │2H₂O+2e=H₂↑ │        │ │
  │  │  └──────────────┘       │  │  └──────────────┘        │ │
  │  └──────────────────────────┘  └──────────────────────────┘ │
  │                                                             │
  │              步骤 X/8                                       │
  │         [◀ 上一步]      [下一步 ▶]                          │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 currentStep（0-8）跟踪当前步骤
  2. 元素 ID 命名：所有元素 ID 以 scene2- 为前缀（如 scene2-electrode-fe、scene2-reaction-anode）
  3. 显示/隐藏控制：使用 class="hidden"配合 CSS display:none，或 JS setAttribute('display','none')
  4. 高亮效果：通过修改 stroke 和 stroke-width 属性实现
  5. 按钮状态：步骤0时禁用"上一步"，步骤8时禁用"下一步"（opacity=0.5，pointer-events=none）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 事件绑定：使用 addEventListener 绑定按钮点击事件
  8. MathJax：如需渲染复杂数学公式，可引入 MathJax CDN，但本场景反应式可用普通文本
