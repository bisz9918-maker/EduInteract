题目原文：
如图，边长都是1的正方形和正三角形，其一边在同一水平线上，三角形沿该水平线自左向右匀速穿过正方形．设穿过的时间为t，正方形与三角形重合部分的面积为S(空白部分)，那么S关于t的函数大致图象为( )

题目分析：
本题考察动态几何中的面积变化规律，需要分析正三角形匀速穿过正方形过程中，重叠面积S随时间t的变化关系。

关键信息：

  • 正方形边长 = 1
  • 正三角形边长 = 1，高 = √3/2 ≈ 0.866
  • 三角形匀速运动
  • 求S-t函数图像

整体讲解思路：

  1. 首先展示三角形穿过正方形的完整过程，让学生直观理解运动轨迹
  2. 分析面积变化的三个阶段：进入→完全重叠→离开
  3. 推导每个阶段面积与时间的函数关系
  4. 根据函数关系选择正确的图像

图示规划：

  • Scene 1：动态演示三角形穿过正方形的全过程，展示面积变化的五个关键阶段
阶段 0：初始位置

教学说明：

本图示通过分步动画展示三角形穿过正方形的完整过程，教师应按以下步骤引导学生：

1. 观察几何关系（步骤0-1）
让学生注意三角形和正方形的尺寸关系：

  • 三角形高 = √3/2 ≈ 0.866 < 正方形边长 = 1
  • 因此三角形可以完全进入正方形内部

2. 分析面积变化规律（步骤2-5）

进入阶段（步骤2）：

  • 重叠部分是一个小正三角形
  • 设进入距离为x，则重叠三角形边长为x
  • 面积 S = (√3/4)·x²，是x的二次函数
  • 由于匀速运动，x = vt，所以 S ∝ t²
  • 图像特征：上升的抛物线（开口向上）

完全重叠阶段（步骤3-4）：

  • 三角形完全在正方形内部
  • 重叠面积 = 三角形面积 = √3/4（常数）
  • 图像特征：水平直线

离开阶段（步骤5）：

  • 重叠部分逐渐减小
  • 面积变化规律与进入阶段对称
  • 图像特征：下降的抛物线（开口向下）

3. 匹配函数图像
根据上述分析，S-t图像应该是：

  • 先上升（曲线）
  • 然后水平（常数）
  • 最后下降（曲线）

对应选项C的形状。

4. 关键公式
正三角形面积公式：S = (√3/4)·a²，其中a为边长

5. 易错点提醒

  • 学生容易误认为面积变化是线性的（选A）
  • 需要强调：小三角形的面积与边长的平方成正比，不是线性关系
  • 完全重叠阶段的存在是因为三角形高 < 正方形边长

完整解答：

答案：C

解题过程总结：

  1. 确定运动阶段
  • 进入阶段：三角形从接触正方形到完全进入
  • 完全重叠阶段：三角形完全在正方形内部
  • 离开阶段：三角形从开始离开到完全离开
  1. 分析各阶段面积变化
  • 进入阶段：S = (√3/4)·(vt)²，二次函数，图像为上升抛物线
  • 完全重叠阶段：S = √3/4（常数），图像为水平直线
  • 离开阶段：S = (√3/4)·(v(T-t))²，二次函数，图像为下降抛物线
  1. 选择正确图像
  • A：线性变化，错误
  • B：无水平段，错误
  • C：曲线上升→水平→曲线下降，正确
  • D：无水平段且形状不对，错误

课堂讲解建议：

  • 先用图示演示完整过程，建立直观认识
  • 重点讲解进入和离开阶段的面积公式推导
  • 强调"面积与边长平方成正比"这一关键关系
  • 通过对比四个选项，排除错误答案
  • 总结：动态几何问题要分阶段分析，每个阶段用相应的数学工具
