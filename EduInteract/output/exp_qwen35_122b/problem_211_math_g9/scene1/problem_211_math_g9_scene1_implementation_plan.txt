[分步序列]
- 步骤0（初始状态）：
  - 显示：平行四边形ABCD、对角线BD、点E和F、线段AE和CF
  - 标注：顶点标签A、B、C、D、E、F，∠1和∠2标签及弧线
  - 已知条件高亮：AB=CD等长标记（绿色）、AB∥CD平行箭头（绿色）、∠ABE=∠CDF内错角弧（绿色）
  - 顶部说明文本："如图，四边形ABCD中，AB∥CD，AB=CD，E、F是对角线BD上的两点"

- 步骤1（选项A分析）：
  - 新增：高亮显示线段AE和CF为红色（#c62828）
  - 顶部说明文本："选项A：添加AE=CF，这是SSA（边边角），不能判定△ABE≌△CDF"
  - 底部提示："SSA不是全等判定定理"

- 步骤2（选项B分析）：
  - 高亮变化：线段AE和CF恢复黑色，高亮线段BE和FD为蓝色（#1565c0）
  - 顶部说明文本："选项B：添加BE=FD，结合AB=CD和∠ABE=∠CDF，可用SAS判定△ABE≌△CDF"
  - 底部提示："SAS：两边及其夹角对应相等"

- 步骤3（选项C分析）：
  - 高亮变化：显示BF=DE推导过程，高亮BE和FD为蓝色
  - 顶部说明文本："选项C：添加BF=DE，可推出BE=FD（BF-EF=DE-EF），同选项B，SAS可判定"
  - 底部提示："等量减等量，差相等"

- 步骤4（选项D分析）：
  - 高亮变化：高亮∠1和∠2弧线为蓝色（#1565c0）
  - 顶部说明文本："选项D：添加∠1=∠2，结合AB=CD和∠ABE=∠CDF，可用ASA判定△ABE≌△CDF"
  - 底部提示："ASA：两角及其夹边对应相等"

- 步骤5（总结）：
  - 高亮变化：选项A的AE=CF保持红色高亮，其他选项条件显示为蓝色
  - 顶部说明文本："总结：选项A（AE=CF）是SSA，不能判定全等，故答案为A"
  - 底部提示："正确答案：A"

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 按钮"◀ 上一步"：位置(250,455)，作用：返回上一状态，第一步时禁用
  - 按钮"下一步 ▶"：位置(450,455)，作用：进入下一状态，最后一步时变为"完成"
- 教师操作流程：
  1. 从步骤0开始，展示题目原图和已知条件
  2. 点击"下一步"依次展示选项A、B、C、D的分析
  3. 每个步骤讲解对应选项的几何意义和判定方法
  4. 最后一步总结答案，可回退复习关键步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │  步骤说明文本区 (50,50)-(750,100)                       │
  │                                                         │
  │         A(250,150)                    D(650,150)        │
  │           ╱│╲                        ╱│╲               │
  │          ╱ │ ╲                      ╱ │ ╲              │
  │         ╱  │  ╲                    ╱  │  ╲             │
  │   B(150,350) E(275,300)    F(525,200) C(550,350)       │
  │                                                         │
  │                                                         │
  │                                                         │
  │          [◀ 上一步]      [下一步 ▶]                     │
  │          (250,455)        (450,455)                     │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 currentStep 跟踪当前步骤（0-5），步骤0为初始状态
  2. 坐标计算：所有元素坐标硬编码，确保精确到像素级
  3. 高亮切换：通过修改 SVG 元素的 stroke/fill 属性实现颜色变化
  4. 文本更新：顶部说明文本和底部提示文本根据步骤动态更新
  5. 按钮状态：第一步禁用"上一步"，最后一步"下一步"变为"完成"
  6. ID 命名规范：所有元素 ID 以"scene1-"为前缀（如 scene1-quad-abcd、scene1-btn-prev）
  7. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  8. 事件绑定：使用 addEventListener 绑定按钮点击事件，通过 data-step 属性传递步骤信息
