场景导航：Scene 1

题目原文：
如图，自行车的链条每节长为2.5cm，每两节链条相连接部分重叠的圆的直径为0.8cm如果某种型号的自行车链条共有100节，则这根链条没有安装时的总长度为（ ）

A．250cm B．174.5cm C．170.8cm D．172cm

题目分析：
这是一道找规律的数学应用题，核心在于理解链条连接时的重叠关系。

关键信息提取：

  • 单节链条长度：2.5cm
  • 连接重叠部分：0.8cm（每两节连接时重叠一次）
  • 链条节数：100节

解题思路：

  1. 先观察1节、2节、3节链条的长度，找出规律
  2. 推导n节链条的通用公式
  3. 代入n=100计算最终答案

图示规划：
本设计规划1个核心图示，通过分步导航展示从具体到抽象的完整推导过程：

  • 步骤0：展示1节链条（基础长度）
  • 步骤1：展示2节链条（引入重叠概念）
  • 步骤2：展示3节链条（验证规律）
  • 步骤3：展示n节链条通用公式
  • 步骤4：展示100节链条计算结果

教学说明：

本图示通过递进式分步导航，帮助学生从直观感知到抽象推导，完整理解链条长度规律。

讲解要点：

  1. 步骤0→步骤1：重点讲解"重叠"概念
  • 引导学生观察：2节链条不是简单的2.5×2=5cm
  • 强调重叠部分0.8cm被"计算了两次"，需要减去一次
  • 得出：2节长度 = 2.5 + 2.5 - 0.8 = 4.2cm
  1. 步骤1→步骤2：验证规律的一致性
  • 3节链条有2个重叠部分
  • 总长度 = 2.5×3 - 0.8×2 = 7.5 - 1.6 = 5.9cm
  • 引导学生发现：n节链条有(n-1)个重叠部分
  1. 步骤2→步骤3：抽象为通用公式
  • 总长度 = 单节长度×节数 - 重叠长度×(节数-1)
  • L = 2.5n - 0.8(n-1)
  • 化简：L = 2.5n - 0.8n + 0.8 = 1.7n + 0.8
  1. 步骤3→步骤4：代入计算
  • n = 100
  • L = 1.7×100 + 0.8 = 170 + 0.8 = 170.8cm
  • 答案选C

易错点提醒：

  • 学生容易忘记重叠部分，直接计算2.5×100=250cm（选项A）
  • 学生可能错误计算重叠次数，用100个重叠而不是99个
  • 强调：n节链条只有(n-1)个连接点

课堂建议：

  • 可让学生先独立思考，再逐步揭示答案
  • 用分步导航回看关键步骤，强化"重叠次数=节数-1"的理解
  • 可拓展：如果链条有n节，总长度公式是什么？
