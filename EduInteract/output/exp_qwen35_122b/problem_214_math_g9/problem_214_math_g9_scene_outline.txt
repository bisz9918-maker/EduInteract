    **题目原文：**
    如图，在△ABC中，AB、AC的垂直平分线分别交BC于点E、F，若∠BAC=110°，则∠EAF为（  ）
    A．35°  B．40°  C．45°  D．50°

    **题目分析：**
    本题考察垂直平分线的性质及其在角度计算中的应用。关键知识点：
    1. 垂直平分线上的点到线段两端距离相等
    2. 等腰三角形底角相等的性质
    3. 三角形内角和定理

    **整体讲解思路：**
    本题的核心在于理解垂直平分线如何构造等腰三角形，进而利用等腰三角形的底角相等性质建立角度关系。讲解时应分三步：
    1. 先展示题目原图，明确已知条件（垂直平分线、∠BAC=110°）
    2. 揭示垂直平分线的性质：EA=EC，FA=FB，形成两个等腰三角形
    3. 通过角度关系推导：∠EAF = ∠BAC - (∠B + ∠C) = 110° - 70° = 40°

    **教学说明：**

    本图示通过分步导航完整展示了解题的推理链条，教师应按以下步骤引导学生：

    **步骤0（题目原图）：**
    展示原始图形，让学生明确已知条件：
    - EG是AC的垂直平分线，交BC于E
    - FH是AB的垂直平分线，交BC于F
    - ∠BAC=110°
    - 目标：求∠EAF

    **步骤1（揭示垂直平分线性质）：**
    高亮显示垂直平分线EG和FH，并标注等长关系：
    - 垂直平分线性质：垂直平分线上的点到线段两端距离相等
    - 因此：EA = EC，FA = FB
    - 这形成了两个等腰三角形：△EAC和△FAB

    **步骤2（标注等腰三角形底角）：**
    利用等腰三角形性质标注底角相等：
    - △EAC中：∠EAC = ∠ECA = ∠C
    - △FAB中：∠FAB = ∠FBA = ∠B

    **步骤3（角度关系推导）：**
    建立角度方程：
    - ∠BAC = ∠EAC + ∠EAF + ∠FAB
    - 代入等腰三角形底角关系：∠BAC = ∠C + ∠EAF + ∠B
    - 已知∠BAC = 110°，所以：110° = ∠B + ∠C + ∠EAF

    **步骤4（得出结论）：**
    利用三角形内角和定理完成计算：
    - 在△ABC中：∠B + ∠C = 180° - ∠BAC = 180° - 110° = 70°
    - 代入上式：∠EAF = 110° - (∠B + ∠C) = 110° - 70° = 40°
    - 答案：B．40°

    **讲解要点：**
    1. 强调垂直平分线性质的应用是解题关键
    2. 引导学生观察等腰三角形如何帮助建立角度关系
    3. 提醒学生注意角度的分解与组合：∠BAC被AE、AF分成三部分
    4. 最后验证答案合理性：40°是合理角度值
