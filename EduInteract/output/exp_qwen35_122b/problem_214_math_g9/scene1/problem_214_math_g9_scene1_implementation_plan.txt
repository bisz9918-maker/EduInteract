[分步序列]
步骤0（初始状态）：
- 显示：三角形ABC（黑色）、点A/B/C/E/F标签、线段AE/AF（黑色）
- 显示：∠BAC=110°标签（A点下方）、∠EAF=?标签（∠BAC下方）
- 显示：∠BAC、∠EAF、∠B、∠C的绿色角度弧线
- 隐藏：垂直平分线EG/FH、直角标记、等长标记、推导公式、结论

步骤1（垂直平分线性质）：
- 新增：垂直平分线EG（蓝色）、FH（蓝色）
- 新增：直角标记G、H（蓝色）
- 新增：等长标记短线（EA/EC用相同标记，FA/FB用相同标记）
- 新增：标签"EA=EC"（左侧200,320）、"FA=FB"（右侧540,320）
- 高亮：EG、FH线段加粗至3px

步骤2（等腰三角形底角）：
- 新增：标签"∠C=∠EAC"（左侧120,360）
- 新增：标签"∠B=∠FAB"（右侧680,360）
- 高亮：∠C和∠EAC弧线用相同颜色/样式
- 高亮：∠B和∠FAB弧线用相同颜色/样式

步骤3（角度关系推导）：
- 新增：推导公式文本（400,450）：
  "∠B + ∠C = 180° - 110° = 70°"
  "∠EAF = 110° - (∠EAC + ∠FAB) = 110° - (∠C + ∠B) = 40°"
- 高亮：∠EAC和∠FAB区域用灰色虚线框标注

步骤4（最终结论）：
- 新增：结论标签"∠EAF = 40°"（400,200，红色加粗20px）
- 高亮：∠EAF区域填充红色20%透明度
- 隐藏：推导公式（或移至角落）
- 显示：选项"A．35° B．40° C．45° D．50°"，其中B项高亮

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - scene1-prevBtn：上一步按钮，位于(280,455)，点击返回上一步，步骤0时禁用
  - scene1-nextBtn：下一步按钮，位于(620,455)，点击进入下一步，步骤4时禁用
  - scene1-stepIndicator：步骤指示器，位于(400,465)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始展示题目图形和已知条件（∠BAC=110°，求∠EAF）
  2. 点击"下一步"，揭示垂直平分线及其性质（EA=EC，FA=FB）
  3. 点击"下一步"，标注等腰三角形底角相等关系
  4. 点击"下一步"，展示角度推导过程
  5. 点击"下一步"，突出显示最终结论∠EAF=40°
  6. 可随时点击"上一步"回退复习关键步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（几何图形简单，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  ┌─────────────────────────────────────────────────┐
  │              图示区 800×500                     │
  │                                                 │
  │                    A(400,100)                   │
  │                   /    \                        │
  │                  /      \                       │
  │                 G        H                      │
  │                /          \                     │
  │               /            \                    │
  │              /    ∠EAF     \                   │
  │             E───────────────F                   │
  │            /                 \                  │
  │           C                   B                 │
  │                                                 │
  │  [控件栏 y=440~490]                             │
  │  ◀ 上一步    步骤 1/5    下一步 ▶               │
  └─────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-4) 跟踪当前步骤
  2. 元素分组：每个步骤的元素用 data-step 属性标记，如 data-step="1" 表示步骤1显示
  3. 坐标计算：所有坐标硬编码，确保精确到像素
  4. 动画曲线：步骤切换用 opacity 过渡 (0.3s ease)
  5. 事件绑定：按钮点击事件监听，更新 currentStep 并刷新显示
  6. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-tri-abc、scene1-prevBtn）
  7. IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局污染
  8. 禁用状态：步骤0时 prevBtn 禁用，步骤4时 nextBtn 禁用，用 opacity=0.5 和 pointer-events=none
