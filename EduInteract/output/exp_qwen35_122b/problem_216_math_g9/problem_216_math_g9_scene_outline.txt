    **题目原文：**
    如图，抛物线 y＝ax²+bx+c（a≠0）的对称轴为直线 x＝1，与 x 轴的一个交点坐标为（﹣1，0），其部分图象如图所示，下列结论：①4ac＜b²；②3a+c＞0；③当 x＞0 时，y 随 x 的增大而减小；④当 y＞0 时，x 的取值范围是﹣1＜x＜3；⑤方程 ax²+bx+c＝0 的两个根是 x₁＝﹣1，x₂＝3；其中结论正确的个数是（  ）

    A．4个  B．3个  C．2个  D．1个

    **题目分析：**
    本题考查二次函数图像与性质的综合应用。从图像和已知条件可提取以下关键信息：
    - 抛物线开口向下 → a < 0
    - 对称轴 x = 1 → -b/(2a) = 1
    - 与 x 轴交点 (-1, 0) → 代入得 a - b + c = 0
    - 与 y 轴交点 (0, 3) → c = 3

    **整体讲解思路：**
    1. 首先引导学生观察图像，识别抛物线的基本特征（开口方向、对称轴、交点）
    2. 利用对称性求出另一个 x 轴交点坐标
    3. 逐个验证五个结论的正确性
    4. 统计正确结论个数

    **图示规划说明：**
    - Scene 1：展示抛物线完整图像，标注对称轴、已知交点、y 轴交点，通过点击逐步揭示另一个交点（利用对称性）

    **图示 1 教学说明：**

    本图示用于引导学生观察抛物线图像的基本特征，并应用对称性求出另一个交点。

    **讲解要点：**

    1. **观察图像特征**
    - 抛物线开口向下，说明 a < 0
    - 对称轴为直线 x = 1（图中虚线）
    - 与 x 轴的一个交点为 (-1, 0)
    - 与 y 轴的交点为 (0, 3)，即 c = 3

    2. **应用对称性求另一个交点**
    - 对称轴 x = 1，已知交点 (-1, 0) 到对称轴的距离为 |1 - (-1)| = 2
    - 根据对称性，另一个交点到对称轴的距离也为 2
    - 因此另一个交点坐标为 (1 + 2, 0) = (3, 0)

    3. **关键结论**
    - 抛物线与 x 轴有两个交点：x₁ = -1，x₂ = 3
    - 当 y > 0 时，x 的取值范围是 -1 < x < 3（抛物线在 x 轴上方的部分）

    **引导学生观察的顺序：**
    - 先让学生识别图像中的已知条件（对称轴、已知交点）

    **图示 2 教学说明：**

    本图示用于逐一验证五个结论的正确性，是本题的核心推导部分。

    **各结论验证过程：**

    1. **结论①：4ac < b²**
    - 抛物线与 x 轴有两个交点，说明方程 ax² + bx + c = 0 有两个不等实根
    - 判别式 Δ = b² - 4ac > 0
    - 因此 b² > 4ac，即 4ac < b²
    - **结论①正确** ✓

    2. **结论②：3a + c > 0**
    - 已知 c = 3（与 y 轴交点）
    - 对称轴 x = 1，即 -b/(2a) = 1，得 b = -2a
    - 代入交点 (-1, 0)：a(-1)² + b(-1) + c = 0
    - 即 a - b + c = 0，代入 b = -2a 得：a - (-2a) + 3 = 0
    - 3a + 3 = 0，得 a = -1
    - 因此 3a + c = 3(-1) + 3 = 0，不是大于 0
    - **结论②错误** ✗

    3. **结论③：当 x > 0 时，y 随 x 的增大而减小**
    - 对称轴 x = 1，开口向下
    - 当 x < 1 时，y 随 x 增大而增大
    - 当 x > 1 时，y 随 x 增大而减小
    - 因此"当 x > 0 时"这个说法不准确（0 < x < 1 时 y 是增大的）
    - **结论③错误** ✗

    4. **结论④：当 y > 0 时，x 的取值范围是 -1 < x < 3**
    - 抛物线与 x 轴交于 (-1, 0) 和 (3, 0)
    - 开口向下，所以在两个交点之间抛物线在 x 轴上方
    - 即当 -1 < x < 3 时，y > 0
    - **结论④正确** ✓

    5. **结论⑤：方程 ax² + bx + c = 0 的两个根是 x₁ = -1，x₂ = 3**
    - 由图像和对称性已求得两个交点为 (-1, 0) 和 (3, 0)
    - 即方程的两个根为 x₁ = -1，x₂ = 3
    - **结论⑤正确** ✓

    **最终统计：**
    - 正确结论：①、④、⑤，共 3 个
    - 答案：**B．3 个**

    **课堂讲解建议：**
    - 先让学生独立判断每个结论，再公布答案
    - 重点讲解结论②和③的推导过程，这是易错点
    - 强调对称性在二次函数问题中的重要性
