[分步序列]
- 步骤0（初始状态）：
  - 显示左侧结论列表（5个结论）
  - 右侧显示抛物线简化图（含对称轴、三个交点）
  - 高亮框位于结论①
  - 推导公式区显示："点击「下一步」开始验证"
  - 判断结果区显示："-"

- 步骤1（验证结论① 4ac < b²）：
  - 高亮框移至结论①
  - 推导公式显示："抛物线与x轴有两个交点 → Δ = b² - 4ac > 0 → 4ac < b²"
  - 判断结果显示："正确"（绿色✓）
  - 抛物线图上高亮两个x轴交点（红色闪烁）

- 步骤2（验证结论② 3a + c > 0）：
  - 高亮框移至结论②
  - 推导公式显示："对称轴x=1 → -b/(2a)=1 → b=-2a；过(-1,0) → a-b+c=0 → 3a+c=0"
  - 判断结果显示："错误"（红色✗）
  - 抛物线图上高亮对称轴和点(-1,0)

- 步骤3（验证结论③ x>0时单调性）：
  - 高亮框移至结论③
  - 推导公式显示："开口向下，对称轴x=1 → x<1时y递增，x>1时y递减"
  - 判断结果显示："错误"（红色✗）
  - 抛物线图上用箭头标注：x<1区域向上箭头，x>1区域向下箭头

- 步骤4（验证结论④ y>0时x范围）：
  - 高亮框移至结论④
  - 推导公式显示："两根为-1和3，开口向下 → y>0在两根之间 → -1<x<3"
  - 判断结果显示："正确"（绿色✓）
  - 抛物线图上高亮x轴上方区域（-1到3之间）

- 步骤5（验证结论⑤ 方程的两个根）：
  - 高亮框移至结论⑤
  - 推导公式显示："对称轴x=1，一根为-1 → 另一根=1+(1-(-1))=3"
  - 判断结果显示："正确"（绿色✓）
  - 抛物线图上高亮两个x轴交点并标注坐标

- 步骤6（统计正确结论个数）：
  - 高亮框消失
  - 推导公式显示："正确结论：①、④、⑤"
  - 判断结果显示："共3个"（蓝色加粗）
  - 统计结果文本显示："正确结论个数：3个（答案B）"
  - 抛物线图上正确结论对应的元素同时高亮

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "上一步"按钮：位于底部左侧(280,450)，回退到上一个验证步骤
  - "下一步"按钮：位于底部中间(420,450)，进入下一个验证步骤
  - "重置"按钮：位于底部右侧(560,450)，回到初始状态
- 教师操作流程：
  1. 初始展示所有结论和抛物线图
  2. 点击"下一步"逐个验证每个结论
  3. 每个步骤展示推导过程和判断结果
  4. 可点击"上一步"回退复习某个结论的推导
  5. 最终步骤统计正确结论个数，给出答案

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无需额外库，图形简单）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │                        标题区（可选）                           │
  ├──────────────────────┬─────────────────────────────────────────┤
  │                      │                                         │
  │   左侧结论列表        │         右侧推导区                       │
  │   (300×340)         │         (420×340)                        │
  │   ① 4ac < b²        │         ┌─────────────────────────┐      │
  │   ② 3a + c > 0      │         │   抛物线简化图           │      │
  │   ③ 单调性          │         │   (含对称轴、交点)       │      │
  │   ④ y>0范围         │         └─────────────────────────┘      │
  │   ⑤ 方程根          │                                         │
  │                      │         推导公式：...                   │
  │                      │         判断：正确/错误                 │
  ├──────────────────────┴─────────────────────────────────────────┤
  │                      统计结果区                                  │
  │         正确结论个数：3个（答案B）                              │
  ├────────────────────────────────────────────────────────────────┤
  │              [上一步]        [下一步]        [重置]             │
  └────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：currentStep 变量（0-6），每个步骤对应不同的显示内容
  2. 坐标计算：抛物线用 SVG path 绘制，顶点在(570,80)，开口向下
  3. 高亮效果：使用 CSS class 切换（.highlight 蓝色背景，.correct 绿色，.wrong 红色）
  4. 动画曲线：元素出现使用 opacity 过渡（0.3s ease）
  5. 事件绑定：按钮点击事件更新 currentStep，重新渲染对应内容
  6. ID 命名规范：所有元素 ID 以"scene2-"为前缀（如 scene2-conclusion-1、scene2-next-btn）
  7. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  8. 抛物线绘制：使用 SVG path 的 quadratic bezier 曲线，顶点(570,80)，过点(410,280)和(730,280)
