[图示主题与整合说明]
- 本图示主题：二次函数 y = x² - 2x - 3 的图像性质验证
- 整合内容：∠ABC 角度验证（结论②）、0<x<2 区间函数值范围分析（结论③）
- 教学价值：教师可通过分步演示，引导学生理解抛物线与坐标轴交点的计算、等腰直角三角形的判定、以及函数值域的区间分析，帮助学生建立代数与几何的直观联系

[分步序列]
步骤 0（初始状态）：
- 显示：x 轴、y 轴、完整抛物线、点 A、B、C、O
- 隐藏：线段 BC、OB、OC、顶点 V、区间边界、范围阴影、所有结论标签
- 目的：展示题目基础图形

步骤 1：
- 新增：线段 BC（蓝色）、线段 OB（灰色）、线段 OC（灰色）
- 新增：标签"OB=3"在 (470,85)、标签"OC=3"在 (330,220)
- 高亮：△OBC 三边同时显示
- 目的：构建直角三角形 OBC，为角度验证做准备

步骤 2：
- 新增：角度弧线（B 点处，半径 40px，蓝色）
- 新增：标签"∠ABC=45°"在 (500,60)
- 高亮：∠ABC 角区域
- 结论：由于 OB=OC=3，△OBC 为等腰直角三角形，故∠OBC=45°，即∠ABC=45°，结论②正确

步骤 3：
- 新增：顶点 V（绿色圆点）
- 新增：标签"V"在 (440,435)
- 新增：区间左边界虚线（x=0，即 y 轴本身，用不同样式区分）
- 新增：区间右边界虚线（x=510，即 x=2 处）
- 新增：标签"0<x<2"在 (390,85)
- 目的：展示函数顶点及待分析区间

步骤 4：
- 新增：范围阴影区域（x∈[0,2]，y∈[-4,-3]，绿色 20% 透明度）
- 新增：标签"-4≤y<-3"在 (230,380)
- 高亮：阴影区域及边界
- 目的：直观展示 0<x<2 时函数值的变化范围

步骤 5（结论）：
- 汇总：所有元素显示
- 结论文本：结论②正确（∠ABC=45°），结论③正确（0<x<2 时，-4≤y<-3）
- 最终答案：正确结论有 2 个，选 B

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮：ID=scene2-prev，位置 (280,455)，作用：返回上一状态
  - 下一步按钮：ID=scene2-next，位置 (460,455)，作用：进入下一状态
  - 步骤指示器：位置 (370,460)，显示当前步骤"步骤 k/5"
- 教师操作流程：
  1. 初始展示抛物线与交点，引导学生回忆交点坐标计算方法
  2. 点击下一步，显示△OBC，引导学生观察边长关系
  3. 点击下一步，显示角度结论，讲解等腰直角三角形判定
  4. 点击下一步，显示顶点和区间，引导学生理解函数最值
  5. 点击下一步，显示范围阴影，直观展示函数值变化
  6. 点击下一步，总结结论，得出答案 B

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（线段、圆、路径），无需复杂数据可视化库，原生 SVG 性能最佳且代码简洁
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    SVG 画布 800×500                      │
  │                                                         │
  │     y↑                                                  │
  │       │                    ●B(3,0)                      │
  │       │                  /                              │
  │   ●A  │                /                                │
  │ (-1,0)│              /                                  │
  │       │            /                                    │
  │       ├──────●O──────────────────────→x                │
  │       │      (0,0)                                      │
  │       │                                                 │
  │       │                                                 │
  │       │              ●V(1,-4)                           │
  │       │                                                 │
  │       │        ●C(0,-3)                                 │
  │       │                                                 │
  │       │                                                 │
  │  ┌─────────────────────────────────────────────────┐   │
  │  │      ◀上一步    步骤 0/5      下一步▶            │   │
  │  └─────────────────────────────────────────────────┘   │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量（0-5），每一步对应一个状态对象，包含该步骤应显示/隐藏的元素 ID 列表
  2. 坐标计算：定义函数 px(x, y) 将数学坐标转换为像素坐标，x_px = 350 + x*80，y_px = 100 - y*80
  3. 抛物线绘制：采样 x∈[-2,5] 共 100 点，计算 y=x²-2x-3，生成 SVG 路径数据
  4. 动画曲线：使用 SVG SMIL 或 CSS transition 实现元素淡入淡出（opacity: 0→1）
  5. 事件绑定：上一步/下一步按钮点击事件，更新 currentStep 后调用 updateScene() 刷新显示
  6. ID 命名规范：所有元素 ID 以 scene2- 为前缀，如 scene2-axes、scene2-parabola、scene2-point-a 等
  7. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染

- 状态对象示例：
  ```javascript
  const sceneStates = {
    0: { show: ['axes', 'parabola', 'point-a', 'point-b', 'point-c', 'point-o'], hide: [...] },
    1: { show: ['axes', 'parabola', 'point-a', 'point-b', 'point-c', 'point-o', 'line-bc', 'line-ob', 'line-oc', 'label-ob', 'label-oc'], ... },
    // ... 步骤 2-5
  };
  ```
