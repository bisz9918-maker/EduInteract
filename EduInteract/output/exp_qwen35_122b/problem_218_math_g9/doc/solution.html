题目分析：
本题涉及两个直角三角板的组合摆放，核心知识点包括：

  1. 等腰直角三角形的性质（∠A=90°，AB=AC ⇒ ∠ACB=∠ABC=45°）
  2. 含 30°角的直角三角形性质（∠EDF=90°，∠E=30° ⇒ ∠F=60°）
  3. 平角性质（点 C 在 EF 上 ⇒ ∠ECF=180°）
  4. 三点共线性质（A、D、C 共线）
  5. 三角形内角和定理

整体讲解思路：
教师应先引导学生识别两个三角板的类型及已知角度，再逐步推导未知角度。关键在于理解点 C 在 EF 上形成的平角关系，以及 A、D、C 三点共线的隐含条件。

∠ACF = 180° - ∠ACE = 180° - 85° = 95°

步骤 4：确定∠DCF
