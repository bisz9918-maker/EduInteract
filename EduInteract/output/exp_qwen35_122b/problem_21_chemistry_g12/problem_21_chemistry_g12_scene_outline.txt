    **题目原文：**
    如图所示，a、b是两根石墨棒．下列叙述正确的是（  ）

    A．a为阳极，发生氧化反应：锌为负极被还原
    B．电路中电子流动方向：锌→b→a→铜
    C．电路中通过0.2mol电子，铜片上产生2.24L气体
    D．往滤纸上滴加酚酞，b极附近颜色变红

    **题目分析：**
    本题考察原电池与电解池的串联装置，涉及以下核心知识点：
    1. 原电池电极判断：锌比铜活泼，锌作负极，铜作正极
    2. 电解池电极判断：与电源正极相连的为阳极，与负极相连的为阴极
    3. 电极反应类型：负极/阳极发生氧化反应，正极/阴极发生还原反应
    4. 电子流动方向：电子从负极流出，经外电路流向正极，不经过电解质溶液
    5. 电解饱和食盐水产物：阴极产生 H₂ 和 OH⁻，阳极产生 Cl₂

    **整体讲解思路：**
    教师应引导学生分三步理解：首先识别左侧原电池的电极性质，其次判断右侧电解池的阴阳极，最后分析各电极的反应产物。图示将清晰展示装置连接、电子流向、离子移动和反应类型。

    **教学说明：**

    本图示用于引导学生系统理解原电池与电解池串联装置的工作原理。教师应按以下步骤讲解：

    1. **步骤 0：装置概览**
    先让学生观察整体装置，识别两个部分：左侧是原电池（锌铜稀硫酸），右侧是电解池（石墨棒电解饱和食盐水）。强调两个装置通过导线串联。

    2. **步骤 1：原电池电极判断**
    引导学生回忆金属活动性顺序：锌比铜活泼。因此锌作负极（失电子被氧化），铜作正极（得电子发生还原）。
    负极反应：Zn → Zn²⁺ + 2e⁻
    正极反应：2H⁺ + 2e⁻ → H₂↑

    3. **步骤 2：电解池电极判断**
    关键规则：与电源正极相连的是阳极，与电源负极相连的是阴极。
    - a 连接铜（正极）→ a 是阳极
    - b 连接锌（负极）→ b 是阴极

    4. **步骤 3：电子流向分析**
    电子从负极（锌）流出，经导线流向阴极（b）；阳极（a）的电子经导线流向正极（铜）。**电子不经过电解质溶液**，这是学生常见误区。

    5. **步骤 4：电极反应式**
    阳极（a）：2Cl⁻ → Cl₂↑ + 2e⁻（氧化反应）
    阴极（b）：2H₂O + 2e⁻ → H₂↑ + 2OH⁻（还原反应）

    6. **步骤 5：酚酞验证**
    b 极（阴极）产生 OH⁻，溶液呈碱性，滴加酚酞后变红。这是检验阴极产物的经典方法。

    **选项解析：**
    - A 错误：锌为负极被**氧化**，不是被还原
    - B 错误：电子不经过溶液，流向应为：锌→b（外电路），a→铜（外电路）
    - C 错误：未说明标准状况，无法确定气体体积
    - D 正确：b 极产生 OH⁻，酚酞变红

    **课堂总结与拓展：**

    **完整解答：** 正确答案为 D。

    **关键记忆点：**
    1. 原电池：活泼金属作负极，发生氧化反应
    2. 电解池：连正为阳，连负为阴
    3. 电子流向：负极→阴极，阳极→正极（不经过溶液）
    4. 电解饱和食盐水：阴极产生 H₂ 和 OH⁻，阳极产生 Cl₂

    **易错点提醒：**
    - 电子不经过电解质溶液，离子在溶液中移动形成闭合回路
    - "被氧化/被还原"与"作负极/正极"的对应关系要记清
    - 气体体积计算必须说明标准状况
