[分步序列]
步骤 0（初始状态 - 装置概览）：
- 显示：烧杯、滤纸、锌棒、铜棒、石墨棒 a 和 b、导线连接
- 标签：锌、铜、a、b、稀硫酸、饱和食盐水滤纸
- 不显示：电极性质标签、电子流向、反应式、酚酞变色

步骤 1（原电池电极标注）：
- 新增：负极标签（锌电极下方）、正极标签（铜电极下方）
- 高亮：锌棒蓝色加深，铜棒橙色加深
- 显示反应式框 1：负极反应 Zn → Zn²⁺ + 2e⁻（氧化反应）

步骤 2（电解池电极标注）：
- 新增：阳极标签（石墨棒 a 下方）、阴极标签（石墨棒 b 下方）
- 显示反应式框 2：阳极反应 2Cl⁻ → Cl₂↑ + 2e⁻（氧化反应）
- 显示反应式框 3：阴极反应 2H₂O + 2e⁻ → H₂↑ + 2OH⁻（还原反应）

步骤 3（电子流向高亮）：
- 新增：电子流向箭头（红色）
- 箭头 1：锌→石墨棒 b（沿导线）
- 箭头 2：石墨棒 a→铜（沿导线）
- 标注"e⁻"在箭头旁

步骤 4（电极反应式展示）：
- 完整显示三个反应式框
- 阳极反应框：红色边框 #c62828
- 阴极反应框：绿色边框 #2e7d32
- 离子流向箭头：绿色 #2e7d32 显示溶液中离子移动

步骤 5（酚酞变色验证）：
- 新增：b 极附近红色区域（酚酞变红）
- 标注：b 极产生 OH⁻，溶液呈碱性
- 结论：选项 D 正确

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于 (300,450)，返回上一状态
  - 「下一步 ▶」按钮：位于 (450,450)，进入下一状态

- 教师操作流程：
  1. 初始展示装置全貌，让学生观察整体结构
  2. 点击"下一步"展示原电池电极判断（锌负极、铜正极）
  3. 点击"下一步"展示电解池电极判断（a 阳极、b 阴极）
  4. 点击"下一步"展示电子流向
  5. 点击"下一步"展示完整电极反应式
  6. 点击"下一步"展示酚酞变色验证，得出结论

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │                        图示区 800×500                          │
  │                                                                │
  │   [烧杯区]                    [导线]              [滤纸区]     │
  │   ┌──────┐                    ──────            ┌──────────┐  │
  │   │ 锌 │铜 │                  ↗    ↘           │   a  b   │  │
  │   │     │  │                 │      │          │  ●    ●  │  │
  │   │ 稀硫酸 │                 │      │          └──────────┘  │
  │   └──────┘                  ──────                             │
  │                                                                │
  │   负极      正极                    阳极      阴极             │
  │                                                                │
  │   [反应式框 1]  [反应式框 2]  [反应式框 3]                      │
  │                                                                │
  │              [◀ 上一步]  [步骤 X/5]  [下一步 ▶]                │
  └────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：currentStep 变量 (0-5)，控制各元素 visibility
  2. 坐标计算：所有元素使用绝对坐标，SVG 内定位
  3. 动画曲线：元素出现使用 opacity 渐变 (0→1，300ms)
  4. 事件绑定：按钮点击事件更新 currentStep，刷新元素显示状态
  5. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-zinc-electrode、scene1-copper-electrode、scene1-step-btn-next 等）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 元素显示控制：通过 setAttribute('display', 'none/block') 或 setAttribute('opacity', '0/1') 控制
