[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "上一步"按钮：scene2-prev-btn，位于 (270,455)，点击返回前一步骤

  - 步骤指示器：显示"步骤 X/6"，位于 (360,420)
- 教师操作流程：
  1. 初始展示基础环流图，让学生观察 a/b/c/d 四点位置和气流方向
  2. 点击"下一步"，逐步标注 30°N 副热带高压带及其动力下沉成因
  3. 继续点击"下一步"，标注 60°N 副极地低压带
  4. 展示 b 处极锋形成（冷暖气流相遇），解释选项 C 的正确性
  5. 标注④箭头为"动力原因"，对比选项 D 的错误
  6. 最后显示结论，总结选项 C 正确、D 错误的判断依据

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）

- 关键实现要点：
  1. 状态机设计：currentStep 变量 (0-5)，控制各元素 visibility/display
  2. 坐标计算：所有元素使用绝对定位，SVG 内使用 x/y 属性
  3. 动画曲线：元素出现使用 opacity 渐变 (0→1，duration 300ms)
  4. 事件绑定：按钮点击事件监听，更新 currentStep 并刷新显示
  5. ID 命名规范：所有元素 ID 以 scene2- 为前缀（如 scene2-point-a、scene2-arrow-1、scene2-prev-btn）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 元素分组：使用 SVG <g> 元素按步骤分组，便于批量显示/隐藏
