[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：本题为几何图形标注，SVG 适合绘制线条、多边形、文本标签，原生 JS 足以实现分步状态切换，无需引入重型库

- 画布尺寸：800 × 500 px

- 布局草图（ASCII）：
```
┌─────────────────────────────────────────────────────────────┐
│                        图示区 800×500                        │
│                                                             │
│   23.5°N  ─────────────────────────────────────────────     │
│           ╱│                                              │
│          ╱ │  西半球│东半球                                │
│   0°    ╱  │  黑夜  │白昼                                  │
│   ─────●───┼────────┼────────                              │
│        ╱   │   甲   │                                      │
│   23.5°S ╲ │        │  乙                                  │
│           ╲│                                              │
│                                                             │
│   [◀ 上一步]                    [下一步 ▶]                  │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-5) 跟踪当前步骤
  2. 元素分组：每个步骤新增的元素用 data-step 属性标记，如 data-step="1" 表示步骤1显示
  3. 坐标计算：所有元素使用绝对坐标，SVG 中用 x/y 属性精确控制位置
  4. 动画曲线：高亮效果使用 CSS transition，闪烁效果用 keyframe 动画
  5. 事件绑定：按钮点击事件监听，更新 currentStep 后重新渲染可见元素
  6. ID 命名规范：所有交互元素 ID 以 scene1- 为前缀，如 scene1-prev-btn、scene1-next-btn、scene1-晨昏线、scene1-甲点等
  7. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染

- 状态切换逻辑：
```javascript
(function() {
  var currentStep = 0;
  var maxStep = 5;
  
  function updateVisibility() {
    // 遍历所有 data-step 元素
    // data-step="0" 始终显示
    // data-step="1" 在 step>=1 时显示
    // ...
    // data-step="all" 始终显示（如控件栏）
  }
  
  function prevStep() {
    if (currentStep > 0) {
      currentStep--;
      updateVisibility();
    }
  }
  
  function nextStep() {
    if (currentStep < maxStep) {
      currentStep++;
      updateVisibility();
    }
  }
  
  // 绑定事件
  document.getElementById('scene1-prev-btn').addEventListener('click', prevStep);
  document.getElementById('scene1-next-btn').addEventListener('click', nextStep);
  
  // 初始化
  updateVisibility();
})();
```
