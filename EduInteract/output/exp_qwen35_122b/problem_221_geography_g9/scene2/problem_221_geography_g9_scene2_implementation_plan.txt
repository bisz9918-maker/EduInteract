[分步序列]
- 步骤0（初始状态）：显示地球侧视图基础图示
  - 地球轮廓、赤道、南北回归线、晨昏线
  - 太阳直射点在南回归线(200,300)
  - 上海位置(260,175)
  - 甲、乙点标注
  - 所有纬度标签
  - 标题："基础图示"

- 步骤1：农历十五月出时间判断
  - 保留步骤0所有元素
  - 右侧出现月出时间示意图
  - 标注"农历十五"、"月出时间≈18:00"
  - 解释：农历十五月球与太阳相对，月出时间≈日落时间
  - 新增标签："18:00"在(600,100)

- 步骤2：太阳高度角计算
  - 保留步骤0地球图示
  - 右侧出现太阳能板示意图基础
  - 显示太阳光线射向上海位置
  - 标注正午太阳高度角H = 90° - |31° - (-23.5°)| = 35.5°
  - 新增标签"H=35.5°"在(610,300)

- 步骤3：太阳能板角度确定
  - 保留步骤2所有元素
  - 太阳能板显示最佳倾角位置
  - 标注太阳能板与墙面夹角α = 90° - H = 54.5°
  - 或太阳能板与地面夹角 = H = 35.5°
  - 新增标签"α=54.5°"在(590,340)

- 步骤4（结论）：综合答案
  - 显示所有计算结果汇总
  - 左侧：太阳直射点在南半球，甲地地方时6:00
  - 右侧：乙地白昼约11小时，月出时间约18:00，太阳能板最佳倾角54.5°
  - 高亮显示最终答案

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单，无需复杂库，原生实现更轻量
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │                        标题区 (y=50-70)                         │
  ├──────────────────────────┬─────────────────────────────────────┤
  │                          │                                     │
  │     地球侧视图区          │      太阳能板示意图区                │
  │     (x=50-350, y=80-400) │      (x=450-720, y=80-400)          │
  │                          │                                     │
  ├──────────────────────────┴─────────────────────────────────────┤
  │                        控件栏 (y=420-490)                       │
  │              [◀ 上一步]    步骤 X/5    [下一步 ▶]                │
  └────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量(0-4)跟踪当前步骤
  2. 坐标计算：所有元素使用绝对坐标，通过 SVG transform 控制显示/隐藏
  3. 动画曲线：步骤切换时使用 opacity 渐变(300ms ease-in-out)
  4. 事件绑定：按钮点击事件监听，更新 currentStep 并刷新视图
  5. ID 命名规范：所有元素 ID 以"scene2-"为前缀（如 scene2-earth, scene2-panel）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中
  7. 使用 data-step 属性标记各元素所属步骤，便于批量控制显示
- 元素显示控制：
  - 步骤0元素：data-step="0"
  - 步骤1新增：data-step="1"
  - 步骤2新增：data-step="2"
  - 步骤3新增：data-step="3"
  - 步骤4（结论）：data-step="4"
  - 更新视图时，显示 data-step ≤ currentStep 的所有元素
