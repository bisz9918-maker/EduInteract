[分步序列]
步骤0（初始状态）：
- 显示完整经纬网格（11条经线+6条纬线）
- 显示经度标注（上方）和纬度标注（右侧）
- 显示四个点①②③④（黑色实心圆，直径6px）
- 显示点号标注①②③④
- 不显示辅助线、新加坡标记、答案框

步骤1（方向判断）：
- 高亮①点和③点（蓝色#1565c0，直径8px）
- 绘制南北向参考虚线：从③(656,92)垂直向下到(656,316)
- 绘制东西向参考虚线：从①(144,316)水平向右到(656,316)
- 在③点上方显示"北"字标注（灰色）
- 在①点下方显示"南"字标注（灰色）
- 在①点左侧显示"西"字标注（灰色）
- 在③点右侧显示"东"字标注（灰色）
- 目的：展示方向判断逻辑——①在③的南方（纬度更低）和西方（经度更西）

步骤2（坐标匹配）：
- 保留步骤1的所有元素
- 在新加坡坐标位置(1°N, 104°E)绘制红色空心圆圈（直径8px）
  - 计算位置：经度104°E对应x≈619（120°E在656，90°E在592，104°在中间偏左）
  - 纬度1°N对应y≈309（0°在316，10°N在252，1°N靠近0°）
  - 实际使用(630, 308)
- 显示新加坡标注文字"新加坡(1°N, 104°E)"（红色，位于点右上方）
- 目的：让学生视觉对比新加坡位置与图中四个点的接近程度

步骤3（结论展示）：
- 保留步骤2的所有元素
- 在右下角显示答案框（绿色边框，背景透明度20%）
- 答案框内显示：
  - "（1）①点在③点的西南方向"
  - "（2）新加坡位置接近②，①的经纬度为(0°, 120°W)"
- 目的：展示完整答案，供教师总结讲解

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：位于(150,450)，点击返回上一状态，初始状态时禁用
  - "下一步 ▶"按钮：位于(550,450)，点击进入下一状态，最终状态时变为"完成"
  - 步骤指示器：位于(370,455)，显示"步骤 1/4"等，实时更新
- 教师操作流程：
  1. 初始展示经纬网图，让学生观察四个点位置
  2. 点击"下一步"进入步骤1，高亮①③点并显示辅助线，讲解方向判断方法
  3. 点击"下一步"进入步骤2，显示新加坡位置，引导学生比较与哪个点接近
  4. 点击"下一步"进入步骤3，显示完整答案，进行总结
  5. 可随时点击"上一步"回退复习某个步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：经纬网为规则网格，用SVG line和circle元素即可精确绘制，无需复杂库
  - 动画效果简单（显示/隐藏），原生JS足以实现

- 画布尺寸：800 × 500 px

- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-3) 跟踪当前步骤
  2. 坐标计算：经度→x = 80 + (经度+150)×64/30；纬度→y = 380 - (纬度+10)×64/5
  3. 元素显示/隐藏：通过设置 SVG 元素的 display 属性或 opacity 控制
  4. 事件绑定：按钮点击事件监听，更新 currentStep 并刷新显示
  5. 按钮状态：步骤0时禁用"上一步"，步骤3时"下一步"变为"完成"

- ID 命名规范：所有交互元素 ID 以 scene1- 为前缀
  - scene1-grid-lines（网格线组）
  - scene1-point-1、scene1-point-2、scene1-point-3、scene1-point-4（四个点）
  - scene1-label-1、scene1-label-2、scene1-label-3、scene1-label-4（点号标注）
  - scene1-guide-vertical、scene1-guide-horizontal（方向辅助线）
  - scene1-singapore-point、scene1-singapore-label（新加坡标记）
  - scene1-answer-box、scene1-answer-text（答案框）
  - scene1-prev-btn、scene1-next-btn（导航按钮）
  - scene1-step-indicator（步骤指示器）

- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染
