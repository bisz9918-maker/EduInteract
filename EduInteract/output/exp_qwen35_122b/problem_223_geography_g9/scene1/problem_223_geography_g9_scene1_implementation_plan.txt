[分步序列]
- 步骤 0（整体概览）：显示太阳、公转轨道、四个地球位置（a/b/c/d）、地轴、公转方向箭头、季节标签（春夏秋冬）。不显示直射点标记和纬线标注。所有地球以正常样式显示。
- 步骤 1（a 位置 - 冬至）：高亮地球 a（绿色粗框），显示直射点 a（南回归线），显示南回归线标注 (400,350)，显示南极圈标注 (400,370)。文字说明：太阳直射南回归线，北半球昼短夜长，为冬至日。
- 步骤 2（b 位置 - 春分）：高亮地球 b（绿色粗框），显示直射点（赤道），显示赤道标注 (400,230)，显示北极圈标注 (400,130)。文字说明：太阳直射赤道，全球昼夜平分，为春分日。
- 步骤 3（c 位置 - 夏至）：高亮地球 c（绿色粗框），显示直射点 c（北回归线），显示北回归线标注 (400,150)，显示北极圈标注 (400,130)。文字说明：太阳直射北回归线，北半球昼长夜短，为夏至日。
- 步骤 4（d 位置 - 秋分）：高亮地球 d（绿色粗框），显示直射点（赤道），显示赤道标注 (400,230)，显示南极圈标注 (400,370)。文字说明：太阳直射赤道，全球昼夜平分，为秋分日。
- 步骤 5（南北半球季节对比）：所有地球恢复正常显示，在地球 a（冬至）旁显示"北半球冬季/南半球夏季"，在地球 c（夏至）旁显示"北半球夏季/南半球冬季"。强调南北半球季节相反。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮：ID scene1-prev-btn，位置 (250,465)，作用：返回上一个步骤
  - 下一步按钮：ID scene1-next-btn，位置 (460,465)，作用：进入下一个步骤
  - 步骤指示器：ID scene1-step-indicator，位置 (370,468)，显示"步骤 1/6"格式
- 教师操作流程：
  1. 初始显示整体概览，教师介绍地球公转轨道和四个基本位置
  2. 点击"下一步"依次讲解冬至、春分、夏至、秋分的特征
  3. 每个步骤高亮对应地球，显示直射点和相关纬线标注
  4. 最后一步强调南北半球季节相反的概念
  5. 可随时点击"上一步"回退复习

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    地球公转示意图                        │
  │                                                         │
  │           春 (400,50)                                   │
  │              ↑                                          │
  │         ┌────b────┐  北回归线                           │
  │         │ 地球 b  │  北极圈                             │
  │    夏 ←─┤         ├─→ 冬                               │
  │   (100,250)      │  (700,250)                          │
  │         │ 地球 c  │  地球 a                             │
  │    ←───┤         ├─→                                   │
  │         └────d────┘  南回归线                           │
  │              ↓      南极圈                              │
  │           秋 (400,450)                                  │
  │                                                         │
  │              [太阳]                                     │
  │                                                         │
  │  ┌─────────────────────────────────────────────────┐   │
  │  │  ◀上一步    步骤 1/6    下一步▶                  │   │
  │  └─────────────────────────────────────────────────┘   │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：currentStep 变量 (0-5)，控制各元素的显示/隐藏
  2. 坐标计算：使用 SVG 绝对坐标，地球位置基于椭圆轨道参数计算
  3. 动画曲线：元素出现使用 opacity 渐变 (0→1)，高亮框使用 stroke-width 变化
  4. 事件绑定：按钮点击事件更新 currentStep，调用 updateScene() 刷新显示
  5. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-sun、scene1-earth-a、scene1-prev-btn）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 地球昼夜半球绘制：使用 SVG path 绘制半圆，昼半球蓝色填充，夜半球红色半透明填充
  8. 地轴倾斜：使用 SVG line 元素，角度 23.5°，穿过地球中心
  9. 直射点标记：仅步骤 1 和 3 显示，使用 SVG circle 元素
