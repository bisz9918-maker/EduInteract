problem_224_geography_g9

场景导航：Scene 1

题目原文：

下图为某日太阳光照示意图，图中EDF表示晨昏线，且ED为晨线。读图回答问题。

（1）在图上找出夜半球，并用斜线表示其范围。
（2）该图所示的日期在月日前后，太阳直射点的地理坐标：经度，纬度。
（3）图中A、B、C、D四点中，正午太阳高度角相等的是，地方时相等的是，线速度相等的是_。
（4）此时北京时间为_时。
（5）此时D点的太阳高度是，C点的正午太阳高度是。

题目分析：

本题为地球运动章节的经典光照图判读题，考查以下核心知识点：

  1. 晨昏线的判读（晨线/昏线）
  2. 昼夜半球的识别
  3. 节气判断（根据极昼极夜范围）
  4. 太阳直射点坐标的确定
  5. 地方时计算
  6. 正午太阳高度角的比较与计算
  7. 地球自转线速度的分布规律

整体讲解思路：

教师应引导学生按以下步骤分析：

  1. 首先识别图示类型——这是侧视光照图，展示地球某时刻的昼夜分布
  2. 根据"ED为晨线"判断地球自转方向（自西向东），晨线是夜→昼的分界线
  3. 观察北极圈及其以北出现极昼现象，判断为夏至日（6月22日前后）
  4. 太阳直射点位于北回归线（23.5°N），经度为昼半球中央经线（45°E）
  5. 逐题分析各点的位置关系和地理意义

图示规划说明：

本教学图示整合了以下认知步骤：

  • 步骤0：展示基础光照图（含经纬网、晨昏线、各点位置）
  • 步骤1：高亮夜半球范围（斜线填充）
  • 步骤2：标注太阳直射点位置
  • 步骤3：分析A、B、C、D四点的地理关系

通过分步按钮导航，教师可逐步引导学生从直观感知到抽象推理，最终完成全部问题的解答。

步骤 1/4

图示教学说明：

步骤0讲解要点：
教师首先引导学生观察基础图，确认以下信息：

  • 图示类型：侧视光照图，展示地球某时刻的昼夜分布
  • 经纬网：横向为纬线，纵向为经线
  • 晨昏线EDF：将地球分为昼半球和夜半球
  • ED为晨线：说明地球自西向东自转，晨线是夜→昼的分界

步骤1讲解要点：
高亮夜半球后，引导学生判断：

  • 夜半球在晨昏线EDF的左侧（西侧）
  • 北极圈（66.5°N）及其以北出现极昼现象
  • 南极圈（66.5°S）及其以南出现极夜现象
  • 结论：这是夏至日（6月22日前后）

步骤2讲解要点：
标注太阳直射点后，说明：

  • 太阳直射纬度：北回归线（23.5°N），因为北极圈极昼
  • 太阳直射经度：45°E，因为这是昼半球的中央经线（地方时12:00）
  • 太阳直射点坐标：（23.5°N，45°E）

步骤3讲解要点：
对比A、B、C、D四点属性：

  1. 正午太阳高度角相等的是：B和C
  • 正午太阳高度公式：H = 90° - |φ - δ|
  • B点（赤道，0°）：H = 90° - |0° - 23.5°| = 66.5°
  • C点（23.5°N）：H = 90° - |23.5° - 23.5°| = 90°
  • 更正：正午太阳高度相等的是A和C（对称分布）
  • A点（66.5°S）：H = 90° - |66.5° - (-23.5°)| = 90° - 90° = 0°
  • 实际上，B和D关于北回归线对称，正午太阳高度相等
  1. 地方时相等的是：B、C、D
  • 三点都在45°E经线上，地方时相同
  1. 线速度相等的是：无
  • 地球自转线速度随纬度升高而减小
  • 四点纬度不同，线速度均不相等
  • 规律：赤道最大，向两极递减
  1. 北京时间计算：
  • 45°E地方时为12:00
  • 北京时间（120°E）= 12:00 + (120-45)×4分钟 = 12:00 + 5小时 = 17:00
  1. D点太阳高度：
  • D点在晨昏线上，太阳高度为0°
  1. C点正午太阳高度：
  • C点在北回归线上，太阳直射点也在北回归线
  • H = 90° - |23.5° - 23.5°| = 90°

完整解答总结：

（1）夜半球：晨昏线EDF左侧区域，用斜线填充

（2）日期：6月22日前后
太阳直射点坐标：经度45°E，纬度23.5°N

（3）A、B、C、D四点比较：

  • 正午太阳高度角相等的是：B和D（关于北回归线对称）
  • 地方时相等的是：B、C、D（同经度45°E）
  • 线速度相等的是：无（四点纬度不同）

（4）北京时间：17时

（5）D点太阳高度：0°（在晨昏线上）
C点正午太阳高度：90°（太阳直射点所在纬线）

课堂讲解建议：

  1. 使用分步导航时，每步停留约30-60秒，确保学生理解后再进入下一步
  2. 步骤1重点强调"极昼极夜范围判断节气"这一核心方法
  3. 步骤2引导学生理解"昼半球中央经线=太阳直射经线"的逻辑
  4. 步骤3的对比表格可让学生先独立思考，再公布答案
  5. 对于地方时计算，建议补充时区换算的板书演示
  6. 可延伸讨论：若ED为昏线，图示会如何变化？（冬至日情景）
