[分步序列]
- 步骤0（初始状态）：显示经纬网格背景、B点(170°E,20°N)、D点(170°W,20°N)、所有经纬度标签。等待教师点击"下一步"
- 步骤1：显示B到D的完整虚线路径（向北凸起的弧线），路径最高点(400,220)标记。新增经度变化标注"170°E→180°→170°W"
- 步骤2：在路径前半段(225,290)-(300,260)显示"东北"方向箭头及标签。学生可观察路径起始方向
- 步骤3：在路径后半段(500,260)-(575,290)显示"东南"方向箭头及标签。学生可观察路径后半方向
- 步骤4：显示纬度变化标注"20°N→30°N→20°N"在路径最高点附近，以及右侧纬度刻度。总结路径跨越的纬度范围
- 步骤5（结论）：底部显示结论文字"方向变化：先向东北，再向东南"，所有元素高亮显示，帮助学生形成完整认知

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀上一步"按钮：位置(280,460)，作用返回上一步骤
  - "下一步▶"按钮：位置(500,460)，作用进入下一步骤
  - 步骤指示器：位置(380,460)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始展示B、D两点位置，让学生先判断两点经纬度
  2. 点击"下一步"显示虚线路径，引导学生观察路径形状
  3. 点击"下一步"显示"东北"箭头，讲解路径前半段方向
  4. 点击"下一步"显示"东南"箭头，讲解路径后半段方向
  5. 点击"下一步"显示纬度变化，总结方向变化规律
  6. 可点击"上一步"回退复习任意步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    经纬网图示区                          │
  │  40°N ──────────────────────────────────────────────    │
  │         ╱           ╱           ╱                       │
  │  30°N ─╱───────────╱───────────╱──────── 纬度变化       │
  │       ╱    东北→  ╱    ←东南  ╱                         │
  │  20°N─●───────────●───────────●─────── 20°N            │
  │      B           路径         D                         │
  │     170°E       180°        170°W                       │
  │                                                         │
  │  结论：方向变化：先向东北，再向东南                      │
  │          ◀上一步    步骤 3/5    下一步▶                 │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量(0-5)跟踪当前步骤，每一步显示对应元素集合
  2. 坐标计算：经纬线使用 SVG path 绘制弧线，B到D路径使用 quadraticCurveTo 绘制贝塞尔曲线
  3. 动画曲线：元素出现使用 opacity 过渡动画(0.3s ease-in-out)
  4. 事件绑定：按钮点击事件更新 currentStep，调用 updateScene() 刷新显示
  5. ID 命名规范：所有元素 ID 以"scene2-"为前缀（如 scene2-point-B、scene2-path、scene2-arrow-northeast）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 元素显示控制：使用 class="step-X"标记各步骤元素，updateScene() 根据 currentStep 控制 display 属性
