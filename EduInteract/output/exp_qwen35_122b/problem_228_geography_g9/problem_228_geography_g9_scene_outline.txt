    **题目原文：**

    下图中 AO 和 BO 分别为昏线和晨线，阴影所在的经度范围与全球其他地区日期不同。读图回答问题。

    (1) 据图判断，图示日期在北半球二分二至日中的 ______ 日前后，地球上出现极昼现象的地区是 ______。
    (2) B 地地方时是 ______ 点，O 地地方时是 ______ 点。
    (3) A 地经度是________，该日 A 地的夜长约________小时。
    (4) 此时太阳直射点的经度是________，纬度是________。
    (5) 一年中，A 地正午太阳高度最大值与最小值之差是____。

    **题目分析：**

    本题是一道综合性地理题，考查晨昏线判读、日期分界线、地方时计算、太阳直射点确定等核心知识点。

    **关键信息提取：**
    1. AO 为昏线（昼→夜的界线），BO 为晨线（夜→昼的界线）
    2. 阴影区域与全球其他地区日期不同 → 阴影边界为日期分界线（180°经线或 0 时经线）
    3. O 点位于 70°纬线，是晨昏线与纬线的切点
    4. A 点位于 23.5°纬线（回归线），B 点位于赤道

    **解题思路：**
    - 晨昏线交点 O 是晨线与昏线的交点，地方时为 0 时或 12 时
    - 70°纬线出现极昼/极夜现象，说明太阳直射 20°纬线（90°-70°=20°）
    - 阴影区域为日期不同区域，其边界经线一条是 180°经线，另一条是 0 时经线
    - 根据晨昏线分布判断季节和太阳直射点位置

    **图示规划说明：**
    本教案设计 3 个图示场景：
    - Scene 1：晨昏线判读与季节判断（整合晨昏线概念、晨线/昏线区分、极昼范围判断）
    - Scene 2：地方时计算与日期分界线（整合地方时推算、0 时经线确定、日期范围分析）
    - Scene 3：太阳直射点与正午太阳高度（整合直射点坐标计算、正午太阳高度极值差）
    </TEXT_1>

    4. 点击"下一步"引发认知冲突，讲解："如果 B 点是 6:00，O 点在 B 点西侧 45°，则 O 点应为 3:00。但 O 点是晨昏线交点，地方时应为 0:00 或 12:00。这里出现矛盾，说明我们的假设有问题。"

    5. 点击"下一步"重新分析，讲解："关键信息：阴影区域与全球其他地区日期不同。这意味着阴影的边界是日期分界线。日期分界线有两条：180°经线和 0 时经线。O 点地方时为 0:00，所以 O 点所在经线是 0 时经线。"

    6. 点击"下一步"确定经度，讲解："阴影左边界为 180°经线，O 点所在经线为 0 时经线。从图中看，A 点与 180°经线相差 4 格=60°，所以 A 点经度为 120°E。"

    7. 点击"下一步"计算夜长，讲解："A 点位于 23.5°S，该日太阳直射 20°S。A 点昼长可通过晨昏线位置推算。A 点在昏线上，日落时间约为 18:00+ 时差。更简单的方法：A 点纬度 23.5°S，该日接近冬至，南半球昼长夜短。根据对称性，A 点夜长约为 10 小时（昼长 14 小时）。"

    **关键公式：**
    - 地方时差 = 经度差 ÷ 15°/小时
    - 东加西减：东侧地点时间早于西侧
    - 晨线与赤道交点 = 6:00，昏线与赤道交点 = 18:00
    - 0 时经线与 180°经线是两条日期分界线

    **解题答案：**
    - (2) B 地地方时：6:00，O 地地方时：0:00
    - (3) A 地经度：120°E，A 地夜长：约 10 小时

    **Scene 3 教学说明：**

    **引导步骤：**

    1. 首先回顾 Scene 1 的结论："太阳直射 20°S 纬线"

    2. 点击"下一步"显示直射点纬度计算，讲解："O 点是晨昏线与 70°S 的切点，说明 70°S 出现极昼。根据公式：太阳直射点纬度 = 90° - 切点纬度 = 90° - 70° = 20°S"

    3. 点击"下一步"分析直射点经度，讲解："太阳直射点的地方时为 12:00。O 点地方时为 0:00，所以直射点经度与 O 点经度相差 180°。若 O 点经度为 60°E，则直射点经度为 120°W"

    4. 点击"下一步"显示正午太阳高度公式，讲解："正午太阳高度 H = 90° - |当地纬度 φ - 太阳直射点纬度 δ|"

    5. 点击"下一步"计算 A 点夏至日正午太阳高度，讲解："A 点纬度 23.5°S。夏至日太阳直射 23.5°N，H_max = 90° - |23.5°S - 23.5°N| = 90° - 47° = 43°... 等等，这里需要重新考虑。"

    6. 纠正并重新计算，讲解："A 点位于 23.5°S（南回归线）。一年中：
       - 冬至日（太阳直射 23.5°S）：H_max = 90° - |23.5°S - 23.5°S| = 90°
       - 夏至日（太阳直射 23.5°N）：H_min = 90° - |23.5°S - 23.5°N| = 90° - 47° = 43°"

    7. 点击"下一步"显示结论，讲解："A 地正午太阳高度最大值与最小值之差 = 90° - 43° = 47°"

    **关键公式：**
    - 正午太阳高度：H = 90° - |φ - δ|
    - 其中 φ 为当地纬度，δ 为太阳直射点纬度
    - 回归线地区的正午太阳高度年较差 = 47°（2 × 23.5°）

    **解题答案：**
    - (4) 太阳直射点：经度 120°W，纬度 20°S
    - (5) A 地正午太阳高度年较差：47°
