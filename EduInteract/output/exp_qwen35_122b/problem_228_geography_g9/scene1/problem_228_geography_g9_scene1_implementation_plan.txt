- 纬度 0°(730,75) 与 点 B(730,70)：垂直间距 5px → 冲突！解决方案：将点 B 标签移至 (740,60)，向右上方偏移

- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-5) 跟踪当前步骤，每一步对应一组元素的显示/隐藏
  2. 坐标计算：所有元素坐标已在布局坐标表中精确定义，SVG 元素使用绝对坐标
  3. 动画曲线：高亮效果使用 CSS transition (0.3s ease) 实现平滑过渡
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateScene() 刷新显示
  5. ID 命名规范：所有交互元素 ID 以 scene1- 为前缀（如 scene1-ao-line、scene1-bo-line、scene1-o-point、scene1-polar-day、scene1-sun-rays、scene1-conclusion）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 元素显示控制：使用 display 属性或 opacity 控制元素显示/隐藏，高亮状态通过 class 切换实现
