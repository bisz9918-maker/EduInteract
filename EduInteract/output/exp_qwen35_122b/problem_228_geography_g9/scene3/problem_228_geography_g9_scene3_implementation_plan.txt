[图示主题与整合说明]
- 本图示主题：太阳直射点坐标与正午太阳高度计算
- 整合内容：太阳直射点经度确定、太阳直射点纬度确定、A 点正午太阳高度最大值与最小值差计算

[分步序列]
- 步骤0（初始状态）：显示经纬网基础框架，标注A点(23.5°S)、O点(70°S)，显示晨昏线AO和BO，右侧三个信息框为空
- 步骤1：右侧太阳直射点坐标框显示"太阳直射点纬度 = 90° - 70° = 20°S"，太阳光线和直射点标记出现
- 步骤2：坐标框补充"0时经线为O点所在经线，12时经线（直射点经度）与之相差180°"
- 步骤3：坐标框补充"若O点经度为60°E，则直射点经度为120°W"，完整显示直射点坐标(120°W, 20°S)
- 步骤4：公式框显示正午太阳高度公式 H = 90° - |φ - δ|
- 步骤5：计算框显示"A点夏至 H_max = 90° - |23.5°S - 23.5°S| = 90°"
- 步骤6：计算框补充"A点冬至 H_min = 90° - |23.5°S - 23.5°N| = 90° - 47° = 43°"
- 步骤7：计算框高亮显示结论"H_max - H_min = 90° - 43° = 47°"，文字用#c62828加粗

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何和文本显示，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │                        800 × 500 画布                          │
  │  ┌────────────────────┬─────────────────────────────────────┐  │
  │  │                    │  太阳直射点坐标框                    │  │
  │  │   经纬网区域       │  (450,30)-(750,100)                │  │
  │  │   (0,0)-(400,500)  │                                     │  │
  │  │                    │  公式框                             │  │
  │  │   纬线0°           │  (450,150)-(750,240)               │  │
  │  │   纬线23.5°S ←A    │                                     │  │
  │  │   纬线70°S   ←O    │  计算过程框                         │  │
  │  │   晨昏线AO、BO     │  (450,260)-(750,410)               │  │
  │  │                    │                                     │  │
  │  └────────────────────┴─────────────────────────────────────┘  │
  │                                                                │
  │              [◀上一步]              [下一步▶]                  │
  │                    (控件栏 y=440-490)                          │
  └────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  - 使用 SVG 绘制所有几何元素，text 元素用于标签
  - 状态机设计：currentStep 变量记录当前步骤（0-7），updateDisplay() 函数根据 currentStep 控制各元素显示/隐藏
  - 坐标计算：所有元素位置严格按照布局坐标表实现
  - 事件绑定：按钮点击事件触发 stepChange() 函数，更新 currentStep 并调用 updateDisplay()
  - ID 命名规范：所有交互元素 ID 以 scene3- 为前缀（如 scene3-prev-btn、scene3-next-btn、scene3-lat-0、scene3-point-a 等）
  - IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  - 初始状态：步骤0时右侧三个信息框内容为空或显示占位符，点击下一步后逐步填充
