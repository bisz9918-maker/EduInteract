[分步序列]
本场景采用多状态切换交互（2个状态），非分步导航：

- 初始状态（加载后默认显示状态1）：
  - 显示基础装置：烧杯、溶液、Cu电极、Fe电极、接线柱a/b
  - 状态1连接线为实线（a接电源正极，b接电源负极）
  - 状态2连接线为虚线（备用）
  - Cu电极标注"阳极"（红色边框），Fe电极标注"阴极"（绿色边框）
  - Cu电极反应：Cu → Cu²⁺ + 2e⁻（阳极氧化）
  - Fe电极反应：Cu²⁺ + 2e⁻ → Cu（阴极还原）
  - Cu²⁺箭头向左指向Fe电极（蓝色实线）
  - SO₄²⁻箭头向右指向Cu电极（灰色虚线）
  - 按钮1高亮显示（当前状态）

- 状态2（点击按钮2切换）：
  - 连接线反转：状态2连接线变为实线，状态1连接线变为虚线
  - Cu电极标注"阴极"（绿色边框），Fe电极标注"阳极"（红色边框）
  - Cu电极反应：Cu²⁺ + 2e⁻ → Cu（阴极还原）
  - Fe电极反应：Fe → Fe²⁺ + 2e⁻（阳极氧化）
  - Cu²⁺箭头向右指向Cu电极（蓝色实线）
  - SO₄²⁻箭头向左指向Fe电极（灰色虚线）
  - 按钮2高亮显示（当前状态）

[交互方案]
- 交互类型：多状态切换（2个按钮）
- 控件说明：
  - 按钮1（scene2-btn-state1）：位置(280,485)，尺寸120×35px，文本"状态1：a接正"，点击切换至状态1（a接电源正极，b接电源负极）
  - 按钮2（scene2-btn-state2）：位置(460,485)，尺寸120×35px，文本"状态2：b接正"，点击切换至状态2（b接电源正极，a接电源负极）
- 教师操作流程：
  1. 加载图示后默认显示状态1，教师讲解"当a接正极、b接负极时"的电解池工作情况
  2. 指出Cu电极为阳极（红色高亮），发生氧化反应Cu→Cu²⁺+2e⁻
  3. 指出Fe电极为阴极（绿色高亮），发生还原反应Cu²⁺+2e⁻→Cu
  4. 观察Cu²⁺向阴极（Fe电极）移动，SO₄²⁻向阳极（Cu电极）移动
  5. 点击按钮2切换至状态2，讲解连接方式反转后的变化
  6. 对比两种状态下电极极性反转、反应方程式变化、离子移动方向变化
  7. 引导学生判断题目选项B、C的正确性

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形和状态切换，无需复杂库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    直流电源 [+ -]                       │
  │                      ╱        ╲                         │
  │                     ╱          ╲                        │
  │        (a) ○───────╱            ╲───────○ (b)           │
  │           │       ╱              ╲       │              │
  │           │      ╱                ╲      │              │
  │        ┌──┴──┐  ╱                  ╲  ┌──┴──┐          │
  │        │ Cu  │ ╱                    ╲ │ Fe  │          │
  │        │     │╱                      ╲│     │          │
  │    ┌───┴─────┴────────────────────────┴─────┴───┐      │
  │    │              溶液 (Cu²⁺, SO₄²⁻)             │      │
  │    │                                             │      │
  │    │   Cu²⁺ → ← SO₄²⁻  (离子移动箭头)            │      │
  │    │                                             │      │
  │    └─────────────────────────────────────────────┘      │
  │                                                         │
  │  [Cu反应框]                           [Fe反应框]        │
  │  Cu → Cu²⁺+2e⁻                        Cu²⁺+2e⁻→Cu      │
  │                                                         │
  │        [状态1：a接正]        [状态2：b接正]             │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `currentState` 记录当前状态（1或2），切换时更新连接线样式、电极极性标签、反应方程式、离子箭头方向
  2. 坐标计算：所有元素使用绝对坐标，SVG 元素通过 `setAttribute` 动态修改
  3. 动画曲线：连接线切换使用 CSS transition（opacity 0.3s），离子箭头方向改变使用 transform（scaleX(-1)）
  4. 事件绑定：按钮点击事件绑定到 `scene2-btn-state1` 和 `scene2-btn-state2`，切换时调用 `switchState(newState)` 函数
  5. ID 命名规范：所有元素 ID 以 `scene2-` 为前缀（如 `scene2-cu-electrode`, `scene2-fe-electrode`, `scene2-line-state1-1` 等）
  6. IIFE 隔离：所有 JS 代码包裹在 `(function() { ... })()` 中，避免全局变量污染
  7. 连接线切换：通过修改 `stroke-dasharray` 属性实现实线/虚线切换，当前状态为实线（`stroke-dasharray=""`），备用状态为虚线（`stroke-dasharray="5,5"`）
  8. 电极极性标签：通过修改文本内容和边框颜色实现状态切换（阳极=红色#c62828，阴极=绿色#2e7d32）
  9. 离子箭头方向：通过修改箭头终点坐标或应用 `transform="scaleX(-1)"` 实现方向反转
