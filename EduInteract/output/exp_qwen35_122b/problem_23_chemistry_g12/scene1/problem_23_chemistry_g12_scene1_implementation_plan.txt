[分步序列]
- 步骤 0（初始状态）：
  - 显示：标题、两个灰色虚线平面、O1/O2/H1/H2 四个原子、三条化学键（黑色）
  - 隐藏：所有键说明标签、二面角标注、偶极矩箭头
  - 目的：展示 H₂O₂分子的基本骨架结构

- 步骤 1（标注 O-O 非极性键）：
  - 新增：O-O 键标签 "O-O 非极性键" 显示在 (225,270)
  - 变化：O1-O2 键颜色从黑色变为绿色 #2e7d32
  - 显示：二面角弧线
  - 目的：强调 O-O 单键为非极性共价键

- 步骤 2（标注 O-H 极性键）：
  - 新增：O-H 键标签 "O-H 极性键" 显示在 (180,220)
  - 变化：O1-H1 键和 O2-H2 键颜色从黑色变为蓝色 #1565c0
  - 显示：二面角标签 "≈110°" 在 (225,210)
  - 目的：强调 O-H 键为极性共价键，并展示二面角

- 步骤 3（显示分子不对称性）：
  - 新增：偶极矩箭头从 (225,250) 指向 (225,320)，红色 #c62828
  - 新增：偶极矩标签 "μ (偶极矩)" 在 (240,285)
  - 目的：展示分子正负电荷中心不重合，存在净偶极矩

- 结论步骤（步骤 4）：
  - 高亮：所有极性键（蓝色）和非极性键（绿色）同时显示
  - 新增：结论文本框 "结论：H₂O₂分子为极性分子" 在 (200,360)
  - 目的：总结分子极性判断依据

  6. 可随时点击"上一步"回退复习

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：分子结构为几何图形，SVG 适合绘制精确的几何形状和动画，无需额外库依赖
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    H₂O₂分子结构与极性分析               │  y=20
  │                                                         │
  │         ┌───────────────────────────────────┐           │
  │         │      左侧平面 (虚线)   右侧平面    │           │
  │         │         ╱│              ╱│        │           │
  │    H1  ●─O1══════O2─●  H2        │           │           │
  │         │         ╲│              ╲│        │           │
  │         └───────────────────────────────────┘           │
  │                    ↕ μ (偶极矩)                         │
  │                                                         │
  │              [◀上一步]  步骤 X/5  [下一步▶]             │  y=450
  └─────────────────────────────────────────────────────────┘
  ```

- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-4) 跟踪当前步骤
  2. 元素 ID 命名：所有元素以 scene1- 为前缀，如 scene1-o1-atom, scene1-o-o-bond
  3. 颜色切换：通过修改 SVG 元素的 stroke 属性实现键的颜色变化
  4. 元素显示/隐藏：通过修改 display 或 opacity 属性控制
  5. 按钮状态：步骤 0 时禁用"上一步"，步骤 4 时"下一步"改为"完成"
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染

- 坐标计算要点：
  - 分子中心点 (225,250) 作为参考原点
  - O1-O2 键水平放置，便于展示对称性
  - 二面角通过两个平面的透视效果体现（非真实 3D，而是 2D 透视示意）
  - 偶极矩箭头垂直向下，表示正负电荷中心偏移方向

- 动画曲线：键颜色变化使用 CSS transition (0.3s ease)，偶极矩箭头出现使用淡入动画 (opacity 0→1)
