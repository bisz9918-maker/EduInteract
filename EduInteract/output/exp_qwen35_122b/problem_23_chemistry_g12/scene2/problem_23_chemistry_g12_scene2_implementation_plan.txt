[视觉元素清单]
- 晶胞框架：12 条线段（8 条实线#000000 表示可见棱，4 条虚线#888888 表示被遮挡棱）
- A 离子：4 个实心圆（#1565c0 蓝色填充），位于不相邻的 4 个顶点
- B 离子：4 个空心圆（#c62828 红色描边，白色填充），位于另外 4 个不相邻顶点
- 最近邻连线：绿色实线#2e7d32，连接某个 A 离子到其最近邻 B 离子
- 辅助参考线：灰色虚线#888888，晶胞内部对角线（可选）
- 标签：A、B、a（晶胞边长）、图例

[分步序列]

步骤 0（初始状态）：
- 显示：完整的立方体晶胞框架（12 条棱）
- 显示：8 个顶点位置（4 个 A 离子黑点 + 4 个 B 离子白圈，按交替方式排列）
- 显示：图例（A=黑点，B=白圈）
- 显示：标题"晶体 X 的结构单元"
- 不显示：晶胞边长标注、最近邻连线
- 目的：让学生先观察整体结构

步骤 1：
- 新增：高亮显示所有 A 离子位置（4 个蓝色实心圆）
- 新增：在 A 离子旁边标注"A"
- 视觉变化：A 离子从黑点变为蓝色高亮
- 目的：引导学生识别 A 离子的空间分布

步骤 2：
- 新增：高亮显示所有 B 离子位置（4 个红色空心圆）
- 新增：在 B 离子旁边标注"B"
- 视觉变化：B 离子从白圈变为红色高亮
- 目的：引导学生识别 B 离子的空间分布

步骤 3：
- 新增：晶胞边长标注"a"（显示在晶胞内部或某条棱旁边）
- 新增：文字说明"晶胞中 A 离子个数 = 4×1/8 = 0.5"、"晶胞中 B 离子个数 = 4×1/8 = 0.5"
- 显示：化学式推导过程
- 目的：引导学生计算晶胞内离子个数，得出化学式 AB

步骤 4：
- 新增：从某个 A 离子（如前下左顶点 A1）出发，画出到最近邻 B 离子的连线（绿色#2e7d32）
- 新增：高亮显示所有与 A1 距离最近的 B 离子（共 12 个，在完整晶体中）
- 显示：文字说明"配位数 = 12"
- 目的：分析配位关系

结论（最终步骤）：
- 汇总显示：
  - 化学式：AB
  - 配位数：A 的配位数 = 12，B 的配位数 = 12
  - 晶体类型：离子晶体
- 所有元素保持显示状态
- 目的：总结关键结论

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 按钮◀（id: scene2-btn-prev）：位置 (260,450)，点击返回上一步，步骤 0 时禁用
  - 步骤显示（id: scene2-step-display）：位置 (360,455)，显示当前步骤"步骤 X/5"
  - 按钮▶（id: scene2-btn-next）：位置 (460,450)，点击进入下一步，结论步骤时禁用
- 教师操作流程：
  1. 初始展示晶胞结构，让学生观察整体
  2. 点击"下一步"，逐步高亮 A 离子、B 离子
  3. 继续点击，展示化学式计算过程
  4. 最后展示配位数分析
  5. 可随时点击"上一步"回退复习

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    标题：晶体 X 的结构单元                │ (y=40)
  │                                                         │
  │           ┌─────────────────────────────────┐           │
  │           │                                 │           │
  │           │      立方体晶胞（透视）          │           │ (y=80-380)
  │           │      A 离子（蓝）B 离子（红）      │           │
  │           │                                 │           │
  │           └─────────────────────────────────┘           │
  │                                                         │
  │  图例：● A    ○ B                                       │ (y=100-130)
  │                                                         │
  │                                                         │
  │         ┌─────────────────────────────────┐             │
  │         │  ◀上一步   步骤 X/5   下一步▶    │             │ (y=440-490)
  │         └─────────────────────────────────┘             │
  └─────────────────────────────────────────────────────────┘
  ```

- 关键实现要点：
  1. 状态机设计：使用变量 currentStep（0-5）跟踪当前步骤，5 为结论状态
  2. 坐标计算：立方体采用等轴测投影，顶点坐标预先计算好
  3. 动画曲线：元素出现使用 opacity 渐变（0→1，duration=300ms）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后重绘/显示对应元素
  5. ID 命名规范：所有元素 ID 以 scene2- 为前缀（如 scene2-cube-frame、scene2-ion-a1、scene2-btn-next 等）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 元素显示控制：使用 CSS class（如 .step-1、.step-2 等）控制各步骤元素的显示/隐藏
