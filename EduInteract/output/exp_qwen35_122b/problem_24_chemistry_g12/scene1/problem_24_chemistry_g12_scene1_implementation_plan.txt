[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "上一步"按钮：ID=scene1-btn-prev，位置(250,450)，作用：返回上一状态
  - "下一步"按钮：ID=scene1-btn-next，位置(400,450)，作用：进入下一状态
  - 步骤指示器：ID=scene1-step-indicator，位置(320,420)，显示"步骤 1/5"
- 教师操作流程：
  1. 从步骤0开始，先介绍图示主题
  2. 点击"下一步"展示甲容器，讲解恒容容器特点
  3. 点击"下一步"展示乙容器，对比恒压容器（活塞结构）
  4. 点击"下一步"展示丙容器，说明初始物质不同
  5. 点击"下一步"完成对比，引导学生观察三容器异同
  6. 可随时点击"上一步"回退复习某个容器的特征

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    三个容器的初始状态对比                │  y=40
  │                                                         │
  │   ┌──────────┐    ┌──────────┐    ┌──────────┐         │
  │   │0.2 mol   │    │  ┌────┐  │    │0.1 mol   │         │
  │   │NO₂       │    │  │活塞│  │    │N₂O₄      │         │ y=100-250
  │   └──────────┘    │  └────┘  │    └──────────┘         │
  │      甲              乙            丙                    │  y=280
  │    恒容            恒压          恒容                    │  y=300
  │                                                         │
  │   ┌───────────────────────────────────────────────┐     │
  │   │        初始容积相等、温度相同                  │     │  y=350-390
  │   └───────────────────────────────────────────────┘     │
  │                                                         │
  │              [步骤 1/5]  [◀上一步] [下一步▶]             │  y=420-490
  └─────────────────────────────────────────────────────────┘
  ```

- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-4) 跟踪当前步骤
  2. 元素显示控制：每个 SVG 元素设置 data-step 属性，根据 currentStep 控制 display 属性
  3. 高亮效果：使用 CSS class 切换高亮颜色（blue-highlight/red-highlight/green-highlight）
  4. 按钮状态：步骤0禁用"上一步"，步骤4禁用"下一步"
  5. 坐标计算：所有元素使用绝对坐标，确保精确对齐
  6. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-container-a、scene1-label-a、scene1-btn-prev 等）
  7. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染

- SVG 元素 ID 命名示例：
  - 容器：scene1-container-a、scene1-container-b、scene1-container-c
  - 活塞：scene1-piston
  - 内容文字：scene1-text-a、scene1-text-b、scene1-text-c
  - 标签：scene1-label-a、scene1-label-b、scene1-label-c
  - 类型标签：scene1-type-a、scene1-type-b、scene1-type-c
  - 控件：scene1-btn-prev、scene1-btn-next、scene1-step-indicator
