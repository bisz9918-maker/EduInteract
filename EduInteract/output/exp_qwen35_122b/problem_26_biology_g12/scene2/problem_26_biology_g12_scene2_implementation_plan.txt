[图示主题与整合说明]
- 本图示主题：F₂表型比例与基因型对应关系分析
- 整合内容：9:3:4比例的遗传学解释、基因型与表型的对应、伴性遗传特征

[分步序列]
- 步骤 0（初始状态）：
  - 显示：标题、棋盘格（仅边框，无填充色）、图例区（仅文字，无色块）、基因型表（仅文字）、比例统计区（仅框架）
  - 目的：展示基础框架，等待教师开始讲解

- 步骤 1：展开 9:3:4 = 9:3:3:1 的变形
  - 视觉变化：棋盘格填充颜色（9 蓝、3 红、4 绿），图例区显示彩色方块，比例柱状图显示三柱
  - 新增元素：棋盘格填充色、图例色块、柱状图
  - 标签显示：各柱上方显示"9/16"、"3/16"、"4/16"
  - 目的：从 F₂表型比例现象入手，说明这是两对基因控制的 9:3:3:1 变形

- 步骤 2：标注基因位置
  - 视觉变化：染色体示意图高亮显示，常染色体标注"A/a"，X 染色体标注"B/b"
  - 新增元素：染色体标签、基因符号
  - 高亮：用虚线框将棋盘格按基因型分组（A/a 分组、B/b 分组）
  - 目的：说明一对基因在常染色体，一对在 X 染色体（伴性遗传）

- 步骤 3：展示基因型与表型对应关系
  - 视觉变化：基因型表逐行高亮显示
  - 行 1 高亮：A_X^B_ → 长翅（蓝色）
  - 行 2 高亮：A_X^bY → 小翅（红色）
  - 行 3 高亮：aa__ → 残翅（绿色）
  - 目的：明确基因型与表型的对应规则

- 步骤 4：高亮伴性遗传特征
  - 视觉变化：棋盘格中仅雄性的格子（Y 染色体相关）用特殊边框高亮
  - 新增元素：性别符号标注（♀/♂）在棋盘格边缘
  - 高亮：小翅基因型 A_X^bY 仅出现在雄性，用红色粗边框圈出
  - 目的：强调伴性遗传特征——小翅仅出现在雄性个体

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（矩形、线段、文本），无需复杂图表库；原生实现轻量、可控
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │                        标题区 (300,15)                         │
  │                                                                │
  │  染色体示意图              │              图例区               │
  │  (50,50)-(250,130)         │      (420,50)-(750,150)          │
  │  常染色体  X 染色体         │      长翅■  小翅■  残翅■         │
  │                            │                                  │
  │  棋盘格区域                 │      基因型 - 表型对应表          │
  │  (50,160)-(370,400)        │      (420,180)-(750,310)         │
  │  4×4 网格 9 蓝 3 红 4 绿       │      A_X^B_→长翅               │
  │                            │      A_X^bY→小翅(♂)             │
  │                            │      aa__→残翅                   │
  │                            │                                  │
  │                            │      比例统计柱状图               │
  │                            │      (420,320)-(750,400)         │

  │              控件栏 (250,440)-(550,490)                        │
  │              [◀上一步]  步骤 1/5  [下一步▶]                     │
  └────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-4) 跟踪当前步骤，updateScene() 函数根据 currentStep 更新显示
  2. 坐标计算：所有元素坐标硬编码在配置对象中，便于维护和修改
  3. 动画曲线：使用 CSS transition 实现平滑过渡（fill-opacity、stroke-width）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateScene()
  5. 颜色管理：用 CSS class 控制颜色（scene2-long-wing、scene2-small-wing、scene2-vestigial）
  6. 高亮效果：用 stroke 和 stroke-width 实现高亮边框
- ID 命名规范：所有交互元素 ID 以 scene2- 为前缀
  - 棋盘格单元格：scene2-cell-{row}-{col}
  - 染色体元素：scene2-chrom-const、scene2-chrom-x
  - 图例元素：scene2-legend-long、scene2-legend-small、scene2-legend-vestigial
  - 基因型表行：scene2-genotype-row-1、scene2-genotype-row-2、scene2-genotype-row-3
  - 柱状图：scene2-bar-long、scene2-bar-small、scene2-bar-vestigial
  - 按钮：scene2-prev-btn、scene2-next-btn
  - 步骤指示器：scene2-step-indicator
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局污染
