[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 按钮"◀上一步"：位置(300,460)，作用：返回上一状态，第一步时禁用
  - 按钮"下一步▶"：位置(500,460)，作用：进入下一状态，最后一步时变为"完成"
- 教师操作流程：
  1. 初始展示反交实验定义和与正交的对比
  2. 点击"下一步"展示反交亲本选择（小翅♀×残翅♂）
  3. 点击"下一步"展示F₁表型和基因型预测
  4. 点击"下一步"展示F₂预测比例柱状图
  5. 教师可点击"上一步"回退复习关键步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何和文本，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │                        反交实验设计与预测                       │  y=20
  │                                                                │
  │  ┌──────────────┐         ┌────────────────────┐              │
  │  │   小翅♀      │  ───→   │      F₁代          │   ┌──────────┐
  │  │  AAX^bX^b    │         │  ♀长翅  ♂小翅      │   │ 与正交   │
  │  └──────────────┘         └────────────────────┘   │  对比    │
  │                        ↓                           │          │
  │  ┌──────────────────────────────────────────────┐   │          │
  │  │              F₂表型比例                       │   │          │
  │  │    ████   ███   ████                         │   │          │
  │  │   长翅   小翅   残翅                         │   │          │
  │  │   9/16   3/16   4/16                         │   │          │
  │  └──────────────────────────────────────────────┘   │          │
  │                                                     └──────────┘
  │                    [◀上一步]  [下一步▶]              │  y=460
  └────────────────────────────────────────────────────────────────┘
  ```

- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-4) 跟踪当前步骤
  2. 元素分组：每个步骤的元素用<g id="scene3-stepN">分组，通过 display 控制显示/隐藏
  3. 坐标计算：所有元素按布局坐标表精确放置
  4. 动画曲线：步骤切换使用 opacity 淡入效果（0→1，duration 300ms）
  5. 事件绑定：按钮点击事件监听，更新 currentStep 并刷新显示
  6. MathJax 集成：用于渲染基因型中的上标（X^B、X^b）

- ID 命名规范：所有交互元素 ID 以 scene3- 为前缀
  - 步骤组：scene3-step0, scene3-step1, scene3-step2, scene3-step3, scene3-step4
  - 按钮：scene3-btn-prev, scene3-btn-next
  - 元素：scene3-parent-female, scene3-parent-male, scene3-f1-female, scene3-f1-male, scene3-bar-long, scene3-bar-small, scene3-bar-vestigial

- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局污染
