[图示主题与整合说明]
- 本图示主题：染色体变异机制与细胞分裂图像分析

  3. 点击下一步，显示变异类型结论

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形（染色体、细胞）用 SVG 绘制清晰且易于动画控制；无需复杂图表库；原生 JS 足够实现分步状态切换
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │                    染色体变异与细胞分裂分析                     │  y=15

  │   [X]    [Y]        移接箭头                    [X1]   [X2*]   │
  │                                                              │
  │              ┌────────────────────────────────┐               │  y=200
  ```

- 关键实现要点：
  1. 状态机设计：用 currentStep 变量（0-5）跟踪当前步骤，每一步定义 showElements 和 hideElements 数组
  2. 坐标计算：所有元素使用绝对坐标，SVG 元素通过 x/y/cx/cy 属性精确定位
  3. 动画曲线：移接片段闪烁用 CSS animation（keyframes 控制 opacity 0.3-1 循环）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateScene() 刷新显示
  5. ID 命名规范：所有元素 ID 以 scene2- 为前缀（如 scene2-chr-x-normal、scene2-chr-x2-mutant、scene2-cell-outline 等）
  6. JS 隔离：所有代码包在 (function() { ... })() IIFE 中，避免全局污染
  7. 结论框显示控制：用 display:none/block 控制，配合 CSS transition 实现淡入效果
  8. 染色体绘制：用 path 元素绘制 X 形和 Y 形染色体，包含姐妹染色单体结构
