[分步序列]
- 初始状态（步骤0）：
  - 显示原始DNA双链（a链和b链，黑色）
  - 显示碱基配对虚线
  - 显示5'/3'方向标签
  - 显示引物Ⅰ（蓝色，已给出）
  - 引物Ⅱ位置显示虚线框和"？"提示
  - 阶段标题："步骤0：原始DNA模板"
  - 右侧阶段指示器：阶段1高亮

- 步骤1：点击「下一步」→ 95°C变性阶段
  - 阶段标题："步骤1：95°C 变性"
  - a链和b链分离，b链向下移动20px
  - 碱基配对虚线消失
  - 95°C温度框高亮（黄色边框）
  - 右侧阶段指示器：阶段1保持高亮
  - 引物Ⅱ虚线框仍显示"？"

- 步骤2：点击「下一步」→ 55°C复性阶段
  - 阶段标题："步骤2：55°C 复性"
  - 引物Ⅱ实线显示（补全序列：3'-C-C-...-A-G-5'）
  - 引物Ⅰ和引物Ⅱ分别结合到对应模板链
  - 引物Ⅰ位置：(580,190)-(650,190)与b链配对
  - 引物Ⅱ位置：(150,90)-(220,90)与a链配对
  - 55°C温度框高亮
  - 右侧阶段指示器：阶段2高亮

- 步骤3：点击「下一步」→ 72°C延伸阶段
  - 阶段标题："步骤3：72°C 延伸"
  - DNA聚合酶图标显示在引物3'端附近
  - 新合成链从引物3'端开始延伸（绿色）
  - 新链1：从引物Ⅱ的3'端向右延伸，与a链互补
  - 新链2：从引物Ⅰ的3'端向左延伸，与b链互补
  - 72°C温度框高亮
  - 右侧阶段指示器：阶段3高亮

- 步骤4（完成）：点击「完成」→ 循环一次后的DNA分子
  - 阶段标题："完成：循环一次后的两个DNA分子"
  - 显示两个完整的DNA双链分子
  - 左侧DNA：a链（原始）+ 新合成链2（绿色）
  - 右侧DNA：b链（原始）+ 新合成链1（绿色）
  - 所有温度框恢复原色
  - 右侧阶段指示器：完成指示高亮
  - 标注：每个DNA分子含一条原始链和一条新链（半保留复制）

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶/完成）
- 控件说明：
  - 「◀ 上一步」按钮：位于(220,450)，回退到上一阶段，用于复习
  - 「下一步 ▶」按钮：位于(350,450)，进入下一阶段，推动讲解进程
  - 「完成」按钮：位于(480,450)，直接跳到最终状态，展示完整结果
- 教师操作流程：
  1. 初始展示原始DNA模板，讲解PCR的前提条件
  2. 点击「下一步」进入变性阶段，讲解高温使双链解开的原理
  3. 点击「下一步」进入复性阶段，讲解引物结合的特异性
  4. 点击「下一步」进入延伸阶段，讲解DNA聚合酶的作用
  5. 点击「完成」展示循环结果，讲解半保留复制特点
  6. 可随时点击「上一步」回退复习某个阶段

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（线段、矩形、文本），无需复杂绘图库；原生实现性能好、代码轻量
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │                    步骤X：阶段标题 (y=25)                       │
  │                                                                │
  │  ┌────┐                                                       │
  │  │95°C│  a链 ────────────────────────────── 5'→3'              │
  │  └────┘  ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─                       │
  │  ↓      b链 ────────────────────────────── 3'→5'              │
  │  ┌────┐                                                       │
  │  │55°C│  引物Ⅱ ────                    引物Ⅰ ────              │
  │  └────┘                                                       │
  │  ↓                                                            │
  │  ┌────┐                                                       │
  │  │72°C│  新合成链（绿色）                                      │
  │  └────┘                                                       │
  │                                                                │
  │  [◀上一步]  [下一步▶]  [完成]    │ 阶段1│阶段2│阶段3│完成│      │
  └────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量（0-4）跟踪当前步骤，每个步骤对应不同的元素可见性
  2. 坐标计算：所有元素使用绝对坐标，通过 CSS transform 或 SVG 属性控制位置变化
  3. 动画曲线：使用 CSS transition 实现平滑过渡（0.3s ease-in-out）
  4. 事件绑定：按钮点击事件触发 stepChange() 函数，更新 currentStep 并刷新视图
  5. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-dna-a、scene1-btn-next）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 元素可见性控制：通过 class 添加/移除 'visible' 或 'hidden' 类控制显示
  8. 温度框高亮：通过添加 'highlight' 类改变边框颜色
  9. 阶段指示器：通过 'active' 类高亮当前阶段
