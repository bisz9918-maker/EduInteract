[图示主题与整合说明]
- 本图示主题：小车下滑实验装置与能量转化过程
- 整合的内容：实验装置展示、小车下滑三位置能量状态对比、能量转化关系说明
- 教学价值：教师可通过分步动画展示小车从斜面顶端滑到底端的全过程，直观呈现重力势能逐渐转化为动能的过程，帮助学生理解机械能守恒（不计摩擦时）或机械能损失（有摩擦时）的概念。配合选项 D 的讨论，可进一步引出牛顿第一定律（惯性定律）。

[分步序列]
- 步骤 0（初始状态）：
  - 显示：斜面、水平木板、小车（在斜面顶端位置 (120,160)）、木块（在 (450,240)）、高度标记线、h 标签、小车标签、木块标签、木板标签
  - 不显示：Ep 箭头、Ek 箭头、能量说明文本
  - 小车状态：静止（无运动箭头）
  - 按钮状态：上一步 disabled，下一步 enabled

- 步骤 1（小车下滑至斜面中部）：
  - 小车位置：移动到 (180,220)
  - 新增显示：Ep 箭头（红色，从 (100,180) 到 (100,240)，箭头向下，表示 Ep 减小）、Ek 箭头（蓝色，从 (140,200) 到 (200,200)，箭头向右，表示 Ek 增大）
  - Ep 箭头长度：60px（中等长度，表示 Ep 中等）
  - Ek 箭头长度：60px（中等长度，表示 Ek 中等）
  - 按钮状态：上一步 enabled，下一步 enabled

- 步骤 2（小车到达斜面底端即将撞击）：
  - 小车位置：移动到 (260,270)
  - Ep 箭头长度：20px（短，表示 Ep 接近 0）
  - Ek 箭头长度：100px（长，表示 Ek 最大）
  - 新增显示：能量说明文本"Ep↓ Ek↑ 重力势能转化为动能"，坐标 (550,150)
  - 按钮状态：上一步 enabled，下一步 disabled

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮（scene1-prev）：位于控件栏左侧，点击后返回上一状态，步骤 0 时禁用
  - 下一步按钮（scene1-next）：位于控件栏右侧，点击后进入下一状态，步骤 2 时禁用
- 教师操作流程：
  1. 初始展示实验装置，讲解小车在斜面顶端具有最大重力势能
  2. 点击"下一步"，小车下滑至中部，展示 Ep 减小、Ek 增大的箭头，讲解能量转化
  3. 再次点击"下一步"，小车到达底端，Ep 最小、Ek 最大，总结能量转化规律
  4. 可点击"上一步"回退复习，强化学生对能量转化过程的理解

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何动画，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │                           图示区 800×500                        │
  │                                                                │
  │    小车                                                         │
  │      ▲                                                         │
  │     ╱│                                                         │
  │    ╱ h │                                                         │
  │   ╱  ▼                                                         │
  │  ╱───────────────────────────────────────────────────────      │
  │ ╱斜面                    木块              木板                │
  │ ═══════════════════════════════════════════════════════════    │
  │                                                                │
  │                                                                │
  │                                                                │
  │                   [◀上一步]        [下一步▶]                   │
  │                   (控件栏 y=440~490)                           │
  └────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep 记录当前步骤（0/1/2），根据步骤更新小车位置、箭头长度、显示/隐藏元素
  2. 坐标计算：小车位置用数组存储 [{x:120,y:160}, {x:180,y:220}, {x:260,y:270}]，根据 currentStep 索引获取
  3. 箭头长度：Ep 箭头长度 = [0, 60, 20][currentStep]，Ek 箭头长度 = [0, 60, 100][currentStep]
  4. 动画曲线：小车移动使用 SMIL 动画或 requestAnimationFrame 实现平滑过渡（可选）
  5. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 render() 函数重绘
  6. ID 命名规范：所有元素 ID 以 scene1- 为前缀，如 scene1-cart、scene1-block、scene1-ep-arrow、scene1-ek-arrow、scene1-prev、scene1-next
  7. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
