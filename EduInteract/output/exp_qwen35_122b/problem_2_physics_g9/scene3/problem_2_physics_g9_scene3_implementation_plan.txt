[图示主题与整合说明]
- 本图示主题：光滑木板条件下木块的运动状态对比
- 整合的内容：普通木板与光滑木板对比、木块撞击后的运动状态、动能变化分析
- 教学价值：教师可通过分步演示，帮助学生理解摩擦力对物体运动的影响，以及牛顿第一定律（惯性定律）的实际应用。通过对比普通木板和光滑木板两种情况，学生能直观理解"若表面光滑，木块将保持匀速直线运动"的物理概念。

[分步序列]
- 步骤0（初始状态）：
  - 显示：斜面、水平木板、小车（初始位置在斜面顶部）、木块（静止在木板中央）
  - 不显示：速度矢量、摩擦力、动能指示条、表面状态标记
  - 状态：木块静止，v=0，E_k=0

- 步骤1（撞击瞬间）：
  - 显示：斜面、水平木板、小车（移动至斜面底部）、木块（即将被撞击）
  - 不显示：速度矢量、摩擦力、动能指示条、表面状态标记
  - 状态：小车撞击木块瞬间，木块即将获得速度

- 步骤2（普通木板）：
  - 显示：斜面、水平木板、小车（停在斜面底部）、木块（向右运动）、速度矢量v（中等长度）、摩擦力f（红色波浪线）、动能指示条E_k（中等长度，逐渐缩短）、表面状态标记"普通"
  - 状态：木块在普通木板上减速运动，摩擦力做负功，动能逐渐减小

- 步骤3（光滑木板）：
  - 显示：斜面、水平木板、小车（停在斜面底部）、木块（向右匀速运动）、速度矢量v（较长，保持不变）、无摩擦力f、动能指示条E_k（较长，保持不变）、表面状态标记"光滑"
  - 状态：木块在光滑木板上匀速直线运动，无摩擦力，动能保持不变

- 结论（可选步骤4）：
  - 显示：步骤3的所有元素 + 结论文本框（位于底部控件区上方）
  - 结论文本："若木板表面光滑且足够长，木块将保持匀速直线运动，动能不变。故选D正确。"

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 按钮"◀上一步"：位置(280,450)，作用：返回上一步骤
  - 按钮"下一步▶"：位置(520,450)，作用：进入下一步骤
  - 文本显示"步骤 X/4"：位置(380,450)，作用：显示当前步骤
- 教师操作流程：
  1. 点击"下一步▶"从步骤0到步骤1，讲解小车下滑过程
  2. 点击"下一步▶"从步骤1到步骤2，讲解普通木板上的减速运动
  3. 点击"下一步▶"从步骤2到步骤3，对比讲解光滑木板上的匀速运动
  4. 引导学生分析选项，得出D正确的结论

- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）

- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-4) 跟踪当前步骤
  2. 坐标计算：所有元素使用绝对定位，通过 CSS transform 或 SVG 属性控制显示/隐藏
  3. 动画曲线：步骤2→3切换时，速度矢量长度和动能条长度使用 CSS transition 平滑过渡
  4. 事件绑定：按钮点击事件更新 currentStep，调用 renderStep() 函数重绘
  5. ID 命名规范：所有元素 ID 以 scene3- 为前缀（如 scene3-cart-initial、scene3-block、scene3-velocity-arrow）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 摩擦力波浪线：使用 SVG path 绘制正弦波曲线
  8. 动能指示条：宽度根据步骤动态变化（步骤2：60px，步骤3：100px）
