[图示主题与整合说明]
- 本图示主题：体心立方晶胞（BCC）的配位数分析
- 整合的步骤/概念：整合体心立方晶胞的完整结构展示、中心原子最近邻原子识别、配位数计算三个步骤

[分步序列]
- 初始状态（步骤 0）：
  - 显示：立方体框架（12 条棱边）、8 个顶点原子、体心原子
  - 标签：所有"Fe"标签、"Fe（中心）"标签、3 个"a"标签
  - 隐藏：体心 - 顶点连接线、"配位数 = 8"标签
  - 无高亮

- 步骤 1：点击「下一步」→
  - 视觉变化：体心原子填充色变为 #1565c0（蓝色高亮）
  - 新增：无
  - 目的：突出分析对象——体心原子

- 步骤 2：点击「下一步」→
  - 视觉变化：8 条体心 - 顶点连接线显示（灰色虚线）
  - 视觉变化：8 个顶点原子依次高亮为 #c62828（红色），每 0.3 秒高亮一个，形成动画效果
  - 目的：展示体心原子与 8 个顶点原子的最近邻关系

- 步骤 3：点击「下一步」→
  - 视觉变化：在图示下方显示"配位数 = 8"标签（字体加粗，颜色 #000000）
  - 所有高亮保持（体心原子蓝色，8 个顶点原子红色）
  - 目的：得出结论——体心立方晶胞的配位数为 8

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 按钮"◀上一步"：位于控件栏左侧 (220, 450)，点击返回上一步，步骤 0 时禁用（灰色）
  - 按钮"下一步▶"：位于控件栏右侧 (460, 450)，点击进入下一步，步骤 3 时禁用（灰色）
- 教师操作流程：
  1. 初始展示完整 BCC 晶胞结构，让学生观察立方体框架和原子位置
  2. 点击「下一步」，体心原子变蓝高亮，引导学生关注分析对象
  3. 点击「下一步」，8 条虚线连接体心与顶点，顶点原子依次变红高亮，展示最近邻关系
  4. 点击「下一步」，显示"配位数 = 8"结论，完成认知链条
  5. 可随时点击「上一步」回退复习，巩固空间想象能力

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript
  - 理由：几何图形（立方体、圆、线段）用 SVG 绘制最清晰，动画用 CSS transition 或 requestAnimationFrame 实现，无需额外库
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：

- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-3) 记录当前步骤，updateScene() 函数根据 currentStep 控制元素显示/隐藏/高亮
  2. 坐标计算：立方体采用斜二测投影，前表面为矩形 (300,180)-(500,320)，后表面向右上方偏移 (60,-40)
  3. 动画曲线：顶点原子高亮用 requestAnimationFrame 实现 0.3 秒间隔的依次高亮
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateScene()
  5. 禁用状态：步骤 0 时"◀上一步"禁用，步骤 3 时"下一步▶"禁用
- ID 命名规范：所有交互元素 ID 以 scene1- 为前缀，如 scene1-cube-edge-1、scene1-atom-vertex-1、scene1-atom-center、scene1-line-connect-1、scene1-label-coordination、scene1-btn-prev、scene1-btn-next
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
