- 关键实现要点：
  1. 状态机设计：使用变量 currentStep（0-3）跟踪当前步骤，updateScene() 函数根据 currentStep 显示/隐藏相应元素
  2. 坐标计算：预先计算 3D 立方体各顶点的 2D 投影坐标，存储在常量数组中
  3. 动画曲线：使用 CSS transition 实现平滑的高亮切换（opacity、fill、stroke 属性）
  4. 事件绑定：按钮点击事件调用 changeStep(delta) 函数，更新 currentStep 并刷新视图
  5. 元素显示控制：使用 display: none/block 或 opacity 控制各步骤元素的可见性

- ID 命名规范：
  - 所有交互元素 ID 以 scene2- 为前缀
  - 示例：scene2-cube-edge-1, scene2-vertex-atom-0, scene2-face-atom-0, scene2-prev-btn, scene2-next-btn, scene2-step-label

- IIFE 隔离：
  ```javascript
  (function() {
      // 所有 Scene 2 的 JS 代码
      const currentStep = 0;
      const maxStep = 3;
      
      function updateScene() {
          // 根据 currentStep 更新视图
      }
      
      function changeStep(delta) {
          currentStep += delta;
          if (currentStep < 0) currentStep = 0;
          if (currentStep > maxStep) currentStep = maxStep;
          updateScene();
      }
      
      // 初始化
      document.addEventListener('DOMContentLoaded', function() {
          updateScene();
          document.getElementById('scene2-prev-btn').addEventListener('click', function() {
              changeStep(-1);
          });
          document.getElementById('scene2-next-btn').addEventListener('click', function() {
              changeStep(1);
          });
      });
  })();
  ```
