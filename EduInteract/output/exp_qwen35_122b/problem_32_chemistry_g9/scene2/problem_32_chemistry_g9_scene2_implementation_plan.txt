[图示主题与整合说明]
- 本图示主题：氨气溶解导致压强变化与酚酞变色（问题 32 第 2 问）
- 整合的步骤/概念：初始状态 → 挤入水滴 → 氨气溶解 → 压强降低 → 水倒吸 → 酚酞变色
- 教学价值：教师可通过分步演示，帮助学生理解气体溶解导致压强变化的连锁反应，以及氨水呈碱性的性质。图示清晰展示"分子减少→压强降低→水倒吸→酚酞变色"的因果关系链。

[分步序列]
- 步骤 0（初始状态）：
  - 显示：B 瓶（内含 12 个 NH₃分子）、胶头滴管、导管、活塞 a 和 b（红色关闭状态）、烧杯（内有无色水+酚酞）
  - 标签："B"（B 瓶右上方 (580,130)）、"NH₃"（B 瓶内顶部 (550,110)）、"a"（活塞 a 右侧 (565,248)）、"b"（活塞 b 下方 (400,315)）、"水 + 酚酞"（烧杯右侧 (450,440)）
  - 状态：等待教师点击"下一步"

- 步骤 1（挤入水滴）：
  - 视觉变化：胶头滴管高亮（黄色闪烁），一滴水从滴管滴入 B 瓶（动画：小圆从 (550,80) 移动到 (550,150)）
  - 新增标签："挤入水滴"（胶头滴管左侧 (510,100)）
  - 其他元素保持不变

- 步骤 2（氨气溶解）：
  - 视觉变化：B 瓶内 NH₃分子从 12 个减少到 4 个（8 个分子淡出消失）
  - 保留分子坐标：(550,130),(530,160),(570,160),(550,180)
  - 新增标签："NH₃溶解"（B 瓶左侧 (470,150)）

- 步骤 3（压强降低）：
  - 视觉变化：B 瓶内显示"压强降低"标识（红色向下箭头 + 文字）
  - 标识位置：B 瓶内中部 (550,170)，红色#c62828
  - 新增标签："压强降低"（B 瓶右下方 (600,180)）

- 步骤 4（水倒吸）：
  - 视觉变化：活塞 a 和 b 变为绿色（打开状态），蓝色水流箭头从烧杯向上流向 B 瓶
  - 水流路径：(400,380)→(400,300)→(550,300)→(550,230)
  - 新增标签："倒吸"（导管左侧 (370,340)）

- 步骤 5（颜色变化）：
  - 视觉变化：烧杯内液体保持无色，进入 B 瓶的水变为红色（显示在 B 瓶底部）
  - B 瓶内红色液体：矩形 (510,200)-(590,210)，红色#c62828 透明度 30%
  - 新增标签："碱性→红色"（B 瓶内液体上方 (550,190)）
  - 最终状态：展示完整现象，教师可点击"上一步"复习

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "上一步"按钮：位于 SVG 底部左侧 (100,460)，宽 80px，高 30px，作用：回退到上一状态
  - "下一步"按钮：位于 SVG 底部右侧 (620,460)，宽 80px，高 30px，作用：前进到下一状态
  - 步骤指示器：位于 SVG 底部中央 (350,465)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始展示装置全貌，讲解问题背景
  2. 点击"下一步"→ 演示挤入水滴操作
  3. 点击"下一步"→ 展示氨气溶解，分子减少
  4. 点击"下一步"→ 显示压强降低
  5. 点击"下一步"→ 演示水倒吸现象
  6. 点击"下一步"→ 展示酚酞变色，总结结论
  7. 可随时点击"上一步"回退复习关键步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何动画，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    [胶头滴管]                           │
  │                         │                               │
  │              ┌──────────┴──────────┐                    │
  │              │      B 瓶 (NH₃)      │                    │
  │              │   ●●●●●●●●●●●●     │                    │
  │              └──────────┬──────────┘                    │
  │                         │ [活塞 a]                       │
  │                         │                               │
  │              ┌──────────┴──────────┐                    │
  │              │      导管            │                    │
  │              │      [活塞 b]        │                    │
  │              └──────────┬──────────┘                    │
  │                         │                               │
  │              ┌──────────┴──────────┐                    │
  │              │    烧杯 (水 + 酚酞)   │                    │
  │              └─────────────────────┘                    │
  │                                                         │
  │  [◀上一步]        步骤 X/5         [下一步▶]            │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-5) 跟踪当前步骤，updateScene() 函数根据 currentStep 显示/隐藏元素
  2. 坐标计算：所有元素使用绝对坐标，NH₃分子坐标预先定义在数组中
  3. 动画曲线：水滴下落用 requestAnimationFrame 实现缓动动画，水流用 CSS transition
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateScene()
  5. ID 命名规范：所有元素 ID 以"scene2-"为前缀（如 scene2-bottle、scene2-molecule-1、scene2-btn-next）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 元素显示控制：用 display:none/block 或 opacity 控制元素显示/隐藏
  8. 颜色渐变：酚酞变色用 CSS transition 实现颜色平滑过渡
