[图示主题与整合说明]
- 本图示主题：长方形剪去正方形后的周长计算
- 整合内容：原长方形展示 → 剪去位置标注 → 最终凹字形图形 → 周长计算标注（四步整合）
- 教学价值：教师可通过分步演示，引导学生理解"剪去正方形后周长变化"的核心概念——原长方形周长 20cm，剪去后新增两条边，周长变为 22cm

[分步序列]
- 步骤 0（初始状态）：
  - 显示：原长方形轮廓（黑色实线）
  - 标签：左边"4"、下边"6"
  - 目的：展示题目初始条件

- 步骤 1：
  - 显示：原长方形 + 剪去正方形虚线框（右侧中间）+ 剪去区域浅灰填充
  - 新增标签：虚线框右边"2"（表示剪去正方形边长）
  - 高亮：虚线框用红色 #c62828 表示将被移除
  - 目的：明确剪去位置和大小

- 步骤 2：
  - 显示：凹字形图形（实线轮廓），虚线框和填充消失
  - 新增标签：上边"6"、凹口竖边"2"、凹口上横边"2"、凹口下横边"2"、右上竖边"1"、右下竖边"1"
  - 高亮：新增的两条竖边（凹口左右）用蓝色 #1565c0 高亮
  - 目的：展示剪去后的最终图形

- 步骤 3（最终状态）：
  - 显示：凹字形图形 + 所有边长标签 + 周长计算式
  - 新增：底部显示"周长 = 4+6+6+2+2+2+1+1 = 24 厘米"
  - 高亮：周长结果"24"用绿色 #2e7d32 加粗显示
  - 目的：展示周长计算过程和结果

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于 (250,455)，步骤 1-3 时可用，步骤 0 时禁用（灰色）
  - 「下一步 ▶」按钮：位于 (450,455)，步骤 0-2 时可用，步骤 3 时禁用（灰色）
- 教师操作流程：
  1. 初始展示原长方形，提问"这个长方形的周长是多少？"
  2. 点击"下一步"，展示剪去位置，提问"剪去的是多大的正方形？"
  3. 点击"下一步"，展示最终图形，提问"剪去后周长变大了还是变小了？"
  4. 点击"下一步"，展示计算式，引导学生理解"新增两条边，周长增加 4cm"

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    图示区 800×500                       │
  │                                                         │
  │         ┌─────────────────────────────────┐            │
  │         │                                 │            │
  │    4    │         原长方形/凹字形          │    2       │
  │    ←    │         (250,150)-(550,350)     │    →       │
  │         │                                 │            │
  │         └─────────────────────────────────┘            │
  │                    6                                   │
  │                                                         │
  │         周长 = 4+6+6+2+2+2+1+1 = 24 厘米               │
  │                                                         │
  │         ┌─────────┐         ┌─────────┐               │
  │         │◀ 上一步 │         │下一步 ▶ │               │
  │         └─────────┘         └─────────┘               │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机：用变量 currentStep (0-3) 跟踪当前步骤
  2. 元素 ID 命名：所有元素以 scene1- 为前缀（如 scene1-rect-original, scene1-path-concave）
  3. 步骤切换：根据 currentStep 显示/隐藏对应元素组
  4. 按钮状态：currentStep=0 时禁用上一步，currentStep=3 时禁用下一步
  5. 凹字形 path 坐标：M250,150 L550,150 L550,200 L500,200 L500,300 L550,300 L550,350 L250,350 Z
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中
  7. 颜色定义：const COLORS = { main: '#000000', highlightBlue: '#1565c0', highlightRed: '#c62828', highlightGreen: '#2e7d32',辅助线: '#888888', fillGray: '#e0e0e0' }
