    <TEXT_1>
    **题目原文：**
    如图，把一个半径是10cm的圆剪拼成一个近似的长方形，现在的长方形的周长是（  ）cm．
    A．31.4    B．62.8    C．72.8    D．82.8

    **题目分析：**
    本题考察圆的剪拼变换及其周长变化规律。核心知识点是：当圆被分割成若干等份后重新拼成近似长方形时，长方形的长和宽与圆的半径、周长之间的对应关系。

    **整体讲解思路：**
    1. 首先展示圆剪拼成长方形的动态过程，让学生直观感知形状变化
    2. 引导学生观察并发现：长方形的长≈圆周长的一半，长方形的宽≈圆的半径
    3. 基于上述关系，推导长方形周长公式：周长 = 2(πr + r) = 2r(π + 1)
    4. 代入 r = 10cm 计算得出答案

    **图示规划说明：**
    本大题规划 2 个图示：
    - SCENE_1：圆剪拼成长方形的动态演示，展示形状变换过程
    - SCENE_2：标注关键尺寸关系，推导周长计算公式
    </TEXT_1>

    **图示 2 教学说明：**

    教师应引导学生按以下步骤理解：

    1. **步骤 0→1→2**：重点观察标注线和关系弧线，理解"长方形的长来自圆周长的一半，宽就是圆的半径"

    2. **步骤 3→4**：同步推导公式，强调代数表达：
       - 长 = πr（圆周长的一半）
       - 宽 = r（圆的半径）
       - 周长 = 2(长 + 宽) = 2(πr + r) = 2r(π + 1)

    3. **步骤 5**：代入计算，强调 π 取 3.14

    **关键推导公式（板书配合）：**
    ```
    长方形的长 = 圆周长的一半 = C/2 = 2πr/2 = πr
    长方形的宽 = 圆的半径 = r
    长方形周长 = 2(长 + 宽) = 2(πr + r) = 2r(π + 1)
    代入 r = 10：
    周长 = 2 × 10 × (3.14 + 1) = 20 × 4.14 = 82.8 (cm)
    ```

    **易错点提醒：**
    - 学生容易误以为长方形周长等于圆周长（62.8cm），要强调剪拼后增加了两条宽（即 2r）
    - 正确理解：长方形周长 = 圆周长 + 2r = 2πr + 2r = 2r(π + 1)

    **完整解答：**
    长方形的周长 = 2r(π + 1) = 2 × 10 × (3.14 + 1) = 82.8cm
    正确答案：**D．82.8**

    **课堂讲解建议：**
    1. 先用 SCENE_1 建立直观感知，让学生"看到"变换过程
    2. 再用 SCENE_2 进行抽象推导，让学生"理解"数量关系
    3. 最后通过变式练习巩固：若半径改为 5cm，周长是多少？（答案：2×5×4.14 = 41.4cm）
