[图示主题与整合说明]
- 本图示主题：三个等面积圆的布局与重叠关系
- 整合的内容：三个圆的位置关系、两个重叠区域、直线a穿过圆心的几何特征、面积标注

[分步序列]
- 步骤0（初始状态）：显示三个圆的轮廓（圆A、圆B、圆C），圆心点A、B、C，标签"A"、"B"、"C"，直线a，标签"a"。重叠区域不显示，面积标注不显示。
- 步骤1：高亮显示两个重叠区域（重叠区域1、重叠区域2填充蓝色20%透明度），在重叠区域中心显示标签"x"（表示每个重叠区域面积为x）。
- 步骤2：在三个圆上方分别显示标签"S"（表示每个圆面积为S），在底部显示标签"2S+2"（表示总覆盖面积）。
- 步骤3：在底部显示标签"9"（表示直线a下方被圆覆盖的面积），完成所有已知条件标注。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 按钮"◀上一步"：位置(280,450)，作用：返回上一步骤
  - 按钮"下一步▶"：位置(500,450)，作用：进入下一步骤
  - 步骤指示器：位置(380,450)，显示"步骤 1/4"
- 教师操作流程：
  1. 初始展示三个圆的基本布局，让学生观察圆的相对位置
  2. 点击"下一步"，高亮重叠区域，引导学生关注重叠部分
  3. 点击"下一步"，标注各圆面积S和总覆盖面积2S+2
  4. 点击"下一步"，标注直线a下方覆盖面积9，完成题目条件展示
  5. 教师可点击"上一步"回退复习，帮助学生理解各条件之间的关系

[技术实现]
- JS 库选择：原生 SVG（简单几何首选，无需额外依赖，性能好）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────┐
  │                                                         │
  │     ○A              ○B              ○C                 │
  │    ╱  ╲            ╱  ╲            ╱  ╲               │
  │   │ S  │          │ S  │          │ S  │               │
  │   │    │    x     │    │    x     │    │               │
  │  ╱─────╲══════════╪════╪══════════╪════╲               │
  │  │  A  │══════════●════●══════════│     ╲              │
  │  │     │    直线a ║    ║           │      ╲             │
  │  ╲─────╱══════════╪════╪══════════╪════╱               │
  │    ╲  ╱            ╲  ╱            ╲  ╱               │
  │     ○              ○B              ○C                 │
  │                                                         │
  │              2S+2 (总覆盖面积)                          │
  │                  9 (a下方面积)                          │
  │                                                         │
  │        [◀上一步]    步骤 1/4    [下一步▶]              │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-3) 跟踪当前步骤，每个步骤对应一个显示配置对象
  2. 坐标计算：圆重叠区域使用 SVG path 的 clipPath 或手动计算交集路径
  3. 动画曲线：元素出现使用 opacity 从 0 到 1 的过渡动画，持续时间 300ms
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 renderStep() 重新渲染
  5. ID 命名规范：所有交互元素 ID 以 scene1- 为前缀（如 scene1-circle-a, scene1-btn-next）
  6. IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局污染
  7. 重叠区域计算：使用 SVG clipPath 实现圆的交集填充，或预先计算交集路径坐标
- 重叠区域路径计算（近似）：
  - 重叠区域1（圆A与圆B）：两圆圆心距150px，半径60px，交集为透镜形状
  - 重叠区域2（圆B与圆C）：两圆圆心距≈180px（√(150²+120²)），半径60px，交集为透镜形状
  - 使用 SVG path 的 M A r 0 0 1/0 A r 0 0 0/1 Z 语法绘制圆弧交集
