[分步序列]

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于(540,420)，80×30px，灰色背景，用于回退到前一步骤
  - 「下一步」按钮：位于(640,420)，80×30px，蓝色背景，用于进入下一步骤
  - 「重置」按钮：位于(740,420)，60×30px，红色背景，用于回到初始状态
- 教师操作流程：
  1. 初始展示三个圆及重叠区域，让学生观察图形结构
  2. 点击「下一步」展示容斥原理公式，讲解为什么是"3S - 2x"
  3. 再次点击展示代数变形结果 x = (S-2)/2
  4. 点击展示直线 a 下方区域高亮，引导学生分析该区域由哪些部分组成
  5. 点击展示方程 S - x = 9，解释为什么是"S - x"（圆 A 下半 S/2 + 圆 B 下半 S/2 - 重叠下半 x/2 = S - x/2，但题目给出的是 9，实际应为 S - x/2 = 9，这里按题目给定的方程展示）
  6. 最后点击展示求解结果 S = 6

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（几何图形简单，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │                        图示区 800×500                          │
  │                                                                │
  │    圆 A        圆 B              圆 C                          │
  │   (140,220)  (240,220)        (300,300)                       │
  │      ○────────○                ○                              │
  │     /  重叠   /  \              /  \                           │
  │    │   (蓝)  │    \            │    \                          │
  │    │         │     \           │  重叠 │                        │
  │   ─┼─────────┼──────┼──────────┼──────┼────────── 直线 a       │
  │    │         │      \          │ (绿) │                        │
  │    │         │       \         │ 下方 │                        │
  │     \       /         \        \      /                         │
  │      ○─────○           ○        ○───○                          │
  │                                                                │
  │                    公式推导区（右侧）                           │
  │    推导过程：                                                   │
  │    3S - 2x = 2S + 2                                            │

  │  ┌─────────────────────────────────────────────────────────┐   │

  │  └─────────────────────────────────────────────────────────┘   │
  └────────────────────────────────────────────────────────────────┘
  ```

- 关键实现要点：
  1. 状态机设计：使用变量 currentStep（0-5）跟踪当前步骤，每一步对应不同的元素可见性状态
  2. 圆相交区域绘制：使用 SVG path 的 clipPath 或手动计算相交弧线段绘制重叠区域
  3. 直线 a 下方区域：使用 SVG clipPath 裁剪三个圆在直线 y=220 下方的部分，组合成多边形填充
  4. 动画曲线：步骤切换时使用 opacity 渐变（0.3s ease-in-out）实现平滑过渡
  5. 事件绑定：按钮点击事件更新 currentStep，调用 updateScene() 函数刷新显示
  6. ID 命名规范：所有元素 ID 以"scene2-"为前缀（如 scene2-circle-a、scene2-formula-1、scene2-btn-next）
  7. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染

- 圆相交区域计算（关键）：
  - 圆 A 与圆 B：圆心距 100，半径 60，相交区域用 SVG path 绘制
  - 圆 B 与圆 C：圆心距约 80.6（√(60²+80²)），半径 60，相交区域用 SVG path 绘制
  - 使用 SVG <path>的 A 命令绘制圆弧，手动计算相交点坐标

- 直线 a 下方区域计算：
  - 圆 A 下半：半圆，面积 S/2
  - 圆 B 下半：半圆减去重叠部分下半，面积 S/2 - x/2
  - 圆 C 下半：根据圆心位置计算，约 S/2 + 部分重叠
  - 总下方面积 = S/2 + (S/2 - x/2) + (S/2 + x/2) = 3S/2 - x/2（需根据实际图形调整）
  - 题目给定下方面积为 9，方程为 S - x = 9（按题目要求展示）
