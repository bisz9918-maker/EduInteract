[分步序列]
本场景为连续拖拽交互，无分步导航，状态随拖拽实时更新：

- 初始状态（步骤 0）：
  - 物体位于 x=350（距离路灯杆 250px）
  - 显示完整场景：路灯杆、光源、地面、物体、光线、影子
  - 距离 a = 250 米（实际为 250px 单位换算）
  - 影长 s = 计算值（根据相似三角形：s = (物体高度 × a) / (路灯高度 - 物体高度)）
  - 数值显示框显示当前 a 和 s 值
  - 滑块指示器位于轨道中间位置

- 拖拽过程（动态状态）：
  - 拖动滑块或物体 → 物体水平移动 → 距离 a 实时更新
  - 光线重新计算 → 影子末端位置重新计算 → 影子区域重新填充
  - 距离标注线 a 和影长标注线 s 长度实时更新
  - 数值显示框实时刷新 a 和 s 的数值
  - 规律验证：a 越小 → s 越短；a 越大 → s 越长

- 极端位置验证：
  - 物体最左（x=150，a=50）：影子最短，约 20px
  - 物体最右（x=550，a=450）：影子最长，约 180px

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：
  1. 滑块轨道：位于底部 (200,450)-(600,470)，灰色背景
  2. 滑块指示器：蓝色圆形，可左右拖动，拖动范围 x=200~600
  3. 物体：也可直接拖动物体本身（x=150~550 范围）
- 教师操作流程：
  1. 初始展示：物体在中间位置，说明当前距离 a 和影长 s
  2. 向左拖动：将物体移近路灯，观察影子变短，a 值减小，s 值减小
  3. 向右拖动：将物体移远路灯，观察影子变长，a 值增大，s 值增大
  4. 总结规律：距离 a 越小→影子 s 越短；距离 a 越大→影子 s 越长
  5. 验证选项：选项 B 正确（若 a 越小，则物体的影子越短）

- 画布尺寸：800 × 500 px

- 关键实现要点：
  1. 状态机设计：
     - 核心状态：objectX（物体底部中心 x 坐标，范围 150~550）
     - 派生状态：a = objectX - 100（距离），shadowEndX（影子末端 x 坐标）
     - 影子末端计算：根据相似三角形，光线从 (100,100) 经 (objectX,280) 到地面
       - 光线斜率 k = (280-100)/(objectX-100) = 180/(objectX-100)
       - 影子末端 x = objectX + (380-280)/k = objectX + 100*(objectX-100)/180

  2. 坐标计算函数：
     - updateScene(objectX): 重新计算所有派生坐标，更新 SVG 元素
     - 距离 a = objectX - 100
     - 影子末端 x = objectX + (objectX - 100) * 100 / 180
     - 影长 s = 影子末端 x - objectX

  3. 动画曲线：拖拽为线性移动，无特殊曲线需求

  4. 事件绑定：
     - 滑块指示器 mousedown/touchstart → 开始拖拽
     - document mousemove/touchmove → 更新物体位置
     - document mouseup/touchend → 结束拖拽
     - 物体本身也可直接拖拽（相同事件处理）

  5. ID 命名规范：所有交互元素 ID 以 scene1- 为前缀
     - scene1-pole（路灯杆）
     - scene1-light（光源）
     - scene1-object（物体）
     - scene1-ground（地面）
     - scene1-ray（光线）
     - scene1-shadow（影子区域）
     - scene1-dist-line（距离标注线）
     - scene1-dist-text（距离标注文字）
     - scene1-shadow-line（影长标注线）
     - scene1-shadow-text（影长标注文字）
     - scene1-value-box（数值显示框）
     - scene1-slider-track（滑块轨道）
     - scene1-slider-thumb（滑块指示器）

  6. IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局污染

  7. 数值显示更新：
     - 每次物体位置变化，实时更新数值显示框内容
     - 使用 textElement.textContent = `距离 a = ${a.toFixed(1)} 米`

  8. 边界限制：
     - 物体 x 范围：150~550（距路灯杆 50~450）
     - 滑块 x 范围：200~600（与物体位置线性映射）
