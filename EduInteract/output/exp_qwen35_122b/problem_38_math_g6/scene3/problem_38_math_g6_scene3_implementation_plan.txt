[分步序列]
- 初始状态（步骤0）：
  - 显示标题"从上面观察"
  - 显示左图俯视图（3个正方形并排，填充#e3f2fd）
  - 显示右图俯视图（3个正方形并排，填充#e3f2fd）
  - 显示"形状相同"标识在中间
  - 显示三个选项A、B、C（默认灰色）
  - 不显示正确答案文字
  - 不显示高亮框

- 步骤1：点击「下一步」→
  - 左图俯视图的3个正方形高亮显示（添加#2e7d32绿色边框）
  - 右图俯视图的3个正方形高亮显示（添加#2e7d32绿色边框）
  - "形状相同"标识变为绿色加粗
  - 选项C按钮变为绿色高亮状态（#2e7d32边框，#e8f5e9填充）

- 步骤2（最终步骤）：点击「下一步」→
  - 保持步骤1的所有高亮状态
  - 显示"正确答案：C.上面"文字（绿色粗体）
  - 选项A、B保持灰色默认状态

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮（scene3-prev-btn）：位于(280,450)，点击返回上一状态，步骤0时禁用
  - 下一步按钮（scene3-next-btn）：位于(420,450)，点击进入下一状态，步骤2时禁用
- 教师操作流程：
  1. 初始展示两个立体图形从上面观察的俯视图
  2. 点击"下一步"，高亮显示两个视图的相同部分，同时选项C高亮
  3. 再次点击"下一步"，显示正确答案文字，完成讲解
  4. 可随时点击"上一步"回退复习

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │                      从上面观察 (25,300)                     │
  │                                                             │
  │   左图                    形状相同              右图         │
  │   ┌─────┐                ┌─────┐              ┌─────┐       │
  │   │ □□□ │                │     │              │ □□□ │       │
  │   └─────┘                └─────┘              └─────┘       │
  │  (100,100)              (380,185)           (500,100)       │
  │                                                             │
  │   A.左面      B.前面      C.上面                             │
  │  ┌──────┐   ┌──────┐   ┌──────┐                            │
  │  │      │   │      │   │      │                            │
  │  └──────┘   └──────┘   └──────┘                            │
  │  (150,320)  (350,320)  (550,320)                            │
  │                                                             │
  │              正确答案：C.上面                               │
  │                    (320,405)                                │
  │                                                             │
  │         ┌────────┐      ┌────────┐                         │
  │         │◀上一步 │      │下一步▶ │                         │
  │         └────────┘      └────────┘                         │
  │         (280,450)      (420,450)                            │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量（0/1/2）跟踪当前步骤
  2. 坐标计算：所有元素使用绝对坐标，俯视图方块间距50px
  3. 动画曲线：高亮效果使用 CSS transition（0.3s ease）
  4. 事件绑定：按钮点击事件绑定到 scene3-prev-btn 和 scene3-next-btn
  5. 步骤0时禁用上一步按钮，步骤2时禁用下一步按钮
  6. 高亮框使用 stroke 属性动态添加/移除
- ID 命名规范：所有交互元素 ID 以 scene3- 为前缀（如 scene3-left-view, scene3-right-view, scene3-prev-btn, scene3-next-btn）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局污染
