[分步序列]
- 步骤 0（初始状态）：
  - 显示：三个装置的完整结构（地面线、墙壁、物体、滑轮、绳子）
  - 显示：装置编号 (1)、(2)、(3)
  - 不显示：所有力的标注（F₁/F₂/F₃、f、T）
  - 目的：让学生先观察三种装置的结构差异

- 步骤 1：
  - 新增：绳子张力标注 T₁、T₂、T₃（绿色，显示在绳子水平段下方）
  - 新增：绳子张力方向箭头（沿绳子方向，绿色虚线箭头）
  - 高亮：三根绳子用绿色高亮显示
  - 目的：理解绳子张力的传递路径

- 步骤 2：
  - 新增：摩擦力 f 标注（红色箭头，作用在三个物体底部，均向左）
  - 新增：f 标签（红色，三个装置中 f 大小相同）
  - 显示：文字提示"f₁ = f₂ = f₃ = f（相同地面，相同物体）"
  - 目的：明确三种情况下摩擦力相同，为后续比较做铺垫

- 步骤 3：
  - 新增：拉力 F₁、F₂、F₃ 标注（蓝色箭头和文字）
  - F₁ 箭头：长度 60px（基准长度）
  - F₂ 箭头：长度 30px（F₁的一半）
  - F₃ 箭头：长度 120px（F₁的两倍）
  - 显示：文字提示"F₁ = f，F₂ = f/2，F₃ = 2f"
  - 目的：直观展示三种拉力的大小差异

- 步骤 4（结论）：
  - 高亮：F₂、F₁、F₃ 标签依次闪烁（绿→蓝→蓝）
  - 新增：结论文本"F₂ < F₁ < F₃"（绿色，底部中央）
  - 新增：正确选项"D"（绿色，加粗，带边框）
  - 目的：总结三种拉力的大小关系，确认正确答案

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：位于底部左侧，灰色，点击返回上一状态
  - "下一步 ▶"按钮：位于底部右侧，蓝色，点击进入下一状态
  - 步骤指示器：显示当前步骤"步骤 X/5"
- 教师操作流程：
  1. 初始展示三种滑轮装置结构，让学生观察差异
  2. 点击"下一步"，展示绳子张力传递路径
  3. 点击"下一步"，标注摩擦力，强调三种情况 f 相同
  4. 点击"下一步"，标注三种拉力，用箭头长度直观展示大小
  5. 点击"下一步"，显示结论 F₂<F₁<F₃ 和正确选项 D
  6. 可随时点击"上一步"回退复习，巩固理解

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（圆、矩形、线段、箭头），原生 SVG 足以实现，无需引入重型库
  - 动画使用 CSS transition + requestAnimationFrame 实现平滑过渡

- 画布尺寸：800 × 500 px

- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-4) 跟踪当前步骤，每一步定义要显示/隐藏/高亮的元素 ID 列表
  2. 坐标计算：所有元素坐标硬编码在布局表中，确保精确到像素级
  3. 动画曲线：力的箭头长度变化使用 CSS transition (ease-out, 0.3s)
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateScene() 刷新显示
  5. ID 命名规范：所有元素 ID 以"scene1-"为前缀，如 scene1-pulley-1、scene1-f1-arrow、scene1-btn-next
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 元素显示控制：使用 display: none / display: block 或 opacity 控制元素可见性
  8. 箭头绘制：使用 SVG <line> + <polygon>组合实现带箭头的线段
