[分步序列]
- 步骤0（初始状态）：
  - 显示标题"正方体展开图对面规律"
  - 显示参考区：1-4-1型展开图模板，标注对面关系（虚线连接相对面）
  - 显示四个选项A、B、C、D的展开图（2×2排列，均正常显示）
  - 判断结果区显示："请分析各选项的对面关系"
  - 所有选项边框正常（#000000 2px）

- 步骤1（分析选项A）：
  - 选项A边框高亮（#1565c0 3px）
  - 选项A内部显示三组对面连线（虚线#888888）
  - 爱心-爱心相对、笑脸-笑脸相对、太阳-太阳相对
  - 判断结果区显示："✓ 选项A：三组对面图案相同"

- 步骤2（分析选项B）：
  - 选项B边框高亮（#1565c0 3px）
  - 选项B内部显示对面连线
  - 爱心-爱心相对、太阳-太阳相对、笑脸-笑脸相对
  - 但顶面是笑脸（题目中顶面是太阳）
  - 判断结果区显示："✗ 选项B：顶面图案不符（应为太阳）"

- 步骤3（分析选项C）：
  - 选项C边框高亮（#1565c0 3px）
  - 选项C内部显示图案分布
  - 太阳有3个，笑脸只有1个
  - 判断结果区显示："✗ 选项C：图案数量不对（太阳3个，笑脸1个）"

- 步骤4（分析选项D）：
  - 选项D边框高亮（#1565c0 3px）
  - 选项D内部显示对面连线
  - 爱心-爱心相对，但太阳和笑脸的相对关系不符合题目
  - 判断结果区显示："✗ 选项D：相邻面关系不符"

- 步骤5（验证选项A）：
  - 选项A边框保持高亮
  - 右侧显示立体验证图（展开图→立体图动画）
  - 立体图显示：顶面太阳、正面笑脸、右侧面爱心
  - 判断结果区显示："✓ 选项A可折叠成题目立体图"

- 步骤6（结论）：
  - 所有选项边框恢复正常
  - 选项A边框绿色高亮（#2e7d32 4px）
  - 判断结果区显示："✓ 正确答案：A"
  - 立体验证图保持显示

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮（scene2-btn-prev）：位于底部左侧，点击返回上一步
  - "下一步 ▶"按钮（scene2-btn-next）：位于底部右侧，点击进入下一步
  - 步骤0时"上一步"按钮禁用，步骤6时"下一步"按钮禁用
- 教师操作流程：
  1. 步骤0：展示1-4-1型展开图对面规律参考，引导学生理解相对面概念
  2. 步骤1-4：逐个分析四个选项，高亮当前选项，显示判断结果
  3. 步骤5：展示选项A折叠成立体图的验证过程
  4. 步骤6：得出结论，强调正确答案
  5. 可随时点击"上一步"回退复习某个选项的分析过程

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形（网格、图案）用 SVG 绘制清晰，动画和状态切换用原生 JS 即可实现，无需额外库
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │                    正方体展开图对面规律                         │
  │                                                                │
  │  1-4-1型对面规律参考        │        四个选项分析              │
  │  ┌─────────────┐           │   ┌───┐  ┌───┐                   │
  │  │   太阳      │           │   │ A │  │ B │                   │
  │  │ ┌───┬───┐  │           │   └───┘  └───┘                   │
  │  │ │爱 │笑 │  │           │   ┌───┐  ┌───┐                   │
  │  │ │心 │脸 │  │           │   │ C │  │ D │                   │
  │  │ └───┴───┘  │           │   └───┘  └───┘                   │
  │  │   太阳      │           │                                  │
  │  └─────────────┘           │                                  │
  │                            │                                  │
  │        判断结果区：请分析各选项的对面关系                       │
  │                                                                │
  │              [◀ 上一步]        [下一步 ▶]                      │
  └────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量（0-6）跟踪当前步骤
  2. 坐标计算：所有元素坐标预先计算并硬编码，确保无重叠
  3. 图案绘制：爱心、太阳、笑脸用 SVG path 绘制简化版
  4. 动画曲线：步骤5的折叠验证使用 SVG transform + CSS transition
  5. 事件绑定：按钮点击事件绑定到 scene2-btn-prev 和 scene2-btn-next
  6. ID 命名规范：所有元素 ID 以 scene2- 为前缀（如 scene2-opt-a, scene2-btn-prev）
  7. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中
  8. 状态切换：每次步骤变化时，更新当前高亮选项边框、判断结果文字、显示/隐藏相关元素
- 图案定义（SVG path）：
  - 爱心：简化心形 path，居中于40×40格子内
  - 太阳：圆形+放射线条，居中于40×40格子内
  - 笑脸：圆形+眼睛+嘴巴，居中于40×40格子内
