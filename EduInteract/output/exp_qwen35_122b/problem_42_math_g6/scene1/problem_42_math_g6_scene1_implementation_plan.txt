[分步序列]
- 步骤0（初始状态）：
  - 显示：主视图图形、左视图图形、俯视图标签、空白俯视图网格（仅网格线，无数字）
  - 总数显示区：隐藏
  - 高亮：无
  - 目的：展示题目基础条件，让学生观察三视图

- 步骤1（点击"下一步"）：
  - 新增：俯视图网格中4个有方块的位置填充浅蓝色背景
  - 高亮：俯视图网格区域用蓝色 #1565c0 边框高亮
  - 目的：确认俯视图显示底层有4个位置

- 步骤2（点击"下一步"）：
  - 新增：格1-2、格1-3、格2-1标注"1"（黑色）
  - 高亮：主视图第2、3列用蓝色 #1565c0 边框高亮，显示列高为1
  - 目的：根据主视图，第2、3列最高1层，对应俯视图的格1-2、格1-3为1层

- 步骤3（点击"下一步"）：
  - 新增：格1-1标注"2"（红色 #c62828）
  - 高亮：主视图第1列和左视图第1列同时用红色 #c62828 边框高亮
  - 目的：根据主视图第1列高2层、左视图第1列高2层，推断左上角位置为2层

- 步骤4（最终步骤，点击"下一步"）：
  - 新增：总数显示区显示"总数 = 2 + 1 + 1 + 1 = 5"，绿色 #2e7d32
  - 高亮：所有4个格子的数字同时闪烁一次，然后总数数字"5"加粗放大
  - 目的：展示最终计算结果，答案为B.5

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮（scene1-prev-btn）：位于底部左侧，点击返回前一步骤，步骤0时禁用
  - 下一步按钮（scene1-next-btn）：位于底部右侧，点击进入下一步骤，步骤4时变为"完成"并禁用
- 教师操作流程：
  1. 初始展示三视图，引导学生观察三个视图的形状
  2. 点击"下一步"，确认俯视图的4个位置
  3. 点击"下一步"，根据主视图标注第2、3列的1层
  4. 点击"下一步"，根据主视图和左视图共同推断左上角为2层
  5. 点击"下一步"，展示总数计算结果

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │  从正面看      从左面看      从上面看                           │
  │  ┌──────┐     ┌──────┐     ┌─────────────────────┐            │
  │  │ 主视图│     │ 左视图│     │ 俯视图网格 2×3      │            │
  │  │ L形  │     │ L形  │     │  [2][1][1]          │            │
  │  │ 2层  │     │ 2层  │     │  [1][ ][ ]          │            │
  │  └──────┘     └──────┘     └─────────────────────┘            │
  │                                                                 │
  │                                                                 │
  │              总数 = 2 + 1 + 1 + 1 = 5                           │
  │                                                                 │
  │              [◀ 上一步]  [下一步 ▶]                             │
  └────────────────────────────────────────────────────────────────┘
  ```

- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-4) 跟踪当前步骤，updateScene() 函数根据 currentStep 显示/隐藏元素
  2. 坐标计算：所有元素使用绝对定位，基于布局坐标表精确到像素
  3. 动画曲线：数字标注使用 opacity 淡入动画（0.3s ease-in-out）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateScene()
  5. 禁用状态：步骤0时上一步按钮 disabled，步骤4时下一步按钮改为"完成"并 disabled

- ID 命名规范：
  - 所有交互元素 ID 以 scene1- 为前缀
  - 示例：scene1-main-view, scene1-left-view, scene1-top-grid, scene1-cell-1-1, scene1-cell-1-2, scene1-cell-1-3, scene1-cell-2-1, scene1-total-text, scene1-prev-btn, scene1-next-btn
  - 数字标签 ID：scene1-num-1-1, scene1-num-1-2, scene1-num-1-3, scene1-num-2-1

- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
