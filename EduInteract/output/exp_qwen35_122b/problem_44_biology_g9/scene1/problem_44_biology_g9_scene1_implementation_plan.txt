[图示主题与整合说明]
- 本图示主题：血液循环路径与不同器官的血液成分变化对比
- 整合内容：整合基础血流模型 + 四个选项对应的四种情况分析（毛细血管网、小肠、肾小球、胰岛）
- 教学价值：教师可通过分步导航逐步展示四种不同情况，帮助学生理解不同器官中血液成分的变化规律，对比动脉血与静脉血的转换，以及营养物质和激素的运输机制

[分步序列]
步骤0（初始状态 - 基础模型）：
- 显示：血管甲、乙结构、血管丙的基础框架
- 血液颜色：灰色填充（表示未确定状态）
- 说明文字："基础血流模型：甲→乙→丙，箭头表示血流方向"
- 等待教师点击"下一步"

步骤1（毛细血管网情况）：
- 乙结构标注："A. 毛细血管网"
- 血管甲颜色：蓝色填充（动脉血入）
- 血管丙颜色：红色填充（静脉血出）
- 说明文字："若乙为毛细血管网：动脉血→毛细血管→静脉血，氧气减少，二氧化碳增加"
- 高亮：选项A用绿色边框标记（正确选项）
- 新增元素：在血管甲上方显示"动脉血"标签(150,200)，血管丙上方显示"静脉血"标签(620,200)

步骤2（小肠情况）：
- 乙结构标注："B. 小肠"
- 血管甲颜色：蓝色填充（动脉血入）
- 血管丙颜色：红色填充（静脉血出）
- 说明文字："若乙为小肠：动脉血→小肠→静脉血，氧气减少，但营养物质增加"
- 高亮：无（选项B错误，因为含氧量减少而非增加）
- 新增元素：在小肠矩形内显示"营养物质吸收↑"标签(400,270)

步骤3（肾小球情况）：
- 乙结构标注："C. 肾小球"
- 血管甲颜色：蓝色填充（入球小动脉）
- 血管丙颜色：蓝色填充（出球小动脉，仍为动脉血）
- 说明文字："若乙为肾小球：入球小动脉→肾小球→出球小动脉，丙仍为动脉血管，血液仍为动脉血"
- 高亮：无（选项C错误，因为丙是动脉血管而非静脉血管）
- 新增元素：在血管丙上方显示"动脉血"标签(620,200)

步骤4（胰岛情况）：
- 乙结构标注："D. 胰岛"
- 血管甲颜色：蓝色填充（动脉血入）
- 血管丙颜色：红色填充（静脉血出）
- 说明文字："若乙为胰岛：当血糖增多时，胰岛分泌胰岛素增加，丙内胰岛素含量增加"
- 高亮：选项D用绿色边框标记（正确选项）
- 新增元素：在胰岛矩形内显示"胰岛素分泌↑"标签(400,270)

步骤5（结论总结）：
- 乙结构标注："正确选项：A、D"
- 血管甲颜色：蓝色填充
- 血管丙颜色：红色填充（除肾小球情况外）
- 说明文字："总结：A正确（毛细血管网动脉血变静脉血）；B错误（小肠含氧量减少）；C错误（肾小球出球仍为动脉血）；D正确（胰岛分泌胰岛素进入血液）"
- 高亮：选项A和D用绿色边框标记

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 按钮"上一步"：位置(300,450)，作用：返回上一状态
  - 按钮"下一步"：位置(420,450)，作用：进入下一状态
  - 步骤指示器：位置(350,420)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始展示基础模型，讲解血流方向
  2. 点击"下一步"逐个展示四种情况
  3. 每步讲解该器官的血液变化特点
  4. 引导学生判断选项正误
  5. 最后一步总结所有正确选项

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  
  甲标签(150,220)                    丙标签(620,220)
       ↓                                  ↓
  ─────────→[    乙结构    ]────────────→
  (80,250)   (280,200)     (520,300)   (720,250)
  
  [说明文字区 50,350-750,420]
  
  [上一步] [下一步]
  (300,450) (420,450)
  
  [控件栏（SVG内底部 y=440~490）]
  ```

- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-5) 跟踪当前步骤
  2. 坐标计算：所有元素使用绝对坐标，通过 SVG transform 定位
  3. 颜色切换：通过修改 SVG 元素的 fill 属性实现血液颜色变化
  4. 事件绑定：按钮点击事件触发状态更新和视图重绘
  5. 标签动态显示：根据步骤显示/隐藏相应标签元素

- ID 命名规范：所有交互元素 ID 以 scene1- 为前缀
  - scene1-arrow-a（血管甲）
  - scene1-rect-b（乙结构）
  - scene1-arrow-c（血管丙）
  - scene1-label-a（甲标签）
  - scene1-label-b（乙标签）
  - scene1-label-c（丙标签）
  - scene1-btn-prev（上一步按钮）
  - scene1-btn-next（下一步按钮）
  - scene1-text-desc（说明文字）
  - scene1-text-step（步骤指示器）

- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
