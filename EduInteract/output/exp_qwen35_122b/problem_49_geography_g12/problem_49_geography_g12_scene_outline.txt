    **题目原文：**

    图中O为南极点，MA为晨昏线，M为晨昏线与纬线（70°）相切的切点，且与经线B相交，图中阴影部分表示与全球其他地区日期不同。读后完成下列问题。

    （1）太阳直射点的坐标是______________________________。

    （2）我国某地（30.5°N，114.5°E）正午太阳高度角是_______________，地方时是_______________。

    **题目分析：**

    本题是地球运动综合题，考查晨昏线、太阳直射点、日期分界线、地方时和正午太阳高度角的计算。

    **关键信息提取：**
    1. O为南极点 → 这是南极俯视图
    2. M为晨昏线与70°纬线切点 → 太阳直射点纬度 = 90° - 70° = 20°
    3. 阴影部分日期不同 → 阴影边界为180°经线和0时经线
    4. MA为晨昏线 → 需要判断是晨线还是昏线

    **解题思路：**
    1. 太阳直射点纬度：根据切点纬度计算（互余关系）
    2. 太阳直射点经度：0时经线与12时经线相对，阴影边界之一是0时经线
    3. 正午太阳高度角：H = 90° - |φ - δ|
    4. 地方时计算：根据经度差计算时差

    **图示规划：**
    - Scene 1：南极俯视图完整展示，标注晨昏线、切点、日期分界线
    - Scene 2：太阳直射点位置推导（纬度+经度）
    - Scene 3：正午太阳高度角计算示意图

    **图示3教学说明：**

    本图示展示正午太阳高度角的计算过程，教师应引导学生：

    **公式理解：**
    1. 正午太阳高度角公式：H = 90° - |φ - δ|
    2. φ = 当地纬度，δ = 太阳直射点纬度
    3. 注意纬度符号：北纬为正，南纬为负

    **本题计算：**
    1. 已知：φ = 30.5°N = +30.5°，δ = 20°S = -20°
    2. 代入：H = 90° - |30.5° - (-20°)|
    3. 计算：H = 90° - |50.5°| = 90° - 50.5° = 39.5°

    **地方时计算：**
    1. 我国某地经度：114.5°E
    2. 需要确定此时的标准时间参考
    3. 若太阳直射点经度已知，可计算该地与直射点经度的时差
    4. 时差 = 经度差 ÷ 15°/小时

    （1）太阳直射点坐标：(20°S, 根据图中阴影判断的经度)
