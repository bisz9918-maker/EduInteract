[视觉元素清单]

5. 晨昏线 MA：贝塞尔曲线，起点 M(340,270)，终点 A(650,220)，控制点 (480,200)，红色 #c62828，线宽 3px

[分步序列]
步骤 0（初始状态）：基础框架
- 显示：中心点 O、外圈纬线、70° 纬线、水平直径
- 标签：O、70°
- 目的：建立南极俯视图的基本框架

步骤 1：添加经线与切点
- 新增：经线 B（从 O 到外圈）、切点 M（在 70° 纬线上）
- 高亮：经线 B 和切点 M 用蓝色/红色加粗显示
- 标签：B、M
- 目的：展示经线 B 与 70° 纬线的交点关系

步骤 2：添加晨昏线
- 新增：晨昏线 MA（红色弧线，从 M 到 A）
- 高亮：晨昏线 MA 加粗显示，端点 A 出现
- 标签：A
- 目的：展示晨昏线与纬线相切于 M 点的特征

步骤 3：添加阴影日期区域
- 新增：阴影扇形（从经线 B 到水平向左）
- 高亮：阴影区域填充显示
- 标签：阴影标注"日期不同区"
- 目的：展示日期分界线的范围

步骤 4：总结标注
- 所有元素同时显示
- 高亮：切点 M 闪烁或加粗，标注"切点：晨昏线与纬线相切"
- 新增说明文字：在底部显示关键地理意义
  - "M 为切点：70°S 纬线出现极昼/极夜"
  - "阴影区：日期分界线（180°经线或 0 时经线）"
- 目的：总结图示的地理意义，辅助解题

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 理由：几何图形（圆、弧、线段、扇形）用 SVG 绘制最精确，无需额外库
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    图示区 800×500                        │
  │                                                         │
  │              B                                          │
  │             /                                           │
  │            /   阴影区                                   │
  │           /███████                                      │
  │          /███████    M                                  │
  │         /███████     ●                                  │
  │        /███████      ╲                                  │
  │       /███████        ╲  晨昏线 MA                      │
  │      /███████          ╲                                │
  │     /███████            ╲      A                        │
  │    ─────────────────────●────────────────               │
  │           O             70°                             │
  │          ●                                                │
  │                                                         │
  │  ┌─────────┐  步骤 1/5  ┌─────────┐                      │
  │  │ ◀上一步 │            │ 下一步▶ │                      │
  │  └─────────┘            └─────────┘                      │
  └─────────────────────────────────────────────────────────┘
  ```

- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-4) 跟踪当前步骤，每一步控制元素的 display 属性
  2. 坐标计算：
     - 中心点 O：(400, 350)
     - 70° 纬线：arc(400,350,120,0,Math.PI)
     - 外圈纬线：arc(400,350,200,0,Math.PI)
     - 经线 B 终点：角度 150°，(400+200*cos(150°), 350+200*sin(150°)) ≈ (227, 250)
     - 切点 M：在 70° 纬线上，角度 150°，(400+120*cos(150°), 350+120*sin(150°)) ≈ (296, 310)
     - 端点 A：(650, 220)
  3. 动画曲线：晨昏线 MA 用贝塞尔曲线，控制点 (480, 200)
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后重绘/切换元素显示
  5. ID 命名规范：所有元素 ID 以 scene1- 为前缀，如 scene1-center-O、scene1-arc-70、scene1-line-B、scene1-curve-MA 等
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染

- SVG 元素 ID 映射：
  - scene1-center-O：中心点 O
