    **图示 1 教学说明：**

    本图示展示昼半球图示的完整解读过程，教师应引导学生按以下步骤观察：

    1. 首先识别图示基本要素：圆形代表昼半球，圆心 A 即为太阳直射点位置，这是解题的关键前提

    2. 理解东西半球分界：A 点"西侧为东半球，东侧为西半球"，说明 A 点位于东西半球分界线上。东西半球分界线是 20°W 和 160°E，其中 20°W 西侧是东半球、东侧是西半球，故 A 点经度为 20°W

    3. 推导太阳直射点纬度：昼半球范围是 90°（从直射点向四周各 90°），B 点位于昼半球边缘且纬度为 75°，说明直射点纬度 = 90° - 75° = 15°。根据赤道位置判断 B 点在北半球，故直射点纬度为 15°N

    4. 确定 C 点坐标：C 点与 A 点关于地心对称，经度相差 180°（20°W → 160°E），纬度数值相同但南北相反（15°N → 15°S）

    5. 计算北京时间：太阳直射 20°W 时，20°W 地方时为 12:00。北京（120°E）与 20°W 经度差 140°，时差 = 140° ÷ 15°/h = 9 小时 20 分，故北京时间 = 12:00 + 9:20 = 21:20

    **关键公式：**
    - 昼半球范围：从直射点向四周各 90°
    - 时差计算：经度差 ÷ 15°/h = 时差（小时）
    - 对称点坐标：经度相差 180°，纬度数值相同南北相反

    **图示 2 教学说明：**

    本图示展示线速度与正午太阳高度角的比较规律，教师应引导学生理解两个不同物理量的决定因素：

    **线速度比较：**
    地球自转线速度公式：v = ωRcosφ

    其中 ω 为角速度（全球除极点外相等），R 为地球半径，φ为纬度。cosφ随纬度升高而减小，故线速度随纬度升高而减小。

    - A 点纬度 15°N，C 点纬度 15°S，两者纬度数值相同，故 v_A = v_C
    - B 点纬度 75°N，纬度最高，cos75°最小，故 v_B 最小
    - 结论：v_A = v_C > v_B

    **正午太阳高度角比较：**
    正午太阳高度角公式：H = 90° - |φ - δ|

    其中 φ为当地纬度，δ为太阳直射点纬度（本题中 δ = 15°N）

    - A 点：H = 90° - |15° - 15°| = 90°（直射点，正午太阳在头顶）
    - B 点：H = 90° - |75° - 15°| = 90° - 60° = 30°
    - C 点：H = 90° - |15° - 15°| = 90°（与直射点纬度数值相同，南北相反，正午太阳高度角也等于 90°）

    结论：H_A = H_C > H_B

    **课堂讲解建议：**
    1. 强调线速度取决于纬度（与地球自转相关），而正午太阳高度角取决于与直射点的纬度差（与太阳位置相关）
    2. 提醒学生注意 C 点虽然在南半球，但其纬度数值与直射点相同，故正午太阳高度角也等于 90°
    3. 可结合地球仪或手势演示，帮助学生建立空间想象

    **完整解答：**
    (1) 太阳直射点坐标：(20°W, 15°N)；C 点坐标：(160°E, 15°S)；北京时间：21:20
    (2) 线速度：v_A = v_C > v_B；正午太阳高度角：H_A = H_C > H_B
