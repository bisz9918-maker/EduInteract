[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：位置 (280,465)，作用：返回上一状态，隐藏当前步骤的推导框和引导线
  - "下一步 ▶"按钮：位置 (500,465)，作用：进入下一状态，显示当前步骤的推导框和引导线
  - 步骤指示器：位置 (380,465)，显示"步骤 1/8"，随步骤变化
- 教师操作流程：
  1. 初始展示昼半球图形和已知条件
  2. 点击"下一步"逐步展示推导过程，每步配合讲解
  3. 学生可跟随每一步理解从已知到结论的逻辑链
  4. 如需复习某一步，可点击"上一步"回退
  5. 最终步骤展示所有答案，便于总结

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    昼半球图示区                          │
  │                                                         │
  │           C                                            │
  │           ●                                            │
  │          /│\                                           │
  │         / │ \              推导框 1                     │
  │        /  │  \           ┌──────────┐                  │
  │       /   │   \          │ 圆心 A=  │                  │
  │      /    A●   \         │ 直射点   │                  │
  │     /    (蓝)   \        └──────────┘                  │
  │    /      │      \                                      │
  │   /   赤道 │       \                                    │
  │  ●─────────┼────────●                                   │
  │            │                                            │
  │            │                                            │
  │            ● B                                           │
  │           (红)                                           │
  │                                                         │
  │  ┌─────────────────────────────────────────────────┐   │
  │  │ 答案：直射点(20°W,15°N)  C(160°E,15°S)  21:20  │   │
  │  └─────────────────────────────────────────────────┘   │
  │                                                         │
  │  [◀ 上一步]  步骤 1/8  [下一步 ▶]                        │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：currentStep 变量跟踪当前步骤 (0-8)，每一步对应一组显示/隐藏规则
  2. 坐标计算：所有元素坐标硬编码在 SVG 中，确保精确位置
  3. 动画曲线：引导线使用 opacity 渐变 (0→1) 0.3s 过渡，推导框使用 transform: scale(0.95→1) 0.2s 过渡
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateScene() 刷新显示
  5. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-circle, scene1-point-a, scene1-btn-next）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 高亮效果：使用 CSS class 切换（scene1-highlight-blue, scene1-highlight-red, scene1-highlight-green）
  8. 答案框闪烁：步骤 8 时添加 CSS 动画 keyframes 实现边框颜色循环
