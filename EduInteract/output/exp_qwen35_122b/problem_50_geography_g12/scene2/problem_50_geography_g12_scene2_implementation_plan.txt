[分步序列]
- 步骤 0（初始状态）：显示地球侧视示意图，标注赤道、A 点（15°N）、B 点（75°N）、C 点（15°S）的相对位置，三点均显示但无高亮，右侧无公式框
- 步骤 1：显示线速度规律公式框"线速度 v = ωRcosφ，随纬度升高而减小"，A、B、C 三点淡入显示
- 步骤 2：高亮三点并显示纬度"A: 15°N, B: 75°N, C: 15°S"，A 点蓝色高亮，B 点红色高亮，C 点绿色高亮，同时显示三条纬线辅助虚线
- 步骤 3：显示线速度比较结果框"v_A = v_C > v_B"，A 点和 C 点同时闪烁蓝色，B 点闪烁红色，强调 A、C 纬度相同
- 步骤 4：显示正午太阳高度角规律公式框"H = 90° - |φ - δ|，δ为直射点纬度（15°N）"，线速度公式框淡出
- 步骤 5：计算三点正午太阳高度角，在对应点旁显示计算过程"A: H=90°（直射点）；B: H=30°；C: H=90°"
- 步骤 6：显示正午太阳高度角比较结果框"H_A = H_C > H_B"，A 点和 C 点同时闪烁绿色，B 点闪烁红色
- 步骤 7（结论）：两个比较结果框并列高亮显示，左侧显示"线速度：v_A = v_C > v_B"，右侧显示"正午太阳高度角：H_A = H_C > H_B"，所有公式框淡出，仅保留结果框

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "上一步"按钮：位于控件栏左侧，点击返回前一步状态
  - "下一步"按钮：位于控件栏右侧，点击进入下一步状态
- 教师操作流程：
  1. 初始展示地球侧视图，让学生观察 A、B、C 三点位置
  2. 点击"下一步"展示线速度公式，引导学生回忆线速度与纬度的关系
  3. 继续点击展示三点纬度和高亮，让学生比较纬度高低
  4. 展示线速度比较结果，强调 A、C 纬度相同所以线速度相等
  5. 继续点击切换到正午太阳高度角公式，讲解直射点概念
  6. 展示三点高度角计算过程
  7. 展示高度角比较结果
  8. 最后并列显示两个结论，帮助学生区分两个不同概念

- 关键实现要点：
  1. 状态机设计：使用变量 currentStep 记录当前步骤（0-7），每一步对应不同的元素显示状态
  2. 坐标计算：所有元素使用绝对坐标，通过 SVG transform 实现淡入淡出动画
  3. 动画曲线：使用 CSS transition 实现 opacity 和 transform 的平滑过渡（0.3s ease）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateScene() 刷新显示
  5. ID 命名规范：所有交互元素 ID 以 scene2- 为前缀（如 scene2-earth, scene2-point-a, scene2-prev-btn, scene2-next-btn）
  6. IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
  7. 元素显示控制：使用 display 和 opacity 配合实现淡入淡出效果，高亮元素使用 fill-opacity 改变透明度
