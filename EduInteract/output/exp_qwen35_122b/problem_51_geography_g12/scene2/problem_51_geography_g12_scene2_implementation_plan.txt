[分步序列]
- 步骤0（初始状态）：显示地球椭圆轮廓、夜半球填充、晨昏线、A/B/C/O四点、0°经线（红色）、120°E经线（蓝色）、赤道线。等待教师点击"下一步"
- 步骤1：新增晨线与昏线区分（晨线用实线、昏线用虚线），标注6:00（晨线与赤道交点下方）、18:00（昏线与赤道交点下方）、0:00（夜半球中央经线左侧）
- 步骤2：新增太阳直射经线（12:00经线，红色高亮），标注12:00标签（上方），显示太阳直射点位置（红色实心圆）
- 步骤3：标注0°经线地方时（根据晨昏线位置推算），显示计算过程文字"0°经线地方时 = X时"
- 步骤4：计算并显示北京时间"120°E地方时 = X时"，120°E经线闪烁高亮
- 步骤5：标注太阳直射点纬度（根据晨昏线与极圈关系），显示"太阳直射点纬度 = X°N/S"
- 结论：太阳直射点完整坐标显示"太阳直射点坐标：(X°E/W, X°N/S)"，所有关键元素同时高亮

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "上一步"按钮：scene2-btn-prev，位置(250,460)，作用：返回上一状态
  - "下一步"按钮：scene2-btn-next，位置(550,460)，作用：进入下一状态
  - 步骤指示器：scene2-step-indicator，位置(380,460)，显示"步骤 X/6"
- 教师操作流程：
  1. 初始展示基础光照图，讲解地球昼夜分布
  2. 点击"下一步"，标注晨昏线及关键时间点（6:00、18:00、0:00）
  3. 点击"下一步"，标注太阳直射经线（12:00）和直射点
  4. 点击"下一步"，推导0°经线地方时
  5. 点击"下一步"，计算北京时间（120°E地方时）
  6. 点击"下一步"，标注太阳直射点纬度
  7. 最终步骤，汇总太阳直射点完整坐标
  教师可随时点击"上一步"回退复习，巩固推导逻辑

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │                        图示区 800×500                        │
  │                                                             │

  │    夜半球  /  │  \  /  │  \/  │  \/  │  \  昼半球           │
  │   (半透明) /   │   \/   │   /\   │   /\   │                  │
  │           /    │   /\   │  /  \  │  /  \  │                 │

  │  └───────────────────────────────────────────────────────┘  │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 currentStep 记录当前步骤（0-6），每个步骤对应一个元素显示数组
  2. 坐标计算：所有元素使用绝对坐标，通过 SVG transform 定位
  3. 动画曲线：元素出现使用 opacity 渐变（0→1，时长 300ms）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后重绘可见元素
  5. 高亮闪烁：使用 CSS animation 实现关键元素闪烁效果（120°E经线）
- ID 命名规范：所有交互元素 ID 以 scene2- 为前缀（如 scene2-circle-A、scene2-line-0deg、scene2-btn-next）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局污染
