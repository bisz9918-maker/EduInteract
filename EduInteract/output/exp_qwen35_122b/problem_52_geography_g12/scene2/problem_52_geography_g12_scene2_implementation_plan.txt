[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 (280,455)，ID 为 scene2-prev-btn，点击后当前步骤减 1（步骤 0 时禁用）
  - 「下一步」按钮：位于 (460,455)，ID 为 scene2-next-btn，点击后当前步骤加 1（最终步骤时禁用）
- 教师操作流程：

  3. 点击「下一步」→ 显示北半球阴影和极昼极夜标签，讲解极昼极夜现象
  4. 点击「下一步」→ 显示南极圈/北极圈纬度标注，引导学生观察纬度与极昼极夜的关系

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：

  ```
  │  (280,455)                    (460,455)                 │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 currentStep 记录当前步骤（0-4），根据 currentStep 控制各元素的 display/opacity 属性
  2. 坐标计算：使用 SVG 的 viewBox="0 0 800 500"，所有坐标直接对应像素
  3. 动画曲线：使用 CSS transition 实现淡入效果（opacity: 0 → 1，duration 0.3s）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateScene() 刷新显示
  5. ID 命名规范：所有交互元素 ID 以 scene2- 为前缀（如 scene2-hemisphere-left、scene2-terminator、scene2-prev-btn、scene2-next-btn）
  6. IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
  7. 阴影填充：使用 SVG <pattern> 定义斜线图案，应用于阴影区域
  8. 晨昏线绘制：使用 SVG <path> 绘制斜穿两半球的弧线
