[图示主题与整合说明]
- 本图示主题：时区计算、昼长计算与太阳高度综合
- 整合的步骤/概念：
  1. 时区计算：根据甲地时间推算乙地时间（经度差→时间差）
  2. 昼长计算：根据 C 点昼弧所跨经度计算昼长
  3. 太阳直射纬度：根据晨昏线与极圈相切判断直射点纬度
  4. 正午太阳高度：H = 90° - |φ - δ| 公式计算
  5. 地球公转位置：根据日期判断近日点/远日点
- 教学价值：教师可逐步演示从基础地理信息到复杂计算的完整推理链条，帮助学生理解时区、昼长、太阳高度之间的内在联系

[分步序列]
- 初始状态（步骤 0）：
  - 显示双半球基础图（轮廓、经线、赤道）
  - 显示甲、乙、C 三点（蓝色圆点）
  - 显示晨昏线（虚线）

  - 地球公转轨道小图显示（灰色椭圆、太阳、近日点、远日点）

- 步骤 1：点击「下一步」→ 时区计算
  - 高亮甲点和乙点（蓝色闪烁）
  - 显示经度差标注线（灰色虚线连接甲乙）
  - 计算结果框显示："甲地 22 日 16 时 → 乙地时间计算"
  - 显示："甲乙经度差 = 90° → 时间差 = 6 小时"
  - 显示："乙地在甲地东侧 → 乙地 = 22 日 22 时"

- 步骤 2：点击「下一步」→ C 点昼长计算
  - 高亮 C 点（蓝色闪烁）
  - 显示 C 点所在纬度的昼弧（绿色粗线，跨越 120°经度）
  - 计算结果框新增："C 点昼长计算"
  - 显示："昼弧所跨经度 = 120°"
  - 显示："昼长 = 120° ÷ 15°/小时 = 8 小时"

- 步骤 3：点击「下一步」→ 太阳直射纬度
  - 显示太阳直射点（红色圆点在 23.5°S）
  - 高亮晨昏线与南极圈相切位置
  - 计算结果框新增："太阳直射纬度判断"

  - 显示："太阳直射纬度 = 23.5°S"

- 步骤 4：点击「下一步」→ 北京正午太阳高度
  - 显示北京点（绿色圆点）
  - 计算结果框新增："北京正午太阳高度计算"
  - 显示："H = 90° - |φ - δ|"
  - 显示："H = 90° - |39° - (-23.5°)| = 90° - 62.5° = 27.5°"

- 步骤 5：点击「下一步」→ 地球公转位置
  - 高亮地球公转轨道小图

  - 计算结果框新增："地球公转位置"
  - 显示："日期为 12 月 22 日（冬至）"
  - 显示："接近 1 月初 → 地球位于近日点附近"
  - 显示："地球距太阳较近"

- 最终步骤（步骤 6）：结论汇总

  - 所有关键点（甲、乙、C、太阳直射点、北京）同时高亮

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：

  ```
  │  └──────────────────────────────────────────────────────────┘ │
  └────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量（0-6），每一步对应不同的元素显示/隐藏状态
  2. 坐标计算：所有元素使用绝对坐标，SVG 元素通过 x、y、cx、cy 属性定位
  3. 动画曲线：高亮效果使用 CSS transition（opacity 0.3s ease）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 并调用 renderStep() 函数
  5. 计算结果框：使用 <text> 元素动态更新 innerHTML 或 textContent
  6. ID 命名规范：所有元素 ID 以 scene3- 为前缀（如 scene3-circle-jia、scene3-line-longitude-diff）
  7. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  8. 昼弧绘制：使用 SVG <path> 元素，根据 C 点纬度计算圆弧路径
  9. 晨昏线绘制：使用 SVG <path> 元素，绘制左半球的晨昏线弧线
