[分步序列]
- 步骤 0（初始状态）：显示四棱锥完整框架
  - 显示：顶点 P、A、B、C、D 及标签
  - 显示：所有棱（PA、PB、PC 实线；PD、CD、DA 虚线）
  - 显示：底边 AB、BC 实线
  - 显示：对角线 AC 虚线
  - 隐藏：点 M、N，线段 MN，平面填充，比例标注，平行符号

- 步骤 1：标注点 M、N 位置
  - 新增：点 M 在 AC 上（坐标 510,364），标签"M"
  - 新增：点 N 在 PC 上（坐标 560,304），标签"N"
  - 显示：比例标注"CM:MA=1:4"在 AC 下方（350,395）
  - 其他元素保持步骤 0 状态

- 步骤 2：高亮 MN 与平面 PAD 平行关系
  - 新增：线段 MN（蓝色 #1565c0，线宽 3）
  - 新增：平面 PAD 填充（三角形 P-A-D，透明度 20%）
  - 新增：平行符号"∥"在 MN 与平面之间（535,335）
  - 视觉提示：MN 与平面 PAD 无交点，直观展示平行关系

- 步骤 3：添加辅助线 PA
  - 叠加：在棱 PA 上叠加红色高亮线（#c62828，线宽 3）
  - 说明：PA 是平面 PAD 内的一条线，MN∥平面 PAD ⇒ MN 与平面内某线平行

- 步骤 4：展示比例关系结论
  - 新增：比例标注"NC:NP=1:4"在 PC 右侧（585,200）
  - 说明：由线面平行性质定理，MN∥平面 PAD ⇒ MN 与平面内过 N 的线平行
  - 推理：在△PAC 中，MN∥PA ⇒ CM:MA = CN:NP = 1:4
  - 最终结论：NC:NP = 1:4

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮（scene1-btn-prev）：位于 (250, 455)，点击返回上一状态，步骤 0 时禁用（灰色）
  - 下一步按钮（scene1-btn-next）：位于 (450, 455)，点击进入下一状态，步骤 4 时禁用（灰色）
  - 步骤指示器（scene1-step-indicator）：位于 (350, 420)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始展示四棱锥框架，让学生识别几何体结构
  2. 点击"下一步"标注 M、N 点位置，强调 CM:MA=1:4 已知条件
  3. 点击"下一步"高亮 MN 与平面 PAD，引导学生观察平行关系
  4. 点击"下一步"叠加 PA 辅助线，提示"找平面内与 MN 平行的线"
  5. 点击"下一步"展示结论，完整呈现推理过程

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 理由：几何图形简单（线段、点、多边形），原生 SVG 足够且性能好，无需引入重型库
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    四棱锥 P-ABCD                        │
  │                      P(400,80)                          │
  │                     / |  \                              │
  │                    /  |   \                             │
  │                   /   |    \                            │
  │              D---/----|-----\---C                       │
  │               /  \    |      /  \                       │
  │              /     \  |     /     \                     │
  │             A-------\-M---/--------B                    │
  │                    N  \ /                               │
  │                      \ /                                │
  │                       ·                                 │
  │                                                           │
  │              [步骤 X/5]                                  │
  │        [◀ 上一步]    [下一步 ▶]                          │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：currentStep 变量（0-4），updateScene() 函数根据 currentStep 显示/隐藏元素
  2. 坐标计算：所有元素坐标硬编码在 SVG 中，M 点坐标 (510,364) 按 CM:MA=1:4 计算得出
  3. 元素显示控制：每个动态元素添加 class（如 scene1-mn、scene1-plane-pad 等），通过 toggleClass 控制 display
  4. 按钮状态：步骤 0 禁用 prev，步骤 4 禁用 next，通过 disabled 属性控制
  5. 动画曲线：元素出现使用 opacity 过渡（0→1，duration 300ms），平滑展示
  6. 事件绑定：DOMContentLoaded 后绑定按钮点击事件，preventDefault 防止默认行为
- ID 命名规范：所有元素 ID 以 scene1- 为前缀
  - 顶点：scene1-pt-p, scene1-pt-a, scene1-pt-b, scene1-pt-c, scene1-pt-d
  - 点 M/N：scene1-pt-m, scene1-pt-n
  - 棱：scene1-edge-pa, scene1-edge-pb, scene1-edge-pc, scene1-edge-pd
  - 底边：scene1-edge-ab, scene1-edge-bc, scene1-edge-cd, scene1-edge-da
  - 对角线：scene1-edge-ac
  - 线段 MN：scene1-seg-mn
  - 平面填充：scene1-plane-pad
  - 标签：scene1-label-p, scene1-label-a, ..., scene1-label-m, scene1-label-n
  - 比例文本：scene1-text-cm-ma, scene1-text-nc-np
  - 平行符号：scene1-symbol-parallel
  - 控件：scene1-btn-prev, scene1-btn-next, scene1-step-indicator
- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
