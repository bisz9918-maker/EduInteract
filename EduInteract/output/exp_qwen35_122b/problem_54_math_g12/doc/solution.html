题目原文：
如图，AC=5cm，CD=3cm，DF=6cm，则从长方体表面上的点A到点F的最短距离等于．

题目分析：
这是一道经典的长方体表面最短路径问题。核心考点是将立体图形的表面路径转化为平面几何问题求解。

关键知识点：

  1. 长方体表面两点间最短路径需将相关面展开成平面
  2. 展开方式不唯一，需比较多种展开路径
  3. 展开后两点间直线距离即为该展开方式下的最短表面距离

已知条件：

  • AC = 5cm（长方体的长）
  • CD = 3cm（长方体的宽）
  • DF = 6cm（F点在右侧棱上，距离D点6cm）

整体讲解思路：

  1. 首先展示原长方体图，明确点A和点F的位置
  2. 引导学生思考：立体表面路径如何转化为平面问题？
  3. 展示不同展开方式，计算各方式下的直线距离
  4. 比较得出最短距离

图示规划：

  • Scene 1：原长方体图（标注已知条件）
  • Scene 2：多种展开方式对比（交互式切换）
长方体表面最短路径问题
步骤 0/4

Scene 1 教学说明：

本图示用于帮助学生建立长方体的空间认知，明确起点A和终点F的位置关系。

讲解要点：

  1. 首先引导学生观察长方体结构，识别可见棱与不可见棱
  2. 确认各顶点位置：A为底面左前顶点，C为底面右前顶点，D为底面右后顶点
  3. 明确F点位置：F在右侧竖直棱上，距离底面D点6cm
  4. 强调问题本质：求沿长方体表面从A到F的最短距离（非空间直线距离）

关键提问：

  • "如果蚂蚁要从A爬到F，它只能沿表面爬行，最短路径是怎样的？"
  • "立体图形的表面路径问题，我们能否转化为平面问题来解决？"

过渡引导：
引出"展开法"——将长方体相关面展开成平面，两点间直线距离即为最短表面距离。

Scene 2 教学说明：

本图示是本题的核心，展示多种展开方式并比较得出最短距离。

讲解要点：

  1. 展开方式1（前面+右面）：将前面和右面沿公共棱展开成平面
  • A到F的水平距离 = AC + CD = 5 + 3 = 8cm
  • A到F的垂直距离 = DF = 6cm
  • 直线距离 = √(8² + 6²) = √100 = 10cm
  1. 展开方式2（底面+右面）：将底面和右面展开
  • 水平距离 = AC = 5cm
  • 垂直距离 = CD + DF = 3 + 6 = 9cm
  • 直线距离 = √(5² + 9²) = √106 ≈ 10.3cm
  1. 展开方式3（前面+顶面+右面或其他组合）：
  • 水平距离 = 5 + 6 = 11cm
  • 垂直距离 = 3cm
  • 直线距离 = √(11² + 3²) = √130 ≈ 11.4cm

关键结论：
比较三种展开方式，展开方式1得到最短距离10cm，因此答案为10cm。

教学建议：

  • 逐一展示每种展开方式，让学生理解"展开"的几何意义
  • 强调：展开后A、F两点间的直线距离即为该展开方式下的最短表面距离
  • 引导学生思考：为什么需要比较多种展开方式？（因为不同展开路径对应不同表面路线）
  • 总结解题步骤：确定起点终点→选择展开方式→计算直线距离→比较得出最短

完整解答：
从长方体表面点A到点F的最短距离为 10cm。
