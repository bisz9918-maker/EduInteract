[分步序列]
- 步骤 0（初始）：空白画布，仅显示标题"长方体表面最短路径问题"和控件栏（上一步禁用）
- 步骤 1：绘制长方体线框（所有 12 条棱），可见棱实线黑色，不可见棱虚线灰色
- 步骤 2：标注顶点标签 A、C、D、F、B、E，在对应顶点位置显示字母
- 步骤 3：标注已知长度，在棱 AC 下方显示"AC=5cm"，棱 CD 右侧显示"CD=3cm"，棱 DF 右侧显示"DF=6cm"，标注文字绿色
- 步骤 4：高亮起点 A（蓝色外圈）和终点 F（红色外圈），强调路径起点和终点

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮：scene1-prev-btn，位于 (250,460)，点击返回上一步，步骤 0 时禁用
  - 下一步按钮：scene1-next-btn，位于 (670,460)，点击进入下一步，步骤 4 时禁用
  - 步骤指示器：scene1-step-indicator，位于 (400,465)，显示"步骤 X/4"
- 教师操作流程：
  1. 点击"下一步"展示长方体框架，讲解立体结构
  2. 点击"下一步"标注顶点，帮助学生识别各点位置
  3. 点击"下一步"标注已知长度，强调题目条件
  4. 点击"下一步"高亮起点终点，引出最短路径问题

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │                    长方体表面最短路径问题                    │
  │                                                             │
  │              ┌─────────────────────────────────┐            │
  │              │                                 │            │
  │              │         长方体线框图             │            │
  │              │      (透视效果，居中偏左)        │            │
  │              │                                 │            │
  │              │    A───────C                    │            │
  │              │   /       /|                    │            │
  │              │  E───────D |                    │            │
  │              │  |       | B                   │            │
  │              │  |       | /                   │            │
  │              │  └───────┘F                    │            │
  │              │                                 │            │
  │              └─────────────────────────────────┘            │
  │                                                             │
  │  [上一步]              步骤 X/4              [下一步]       │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  - 使用 SVG 绘制长方体线框，12 条棱分别用 polyline 元素
  - 可见棱：stroke="#000000" stroke-width="2"
  - 不可见棱：stroke="#888880" stroke-width="2" stroke-dasharray="5,5"
  - 状态机：currentStep 变量记录当前步骤 (0-4)
  - 每个步骤对应一个显示函数 showStep(n)，控制元素 visibility 属性
  - 按钮点击事件更新 currentStep 并调用 showStep
  - 上一步按钮在 step=0 时 disabled=true，下一步按钮在 step=4 时 disabled=true
  - 高亮效果：步骤 4 时给 A 点和 F 点添加外圈 circle，stroke-width=6，分别用蓝色和红色
- ID 命名规范：所有元素 ID 以 scene1- 为前缀，如 scene1-棱-AC、scene1-标签-A、scene1-prev-btn、scene1-next-btn、scene1-step-indicator
- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
