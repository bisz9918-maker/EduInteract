[分步序列]
- 步骤0（初始状态）：显示坐标系（x轴、y轴、原点O）、抛物线y²=2px、焦点F。等待教师点击"下一步"
- 步骤1：添加点A在抛物线上，绘制直线AF，标注∠AFx=60°（绿色角度弧+文字）。新增元素：点A(580,77)、直线AF、60°标注
- 步骤2：添加点N（A在y轴投影），绘制线段AN（灰色虚线）、线段ON。新增元素：点N(400,77)、线段AN、线段ON
- 步骤3：绘制以F为圆心、p/2为半径的圆，标注交点B。新增元素：圆（蓝色）、点B(475,207)
- 步骤4：绘制线段NB、OB，高亮△ONB（绿色填充20%），标注∠ONB=90°（绿色角度弧+文字）。新增元素：线段NB、线段OB、90°角度弧、90°文字标签、△ONB高亮填充

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：几何图形简单，SVG适合精确坐标绘制，无需额外依赖
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
```
┌─────────────────────────────────────────────────────────────┐
│                      图示区 800×500                          │
│                                                             │
│     y                                                       │
│     ↑                                                       │
│   N●───────●A                    抛物线 y²=2px              │
│    │       │                                              │
│    │       │                                              │
│    │       ●B                                             │
│     \     /                                               │
│      \   /                                                │
│       \ /                                                 │
│   O●───●────────────────────────────────→ x              │
│       F                                                   │
│              ● (圆)                                       │
│                                                             │
│                                                             │
│  ┌───────────────────────────────────────────────────────┐  │
│  │  ◀上一步          步骤 k/4           下一步▶         │  │
│  └───────────────────────────────────────────────────────┘  │
│                     控件栏 y=440~490                        │
└─────────────────────────────────────────────────────────────┘
```

- 关键实现要点：
  1. 状态机设计：使用变量currentStep(0-4)跟踪当前步骤，每个步骤对应一个显示元素集合
  2. 坐标计算：所有坐标基于原点O(400,250)计算，p=100，抛物线方程y=±√(200x)
  3. 点A坐标计算：由∠AFx=60°，直线AF斜率√3，联立抛物线方程得A(580,77)
  4. 点B坐标计算：B在AF上，FB=p/2=50，向量FB=50×(cos60°,sin60°)=(25,43.3)，B=F+(25,-43.3)=(475,207)
  5. 动画曲线：元素出现使用opacity从0到1的过渡动画，duration=300ms
  6. 事件绑定：按钮点击事件更新currentStep，重新渲染对应步骤的元素可见性
  7. ID命名规范：所有元素ID以"scene1-"为前缀，如scene1-axis-x、scene1-point-A、scene1-btn-next
  8. IIFE隔离：所有JS代码包裹在(function(){ ... })()中，避免全局污染

- SVG元素ID命名示例：
  - 坐标轴：scene1-axis-x、scene1-axis-y
  - 抛物线：scene1-parabola
  - 点：scene1-point-O、scene1-point-F、scene1-point-A、scene1-point-B、scene1-point-N
  - 线段：scene1-line-AF、scene1-line-AN、scene1-line-ON、scene1-line-NB、scene1-line-OB
  - 圆：scene1-circle
  - 角度弧：scene1-arc-60、scene1-arc-90
  - 高亮填充：scene1-highlight-ONB
  - 标签：scene1-label-O、scene1-label-F、scene1-label-A、scene1-label-B、scene1-label-N、scene1-label-60、scene1-label-90
  - 控件：scene1-btn-prev、scene1-btn-next、scene1-step-indicator

- 初始状态渲染：页面加载后自动渲染步骤0元素（坐标系、抛物线、原点O、焦点F），currentStep=0，"上一步"按钮禁用
