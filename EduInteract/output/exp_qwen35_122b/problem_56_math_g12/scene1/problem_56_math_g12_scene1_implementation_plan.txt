[图示主题与整合说明]
- 本图示主题：圆与正六边形的无限嵌套构造
- 整合的步骤/概念：展示"圆→内接正六边形→内切圆→内接正六边形→内切圆"的完整嵌套过程，揭示半径递推关系 R_{n+1} = R_n × √3/2
- 教学价值：教师可逐步演示嵌套构造过程，帮助学生理解几何递推关系，为后续求无穷等比数列和做铺垫

[分步序列]
- 步骤0（初始状态）：
  - 显示：圆心O、第1个圆C1、半径线R1、标签O、标签R₁=1m

  - 说明：展示最外层圆，半径=1m，作为构造起点

- 步骤1：
  - 新增：正六边形H1、顶点标签A₁~A₆
  - 高亮：H1的6条边用绿色#2e7d32
  - 说明：在C1内作内接正六边形，顶点在圆周上

- 步骤2：
  - 新增：第2个圆C2、半径线R2、标签R₂
  - 高亮：C2用绿色#2e7d32
  - 说明：作正六边形H1的内切圆C2，与H1各边相切

- 步骤3：
  - 新增：正六边形H2、顶点标签B₁~B₆
  - 高亮：H2的6条边用绿色#2e7d32
  - 说明：在C2内作内接正六边形

- 步骤4：

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮（scene1-prev-btn）：位于底部左侧，点击返回前一步骤
  - 下一步按钮（scene1-next-btn）：位于底部右侧，点击进入下一步骤
  - 步骤指示器：显示当前步骤"步骤 X/5"
- 教师操作流程：
  1. 从步骤0开始，先讲解最外层圆的半径
  2. 点击"下一步"，展示内接正六边形，讲解顶点在圆周上的关系
  3. 点击"下一步"，展示内切圆，讲解内切圆半径与正六边形的关系
  4. 继续点击"下一步"，重复上述过程展示第二层嵌套
  5. 到达步骤5，高亮所有圆，引导学生发现半径递推规律 R_{n+1} = R_n × √3/2
  6. 可随时点击"上一步"回退复习某个步骤的几何关系

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形（圆、多边形、线段）用 SVG 绘制最精确，无需额外库
  - 动画和状态切换用原生 JS 实现，轻量高效

- 画布尺寸：800 × 500 px

- 布局草图（ASCII）：
```

└─────────────────────────────────────────────────────────────┘
```

- 关键实现要点：
  1. 状态机设计：用变量 currentStep 记录当前步骤（0-5），每一步定义 showElements 和 hideElements 数组
  2. 坐标计算：
     - 圆心：(400, 250)
     - 正六边形顶点：对于半径 r，第 i 个顶点坐标为 (400 + r×cos(θ), 250 + r×sin(θ))，θ = i×60° - 90°（从顶部开始）
     - 注意 SVG 坐标系 y 轴向下，角度从正 x 轴逆时针计算
  3. 元素显示/隐藏：用 CSS display 或 opacity 控制，避免重新渲染
  4. 高亮效果：当前步骤新增元素添加 class="highlight"，用 stroke="#2e7d32" 和 stroke-width="3"
  5. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateScene() 刷新显示
  6. 边界检查：步骤0时禁用"上一步"按钮，步骤5时禁用"下一步"按钮

- ID 命名规范：
  - 所有元素 ID 以 scene1- 为前缀
  - 圆：scene1-circle-1, scene1-circle-2, scene1-circle-3
  - 六边形：scene1-hex-1, scene1-hex-2
  - 半径线：scene1-radius-1, scene1-radius-2, scene1-radius-3
  - 标签：scene1-label-O, scene1-label-R1, scene1-label-R2, scene1-label-R3
  - 顶点标签：scene1-vertex-A1~A6, scene1-vertex-B1~B6
  - 按钮：scene1-prev-btn, scene1-next-btn
  - 指示器：scene1-step-indicator

- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染
