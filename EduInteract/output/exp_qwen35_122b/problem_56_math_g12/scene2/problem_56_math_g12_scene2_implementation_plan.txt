[分步序列]
- 步骤 0（初始状态）：
  - 显示：第 1 个圆（黑色）、正六边形边 AB（黑色）、圆心 O（红色点 + 标签）、顶点 A（黑色点 + 标签）、顶点 B（黑色点 + 标签）
  - 隐藏：垂线段 OM、半径 OA、直角符号、角度弧线、所有公式文本
  - 目的：展示题目基础条件——圆及其内接正六边形

- 步骤 1（点击"下一步"）：
  - 新增显示：半径 OA（蓝色）、垂线段 OM（蓝色）、垂足 M（黑色点 + 标签）、直角符号（红色）
  - 新增标签：R₁（在 OA 旁）、R₂（在 OM 旁）
  - 目的：展示从圆心向正六边形一边作垂线，形成直角三角形 OAM

- 步骤 2（点击"下一步"）：
  - 新增显示：角度弧线（绿色）、标签"∠AOM=30°"
  - 说明：正六边形中心角 60°，垂线平分中心角，故∠AOM=30°
  - 目的：标注关键角度，为三角函数计算做准备

- 步骤 3（点击"下一步"）：
  - 新增显示：公式文本"R₂ = R₁·cos30° = R₁·√3/2"
  - 高亮：OA 和 OM 线段加粗闪烁一次
  - 目的：展示三角函数关系推导

- 步骤 4（点击"下一步"，最终步骤）：
  - 新增显示：结论文本"公比 q=√3/2，面积公比 q²=3/4"
  - 高亮：整个三角形 OAM 边框闪烁
  - 目的：总结半径递推关系，引出等比数列

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（圆、线段、文本），无需复杂图表库；原生 SVG 便于精确控制坐标和样式；动画可通过 CSS transition 或 requestAnimationFrame 实现

- 画布尺寸：800 × 500 px（固定）

- 关键实现要点：
  1. 状态机设计：用变量 currentStep（0-4）记录当前步骤，updateScene() 函数根据 currentStep 控制元素显示/隐藏
  2. 坐标计算：
     - 圆心 O(400,220)，半径 R=120
     - A 点：角度 30°，坐标 (400+120·cos30°, 220-120·sin30°) ≈ (504,160)
     - B 点：角度 90°，坐标 (400+120·cos90°, 220-120·sin90°) ≈ (400,100)
     - 实际采用简化坐标：A(460,160), B(504,180), M 为 AB 中点 (482,170)
  3. 动画曲线：元素出现用 opacity 0→1 过渡（300ms ease-out），高亮用 stroke-width 变化 + 颜色闪烁
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateScene()
  5. 直角符号：用 SVG path 绘制 L 形，坐标基于 M 点偏移

- ID 命名规范：
  - 所有交互元素 ID 前缀：scene2-
  - 示例：scene2-circle-main, scene2-line-oa, scene2-line-om, scene2-label-o, scene2-btn-prev, scene2-btn-next
  - JS 中使用 getElementById('scene2-xxx') 获取元素

- IIFE 隔离：
```javascript
(function() {
    'use strict';
    // 所有代码包在此 IIFE 中
    const currentStep = 0;
    // ... 其他变量和函数
})();
```

- 元素显示控制：
  - 步骤 0：显示 circle-main, line-ab, circle-o, circle-a, circle-b, label-o, label-a, label-b
  - 步骤 1：+ 显示 line-oa, line-om, circle-m, label-m, label-r1, label-r2, rect-symbol
  - 步骤 2：+ 显示 arc-angle, label-angle
  - 步骤 3：+ 显示 text-formula
  - 步骤 4：+ 显示 text-conclusion

- 按钮状态：
  - 步骤 0：prev 禁用，next 启用
  - 步骤 1-3：prev 启用，next 启用
  - 步骤 4：prev 启用，next 显示"完成"或禁用
