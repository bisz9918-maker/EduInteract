[分步序列]
- 步骤0（初始状态）：
  - 显示：平面M（淡灰平行四边形）、点P、点O、点A
  - 显示：线段PO（虚线垂线）、线段PA（实线斜线）
  - 显示：线段OA（虚线辅助线）
  - 显示：标签P、O、A、M、α（∠APO处）、垂直符号⊥
  - 隐藏：点B、线段PB、线段OB、线段AB、β标签、圆锥面、截线

- 步骤1（引入动直线）：
  - 新增：点B（在平面M上，PB与平面交点）
  - 新增：线段PB（实线，从P到B）
  - 新增：线段OB、线段AB（平面内虚线辅助线）
  - 新增：β标签（∠APB处）
  - 显示：β角度弧（标注∠APB）
  - 教师讲解：说明PB是过P点的动直线，B是动点

- 步骤2（形成圆锥面）：
  - 新增：圆锥面（以P为顶点、PA为轴、β为半顶角的圆锥）
  - 圆锥面用半透明蓝色填充，显示旋转轨迹
  - 点B沿圆锥母线移动（动画效果）
  - 教师讲解：PB绕PA旋转形成圆锥面，B点在圆锥母线上

- 步骤3（平面截圆锥）：
  - 新增：截线（平面M与圆锥的交线，用粗红色椭圆高亮）
  - 截线显示在平面M上，与圆锥相交
  - 点B沿截线轨迹移动（动画）
  - 教师讲解：平面M截圆锥得到截线，B点轨迹即为此截线

- 步骤4（轨迹类型对比）：
  - 显示：四种不同α+β条件下的截线类型对比图（小型缩略图或文字说明）
  - ① α=0°, β=90° → 圆
  - ② α≠0°, β=90° → 直线
  - ③ α+β=90° → 抛物线
  - ④ α+β>90° → 椭圆
  - ⑤ α+β<90° → 双曲线
  - 当前场景高亮显示与题目条件匹配的结论
  - 教师讲解：总结圆锥截面分类规律

- "α"(370,180)与"β"(450,200)：水平距离80px，垂直距离20px → 无冲突（对角分布）
- "α"(370,180)与"O"(410,305)：垂直距离125px → 无冲突
- "β"(450,200)与"B"(495,345)：垂直距离145px → 无冲突
- "O"(410,305)与"⊥"(405,290)：距离约16px → 接近但可接受（不同含义）
- "O"(410,305)与"A"(265,325)：水平距离145px → 无冲突
- "O"(410,305)与"B"(495,345)：水平距离85px → 无冲突
- "A"(265,325)与"B"(495,345)：水平距离230px → 无冲突
- "B"(495,345)与"M"(660,350)：水平距离165px → 无冲突

结论：所有标签间距均≥16px，无重叠冲突。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 按钮"◀ 上一步"：位置(250,455)，作用：返回上一状态，可复习前序步骤
  - 按钮"下一步 ▶"：位置(450,455)，作用：进入下一状态，推进演示
  - 步骤指示器：位置(350,455)，显示"步骤 k/4"，作用：显示当前进度
- 教师操作流程：
  1. 从步骤0开始，讲解基础空间几何模型（PO⊥M，PA为斜线）
  2. 点击"下一步"进入步骤1，引入动直线PB和动点B
  3. 点击"下一步"进入步骤2，展示圆锥面形成过程
  4. 点击"下一步"进入步骤3，展示平面截圆锥得到截线
  5. 点击"下一步"进入步骤4，总结轨迹类型分类规律
  6. 可随时点击"上一步"回退复习关键概念

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形（线段、圆、多边形、路径）用 SVG 绘制最清晰，动画用 CSS transition 和 JS 控制状态即可，无需重型库
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │  800px                                                  │
  │                                                         │
  │           P(400,80)                                     │
  │            │                                            │
  │            │ PO(虚线)                                   │
  │            │                                            │
  │      A─────┼─────B    ← 平面M上的点                     │
  │     /      │      \                                     │
  │    /       │       \   ← 圆锥面（步骤2）                │
  │   /    O   │        \                                  │
  │  /    ●────┼────────● B                                │
  │ /   /      │        /                                  │
  │────┴───────────────┴──────── 平面M（淡灰平行四边形）    │
  │   A(280)  O(400)  B(480)                               │
  │                                                         │
  │  ┌─────────────────────────────────────────────────┐   │
  │  │  ◀ 上一步    步骤 k/4    下一步 ▶              │   │
  │  │  (250,455)   (350,455)   (450,455)             │   │
  │  └─────────────────────────────────────────────────┘   │
  │                                                         │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-4) 跟踪当前步骤，updateScene() 函数根据 currentStep 显示/隐藏对应元素
  2. 坐标计算：所有元素坐标硬编码在 plan 中，SVG 元素用绝对坐标
  3. 动画曲线：圆锥面形成用 CSS transition（opacity 0.5s ease），点B移动用 requestAnimationFrame 实现平滑轨迹
  4. 事件绑定：按钮点击事件绑定到 scene1-prevBtn 和 scene1-nextBtn，阻止默认行为
  5. ID 命名规范：所有元素 ID 以"scene1-"为前缀（如 scene1-pointP、scene1-linePO、scene1-coneSurface）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 元素显示控制：用 class="hidden" 和 class="visible" 控制元素显示/隐藏，配合 CSS transition 实现淡入淡出
  8. 截线动画：步骤3-4中，点B沿椭圆轨迹移动用参数方程 x = cx + rx*cos(t), y = cy + ry*sin(t)
