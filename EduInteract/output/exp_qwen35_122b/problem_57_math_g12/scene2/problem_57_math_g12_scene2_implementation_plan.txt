[分步序列]
本场景为连续拖拽滑块交互，无分步导航，状态由滑块位置动态决定：

- 初始状态：α=30°，β=45°，α+β=75°＜90°，显示双曲线
  - 三维图：圆锥截面显示双曲线形状
  - 俯视图：显示双曲线 2D 投影
  - 类型标签：显示"双曲线"（红色#c62828）
  
- 拖动α滑块（0°-60°）：
  - α从 30°增加到 45°，α+β=90°，截线变为抛物线
  - α继续增加到 60°，α+β=105°＞90°，截线变为椭圆
  - 曲线形状平滑过渡，颜色相应变化
  
- 拖动β滑块（30°-90°）：
  - β从 45°减小到 30°，α+β=60°＜90°，保持双曲线但开口变化
  - β增加到 60°，α+β=90°，截线变为抛物线
  - β继续增加到 90°，α+β=120°＞90°，截线变为椭圆
  - 特殊情形β=90°时高亮显示"直线"情形（若α=0°则为圆）

- 特殊情形自动高亮：
  - α=0°：显示"圆"情形（绿色#2e7d32）
  - β=90°且α≠0°：显示"直线"情形（黑色）
  - α+β=90°：显示"抛物线"情形（蓝色#1565c0）
  - α+β＞90°：显示"椭圆"情形（蓝色#1565c0）
  - α+β＜90°：显示"双曲线"情形（红色#c62828）

[交互方案]
- 交互类型：连续拖拽滑块（两个滑块：α和β）
- 控件说明：
  1. α滑块：位置 (560,250)-(760,250)，范围 0°-60°，初始值 30°
     - 作用：调节∠APO 角度，改变圆锥轴线与截面平面的夹角
  2. β滑块：位置 (560,310)-(760,310)，范围 30°-90°，初始值 45°
     - 作用：调节∠APB 角度，改变动直线 PB 与斜线 PA 的夹角
  3. 数值显示区：实时显示α、β、α+β的当前值及对应的曲线类型
- 教师操作流程：
  1. 初始展示α=30°、β=45°的双曲线情形
  2. 拖动α滑块，让学生观察α+β从 75°→90°→105°时截线从双曲线→抛物线→椭圆的变化
  3. 拖动β滑块，让学生观察β变化对截线类型的影响
  4. 特别演示α=0°（圆）和β=90°（直线）的特殊情形
  5. 引导学生总结圆锥曲线分类的判定条件：α+β与 90°的大小关系

- 画布尺寸：800 × 500 px（固定）

- 关键实现要点：
  1. 状态机设计：
     - 状态变量：alpha（0-60）、beta（30-90）
     - 派生变量：sum = alpha + beta
     - 曲线类型判定：
       * alpha === 0 → "圆"
       * beta === 90 && alpha !== 0 → "直线"
       * sum === 90 → "抛物线"
       * sum > 90 → "椭圆"
       * sum < 90 → "双曲线"
  
  2. 截线绘制算法：
     - 双曲线：根据α+β计算渐近线角度，绘制两支曲线
     - 抛物线：根据α+β计算开口大小，绘制单支抛物线
     - 椭圆：根据α+β计算长短轴，绘制椭圆
     - 圆：固定半径圆
     - 直线：根据β=90°绘制直线
  
  3. 坐标计算：
     - 三维图截线：使用透视投影将 3D 截线投影到 2D 画布
     - 俯视图截线：直接使用 2D 曲线坐标
  
  4. 动画曲线：滑块拖动时使用 requestAnimationFrame 平滑更新
  
  5. 事件绑定：
     - mousedown/mousemove/mouseup 实现滑块拖拽
     - touchstart/touchmove/touchend 支持移动端
  
  6. ID 命名规范：所有交互元素 ID 以"scene2-"为前缀
     - scene2-cone-vertex（圆锥顶点）
     - scene2-section-curve（截线）
     - scene2-alpha-slider（α滑块手柄）
     - scene2-beta-slider（β滑块手柄）
     - scene2-alpha-value（α数值显示）
     - scene2-beta-value（β数值显示）
     - scene2-sum-value（α+β数值显示）
     - scene2-curve-type（曲线类型标签）
  
  7. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
