[分步序列]
- 步骤 0（初始状态）：
  - 显示：球体轮廓（实线前半+虚线后半）、球心 O、标签"O"、标签"R=3"
  - 隐藏：截面圆、A/B/C 三点、所有线段、所有其他标签
  - 目的：建立球体基本框架

- 步骤 1：
  - 新增：截面圆（椭圆，前半实线后半虚线，15% 蓝色填充）、截面圆中心点、垂线 OD、标签"d=3√2/2"
  - 保留：步骤 0 所有元素
  - 目的：展示球心到截面平面的距离关系

- 步骤 2：
  - 新增：点 A、B、C、线段 AB、BC、AC、直角标记、标签"A"、"B"、"C"、标签"∠ABC=90°"
  - 保留：步骤 0-1 所有元素
  - 目的：展示△ABC 在截面圆上的位置及直角关系

- 步骤 3：
  - 新增：等长标记 AB、等长标记 BC、标签"BA=BC"、标签"r=3√2/2"
  - 高亮：截面圆半径计算过程（在标签旁显示公式 r = √(R²-d²) = √(9-9/2) = 3√2/2）
  - 保留：步骤 0-2 所有元素
  - 目的：强调等腰直角三角形性质及截面圆半径计算

- 步骤 4（最终步骤）：
  - 高亮：线段 BC、标签"BC=3"（在 BC 线段上方显示计算过程）
  - 显示：球面距离公式提示（在底部显示"s = R×θ，θ为圆心角"）
  - 保留：步骤 0-3 所有元素
  - 目的：引导计算 B、C 球面距离（BC=3，截面圆半径 r=3√2/2，∠BOC=90°，球面距离=3π/2）

- 标签"O"：(415,245)
- 标签"A"：(310,225)
- 标签"B"：(265,315)
- 标签"C"：(535,315)
- 标签"R=3"：(590,180)

- 标签"∠ABC=90°"：(295,280)

冲突检查：
- "O"(415,245) 与 "d=3√2/2"(420,265)：间距≈20px → 无冲突（垂直方向错开）
- "A"(310,225) 与 "∠ABC=90°"(295,280)：间距≈55px → 无冲突
- "B"(265,315) 与 "∠ABC=90°"(295,280)：间距≈42px → 无冲突
- "B"(265,315) 与 "BA=BC"(380,330)：间距≈116px → 无冲突
- "C"(535,315) 与 "r=3√2/2"(560,275)：间距≈47px → 无冲突
- "d=3√2/2"(420,265) 与 "r=3√2/2"(560,275)：间距≈141px → 无冲突
- "R=3"(590,180) 与其他所有标签间距均>100px → 无冲突

结论：所有标签间距≥20px，无冲突。

  6. 可随时点击"上一步"回顾关键步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（圆、椭圆、线段、点），原生 SVG 足够且性能好，无需额外库依赖
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    [图示区 800×500]                     │
  │                                                         │
  │              球体轮廓（圆，半径 180，居中）              │
  │                    ● O (400,250)                       │
  │                                                         │
  │         A(320,240)        截面圆椭圆                    │
  │           ●━━━━━━━━━━━━━━●━━━━━━━━━━━━●               │
  │          /                  \          \               │
  │         /                    \          \              │
  │        ● B(280,300)━━━━━━━━━━●━━━━━━━━━━● C(520,300)  │
  │                                                         │
  │                                                         │
  │  ┌─────────────────────────────────────────────────┐   │
  │  │  ◀ 上一步        步骤 k/4         下一步 ▶      │   │
  │  │  (280,460)                   (500,460)          │   │
  │  └─────────────────────────────────────────────────┘   │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-4) 跟踪当前步骤，每一步定义显示/隐藏的元素 ID 列表
  2. 坐标计算：所有元素坐标硬编码在布局表中，SVG 元素用绝对坐标
  3. 动画曲线：元素出现用 opacity 从 0 到 1 的过渡动画（0.3s ease-in-out）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateScene() 刷新显示
  5. ID 命名规范：所有元素 ID 以"scene1-"为前缀（如 scene1-sphere, scene1-point-A, scene1-btn-next）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 元素层级：球体轮廓在最底层，截面圆在中间，点和线段在上层，标签在最顶层
  8. 虚线实现：SVG stroke-dasharray 属性实现虚线效果
  9. 椭圆实现：SVG <ellipse>元素，cx/cy 为中心，rx/ry 为长短轴半径
  10. 填充透明度：截面圆用 fill-opacity="0.15"实现 15% 透明度
