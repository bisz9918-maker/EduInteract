[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 按钮"◀ 上一步"：位置(220,460)，作用：返回上一步骤，可复习之前内容
  - 按钮"下一步 ▶"：位置(480,460)，作用：进入下一步骤，展示新内容
  - 步骤指示器：位置(350,460)，显示"步骤 1/5"格式
- 教师操作流程：
  1. 初始展示球体和基本点线结构
  2. 点击"下一步"标注半径和弦长数值
  3. 点击"下一步"展示等边三角形判定
  4. 点击"下一步"显示球心角计算
  5. 点击"下一步"展示球面距离公式应用，得到最终答案π
  教师可随时点击"上一步"回退复习，配合讲解每个推导环节

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（几何图形简单，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │                        图示区 800×500                          │
  │                                                                │
  │     ┌────────────────────────────────────────────┐            │
  │     │                                            │            │
  │     │           球体 (居中偏左)                   │   公式区   │
  │     │         ┌──────────────┐                   │  (右侧)    │
  │     │        /    △BOC       \                  │            │
  │     │       |   O(球心)        |                 │ ∠BOC=60°   │
  │     │       |    /    \        |                 │ s=R·θ=π    │
  │     │       |   B------C       |                 │            │
  │     │        \              /                   │            │
  │     │         └──────────────┘                   │            │
  │     │                                            │            │
  │     └────────────────────────────────────────────┘            │
  │                                                                │
  │     ┌────────────────────────────────────────────────────┐    │
  │     │     ◀ 上一步      步骤 1/5       下一步 ▶           │    │
  │     └────────────────────────────────────────────────────┘    │
  └────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep 记录当前步骤(0-4)，每一步定义 showElements 和 hideElements 数组
  2. 坐标计算：OB 与 OC 对称，B(220,320)、C(380,320)，O(300,250)，BC 水平长度 160px（投影后）
  3. 球面距离弧：用贝塞尔曲线模拟，控制点(300,380)使曲线向下凸出
  4. 球心角弧线：SVG path 用 arc 命令，从 OB 方向到 OC 方向
  5. 事件绑定：按钮点击事件更新 currentStep，调用 updateScene() 刷新显示
  6. 等边标记：三边中点处画短线段，垂直于对应边
- ID 命名规范：所有交互元素 ID 以 scene2- 为前缀（如 scene2-btn-prev、scene2-btn-next、scene2-step-indicator）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局污染
