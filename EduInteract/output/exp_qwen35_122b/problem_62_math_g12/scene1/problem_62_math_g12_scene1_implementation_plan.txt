[图示主题与整合说明]
- 本图示主题：四面体 ABCD 中平面 α 绕 EF 旋转的动态几何演示
- 整合的内容：四面体空间结构、中点连线 EF、平面 α 与棱的交点 G/H 运动轨迹、几何约束关系
- 教学价值：教师可通过拖动滑块展示平面 α 绕 EF 轴旋转的全过程，帮助学生直观理解：
  1) 平面 α 的任意性（可绕 EF 连续旋转）
  2) G、H 分别在 BC、AD 上的运动规律
  3) 验证题目中四个结论的正确性（通过观察 G、H 位置关系）

[分步序列]
本场景采用连续拖拽滑块交互，无分步导航，状态随滑块连续变化：

- 初始状态（滑块=0）：
  - 显示完整四面体 ABCD 框架
  - E、F 中点标注（蓝色圆点）
  - EF 连线（蓝色加粗）
  - 平面 α 处于初始位置：G 靠近 B 点，H 靠近 A 点
  - 平面 α 四边形 EG-FH 显示（红色半透明）

- 滑块拖动过程（0→100）：
  - G 点沿 BC 从 B 向 C 移动（参数化：G = B + t×(C-B)，t∈[0,1]）
  - H 点沿 AD 从 A 向 D 移动（参数化：H = A + t×(D-A)，t∈[0,1]）
  - 平面 α 四边形实时重绘，保持 E-G-F-H 顺序
  - 数值显示实时更新当前角度值

- 极端位置观察：
  - 滑块=0：G 接近 B，H 接近 A，平面 α 接近侧面 ABD
  - 滑块=50：G 接近 BC 中点，H 接近 AD 中点，平面 α 穿过四面体中心
  - 滑块=100：G 接近 C，H 接近 D，平面 α 接近侧面 ACD

[交互方案]
- 交互类型：连续拖拽滑块（单滑块控制平面 α 旋转角度）
- 控件说明：
  1. 滑块 input[type=range]：id="scene1-slider"，位置 (200,460)-(600,480)，范围 0-100
  2. 数值显示 text：id="scene1-value"，位置 (620,460)，实时显示当前角度值（0-100）
  3. 说明文字 text：id="scene1-label"，位置 (200,440)，显示"平面 α 旋转角度"
- 教师操作流程：
  1. 初始展示四面体结构，强调 E、F 为中点
  2. 拖动滑块从 0 到 100，观察 G、H 在 BC、AD 上的同步运动
  3. 停在中间位置（滑块=50），讲解此时平面 α 穿过四面体中心
  4. 对比极端位置，引导学生思考题目中四个结论的正确性
  5. 可反复拖动，验证"对于任意平面 α"的命题是否成立

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（几何计算简单，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    四面体 ABCD 图示区                    │
  │                                                         │
  │                    A(400,80)                            │
  │                   /  |  \                              │
  │                  /   |   \                             │
  │             E●--/----+----\--●H (动态)                  │
  │            (275,215)  |     \                          │
  │              /        |      \                         │
  │             /     平面α      \                          │
  │            /   (红色半透明)    \                         │
  │      B●--/-------●G(动态)------\--●D                    │
  │    (150,350)  (BC 上)            (650,350)               │
  │           \      /    \      /                          │
  │            \    /      \    /                           │
  │             \  /        \  /                            │
  │              ●F(525,385)                                │
  │             C(400,420)                                  │
  │                                                         │
  │  控件区：平面 α 旋转角度 [████████░░░░░░░░░░] 50        │
  │         (200,440)        (200-600,460)   (620,460)     │
  └─────────────────────────────────────────────────────────┘
  ```

- 关键实现要点：
  1. 状态机设计：单一状态变量 t∈[0,1] 控制滑块位置，G、H 坐标由 t 参数化计算
  2. 坐标计算：
     - G = (1-t)×B + t×C = (150+250t, 350+70t)
     - H = (1-t)×A + t×D = (400+250t, 80+270t)
  3. 平面 α 四边形顶点顺序：E→G→F→H，使用 SVG polygon 元素
  4. 事件绑定：slider 的 input 事件触发重绘，实时更新 G、H 位置和数值显示
  5. 虚线实现：BD 棱使用 stroke-dasharray="5,5"
  6. 半透明填充：polygon 的 fill 属性使用 rgba 或 opacity 属性

- ID 命名规范：所有元素 ID 以 "scene1-" 为前缀
  - 四面体顶点：scene1-vertex-A/B/C/D
  - 棱线：scene1-edge-AB/AC/AD/BC/BD/CD
  - 中点：scene1-point-E/F
  - 动点：scene1-point-G/H
  - EF 连线：scene1-line-EF
  - 平面边界：scene1-line-EG/scene1-line-GF/scene1-line-FH/scene1-line-HE
  - 平面填充：scene1-polygon-alpha
  - 控件：scene1-slider/scene1-value/scene1-label
  - 标签文字：scene1-label-A/B/C/D/E/F/G/H/alpha

- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
