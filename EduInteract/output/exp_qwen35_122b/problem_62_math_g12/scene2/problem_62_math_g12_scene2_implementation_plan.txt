[视觉元素清单]

- 步骤 1 元素（三线共点）：

  - 交点 P(425,340)：#c62828 实心圆，半径 5px

[分步序列]
- 步骤 0（初始状态）：
  - 显示：四面体 ABCD（所有棱线）、点 E、F、线段 EF、点 G、H
  - 隐藏：GF、EH、BD 延长线、交点 P、三角形填充、结论判定
  - 标签：A、B、C、D、E、F、G、H 显示

- 步骤 1（验证①三线共点）：
  - 新增：直线 GF、EH、BD 的延长线（#c62828 虚线）
  - 新增：交点 P(425,340)（#c62828 实心圆）
  - 高亮：GF、EH、BD 三条线
  - 标签：显示"①三线共点"及判定✓
  - 说明：三条直线延长后交于同一点 P

- 步骤 2（验证②平行情况）：
  - 切换：G 移动至 BC 延长线上特定位置，H 移动至 AD 延长线上特定位置
  - 变化：GF、EH、BD 变为#2e7d32 加粗实线
  - 新增：平行标记// 在三条线上
  - 隐藏：交点 P 及红色虚线
  - 标签：显示"②平行情况"及判定✓
  - 说明：存在特殊平面α₀使 GF∥EH∥BD

- 步骤 3（验证④面积相等）：
  - 新增：△EFG 填充（#1565c0，opacity=0.25）
  - 新增：△EFH 填充（#2e7d32，opacity=0.25）
  - 新增：面积标注"S△EFG = S△EFH"
  - 标签：显示"④面积相等"及判定✓
  - 说明：两个三角形面积相等

- 步骤 4（结论汇总）：
  - 显示：所有四个结论的判定结果
  - ①✓ ②✓ ③✗ ④✓
  - 高亮：正确结论用绿色✓，错误结论用红色✗
  - 说明：总结四个结论的真假判断

[交互方案]
- 交互类型：分步按钮导航（◀ 上一步 / 下一步 ▶）
- 控件说明：
  - "◀ 上一步"按钮：位于 (250, 455)，返回上一状态
  - "下一步 ▶"按钮：位于 (450, 455)，进入下一状态
  - 共 5 个状态（步骤 0-4），步骤 0 时"上一步"禁用，步骤 4 时"下一步"禁用
- 教师操作流程：
  1. 初始展示四面体基本结构
  2. 点击"下一步"展示三线共点现象
  3. 点击"下一步"展示平行特殊情况
  4. 点击"下一步"展示面积相等关系
  5. 点击"下一步"汇总所有结论判定
  6. 可随时点击"上一步"回退复习

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形绘制简单，SVG 适合精确坐标定位和样式控制，无需额外依赖
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    800 × 500 SVG 画布                    │
  │                                                         │
  │        A(400,80)                                        │
  │       /  \  \                                           │
  │      /    \  \                                          │
  │   E(275,215)  H(500,240)                                │
  │    /    \    /  \                                       │
  │   /      \  /    \                                      │
  │ B(150,350)──G(250,365)  F(475,360)──D(600,320)          │
  │           \    /    \                                   │
  │            \  /      \                                  │
  │            C(350,400)                                   │
  │                                                         │
  │  左侧标签区：①三线共点  ②平行情况  ④面积相等            │
  │  右侧标签区：S△EFG=S△EFH  ✓  ✗                         │
  │                                                         │
  │  ┌─────────────────────────────────────────────────┐   │
  │  │      ◀ 上一步          下一步 ▶                  │   │
  │  │      (250,455)        (450,455)                  │   │
  │  └─────────────────────────────────────────────────┘   │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用 currentStep 变量跟踪当前步骤（0-4），updateScene() 函数根据 currentStep 显示/隐藏对应元素
  2. 坐标计算：所有元素坐标硬编码在配置对象中，便于维护和修改
  3. 动画曲线：步骤切换使用 SVG 元素的 opacity 过渡（transition: opacity 0.3s ease）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateScene()
  5. ID 命名规范：所有元素 ID 以 scene2- 为前缀（如 scene2-vertex-a、scene2-edge-ab、scene2-prev-btn）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 虚线样式：被遮挡棱线和延长线使用 stroke-dasharray="5,5"
  8. 半透明填充：三角形使用 fill-opacity="0.25"
