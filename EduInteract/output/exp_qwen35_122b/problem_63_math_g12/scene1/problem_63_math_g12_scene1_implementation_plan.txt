[分步序列]
- 步骤 0（初始状态）：显示坐标系（x 轴、y 轴）、双曲线（左右两支）、圆、原点 O 标签。等待教师触发交互。
- 步骤 1：添加焦点 F（红色圆点）及其标签，显示在 x 轴正半轴 (520, 250)。
- 步骤 2：添加切线 l（黑色实线）、切点 M（蓝色圆点）及其标签，显示直角标记（OM⊥l），添加线段 OM（灰色虚线）。
- 步骤 3：添加交点 P（绿色圆点）及其标签，显示线段 PF（灰色虚线），添加中点标记（M 为 PF 中点）。
- 结论步骤：高亮关键几何关系——用红色加粗显示直角标记和中点标记，所有元素完整呈现，教师可讲解双曲线渐近线方程的推导。

冲突检查：
- "O"与"F"：水平距离 145px → 无冲突
- "O"与"M"：距离约 85px → 无冲突
- "M"与"P"：距离约 55px → 无冲突
- "M"与"l"：距离约 30px → 无冲突（"l"在直线旁，"M"在切点旁）
- "P"与"l"：距离约 20px → 无冲突（"l"标签在直线上方，"P"在交点旁）
- "双曲线"与"圆"：垂直距离 20px → 无冲突（图例区域紧凑排列）
- "y"与"双曲线"：距离约 10px → 轻微接近，"y"标签微调至 (380, 105) → 无冲突

解决方案：所有标签间距均 ≥ 20px，无重叠风险。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "上一步"按钮：位于 SVG 底部左侧 (100, 460)，80×30px，灰色背景，点击回退到前一步骤
  - "下一步"按钮：位于 SVG 底部右侧 (620, 460)，80×30px，蓝色背景，点击前进到下一步骤
  - 步骤指示器：位于 SVG 底部中央 (350, 465)，显示"步骤 1/4"，黑色文字
- 教师操作流程：
  1. 初始展示双曲线和圆的基础图形，讲解双曲线定义和圆的方程
  2. 点击"下一步"添加焦点 F，讲解焦点坐标与 a、b、c 的关系
  3. 点击"下一步"添加切线 l 和切点 M，讲解圆的切线性质（OM⊥l）
  4. 点击"下一步"添加交点 P 和中点关系，讲解 M 为 PF 中点的几何意义
  5. 结论步骤高亮关键关系，引导学生推导渐近线方程 y = ±(b/a)x

- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-4) 跟踪当前步骤，每一步控制元素的 display 属性
  2. 坐标计算：所有元素坐标基于原点 (400, 250) 计算，x 轴向右为正，y 轴向下为负（SVG 坐标系需翻转 y）
  3. 双曲线绘制：使用 path 元素，根据方程 x²/a² - y²/b² = 1 计算点坐标（取 a=40, b=70 近似绘制）
  4. 圆绘制：使用 circle 元素，cx=400, cy=250, r=70
  5. 直线 l：根据 F(520,250) 和 M(455,195) 计算斜率，延伸至 P 点
  6. 事件绑定：按钮点击事件更新 currentStep，重新渲染对应步骤的元素
  7. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-axis-x, scene1-hyperbola-right, scene1-point-F）
  8. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染

- SVG 元素 ID 命名示例：
  - scene1-axis-x, scene1-axis-y
  - scene1-hyperbola-left, scene1-hyperbola-right
  - scene1-circle

  - scene1-btn-prev, scene1-btn-next, scene1-step-indicator

- 动画效果：步骤切换时使用 opacity 渐变（0→1），持续时间 300ms，ease-in-out 曲线
