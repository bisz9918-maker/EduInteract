problem_65_math_g12

场景导航：Scene 1

题目原文：
如图，已知 Rt△ABC 的两条直角边 AC，BC 的长分别为 6cm，8cm，以 AC 为直径的圆与 AB 交于点 D 则 BD=__cm．

题目分析：
这是一道结合圆与直角三角形的几何计算题。核心考点包括：

  1. 勾股定理：计算斜边 AB 的长度
  2. 圆的性质：直径所对圆周角为直角
  3. 相似三角形：利用相似比求解线段长度
  4. 切割线定理：作为替代解法

整体讲解思路：
本题的关键在于发现∠ADC=90°（直径 AC 所对圆周角），从而得到 CD⊥AB，进而利用相似三角形或切割线定理求解。

图示规划说明：
设计 1 个综合图示，通过分步导航展示：①题目基础图形→②添加圆与交点→③揭示关键垂直关系→④展示相似三角形→⑤完成计算。

完整解答：
方法一（相似三角形）：

  1. 由勾股定理：AB = √(AC² + BC²) = √(6² + 8²) = √100 = 10cm
  2. ∵ AC 为直径，∴ ∠ADC = 90°（直径所对圆周角为直角）
  3. ∴ CD⊥AB，△ABC ∽ △CBD（AA 相似：∠B 公共，∠C=∠CDB=90°）
  4. 由相似比：BC/AB = BD/BC ⇒ BD = BC²/AB = 8²/10 = 64/10 = 6.4cm

方法二（切割线定理）：
∵ BC 为圆的切线（∠ACB=90°，AC 为直径）
∴ BD·BA = BC² ⇒ BD = BC²/AB = 64/10 = 6.4cm

教学说明：

本图示通过分步导航完整呈现了解题的几何推理过程。教师应按以下步骤引导学生：

步骤 0-1 引导要点：
首先让学生观察已知条件：Rt△ABC 中 AC=6、BC=8，根据勾股定理可求得 AB=10。然后添加以 AC 为直径的圆，提问学生："圆与斜边 AB 的交点 D 有什么特殊性质？"

步骤 2-3 关键突破：
连接 CD 后，引导学生回忆圆周角定理："直径所对的圆周角是什么角？"学生应回答 90°。这是本题的核心突破点——发现 CD⊥AB。

步骤 4 相似识别：
高亮△ABC 与△CBD，引导学生寻找相似条件：

  • ∠B 为公共角
  • ∠ACB=∠CDB=90°

因此△ABC ∽ △CBD（AA 相似）

步骤 5 计算完成：
由相似比 BC/AB = BD/BC，得 BD = BC²/AB = 64/10 = 6.4cm

拓展思考：
可进一步介绍切割线定理作为替代解法：BC 为切线，故 BD·BA = BC²，同样得到 BD = 64/10 = 6.4cm。

易错点提醒：

  1. 学生可能忽略直径所对圆周角为直角这一关键性质
  2. 相似三角形对应边容易写错，需强调对应顶点顺序
  3. 计算时注意单位统一
