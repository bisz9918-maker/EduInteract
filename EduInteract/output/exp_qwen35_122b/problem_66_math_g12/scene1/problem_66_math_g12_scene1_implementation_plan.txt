[视觉元素清单]
- 三角形 ABC：三条线段 AB、BC、AC，黑色实线 2px
- 中线 AF：线段，黑色实线 2px
- 中位线 DE：线段，黑色实线 2px（步骤 5 后变为红色）
- 各顶点/中点：A、B、C、D、E、F、G、A'，4px 直径圆点
- 旋转后三角形 A'ED：线段 A'D、A'E，红色实线 2px

- 标签：A、B、C、D、E、F、G、A'、a、DE，16px 字体

[分步序列]
- 步骤 0（初始状态）：
  - 显示正三角形 ABC（边 AB、BC、AC）
  - 显示顶点 A、B、C 及其标签
  - 显示边长标注 "a"（在 AB 边外侧）
  - 等待教师点击「下一步」

- 步骤 1：
  - 新增中线 AF（黑色实线）
  - 新增中点 F 及其标签
  - AF 以蓝色高亮显示 0.5 秒后恢复黑色
  - 教师讲解：中线定义，F 是 BC 中点

- 步骤 2：
  - 新增中位线 DE（黑色实线）
  - 新增中点 D、E 及其标签
  - DE 以蓝色高亮显示 0.5 秒后恢复黑色
  - 教师讲解：中位线定义，DE 平行于 BC，DE = BC/2

- 步骤 3：
  - 新增交点 G（绿色填充圆点）
  - 新增标签 G（绿色）
  - 显示文字标注 "G 是 AF 中点"（在 G 点右侧）
  - 教师讲解：G 是 AF 与 DE 的交点，由于 DE 是中位线，G 平分 AF

- 步骤 4：
  - 高亮显示△AED（用浅蓝色填充，透明度 20%）
  - 教师讲解：这是将要绕 DE 旋转的部分

- 步骤 5：
  - 显示旋转后的点 A'（红色填充）
  - 显示旋转边 A'D、A'E（红色实线）
  - 显示标签 A'（红色）
  - DE 变为红色（强调旋转轴）
  - 显示标签 "DE"（红色，在 DE 上方）
  - 教师讲解：△AED 绕 DE 旋转得到△A'ED，DE 是旋转轴

- 步骤 6（最终状态）：
  - 显示旋转轨迹圆弧（灰色虚线，从 A 到 A'）
  - 教师讲解：A' 的轨迹是以 DE 为轴的圆弧，A' 在平面 ABC 上的射影在线段 AF 上（命题 1）

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 底部左侧 (50, 450)，灰色背景，点击返回上一状态
  - 「下一步」按钮：位于 SVG 底部右侧 (700, 450)，蓝色背景，点击进入下一状态
  - 步骤指示器：位于 SVG 底部中央 (350, 450)，显示 "步骤 k/6"
- 教师操作流程：
  1. 初始展示正三角形 ABC，引入题目背景
  2. 逐步添加中线 AF、中位线 DE，讲解几何元素定义
  3. 标出交点 G，说明 G 是 AF 中点
  4. 高亮△AED，说明这是旋转部分
  5. 展示旋转后的△A'ED，强调 DE 是旋转轴
  6. 显示旋转轨迹，引导学生判断四个命题的正确性

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（几何图形简单，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    图示区 800×500                       │
  │                                                         │
  │                    A(400,80)                            │
  │                   /│\                                   │
  │                  / │ \                                  │
  │                 /  │  \                                 │
  │            D---/---G---\---E                            │
  │           (275,140) (400,140) (525,140)                 │
  │          /     │      \     │      \                    │
  │         /      │       \    │       \                   │
  │        B-------F--------C                               │
  │      (150,200) (400,200) (650,200)                      │
  │                                                         │
  │              A'(400,40) [步骤 5 后显示]                  │
  │                 /│\                                    │
  │                / │ \                                   │
  │               /  │  \                                  │
  │              D---G---E                                 │
  │                                                         │
  │  ─────────────────────────────────────────────────────  │
  │  [上一步]                    步骤 k/6              [下一步]│
  │  (50,450)                  (350,450)                (700,450)│
  └─────────────────────────────────────────────────────────┘
  ```

- 关键实现要点：
  1. 状态机设计：用变量 currentStep 记录当前步骤（0-6），根据 currentStep 控制元素显示/隐藏
  2. 坐标计算：所有坐标已在布局坐标表中精确定义，直接硬编码
  3. 动画曲线：高亮效果使用 CSS transition，0.5s 淡入淡出
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后重绘
  5. ID 命名规范：所有元素 ID 以 "scene1-" 为前缀，如 scene1-line-ab、scene1-point-a、scene1-btn-next
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
