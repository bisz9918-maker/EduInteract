[分步序列]
本场景为连续滑块交互，无分步导航，状态随滑块连续变化：

- 初始状态（θ = 0°）：
  - A'位于初始位置 (235,120)，与 A 重合
  - 三棱锥 A'-FED 体积 V = 0（A'在底面所在平面）
  - 异面直线 A'E 与 BD 夹角 φ ≈ 60°
  - 体积曲线显示起点 (0, 0)
  - 滑块位置在最左侧

- 拖动过程（θ 从 0°到 180°连续变化）：
  - A'沿以 DE 为轴的圆弧运动，坐标实时计算
  - 高 h 长度变化，体积 V = (1/3)×S_FED×h 实时更新
  - 体积曲线动态延伸，显示 V(θ) 变化趋势
  - 异面直线夹角 φ 实时计算并显示
  - 当φ接近 90°时，夹角弧线高亮；当φ=90°时，显示红色直角标记

- 最大值状态（θ ≈ 90°）：
  - A'到达最高点，高 h 最大
  - 体积 V 达到最大值 V_max
  - 体积曲线上标记红色最大值点
  - 命题 (2) 得证：体积确实有最大值

- 垂直状态（θ ≈ 特定角度）：
  - 当φ = 90°时，异面直线 A'E 与 BD 垂直
  - 夹角显示区域显示红色直角符号
  - 命题 (4) 得证：异面直线可能垂直（原命题说"不可能"是错的）

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：
  - 滑块：id="scene3-slider"，位置 (100,440)-(700,460)，范围 0-180°，步长 1°
  - 角度数值显示：id="scene3-angle-display"，位置 (650,420)，实时显示当前θ值
  - 体积数值显示：id="scene3-volume-display"，位置 (600,210)，实时显示 V 值
  - 夹角数值显示：id="scene3-angle-phi"，位置 (600,300)，实时显示φ值
- 教师操作流程：
  1. 初始展示：θ=0°，说明此时 A'与 A 重合，三棱锥体积为 0
  2. 拖动滑块：缓慢拖动滑块从 0°到 180°，引导学生观察体积变化
  3. 找到最大值：在θ≈90°时暂停，说明此时体积最大，验证命题 (2)
  4. 寻找垂直：继续拖动，当φ=90°时暂停，说明异面直线可以垂直，命题 (4) 错误
  5. 对比观察：来回拖动，让学生理解动态变化规律

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形用 SVG 绘制清晰，动画和计算用原生 JS 足够，无需额外库
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │ 800×500 画布                                                    │
  │                                                                 │
  │ ┌─────────────────┐  ┌─────────────────────────────────────┐   │
  │ │                 │  │         体积曲线图                   │   │
  │ │   三棱锥立体图   │  │         (θ-V 关系)                  │   │
  │ │   A'-FED        │  │         y:V, x:θ                    │   │
  │ │                 │  │         显示 V_max 点                 │   │
  │ │   底面 FED      │  └─────────────────────────────────────┘   │
  │ │   顶点 A'       │                                            │
  │ │   高 h          │  ┌─────────────────────────────────────┐   │
  │ │                 │  │         异面直线夹角                 │   │
  │ └─────────────────┘  │         φ实时显示                    │   │
  │                      │         垂直时高亮                   │   │
  │                      └─────────────────────────────────────┘   │
  │                                                                 │
  │  ┌─────────────────────────────────────────────────────────┐   │
  │  │  滑块控件：旋转角度 θ：0° ─────●──────────── 180°       │   │
  │  └─────────────────────────────────────────────────────────┘   │
  └────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：单一状态变量 theta（0-180），所有显示元素由 theta 推导
  2. 坐标计算：
     - A'坐标：以 DE 中点 G 为旋转中心，DE 为旋转轴，A 绕 DE 旋转θ角
     - 高 h：A'到平面 FED 的距离（平面 FED 即平面 ABC，z=0）
     - 体积 V = (1/3) × S_FED × h，S_FED 为定值
     - 异面直线夹角：将 A'E 和 BD 平移至共点，计算向量夹角
  3. 动画曲线：滑块拖动时直接更新，无需缓动
  4. 事件绑定：slider 的 input 事件触发全部重绘
  5. ID 命名规范：所有元素 ID 以"scene3-"为前缀
  6. IIFE 隔离：所有 JS 包在 (function() { ... })() 中
- 核心计算公式：
  - 设正三角形边长 a=2（单位化），则：
    - A(0,0), B(-1,-√3), C(1,-√3)
    - F(0,-√3) 为 BC 中点
    - D(-0.5,-√3/2), E(0.5,-√3/2) 为 AB、AC 中点
    - G(0,-√3/2) 为 DE 中点，也是 AF 与 DE 交点
  - A'绕 DE 旋转θ角后的坐标（3D 转 2D 透视投影）
  - 高 h = |A'的 z 坐标|
  - S_FED = (1/2) × |FE| × |D 到 FE 的距离| = 定值
  - V(θ) = (1/3) × S_FED × h(θ)
  - 异面直线夹角：向量 A'E 与向量 BD 的夹角
