[分步序列]
- 初始状态（步骤 0）：
  显示：圆 O、直径 AB、延长线 BP、点 A/B/O/P、切线 PC、点 C、标注"PB=2"、"BO=2"
  隐藏：半径 OC、垂线 CD、点 D、直角标记、所有计算结果标注
  目的：呈现题目基础条件

- 步骤 1：点击「下一步」→
  新增显示：半径 OC（蓝色）、点 D、直角标记∠OCP（红色）、标注"OC=2"、"OP=4"
  视觉变化：OC 高亮显示，揭示切线性质（半径垂直于切线）
  目的：引导学生发现 OC⊥PC 的关键性质

- 步骤 2：点击「下一步」→
  新增显示：标注"PC=2√3"
  视觉变化：在 PC 线段上方显示计算结果
  目的：展示勾股定理应用：PC = √(OP² - OC²) = √(16-4) = 2√3

- 步骤 3：点击「下一步」→
  新增显示：垂线 CD（绿色）、直角标记∠CDO（红色）、标注"CD=√3"
  视觉变化：CD 高亮显示，展示面积法求解过程
  目的：展示面积法：S△OCP = 1/2×OC×PC = 1/2×OP×CD，得 CD = (OC×PC)/OP = √3

- 步骤 4（最终步骤）：点击「下一步」→
  所有元素显示完毕，标注"CD=√3"加粗高亮
  目的：呈现最终答案，完成解题过程

[标签冲突检查]
- 标签"O"：坐标 (300,275)
- 标签"A"：坐标 (185,265)
- 标签"B"：坐标 (405,265)
- 标签"P"：坐标 (610,265)
- 标签"C"：坐标 (343,141)
- 标签"D"：坐标 (333,270)
- 标注"PB=2"：坐标 (500,235)
- 标注"BO=2"：坐标 (350,235)
- 标注"OC=2"：坐标 (315,205)
- 标注"OP=4"：坐标 (450,235)
- 标注"PC=2√3"：坐标 (470,195)
- 标注"CD=√3"：坐标 (310,200)

逐对检查间距：
- "O"(300,275) 与 "D"(333,270)：间距 √(33²+5²) ≈ 33.4px → 无冲突
- "O"(300,275) 与 "B"(405,265)：间距 √(105²+10²) ≈ 105.5px → 无冲突
- "C"(343,141) 与 "OC=2"(315,205)：间距 √(28²+64²) ≈ 69.8px → 无冲突
- "C"(343,141) 与 "CD=√3"(310,200)：间距 √(33²+59²) ≈ 67.6px → 无冲突
- "OC=2"(315,205) 与 "CD=√3"(310,200)：间距 √(5²+5²) ≈ 7.1px → 冲突！解决方案：将"CD=√3"移至 (300,210)，间距变为 √(15²+5²) ≈ 15.8px，仍偏小；改为 (290,215)，间距 √(25²+10²) ≈ 26.9px → 无冲突
- "BO=2"(350,235) 与 "OP=4"(450,235)：间距 100px → 无冲突
- "PC=2√3"(470,195) 与 "OP=4"(450,235)：间距 √(20²+40²) ≈ 44.7px → 无冲突
- "PB=2"(500,235) 与 "OP=4"(450,235)：间距 50px → 无冲突

修正后"CD=√3"坐标：(290,215)

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（几何图形简单，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────┐
  │                                                         │
  │           C●                                            │
  │          / │                                            │
  │         /  │CD                                          │
  │        /   │                                            │
  │   ●──●────●────●────────●                               │
  │   A  O    D    B        P                               │
  │      \         \                                        │
  │       \         \ PC                                    │
  │        \         ●                                      │
  │         \                                              │
  │          \                                             │
  │           ● (圆 O)                                     │
  │                                                         │
  │          [上一步]            [下一步]                   │
  │          (250,455)          (470,455)                  │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：currentStep 变量 (0-4)，根据步骤控制元素显示/隐藏
  2. 坐标计算：C 点坐标通过三角函数计算，cosθ=1/3, sinθ=2√2/3
  3. 元素分组：用<g>标签分组相关元素（如 oc-group、cd-group），便于批量控制显示
  4. 动画曲线：元素出现使用 opacity 过渡动画 (0→1，duration=300ms)
  5. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateDisplay()
  6. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-circle-o、scene1-line-oc）
  7. IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
  8. 直角标记绘制：使用<path>绘制 L 形路径，顶点在直角处
