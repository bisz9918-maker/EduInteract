- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量 (0-4) 跟踪当前步骤
  2. 坐标计算：所有元素坐标按布局坐标表精确实现
  3. 动画曲线：步骤切换使用 opacity 渐变 (0.3s ease-in-out)
  4. 事件绑定：按钮点击事件监听，更新 currentStep 并重新渲染
  5. ID 命名规范：所有元素 ID 以 "scene1-" 为前缀（如 scene1-vertex-A1, scene1-edge-AA1）
  6. IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
  7. 元素显示控制：使用 display 或 opacity 控制各步骤元素的显示/隐藏
  8. 直角符号绘制：使用 SVG polyline 绘制 L 形直角标记
  9. 推导框文字：使用 SVG text 元素，多行文本通过 y 坐标递增实现
