[分步序列]
- 步骤 0（初始状态）：显示三棱柱框架（所有棱线、顶点标签 A₁、B₁、C₁、A、B、C），显示已知长度标注（A₁B₁=6、B₁C₁=10、AA₁=8），准备添加外接球
- 步骤 1：添加外接球球面（半透明蓝色椭圆轮廓 + 15% 填充），六个顶点恰好落在球面上，球面轮廓淡入动画
- 步骤 2：显示球心 O（红色圆点）位于三棱柱几何中心(280,250)，显示标签"O"，球心点淡入
- 步骤 3：高亮空间对角线 A₁C（红色加粗实线），显示从 A₁到 C 的连线穿过球心 O，右侧公式框出现"d = √(A₁B₁² + B₁C₁² + AA₁²)"
- 步骤 4：显示球半径 OA₁（绿色实线），公式框更新显示"d = √(6² + 10² + 8²) = √200 = 10√2"和"R = d/2 = 5√2"，标注"d=10√2"和"R=5√2"出现在公式框旁
- 步骤 5：显示球体积公式和最终结果，公式框显示"V = (4/3)πR³ = (4/3)π(5√2)³ = (1000√2/3)π"，标注"V=(1000√2/3)π"以绿色高亮显示

冲突检查：
- "A₁"(395,175) 与 "A₁B₁=6"(290,205)：间距 √((395-290)²+(175-205)²) = √(11025+900) ≈ 109px → 无冲突
- "B₁"(215,235) 与 "B₁C₁=10"(185,165)：间距 √((215-185)²+(235-165)²) = √(900+4900) ≈ 76px → 无冲突
- "O"(295,245) 与 "A₁B₁=6"(290,205)：间距 √((295-290)²+(245-205)²) = √(25+1600) ≈ 41px → 无冲突
- "O"(295,245) 与 "R=5√2"(550,240)：间距 √((295-550)²+(245-240)²) ≈ 255px → 无冲突
- "d=10√2"(550,200) 与 "R=5√2"(550,240)：间距 40px → 无冲突（垂直排列）
- "R=5√2"(550,240) 与 "V=(1000√2/3)π"(520,280)：间距 √((550-520)²+(240-280)²) = √(900+1600) = 50px → 无冲突
- 所有顶点标签之间间距均 > 60px → 无冲突

结论：所有标签间距均 ≥ 20px，无冲突。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：位于 SVG 底部左侧 (100,450)，作用：返回上一状态
  - "下一步 ▶"按钮：位于 SVG 底部右侧 (650,450)，作用：进入下一状态
  - 步骤指示器：位于 SVG 底部中央 (350,450)，显示"步骤 k/5"
- 教师操作流程：
  1. 初始展示三棱柱结构和已知条件
  2. 点击"下一步"逐步添加外接球、球心、空间对角线
  3. 每步配合讲解几何关系（球心位置、空间对角线=直径、半径推导）
  4. 最终展示体积计算结果
  5. 可随时点击"上一步"回退复习关键步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（几何图形简单，SVG 适合精确坐标绘制和动画控制）

- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量（0-5），每个步骤对应一个状态对象，包含该步骤应显示的元素列表
  2. 坐标计算：三棱柱顶点坐标基于透视投影原理，上底面 y 坐标较小（更靠上），下底面 y 坐标较大
  3. 动画曲线：使用 SVG SMIL 或 JS requestAnimationFrame 实现淡入效果（opacity 从 0 到 1）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 renderStep() 重绘
  5. ID 命名规范：所有元素 ID 以"scene2-"为前缀（如 scene2-sphere、scene2-center、scene2-diagonal、scene2-btn-prev、scene2-btn-next）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染
  7. 元素显示控制：使用 style.display 或 style.opacity 控制元素显示/隐藏，而非删除 DOM 节点
  8. 公式渲染：使用 MathJax 或纯文本（√、π 等符号用 Unicode）
