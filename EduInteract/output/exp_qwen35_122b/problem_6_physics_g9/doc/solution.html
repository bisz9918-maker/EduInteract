场景导航：Scene 1 | Scene 2 | Scene 3

题目原文：

如图所示，闭合开关后将变阻器的滑片向右移动，下列说法正确的是（）

A. 电路总电阻变小
B. 弹簧测力计示数变小
C. 电磁铁的磁性增强
D. 电流表读数变大

题目分析：

本题是一道电磁学与力学综合题，涉及以下核心知识点：

  1. 串联电路的电阻规律
  2. 滑动变阻器的工作原理
  3. 欧姆定律（I = U/R）
  4. 电磁铁磁性强弱与电流的关系
  5. 磁力对铁球的吸引作用

解题思路：

  1. 分析电路结构：电源、开关、滑动变阻器、定值电阻、电流表、电磁铁线圈串联
  2. 滑片右移 → 接入电路的电阻丝变长 → 滑动变阻器阻值变大 → 总电阻变大
  3. 根据欧姆定律：电源电压不变，总电阻变大 → 电流变小
  4. 电磁铁磁性强弱与电流大小成正比 → 电流变小 → 磁性减弱
  5. 电磁铁对铁球的吸引力减弱 → 弹簧测力计示数变小

正确答案：B

图示规划说明：

本套图示包含 3 个场景，分别从电路结构、滑动变阻器工作原理、电磁铁磁性变化三个角度进行可视化讲解，帮助学生建立从电路变化到力学现象的完整因果链。

步骤 0/5

图示 1 教学说明：

本图示用于帮助学生识别电路各元件及其连接方式。教师应按以下步骤引导学生观察：

  1. 从步骤 1 开始，让学生识别电源、开关、电流表的基本符号
  2. 步骤 2 加入滑动变阻器和定值电阻，说明滑动变阻器的滑片可以移动改变电阻
  3. 步骤 3 展示电磁铁线圈，说明通电后会产生磁性
  4. 步骤 4 展示弹簧测力计与铁球，说明铁球会被电磁铁吸引
  5. 步骤 5 完整展示电路，用绿色箭头标出电流方向，强调这是一个串联电路

关键提问：

  • 这个电路是串联还是并联？为什么？
  • 滑动变阻器的滑片移动会改变什么？
  • 电磁铁通电后会对铁球产生什么作用？

图示 2 教学说明：

本图示用于演示滑动变阻器的工作原理。教师应引导学生：

  1. 先让学生观察滑片在中间位置时的电阻值和电流值
  2. 让学生向左拖拽滑片，观察电阻值减小、电流值增大的现象
  3. 让学生向右拖拽滑片，观察电阻值增大、电流值减小的现象
  4. 引导学生总结规律：滑片移动方向与电阻变化的关系

关键公式：

  • 欧姆定律：$I = \frac{U}{R}$
  • 串联电路总电阻：$R_{总} = R_1 + R_2 + ... + R_n$

解题应用：
题目中滑片向右移动 → 接入电阻丝变长 → 滑动变阻器阻值变大 → 总电阻变大 → 电流变小

易错点提醒：
学生容易误认为滑片右移电阻变小，需强调"接入电路的电阻丝长度"决定电阻大小，而非滑片的绝对位置。

步骤 1/6

图示 3 教学说明：

本图示用于展示电磁铁磁性变化对弹簧测力计示数的影响。教师应按以下步骤讲解：

  1. 步骤 0-1：闭合开关，电流通过电磁铁线圈
  2. 步骤 2：电磁铁产生磁性，对铁球产生向下的吸引力，弹簧测力计示数 = 铁球重力 + 磁力
  3. 步骤 3：滑片右移，电流减小
  4. 步骤 4：电磁铁磁性减弱，对铁球的吸引力减小
  5. 步骤 5：弹簧测力计示数变小

关键公式：

  • 弹簧测力计示数：$F = G + F_{磁}$
  • 电磁铁磁性强弱：与电流大小成正比

完整解答：
滑片向右移动 → 接入电路的电阻丝变长 → 滑动变阻器阻值变大 → 电路总电阻变大 → 电流变小 → 电磁铁磁性减弱 → 对铁球的吸引力减小 → 弹簧测力计示数变小

选项分析：

  • A 错误：滑片右移，电阻变大，不是变小
  • B 正确：磁性减弱，吸引力减小，示数变小
  • C 错误：电流变小，磁性减弱，不是增强
  • D 错误：总电阻变大，电流变小，不是变大

课堂讲解建议：
建议教师先用图示 1 让学生熟悉电路结构，再用图示 2 演示滑动变阻器原理，最后用图示 3 展示完整的因果链。讲解时强调"滑片移动方向→电阻变化→电流变化→磁性变化→示数变化"这一逻辑链条。
