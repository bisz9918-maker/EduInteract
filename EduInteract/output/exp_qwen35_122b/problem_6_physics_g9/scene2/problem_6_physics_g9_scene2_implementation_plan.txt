[分步序列]
本场景为连续拖拽交互，无分步导航，状态随拖拽实时更新：

- 初始状态（步骤 0）：
  - 滑片位于中间位置 (370,160)-(390,220)
  - 接入电阻丝长度：220px（从 150 到 370）
  - 电阻值显示："2.5Ω"
  - 电流值显示："0.48A"
  - 蓝色高亮显示接入部分 (150,220)-(370,220)
  - 下方拖拽滑块手柄位于中间 (350,450)

- 拖拽过程（动态状态）：
  - 滑片左移（如到 270）：接入长度变短 → 电阻变小（如 1.5Ω）→ 电流变大（如 0.80A）→ 蓝色高亮区域缩短
  - 滑片右移（如到 470）：接入长度变长 → 电阻变大（如 3.5Ω）→ 电流变小（如 0.34A）→ 蓝色高亮区域延长
  - 所有数值实时计算并更新显示
  - 位置指示箭头同步移动

- 极值状态：
  - 滑片最左（150）：接入长度 0 → 电阻 0Ω → 电流最大（如 1.20A）
  - 滑片最右（550）：接入长度 400 → 电阻最大（如 5.0Ω）→ 电流最小（如 0.24A）

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：
  1. 主滑片（红色矩形）：位于电阻丝上方，可直接拖拽左右移动
  2. 下方拖拽滑块：位于控件区 (200,460)-(600,460)，拖动手柄同步控制主滑片
  3. 两个控件联动，提供两种操作方式

- 教师操作流程：
  1. 初始展示：滑片在中间，显示当前电阻和电流值
  2. 讲解原理：拖拽滑片向左 → 说明接入电阻丝变短 → 电阻变小 → 电流变大
  3. 反向验证：拖拽滑片向右 → 说明接入电阻丝变长 → 电阻变大 → 电流变小
  4. 极值演示：拖到最左/最右，展示电阻和电流的极值
  5. 配合题目：说明本题中滑片右移 → 电阻变大 → 电流变小 → 电磁铁磁性减弱 → 弹簧测力计示数变小（对应选项 B 正确）

- 关键实现要点：
  1. 状态机设计：
     - 状态变量：sliderPosition（滑片 x 坐标，范围 150-550）
     - 计算属性：接入长度 = sliderPosition - 150
     - 计算属性：电阻值 = 接入长度 / 400 × 5（假设最大电阻 5Ω）
     - 计算属性：电流值 = 1.2 / 电阻值（假设电源电压 1.2V，含定值电阻）
  
  2. 坐标计算：
     - 滑片 x 坐标：sliderPosition（150-550）
     - 蓝色高亮右端：sliderPosition
     - 下方滑块手柄 x：200 + (sliderPosition - 150) / 400 × 400 = sliderPosition + 50
  
  3. 动画曲线：拖拽时实时更新，无缓动（物理量变化应即时响应）
  
  4. 事件绑定：
     - 主滑片：mousedown/mousemove/mouseup（拖拽）
     - 下方滑块手柄：mousedown/mousemove/mouseup（拖拽）
     - 电阻丝区域：click（快速定位）
  
  5. 更新函数：updateDisplay() 重绘蓝色高亮区域、更新数值文本、同步两个滑块位置

- ID 命名规范：所有交互元素 ID 以 scene2- 为前缀
  - scene2-resistor-wire（电阻丝）
  - scene2-slider（主滑片）
  - scene2-slider-handle（下方滑块手柄）
  - scene2-resistance-value（电阻数值）
  - scene2-current-value（电流数值）
  - scene2-highlight-path（蓝色高亮路径）
  - scene2-position-indicator（位置指示箭头）

- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
