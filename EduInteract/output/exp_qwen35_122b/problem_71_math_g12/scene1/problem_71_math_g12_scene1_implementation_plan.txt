[分步序列]
步骤 0（初始状态）：
- 显示：圆 O（黑色）、圆心点 O、标签"O"
- 隐藏：所有顶点、边、向量、角度标注
- 目的：建立基础参照系

步骤 1：
- 新增：六个顶点 A₁-A₆（黑色实心圆点）及其标签
- 显示：圆 O、圆心 O、顶点 A₁-A₆ 及标签
- 目的：展示正六边形顶点在圆周上的均匀分布

步骤 2：
- 新增：正六边形的六条边（黑色线段）
- 显示：圆 O、圆心 O、顶点 A₁-A₆ 及标签、六条边
- 目的：形成完整的正六边形轮廓

步骤 3：
- 新增：六个中心角弧线（绿色）及角度标注"60°"
- 显示：圆 O、圆心 O、顶点 A₁-A₆ 及标签、六条边、中心角弧线、"60°"标注
- 目的：强调相邻顶点间的中心角为 60°

步骤 4（最终状态）：
- 新增：六条半径向量 OA₁-OA₆（蓝色，带箭头）
- 显示：所有元素（圆、圆心、顶点、边、中心角、向量）
- 目的：完整展示正六边形内接于圆的几何结构，为后续向量夹角问题做铺垫

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀上一步"按钮：位于 (300,460)，点击返回前一个步骤，步骤 0 时禁用
  - "下一步▶"按钮：位于 (500,460)，点击进入下一个步骤，步骤 4 时禁用
- 教师操作流程：
  1. 初始展示圆和圆心，建立参照系
  2. 点击"下一步"，逐个顶点出现，讲解正六边形顶点的均匀分布
  3. 点击"下一步"，六条边出现，形成完整正六边形
  4. 点击"下一步"，中心角弧线出现，强调 60°中心角
  5. 点击"下一步"，半径向量出现，为后续向量夹角问题铺垫
  6. 可随时点击"上一步"回退复习

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（圆、线段、点、文本），原生 SVG 足以实现，无需引入重型库
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │                         800px                               │
  │  ┌─────────────────────────────────────────────────────┐   │
  │  │                                                     │   │
  │  │              正六边形内接于圆图示                    │   │
  │  │                   (主图区)                          │   │
  │  │                                                     │   │
  │  │                    ● A₂                             │   │
  │  │                  /     \                            │   │
  │  │              ● A₃       ● A₁                        │   │
  │  │             /             \                         │   │
  │  │           ● O ────────────● A₄                      │   │
  │  │             \             /                         │   │
  │  │              \           /                          │   │
  │  │              ● A₅       ● A₆                        │   │
  │  │                                                     │   │
  │  │                    [◀上一步] [下一步▶]              │   │
  │  │                     y=460 控件栏                    │   │
  │  └─────────────────────────────────────────────────────┘   │
  │                         500px                               │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep 记录当前步骤（0-4），根据 currentStep 控制各元素的 display 属性
  2. 坐标计算：顶点坐标用三角函数计算，Aᵢ 的角度为 (i-1)×60°，坐标为 (400+180×cosθ, 250-180×sinθ)
  3. 箭头实现：SVG marker 元素定义箭头，应用到向量线段的 marker-end 属性
  4. 弧线绘制：SVG path 的 arc 命令，或计算起点终点用 line 近似
  5. 事件绑定：按钮点击事件监听，更新 currentStep 后重新渲染元素可见性
  6. 禁用状态：步骤 0 时禁用"上一步"按钮，步骤 4 时禁用"下一步"按钮
- ID 命名规范：所有交互元素 ID 以 scene1- 为前缀
  - 圆：scene1-circle
  - 圆心：scene1-center
  - 顶点：scene1-A1, scene1-A2, ..., scene1-A6
  - 边：scene1-edge1, scene1-edge2, ..., scene1-edge6
  - 向量：scene1-vec1, scene1-vec2, ..., scene1-vec6
  - 中心角弧：scene1-arc1, scene1-arc2, ..., scene1-arc6
  - 标签：scene1-label-O, scene1-label-A1, ..., scene1-label-A6, scene1-label-angle
  - 按钮：scene1-btn-prev, scene1-btn-next
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
