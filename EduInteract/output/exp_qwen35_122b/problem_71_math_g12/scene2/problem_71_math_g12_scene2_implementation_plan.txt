[分步序列]
本场景采用连续拖拽交互，无分步导航，状态随滑块连续变化：

- 初始状态（滑块=0°）：
  - P 位于 A₁ 位置 (550,250)
  - 向量 OP 与 OA₁ 重合
  - θ₁ = 0°, θ₂ = 60°, θ₃ = 120°, θ₄ = 180°, θ₅ = 240°, θ₆ = 300°
  - 数列显示框显示排序后的角度值
  - α₃ 高亮显示当前第 3 项的值

- 拖拽过程（滑块 0°~360°）：
  - P 沿圆周连续移动
  - 向量 OP 实时跟随 P 的位置
  - 六个夹角 θᵢ 实时更新（θᵢ = |∠(OP, OAᵢ)|，取值范围 0°~180°）
  - 夹角弧线随 P 位置动态调整
  - 数列显示框中的排序值实时更新
  - α₃ 高亮值实时更新

- 关键位置（教师可引导观察）：
  - 滑块=30°：P 位于 A₁ 与 A₂ 中点，θ 值排序后形成等差数列
  - 滑块=90°：P 位于 A₂ 与 A₃ 中点，θ 值排序后形成等差数列
  - 滑块=150°：P 位于 A₃ 与 A₄ 中点，θ 值排序后形成等差数列
  - 以此类推，每 60° 一个周期

- 结论状态（当 P 位于相邻顶点中点时）：
  - 六个夹角排序后为：30°, 30°, 90°, 90°, 150°, 150°（或类似等差数列）
  - α₃ 高亮显示第 3 项的值（如 90°）

冲突检查：
- "O"(400,265) 与 "A₁"(565,250)：间距 ≈ 166px → 无冲突
- "O"(400,265) 与 "A₂"(475,105)：间距 ≈ 177px → 无冲突
- "O"(400,265) 与 "A₃"(325,105)：间距 ≈ 177px → 无冲突
- "O"(400,265) 与 "A₄"(235,250)：间距 ≈ 165px → 无冲突
- "O"(400,265) 与 "A₅"(325,395)：间距 ≈ 149px → 无冲突
- "O"(400,265) 与 "A₆"(475,395)：间距 ≈ 149px → 无冲突
- "P"(560,235) 与 "A₁"(565,250)：间距 ≈ 16px → 接近但可接受（P 移动后会远离）
- "P"(560,235) 与 "θ₁"(530,230)：间距 ≈ 30px → 无冲突
- "排序后："(590,320) 与 "α₁" 数值行 (590,345)：间距 25px → 无冲突
- "α₃ = ?"(680,375) 与 "α₄" 数值 (720,375)：间距 40px → 无冲突
- 所有顶点标签之间间距均 > 100px → 无冲突
- 夹角标签 θ₁~θ₆ 初始位置分散在圆内不同区域，间距均 > 50px → 无冲突

解决方案：初始状态 P 与 A₁ 较近，但 P 移动后会立即远离；夹角标签采用不同半径的弧线（40~90px），确保互不重叠。

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：
  - 滑块控件：位于 SVG 底部 (200,450)-(600,470)，范围 0-360 度，控制点 P 在圆周上的角度位置
  - 提示文字：滑块下方 (200,480)，显示 "拖动点 P 沿圆周移动"
- 教师操作流程：
  1. 初始展示：P 位于 A₁，六个夹角 θ₁~θ₆ 显示初始值
  2. 拖动滑块：教师拖动滑块，点 P 沿圆周移动，六个夹角实时变化
  3. 引导观察：当 P 移动到相邻顶点中点（如 30°、90°、150°等）时，暂停并让学生观察排序后的夹角值
  4. 发现规律：学生发现此时六个夹角排序后形成等差数列
  5. 得出结论：α₃ 高亮显示第 3 项的值，教师引导学生计算并填写答案

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript
  - 理由：几何图形（圆、多边形、线段、圆弧）用 SVG 绘制最清晰，交互逻辑简单，无需复杂动画库
  - 数学公式用 MathJax 渲染（可选，用于显示 θᵢ 等符号）

- 画布尺寸：800 × 500 px

- 关键实现要点：
  1. 状态机设计：
     - 状态变量：pAngle（P 的角度，0-360°）
     - 派生变量：P 坐标 (400+150*cos(pAngle), 250+150*sin(pAngle))
     - 派生变量：六个夹角 θᵢ = |pAngle - vertexAngleᵢ|，取 0-180° 范围内的最小角
     - 派生变量：排序后的数组 sortedAngles，取前 6 个值

  2. 坐标计算：
     - 顶点角度：A₁=0°, A₂=60°, A₃=120°, A₄=180°, A₅=240°, A₆=300°
     - 顶点坐标：x = 400 + 150*cos(θ), y = 250 + 150*sin(θ)
     - 夹角计算：θᵢ = min(|pAngle - vertexAngleᵢ|, 360 - |pAngle - vertexAngleᵢ|)

  3. 动画曲线：
     - 滑块拖动时实时更新 P 的位置和所有夹角值
     - 使用 requestAnimationFrame 平滑更新

  4. 事件绑定：
     - 滑块 input 事件：更新 pAngle，触发重绘
     - 重绘函数：更新向量 OP、夹角弧线、夹角标签、数列显示

  5. ID 命名规范：
     - 所有交互元素 ID 以 "scene2-" 为前缀
     - 如：scene2-circle, scene2-polygon, scene2-point-p, scene2-vector-op, scene2-slider, scene2-arc-theta1~6, scene2-label-theta1~6, scene2-数列框, scene2-α3-highlight

  6. IIFE 隔离：
     - 所有 JS 代码包在 (function() { ... })() 中
     - 避免全局变量污染

  7. 夹角弧线绘制：
     - 使用 SVG path 的 arc 命令
     - 弧线起点在 OP 方向，终点在 OAᵢ 方向
     - 半径从 40px 到 90px 递增，避免重叠

  8. 数值显示格式化：
     - 角度值保留整数或一位小数
     - 排序后显示为 "α₁=30° α₂=30°" 等格式
