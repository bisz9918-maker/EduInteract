[分步序列]
- 步骤 0（初始状态）：
  - 显示：主视图、俯视图、侧视图三个视图（黑色轮廓）
  - 显示：三个视图的标签（主视图、俯视图、侧视图）
  - 显示：所有尺寸标注（3、3、6、2、4）
  - 隐藏：立体四棱锥、立体图标签、立体图尺寸标注
  - 目的：展示题目原始三视图

- 步骤 1：
  - 视觉变化：主视图三角形填充蓝色高亮（rgba(21, 101, 192, 0.3)），边框变为蓝色（#1565c0）
  - 显示：主视图底边被分为 3+3 的标注
  - 目的：强调主视图显示底面长度为 6（3+3），高度为 4

- 步骤 2：
  - 视觉变化：主视图恢复原色，俯视图矩形填充蓝色高亮（rgba(21, 101, 192, 0.3)），边框变为蓝色
  - 显示：俯视图矩形的长 6、宽 2 标注
  - 显示：俯视图中的两条对角线（表示顶点投影在底面中心）
  - 目的：强调俯视图显示底面为 6×2 矩形，顶点投影在长边中点

- 步骤 3：
  - 视觉变化：俯视图恢复原色，侧视图三角形填充蓝色高亮（rgba(21, 101, 192, 0.3)），边框变为蓝色
  - 显示：侧视图的底边 2、高 4 标注
  - 目的：强调侧视图显示几何体高度为 4，底面宽度为 2

- 步骤 4：
  - 视觉变化：侧视图恢复原色，三个视图边框恢复黑色
  - 显示：立体四棱锥（绿色轮廓 #2e7d32，底面填充 rgba(46, 125, 50, 0.2)）
  - 显示：立体图顶点标签"顶点"、底面标签"底面"
  - 目的：展示三视图对应的立体几何体——四棱锥

- 步骤 5（最终步骤）：
  - 视觉变化：立体四棱锥保持绿色高亮
  - 显示：立体图关键尺寸标注（h=4、底面长 6、底面宽 2），使用红色高亮 #c62828
  - 显示：立体图高线（虚线 #888888）
  - 目的：整合所有尺寸信息，为计算表面积做准备

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：ID=scene1-btn-prev，位置 (260,455)，作用：返回上一步，若已在步骤 0 则禁用
  - "下一步 ▶"按钮：ID=scene1-btn-next，位置 (440,455)，作用：进入下一步，若已在步骤 5 则禁用
  - 步骤指示器：ID=scene1-step-indicator，位置 (350,420)，显示"步骤 1/6"
- 教师操作流程：
  1. 初始展示三视图，让学生观察并识别各视图
  2. 点击"下一步"，依次高亮主视图、俯视图、侧视图，讲解每个视图的含义
  3. 继续点击"下一步"，展示立体四棱锥，建立三视图与立体图的对应
  4. 最后一步标注所有关键尺寸，引导学生计算表面积
  5. 可随时点击"上一步"回退复习某个视图或概念

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（三角形、矩形、线段），原生 SVG 足以实现，无需引入重型库
  - 动画通过 CSS transition 和 JS 类名切换实现
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │                    四棱锥三视图与立体图                         │  y=15
  ├──────────────────────┬─────────────────────────────────────────┤
  │   主视图             │              侧视图                      │
  │   △                  │              △                          │
  │  / \   (3) (3)       │             /|  (4)                     │
  │ /___\_______________ │            / |                          │
  │                      │           /__| (2)                      │
  │   俯视图             │                                          │
  │  ┌──────────┐        │         立体四棱锥展示区                 │
  │  │    /\    │  (2)   │              /\                         │
  │  │   /  \   │        │             /  \  (h=4)                 │
  │  │__/____\__│        │            /____\                        │
  │  (6)         │        │        (6) 底面 (2)                     │
  └──────────────────────┴─────────────────────────────────────────┘
                    ◀ 上一步    [步骤 1/6]    下一步 ▶
                           y=440~490 (控件栏)
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-5) 跟踪当前步骤
  2. 坐标计算：所有元素坐标已在布局坐标表中精确定义
  3. 动画曲线：使用 CSS transition 实现淡入淡出（opacity 0→1）和高亮切换（fill 颜色变化）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 并调用 renderStep() 重绘
  5. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-tri-main、scene1-rect-top、scene1-btn-next）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 高亮实现：通过添加/移除 CSS 类名 highlight-blue、highlight-green、highlight-red 控制颜色
  8. 尺寸标注颜色：步骤 5 中立体图尺寸标注使用红色高亮类名 highlight-red
