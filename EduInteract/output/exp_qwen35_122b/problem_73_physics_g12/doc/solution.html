场景导航：Scene 1 | Scene 2

题目原文：
如图所示，U 形导体框架的宽度为 L=1m，其所在平面与水平面夹角θ=30°，其电阻可以忽略不计。设匀强磁场与 U 形框架的平面垂直，磁感强度 B=0.2Wb/m²。今有一条形导体棒 MN，其质量 m=0.2kg，其电阻 R=0.2Ω，跨放在 U 形框架（足够长）上，并能无摩擦地滑动，求：
（1）导体棒 MN 下滑过程的最大速度 v_m；
（2）在最大速度 v_m 时，在导体棒 MN 上释放出来的电功率 P；
（3）若导体棒从开始下滑到达到最大速度这一过程中导体棒消耗的电能为 Q_电=1.5J，则此过程中通过导体棒横截面积的电量 q 是多少？

题目分析：
本题是电磁感应与力学综合问题，核心知识点包括：

  1. 导体棒在倾斜导轨上下滑时的受力分析（重力分力与安培力）
  2. 电磁感应定律：感应电动势 E=BLv，感应电流 I=E/R
  3. 安培力公式：F_安=BIL=B²L²v/R
  4. 最大速度条件：当安培力与重力沿斜面分力平衡时，速度达到最大
  5. 能量转化：重力势能转化为动能和电能
  6. 电量计算：q=ΔΦ/R 或 q=It

整体讲解思路：

  1. 首先通过图示 1 展示物理情境，引导学生理解装置结构和磁场方向
  2. 逐步分析受力情况，展示导体棒下滑过程中的力变化
  3. 解释最大速度的物理意义（受力平衡状态）
  4. 通过图示 2 展示能量转化关系，帮助学生理解电功率和电量的计算原理

图示规划说明：

  • Scene 1：物理情境与受力分析（整合装置展示、磁场方向、运动过程、感应电流、安培力、受力平衡）
  • Scene 2：能量转化与计算（整合能量转化关系、电功率计算、电量计算）
步骤 0/6

Scene 1 教学说明：

引导学生观察要点：

  1. 首先让学生观察装置结构：U 形框架倾斜放置，导体棒可以沿框架滑动
  2. 强调磁场方向：垂直于框架平面，这是产生感应电动势的关键条件
  3. 引导学生理解导体棒下滑时切割磁感线，产生感应电动势 E=BLv
  4. 用右手定则判断感应电流方向：从 N 到 M
  5. 用左手定则判断安培力方向：沿斜面向上，阻碍导体棒下滑

关键公式推导：

  1. 感应电动势：E = BLv
  2. 感应电流：I = E/R = BLv/R
  3. 安培力：F_安 = BIL = B²L²v/R
  4. 最大速度条件：当 F_安 = mg sinθ 时，速度达到最大
  5. 最大速度计算：v_m = mgR sinθ / (B²L²)

代入数值计算：
v_m = (0.2 × 9.8 × 0.2 × sin30°) / (0.2² × 1²) = (0.2 × 9.8 × 0.2 × 0.5) / 0.04 = 0.196 / 0.04 = 4.9 m/s

讲解建议：

  • 在步骤 5 时，暂停让学生思考：为什么速度会达到最大？
  • 在步骤 6 时，强调平衡状态：合力为零，加速度为零，速度恒定
  • 可以让学生预测：如果磁场更强，最大速度会如何变化？
p = mgh 动能 ΔEk = ½mvm² 电能 Q电 = 1.5J ΔEp = ΔEk + Q电 电功率 P P = I²R = B²L²vm²/R 当 v = vm 时，P 最大 电量 q q = It = ΔΦ/R = BLx/R x ΔΦ = BLx q = ΔΦ/R = BLx/R

Scene 2 教学说明：

能量转化讲解要点：

  1. 导体棒下滑过程中，重力势能减少，转化为动能和电能
  2. 电能最终以焦耳热的形式在电阻上释放
  3. 能量守恒：ΔEp = ΔEk + Q_电

电功率计算：
在最大速度时，电功率 P = I²R = (BLvm/R)²R = B²L²vm²/R
代入数值：P = (0.2² × 1² × 4.9²) / 0.2 = (0.04 × 24.01) / 0.2 = 0.9604 / 0.2 = 4.802 W

电量计算：
方法一：q = It，需要知道时间 t
方法二：q = ΔΦ/R = BLx/R，需要知道下滑距离 x
方法三：利用能量关系，Q_电 = I²Rt = (BLv/R)²Rt = B²L²v²t/R
但更直接的方法是利用：Q电 = I²Rt = (BLvm/R)²R × t = B²L²v_m²t/R
而 q = It = BLv_m t/R
所以 Q电 = B²L²vm q / R
解得：q = Q电 R / (B²L²vm) = 1.5 × 0.2 / (0.04 × 1 × 4.9) = 0.3 / 0.196 ≈ 1.53 C

完整解答总结：
（1）最大速度 v_m = mgR sinθ / (B²L²) = 4.9 m/s
（2）电功率 P = B²L²v_m²/R = 4.8 W
（3）电量 q = Q电 R / (B²L²vm) ≈ 1.53 C

课堂讲解建议：

  • 强调能量转化的物理意义：重力做功转化为电能
  • 引导学生理解电量的两种计算方法（时间积分 vs 磁通量变化）
  • 可以让学生讨论：如果考虑摩擦，结果会如何变化？
  • 总结电磁感应问题的解题思路：受力分析→运动分析→能量分析
