[分步序列]
- 步骤0（初始状态）：显示磁场区域（带×填充）、线圈abcd、砝码m₂、滑轮系统。显示速度矢量v（绿色向上）。标注磁场B、边长l、宽度h。等待教师触发交互。

- 步骤1：高亮显示ab边（线圈上边框加粗），在右侧显示感应电动势公式"E = Blv"（黑色，16px）。ab边用黄色高亮#fff176。

- 步骤2：显示感应电流方向，沿线圈边框绘制绿色带箭头闭合曲线（a→b→c→d→a）。在右侧显示感应电流公式"I = E/R = Blv/R"。

- 步骤3：显示ab边受到的安培力F_A，从线圈中心(150,250)向下绘制红色箭头至(150,290)，右侧标注"F_A = BIl = B²l²v/R"。

- 步骤4：显示全部受力分析。左侧线圈：从中心(150,250)同时显示三个力矢量——拉力T向上（蓝色）、重力m₁g向下（红色）、安培力F_A向下（红色）。右侧砝码：从中心(350,140)显示两个力矢量——拉力T向上（蓝色）、重力m₂g向下（红色）。

- 步骤5：在底部公式区显示平衡方程和速度解：
  左侧显示："平衡方程：m₂g = m₁g + B²l²v/R"
  下方显示："速度解：v = (m₂ - m₁)gR / (B²l²) = 2.0 m/s"
  公式用黑色加粗显示。

- 步骤6：在右侧能量转化区显示能量流程图，同时在底部右侧显示热量公式：
  能量区显示："m₂gh ↓ → m₁gh ↑ + Q"
  底部右侧显示："热量公式：Q = (m₂ - m₁)gh = 0.078 J"
  用灰色箭头连接各能量项。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "上一步"按钮：位置(320,460)，作用：返回上一状态
  - "下一步"按钮：位置(400,460)，作用：进入下一状态
  - 两个按钮均为矩形，背景色#1976d2，文字白色，字号14px
- 教师操作流程：
  1. 初始展示线圈在磁场中的基本状态
  2. 点击"下一步"逐步展示电磁感应过程（电动势→电流→安培力）
  3. 继续点击展示受力平衡分析
  4. 最后展示能量转化关系
  5. 可随时点击"上一步"回退复习关键步骤

- 关键实现要点：
  1. 状态机设计：用变量 currentStep 记录当前步骤（0-6），每一步根据 currentStep 显示/隐藏对应元素
  2. 坐标计算：所有元素使用绝对坐标，力矢量从线圈中心(150,250)和砝码中心(350,140)出发
  3. 动画曲线：力矢量和公式使用 opacity 渐变（0→1，300ms）实现淡入效果
  4. 事件绑定：按钮点击事件更新 currentStep，调用 updateDisplay() 刷新界面
  5. ID 命名规范：所有元素 ID 以"scene2-"为前缀（如 scene2-coil、scene2-force-fa、scene2-btn-next）
  6. JS 使用 getElementById 获取元素，避免 querySelectorAll 全局选择
  7. 所有 JS 代码包在 IIFE (function() { ... })() 中隔离作用域
  8. 磁场×符号用循环生成，间距约20px
  9. 感应电流箭头用 polyline 沿线圈边框绘制，带箭头标记
