[图示主题与整合说明]
- 本图示主题：三球带电系统竖直下落进入平行板电容器的多阶段运动过程
- 整合内容：初始状态、三球依次进入电场、下端小球到达下极板三个关键阶段，以及最大速度位置的标注
- 教学价值：教师可通过分步演示，清晰展示三球系统在不同时刻的位置关系、受力变化，帮助学生理解多体系统在电场中的运动规律，特别是速度从 0 增加到最大再减小到 0 的全过程

[分步序列]
步骤 0（初始状态）：
- 显示：上极板（带小孔）、下极板、三球竖直排列（球 1 在小孔处）、杆 1-2 和杆 2-3、标注 d、标注 L1 和 L2、标签 +q1/+q2/+q3、标签 m1/m2/m3
- 隐藏：电场线、运动轨迹、v_max 标记、速度矢量
- 状态：三球静止，速度 v=0

步骤 1（第一球进入电场 L，第二球刚进入）：
- 三球整体下移 L=60px
- 球 1 位置：(400,210)，球 2 位置：(400,150)，球 3 位置：(400,90)
- 显示：电场线（3 条，板间均匀分布）、运动轨迹（竖直虚线）
- 标注：球 1 进入电场深度"L"（在球 1 右侧）
- 状态：三球加速下落，v>0

步骤 2（第一球进入电场 2L，第二球进入 L，第三球刚进入）：
- 三球整体再下移 L=60px
- 球 1 位置：(400,270)，球 2 位置：(400,210)，球 3 位置：(400,150)
- 标注：球 1 进入深度"2L"，球 2 进入深度"L"
- 状态：三球继续加速，v 增大

步骤 3（第一球到达下极板，速度为 0）：
- 三球整体再下移 L=60px
- 球 1 位置：(400,330)，球 2 位置：(400,270)，球 3 位置：(400,210)
- 标注：球 1 进入深度"3L=d"，球 2 进入深度"2L"，球 3 进入深度"L"
- 状态：三球速度 v=0，运动停止
- 高亮：球 1 用#ff5722 边框表示到达终点

步骤 4（结论：最大速度位置）：
- 三球回到步骤 2 的位置（或保持步骤 3 位置，叠加显示 v_max 标记）
- 显示：v_max 标记点 (400,240)，即合力为零处
- 显示：速度矢量箭头（从 v_max 位置向上，长度表示最大速度）
- 标注：标签"v_max"(420,240)
- 说明：此处重力与电场力平衡，加速度为 0，速度达到最大

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 按钮"◀ 上一步"：位置 (280,460)，作用：返回上一状态，若已在步骤 0 则禁用
  - 按钮"下一步 ▶"：位置 (520,460)，作用：进入下一状态，若已在步骤 4 则禁用
  - 状态指示器：位置 (380,460)，显示"步骤 k/4"，k=0~4
- 教师操作流程：
  1. 初始显示步骤 0，讲解三球系统的初始位置和已知条件
  2. 点击"下一步"进入步骤 1，讲解第一球进入电场后的受力变化
  3. 继续点击"下一步"进入步骤 2、3，展示三球依次进入电场的过程
  4. 步骤 3 展示最终状态（速度为 0），引出能量守恒分析
  5. 点击"下一步"进入步骤 4，标注最大速度位置，讲解合力为零的物理意义
  6. 可随时点击"上一步"回退复习，巩固关键概念

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────┐
  │                    图示区 800×500                    │
  │                                                      │
  │         上极板 ──────────○───────────               │
  │              │          │          │                │
  │              │  电场线   │  电场线   │  电场线        │
  │              │    ↑     │    ↑     │    ↑          │
  │         下极板 ─────────────────────────             │
  │                                                      │
  │         标注 d     标注 L      标注 L                │
  │                                                      │
  │  ┌───────────────────────────────────────────────┐  │
  │  │      ◀ 上一步      步骤 k/4      下一步 ▶      │  │
  │  └───────────────────────────────────────────────┘  │
  └─────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0~4) 跟踪当前步骤，updateScene() 函数根据 currentStep 显示/隐藏相应元素
  2. 坐标计算：所有元素位置预先计算好，存储在配置对象中，便于步骤切换时快速更新
  3. 动画曲线：步骤切换时使用 SVG SMIL 或 requestAnimationFrame 实现平滑过渡（可选）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateScene()
  5. 禁用状态：步骤 0 时禁用"上一步"，步骤 4 时禁用"下一步"
- ID 命名规范：所有交互元素 ID 以 scene1- 为前缀，如 scene1-ball1、scene1-field-line1、scene1-btn-prev、scene1-btn-next、scene1-step-indicator
- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染
