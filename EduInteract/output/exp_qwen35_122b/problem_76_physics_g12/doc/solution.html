problem_76_physics_g12

场景导航：Scene 1 | Scene 2

题目原文：

如图所示，在光滑水平面上有两个并排放置的木块A、B，已知mA=0.5kg，mB=0.3kg。现有质量m0=0.08kg的小物块C以初速v0=25m/s在A表面沿水平方向向右滑动，由于C与A、B间均有摩擦，C最终停在B上，B、C最后的共同速度v=2.5m/s。求：

（1）A木块的最终速度的大小；
（2）C物块滑离A木块的瞬时速度大小。

题目分析：

这是一道动量守恒定律的综合应用题，涉及多体系统的分阶段动量守恒分析。

关键物理过程：

  1. 第一阶段：C在A上滑动，A和B紧靠在一起共同运动
  • 系统：C + A + B
  • 动量守恒：mC·v0 = mC·vC1 + (mA + mB)·v_A1
  • 此阶段结束时，C滑离A，A获得速度v_A1
  1. 第二阶段：C滑上B，A以v_A1匀速运动，B和C相互作用
  • 系统：C + B（A已分离）
  • 动量守恒：mC·vC1 + mB·vA1 = (mC + mB)·v_final
  • 最终状态：B和C共速v_final = 2.5m/s

解题思路：

  1. 先分析第一阶段，建立C、A、B的动量守恒方程
  2. 再分析第二阶段，建立C、B的动量守恒方程
  3. 联立求解两个方程，得到vA1和vC1

本图示集合将展示：

步骤 1/5

图示教学要点：

  1. 引导学生观察物理过程的阶段性
  • 步骤0→1：C开始在A上滑动，由于A、B紧靠，摩擦力使A、B一起向右加速
  • 步骤1→2：C滑离A的瞬间，A获得最终速度v_A（此后A匀速运动）
  • 步骤2→3：C滑上B，B开始加速，C减速
  • 步骤3→4：C、B达到共同速度v=2.5m/s，相对静止
  1. 强调系统边界的变化
  • 第一阶段（C在A上）：系统 = C + A + B，三者动量守恒
  • 第二阶段（C在B上）：系统 = C + B，A已分离，动量不再参与
  1. 关键物理量标注
  • 已知量用黑色实线箭头标注
  • 待求量v_A用灰色虚线箭头标注，引导学生关注求解目标
  • 最终速度v=2.5m/s用黑色标注在B、C上

讲解建议：

教师应引导学生：

  • 先理解为什么第一阶段A、B一起运动（紧靠+摩擦传递）
  • 再理解为什么第二阶段A分离（C滑离后A不再受摩擦力）
  • 最后理解为什么最终B、C共速（摩擦力使相对速度减为零）

完整解答：

第一阶段：C在A上滑动（C、A、B系统动量守恒）

设C滑离A时的速度为vC1，此时A、B的共同速度为vA（即A的最终速度）

动量守恒方程：
mC·v0 = mC·vC1 + (mA + mB)·v_A ……①

第二阶段：C在B上滑动（C、B系统动量守恒）

C滑上B时，B的初速度为vA，C的初速度为vC1
最终B、C共速v = 2.5m/s

动量守恒方程：
mC·vC1 + mB·vA = (mC + mB)·v ……②

联立求解：

将已知数据代入方程②：
0.08·vC1 + 0.3·vA = (0.08 + 0.3)×2.5
0.08·vC1 + 0.3·vA = 0.95 ……③

将已知数据代入方程①：
0.08×25 = 0.08·vC1 + (0.5 + 0.3)·vA
2 = 0.08·vC1 + 0.8·vA ……④

由③得：0.08·vC1 = 0.95 - 0.3·vA
代入④：2 = (0.95 - 0.3·vA) + 0.8·vA
2 = 0.95 + 0.5·v_A
v_A = (2 - 0.95) / 0.5 = 2.1m/s

将v_A = 2.1m/s代入③：
0.08·v_C1 + 0.3×2.1 = 0.95
0.08·v_C1 = 0.95 - 0.63 = 0.32
v_C1 = 4m/s

答案：
（1）A木块的最终速度大小：v_A = 2.1m/s
（2）C物块滑离A木块的瞬时速度大小：v_C1 = 4m/s

课堂讲解建议：

  1. 强调动量守恒的条件：系统不受外力或合外力为零
  2. 引导学生识别每个阶段的系统边界（哪些物体参与动量守恒）
  3. 提醒学生注意速度的方向性（本题均为同向，取正值）
  4. 验证答案合理性：vC1 > vA > v，符合物理直觉（C减速，A、B加速）
