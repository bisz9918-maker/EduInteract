[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮（scene2-prevBtn）：位于底部左侧，点击返回上一状态，步骤 0 时禁用
  - 下一步按钮（scene2-nextBtn）：位于底部右侧，点击进入下一状态，步骤 5 时禁用
- 教师操作流程：
  1. 初始展示已知条件和待求量，引导学生明确问题
  2. 点击"下一步"，展示第一阶段动量守恒方程，讲解系统划分
  3. 点击"下一步"，展示第二阶段动量守恒方程，讲解两阶段关联
  4. 点击"下一步"，展示数值代入过程
  5. 点击"下一步"，展示 v_A 求解结果
  6. 点击"下一步"，展示完整答案，结束推导
  7. 可随时点击"上一步"回退复习关键步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何和文本布局，无需复杂绘图库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    分阶段动量守恒方程推导                │  y=20
  ├─────────────────────────────────────────────────────────┤
  │ 第一阶段：C 在 A 上滑动        →→→        第二阶段：C 在 B 上滑动  │  y=60
  │ ┌─────────────────────┐              ┌─────────────────────┐
  │ │  方程 1 内容          │              │  方程 2 内容          │  y=90-200
  │ │  (3 行)              │              │  (3 行)              │
  │ └─────────────────────┘              └─────────────────────┘
  ├─────────────────────────────────────────────────────────┤
  │ 已知量标注区              │        待求量标注区           │  y=240-320
  │ (m_A, m_B, m₀, v₀, v)   │        (v_A=?, v_C1=?)       │
  ├─────────────────────────────────────────────────────────┤
  │         最终答案框（v_A=2.0, v_C1=15.0）                │  y=360-430
  ├─────────────────────────────────────────────────────────┤
  │              [◀上一步]        [下一步▶]                 │  y=455
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用 currentStep 变量（0-5）跟踪当前步骤，每一步定义 showElements 和 hideElements 数组
  2. 坐标计算：所有元素使用绝对定位，SVG 内元素用 transform 或直接坐标
  3. 动画曲线：使用 CSS transition（opacity 0.3s ease）实现淡入淡出
  4. 事件绑定：按钮点击事件更新 currentStep，调用 updateDisplay() 刷新显示
  5. ID 命名规范：所有元素 ID 以 scene2- 为前缀（如 scene2-title, scene2-eq1-box, scene2-prevBtn）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 按钮状态：步骤 0 时禁用 prevBtn，步骤 5 时禁用 nextBtn
