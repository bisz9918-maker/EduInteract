场景导航：Scene 1 | Scene 2 | Scene 3

题目原文：

如图1所示，平行金属板A和B的距离为d，它们的右端安放着垂直金属板的靶MN．现在A、B板上加上如图2所示的方波形电压，t=0时A板比B板的电势高，电压的正向值为U₀，反向值也为U₀，现有由质量为m的带正电且电荷量为q的粒子组成的粒子束，从AB的中点O以平行于金属板方向OO′的某一初速射入．设粒子能全部打在靶MN上，而且所有粒子在AB间的飞行时间均为T，不计重力影响，试问：

（1）在距靶MN的中心O′点多远的范围内有粒子击中？

（2）要使粒子能全部打在靶MN上，电压U₀的数值应满足什么条件？（写出U₀，m、d、q，T的关系式即可）．

（3）电场力对每个击中靶MN的带电粒子所做的总功是否相等？若相等，请证明并求出此功的数值；若不相等，求出此功的数值范围．

题目分析：

本题考查带电粒子在交变电场中的运动，核心知识点包括：

  1. 粒子在平行板电容器中的类平抛运动
  2. 方波电压下电场力的周期性变化
  3. 不同时刻进入的粒子具有不同的偏转轨迹
  4. 竖直方向位移的叠加计算

关键物理过程：

  • 粒子水平方向：匀速直线运动，速度v₀，飞行时间T
  • 粒子竖直方向：受电场力作用，加速度a = qU₀/(md)，方向随电压极性变化
  • 电压周期为T，在0~2T/3期间电场向下（A板电势高，正电荷受力向下），在2T/3~T期间电场向上

图示规划：

  • Scene 1：装置结构与电场方向示意，帮助学生建立空间概念
  • Scene 2：电压波形与粒子进入时刻的关系，理解不同入射时刻的粒子受力情况
  • Scene 3：典型粒子轨迹对比与偏转范围分析，直观展示最大偏转位移
步骤 0/4

Scene 1 教学说明：

本图示用于帮助学生建立对实验装置的空间认知。教师应按以下步骤引导学生观察：

  1. 首先展示平行板结构，强调板间距为d，粒子从两板正中间O点入射
  1. 展示靶板位置，说明O′是靶的中心点，也是粒子无偏转时的击中位置
  1. 重点讲解电场方向与电压极性的关系：
  • t=0时，A板电势高于B板，电场方向由A指向B（向下）
  • 带正电粒子受力方向与电场方向相同，即向下
  1. 引导学生理解：粒子在水平方向做匀速运动，在竖直方向受电场力作用产生加速度

关键公式：

  • 电场强度：E = U₀/d
  • 粒子加速度：a = F/m = qE/m = qU₀/(md)
  • 水平方向：x = v₀t
  • 竖直方向：y = ½at²（匀加速阶段）

此图示为后续分析粒子偏转轨迹建立空间参照系。

t₀ = 0

Scene 2 教学说明：

本图示是本题的核心，帮助学生理解"不同时刻入射的粒子经历不同的电场时序"这一关键概念。

引导步骤：

  1. 首先让学生观察电压波形：周期为T，在0~2T/3期间电压为+U₀（电场向下），在2T/3~T期间电压为-U₀（电场向上）
  1. 拖动滑块改变入射时刻t₀，观察高亮区间[t₀, t₀+T]内电压状态的变化
  1. 重点分析两种极端情况：
  • t₀ = 0时：粒子在0~2T/3期间受向下力，在2T/3~T期间受向上力
  • t₀ = 2T/3时：粒子在2T/3~T期间受向上力，在T~5T/3（即下一个周期0~2T/3）期间受向下力
  1. 引导学生理解：虽然所有粒子飞行时间都是T，但由于入射时刻不同，它们在电场中经历的"向下加速"和"向上加速"的时间分配不同，导致最终偏转位移不同

关键推导：
设粒子在t₀时刻入射，加速度大小a = qU₀/(md)

对于t₀ = 0的粒子：

  • 0~2T/3：向下加速，位移 y₁ = ½a(2T/3)² = 2aT²/9
  • 2T/3~T：向上加速，初速度v₁ = a(2T/3)，位移 y₂ = v₁(T/3) - ½a(T/3)² = 2aT²/9 - aT²/18 = 3aT²/18 = aT²/6
  • 总位移：y = y₁ + y₂ = 2aT²/9 + aT²/6 = 7aT²/18

此图示为计算最大偏转范围奠定基础。

步骤 1/5

Scene 3 教学说明：

本图示整合了所有典型轨迹，直观展示粒子击中靶板的范围。

讲解要点：

  1. 轨迹分析：
  • t₀=0入射的粒子：先向下加速2T/3时间，再向上加速T/3时间，最终向下偏转
  • t₀=2T/3入射的粒子：先向上加速T/3时间，再向下加速2T/3时间，最终向上偏转
  • 其他时刻入射的粒子：偏转位移介于两者之间
  1. 最大偏转位移计算（以t₀=0为例）：
  • 第一阶段（0~2T/3）：y₁ = ½a(2T/3)² = 2qU₀T²/(9md)
  • 第一阶段末速度：v₁ = a(2T/3) = 2qU₀T/(3md)
  • 第二阶段（2T/3~T）：y₂ = v₁(T/3) - ½a(T/3)² = 2qU₀T²/(9md) - qU₀T²/(18md) = 3qU₀T²/(18md) = qU₀T²/(6md)
  • 总位移：y_max↓ = y₁ + y₂ = 2qU₀T²/(9md) + qU₀T²/(6md) = 7qU₀T²/(18md)

同理，t₀=2T/3时向上最大偏转：y_max↑ = qU₀T²/(18md)

  1. 击中范围：距O′点上下分别为ymax↓和ymax↑，总范围高度为ymax↓ + ymax↑ = 8qU₀T²/(18md) = 4qU₀T²/(9md)
  1. 第（2）问条件：要使粒子全部打在靶上，最大偏转位移不能超过板间距的一半，即 y_max↓ < d/2，得 U₀ < 9md²/(14qT²)
  1. 第（3）问功的分析：
  • 电场力做功 W = qU_竖直位移
  • 由于所有粒子在竖直方向的位移不同，电场力做功不相等
  • 但注意：粒子在水平方向不受力，只有竖直方向电场力做功
  • 实际上，电场力做功 W = q·(U₀/d)·y，其中y为竖直位移
  • 由于y不同，W也不同，范围为 [qU₀ymax↑/d, qU₀ymax↓/d]

课堂总结：
本题的关键在于理解"不同入射时刻→不同受力时序→不同偏转位移"的因果关系。通过三个图示的递进展示，学生可以从装置认知→时序分析→轨迹对比，完整掌握带电粒子在交变电场中的运动规律。
