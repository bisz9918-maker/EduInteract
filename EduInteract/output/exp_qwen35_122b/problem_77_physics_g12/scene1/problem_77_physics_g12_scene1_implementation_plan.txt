[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "上一步"按钮：位于 SVG 内底部左侧 (50,450)，作用：返回上一状态
  - "下一步"按钮：位于 SVG 内底部右侧 (700,450)，作用：进入下一状态
  - 步骤指示器：位于底部中央 (350,455)，显示"步骤 X/4"
- 教师操作流程：
  1. 初始展示空白框架，教师可先介绍图示主题
  2. 点击"下一步"逐步展示极板、靶板、轴线、入射点、电场等元素
  3. 每步展示后暂停，讲解该部分物理意义
  4. 如需回顾，可点击"上一步"返回
  5. 最终步骤展示完整装置，教师可总结各部分关系

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────┐
  │                    平行板电容器装置                      │  y=30
  │                                                         │
  │   A ─────────────────────────────                       │  y=150-170
  │   │                                                     │
  │   │  ←d→                                                │
  │   │                                                     │  y=250 (轴线)
  │   O ────v₀────→ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ O′             │
  │   │                                                     │
  │   │                                                     │  y=330-350
  │   B ─────────────────────────────                       │
  │                                                         │
  │                              │                          │  y=120-380
  │                              │ M                        │
  │                              │                          │
  │                              │                          │
  │                              │ N                        │  y=380
  │                                                         │
  │  [上一步]                              步骤 4/4           [下一步]  y=450
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量（0-4）跟踪当前步骤
  2. 坐标计算：所有元素坐标硬编码，确保精确到像素级
  3. 动画曲线：元素出现使用 opacity 从 0 到 1 的过渡动画（duration=300ms）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后重绘对应元素
  5. ID 命名规范：所有交互元素 ID 以"scene1-"为前缀（如 scene1-step-btn-next、scene1-step-btn-prev、scene1-plate-a、scene1-plate-b 等）
  6. JS 使用 getElementById 获取元素，避免 querySelectorAll 配合全局 class
  7. IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
  8. 元素显示控制：每个步骤对应一组元素的 display 或 opacity 属性切换
  9. 步骤指示器动态更新：每次步骤变化时更新文本内容
