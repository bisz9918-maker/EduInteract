[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：位于SVG底部左侧(100,450)，点击回退到上一状态
  - "下一步 ▶"按钮：位于SVG底部右侧(650,450)，点击进入下一状态
  - 步骤指示器：位于SVG底部中央(350,450)，显示"步骤 k/4"
- 教师操作流程：
  1. 初始展示装置框架，讲解平行板电容器结构和粒子入射条件
  2. 点击"下一步"展示t₀=0时刻粒子轨迹，讲解此时电场方向向下，粒子向下偏转
  3. 点击"下一步"展示t₀=2T/3时刻粒子轨迹，讲解此时电场方向向上，粒子向上偏转
  4. 点击"下一步"展示其他时刻轨迹，说明不同入射时刻对应不同偏转
  5. 点击"下一步"高亮最大偏转点和击中范围，总结粒子击中靶板的范围

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何绘图，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────┐
  │                                                         │
  │    A ──────────────────────────────── M                 │
  │    │                                  │                 │
  │    │     ╱ (t₀=2T/3 蓝色向上)         │                 │
  │    │   ╱                              │                 │
  │  O─┼─╱─────── (OO' 中心轴线) ───────O′ │                 │
  │    │ ╲                                │                 │
  │    │   ╲ (t₀=0 红色向下)              │                 │
  │    │     ╲                            │                 │
  │    B ──────────────────────────────── N                 │
  │                                                         │
  │  [◀ 上一步]        步骤 k/4        [下一步 ▶]           │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  - 状态机设计：currentStep 变量记录当前步骤(0-4)，updateScene() 函数根据 currentStep 控制元素显示/隐藏
  - 坐标计算：粒子轨迹用贝塞尔曲线模拟抛物线，控制点根据偏转位移计算
  - 动画曲线：轨迹显示使用 stroke-dasharray + stroke-dashoffset 实现绘制动画
  - 事件绑定：按钮点击事件更新 currentStep 并调用 updateScene()
  - ID 命名规范：所有元素 ID 以"scene3-"为前缀（如 scene3-plateA、scene3-trajectory0、scene3-btn-next）
  - IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
- 轨迹绘制公式：
  - t₀=0轨迹：从(50,250)到(600,320)，用二次贝塞尔曲线，控制点(325,285)
  - t₀=2T/3轨迹：从(50,250)到(600,180)，用二次贝塞尔曲线，控制点(325,215)
  - t₀=T/3轨迹：从(50,250)到(600,270)，用二次贝塞尔曲线，控制点(325,260)
  - t₀=T轨迹：从(50,250)到(600,310)，用二次贝塞尔曲线，控制点(325,280)
