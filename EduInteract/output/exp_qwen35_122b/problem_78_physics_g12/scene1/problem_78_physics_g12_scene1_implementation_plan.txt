[分步序列]
- 步骤 0（初始状态）：
  - 显示：完整装置结构（导轨、电阻 R、磁场区域 L₁-L₂、磁场×符号）
  - 显示：导体棒 a 在位置 M（y=100），导体棒 b 在位置 N（y=170）
  - 显示：位置标签 M、N（红色虚线框）
  - 显示：磁场高度标注 d=0.5m
  - 隐藏：速度标注 vₐ、vᵦ，运动箭头
  - 状态：两棒静止，等待开始

- 步骤 1：
  - 新增：两棒同时释放的运动箭头（从 M、N 位置向下）
  - 高亮：a 棒和 b 棒变为#2e7d32 绿色
  - 显示：文字提示"两棒同时由静止释放，自由下落"
  - 状态：两棒开始自由下落（动画：棒位置向下移动）

- 步骤 2：
  - 变化：b 棒到达 L₁位置（y=200），进入磁场
  - 新增：b 棒速度标注 vᵦ（#c62828，在(230,280)）
  - 高亮：b 棒变为#1565c0 蓝色，表示匀速运动
  - 显示：文字提示"b 棒进入磁场，开始匀速运动"
  - 状态：b 棒匀速穿过磁场，a 棒继续自由下落

- 步骤 3：
  - 变化：b 棒在磁场中向下移动（y=275，磁场中部）
  - 变化：a 棒继续下落（y=150）
  - 显示：b 棒运动轨迹箭头（从 L₁到当前位置）
  - 显示：文字提示"b 棒匀速穿过磁场，a 棒继续加速下落"

- 步骤 4（关键时间点）：
  - 变化：b 棒到达 L₂位置（y=350），穿出磁场
  - 变化：a 棒同时到达 L₁位置（y=200），进入磁场
  - 高亮：a 棒变为#1565c0 蓝色，b 棒恢复#000000
  - 新增：a 棒速度标注 vₐ（#1565c0，在(230,250)）
  - 显示：文字提示"b 刚穿出磁场时，a 正好进入磁场"
  - 状态：关键时间关系展示完成

- 步骤 5：
  - 变化：a 棒在磁场中向下移动（y=275，磁场中部）
  - 变化：b 棒离开磁场后继续下落（y=400）
  - 高亮：a 棒保持#1565c0 蓝色，表示匀速运动
  - 显示：文字提示"a 棒匀速穿过磁场，b 棒离开磁场后继续加速"

- 步骤 6（总结）：
  - 显示：两棒完整运动轨迹（虚线箭头）
  - 显示：速度对比 vₐ、vᵦ标注
  - 显示：总结文字"两棒均匀速穿过磁场，vₐ:vᵦ=2:1"
  - 高亮：磁场区域和两棒最终位置

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮（scene1-prev-btn）：位于 (250,455)，点击返回上一步
  - 下一步按钮（scene1-next-btn）：位于 (450,455)，点击进入下一步
  - 步骤指示器：位于 (350,420)，显示"步骤 X/7"
- 教师操作流程：
  1. 初始展示装置结构，讲解导轨、电阻、磁场区域
  2. 点击"下一步"展示两棒同时释放
  3. 继续点击展示 b 棒进入磁场开始匀速运动
  4. 重点讲解步骤 4，强调"b 刚穿出磁场时 a 正好进入磁场"的时间关系
  5. 继续展示 a 棒匀速穿过磁场的过程
  6. 最后总结两棒运动对比，引出速度比计算

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何动画，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    图示区 800×500                       │
  │                                                         │
  │         ┌─────────────────────────────────┐            │
  │         │              R                   │            │
  │         ├─────────────────────────────────┤            │
  │    a ───┤                                  ├─── M       │
  │         │                                  │            │
  │    b ───┤                                  ├─── N       │
  │         │                                  │            │
  │         │         ╳  ╳  ╳  ╳  ╳  ╳        │            │
  │   L₁ ───┤─────────╳  ╳  B  ╳  ╳───────────┤            │
  │         │         ╳  ╳  ╳  ╳  ╳  ╳        │            │
  │         │         ╳  ╳  ╳  ╳  ╳  ╳        │            │
  │   L₂ ───┤─────────╳  ╳  ╳  ╳  ╳  ╳────────┤            │
  │         │         ╳  ╳  ╳  ╳  ╳  ╳        │            │
  │         │                                  │            │
  │    d=0.5m                                  │            │
  │                                                         │
  │         步骤指示器：步骤 1/7                             │
  │         [◀上一步]        [下一步▶]                       │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：currentStep 变量 (0-6)，控制各元素显示/隐藏
  2. 坐标计算：所有元素使用固定像素坐标，棒位置通过 y 坐标控制
  3. 动画曲线：棒移动使用 requestAnimationFrame 实现平滑过渡
  4. 事件绑定：按钮点击事件更新 currentStep，触发 DOM 更新
  5. ID 命名规范：所有元素 ID 以"scene1-"为前缀（如 scene1-rod-a、scene1-rod-b、scene1-magnetic-field）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 元素显示控制：通过 style.display 或 class 切换控制元素可见性
  8. 棒位置动画：使用 transform: translateY() 实现平滑移动
