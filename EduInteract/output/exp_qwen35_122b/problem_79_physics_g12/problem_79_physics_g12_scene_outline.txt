    **题目原文：**

    如图所示，光滑水平面上静止放着长$L=1.6m$，质量为$M=3kg$的木板，一个质量为$m=1kg$的小物块放在木板的最右端，$m$与$M$之间的动摩擦因数为$μ=0.1$，现对木板施加一个水平向右的拉力$F$。（小物块可看作质点，$g=10m⋅s^{−2}$）

    $(1)$施加$F$后，要想把木板从物体$m$的下方抽出来，求力$F$的大小应满足的条件；

    $(2)$如果所施力$F=10N$，为了把木板从物体的下方抽出来，此力$F$的作用时间不得小于多少？

    ---

    **题目分析：**

    这是一道经典的**板块模型**物理题，涉及相对运动和牛顿第二定律的综合应用。

    **核心物理过程：**
    1. 木板 M 受拉力 F 向右加速
    2. 物块 m 通过摩擦力被带动向右加速
    3. 当木板加速度大于物块最大加速度时，两者发生相对滑动
    4. 物块从木板右端滑到左端，相对位移等于板长 L

    **关键公式：**
    - 物块最大加速度：$a_{m,max} = μg = 0.1 × 10 = 1m/s^2$
    - 临界条件：$a_M = a_m$ 时，$F_{min} = (M+m)a_m$
    - 相对位移：$Δx = x_M - x_m = L$

    **图示规划说明：**
    本大纲规划 3 个图示，分别展示：(1) 初始状态与受力分析；(2) 临界状态分析；(3) 运动过程动态演示。
    </TEXT_1>

    **图示 1 教学说明：**

    本图示用于帮助学生建立题目物理图景，教师应按以下步骤引导学生：

    **步骤 0→1：标注已知条件**
    引导学生识别题目中的关键参数：
    - 木板质量 M=3kg，长度 L=1.6m
    - 物块质量 m=1kg
    - 动摩擦因数 μ=0.1

    **步骤 1→2：受力分析**
    重点讲解：
    1. 木板 M 受力：拉力 F 向右，物块对木板的摩擦力 f 向左
    2. 物块 m 受力：木板对物块的摩擦力 f 向右（这是物块运动的动力）
    3. 竖直方向重力与支持力平衡

    **步骤 2→3：摩擦力方向**
    关键理解点：
    - 物块 m 相对木板有向左滑动的趋势
    - 因此木板对物块的摩擦力方向向右
    - 根据牛顿第三定律，物块对木板的摩擦力方向向左

    **核心公式推导：**
    物块能获得的最大加速度由最大静摩擦力决定：

    $f_{max} = μmg$

    $a_{m,max} = \frac{f_{max}}{m} = μg = 0.1 × 10 = 1m/s^2$

    这是后续分析临界条件的基础。

    **图示 2 教学说明：**

    本图示用于讲解临界条件的推导，是解题的关键。

    **步骤 0→1：共速状态理解**
    引导学生理解：
    - 当 F 较小时，木板和物块一起加速，无相对滑动
    - 此时两者加速度相等：$a_M = a_m$

    **步骤 1→2：加速度关系**
    关键推导：
    - 物块加速度由摩擦力提供：$a_m = \frac{f}{m} ≤ μg$
    - 木板加速度：$a_M = \frac{F - f}{M}$
    - 临界状态：$a_M = a_m = μg$

    **步骤 2→3：F 临界值计算**
    完整推导过程：

    临界状态下，整体加速度 $a = μg = 1m/s^2$

    对整体应用牛顿第二定律：

    $F_{min} = (M + m)a = (3 + 1) × 1 = 4N$

    **步骤 3：结论**
    要抽出木板，必须满足：

    $F > F_{min} = 4N$

    **教学要点：**
    强调临界状态是"刚好能抽出"的边界条件，实际抽出需要 F 略大于 4N。

    **图示 3 教学说明：**

    本图示用于动态演示 F=10N 时抽出木板所需的最短时间，是第 (2) 问的可视化。

    **物理过程分析：**

    **阶段 1：F 作用期间（0 ≤ t ≤ t₀）**
    木板加速度：$a_{M1} = \frac{F - μmg}{M} = \frac{10 - 0.1×1×10}{3} = \frac{9}{3} = 3m/s^2$

    物块加速度：$a_{m1} = μg = 1m/s^2$

    **阶段 2：F 撤去后（t > t₀）**
    木板加速度：$a_{M2} = -\frac{μmg}{M} = -\frac{1}{3}m/s^2$（减速）

    物块加速度：$a_{m2} = μg = 1m/s^2$（继续加速）

    **临界条件：**
    物块刚好滑离时，相对位移 Δx = L = 1.6m

    **计算过程：**
    设 F 作用时间为 t₀，此时：
    - 木板速度：$v_M = a_{M1}t₀ = 3t₀$
    - 物块速度：$v_m = a_{m1}t₀ = t₀$
    - 木板位移：$x_{M1} = \frac{1}{2}a_{M1}t₀^2 = 1.5t₀^2$
    - 物块位移：$x_{m1} = \frac{1}{2}a_{m1}t₀^2 = 0.5t₀^2$

    F 撤去后，设再经过时间 t₁物块滑离：
    - 木板：$x_{M2} = v_Mt₁ + \frac{1}{2}a_{M2}t₁^2 = 3t₀t₁ - \frac{1}{6}t₁^2$
    - 物块：$x_{m2} = v_mt₁ + \frac{1}{2}a_{m2}t₁^2 = t₀t₁ + 0.5t₁^2$

    总相对位移：
    $Δx = (x_{M1} + x_{M2}) - (x_{m1} + x_{m2}) = 1.6m$

    解得：$t₀ ≥ 0.8s$

    **教师引导要点：**
    1. 拖动滑块观察相对位移 Δx 的变化
    2. 当 Δx 达到 1.6m 时，记录对应的 t₀值
    3. 理解"最短时间"的含义：小于此时间，物块无法滑离
    4. 强调 F 撤去后木板减速但物块继续加速的相对运动特点

    **完整解答总结：**
    (1) F > 4N
    (2) t₀ ≥ 0.8s
