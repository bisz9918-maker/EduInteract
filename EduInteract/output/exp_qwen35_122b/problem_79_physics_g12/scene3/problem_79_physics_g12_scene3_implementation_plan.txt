[分步序列]
本场景为连续拖拽交互，无分步导航，状态随滑块位置动态变化：

- 初始状态（t=0）：
  - 显示木板和物块的初始位置（黑色实线框）
  - 滑块手柄在最左端
  - 数值显示：t=0.00s, x_M=0.00m, x_m=0.00m, Δx=0.00m
  - 状态指示："就绪"

- 拖拽过程（0 < t ≤ t₀=0.8s，F 作用阶段）：
  - 木板当前位置框向右移动：x_M = 0.5×a_M×t² = 1.5t²
  - 物块当前位置框向右移动：x_m = 0.5×a_m×t² = 0.5t²
  - 拉力 F 箭头显示
  - 状态指示："F 作用中 (F=10N)"
  - 实时显示 t、x_M、x_m、Δx = x_M - x_m

- 拖拽过程（t₀ < t ≤ t_max，F 撤去后阶段）：
  - 拉力 F 箭头隐藏
  - 木板减速：x_M(t) = x_M(t₀) + v_M(t₀)×(t-t₀) + 0.5×a_M'×(t-t₀)²
  - 物块继续加速：x_m(t) = x_m(t₀) + v_m(t₀)×(t-t₀) + 0.5×a_m×(t-t₀)²
  - 状态指示："F 已撤去"
  - 实时显示 t、x_M、x_m、Δx

- 临界状态（Δx = L = 1.6m）：
  - 相对位移线变为粗红色
  - 显示"物块刚好滑离"提示
  - 此时 t ≈ 1.6s

冲突检查：
- M(280,185) 与 m(475,130)：间距≈200px → 无冲突
- M(280,185) 与 F(565,185)：间距≈285px → 无冲突
- L=1.6m(300,270) 与 x_M(300,245)：间距=25px → 无冲突（垂直方向）
- x_M(300,245) 与 Δx(300,265)：间距=20px → 临界，Δx 改为 (300,268)
- 数值区标签间距均为 20px → 无冲突
- t₀(360,420) 与滑块轨道 y=440：间距=20px → 无冲突

解决方案：Δx 标签 y 坐标从 265 调整为 268，确保与 x_M 间距≥23px

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：
  1. 时间滑块（scene3-slider）：底部中央水平滑块，范围 0~3s，拖动手柄改变时间 t
  2. 状态指示框（scene3-status）：左上角显示当前阶段"F 作用中"或"F 已撤去"
  3. 数值显示框（scene3-values）：右侧实时显示 t、x_M、x_m、Δx 的数值

- 教师操作流程：
  1. 初始状态展示题目条件（木板 M、物块 m、长度 L）
  2. 拖动滑块从 t=0 开始，演示 F 作用阶段木板和物块的加速运动
  3. 观察 t₀=0.8s 时滑块上的红色标记，说明此时撤去 F
  4. 继续拖动滑块，演示 F 撤去后木板减速、物块继续加速的过程
  5. 当Δx 接近 1.6m 时，强调临界条件：物块刚好滑离木板
  6. 可反复拖动对比不同时刻的位移关系

关键实现要点：
1. 状态机设计：
   - 阶段 0：t ≤ t₀，F 作用，a_M=3m/s², a_m=1m/s²
   - 阶段 1：t > t₀，F 撤去，a_M'=-μMg/M=-0.33m/s², a_m=1m/s²
   
2. 坐标计算：
   - 比例尺：1m = 250px（L=1.6m → 400px）
   - x_M(t) 和 x_m(t) 根据运动学公式实时计算
   - 当前位置框的 x 坐标 = 初始 x + 位移（px）

3. 动画曲线：平滑插值，使用 requestAnimationFrame 实现流畅拖动反馈

4. 事件绑定：
   - 滑块 mousedown/mousemove/mouseup 处理拖拽
   - 触摸事件支持移动端
   - 边界检查：t 限制在 0~3s

5. ID 命名规范：所有元素 ID 以 scene3- 为前缀
   - scene3-slider, scene3-slider-track, scene3-slider-handle
   - scene3-status, scene3-values, scene3-木板初始, scene3-物块初始
   - scene3-木板当前, scene3-物块当前, scene3-F 箭头

6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染

7. 物理参数（F=10N 情况）：
   - a_m = μg = 1m/s²
   - a_M = (F-μmg)/M = 3m/s²
   - t₀ = 0.8s（临界作用时间）
   - F 撤去后 a_M' = -μmg/M = -0.33m/s²
