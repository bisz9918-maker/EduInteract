[图示主题与整合说明]
- 本图示主题：甲物块在两种情况下的浮力对比分析

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：位置 (260,455)，作用：返回上一步骤，若已在步骤 0 则禁用
  - "下一步 ▶"按钮：位置 (440,455)，作用：进入下一步骤，若已在最终步骤则禁用
  - 步骤指示器：位置 (350,460)，显示"步骤 1/5"，帮助教师了解当前进度
- 教师操作流程：
  1. 初始展示两种情况的基本图形，引导学生观察甲的位置
  2. 点击"下一步"高亮甲，强调排开水体积相同
  3. 点击"下一步"显示浮力箭头，讲解阿基米德原理
  4. 点击"下一步"显示受力分析，引导学生推导 T = G_丙
  5. 点击"下一步"显示结论，总结正确选项

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │                    图示区 800×500                           │
  │                                                             │
  │   左图区域 (50-390)           右图区域 (450-750)            │
  │   ┌─────────────┐             ┌─────────────┐              │
  │   │   水面线    │             │   水面线    │              │
  │   │  ┌───────┐  │             │  ┌───────┐  │              │
  │   │  │  甲   │  │             │  │  甲   │  │              │
  │   │  └───┬───┘  │             │  └───┬───┘  │              │
  │   │      │      │             │   ┌──┴──┐  │              │
  │   │   ┌──┴──┐   │             │   │ 丙  │  │              │
  │   │   │  乙  │   │             │   └─────┘  │              │
  │   │   └─────┘   │             │            │              │
  │   └─────────────┘             └─────────────┘              │
  │                                                             │
  │   [公式区]              [结论区]              [公式区]      │
  │                                                             │
  │   ┌───────────────────────────────────────────────────┐   │
  │   │        ◀ 上一步    [步骤 1/5]    下一步 ▶          │   │
  │   └───────────────────────────────────────────────────┘   │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep 记录当前步骤（0-4），根据 currentStep 控制元素显示/隐藏
  2. 坐标计算：所有元素坐标已在布局坐标表中精确定义，直接按坐标绘制
  3. 动画曲线：步骤切换使用淡入淡出效果（opacity 0→1，duration 300ms）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后重绘/切换元素显示状态
  5. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-block-jia-left、scene1-arrow-fu-left）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 元素分组：用 SVG <g> 元素按步骤分组，便于批量显示/隐藏（如 scene1-step2-group）
