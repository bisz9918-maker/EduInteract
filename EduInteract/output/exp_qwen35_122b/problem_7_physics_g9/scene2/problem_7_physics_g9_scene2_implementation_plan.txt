[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "上一步"按钮：ID=scene2-prevBtn，位置 (300,450)，作用：返回上一状态，步骤 0 时禁用
  - "下一步"按钮：ID=scene2-nextBtn，位置 (420,450)，作用：进入下一状态，最终步骤时禁用
- 教师操作流程：
  1. 初始展示乙和丙的基本受力（重力）
  2. 点击"下一步"，展示乙的完整受力（浮力、拉力）及平衡方程
  3. 点击"下一步"，分析乙的密度与水的关系，指出选项 C 错误
  4. 点击"下一步"，推导乙和丙的质量关系，得出最终答案
  5. 如需复习，可点击"上一步"回退

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何和文本，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │                        800px                                   │
  │  ┌─────────────┐              ┌─────────────┐                  │
  │  │   乙受力    │   公式/结论   │   丙受力    │                  │
  │  │   分析区    │   推导区      │   分析区    │   500px          │
  │  │  (100-350)  │   (350-450)  │  (450-700)  │                  │
  │  │             │              │             │                  │
  │  │  [乙物块]   │   T+F浮=G乙  │  [丙物块]   │                  │
  │  │   ↓G乙      │              │   ↓G丙      │                  │
  │  │  ↑F浮 ↑T   │   ρ乙>ρ水    │   ↑N        │                  │
  │  │             │   m乙>m丙    │             │                  │
  │  └─────────────┘              └─────────────┘                  │
  │                                                                  │
  │  ┌──────────────────────────────────────────────────────────┐  │
  │  │              [◀上一步]  [下一步▶]  (控件栏)               │  │
  │  └──────────────────────────────────────────────────────────┘  │
  └────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep 记录当前步骤（0-3），根据 currentStep 控制元素显示/隐藏
  2. 坐标计算：所有元素使用绝对坐标，确保无重叠
  3. 动画曲线：元素出现使用 opacity 渐变（0→1），时长 300ms
  4. 事件绑定：按钮点击事件更新 currentStep，重新渲染显示状态
  5. ID 命名规范：所有交互元素 ID 以 scene2- 为前缀（如 scene2-rect-yi、scene2-arrow-Gyi、scene2-prevBtn、scene2-nextBtn）
  6. IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局污染
  7. 元素显示控制：用 display 或 opacity 控制，步骤 0 时仅显示基础元素，后续步骤逐步显示
