[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "上一步"按钮：scene1-btn-prev，位置 (620,460)，作用：返回上一状态
  - "下一步"按钮：scene1-btn-next，位置 (700,460)，作用：进入下一状态
  - 步骤指示器：scene1-step-indicator，位置 (350,460)，显示"步骤 1/4"
- 教师操作流程：
  1. 初始展示摆动 setup，讲解角度和绳长
  2. 点击"下一步"展示摆动轨迹，讲解能量转换
  3. 点击"下一步"展示最低点状态，讲解向心力
  4. 点击"下一步"展示平抛轨迹，讲解运动分解
  5. 可随时点击"上一步"回退复习

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何动画，无需重型库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    800 × 500 SVG 画布                    │
  │                                                         │
  │    O(300,80)                                            │
  │     ╱  ←初始绳(蓝)                                       │
  │    ╱                                                     │
  │   m(166,181)                                            │
  │    ╲                                                     │
  │     ╲ ←摆动轨迹(蓝虚)                                    │
  │      │                                                   │
  │      │ ←最低点绳(黑)                                     │
  │      ●(300,248) → v(红箭头)                              │
  │       ╲                                                  │
  │        ╲ ←平抛轨迹(绿虚)                                  │
  │         ╲                                                │
  │          ●(650,400) ←浮台                                │
  │  岸│────────────────────────────────────────────水面────  │
  │     │                                                    │
  │     │  标注区：H、h₂、d 在右侧和下方                       │
  │                                                         │
  │  [步骤指示] [◀上一步] [下一步▶] ← 控件栏 y=460~480        │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：currentStep 变量 (0-3)，updateScene() 函数根据 currentStep 显示/隐藏元素
  2. 坐标计算：使用 SVG transform 和 path 命令精确绘制圆弧和抛物线
  3. 动画曲线：使用 CSS transition 实现元素淡入淡出 (opacity: 0→1)
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateScene()
  5. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-rope-init、scene1-mass-low）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 抛物线绘制：使用 SVG path 命令 "M x1 y1 Q cx cy x2 y2"（二次贝塞尔曲线）
  8. 圆弧绘制：使用 SVG path 命令 "M x1 y1 A rx ry 0 large-arc-flag sweep-flag x2 y2"
