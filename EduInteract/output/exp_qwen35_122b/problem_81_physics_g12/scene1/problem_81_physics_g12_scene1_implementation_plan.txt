[分步序列]
- 步骤0（初始状态）：显示系统完整配置（墙面、平台、弹簧、物体A、滑轮、细线、物体B），显示物体标签A、B和质量m，显示角度30°，不显示力矢量
- 步骤1（B的受力分析）：在步骤0基础上，高亮物体B，显示B的受力矢量：重力G_B（向下，标注mg）、拉力T_B（向上，标注T）
- 步骤2（A的受力分析）：在步骤1基础上，高亮物体A，显示A的受力矢量：重力G_A（向下，标注mg）、支持力N（向上，标注N）、弹力F_弹（向左，标注F_弹）、拉力T_A（右上30°，标注T）
- 步骤3（平衡方程与弹簧伸长量）：在步骤2基础上，显示平衡方程文本框（位于右侧空白区）：
  - B平衡：T = mg
  - A水平平衡：F_弹 = T·cos30° = mg·cos30°
  - A竖直平衡：N + T·sin30° = mg
  - 弹簧伸长量：x₀ = F_弹/k = (mg·cos30°)/k

[交互方案]

  - 按钮"◀ 上一步"：位置(250,460)，作用：返回上一状态
  - 按钮"下一步 ▶"：位置(500,460)，作用：进入下一状态

- 教师操作流程：

  2. 点击"下一步"展示B的受力，讲解悬挂物体的平衡
  3. 点击"下一步"展示A的受力，讲解平台上物体的多力平衡
  4. 点击"下一步"展示平衡方程和弹簧伸长量计算，引导学生推导

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────┐
  │                    天花板支架                           │
  │                    ────────                             │
  │                       ○ 滑轮                            │
  │                      /                                  │
  │                     / 细线                              │
  │    弹簧    ┌────┐  /                                    │
  │   ~~~~~~   │ A  │/                                      │
  │  ──────────┴────┼──────────平台─────────────────────    │
  │   墙面          │                                       │
  │                 │                                       │
  │                 │              B                        │
  │                 │             ┌───┐                     │
  │                 │             │   │                     │
  │                 │             └───┘                     │
  │                                                         │
  │  [◀ 上一步]  步骤 X/3  [下一步 ▶]  (控件栏 y=440~490)   │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep 记录当前步骤（0-3），每一步显示对应的力矢量和标签
  2. 坐标计算：所有元素使用绝对坐标，力矢量箭头用 line + polygon 实现
  3. 动画曲线：力矢量出现使用 opacity 从 0 到 1 的过渡动画（0.3s ease）
  4. 事件绑定：按钮点击事件更新 currentStep，重新渲染对应步骤的元素
  5. ID 命名规范：所有元素 ID 以"scene1-"为前缀（如 scene1-obj-A、scene1-force-T_A）
  6. IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
  7. 力矢量绘制：每个力矢量由 line（箭杆）+ polygon（箭头）组成，箭头指向力的方向
  8. 弹簧绘制：用 polyline 绘制锯齿线，10个锯齿，每个锯齿宽12px高10px
