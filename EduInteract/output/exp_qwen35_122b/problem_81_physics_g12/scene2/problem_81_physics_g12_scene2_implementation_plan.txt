[分步序列]
步骤 0（初始状态 - 悬线断开瞬间）：
- 显示：左侧墙面、水平轨道、弹簧（连接墙面与 A，长度 130px）、物体 A 在初始位置 (150,150)、初始位置线（#1565c0）、右侧天花板、滑轮、物体 B 在初始高度 (630,100)、地面线、高度标注线、时间轴及 t=0 标记
- 隐藏：平衡位置线、压缩最短线、振幅标注线、t=T/4 和 t=T/2 标记
- 标签：显示"A"、"B"、"初始"、"h"、"t=0"

步骤 1（A 运动至平衡位置，B 下落一段距离）：
- 显示：弹簧（伸长至 180px）、物体 A 移动至平衡位置 (200,150)、平衡位置线（#2e7d32）、物体 B 下落至中间位置 (630,200)、t=T/4 标记（蓝色高亮）
- 隐藏：初始位置线（或变淡）、物体 A 和 B 的初始位置（变淡）
- 新增标签：在时间轴 t=T/4 处显示"t=T/4"
- 动画：A 从初始位置平滑移动至平衡位置，B 从初始高度下落至中间

步骤 2（A 运动至压缩最短，B 落地）：
- 显示：弹簧（压缩至 60px）、物体 A 移动至压缩最短位置 (30,150)、压缩最短线（#c62828）、物体 B 落地 (630,310)、t=T/2 标记（红色高亮）
- 隐藏：平衡位置线（或变淡）、物体 A 和 B 的中间位置（变淡）
- 新增标签：在时间轴 t=T/2 处显示"t=T/2"
- 新增：振幅标注线（#1565c0 双向箭头，从压缩最短位置到初始位置）、标签"A"
- 动画：A 从平衡位置平滑移动至压缩最短位置，B 从中间位置下落至地面

步骤 3（时间关系总结）：
- 显示：所有位置线（初始、平衡、压缩最短）同时显示、振幅标注完整显示、时间轴上三个时间点全部高亮
- 新增文字说明：在时间轴下方显示"当 B 落地时（t=T/2），A 恰好将弹簧压缩到最短"
- 高亮：用彩色箭头连接 t=T/2 标记与压缩最短位置，强调时间同步关系

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "上一步"按钮：scene2-btn-prev，位置 (320,455)，作用：返回上一状态
  - "下一步"按钮：scene2-btn-next，位置 (440,455)，作用：进入下一状态
  - 步骤指示器：scene2-step-indicator，位置 (350,430)，显示"步骤 X/4"
- 教师操作流程：
  1. 初始展示悬线断开瞬间的系统状态
  2. 点击"下一步"，展示 A 运动到平衡位置、B 下落的过程，强调 t=T/4 时刻
  3. 再次点击"下一步"，展示 A 压缩弹簧到最短、B 落地的过程，强调 t=T/2 时刻
  4. 最后一步总结时间关系，突出"当 B 落地时 A 恰好将弹簧压缩到最短"这一关键条件
  5. 可随时点击"上一步"回退复习，帮助学生理解运动过程

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何动画，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────────┐
  │  A 的简谐运动                    B 的自由落体                │
  │  ┌─────────────────────┐      ┌─────────────────┐          │
  │  │  墙面  弹簧  A      │      │    天花板      │          │
  │  │  │     ~~~~  □     │      │      ────      │          │
  │  │  │          │      │      │       ○ 滑轮   │          │
  │  │  └──────────┼──────┘      │       │         │          │
  │  │   初始 平衡 压缩           │       │ B □     │          │
  │  │   │    │    │             │       │  ↓      │          │
  │  │   └────┴────┴───振幅 A    │       │         │          │
  │  │          轨道             │      ─┴───────地面         │
  │  └───────────────────────────┘      └─────────────────┘   │
  │                                                             │
  │  时间轴：●════════●════════●                               │
  │         t=0     t=T/4     t=T/2                            │
  │                                                             │
  │              [◀上一步]  步骤 1/4  [下一步▶]                 │
  └─────────────────────────────────────────────────────────────┘
  ```

- 关键实现要点：
  1. 状态机设计：用变量 currentStep 记录当前步骤（0-3），每一步定义显示/隐藏的元素列表
  2. 坐标计算：所有元素位置预先计算好，存储在配置对象中，便于步骤切换时快速定位
  3. 动画曲线：使用 requestAnimationFrame 实现平滑过渡，A 和 B 的位置变化用线性插值
  4. 事件绑定：按钮点击事件更新 currentStep，触发视图更新函数
  5. ID 命名规范：所有元素 ID 以 scene2- 为前缀（如 scene2-obj-a、scene2-spring、scene2-btn-next）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染

- SVG 元素 ID 命名：
  - 物体：scene2-obj-a、scene2-obj-b
  - 弹簧：scene2-spring
  - 位置线：scene2-line-initial、scene2-line-equilibrium、scene2-line-compressed
  - 标注：scene2-amp-arrow、scene2-height-arrow
  - 时间轴：scene2-time-axis、scene2-time-dot-0、scene2-time-dot-1、scene2-time-dot-2
  - 标签：scene2-label-a、scene2-label-b、scene2-label-h、scene2-label-amplitude
  - 控件：scene2-btn-prev、scene2-btn-next、scene2-step-indicator

- 状态切换逻辑：
  ```javascript
  function updateScene(step) {
    // 根据 step 显示/隐藏对应元素
    // 更新物体 A、B 的位置
    // 更新弹簧长度
    // 高亮当前时间标记
    // 更新步骤指示器
  }
  ```
