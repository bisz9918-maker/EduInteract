[分步序列]
步骤0（初始状态）：
- 显示：斜面、三球（A在顶端、B在中点、C在底部）、两绳、弧形挡板
- 显示：所有质量标签(3m,2m,m)、球名标签(A,B,C)、绳长标签(L)、角度30°、高度L
- 高亮：无（所有球白色填充）
- 隐藏：A下落轨迹虚线

步骤1（A球下落L至落地）：
- 变化：A球沿虚线从(650,150)移动到(650,300)
- 变化：绳AB缩短（A球位置改变，B球沿斜面向上移动L距离至(650,150)）
- 变化：绳BC保持长度L，C球沿斜面向上移动L距离至(425,225)
- 高亮：A球红高亮#c62828（已落地静止），B球蓝高亮#1565c0（当前主动运动），C球绿高亮#2e7d32（被带动）
- 显示：A下落轨迹虚线
- 阶段标签："阶段1：A下落"

步骤2（B球继续上升至斜面顶端）：
- 变化：B球从斜面中点(425,225)移动到斜面顶端(650,150)
- 变化：C球从斜面中点(425,225)移动到斜面顶端(650,150)
- 变化：绳BC缩短，B球到达顶端后开始竖直下落
- 高亮：A球红高亮#c62828（已落地静止），B球蓝高亮#1565c0（当前主动运动），C球绿高亮#2e7d32（被带动）
- 阶段标签："阶段2：B上升"

步骤3（B球竖直下落，C球继续运动）：

- 变化：C球从斜面顶端(650,150)沿斜面向下运动
- 高亮：A球红高亮#c62828（已落地静止），B球红高亮#c62828（已落地静止），C球蓝高亮#1565c0（当前主动运动）
- 阶段标签："阶段3：B下落"

结论（三阶段速度变化总结）：

[标签冲突检查]
- 标签"3m"：坐标(670,135)
- 标签"A"：坐标(665,155)
- "3m"与"A"间距：√[(670-665)²+(135-155)²] = √(25+400) = √425 ≈ 20.6px → 无冲突（≥20px）

- 标签"2m"：坐标(425,205)
- 标签"B"：坐标(440,230)
- "2m"与"B"间距：√[(425-440)²+(205-230)²] = √(225+625) = √850 ≈ 29.2px → 无冲突

- 标签"m"：坐标(185,290)
- 标签"C"：坐标(185,305)
- "m"与"C"间距：|290-305| = 15px → 有冲突！解决方案：将"C"改为(170,305)，间距变为√[(185-170)²+(290-305)²] = √(225+225) = √450 ≈ 21.2px → 无冲突

- 标签"L"(绳AB)：坐标(530,180)
- 标签"2m"：坐标(425,205)
- 间距：√[(530-425)²+(180-205)²] = √(11025+625) = √11650 ≈ 108px → 无冲突

- 标签"L"(绳BC)：坐标(315,255)
- 标签"m"：坐标(185,290)
- 间距：√[(315-185)²+(255-290)²] = √(16900+1225) = √18125 ≈ 135px → 无冲突

- 标签"30°"：坐标(230,290)
- 标签"m"：坐标(185,290)
- 间距：|230-185| = 45px → 无冲突

- 标签"L"(高度)：坐标(665,225)
- 标签"3m"：坐标(670,135)
- 间距：√[(665-670)²+(225-135)²] = √(25+8100) = √8125 ≈ 90px → 无冲突

- 控件区标签与主图区：控件栏在y=440~490，主图最低点在y=300+18=318，间距122px → 无冲突

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：位置(250,455)，点击返回上一状态，步骤0时禁用
  - "下一步 ▶"按钮：位置(450,455)，点击进入下一状态，结论步骤时禁用
  - 阶段标签：位置(350,460)，显示当前阶段名称
- 教师操作流程：
  1. 初始展示系统配置（步骤0）
  2. 点击"下一步"演示A球下落过程，讲解第一阶段能量守恒
  3. 点击"下一步"演示B球继续上升，讲解第二阶段运动特点
  4. 点击"下一步"演示B球下落带动C，讲解第三阶段
  5. 点击"下一步"展示结论，总结三阶段速度变化
  6. 可随时点击"上一步"回退复习某个阶段

- 关键实现要点：
  1. 状态机设计：currentStep 变量(0-5)，对应步骤0-结论
  2. 坐标计算：斜面角度30°，sin30°=0.5，cos30°=√3/2≈0.866
     - 斜面长度2L=300px（L=150px）
     - A初始(650,150)，B初始(425,225)，C初始(200,300)
     - 沿斜面移动L=150px对应像素距离250px（因缩放）
  3. 动画曲线：使用 requestAnimationFrame 实现平滑过渡，easing 函数采用 easeInOutQuad
  4. 事件绑定：按钮点击事件监听，步骤0禁用上一步，步骤5禁用下一步
  5. 高亮切换：通过修改 circle fill 属性实现颜色变化
  6. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-ball-A、scene1-rod-AB、scene1-prev-btn）
  7. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  8. 状态保存：每个步骤保存三球位置、高亮状态、轨迹显示状态到配置对象
