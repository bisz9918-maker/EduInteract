    **题目原文：**
    如图所示，宽度$L=1m$的足够长的$U$形金属框架水平放置，右端接有$R=0.8Ω$的电阻$R$，框架处在竖直向上的匀强磁场中，磁感应强度$B=1T$，框架导轨上放置一根质量$m=0.2Kg$、电阻$r=0.2Ω$的金属金属棒$ab$，棒$ab$与导轨间的动摩擦因数为$μ=0.5$，现用一恒力$F=3N$的力使棒从静止开始沿导轨运动(棒始终与导轨接触良好且垂直)，经过一段时间棒获得稳定速度，此过程中，通过棒的电量$q=2.8C$(框架电阻不计，$g=10m⋅s^{−2}$)问：

    $(1)$棒$ab$达到的稳定速度是多大？
    $(2)$从开始到速度稳定时，电阻$R$产生的热量是多少？

    **题目分析：**
    本题是电磁感应与动力学、能量综合问题。核心物理过程：金属棒在恒力作用下从静止开始运动，切割磁感线产生感应电动势和感应电流，同时受到安培力和摩擦力的作用。随着速度增加，安培力增大，加速度减小，最终达到受力平衡的稳定状态。

    **关键物理关系：**
    1. 稳定状态：外力 F = 安培力 F_A + 摩擦力 f
    2. 安培力：F_A = BIL = B²L²v/(R+r)
    3. 摩擦力：f = μmg
    4. 能量守恒：W_F = ΔE_k + Q_f + Q_总

    **图示规划说明：**
    规划 2 个核心图示：
    - Scene 1：装置结构与受力分析（整合装置展示、受力标注、平衡条件）
    - Scene 2：运动过程与能量转化（整合速度变化、能量分配、热量计算）

    **教学要点：**

    1. **引导学生观察装置结构**
    教师应先展示步骤 0-1，让学生识别 U 形框架、金属棒、电阻、磁场等基本元素。强调这是"俯视图"，磁场方向垂直纸面向上。

    2. **受力分析的逻辑顺序**
    按步骤 2-4 依次添加三个力，引导学生分析每个力的来源：
    - 外力 F：人为施加的恒力，方向向左
    - 摩擦力 f：棒与导轨间的滑动摩擦，f = μmg = 0.5 × 0.2 × 10 = 1N，方向向右
    - 安培力 F_A：感应电流在磁场中受到的力，方向与运动方向相反（向右）

    3. **稳定状态的物理意义**
    步骤 5 高亮平衡条件 F = F_A + f，这是解题关键。引导学生理解：
    - 初始时刻 v=0，F_A=0，加速度最大
    - 随着 v 增大，F_A 增大，加速度减小
    - 当 F = F_A + f 时，a=0，速度达到稳定值 v_m

    4. **稳定速度的计算**
    由 F = F_A + f 得：
    F = B²L²v_m/(R+r) + μmg

    代入数据：3 = 1²×1²×v_m/(0.8+0.2) + 0.5×0.2×10

    解得：v_m = 2m/s

    <TEXT_3>
    **教学要点：**

    1. **运动过程分析**
    展示 v-t 曲线，引导学生理解：
    - 初始阶段：v 小，F_A 小，加速度大
    - 中间阶段：v 增大，F_A 增大，加速度减小
    - 稳定阶段：a=0，v=v_m 恒定

    2. **电量与位移的关系**
    由电磁感应定律：q = ∫I·dt = ∫(E/(R+r))·dt = ∫(BLv/(R+r))·dt = BLx/(R+r)

    代入已知 q=2.8C，得：x = q(R+r)/(BL) = 2.8×1/(1×1) = 2.8m

    3. **能量守恒计算**
    外力做功：W_F = F·x = 3×2.8 = 8.4J

    动能增量：ΔE_k = ½mv_m² = ½×0.2×2² = 0.4J

    摩擦生热：Q_f = f·x = μmg·x = 1×2.8 = 2.8J

    总焦耳热：Q_总 = W_F - ΔE_k - Q_f = 8.4 - 0.4 - 2.8 = 5.2J

    4. **电阻 R 的热量分配**
    串联电路中，热量按电阻比例分配：
    Q_R = Q_总 × R/(R+r) = 5.2 × 0.8/(0.8+0.2) = 5.2 × 0.8 = 4.16J

    **课堂讲解建议：**
    - 先通过 Scene 1 建立物理模型，明确受力关系
    - 再用 Scene 2 分析运动过程和能量转化
    - 强调"稳定速度"是受力平衡的结果，而非速度不再变化
    - 提醒学生注意热量分配是按电阻比例，而非平均分配
    </TEXT_3>
