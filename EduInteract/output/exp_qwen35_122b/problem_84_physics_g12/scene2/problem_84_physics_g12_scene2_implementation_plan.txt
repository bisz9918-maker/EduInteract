[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "上一步"按钮（scene2-prev-btn）：位于底部左侧，点击返回前一状态，初始禁用
  - "下一步"按钮（scene2-next-btn）：位于底部右侧，点击进入下一状态，最终步骤隐藏
- 教师操作流程：
  1. 初始展示 v-t 曲线，引入运动过程概念
  2. 点击下一步，标注稳定速度 v_m，讲解受力平衡条件
  3. 点击下一步，展示电量与位移关系，推导位移 x
  4. 点击下一步，展示能量分配条形图，讲解能量守恒
  5. 点击下一步，展示最终热量计算结果 Q_R=4.16J

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无需额外库，几何图形和简单动画用原生即可实现）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │ 800×500 画布                                                   │
  │                                                                │
  │  ┌──────────────┐  ┌────────────────────────────────────┐     │
  │  │ v-t 曲线图   │  │ 电量公式框                         │     │
  │  │ (60,40)      │  │ (380,40)                           │     │
  │  │ 280×300      │  │ 360×100                            │     │
  │  └──────────────┘  └────────────────────────────────────┘     │
  │                                                                │
  │  ┌──────────────┐  ┌────────────────────────────────────┐     │
  │  │ (留白)       │  │ 能量分配条形图                     │     │
  │  │              │  │ (380,180)                          │     │
  │  │              │  │ 360×160                            │     │
  │  └──────────────┘  └────────────────────────────────────┘     │
  │                                                                │
  │  ┌──────────────────────────────────────────────────────┐     │
  │  │ 热量计算结果框                                       │     │
  │  │ (380,360) 360×60                                     │     │
  │  └──────────────────────────────────────────────────────┘     │
  │                                                                │
  │  ┌──────────────────────────────────────────────────────┐     │
  │  │           [上一步]              [下一步]             │     │
  │  │           (290,450)             (430,450)            │     │
  │  └──────────────────────────────────────────────────────┘     │
  └────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用 currentStep 变量（0-4）跟踪当前步骤，steps 数组存储每步应显示的元素 ID 列表
  2. 坐标计算：v-t 曲线采用指数函数 v(t) = v_m × (1 - e^(-kt)) 的离散点绘制，k 值调节曲线陡峭度
  3. 条形图高度映射：1J = 约 12px 高度（100px 对应 8.4J）
  4. 元素显示/隐藏：通过 setAttribute('display', 'none/block') 控制 SVG 元素可见性
  5. 按钮状态：currentStep=0 时禁用"上一步"，currentStep=4 时隐藏"下一步"
  6. ID 命名规范：所有交互元素 ID 以 scene2- 为前缀（如 scene2-vt-curve、scene2-prev-btn、scene2-next-btn）
  7. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  8. 事件绑定：使用 addEventListener 绑定按钮点击事件，事件处理函数内部更新状态并刷新显示
