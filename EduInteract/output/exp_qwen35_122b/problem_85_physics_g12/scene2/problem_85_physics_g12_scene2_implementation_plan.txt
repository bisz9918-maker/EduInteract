[分步序列]
本场景采用连续拖拽交互，无分步导航，状态随滑块连续变化：

- 初始状态（滑块最左端）：
  - 活塞 b 位于 y=230（气缸 B 中部，H/2 位置）
  - 氮气体积 V = V₀（初始值）
  - 氮气温度 T = 280K（7℃）
  - 氮气压强 P = P₀（恒定）
  - 氮气区域显示为绿色填充，从活塞 a 下方延伸至活塞 b 下方

- 拖拽过程（滑块从左到右）：
  - 活塞 b 从 y=230 连续移动到 y=80
  - 氮气体积 V 从 V₀ 线性增加到 2V₀（因为 B 气缸截面积是 A 的 1/4，活塞 b 上升 H/2 时，氮气体积增加量等于活塞 a 上方氧气体积的 2 倍）
  - 氮气温度 T 从 280K 线性增加到 420K（等压膨胀，V∝T）
  - 氮气区域绿色填充范围随活塞 b 位置动态扩大
  - 状态显示框数值实时更新

- 最终状态（滑块最右端）：
  - 活塞 b 位于 y=80（气缸 B 顶部）
  - 氮气体积 V = 2V₀
  - 氮气温度 T = 420K（147℃）
  - 氮气压强 P = P₀（仍为恒定）
  - 显示"过程 (1) 完成"提示

- 教师操作流程：
  1. 图示加载后，活塞 b 位于初始位置（气缸 B 中部）
  2. 教师讲解初始状态：活塞 b 在 H/2，氮气温度 7℃，压强 P₀
  3. 教师拖动滑块向右，活塞 b 同步上升

- 画布尺寸：800 × 500 px

- 关键实现要点：
  1. 状态机设计：
     - 滑块位置 x ∈ [250, 550]，映射到活塞 b 的 y 坐标：y_b = 230 - (x - 250) * 150 / 300 = 230 - (x - 250) * 0.5
     - 当 x=250 时，y_b=230（初始位置 H/2）
     - 当 x=550 时，y_b=80（顶部位置 H）
  
  2. 体积计算：
     - 气缸 A 直径是 B 的 2 倍，截面积 S_A = 4 * S_B
     - 设气缸高度 H=300px，S_B = k，S_A = 4k
     - 初始氮气体积 V₀ = S_A * (H - H/4) + S_B * (H/2) = 4k * 225 + k * 150 = 1050k
     - 活塞 b 上升距离 Δh = 230 - y_b（像素），对应实际高度比例 Δh/H
     - 当前氮气体积 V = V₀ + S_B * (230 - y_b) * H/150
  
  3. 温度计算（等压过程 V∝T）：
     - 初始温度 T₀ = 280K（7℃）
     - 当前温度 T = T₀ * V / V₀
  
  4. 氮气区域动态绘制：
     - 使用 SVG <path> 元素，根据活塞 b 位置动态更新 d 属性
     - 路径：从活塞 a 左端开始，向下到气缸 A 底部，向右到气缸 B 底部，向上到活塞 b，向左到气缸 B 左壁，向下到气缸 A 底部，闭合
  
  5. 事件绑定：
     - 滑块手柄 mousedown 事件：开始拖拽，设置 isDragging = true
     - document mousemove 事件：更新滑块位置，同步更新活塞 b 和状态显示
     - document mouseup 事件：结束拖拽，设置 isDragging = false
     - 触摸事件支持：touchstart/touchmove/touchend
  
  6. ID 命名规范：
     - 所有交互元素 ID 以 scene2- 为前缀
     - 例如：scene2-slider-track, scene2-slider-handle, scene2-piston-b, scene2-nitrogen-area
  
  7. IIFE 隔离：
     - 所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染

- 数值显示格式：
  - P：固定显示 "P = P₀"
  - V：显示 "V = X.X V₀"（保留 1 位小数）
  - T：显示 "T = XXX K (XX℃)"（保留整数）
