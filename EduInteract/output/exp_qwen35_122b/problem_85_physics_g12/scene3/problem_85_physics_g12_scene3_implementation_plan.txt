[分步序列]
本场景为连续拖拽交互，无分步按钮，状态随滑块位置连续变化：

- 初始状态（滑块最左，Δh = 0）：
  - 活塞 a 位于 y = 155（初始位置，离顶部 H/4 = 75px，气缸高度 H = 300px）
  - 氧气体积 V_氧 = V₀ = S_A × 75（S_A 为气缸 A 截面积）
  - 氧气压强 P_氧 = P₀（初始大气压）
  - 氧气温度 T_氧 = T₀ = 280K（7℃）
  - 活塞 b 固定在顶部 y = 84

- 拖动过程（Δh 从 0 到 H/16 = 18.75px）：
  - 活塞 a 向上移动，y_a = 155 - Δh
  - 氧气体积 V_氧 = S_A × (75 - Δh)，线性减小
  - 氧气压强 P_氧 = P₀ × 75 / (75 - Δh)，按玻意耳定律增大
  - 氧气温度 T_氧 = T₀ 恒定（等温过程）
  - 进度条和数值实时同步更新

- 最终状态（滑块最右，Δh = H/16 = 18.75px）：
  - 活塞 a 位于 y = 136.25
  - 氧气体积 V_氧 = S_A × 56.25 = 0.75V₀
  - 氧气压强 P_氧 = P₀ × 75 / 56.25 = 1.33P₀
  - 氧气温度 T_氧 = T₀ = 280K

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：
  - 滑块轨道：位于底部中央 (250, 430)-(550, 430)，灰色水平线
  - 滑块手柄：蓝色圆形，可沿轨道左右拖动
  - 左侧标记 "0"：表示 Δh = 0（初始位置）
  - 右侧标记 "H/16"：表示 Δh = H/16（最大上升距离）
  - 数值显示 "Δh值"：实时显示当前上升距离（单位：px 或 H 的分数）

- 教师操作流程：
  1. 图示加载后，活塞 a 位于初始位置，显示初始状态（P_氧 = P₀, V_氧 = V₀, T_氧 = T₀）
  2. 教师讲解：过程 (2) 中活塞 b 已升至顶部固定，继续加热使活塞 a 上升
  3. 教师拖动滑块从左向右，演示活塞 a 上升过程
  4. 学生观察：氧气体积减小（进度条缩短）、压强增大（进度条增长）、温度恒定
  5. 教师引导：验证 P_氧 × V_氧 = 常数（玻意耳定律）
  6. 滑块拖至最右，显示最终状态（P_氧 = 1.33P₀, V_氧 = 0.75V₀）

- 关键实现要点：
  1. 状态机设计：单一状态变量 delta_h（0 到 H/16 = 18.75），所有显示值由此计算
  2. 坐标计算：
     - 气缸高度 H = 300px
     - 活塞 a 初始 y = 80 + 75 = 155（离顶部 75px = H/4）
     - 活塞 a 当前 y = 155 - delta_h
     - 氧气体积比例 = (75 - delta_h) / 75
     - 氧气压强比例 = 75 / (75 - delta_h)
  3. 动画曲线：滑块拖动时实时更新，无需缓动（物理过程演示）
  4. 事件绑定：
     - mousedown/mousemove/mouseup 实现滑块拖动
     - touchstart/touchmove/touchend 支持移动端
  5. 数值格式化：压强显示为 "1.33 P₀" 格式，体积显示为 "0.75 V₀" 格式
  6. 进度条更新：根据数值比例动态调整填充宽度
