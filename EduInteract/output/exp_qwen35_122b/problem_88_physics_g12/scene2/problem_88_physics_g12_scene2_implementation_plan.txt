[分步序列]
- 初始状态（步骤0）：
  - 显示：圆弧轨道、金属棒cd（实线）、磁场B箭头、速度v₀箭头、半径r标注
  - 隐藏：金属棒ab、电阻R、内阻r、电路连线、电流I、电动势E、电流变化曲线
  - 目的：展示题目基础条件，金属棒在最低位置cd开始运动

- 步骤1：点击「下一步」→
  - 新增：金属棒ab（虚线，表示终点位置）、电动势E标注(215,250)
  - 显示公式文本：E = BLv₀（在左侧图上方）
  - 目的：展示初始时刻金属棒切割磁感线产生感应电动势

- 步骤2：点击「下一步」→
  - 新增：右侧电路等效图（电阻R、内阻r、电路连线）
  - 新增：电流I箭头（沿电路顺时针方向）
  - 显示公式文本：I = E/(R+r) = E/(4R/3)（在电路图上方）
  - 目的：展示闭合回路中的电流方向和大小计算

- 步骤3：点击「下一步」→
  - 新增：电流变化曲线（下方区域）
  - 曲线特征：I随θ增大而减小（因为有效切割速度分量减小）
  - 显示公式文本：I(θ) = BLv₀cosθ/(R+r)（在曲线图上方）
  - 目的：展示整个运动过程中电流的变化规律

- 步骤4（最终步骤）：点击「下一步」→
  - 高亮：所有关键元素（电动势E、电流I、电阻R、内阻r）
  - 汇总显示：完整电路分析结论
  - 目的：整合所有知识点，形成完整认知

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "上一步"按钮：scene2-prev-btn，位置(300,455)-(380,475)，点击后返回上一状态
  - "下一步"按钮：scene2-next-btn，位置(420,455)-(500,475)，点击后进入下一状态
  - 初始状态时"上一步"按钮禁用
  - 最终状态时"下一步"按钮禁用
- 教师操作流程：
  1. 初始展示金属棒在cd位置，讲解题目条件
  2. 点击"下一步"，展示电动势产生，讲解E=BLv₀公式
  3. 点击"下一步"，展示电路等效图，讲解电流方向和大小计算
  4. 点击"下一步"，展示电流变化曲线，讲解I(θ)变化规律
  5. 可点击"上一步"回退复习任意阶段

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何和动画，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │                    电磁感应过程分析 (标题)                      │
  ├──────────────────────┬──────────────────────┬──────────────────┤
  │                      │                      │                  │
  │   左侧示意图区        │    右侧电路图区       │                  │
  │   (金属棒切割磁感线)   │    (电路等效图)       │                  │
  │                      │                      │                  │
  │   B ↑  ↑  ↑          │   ┌───R───┐          │                  │
  │   │  │  │ v₀→        │   │       │          │                  │
  │   └──┴──┘            │   └───r───┘          │                  │
  │   cd (实线)          │                      │                  │
  │   ab (虚线)          │                      │                  │
  │                      │                      │                  │
  ├──────────────────────┴──────────────────────┴──────────────────┤
  │                      电流变化曲线区                              │
  │   I ↑                                                          │
  │     │    ╭───────╮                                             │
  │     │   ╱         ╲                                            │
  │     └──┴───────────┴──→ θ                                      │
  ├────────────────────────────────────────────────────────────────┤
  │                        [上一步]  [下一步]                        │
  └────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-4) 跟踪当前步骤
  2. 元素显示控制：每个元素设置 data-step 属性，根据 currentStep 控制 display 属性
  3. 坐标计算：所有元素使用绝对坐标，避免相对定位导致的重叠
  4. 动画曲线：电流变化曲线使用 SVG path 绘制，坐标点预先计算
  5. 事件绑定：按钮点击事件监听，更新 currentStep 后刷新显示
  6. ID 命名规范：所有元素 ID 以 scene2- 为前缀（如 scene2-rod-cd、scene2-resistor-R）
  7. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  8. 按钮状态管理：currentStep=0 时禁用"上一步"，currentStep=4 时禁用"下一步"
