场景导航：Scene 1 | Scene 2

题目原文：

如图所示，在直角坐标系 xoy 中，虚线 ab 将第一象限分成两块区域，左边区域匀强电场沿 x 轴正方向，电场强度 E₁，右边区域匀强电场方向沿 y 轴负方向，电场强度 E₂。现一个质量为 m（重力忽略不计），电荷量为 q 的正粒子静止放在 y 轴上的 P（0，h）点，粒子在电场力的作用下运动，最后从 x 轴上的 Q 点离开电场区域，已知虚线 ab 距 y 轴的距离 L，求：

（1）粒子穿过 E₁ 电场区域的速度；

（2）粒子经过 Q 点的速度大小；

（3）Q 点的坐标。

题目分析：

本题是带电粒子在分段匀强电场中的运动问题，涉及两个阶段的运动分析：

  1. 第一阶段（E₁ 区域，0 < x < L）：粒子从 P(0, h) 静止释放，受水平向右的电场力 F₁ = qE₁，沿 x 轴正方向做匀加速直线运动。
  1. 第二阶段（E₂ 区域，x > L）：粒子以速度 v₁ 进入 E₂ 区域，受竖直向下的电场力 F₂ = qE₂，做类平抛运动（水平匀速，竖直匀加速）。

整体讲解思路：

  • 首先通过图示展示电场分布和粒子运动轨迹，帮助学生建立空间概念
  • 然后分步分析两个阶段的运动规律，运用动能定理和运动学公式求解
  • 最后综合两个阶段的结果，求出 Q 点坐标

本大纲设计 2 个图示场景：

步骤 1/5

SCENE_1 教学说明：

本图示用于展示粒子在分段电场中的完整运动过程，教师应按以下步骤引导学生观察：

步骤 0-1：理解电场分布与初始运动

首先展示初始状态，让学生明确：

  • 两个电场区域的分界（虚线 ab，x=L）
  • E₁电场方向水平向右，E₂电场方向竖直向下
  • 正粒子在 P 点静止释放，受 E₁电场力作用沿 x 轴正方向加速

讲解要点：

  • 粒子在 E₁区域只受水平电场力 F₁ = qE₁
  • 由动能定理：qE₁L = ½mv₁² - 0
  • 解得穿过 ab 线时的速度：v₁ = √(2qE₁L/m)，方向水平向右

步骤 2-3：分析进入 E₂后的运动

展示粒子进入 E₂区域后的偏转轨迹，强调：

  • 水平方向：不受力，保持 v₁匀速运动
  • 竖直方向：受向下的电场力 F₂ = qE₂，做初速度为 0 的匀加速运动

讲解要点：

  • 竖直加速度：a₂ = qE₂/m
  • 竖直位移：h = ½a₂t² = ½(qE₂/m)t²
  • 运动时间：t = √(2mh/qE₂)
  • 竖直分速度：v_y = a₂t = √(2qE₂h/m)

步骤 4：求解 Q 点坐标

高亮 Q 点位置，总结：

  • 水平位移增量：Δx = v₁t = √(2qE₁L/m) × √(2mh/qE₂) = 2L√(E₁/E₂)
  • Q 点横坐标：x_Q = L + Δx = L + 2L√(E₁/E₂) = L(1 + 2√(E₁/E₂))
  • Q 点纵坐标：y_Q = 0（在 x 轴上）
步骤 1/4

SCENE_2 教学说明：

本图示用于深入分析粒子速度的变化规律，教师应引导学生理解速度矢量的分解与合成：

步骤 0-1：从静止到水平加速

展示 P 点静止状态和 ab 线处的速度 v₁：

  • 初始：v₀ = 0
  • 在 E₁区域，电场力做功 W₁ = qE₁L
  • 由动能定理：qE₁L = ½mv₁²
  • 得：v₁ = √(2qE₁L/m)

步骤 2：速度分解

展示 Q 点速度 v₂的分解：

  • 水平分量：v_x = v₁（水平方向匀速）
  • 竖直分量：v_y = √(2qE₂h/m)（竖直方向匀加速，位移 h）
  • 合速度：v₂ = √(vx² + vy²) = √(v₁² + v_y²)

步骤 3：综合计算

代入 v₁和 v_y 的表达式：

  • v₂ = √(2qE₁L/m + 2qE₂h/m) = √[2q(E₁L + E₂h)/m]

课堂讲解建议：

  1. 先让学生观察 SCENE_1 的运动轨迹，建立直观认识
  2. 再用 SCENE_2 深入分析速度变化，强调矢量分解的思想
  3. 引导学生总结：分段电场问题需要分阶段应用运动学规律，注意各阶段的速度衔接
  4. 最后给出完整答案：
  • (1) v₁ = √(2qE₁L/m)
  • (2) v₂ = √[2q(E₁L + E₂h)/m]
  • (3) Q 点坐标：(L(1 + 2√(E₁/E₂)), 0)
