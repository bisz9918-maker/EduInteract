[分步序列]
- 步骤 0（初始状态）：
  - 显示：坐标系（x 轴、y 轴、原点 O）、虚线 ab、E₁和 E₂区域背景及电场线、P 点及标签 P(0,h)、L 标注、a/b 标签
  - 隐藏：粒子轨迹、Q 点、速度矢量、粒子
  - 目的：展示题目基础条件，电场区域划分和粒子初始位置

- 步骤 1（粒子在 E₁中加速）：
  - 新增：轨迹段 1（P 点到 ab 线的水平直线）、v₁矢量箭头及标签、粒子（位于轨迹起点 P）
  - 粒子开始沿轨迹段 1 向右移动（动画）
  - 目的：展示粒子在水平电场 E₁中做匀加速直线运动，获得水平速度 v₁

- 步骤 2（ab 线处速度分解）：
  - 新增：粒子停在 ab 线处 (350,250)
  - 高亮：ab 线（加粗闪烁）、v₁矢量（加粗）
  - 目的：强调粒子进入 E₂区域前的状态，速度方向水平，大小为 v₁

- 步骤 3（粒子在 E₂中偏转）：
  - 新增：轨迹段 2（从 ab 线到 Q 点的抛物线）、v₂矢量箭头及标签、Q 点及标签
  - 粒子从 ab 线沿抛物线运动到 Q 点（动画）
  - 目的：展示粒子在竖直电场 E₂中受向下的电场力，做类平抛运动，轨迹向下偏转

- 步骤 4（结论）：
  - 高亮：Q 点（放大闪烁）、Q 点坐标位置
  - 显示：Q 点坐标标注（如 Q(x_Q, 0)）
  - 目的：强调粒子最终从 x 轴上的 Q 点离开电场区域，引出第 (3) 问求解 Q 点坐标

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 上一步按钮：scene1-btn-prev，位置 (280, 455)，作用：返回上一状态
  - 下一步按钮：scene1-btn-next，位置 (500, 455)，作用：进入下一状态
  - 步骤指示器：scene1-step-indicator，位置 (370, 455)，显示 "步骤 1/5"
- 教师操作流程：
  1. 初始展示电场区域和 P 点，讲解题目条件
  2. 点击"下一步"→ 显示粒子在 E₁中的运动轨迹和 v₁，讲解水平加速过程
  3. 点击"下一步"→ 高亮 ab 线处状态，讲解速度进入 E₂区域前的状态
  4. 点击"下一步"→ 显示粒子在 E₂中的偏转轨迹和 v₂，讲解类平抛运动
  5. 点击"下一步"→ 高亮 Q 点，引出坐标求解问题
  6. 可随时点击"上一步"回退复习关键步骤

- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-4) 跟踪当前步骤，updateScene() 函数根据 currentStep 显示/隐藏对应元素
  2. 坐标计算：所有元素坐标按上述布局表精确实现，使用 SVG 坐标系统
  3. 动画曲线：粒子运动使用 requestAnimationFrame 实现平滑动画，E₁区域匀速/匀加速，E₂区域抛物线轨迹
  4. 事件绑定：按钮点击事件绑定到 scene1-btn-prev 和 scene1-btn-next，边界检查防止越界
  5. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-axis-x、scene1-point-P、scene1-traj-1 等）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
