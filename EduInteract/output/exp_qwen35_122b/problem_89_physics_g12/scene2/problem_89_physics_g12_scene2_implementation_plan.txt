[图示主题与整合说明]
- 本图示主题：速度矢量分解与合成分析

[分步序列]

  - 隐藏：所有速度矢量（v₁、v₂、v_x、v_y）、合成三角形、公式标签

- 步骤 1（ab 线处速度）：
  - 新增：v₁矢量箭头从 (280,200) 指向 (400,200)，蓝色

  - 说明：粒子穿过 E₁电场后获得水平速度 v₁

- 步骤 2（Q 点速度分解）：
  - 新增：v_x 矢量箭头从 (600,400) 指向 (700,400)，蓝色
  - 新增：v_y 矢量箭头从 (700,400) 指向 (700,280)，红色
  - 新增：v₂矢量箭头从 (600,400) 指向 (700,280)，绿色
  - 新增：合成三角形虚线连接 (600,400)-(700,400)-(700,280)
  - 新增：v_x 标签在 (650,415)、v_y 标签在 (715,340)、v₂标签在 (650,325)
  - 说明：粒子在 Q 点的速度 v₂分解为水平分量 v_x=v₁和竖直分量 v_y

- 步骤 3（结论）：

  - 保留：步骤 2 所有元素

- 教师操作流程：

  2. 点击"下一步"展示粒子穿过 E₁后的水平速度 v₁
  3. 点击"下一步"展示 Q 点速度分解，讲解 v_x=v₁、v_y 的合成
  4. 点击"下一步"展示速度大小公式，总结矢量合成规律
  5. 可随时点击"上一步"回退复习关键概念

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形和动画，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │  y                                                          │
  │  ↑                                                          │
  │  │    E₁区域          ab        E₂区域                      │
  │  │  ┌─────────┐       │      ┌──────────────────┐          │
  │  │  │  →→→→   │       │      │      ↓           │          │
  │  │  │  →→→→   │       │      │      ↓           │          │
  │  │  │  →→→→   │       │      │      ↓           │          │
  │  │  P●  →→→→   │       │      │      ↓           │          │
  │  │  (v₀=0)    │       │      │      ↓           │          │
  │  │            │       │      │      ↓           │          │
  │  └────────────┼───────┼──────┼──────────────────┘          │
  │  O            │       │      │                             │
  │  └────────────┴───────┴──────┴─────────────────────────→ x  │
  │                     b      Q                               │
  │                                                             │
  │              [步骤指示器: 步骤 1/4]                          │
  │              [◀ 上一步]  [下一步 ▶]                         │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-3) 跟踪当前步骤，updateScene() 函数根据 currentStep 显示/隐藏对应元素
  2. 坐标计算：所有元素坐标硬编码在 SVG 属性中，确保精确位置
  3. 动画曲线：步骤切换使用 CSS transition (opacity 0.3s ease) 实现平滑过渡
  4. 事件绑定：按钮点击事件调用 nextStep() / prevStep() 函数，更新 currentStep 后调用 updateScene()
  5. ID 命名规范：所有元素 ID 以"scene2-"为前缀（如 scene2-axis-x、scene2-vec-v1、scene2-btn-next）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 元素显示控制：用 CSS class "hidden" (display: none) 控制元素显示/隐藏，updateScene() 中切换 class
