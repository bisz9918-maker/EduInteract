[标签冲突检查]
列出所有标签名及其预计坐标，逐对检查间距：
- 标签"L₁"：坐标(600, 95)
- 标签"L₂"：坐标(180, 365)
- 标签"开关"：坐标(180, 85)
- 标签"电压表"：坐标(410, 185)
- 标签"电源"：坐标(660, 365)
- 状态描述文字：坐标(520, 70) 起

冲突检查：
- "L₁"(600,95) 与 "开关"(180,85)：水平距离 420px → 无冲突
- "L₁"(600,95) 与 "电压表"(410,185)：水平距离 190px，垂直距离 90px → 无冲突
- "L₂"(180,365) 与 "开关"(180,85)：垂直距离 280px → 无冲突
- "L₂"(180,365) 与 "电源"(660,365)：水平距离 480px → 无冲突
- "电压表"(410,185) 与 "状态描述"(520,70)：水平距离 110px，垂直距离 115px → 无冲突
- 所有按钮标签间距：140px 按钮宽 + 10px 间距 = 150px 中心距 → 无冲突

结论：所有标签间距均≥100px，无冲突。

[交互方案]
- 交互类型：多状态切换（5 个状态按钮）
- 控件说明：
  - 按钮 1 "正常"：位置(60,430)，切换到正常电路状态
  - 按钮 2 "L₁短路"：位置(210,430)，切换到 L₁短路故障状态
  - 按钮 3 "L₁断路"：位置(360,430)，切换到 L₁断路故障状态
  - 按钮 4 "L₂短路"：位置(510,430)，切换到 L₂短路故障状态
  - 按钮 5 "L₂断路"：位置(660,430)，切换到 L₂断路故障状态
- 教师操作流程：
  1. 点击"正常"按钮，展示正常串联电路现象（两灯都亮，电压表有示数）
  2. 依次点击各故障按钮，对比不同故障下的现象差异
  3. 引导学生根据题目条件（一灯亮一灯不亮，电压表有示数）推理故障原因
  4. 最终得出结论：L₁短路符合题意（L₁不亮，L₂亮，电压表有示数）

- 关键实现要点：
  1. 状态机设计：用变量 currentStatus (0-4) 记录当前状态
  2. 坐标计算：所有元素使用绝对坐标，SVG 元素通过 x/y/cx/cy 属性定位
  3. 灯泡亮灭：通过 fill 属性切换 (#ffeb3b 或 #9e9e9e)
  4. 电压表示数：通过 stroke 属性切换 (#2e7d32 或 #9e9e9e)，指针角度通过 transform 旋转
  5. 按钮高亮：通过 fill 属性切换，激活状态用对应颜色
  6. 描述文字更新：通过 textContent 动态更新状态描述
  7. ID 命名规范：所有元素 ID 以 scene2- 为前缀（如 scene2-bulb-l1, scene2-btn-normal）
  8. JS 使用 getElementById 获取元素，避免 querySelectorAll 全局污染
  9. 所有 JS 代码包在 IIFE (function() { ... })() 中隔离作用域
  10. 故障高亮：短路状态用#2e7d32 外框，断路状态用#c62828 断点标记
