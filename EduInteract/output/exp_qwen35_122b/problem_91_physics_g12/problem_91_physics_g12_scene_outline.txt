    <TEXT_1>
    **题目原文：**

    如图所示，光滑绝缘水平面上固定着 A、B、C 三个带电小球，它们的质量为 m，间距均为 r，A、B 带正电，电荷量均为 q。现对 C 施一水平力 F 的同时放开三个小球，欲使三小球在运动过程中保持间距 r 不变，求：

    （1）C 球的电性和电荷量；

    （2）水平力 F 的大小。

    ---

    **题目分析：**

    本题是静电学与牛顿力学的综合应用题，核心在于理解"保持间距不变"的物理含义——三小球必须有**相同的加速度**，这样才能保持相对位置不变。

    **关键物理概念：**
    1. 库仑定律：F = k·q₁q₂/r²
    2. 牛顿第二定律：F = ma
    3. 等边三角形几何关系（内角 60°）
    4. 力的矢量合成

    **解题思路：**
    1. 首先判断 C 球电性：A、B 均带正电，若 C 也带正电，则 A、B 对 C 的斥力会使 C 远离，无法保持等边三角形结构；因此 C 必须带负电，A、B 对 C 的吸引力才能与外力 F 平衡
    2. 对 C 球受力分析：A、B 对 C 的库仑引力 + 外力 F = ma
    3. 对 A 球（或 B 球）受力分析：B 对 A 的斥力 + C 对 A 的引力 = ma
    4. 联立方程求解

    **图示规划说明：**
    本大题需要 2 个教学图示：
    - Scene 1：展示三球位置关系、电荷分布、各球受力分析（库仑力方向）
    - Scene 2：展示力的矢量合成与牛顿第二定律的应用，逐步推导求解过程
    </TEXT_1>

    **Scene 1 教学说明：**

    本图示用于引导学生理解三球系统的受力结构，教师应按以下步骤讲解：

    **步骤 0-1：建立几何模型**
    首先展示等边三角形结构，强调"间距均为 r"意味着三球构成等边三角形，内角均为 60°。这是后续力分解的几何基础。

    **步骤 2-3：库仑力方向判断**
    引导学生根据电荷性质判断力的方向：
    - 同种电荷相斥：A、B 均带正电，故 F_AB 与 F_BA 为斥力，沿 AB 连线向外
    - 异种电荷相吸：若 C 带负电，则 F_AC、F_BC 为引力，沿 AC、BC 连线指向 C

    **步骤 4-5：电性判断的关键推理**
    这是本题的核心难点。教师应引导学生思考：
    1. 若 C 带正电，A、B 对 C 的斥力将使 C 向右加速远离，而 A、B 将相互远离，无法保持等边三角形
    2. 若 C 带负电，A、B 对 C 的引力指向左方，可与外力 F 平衡；同时 C 对 A、B 的引力指向右方，可抵消 A、B 间的斥力
    3. 因此 C 必须带负电

    **关键公式提示：**
    库仑定律：$$F = k\\frac{q_1 q_2}{r^2}$$

    教师应强调：力的方向判断是解题的第一步，也是判断 C 球电性的依据。

    **Scene 2 教学说明：**

    本图示用于展示完整的数学推导过程，教师应配合方程逐步讲解：

    **步骤 0-2：C 球受力分析**

    C 球受到 A、B 的库仑引力：
    $$F_{AC} = F_{BC} = k\\frac{qQ}{r^2}$$

    两力夹角为 60°，合力沿水平向左方向：
    $$F_{合C} = 2F_{AC}\\cos30° = 2k\\frac{qQ}{r^2} \\cdot \\frac{\\sqrt{3}}{2} = \\sqrt{3}k\\frac{qQ}{r^2}$$

    根据牛顿第二定律（C 球）：
    $$F - F_{合C} = ma$$
    $$F - \\sqrt{3}k\\frac{qQ}{r^2} = ma$$ ……①

    **步骤 3-5：A 球受力分析**

    A 球受到：
    - B 的斥力：$$F_{BA} = k\\frac{q^2}{r^2}$$（水平向右）
    - C 的引力：$$F_{CA} = k\\frac{qQ}{r^2}$$（沿 AC 方向，与水平成 30°）

    F_CA 的水平分量：
    $$F_{CA_x} = F_{CA}\\cos30° = k\\frac{qQ}{r^2} \\cdot \\frac{\\sqrt{3}}{2}$$

    A 球合力（水平向右）：
    $$F_{合A} = F_{BA} + F_{CA_x} = k\\frac{q^2}{r^2} + \\frac{\\sqrt{3}}{2}k\\frac{qQ}{r^2}$$

    根据牛顿第二定律（A 球）：
    $$F_{合A} = ma$$ ……②

    **步骤 6：联立求解**

    由①②式，ma 相等：
    $$F - \\sqrt{3}k\\frac{qQ}{r^2} = k\\frac{q^2}{r^2} + \\frac{\\sqrt{3}}{2}k\\frac{qQ}{r^2}$$

    整理得：
    $$F = k\\frac{q^2}{r^2} + \\frac{3\\sqrt{3}}{2}k\\frac{qQ}{r^2}$$

    另外，考虑系统整体：F = 3ma

    联立求解可得：
    **Q = 2q**（C 球带负电，电荷量为 2q）
    **F = 3kq²/r²**

    **课堂讲解建议：**
    1. 强调"保持间距不变"等价于"三球加速度相同"，这是列方程的关键
    2. 力分解时注意角度：等边三角形内角 60°，力与水平夹角 30°
    3. 提醒学生注意力的方向，这是容易出错的地方
    4. 最终结果验证：Q = 2q 说明 C 球电荷量是 A、B 的两倍，这是保持系统稳定的必要条件
    </TEXT_3>
