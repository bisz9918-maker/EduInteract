[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    图示区 800×500                       │
  │                                                         │
  │   A ────────────────M        P                          │
  │   │                 │        │                          │
  │   │    E↓↓↓↓        │   L    │                          │
  │   │  ↓↓↓↓↓↓         │←──────→│                          │
  │  R●──→v₀   抛物线    │  直线   │                          │
  │   │  ~~~~→          │  ─────→│                          │
  │   │        v↗θ      │        │                          │
  │   │       ↗v_y      │        │                          │
  │   │      →v_x       │        │                          │
  │   │                 │        │                          │
  │   B ────────────────N        S                          │
  │   ←──── l ────→     │        │                          │
  │   ↑                                                         │
  │   d                                                         │
  │                                                         │
  │                    [◀上一步] [步骤 1/5] [下一步▶]         │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用 currentStep 变量（0-4）跟踪当前步骤，每一步定义 showElements 和 hideElements 数组
  2. 坐标计算：所有元素坐标硬编码在配置对象中，便于维护和修改
  3. 动画曲线：抛物线用 SVG path 的 Q（二次贝塞尔）或 C（三次贝塞尔）命令绘制
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后重绘可见元素
  5. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-plate-A、scene1-trajectory-1）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 使用 requestAnimationFrame 实现轨迹动画效果（可选）
