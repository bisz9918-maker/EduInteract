[分步序列]

  - 显示：中心线、界面 PS、荧光屏 EF、点电荷 O、粒子入射点 P_in

  - 显示：偏离距离线及标签"y=12cm"
  - 隐藏：粒子轨迹、速度矢量、库仑力矢量、角度弧线、直角符号、标签"θ"、"垂直"

- 步骤 1：
  - 新增：粒子轨迹曲线（从 P_in 到 E，向中心线弯曲）
  - 新增：入射速度矢量 v1（从 P_in 指向右下方）
  - 新增：角度弧线及标签"θ"
  - 说明：轨迹向中心线弯曲，表明粒子受指向 O 点的吸引力

- 步骤 2：
  - 新增：出射速度矢量 v2（从 E 点水平向右）
  - 新增：直角符号及标签"垂直"
  - 说明：粒子垂直打在荧光屏上，速度方向水平

- 步骤 3：
  - 新增：库仑力矢量 F（从轨迹上某点指向 O 点）
  - 高亮：点电荷 O 及标签"-Q"
  - 说明：粒子带正电且受吸引力→Q 为负电荷

- 步骤 4（最终步骤）：
  - 高亮：整个轨迹及所有矢量
  - 显示计算思路提示："利用能量守恒或库仑力提供向心力计算 Q"
  - 说明：已知入射条件、轨迹几何、垂直出射条件，可列方程求解 Q

[交互方案]

- 控件说明：
  - "上一步"按钮：scene2-btn-prev，位置 (320,460)，作用：返回上一状态
  - "下一步"按钮：scene2-btn-next，位置 (480,460)，作用：进入下一状态

- 教师操作流程：
  1. 初始展示题目基础条件（界面、点电荷位置、入射点）
  2. 点击"下一步"展示轨迹和入射速度，引导学生观察轨迹弯曲方向
  3. 点击"下一步"展示垂直出射条件，强调几何约束
  4. 点击"下一步"展示库仑力方向，推断点电荷电性
  5. 点击"下一步"展示完整分析，引出电量计算思路
  6. 可随时点击"上一步"回退复习关键概念

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────┐
  │                                                         │
  │    P                                                    │
  │    │                                                    │
  │    │        粒子轨迹                                     │
  │    │       ╱───────╲                                    │
  │    │      ╱    F    ╲      v2→                         │
  │    │     ╱           ╲    ────────>                    │
  │  PS│    ● P_in        ● E ────────────● O   ────────   │
  │    │   ╱  v1→          │              -Q    荧光屏 EF   │
  │    │  ╱   θ            │                                 │
  │    │ ╱     y=12cm      │                                 │
  │    │╱       ↑          │                                 │
  │    └────────┼──────────┼─────────────────────────────   │
  │             │          │                                 │
  │             │          │                                 │
  │    S        │          │                                 │
  │             │          │                                 │
  │         中心线─────────┼─────────────────────────────   │
  │                       │                                 │
  │  [◀上一步]  [下一步▶]  [步骤 k/4]                        │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep 记录当前步骤（0-4），每一步定义要显示/隐藏的元素 ID 列表
  2. 坐标计算：所有元素坐标按布局坐标表精确实现，使用 SVG 的 x、y 属性
  3. 动画曲线：粒子轨迹使用 SVG 的<path>元素，d 属性为贝塞尔曲线命令（M x1 y1 C cx1 cy1 cx2 cy2 x2 y2）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateDisplay() 函数刷新显示
  5. ID 命名规范：所有元素 ID 以 scene2- 为前缀（如 scene2-line-center、scene2-circle-O、scene2-path-trajectory 等）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 箭头绘制：使用 SVG 的<marker>定义箭头头部，在<line>或<path>的 marker-end 属性中引用
  8. 双箭头绘制：使用两条带箭头的线段或自定义路径实现
  9. 直角符号：使用<path>绘制 L 形折线
