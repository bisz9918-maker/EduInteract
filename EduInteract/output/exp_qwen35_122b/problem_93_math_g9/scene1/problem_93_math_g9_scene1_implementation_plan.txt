[分步序列]
- 步骤0（初始状态）：
  - 显示线段AB（黑线，100,350到700,350）
  - 显示点A、B（黑点）
  - 显示标签"A"、"B"、"AB=8"
  - 等待教师点击"下一步"

- 步骤1：
  - 添加等边三角形ACD（蓝框，填充20%）
  - 添加等边三角形BCE（蓝框，填充20%）
  - 添加点C、D、E
  - 添加标签"C"、"D"、"E"
  - 添加角度标注"60°"在两个三角形内
  - 视觉变化：两个等边三角形出现

- 步骤2：
  - 添加线段DE（黑线）
  - 添加点P（DE中点，绿框）
  - 添加点F（BE中点，绿框）
  - 添加标签"P"、"F"
  - 视觉变化：DE线段和中点出现

- 步骤3：
  - 添加线段AF（黑线）
  - 添加交点G（AF∩DC）
  - 添加交点H（AF∩CE）
  - 添加标签"G"、"H"
  - 视觉变化：AF线段和交点出现

- 步骤4：
  - 高亮相似三角形对△ACG∽△ABF（红色虚线框）
  - 高亮相似三角形对△BHF∽△BCA（红色虚线框）
  - 添加相似符号"∽"标签
  - 视觉变化：红色高亮框出现

- 步骤5（最终步骤）：
  - 显示所有相似三角形总结文本
  - 列出：△ACG∽△ABF，△BHF∽△BCA，△DGP∽△EFP等
  - 视觉变化：总结文本框出现

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 按钮"◀ 上一步"：位置(280,460)，作用：返回上一状态
  - 按钮"下一步 ▶"：位置(520,460)，作用：进入下一状态
  - 步骤指示器：位置(380,430)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始显示AB线段，引入题目基本条件
  2. 点击"下一步"，展示两个等边三角形，讲解等边性质
  3. 点击"下一步"，展示DE和中点P、F，讲解中点概念
  4. 点击"下一步"，展示AF和交点G、H，讲解交点形成
  5. 点击"下一步"，高亮相似三角形，引导学生识别相似关系
  6. 点击"下一步"，总结所有相似三角形，完成问题(1)的解答

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（几何图形简单，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  ┌─────────────────────────────────────────────────┐
  │              图示区 800×500                      │
  │                                                  │
  │           D(225,133)        E(525,47)           │
  │              ●────────────────●                  │
  │             / \              / \                 │
  │            /   \            /   \                │
  │           /     \          /     \               │
  │    A(100,350) C(350,350)        B(700,350)       │
  │      ●─────────●──────────────────●              │
  │                                                  │
  │      G(265,265)     H(465,265)                  │
  │         ●────────────●                           │
  │          \          /                           │
  │           \        /                            │
  │            \      /                             │
  │             \    /                              │
  │              \  /                               │
  │               ● F(630,199)                      │
  │                                                  │
  │         步骤指示器 [步骤 X/5]                    │
  │         [◀ 上一步]  [下一步 ▶]                   │
  └─────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：currentStep变量(0-5)，每一步对应不同的元素显示集合
  2. 坐标计算：使用精确像素坐标，等边三角形高度=边长×√3/2
  3. 动画曲线：元素出现使用opacity从0到1的过渡动画(300ms ease-in-out)
  4. 事件绑定：按钮click事件触发stepChange函数，更新currentStep并重新渲染
  5. ID命名规范：所有元素ID以"scene1-"为前缀（如scene1-line-ab、scene1-point-a）
  6. IIFE隔离：所有JS代码包裹在(function(){ ... })()中，避免全局污染
  7. 使用SVG的<g>元素分组管理相关元素，便于批量显示/隐藏
  8. 相似三角形高亮框使用SVG的<polygon>元素，动态计算顶点坐标
