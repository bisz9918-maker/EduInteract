[交互方案]

  5. 点击「下一步」高亮三段线段，引导学生计算比例
  6. 最终步骤展示完整结论

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（几何图形简单，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
```
┌─────────────────────────────────────────────────────┐
│                    图示区 800×500                    │
│                                                      │
│         D(250,96)──────P(400,96)──────E(550,96)     │
│          ╲              │              ╱             │
│           ╲             │ CP           ╱             │
│            ╲            │ (绿)        ╱              │
│             G(283,240)  │            H(467,283)      │
│              ╲          │           ╱                │
│               ╲         │          ╱                 │
│                ╲        │         ╱                  │
│                 A(100,350)──C(400,350)──B(700,350)   │
│                          ╱    │    ╲                 │
│                         F(550,223)                   │
│                                                      │
│         结论：CP=2√3, AG:GH:HF=3:2:1                 │
│                                                      │
│         [◀上一步]  步骤 3/5  [下一步▶]               │
│         (620,460)   (350,465)   (700,460)            │
└─────────────────────────────────────────────────────┘
```

- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-5) 控制当前步骤，每一步定义要显示/高亮的元素 ID 列表
  2. 坐标计算：所有坐标预先计算好，硬编码在 JS 中，确保精确
  3. 动画曲线：元素出现使用 opacity 从 0 到 1 的过渡动画 (0.3s ease-in-out)
  4. 事件绑定：按钮点击事件更新 currentStep，调用 updateScene() 刷新显示
  5. ID 命名规范：所有元素 ID 以 scene2- 为前缀（如 scene2-line-ab, scene2-point-d, scene2-tri-acd）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 步骤控制：updateScene() 函数根据 currentStep 显示/隐藏对应元素，更新标签内容

- SVG 元素 ID 命名示例：
  - 线段：scene2-line-ab, scene2-line-de, scene2-line-cp, scene2-line-af, scene2-line-dc, scene2-line-ce, scene2-line-be
  - 点：scene2-point-a, scene2-point-b, scene2-point-c, scene2-point-d, scene2-point-e, scene2-point-p, scene2-point-f, scene2-point-g, scene2-point-h
  - 三角形：scene2-tri-acd, scene2-tri-bce
  - 高亮段：scene2-highlight-ag, scene2-highlight-gh, scene2-highlight-hf
  - 标签：scene2-label-a, scene2-label-b, ..., scene2-label-cp-value, scene2-label-ratio
  - 控件：scene2-btn-prev, scene2-btn-next, scene2-step-indicator
