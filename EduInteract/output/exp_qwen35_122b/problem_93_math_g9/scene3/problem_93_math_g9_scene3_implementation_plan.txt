[图示主题与整合说明]
- 本图示主题：动点 P 的轨迹演示（Scene 3）
- 整合内容：C 点运动范围标注、P 点轨迹生成、路径长度计算
- 教学价值：教师可通过拖动滑块，让学生直观观察 P 点随 C 点运动的轨迹规律，理解"动点轨迹为线段"的几何本质，验证路径长度计算结果

几何计算（C 点坐标 Cx ∈ [250, 550]，对应实际 c ∈ [2, 6]）：
- D 点：等边三角形 ACD 顶点，Dx = (100 + Cx)/2，Dy = 380 - (Cx-100)×√3/2
- E 点：等边三角形 BCE 顶点，Ex = (Cx + 700)/2，Ey = 380 - (700-Cx)×√3/2
- P 点：DE 中点，Px = (Dx+Ex)/2 = (Cx+400)/2，Py = (Dy+Ey)/2 = 290（恒定！）
- 轨迹范围：C=2 时 P=(325,290)，C=6 时 P=(475,290)，轨迹长度=150px=2 单位

[分步序列]
本场景采用连续拖拽滑块交互，无分步导航，状态随滑块实时变化：

- 初始状态（滑块在中间位置 C=4，即 Cx=400）：
  - 显示线段 AB，标注 A、B、M、N 及位置数值
  - 显示 M、N 位置虚线标记
  - 显示 C 点在中间位置（红色）
  - 显示两个等边三角形 ACD、BCE（蓝色）
  - 显示 D、E、P 点及线段 DE
  - 轨迹线段灰色显示（未激活）
  - 滑块控件显示在底部

- 拖动状态（用户拖动滑块，C 点在 M、N 间移动）：
  - C 点实时跟随滑块位置移动（红色高亮）
  - 两个等边三角形实时重绘（顶点 D、E 位置变化）
  - P 点实时移动，始终保持在 y=290 水平线上
  - 轨迹线段从起点到当前 P 点位置逐步绘制（绿色）
  - 实时显示当前 C 点位置数值和 P 点轨迹长度

- 最终状态（C 点从 M 移动到 N，完成全程）：
  - 轨迹线段完整显示为绿色高亮线段 (325,290)-(475,290)
  - 显示轨迹长度标注："P 点轨迹长度 = 2"
  - 可反向拖动滑块观察轨迹消失过程

- N(550,400) 与 N 数值(540,415)：间距 18px → 接近但可接受

- P(325~475, 275) 与 D/E（动态）：D 点 x 坐标范围 [175, 325]，E 点 x 坐标范围 [475, 625]，P 点在中间，y 坐标 P=275，D/E 的 y 坐标约 290-350，间距 >15px ✓

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：
  1. 滑块（id: scene3-slider）：位置 (200,450)-(600,470)，范围 250-550（对应 C 点 x 坐标）
     - 拖动滑块 → C 点实时移动 → 三角形重绘 → P 点移动 → 轨迹绘制
  2. 重置按钮（id: scene3-reset）：位置 (650,455)，"重置"
     - 点击 → 滑块回到中间位置（C=4）

- 教师操作流程：
  1. 初始展示：说明 AB=8，M、N 位置（AM=BN=2）
  2. 拖动滑块：从 M 向 N 缓慢拖动，让学生观察 P 点如何移动
  3. 引导发现：P 点始终在同一高度（y=290），轨迹是水平线段
  4. 完成拖动：展示完整轨迹，讲解路径长度计算（2 单位）
  5. 反向拖动：让学生观察轨迹"消失"过程，强化理解

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（线段、三角形、圆点），原生 SVG 足够且性能好，无需引入大型库

- 画布尺寸：800 × 500 px

- 布局草图（ASCII）：

- 关键实现要点：
  1. 状态机设计：
     - 状态变量：cValue（C 点实际坐标，范围 2-6），cPx（C 点像素坐标，范围 250-550）
     - 转换：滑块拖动 → 更新 cValue → 计算所有依赖点坐标 → 重绘
  
  2. 坐标计算函数：
     - cToPx(c) = 100 + c * 75（实际坐标转像素）
     - pxToC(px) = (px - 100) / 75（像素转实际坐标）
     - calcD(c)：返回 D 点坐标
     - calcE(c)：返回 E 点坐标
     - calcP(d, e)：返回 DE 中点 P 坐标
  
  3. 重绘逻辑：
     - 清除动态元素（C、D、E、P、三角形、DE、轨迹）
     - 根据当前 cValue 重新计算所有点坐标
     - 更新 SVG 元素属性（path d 属性、circle cx/cy 属性）
     - 轨迹线段：从起点 (325,290) 到当前 P 点 x 坐标绘制
  
  4. 动画曲线：无特殊动画，实时响应滑块拖动
  
  5. 事件绑定：
     - slider input 事件 → 实时更新
     - reset button click 事件 → 重置到 c=4
