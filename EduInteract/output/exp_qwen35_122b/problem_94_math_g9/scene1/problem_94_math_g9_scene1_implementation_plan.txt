[图示主题与整合说明]
- 本图示主题：三棱柱的立体结构与面的组成
- 整合的步骤/概念：三棱柱立体图展示 → 侧面识别 → 底面识别 → 展开图示意
- 教学价值：教师可逐步引导学生认识三棱柱的 5 个面（3 个矩形侧面 + 2 个三角形底面），帮助学生建立从立体到展开图的空间转换概念，为判断正确展开图奠定基础

[分步序列]
- 初始状态（步骤 0）：
  - 显示三棱柱立体图（所有面正常显示，无高亮）
  - 显示右侧说明区（面的组成文字说明）
  - 显示标题"三棱柱的立体结构"
  - 展开图示意隐藏
  - 步骤指示器显示"步骤 1/4"

- 步骤 1：点击「下一步」→
  - 高亮 3 个矩形侧面（侧面 1、2、3 描边变为#1565c0，填充透明度 20%）
  - 侧面标签"侧面 1"、"侧面 2"、"侧面 3"变为#1565c0
  - 右侧说明区高亮显示"• 3 个矩形侧面"（文字变#1565c0）
  - 步骤指示器显示"步骤 2/4"

- 步骤 2：点击「下一步」→
  - 取消侧面高亮
  - 高亮 2 个三角形底面（上底面、下底面描边变为#c62828，填充透明度 20%）
  - 底面标签"上底面"、"下底面"变为#c62828
  - 右侧说明区高亮显示"• 2 个三角形底面"（文字变#c62828）
  - 步骤指示器显示"步骤 3/4"

- 步骤 3（最终步骤）：点击「下一步」→
  - 取消底面高亮
  - 显示展开图示意（右侧展开图区域淡入）
  - 展开图所有面用#2e7d32 描边高亮
  - 右侧说明区显示"• 展开图：3 个矩形 + 2 个三角形"（文字变#2e7d32）
  - 步骤指示器显示"步骤 4/4"
  - 「下一步」按钮隐藏或禁用

- 上一步回退：
  - 点击「上一步」可返回前一状态，恢复对应高亮和显示状态

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - scene1-prev-btn：上一步按钮，位置 (280,455)，点击返回前一状态
  - scene1-next-btn：下一步按钮，位置 (440,455)，点击进入下一状态
  - scene1-step-indicator：步骤指示器，位置 (360,420)，显示当前步骤"步骤 X/4"
- 教师操作流程：
  1. 初始展示三棱柱立体图，让学生观察整体形状
  2. 点击「下一步」，高亮 3 个矩形侧面，讲解侧面的特征
  3. 点击「下一步」，高亮 2 个三角形底面，讲解底面的特征
  4. 点击「下一步」，展示展开图示意，帮助学生理解立体到平面的转换
  5. 可随时点击「上一步」回退复习，巩固概念

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │ 三棱柱的立体结构                                               │
  │                                                                │
  │  ┌──────────────────────┐    ┌──────────────────────────────┐  │
  │  │                      │    │  面的组成                    │  │
  │  │    三棱柱立体图      │    │  • 3 个矩形侧面              │  │
  │  │   (透视效果)         │    │  • 2 个三角形底面            │  │
  │  │                      │    │  • 共 5 个面                 │  │
  │  │   [上底面]           │    │                              │  │
  │  │  /       \           │    │  [展开图示意区域]            │  │
  │  │ /侧面 1  \侧面 2\     │    │   □ □ □                     │  │
  │  │ \       /            │    │  △                         │  │
  │  │  \_____/             │    │                              │  │
  │  │   [下底面]           │    │                              │  │
  │  └──────────────────────┘    └──────────────────────────────┘  │
  │                                                                │
  │                    步骤 1/4                                    │
  │                  [上一步] [下一步]                             │
  └────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用 currentStep 变量（0-3）跟踪当前步骤，stepStates 数组存储每步的显示状态
  2. 坐标计算：所有元素坐标已在布局坐标表中精确定义，SVG 元素按坐标绘制
  3. 动画曲线：高亮效果使用 CSS transition（0.3s ease），展开图淡入使用 opacity 动画
  4. 事件绑定：按钮点击事件绑定到 scene1-prev-btn 和 scene1-next-btn，更新状态后重绘
  5. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-top-face、scene1-side-1）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 高亮实现：通过修改 SVG 元素的 stroke 和 fill-opacity 属性实现高亮效果
  8. 展开图淡入：步骤 3 时设置展开图元素 opacity 从 0 到 1 的过渡动画
