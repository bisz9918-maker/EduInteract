[图示主题与整合说明]
- 本图示主题：海岸线上 A、B、C 三个港口的空间布局与两船运动方向

[分步序列]
- 步骤0（初始状态）：
  - 显示：海岸线（黑色粗实线）、三个港口圆点（A、B、C位置，但不显示标签）
  - 隐藏：所有标签、箭头、距离标注
  - 目的：让学生先观察海岸线和三个港口的相对位置

- 步骤1：
  - 新增显示：港口标签"A"、"B"、"C"（分别在对应港口下方）
  - 新增显示：甲船箭头（蓝色，海岸线上方从左向右）和"甲船"标签
  - 目的：明确港口名称，显示甲船从A到C的运动方向

- 步骤2：
  - 新增显示：乙船箭头（红色，海岸线下方从右向左）和"乙船"标签
  - 目的：显示乙船从B到A的运动方向，形成两船相对运动的完整画面

- 步骤3（最终步骤）：
  - 新增显示：AB距离线（虚线）和"AB=400km"标注
  - 新增显示：BC距离线（虚线）和"BC=200km"标注
  - 目的：显示已知距离信息，为后续函数图像分析提供数据支持

冲突检查：
- "A"与"B"：水平间距200px → 无冲突
- "B"与"C"：水平间距200px → 无冲突
- "甲船"与"乙船"：垂直间距140px，水平间距100px → 无冲突
- "AB=400km"与"BC=200km"：水平间距200px → 无冲突
- "乙船"(250,350)与"AB=400km"(250,325)：垂直间距25px → 无冲突（>20px安全距离）
- 标题与所有其他标签：垂直间距≥170px → 无冲突

所有标签间距均≥20px，无冲突。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "上一步"按钮：ID=scene1-btn-prev，位置(280,450)，作用：返回上一步骤
  - "下一步"按钮：ID=scene1-btn-next，位置(520,450)，作用：进入下一步骤
  - 步骤指示器：text，位置(380,450)，显示"步骤 1/4"
- 教师操作流程：
  1. 初始展示海岸线和三个港口，引导学生观察位置关系
  2. 点击"下一步"，揭示港口名称和甲船运动方向
  3. 点击"下一步"，揭示乙船运动方向，形成完整运动画面
  4. 点击"下一步"，显示距离标注，为函数图像分析提供数据
  5. 可随时点击"上一步"回退复习，巩固空间模型

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    海岸线上港口布局示意图                │  y=40
  │                                                         │
  │                                                         │
  │              甲船 → → → → → → → → → →                   │  y=210~230
  │                                                         │
  │    ●──────────────────────────────────────────●    ●    │  y=280
  │    A                                          B    C    │  y=300
  │         ← ← ← ← 乙船                           │         │  y=330~350
  │         ─────────────────────────────────────  │         │  y=310~325
  │              AB=400km        BC=200km                      │
  │                                                         │
  │                                                         │
  │            [◀ 上一步]    步骤 1/4    [下一步 ▶]          │  y=450
  └─────────────────────────────────────────────────────────┘
  ```

- 关键实现要点：
  1. 状态机设计：用变量 currentStep 记录当前步骤（0-3），根据 currentStep 控制各元素的 display 属性
  2. 坐标计算：所有元素坐标已在布局坐标表中精确指定，直接按坐标绘制
  3. 动画曲线：步骤切换使用 opacity 渐变（0.3s ease-in-out），元素淡入效果
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后重新渲染元素可见性
  5. 边界检查：第一步时禁用"上一步"按钮，最后一步时禁用"下一步"按钮

- ID 命名规范：
  - 所有元素 ID 以 scene1- 为前缀
  - 港口：scene1-port-A, scene1-port-B, scene1-port-C
  - 标签：scene1-label-A, scene1-label-B, scene1-label-C, scene1-label-甲船, scene1-label-乙船
  - 箭头：scene1-arrow-甲船, scene1-arrow-乙船
  - 距离线：scene1-dist-AB, scene1-dist-BC
  - 距离标注：scene1-label-dist-AB, scene1-label-dist-BC
  - 按钮：scene1-btn-prev, scene1-btn-next
  - 步骤指示：scene1-step-indicator

- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染
