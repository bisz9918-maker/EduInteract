[分步序列]
- 步骤0（初始状态）：
  - 显示完整展开图（5个正方形组成的十字形）
  - 上方正方形内有空心圆
  - 左侧正方形有左下角阴影三角形
  - 右侧正方形有右下角阴影三角形
  - 中间和下方正方形为空白
  - 折叠线用虚线标出
  - 步骤指示器显示"步骤 0/6"

- 步骤1：
  - 左侧阴影面向左翻折90度（视觉上用箭头指示折叠方向）
  - 左侧正方形开始向屏幕外/内旋转（用透视变形表示）
  - 折叠箭头从左侧正方形指向左方
  - 步骤指示器显示"步骤 1/6"

- 步骤2：
  - 右侧阴影面向右翻折90度
  - 右侧正方形开始向屏幕外/内旋转
  - 折叠箭头从右侧正方形指向右方
  - 步骤指示器显示"步骤 2/6"

- 步骤3：
  - 下方空白面向下翻折90度
  - 下方正方形开始向屏幕外/内旋转
  - 折叠箭头从下方正方形指向下方
  - 步骤指示器显示"步骤 3/6"

- 步骤4：
  - 上方圆圈面向上翻折90度
  - 上方正方形开始向屏幕外/内旋转
  - 折叠箭头从上方正方形指向上方
  - 步骤指示器显示"步骤 4/6"

- 步骤5：
  - 展开图消失
  - 显示最终折叠成的正方体（3D透视）
  - 正面显示一个阴影面（阴影在左下角）
  - 顶面显示圆圈
  - 右侧面显示另一个阴影面（阴影在右下角）
  - 步骤指示器显示"步骤 5/6"

- 步骤6：
  - 最终正方体保持在上方
  - 下方显示四个选项A、B、C、D
  - 选项B的正方体图案与最终正方体匹配
  - 选项B框用绿色实线高亮（#2e7d32，3px）
  - 选项A、C、D用红色虚线标记（#c62828，2px）
  - 选项B上方显示"✓"标记
  - 步骤指示器显示"步骤 6/6"

- 标签"B"：坐标(255,320)

- 标签"D"：坐标(535,320)
- 标签"上一步按钮"：坐标(330,470)
- 标签"下一步按钮"：坐标(470,470)

冲突检查：
- "圆圈面"(380,60)与"步骤指示器"(380,50)：垂直间距10px → 冲突！解决方案：将"圆圈面"标签移至(380,40)，间距变为10px，或移除该标签（因圆圈本身已足够明显）
- "左阴影面"(200,230)与其他标签：最近的是"A"(115,320)，间距约100px → 无冲突
- "右阴影面"(560,230)与其他标签：最近的是"D"(535,320)，间距约90px → 无冲突
- "空白面"(400,400)与选项标签：最近的是"C"(395,320)，间距80px → 无冲突
- 选项标签A/B/C/D之间：间距140px → 无冲突
- 按钮标签之间：间距140px → 无冲突

最终决定：移除"圆圈面"、"左阴影面"、"右阴影面"、"空白面"等解释性标签，仅保留步骤指示器和选项标签，符合"仅点名/轴名/数值/符号"的要求。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：位于(280,450)，点击返回上一步骤，步骤0时禁用
  - "下一步 ▶"按钮：位于(420,450)，点击进入下一步骤，步骤6时禁用
- 教师操作流程：
  1. 初始展示展开图，让学生观察各面图案
  2. 点击"下一步"逐步演示折叠过程，每步停顿让学生思考
  3. 折叠完成后展示最终正方体
  4. 最后展示四个选项，让学生选择正确答案
  5. 高亮正确答案B，可点击"上一步"回顾折叠过程

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（正方形、圆形、多边形），SVG 适合精确绘制，无需复杂动画库
  - 3D效果用 CSS transform 或 SVG 透视模拟

- 画布尺寸：800 × 500 px

- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-6) 跟踪当前步骤
  2. 坐标计算：所有元素用绝对坐标，折叠动画用 CSS transform 的 rotate3d 或 SVG transform
  3. 动画曲线：折叠过程用 ease-in-out 过渡，时长 500ms
  4. 事件绑定：按钮点击事件更新 currentStep，调用 renderStep() 重绘
  5. ID 命名规范：所有元素 ID 以 scene1- 为前缀，如 scene1-square-top、scene1-btn-prev
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中
  7. 折叠动画实现：用 SVG transform 的 matrix 或 rotate 模拟3D效果
  8. 选项对比：步骤6时显示4个选项，用 CSS class 控制边框样式

- 折叠动画技术细节：
  - 左侧阴影面折叠：transform-origin: right center; transform: rotateY(-90deg)
  - 右侧阴影面折叠：transform-origin: left center; transform: rotateY(90deg)
  - 下方空白面折叠：transform-origin: top center; transform: rotateX(90deg)
  - 上方圆圈面折叠：transform-origin: bottom center; transform: rotateX(-90deg)
  - 使用 transition 实现平滑过渡

- 最终正方体绘制：
  - 用三个 polygon 模拟3D透视
  - 正面：平行四边形
  - 顶面：平行四边形（向上偏移）
  - 右侧面：平行四边形（向右偏移）
  - 图案根据折叠逻辑确定位置

- 选项正方体绘制：
  - 4个相同的3D立方体框架
  - 每个选项的图案不同，通过 polygon 填充区分
  - 选项B的图案与最终正方体一致
