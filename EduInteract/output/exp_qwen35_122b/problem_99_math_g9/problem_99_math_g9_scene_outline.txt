    **题目原文：**
    如图，D是等边△ABC边AB上的一点，且AD=1，BD=2，现将△ABC折叠，使点C与D重合，折痕EF，点E、F分别在AC和BC上，若BF=1.25，则CE=（ ）

    A．7/5  B．2/3  C．5/6  D．1/2

    **题目分析：**
    这是一道等边三角形折叠问题，核心考点是折叠的几何性质：
    1. 折叠后重合的点到折痕的距离相等
    2. 折叠保持线段长度不变（CE=DE，CF=DF）
    3. 等边三角形内角均为60°，边长相等

    **已知条件梳理：**
    - △ABC 是等边三角形，边长 AB = AD + BD = 1 + 2 = 3
    - 所以 AC = BC = AB = 3
    - BF = 1.25，则 CF = BC - BF = 3 - 1.25 = 1.75
    - 折叠后 C 与 D 重合，故 CF = DF = 1.75

    **解题思路：**
    1. 利用折叠性质：CE = DE，CF = DF
    2. 在△BDF 中，已知 BD=2，BF=1.25，DF=1.75，∠B=60°
    3. 可用余弦定理验证△BDF 的边角关系
    4. 在△ADE 中，AD=1，∠A=60°，设 CE=x，则 DE=x，AE=3-x
    5. 用余弦定理建立方程求解 x

    **图示教学说明：**

    本图示通过分步动画展示折叠问题的完整过程，教师应按以下步骤引导学生：

    **步骤 0：建立基础认知**
    1. 首先展示等边三角形 ABC，强调边长为 3（AD+BD=1+2）
    2. 标注已知数据：AD=1，BD=2，BF=1.25
    3. 引导学生计算：BC=3，故 CF=BC-BF=3-1.25=1.75

    **步骤 1：理解折叠动作**
    1. 显示折痕 EF，说明这是折叠的对称轴
    2. 动画演示 C 点沿折痕 EF 折叠到 D 点
    3. 强调折叠的本质：关于折痕 EF 的轴对称变换

    **步骤 2：掌握折叠性质**
    1. 高亮显示 CE 与 DE，说明折叠后 C 与 D 重合，故 CE=DE
    2. 高亮显示 CF 与 DF，同理 CF=DF=1.75
    3. 这是解题的关键：折叠保持对应线段长度不变

    **步骤 3：建立方程求解**
    1. 设 CE=x，则 DE=x，AE=AC-CE=3-x
    2. 在△ADE 中，AD=1，∠A=60°，AE=3-x，DE=x
    3. 应用余弦定理：DE² = AD² + AE² - 2·AD·AE·cos60°
    4. 代入：x² = 1² + (3-x)² - 2·1·(3-x)·(1/2)
    5. 化简：x² = 1 + 9 - 6x + x² - (3-x)
    6. 继续：x² = 10 - 6x + x² - 3 + x
    7. 整理：0 = 7 - 5x，得 x = 7/5

    **答案：CE = 7/5，选 A**

    **教学建议：**
    - 折叠问题核心是"对应线段相等"，务必让学生理解 CE=DE，CF=DF
    - 余弦定理应用时，强调∠A=60°来自等边三角形性质
    - 可引导学生用△BDF 验证：BD=2，BF=1.25，DF=1.75，∠B=60°，用余弦定理验证 DF²=BD²+BF²-2·BD·BF·cos60°
