[分步序列]
- 初始状态（步骤 0）：
  - 显示完整电路图，所有开关断开（S₁悬空，S₂断开）
  - 灯泡均为灰色填充（透明度 70%）
  - 无电流箭头
  - 状态说明："点击下一步分析开关状态"
  - 功率数值："—"

- 步骤 1：S₂断开，S₁接 b（L₁单独接入）
  - S₁开关臂指向 b 触点，用红色高亮闭合路径
  - S₂保持断开状态
  - 电流路径：电源正极 → L₁ → S₁(b) → 电源负极（蓝色箭头显示）
  - L₁绿色填充透明度 30%（功率 1.5W）
  - L₂灰色填充透明度 70%（未接入）
  - L₁功率标签显示："L₁: 1.5W"
  - L₂功率标签显示："L₂: 0W"
  - 状态说明："S₂断开，S₁接 b：L₁单独接入 3V 电源"
  - 功率数值："L₁功率 = U²/R₁ = 3²/6 = 1.5W（不能正常发光，需 6V）"

- 步骤 2：S₂断开，S₁接 a（L₁与 L₂串联）
  - S₁开关臂指向 a 触点，用红色高亮闭合路径
  - S₂保持断开状态
  - 电流路径：电源正极 → L₁ → L₂ → S₁(a) → 电源负极（蓝色箭头显示）
  - L₁绿色填充透明度 30%（功率 0.67W）
  - L₂绿色填充透明度 30%（功率 0.33W）
  - L₁功率标签显示："L₁: 0.67W"
  - L₂功率标签显示："L₂: 0.33W"
  - 状态说明："S₂断开，S₁接 a：L₁与 L₂串联"
  - 功率数值："R 总=6+3=9Ω，I=3/9=1/3A，L₁功率=I²R₁=0.67W，L₂功率=I²R₂=0.33W，L₁更亮"

- 步骤 3：S₂闭合，S₁接 b（L₁与 L₂并联）
  - S₁开关臂指向 b 触点，用红色高亮
  - S₂开关闭合，用红色高亮
  - 电流路径：电源正极 → 分两路（L₁ 和 S₂→L₂）→ 汇合 → S₁(b) → 电源负极（蓝色箭头显示）
  - L₁绿色填充透明度 30%（功率 1.5W）
  - L₂绿色填充透明度 10%（功率 3W，更亮）
  - L₁功率标签显示："L₁: 1.5W"
  - L₂功率标签显示："L₂: 3W"
  - 状态说明："S₂闭合，S₁接 b：L₁与 L₂并联"
  - 功率数值："L₁功率=3²/6=1.5W，L₂功率=3²/3=3W（正常发光），L₂更亮"

- 步骤 4：总结对比表格
  - 表格覆盖电路图中央区域 (100,100)-(700,350)
  - 表格内容：
    | 状态 | S₂ | S₁ | L₁功率 | L₂功率 | 谁更亮 |
    |------|-----|-----|--------|--------|--------|
    | 选项 A | 断 | b | 1.5W | 0W | L₁ |
    | 选项 B | 断 | a | 0.67W | 0.33W | L₁ |
    | 选项 C | 断 | a | 0.67W | 0.33W | L₁ |
    | 选项 D | 闭 | b | 1.5W | 3W | L₂ |
  - 标注正确答案："选项 D 正确"
  - 状态说明："四种状态对比总结"
  - 功率数值："正确答案：D（S₂闭合，S₁接 b 时 L₂更亮）"

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "上一步"按钮：位置 (250,450)-(370,485)，作用：返回上一状态
  - "下一步"按钮：位置 (430,450)-(550,485)，作用：进入下一状态
  - 按钮状态：初始状态"上一步"禁用，步骤 4 时"下一步"禁用
- 教师操作流程：
  1. 初始状态展示电路图，说明元件位置
  2. 点击"下一步"分析选项 A（S₂断，S₁接 b），讲解 L₁单独接入
  3. 点击"下一步"分析选项 B/C（S₂断，S₁接 a），讲解串联电路
  4. 点击"下一步"分析选项 D（S₂闭，S₁接 b），讲解并联电路
  5. 点击"下一步"显示对比表格，总结正确答案

- 关键实现要点：
  1. 状态机设计：用 currentStep 变量跟踪当前步骤 (0-4)
  2. 坐标计算：所有元件坐标预先定义在常量对象中
  3. 动画曲线：开关臂旋转用 SVG transform rotate，电流箭头用 opacity 渐变
  4. 事件绑定：按钮点击事件更新状态，重新渲染相关元素
  5. 灯泡亮度：通过修改 fill-opacity 属性实现
  6. ID 命名规范：所有元素 ID 以"scene2-"为前缀（如 scene2-lamp1、scene2-switch1）
  7. IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中
  8. 表格显示：步骤 4 时显示 SVG 表格元素，覆盖电路图

- 灯泡电阻计算（预计算）：
  - L₁：R₁ = U²/P = 6²/6 = 6Ω
  - L₂：R₂ = U²/P = 3²/3 = 3Ω

- 各步骤功率计算（预计算）：
  - 步骤 1：L₁单独，P₁ = 3²/6 = 1.5W，P₂ = 0W
  - 步骤 2：串联，I = 3/(6+3) = 1/3A，P₁ = (1/3)²×6 = 0.67W，P₂ = (1/3)²×3 = 0.33W
  - 步骤 3：并联，P₁ = 3²/6 = 1.5W，P₂ = 3²/3 = 3W
