[图示主题与整合说明]
- 本图示主题：正三棱柱的立体结构与展开图特征
- 整合内容：立体三棱柱展示、展开图分解、底面与侧面对应关系
- 教学价值：教师如何使用此图示进行课堂讲解
  1. 初始状态展示正三棱柱立体结构，帮助学生建立空间概念
  2. 逐步高亮底面和侧面，让学生理解三棱柱的组成部分
  3. 展开过程演示，建立立体与平面展开图的对应关系
  4. 最终展示完整展开图，与题目中的4个选项进行对比分析
  5. 教师可配合"上一步/下一步"按钮，引导学生思考哪些展开图能正确围成三棱柱

[分步序列]
- 初始状态（步骤0）：显示正三棱柱立体图（线框，无填充），右侧展开图区域空白
  - 显示元素：立体三棱柱所有棱线（可见实线、隐藏虚线）
  - 标签：无
  - 按钮："上一步"禁用，"下一步"启用

- 步骤1：高亮两个底面正三角形
  - 视觉变化：立体图上底面和下底面填充蓝色 #1565c0 透明度20%
  - 新增标签："底面"标签出现在上底面左上方(100,150)和下底面左下方(130,390)
  - 按钮："上一步"启用，"下一步"启用

- 步骤2：高亮三个侧面矩形
  - 视觉变化：立体图三个侧面填充绿色 #2e7d32 透明度20%
  - 新增标签："侧面"标签出现在立体图右侧(180,250)
  - 按钮："上一步"启用，"下一步"启用

- 步骤3：显示展开箭头和完整展开图
  - 视觉变化：中间出现展开箭头，右侧显示完整展开图
  - 展开图元素：三个并排矩形（侧面）+ 上下两个正三角形（底面）
  - 新增标签："底面（正三角形）"在展开图上方(480,120)和下方(480,400)，"侧面（矩形）"在展开图右侧(560,260)
  - 按钮："上一步"启用，"下一步"禁用（最后一步）

[标签冲突检查]
- 标签"底面"(上)：坐标(100,150)
- 标签"底面"(下)：坐标(130,390)
- 标签"侧面"：坐标(180,250)
- 标签"底面（正三角形）"(上)：坐标(480,120)
- 标签"底面（正三角形）"(下)：坐标(480,400)
- 标签"侧面（矩形）"：坐标(560,260)
- 步骤指示器：坐标(450,460)

冲突检查：
- "底面"(上)与"底面"(下)：垂直距离240px → 无冲突
- "底面"(上)与"侧面"：距离约100px → 无冲突
- "底面"(下)与"侧面"：距离约150px → 无冲突
- "底面（正三角形）"(上)与"底面（正三角形）"(下)：垂直距离280px → 无冲突
- "侧面（矩形）"与其他标签：最近距离约100px → 无冲突
- 所有标签与图形元素：标签均放置在图形外侧空白区域 → 无冲突
- 控件区(y=440~490)与主图区：主图元素最高到y=400，控件从y=455开始 → 无冲突

结论：所有标签间距均≥20px，无重叠冲突

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "上一步"按钮：位于(320,455)，80×30px，初始禁用，步骤>0时启用
  - "下一步"按钮：位于(400,455)，80×30px，初始启用，步骤=3时禁用
  - 步骤指示器：位于(450,460)，显示当前步骤"步骤 X/4"
- 教师操作流程：
  1. 课堂引入：展示步骤0立体图，提问"三棱柱由哪些面组成？"
  2. 点击"下一步"到步骤1：高亮底面，讲解"两个底面是全等的正三角形"
  3. 点击"下一步"到步骤2：高亮侧面，讲解"三个侧面是矩形"
  4. 点击"下一步"到步骤3：展示展开图，讲解"展开后底面和侧面的位置关系"
  5. 结合题目图片，引导学生判断哪些展开图能围成正三棱柱

[技术实现]
- JS 库选择及原因：原生 SVG
  - 原因：几何图形简单，SVG 矢量图清晰，无需额外库依赖
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |   [立体三棱柱]        [箭头]    [展开图]         |
  |   x=20~220           x=370~430  x=400~640       |
  |   y=160~370                   y=120~400         |
  |                                                  |
  |                                                  |
  |                                                  |
  |              [上一步] [下一步] 步骤 X/4          |
  |              y=455                               |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-3) 跟踪当前步骤
  2. 所有元素预渲染但初始隐藏，通过 display/opacity 控制显示
  3. 每个步骤对应一组元素的显示状态，用对象存储配置
  4. 按钮点击事件更新 currentStep，调用 renderStep() 刷新显示
  5. 按钮状态根据 currentStep 动态启用/禁用
  6. 步骤指示器同步更新
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀
  - scene1-prism-top-base, scene1-prism-bottom-base
  - scene1-prism-side1, scene1-prism-side2, scene1-prism-side3
  - scene1-arrow
  - scene1-net-side1, scene1-net-side2, scene1-net-side3
  - scene1-net-top-base, scene1-net-bottom-base
  - scene1-label-base-top, scene1-label-base-bottom, scene1-label-side
  - scene1-label-net-base-top, scene1-label-net-base-bottom, scene1-label-net-side
  - scene1-btn-prev, scene1-btn-next, scene1-step-indicator
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中
