[图示主题与整合说明]
- 本图示主题：四个图形中三角形类型的对比分析
- 整合的内容：图①~④的三角形角度标注、类型判断、是否符合正三棱柱底面要求
- 教学价值：教师可逐步高亮每个图形的三角形部分，标注角度特征，引导学生理解正三棱柱底面必须是正三角形（三个角都是60°的等边三角形），而直角三角形和一般锐角三角形不能作为正三棱柱的底面

[分步序列]
- 初始状态（步骤0）：显示四个图形原图（网格、侧面矩形、三角形轮廓），无高亮，无标注
- 步骤1：高亮图①②的三角形（红色边框2px，15%填充），在三角形内绘制60°角弧线，显示标签"60°"和"直角三角形"，下方显示"✗ 不能作为正三棱柱底面"
- 步骤2：在图①②下方显示结论"直角三角形≠正三角形"，图③④保持原图
- 步骤3：高亮图③④的三角形（绿色边框2px，15%填充），在三角形内绘制60°角弧线，显示标签"60°"和"锐角三角形"，图①②保持步骤2状态
- 步骤4：在图③④下方显示"可能是正三角形"，图④额外显示"✓ 侧面是矩形，可围成正三棱柱"，总结正三棱柱条件

冲突检查：
- "图①"与"60°(图①)"：垂直距离135px → 无冲突
- "图①"与"直角三角形"：垂直距离20px → 刚好，需确保"图①"在220，"直角三角形"在245
- "60°"与三角形边框：弧线半径8px，标签在弧线外侧5px → 无冲突
- 各图形间距：横向20px，横向30px → 无冲突

解决方案：将类型标签统一放在y=225（图①②）和y=435（图③④），图形编号放在y=210和y=420

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位置(320,470)，返回上一状态
  - 「下一步」按钮：位置(420,470)，进入下一状态

- 教师操作流程：
  1. 初始展示四个图形原图，让学生观察
  2. 点击「下一步」高亮图①②，讲解直角三角形特征
  3. 点击「下一步」显示结论，强调直角三角形不能作为正三棱柱底面
  4. 点击「下一步」高亮图③④，对比锐角三角形
  5. 点击「下一步」显示最终结论，总结正三棱柱的条件

[技术实现]
- JS库选择：原生SVG（简单几何图形，无需额外库）
- 画布尺寸：800×500px
- 布局草图：
  ```
  [图示区 800×500]
  +------------------------------------------+
  |  [图①] 20px  [图②]                     | y=30-210
  |                                          |
  |  [图③] 20px  [图④]                     | y=240-420
  |                                          |
  |  [上一步] [步骤2/4] [下一步]            | y=460-495
  +------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机：用currentStep变量(0-4)跟踪当前步骤
  2. 每个步骤对应一组元素的display/opacity变化
  3. 三角形用<polygon>绘制，高亮时添加class="highlight-red"或"highlight-green"
  4. 角度弧线用<path>绘制圆弧
  5. 按钮点击事件切换状态，更新步骤指示器
- ID命名规范：所有元素ID以"scene2-"为前缀，如scene2-fig1-triangle、scene2-fig1-label等
- IIFE隔离：所有JS代码包在(function() { ... })()中，避免全局污染
