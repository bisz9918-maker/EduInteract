[图示主题与整合说明]
- 本图示主题：展开图折叠成正三棱柱的动态演示
- 整合的内容：图③和图④的折叠过程演示、图①和图②的折叠失败演示
- 教学价值：教师可通过逐步折叠动画，直观展示正三棱柱展开图的空间变换过程，帮助学生理解哪些展开图能围成正三棱柱。学生可观察折叠方向、面的对应关系，以及失败案例中三角形位置错误导致无法封闭的原因。

[分步序列]
- 步骤0（初始状态）：展示图③展开图（3个矩形+2个三角形），立体图区空白，显示"步骤 0/6"和"观察展开图"
- 步骤1：图③第一个侧面开始折叠（绕左侧边旋转60°），该面变为半透明蓝色#1565c0(30%)，显示折叠箭头，立体图区显示该面的投影
- 步骤2：图③第二个侧面开始折叠（绕右侧边旋转60°），该面变为半透明蓝色，立体图区更新显示两个侧面
- 步骤3：图③第三个侧面折叠完成，三个侧面形成三棱柱侧面，所有侧面变为半透明绿色#2e7d32(20%)
- 步骤4：图③上底面三角形开始折叠（向下旋转），显示折叠箭头，立体图区显示上底面
- 步骤5：图③下底面三角形折叠完成，形成封闭三棱柱，显示"✓能围成"绿色标记，立体图区显示完整正三棱柱
- 步骤6：切换到图④，重复步骤0-5的折叠过程，展示图④也能围成正三棱柱
- 步骤7（对比演示）：展示图①展开图，尝试折叠时显示三角形位置错误导致无法封闭，显示"✗不能围成"红色标记
- 步骤8（对比演示）：展示图②展开图，同样显示无法封闭，最终回到图③④的完整三棱柱展示

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 重置 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：返回上一个折叠步骤，位置(280,455)，尺寸80×30
  - 「重置」按钮：回到步骤0初始状态，位置(380,455)，尺寸60×30
  - 「下一步」按钮：进入下一个折叠步骤，位置(440,455)，尺寸80×30
- 教师操作流程：
  1. 初始展示图③展开图，让学生观察三角形和矩形的位置关系
  2. 点击「下一步」逐步展示折叠过程，讲解每个面的折叠方向和角度
  3. 折叠完成后展示"✓能围成"标记，强调图③的正确性
  4. 继续点击切换到图④，重复折叠过程
  5. 最后对比展示图①②的折叠失败，解释三角形位置错误的原因
  6. 可随时点击「上一步」回退复习关键步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形和简单动画用原生 SVG 即可实现，无需引入重型库；折叠动画通过 SVG transform 实现
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [800×500 画布]
  +--------------------------------------------------+
  |              正三棱柱展开图折叠演示               | y=35
  +--------------------------------------------------+
  |  [图③展开图]  [图④展开图]     [立体图区]        | y=60~260
  |     180×140      180×140        280×200          |
  |     (50,60)      (280,60)       (500,60)         |
  +--------------------------------------------------+
  |         图③           图④        正三棱柱        | y=210~270
  +--------------------------------------------------+
  |              步骤 3/6                            | y=280
  |           侧面折叠完成                           | y=310
  |                  ✓能围成                         | y=300
  +--------------------------------------------------+
  |        [◀上一步]  [重置]  [下一步▶]              | y=440~490
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用 currentState 变量跟踪当前步骤（0-8），steps 数组存储每个状态的配置
  2. 折叠动画：使用 SVG transform="rotate()" 实现面的旋转，配合 transition 实现平滑动画
  3. 透明度变化：通过 opacity 属性和 fill 颜色的 rgba 值控制
  4. 事件绑定：三个按钮分别绑定 click 事件，调用 stepBack()、reset()、stepForward() 函数
  5. 立体图绘制：用 SVG path 绘制正三棱柱的线框图，可见面用浅蓝色填充
- ID 命名规范：
  - 所有元素 ID 以 scene3- 为前缀
  - 示例：scene3-net-fig3（图③展开图）、scene3-prism-3d（立体图）、scene3-btn-prev（上一步按钮）
  - JS 中使用 getElementById('scene3-xxx') 精确获取元素
- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染
- 动画曲线：使用 CSS transition: transform 0.5s ease-in-out 实现平滑折叠效果
