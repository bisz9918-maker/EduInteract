[图示主题与整合说明]
- 本图示主题：正方形沿对角线折叠的变换过程
- 整合的步骤/概念：正方形初始状态 → 显示对角线折痕 → 折叠动画 → 形成等腰直角三角形
- 教学价值：教师可通过分步演示，让学生直观理解折叠变换的几何过程，观察对角线作为对称轴的作用，为后续理解展开后圆洞的对称分布做铺垫。教师可控制节奏，在关键步骤暂停讲解。

  5. 可随时点击"上一步"回退复习关键步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单，无需复杂库；原生 SVG 轻量且易于控制元素显隐和动画
- 画布尺寸：800×500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |              步骤标题 (400,40)                    |
  |                                                  |
  |   +--------+          +--------+                 |
  |   |        |\         |       /|                 |
  |   | 正方形 | \ 对角线 | 三角形/ |                 |
  |   |        | \       |      /  |                 |
  |   +--------+  \      |     /   |                 |
  |      折叠箭头  \     |    /    |                 |
  |                 \    |   /     |                 |
  |                  --> |  /      |                 |
  |                 过程  | /       |                 |
  |                 箭头  |/________|                 |
  |                                                  |
  |        [上一步]  步骤指示器  [下一步]             |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-3) 跟踪当前步骤
  2. 元素分组：将各步骤的元素放入不同 g 组，用 display 控制显隐
  3. 按钮事件：上一步/下一步按钮绑定 click 事件，更新 currentStep 并刷新视图
  4. 动画：折叠箭头可用 CSS animation 实现轻微摆动（可选）
  5. 按钮状态：步骤 0 时禁用上一步，步骤 3 时下一步文字变"完成"
- ID 命名规范：
  - 所有元素 ID 以 scene1- 为前缀
  - 示例：scene1-square, scene1-diagonal, scene1-fold-arrow, scene1-triangle, scene1-hole1, scene1-right-angle-mark, scene1-label-diagonal, scene1-btn-prev, scene1-btn-next, scene1-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
