[图示主题与整合说明]
- 本图示主题：阴影面积的割补法验证
- 整合的步骤/概念：将阴影部分（五边形 ABPED）通过作垂线 PH 分割为梯形 ABHP 和矩形 PHDE 两部分，标注各部分尺寸，逐步展示面积计算过程
- 教学价值：教师可通过分步演示，引导学生理解割补法的核心思想——将不规则图形分割为规则图形分别计算；通过标注尺寸和面积，验证最终结果 11，与 Scene 1 的解法形成对比，培养学生多角度思考能力

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 按钮「◀上一步」：位置 (350, 455)，宽 100px，高 30px，点击返回上一状态
  - 按钮「下一步▶」：位置 (450, 455)，宽 100px，高 30px，点击进入下一状态
  - 状态指示器：位置 (400, 445)，显示「步骤 X / 3」
- 教师操作流程：
  1. 初始状态展示题目图形，让学生观察阴影部分形状
  2. 点击「下一步」显示分割线 PH，讲解割补法思路
  3. 点击「下一步」显示尺寸标注，引导学生读取数据
  4. 点击「下一步」显示面积计算，验证结果
  5. 可随时点击「上一步」回退复习关键步骤

[技术实现]
- JS 库选择：原生 SVG（简单几何图形首选，无需额外库）
- 画布尺寸：800 × 500 px（固定画布）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  A(280,100)________D(530,100)                    |
  |   |               | |                            |
  |   |  阴影区域     | |E                           |
  |   |    (蓝色)     | |                            |
  |   |       P_______|/                             |
  |   |      /        |                              |
  |   |     /         |                              |
  |  B(280,350)_______H(430)___C(530,350)            |
  |         <-3->  <-2->                              |
  |                                                  |
  |              [步骤指示器]                         |
  |         [◀上一步]  [下一步▶]                      |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 currentState (0-3)，每次点击按钮更新状态并重绘
  2. 坐标计算：所有坐标预先计算好硬编码，避免运行时计算误差
  3. 动画曲线：元素出现使用淡入效果（opacity 0→1，duration 300ms）
  4. 事件绑定：按钮点击事件绑定到 updateState() 函数
  5. 元素显示/隐藏：通过 display 属性或 opacity 控制
- ID 命名规范：所有交互元素 ID 必须以 scene2- 为前缀
  - scene2-square-abcd（正方形）
  - scene2-rhombus-pqcb（菱形）
  - scene2-shadow（阴影区域）
  - scene2-line-ph（分割线 PH）
  - scene2-line-pe（辅助线 PE）
  - scene2-label-a/b/c/d/p/h/e（点标签）
  - scene2-dim-5/3/2/4（尺寸标注）
  - scene2-area-text（面积计算文本）
  - scene2-btn-prev/next（按钮）
  - scene2-state-indicator（状态指示器）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
