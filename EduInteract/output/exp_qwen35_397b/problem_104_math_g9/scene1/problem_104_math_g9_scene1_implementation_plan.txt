[分步序列]
步骤0（初始状态）：仅显示坐标系

- 隐藏：所有正方形、所有顶点标签、角度标注、平行标识

步骤1：添加第一个正方形A₁B₁C₁D₁及角度标注
- 显示：正方形A₁B₁C₁D₁（填充#cccccc33）、标签A₁、B₁、C₁、D₁
- 显示：角度弧线（#1565c0）和30°标签

步骤2：添加完整正方形序列

- 显示：所有顶点标签A₁~A₃、B₁~B₃、C₁~C₃、D₁~D₂、E₁~E₄

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 按钮"◀上一步"：位置(320,460)，尺寸80×30，点击后退到前一步
  - 按钮"下一步▶"：位置(420,460)，尺寸80×30，点击前进到下一步
  - 步骤指示器：位置(360,435)，显示"步骤X/4"
- 教师操作流程：
  1. 初始展示坐标系，讲解坐标框架
  2. 点击"下一步"显示第一个正方形，讲解∠C₁B₁O=30°和边长1
  3. 点击"下一步"显示完整序列，观察正方形大小递减规律
  4. 点击"下一步"高亮平行关系，强调B₁C₁∥B₂C₂∥B₃C₃
  5. 点击"下一步"高亮x轴上的点，为后续计算做铺垫
  6. 可随时点击"上一步"回退复习

[技术实现]
- JS库选择：原生SVG（简单几何图形，无需额外库）
- 画布尺寸：800×500px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +------------------------------------------+
  | y                                        |
  | ↑                                        |
  | |   A₁                                   |
  | |  ╱│╲    A₂      A₃                     |
  | | ╱ │ ╲  ╱│╲    ╱│╲                     |
  | B₁──C₁──D₁B₂C₂D₂B₃C₃                    |
  | |      │  │      │                       |
  | O──────E₁──E₂────E₃──E₄────→ x          |
  |                                          |
  |         [◀上一步] [下一步▶]              |
  |            步骤X/4                       |
  +------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量currentStep(0-4)跟踪当前步骤
  2. 所有图形元素按步骤分组，用display属性控制显示/隐藏
  3. 所有交互元素ID以"scene1-"为前缀（如scene1-square1、scene1-label-a1）
  4. JS代码包在IIFE中：(function() { ... })()
  5. 按钮事件绑定用getElementById，避免跨场景污染
  6. 平行箭头用SVG marker或path绘制，方向与对应边平行
  7. 角度弧线用SVG arc路径，以B₁为圆心
- ID命名规范：
  - 正方形：scene1-square1、scene1-square2、scene1-square3
  - 小正方形：scene1-rect1、scene1-rect2
  - 标签：scene1-label-a1、scene1-label-b1...
  - 坐标轴：scene1-xaxis、scene1-yaxis
  - 角度弧：scene1-angle-arc
  - 平行箭头：scene1-parallel1、scene1-parallel2、scene1-parallel3
  - 控件：scene1-btn-prev、scene1-btn-next、scene1-step-indicator
