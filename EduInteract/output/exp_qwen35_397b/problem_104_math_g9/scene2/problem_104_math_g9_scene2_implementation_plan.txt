[图示主题与整合说明]
- 本图示主题：相邻倾斜正方形边长的递推关系推导
- 整合的步骤/概念：整合了第一个倾斜正方形 A₁B₁C₁D₁、过渡小正方形 D₁E₁E₂B₂、第二个倾斜正方形 A₂B₂C₂D₂ 的局部放大图，以及边长关系的几何推导（三角函数/相似三角形）
- 教学价值：教师可通过分步演示，引导学生从已知边长出发，分析过渡区域的几何关系，建立等式，最终得出公比 q = √3/3，理解等比数列的形成过程

- 步骤2：点击「下一步」→ 高亮小正方形D₁E₁E₂B₂（填充加深至50%），强调它是过渡区域

- 步骤5：点击「下一步」→ 显示推导公式框，内含 a₂/a₁ = √3/3，得出公比 q = √3/3

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于(150,460)，宽100px，高30px，灰色背景，点击返回上一状态
  - 「下一步」按钮：位于(550,460)，宽100px，高30px，蓝色背景，点击进入下一状态
  - 步骤指示器：位于(350,465)，显示「步骤 X/5」
- 教师操作流程：
  1. 初始状态展示基础图形，讲解题目已知条件
  2. 点击「下一步」逐步揭示几何关系
  3. 在步骤3-4引导学生观察辅助线形成的直角三角形
  4. 在步骤5总结递推公式，得出公比

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单，SVG 原生支持多边形、虚线、文本等元素，无需额外库
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |  y轴                                             |
  |  |                    [推导公式框]               |
  |  |   A₁                                         |
  |  |  /  \                                        |
  |  | B₁   \      D₁___B₂   A₂                     |
  |  | |     \     |   |   /  \                     |
  |  | |      \____|___|__/____\____ C₂             |
  |  | O      C₁   E₁  E₂                            |
  |  +------------------------------------ x轴 ------|
  |                                                  |
  |        [◀上一步]  步骤 0/5  [下一步▶]            |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量(0-5)，数组存储每步可见元素ID列表
  2. 坐标计算：所有顶点坐标预先计算好，硬编码在JS中
  3. 动画曲线：元素淡入使用 CSS transition opacity 0.3s ease
  4. 事件绑定：按钮点击事件绑定到 stepForward() 和 stepBack() 函数
  5. 元素显隐：通过 display:none / display:block 或 opacity 控制
- ID 命名规范：所有交互元素 ID 必须以 scene2- 为前缀
  - scene2-square1, scene2-square2, scene2-small-square
  - scene2-label-a1, scene2-label-a2, scene2-label-60deg
  - scene2-btn-prev, scene2-btn-next, scene2-step-indicator
  - scene2-formula-box, scene2-aux-line1, scene2-aux-line2
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中
