    **证明过程：**

    1. AD = AF（已知）
    2. AE = AE（公共边）

    - 强调"公共边"是全等证明中常用的隐含条件

    **易错提醒：**

    学生可能忽略角度计算步骤，直接认为∠DAE=∠FAE，需强调推导过程。

    **教学说明：**

    本图示是本题的核心，展示旋转变换这一关键解题思想，并整合结论③④的证明。

    **旋转变换分析：**

    由于 AB=AC，AD=AF，∠BAC=∠DAF=90°，可将△ACD 绕点 A 逆时针旋转 90°：
    - 点 C 旋转至点 B（因为 AC=AB，旋转 90°）
    - 点 D 旋转至点 F（因为 AD=AF，旋转 90°）
    - ∴ △ACD ≌ △ABF（旋转不改变形状大小）
    - ∴ BF = DC（对应边相等）

    **∠EBF=90°的证明：**

    1. 在等腰直角△ABC 中，∠ABC = ∠ACB = 45°
    2. 由旋转知∠ABF = ∠ACD = 45°
    3. ∴ ∠EBF = ∠ABF + ∠ABC = 45° + 45° = 90°

    **结论③的证明：**

    在△BEF 中，由三角形不等式：BE + BF > EF
    又 BF = DC，EF = DE（由结论①）
    ∴ BE + DC > DE ✓

    **结论④的证明：**

    在 Rt△BEF 中，由勾股定理：BE² + BF² = EF²
    又 BF = DC，EF = DE
    ∴ BE² + DC² = DE² ✓

    **结论②的分析：**

    △ABE ∽ △ACD 需要对应角相等或对应边成比例，但题目条件不足以证明这一点，故结论②不成立。

    **正确答案：C（①③④正确，共 3 个）**

    **课堂讲解建议：**

    1. 先让学生独立思考每个结论，再逐一验证
    2. 旋转变换是本题的"题眼"，需重点讲解
    3. 结论③④的证明依赖结论①和旋转变换，体现知识的串联
    4. 可让学生尝试用其他方法证明，培养发散思维
