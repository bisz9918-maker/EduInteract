[分步序列]
- 初始状态（步骤 0）：显示基础图形框架
  - 显示：所有线段 AB、AC、BC、AD、AE、AF、BF、EF（黑色）
  - 显示：6 个顶点标签 A、B、C、D、E、F
  - 隐藏：所有等边标记、直角符号、角度弧线、角度数值

- 步骤 1：高亮 AB=AC 等边关系
  - 显示：AB、AC 线段变为蓝色(#1565c0)
  - 显示：AB 中点蓝色单短线标记、AC 中点蓝色单短线标记
  - 保持：其他元素为黑色

- 步骤 2：高亮 AD=AF 等边关系
  - 显示：AD、AF 线段变为红色(#c62828)
  - 显示：AD 中点红色双短线标记、AF 中点红色双短线标记
  - 保持：步骤 1 的蓝色标记仍显示

- 步骤 3：标注∠BAC=90°
  - 显示：A 点处直角符号（黑色，20×20）
  - 显示：角度值"90°"文本 (420,150)
  - 保持：步骤 1、2 的等边标记

- 步骤 4：标注∠DAF=90°
  - 显示：A 点处嵌套直角符号（黑色，16×16，内层）
  - 保持：步骤 1、2、3 的所有标记

- 步骤 5：标注∠DAE=45°
  - 显示：∠DAE 绿色弧线（半径 50px，从 AD 到 AE）
  - 显示：角度值"45°"文本 (410,180)
  - 保持：之前所有标记

- 步骤 6：显示全部标注（最终状态）
  - 所有等边标记、直角符号、角度弧线、角度数值均显示
  - 线段恢复黑色，仅标记保留颜色
  - 完整呈现题目所有已知条件

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 底部左侧 (x=350, y=455)，点击返回上一状态
  - 「下一步」按钮：位于 SVG 底部右侧 (x=450, y=455)，点击进入下一状态
  - 状态指示器：位于底部中央 (x=400, y=455)，显示「步骤 X/6」
- 教师操作流程：
  1. 初始展示基础图形，让学生观察整体结构
  2. 点击「下一步」高亮 AB=AC，提问「这两条边有什么关系？」
  3. 点击「下一步」高亮 AD=AF，提问「还有哪些边相等？」
  4. 点击「下一步」显示∠BAC=90°，强调等腰直角三角形
  5. 点击「下一步」显示∠DAF=90°，引导学生发现两个直角
  6. 点击「下一步」显示∠DAE=45°，完成所有已知条件标注
  7. 可随时点击「上一步」回退复习

[技术实现]
- JS 库选择：原生 SVG（简单几何图形首选，无需额外库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +------------------------------------------+
  |                                          |
  |              A(400,120)                  |
  |             / | \  \                     |
  |            /  |  \  \ 90°                |
  |           /   |   \  \                   |
  |      F(180,220)  |    \                  |
  |         / \     |     \                  |
  |        /   \    |      \                 |
  |       /     \   |       \                |
  |      /       \  |        \               |
  |     /         \ |         \              |
  |    /           \|          \             |
  |   B-----E-------D-----------C            |
  | (220,380)                              |
  |                                          |
  |        [◀上一步] 步骤X/6 [下一步▶]        |
  |              (y=440~490)                 |
  +------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentState(0-6) 跟踪当前步骤
  2. 元素分组：将等边标记、直角符号、角度弧线分别放入<g>组，用 display 控制显隐
  3. 颜色切换：步骤 1-2 通过修改线段 stroke 属性实现高亮
  4. 事件绑定：按钮点击事件绑定到 nextState()/prevState() 函数
  5. 边界处理：currentState=0 时禁用「上一步」，currentState=6 时禁用「下一步」
- ID 命名规范：
  - 所有元素 ID 以 scene1- 为前缀
  - 线段：scene1-line-ab, scene1-line-ac, scene1-line-ad, scene1-line-af, scene1-line-ae, scene1-line-bc, scene1-line-bf, scene1-line-ef
  - 标签：scene1-label-a, scene1-label-b, scene1-label-c, scene1-label-d, scene1-label-e, scene1-label-f
  - 标记组：scene1-mark-equal-ab, scene1-mark-equal-ac, scene1-mark-equal-ad, scene1-mark-equal-af
  - 角度组：scene1-angle-bac, scene1-angle-daf, scene1-angle-dae
  - 控件：scene1-btn-prev, scene1-btn-next, scene1-status
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
