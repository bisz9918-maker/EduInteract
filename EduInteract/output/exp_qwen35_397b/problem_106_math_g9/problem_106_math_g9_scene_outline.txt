    **题目原文：**

    如图，已知⊙O是等腰Rt△ABC的外接圆，点D是$\stackrel\frown{AC}$上一点，BD交AC于点E，若BC=4，AD=$\frac{4}{5}$，则AE的长是（  ）

    A．3    B．2    C．1    D．1.2

    **题目分析：**

    本题是圆与等腰直角三角形结合的几何计算题。关键条件：
    - △ABC是等腰直角三角形，∠C=90°，AC=BC=4
    - ⊙O是外接圆，AB为直径（直径所对圆周角为直角）
    - 点D在弧AC上，BD与AC交于点E
    - 已知AD=4/5，求AE

    **解题思路：**

    核心是利用圆周角定理发现相似三角形：
    1. ∠DAC与∠DBC同对弧DC，故∠DAC=∠DBC
    2. ∠ADE与∠BCE同对弧AB，故∠ADE=∠BCE
    3. 因此△ADE∽△BCE（AA相似）
    4. 由相似得比例：AD/BC = AE/BE = DE/CE
    5. 代入AD=4/5，BC=4，得AE/BE = 1/5
    6. 设AE=x，则BE=5x，又AE+EC=AC=4，需进一步求解

    更优解法：利用△ABD∽△AED或其他相似关系。

    - SCENE_2：相似三角形比例关系的可视化推导

    **教学说明：**

    本图示用于引导学生发现相似三角形关系。

    **讲解步骤：**

    1. 首先让学生观察图形结构：圆内接等腰直角三角形，点D在弧上

    2. 提问：∠DAC和∠DBC有什么关系？引导学生发现它们同对弧DC

    3. 点击步骤2，显示蓝色角度弧线，确认∠DAC=∠DBC（同弧所对圆周角相等）

    4. 提问：还能找到哪对角相等？引导学生观察∠ADE和∠BCE

    5. 点击步骤3，显示绿色角度弧线，确认∠ADE=∠BCE

    6. 由两对角相等，得出△ADE∽△BCE

    7. 点击步骤4-5，显示相似关系和比例式

    **关键公式：**

    由△ADE∽△BCE得：
    
    $$\frac{AD}{BC} = \frac{AE}{BE} = \frac{DE}{CE}$$

    代入已知：AD=4/5，BC=4，得：
    
    $$\frac{AE}{BE} = \frac{4/5}{4} = \frac{1}{5}$$

    **教学说明：**

    本图示用于完成代数计算部分，将几何关系转化为方程求解。

    **完整解答：**

    由△ADE∽△BCE得：
    
    $$\frac{AD}{BC} = \frac{AE}{BE}$$
    
    $$\frac{4/5}{4} = \frac{AE}{BE} = \frac{1}{5}$$
    
    设AE=x，则BE=5x

    在△ABC中，AC=BC=4（等腰直角三角形）

    在△ABE中，利用勾股定理或相似关系：
    
    注意到△ABC是等腰直角三角形，AB=$4\sqrt{2}$

    更简洁的方法：利用△ABD中的关系

    实际上，由AE/BE=1/5且E在AC上：
    
    AE + EC = AC = 4
    
    由相似：DE/CE = 1/5，即CE = 5DE

    最终解得：**AE = 1**

    **课堂讲解建议：**

    1. 先让学生独立尝试，发现困难点

    4. 强调圆周角定理的应用场景

    5. 总结：圆内接四边形+相似三角形是常见组合
