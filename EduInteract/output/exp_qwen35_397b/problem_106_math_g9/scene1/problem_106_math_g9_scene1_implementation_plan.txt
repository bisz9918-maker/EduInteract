[分步序列]
- 初始状态（步骤0）：显示基础图形——圆O、直径AB、等腰Rt△ABC（AC、BC边）、点D在弧AC上、线段BD与AC交于E、圆心O。所有点标注A、B、C、D、E、O可见。
- 步骤1：点击「下一步」→ 显示已知条件标注：BC=4（位置490,190）、AD=4/5（位置260,200）、∠C=90°直角符号（C点处）。
- 步骤2：点击「下一步」→ 高亮圆周角∠DAC与∠DBC：以A为圆心画蓝色弧线#1565c0（半径25px），以B为圆心画蓝色弧线#1565c0（半径25px），在弧线旁显示文字"同弧DC所对圆周角"（位置400,80）。
- 步骤3：点击「下一步」→ 高亮圆周角∠ADE与∠BCE：以D为圆心画绿色弧线#2e7d32（半径20px），以C为圆心画绿色弧线#2e7d32（半径20px），在弧线旁显示文字"同弧AB所对圆周角"（位置400,320）。
- 步骤4：点击「下一步」→ 用半透明蓝色#1565c0(20%)填充△ADE区域，用半透明红色#c62828(20%)填充△BCE区域，在画布中央显示结论文本"△ADE∽△BCE"（位置400,240，加粗）。
- 步骤5：点击「下一步」→ 显示比例关系"AD/BC = AE/BE"（位置400,360），同时高亮对应边：AD与BC用蓝色加粗，AE与BE用红色加粗。

- "C"(400,95)与"同弧DC所对圆周角"(400,80)：垂直距离15px → 接近但可接受（文字基线不同）

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 按钮"◀上一步"：位置(320,465)，宽100px，高35px，灰色背景#e0e0e0，点击返回上一状态
  - 按钮"下一步▶"：位置(480,465)，宽100px，高35px，蓝色背景#1565c0，白色文字，点击进入下一状态
  - 步骤指示器：位置(400,465)，显示"步骤 X/5"，白色文字
- 教师操作流程：
  1. 初始状态展示基础图形，教师引导学生观察圆内接三角形的基本结构
  2. 点击"下一步"显示已知条件，教师强调BC=4、AD=4/5、∠C=90°
  3. 点击"下一步"高亮第一组圆周角，教师讲解"同弧所对圆周角相等"
  4. 点击"下一步"高亮第二组圆周角，教师引导学生发现两组角对应相等
  5. 点击"下一步"填充相似三角形，教师总结"两角对应相等→三角形相似"
  6. 点击"下一步"显示比例关系，教师推导最终结论

[技术实现]
- JS 库选择及原因：原生 SVG。理由：本场景为静态几何图形+简单填充+分步显示，无需复杂动画或交互，原生 SVG 轻量且精确控制坐标。
- 画布尺寸：800 × 500 px（固定画布）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +------------------------------------------+
  |                                          |
  |              C(400,110)                  |
  |           "同弧DC所对圆周角"              |
  |         D ●       ●                      |
  |            \     / \                     |
  |             \ E ●   \                    |
  |              \   /   \                   |
  |     A ●_______\_/_____\___ ● B           |
  |              O(400,260)                  |
  |         "△ADE∽△BCE"                      |
  |         "同弧AB所对圆周角"                |
  |           "AD/BC=AE/BE"                  |
  |                                          |
  |      [◀上一步]  步骤X/5  [下一步▶]        |
  +------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep(0-5) 跟踪当前步骤，数组 steps 存储每步需显示的元素ID列表
  2. 坐标计算：所有点坐标预先计算硬编码，避免运行时计算误差
  3. 动画曲线：元素显示/隐藏使用 CSS transition opacity 0.3s ease
  4. 事件绑定：按钮点击事件绑定到 scene1-btn-prev 和 scene1-btn-next
  5. 元素分组：用<g>元素按步骤分组，每步控制对应组的 display 属性
- ID 命名规范：所有元素 ID 以 scene1- 为前缀，如 scene1-circle-o、scene1-point-a、scene1-label-bc、scene1-arc-dac、scene1-tri-ade 等
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
