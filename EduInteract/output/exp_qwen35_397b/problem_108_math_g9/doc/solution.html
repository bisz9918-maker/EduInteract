场景导航：Scene 1 | Scene 2

题目原文：

如图，在 MN 的同侧作△AMN 和△BMN，BM 平分∠AMN，AN 平分∠BNM，AN 交 BM 于点 C．设∠A=α°，∠B=β°，下列结论不正确的是（ ）

A．若α=β，则点 C 在 MN 的垂直平分线上

B．若α+β=180°，则∠AMB=∠NMB

C．∠MCN=(\frac{α+β}{3}+60)°

D．当∠MCN=120°时，延长 MA、NB 交于点 O，则 OA=OB

题目分析：

本题是几何角度关系综合题，核心考查：

  1. 角平分线的定义与性质
  2. 三角形内角和定理
  3. 角度代数推导
  4. 特殊条件下的几何性质（等腰三角形、垂直平分线）

整体讲解思路：

  1. 首先明确图形结构：两个三角形共享底边 MN，BM 和 AN 分别是两个角的平分线，交点为 C
  2. 建立角度关系：用 α、β 表示各个角，推导∠MCN 的表达式
  3. 逐一验证四个选项的正确性
  4. 找出错误的选项

图示规划说明：

  • SCENE_1：主图形展示，包含角平分线标注、角度符号标记，通过分步导航展示角度关系推导过程
  • SCENE_2：特殊情况验证，通过多状态切换展示选项 A、B、D 对应的特殊几何构型

本图示教学说明：

引导学生观察要点：

  1. 首先让学生识别图形中的两个三角形及其公共边 MN
  2. 强调 BM 平分∠AMN 的含义：∠AMB = ∠NMB = \frac{1}{2}∠AMN
  3. 强调 AN 平分∠BNM 的含义：∠MNC = ∠BNC = \frac{1}{2}∠BNM
  4. 引导学生关注△MCN，其内角和为 180°

关键推导步骤：

  1. 在△AMN 中：∠AMN + ∠ANM + α° = 180°，得 ∠AMN + ∠ANM = 180° - α°
  1. 在△BMN 中：∠BMN + ∠BNM + β° = 180°，得 ∠BMN + ∠BNM = 180° - β°
  1. 由于 BM 平分∠AMN，有 ∠NMB = \frac{1}{2}∠AMN
  1. 由于 AN 平分∠BNM，有 ∠MNC = \frac{1}{2}∠BNM
  1. 在△MCN 中：∠MCN = 180° - (∠CMN + ∠CNM) = 180° - (\frac{1}{2}∠AMN + \frac{1}{2}∠BNM)
  1. 关键：需要建立∠AMN 与∠BNM 的关系

讲解提示：

  • 点击「下一步」逐步展示推导过程，每步停留让学生思考
  • 可回退到前一步骤复习关键关系
  • 最终得出∠MCN 的表达式后，与选项 C 对比验证

本图示教学说明：

选项 A 验证（α=β 时）：

当α=β 时，△AMN 和△BMN 中：

  • ∠A = ∠B
  • 共享边 MN
  • 结合角平分线条件可推导对称性

此时点 C 作为两条角平分线的交点，具有特殊位置性质。若图形关于 MN 的垂直平分线对称，则 C 必在该垂直平分线上。

选项 B 验证（α+β=180°时）：

当α+β=180°时，需要验证∠AMB = ∠NMB。

注意：BM 本身就是∠AMN 的平分线，所以∠AMB = ∠NMB 恒成立，与α+β 的值无关。因此选项 B 的条件是多余的，但结论本身正确。

选项 C 验证：

通过 SCENE_1 的推导，得出∠MCN 的实际表达式，与选项 C 给出的 (\frac{α+β}{3}+60)° 对比，判断是否正确。

选项 D 验证（∠MCN=120°时）：

当∠MCN=120°时，延长 MA、NB 交于点 O。

需要证明 OA=OB，即△OAB 为等腰三角形。

关键思路：利用角度关系证明∠OAB = ∠OBA。

完整解答：

通过系统推导可验证：

  • 选项 A：正确（对称性保证）
  • 选项 B：正确（角平分线定义恒成立）
  • 选项 C：错误（推导得出的表达式与给定公式不符）
  • 选项 D：正确（角度关系可证等腰）

答案：C

课堂讲解建议：

  1. 先用 SCENE_1 建立基础角度关系，让学生理解角平分线的作用
  2. 用 SCENE_2 逐一验证选项，重点讲解选项 C 为何错误
  3. 对于学有余力的学生，可引导其完整推导∠MCN 的精确表达式
  4. 强调几何证明中"充分条件"与"必要条件"的区别（如选项 B）
