[图示主题与整合说明]
- 本图示主题：四个选项的几何验证（特殊情况展示）
- 整合的步骤/概念：整合了选项 A（α=β 时 C 在垂直平分线上）、选项 B（α+β=180°时的角度关系）、选项 D（∠MCN=120°时延长线交点 O 的性质）的几何构型验证
- 教学价值：教师可通过状态切换快速展示不同条件下的几何特征，对比分析各选项的正确性，帮助学生理解角平分线性质、等腰三角形判定、垂直平分线定理等核心概念

[分步序列]
- 初始状态（状态 0 - 基础图形）：显示△AMN 和△BMN 基础结构，MN 水平底边，AN 与 BM 交于 C，标注点 A、B、C、M、N，显示∠A=α°、∠B=β°角度弧和标签，不显示任何特殊条件
- 状态 1（选项 A：α=β）：设置α=β=60°，显示 MN 的垂直平分线（灰色虚线从 (400,380) 到 (400,80)），高亮点 C 位于垂直平分线上，右上角显示"选项 A：✓正确"，右侧说明区显示"当α=β时，△AMN≌△BMN，C 在 MN 垂直平分线上"
- 状态 2（选项 B：α+β=180°）：设置α=100°、β=80°（和为 180°），高亮∠AMB 和∠NMB，右上角显示"选项 B：✗错误"，右侧说明区显示"α+β=180°时，∠AMB≠∠NMB，BM 平分∠AMN 不意味着∠AMB=∠NMB"
- 状态 3（选项 D：∠MCN=120°）：设置∠MCN=120°，显示 MA 延长线和 NB 延长线交于点 O(400,40)，显示 OA 和 OB 上的绿色等长标记，标注"OA=OB"，右上角显示"选项 D：✓正确"，右侧说明区显示"当∠MCN=120°时，△OAB 为等腰三角形，OA=OB"

冲突检查：
- "A"(280,105) 与"α"(290,100)：间距≈11px → 调整α到(295,90)，间距≈18px，可接受
- "B"(560,145) 与"β"(570,140)：间距≈11px → 调整β到(575,130)，间距≈18px，可接受
- "C"(435,280) 与"120°"(430,260)：间距≈20px → 无冲突
- "O"(400,25) 与"A"(280,105)：间距≈97px → 无冲突
- "选项判断"(650,100) 与"B"(560,145)：间距≈100px → 无冲突
- 垂直平分线 x=400 与点 C(420,280)：水平距离 20px → 点 C 略偏右，视觉上可接受

[交互方案]
- 交互类型：多状态切换（4 个按钮：基础图形、选项 A、选项 B、选项 D）
- 控件说明：
  - 按钮"基础图形"：位置(510,450)，返回初始状态，仅显示基础几何结构
  - 按钮"选项 A"：位置(150,450)，展示α=β时的垂直平分线性质
  - 按钮"选项 B"：位置(270,450)，展示α+β=180°时的角度关系
  - 按钮"选项 D"：位置(390,450)，展示∠MCN=120°时延长线交点 O 的性质
- 教师操作流程：教师点击不同状态按钮→图示更新显示对应条件下的几何特征→结合右侧结论说明区讲解该选项的正确性→学生直观理解各选项的几何意义

[技术实现]
- JS 库选择及原因：原生 SVG（简单几何图形，无需复杂库，代码轻量易维护）
- 画布尺寸：800 × 500 px（固定画布）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |                    O(状态 3)                     |
  |                   / \                            |
  |                  /   \                           |
  |                 A     B                          |
  |                / \   / \                         |
  |               /   \ /   \                        |
  |              /     C     \                       |
  |             /             \                      |
  |            M---------------N                     |
  |                                                  |
  |   [垂直平分线：状态 1 显示]                       |
  |                                                  |
  +--------------------------------------------------+
  |  [选项 A] [选项 B] [选项 D] [基础图形]  [结论区]  |
  |  (150,450)(270,450)(390,450)(510,450)  (620,200) |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用 currentState 变量跟踪当前状态（0-3），点击按钮时更新状态并重绘
  2. 坐标计算：所有点坐标硬编码，确保布局精确；垂直平分线 x=400 为 MN 中点
  3. 动画曲线：状态切换使用 CSS transition 实现平滑过渡（opacity、stroke-dasharray）
  4. 事件绑定：4 个按钮分别绑定 click 事件，调用 updateState(newState) 函数
  5. 条件显示：用 SVG 元素的 display 属性或 opacity 控制各状态下元素的显示/隐藏
- ID 命名规范：所有交互元素 ID 必须以 scene2- 为前缀（如 scene2-tri-amn、scene2-perp-bisector、scene2-btn-optionA）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
