[图示主题与整合说明]
- 本图示主题：半圆绕点 B 旋转 45° 形成阴影部分的动态过程
- 整合的内容：原始半圆位置、旋转轨迹、旋转后半圆位置、阴影区域形成
- 教学价值：教师可通过分步动画展示旋转过程，帮助学生理解阴影部分面积的几何构成，直观感受旋转不变性（半圆面积不变），从而推导阴影面积等于扇形 ABA' 的面积

[分步序列]
- 初始状态（步骤 0）：显示原始半圆（线段 AB + 上半圆弧），标签 A、B 可见
- 步骤 1：高亮旋转中心点 B（B 点显示红色小圆点），显示顺时针旋转箭头（在 B 点右侧）
- 步骤 2：显示点 A 的运动轨迹（红色虚线圆弧从 A 到 A'），标签 A' 出现在轨迹终点
- 步骤 3：显示旋转后的半圆（蓝色轮廓线段 A'B + 蓝色半圆弧）
- 步骤 4：显示角度标注弧（绿色小圆弧）和标签"45°"，填充阴影区域（红色半透明）
- 最终步骤：所有元素完整显示，教师可讲解阴影面积 = 扇形 ABA' 面积 = (45/360)×π×4² = 2π

冲突检查：
- "A"与"B"间距：270px → 无冲突
- "A"与"A'"间距：√[(330-265)²+(165-370)²] = √[4225+42025] = √46250 ≈ 215px → 无冲突
- "A"与"45°"间距：√[(475-265)²+(315-370)²] = √[44100+3025] = √47125 ≈ 217px → 无冲突
- "B"与"A'"间距：√[(330-535)²+(165-370)²] = √[42025+42025] = √84050 ≈ 290px → 无冲突
- "B"与"45°"间距：√[(475-535)²+(315-370)²] = √[3600+3025] = √6625 ≈ 81px → 无冲突（间距充足）
- "A'"与"45°"间距：√[(475-330)²+(315-165)²] = √[21025+22500] = √43525 ≈ 209px → 无冲突

所有标签间距均≥20px，无冲突。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 按钮"上一步"：位于 SVG 底部左侧 (x=320, y=455)，返回上一状态
  - 按钮"下一步"：位于 SVG 底部右侧 (x=460, y=455)，进入下一状态
  - 状态指示器：位于两按钮之间 (x=400, y=460)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始状态展示题目基础图形（原始半圆）
  2. 点击"下一步"高亮旋转中心 B，引导学生关注旋转支点
  3. 点击"下一步"显示 A 点运动轨迹，直观展示旋转路径
  4. 点击"下一步"显示旋转后半圆，对比前后位置
  5. 点击"下一步"显示角度和阴影，完成阴影区域构建
  6. 可随时点击"上一步"回退复习关键步骤

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript
  - 原因：几何图形（圆弧、线段、路径）用 SVG 原生元素即可精确绘制，无需额外库
  - 动画使用 CSS transition 或 JS requestAnimationFrame 实现平滑过渡
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +------------------------------------------+
  |                                          |
  |           A'  (旋转后半圆)               |
  |          /¯¯¯¯¯¯¯¯¯¯\                    |
  |         /   阴影区    \                  |
  |        /              \                  |
  |       A────────────────B                 |
  |        \______________/ (原始半圆)        |
  |                                          |
  |                              45°标注     |
  |                                          |
  |    [◀ 上一步]  步骤 X/5  [下一步 ▶]       |
  +------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量 (0-4) 跟踪当前步骤，steps 数组存储每步可见元素 ID 列表
  2. 坐标计算：A' 坐标通过旋转矩阵计算：x' = Bx + (Ax-Bx)*cos(45°) - (Ay-By)*sin(45°), y' = By + (Ax-Bx)*sin(45°) + (Ay-By)*cos(45°)
  3. 阴影路径：使用 SVG path 的 A 命令绘制两段圆弧形成封闭区域
  4. 事件绑定：按钮点击事件切换状态，更新各元素 display/opacity 属性
  5. 动画效果：轨迹弧和阴影区域使用 opacity 从 0 到 1 的过渡动画（300ms）
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀
  - scene1-line-ab, scene1-arc-original, scene1-arc-rotated, scene1-line-a1b
  - scene1-path-trajectory, scene1-path-shadow, scene1-arc-angle
  - scene1-label-a, scene1-label-b, scene1-label-a1, scene1-label-45deg
  - scene1-btn-prev, scene1-btn-next, scene1-step-indicator
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
