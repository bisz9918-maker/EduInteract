problem_10_physics_g9

场景导航：Scene 1 | Scene 2

题目原文：

如图，两个用同一种材料制成且完全相同的密闭圆台形容器一正一反放置在同一水平桌面上，容器内装有质量和深度均相同的液体，密度分别为ρ₁和ρ₂，若它们分别在水平方向拉力F₁和F₂的作用下沿桌面做匀速直线运动，速度分别为v和2v，容器底部受到液体的压强分别为P₁和P₂，容器底部受到液体的压力分别为N₁和N₂，现对这些物理量做出如下判断：①ρ₁＞ρ₂；②F₁=F₂；③P₁＞P₂；④N₁＜N₂，其中正确的是（ ）

题目分析：

本题综合考查液体密度、压强、压力以及摩擦力的分析。关键信息：

  • 两容器完全相同，一正一反放置
  • 液体质量相同、深度相同
  • 匀速直线运动（拉力=摩擦力）
  • 速度不同（v 和 2v），但匀速运动时速度不影响受力平衡

整体讲解思路：

  1. 首先分析密度关系：相同质量下，体积小的密度大
  2. 分析拉力关系：匀速运动时拉力等于摩擦力，摩擦力取决于总重力
  3. 分析压强关系：P=ρgh，深度相同，密度大的压强大
  4. 分析压力关系：需考虑容器形状对底部压力的影响

图示规划说明：

  • SCENE_1：展示两容器形状对比，高亮液体体积差异，推导密度关系
  • SCENE_2：综合力学分析，展示拉力平衡和底部压力的受力分析
步骤 0/3

SCENE_1 教学说明：

教师引导学生观察：

  1. 两容器形状完全相同，但放置方向相反
  2. 液体深度 h 相同（用红色标注线强调）
  3. 由于圆台形状，左侧（倒放）液体体积 V₁ 小于右侧（正放）液体体积 V₂
  4. 已知质量 m₁ = m₂，根据密度公式 ρ = m/V

关键推导：

  • V₁ < V₂（从图形直观看出）
  • m₁ = m₂（题目已知）
  • ∴ ρ₁ = m₁/V₁ > m₂/V₂ = ρ₂

结论：① ρ₁ > ρ₂ 正确

步骤 0/4

SCENE_2 教学说明：

拉力分析（步骤 1-2）：

  1. 两容器匀速直线运动，处于平衡状态
  2. 水平方向：拉力 F = 摩擦力 f
  3. 摩擦力 f = μ × N支，N支 = G_总（容器重 + 液体重）
  4. 两容器材料相同、液体质量相同 → G_总相同 → f₁ = f₂
  5. ∴ F₁ = F₂（与速度 v 或 2v 无关）

结论：② F₁ = F₂ 正确

压强分析（步骤 3）：

液体压强公式：P = ρgh

  • 深度 h 相同
  • ρ₁ > ρ₂（已证）
  • ∴ P₁ = ρ₁gh > ρ₂gh = P₂

结论：③ P₁ > P₂ 正确

压力分析（步骤 4）：

底部压力 N = P × S_底，但需考虑容器形状影响：

  • 左侧（倒放）：侧壁对液体有向下的压力分量，N₁ > G_液
  • 右侧（正放）：侧壁对液体有向上的支持分量，N₂ < G_液
  • ∴ N₁ > N₂

结论：④ N₁ < N₂ 错误

最终答案：B（①②③正确）
