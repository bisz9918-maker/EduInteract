[分步序列]
步骤 0（初始状态）：
- 显示：两容器轮廓、液体区域（灰色填充 30%）、桌面线
- 显示：速度箭头（v 和 2v，上方标注）
- 显示：拉力箭头 F₁、F₂（蓝色，从容器中心向右）
- 标签：F₁、F₂、v、2v
- 公式区：空白

步骤 1（水平受力分析）：
- 新增：摩擦力箭头 f₁、f₂（灰色虚线，从容器中心向左）
- 新增：重力箭头 G（黑色，向下）、支持力箭头 N 支（绿色，向上）
- 标签：f₁、f₂、G、N 支
- 公式区显示：「匀速直线运动 → 合力为零」
- 高亮：拉力与摩擦力箭头（加粗显示）

步骤 2（拉力平衡结论）：
- 保持步骤 1 所有元素
- 公式区新增：「F₁ = f₁，F₂ = f₂」
- 公式区新增：「材料相同→μ相同；质量相同→N 相同→f=μN 相同」
- 公式区结论：「∴ F₁ = F₂」
- 高亮：F₁ 和 F₂ 箭头变为绿色表示相等

步骤 3（底部压强分析）：
- 隐藏：水平受力箭头（f₁、f₂、G、N 支），保留容器、液体、拉力
- 新增：压强区域填充（容器底部，#c62828 透明度 20%）
- 新增：压强标注 P₁、P₂（红色文字，容器底部下方）
- 公式区显示：「P = ρgh」
- 公式区分析：「h 相同，但 V₁ < V₂（容器 1 上宽下窄，液体体积较小）」
- 公式区分析：「质量 m 相同→ρ₁ = m/V₁ > ρ₂ = m/V₂」
- 公式区结论：「∴ P₁ > P₂」
- 高亮：P₁ 和 P₂ 标签

步骤 4（底部压力分析）：
- 保持步骤 3 的压强区域
- 新增：底部压力箭头 N₁、N₂（红色，从底部向下）
- 新增：侧壁作用力箭头（蓝色虚线，垂直于侧壁）
  - 容器 1（正放）：侧壁向外倾斜，法向力有向上的竖直分量→侧壁承担部分液体重力→N₁ < G 液
  - 容器 2（反放）：侧壁向内倾斜，法向力有向下的竖直分量→侧壁对液体有向下压力→N₂ > G 液
- 公式区显示：「容器 1：侧壁作用力有向上分量→N₁ < G 液」
- 公式区显示：「容器 2：侧壁作用力有向下分量→N₂ > G 液」
- 公式区结论：「∴ N₁ < N₂」
- 高亮：N₁ 和 N₂ 箭头，侧壁作用力箭头

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（梯形、箭头、文本），无需复杂库；原生 SVG 便于精确控制坐标和样式；代码轻量，加载快
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +----------------------------------------------------------+
  |  v→    [容器 1]  F₁→           [容器 2]  F₂→    ←2v      | y=50-150
  |                                                          |
  |         f₁←  [受力分析]  →f₂                             | y=150-200
  |                                                          |
  |              P₁  P₂   N₁  N₂                             | y=200-250
  |                                                          |
  |  +------------------+  [公式区]                          | y=50-420
  |  |  F = f           |  x=600-780                         |
  |  |  P = ρgh         |                                     |
  |  |  N₁ < N₂         |                                     |
  |  +------------------+                                     |
  |                                                          |
  |  [上一步]  步骤 X/4  [下一步]                            | y=440-490
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-4) 跟踪当前步骤，数组 stepConfig 存储每步的显示/隐藏配置
  2. 坐标计算：所有元素坐标硬编码（基于布局坐标表），箭头终点=起点 + 方向向量×长度
  3. 动画曲线：元素显示/隐藏使用 CSS transition opacity 0.3s ease，箭头绘制使用 stroke-dasharray 动画
  4. 事件绑定：按钮点击事件绑定到 stepChange 函数，更新 currentStep 并调用 renderStep()
  5. 元素 ID 命名：所有元素 ID 以 scene2- 为前缀，如 scene2-container1、scene2-arrow-F1、scene2-label-P1
  6. IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
