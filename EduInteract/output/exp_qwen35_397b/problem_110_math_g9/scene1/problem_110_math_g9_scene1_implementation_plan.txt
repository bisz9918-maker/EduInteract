[图示主题与整合说明]
- 本图示主题：台球反射问题中的角度关系推导
- 整合的内容：台球桌原图、角度标注（∠1、∠2、∠3）、反射定律说明、矩形角关系、完整推导过程
- 教学价值：教师可通过分步动画展示台球反射问题中角度的推导链条，从已知∠3=30°出发，利用矩形内角性质和反射定律，逐步求得∠1=60°。学生可直观理解"入射角=反射角"的物理原理与几何角度计算的结合应用。

[标签冲突检查]
所有标签坐标及间距检查：

| 标签名 | 坐标 (x,y) | 备注 |
|--------|-----------|------|
| ∠3=30° | (680,355) | 右下角弧线左上方 |
| 90° | (690,105) | 右上角直角标记下方 |
| ∠2=60° | (465,65) | 法线右侧 |
| 60°计算式 | (465,50) | ∠2 标签上方 |
| ∠1=60° | (435,65) | 法线左侧 |
| 答案文本 | (400,420) | 图示下方中央 |

冲突检查：
- "∠3=30°" (680,355) 与 "90°" (690,105)：垂直距离 250px → 无冲突
- "90°" (690,105) 与 "∠2=60°" (465,65)：水平距离 225px，垂直距离 40px → 无冲突
- "∠2=60°" (465,65) 与 "60°计算式" (465,50)：垂直距离 15px → 接近但可接受（计算式在标签正上方）
- "∠2=60°" (465,65) 与 "∠1=60°" (435,65)：水平距离 30px → 无冲突（法线分隔）
- "∠1=60°" (435,65) 与 "答案文本" (400,420)：垂直距离 355px → 无冲突
- 所有标签与图形元素：角度标签均在弧线外侧，不压在线段或球体上 → 无冲突

解决方案：
- "60°计算式" 与 "∠2=60°" 垂直间距仅 15px，若显示拥挤可将计算式上移至 y=40
- 步骤 3 的"入射角=反射角"说明文本临时显示于 (450,35)，不与其他标签重叠

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于 (320,455)，80×30px，点击后退到前一状态
  - 「下一步 ▶」按钮：位于 (420,455)，80×30px，点击前进到下一状态
  - 步骤指示器：位于两按钮之间，显示"步骤 X/5"
- 教师操作流程：
  1. 初始状态展示题目原图，引导学生观察已知条件∠3=30°
  2. 点击「下一步」高亮右上角，提问"矩形内角是多少度？"
  3. 点击「下一步」显示∠2 计算过程，引导学生理解互余关系
  4. 点击「下一步」高亮法线，讲解反射定律"入射角=反射角"
  5. 点击「下一步」显示最终答案，完成推导链条

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单，无需复杂库；SVG 便于精确控制坐标和样式；原生 JS 足够实现分步状态切换
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────┐
  │                    台球桌主图区 (800×420)                  │
  │  ┌──────────────────────────────────────────────────────┐  │
  │  │  ○        ○                    ○        ○            │  │
  │  │                                                      │  │
  │  │           ╲        │        ╱                        │  │
  │  │            ╲  ∠1   │   ∠2  ╱                         │  │
  │  │             ╲      │      ╱                          │  │
  │  │              ●─────┼─────●                           │  │
  │  │             白球   │    黑球                          │  │
  │  │                    │                                  │  │
  │  │  ○        ○        │        ○        ○               │  │
  │  └────────────────────┼──────────────────────────────────┘  │
  │                       │  ∠3=30°                             │
  └───────────────────────┴──────────────────────────────────────┘
  ┌────────────────────────────────────────────────────────────┐
  │  控件栏 (y=450~490)                                        │
  │         [◀ 上一步]  步骤 1/5  [下一步 ▶]                    │
  └────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-4) 跟踪当前步骤，数组 steps 定义每步显示/隐藏的元素 ID 列表
  2. 坐标计算：所有元素坐标硬编码，确保与布局坐标表一致
  3. 动画曲线：使用 CSS transition 实现平滑过渡（opacity、stroke 颜色变化）
  4. 事件绑定：按钮点击事件绑定 stepForward() 和 stepBackward() 函数
  5. 元素显隐：通过 display="none" 或 opacity="0" 控制，高亮通过修改 stroke/fill 颜色
- ID 命名规范：
  - 所有元素 ID 以 "scene1-" 为前缀
  - 示例：scene1-table（台球桌）、scene1-white-ball（白球）、scene1-black-ball（黑球）
  - scene1-trajectory-in（入射轨迹）、scene1-trajectory-out（反射轨迹）
  - scene1-normal（法线）、scene1-angle-arc-1（∠1 弧线）、scene1-angle-label-1（∠1 标签）
  - scene1-btn-prev（上一步按钮）、scene1-btn-next（下一步按钮）、scene1-step-indicator（步骤指示器）
- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染
- 箭头 marker 定义：在 SVG <defs> 中定义蓝色箭头 marker，复用给三条轨迹线
