[图示主题与整合说明]
- 本图示主题：等腰三角形中的角度推导与线段等量关系（黄金三角形）
- 整合的内容：基础图形展示、角度计算、垂直平分线性质应用、等腰三角形判定、黄金三角形结论五个认知阶段
- 教学价值：教师可使用此图示逐步引导学生从已知条件（AB=AC=4，∠C=72°）出发，通过角度推导发现∠A=36°，再利用垂直平分线性质得到 EA=EB，进而推导出△ABE 和△BCE 的角度关系，最终得出 BE=BC 的黄金三角形结论，求得 cos36°=(√5+1)/4

[分步序列]
步骤 0（初始状态）：
- 显示：三角形 ABC 黑色边框
- 显示：线段 DE（垂直平分线）
- 显示：直角符号在 D 点
- 显示：等长标记（AB 和 AC 上的双短线）
- 显示：标签 A、B、C、D、E
- 显示：标注 AB=4（左侧）、AC=4（右侧）、∠C=72°（C 点内侧）
- 隐藏：BE 线段、所有角度弧线（除∠C 外）、推导标注

步骤 1（点击「下一步」）：
- 显示：∠B 弧线 + 标注∠B=72°（B 点内侧）
- 显示：∠A 弧线（蓝色填充 15%）+ 标注∠A=36°（蓝色，A 点下方）
- 高亮：∠B 和∠C 弧线
- 文字提示：「等腰三角形底角相等：∠B=∠C=72°，顶角∠A=180°−72°−72°=36°」

步骤 2（点击「下一步」）：
- 显示：线段 BE（蓝色虚线）
- 显示：标注 EA=EB（绿色，BE 线段上方）
- 高亮：线段 DE 和点 E
- 文字提示：「DE 是 AB 的垂直平分线 → EA=EB（垂直平分线上的点到线段两端距离相等）」

步骤 3（点击「下一步」）：
- 显示：∠ABE 弧线（蓝色填充）+ 标注∠ABE=36°（蓝色）
- 显示：∠CBE 弧线 + 标注∠CBE=36°（72°−36°=36°）
- 显示：∠BEC 弧线 + 标注∠BEC=72°
- 文字提示：「△ABE 中∠ABE=∠A=36°；△BCE 中∠CBE=72°−36°=36°，∠BEC=180°−36°−72°=72°」

步骤 4（点击「下一步」）：
- 显示：标注 BE=BC（绿色，BC 线段下方）
- 显示：标注 AE=x（AC 外侧）
- 显示：标注 EC=4−x（AC 外侧下方）
- 高亮：BE 和 BC 线段（绿色）
- 文字提示：「△BCE 中∠BEC=∠C=72° → BE=BC；设 AE=x，则 EC=4−x，BC=BE=x」

步骤 5（点击「下一步」）：
- 显示：结论 cosA=cos36°=(√5+1)/4（蓝色，底部居中）
- 显示：选项 C 高亮
- 文字提示：「在△ABC 中，cosA=cos36°=(√5+1)/4，对应选项 C」

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于 (280, 450)，点击后返回上一状态（步骤 0 时禁用）
  - 「下一步 ▶」按钮：位于 (420, 450)，点击后进入下一状态（步骤 5 时禁用）
  - 步骤指示器：位于 (550, 465)，显示当前步骤「步骤 X/5」
- 教师操作流程：
  1. 初始加载显示步骤 0（基础图形和已知条件）
  2. 讲解已知条件后，点击「下一步」进入步骤 1，引导学生计算角度
  3. 继续点击「下一步」逐步揭示垂直平分线性质、等腰三角形判定
  4. 步骤 4 引导学生设未知数建立比例关系
  5. 步骤 5 展示最终结论 cos36°=(√5+1)/4
  6. 教师可随时点击「上一步」回退复习关键步骤

[技术实现]
- JS 库选择：原生 SVG（简单几何图形首选，无需额外库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │                        A(400,100)                           │
  │                         /|\                                 │
  │                        / | \                                │
  │              AB=4    /  |  \   AC=4                         │
  │                      /   |   \                              │
  │                     /    |    \                             │
  │               D ___/_____|_____E                            │
  │                   /      |      \                           │
  │                  /       |       \                          │
  │                 /        |        \                         │
  │                /         |         \                        │
  │           B(320,350)_____|__________C(480,350)              │
  │                     BE=BC                                   │
  │                                                             │
  │              cosA = cos36° = (√5+1)/4                       │
  │                                                             │
  │    [◀ 上一步]    [下一步 ▶]          步骤 0/1/2/3/4/5       │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量 (0-5)，每个步骤对应一个状态对象，包含显示/隐藏的元素 ID 列表
  2. 坐标计算：所有元素坐标预先计算好，直接写入 SVG 属性
  3. 动画曲线：元素淡入使用 CSS transition opacity 0.3s ease
  4. 事件绑定：按钮点击事件绑定到 stepForward() 和 stepBackward() 函数
  5. 元素分组：使用 <g> 标签按步骤分组元素，通过 display 属性控制显示/隐藏
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀
  - scene1-tri-abc（三角形）
  - scene1-line-de（线段 DE）
  - scene1-line-be（线段 BE）
  - scene1-label-a, scene1-label-b, scene1-label-c, scene1-label-d, scene1-label-e
  - scene1-anno-ab4, scene1-anno-ac4, scene1-anno-angle-c72
  - scene1-angle-a, scene1-angle-b, scene1-angle-c（角度弧线）
  - scene1-anno-angle-a36, scene1-anno-angle-b72（角度数值标注）
  - scene1-anno-eaeb, scene1-anno-bebc（等量关系标注）
  - scene1-btn-prev, scene1-btn-next, scene1-step-indicator（控件）
  - scene1-conclusion（结论文本）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
