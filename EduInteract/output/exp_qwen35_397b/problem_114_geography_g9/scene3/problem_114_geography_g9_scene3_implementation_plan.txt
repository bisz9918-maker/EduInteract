[图示主题与整合说明]
- 本图示主题：A、B 点经纬度定位与东西半球判断
- 整合的步骤/概念：经线标注、A 点经度读取、B 点经度读取、东西半球划分界线、A 和 B 的半球归属

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于(280,450)，100×35px，点击返回上一状态
  - 「下一步」按钮：位于(420,450)，100×35px，点击进入下一状态
  - 步骤指示：位于(400,490)，显示当前步骤"步骤 X/5"
- 教师操作流程：
  1. 初始展示两图基础结构，引导学生观察自转方向差异
  2. 点击「下一步」讲解经度判读规则（逆东顺西）
  3. 点击「下一步」读出 A、B 具体经度
  4. 点击「下一步」展示东西半球划分标准
  5. 点击「下一步」得出最终判断结论
  6. 可随时点击「上一步」回退复习关键概念

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript。原因：本场景为静态几何图形展示，无需复杂动画或数据可视化，原生 SVG 足够且性能最优
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────┐
  │  [左图]                    [右图]                   │
  │   北极俯视                  南极俯视                │
  │   中心(200,150)            中心(600,150)           │
  │                                                     │
  │           [东西半球划分示意图]                      │
  │   180°←─西半球─20°W───东半球───160°E─→180°        │
  │                                                     │
  │   A(135°E)→东半球          B(45°W)→西半球          │
  │                                                     │
  │         [◀上一步]  [下一步▶]   步骤 X/5            │
  └─────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量(0-4)跟踪当前步骤，steps 数组存储每步需显示的元素 ID 列表
  2. 坐标计算：经线角度 = 基础角度 + i × 45°，A 点角度=135°(逆时针从 0°)，B 点角度=315°(顺时针 45°)
  3. 动画曲线：元素显示使用 opacity 过渡(0→1, 300ms)，无需位移动画
  4. 事件绑定：按钮点击事件绑定到 scene3-prev-btn 和 scene3-next-btn，更新状态后调用 renderStep()
  5. 元素显隐：每步 renderStep() 遍历所有可显隐元素，根据 steps[currentState] 设置 display 属性
- ID 命名规范：所有交互元素 ID 必须以 scene3- 为前缀（如 scene3-left-circle、scene3-point-a、scene3-prev-btn）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
