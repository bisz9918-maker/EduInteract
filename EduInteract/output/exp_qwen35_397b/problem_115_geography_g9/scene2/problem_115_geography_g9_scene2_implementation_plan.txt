[分步序列]
本场景采用滑块连续交互 + 分步展示结合模式：

- 初始状态（步骤 0）：仅显示地球球体（蓝色半透明圆）、经纬线网格、地心（小红点）
- 步骤 1：点击「下一步」→ 显示咸蛋超人家位置（蓝色标记点）及标签 "咸蛋超人 (30°N,120°E)"
- 步骤 2：点击「下一步」→ 显示穿地直线（红色虚线，从咸蛋点穿过地心延伸到球体另一侧）
- 步骤 3：点击「下一步」→ 显示面包超人家位置（红色标记点）及标签 "面包超人 (30°S,60°W)"
- 步骤 4：点击「下一步」→ 显示右侧二维剖面图和坐标计算框，展示对跖点计算公式和结果
- 最终状态：所有元素显示完整，教师可拖动滑块旋转地球（0°-360°），观察两点在球面上的对称关系

[技术实现]
- JS 库选择：原生 SVG（地球球体、标记点、经纬线）+ 原生 Canvas 2D（可选，用于更复杂的三维投影效果）
  选择原因：本场景以球体和标记点为主，原生 SVG 足够实现，且便于控制每个元素的坐标和样式
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |   [地球球体]              [二维剖面图]           |
  |   圆心 (250,250)          圆心 (600,200)         |
  |   半径 140                半径 80                |
  |                                                  |
  |                           [坐标计算框]           |
  |                           (520,300)-(780,420)    |
  |                                                  |
  |                    [旋转滑块]                    |
  |              (200,460)--------(600,480)          |
  |   [上一步]                              [下一步]  |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 三维球体投影：使用 SVG 圆形模拟球体，经纬线用椭圆弧近似（经线为纵向椭圆弧，纬线为横向椭圆弧）
  2. 球面坐标投影：将经纬度 (lat, lon) 转换为球面投影坐标 (x, y)
     - 经度旋转：根据滑块角度 offsetLon = lon + rotationAngle
     - 投影公式：x = cx + R * cos(lat) * sin(offsetLon), y = cy - R * sin(lat) * cos(offsetLon)
  3. 穿地直线：始终连接咸蛋点、地心、面包点三点一线
  4. 状态机：用 stepIndex (0-4) 管理分步状态，每步控制对应元素的 display 属性
  5. 滑块事件：监听 input 事件，实时更新旋转角度和球面点位置
  6. IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局污染
