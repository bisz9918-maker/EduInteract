[图示主题与整合说明]
- 本图示主题：斜经纬网上两点方向判断的完整演示
- 整合的步骤/概念：坐标读取（A 点、B 点经纬度标注）+ 方向参考线绘制 + 相对位置关系展示 + 结论得出
- 教学价值：教师可使用此图示逐步演示如何在斜经纬网上判断两点相对方向。先让学生读取坐标，再建立方向参考系，最后通过箭头直观展示方向关系，符合从已知到未知的认知规律。分步导航支持课堂节奏控制，可随时回退复习。

[分步序列]
- 初始状态（步骤 0）：显示完整斜经纬网、6 条经线、3 条纬线、所有经度纬度标注、A 点红色圆点 (260,200)、B 点红色圆点 (310,120)、指北针。不显示坐标标注、参考线、箭头、结论。
- 步骤 1：点击「下一步」→ A 点高亮（r 从 6 变为 8，添加光晕效果），显示 A 坐标标签 (275,185) "180°, 40°N" #1565c0 淡入。
- 步骤 2：点击「下一步」→ B 点高亮（r 从 6 变为 8，添加光晕效果），显示 B 坐标标签 (325,105) "160°W, 60°N" #1565c0 淡入。A 点恢复原状。
- 步骤 3：点击「下一步」→ 从 B 点 (310,120) 绘制南北向虚线 (310,80)-(310,200) 和东西向虚线 (250,120)-(370,120)，#888888 虚线样式。在虚线端点显示"北"(310,70)、"南"(310,215)、"西"(235,120)、"东"(385,120) 小字标注。
- 步骤 4：点击「下一步」→ 绘制蓝色箭头从 B(310,120) 指向 A(260,200)，箭头旁显示"西南"文本 (270,155) #1565c0。
- 步骤 5：点击「下一步」→ 在右侧 (580,200) 显示结论文本"A 在 B 的西南方向" #2e7d32 加粗 14px，背景可加浅色圆角矩形衬托。

[标签冲突检查]
- 标签"A 坐标"：坐标 (275,185)
- 标签"B 坐标"：坐标 (325,105)
- "A 坐标"与"B 坐标"间距：√[(325-275)²+(105-185)²] = √[2500+6400] ≈ 94px → 无冲突
- 标签"经度 140°E"：坐标 (90,380)
- 标签"经度 160°E"：坐标 (140,380)
- 相邻经度标签间距：50px → 无冲突（≥20px）
- 标签"纬度 20°"：坐标 (480,320)
- 标签"纬度 40°"：坐标 (480,240)
- 相邻纬度标签间距：80px → 无冲突
- 标签"北"：坐标 (310,70)
- 标签"B 坐标"：坐标 (325,105)
- 间距：√[(325-310)²+(105-70)²] = √[225+1225] ≈ 38px → 无冲突
- 标签"西南"：坐标 (270,155)
- 标签"A 坐标"：坐标 (275,185)
- 间距：√[(275-270)²+(185-155)²] = √[25+900] ≈ 30px → 无冲突
- 结论文本 (580,200) 与所有其他元素间距均 > 50px → 无冲突
- 所有标签均放置在图形外侧空白区域，无重叠风险

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 按钮"◀ 上一步"：位置 (320,455)，宽 100px，高 36px，浅灰色背景 #e0e0e0，深灰文字 #424242
  - 按钮"下一步 ▶"：位置 (480,455)，宽 100px，高 36px，蓝色背景 #1565c0，白色文字 #ffffff
  - 步骤指示器：位置 (420,455)，显示"步骤 X/5"，12px 灰色文字
- 教师操作流程：
  1. 初始状态展示原图，让学生观察斜经纬网和 A、B 两点位置
  2. 点击"下一步"高亮 A 点并显示坐标，引导学生读取 A 点经纬度
  3. 点击"下一步"高亮 B 点并显示坐标，引导学生读取 B 点经纬度
  4. 点击"下一步"显示方向参考线，讲解如何建立方向坐标系
  5. 点击"下一步"显示方向箭头，直观展示从 B 到 A 的方向
  6. 点击"下一步"显示结论，总结答案
  7. 可随时点击"上一步"回退复习某个步骤

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript。原因：本图示为 2D 几何图形，无需复杂库；SVG 适合绘制精确坐标的经纬网、点、线、箭头；原生 JS 足够实现分步状态切换。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  [指北针]                           (600,60)     |
  |                                                  |
  |     [斜经纬网主体]                               |
  |     (100,80)-(550,380)                           |
  |     A● B●                                        |
  |                                                  |
  |     [经度标注底部] [纬度标注右侧]                |
  |                                                  |
  |                              [结论文本]          |
  |                              (580,200)           |
  |                                                  |
  |  [◀ 上一步]  步骤 X/5  [下一步 ▶]                |
  |  (320,455)   (420,455)  (480,455)                |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量 (0-5)，每个步骤对应一个状态对象，包含该步骤应显示的元素 ID 列表
  2. 坐标计算：所有元素坐标预先计算好，硬编码在 SVG 中，避免运行时计算误差
  3. 动画曲线：使用 CSS transition 实现淡入效果 (opacity 0→1, 0.3s ease)
  4. 事件绑定：按钮点击事件绑定到 updateStep() 函数，更新 currentStep 并调用 render()
  5. 元素显隐：使用 display="none"/"inline" 或 opacity 控制元素显示
  6. 箭头绘制：使用 SVG <marker> 定义箭头头部，<line> 或 <path> 绘制箭身
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀
  - scene1-grid（经纬网组）
  - scene1-point-a（A 点）
  - scene1-point-b（B 点）
  - scene1-label-a-coord（A 坐标标签）
  - scene1-label-b-coord（B 坐标标签）
  - scene1-ref-line-ns（南北参考线）
  - scene1-ref-line-ew（东西参考线）
  - scene1-arrow-direction（方向箭头）
  - scene1-label-direction（方向文本）
  - scene1-label-conclusion（结论文本）
  - scene1-btn-prev（上一步按钮）
  - scene1-btn-next（下一步按钮）
  - scene1-step-indicator（步骤指示器）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
