    **题目原文：**

    下列选项正确的是（   ）

    A． 甲、乙两地在同一条纬线上

    B． 甲、乙两地在同一条经线上

    C． 甲在乙的西南方

    D． 乙在甲的正东方

    **题目分析：**

    本题考查经纬网定位与方向判断。关键在于：
    1. 正确判读甲、乙两地的经纬度（注意经度、纬度的增减方向）
    2. 理解南北半球、东西经的判断方法
    3. 掌握两地相对方向的判断规则

    **整体讲解思路：**

    1. 先引导学生判读甲地经纬度：左图经度向西增大（西经），纬度向南增大（南纬）→ 甲 (40°W, 30°S)
    2. 再判读乙地经纬度：右图经度向东增大（东经），纬度向北增大（北纬）→ 乙 (40°E, 30°N)
    3. 对比两地坐标，排除 A、B 选项
    4. 用图示展示方向判断：南北方向看纬度，东西方向看经度

    **图示规划说明：**

    - SCENE_1：整合两个经纬网图，标注甲乙坐标，展示经纬度判读方法
    - SCENE_2：展示方向判断的分解过程（南北方向 + 东西方向 → 综合方向）
    </TEXT_1>

    **教学说明：**

    本图示用于引导学生正确判读经纬度。教师应强调：

    1. **经度判读规则：**
       - 经度向西增大 → 西经（W）
       - 经度向东增大 → 东经（E）

    2. **纬度判读规则：**
       - 纬度向南增大 → 南纬（S）
       - 纬度向北增大 → 北纬（N）

    3. **甲地坐标：** 40°W, 30°S（西经 40 度，南纬 30 度）

    4. **乙地坐标：** 40°E, 30°N（东经 40 度，北纬 30 度）

    通过步骤导航，学生可逐步理解经纬度的判读方法，避免直接给出答案。

    <TEXT_3>
    **教学说明：**

    本图示用于讲解两地相对方向的判断方法。教师应强调：

    1. **南北方向判断（看纬度）：**
       - 甲在南纬 30°，乙在北纬 30°
       - 甲在乙的**南方**

    2. **东西方向判断（看经度）：**
       - 甲在西经 40°，乙在东经 40°
       - 两地经度差 = 40° + 40° = 80°（小于 180°）
       - 从乙看甲，甲在乙的**西方**

    3. **综合方向：**
       - 甲在乙的**西南方**

    4. **选项分析：**
       - A 错误：甲 (30°S) 与乙 (30°N) 不在同一条纬线上
       - B 错误：甲 (40°W) 与乙 (40°E) 不在同一条经线上
       - C 正确：甲在乙的西南方
       - D 错误：乙在甲的东北方，不是正东方

    **正确答案：C**
