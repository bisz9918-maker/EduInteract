[图示主题与整合说明]
- 本图示主题：甲乙两地相对方向判断
- 整合内容：南北方向判断、东西方向判断、综合方向推导
- 教学价值：教师可通过分步演示，先让学生分别判断南北方向和东西方向，再综合得出最终结论。这种分解式教学有助于学生理解方向判断的逻辑过程，避免直接给出答案导致的机械记忆。

[分步序列]
- 初始状态（步骤 0）：显示地球轮廓、赤道线、南北半球填充区域、甲点及标签、乙点及标签、赤道标签、北半球标签、南半球标签。方向箭头全部隐藏。
- 步骤 1（点击「下一步」）：显示南北方向箭头（从乙点垂直向下）和"南方"标签。说明：乙在北半球(30°N)，甲在南半球(30°S)，所以甲在乙的南方。
- 步骤 2（点击「下一步」）：保持步骤 1 元素，新增东西方向箭头（沿赤道从西经指向东经）和"东方"标签。说明：甲在西经(40°W)，乙在东经(40°E)，从甲看乙是向东，即乙在甲的东方，反过来甲在乙的西方。
- 步骤 3（点击「下一步」）：保持步骤 1-2 元素，新增综合方向箭头（从乙指向甲的斜向箭头）和"西南方"标签。南北和东西方向箭头变为虚线或降低透明度。结论：甲在乙的西南方，对应选项 C。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于(280,460)，宽 80px，高 36px，浅灰色背景，点击后返回上一状态
  - 「下一步」按钮：位于(440,460)，宽 80px，高 36px，蓝色背景，点击后进入下一状态
  - 状态指示器：位于(380,465)，显示"步骤 X/3"
- 教师操作流程：
  1. 初始状态展示甲乙两地的坐标位置，让学生观察
  2. 点击「下一步」展示南北方向判断，提问学生"甲在乙的哪个南北方向？"
  3. 点击「下一步」展示东西方向判断，提问学生"甲在乙的哪个东西方向？"
  4. 点击「下一步」展示综合结论，引导学生得出"西南方"答案
  5. 可随时点击「上一步」回顾之前的判断步骤

[技术实现]
- JS 库选择及原因：原生 SVG。理由：本场景为 2D 几何示意图，元素数量适中（约 15 个），无需复杂动画库。原生 SVG 轻量、语义清晰、易于控制每个元素的显示/隐藏状态。
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |                    北半球                         |
  |                      乙●                         |
  |                                                  |
  |        赤道 - - - - - - - - - - - - - - - -      |
  |                                                  |
  |                      ●甲                         |
  |                    南半球                         |
  |                                                  |
  |          [◀上一步]  步骤 2/3  [下一步▶]          |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-3），每次点击按钮更新状态并重绘相关元素
  2. 元素分组：将不同步骤的元素放入不同的<g>组，通过 display 属性控制显示/隐藏
  3. 箭头绘制：使用 SVG marker 定义箭头头部，路径使用<path>元素
  4. 坐标计算：甲点(300,300)、乙点(500,140) 根据地球半径和经纬度比例计算得出
  5. 事件绑定：按钮点击事件使用 addEventListener，避免内联 onclick
- ID 命名规范：所有交互元素 ID 必须以 scene2- 为前缀，例如：
  - scene2-earth-circle（地球轮廓）
  - scene2-equator-line（赤道线）
  - scene2-point-jia（甲点）
  - scene2-point-yi（乙点）
  - scene2-arrow-ns（南北方向箭头）
  - scene2-arrow-ew（东西方向箭头）
  - scene2-arrow-final（综合方向箭头）
  - scene2-btn-prev（上一步按钮）
  - scene2-btn-next（下一步按钮）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
