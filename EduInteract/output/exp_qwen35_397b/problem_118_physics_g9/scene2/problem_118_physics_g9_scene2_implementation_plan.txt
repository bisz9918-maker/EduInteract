[视觉元素清单]
- 电路图：使用 SVG 路径绘制，线宽 2px，颜色 #000000
- 电阻 R₁：矩形框，20×60px，位置 (60,150)，边框 #000000
- 变阻器 R₂：矩形框 120×25px + 滑动箭头，位置 (100,80)
- 滑片 P：两个位置对比，初始位置 (180,80) 灰色 #888888，左移后 (130,80) 蓝色 #1565c0
- 电表：圆形 30×30px，V₁(100,50)、V₂(140,320)、A(260,50)
- 变化量箭头：△I 绿色向上 (300,100)，△U₁ 红色向下 (300,150)，△U₂ 标注 (300,200)
- 选项框：4 个矩形框垂直排列，间距 20px，边框 #000000 1px，填充透明度 15%
- 判断标记：绿色✓ #2e7d32 表示正确，红色✗ #c62828 表示错误
- 颜色规格：背景 #ffffff / 电路图 #000000 / 初始状态 #888888 / 变化后 #1565c0 / 增加量 #2e7d32 / 减少量 #c62828

[分步序列]
- 步骤 0（初始状态）：显示完整电路图，标注 R₁、R₂、P、V₁、V₂、A、I、U₁、U₂；滑片 P 显示初始位置（灰色）；右侧选项框显示但内容灰色；推导公式区空白
- 步骤 1（滑片左移）：滑片 P 从 (180,80) 移动到 (130,80)，新位置用蓝色高亮；显示变化量标注：△I 绿色向上箭头、△U₁ 红色向下箭头、△U₂=0；推导公式区显示"I↑, U₁↓, U₂不变"
- 步骤 2（分析选项 A）：选项 A 框高亮，显示公式"U₂/I"，U₂ 不变、I 变大→比值变小；选项 A 标记显示绿色✓；推导公式区显示"U₂不变, I 变大 → U₂/I 变小"
- 步骤 3（分析选项 B）：选项 B 框高亮，显示公式"(U₂-U₁)/I = R₁"，R₁ 为定值电阻；选项 B 标记显示绿色✓；推导公式区显示"U₂-U₁ = U_R₁ = I·R₁ → (U₂-U₁)/I = R₁(定值)"
- 步骤 4（分析选项 C）：选项 C 框高亮，显示公式"△U₁/△I"；推导公式区显示"U₁ = U₂ - I·R₁ → △U₁ = -△I·R₁ → |△U₁/△I| = R₁(定值)"；选项 C 标记显示绿色✓
- 步骤 5（分析选项 D）：选项 D 框高亮；推导公式区显示"△U₂ = 0(电源电压恒定), △U₁ ≠ 0 → △U₁ ≠ △U₂"；选项 D 标记显示红色✗
- 步骤 6（结论）：所有选项标记显示；底部显示"正确选项：A、B、C"；正确选项框用绿色边框高亮，错误选项框用红色边框高亮

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 (280,455)，点击返回上一状态
  - 「下一步」按钮：位于 (420,455)，点击进入下一状态
  - 步骤指示器：显示"步骤 X/6"，位于两按钮之间 (400,455)
- 教师操作流程：
  1. 初始状态展示电路结构，讲解各电表测量对象
  2. 点击「下一步」展示滑片左移，引导学生分析电流电压变化
  3. 依次点击「下一步」分析每个选项，讲解推导过程
  4. 最后展示结论，强调正确选项 A、B、C

[技术实现]
- JS 库选择：原生 SVG（电路图绘制）+ 原生 JavaScript（状态管理），无需额外库
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────┐
  │  [电路图区 x=20~380]     [选项分析区 x=400~780]        │
  │   V₁  ──── P ──── A       ┌─────────────────────┐      │
  │   │       │    │          │ 选项 A: U₂/I       ✓ │      │
  │   R₁      R₂   │          ├─────────────────────┤      │
  │   │       │    │          │ 选项 B: (U₂-U₁)/I  ✓ │      │
  │  ─┴─ S   ─┴─   │          ├─────────────────────┤      │
  │   │            │          │ 选项 C: △U₁/△I    ✓ │      │
  │   V₂           │          ├─────────────────────┤      │
  │                │          │ 选项 D: △U₁=△U₂   ✗ │      │
  │  [变化量标注 x=300]        └─────────────────────┘      │
  │   △I↑  △U₁↓  △U₂=0       [推导公式区]                  │
  │                              │                          │
  │  ────────────────────────────────────────────────────   │
  │         [◀上一步]  步骤 X/6  [下一步▶]                  │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量 (0-6)，steps 数组存储每步的显示配置
  2. 滑片动画：使用 SVG <animate> 或 JS 逐步改变 cx/cy 属性实现平滑移动
  3. 元素显示控制：每步通过 display 属性控制元素可见性
  4. 高亮效果：通过改变 stroke/fill 颜色或添加 CSS class 实现
  5. 事件绑定：按钮点击事件绑定到状态切换函数
- ID 命名规范：所有元素 ID 以 scene2- 为前缀，如 scene2-r1、scene2-r2、scene2-slider-initial、scene2-slider-moved、scene2-option-a、scene2-btn-prev、scene2-btn-next
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
