[分步序列]
- 初始状态（步骤 0）：显示完整原始电路图（电源、开关 S、滑动变阻器、灯泡 L₁ 和 L₂、导线、标签 S、P、L₁、L₂），无高亮，无动画
- 步骤 1：点击「下一步」→ L₁ 支路区域显示蓝色半透明高亮 (100,360)-(420,460)，显示电压标注"U"在电源右侧，显示电流箭头 I₁ 在 L₁ 支路，文字说明"L₁ 支路电压=电源电压 U（不变）"
- 步骤 2：点击「下一步」→ L₂ 支路区域显示绿色半透明高亮 (100,180)-(420,280)，显示滑片 P 向右移动的红色箭头 (200,160)-(240,160)，显示电流箭头 I₂ 在 L₂ 支路，文字说明"滑片 P 右移→L₂ 支路电阻减小→电流 I₂ 增大"
- 步骤 3：点击「下一步」→ 同时显示两条支路高亮，L₂ 灯泡添加黄色发光效果（opacity 脉冲动画 0.6→1.0→0.6 循环），L₁ 灯泡保持原亮度，显示结论文字"L₁ 亮度不变，L₂ 变亮"

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位置 (280,475)，尺寸 100×35px，点击返回上一状态
  - 「下一步 ▶」按钮：位置 (420,475)，尺寸 100×35px，点击进入下一状态
  - 步骤指示器：位置 (390,475)，显示"步骤 X/3"
- 教师操作流程：
  1. 初始展示完整电路图，让学生观察电路结构
  2. 点击「下一步」高亮 L₁ 支路，讲解并联电路各支路电压相等
  3. 点击「下一步」高亮 L₂ 支路并显示滑片移动方向，讲解电阻变化
  4. 点击「下一步」展示最终结论，L₂ 发光动画直观呈现亮度变化

[技术实现]
- JS 库选择及原因：原生 SVG（电路图几何形状简单，SVG 缩放不失真，便于精确控制坐标）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                    电源 U                        |
  |         开关 S                                   |
  |    +----[变阻器 P]----(L₂)----+                  |
  |    |                         |                  |
  |    +---------[导线]----------+                  |
  |    |                         |                  |
  |    +---------[导线]----------+                  |
  |    |                         |                  |
  |    +-----------(L₁)----------+                  |
  |                                                  |
  |                                                  |
  |              [◀ 上一步]  [下一步 ▶]              |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentState(0-3) 跟踪当前步骤，数组存储各状态配置
  2. 坐标计算：所有元件位置硬编码，确保与题目原图布局一致
  3. 动画曲线：L₂ 亮度变化用 CSS transition opacity 0.5s ease-in-out
  4. 事件绑定：按钮点击事件切换状态，更新 SVG 元素 display/opacity 属性
  5. 高亮区域：用<rect>元素 + opacity=0.2 实现半透明填充
- ID 命名规范：所有交互元素 ID 以 scene1- 为前缀（如 scene1-bulb-L1、scene1-bulb-L2、scene1-highlight-L1、scene1-btn-prev、scene1-btn-next）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
