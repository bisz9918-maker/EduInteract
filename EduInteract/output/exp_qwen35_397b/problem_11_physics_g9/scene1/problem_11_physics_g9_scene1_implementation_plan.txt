[分步序列]
- 初始状态（步骤 0）：显示完整电路图，所有元件静态展示，电表指针在初始位置，无高亮
- 步骤 1：高亮滑动变阻器 R（蓝色边框 #1565c0，线宽 3px），显示滑片移动箭头（蓝色向右箭头），标签"滑片右移"在箭头上方 (240,155)
- 步骤 2：滑动变阻器 R 内部填充渐变色（从蓝色 20% 透明度到 0%），表示电阻减小，标签"R↓"在 (220,230) 下方
- 步骤 3：电流表 A 圆圈变为绿色边框 #2e7d32，指针顺时针偏转 15°，电路主路径显示绿色流动箭头（从电源正极经各元件回到负极），标签"I↑"在电流表旁 (180,330)
- 步骤 4：电压表 V 圆圈变为红色边框 #c62828，指针逆时针偏转 10°（示数减小），R 两端显示红色虚线标注，标签"U↓"在电压表旁 (220,230)
- 步骤 5：螺线管 B 显示磁感线（绿色虚线椭圆），上端标"N"在 (550,240) 上方，条形磁铁 A 下方显示向上排斥力箭头（红色），弹簧测力计弹簧缩短（向上移动 5px），标签"F 斥↑"在磁铁右侧 (580,160)，底部显示结论框"电流表示数变大，电压表示数变小"

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于 (320,465)，宽 80px，高 30px，点击返回上一状态
  - 「下一步 ▶」按钮：位于 (420,465)，宽 80px，高 30px，点击进入下一状态
  - 步骤指示器：位于 (400,450)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始状态展示完整电路，让学生识别各元件
  2. 点击「下一步」高亮滑动变阻器，提问"滑片向右移动时，接入电阻如何变化？"
  3. 点击「下一步」显示电阻减小，引导学生分析总电流变化
  4. 点击「下一步」显示电流增大，提问"电压表示数如何变化？"
  5. 点击「下一步」显示电压减小，总结电表示数变化规律
  6. 点击「下一步」显示电磁效应，分析弹簧测力计示数变化

[技术实现]
- JS 库选择：原生 SVG（电路图几何形状简单，SVG 缩放不失真，适合精确坐标控制）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                    弹簧测力计                     |
  |                       [A] S                       |
  |                        | N                        |
  |                    螺线管 [B]                     |
  |                                                   |
  |    [S]──[电源]──┬────[R]────┬──                  |
  |                 │    (V)    │                     |
  |                [R₀]──(A)────┘                     |
  |                                                   |
  |                                                   |
  |              [◀ 上一步] [下一步 ▶]                |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-5) 跟踪当前步骤，每个步骤对应一个 render 函数
  2. 坐标计算：所有元件位置预先定义为常量对象，便于调整
  3. 动画曲线：电表指针偏转用 CSS transition，duration 0.5s，ease-out
  4. 事件绑定：按钮点击事件绑定 stepChange 函数，更新 currentStep 后重绘
  5. 高亮效果：通过修改 stroke 和 stroke-width 实现，用 CSS class 切换
  6. 箭头绘制：用 SVG marker-end 定义箭头样式
  7. 磁感线：用椭圆 path，stroke-dasharray 实现虚线
- ID 命名规范：所有元素 ID 以 scene1- 为前缀，如 scene1-power、scene1-switch、scene1-R0、scene1-R、scene1-V、scene1-A、scene1-coil、scene1-magnet、scene1-spring、scene1-btn-prev、scene1-btn-next
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
