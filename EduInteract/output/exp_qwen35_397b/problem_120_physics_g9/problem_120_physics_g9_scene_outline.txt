    **题目原文：**

    如图所示，电源电压不变，灯的电阻不变，滑动变阻器的滑片 P 在移动过程中，电流表的最小示数为 0.2A，电压表的最大示数为 4V，当滑片 P 滑到中点时，灯 L 的功率达到最大，且灯的最大功率与最小功率之比为 9：4．下列结论正确的是（  ）

    A．电源电压为 10V

    B．灯的电阻为 20Ω

    C．滑动变阻器的最大电阻为 40Ω

    D．电路消耗的最大功率为 1.8W

    **题目分析：**

    本题是串联电路动态分析问题。电路结构：电源、开关 S、灯泡 L、滑动变阻器串联，电流表测总电流，电压表测滑动变阻器两端电压。

    关键条件：
    1. 滑片在最大阻值处时，电流最小（0.2A），电压表示数最大（4V）
    2. 滑片在中点时，灯功率最大
    3. P_max : P_min = 9 : 4

    **整体讲解思路：**

    1. 首先分析电路结构，明确各电表测量对象
    2. 分析滑片移动时电路参数的变化规律
    3. 利用功率比例关系建立方程
    4. 求解电源电压、灯电阻、滑动变阻器最大阻值
    5. 验证各选项

    **图示规划说明：**

    - SCENE_1：电路结构图，展示元件连接关系和电表测量对象
    - SCENE_2：滑片移动过程的动态分析，展示电流、电压随滑片位置的变化
    - SCENE_3：功率比例关系的可视化推导

    **教学说明：**

    本图示用于展示滑片移动时各物理量的变化规律。教师应引导学生观察：

    1. 滑片在最右端（最大阻值）时：电流最小（0.2A），电压表示数最大（4V）
    2. 滑片向左移动时：滑动变阻器阻值减小，总电阻减小，电流增大
    3. 滑片在最左端（零阻值）时：电流最大，电压表示数为 0
    4. 灯功率随电流增大而增大（P = I²R_L）

    **关键推导：**

    设电源电压为 U，灯电阻为 R_L，滑动变阻器最大阻值为 R。

    滑片在最大阻值处：
    - I_min = 0.2A
    - U_V_max = 4V = I_min × R = 0.2 × R
    - 得：R = 20Ω

    滑片在中点时灯功率最大，此时滑动变阻器接入阻值为 R/2。

    <TEXT_4>
    **教学说明：**

    本图示用于展示完整的代数推导过程。教师应引导学生：

    1. 利用功率比例关系建立方程
    2. 理解 P = I²R_L，功率比等于电流平方比
    3. 逐步求解各未知量

    **完整推导：**

    1. 由电压表最大示数：U_V_max = I_min × R = 4V，I_min = 0.2A，得 R = 20Ω

    2. 功率比例关系：P_max / P_min = (I_max² × R_L) / (I_min² × R_L) = I_max² / I_min² = 9/4

    3. 得：I_max / I_min = 3/2，I_max = 1.5 × I_min = 0.3A

    4. 滑片在中点时电流最大：I_max = U / (R_L + R/2) = U / (R_L + 10)

    5. 滑片在最大阻值处：I_min = U / (R_L + R) = U / (R_L + 20) = 0.2A

    6. 联立：U / (R_L + 10) = 0.3，U / (R_L + 20) = 0.2

    7. 解得：R_L = 10Ω，U = 6V

    8. 验证选项：
       - A：电源电压 10V ❌（实际 6V）
       - B：灯电阻 20Ω ❌（实际 10Ω）
       - C：滑动变阻器最大电阻 40Ω ❌（实际 20Ω）
       - D：电路最大功率 P_max = U × I_max = 6 × 0.3 = 1.8W ✓

    **正确答案：D**
