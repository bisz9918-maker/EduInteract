[分步序列]
本场景为连续拖拽交互，无分步导航，定义3个关键状态供教师参考：

- 初始状态（滑片在最右端，R=R_max）：
  - 滑片P位于(240,265)
  - 电流表示数 I=0.2A（最小值）
  - 电压表示数 U_V=4V（最大值）
  - 灯功率 P_L=P_min
  - I-R曲线显示完整，当前点在最右端
  - U-R曲线显示完整，当前点在最右端（最高点）
  - P-R曲线显示完整，当前点在最右端（较低点）
  - 实时数值：I=0.2A, U_V=4V, P_L=待计算

- 状态1（滑片在中点，R=R_max/2）：
  - 滑片P位于(150,265)
  - 电流表示数 I=I_mid（中间值）
  - 电压表示数 U_V=U_mid（中间值）
  - 灯功率 P_L=P_max（最大值，9:4中的9）
  - 三曲线当前点均在中点x=550处
  - P-R曲线峰值点高亮显示（黑色实心圆）
  - 实时数值：I=?, U_V=?, P_L=P_max

- 状态2（滑片在最左端，R=0）：
  - 滑片P位于(60,265)
  - 电流表示数 I=I_max（最大值）
  - 电压表示数 U_V=0V（最小值）
  - 灯功率 P_L=0（无电流通过变阻器）
  - 三曲线当前点均在最左端x=360处
  - 实时数值：I=I_max, U_V=0V, P_L=0

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：
  - 滑片拖拽条：位于底部y=420，x从100到700，对应变阻器阻值从0到R_max
  - 滑片手柄：20×30px蓝色矩形，可左右拖拽
  - 实时数值显示：位于(400,450)，格式"I=0.XXA | U_V=X.XV | P_L=X.XW"
- 教师操作流程：
  1. 初始状态滑片在最右端，讲解"此时变阻器阻值最大，电流最小0.2A，电压表示数最大4V"
  2. 拖拽滑片向左移动，观察三曲线实时变化，强调"电流增大、电压减小"
  3. 拖至中点位置，讲解"此时灯功率达到最大值，题目给出P_max:P_min=9:4"
  4. 继续拖至最左端，讲解"此时变阻器阻值为0，电压表示数为0"
  5. 可反复拖拽，让学生观察变化规律，理解极值条件

[技术实现]
- JS库选择：原生SVG + 原生JavaScript
  - 原因：电路图几何简单，SVG矢量图清晰；拖拽交互用原生JS足够；无需复杂图表库
- 画布尺寸：800×500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  | [电路图区 300×300]  | [I-R图  380×60]            |
  |  电源 开关 灯泡     | [U-R图  380×60]            |
  |  电流表 电压表      | [P-R图  380×60]            |
  |  滑动变阻器+滑片P   |                            |
  +--------------------------------------------------+
  | [滑片拖拽条 =====================●========]      |
  | [实时数值: I=0.XXA | U_V=X.XV | P_L=X.XW]        |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用单个变量 sliderPosition (0-1) 表示滑片位置，0=最左端(R=0)，1=最右端(R=R_max)
  2. 坐标计算：
     - 滑片x坐标 = 60 + sliderPosition × 180（电路图区）
     - 拖拽手柄x坐标 = 100 + sliderPosition × 600（底部拖拽条）
     - 曲线当前点x坐标 = 360 + sliderPosition × 380（三图共用）
  3. 物理量计算（根据题目条件推导）：
     - 设电源电压U，灯电阻R_L，变阻器最大阻值R_max
     - 最右端：I_min=0.2A, U_V_max=4V → R_max = U_V_max / I_min = 4/0.2 = 20Ω（需验证）
     - 中点时P_L最大，P_max:P_min=9:4
     - 实际计算需在JS中实现公式
  4. 动画曲线：拖拽时实时更新，无需过渡动画（即时响应）
  5. 事件绑定：
     - mousedown/touchstart：开始拖拽
     - mousemove/touchmove：更新滑片位置
     - mouseup/touchend：结束拖拽
  6. 曲线绘制：用SVG <path> 元素，d属性用二次贝塞尔曲线或折线近似
- ID命名规范：
  - 所有元素ID以 scene2- 为前缀
  - 示例：scene2-slider-handle, scene2-circuit-diagram, scene2-ir-curve, scene2-ur-curve, scene2-pr-curve, scene2-realtime-display
- IIFE隔离：所有JS代码包在 (function() { ... })() 中，避免全局变量污染
- 配色规格（沿用scene_outline）：
  - 背景：#ffffff
  - 电路图：#000000 实线
  - 电流曲线：#1565c0 实线
  - 电压曲线：#c62828 实线
  - 功率曲线：#2e7d32 实线
  - 极值点标记：#000000 实心圆
  - 滑片指示器：#1565c0 填充30%
  - 坐标轴：#888888
