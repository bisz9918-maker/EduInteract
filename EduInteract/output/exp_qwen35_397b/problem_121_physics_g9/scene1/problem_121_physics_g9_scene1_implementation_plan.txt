  5. 可随时点击「上一步」回退复习关键步骤

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库）+ 原生 JavaScript（状态管理）
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [图示区 800×440]
  ├─ 顶部空白区 (y=0~200)
  ├─ 物块区 (y=230~290)：六个矩形水平排列
  ├─ 外力箭头区 (y=260)：左侧 F 箭头
  ├─ 摩擦力箭头区 (y=290~310)：物块底部
  ├─ 标签区 (y=235~325)：各类数值标签
  └─ 结论区 (y=360~410)：步骤 3 显示
  [控件栏 y=440~500]
  ├─ 步骤指示 (400,445)
  ├─ 上一步按钮 (280,460)
  └─ 下一步按钮 (440,460)
  ```
- 关键实现要点：
  1. 状态机设计：用 currentStep 变量(0-3)跟踪当前步骤，steps 数组存储每步显示的元素 ID 列表
  2. 坐标计算：物块位置用基准坐标 + 偏移量计算，确保对齐
  3. 动画曲线：元素显示/隐藏用 CSS transition: opacity 0.3s ease
  4. 事件绑定：按钮点击事件切换步骤，更新元素可见性和按钮状态
  5. 元素分组：按步骤将元素分组（step0-elements, step1-elements 等），便于批量显示/隐藏
- ID 命名规范：所有元素 ID 以 scene1- 为前缀
  · scene1-block-1 ~ scene1-block-6（物块）
  · scene1-surface（水平面）
  · scene1-force-f（外力箭头）
  · scene1-label-f（F=6N 标签）
  · scene1-friction-1 ~ scene1-friction-6（摩擦力箭头）
  · scene1-label-f1（f=1N 标签）
  · scene1-highlight（高亮区域）
  · scene1-label-ftotal（f_total=3N 标签）
  · scene1-pressure（压力箭头）
  · scene1-label-n34（N_34=3N 标签）
  · scene1-conclusion-box（结论框）
  · scene1-label-conclusion（结论文字）
  · scene1-btn-prev（上一步按钮）
  · scene1-btn-next（下一步按钮）
  · scene1-step-indicator（步骤指示）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
- CDN 引入：无需额外库，纯原生实现
