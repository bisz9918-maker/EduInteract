[图示主题与整合说明]
- 本图示主题：电磁铁与永磁体磁极判断的综合分析

[分步序列]
- 初始状态（步骤 0）：显示原始题目图
  - 电磁铁甲（铁芯 + 线圈 + 电源 + 开关）
  - 永磁体乙
  - 磁感线（b、c 之间向外发散）
  - 端点标签 a、b、c、d
  - 等待教师触发交互

- 步骤 1：显示电流方向
  - 高亮电源正负极（+ 极红色，- 极蓝色）
  - 显示红色电流箭头沿线圈绕向（从电源正极出发，经开关，流入线圈右端，从左端流出回负极）
  - 新增元素：电源 + 极标注、电源 - 极标注、电流箭头 1、电流箭头 2

- 步骤 2：应用安培定则判断电磁铁磁极
  - 显示右手螺旋定则示意图（电磁铁下方）
  - 右手握管姿势，四指指向电流方向，大拇指指向 b 端
  - 标注 b 端为 N 极（红色 N，坐标 395,170）
  - 标注 a 端为 S 极（蓝色 S，坐标 105,170）
  - 新增元素：右手示意图、右手大拇指、N 极标注 b、S 极标注 a

- 步骤 3：分析磁感线特征判断永磁体磁极
  - 高亮 b、c 之间的磁感线（加粗或变色）
  - 磁感线箭头清晰显示从 b、c 两端向外发散
  - 显示"磁感线"标签和"同名磁极相互排斥"说明文字
  - 新增元素：磁感线标签、排斥说明

- 步骤 4：显示完整结论
  - 标注 c 端为 N 极（红色 N，坐标 505,170）
  - 标注 d 端为 S 极（蓝色 S，坐标 735,170）
  - 显示结论文字："a(S 极)、b(N 极)、c(N 极)、d(S 极)"
  - 高亮选项 C："C、b、c 两端都是 N 极"（绿色背景）
  - 新增元素：N 极标注 c、S 极标注 d、结论文字、选项 C 高亮

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于 SVG 内底部左侧 (280,455)，点击返回上一状态
  - 「下一步 ▶」按钮：位于 SVG 内底部右侧 (420,455)，点击进入下一状态
  - 步骤指示器：显示当前步骤/总步骤数（如"步骤 2/4"）
- 教师操作流程：
  1. 加载图示后显示原始题目图（步骤 0），教师引导学生观察电磁铁和永磁体的基本结构
  2. 点击「下一步」显示电流方向（步骤 1），教师讲解电源极性与电流流向的关系
  3. 点击「下一步」显示安培定则（步骤 2），教师演示右手螺旋定则判断电磁铁磁极
  4. 点击「下一步」高亮磁感线（步骤 3），教师分析磁感线发散特征说明同名磁极排斥
  5. 点击「下一步」显示完整结论（步骤 4），教师总结并高亮正确选项 C
  6. 如需复习，可随时点击「上一步」回退到之前步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（矩形、路径、文本），无需复杂库；原生 SVG 便于精确控制坐标和样式；代码轻量，加载快
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |   a [电磁铁甲========] b    c [永磁体乙====] d   |
  |      (线圈绕制)        \  /                      |
  |                         \/ 磁感线                |
  |                                                  |
  |              [右手示意图]                        |
  |                                                  |
  |         [电源]---[开关]---[线圈]                 |
  |                                                  |
  |              [结论文字区]                        |
  |                                                  |
  |        [◀ 上一步]          [下一步 ▶]            |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-4），每个状态对应一组可见元素
  2. 元素分组：将相关元素放入 <g> 组，通过 display 属性控制显示/隐藏
     - scene1-step0: 基础图（始终显示）
     - scene1-step1: 电流方向元素
     - scene1-step2: 安培定则元素
     - scene1-step3: 磁感线高亮元素
     - scene1-step4: 结论元素
  3. 坐标计算：所有元素使用绝对坐标，确保跨浏览器一致性
  4. 动画曲线：步骤切换使用 CSS transition，opacity 从 0 到 1，duration 300ms
  5. 事件绑定：按钮点击事件绑定到 updateState() 函数，更新 currentState 并刷新显示
  6. 边界检查：第一步禁用「上一步」，最后一步禁用「下一步」
- ID 命名规范：
  - 所有元素 ID 以 scene1- 为前缀
  - 示例：scene1-iron-core（铁芯）、scene1-coil（线圈）、scene1-magnet（永磁体）
  - 步骤组：scene1-step0、scene1-step1、...、scene1-step4
  - 按钮：scene1-btn-prev、scene1-btn-next
  - 标签：scene1-label-a、scene1-label-b、scene1-label-c、scene1-label-d
  - 磁极标注：scene1-pole-a、scene1-pole-b、scene1-pole-c、scene1-pole-d
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
- CDN 引入：无需外部库，纯原生实现
