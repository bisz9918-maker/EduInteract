[图示主题与整合说明]
- 本图示主题：物距变化对像距和像大小的影响规律
- 整合内容：蜡烛从远处向透镜移动过程中，像距变化、像大小变化、成像性质变化的连续演示
- 教学价值：教师可通过拖动滑块实时展示物距 u 变化时，像距 v 和放大率 m 的连续变化规律，帮助学生建立"物近像远像变大"的动态认知，理解凸透镜成像公式 v=uf/(u-f) 的物理意义

[分步序列]
本场景为连续拖拽交互，无分步导航，状态由滑块位置实时决定：

- 初始状态（u=2.5f）：
  - 蜡烛位于 x=200（距透镜 200px，即 u=2.5f）
  - 像距 v=uf/(u-f)=2.5f×f/(2.5f-f)=2.5f/1.5≈1.67f≈133px
  - 光屏位于 x=400+133=533
  - 放大率 m=v/u≈0.67，像高≈27px（缩小）
  - 成像性质：倒立缩小实像
  - 数值显示：u=2.5f, v≈1.67f, m≈0.67

- 拖动过程状态变化：
  - u>2f：倒立缩小实像，v<2f，像比物小
  - u=2f：倒立等大实像，v=2f，像物等大（m=1）
  - f<u<2f：倒立放大实像，v>2f，像比物大
  - u=f：不成像（平行光），显示提示"u=f 时不成像"
  - u<f：正立放大虚像，光屏上无像，虚像在蜡烛同侧

- 关键位置标记：
  - u=2f 时：高亮显示"倒立等大实像"，m=1
  - u=f 时：显示警告提示，像距趋于无穷
  - u<f 时：光屏消失，显示蓝色虚线虚像

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：
  - 物距调节滑块：位于底部 y=460，范围 x=100~700，对应用距 u 从 4f 到 1.1f
  - 滑块刻度：标记 f、2f、3f 位置，用短竖线和文字标注
  - 数值显示区：实时显示 u/f 比值、v/f 比值、放大率 m
  - 成像性质提示：实时显示当前成像类型（倒立缩小实像/倒立等大实像/倒立放大实像/正立放大虚像）
- 教师操作流程：
  1. 初始状态展示 u>2f 时的成像情况
  2. 缓慢向右拖动滑块（减小物距），观察像距增大、像变大的过程
  3. 停在 u=2f 位置，强调"倒立等大实像"
  4. 继续拖动到 f<u<2f，观察"倒立放大实像"
  5. 拖动到 u=f 附近，展示像距趋于无穷
  6. 拖动到 u<f，展示虚像（光屏上无像）

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单，无需复杂库；拖拽交互用原生事件即可实现
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |                    蜡烛        凸透镜      光屏   |
  |                     |           ||        |      |
  |                     |           ||        |      |
  |         2F    F     |     O     F    2F   |      |
  |---------●----●------|-----●-----●----●----|------| 主光轴 y=300
  |                     |           ||        |      |
  |              u←→    |    ←→v    |        |      |
  |                                                  |
  |  [数值显示]                              [成像性质]|
  |  u=2.5f                                  倒立缩小 |
  |  v=1.67f                                 实像    |
  |  m=0.67                                     |
  |                                                  |
  |  [滑块轨道━━━━━━━━━━━━━━━━●━━━━━━━━━━━━━━━━]      |
  |         3f   2f   f              透镜位置         |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：单一状态对象 { u: number, f: 80 }，所有元素位置由 u 计算得出
  2. 坐标计算：
     - 蜡烛 x = 400 - u（透镜在 x=400）
     - 像距 v = u*f/(u-f)（当 u>f 时）
     - 光屏 x = 400 + v（实像在右侧）
     - 放大率 m = v/u，像高 = 40 * |m|
  3. 虚像处理：u<f 时，v 为负值，虚像在左侧 x=400+v，用蓝色虚线绘制
  4. 动画曲线：拖拽时实时更新，无需过渡动画
  5. 事件绑定：mousedown/mousemove/mouseup 实现拖拽，touch 事件支持移动端
  6. 边界限制：u 最小 1.1f（避免除零），最大 4f
