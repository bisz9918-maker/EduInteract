[图示主题与整合说明]
- 本图示主题：凸透镜三种成像应用对比（照相机/投影仪/放大镜）
- 整合内容：照相机、投影仪、放大镜三种光学仪器的成像条件对比，包括物距范围、像距范围、像的性质（正倒/大小/虚实）、典型应用场景
- 教学价值：教师可通过切换三种状态，直观对比不同成像条件的差异，帮助学生理解物距变化如何影响成像性质，建立光学仪器与成像规律的对应关系

[视觉元素清单]
- 主光轴：黑色实线 #000000，线宽3px，从(80,280)到(720,280)
- 凸透镜：黑色轮廓 #000000，无填充，椭圆30×120px，中心(400,280)
- 焦点标记：黑色实心圆点4px，F标签位于点下方15px
- 2F标记：黑色实心圆点4px，2F标签位于点下方15px
- 物体(蜡烛)：橙色火焰#ff9800，白色烛身#f5f5f5，状态相关位置
- 实像：红色箭头#c62828，实线，状态相关位置
- 虚像：蓝色箭头#1565c0，虚线，状态相关位置
- 光路光线：实线表示实际光线，虚线表示反向延长线
- 应用图标：简笔画风格，颜色随状态变化
- 参数表格：边框#888888，背景透明度20%
- 按钮：未选中#e0e0e0深灰文字，选中#1565c0白文字

[分步序列]
状态1（照相机）：
- 物体位置：x=180（u>2F区域），蜡烛图标
- 像位置：x=520（F与2F之间），倒立缩小红色实像箭头
- 物距标注：u>2f，位于(250,260)
- 像距标注：f<v<2f，位于(450,260)
- 应用图标：照相机简笔画，蓝色#1565c0
- 参数表格：物距u>2f | 像距f<v<2f | 倒立缩小实像 | 应用：照相机

状态2（投影仪）：
- 物体位置：x=350（F与2F之间），蜡烛/胶片图标
- 像位置：x=620（2F之外），倒立放大红色实像箭头
- 物距标注：f<u<2f，位于(370,260)
- 像距标注：v>2f，位于(550,260)
- 应用图标：投影仪简笔画，绿色#2e7d32
- 参数表格：物距f<u<2f | 像距v>2f | 倒立放大实像 | 应用：投影仪

状态3（放大镜）：
- 物体位置：x=370（F之内），蜡烛图标
- 像位置：x=300（物体左侧，同侧），正立放大蓝色虚像箭头（虚线）
- 物距标注：u<f，位于(380,260)
- 像距标注：v>u，位于(330,240)
- 光路：虚线反向延长线
- 应用图标：放大镜简笔画，红色#c62828
- 参数表格：物距u<f | 像距v>u | 正立放大虚像 | 应用：放大镜

- 三种状态互斥显示，同一时间标签不重叠 → 无冲突

[交互方案]
- 交互类型：多状态切换（3个按钮）
- 控件说明：
  - 「照相机」按钮：位置(200,450)，点击显示照相机成像状态
  - 「投影仪」按钮：位置(350,450)，点击显示投影仪成像状态
  - 「放大镜」按钮：位置(500,450)，点击显示放大镜成像状态
- 教师操作流程：
  1. 初始默认显示照相机状态
  2. 点击「投影仪」按钮，对比物距变小后像的变化
  3. 点击「放大镜」按钮，展示虚像成像特点
  4. 可反复切换，引导学生总结规律

[技术实现]
- JS 库选择：原生 SVG（几何图形简单，无需复杂库）
- 画布尺寸：800×500 px
- 布局草图：
  ```
  [图示区 800×500]
  +------------------------------------------+
  |  [应用图标] 照相机/投影仪/放大镜          | y=60-130
  |  +------------------------------------+  | y=160-240
  |  | 参数表格：物距|像距|像性质|应用    |  |
  |  +------------------------------------+  |
  |                                          |
  |     蜡烛    2F   F   透镜   F   2F  光屏 | y=280 主光轴
  |                                          |
  |                                          |
  |  [照相机]  [投影仪]  [放大镜]            | y=450-485 按钮区
  +------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机：用变量currentState存储当前状态(0/1/2)
  2. 所有交互元素ID以scene3-为前缀（如scene3-camera-btn）
  3. 用IIFE包裹所有JS代码，避免全局污染
  4. 切换状态时：隐藏所有状态元素→显示当前状态元素→更新按钮样式
  5. 光路光线用<path>绘制，实像用实线，虚像用虚线+蓝色
  6. 按钮点击事件绑定，切换时更新fill和text颜色
- ID 命名规范：
  - 按钮：scene3-btn-camera, scene3-btn-projector, scene3-btn-magnifier
  - 主光轴：scene3-optical-axis
  - 凸透镜：scene3-lens
  - 焦点：scene3-focal-left, scene3-focal-right
  - 物体：scene3-object
  - 像：scene3-image
  - 光路：scene3-light-ray-1, scene3-light-ray-2
  - 应用图标：scene3-app-icon
  - 参数表格：scene3-param-table
  - 标注文字：scene3-label-u, scene3-label-v
