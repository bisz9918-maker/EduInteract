problem_126_physics_g9

场景导航：Scene 1 | Scene 2

题目原文：

如图所示，在拉力F作用下，物体A在水平桌面上以速度υ向右匀速运动了距离S，已知A的重力为G，桌面对A的摩擦力为f（滑轮及绳重不计）．则下列说法不正确的是（ ）

A、有用功为GS B、拉力做功为3FS C、拉力做功的功率为3Fυ D、装置的机械效率为$\frac{f}{3F}$

题目分析：

本题考查滑轮组在水平方向拉动物体时的功、功率和机械效率计算。关键点：

  1. 物体水平运动，有用功是克服摩擦力做功，不是克服重力做功
  2. 滑轮组有3段绳子承担拉力，绳端移动距离是物体移动距离的3倍
  3. 功率计算需用绳端速度和拉力
  4. 机械效率 = 有用功 / 总功

整体讲解思路：

首先展示滑轮组结构，明确绳子段数n=3；然后分析有用功和总功的区别；最后推导功率和机械效率公式。

图示规划说明：

设计2个图示：

  • SCENE_1：滑轮组结构与力的关系（展示n=3的绳子段数、拉力F与摩擦力f的关系）
  • SCENE_2：功与效率的计算关系（对比有用功、总功，推导机械效率）

教学说明：

本图示帮助学生理解滑轮组的基本结构和运动关系。

讲解要点：

  1. 引导学生数出承担拉力的绳子段数n=3（动滑轮上的绳子段数）
  2. 强调绳端移动距离是物体移动距离的n倍：$s_{绳} = nS = 3S$
  3. 同理，绳端速度是物体速度的n倍：$v_{绳} = nυ = 3υ$
  4. 物体匀速运动，水平方向受力平衡：拉力（滑轮组对物体的拉力）= 摩擦力f

关键公式：

  • 绳子段数：n = 3
  • 距离关系：$s_{绳端} = 3S$
  • 速度关系：$v_{绳端} = 3υ$

教学说明：

本图示聚焦于功、功率和机械效率的计算，帮助学生辨析各选项的正误。

讲解要点：

  1. 有用功的辨析（关键易错点）
  • 水平拉动物体时，有用功是克服摩擦力做功，不是克服重力做功
  • 正确：$W_{有用} = fS$
  • 错误：$W_{有用} = GS$（重力方向与运动方向垂直，重力不做功）
  1. 总功计算
  • 拉力F作用点移动距离为3S
  • $W_{总} = F \cdot 3S = 3FS$
  1. 功率计算
  • $P = \frac{W}{t} = F \cdot v_{绳端} = F \cdot 3υ = 3Fυ$
  1. 机械效率
  • $\eta = \frac{W_{有用}}{W_{总}} = \frac{fS}{3FS} = \frac{f}{3F}$

完整解答：

选项A错误（有用功应为fS，不是GS），故选A。

课堂讲解建议：

  • 先让学生独立判断各选项，再逐步揭示推导过程
  • 强调"水平运动时重力不做功"这一关键点
  • 对比竖直提升和水平拉动两种情境下有用功的区别
