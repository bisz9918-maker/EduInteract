[分步序列]
- 初始状态（步骤0）：显示完整滑轮组系统基础结构
  - 显示：桌面、物体A、标签A、动滑轮组（2轮）、定滑轮、墙面、绳子路径（黑色）、拉力F箭头、标签F
  - 隐藏：摩擦力f、距离标注S/3S、速度标注υ/3υ、3段绳高亮、n=3标签

- 步骤1：高亮显示3段承担拉力的绳子
  - 显示：3段绳高亮（蓝色#1565c0）、n=3标签（蓝色#1565c0）
  - 保持：步骤0所有元素
  - 视觉变化：绳子路径上叠加蓝色高亮，动滑轮组下方显示"n=3"

- 步骤2：标注物体移动距离S与绳端移动距离3S的关系
  - 显示：距离S标注（绿色双箭头）、标签S、距离3S标注（绿色双箭头）、标签3S
  - 保持：步骤1所有元素
  - 视觉变化：物体A下方显示移动距离S，绳端区域显示3S

- 步骤3：标注物体速度υ与绳端速度3υ的关系
  - 显示：速度υ标注（绿色虚线箭头）、标签υ、速度3υ标注（绿色虚线箭头）、标签3υ
  - 保持：步骤2所有元素
  - 视觉变化：物体A上方显示速度υ，绳端上方显示3υ

- 步骤4：显示拉力F与摩擦力f的平衡关系（匀速运动）
  - 显示：摩擦力f箭头（红色）、标签f
  - 保持：步骤3所有元素
  - 视觉变化：物体A左侧显示摩擦力f箭头，强调匀速运动时力的平衡

- 最终状态（步骤4）：展示所有结论
  - 所有元素显示完整，教师可总结：n=3，s_绳=3s_物，v_绳=3v_物，F=f/3（理想情况）

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于控件栏左侧，点击返回上一状态（步骤0时禁用）
  - 「下一步」按钮：位于控件栏右侧，点击进入下一状态（步骤4时禁用）
  - 步骤指示器：显示当前步骤编号（如"步骤 1/4"）
- 教师操作流程：
  1. 初始加载显示滑轮组基础结构，教师介绍整体 setup
  2. 点击「下一步」高亮3段绳子，讲解如何数绳子段数n=3
  3. 点击「下一步」显示距离关系，讲解s_绳=ns_物
  4. 点击「下一步」显示速度关系，讲解v_绳=nv_物
  5. 点击「下一步」显示摩擦力，讲解匀速运动时力的平衡
  6. 教师可随时点击「上一步」回退复习关键概念

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（圆、线段、矩形、箭头），无需复杂库；原生 SVG 便于精确控制坐标和样式；代码轻量易维护
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +----------------------------------------------------------+
  |  υ                          3υ                           |
  |                                                          |
  |     F                                                    |
  |                                                          |
  |  +---+                              ___                   |
  |  | A |-----(动滑轮)-----(定滑轮)---|   | 墙              |
  |  +---+     (__) (__)      (__)     |___|                 |
  |     f                                                      |
  |                                                          |
  |  ←S→              ←-----3S-----→                          |
  |                                                          |
  |                    n=3                                   |
  |                                                          |
  |            [◀ 上一步]  步骤 1/4  [下一步 ▶]               |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-4），数组存储每步需显示的元素ID列表
  2. 坐标计算：所有元素坐标硬编码，确保与布局表一致
  3. 动画曲线：元素显示使用淡入效果（opacity 0→1，300ms ease-out）
  4. 事件绑定：按钮点击事件绑定到 updateState() 函数，更新显示元素并禁用边界按钮
  5. 绳子路径：使用 SVG <path> 元素，d 属性精确描述绕法
  6. 箭头绘制：使用 SVG <marker> 定义箭头头部，复用于各箭头元素
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀
  - 示例：scene1-objectA, scene1-pulley-moving-left, scene1-rope-highlight, scene1-label-F, scene1-btn-prev, scene1-btn-next
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
- 控件栏实现：使用 SVG <g> 元素包裹按钮，position: absolute 定位到 y=450 区域，不额外撑高容器
