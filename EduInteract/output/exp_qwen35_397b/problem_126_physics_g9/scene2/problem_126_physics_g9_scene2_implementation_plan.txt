[图示主题与整合说明]
- 本图示主题：功、功率与机械效率的计算关系（滑轮组水平拉动物体）
- 整合的内容：有用功定义、总功计算、功率公式、机械效率推导、选项正误判断
- 教学价值：教师可逐步展示各物理量的推导过程，对比有用功与总功的区别，帮助学生理解机械效率的本质。通过分步动画，学生能清晰看到为什么有用功是 fS 而非 GS（水平运动克服的是摩擦力而非重力）。

[分步序列]
步骤 0（初始状态）：
- 显示：力学示意图（物体 A、地面、滑轮组、绳子、拉力 F、摩擦力 f）
- 公式区显示：标题"有用功" + 公式 W_有用 = fS（蓝色）
- 选项区：空白（等待后续步骤显示判断）
- 控件：上一步（禁用）、下一步（启用）

步骤 1（点击下一步）：
- 视觉变化：公式区新增"总功"标题 + W_总 = F·3S = 3FS（蓝色）
- 选项区显示：A 选项 "有用功为 GS" + 红色×标记
- 高亮：摩擦力 f 箭头闪烁 2 次强调
- 控件：上一步（启用）、下一步（启用）

步骤 2（点击下一步）：
- 视觉变化：公式区新增"功率"标题 + P = F·v_绳端 = F·3υ = 3Fυ（蓝色）
- 选项区显示：B 选项 "拉力做功为 3FS" + 绿色✓标记
- 高亮：拉力 F 箭头闪烁 2 次强调
- 控件：上一步（启用）、下一步（启用）

步骤 3（点击下一步）：
- 视觉变化：公式区新增"机械效率"标题 + η = W_有用/W_总 = fS/(3FS) = f/(3F)（蓝色）
- 选项区显示：C 选项 "拉力做功的功率为 3Fυ" + 绿色✓标记
- 高亮：公式 η 表达式放大 1.1 倍后恢复
- 控件：上一步（启用）、下一步（启用）

步骤 4（点击下一步）：
- 视觉变化：选项区显示：D 选项 "机械效率为 f/(3F)" + 绿色✓标记
- 高亮：D 选项背景短暂高亮 #e8f5e9
- 控件：上一步（启用）、下一步（启用）

步骤 5（最终步骤）：
- 视觉变化：公式区底部显示"本题答案：A"（红色加粗）

- 控件：上一步（启用）、下一步（禁用）

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单，无需复杂库；原生 SVG 便于精确控制坐标和动画
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |  [力学示意图]           [公式推导区]             |
  |   物体 A → 滑轮组        W_有用 = fS              |
  |   摩擦力 f ←            W_总 = 3FS               |
  |   拉力 F →              P = 3Fυ                  |
  |                          η = f/(3F)              |
  |                          选项判断区               |
  |                                                  |
  |  [控件栏]                                        |
  |     [◀上一步]  步骤 X/5  [下一步▶]               |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用 currentStep 变量（0-5）跟踪当前步骤，steps 数组存储每步的显示配置
  2. 坐标计算：所有元素使用绝对坐标，滑轮组绳子路径用 polyline 精确绘制
  3. 动画曲线：使用 CSS transition 实现平滑过渡（opacity、transform）
  4. 事件绑定：按钮点击事件绑定到 updateStep() 函数，更新 DOM 元素显示状态
  5. 禁用状态：首步禁用上一步，末步禁用下一步（opacity:0.5, pointer-events:none）
- ID 命名规范：
  - 所有元素 ID 以 scene2- 为前缀
  - 示例：scene2-object-a, scene2-friction-f, scene2-force-f, scene2-formula-useful, scene2-btn-prev, scene2-btn-next
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
- 状态管理：
  ```javascript
  const state = {
    currentStep: 0,
    totalSteps: 5,
    elements: {
      usefulWork: null,
      totalWork: null,
      power: null,
      efficiency: null,
      optionA: null,
      optionB: null,
      optionC: null,
      optionD: null
    }
  };
  ```
