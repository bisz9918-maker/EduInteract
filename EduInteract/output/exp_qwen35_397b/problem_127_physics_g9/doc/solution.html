problem_127_physics_g9

场景导航：Scene 1 | Scene 2

题目原文：

让一束光斜射入一块玻璃砖，这束光射入和射出玻璃后的的光路正确的是（）

题目分析：

本题考查光的折射规律，具体涉及：

  1. 光从空气斜射入玻璃（光疏→光密介质）时的折射规律
  2. 光从玻璃斜射入空气（光密→光疏介质）时的折射规律
  3. 平行玻璃砖对光线的作用特点

核心知识点：

  • 光从空气斜射入玻璃：折射角 < 入射角，光线向法线偏折
  • 光从玻璃斜射入空气：折射角 > 入射角，光线远离法线偏折
  • 平行玻璃砖：出射光线与入射光线平行，但产生侧移

图示规划说明：
设计 2 个图示：

  1. 光的折射规律动态演示（展示入射角变化时折射角的变化关系）
  2. 四个选项对比分析（高亮正确选项，标注错误选项的问题所在）

教学说明：

本图示用于帮助学生建立光的折射的直观认识。

引导步骤：

  1. 首先让学生观察初始状态（入射角 30°），提问：光线进入玻璃后向哪个方向偏折？
  2. 拖动滑块减小入射角，引导学生发现：入射角越小，折射角也越小，但折射角始终小于入射角
  3. 拖动滑块增大入射角，引导学生发现：入射角增大时，折射角也增大，但折射角始终小于入射角
  4. 让学生观察出射光线与入射光线的关系，发现：出射光线与入射光线平行

关键公式：
根据斯涅尔定律（折射定律）：

n₁·sin(θ₁) = n₂·sin(θ₂)

其中 n₁ 为空气折射率（≈1），n₂ 为玻璃折射率（≈1.5），θ₁ 为入射角，θ₂ 为折射角。

由于 n₂ > n₁，所以 sin(θ₂) < sin(θ₁)，即 θ₂ < θ₁。

步骤 0/4

教学说明：

本图示用于系统分析四个选项，帮助学生理解每个选项的正误原因。

各选项分析：

A 选项（正确）：

  • 光从空气进入玻璃：折射角小于入射角，光线向法线偏折 ✓
  • 光从玻璃射出空气：折射角大于入射角，光线远离法线偏折 ✓
  • 出射光线与入射光线平行 ✓

B 选项（错误）：

  • 光线进入玻璃时传播方向未改变 ✗
  • 错误原因：忽略了光的折射现象

C 选项（错误）：

  • 光线在玻璃砖内部发生反射 ✗
  • 错误原因：题目考查折射光路，不应出现反射

D 选项（错误）：

  • 光从空气进入玻璃时，折射角大于入射角 ✗
  • 错误原因：搞反了折射规律，光疏→光密应向法线偏折

课堂讲解建议：

  1. 先让学生独立判断，再逐一分析
  2. 强调记忆口诀：「疏→密，向法线；密→疏，离法线」
  3. 总结平行玻璃砖的特点：出射光线与入射光线平行，但产生侧移
