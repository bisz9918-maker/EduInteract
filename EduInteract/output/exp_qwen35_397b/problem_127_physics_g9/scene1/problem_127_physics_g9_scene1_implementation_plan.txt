[图示主题与整合说明]
- 本图示主题：光通过平行玻璃砖的折射规律动态演示
- 整合的内容：光从空气→玻璃→空气的完整折射过程、法线标注、入射角与折射角关系、出射光线侧移现象
- 教学价值：教师可通过拖动滑块调节入射角，让学生直观观察折射角的变化规律，理解"光从空气斜射入玻璃时向法线偏折，从玻璃射入空气时远离法线偏折"的规律，并发现出射光线始终与入射光线平行但产生侧移的现象

[分步序列]
本场景采用连续拖拽滑块交互，无分步导航，状态随滑块实时变化：
- 初始状态（入射角 30°）：
  - 显示完整光路：入射光线、折射光线、出射光线
  - 显示两条法线（虚线）
  - 显示入射角弧线（绿色）和折射角弧线（绿色）
  - 右侧面板显示：θ₁=30°，θ₂≈19°（按 n=1.5 计算）
  - 滑块位于中间位置

- 拖动滑块减小入射角（0°~30°）：
  - 入射光线角度变陡（更接近法线）
  - 折射角同步减小
  - 出射光线同步调整，保持与入射光线平行
  - 角度弧线实时缩放
  - 数值面板实时更新

- 拖动滑块增大入射角（30°~60°）：
  - 入射光线角度变缓（更远离法线）
  - 折射角同步增大
  - 出射光线同步调整，保持与入射光线平行
  - 侧移距离明显增大
  - 数值面板实时更新

- 观察要点：
  - 出射光线始终与入射光线平行
  - 入射角增大时，侧移距离增大
  - 折射角始终小于入射角（光从空气到玻璃）

[交互方案]
- 交互类型：连续拖拽滑块（入射角调节 0°~60°）
- 控件说明：
  - 滑块：位于 SVG 底部 y=460~480，范围 0~60，初始值 30
  - 滑块标签："入射角调节" 位于滑块上方 y=440
  - 数值面板：右侧 (650,120) 区域，实时显示θ₁和θ₂数值
- 教师操作流程：
  1. 初始状态展示完整光路，讲解光的折射基本概念
  2. 缓慢拖动滑块减小入射角，引导学生观察折射角变化
  3. 拖动滑块增大入射角，让学生注意侧移距离的变化
  4. 强调出射光线始终与入射光线平行这一关键规律
  5. 可停在特定角度（如 45°）讲解折射定律 n=sinθ₁/sinθ₂

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单，SVG 矢量绘制清晰，无需额外库
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +----------------------------------------------------------+
  |  [空气]                    角度数值面板                   |
  |                           θ₁ = 30°                       |
  |     \  θ₁                 θ₂ = 19°                       |
  |      \  | (法线)                                          |
  |       \ |                                                  |
  |        \|                                                  |
  |  -------+--------------------------- 玻璃砖 -------------- |
  |         |\  θ₂                                            |
  |         | \                                                |
  |         |  \                                               |
  |         |   \                                              |
  |  -------+----\--------------------------                   |
  |         |     \                                            |
  |         | (法线)\                                          |
  |          \       \                                         |
  |           \       \                                        |
  |            \     [空气]                                    |
  |                                                          |
  |  入射角调节                                               |
  |  [====●============]  0°────────────60°                   |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 折射角计算：使用斯涅尔定律 sin(θ₂) = sin(θ₁)/n，n=1.5（玻璃折射率）
  2. 光线路径计算：
     - 入射点固定于 (350,200)
     - 入射光线起点随角度变化：x = 350 - 130*sin(θ₁), y = 200 - 130*cos(θ₁)
     - 折射光线终点（出射点）：x = 350 + 120*tan(θ₂), y = 320
     - 出射光线方向与入射光线平行
  3. 状态机：单状态连续交互，无需步骤切换
  4. 事件绑定：slider 的 input 事件实时更新所有相关元素
  5. 角度弧线：使用 SVG arc 路径，半径随角度动态调整
- ID 命名规范：
  - scene1-glass-rect（玻璃砖）
  - scene1-normal-top（上法线）
  - scene1-normal-bottom（下法线）
  - scene1-incident-ray（入射光线）
  - scene1-refracted-ray（折射光线）
  - scene1-exit-ray（出射光线）
  - scene1-incident-arc（入射角弧线）
  - scene1-refracted-arc（折射角弧线）
  - scene1-angle-display（角度数值显示）
  - scene1-angle-slider（角度滑块）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
