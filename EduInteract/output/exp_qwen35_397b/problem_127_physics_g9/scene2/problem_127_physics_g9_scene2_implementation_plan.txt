[图示主题与整合说明]
- 本图示主题：四个选项光路对比分析
- 整合的内容：整合了 A、B、C、D 四个选项的光路图，标注每个选项的正误原因，高亮显示正确选项

[分步序列]
共 5 个步骤（步骤 0-4），教师可通过「上一步」「下一步」按钮切换：

- 步骤 0（初始状态）：
  - 显示四个选项的完整光路图（A、B、C、D）
  - 显示玻璃砖、光线、法线、选项标签
  - 不显示高亮框和正误标注
  - 步骤指示显示「步骤 0/4」

- 步骤 1（分析 A 选项）：
  - 显示 A 选项高亮框（绿色#2e7d32）
  - 显示 A 选项正误标注：「✓ 正确」
  - 显示 A 选项原因文字：「入射向法线偏折，出射远离法线」
  - 其他选项保持原样，无高亮
  - 步骤指示显示「步骤 1/4」

- 步骤 2（分析 B 选项）：
  - 隐藏步骤 1 的高亮框和标注
  - 显示 B 选项高亮框（红色#c62828）
  - 显示 B 选项错误标注：「✗ 错误」
  - 显示 B 选项原因文字：「光线未发生折射」
  - 步骤指示显示「步骤 2/4」

- 步骤 3（分析 C 选项）：
  - 隐藏步骤 2 的高亮框和标注
  - 显示 C 选项高亮框（红色#c62828）
  - 显示 C 选项错误标注：「✗ 错误」
  - 显示 C 选项原因文字：「玻璃内部发生反射」
  - 步骤指示显示「步骤 3/4」

- 步骤 4（分析 D 选项）：
  - 隐藏步骤 3 的高亮框和标注
  - 显示 D 选项高亮框（红色#c62828）
  - 显示 D 选项错误标注：「✗ 错误」
  - 显示 D 选项原因文字：「入射时无偏折」
  - 步骤指示显示「步骤 4/4」

[交互方案]
- 交互类型：分步按钮导航（◀ 上一步 / 下一步 ▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于 (280,455)，120×30px，点击后切换到上一步骤（步骤 0 时禁用）
  - 「下一步 ▶」按钮：位于 (480,455)，120×30px，点击后切换到下一步骤（步骤 4 时禁用）
  - 步骤指示：位于 (400,460)，显示当前步骤编号「步骤 X/4」
- 教师操作流程：
  1. 初始展示四个选项原图，让学生观察差异
  2. 点击「下一步」进入步骤 1，高亮 A 选项，讲解正确光路
  3. 点击「下一步」进入步骤 2，高亮 B 选项，指出无折射的错误
  4. 点击「下一步」进入步骤 3，高亮 C 选项，指出内部反射的错误
  5. 点击「下一步」进入步骤 4，高亮 D 选项，指出入射无偏折的错误
  6. 可随时点击「上一步」回退复习

[技术实现]
- JS 库选择：原生 SVG（简单几何图形首选，无需额外库）
- 画布尺寸：800×500px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |  [A 选项光路图]           [B 选项光路图]          |
  |   玻璃砖 + 光线 + 法线      玻璃砖 + 光线 + 法线   |
  |        A 标签                  B 标签             |
  |                                                    |
  |  [C 选项光路图]           [D 选项光路图]          |
  |   玻璃砖 + 光线 + 法线      玻璃砖 + 光线 + 法线   |
  |        C 标签                  D 标签             |
  |                                                    |
  |              [◀ 上一步]  步骤 X/4  [下一步 ▶]      |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-4) 跟踪当前步骤
  2. 所有元素按步骤分组，用 display:none 控制显示/隐藏
  3. 高亮框使用 stroke 属性，无 fill
  4. 光线箭头使用 SVG marker 或 path 绘制
  5. 按钮点击事件绑定，更新 currentStep 并刷新显示状态
  6. 步骤 0 和步骤 4 时分别禁用「上一步」和「下一步」按钮（opacity:0.5, pointer-events:none）
- ID 命名规范：所有元素 ID 以 scene2- 为前缀
  - 示例：scene2-glass-a, scene2-ray-incident-a, scene2-highlight-a, scene2-btn-prev, scene2-btn-next
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
- 按钮样式：圆角矩形，背景色#1976d2，文字白色，hover 效果加深背景
