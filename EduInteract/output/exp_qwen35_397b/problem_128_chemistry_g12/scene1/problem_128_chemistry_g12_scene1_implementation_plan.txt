[图示主题与整合说明]
- 本图示主题：正三棱柱晶体结构及三种粒子分摊计算
- 整合的步骤/概念：完整结构展示 → A粒子（顶点）高亮与计算 → B粒子（棱中点）高亮与计算 → C粒子（体心）高亮与计算 → 最终比例结论
- 教学价值：教师可按认知顺序逐步展示三种粒子的位置和分摊系数计算，分步导航让教师可控制讲解节奏，随时回退复习。通过视觉高亮帮助学生理解晶胞中不同位置粒子的共享规则（顶点1/12、棱上1/6、体心1）。

[视觉元素清单]
- 正三棱柱线框：6条可见棱用#000000实线2px，1条被遮挡后棱用#888888虚线2px
- A粒子（顶点）：6个r=8px实心圆，默认#000000，步骤1高亮#1565c0
- B粒子（棱中点）：9个r=5px实心圆，默认#000000，步骤2高亮#2e7d32
- C粒子（体心）：1个r=10px空心圆（fill=#ffffff,stroke=#000000），步骤3高亮stroke=#c62828
- 图例区：左上角(280,40)起显示A/B/C三种粒子图例
- 计算公式区：右侧(550,100)起显示当前步骤的计算公式
- 颜色/样式沿用spec中声明：背景#ffffff / 主线#000000 / 遮挡棱#888888虚线 / A高亮#1565c0 / B高亮#2e7d32 / C高亮#c62828

[分步序列]
- 初始状态（步骤0）：显示完整正三棱柱线框结构，所有A/B/C粒子以默认黑色显示，右侧公式区显示"正三棱柱晶体结构"
- 步骤1：高亮6个顶点A粒子（变为#1565c0蓝色），其他粒子变淡，右侧公式区显示"A粒子（顶点）：6×1/12=0.5"
- 步骤2：A粒子恢复默认，高亮9个棱中点B粒子（变为#2e7d32绿色），右侧公式区显示"B粒子（棱上）：9×1/6=1.5"
- 步骤3：B粒子恢复默认，高亮体心C粒子（空心圆stroke变为#c62828红色），右侧公式区显示"C粒子（体心）：1×1=1"
- 步骤4：所有粒子恢复默认，右侧公式区显示最终结论"A:B:C=0.5:1.5:1=1:3:2=2:9:4"，并用不同颜色标注三种粒子

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 按钮"◀ 上一步"：位于(320,460)，点击后切换到前一状态（步骤0时禁用）
  - 按钮"下一步 ▶"：位于(420,460)，点击后切换到下一状态（步骤4时禁用）
  - 当前步骤指示：位于(380,460)，显示"步骤X/4"
- 教师操作流程：
  1. 初始展示完整结构，让学生观察三棱柱形状和粒子分布
  2. 点击"下一步"高亮A粒子，讲解顶点粒子被12个晶胞共享（分摊系数1/12）
  3. 点击"下一步"高亮B粒子，讲解棱上粒子被6个晶胞共享（分摊系数1/6）
  4. 点击"下一步"高亮C粒子，讲解体心粒子完全属于本晶胞（分摊系数1）
  5. 点击"下一步"显示最终比例，引导学生化简得到答案2:9:4
  6. 可随时点击"上一步"回退复习

[技术实现]
- JS库选择：原生SVG（简单几何图形首选，无需额外库）
- 画布尺寸：800×500px（固定画布）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  | [图例A B C]                    [计算公式区]      |
  |                                                  |
  |           T1                                     |
  |          /  \                                    |
  |        T3----T2                                  |
  |         |    |                                   |
  |         |    |                                   |
  |        B3----B2                                  |
  |          \  /                                    |
  |           B1                                     |
  |                                                  |
  |                                                  |
  |              [控件栏]                            |
  |         [◀上一步][步骤X/4][下一步▶]              |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量currentStep(0-4)跟踪当前步骤，数组steps存储每步的视觉配置
  2. 坐标计算：三棱柱顶点坐标预先计算好，棱中点用中点公式((x1+x2)/2,(y1+y2)/2)
  3. 高亮实现：通过修改circle元素的fill/stroke属性和opacity实现
  4. 事件绑定：按钮点击事件切换currentStep，调用renderStep()更新视图
  5. 公式更新：每步更新右侧text元素的textContent
- ID命名规范：所有元素ID以scene1-为前缀，如scene1-prism-edge-1, scene1-particle-a-1, scene1-btn-prev, scene1-formula-text
- IIFE隔离：所有JS代码包在(function() { ... })()中，避免全局污染
