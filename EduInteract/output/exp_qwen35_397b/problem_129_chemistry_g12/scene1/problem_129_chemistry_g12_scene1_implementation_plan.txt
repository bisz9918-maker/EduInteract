[图示主题与整合说明]
- 本图示主题：偏二甲肼-四氧化二氮原电池工作原理
- 整合的内容：电子流向判断正负极、燃料/氧化剂通入位置、离子移动方向、产物排出位置
- 教学价值：教师可按逻辑顺序逐步揭示原电池各部分功能，从电子流向→电极判断→物质通入→离子移动→产物排出，形成完整的认知链条。学生可直观理解燃料电池的工作原理，掌握电极判断方法和离子移动规律。

[分步序列]
- 初始状态（步骤 0）：显示原电池基础装置
  - 显示：电极 A、电极 B、外电路导线、灯泡、电解质区域、入口 a/b 箭头、出口 c/d 箭头
  - 显示标签：A、B、H₂SO₄、a、b、c、d
  - 隐藏：电子流向箭头、正负极标注、H⁺移动箭头、燃料/氧化剂标签、产物标签

- 步骤 1：点击「下一步」→ 高亮显示电子流向
  - 视觉变化：外电路导线上出现蓝色箭头，从 B 指向 A
  - 新增元素：电子流向箭头（B→A）、"e⁻" 标签 (325,90) 和 (445,90)
  - 高亮：外电路导线变为蓝色 3px

- 步骤 2：点击「下一步」→ 根据电子流向判断并标注正负极
  - 视觉变化：在电极 A 左侧显示"正极"，在电极 B 右侧显示"负极"
  - 新增元素："正极" 标签 (305,200)、"负极" 标签 (460,200)
  - 样式：红色粗体

- 步骤 3：点击「下一步」→ 显示燃料/氧化剂通入位置
  - 视觉变化：在 a 入口下方显示"C₂H₈N₂"，在 b 入口下方显示"N₂O₄"
  - 新增元素："C₂H₈N₂" 标签 (210,405)、"N₂O₄" 标签 (590,405)
  - 样式：蓝色
  - 说明：燃料偏二甲肼从 b 口通入（指向 B 极负极），氧化剂 N₂O₄从 a 口通入（指向 A 极正极）
  - 注意：根据原电池原理，燃料在负极反应，氧化剂在正极反应

- 步骤 4：点击「下一步」→ 显示 H⁺离子从负极区向正极区移动
  - 视觉变化：电解质区域内出现绿色虚线箭头，从 B 侧指向 A 侧
  - 新增元素：H⁺移动箭头 (460,280)→(360,280)、"H⁺" 标签 (400,265)
  - 样式：绿色虚线 2px

- 步骤 5：点击「下一步」→ 显示产物从 c 口和 d 口排出
  - 视觉变化：在 c 出口上方显示"CO₂+N₂"，在 d 出口上方显示"H₂O"

  - 样式：绿色
  - 说明：正极产物 CO₂和 N₂从 c 口排出，负极产物 H₂O 从 d 口排出

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 底部左侧 (x=320, y=455)，点击回退到前一状态
  - 「下一步」按钮：位于 SVG 底部右侧 (x=460, y=455)，点击进入下一状态
  - 步骤指示器：位于底部中央 (x=400, y=455)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始状态展示原电池基础装置，讲解装置结构
  2. 点击「下一步」，电子流向出现，讲解电子从负极流向正极
  3. 点击「下一步」，正负极标注出现，讲解如何根据电子流向判断电极
  4. 点击「下一步」，燃料/氧化剂标签出现，讲解反应物通入位置
  5. 点击「下一步」，H⁺移动箭头出现，讲解电解质中离子移动方向
  6. 点击「下一步」，产物标签出现，讲解电极反应产物
  7. 可随时点击「上一步」回退复习

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript
  - 原因：本图示为 2D 静态几何图形为主，配合简单箭头动画，原生 SVG 足够实现且性能最优
  - 无需引入重型库如 D3.js 或 Three.js

- 画布尺寸：800 × 500 px（固定）

- 布局草图：
  ```
  [图示区 800×500]
  +----------------------------------------------------------+
  |                    [灯泡]                                |
  |              c ← ┌──────┐ → d                            |
  |         CO₂+N₂   │  A   │    H₂O                         |
  |              ←───│      │───→                            |
  |         正极     │      │     负极                       |
  |              A   │======│   B                            |
  |                  │ H⁺→  │                                |
  |                  │H₂SO₄ │                                |
  |      a → C₂H₈N₂  │      │  N₂O₄ ← b                      |
  +----------------------------------------------------------+
  |         [◀上一步]    步骤 X/5    [下一步▶]               |
  +----------------------------------------------------------+
  ```

- 关键实现要点：
  1. 状态机设计：使用 currentState 变量 (0-5) 跟踪当前步骤
  2. 元素分组：将各步骤新增元素按组分配 ID，如 scene1-step1-arrows、scene1-step2-labels 等
  3. 显示/隐藏控制：通过 CSS display 属性或 SVG visibility 属性控制各步骤元素
  4. 按钮事件绑定：为「上一步」「下一步」按钮添加 click 事件监听器
  5. 边界处理：步骤 0 时禁用「上一步」，步骤 5 时禁用「下一步」
  6. 动画效果：电子流向箭头可使用 CSS transition 实现淡入效果

- ID 命名规范：
  - 所有交互元素 ID 必须以 scene1- 为前缀
  - 示例：scene1-electrode-a、scene1-electrode-b、scene1-wire、scene1-bulb
  - 步骤元素：scene1-step1-electron-arrow、scene1-step2-polarity-labels
  - 控件：scene1-btn-prev、scene1-btn-next、scene1-step-indicator

- IIFE 隔离：
  ```javascript
  (function() {
      // 所有 JS 代码包裹在此
      let currentState = 0;
      const totalSteps = 5;
      
      function updateDisplay() {
          // 根据 currentState 显示/隐藏对应元素
      }
      
      function nextStep() {
          if (currentState < totalSteps) {
              currentState++;
              updateDisplay();
          }
      }
      
      function prevStep() {
          if (currentState > 0) {
              currentState--;
              updateDisplay();
          }
      }
      
      // 事件绑定
      document.getElementById('scene1-btn-next').addEventListener('click', nextStep);
      document.getElementById('scene1-btn-prev').addEventListener('click', prevStep);
      
      // 初始化
      updateDisplay();
  })();
  ```
