[图示主题与整合说明]
- 本图示主题：电极反应式推导与验证——偏二甲肼/四氧化二氮燃料电池
- 整合的步骤/概念：负极氧化反应式配平过程、正极还原反应式、总反应式、选项 D 的配平验证
- 教学价值：教师可逐步展示电极反应式的配平逻辑（原子守恒→电荷守恒），帮助学生理解燃料电池的工作原理，并通过与选项 D 对比验证答案正确性

[分步序列]
- 步骤 0（初始状态）：显示标题、负极区标题、正极区标题、负极反应框架（C₂H₈N₂ → CO₂ + N₂ + H⁺，未配平）、正极反应式框架（N₂O₄ + H⁺ + e⁻ → N₂ + H₂O）
- 步骤 1：高亮负极反应框架，显示"确定氧化产物"提示，C→CO₂、N→N₂、H→H⁺ 用箭头标注
- 步骤 2：配平 C 原子，显示"C₂ → 2CO₂"，系数"2"用蓝色粗体高亮
- 步骤 3：配平 N 原子，显示"N₂ → N₂"（已平衡），灰色标记"✓"
- 步骤 4：配平 O 原子，显示"需 8H₂O 提供 O"，添加"8H₂O"到反应物侧
- 步骤 5：配平 H 原子和电荷，显示"生成 16H⁺，转移 16e⁻"，添加"16H⁺"和"16e⁻"
- 步骤 6：显示完整负极反应式（C₂H₈N₂ - 16e⁻ + 8H₂O = 2CO₂ + N₂ + 16H⁺），显示原子守恒检查标记（C:2=2, N:2=2, O:8=8, H:16=16）和电荷守恒检查标记（左侧-16，右侧+16，平衡）
- 步骤 7：显示选项 D 对比框，将完整负极反应式与选项 D（C₂H₈N₂ - 16e⁻ + 8H₂O = CO₂ + N₂ + 16H⁺）对比，高亮差异（选项 D 中 CO₂ 系数应为 2），边框变红色表示错误
- 步骤 8（最终）：显示总反应式（C₂H₈N₂ + 2N₂O₄ = 2CO₂ + 3N₂ + 4H₂O），显示正极反应式完整形式（N₂O₄ + 8H⁺ + 8e⁻ = N₂ + 4H₂O）

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - "上一步"按钮：位于 SVG 底部左侧 (280,450)，点击回退到上一状态
  - "下一步"按钮：位于 SVG 底部右侧 (440,450)，点击进入下一状态
  - 步骤指示器：位于两按钮之间 (400,460)，显示当前步骤序号
- 教师操作流程：
  1. 初始展示反应框架，引导学生思考如何配平
  2. 点击"下一步"逐步展示配平逻辑（原子守恒→电荷守恒）
  3. 步骤 6 时引导学生检查原子和电荷是否守恒
  4. 步骤 7 时对比选项 D，让学生发现 CO₂ 系数错误
  5. 步骤 8 展示总反应式，完成整个电极反应推导

[技术实现]
- JS 库选择：原生 SVG（适合化学方程式文本展示，无需复杂图形库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────┐
  │           电极反应式推导与验证 (标题)                │
  │                                                     │
  │    负极（A 极）              正极（B 极）            │
  │    ┌─────────────┐          ┌─────────────┐        │
  │    │ 反应框架    │          │ 反应式      │        │
  │    │ 配平步骤    │          │             │        │
  │    │ 完整反应式  │          │             │        │
  │    └─────────────┘          └─────────────┘        │
  │                                                     │
  │    ┌─────────────────────────────────────┐         │
  │    │ 选项 D 对比框                        │         │
  │    └─────────────────────────────────────┘         │
  │                                                     │
  │              总反应式（居中）                       │
  │                                                     │
  │         [◀上一步]  步骤 X/8  [下一步▶]             │
  └─────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用 currentState 变量（0-8）跟踪当前步骤，steps 数组存储每步的显示配置
  2. 每步显示/隐藏：用 CSS class "visible" 控制元素显隐，避免重复创建 DOM
  3. 配平系数高亮：用 <tspan> 元素单独设置系数颜色和字体粗细
  4. 选项 D 对比：用两个并排文本框，差异部分用红色高亮
  5. 事件绑定：按钮点击事件绑定到 updateStep() 函数，更新 currentState 并刷新显示
- ID 命名规范：所有元素 ID 以 "scene2-" 为前缀（如 scene2-title, scene2-anode-frame, scene2-step1-coef 等）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
