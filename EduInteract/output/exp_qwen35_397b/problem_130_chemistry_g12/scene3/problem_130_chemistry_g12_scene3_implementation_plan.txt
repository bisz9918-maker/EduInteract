[视觉元素清单]
- 结构式：使用 SVG path 绘制键线式骨架，text 元素标注 CH₃、CH₂、CH、Cl 等基团
- 结构编号：红色圆圈(#c62828)内白字，半径 12px
- 基团计数标签：蓝色(#1565c0)小字，格式"CH₃×2 CH₂×2 CH×1 Cl×1"
- 符合标记：绿色(#2e7d32)对勾符号，12×12px
- 答案文本：绿色(#2e7d32)粗体 18px，显示"C. 4 种"
- 背景：#ffffff 白色
- 结构式线条：#000000 黑色实线，线宽 2px

[分步序列]
- 步骤 0（初始状态）：画布空白，仅显示控件栏，上一步按钮禁用
- 步骤 1：显示结构 1（CH₃-CH₂-CH(CH₃)-CH₂Cl，1-氯 -2-甲基丁烷）
  - 结构 1 编号圆圈、结构式、基团计数标签、绿色对勾依次淡入
  - 其他结构区域保持空白
- 步骤 2：保留结构 1，新增显示结构 2（CH₃-CH(CH₃)-CH₂-CH₂Cl，1-氯 -3-甲基丁烷）
  - 结构 2 编号圆圈、结构式、基团计数标签、绿色对勾依次淡入
- 步骤 3：保留结构 1-2，新增显示结构 3（CH₃-CH₂-CHCl-CH₂-CH₃，3-氯戊烷）
  - 结构 3 编号圆圈、结构式、基团计数标签、绿色对勾依次淡入
- 步骤 4：保留结构 1-3，新增显示结构 4（CH₃-CH(Cl)-CH₂-CH₂-CH₃，2-氯戊烷）
  - 结构 4 编号圆圈、结构式、基团计数标签、绿色对勾依次淡入
- 步骤 5：4 种结构全部显示，底部答案区淡入显示"C. 4 种"
  - 答案文本绿色粗体高亮，完成展示

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 上一步按钮：返回上一状态，步骤 0 时禁用
  - 下一步按钮：进入下一状态，步骤 5 时禁用或显示"完成"
  - 步骤指示器：显示当前步骤 X/5
- 教师操作流程：
  1. 初始状态空白，教师说明题目条件
  2. 点击"下一步"展示结构 1，引导学生验证基团计数
  3. 依次点击展示结构 2、3、4，每步让学生确认是否符合条件
  4. 最后一步显示答案，总结共有 4 种异构体

[技术实现]
- JS 库选择：原生 SVG（简单几何图形和文本，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  [结构 1]           [结构 2]                      |
  |   CH₃-CH₂-...       CH₃-CH-...                    |
  |   CH₃×2 ✓           CH₃×2 ✓                       |
  |                                                  |
  |  [结构 3]           [结构 4]                      |
  |   CH₃-CH₂-...       CH₃-CH-...                    |
  |   CH₃×2 ✓           CH₃×2 ✓                       |
  |                                                  |
  |            C. 4 种                                |
  |                                                  |
  |      [◀上一步]  步骤 X/5  [下一步▶]               |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  - 状态机：currentStep 变量 (0-5)，每步对应显示不同的 g 组元素
  - 每个结构式封装在独立 g 组中，ID 为 scene3-struct1 至 scene3-struct4
  - 答案区封装在 g 组 scene3-answer 中，步骤 5 才显示
  - 按钮点击事件更新 currentStep，调用 updateDisplay() 函数控制各 g 组的 display 属性
  - 淡入动画：使用 CSS transition opacity 0.3s
- ID 命名规范：所有元素 ID 以 scene3- 为前缀
  - scene3-struct1, scene3-struct2, scene3-struct3, scene3-struct4
  - scene3-answer, scene3-btn-prev, scene3-btn-next, scene3-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
