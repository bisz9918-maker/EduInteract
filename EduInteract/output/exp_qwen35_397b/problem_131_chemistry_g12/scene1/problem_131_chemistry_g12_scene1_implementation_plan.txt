[图示主题与整合说明]
- 本图示主题：原电池与电解池组合装置的整体结构与电流方向
- 整合的步骤/概念：装置连接关系、原电池/电解池判断、电子流向、离子移动方向、电极极性标注
- 教学价值：教师可逐步引导学生从装置识别开始，先判断哪个是原电池哪个是电解池，再分析电子在外电路的流向，然后分析离子在溶液中的移动方向，最后标注各电极的极性（正极/负极/阳极/阴极），帮助学生建立完整的电化学认知框架

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于SVG底部左侧(x=320,y=465)，灰色背景，点击返回上一状态
  - 「下一步」按钮：位于SVG底部右侧(x=460,y=465)，蓝色背景，点击进入下一状态
  - 步骤指示器：位于底部中央(x=400,y=465)，显示"步骤 X/4"
- 教师操作流程：
  1. 初始展示装置结构，让学生识别两个烧杯和四个电极
  2. 点击「下一步」展示原电池/电解池区域划分，引导学生判断哪边是原电池（Zn-C-稀H₂SO₄，自发反应）
  3. 点击「下一步」展示电子流向，分析外电路电子从负极(Zn)流向正极(C)
  4. 点击「下一步」展示离子移动方向，分析溶液中阴阳离子的移动规律
  5. 点击「下一步」展示电极极性，总结各电极的名称（正极/负极/阳极/阴极）

[技术实现]
- JS 库选择：原生SVG + 原生JavaScript
  - 原因：几何图形简单（烧杯、电极、导线、箭头），原生SVG足够胜任，无需引入重型库
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────┐
  │                    [电流表 A]                            │
  │         ┌─────┐              ┌─────┐                    │
  │         │ Pt  │              │ Zn  │                    │
  │  电解池 │━━━━━│   导线       │━━━━━│   原电池          │
  │  (蓝色) │ Cu  │──────────────│ C   │   (绿色)          │
  │         └─────┘    开关      └─────┘                    │
  │        NaCl溶液            稀H₂SO₄                      │
  │                                                         │
  │  [离子箭头]              [离子箭头]                      │
  │                                                         │
  │         [◀上一步]  步骤 X/4  [下一步▶]                  │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量currentStep(0-4)跟踪当前步骤，steps数组存储每步显示的元素ID列表
  2. 元素分组：将电子流向、离子箭头、极性标签分别放入<g>组，用display控制显隐
  3. 箭头绘制：用marker-end定义箭头样式，线段+marker实现带方向的箭头
  4. 虚线箭头：stroke-dasharray="5,5"实现虚线效果
  5. 事件绑定：按钮点击事件切换currentStep，调用updateDisplay()刷新显隐状态
  6. 边界检查：步骤0和步骤4时禁用对应按钮（opacity=0.5, pointer-events=none）
- ID 命名规范：所有元素ID以scene1-为前缀
  - scene1-beaker-left, scene1-beaker-right
  - scene1-electrode-pt, scene1-electrode-cu, scene1-electrode-zn, scene1-electrode-c
  - scene1-wire-*, scene1-ammeter, scene1-switch
  - scene1-label-pt, scene1-label-cu, scene1-label-zn, scene1-label-c
  - scene1-label-nacl, scene1-label-h2so4
  - scene1-region-electrolytic, scene1-region-galvanic
  - scene1-label-electrolytic, scene1-label-galvanic
  - scene1-electron-flow-* (4个箭头)
  - scene1-ion-na, scene1-ion-cl, scene1-ion-h, scene1-ion-so4
  - scene1-polarity-zn, scene1-polarity-c, scene1-polarity-pt, scene1-polarity-cu
  - scene1-btn-prev, scene1-btn-next, scene1-step-indicator
- IIFE 隔离：所有JS代码包在 (function() { ... })() 中，避免全局变量污染
