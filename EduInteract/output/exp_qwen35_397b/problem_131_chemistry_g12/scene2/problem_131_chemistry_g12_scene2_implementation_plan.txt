[分步序列]
步骤 0（初始状态）：
- 显示：两个烧杯轮廓、液面、四个电极、导线、电流表、开关（断开）、溶液标签、电极点名标签
- 隐藏：所有反应方程式、气泡、OH⁻富集区、选项框
- 状态：开关断开，无高亮

步骤 1（Zn 电极反应）：
- 高亮：Zn 电极（蓝色加粗边框）
- 显示：Zn 反应式"Zn - 2e⁻ → Zn²⁺"（坐标 460,280）、Zn²⁺离子气泡（540-580,300-330）
- 隐藏：其他电极反应式
- 说明：Zn 为原电池负极，发生氧化反应

步骤 2（C 电极反应）：
- 高亮：C 电极（蓝色加粗边框）
- 显示：C 反应式"2H⁺ + 2e⁻ → H₂↑"（坐标 720,280）、H₂气泡（680-700,220-240）
- 隐藏：Zn 反应式及气泡
- 说明：C 为原电池正极，H⁺得电子生成 H₂

步骤 3（Pt 电极反应）：
- 高亮：Pt 电极（蓝色加粗边框）
- 显示：Pt 反应式"2Cl⁻ - 2e⁻ → Cl₂↑"（坐标 40,280）、Cl₂气泡（100-120,220-240）
- 隐藏：C 反应式及气泡
- 说明：Pt 为电解池阳极，Cl⁻失电子生成 Cl₂

步骤 4（Cu 电极反应）：
- 高亮：Cu 电极（蓝色加粗边框）
- 显示：Cu 反应式"2H₂O + 2e⁻ → H₂↑ + 2OH⁻"（坐标 280,280）、H₂气泡（240-260,220-240）、OH⁻富集区（220-260,290-330 半透明绿）
- 隐藏：Pt 反应式及气泡
- 说明：Cu 为电解池阴极，H₂O 得电子生成 H₂和 OH⁻

步骤 5（选项判断汇总）：
- 高亮：无（或四个电极恢复正常边框）
- 显示：四个选项框及判断结果
  - A: "C 电极为电解池的阳极" → ×（红色，C 是原电池正极）
  - B: "Cu 电极附近 OH⁻浓度增大" → ✓（绿色，正确）
  - C: "Na⁺移向 Pt 电极" → ×（红色，Na⁺移向 Cu 电极）
  - D: "Pt 电极上有 O₂生成" → ×（红色，生成 Cl₂）
- 隐藏：所有反应方程式、气泡、OH⁻富集区

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 上一步按钮：位于 (280,465)，宽 80px，高 30px，点击返回上一状态
  - 下一步按钮：位于 (440,465)，宽 80px，高 30px，点击进入下一状态
  - 步骤指示器：位于 (380,470)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始展示装置全貌，讲解原电池与电解池的判断依据
  2. 点击"下一步"依次展示每个电极的反应，引导学生分析电极类型
  3. 每步停留讲解反应式书写、产物判断、离子移动方向
  4. 最后一步汇总四个选项，带领学生逐一判断正误并说明理由

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单，无需复杂库；原生实现轻量、加载快、易于多场景合并
- 画布尺寸：800×500px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────────┐
  │                                                             │
  │    [左烧杯]                    [右烧杯]                     │
  │    Pt  Cu                      Zn   C                       │
  │    NaCl 溶液                   稀 H₂SO₄                     │
  │                                                             │
  │         [电流表 A]                                          │
  │              ═══                                            │
  │         [开关]                                              │
  │                                                             │
  │    [反应式区]  [反应式区]  [反应式区]  [反应式区]           │
  │                                                             │
  │  [A×]  [B✓]  [C×]  [D×]  (步骤 5 显示)                     │
  │                                                             │
  │         [◀上一步]  步骤 X/5  [下一步▶]                      │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-5），数组存储每步的显示/隐藏元素 ID 列表
  2. 坐标计算：所有元素使用绝对坐标，反应式位置根据电极位置动态计算偏移
  3. 动画曲线：电极高亮使用 CSS transition（0.3s ease），气泡使用 opacity 淡入
  4. 事件绑定：按钮点击事件绑定到 updateScene() 函数，根据 currentState 更新 DOM 元素 display 属性
  5. ID 命名规范：所有元素 ID 以 scene2- 为前缀（如 scene2-pt-electrode, scene2-zn-reaction）
  6. IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
  7. 元素分组：使用 SVG <g> 元素将相关元素分组（如 scene2-step1-group 包含 Zn 电极高亮、反应式、气泡）
  8. 开关状态：步骤 0 开关断开，步骤 1-5 开关闭合（路径变化）
