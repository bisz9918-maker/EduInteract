[图示主题与整合说明]
- 本图示主题：罂粟碱分子苯环取代反应位点分析与一溴代物同分异构体计数
- 整合的步骤/概念：整合了苯环识别、可取代氢原子定位、同分异构体计数三个步骤
- 教学价值：教师可使用此图示逐步展示苯环上可取代位点的分析方法，帮助学生理解为什么罂粟碱与 Br2 发生苯环取代反应生成 5 种一溴代物同分异构体。通过分步高亮和编号，学生能清晰看到每个可取代位置的来源，避免遗漏或重复计数。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：分子结构为静态几何图形，无需复杂动画或物理模拟；原生 SVG 可精确控制每个元素的位置和样式；代码轻量，加载快速
- 画布尺寸：800×500 px（固定）
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │                    苯环取代位点分析                         │  y=40 标题
  │                                                             │
  │         [左侧异喹啉]              [右侧苯环]                │
  │        ┌─────────┐              ┌─────────┐                │
  │        │ ①       │              │    ③    │                │  y=130-180
  │   CH3O─┤  苯环   ├──N           │  苯环   ├─OCH3           │
  │   CH3O─┤  ②     │  │            │ ④  ⑤   │                │  y=200-270
  │        └─────────┘  │            └─────────┘                │
  │                     └──CH2───                               │
  │                                                             │
  │                    步骤 3/5                                 │  y=440
  │              ┌──────┐ ┌──────┐ ┌──────┐                     │  y=455-485
  │              │上一步│ │下一步│ │ 重置 │                     │
  │                                                             │
  │              共 5 种一溴代物同分异构体                       │  y=470 汇总
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-5），每个状态对应一组可见元素
  2. 元素分组：将相关元素放入 SVG <g> 组，通过 display 属性控制显示/隐藏
     - scene3-left-ring-highlight：左侧苯环高亮区
     - scene3-right-ring-highlight：右侧苯环高亮区
     - scene3-left-labels：左侧苯环相关标签
     - scene3-right-labels：右侧苯环相关标签
     - scene3-site-1, scene3-site-2：左侧可取代位点
     - scene3-site-3, scene3-site-4, scene3-site-5：右侧可取代位点
     - scene3-summary：汇总标签
  3. 按钮状态：步骤 0 时禁用「上一步」，步骤 5 时禁用「下一步」
  4. 动画效果：状态切换时使用 CSS transition 实现淡入淡出（opacity 0→1，duration 300ms）
  5. 事件绑定：使用 addEventListener 绑定按钮点击事件
- ID 命名规范：所有元素 ID 以 scene3- 为前缀
  - scene3-molecule-skeleton：分子骨架
  - scene3-left-ring-poly：左侧苯环多边形
  - scene3-right-ring-poly：右侧苯环多边形
  - scene3-btn-prev：上一步按钮
  - scene3-btn-next：下一步按钮
  - scene3-btn-reset：重置按钮
  - scene3-step-indicator：步骤指示器
- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染
- CDN 引入：无需外部库，纯原生实现
