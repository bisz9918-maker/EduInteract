[图示主题与整合说明]
- 本图示主题：活塞位置变化与气体体积关系
- 整合内容：初始状态展示、反应过程示意、最终状态展示，整合为连贯的分步动画
- 教学价值：教师可逐步引导学生观察活塞移动与体积变化的因果关系，理解化学反应前后气体物质的量变化对压强的影响，最终通过活塞位置推断原混合气体中H₂与O₂的体积比

[分步序列]
- 初始状态（步骤0）：显示容器外框、活塞在x=240位置、左区浅蓝填充标注"空气"、右区浅红填充标注"H₂+O₂混合气"、底部体积标注"1"和"3"、活塞标签"活塞"、底部标尺及刻度
- 步骤1（点燃瞬间）：在容器上方显示反应方程式"2H₂ + O₂ → 2H₂O(l)"（红色高亮），活塞左侧出现绿色左向箭头表示"左弹"，右区颜色加深表示反应发生
- 步骤2（恢复温度）：左弹箭头消失，出现从x=240指向x=400的绿色右滑箭头，表示活塞向右移动，右区填充逐渐变为浅蓝色（表示生成液态水，气体减少）
- 步骤3（最终状态）：活塞移动到x=400（中央位置），左右两区体积相等，左区仍为"空气"，右区标注"剩余气体"，底部标注"中央"，左右体积均为"2"

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 按钮"◀上一步"：位置(320,450)，点击后退到前一状态
  - 按钮"下一步▶"：位置(460,450)，点击进入下一状态
  - 状态指示器：位置(400,480)，显示"步骤 X/3"
- 教师操作流程：
  1. 初始状态展示题目条件，引导学生观察左右体积比1:3
  2. 点击"下一步"展示点燃反应，解释H₂与O₂反应生成液态水
  3. 点击"下一步"展示活塞右滑过程，解释气体物质的量减少导致压强变化
  4. 点击"下一步"展示最终平衡状态，引导学生计算原混合气体中H₂与O₂的体积比

[技术实现]
- JS 库选择及原因：原生SVG + 原生JavaScript。原因：几何图形简单（矩形、直线、箭头），无需复杂库，原生实现轻量且易于控制动画状态
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +----------------------------------------------------------+
  |              2H₂ + O₂ → 2H₂O(l)                          |
  |  +----------------------------------------------------+  |
  |  | 空气           | H₂+O₂混合气                       |  |
  |  |                |                                    |  |
  |  |←──── 1 ────→|←─────────── 3 ───────────→|  |
  |  +----------------------------------------------------+  |
  |         ↑                                            |  |
  |       活塞                                           |  |
  |                                                      |  |
  |  +----+----+----+----+----+----+----+----+           |  |
  |  0    1    2    3    4    5    6    7    8  (标尺)   |  |
  |                                                      |  |
  |           [◀上一步]   步骤1/3   [下一步▶]            |  |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用currentState变量(0-3)，每个状态对应一组SVG元素显示/隐藏
  2. 活塞动画：使用SVG transform translate实现平滑移动，过渡时间500ms
  3. 箭头动画：使用stroke-dasharray实现绘制动画效果
  4. 事件绑定：按钮点击事件绑定到状态切换函数，更新currentState并重绘相关元素
  5. 区域填充变化：步骤2-3时右区填充色从浅红渐变为浅蓝，表示气体成分变化
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀（如 scene1-piston、scene1-left-zone、scene1-btn-prev）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
