[图示主题与整合说明]
- 本图示主题：两种过量情况的气体体积变化分析（H₂与 O₂反应）
- 整合的步骤/概念：
  1. 初始状态：空气体积 1，H₂+O₂混合气体体积 3
  2. 反应原理：2H₂ + O₂ → 2H₂O（液态，体积忽略）
  3. 最终状态：活塞停在中央，剩余气体体积 = 2
  4. 分类讨论：H₂过量情况 vs O₂过量情况
  5. 两种情况分别计算 H₂:O₂体积比
- 教学价值：教师可通过切换按钮对比展示两种过量情况的计算过程，帮助学生理解分类讨论思想，掌握气体反应体积变化的分析方法

[分步序列]
本场景采用多状态切换交互，共 2 个状态：

状态 0（初始/默认显示 H₂过量）：
- 显示状态 1 区域全部元素（H₂过量情况）
- 状态 2 区域隐藏
- 初始示意图显示
- 反应式显示
- "H₂过量"按钮高亮（背景色#1565c0，文字白色）
- "O₂过量"按钮普通（背景色#e0e0e0，文字黑色）

状态 1（点击"O₂过量"按钮切换）：
- 状态 1 区域隐藏
- 显示状态 2 区域全部元素（O₂过量情况）
- 初始示意图保持显示
- 反应式保持显示
- "H₂过量"按钮普通
- "O₂过量"按钮高亮

状态 0 详细计算式内容：
行 1: "设 O₂体积为 x，则 H₂体积为 3-x"
行 2: "消耗 H₂体积 = 2x（2H₂:1O₂）"
行 3: "剩余 H₂ = (3-x) - 2x = 3-3x"
行 4: "3-3x = 2  →  x = 1/3"

状态 1 详细计算式内容：
行 1: "设 H₂体积为 y，则 O₂体积为 3-y"
行 2: "消耗 O₂体积 = y/2（2H₂:1O₂）"
行 3: "剩余 O₂ = (3-y) - y/2 = 3-3y/2"
行 4: "3-3y/2 = 2  →  y = 2/3"

- 关键实现要点：
  1. 状态机：使用变量 currentState (0=H₂过量，1=O₂过量)
  2. 斜线填充 pattern：定义 SVG <pattern> 元素，id="scene2-hatch"
  3. 按钮高亮：切换 class 或直接修改 fill/text 属性
  4. 元素显示/隐藏：使用 display="none" 或 opacity=0
  5. ID 命名规范：所有元素 ID 以 "scene2-" 为前缀
  6. IIFE 隔离：JS 代码包在 (function() { ... })() 中
