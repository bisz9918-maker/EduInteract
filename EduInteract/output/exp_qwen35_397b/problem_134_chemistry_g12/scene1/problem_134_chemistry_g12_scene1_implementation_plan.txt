- 最简式 CH（A）：(180, 385)
- 最简式 CH（B）：(400, 385)
- 最简式 CH（C）：(620, 385)

冲突检查：
- 分子式之间：A-B 水平距离 220px，B-C 水平距离 220px → 无冲突
- 结构标签之间：A-B 水平距离 220px，B-C 水平距离 220px → 无冲突
- 最简式之间：A-B 水平距离 220px，B-C 水平距离 220px → 无冲突
- 分子式与结构标签：垂直距离 240px → 无冲突
- 结构标签与最简式：垂直距离 35px（385-350=35）→ 足够间隙（≥20px），无冲突
- 分子式与结构顶点：A 分子式 y=110，A 最高顶点 y=160，垂直距离 50px → 无冲突
- 最简式与控件栏：最简式 y=385，控件栏 y=440，垂直距离 55px → 无冲突

结论：所有标签间距均≥20px，无重叠冲突。

[技术实现]

- JS 库选择：原生 SVG
  - 原因：立体线框图适合用 SVG 路径和线条绘制，无需复杂 3D 库；交互简单，原生 JS 即可实现状态切换

- 画布尺寸：800×500px（固定）

- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |   C₄H₄          C₆H₆          C₈H₈              | y=110
  |    ∆            /|\           +---+              |
  |   /|\          / | \         /|  /|              |
  |  / | \        /__|__\       +---+ |              | y=160-280
  | /__|__\       |  |  |       | +---+              |
  |                                                  |
  |    A             B             C                 | y=350
  |   CH            CH            CH                 | y=385
  |                                                  |
  |          [◀上一步]  步骤 X/5  [下一步▶]          | y=440-490
  +--------------------------------------------------+
  ```

- 关键实现要点：
  1. 状态机设计：用变量 currentStep（0-4）跟踪当前步骤，数组 steps 定义每步显示的元素
  2. 坐标计算：所有顶点坐标硬编码，确保三个结构在画布上均匀分布
  3. 动画曲线：步骤切换使用 CSS transition，opacity 从 0 到 1，duration 300ms
  4. 事件绑定：按钮点击事件切换 currentStep，调用 updateDisplay() 更新可见性
  5. 元素可见性：用 display:none 或 opacity:0 控制，高亮用 fill-opacity 和 stroke 颜色

- ID 命名规范：
  - 所有元素 ID 以 scene1- 为前缀
  - 结构 A 相关：scene1-struct-a, scene1-a-molecule-formula, scene1-a-carbon-dots, scene1-a-ch-bonds
  - 结构 B 相关：scene1-struct-b, scene1-b-molecule-formula, scene1-b-carbon-dots, scene1-b-ch-bonds
  - 结构 C 相关：scene1-struct-c, scene1-c-molecule-formula, scene1-c-carbon-dots, scene1-c-ch-bonds
  - 最简式：scene1-simple-formula-a, scene1-simple-formula-b, scene1-simple-formula-c
  - 控件：scene1-prev-btn, scene1-next-btn, scene1-step-indicator

- IIFE 隔离：
  ```javascript
  (function() {
    // 所有 JS 代码包在此 IIFE 中
    let currentStep = 0;
    const totalSteps = 5;
    
    function updateDisplay() {
      // 根据 currentStep 更新各元素可见性
    }
    
    // 事件绑定
    document.getElementById('scene1-prev-btn').addEventListener('click', function() {
      if (currentStep > 0) {
        currentStep--;
        updateDisplay();
      }
    });
    
    document.getElementById('scene1-next-btn').addEventListener('click', function() {
      if (currentStep < totalSteps - 1) {
        currentStep++;
        updateDisplay();
      }
    });
    
    // 初始化
    updateDisplay();
  })();
  ```
