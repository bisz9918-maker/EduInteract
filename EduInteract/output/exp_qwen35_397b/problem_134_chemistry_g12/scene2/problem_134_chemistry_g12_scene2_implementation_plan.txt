[图示主题与整合说明]
- 本图示主题：四面体烷（A）的对称性与二氯代物分析
- 整合的内容：四面体结构展示、对称性演示、二氯代物取代位置分析

[分步序列]
- 步骤 0（初始状态）：显示完整四面体碳架结构（4 个顶点圆点，6 条棱线），右侧空白，控件"下一步"可用，"上一步"禁用
- 步骤 1：高亮左上顶点（250,150）和左下顶点（150,280）为蓝色#1565c0，显示标签"位置 1"和"位置 2"，右侧仍空白
- 步骤 2：显示灰色旋转箭头（380,200 附近），四面体轻微旋转动画（绕垂直轴旋转 15°×3 次），展示所有顶点可通过对称操作重合
- 步骤 3：在四面体上显示两个绿色氯原子圆点（位置 1 和位置 2），显示"Cl"标签，右侧开始绘制二氯代物结构简图
- 步骤 4（最终步骤）：右侧完整显示二氯代物结构（四面体 + 两个绿色 Cl 原子），左侧结论文本框出现，显示"二氯代物只有 1 种"红色加粗文字，"下一步"按钮变为"完成"

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - "上一步"按钮：位于 (280,455)，灰色，步骤 0 禁用，步骤 1-4 可用
  - "下一步"按钮：位于 (440,455)，蓝色，步骤 0-3 显示"下一步"，步骤 4 显示"完成"
  - 步骤指示器：位于 (380,465)，显示当前步骤/总步骤（如"1/5"）
- 教师操作流程：
  1. 初始展示四面体结构，讲解四面体烷的碳架特点
  2. 点击"下一步"，高亮两个顶点，提问"这两个位置是否等价？"
  3. 点击"下一步"，播放旋转动画，展示对称性，说明所有顶点可通过旋转重合
  4. 点击"下一步"，显示氯原子取代，讲解取代反应
  5. 点击"下一步"，显示结论，强调"只有 1 种二氯代物"

[技术实现]
- JS 库选择：原生 SVG（简单几何图形首选，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────┐
  │                                                         │
  │    [四面体结构]              [二氯代物结构]            │
  │       ▲                          ▲                     │
  │      / \                        / \                    │
  │     /   \                      /   \                   │
  │    /_____\                    /_____\                  │
  │   位置 1,2 标记                Cl 标记                  │
  │                                                         │
  │                              ┌──────────────┐          │
  │                              │二氯代物只有 1 种│          │
  │                              └──────────────┘          │
  │                                                         │
  │  ┌─────────────────────────────────────────────────┐   │
  │  │  [◀上一步]   步骤指示   [下一步▶/完成]        │   │
  │  └─────────────────────────────────────────────────┘   │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用 scene2-currentStep 变量跟踪当前步骤（0-4），每步调用 renderStep(n) 函数
  2. 坐标计算：四面体顶点坐标预定义为常量对象，便于动画插值
  3. 动画曲线：旋转动画用 requestAnimationFrame + 线性插值，每次旋转 15°，共 3 次
  4. 事件绑定：按钮点击事件绑定到 stepForward() 和 stepBack() 函数，更新状态后重绘
  5. 元素显隐：用 SVG 元素的 display 属性控制（display="none" / display="block"）
- ID 命名规范：所有元素 ID 以 scene2- 为前缀
  - scene2-tetrahedron-front-edge-1/2/3（前棱）
  - scene2-tetrahedron-back-edge-1/2/3（后棱）
  - scene2-vertex-top/left/right/back（顶点）
  - scene2-label-pos1/pos2（位置标签）
  - scene2-cl-atom-1/2（氯原子）
  - scene2-cl-label-1/2（氯标签）
  - scene2-rotate-arrow（旋转箭头）
  - scene2-dichloro-structure（二氯代物结构组）
  - scene2-conclusion-box/text（结论文本框）
  - scene2-btn-prev/next（按钮）
  - scene2-step-indicator（步骤指示）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
