[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单，无需复杂库；SVG 便于元素独立控制和动画
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  [电池]                                          |
  |     +                                            |
  |                          [烧杯]                  |
  |                          |====|                  |
  |  [灯泡]                   |A B|  ← 电极          |
  |                           |~~~|  ← 溶液          |
  |                           |   |                  |
  |                           |   |                  |
  |                                            [+][-]|
  |                                            离子  |
  |                                                  |
  |              电流方向                            |
  |                                                  |
  +--------------------------------------------------+
  |        [◀上一步]  步骤 X/3  [下一步▶]            |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：currentState (0-3)，steps 数组存储每步显示的元素 ID 列表
  2. 坐标计算：所有元素使用绝对坐标，SVG viewBox="0 0 800 500"
  3. 动画曲线：离子脉动使用 CSS animation，导线流动使用 SMIL 或 JS 更新
  4. 事件绑定：按钮点击事件切换状态，更新元素 display/opacity
  5. 灯泡发光：使用 SVG filter 实现外发光效果
- ID 命名规范：所有元素 ID 以 scene1- 为前缀
  - scene1-battery, scene1-bulb, scene1-beaker, scene1-solution
  - scene1-electrode-a, scene1-electrode-b
  - scene1-label-anode, scene1-label-cathode
  - scene1-cation-1~4, scene1-anion-1~4
  - scene1-arrow-cation, scene1-arrow-anion
  - scene1-btn-prev, scene1-btn-next, scene1-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
