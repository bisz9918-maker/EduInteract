- 本图示主题：四选项反应前后离子浓度对比——溶液导电性变化分析

[分步序列]
本场景为多状态切换交互，4 个状态对应 4 个选项：

状态 0（初始/默认 A）：
- 显示选项 A 内容
- 方程式："CH₃COOH + NH₃·H₂O → CH₃COONH₄ + H₂O"
- 反应前柱状图：CH₃COOH（弱电解质）显示少量 CH₃COO⁻(#2e7d32, 高度 20px) + H⁺(#c62828, 高度 20px)
- 反应后柱状图（恰好反应）：CH₃COONH₄（强电解质）显示大量 CH₃COO⁻(#2e7d32, 高度 80px) + NH₄⁺(#7b1fa2, 高度 80px)
- 导电性：反应前"弱"（灯泡暗#bdbdbd），反应后"强"（灯泡亮#ffd54f）
- 按钮 A 高亮

状态 1（点击 B）：
- 方程式："AgNO₃ + HCl → AgCl↓ + HNO₃"
- 反应前柱状图：Ag⁺(#ff9800, 60px) + NO₃⁻(#00bcd4, 60px)
- 反应后柱状图：H⁺(#c62828, 60px) + NO₃⁻(#00bcd4, 60px) + AgCl 沉淀符号(#888888)
- 导电性：反应前"中"，反应后"中"（离子总数变化不大）
- 按钮 B 高亮

状态 2（点击 C）：
- 方程式："HCl + NaCl → H⁺ + Cl⁻ + Na⁺ + Cl⁻"（混合，无反应）
- 反应前柱状图：H⁺(#c62828, 60px) + Cl⁻(#607d8b, 60px)
- 反应后柱状图：H⁺(#c62828, 50px) + Cl⁻(#607d8b, 70px) + Na⁺(新增，#ffa726, 50px)
- 导电性：反应前"中"，反应后"中强"（离子浓度增加或稀释）
- 按钮 C 高亮

状态 3（点击 D）：
- 方程式："H₂SO₄ + BaCl₂ → BaSO₄↓ + 2HCl"
- 反应前柱状图：H⁺(#c62828, 80px) + SO₄²⁻(#3f51b5, 40px) + Ba²⁺(#e91e63, 40px) + Cl⁻(#607d8b, 80px)
- 反应后柱状图：H⁺(#c62828, 80px) + Cl⁻(#607d8b, 80px) + BaSO₄ 沉淀符号
- 导电性：反应前"强"，反应后"中"（沉淀导致离子减少）
- 按钮 D 高亮

[交互方案]
- 交互类型：多状态切换（4 个选项按钮）
- 控件说明：
  - 按钮 A（80,450）：显示醋酸 + 氨水反应
  - 按钮 B（210,450）：显示 AgNO₃ + HCl 反应
  - 按钮 C（340,450）：显示盐酸 + NaCl 混合
  - 按钮 D（470,450）：显示 H₂SO₄ + BaCl₂ 反应
- 教师操作流程：
  1. 初始显示选项 A，讲解弱电解质反应生成强电解质导电性增强
  2. 依次点击 B/C/D，对比各选项离子变化
  3. 引导学生发现只有 A 符合"先增大后减弱"（过量氨水稀释）
  4. 强调沉淀反应（B/D）离子减少，混合（C）离子变化平缓

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：柱状图为简单矩形堆叠，无需复杂库；状态切换逻辑简单
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [800×500 画布]
  ┌────────────────────────────────────────────────────┐
  │           溶液导电性变化对比 (标题 y=35)            │
  ├────────────────────────────────────────────────────┤
  │        化学反应方程式 (居中 y=80)                   │
  ├────────────────────────────────────────────────────┤
  │     反应前          │          反应后              │
  │    ┌─────┐         │         ┌─────┐              │
  │    │离子 │         │         │离子 │              │
  │    │柱状 │         │         │柱状 │              │
  │    │ 图  │         │         │ 图  │              │
  │    └─────┘         │         └─────┘              │
  │   (200,230)        │        (600,230)             │
  ├────────────────────────────────────────────────────┤
  │  离子图例 (左下)    │    导电性指示 (右下)          │
  │  H⁺■ OH⁻■ ...     │       💡 强/中/弱             │
  ├────────────────────────────────────────────────────┤
  │  [A]    [B]    [C]    [D]    (按钮 y=450-485)      │
  └────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用 currentState 变量(0-3)跟踪当前选项
  2. 数据驱动：定义 optionsData 数组存储 4 个选项的方程式、离子数据、导电性等级
  3. 柱状图渲染：根据离子浓度数据动态计算 rect 高度和 y 位置（从下往上堆叠）
  4. 灯泡渲染：根据导电性等级切换 fill 颜色（#ffd54f 亮 / #bdbdbd 暗）
  5. 按钮高亮：选中按钮添加蓝色边框和背景
  6. 事件绑定：4 个按钮分别绑定 click 事件，调用 updateScene(optionIndex)
- ID 命名规范：
  - 场景容器：scene2-container
  - 方程式：scene2-equation
  - 反应前柱状图组：scene2-bar-before
  - 反应后柱状图组：scene2-bar-after
  - 灯泡：scene2-bulb
  - 导电性文字：scene2-conductivity-text
  - 按钮：scene2-btn-a, scene2-btn-b, scene2-btn-c, scene2-btn-d
  - 图例区：scene2-legend
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
- 动画效果：状态切换时柱状图高度变化使用 CSS transition（0.3s ease）
