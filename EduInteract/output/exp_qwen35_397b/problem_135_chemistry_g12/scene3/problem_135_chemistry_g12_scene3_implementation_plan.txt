[图示主题与整合说明]
- 本图示主题：溶液导电性变化曲线图
- 整合内容：四个选项导电性随加入试剂体积的变化曲线对比（A.醋酸+氨水、B.AgNO₃+HCl、C.盐酸+NaCl、D.H₂SO₄+BaCl₂）

[分步序列]
- 初始状态（步骤0）：显示空坐标系（坐标轴、网格线、轴标签、原点O），图例框（仅边框和标题），不显示任何曲线
- 步骤1：点击「下一步」→ 显示曲线A（红色实线）、峰值点标记(400,100)、峰值标签"最大导电性"、起点标注"起始点"，图例A高亮（加粗边框）
- 步骤2：点击「下一步」→ 新增曲线B（蓝色虚线），图例B高亮，曲线A保持显示但取消高亮
- 步骤3：点击「下一步」→ 新增曲线C（绿色点划线），图例C高亮，曲线A、B保持显示
- 步骤4：点击「下一步」→ 新增曲线D（紫色点线），图例D高亮，所有曲线显示
- 步骤5（最终）：四条曲线全部显示，曲线A重新高亮（加粗+峰值点闪烁），图例A高亮，展示完整对比效果
（教师可随时点击「上一步」回退复习）

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮：位于(260,460)，点击后返回前一状态，步骤0时禁用
  - 下一步按钮：位于(460,460)，点击后进入下一状态，步骤5时禁用
  - 步骤指示：位于(380,470)，显示当前步骤"步骤 X/5"
- 教师操作流程：
  1. 初始展示空坐标系，讲解坐标轴含义（横轴为加入试剂体积，纵轴为导电性）
  2. 点击「下一步」展示曲线A，讲解醋酸（弱电解质）+氨水（弱电解质）→醋酸铵（强电解质）导电性上升，过量氨水稀释后导电性下降
  3. 点击「下一步」展示曲线B，讲解AgNO₃+HCl→AgCl沉淀+HNO₃，离子浓度变化不大，导电性基本不变
  4. 点击「下一步」展示曲线C，讲解盐酸+NaCl，同离子效应，导电性缓慢上升
  5. 点击「下一步」展示曲线D，讲解H₂SO₄+BaCl₂→BaSO₄沉淀+2HCl，离子浓度变化不大
  6. 最终对比四条曲线，强调A为正确答案（先增大后减弱）

[技术实现]
- JS 库选择：原生 SVG（曲线绘制简单，无需复杂库）+ 原生 JS（状态管理）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +----------------------------------------------------------+
  |                                                          |
  |   导电性κ                                                 |
  |     ↑                                    ┌───────────┐   |
  |     |                                    │图例       │   |
  |     |     A曲线(峰形)                    │A:醋酸+氨水│   |
  |     |    ╱╲                              │B:AgNO₃+HCl│   |
  |     |   ╱  ╲  B曲线(水平)───────────────│C:盐酸+NaCl│   |
  |     |  ╱    ╲C曲线(缓升)────────────────│D:H₂SO₄+...│   |
  |     | ╱      ╲D曲线(水平)───────────────└───────────┘   |
  |     |╱                                                    |
  |     O────────────────────────────────→ 加入试剂体积 V/mL  |
  |                                                          |
  |                                                          |
  |              [◀上一步]  步骤 X/5  [下一步▶]              |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-5) 跟踪当前步骤，数组 curvesVisible 控制各曲线显示状态
  2. 曲线绘制：使用 SVG <path> 元素，d 属性定义路径，曲线A用二次贝塞尔曲线或折线近似峰形
  3. 动画曲线：曲线出现时使用 stroke-dasharray + stroke-dashoffset 实现绘制动画（duration: 800ms）
  4. 事件绑定：按钮点击事件绑定到 stepForward() 和 stepBackward() 函数，更新状态后重绘
  5. 高亮效果：曲线A高亮时，stroke-width 从3px增至4px，峰值点添加 CSS 闪烁动画
- ID 命名规范：所有元素 ID 以 scene3- 为前缀
  - scene3-coord-system, scene3-grid, scene3-xaxis, scene3-yaxis
  - scene3-curve-a, scene3-curve-b, scene3-curve-c, scene3-curve-d
  - scene3-peak-point, scene3-peak-label, scene3-start-label
  - scene3-legend-box, scene3-legend-a, scene3-legend-b, scene3-legend-c, scene3-legend-d
  - scene3-btn-prev, scene3-btn-next, scene3-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
