[分步序列]
- 初始状态（步骤0）：显示图例区（H原子图例、C原子图例、未知原子图例），分子链区域空白。教师可先介绍原子类型识别方法。
- 步骤1：点击「下一步」→ 显示完整分子骨架（1个H原子+9个C原子+1个未知原子，以及连接它们的化学键）。教师讲解分子整体结构。
- 步骤2：点击「下一步」→ 高亮显示标注①②③位置（蓝色圆圈环绕对应位置，下方显示标注文字）。教师讲解关键化学键位置。
- 步骤3：点击「下一步」→ 显示碳原子编号C1-C9（在各碳原子上方显示对应编号）。教师讲解碳链编号规则，便于后续分析化学键类型。

[标签冲突检查]
- 标签"氢原子"：坐标(100,295)
- 标签"碳原子"：坐标(200,295)
- 标注"①"：坐标(375,330)
- 标注"②"：坐标(525,330)
- 标注"③"：坐标(600,330)
- 碳编号"C1"~"C9"：坐标y=225，x从150到550

冲突检查：
- "氢原子"(100,295)与"碳原子"(200,295)：水平间距100px → 无冲突
- "碳原子"(200,295)与标注"①"(375,330)：水平间距175px，垂直间距35px → 无冲突
- 标注"①"(375,330)与标注"②"(525,330)：水平间距150px → 无冲突
- 标注"②"(525,330)与标注"③"(600,330)：水平间距75px → 无冲突
- 碳编号C1-C9(y=225)与原子圆(y=250)：垂直间距25px（圆心到编号底部约12px）→ 无冲突
- 碳编号之间：水平间距50px，每个编号宽约20px → 间距30px，无冲突
- 图例区(y=380-430)与标注区(y=330)：垂直间距50px → 无冲突
- 所有标签与原子圆：最小垂直间距25px（上方编号）或45px（下方标签）→ 无冲突

结论：所有标签间距均≥20px，无重叠冲突。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于(300,460)，宽80px，高30px，点击后退到前一状态
  - 「下一步」按钮：位于(420,460)，宽80px，高30px，点击前进到下一状态
  - 步骤指示器：位于(390,460)，显示"步骤X/4"
- 教师操作流程：
  1. 初始加载后，先讲解图例（白球=H、黑球=C、条纹球=未知原子）
  2. 点击「下一步」展示完整分子链，讲解碳链骨架结构
  3. 点击「下一步」高亮①②③位置，引导学生关注关键化学键
  4. 点击「下一步」显示碳原子编号，讲解编号规则及后续题目分析
  5. 可随时点击「上一步」回退复习

[技术实现]
- JS 库选择及原因：原生SVG。理由：分子结构由简单的圆和线段组成，SVG矢量图形清晰，无需复杂动画库。
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |                    C1 C2 ... C9                  |  y=225 碳编号区
  |   ○━━●━━●━━●━━●━━●━━●━━●━━●━━●━━◍              |  y=250 分子链
  |                                                  |
  |  氢原子  碳原子                                  |  y=295 原子标签
  |              ①       ②    ③                     |  y=330 位置标注
  |                                                  |
  |  图例: ○=H  ●=C  ◍=未知                          |  y=400 图例区
  |                                                  |
  |          [◀上一步]  步骤X/4  [下一步▶]           |  y=460 控件栏
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量currentStep(0-3)跟踪当前步骤，steps数组定义每步显示的元素ID列表
  2. 坐标计算：原子圆心x坐标=100+stepIndex*50，y=250固定
  3. 条纹填充：使用SVG pattern定义斜线填充，应用于未知原子圆
  4. 事件绑定：按钮点击事件调用stepForward()/stepBackward()，更新display属性
  5. 初始状态：步骤0仅显示图例区元素，分子链元素display="none"
- ID 命名规范：所有元素ID以scene1-为前缀
  - scene1-h-atom, scene1-c1~scene1-c9, scene1-unknown-atom
  - scene1-bond1~scene1-bond10（化学键）
  - scene1-label-h, scene1-label-c（原子标签）
  - scene1-mark1, scene1-mark2, scene1-mark3（位置标注）
  - scene1-legend-h, scene1-legend-c, scene1-legend-unknown（图例）
  - scene1-carbon-num1~scene1-carbon-num9（碳编号）
  - scene1-btn-prev, scene1-btn-next, scene1-step-indicator（控件）
- IIFE 隔离：所有JS代码包在(function() { ... })()中，避免全局变量污染
