[图示主题与整合说明]
- 本图示主题：碳链成键分析与化学键类型推导
- 整合的步骤/概念：碳四价原则应用、化学键类型推导、①②处键型判断
- 教学价值：教师可逐步展示从分子左端到右端的成键推导过程，每一步聚焦一个碳原子的价键分析，帮助学生理解碳四价原则如何决定化学键类型。通过高亮当前推导步骤和已确定的键型，学生能清晰看到交替的单键-三键模式形成过程，最终得出①处为三键、②处为单键的结论。

  ```
  |         [◀上一步]  步骤X/9  [下一步▶]            |
  |              (控件栏 y=440~490)                   |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0~9) 跟踪当前步骤
  2. 键型数组：bondTypes = ['单','三','单','三','单','三','单','三','单','三'] 对应10个键
  3. 三键绘制：用三条平行线段（间距2px）表示
  4. 高亮逻辑：当前推导的碳原子用蓝色圆圈包围，已确定的键用绿色
  5. 事件绑定：按钮点击事件更新 currentStep，重绘相关元素
- ID 命名规范：所有元素 ID 以 scene2- 为前缀，如 scene2-atom-c1、scene2-bond-c1c2、scene2-btn-next
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
