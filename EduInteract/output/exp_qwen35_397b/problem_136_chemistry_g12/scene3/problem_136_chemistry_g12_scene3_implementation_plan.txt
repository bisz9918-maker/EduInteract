[分步序列]
多状态切换交互，4个状态对应4个选项分析：

- 初始状态（无选项激活）：
  - 显示完整分子结构图（重现题目图片）
  - 显示4个选项卡片轮廓（灰色边框，无背景色）
  - 卡片内仅显示选项字母和题干文字，无分析内容
  - 无判断标记

- 状态1（点击按钮A）：
  - 选项A卡片背景变为浅红#ffcdd2
  - 显示分析文字："此分子含③处非C、H原子，不属于烃类"
  - 右上角显示红色✗标记
  - 分子图中③处原子高亮（加粗边框）
  - 其他选项卡片保持灰色轮廓

- 状态2（点击按钮B）：
  - 选项A恢复灰色轮廓
  - 选项B卡片背景变为浅红#ffcdd2
  - 显示分析文字："①处为碳碳三键，非双键"
  - 右上角显示红色✗标记
  - 分子图中①处化学键高亮（加粗或变色）
  - 其他选项卡片保持灰色轮廓

- 状态3（点击按钮C）：
  - 选项B恢复灰色轮廓
  - 选项C卡片背景变为浅绿#c8e6c9
  - 显示分析文字："②处为碳碳单键，正确"
  - 右上角显示绿色✓标记
  - 分子图中②处化学键高亮
  - 其他选项卡片保持灰色轮廓

- 状态4（点击按钮D）：
  - 选项C恢复灰色轮廓
  - 选项D卡片背景变为浅红#ffcdd2
  - 显示分析文字："③处与C形成单键，但根据碳四价原则，此处应为H或卤素，需结合整体结构判断"
  - 右上角显示红色✗标记
  - 分子图中③处原子及C9-C8键高亮
  - 其他选项卡片保持灰色轮廓

[交互方案]
- 交互类型：多状态切换（4个按钮，每次激活一个选项）
- 控件说明：
  - 按钮A：位置(60, 450)，尺寸160×35，文字"选项A"，点击显示A的分析
  - 按钮B：位置(230, 450)，尺寸160×35，文字"选项B"，点击显示B的分析
  - 按钮C：位置(400, 450)，尺寸160×35，文字"选项C"，点击显示C的分析
  - 按钮D：位置(570, 450)，尺寸160×35，文字"选项D"，点击显示D的分析
- 教师操作流程：
  1. 初始状态展示分子结构，让学生观察
  2. 点击"选项A"，讲解烃类定义（仅含C、H），指出③处非C、H原子
  3. 点击"选项B"，讲解①处化学键类型（三键非双键）
  4. 点击"选项C"，确认②处为单键，标记正确✓
  5. 点击"选项D"，讲解③处原子成键分析
  6. 可重复点击任一选项复习

[技术实现]
- JS库选择：原生SVG + 原生JavaScript
  - 原因：几何图形简单（圆圈、线段、矩形），无需复杂库；状态切换逻辑简单
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────┐
  │  [分子结构区 y=80-260]                              │
  │   H—C—C—C—C—C—C—C—C—C—③                            │
  │        ①       ②                                   │
  │                                                     │
  │  ┌──────选项A──────┐ ┌──────选项B──────┐           │
  │  │ 分析文字    ✗   │ │ 分析文字    ✗   │           │
  │  └─────────────────┘ └─────────────────┘           │
  │  ┌──────选项C──────┐ ┌──────选项D──────┐           │
  │  │ 分析文字    ✓   │ │ 分析文字    ✗   │           │
  │  └─────────────────┘ └─────────────────┘           │
  │                                                     │
  │  [按钮A] [按钮B] [按钮C] [按钮D]  (y=440-490)       │
  └─────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量currentState存储当前激活的选项('none'/'A'/'B'/'C'/'D')
  2. 每个选项卡片包含：背景矩形、选项文字、分析文字组、判断标记组
  3. 分析文字和判断标记初始display='none'，激活时display='block'
  4. 分子图高亮：对应原子/化学键的stroke-width从2变为4，或stroke变色
  5. 按钮点击事件：先重置所有卡片为灰色轮廓，再激活目标卡片
  6. 按钮样式：当前激活状态的按钮背景色加深表示选中
- ID命名规范：
  - 所有元素ID以scene3-为前缀
  - 分子元素：scene3-atom-h, scene3-atom-c1~c9, scene3-atom-x3
  - 化学键：scene3-bond-1~10
  - 标注：scene3-label-1, scene3-label-2, scene3-label-3
  - 卡片：scene3-card-a, scene3-card-b, scene3-card-c, scene3-card-d
  - 判断标记：scene3-mark-a, scene3-mark-b, scene3-mark-c, scene3-mark-d
  - 分析文字：scene3-analysis-a, scene3-analysis-b, scene3-analysis-c, scene3-analysis-d
  - 按钮：scene3-btn-a, scene3-btn-b, scene3-btn-c, scene3-btn-d
- IIFE隔离：所有JS代码包在(function() { ... })()中，避免全局变量污染
