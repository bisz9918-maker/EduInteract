[图示主题与整合说明]
- 本图示主题：选项 C 反应计量的专项对比展示
- 整合的内容：H₂加成位点计数、NaOH 水解位点计数、错误选项可视化纠正
- 教学价值：教师可通过三状态切换，直观对比 H₂加成与 NaOH 水解的不同反应位点，帮助学生理解为何选项 C 中"5 mol H₂"是错误的（实际为 4 mol），而"3 mol NaOH"是正确的。通过高亮显示和计量标注，学生能清晰看到每种反应的具体位置和数量。

[分步序列]
- 初始状态（步骤 0）：显示分子骨架结构（黑色实线），无高亮，无标注，等待教师选择状态
- 状态 1（H₂加成）：
  - 显示 4 个双键高亮区域（蓝色半透明）
  - 每个双键上方显示"+1 mol H₂"标注
  - 底部显示"总计：4 mol H₂"
  - 酯基高亮和 NaOH 标注隐藏
- 状态 2（NaOH 水解）：
  - 显示 3 个酯基高亮区域（红色半透明）
  - 每个酯基附近显示"+1 mol NaOH"标注
  - 底部显示"总计：3 mol NaOH"
  - 双键高亮和 H₂标注隐藏
- 状态 3（对比纠错）：
  - 分子骨架恢复默认（无高亮）
  - 显示对比表格：左侧"正确值：4 mol H₂ / 3 mol NaOH"（带绿色✓），右侧"选项 C：5 mol H₂ / 3 mol NaOH"（5 mol H₂旁带红色✗）
  - 底部无总计文本

冲突检查：
- H₂标注 1(220,185) 与 NaOH 标注 1(150,165)：距离≈76px → 无冲突
- H₂标注 2(400,205) 与 NaOH 标注 2(320,125)：距离≈113px → 无冲突
- H₂标注 3(500,225) 与 H₂标注 4(560,245)：距离≈63px → 无冲突
- NaOH 标注 3(340,325) 与 H₂总计 (400,400)：距离≈96px → 无冲突
- H₂总计 (400,400) 与 NaOH 总计 (400,425)：垂直距离 25px → 无冲突（状态 1/2 不同时显示）
- 所有标注与分子骨架距离≥15px → 无冲突

解决方案：状态 1 和状态 2 的标注不会同时显示，状态 3 使用独立对比表格区域，所有标签间距均≥20px，无重叠风险。

[交互方案]
- 交互类型：多状态切换（3 个按钮）
- 控件说明：
  - 按钮 1 "H₂加成"：位置 (180,455)，点击后显示双键高亮和 H₂计量标注
  - 按钮 2 "NaOH 水解"：位置 (340,455)，点击后显示酯基高亮和 NaOH 计量标注
  - 按钮 3 "对比纠错"：位置 (500,455)，点击后显示对比表格和对错标记
- 教师操作流程：
  1. 初始加载后，教师先展示分子骨架，让学生观察结构
  2. 点击"H₂加成"，引导学生数出 4 个碳碳双键，理解 4 mol H₂的来源
  3. 点击"NaOH 水解"，引导学生数出 3 个酯基，理解 3 mol NaOH 的来源
  4. 点击"对比纠错"，展示正确值与选项 C 的对比，明确指出"5 mol H₂"是错误的

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：分子结构为 2D 静态图形，只需简单的显示/隐藏切换，无需复杂动画或 3D 效果
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |              分子骨架结构（居中）                  |
  |         双键/酯基高亮区域 + 计量标注               |
  |                                                  |
  |              [状态 3 对比表格]                     |
  |                                                  |
  |        [H₂加成]  [NaOH 水解]  [对比纠错]          |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（1/2/3），点击按钮时更新状态并重新渲染
  2. 所有高亮区域和标注预先绘制在 SVG 中，通过 display 属性控制显示/隐藏
  3. 按钮激活状态：当前状态按钮高亮（背景色加深），其他按钮默认样式
  4. 坐标计算：分子骨架路径根据图片中的实际结构手动绘制，确保双键和酯基位置准确
- ID 命名规范：所有元素 ID 以 scene2- 为前缀
  - 分子骨架：scene2-molecule-skeleton
  - 双键高亮：scene2-double-bond-1/2/3/4
  - 酯基高亮：scene2-ester-1/2/3
  - H₂标注：scene2-h2-label-1/2/3/4
  - NaOH 标注：scene2-naoh-label-1/2/3
  - 总计文本：scene2-h2-total / scene2-naoh-total
  - 对比表格：scene2-comparison-table
  - 按钮：scene2-btn-h2 / scene2-btn-naoh / scene2-btn-compare
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
