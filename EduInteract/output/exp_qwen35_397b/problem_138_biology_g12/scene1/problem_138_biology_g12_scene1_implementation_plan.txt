[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript
  - 原因：本场景为流程图，几何元素简单（矩形、线段、箭头、文本），无需复杂库
  - 箭头用 marker-end 实现，高亮通过修改 stroke 和 stroke-width 实现
  - 状态切换通过显示/隐藏元素和控制样式实现

- 画布尺寸：800 × 500 px（固定）

- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +----------------------------------------------------------+
  |  [植株甲]  →①→ [无种子]                                  |
  |     |                                                    |
  |     →②→ [有种子]                                         |
  |  [植株乙]  →③→ [单倍体] →④→ [二倍体]                     |
  |                                                          |
  |  [============================================]          |
  |  [  概念标签：当前处理的生物学含义说明            ]          |
  |  [============================================]          |
  |                                                          |
  |              [◀ 上一步]        [下一步 ▶]                |
  +----------------------------------------------------------+
  ```

- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-4) 跟踪当前步骤
  2. 状态数组：定义每个步骤的高亮元素 ID 列表和概念标签文本
  3. 高亮实现：通过 getElementById 获取元素，修改 style.stroke 和 style.strokeWidth
  4. 概念标签更新：每步更新 textContent
  5. 按钮状态：步骤0禁用上一步，步骤4禁用下一步
  6. 箭头定义：使用 <marker> 定义箭头样式，line 元素用 marker-end 引用

- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀
  - scene1-plant-a-frame, scene1-plant-a-icon, scene1-plant-a-label, scene1-plant-a-genotype
  - scene1-plant-b-frame, scene1-plant-b-icon, scene1-plant-b-label, scene1-plant-b-genotype
  - scene1-arrow-1, scene1-label-1, scene1-result-1, scene1-result-1-text
  - scene1-arrow-2, scene1-label-2, scene1-result-2, scene1-result-2-text
  - scene1-arrow-3, scene1-label-3, scene1-result-3, scene1-result-3-text
  - scene1-arrow-4, scene1-label-4, scene1-result-4, scene1-result-4-text
  - scene1-concept-box, scene1-concept-text
  - scene1-btn-prev, scene1-btn-next

- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
