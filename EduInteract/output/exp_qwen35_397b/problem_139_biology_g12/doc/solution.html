题目原文：

某植物的花色由两对独立遗传的等位基因A、a和B、b控制，A对a、B对b完全显性，基因A、B控制花色的生化作用机制如下图所示。回答下列问题：

（1）图中①、②过程合称。图示反映了基因与生物性状的关系是_。

（2）用纯合紫花和纯合蓝花为亲本杂交得F₁，F₁自交得F₂，将F₂中的白花个体收获后，每株的所有种子单独种植在一起得到一个株系，所有株系中，子代表现出紫花：蓝花：白花=3：3：10的株系比例为，若让子代所有紫花植株测交，后代的性状及比例是__。

（3）现有一株白花植株，在种植过程中发现白花植株因基因突变使其一个白色花瓣上出现蓝色斑点，此植株可能的基因型有__。

题目分析：

本题考查基因互作控制性状的遗传规律。核心机制：

  • 基因A控制酶A合成，催化白色前体→紫色色素
  • 基因B控制酶B合成，催化白色前体→蓝色色素
  • A、B同时存在时，两种mRNA结合，酶A、酶B均不能合成→白色

基因型与表现型对应关系：

  • AB：白色（双显性，酶被抑制）
  • A_bb：紫色（只有酶A）
  • aaB_：蓝色（只有酶B）
  • aabb：白色（双隐性，无酶）

整体讲解思路：

  1. 首先通过图示理解基因表达过程（转录①、翻译②）和色素合成路径
  2. 明确基因型与表现型的对应关系
  3. 分析F₂代遗传比例，重点讲解白花个体的基因型组成
  4. 讨论基因突变导致性状改变的可能情况

教学说明：

本图示用于讲解第（1）问，帮助学生理解基因如何控制性状。

引导要点：

  1. 过程①是转录（DNA→mRNA），过程②是翻译（mRNA→蛋白质/酶），合称为基因的表达
  2. 基因通过控制酶的合成来控制代谢过程，进而控制生物性状
  3. 强调基因互作：当A、B同时存在时，两种mRNA相互结合，导致翻译受阻，酶无法合成

关键公式：

  • 基因A存在且B不存在（A_bb）→ 酶A合成 → 白色前体→紫色色素
  • 基因B存在且A不存在（aaB_）→ 酶B合成 → 白色前体→蓝色色素
  • A、B同时存在（AB）→ mRNA结合 → 无酶 → 白色
  • aabb → 无酶 → 白色

教学说明：

本图示用于讲解第（2）问的遗传计算，是本题的核心难点。

推导步骤：

  1. 亲本：纯合紫花（AAbb）× 纯合蓝花（aaBB）→ F₁：AaBb（白色）
  2. F₁自交：AaBb × AaBb → F₂基因型比例9AB : 3Abb : 3aaB : 1aabb
  3. 表现型比例：白色（9+1=10）: 紫色（3）: 蓝色（3）= 10:3:3
  4. F₂中白花个体基因型及比例（共10份）：
  • AABB：1/16 → 占白花的1/10
  • AABb：2/16 → 占白花的2/10
  • AaBB：2/16 → 占白花的2/10
  • AaBb：4/16 → 占白花的4/10
  • aabb：1/16 → 占白花的1/10
  1. 各白花株系自交后代：
  • AABB自交→ 全白
  • AABb自交→ 3白:1紫
  • AaBB自交→ 3白:1蓝
  • AaBb自交→ 10白:3紫:3蓝（目标株系）
  • aabb自交→ 全白
  1. 子代出现3:3:10的株系是AaBb，占白花株系的4/10 = 2/5

紫花植株测交：
F₂紫花基因型：1/3 AAbb + 2/3 Aabb
测交（×aabb）后代：

  • AAbb × aabb → 全紫（Aabb）
  • Aabb × aabb → 1紫（Aabb）: 1白（aabb）

综合：紫花:白花 = (1/3×1 + 2/3×1/2) : (2/3×1/2) = 2/3 : 1/3 = 2:1

教学说明：

本图示用于讲解第（3）问，分析基因突变导致性状改变的可能情况。

关键分析：
蓝色斑点出现意味着该细胞能合成酶B，即B基因表达且A基因不表达。

白花植株可能的基因型：

  1. AB型：若体细胞中A基因突变为a，则该细胞基因型变为aB_，可合成酶B→蓝色斑点
  2. aabb型：若体细胞中b基因突变为B，则该细胞基因型变为aaB_，可合成酶B→蓝色斑点
  3. A_bb型：理论上为紫花，但若题目考虑特殊情况（如A基因突变失活），也可能出现

答案： 白花植株可能的基因型有 AABB、AABb、AaBB、AaBb、aabb（即所有白花基因型都可能，只要发生适当突变）

更精确答案： 能产生蓝色斑点的突变要求突变后细胞为aaB_，因此：

  • AB植株：A→a突变
  • aabb植株：b→B突变
  • Abb植株：无法通过单次突变产生aaB

故答案为：AABB、AABb、AaBB、AaBb、aabb
