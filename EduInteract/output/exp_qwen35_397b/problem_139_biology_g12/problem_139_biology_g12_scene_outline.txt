    **题目原文：**

    某植物的花色由两对独立遗传的等位基因A、a和B、b控制，A对a、B对b完全显性，基因A、B控制花色的生化作用机制如下图所示。回答下列问题：

    （1）图中①、②过程合称_____________。图示反映了基因与生物性状的关系是____________。

    （2）用纯合紫花和纯合蓝花为亲本杂交得F₁，F₁自交得F₂，将F₂中的白花个体收获后，每株的所有种子单独种植在一起得到一个株系，所有株系中，子代表现出紫花：蓝花：白花=3：3：10的株系比例为______，若让子代所有紫花植株测交，后代的性状及比例是______________________。

    （3）现有一株白花植株，在种植过程中发现白花植株因基因突变使其一个白色花瓣上出现蓝色斑点，此植株可能的基因型有__________________。

    **题目分析：**

    本题考查基因互作控制性状的遗传规律。核心机制：
    - 基因A控制酶A合成，催化白色前体→紫色色素
    - 基因B控制酶B合成，催化白色前体→蓝色色素
    - A、B同时存在时，两种mRNA结合，酶A、酶B均不能合成→白色

    基因型与表现型对应关系：
    - A_B_：白色（双显性，酶被抑制）
    - A_bb：紫色（只有酶A）
    - aaB_：蓝色（只有酶B）
    - aabb：白色（双隐性，无酶）

    **整体讲解思路：**
    1. 首先通过图示理解基因表达过程（转录①、翻译②）和色素合成路径
    2. 明确基因型与表现型的对应关系
    3. 分析F₂代遗传比例，重点讲解白花个体的基因型组成
    4. 讨论基因突变导致性状改变的可能情况

    **图示规划说明：**
    - SCENE_1：基因表达与色素合成机制图，整合转录翻译过程和代谢路径
    - SCENE_2：基因型-表现型对应关系图，展示四种基因组合的结果
    - SCENE_3：F₂代遗传分析图，展示杂交过程和比例计算
    </TEXT_1>

    **教学说明：**

    本图示用于讲解第（2）问的遗传计算，是本题的核心难点。

    **推导步骤：**
    1. 亲本：纯合紫花（AAbb）× 纯合蓝花（aaBB）→ F₁：AaBb（白色）
    2. F₁自交：AaBb × AaBb → F₂基因型比例9A_B_ : 3A_bb : 3aaB_ : 1aabb
    3. 表现型比例：白色（9+1=10）: 紫色（3）: 蓝色（3）= 10:3:3
    4. F₂中白花个体基因型及比例（共10份）：
       - AABB：1/16 → 占白花的1/10
       - AABb：2/16 → 占白花的2/10
       - AaBB：2/16 → 占白花的2/10
       - AaBb：4/16 → 占白花的4/10
       - aabb：1/16 → 占白花的1/10
    5. 各白花株系自交后代：
       - AABB自交→ 全白
       - AABb自交→ 3白:1紫
       - AaBB自交→ 3白:1蓝
       - AaBb自交→ 10白:3紫:3蓝（目标株系）
       - aabb自交→ 全白
    6. 子代出现3:3:10的株系是AaBb，占白花株系的**4/10 = 2/5**

    **紫花植株测交：**
    F₂紫花基因型：1/3 AAbb + 2/3 Aabb
    测交（×aabb）后代：
    - AAbb × aabb → 全紫（Aabb）
    - Aabb × aabb → 1紫（Aabb）: 1白（aabb）
    综合：紫花:白花 = (1/3×1 + 2/3×1/2) : (2/3×1/2) = 2/3 : 1/3 = 2:1
    </TEXT_4>

    <TEXT_5>
    **教学说明：**

    本图示用于讲解第（3）问，分析基因突变导致性状改变的可能情况。

    **关键分析：**
    蓝色斑点出现意味着该细胞能合成酶B，即B基因表达且A基因不表达。

    **白花植株可能的基因型：**
    1. **A_B_型**：若体细胞中A基因突变为a，则该细胞基因型变为aB_，可合成酶B→蓝色斑点
    2. **aabb型**：若体细胞中b基因突变为B，则该细胞基因型变为aaB_，可合成酶B→蓝色斑点
    3. **A_bb型**：理论上为紫花，但若题目考虑特殊情况（如A基因突变失活），也可能出现

    **答案：** 白花植株可能的基因型有 **AABB、AABb、AaBB、AaBb、aabb**（即所有白花基因型都可能，只要发生适当突变）

    **更精确答案：** 能产生蓝色斑点的突变要求突变后细胞为aaB_，因此：
    - A_B_植株：A→a突变
    - aabb植株：b→B突变
    - A_bb植株：无法通过单次突变产生aaB_

    故答案为：**AABB、AABb、AaBB、AaBb、aabb**
    </TEXT_5>
