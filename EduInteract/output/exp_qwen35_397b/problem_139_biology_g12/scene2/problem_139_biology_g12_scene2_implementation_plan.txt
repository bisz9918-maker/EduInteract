[图示主题与整合说明]
- 本图示主题：基因型与表现型对应关系
- 整合内容：四种基因组合类型（A_B_、A_bb、aaB_、aabb）及其对应的花色表现、酶合成情况、代谢路径
- 教学价值：教师可通过切换四种基因型状态，直观展示不同基因组合如何影响酶的合成，进而决定花色表现型。便于分类讨论 F2 代中不同基因型的表现型比例计算，帮助学生理解"基因通过控制酶的合成来控制代谢过程，从而控制生物性状"这一核心概念。

[分步序列]
本场景为多状态切换交互，无分步序列，通过底部按钮切换 4 个状态：

状态 0（初始/默认）：显示全部四个卡片的完整信息，按钮 1 高亮
状态 1（点击按钮 1）：高亮卡片 1（A_B_），其他卡片半透明
  - 酶 A: ×（红色），酶 B: ×（红色）
  - 代谢路径：白色前体物质 → 无酶催化 → 白色
  - 花色：白色圆形图标
状态 2（点击按钮 2）：高亮卡片 2（A_bb），其他卡片半透明
  - 酶 A: ✓（绿色），酶 B: ×（红色）
  - 代谢路径：白色前体物质 → 酶 A 催化 → 紫色色素
  - 花色：紫色圆形图标
状态 3（点击按钮 3）：高亮卡片 3（aaB_），其他卡片半透明
  - 酶 A: ×（红色），酶 B: ✓（绿色）
  - 代谢路径：白色前体物质 → 酶 B 催化 → 蓝色色素
  - 花色：蓝色圆形图标
状态 4（点击按钮 4）：高亮卡片 4（aabb），其他卡片半透明
  - 酶 A: ×（红色），酶 B: ×（红色）
  - 代谢路径：白色前体物质 → 无酶催化 → 白色
  - 花色：白色圆形图标

[交互方案]
- 交互类型：多状态切换（4 个按钮）
- 控件说明：
  - 按钮 1（scene2-btn-1）：位置 (80,450)，文字"A_B_ 白色"，点击显示 A_B_ 基因型对应状态
  - 按钮 2（scene2-btn-2）：位置 (250,450)，文字"A_bb 紫色"，点击显示 A_bb 基因型对应状态
  - 按钮 3（scene2-btn-3）：位置 (420,450)，文字"aaB_ 蓝色"，点击显示 aaB_ 基因型对应状态
  - 按钮 4（scene2-btn-4）：位置 (590,450)，文字"aabb 白色"，点击显示 aabb 基因型对应状态
- 教师操作流程：
  1. 初始状态展示四种基因型的完整对比
  2. 点击按钮 1，讲解 A_B_ 为何表现为白色（两种 mRNA 结合，酶 A、B 均不能合成）
  3. 点击按钮 2，讲解 A_bb 为何表现为紫色（有酶 A 无酶 B，合成紫色色素）
  4. 点击按钮 3，讲解 aaB_ 为何表现为蓝色（无酶 A 有酶 B，合成蓝色色素）
  5. 点击按钮 4，讲解 aabb 为何表现为白色（无酶 A 无酶 B，无法合成色素）
  6. 可反复切换对比，帮助学生理解基因型与表现型的对应关系

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：图形简单（矩形、圆形、文字、箭头），无需复杂库；状态切换逻辑简单，原生 JS 足够
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +------------------------------------------+
  |  +------------+    +------------+        |
  |  |  A_B_      |    |  A_bb      |        |
  |  |  酶A×酶B×  |    |  酶A✓酶B×  |        | y=40~220
  |  |  白色花    |    |  紫色花    |        |
  |  +------------+    +------------+        |
  |                                          |
  |  +------------+    +------------+        |
  |  |  aaB_      |    |  aabb      |        |
  |  |  酶A×酶B✓  |    |  酶A×酶B×  |        | y=260~440
  |  |  蓝色花    |    |  白色花    |        |
  |  +------------+    +------------+        |
  |                                          |
  |  [A_B_白] [A_bb紫] [aaB_蓝] [aabb 白]    | y=450~485
  +------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量 (0-3) 跟踪当前激活的卡片
  2. 卡片高亮：激活卡片 opacity=1、stroke-width=3，非激活卡片 opacity=0.4、stroke-width=1
  3. 按钮高亮：激活按钮 fill=#e8f5e9、stroke=#2e7d32、stroke-width=3，非激活按钮 fill=#f5f5f5、stroke=#cccccc
  4. 事件绑定：每个按钮绑定 click 事件，调用 switchState(cardIndex) 函数
  5. 动画过渡：卡片透明度变化使用 CSS transition: opacity 0.3s ease
- ID 命名规范：
  - 卡片背景：scene2-card-1, scene2-card-2, scene2-card-3, scene2-card-4
  - 卡片标题：scene2-title-1, scene2-title-2, scene2-title-3, scene2-title-4
  - 酶状态：scene2-enzymeA-1, scene2-enzymeB-1, ...
  - 花色图标：scene2-flower-1, scene2-flower-2, scene2-flower-3, scene2-flower-4
  - 按钮：scene2-btn-1, scene2-btn-2, scene2-btn-3, scene2-btn-4
- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染
