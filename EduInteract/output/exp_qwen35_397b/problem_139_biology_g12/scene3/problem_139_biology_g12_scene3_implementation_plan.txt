[技术实现]
- JS 库选择：原生 SVG（几何形状简单，无需复杂库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────┐
  │                    P 代标题                          │ y=20-40
  │         [紫花 AAbb]  →→→  [蓝花 aaBB]               │ y=50-80
  │                    F₁标题                            │ y=100-120
  │                    [F₁ AaBb]                        │ y=125-155
  │                       ↓↓                            │ y=160-190
  │                    F₂标题                            │ y=195-210
  │              ┌────┬────┬────┬────┐                  │ y=215-265
  │              │    │    │    │    │  9A_B_          │ y=240
  │              ├────┼────┼────┼────┤  3A_bb          │ y=290
  │              │    │    │    │    │  3aaB_          │ y=340
  │              ├────┼────┼────┼────┤  1aabb          │ y=390
  │              │    │    │    │    │                  │
  │              └────┴────┴────┴────┘                  │ y=415
  │                                                     │
  │   株系:AABB AABb AaBB [AaBb] aabb    比例:3:3:10    │ y=455
  │                                                     │
  │              [◀上一步] 步骤 X/5 [下一步▶]           │ y=470-495
  └─────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-5），每个状态对应一个 render 函数
  2. 坐标计算：棋盘格使用嵌套循环生成，行 i(0-3)、列 j(0-3)，坐标 (300+j*50, 215+i*50)
  3. 基因型映射：预定义 4×4 基因型数组，根据配子组合确定每个格子的基因型
  4. 花色判断：A_B_→紫花，A_bb→白花，aaB_→蓝花，aabb→白花
  5. 动画曲线：元素淡入使用 CSS transition opacity 0.3s ease
  6. 事件绑定：按钮点击事件切换 currentState 并调用 render 函数
- ID 命名规范：所有元素 ID 以 scene3- 为前缀（如 scene3-parent-purple、scene3-f1-rect、scene3-grid-cell-0-0）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
