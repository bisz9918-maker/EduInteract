[视觉元素清单]
- 选项框：4 个白色矩形框，垂直排列于左侧 (x=50-400, y=30-275)，每个 350×50px，间距 15px
- 选项文字：黑色 #000000，14px 字体，框内左对齐
- 判断标记：✓ (绿色 #2e7d32) / ✗ (红色 #c62828)，20px 字号，位于选项框右侧 (x=410)
- 结论区标题：黑色 #000000，16px 粗体，位于右上 (450,50)
- 结论框：2 个浅灰色填充矩形 (330×70px)，分别位于 (450,80) 和 (450,170)
- 结论公式：蓝色 #1565c0，16px 粗体，高亮显示 f₂>f₁ 和 f_AB'<f_AB
- 正确选项高亮：状态 3 时，正确选项 (B、D) 用绿色 #2e7d32 边框 (3px)，错误选项 (A、C) 用红色 #c62828 边框 (3px)
- 按钮：3 个圆角矩形，白色填充，黑色边框，位于 SVG 底部 (y=450-485)

[分步序列]
- 状态 0（初始）：显示 4 个选项文字框，无判断标记，无高亮边框，结论区隐藏
- 状态 1（点击"选项 A/B"）：显示结论 1 框（实验台摩擦力分析），在选项 A、C 右侧显示红色✗，在选项 B 右侧显示绿色✓（暂不显示，仅显示结论 1）
- 状态 2（点击"选项 C"）：保持状态 1 内容，强调选项 C 错误
- 状态 3（点击"选项 D"）：显示结论 2 框（A、B 间摩擦力分析），在选项 D 右侧显示绿色✓，选项 B、D 用绿色边框高亮，选项 A、C 用红色边框高亮

[交互方案]
- 交互类型：多状态切换（3 个按钮）
- 控件说明：
  - 按钮 1 "选项 A/B"：位置 (150,450)，切换状态 1，显示实验台摩擦力分析结论
  - 按钮 2 "选项 C"：位置 (340,450)，切换状态 2，强调选项 C 错误
  - 按钮 3 "选项 D"：位置 (530,450)，切换状态 3，显示 A、B 间摩擦力分析并标注正确选项
- 教师操作流程：
  1. 初始状态展示 4 个选项，让学生思考
  2. 点击"选项 A/B"按钮，展示实验台摩擦力分析 (f₂>f₁)，说明 A 错误、B 正确
  3. 点击"选项 C"按钮，强调 C 错误
  4. 点击"选项 D"按钮，展示 A、B 间摩擦力分析 (f_AB'<f_AB)，说明 D 正确，最终高亮 B、D 为正确选项

[技术实现]
- JS 库选择：原生 SVG（简单几何图形和文本，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────────┐
  │ [选项 A] [选项 B] [选项 C] [选项 D]    │ 判断依据          │
  │                                         │ ┌─────────────┐  │
  │                                         │ │ 结论 1      │  │
  │                                         │ └─────────────┘  │
  │                                         │ ┌─────────────┐  │
  │                                         │ │ 结论 2      │  │
  │                                         │ └─────────────┘  │
  │                                                             │
  │                                                             │
  │         [选项 A/B]    [选项 C]    [选项 D]                  │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用 currentState 变量 (0-3) 跟踪当前状态，每个状态对应不同的显示元素
  2. 元素 ID 命名：所有元素以 scene3- 为前缀（如 scene3-option-a、scene3-conclusion-1）
  3. 状态切换函数：updateState(newState) 根据状态显示/隐藏对应元素
  4. 高亮效果：通过修改 stroke 和 stroke-width 属性实现边框高亮
  5. 事件绑定：3 个按钮分别绑定 onclick 事件，调用 updateState(1/2/3)
  6. IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
- 颜色规格：
  - 背景：#ffffff
  - 主线/文字：#000000
  - 正确选项：#2e7d32（绿色）
  - 错误选项：#c62828（红色）
  - 高亮结论：#1565c0（蓝色）
  - 填充透明度：15%
