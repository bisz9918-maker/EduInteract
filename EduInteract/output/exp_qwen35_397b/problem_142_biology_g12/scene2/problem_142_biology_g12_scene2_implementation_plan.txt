[图示主题与整合说明]
- 本图示主题：三种黑青色突变体的染色体结构对比
- 整合的内容：突变体甲/乙/丙的 C/c 基因数量与染色体位置关系
- 教学价值：教师可通过切换三种突变体状态，直观展示 C 基因与 c 基因数量比例差异，帮助学生理解基因剂量效应对性状的影响。点击按钮即可高亮显示当前突变体的基因组成，便于课堂对比讲解。

[视觉元素清单]
- 染色体：黑色#000000 实线矩形，每组 2-4 条，垂直排列
- C 基因：绿色#2e7d32 实心圆，r=6px，位于染色体上特定位置
- c 基因：灰色#888888 空心圆（stroke _only），r=6px，位于染色体上特定位置
- 突变体名称标签：黑色#000000 文本，位于每组染色体下方
- C/c 比例标签：黑色#000000 文本，位于每组染色体右侧
- 图例：左下角展示 C 基因和 c 基因的图示说明
- 高亮边框：当某突变体被选中时，其容器添加#1565c0 蓝色边框（stroke-width=3）

颜色规格沿用 scene_outline：
- 背景：#ffffff
- 染色体：#000000 实线
- C 基因：#2e7d32 实心圆
- c 基因：#888888 空心圆（stroke=#888888, fill=none）
- 高亮边框：#1565c0

[分步序列]
本场景为多状态切换交互（3 个状态），无分步导航：

- 初始状态（默认显示突变体甲）：
  - 显示突变体甲的完整染色体结构（3 条染色体，2 个 C 基因，1 个 c 基因）
  - 突变体甲容器添加#1565c0 高亮边框
  - 突变体乙、丙的染色体结构隐藏（opacity=0 或 display=none）
  - 按钮"突变体甲"高亮显示

- 状态 1（点击"突变体甲"按钮）：
  - 显示突变体甲结构，高亮边框#1565c0
  - 隐藏突变体乙、丙
  - 右侧标签显示"2C:1c"

- 状态 2（点击"突变体乙"按钮）：
  - 显示突变体乙结构（4 条染色体，2 个 C 基因，2 个 c 基因）
  - 突变体乙容器添加#1565c0 高亮边框
  - 隐藏突变体甲、丙
  - 右侧标签显示"2C:2c"

- 状态 3（点击"突变体丙"按钮）：
  - 显示突变体丙结构（3 条染色体，1 个 C 基因，2 个 c 基因）
  - 突变体丙容器添加#1565c0 高亮边框
  - 隐藏突变体甲、乙
  - 右侧标签显示"1C:2c"

[交互方案]
- 交互类型：多状态切换（3 个按钮）
- 控件说明：
  - 按钮"突变体甲"：位于 (200,450)，点击显示突变体甲染色体结构
  - 按钮"突变体乙"：位于 (350,450)，点击显示突变体乙染色体结构
  - 按钮"突变体丙"：位于 (500,450)，点击显示突变体丙染色体结构
- 教师操作流程：
  1. 初始展示突变体甲，讲解其 C/c 基因组成（2C:1c）
  2. 点击"突变体乙"按钮，对比展示乙的染色体结构（2C:2c）
  3. 点击"突变体丙"按钮，展示丙的结构（1C:2c）
  4. 可反复切换对比三种突变体的基因剂量差异

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库）
- 画布尺寸：800×500 px
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |              三种黑青色突变体染色体结构对比        |  y=35
  +--------------------------------------------------+
  |                                                  |
  |   [突变体甲]      [突变体乙]      [突变体丙]      |  y=70~380
  |   2C:1c          2C:2c          1C:2c           |
  |   (3 条染色体)    (4 条染色体)    (3 条染色体)     |
  |                                                  |
  +--------------------------------------------------+
  |  图例：●C 基因  ○c 基因                           |  y=400~430
  +--------------------------------------------------+
  |     [突变体甲]    [突变体乙]    [突变体丙]        |  y=440~490
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentState 记录当前显示的突变体（1/2/3）
  2. 三个突变体容器分别用 g 元素包裹，ID 为 scene2-mutant-a/b/c
  3. 点击按钮时：隐藏所有容器 → 显示目标容器 → 添加高亮边框 → 更新按钮样式
  4. 染色体用<rect>绘制，基因用<circle>绘制
  5. C 基因：fill=#2e7d32, stroke=none
  6. c 基因：fill=none, stroke=#888888, stroke-width=2
- ID 命名规范：
  - 所有元素 ID 以 scene2- 为前缀
  - 突变体甲容器：scene2-mutant-a
  - 突变体乙容器：scene2-mutant-b
  - 突变体丙容器：scene2-mutant-c
  - 按钮：scene2-btn-a, scene2-btn-b, scene2-btn-c
  - C 基因：scene2-c-gene-a1, scene2-c-gene-a2, ...
  - c 基因：scene2-c-gene-lower-a1, ...
- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中
- 事件绑定：使用 addEventListener，避免内联 onclick
