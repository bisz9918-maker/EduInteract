[图示主题与整合说明]
- 本图示主题：食物网结构与营养级关系
- 整合的内容：完整食物网、各生物营养级标注、5 条食物链路径高亮展示

[分步序列]
共 8 个步骤（步骤 0-7）：

- 步骤 0（初始状态）：显示完整食物网基础结构
  - 显示所有 8 个生物节点（草、羚羊、斑马、鼠、野狗、蛇、食蛇动物、狮子）
  - 显示所有 11 条能量流动箭头（#1565c0 蓝色，2px）
  - 不显示营养级标签，不显示高亮路径

- 步骤 1：标注营养级
  - 在步骤 0 基础上，显示 5 个营养级标签（#2e7d32 绿色）
  - 第一营养级（草上方）、第二营养级（羚羊/斑马/鼠上方）、第三营养级（野狗/蛇上方）、第四营养级（食蛇动物上方）、第五营养级（狮子上方）

- 步骤 2：高亮食物链 1（草→羚羊→野狗→狮子）
  - 保持步骤 1 所有元素
  - 高亮路径：草→羚羊、羚羊→野狗、野狗→狮子（#c62828 红色，4px 加粗）
  - 其他箭头保持蓝色 2px

- 步骤 3：高亮食物链 2（草→羚羊→狮子）
  - 保持步骤 1 所有元素
  - 高亮路径：草→羚羊、羚羊→狮子（#c62828 红色，4px 加粗）
  - 其他箭头保持蓝色 2px

- 步骤 4：高亮食物链 3（草→斑马→野狗→狮子）
  - 保持步骤 1 所有元素
  - 高亮路径：草→斑马、斑马→野狗、野狗→狮子（#c62828 红色，4px 加粗）
  - 其他箭头保持蓝色 2px

- 步骤 5：高亮食物链 4（草→斑马→狮子）
  - 保持步骤 1 所有元素
  - 高亮路径：草→斑马、斑马→狮子（#c62828 红色，4px 加粗）

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 底部左侧 (x=350, y=465)，点击返回上一状态
  - 「下一步」按钮：位于 SVG 底部右侧 (x=450, y=465)，点击进入下一状态
  - 步骤指示器：位于底部中央 (x=400, y=465)，显示「步骤 X/8」
- 教师操作流程：
  1. 初始展示完整食物网（步骤 0），让学生观察整体结构
  2. 点击「下一步」显示营养级标注（步骤 1），讲解营养级概念
  3. 依次点击「下一步」（步骤 2-6），逐条高亮展示 5 条食物链，讲解能量流动路径
  4. 最后点击「下一步」（步骤 7）汇总所有路径，强调食物网的复杂性
  5. 可随时点击「上一步」回退复习

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：食物网为 2D 静态图加简单高亮动画，原生 SVG 足够胜任，无需额外库依赖
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌────────────────────────────────────────────────────────────┐
  │  第一  第二   第三   第四   第五                           │ y=60
  │  营养级 营养级 营养级 营养级 营养级                         │
  │                                                            │
  │         羚羊                                               │ y=140
  │                    野狗                      狮子          │ y=150-180
  │    草          斑马                                        │ y=235
  │                              食蛇动物                      │ y=240
  │         鼠           蛇                                    │ y=320-350
  │                                                            │
  │                                                            │
  │              [◀上一步]  步骤 X/8  [下一步▶]                │ y=465
  └────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-7），数组存储每个状态应显示的元素 ID 列表
  2. 箭头绘制：使用 SVG <path> 元素，d 属性定义路径，marker-end 引用箭头标记
  3. 高亮切换：通过改变箭头的 stroke 和 stroke-width 属性实现高亮效果
  4. 事件绑定：为按钮添加 click 事件监听器，更新 currentState 并调用 renderState() 函数
  5. 节点绘制：使用 SVG <ellipse> 元素，rx/ry 定义椭圆大小
  6. 标签绘制：使用 SVG <text> 元素，text-anchor="middle" 居中
- ID 命名规范：
  - 所有元素 ID 以 scene1- 为前缀
  - 节点：scene1-node-grass, scene1-node-antilope, scene1-node-zebra, scene1-node-mouse, scene1-node-wilddog, scene1-node-snake, scene1-node-snakeeater, scene1-node-lion
  - 箭头：scene1-arrow-1 至 scene1-arrow-11
  - 营养级标签：scene1-trophic-1 至 scene1-trophic-5
  - 按钮：scene1-btn-prev, scene1-btn-next, scene1-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
