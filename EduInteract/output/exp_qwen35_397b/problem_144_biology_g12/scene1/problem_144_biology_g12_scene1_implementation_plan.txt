[视觉元素清单]
- 果蝇图标：用椭圆组合表示身体+眼睛，棒眼用红色细长椭圆（#c62828），圆眼用绿色圆形（#2e7d32）

- 杂交箭头：黑色实线箭头（#000000），线宽 3px，箭头头部 10×8px
- 代际标签：P、F₁、F₂，字体 20px 粗体，颜色 #000000
- 表型标签：棒眼/圆眼，字体 14px，颜色 #000000
- 比例数字：1:1:1:1，字体 16px 粗体，颜色 #000000
- 基因型标注：X^A X^a 等，字体 12px，颜色 #1565c0，步骤 4 显示
- 配色沿用 spec：背景 #ffffff / 主线 #000000 / 棒眼 #c62828 / 圆眼 #2e7d32 / 基因型 #1565c0

[分步序列]
共 5 个步骤（步骤 0-4），教师可点击「上一步」「下一步」导航

- 步骤 0（初始状态）：
  - 显示：P 代标签、P 代♀棒眼图标、P 代♂圆眼图标、杂交符号×
  - 隐藏：P→F1 箭头、F1 代、F1→F2 箭头、F2 代、比例、基因型标注
  - 视觉：P 代区域高亮，其他区域空白

- 步骤 1：
  - 新增：P→F1 向下箭头（从 y=95 到 y=155）
  - 显示：F1 代标签、F1 代空白框（待填表型）、F1(♀♂) 符号
  - 隐藏：F1→F2 箭头、F2 代、比例、基因型标注
  - 视觉：箭头淡入动画（300ms）

- 步骤 2：
  - 新增：F1→F2 向下箭头（从 y=195 到 y=255）、"F₁雌雄交配"文字
  - 显示：F2 代标签、F2 代四个图标（♀圆眼、♀棒眼、♂圆眼、♂棒眼）
  - 隐藏：比例数字、基因型标注
  - 视觉：F2 图标依次淡入（每个间隔 150ms）

- 步骤 3：
  - 新增：比例标签 1:1:1:1（位于 F2 代图标下方 y=365）
  - 显示：所有 F2 代表型标签
  - 隐藏：基因型标注
  - 视觉：比例数字从 0 缩放至 1（300ms 动画）

- 步骤 4（最终步骤）：
  - 新增：基因型标注框（每个 F2 图标下方显示基因型）
    - F2♀圆眼：X^a X^a
    - F2♀棒眼：X^A X^a
    - F2♂圆眼：X^a Y
    - F2♂棒眼：X^A Y
  - 显示：F1 空白框填充为"棒眼"
  - 视觉：基因型标注蓝色高亮（#1565c0），淡入动画

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「◀上一步」按钮：位于 (250,455)，80×30px，点击返回上一状态
  - 「下一步▶」按钮：位于 (470,455)，80×30px，点击进入下一状态
  - 步骤指示器：位于 (380,465)，显示当前步骤/总步骤（如"步骤 3/5"）
- 教师操作流程：
  1. 初始展示 P 代亲本杂交组合，讲解实验设计
  2. 点击「下一步」展示 F1 代，提问学生 F1 表型是什么
  3. 点击「下一步」展示 F1 雌雄交配及 F2 代四种表型
  4. 点击「下一步」展示 1:1:1:1 比例，引导学生分析为何雌雄表型不同
  5. 点击「下一步」展示基因型，验证伴 X 遗传推断
  6. 可随时点击「上一步」回退复习关键步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（椭圆、箭头、文字），无需复杂库；原生实现轻量、加载快
- 画布尺寸：800×500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌────────────────────────────────────────────────────┐
  │  P 代：♀棒眼 × ♂圆眼                    y=60-120  │
  │            ↓                                      │
  │  F1 代：___眼(♀♂)                      y=170-240  │
  │            ↓  F₁雌雄交配                          │
  │  F2 代：♀圆眼  ♀棒眼  ♂圆眼  ♂棒眼   y=290-400  │
  │         1  :  1  :  1  :  1                       │
  │                                                   │
  │  ┌─────────────────────────┐                      │
  │  │ ◀上一步  步骤 3/5  下一步▶ │  y=440-490        │
  │  └─────────────────────────┘                      │
  └────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用 currentStep 变量（0-4）跟踪当前步骤，steps 数组存储每步的显示/隐藏元素 ID 列表
  2. 坐标计算：所有元素用绝对坐标（非相对定位），确保多场景合并时不偏移
  3. 动画曲线：使用 CSS transition 实现淡入效果（opacity: 0→1，300ms ease-out）
  4. 事件绑定：按钮点击事件用 addEventListener，避免内联 onclick
  5. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-p-female、scene1-f2-round-female）
  6. IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
  7. 按钮状态：步骤 0 时禁用「上一步」，步骤 4 时禁用「下一步」（灰色显示）
  8. 果蝇图标绘制：用 SVG <ellipse> 组合，身体椭圆 + 眼睛椭圆，棒眼用细长椭圆（rx=8, ry=15），圆眼用圆形（rx=ry=12）

- 元素 ID 命名示例：
  - scene1-p-label（P 代标签）
  - scene1-p-female-icon（P 代♀图标）
  - scene1-p-male-icon（P 代♂图标）
  - scene1-arrow-p-f1（P→F1 箭头）
  - scene1-f1-label（F1 代标签）
  - scene1-f1-blank（F1 空白框）
  - scene1-arrow-f1-f2（F1→F2 箭头）
  - scene1-f2-label（F2 代标签）
  - scene1-f2-round-female（F2♀圆眼图标）
  - scene1-f2-bar-female（F2♀棒眼图标）
  - scene1-f2-round-male（F2♂圆眼图标）
  - scene1-f2-bar-male（F2♂棒眼图标）
  - scene1-ratio-label（比例 1:1:1:1）
  - scene1-genotype-group（基因型标注组）
  - scene1-btn-prev（上一步按钮）
  - scene1-btn-next（下一步按钮）
  - scene1-step-indicator（步骤指示器）
