[图示主题与整合说明]
- 本图示主题：三种遗传假设的 F2 预期比例对比
- 整合的步骤/概念：
  1. 常染色体显性假设的遗传图解及 F2 预期
  2. 常染色体隐性假设的遗传图解及 F2 预期
  3. X 染色体显性假设的遗传图解及 F2 预期
  4. 三种假设与实际实验结果（1:1:1:1）的匹配对比
- 教学价值：教师可通过切换三种假设状态，引导学生对比分析哪种遗传方式能产生观察到的 F2 比例（1:1:1:1），帮助学生理解遗传假设验证的逻辑推理过程

[分步序列]
本场景为多状态切换交互，无分步序列，三个状态如下：

- 状态 0（初始/常染色体显性）：
  - 按钮1 高亮为蓝色（中性）
  - 显示常染色体显性假设图解：
    - P: AA(棒眼♀) × aa(圆眼♂)
    - F1: Aa(全部棒眼)
    - F2: AA:Aa:aa = 1:2:1 → 表型 棒眼:圆眼 = 3:1
  - 预期比例："3:1（棒眼:圆眼）"
  - 匹配指示器：✗（红色，与 1:1:1:1 不符）

- 状态 1（常染色体隐性）：
  - 按钮2 高亮为蓝色（中性）
  - 显示常染色体隐性假设图解：
    - P: aa(棒眼♀) × AA(圆眼♂)
    - F1: Aa(全部圆眼) — 与实验 F1 全为棒眼矛盾！
  - 预期比例："此假设与 F1 结果矛盾"
  - 匹配指示器：✗（红色）

- 状态 2（X 染色体显性）：
  - 按钮3 高亮为绿色（匹配）
  - 显示 X 染色体显性假设图解：
    - P: X^A X^A(棒眼♀) × X^a Y(圆眼♂)
    - F1: X^A X^a(棒眼♀), X^A Y(棒眼♂)
    - F2: X^A X^a(棒眼♀):X^a X^a(圆眼♀):X^A Y(棒眼♂):X^a Y(圆眼♂) = 1:1:1:1
  - 预期比例："1:1:1:1（♀棒:♀圆:♂棒:♂圆）"
  - 匹配指示器：✓（绿色，与实验结果匹配）

[交互方案]
- 交互类型：多状态切换（3 个按钮）
- 控件说明：
  - 按钮 1「常染色体显性」：点击显示常染色体显性假设的完整遗传图解
  - 按钮 2「常染色体隐性」：点击显示常染色体隐性假设的完整遗传图解
  - 按钮 3「X 染色体显性」：点击显示 X 染色体显性假设的完整遗传图解
- 教师操作流程：
  1. 初始状态默认显示「常染色体显性」，讲解该假设下 F2 预期为 3:1
  2. 点击「常染色体隐性」，指出该假设与 F1 结果矛盾（F1 应全为圆眼但实际全为棒眼）
  3. 点击「X 染色体显性」，展示该假设下 F2 预期为 1:1:1:1，与实验结果完全匹配
  4. 引导学生得出结论：控制眼型的基因位于 X 染色体上，棒眼为显性性状

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何元素简单（矩形、文本、箭头），无需复杂库；状态切换逻辑简单
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +----------------------------------------------------------+
  |  [按钮 1]                                    [标题区]    |
  |  [按钮 2]                                    [图例区]    |
  |  [按钮 3]                                                |
  |                                                          |
  |          [P 代遗传图解]                                  |
  |              ↓                                           |
  |          [F1 代遗传图解]                                 |
  |              ↓                                           |
  |          [F2 代遗传图解]                                 |
  |                                                          |
  |  ─────────────────────────────────────                   |
  |  [预期比例]                    [匹配指示器]              |
  |  [实际结果参照框 1:1:1:1]                                |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用 currentState 变量（0/1/2）跟踪当前选中状态
  2. 三个状态的数据对象：每个状态包含{pText, f1Text, f2Text, ratioText, isMatch}
  3. 按钮样式切换：点击时移除所有按钮的 active 类，给当前按钮添加 active 类
  4. 匹配指示器：根据 isMatch 显示✓（#2e7d32）或✗（#c62828）
  5. 遗传图解动态更新：根据当前状态更新 SVG 文本元素的 textContent
  6. 箭头绘制：用<path>绘制 P→F1→F2 的连接箭头
- ID 命名规范：
  - 按钮：scene2-btn-const-dom, scene2-btn-const-rec, scene2-btn-x-dom
  - 图解文本：scene2-p-text, scene2-f1-text, scene2-f2-text
  - 比例区：scene2-ratio-text, scene2-actual-box, scene2-match-indicator
  - 箭头：scene2-arrow-p-f1, scene2-arrow-f1-f2
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
