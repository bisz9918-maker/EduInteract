[图示主题与整合说明]
- 本图示主题：验证实验的杂交组合及预期结果（果蝇眼型遗传）
- 整合内容：两个验证实验的杂交组合设计、亲本基因型、预期后代表型及比例
- 教学价值：教师可通过分步导航展示验证实验的完整逻辑链条，从选择亲本到预期结果，帮助学生理解如何通过杂交实验验证基因位置和显隐关系。学生可直观看到不同杂交组合产生的不同表型比例，加深对伴性遗传的理解。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 上一步按钮：位于 (280,465)，灰色背景，点击回退到上一状态
  - 下一步按钮：位于 (440,465)，蓝色背景，点击进入下一状态
  - 步骤指示器：位于 (400,490)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始状态展示实验目的框架
  2. 点击"下一步"展示实验一的亲本选择
  3. 点击"下一步"展示实验一的配子和预期结果
  4. 点击"下一步"切换到实验二的亲本选择
  5. 点击"下一步"展示实验二的配子和预期结果，同时显示总结
  6. 教师可随时点击"上一步"回退复习关键步骤

[技术实现]
- JS 库选择：原生 SVG（几何图形和文本标注简单，无需额外库）
- 画布尺寸：800×500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |              验证实验设计 (标题)                  |
  +------------------------+-------------------------+
  |    实验一 (蓝色)        |     实验二 (绿色)        |
  |  [亲本♀] × [亲本♂]     |  [亲本♀] × [亲本♂]      |
  |     配子标注            |      配子标注           |
  |  +------------------+   |  +------------------+   |
  |  |   预期结果        |   |  |   预期结果        |   |
  |  +------------------+   |  +------------------+   |
  +------------------------+-------------------------+
  |           总结区（两个实验均能独立证明...）         |
  +--------------------------------------------------+
  |        [◀上一步]    步骤 X/5    [下一步▶]         |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量 (0-5) 跟踪当前步骤
  2. 元素分组：每个步骤的元素用 g 元素分组，通过 display 属性控制显示/隐藏
  3. 高亮效果：通过改变 stroke-opacity 和 fill-opacity 实现区域高亮
  4. 按钮状态：第一步禁用上一步，最后一步禁用下一步
  5. 基因型上标：使用 SVG tspan 元素实现 X^A 格式
- ID 命名规范：
  - 实验一区域：scene3-exp1-area
  - 实验二区域：scene3-exp2-area
  - 实验一亲本♀：scene3-exp1-female
  - 实验一亲本♂：scene3-exp1-male
  - 实验二亲本♀：scene3-exp2-female
  - 实验二亲本♂：scene3-exp2-male
  - 上一步按钮：scene3-prev-btn
  - 下一步按钮：scene3-next-btn
  - 步骤指示器：scene3-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
