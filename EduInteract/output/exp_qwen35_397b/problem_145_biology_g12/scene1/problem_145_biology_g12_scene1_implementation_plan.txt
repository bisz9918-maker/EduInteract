[标签冲突检查]
所有标签坐标及间距检查：
- Ⅰ-1 标签 (55,35) 与 Ⅰ-2 标签 (155,35)：间距 100px → 无冲突
- Ⅱ代标签组 (25~225,155)：相邻间距 50px → 无冲突
- Ⅲ代标签 (45,275) 与 (200,275)：间距 155px → 无冲突
- 代际标签Ⅰ(10,65)、Ⅱ(10,185)、Ⅲ(10,305)：垂直间距 120px → 无冲突
- 基因型标签位于符号下方 10px（y=符号 y+40），与下一行元素间距充足
- 图例区 (590~760,40~140) 与系谱图区 (20~260,50~320)：水平间距 30px → 无冲突
- 结论框 (590~760,350~450) 与控件栏 (y=450~490)：垂直间距 0px（紧邻但不重叠）

解决方案：所有标签均放置在符号外侧空白区域，无重叠风险。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：位于 (280,460)，点击后退到前一状态（步骤 0 时禁用）
  - "下一步 ▶"按钮：位于 (440,460)，点击前进到下一状态（步骤 5 时显示"完成"）
  - 步骤指示器：位于 (380,475)，显示当前步骤"步骤 X/5"
- 教师操作流程：
  1. 初始展示系谱图，让学生观察家族患病分布
  2. 点击"下一步"高亮甲病患者，引导学生发现父子相传特征
  3. 继续点击高亮乙病患者，分析隐性遗传特征
  4. 逐步显示基因型，验证遗传方式判断
  5. 最后展示结论框，总结两种遗传病的遗传类型

[技术实现]
- JS 库选择：原生 SVG（系谱图为静态几何图形，无需复杂动画）
- 画布尺寸：800×500px（固定）
- 布局草图：
  ```
  [系谱图区 540×350]     [图例区 200×100]
  Ⅰ代：□─○               图例标题
       │                  甲病图例
  Ⅱ代：□○○○□             乙病图例
       ││  │              正常图例
  Ⅲ代：  ?   □
                          [结论区 200×100]
                          遗传方式判断
                          甲病：常显
                          乙病：伴 X 隐
  [控件栏 800×40]
  [◀上一步] [步骤 X/5] [下一步▶]
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0~5) 跟踪当前步骤
  2. 元素分组：将高亮框、基因型标签、结论框分别放入<g>组，用 display 控制显示/隐藏
  3. 基因型标注：使用<tspan>实现上标（如 X^B 写作 X<tspan dy="-4" font-size="10">B</tspan>）
  4. 事件绑定：按钮点击事件切换 currentStep，更新各组 display 属性
  5. IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中
- ID 命名规范：
  - 系谱图符号：scene1-symbol-I1, scene1-symbol-I2, scene1-symbol-II3, ...
  - 高亮框：scene1-highlight-甲病，scene1-highlight-乙病
  - 基因型标签：scene1-genotype-甲病-I1, scene1-genotype-乙病-I1, ...
  - 结论框：scene1-conclusion-box
  - 按钮：scene1-btn-prev, scene1-btn-next, scene1-step-indicator
  - 图例：scene1-legend-甲病，scene1-legend-乙病，scene1-legend-正常
