    **题目原文：**

    几种性染色体异常果蝇的性别、育性等如图所示。

    （1）正常果蝇在减数第一次分裂中期的细胞内染色体组数为______，在减数第二次分裂后期的细胞中染色体数是______条。

    （2）白眼雌果蝇（X^rX^rY）最多能产生 X^r、X^rX^r、__________和______四种类型的配子。该果蝇与红眼雄果蝇（X^RY）杂交，子代中红眼雌果蝇的基因型为________________。

    （3）用黑身白眼雌果蝇（aaX^rX^r）与灰身红眼雄果蝇（AAX^RY）杂交，F₁雌果蝇表现为灰身红眼，雄果蝇表现为灰身白眼。F₂中灰身红眼与黑身白眼果蝇的比例为______，从 F₂灰身红眼雌果蝇和灰身白眼雄果蝇中各随机选取一只杂交，子代中出现黑身白眼果蝇的概率为______。

    （4）用红眼雌果蝇（X^RX^R）与白眼雄果蝇（X^rY）为亲本杂交，在 F₁群体中发现一只白眼雄果蝇（记为"M"）。M 果蝇出现的原因有三种可能：第一种是环境改变引起表现型变化，但基因型未变；第二种是亲本果蝇发生基因突变；第三种是亲本雌果蝇在减数分裂时 X 染色体不分离。请设计简便的杂交实验，确定 M 果蝇的出现是由哪一种原因引起的。

    **题目分析：**

    本题综合考查果蝇的染色体组成、减数分裂、伴性遗传及实验设计能力。核心知识点包括：
    - 果蝇染色体组成（2n=8，3 对常染色体 +1 对性染色体）
    - 性染色体异常的类型及后果（XXY、XO、XXX、OY）
    - 减数分裂各时期染色体行为
    - 三体个体（XXY）产生配子的类型
    - 两对相对性状的自由组合定律
    - 实验设计与结果预测

    **整体讲解思路：**

    1. 首先通过图示理解题目给出的四种性染色体异常情况
    2. 回顾正常果蝇减数分裂过程，回答第（1）问
    3. 分析 XXY 个体减数分裂时染色体的分离方式，推导配子类型
    4. 用遗传图解分析第（2）（3）问的杂交结果
    5. 设计实验区分三种可能原因

    教师可引导学生对比有丝分裂和减数分裂的染色体行为差异，强调减Ⅱ后期染色体数暂时加倍的原因。

    **教学说明：**

    本图示整合第（2）（3）问的遗传分析，是本题的核心内容。

    **第（2）问解析：**

    1. XXY 个体减数分裂时，三条性染色体的分离方式：
       - 两条 X 配对，Y 随机移向一极 → 配子：X、XY
       - X 与 Y 配对，另一条 X 随机移向一极 → 配子：XX、Y

    2. 白眼雌果蝇（X^rX^rY）产生的四种配子：
       - **X^r**、**X^rX^r**、**X^rY**、**Y**

    3. 与红眼雄果蝇（X^RY）杂交：
       | 雌配子 | X^R（雄） | Y（雄） |
       |--------|-----------|---------|
       | X^r    | X^RX^r（红眼雌） | X^rY（白眼雄） |
       | X^rX^r | X^RX^rX^r（红眼雌） | X^rX^rY（白眼雌） |
       | X^rY   | X^RX^rY（红眼雌） | X^rYY（白眼雄） |
       | Y      | X^RY（红眼雄） | YY（死亡） |

    4. 子代红眼雌果蝇基因型：**X^RX^r、X^RX^rX^r、X^RX^rY**

    **第（3）问解析：**

    1. 亲本：aaX^rX^r（黑身白眼雌）× AAX^RY（灰身红眼雄）

    2. F₁：AaX^RX^r（灰身红眼雌）、AaX^rY（灰身白眼雄）

    3. F₁自交得 F₂：
       - 体色：Aa×Aa → 3 灰身：1 黑身
       - 眼色：X^RX^r × X^rY → 1 红眼：1 白眼（雌雄各半）

    4. F₂中灰身红眼：黑身白眼 = **3:1**

    5. F₂灰身红眼雌（A_X^RX^r）× 灰身白眼雄（A_X^rY）：
       - 灰身概率：2/3 Aa × 2/3 Aa → 1/4 aa，故黑身概率 = 2/3×2/3×1/4 = 1/9
       - 白眼概率：X^RX^r × X^rY → 1/2 白眼
       - 黑身白眼概率 = 1/9 × 1/2 = **1/18**

    **教学说明：**

    本图示用于解答第（4）问的实验设计题，考查学生的科学探究能力。

    **实验设计思路：**

    M 果蝇为白眼雄果蝇，可能基因型：
    - 环境改变：X^RY（基因型正常，表现型异常）
    - 基因突变：X^rY（X^R 突变为 X^r）
    - X 不分离：X^rO（母本减数分裂异常，产生不含 X 的卵细胞）

    **实验步骤：**

    将 M 果蝇与正常白眼雌果蝇（X^rX^r）杂交，观察子代的表现型。

    **结果预测：**

    Ⅰ. 若**子代出现红眼果蝇（且有雌雄）**，则是环境改变（M 为 X^RY，与 X^rX^r杂交→X^RX^r红眼雌 + X^rY 白眼雄）

    Ⅱ. 若**子代全为白眼果蝇（且有雌雄）**，则是基因突变（M 为 X^rY，与 X^rX^r杂交→X^rX^r白眼雌 + X^rY 白眼雄）

    Ⅲ. 若**子代无果蝇产生（或极少）**，则是 X 染色体不分离（M 为 X^rO，不育，无法产生正常配子）

    **完整答案：**

    实验步骤：**将 M 果蝇与正常白眼雌果蝇杂交，观察并统计子代的表现型及比例**

    结果预测：
    - Ⅰ. 若**子代中出现红眼果蝇**，则是环境改变
    - Ⅱ. 若**子代全为白眼果蝇**，则是基因突变
    - Ⅲ. 若**子代无果蝇产生（M 不育）**，则是减数分裂时 X 染色体不分离

    **课堂讲解建议：**
    引导学生从"如何区分可遗传变异与不可遗传变异"的角度思考实验设计，理解测交在遗传分析中的应用。
