[图示主题与整合说明]
- 本图示主题：XXY 个体配子形成与遗传杂交分析
- 整合的步骤/概念：
  1. XXY 雌果蝇减数分裂时染色体分离的两种情况
  2. XXY 个体产生的四种配子类型（X^r、X^rX^r、X^rY、Y）
  3. XXY 与正常雄果蝇（X^RY）杂交的 Punnett 方格分析
  4. 体色（A/a）与眼色（X^R/X^r）两对性状的遗传分析
  5. F₁自交得 F₂的表型比例计算
  6. F₂随机杂交的概率推导
- 教学价值：教师可逐步展示 XXY 异常染色体的配子形成机制，帮助学生理解染色体不分离导致的遗传异常；通过分步展示杂交过程，让学生掌握多基因遗传的分析方法和概率计算技巧

[分步序列]
- 初始状态（步骤 0）：显示标题"XXY 雌果蝇减数分裂"，中央细胞圆内含 2 条 X 染色体（蓝色）和 1 条 Y 染色体（红色），用虚线表示 X-X 联会和 X-Y 联会两种可能
- 步骤 1：点击「下一步」→ 细胞圆淡出，4 个配子圆圈从中心向两侧展开动画，分别显示 X^r、X^rX^r、X^rY、Y 四种配子，每个配子内含对应染色体简图，下方显示配子名称标签
- 步骤 2：点击「下一步」→ 配子图上移，中部出现 Punnett 方格（4 行×2 列），左侧标注 4 种雌配子（X^r、X^rX^r、X^rY、Y），顶部标注 2 种雄配子（X^R、Y），方格内填充 8 种子代基因型（X^RX^r、X^rY、X^RX^rX^r、X^rX^rY、X^RX^rY、YY 死亡、X^R、X^rY），可育子代用绿色边框高亮
- 步骤 3：点击「下一步」→ 上方内容上移淡出，下部显示第（3）问亲本杂交：左侧"P: aaX^rX^r(黑身白眼♀) × AAX^RY(灰身红眼♂)"，箭头指向右侧"F₁: AaX^RX^r(灰身红眼♀) AaX^rY(灰身白眼♂)"，基因型中 A/a 用黑色/灰色，X^R/X^r 用绿色/红色
- 步骤 4：点击「下一步」→ F₁自交图示出现，显示"F₁♀×F₁♂"，下方出现 F₂表型比例："灰身红眼:灰身白眼:黑身红眼:黑身白眼 = 9:3:3:1"，其中"灰身红眼:黑身白眼=3:1"用方框高亮
- 步骤 5：点击「下一步」→ 右侧概率计算面板展开，显示"F₂灰身红眼♀(A_X^RX^-) × F₂灰身白眼♂(A_X^rY) 随机杂交"，分步计算：P(黑身 aa)=1/4，P(白眼)=2/3，最终"1/4×2/3=1/6"用红色加粗显示

[技术实现]
- JS 库选择及原因：
  - 原生 SVG：用于绘制染色体、配子圆圈、Punnett 方格等几何元素，轻量且易于控制
  - 原生 JavaScript：状态管理和事件处理，无需额外库
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────────┐
  │                    XXY 雌果蝇减数分裂                        │ y=25
  │                                                             │
  │         ○      ○      ○      ○      (配子圆圈)              │ y=110
  │        X^r   X^rX^r   X^rY     Y     (配子标签)             │ y=155
  │                                                             │
  │    ┌─────────────────────────────────────┐                  │ y=200-340
  │    │         Punnett 方格 (4×2)          │                  │
  │    └─────────────────────────────────────┘                  │
  │                                                             │
  │  P: aaX^rX^r × AAX^RY  →  F₁: AaX^RX^r  AaX^rY             │ y=350
  │  F₂比例：灰身红眼:黑身白眼 = 3:1                            │ y=385
  │                                        ┌───────────────┐   │
  │                                        │ P(黑身)=1/4   │   │ y=340-430
  │                                        │ P(白眼)=2/3   │   │
  │                                        │ 1/4×2/3=1/6   │   │
  │                                        └───────────────┘   │
  │─────────────────────────────────────────────────────────────│ y=440
  │              [◀ 上一步]  步骤 X/6  [下一步 ▶]               │ y=455-490
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-5），steps 数组存储每步的显示配置
  2. 坐标计算：所有元素使用绝对坐标，避免相对定位导致的偏移
  3. 动画曲线：配子展开使用 ease-out 缓动（CSS transition: transform 0.5s ease-out）
  4. 事件绑定：按钮点击事件绑定到 scene3-prev-btn 和 scene3-next-btn ID
  5. 元素显隐：使用 display:none / display:block 或 opacity 切换
- ID 命名规范：
  - 所有元素 ID 以 scene3- 为前缀
  - 示例：scene3-title, scene3-cell, scene3-gamete-1, scene3-punnett, scene3-prev-btn, scene3-next-btn
- IIFE 隔离：
  ```javascript
  (function() {
    // 所有 JS 代码包裹在此
    const currentState = 0;
    // ...
  })();
  ```
