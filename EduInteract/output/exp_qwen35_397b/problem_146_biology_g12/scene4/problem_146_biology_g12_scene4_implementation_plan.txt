[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript。原因：本场景为流程图形式，几何元素简单（矩形、圆形、线段、文字），无需复杂库；原生实现轻量且易于多场景合并。
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────────┐
  │                    [标题：M 果蝇实验设计]                    │ y=20-50
  │                                                             │
  │         [原因 1]    [M 图标]    [原因 2]    [原因 3]        │ y=80-130
  │                        ↓                                    │
  │              [实验步骤：M × 白眼雌]                         │ y=150-190
  │                        ↓                                    │
  │                      [分支点]                               │ y=230
  │                     ↙    ↓    ↘                             │
  │              [结果 1]  [结果 2]  [结果 3]                   │ y=290-380
  │                                                             │
  │            [对比表：三种结果对比总结]                       │ y=400-435
  │                                                             │
  │              [◀上一步]  [步骤 X/6]  [下一步▶]               │ y=450-485
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-6），每个状态对应 show/hide 特定元素组
  2. 元素分组：将 SVG 元素按步骤分组（step0-elements, step1-elements...），用 class 或 data-step 属性标记
  3. 高亮逻辑：使用 CSS class"highlight"切换边框颜色和填充透明度
  4. 按钮事件：绑定 click 事件，更新 currentState，调用 render() 函数刷新显示
  5. 边界处理：步骤 0 时禁用「上一步」，步骤 6 时禁用「下一步」
- ID 命名规范：所有交互元素 ID 必须以 scene4- 为前缀（如 scene4-m-icon, scene4-cause1-box, scene4-result1-box, scene4-btn-prev, scene4-btn-next）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
