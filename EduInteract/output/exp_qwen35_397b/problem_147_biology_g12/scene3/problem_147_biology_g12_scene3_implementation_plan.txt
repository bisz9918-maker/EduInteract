[图示主题与整合说明]
- 本图示主题：DNA复制产物与放射性标记分析
- 整合的内容：整合了循环一次产物、循环n次产物、放射性单链比例计算三个分析环节
- 教学价值：教师通过滑块调节PCR循环次数n，学生可直观观察DNA分子数量呈指数增长（2ⁿ），同时理解原始模板链始终为2条且不含放射性，新合成链均含³²P标记，从而推导出不含放射性单链比例=2/2ⁿ⁺¹=1/2ⁿ的数学规律。此图示将抽象的指数关系可视化，帮助学生建立数学模型。

[分步序列]
本场景采用连续滑块交互，无分步导航。状态随滑块n值实时变化：

- 初始状态（n=1）：
  - DNA树状图显示第0代（1个原始DNA）、第1代（2个DNA分子）
  - 第1代DNA分子中：每条双链含1条灰色原始链+1条绿色新合成链
  - 统计面板：DNA分子总数=2、单链总数=4、含³²P=2、不含=2、比例=1/2
  - 滑块手柄位于最左侧（n=1位置）

- 状态变化（n=2~10，随滑块拖动实时更新）：
  - n=2：树状图扩展显示第2代（4个DNA分子），统计：总数=4、单链=8、含³²P=6、不含=2、比例=1/4
  - n=3：树状图显示第3代（8个DNA分子，简化为示意），统计：总数=8、单链=16、含³²P=14、不含=2、比例=1/8
  - n=4~10：树状图保持显示前3代示意（避免过密），统计面板数值按公式计算更新
  - 比例结果面板始终显示公式"不含放射性单链比例 = 2/2ⁿ⁺¹ = 1/2ⁿ"

- 视觉变化规则：
  - DNA分子总数 = 2ⁿ（指数增长）
  - DNA单链总数 = 2ⁿ⁺¹
  - 含³²P单链数 = 2ⁿ⁺¹ - 2（总单链减2条原始链）
  - 不含³²P单链数 = 2（始终为原始模板链）
  - 比例 = 2/2ⁿ⁺¹ = 1/2ⁿ

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：
  - 滑块轨道：水平线段，从n=1到n=10，共10个刻度
  - 滑块手柄：圆形可拖拽元素，拖动时更新n值
  - 数值显示：滑块右侧实时显示当前n值
- 教师操作流程：
  1. 初始状态n=1，讲解PCR循环1次后产物特点（2个DNA分子，每条含1条原始链+1条新链）
  2. 拖动滑块到n=2，观察DNA分子数变为4，引导学生发现2ⁿ规律
  3. 继续拖动到n=3、4，让学生预测数值变化
  4. 拖动到n=10，展示指数增长的巨大效果（1024个DNA分子）
  5. 重点讲解"不含放射性单链数始终为2"的原因（原始模板链不被标记）
  6. 引导学生推导比例公式：2/2ⁿ⁺¹ = 1/2ⁿ

[技术实现]
- JS库选择：原生SVG + 原生JavaScript
  - 原因：几何图形简单，无需复杂库；原生SVG便于精确控制坐标和样式
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────┐
  │  [DNA树状图]          [统计面板]                   │
  │   第0代  ●            ┌──────────────────┐          │
  │         / \           │ n = [滑块值]     │          │
  │   第1代 ●   ●         │ DNA总数: 2ⁿ      │          │
  │       / \ / \         │ 单链总数: 2ⁿ⁺¹   │          │
  │  第2代● ● ● ●         │ 含³²P: X         │          │
  │                       │ 不含³²P: 2       │          │
  │                       │ 比例: 1/2ⁿ       │          │
  │                       └──────────────────┘          │
  │                       [滑块 n=1━━━━━━━━━━10]        │
  │                       [比例结果面板]                │
  │  [图例] 灰色=原始链  绿色=新合成链(³²P)              │
  └─────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：单一状态变量currentN（1-10），拖动滑块时更新
  2. 坐标计算：DNA树状图采用二叉树布局，第k代x坐标 = 200 + (偏移量)×(2^k)
  3. 动画曲线：滑块拖动时数值实时更新，无过渡动画（保证响应性）
  4. 事件绑定：
     - slider.addEventListener('input', updateScene)
     - 计算所有统计数值并更新text元素textContent
  5. 指数计算：使用Math.pow(2, n)或位运算1<<n
  6. 树状图渲染：n≤3时完整显示所有DNA分子，n>3时仅显示前3代示意（避免过密）
- ID命名规范：
  - 所有元素ID以scene3-为前缀
  - 示例：scene3-dna-tree、scene3-slider、scene3-stat-total、scene3-stat-ratio等
- IIFE隔离：所有JS代码包裹在(function() { ... })()中，避免全局变量污染
