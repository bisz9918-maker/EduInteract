problem_148_chemistry_g9

场景导航：Scene 1 | Scene 2

题目原文：
甲烷和水反应可以制水煤气（混合气体），其反应的微观示意图如图所示．根据微观示意图得出的结论正确的是（ ）

A. 反应前后各元素的化合价均不变
B. 该反应中含氢元素的化合物有 3 种
C. 该反应中乙和丁的质量比为 3：1
D. 该反应中丙和丁的分子个数比为 1：3

题目分析：
本题通过微观示意图展示甲烷（CH₄）与水（H₂O）在高温下反应生成一氧化碳（CO）和氢气（H₂）的过程。需结合图示分析反应方程式、物质分类、质量比及分子个数比。

整体讲解思路：

  1. 通过微观图示明确反应物与生成物的分子结构
  2. 写出配平的化学方程式：CH₄ + H₂O → CO + 3H₂
  3. 逐项分析选项：
  • A：碳元素化合价从 -4（CH₄）变为 +2（CO），错误
  • B：含氢化合物为 CH₄、H₂O 共 2 种，错误
  • C：乙（H₂O）与丁（H₂）质量比 = 18 : (3×2) = 3:1，正确
  • D：丙（CO）与丁（H₂）分子个数比 1:3，正确
  1. 注意题目可能存在多选情况，但通常单选题需结合图示细节确认

图示规划说明：

  • SCENE_1：整合反应微观过程（反应物→原子重组→生成物），用分步按钮展示动态变化
  • SCENE_2：整合反应方程式、分子个数比与质量比计算，用分步导航对比选项 C 和 D
步骤 1/5

教学要点：

  1. 引导学生观察反应前后分子种类变化，明确化学反应本质是原子重组
  2. 强调反应条件“高温”对反应的影响
  3. 通过步骤分解帮助学生理解微观过程与宏观方程式的对应关系

关键公式：
化学方程式：CH₄ + H₂O → CO + 3H₂

讲解建议：

  • 步骤 0：指出反应物甲（甲烷）、乙（水）的分子构成
  • 步骤 1：展示化学键断裂，强调原子种类和数目守恒
  • 步骤 2：演示碳、氧原子结合成 CO，氢原子结合成 H₂
  • 步骤 3：总结生成物丙（CO）、丁（H₂）的分子个数比 1:3

教学要点：

  1. 通过配平方程式明确各物质系数，为定量分析奠定基础
  2. 分子个数比直接由系数得出，质量比需结合摩尔质量计算
  3. 强调选项 C 和 D 均正确，但需根据题目要求判断是否多选

关键公式：

  • 分子个数比：丙 : 丁 = 1 : 3
  • 质量比：乙 : 丁 = (1×18) : (3×2) = 3 : 1

讲解建议：

  • 步骤 0：带领学生配平方程式，确认系数
  • 步骤 1：直接读取系数得出分子个数比，验证选项 D
  • 步骤 2：计算乙（H₂O）与丁（H₂）的质量比，验证选项 C
  • 结论：若题目为多选则 C、D 均正确，单选需结合图示细节（如丁分子数量是否为 3）
