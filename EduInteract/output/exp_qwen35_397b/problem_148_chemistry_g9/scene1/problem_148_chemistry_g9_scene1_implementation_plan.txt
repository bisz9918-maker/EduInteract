[分步序列]
步骤0（初始状态 - 反应前）：
- 显示：反应前框、甲分子（完整CH₄结构）、乙分子（完整H₂O结构）
- 高亮：反应前框加粗边框 #1565c0
- 隐藏：反应后框内容、反应箭头、高温文字
- 显示标签：甲(CH₄)、乙(H₂O)、反应前标题

步骤1（化学键断裂）：
- 显示：反应前框、甲分子原子（分散状态，化学键消失）、乙分子原子（分散状态，化学键消失）
- 动画：甲分子4个H原子从中心碳原子向外移动20px，乙分子2个H原子从氧原子向外移动15px
- 化学键：淡出消失（opacity: 0）
- 高亮：反应前框 #1565c0
- 新增：反应箭头、高温文字（淡入）

步骤2（原子重组中）：
- 显示：所有原子开始向生成物位置移动
- 动画：碳原子和1个氧原子向丙分子位置移动，6个氢原子两两配对向丁分子位置移动
- 高亮：反应箭头 #1565c0

步骤3（生成物形成）：
- 显示：反应后框、丙分子（CO完整结构）、丁分子（3个H₂完整结构）
- 高亮：反应后框 #1565c0
- 隐藏：反应前框内容
- 显示标签：丙(CO)、丁(H₂)、反应后标题

步骤4（结论 - 化学方程式）：
- 显示：完整反应前后对比
- 新增：化学方程式 "CH₄ + H₂O → CO + 3H₂"（底部中央）
- 高亮：方程式区域
- 所有分子完整显示

[交互方案]

  - scene1-btn-prev：上一步按钮，位置(300,455)，尺寸80×30px

  - scene1-step-indicator：步骤指示器，位置(380,460)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始显示步骤0（反应前分子结构）
  2. 点击"下一步"→步骤1（化学键断裂为原子）
  3. 点击"下一步"→步骤2（原子开始重组移动）
  4. 点击"下一步"→步骤3（生成物形成）
  5. 点击"下一步"→步骤4（显示完整方程式）
  6. 可随时点击"上一步"回退复习

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：分子结构简单，SVG 矢量图形清晰，无需额外库；动画使用 CSS transition 和 JS 控制
- 画布尺寸：800×500px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  [反应前框]        [箭头]       [反应后框]        |
  |   甲(CH₄) 乙(H₂O)   高温         丙(CO)  丁(H₂)   |
  |                                                  |
  |  [图例区]              [方程式]                  |
  |   氢原子                                         |
  |   氧原子                                         |
  |   碳原子                                         |
  |                                                  |
  |           [◀上一步] [步骤X/5] [下一步▶]          |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-4），每个状态对应一组显示/隐藏规则
  2. 原子动画：使用 CSS transition 配合 JS 修改 cx/cy 属性实现平滑移动
  3. 化学键淡入淡出：使用 opacity 属性 transition
  4. 事件绑定：按钮点击事件触发状态切换，更新所有元素可见性
  5. 边界检查：确保步骤不超出 0-4 范围
- ID 命名规范：
  - 所有元素 ID 以 scene1- 为前缀
  - 示例：scene1-reactant-box, scene1-product-box, scene1-c-atom, scene1-o-atom, scene1-h-atom-1, scene1-bond-1, scene1-btn-prev, scene1-btn-next
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
- 斜线填充 pattern 定义：
  ```svg
  <defs>
    <pattern id="scene1-hatch" patternUnits="userSpaceOnUse" width="10" height="10" patternTransform="rotate(45)">
      <line x1="0" y1="0" x2="0" y2="10" stroke="#888888" stroke-width="2"/>
    </pattern>
  </defs>
  ```
