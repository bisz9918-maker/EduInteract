[分步序列]
- 初始状态（步骤0）：显示反应物框甲，内含4个a₂分子（蓝色双原子）和2个cb₂c分子（红 - 绿 - 红结构），下方标注"4a₂"和"2cb₂c"，甲框下方显示"甲"标签
- 步骤1：点击「下一步」→ 显示生成物框乙，内含2个c原子（红色单原子）、2个b₂分子（绿色双原子）、4个a₂b分子（蓝 - 蓝 - 绿结构），下方标注"2c"、"2b₂"、"4a₂b"，乙框下方显示"乙"标签
- 步骤2：点击「下一步」→ 显示反应箭头（从甲框指向乙框的黑色粗箭头），标注反应方向
- 步骤3：点击「下一步」→ 高亮显示反应特点分析：反应物为"4a₂ + 2cb₂c"（一种单质+一种化合物），生成物为"2c + 2b₂ + 4a₂b"（多种新物质），用不同颜色框标注
- 步骤4：点击「下一步」→ 显示反应类型答案框（绿色背景），文字显示"分解反应"（注：根据反应特点，一种物质分解为多种物质）
- 步骤5：点击「下一步」→ 显示化学方程式框，显示配平后的方程式："4a₂ + 2cb₂c → 2c + 2b₂ + 4a₂b"，并简化为"2a₂ + cb₂c → c + b₂ + 2a₂b"

[技术实现]
- JS 库选择：原生 SVG（分子模型为简单几何图形，SVG 最适合）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  [反应物框甲]        [箭头]      [生成物框乙]    |
  |   4a₂ + 2cb₂c        →→→        2c + 2b₂ + 4a₂b |
  |                                                  |
  |                    甲              乙            |
  |                                                  |
  |  [反应类型：____]  [答案框：分解反应]            |
  |  [化学方程式：________________________]          |
  |                                                  |
  |            [◀上一步]        [下一步▶]           |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用 currentState 变量跟踪当前步骤（0-5），每步控制对应元素的 display 属性
  2. 分子模型：用<circle>元素组合表示原子，用<g>分组表示分子
  3. 动画效果：元素出现时使用淡入动画（opacity 0→1，duration 300ms）
  4. 事件绑定：按钮点击事件切换状态，更新按钮可用状态（第一步禁用上一步，最后一步禁用下一步）
  5. ID 命名规范：所有元素 ID 以 scene2-为前缀（如 scene2-box-a、scene2-mol-a2-1、scene2-btn-next）
  6. IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
- 元素 ID 示例：
  - scene2-box-reactant（反应物框）
  - scene2-box-product（生成物框）
  - scene2-arrow（反应箭头）
  - scene2-mol-a2-1~4（4 个 a₂分子）
  - scene2-mol-cb2c-1~2（2 个 cb₂c 分子）
  - scene2-mol-c-1~2（2 个 c 原子）
  - scene2-mol-b2-1~2（2 个 b₂分子）
  - scene2-mol-a2b-1~4（4 个 a₂b 分子）
  - scene2-label-reactant-type（反应类型标签）
  - scene2-label-equation（化学方程式标签）
  - scene2-btn-prev（上一步按钮）
  - scene2-btn-next（下一步按钮）
