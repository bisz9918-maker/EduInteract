[分步序列]
本场景采用多状态切换交互，共 5 个状态（4 个选项 + 初始汇总态）：

状态 0（初始/汇总态）：
- 显示四个选项按钮（均为蓝色#1565c0）
- 分析区显示："请选择一个选项进行分析"
- 汇总区显示："正确答案：B"（绿色#2e7d32）

状态 1（点击选项 A）：
- 按钮 A 变为深蓝#0d47a1，其他按钮恢复蓝色
- 分析区标题："选项 A：物体所受合力为 5N"
- 计算过程：
  · 物体做匀速直线运动
  · 根据牛顿第一定律，匀速运动时合力为 0
  · 选项声称合力为 5N，与事实不符
- 判断标记：✗（红色#c62828）
- 判断结论："该选项错误"（红色）
- 按钮 A 背景高亮为#ffebee

状态 2（点击选项 B）：
- 按钮 B 变为深蓝#0d47a1，其他按钮恢复蓝色
- 分析区标题："选项 B：物体受到的摩擦力为 12N"
- 计算过程：
  · 已知：F=5N，η=80%，n=3（绳子段数）
  · 机械效率公式：η = W_有用 / W_总 = f·s / (F·n·s) = f / (n·F)
  · 摩擦力：f = η × n × F = 0.8 × 3 × 5N = 12N
  · 计算结果与选项一致
- 判断标记：✓（绿色#2e7d32）
- 判断结论："该选项正确"（绿色）
- 按钮 B 背景高亮为#e8f5e9

状态 3（点击选项 C）：
- 按钮 C 变为深蓝#0d47a1，其他按钮恢复蓝色
- 分析区标题："选项 C：拉力 F 做功的功率为 5W"
- 计算过程：
  · 已知：F=5N，v_物=1m/s，n=3
  · 绳子自由端速度：v_绳 = n × v_物 = 3 × 1m/s = 3m/s
  · 拉力功率：P = F × v_绳 = 5N × 3m/s = 15W
  · 选项声称 5W，与计算结果 15W 不符
- 判断标记：✗（红色#c62828）
- 判断结论："该选项错误"（红色）
- 按钮 C 背景高亮为#ffebee

状态 4（点击选项 D）：
- 按钮 D 变为深蓝#0d47a1，其他按钮恢复蓝色
- 分析区标题："选项 D：10s 内机械所做的有用功为 500J"
- 计算过程：
  · 已知：f=12N（由选项 B 计算得），v_物=1m/s，t=10s
  · 物体移动距离：s = v_物 × t = 1m/s × 10s = 10m
  · 有用功：W_有用 = f × s = 12N × 10m = 120J
  · 选项声称 500J，与计算结果 120J 不符
- 判断标记：✗（红色#c62828）
- 判断结论："该选项错误"（红色）
- 按钮 D 背景高亮为#ffebee

[交互方案]
- 交互类型：多状态切换（4 个选项按钮）
- 控件说明：
  · 按钮 A（80,60,140,40）：显示选项 A 的分析
  · 按钮 B（240,60,140,40）：显示选项 B 的分析
  · 按钮 C（400,60,140,40）：显示选项 C 的分析
  · 按钮 D（560,60,140,40）：显示选项 D 的分析
- 教师操作流程：
  1. 初始状态展示汇总答案（正确答案：B）
  2. 点击按钮 A，讲解为什么合力为 0（匀速运动）
  3. 点击按钮 B，详细推导摩擦力计算过程（核心考点）
  4. 点击按钮 C，讲解功率计算中绳子速度的关系
  5. 点击按钮 D，讲解有用功的计算方法
  6. 可反复切换对比，强化学生理解

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  · 原因：本场景以文本展示和按钮切换为主，无需复杂绘图库
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [800×500 画布]
  ┌────────────────────────────────────────────────────────────┐
  │  [选项 A]  [选项 B]  [选项 C]  [选项 D]   ← 顶部按钮区 y=60│
  ├────────────────────────────────────────────────────────────┤
  │  ┌──────────────────────────────────────────────────────┐  │
  │  │  选项 X 分析                              [✓/✗]     │  │
  │  │                                                      │  │
  │  │  计算过程内容...                                     │  │
  │  │  · 已知条件...                                       │  │
  │  │  · 公式推导...                                       │  │
  │  │  · 计算结果...                                       │  │
  │  │                                                      │  │
  │  │  该选项正确/错误                                     │  │
  │  └──────────────────────────────────────────────────────┘  │
  ├────────────────────────────────────────────────────────────┤
  │  正确答案：B                                               │  │
  └────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用 currentState 变量跟踪当前选中选项（0-4，0 为初始态）
  2. 每个选项的数据对象包含：title、steps 数组、isCorrect 布尔值
  3. 点击按钮时更新 currentState，调用 renderAnalysis() 重绘分析区
  4. 按钮样式根据 currentState 动态切换（选中态/正常态/正确高亮/错误高亮）
  5. 判断标记使用 Unicode 字符 ✓ (U+2713) 和 ✗ (U+2717)
- ID 命名规范：
  · 按钮：scene3-btn-a, scene3-btn-b, scene3-btn-c, scene3-btn-d
  · 分析区：scene3-analysis-bg, scene3-analysis-title, scene3-analysis-content
  · 判断标记：scene3-judgment-mark, scene3-judgment-text
  · 汇总区：scene3-summary-bg, scene3-summary-text
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
