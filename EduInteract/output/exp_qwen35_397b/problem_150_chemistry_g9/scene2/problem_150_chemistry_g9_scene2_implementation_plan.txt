冲突解决方案：
- 所有装置标签与功能标签采用垂直排列（标签在上，功能在下），间距 20px，无重叠
- 四个装置横向间距 170px+，功能标签不会相互干扰
- 质量标注横向间距 130px，足够容纳文本
- 底部控件栏 y=440 起始，与内容区 y=420 有 20px 间隙

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  · "上一步"按钮：位置 (280,455)，尺寸 100×35px，灰色边框 #999999，点击返回上一状态
  · "下一步"按钮：位置 (420,455)，尺寸 100×35px，绿色填充 #2e7d32，点击进入下一状态
  · 步骤指示器：位置 (400,485)，显示"步骤 X/6"，只读文本
- 教师操作流程：
  1. 初始展示四个装置原貌，让学生识别
  2. 点击"下一步"显示各装置功能，确认学生理解
  3. 点击"下一步"提出问题，引发思考
  4. 点击"下一步"展示错误顺序，分析干扰原因
  5. 点击"下一步"展示正确顺序，强调测量原理
  6. 点击"下一步"总结完整连接顺序
  7. 可随时点击"上一步"回退复习关键概念

[技术实现]
- JS 库选择：原生 SVG（简单几何图形首选，无需额外库）
- 画布尺寸：800×500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────┐
  │  [装置 a]    [装置 b]    [装置 c]    [装置 d]       │ y=60-210
  │   酒精灯     NaOH 瓶    浓硫酸瓶    石灰水瓶        │
  │                                                     │
  │  ┌─────────────────────────────────────────────┐   │ y=250-420
  │  │  [连接示意图区]                              │   │
  │  │   甲 → [c] → [b] → [a]                      │   │
  │  │   气体箭头 + 质量标注                        │   │
  │  └─────────────────────────────────────────────┘   │
  │                                                     │
  │  [◀上一步]  [步骤 3/6]  [下一步▶]                  │ y=440-500
  └─────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-5），steps 数组存储每步的显示/隐藏元素 ID 列表
  2. 坐标计算：所有元素使用绝对坐标（spec 中规划的像素值），洗气瓶导管"长进短出"原则
  3. 动画曲线：淡入使用 CSS transition opacity 0.3s ease-in-out
  4. 事件绑定：按钮点击事件绑定到 updateStep() 函数，更新当前状态并重绘
  5. 元素显隐：使用 display:none / display:block 或 opacity:0 / opacity:1 控制
- ID 命名规范：所有元素 ID 以 scene2- 为前缀
  · scene2-device-a, scene2-device-b, scene2-device-c, scene2-device-d
  · scene2-label-a, scene2-label-b, scene2-label-c, scene2-label-d
  · scene2-func-a, scene2-func-b, scene2-func-c, scene2-func-d
  · scene2-conn-area, scene2-conn-correct, scene2-conn-wrong
  · scene2-arrow-1, scene2-arrow-2, scene2-arrow-3, scene2-arrow-4
  · scene2-mass-c, scene2-mass-b
  · scene2-btn-prev, scene2-btn-next, scene2-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
