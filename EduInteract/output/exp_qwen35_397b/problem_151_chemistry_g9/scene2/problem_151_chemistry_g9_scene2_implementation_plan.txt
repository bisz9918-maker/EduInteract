[交互方案]

- 控件说明：
  - 「上一步」按钮：位置 (280,460)，尺寸 80×35px，背景 #e0e0e0，文字 #000000，点击后退到前一状态
  - 「下一步」按钮：位置 (440,460)，尺寸 80×35px，背景 #1565c0，文字 #ffffff，点击前进到下一状态

- 教师操作流程：
  1. 初始状态展示完整反应微观图，让学生观察反应前后的分子变化
  2. 点击「下一步」高亮碳原子，引导学生数出反应前后碳原子数目（均为 1 个）
  3. 点击「下一步」高亮氢原子，引导学生数出反应前后氢原子数目（均为 4 个）
  4. 点击「下一步」高亮氧原子，引导学生数出反应前后氧原子数目（均为 4 个）
  5. 点击「下一步」显示结论，总结原子数目不变的规律，验证选项 A 正确

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript。原因：本场景为 2D 静态图示加分步高亮，无需复杂动画或 3D 效果，原生 SVG 足够实现且性能好，代码简洁易维护。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +----------------------------------------------------------+
  |  [反应前框 300×200]    →点燃→    [反应后框 300×200]      |
  |   甲烷 A    氧气 B              CO2 C    水分子 D        |
  |   (50,50)-(350,250)            (450,50)-(750,250)       |
  |                                                          |
  |              [原子计数对比表格 400×120]                  |
  |              (200,280)-(600,400)                         |
  |              ┌─────────────────────────┐                 |
  |              │原子类型│反应前│反应后│                 |
  |              ├────────┼─────┼──────┤                 |
  |              │碳原子  │ 1   │  1   │                 |
  |              │氢原子  │ 4   │  4   │                 |
  |              │氧原子  │ 4   │  4   │                 |
  |              └─────────────────────────┘                 |
  |                    原子数目不变 ✓                        |
  |                                                          |
  |              [◀上一步]  步骤 X/4  [下一步▶]              |
  |              (控件栏 y=440~490)                          |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量 (0-4) 跟踪当前步骤，steps 数组存储每步的配置
  2. 原子分组：为每种原子类型的 SVG 元素添加统一 class（如 scene2-carbon-atom），便于批量高亮
  3. 高亮效果：使用 SVG filter 实现发光效果（<feGaussianBlur> + <feMerge>），动态添加/移除光环元素
  4. 表格动态填充：每步更新对应表格行的 innerHTML，使用 CSS transition 实现淡入效果
  5. 按钮状态：第一步禁用「上一步」，最后一步禁用「下一步」或改为「完成」
  6. 坐标计算：所有原子位置硬编码，确保与题目图片一致
- ID 命名规范：所有交互元素 ID 必须以 scene2- 为前缀
  - scene2-react-before-box, scene2-react-after-box
  - scene2-molecule-a, scene2-molecule-b, scene2-molecule-c, scene2-molecule-d
  - scene2-carbon-atom-1, scene2-carbon-atom-2
  - scene2-hydrogen-atom-1~8
  - scene2-oxygen-atom-1~5
  - scene2-table-row-carbon, scene2-table-row-hydrogen, scene2-table-row-oxygen
  - scene2-btn-prev, scene2-btn-next, scene2-step-indicator
  - scene2-highlight-ring（动态创建）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
