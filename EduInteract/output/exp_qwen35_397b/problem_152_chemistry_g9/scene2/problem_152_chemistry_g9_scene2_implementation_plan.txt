[图示主题与整合说明]
- 本图示主题：测定空气中氧气含量实验过程动态演示
- 整合的步骤/概念：整合点燃前状态→红磷燃烧→冷却后→打开止水夹→水进入集气瓶的完整过程，展示空气中氧气约占 1/5 体积的实验原理
- 教学价值：教师可通过分步演示，让学生清晰观察每个阶段的实验现象变化，理解红磷燃烧消耗氧气、瓶内气压降低、水被压入集气瓶的因果关系，直观得出氧气约占空气体积 1/5 的结论

[分步序列]
- 初始状态（步骤 0）：显示集气瓶、烧杯、导管、止水夹（关闭状态#000000）、燃烧匙内红磷（未点燃#c62828）、集气瓶底部少量水、烧杯内水。步骤说明文字："步骤 0：实验装置准备完毕，止水夹关闭"
- 步骤 1：红磷被点燃并伸入集气瓶。红磷颜色变为亮红色#c62828 并添加发光效果（外发光阴影）。步骤说明文字："步骤 1：点燃红磷，迅速伸入集气瓶并塞紧橡胶塞"
- 步骤 2：红磷燃烧，产生大量白烟。在集气瓶内 (170,200)-(230,300) 区域显示多个半透明圆形 (#888888 透明度 50%) 模拟白烟，圆形有轻微上下浮动动画。步骤说明文字："步骤 2：红磷燃烧，产生大量白烟（五氧化二磷）"
- 步骤 3：燃烧结束，白烟逐渐消失，红磷变暗。白烟圆形透明度降至 20%，红磷颜色变为暗红色#8b0000。步骤说明文字："步骤 3：燃烧结束，待集气瓶冷却至室温"
- 步骤 4：打开止水夹。止水夹颜色从#000000 变为#2e7d32（绿色表示打开）。步骤说明文字："步骤 4：打开止水夹"
- 步骤 5：水从烧杯经导管进入集气瓶，水位上升至刻度 1 处（约 1/5 体积）。集气瓶内水填充区域从 (125,395)-(275,400) 变为 (125,350)-(275,400)，烧杯内水位略微下降。导管内显示水流效果（蓝色小圆点沿导管移动）。步骤说明文字："步骤 5：水进入集气瓶至刻度 1 处，氧气约占空气体积的 1/5"

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位置 (320,455)，点击后返回上一状态，步骤 0 时禁用
  - 「下一步」按钮：位置 (430,455)，点击后进入下一状态，步骤 5 时禁用
  - 步骤指示器：位置 (380,455)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始加载显示步骤 0，教师介绍实验装置组成
  2. 点击「下一步」至步骤 1，讲解点燃红磷的操作要点
  3. 点击「下一步」至步骤 2，引导学生观察白烟现象，解释化学反应
  4. 点击「下一步」至步骤 3，强调冷却至室温的必要性
  5. 点击「下一步」至步骤 4，讲解打开止水夹的时机
  6. 点击「下一步」至步骤 5，引导学生观察水位变化，得出氧气约占 1/5 的结论
  7. 可随时点击「上一步」回退复习关键现象

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript。原因：本场景为 2D 实验装置示意图，几何形状简单（矩形、线段、圆形），无需复杂库；原生 SVG 可精确控制每个元素的状态变化和动画，代码轻量且易于多场景合并
- 画布尺寸：800 × 500 px（固定画布）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +----------------------------------------------------------+
  |                    步骤说明文字                           |
  |                     (400,50)                              |
  |                                                           |
  |    集气瓶              导管              烧杯              |
  |   +-------+          ======            +-------+          |
  |   |  白烟  |---------|止水夹|----------|  水   |          |
  |   | 红磷  |                            |       |          |
  |   |       |                            |       |          |
  |   |  水   |                            |       |          |
  |   +-------+                            +-------+          |
  |    刻度 1-4 左侧                                          |
  |                                                           |
  |              [◀上一步]  步骤 X/5  [下一步▶]               |
  |                    (控件栏 y=440-490)                     |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量 (0-5) 跟踪当前步骤，每个步骤对应一组元素显示/隐藏/样式状态
  2. 坐标计算：所有元素坐标硬编码在 SVG 中，水位变化通过修改 rect 的 y/height 属性实现
  3. 动画曲线：白烟浮动使用 CSS animation (translateY ±5px, opacity 0.3-0.6)，水流使用 SMIL animateMotion 或 JS requestAnimationFrame
  4. 事件绑定：按钮点击事件绑定到 updateStep() 函数，根据 currentStep 更新所有元素状态
  5. 元素状态管理：每个可变化元素通过 class 或 data-step 属性标记其显示步骤，如 class="step-2-only"
- ID 命名规范：所有交互元素 ID 必须以 scene2- 为前缀（如 scene2-collect-bottle, scene2-red-phosphorus, scene2-water-level, scene2-step-indicator）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
