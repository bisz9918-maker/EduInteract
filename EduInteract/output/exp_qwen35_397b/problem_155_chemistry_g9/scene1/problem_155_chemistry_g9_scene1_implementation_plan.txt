[图示主题与整合说明]
- 本图示主题：化学提纯装置结构与物质转化流程
- 整合内容：装置结构、气体流向、两容器温度设置、各阶段物质状态变化、反应方向标注
- 教学价值：教师可使用此图示逐步展示钴的提纯过程，从进气到容器1发生正向反应（900℃）、气态产物传输到容器2、容器2发生逆向反应（600℃）、最终得到纯净钴固体和回收的HCl气体。分步呈现帮助学生追踪物质变化路径，理解化学提纯原理。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript
  - 原因：本图示为2D装置示意图，几何形状简单（矩形、圆角矩形、箭头），无需复杂库
  - 原生SVG可精确控制每个元素的位置和样式，便于分步显示/隐藏
  - 代码轻量，加载快，适合课堂演示

- 画布尺寸：800 × 500 px（固定）

- 布局草图（ASCII）：
  ```
  [800×500 画布]
  +----------------------------------------------------------+
  |                    900℃           600℃                   |
  |                    容器1          容器2                   |
  |   气体Y → ══════[████████]═══[████████]══════ → 导出气体  |
  |                    含杂质Co      纯净Co                   |
  |                      ↑              ↓                     |
  |                   正向反应      逆向反应                  |
  |                                                          |
  |            Co + 2HCl ⇌ CoCl₂ + H₂ (反应方程式)            |
  |                                                          |
  |              [◀上一步]  [下一步▶]  [重置]                 |
  +----------------------------------------------------------+
  ```

- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-4），steps 数组存储每步的配置
  2. 每步配置包含：要显示的元素ID列表、要隐藏的元素ID列表、样式变更
  3. 使用 getElementById 精确控制每个元素，避免跨场景污染
  4. 按钮事件绑定：点击时更新 currentState，调用 renderStep() 函数
  5. 边界处理：步骤0时禁用"上一步"，步骤4时禁用"下一步"
  6. 动画效果：元素显示/隐藏使用 opacity 过渡（0.3s），增强视觉流畅性

- ID 命名规范：
  - 所有元素ID以 scene1- 为前缀
  - 示例：scene1-container1, scene1-container2, scene1-temp900, scene1-temp600,
          scene1-arrow-in, scene1-arrow-out, scene1-solid1, scene1-solid2,
          scene1-flow-arrow1, scene1-flow-arrow2, scene1-reaction-up, scene1-reaction-down,
          scene1-equation, scene1-btn-prev, scene1-btn-next, scene1-btn-reset

- IIFE 隔离：
  ```javascript
  (function() {
      // 所有JS代码包在此闭包内
      let currentState = 0;
      // ... 其他代码
  })();
  ```
