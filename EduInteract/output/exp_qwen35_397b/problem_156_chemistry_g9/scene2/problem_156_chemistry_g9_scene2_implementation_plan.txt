[图示主题与整合说明]
- 本图示主题：化学反应本质——化学键断裂与原子重组
- 整合的步骤/概念：反应物分子拆解为原子、原子重新组合、生成物分子形成、反应类型判断
- 教学价值：教师可使用此图示分步展示化学反应的微观本质，帮助学生理解"原子不变、分子改变"的核心概念。通过可视化化学键的断裂与形成过程，学生能直观理解化合反应的特征（多变一），区分物理变化与化学变化的本质差异。

[分步序列]
步骤 0（初始状态）：展示反应物
- 显示 4 个○○分子（白色双原子）和 1 个●●分子（黑色双原子）在反应物区（y=60~90）
- 分子位置：A1(200,70), A2(320,70), B(440,70), A3(560,70)
- 化学键为黑色实线
- 显示标题"反应物"
- 原子区、生成物区为空

步骤 1：化学键断裂
- 反应物区分子化学键变为红色虚线（#c62828）
- 原子区开始显示 6 个游离原子（4 个○ + 2 个●），从反应物位置向下移动
- 显示过程标签"化学键断裂"
- 原子运动轨迹显示灰色点线

步骤 2：原子重组
- 原子区 6 个原子完全显示，化学键消失
- 原子位置：O1(180,210), O2(260,210), O3(340,210), O4(420,210), B1(380,210), B2(460,210)
- 显示过程标签"原子重组"
- 生成物区开始显示原子移动轨迹

步骤 3：化学键形成
- 生成物区显示 2 个○○●分子，化学键为绿色虚线（#2e7d32）
- 分子位置：C1(320,370), C2(480,370)
- 剩余 2 个○○分子显示在右侧（600,370）
- 显示过程标签"化学键形成"

步骤 4（最终状态）：结论展示
- 所有化学键变为黑色实线
- 显示结论标签"化合反应：多变一"（绿色加粗）
- 隐藏过程标签
- 显示完整反应流程

- 过程标签 y 坐标间隔 50-100px（150→250→300），与原子区 y=210 有重叠风险
- 解决方案：将"原子重组"移至 y=280，将"化学键形成"移至 y=320
- 结论标签 y=420 与按钮区 y=460 间距 40px，安全
- 原子标签不单独显示，避免与原子图形重叠

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮：位于 (280,460)，80×30px，点击后退到前一状态
  - 下一步按钮：位于 (440,460)，80×30px，点击前进到下一状态
  - 步骤指示器：位于 (400,490)，显示当前步骤/总步骤数
- 教师操作流程：
  1. 初始展示反应物分子，讲解反应前的物质组成
  2. 点击"下一步"，展示化学键断裂过程，讲解旧键断裂需要吸收能量
  3. 点击"下一步"，展示游离原子状态，强调原子是化学变化中的最小粒子
  4. 点击"下一步"，展示新化学键形成，讲解新键形成释放能量
  5. 点击"下一步"，展示最终生成物和结论，总结化合反应特征

[技术实现]
- JS 库选择：原生 SVG
  - 原因：分子结构为简单几何图形（圆形 + 线段），SVG 缩放不失真，适合精确控制原子位置和化学键样式
- 画布尺寸：800×500px
- 布局草图：
  ```
  [图示区 800×500]
  +------------------------------------------+
  |           反应物 (y=35)                  |
  |   ○○  ○○  ●●  ○○  (y=60~90)             |
  |                                          |
  |        化学键断裂 (y=150)                |
  |                                          |
  |         游离原子 (y=185)                 |
  |      ○ ○ ○ ○ ● ●  (y=210)               |
  |                                          |
  |         原子重组 (y=280)                 |
  |       化学键形成 (y=320)                 |
  |                                          |
  |           生成物 (y=335)                 |
  |        ○○●   ○○●   ○○  (y=370)          |
  |                                          |
  |     化合反应：多变一 (y=420)             |
  |                                          |
  |   [◀上一步]      [下一步▶]  (y=460)      |
  |         步骤 X/4 (y=490)                 |
  +------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-4），每个状态对应一组 SVG 元素显示/隐藏
  2. 原子定义：使用<symbol>定义白色原子和黑色原子模板，通过<use>复用
  3. 化学键动画：通过 CSS transition 实现实线→虚线→消失的过渡效果
  4. 运动轨迹：使用<line>元素，stroke-dasharray 实现点线效果，动画完成后隐藏
  5. 按钮事件：绑定 click 事件，更新 currentState 并调用 render() 重绘
  6. 边界处理：第一步禁用"上一步"，最后一步禁用"下一步"
- ID 命名规范：所有元素 ID 以 scene2- 为前缀
  - 原子：scene2-atom-w1, scene2-atom-w2, ..., scene2-atom-b1, scene2-atom-b2
  - 分子：scene2-mol-a1, scene2-mol-a2, scene2-mol-b, scene2-mol-c1, scene2-mol-c2
  - 化学键：scene2-bond-a1, scene2-bond-a2, scene2-bond-b, ...
  - 标签：scene2-label-reactants, scene2-label-atoms, scene2-label-products
  - 按钮：scene2-btn-prev, scene2-btn-next, scene2-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
