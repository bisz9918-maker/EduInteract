冲突检查结果：
- 选项 A 文字右边界(330)与标识 A 左边界(340)间距 10px → 略小但可接受（标识在卡片内右侧）
- 选项 B 文字右边界(710)与标识 B 左边界(720)间距 10px → 略小但可接受
- 选项 C 文字右边界(330)与标识 C 左边界(340)间距 10px → 略小但可接受
- 选项 D 文字右边界(710)与标识 D 左边界(720)间距 10px → 略小但可接受
- 各卡片之间间距：卡片 A/B 之间 60px，卡片 C/D 之间 60px，卡片 A/C 之间 30px，卡片 B/D 之间 30px → 无冲突
- 判断依据区与卡片区间距：30px → 无冲突
- 控件栏与判断依据区间距：20px → 无冲突

解决方案：将选项文字右边界限制在 320px 内（卡片宽度 320px，文字从 70px 开始，最多到 310px），标识从 325px 开始，确保 15px 间距。

  - "选项 A"按钮（280,450）：显示选项 A 的验证分析
  - "选项 B"按钮（360,450）：显示选项 B 的验证分析
  - "选项 C"按钮（440,450）：显示选项 C 的验证分析
  - "选项 D"按钮（520,450）：显示选项 D 的验证分析
- 教师操作流程：
  1. 初始状态展示四个选项，让学生观察题目
  2. 点击"选项 A"，展示化合反应的判断依据，引导学生理解化合反应定义
  3. 点击"选项 B"，展示单质/化合物的区别，强调生成物由不同原子组成
  4. 点击"选项 C"，展示分子种类变化，对比反应前后
  5. 点击"选项 D"，展示反应计量比的计算方法，强调要区分"总量"和"参与反应的量"

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：本场景为静态卡片布局 + 状态切换，无需复杂动画或绘图，原生 SVG 足够且性能最优
- 画布尺寸：800×500 px（固定）
- 布局草图（ASCII）：
  ```
  [800×500 画布]
  +--------------------------------------------------+
  | [选项 A 卡片]           [选项 B 卡片]            | y=50-140
  |  A．是化合反应 ✓       B．有单质生成 ✗          |
  +--------------------------------------------------+
  | [选项 C 卡片]           [选项 D 卡片]            | y=170-260
  |  C．分子种类不变 ✗     D．4:1✗                  |
  +--------------------------------------------------+
  | [判断依据区]                                     | y=290-420
  |  选项 A 分析：...    [微观示意图缩略]            |
  +--------------------------------------------------+
  |      [初始] [选项 A] [选项 B] [选项 C] [选项 D]  | y=440-490
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用 currentState 变量（0-4）跟踪当前状态，点击按钮时更新状态并重绘
  2. 卡片高亮：通过修改 rect 的 fill 属性实现（#f5f5f5 → #e3f2fd）
  3. 判断标识显示/隐藏：通过 text 元素的 display 属性或 opacity 控制
  4. 判断依据文本更新：根据 currentState 更新 textContent
  5. 事件绑定：每个按钮绑定 click 事件，调用 updateState(newState)
  6. IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染

  - 选项 D 卡片：scene3-card-d
  - 判断标识 A：scene3-mark-a
  - 判断标识 B：scene3-mark-b

  - 判断标识 D：scene3-mark-d
  - 判断依据区：scene3-explanation
