某固体物质的溶解度曲线如图所示，根据图回答如下问题：

（1）图中B点的意义：表示该物质在t₃℃时，每100g溶剂和S₁g溶质形成不饱和溶液．A点的意义：$\underline{\hspace{5em}}$．此溶液的溶质质量分数的表达式$\underline{\hspace{5em}}$．

（2）若A、B两点的溶液在保持温度不变的情况下各加20克水，A点的溶解度将$\underline{\hspace{5em}}$（填"增大"、"减小"、或"不变"）；A、B的溶质质量分数$\underline{\hspace{5em}}$（填"前者大"、"后者大"或"相等"）．

（3）当温度降低时，A点变动后溶液的质量分数与原来比较$\underline{\hspace{5em}}$（填"增大"、"减小"或"不变"）．

（4）若使M点的（100+S₁）g溶液成为饱和溶液的方法：降温至$\underline{\hspace{5em}}$℃；增加溶质$\underline{\hspace{5em}}$g和$\underline{\hspace{5em}}$．

题目分析：

本题考查溶解度曲线的理解与应用，核心知识点包括：

  1. 溶解度曲线上点的含义（饱和溶液）
  2. 曲线下方点的含义（不饱和溶液）
  3. 溶解度只与温度有关，与溶剂量无关
  4. 溶质质量分数的计算
  5. 不饱和溶液转化为饱和溶液的方法

整体讲解思路：

  1. 首先认识溶解度曲线的基本结构（坐标轴、曲线含义）
  2. 理解曲线上点与曲线下方点的区别
  3. 分析温度变化对溶液状态的影响
  4. 掌握不饱和溶液变饱和的三种方法

步骤 1/5

本图示教学说明：

本图示帮助学生建立溶解度曲线的基本认知框架。

引导学生观察要点：

  1. 曲线上的任意一点都表示对应温度下的饱和溶液
  2. 曲线下方的点表示对应温度下的不饱和溶液
  3. 同一温度下，曲线上点的溶质质量分数大于曲线下方点

关键公式：

饱和溶液的溶质质量分数计算公式：

$$\text{溶质质量分数} = \frac{\text{溶质质量}}{\text{溶液质量}} \times 100\% = \frac{S}{100 + S} \times 100\%$$

其中S为该温度下的溶解度。

A点的具体计算：

A点在t₂℃时溶解度为S₂克，溶质质量分数为：

$$\frac{S_2}{100 + S_2} \times 100\%$$

讲解建议：

先让学生识别A点在曲线上，因此是饱和溶液；B点和M点在曲线下方，因此是不饱和溶液。强调溶解度的定义：一定温度下，100g溶剂中达到饱和时溶解的溶质质量。

本图示教学说明：

本图示展示温度降低时饱和溶液的变化过程。

核心概念：

  1. 该物质溶解度随温度升高而增大（曲线向上倾斜）
  2. 饱和溶液降温时，溶解度减小，多余溶质会析出
  3. 析出晶体后，溶液仍为饱和溶液，但溶质质量分数减小

问题（3）解答：

当温度降低时，A点沿曲线向左下方移动，溶解度减小，溶质析出。

降温后溶质质量分数与原来比较：减小

原因：原质量分数为 $\frac{S_2}{100 + S_2}$，降温后溶解度变为S'（S' < S₂），质量分数变为 $\frac{S'}{100 + S'}$，显然减小。

讲解建议：

让学生拖动滑块观察：温度降低→溶解度减小→晶体析出→溶液仍饱和但浓度降低。强调析出晶体后，溶剂质量不变，溶质质量减少，因此质量分数减小。

本图示教学说明：

本图示对比展示不饱和溶液转化为饱和溶液的三种方法。

问题（4）解答：

M点坐标为(t₂, S₁)，表示t₂℃时100g溶剂中溶解了S₁g溶质的不饱和溶液。

方法一：降温

降温至 t₁ ℃（t₁℃时溶解度恰好为S₁克）

方法二：增加溶质

需增加溶质 (S₂ - S₁) g（从S₁增加到S₂达到饱和）

方法三：蒸发溶剂

恒温蒸发溶剂，使溶剂质量减少，溶质质量分数增大至饱和

问题（2）补充解答：

A、B两点溶液保持温度不变各加20克水：

  • A点的溶解度将 不变（溶解度只与温度有关）
  • A点原为饱和溶液，B点原为不饱和溶液，加水后两者都变为不饱和溶液
  • 溶质质量分数：前者大（A点原溶质质量分数为$\frac{S_2}{100+S_2}$，B点为$\frac{S_1}{100+S_1}$，因S₂ > S₁，故A点质量分数大；加水相同倍数后，相对大小关系不变）

讲解建议：

强调三种方法的本质都是使$\frac{\text{溶质}}{\text{溶剂}}$的比值达到该温度下溶解度对应的饱和比值。降温是降低溶解度标准，加溶质是增加分子，蒸发溶剂是减少分母。
