[图示主题与整合说明]
- 本图示主题：溶解度曲线基础——曲线上点与曲线下方点的含义对比
- 整合的内容：坐标轴标注、溶解度曲线、A 点（饱和）、B 点（不饱和）、M 点（不饱和）的位置及含义、溶质质量分数公式
- 教学价值：教师可使用此图示逐步讲解溶解度曲线的含义，通过高亮不同点对比饱和溶液与不饱和溶液的区别，帮助学生理解曲线上点表示饱和状态、曲线下方点表示不饱和状态的核心概念

[分步序列]
- 步骤 0（初始状态）：显示坐标系、溶解度曲线、所有刻度标签 (t₁,t₂,t₃,S₁,S₂)、轴标签。点 A 显示但不高亮，辅助虚线显示。说明框显示"溶解度曲线表示某物质在不同温度下的溶解度"
- 步骤 1：高亮点 A（蓝色光晕），A 点标签"A"显示。说明框更新为"A 点在曲线上，表示 t₂℃时该物质的饱和溶液，溶解度为 S₂克"
- 步骤 2：显示点 M（绿色），M 点标签"M"显示，M 点水平虚线高亮。说明框更新为"M 点在曲线下方，表示 t₂℃时该物质的不饱和溶液，溶质质量为 S₁克（S₁<S₂）"
- 步骤 3：显示点 B（绿色），B 点标签"B"显示，B 点垂线显示。说明框更新为"B 点也在曲线下方，表示 t₃℃时的不饱和溶液。M、B 两点溶质质量相同（均为 S₁克），但温度不同"
- 步骤 4：说明框显示溶质质量分数公式："溶质质量分数 = 溶质质量 / (溶质质量 + 溶剂质量) × 100% = S / (S + 100) × 100%"，A 点再次高亮强调饱和溶液

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - "上一步"按钮：位于 (280,465)，宽 100px，高 30px，点击返回上一状态
  - "下一步"按钮：位于 (420,465)，宽 100px，高 30px，点击进入下一状态
  - 步骤指示器：位于 (390,465)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始展示坐标系和曲线，讲解溶解度曲线的基本结构
  2. 点击"下一步"高亮 A 点，讲解饱和溶液的含义
  3. 点击"下一步"显示 M 点，对比同一温度下饱和与不饱和的区别
  4. 点击"下一步"显示 B 点，讲解不同温度下不饱和溶液的对比
  5. 点击"下一步"显示公式，总结溶质质量分数的计算方法

[技术实现]
- JS 库选择：原生 SVG（简单几何图形首选，无需额外库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  Y 轴标签                                         |
  |  溶  |                                    说明框  |
  |  解  |                                    动态  |
  |  度  |     曲线                                  |
  |  （  |    /                                      |
  |  克  |   /  A●                                   |
  |  ）  |  /   :                                    |
  |      | /    :M●────────────B●                    |
  |      |/    :    :            :                   |
  |  ____|_____:____:____________:___ X 轴标签        |
  |      t₁   t₂   t₃           温度（℃）            |
  |                                                  |
  |            [◀上一步]  步骤 X/5  [下一步▶]         |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量 (0-4) 跟踪当前步骤
  2. 每个步骤对应一个 updateScene(step) 函数，控制元素显示/隐藏/高亮
  3. 所有交互元素 ID 以 "scene1-" 为前缀（如 scene1-point-a, scene1-btn-next）
  4. JS 代码包在 IIFE 中：(function() { ... })() 避免全局污染
  5. 按钮事件绑定：document.getElementById('scene1-btn-next').addEventListener('click', ...)
  6. 动画效果：使用 CSS transition 实现平滑过渡（opacity, fill-opacity）
  7. 曲线绘制：使用 SVG path 的二次贝塞尔曲线 Q 或三次贝塞尔曲线 C
- ID 命名规范：
  - 点：scene1-point-a, scene1-point-m, scene1-point-b
  - 虚线：scene1-dash-a-vertical, scene1-dash-a-horizontal, scene1-dash-m-horizontal
  - 标签：scene1-label-a, scene1-label-m, scene1-label-b, scene1-label-t1, scene1-label-s1
  - 按钮：scene1-btn-prev, scene1-btn-next
  - 说明框：scene1-info-box
  - 坐标轴：scene1-axis-x, scene1-axis-y
  - 曲线：scene1-curve
