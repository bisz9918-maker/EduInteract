[图示主题与整合说明]
- 本图示主题：M 点不饱和溶液转化为饱和溶液的三种方法对比
- 整合内容：M 点初始状态、方法一（降温至 t₁）、方法二（加溶质 S₂-S₁克）、方法三（蒸发溶剂），三种方法的路径对比
- 教学价值：教师可通过切换三种方法，直观展示不饱和溶液转化为饱和溶液的不同途径，帮助学生理解溶解度曲线的应用。每种方法的路径和关键数据高亮显示，便于对比分析温度变化、溶质增加、溶剂减少对溶液状态的影响。

[交互方案]
- 交互类型：多状态切换（3 个按钮）
- 控件说明：
  - 按钮 1「降温」：位于 (180,455)，100×30px，点击后显示方法一的路径和标注
  - 按钮 2「加溶质」：位于 (350,455)，100×30px，点击后显示方法二的路径和标注
  - 按钮 3「蒸发溶剂」：位于 (520,455)，100×30px，点击后显示方法三的路径和标注
- 教师操作流程：
  1. 初始状态展示 M 点不饱和溶液的位置
  2. 点击「降温」按钮，展示水平向左的路径，讲解温度降低使溶液达到饱和
  3. 点击「加溶质」按钮，展示垂直向上的路径，讲解增加溶质使溶液达到饱和
  4. 点击「蒸发溶剂」按钮，展示斜向路径，讲解减少溶剂使溶液达到饱和
  5. 可反复切换对比三种方法的异同

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript。原因：本场景为 2D 坐标系和简单几何图形，原生 SVG 足够实现，无需引入重型库，加载快且易于维护。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  溶解度 (克)                                      |
  |     ↑                                            |
  |  S₂ + - - - - - - - - -A- - - - -                |
  |     |                  |                         |
  |     |                  |  曲线                   |
  |  S₁ + - - - - - - -M- -| - -B- -                 |
  |     |              /   |                         |
  |     |           /      |                         |
  |     +--------t₁---t₂---t₃------→ 温度 (℃)        |
  |                                                    |
  |          [降温]  [加溶质]  [蒸发溶剂]              |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0=初始，1=降温，2=加溶质，3=蒸发溶剂），每次点击按钮更新状态并重绘
  2. 坐标计算：所有元素坐标预先计算好，硬编码在 JS 中，避免运行时计算误差
  3. 动画曲线：路径箭头使用 SVG <path> 元素，带箭头标记（marker-end）
  4. 事件绑定：三个按钮分别绑定 click 事件，点击时更新 currentState 并调用 render() 函数
  5. 高亮逻辑：当前选中的方法路径和标注显示，其他隐藏；使用 display 属性控制可见性
- ID 命名规范：所有交互元素 ID 必须以 scene3- 为前缀（如 scene3-point-m、scene3-path-method1、scene3-btn-cooling）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
