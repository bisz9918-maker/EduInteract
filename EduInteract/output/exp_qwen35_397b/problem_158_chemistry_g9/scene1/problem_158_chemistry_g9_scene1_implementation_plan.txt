[分步序列]
步骤0（初始状态）：
- 显示三个三角形转化图的基础结构（黑色箭头）
- 显示所有化学物质标签（CaCO₃、CaO、Ca(OH)₂、Fe、Fe₂O₃、FeSO₄、H₂O、O₂、MgO）
- 显示序号①②③
- 隐藏所有可行性标记（✓/✗）
- 方程式区显示："点击「下一步」开始分析图①"
- 选项区显示四个选项，无高亮

步骤1（分析图①）：
- 图①的三个箭头变为绿色 #2e7d32 加粗（stroke-width="3"）
- 在图①三个箭头中点外侧显示绿色✓标记
- 方程式区显示三条反应方程式：
  "图①分析：
  1. CaCO₃ → CaO：CaCO₃ →(高温) CaO + CO₂↑  ✓ 可一步实现
  2. CaO → Ca(OH)₂：CaO + H₂O → Ca(OH)₂  ✓ 可一步实现
  3. Ca(OH)₂ → CaCO₃：Ca(OH)₂ + CO₂ → CaCO₃↓ + H₂O  ✓ 可一步实现"
- 图②③保持黑色箭头，无标记

步骤2（分析图②）：
- 图①保持绿色✓状态
- 图②的 Fe→Fe₂O₃ 箭头变为红色 #c62828，显示红色✗
- 图②的 Fe₂O₃→FeSO₄ 箭头变为红色 #c62828，显示红色✗
- 图②的 FeSO₄→Fe 箭头变为绿色 #2e7d32，显示绿色✓
- 方程式区显示：
  "图②分析：
  1. Fe → Fe₂O₃：铁燃烧生成 Fe₃O₄，不能一步得 Fe₂O₃  ✗
  2. Fe₂O₃ → FeSO₄：Fe₂O₃ + H₂SO₄ → Fe₂(SO₄)₃（硫酸铁），不是 FeSO₄  ✗
  3. FeSO₄ → Fe：FeSO₄ + Zn → ZnSO₄ + Fe（置换）✓"

步骤3（分析图③）：
- 图①②保持之前状态
- 图③的三个箭头变为绿色 #2e7d32 加粗
- 在图③三个箭头中点外侧显示绿色✓标记
- 方程式区显示：
  "图③分析：
  1. H₂O → O₂：2H₂O →(电解) 2H₂↑ + O₂↑  ✓
  2. O₂ → MgO：2Mg + O₂ →(点燃) 2MgO  ✓
  3. MgO → H₂O：MgO + H₂SO₄ → MgSO₄ + H₂O  ✓"

步骤4（汇总结论）：
- 所有图的箭头和标记保持步骤3状态
- 方程式区显示结论：
  "结论：图①和图③的所有转化均可一步实现，图②中有转化不能一步实现。
  正确答案：B．①③"
- 选项 B 周围显示绿色高亮框（rect 边框 #2e7d32 stroke-width="2"）
- 「下一步」按钮变为「完成」或禁用

[交互方案]
- 交互类型：分步按钮导航（◀ 上一步 / 下一步 ▶）
- 控件说明：
  - 「上一步」按钮：位于 (260,455)，120×30px，点击返回上一状态（步骤0时禁用）
  - 「下一步」按钮：位于 (420,455)，120×30px，点击进入下一状态（步骤4时变为「完成」或禁用）
- 教师操作流程：
  1. 初始展示三个转化图结构，让学生观察整体
  2. 点击「下一步」分析图①，讲解三个反应均可一步实现
  3. 点击「下一步」分析图②，指出两个不可行转化的原因
  4. 点击「下一步」分析图③，讲解三个反应均可一步实现
  5. 点击「下一步」汇总结论，高亮正确选项 B
  6. 可随时点击「上一步」回退复习

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（三角形、箭头、文本），无需复杂库；原生实现轻量、加载快
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |   ①          ②          ③                       |
  |  CaCO₃       Fe         H₂O                      |
  |   ↘         ↘          ↘                        |
  | CaO→Ca(OH)₂ Fe₂O₃→FeSO₄ O₂→MgO                  |
  |   ↖         ↖          ↖                        |
  |                                                  |
  |   ①         ②          ③                        |
  +--------------------------------------------------+
  | [方程式显示区 760×150 浅灰背景]                  |
  | 当前步骤的反应方程式...                          |
  +--------------------------------------------------+
  |  A．①②   B．①③   C．②③   D．①②③               |
  +--------------------------------------------------+
  |        [◀ 上一步]        [下一步 ▶]              |
  |        (y=455)           (y=455)                 |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-4) 跟踪当前步骤
  2. 每个步骤对应一个 updateScene() 函数，根据 currentStep 显示/隐藏元素
  3. 箭头颜色切换：通过修改 stroke 和 stroke-width 属性
  4. 可行性标记：使用<text>元素，初始 opacity="0"，按步骤设置 opacity="1"
  5. 方程式文本：使用<tspan>换行，或分多个<text>元素
  6. 选项高亮框：步骤4时显示<rect>边框
  7. 按钮事件：addEventListener('click') 绑定步进逻辑
  8. 边界检查：步骤0禁用「上一步」，步骤4禁用「下一步」或改为「完成」
- ID 命名规范：
  - 所有元素 ID 以 scene1- 为前缀
  - 示例：scene1-tri-1（图①三角形）、scene1-arrow-1-1（图①第1个箭头）、scene1-label-caco3、scene1-check-1-1（图①第1个✓）、scene1-btn-prev、scene1-btn-next、scene1-equation-box、scene1-option-b-highlight
- IIFE 隔离：
  ```javascript
  (function() {
    // 所有 JS 代码包在此 IIFE 中
    let currentStep = 0;
    // ...
  })();
  ```
