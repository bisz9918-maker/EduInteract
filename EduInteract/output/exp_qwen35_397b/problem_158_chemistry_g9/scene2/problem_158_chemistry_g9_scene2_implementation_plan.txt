[图示主题与整合说明]
- 本图示主题：关键难点突破——Fe₂O₃ 与酸反应的产物价态
- 整合的步骤/概念：整合了 Fe₂O₃→FeSO₄ 不能一步实现的原因分析、Fe³⁺与 Fe²⁺的价态对比、正确转化路径建议
- 教学价值：教师可使用此图示进行课堂讲解，通过三状态切换对比展示，帮助学生理解为什么 Fe₂O₃ 与酸反应生成的是 Fe₂(SO₄)₃ 而非 FeSO₄，核心在于铁元素价态守恒（+3 价 Fe 不能直接变为 +2 价，需要还原剂）

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript
  - 原因：本场景为静态图示 + 状态切换，无需复杂动画库；SVG 适合化学方程式和数轴的精确绘制
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +----------------------------------------------------------+
  | [错误路径分析]    [价态对比分析]      [正确转化路径]     |
  | +--------------+  0--+2--+3--  +---------------------+   |
  | | Fe₂O₃+H₂SO₄ |    Fe²⁺  Fe³⁺   | Fe₂O₃→Fe₂(SO₄)₃  ✓ |   |
  | |      ×       |  [价态说明框]   | Fe→FeSO₄+H₂↑     ✓ |   |
  | +--------------+                 +---------------------+   |
  | [=================== 核心原理说明区 ===================]   |
  | 金属氧化物与酸反应时，金属元素价态保持不变...             |
  |                                                          |
  |              [错误路径] [价态分析] [正确路径]             |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  - 状态机设计：使用 currentState 变量（1/2/3）跟踪当前状态
  - 三个状态组：scene2-state1、scene2-state2、scene2-state3，每组包含对应 SVG 元素
  - 按钮激活态：当前状态按钮高亮（绿色背景），其他按钮灰色
  - 显示/隐藏：通过 display 属性或 opacity 控制各组可见性
  - 底部说明文字：根据 currentState 动态更新textContent
- ID 命名规范：所有交互元素 ID 必须以 scene2- 为前缀
  - scene2-btn-state1、scene2-btn-state2、scene2-btn-state3
  - scene2-group-error、scene2-group-valence、scene2-group-correct
  - scene2-info-text（底部说明文字）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
