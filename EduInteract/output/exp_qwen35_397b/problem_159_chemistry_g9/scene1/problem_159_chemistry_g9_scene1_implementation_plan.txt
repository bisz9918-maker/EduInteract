[分步序列]
步骤 0（初始状态）：
- 显示四个坐标图的原图（黑色实线曲线）
- 显示所有坐标轴、标签、选项字母
- 无高亮框、无对错标记、无正确曲线
- 顶部标题："请分析四个实验操作图像"

步骤 1（分析选项 A）：
- 显示图 A 的蓝色高亮框
- 显示图 A 的绿色正确曲线（虚线，从左上向右下下降）
- 显示图 A 的红色"✗"标记
- 顶部标题："选项 A：向饱和石灰水中加入氧化钙——错误"
- 说明：氧化钙与水反应消耗溶剂，溶质质量应下降

步骤 2（分析选项 B）：
- 隐藏步骤 1 的高亮和标记
- 显示图 B 的蓝色高亮框
- 显示图 B 的绿色正确曲线（虚线，下降至非零值）
- 显示图 B 的红色"✗"标记
- 顶部标题："选项 B：加热高锰酸钾产生氧气——错误"
- 说明：反应后剩余锰酸钾和二氧化锰，固体质量不为 0

步骤 3（分析选项 C）：
- 隐藏步骤 2 的高亮和标记
- 显示图 C 的蓝色高亮框
- 显示图 C 的绿色"✓"标记
- 顶部标题："选项 C：高温煅烧碳酸钙——正确"
- 说明：先升温（质量不变）→ 分解（质量下降）→ 剩余氧化钙（非零）

步骤 4（分析选项 D）：
- 隐藏步骤 3 的高亮和标记
- 显示图 D 的蓝色高亮框
- 显示图 D 的绿色正确曲线（虚线，下降曲线）
- 显示图 D 的红色"✗"标记
- 顶部标题："选项 D：氧气在水中的溶解性——错误"
- 说明：气体溶解度随温度升高而下降

步骤 5（总结）：
- 隐藏所有高亮框
- 显示所有对错标记（A✗ B✗ C✓ D✗）
- 顶部标题："正确答案：C"
- 底部显示总结文字："只有选项 C 的图像正确反映了实验过程"

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "上一步"按钮：位于(280,440)，点击返回上一状态
  - "下一步"按钮：位于(420,440)，点击进入下一状态
  - 步骤指示器：显示"步骤 X/5"，位于顶部标题右侧
- 教师操作流程：
  1. 初始展示四图，让学生观察差异
  2. 点击"下一步"逐一分析每个选项
  3. 在每一步停留讲解化学反应原理
  4. 最后总结正确答案

[技术实现]
- JS 库选择：原生 SVG（简单几何图形和坐标图，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [800×500 画布]
  ┌─────────────────────────────────────────────────────┐
  │  标题区：步骤说明文字 (y=10-40)                      │
  ├───────────────────────┬─────────────────────────────┤
  │   图 A (左上)          │   图 B (右上)                │
  │   20,50 - 390,260      │   410,50 - 780,260          │
  │   溶质质量 vs 氧化钙    │   固体质量 vs 反应时间        │
  ├───────────────────────┼─────────────────────────────┤
  │   图 C (左下)          │   图 D (右下)                │
  │   20,270 - 390,400     │   410,270 - 780,400         │
  │   固体质量 vs 时间      │   溶解度 vs 温度             │
  ├───────────────────────┴─────────────────────────────┤
  │   控件栏 (y=440-470)：[◀ 上一步]      [下一步 ▶]     │
  └─────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-5) 跟踪当前步骤
  2. 所有元素用 scene1-前缀命名（如 scene1-graph-a、scene1-highlight-a）
  3. 初始隐藏所有高亮框、对错标记、正确曲线
  4. 每步根据 currentStep 显示/隐藏对应元素
  5. 按钮边界检查：步骤 0 禁用"上一步"，步骤 5 禁用"下一步"
  6. 使用 IIFE 隔离：(function() { ... })()
- ID 命名规范：
  - 图 A 相关：scene1-graph-a, scene1-curve-a-orig, scene1-curve-a-correct, scene1-highlight-a, scene1-mark-a
  - 图 B 相关：scene1-graph-b, scene1-curve-b-orig, scene1-curve-b-correct, scene1-highlight-b, scene1-mark-b
  - 图 C 相关：scene1-graph-c, scene1-curve-c-orig, scene1-highlight-c, scene1-mark-c
  - 图 D 相关：scene1-graph-d, scene1-curve-d-orig, scene1-curve-d-correct, scene1-highlight-d, scene1-mark-d
  - 控件：scene1-btn-prev, scene1-btn-next, scene1-title
- 配色方案（严格沿用 spec）：
  - 背景：#ffffff
  - 原图曲线：#000000 实线
  - 高亮框：#1565c0（蓝色边框，20% 填充）
  - 错误标记：#c62828（红色）
  - 正确曲线/标记：#2e7d32（绿色虚线）
  - 辅助线：#888888 虚线
