[图示主题与整合说明]
- 本图示主题：选项 C（高温煅烧碳酸钙）反应过程详解
- 整合的内容：反应装置示意、固体质量变化曲线、反应阶段标注、化学方程式展示
- 教学价值：教师可通过分步演示帮助学生理解碳酸钙高温分解的三个阶段——加热初期质量不变、分解期质量下降（CO₂逸出）、完全分解后质量恒定。左右对照设计让学生直观看到实验装置与质量变化曲线的对应关系。

[分步序列]
- 步骤 0（初始状态）：
  - 显示完整反应装置（试管、酒精灯、固体 CaCO₃）
  - 显示完整坐标图（三阶段曲线、坐标轴、标签）
  - 顶部说明："高温煅烧碳酸钙反应过程"
  - 无高亮，无动画

- 步骤 1（阶段一：加热初期）：
  - 顶部说明："阶段一：加热初期，温度未达分解温度"
  - 左侧：CaCO₃标签显示，蓝色高亮固体区域
  - 右侧：曲线第一阶段（水平段）蓝色高亮 #1565c0
  - 阶段一标签显示，阶段一分界线加粗
  - 无气体分子动画

- 步骤 2（阶段二：分解反应）：
  - 顶部说明："阶段二：达到分解温度，CaCO₃分解，CO₂逸出"
  - 左侧：CO₂分子动画启动（向上飘动），CaCO₃标签渐隐
  - 右侧：曲线第二阶段（下降段）蓝色高亮
  - 阶段二标签显示，阶段二分界线加粗
  - 化学方程式部分显示：CaCO₃ → ...

- 步骤 3（阶段三：完全分解）：
  - 顶部说明："阶段三：完全分解，剩余 CaO，质量恒定"
  - 左侧：固体变为 CaO（绿色 #2e7d32），CaO 标签显示
  - 右侧：曲线第三阶段（水平段）蓝色高亮，终点用绿色圆点标记
  - 阶段三标签显示
  - 化学方程式显示：CaCO₃ → CaO + CO₂↑

- 步骤 4（总结）：
  - 顶部说明："反应总结：CaCO₃ 高温分解为 CaO 和 CO₂"
  - 左侧：完整装置，CaO 绿色高亮
  - 右侧：完整曲线，三阶段分界线清晰
  - 化学方程式完整显示并绿色高亮
  - 所有阶段标签同时显示（不同颜色区分）

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于底部左侧 (280,450)，点击返回上一状态
  - 「下一步」按钮：位于底部右侧 (420,450)，点击进入下一状态
  - 步骤指示器：底部中央显示「步骤 X/4」
- 教师操作流程：
  1. 初始展示完整图示，让学生观察整体结构
  2. 点击「下一步」进入阶段一，讲解加热初期固体质量不变的原因
  3. 点击「下一步」进入阶段二，配合 CO₂动画讲解质量下降原因
  4. 点击「下一步」进入阶段三，说明完全分解后剩余 CaO 的质量
  5. 点击「下一步」总结，展示完整化学方程式
  6. 可随时点击「上一步」回退复习关键概念

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单，无需复杂库；SVG 便于精确控制坐标和动画
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  +----------------------------------------------------------+
  | [顶部说明栏：当前阶段标题]                               |
  +---------------------------+------------------------------+
  | 左侧反应装置区 (320px)    | 右侧坐标图区 (420px)         |
  |                           |                              |
  |   [试管] [酒精灯]         |    Y轴                       |
  |   [固体 CaCO₃/CaO]        |    |                         |
  |   [CO₂分子动画]           |    |    曲线                 |
  |                           |    |   /                     |
  |   CaCO₃/CaO 标签          |    |  /                      |
  |                           |    | /                       |
  |                           |    |/________________ X 轴   |
  |                           |         时间                  |
  +---------------------------+------------------------------+
  |        [◀上一步]  步骤 X/4  [下一步▶]                    |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用 currentState 变量 (0-4) 跟踪当前步骤
  2. 坐标计算：所有元素使用绝对坐标，避免相对定位导致的偏移
  3. 动画曲线：CO₂分子使用 CSS animation 或 requestAnimationFrame 实现向上飘动
  4. 事件绑定：按钮点击事件绑定到状态切换函数
  5. 高亮逻辑：每步只高亮当前阶段相关元素，其他元素保持默认样式
- ID 命名规范：所有元素 ID 以 scene2- 为前缀
  - scene2-topbar, scene2-left-panel, scene2-right-panel
  - scene2-test-tube, scene2-solid, scene2-alcohol-lamp, scene2-flame
  - scene2-co2-1, scene2-co2-2, scene2-co2-3
  - scene2-axis-x, scene2-axis-y, scene2-curve
  - scene2-phase-1, scene2-phase-2, scene2-phase-3
  - scene2-btn-prev, scene2-btn-next, scene2-step-indicator
  - scene2-label-caco3, scene2-label-cao, scene2-label-equation
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
