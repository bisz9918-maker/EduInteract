[分步序列]
- 初始状态（步骤 0）：显示桌面、木块 A、木块 B、标签 A、标签 B、速度 v₂ 箭头、v₂=2m/s 标签。其他元素隐藏。
- 步骤 1：点击「下一步」→ 显示重力 G 箭头（灰色虚线向下）、支持力 N 箭头（灰色虚线向上）、N=2mg 标签。标注正压力等于总重力。
- 步骤 2：点击「下一步」→ 显示摩擦力 f₂ 箭头组（红色向左箭头）、f₂ 标签。标注摩擦力 f₂=μN。
- 步骤 3：点击「下一步」→ 显示推力 F₂ 箭头（蓝色向右）、F₂=? 标签，同时 F₂=? 变为 F₂=f₂。展示推力与摩擦力平衡关系。
- 最终步骤：所有元素显示完整，教师可点击「上一步」回退复习任一阶段。

[标签冲突检查]
- 标签"A"：坐标(330,315) — 木块 A 中心
- 标签"B"：坐标(430,315) — 木块 B 中心
- 标签"F₂=?"：坐标(230,295) — 推力箭头上方
- 标签"f₂"：坐标(380,375) — 摩擦力箭头下方
- 标签"N=2mg"：坐标(395,245) — 重力箭头右侧
- 标签"v₂=2m/s"：坐标(380,230) — 速度箭头上方

冲突检查：
- "A"(330,315) 与 "B"(430,315)：水平距离 100px → 无冲突
- "A"(330,315) 与 "F₂=?"(230,295)：距离 √(100²+20²)≈102px → 无冲突
- "B"(430,315) 与 "f₂"(380,375)：距离 √(50²+60²)≈78px → 无冲突
- "N=2mg"(395,245) 与 "v₂=2m/s"(380,230)：距离 √(15²+15²)≈21px → 边界安全，微调 N=2mg 至 (405,250) 确保间距≥25px
- "f₂"(380,375) 与 控件栏 y=455：垂直距离 80px → 无冲突
- 所有标签与图形元素：均保持≥15px 间距 → 无冲突

解决方案：将 N=2mg 标签调整至 (405,250)，确保与 v₂=2m/s 有足够间距。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 内底部左侧 (320,455)，60×30px，点击后退到前一状态
  - 「下一步」按钮：位于 SVG 内底部右侧 (420,455)，60×30px，点击前进到下一状态
  - 步骤指示器：位于底部中央 (400,460)，显示「步骤 X/3」
- 教师操作流程：
  1. 初始状态展示并排木块和运动速度，让学生观察图乙 setup
  2. 点击「下一步」展示重力和支持力，讲解 N=2mg（整体法）
  3. 点击「下一步」展示摩擦力，讲解 f₂=μN
  4. 点击「下一步」展示推力，讲解匀速运动时 F₂=f₂，得出 F₂=100N
  5. 可随时点击「上一步」回退复习任一受力分析阶段

[技术实现]
- JS 库选择：原生 SVG（简单几何图形和箭头，无需额外库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |                    v₂=2m/s                       |
  |              ←──────────────────→                |
  |                                                  |
  |         F₂=?          A      B                   |
  |      ←─────────    [____][____]                  |
  |                                                  |
  |                    N=2mg                         |
  |                      ↓                           |
  |              ────────┴──────── 桌面              |
  |         ←←←←←←←←←←←←←←←←←←←←←←←←                  |
  |                    f₂                            |
  |                                                  |
  |                                                  |
  |              [◀上一步] 步骤 3/3 [下一步▶]        |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentState (0-3) 跟踪当前步骤，数组存储各状态应显示的元素 ID 列表
  2. 坐标计算：所有元素坐标硬编码于布局坐标表，箭头路径用 SVG <path> 或 <line>+<polygon> 实现
  3. 动画曲线：元素显示/隐藏使用 CSS transition opacity 0.3s ease，箭头绘制使用 stroke-dasharray 动画
  4. 事件绑定：按钮点击事件绑定到 state 切换函数，更新显示元素集合并更新步骤指示器文本
  5. 边界检查：步骤 0 时禁用「上一步」，步骤 3 时禁用「下一步」（或隐藏）
- ID 命名规范：所有交互元素 ID 必须以 scene2- 为前缀
  - scene2-desk, scene2-block-a, scene2-block-b
  - scene2-label-a, scene2-label-b
  - scene2-arrow-f2, scene2-label-f2
  - scene2-arrow-fri, scene2-label-fri
  - scene2-arrow-g, scene2-arrow-n, scene2-label-n
  - scene2-arrow-v, scene2-label-v
  - scene2-btn-prev, scene2-btn-next, scene2-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
