problem_160_math_g6

场景导航：Scene 1 | Scene 2 | Scene 3

题目原文：

如图是一座楼房的平面图，图中不同字母表示长度不同的各条边长，若 b=50 米，c=30 米，g=10 米，则这座楼房平面图的周长是（ ）

A．90 米 B．150 米 C．180 米

题目分析：

本题是一个不规则多边形周长计算问题。图形为凹多边形（有凹口），直接逐边相加无法求解，因为大部分边长未知。

核心思路：平移法

  1. 将凹多边形的边通过平移"补"成规则矩形
  2. 观察哪些边可以完全平移重合，哪些边会"多出来"
  3. 发现凹口的竖直边 g 在平移后会被计算两次（一次向下、一次向上）

图示规划说明：

  • SCENE_1：展示原图及已知条件标注，建立视觉基准
  • SCENE_2：动态演示平移法——将水平边向上/下平移、竖直边向左/右平移，直观展示周长 = 2(b+c) + 2g
  • SCENE_3：对比展示——完整矩形周长 vs 实际周长，突出凹口贡献的额外长度 2g
步骤 1/4

教学引导要点：

  1. 首先让学生识别图形特征：这是一个凹多边形，有 8 条边
  2. 引导学生观察已知条件：只有 3 条边的长度已知（b=50, c=30, g=10）
  3. 提问：直接相加所有边长可行吗？（不可行，因为 a,d,e,f,h 未知）
  4. 启发思考：能否通过图形的几何关系，将未知边转化为已知边？

关键观察：

  • 水平方向的边：h, f, d（上侧）与 b（下侧）
  • 竖直方向的边：a, g, e（左侧区域）与 c（右侧）
  • 凹口的存在使得某些边在平移后会被"重复计算"
步骤 1/5

平移法详解：

水平方向：

  1. 上侧水平边 h, f, d 向下平移，恰好拼成底边 b
  2. 因此：h + f + d = b = 50 米
  3. 水平方向总贡献：上侧 (h+f+d) + 下侧 b = 2b = 100 米

竖直方向：

  1. 左侧边 a 和凸起边 e 向右平移，与右侧边 c 比较
  2. 由于凹口 g 的存在：a - g + e = c，即 a + e = c + g
  3. 竖直方向总贡献：左侧 (a+e) + 凹口 g + 右侧 c = (c+g) + g + c = 2c + 2g = 80 米

周长公式：

  • 周长 = 2b + 2c + 2g
  • 周长 = 2 × 50 + 2 × 30 + 2 × 10
  • 周长 = 100 + 60 + 20 = 180 米

关键理解：

凹口的竖直边 g 被计算了两次——一次是向下走的 g，一次是向上补偿的 g（因为 a+e 比 c 多了 g）。

完整解答：

根据平移法分析：

  1. 水平边总长：(h + f + d) + b = b + b = 2b = 2 × 50 = 100 米
  2. 竖直边总长：(a + e) + g + c = (c + g) + g + c = 2c + 2g = 2 × 30 + 2 × 10 = 80 米
  3. 周长 = 100 + 80 = 180 米

答案：C．180 米

课堂讲解建议：

  1. 先用 SCENE_1 让学生熟悉图形和已知条件
  2. 用 SCENE_2 动态演示平移过程，这是理解本题的关键
  3. 用 SCENE_3 对比展示，强化"凹口贡献 2g"这一核心概念
  4. 引导学生总结：对于凹多边形，周长 = 外接矩形周长 + 2 × 凹口深度

拓展思考：

  • 如果凹口在右侧而非左侧，结论是否相同？（相同，平移法依然适用）
  • 如果有多个凹口呢？（每个凹口的竖直边都会被计算两次）
  • 这种方法适用于凸多边形吗？（凸多边形可直接平移为矩形，无额外贡献）
