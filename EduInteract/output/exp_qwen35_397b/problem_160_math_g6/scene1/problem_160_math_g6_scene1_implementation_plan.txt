[视觉元素清单]
- 凹多边形轮廓：SVG path元素，8条边连接成闭合图形，初始状态黑色实线2px
- 边字母标注(a-h)：8个text元素，分别位于对应边外侧，黑色#000000，字体14px

- 颜色规格：背景#ffffff / 轮廓线#000000实线2px / 字母标注#000000 / 已知边高亮#1565c0加粗3px / 已知数值#1565c0加粗

[分步序列]
- 初始状态（步骤0）：显示凹多边形轮廓（8条边，黑色2px实线），无字母标注，无已知数值
- 步骤1：点击「下一步」→ 显示所有8个边字母标注(a,b,c,d,e,f,g,h)，位置见布局坐标表
- 步骤2：点击「下一步」→ 边b、c、g高亮为蓝色#1565c0加粗3px，图例区显示三个已知数值框(b=50, c=30, g=10)
- 步骤3：点击「下一步」→ 底部显示问题文本"这座楼房平面图的周长是多少？"，完成题目呈现
（教师可随时点击「上一步」回退复习）

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于控件栏左侧，点击返回上一状态
  - 「下一步」按钮：位于控件栏右侧，点击进入下一状态
  - 步骤指示器：显示"步骤 X/4"，位于两按钮中间
- 教师操作流程：
  1. 初始展示图形轮廓，让学生观察整体形状
  2. 点击「下一步」显示所有边字母，引导学生识别8条边
  3. 点击「下一步」高亮已知边并显示数值，强调已知条件
  4. 点击「下一步」显示问题，引发学生思考周长计算方法

[技术实现]
- JS库选择：原生SVG + 原生JavaScript
  - 原因：几何图形简单，SVG精度高、缩放无损，无需额外库
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────┐
  │                                                         │
  │                    凹多边形图形区                        │
  │         h─────┐        d───┐                            │
  │         │     │        │   │                            │
  │       a │   g │    e   │   │ c                          │
  │         │     └────f───┘   │                            │
  │         └──────────────────┘                            │
  │                    b                                    │
  │                                                         │
  │  [图例区] b=50   c=30   g=10                            │
  │                                                         │
  │  [控件栏] ◀ 上一步   步骤 1/4   下一步 ▶                │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用currentStep变量(0-3)跟踪当前步骤，steps数组存储每步状态配置
  2. 坐标计算：多边形顶点坐标硬编码，确保比例与原题图一致
  3. 动画曲线：元素淡入使用CSS transition opacity 0.3s ease
  4. 事件绑定：按钮点击事件绑定到stepChange函数，更新DOM元素可见性
  5. ID命名规范：所有元素ID以scene1-为前缀（如scene1-polygon, scene1-label-a, scene1-btn-next）
  6. IIFE隔离：所有JS代码包在(function() { ... })()中，避免全局污染
- 多边形顶点坐标（按顺时针）：
  - P1(250,380) → P2(250,180) → P3(400,180) → P4(400,230) → P5(580,230) → P6(580,180) → P7(650,180) → P8(650,380) → 闭合回P1
