[图示主题与整合说明]
- 本图示主题：平移法动态演示——将凹多边形边平移补成矩形
- 整合的内容：水平边平移（h,f,d→b）、竖直边平移（a,e→c）、凹口边 g 的两次贡献
- 教学价值：教师可通过分步动画展示"平移法"求凹多边形周长的几何思想，让学生直观理解为何周长=2b+2c+2g。步骤0展示原图，步骤1展示水平边向下平移与底边重合，步骤2展示竖直边向右平移与右边重合，步骤3高亮凹口边g说明其被计算两次，步骤4总结公式。右侧公式区同步显示推导过程。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 上一步按钮：位于(280,455)，80×30px，步骤0时禁用
  - 下一步按钮：位于(440,455)，80×30px，步骤4时禁用
  - 步骤指示：位于(380,465)，显示"步骤 X/4"
- 教师操作流程：
  1. 初始状态展示原图，教师介绍题目条件（b=50, c=30, g=10）
  2. 点击"下一步"展示水平边平移，教师讲解"h+f+d=b"
  3. 点击"下一步"展示竖直边平移，教师讲解"a+e=c+g"
  4. 点击"下一步"高亮凹口边g，教师强调"g被计算两次"
  5. 点击"下一步"显示结论，教师总结公式"周长=2b+2c+2g=180米"
  6. 可随时点击"上一步"回退复习关键步骤

[技术实现]
- JS库选择：原生SVG + 原生JavaScript
  - 原因：几何图形简单，无需复杂库；SVG便于精确控制坐标和样式；原生JS足够实现分步状态切换
- 画布尺寸：800×500px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  [凹多边形图形区]        [公式推导区]            |
  |  x:50-420               x:450-780                |
  |  y:80-400                 y:80-280               |
  |                                                  |
  |                                                  |
  |                                                  |
  |  [控件栏 y:440-490]                              |
  |  [◀上一步]  步骤X/4  [下一步▶]                   |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量currentStep(0-4)跟踪当前步骤，数组steps存储每步显示的元素ID列表
  2. 坐标计算：所有顶点坐标硬编码，比例7px/米
  3. 动画曲线：平移箭头用CSS transition实现淡入，duration 300ms
  4. 事件绑定：按钮click事件触发stepChange函数，更新display属性
  5. 元素显隐：每步调用updateDisplay()，遍历所有元素根据steps[currentStep]设置display
- ID命名规范：所有元素ID以scene2-为前缀
  - 示例：scene2-polygon（轮廓）、scene2-label-a（边a标签）、scene2-arrow-1（平移箭头1）
  - scene2-btn-prev（上一步按钮）、scene2-btn-next（下一步按钮）、scene2-step-indicator（步骤指示）
- IIFE隔离：所有JS代码包裹在(function() { ... })()中，避免全局变量污染
- CDN：无需外部库，纯原生实现
