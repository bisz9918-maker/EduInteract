[图示主题与整合说明]
- 本图示主题：周长构成对比——矩形周长 vs 凹口额外贡献
- 整合内容：完整矩形周长 2(b+c)、凹口额外贡献 2g、最终周长 2(b+c)+2g
- 教学价值：教师可通过三状态切换，直观展示凹多边形周长的构成逻辑——先理解外接矩形周长，再识别凹口带来的额外边长贡献，最后合并得到总周长。这种分步对比帮助学生建立"转化思想"，将复杂图形周长问题转化为熟悉矩形周长加修正项。

[分步序列]
多状态切换（3 个状态，教师点击按钮切换）：

状态 0（初始/默认）：显示凹多边形轮廓 + 边标签 b,c,g，无数值框
- 显示：凹多边形路径、边标签 b(380,280)、c(595,170)、g(325,170)
- 隐藏：外接矩形、凹口高亮区、数值框

状态 1（点击"外接矩形"按钮）：
- 显示：外接矩形虚线框(180,80)-(580,260)
- 数值框内容："外接矩形周长 = 2(b+c) = 2(50+30) = 160 米"
- 数值框位置：(200,320)-(600,360)，绿色边框
- 隐藏：凹口高亮区

状态 2（点击"凹口贡献"按钮）：
- 显示：凹口高亮区 rect(340,140,80,120) 红色半透明
- 数值框内容："凹口额外贡献 = 2g = 2×10 = 20 米"
- 高亮：凹槽的两条竖边（各长 g=10 米）
- 隐藏：外接矩形

状态 3（点击"总周长"按钮）：
- 显示：外接矩形 + 凹口高亮区 同时显示
- 数值框内容："总周长 = 2(b+c) + 2g = 160 + 20 = 180 米"
- 数值框样式：#2e7d32 边框，24px 加粗字体
- 最终答案高亮闪烁一次（可选）

[交互方案]
- 交互类型：多状态切换（3 个按钮）
- 控件说明：
  - 按钮 1"外接矩形"：位置 (220,450)，显示外接矩形周长计算
  - 按钮 2"凹口贡献"：位置 (350,450)，高亮凹口区域并显示额外贡献
  - 按钮 3"总周长"：位置 (480,450)，合并显示并给出最终答案
- 教师操作流程：
  1. 初始状态展示凹多边形，提问"如何计算这个图形的周长？"
  2. 点击"外接矩形"，引导学生理解转化思想：若补全凹口，周长是多少
  3. 点击"凹口贡献"，提问"凹口使周长增加了多少？"，高亮显示两条竖边
  4. 点击"总周长"，总结公式：总周长=外接矩形周长+凹口额外贡献

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库）
- 画布尺寸：800×500 px（固定）
- 布局草图：
  ```
  [800×500 画布]
  ┌─────────────────────────────────────┐
  │                                     │
  │    [图形区 y=60~280]                │
  │    外接矩形(虚线) + 凹多边形(实线)   │
  │    凹口高亮区(红色半透明)           │
  │    边标签 b, c, g                   │
  │                                     │
  │    [数值区 y=300~400]               │
  │    ┌───────────────────────────┐    │
  │    │  动态数值框（状态相关）   │    │
  │    └───────────────────────────┘    │
  │                                     │
  │    [控件区 y=440~490]               │
  │    [外接矩形] [凹口贡献] [总周长]   │
  └─────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机：用 currentState 变量(0-3)跟踪，点击按钮更新状态并重绘
  2. 元素 ID 规范：所有元素以 scene3- 为前缀（如 scene3-outer-rect, scene3-concave-path）
  3. 显示/隐藏：通过 display 属性或 opacity 控制元素可见性
  4. 数值框更新：根据 currentState 设置 textContent 和样式
  5. IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中
  6. 事件绑定：按钮点击事件用 addEventListener，避免内联 onclick

- 元素 ID 列表：
  - scene3-outer-rect：外接矩形
  - scene3-concave-path：凹多边形路径
  - scene3-notch-highlight：凹口高亮区
  - scene3-label-b, scene3-label-c, scene3-label-g：边标签
  - scene3-value-box：数值框背景
  - scene3-value-text：数值文本
  - scene3-btn-1, scene3-btn-2, scene3-btn-3：三个状态按钮
