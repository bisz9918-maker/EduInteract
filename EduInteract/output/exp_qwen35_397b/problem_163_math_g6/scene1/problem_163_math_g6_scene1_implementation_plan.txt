[图示主题与整合说明]
- 本图示主题：三角形 ABC 中 AB 边上的高的判定
- 整合的步骤/概念：原图展示 → 三角形 ABC 高亮 → 高的定义演示（从顶点 C 向底边 AB 作垂线）→ 三个选项对比 → 正确答案确认
- 教学价值：教师可通过分步导航控制讲解节奏，先让学生观察原图，再逐步高亮三角形 ABC，演示高的作图过程，最后对比三个选项帮助学生理解为什么 CD 是正确答案。支持随时回退复习关键概念。

[分步序列]
步骤 0（初始状态）：显示原图基础结构
- 显示：底边 AD、左侧矩形、右侧矩形、点 A/B/C/D/E 及标签、三角形 ABC 轮廓（半透明填充）
- 隐藏：高 CD 高亮、直角符号、选项对比线、功能标签

步骤 1：高亮三角形 ABC 三顶点
- 视觉变化：顶点 A、B、C 的圆点放大至 r=7，添加淡蓝色光晕效果
- 新增：三角形 ABC 填充色加深至 rgba(21,101,192,0.3)
- 标签：无新增

步骤 2：标注底边 AB，显示从 C 向 AB 作垂线的过程
- 视觉变化：边 AB 加粗至 3px 黑色
- 新增：标签"底边 AB"位于 (225,385)
- 新增：从 C 到 D 的蓝色高亮线 CD（#1565c0, 2.5px）
- 新增：标签"高 CD"位于 (575,250)

步骤 3：高亮 CD，标注垂直符号
- 视觉变化：CD 线段闪烁动画（2 次）
- 新增：直角符号在 D 点 (535,335)-(550,350)
- 新增：标签"垂足 D"位于 (565,390)

步骤 4：对比展示三个选项
- 视觉变化：
  - CB 线段变为红色虚线 #c62828，旁边标注"×"（不垂直 AB）
  - EB 线段变为红色虚线 #c62828，旁边标注"×"（不是从 C 出发）
  - CD 保持蓝色实线，旁边添加"√"标记
- 新增：右侧对比说明文字（小字 12px）：
  - "CB：不垂直于 AB"
  - "EB：不是从顶点 C 出发"
  - "CD：从 C 垂直于 AB ✓"

步骤 5（最终步骤）：结论确认
- 视觉变化：CD 线段持续高亮，添加脉冲动画
- 新增：底部结论文字"答案：B. CD"（蓝色加粗 16px，位于 y=420）
- 所有正确元素保持高亮状态

[标签冲突检查]
| 标签名 | 预计坐标 | 相邻标签 | 间距计算 | 是否冲突 | 解决方案 |
|--------|----------|----------|----------|----------|----------|
| "A" | (135,370) | "底边 AB"(225,385) | √[(90)²+(15)²]≈91px | 否 | - |
| "B" | (300,368) | "底边 AB"(225,385) | √[(75)²+(17)²]≈77px | 否 | - |
| "C" | (565,135) | "高 CD"(575,250) | √[(10)²+(115)²]≈115px | 否 | - |
| "D" | (565,370) | "垂足 D"(565,390) | 20px | 临界 | 已预留最小间距 |
| "E" | (285,235) | 无邻近标签 | - | 否 | - |
| "底边 AB" | (225,385) | "B"(300,368) | 77px | 否 | - |
| "高 CD" | (575,250) | "√"(580,240) | √[(5)²+(10)²]≈11px | 临界 | "√"微调至 (590,245) |
| "垂足 D" | (565,390) | "D"(565,370) | 20px | 临界 | 保持当前间距 |

冲突解决方案：
1. "D"与"垂足 D"垂直间距 20px，刚好满足最小要求，保持
2. "高 CD"与"√"间距 11px，将"√"从 (580,240) 调整至 (590,245)，间距增至√[(15)²+(5)²]≈16px

调整后最终坐标：
- "√"：(590,245)

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于 (280,455)，80×30px，浅灰色背景 #e0e0e0，点击返回上一状态
  - 「下一步 ▶」按钮：位于 (440,455)，80×30px，蓝色背景 #1565c0，白色文字，点击进入下一状态
  - 步骤指示器：位于两按钮之间 (380,465)，显示"步骤 X/5"
- 教师操作流程：
  1. 加载后显示步骤 0（原图），教师引导学生观察图形结构
  2. 点击「下一步」→ 步骤 1，高亮三角形 ABC 顶点，提问"这是哪个三角形？"
  3. 点击「下一步」→ 步骤 2，显示底边 AB 和高 CD，讲解高的定义
  4. 点击「下一步」→ 步骤 3，标注垂足和直角符号，强调垂直关系
  5. 点击「下一步」→ 步骤 4，对比三个选项，逐一分析为什么 CB 和 EB 不对
  6. 点击「下一步」→ 步骤 5，显示正确答案，总结结论
  7. 可随时点击「上一步」回退复习

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单，无需复杂库；SVG 便于精确控制坐标和样式；原生 JS 足够实现分步状态切换
- 画布尺寸：800×500 px（固定）
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │                    图示区 (800×440)                          │
  │                                                             │
  │         C(550,150)                                          │
  │          *                                                  │
  │         /|\                                                 │
  │        / | \                                                │
  │       /  |  \  高 CD (蓝色)                                   │
  │      /   |   \                                               │
  │     /    |    \                                              │
  │    /     |     \                                             │
  │   *------*------*                                            │
  │  A(150)  B(300)  D(550)  底边 AB                              │
  │                                                             │
  │  [左侧矩形]  [右侧矩形]  直角符号⊟                            │
  │                                                             │
  ├─────────────────────────────────────────────────────────────┤
  │  控件栏 (y=440~490)                                          │
  │         [◀ 上一步]   步骤 3/5   [下一步 ▶]                    │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用数组存储 6 个状态（步骤 0-5），每个状态定义显示/隐藏的元素 ID 列表
  2. 坐标计算：所有元素坐标硬编码，确保与布局表一致
  3. 动画曲线：使用 CSS transition 实现平滑过渡（opacity: 0→1, stroke-width: 1→3）
  4. 事件绑定：按钮点击事件绑定状态切换函数，边界检查（步骤 0 禁用上一步，步骤 5 禁用下一步）
  5. 直角符号绘制：使用 polyline 绘制 L 形，两点 (535,335)-(550,335)-(550,350)
- ID 命名规范：
  - 所有元素 ID 以 scene1- 为前缀
  - 示例：scene1-point-a, scene1-point-b, scene1-point-c, scene1-point-d, scene1-point-e
  - 示例：scene1-tri-abc, scene1-line-ab, scene1-line-cd, scene1-line-cb, scene1-line-eb
  - 示例：scene1-label-a, scene1-label-b, scene1-label-c, scene1-label-d, scene1-label-e
  - 示例：scene1-label-base-ab, scene1-label-height-cd, scene1-label-foot-d
  - 示例：scene1-rect-left, scene1-rect-right, scene1-rect-right-angle
  - 示例：scene1-btn-prev, scene1-btn-next, scene1-step-indicator
- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染
