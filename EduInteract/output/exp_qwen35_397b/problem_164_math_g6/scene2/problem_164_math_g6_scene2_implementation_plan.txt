[分步序列]
- 初始状态（步骤0）：显示三个物体立体图（均为未选中状态，边框#888888），俯视图区域空白（仅显示边框和标签），题目条件区显示梯形参考图，三个按钮均为未选中样式
- 状态1（点击按钮①）：物体①高亮（边框#1565c0线宽3px），物体②③变灰（边框#888888线宽1px），俯视图区域显示矩形（长方体俯视图），右侧显示红色✗标记，表示"不符合"
- 状态2（点击按钮②）：物体②高亮（边框#1565c0线宽3px），物体①③变灰，俯视图区域显示五边形（五棱柱俯视图），右侧显示红色✗标记，表示"不符合"
- 状态3（点击按钮③）：物体③高亮（边框#1565c0线宽3px），物体①②变灰，俯视图区域显示梯形（梯形四棱柱俯视图），右侧显示绿色✓标记，表示"符合题目条件"

[交互方案]
- 交互类型：多状态切换（4个状态：初始+3个物体选择）
- 控件说明：
  - 按钮①：圆形，位置(200,465)，点击后显示物体①的俯视图（矩形）及✗标记
  - 按钮②：圆形，位置(400,465)，点击后显示物体②的俯视图（五边形）及✗标记
  - 按钮③：圆形，位置(600,465)，点击后显示物体③的俯视图（梯形）及✓标记
- 教师操作流程：
  1. 初始状态向学生展示三个候选物体
  2. 依次点击按钮①②③，引导学生观察每个物体的俯视图形状
  3. 对比题目给定的"上面视图"（梯形），让学生判断哪个匹配
  4. 点击按钮③时显示✓，确认正确答案，强化三视图概念

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript。原因：几何图形简单，无需复杂库；SVG 便于精确控制坐标和样式切换；原生 JS 足够处理状态切换逻辑
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────────┐
  │           三个物体的俯视图对比 (标题 y=25)                   │
  │                                                             │
  │   [物体①]      [物体②]      [物体③]   (y=60-180)            │
  │    长方体       五棱柱      梯形柱                          │
  │                                                             │
  │   ┌──────────────┐    ┌──────────────┐                      │
  │   │   俯视图     │    │  题目条件    │   (y=260-380)        │
  │   │  [动态图形]  │    │  [梯形]      │                      │
  │   │         [✓/✗]│    │              │                      │
  │   └──────────────┘    └──────────────┘                      │
  │                                                             │
  │        (①)        (②)        (③)      (y=440-490 按钮栏)    │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentState 存储当前状态（0-3），0=初始，1=物体①，2=物体②，3=物体③
  2. 坐标计算：三个物体等间距排列，中心x坐标分别为160,350,540，间距190px
  3. 俯视图绘制：
     - 物体①俯视图：矩形 (150,300)-(310,340)
     - 物体②俯视图：五边形，顶点坐标根据五棱柱顶面计算
     - 物体③俯视图：梯形 (160,300)-(300,300)-(290,340)-(170,340)
  4. 事件绑定：三个按钮分别绑定 click 事件，调用 setState(1/2/3)
  5. 样式切换：通过修改 SVG 元素的 stroke、stroke-width、fill 属性实现高亮/未选中切换
  6. 判断标记：根据状态显示不同文本和颜色，state=3 时显示绿色✓，否则显示红色✗
- ID 命名规范：所有交互元素 ID 以 scene2- 为前缀
  - scene2-obj1, scene2-obj2, scene2-obj3（物体立体图）
  - scene2-label1, scene2-label2, scene2-label3（物体标签）
  - scene2-topview-group（俯视图显示区）
  - scene2-topview-shape（俯视图形状）
  - scene2-judgment（判断标记）
  - scene2-btn1, scene2-btn2, scene2-btn3（三个按钮）
  - scene2-ref-trapezoid（题目条件梯形）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
