[图示主题与整合说明]
- 本图示主题：网格中甲、乙阴影三角形面积比较
- 整合的步骤/概念：原始图形展示 → 甲三角形面积计算（底×高÷2）→ 乙三角形面积计算（两个小三角形面积和）→ 面积对比结论
- 教学价值：教师可使用此图示逐步引导学生观察网格中的三角形，通过标注底和高，直观理解三角形面积公式的应用，最终得出甲乙面积相等的结论。分步展示便于课堂节奏控制，学生可跟随教师的讲解逐步思考。

[分步序列]
步骤 0（初始状态）：
- 显示：网格线、甲三角形（蓝色半透明）、乙三角形（绿色半透明）、"甲"标签、"乙"标签
- 隐藏：所有尺寸标注、面积公式、结论

步骤 1（高亮甲并标注底高）：
- 显示：甲三角形加粗边框（#000000, 2px）
- 显示：甲底标注线 (160,140)-(400,140) 和文字"底=3" (280,120)
- 显示：甲高标注线 (410,150)-(410,310) 和文字"高=2" (420,230)
- 隐藏：乙相关标注

步骤 2（显示甲面积计算）：
- 保持步骤 1 所有元素
- 显示：面积公式框，内容"S_甲 = 底×高÷2 = 3×2÷2 = 3"
- 公式框位置：(50,380)-(400,430)

步骤 3（高亮乙并标注底高）：
- 甲恢复普通边框
- 显示：乙三角形加粗边框（#000000, 2px）
- 显示：乙底标注线1 (480,320)-(560,320) 和文字"底=1" (520,340)
- 显示：乙底标注线2 (560,320)-(640,320) 和文字"底=1" (600,340)
- 显示：乙高标注线 (570,230)-(570,310) 和文字"高=1" (580,270)
- 隐藏：甲的标注线（可选保留）

步骤 4（显示乙面积计算）：
- 保持步骤 3 所有元素
- 显示/更新：面积公式框，内容"S_乙 = (底×高÷2)×2 = (1×1÷2)×2 = 1"
- 公式框位置：(50,380)-(400,430)

步骤 5（面积对比结论）：
- 保持步骤 4 所有元素
- 显示：结论文字"S_甲 = 3 > S_乙 = 1"，坐标 (450,405)，红色加粗 18px
- 或显示结论："甲的阴影面积 > 乙的阴影面积"

[标签冲突检查]
所有标签坐标及间距检查：
- "甲"：(260,200)
- "乙"：(580,260)
- "底=3"：(280,120)
- "高=2"：(420,230)
- "底=1"（乙1）：(520,340)
- "底=1"（乙2）：(600,340)
- "高=1"：(580,270)
- "S_甲=3"：(200,405)
- "S_乙=1"：(200,405)（步骤切换显示）
- 结论：(500,405)

冲突检查：
- "甲"(260,200) 与 "底=3"(280,120)：y 差 80px → 无冲突
- "甲"(260,200) 与 "高=2"(420,230)：x 差 160px → 无冲突
- "乙"(580,260) 与 "高=1"(580,270)：y 差 10px → 接近但可接受（"乙"在三角形内，"高=1"在右侧外部）
- "底=1"(520,340) 与 "底=1"(600,340)：x 差 80px → 无冲突
- "高=1"(580,270) 与 "底=1"(520,340)：距离 √(60²+70²)≈92px → 无冲突
- 面积公式框 (y=380~430) 与网格底部 (y=310)：间距 70px → 无冲突
- 结论文字与面积公式：同 y 坐标但 x 错开 → 无冲突

所有标签间距 ≥ 10px，主要标签间距 ≥ 50px，无明显冲突。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 (280,460)，80×30px，点击后退到前一状态
  - 「下一步」按钮：位于 (440,460)，80×30px，点击前进到下一状态
  - 步骤指示器：位于 (380,465)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始展示原始图形，让学生观察甲乙形状
  2. 点击「下一步」高亮甲并标注底高，引导学生识别甲的底和高
  3. 点击「下一步」显示甲面积计算，讲解公式应用
  4. 点击「下一步」高亮乙并标注底高，引导学生观察乙由两个小三角形组成
  5. 点击「下一步」显示乙面积计算，讲解组合图形面积
  6. 点击「下一步」显示结论，得出甲面积大于乙面积
  7. 可随时点击「上一步」回退复习

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库）
- 画布尺寸：800×500px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |              网格区域 (480×160)                   |
  |         甲三角形        乙三角形                  |
  |         (左侧)          (右侧)                    |
  |                                                  |
  |              尺寸标注区 (y=320~360)               |
  |                                                  |
  |         [面积公式框]          [结论]              |
  |         (y=380~430)                               |
  |                                                  |
  |         [◀上一步]  步骤 X/5  [下一步▶]            |
  |         (y=460~490) 控件栏                        |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量 (0-5)，每个步骤对应一组显示/隐藏的元素
  2. 坐标计算：网格每格 80px，起始点 (160,150)，所有元素坐标基于此计算
  3. 动画曲线：元素显示使用淡入效果（opacity 0→1，300ms）
  4. 事件绑定：按钮点击事件切换 currentStep，调用 updateDisplay() 函数
  5. 元素分组：使用 SVG <g> 元素按功能分组（grid、triangle-jia、triangle-yi、labels-jia、labels-yi、formula、conclusion）
- ID 命名规范：
  - 所有元素 ID 以 "scene1-" 为前缀
  - 示例：scene1-grid, scene1-tri-jia, scene1-tri-yi1, scene1-tri-yi2
  - 标注：scene1-label-jia, scene1-label-yi, scene1-dim-jia-base, scene1-dim-jia-height
  - 按钮：scene1-btn-prev, scene1-btn-next, scene1-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
