problem_168_math_g6

场景导航：Scene 1 | Scene 2

题目原文：

图中的两个小圆的周长的和与大圆的周长比较，（ ）

A．一样长
B．大圆的周长长
C．大圆的周长短
D．无法比较

题目分析：

本题考察圆的周长公式及直径关系的理解。从图中可见：

  • 一个大圆内部包含两个小圆
  • 两个小圆的直径都在大圆的同一条直径上
  • 两个小圆彼此相切，且分别与大圆内切
  • 关键几何关系：两个小圆的直径之和等于大圆的直径

整体讲解思路：

  1. 首先引导学生观察图形结构，识别三个圆的位置关系
  2. 标注出三个圆的直径，建立直径之间的数量关系
  3. 回顾圆周长公式 C = πd
  4. 通过代数推导证明两个小圆周长之和等于大圆周长
  5. 得出结论并选择答案 A

图示规划说明：

规划 2 个图示场景：

  • SCENE_1：展示三个圆的直径关系，用线段标注清晰呈现 d1 + d2 = D
  • SCENE_2：动态演示圆周长的展开对比，直观展示周长相等

教学说明：

本图示用于引导学生建立直径关系的直观认识。

讲解要点：

  1. 先展示原始图形，让学生观察三个圆的位置关系
  2. 依次标注直径，强调两个小圆的直径都在大圆的直径上
  3. 通过线段拼接动画，直观展示 d1 + d2 = D
  4. 引出圆周长公式 C = πd，为下一步推导做准备

关键提问：

  • "两个小圆的直径加起来和大圆的直径有什么关系？"
  • "如果知道直径，如何计算圆的周长？"
步骤 1/5

教学说明：

本图示用于直观验证代数推导的结论，将抽象的公式转化为可视化的长度对比。

讲解要点：

  1. 回顾圆周长公式 C = πd
  2. 分别计算：大圆周长 = πD，两个小圆周长之和 = πd1 + πd2
  3. 利用分配律：πd1 + πd2 = π(d1 + d2)
  4. 结合直径关系 d1 + d2 = D，得出 π(d1 + d2) = πD
  5. 结论：两个小圆周长之和等于大圆周长

完整解答：

设大圆直径为 D，两个小圆直径分别为 d₁ 和 d₂。

由图可知：d₁ + d₂ = D

大圆周长：C = πD

两个小圆周长之和：C₁ + C₂ = πd₁ + πd₂ = π(d₁ + d₂) = πD

因此，两个小圆的周长之和与大圆的周长一样长。

答案：A

课堂讲解建议：

  • 可让学生先猜测答案，再用图示验证，增强参与感
  • 强调这是"一般性结论"：无论两个小圆大小如何分配，只要它们的直径之和等于大圆直径，周长之和就一定等于大圆周长
  • 可延伸思考：如果是三个、四个小圆呢？结论是否依然成立？
