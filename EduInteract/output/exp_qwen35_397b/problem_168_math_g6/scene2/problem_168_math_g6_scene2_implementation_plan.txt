[图示主题与整合说明]
- 本图示主题：圆周长展开对比演示
- 整合的内容：周长公式应用、代数推导、结论验证三个认知阶段
- 教学价值：教师通过逐步展开圆周长的方式，将抽象的代数推导可视化，帮助学生理解为什么两个小圆周长之和等于大圆周长。学生可以直观看到周长展开后的长度对比，从几何直观过渡到代数证明。

[分步序列]
- 初始状态（步骤0）：显示三个圆（大圆、小圆1、小圆2）及直径线，标注 D、d₁、d₂。周长展开区域为空。
- 步骤1：点击「下一步」→ 大圆周长展开条出现（蓝色矩形条 100,280-700,310），上方显示标签"πD"。三个圆保持显示但透明度降至 50%。
- 步骤2：点击「下一步」→ 两个小圆周长展开条出现（绿色矩形条，分别在 y=330-360），上方显示标签"πd₁"和"πd₂"。大圆展开条保持显示。
- 步骤3：点击「下一步」→ 显示对比对齐虚线（左右两端），右侧显示红色等号"="。强调两个绿色条拼接后总长度等于蓝色条长度。
- 步骤4：点击「下一步」→ 底部显示推导公式"πd₁ + πd₂ = π(d₁ + d₂) = πD"，最下方显示结论"一样长"（红色加粗）。所有元素完整显示。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 上一步按钮：位于(280,460)，尺寸 80×30，点击后返回上一状态
  - 下一步按钮：位于(440,460)，尺寸 80×30，点击后进入下一状态
  - 步骤指示器：显示"步骤 X/5"，位于两按钮之间(380,465)
- 教师操作流程：
  1. 初始状态展示题目原图，让学生观察三个圆的关系
  2. 点击「下一步」展开大圆周长，提问"大圆周长如何表示？"
  3. 点击「下一步」展开两个小圆周长，提问"两个小圆周长如何表示？"
  4. 点击「下一步」显示对齐线和等号，引导学生直观比较长度
  5. 点击「下一步」显示代数推导，完成从几何直观到代数证明的过渡

[技术实现]
- JS 库选择及原因：原生 SVG。原因：本场景为 2D 几何图形，无需复杂动画库，原生 SVG 轻量且易于精确控制坐标。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────┐
  │  y=50-200:  三个圆原始图形（大圆+两小圆+直径标注）   │
  │                                                     │
  │  y=280-310: 大圆周长展开条（蓝色）[步骤1 显示]      │
  │  y=330-360: 小圆周长展开条（绿色×2）[步骤 2 显示]   │
  │  y=310-360: 对比对齐虚线 + 等号 [步骤 3 显示]       │
  │                                                     │
  │  y=390-410: 推导公式 πd₁+πd₂=π(d₁+d₂)=πD [步骤 4]  │
  │  y=420-440: 结论"一样长" [步骤 4]                   │
  │                                                     │
  │  y=450-490: [◀上一步]  步骤 X/5  [下一步▶]          │
  └─────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量(0-4)跟踪当前步骤，steps 数组存储每步的可见元素 ID 列表
  2. 坐标计算：圆的位置按比例缩放，确保两小圆直径之和等于大圆直径（r1+r2=R）
  3. 动画曲线：使用 CSS transition 实现淡入效果（opacity 0→1，duration 300ms）
  4. 事件绑定：按钮点击事件切换步骤，更新可见元素和步骤指示器
  5. 元素显隐：每步通过 display/opacity 控制元素可见性，而非删除 DOM
- ID 命名规范：所有交互元素 ID 必须以 scene2- 为前缀
  - scene2-circle-big, scene2-circle-small1, scene2-circle-small2
  - scene2-diameter-line, scene2-label-D, scene2-label-d1, scene2-label-d2
  - scene2-expand-big, scene2-expand-small1, scene2-expand-small2
  - scene2-label-piD, scene2-label-pid1, scene2-label-pid2
  - scene2-align-left, scene2-align-right, scene2-equals-sign
  - scene2-formula, scene2-conclusion
  - scene2-btn-prev, scene2-btn-next, scene2-step-indicator
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中
