    **题目原文：**

    如图所示，电源电压恒定，闭合开关后，将滑动变阻器的滑片向右端移动的过程中，下列说法正确的是（  ）

    A．电流表示数变小，电压表 V₁ 示数变大

    B．小灯泡变暗，电压表 V₂ 示数变小

    C．电压表 V₁ 和电压表 V₂ 示数之和不变

    D．电路的总功率变大

    **题目分析：**

    本题为串联电路动态分析问题。电路结构为：小灯泡与滑动变阻器串联，电流表测总电流，电压表 V₁ 测滑动变阻器两端电压，电压表 V₂ 测小灯泡两端电压。

    **整体讲解思路：**

    1. 首先识别电路连接方式（串联）
    2. 明确各电表测量对象
    3. 分析滑片右移时滑动变阻器接入电阻的变化
    4. 根据欧姆定律推导电流、电压的变化
    5. 判断各选项正误

    **图示规划说明：**

    - SCENE_1：电路结构图，展示实物连接与等效电路图的对应关系
    - SCENE_2：动态分析图示，展示滑片移动时电阻、电流、电压的联动变化
</TEXT_1>

    本图示帮助学生完成从实物图到等效电路图的抽象过程，这是电路分析的关键第一步。

    **引导步骤：**

    1. 让学生观察实物图，追踪电流从电源正极出发的完整路径
    2. 识别串联关系：电流依次经过开关→灯泡→滑动变阻器→电流表，回到负极
    3. 明确电压表并联位置：V₁ 并联在滑动变阻器两端，V₂ 并联在灯泡两端
    4. 绘制等效电路图，用标准符号表示各元件

    **关键公式：**

    - 串联电路电流处处相等：I = I_L = I_R
    - 串联电路电压分配：U = U_L + U_R（即 V₂ + V₁ = 电源电压）
    - 欧姆定律：I = U / R_总

    <TEXT_3>
    **教学说明：**

    本图示通过连续拖拽交互，让学生直观观察滑片移动时各物理量的联动变化，建立"电阻变化→电流变化→电压重新分配"的因果链。

    **引导观察要点：**

    1. 滑片向右移动 → 滑动变阻器接入电阻 R_滑 增大
    2. 总电阻 R_总 = R_L + R_滑 增大 → 总电流 I = U / R_总 减小
    3. 灯泡两端电压 U_L = I × R_L 减小（V₂ 示数变小）
    4. 滑动变阻器两端电压 U_R = U - U_L 增大（V₁ 示数变大）
    5. 灯泡实际功率 P_L = I² × R_L 减小 → 灯泡变暗
    6. 电路总功率 P_总 = U × I 减小

    **选项判断：**

    - A：电流表示数变小✓，V₁ 示数变大✓ → **正确**
    - B：小灯泡变暗✓，V₂ 示数变小✓ → **正确**
    - C：V₁ + V₂ = 电源电压 U（恒定）→ **正确**
    - D：总功率 P_总 = UI，I 减小 → 总功率变小✗ → **错误**

    **答案：A、B、C 正确（若为单选题则需重新审视题目要求）**

    **课堂讲解建议：**

    让学生先拖动滑块观察现象，再引导其用欧姆定律解释原因，最后独立完成选项判断。
