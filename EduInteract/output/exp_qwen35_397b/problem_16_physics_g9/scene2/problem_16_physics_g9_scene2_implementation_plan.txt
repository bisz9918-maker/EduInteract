[分步序列]
本场景为连续拖拽交互，无分步导航，状态随滑块位置连续变化：

- 初始状态（滑块在左端）：
  - 滑动变阻器接入电阻最小（R_滑=0Ω）
  - 电流表示数最大（I=U/R_L）
  - V1 示数最小（U1=0V）
  - V2 示数最大（U2=U 电源）
  - 灯泡最亮（透明度 100%）
  - 总功率最大
  - 趋势箭头：I↓、U1↑、U2↓、P 总↓（指向右移时的变化方向）

- 滑块移动到右端过程中（连续变化）：
  - R_滑 从 0Ω 线性增加到最大值（如 50Ω）
  - I 从最大值逐渐减小
  - U1 从 0V 逐渐增大
  - U2 从电源电压逐渐减小
  - 灯泡亮度从 100% 逐渐变暗（透明度降至 30%）
  - P 总 逐渐减小

- 最终状态（滑块在右端）：
  - 滑动变阻器接入电阻最大
  - 电流表示数最小
  - V1 示数最大
  - V2 示数最小
  - 灯泡最暗
  - 总功率最小

[交互方案]
- 交互类型：连续拖拽滑块（左端↔右端）
- 控件说明：
  - 滑块轨道：位于 y=450，x=150~650，长度 500px
  - 滑块手柄：直径 24px 圆形，可沿轨道拖拽
  - 左端标签："左端"（电阻最小）
  - 右端标签："右端"（电阻最大）
- 教师操作流程：
  1. 初始状态展示滑片在左端时的电路状态
  2. 缓慢向右拖动滑块，引导学生观察各仪表数值变化
  3. 暂停在中间位置，提问学生各物理量的变化趋势
  4. 继续拖到右端，验证猜想
  5. 可来回拖动，强化"滑片右移→电阻变大→电流变小→电压重新分配"的因果关系

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：电路图几何形状简单，无需复杂库；拖拽交互用原生事件即可实现
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [电路图区 y=50~180]
  ┌─────────────────────────────────────────────────────────┐
  │  [电源]--[开关]--[灯泡]--[变阻器]--[A]                  │
  │           |                    |                        │
  │          [V₂]                 [V₁]                      │
  └─────────────────────────────────────────────────────────┘
  
  [仪表显示区 y=260~340]
  ┌─────────────────────────────────────────────────────────┐
  │  [I:0.5A]  [U₁:0V]  [U₂:6V]  [P 总:3W]   [趋势箭头区]   │
  └─────────────────────────────────────────────────────────┘
  
  [灯泡亮度区 y=360~440]
  ┌─────────────────────────────────────────────────────────┐
  │     [灯泡图标💡]                                        │
  └─────────────────────────────────────────────────────────┘
  
  [滑块控制区 y=440~480]
  ┌─────────────────────────────────────────────────────────┐
  │  左端 [━━━━━━━━━━●━━━━━━━━━━] 右端                       │
  │                    P 位置                               │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用单个变量 sliderPosition（0~1）表示滑块位置
  2. 坐标计算：滑片 P 的 x 坐标 = 380 + sliderPosition × 120
  3. 物理量计算（假设电源电压 U=6V，灯泡电阻 R_L=12Ω，变阻器最大 R_max=50Ω）：
     - R_滑 = sliderPosition × 50
     - I = U / (R_L + R_滑)
     - U1 = I × R_滑
     - U2 = I × R_L
     - P_总 = U × I
     - 灯泡亮度透明度 = 30% + (1-sliderPosition) × 70%
  4. 动画曲线：拖拽时实时更新，无需缓动
  5. 事件绑定：mousedown/touchstart 开始拖拽，mousemove/touchmove 更新位置，mouseup/touchend 结束
  6. 趋势箭头：根据 sliderPosition 变化方向动态显示↑或↓（右移时：I↓、U1↑、U2↓、P 总↓）
- ID 命名规范：所有元素 ID 以 scene2- 为前缀
  - scene2-slider-track、scene2-slider-handle、scene2-bulb、scene2-meter-I、scene2-meter-V1、scene2-meter-V2、scene2-meter-P、scene2-arrow-I、scene2-arrow-V1、scene2-arrow-V2、scene2-arrow-P
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
