- 本图示主题：集合包含关系模型——大类别包含三个并列子类别

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于(280,455)，灰色背景，步骤0时禁用，步骤1-3可点击回退
  - 「下一步」按钮：位于(420,455)，蓝色背景(#1565c0)，步骤3时禁用
  - 步骤指示器：位于两按钮之间(400,475)，显示"步骤 X/4"
- 教师操作流程：
  1. 初始展示完整图示，让学生观察整体结构
  2. 点击「下一步」高亮大圆，讲解"这是父集/大类别"
  3. 点击「下一步」高亮三个小圆，讲解"这是三个并列的子类别"
  4. 点击「下一步」显示关系箭头，总结"大类别包含三个互斥的小类别"
  5. 可随时点击「上一步」回退复习

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript。理由：本图示为简单几何图形（圆形、箭头、文字），无需复杂库，原生 SVG 性能好且代码简洁。
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                    父集/大类别                    |
  |              (步骤1标注)                          |
  |                                                   |
  |         Ⅰ包含Ⅱ、Ⅲ、Ⅳ  (步骤3)                    |
  |              ↓                                    |
  |        +-------------------+                      |
  |       /    Ⅰ      Ⅱ       \                      |
  |      |     (大圆)  ○       |                      |
  |      |            Ⅱ        |                      |
  |      |                     |                      |
  |      |   Ⅲ ○       Ⅳ ○    |                      |
  |       \                   /                       |
  |        +-----------------+                        |
  |              ↓                                    |
  |        Ⅱ、Ⅲ、Ⅳ互斥 (步骤3)                        |
  |                                                   |
  |              并列子类别                           |
  |              (步骤2标注)                          |
  +--------------------------------------------------+
  |          [◀上一步]  步骤1/4  [下一步▶]           |
  |              (控件栏 y=440~490)                   |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-3) 跟踪当前步骤，每个步骤对应一组可见元素
  2. 元素分组：将 SVG 元素按步骤分组（step0-elements, step1-elements等），用 display 控制显示/隐藏
  3. 高亮边框：用<circle>元素与大圆/小圆同心，stroke=#1565c0 stroke-width=3，初始display=none
  4. 箭头绘制：用<line>+<polygon>或<path>绘制带箭头的线段
  5. 按钮状态：步骤0时禁用上一步，步骤3时禁用下一步，用 opacity 和 pointer-events 控制
  6. 动画过渡：元素显示/隐藏可用 opacity 过渡(0.3s)增强视觉效果
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀（如 scene1-big-circle, scene1-small-circle-2, scene1-btn-next）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中
