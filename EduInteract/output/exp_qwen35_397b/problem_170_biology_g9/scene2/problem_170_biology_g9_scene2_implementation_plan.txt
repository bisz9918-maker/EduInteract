[分步序列]
本场景为多状态切换交互，无分步序列，状态定义如下：

- 初始状态（无选项选中）：
  - 左侧显示题目原图（I 包含 II、III、IV 三个并列小圆）
  - 右侧显示占位提示文字"请选择一个选项"
  - 四个按钮均为默认状态
  - 无判断标记和理由框

- 状态 A（点击「选项 A」）：
  - 右侧绘制：外圆标"鱼类"，内部三个独立小圆分别标"爬行类""鸟类""哺乳类"
  - 但实际 A 选项中四类是并列关系（都是脊椎动物），鱼类不包含其他三类
  - 判断标记：✗不符合（红色）
  - 理由：鱼类、爬行类、鸟类、哺乳类是并列关系，鱼类不包含其他三类

- 状态 B（点击「选项 B」）：
  - 右侧绘制：四层嵌套圆（细胞核>染色体>DNA>基因）
  - 判断标记：✗不符合（红色）
  - 理由：细胞核、染色体、DNA、基因是层级包含关系，不是大圆含三个并列小圆

- 状态 C（点击「选项 C」）：
  - 右侧绘制：外圆"种子"，内含"胚"和"种皮"两个圆，"胚"内再含"子叶"
  - 判断标记：✗不符合（红色）
  - 理由：种子包含胚和种皮，胚包含子叶，是两层嵌套关系

- 状态 D（点击「选项 D」）：
  - 右侧绘制：外圆"微生物"，内含三个并列小圆"病毒""细菌""真菌"
  - 判断标记：✓符合（绿色）
  - 理由：微生物包含病毒、细菌、真菌，三者是并列关系，与图示相符

[交互方案]
- 交互类型：多状态切换 — 四个按钮切换
- 控件说明：
  - 「选项 A」按钮：位置(150,450)，显示 A 选项的概念关系图
  - 「选项 B」按钮：位置(260,450)，显示 B 选项的概念关系图
  - 「选项 C」按钮：位置(370,450)，显示 C 选项的概念关系图
  - 「选项 D」按钮：位置(480,450)，显示 D 选项的概念关系图
- 教师操作流程：
  1. 首先展示题目原图，讲解图示含义（大圆包含三个并列小圆）
  2. 依次点击四个选项按钮，展示每个选项的概念关系
  3. 引导学生对比判断哪个选项与图示相符
  4. 点击 D 选项时显示✓符合，强化正确答案

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  [题目原图]           |  [选项动态图]            |
  |     I                 |      外圆标签            |
  |   +---+               |    +-------+             |
  |   |II |               |    | 内 1  |             |
  | +-------+             |  +---+---+---+           |
  | |III|IV |             |  |内 2|内 3|             |
  |   题目图示             |    判断标记              |
  |                       |   [理由框]               |
  |-----------------------|--------------------------|
  |  [A]  [B]  [C]  [D]   |  底部按钮区               |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentOption 存储当前选中选项（null/'A'/'B'/'C'/'D'）
  2. 每个选项的数据结构包含：外圆标签、内圆标签数组、内圆位置数组、是否符合、理由文字
  3. 点击按钮时：更新 currentOption，清除右侧原有图形，根据数据重新绘制
  4. 按钮高亮：选中按钮添加高亮样式，其他按钮恢复默认
  5. 判断标记和理由框：根据是否符合显示不同颜色和文字

- ID 命名规范：
  - 题目原图：scene2-original-outer, scene2-original-inner-1/2/3
  - 选项图：scene2-option-outer, scene2-option-inner-1/2/3
  - 标签：scene2-label-original-I/II/III/IV, scene2-label-option-1/2/3
  - 判断标记：scene2-judgment-mark, scene2-judgment-text
  - 理由框：scene2-reason-box, scene2-reason-text
  - 按钮：scene2-btn-a, scene2-btn-b, scene2-btn-c, scene2-btn-d
  - 分隔线：scene2-divider

- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
