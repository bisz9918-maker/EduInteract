[图示主题与整合说明]
- 本图示主题：DNA 分子的化学组成层次结构
- 整合的步骤/概念：整合了概念图原图（A+B+C→D→E）、各组分名称标注、脱氧核苷酸的形成过程、DNA 链的聚合结构
- 教学价值：教师可使用此图示逐步展示从基本化学组分（碱基、脱氧核糖、磷酸）到脱氧核苷酸单体，再到 DNA 双螺旋聚合物的层次关系。分步呈现有助于学生理解生物大分子的组装逻辑，配合高亮和分子结构图，使抽象概念可视化。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：本图示以几何形状（矩形、圆形、路径）和文本为主，无需复杂图表库；原生 SVG 轻量且易于控制每个元素的状态
- 画布尺寸：800×500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +----------------------------------------------------------+
  |  [A] + [B] + [C] ---> [D] ---> [E]        y=50~110       |
  |   ↑     ↑     ↑         ↑         ↑                     |
  |  标签  标签  标签      标签      标签    y=20~35         |
  +----------------------------------------------------------+
  |              分子结构示意图              y=180            |
  +----------------------------------------------------------+
  |   步骤 0-3: 逐步显示分子组件                              |
  |   步骤 4: [磷酸]--[糖]--[碱基] 组合成核苷酸               |
  |   步骤 5: DNA 双螺旋简图（两条链 + 碱基对）               |
  +----------------------------------------------------------+
  |  [上一步]  [下一步]  步骤 X/5            y=450~490        |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量（0-5），每个步骤对应一个 render 函数或状态更新逻辑
  2. 元素分组：将相关元素放入 <g> 组，如 concept-group、molecule-group、dna-group、controls-group
  3. 高亮逻辑：每个框有 data-step 属性，根据 currentStep 动态设置 fill 和 opacity
  4. 按钮事件：点击「下一步」currentStep++，点击「上一步」currentStep--，边界时禁用对应按钮
  5. 动画效果：使用 CSS transition 实现颜色渐变（0.3s ease）
  6. 元素显示/隐藏：使用 display="none" 或 opacity 控制各步骤特有元素
- ID 命名规范：所有元素 ID 以 scene1- 为前缀
  - scene1-box-a, scene1-box-b, scene1-box-c, scene1-box-d, scene1-box-e
  - scene1-label-a, scene1-label-b, scene1-label-c, scene1-label-d, scene1-label-e
  - scene1-molecule-phosphate, scene1-molecule-sugar, scene1-molecule-base
  - scene1-dna-chain1, scene1-dna-chain2, scene1-dna-bond-1~4
  - scene1-btn-prev, scene1-btn-next, scene1-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
- CDN 引入：无需额外库，使用原生 SVG 和 JS
