B．只有①所示的过程能逆浓度梯度运输物质
C．大分子物质只有通过①过程才能进入细胞
D．葡萄糖进入小肠上皮细胞与过程②有关

题目分析：

本题考查物质跨膜运输方式的分类体系及各运输方式的特点。原图是一个树状分类图，需要学生：

  1. 识别分类层级关系
  2. 推断序号①②③④分别代表的运输方式或实例
  3. 根据各运输方式的特点判断选项正误

整体讲解思路：

  1. 首先呈现完整的分类图，让学生识别①=主动运输，②=协助扩散
  2. 对比三种小分子运输方式（自由扩散、协助扩散、主动运输）的特点
  3. 分析各选项，结合具体实例判断

图示规划说明：

  • SCENE_1：完整的分类树状图，可逐步揭示序号含义
  • SCENE_2：三种运输方式的对比表格/示意图，展示特点差异
  • SCENE_3：各选项分析，高亮正确选项并说明理由
步骤 0/5

教学说明：

本图示用于帮助学生建立物质跨膜运输的完整分类框架。

讲解要点：

  1. 物质跨膜运输方式分为两大类：被动运输和主动运输（①）
  2. 被动运输不消耗能量，包括自由扩散和协助扩散（②）
  3. 主动运输需要消耗 ATP，可逆浓度梯度运输

引导学生观察：

  • 被动运输和主动运输的根本区别是什么？（是否消耗能量）
  • 自由扩散和协助扩散的区别是什么？（是否需要载体蛋白）

关键公式/概念：

  • 被动运输：顺浓度梯度，不消耗 ATP
  • 主动运输：逆浓度梯度，消耗 ATP，需要载体蛋白
  • 协助扩散：顺浓度梯度，不消耗 ATP，需要载体蛋白
步骤 0/5

教学说明：

本图示用于对比三种运输方式的核心差异，帮助学生理解选项判断的依据。

讲解要点：

  1. 能量消耗：只有主动运输消耗 ATP
  2. 浓度梯度：只有主动运输可逆浓度梯度
  3. 载体蛋白：自由扩散不需要，协助扩散和主动运输需要

选项分析引导：

  • 选项 A：①主动运输消耗 ATP，②协助扩散不消耗 ATP → A 错误
  • 选项 B：只有主动运输可逆浓度梯度 → B 正确
  • 选项 C：大分子物质通过胞吞胞吐进出细胞，不是主动运输 → C 错误
  • 选项 D：葡萄糖进入小肠上皮细胞是主动运输（①），不是协助扩散（②） → D 错误

正确答案：B

总结：

完整解答：

根据分类图可知：

  • ① = 主动运输
  • ② = 协助扩散

各选项分析：

  • A 错误：①主动运输消耗 ATP，但②协助扩散不消耗 ATP
  • B 正确：只有主动运输能逆浓度梯度运输物质
  • C 错误：大分子物质通过胞吞作用进入细胞，不是主动运输
  • D 错误：葡萄糖进入小肠上皮细胞是主动运输（①），葡萄糖进入红细胞才是协助扩散（②）

课堂讲解建议：

  1. 先让学生根据分类树推断①②的含义
  2. 回顾三种运输方式的特点对比
  3. 逐一分析选项，强调判断依据
  4. 提醒学生注意易错点：大分子运输方式、葡萄糖的不同运输方式

易错点提醒：

  • 葡萄糖进入不同细胞的运输方式不同：进入红细胞是协助扩散，进入小肠上皮细胞是主动运输
  • 大分子物质（蛋白质、多糖等）通过胞吞胞吐进出细胞，不属于主动运输
