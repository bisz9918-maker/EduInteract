[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮：位于 (280,460)，点击后退到前一个步骤
  - 下一步按钮：位于 (440,460)，点击前进到下一个步骤
  - 步骤指示器：位于 (380,465)，显示当前步骤 X/5
- 教师操作流程：
  1. 初始状态仅显示顶层概念，教师引入主题
  2. 点击"下一步"显示第二层分支，讲解被动运输与主动运输的区分
  3. 点击"下一步"显示第三层，讲解被动运输的两种类型
  4. 点击"下一步"显示第四层实例，讲解具体运输方式
  5. 点击"下一步"高亮显示序号含义，揭示①=主动运输、②=协助扩散
  6. 点击"下一步"完整展示所有序号含义，总结分类体系
  7. 教师可随时点击"上一步"回退复习关键概念

[技术实现]
- JS 库选择：原生 SVG（简单几何图形首选，无需额外库）
- 画布尺寸：800×500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |              [物质跨膜运输方式]                   |  y=40
  |                   /        \                      |
  |          [被动运输]        [①主动运输]            |  y=120
  |             /    \              |                 |
  |      [自由扩散] [②协助扩散]     |                 |  y=200
  |           |        |            |                 |
  |      [氧气]   [③葡萄糖]    [④K+离子]             |  y=280
  |                                                    |
  |                                                    |
  |  [◀上一步]  步骤 X/5  [下一步▶]                    |  y=460
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep 跟踪当前步骤 (0-5)，数组 steps 定义每步显示的元素 ID 列表
  2. 坐标计算：所有元素使用绝对坐标，SVG 中用 <rect>、<line>、<circle>、<text> 元素
  3. 动画曲线：元素出现使用淡入效果 (opacity 0→1，duration 300ms)
  4. 事件绑定：按钮点击事件切换步骤，更新元素 display/opacity 属性
  5. 边界处理：步骤 0 时禁用"上一步"，步骤 5 时禁用"下一步"
- ID 命名规范：所有元素 ID 以 scene1- 为前缀
  - scene1-box-top（顶层框）
  - scene1-box-passive（被动运输框）
  - scene1-box-active（①主动运输框）
  - scene1-box-free（自由扩散框）
  - scene1-box-facilitated（②协助扩散框）
  - scene1-box-oxygen（氧气框）
  - scene1-box-glucose（③葡萄糖框）
  - scene1-box-ion（④离子框）
  - scene1-num-1/2/3/4（序号圆圈）
  - scene1-label-1/2/3/4（含义标注）
  - scene1-line-1~7（连接线）
  - scene1-btn-prev/next（按钮）
  - scene1-step-indicator（步骤指示器）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
- 颜色规格：
  - 背景：#ffffff
  - 框线：#000000（默认），#2e7d32（被动分支高亮），#c62828（主动分支高亮），#1565c0（序号含义高亮）
  - 填充：#f5f5f5（10% 透明度效果，实际用 fill-opacity="0.1"）
  - 序号圆圈：#c62828 填充，#ffffff 文字
  - 含义标注：#1565c0 文字
