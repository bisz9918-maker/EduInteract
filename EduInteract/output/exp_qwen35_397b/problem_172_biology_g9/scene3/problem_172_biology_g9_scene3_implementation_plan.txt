[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 内底部左侧 (50,460)，点击回退到前一状态
  - 「下一步」按钮：位于 SVG 内底部右侧 (550,460)，点击前进到下一状态
  - 步骤指示器：显示当前步骤序号（如"步骤 2/5"），位于两按钮之间
- 教师操作流程：
  1. 初始状态展示四个选项，让学生阅读题目
  2. 点击「下一步」分析选项 A，讲解为什么错误（①主动运输消耗 ATP，②协助扩散不消耗）
  3. 点击「下一步」分析选项 B，讲解为什么正确（主动运输是唯一可逆浓度梯度的运输方式），同时绿色高亮框突出显示
  4. 点击「下一步」分析选项 C，讲解为什么错误（大分子通过胞吞胞吐，不是主动运输）
  5. 点击「下一步」分析选项 D，讲解为什么错误（葡萄糖进入小肠上皮细胞是主动运输①，不是协助扩散②）
  6. 点击「下一步」显示最终结论，强调正确答案 B

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript。理由：本场景为静态文本展示 + 分步显隐，无需复杂动画或绘图库，原生实现最轻量。
- 画布尺寸：800 × 500 px（固定画布）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌────────────────────────────────────────────────────┐
  │  [选项 A 框]  A．①和②...              ✗          │
  │            ①消耗 ATP，②不消耗 ATP                 │
  ├────────────────────────────────────────────────────┤
  │  [选项 B 框]  B．只有①...             ✓  [绿框]   │
  │            主动运输唯一可逆浓度梯度                │
  ├────────────────────────────────────────────────────┤
  │  [选项 C 框]  C．大分子...            ✗          │
  │            大分子通过胞吞胞吐                      │
  ├────────────────────────────────────────────────────┤
  │  [选项 D 框]  D．葡萄糖...            ✗          │
  │            葡萄糖进入小肠上皮细胞是主动运输①       │
  ├────────────────────────────────────────────────────┤
  │                    正确答案：B                     │
  ├────────────────────────────────────────────────────┤
  │  [◀上一步]              步骤 X/5        [下一步▶]  │ ← 控件栏 y=460-490
  └────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep 跟踪当前步骤（0-5），数组 stepElements 存储每步需显示的元素 ID
  2. 显隐控制：每步调用 updateDisplay() 函数，遍历所有元素，根据 currentStep 决定 display 属性
  3. 按钮状态：步骤 0 时禁用「上一步」，步骤 5 时禁用「下一步」，用 opacity 和 pointer-events 控制
  4. 动画效果：元素显示时添加淡入动画（opacity 0→1，transition 0.3s）
  5. 事件绑定：按钮点击事件绑定到 updateStep() 函数，增减 currentStep 后调用 updateDisplay()
- ID 命名规范：所有交互元素 ID 必须以 scene3- 为前缀
  - scene3-option-a, scene3-option-b, scene3-option-c, scene3-option-d（选项框）
  - scene3-text-a, scene3-text-b, scene3-text-c, scene3-text-d（选项文本）
  - scene3-mark-a, scene3-mark-b, scene3-mark-c, scene3-mark-d（判断标记）
  - scene3-reason-a, scene3-reason-b, scene3-reason-c, scene3-reason-d（理由文本）
  - scene3-highlight-b（高亮框）
  - scene3-conclusion（结论文本）
  - scene3-btn-prev, scene3-btn-next, scene3-step-indicator（控件）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
