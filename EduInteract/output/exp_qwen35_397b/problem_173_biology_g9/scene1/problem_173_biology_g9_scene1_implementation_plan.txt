[图示主题与整合说明]
- 本图示主题：自然界碳循环中各成分的身份判断
- 整合的步骤/概念：碳循环图的完整结构、各成分与大气 CO₂的关系、碳元素流动路径、甲乙丙身份推导
- 教学价值：教师可使用此图示逐步引导学生观察箭头方向→分析物质流动关系→推导生态角色身份，从现象到本质的认知过程，帮助学生理解生态系统中生产者、消费者、分解者的功能区别

[分步序列]
- 初始状态（步骤 0）：显示基础碳循环图
  - 大气 CO₂框（灰色边框）
  - 甲、乙、丙三个圆形节点（灰色边框，内部显示"甲""乙""丙"）
  - 所有 6 条箭头均为灰色 #888888
  - 无结论框，无选项高亮

- 步骤 1：点击「下一步」→ 高亮甲与大气之间的双向箭头
  - 大气↔甲的双向箭头变为蓝色 #1565c0，线宽加粗至 3px
  - 在箭头旁显示注释文本框："双向交换→生产者"（蓝色背景，白字）
  - 其他箭头保持灰色

- 步骤 2：点击「下一步」→ 高亮甲→丙的箭头
  - 甲→丙的单向箭头变为绿色 #2e7d32，线宽加粗至 3px
  - 在箭头旁显示注释文本框："甲被丙摄食→丙是消费者"（绿色背景，白字）
  - 步骤 1 的蓝色箭头保持高亮

- 步骤 3：点击「下一步」→ 高亮分解相关箭头
  - 甲→乙、丙→乙、乙→大气三条箭头变为橙色 #f57c00，线宽加粗至 3px
  - 在乙节点旁显示注释文本框："分解遗体释放 CO₂→乙是分解者"（橙色背景，白字）
  - 步骤 1、2 的高亮保持

- 步骤 4：点击「下一步」→ 显示结论并高亮正确选项
  - 隐藏所有注释文本框
  - 在甲、乙、丙节点旁分别显示结论框：
    - 甲=生产者（蓝色框）
    - 乙=分解者（橙色框）
    - 丙=消费者（绿色框）
  - 选项 A 显示绿色边框 #2e7d32（线宽 3px），其他选项灰色边框

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于 (280,465)，返回上一状态
  - 「下一步 ▶」按钮：位于 (420,465)，进入下一状态
  - 步骤指示器：位于 (360,465)，显示"步骤 X/4"
- 教师操作流程：
  1. 初始展示完整碳循环图，让学生观察箭头方向
  2. 点击「下一步」步骤 1，引导学生注意甲与大气的双向交换，推导甲是生产者
  3. 点击「下一步」步骤 2，展示甲→丙的摄食关系，推导丙是消费者
  4. 点击「下一步」步骤 3，展示乙的分解功能，推导乙是分解者
  5. 点击「下一步」步骤 4，显示最终结论并高亮正确选项 A
  6. 可随时点击「上一步」回退复习关键推理步骤

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（圆形节点、矩形框、箭头），无需复杂库；原生 SVG 对箭头标记（marker）支持良好；代码轻量易维护
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +----------------------------------------------------------+
  |              [大气中的二氧化碳]                          |
  |                    ↕ (双向)                              |
  |                                                           |
  |     (甲) ←──────────────────────────→ (丙)               |
  |      | ↘                            ↙ |                  |
  |      |   ↘                        ↙   |                  |
  |      |     ↘                    ↙     |                  |
  |      |       ↘                ↙       |                  |
  |      |         ↘            ↙         |                  |
  |      ↓           ↘        ↙           ↑                  |
  |                   (乙) ←──────────────                    |
  |                     ↓                                     |
  |                                                           |
  |  [结论框]                              [选项框 A/B/C/D]   |
  |                                                           |
  |              [◀上一步] [步骤 X/4] [下一步▶]               |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-4），数组存储每步的配置对象
  2. 箭头高亮：通过修改 stroke 属性和 marker-end/marker-start 的 fill 属性实现
  3. 双向箭头：使用两个单向箭头叠加，或自定义 SVG marker
  4. 注释文本框：使用 <g> 分组，包含 rect 背景和 text，步骤切换时显示/隐藏
  5. 结论框：步骤 4 时动态创建或显示预定义的 <g> 元素
  6. 选项高亮：修改选项矩形的 stroke 和 stroke-width 属性
- ID 命名规范：
  - 所有元素 ID 以 scene1- 为前缀
  - 示例：scene1-atmosphere-box, scene1-node-jia, scene1-node-yi, scene1-node-bing
  - 箭头：scene1-arrow-atm-jia, scene1-arrow-jia-bing, scene1-arrow-jia-yi, scene1-arrow-bing-yi, scene1-arrow-yi-atm, scene1-arrow-bing-atm
  - 结论框：scene1-conclusion-jia, scene1-conclusion-yi, scene1-conclusion-bing
  - 选项：scene1-option-a, scene1-option-b, scene1-option-c, scene1-option-d
  - 按钮：scene1-btn-prev, scene1-btn-next, scene1-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
- 箭头实现细节：
  - 使用 <defs> 定义 arrowhead marker
  - 单向箭头：line + marker-end
  - 双向箭头：line + marker-start + marker-end
  - 曲线路径：甲→乙、丙→乙使用 quadratic Bézier 曲线 (Q 命令) 避免与直线重叠
