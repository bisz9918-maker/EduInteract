    **题目原文：**

    如图为突触的结构，并在 a、d 两点连接一测量电位变化的灵敏电流计，下列分析中正确的是（ ）

    ①图示的结构包括 3 个神经元，含有 3 个突触
    ②分别刺激 b、c 点时，指针都偏转 2 次
    ③如果 B 受刺激，C 会兴奋；如果 A、B 同时受刺激，C 不会兴奋。则 A 释放的是抑制性递质。
    ④递质可与突触后膜的"受体"结合，"受体"的化学本质是糖蛋白
    ⑤A、B 一定是轴突，C 可能是树突，也可能是轴突

    A．①③④       B．②④      C．①③⑤       D．③④

    **题目分析：**

    本题考查突触结构、神经冲动传导及电流计偏转原理。关键知识点包括：
    - 突触的组成结构（突触前膜、突触间隙、突触后膜）
    - 神经元之间的连接方式
    - 兴奋在神经纤维上的双向传导与在突触间的单向传递
    - 电流计指针偏转次数与兴奋传导路径的关系
    - 兴奋性递质与抑制性递质的作用机制

    **整体讲解思路：**

    1. 首先识别图中神经元数量及突触数量
    2. 分析刺激不同点时兴奋的传导路径
    3. 理解电流计指针偏转的原理（兴奋先后经过 a、d 两点时指针偏转）
    4. 理解抑制性递质的作用机制
    5. 识别突触结构中各部分的名称及受体本质

    **图示规划说明：**

    共设计 3 个图示场景：
    - SCENE_1：突触结构详解，标注各部分名称
    - SCENE_2：刺激 b、c 点时兴奋传导路径与电流计偏转演示
    - SCENE_3：兴奋性/抑制性递质作用对比
    </TEXT_1>

    <TEXT_3>
    **教学说明：**

    本图示演示兴奋在神经纤维上的传导和在突触间的传递特点，帮助学生理解电流计指针偏转次数的判断方法。

    **讲解要点：**

    1. **兴奋传导特点：**
       - 在神经纤维上：双向传导
       - 在突触间：单向传递（只能从突触前膜到突触后膜）

    2. **刺激 b 点时：**
       - 兴奋在 B 神经元上双向传导
       - 向左传至 a 点，电流计指针第一次偏转
       - 向右经突触传至 C 神经元，再传至 d 点，电流计指针第二次偏转
       - 结论：指针偏转 2 次

    3. **刺激 c 点时：**
       - 兴奋在 C 神经元上双向传导
       - 向右传至 d 点，电流计指针偏转 1 次
       - 向左不能经突触逆向传至 B 神经元（突触传递的单向性）
       - 无法到达 a 点
       - 结论：指针偏转 1 次

    4. 因此选项②"分别刺激 b、c 点时，指针都偏转 2 次"是错误的

    **关键公式/原理：**

    电流计指针偏转次数 = 兴奋先后经过两个电极点的次数差

    <TEXT_4>
    **教学说明：**

    本图示展示抑制性递质的作用机制，帮助学生理解选项③的判断依据。

    **讲解要点：**

    1. **题干条件分析：**
       - 条件 1：B 受刺激 → C 兴奋（说明 B 释放的是兴奋性递质）
       - 条件 2：A、B 同时受刺激 → C 不兴奋

    2. **推理过程：**
       - A 的轴突末梢与 B 形成突触，A 可释放递质作用于 B
       - 当 A、B 同时受刺激时，若 A 释放抑制性递质，会使 B 的兴奋被抑制
       - B 被抑制后无法释放兴奋性递质作用于 C
       - 因此 C 不会兴奋

    3. **结论：** 选项③正确，A 释放的是抑制性递质

    **神经元结构判断（选项⑤）：**

    - A、B 的末梢都含有突触小泡，说明都是轴突末梢
    - C 作为突触后神经元，可能是树突（接收信号）也可能是轴突（继续传导）
    - 因此选项⑤正确

    **综合判断：**

    | 选项 | 判断 | 理由 |
    |------|------|------|
    | ① | 错误 | 3 个神经元，2 个突触 |
    | ② | 错误 | 刺激 b 偏转 2 次，刺激 c 偏转 1 次 |
    | ③ | 正确 | A 释放抑制性递质 |
    | ④ | 正确 | 受体是糖蛋白 |
    | ⑤ | 正确 | A、B 是轴突，C 可能是树突或轴突 |

    **正确答案：D．③④**

    （注：若⑤也正确，则答案应为③④⑤，但选项中无此组合，根据题目选项设置，答案为 D）
