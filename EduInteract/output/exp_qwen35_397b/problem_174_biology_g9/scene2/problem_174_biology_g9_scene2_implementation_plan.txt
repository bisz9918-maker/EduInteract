[图示主题与整合说明]
- 本图示主题：兴奋传导路径与电流计偏转演示
- 整合的步骤/概念：整合了刺激 b 点和 c 点两种情况的兴奋传导路径、电流计偏转次数对比

[分步序列]
- 状态 0（原始状态）：显示完整的突触结构图，包括神经元 A、B、C，电流计连接 a、d 两点，指针居中向上，无兴奋传导
- 状态 1（刺激 b 点）：
  * b 点出现红色脉冲标记
  * 兴奋从 b 点双向传导：向左经轴突传至 a 点（红色波浪箭头动画），向右经突触传至 C 神经元再传至 d 点
  * a 点高亮（蓝色半透明圆），d 点高亮（绿色半透明圆）
  * 电流计指针先向左偏转（a 点先兴奋），再向右偏转（d 点后兴奋），显示"偏转 2 次"
- 状态 2（刺激 c 点）：
  * c 点出现红色脉冲标记
  * 兴奋从 c 点双向传导：向右传至 d 点（红色波浪箭头动画），向左传至突触但被阻断（显示×标记）
  * 只有 d 点高亮（绿色半透明圆），a 点无变化
  * 电流计指针只向右偏转 1 次，显示"偏转 1 次"

[交互方案]
- 交互类型：多状态切换（3 个按钮：原始状态/刺激 b 点/刺激 c 点）
- 控件说明：
  * 按钮"原始状态"：位于底部左侧(70,470)，点击恢复初始图示
  * 按钮"刺激 b 点"：位于底部中间(250,470)，点击展示状态 1
  * 按钮"刺激 c 点"：位于底部右侧(430,470)，点击展示状态 2
- 教师操作流程：
  1. 先展示原始状态，介绍突触结构和电流计连接方式
  2. 点击"刺激 b 点"，引导学生观察兴奋双向传导及经过突触的单向传递，指针偏转 2 次
  3. 点击"刺激 c 点"，对比观察兴奋不能逆向通过突触，指针只偏转 1 次
  4. 可反复切换对比，强化理解

[技术实现]
- JS 库选择：原生 SVG（适合绘制神经元结构、波浪箭头、指针动画），无需额外库
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────┐
  │              刺激 b 点 (状态 1 标题)                 │ y=30
  │         [电流计]                                    │ y=50-100
  │    a←──b──→[突触]──→d          偏转 2 次            │ y=80-180
  │     (神经元 B)    (神经元 C)                        │
  │                                                     │
  │              刺激 c 点 (状态 2 标题)                 │ y=260
  │         [电流计]                                    │ y=280-330
  │    a    [×]  c──→d              偏转 1 次           │ y=310-410
  │     (神经元 B)    (神经元 C)                        │
  │                                                     │
  │  [原始状态]  [刺激 b 点]  [刺激 c 点]               │ y=470
  └─────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  * 状态机设计：用 currentState 变量(0/1/2)跟踪当前状态，点击按钮时更新并重新渲染
  * 波浪箭头动画：使用 SVG <path>配合 stroke-dasharray 和 stroke-dashoffset 实现流动效果
  * 指针偏转动画：使用 CSS transform: rotate() 配合 transition 实现平滑偏转
  * 脉冲动画：刺激点使用 CSS @keyframes 实现半径脉冲扩散效果
  * 事件绑定：三个按钮分别绑定 onclick 事件，调用 setState(0/1/2)
- ID 命名规范：所有元素 ID 以 scene2- 为前缀，如 scene2-neuron-b-state1、scene2-pointer-state1、scene2-btn-original 等
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
