[图示主题与整合说明]
- 本图示主题：兴奋性与抑制性递质作用机制对比
- 整合的步骤/概念：整合了 B 单独受刺激、A 与 B 同时受刺激两种情况的对比，展示抑制性递质的作用效果
- 教学价值：教师可通过切换两种刺激状态，直观展示抑制性递质如何阻断神经信号传递。状态 1 展示正常兴奋传递（B→C），状态 2 展示 A 释放抑制性递质后 B 被抑制、C 无法兴奋的机制。配合右侧电位变化曲线，学生可理解动作电位产生与否的差异。

[分步序列]
- 初始状态（状态 0）：
  - 显示：神经元 A、B、C 结构，电流计，电极 a/d，刺激点 b/c 标记
  - 突触小泡：B 内有 5 个未释放小泡（灰色），A 内有 4 个未释放小泡（灰色）
  - 电位图：仅显示静息电位基线（虚线），无动作电位曲线
  - C 神经元：灰色填充 #f5f5f5
  - 标题："原始状态"
  - 无递质分子显示

- 状态 1（点击「B 单独受刺激」按钮）：
  - B 神经元：高亮边框 #2e7d32，内部小泡变为绿色 #2e7d32
  - 递质释放动画：5 个绿色圆点从 B 突触前膜移向 C 突触后膜（持续 1.5 秒）
  - C 神经元：填充变为 #e8f5e9（绿色高亮），边框 #2e7d32
  - 电流计：指针先向右偏转（a 点兴奋），再向左偏转（d 点兴奋），模拟 2 次偏转
  - 电位图：绘制蓝色动作电位曲线（从静息电位上升至峰值后恢复）
  - 显示标签："兴奋性递质"（绿色）、"C 兴奋"（绿色）、"动作电位"
  - 标题："B 单独受刺激"

- 状态 2（点击「A、B 同时受刺激」按钮）：
  - A 神经元：高亮边框 #c62828，内部小泡变为红色 #c62828
  - 递质释放动画：4 个红色圆点从 A 移向 B 突触后膜（持续 1.5 秒）
  - B 神经元：保持灰色，小泡不释放（被抑制）
  - C 神经元：保持灰色填充 #f5f5f5，无高亮
  - 电流计：指针仅轻微偏转 1 次（仅 a 点有电位变化，d 点无）
  - 电位图：仅显示静息电位基线（灰色直线），无动作电位峰
  - 显示标签："抑制性递质"（红色）、"C 不兴奋"（灰色）、"A 释放抑制性递质"
  - 标题："A、B 同时受刺激"

[交互方案]
- 交互类型：多状态切换（3 个状态：原始状态 / B 单独刺激 / A+B 同时刺激）
- 控件说明：
  - 按钮 1「B 单独受刺激」：位置 (580, 455)，尺寸 120×35，切换到状态 1
  - 按钮 2「A、B 同时受刺激」：位置 (710, 455)，尺寸 140×35，切换到状态 2
  - 按钮 3「重置」：位置 (500, 455)，尺寸 70×35，返回状态 0
- 教师操作流程：
  1. 初始展示原始状态，讲解突触结构（A→B→C 的连接关系）
  2. 点击「B 单独受刺激」，观察 B 释放兴奋性递质、C 兴奋产生动作电位的过程，讲解正常神经信号传递
  3. 点击「重置」回到原始状态
  4. 点击「A、B 同时受刺激」，观察 A 释放抑制性递质、B 被抑制、C 不兴奋的过程，讲解抑制性递质的阻断机制
  5. 对比两种状态下电流计偏转次数和电位曲线的差异

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript
  - 原因：几何形状简单（椭圆、圆形、路径），无需复杂库；状态切换逻辑简单；SVG 便于精确控制元素位置和样式
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +----------------------------------------------------------+
  |  [电流计]                      [电位图标题]              |
  |     ↑                          原始状态/B 刺激/A+B 刺激  |
  |  A  |  B       C                                       |
  |     | (●)----(●)          +------------------+          |
  |     |  ●●●    ●●●         | 电位图           |          |
  |     |   ●●     ●●          |  ~~~动作电位~~~  |          |
  |     |                      |  ------------    |          |
  |     +----a          d------+  +------------------+          |
  |                          时间 t→                            |
  +----------------------------------------------------------+
  |  [重置]  [B 单独受刺激]  [A、B 同时受刺激]                 |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0/1/2），每个状态对应一组显示/隐藏的元素
  2. 递质释放动画：使用 CSS transition 或 requestAnimationFrame，将递质分子从突触前膜位置渐变到突触后膜位置
  3. 电位曲线绘制：使用 SVG <path> 元素，状态 1 显示完整动作电位路径，状态 2 仅显示基线
  4. 电流计指针动画：使用 transform: rotate()，状态 1 模拟两次偏转（+30° → -30° → 0°），状态 2 仅一次轻微偏转（+15° → 0°）
  5. C 神经元高亮：通过切换 class 改变 fill 和 stroke 颜色
  6. 事件绑定：三个按钮分别绑定 click 事件，调用 updateState(newState) 函数
- ID 命名规范：所有元素 ID 以 scene3- 为前缀
  - 神经元：scene3-neuron-a, scene3-neuron-b, scene3-neuron-c
  - 递质分子：scene3-excitatory-vesicle-1~5, scene3-inhibitory-vesicle-1~4
  - 电位曲线：scene3-action-potential-curve, scene3-resting-line
  - 电流计：scene3-galvanometer, scene3-galvanometer-needle
  - 按钮：scene3-btn-reset, scene3-btn-b-only, scene3-btn-ab-simultaneous
  - 标签：scene3-label-a, scene3-label-b, scene3-label-c, scene3-label-excitatory, scene3-label-inhibitory
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
