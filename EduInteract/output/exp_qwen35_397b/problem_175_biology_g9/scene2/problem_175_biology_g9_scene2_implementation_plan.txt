[图示主题与整合说明]
- 本图示主题：四类植物关键特征对比表
- 整合的步骤/概念：藻类植物、苔藓植物、蕨类植物、裸子植物的核心特征对比（有无种子、有无茎叶、有无输导组织、有无真根、生活环境），并与题目分类图中的②③④编号建立对应关系

[分步序列]
- 初始状态（步骤0）：显示表格外框、表头（6 列标题）、表格网格线。数据行全部隐藏。
- 步骤1：显示藻类植物行（行1背景、植物名、编号②、5 个特征标记、生活环境）。当前行高亮 #e3f2fd。
- 步骤2：显示苔藓植物行（行2背景、植物名、编号④、5 个特征标记、生活环境）。行1取消高亮，行2高亮。
- 步骤3：显示蕨类植物行（行3背景、植物名、编号③、5 个特征标记、生活环境）。行2取消高亮，行3高亮。
- 步骤4：显示裸子植物行（行4背景、植物名、编号①、5 个特征标记、生活环境）。行3取消高亮，行4高亮。
- 步骤5：显示分类树缩略图（位于右下角）、3 条连线（②③④分别连向缩略图对应分支）。所有行保持显示，无高亮。

[标签冲突检查]
- 表头标签间距：各列中心间距约 110px，文字宽度约 60-80px，间距充足无冲突
- 行内标签：每列内容居中，列宽 110-120px，✓/✗符号宽约 20px，无冲突
- 编号圆圈与植物名：植物名在 x=110，编号圆圈在 x=175，间距 65px，无冲突
- 行间距：每行高度 65px，文字垂直居中，行间距 5px（如行1底 y=155，行2顶 y=160），无冲突
- 步骤5连线：从编号圆圈 (175,125/195/265) 斜向连至缩略图 (620-700,415)，不穿过其他行内容
- 缩略图位置：y=400-430，在表格下方 (表格底 y=370)，间距 30px，无冲突

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 (320,450)-(390,480)，点击回退到前一状态，步骤0时禁用
  - 「下一步」按钮：位于 (410,450)-(480,480)，点击进入下一状态，步骤5时禁用
- 教师操作流程：
  1. 初始展示表头，讲解分类依据（有无种子、有无茎叶等）
  2. 点击「下一步」揭示藻类特征，讲解②对应藻类、无种子无茎叶等
  3. 继续点击揭示苔藓、蕨类、裸子植物，逐项对比
  4. 步骤5展示分类树缩略图，用连线说明表格与题目图解的对应关系
  5. 可点击「上一步」回退复习特定类群

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript。表格结构简单，无需复杂库；SVG 便于精确控制每个元素的位置和显隐。
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +----------------------------------------------------------+
  |  [表头：植物类群 | 有无种子 | 有无茎叶 | 输导组织 | 真根 | 生活环境]  |
  |  +----------------------------------------------------+  |
  |  | 藻类植物 ② |   ✗   |   ✗   |   ✗   |  ✗  |  水中   |  |
  |  +----------------------------------------------------+  |
  |  | 苔藓植物 ④ |   ✗   |   ✓   |   ✗   | 假根 | 阴湿陆地 |  |
  |  +----------------------------------------------------+  |
  |  | 蕨类植物 ③ |   ✗   |   ✓   |   ✓   | 真根 | 阴湿陆地 |  |
  |  +----------------------------------------------------+  |
  |  | 裸子植物 ① |   ✓   |   ✓   |   ✓   | 真根 | 干旱陆地 |  |
  |  +----------------------------------------------------+  |
  |                            [分类树缩略图] (步骤5显示)     |
  |                                                          |
  |              [◀上一步]      [下一步▶]                    |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  - 状态机设计：用变量 currentStep (0-5) 跟踪当前步骤
  - 每个步骤对应的元素组用 class="step-0"、"step-1"等标记，通过 display 控制显隐
  - 高亮行：用 class="highlight" 切换背景色 #e3f2fd
  - 按钮状态：步骤0禁用上一步，步骤5禁用下一步（opacity:0.5，pointer-events:none）
  - 连线用 SVG <line> 元素，stroke-dasharray="5,5" 实现虚线
- ID 命名规范：所有元素 ID 以 scene2- 为前缀，如 scene2-table-header、scene2-row1-algae、scene2-btn-next 等
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
