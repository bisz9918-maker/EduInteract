    <TEXT_1>
    **题目原文：**

    右图为某同学用丝带扎紧上臂的示意简图。发现丝带下方（近手指端）的血管①膨胀，血管②变扁；丝带上方的血管③膨胀，血管④变扁。下列有关叙述中，正确的是

    A．血管①、④是动脉
    B．血管②、③是静脉
    C．血管①中血液的含氧量比血管③低
    D．血管④中血液的含氧量比血管②高

    **题目分析：**

    本题考查人体血液循环系统中动脉和静脉的特点，以及血管被阻断后的血流变化规律。

    **核心知识点：**
    1. 动脉：将血液从心脏输送到全身各处，血流方向是"离心"的
    2. 静脉：将血液从全身送回心脏，血流方向是"回心"的
    3. 在上臂中，动脉血向下流向手指，静脉血向上流回心脏
    4. 丝带扎紧后，静脉远心端膨胀（血液回流受阻），动脉近心端膨胀（血液无法流向远端）
    5. 动脉血含氧量高，静脉血含氧量低

    **图示规划说明：**
    - SCENE_1：展示正常状态下上臂动脉和静脉的血流方向及位置关系
    - SCENE_2：展示丝带扎紧后血管的膨胀/变扁变化，解释原因
    - SCENE_3：对比动脉血与静脉血的含氧量差异

    **讲解思路：**
    先让学生识别图中血管类型→理解丝带阻断效应→分析各选项正误
    </TEXT_1>

       - 动脉：血液从心脏流出，在上臂中方向向下（流向手指）
       - 静脉：血液流回心脏，在上臂中方向向上（流向心脏）

    2. **图中血管判断**
       - 左侧血管箭头向上 → 静脉
       - 右侧血管箭头向下 → 动脉

    3. **区域对应**
       - ①：静脉，丝带下方（远心端）
       - ②：动脉，丝带下方（远心端）
       - ③：动脉，丝带上方（近心端）
       - ④：静脉，丝带上方（近心端）

    **引导问题：**
    - 为什么左侧血管箭头向上？（血液要流回心脏）

    <TEXT_3>
    **教学要点：**

    1. **丝带扎紧的阻断效应**
       - 丝带压迫血管，阻断血液流动
       - 静脉被阻断：远心端（①）血液无法回流 → 膨胀
       - 动脉被阻断：近心端（③）血液无法流向远端 → 膨胀

    2. **变扁的原因**
       - ②（动脉远心端）：血液被阻断无法流下来 → 变扁
       - ④（静脉近心端）：血液已流回心脏，无血液补充 → 变扁

    3. **血管类型判断结论**
       - ①：静脉（膨胀，远心端）
       - ②：动脉（变扁，远心端）
       - ③：动脉（膨胀，近心端）
       - ④：静脉（变扁，近心端）

    **选项分析：**
    - A 错误：①④都是静脉，不是动脉
    - B 错误：②③都是动脉，不是静脉
    </TEXT_3>

    <TEXT_4>
    **教学要点：**

    1. **含氧量规律**
       - 动脉血：从心脏泵出，经过肺部氧合，含氧量高（约 95-100%）
       - 静脉血：经过组织细胞消耗氧气后回流，含氧量低（约 60-75%）

    2. **本题中含氧量对比**
       - ①是静脉血，③是动脉血 → ①含氧量 < ③含氧量（选项 C 正确）
       - ④是静脉血，②是动脉血 → ④含氧量 < ②含氧量（选项 D 错误）

    3. **正确答案：C**
       - 血管①（静脉血）中血液的含氧量比血管③（动脉血）低

    **完整解答：**
    1. 根据血流方向判断：左侧向上为静脉，右侧向下为动脉
    2. 根据膨胀/变扁判断：①静脉远心端膨胀，②动脉远心端变扁，③动脉近心端膨胀，④静脉近心端变扁
    3. 含氧量：静脉血（①④）< 动脉血（②③）
    4. 选项 C 正确：①（静脉血）含氧量比③（动脉血）低

    **课堂讲解建议：**
    - 先让学生观察原图，识别血流方向
    - 用 SCENE_1 建立动脉静脉概念
    - 用 SCENE_2 解释膨胀变扁的机制
    - 用 SCENE_3 对比含氧量，得出最终答案
