[图示主题与整合说明]
- 本图示主题：丝带扎紧后血管的膨胀与变扁效应
- 整合内容：丝带阻断血流的原理、静脉远心端膨胀、动脉近心端膨胀、四个血管状态对比
- 教学价值：教师可通过分步动画展示丝带扎紧上臂后，静脉和动脉在不同位置的血流变化，帮助学生理解"静脉远心端膨胀、动脉近心端膨胀"的因果关系，配合生物学中血液循环方向的知识

[分步序列]
- 初始状态（步骤0）：显示正常状态的静脉和动脉血管（宽度12px，不透明），丝带半透明显示，四个数字标签①②③④显示，静脉/动脉文字标签显示
- 步骤1：点击「下一步」→ 丝带变为不透明（扎紧），静脉①区域（丝带下方左侧）血管变粗至24px，填充蓝色透明度40%，右侧出现"膨胀"标注框，步骤说明显示"静脉①：血液回流受阻，远心端膨胀"
- 步骤2：点击「下一步」→ 动脉③区域（丝带上方右侧）血管变粗至24px，填充红色透明度40%，左侧出现"膨胀"标注框，步骤说明显示"动脉③：心脏泵血被阻断，近心端膨胀"
- 步骤3：点击「下一步」→ 静脉④区域（丝带上方左侧）血管变细至4px，透明度10%，右侧出现"变扁"标注框；动脉②区域（丝带下方右侧）血管变细至4px，透明度10%，左侧出现"变扁"标注框，步骤说明显示"②④：血液无法流过，远心端变扁"
- 步骤4：点击「下一步」→ 所有膨胀/变扁标注同时显示，添加原因说明文字框："静脉血回流心脏受阻→①膨胀"、"动脉血从心脏流出受阻→③膨胀"，步骤说明显示"完整状态：丝带阻断血流，近心端膨胀，远心端变扁"

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：SVG 内底部左侧 (x=280, y=455)，返回上一状态
  - 「下一步」按钮：SVG 内底部右侧 (x=440, y=455)，进入下一状态
  - 步骤指示器：SVG 内底部中央 (x=350, y=475)，显示当前步骤说明文字
- 教师操作流程：
  1. 初始状态展示正常血管布局，讲解静脉和动脉的血流方向
  2. 点击「下一步」展示丝带扎紧，静脉①膨胀，解释"静脉血回流受阻"
  3. 点击「下一步」展示动脉③膨胀，解释"动脉血从心脏流出被阻断"
  4. 点击「下一步」展示②④变扁，解释"远心端血液供应不足"
  5. 点击「下一步」展示完整状态，总结规律，可点击「上一步」回退复习

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，血管用 path/line 绘制，动画用 CSS transition）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────┐
  │                    静脉        动脉                      │
  │                     ↑          ↓                        │
  │              ④ ──── │          │ ──── ③                 │
  │                     │          │                        │
  │  ───────────────────┼──────────┼───────────────── 丝带   │
  │                     │          │                        │
  │              ① ──── │          │ ──── ②                 │
  │                     ↓          ↑                        │
  │                  膨胀        变扁                        │
  │                                                         │
  │              [◀上一步]  步骤说明  [下一步▶]              │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用 currentState 变量跟踪 0-4 共 5 个状态
  2. 血管宽度动画：用 CSS transition 实现平滑过渡（transition: width 0.5s, opacity 0.5s）
  3. 膨胀/变扁标注显示：用 display 属性控制，配合 opacity 淡入效果
  4. 事件绑定：按钮点击事件切换状态，更新所有血管样式和标注显示
  5. ID 命名规范：所有元素 ID 以 scene2- 为前缀（如 scene2-vein、scene2-artery、scene2-ribbon、scene2-label1 等）
  6. IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
- 血管绘制：用两个 rect 元素表示血管主体（可调整宽度），用 polygon 绘制箭头
- 丝带绘制：用 rect 元素，y=244, height=12, width=500, x=150
- 标注框：用 rect+text 组合，圆角矩形背景#fff9c4，边框#fbc02d
