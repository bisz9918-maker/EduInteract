[图示主题与整合说明]
- 本图示主题：染色体-DNA-基因的结构层级与概念包含关系
- 整合的内容：图甲组分拆解（染色体→DNA+蛋白质→基因定位）+ 图乙嵌套圆层级映射（①染色体/②DNA/③基因）
- 教学价值：教师可通过分步高亮，帮助学生建立微观结构（图甲）与抽象概念（图乙）的对应关系，理解遗传物质的层级结构。步骤化展示适合课堂讲解节奏，学生可跟随教师点击逐步理解染色体如何由DNA和蛋白质组成，以及基因在DNA上的定位。

[分步序列]
共5个步骤（步骤0-4），教师可点击「上一步/下一步」导航：

- 步骤0（初始状态）：显示完整图甲（染色体+DNA+蛋白质+基因）和图乙（三层嵌套圆），所有元素默认透明度60%，无高亮
- 步骤1：高亮染色体[1]（不透明度100%，加粗描边）+ 高亮圆①（填充不透明度40%，加粗边框），显示连接箭头从[1]指向①
- 步骤2：染色体[1]淡出，展开显示DNA[2]和蛋白质[3]细节（不透明度100%），高亮DNA双螺旋结构
- 步骤3：高亮基因[4]片段（红色加粗）+ 高亮圆③（填充不透明度40%），显示连接箭头从[4]指向③
- 步骤4（最终步骤）：在DNA[2]下方添加标注框"遗传信息载体"，所有对应关系用虚线连接（[1]→①、[2]→②、[4]→③）

  6. 可随时点击"上一步"回退复习关键概念

[技术实现]
- JS库选择：原生SVG（适合几何图形和路径动画，无需额外库）
- 画布尺寸：800×500px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  [图甲区域 x=20-460]    |  [图乙区域 x=500-780]  |
  |     染色体[1]           |      嵌套圆①②③        |
  |        ↓                |        ①(外)           |
  |     DNA[2]+蛋白质[3]    |        ②(中)           |
  |        →基因[4]         |        ③(内)           |
  |                         |                        |
  |   "图甲"(200,420)       |   "图乙"(680,420)      |
  +--------------------------------------------------+
  |         [◀上一步]  步骤X/4  [下一步▶]            |
  |              (控件栏 y=450-490)                  |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量currentStep(0-4)跟踪当前步骤，steps数组存储每步的显示配置
  2. 坐标计算：所有元素位置硬编码为像素值，确保布局精确
  3. 动画曲线：使用CSS transition实现淡入淡出（opacity 0.3s ease）
  4. 事件绑定：按钮点击事件切换currentStep，调用renderStep()重绘
  5. ID命名规范：所有元素ID以"scene1-"为前缀（如scene1-chromosome、scene1-dna、scene1-circle1）
  6. IIFE隔离：所有JS代码包在(function() { ... })()中，避免全局污染
  7. 高亮实现：通过修改opacity和stroke-width属性，非高亮元素opacity=0.4，高亮元素opacity=1.0
- 元素ID列表：
  - scene1-chromosome（染色体[1]）
  - scene1-dna（DNA[2]）
  - scene1-protein（蛋白质[3]）
  - scene1-gene（基因[4]）
  - scene1-circle1（圆①）
  - scene1-circle2（圆②）
  - scene1-circle3（圆③）
  - scene1-label-1至scene1-label-4（标签[1]-[4]）
  - scene1-label-c1至scene1-label-c3（标签①-③）
  - scene1-btn-prev（上一步按钮）
  - scene1-btn-next（下一步按钮）
  - scene1-step-indicator（步骤指示器）
