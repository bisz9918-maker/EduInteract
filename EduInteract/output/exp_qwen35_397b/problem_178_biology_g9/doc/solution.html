题目原文：

南瓜的花色由一对等位基因控制。相关杂交实验及结果如右图所示。下列说法中错误的是

A．F₁的表现型及其比例可验证基因的分离定律
B．由过程③可知白色是显性性状
C．F₂中黄花与白花的比例是5∶3
D．F₁与F₂中白花个体的基因型相同

题目分析：

本题考查孟德尔分离定律的应用。系谱图显示：

  • P代：黄花 × 白花 → F₁有黄花和白花
  • F₁黄花自交（过程②）→ F₂全为黄花
  • F₁白花自交（过程③）→ F₂出现黄花和白花（性状分离）

整体讲解思路：

  1. 首先判断显隐性：过程③中白花自交出现性状分离，说明白花为显性（Aa），黄花为隐性（aa）
  2. 推导各代基因型：P代黄花(aa) × 白花(Aa) → F₁黄花(aa) : 白花(Aa) = 1:1
  3. 计算F₂比例：F₁黄花(aa)自交→全aa；F₁白花(Aa)自交→aa:A_:aa = 1:2:1
  4. 逐项分析选项，找出错误说法

图示规划说明：

共设计3个图示：

  • SCENE_1：完整遗传系谱图，标注各代基因型，展示显隐性判断依据
  • SCENE_2：过程③的分离定律验证（Punnett方格展示配子结合）
  • SCENE_3：F₂代比例计算可视化（分步累加各支系贡献）

教学说明：

本图示用于引导学生理解遗传系谱图的分析方法。

讲解要点：

  1. 先让学生观察系谱图结构，识别P代、F₁代、F₂代的关系
  2. 提问：如何判断显隐性？引导学生关注过程③
  3. 关键推理：F₁白花自交后代出现黄花，说明发生了性状分离，只有杂合子自交才会性状分离，因此白花为显性（Aa），黄花为隐性（aa）
  4. 推导P代基因型：黄花必为aa，白花与aa杂交产生1:1的F₁，说明P代白花为Aa

核心公式：

  • 显隐性判断依据：杂合子自交→性状分离
  • P代杂交：aa（黄花）× Aa（白花）→ F₁：1aa : 1Aa
步骤 0/5

教学说明：

本图示专门验证分离定律，对应选项A的判断依据。

讲解要点：

  1. 分离定律的核心：杂合子形成配子时，等位基因彼此分离，分别进入不同配子
  2. F₁白花(Aa)产生两种配子A和a，比例1:1
  3. 自交时雌雄配子随机结合，产生4种组合
  4. 基因型比例AA:Aa:aa = 1:2:1，表现型比例白花:黄花 = 3:1

关键结论：

  • 过程③的后代比例验证了分离定律
  • 选项A正确：F₁的表现型及其比例（1:1测交比例）可验证分离定律
  • 选项B正确：过程③出现性状分离，说明白花是显性

教学说明：

本图示用于计算F₂代的表现型比例，对应选项C的判断。

讲解要点：

  1. F₁的构成：P代aa×Aa→F₁为1/2 aa（黄花）+ 1/2 Aa（白花）
  2. F₁黄花支系：1/2 aa自交→全部aa（黄花），贡献1/2黄花
  3. F₁白花支系：1/2 Aa自交→1/4 aa + 3/4 A_，贡献1/8黄花 + 3/8白花
  4. 汇总：黄花=1/2+1/8=5/8，白花=3/8，比例5:3

完整计算：

$$F_2黄花比例 = \frac{1}{2} \times 1 + \frac{1}{2} \times \frac{1}{4} = \frac{5}{8}$$

$$F_2白花比例 = \frac{1}{2} \times \frac{3}{4} = \frac{3}{8}$$

$$黄花:白花 = 5:3$$

因此选项C正确。

总结：完整解答与课堂讲解建议

各选项分析：

  1. 选项A：F₁的表现型及比例（黄花:白花=1:1）是测交结果，可验证分离定律 → 正确
  1. 选项B：过程③中F₁白花自交出现性状分离，说明白花为显性 → 正确
  1. 选项C：经计算F₂中黄花:白花=5:3 → 正确
  1. 选项D：F₁白花基因型为Aa（杂合子）；F₂白花基因型为AA或Aa（纯合子或杂合子）→ 基因型不完全相同 → 错误

答案：D

课堂讲解建议：

  1. 先用SCENE_1建立系谱图整体认知，引导学生发现过程③的特殊性
  2. 用SCENE_2深入讲解分离定律的验证机制
  3. 用SCENE_3演示比例计算的完整过程
  4. 最后回归选项D的辨析：F₁白花只有Aa一种基因型，F₂白花有AA和Aa两种基因型，因此"基因型相同"的说法错误

易错点提醒：

  • 学生容易忽略F₂白花包含AA和Aa两种基因型
  • 比例计算时容易忘记F₁两支系各自的权重（各1/2）
