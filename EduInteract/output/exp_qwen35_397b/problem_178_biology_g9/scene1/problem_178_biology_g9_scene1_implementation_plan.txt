[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 底部左侧 (320,455)，点击回退到前一状态
  - 「下一步」按钮：位于 SVG 底部右侧 (420,455)，点击进入下一状态
  - 步骤指示器：显示当前步骤编号（如"步骤 2/5"）
- 教师操作流程：
  1. 初始展示纯系谱图，让学生观察表现型分布
  2. 点击「下一步」揭示 P 代基因型，讲解亲本基因型推导
  3. 点击「下一步」揭示 F₁代基因型，讲解测交结果
  4. 点击「下一步」高亮过程③，引导学生发现性状分离现象，得出显隐性判断
  5. 点击「下一步」完成 F₂代基因型标注，验证分离定律

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：系谱图为静态几何图形（线、圆、文本），无需复杂动画库；原生 SVG 轻量且易于精确控制坐标
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────┐
  │  P    黄花 × 白花                                   │ y=50-100
  │         ①                                          │
  │        /  \                                        │
  │  F₁  黄花  白花                                     │ y=180-230
  │       │    / \                                     │
  │       ②   ③  \                                    │ y=260-280
  │      /        \                                    │
  │  F₂ 黄花      黄花  白花                            │ y=350-400
  │                    [结论框]                        │ y=290-340
  │                                                     │
  │         [◀上一步]  [下一步▶]                       │ y=440-490
  └─────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用 currentStep 变量（0-4）跟踪当前步骤，steps 数组存储每步应显示的元素 ID 列表
  2. 元素分组：按显示时机给 SVG 元素分组（g 标签），如 g id="step0-elements"、g id="step1-elements"等
  3. 显示/隐藏控制：每步切换时遍历所有步骤组，仅当前步骤及之前步骤的组设为 display="block"
  4. 按钮状态：步骤 0 禁用「上一步」，步骤 4 禁用「下一步」
  5. 动画过渡：基因型标注使用淡入效果（opacity 0→1，duration 300ms）
- ID 命名规范：
  - 所有元素 ID 以 scene1- 为前缀
  - 示例：scene1-p-yellow、scene1-p-white、scene1-f1-yellow、scene1-f1-white、scene1-f2-yellow1、scene1-f2-yellow2、scene1-f2-white
  - 基因型：scene1-p-yellow-genotype、scene1-p-white-genotype 等
  - 过程圆圈：scene1-process1、scene1-process2、scene1-process3
  - 控件：scene1-btn-prev、scene1-btn-next、scene1-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
