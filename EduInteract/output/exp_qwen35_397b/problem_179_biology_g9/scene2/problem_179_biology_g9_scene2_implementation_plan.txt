[图示主题与整合说明]
- 本图示主题：二氧化碳使石灰水变浑浊的化学反应微观原理
- 整合内容：CO₂分子与氢氧化钙反应生成碳酸钙沉淀的微观过程、宏观浑浊现象与粒子变化的对应关系
- 教学价值：教师可通过拖动 CO₂浓度滑块，动态展示反应程度与浑浊程度的正相关关系，帮助学生理解"量变引起质变"的化学原理，建立宏观现象（石灰水变浑浊）与微观粒子（CO₂+Ca(OH)₂→CaCO₃↓+H₂O）之间的联系

[分步序列]
本场景为连续拖拽滑块交互，无分步导航，定义 3 个关键状态：

- 初始状态（滑块 0%）：
  - 显示 0 个 CO₂分子
  - 显示 12 个 Ca²⁺离子（蓝色）和 12 个 OH⁻离子（红色）均匀分布
  - 显示 0 个 CaCO₃沉淀
  - 溶液背景透明度 20%（#e3f2fd 浅蓝色，近乎澄清）
  - 浑浊指示条显示最浅状态
  - 化学方程式完整显示：CO₂ + Ca(OH)₂ → CaCO₃↓ + H₂O

- 状态 1（滑块 50%）：
  - 显示 7-8 个 CO₂分子从试管顶部飘入
  - Ca²⁺和 OH⁻离子位置不变
  - 显示约 25 个 CaCO₃沉淀颗粒（白色）在溶液底部聚集
  - 溶液背景透明度 45%（微浊状态）
  - 浑浊指示条显示中等浑浊
  - 反应箭头高亮闪烁

- 状态 2（滑块 100%）：
  - 显示 15 个 CO₂分子充满试管上部
  - Ca²⁺和 OH⁻离子部分被沉淀遮挡（视觉上层叠）
  - 显示 50 个 CaCO₃沉淀颗粒密集分布
  - 溶液背景透明度 70%（#ffffff 白色，高度浑浊）
  - 浑浊指示条显示最深浑浊状态
  - 反应箭头持续高亮

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：
  - CO₂浓度滑块：位于右侧上部，水平滑块，拖拽范围 0-100%
  - 浑浊程度指示条：位于右侧下部，垂直渐变条，只读显示当前浑浊度
- 教师操作流程：
  1. 初始状态展示澄清石灰水中的离子分布
  2. 缓慢拖动滑块向右，CO₂分子逐渐进入试管
  3. 引导学生观察沉淀颗粒数量增加与溶液浑浊度变化的同步关系
  4. 滑块至最右端时，强调大量白色沉淀生成的宏观现象
  5. 可来回拖动滑块，对比不同浓度下的反应程度

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：分子/离子为简单圆形，SVG 足够胜任；拖拽交互用原生事件处理即可；无需复杂动画库
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [800×500 画布]
  +--------------------------------------------------+
  |           标题"石灰水反应微观示意图"              |
  |                                                  |
  |  +------------------+       +-----------------+  |
  |  |                  |       | CO₂浓度滑块     |  |
  |  |   试管放大视图    |       | [====●====]     |  |
  |  |   (分子/离子/沉淀) |       | 低←→高          |  |
  |  |                  |       |                 |  |
  |  |                  |       | 浑浊程度指示条  |  |
  |  |                  |       | ▒▒▒▒▒▒▒▒▒▒     |  |
  |  |                  |       | ▒▒▒▒▒▒▒▒▒▒     |  |
  |  +------------------+       | 澄清→浑浊       |  |
  |                             +-----------------+  |
  |                                                  |
  |        CO₂ + Ca(OH)₂ → CaCO₃↓ + H₂O              |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用单个变量 sliderValue (0-100) 控制所有动态元素
  2. 分子/离子/沉淀用 SVG <circle> 元素，位置预计算后存入数组
  3. 拖拽事件：mousedown/mousemove/mouseup 或 touch 事件兼容
  4. 溶液背景透明度：opacity = 0.2 + (sliderValue / 100) * 0.5
  5. CO₂分子数量：Math.floor(sliderValue / 100 * 15)
  6. CaCO₃沉淀数量：Math.floor(sliderValue / 100 * 50)
  7. 浑浊指示条：用 SVG <rect> 叠加多层，透明度随 sliderValue 变化
  8. 反应箭头高亮：sliderValue > 0 时添加 CSS 动画（opacity 闪烁）
- ID 命名规范：所有元素 ID 以 scene2- 为前缀
  - scene2-tube（试管容器）
  - scene2-solution（溶液背景）
  - scene2-co2-group（CO₂分子组）
  - scene2-ca-ion-group（Ca²⁺离子组）
  - scene2-oh-ion-group（OH⁻离子组）
  - scene2-precipitate-group（CaCO₃沉淀组）
  - scene2-reaction-arrow（反应箭头）
  - scene2-slider-track（滑块轨道）
  - scene2-slider-thumb（滑块按钮）
  - scene2-turbidity-bar（浑浊指示条）
  - scene2-equation（化学方程式）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
