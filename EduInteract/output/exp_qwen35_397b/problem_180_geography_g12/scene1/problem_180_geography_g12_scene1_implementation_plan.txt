[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于 SVG 内底部左侧(320,455)，点击后回退到上一状态
  - 「下一步 ▶」按钮：位于 SVG 内底部右侧(400,455)，点击后进入下一状态
- 教师操作流程：
  1. 初始状态展示地球基本结构，教师介绍光照图的基本组成
  2. 点击「下一步」展示太阳光线，讲解太阳光平行射入的特点
  3. 点击「下一步」高亮晨昏线，讲解晨昏线的定义和位置
  4. 点击「下一步」显示昼夜半球，讲解昼夜划分原理
  5. 点击「下一步」强调 A/B/C 三点，讲解各点的地理意义（A 在晨昏线上太阳高度为 0，B 在昼半球，C 接近直射点）
  6. 教师可随时点击「上一步」回退复习

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript。原因：本图示为 2D 几何图形，SVG 适合绘制球体、弧线、箭头等几何元素，且便于通过 CSS 控制显隐和动画；无需引入重型库。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |                    73°41'                        |
  |                      N                           |
  |         夜半球    /    \    昼半球               |
  |               /   晨昏线   \                     |
  |         B •  /      • A     \   • C              |
  |             /                \                   |
  |            |                  |                  |
  |             \                /                   |
  |              \      S       /                    |
  |                                                  |
  |                    → → →  太阳光线               |
  |                                                  |
  |              [◀ 上一步] [下一步 ▶]               |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-4），数组存储每步需显示的元素 ID 列表
  2. 坐标计算：球体中心(400,250)，半径 140px；晨昏线为倾斜椭圆弧，使用 SVG path 绘制
  3. 动画曲线：使用 CSS transition 实现淡入淡出（opacity 0→1），关键元素添加 scale 放大效果
  4. 事件绑定：按钮点击事件切换状态，更新元素 display/opacity 属性
  5. 按钮边界检查：步骤 0 时禁用「上一步」，步骤 4 时禁用「下一步」
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀（如 scene1-earth、scene1-morning-line、scene1-point-a、scene1-btn-prev、scene1-btn-next）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
