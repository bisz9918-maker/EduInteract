[图示主题与整合说明]
- 本图示主题：太阳高度角概念——A 点与 C 点的太阳高度对比
- 整合内容：晨昏线上太阳高度为 0°、直射点太阳高度为 90°、太阳光线与地平面的夹角关系
- 教学价值：教师可通过分步对比展示，帮助学生理解太阳高度角的定义——太阳光线与地平面（切线）的夹角。左侧 A 点位于晨昏线，太阳光线与地平面平行（0°）；右侧 C 点位于直射点，太阳光线垂直地平面（90°）。通过视觉对比强化概念记忆。

[分步序列]
步骤 0（初始状态）：
- 显示：标题、左右地球圆弧、A 点、C 点、分隔线
- 隐藏：太阳光线、地平面切线、角度弧线、数值标签、结论框
- 教师讲解：指出 A 点位于晨昏线，C 点位于太阳直射点

步骤 1（点击"下一步"）：
- 显示：左侧 A 点的地平面切线、太阳光线、角度弧线、标签"0°"
- 高亮：A 点区域
- 隐藏：右侧 C 点的相关元素
- 教师讲解：A 点在晨昏线上，太阳光线与地平面平行，太阳高度角为 0°

步骤 2（点击"下一步"）：
- 显示：右侧 C 点的地平面切线、太阳光线、角度弧线、标签"90°"
- 隐藏：左侧 A 点的相关元素（或保留）
- 高亮：C 点区域
- 教师讲解：C 点是太阳直射点，太阳光线垂直地平面，太阳高度角为 90°

步骤 3（点击"下一步"）：
- 显示：左右两侧所有元素、结论框
- 结论框内容："晨昏线上太阳高度=0°；直射点太阳高度=90°"
- 教师讲解：总结太阳高度角的变化规律

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "上一步"按钮：位于 (300,455)，点击返回上一状态
  - "下一步"按钮：位于 (420,455)，点击进入下一状态
  - 步骤指示器：位于 (400,470)，显示当前步骤"步骤 X/3"
- 教师操作流程：
  1. 初始状态展示 A、C 两点位置，引导学生观察
  2. 点击"下一步"展示 A 点太阳高度 0°，讲解晨昏线特点
  3. 点击"下一步"展示 C 点太阳高度 90°，讲解直射点特点
  4. 点击"下一步"展示完整对比和结论，总结规律
  5. 可随时点击"上一步"回退复习

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库）
- 画布尺寸：800×500 px
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |              太阳高度角对比                       | y=35
  +--------------------------------------------------+
  |                                                  |
  |   [左侧 A 点区域]    |    [右侧 C 点区域]         |
  |   地球圆弧+A 点      |    地球圆弧+C 点           | y=80~320
  |   太阳光线→地平面    |    太阳光线↓地平面         |
  |   0°标注            |    90°标注                 |
  |                      |                           |
  |   [结论框 步骤 3 显示]                            | y=340~400
  +--------------------------------------------------+
  |        [◀上一步]  步骤 X/3  [下一步▶]            | y=455~485
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep(0-3) 跟踪当前步骤
  2. 元素分组：将每步显示的元素放入<group>，用 display 控制显隐
  3. 箭头绘制：用 marker-end 或 path 绘制箭头
  4. 角度弧线：用 SVG arc 路径绘制
  5. 按钮事件：绑定 click 事件，更新 currentStep 并刷新显示
  6. 边界处理：步骤 0 时禁用"上一步"，步骤 3 时禁用"下一步"
- ID 命名规范：所有元素 ID 以 scene2- 为前缀
  - scene2-title, scene2-arc-left, scene2-point-a, scene2-tangent-a, scene2-ray-a, scene2-angle-a, scene2-label-a, scene2-value-0
  - scene2-arc-right, scene2-point-c, scene2-tangent-c, scene2-ray-c, scene2-angle-c, scene2-label-c, scene2-value-90
  - scene2-divider, scene2-conclusion-box, scene2-btn-prev, scene2-btn-next, scene2-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
