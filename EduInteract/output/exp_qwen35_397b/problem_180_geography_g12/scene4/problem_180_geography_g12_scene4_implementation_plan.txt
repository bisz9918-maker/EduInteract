[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript。原因：几何图形简单（圆形、线段、弧线），无需复杂库；原生实现轻量且易于状态控制。
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  [地球光照图]           [时间计算步骤区]         |
  |     (左侧400px)          (右侧400px)             |
  |        N                 ┌─────────────┐         |
  |       /|\                │ 时间计算    │         |
  |      / | \               ├─────────────┤         |
  |     B  |  \              │ 步骤1: A点  │         |
  |    /   |   \             │ 6:00       │         |
  |   /    A----C------------│ 步骤2: C点  │         |
  |  /     |                 │ 110°W      │         |
  | /      |                 │ 步骤3: 经度差│         |
  | S      |                 │ 230°       │         |
  |        |                 │ 步骤4: 北京时间│        |
  |                        │ 21:20      │         |
  |                          └─────────────┘         |
  |                                                  |
  |              [◀上一步]  步骤X/4  [下一步▶]       |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量(0-4)跟踪当前步骤，steps 数组存储每步显示的元素ID列表
  2. 坐标计算：地球圆心(150,250)，经线用SVG path弧线绘制，晨昏线为直线段
  3. 动画曲线：元素显示使用淡入效果（opacity 0→1，duration 300ms）
  4. 事件绑定：按钮点击事件绑定到 updateStep() 函数，更新当前状态并显示/隐藏对应元素
  5. 边界处理：步骤0时禁用"上一步"，步骤4时禁用"下一步"
- ID 命名规范：所有交互元素 ID 必须以 scene4- 为前缀
  - scene4-earth（地球轮廓）
  - scene4-equator（赤道线）
  - scene4-terminator（晨昏线）
  - scene4-night（夜半球）
  - scene4-meridian-1/2/3（经线）
  - scene4-point-a/b/c（ABC三点）
  - scene4-label-a/b/c（点标签）
  - scene4-time-a（A点时间标注）
  - scene4-longitude-c（C点经度标注）
  - scene4-step-box-1/2/3/4（步骤框）
  - scene4-btn-prev（上一步按钮）
  - scene4-btn-next（下一步按钮）
  - scene4-step-indicator（步骤指示器）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
