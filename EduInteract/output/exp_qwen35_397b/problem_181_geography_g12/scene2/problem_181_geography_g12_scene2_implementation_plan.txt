[图示主题与整合说明]
- 本图示主题：极地俯视图风带分布与半球季节判断
- 整合的步骤/概念：整合图乙的极地俯视风带图，包括气压带位置、风向箭头、a/b 风带标注、半球判断依据（风向偏转）、季节判断依据（气压带位置移动）
- 教学价值：教师可通过分步演示，先展示基础风带分布框架，再逐步揭示风向偏转特征（判断半球），最后通过气压带位置移动判断季节。学生可直观理解极地俯视图中风向与半球、季节的关系。

[交互方案]

  - 「上一步」按钮：位置 (270,460)，尺寸 80×30px，点击返回上一状态
  - 「下一步」按钮：位置 (450,460)，尺寸 80×30px，点击进入下一状态

- 教师操作流程：

  4. 点击「下一步」显示半球判断框，引导学生根据风向右偏判断为北半球
  5. 点击「下一步」显示季节判断框，讲解气压带北移说明北半球夏季

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript
  - 原因：极地俯视图由同心圆、放射线、曲线箭头等几何元素组成，SVG 原生支持良好；无需复杂动画库
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +----------------------------------------------------------+
  |  [半球判断框]  [季节判断框]                              |
  |                                                          |
  |           0°                                             |
  |            ↑                                             |
  |      270° ←(●)→ 90°    ← 极地俯视图 (圆心 400,250)       |
  |            ↓                                             |
  |           180°                                           |
  |                                                          |
  |                    [气压带图例]                          |
  |                                                          |
  |         [上一步]        步骤 X/5        [下一步]         |
  +----------------------------------------------------------+
  [控件栏在 SVG 内底部 y=440~490]
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量 (0-4)，数组存储每步需显示的元素 ID 列表
  2. 坐标计算：同心圆半径按比例计算 (180px 为赤道，每 30°纬度差 60px 半径)
  3. 风向箭头：使用 SVG <path> 绘制曲线，d 属性定义贝塞尔曲线实现右偏效果
  4. 扇形高亮区：使用 SVG <path> 绘制扇形，fill-opacity="0.2"
  5. 事件绑定：按钮点击事件切换状态，更新元素 display 属性
  6. 步骤指示器：同步更新显示当前步骤编号
- ID 命名规范：所有元素 ID 以 scene2- 为前缀
  - scene2-circle-0 (赤道圈)
  - scene2-circle-30 (30°纬度圈)
  - scene2-circle-60 (60°纬度圈)
  - scene2-line-0、scene2-line-90、scene2-line-180、scene2-line-270 (经线)
  - scene2-pressure-band (气压带)
  - scene2-wind-arrow-1、scene2-wind-arrow-2 (风向箭头)
  - scene2-zone-a、scene2-zone-b (风带区)
  - scene2-label-a、scene2-label-b (风带标签)
  - scene2-box-hemisphere (半球判断框)
  - scene2-box-season (季节判断框)
  - scene2-btn-prev、scene2-btn-next (按钮)
  - scene2-step-indicator (步骤指示器)
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
