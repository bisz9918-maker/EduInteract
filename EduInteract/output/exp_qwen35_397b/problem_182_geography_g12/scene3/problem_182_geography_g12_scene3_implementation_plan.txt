- 步骤 4：点击「下一步」→ 计算框 2 显示 "3330 km ÷ 1110 km/h = 3 小时"，时间数值 "3 小时" 以 #2e7d32 加粗显示

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 (300,460)，点击回退到前一状态
  - 「下一步」按钮：位于 (420,460)，点击前进到下一状态
  - 步骤指示器：位于 (380,460)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始展示 D、E 两点位置，让学生观察两点在同一纬线上
  2. 点击「下一步」高亮路径，强调飞行路线沿纬线
  3. 点击「下一步」显示经度差，引导学生计算经度差
  4. 点击「下一步」显示距离公式和结果，讲解纬线距离需余弦修正
  5. 点击「下一步」显示飞行时间，结合速度计算
  6. 点击「下一步」显示地方时推算，讲解经度差转时间差（15°/小时）

[技术实现]
- JS 库选择及原因：原生 SVG（简单几何图形，经纬网、点、线段、弧线均可用 SVG 原生元素实现，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  [经纬网 500×350]      |  [计算框 1] 距离计算    |
  |  D●────────●E          |  [计算框 2] 飞行时间    |
  |  经度差弧 60°           |  [计算框 3] 地方时      |
  |                          |                         |
  |                          |                         |
  |                          |                         |
  |         [上一步] 步骤 X/5 [下一步]                 |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  - 状态机设计：使用 currentState 变量 (0-5)，数组存储每步需显示的元素 ID 列表
  - 坐标计算：经纬网按等比例映射，经度每 60°=83px，纬度每 30°=58px
  - 动画曲线：路径显示使用 stroke-dasharray 动画，计算框数值使用 opacity 淡入
  - 事件绑定：按钮点击事件切换状态，更新元素 display/opacity 属性
- ID 命名规范：所有交互元素 ID 必须以 scene3- 为前缀（如 scene3-point-d、scene3-path-de、scene3-box1、scene3-btn-prev、scene3-btn-next）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
