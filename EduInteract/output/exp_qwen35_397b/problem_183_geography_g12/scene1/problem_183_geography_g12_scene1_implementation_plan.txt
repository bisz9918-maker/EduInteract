[图示主题与整合说明]

[分步序列]
- 初始状态（步骤 0）：显示太阳、公转轨道、四个地球位置（基础样式）、地轴、赤道、位置标签 A/B/C/D、标题。不显示节气名称和太阳光线。
- 步骤 1：高亮地球 A（轮廓变为#1565c0 加粗），显示太阳光线从太阳指向 A，在地球 A 下方显示倾斜标注"北极倾向太阳"（#ff6f00 小字）
- 步骤 2：在步骤 1 基础上，在地球 A 下方显示节气名称"夏至（6 月 22 日前后）"（#2e7d32 粗体）
- 步骤 3：取消 A 高亮，高亮地球 C，显示太阳光线从太阳指向 C，在地球 C 下方显示倾斜标注"北极远离太阳"
- 步骤 4：在步骤 3 基础上，在地球 C 下方显示节气名称"冬至（12 月 22 日前后）"
- 步骤 5：取消 C 高亮，高亮地球 D，在地球 D 上方显示节气名称"春分（3 月 21 日前后）"
- 步骤 6：取消 D 高亮，高亮地球 B，在地球 B 下方显示节气名称"秋分（9 月 23 日前后）"
- 步骤 7（最终）：取消所有高亮，四个地球恢复基础样式，显示全部四个节气名称，太阳光线隐藏，完整展示二分二至位置

[交互方案]
- 交互类型：分步按钮导航（◀ 上一步 / 下一步 ▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于 SVG 底部左侧 (320, 465)，点击返回上一状态
  - 「下一步 ▶」按钮：位于 SVG 底部右侧 (420, 465)，点击进入下一状态
  - 状态指示器：位于两按钮之间 (380, 470)，显示"步骤 X/7"
- 教师操作流程：
  1. 初始展示公转轨道基础图，让学生观察四个地球位置
  2. 点击「下一步」高亮 A 位置，引导学生观察地轴倾斜方向与太阳的关系
  3. 继续点击显示"夏至"结论，强化认知
  4. 同理演示 C 位置"冬至"
  5. 快速展示 D"春分"、B"秋分"
  6. 最终展示完整图示，总结二分二至位置规律
  7. 可随时点击「上一步」回退复习关键节点

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（圆形、椭圆、线段），无需复杂库；原生 SVG 交互性能好，代码简洁
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +------------------------------------------+
  |           地球公转示意图 (标题)           | y=30
  |                                          |
  |              D 春分                       | y=60-120
  |                ⊕                          |
  |                                          |
  |     A 夏至    太阳    C 冬至              | y=250
  |       ⊕       ☉       ⊕                  |
  |                                          |
  |                ⊕                          |
  |              B 秋分                       | y=380-430
  |                                          |
  |         [◀ 上一步]  [下一步 ▶]            | y=460-490
  +------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用 currentState 变量 (0-7) 跟踪当前步骤，steps 数组定义每步显示的元素 ID 列表
  2. 坐标计算：椭圆上四点坐标预先计算硬编码，地轴倾斜角 23.5° 用 Math.tan 计算端点
  3. 动画曲线：高亮切换用 CSS transition 实现平滑过渡（0.3s ease）
  4. 事件绑定：按钮点击事件绑定到 stepForward() 和 stepBackward() 函数
  5. 元素显隐：用 display="none"/"block" 或 opacity 控制元素显示
- ID 命名规范：所有元素 ID 以 scene1- 为前缀
  - scene1-sun, scene1-orbit, scene1-earth-a, scene1-earth-b, scene1-earth-c, scene1-earth-d
  - scene1-axis-a, scene1-axis-b, scene1-axis-c, scene1-axis-d
  - scene1-label-a, scene1-label-b, scene1-label-c, scene1-label-d
  - scene1-solstice-a, scene1-solstice-c, scene1-equinox-d, scene1-equinox-b
  - scene1-ray-a, scene1-ray-c（太阳光线）
  - scene1-tilt-text-a, scene1-tilt-text-c（倾斜标注）
  - scene1-btn-prev, scene1-btn-next, scene1-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
