[图示主题与整合说明]
- 本图示主题：太阳直射点移动与昼夜长短、正午太阳高度关系
- 整合的步骤/概念：整合了太阳直射点纬度变化、昼夜长短对比、正午太阳高度变化、题目问题答案揭示
- 教学价值：教师可使用此图示逐步演示地球公转过程中太阳直射点的移动规律，推导昼夜长短变化和正午太阳高度变化，帮助学生理解季节变化的成因。通过分步展示，教师可以先让学生观察太阳直射点位置，再引导学生推理昼夜长短和极昼极夜现象，最后得出题目答案。

[分步序列]
- 初始状态（步骤 0）：显示公转轨道椭圆、太阳、四个地球位置（A/B/C/D）、地轴倾斜、直射点标记、纬度标尺及刻度标签。地球用半透明蓝色填充，等待教师触发交互。
- 步骤 1：高亮地球 C（冬至位置），轮廓变为红色#c62828 加粗 3px。在地球 C 旁边显示标注文本"北半球昼最短、夜最长"（位置：(380,240)，右侧偏移）。右侧纬度标尺上 23.5°S 位置高亮显示。
- 步骤 2：保持地球 C 高亮。在地球 C 上显示南极圈内极昼区域（黄色扇形填充）和北极圈内极夜区域（深色扇形填充）。显示标注文本"南极圈内极昼"（位置：(380,260)，右侧偏移）。
- 步骤 3：保持地球 C 高亮和极昼极夜显示。添加正午太阳高度示意线（从太阳到地球 C 的光线）。显示标注文本"南回归线以南正午太阳高度最大"（位置：(380,280)，右侧偏移）。
- 步骤 4：汇总显示答案。在底部答案框（(480,420)-(780,480)）内显示："（1）A 夏至 C 冬至 （2）C C C"。所有高亮和标注保持显示。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 (250,450)，80×30px，点击后退到前一状态
  - 「下一步」按钮：位于 (470,450)，80×30px，点击前进到下一状态
  - 步骤指示文本：位于 (400,455)，显示"步骤 X/4"
- 教师操作流程：
  1. 初始状态展示公转轨道基础图，让学生识别四个位置
  2. 点击「下一步」步骤 1，高亮 C 位置，引导学生观察冬至时太阳直射南回归线，推导北半球昼短夜长
  3. 点击「下一步」步骤 2，展示极昼极夜区域，讲解南极圈内极昼现象
  4. 点击「下一步」步骤 3，展示正午太阳高度，讲解南回归线以南地区正午太阳高度最大
  5. 点击「下一步」步骤 4，汇总显示三个问题的答案，完成题目讲解
  6. 可随时点击「上一步」回退复习某个概念

[技术实现]
- JS 库选择及原因：原生 SVG。理由：本场景为静态几何图形（椭圆、圆形、线段、文本），无需复杂动画或 3D 效果，原生 SVG 轻量且易于精确控制坐标。
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  D(春分)                                         |
  |     o                                            |
  |                                                  |
  |        A(夏至)    太阳    C(冬至)                |
  |     o  <--- 轨道 --->  o                         |
  |                                                  |
  |     B(秋分)                    纬度标尺          |
  |       o                         | 23.5°N         |
  |                                 | 0°             |
  |                                 | 23.5°S         |
  |                                                  |
  |                    [答案框]                      |
  +--------------------------------------------------+
  |  [◀上一步]   步骤 X/4   [下一步▶]                |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-4），每次点击按钮更新状态并重绘相关元素
  2. 坐标计算：地球位置基于椭圆参数方程，地轴倾斜角度固定 23.5°
  3. 高亮效果：通过改变 stroke 颜色和 stroke-width 实现
  4. 事件绑定：按钮点击事件绑定到状态切换函数
  5. 元素显示/隐藏：通过 display 属性或 opacity 控制各步骤特有元素
- ID 命名规范：所有交互元素 ID 必须以 scene2- 为前缀（如 scene2-earth-c、scene2-label-c、scene2-btn-next）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
