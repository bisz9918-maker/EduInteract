[图示主题与整合说明]
- 本图示主题：球面最短航线（大圆航线）方向判断
- 整合内容：A到B的最短路径、大圆航线原理、飞行方向变化
- 教学价值：教师可通过拖拽滑块动态展示从A点飞往B点的最短路径（大圆航线），让学生直观理解为什么最短航线不是沿纬线飞行，而是向高纬度（北极方向）凸出，以及飞行方向如何从东北→正东→东南连续变化

[分步序列]
本场景为连续拖拽交互，无分步导航，状态随滑块位置连续变化：

- 初始状态（滑块0%）：
  - 显示30°N纬线圈、A点、B点、北极点N
  - 大圆航线完整显示（蓝色弧线）
  - 移动点P位于A点(220,250)
  - 方向箭头指向东北方向
  - 方向文字显示"东北"

- 滑块25%位置：
  - P点移动到大圆航线约1/4处(约310,180)
  - 方向箭头指向东北偏东
  - 方向文字显示"东北"

- 滑块50%位置（大圆最高点）：
  - P点移动到大圆顶点(400,130)
  - 方向箭头指向正东（水平向右）
  - 方向文字显示"正东"

- 滑块75%位置：
  - P点移动到大圆航线约3/4处(约490,180)
  - 方向箭头指向东南偏东
  - 方向文字显示"东南"

- 滑块100%位置：
  - P点移动到B点(580,250)
  - 方向箭头指向东南方向
  - 方向文字显示"东南"

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：
  - 滑块轨道：位于SVG底部y=470~485，x=200~600
  - 滑块手柄：蓝色圆形，可左右拖动，范围0%~100%
  - 起点标签"起点A"：滑块左端上方
  - 终点标签"终点B"：滑块右端上方
- 教师操作流程：
  1. 初始状态展示A、B两点和大圆航线
  2. 拖动滑块从0%向100%移动，展示飞机从A飞往B的过程
  3. 在25%处暂停，讲解此时飞行方向为东北
  4. 拖到50%处（最高点），强调此时为正东方向
  5. 继续拖到75%~100%，说明后半程为东南方向
  6. 总结：最短航线向高纬凸出，方向先东北→正东→东南

[技术实现]
- JS库选择：原生SVG + 原生JavaScript
  - 原因：几何图形简单，无需复杂库；原生SVG便于精确控制坐标和动画
- 画布尺寸：800×500px
- 布局草图：
  ```
  [图示区 800×500]
  +------------------------------------------+
  |                                          |
  |              北极点N                      |
  |                ●                         |
  |           ╱         ╲                    |
  |      A ●─╱  大圆航线  ╲─● B              |
  |         ╲   (蓝色)    ╱                  |
  |          ╲           ╱                   |
  |           ╲         ╱                    |
  |            ╲       ╱                     |
  |             ╲     ╱                      |
  |              ╲   ╱                       |
  |           30°N纬线圈(灰色)                |
  |                                          |
  |   起点A [━━━━━━━━●━━━━━━━━] 终点B        |
  |              滑块手柄                     |
  +------------------------------------------+
  ```
- 关键实现要点：
  1. 大圆航线参数方程：使用二次贝塞尔曲线或椭圆弧，控制点为(400,130)
  2. 滑块拖动：监听mousedown/touchstart、mousemove/touchmove、mouseup/touchend
  3. 移动点P坐标计算：根据滑块百分比t(0~1)，用贝塞尔曲线公式计算P点坐标
     - B(t) = (1-t)²×A + 2(1-t)×t×C + t²×B，其中C为控制点(400,130)
  4. 方向箭头：计算大圆曲线在P点的切线方向（对t求导）
  5. 方向文字判断：
     - t < 0.4：显示"东北"
     - 0.4 ≤ t ≤ 0.6：显示"正东"
     - t > 0.6：显示"东南"
- ID命名规范：
  - scene4-circle-30N（纬线圈）
  - scene4-point-A（A点）
  - scene4-point-B（B点）
  - scene4-point-N（北极点）
  - scene4-path-greatcircle（大圆航线）
  - scene4-point-moving（移动点P）
  - scene4-arrow-direction（方向箭头）
  - scene4-text-direction（方向文字）
  - scene4-slider-track（滑块轨道）
  - scene4-slider-handle（滑块手柄）
- IIFE隔离：所有JS代码包在(function() { ... })()中，避免全局变量污染
