[图示主题与整合说明]
- 本图示主题：太阳直射点的回归运动
- 整合的内容：太阳直射点在南北回归线之间的周年移动、二分二至日的位置对应关系
- 教学价值：教师通过拖动滑块，可连续演示太阳直射点随地球公转的周年移动轨迹，直观展示"回归"含义——直射点在南北回归线之间往返移动。配合日期和纬度显示，帮助学生理解二分二至日的天文意义及四季形成的根本原因。

[分步序列]
本场景为连续拖拽滑块交互，无分步导航。状态由滑块位置(0-100%)连续决定：

- 初始状态（滑块0%）：春分位置
  - 直射点位于赤道(520,250)
  - 日期显示"春分 3.21"
  - 纬度显示"直射纬度：0°"
  - 太阳光线水平射向赤道

- 滑块25%：夏至位置
  - 直射点位于北回归线(520,198)
  - 日期显示"夏至 6.22"
  - 纬度显示"直射纬度：23°26'N"
  - 太阳光线射向北回归线

- 滑块50%：秋分位置
  - 直射点位于赤道(520,250)
  - 日期显示"秋分 9.23"
  - 纬度显示"直射纬度：0°"

- 滑块75%：冬至位置
  - 直射点位于南回归线(520,302)
  - 日期显示"冬至 12.22"
  - 纬度显示"直射纬度：23°26'S"

- 滑块100%：回到春分（完成周年循环）
  - 直射点回到赤道(520,250)
  - 日期显示"春分 3.21"
  - 纬度显示"直射纬度：0°"

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：
  - 滑块轨道：位于SVG底部y=460-475，x=100-700，灰色背景
  - 滑块手柄：红色圆形，可沿轨道左右拖动，x范围100-700
  - 刻度标记：轨道下方标注四个关键位置（春分、夏至、秋分、冬至）
- 教师操作流程：
  1. 初始展示春分状态，讲解直射点在赤道
  2. 缓慢向右拖动滑块，观察直射点向北移动
  3. 停在夏至位置(25%)，讲解北半球夏季成因
  4. 继续拖动至秋分(50%)，讲解直射点返回赤道
  5. 拖动至冬至(75%)，讲解南半球夏季/北半球冬季
  6. 拖回春分(100%/0%)，完成周年循环，强调"回归"含义

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（圆形、直线、箭头），无需复杂库；拖拽交互用原生事件即可实现
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [800 × 500 画布]
  +--------------------------------------------------+
  |              标题：太阳直射点的回归运动           | y=25
  |                                                  |
  |   [日期显示]                      [纬度显示]      | y=50-90
  |                                                  |
  |                    地球                           |
  |                   /    \                          |
  |        北回归线 ---●------  23°26'N               | y=198
  |                  /   \                            |
  |        赤道  ----●------  0°                      | y=250
  |                  \   /                            |
  |        南回归线 ---●------  23°26'S               | y=302
  |                   \__/                            |
  |                    ↑                              |
  |                 直射点                            |
  |                                                  |
  |                                                  |
  |   春分    夏至    秋分    冬至                    | y=490
  |   [═══════════════════════════════════]          | y=460-475 滑块
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：滑块位置 percentage (0-100) → 计算直射点y坐标
     - 使用正弦函数模拟回归运动：y = 250 + 52 * sin(percentage * 2π - π/2)
     - 或分段线性：0-25% 从0°到23°26'N，25-50% 从23°26'N到0°，以此类推
  2. 日期映射：根据 percentage 确定当前节气
     - 0%: 春分, 25%: 夏至, 50%: 秋分, 75%: 冬至, 100%: 春分
     - 中间值用线性插值估算日期
  3. 纬度计算：直射点纬度 = 23.43 * sin(percentage * 2π - π/2)
  4. 拖拽事件：mousedown/mousemove/mouseup 或 touch 事件
  5. 动画平滑：拖动时实时更新，无需额外动画
- ID 命名规范：所有元素 ID 以 scene2- 为前缀
  - scene2-earth, scene2-equator, scene2-tropic-n, scene2-tropic-s
  - scene2-sun-point, scene2-sun-ray
  - scene2-date-box, scene2-latitude-box
  - scene2-slider-track, scene2-slider-handle
  - scene2-label-n, scene2-label-0, scene2-label-s
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
