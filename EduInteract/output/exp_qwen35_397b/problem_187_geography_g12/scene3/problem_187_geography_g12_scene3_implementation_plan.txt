[图示主题与整合说明]
- 本图示主题：四地经度计算与世界时对照
- 整合的步骤/概念：地方时概念 → 时差计算 → 经度换算 → 四地经度位置标定
- 教学价值：教师可逐步演示如何从世界时数据推算各地经度，帮助学生理解"当地正午地方时为 12 时"这一核心概念，以及时差与经度的换算关系（1 小时=15°）。通过分步展示，学生能清晰看到计算逻辑链条。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - "上一步"按钮：位于 (280,460)，点击后回退到前一状态，初始禁用
  - "下一步"按钮：位于 (420,460)，点击后进入下一状态，最终步骤禁用
- 教师操作流程：
  1. 初始展示世界时数据，提问"如何从世界时推算经度？"
  2. 点击"下一步"展示计算表格框架，引出地方时概念
  3. 逐步点击"下一步"，依次展示 A、B、C、D 四地的时差计算过程
  4. 每步配合讲解：当地正午地方时恒为 12 时 → 时差=12-世界时 → 经度=时差×15°
  5. 最终在经度图上标定四地位置，直观展示东西分布
  6. 可点击"上一步"回退复习关键步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何元素简单（线段、圆、矩形、文本），无需复杂库；原生实现轻量且易于多场景合并
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [800×500 画布]
  +--------------------------------------------------+
  |           四地经度计算与世界时对照               | y=25
  +--------------------------------------------------+
  |  世界时轴：0 时────A───B───C───────────D──24 时   | y=52-95
  |         (0)   (4)  (8) (12)        (24)          |
  +--------------------------------------------------+
  |  ┌──────────── 时差与经度计算 ────────────────┐  | y=120-235
  |  │ 地点 | 世界时 | 地方时 | 时差 | 经度      │  |
  |  │  A   |  4 时  |  12 时  | +8h  | 120°E   │  |
  |  │  B   |  8 时  |  12 时  | +4h  | 60°E    │  |
  |  │  C   |  12 时 |  12 时  | 0h   | 0°      │  |
  |  │  D   |  24 时 |  12 时  | -12h | 180°    │  |
  |  └────────────────────────────────────────────┘  |
  |  ┌─────────────────────┐                         | y=260-300
  |  │ 经度=时差×15°/小时  │                         |
  |  └─────────────────────┘                         |
  +--------------------------------------------------+
  |  经度轴：180°W────D────90°W───C───90°E──A──180°E | y=295-345
  |                    (0°)      (60°E)(120°E)       |
  +--------------------------------------------------+
  |              [◀ 上一步]  [下一步 ▶]              | y=460-495
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep(0-6) 跟踪当前步骤，数组 steps[] 定义每步显示的元素 ID 列表
  2. 元素分组：按步骤将 SVG 元素分组（<g id="scene3-step0">等），通过 display 属性控制显示/隐藏
  3. 高亮效果：使用 CSS class .highlight 实现填充色/描边加粗变化
  4. 按钮状态：禁用按钮添加 opacity:0.5 和 pointer-events:none
  5. 坐标计算：所有坐标硬编码（已在布局表中精确计算），避免运行时计算误差
- ID 命名规范：
  - 所有元素 ID 以 "scene3-" 为前缀
  - 示例：scene3-title, scene3-time-axis, scene3-point-a, scene3-table-row-a, scene3-lon-point-a, scene3-btn-prev, scene3-btn-next
- IIFE 隔离：
