[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（直线、圆圈、文字），无需复杂库；原生 SVG 交互性能好，代码简洁
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [800 × 500 画布]
  +--------------------------------------------------+
  |  23°26′N                    北回归线             |
  |      (2) 夏至                                    |
  |       6 月 22 日                                  |
  |      /    \                                      |
  |     /      \                                     |
  | (1)        (3) 秋分          赤道                |
  |  春分       9 月 23 日                            |
  |  3 月 21 日    \                                  |
  |              \                                   |
  |               (4) 冬至                           |
  |                12 月 22 日       南回归线        |
  |  23°26′S                                         |
  |                                                  |
  |          [◀上一步]  步骤 X/5  [下一步▶]          |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量（0-5），每个步骤对应一个状态对象，定义该步骤应显示的元素 ID 列表
  2. 元素分组：将 SVG 元素按功能分组（纬线组、轨迹组、点组、标签组），便于按步骤控制显示/隐藏
  3. 高亮逻辑：当前点使用#1565c0 填充，已标注点使用#2e7d32 填充，未激活点使用白色填充 + 黑色描边
  4. 动画效果：步骤 5 使用 CSS animation 实现轨迹线脉冲效果（opacity 从 0.5 到 1 循环）
  5. 按钮状态：步骤 0 时禁用「上一步」，步骤 5 时禁用「下一步」，使用 opacity 和 pointer-events 控制
  6. 事件绑定：使用 addEventListener 绑定点击事件，避免内联 onclick
- ID 命名规范：
  - 所有元素 ID 以 scene1- 为前缀
  - 纬线：scene1-latitude-tropic-n, scene1-latitude-equator, scene1-latitude-tropic-s
  - 纬线标签：scene1-label-tropic-n, scene1-label-equator, scene1-label-tropic-s
  - 纬度标注：scene1-latval-n, scene1-latval-0, scene1-latval-s
  - 轨迹线：scene1-path-1-2, scene1-path-2-3, scene1-path-3-4, scene1-path-4-5
  - 点：scene1-point-1, scene1-point-2, scene1-point-3, scene1-point-4
  - 点标签：scene1-pointlabel-1, scene1-pointlabel-2, scene1-pointlabel-3, scene1-pointlabel-4
  - 节气标签：scene1-season-1, scene1-season-2, scene1-season-3, scene1-season-4
  - 日期标签：scene1-date-1, scene1-date-2, scene1-date-3, scene1-date-4
  - 按钮：scene1-btn-prev, scene1-btn-next
  - 步骤指示：scene1-step-indicator
- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染
- 响应式考虑：SVG 使用 viewBox="0 0 800 500" 保持比例，容器使用 max-width:100% 适配不同屏幕
