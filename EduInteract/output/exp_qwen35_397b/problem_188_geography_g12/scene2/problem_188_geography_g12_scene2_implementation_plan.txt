[图示主题与整合说明]
- 本图示主题：太阳直射点位置与昼夜长短、正午太阳高度的关系
- 整合的内容：整合了不同直射点位置时的昼夜分布、正午太阳高度变化规律、极昼极夜范围
- 教学价值：教师通过拖动滑块改变太阳直射点纬度，学生可实时观察昼夜长短和正午太阳高度的联动变化，直观理解太阳直射点回归运动对地球各地天文现象的影响，培养空间思维和动态分析能力

[分步序列]
本场景为连续拖拽滑块交互，无分步导航。状态由滑块位置连续决定：

- 初始状态（滑块在赤道0°）：
  - 直射点纬度：0°
  - 节气：春分/秋分
  - 晨昏线：通过南北极的直线（经线圈）
  - 全球昼夜平分（各12小时）
  - 正午太阳高度：赤道90°，向两极递减
  - 无极昼极夜现象

- 滑块拖至北回归线（+23°26′）：
  - 直射点纬度：23°26′N
  - 节气：夏至
  - 晨昏线：与经线成23°26′夹角
  - 北半球昼长夜短，白城昼长约15小时
  - 北极圈内极昼，南极圈内极夜
  - 正午太阳高度：北回归线90°，向两侧递减

- 滑块拖至南回归线（-23°26′）：
  - 直射点纬度：23°26′S
  - 节气：冬至
  - 晨昏线：与经线成23°26′夹角（反向）
  - 北半球昼短夜长，白城昼长约9小时
  - 北极圈内极夜，南极圈内极昼
  - 正午太阳高度：南回归线90°，向两侧递减

- 滑块在任意中间位置：
  - 实时计算并更新所有视觉元素
  - 直射点纬度 = 滑块位置对应的纬度值
  - 晨昏线倾斜角 = 直射点纬度
  - 白城昼长 = 根据直射点纬度计算
  - 正午太阳高度曲线实时更新
  - 极昼极夜范围 = 90°-|直射点纬度| 至极点

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：
  - 滑块手柄（scene2-slider-handle）：圆形，可上下拖拽，范围y=80至y=350
  - 滑块轨道（scene2-slider-track）：竖直引导线，限定拖拽范围
- 教师操作流程：
  1. 初始状态展示春分/秋分时的全球昼夜分布
  2. 缓慢向上拖动滑块，观察太阳直射点北移时的变化：
     - 北半球昼渐长、夜渐短
     - 北极地区出现极昼并扩大
     - 正午太阳高度最大值位置北移
  3. 拖至北回归线（夏至），讲解夏至日特征
  4. 向下拖动经过赤道至南回归线，对比冬至日特征
  5. 在白城昼长比例条处停顿，讲解纬度与昼夜长短的关系

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单，无需复杂库；拖拽交互用原生事件即可实现；实时计算和更新用requestAnimationFrame保证流畅
- 画布尺寸：800×500 px
- 布局草图：
  ```
  +----------------------------------------------------------+
  | [滑块区]    [地球昼夜示意图]        [正午太阳高度曲线]    |
  |   |           (O)                    /|\                 |
  |   |          /   \                   / | \               |
  |   |         | 晨  |                /  |  \              |
  |   |          \   /                   \ | /               |
  |   |           (O)                     \|/                 |
  |                                                          |
  | [直射纬度：0°]        [节气：春分]                        |
  +----------------------------------------------------------+
  | [昼夜比例条] ████████░░░░░░░░ 昼长：12h  夜长：12h        |
  | [极昼范围：无]  [极夜范围：无]                            |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：单一状态对象存储当前直射点纬度（-23.43至+23.43）
  2. 坐标计算：
     - 滑块y坐标与纬度的线性映射：lat = (215 - y) * (23.43/135)
     - 晨昏线倾斜角 = 直射点纬度（弧度制）
     - 白城昼长 = 12 + (2/15) * arcsin(tan(45.6°) * tan(lat)) * (180/π) 小时
  3. 动画曲线：拖拽时实时更新，无需额外动画
  4. 事件绑定：
     - mousedown/touchstart：开始拖拽
     - mousemove/touchmove：更新滑块位置和所有关联元素
     - mouseup/touchend：结束拖拽
  5. 极昼极夜范围计算：
     - 极昼纬度下限 = 90° - |lat|（与直射点同半球）
     - 极夜纬度下限 = 90° - |lat|（与直射点异半球）
  6. 正午太阳高度曲线计算：
     - H(φ) = 90° - |φ - lat|，其中φ为各地纬度，lat为直射点纬度
- ID 命名规范：所有交互元素 ID 以 scene2- 为前缀
  - scene2-slider-handle, scene2-slider-track
  - scene2-earth-circle, scene2-terminator, scene2-day-hemisphere, scene2-night-hemisphere
  - scene2-solar-zenith-point, scene2-polar-day, scene2-polar-night
  - scene2-season-label, scene2-latitude-display
  - scene2-daylight-bar, scene2-nighttime-bar, scene2-day-length-label, scene2-night-length-label
  - scene2-polar-day-label, scene2-polar-night-label
  - scene2-noon-height-chart, scene2-baicheng-marker
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
