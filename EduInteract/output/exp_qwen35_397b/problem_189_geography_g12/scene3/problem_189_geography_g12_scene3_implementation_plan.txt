状态 2（西半球全部黑夜）：

- 北京时间显示：3 月 21 日 10:40

[交互方案]
- 交互类型：多状态切换（3 个按钮）
- 控件说明：
  - 按钮 1「春分/秋分」：显示标准昼夜平分状态，晨昏线过两极
  - 按钮 2「东半球黑夜」：展示东半球全部处于夜半球的条件
  - 按钮 3「西半球黑夜」：展示西半球全部处于夜半球的条件
- 教师操作流程：
  1. 点击「春分/秋分」讲解全球昼夜平分的基本概念
  2. 点击「东半球黑夜」引导学生观察 20°W 作为晨昏线时的昼夜分布，计算北京时间
  3. 点击「西半球黑夜」对比分析 160°E 作为晨昏线时的情况
  4. 配合右侧时间面板，讲解地方时计算方法

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（圆形、直线、弧线），无需复杂库；状态切换逻辑简单，原生 JS 足够
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |    [东半球○]              [西半球○]    [信息面板]|
  |       N                      N                   |
  |    20°W  0°              180°  160°E             |
  |       S                      S                   |
  |   "东半球"              "西半球"                  |
  |                                                  |
  |         [状态 1]  [状态 2]  [状态 3]             |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用 currentState 变量(0/1/2) 跟踪当前状态，点击按钮时更新并重绘
  2. 晨昏线绘制：根据状态计算晨昏线的 x 坐标（状态 0:x=200 或 600，状态 1:x=120，状态 2:x=680）
  3. 昼夜区域填充：使用 SVG clipPath 或 path 元素，根据晨昏线位置裁剪填充区域
  4. 事件绑定：三个按钮分别绑定 click 事件，调用 updateState(newState) 函数
  5. 时间计算：根据晨昏线经度计算北京时间（120°E 地方时）
- ID 命名规范：所有元素 ID 以 scene3- 为前缀
  - scene3-east-hemisphere, scene3-west-hemisphere
  - scene3-state-btn-0, scene3-state-btn-1, scene3-state-btn-2
  - scene3-day-night-overlay, scene3-terminator-line
  - scene3-time-display
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
