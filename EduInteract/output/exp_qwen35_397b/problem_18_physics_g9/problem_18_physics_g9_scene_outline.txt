    **题目原文：**

    如图所示，浸在水中的 A 物体的质量为 3kg，B 物体的质量为 2kg，且整体处于静止状态，弹簧测力计自身重力不计．下列说法正确的是（  ）

    A. 弹簧测力计的示数为 19.6N

    B. 物体 A 浸在水中的体积为 500cm³

    C. 物体 A 处于非平衡状态

    D. 物体 B 受到的重力和 B 对绳的拉力是一对平衡力

    **题目分析：**

    本题综合考查定滑轮特点、二力平衡、浮力计算等知识点。系统静止说明各物体均处于平衡状态。

    **整体讲解思路：**

    1. 首先分析装置结构：定滑轮改变力的方向，不改变力的大小
    2. 对物体 B 受力分析：静止→重力与绳拉力平衡→求出绳的拉力
    3. 对物体 A 受力分析：重力向下、浮力向上、弹簧拉力向上→三力平衡
    4. 根据弹簧测力计示数等于绳的拉力，计算 A 受到的浮力
    5. 由阿基米德原理求出 A 排开水的体积
    6. 逐一判断选项正误

    **图示规划说明：**

    - SCENE_1：整体装置受力分析图，分步展示 B 和 A 的受力情况
    - SCENE_2：物体 A 的浮力与排水体积关系图，聚焦浮力计算过程

    **SCENE_1 教学说明：**

    **引导学生观察：**

    1. 首先让学生识别装置类型：这是一个定滑轮系统，定滑轮的特点是只改变力的方向，不改变力的大小

    2. 从简单入手：先分析物体 B 的受力
       - B 静止，处于平衡状态
       - B 受两个力：重力 G_B 向下，绳的拉力 T 向上
       - 根据二力平衡：T = G_B = m_B × g = 2kg × 9.8N/kg = 19.6N

    3. 弹簧测力计的示数等于绳的拉力：F = T = 19.6N

    4. 再分析物体 A 的受力
       - A 静止，处于平衡状态
       - A 受三个力：重力 G_A 向下，浮力 F_浮向上，弹簧拉力 F 向上
       - 根据三力平衡：G_A = F_浮 + F

    5. 计算 A 的重力：G_A = m_A × g = 3kg × 9.8N/kg = 29.4N

    6. 求出浮力：F_浮 = G_A - F = 29.4N - 19.6N = 9.8N

    **关键公式：**

    - 重力公式：G = mg
    - 二力平衡条件：合力为零
    - 三力平衡：G_A = F_浮 + F

    **SCENE_2 教学说明：**

    **引导学生观察：**

    1. 回顾已求出的浮力：F_浮 = 9.8N

    2. 引入阿基米德原理：浸在液体中的物体受到的浮力等于它排开液体的重力
       - 公式：F_浮 = ρ_液 × g × V_排

    3. 代入已知量求解 V_排：
       - ρ_水 = 1000kg/m³
       - g = 9.8N/kg
       - F_浮 = 9.8N

    4. 计算过程：
       - V_排 = F_浮 / (ρ_水 × g)
       - V_排 = 9.8N / (1000kg/m³ × 9.8N/kg)
       - V_排 = 0.001m³ = 1000cm³

    5. 对比选项 B 的 500cm³，明显错误

    **关键公式：**

    - 阿基米德原理：F_浮 = ρ_液 × g × V_排
    - 体积换算：1m³ = 10⁶cm³

    **完整解答与课堂讲解建议：**

    **逐项判断：**

    **A. 弹簧测力计的示数为 19.6N** ✓ 正确
    - 绳的拉力 T = G_B = 2kg × 9.8N/kg = 19.6N
    - 弹簧测力计示数等于绳的拉力，故为 19.6N

    **B. 物体 A 浸在水中的体积为 500cm³** ✗ 错误
    - 由 F_浮 = G_A - F = 29.4N - 19.6N = 9.8N
    - V_排 = F_浮 / (ρ_水 × g) = 9.8N / (1000kg/m³ × 9.8N/kg) = 0.001m³ = 1000cm³
    - 选项给出的 500cm³ 错误

    **C. 物体 A 处于非平衡状态** ✗ 错误
    - 题目明确说明"整体处于静止状态"
    - 静止即平衡状态，故 A 处于平衡状态

    **D. 物体 B 受到的重力和 B 对绳的拉力是一对平衡力** ✗ 错误
    - 平衡力必须作用在同一个物体上
    - B 的重力作用在 B 上，B 对绳的拉力作用在绳上
    - 这两个力作用在不同物体上，不是平衡力
    - B 的平衡力是：B 的重力（向下）和绳对 B 的拉力（向上）

    **正确答案：A**

    **课堂讲解建议：**

    1. 先用 SCENE_1 展示整体受力分析，让学生理解定滑轮系统的力传递关系

    2. 强调"静止=平衡状态"这一关键判断

    3. 用 SCENE_2 深入讲解浮力计算，强化阿基米德原理的应用

    4. 对于选项 D，要特别强调平衡力的条件：同体、等大、反向、共线

    5. 总结本题考点：定滑轮、二力平衡、三力平衡、阿基米德原理、平衡力的判断条件
