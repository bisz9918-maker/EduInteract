[分步序列]
- 初始状态（步骤 0）：显示完整装置结构（天花板、滑轮、绳子、弹簧测力计、物体 A、物体 B、盛水容器、水面），所有力向量和标签隐藏，底部方程区显示"初始状态：装置静止"
- 步骤 1：点击「下一步」→ 显示物体 B 的重力向量 G_B（红色向下箭头）及标签"G_B=19.6N"，底部方程区显示"G_B = m_B × g = 2kg × 9.8N/kg = 19.6N"
- 步骤 2：点击「下一步」→ 显示物体 B 的绳拉力向量 T（蓝色向上箭头，与 G_B 等长）及标签"T=19.6N"，G_B 和 T 高亮显示，底部方程区显示"B 静止 → T = G_B = 19.6N（二力平衡）"
- 步骤 3：点击「下一步」→ 显示弹簧测力计示数标签"F=19.6N"，弹簧测力计高亮，底部方程区显示"弹簧测力计示数 F = T = 19.6N"
- 步骤 4：点击「下一步」→ 显示物体 A 的重力向量 G_A（红色向下箭头，比 G_B 稍长）及标签"G_A=29.4N"，底部方程区显示"G_A = m_A × g = 3kg × 9.8N/kg = 29.4N"
- 步骤 5：点击「下一步」→ 显示物体 A 的浮力向量 F_浮（绿色向上箭头）及标签"F_浮=9.8N"，底部方程区显示"F_浮 = G_A - F = 29.4N - 19.6N = 9.8N"
- 步骤 6：点击「下一步」→ 显示物体 A 的弹簧拉力向量 F（蓝色向上箭头）及标签"F=19.6N"，A 的三个力同时高亮，底部方程区显示"A 静止 → G_A = F_浮 + F（三力平衡）"
- 最终步骤（步骤 7）：所有力向量和标签完整显示，底部方程区显示完整结论："T = G_B = 19.6N；G_A = F_浮 + F = 29.4N；弹簧测力计示数 = 19.6N"

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于底部左侧 (320,485)，点击后回退到前一状态
  - 「下一步」按钮：位于底部右侧 (420,485)，点击后进入下一状态
  - 步骤指示器：位于两按钮之间 (380,485)，显示"步骤 X/7"
- 教师操作流程：
  1. 初始状态展示装置结构，让学生观察整体布局
  2. 点击「下一步」逐步展示 B 的受力，讲解二力平衡
  3. 继续点击展示弹簧测力计示数，建立 T 与 F 的等量关系
  4. 展示 A 的受力，讲解三力平衡
  5. 最后总结完整平衡方程，验证选项

[技术实现]
- JS 库选择：原生 SVG（简单几何图形和箭头绘制，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  ┌────────────────────────────────────────┐
  │  天花板支架 (y=30)                     │
  │     ┌─────┐                            │
  │     │滑轮 │ (y=80)                     │
  │     └─────┘                            │
  │    ╱       ╲                           │
  │   B         弹簧                       │
  │  [□]       ~~~~                        │
  │   ↓G_B      [||]                       │
  │   ↑T         |                         │
  │              ↓                         │
  │            ┌────┐                      │
  │            │ A  │←── 水面 (y=350)      │
  │            └────┘   ~~~~~~~            │
  │             ↓G_A   容器                │
  │             ↑F_浮                       │
  │             ↑F                         │
  │                                        │
  │  [平衡方程显示区 y=465]                │
  │  [◀上一步]  步骤 X/7  [下一步▶] y=485  │
  └────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-7），数组存储每个状态的配置
  2. 每个状态定义：visibleElements 数组控制哪些元素显示/隐藏
  3. 箭头绘制：使用 SVG marker-end 定义箭头样式，线段 + marker 组合
  4. 动画效果：使用 CSS transition 实现淡入淡出（opacity 变化）
  5. 事件绑定：按钮点击事件切换状态，更新 visibleElements 和方程文本
  6. 边界检查：第一步禁用「上一步」，最后一步禁用「下一步」
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀
  - scene1-ceiling, scene1-pulley, scene1-rope-left, scene1-rope-right
  - scene1-object-b, scene1-label-b, scene1-arrow-gb, scene1-label-gb
  - scene1-arrow-tb, scene1-label-tb, scene1-spring-scale, scene1-label-f-spring
  - scene1-object-a, scene1-label-a, scene1-container, scene1-water-line
  - scene1-arrow-ga, scene1-label-ga, scene1-arrow-float, scene1-label-float
  - scene1-arrow-fa, scene1-label-fa, scene1-equation-box
  - scene1-btn-prev, scene1-btn-next, scene1-step-indicator
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
