[图示主题与整合说明]
- 本图示主题：四棱锥 P-ABCD 基础结构及命题①的线面平行分析
- 整合的内容：四棱锥完整结构展示、平面 PAB 高亮、直线 DC 高亮、DC 与 AB 延长线交点 E、线面位置关系分析
- 教学价值：教师可通过分步展示，引导学生理解"平面 PAB 内不存在直线与 DC 平行"这一命题。从基础结构→平面高亮→直线高亮→交点呈现→结论得出，逐步建立空间想象，理解线面相交则平面内不可能存在与该线平行的直线这一几何原理。

[标签冲突检查]
所有标签坐标及间距检查：
- 标签"P"：(400, 65)
- 标签"A"：(180, 350)
- 标签"B"：(350, 425)
- 标签"C"：(615, 380)
- 标签"D"：(450, 305)
- 标签"E"：(765, 460)
- 结论文本：(50, 20) 起始，宽约 700px，高约 30px

间距检查：
- P(400,65) 与 A(180,350)：距离≈292px → 无冲突
- P(400,65) 与 D(450,305)：距离≈245px → 无冲突
- A(180,350) 与 B(350,425)：距离≈186px → 无冲突
- B(350,425) 与 C(615,380)：距离≈269px → 无冲突
- C(615,380) 与 D(450,305)：距离≈181px → 无冲突
- D(450,305) 与 E(765,460)：距离≈350px → 无冲突
- 结论文本 (50,20)-(750,50) 与 P(400,65)：垂直间距≈15px → 需调整结论文本 y 坐标至 y=10

解决方案：结论文本 y 坐标调整为 10，确保与标签 P 有足够间距（≥20px）

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 内底部左侧 (x=350, y=465)，宽 80px，高 30px
  - 「下一步」按钮：位于 SVG 内底部右侧 (x=450, y=465)，宽 80px，高 30px
  - 步骤指示器：位于两按钮之间，显示"步骤 X/4"
- 教师操作流程：
  1. 初始展示四棱锥基础结构，讲解四棱锥 P-ABCD 的构成
  2. 点击「下一步」高亮平面 PAB，引导学生关注该平面
  3. 点击「下一步」高亮直线 DC，突出 DC 与平面 PAB 的关系
  4. 点击「下一步」显示延长线交点 E，直观展示 DC 与平面 PAB 相交
  5. 点击「下一步」显示结论，完成命题①的证明
  6. 可随时点击「上一步」回退复习关键步骤

[技术实现]
- JS 库选择：原生 SVG（简单几何图形首选，无需额外库）
- 画布尺寸：800×500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +------------------------------------------+
  | [结论文本区 y=10~40]                     |
  |                                          |
  |              P                           |
  |             /|\                          |
  |            / | \                         |
  |           /  |  \                        |
  |          A---B---C                       |
  |           \  |  /                        |
  |            \ | /                         |
  |             \|/                          |
  |              D----E (延长线交点)         |
  |                                          |
  | [控件栏 y=450~490]                       |
  |      [◀上一步]  步骤 X/4  [下一步▶]      |
  +------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-4），每次点击按钮更新状态并重绘
  2. 坐标计算：所有顶点坐标硬编码，延长线交点 E 通过直线方程计算或硬编码
  3. 动画曲线：元素显示/隐藏使用 CSS transition，opacity 从 0 到 1，duration=300ms
  4. 事件绑定：按钮点击事件绑定到 updateState() 函数，更新 currentState 并调用 render()
  5. 虚线实现：SVG stroke-dasharray="5,5"
  6. 半透明填充：SVG polygon fill-opacity="0.2"
- ID 命名规范：
  - 场景容器：scene1-container
  - 棱线：scene1-edge-pa, scene1-edge-pb, scene1-edge-pc, scene1-edge-pd, scene1-edge-ab, scene1-edge-bc, scene1-edge-cd, scene1-edge-da
  - 平面填充：scene1-plane-pab
  - 延长线：scene1-ext-ab, scene1-ext-dc
  - 交点：scene1-point-e
  - 标签：scene1-label-p, scene1-label-a, scene1-label-b, scene1-label-c, scene1-label-d, scene1-label-e
  - 结论文本：scene1-conclusion
  - 按钮：scene1-btn-prev, scene1-btn-next, scene1-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
