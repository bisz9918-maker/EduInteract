- 本图示主题：圆的切线、割线与角平分线的角度关系推导
- 整合内容：整合了基础图形展示、弦切角定理应用、角平分线标注、角度推导全过程

[分步序列]
- 初始状态（步骤 0）：显示完整基础图形
  - 圆、所有点 P/A/B/C/D/E、切线 PE、割线 PBA、弦 AE/BE、角平分线 PCD（蓝色）
  - 标注∠AEB=40°（红色弧线+文字）
  - 所有点标签显示
  
- 步骤 1：弦切角定理展示
  - 高亮∠PEB（弦切角）和∠EAB（圆周角），用绿色弧线#2e7d32 标注
  - 添加标签"α"在两个角旁，表示∠PEB=∠EAB=α
  - 其他元素保持显示
  
- 步骤 2：角平分线性质展示
  - 在 P 点处用相同颜色小弧线标注∠EPC 和∠APC，表示相等
  - 添加标签"∠1"和"∠2"或相同符号标记等角
  - 角平分线 PCD 保持蓝色高亮
  
- 步骤 3：角度推导与答案
  - 在△PCE 区域显示推导过程：
    - ∠PCE = 180° - ∠EPC - ∠PEC
    - ∠PEC = ∠PEB + ∠BEC = α + 40°
    - 最终显示：∠PCE = 70°（绿色大字）
  - 用绿色弧线高亮∠PCE

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 内底部左侧 (x=320, y=455)，灰色背景，点击回退到前一状态
  - 「下一步」按钮：位于 SVG 内底部右侧 (x=460, y=455)，蓝色背景，点击进入下一状态
  - 状态指示器：位于中间 (x=400, y=460)，显示"步骤 X/4"
- 教师操作流程：
  1. 初始展示完整图形，让学生观察已知条件
  2. 点击「下一步」高亮弦切角与圆周角，讲解弦切角定理
  3. 点击「下一步」展示角平分线等角关系
  4. 点击「下一步」展示完整推导过程和最终答案 70°
  5. 可随时点击「上一步」回退复习

[技术实现]
- JS 库选择：原生 SVG（几何图形精确、标签定位清晰、无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +------------------------------------------+
  |           P                              |
  |          / \                             |
  |         /   \ B                          |
  |        /     \                           |
  |       E-------C----A    (圆居中偏下)     |
  |        \     / \                         |
  |         \   /   \                        |
  |          \ /     \                       |
  |           D       \                      |
  |            \_______/ (圆)                |
  |                                          |
  |        [◀上一步] 步骤 1/4 [下一步▶]      |
  +------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用 currentState 变量(0-3)跟踪当前步骤，steps 数组存储每步的显示配置
  2. 坐标计算：所有点坐标硬编码，确保与布局表一致；角度弧线用 SVG path 绘制
  3. 动画曲线：元素淡入淡出用 CSS transition opacity 0.3s
  4. 事件绑定：按钮点击事件切换状态，更新 DOM 元素显示/隐藏
  5. 弦切角定理可视化：∠PEB 和∠EAB 用相同颜色弧线和相同标签"α"
- ID 命名规范：所有元素 ID 以 scene1- 为前缀
  - scene1-circle, scene1-point-p, scene1-point-e, scene1-point-a, scene1-point-b, scene1-point-c, scene1-point-d
  - scene1-line-pe, scene1-line-pba, scene1-line-ae, scene1-line-be, scene1-line-pcd
  - scene1-angle-aeb, scene1-angle-peb, scene1-angle-eab, scene1-angle-epc, scene1-angle-apc
  - scene1-label-p, scene1-label-e, scene1-label-a, scene1-label-b, scene1-label-c, scene1-label-d
  - scene1-btn-prev, scene1-btn-next, scene1-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
