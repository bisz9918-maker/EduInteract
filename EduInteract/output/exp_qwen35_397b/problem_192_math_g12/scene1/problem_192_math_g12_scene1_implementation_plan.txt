[图示主题与整合说明]
- 本图示主题：牛顿调和三角形的数阵结构与递推关系可视化

[视觉元素清单]
- 三角形数阵：15 个分数文本（前 5 行）+ 6 个分数文本（第 6 行），位置见坐标表
- 行号标签：n=1 至 n=6，左侧 x=70 处垂直排列
- 递推箭头：蓝色实线 (#1565c0)，带箭头，连接上层数与下层相邻两数
- 高亮背景：当前高亮的数用红色背景 (#c62828, 20% 透明度) 圆角矩形框
- 第 6 行初始状态：灰色虚线框 (#888888, stroke-dasharray="5,5")
- 答案高亮：绿色背景 (#2e7d32, 20% 透明度) 圆角矩形框
- 等式框：白色背景，黑色边框，显示递推等式
- 颜色规格：背景#ffffff / 数阵主线#000000 / 递推箭头#1565c0 / 高亮数#c62828 / 第 6 行初始#888888 / 答案#2e7d32

[分步序列]
- 初始状态（步骤 0）：显示前 5 行完整数阵（15 个分数），第 6 行 6 个位置显示灰色虚线空框，行号 n=1~6 全部显示（n=6 灰色），无箭头，无等式框
- 步骤 1：点击「下一步」→ 高亮第 2 行左 1/2（红色背景），高亮第 3 行 1/3 和 1/6（红色背景），显示两条蓝色箭头从 1/2 指向 1/3 和 1/6，右侧等式框显示"1/2 = 1/3 + 1/6"
- 步骤 2：点击「下一步」→ 清除步骤 1 高亮，高亮第 3 行左 1/3（红色背景），高亮第 4 行 1/4 和 1/12（红色背景），显示两条蓝色箭头从 1/3 指向 1/4 和 1/12，右侧等式框显示"1/3 = 1/4 + 1/12"
- 步骤 3：点击「下一步」→ 清除步骤 2 高亮，高亮第 4 行左 1/4（红色背景），高亮第 5 行 1/5 和 1/20（红色背景），显示两条蓝色箭头从 1/4 指向 1/5 和 1/20，右侧等式框显示"1/4 = 1/5 + 1/20"
- 步骤 4：点击「下一步」→ 清除步骤 3 高亮，第 6 行 6 个虚线框变为实线，依次填入计算出的数值：1/6, 1/30, 1/60, 1/60, 1/30, 1/6（黑色实线框）
- 步骤 5：点击「下一步」→ 高亮第 6 行第 2 个数 1/30（绿色背景），下方显示答案标注"第 6 行第 2 个数 = 1/30"，步骤指示显示"完成"

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 内底部左侧 (320,450)，点击回退到上一状态
  - 「下一步」按钮：位于 SVG 内底部右侧 (400,450)，点击进入下一状态
  - 步骤指示器：位于底部中央 (400,490)，显示当前步骤"步骤 X/5"
- 教师操作流程：
  1. 初始展示完整前 5 行数阵，让学生观察规律
  2. 点击「下一步」演示第一个递推实例 1/2=1/3+1/6，讲解递推关系
  3. 继续点击演示第二、三个实例，强化理解
  4. 点击扩展到第 6 行，引导学生根据规律计算
  5. 最后高亮答案，完成题目第 (1) 问的可视化推导

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何布局简单（文本 + 箭头 + 矩形），无需复杂库；原生 SVG 对分数文本渲染友好，CDN 依赖最少
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────────┐
  │  n=1                          1/1                           │
  │  n=2                    1/2       1/2                       │
  │  n=3                1/3   1/6   1/3                         │
  │  n=4            1/4  1/12  1/12  1/4                        │
  │  n=5        1/5  1/20  1/30  1/20  1/5                      │
  │  n=6    [1/6][1/30][1/60][1/60][1/30][1/6]  (虚线→实线)    │
  │                                                             │
  │                    [等式框区域 x=580-760]                   │
  │                                                             │
  │              [◀上一步]  [下一步▶]                           │
  │                   步骤 X/5                                  │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用 currentState 变量 (0-5) 跟踪当前步骤，steps 数组存储每步的显示配置
  2. 每个状态配置包含：highlights 数组（高亮元素 ID）、arrows 数组（显示哪些箭头）、equations 数组（显示哪些等式）、row6Style（虚线/实线）、answerVisible（布尔）
  3. 坐标计算：数阵位置预计算为常量对象，避免运行时计算误差
  4. 动画曲线：高亮背景用 CSS transition: opacity 0.3s ease，箭头用 stroke-dasharray 动画实现"绘制"效果
  5. 事件绑定：按钮点击事件绑定到 updateState() 函数，更新后重绘所有元素状态
  6. 边界处理：步骤 0 时禁用「上一步」，步骤 5 时禁用「下一步」并显示"完成"
- ID 命名规范：所有元素 ID 以 scene1- 为前缀
  - 数阵元素：scene1-num-{行}-{列}（如 scene1-num-2-1 表示第 2 行第 1 个数 1/2）
  - 行号：scene1-rowlabel-{n}（如 scene1-rowlabel-1）
  - 箭头：scene1-arrow-{步骤}-{序号}（如 scene1-arrow-1-1）
  - 等式框：scene1-equation-{步骤}
  - 高亮框：scene1-highlight-{行}-{列}
  - 第 6 行框：scene1-row6-{列}
  - 按钮：scene1-btn-prev, scene1-btn-next
  - 步骤指示：scene1-step-indicator
  - 答案标注：scene1-answer-label
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
