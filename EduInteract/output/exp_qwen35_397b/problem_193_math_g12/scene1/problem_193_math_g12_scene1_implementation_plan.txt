[图示主题与整合说明]
- 本图示主题：从三视图还原组合几何体
- 整合的内容：三视图展示→半圆锥还原→三棱锥还原→组合体成型→体积计算验证
- 教学价值：教师可逐步演示如何从二维三视图还原三维几何体，帮助学生建立空间想象能力。通过分步动画展示半圆锥和三棱锥的组合过程，最后验证体积公式求解参数a。

[分步序列]
- 步骤0（初始状态）：仅显示三个视图（正视图、侧视图、俯视图），立体图区域空白，显示标题"从三视图还原几何体"
- 步骤1：点击「下一步」→ 半圆锥立体以淡入动画浮现（透明度0%→20%），同时从俯视图半圆部分引出投影虚线指向立体图的半圆锥底面，显示标签"半圆锥"
- 步骤2：点击「下一步」→ 三棱锥立体以淡入动画浮现（透明度0%→20%），同时从俯视图三角形部分引出投影虚线指向立体图的三棱锥底面，显示标签"三棱锥"
- 步骤3：点击「下一步」→ 完整组合体高亮显示（轮廓线加粗），显示高标注"a"和体积公式：V = V_半圆锥 + V_三棱锥 = (πa/6) + (a/3) = (π+2)a/6，已知 V = (π+2)/6，故 a = 1

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于(320,455)，80×30px，点击后退到前一状态（步骤0时禁用）
  - 「下一步」按钮：位于(400,455)，80×30px，点击前进到下一状态（步骤3时禁用）
  - 步骤指示器：位于(400,30)，显示"步骤 X/4"
- 教师操作流程：
  1. 初始展示三视图，引导学生观察三个视图的特征
  2. 点击「下一步」展示半圆锥还原，讲解半圆对应半圆锥
  3. 点击「下一步」展示三棱锥还原，讲解三角形对应三棱锥
  4. 点击「下一步」展示完整组合体和体积计算，引导学生求解a

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [800 × 500 画布]
  +--------------------------------------------------+
  |              步骤指示器 (400,30)                  |
  |                                                  |
  |  [正视图]    [侧视图]    [俯视图]                 |
  |   (150,120)  (360,120)   (570,120)               |
  |                                                  |
  |              (投影虚线连接)                       |
  |                                                  |
  |           [立体组合体] (400,350)                 |
  |                                                  |
  |  +--------------------------------------------+  |
  |  |  [◀ 上一步]  [下一步 ▶]   (控件栏 y=440-490)|  |
  |  +--------------------------------------------+  |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-3) 跟踪当前步骤
  2. 所有元素用 scene1- 前缀命名 ID，如 scene1-front-view、scene1-half-cone
  3. 半圆锥和三棱锥初始 opacity=0，步骤1和2分别淡入到 opacity=0.2
  4. 投影虚线初始隐藏，对应步骤显示
  5. 体积公式在步骤3用 MathJax 渲染或 SVG text 显示
  6. 按钮状态：步骤0时禁用「上一步」，步骤3时禁用「下一步」
  7. 所有 JS 代码包在 IIFE 中：(function() { ... })()
- ID 命名规范：
  - scene1-front-view（正视图组）
  - scene1-side-view（侧视图组）
  - scene1-top-view（俯视图组）
  - scene1-half-cone（半圆锥立体）
  - scene1-tri-pyramid（三棱锥立体）
  - scene1-proj-line-1/2/3（投影虚线）
  - scene1-btn-prev（上一步按钮）
  - scene1-btn-next（下一步按钮）
  - scene1-step-indicator（步骤指示器）
