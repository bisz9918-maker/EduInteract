[图示主题与整合说明]
- 本图示主题：组合体体积计算与参数 a 的求解
- 整合的步骤/概念：
  1. 半圆锥体积公式：V_半圆锥 = (1/2) × (1/3)πr²h = πa/6（其中 r=1, h=a）
  2. 三棱锥体积公式：V_三棱锥 = (1/3) × 底面积 × 高 = (1/3) × (1/2×2×1) × a = a/3
  3. 总体积表达式：V_总 = V_半圆锥 + V_三棱锥 = a(π+2)/6
  4. 代入已知值求解：当 V_总 = (π+2)/6 时，a=1
- 教学价值：教师可通过滑块动态演示体积随参数 a 变化的线性关系，学生直观理解当 a=1 时总体积恰好等于给定值 (π+2)/6，验证答案的正确性

[分步序列]
本场景为连续拖拽滑块交互，无分步导航，状态连续变化：
- 初始状态（a=1.0）：
  - 左侧显示半圆锥和三棱锥的立体组合图
  - 右侧显示三个体积公式
  - 数值显示区显示：V_半圆锥=π/6≈0.524，V_三棱锥=1/3≈0.333，V_总=(π+2)/6≈0.857
  - V_总数值区域用绿色背景高亮
  - 滑块按钮位于轨道中点（a=1.0 位置）
  - 显示提示文本"当 a=1 时，V_总=(π+2)/6"

- 拖拽状态（a 变化）：
  - 滑块按钮随拖拽移动
  - 当前 a 值实时更新显示
  - 三个体积数值实时重新计算并显示
  - 当 a≠1 时，V_总数值区域取消高亮，提示文本隐藏
  - 当 a=1 时（容差±0.02），V_总数值区域高亮，提示文本显示

- 边界状态（a=0.5 或 a=2.0）：
  - 滑块按钮到达轨道端点
  - 体积数值按公式计算显示
  - 无高亮效果

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：
  - 滑块轨道：水平线段，从 (360,450) 到 (780,450)，长度 420px
  - 滑块按钮：圆形，半径 12px，可沿轨道拖拽
  - a 值范围：0.5 ~ 2.0，默认 1.0
  - 映射关系：滑块 x 坐标 = 360 + (a-0.5) × 420/1.5 = 360 + (a-0.5) × 280
  - 当前 a 值显示：位于滑块按钮正上方 25px 处
- 教师操作流程：
  1. 初始状态 a=1.0，展示题目给定的体积值对应的参数
  2. 拖拽滑块改变 a 值，观察体积数值的线性变化
  3. 引导学生发现 V_总与 a 成正比关系
  4. 回到 a=1.0，验证此时 V_总=(π+2)/6，确认答案

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript
  - 立体图用 SVG 路径绘制（伪 3D 效果）
  - 滑块用 SVG circle + mouse/touch 事件实现拖拽
  - 无需额外库，轻量且兼容性好
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  [左侧 40%]          |  [右侧 60%]              |
  |   半圆锥立体图        |  公式面板                 |
  |   (50,80)-(320,320)  |  V_半圆锥 = πa/6         |
  |                      |  V_三棱锥 = a/3          |
  |   三棱锥立体图        |  V_总 = a(π+2)/6         |
  |   (50,320)-(320,420) |  [数值显示区]            |
  |                      |  V_半圆锥：xxx           |
  |                      |  V_三棱锥：xxx           |
  |                      |  V_总：xxx [高亮]        |
  |----------------------|--------------------------|
  |  [滑块控件区 y=420-490]                          |
  |     0.5 [====●====] 2.0   当前 a: 1.0           |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态管理：维护当前 a 值（默认 1.0），范围 [0.5, 2.0]
  2. 坐标映射：a 值 ↔ 滑块 x 坐标的线性映射
  3. 体积计算：
     - V_半圆锥 = Math.PI * a / 6
     - V_三棱锥 = a / 3
     - V_总 = a * (Math.PI + 2) / 6
  4. 高亮判断：Math.abs(a - 1.0) < 0.02 时触发高亮
  5. 事件绑定：mousedown/touchstart 启动拖拽，mousemove/touchmove 更新位置，mouseup/touchend 结束拖拽
  6. 数值格式化：保留 3 位小数显示
- ID 命名规范：
  - scene2-combine-shape：组合体图形组
  - scene2-hemisphere-cone：半圆锥图形
  - scene2-triangular-pyramid：三棱锥图形
  - scene2-formula-panel：公式面板背景
  - scene2-formula-hemisphere：V_半圆锥公式文本
  - scene2-formula-triangular：V_三棱锥公式文本
  - scene2-formula-total：V_总公式文本
  - scene2-value-hemisphere：V_半圆锥数值显示
  - scene2-value-triangular：V_三棱锥数值显示
  - scene2-value-total：V_总数值显示
  - scene2-slider-track：滑块轨道
  - scene2-slider-thumb：滑块按钮
  - scene2-slider-value：当前 a 值显示
  - scene2-highlight-hint：高亮提示文本
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
