[视觉元素清单]
- 四面体线框：6 条棱，5 条实线（#000000），1 条虚线 AC（#888888）
- 顶点：4 个顶点用小圆点表示（r=3，#333333）
- 顶点标签：A、B、C、D 四个字母（font-size: 18px，#333333）
- 长度标注："2c" 标注 AD 棱（font-size: 16px，#000000），"2" 标注 BC 棱
- 高亮 AD 棱：步骤 1 时变为 #1565c0，线宽 5px
- 高亮 BC 棱：步骤 2 时变为 #c62828，线宽 5px
- 公垂线段：步骤 3 显示，连接 AD 中点与 BC 上某点，颜色 #2e7d32
- 垂直符号：直角标记，颜色 #2e7d32

[分步序列]
- 初始状态（步骤 0）：显示完整四面体线框（AD/AB/BD/BC/CD 实线黑色，AC 虚线灰色），四个顶点标签 A/B/C/D，无长度标注
- 步骤 1：点击「下一步」→ AD 棱高亮为蓝色（#1565c0），线宽加粗至 5px，在 AD 右侧中间位置 (295,240) 显示长度标注 "2c"
- 步骤 2：点击「下一步」→ AD 恢复黑色，BC 棱高亮为红色（#c62828），线宽加粗至 5px，在 BC 下方 (540,335) 显示长度标注 "2"
- 步骤 3：点击「下一步」→ BC 恢复黑色，显示公垂线段（从 AD 上点 (280,280) 到 BC 上点 (460,280) 的绿色线段），在公垂线与 AD 交点处显示直角符号，在公垂线上方 (380,260) 显示 "⊥" 符号

[标签冲突检查]
- 标签"A"：坐标 (265, 420)
- 标签"B"：坐标 (470, 370)
- 标签"C"：坐标 (635, 280)
- 标签"D"：坐标 (265, 65)
- 标注"2c"：坐标 (295, 240)
- 标注"2"：坐标 (540, 335)
- 标注"⊥"：坐标 (380, 260)

冲突检查：
- "A"与"2c"：距离 sqrt((295-265)^2+(240-420)^2) ≈ 182px → 无冲突
- "A"与"D"：距离 sqrt((265-265)^2+(65-420)^2) = 355px → 无冲突
- "2c"与"⊥"：距离 sqrt((380-295)^2+(260-240)^2) ≈ 87px → 无冲突
- "2"与"B"：距离 sqrt((540-470)^2+(335-370)^2) ≈ 78px → 无冲突
- "2"与"⊥"：距离 sqrt((540-380)^2+(335-260)^2) ≈ 177px → 无冲突
- "C"与"2"：距离 sqrt((635-540)^2+(280-335)^2) ≈ 110px → 无冲突

所有标签间距均大于 20px，无冲突。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 底部左侧 (x=350, y=455)，返回上一状态
  - 「下一步」按钮：位于 SVG 底部右侧 (x=450, y=455)，进入下一状态
  - 步骤指示器：位于两按钮之间 (x=400, y=455)，显示当前步骤序号
- 教师操作流程：
  1. 初始展示四面体框架，让学生识别顶点和棱
  2. 点击「下一步」高亮 AD 棱，讲解 AD=2c 的含义
  3. 点击「下一步」高亮 BC 棱，讲解 BC=2 的含义
  4. 点击「下一步」显示公垂线和垂直符号，讲解 AD⊥BC 的几何意义
  5. 可随时点击「上一步」回退复习

- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-3) 跟踪当前步骤
  2. 坐标计算：四面体顶点坐标固定，棱由顶点坐标计算
  3. 动画曲线：棱高亮用 CSS transition 实现平滑过渡（0.3s ease）
  4. 事件绑定：按钮点击事件切换 currentStep，调用 updateScene() 更新显示
  5. 虚线实现：SVG stroke-dasharray="5,5"
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀（如 scene1-edge-ad、scene1-label-a、scene1-btn-prev）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
