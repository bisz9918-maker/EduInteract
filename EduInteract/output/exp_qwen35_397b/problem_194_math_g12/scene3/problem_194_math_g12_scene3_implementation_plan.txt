[分步序列]
- 初始状态（步骤0）：显示四面体线框（6条棱+4个顶点+4个标签），显示BC=2和AD=2c标注，右侧显示体积公式框"V = 1/3 · S_△ABC · h"（蓝色边框）
- 步骤1：点击「下一步」→ △ABC区域高亮显示（绿色填充30%透明），公式框更新为"V = 1/3 · (1/2·BC·h₁) · h₂"，强调底面积与BC的关系
- 步骤2：点击「下一步」→ 最大值条件框显示（红色边框）"BC⊥AD 且位于椭圆短轴"，AD棱加粗高亮（线宽4px→6px），BC棱高亮（颜色#c62828）
- 步骤3：点击「下一步」→ 最终结果框显示（绿色边框）"V_max = (2/3)c√(a²-c²-1)"，所有高亮保持，完成推导

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮：位于(520,450)，80×30px，蓝色背景，点击回退到前一状态

  2. 点击下一步，高亮△ABC，讲解底面积计算
  3. 点击下一步，展示最大值条件，解释为何BC⊥AD时体积最大
  4. 点击下一步，展示最终结果，完成推导

[技术实现]
- JS库选择：原生SVG（四面体几何结构简单，无需复杂库）
- 画布尺寸：800×500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +------------------------------------------+
  |  [四面体]          |  [公式推导区]       |
  |   D                |  +---------------+  |
  |   |\\               |  | 体积公式     |  |
  |   | \\              |  +---------------+  |
  |   |  \\ C           |  +---------------+  |
  |   | /               |  | 最大值条件   |  |
  |   |/                |  +---------------+  |
  |   A----B            |  +---------------+  |
  |                      |  | 最终结果     |  |
  |                      |  +---------------+  |
  +------------------------------------------+
  |        [◀上一步] [步骤X/3] [下一步▶]      |
  +------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用currentState变量(0-3)跟踪当前步骤，steps数组存储每步的显示配置
  2. 坐标计算：四面体顶点坐标硬编码，确保透视效果合理
  3. 动画曲线：元素显示/高亮使用CSS transition，duration 300ms，ease-out
  4. 事件绑定：按钮点击事件绑定到stateChange函数，更新DOM元素display/opacity属性
  5. ID命名规范：所有元素ID以scene3-为前缀（如scene3-vertex-a, scene3-edge-ad, scene3-formula-box）
  6. IIFE隔离：所有JS代码包在(function() { ... })()中，避免全局变量污染
  7. 虚线实现：AC棱使用stroke-dasharray="5,5"实现虚线效果
  8. 高亮实现：通过改变opacity和fill属性实现区域高亮
