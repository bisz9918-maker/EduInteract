    **教学说明：**

    本图示展示核心推导过程，教师应重点讲解以下逻辑链：

    1. **发现两个直角**：
       - ∠OPA = 90°（切线性质）
       - ∠OMA = 90°（垂径定理：OM ⊥ BC，而 A、M、C 共线）

    2. **判定四点共圆**：
       - 在四边形 OAPM 中，∠OPA + ∠OMA = 180°
       - 因此 O、A、P、M 四点共圆

    3. **利用圆周角性质**：
       - 在四点共圆中，∠OAM 和∠OPM 都对弧 OM
       - 所以∠OAM = ∠OPM

    4. **得出结论**：
       - ∠OAM + ∠APM = ∠OPM + ∠APM = ∠OPA = 90°

    **完整解答：**

    连接 OP、OM。

    ∵ AP 是圆 O 的切线，P 为切点
    ∴ OP ⊥ AP，即∠OPA = 90°

    ∵ M 是弦 BC 的中点
    ∴ OM ⊥ BC（垂径定理）

    在四边形 OAPM 中：
    ∠OPA + ∠OMA = 90° + 90° = 180°

    ∴ O、A、P、M 四点共圆

    ∴ ∠OAM = ∠OPM（同弧所对圆周角相等）

    ∴ ∠OAM + ∠APM = ∠OPM + ∠APM = ∠OPA = 90°

    **答案：90°**
