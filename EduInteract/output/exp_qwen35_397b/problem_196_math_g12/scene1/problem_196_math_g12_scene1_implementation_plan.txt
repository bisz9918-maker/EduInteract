[图示主题与整合说明]
- 本图示主题：圆的切线与割线性质——∠OAM+∠APM 的几何关系
- 整合内容：完整图形（圆 O、切线 AP、割线 AC）、切线性质（OP⊥AP）、垂径定理（OM⊥BC）、各点标注、待求角标注
- 教学价值：教师可逐步展示几何条件，先呈现基础图形，再依次揭示切线垂直性质、垂径定理，最后标注待求角，引导学生发现∠OAM+∠APM=90°的结论。分步导航允许教师控制节奏，随时回退强调关键点。

[分步序列]
步骤 0（初始状态）：基础图形
- 显示：圆 O（黑色轮廓）、切线 AP（黑色）、割线 AC（黑色）
- 显示点标签：A、O、P、B、C、M（黑色文字，位置见布局坐标表）
- 隐藏：OP、OM、AM、PM、直角标记、角度弧
- 等待教师点击「下一步」

步骤 1：揭示切线性质 OP⊥AP
- 新增显示：半径 OP（蓝色 #1565c0）
- 新增显示：P 点处直角标记（小正方形，表示 OP⊥AP）
- 保持：步骤 0 所有元素
- 教师讲解：切线垂直于过切点的半径

步骤 2：揭示垂径定理 OM⊥BC
- 新增显示：线段 OM（绿色 #2e7d32）
- 新增显示：M 点处直角标记（小正方形，表示 OM⊥BC）
- 保持：步骤 0、1 所有元素
- 教师讲解：M 为弦 BC 中点，圆心到弦中点的连线垂直于弦

步骤 3（最终步骤）：标注待求角∠OAM 和∠APM
- 新增显示：线段 AM（红色 #c62828）
- 新增显示：线段 PM（红色 #c62828）
- 新增显示：∠OAM 角度弧（红色圆弧，以 A 为圆心，r=25px）
- 新增显示：∠APM 角度弧（红色圆弧，以 P 为圆心，r=25px）
- 保持：步骤 0、1、2 所有元素
- 教师讲解：观察两角关系，引导学生发现∠OAM+∠APM=90°

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 按钮「◀上一步」：位于 SVG 内底部左侧 (x=350, y=460)，宽 100px，高 30px
  - 按钮「下一步▶」：位于 SVG 内底部右侧 (x=450, y=460)，宽 100px，高 30px
  - 步骤指示器：位于两按钮之间 (x=380, y=465)，显示「步骤 X/4」
- 教师操作流程：
  1. 加载图示，显示基础图形（步骤 0），教师介绍题目条件
  2. 点击「下一步」，显示 OP⊥AP（步骤 1），教师讲解切线性质
  3. 点击「下一步」，显示 OM⊥BC（步骤 2），教师讲解垂径定理
  4. 点击「下一步」，显示待求角（步骤 3），教师引导学生观察两角关系
  5. 可随时点击「上一步」回退复习关键点

[技术实现]
- JS 库选择：原生 SVG（简单几何图形首选，无需额外库）
- 画布尺寸：800×500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |    A                                             |
  |     \                                            |
  |      \                                           |
  |       \       圆 O                               |
  |        \    +-------+                            |
  |         \  /         \                           |
  |          \/    P      \                          |
  |          |     *      |                           |
  |          |   /   \    |                           |
  |          |  /     \   |                           |
  |          | / B  M  \  |                           |
  |          |/         \ |                           |
  |          +----C------+                            |
  |                                                  |
  |                                                  |
  |              [◀上一步]  步骤 1/4  [下一步▶]       |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-3) 跟踪当前步骤，每次点击按钮更新状态并重绘
  2. 坐标计算：所有点坐标硬编码（见布局坐标表），确保精确
  3. 动画曲线：元素显示/隐藏使用 CSS transition (opacity 0.3s ease)
  4. 事件绑定：按钮点击事件绑定到 stepChange 函数，更新 currentStep 并调用 render()
  5. 直角标记绘制：用 path 绘制小正方形，边长 12px，位于垂直交点处
  6. 角度弧绘制：用 path 绘制圆弧，r=25px，起始/终止角度根据线段方向计算
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀
  - scene1-circle-o, scene1-line-ap, scene1-line-ac, scene1-line-op, scene1-line-om
  - scene1-line-am, scene1-line-pm, scene1-point-a, scene1-point-o, scene1-point-p
  - scene1-point-b, scene1-point-c, scene1-point-m
  - scene1-label-a, scene1-label-o, scene1-label-p, scene1-label-b, scene1-label-c, scene1-label-m
  - scene1-rect-p, scene1-rect-m (直角标记)
  - scene1-arc-oam, scene1-arc-apm (角度弧)
  - scene1-btn-prev, scene1-btn-next, scene1-step-indicator
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局污染
- 控件栏实现：用 foreignObject 在 SVG 内嵌入 HTML 按钮，或直接用 HTML 绝对定位叠在 SVG 上
