[视觉元素清单]

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 内底部左侧 (x=350, y=460)，点击回退到前一状态
  - 「下一步」按钮：位于 SVG 内底部右侧 (x=450, y=460)，点击进入下一状态
  - 步骤指示器：位于两按钮之间 (x=400, y=465)，显示"步骤 X/4"
- 教师操作流程：
  1. 初始展示四边形 OAPM 和两个直角，引导学生观察
  2. 点击「下一步」展示四点共圆，讲解对角互补判定
  3. 点击「下一步」展示同弧圆周角相等，建立∠OAM = ∠OPM
  4. 点击「下一步」展示角度和推导，得出最终结论 90°

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单，无需复杂库；原生 SVG 精度高、性能好、易于控制坐标
- 画布尺寸：800×500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  [步骤说明文本区 y=50~100]                        |
  |                                                  |
  |     A(180,240)              P(530,155)           |
  |        *--------------------*                    |
  |         \                  / |                   |
  |          \                /  |                   |
  |           \              /   |                   |
  |            \            /    |                   |
  |             \          /     |                   |
  |              \        /      |                   |
  |               \      /       |                   |
  |                \    /        |                   |
  |                 \  /         |                   |
  |                  \/          |                   |
  |              M(545,285)------O(560,240)          |
  |                 [圆 O 及外接圆]                   |
  |                                                  |
  |           [结论文本区 y=420]                      |
  |                                                  |
  |  [◀上一步]  [步骤 1/4]  [下一步▶]  y=450~490      |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用 currentState 变量(0~3)跟踪当前步骤，steps 数组存储每步的显示配置
  2. 元素分组：用<g>元素将相关元素分组（如 angle-opa、angle-oma、circumcircle 等），通过 display 属性控制显示/隐藏
  3. 动画效果：使用 CSS transition 实现淡入效果（opacity 0→1，duration 0.5s）
  4. 事件绑定：按钮点击事件切换 currentState，调用 renderStep() 更新显示
  5. 边界检查：第一步禁用「上一步」，最后一步禁用「下一步」
- ID 命名规范：
  - 所有元素 ID 以 scene2- 为前缀
  - 示例：scene2-circle-o、scene2-quad-oapm、scene2-angle-opa、scene2-btn-next、scene2-btn-prev
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
