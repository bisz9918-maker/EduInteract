场景导航：Scene 1 | Scene 2

题目原文：

如图，将△ABC 沿着它的中位线 DE 折叠后，点 A 落到点 A′，若∠C=120°，∠A=26°，则∠A′DB 的度数是$\underline{\hspace{5em}}$．

题目分析：

本题是一道几何折叠问题，核心考点包括：

  1. 三角形中位线的性质（DE∥BC，D、E 分别为 AB、AC 中点）
  2. 折叠变换的性质（折叠前后图形全等，对应角相等）
  3. 平行线的性质（同位角相等）
  4. 三角形内角和定理

整体讲解思路：

  1. 首先展示原三角形 ABC 及中位线 DE，标注已知角度
  2. 演示折叠过程，展示点 A 沿 DE 折叠到 A'的轨迹
  3. 利用折叠性质和中位线性质推导角度关系
  4. 最终计算∠A'DB 的度数

图示规划说明：

设计 2 个场景：

  • SCENE_1：展示折叠动态过程，从原三角形到折叠后状态的完整动画
  • SCENE_2：展示角度推导关系，标注关键角度值及等量关系
步骤 1/4

教学说明：

本图示用于引导学生理解折叠变换的几何本质。

讲解要点：

  1. 首先确认 DE 是中位线，因此 D 是 AB 中点，E 是 AC 中点
  2. 折叠的本质是轴对称变换，DE 是对称轴
  3. 折叠后△ADE ≅ △A'DE，对应边、对应角相等

关键推导：

  1. 在△ABC 中，∠B = 180° - ∠A - ∠C = 180° - 26° - 120° = 34°
  2. 因为 DE∥BC（中位线性质），所以∠ADE = ∠B = 34°（同位角）
  3. 折叠后∠A'DE = ∠ADE = 34°（折叠性质）
  4. 因为 D 在 AB 上，∠ADB = 180°（平角）
  5. 所以∠A'DB = 180° - ∠A'DE - ∠ADE = 180° - 34° - 34° = 112°

教师应引导学生观察折叠前后哪些量保持不变（边长、角度），哪些位置关系发生变化。

总结与课堂讲解建议：

完整解答：

  1. 在△ABC 中，由内角和定理：∠B = 180° - 26° - 120° = 34°
  2. 因为 DE 是中位线，所以 DE∥BC
  3. 由平行线性质：∠ADE = ∠B = 34°（同位角相等）
  4. 由折叠性质：∠A'DE = ∠ADE = 34°
  5. 因为点 D 在 AB 上，∠ADB 为平角，即∠ADB = 180°
  6. 所以∠A'DB = 180° - ∠ADE - ∠A'DE = 180° - 34° - 34° = 112°

课堂讲解建议：

  1. 先让学生观察图形，识别已知条件和所求角度
  2. 利用 SCENE_1 演示折叠过程，帮助学生建立空间想象
  3. 利用 SCENE_2 逐步标注角度，引导学生发现角度之间的等量关系
  4. 强调折叠问题的核心：折叠前后对应角相等、对应边相等
  5. 提醒学生注意中位线的双重性质：平分两边且平行于第三边

易错点提示：

  • 学生可能忽略 D 在 AB 上这一关键位置关系
  • 可能混淆∠A'DB 与∠A'DE 的关系
  • 需要明确∠ADB 是平角（180°）这一隐含条件
