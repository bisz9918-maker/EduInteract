[图示主题与整合说明]
- 本图示主题：三角形沿中位线折叠的动态过程演示
- 整合的内容：原三角形ABC状态、中位线DE、折叠动画过程、折叠后最终状态△A'DE、关键角度关系
- 教学价值：教师可通过分步控制展示折叠变换的完整过程，帮助学生理解：(1)中位线的定义与位置；(2)折叠是轴对称变换，DE为对称轴；(3)折叠前后对应线段相等(AD=A'D)、对应角相等(∠ADE=∠A'DE)；(4)利用几何关系求解∠A'DB

[分步序列]
步骤0（初始状态）：
- 显示：原三角形△ABC（三边黑色实线）
- 显示：中位线DE（蓝色实线）
- 显示：所有顶点标签A、B、C、D、E
- 显示：角度标注∠A=26°、∠C=120°
- 隐藏：折叠后三角形、运动轨迹、等长标记、A'点
- 控件状态：「上一步」禁用，「下一步」可用

步骤1（开始折叠）：
- 新增显示：点A的运动轨迹（灰色虚线圆弧，从A到A'的路径）
- 动画效果：点A沿圆弧向A'移动至中点位置，A点变为半透明
- 保持显示：原三角形ABC、中位线DE、所有标签
- 控件状态：「上一步」「下一步」均可用

步骤2（折叠完成）：
- 新增显示：折叠后△A'DE（绿色实线，A'D、A'E两边）
- 新增显示：点A'（绿色实心圆）及标签A'
- 新增显示：等长标记3组（AD=A'D=DB，红色短线）
- 隐藏：运动轨迹、半透明A点（恢复原位置A）
- 保持显示：原三角形ABC、中位线DE、所有标签
- 控件状态：「上一步」「下一步」均可用

步骤3（角度关系高亮）：
- 新增显示：∠ADE高亮弧（橙色，圆心D，半径25px）
- 新增显示：∠A'DE高亮弧（橙色，圆心D，半径25px）
- 新增显示：文字提示"∠ADE=∠A'DE"（步骤2已隐含，此步强调）
- 保持显示：步骤2所有元素
- 控件状态：「上一步」可用，「下一步」禁用（最后一步）

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于(280,455)，80×30px，步骤0时禁用，其他步骤可用
  - 「下一步」按钮：位于(440,455)，80×30px，步骤3时禁用，其他步骤可用
  - 步骤指示器：位于(400,475)，显示"步骤X/4"
- 教师操作流程：
  1. 初始展示原三角形与中位线，讲解题目条件∠A=26°、∠C=120°
  2. 点击「下一步」展示折叠轨迹，说明A点将沿DE对称折叠
  3. 点击「下一步」展示折叠完成状态，强调AD=A'D=DB（中位线性质+折叠对称）
  4. 点击「下一步」高亮∠ADE与∠A'DE，引导学生发现两角相等，进而求解∠A'DB

[技术实现]
- JS库选择：原生SVG + 原生JavaScript
  - 原因：几何图形简单，SVG原生支持线段、圆弧、文本，无需额外库；动画用CSS transition或requestAnimationFrame即可
- 画布尺寸：800×500px（固定）
- 布局草图：
  ```
  +--------------------------------------------------+
  |                    C(320,140)                    |
  |                   / \                            |
  |                  /   \ E(500,200)                |
  |                 /     \                          |
  |                /       \                         |
  |           D(430,320)---\--------A(680,260)       |
  |              / \        \       /                |
  |             /   \        \     /                 |
  |            /     \        \   /                  |
  |           /       \        \ /                   |
  |      B(180,380)------------A'(570,380)           |
  |                                                  |
  |                                                  |
  |              [◀上一步]  步骤2/4  [下一步▶]       |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量currentStep(0-3)跟踪当前步骤，每步对应一组显示/隐藏的元素
  2. 坐标计算：D为AB中点((180+680)/2,(380+260)/2)=(430,320)；E为AC中点((320+680)/2,(140+260)/2)=(500,200)
  3. A'坐标计算：A关于直线DE的对称点。DE斜率k=(200-320)/(500-430)=-120/70≈-1.714，通过几何对称公式计算得A'(570,380)
  4. 动画实现：步骤1中A点沿圆弧移动，用参数方程x=cx+r*cos(θ), y=cy+r*sin(θ)，θ从θ_start渐变到θ_end
  5. 事件绑定：按钮点击事件切换currentStep，调用updateScene()函数更新各元素display属性
- ID命名规范：所有元素ID以scene1-为前缀
  - scene1-tri-abc（原三角形路径）
  - scene1-line-de（中位线）
  - scene1-tri-aprime-de（折叠后三角形）
  - scene1-arc-trajectory（运动轨迹）
  - scene1-mark-ad、scene1-mark-aprime-d、scene1-mark-db（等长标记）
  - scene1-point-a/b/c/d/e/aprime（顶点）
  - scene1-label-a/b/c/d/e/aprime（标签文本）
  - scene1-angle-ade、scene1-angle-aprime-de（角度高亮弧）
  - scene1-btn-prev、scene1-btn-next、scene1-step-indicator（控件）
- IIFE隔离：所有JS代码包在(function() { ... })()中，避免全局变量污染
- 配色方案：严格遵循spec中定义
  - 背景：#ffffff
  - 原三角形边线：#000000
  - 中位线DE：#1565c0
  - 折叠后三角形：#2e7d32
  - 运动轨迹：#888888
  - 等长标记：#c62828
  - 角度高亮：#ff9800
