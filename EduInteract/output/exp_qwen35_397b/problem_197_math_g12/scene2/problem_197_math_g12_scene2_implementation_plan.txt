  - 「上一步」按钮：SVG 内左下角 (350,460)，灰色背景，点击后退到前一状态

  3. 点击「下一步」展示平行线性质推导∠ADE=34°

  6. 可随时点击「上一步」回退复习关键推导步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单，无需复杂库；SVG 缩放不失真，适合教学图示
- 画布尺寸：800×500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |                    A                             |
  |                   / \                            |
  |                  /   \                           |
  |                 /     \                          |
  |                D-------E                         |
  |               / \     / \                        |
  |              /   \   /   \                       |
  |             /     \ /     \                      |
  |            B-------C       A'                    |
  |                                                  |
  |         [角度标注分散在对应顶点附近]              |
  |                                                  |
  |                              [答案框]            |
  |                                                  |
  |    [◀上一步]    步骤 X/5    [下一步▶]           |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用数组存储 5 个状态，每个状态定义显示/隐藏的元素 ID 列表
  2. 坐标计算：所有坐标硬编码，确保与布局表一致
  3. 动画曲线：使用 CSS transition 实现淡入效果（opacity 0→1，300ms ease-out）
  4. 事件绑定：按钮点击事件切换当前状态索引，调用 updateScene() 更新显示
  5. 角度弧线绘制：使用 SVG path 的 arc 命令，根据圆心、半径、起始/终止角度计算
- ID 命名规范：所有元素 ID 以 scene2- 为前缀
  - scene2-tri-abc（△ABC 轮廓）
  - scene2-seg-de（中位线 DE）
  - scene2-tri-a'de（△A'DE）
  - scene2-seg-db、scene2-seg-ec、scene2-seg-bc
  - scene2-arc-a、scene2-arc-b、scene2-arc-c（已知角度弧线）
  - scene2-arc-ade、scene2-arc-a'de、scene2-arc-a'db（推导角度弧线）
  - scene2-label-a、scene2-label-b、scene2-label-c、scene2-label-d、scene2-label-e、scene2-label-a'
  - scene2-angle-a、scene2-angle-b、scene2-angle-c（角度数值标签）
  - scene2-angle-ade、scene2-angle-a'de、scene2-angle-a'db
  - scene2-parallel-mark1、scene2-parallel-mark2（平行标记箭头）
  - scene2-parallel-label（DE∥BC 标签）
  - scene2-answer-box（答案框）
  - scene2-btn-prev、scene2-btn-next、scene2-step-indicator（控件）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
- 状态数据结构示例：
  ```javascript
  const states = [
    { show: ['scene2-tri-abc','scene2-seg-de','scene2-tri-a\'de','scene2-seg-db','scene2-seg-ec','scene2-seg-bc','scene2-label-a','scene2-label-b','scene2-label-c','scene2-label-d','scene2-label-e','scene2-label-a\'','scene2-arc-a','scene2-arc-c','scene2-angle-a','scene2-angle-c'] },

    { show: [...states[2].show, 'scene2-arc-a\'de','scene2-angle-a\'de'] },
  ```
