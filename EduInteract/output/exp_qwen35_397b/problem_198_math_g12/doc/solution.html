题目原文：

(2011•江门一模) 如图，P是圆O外一点，直线PO与圆O相交于C、D，PA、PB是圆O的切线，切点为A、B．若PC=CD=1，则四边形PADB的面积S=．

题目分析：

本题是圆的切线与割线综合问题，涉及以下核心知识点：

  1. 切线性质：切线垂直于过切点的半径（OA⊥PA，OB⊥PB）
  2. 切线长定理：从圆外一点引圆的两条切线，切线长相等（PA=PB）
  3. 圆的对称性：图形关于直线PO对称
  4. 四边形面积计算：利用对称性将四边形分解为两个全等三角形

整体讲解思路：

  1. 首先识别已知条件：PC=CD=1，CD是直径（因为过圆心O）
  2. 推导半径：r = CD/2 = 0.5，PO = PC + CO = 1 + 0.5 = 1.5
  3. 利用勾股定理求切线长：PA = √(PO² - OA²) = √(1.5² - 0.5²) = √2
  4. 利用对称性：SPADB = 2 × S△PAD
  5. 计算△PAD的面积，需要确定高或利用向量/坐标法

本图示教学说明：

教师应引导学生按以下顺序观察：

  1. 识别基本结构：首先让学生识别这是一个"圆外一点引两条切线"的经典模型，回忆切线的基本性质。
  1. 分析已知条件：
  • PC = CD = 1
  • 关键推论：CD过圆心O，因此CD是直径
  • 半径 r = CD/2 = 0.5
  1. 推导关键长度：
  • CO = OD = 0.5（半径）
  • PO = PC + CO = 1 + 0.5 = 1.5
  • PD = PC + CD = 1 + 1 = 2
  1. 应用切线性质：
  • OA ⊥ PA，OB ⊥ PB（切线垂直于过切点的半径）
  • PA = PB（切线长定理）
  1. 勾股定理求切线长：
  • 在 Rt△POA 中：PA = √(PO² - OA²) = √(1.5² - 0.5²) = √(2.25 - 0.25) = √2
  1. 观察对称性：
  • 图形关于直线PO对称
  • 四边形PADB关于PO对称，因此 SPADB = 2 × S△PAD

本图示教学说明：

面积计算方法一（坐标法）：

  1. 建立坐标系：设O为原点(0,0)，则：
  • C(-0.5, 0)，D(0.5, 0)，P(-1.5, 0)
  1. 求切点A的坐标：
  • 圆方程：x² + y² = 0.25
  • 切线PA的斜率可通过几何关系求得
  • 或利用：OA·PA = 0（垂直）
  1. 利用相似三角形或三角函数：
  • 在Rt△POA中，cos∠POA = OA/PO = 0.5/1.5 = 1/3
  • sin∠POA = PA/PO = √2/1.5 = 2√2/3
  1. 切点A的坐标：
  • A(0.5·cos∠POA, -0.5·sin∠POA) = (0.5×1/3, -0.5×2√2/3) = (1/6, -√2/3)
  1. △PAD的面积（用坐标公式）：
  • P(-1.5, 0)，A(1/6, -√2/3)，D(0.5, 0)
  • S△PAD = ½|×P(yA - yD) + xA(yD - yP) + xD(yP - yA)|
  • = ½|(-1.5)(-√2/3 - 0) + (1/6)(0 - 0) + 0.5(0 - (-√2/3))|
  • = ½|1.5×√2/3 + 0.5×√2/3| = ½|2√2/3| = √2/3
  1. 四边形面积：
  • SPADB = 2 × S△PAD = 2 × √2/3 = 2√2/3

面积计算方法二（几何法）：

  1. 连接AB，四边形PADB = △PAB + △DAB
  1. 或利用：SPADB = S△POA + S△POB + S△DOA + S_△DOB
  1. 最简洁方法：利用对称性和三角函数
  • ∠APD = 2∠APO
  • 在Rt△POA中，sin∠APO = OA/PO = 1/3
  • S_△PAD = ½ × PA × PD × sin∠APD

  • 鼓励学生用多种方法验证答案
  • 强调切线性质的应用：垂直关系和切线长相等
  • 总结此类题目的通用解题策略

最终答案： S = 2√2/3
