[分步序列]
- 初始状态（步骤 0）：显示圆 O（黑色轮廓）、直线 POD（黑色实线从 P 到 D）、切线 PA 和 PB（黑色实线）、线段 AD 和 BD（黑色细线）、所有点 P/O/C/D/A/B（实心黑点）。等待教师触发交互。
- 步骤 1：点击「下一步」→ 显示所有点名称标签（P、O、C、D、A、B），标签按坐标表位置淡入显示。
- 步骤 2：点击「下一步」→ 在 PC 线段上方显示蓝色双箭头标注"PC=1"（位置 317,220），在 CD 线段上方显示蓝色双箭头标注"CD=1"（位置 550,220）。
- 步骤 3：点击「下一步」→ 添加半径 OA 和 OB（绿色实线），在 OA 右侧显示"0.5"标签（540,300），在 OB 右侧显示"0.5"标签（540,200）。
- 步骤 4：点击「下一步」→ 在 A 点处添加红色直角标记（515,340 处 8×8 正方形），在 B 点处添加红色直角标记（515,148 处 8×8 正方形），表示 OA⊥PA、OB⊥PB。
- 步骤 5：点击「下一步」→ 高亮对称轴 PO（蓝色虚线从 P 到 O），展示图形关于 PO 对称。
- 步骤 6：点击「下一步」→ 在 PO 中点下方显示"PO=1.5"标签（375,280），在 PD 中点下方显示"PD=2"标签（434,295）。展示所有已知条件，完成基础图形标注。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 底部左侧（x=350, y=455），点击后回退到上一状态
  - 「下一步」按钮：位于 SVG 底部右侧（x=450, y=455），点击后进入下一状态
  - 状态指示器：位于两按钮之间（x=400, y=460），显示"步骤 X/6"
- 教师操作流程：
  1. 初始状态展示基础图形，教师介绍题目背景
  2. 点击「下一步」显示点名称，教师讲解各点定义
  3. 点击「下一步」显示已知长度 PC=1、CD=1，教师强调已知条件
  4. 点击「下一步」显示半径 OA、OB 及长度 0.5，教师讲解切线性质（半径垂直于切线）
  5. 点击「下一步」显示直角标记，强化垂直关系
  6. 点击「下一步」显示对称轴，教师讲解图形对称性
  7. 点击「下一步」显示 PO=1.5、PD=2，完成所有已知条件标注，准备进入面积计算

[技术实现]
- JS 库选择及原因：原生 SVG。理由：本题为纯几何图形（圆、直线、点），SVG 原生支持这些元素，无需额外库，代码简洁且缩放无损。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |                    B(521,154)                    |
  |                   /        \                     |
  |              PB  /          \  BD                |
  |               /              \                   |
  |    P(200,250)----------------C----O----D(667,250)|
  |               \              /                   |
  |              PA  \          /  AD                |
  |                   \        \                     |
  |                    A(521,346)                    |
  |                                                  |
  |         [PC=1]    [CD=1]                         |
  |                                                  |
  |              [PO=1.5]  [PD=2]                    |
  |                                                  |
  +--------------------------------------------------+
  |              [◀上一步] 步骤 X/6 [下一步▶]         |
  |                   (y=440-490 控件栏)              |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 currentState（0-6），数组存储每步需显示的元素 ID 列表
  2. 坐标计算：所有坐标预先计算好硬编码，避免运行时计算误差
  3. 动画曲线：元素淡入使用 CSS transition opacity 0.3s ease
  4. 事件绑定：按钮点击事件绑定到 updateState() 函数，根据 currentState 显示/隐藏对应元素
  5. 初始状态：所有元素默认 display:none 或 opacity:0，步骤 0 仅显示基础图形元素
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀
  - scene1-circle-o（圆 O）
  - scene1-line-pod（直线 POD）
  - scene1-line-pa（切线 PA）
  - scene1-line-pb（切线 PB）
  - scene1-line-oa（半径 OA）

  - scene1-point-p（点 P）
  - scene1-point-o（点 O）
  - scene1-point-c（点 C）

  - scene1-point-a（点 A）
  - scene1-point-b（点 B）
  - scene1-label-p（标签 P）
  - scene1-label-o（标签 O）
  - scene1-label-c（标签 C）
  - scene1-label-d（标签 D）
  - scene1-label-a（标签 A）
  - scene1-label-b（标签 B）
  - scene1-anno-pc（标注 PC=1）
  - scene1-anno-cd（标注 CD=1）
  - scene1-anno-oa（标注 OA=0.5）
  - scene1-anno-ob（标注 OB=0.5）
  - scene1-rect-a（直角标记 A）
  - scene1-rect-b（直角标记 B）
