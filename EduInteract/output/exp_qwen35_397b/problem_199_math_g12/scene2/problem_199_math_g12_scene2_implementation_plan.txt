[图示主题与整合说明]
- 本图示主题：奇偶性对比验证——t 与 -t 情况下△OMN 面积相等
- 整合的步骤/概念：同时展示 t>0、t=0、t<0 三种状态，通过并置对比验证 S(t) = S(-t)，证明 f(t) 是偶函数
- 教学价值：教师可通过切换按钮直观展示直线位置变化与三角形面积的关系，学生能清晰观察到对称性，理解偶函数的几何意义

[交互方案]
- 交互类型：多状态切换（3 个按钮）
- 控件说明：
  - 按钮 1「t>0」：位置 (285,405)，显示状态 0（上方直线及△OMN）
  - 按钮 2「t=0」：位置 (385,405)，显示状态 1（直线过原点）
  - 按钮 3「t<0」：位置 (485,405)，显示状态 2（下方直线及对称三角形）
- 教师操作流程：
  1. 初始点击「t>0」，展示直线在上方时的三角形
  2. 点击「t=0」，展示直线过原点时面积为 0
  3. 点击「t<0」，同时展示两种情况，通过虚线对称连线和面积数值对比，直观验证 S(t) = S(-t)
  4. 引导学生观察对称关系，得出偶函数结论

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +------------------------------------------+
  |                    y                     |
  |                    ↑                     |
  |              E ____|____ D               |
  |           F /    / | \    \ C            |
  |     ------/----/--O--\----\------ x      |
  |         /    /   |   \    \              |
  |       A /____/___ | ___\____\ B          |
  |                    |                     |
  |                                        L₁|
  |                                          |
  |                                          |
  |                                        L₂|
  |                                          |

  |                                          |
  |     面积显示区 (右上)                     |
  |                                          |
  |     [结论框：S(t)=S(-t) ∴ f(t)是偶函数]   |
  +------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentState (0/1/2) 跟踪当前状态
  2. 坐标转换：数学坐标 (x,y) 转画布坐标 (canvasX, canvasY)：
     - canvasX = 400 + x
     - canvasY = 250 - y
  3. 交点计算：直线 y = kx + t 与六边形各边求交，取有效交点
  4. 三角形面积：用向量叉积公式 S = 0.5 × |x₁y₂ - x₂y₁|
  5. 事件绑定：三个按钮分别绑定点击事件，切换状态时更新所有元素 display 属性
  6. 动画过渡：可选添加 opacity 过渡效果（0.3s）
- ID 命名规范：所有元素 ID 以 scene2- 为前缀
  - scene2-axis-x, scene2-axis-y
  - scene2-hexagon, scene2-vertex-a, ..., scene2-vertex-f
  - scene2-origin-o
  - scene2-line-l1, scene2-line-l2, scene2-line-zero
  - scene2-point-m1, scene2-point-n1, scene2-point-m2, scene2-point-n2
  - scene2-tri-om1n1, scene2-tri-om2n2
  - scene2-sym-m1m2, scene2-sym-n1n2
  - scene2-label-m1, scene2-label-n1, scene2-label-m2, scene2-label-n2
  - scene2-label-l1, scene2-label-l2
  - scene2-area-display, scene2-area-st, scene2-area-snt
  - scene2-conclusion-box, scene2-conclusion-text
  - scene2-btn-t-pos, scene2-btn-t-zero, scene2-btn-t-neg
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
