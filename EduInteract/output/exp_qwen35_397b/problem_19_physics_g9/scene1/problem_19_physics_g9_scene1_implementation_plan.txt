[分步序列]

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于(280,455)，100×35px，灰色背景#9e9e9e，白色文字，步骤0时禁用
  - 「下一步」按钮：位于(420,455)，100×35px，蓝色背景#1976d2，白色文字，步骤3时禁用
  - 步骤指示器：位于(550,470)，显示"步骤 X/4"，黑色文字#212121
- 教师操作流程：
  1. 初始加载显示步骤0（原电路图），教师介绍题目背景
  2. 点击「下一步」到步骤1，标注电流方向，讲解电流路径
  3. 点击「下一步」到步骤2，展示等效变换，讲解并联结构
  4. 点击「下一步」到步骤3，标注电阻分段，讲解电阻与长度关系
  5. 可随时点击「上一步」回退复习关键概念

[技术实现]
- JS库选择：原生SVG（电路图为几何图形，无需复杂库，轻量且易控制）
- 画布尺寸：800×500px（固定）
- 布局草图（ASCII）：
  ```
  [800×500 画布]
  +--------------------------------------------------+
  |  [原电路图区 380×340]    [等效电路图区 340×340]  |
  |   电源/开关/铅笔芯         标准并联电路           |
  |   A1/A2/滑片P             R_AP/R_PB标注          |
  |                                                  |
  |                                                  |
  |                                                  |
  |              [控件栏 400×50]                     |
  |         [◀上一步]  [下一步▶]  步骤X/4            |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量currentStep(0-3)跟踪当前步骤，每步对应一组显示/隐藏的元素ID
  2. 元素分组：将SVG元素按步骤分组，用class="step0"、"step1"等标记，通过CSS display控制显示
  3. 按钮状态：步骤0时禁用上一步，步骤3时禁用下一步，用opacity和pointer-events控制
  4. 动画过渡：步骤切换时用CSS transition实现淡入淡出（opacity 0→1，时长300ms）
  5. 事件绑定：按钮点击事件绑定到stepChange函数，更新currentStep并刷新显示状态
- ID命名规范：所有元素ID以"scene1-"为前缀，例如：
  - scene1-original-frame（原图外框）
  - scene1-equivalent-frame（等效图外框）
  - scene1-pencil-ab（铅笔芯）
  - scene1-slider-p（滑片P）
  - scene1-ammeter-a1（电流表A1）
  - scene1-ammeter-a2（电流表A2）
  - scene1-current-arrow-1（电流箭头1）
  - scene1-label-a（A标签）
  - scene1-label-r-ap（R_AP标签）
  - scene1-btn-prev（上一步按钮）
  - scene1-btn-next（下一步按钮）
- IIFE隔离：所有JS代码包在(function() { ... })()中，避免全局变量污染
- CDN引入：无需额外库，使用原生SVG和JavaScript
