[分步序列]
- 初始状态（步骤 0）：显示铅笔芯 AB、c/d 边界、空数值面板、空白曲线图坐标轴
- 步骤 1：滑片 P 出现在中点位置，显示当前 x 值和 I₁/I₂ 比值
- 步骤 2：显示 R_AP 和 R_PB 电阻条形图，条形长度随 P 位置动态变化
- 步骤 3：绘制完整的 I₁/I₂ 函数曲线，标注 c、d 对应的曲线点
- 步骤 4：高亮 c-d 范围区域，显示该范围内比值的变化区间
- 最终步骤：所有元素完整显示，教师可自由拖动滑片观察实时变化

- "R_AP"与"R_PB"：水平距离 140px → 无冲突

- 所有标签间距均 ≥ 20px，无重叠风险

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：
  - 滑片 P：可沿铅笔芯 AB 水平拖拽，范围 x ∈ [0, 640]px
  - 数值面板：实时显示当前 x 位置 (cm)、I₁/I₂ 比值、当前量程
  - 分步按钮：「◀ 上一步」「下一步 ▶」位于底部控件栏
- 教师操作流程：
  1. 点击「下一步」逐步展示各元素
  2. 拖动滑片 P 从 A 向 B 移动，观察 I₁/I₂ 比值变化
  3. 停在 c、d 位置，讲解边界条件
  4. 结合曲线图说明函数关系 I₁/I₂ = (L-x)/x

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形和交互，无需重型库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────┐
  │  [数值面板]                    [铅笔芯 AB 与滑片 P]  │
  │  x = ...                       A====P====B         │
  │  I₁/I₂ = ...                   [c]====[d]          │
  │  量程：0-3A                                        │
  │                                                     │
  │  [电阻条形图]                  [比值曲线图]        │
  │  R_AP ████                     y↑                  │
  │  R_PB ████████                   │    ╱            │
  │                                  │  ╱              │
  │                                  │╱                │
  │                                  └──────────→x     │
  │                                                     │
  │            [◀ 上一步]      [下一步 ▶]              │
  └─────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用 step 变量 (0-4) 控制分步显示，用 dragState 控制拖拽状态
  2. 坐标计算：铅笔芯总长 L=640px 对应实际长度（根据题目 c-d=12cm 推算比例）
  3. 函数曲线：预计算 50 个点，用 SVG path 绘制 I₁/I₂ = (L-x)/x 双曲线
  4. 事件绑定：滑片 P 绑定 mousedown/mousemove/mouseup 实现拖拽
  5. 实时更新：拖拽时同步更新数值面板、电阻条形图、曲线上的标记点
- ID 命名规范：所有元素 ID 以 scene2- 为前缀，如 scene2-pencil、scene2-slider-p、scene2-curve 等
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
