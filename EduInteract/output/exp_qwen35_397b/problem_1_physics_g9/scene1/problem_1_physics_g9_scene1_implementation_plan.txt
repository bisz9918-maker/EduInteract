[图示主题与整合说明]
- 本图示主题：杠杆平衡条件与力臂比较分析
- 整合的内容：杠杆结构展示 + 四个力的方向 + 各力力臂绘制与比较 + 最小力判定结论
- 教学价值：教师可使用此图示逐步讲解杠杆平衡条件，通过动态展示力臂概念，帮助学生理解"力臂越大，所需力越小"的物理原理。分步导航让教师能按课堂节奏控制讲解进度，从基础结构到力臂比较再到结论得出，符合认知规律。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于 (280,450)，点击后返回上一状态，步骤 0 时禁用
  - 「下一步 ▶」按钮：位于 (420,450)，点击后进入下一状态，步骤 4 时禁用
- 教师操作流程：
  1. 图示加载后显示步骤 0（杠杆基础结构），教师介绍杠杆 OAB、支点 O、重物 G
  2. 点击「下一步」进入步骤 1，显示四个力，教师讲解在 B 点可施加不同方向的力
  3. 点击「下一步」进入步骤 2，高亮 F3 并显示其力臂 l3=OB，教师讲解 F3 竖直向上时力臂最大
  4. 点击「下一步」进入步骤 3，显示其他力的力臂，教师对比 l1、l2、l4 均小于 l3
  5. 点击「下一步」进入步骤 4，显示结论，教师总结"力臂越大，所需力越小"，故 F3 最小

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：本图示为 2D 几何图形，无需复杂库；原生 SVG 可精确控制坐标，便于力臂垂线绘制
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +----------------------------------------------------------+
  |                                                          |
  |   O        A                    F4 F3 F2                 |
  |   △--------●--------------------↖ ↑ ↗                    |
  |   |        |                      |                      |
  |   |        |                      ↓ F1                   |
  |   |        ▓▓▓                    |                      |
  |   |        ▓ G ▓                  |                      |
  |   |        ▓▓▓                    |                      |
  |                                                          |
  |              [l3 蓝色力臂 = OB]                          |
  |         [l1/l2/l4 红色虚线力臂]                          |
  |                                                          |
  |        ┌────────────────────────────┐                    |
  |        │   F₃力臂最大 → F₃最小      │                    |
  |        └────────────────────────────┘                    |
  |                                                          |
  |           [◀ 上一步]    [下一步 ▶]                       |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-4) 跟踪当前步骤，steps 数组存储每步的显示配置
  2. 坐标计算：力臂垂足通过几何计算得出（点到直线距离公式）
  3. 动画曲线：元素显示/隐藏使用 CSS transition，opacity 从 0 到 1，时长 300ms
  4. 事件绑定：按钮点击事件绑定到 stepChange 函数，更新 currentStep 并重新渲染
  5. 元素分组：使用 SVG <g> 元素按步骤分组，通过 display 属性控制显示/隐藏
- ID 命名规范：
  - 所有交互元素 ID 必须以 scene1- 为前缀
  - 示例：scene1-lever（杠杆）、scene1-fulcrum（支点）、scene1-weight-g（重物）、scene1-f1-arrow（F1 箭头）、scene1-l3-arm（l3 力臂）、scene1-btn-prev（上一步按钮）、scene1-btn-next（下一步按钮）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
- 垂足计算（供代码参考）：
  - F3 竖直向上，作用线为 x=700，O(100,200) 到该线的垂足为 (700,200)，即 B 点
  - F1 方向向量 (50,50)，作用线方程 y-200 = 1*(x-700)，即 y = x - 500
  - F2 方向向量 (50,-50)，作用线方程 y-200 = -1*(x-700)，即 y = -x + 900
  - F4 方向向量 (-50,-50)，作用线方程 y-200 = 1*(x-700)，即 y = x - 500（与 F1 同斜率但方向相反）
