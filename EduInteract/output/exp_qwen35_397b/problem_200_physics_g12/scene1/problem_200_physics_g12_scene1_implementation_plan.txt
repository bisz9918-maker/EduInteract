- 本图示主题：初始状态与压强平衡分析
- 整合的内容：题目原图复现 + 各部分压强标注 + 压强叠加推导过程

[分步序列]
- 初始状态（步骤 0）：显示容器轮廓、活塞、水银区域（斜线填充）、封闭气体（浅蓝填充）、尺寸标注 h₁=5cm、h₂=10cm、L=112cm、A/B 标签、力 F 箭头及标签
- 步骤 1：高亮显示大气压 p₀——在活塞上方出现向下绿色箭头，左侧显示"p₀=75cmHg"标签，同时活塞上表面高亮（加粗边框）
- 步骤 2：展示 A 管水银柱产生的压强——在 A 管水银区域右侧出现"p₀+h₁=80cmHg"标签，A 管水银区域边框高亮，同时从活塞下表面到 A 管水银底部出现绿色压强传递箭头
- 步骤 3：展示 B 管水银柱产生的压强——在 B 管右侧出现"p₀+h₁+h₂=90cmHg"标签，B 管水银区域边框高亮，压强传递箭头延伸到 B 管水银底部
- 步骤 4：得出封闭气体压强——在封闭气体区域右侧显示最终结论"p₁=90cmHg"，封闭气体区域边框高亮（#2e7d32 绿色，stroke-width=3），同时显示压强平衡公式"p₁ = p₀ + h₁ + h₂ = 75 + 5 + 10 = 90 cmHg"在画布底部

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于底部左侧，点击返回上一状态
  - 「下一步」按钮：位于底部右侧，点击进入下一状态
  - 步骤指示器：位于两按钮之间，显示"步骤 X/5"
- 教师操作流程：
  1. 初始状态展示题目条件，让学生观察容器结构
  2. 点击「下一步」高亮大气压，讲解 p₀作用于活塞上表面
  3. 点击「下一步」展示 A 管水银柱压强，讲解 p₀+h₁的推导
  4. 点击「下一步」展示 B 管水银柱压强，讲解压强叠加
  5. 点击「下一步」得出封闭气体压强，总结压强平衡公式

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                    F↑                            |
  |              ┌────────────┐                      |
  |         p₀↓  │   活塞     │ A    h₁              |
  |              ├────────────┤                      |
  |              │░░░░░░░░░░░░│                      |
  |              │░░A 管水银░░│                      |
  |              └──────┬─────┘                      |
  |               B    │h₂   │B 管水银░░             |
  |                    │░░░░░│                      |
  |                    │气体 │ L                     |
  |                    │     │                      |
  |                    └─────┘         p₁           |
  |                                                  |
  |              [◀上一步] 步骤 1/5 [下一步▶]        |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-4），数组存储每步需显示的元素 ID
  2. 元素分组：将相关元素按步骤分组，如 step1Elements = ['p0-arrow', 'p0-label']
  3. 动画效果：使用 CSS transition 实现 opacity 渐变（0.3s ease-in-out）
  4. 事件绑定：按钮点击事件切换状态，更新元素 display/opacity 属性
  5. 边界检查：第一步禁用「上一步」，最后一步禁用「下一步」
- ID 命名规范：所有元素 ID 以 scene1- 为前缀，如 scene1-container-a、scene1-mercury-a、scene1-label-h1
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
