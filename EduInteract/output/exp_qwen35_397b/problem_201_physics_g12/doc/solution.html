problem_201_physics_g12

场景导航：Scene 1 | Scene 2 | Scene 3

题目原文：

如图所示，质量为 m，带电量为 q 的粒子，以初速度 v₀，从 A 点竖直向上射入真空中的沿水平方向的匀强电场中，粒子通过电场中 B 点时，速率 v_B = 2v₀，方向与电场的方向一致，问：
（1）水平方向和竖直方向分别作什么运动？
（2）从 A 到 B 竖直方向位移是多少？
（3）从 A 到 B 重力做的功是多少？
（4）从 A 到 B 电场力做的功是多少？
（5）A、B 两点的电势差是多少？

题目分析：

本题是带电粒子在重力场和匀强电场复合场中的运动问题。粒子同时受重力（竖直向下）和电场力（水平方向）作用，运动可分解为：

  • 竖直方向：竖直上抛运动（只受重力）
  • 水平方向：初速为零的匀加速直线运动（只受电场力）

B 点速度方向与电场方向一致，说明此时竖直分速度为零，即 B 点是竖直上抛的最高点。

整体讲解思路：

  1. 首先展示复合场环境和粒子运动轨迹
  2. 分解运动：水平匀加速 + 竖直上抛
  3. 利用 B 点速度条件确定运动时间
  4. 分别计算位移、功和电势差

图示规划说明：

  • SCENE_1：复合场环境与运动轨迹（整合电场线、轨迹、A/B 位置、速度矢量）
  • SCENE_2：受力分析与运动分解（整合受力图、分运动示意、速度变化）
  • SCENE_3：能量与功的关系（整合重力做功、电场力做功、动能定理）
步骤 1/5

教学说明：

本图示帮助学生建立粒子在复合场中运动的直观图像。

引导学生观察：

  1. 电场方向水平向右，粒子带正电（由运动方向判断）
  2. 轨迹是曲线，说明粒子同时参与两个方向的运动
  3. A 点速度竖直向上，B 点速度水平向右
  4. B 点是轨迹的"转折点"，竖直分速度为零

关键公式：

竖直方向（竖直上抛）：

  • v_y = v₀ - gt
  • 在 B 点：v_y = 0，得 t = v₀/g

水平方向（匀加速直线运动）：

  • vx = ax · t
  • 在 B 点：v_x = 2v₀
步骤 0/4

教学说明：

本图示核心是让学生理解"运动的独立性原理"——两个方向的运动互不影响，可分别分析。

讲解要点：

  1. 受力决定加速度：
  • 竖直方向：只受重力，加速度为 g（向下）
  • 水平方向：只受电场力，加速度 a_x = qE/m（向右）
  1. 运动性质判断：
  • 竖直方向：初速度 v₀ 向上，加速度 g 向下 → 竖直上抛运动
  • 水平方向：初速度为 0，加速度 a_x 恒定 → 初速为零的匀加速直线运动
  1. B 点的特殊性：
  • B 点速度方向水平，说明竖直分速度 v_y = 0
  • 即 B 点是竖直上抛的最高点

推导时间 t：

竖直方向：v_y = v₀ - gt = 0

得：t = v₀ / g

推导水平加速度：

水平方向：vx = ax · t = 2v₀

代入 t：a_x = 2v₀ / t = 2v₀ / (v₀/g) = 2g

教学说明：

本图示整合了题目 5 个小问的完整解答过程，帮助学生建立从运动学到能量学的完整认知链条。

完整解答：

（1）水平方向和竖直方向分别作什么运动？

  • 竖直方向：竖直上抛运动（初速度 v₀ 向上，加速度 g 向下）
  • 水平方向：初速度为零的匀加速直线运动（加速度 a_x = qE/m 向右）

（2）从 A 到 B 竖直方向位移是多少？

竖直方向用速度位移公式：

  • v_y² - v₀² = -2gh
  • 0 - v₀² = -2gh
  • h = v₀² / (2g)

（3）从 A 到 B 重力做的功是多少？

重力做功：

  • W_G = -mgh = -mg · v₀²/(2g) = -mv₀²/2

（负号表示重力做负功，粒子克服重力上升）

（4）从 A 到 B 电场力做的功是多少？

用动能定理：W合 = ΔEk

  • 初动能：E_kA = (1/2)mv₀²
  • 末动能：E_kB = (1/2)m(2v₀)² = 2mv₀²
  • 动能变化：ΔE_k = 2mv₀² - (1/2)mv₀² = (3/2)mv₀²

合力做功 = 重力做功 + 电场力做功：

  • WG + We = ΔE_k
  • -mv₀²/2 + W_e = (3/2)mv₀²
  • W_e = 2mv₀²

（5）A、B 两点的电势差是多少？

电场力做功与电势差关系：

  • We = qUAB
  • UAB = We / q = 2mv₀² / q

课堂讲解建议：

  1. 先让学生观察图像，判断粒子带正电还是负电
  2. 强调运动分解思想：两个方向独立分析
  3. B 点速度方向是关键突破口（竖直分速度为零）
  4. 第（4）（5）问用动能定理最简洁，避免求水平位移
