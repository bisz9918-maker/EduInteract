[图示主题与整合说明]
- 本图示主题：带电粒子在复合场中的运动轨迹
- 整合内容：匀强电场环境、粒子从 A 到 B 的运动轨迹、A 点和 B 点的速度矢量、坐标参考系

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 底部左侧 (x=50, y=455)，返回上一状态
  - 「下一步」按钮：位于 SVG 底部右侧 (x=700, y=455)，进入下一状态
  - 步骤指示器：位于底部中央 (x=400, y=455)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始展示电场环境和 A、B 位置，讲解复合场背景
  2. 点击「下一步」展示轨迹，讲解粒子运动路径
  3. 点击「下一步」展示 v₀，讲解竖直方向初速度
  4. 点击「下一步」展示 v_B，讲解水平方向末速度
  5. 点击「下一步」展示坐标系，讲解运动分解方法

[技术实现]
- JS 库选择：原生 SVG（简单几何图形和箭头，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  ┌────────────────────────────────────────────┐
  │  E 电场线区域 (y=80~400)                   │
  │                                            │
  │         B●────→v_B                         │
  │          ╲                                 │
  │           ╲ 轨迹                           │
  │            ╲                               │
  │             ╲                              │
  │              ●A↑v₀                         │
  │                                            │
  │         x 轴→  y 轴↑                       │
  │                                            │
  │  [◀上一步]    步骤 X/5    [下一步▶]        │
  └────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用 currentStep 变量 (0-4) 跟踪当前步骤，steps 数组存储每步应显示的元素 ID 列表
  2. 轨迹绘制：使用 SVG <path> 的二次贝塞尔曲线，控制点设在 A、B 中点偏左上方，使曲线呈抛物线形状
  3. 箭头绘制：定义 <marker>  reusable 箭头，用于电场线、轨迹末端、速度矢量
  4. 事件绑定：按钮点击事件切换 currentStep，调用 updateDisplay() 函数显示/隐藏对应元素
  5. 动画效果：轨迹和矢量使用 CSS transition 实现淡入效果 (opacity: 0→1, 0.3s)
- ID 命名规范：所有元素 ID 以 scene1- 为前缀，如 scene1-field-line-1、scene1-point-a、scene1-velocity-v0、scene1-axis-x
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
