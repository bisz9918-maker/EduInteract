[图示主题与整合说明]
- 本图示主题：带电粒子在复合场中的运动——位移、功与电势差的计算

[分步序列]
步骤0（初始状态）：
- 显示：5条电场线、A点、B点、运动轨迹曲线、v0箭头、vB箭头
- 显示：竖直投影虚线、水平投影虚线
- 显示：竖直位移h双向箭头及标签"h"、水平位移x双向箭头及标签"x"
- 显示：标签"A"、"B"
- 公式框1-5：隐藏
- 步骤指示："步骤 0/5"

步骤1（点击"下一步"）：
- 保持步骤0所有元素
- 显示公式框1（竖直位移计算）：
  - 标题："竖直方向：竖直上抛运动"
  - 公式：h = v₀²/(2g)
- 步骤指示："步骤 1/5"

步骤2（点击"下一步"）：
- 保持步骤1所有元素
- 显示公式框2（重力做功）：
  - 标题："重力做功"
  - 公式：W_G = -mgh = -mg·v₀²/(2g) = -½mv₀²
- 步骤指示："步骤 2/5"

步骤3（点击"下一步"）：
- 保持步骤2所有元素
- 显示公式框3（电场力做功）：
  - 标题："电场力做功（动能定理）"
  - 公式：W_e = ΔE_k - W_G = ½m(2v₀)² - ½mv₀² - (-½mv₀²) = 2mv₀² - ½mv₀² + ½mv₀² = ³/₂mv₀²
- 步骤指示："步骤 3/5"

步骤4（点击"下一步"）：
- 保持步骤3所有元素
- 显示公式框4（电势差）：
  - 标题："A、B电势差"
  - 公式：U_AB = W_e/q = (³/₂mv₀²)/q = ³mv₀²/(2q)
- 步骤指示："步骤 4/5"

步骤5（点击"下一步"）：
- 保持步骤4所有元素
- 显示公式框5（结论汇总）：
  - 标题："结论汇总"
  - 内容：h=v₀²/(2g) | W_G=-½mv₀² | W_e=³/₂mv₀² | U_AB=³mv₀²/(2q)
- 步骤指示："步骤 5/5"
- 高亮运动轨迹（线宽增至3px，颜色加深）

[交互方案]

- 控件说明：
  - 上一步按钮：位于(250,455)，尺寸80×30px，点击后返回上一状态（步骤0时禁用）
  - 下一步按钮：位于(470,455)，尺寸80×30px，点击后进入下一状态（步骤5时禁用）
  - 步骤指示器：位于(360,460)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始状态展示粒子运动轨迹和位移标注，引导学生观察运动分解
  2. 点击"下一步"逐步显示各物理量的计算公式
  3. 每步停留讲解公式推导过程
  4. 可随时点击"上一步"回顾前序步骤
  5. 最终步骤汇总所有结论，强化知识链条

[技术实现]
- JS库选择：原生SVG + 原生JavaScript
  - 原因：几何图形简单（电场线、点、曲线、箭头），无需复杂库；原生SVG便于精确控制坐标和样式
- 画布尺寸：800×500px（固定）
- 布局草图：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │  [左侧图形区 350×400]          [右侧公式区 380×340]        │
  │  ┌─────────────┐              ┌──────────────────┐         │
  │  │  电场线     │              │ 公式框1: 位移    │         │
  │  │  A→B轨迹    │              │ 公式框2: 重力功  │         │
  │  │  h、x标注   │              │ 公式框3: 电场力功│         │
  │  │             │              │ 公式框4: 电势差  │         │
  │  │             │              │ 公式框5: 结论    │         │
  │  └─────────────┘              └──────────────────┘         │
  │                                                             │
  │  ┌─────────────────────────────────────────────────────┐   │
  │  │      [◀上一步]    步骤 X/5    [下一步▶]            │   │
  │  └─────────────────────────────────────────────────────┘   │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-5) 跟踪当前步骤，steps数组存储每步的可见元素ID列表
  2. 坐标计算：所有元素坐标硬编码，确保与布局表一致
  3. 动画曲线：公式框淡入用 CSS transition: opacity 0.3s ease
  4. 事件绑定：按钮点击事件绑定到 updateStep() 函数，更新可见性和步骤指示
  5. 按钮禁用状态：步骤0时禁用"上一步"，步骤5时禁用"下一步"（opacity:0.5, pointer-events:none）
- ID命名规范：
  - 所有元素ID以 scene3- 为前缀
  - 示例：scene3-point-a, scene3-point-b, scene3-trajectory, scene3-arrow-h, scene3-formula-box-1, scene3-btn-prev, scene3-btn-next
- IIFE隔离：所有JS代码包裹在 (function() { ... })() 中，避免全局变量污染
- 公式渲染：使用 SVG text 元素，数学符号用 Unicode 字符（如 ½ ³/₂）或简单HTML实体
