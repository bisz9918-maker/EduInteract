[图示主题与整合说明]
- 本图示主题：带电粒子在电场中的类平抛运动轨迹分析
- 整合的步骤/概念：整合了粒子从 A 点出发→第Ⅱ象限运动→穿越 x 轴→第Ⅲ象限运动→到达 A'点沿水平方向进入磁场的完整电场运动过程
- 教学价值：教师可使用此图示分步展示带电粒子在交变电场中的运动轨迹，帮助学生理解类平抛运动的分解方法、电场力对粒子运动的影响、以及对称性在解题中的应用。分步导航让教师可以逐阶段讲解，学生可以清晰看到每个阶段的运动特征。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 内底部左侧 (x=350, y=460)，点击后回退到前一状态
  - 「下一步」按钮：位于 SVG 内底部右侧 (x=450, y=460)，点击后进入下一状态
  - 步骤指示器：位于两按钮之间 (x=400, y=460)，显示当前步骤编号（如"步骤 2/4"）
- 教师操作流程：
  1. 初始加载后，教师先讲解坐标系和电场区域设置（步骤 0）
  2. 点击「下一步」展示电场方向和初速度，讲解粒子受力情况（步骤 1）
  3. 点击「下一步」展示第Ⅱ象限轨迹，讲解类平抛运动的分解（步骤 2）
  4. 点击「下一步」展示完整轨迹，讲解对称性（步骤 3）
  5. 点击「下一步」展示 A'点和磁场区域，讲解粒子进入磁场的状态（步骤 4）
  6. 可随时点击「上一步」回退复习关键概念

[技术实现]
- JS 库选择及原因：原生 SVG。理由：本题为 2D 几何图形和简单曲线（抛物线），原生 SVG 足够实现，无需引入重型库，代码简洁且易于控制每个元素的显示/隐藏状态。
- 画布尺寸：800×500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                    y 轴                           |
  |                    |                              |
  |      电场区        |      磁场区                   |
  |   x=-2L   Ⅱ象限    |      Ⅰ象限                    |
  |    |      ↑E       |      ×××                     |
  |    |      | 轨迹   |      ×××                     |
  | A  o----->v₀      \|/     ×××                     |
  |    |      \        |------------------------------| x 轴
  | C  o-------\-------o------ |      ×××             |
  |    |        \      |       |      ×××             |
  |    |         \     |       |      ×××             |
  |    |          \    |       |                      |
  |    |           \   |       |                      |
  |    |            \  |       |                      |
  |    |             \ |       |                      |
  |    |              \|       |                      |
  |    |               o A'    |                      |
  |    |              ->v₀     |                      |
  |                    |                              |
  +--------------------------------------------------+
  |        [◀上一步]  步骤 2/4  [下一步▶]              |
  |              (控件栏 y=440~490)                    |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-4），每个状态对应显示的元素集合
  2. 元素分组：将 SVG 元素按步骤分组，使用 class="step-0"、"step-1"等标识
  3. 抛物线绘制：使用 SVG <path> 元素，通过二次贝塞尔曲线或多次线段逼近抛物线形状
     - 第Ⅱ象限轨迹：从 (380,180) 到 (450,250)，控制点根据类平抛运动公式计算
     - 第Ⅲ象限轨迹：从 (450,250) 到 (520,320)，对称设计
  4. 事件绑定：为按钮添加 click 事件监听器，更新 currentState 并调用 render() 函数
  5. 动画效果：轨迹显示可使用 stroke-dasharray 和 stroke-dashoffset 实现绘制动画
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀
  - scene1-axis-x, scene1-axis-y, scene1-boundary-left
  - scene1-point-a, scene1-point-c, scene1-point-aprime, scene1-point-mid
  - scene1-e-field-1~6, scene1-b-field-1~9
  - scene1-trajectory-part1, scene1-trajectory-part2
  - scene1-velocity-a, scene1-velocity-aprime
  - scene1-label-a, scene1-label-c, scene1-label-o, scene1-label-aprime
  - scene1-btn-prev, scene1-btn-next, scene1-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
