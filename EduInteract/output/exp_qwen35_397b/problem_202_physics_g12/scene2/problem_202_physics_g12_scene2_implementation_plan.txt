[图示主题与整合说明]
- 本图示主题：带电粒子在磁场中的圆周运动及返回轨迹
- 整合内容：整合了粒子从 A'点进入磁场→做圆周运动→穿出磁场→在电场中运动→返回 x=-2L 的完整过程
- 教学价值：教师可分步展示带电粒子在匀强磁场中做匀速圆周运动的几何关系（圆心、半径、轨迹弧），以及粒子穿出磁场后在电场中的类抛体运动返回过程，帮助学生理解电磁场中粒子运动的完整轨迹和几何特征

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 内底部左侧 (x=320, y=460)，返回上一步状态
  - 「下一步」按钮：位于 SVG 内底部右侧 (x=480, y=460)，进入下一步状态
  - 步骤指示器：位于两按钮之间 (x=400, y=460)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始状态展示题目基础条件（坐标系、场区、A'点入射）
  2. 点击「下一步」展示圆心和半径，讲解洛伦兹力提供向心力
  3. 点击「下一步」展示圆周轨迹，讲解半径公式 R=mv/qB
  4. 点击「下一步」展示穿出点，讲解几何关系
  5. 点击「下一步」展示返回轨迹和最终位置，讲解电场中的类抛体运动

[技术实现]
- JS 库选择：原生 SVG（适合几何图形、圆弧、路径绘制，无需额外库）
- 画布尺寸：800×500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                    y 轴                          |
  |         电场区      |      磁场区 (×填充)        |
  |      (电场线)       |                            |
  |                     |                            |
  |----------x 轴-------O------------------->        |
  |                     |                            |
  |      A'●→v₀    圆心●----R----                    |
  |           \         )  圆周轨迹                  |
  |            \       )                             |
  |             \     ) P●                           |
  |              \   /                               |
  |               \ /  返回轨迹                      |
  |                \ /                               |
  |  返回点 F●------\/-------------------------------|
  |  (−2L,−1.6L)                                     |
  |                                                  |
  |     [◀上一步]   步骤 3/5   [下一步▶]            |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用 currentState 变量 (0-4) 跟踪当前步骤，steps 数组存储每步需显示的元素 ID 列表
  2. 坐标计算：圆心 x = A'x + R = 520 + 80 = 600，圆心 y = A'y = 330；穿出点 P 用三角函数计算
  3. 圆弧绘制：使用 SVG <path> 的 A 命令绘制圆弧，从 A'点逆时针到 P 点
  4. 返回轨迹：使用 SVG <path> 的 Q 或 C 命令绘制抛物线近似曲线
  5. 事件绑定：按钮点击事件切换 currentState，调用 updateDisplay() 函数显示/隐藏对应元素
  6. ×符号填充：用循环生成 30 个<text>元素，均匀分布在磁场区域
- ID 命名规范：所有元素 ID 以 scene2- 为前缀，如 scene2-x-axis、scene2-y-axis、scene2-point-A'、scene2-circle-center、scene2-arc-trajectory、scene2-return-path、scene2-btn-prev、scene2-btn-next
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
