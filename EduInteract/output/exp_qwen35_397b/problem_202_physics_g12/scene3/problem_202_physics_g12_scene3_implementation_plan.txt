[图示主题与整合说明]
- 本图示主题：AC 间不同位置粒子轨迹对比与对称性分析
- 整合内容：整合从 AC 连线上三个典型位置（A 点、AC 中点、C 点上方某位置）出发的粒子在电场中的运动轨迹，对比展示哪些位置的粒子能沿 x 轴正方向水平进入磁场
- 教学价值：教师可通过状态切换对比不同初始位置对应的轨迹特征，帮助学生理解粒子在交变电场中的运动规律，掌握"能水平出射"的对称性条件，为后续求解第 (3) 问做铺垫

[分步序列]
多状态切换交互（3 个状态）：

状态 0（初始）：显示坐标系、电场区域、磁场区域、AC 连线、A 点和 C 点标记，不显示任何轨迹

状态 1（点击"状态 1:A 点"）：
- 显示轨迹 1：从 A(380,190) 出发的#1565c0 实线曲线，经电场偏转后从 A'(500,310) 水平向右进入磁场
- 在 A 点显示初速度箭头 v₀
- 在出射点 A'显示水平向右箭头
- 状态标签显示："能水平出射"
- 轨迹 2、3 隐藏

状态 2（点击"状态 2:AC 中点"）：
- 隐藏轨迹 1，显示轨迹 2：从 AC 中点 (380,220) 出发的#888888 虚线曲线
- 出射方向非水平（斜向下）
- 在出射点显示斜向箭头
- 状态标签显示："不能水平出射"
- 轨迹 1、3 隐藏

状态 3（点击"状态 3:对称位置"）：
- 隐藏轨迹 2，同时显示轨迹 1 和轨迹 3
- 轨迹 3：从 (380,235) 出发的#1565c0 实线曲线，能水平出射
- 用虚线连接轨迹 1 和轨迹 3 的初始位置，标注对称关系
- 状态标签显示："能水平出射（对称位置）"
- 突出显示两条有效轨迹的对称性

[交互方案]
- 交互类型：多状态切换（3 个按钮）
- 控件说明：
  - 按钮 1"状态 1:A 点"：位于 (120,460)，显示从 A 点出发的粒子轨迹
  - 按钮 2"状态 2:AC 中点"：位于 (220,460)，显示从 AC 中点出发的粒子轨迹
  - 按钮 3"状态 3:对称位置"：位于 (340,460)，同时显示两条能水平出射的轨迹并标注对称关系
  - 状态指示文本：位于 (500,465)，显示当前状态说明
- 教师操作流程：
  1. 初始状态展示题目基本设置（坐标系、电场、磁场区域）
  2. 点击"状态 1"展示 A 点粒子轨迹，讲解为何能水平出射
  3. 点击"状态 2"对比 AC 中点粒子轨迹，说明为何不能水平出射
  4. 点击"状态 3"展示对称位置的粒子也能水平出射，引导学生发现规律
  5. 通过对比帮助学生理解第 (3) 问的对称性条件

[技术实现]
- JS 库选择：原生 SVG（简单几何图形和路径，无需额外库）
- 画布尺寸：800×500px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                    y 轴                          |
  |   x=-2L   电场区      磁场区 (×××)               |
  |    |      ||||        ××××××                     |
  |    A------→轨迹      ××××××                      |
  |    |      ||||        ××××××                     |
  |    C-------x 轴-------O--------→x                |
  |           ||||        ××××××                     |
  |                    轨迹出射                       |
  |                                                  |
  |  [状态 1] [状态 2] [状态 3]  [状态说明]          |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用 currentState 变量 (0-3) 跟踪当前状态，点击按钮时更新并调用 render()
  2. 轨迹路径：使用 SVG <path> 元素，d 属性用二次贝塞尔曲线 M start Q control end
  3. 电场线箭头：用<marker>定义箭头，<line>引用 marker-end
  4. 磁场×符号：循环生成 4 行 6 列的<text>或<path>
  5. 事件绑定：按钮点击事件切换状态，更新轨迹显示/隐藏
  6. IIFE 隔离：所有 JS 包在 (function() { ... })() 中
