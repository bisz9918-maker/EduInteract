problem_203_physics_g12

场景导航：Scene 1 | Scene 2 | Scene 3

题目原文：

如图所示，两平行金属板 A、B 长 8cm，两板间距离 d=8cm，A 板比 B 板电势高 300V，一带正电的粒子电荷量 q=10⁻¹⁰C，质量 m=10⁻²⁰kg，沿电场中心线 RD 垂直电场线飞入电场，初速度 v₀=2×10⁶m/s，粒子飞出平行板电场后经过界面 MN、PS 间的无电场区域后求：粒子穿过界面 MN 时偏离中心线 RD 的距离多远？到达 PS 界面时离 D 点多远？已知两界面 MN、PS 相距为 12cm，静电力常数 k=9.0×10⁹N·m²/C²。

题目分析：

这是典型的带电粒子在匀强电场中的类平抛运动问题。粒子运动分为两个阶段：

  1. 在平行板电场中（R 到 MN）：水平方向匀速直线运动，竖直方向匀加速直线运动（类平抛）
  2. 在无电场区域（MN 到 PS）：匀速直线运动（沿飞出电场时的速度方向）

整体讲解思路：

  1. 首先分析电场强度 E = U/d，计算粒子受力和加速度
  2. 计算粒子在电场中的运动时间 t₁ = L/v₀
  3. 计算穿出电场时的竖直偏移 y₁ = ½at₁² 和竖直速度 vy = at₁
  4. 在无电场区域，粒子沿直线运动，利用几何相似关系求 PS 处的总偏移

图示规划说明：

  • SCENE_1：完整装置图 + 粒子运动轨迹，分步展示电场中偏转和无电场区直线运动
  • SCENE_2：速度矢量分解图，展示飞出电场时的速度方向
  • SCENE_3：几何相似三角形，用于推导 PS 界面的偏移距离
步骤 0/4

SCENE_1 教学说明：

本图示展示粒子运动的完整轨迹，教师应引导学生观察：

  1. 电场区域的特点：两板间存在匀强电场，方向由 A 指向 B（向下）
  2. 粒子受力分析：正电荷受电场力向下，产生竖直向下的加速度
  3. 运动分解：水平方向不受力，保持 v₀ 匀速；竖直方向初速为 0 的匀加速

关键公式推导：

电场强度：E = U/d = 300V / 0.08m = 3750 V/m

粒子加速度：a = F/m = qE/m = (10⁻¹⁰ × 3750) / 10⁻²⁰ = 3.75 × 10¹³ m/s²

电场中运动时间：t₁ = L/v₀ = 0.08 / (2×10⁶) = 4×10⁻⁸ s

MN 处偏移：y₁ = ½at₁² = ½ × 3.75×10¹³ × (4×10⁻⁸)² = 0.03 m = 3 cm

步骤 0/4

SCENE_2 教学说明：

本图示帮助学生理解粒子飞出电场后的运动方向。

讲解要点：

  1. 飞出电场瞬间，粒子同时具有水平速度 vx 和竖直速度 vy
  2. 合速度方向即为粒子后续直线运动的方向
  3. 在无电场区域，粒子不受力，保持该速度做匀速直线运动

速度计算：

vx = v₀ = 2×10⁶ m/s（水平速度不变）

vy = at₁ = 3.75×10¹³ × 4×10⁻⁸ = 1.5×10⁶ m/s

速度偏转角：tanθ = vy/vx = 1.5×10⁶ / 2×10⁶ = 0.75

步骤 1/5

SCENE_3 教学说明：

本图示展示利用几何相似关系求解 PS 界面总偏移的方法。

讲解要点：

  1. 粒子飞出电场后沿直线运动，该直线与中心线的夹角等于速度偏转角 θ
  2. 从 MN 到 PS，水平距离为 12cm，竖直位移 Δy = 12cm × tanθ
  3. 总偏移 y₂ = y₁ + Δy

完整解答：

由相似三角形或速度方向关系：

Δy = 12cm × tanθ = 12 × 0.75 = 9 cm

总偏移：y₂ = y₁ + Δy = 3cm + 9cm = 12 cm

答案：

  • 粒子穿过界面 MN 时偏离中心线 RD 的距离：3 cm
  • 到达 PS 界面时离 D 点的距离：12 cm

课堂讲解建议：

  1. 先用 SCENE_1 建立整体运动图像
  2. 用 SCENE_2 解释速度分解和飞出方向
  3. 用 SCENE_3 推导几何关系并得出最终答案
  4. 强调类平抛运动的处理方法：运动的独立性原理
