[图示主题与整合说明]
- 本图示主题：飞出电场时的速度矢量分解
- 整合的步骤/概念：水平速度 vx、竖直速度 vy、合速度 v 及其方向角θ
- 教学价值：教师可逐步展示带电粒子飞出偏转电场瞬间的速度分解过程，帮助学生理解类平抛运动的速度合成规律。通过分步动画，学生能清晰看到 vx 保持不变、vy 由电场加速获得、合速度沿轨迹切线方向，以及偏转角与分速度的关系。

[分步序列]
- 初始状态（步骤 0）：显示中心线 RD（灰色虚线）、MN 界面（灰色虚线）、粒子位置 P（红色圆点在 (400,280)）。等待教师触发下一步。
- 步骤 1：点击「下一步」→ 绘制水平速度矢量 vx（蓝色箭头从 (400,280) 到 (520,280)），显示标签 "vx = v₀" 于 (460,265)。vx 箭头带轻微绘制动画（从 0 长度渐变到 120px）。
- 步骤 2：点击「下一步」→ 绘制竖直速度矢量 vy（绿色箭头从 (400,280) 到 (400,360)），显示标签 "vy = at₁" 于 (410,330)。vy 箭头带绘制动画。
- 步骤 3：点击「下一步」→ 绘制合速度 v（红色箭头从 (400,280) 到 (520,360)），显示标签 "v" 于 (480,310)。同时显示辅助虚线三角形（灰色虚线连接 vx 末端和 vy 末端）。v 箭头带绘制动画。
- 步骤 4：点击「下一步」→ 绘制偏转角θ弧线（黑色，半径 40px，从 vx 到 v），显示标签 "θ" 于 (445,295)，显示公式 "tanθ = vy/vx" 于 (550,320)。弧线带绘制动画（角度从 0°渐变到目标角度）。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 (280,460)，宽 100px，高 36px，点击后回退到前一状态
  - 「下一步」按钮：位于 (420,460)，宽 100px，高 36px，点击后进入下一状态

- 教师操作流程：
  1. 初始状态展示粒子在 MN 界面的位置，提问学生"粒子飞出电场时速度方向如何？"
  2. 点击「下一步」展示 vx，强调"水平方向不受力，速度保持 v₀"
  3. 点击「下一步」展示 vy，强调"竖直方向受电场力加速，vy = at₁"
  4. 点击「下一步」展示合速度 v 和辅助三角形，强调"速度合成遵循平行四边形定则"
  5. 点击「下一步」展示偏转角θ和公式，强调"tanθ = vy/vx 是解题关键"

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（箭头、虚线、弧线），无需复杂库；原生 SVG 便于精确控制坐标和动画
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |                    (中心线 RD)                   |
  |         R ------------------P--------> vx        |
  |                              | \                 |
  |                              |  \ v              |
  |                              |   \               |
  |                              v vy \              |
  |                                    \             |
  |                                     \            |
  |                                      \           |
  |                                       (θ)        |
  |                                            tanθ  |
  |                                                  |
  |              [上一步]  步骤 X/4  [下一步]        |
  +--------------------------------------------------+
  [控件栏在 SVG 内底部 y=440~490]
  ```
- 关键实现要点：
  1. 状态机设计：使用 step 变量 (0-4) 跟踪当前步骤，steps 数组存储每步的显示配置
  2. 箭头绘制：使用 SVG <marker> 定义箭头，<line> + <marker-end> 组合
  3. 动画实现：使用 CSS transition 或 requestAnimationFrame 实现箭头长度/角度渐变
  4. 事件绑定：按钮点击事件切换 step，调用 renderStep() 更新显示
  5. 弧线绘制：使用 SVG <path> 的 A 命令绘制圆弧
- ID 命名规范：所有元素 ID 以 scene2- 为前缀
  - scene2-center-line, scene2-mn-interface, scene2-particle-point
  - scene2-vx-arrow, scene2-vy-arrow, scene2-v-arrow
  - scene2-vx-label, scene2-vy-label, scene2-v-label, scene2-theta-label, scene2-formula
  - scene2-prev-btn, scene2-next-btn, scene2-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
