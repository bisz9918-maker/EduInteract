[图示主题与整合说明]
- 本图示主题：几何相似三角形关系（求 PS 界面总偏移）
- 整合的步骤/概念：电场中偏移 y₁、无电场区位移、相似三角形比例关系
- 教学价值：教师可逐步展示带电粒子在电场中的抛物线轨迹如何近似为直线延长，利用相似三角形快速求解总偏移量。通过高亮两个相似三角形，学生直观理解"电场内偏转 + 电场外匀速直线运动"的几何关系，掌握 y₂/y₁ = (L+D)/L 的比例推导方法。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 按钮「◀ 上一步」：位于 (260,460)，宽 120px，高 30px，初始禁用
  - 按钮「下一步 ▶」：位于 (420,460)，宽 120px，高 30px
  - 步骤指示器：位于 (320,455)，显示 "步骤 X/4"
- 教师操作流程：
  1. 初始展示完整装置和轨迹，让学生观察粒子运动路径
  2. 点击「下一步」高亮电场内三角形，讲解 y₁ 的产生
  3. 点击「下一步」高亮电场外三角形，讲解匀速直线运动段
  4. 点击「下一步」显示相似关系和比例公式，推导 y₂ 计算方法
  5. 点击「下一步」显示最终计算结果，完成求解

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单，无需复杂库；SVG 便于精确控制坐标和样式；原生 JS 足够实现分步状态切换
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +----------------------------------------------------------+
  |  P(690,95)                                    PS 界面    |
  |    |                                                    |
  |    |                                                    |
  |  M |  平行板 A  ======                                  |
  |    |            ======  轨迹 → → → → → → → → → → → → →  |
  |  --R------------------------D(710,245)------------------| 中心线
  |    |            ======                                  |
  |  N |  平行板 B  ======                                  |
  |    |                                                    |
  |    |  L=8cm      12cm                    S(690,405)     |
  |    |                                                    |
  |         [三角形 1]        [三角形 2]                     |
  |                    y₂/y₁ = (L+D)/L                       |
  |                                                          |
  |              [◀ 上一步]  步骤 X/4  [下一步 ▶]             |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量 (0-4)，每个步骤对应一组可见元素 ID 列表
  2. 坐标计算：所有坐标硬编码，确保与布局表一致；三角形顶点坐标根据轨迹交点计算
  3. 动画曲线：元素淡入使用 CSS transition opacity 0.3s ease
  4. 事件绑定：按钮点击事件切换状态，更新可见性并刷新步骤指示器
  5. 元素初始可见性：步骤 0 可见元素设置 opacity=1，其他设置 opacity=0 并添加 hidden 类
- ID 命名规范：所有元素 ID 以 scene3- 为前缀
  - scene3-center-line, scene3-plate-a, scene3-plate-b
  - scene3-mn-line, scene3-ps-line, scene3-trajectory
  - scene3-tri1, scene3-tri2
  - scene3-label-r, scene3-label-d, scene3-label-m, scene3-label-n, scene3-label-p, scene3-label-s
  - scene3-label-l, scene3-label-dist12, scene3-label-y1, scene3-label-y2, scene3-label-dy
  - scene3-arrow-y1, scene3-arrow-y2, scene3-formula
  - scene3-btn-prev, scene3-btn-next, scene3-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
