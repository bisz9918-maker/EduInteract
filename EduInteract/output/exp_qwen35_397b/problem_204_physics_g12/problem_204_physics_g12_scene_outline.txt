    **题目原文：**

    如图所示，匀速转动的水平圆盘上，沿半径方向放置两个用细线相连的质量均为 m 的小物体 A、B，它们到转轴距离分别为 r_A = 20cm、r_B = 10cm，A、B 与盘面间的最大静摩擦力均为重力的 0.5 倍，连接 OB 以及 AB 的两根细绳所能承受的最大张力均为 2mg，试求：
    （1）当 AB 之间的细线上开始有弹力时，圆盘的角速度 ω₀；
    （2）当 OB 之间的细线上开始有弹力时，圆盘的角速度 ω₁；
    （3）当物体 A 刚开始滑动时，圆盘的角速度 ω₂。

    **题目分析：**

    本题是圆周运动向心力来源的典型问题。两个物体 A、B 随圆盘转动，向心力由静摩擦力和绳子张力提供。随着角速度 ω 增大：
    - 初始阶段：静摩擦力单独提供向心力
    - 当静摩擦力达到最大值后，绳子开始产生张力
    - 由于 r_A > r_B，A 需要更大的向心力，A 的静摩擦力先达到最大值

    **整体讲解思路：**

    1. 首先展示系统结构，明确 A、B 位置关系和连接方式
    2. 分析向心力来源：静摩擦力 → 绳子张力
    3. 分三个阶段分析临界状态，计算对应的角速度
    4. 总结解题关键：判断哪个物体先达到临界状态

    **图示规划说明：**

    - Scene 1：系统结构示意图（俯视图），展示圆盘、转轴、A、B 位置及两根细绳的连接关系
    - Scene 2：三阶段临界状态受力分析（整合三个临界状态），用分步导航展示每个阶段的受力变化和临界条件
    </TEXT_1>

    **Scene 2 教学说明：**

    本图示整合三个临界状态的受力分析，教师应按以下步骤讲解：

    **阶段 1：AB 绳开始有张力（ω = ω₀）**
    1. 当 ω 较小时，静摩擦力单独提供向心力
    2. 由于 r_A > r_B，A 的静摩擦力先达到最大值 f_m = 0.5mg
    3. 临界条件：f_A = mω₀²r_A = 0.5mg
    4. 解得：ω₀ = √(0.5g/r_A) = √(0.5×10/0.2) = 5 rad/s

    **阶段 2：OB 绳开始有张力（ω = ω₁）**
    1. ω > ω₀ 后，AB 绳有张力 T_AB，A 的向心力由 f_m + T_AB 提供
    2. B 的向心力仍由静摩擦力单独提供（T_AB 对 B 是向外的拉力）
    3. 当 B 的静摩擦力也达到最大值时，OB 绳开始有张力
    4. 临界条件：f_B = mω₁²r_B = 0.5mg
    5. 解得：ω₁ = √(0.5g/r_B) = √(0.5×10/0.1) = 5√2 ≈ 7.07 rad/s

    **阶段 3：A 刚开始滑动（ω = ω₂）**
    1. ω > ω₁ 后，OB 绳有张力 T_OB
    2. 对 A：T_AB + f_m = mω₂²r_A
    3. 对 B：T_OB + f_m - T_AB = mω₂²r_B（注意 T_AB 对 B 是向外的）
    4. 当 T_AB 达到最大值 2mg 时，A 即将滑动
    5. 联立方程求解 ω₂

    **讲解要点：**
    - 强调静摩擦力方向始终指向圆心（提供向心力）
    - 绳子张力对 A 是向内的拉力，对 B 是向外的拉力
    - 判断临界状态的关键是找到哪个力先达到最大值
    </TEXT_3>

    <TEXT_4>
    **Scene 3 教学说明：**

    本图示展示各力随角速度变化的连续关系，帮助学生建立动态认知。

    **引导学生观察：**
    1. 初始阶段（ω < ω₀）：f_A 和 f_B 都随 ω² 线性增长，绳子无张力
    2. 第一临界点（ω = ω₀）：f_A 达到最大值 0.5mg，之后保持不变；T_AB 开始出现
    3. 第二临界点（ω = ω₁）：f_B 达到最大值 0.5mg，之后保持不变；T_OB 开始出现
    4. 第三临界点（ω = ω₂）：T_AB 达到最大值 2mg，A 即将滑动

    **完整解答：**

    （1）当 AB 绳开始有弹力时：
    f_A = mω₀²r_A = 0.5mg
    ω₀ = √(0.5g/r_A) = √(0.5×10/0.2) = **5 rad/s**

    （2）当 OB 绳开始有弹力时：
    f_B = mω₁²r_B = 0.5mg
    ω₁ = √(0.5g/r_B) = √(0.5×10/0.1) = **5√2 ≈ 7.07 rad/s**

    （3）当 A 刚开始滑动时：
    对 A：T_AB + f_m = mω₂²r_A
    对 B：T_OB + f_m - T_AB = mω₂²r_B
    当 T_AB = 2mg 时：
    2mg + 0.5mg = mω₂² × 0.2
    ω₂² = 2.5g/0.2 = 12.5g = 125
    ω₂ = **5√5 ≈ 11.18 rad/s**

    **课堂讲解建议：**
    - 先用 Scene 1 建立空间认知
    - 再用 Scene 2 分步分析三个临界状态
    - 最后用 Scene 3 展示连续变化关系，验证计算结果
    - 强调解题关键：判断哪个物体、哪个力先达到临界值
    </TEXT_4>
