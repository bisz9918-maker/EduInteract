[图示主题与整合说明]
- 本图示主题：旋转圆盘系统结构示意（俯视图）
- 整合的内容：圆盘整体结构、转轴位置、物体 A 和 B 的位置标注、两根细绳（OB 绳和 AB 绳）的连接关系、转动方向
- 教学价值：教师可逐步展示旋转圆盘系统的各个组成部分，帮助学生建立空间认知，理解向心力来源及绳子张力的作用机制。通过分步呈现，学生能清晰看到每个物体与转轴的相对位置关系，为后续分析静摩擦力和绳子张力做铺垫。

[分步序列]
- 初始状态（步骤 0）：仅显示圆盘（椭圆）和转轴（中心圆柱），圆心标签 O 可见。其他元素 opacity=0 隐藏。
- 步骤 1：点击「下一步」→ 显示物体 B（蓝色矩形）及其标签"B"，显示 r_B 标注虚线和文字"r_B=10cm"。物体 B 从透明度 0 渐变到 1（300ms）。
- 步骤 2：点击「下一步」→ 显示物体 A（蓝色矩形）及其标签"A"，显示 r_A 标注虚线和文字"r_A=20cm"。物体 A 从透明度 0 渐变到 1（300ms）。
- 步骤 3：点击「下一步」→ 显示 OB 绳（线段从圆心附近到 B）和 AB 绳（线段从 B 到 A）。两条绳子从长度 0 渐变到完整长度（300ms 动画）。
- 步骤 4：点击「下一步」→ 显示转动方向弧形箭头（逆时针）和角速度符号"ω"。箭头从透明度 0 渐变到 1，同时 ω 符号淡入（300ms）。
- 最终状态：所有元素完整显示，教师可点击「上一步」回退复习任一组件。

  3. 点击「下一步」添加物体 A，对比外侧物体的位置差异
  4. 点击「下一步」添加两根细绳，说明连接关系和张力传递

  6. 可随时点击「上一步」回退复习，强化学生对系统结构的理解

[技术实现]
- JS 库选择及原因：原生 SVG。理由：本场景为静态几何图示+简单淡入动画，无需复杂库；SVG 矢量图形清晰，适合几何标注，代码简洁易维护。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |                    转动箭头 ω                     |
  |                      ╭───→                        |
  |                      │                           |
  |         转轴         │                           |
  |          ││          │                           |
  |          ││ O        │                           |
  |          ││●─────────┼─────B───────A             |
  |         ──┴──────────┴───────────────── 圆盘椭圆  |
  |              r_B=10cm      r_A=20cm              |
  |                                                  |
  |                                                  |
  |                                                  |
  |              [◀上一步] 步骤X/5 [下一步▶]          |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-4)，数组 steps 定义每步显示的元素 ID 列表
  2. 坐标计算：所有元素坐标硬编码在 SVG 中，确保与布局表一致
  3. 动画曲线：使用 CSS transition opacity 0.3s ease-in-out 实现淡入效果
  4. 事件绑定：按钮点击事件监听，更新 currentStep 并调用 renderStep() 函数
  5. 元素显隐：通过 setAttribute('opacity', '0'/'1') 或 CSS class 控制
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀，例如：
  - scene1-disc（圆盘）
  - scene1-axis（转轴）
  - scene1-label-o（圆心标签）
  - scene1-obj-b（物体 B）
  - scene1-label-b（标签 B）
  - scene1-rb-label（r_B 标注）
  - scene1-obj-a（物体 A）
  - scene1-label-a（标签 A）
  - scene1-ra-label（r_A 标注）
  - scene1-rope-ob（OB 绳）
  - scene1-rope-ab（AB 绳）
  - scene1-rotation-arrow（转动箭头）
  - scene1-omega（ω符号）
  - scene1-btn-prev（上一步按钮）
  - scene1-btn-next（下一步按钮）
  - scene1-step-indicator（步骤指示器）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
- 控件栏实现：使用 SVG <g> 元素包裹按钮，按钮用 <rect>+<text> 组合，点击区域用 <rect> 定义，通过 getBoundingClientRect() 或 SVG 坐标转换处理点击事件
