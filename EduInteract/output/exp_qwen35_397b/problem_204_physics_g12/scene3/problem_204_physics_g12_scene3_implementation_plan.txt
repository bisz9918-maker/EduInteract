[视觉元素清单]
- 坐标系：横轴 ω 范围 0~10 rad/s，纵轴 F 范围 0~2.5 mg
- f_A 曲线（#1565c0 实线）：
  - 0 ≤ ω ≤ 5：f_A = (r_A/g)·ω² = 0.02ω²（抛物线增长）
  - ω > 5：f_A = 0.5（水平线）
- f_B 曲线（#1565c0 虚线）：
  - 0 ≤ ω ≤ 5：f_B = (r_B/g)·ω² = 0.01ω²（抛物线增长）
  - 5 < ω ≤ ω₁：f_B 继续增长至 0.5
  - ω > ω₁：f_B = 0.5（水平线）
- T_AB 曲线（#2e7d32 实线）：
  - 0 ≤ ω ≤ 5：T_AB = 0
  - ω > 5：T_AB = (r_A/g)·ω² - 0.5 = 0.02ω² - 0.5（线性增长近似）
- T_OB 曲线（#2e7d32 虚线）：
  - 0 ≤ ω ≤ ω₁：T_OB = 0
  - ω > ω₁：T_OB 开始增长
- 临界点竖直线（#c62828 虚线）：
  - ω₀ = 5 rad/s（AB 绳开始有张力）
  - ω₁ = 5√2 ≈ 7.07 rad/s（OB 绳开始有张力）
  - ω₂ ≈ 8.66 rad/s（A 开始滑动，需计算）
- 图例：右上角，标明四条曲线的含义和样式
- 滑块：底部中央，可拖拽改变 ω 值

[分步序列]
本场景为连续拖拽交互，无分步导航。状态定义如下：

- 初始状态（ω = 0）：
  - 所有力均为 0
  - 滑块手柄位于最左端
  - 显示"ω = 0.0 rad/s"

- 状态 1（ω = ω₀ = 5 rad/s）：
  - f_A 达到 0.5mg（最大静摩擦）
  - f_B = 0.25mg
  - T_AB 即将开始出现
  - ω₀ 竖直线高亮显示
  - 滑块手柄移至 x=314 位置

- 状态 2（ω = ω₁ ≈ 7.07 rad/s）：
  - f_A = 0.5mg，f_B = 0.5mg（均达最大）
  - T_AB > 0
  - T_OB 即将开始出现
  - ω₁ 竖直线高亮显示
  - 滑块手柄移至 x=456 位置

- 状态 3（ω = ω₂ ≈ 8.66 rad/s）：
  - A 即将滑动（临界状态）
  - 所有力均达到特定值
  - ω₂ 竖直线高亮显示
  - 滑块手柄移至 x=620 位置

- 任意状态（教师自由拖拽）：
  - 实时计算并绘制四条曲线在当前 ω 处的值
  - 用圆点标记当前 ω 对应的四个力值
  - 显示当前 ω 数值

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：
  - 滑块轨道：位于 y=455~475，x=200~600，长度 400px
  - 滑块手柄：圆形，半径 12px，颜色 #1565c0，可左右拖拽
  - 当前值显示：滑块上方显示"ω = X.X rad/s"
- 教师操作流程：
  1. 初始状态展示 ω=0 时各力为零
  2. 缓慢向右拖动滑块，观察四条曲线的变化趋势
  3. 在 ω₀=5 处暂停，讲解"此时 A 的静摩擦力达到最大，AB 绳开始有张力"
  4. 继续拖动至 ω₁≈7.07，讲解"此时 B 的静摩擦力也达到最大，OB 绳开始有张力"
  5. 拖动至 ω₂，讲解"此时 A 即将滑动，系统达到临界状态"
  6. 可来回拖动对比不同 ω 下的受力情况

- 关键实现要点：
  1. 坐标映射函数：
     - x(ω) = 60 + (ω/10) × 700
     - y(F) = 400 - (F/2.5) × 360
  2. 曲线计算函数（给定 ω 返回四个力值）：
     - f_A(ω) = min(0.02×ω², 0.5)
     - f_B(ω) = 分段函数（见下方）
     - T_AB(ω) = max(0, 0.02×ω² - 0.5)
     - T_OB(ω) = 分段函数（ω > ω₁ 后开始增长）
  3. 拖拽事件：mousedown/mousemove/mouseup 实现滑块手柄拖拽
  4. 实时更新：拖拽时重新计算曲线并更新 SVG path
  5. 临界点高亮：当滑块接近 ω₀/ω₁/ω₂ 时（±0.2 范围内），对应竖直线加粗显示
  6. 状态机：记录当前 ω 值，支持点击临界点标签快速跳转
- ID 命名规范：
  - 所有元素 ID 以 scene3- 为前缀
  - 示例：scene3-axis-x, scene3-axis-y, scene3-curve-fa, scene3-curve-fb, scene3-curve-tab, scene3-curve-tob
  - 滑块：scene3-slider-track, scene3-slider-handle, scene3-slider-value
  - 临界点：scene3-critical-omega0, scene3-critical-omega1, scene3-critical-omega2
  - 图例：scene3-legend-fa, scene3-legend-fb, scene3-legend-tab, scene3-legend-tob
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
- 物理公式（用于曲线计算）：
  - r_A = 0.2m, r_B = 0.1m, g = 10m/s²
  - ω₀ = 5 rad/s（A 达最大静摩擦）
  - ω₁ = 5√2 ≈ 7.07 rad/s（B 达最大静摩擦）
  - ω₂：当 A 即将滑动时，需满足 T_AB + f_A(max) = m·r_A·ω₂²
    同时 T_OB + f_B(max) - T_AB = m·r_B·ω₂²
    联立求解得 ω₂ ≈ 8.66 rad/s
