    **题目原文：**

    如图所示，现在有一个小物块，质量为 m=80g，带正电荷 q=2×10⁻⁴C，放在水平轨道上 M 点，物块与水平轨道之间的滑动摩擦系数 μ=0.2，轨道处在一个水平向左的匀强电场中，E=10³V/m，在水平轨道的末端 N 处，连接一个光滑的半圆形轨道，半径为 R=40cm，取 g=10m/s²，求：
    （1）要使小物块能够运动到轨道的最高点 L，那么 M、N 间的距离 S 至少多大？
    （2）如果在（1）题的位置释放小物块，当它运动到 P（轨道中点）点时对轨道的压力等于多少？

    **题目分析：**

    本题是带电粒子在复合场（电场 + 重力场）中的运动问题，涉及：
    1. 动能定理/能量守恒
    2. 圆周运动的临界条件
    3. 向心力公式
    4. 电场力做功与摩擦力做功

    **整体讲解思路：**

    第（1）问关键：物块能到达 L 点的临界条件是 L 点速度满足圆周运动最小速度要求（仅由重力提供向心力）

    第（2）问关键：P 点受力分析，轨道支持力与电场力的合力提供向心力

    **图示规划说明：**

    - SCENE_1：整体装置图 + 全过程受力分析（整合电场、重力、摩擦力方向）
    - SCENE_2：能量转化与临界条件（从 M 到 L 的功能关系，L 点临界速度）
    - SCENE_3：P 点受力分析与压力计算（向心力分解）
    </TEXT_1>

    **SCENE_2 教学说明：**

    本图示讲解第（1）问的核心：动能定理 + 临界条件。

    **讲解要点：**

    1. **临界条件分析**：物块恰好能到达 L 点，意味着 L 点轨道支持力为 0，仅由重力提供向心力
       $$mg = m\frac{v_L^2}{R} \Rightarrow v_L = \sqrt{gR}$$

    2. **动能定理全过程**：从 M 到 L
       $$qE(S+R) - \mu mgS - mg(2R) = \frac{1}{2}mv_L^2 - 0$$

    3. **代入临界速度**：
       $$qE(S+R) - \mu mgS - 2mgR = \frac{1}{2}mgR$$

    4. **解出 S**：
       $$S(qE - \mu mg) = \frac{5}{2}mgR - qER$$
       $$S = \frac{\frac{5}{2}mgR - qER}{qE - \mu mg}$$

    **数值计算引导：**

    - m = 0.08 kg, q = 2×10⁻⁴ C, E = 10³ V/m, μ = 0.2, R = 0.4 m, g = 10 m/s²
    - qE = 0.2 N, μmg = 0.16 N
    - 代入求解 S

    **SCENE_3 教学说明：**

    本图示讲解第（2）问：P 点轨道压力计算。

    **讲解要点：**

    1. **P 点位置特点**：P 是半圆轨道中点，与圆心 O 等高，因此 P 点高度为 R（相对于 N 点）

    2. **P 点受力分析**：
       - 重力 mg：竖直向下（与向心力方向垂直，不提供向心力）
       - 电场力 qE：水平向左（背离圆心）
       - 轨道支持力 N_P：水平向右（指向圆心）

    3. **向心力方程**（水平方向）：
       $$N_P - qE = m\frac{v_P^2}{R}$$
       $$N_P = qE + m\frac{v_P^2}{R}$$

    4. **求 v_P（从 M 到 P 的动能定理）**：
       $$qE(S+R) - \mu mgS - mgR = \frac{1}{2}mv_P^2$$

    5. **牛顿第三定律**：物块对轨道的压力大小等于轨道对物块的支持力 N_P

    **完整解答总结：**

    第（1）问：代入数值 S ≈ 1.25 m（具体计算见课堂推导）

    第（2）问：先求 v_P，再代入向心力方程求 N_P，即为所求压力
