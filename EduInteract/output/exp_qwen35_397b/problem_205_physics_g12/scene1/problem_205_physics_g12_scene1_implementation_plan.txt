[图示主题与整合说明]
- 本图示主题：带电物块在复合场中运动的整体装置与受力分析
- 整合的内容：轨道系统结构（水平轨道 MN + 半圆形轨道 NL）、匀强电场方向、物块在 MN 段与 NL 段的受力差异
- 教学价值：教师可逐步展示从整体装置到局部受力分析的认知递进过程，帮助学生理解：(1) 电场力方向与电荷正负的关系；(2) 水平段与圆弧段受力的差异（摩擦力有无）；(3) 各关键位置（M、N、P、L）的物理意义

[分步序列]
- 初始状态（步骤 0）：显示基础装置
  · 半圆轨道 NL（黑色粗线）
  · 水平轨道 MN（黑色粗线）
  · 6 条电场线（灰色，带向左箭头）
  · 物块位于 M 点（红色半透明方块）
  · 位置标签 M、N、P、L
  · 电场 E 标签（左上角）
  · 质量 m 标签（物块右侧）
  · 半径 R 标注（半圆右侧）
  · 所有受力向量隐藏

- 步骤 1：MN 段受力分析（水平轨道段）
  · 保持步骤 0 所有元素
  · 显示物块在 M 点的 4 个受力向量：
    - 重力 mg（红色，竖直向下）+ 标签"mg"
    - 电场力 qE（蓝色，水平向左）+ 标签"qE"
    - 摩擦力 f（绿色，水平向右）+ 标签"f"
    - 支持力 N（灰色，竖直向上）+ 标签"N"
  · 高亮水平轨道 MN 段（线宽加粗至 5px 或变色提示）

- 步骤 2：NL 段受力特点（圆弧轨道段，无摩擦）
  · 保持轨道、电场线、物块、位置标签
  · 隐藏 MN 段受力向量（mg/qE/f/N 及标签）
  · 在 P 点（半圆中点，坐标 80,300）显示受力：
    - 重力 mg（红色，竖直向下）
    - 电场力 qE（蓝色，水平向左）
    - 支持力 N（灰色，指向圆心，即水平向右）
  · 说明：圆弧段光滑，无摩擦力
  · 高亮半圆轨道 NL 段

- 步骤 3：关键位置标注与物理量汇总
  · 显示所有位置标签 M、N、P、L（加粗或放大）
  · 在 M 点旁显示已知条件标签：
    - "m=80g"（物块上方）
    - "q=2×10⁻⁴C"（物块下方）
    - "μ=0.2"（水平轨道下方）
  · 在半圆旁显示：
    - "R=40cm"（半径标注）
    - "E=10³V/m"（电场强度，左上角）
  · 显示 g=10m/s²（右下角）

冲突检查：
- "m"(675,410) 与 "M"(660,445)：垂直距离 35px > 20px → 无冲突
- "mg"(650,480) 与 "M"(660,445)：垂直距离 35px > 20px → 无冲突
- "qE"(570,400) 与 "f"(700,400)：水平距离 130px > 20px → 无冲突
- "N"(力)(655,350) 与 "qE"(570,400)：距离 √(85²+50²)≈98px > 20px → 无冲突
- "P"(55,300) 与电场线 y=300：P 标签在电场线左侧外部 → 无冲突
- "L"(215,170) 与电场线 y=150：垂直距离 20px → 边界安全，可接受
- "E"(60,65) 与电场线 y=80：垂直距离 15px → 略近，但 E 在电场线上方空白区 → 可接受

所有标签间距均 ≥ 15px，无明显重叠冲突。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  · 按钮"◀上一步"：位置 (280,465), 宽 100px, 高 40px, 返回上一状态
  · 按钮"下一步▶"：位置 (420,465), 宽 100px, 高 40px, 进入下一状态
  · 状态指示器：位置 (390,450), 显示"步骤 X/4"
- 教师操作流程：
  1. 初始展示整体装置（步骤 0），介绍轨道结构和电场方向
  2. 点击"下一步"展示 MN 段受力（步骤 1），讲解水平段四力平衡/非平衡
  3. 点击"下一步"切换到 NL 段受力（步骤 2），强调圆弧段光滑无摩擦
  4. 点击"下一步"显示全部已知条件（步骤 3），为后续计算做准备
  5. 可随时点击"上一步"回退复习关键概念

- 关键实现要点：
  1. 状态机设计：用变量 currentState (0-3) 跟踪当前步骤，数组存储各状态配置
  2. 箭头绘制：使用 SVG <marker> 定义箭头，<line> + marker-end 绘制带箭头线段
  3. 半圆绘制：<path d="M 200,420 A 120,120 0 0,1 200,180" /> 逆时针绘制
  4. 向量显示/隐藏：给每个受力向量组添加 class="force-mn"或"force-nl"，通过 display 控制
  5. 事件绑定：按钮点击事件切换 currentState，调用 updateScene() 更新显示
  6. 动画过渡：向量出现时使用 opacity 从 0 到 1 的过渡（0.3s ease-out）

- ID 命名规范：
  · 所有元素 ID 以 scene1- 为前缀
  · 轨道：scene1-track-horizontal, scene1-track-semicircle
  · 电场线：scene1-efield-1 至 scene1-efield-6
  · 物块：scene1-block
  · 受力向量：scene1-force-mg, scene1-force-qe, scene1-force-f, scene1-force-n
  · 标签：scene1-label-M, scene1-label-N, scene1-label-P, scene1-label-L
  · 物理量标签：scene1-label-E, scene1-label-m, scene1-label-R
  · 向量标签：scene1-label-mg, scene1-label-qe, scene1-label-f, scene1-label-N-force
  · 按钮：scene1-btn-prev, scene1-btn-next, scene1-status

- IIFE 隔离：
  ```javascript
  (function() {
      // 所有 JS 代码包裹在此
      let currentState = 0;
      const totalStates = 4;
      
      function updateScene() {
          // 根据 currentState 显示/隐藏对应元素
      }
      
      // 事件绑定
      document.getElementById('scene1-btn-prev').addEventListener('click', function() {
          if (currentState > 0) {
              currentState--;
              updateScene();
          }
      });
      
      document.getElementById('scene1-btn-next').addEventListener('click', function() {
          if (currentState < totalStates - 1) {
              currentState++;
              updateScene();
          }
      });
      
      // 初始化
      updateScene();
  })();
  ```
