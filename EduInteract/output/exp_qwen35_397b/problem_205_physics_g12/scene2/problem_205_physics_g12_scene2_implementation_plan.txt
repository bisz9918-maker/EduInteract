[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单，无需复杂库；原生 SVG 便于精确控制坐标和动画；代码轻量易于多场景合并
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────┐
  │  E 电场线区域 (y=50~180)                                │
  │  ─────────────────────────────────────────────────      │
  │                                                         │
  │     轨道系统 (y=70~175)           L 点临界条件 (x>550)  │
  │     M───────N⌒L                    ┌─────────────┐      │
  │     [物块]  (半圆)                  │  ○  mg↓    │      │
  │                                    │ mg=mv²/R   │      │
  │                                    └─────────────┘      │
  │  ─────────────────────────────────────────────────      │
  │  能量转化分析 (y=230~380)                               │
  │  qE(S+R) →→→→→→→→→→                                     │
  │  -μmgS   →→→→→→→→→→    ½mv_L² →→→→→→→→                  │
  │  -mg·2R  →→→→→→→→→→                                     │
  │  ─────────────────────────────────────────────────      │
  │  [方程框：qE(S+R) - μmgS - mg·2R = ½mv_L²] (y=400~435) │
  │  ─────────────────────────────────────────────────      │
  │         [◀上一步]  步骤 X/4  [下一步▶]   (y=440~490)   │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量 (0-4) 跟踪当前步骤，steps 数组存储每步的显示/隐藏元素 ID 列表
  2. 坐标计算：所有元素使用绝对坐标，圆弧使用 SVG path 命令绘制（M500,150 A80,80 0 0,0 500,70）
  3. 动画曲线：元素出现使用淡入动画（opacity 0→1，300ms），箭头使用描边动画（stroke-dasharray/stroke-dashoffset）
  4. 事件绑定：按钮点击事件绑定到 updateStep() 函数，更新 currentStep 并调用 renderStep()
  5. 元素显隐：使用 display:none/block 或 opacity 控制，避免重绘
- ID 命名规范：所有元素 ID 以 scene2- 为前缀
  - 轨道：scene2-track-mn, scene2-track-nl
  - 物块：scene2-block-m, scene2-block-l（虚影）
  - 标签：scene2-label-m, scene2-label-n, scene2-label-l, scene2-label-p, scene2-label-s, scene2-label-r
  - 能量箭头：scene2-arrow-electric, scene2-arrow-friction, scene2-arrow-gravity, scene2-arrow-kinetic
  - 能量标签：scene2-text-electric, scene2-text-friction, scene2-text-gravity, scene2-text-kinetic
  - L 临界元素：scene2-critical-circle, scene2-critical-gravity, scene2-text-critical-force, scene2-text-critical-velocity
  - 方程框：scene2-equation-box, scene2-equation-text
  - 控件：scene2-btn-prev, scene2-btn-next, scene2-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
