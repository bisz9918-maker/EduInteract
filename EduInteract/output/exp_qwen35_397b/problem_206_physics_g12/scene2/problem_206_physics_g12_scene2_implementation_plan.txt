[图示主题与整合说明]
- 本图示主题：两球速度 - 时间（v-t）图像——揭示碰撞规律
- 整合内容：第一次碰撞前后速度变化、第二次碰撞过程、第三次碰撞过程、速度交换规律的可视化
- 教学价值：教师可通过分步展示 v-t 图的构建过程，帮助学生理解：(1) A 球在电场中匀加速运动的 v-t 特征（斜直线）；(2) 弹性碰撞时速度交换的瞬时性（垂直跳变）；(3) 多次碰撞的周期性规律；(4) 从图像中读取时间间隔和速度值的关系

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 内底部左侧 (280,455)，点击返回上一状态
  - 「下一步」按钮：位于 SVG 内底部右侧 (450,455)，点击进入下一状态
  - 步骤指示器：位于两按钮之间 (380,465)，显示当前步骤"步骤 X/5"
- 教师操作流程：
  1. 初始加载显示步骤 0，讲解 A 球在电场中匀加速、B 球静止
  2. 点击「下一步」到步骤 1，讲解第一次碰撞瞬间速度交换
  3. 点击「下一步」到步骤 2，讲解碰撞后 A 重新加速、B 匀速运动
  4. 点击「下一步」到步骤 3，讲解第二次碰撞速度再次交换
  5. 点击「下一步」到步骤 4，展示第三次碰撞前的运动模式
  6. 点击「下一步」到步骤 5，展示完整图像，总结周期性规律
  7. 可随时点击「上一步」回退复习关键节点

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：v-t 图为 2D 折线图，SVG 路径绘制简洁；无需复杂动画库；原生 JS 足够处理状态切换
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |  [v]                        图例：               |
  |   |                          ━━ A 球            |
  | 3v₀├─────●──────────────────  ━━ B 球            |
  |   |    / | \                  |                  |
  | 2v₀├───/──┼──●────────────────┼────────          |
  |   |  /   | / | \              | |                |
  | v₀├─/────●──┼──●──────────────┼─┼────────        |
  |   |/     |  / | /              | |                |
  | 0 └──────┴──┴──┴──────────────┴─┴──────── t      |
  |   0      t₁  t₂ t₃                                  |
  |                                                    |
  |              [◀上一步] 步骤 X/5 [下一步▶]          |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用 currentStep 变量 (0-5) 跟踪当前步骤，steps 数组存储每步应显示的元素 ID 列表
  2. 坐标计算：
     - 原点 (80,420)，横轴单位长度 160px/t₁，纵轴单位长度 80px/v₀
     - t₁=240, t₂=400, t₃=560（等间距 160px）
     - v₀=340, 2v₀=260, 3v₀=180（等间距 80px，y 轴向下为正）
  3. A 球 v-t 路径：使用 SVG <polyline> 或 <path>，分段显示
  4. B 球 v-t 路径：使用 SVG <polyline>，分段显示
  5. 事件绑定：按钮点击事件切换 currentStep，调用 updateDisplay() 函数更新可见性
  6. 动画曲线：步骤切换使用 CSS transition 实现 0.3s 淡入淡出
- ID 命名规范：
  - 所有元素 ID 以 scene2- 为前缀
  - 示例：scene2-axis-v, scene2-axis-t, scene2-line-a-seg1, scene2-line-b-seg1, scene2-dash-1, scene2-point-1, scene2-label-t1, scene2-btn-prev, scene2-btn-next, scene2-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
- 状态显示逻辑：
  - 每步定义一个数组 visibleElements，包含该步应显示的 ID
  - updateDisplay() 遍历所有元素，ID 在 visibleElements 中的设 display:block，否则 display:none
  - 按钮状态：步骤 0 时禁用「上一步」，步骤 5 时禁用「下一步」
