[图示主题与整合说明]
- 本图示主题：多次碰撞时空图（x-t 图像）——推导第 n 次碰撞位移规律
- 整合内容：两球位移 - 时间关系、各次碰撞位置、第 n 次碰撞的位移公式推导
- 教学价值：教师可通过分步展示 x-t 图像，帮助学生直观理解 A 球（匀加速）和 B 球（碰撞后匀速）的运动规律，发现碰撞位置呈现 n²L 的数列规律，理解弹性碰撞中速度交换的物理本质

- 步骤 1：A 球完整抛物线段 1 显示到 (200,280)，碰撞点 1 出现（红色圆），显示 t₁ 刻度和标签、L 刻度和标签、坐标标签 (t₁,L)。B 球轨迹仍不显示
- 步骤 2：A 球抛物线段 2 从 (200,280) 绘制到约 1/2 位置，B 球直线段 1 从 (200,280) 开始绘制到约 1/2 位置。t₂ 和 4L 的刻度线出现但标签暂不显示
- 步骤 3：A 球抛物线段 2 完成到 (360,160)，B 球直线段 1 完成到 (360,160)，碰撞点 2 出现。显示 t₂ 标签、4L 标签、坐标标签 (t₂,4L)
- 步骤 4：A 球抛物线段 3 从 (360,160) 绘制到 (560,60)，B 球直线段 2 从 (360,160) 绘制到 (560,60)，碰撞点 3 出现。显示 t₃ 刻度标签、9L 刻度标签、坐标标签 (t₃,9L)

- "0"与"t₁"：水平距离 125px → 无冲突
- "t₁"与"t₂"：水平距离 160px → 无冲突
- "t₂"与"t₃"：水平距离 200px → 无冲突
- "L"与"4L"：垂直距离 120px → 无冲突
- "4L"与"9L"：垂直距离 100px → 无冲突
- "(t₁,L)"与 A 球轨迹：偏移 10px 向右下 → 无冲突
- "(t₂,4L)"与 B 球轨迹：偏移 10px 向右上 → 无冲突
- "(t₃,9L)"与公式框：y 坐标 50 vs 公式框 y=90 → 间距 40px → 无冲突
- 图例与公式框：图例 y=380/400，公式框 y=90-180 → 间距>200px → 无冲突
- 所有标签间距均≥20px，无重叠风险

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 (280,455)，80×30px，点击回退到前一状态
  - 「下一步」按钮：位于 (440,455)，80×30px，点击前进到下一状态
  - 步骤指示文本：位于 (380,465)，显示当前步骤序号如"步骤 3/5"
- 教师操作流程：
  1. 初始状态展示坐标系和图例，介绍 x-t 图像含义
  2. 点击「下一步」展示第一次碰撞，讲解 A 球匀加速运动
  3. 点击「下一步」展示第二次碰撞过程，讲解弹性碰撞速度交换
  4. 点击「下一步」展示第二次碰撞完成，指出位置 4L
  5. 点击「下一步」展示第三次碰撞，指出位置 9L
  6. 点击「下一步」高亮公式框，引导学生发现 n²L 规律

[技术实现]
- JS 库选择：原生 SVG（适合绘制精确坐标的曲线和直线，无需额外库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  x                                               |
  |  ^                                    +--------+ |
  |  |                                    |x_n=n²L | |
  |  |         ·(t₃,9L)                   +--------+ |
  |  |        /                            +--------+ |
  |  |       / ·(t₂,4L)                   |t_n=     | |
  |  |      / /                           |(2n-1)t₁| |
  |  |     / /                            +--------+ |
  |  |    / /                              图例：    |
  |  |   / /                              — A 球    |
  |  |  ·(t₁,L)                           — B 球    |
  |  | /                                  (右上角)  |
  |  |/                                          |
  |  +-------------------------------------------> t
  |  0   t₁    t₂      t₃                         |
  |                                               |
  |              [◀上一步] 步骤 X/5 [下一步▶]      |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量 (0-5)，每个状态对应一组可见元素
  2. 抛物线计算：A 球位移 x = (1/2)at²，在 SVG 中用二次贝塞尔曲线近似，控制点根据物理公式计算
  3. 坐标映射：物理量 (t, x) 映射到像素坐标 (px, py)，px = 80 + t * scale_t，py = 420 - x * scale_x
  4. 动画曲线：使用 CSS transition 或 requestAnimationFrame 实现平滑过渡
  5. 事件绑定：按钮点击事件切换状态，更新各元素 display 属性
- ID 命名规范：所有元素 ID 以 scene3- 为前缀，如 scene3-axis-x、scene3-axis-y、scene3-curve-a1、scene3-point-1、scene3-btn-prev、scene3-btn-next
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
