[分步序列]
步骤0（初始状态）：
- 显示：地面、斜面主体、木板B、滑块A在斜面顶端(40,169)
- 标注：α=37°、9m、L=3m、A、B、μ₁=0.5、μ₂=?
- 隐藏：运动箭头、滑块A的其他位置、"刚好未滑下"标签

- 新增标注：无
- 保持：步骤0的所有静态元素

步骤2（A滑上B，减速滑行）：

- 滑块A从(308,385)动画移动到(450,385)（B中点位置）
- 保持：步骤1的运动箭头1

步骤3（A到达B右端，两者共速）：
- 滑块A移动到(548,385)（B右端）
- 显示："刚好未滑下"标签(550,320)
- 高亮：滑块A和木板B边框加粗显示
- 保持：所有运动箭头

[交互方案]
- 交互类型：分步按钮导航
- 控件说明：
  - 「◀上一步」按钮：位于(320,455)，60×30px，点击返回上一状态
  - 「下一步▶」按钮：位于(420,455)，60×30px，点击进入下一状态
  - 步骤指示器：位于(400,480)，显示"步骤X/3"
- 教师操作流程：
  1. 初始展示装置图，讲解题目已知条件
  2. 点击「下一步」展示A下滑过程，讲解斜面运动阶段
  3. 点击「下一步」展示A在B上滑行，讲解相对运动和摩擦力
  4. 点击「下一步」展示最终状态，讲解"刚好未滑下"的临界条件

[技术实现]
- JS库选择：原生SVG（简单几何图形首选，无需额外库）
- 画布尺寸：800×500px（固定画布）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |    A                                             |
  |   ┌─┐                                            |
  |   │ │\                                           |
  |   └─┘ \  9m                                      |
  |        \      →                                   |
  |         \                                         |
  |          \ α=37°                                  |
  |           └────────────┐                          |
  |                        │ B  L=3m                  |
  |                        └────────────┐             |
  |══════════════════════════════════════════════════| 地面
  |                                                  |
  |     μ₁=0.5                    μ₂=?               |
  |                                                  |
  |              [◀上一步] [下一步▶]                 | 控件栏
  |                  步骤 1/3                        |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用currentState变量(0-3)跟踪当前步骤，steps数组存储每步的显示配置
  2. 滑块A动画：使用requestAnimationFrame实现平滑移动，从起点到终点插值计算位置
  3. 元素显示/隐藏：通过SVG元素的display属性控制，每步更新时遍历配置
  4. 事件绑定：按钮点击事件绑定到stepForward/stepBack函数
  5. 边界检查：步骤0时禁用"上一步"，步骤3时禁用"下一步"
- ID命名规范：所有元素ID以scene1-为前缀
  - scene1-ground（地面）
  - scene1-incline（斜面）
  - scene1-board-b（木板B）
  - scene1-block-a（滑块A）
  - scene1-arrow1（运动箭头1）
  - scene1-arrow2（运动箭头2）
  - scene1-label-alpha（α标签）
  - scene1-label-9m（9m标签）
  - scene1-label-l3m（L=3m标签）
  - scene1-label-mu1（μ₁标签）
  - scene1-label-mu2（μ₂标签）
  - scene1-label-final（刚好未滑下标签）
  - scene1-btn-prev（上一步按钮）
  - scene1-btn-next（下一步按钮）
  - scene1-step-indicator（步骤指示器）
- IIFE隔离：所有JS代码包在(function() { ... })()中，避免全局变量污染
