[图示主题与整合说明]
- 本图示主题：受力分析综合图（A在斜面上 + A在B上 + B的受力）
- 整合的步骤/概念：
  1. A在斜面上的受力分析（重力、支持力、摩擦力）
  2. A滑上B后A的受力分析（重力、支持力、摩擦力）
  3. B的受力分析（压力、摩擦力、重力、支持力）
  4. 力的数值计算与B滑动临界条件判断
- 教学价值：教师可逐步展开受力分析，从简单隔离体到复杂系统，帮助学生理解每个力的来源、方向和大小关系。通过分步展示，学生能清晰看到A与B之间的相互作用力（牛顿第三定律），并通过数值计算判断B是否滑动。

[分步序列]
步骤0（初始状态）：A在斜面上受力
- 显示：左图完整（斜面、滑块A、重力mg、支持力N₁、摩擦力f₁、角度α）
- 隐藏：中图、右图、计算框

步骤1：点击「下一步」→ A滑上B后A的受力
- 显示：左图(淡出50%)、中图完整（木板B、滑块A、重力mg、支持力N₂、摩擦力f₂）
- 隐藏：右图、计算框
- 高亮：中图所有力箭头（蓝色支持力、红色摩擦力）

步骤2：点击「下一步」→ B的受力
- 显示：左图(淡出50%)、中图(淡出50%)、右图完整（木板B、N₂'、f₂'、f₃、mg、N₃）
- 隐藏：计算框
- 高亮：右图所有力箭头，特别标注f₂'与f₂大小相等方向相反

步骤3：点击「下一步」→ 力的数值计算与判断
- 显示：全部三图（左中右均淡出30%）、计算框完整显示
- 计算框内容：
  - f₁=μ₁N₁=μ₁mgcos37°=0.5×m×10×0.8=4m
  - f₂=μ₁N₂=μ₁mg=0.5×m×10=5m
  - f₂'=f₂=5m（牛顿第三定律）
  - N₃=mg+N₂'=mg+mg=2mg
  - f₃max=μ₂N₃=μ₂×2mg
  - 判断：若B滑动，需f₂'>f₃max，即5m>μ₂×2mg，得μ₂<0.25
  - 结论：B会滑动，μ₂=0.25（临界值）

- 画布尺寸：800×500px（固定）
- 布局草图：
  ```

  +----------------------------------------------------------+
  |                    受力分析 (标题 y=35)                   |
  +----------------------------------------------------------+
  |  [左图]        |    [中图]        |    [右图]             |

  |  x=40-280      |    x=300-540     |    x=560-780          |

  |  [计算结果区 y=340-420，浅绿背景，步骤3显示]               |
  +----------------------------------------------------------+
  |     [◀上一步]          [下一步▶]      [步骤X/4]           |
  |     (280,455)          (440,455)      (400,490)          |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量currentStep(0-3)跟踪当前步骤，steps数组存储每步的显示/隐藏配置
  2. 箭头绘制：用SVG marker-end定义箭头，line元素绘制箭身
  3. 淡出效果：用opacity属性控制，步骤0时opacity=1，后续步骤逐步降低
  4. 事件绑定：按钮点击事件调用updateStep()函数更新状态
  5. ID命名规范：所有元素ID以scene2-为前缀，如scene2-left-slope、scene2-arrow-mg1等
  6. IIFE隔离：所有JS代码包在(function() { ... })()中，避免全局污染
