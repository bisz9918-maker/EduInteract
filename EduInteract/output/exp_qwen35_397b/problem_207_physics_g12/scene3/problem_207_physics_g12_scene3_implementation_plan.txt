[图示主题与整合说明]
- 本图示主题：运动学分析与临界条件——滑块 A 在木板 B 上滑行的 v-t 图像分析
- 整合内容：A 在 B 上滑行的 v-t 图像、相对位移关系、"刚好未滑下"的临界条件可视化
- 教学价值：教师可通过分步演示 v-t 图的构建过程，直观展示 A、B 的速度变化规律，通过面积差理解相对位移的物理意义，帮助学生掌握"刚好未滑下"的临界条件（相对位移等于木板长度 L）

[分步序列]
- 初始状态（步骤 0）：显示 v-t 坐标系（坐标轴、刻度、轴标签），显示图例框（仅边框和标题），显示空白的方程区背景
- 步骤 1：点击「下一步」→ 绘制 A 的 v-t 图线（蓝色从 v₀=6m/s 开始），显示 v₀=6m/s 标签，显示 A 位移面积（蓝色填充），显示 S_A 标签
- 步骤 2：点击「下一步」→ 绘制 B 的 v-t 图线（绿色从 0 开始），显示 B 位移面积（绿色填充），显示 S_B 标签
- 步骤 3：点击「下一步」→ 高亮交点（红色实心圆），显示 t 共速标签和 v_共标签，显示相对位移面积（红色填充），显示 S_A-S_B=L=3m 标签
- 步骤 4：点击「下一步」→ 显示完整方程和计算结果：
  "对 A：a_A = -μ₁g = -5 m/s²
   对 B：a_B = (μ₁mg - μ₂·2mg)/m = μ₁g - 2μ₂g
   共速时：v₀ + a_A·t = a_B·t
   相对位移：S_A - S_B = L = 3m
   解得：μ₂ = 0.2"

[标签冲突检查]
- 标签"v(m/s)"：坐标 (85,60)
- 标签"t(s)"：坐标 (660,395)
- 标签"v₀=6m/s"：坐标 (110,125)
- 标签"t_共"：坐标 (400,405)
- 标签"v_共"：坐标 (415,250)
- 标签"S_A"：坐标 (220,300)
- 标签"S_B"：坐标 (280,350)
- 标签"S_A-S_B=L"：坐标 (200,200)
- 图例文本：坐标 (560,95), (560,120), (560,145)
- 方程文本：坐标 (100,440) 起始

冲突检查：
- "v(m/s)"与"v₀=6m/s"：垂直距离 65px → 无冲突
- "t_共"与 t 轴刻度：垂直距离 10px → 需调整 t_共到 (400,415)，距离 20px
- "v_共"与 B 图线：水平距离 15px → 无冲突
- "S_A"与"S_B"：距离 √((280-220)²+(350-300)²) = √(3600+2500) ≈ 78px → 无冲突
- "S_A-S_B=L"与其他标签：最近为"S_A"，距离 √((220-200)²+(300-200)²) ≈ 102px → 无冲突
- 图例与主图区：图例 x=520，主图区 x≤500 → 无冲突
- 方程区与主图区：方程区 y=420，主图区 y≤400 → 无冲突

解决方案：将"t_共"标签从 (400,405) 调整到 (400,415)，确保与 t 轴刻度有足够间距。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 (580,450)，80×30px，点击后退到前一步状态
  - 「下一步」按钮：位于 (680,450)，80×30px，点击前进到下一步状态
  - 步骤指示器：显示"步骤 X/5"，位于两按钮之间 (660,455)
- 教师操作流程：
  1. 初始状态展示空白坐标系，引导学生建立 v-t 图概念
  2. 点击「下一步」展示 A 的减速过程，讲解 A 的加速度和位移
  3. 点击「下一步」展示 B 的加速过程（若滑动），对比 A、B 运动
  4. 点击「下一步」高亮共速时刻，讲解临界条件的几何意义（面积差=L）
  5. 点击「下一步」展示完整方程，总结计算过程

[技术实现]
- JS 库选择：原生 SVG（简单几何图形和坐标系，无需额外库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [800 × 500 画布]
  +--------------------------------------------------+
  |  v(m/s)                                          |
  |    6 +----* (v₀)                    [图例]       |
  |      |   / \                                      |
  |    4 |  /   \                                     |
  |      | /     \                                    |
  |    2 |/       \                                   |
  |      |         * (共速点)                         |
  |    0 +---------+---------+---------+---- t(s)     |
  |      0        0.2       0.4       0.6             |
  |                                                    |
  |  [方程区：计算过程和结果]                          |
  |                                                    |
  |              [◀上一步] [步骤 3/5] [下一步▶]        |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-4），数组存储每步的可见元素 ID 列表
  2. 坐标计算：v-t 图比例尺：v 轴 60px/m/s，t 轴 100px/0.2s
  3. 动画曲线：使用 CSS transition 实现图线绘制的过渡效果（stroke-dasharray 技巧）
  4. 事件绑定：按钮点击事件切换状态，更新可见元素
  5. 面积填充：使用 SVG <polygon> 元素，fill-opacity 控制透明度
- ID 命名规范：所有交互元素 ID 必须以 scene3- 为前缀
  - scene3-axis-v, scene3-axis-t（坐标轴）
  - scene3-line-a, scene3-line-b（A、B 图线）
  - scene3-area-a, scene3-area-b, scene3-area-rel（面积填充）
  - scene3-point-intersect（交点）
  - scene3-label-*（所有标签）
  - scene3-legend-*（图例元素）
  - scene3-equation（方程区）
  - scene3-btn-prev, scene3-btn-next（按钮）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
