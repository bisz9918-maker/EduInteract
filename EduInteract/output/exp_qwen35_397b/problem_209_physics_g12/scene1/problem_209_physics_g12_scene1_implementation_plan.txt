[分步序列]
步骤 0（初始状态）：
- 显示：左右斜面、水平基线、倾角θ弧及标签、左右物块
- 标签："上滑"、"下滑"、两个"θ"
- 隐藏：所有力箭头和分力箭头

步骤 1（上滑受力）：
- 新增显示：左侧重力 mg 箭头及标签、左侧支持力 N 箭头及标签、左侧摩擦力 f 箭头及标签（沿斜面向下）
- 高亮：左侧物块边框加粗

步骤 2（上滑合力）：
- 新增显示：左侧 mgcosθ 虚线箭头及标签、左侧 mgsinθ 虚线箭头及标签
- 新增显示：左侧合力 F_合 粗箭头及标签（沿斜面向下，表示 mgsinθ+f 的合力）
- 高亮：左侧合力箭头

步骤 3（下滑受力）：
- 新增显示：右侧重力 mg 箭头及标签、右侧支持力 N 箭头及标签、右侧摩擦力 f 箭头及标签（沿斜面向上）
- 高亮：右侧物块边框加粗
- 保持：左侧所有元素可见但降低透明度至 50%

步骤 4（下滑合力）：
- 新增显示：右侧 mgcosθ 虚线箭头及标签、右侧 mgsinθ 虚线箭头及标签
- 新增显示：右侧合力 F_合 粗箭头及标签（沿斜面向下，表示 mgsinθ-f 的合力）
- 高亮：右侧合力箭头
- 保持：左侧所有元素可见但透明度 50%

步骤 5（对比总结）：
- 恢复：左右两侧所有元素透明度 100%
- 高亮：左右摩擦力箭头（红色加粗），强调方向相反
- 显示：底部总结文本框"摩擦力方向始终与相对运动方向相反"

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - "上一步"按钮：位于 (320,460)，80×30px，点击返回上一状态
  - "下一步"按钮：位于 (400,460)，80×30px，点击进入下一状态
  - 步骤指示：位于 (400,430)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始展示斜面与物块（步骤 0），介绍问题情境
  2. 点击"下一步"展示上滑阶段受力（步骤 1），讲解重力、支持力、摩擦力方向
  3. 点击"下一步"展示上滑合力（步骤 2），讲解力的分解与合成
  4. 点击"下一步"展示下滑阶段受力（步骤 3），重点强调摩擦力方向改变
  5. 点击"下一步"展示下滑合力（步骤 4），对比两阶段合力差异
  6. 点击"下一步"进入总结（步骤 5），强调摩擦力方向规律

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单，无需复杂库；SVG 箭头和线条清晰，适合受力分析图
- 画布尺寸：800×500px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  [上滑]                    [下滑]                |
  |     /|                        /|                 |
  |    / | 受力图                / | 受力图          |
  |   /θ |                      /θ |                 |
  |  /___|                     /___|                 |
  |  [mg][N][f][F_合]         [mg][N][f][F_合]      |
  |                                                  |
  |                                                  |
  |              步骤 0/5                            |
  |         [◀上一步] [下一步▶]                      |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量（0-5），每个步骤对应一组显示/隐藏状态
  2. 元素分组：使用 SVG <g> 元素按功能分组（left-forces, right-forces, left-components, right-components 等）
  3. 箭头定义：使用 <marker> 定义箭头头部，统一样式
  4. 透明度控制：使用 CSS class .dimmed { opacity: 0.5 } 实现非当前焦点区域淡化
  5. 事件绑定：按钮点击事件切换 currentStep，调用 updateDisplay() 函数更新各元素可见性
- ID 命名规范：
  - 所有元素 ID 以 scene1- 为前缀
  - 示例：scene1-left-block, scene1-right-block, scene1-left-mg, scene1-right-f, scene1-btn-prev, scene1-btn-next, scene1-step-indicator
- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染
- 按钮样式：矩形圆角 rx=5，填充 #1976d2，文字白色，hover 效果加深
