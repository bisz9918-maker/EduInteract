[分步序列]
- 初始状态（步骤 0）：显示完整 v-t 图线（两段蓝色折线）、坐标轴、原点 O、轴名 t 和 v
- 步骤 1：显示 3 个关键点红色圆点，同时显示标签 v₀、t₁、3t₁、-v₁
- 步骤 2：高亮上滑段（线宽增至 5px 或叠加黄色半透明），显示上滑段斜率三角形（灰色虚线），显示阶段标签"上滑阶段"
- 步骤 3：高亮下滑段（线宽增至 5px 或叠加黄色半透明），显示下滑段斜率三角形（灰色虚线），显示阶段标签"下滑阶段"
- 步骤 4：显示加速度标注框 a₁ = v₀/t₁ 和 a₂ = v₁/(2t₁)，框内文字为公式形式
- 步骤 5：在加速度框下方显示联立提示文字"结合受力分析列方程求解 μ"

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 按钮"◀ 上一步"：位置 (280,460)，宽 100px，高 35px，灰色背景 #e0e0e0
  - 按钮"下一步 ▶"：位置 (420,460)，宽 100px，高 35px，蓝色背景 #1565c0，白色文字
  - 步骤指示器：位置 (550,465)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始展示完整 v-t 图，让学生观察图像形状
  2. 点击"下一步"显示关键点，引导学生读取坐标
  3. 点击"下一步"高亮上滑段，讲解上滑加速度 a₁ = v₀/t₁
  4. 点击"下一步"高亮下滑段，讲解下滑加速度 a₂ = v₁/(2t₁)
  5. 点击"下一步"显示加速度公式框，总结两段加速度表达式
  6. 点击"下一步"显示联立提示，过渡到受力分析环节
  7. 可随时点击"上一步"回退复习

[技术实现]
- JS 库选择：原生 SVG（简单坐标系和折线图，无需额外库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  v                                               |
  |  ^                                               |
  |  |  v₀●                                          |
  |  |   \                                          |
  |  |    \  上滑阶段                                |
  |  |     \                                        |
  |  |      \                                       |
  |  |       ●t₁─────────── 下滑阶段                |
  |  |        \                                     |
  |  |         \                                    |
  |  |          \                                   |
  |  |           ●-v₁                               |
  |  |                                              |
  |  +──────────────────────────────────────→ t     |
  |  O    t₁              3t₁                       |
  |                                                  |
  |        [a₁=v₀/t₁]  [a₂=v₁/(2t₁)]                |
  |                                                  |
  |              [◀上一步] [下一步▶]  步骤 X/5       |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-5) 跟踪当前步骤，数组 steps 存储每步需显示的元素 ID 列表
  2. 坐标计算：所有坐标硬编码，确保与布局表一致
  3. 动画曲线：元素显示/隐藏使用 CSS transition，opacity 从 0 到 1，时长 300ms
  4. 事件绑定：按钮点击事件绑定到 stepChange 函数，更新 currentStep 并刷新显示状态
  5. 边界处理：步骤 0 时禁用"上一步"，步骤 5 时禁用"下一步"
- ID 命名规范：所有元素 ID 以 scene2- 为前缀，如 scene2-axis-t、scene2-line-up、scene2-point-a、scene2-label-v0、scene2-btn-prev、scene2-btn-next
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
