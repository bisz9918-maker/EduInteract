[图示主题与整合说明]

冲突检查：
- "K₁"(400,60) 与 "电源+"(410,55)：间距约 11px → 轻微接近，但 K₁ 在开关上方，电源 + 在电源符号上方，垂直方向错开，可接受
- "K₁"(400,60) 与 "电源-"(390,55)：间距约 11px → 同上，可接受
- "Na⁺"(340,305) 与 "Cl⁻"(460,305)：间距 120px → 无冲突
- "C（阳极）"(290,240) 与 "C"(290,290)：垂直间距 50px → 无冲突
- "Fe（阴极）"(510,240) 与 "Fe"(510,290)：垂直间距 50px → 无冲突
- "e⁻"(485,135) 与 "K₂"(400,100)：间距约 100px → 无冲突
- 反应式标签与烧杯底部：反应式 y=430，烧杯底部 y=420，间距 10px → 调整为 y=445，确保间距≥15px

解决方案：将反应式 y 坐标调整为 445，确保与烧杯底部有足够间距。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 (280,465)，点击后返回上一状态
  - 「下一步」按钮：位于 (420,465)，点击后进入下一状态
  - 状态指示器：位于 (360,465)，显示当前步骤（如"步骤 2/4"）
- 教师操作流程：
  1. 初始状态展示基础装置，讲解电解池的基本构造
  2. 点击「下一步」展示电极极性，讲解 C 棒为阳极、Fe 棒为阴极的判断依据
  3. 点击「下一步」展示电子流向，讲解外电路中电子从电源负极流向阴极
  4. 点击「下一步」展示离子迁移，讲解溶液中阳离子向阴极移动、阴离子向阳极移动
  5. 点击「下一步」展示电极反应式，讲解两极发生的氧化还原反应
  6. 可随时点击「上一步」回退复习关键概念

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript
  - 原因：本场景为 2D 静态图示加简单动画，原生 SVG 足够胜任，无需引入重型库
  - 离子移动动画使用 CSS transition 或 requestAnimationFrame 实现
- 画布尺寸：800 × 500 px（固定画布）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                    电源 (+ -)                     |
  |              K₁ (断开)  K₂ (闭合)                 |
  |                   |        |                      |
  |              C棒  |        |  Fe棒                |
  |              [C]  |        |  [Fe]                |
  |           +-------+--------+-------+              |
  |           |  饱和 NaCl 溶液        |              |
  |           |  Na⁺→    ←Cl⁻         |              |
  |           +------------------------+              |
  |                                                  |
  |     2Cl⁻-2e⁻=Cl₂↑        2H⁺+2e⁻=H₂↑             |
  |                                                  |
  |         [◀上一步]  步骤 2/4  [下一步▶]           |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-4）跟踪当前步骤，steps 数组存储每步的显示/隐藏元素 ID 列表
  2. 坐标计算：所有元素使用绝对坐标（像素），确保布局精确
  3. 动画曲线：离子移动使用 linear 缓动，电子流向使用 dashed 线条 offset 动画
  4. 事件绑定：按钮点击事件绑定到 updateStep() 函数，更新 DOM 元素 display 属性
  5. 元素 ID 规范：所有元素 ID 以 scene2- 为前缀，如 scene2-c-electrode、scene2-fe-electrode、scene2-k1-switch 等
  6. IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
- ID 命名示例：
  - scene2-beaker（烧杯）
  - scene2-solution（溶液）
  - scene2-c-electrode（C 棒）
  - scene2-fe-electrode（Fe 棒）
  - scene2-power（电源）
  - scene2-k1-switch（开关 K₁）
  - scene2-k2-switch（开关 K₂）
  - scene2-wire-*（导线各段）
  - scene2-electron-arrow（电子流向箭头）
  - scene2-na-ions（Na⁺ 离子组）
  - scene2-cl-ions（Cl⁻ 离子组）
  - scene2-na-arrow（Na⁺ 迁移箭头）
  - scene2-cl-arrow（Cl⁻ 迁移箭头）
  - scene2-c-anode-label（C 阳极标签）
  - scene2-fe-cathode-label（Fe 阴极标签）
  - scene2-c-reaction（C 极反应式）
  - scene2-fe-reaction（Fe 极反应式）
  - scene2-prev-btn（上一步按钮）
  - scene2-next-btn（下一步按钮）
  - scene2-step-indicator（步骤指示器）
