    **题目原文：**

    如图，边长都是 1 的正方形和正三角形，其一边在同一水平线上，三角形沿该水平线自左向右匀速穿过正方形．设穿过的时间为 t，正方形与三角形重合部分的面积为 S(空白部分)，那么 S 关于 t 的函数大致图象为 (  )

    **题目分析：**

    本题考察动点问题中重合面积随时间的变化规律。关键要素：
    - 正方形边长 = 1，正三角形边长 = 1
    - 正三角形的高 h = √3/2 ≈ 0.866 < 1，因此三角形可完全进入正方形内部
    - 三角形匀速运动，时间 t 与位移 x 成正比

    **解题思路：**

    1. **进入阶段**：三角形从左侧开始进入正方形，重合面积从 0 开始增加。由于三角形是斜边，重合部分的宽度随位移非线性变化，面积 S 与时间 t 呈二次函数关系（曲线上升）

    2. **平台阶段**：当三角形完全进入正方形后，重合面积等于三角形总面积 S = √3/4，保持不变

    3. **离开阶段**：三角形开始离开正方形，重合面积对称地非线性减少至 0（曲线下降）

    因此 S-t 图像应为：曲线上升 → 平台 → 曲线下降，对应选项 **C**（梯形形状）

    **图示规划说明：**

    - SCENE_1：动态展示三角形穿过正方形的 5 个关键阶段，直观呈现运动过程
    - SCENE_2：交互式 S-t 函数图像，拖拽三角形位置时实时显示对应时刻的重合面积点

    **教学引导要点：**

    1. 引导学生观察每个阶段重合部分的形状变化

    2. 重点讲解步骤 1→2：进入过程中，重合面积如何从 0 增加到最大值
       - 提问：面积是均匀增加吗？为什么？
       - 提示：三角形宽度随高度变化，因此面积变化是非线性的

    3. 重点讲解步骤 2：为什么会有平台期？
       - 因为三角形高 √3/2 < 正方形边长 1，三角形可完全容纳在正方形内
       - 此时重合面积恒等于三角形面积

    4. 步骤 3→4 与步骤 1→2 对称，面积非线性减少

    **关键公式：**

    正三角形面积公式：S = (√3/4) × 边长² = √3/4 ≈ 0.433

    **教学引导要点：**

    1. 让学生拖动滑块，观察三角形位置与 S-t 图像上红点的对应关系

    2. 引导学生发现：
       - 进入阶段：红点沿曲线上升（非线性）
       - 平台阶段：红点水平移动（面积不变）
       - 离开阶段：红点沿曲线下降（非线性）

    3. 对比四个选项：
       - A：直线上升下降，错误（面积变化不是线性的）
       - B：无平台期，错误（三角形可完全进入）
       - C：正确（曲线上升→平台→曲线下降）
       - D：无平台期且曲线形状不对，错误

    **完整解答：**

    设三角形移动速度为 v，位移 x = vt

    - 当 0 ≤ x < 1 时（进入阶段）：重合面积 S 随 x 二次函数增加
    - 当 1 ≤ x < 2 时（平台阶段）：S = √3/4（常数）
    - 当 2 ≤ x < 3 时（离开阶段）：S 随 x 二次函数减少至 0

    因此 S-t 图像为梯形形状，答案选 **C**

    **课堂讲解建议：**

    1. 先用 SCENE_1 展示运动过程，建立直观印象
    2. 再用 SCENE_2 让学生动手拖拽，理解函数图像的生成
    3. 最后总结：动点问题中，重合面积的变化规律取决于图形形状和相对位置
