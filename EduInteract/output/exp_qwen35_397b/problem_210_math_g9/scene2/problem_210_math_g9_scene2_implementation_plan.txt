[分步序列]
本场景采用连续拖拽交互，无分步导航。状态定义如下：
- 初始状态（滑块在最左端 t=0）：
  - 三角形在正方形左侧，未接触
  - 重合面积 S=0
  - 动态红点在坐标原点 (80,440)
  - S-t 曲线完整显示（绿色梯形）
  
- 拖拽过程状态（t 从 0 到 1）：
  - 三角形向右移动，开始进入正方形
  - 重合部分逐渐增大（三角形进入部分）
  - 动态红点沿曲线上升段移动
  
- 拖拽过程状态（t 从 1 到 2）：
  - 三角形完全在正方形内部
  - 重合面积保持最大值 S_max = √3/4
  - 动态红点沿曲线平台段移动
  
- 拖拽过程状态（t 从 2 到 3）：
  - 三角形开始离开正方形
  - 重合部分逐渐减小
  - 动态红点沿曲线下降段移动
  
- 最终状态（滑块在最右端 t=3）：
  - 三角形完全离开正方形
  - 重合面积 S=0
  - 动态红点回到 t 轴 (460,440)

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：
  - 滑块轨道：位于 y=480，从 x=100 到 x=500，长度 400px
  - 滑块手柄：蓝色圆点，可左右拖拽，限制在轨道范围内
  - 选项切换按钮（可选）：四个小按钮显示 A/B/C/D，点击可高亮对应曲线
  
- 教师操作流程：
  1. 初始状态展示完整 S-t 曲线（正确答案 C）
  2. 拖拽滑块从左到右，让学生观察三角形位置与红点位置的对应
  3. 在平台期暂停，强调此时三角形完全在正方形内，面积最大且不变
  4. 可点击选项按钮对比其他错误选项的曲线形状
  5. 引导学生理解为何答案是 C（梯形）而非 A（三角形）、B（抛物线）、D（钟形）

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何形状简单，无需复杂库；SVG 便于动态更新多边形顶点
  
- 画布尺寸：800 × 500 px（固定）
  
- 布局草图（ASCII）：
  ```
  [800 × 500 画布]
  +--------------------------------------------------+
  |  [运动示意图区 y=20~220]                         |
  |     △        □        → 三角形穿过正方形          |
  |     重合部分蓝色高亮                             |
  +--------------------------------------------------+
  |  [S-t 坐标系区 y=240~460]                        |
  |     S ↑                                          |
  |       |    ╱¯¯¯¯¯╲      绿色曲线                 |
  |       |   /       \     红点●                    |
  |     O +──┴─────────┴──→ t                        |
  +--------------------------------------------------+
  |  [控件栏 y=470~490]                              |
  |     o━━━━━━━━━━━━●━━━━━━━━━━━━o  滑块            |
  +--------------------------------------------------+
  |  [选项区 x=540~620]                              |
  |     A: △  B: ∩  C: ▯  D: ∿                       |
  +--------------------------------------------------+
  ```

- 关键实现要点：
  1. 状态机：单状态连续交互，无需步骤切换
  2. 坐标计算：
     - 三角形位置：sliderValue 映射到 x 坐标 (130~430)
     - 重合面积：分段函数计算
       * t∈[0,1]：S = (√3/4) × t²（三角形进入）
       * t∈[1,2]：S = √3/4（完全在内）
       * t∈[2,3]：S = (√3/4) × (3-t)²（三角形离开）
     - 红点位置：根据当前 t 值计算曲线上对应点坐标
  3. 重合多边形计算：根据三角形与正方形的交集动态计算顶点
  4. 事件绑定：滑块的 mousedown/mousemove/mouseup 事件，支持拖拽
  5. 动画平滑：requestAnimationFrame 更新红点位置
  
- ID 命名规范：
  - 所有元素 ID 以 "scene2-" 为前缀
  - 示例：scene2-square, scene2-triangle, scene2-overlap, scene2-curve, scene2-dot, scene2-slider, scene2-slider-handle
  
- IIFE 隔离：
  ```javascript
  (function() {
    // 所有场景 2 的代码包在此 IIFE 中
    // 避免与场景 1 或其他场景冲突
  })();
  ```

- 数学公式：
  - 正三角形面积公式：S = (√3/4) × 边长²
  - 最大重合面积：S_max = √3/4 ≈ 0.433
  - 分段函数需用 JavaScript 条件判断实现
