[分步序列]
- 初始状态（步骤 0）：显示四边形 ABCD 基础图形（四条边 AB、BC、CD、DA）、对角线 BD、线段 AE、线段 CF、所有顶点标签 A/B/C/D/E/F
- 步骤 1：点击「下一步」→ 在 AB 和 CD 边上显示平行箭头标记（双线箭头），表示 AB∥CD
- 步骤 2：点击「下一步」→ 在 AB 和 CD 边中点处显示等长标记（短划线），表示 AB=CD
- 步骤 3：点击「下一步」→ 高亮显示内错角∠ABE 和∠CDF（蓝色弧线），并在弧线旁标注"相等"文字（可选）
- 步骤 4：点击「下一步」→ 显示∠1 和∠2 的角度弧线及标签，完成所有已知条件标注

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 底部左侧 (x=350, y=460)，点击后回退到前一状态
  - 「下一步」按钮：位于 SVG 底部右侧 (x=450, y=460)，点击后进入下一状态
  - 状态指示器：位于底部中央 (x=400, y=460)，显示当前步骤编号（如"步骤 1/4"）
- 教师操作流程：
  1. 初始状态展示基础图形，让学生观察四边形结构
  2. 点击「下一步」展示平行条件，引导学生识别 AB∥CD
  3. 点击「下一步」展示等长条件，强调 AB=CD
  4. 点击「下一步」高亮内错角，说明由平行可得∠ABE=∠CDF
  5. 点击「下一步」展示∠1 和∠2，为后续全等判定讨论做准备
  6. 教师可随时点击「上一步」回退复习某个条件

[技术实现]
- JS 库选择及原因：原生 SVG。理由：几何图形简单，无需复杂动画库；SVG 缩放不失真，适合几何图示；代码简洁易维护。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +------------------------------------------+
  |  A(180,120)         D(680,120)           |
  |     /|               |\                   |
  |    / |               | \                  |
  |   /  |∠1            ∠2|  \                |
  |  B(120,380)---E------F---D(680,140)      |
  |   \  |               |  /                 |
  |    \ |               | /                  |
  |     \|               |/                   |
  |  C(620,380)                              |
  |                                          |
  |         [◀上一步] 步骤 1/4 [下一步▶]      |
  +------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-4），每个状态对应一组可见元素
  2. 元素分组：将平行标记、等长标记、内错角弧线、∠1∠2 弧线分别放入独立的<g>组，通过 display 属性控制显示/隐藏
  3. 坐标计算：E 点 = B + 0.25*(D-B)，F 点 = B + 0.75*(D-B)
  4. 事件绑定：按钮点击事件切换 currentState，调用 updateDisplay() 函数更新各组可见性
  5. 边界处理：第一步禁用「上一步」，最后一步禁用「下一步」
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀
  - scene1-quad-abcd（四边形）
  - scene1-diag-bd（对角线）
  - scene1-seg-ae（线段 AE）
  - scene1-seg-cf（线段 CF）
  - scene1-parallel-mark（平行标记组）
  - scene1-equal-mark（等长标记组）
  - scene1-alt-angle（内错角弧线组）
  - scene1-angle1（∠1 弧线及标签）
  - scene1-angle2（∠2 弧线及标签）
  - scene1-btn-prev（上一步按钮）
  - scene1-btn-next（下一步按钮）
  - scene1-step-indicator（步骤指示器）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
