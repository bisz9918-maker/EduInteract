[图示主题与整合说明]
- 本图示主题：四个选项的全等判定对比分析
- 整合的步骤/概念：四个选项 A/B/C/D 的逐一展示，每个选项对应的条件可视化、全等判定类型（SAS/ASA/SSA）、能否判定全等的结论
- 教学价值：教师可逐个点击选项按钮，对比展示每个条件下的全等判定情况，帮助学生理解为什么 SSA 不能判定全等，而 SAS/ASA 可以。通过视觉对比强化全等三角形判定定理的理解。

[分步序列]
多状态切换（4 个状态对应选项 A/B/C/D）：

状态 0（初始/无选择）：
- 显示基础图形：平行四边形 ABCD、对角线 BD、点 E、F、线段 AE、CF
- 显示∠1、∠2 标注
- 显示 AB=CD 等长标记
- 判定框显示"请选择选项"
- 所有按钮默认灰色

状态 A（点击选项 A 按钮）：
- 高亮线段 AE 和 CF（蓝色 #1565c0, 3px）
- 在 AE 和 CF 上添加等长标记（单短线）
- 判定框显示：
  - 判定类型："SSA"
  - 结论标识："✗"（红色 #c62828）
  - 结论文字："不能判定全等"
  - 条件标注："AE=CF, AB=CD, ∠ABE=∠CDF"
- 按钮 A 背景变蓝色

状态 B（点击选项 B 按钮）：
- 高亮线段 BE 和 FD（蓝色 #1565c0, 3px）
- 在 BE 和 FD 上添加等长标记（单短线）
- 判定框显示：
  - 判定类型："SAS"
  - 结论标识："✓"（绿色 #2e7d32）
  - 结论文字："可判定全等"
  - 条件标注："BE=FD, AB=CD, ∠ABE=∠CDF"
- 按钮 B 背景变蓝色

状态 C（点击选项 C 按钮）：
- 高亮线段 BF 和 DE（蓝色 #1565c0, 3px）
- 在 BF 和 DE 上添加等长标记（单短线）
- 添加推导提示："BF=DE → BE=FD"
- 判定框显示：
  - 判定类型："SAS"
  - 结论标识："✓"（绿色 #2e7d32）
  - 结论文字："可判定全等"
  - 条件标注："BF=DE → BE=FD, AB=CD, ∠ABE=∠CDF"
- 按钮 C 背景变蓝色

状态 D（点击选项 D 按钮）：
- 高亮∠1 和∠2（蓝色弧线 #1565c0, 2px）
- 判定框显示：
  - 判定类型："ASA"
  - 结论标识："✓"（绿色 #2e7d32）
  - 结论文字："可判定全等"
  - 条件标注："∠1=∠2, AB=CD, ∠ABE=∠CDF"
- 按钮 D 背景变蓝色

[交互方案]
- 交互类型：多状态切换（4 个按钮对应选项 A/B/C/D）
- 控件说明：
  - 按钮 A（scene2-btn-a）：(120,450), 130×35px，显示"选项 A: AE=CF"
  - 按钮 B（scene2-btn-b）：(260,450), 130×35px，显示"选项 B: BE=FD"
  - 按钮 C（scene2-btn-c）：(400,450), 130×35px，显示"选项 C: BF=DE"
  - 按钮 D（scene2-btn-d）：(540,450), 130×35px，显示"选项 D: ∠1=∠2"
- 教师操作流程：
  1. 初始状态展示基础图形，让学生观察已知条件（AB∥CD, AB=CD）
  2. 点击按钮 A，展示 SSA 情况，解释为什么不能判定全等
  3. 点击按钮 B，展示 SAS 情况，解释可以判定全等
  4. 点击按钮 C，展示通过 BF=DE 推导 BE=FD 的过程，再用 SAS 判定
  5. 点击按钮 D，展示 ASA 情况，解释可以判定全等
  6. 对比四个选项，得出答案 A 是不能判定的条件

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |   A _______________ D                            |
  |    /|             /|        [判定分析区]         |
  |   / | 1          / | F      +----------------+   |
  |  /  |           /  |/       | 判定类型：SAS  |   |
  | B___|__________C   /        | 结论：✓        |   |
  |      E            /         | 条件：BE=FD    |   |
  |                   /         +----------------+   |
  |                                                  |
  |                                                  |
  |  [A]    [B]    [C]    [D]   <- 选项按钮栏        |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用 currentState 变量跟踪当前选中状态（null/'A'/'B'/'C'/'D'）
  2. 所有交互元素 ID 以 scene2- 为前缀（如 scene2-btn-a, scene2-ae-line）
  3. JS 代码包在 IIFE 中：(function() { ... })()
  4. 按钮点击事件：点击时更新 currentState，调用 updateDisplay() 函数
  5. updateDisplay() 函数：根据 currentState 显示/隐藏对应元素，更新判定框内容
  6. 等长标记：用短线段组表示，垂直于被标记线段
  7. 颜色切换：选中按钮背景变蓝色 (#1565c0)，文字变白色；判定结论用绿色/红色
- ID 命名规范：
  - 图形元素：scene2-AB, scene2-BC, scene2-CD, scene2-DA, scene2-BD
  - 三角形边：scene2-AE, scene2-CF, scene2-BE, scene2-FD, scene2-BF, scene2-DE
  - 点标签：scene2-label-A, scene2-label-B, ..., scene2-label-F
  - 角度标注：scene2-angle1, scene2-angle2
  - 按钮：scene2-btn-a, scene2-btn-b, scene2-btn-c, scene2-btn-d
  - 判定框元素：scene2-judge-type, scene2-judge-result, scene2-judge-text, scene2-judge-condition
  - 等长标记：scene2-mark-AB, scene2-mark-CD, scene2-mark-AE, scene2-mark-CF 等
