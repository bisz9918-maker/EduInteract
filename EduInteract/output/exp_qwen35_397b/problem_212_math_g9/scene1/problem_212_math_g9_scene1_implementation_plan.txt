[分步序列]
- 初始状态（步骤 0）：显示题目基础图形——大三角形 ABC 框架、内部线段 DE/DF/EF、所有顶点标签 A/B/C/D/E/F。计数器显示"0/5"。无高亮填充。
- 步骤 1：点击「下一步」→ 高亮显示△ADE（填充#1565c0 25% 透明），计数器更新为"1/5"。其他三角形无填充。
- 步骤 2：点击「下一步」→ △ADE 变为已计数状态（填充#2e7d32 20% 透明），新增高亮△BDF（#1565c0 25% 透明），计数器更新为"2/5"。
- 步骤 3：点击「下一步」→ △ADE 和△BDF 保持已计数状态，新增高亮△CEF（#1565c0 25% 透明），计数器更新为"3/5"。
- 步骤 4：点击「下一步」→ 前三个三角形保持已计数状态，新增高亮△DEF（#1565c0 25% 透明），计数器更新为"4/5"。
- 步骤 5：点击「下一步」→ 前四个三角形保持已计数状态，新增高亮△ABC（#1565c0 25% 透明），计数器更新为"5/5"。
- 步骤 6（最终）：所有 5 个三角形均显示为已计数状态（#2e7d32 20% 透明），在图形下方显示结果文本"共 5 个三角形"，计数器保持"5/5"。

冲突检查：
- "A"(400,60) 与 计数器(700,50)：水平距离 300px → 无冲突
- "D"(285,230) 与 "E"(515,230)：水平距离 230px → 无冲突
- "B"(180,400) 与 "F"(400,405)：水平距离 220px → 无冲突
- "F"(400,405) 与 "C"(620,400)：水平距离 220px → 无冲突
- 结果文本(400,350) 与 F 标签(400,405)：垂直距离 55px → 无冲突
- 所有标签与线段：标签均放置在顶点外侧，不压在线段上 → 无冲突

结论：所有标签间距均≥20px，无重叠冲突。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于 SVG 内底部左侧 (250,460)，点击后回退到上一个步骤，恢复上一步的视觉状态
  - 「下一步 ▶」按钮：位于 SVG 内底部右侧 (450,460)，点击后进入下一个步骤，更新高亮区域和计数器
  - 计数器：位于右上角 (700,50)，实时显示当前计数进度（如"3/5"）
- 教师操作流程：
  1. 初始状态展示原图，让学生观察图形结构
  2. 点击「下一步」逐个高亮三角形，引导学生跟随计数
  3. 每步可暂停讲解该三角形的顶点构成
  4. 到达步骤 6 后展示最终答案，强调系统性计数方法
  5. 可随时点击「上一步」回退复习特定三角形

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单，无需复杂库；原生 SVG 对多边形填充、路径绘制支持良好；代码轻量易维护
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +------------------------------------------+
  |                              [计数器]    |
  |                                          |
  |              A                           |
  |             / \                          |
  |            /   \                         |
  |           D-----E                        |
  |          / \   / \                       |
  |         /   \ /   \                      |
  |        B-----F-----C                     |
  |                                          |
  |              [结果文本]                  |
  |                                          |
  |     [◀ 上一步]          [下一步 ▶]       |
  +------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量（0-6）跟踪当前步骤，steps 数组存储每步的配置（高亮三角形列表、计数器文本、是否显示结果）
  2. 三角形填充层：使用 5 个独立的 polygon 元素，每个对应一个三角形，通过 class 控制显示状态（current-highlight / counted / hidden）
  3. 坐标计算：所有顶点坐标硬编码，确保与布局表一致
  4. 事件绑定：按钮点击事件触发 updateStep() 函数，根据 direction 参数增减 currentStep
  5. 边界处理：步骤 0 时禁用「上一步」，步骤 6 时禁用「下一步」
- ID 命名规范：
  - 所有元素 ID 以 scene1- 为前缀
  - 示例：scene1-tri-ade（△ADE 填充）、scene1-tri-bdf（△BDF 填充）、scene1-label-a（标签 A）、scene1-btn-prev（上一步按钮）、scene1-btn-next（下一步按钮）、scene1-counter（计数器）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
