    **题目原文：**

    如图，自行车的链条每节长为 2.5cm，每两节链条相连接部分重叠的圆的直径为 0.8cm。如果某种型号的自行车链条共有 100 节，则这根链条没有安装时的总长度为（  ）

    A．250cm  B．174.5cm  C．170.8cm  D．172cm

    **题目分析：**

    本题考察等差数列/递推规律的应用。关键在于理解链条连接时的重叠机制：
    - 单独 1 节链条长度为 2.5cm
    - 2 节链条连接时，重叠部分长度为 0.8cm（即连接处圆的直径）
    - n 节链条有 (n-1) 个连接处，每个连接处重叠 0.8cm

    **整体讲解思路：**

    1. 从 1 节、2 节、3 节链条的具体长度入手，让学生观察规律
    2. 引导学生发现：每增加 1 节链条，实际增加的长度是 (2.5 - 0.8) = 1.7cm
    3. 推导通项公式：总长度 = 2.5n - 0.8(n-1) = 1.7n + 0.8
    4. 代入 n=100 计算最终答案

    **图示规划说明：**

    - SCENE_1：展示链条连接的递进规律，用分步动画从 1 节→2 节→3 节→n 节，直观呈现重叠部分和长度计算
    - SCENE_2：用坐标图/柱状图展示节数与总长度的线性关系，验证公式
</TEXT_1>

    **讲解要点：**

    1. 先展示 1 节链条，确认基础长度为 2.5cm
    2. 展示 2 节链条时，重点高亮重叠部分，提问学生：「两节链条直接相加是多少？实际长度为什么变短了？」

    4. 推导通项公式时，板书：
       - n 节链条总长度 = 2.5n - 0.8(n-1)
       - 化简：= 2.5n - 0.8n + 0.8 = 1.7n + 0.8
    5. 代入 n=100：1.7 × 100 + 0.8 = 170.8cm

    **关键公式：**

    - 每节长度：a = 2.5cm
    - 重叠长度：d = 0.8cm
    - n 节总长度：L = an - d(n-1) = (a-d)n + d = 1.7n + 0.8

    **总结与课堂讲解建议：**

    **完整解答：**

    设链条节数为 n，总长度为 L(n)。

    方法一（直接法）：
    - n 节链条有 (n-1) 个连接处
    - 每个连接处重叠 0.8cm
    - L(n) = 2.5n - 0.8(n-1) = 1.7n + 0.8
    - 当 n=100 时，L(100) = 1.7 × 100 + 0.8 = 170.8cm

    方法二（递推法）：
    - 第 1 节：2.5cm
    - 每增加 1 节，实际增加 (2.5 - 0.8) = 1.7cm
    - L(n) = 2.5 + 1.7(n-1) = 1.7n + 0.8
    - 当 n=100 时，L(100) = 170.8cm

    **答案：C．170.8cm**

    **课堂讲解建议：**

    1. 先用 SCENE_1 让学生直观理解重叠机制，避免学生误以为总长度是 2.5×100=250cm
    2. 强调「重叠处数量 = 节数 -1」这一关键关系
    3. 用 SCENE_2 验证公式的线性特征，帮助学生建立函数思想
    4. 可延伸提问：如果有 200 节链条，总长度是多少？（答案：340.8cm）
