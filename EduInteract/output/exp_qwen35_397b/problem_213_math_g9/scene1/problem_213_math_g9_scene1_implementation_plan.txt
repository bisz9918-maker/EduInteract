[分步序列]
- 初始状态（步骤 0）：显示标题、单节链条图形（50,120)-(170,180)、顶部 2.5cm 标注、底部"1 节"标签、公式框显示"1 节长度 = 2.5cm"
- 步骤 1：点击「下一步」→ 显示两节链条（280-490 区域）、高亮重叠区（红色半透明圆）、顶部显示两个 2.5cm 标注和 0.8cm 重叠标注、底部"2 节"标签、公式框显示"2 节长度 = 2.5 + 2.5 - 0.8 = 4.2cm"
- 步骤 2：点击「下一步」→ 显示三节链条（50-350 区域）、高亮两个重叠区、底部"3 节"标签、公式框显示"3 节长度 = 2.5×3 - 0.8×2 = 5.9cm"
- 步骤 3：点击「下一步」→ 显示 n 节链条示意（450-750 区域，含省略号）、底部"n 节"标签、公式框显示"n 节长度 = 2.5n - 0.8(n-1) = 1.7n + 0.8"
- 步骤 4（结论）：点击「下一步」→ 公式框显示"100 节长度 = 1.7×100 + 0.8 = 170.8cm ✓"，高亮正确答案 C

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于(280,450)，点击返回上一状态
  - 「下一步」按钮：位于(440,450)，点击进入下一状态
  - 步骤指示器：位于(380,455)，显示"步骤 X/4"
- 教师操作流程：
  1. 初始展示 1 节链条，讲解单节长度定义
  2. 点击「下一步」展示 2 节，引导学生观察重叠部分，提问"为什么不是 2.5×2？"
  3. 点击「下一步」展示 3 节，让学生发现重叠次数规律（n 节有 n-1 个重叠）
  4. 点击「下一步」展示通式，推导化简过程
  5. 点击「下一步」展示最终计算，得出答案 170.8cm

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [800 × 500 画布]
  +------------------------------------------+
  |  标题区 (y=20-50)                        |
  |  长度标注区 (y=60-85)                    |
  |  +------------------------------------+  |
  |  |  链条图形区 (y=120-320)            |  |
  |  |  [步骤 0/1/2/3 链条图形动态切换]    |  |
  |  +------------------------------------+  |
  |  节数标注区 (y=200/340)                |
  |  +------------------------------------+  |
  |  |  公式框 (y=380-430)                |  |
  |  |  [动态显示计算公式]                |  |
  |  +------------------------------------+  |
  |  [◀上一步] [步骤 1/4] [下一步▶] (y=450) |
  +------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用 currentStep 变量(0-4)跟踪当前步骤，steps 数组存储每步的可见元素 ID 列表
  2. 坐标计算：链条单元宽度 120px，重叠偏移 30px（120-90=30，实际重叠 0.8/2.5×120≈38px，简化为 30px 便于绘制）
  3. 动画曲线：使用 CSS transition 实现淡入淡出（opacity 0→1，duration 300ms）
  4. 事件绑定：按钮点击事件调用 updateStep() 函数，根据 currentStep 更新各元素 display 属性
  5. 公式更新：每步更新公式框 textContent，步骤 4 高亮显示最终答案
- ID 命名规范：所有元素 ID 以 scene1- 为前缀，如 scene1-chain-1、scene1-overlay-1、scene1-label-2_5cm、scene1-formula-box、scene1-btn-prev、scene1-btn-next
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
