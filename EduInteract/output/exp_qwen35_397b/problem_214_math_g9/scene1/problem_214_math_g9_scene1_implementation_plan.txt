[图示主题与整合说明]
- 本图示主题：垂直平分线性质与角度推导
- 整合的内容：垂直平分线标注、等腰三角形识别、角度关系推导、最终计算
- 教学价值：教师可通过分步演示，引导学生理解垂直平分线的性质（到线段两端点距离相等），进而推导等腰三角形的底角相等关系，最终完成角度计算。分步设计符合认知递进规律，便于课堂讲解时控制节奏。

  3. 继续点击「下一步」进入步骤 2，高亮 FH 并展示 FA=FB

  6. 可随时点击「上一步」回退复习

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单，原生 SVG 足够胜任；无需额外库依赖，加载快，代码简洁
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +------------------------------------------+
  |              ∠BAC=110°                   |
  |                  A                       |
  |                 / \                      |
  |                /   \                     |
  |           G   /     \   H                |
  |          o---/-------\---o               |
  |            /    ∠EAF  \                  |
  |           /     40°    \                 |
  |      C---E-------------F---B             |
  |                                          |
  |    ∠EAC=∠C        ∠B+∠C=70°    ∠FAB=∠B  |
  |                                          |
  |         [计算式区域 y=435]               |
  |    [◀上一步] [步骤 1/5] [下一步▶] y=455  |
  +------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-4) 跟踪当前步骤
  2. 元素分组：将每个步骤新增的元素放入独立的 <g> 组，通过 display 属性控制显示/隐藏
  3. 坐标计算：所有坐标硬编码，确保精确控制
  4. 事件绑定：按钮点击事件绑定到 step 切换函数
  5. 动画效果：步骤切换时可使用淡入效果（opacity 过渡 0.3s）
- ID 命名规范：
  - 所有交互元素 ID 必须以 scene1- 为前缀
  - 示例：scene1-tri-abc（三角形）、scene1-line-ea（线段 EA）、scene1-label-a（标签 A）
  - 按钮 ID：scene1-btn-prev、scene1-btn-next、scene1-step-indicator
  - 步骤组 ID：scene1-step0、scene1-step1、...、scene1-step4
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
- 状态切换逻辑：
  ```javascript
  (function() {
    let currentStep = 0;
    const totalSteps = 5;
    
    function updateDisplay() {
      // 隐藏所有步骤组
      for (let i = 0; i < totalSteps; i++) {
        document.getElementById('scene1-step' + i).style.display = 'none';
      }
      // 显示当前及之前步骤的元素
      for (let i = 0; i <= currentStep; i++) {
        document.getElementById('scene1-step' + i).style.display = 'block';
      }
      // 更新按钮状态
      document.getElementById('scene1-btn-prev').disabled = (currentStep === 0);
      document.getElementById('scene1-btn-next').disabled = (currentStep === totalSteps - 1);
      // 更新步骤指示器
      document.getElementById('scene1-step-indicator').textContent = '步骤 ' + (currentStep + 1) + '/' + totalSteps;
    }
    
    // 绑定事件
    document.getElementById('scene1-btn-prev').addEventListener('click', function() {
      if (currentStep > 0) {
        currentStep--;
        updateDisplay();
      }
    });
    
    document.getElementById('scene1-btn-next').addEventListener('click', function() {
      if (currentStep < totalSteps - 1) {
        currentStep++;
        updateDisplay();
      }
    });
    
    // 初始化
    updateDisplay();
  })();
  ```
