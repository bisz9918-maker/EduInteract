场景导航：Scene 1

题目原文：

如图所示，直线$a$经过正方形$ABCD$的顶点$A$，分别过顶点$D$，$B$作$DE\bot a$于点$E$，$BF\bot a$于点$F$，若$DE=4$，$BF=3$，则$EF$的长为（ ）

A．1 B．5 C．7 D．12

题目分析：

本题是典型的正方形与全等三角形综合题。核心思路是通过证明两个直角三角形全等，将已知线段长度转化为所求线段的组成部分。

整体讲解思路：

  1. 首先引导学生观察图形结构：正方形 ABCD，直线 a 过顶点 A，两条垂线 DE 和 BF
  2. 识别关键三角形：△AED 和 △BFA 都是直角三角形
  3. 寻找全等条件：利用正方形性质和角度关系证明两三角形全等
  4. 利用全等三角形对应边相等，得出 AE=BF=3，AF=DE=4
  5. 计算 EF = AE + AF = 3 + 4 = 7

图示规划说明：

设计一个综合图示，通过分步按钮导航展示从已知条件到全等证明再到结论的完整推导过程。所有几何元素整合在一个图中，避免拆分多个相似图示。

本图示教学说明：

引导学生观察：

  1. 首先让学生识别图中的基本图形：正方形 ABCD 有什么性质？（四边相等、四角都是 90°）
  1. 观察垂线构造：DE⊥a，BF⊥a，这意味着什么？（∠AED=∠BFA=90°，两个直角三角形）

关键推导步骤：

  1. 在△AED 中：∠DAE + ∠ADE = 90°（直角三角形两锐角互余）
  1. 在正方形中：∠DAB = 90°，而∠DAB = ∠DAE + ∠BAF
  1. 因此：∠BAF = 90° - ∠DAE = ∠ADE
  1. 同理可证：∠ABF = ∠DAE
  1. 又因为 AD = AB（正方形边长相等）
  1. 所以△AED ≌ △BFA（AAS 全等判定）

全等结论应用：

  • 对应边相等：AE = BF = 3，AF = DE = 4
  • 所求 EF = AE + AF = 3 + 4 = 7

讲解建议：

教师可使用分步按钮，先让学生猜想两个三角形的关系，再逐步揭示证明过程。步骤 4 是关键转折点，应停留足够时间让学生理解角度相等的推导。

总结与课堂建议：

完整解答：

解：∵ 四边形 ABCD 是正方形
∴ AD = AB，∠DAB = 90°

∵ DE⊥a，BF⊥a
∴ ∠AED = ∠BFA = 90°

∵ ∠DAE + ∠ADE = 90°，∠DAE + ∠BAF = ∠DAB = 90°
∴ ∠ADE = ∠BAF

在△AED 和△BFA 中：

  • ∠AED = ∠BFA = 90°
  • ∠ADE = ∠BAF
  • AD = AB

∴ △AED ≌ △BFA（AAS）

∴ AE = BF = 3，AF = DE = 4

∴ EF = AE + AF = 3 + 4 = 7

答案：C

课堂讲解建议：

  1. 本题是"一线三垂直"模型的典型应用，可拓展讲解此类模型的识别方法
  2. 强调全等三角形证明的书写规范：先列条件，再写判定依据，最后写结论
  3. 可追问学生：若直线 a 的位置改变（如更陡或更平），结论是否仍成立？（成立，因为全等关系不依赖直线 a 的具体斜率）
  4. 变式训练：交换已知条件（如已知 EF 和其中一段，求另一段），巩固全等应用
