场景导航：Scene 1

题目原文：

如图，抛物线 y＝ax²+bx+c（a≠0）的对称轴为直线 x＝1，与 x 轴的一个交点坐标为（﹣1，0），其部分图象如图所示，下列结论：①4ac＜b²；②3a+c＞0；③当 x＞0 时，y 随 x 的增大而减小；④当 y＞0 时，x 的取值范围是﹣1＜x＜3；⑤方程 ax²+bx+c＝0 的两个根是 x₁＝﹣1，x₂＝3；其中结论正确的个数是（ ）

A．4 个 B．3 个 C．2 个 D．1 个

题目分析：

本题考察二次函数图像与系数的关系。从图像可知：

  • 抛物线开口向下 → a < 0
  • 对称轴 x = 1 → -b/(2a) = 1 → b = -2a
  • 与 x 轴交点 (-1, 0)，由对称性可得另一交点 (3, 0)
  • 与 y 轴交点 (0, 3) → c = 3

整体讲解思路：

  1. 首先引导学生观察图像的基本特征（开口方向、对称轴、交点）
  2. 利用对称性求出另一根 x = 3
  3. 逐一验证 5 个结论
  4. 统计正确结论个数

图示规划说明：

设计 1 个综合图示，用分步按钮导航展示 5 个结论的验证过程，所有分析在同一坐标系中完成。

本图示教学说明：

引导学生观察顺序：

  1. 步骤 0：让学生识别图像中的已知信息
  • 开口方向 → a 的符号
  • 对称轴位置 → x=1
  • 与坐标轴交点
  1. 步骤 1（结论①）：讲解判别式的几何意义
  • 抛物线与 x 轴有两个交点 → 方程有两个不等实根 → Δ = b²-4ac > 0
  • 因此 4ac < b² 正确 ✓
  1. 步骤 2（结论⑤）：利用对称性求另一根
  • 对称轴 x=1，已知根 x₁=-1
  • 对称点：1 - (-1) = 2，所以另一根为 1 + 2 = 3
  • 两根为 x₁=-1, x₂=3 正确 ✓
  1. 步骤 3（结论③）：分析增减性
  • 开口向下，对称轴 x=1
  • x < 1 时，y 随 x 增大而增大
  • x > 1 时，y 随 x 增大而减小
  • 结论说"x > 0 时 y 随 x 增大而减小"，但 0 < x < 1 区间是递增的
  • 因此结论③错误 ✗
  1. 步骤 4（结论④）：读取 y > 0 的区间
  • 抛物线在 x 轴上方的部分对应 y > 0
  • 从图像看：-1 < x < 3 时抛物线在 x 轴上方
  • 结论④正确 ✓
  1. 步骤 5（结论②）：代数推导验证
  • x = -1 时，y = 0：a(-1)² + b(-1) + c = 0 → a - b + c = 0
  • 对称轴 x = 1：-b/(2a) = 1 → b = -2a
  • 代入：a - (-2a) + c = 0 → 3a + c = 0
  • 因此 3a + c > 0 错误 ✗

关键公式：

  • 对称轴公式：x = -b/(2a)
  • 判别式：Δ = b² - 4ac
  • 两根关于对称轴对称：(x₁ + x₂)/2 = 对称轴

总结与课堂讲解建议：

正确答案：B（3 个正确结论）

正确结论：①、④、⑤

讲解建议：

  1. 先整体后局部：先让学生整体观察抛物线特征，再逐一分析结论
  1. 数形结合：强调代数结论与几何图像的对应关系
  • 判别式 Δ > 0 ↔ 与 x 轴有两个交点
  • y > 0 的解集 ↔ 图像在 x 轴上方的区间
  1. 对称性的应用：这是本题的关键技巧
  • 已知一根和对称轴，可快速求另一根
  • 对称点距离相等：|x₁ - 对称轴| = |x₂ - 对称轴|
  1. 易错点提醒：
  • 结论③的陷阱：x > 0 包含了 0 < x < 1 的递增区间
  • 结论②需要代数推导，不能仅从图像判断
  1. 拓展思考：
  • 若已知三个点，如何求 a, b, c？
  • 顶点坐标如何用 a, b, c 表示？
