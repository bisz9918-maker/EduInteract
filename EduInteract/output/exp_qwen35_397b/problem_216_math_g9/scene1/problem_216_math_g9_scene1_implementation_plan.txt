[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单，无需复杂库；SVG 缩放不失真，适合数学图示
- 画布尺寸：800×500px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +------------------------------------------+
  |  y                                     |
  |  ^         抛物线                       |
  |  |        /    \      结论区            |
  |  |       /      \     ① ____ ✓         |
  |  |      /        \    ② ____ ✗         |
  |  |-----/----------\--- ③ ____ ✗         |
  |  |    /            \  ④ ____ ✓         |
  |  |___/______________\_ ⑤ ____ ✓         |
  |  O  -1   1    3     x                   |
  |                                          |
  |        [◀ 上一步]  [下一步 ▶]            |
  +------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：currentState (0-5)，steps 数组存储每步显示的元素 ID 列表
  2. 坐标计算：像素坐标 = 原点像素 + 逻辑坐标 × 60（y 轴反向）
  3. 抛物线路径：使用二次贝塞尔曲线或离散点拟合
  4. 事件绑定：按钮点击事件切换状态，更新元素 display 属性
  5. 动画过渡：可选 fade-in 效果（opacity 0→1，0.3s）
- ID 命名规范：
  - 所有元素 ID 以 scene1- 为前缀
  - 示例：scene1-axis-x, scene1-axis-y, scene1-parabola, scene1-sym-axis
  - 点：scene1-point-a, scene1-point-b, scene1-point-c, scene1-point-v
  - 标签：scene1-label-a, scene1-label-sym, scene1-label-y3
  - 结论标记：scene1-concl-1, scene1-concl-2, ..., scene1-concl-5
  - 按钮：scene1-btn-prev, scene1-btn-next
  - 填充区：scene1-fill-ypos
  - 箭头：scene1-arrow-increase, scene1-arrow-decrease
- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
- 抛物线方程推导（用于精确绘制）：
  - 已知：过点 (-1,0), (0,3), (3,0)
  - 代入 y=ax²+bx+c：
    - a-b+c=0 (x=-1)
    - c=3 (x=0)
    - 9a+3b+c=0 (x=3)
  - 解得：a=-1, b=2, c=3
  - 抛物线方程：y = -x² + 2x + 3
  - 顶点：x=-b/2a=1, y=-(1)²+2(1)+3=4 → (1,4) ✓
