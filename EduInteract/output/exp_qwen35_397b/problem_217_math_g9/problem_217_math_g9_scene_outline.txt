    **题目原文：**

    如图，二次函数 $y=x^2-2x-3$ 的图像与 $x$ 轴交于 $A,B$ 两点，与 $y$ 轴交于点 $C$，下列说法:① $AB=4;$ ② $\angle ABC=45^\circ;$ ③当 $0< x<2$ 时，$-4\le y<-3$；④当 $x>1$ 时，$y$ 随 $x$ 的增大而增大，其中结论正确的个数有（ ）

    A．1 个  B．2 个  C．3 个  D．4 个

    **题目分析：**

    本题综合考查二次函数的图像性质，包括：
    1. 与坐标轴的交点坐标计算
    2. 线段长度与角度关系（几何性质）
    3. 函数在给定区间内的取值范围
    4. 函数的单调性（对称轴两侧的增减性）

    **整体讲解思路：**

    1. 首先求出 A、B、C 三点坐标，验证结论①
    2. 利用坐标几何验证△OBC 为等腰直角三角形，得∠ABC=45°
    3. 求出顶点坐标和对称轴，分析区间 [0,2] 内的函数值范围
    4. 根据对称轴和开口方向判断单调性

    **图示规划说明：**

    共设计 3 个图示场景：
    - SCENE_1：基础图像展示交点坐标与 AB 长度
    - SCENE_2：几何角度验证（等腰直角三角形）
    - SCENE_3：函数性质综合展示（对称轴、顶点、区间范围、单调性）

    **教学说明：**

    本图示用于引导学生从图像上直观认识二次函数与坐标轴的交点。

    **讲解要点：**

    1. 令 $y=0$，解方程 $x^2-2x-3=0$
       - 因式分解：$(x-3)(x+1)=0$
       - 得 $x_1=-1, x_2=3$
       - 故 A(-1,0)，B(3,0)

    2. 令 $x=0$，得 $y=-3$
       - 故 C(0,-3)

    3. 计算 AB 长度：
       - $AB = 3 - (-1) = 4$
       - 结论①正确

    **引导学生观察：** 从图像上可以看到 A、B 关于对称轴对称，AB 跨越 4 个单位长度。

    本图示用于验证结论②，通过几何方法证明∠ABC=45°。

    **讲解要点：**

    1. 观察△OBC 的顶点坐标：
       - O(0,0)，B(3,0)，C(0,-3)

    2. 计算边长：
       - $OB = 3$（x 轴上从 0 到 3）
       - $OC = 3$（y 轴上从 0 到 -3，取绝对值）
       - $OB = OC$

    3. ∠BOC = 90°（坐标轴垂直）

    4. 结论：△OBC 是等腰直角三角形
       - 底角∠OBC = ∠OCB = 45°
       - 即∠ABC = 45°
       - 结论②正确

    **引导学生观察：** 等腰直角三角形的两个锐角都是 45°，这是几何基本性质。

    **教学说明：**

    本图示综合展示结论③和④，涉及函数的最值、区间取值范围和单调性。

    **讲解要点：**

    1. 求对称轴和顶点：
       - 对称轴：$x = -\frac{b}{2a} = \frac{2}{2} = 1$
       - 顶点纵坐标：$y = 1^2 - 2\times1 - 3 = -4$
       - 顶点坐标 (1,-4)

    2. 验证结论③（区间 [0,2] 内的函数值）：
       - 当 $x=0$ 时，$y=-3$
       - 当 $x=2$ 时，$y=4-4-3=-3$
       - 当 $x=1$ 时（顶点），$y=-4$（最小值）
       - 故当 $0<x<2$ 时，$-4 \le y < -3$
       - 结论③正确

    3. 验证结论④（单调性）：
       - 抛物线开口向上（$a=1>0$）
       - 对称轴 $x=1$
       - 当 $x>1$ 时，y 随 x 增大而增大
       - 结论④正确

    **总结：** 四个结论全部正确，答案为 D（4 个）。

    **课堂讲解建议：** 先让学生观察图像猜测，再用代数方法严格验证，培养数形结合思想。
