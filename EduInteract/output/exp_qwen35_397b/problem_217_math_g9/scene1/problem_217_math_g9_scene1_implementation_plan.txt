[分步序列]
- 初始状态（步骤 0）：仅显示坐标系和抛物线，无交点标记
- 步骤 1：点击「下一步」→ 显示点 A 和点 B（蓝色圆点），标签"A"和"B"出现
- 步骤 2：点击「下一步」→ 显示点 C（蓝色圆点），标签"C"出现
- 步骤 3：点击「下一步」→ 显示坐标标签 A(-1,0)、B(3,0)、C(0,-3)，同时显示顶点 V(1,-4)
- 步骤 4：点击「下一步」→ 高亮 AB 线段（绿色加粗），显示"AB=4"标注
- 教师可随时点击「上一步」回退复习

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 按钮「◀上一步」：位置 (320,460)，返回上一状态
  - 按钮「下一步▶」：位置 (460,460)，进入下一状态
  - 步骤指示器：位置 (400,460)，显示"步骤 X/4"
- 教师操作流程：
  1. 初始展示抛物线，让学生观察图像形状
  2. 点击「下一步」显示 A、B 交点，引导学生发现与 x 轴交点
  3. 点击「下一步」显示 C 交点，引导学生发现与 y 轴交点
  4. 点击「下一步」显示坐标，进行代数验证
  5. 点击「下一步」高亮 AB 并显示长度，验证结论①

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +------------------------------------------+
  |                    y                     |
  |                    ↑                     |
  |                    |                     |
  |         抛物线     |                     |
  |      ／          ＼|                     |
  |     /            \ |                     |
  |----A-----O--------B------------------→ x |
  |     \            / |                     |
  |      ＼    C    ／  |                     |
  |        ＼   |  ／    |                     |
  |          ＼ |／      |                     |
  |            V         |                     |
  |                                          |
  |      [◀上一步] 步骤 X/4 [下一步▶]         |
  +------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentState (0-4) 跟踪当前步骤
  2. 坐标计算：数学坐标 (x,y) 转换为 SVG 坐标 (svgX, svgY)
     - svgX = originX + x * scaleX = 250 + x * 60
     - svgY = originY - y * scaleY = 180 - y * 40（注意 y 轴翻转）
  3. 抛物线路径：用<path>绘制，d 属性通过计算多个点生成
  4. 元素显隐：用 display="none" 或 opacity 控制各步骤元素
  5. 事件绑定：按钮点击事件更新 currentState 并刷新视图
- ID 命名规范：所有元素 ID 以 scene1- 为前缀
  - scene1-x-axis, scene1-y-axis, scene1-parabola
  - scene1-point-a, scene1-point-b, scene1-point-c, scene1-point-v
  - scene1-label-a, scene1-label-b, scene1-label-c
  - scene1-coord-a, scene1-coord-b, scene1-coord-c
  - scene1-segment-ab, scene1-label-ab
  - scene1-btn-prev, scene1-btn-next, scene1-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中
