[图示主题与整合说明]
- 本图示主题：∠ABC=45°的几何验证（等腰直角三角形）
- 整合的步骤/概念：通过△OBC 的边长关系（OB=OC=3）和直角（∠BOC=90°）推导出△OBC 为等腰直角三角形，从而得出∠OBC=∠ABC=45°
- 教学价值：教师可分步展示从已知条件到结论的完整逻辑链，帮助学生理解几何证明的递进关系。步骤 0 展示基础图形，步骤 1-2 标注边长和直角，步骤 3 得出等腰直角三角形结论，步骤 4 标注 45°角，形成完整的证明链条。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 底部左侧 (x=320, y=465)，灰色背景，点击后退到前一状态
  - 「下一步」按钮：位于 SVG 底部右侧 (x=480, y=465)，蓝色背景，点击前进到下一状态
  - 步骤指示器：位于两按钮之间 (x=400, y=470)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始展示△OBC 基础图形，让学生观察三角形形状
  2. 点击「下一步」展示 OB=OC=3，引导学生发现等腰关系
  3. 点击「下一步」展示直角符号，确认∠BOC=90°
  4. 点击「下一步」得出等腰直角三角形结论
  5. 点击「下一步」展示∠ABC=45°，完成证明
  6. 可随时回退复习关键步骤

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |                    y 轴                           |
  |                    |                             |
  |                    |                             |
  |           (第二象限)  |  (第一象限)                |
  |                    |                             |
  |                    O--------B----→ x 轴          |
  |                    |       /                     |
  |                    |      /                      |
  |                    |     /                       |
  |                    |    /                        |
  |                    |   /                         |
  |                    |  /                          |
  |                    | /                           |
  |                    |/                            |
  |                    C                             |
  |                                                  |
  |                                                  |
  |        [◀上一步]  步骤 1/5  [下一步▶]            |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量 (0-4) 跟踪当前步骤
  2. 元素分组：将每步新增元素放入独立<g>组，用 display 控制显隐
  3. 坐标计算：所有坐标基于原点 (400,250) 的相对偏移
  4. 事件绑定：按钮点击事件绑定到 nextState/prevState 函数
  5. 按钮禁用：步骤 0 时禁用「上一步」，步骤 4 时禁用「下一步」
- ID 命名规范：所有元素 ID 以 scene2- 为前缀
  - scene2-axis-x, scene2-axis-y（坐标轴）
  - scene2-point-o, scene2-point-b, scene2-point-c（点）
  - scene2-seg-ob, scene2-seg-oc, scene2-seg-bc（线段）
  - scene2-mark-ob, scene2-mark-oc（等长标记）
  - scene2-right-angle（直角符号）
  - scene2-angle-arc（角度弧线）
  - scene2-label-o, scene2-label-b, scene2-label-c（点标签）
  - scene2-anno-ob, scene2-anno-oc（边长标注）
  - scene2-anno-90, scene2-anno-45（角度标注）
  - scene2-btn-prev, scene2-btn-next, scene2-step-indicator（控件）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
