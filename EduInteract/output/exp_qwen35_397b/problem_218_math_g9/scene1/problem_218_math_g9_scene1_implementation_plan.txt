[图示主题与整合说明]
- 本图示主题：两个直角三角板组合的角度关系推导
- 整合的内容：题目原图 + 两个三角板的内角标注 + 已知角∠BCE + 推导角∠ACF + 最终求解∠CDF
- 教学价值：教师可使用此图示逐步展示几何推导过程，从已知条件出发，通过等腰直角三角形性质、平角定义、三角形内角和定理，层层递进求解目标角度。学生可跟随每一步逻辑，理解角度计算的依据。

[分步序列]
- 初始状态（步骤0）：显示两个三角形轮廓（△ABC和△DEF），所有顶点A/B/C/D/E/F标注，E-C-F共线虚线。无角度标注，无高亮。
- 步骤1：高亮△ABC（蓝色填充15%），显示直角符号∠A，显示∠B=45°弧线及标签，显示∠ACB=45°弧线及标签。说明文字："步骤1：分析等腰直角三角形ABC"
- 步骤2：取消△ABC高亮，高亮△DEF（蓝色填充15%），显示直角符号∠EDF，显示∠E=30°弧线及标签，显示∠F=60°弧线及标签。说明文字："步骤2：分析直角三角形DEF"
- 步骤3：取消△DEF高亮，显示∠BCE=40°弧线（红色）及标签，显示E-C-F平角关系，推导显示∠ACF=180°-40°-45°=95°（绿色）及弧线。说明文字："步骤3：利用平角求∠ACF"
- 步骤4：高亮△CDF（蓝色填充15%），显示∠CDF+∠DCF+∠F=180°关系式，计算显示∠CDF=180°-95°-60°=25°（绿色加粗），用醒目绿色弧线标出∠CDF。说明文字："步骤4：三角形内角和求∠CDF"

冲突检查：
- "C"(520,375)与"∠ACB=45°"(490,340)：间距≈46px → 无冲突
- "C"(520,375)与"∠BCE=40°"(470,335)：间距≈64px → 无冲突
- "∠BCE=40°"(470,335)与"∠ACF=95°"(580,335)：间距110px → 无冲突（分居C点两侧）
- "D"(565,195)与"∠CDF=25°"(580,220)：间距≈29px → 无冲突
- "E"(135,375)与"∠E=30°"(175,335)：间距≈57px → 无冲突
- "F"(665,375)与"∠F=60°"(625,335)：间距≈57px → 无冲突
- "B"(205,145)与"∠B=45°"(195,135)：间距≈14px → 略近，调整"∠B=45°"至(185,125)
- "A"(590,90)与直角符号(565,100)：间距≈26px → 无冲突

解决方案：将"∠B=45°"标签调整至(185,125)，确保与B点标签间距≥20px。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于SVG内底部左侧(280,455)，点击后退到前一状态
  - 「下一步 ▶」按钮：位于SVG内底部右侧(420,455)，点击前进到下一状态
  - 步骤指示器：位于两按钮之间(400,460)，显示当前步骤编号"步骤X/5"
- 教师操作流程：
  1. 初始展示基础图形，让学生观察两个三角板的摆放位置
  2. 点击「下一步」进入步骤1，讲解等腰直角三角形ABC的性质（∠A=90°，AB=AC→∠B=∠ACB=45°）
  3. 点击「下一步」进入步骤2，讲解直角三角形DEF的内角（∠EDF=90°，∠E=30°→∠F=60°）
  4. 点击「下一步」进入步骤3，讲解平角E-C-F=180°，已知∠BCE=40°，推导∠ACF=180°-40°-45°=95°
  5. 点击「下一步」进入步骤4，讲解△CDF内角和180°，计算∠CDF=180°-95°-60°=25°，得出答案
  6. 教师可随时点击「上一步」回退复习关键步骤

[技术实现]
- JS库选择及原因：原生SVG + 原生JavaScript。原因：本题为静态几何图形+分步高亮，无需复杂动画库，原生SVG可精确控制坐标和样式，代码简洁易维护。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  | [步骤说明：步骤X/5]                              | y=25
  |                                                  |
  |         A                                        |
  |        / \                                       |
  |       B   \                                      |
  |            D                                     | y=200
  |           / \                                    |
  |          /   \                                   |
  |         /     \                                  |
  |        E-------C-------F                         | y=350
  |                                                  |
  |                                                  |
  |              [◀上一步] [步骤X/5] [下一步▶]       | y=455
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用currentIndex变量(0-4)跟踪当前步骤，steps数组存储每步的显示配置
  2. 每步配置包含：高亮三角形ID列表、显示的角度弧线ID列表、显示的文本标签ID列表、步骤说明文字
  3. 坐标计算：所有顶点坐标硬编码，确保与布局坐标表一致
  4. 动画曲线：步骤切换使用CSS transition，透明度变化duration=300ms ease-in-out
  5. 事件绑定：按钮点击事件绑定到updateStep()函数，更新DOM元素display/opacity属性
  6. 边界处理：第一步禁用「上一步」，最后一步禁用「下一步」
- ID命名规范：所有元素ID以scene1-为前缀，如scene1-tri-abc、scene1-tri-def、scene1-point-a、scene1-label-angle-b等
- IIFE隔离：所有JS代码包在(function() { ... })()中，避免全局变量污染
