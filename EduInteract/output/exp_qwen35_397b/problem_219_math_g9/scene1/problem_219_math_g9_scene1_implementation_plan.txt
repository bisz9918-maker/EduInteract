[图示主题与整合说明]
- 本图示主题：反比例函数图像上的几何构造——梯形 ABCD 的形成
- 整合的内容：反比例函数曲线、点 A/B 位置、垂线 AD/BC、梯形 ABCD 轮廓、坐标轴标注
- 教学价值：教师可逐步展示从函数图像到几何图形的构造过程，帮助学生理解反比例函数上任意两点向 y 轴作垂线形成的梯形结构，为后续比较 S1 与 S2 的面积关系做铺垫。分步呈现降低认知负荷，让学生清晰看到每个几何元素的来源。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 (280,460)，返回上一状态
  - 「下一步」按钮：位于 (440,460)，进入下一状态
  - 状态指示器：位于 (380,460)，显示「步骤 X/4」
- 教师操作流程：
  1. 初始展示坐标系和曲线，介绍反比例函数图像特征
  2. 点击「下一步」展示点 A 和垂线 AD，讲解点 A 向 y 轴作垂线的构造
  3. 点击「下一步」展示点 B 和垂线 BC，类比点 A 的构造
  4. 点击「下一步」高亮梯形 ABCD 边框，引导学生识别梯形结构
  5. 点击「下一步」显示 S₁ 标注，引出梯形面积概念
  6. 可随时点击「上一步」回退复习关键构造步骤

[技术实现]
- JS 库选择：原生 SVG
  - 原因：几何图形简单（线段、圆点、路径、文字），原生 SVG 足够且轻量，无需额外库
- 画布尺寸：800×500px（固定）
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────┐
  │  y                                                         │
  │  ↑                                                         │
  │  │    y=k/x                                               │
  │  │   ╱                                                      │
  │  │  ╱   ●A                                                  │
  │  D├─────┘                                                   │
  │  │  │    ╲                                                 │
  │  │  │     ╲  ●B                                            │
  │  C├──┼──────┘                                               │
  │  │  │     ╱                                                 │
  │  │  │    ╱                                                  │
  │  O└──┴───┴────────────────────────────→ x                   │
  │                                                            │
  │              S₁ (梯形内部)                                  │
  │                                                            │
  │         [◀上一步]  步骤 X/4  [下一步▶]                      │
  └────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentState(0-4) 跟踪当前步骤，数组存储每步可见元素 ID 列表
  2. 坐标计算：反比例曲线用 path 元素，通过 y=k/x 公式计算关键点（设 k=36000，使曲线经过 A(220,180) 和 B(420,280) 附近）
  3. 动画曲线：元素出现用 opacity 从 0 到 1 的过渡，duration=300ms
  4. 事件绑定：按钮点击事件切换状态，调用 updateScene() 函数更新可见性
  5. 梯形斜边 BA：用 line 元素连接 (220,180) 和 (420,280)
- ID 命名规范：
  - scene1-axis-x, scene1-axis-y, scene1-origin-o
  - scene1-curve, scene1-formula
  - scene1-point-a, scene1-point-b
  - scene1-line-ad, scene1-line-bc
  - scene1-trapezoid-ad, scene1-trapezoid-dc, scene1-trapezoid-cb, scene1-trapezoid-ba
  - scene1-label-o, scene1-label-a, scene1-label-b, scene1-label-c, scene1-label-d
  - scene1-label-x, scene1-label-y, scene1-label-s1
  - scene1-btn-prev, scene1-btn-next, scene1-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
