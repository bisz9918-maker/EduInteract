[图示主题与整合说明]
- 本图示主题：各电极反应与实验现象（酚酞变色）
- 整合内容：四电极反应式、气体产生位置、酚酞变色现象、选项验证
- 教学价值：教师可逐步展示原电池（锌-铜-稀硫酸）和电解池（石墨a-b-饱和食盐水）的工作原理，通过分步动画演示各电极的氧化还原反应，最终验证选择题各选项的正误。学生可直观理解电子流动方向、电极产物及酚酞变色原理。

[分步序列]
步骤0（初始状态）：显示完整装置图
- 显示：烧杯、锌电极、铜电极、稀硫酸、导线、滤纸、石墨棒a/b
- 显示标签：锌、铜、a、b、稀硫酸、滤纸标注
- 右侧信息区：标题"电极反应分析"，步骤指示器"步骤0/4"
- 控件栏：显示"◀上一步"（禁用）、"下一步▶"、"重置"

步骤1：锌电极反应（原电池负极）
- 视觉变化：锌电极高亮 #ffd54f 闪烁，电子流动动画（锌→导线→b）
- 反应式文本框显示：
  "锌电极（负极）：Zn - 2e⁻ → Zn²⁺"
  "氧化反应，锌被消耗"
- 选项验证区显示：
  "A选项：a为阳极，发生氧化反应：锌为负极被还原 ❌"
  "错误原因：锌为负极发生氧化反应，不是被还原"

步骤2：铜电极反应（原电池正极）
- 视觉变化：铜电极高亮 #ffcc80，气泡从铜电极表面产生并上浮（3-5个气泡动画循环）
- 反应式文本框显示：
  "铜电极（正极）：2H⁺ + 2e⁻ → H₂↑"
  "还原反应，产生氢气"
- 选项验证区追加：
  "B选项：电路中电子流动方向：锌→b→a→铜 ❌"
  "错误原因：电子不经过电解质溶液，应为锌→b，a→铜"
  "C选项：电路中通过0.2mol电子，铜片上产生2.24L气体 ❌"
  "错误原因：未说明标准状况，无法确定体积"

步骤3：a电极反应（电解池阳极）
- 视觉变化：a电极高亮 #90a4ae，Cl⁻离子向a移动动画，黄绿色气体效果
- 反应式文本框显示：
  "a电极（阳极）：2Cl⁻ - 2e⁻ → Cl₂↑"
  "氧化反应，产生氯气"
- 选项验证区保持步骤2内容

步骤4：b电极反应（电解池阴极）+ 酚酞变色
- 视觉变化：b电极高亮 #90a4ae，H⁺离子向b移动动画，b极附近红色晕染扩散（酚酞遇碱变红）
- 反应式文本框显示：
  "b电极（阴极）：2H₂O + 2e⁻ → H₂↑ + 2OH⁻"
  "还原反应，OH⁻富集使酚酞变红"
- 选项验证区追加：
  "D选项：往滤纸上滴加酚酞，b极附近颜色变红 ✓"
  "正确原因：b为阴极，H⁺放电后OH⁻富集，溶液呈碱性"
- 最终总结：显示"正确答案：D"，绿色边框高亮

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶ / 重置）
- 控件说明：
  - "◀上一步"按钮：位于(280,455)，灰色#9e9e9e，步骤0时禁用
  - "下一步▶"按钮：位于(380,455)，蓝色#1976d2，最后一步时禁用
  - "重置"按钮：位于(480,455)，绿色#388e3c，始终可用
- 教师操作流程：
  1. 初始展示完整装置图，让学生观察原电池+电解池组合
  2. 点击"下一步"逐步展示各电极反应，配合讲解氧化还原原理
  3. 每步显示对应选项验证，引导学生排除错误选项
  4. 最终步骤展示酚酞变色现象，验证D选项正确
  5. 可随时点击"上一步"回顾之前的反应过程
  6. 点击"重置"回到初始状态重新开始讲解

[技术实现]
- JS库选择：原生SVG + 原生JavaScript
  - 原因：几何图形简单，无需复杂库；SVG便于精确控制坐标和动画；原生JS足够实现分步状态管理
- 画布尺寸：800×500px（固定）
- 布局草图：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │  [原电池区]              [电解池区]        [信息区]         │
  │   锌  铜                  a    b          反应式文本框      │
  │   │   │                  │    │          (540,80-780,160)  │
  │   └───┴──────────────────┴────┘                            │
  │   烧杯+稀硫酸            滤纸椭圆         选项验证区        │
  │   (40,280-280,420)      (360,280-580,380) (540,180-780,380)│
  │                                                              │
  │                    [控件栏]                                  │
  │              ◀上一步 | 下一步▶ | 重置                        │
  │                  (280,450 - 520,490)                        │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用currentStep变量(0-4)跟踪当前步骤，steps数组存储每步的配置
  2. 坐标计算：所有元素使用绝对坐标，SVG viewBox="0 0 800 500"
  3. 动画曲线：气泡上浮用CSS animation，酚酞红晕用SMIL animate或JS控制opacity
  4. 事件绑定：按钮点击事件绑定到updateStep()函数，更新DOM元素显示状态
  5. 元素显隐：每步通过display属性或opacity控制元素显示/隐藏
  6. 电子流动动画：用虚线+小圆点沿导线路径移动，CSS offset-path或JS逐帧更新
- ID命名规范：所有元素ID以scene3-为前缀
  - scene3-zinc-electrode, scene3-copper-electrode
  - scene3-graphite-a, scene3-graphite-b
  - scene3-beaker, scene3-filter-paper
  - scene3-reaction-box, scene3-option-panel
  - scene3-btn-prev, scene3-btn-next, scene3-btn-reset
  - scene3-bubble-group, scene3-phenolphthalein-glow
- IIFE隔离：所有JS代码包在(function() { ... })()中，避免全局变量污染
- 响应式考虑：固定800×500画布，容器overflow:hidden确保不溢出
