场景导航：Scene 1 | Scene 2

题目原文：

读下图，有关该图叙述正确的是

A．若此图为热力环流侧视图，则温度：a > b > c > d

B．若此图为热力环流侧视图，则气压：d > a > b > c

C．若此图为北半球三圈环流的中纬环流侧视图，b 处有冷暖气流相遇

D．若此图为北半球三圈环流的中纬环流侧视图，④为热力原因引起的下沉气流

题目分析：

本题考察热力环流和三圈环流的核心概念。图中展示了一个闭合的环流圈，包含四个关键位置（a、b、c、d）和四个气流方向（①②③④）。

整体讲解思路：

  1. 首先理解热力环流的基本原理：地面受热不均→空气垂直运动→同一水平面气压差异→空气水平运动
  2. 掌握热力环流中温度和气压的分布规律
  3. 理解三圈环流中纬环流的形成机制和特征
  4. 逐一分析四个选项

图示规划说明：

  • SCENE_1：展示热力环流侧视图，通过分步动画呈现环流形成过程，并标注温度、气压分布规律
  • SCENE_2：对比展示三圈环流的中纬环流特征，说明 b 处（副极地低压带）和④处（副热带高压带）的成因
步骤 1/7

教学说明：

本图示用于讲解热力环流的基本原理和温度气压分布规律。

引导学生观察要点：

  1. 热力环流的根本原因是地面受热不均
  2. 受热处（b）空气膨胀上升，近地面形成低压；冷却处（a）空气收缩下沉，近地面形成高压
  3. 同一水平面上，近地面气压 a>b，高空气压 d>c
  4. 垂直方向上，海拔越高气压越低，故 a>b>c>d
  5. 温度分布：近地面 b>a（b 处受热），垂直方向海拔越高温度越低，故 b>a>d>c

选项分析：

  • 选项 A：温度应为 b>a>d>c，而非 a>b>c>d，故 A 错误
  • 选项 B：气压应为 a>b>c>d，而非 d>a>b>c，故 B 错误

关键公式：

  • 垂直方向气压递减：海拔每升高 100m，气压约下降 10hPa
  • 热力环流因果关系：受热不均→垂直运动→水平气压差→水平运动
步骤 0/5

教学说明：

本图示用于讲解三圈环流中纬环流的特征和成因。

引导学生观察要点：

  1. 中纬环流位于 30°N-60°N 之间
  2. a 处（约 30°N）为副热带高压带，④处气流下沉
  3. b 处（约 60°N）为副极地低压带，冷暖气流在此相遇

关键概念区分：

  • 热力原因：由于地面冷热不均引起的垂直运动（如赤道低压带、极地高压带）
  • 动力原因：由于空气运动受阻或堆积引起的垂直运动（如副热带高压带、副极地低压带）

选项分析：

  • 选项 C：b 处为副极地低压带，来自低纬的暖湿西风与来自高纬的冷干极地东风在此相遇，暖空气被迫抬升，形成极锋，故 C 正确
  • 选项 D：④处（副热带高压带）的下沉气流是动力原因（高空空气堆积下沉），而非热力原因，故 D 错误

正确答案：C

课堂讲解建议：

  1. 先复习热力环流基本原理
  2. 再引入三圈环流的概念，说明中纬环流的位置和特征
  3. 重点区分热力原因和动力原因的垂直运动
  4. 结合选项逐一验证，培养学生严谨的推理能力
