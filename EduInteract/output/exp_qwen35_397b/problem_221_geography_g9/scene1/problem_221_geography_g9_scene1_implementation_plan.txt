- 说明文本："原图展示某日部分地区昼夜分布。阴影表示黑夜，白色表示白昼。观察晨昏线走向及甲、乙两地位置。"

步骤 1：高亮晨昏线，标注晨线/昏线
- 显示：步骤 0 所有元素 + 晨线标签 (340,180) 高亮显示 #1565c0 加粗
- 隐藏：无
- 视觉变化：晨昏线闪烁动画（opacity 0.5→1.0 两次），晨线标签淡入
- 说明文本："晨昏线是昼夜分界线。顺着地球自转方向（自西向东），由夜入昼为晨线，由昼入夜为昏线。图中晨昏线东侧为白昼，故为晨线。"

步骤 2：叠加东西半球分界线，判断阴影主要所在半球
- 显示：步骤 1 所有元素 + 东西半球分界虚线 (100,60)-(100,380)、西半球标签 (120,200) #ffffff

步骤 3：高亮甲地，说明晨线与赤道交点地方时为 6 时

- 说明文本："甲地位于赤道与晨线的交点。晨线与赤道交点的地方时恒为 6 时（日出时刻）。因此甲地地方时为 6 点。"

步骤 4：展示北半球昼长夜短，推断太阳直射北半球；高亮昼半球中央经线即直射点经度

冲突检查：
- "23.5°N"与"0°"：y 间距=107px → 无冲突
- "0°"与"23.5°S"：y 间距=107px → 无冲突
- "37.5"与"22.5"：x 间距=120px → 无冲突
- "甲"与"6 时"：y 间距=10px → 接近但可接受（"6 时"在"甲"下方，颜色不同可区分）
- "甲"与"晨线"：距离≈35px → 无冲突
- "乙"与"23.5°S"标签：乙(402,312) 与 23.5°S(550,332)，距离≈150px → 无冲突
- "37.5"与晨昏线顶端：晨昏线顶端(240,60)，"37.5"(175,50)，距离≈75px → 无冲突
- "西半球"在阴影区内，使用白色文字#ffffff，与#888888 背景对比度足够 → 无冲突
- "直射点经度"(420,45) 与"22.5"(295,50)：x 间距=125px → 无冲突

解决方案：所有标签间距均≥10px，"甲"与"6 时"虽近但垂直排列且颜色不同，可清晰区分。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 (180,450)，点击返回上一状态，步骤 0 时禁用
  - 「下一步」按钮：位于 (340,450)，点击进入下一状态，步骤 4 时禁用
  - 步骤指示器：位于两按钮之间 (290,460)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始展示原图，让学生观察昼夜分布特征
  2. 点击「下一步」高亮晨昏线，讲解晨线昏线判断方法
  3. 点击「下一步」显示东西半球分界，引导学生判断阴影所在半球
  4. 点击「下一步」高亮甲地，讲解晨线与赤道交点地方时为 6 时的规律
  5. 点击「下一步」显示直射点经线，讲解太阳直射点位置的判断方法
  6. 可随时点击「上一步」回退复习关键概念

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript
  - 原因：本图示为 2D 静态几何图形为主，辅以简单动画（淡入、绘制动画），原生 SVG 足够胜任且无需额外依赖
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +----------------------------------------------------------+
  | [图示区 480×320]        | [说明区 220×320]              |
  |  +------------------+   | 步骤说明文字                  |
  |  |  经纬网 + 晨昏线  |   | 动态更新每步讲解内容          |
  |  |  阴影区 + 标注    |   |                              |
  |  +------------------+   |                              |
  |                         |                              |
  |        [控件栏 y=440~490]                              |
  |     [◀上一步] [步骤 X/5] [下一步▶]                     |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量（0-4），steps 数组存储每步的配置对象（显示/隐藏的元素 ID 列表、说明文本）
  2. 坐标计算：所有元素坐标硬编码，确保与布局坐标表一致
  3. 动画曲线：使用 CSS transition 实现淡入淡出（opacity 0→1, 0.5s ease），绘制动画使用 stroke-dasharray + stroke-dashoffset
  4. 事件绑定：按钮点击事件绑定到 updateStep() 函数，更新当前步骤并刷新 DOM 元素显示状态
  5. 按钮禁用状态：步骤 0 时禁用「上一步」，步骤 4 时禁用「下一步」，添加 disabled 样式
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀
  - scene1-frame（图框）
  - scene1-lat-235n（23.5°N 纬线）
  - scene1-lat-0（赤道）
  - scene1-lat-235s（23.5°S 纬线）
  - scene1-lon-375w（37.5°W 经线）
  - scene1-lon-225w（22.5°W 经线）
  - scene1-terminator（晨昏线）
  - scene1-shadow（阴影区）
  - scene1-point-a（甲点）
  - scene1-point-b（乙点）
  - scene1-label-235n、scene1-label-0、scene1-label-235s（纬度标签）
  - scene1-label-375、scene1-label-225（经度标签）
  - scene1-label-a、scene1-label-b（点名标签）
  - scene1-label-morning（晨线标签）
  - scene1-label-6oclock（6 时标签）
  - scene1-hemisphere-boundary（东西半球分界虚线）
  - scene1-label-western（西半球标签）
  - scene1-solar-meridian（直射点经线）
  - scene1-label-solar（直射点标签）
  - scene1-description（说明文本区）
  - scene1-btn-prev（上一步按钮）
  - scene1-btn-next（下一步按钮）
  - scene1-step-indicator（步骤指示器）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
- 阴影填充实现：使用 SVG pattern 定义斜线填充，应用到 scene1-shadow 多边形
