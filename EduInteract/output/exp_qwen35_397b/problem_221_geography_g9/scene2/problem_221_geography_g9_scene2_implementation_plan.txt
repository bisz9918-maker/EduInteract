[图示主题与整合说明]
- 本图示主题：乙地昼长计算
- 整合的步骤/概念：通过昼弧占纬线圈的比例计算白昼时间，展示昼弧度数与昼长的换算关系
- 教学价值：教师可通过拖动滑块动态展示乙地所在纬线的昼弧范围，学生直观看到昼弧与夜弧的比例关系，理解"昼长=昼弧度数÷15°/小时"的计算原理，掌握从昼夜示意图中提取信息并计算昼长的方法

[分步序列]
本场景采用连续拖拽滑块交互，无固定步骤，状态连续变化：
- 初始状态（滑块 0%）：昼弧长度为 0，仅显示纬线基线、经线网格、乙地点，昼弧角度显示"0°"，昼长显示"0 小时"
- 拖拽过程（滑块 0%~100%）：
  - 昼弧段从乙地点向右逐渐延伸，绿色高亮区域逐渐扩大
  - 晨昏线交点随滑块右移
  - 昼弧角度标注实时更新：角度 = 滑块值% × 165°（乙地昼弧约 165°）
  - 昼长结果实时更新：昼长 = 昼弧度数 ÷ 15
- 最终状态（滑块 100%）：昼弧段延伸至完整长度，显示"昼弧 165°"，昼长显示"≈ 11 小时"

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：
  - 滑块轨道：位置 (200,450)-(600,470)，表示昼弧展开进度 0%~100%
  - 滑块手柄：圆形可拖拽元素，初始位置 (200,460)，拖拽范围 x=200~600
  - 左标签"0%"：位置 (120,460)
  - 右标签"100%"：位置 (620,460)
- 教师操作流程：
  1. 初始状态展示乙地纬线和经线网格，介绍乙地位置（南回归线 23.5°S）
  2. 拖动滑块从左向右，学生观察昼弧段（绿色）逐渐延伸
  3. 引导学生读取实时更新的昼弧度数和昼长计算结果
  4. 拖至 100% 时定格，强调乙地昼长约 11 小时的计算过程
  5. 可来回拖动滑块，对比不同进度下的昼弧比例

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript
  - SVG 适合绘制精确的几何图形和标注
  - 原生 JS 实现滑块拖拽逻辑简单高效，无需额外库
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |            乙地昼长计算示意图 (标题 y=40)          |
  |                                                  |
  |  +--------------------------------------------+  |
  |  |                                            |  |
  |  |   乙地      昼弧 (绿色)      夜弧 (灰色)     |  |
  |  |   ●━━━━━━━━━━━━━━━━━━┄┄┄┄┄┄┄┄┄┄┄┄┄┄●       |  |
  |  |   (23.5°S)  昼弧 XXX°                      |  |
  |  |                                            |  |
  |  |   |    |    |    |    |    |    |  经线     |  |
  |  +--------------------------------------------+  |
  |                                                  |
  |        昼长 = 昼弧度数 ÷ 15°/小时                |
  |              ≈ 11 小时                           |
  |                                                  |
  |        0% [━━━━●━━━━] 100%   (滑块控件)         |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：单一状态变量 sliderValue (0~100)，所有视觉元素根据此值更新
  2. 坐标计算：
     - 昼弧终点 x = 100 + (sliderValue / 100) × 360
     - 昼弧度数 = (sliderValue / 100) × 165（乙地昼弧约 165°）
     - 昼长 = 昼弧度数 / 15
  3. 动画曲线：拖拽时实时更新，无需额外动画
  4. 事件绑定：
     - mousedown/touchstart：开始拖拽
     - mousemove/touchmove：更新滑块位置和昼弧显示
     - mouseup/touchend：结束拖拽
  5. 边界限制：滑块手柄 x 坐标限制在 200~600 范围内
- ID 命名规范：所有交互元素 ID 以 scene2- 为前缀
  - scene2-lat-circle（纬线圈展开图）
  - scene2-lat-line（纬线基线）
  - scene2-day-arc（昼弧段）
  - scene2-night-arc（夜弧段）
  - scene2-point-yi（乙地点）
  - scene2-meridian-1~6（6 条经线）
  - scene2-day-angle-label（昼弧角度标注）
  - scene2-day-length-formula（昼长公式）
  - scene2-day-length-result（昼长结果）
  - scene2-slider-track（滑块轨道）
  - scene2-slider-handle（滑块手柄）
  - scene2-label-yi（乙地标签）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
