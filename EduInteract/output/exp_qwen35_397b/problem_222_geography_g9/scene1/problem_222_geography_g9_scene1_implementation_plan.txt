[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于 (250,460)，点击后返回上一状态，步骤 0 时禁用
  - 「步骤 X/5」显示：位于 (400,465)，显示当前步骤序号
  - 「下一步 ▶」按钮：位于 (550,460)，点击后进入下一状态，步骤 5 时禁用
- 教师操作流程：
  1. 初始展示经纬网框架，讲解经纬度概念
  2. 点击「下一步」逐步展示①②③④四点坐标，引导学生读图
  3. 最后展示新加坡位置，提问学生哪个点最接近
  4. 显示高亮点②，验证答案
  5. 可随时点击「上一步」回退复习

[技术实现]
- JS 库选择及原因：原生 SVG（简单几何图形，无需额外库，轻量且易于精确控制坐标）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  经度标注 (y=25): 150° 120° ... 0° ... 120° 150° |
  |  +--------------------------------------------+  |
  |  |                                            |  |
  |  |           经纬网网格区域                    |  | 纬度标注
  |  |   ④(129,80)                    ③(681,80)  |  | (x=765)
  |  |                                            |  | 40°N
  |  |                                            |  | 30°N
  |  |                                            |  | 20°N
  |  |                                            |  | 10°N
  |  |   ①(129,360)                   ②(612,360) |  | 0°
  |  |                              ★新加坡       |  | 10°S
  |  +--------------------------------------------+  |
  |                                                  |
  |        [◀ 上一步]  步骤 X/5  [下一步 ▶]          |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量（0-5），每个步骤对应一组可见元素
  2. 坐标计算：经度 x = 60 + (lon + 150) * 2.3，纬度 y = 40 + (40 - lat) * 8
  3. 元素分组：将每个步骤新增的元素放入独立 g 元素，通过 display 控制显示/隐藏
  4. 按钮状态：步骤 0 禁用上一步，步骤 5 禁用下一步
  5. 动画效果：元素出现使用淡入动画（opacity 0→1，300ms）
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀
  - scene1-grid-group（经纬网组）
  - scene1-point1, scene1-point2, scene1-point3, scene1-point4（四个点）
  - scene1-label1, scene1-label2, scene1-label3, scene1-label4（坐标标注）
  - scene1-singapore（新加坡标记组）
  - scene1-highlight2（点②高亮圈）
  - scene1-btn-prev, scene1-btn-next, scene1-step-display（控件）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中
