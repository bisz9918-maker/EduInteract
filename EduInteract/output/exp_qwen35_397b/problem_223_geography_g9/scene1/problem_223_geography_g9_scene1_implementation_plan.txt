[图示主题与整合说明]
- 本图示主题：地球公转轨道四位置（二分二至点）及其地理意义
- 整合的步骤/概念：整合了公转轨道整体结构、四个位置（a/b/c/d）的日期、太阳直射点、昼夜长短、极昼极夜现象

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于 (280, 465)，点击后切换到前一个步骤，步骤 0 时禁用
  - 「下一步 ▶」按钮：位于 (420, 465)，点击后切换到下一个步骤，步骤 5 时禁用
  - 步骤指示器：位于 (390, 470)，显示当前步骤编号如"步骤 2/5"
- 教师操作流程：
  1. 初始展示完整公转轨道图，让学生观察四个位置
  2. 点击「下一步」进入步骤 1，讲解夏至位置 c 的特征
  3. 继续点击「下一步」依次讲解冬至、春分、秋分
  4. 如需复习，点击「上一步」回退到之前位置
  5. 最后到达步骤 5 总结公转规律

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（圆形、椭圆、线段），无需复杂库；原生 SVG 性能好、代码简洁；交互逻辑简单（状态切换）
  
- 画布尺寸：800 × 500 px（固定）

- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                    b(春分)                        |
  |                      ●                            |
  |                                                   |
  |     c(夏至)  ●-----------●  a(冬至)              |
  |                  (太阳)                           |
  |                                                   |
  |                      ●                            |
  |                    d(秋分)                        |
  |                                    [信息框]       |
  |                                                   |
  |                                                   |
  |         [◀ 上一步]  步骤 X/5  [下一步 ▶]          |
  +--------------------------------------------------+
  ```

- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量 (0-5) 跟踪当前步骤，steps 数组存储每步配置
  2. 坐标计算：地球位置使用椭圆参数方程 x=400+260*cos(θ), y=250+160*sin(θ)，其中θ分别为 0°(a)、90°(b)、180°(c)、270°(d)
  3. 地轴倾斜：所有地轴保持相同倾斜方向（指向北极星），与公转位置无关
  4. 昼夜半球：根据太阳方向计算昼/夜半球的分界线，使用 clipPath 或 mask 实现
  5. 动画曲线：公转箭头循环动画使用 CSS animation 或 requestAnimationFrame
  6. 事件绑定：按钮点击事件绑定到 stepChange 函数，更新 currentStep 并调用 renderStep()
  7. 元素显隐：使用 display/opacity 或 SVG visibility 属性控制元素显示

- ID 命名规范：
  - 所有交互元素 ID 必须以 scene1- 为前缀
  - 示例：scene1-sun, scene1-orbit, scene1-earth-a, scene1-earth-b, scene1-earth-c, scene1-earth-d
  - 示例：scene1-label-a, scene1-label-b, scene1-label-c, scene1-label-d
  - 示例：scene1-info-box, scene1-btn-prev, scene1-btn-next, scene1-step-indicator
  - 示例：scene1-axis-a, scene1-axis-b, scene1-axis-c, scene1-axis-d
  - 示例：scene1-arrow-1, scene1-arrow-2, scene1-arrow-3, scene1-arrow-4
  - JS 中使用 getElementById('scene1-earth-a') 直接获取，避免跨场景污染
