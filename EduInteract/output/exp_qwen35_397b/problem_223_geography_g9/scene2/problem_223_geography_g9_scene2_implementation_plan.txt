[图示主题与整合说明]
- 本图示主题：太阳直射点移动规律与南北半球季节对比

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：
  - 滑块轨道：位于底部 y=460，从 x=50 到 x=750，长度 700px
  - 滑块手柄：绿色圆形，可左右拖拽，范围 0%-100%
  - 刻度标签：1 月、6 月、12 月标记在滑块下方
- 教师操作流程：
  1. 初始状态显示夏至（6 月），教师讲解北半球夏季特征
  2. 缓慢向左拖动滑块，学生观察直射点如何从北回归线向南移动
  3. 停在春分（3 月）位置，讲解昼夜平分现象
  4. 继续拖动到冬至（1 月），对比南北半球季节相反
  5. 拖动到秋分（9 月），完成一个周年循环
  6. 可快速来回拖动，让学生感受直射点移动的连续性和周期性

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（坐标轴、正弦曲线、圆形标记），无需复杂库；拖拽交互用原生事件即可实现
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  | [左侧坐标图区 60%]    | [右侧季节表区 40%]       |
  |                        |                          |
  |  23.5°N ───────┐      |  北半球：[夏季]          |
  |        ╱╲      │      |                          |
  |  0° ──╱──╲─────┤      |  南半球：[冬季]          |
  |      ╱    ╲    │      |                          |
  | 23.5°S──────╲──┘      |                          |
  |  1 月   6 月   12 月   |                          |
  |                        |                          |
  |  当前：6 月 夏至       |                          |
  |  直射点：23.5°N       |                          |
  |                        |                          |
  |  [══════●══════] 滑块 |                          |
  |   1 月       6 月  12 月|                          |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 正弦曲线计算：y = 190 - 130 * sin((sliderValue / 100) * 2π - π/2)，其中 190 是赤道 y 坐标，130 是振幅
  2. 月份计算：sliderValue 0-100 对应 1-12 月，月份 = Math.floor(sliderValue / 100 * 12) + 1
  3. 节气判断：根据 sliderValue 范围判断春分 (25%)、夏至 (50%)、秋分 (75%)、冬至 (0%/100%)
  4. 季节判断：3-5 月春季，6-8 月夏季，9-11 月秋季，12-2 月冬季；南半球相反
  5. 吸附效果：当滑块接近 0%、25%、50%、75%、100% 时（±3% 范围），自动吸附到精确位置
  6. 拖拽事件：mousedown/touchstart 开始拖拽，mousemove/touchmove 更新位置，mouseup/touchend 结束
  7. 地球公转位置同步：根据滑块位置计算地球在轨道上的角度，更新地球图标位置
- ID 命名规范：所有元素 ID 以 scene2- 为前缀
  - scene2-axis-y, scene2-axis-x
  - scene2-line-tropic-n, scene2-line-equator, scene2-line-tropic-s
  - scene2-curve-trajectory, scene2-dot-sun
  - scene2-label-23-5n, scene2-label-0, scene2-label-23-5s
  - scene2-label-jan, scene2-label-jun, scene2-label-dec
  - scene2-label-spring, scene2-label-summer, scene2-label-autumn, scene2-label-winter
  - scene2-box-north, scene2-text-north-season
  - scene2-box-south, scene2-text-south-season
  - scene2-text-month, scene2-text-latitude
  - scene2-slider-track, scene2-slider-handle
  - scene2-text-slider-jan, scene2-text-slider-jun, scene2-text-slider-dec
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
