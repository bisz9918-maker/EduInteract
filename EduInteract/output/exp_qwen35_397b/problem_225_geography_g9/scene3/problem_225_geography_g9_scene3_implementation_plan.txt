[图示主题与整合说明]
- 本图示主题：经纬网中点对方向关系判断
- 整合内容：整合了 A 与 C 的方向关系、B 与 C 的方向关系两小题的方向判断可视化
- 教学价值：教师可通过状态切换清晰展示不同点对之间的方向判断逻辑。状态 1 展示同经度点的正北/正南方向判断（纬度比较），状态 2 展示不同经纬度点的复合方向判断（东北/东南/西北/西南），帮助学生理解方向判断的两个维度：南北方向看纬度，东西方向看经度。

[交互方案]
- 交互类型：多状态切换（3 个状态按钮）
- 控件说明：
  - 按钮"基础图"：位于 (140,465)，点击返回状态 0，显示基础经纬网和四点
  - 按钮"A→C 方向"：位于 (250,465)，切换到状态 1，展示 A 与 C 的正北方向关系
  - 按钮"B→C 方向"：位于 (360,465)，切换到状态 2，展示 B 与 C 的东北方向关系
- 教师操作流程：
  1. 初始展示基础图，让学生识别四点的经纬度坐标
  2. 点击"A→C 方向"，引导学生观察 A 和 C 在同一条经线上，A 的纬度更高，因此 A 在 C 的正北方向
  3. 点击"B→C 方向"，引导学生分析 B 相对于 C 既有向东的经度差，又有向北的纬度差，因此 B 在 C 的东北方向
  4. 可随时点击"基础图"返回初始状态复习

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（直线、圆、箭头），无需复杂库；原生 SVG 交互性能好，代码简洁
- 画布尺寸：800×500 px（固定）
- 布局草图：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │  80°│  A                                                      │
  │  60°│                                                         │
  │  40°│                          B                              │
  │  20°│  C                                                      │
  │   0°│─────────────────────────────────────────────────────────│
  │  20°│                          D                              │
  │  40°│                                                         │
  │     └─────────────────────────────────────────────────────────┘
  │      120° 140° 160° 180° 160° 140° 120°                        │
  │                                                                 │
  │     [基础图]  [A→C 方向]  [B→C 方向]                            │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentState 跟踪当前状态（0/1/2），每次切换先隐藏所有状态相关元素，再显示目标状态元素
  2. 箭头 marker 定义：在 SVG <defs> 中定义红色箭头 marker，用于方向箭头
  3. 点的状态切换：通过改变 fill 和 r 属性实现颜色和大小的变化
  4. 元素分组：将状态 1 和状态 2 的元素分别放在 <g> 组中，通过 display 属性控制显示/隐藏
  5. 事件绑定：三个按钮分别绑定点击事件，调用 switchState(0/1/2) 函数
- ID 命名规范：所有元素 ID 以 scene3- 为前缀
  - 点：scene3-point-a, scene3-point-b, scene3-point-c, scene3-point-d
  - 标签：scene3-label-a, scene3-label-b, scene3-label-c, scene3-label-d
  - 箭头：scene3-arrow-ac, scene3-arrow-cb, scene3-arrow-east, scene3-arrow-north
  - 状态组：scene3-state1-group, scene3-state2-group
  - 按钮：scene3-btn-base, scene3-btn-ac, scene3-btn-cb
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
