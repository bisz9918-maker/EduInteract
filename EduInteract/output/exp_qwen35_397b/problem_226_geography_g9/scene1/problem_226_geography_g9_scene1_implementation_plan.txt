[图示主题与整合说明]
- 本图示主题：地球光照图核心要素解析——冬至日太阳光照特征
- 整合的步骤/概念：太阳光线方向、晨昏线、太阳直射点、极昼极夜区域、A/B/C 三点位置、昼夜长短判定
- 教学价值：教师可逐步揭示光照图各要素，从整体到局部，帮助学生建立完整的读图方法。通过分步高亮，学生能清晰理解冬至日太阳直射南回归线时，北半球昼短夜长、北极圈极夜、南极圈极昼的特征。

[分步序列]
- 初始状态（步骤0）：显示地球球体轮廓、地轴(N/S)、5条纬线、多条经线、A/B/C三点及其标签、太阳光线5条（灰色半透明）、夜半球阴影（灰色半透明）。等待教师触发交互。
- 步骤1：点击「下一步」→ 太阳光线变为#f57f17橙色高亮，太阳直射点红点出现，"23.5°S"标签出现，"太阳光线"标签出现。强调光线平行射入，直射南回归线。
- 步骤2：点击「下一步」→ 晨昏线变为#1565c0蓝色高亮，"晨昏线"标签出现，"昼半球"(200,350)和"夜半球"(600,350)标签出现。说明晨昏线是昼夜分界线。
- 步骤3：点击「下一步」→ 北极圈内显示"极夜"标签(400,130)，南极圈内显示"极昼"标签(400,370)，极夜/极昼区域用不同透明度阴影强调。说明冬至日极圈内的特殊现象。
- 步骤4：点击「下一步」→ A/B/C三点及标签高亮显示，A点所在经线标注"正午"，C点所在经线标注"深夜"。说明不同经度的时间差异。
- 最终步骤（结论）：所有元素完整显示，底部显示结论框"冬至日：12月22日前后，太阳直射23.5°S，北半球昼短夜长，北极圈极夜"。

- "S"(355,325)与"昼半球"(200,350)：水平距离155px，垂直距离25px → 无冲突
- "23.5°S"(250,305)与"A"(330,215)：水平距离80px，垂直距离90px → 无冲突
- "晨昏线"(420,250)与"C"(535,245)：水平距离115px，垂直距离5px → 无冲突（晨昏线在球内，C在球外右侧）
- "极夜"(400,130)与"N"(445,175)：水平距离45px，垂直距离45px → 无冲突
- "极昼"(400,370)与"昼半球"(200,350)：水平距离200px，垂直距离20px → 无冲突
- "昼半球"(200,350)与"夜半球"(600,350)：水平距离400px → 无冲突
- 所有标签与地球球体边缘距离≥15px → 无冲突

结论：所有标签间距均≥20px，无重叠冲突。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 按钮"◀上一步"：位置(320,460)，宽100px，高40px，点击后退到前一状态
  - 按钮"下一步▶"：位置(480,460)，宽100px，高40px，点击前进到下一状态
  - 状态指示器：位置(400,445)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始状态展示完整光照图框架，让学生观察整体
  2. 点击"下一步"高亮太阳光线，提问"太阳光线从哪个方向射入？直射哪里？"
  3. 点击"下一步"高亮晨昏线，提问"哪边是昼半球？哪边是夜半球？"
  4. 点击"下一步"显示极昼极夜，提问"北极圈内是什么现象？"
  5. 点击"下一步"标注ABC三点，提问"A、B、C三点分别在什么时间？"
  6. 最后总结冬至日的判定依据

[技术实现]
- JS 库选择及原因：原生 SVG。原因：地球光照图为2D几何图形，SVG 能精确控制圆形、弧线、箭头、文本的位置和样式，且支持分层显示和透明度控制，无需额外库。
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                    极夜(400,130)                  |
  |         太阳光线                    N(445,175)    |
  |    →→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→  |
  |    →→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→  |
  |    →→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→  |
  |    →→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→  |
  |    →→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→  |
  |                    晨昏线(420,250)  C(535,245)    |
  |         23.5°S(250,305)                           |
  |                                                   |
  |    昼半球(200,350)          极昼(400,370)  夜半球(600,350)|
  |                                                   |
  |              [◀上一步]  步骤X/5  [下一步▶]         |
  |                    (控件栏 y=440~490)             |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentIndex 变量(0-5)跟踪当前步骤，steps 数组存储每步需要显示的元素ID列表
  2. 坐标计算：地球球体中心(400,250)，纬线为椭圆弧，使用 SVG <ellipse> 或 <path> 绘制
  3. 太阳光线箭头：使用 SVG <marker> 定义箭头，<line> + marker-end 实现
  4. 夜半球阴影：使用 <clipPath> 裁剪右半圆，配合 <pattern> 实现斜线填充
  5. 事件绑定：按钮点击事件切换状态，更新元素 display 属性
  6. 动画过渡：可选添加 opacity 过渡效果(0.3s)使元素渐显
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀（如 scene1-earth、scene1-sun-ray-1、scene1-point-a）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中
