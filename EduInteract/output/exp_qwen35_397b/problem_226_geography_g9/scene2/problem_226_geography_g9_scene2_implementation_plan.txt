[图示主题与整合说明]
- 本图示主题：太阳直射点周年移动与昼夜长短变化规律
- 整合的步骤/概念：整合春分、夏至、秋分、冬至四个关键节气的太阳直射点位置、对应日期、全球昼夜长短分布的对比展示
- 教学价值：教师可通过分步切换展示四个节气的光照图，直观演示太阳直射点在南北回归线之间的周年移动规律，以及由此导致的全球昼夜长短变化。学生可清晰观察到：直射点在北半球时北半球昼长夜短，直射点在南半球时北半球昼短夜长，直射赤道时全球昼夜平分。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 内底部左侧 (280,450)，点击返回上一节气状态
  - 「下一步」按钮：位于 SVG 内底部右侧 (440,450)，点击进入下一节气状态
  - 步骤指示器：位于两按钮之间 (380,455)，显示当前步骤如"1/5"
- 教师操作流程：
  1. 初始显示春分日光照图，讲解直射赤道时全球昼夜平分
  2. 点击「下一步」切换到夏至日，讲解直射北回归线时北半球昼长夜短
  3. 点击「下一步」切换到秋分日，再次展示昼夜平分
  4. 点击「下一步」切换到冬至日（本题状态），讲解直射南回归线时北半球昼短夜长，对应题图
  5. 点击「下一步」显示总结表格，对比四个节气的差异
  6. 可随时点击「上一步」回退复习

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript。原因：本场景为 2D 几何图形切换，无需复杂动画库，原生 SVG 可精确控制坐标和样式，代码轻量易维护
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                    节气名称                       | y=50
  |                    日期标注                       | y=75
  |                                                  |
  |         太阳光线  →→→  [地球光照图]              | y=100-300
  |                                                  |
  |                  直射纬度                         | y=320
  |                  昼夜情况                         | y=345
  |                                                  |
  |              [总结表格 - 步骤 4 显示]              | y=380-430
  |                                                  |
  |         [◀上一步]  1/5  [下一步▶]                | y=450
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量 (0-4) 跟踪当前步骤，steps 数组存储每个步骤的配置数据
  2. 坐标计算：直射点 y 坐标 = 200 - sin(节气角度) × 21（23.5°对应约 21px 像素偏移）
  3. 晨昏线绘制：春分/秋分为竖直线，夏至/冬至为倾斜线（使用 clipPath 实现昼夜半球）
  4. 动画过渡：直射点移动使用 CSS transition 实现平滑过渡（duration 500ms）
  5. 事件绑定：按钮点击事件更新 currentStep，调用 renderStep() 重绘
  6. 边界处理：步骤 0 时禁用「上一步」，步骤 4 时禁用「下一步」
- ID 命名规范：所有交互元素 ID 必须以 scene2- 为前缀
  - scene2-earth（地球轮廓）
  - scene2-sun-rays（太阳光线组）
  - scene2-day-hemisphere（昼半球）
  - scene2-night-hemisphere（夜半球）
  - scene2-terminator（晨昏线）
  - scene2-direct-point（直射点）
  - scene2-direct-label（直射点标签）
  - scene2-solar-term-name（节气名称）
  - scene2-date-label（日期标注）
  - scene2-latitude-label（直射纬度）
  - scene2-daynight-label（昼夜情况）
  - scene2-prev-btn（上一步按钮）
  - scene2-next-btn（下一步按钮）
  - scene2-step-indicator（步骤指示器）
  - scene2-summary-table（总结表格）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
