冲突检查：
- A坐标标签(105,45)与纬度40°(610,60)：水平距离505px → 无冲突
- B坐标标签(105,245)与纬度20°(610,220)：水平距离505px → 无冲突
- C坐标标签(535,85)与纬度30°(610,140)：水平距离75px，垂直距离55px → 无冲突
- D坐标标签(535,245)与纬度20°(610,220)：水平距离75px，垂直距离25px → 无冲突
- 经度标签之间：(100,390)与(310,390)距离210px，(310,390)与(520,390)距离210px → 无冲突
- 所有坐标标签与主图区元素：标签放在点的外侧，距离点至少15px → 无冲突

解决方案：所有标签间距均≥20px，布局合理无重叠

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于SVG底部左侧(x=320,y=455)，灰色背景，点击返回上一状态
  - 「下一步」按钮：位于SVG底部右侧(x=460,y=455)，蓝色背景，点击进入下一状态
  - 步骤指示器：位于底部中央(x=400,y=455)，显示"步骤X/4"
- 教师操作流程：
  1. 初始展示原图，让学生观察经纬网结构
  2. 点击「下一步」显示四点坐标，引导学生读取坐标
  3. 点击「下一步」显示南北半球划分，讲解赤道的作用
  4. 点击「下一步」显示东西半球划分，强调20°W-160°E规则
  5. 点击「下一步」显示完整结论，总结判断方法

[技术实现]
- JS库选择：原生SVG + 原生JavaScript
  - 原因：几何图形简单，无需复杂库；SVG便于精确控制坐标和样式
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：

- 关键实现要点：
  1. 状态机设计：用currentStep变量(0-4)跟踪当前步骤，steps数组存储每步的可见元素ID列表
  2. 坐标计算：经纬线使用SVG path的二次贝塞尔曲线(Q命令)绘制弯曲效果
  3. 动画曲线：元素淡入使用CSS transition opacity 0.3s ease
  4. 事件绑定：按钮点击事件调用updateStep()函数，根据currentStep显示/隐藏对应元素
  5. 边界检查：第一步禁用「上一步」，最后一步禁用「下一步」
- ID命名规范：所有元素ID以scene1-为前缀
  - scene1-lat-40, scene1-lat-30, scene1-lat-20（纬线）
  - scene1-lon-170E, scene1-lon-180, scene1-lon-170W（经线）
  - scene1-point-a, scene1-point-b, scene1-point-c, scene1-point-d（四点）
  - scene1-label-a, scene1-label-b, scene1-label-c, scene1-label-d（坐标标签）
  - scene1-equator, scene1-north-hemisphere（赤道和北半球区域）
  - scene1-ew-boundary-1, scene1-ew-boundary-2（东西半球分界线）
  - scene1-west-hemisphere（西半球区域）
  - scene1-conclusion-text（结论文本）
  - scene1-btn-prev, scene1-btn-next, scene1-step-indicator（控件）
- IIFE隔离：所有JS代码包在(function() { ... })()中，避免全局变量污染
