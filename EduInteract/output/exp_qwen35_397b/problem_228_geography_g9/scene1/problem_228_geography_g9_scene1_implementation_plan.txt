[图示主题与整合说明]
- 本图示主题：光照图基础要素识别与日期分界线分析

- "0°"(670,85)与"23.5°"(670,160)：间距75px → 不冲突
- "23.5°"(670,160)与"70°"(670,310)：间距150px → 不冲突

- "B"(665,65)与"0°"(670,85)：间距≈21px → 临界，已错开y坐标
- "O"(405,325)与"70°"(670,310)：x间距265px → 不冲突
- "晨线"(520,200)与"昏线"(280,200)：x间距240px → 不冲突
- "180°"(670,230)与"0时"(120,230)：x间距550px → 不冲突
- 所有标签与图形元素：标签均置于外侧空白区，无重叠

结论：所有标签间距≥20px，无冲突

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于(280,450)，点击返回上一状态，第一步时禁用
  - 「下一步 ▶」按钮：位于(420,450)，点击进入下一状态，最后一步时禁用
  - 步骤指示器：位于(380,475)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始展示基础经纬网格，让学生识别A、B、O三点位置
  2. 点击「下一步」高亮晨昏线，讲解晨线BO和昏线AO的判断方法
  3. 点击「下一步」填充昼夜半球，直观展示昼夜分布
  4. 点击「下一步」显示日期分界线，讲解180°经线和0时经线的意义
  5. 点击「下一步」显示阴影区，说明阴影区与0时经线的关系（阴影区即为与全球日期不同的经度范围）

[技术实现]
- JS库选择：原生SVG + 原生JavaScript
  - 原因：几何图形简单，SVG原生支持足够；无需复杂动画库；CDN依赖最少
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [800 × 500 画布]
  +----------------------------------------------------------+
  |                    光照图基础要素识别                      |  y=35 标题
  +----------------------------------------------------------+
  |                                                          |
  |   [0时]  昏线              晨线                    [180°]  |
  |     |     \                /                        |     |
  |     |      \              /                         |     |
  |     |       \     O      /                          |     |
  |     |        \    *     /                           |     |
  |     |         \        /                            |     |
  |     |          \      /                             |     |
  |   [阴影区]       \    /                              |     |
  |     |            \  /                               |     |
  |     |             \/                                |     |
  |                                                          |
  |   [图例区：晨线/昏线/昼/夜/日期线/阴影]                     |
  |                                                          |
  +----------------------------------------------------------+
  |              [◀ 上一步]      [下一步 ▶]                    |  y=450 控件
  |                    步骤 1/5                                |  y=475 指示
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量currentStep(0-4)跟踪当前步骤，steps数组存储每步需显示的元素ID列表
  2. 元素分组：按步骤将SVG元素分组，每组用display控制显隐
  3. 按钮状态：第一步禁用「上一步」，最后一步禁用「下一步」
  4. 坐标计算：所有坐标硬编码，确保与布局表一致
  5. 动画过渡：使用CSS transition实现淡入效果（opacity从0到1，300ms）
- ID命名规范：所有元素ID以scene1-为前缀
  - scene1-grid-lat-0, scene1-grid-lat-235, scene1-grid-lat-70
  - scene1-grid-lon-1至scene1-grid-lon-7
  - scene1-point-a, scene1-point-b, scene1-point-o
  - scene1-line-ao（昏线）, scene1-line-bo（晨线）
  - scene1-label-a, scene1-label-b, scene1-label-o
  - scene1-label-0deg, scene1-label-235deg, scene1-label-70deg
  - scene1-day-area, scene1-night-area
  - scene1-date-line-180, scene1-date-line-0h
  - scene1-shadow-area
  - scene1-btn-prev, scene1-btn-next, scene1-step-indicator
- IIFE隔离：所有JS代码包在(function() { ... })()中，避免全局污染
