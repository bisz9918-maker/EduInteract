[图示主题与整合说明]
- 本图示主题：太阳直射点位置推导与季节判断
- 整合的步骤/概念：极昼极夜范围判定、直射点纬度计算、二分二至日判断、直射点经度确定

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  · 上一步按钮：位置(480,440)，尺寸100×40px，背景#1565c0蓝色，文字白色
  · 下一步按钮：位置(620,440)，尺寸100×40px，背景#1565c0蓝色，文字白色
  · 步骤指示器：位置(300,450)，显示"步骤X/4"
- 教师操作流程：
  1. 初始状态展示基础光照图，引导学生观察晨昏线形态
  2. 点击"下一步"展示极昼区，提问学生极昼范围与直射点的关系
  3. 点击"下一步"展示直射点和光线，讲解纬度计算原理
  4. 点击"下一步"判断季节，联系二分二至日知识
  5. 点击"下一步"确定经度，完成直射点坐标推导
  6. 可随时点击"上一步"回退复习关键步骤

[技术实现]
- JS库选择：原生SVG + 原生JavaScript
  · 原因：几何图形简单，无需复杂库；SVG便于精确坐标控制和动画
- 画布尺寸：800×500px（固定）
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │ [标题] 太阳直射点位置推导                    (800×25)       │
  ├─────────────────────┬───────────────────────────────────────┤
  │                     │                                       │
  │   光照图分析区      │         推导过程文字框                │
  │   (40,60)-(420,420) │         (450,60)-(780,420)           │
  │   380×360           │         330×360                       │
  │                     │                                       │
  │   [晨昏线+纬线+     │   [分步显示推导文字]                  │
  │    极昼区+直射点]   │                                       │
  │                     │                                       │
  ├─────────────────────┴───────────────────────────────────────┤
  │         [◀上一步]    步骤X/4    [下一步▶]                   │
  │         (480,440)              (620,440)                    │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用currentStep变量(0-4)跟踪当前步骤
  2. 元素分组：将每步新增元素放入独立<g>组，通过display控制显示/隐藏
  3. 动画效果：直射点使用CSS animation实现半径脉冲(6→8→6)
  4. 事件绑定：按钮点击事件切换步骤，更新推导文字内容
  5. 边界检查：步骤0禁用"上一步"，步骤4禁用"下一步"
- ID命名规范：所有元素ID以scene2-为前缀
  · scene2-light-diagram（光照图主组）
  · scene2-step0、scene2-step1...scene2-step4（各步骤元素组）
  · scene2-btn-prev、scene2-btn-next（导航按钮）
  · scene2-step-indicator（步骤指示器）
  · scene2-derivation-text（推导文字）
- IIFE隔离：所有JS代码包裹在(function() { ... })()中
- 响应式：固定800×500画布，通过viewBox实现SVG缩放
