[图示主题与整合说明]
- 本图示主题：利用经纬网判断相对方向
- 整合的步骤/概念：整合了方向判断原理、D 相对于 A 的方向、E 相对于 F 的方向两个实例
- 教学价值：教师可使用此图示逐步演示经纬网上两点间相对方向的判断方法。先展示参考点和目标点，再分别高亮东西方向和南北方向的判断过程，最后合成显示完整方向结论。通过分步动画帮助学生理解"先判东西、再判南北、最后合成"的方向判断逻辑。

[视觉元素清单]

- 经度标签：140°E、180°、140°W，黑色文字，位于顶部 y=65
- 纬度标签：60°N、40°N，黑色文字，位于右侧 x=660
- 参考点 A、F：#1565c0 蓝色实心圆，r=6px
- 目标点 D、E：#c62828 红色实心圆，r=6px
- 点标签 A、D、E、F：黑色文字，偏移放置避免重叠
- 东西向辅助线：#888888 灰色虚线 2px
- 南北向辅助线：#888888 灰色虚线 2px
- 方向箭头：#2e7d32 绿色实线箭头 2px
- 方向标签框：白色背景带边框，显示"西北"或"西南"
- 颜色规格沿用 scene_outline 中的配色规则

[分步序列]
- 初始状态（步骤 0）：显示完整经纬网、经度纬度标签、点 A（蓝色）和点 D（红色）、点标签 A 和 D。E 和 F 点隐藏。
- 步骤 1：点击「下一步」→ 显示从 D 到 A 的东西向辅助线（灰色虚线），显示绿色箭头从 D 指向东（A 的方向），在箭头上方显示"东"标签。
- 步骤 2：点击「下一步」→ 显示从 D 向南的南北向辅助线（灰色虚线），显示绿色箭头从 D 指向南，在箭头旁显示"南"标签。
- 步骤 3：点击「下一步」→ 显示合成方向箭头（从 D 指向东南方向的 A），在箭头末端显示标签框"西北"（D 在 A 的西北方向）。
- 步骤 4：点击「下一步」→ 隐藏 A、D 相关元素，显示点 F（蓝色）和点 E（红色）、点标签 F 和 E。经纬网保持显示。
- 步骤 5：点击「下一步」→ 显示从 E 到 F 的东西向辅助线和箭头（E 在 F 的西侧），显示南北向辅助线和箭头（E 在 F 的南侧），最后显示合成方向箭头和标签框"西南"。
- 最终步骤：展示 E 在 F 的西南方向完整结论，所有方向箭头和标签可见。

冲突检查：
- "A"(410,70) 与 "180°"(385,65)：间距≈26px → 无冲突
- "D"(135,65) 与 "140°E"(145,65)：间距≈10px → 有冲突！解决方案：将 D 标签移至(130,55)
- "E"(135,415) 与 "40°N"(660,395)：间距远 → 无冲突
- "F"(665,415) 与 "40°N"(660,395)：间距≈20px → 边界，将 F 移至(670,425)
- "西北"(260,50) 与 其他标签：间距充足 → 无冲突
- "西南"(380,350) 与 其他标签：间距充足 → 无冲突

修正后标签坐标：
- 标签"D"：(125,55) 左上偏移
- 标签"F"：(670,425) 右下偏移

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于(250,455)，100×35px，点击返回上一状态
  - 「下一步」按钮：位于(450,455)，100×35px，点击进入下一状态
  - 步骤指示器：位于(400,470)，显示"步骤 X/6"
- 教师操作流程：
  1. 初始状态展示经纬网和 A、D 两点，提问"D 在 A 的什么方向？"
  2. 点击「下一步」高亮东西方向，引导学生判断 D 在 A 的西侧
  3. 点击「下一步」高亮南北方向，引导学生判断 D 在 A 的北侧
  4. 点击「下一步」显示合成结论"西北"，总结判断方法
  5. 点击「下一步」切换到 E、F 两点，让学生独立练习
  6. 点击「下一步」显示 E 相对于 F 的方向判断过程和结论"西南"

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +------------------------------------------+
  |  140°E  180°  140°W    60°N              |
  |  D-----------A-------------------  60°N  |
  |   \         |         /                  |
  |    \        |        /                   |
  |     \       |       /                    |
  |      \      |      /                     |
  |       \     |     /                      |
  |        \    |    /                       |
  |   E-----\---+---/------------F  40°N     |
  |                                          |
  |         [西北]        [西南]             |
  |                                          |
  |      [◀上一步]  步骤 X/6  [下一步▶]      |
  +------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量(0-6)跟踪当前步骤，steps 数组存储每步的显示配置
  2. 坐标计算：经纬线使用 SVG path 绘制弧线，经线为纵向弧，纬线为横向弧
  3. 动画曲线：使用 CSS transition 实现元素淡入淡出，duration 300ms
  4. 事件绑定：按钮点击事件绑定到 stepForward() 和 stepBack() 函数
  5. 元素分组：使用 SVG g 元素按功能分组（经纬网组、点组、箭头组、标签组），便于按步骤显示/隐藏
- ID 命名规范：所有交互元素 ID 必须以 scene2- 为前缀
  - scene2-lat-lon-grid（经纬网组）
  - scene2-point-a, scene2-point-d, scene2-point-e, scene2-point-f
  - scene2-label-a, scene2-label-d, scene2-label-e, scene2-label-f
  - scene2-arrow-ad-east, scene2-arrow-ad-north
  - scene2-arrow-ef-west, scene2-arrow-ef-south
  - scene2-direction-nw, scene2-direction-sw
  - scene2-btn-prev, scene2-btn-next, scene2-step-indicator
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
