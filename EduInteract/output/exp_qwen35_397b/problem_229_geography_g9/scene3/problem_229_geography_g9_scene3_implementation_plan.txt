[分步序列]
本场景为连续拖拽滑块交互，无分步导航，状态随滑块实时变化：

- 初始状态（滑块在 0°）：
  - 显示地球侧视图，0°经线（灰色）和 180°经线（灰色虚线）重合于中央
  - 当前经线（蓝色）与 0°经线重合
  - 互补经线（红色）与 180°经线重合
  - 顶部显示："当前经线：0°"，"互补经线：180°"
  - 经线圈（绿色虚线）高亮显示
  - 规律公式："互补经线和为 180°，东西经相反"

- 滑块拖动过程（0°→180°连续变化）：
  - 当前经线（蓝色）从 0°位置顺时针旋转
  - 互补经线（红色）始终与当前经线保持 180°相对位置
  - 经度数值实时更新：当前经度 = 滑块值，互补经度 = 180°-滑块值
  - 东西经标识自动切换（0°-180°为东经，互补为西经）

- 特例状态（滑块在 180°）：
  - 当前经线（蓝色）位于 180°位置
  - 互补经线（红色）回到 0°位置
  - 顶部显示："当前经线：180°"，"互补经线：0°"
  - 展示 180°经线的互补经线是 0°经线

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：
  - 滑块轨道：水平线段，从 0°到 180°
  - 滑块手柄：圆形，可左右拖动，改变当前经度值
  - 0°刻度：滑块左端标注
  - 180°刻度：滑块右端标注
  - 东经/西经标识：滑块两端上方标注
- 教师操作流程：
  1. 初始状态展示 0°与 180°的互补关系
  2. 拖动滑块从 0°向 180°移动，观察当前经线与互补经线的实时变化
  3. 暂停在任意位置（如 30°、60°、90°），让学生计算互补经度
  4. 拖动到 180°，展示特例：180°的互补经线是 0°
  5. 引导学生总结规律：互补经线和为 180°，东西经相反

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单，无需复杂库；原生 SVG 便于精确控制坐标和动画
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────┐
  │  当前经线：X°        互补经线：Y°                   │ y=50
  │  互补经线和为 180°，东西经相反                       │ y=80-105
  │                                                     │
  │           ┌─────────────┐                           │
  │           │   地球视图   │  [图例]                   │ y=110-370
  │           │  (经线动态)  │  蓝色：当前经线           │
  │           └─────────────┘  红色：互补经线           │
  │                              绿色：经线圈           │
  │                                                     │
  │         东经                    西经                │ y=420
  │  0° ──────●─────────────── 180°                    │ y=440-465
  │         滑块手柄                                    │
  └─────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：单一状态变量 currentLongitude（0-180），互补经度 = 180 - currentLongitude
  2. 坐标计算：经线在侧视图中的 x 偏移 = centerX + radius * sin(经度角度)，考虑透视效果
  3. 事件绑定：滑块的 mousedown/touchstart 启动拖动，mousemove/touchmove 更新位置，mouseup/touchend 结束
  4. 实时更新：拖动时同步更新经线位置、经度数值标签、东西经标识
  5. 边界限制：滑块手柄限制在轨道范围内（200-600px）
- ID 命名规范：所有交互元素 ID 必须以 scene3- 为前缀
  - scene3-earth-circle, scene3-meridian-current, scene3-meridian-complement
  - scene3-circle-indicator, scene3-label-current, scene3-label-complement
  - scene3-slider-track, scene3-slider-handle, scene3-slider-value
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
