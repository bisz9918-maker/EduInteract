[图示主题与整合说明]
- 本图示主题：半球划分与特殊区域辨析
- 整合的步骤/概念：南北半球划分（赤道为界）、东西半球划分（20°W和160°E为界）、图中区域半球归属判断、西半球且东经度的特殊重叠区域
- 教学价值：教师可通过分步展示，先让学生理解南北半球以赤道为界，再理解东西半球以20°W-160°E为界（而非0°-180°），最后辨析特殊区域（160°E向东至180°既属于西半球又属于东经度），帮助学生突破半球划分的认知难点

[分步序列]
- 初始状态（步骤0）：显示原始经纬网（5经3纬）、四个点D/E/F/A及其标签、经纬度数值标签。无填充色，无分界线高亮。
- 步骤1（南北半球划分）：在y=420处绘制赤道示意虚线（#888888），在y=80至y=230区域填充北半球标识色（#1565c0透明度15%），显示"北半球"标签于(400,100)。说明：赤道（0°纬线）是南北半球分界线，图中区域全部位于北半球。
- 步骤2（东西半球划分）：在x=50处绘制20°W虚线（图外左侧），在x=250处高亮160°E经线为虚线（#888888 2px），显示"东半球"标签于(200,360)、"西半球"标签于(500,360)。说明：20°W向东至160°E为东半球，160°E向东至20°W为西半球。
- 步骤3（图中区域归属）：保持步骤2的分界线，用文字标注说明图中140°E至180°属于东半球，180°至140°W属于西半球。在(400,200)显示"图中大部分位于东半球"。
- 步骤4（特殊区域高亮）：在x=250至x=350、y=80至y=230区域（即160°E至180°范围）填充特殊区域色（#c62828透明度30%），显示"西半球且东经度"标签于(300,150)。说明：160°E向东至180°既属于西半球（因在160°E以东），又属于东经度（因在0°至180°E范围内）。
- 结论：底部显示正确答案"C、160°E向东至180°"，高亮选项C。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于SVG底部左侧(120,460)，宽80px高30px，点击回退到前一状态
  - 「下一步」按钮：位于SVG底部右侧(600,460)，宽80px高30px，点击进入下一状态
  - 步骤指示器：位于底部中央(380,460)，显示"步骤X/5"
- 教师操作流程：
  1. 初始展示原始经纬网，让学生观察图中点的位置
  2. 点击「下一步」展示赤道和北半球填充，讲解南北半球划分
  3. 点击「下一步」展示东西半球分界线，讲解20°W-160°E划分规则
  4. 点击「下一步」分析图中区域归属，回答第(4)问
  5. 点击「下一步」高亮特殊区域，讲解西半球且东经度的重叠概念，回答第(5)问
  6. 可随时点击「上一步」回退复习

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：几何图形简单，无需复杂库；SVG便于精确控制坐标和样式；原生JS足够实现分步状态切换
- 画布尺寸：800×500px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  经纬网主图区 (100,80)-(700,380)  600×300        |
  |  包含：5条经线、3条纬线、4个点及其标签           |
  |                                                  |
  |  经度标签区 (底部y=400)：140°E  180°  140°W      |
  |  纬度标签区 (右侧x=720)：60°N  40°N              |
  |                                                  |
  |  半球标签区 (动态显示)                           |
  +--------------------------------------------------+
  |  控件栏 (y=450-490)                              |
  |  [◀上一步]        步骤X/5        [下一步▶]       |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量currentStep(0-5)跟踪当前步骤，steps数组存储每步的显示配置
  2. 坐标计算：经线按等间距分布（x=150/250/350/450/550），纬线按等间距分布（y=130/230/330）
  3. 动画曲线：填充色用CSS transition实现淡入效果（opacity 0→1，0.3s ease）
  4. 事件绑定：按钮点击事件调用updateStep()函数，根据currentStep显示/隐藏对应元素
  5. 元素ID规范：所有元素ID以scene4-为前缀，如scene4-grid、scene4-point-d、scene4-label-north等
  6. IIFE隔离：所有JS代码包在(function() { ... })()中，避免全局变量污染
- 颜色规格严格遵循：
  - 背景：#ffffff
  - 经纬网格线：#000000实线1.5px
  - 北半球填充：#1565c0透明度15%
  - 东半球填充：#2e7d32透明度15%（本场景未使用，保留规格）
  - 西半球且东经度区：#c62828透明度30%
  - 分界线：#888888虚线2px
