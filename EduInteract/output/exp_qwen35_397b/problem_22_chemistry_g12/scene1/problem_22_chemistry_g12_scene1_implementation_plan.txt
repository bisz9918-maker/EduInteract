[分步序列]
- 初始状态（步骤 0）：仅显示烧杯轮廓（空烧杯），无溶液、无电极、无端子
- 步骤 1：点击「下一步」→ 显示溶液区域（#bbdefb 半透明填充）+ Cu²⁺离子（6 个蓝色小球）+ SO₄²⁻离子（6 个黄色小球）+ 离子标签"Cu²⁺"和"SO₄²⁻"
- 步骤 2：点击「下一步」→ 显示铜电极（左侧橙红色矩形）+ 铁电极（右侧银灰色矩形）+ 电极标签"Cu"和"Fe"
- 步骤 3：点击「下一步」→ 显示端子 a 和 b（空心圆圈）+ 端子标签"a"和"b" + 导线（连接电极与端子）
- 最终状态：展示完整电化学装置，所有元素可见

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 (280,450)，宽 100px，高 35px，浅灰色背景 #e0e0e0，黑色文字
  - 「下一步」按钮：位于 (420,450)，宽 100px，高 35px，蓝色背景 #1976d2，白色文字
  - 步骤指示器：位于中间 (390,455)，显示"步骤 X/3"
- 教师操作流程：
  1. 初始加载显示空烧杯，教师介绍实验容器
  2. 点击「下一步」显示溶液和离子，讲解电解质组成
  3. 点击「下一步」显示电极，讲解电极材料选择
  4. 点击「下一步」显示端子和导线，讲解电路连接方式
  5. 可随时点击「上一步」回退复习特定部分

[技术实现]
- JS 库选择：原生 SVG（简单几何图形首选，无需额外库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                    a       b                     |
  |                    ○       ○                     |
  |                    |       |                     |
  |              +-----+-------+-----+               |
  |              | Cu |         | Fe |               |
  |              |    |  Cu²⁺   |    |               |
  |  烧杯        |    |  SO₄²⁻  |    |               |
  |  +--------+  |    |         |    |  +--------+   |
  |  |        |  |    |         |    |  |        |   |
  |  | 溶液   |  +----+---------+----+  |        |   |
  |  |        |                         |        |   |
  |  +--------+                         +--------+   |
  |                                                  |
  |                                                  |
  |              [◀上一步] 步骤 3/3 [下一步▶]        |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-3），每个状态对应显示的元素组
  2. 元素分组：将元素按步骤分组（step0Elements, step1Elements, step2Elements, step3Elements），初始隐藏 step1-3
  3. 动画效果：元素出现使用淡入动画（opacity 0→1，duration 300ms）
  4. 事件绑定：按钮点击事件切换状态，更新显示元素和步骤指示器
  5. 边界处理：步骤 0 时禁用「上一步」，步骤 3 时禁用「下一步」
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀
  - scene1-beaker（烧杯）
  - scene1-solution（溶液）
  - scene1-cu-electrode（铜电极）
  - scene1-fe-electrode（铁电极）
  - scene1-cu-ions（Cu²⁺离子组）
  - scene1-so4-ions（SO₄²⁻离子组）
  - scene1-terminal-a（端子 a）
  - scene1-terminal-b（端子 b）
  - scene1-wire-a（导线 a）
  - scene1-wire-b（导线 b）
  - scene1-btn-prev（上一步按钮）
  - scene1-btn-next（下一步按钮）
  - scene1-step-indicator（步骤指示器）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
