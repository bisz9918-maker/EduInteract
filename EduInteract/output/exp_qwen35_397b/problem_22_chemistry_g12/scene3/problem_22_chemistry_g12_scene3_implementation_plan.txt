[图示主题与整合说明]
- 本图示主题：电解池两种连接方式对比
- 整合内容：整合两种电解池连接方式的电极极性、离子移动、电极反应、现象对比
- 教学价值：教师可通过切换不同连接方式，直观展示外接电源极性如何影响电极反应，帮助学生理解电解池工作原理，对比阳极/阴极在不同连接下的变化

[分步序列]
状态 0（基础装置）：
- 显示烧杯、溶液（浅蓝色）、铜电极（左）、铁电极（右）
- 显示端子 a（连 Cu）、端子 b（连 Fe）
- 显示溶液中的 Cu²⁺、SO₄²⁻ 离子符号
- 不显示电源、不显示箭头、不显示反应式

状态 1（b 接正极、a 接负极 → Fe 为阳极，Cu 为阴极）：
- 在装置上方显示直流电源符号
- 电源正极（长线，红色）连接端子 b（Fe 电极）
- 电源负极（短线，蓝色）连接端子 a（Cu 电极）
- Fe 电极上方显示「阳极」标签（红色 #c62828）
- Cu 电极上方显示「阴极」标签（绿色 #2e7d32）
- 电子流向箭头：从电源负极→a→Cu 电极，从 Fe 电极→b→电源正极
- SO₄²⁻移动箭头：在溶液中指向 Fe 电极（阳极）
- Cu²⁺移动箭头：在溶液中指向 Cu 电极（阴极）
- Fe 电极旁显示反应式：Fe - 2e⁻ = Fe²⁺（铁溶解）
- Cu 电极旁显示反应式：Cu²⁺ + 2e⁻ = Cu（铜析出）
- Fe 电极底部显示溶解效果（电极变细）
- Cu 电极底部显示析出效果（金属沉积）

状态 2（a 接正极、b 接负极 → Cu 为阳极，Fe 为阴极）：
- 电源符号反转：正极连接端子 a（Cu 电极），负极连接端子 b（Fe 电极）
- Cu 电极上方显示「阳极」标签（红色 #c62828）
- Fe 电极上方显示「阴极」标签（绿色 #2e7d32）
- 电子流向箭头：从电源负极→b→Fe 电极，从 Cu 电极→a→电源正极
- SO₄²⁻移动箭头：在溶液中指向 Cu 电极（阳极）
- Cu²⁺移动箭头：在溶液中指向 Fe 电极（阴极）
- Cu 电极旁显示反应式：Cu - 2e⁻ = Cu²⁺（铜溶解）
- Fe 电极旁显示反应式：Cu²⁺ + 2e⁻ = Cu（铜析出）
- Cu 电极底部显示溶解效果（电极变细）
- Fe 电极底部显示析出效果（金属沉积）

状态 3（对比表格总结）：
- 隐藏电源符号和箭头
- 显示对比表格（500×260px，居中）
- 表格内容：
  | 连接方式 | 阳极 | 阴极 | 阳极反应 | 阴极反应 | 现象 |
  |----------|------|------|----------|----------|------|
  | b 正 a 负 | Fe | Cu | Fe-2e⁻=Fe²⁺ | Cu²⁺+2e⁻=Cu | Fe 溶解，Cu 析出 |
  | a 正 b 负 | Cu | Fe | Cu-2e⁻=Cu²⁺ | Cu²⁺+2e⁻=Cu | Cu 溶解，Fe 上析出 Cu |

- 标签"阴极"状态 2：坐标(535,100)，Fe 电极上方

- 反应式"Cu²⁺+2e⁻=Cu"状态 2：坐标(580,320)，Fe 电极右侧下方

冲突检查：
- "a"与"阳极/阴极"：垂直距离 25px，无冲突
- "b"与"阳极/阴极"：垂直距离 25px，无冲突
- 左右反应式分别位于电极外侧，水平距离电极边缘约 20px，无冲突
- 状态 1 和状态 2 的反应式位置错开（y=200 vs y=320），避免重叠
- 离子移动箭头在溶液内部，不与电极标签重叠

[交互方案]
- 交互类型：多状态切换（4 个状态按钮）
- 控件说明：
  - 按钮 1「基础装置」：显示状态 0，仅基础电解池装置
  - 按钮 2「b 正 a 负」：显示状态 1，Fe 为阳极的连接方式
  - 按钮 3「a 正 b 负」：显示状态 2，Cu 为阳极的连接方式
  - 按钮 4「对比总结」：显示状态 3，对比表格
- 教师操作流程：
  1. 点击「基础装置」介绍电解池基本结构
  2. 点击「b 正 a 负」讲解 Fe 作阳极时的反应
  3. 点击「a 正 b 负」对比 Cu 作阳极时的反应
  4. 点击「对比总结」归纳两种连接方式的差异

[技术实现]
- JS 库选择：原生 SVG（适合绘制电化学装置图，元素清晰，易于控制状态切换）
- 画布尺寸：800×500px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                    电源符号                       |
  |         a  ○                    ○  b             |
  |         |                        |               |
  |      +-----+                  +-----+            |
  |      | Cu  |                  | Fe  |            |
  |      |     |    溶液区         |     |            |
  |      |     |  [Cu²⁺ SO₄²⁻]    |     |            |
  |      |     |                  |     |            |
  |      +-----+                  +-----+            |
  |                                                  |
  |   [反应式]                    [反应式]           |
  |                                                  |
  +--------------------------------------------------+
  | [基础装置] [b 正 a 负] [a 正 b 负] [对比总结]     |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-3），每个状态对应一组显示/隐藏的元素
  2. 所有元素按状态分组，使用 display:none 或 opacity:0 控制显示
  3. 电极反应式使用 text 元素，数学公式可用<tspan>或简单文本表示
  4. 离子移动箭头使用 path+marker 实现箭头效果
  5. 溶解/析出效果使用渐变填充或动态 path 变化
  6. 按钮点击事件绑定，切换状态时更新所有相关元素
- ID 命名规范：所有元素 ID 以 scene3- 为前缀
  - scene3-beaker, scene3-solution, scene3-electrode-cu, scene3-electrode-fe
  - scene3-terminal-a, scene3-terminal-b
  - scene3-power-source, scene3-label-anode, scene3-label-cathode
  - scene3-arrow-electron, scene3-arrow-so4, scene3-arrow-cu2
  - scene3-reaction-fe, scene3-reaction-cu
  - scene3-btn-state0, scene3-btn-state1, scene3-btn-state2, scene3-btn-state3
  - scene3-table-compare
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
