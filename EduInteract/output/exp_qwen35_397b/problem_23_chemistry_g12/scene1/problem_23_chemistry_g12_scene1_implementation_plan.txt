[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 (580,460)，点击后返回上一状态（步骤 0 时禁用）
  - 「下一步」按钮：位于 (700,460)，点击后进入下一状态（步骤 3 时禁用/变为「重播」）
- 教师操作流程：
  1. 初始展示 H₂O₂空间结构，让学生观察分子构型
  2. 点击「下一步」，高亮化学键类型，讲解极性键与非极性键的区别
  3. 点击「下一步」，显示电荷中心，引导学生理解电荷分布
  4. 点击「下一步」，展示最终结论，总结 H₂O₂为极性分子的判断依据
  5. 可随时点击「上一步」回退，复习关键概念

[技术实现]
- JS 库选择：原生 SVG（简单几何图形首选，无需额外库）
- 画布尺寸：800×500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |   [H₂O₂二面角结构]          [分析文字框]         |
  |   左侧 400px                 右侧 260px          |
  |   (原子 + 化学键 + 平面)      (分步显示要点)      |
  |                                                  |
  |                              [正电荷中心]        |
  |                                                  |
  |   [负电荷中心]                                   |
  |                                                  |
  |                              [◀上一步][下一步▶]  |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-3），steps 数组存储每步的配置对象
  2. 坐标计算：所有元素坐标硬编码，确保与布局表一致
  3. 动画曲线：使用 CSS transition（ease-out，300ms）实现平滑过渡
  4. 事件绑定：按钮点击事件绑定到 updateStep() 函数，更新 DOM 元素显示状态
  5. 元素显隐：通过 display/opacity 控制，高亮通过 stroke-width/class 切换
- ID 命名规范：所有元素 ID 以 scene1- 为前缀
  - scene1-plane1, scene1-plane2（两个平面）
  - scene1-o1, scene1-o2（O 原子）
  - scene1-h1, scene1-h2（H 原子）
  - scene1-bond-oo（O-O 键）
  - scene1-bond-oh1, scene1-bond-oh2（O-H 键）
  - scene1-angle-arc（二面角弧线）
  - scene1-charge-plus, scene1-charge-minus（电荷中心）
  - scene1-label-polar, scene1-label-nonpolar（键类型标签）
  - scene1-analysis-box（分析文字框）
  - scene1-btn-prev, scene1-btn-next（导航按钮）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
- 多场景合并兼容：使用 getElementById('scene1-xxx') 精确选择，不使用全局 class 选择器
