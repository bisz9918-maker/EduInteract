[图示主题与整合说明]
- 本图示主题：甲丙等效平衡关系
- 整合内容：甲从 NO₂ 开始、丙从 N₂O₄ 开始，两者在恒容条件下达到同一平衡状态的动态过程
- 教学价值：教师可通过分步演示展示等效平衡的建立过程，帮助学生理解"从不同方向出发可达到同一平衡状态"的核心概念。步骤 0-2 展示反应进行方向，步骤 3 展示平衡时浓度相等，步骤 4 总结等效平衡结论。

[分步序列]
- 初始状态（步骤 0）：显示甲、丙两容器框架，甲容器上方标注"0.2 mol NO₂"，丙容器上方标注"0.1 mol N₂O₄"，容器标签"甲""丙"，等效箭头和"等效平衡"标识淡显示
- 步骤 1：点击「下一步」→ 甲容器内出现红色 NO₂ 分子圆点 (180,180)，随后出现蓝色 N₂O₄ 分子圆点 (220,220)，甲容器内显示反应箭头 (150,250)-(250,250) 指向右，表示 2NO₂ → N₂O₄
- 步骤 2：点击「下一步」→ 丙容器内出现蓝色 N₂O₄ 分子圆点 (580,180)，随后出现红色 NO₂ 分子圆点 (620,220)，丙容器内显示反应箭头 (550,250)-(650,250) 指向左，表示 N₂O₄ → 2NO₂
- 步骤 3：点击「下一步」→ 两容器内分子数量达到平衡比例（甲：约 60% NO₂ + 40% N₂O₄，丙：相同比例），容器下方出现"c(NO₂) 甲"和"c(NO₂) 丙"标注，中间显示绿色等号"="
- 步骤 4：点击「下一步」→ 底部显示结论文本"甲 = 丙 等效平衡"，等效箭头加粗高亮，两容器边框同时闪烁绿色表示等效

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮：位于 (280,460)，宽 100px，点击返回上一状态
  - 下一步按钮：位于 (420,460)，宽 100px，点击进入下一状态
  - 步骤指示器：位于 (380,440)，显示"步骤 X/4"
- 教师操作流程：
  1. 初始状态展示甲丙两容器及初始物质
  2. 点击下一步展示甲中反应方向（NO₂ 转化为 N₂O₄）
  3. 点击下一步展示丙中反应方向（N₂O₄ 转化为 NO₂）
  4. 点击下一步展示平衡时浓度相等
  5. 点击下一步展示等效平衡结论
  6. 可随时点击上一步回退复习

[技术实现]
- JS 库选择：原生 SVG（简单几何图形和动画足够，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  [0.2mol NO₂]              [0.1mol N₂O₄]         |
  |     +--------+    等效    +--------+             |
  |     |  甲    |  ←------→  |  丙    |             |
  |     | 容器   |   平衡     | 容器   |             |
  |     +--------+            +--------+             |
  |       甲                      丙                 |
  |                                                  |
  |   c(NO₂)甲    =    c(NO₂)丙                      |
  |                                                  |
  |         甲 = 丙 等效平衡                         |
  |                                                  |
  |         [◀上一步]  步骤 X/4  [下一步▶]           |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量 (0-4)，steps 数组存储每步的可见元素 ID 列表
  2. 坐标计算：所有元素使用绝对坐标，分子位置相对于容器中心偏移
  3. 动画曲线：使用 CSS transition 实现淡入淡出 (opacity 0→1, 300ms ease)
  4. 事件绑定：按钮点击事件切换状态，更新可见元素
  5. 步骤指示器：每步更新显示当前步骤编号
- ID 命名规范：所有元素 ID 以 scene2- 为前缀
  - scene2-container-jia, scene2-container-bing
  - scene2-label-jia, scene2-label-bing
  - scene2-initial-jia, scene2-initial-bing
  - scene2-equiv-arrow, scene2-equiv-label
  - scene2-mol-jia-no2, scene2-mol-jia-n2o4
  - scene2-mol-bing-no2, scene2-mol-bing-n2o4
  - scene2-arrow-jia, scene2-arrow-bing
  - scene2-conc-jia, scene2-conc-bing, scene2-eq-sign
  - scene2-conclusion
  - scene2-btn-prev, scene2-btn-next, scene2-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
