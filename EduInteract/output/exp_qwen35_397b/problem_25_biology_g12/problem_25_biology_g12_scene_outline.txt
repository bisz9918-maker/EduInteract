    果蝇体表硬而长的毛称为刚毛，一个自然繁殖的直刚毛果蝇种群中，偶然出现了一只卷刚毛雄果蝇。请回答下问题（等位基因分别用 A 和 a 表示）：

    ②若已知这只卷刚毛雄果蝇与直刚毛雌果蝇杂交，F₁全部是直刚毛，F₁雌、雄果蝇随机交配，F₂的表现型及比例是直刚毛雌果蝇:直刚毛雄果蝇:卷刚毛雄果蝇=2:1:1，此时最合理的假说是？

    ③为验证②中的假说，某同学设计了如图所示的测交实验。该实验及现象是否能够验证第②小题中提出的假说？请说明理由。

    ④若为你提供以下纯合的果蝇作为材料：直刚毛雌果蝇、直刚毛雄果蝇、卷刚毛雌果蝇、卷刚毛雄果蝇，请你也来设计一个测交实验，以验证第②小题中提出的假说（不需要写结果）。

    **题目分析：**

    本题是典型的伴性遗传分析题，核心考点包括：
    1. 基因突变类型的假说提出（显性/隐性突变、常染色体/X 染色体）
    2. 根据杂交结果推断遗传方式
    3. 测交实验的设计与评价

    从 F₂表现型比例 2:1:1 且卷刚毛只出现在雄果蝇中，可推断这是 X 染色体隐性遗传。

    **整体讲解思路：**

    1. 先分析卷刚毛性状的可能遗传方式（多种假说）
    2. 根据杂交实验结果排除不合理假说
    3. 评价题目给出的测交实验
    4. 设计正确的测交实验方案

    **教学说明：**

    本图示用于讲解第①问，帮助学生理解遗传假说的多样性。

    **讲解要点：**

    1. 首先明确题目条件：基因不在性染色体同源区段，即只可能在 X 染色体非同源区段或常染色体上

    2. 引导学生思考突变类型：
       - 显性突变：a→A（隐性基因突变为显性）
       - 隐性突变：A→a（显性基因突变为隐性）

    3. 组合后共有四种可能假说：
       - 假说 1：X 染色体显性突变（题目已给出）
       - 假说 2：X 染色体隐性突变
       - 假说 3：常染色体显性突变
       - 假说 4：常染色体隐性突变

    **关键公式：**

    亲代直刚毛种群基因型（假设直刚毛为野生型）：
    - 若为显性性状：AA 或 X^AX^A
    - 若为隐性性状：aa 或 X^aX^a

    突变个体（卷刚毛雄果蝇）基因型：
    - X 染色体显性突变：X^AY
    - X 染色体隐性突变：X^aY
    - 常染色体显性突变：Aa
    - 常染色体隐性突变：aa

    **教学说明：**

    本图示用于讲解第②问，通过可视化遗传过程帮助学生理解为何 F₂比例为 2:1:1 且卷刚毛只出现在雄性。

    **讲解要点：**

    1. 根据 F₁全部是直刚毛，推断直刚毛为显性性状

    2. 根据 F₂中卷刚毛只出现在雄果蝇，推断基因位于 X 染色体上（伴性遗传特征）

    3. 完整推导过程：

    **亲本杂交：**
    - 直刚毛雌果蝇：X^AX^A（纯合显性）
    - 卷刚毛雄果蝇：X^aY（隐性）

    **F₁代：**
    - 雌性：X^AX^a（直刚毛）
    - 雄性：X^AY（直刚毛）

    **F₁随机交配：**
    - 雌配子：X^A : X^a = 1:1
    - 雄配子：X^A : Y = 1:1

    **F₂代：**
    | | X^A | Y |
    |---|---|---|
    | X^A | X^AX^A(直♀) | X^AY(直♂) |
    | X^a | X^AX^a(直♀) | X^aY(卷♂) |

    **表现型比例：** 直刚毛♀:直刚毛♂:卷刚毛♂ = 2:1:1

    **最合理假说：** 卷刚毛是 X 染色体上的隐性突变（A→a）

    **教学说明：**

    本图示用于讲解第③④问，帮助学生理解测交实验的设计原则和评价标准。

    **第③问讲解要点：**

    题目中的测交实验：F₁直刚毛♀(X^AX^a) × 卷刚毛♂(X^aY)

    预期后代：X^AX^a(直♀) : X^aY(卷♂) : X^aX^a(卷♀) : X^AY(直♂) = 1:1:1:1

    **问题：** 该实验无法区分以下两种假说：
    - X 染色体隐性遗传：后代雌雄中直:卷均为 1:1
    - 常染色体隐性遗传：Aa × aa → 后代直:卷 = 1:1（与性别无关）

    因此**不能充分验证**第②问的假说。

    **第④问正确方案：**

    **测交组合：** 卷刚毛雌果蝇 (X^aX^a) × 直刚毛雄果蝇 (X^AY)

    **预期结果（若为 X 染色体隐性遗传）：**
    - 雌性后代：全部为 X^AX^a（直刚毛）
    - 雄性后代：全部为 X^aY（卷刚毛）
    - 即：雌性全直，雄性全卷，与性别完全关联

    **关键区别：** 若为常染色体遗传，后代直:卷 = 1:1 且与性别无关；若为 X 染色体遗传，后代性状与性别完全关联。

    **课堂讲解建议：**

    强调测交实验设计的核心原则——选择能够产生**差异化预期结果**的亲本组合，使不同假说对应不同的可观察现象。
    </TEXT_4>
