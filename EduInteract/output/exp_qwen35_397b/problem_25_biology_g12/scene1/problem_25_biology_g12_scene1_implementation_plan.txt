[图示主题与整合说明]
- 本图示主题：卷刚毛性状遗传的多种假说对比
- 整合的步骤/概念：整合了 X 染色体显性突变、X 染色体隐性突变、常染色体显性突变、常染色体隐性突变四种假说的基因位置与突变方向示意

[分步序列]
本场景采用多状态切换交互，共 4 个状态（对应 4 种假说）：

状态 0（初始/默认）：显示 X 染色体隐性突变假说（与题目图片一致）
- 染色体组：X 染色体上 a 基因位置标记（y=260 处黑点）
- 突变箭头：从 A→a（蓝色，表示显性→隐性突变）
- 基因型标注：亲代 X^A X^a × X^a Y，子代比例 1:1:1:1

状态 1（点击按钮 1）：X 染色体显性突变假说
- 染色体组：X 染色体上 A 基因位置标记（y=260 处黑点）
- 突变箭头：从 a→A（红色，表示隐性→显性突变）
- 基因型标注：亲代 X^a X^a × X^A Y，子代雌性全为卷刚毛，雄性全为直刚毛

状态 2（点击按钮 2）：X 染色体隐性突变假说
- 染色体组：X 染色体上 a 基因位置标记（y=260 处黑点）
- 突变箭头：从 A→a（蓝色，表示显性→隐性突变）
- 基因型标注：亲代 X^A X^a × X^a Y，子代比例 1:1:1:1

状态 3（点击按钮 3）：常染色体显性突变假说
- 染色体组：常染色体Ⅰ上 A 基因位置标记（第一对染色体上黑点）
- 突变箭头：从 a→A（红色，表示隐性→显性突变）
- 基因型标注：亲代 aa × Aa，子代比例 1:1（与性别无关）

状态 4（点击按钮 4）：常染色体隐性突变假说
- 染色体组：常染色体Ⅰ上 a 基因位置标记（第一对染色体上黑点）
- 突变箭头：从 A→a（蓝色，表示显性→隐性突变）
- 基因型标注：亲代 Aa × aa，子代比例 1:1（与性别无关）

[交互方案]
- 交互类型：多状态切换（4 个按钮）
- 控件说明：
  - 按钮 1 (scene1-btn-hypo1)：「X 染色体显性突变」- 位于 (100,450)
  - 按钮 2 (scene1-btn-hypo2)：「X 染色体隐性突变」- 位于 (260,450)
  - 按钮 3 (scene1-btn-hypo3)：「常染色体显性突变」- 位于 (420,450)
  - 按钮 4 (scene1-btn-hypo4)：「常染色体隐性突变」- 位于 (580,450)
- 教师操作流程：
  1. 初始状态展示 X 染色体隐性突变（与题目一致）
  2. 依次点击 4 个按钮，对比不同假说下基因位置和遗传结果
  3. 引导学生观察伴性遗传与常染色体遗传的子代比例差异
  4. 重点对比为何题目中 F2 表现型与性别相关，支持伴性遗传假说

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +------------------------------------------+
  |  [染色体组]          [基因型标注框]      |
  |  常Ⅰ  常Ⅱ  常Ⅲ       假说标题            |
  |     X    Y            亲代基因型         |
  |                       子代表现型         |
  |                                          |
  |                                          |
  |  [按钮 1][按钮 2][按钮 3][按钮 4]         |
  +------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用 currentState 变量 (0-3) 跟踪当前假说状态
  2. 坐标计算：染色体位置固定，基因标记点位置随状态变化
  3. 事件绑定：4 个按钮分别绑定 click 事件，调用 updateState() 函数
  4. 动画过渡：基因标记点和箭头使用 CSS transition 实现平滑切换
  5. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-chromo-x、scene1-gene-marker、scene1-btn-hypo1）
  6. IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
  7. 高亮状态：当前选中按钮添加 active 类（背景色加深）
- 数据结构：用对象数组存储 4 种假说的配置（基因位置、箭头方向、基因型文本）
