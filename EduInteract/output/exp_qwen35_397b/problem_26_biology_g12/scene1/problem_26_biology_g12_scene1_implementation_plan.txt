- 教师操作流程：

  2. 点击「下一步」展示 F₁，引导学生观察 F₁全为长翅的现象
  3. 点击「下一步」展示配子，解释 F₁产生配子的类型（自由组合）
  4. 点击「下一步」展示 F₂棋盘格，推导基因型组合
  5. 点击「下一步」展示表型比例，归纳 9:3:4 的规律并解释原因（X 染色体连锁导致小翅只在♂中出现）

[技术实现]
- JS 库选择：原生 SVG（几何图形和文本标注简单清晰，无需复杂库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────┐
  │ P 代: [残翅♀] × [小翅♂]        y=40-140            │
  │            ↓                                        │
  │ F₁代: [长翅♀] [长翅♂]        y=195-280             │
  │            ↓                                        │
  │ F₁配子: AX^B AX^b aX^B aX^b | AX^B AY aX^B aY  y=325-360│
  │            ↓                                        │
  │ F₂代: [棋盘格]  长:小:残=9:3:4  y=375-470           │
  ├─────────────────────────────────────────────────────┤
  │ [◀ 上一步]  步骤 X/5  [下一步 ▶]  y=440-490         │
  └─────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用 currentState 变量（0-4）跟踪当前步骤，steps 数组存储每步显示的元素 ID 列表
  2. 元素显隐：每步调用 updateDisplay()，遍历所有元素根据 steps[currentState] 设置 display 属性
  3. 按钮边界：第一步禁用「上一步」，最后一步禁用「下一步」
  4. 动画效果：元素出现使用 opacity 过渡（0.3s ease-in）
  5. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-p-female、scene1-f1-male、scene1-gamete-axb 等）
  6. IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
  7. MathJax 支持：基因型中的上标（X^B、X^b）用<tspan dy="-5" font-size="12">实现
