  4. 理解染色体结构变异（易位）
  5. 分析细胞分裂图像

教学说明：

本图示用于引导学生分析遗传系谱图，判断两种遗传病的遗传方式。

甲病遗传方式判断：

  1. 观察Ⅰ1（正常）×Ⅰ2（正常）→Ⅱ3（患甲病），符合"无中生有"，判断为隐性遗传
  2. 若为伴X隐性，则Ⅱ3的致病基因来自母亲Ⅰ1，但Ⅱ6也携带甲病基因（题干已知），说明甲病基因可在男性携带，排除伴X隐性
  3. 结论：甲病为常染色体隐性遗传（A-正常，a-患病）

乙病遗传方式判断：

  1. 观察Ⅰ3（患乙病）×Ⅰ4（患乙病）→Ⅱ8（正常），符合"有中生无"，判断为显性遗传
  2. 但若为伴X显性，则Ⅰ3（男性患者）的女儿应全部患病，而Ⅱ5正常，矛盾
  3. 观察Ⅱ7（患乙病）×Ⅱ8（正常）→Ⅲ2（患乙病），若为伴X隐性则Ⅱ7应为纯合子，但其父Ⅰ3患病、母Ⅰ4患病，无法确定
  4. 综合排除：乙病可能为常染色体显性或常染色体隐性

引导学生观察要点：

  • 找"无中生有"或"有中生无"的关键婚配组合
  • 用排除法逐一验证四种遗传方式
  • 注意题干给出的特殊信息（Ⅱ6携带甲病基因、Ⅱ4为XX男性）

教学说明：

本图示用于展示遗传概率的计算过程，帮助学生理解从基因型到表现型概率的推导。

Ⅱ5×Ⅱ6再生正常男孩概率计算：

已知条件：

  • 甲病：常染色体隐性（A正常，a患病）
  • Ⅱ5表现正常，但其母Ⅰ1可能携带，需推导基因型
  • Ⅱ6携带甲病基因，基因型为Aa
  • 乙病：根据前面分析，可能为常染色体显性或隐性

计算步骤：

  1. 甲病：Ⅱ5基因型为Aa（因其兄弟Ⅱ3患病aa，父母均为Aa），Ⅱ6为Aa
  2. 子代患甲病概率=1/4，正常概率=3/4
  3. 男孩概率=1/2
  4. 正常男孩概率=3/4×1/2=3/8

Ⅲ2×Ⅲ3生正常孩子概率：

  1. 若Ⅰ3、Ⅱ7均无甲病基因，则甲病基因传递路径需重新分析
  2. Ⅲ2患乙病，基因型需根据乙病遗传方式确定
  3. Ⅲ3患乙病，同理分析
  4. 综合两病计算正常孩子概率

关键公式：

  • 独立事件概率：P(A且B)=P(A)×P(B)
  • 正常孩子=不患甲病且不患乙病

教学说明：

本图示用于解释染色体结构变异中的易位现象，帮助学生理解Ⅱ4为何是XX男性。

染色体变异类型：

  • Ⅱ4个体的变异属于染色体结构变异（易位）
  • 具体为：Y染色体上含SRY基因（决定睾丸发育）的片段移接到常染色体或X染色体上

红绿色盲概率分析：

  1. 红绿色盲为伴X隐性遗传（设基因为X^b）
  2. Ⅰ1为携带者：X^B X^b
  3. Ⅰ2正常：X^B Y
  4. Ⅱ4为XX男性，两条X染色体分别来自Ⅰ1和Ⅰ2
  5. 来自Ⅰ1的X可能是X^B或X^b（各1/2概率）
  6. 来自Ⅰ2的X必为X^B
  7. Ⅱ4基因型为X^B X^B或X^B X^b，均不患红绿色盲（需要两条X都含b才患病，但Ⅱ4是男性，只有一条X表达）
  8. 实际上，XX男性中只有一条X染色体失活，若含SRY的易位染色体不影响X失活，则Ⅱ4患红绿色盲的概率为0

正确答案：

  • 变异类型：染色体结构变异（易位）
  • Ⅱ4患红绿色盲概率：0

教学说明：

本图示用于分析图2所示的细胞分裂图像，判断分裂时期和个体基因型。

细胞分裂时期判断：

  1. 观察染色体数目：4条染色体
  2. 观察染色体形态：每条染色体含2条姐妹染色单体

  4. 观察同源染色体：存在同源染色体（大小形态相似的染色体成对存在）
  5. 结论：有丝分裂中期（减数第一次分裂中期同源染色体应成对排列在赤道板两侧，减数第二次分裂中期无同源染色体）

个体基因型分析：

  1. 图中一条染色体上标注基因A，其同源染色体上标注基因a
  2. 说明该个体在該基因位点为杂合子
  3. 结论：该个体基因型为Aa

与系谱图的关联：

  • 图2为Ⅱ10的精原细胞
  • Ⅱ10患乙病，其基因型需结合乙病遗传方式分析
  • 若乙病为常染色体显性，则Ⅱ10基因型可能为Bb或BB
  • 图中显示的A/a基因对应甲病基因

完整解答总结：
(1) 乙病遗传方式：A、B（常染色体隐性或常染色体显性）
(2) Ⅱ5×Ⅱ6正常男孩概率：3/8；Ⅲ2×Ⅲ3正常孩子概率：需根据具体基因型计算
(3) 变异类型：染色体结构变异（易位）；红绿色盲概率：0
(4) 分裂时期：有丝分裂中期；基因型：Aa
(5) 跑步能力基因型：6种（RR、RE、EE、R、E、无）
(6) 受体细胞：肌肉细胞等体细胞；子女具有R基因概率：0（体细胞基因改变不遗传）
