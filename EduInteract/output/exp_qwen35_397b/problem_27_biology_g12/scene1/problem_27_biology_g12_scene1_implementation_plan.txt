[图示主题与整合说明]

[分步序列]
- 初始状态（步骤0）：显示完整系谱图（所有个体符号、连接线、图例），无高亮，结论区显示"请分析甲病和乙病的遗传方式"
- 步骤1：高亮框1显示（Ⅰ1×Ⅰ2→Ⅱ3区域，蓝色20%透明度），推导箭头1显示，结论区显示"Ⅰ1×Ⅰ2正常→Ⅱ3患甲病：无中生有为隐性，甲病为隐性遗传"
- 步骤2：高亮框2显示（Ⅱ5×Ⅱ6→Ⅲ2区域，蓝色20%透明度），推导箭头2显示，结论区显示"Ⅱ6携带甲病基因但正常，若为伴X隐性则Ⅱ6必患病，故甲病为常染色体隐性遗传"
- 步骤3：高亮框3显示（Ⅰ3×Ⅰ4→Ⅱ8区域，红色20%透明度），推导箭头3显示，结论区显示"Ⅰ3×Ⅰ4患乙病→Ⅱ8正常：有中生无为显性，排除隐性遗传；若为伴X显性，Ⅰ3患病则女儿必患病，但Ⅱ5正常，故排除伴X显性"
- 步骤4：高亮框4显示（Ⅱ7×Ⅱ8→Ⅲ3区域，红色20%透明度），结论区显示"乙病可能为常染色体显性或常染色体隐性遗传（需进一步信息确认）"

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮：位于(280,450)，80×30px，蓝色背景，白色文字"◀ 上一步"，步骤0时禁用
  - 下一步按钮：位于(440,450)，80×30px，蓝色背景，白色文字"下一步 ▶"，步骤4时禁用
  - 步骤指示器：位于两按钮之间(400,465)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始展示完整系谱图，让学生观察三代个体的患病情况
  2. 点击"下一步"，高亮Ⅰ1×Ⅰ2→Ⅱ3，引导学生发现"无中生有"现象，推导甲病为隐性
  3. 点击"下一步"，高亮Ⅱ5×Ⅱ6→Ⅲ2，结合已知Ⅱ6携带基因，排除伴X隐性，确认常染色体隐性
  4. 点击"下一步"，高亮Ⅰ3×Ⅰ4→Ⅱ8，分析乙病遗传方式，排除伴X显性
  5. 点击"下一步"，高亮Ⅱ7×Ⅱ8→Ⅲ3，得出乙病可能为常染色体显性或隐性的结论
  6. 可随时点击"上一步"回退复习关键推导步骤

[技术实现]
- JS 库选择：原生 SVG（系谱图为静态几何图形，无需复杂动画）
- 画布尺寸：800×500px
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |              遗传系谱图分析 (标题)                |
  +--------------------------------------------------+
  | Ⅰ |  ○   □        ■   ●                          |
  |   |  |   |        |   |                           |
  | Ⅱ |○ □ ■ □ ○ □ ● ○ ● ■ ○                         |
  |   |  |              |   |                         |
  | Ⅲ |  ○            ■   ●   ■   □                  |
  +--------------------------------------------------+
  |                    [图例区]                       |
  +--------------------------------------------------+
  |          结论文字显示区 (居中)                     |
  +--------------------------------------------------+
  |              [◀上一步]  [下一步▶]                 |
  |                    步骤 X/5                       |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：currentStep变量(0-4)，每步对应不同的显示元素组合
  2. 高亮框：使用<rect>元素，fill带透明度，初始display=none，对应步骤时display=block
  3. 推导箭头：使用<path>元素，带marker-end箭头，初始display=none
  4. 结论文字：使用<text>元素，每步更新textContent
  5. 按钮事件：点击时更新currentStep，调用updateDisplay()函数刷新所有元素状态
  6. 按钮禁用状态：步骤0时禁用上一步，步骤4时禁用下一步，使用opacity和pointer-events控制
- ID 命名规范：所有元素ID以scene1-为前缀，如scene1-individual-I1、scene1-highlight-box1、scene1-arrow1、scene1-btn-prev、scene1-btn-next、scene1-conclusion-text
- IIFE 隔离：所有JS代码包在(function() { ... })()中，避免全局变量污染
