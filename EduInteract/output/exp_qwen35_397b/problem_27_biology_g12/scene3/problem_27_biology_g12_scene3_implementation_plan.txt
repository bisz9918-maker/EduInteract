[图示主题与整合说明]
- 本图示主题：染色体结构变异——Y 染色体片段移接导致 XX 男性
- 整合的内容：正常 XY 男性染色体组成、Y 染色体 SRY 基因片段、染色体断裂过程、SRY 片段移接到常染色体的易位过程、异常 XX 男性染色体组成
- 教学价值：教师可通过拖拽滑块动态展示染色体易位的完整过程，帮助学生理解为何Ⅱ4 个体性染色体为 XX 却表现为男性（Y 染色体上的 SRY 基因片段移接到常染色体上）。滑块从 0% 到 100% 的连续变化直观呈现"正常→断裂→易位完成"三个阶段，配合标签说明，便于课堂讲解染色体结构变异的机制。

[分步序列]
本场景采用连续拖拽滑块交互，无固定步骤，但定义三个关键状态：

- 状态 0（滑块 0%）：正常 XY 男性
  - 显示：左侧区域完整显示 X 染色体 (蓝色) 和 Y 染色体 (红色)
  - Y 染色体上部显示绿色 SRY 基因片段
  - 中间和右侧区域半透明或隐藏
  - 状态说明文字："正常 XY 男性：X 染色体 + Y 染色体（Y 上含 SRY 基因）"
  - 滑块手柄位置：x=200

- 状态 1（滑块 50%）：染色体断裂
  - 左侧区域保持显示
  - 中间区域逐渐显现：X 染色体完整，Y 染色体仅显示下半段残段
  - SRY 基因片段从 Y 染色体分离，处于游离状态（绿色矩形）
  - 显示断裂点虚线和易位箭头
  - 状态说明文字："Y 染色体断裂：SRY 基因片段从 Y 染色体分离"
  - 滑块手柄位置：x=400

- 状态 2（滑块 100%）：易位完成
  - 左侧区域半透明
  - 中间区域显示 SRY 片段移接过程（箭头动画）
  - 右侧区域完整显示：两条 X 染色体 (蓝色) + 一条常染色体 (灰色)
  - SRY 基因片段 (绿色) 显示在常染色体上
  - 状态说明文字："易位完成：XX 染色体 + 含 SRY 的常染色体 → XX 男性 (Ⅱ4)"
  - 滑块手柄位置：x=600

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：
  - 滑块轨道：水平长条，位于 y=455~475，x=200~600
  - 滑块手柄：圆形，可沿轨道左右拖拽，限制在轨道范围内
  - 刻度标签：0%、50%、100% 分别标注在轨道下方
- 教师操作流程：
  1. 初始状态 (0%)：向学生展示正常 XY 男性的染色体组成，强调 Y 染色体上的 SRY 基因决定男性发育
  2. 拖拽至 50%：展示 Y 染色体断裂过程，SRY 片段分离，解释染色体结构变异的"断裂"阶段
  3. 拖拽至 100%：展示 SRY 片段移接到常染色体，形成 XX 但含 SRY 的异常男性，对应系谱图中的Ⅱ4 个体
  4. 可来回拖拽滑块，反复演示易位过程，强化学生对染色体易位机制的理解

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：染色体形状可用 SVG path 精确绘制，滑块交互用原生事件处理足够，无需额外库
- 画布尺寸：800×500px（固定）
- 布局草图：
  ```
  [800×500 画布]
  ┌─────────────────────────────────────────────────────────────┐
  │                    染色体易位导致 XX 男性                     │ y=40
  ├──────────────────┬──────────────────┬───────────────────────┤
  │   正常 XY 男性    │   易位过程动画    │    异常 XX 男性 (Ⅱ4)    │ y=75-320
  │   [X] [Y·SRY]    │   [X] [SRY→] [常] │   [X] [X] [常·SRY]    │
  │                  │                  │                       │
  │                  │  染色体结构变异·易位                       │ y=320
  │                  │                  │                       │
  │                  │    状态说明文字                           │ y=425
  ├─────────────────────────────────────────────────────────────┤
  │         0%  [━━━━━━━━●━━━━━━━━]  100%                       │ y=455-490
  │                    滑块控制区                                │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用 sliderValue (0-100) 作为唯一状态变量，根据值计算各元素透明度、位置
  2. 坐标计算：SRY 片段位置随滑块值线性插值，从 Y 染色体 (145,150) 移动到常染色体 (705,145)
  3. 透明度控制：左侧区域透明度 = 1 - sliderValue/100，右侧区域透明度 = sliderValue/100
  4. 事件绑定：slider 元素监听 input 事件，实时更新所有依赖元素
  5. 拖拽实现：mousedown/mousemove/mouseup 事件处理滑块手柄拖拽，限制在轨道范围内
- ID 命名规范：所有元素 ID 以 scene3- 为前缀
  - scene3-chrX-left, scene3-chrY-left, scene3-sry-left
  - scene3-chrX-mid, scene3-chrY-mid, scene3-sry-mid, scene3-chrAuto-mid
  - scene3-chrX1-right, scene3-chrX2-right, scene3-chrAuto-right, scene3-sry-right
  - scene3-slider-track, scene3-slider-handle, scene3-status-text
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
