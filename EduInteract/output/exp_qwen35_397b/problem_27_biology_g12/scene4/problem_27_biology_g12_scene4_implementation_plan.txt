- 步骤5：点击「下一步」→ 底部结论区显示"有丝分裂中期 基因型：Aa"，所有元素保持高亮状态

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 按钮"上一步"：位置(350,465)，宽80px，高30px，点击回退到前一状态
  - 按钮"下一步"：位置(450,465)，宽80px，高30px，点击进入下一状态
  - 状态指示器：位置(400,445)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始展示完整细胞图，让学生整体观察
  2. 点击"下一步"高亮染色体，引导学生计数
  3. 点击"下一步"强调赤道板位置，讲解中期特征
  4. 点击"下一步"展示姐妹染色单体，讲解染色体结构
  5. 点击"下一步"标注基因位置，分析等位基因
  6. 点击"下一步"显示结论，总结分裂时期和基因型

[技术实现]
- JS 库选择及原因：原生 SVG（简单几何图形，无需额外库，轻量且易于控制动画）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +------------------------------------------+
  |                                          |
  |     [着丝点]    [4条染色体]              |
  |          \       /                       |
  |    [染色体1-4排列在赤道板上]             |
  |          /       \                       |
  |     [姐妹染色单体]   [基因A/a]           |
  |                                          |
  |            [赤道板]                      |
  |                                          |
  |         有丝分裂中期 基因型：Aa          |
  |                                          |
  |      [◀上一步]  步骤X/5  [下一步▶]       |
  +------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentState(0-5) 跟踪当前步骤，数组 steps[] 存储每步的显示配置
  2. 染色体绘制：用 SVG path 绘制X形，每条染色体由两个交叉的椭圆或path组成
  3. 动画效果：使用 CSS transition 实现透明度变化和描边加粗，关键帧动画实现着丝点闪烁
  4. 事件绑定：按钮点击事件切换状态，更新所有元素的 class 或 style
  5. 引线绘制：用 SVG line 元素，从标签位置到目标元素边缘
- ID 命名规范：所有交互元素 ID 必须以 scene4- 为前缀（如 scene4-chromosome-1, scene4-centromere-2, scene4-gene-A）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
