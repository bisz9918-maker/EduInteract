[技术实现]
- JS 库选择：原生 SVG（几何形状和文本标注简单，无需额外库）
- 画布尺寸：800×500px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  | 标题：第 (6)(7) 问：基因自由组合分析              |
  +--------------------------------------------------+
  | [第 (6) 问：伴 X 遗传]                            |
  |  [白毛雄] → [黑毛雌] → [子代雌] [子代雄]          |
  |                              结论：伴 X 遗传      |
  +--------------------------------------------------+
  | ------------------- 分隔线 --------------------- |
  | [第 (7) 问：自由组合棋盘格]                       |
  |     AC   Ac   aC   ac  ← 配子（行）              |
  |  AC [  ][  ][  ][  ]                             |
  |  Ac [  ][  ][  ][  ]  ← 4×4 棋盘格               |
  |  aC [  ][  ][  ][  ]                             |
  |  ac [  ][  ][  ][  ]                             |
  |  ↑                                               |
  | 配子（列）                                        |
  +--------------------------------------------------+
  | 表型比例：直毛有毛:直毛无毛:卷毛有毛:卷毛无毛=9:3:3:1 |
  +--------------------------------------------------+
  |                    [上一步] [下一步]              |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentState 跟踪当前步骤（0-3），数组存储各步骤的显示配置
  2. 坐标计算：棋盘格单元格宽 140px、高 50px，配子标签偏移 25px
  3. 动画曲线：元素淡入用 CSS transition opacity 0.3s ease
  4. 事件绑定：按钮点击事件切换状态，更新各元素 display 属性
  5. 基因型着色：根据基因型中 A/a/C/c 的出现，动态设置文本 fill 属性
- ID 命名规范：
  - 所有元素 ID 以 scene3- 为前缀
  - 伴性遗传区：scene3-sex-parent-male, scene3-sex-parent-female, scene3-sex-offspring-f, scene3-sex-offspring-m
  - 棋盘格：scene3-punnett-grid, scene3-punnett-row-label-1~4, scene3-punnett-col-label-1~4
  - 单元格：scene3-punnett-cell-r1c1 ~ scene3-punnett-cell-r4c4
  - 按钮：scene3-btn-prev, scene3-btn-next
  - 表型汇总：scene3-phenotype-summary
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
