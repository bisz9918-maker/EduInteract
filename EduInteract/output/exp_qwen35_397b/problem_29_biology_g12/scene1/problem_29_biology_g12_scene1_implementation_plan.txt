[视觉元素清单]
- DNA 模板链：黑色实线 (#000000)，线宽 3px，表示原始 DNA 单链
- 引物：蓝色加粗线 (#1565c0)，线宽 5px，表示人工合成的短 DNA 片段

- 过程箭头：灰色 (#888888)，指示反应流程方向

[分步序列]
- 初始状态（步骤 0）：显示标题"PCR 循环过程"，阶段 0 标题"初始状态"，两条平行的 DNA 模板链（a 链和 b 链），链两端的 5'/3'标记，右侧显示引物Ⅰ和引物Ⅱ及其标签
- 步骤 1（95℃变性）：阶段 1 标题"95℃变性"出现，两条 DNA 链分开显示（垂直间距增大），右侧显示红色"95℃"标签，过程箭头 1 从高亮变为可见
- 步骤 2（55℃复性）：阶段 2 标题"55℃复性"出现，引物Ⅰ结合到 a 链的 5'端，引物Ⅱ结合到 b 链的 3'端（注意方向），右侧显示红色"55℃"标签，过程箭头 2 可见
- 步骤 3（72℃延伸）：阶段 3 标题"72℃延伸"出现，从引物位置开始延伸出绿色新链，新链沿模板链方向合成，右侧显示红色"72℃"标签，过程箭头 3 可见
- 步骤 4（循环结果）：阶段 4 标题"循环结果"出现，显示两个完整的双链 DNA 分子，每个分子包含一条原始模板链和一条新合成的绿色链，过程箭头 4 可见

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "上一步"按钮：位于控件栏左侧，点击后返回上一个步骤状态
  - "下一步"按钮：位于控件栏右侧，点击后进入下一个步骤状态
  - 步骤指示器：显示当前步骤编号（如"步骤 2/5"）
- 教师操作流程：
  1. 初始加载显示步骤 0（初始 DNA 双链和引物）
  2. 点击"下一步"进入步骤 1，讲解 95℃高温使双链解旋变性
  3. 点击"下一步"进入步骤 2，讲解 55℃时引物与模板链特异性结合
  4. 点击"下一步"进入步骤 3，讲解 72℃时 DNA 聚合酶从引物延伸合成新链
  5. 点击"下一步"进入步骤 4，展示循环一次后得到两个 DNA 分子
  6. 可随时点击"上一步"回退复习关键步骤

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript。原因：PCR 流程图主要是线段、箭头、文字等基础几何元素，原生 SVG 足够胜任，无需引入重型库；原生 JS 可实现简单的状态切换和按钮事件
- 画布尺寸：800 × 500 px（固定画布）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |            PCR 循环过程 (标题 y=35)              |
  +--------------------------------------------------+
  | [初始状态]  DNA 链    引物Ⅰ/Ⅱ    (y=60-130)      |
  |     ↓ 过程箭头                                    |
  | [95℃变性]  分离链    95℃标签    (y=140-210)     |
  |     ↓ 过程箭头                                    |
  | [55℃复性]  引物结合  55℃标签    (y=220-290)     |
  |     ↓ 过程箭头                                    |
  | [72℃延伸]  新链合成  72℃标签    (y=300-370)     |
  |     ↓ 过程箭头                                    |
  | [循环结果]  两个 DNA 分子        (y=380-430)     |
  +--------------------------------------------------+
  |      [◀上一步]        步骤指示器      [下一步▶]   |
  |              控件栏 (y=440-490)                  |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量 (0-4) 跟踪当前步骤，steps 数组存储每个步骤的可见元素配置
  2. 元素分组：每个阶段的所有元素用<g>分组，通过 display 属性控制显示/隐藏
  3. 按钮事件：绑定 click 事件监听器，更新 currentState 并调用 renderStep() 函数
  4. 边界处理：步骤 0 时禁用"上一步"，步骤 4 时禁用"下一步"
  5. 动画过渡：可选添加 opacity 过渡效果使切换更平滑
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀
  - scene1-title, scene1-stage0-group, scene1-stage1-group, ..., scene1-stage4-group
  - scene1-btn-prev, scene1-btn-next, scene1-step-indicator
  - scene1-chain-a, scene1-chain-b, scene1-primer1, scene1-primer2
  - scene1-temp-95, scene1-temp-55, scene1-temp-72
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
