[图示主题与整合说明]
- 本图示主题：放射性标记追踪分析（DNA 半保留复制）
- 整合内容：整合了循环一次后的 DNA 分子放射性分布、循环 n 次后不含放射性单链比例计算、半保留复制特点展示
- 教学价值：教师通过滑块调节循环次数 n，实时观察 DNA 分子数量变化和放射性标记分布规律，帮助学生理解 DNA 半保留复制的本质——原始模板链始终保留，新合成链带有放射性标记。学生可以直观看到随着循环次数增加，不含放射性的原始链比例逐渐降低（1/2ⁿ），从而掌握 PCR 扩增的数学规律。

[分步序列]
本场景采用滑块连续交互 + 分步导航混合模式：

- 初始状态（步骤 0）：
  - 显示滑块（n=1 位置）
  - 显示 2 个 DNA 分子（循环 1 次结果）
  - 每个 DNA 分子：1 条黑色模板链 + 1 条红色新合成链
  - 数据区显示：总 DNA=2，总单链=4，不含放射性=2，比例=1/2
  - 公式区显示：1/2ⁿ

- 步骤 1（n=1）：
  - 滑块位置：x=150
  - DNA 分子：2 个，排列成一行（每个 80×40，间距 40px）
  - 每个 DNA：左侧黑链（模板），右侧红链（新合成）
  - 数据：总 DNA=2¹=2，总单链=2²=4，无放射性=2，比例=2/4=1/2

- 步骤 2（n=2）：
  - 滑块位置：x=200
  - DNA 分子：4 个，排列成 2×2 网格
  - 其中 2 个 DNA 含黑链（来自原始模板），2 个 DNA 全红链
  - 数据：总 DNA=2²=4，总单链=2³=8，无放射性=2，比例=2/8=1/4

- 步骤 3（n=3）：
  - 滑块位置：x=250
  - DNA 分子：8 个，排列成 2×4 网格
  - 其中 2 个 DNA 含黑链，6 个 DNA 全红链
  - 数据：总 DNA=2³=8，总单链=2⁴=16，无放射性=2，比例=2/16=1/8

- 步骤 4（n=4）：
  - 滑块位置：x=300
  - DNA 分子：16 个，排列成 4×4 网格（缩小显示）
  - 其中 2 个 DNA 含黑链，14 个 DNA 全红链
  - 数据：总 DNA=2⁴=16，总单链=2⁵=32，无放射性=2，比例=2/32=1/16

- 步骤 5（n=5 及以上）：
  - 滑块继续右移
  - DNA 分子用简化图标表示（数量太多时显示代表性样本）
  - 重点突出数据变化和公式规律
  - n=10 时：总 DNA=1024，总单链=2048，无放射性=2，比例=2/2048=1/1024

[交互方案]
- 交互类型：连续拖拽滑块 + 分步按钮导航混合
  - 滑块：拖拽调节循环次数 n（1→10），实时更新 DNA 分子可视化和数据
  - 分步按钮：◀上一步 / 下一步▶ / 重置，用于课堂节奏控制

- 控件说明：
  - 滑块轨道：位于顶部 y=40，x=150-650，对应 n=1-10
  - 滑块按钮：圆形可拖拽，跟随 n 值移动
  - 当前 n 值显示：滑块右侧，大号字体突出显示
  - 上一步按钮：减少 n 值（最小 1），更新可视化
  - 下一步按钮：增加 n 值（最大 10），更新可视化
  - 重置按钮：回到 n=1 初始状态

- 教师操作流程：
  1. 初始展示 n=1，讲解 DNA 半保留复制基本概念
  2. 点击「下一步」或拖拽滑块到 n=2，观察 4 个 DNA 分子中 2 个含模板链
  3. 继续增加到 n=3、n=4，引导学生发现规律：不含放射性链始终为 2 条
  4. 拖拽到 n=10，展示比例 1/1024，强调原始模板链被"稀释"
  5. 可随时回退复习关键步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：DNA 双链用贝塞尔曲线绘制简单，无需复杂库；滑块交互用原生事件处理足够

- 画布尺寸：800 × 500 px（固定）

- 布局草图（ASCII）：
  ```
  [800×500 画布]
  ┌────────────────────────────────────────────────────────────┐
  │  [滑块轨道════════════●══════════]  n=1                   │ y=20-70
  │                                                            │
  │         DNA 分子可视化区                                   │
  │    ┌────┐ ┌────┐          (n=1 时 2 个)                    │ y=80-280
  │    │≋≋≋│ │≋≋≋│          黑链 + 红链                       │
  │    └────┘ └────┘                                          │
  │                                                            │
  │  ┌──────────────────────────────────────────────────────┐  │
  │  │ 总 DNA: 2   总单链：4   无放射性：2   比例：1/2      │  │ y=320-410
  ```

- 关键实现要点：
  1. 状态机设计：维护当前 n 值（1-10），每次变化触发 updateScene()
  2. DNA 分子坐标计算：根据 n 值动态计算网格布局（n≤4 用 2×2ⁿ⁻¹，n>4 用简化显示）
  3. 滑块拖拽：mousedown/mousemove/mouseup 事件，计算 x 坐标映射到 n 值
  4. 动画曲线：滑块移动用 requestAnimationFrame 平滑过渡
  5. 事件绑定：按钮点击、滑块拖拽、键盘左右键控制

- ID 命名规范：
  - 所有元素 ID 以 scene3- 为前缀
  - 示例：scene3-slider-track, scene3-slider-button, scene3-dna-group, scene3-dna-0, scene3-dna-1, scene3-data-total, scene3-data-ratio, scene3-btn-prev, scene3-btn-next, scene3-btn-reset
