[图示主题与整合说明]
- 本图示主题：小车下滑过程中的能量转化
- 整合的步骤/概念：整合了小车在斜面上的初始位置、下滑过程、能量转化关系（重力势能→动能）、撞击木块四个阶段
- 教学价值：教师可使用此图示逐步展示机械能转化过程，通过分步控制节奏，让学生直观理解重力势能转化为动能的物理过程，以及动能传递到木块的过程。能量条形图的动态变化帮助学生建立能量守恒的直观认识。

[分步序列]
- 初始状态（步骤0）：显示斜面装置、小车在斜面顶端(90,160)、木块在(340,310)、高度h标注线及标签、小车/木块/木板标签；能量条区域显示Ep标签和Ek标签，条形图为空；速度箭头隐藏
- 步骤1：点击「下一步」→ 小车移动到下滑中位置(160,250)，显示速度v箭头(从车右侧向右的红色箭头)；高度h标注保持显示；能量条仍为空
- 步骤2：点击「下一步」→ 小车保持在(160,250)，速度箭头保持；能量条Ep填充显示70%长度(蓝色)，Ek填充显示30%长度(红色)，右侧显示"70%"/"30%"标签，展示能量转化关系
- 步骤3：点击「下一步」→ 小车移动到撞击前位置(240,330)，木块移动到撞击后位置(420,310)，速度箭头移至木块右侧表示木块获得动能；能量条Ep填充变为10%(蓝色)，Ek填充变为90%(红色)，右侧显示"10%"/"90%"

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于(280,455)，80×30px，点击后退到前一状态
  - 「下一步 ▶」按钮：位于(440,455)，80×30px，点击前进到下一状态
  - 步骤指示器：位于(400,460)，显示"步骤 X/4"
- 教师操作流程：
  1. 初始状态展示实验装置，讲解小车在斜面顶端具有重力势能
  2. 点击「下一步」展示小车下滑过程，引入速度概念
  3. 点击「下一步」展示能量条形图，讲解重力势能转化为动能
  4. 点击「下一步」展示撞击过程，讲解动能传递

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单，无需复杂库；原生实现轻量且易于多场景合并
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  [斜面装置区 480px]    |  [能量条区 320px]       |
  |                         |                         |
  |   小车▲                 |   Ep [███████] 70%     |
  |    ╱╲                   |                         |
  |   ╱  ╲  h               |   Ek [███] 30%         |
  |  ╱____╲___木块___木板   |                         |
  |                         |                         |
  |                         |                         |
  |  [速度v→]               |                         |
  |                         |                         |
  +--------------------------------------------------+
  |        [◀ 上一步]  步骤1/4  [下一步 ▶]           |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用 currentState 变量(0-3)跟踪当前步骤，steps 数组存储每步的视觉配置
  2. 小车动画：使用 SVG transform translate 实现位置过渡，transition: transform 0.5s ease-out
  3. 能量条动画：使用 CSS transition 实现宽度变化，transition: width 0.5s ease
  4. 事件绑定：按钮点击事件调用 updateScene() 函数更新所有元素状态
  5. 边界处理：步骤0时禁用「上一步」，步骤3时禁用「下一步」
- ID 命名规范：所有元素 ID 以 scene1- 为前缀
  - scene1-ramp, scene1-board, scene1-cart, scene1-block, scene1-height-line
  - scene1-ep-bar, scene1-ek-bar, scene1-ep-label, scene1-ek-label
  - scene1-prev-btn, scene1-next-btn, scene1-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
