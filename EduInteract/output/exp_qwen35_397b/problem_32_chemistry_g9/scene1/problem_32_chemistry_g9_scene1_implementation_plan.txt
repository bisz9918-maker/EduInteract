[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：SVG内底部左侧(50,460)，点击返回上一状态
  - 「下一步」按钮：SVG内底部右侧(700,460)，点击进入下一状态
  - 状态指示器：SVG内底部中央(400,460)，显示"步骤X/5"
- 教师操作流程：
  1. 初始展示完整装置，让学生整体观察
  2. 点击「下一步」高亮A瓶，讲解HCl气体性质
  3. 点击「下一步」高亮B瓶和胶头滴管，讲解NH₃气体及滴管作用
  4. 点击「下一步」高亮三个活塞，讲解活塞控制功能
  5. 点击「下一步」高亮烧杯和水，讲解实验接收装置
  6. 可随时点击「上一步」回退复习

[技术实现]
- JS库选择及原因：原生SVG + 原生JavaScript。原因：本场景为静态装置图+分步高亮，无需复杂动画或数据可视化，原生SVG可精确控制每个元素的样式和坐标，代码轻量且易于维护
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  A                    B                          |
  | (HCl)                (NH₃)                       |
  |   |                    |                         |
  |   c--------+-----------a                         |
  |            |                                     |
  |            |b                                    |
  |            |                                     |
  |         [烧杯]                                   |
  |          水                                      |
  |                                                  |
  |              胶头滴管→                           |
  |                                                  |
  |     [◀上一步]    步骤X/5    [下一步▶]            |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量currentStep(0-5)跟踪当前步骤，数组stepStates存储每步的高亮元素ID列表
  2. 坐标计算：所有元素坐标硬编码于SVG中，确保精确对齐
  3. 动画曲线：高亮过渡使用CSS transition: opacity 0.3s ease
  4. 事件绑定：按钮点击事件绑定到stepChange函数，更新currentStep并应用对应样式
  5. 样式切换：每步通过getElementById获取元素，设置style.fillOpacity和style.strokeWidth
- ID命名规范：所有交互元素ID必须以scene1-为前缀（如scene1-flask-a、scene1-piston-a、scene1-label-hcl）
- IIFE隔离：所有JS包在(function() { ... })()中，避免全局变量污染
