[图示主题与整合说明]
- 本图示主题：氨气溶解导致压强变化与喷泉效应
- 整合的步骤/概念：胶头滴管挤水→氨气溶解→B 瓶压强降低→打开活塞后水被吸入→酚酞变红形成红色喷泉
- 教学价值：教师可通过分步演示，清晰展示"操作→现象→原因"的因果链条，帮助学生理解气体溶解导致压强变化的原理，以及氨水呈碱性使酚酞变红的性质

[分步序列]
- 初始状态（步骤 0）：显示 B 瓶（含 NH₃气体，绿色半透明填充）、瓶塞、导管（关闭状态）、烧杯（含水，蓝色半透明）、胶头滴管（未挤压）、活塞 a（关闭状态，橙色）、标签"B"、"NH₃"、"水"、"活塞 a"
- 步骤 1：点击「下一步」→ 胶头滴管挤压变形，水滴从滴管滴落进入 B 瓶，显示标签"挤入水"
- 步骤 2：点击「下一步」→ 水滴消失，B 瓶内气体填充变为更淡（表示溶解），显示向下压强指示箭头，显示标签"NH₃溶解"、"压强减小"
- 步骤 3：点击「下一步」→ 活塞 a 变为开启状态（绿色），显示向上水流方向箭头，烧杯内水面略微下降，导管内显示蓝色水流，显示标签"打开活塞 a、b"
- 步骤 4：点击「下一步」→ B 瓶内显示红色液体从导管口向上喷射形成喷泉（#c62828 渐变），烧杯内水面明显下降，显示标签"酚酞变红"、"氨水呈碱性"

[交互方案]

  - 步骤指示器：位于顶部中央 (400,20)，显示"步骤 X/4"
  - 「上一步」按钮：位于 SVG 底部左侧 (100,460)
  - 「下一步」按钮：位于 SVG 底部右侧 (700,460)
- 教师操作流程：
  1. 初始状态展示装置，讲解实验背景
  2. 点击「下一步」演示挤水操作，提问"水进入 B 瓶后会发生什么"
  3. 点击「下一步」展示氨气溶解和压强降低，讲解因果关系
  4. 点击「下一步」展示打开活塞后水被吸入，提问"为什么水会向上流"
  5. 点击「下一步」展示红色喷泉，讲解氨水呈碱性使酚酞变红
  6. 可随时点击「上一步」回退复习关键步骤

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript。原因：本场景为 2D 示意图，元素数量适中，原生 SVG 可精确控制每个元素的位置和样式，无需引入重型库
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |              [步骤指示器]                        |
  |                                                  |
  |         [B 瓶]    [压强箭头]  [NH₃溶解]          |
  |           |                                      |
  |        [胶头滴管] [挤入水]                       |
  |           |                                      |
  |        [活塞 a]                                  |
  |           |                                      |
  |        [水流箭头]                                |
  |           |                                      |
  |    +------------------+                          |
  |    |    [烧杯/水]     |  [酚酞变红]              |
  |    +------------------+                          |
  |                                                  |
  |    [◀上一步]                    [下一步▶]        |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量 (0-4)，每个步骤对应一组元素显示/隐藏状态
  2. 坐标计算：所有元素使用绝对坐标，确保布局精确
  3. 动画曲线：水滴下落使用 ease-in，喷泉使用 ease-out 模拟重力效果
  4. 事件绑定：按钮点击事件切换 currentStep，调用 updateScene() 更新显示
  5. 元素 ID 命名：所有元素 ID 以 scene3- 为前缀，如 scene3-bottle-b、scene3-dropper、scene3-fountain 等
  6. IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
- ID 命名规范：
  - scene3-bottle-b（B 瓶瓶体）
  - scene3-neck（瓶颈）
  - scene3-stopper（瓶塞）
  - scene3-dropper（胶头滴管）
  - scene3-water-drop（水滴）
  - scene3-tube-vertical（垂直导管）
  - scene3-piston-a（活塞 a）
  - scene3-beaker（烧杯）
  - scene3-water-level（烧杯水面）
  - scene3-fountain（喷泉液柱）
  - scene3-pressure-arrow（压强指示箭头）
  - scene3-flow-arrow（水流方向箭头）
  - scene3-label-b、scene3-label-nh3、scene3-label-water 等（所有标签）
  - scene3-step-indicator（步骤指示器）
  - scene3-btn-prev（上一步按钮）
  - scene3-btn-next（下一步按钮）
