    **题目原文：**

    如下图，甲的周长与乙的周长相比，（    ）．

    A．甲＞乙    B．甲＜乙    C．甲＝乙

    **题目分析：**

    本题考察不规则图形周长的比较。甲、乙两个图形都是在方格纸上的阴影区域，形状不规则但具有对称性。解题关键是用"平移法"——将凹进或凸出的边平移到外围，转化为规则长方形的周长进行比较。

    **整体讲解思路：**

    1. 首先展示两个图形的原始状态，让学生观察形状差异
    2. 通过平移甲图形凹进去的边，展示其周长等于外接长方形周长
    3. 通过平移乙图形凸出来的边，展示其周长也等于同样尺寸的长方形周长
    4. 得出结论：甲乙周长相等

    **图示规划说明：**

    设计一个整合图示，用分步按钮导航展示平移法的完整过程。将甲、乙两个图形并列展示，通过高亮和平移动画直观呈现周长计算方法。

    **教学说明：**

    **步骤 0 引导：**
    让学生先观察甲、乙两个图形的形状，提问："这两个图形形状不同，周长会一样吗？"

    **步骤 1-2 讲解（甲图形）：**
    1. 指出甲图形右上角凹进去的部分
    2. 说明：凹进去的横向边可以向上平移，纵向边可以向右平移
    3. 平移后，甲图形的周长就等于外接长方形的周长
    4. 计算：长方形长 5 格，宽 3 格，周长 = 2×(5+3) = 16 格

    **步骤 3-4 讲解（乙图形）：**
    1. 指出乙图形上方的凸起部分
    2. 说明：凸出来的横向边可以向下平移，纵向边可以向内平移
    3. 平移后，乙图形的周长也等于同样尺寸的长方形周长
    4. 计算：长方形长 5 格，宽 3 格，周长 = 2×(5+3) = 16 格

    **关键公式：**
    - 长方形周长公式：$C = 2 \times (长 + 宽)$
    - 甲周长 = 乙周长 = $2 \times (5 + 3) = 16$（单位长度）

    **总结与课堂建议：**

    **完整解答：**

    通过平移法或逐边计数法均可得出：
    - 甲的周长 = 16 单位长度
    - 乙的周长 = 16 单位长度
    - 因此 甲 = 乙

    **答案：C**

    **课堂讲解建议：**

    1. **先猜后证**：让学生先猜测答案，再用手比划或铅笔描边感受周长
    2. **平移法核心**：强调"凹进去的边平移出来，凸出来的边平移进去"，周长不变
    3. **易错点提醒**：学生容易误以为形状不同周长就不同，需强调周长是"边的总长度"而非"面积大小"
    4. **拓展思考**：可提问"如果甲图形凹进去更深，周长会变化吗？"引导学生理解平移法的本质
