[图示主题与整合说明]
- 本图示主题：周长计算的数值验证——逐边计数法
- 整合的内容：通过逐边高亮并计数的方式，验证 Scene 1 中平移法的结论（甲周长=乙周长）

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单，无需复杂库；原生 SVG 便于精确控制坐标和样式
- 画布尺寸：800×500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |           [网格区域 400×200, y=50-250]           |
  |           +------------------+                   |
  |           |   甲图形   乙图形 |                   |
  |           |   (凹形)  (阶梯) |                   |
  |           +------------------+                   |
  |                                                  |
  |      [甲求和框]          [乙求和框]              |
  |        y=260               y=260                 |
  |                                                  |
  |            [结论框] y=320                        |
  |                                                  |
  |                                                  |
  |      [◀上一步]  步骤 X/17  [下一步▶]             |
  |              y=440-490 (控件栏)                  |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 stepIndex 变量 (0-17) 跟踪当前步骤，steps 数组存储每步的显示配置
  2. 甲图形路径坐标（基于网格，每格 50px，起点 (200,50)）：
     - 甲多边形：M200,50 L200,200 L350,200 L350,150 L300,150 L300,100 L250,100 L250,50 Z
     - 实际周长边：左竖 (200,50)-(200,200)=150px=3 格，但按题目应为 3 单位
     - 需调整：每格代表 1 单位，图形按实际比例绘制
  3. 乙图形路径坐标：
     - 乙多边形：M400,150 L400,200 L450,200 L450,150 L500,150 L500,100 L550,100 L550,150 L600,150 L600,200 L400,200 Z
     - 需根据实际图片调整坐标
  4. 高亮边线：使用 <line> 或 <path> 元素，初始 display:none，按步骤设置 display:block
  5. 边长数值：使用 <text> 元素，初始 opacity:0，按步骤设置 opacity:1
  6. 求和框：使用 <rect>+<text> 组合，动态更新 textContent
  7. 事件绑定：按钮点击事件监听，更新 stepIndex 并调用 renderStep() 函数
  8. 边界处理：步骤 0 时禁用「上一步」，步骤 17 时禁用「下一步」
- ID 命名规范：
  - 所有元素 ID 以 scene2- 为前缀
  - 示例：scene2-grid, scene2-tri-jia, scene2-tri-yi, scene2-highlight-1, scene2-label-jia, scene2-sum-jia, scene2-btn-prev, scene2-btn-next, scene2-step-indicator
- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染
