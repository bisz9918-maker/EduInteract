[图示主题与整合说明]

  - 新增边高亮：两条竖边 (260,110)-(260,130) 和凹槽底部 (260,110)-(280,110) 的部分
  - 尺寸标注："6"在底部 (180,255)，"4"在左侧 (65,160)，"2"在凹槽内 (270,120)
  - 右侧显示：周长 = 24cm，计算过程：原周长 (6+4)×2=20cm，凹槽增加 2×2=4cm，总计 24cm
  - 状态标签："右边（原题）"

- 状态 2（上边）：
  - 显示原长方形虚线参考轮廓 (80,80)-(280,240)

  - 新增边高亮：凹槽内两条竖边
  - 尺寸标注："6"在底部 (180,255)，"4"在左侧 (65,160)，"2"在凹槽上方 (140,70)
  - 右侧显示：周长 = 24cm，计算过程：原周长 (6+4)×2=20cm，凹槽增加 2×2=4cm，总计 24cm
  - 状态标签："上边"

- 状态 3（右上角）：

[交互方案]
- 交互类型：多状态切换（3 个按钮）
- 控件说明：
  - 按钮"右边"：位于 (150,455)，点击显示右边凹槽图形及周长 24cm
  - 按钮"上边"：位于 (360,455)，点击显示上边凹槽图形及周长 24cm
  - 按钮"右上角"：位于 (570,455)，点击显示右上角缺角图形及周长 20cm
- 教师操作流程：
  1. 初始显示"右边（原题）"状态，讲解凹槽增加周长的原理
  2. 点击"上边"按钮，引导学生观察上边凹槽与右边凹槽的相似性
  3. 点击"右上角"按钮，对比角剪与凹槽的区别，归纳规律
  4. 可反复切换对比，强化理解

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  [状态标签：右边（原题）]                         |
  |                                                  |
  |  +------------------+    周长 = 24cm             |
  |  |                  |    原周长：(6+4)×2=20cm   |
  |  |   剪切图形       |    新增：2×2=4cm          |
  |  |   (凹槽)         |    总计：24cm             |
  |  |                  |                            |
  |  +------------------+                            |
  |     6cm                                          |
  |                                                  |
  |  [右边]      [上边]      [右上角]                |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentState 记录当前状态（1/2/3），点击按钮时更新状态并重绘
  2. 坐标计算：三种状态的图形路径坐标预先计算好，存储为数组
  3. 动画过渡：使用 CSS transition 实现图形淡入淡出效果（opacity 变化）
  4. 事件绑定：三个按钮分别绑定 click 事件，调用 updateState() 函数
  5. 高亮边绘制：在图形路径基础上，用更粗的绿色线段叠加绘制新增边
- ID 命名规范：
  - 图形路径：scene3-shape-right / scene3-shape-top / scene3-shape-corner
  - 高亮边：scene3-highlight-edges
  - 尺寸标注：scene3-label-6 / scene3-label-4 / scene3-label-2
  - 周长显示：scene3-perimeter-value / scene3-perimeter-calc
  - 按钮：scene3-btn-right / scene3-btn-top / scene3-btn-corner
  - 状态标签：scene3-status-label
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
