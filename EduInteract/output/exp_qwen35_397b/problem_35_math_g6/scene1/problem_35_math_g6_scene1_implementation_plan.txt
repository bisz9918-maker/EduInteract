[图示主题与整合说明]
- 本图示主题：圆剪拼成长方形的变换过程及尺寸关系
- 整合的步骤/概念：圆的分割、扇形重排、形成长方形、标注长宽关系、周长计算
- 教学价值：教师如何使用此图示进行课堂讲解
  1. 初始状态展示完整圆，引导学生回忆圆的周长公式
  2. 逐步演示分割过程，让学生理解"化曲为直"的数学思想
  3. 通过扇形重排，直观展示长方形长=πr、宽=r 的几何关系
  4. 最终推导周长公式，帮助学生理解为什么长方形周长比圆周长多 2r

[分步序列]
- 初始状态（步骤 0）：显示完整圆，圆心 O，半径标注线及"r=10cm"标签
- 步骤 1：圆内显示 16 条分割线，将圆分为 16 等份扇形，交替填充灰色/白色
- 步骤 2：上半圆 8 个扇形整体向上平移 30px，下半圆 8 个扇形向下平移 30px，显示分离效果
- 步骤 3：扇形开始向右侧移动并交错排列，上半圆扇形齿尖向下，下半圆扇形齿尖向上，形成初步长方形轮廓
- 步骤 4：完整长方形形成于右侧(420,180)，显示蓝色"长=πr"标注和绿色"宽=r"标注
- 步骤 5：右下角显示公式文本框，内容：周长=2(πr+r)=2×10×(3.14+1)=82.8cm

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于(320,455)，80×30px，灰色背景，点击返回上一状态
  - 「下一步 ▶」按钮：位于(400,455)，80×30px，蓝色背景，点击进入下一状态
  - 步骤指示器：位于两按钮之间，显示"步骤 X/6"
- 教师操作流程：
  1. 点击「下一步」展示圆分割，讲解等分概念
  2. 继续点击展示扇形分离，强调上下半圆
  3. 点击展示重排过程，解释"化曲为直"
  4. 点击展示完整长方形及长宽标注，推导长=πr、宽=r
  5. 最后点击显示公式，完成周长计算
  6. 可随时点击「上一步」回退复习关键步骤

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单，无需复杂库；SVG 便于精确控制扇形路径和动画；代码轻量易维护
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +----------------------------------------------------------+
  |                                                          |
  |   [圆]                    [长方形]                        |
  |    O                      +------------------+            |
  |   /|\                     |\/\/\/\/\/\/\/\/|  长=πr      |
  |  r=10cm                   |\/\/\/\/\/\/\/\/|            |
  |                           +------------------+            |
  |                                          |  宽=r         |
  |                                                          |
  |                           [公式框]                        |
  |                           +------------+                 |
  |                           | 周长=...   |                 |
  |                           +------------+                 |
  |                                                          |
  |              [◀上一步] [步骤 X/6] [下一步▶]              |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量(0-5)，数组存储每步显示的元素 ID 列表
  2. 扇形路径计算：使用 SVG path 的 A 命令绘制圆弧，16 等份每份 22.5°
  3. 动画过渡：使用 CSS transition 或 requestAnimationFrame 实现平滑移动
  4. 事件绑定：按钮点击事件切换状态，更新显示元素和按钮禁用状态
  5. 坐标计算：长方形宽度 = πr = 3.14×80≈251px，高度 = r = 80px
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀
  - scene1-circle, scene1-center-o, scene1-radius-line, scene1-label-r
  - scene1-sector-0 至 scene1-sector-15
  - scene1-rect-group, scene1-label-length, scene1-label-width
  - scene1-formula-box, scene1-formula-text
  - scene1-btn-prev, scene1-btn-next, scene1-step-indicator
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
