[图示主题与整合说明]
- 本图示主题：从上面观察两个立体图形的形状对比（俯视图）及最终答案

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮：位于(280,460)，80×30px，点击返回上一状态，步骤0时禁用
  - 下一步按钮：位于(440,460)，80×30px，点击进入下一状态，步骤3时禁用
- 教师操作流程：
  1. 初始展示左图俯视图，提问学生"左图从上面看是什么形状？"
  2. 点击下一步展示右图俯视图，提问"右图从上面看呢？"
  3. 点击下一步显示"形状相同"标注，引导学生得出结论
  4. 点击下一步显示答案"C.上面"，确认正确选项

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript。理由：本场景为简单几何图形（矩形网格）和文字展示，无需复杂库，原生实现轻量高效。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |              从上面观察 (标题)                    | y=35
  |                                                  |
  |    [左图俯视]              [右图俯视]            | y=120-180
  |    □□□                     □□□                   |
  |                                                  |
  |    左图俯视                右图俯视              | y=200
  |                                                  |
  |         ← 形状相同 →                             | y=250
  |                                                  |
  |         [答案：C.上面]                           | y=350
  |                                                  |
  |         (步骤提示文字)                           | y=420
  |                                                  |
  |    [◀上一步]          [下一步▶]                  | y=460
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-3) 跟踪当前步骤，数组存储每步需显示的元素ID
  2. 元素显示控制：每步通过 display: none/block 切换元素可见性
  3. 按钮状态：步骤0禁用上一步，步骤3禁用下一步
  4. 动画效果：元素出现时使用淡入动画（opacity 0→1，transition 0.3s）
- ID 命名规范：所有交互元素 ID 必须以 scene4- 为前缀
  - scene4-title, scene4-left-grid, scene4-right-grid, scene4-left-label, scene4-right-label
  - scene4-same-label, scene4-arrow-left, scene4-arrow-right
  - scene4-answer-bg, scene4-answer-text, scene4-step-hint
  - scene4-btn-prev, scene4-btn-next
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
