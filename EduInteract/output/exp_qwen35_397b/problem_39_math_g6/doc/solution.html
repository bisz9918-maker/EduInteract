problem_39_math_g6

场景导航：Scene 1

题目原文：

如图，小旗的顶点用数对表示为（5，7），现在将小旗绕点 O，顺时针方向旋转 90°，现在小旗的顶点可以用数对（ ）表示。

A．（7，5）B．（10，3）C．（9，3）D．（1，3）

题目分析：

本题考查平面直角坐标系中图形的旋转变换。关键要素：

  1. 旋转中心：点 O（从图中可确定坐标为 (5, 3)）
  2. 旋转方向：顺时针
  3. 旋转角度：90°
  4. 原顶点坐标：(5, 7)

整体讲解思路：

  1. 首先确认旋转中心 O 的坐标
  2. 计算顶点相对于 O 点的位置向量
  3. 应用顺时针 90° 旋转公式：(x, y) → (y, -x)
  4. 将旋转后的相对坐标转换回绝对坐标
  5. 验证答案

图示规划说明：

设计一个整合图示，通过分步动画完整展示旋转过程：

  • 原始位置 → 高亮关键点 → 显示旋转轨迹 → 展示旋转后位置 → 标注新坐标
步骤 1/6

教学说明：

如何引导学生观察：

  1. 步骤 0-1：让学生先确认 O 点坐标
  • 提问：「从顶点 (5, 7) 往下数，O 点在第几行？」
  • 引导学生发现 O 点坐标为 (5, 3)
  1. 步骤 2：理解相对位置
  • 顶点相对于 O 点的位置向量是 (0, 4)
  • 即：x 方向偏移 0，y 方向偏移 +4
  1. 步骤 3-4：观察旋转规律
  • 顺时针 90° 旋转公式：(x, y) → (y, -x)
  • 所以 (0, 4) → (4, 0)
  • 原来竖直向上的向量，旋转后变成水平向右
  1. 步骤 5：计算新坐标
  • 新顶点 = O 点坐标 + 旋转后的向量
  • (5, 3) + (4, 0) = (9, 3)

关键公式：

绕原点顺时针旋转 90° 的坐标变换：

  • (x, y) → (y, -x)

绕任意点 (a, b) 顺时针旋转 90°：

  • 1. 计算相对坐标：(x-a, y-b)
  • 2. 应用旋转：(y-b, -(x-a)) = (y-b, a-x)
  • 3. 转换回绝对坐标：(a + y - b, b + a - x)

本题答案：

  • O 点坐标：(5, 3)
  • 原顶点相对 O：(5-5, 7-3) = (0, 4)
  • 旋转后相对坐标：(4, 0)
  • 新顶点绝对坐标：(5+4, 3+0) = (9, 3)
  • 正确答案：C
