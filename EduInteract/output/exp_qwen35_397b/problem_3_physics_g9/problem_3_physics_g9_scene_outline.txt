    **题目原文：**

    如图所示，用三种方法拉动同一物体在相同的水平地面上做匀速直线运动，所用的拉力分别是 F₁、F₂、F₃，则（）

    A. F₁＞F₂＞F₃
    B. F₁＜F₂＜F₃
    C. F₂＞F₁＞F₃
    D. F₂＜F₁＜F₃

    **题目分析：**

    本题考查滑轮组的力学分析，核心是判断三种滑轮配置下拉力与摩擦力的关系。物体做匀速直线运动，说明拉力与摩擦力平衡。

    **整体讲解思路：**

    1. 首先明确物体匀速运动时，水平方向合力为零，拉力需克服摩擦力 f
    2. 分析图(1)定滑轮：不省力，F₁ = f
    3. 分析图(2)动滑轮：两段绳子承担，F₂ = f/2
    4. 分析图(3)动滑轮（拉力作用在轴上）：F₃ = 2f
    5. 比较三者大小：F₂ < F₁ < F₃，选 D

    **图示规划说明：**

    - SCENE_1：三种滑轮配置的受力分析对比图，整合三个子图的受力标注和绳子段数分析
    - SCENE_2：力学关系推导与大小比较，用条形图直观展示 F₁、F₂、F₃ 与摩擦力 f 的倍数关系
    </TEXT_1>

    **教学说明：**

    本图示用于引导学生分析三种滑轮配置的力学关系。

    **讲解要点：**

    1. **图(1) 定滑轮分析**
       - 定滑轮只改变力的方向，不省力
       - 绳子一端拉物体，拉力 F₁ 直接等于摩擦力 f
       - 公式：F₁ = f

    2. **图(2) 动滑轮分析**
       - 动滑轮随物体一起移动
       - 两段绳子共同承担摩擦力 f
       - 每段绳子张力为 f/2，拉力 F₂ 等于绳子张力
       - 公式：F₂ = f/2

    3. **图(3) 动滑轮分析（特殊情况）**
       - 拉力作用在滑轮轴上，而非绳子自由端
       - 两段绳子都拉物体，每段张力为 f
       - 拉力 F₃ 需平衡两段绳子的张力
       - 公式：F₃ = 2f

    **引导学生观察：**
    - 绳子与滑轮的接触方式
    - 有几段绳子承担物体的摩擦力
    - 拉力作用点在哪里（绳子自由端 vs 滑轮轴）

    **总结与课堂讲解建议：**

    **完整解答：**

    设物体与地面的摩擦力为 f（同一物体、相同地面，f 相同）。

    - 图(1)：定滑轮，F₁ = f
    - 图(2)：动滑轮，两段绳子承担，F₂ = f/2
    - 图(3)：动滑轮（拉力在轴上），F₃ = 2f

    比较得：F₂ < F₁ < F₃

    **答案：D**

    **课堂讲解建议：**

    1. 先让学生观察三图的异同，识别滑轮类型
    2. 强调"匀速直线运动"意味着受力平衡
    3. 关键区分：拉力作用在绳子自由端还是滑轮轴上
    4. 用 SCENE_1 逐步分析受力，用 SCENE_2 直观比较大小
    5. 可延伸提问：若物体重力为 G，摩擦系数为μ，则 f = μG，代入可得具体表达式
