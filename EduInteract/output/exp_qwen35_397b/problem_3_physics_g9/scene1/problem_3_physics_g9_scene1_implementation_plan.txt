[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于(280,455)，宽100px，高30px，灰色背景，点击后退到前一状态
  - 「下一步」按钮：位于(420,455)，宽100px，高30px，蓝色背景，点击前进到下一状态
  - 步骤指示器：位于(390,455)，显示「步骤 X/5」
- 教师操作流程：
  1. 初始状态展示三图结构，让学生观察差异
  2. 点击「下一步」分析图(1)定滑轮，讲解F₁=f
  3. 点击「下一步」分析图(2)动滑轮，讲解两段绳子分担拉力，F₂=f/2
  4. 点击「下一步」分析图(3)动滑轮，讲解拉力作用在轴上，F₃=2f
  5. 点击「下一步」展示完整结论，引导学生比较大小得出F₂<F₁<F₃，选择D

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  图(1)定滑轮          图(2)动滑轮                |
  |  (50,50)-(300,180)    (450,50)-(700,180)         |
  |                                                  |
  |              图(3)动滑轮                          |
  |           (200,250)-(550,380)                    |
  |                                                  |
  |        [结论框：F₁=f, F₂=f/2, F₃=2f]              |
  |        (150,400)-(650,435)                       |
  |                                                  |
  |        [◀上一步] [步骤X/5] [下一步▶]             |
  |        (280,455)  (390,455)  (420,455)           |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量currentStep(0-4)跟踪当前步骤，steps数组定义每步显示的元素ID列表
  2. 坐标计算：所有元素用绝对坐标定义，确保三图比例一致
  3. 动画曲线：元素显示/隐藏用CSS transition: opacity 0.3s ease
  4. 事件绑定：按钮点击事件切换currentStep，调用updateScene()更新显示
  5. 高亮效果：用<rect>覆盖目标区域，fill="#1565c0" opacity="0.2"，stroke="#1565c0" stroke-width="2"
- ID 命名规范：所有元素ID以scene1-为前缀，如scene1-fig1-pulley、scene1-fig1-force-f1、scene1-btn-prev、scene1-btn-next
- IIFE 隔离：所有JS代码包在(function() { ... })()中，避免全局变量污染
