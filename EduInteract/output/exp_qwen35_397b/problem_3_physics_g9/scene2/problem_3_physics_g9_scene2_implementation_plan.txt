[图示主题与整合说明]
- 本图示主题：拉力大小比较的可视化（滑轮组力学分析）
- 整合的内容：F₁、F₂、F₃ 与摩擦力 f 的倍数关系对比，用条形图直观展示大小关系
- 教学价值：教师可通过逐步展示三个拉力与摩擦力的关系，帮助学生理解定滑轮与动滑轮的力学特性，最后汇总比较得出 F₂ < F₁ < F₃ 的结论，对应正确选项 D

[分步序列]
- 初始状态（步骤 0）：显示标题、基准条 f（灰色）、f 标签。其他条形隐藏。
- 步骤 1：点击「下一步」→ 显示 F₁ 条形（蓝色，长度=f=200px）、F₁ 标签、"f"标注。此时 F₁ 条与 f 条等长对齐。
- 步骤 2：点击「下一步」→ 显示 F₂ 条形（蓝色，长度=f/2=100px）、F₂ 标签、"f/2"标注。F₂ 条明显短于 f 条。
- 步骤 3：点击「下一步」→ 显示 F₃ 条形（蓝色，长度=2f=400px）、F₃ 标签、"2f"标注。F₃ 条明显长于 f 条。
- 步骤 4：点击「下一步」→ 显示排序箭头序列（F₂→F₁→F₃）、排序文本"F₂ < F₁ < F₃"、选项框 D 高亮（绿色加粗边框）。完成结论展示。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 (280,450)，点击后退到前一状态
  - 「下一步」按钮：位于 (420,450)，点击前进到下一状态
  - 步骤指示器：显示"步骤 X/5"，位于两按钮之间 (390,465)
- 教师操作流程：
  1. 初始展示基准摩擦力 f，讲解"这是物体受到的摩擦力"
  2. 点击下一步，展示 F₁=f，讲解"定滑轮不省力，F₁ 等于摩擦力"
  3. 点击下一步，展示 F₂=f/2，讲解"动滑轮省一半力，F₂ 是摩擦力的一半"
  4. 点击下一步，展示 F₃=2f，讲解"动滑轮反向使用费力，F₃ 是摩擦力的两倍"
  5. 点击下一步，展示排序和正确选项，总结"F₂ < F₁ < F₃，选 D"

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript。理由：条形图结构简单，无需复杂库；SVG 便于精确控制坐标和动画；原生 JS 足够实现分步状态切换
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |            拉力大小比较 (标题 y=45)              |
  |                                                  |
  |  f 条  [========] f (y=100-140)                 |
  |                                                  |
  |  F₁条  [========] f (y=160-200)                 |
  |                                                  |
  |  F₂条  [====] f/2 (y=220-260)                   |
  |                                                  |
  |  F₃条  [================] 2f (y=280-320)        |
  |                                                  |
  |        F₂ → F₁ → F₃ (排序箭头 y=360-380)        |
  |            F₂ < F₁ < F₃ (y=390)                 |
  |                                                  |
  |  [A]    [B]    [C]    [D]★ (选项 y=410-430)     |
  |                                                  |
  |  [◀上一步] [2/5] [下一步▶] (控件 y=450-480)    |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用 currentStep 变量 (0-4) 跟踪当前步骤，steps 数组存储每步显示的元素 ID 列表
  2. 坐标计算：所有条形左对齐 x=200，高度 40px，垂直间距 20px
  3. 动画曲线：条形使用 CSS transition: width 0.5s ease-out 实现长度动画
  4. 事件绑定：按钮点击事件切换步骤，更新元素 display 属性和步骤指示器
  5. 边界处理：步骤 0 禁用「上一步」，步骤 4 禁用「下一步」
- ID 命名规范：所有交互元素 ID 必须以 scene2- 为前缀
  - scene2-title, scene2-bar-f, scene2-bar-f1, scene2-bar-f2, scene2-bar-f3
  - scene2-label-f, scene2-label-f1, scene2-label-f2, scene2-label-f3
  - scene2-arrow-sort, scene2-text-sort, scene2-option-d
  - scene2-btn-prev, scene2-btn-next, scene2-step-indicator
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
