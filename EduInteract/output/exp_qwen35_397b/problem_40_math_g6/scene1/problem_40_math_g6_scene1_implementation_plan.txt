[图示主题与整合说明]
- 本图示主题：正方体三个可见面的空间关系展示
- 整合的内容：展示立体图、标注三个面的图案、高亮相邻关系
- 教学价值：教师可通过分步高亮引导学生观察正方体的面与面之间的位置关系，理解"相邻面"概念，为后续判断平面展开图做铺垫。学生能直观看到顶面、正面、右侧面三个面的相对位置和图案对应关系。

[视觉元素清单]
- 正方体立体图：使用 SVG path 绘制等轴测视图，三个可见面分别绘制
  - 顶面：平行四边形，填充 #fff9c4 透明度 30%，轮廓 #000000 2px
  - 正面：平行四边形，填充 #ffcdd2 透明度 30%，轮廓 #000000 2px
  - 右侧面：平行四边形，填充 #c8e6c9 透明度 30%，轮廓 #000000 2px
- 图案：使用 emoji 或 SVG 简笔画
  - 太阳：☀️ 或黄色圆形 + 射线
  - 爱心：❤️ 或红色心形路径
  - 笑脸：😊 或黄色圆形 + 眼睛 + 嘴巴
- 高亮边框：#1565c0 实线 3px，沿对应面轮廓外扩绘制
- 箭头：#1565c0 实线 2px，带三角形箭头
- 标签：黑色文字 14px，置于各面外侧空白区域

[分步序列]
- 初始状态（步骤 0）：显示正方体立体图（三个面及轮廓），显示三个图案（太阳、爱心、笑脸），显示三个面标签（顶面、正面、右侧面），高亮框和箭头隐藏
- 步骤 1：点击「下一步」→ 显示顶面高亮框（#1565c0 3px），其他元素保持
- 步骤 2：点击「下一步」→ 隐藏顶面高亮框，显示正面高亮框
- 步骤 3：点击「下一步」→ 隐藏正面高亮框，显示右侧面高亮框
- 步骤 4：点击「下一步」→ 隐藏右侧面高亮框，显示三个箭头（标注三面相邻关系），显示"三面相邻"标签
- 教师可随时点击「上一步」回退复习

[标签冲突检查]
- 标签"顶面"：坐标 (400, 95)
- 标签"正面"：坐标 (290, 200)
- 标签"右侧面"：坐标 (540, 200)
- 标签"三面相邻"：坐标 (400, 250)
- 图案"太阳"：坐标 (400, 135)
- 图案"爱心"：坐标 (340, 200)
- 图案"笑脸"：坐标 (440, 200)

冲突检查：
- "顶面"(400,95) 与 "太阳"(400,135)：垂直间距 40px → 无冲突
- "正面"(290,200) 与 "爱心"(340,200)：水平间距 50px → 无冲突
- "右侧面"(540,200) 与 "笑脸"(440,200)：水平间距 100px → 无冲突
- "三面相邻"(400,250) 与 正方体底部 (y≈320)：间距 70px → 无冲突
- 三个面标签分别位于上、左、右三个方向，互不干扰 → 无冲突

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮：位于 (280, 455)，100×30px，点击后切换到前一状态
  - 下一步按钮：位于 (420, 455)，100×30px，点击后切换到下一状态
  - 步骤指示：位于 (400, 490)，显示当前步骤序号
- 教师操作流程：
  1. 初始展示正方体，让学生观察三个可见面
  2. 点击「下一步」高亮顶面，提问"顶面是什么图案？"
  3. 点击「下一步」高亮正面，提问"正面是什么图案？"
  4. 点击「下一步」高亮右侧面，提问"右侧面是什么图案？"
  5. 点击「下一步」显示箭头，总结"这三个面是相邻的，不是相对的"

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +------------------------------------------+
  |                                          |
  |              [顶面标签]                   |
  |                  ☀️                      |
  |            ┌──────────┐                  |
  |            │  顶面    │                  |
  |    [正面]  │  太阳    ├──────┐           |
  |     ❤️     │          │      │ [右侧面]  |
  |            ├──────────┤ 笑脸 │   😊      |
  |     爱心   │  正面    │      │           |
  |            │          │      │           |
  |            └──────────┴──────┘           |
  |                                          |
  |              三面相邻                     |
  |                                          |
  |         [◀上一步]  [下一步▶]             |
  |              步骤 X/4                    |
  +------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentState (0-4) 跟踪当前步骤
  2. 各元素用 scene1- 前缀命名 ID，如 scene1-top-face, scene1-highlight-top 等
  3. 高亮框初始 display="none"，根据 currentState 切换显示
  4. 箭头组初始 display="none"，仅在步骤 4 显示
  5. 按钮点击事件更新 currentState，调用 updateView() 刷新显示
  6. 边界检查：步骤 0 时禁用上一步，步骤 4 时禁用下一步
- ID 命名规范：所有元素 ID 以 scene1- 为前缀
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中
