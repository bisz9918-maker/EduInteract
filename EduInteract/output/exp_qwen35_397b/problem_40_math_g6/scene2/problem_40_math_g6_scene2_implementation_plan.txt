- 本图示主题：正方体展开图与"对面"概念
- 整合内容：展示正方体展开过程、说明对面图案相同的含义、标注六面图案分布

[视觉元素清单]
- 正方体立体图：3D 透视绘制，显示三个可见面（顶面太阳、前面爱心、右面笑脸）
- 展开图：十字形布局，6 个正方形面
- 太阳图案：☀️ 或 SVG 绘制，填充#fff9c4 透明度 30%
- 爱心图案：❤️ 或 SVG 绘制，填充#ffcdd2 透明度 30%
- 笑脸图案：😊 或 SVG 绘制，填充#c8e6c9 透明度 30%
- 展开动画路径：蓝色虚线#1565c0，显示面的移动轨迹
- 对面连接虚线：灰色#888888 虚线 2px
- 轮廓线：黑色#000000 实线 2px

[分步序列]
- 初始状态（步骤 0）：显示完整正方体立体图（左侧），右侧展开图区域空白，中间显示展开箭头（半透明）
- 步骤 1：正方体顶面（太阳）沿动画路径移动到展开图顶部位置，底面（太阳）出现在展开图底部，两个太阳面之间出现灰色虚线连接，标注"太阳↔太阳"
- 步骤 2：正方体左面（爱心）和右面（爱心）展开到展开图中行左右位置，两个爱心面之间出现灰色虚线连接，标注"爱心↔爱心"
- 步骤 3：正方体前面（笑脸）和后面（笑脸）展开到展开图中行中间和最右位置，两个笑脸面之间出现灰色虚线连接，标注"笑脸↔笑脸"
- 步骤 4：所有展开路径虚线高亮显示，完整展示十字形展开图，三个对面连接虚线全部显示，"对面"标签高亮

[标签冲突检查]
- 标签"太阳↔太阳"：坐标(490,90) - 在顶行太阳面上方
- 标签"爱心↔爱心"：坐标(370,220) - 在左爱心面左侧
- 标签"笑脸↔笑脸"：坐标(690,220) - 在右笑脸面右侧
- 标签"对面"：坐标(600,320) - 在展开图右下角
- 检查：各标签间距均≥30px，无冲突

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 底部左侧 (20,455)，返回上一状态
  - 「下一步」按钮：位于 SVG 底部右侧 (700,455)，进入下一状态
  - 步骤指示器：位于底部中央 (380,455)，显示"步骤 X/4"
- 教师操作流程：
  1. 初始展示正方体，讲解题目条件"对面图案相同"
  2. 点击「下一步」逐步展开，每步暂停讲解对应面的位置关系
  3. 最终步骤展示完整展开图，用虚线强调对面关系
  4. 可点击「上一步」回退复习关键步骤

[技术实现]
- JS 库选择：原生 SVG（几何图形绘制简单，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +------------------+-----------------------+
  |   正方体立体图    |      展开图区域        |
  |   (80,150)       |   (370,100)-(690,340) |
  |   180×180        |   十字形 6 面          |
  +------------------+-----------------------+
  |        ← 展开箭头 (340,240) →            |
  +------------------------------------------+
  | [◀上一步]    步骤 X/4    [下一步▶]       |
  | (控件栏 y=440~490)                       |
  +------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentState 跟踪当前步骤（0-4）
  2. 每个面的初始位置（正方体上）和最终位置（展开图上）预先计算
  3. 动画使用 CSS transition 或 requestAnimationFrame 实现平滑移动
  4. 每个步骤显示/隐藏对应元素，通过 opacity 和 transform 控制
  5. 对面虚线在对应步骤后逐步显示
- ID 命名规范：所有元素 ID 以 scene2- 为前缀（如 scene2-cube、scene2-net-sun-top、scene2-btn-next）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
