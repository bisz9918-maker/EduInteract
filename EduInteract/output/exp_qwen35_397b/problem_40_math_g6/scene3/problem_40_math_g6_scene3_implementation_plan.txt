[交互方案]
- 交互类型：多状态切换（4 个按钮 A/B/C/D）
- 控件说明：
  - 按钮 A：位于(150,450)，点击后展示选项 A 的展开图及折叠结果
  - 按钮 B：位于(250,450)，点击后展示选项 B 的展开图及折叠结果
  - 按钮 C：位于(350,450)，点击后展示选项 C 的展开图及折叠结果
  - 按钮 D：位于(450,450)，点击后展示选项 D 的展开图及折叠结果
- 教师操作流程：
  1. 初始状态默认显示选项 A
  2. 点击不同按钮切换选项，观察展开图布局
  3. 观察折叠动画，理解展开图如何形成正方体
  4. 对比折叠后的三面关系与题目正方体是否一致
  5. 通过正确/错误标记确认答案

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  ┌────────────────────────────────────────────┐
  │  [展开图区域 y=50~200]                     │
  │     □□□□□  (十字形展开图)                  │
  │         □                                  │
  ├────────────────────────────────────────────┤
  │  [正方体区域 y=250~400]                    │
  │        ╱╲                                  │
  │       ╱顶╲  ← 顶面标签                      │
  │      ╱____╲                                │
  │     ╱正  ╱右 ╲  ← 正面/右面标签              │
  │    ╱____╱____╲  [✓/✗]                      │
  ├────────────────────────────────────────────┤
  │  [按钮区 y=440~490]                        │
  │     [A]  [B]  [C]  [D]                     │
  └────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用 currentState 变量跟踪当前选中选项（'A'/'B'/'C'/'D'）
  2. 展开图数据：用对象存储四个选项的 6 个面图案配置
  3. 折叠动画：用 CSS transform 实现各面绕边旋转 90 度
  4. 正方体绘制：用 SVG polygon 绘制等轴测投影的三个可见面
  5. 事件绑定：四个按钮分别绑定点击事件，调用 updateScene(option) 函数
  6. 高亮切换：当前选中按钮背景色改为 #1565c0，其余恢复 #e0e0e0
- ID 命名规范：所有元素 ID 以 scene3- 为前缀
  - scene3-expansion-group：展开图容器
  - scene3-cube-group：正方体容器
  - scene3-btn-a/b/c/d：四个选项按钮
  - scene3-result-mark：正确/错误标记
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
