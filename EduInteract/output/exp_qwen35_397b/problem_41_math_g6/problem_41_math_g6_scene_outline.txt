    **题目原文：**

    如图，晚上小亮在路灯下散步，在小亮由 A 点走向 B 点的过程中，他在地上的影子 (    )。

    A．逐渐变短    B．逐渐变长    C．先变短后变长    D．先变长后变短

    **题目分析：**

    本题考查中心投影（点光源）下物体影子长度的变化规律。路灯可视为点光源，光线从灯泡发出沿直线传播，经过人的头顶后投射到地面形成影子。

    **核心知识点：**
    1. 中心投影原理：点光源发出的光线呈放射状
    2. 影子形成：光线被不透明物体遮挡，在背光侧形成阴影区域
    3. 影子长度与物体到光源水平距离的关系

    **整体讲解思路：**

    1. 首先让学生观察题目原图，明确小亮的运动路径：从 A 点（路灯左侧）→ 路灯正下方 → B 点（路灯右侧）

    2. 分析影子形成原理：从灯泡引一条光线经过人的头顶，延长线与地面的交点即为影子的端点

    3. 分阶段讨论：
       - 阶段 1：小亮从 A 走向路灯 → 离光源水平距离减小 → 影子逐渐变短
       - 阶段 2：小亮在路灯正下方 → 影子最短（理论上为零）
       - 阶段 3：小亮从路灯走向 B → 离光源水平距离增大 → 影子逐渐变长

    4. 结论：影子长度先变短后变长，选 C

    **图示规划说明：**

    设计一个交互式图示，用拖拽滑块让小亮从 A 点移动到 B 点，实时展示影子长度的连续变化过程。教师可拖动滑块或点击播放动画，让学生直观观察影子"先变短后变长"的规律。
    </TEXT_1>

    **本图示教学说明：**

    **如何引导学生观察：**

    1. **初始观察**：先不拖动，让学生看 A 点位置的影子，提问"影子是怎么形成的？"引导学生说出"光线被身体挡住"

    2. **预测环节**：在拖动前，先让学生猜想"小亮往前走，影子会怎么变？"记录学生的不同想法

    3. **拖动演示**：缓慢拖动滑块，让学生观察：
       - 光线路径的变化（红色虚线角度在变）
       - 影子长度的变化（先缩短）
       - 经过路灯下方时的状态（影子最短）
       - 继续向右移动的变化（影子变长，且方向相反）

    4. **关键提问**：
       - "什么时候影子最短？"（路灯正下方）
       - "为什么影子会先变短后变长？"（离光源的水平距离先减小后增大）
       - "影子的方向有变化吗？"（有，过路灯后方向相反）

    **讲解要点：**

    1. 强调这是"中心投影"，光源是点光源（路灯），不是平行光（太阳光）

    2. 影子长度取决于：光源高度、人的高度、人到光源的水平距离

    3. 定性规律：同一光源、同一人，离光源水平距离越近，影子越短

    **公式推导（可选，针对程度较好的学生）：**

    设路灯高度为 $H$，人的高度为 $h$，人到路灯的水平距离为 $x$，影子长度为 $s$。

    由相似三角形可得：
    $$\frac{H}{h} = \frac{x + s}{s}$$

    解得：
    $$s = \frac{h \cdot x}{H - h}$$

    当 $x$ 先减小后增大时，$s$ 也先减小后增大。

    **总结与课堂讲解建议：**

    **完整解答：**

    小亮从 A 点走向 B 点的过程中：
    - 从 A 到路灯：离光源越来越近 → 影子逐渐变短
    - 在路灯正下方：影子最短
    - 从路灯到 B：离光源越来越远 → 影子逐渐变长

    因此影子长度**先变短后变长**，答案选 **C**。

    **课堂讲解建议：**

    1. **先用 SCENE_1 建立直观感知**：拖动滑块让学生亲眼看到影子变化，这是最重要的环节

    2. **再用 SCENE_2 抽象为函数图像**：帮助学生从"看到变化"上升到"理解变化规律"，培养数形结合思想

    3. **联系生活实际**：可提问"傍晚在路灯下走路，你有注意到影子变化吗？"让学生将数学与生活联系起来

    4. **拓展思考**（针对学有余力的学生）：
       - 如果是太阳光（平行光），影子长度会变化吗？（不会，因为太阳光是平行光）
       - 如果路灯更高或更矮，影子变化规律会变吗？（规律不变，但具体长度会变）

    **易错点提醒：**

    - 学生可能误选 D（先变长后变短），原因是没有考虑小亮会经过路灯下方
    - 强调运动路径是 A→路灯→B，不是 A→远离路灯
