[图示主题与整合说明]
- 本图示主题：小亮从 A 到 B 运动过程中影子长度的连续变化
- 整合的内容：影子形成原理（光线传播路径）、小亮在多个位置的影子状态、影子长度变化趋势
- 教学价值：教师可拖动滑块让学生实时观察影子长度随位置连续变化，直观理解中心投影原理，验证"先变短后变长"的结论。关键位置（路灯正下方）可高亮提示，帮助学生建立空间想象与数学结论的联系。

[分步序列]
本场景为连续拖拽交互，无分步导航。状态定义如下：

- 初始状态（小亮在 A 点）：
  - 小亮位于 x=100（A 点右侧 20px 处，避免遮挡 A 标签）
  - 光线从灯泡(575,125)→小亮头顶(115,340)→地面影子端点
  - 影子线段从(115,400)到影子端点，长度约 180px
  - 影子长度数值显示在影子下方
  - 滑块手柄位于轨道左端

- 拖动过程（实时计算）：
  - 小亮 x 坐标随滑块手柄位置变化（范围 100~700）
  - 光线重新计算：使用相似三角形原理
    - 设灯泡高度 H=275px（400-125），小亮高度 h=60px
    - 小亮与路灯水平距离 d = |550 - 人形 x|
    - 影子长度 L = d * h / (H - h) = d * 60 / 215
    - 影子方向：若小亮在路灯左侧，影子向左延伸；若在右侧，影子向右延伸
  - 影子线段和填充区实时更新
  - 影子长度数值动态更新
  - 当小亮经过 x=550（路灯正下方）时：
    - 最短位置高亮圆环显示
    - "最短"提示文本显示
    - 影子长度接近 0

- 最终状态（小亮在 B 点）：
  - 小亮位于 x=700（B 点左侧 20px 处）
  - 影子向右延伸，长度约 180px
  - 滑块手柄位于轨道右端

[标签冲突检查]
列出所有标签名及其预计坐标，逐对检查间距：

| 标签名 | 坐标 (x,y) | 备注 |
|--------|-----------|------|
| A | (70,420) | A 点下方 |
| B | (710,420) | B 点下方 |
| 光源 | (560,100) | 灯泡上方 |
| 影子长度数值 | 动态，约 (人形 x+影子长度/2, 425) | 影子下方 |
| 最短 | (550,375) | 路灯垂足上方 |
| 滑块标签 | (400,485) | 底部中央 |

冲突检查：
- A(70,420) 与 B(710,420)：水平距离 640px → 无冲突
- A(70,420) 与 光源(560,100)：距离远 → 无冲突
- B(710,420) 与 光源(560,100)：距离远 → 无冲突
- 影子长度数值(动态,425) 与 A/B 标签(420)：垂直距离 5px，但影子数值在影子下方中央，A/B 在端点下方，水平位置不重叠 → 需确保影子数值 y=430 以下
- 最短(550,375) 与 光源(560,100)：垂直距离 275px → 无冲突
- 滑块标签(400,485) 与其他所有标签：垂直距离 ≥55px → 无冲突

解决方案：
- 影子长度数值 y 坐标设为 430，确保与 A/B 标签(420) 有 10px 垂直间隙
- 当小亮接近 A 或 B 时，影子数值可能靠近 A/B 标签，此时将影子数值 y 设为 435 增加间隙

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：
  - 滑块轨道：水平线段 (200,460)-(600,460)，表示小亮从 A 到 B 的运动范围
  - 滑块手柄：圆形，可左右拖拽，控制小亮位置
  - 滑块标签："小亮位置：A ←→ B"，位于轨道下方
- 教师操作流程：
  1. 初始状态展示小亮在 A 点，影子较长
  2. 缓慢向右拖动滑块，让学生观察影子逐渐变短
  3. 经过路灯正下方时暂停，强调"此处影子最短"
  4. 继续向右拖动，观察影子逐渐变长
  5. 到达 B 点时，影子长度与 A 点相近
  6. 可反复拖动，让学生总结规律

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript
  - 几何图形简单（线段、圆形、折线），原生 SVG 足够
  - 拖拽交互用原生事件处理即可
  - 无需引入重型库，保持代码轻量

- 画布尺寸：800 × 500 px（spec.json 规定）

- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +----------------------------------------------------------+
  |                                                          |
  |                    光源 (灯泡)                            |
  |                       ●                                  |
  |                      /                                   |
  |                     |                                    |
  |                     | 路灯杆                              |
  |                     |                                    |
  |    小亮              |                                    |
  |    ███              |                                    |
  |    ███  光线→\       |                                    |
  |    ███       \      |                                    |
  |    ███        \     |                                    |

  |    A           影子  路灯垂足                          B    |
  |                                                          |
  |                                                          |
  |         [━━━━━━━━━━━━━━●━━━━━━━━━━━━━━]                  |
  |              小亮位置：A ←→ B                            |
  +----------------------------------------------------------+
  ```

- 关键实现要点：
  1. 状态机设计：单一状态（小亮 x 坐标），所有视觉元素基于此坐标计算
  2. 坐标计算：
     - 灯泡位置：(575, 125)
     - 小亮头顶：(personX, 340)，脚部：(personX, 400)
     - 相似三角形计算影子端点：
       - 若 personX < 550（路灯左侧）：影子向左
         shadowEndX = personX - (550 - personX) * 60 / 215
       - 若 personX > 550（路灯右侧）：影子向右
         shadowEndX = personX + (personX - 550) * 60 / 215
  3. 光线路径：灯泡 → 小亮头顶 → 影子端点（折线）
  4. 动画曲线：拖拽为实时响应，无需动画曲线
  5. 事件绑定：
     - 滑块手柄：mousedown/touchstart 开始拖拽，mousemove/touchmove 更新位置，mouseup/touchend 结束
     - 边界限制：手柄 x 范围 [200, 600]，映射到小亮 x 范围 [100, 700]

- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀
  - scene1-ground（地面线）
  - scene1-point-a（A 点）
  - scene1-label-a（A 标签）
  - scene1-point-b（B 点）
  - scene1-label-b（B 标签）
  - scene1-lamp-pole（路灯杆）
  - scene1-lamp-bulb（灯泡）
  - scene1-label-light（光源标签）
  - scene1-person（小亮人形组）
  - scene1-light-ray（光线）
  - scene1-shadow-line（影子线段）
  - scene1-shadow-fill（影子填充区）
  - scene1-label-shadow-length（影子长度数值）
  - scene1-slider-track（滑块轨道）
  - scene1-slider-handle（滑块手柄）
  - scene1-label-slider（滑块标签）
  - scene1-min-marker（最短位置高亮）
  - scene1-label-min（最短提示文本）

- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
