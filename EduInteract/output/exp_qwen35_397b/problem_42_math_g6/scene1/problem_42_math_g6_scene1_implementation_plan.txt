[图示主题与整合说明]
- 本图示主题：三视图含义解析与底层布局确定
- 整合的内容：三个视图的展示、俯视图网格标注、各视图与立体位置的对应关系
- 教学价值：教师可逐步引导学生理解三视图的空间对应关系，从俯视图建立底层认知，再通过主视图和左视图确定各位置的高度，最终推导出正方体总数。分步展示帮助学生建立空间想象力。

[视觉元素清单]
- 主视图：由4个小正方形组成，左列2个叠放(60,50)-(90,110)，中列1个(90,80)-(120,110)，右列1个(120,80)-(150,110)，轮廓线#000000 2px
- 左视图：由3个小正方形组成，左列2个叠放(260,50)-(290,110)，右列1个(290,80)-(320,110)，轮廓线#000000 2px
- 俯视图（上方）：4个小正方形，第一行3个(460,50)-(540,80)，第二行1个(460,80)-(490,110)，轮廓线#000000 2px
- 下方俯视图网格：2行3列布局，实际显示4个格子（第2行第2、3列不显示），填充#1565c0 透明度20%，轮廓线#000000 1px
- 位置标签A/B/C/D：黑色加粗文字，位于各格子中心
- 对应关系虚线：#888888 虚线，连接上方视图与下方网格
- 高度标注：步骤4显示，标注每个位置的正方体数量
- 高亮元素：#2e7d32 绿色，用于当前步骤强调

[分步序列]
- 初始状态（步骤0）：显示上方三个视图（主视图、左视图、俯视图）及其标题，下方区域空白
- 步骤1：点击「下一步」→ 下方显示俯视图网格（4个格子），填充#1565c0 20%透明度，显示位置标签A、B、C、D
- 步骤2：点击「下一步」→ 显示主视图与俯视图的对应关系虚线（3条），主视图第1列高亮#2e7d32，位置A、D列高亮
- 步骤3：点击「下一步」→ 显示左视图与俯视图的对应关系虚线（2条），左视图高亮#2e7d32，位置A/B/C行和D行分别高亮
- 步骤4：点击「下一步」→ 显示各位置高度标注（A:2, B:1, C:1, D:1），计算总数2+1+1+1=5，显示结论「共5个正方体」

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮：位于(250, 455)，100×36px，点击返回上一状态
  - 下一步按钮：位于(450, 455)，100×36px，点击进入下一状态
  - 步骤指示器：位于(400, 470)，显示当前步骤/总步骤数
- 教师操作流程：
  1. 初始展示三个视图，让学生观察
  2. 点击下一步，展示俯视图网格和位置标注，建立空间基准
  3. 点击下一步，通过虚线连接主视图与俯视图，讲解列对应关系
  4. 点击下一步，通过虚线连接左视图与俯视图，讲解行对应关系
  5. 点击下一步，显示各位置高度，引导学生计算总数

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript。原因：几何图形简单，无需复杂库；SVG 便于精确控制坐标和样式；原生 JS 足够实现分步状态切换
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +----------------------------------------------------------+
  |  从正面看    从左边看    从上面看                          |
  |  [主视图]    [左视图]    [俯视图]                          |
  |     |          |           |                              |
  |     |虚线      |虚线       |虚线                           |
  |     ↓          ↓           ↓                              |
  |        +-------------------+                               |
  |        |  A  |  B  |  C  |  ← 俯视图网格                   |
  |        |  D  |     |     |                                 |
  |        +-------------------+                               |
  |                                                            |
  |  [高度标注：A=2, B=1, C=1, D=1]（步骤4显示）                |
  |                                                            |
  |  +------------------------------------------------------+  |
  |  |          [◀上一步]  步骤X/5  [下一步▶]               |  |
  |  +------------------------------------------------------+  |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-4) 跟踪当前步骤，数组存储各步骤的可见元素ID列表
  2. 坐标计算：所有元素使用绝对坐标（SVG viewBox="0 0 800 500"）
  3. 动画曲线：元素淡入使用 CSS transition opacity 0.3s ease
  4. 事件绑定：按钮点击事件切换状态，更新可见元素集合
  5. 步骤边界：步骤0时禁用上一步按钮，步骤4时禁用下一步按钮
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀（如 scene1-main-view, scene1-pos-A, scene1-dash-line-1）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
