[分步序列]
- 初始状态（步骤 0）：显示完整生命周期循环图（4 节点 +5 箭头），所有节点默认填充#e3f2fd，中部插图区空白，底部显示"家蚕生命周期"
- 步骤 1：点击「下一步」→ 节点 A 高亮（填充#1565c0），中部显示卵形态插图（椭圆形，浅黄色），底部显示"阶段 A：卵（受精卵）"
- 步骤 2：点击「下一步」→ 节点 B 高亮，中部显示幼虫形态插图（蚕宝宝，白色带环节），底部显示"阶段 B：幼虫（蚕宝宝）"，左下角显示绿色提示框"延长 B 时期→增加蚕丝产量"，幼虫插图旁添加吐丝动作示意（虚线螺旋）
- 步骤 3：点击「下一步」→ 节点 D 高亮，中部显示蛹形态插图（茧内蛹，椭圆形茧，浅棕色），底部显示"阶段 D：蛹（茧内）"，提示框隐藏
- 步骤 4：点击「下一步」→ 节点 C 高亮，中部显示成虫形态插图（蚕蛾，白色带翅膀），底部显示"阶段 C：成虫（蚕蛾）"
- 步骤 5：点击「下一步」→ 所有节点恢复默认，中部显示总结文字"选项 C 正确：家蚕幼虫期吐丝结茧，延长 B 时期可增加蚕丝产量"，绿色对勾图标显示

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 上一步按钮：位于 (280,470)，尺寸 100×25，文字"◀ 上一步"，点击返回上一状态
  - 下一步按钮：位于 (400,470)，尺寸 100×25，文字"下一步 ▶"，点击进入下一状态
  - 步骤指示器：位于 (520,485)，显示"步骤 X/5"，只读
- 教师操作流程：
  1. 初始展示完整生命周期图，让学生观察整体结构
  2. 点击「下一步」依次展示各阶段形态，配合讲解各阶段特征
  3. 步骤 2 重点强调幼虫期与蚕丝产量的关系，解释为何延长 B 时期可增加产量
  4. 步骤 5 总结验证选项 C 正确性
  5. 可随时点击「上一步」回退复习关键概念

[技术实现]
- JS 库选择：原生 SVG（简单几何图形和箭头路径）+ 原生 JavaScript（状态管理）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |              生命周期循环图 (500×300)            |
  |                    A(卵)                         |
  |                   /     \                        |
  |              B(幼虫)   C(成虫)                   |
  |                   \     /                        |
  |                    D(蛹)                         |
  |                                                  |
  |           [阶段形态插图区 300×50]                |
  |                                                  |
  |    [蚕丝产量提示框]        [阶段名称标签]        |
  |                                                  |
  |         [◀上一步] [下一步▶]  [步骤 X/5]          |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-5），数组存储各状态配置
  2. 坐标计算：节点位置固定，箭头路径使用二次贝塞尔曲线使箭头更自然
  3. 动画曲线：节点高亮使用 CSS transition，0.3s ease-in-out
  4. 事件绑定：按钮点击事件绑定到状态切换函数，边界检查（步骤 0 禁用上一步，步骤 5 禁用下一步）
  5. 插图渲染：使用 SVG <image> 或 <g> 组合绘制简化的昆虫形态（卵=椭圆，幼虫=多节蠕虫，蛹=茧椭圆，成虫=蛾形）
- ID 命名规范：所有交互元素 ID 必须以 scene2- 为前缀
  - scene2-cycle-group（生命周期图组）
  - scene2-node-a, scene2-node-b, scene2-node-d, scene2-node-c（4 个节点）
  - scene2-arrow-ab, scene2-arrow-bd, scene2-arrow-dc, scene2-arrow-ca, scene2-arrow-da（5 条箭头）
  - scene2-illustration（阶段插图区）
  - scene2-stage-label（阶段名称标签）
  - scene2-silk-tip（蚕丝产量提示框）
  - scene2-btn-prev, scene2-btn-next（导航按钮）
  - scene2-step-indicator（步骤指示器）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
- 按钮状态管理：步骤 0 时上一步按钮 disabled，步骤 5 时下一步按钮 disabled，视觉灰度处理
