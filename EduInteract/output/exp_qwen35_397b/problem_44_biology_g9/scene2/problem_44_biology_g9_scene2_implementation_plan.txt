[分步序列]
多状态切换模式（4 个状态，点击按钮切换）：

状态 0（初始/默认）：显示基础模型，无特定状态高亮
- 显示：甲→乙→丙基础血流模型
- 乙框内显示"乙"
- 血液成分区显示"请选择下方按钮查看具体情况"
- 选项判断区空白

状态 1（毛细血管网）：
- 乙框内：绘制毛细血管网示意图（网状结构，红色→蓝色渐变）
- 乙标签："毛细血管网"
- 甲血管：红色（动脉血），标签"甲（动脉血）"
- 丙血管：蓝色（静脉血），标签"丙（静脉血）"
- 血液成分区：显示"气体交换：氧气减少，二氧化碳增加"
- 选项判断：A 选项 ✓（正确）

状态 2（小肠）：
- 乙框内：绘制小肠绒毛结构（指状突起）
- 乙标签："小肠毛细血管"
- 甲血管：红色（动脉血），标签"甲（动脉血）"
- 丙血管：蓝色（静脉血，含营养颗粒），标签"丙（静脉血，营养↑ 氧气↓）"
- 血液成分区：显示"营养物质增加（吸收），氧气减少（消耗）"
- 选项判断：B 选项 ✗（错误，含氧量应减少而非增加）

状态 3（肾小球）：
- 乙框内：绘制肾小球毛细血管球（球状缠绕）
- 乙标签："肾小球"
- 甲血管：红色（入球小动脉），标签"甲（入球小动脉）"
- 丙血管：红色（出球小动脉），标签"丙（出球小动脉）"
- 血液成分区：显示"过滤作用：血液成分基本不变（仍为动脉血）"
- 选项判断：C 选项 ✗（错误，丙是出球小动脉而非静脉）

状态 4（胰岛）：
- 乙框内：绘制胰岛细胞团（细胞簇）
- 乙标签："胰岛"
- 甲血管：红色（动脉血），标签"甲（动脉血）"
- 丙血管：蓝色（静脉血，含激素颗粒），标签"丙（静脉血，胰岛素↑）"
- 血液成分区：显示"激素分泌：胰岛素增加（血糖调节）"
- 选项判断：D 选项 ✓（正确）

[交互方案]
- 交互类型：多状态切换（4 个按钮）
- 控件说明：
  - 按钮 1「毛细血管网」：切换至状态 1，展示毛细血管网血流变化
  - 按钮 2「小肠」：切换至状态 2，展示小肠吸收营养的血流变化
  - 按钮 3「肾小球」：切换至状态 3，展示肾小球过滤的血流变化
  - 按钮 4「胰岛」：切换至状态 4，展示胰岛分泌激素的血流变化
- 教师操作流程：
  1. 初始展示基础模型，介绍甲→乙→丙的血流方向
  2. 依次点击 4 个按钮，每种情况讲解：
     - 乙结构的特点
     - 血液成分如何变化
     - 对应选项为何正确/错误
  3. 可反复切换对比，强化学生对不同器官血流特点的理解

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  ┌────────────────────────────────────────────────────┐
  │  甲        ┌──────乙──────┐        丙             │ y=80~160
  │  →        │              │        →               │
  │           └──────────────┘                        │
  │                                                    │
  │  ┌──────────────────────────────────────────┐     │ y=180~320
  │  │         乙结构细节图（动态变化）          │     │
  │  └──────────────────────────────────────────┘     │
  │                                                    │
  │  血液成分变化说明（动态文本）                      │ y=340~420
  │  选项判断：A ✓/✗（动态标记）                       │ y=420~440
  │                                                    │
  │  [毛细血管网] [小肠] [肾小球] [胰岛]               │ y=455~490
  └────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用 currentState 变量（0~4）跟踪当前状态
  2. 每个状态对应一个 updateState() 函数，更新乙细节图、标签、血液成分、选项判断
  3. 按钮点击事件绑定，点击后高亮当前按钮（背景色变化），调用对应状态更新
  4. 乙细节图用 SVG 路径绘制：毛细血管网（网状）、小肠绒毛（指状）、肾小球（球状缠绕）、胰岛（细胞簇）
  5. 血管颜色动态切换：用 class 或 style 填充色
  6. 选项判断用✓/✗符号，颜色区分（绿色✓ 红色✗）
- ID 命名规范：所有交互元素 ID 必须以 scene2- 为前缀
  - scene2-vessel-甲, scene2-vessel-丙
  - scene2-organ-乙
  - scene2-detail-area
  - scene2-blood-info
  - scene2-option-result
  - scene2-btn-capillary, scene2-btn-intestine, scene2-btn-glomerulus, scene2-btn-islet
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中
