problem_45_biology_g9

场景导航：Scene 1 | Scene 2 | Scene 3

题目原文：

下图是血液流经某器官的示意图，下列表述正确的是（ ）

图中显示血液从血管 a 流入器官 b，再从血管 c 流出。

A．b 表示心脏，则 c 血管里流的是静脉血
B．b 表示肺，则 c 血管里流的是静脉血
C．b 表示小肠，则 c 血管里流的是动脉血
D．b 表示组织细胞，则 c 血管里流的是静脉血

题目分析：

本题考查血液循环中不同器官对血液性质的影响。核心知识点是：

  • 动脉血：含氧丰富，颜色鲜红
  • 静脉血：含氧较少，颜色暗红
  • 不同器官处发生的气体交换方向不同

整体讲解思路：

  1. 首先理解题目图示结构：a 为流入血管，b 为器官，c 为流出血管
  2. 逐一分析四个选项中器官处的血液变化
  3. 对比得出结论

图示规划说明：

  • SCENE_1：展示题目基础图示，标注血流方向和血管名称
  • SCENE_2：用多状态切换对比四种器官情况下血液性质的变化
步骤 1/5

教学说明：

本图示用于帮助学生建立对题目基本结构的理解。教师应引导学生：

  1. 观察血流方向：箭头从 a 指向 b 再指向 c，说明血液流动路径是 a→b→c
  2. 理解符号含义：a 和 c 是血管，b 是某个器官
  3. 明确问题核心：需要判断当 b 为不同器官时，c 中血液的性质

此图示是后续分析的基础，确保学生理解图示结构后再进入具体器官的分析。

教学说明：

本图示是解题的核心，通过对比四种情况帮助学生理解不同器官处的血液变化规律。

各状态讲解要点：

状态 0（心脏）：

  • 心脏本身不改变血液性质，只是泵血
  • 若 b 为心脏，需区分左右心：右心流出静脉血（肺动脉），左心流出动脉血（主动脉）
  • A 选项表述不准确，排除

状态 1（肺）：

  • 肺部发生气体交换：CO₂排出，O₂进入
  • 肺动脉（静脉血）→ 肺毛细血管 → 肺静脉（动脉血）
  • c 中流动脉血，B 选项错误

状态 2（小肠）：

  • 小肠是组织器官，消耗氧气
  • 动脉血→小肠毛细血管→静脉血
  • c 中流静脉血，C 选项错误

状态 3（组织细胞）：

  • 组织细胞消耗氧气，产生 CO₂
  • 动脉血→组织毛细血管→静脉血
  • c 中流静脉血，D 选项正确

关键公式/结论：

血液性质变化规律：

  • 肺部：静脉血 → 动脉血（气体交换，获氧）
  • 全身组织（包括小肠）：动脉血 → 静脉血（气体交换，耗氧）

总结与课堂讲解建议：

完整解答：

正确答案：D

解析：

  1. 当 b 表示心脏时，c 血管可能是动脉血（左心）或静脉血（右心），A 表述不准确
  2. 当 b 表示肺时，经过气体交换，c（肺静脉）流动脉血，B 错误
  3. 当 b 表示小肠时，小肠消耗氧气，c 流静脉血，C 错误
  4. 当 b 表示组织细胞时，组织细胞消耗氧气，c 流静脉血，D 正确

课堂讲解建议：

  1. 先用 SCENE_1 建立图示结构认知
  2. 用 SCENE_2 对比四种情况，引导学生发现规律：
  • 肺部特殊：静脉血变动脉血
  • 其他组织：动脉血变静脉血
  1. 用 SCENE_3 验证正确答案，强化理解
  2. 总结规律：除肺外，血液流经任何组织器官后，氧气减少，由动脉血变为静脉血
