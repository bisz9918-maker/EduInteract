[分步序列]
- 初始状态（步骤 0）：显示基础结构（器官 b 圆形 + 血管 a 左管 + 血管 c 右管，黑色轮廓），仅显示基础标签"a""b""c"（小字号居中/上方），不显示血流箭头和详细标注
- 步骤 1：点击「下一步」→ 显示标注"a 流入血管"（上方(210,180)）+ 虚线引线指向 a，标签"a"高亮为蓝色 #1565c0
- 步骤 2：点击「下一步」→ 显示标注"b 器官"（上方(400,150)）+ 虚线引线指向圆心，标签"b"高亮为蓝色 #1565c0，保留步骤 1 内容
- 步骤 3：点击「下一步」→ 显示标注"c 流出血管"（上方(590,180)）+ 虚线引线指向 c，标签"c"高亮为蓝色 #1565c0，保留步骤 1-2 内容
- 步骤 4：点击「下一步」→ 显示两个蓝色血流箭头（左箭(140,250) 和右箭(620,250)），箭头带轻微脉动动画（opacity 0.7→1.0 循环），完整展示血流方向 a→b→c

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于底部左侧(280,455)，点击回退到前一状态，步骤 0 时禁用（灰色）
  - 「下一步」按钮：位于底部右侧(440,455)，点击进入下一状态，步骤 4 时禁用（灰色）
  - 步骤指示器：底部中央显示「步骤 X/5」
- 教师操作流程：
  1. 初始展示基础结构，提问学生"图中 a、b、c 分别代表什么？"
  2. 点击「下一步」揭示 a 为流入血管，讲解血液流入器官
  3. 点击「下一步」揭示 b 为器官，强调这是血液流经的目标器官
  4. 点击「下一步」揭示 c 为流出血管，讲解血液流出器官
  5. 点击「下一步」显示血流箭头，动态演示血流方向 a→b→c
  6. 可点击「上一步」回退复习任一环节

[技术实现]
- JS 库选择：原生 SVG（简单几何图形首选，无需额外库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |                    b 器官                         |
  |                     (400,150)                    |
  |         a 流入血管              c 流出血管        |
  |          (210,180)               (590,180)       |
  |                                                  |
  |      a        ┌─────────┐         c              |
  |   ───────►    │         │    ───────►            |
  |   (140,250)   │    b    │    (620,250)           |
  |               │ (400,250)│                        |
  |               └─────────┘                        |
  |                                                  |
  |                                                  |
  |                                                  |
  |    [◀上一步]    步骤 X/5    [下一步▶]            |
  |    (280,455)              (440,455)              |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentState(0-4) 跟踪当前步骤，数组 steps[] 定义每步显示的元素 ID 列表
  2. 坐标计算：所有元素坐标硬编码（见布局坐标表），确保无重叠
  3. 动画曲线：步骤 4 的血流箭头用 CSS animation 实现脉动（@keyframes pulse { 0%,100% { opacity: 0.7; } 50% { opacity: 1.0; } }）
  4. 事件绑定：按钮点击事件切换状态，更新显示元素和按钮禁用状态
  5. 元素显隐：用 display:none / display:block 或 opacity 控制元素显隐
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀（如 scene1-organ-b、scene1-vessel-a、scene1-arrow-left、scene1-label-a、scene1-btn-prev、scene1-btn-next）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
