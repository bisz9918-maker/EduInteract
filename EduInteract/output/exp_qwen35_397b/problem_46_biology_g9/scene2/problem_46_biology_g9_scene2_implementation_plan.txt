[图示主题与整合说明]
- 本图示主题：DNA半保留复制过程中同位素标记的传递规律
- 整合的内容：整合了亲代DNA、复制1次、复制2次、复制3次的完整过程，展示¹⁵N和¹⁴N的分布
- 教学价值：教师可通过分步演示，让学生直观理解DNA半保留复制的机制——亲代DNA的两条链分别作为模板，新合成的链使用培养液中的¹⁴N原料。通过树状图展示，学生能清晰看到每一代DNA分子中¹⁵N链的传递规律，最终理解为什么复制3次后含¹⁴N的DNA分子占100%（所有新DNA都含新合成的¹⁴N链）

  - 「上一步」按钮：位于(280,450)，点击后隐藏当前步骤新增的元素，步骤指示器减1

  - 步骤指示器：位于(380,460)，显示当前步骤序号"步骤 X/4"
- 教师操作流程：
  1. 初始状态展示亲代DNA（全¹⁵N标记），讲解实验初始条件
  2. 点击「下一步」展示第1代，讲解半保留复制机制——两条亲代链分开作为模板
  3. 点击「下一步」展示第2代，讲解¹⁵N链的传递规律
  4. 点击「下一步」展示第3代，让学生观察8个DNA中只有2个含¹⁵N链
  5. 点击「下一步」展示统计结果，讲解为什么含¹⁴N的DNA占100%（所有新合成都用¹⁴N原料）
  6. 可点击「上一步」回退复习关键步骤

[技术实现]
- JS库选择及原因：原生SVG + 原生JavaScript。原因：本图示为2D树状结构图，SVG适合绘制DNA双链矩形和连接虚线，无需复杂动画库；原生JS足以处理分步状态切换
- 画布尺寸：800 × 500 px（固定画布）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────────┐
  │                        亲代 DNA                              │ y=40-60
  │                           ↓                                  │
  │                    第1代 DNA ×2                              │ y=130-150
  │                         ↓ ↓                                  │
  │                  第2代 DNA ×4                                │ y=240-260
  │                       ↓ ↓ ↓ ↓                                │
  │                第3代 DNA ×8                                  │ y=360-380
  │                                                              │
  │  ┌─────────────────┐    ┌─────────────────────────────┐      │
  │  │   图例          │    │      统计框                 │      │
  │  │  ■ ¹⁵N标记链    │    │  DNA总数：8个               │      │
  │  │  ■ ¹⁴N标记链    │    │  含¹⁴N的DNA：8个(100%)      │      │
  │  └─────────────────┘    │  含¹⁵N的DNA：2个(25%)       │      │
  │                         │  只含¹⁴N的DNA：6个(75%)     │      │
  │                         └─────────────────────────────┘      │
  │                                                              │
  │              [◀上一步]  步骤 X/4  [下一步▶]                  │ y=450-485
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量currentStep(0-4)跟踪当前步骤，数组steps存储每步需显示的元素ID列表
  2. 坐标计算：DNA分子用<rect>表示双链，每条链用嵌套<rect>或<line>表示，¹⁵N链fill="#1565c0"，¹⁴N链fill="#2e7d32"
  3. 动画曲线：元素出现使用淡入效果（opacity从0到1，transition: opacity 0.3s ease）
  4. 事件绑定：按钮点击事件监听，更新currentStep后调用renderStep()函数显示/隐藏对应元素
  5. 边界处理：步骤0时禁用「上一步」，步骤4时禁用「下一步」
- ID命名规范：所有交互元素ID必须以scene2-为前缀
  - scene2-parent-dna（亲代DNA）
  - scene2-gen1-dna-1, scene2-gen1-dna-2（第1代DNA）
  - scene2-gen2-dna-1~4（第2代DNA）
  - scene2-gen3-dna-1~8（第3代DNA）
  - scene2-conn-*（连接线）
  - scene2-stats-box（统计框）
  - scene2-legend-box（图例框）
  - scene2-btn-prev, scene2-btn-next（按钮）
  - scene2-step-indicator（步骤指示器）
- IIFE隔离：所有JS代码包在(function() { ... })()中，避免全局变量污染
