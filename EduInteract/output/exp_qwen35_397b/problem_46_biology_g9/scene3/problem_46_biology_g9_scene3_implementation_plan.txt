[标签冲突检查]
- 标签"①"：坐标(165,70)，与碱基"C"(165,95)间距25px → 不冲突
- 标签"②"：坐标(400,115)，与虚线(400,120)间距5px → 箭头指向设计，不冲突
- 标签"T→A"：坐标(195,75)，与①标签(165,70)水平间距30px → 不冲突
- 标签"突变基因:1/2"：坐标(400,405)，与选项C框(140,400)水平间距110px → 不冲突
- 碱基字母间距：同一链上相邻字母水平间距30px（如165,195,225,255）→ 不冲突
- 上下链字母垂直间距60px（y=95 vs y=155）→ 不冲突
- 复制树DNA框与比例框垂直间距60px（y=320 vs y=380）→ 不冲突
- 所有标签与线段间距≥15px → 不冲突
- 结论：所有标签位置经过检查，无重叠冲突

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮：scene3-btn-prev，位置(250,455)，80×30px，点击返回上一状态
  - 下一步按钮：scene3-btn-next，位置(470,455)，80×30px，点击进入下一状态
  - 步骤指示器：scene3-step-indicator，位置(400,465)，显示当前步骤/总步骤
- 教师操作流程：
  1. 初始展示正常DNA结构，讲解①②位置含义
  2. 点击下一步，展示T→A突变，讲解基因突变概念
  3. 点击下一步，展示第1次复制结果，讲解半保留复制
  4. 点击下一步，展示n次复制后比例，对比选项C的错误
  5. 可随时点击上一步回退复习

[技术实现]
- JS库选择：原生SVG + 原生JavaScript
  - 原因：几何元素简单（线段、圆形、矩形、文字），无需复杂库；原生实现轻量、加载快
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌────────────────────────────────────────────────────┐
  │                                                    │
  │           正常DNA双链 (y=100~140)                  │
  │     ①↓                          ②→                │
  │   C T G C ──────── C T T A                        │
  │   │ │ │ │          │ │ │ │                        │
  │   G A C G ──────── G A A T                        │
  │                                                    │
  │         ↓突变红圈+T→A (步骤1显示)                  │
  │                                                    │
  │        ╱              ╲                            │
  │       ↓                ↓                           │
  │   [正常DNA]        [突变DNA]  (步骤2显示)           │
  │    绿色框            红色框                         │
  │                                                    │
  │  ┌─────────┐      ┌───────────────┐               │
  │  │C说1/4❌ │      │ 突变基因:1/2  │  (步骤3显示)   │
  │  └─────────┘      └───────────────┘               │
  │                                                    │
  │  ┌──────────────────────────────────────────────┐ │
  │  │   [◀上一步]     步骤X/4     [下一步▶]       │ │
  │  └──────────────────────────────────────────────┘ │
  └────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用currentState变量(0-4)跟踪当前步骤，steps数组存储每步显示的元素ID列表
  2. 坐标计算：所有元素坐标硬编码在布局坐标表中，确保精确无重叠
  3. 动画曲线：元素显示使用CSS transition opacity 0.3s ease-in-out
  4. 事件绑定：按钮点击事件绑定到updateState()函数，更新显示元素和步骤指示器
  5. 边界处理：步骤0时禁用上一步按钮，步骤4时禁用下一步按钮
- ID命名规范：所有交互元素ID必须以scene3-为前缀
  - 示例：scene3-dna-top, scene3-mutation-circle, scene3-btn-next, scene3-stat-box
- IIFE隔离：所有JS代码包在(function() { ... })()中，避免全局变量污染
- CDN引入：无需外部库，纯原生实现
