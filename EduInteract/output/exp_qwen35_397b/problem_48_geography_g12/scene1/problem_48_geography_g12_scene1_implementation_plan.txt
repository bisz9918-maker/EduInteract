[图示主题与整合说明]
- 本图示主题：北半球同纬度两点间的最短航线（大圆航线）
- 整合内容：经纬网基础框架、M/N 点定位、最短航线路径展示、飞行方向变化
- 教学价值：教师可使用此图示直观展示"球面上两点间最短距离是大圆弧而非直线"这一核心概念。通过分步对比纬线路径与大圆航线，帮助学生理解为什么飞机飞行方向是"先东北后东南"而非"一直向东"。

[分步序列]
- 初始状态（步骤 0）：显示基础经纬网（两条经线 + 两条纬线）、M 点、N 点、所有标签（80°、120°、60°、40°、M、N）。等待教师讲解题目条件。
- 步骤 1：点击「下一步」→ 显示纬线方向的直线路径（灰色虚线从 M 到 N），作为对比参照。教师可说明"如果沿纬线飞是一直向东"。
- 步骤 2：点击「下一步」→ 显示大圆航线（红色实线弧线，向上凸出），同时淡化或隐藏步骤 1 的虚线路径。教师讲解"球面上最短距离是大圆弧"。
- 步骤 3：点击「下一步」→ 在大圆航线上显示两个方向箭头（第一段指向东北，第二段指向东南），并在弧线旁添加简短标注"先东北→后东南"。展示最终结论。

冲突检查：
- "80°"与"120°"：水平距离 300px → 无冲突
- "80°"与"M"：垂直距离 55px → 无冲突
- "120°"与"N"：垂直距离 55px → 无冲突
- "60°"与"40°"：垂直距离 140px → 无冲突
- "M"与"N"：水平距离 300px → 无冲突
- "60°"与"N"：水平距离 27px，垂直距离 15px → 距离约 31px，无冲突（≥20px）
- "80°"与"60°"：距离远 → 无冲突

所有标签间距均≥20px，无重叠冲突。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 底部左侧 (x=320, y=455)，点击返回上一状态
  - 「下一步」按钮：位于 SVG 底部右侧 (x=480, y=455)，点击进入下一状态
  - 状态指示器：位于底部中央 (x=400, y=455)，显示"步骤 X/4"
- 教师操作流程：
  1. 初始状态展示经纬网和 M、N 点，教师读题并让学生定位两点
  2. 点击「下一步」显示纬线路径，提问"如果沿这条线飞方向是什么？"
  3. 点击「下一步」显示大圆航线，讲解"最短路径是向高纬凸出的弧线"
  4. 点击「下一步」显示方向箭头，总结"所以飞行方向是先东北后东南"

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |         80°              120°                    |
  |          |                |                      |
  |    M-----+----------------+-----N   60°         |
  |          |      (弧线)    |                      |
  |          |                |                      |
  |          |                |                      |
  |          +----------------+          40°         |
  |                                                  |
  |                                                  |
  |              [◀上一步] 步骤 1/4 [下一步▶]        |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentState (0-3) 跟踪当前步骤，数组存储每步需显示的元素 ID
  2. 大圆航线：使用 SVG <path> 的二次贝塞尔曲线，d="M 250,180 Q 400,135 550,180"
  3. 方向箭头：使用 SVG <marker> 定义箭头样式，或在弧线上用 <path> 绘制小箭头
  4. 事件绑定：按钮点击事件切换状态，调用 updateDisplay() 函数显示/隐藏对应元素
  5. 动画过渡：路径显示使用 stroke-dasharray 动画，时长 0.5s
- ID 命名规范：所有元素 ID 以 scene1- 为前缀
  - scene1-meridian-80, scene1-meridian-120
  - scene1-parallel-60, scene1-parallel-40
  - scene1-point-m, scene1-point-n
  - scene1-label-80, scene1-label-120, scene1-label-60, scene1-label-40
  - scene1-label-m, scene1-label-n
  - scene1-path-greatcircle, scene1-path-latitude
  - scene1-arrow-1, scene1-arrow-2
  - scene1-btn-prev, scene1-btn-next, scene1-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
