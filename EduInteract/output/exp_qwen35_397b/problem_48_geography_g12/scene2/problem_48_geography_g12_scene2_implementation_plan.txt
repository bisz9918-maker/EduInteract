[分步序列]
- 初始状态（步骤 0）：显示地球球体轮廓、赤道线、地心及标签、北半球/南半球区域标签、M 点及标签"M"、M 坐标标注"60°N, 80°E"
- 步骤 1：点击「下一步」→ 显示对称连线（从 M 点穿过地心的红色虚线），地心高亮显示
- 步骤 2：点击「下一步」→ 显示对称点 M'（绿色实心圆）及标签"M'"，M'点出现在南半球对应位置
- 步骤 3：点击「下一步」→ 显示 M'坐标标注"60°S, 100°W"，同时显示坐标变换规则说明（纬度南北相反、经度东西相反和为 180°）
- 最终步骤：展示完整对跖点概念，教师可点击「上一步」回退复习任一阶段

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 内底部左侧 (280,460)，点击回退到前一状态
  - 「下一步」按钮：位于 SVG 内底部右侧 (480,460)，点击进入下一状态
  - 步骤指示器：位于顶部 (400,30)，显示"步骤 X/4"
- 教师操作流程：
  1. 初始展示地球和 M 点位置，讲解 M 点坐标 (60°N, 80°E)
  2. 点击「下一步」显示对称连线，讲解"穿过地心的直线"
  3. 点击「下一步」显示 M'点，讲解对称点位置
  4. 点击「下一步」显示 M'坐标，讲解变换规则（纬度相反、经度互补）
  5. 可随时点击「上一步」回退复习

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  ┌────────────────────────────────────┐
  │         步骤指示器 (400,30)         │
  │                                    │
  │    北半球 (400,120)                │
  │         M(280,140)                 │
  │           M●                       │
  │                                    │
  │    ─────────●───────── 赤道        │
  │           地心                     │
  │                       ●M'          │
  │                        M'(500,360) │
  │         南半球 (400,380)           │
  │                                    │
  │    [◀上一步]          [下一步▶]    │
  └────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用 state 变量 (0-3) 跟踪当前步骤
  2. 元素显隐控制：每个步骤对应的元素设置 id，通过 display/opacity 控制显示
  3. 对称连线动画：使用 stroke-dashoffset 实现虚线延伸效果
  4. 事件绑定：按钮点击事件切换 state 并更新视图
  5. ID 命名规范：所有元素 ID 以 scene2- 为前缀（如 scene2-earth、scene2-point-m、scene2-point-m-prime、scene2-line-symmetry、scene2-btn-prev、scene2-btn-next）
  6. IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
  7. 初始状态：步骤 0 显示基础元素，按钮根据 state 禁用/启用（步骤 0 禁用上一步，步骤 3 禁用下一步）
