[图示主题与整合说明]
- 本图示主题：晨昏线切点与太阳直射点纬度的互余关系
- 整合内容：整合切点纬度推导直射点纬度的几何关系，展示为什么切点纬度与直射点纬度互余

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 按钮「◀上一步」：位置 (320,460)，返回上一步状态
  - 按钮「下一步▶」：位置 (420,460)，进入下一步状态
  - 步骤指示器：位置 (380,460)，显示"步骤 X/6"
- 教师操作流程：
  1. 初始状态展示基础图形（俯视图、70°纬线、切点 M）
  2. 点击「下一步」逐步显示极夜区域→辅助线→角度关系→直射点位置
  3. 每步暂停讲解，让学生理解几何推导逻辑
  4. 可点击「上一步」回退复习关键步骤

[技术实现]
- JS 库选择及原因：原生 SVG（适合绘制几何图形、圆弧、箭头，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |   [俯视图]              [箭头]    [侧视图]       |
  |     圆形                  →         圆形         |
  |   70°纬线+切点 M                    直射点 20°N  |
  |   极夜区填充                          太阳光线   |
  |   角度标注 20°                                   |
  |                                                  |
  |                                                  |
  |              [◀上一步] 步骤 X/6 [下一步▶]        |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用 stateIndex 变量 (0-5) 跟踪当前步骤，steps 数组存储每步显示的元素 ID 列表
  2. 坐标计算：70°纬线半径 = 外圆半径 × sin(20°) ≈ 140 × 0.342 ≈ 48px
  3. 动画曲线：元素淡入使用 CSS transition opacity 0.3s ease
  4. 事件绑定：按钮点击事件切换 stateIndex，调用 renderStep() 更新显示
  5. 元素初始隐藏：所有步骤专属元素设置 opacity:0，按步骤显示
- ID 命名规范：所有交互元素 ID 必须以 scene2- 为前缀（如 scene2-top-view、scene2-point-m、scene2-btn-next）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中
