[分步序列]
步骤0（初始状态）：显示题目基础条件
- 显示：外圆边界、70°纬线圆、极点O及标签、点A/M/B及标签、晨昏线MA、经线B、阴影区域
- 隐藏：180°经线高亮、0时经线高亮、12时经线、所有时间标注、图例
- 目的：呈现原题图示，让学生观察

步骤1：标注日期分界线的两种类型
- 新增显示：图例框及标题
- 高亮：阴影区域的左右两条边界经线（分别用红色和蓝色）
- 图例项1显示：红色线段+"180°经线（国际日期变更线）"
- 图例项2显示：蓝色线段+"0时经线（自然日期变更线）"
- 目的：让学生理解阴影区域由两条日期分界线围成

步骤2：分析经线B，确定经度
- 高亮：经线B（蓝色#1565c0 2px）
- 显示：经线B标签"经线B"
- 图例项3显示：绿色线段+"12时经线（太阳直射经线）"
- 目的：经线B与阴影右边界重合，即0时经线

步骤3：确定0时经线位置
- 显示：0时标签"0时"在(260,180)蓝色文字
- 标注：阴影右边界即0时经线，与经线B重合
- 根据图示角度：假设经线间隔30°，从180°经线逆时针推算
- 目的：0时经线是夜半球中央经线

步骤4：计算直射点经度（12时经线）
- 显示：12时经线（绿色#2e7d32 2px），与0时经线相对（相差180°）
- 显示：12时标签"12时"在(520,280)绿色文字
- 计算：若0时经线为60°W，则12时经线为120°E
- 目的：太阳直射点所在经线地方时为12时

步骤5：显示完整直射点坐标
- 显示：所有时间标注（0时、12时、18时、24时）沿纬线圈分布
- 高亮：直射点坐标文字"（20°S，120°E）"在图例下方
- 推导：M为70°S纬线切点→直射点纬度=90°-70°=20°S
- 目的：完成太阳直射点坐标的确定

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 按钮"◀上一步"：位于(350,455)，返回上一状态
  - 按钮"下一步▶"：位于(450,455)，进入下一状态
  - 步骤指示器：位于(400,475)，显示"步骤 X / 5"
- 教师操作流程：
  1. 初始展示原题图示（步骤0），让学生观察阴影区域
  2. 点击"下一步"显示两条日期分界线（步骤1），讲解180°经线和0时经线的区别
  3. 点击"下一步"高亮经线B（步骤2），说明经线B即0时经线
  4. 点击"下一步"标注0时位置（步骤3），推导经度
  5. 点击"下一步"显示12时经线（步骤4），讲解直射点经度计算
  6. 点击"下一步"显示完整坐标（步骤5），总结直射点坐标确定方法

[技术实现]
- JS库选择：原生SVG（几何图形简单，无需复杂库）
- 画布尺寸：800×500px
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |    [南极俯视图]              [图例区]            |
  |         外圆                  620,80             |
  |       70°纬线                -160,120-           |
  |    圆心(380,260)              图例内容           |
  |                                                  |
  |                                                  |
  |                                                  |
  |              [控件栏 y=440~490]                  |
  |         [◀上一步]  步骤X/5  [下一步▶]            |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用currentState变量(0-5)跟踪当前步骤，steps数组存储每步显示的元素ID列表
  2. 坐标计算：所有射线从圆心(380,260)出发，根据角度计算端点坐标
  3. 角度设定：180°经线设为270°(正左)，0时经线设为210°，12时经线设为30°
  4. 动画曲线：元素淡入用opacity过渡(0.3s ease)
  5. 事件绑定：按钮点击事件切换状态，更新显示元素
- ID命名规范：所有元素ID以"scene3-"为前缀
  - scene3-outer-circle, scene3-lat-70, scene3-point-o, scene3-point-a, scene3-point-m, scene3-point-b
  - scene3-晨昏线-ma, scene3-经线-b, scene3-阴影区
  - scene3-经线-180, scene3-经线-0时，scene3-经线-12时
  - scene3-label-o, scene3-label-a, scene3-label-m, scene3-label-b
  - scene3-label-180度，scene3-label-0时，scene3-label-12时，scene3-label-70度
  - scene3-legend-box, scene3-legend-item1, scene3-legend-item2, scene3-legend-item3
  - scene3-btn-prev, scene3-btn-next, scene3-step-indicator
- IIFE隔离：所有JS代码包在(function() { ... })()中，避免全局变量污染
