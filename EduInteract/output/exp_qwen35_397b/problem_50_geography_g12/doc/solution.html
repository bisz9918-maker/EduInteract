场景导航：Scene 1 | Scene 2 | Scene 3

题目原文：下图所示区域为昼半球，A为圆心，B点纬度为75°，其中A点西侧为东半球，东侧为西半球，据此回答下列问题。

(1) 此时太阳直射点的地理坐标是，C点的地理坐标是。此时北京时间是。
(2) 图中A、B、C三点的线速度大小排列是(用“＞”“<”“＝”符号表示)；三点的正午太阳高度角大小排列是__(用“＞”“<”“＝”符号表示)。

题目分析：

  1. 昼半球中心A为太阳直射点，其经度由东西半球分界确定（160°E）。
  2. B点纬度75°，结合昼半球范围推断太阳直射点纬度（15°N）。
  3. C点与B点关于地心对称，纬度75°N。
  4. 线速度比较依据纬度高低，正午太阳高度角由直射点纬度计算。

图示规划：

  • SCENE_1：昼半球整体结构，标注A、B、C点位置及关键经纬线。
  • SCENE_2：太阳直射点与时间计算动态演示。
  • SCENE_3：线速度与正午太阳高度角对比图示。
步骤 1/4

教学要点：

  1. 引导学生观察昼半球中心A即太阳直射点。
  2. 通过B点纬度75°S推断太阳直射点纬度：90°-75°=15°N。
  3. 强调A点经度160°E由东西半球分界确定（西侧东半球，东侧西半球）。
  4. C点与B点对称，纬度75°N，经度相同。

公式提示：

  • 太阳直射点纬度 = 90° - 晨昏线切点纬度
  • 东西半球分界：20°W与160°E
步骤 1/4

讲解思路：

  1. 太阳直射点所在经线地方时为12:00（160°E为12:00）。
  2. 北京时间对应120°E地方时，经度差40°（160°-120°）。
  3. 时间差计算：40°×4分钟/°=160分钟=2小时40分。
  4. 北京时间=12:00 - 2h40m = 9:20。

关键点：东早西晚，经度差转时间差。

总结与答案：
(1) 太阳直射点坐标（15°N, 160°E），C点坐标（75°N, 160°E），北京时间9:20。
(2) 线速度：A > B = C；正午太阳高度：A > C > B。

课堂建议：

  • 结合图示分步推导，强调地理坐标与时间的关系。
  • 通过对比强化纬度对线速度与太阳高度的影响。
