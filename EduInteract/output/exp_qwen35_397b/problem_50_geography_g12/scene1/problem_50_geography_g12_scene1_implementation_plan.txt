[图示主题与整合说明]
- 本图示主题：昼半球结构与关键点定位
- 整合内容：地球昼半球投影、A/B/C 点位置、赤道与经纬线标注、东西半球分界
- 教学价值：教师可逐步展示昼半球的几何结构，帮助学生理解太阳直射点、纬度分布、东西半球分界线的空间关系。通过分步导航，学生能清晰看到从基础圆形到完整标注的认知递进过程，适合课堂讲解地理坐标系统。

[分步序列]
步骤 0（初始状态）：显示基础昼半球圆
- 显示：昼半球圆（填充 20% 透明度）、CB 直径黑线
- 隐藏：所有点、标签、赤道线、经线标注

步骤 1：点击「下一步」→ 添加赤道与 A 点
- 新增显示：赤道线（灰色虚线）、A 点（蓝色圆点）、标签"A"、标签"赤道"、标签"15°N"
- 保持显示：昼半球圆、CB 直径

步骤 2：点击「下一步」→ 标注 B/C 纬度
- 新增显示：B 点（红色圆点）、C 点（红色圆点）、标签"B"、标签"C"、标签"75°S"、标签"75°N"
- 保持显示：步骤 1 所有元素

步骤 3：点击「下一步」→ 高亮东西半球分界经线
- 视觉变化：CB 直径线变为蓝色加粗（线宽 4）、显示标签"160°E"
- 保持显示：所有点和标签
- 最终状态：完整展示昼半球结构，所有关键点标注清晰

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 底部左侧 (x=320, y=455)，宽 80px，高 30px
  - 「下一步」按钮：位于 SVG 底部右侧 (x=400, y=455)，宽 80px，高 30px
  - 步骤指示器：位于两按钮之间，显示"步骤 X/4"
- 教师操作流程：
  1. 初始状态仅显示昼半球圆和直径，教师介绍"这是昼半球投影"
  2. 点击「下一步」显示赤道和 A 点，讲解"赤道穿过昼半球中心，A 点是圆心"
  3. 点击「下一步」显示 B/C 点及纬度，讲解"B 点 75°S，C 点 75°N"
  4. 点击「下一步」高亮 160°E 经线，讲解"A 点西侧为东半球，东侧为西半球，故经度为 160°E"

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库）
- 画布尺寸：800×500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |                    C(75°N)                       |
  |                     ●                            |
  |                     |                            |
  |         15°N ←──────┼──────→ 赤道                |
  |                     ● A                          |
  |                     |                            |
  |                     ● B                          |
  |                    (75°S)                        |
  |                                                  |
  |                                                  |
  |              [◀上一步] 步骤 1/4 [下一步▶]        |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep 跟踪当前步骤（0-3），每步对应一组显示/隐藏的元素
  2. 坐标计算：所有元素坐标硬编码，确保与布局坐标表一致
  3. 动画曲线：元素出现使用淡入效果（opacity 0→1，duration 300ms）
  4. 事件绑定：按钮点击事件切换步骤，更新步骤指示器文本
  5. 元素分组：用<g>标签将每步新增元素分组，通过 display 属性控制显示/隐藏
- ID 命名规范：所有交互元素 ID 以 scene1-为前缀
  - scene1-circle（昼半球圆）
  - scene1-equator（赤道线）
  - scene1-diameter（CB 直径）
  - scene1-point-a、scene1-point-b、scene1-point-c（三个点）
  - scene1-label-a、scene1-label-b、scene1-label-c（点标签）
  - scene1-label-equator、scene1-label-160e、scene1-label-75s、scene1-label-75n、scene1-label-15n（数值标签）
  - scene1-btn-prev、scene1-btn-next、scene1-step-indicator（控件）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
