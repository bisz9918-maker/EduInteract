[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于 SVG 内底部左侧 (320,450)，点击回退到上一状态
  - 「下一步 ▶」按钮：位于 SVG 内底部中间 (400,450)，点击前进到下一状态
  - 步骤指示器：位于底部右侧 (500,460)，显示当前步骤如"3/5"
- 教师操作流程：
  1. 初始状态展示基础光照图，引导学生观察昼夜分布
  2. 点击「下一步」高亮晨昏线，讲解晨昏线的识别方法
  3. 点击「下一步」显示极圈和回归线，分析极昼范围判断节气
  4. 点击「下一步」显示太阳光线和直射点，讲解直射点坐标确定
  5. 点击「下一步」显示结论，总结夏至日的判断依据

[技术实现]
- JS 库选择：原生 SVG（简单几何图形首选，无需额外库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +------------------------------------------+
  |              夏至日 (400,30)             |
  |                                          |
  |        北回归线 23°26′N (400,85)         |
  |           北极圈 66°34′N (400,175)       |
  |                                          |
  |    0°      [圆形光照图居中]    太阳光线  |
  |   (210,240)  圆心 (400,250)    →直射点  |
  |              半径 175px        (560,270) |
  |                                          |
  |         晨昏线 (350,180)                 |
  |                                          |
  |                                          |
  |    [◀ 上一步] [下一步 ▶]   步骤：3/5     |
  |     (320,450)  (400,450)    (500,460)    |
  +------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量 (0-4) 跟踪当前步骤
  2. 所有 SVG 元素按步骤分组，用 display:none 控制显示/隐藏
  3. 按钮事件绑定：上一步 (currentState>0 时--), 下一步 (currentState<4 时++)
  4. 每次状态变化后更新步骤指示器文本
  5. 按钮禁用状态：第一步时禁用"上一步"，最后一步时禁用"下一步"
- ID 命名规范：所有元素 ID 以 scene1- 为前缀
  - scene1-earth-outline（地球外轮廓）
  - scene1-arctic-circle（北极圈）
  - scene1-tropic-circle（北回归线）
  - scene1-night-shadow（黑夜阴影）
  - scene1-terminator（晨昏线）
  - scene1-rotation-arrow（自转箭头）
  - scene1-sun-ray（太阳光线）
  - scene1-sun-point（直射点）
  - scene1-label-0deg（0°经线标签）
  - scene1-label-arctic（北极圈标签）
  - scene1-label-tropic（北回归线标签）
  - scene1-label-terminator（晨昏线标签）
  - scene1-label-sun-coord（直射点坐标标签）
  - scene1-label-solstice（夏至日标签）
  - scene1-btn-prev（上一步按钮）
  - scene1-btn-next（下一步按钮）
  - scene1-step-indicator（步骤指示器）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
