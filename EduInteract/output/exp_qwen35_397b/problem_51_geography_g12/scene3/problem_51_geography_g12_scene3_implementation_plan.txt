[图示主题与整合说明]
- 本图示主题：A、B、C 三点物理量对比——地转偏向力与自转线速度
- 整合内容：三点纬度位置、地转偏向力大小比较、自转线速度大小比较
- 教学价值：教师可通过分步展示，帮助学生理解纬度与地转偏向力、自转线速度的关系。步骤化呈现使学生能跟随教师思路，先观察三点位置，再理解物理规律，最后得出结论。交互按钮允许教师随时回退复习关键概念。

[视觉元素清单]

[分步序列]
- 初始状态（步骤 0）：显示北极俯视图框架、O 点、经线 OA、三条纬线圆弧、A/B/C 三点（红色圆点）、三点位置标签
- 步骤 1：高亮显示三点纬度差异，在右侧关系说明框显示"地转偏向力：纬度越高越大"和"自转线速度：纬度越低越大"
- 步骤 2：显示地转偏向力箭头（蓝色），三条箭头长度不同（A 最短→C 最长），高亮 C 点，在结论框显示"地转偏向力最小：C 点"
- 步骤 3：显示自转线速度箭头（绿色），三条箭头长度不同（A 最长→C 最短），高亮 C 点，在结论框显示"自转线速度最快：C 点"
- 步骤 4（最终）：所有元素完整显示，C 点用黄色光环高亮，结论框边框加粗闪烁提示

- "B 点"与"C 点"间距：约 127px → 无冲突
- "A 点"与"C 点"间距：约 215px → 无冲突
- 关系说明文字与结论框文字：垂直间距 120px → 无冲突
- 所有标签均位于图形外侧，无重叠风险

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：位于 SVG 底部左侧 (320, 450)，点击回退到上一状态
  - "下一步 ▶"按钮：位于 SVG 底部中央 (400, 450)，点击进入下一状态
  - 步骤指示器：显示当前步骤序号 "步骤 X/4"
- 教师操作流程：
  1. 初始展示三点位置，让学生观察 A、B、C 的纬度差异
  2. 点击"下一步"显示物理规律说明
  3. 点击"下一步"显示地转偏向力对比，引导学生得出最小值结论
  4. 点击"下一步"显示自转线速度对比，引导学生得出最大值结论
  5. 最后一步总结答案，可随时点击"上一步"回退复习

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单，无需复杂库；原生 SVG 便于精确控制坐标和动画
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  [左侧：北极俯视图]    |  [右侧：说明区]         |
  |       A ●              |  +-------------------+  |
  |        \               |  | 地转偏向力：...   |  |
  |         B ●            |  | 自转线速度：...   |  |
  |          \             |  +-------------------+  |
  |           C ●          |  +-------------------+  |
  |            \           |  | 地转偏向力最小：C |  |
  |             O ●        |  | 自转线速度最快：C |  |
  |                        |  +-------------------+  |
  |                        |                         |
  |  [纬线圆弧虚线]        |                         |
  +--------------------------------------------------+
  |        [◀ 上一步]  [下一步 ▶]   步骤 X/4        |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用 currentStep 变量 (0-4) 跟踪当前步骤，steps 数组存储每步显示的元素 ID 列表
  2. 坐标计算：纬线圆弧用 SVG <path> 的 A 命令绘制，圆心 (400,250)，半径分别为 288/200/110px
  3. 动画曲线：元素出现使用 fade-in 动画 (opacity 0→1, 300ms ease-out)
  4. 事件绑定：按钮点击事件绑定到 stepForward() 和 stepBackward() 函数
  5. 元素显隐：每步调用 updateDisplay() 根据 currentStep 设置元素 display 属性
- ID 命名规范：所有交互元素 ID 必须以 scene3- 为前缀
  - scene3-point-a, scene3-point-b, scene3-point-c
  - scene3-arrow-force-a, scene3-arrow-force-b, scene3-arrow-force-c
  - scene3-arrow-velocity-a, scene3-arrow-velocity-b, scene3-arrow-velocity-c
  - scene3-btn-prev, scene3-btn-next, scene3-step-indicator
  - scene3-relation-box, scene3-conclusion-box
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
