[技术实现]
- JS 库选择：原生 SVG（几何图形简单，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [标题区 y=10-50]
     "太阳直射点与正午太阳高度计算"
  
  [左侧光照图区 x=50-350, y=80-350]
     [太阳] [地球] [光线] [标注]
  
  [右侧轨道图区 x=380-750, y=80-400]
     [椭圆轨道] [太阳] [二分二至点]
  
  [公式区 x=50-750, y=420-480]
     [浅灰背景] [公式文本]
  
  [控件栏 y=485-495]
     [◀上一步] [步骤 X/3] [下一步▶]
  ```
- 关键实现要点：
  1. 状态机设计：用 currentState 变量跟踪当前步骤（0-3），每个状态对应一组可见元素
  2. 坐标计算：地球表面点位置用极坐标转换（纬度→y 偏移）
  3. 动画曲线：元素淡入用 CSS transition opacity 0.3s
  4. 事件绑定：按钮点击事件切换状态，更新可见性
  5. ID 命名规范：所有元素 ID 以 scene3- 为前缀（如 scene3-sun、scene3-earth、scene3-tropic 等）
  6. IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
- 配色沿用 spec 中声明：
  - 背景 #ffffff
  - 主线 #000000 实线
  - 蓝高亮 #1565c0（太阳光线）
  - 红高亮 #c62828（南回归线、直射点、冬至点）
  - 绿高亮 #2e7d32（北京位置、计算结果、太阳高度角）
  - 辅助线 #888888 虚线（地轴、赤道面）
  - 轨道线 #000000 实线
