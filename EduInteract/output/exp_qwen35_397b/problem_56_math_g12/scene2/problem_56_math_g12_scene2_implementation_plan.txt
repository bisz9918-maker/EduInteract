[图示主题与整合说明]
- 本图示主题：圆面积等比数列的形成与求和
- 整合内容：面积计算、等比数列识别、无穷求和公式应用
- 教学价值：教师可通过分步演示，引导学生从具体数值计算（前3个圆的半径和面积）逐步发现等比数列规律（公比q=3/4），最后应用无穷等比数列求和公式得出所有圆面积总和S=4π。此过程帮助学生理解"无限项求和"的数学思想。

  5. 点击「下一步」展示代入计算和最终结果，完成推导

[技术实现]
- JS库选择：原生SVG + 原生JavaScript
  - 原因：几何图形简单（圆、多边形、直线），原生SVG足够；无需复杂动画库
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  [左侧嵌套圆]        [右侧数列表格]              |
  |     (0,0)-(280,260)    (340,60)-(760,240)       |
  |                                                  |
  |                          [求和公式区]            |
  |                          (340,260)-(760,340)     |
  |                                                  |
  |  [步骤指示]  [上一步]  [下一步]                  |
  |  (400,460)   (500,450) (600,450)                 |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量currentStep(0-4)跟踪当前步骤，steps数组存储每步的显示配置
  2. 坐标计算：正六边形顶点用极坐标转换 (r*cos(θ), r*sin(θ)), θ=0°,60°,120°,...
  3. 动画曲线：元素淡入用CSS transition opacity 0.3s ease
  4. 事件绑定：按钮点击事件切换currentStep，调用renderStep()重绘
  5. 元素ID规范：所有元素ID以"scene2-"为前缀（如scene2-circle-0, scene2-table-row-0）
  6. IIFE隔离：所有JS代码包在(function() { ... })()中，避免全局污染
  7. 按钮禁用逻辑：步骤0时禁用「上一步」，步骤4时禁用「下一步」

- 元素ID命名示例：
  - scene2-circle-0, scene2-circle-1, scene2-circle-2（三个圆）
  - scene2-hex-0, scene2-hex-1（两个六边形）
  - scene2-table-header, scene2-table-row-0, scene2-table-row-1, scene2-table-row-2
  - scene2-arrow-1, scene2-arrow-2（等比箭头）
  - scene2-label-a1, scene2-label-q（首项和公比标注）
  - scene2-formula-box, scene2-formula-text, scene2-result
  - scene2-btn-prev, scene2-btn-next, scene2-step-indicator
