[图示主题与整合说明]
- 本图示主题：测量河宽的三角形几何模型及解题辅助线
- 整合的内容：题目原图、角度标注、边长标注、作高辅助线、直角三角形边角关系展示
- 教学价值：教师可通过分步演示，引导学生从理解题意（两岸平行、三角形结构）→标注已知条件（角度和边长）→添加辅助线（作高）→分析两个直角三角形→建立边角关系求解河宽。分步方式帮助学生理解"作高"这一关键解题思路，以及如何在复杂图形中识别基本几何模型。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于(280,455)，尺寸100×35px，点击后退到前一状态
  - 「下一步 ▶」按钮：位于(420,455)，尺寸100×35px，点击前进到下一状态
  - 步骤指示器：位于两按钮之间(390,465)，显示"步骤 X/4"
- 教师操作流程：
  1. 初始展示基础图形（步骤0），让学生观察两岸和三角形结构
  2. 点击「下一步」到步骤1，标注已知角度和边长，引导学生识别已知条件
  3. 点击「下一步」到步骤2，展示作高辅助线，强调"作高"是解斜三角形的常用方法
  4. 点击「下一步」到步骤3，高亮Rt△ACD，分析其中的边角关系
  5. 点击「下一步」到步骤4，高亮Rt△BCD，展示河宽CD的计算公式
  6. 可随时点击「上一步」回退复习关键步骤

[技术实现]
- JS库选择：原生SVG
  - 原因：本题为纯几何图形（线段、圆弧、多边形），原生SVG足够胜任，无需引入重型库；SVG元素可独立控制显隐和样式，适合分步演示
- 画布尺寸：800×500px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |  ================================  上方河岸(y=130)|
  |                    C                             |
  |                   / \                            |
  |                  /   \                           |
  |                 /     \                          |
  |                /       \                         |
  |               /    CD   \                        |
  |              /    |      \                       |
  |             /     |       \                      |
  |            /      |        \                     |
  |  =========A=======D=========B========  下方河岸  |
  |         75°      |        45°                    |
  |                  |                               |
  |              [96米标注]                          |
  |                                                  |
  |        [◀上一步]  步骤X/4  [下一步▶]  (y=455)    |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量currentStep(0-4)跟踪当前步骤，steps数组存储每步的显隐规则
  2. 元素ID命名：所有元素ID以scene1-为前缀，如scene1-river-top、scene1-tri-ac、scene1-label-a等
  3. 显隐控制：每步定义要显示的元素ID列表，用display:none/block控制
  4. 高亮实现：通过修改stroke-width和stroke属性实现加粗高亮
  5. 动画效果：元素出现时用CSS transition实现淡入效果（opacity从0到1，时长300ms）
  6. 按钮状态：步骤0时禁用「上一步」，步骤4时禁用「下一步」
  7. IIFE隔离：所有JS代码包在(function() { ... })()中，避免全局污染
- ID命名规范示例：
  - scene1-river-top（上方河岸）
