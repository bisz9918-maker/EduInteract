    **题目原文：**

    在圆中有如下结论："如图，AB 是圆 O 的直径，直线 AC，BD 是圆 O 过 A，B 的切线，P 是圆 O 上任意一点，CD 是过 P 的切线，则有 PC⋅PD = PO²"．类比到椭圆："如图，AB 是椭圆的长轴（其中 O 为椭圆的中心，F₁、F₂为椭圆的两个焦点），直线 AC，BD 是椭圆过 A，B 的切线，P 是椭圆上任意一点，CD 是过 P 的切线，则有 PC⋅PD = (     )"

    **题目分析：**

    这是一道类比推理题，要求学生从圆的切线性质出发，类比推导椭圆的相应结论。

    圆的情况（左图）：
    - AB 是直径，O 是圆心
    - AC、BD 是过端点 A、B 的切线（垂直于 AB）
    - CD 是过 P 点的切线，与 AC、BD 分别交于 C、D
    - 结论：PC·PD = PO²

    椭圆的情况（右图）：
    - AB 是长轴，O 是中心，F₁、F₂是焦点
    - AC、BD 是过端点 A、B 的切线（垂直于 AB）
    - CD 是过 P 点的切线，与 AC、BD 分别交于 C、D
    - 求：PC·PD = ?

    **整体讲解思路：**

    1. 先验证圆的结论（建立认知基础）
    2. 观察椭圆与圆的结构对应关系
    3. 通过动态演示发现椭圆中的不变量
    4. 类比得出正确结论（PC·PD = PF₁·PF₂ 或 PC·PD = b²）

    **图示规划说明：**

    - SCENE_1：圆的情况验证——拖拽 P 点验证 PC·PD = PO²
    - SCENE_2：椭圆情况探究——拖拽 P 点观察 PC·PD 与焦点距离的关系
    - SCENE_3：圆与椭圆对比——并置展示，突出类比关系

    **引导学生观察：**

    1. 初始状态下，读取 PC、PD、PF₁、PF₂ 的长度值
    2. 计算 PC·PD 和 PF₁·PF₂，观察两者关系
    3. 拖拽 P 点沿椭圆移动，观察数值变化
    4. 发现 PC·PD = PF₁·PF₂ 始终成立

    **类比推理过程：**

    | 圆 | 椭圆 |
    |---|---|
    | 圆心 O | 焦点 F₁、F₂ |
    | PO（半径） | PF₁、PF₂（焦半径） |
    | PO² | PF₁·PF₂ |
    | PC·PD = PO² | PC·PD = PF₁·PF₂ |

    **关键结论：**

    在椭圆中，PC·PD = PF₁·PF₂

    （注：也可进一步推导 PC·PD = b²，其中 b 为短半轴长）

    **讲解要点：**

    - 圆是椭圆的特殊情况（两焦点重合于圆心）
    - 当 F₁、F₂重合于 O 时，PF₁·PF₂ = PO²
    - 类比思想：从特殊到一般

    **SCENE_3 教学说明：**

    本图示用于总结圆与椭圆的类比关系，强化学生的类比推理能力。

    **类比映射表：**

    1. **几何元素对应：**
       - 圆的直径 AB ↔ 椭圆的长轴 AB
       - 圆的圆心 O ↔ 椭圆的两焦点 F₁、F₂
       - 圆的半径 PO ↔ 椭圆的焦半径 PF₁、PF₂

    2. **切线性质对应：**
       - 圆：过 A、B 的切线 AC、BD 垂直于 AB
       - 椭圆：过 A、B 的切线 AC、BD 垂直于 AB

    3. **结论对应：**
       - 圆：PC·PD = PO²
       - 椭圆：PC·PD = PF₁·PF₂

    **完整解答：**

    根据类比推理，椭圆中的结论为：

    **PC·PD = PF₁·PF₂**

    （或进一步推导得 PC·PD = b²，其中 b 为椭圆短半轴长）

    **课堂讲解建议：**

    1. 先用 SCENE_1 验证圆的结论，建立认知基础
    2. 再用 SCENE_2 探究椭圆，让学生自己发现规律
    3. 最后用 SCENE_3 总结类比关系，强化数学思想方法
    4. 可补充说明：当椭圆退化为圆时（F₁、F₂重合于 O），结论一致
