[分步序列]
本场景为连续交互模式，无分步导航，状态随拖拽实时更新：
- 初始状态（P 在椭圆左上象限，约参数角 120°）：
  - 显示完整椭圆、长轴 AB、焦点 F₁/F₂、中心 O
  - 显示切线 AC、BD、CD
  - 显示线段 PC、PD、PF₁、PF₂
  - 数值框显示当前 PC、PD 长度及乘积、PF₁·PF₂、b²
  - P 点可拖拽

- 拖拽交互状态：
  - P 点沿椭圆轨迹移动（约束在椭圆曲线上）
  - 切线 CD 实时更新（始终过 P 点且与椭圆相切）
  - 线段 PC、PD、PF₁、PF₂ 实时更新
  - 数值框实时刷新显示

- 关键观察点（教师可引导学生注意）：
  - P 在任意位置时，PC·PD 的值保持不变
  - PC·PD = PF₁·PF₂ = b²（椭圆短半轴的平方）

[交互方案]
- 交互类型：连续拖拽滑块（P 点沿椭圆轨迹拖拽）
- 控件说明：
  - 无外部按钮控件，采用直接拖拽交互
  - P 点为可拖拽元素，约束在椭圆曲线上
  - 数值显示框实时更新 PC、PD、PC·PD、PF₁·PF₂、b²
- 教师操作流程：
  1. 初始状态展示椭圆结构和各线段
  2. 拖拽 P 点沿椭圆移动，引导学生观察数值变化
  3. 提问：PC·PD 的值是否变化？与 PF₁·PF₂ 有何关系？
  4. 引导学生发现 PC·PD = PF₁·PF₂ = b² 的不变量性质

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单，无需复杂库；拖拽交互用原生事件即可实现
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +------------------------------------------+
  |                                          |
  |     C              P              D      |
  |     |             / \             |      |
  |     |            /   \            |      |
  |     +-----------/-----\-----------+      |
  |    A \         /       \         / B     |
  |-------\-------/---------\-------/--------|
  |        \     /     O     \     /         |
  |         \   /  F₂   |   F₁ \   /          |
  |          \ /         |       \ /          |
  |           +----------+--------+           |
  |                                          |
  |  +----------------------------------+    |
  |  | PC=  PD=  PC·PD=                 |    |
  |  | PF₁·PF₂=  b²=                    |    |
  |  +----------------------------------+    |
  |           拖拽 P 点观察关系               |
  +------------------------------------------+
  ```
- 关键实现要点：
  1. 椭圆参数方程：x = cx + rx*cos(θ), y = cy + ry*sin(θ)
  2. P 点拖拽：监听 mousedown/mousemove/mouseup，将鼠标位置映射到椭圆参数角θ
  3. 切线 CD 计算：椭圆上点 P(x₀,y₀) 的切线方程为 (x₀·x)/rx² + (y₀·y)/ry² = 1
     - 与 x=a 交点得 D，与 x=-a 交点得 C
  4. 距离计算：两点间欧氏距离
  5. 数值实时更新：拖拽时重算所有线段长度和乘积
  6. 状态隔离：所有元素 ID 以 scene2- 为前缀
  7. IIFE 隔离：JS 代码包在 (function() { ... })() 中

- ID 命名规范：
  - 椭圆：scene2-ellipse
  - 长轴：scene2-axis-ab
  - 点：scene2-point-a, scene2-point-b, scene2-point-o, scene2-point-f1, scene2-point-f2, scene2-point-p, scene2-point-c, scene2-point-d
  - 切线：scene2-tangent-ac, scene2-tangent-bd, scene2-tangent-cd
  - 线段：scene2-seg-pc, scene2-seg-pd, scene2-seg-pf1, scene2-seg-pf2
  - 标签：scene2-label-a, scene2-label-b, ...
  - 数值显示：scene2-val-pc, scene2-val-pd, scene2-val-product, scene2-val-pf-product, scene2-val-b2
  - 数值框：scene2-value-box

- 椭圆参数：
  - 中心 O(400, 220)
  - 长半轴 a = 280
  - 短半轴 b = 140
  - 焦距 c = √(a²-b²) = √(280²-140²) ≈ 242.5
  - 焦点 F₁(400+120, 220) = (520, 220)，F₂(400-120, 220) = (280, 220)
  - b² = 140² = 19600（按像素单位），实际教学中可用相对单位

- 初始 P 点位置：参数角θ=2π/3（120°），约(260, 341)
