[分步序列]
- 步骤 0（初始状态）：显示球体轮廓、截面小圆（虚线椭圆）、球心 O、截面圆心 O'、A/B/C 三点、点标签 O/A/B/C
- 步骤 1：高亮显示球半径 OB（蓝色加粗），在(340,280)显示标签"R=3"
- 步骤 2：高亮显示垂线段 OO'（红色加粗），在(410,265)显示标签"d=3√2/2"
- 步骤 3：高亮显示小圆半径 O'C（橙色），在(460,300)显示标签"r"，同时显示计算公式文本"r=√(R²-d²)=3√2/2"于(420,180)
- 步骤 4：高亮显示△ABC 三边（绿色加粗），在 B 点显示直角符号，在(300,340)显示"∠ABC=90°"，在(350,355)显示"BA=BC"
- 步骤 5：高亮显示 AC 为直径，在(450,380)显示"AC=2r=3√2"，为后续求 BC 和球面距离做准备

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 内底部左侧(350,455)，点击返回上一状态
  - 「下一步」按钮：位于 SVG 内底部右侧(450,455)，点击进入下一状态
  - 步骤指示器：显示当前步骤编号（如"步骤 2/6"）
- 教师操作流程：
  1. 初始展示球体与截面基本结构，让学生观察空间关系
  2. 点击「下一步」高亮球半径，强调 R=3
  3. 点击「下一步」显示垂线段，讲解球心到平面距离 d
  4. 点击「下一步」显示小圆半径 r 及计算公式，推导 r 值
  5. 点击「下一步」高亮△ABC，讲解等腰直角三角形性质
  6. 点击「下一步」显示 AC 为直径，为求球面距离做铺垫
  7. 可随时点击「上一步」回退复习关键步骤

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单，无需复杂库；SVG 缩放不失真，适合几何图示；原生 JS 足够实现分步状态切换
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +------------------------------------------+
  |                                          |
  |           公式 r=√(R²-d²)                |
  |              (球体轮廓)                  |
  |         A    O                           |
  |       /   \\ |                           |
  |      /     \\| d                         |
  |     B-------C---- r                      |
  |         AC 直径                          |
  |    ∠ABC=90°  BA=BC                       |
  |                                          |
  |         [◀上一步]  [下一步▶]             |
  +------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量(0-5)跟踪当前步骤，steps 数组存储每步显示的元素 ID 列表
  2. 坐标计算：所有坐标硬编码于计划中，JS 直接按坐标创建 SVG 元素
  3. 动画曲线：元素出现使用 fade-in 过渡（opacity 0→1，300ms）
  4. 事件绑定：按钮点击事件切换状态，更新元素可见性
  5. 高亮效果：通过增加 stroke-width 和改变 opacity 实现
- ID 命名规范：所有元素 ID 以 scene1- 为前缀
  - scene1-sphere（球体轮廓）
  - scene1-section-circle（截面小圆）
  - scene1-point-o, scene1-point-o-prime, scene1-point-a, scene1-point-b, scene1-point-c
  - scene1-label-o, scene1-label-a, scene1-label-b, scene1-label-c
  - scene1-radius-ob, scene1-radius-oc, scene1-radius-oa
  - scene1-perp-oo-prime
  - scene1-small-radius-o-prime-c
  - scene1-tri-ab, scene1-tri-bc, scene1-tri-ac
  - scene1-label-r, scene1-label-d, scene1-label-angle, scene1-label-equal
  - scene1-btn-prev, scene1-btn-next, scene1-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
