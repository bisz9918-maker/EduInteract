题目原文：

如图，F 为双曲线 $\frac{x^{2}}{a^{2}}-\frac{y^{2}}{b^{2}}=1$（b＞a＞0）的右焦点，过 F 作直线 l 与圆 $x^{2}+y^{2}=b^{2}$ 切于点 M，与双曲线交于点 P，且 M 恰为线段 PF 的中点，则双曲线的渐近线方程是 $\underline{\hspace{5em}}$．

题目分析：

本题综合考查双曲线、圆的几何性质以及中点坐标公式的应用。核心条件包括：

  1. 双曲线标准方程 $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$，其中 b > a > 0
  2. 右焦点 F 坐标为 $(c, 0)$，其中 $c = \sqrt{a^2 + b^2}$
  3. 圆 $x^2 + y^2 = b^2$ 以原点 O 为圆心，半径为 b
  4. 直线 PF 与圆相切于 M，故 OM ⊥ PF
  5. M 是 PF 的中点

整体讲解思路：

  1. 首先引导学生识别图中的几何对象：双曲线、圆、焦点、切点
  2. 利用切线性质：半径 OM 垂直于切线 PF
  3. 利用中点条件建立坐标关系
  4. 结合 P 在双曲线上，代入方程求解 a、b 关系
  5. 得出渐近线方程 $y = \pm \frac{b}{a}x$

SCENE_1 教学说明：

本图示用于帮助学生建立几何直观，理解题目中的各个条件。

引导步骤：

  1. 先展示基础图形，让学生识别双曲线和圆的位置关系
  2. 添加直线 PF 后，提问：直线与圆有什么特殊关系？（相切）
  3. 高亮 OM 并添加直角符号，强调切线性质：圆的半径垂直于过切点的切线
  4. 标注中点条件，引导学生思考：M 是 PF 中点意味着什么坐标关系？
  5. 总结已知条件：OM = b，OM ⊥ PF，$\vec{PM} = \vec{MF}$

关键公式：

  • 双曲线焦点坐标：$F(c, 0)$，其中 $c = \sqrt{a^2 + b^2}$
  • 切线性质：$\vec{OM} \cdot \vec{PF} = 0$
  • 中点坐标：若 $P(x_P, y_P)$，$F(c, 0)$，则 $M\left(\frac{x_P + c}{2}, \frac{y_P}{2}\right)$

SCENE_2 教学说明：

本图示用于引导学生从几何直观过渡到代数推导，建立方程求解。

推导步骤：

  1. 设 $F(c, 0)$，$P(x_P, y_P)$，由中点公式得 $M\left(\frac{x_P + c}{2}, \frac{y_P}{2}\right)$
  1. M 在圆上：$\left(\frac{x_P + c}{2}\right)^2 + \left(\frac{y_P}{2}\right)^2 = b^2$
  1. OM ⊥ PF：$\vec{OM} \cdot \vec{PF} = 0$
  • $\vec{OM} = \left(\frac{x_P + c}{2}, \frac{y_P}{2}\right)$
  • $\vec{PF} = (c - x_P, -y_P)$
  • 点积：$\frac{x_P + c}{2}(c - x_P) + \frac{y_P}{2}(-y_P) = 0$
  • 化简：$c^2 - x_P^2 - y_P^2 = 0$，即 $x_P^2 + y_P^2 = c^2$
  1. P 在双曲线上：$\frac{x_P^2}{a^2} - \frac{y_P^2}{b^2} = 1$
  1. 联立求解可得 $c = 2b$，结合 $c^2 = a^2 + b^2$，得 $4b^2 = a^2 + b^2$，即 $a^2 = 3b^2$
  1. 渐近线方程：$y = \pm \frac{b}{a}x = \pm \frac{b}{\sqrt{3}b}x = \pm \frac{1}{\sqrt{3}}x = \pm \frac{\sqrt{3}}{3}x$

讲解要点：

  • 强调向量点积为 0 是垂直的代数表达
  • 中点坐标公式是连接几何与代数的桥梁
  • 最终结果需化简为最简形式

总结与课堂讲解建议：

完整解答：

由题意，设 $F(c, 0)$，其中 $c = \sqrt{a^2 + b^2}$。

设 $P(x_P, y_P)$，因 M 为 PF 中点，故 $M\left(\frac{x_P + c}{2}, \frac{y_P}{2}\right)$。

因 M 在圆 $x^2 + y^2 = b^2$ 上：
$$\left(\frac{x_P + c}{2}\right)^2 + \left(\frac{y_P}{2}\right)^2 = b^2 \quad \cdots (1)$$

因 OM ⊥ PF，向量点积为 0：
$$\frac{x_P + c}{2}(c - x_P) - \frac{y_P^2}{2} = 0$$
化简得：$x_P^2 + y_P^2 = c^2 \quad \cdots (2)$

P 在双曲线上：
$$\frac{x_P^2}{a^2} - \frac{y_P^2}{b^2} = 1 \quad \cdots (3)$$

联立 (1)(2)(3) 解得 $c = 2b$，代入 $c^2 = a^2 + b^2$ 得 $a^2 = 3b^2$。

故渐近线方程为：$y = \pm \frac{b}{a}x = \pm \frac{\sqrt{3}}{3}x$

课堂讲解建议：

  1. 先用 SCENE_1 建立几何直观，让学生理解各条件的几何含义
  2. 再用 SCENE_2 展示代数推导过程，强调几何条件如何转化为代数方程
  3. 最后总结：本题的关键是利用切线垂直性质和中点坐标公式建立方程组
  4. 可拓展提问：若 M 不是中点而是其他比例点，如何求解？
