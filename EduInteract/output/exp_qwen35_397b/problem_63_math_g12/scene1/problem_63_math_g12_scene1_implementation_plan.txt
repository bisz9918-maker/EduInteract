[图示主题与整合说明]
- 本图示主题：双曲线与圆的几何配置及切线中点条件
- 整合的内容：双曲线 x²/a² - y²/b² = 1、圆 x² + y² = b²、右焦点 F、切点 M、交点 P、切线垂直条件（OM ⊥ PF）、中点条件（M 为 PF 中点）
- 教学价值：教师可逐步展示从基础图形到几何条件的应用过程，帮助学生理解切线性质、中点条件如何共同约束几何关系，最终推导渐近线方程。分步导航让教师能控制讲解节奏，每一步都有明确的视觉焦点。

[交互方案]
- 交互类型：分步按钮导航（◀ 上一步 / 下一步 ▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于底部控件栏左侧 (150, 465)，点击后返回上一状态
  - 「下一步 ▶」按钮：位于底部控件栏右侧 (550, 465)，点击后进入下一状态
  - 步骤指示器：位于两按钮之间 (380, 470)，显示当前步骤（如"步骤 2/4"）
- 教师操作流程：
  1. 初始展示基础图形（双曲线、圆、焦点），介绍问题背景
  2. 点击「下一步」添加点 P 和线段 PF，说明 P 是双曲线与直线的交点
  3. 点击「下一步」高亮 M 点和 OM，添加直角符号，讲解切线性质（半径垂直于切线）
  4. 点击「下一步」添加等长标记，强调 M 是 PF 中点这一关键条件
  5. 点击「下一步」综合展示所有条件，引导学生推导渐近线方程

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形（双曲线、圆、线段）用 SVG 路径精确绘制最合适；无需复杂动画库；代码轻量易维护
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                    y                             |
  |                    ↑                             |
  |                   / \                            |
  |                  /   \  P                        |
  |                 /     \ ●                        |
  |                /       | \                       |
  |               /    M   |  \                      |
  |      --------●---------●---●-------- x           |
  |             / \        |   F                     |
  |            /   \       |                          |
  |           /     \      |                          |
  |          /       \     |                          |
  |         /         \    |                          |
  |        O           \   |                          |
  |                      \ |                          |
  |                                               |
  |  [◀ 上一步]    步骤 2/4    [下一步 ▶]           |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量（0-4），每个步骤对应一个状态对象，包含显示/隐藏的元素 ID 列表
  2. 双曲线绘制：使用 SVG <path> 元素，通过参数方程或分段贝塞尔曲线近似绘制
  3. 圆绘制：SVG <circle> 元素，cx=400, cy=280, r=90
  4. 坐标转换：数学坐标 (x,y) 转换为像素坐标 (400+x, 280-y)
  5. 事件绑定：两个按钮绑定 click 事件，更新 currentStep 并调用 renderStep() 函数
  6. 动画过渡：元素显示/隐藏使用 CSS transition（opacity 0.3s）实现平滑过渡
- ID 命名规范：所有元素 ID 以 scene1- 为前缀
  - scene1-x-axis, scene1-y-axis
  - scene1-hyperbola-left, scene1-hyperbola-right
  - scene1-circle
  - scene1-point-f, scene1-point-p, scene1-point-m
  - scene1-line-pf, scene1-line-om
  - scene1-right-angle, scene1-equal-pm, scene1-equal-mf
  - scene1-label-o, scene1-label-f, scene1-label-p, scene1-label-m, scene1-label-x, scene1-label-y
  - scene1-btn-prev, scene1-btn-next, scene1-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
