[图示主题与整合说明]
- 本图示主题：坐标关系与代数推导的可视化
- 整合的步骤/概念：向量表示、坐标推导、代数方程建立的全过程，展示如何从几何条件过渡到代数求解
- 教学价值：教师可逐步展示推导过程，每一步依赖前一步结论，帮助学生理解代数推导的逻辑链条。从设点坐标→中点公式→利用|OM|=b→利用OM⊥PF→利用P在双曲线上→联立求解→得出渐近线方程，完整呈现数学思维过程。

[分步序列]
步骤0（初始状态）：
- 显示：坐标系、圆、双曲线右支、点O、F、P、M、线段PF
- 标签：O、F、P、M、(c,0)、(x_P,y_P)
- 推导框：全部隐藏
- 结论框：隐藏
- 按钮：上一步禁用，下一步启用

步骤1（点击下一步）：
- 新增显示：推导框1
- 内容：M为PF中点 ⇒ M((x_P+c)/2, y_P/2)
- 高亮：点M闪烁2次
- 其他元素保持

步骤2（点击下一步）：
- 新增显示：推导框2
- 内容：|OM|=b ⇒ ((x_P+c)/2)² + (y_P/2)² = b²
- 高亮：向量OM加粗显示

步骤3（点击下一步）：
- 新增显示：推导框3
- 内容：OM⊥PF ⇒ 向量OM·向量PF = 0
- 子内容：((x_P+c)/2, y_P/2) · (c-x_P, -y_P) = 0
- 高亮：向量OM和向量PF同时高亮

步骤4（点击下一步）：
- 新增显示：推导框4
- 内容：P在双曲线上 ⇒ x_P²/a² - y_P²/b² = 1
- 高亮：点P闪烁2次，双曲线加粗

步骤5（点击下一步）：
- 新增显示：推导框5
- 内容：联立求解得 b = 2a
- 关键方程：b = 2a 用#2e7d32绿色高亮
- 高亮：推导框5整体绿色边框

步骤6（点击下一步，最终步骤）：
- 新增显示：结论框
- 内容：渐近线方程 y = ±(b/a)x = ±2x
- 结论：y = ±2x 用#2e7d32绿色大号字体
- 高亮：结论框闪烁2次
- 按钮：下一步禁用

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于(280,455)，80×30px，点击回退到前一步
  - 「下一步▶」按钮：位于(440,455)，80×30px，点击前进到下一步
  - 步骤指示器：位于两按钮之间(380,460)，显示"步骤 X/7"
- 教师操作流程：
  1. 初始展示几何图形，让学生观察点O、F、P、M的位置关系
  2. 点击「下一步」逐步展示推导过程
  3. 每步暂停讲解该步的数学原理
  4. 可随时点击「上一步」回退复习
  5. 最终展示渐近线方程结论

[技术实现]
- JS库选择：原生SVG（几何图形）+ 原生JavaScript（交互逻辑）
  - 原因：几何元素简单，原生SVG足够；无需复杂动画库
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  [几何图形区 400×380]  |  [推导区 380×380]      |
  |        y轴             |  [推导框1]             |
  |         ↑              |  [推导框2]             |
  |    P ●  |              |  [推导框3]             |
  |      \  |              |  [推导框4]             |
  |       \ M●             |  [推导框5]             |
  |        \ |             |  [结论框]              |
  |  O------+----F→ x      |                        |
  |         |              |                        |
  +--------------------------------------------------+
  |        [◀上一步]  步骤X/7  [下一步▶]            |
  |              (控件栏 y=440-490)                  |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量currentStep(0-6)跟踪当前步骤
  2. 每个推导框用<g>包裹，初始display="none"，按步骤显示
  3. 按钮事件绑定：上一步(currentStep>0时currentStep--)，下一步(currentStep<6时currentStep++)
  4. 每步更新后调用updateDisplay()函数刷新所有元素可见性
  5. 步骤指示器同步更新
  6. 边界处理：步骤0时禁用上一步，步骤6时禁用下一步
- ID命名规范：所有元素ID以"scene2-"为前缀
  - scene2-axes（坐标轴组）
  - scene2-circle（圆）
  - scene2-hyperbola（双曲线）
  - scene2-point-o, scene2-point-f, scene2-point-p, scene2-point-m
  - scene2-line-pf, scene2-vector-om, scene2-vector-pf
  - scene2-derive-box1 至 scene2-derive-box6
  - scene2-conclusion-box
  - scene2-btn-prev, scene2-btn-next, scene2-step-indicator
- IIFE隔离：所有JS代码包在 (function() { ... })() 中，避免全局污染
- MathJax配置：需引入MathJax CDN渲染公式，配置tex2jax处理行内公式
