[图示主题与整合说明]
- 本图示主题：底面对角线垂直的四边形示例
- 整合的步骤/概念：展示三种底面情况（一般四边形、菱形、正方形），对比对角线AC与BD的垂直关系
- 教学价值：教师可通过切换三种状态，直观展示"对角线互相垂直"是AC⊥B₁D₁的充要条件（因B₁D₁∥BD），帮助学生理解答案的多样性——菱形、正方形、筝形等均满足条件

[分步序列]
多状态切换交互（3个状态）：
- 状态0（初始）：显示一般四边形
  - 四边形顶点：A(350,340), B(280,280), C(340,200), D(450,260)
  - 对角线AC、BD显示，无垂直符号
  - 底部提示：「对角线不垂直」
  - 按钮1高亮，按钮2/3淡化
  
- 状态1：点击「菱形」按钮→切换为菱形
  - 四边形顶点：A(400,350), B(340,270), C(400,190), D(460,270)
  - 对角线AC（垂直）、BD（水平）在(400,270)相交
  - 显示垂直符号（绿色直角标记）
  - 底部提示：「对角线垂直」
  - 按钮2高亮，按钮1/3淡化
  
- 状态2：点击「正方形」按钮→切换为正方形
  - 四边形顶点：A(400,345), B(335,270), C(400,195), D(465,270)
  - 对角线AC、BD长度相等且垂直
  - 显示垂直符号 + 四边等长标记（每边中点外侧短划线）
  - 底部提示：「对角线垂直」
  - 按钮3高亮，按钮1/2淡化

[交互方案]
- 交互类型：多状态切换（3个按钮）
- 控件说明：
  - 按钮1「一般四边形」：(180, 450)，切换到状态0
  - 按钮2「菱形」：(340, 450)，切换到状态1
  - 按钮3「正方形」：(500, 450)，切换到状态2
- 教师操作流程：
  1. 初始展示一般四边形，说明对角线不垂直时AC与B₁D₁不垂直
  2. 点击「菱形」，展示对角线垂直的情况，强调此时AC⊥BD，因B₁D₁∥BD，故AC⊥B₁D₁
  3. 点击「正方形」，展示特殊情况（对角线垂直且等长），说明正方形也满足条件
  4. 引导学生总结：底面对角线互相垂直即可（菱形、正方形、筝形等）

[技术实现]
- JS库选择：原生SVG（简单几何图形，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +------------------------------------------+
  |           状态标签 (y=80)                |
  |                                          |
  |            ┌─────────────┐               |
  |            │   四边形    │               |
  |            │  +对角线    │  (y=150~380)  |
  |            └─────────────┘               |
  |                                          |
  |         提示文字 (y=410)                 |
  |                                          |
  |  [一般]  [菱形]  [正方形]  (y=450~485)   |
  +------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量currentState(0/1/2)跟踪当前状态
  2. 三个状态的顶点坐标预定义为对象数组
  3. 切换状态时：更新四边形path、对角线line、显示/隐藏垂直符号和等长标记
  4. 按钮高亮：当前状态按钮填充深色，其他按钮填充浅色
  5. 动画：使用SVG的transition实现平滑过渡（可选）
- ID命名规范：
  - scene2-quad（四边形path）
  - scene2-diag-ac（对角线AC）
  - scene2-diag-bd（对角线BD）
  - scene2-perp-symbol（垂直符号）
  - scene2-equal-marks（等长标记组）
  - scene2-label-a/b/c/d（点标签）
  - scene2-label-ac/bd（对角线标签）
  - scene2-state-label（状态标签）
  - scene2-hint（底部提示）
  - scene2-btn-0/1/2（三个按钮）
- IIFE隔离：所有JS代码包在(function() { ... })()中，避免全局污染
