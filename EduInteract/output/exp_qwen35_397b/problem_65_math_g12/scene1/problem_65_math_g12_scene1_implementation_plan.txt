[图示主题与整合说明]
- 本图示主题：圆与直角三角形综合——利用直径所对圆周角和相似三角形求线段长度
- 整合的步骤/概念：基础图形展示 → 已知条件标注 → 辅助线 CD 添加 → 相似三角形高亮 → 比例关系与计算结果
- 教学价值：教师可分步引导学生从识别几何性质（直径所对圆周角为直角）到发现相似三角形（△BCD∽△BAC），再到建立比例关系求解，符合逻辑推导的认知规律，每一步都可暂停讲解

[技术实现]
- JS 库选择及原因：原生 SVG
  - 本题为纯几何图形（线段、圆、点、文字），原生SVG足够胜任
  - 无需复杂动画或交互，SVG元素可通过display/css控制显示隐藏
  - 代码简洁，易于多场景合并时避免冲突

- 画布尺寸：800 × 500 px（固定）

- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |                    A(540,150)                    |
  |                     *                            |
  |                    /|                            |
  |                   / | AC=6                       |
  |              D   /  |                            |
  |               *  /   |                            |
  |              /  /    |                            |
  |             /  /     |                            |
  |            /  /      |                            |
  |           /  /       |                            |
  |      B(180,350)------C(540,350)                   |
  |          BC=8                                      |
  |                                                  |
  |         [比例式区域 y=410-435]                    |
  |                                                  |
  |    [◀上一步]  步骤X/4  [下一步▶]  y=460-490       |
  +--------------------------------------------------+
  ```

- 关键实现要点：
  1. 状态机设计：使用变量currentStep（0-4），数组steps存储每步需显示的元素ID列表
  2. 坐标计算：点D坐标通过几何计算预先得出(397,238)，硬编码避免运行时计算误差
  3. 动画曲线：元素出现使用淡入效果（opacity 0→1，300ms），使用CSS transition
  4. 事件绑定：按钮点击事件绑定到updateStep()函数，更新currentStep并刷新显示
  5. 元素显隐：每步调用时，遍历所有元素，根据steps[currentStep]设置display属性

- ID 命名规范：
  - 所有元素ID必须以 scene1- 为前缀
  - 示例：scene1-tri-abc（三角形）、scene1-circle（圆）、scene1-point-a（点A）
  - 标签ID：scene1-label-a、scene1-label-b、scene1-label-c、scene1-label-d、scene1-label-o
  - 标注ID：scene1-anno-ac、scene1-anno-bc、scene1-anno-ab、scene1-anno-bd
  - 辅助线ID：scene1-line-cd
  - 高亮区域ID：scene1-highlight-bac、scene1-highlight-bcd
  - 按钮ID：scene1-btn-prev、scene1-btn-next、scene1-step-indicator

- IIFE 隔离：
  所有JS代码包裹在 (function() { ... })() 中，避免全局变量污染
  示例结构：
  ```javascript
  (function() {
    var currentStep = 0;
    var steps = [...];
    function updateStep() { ... }
    document.getElementById('scene1-btn-next').addEventListener('click', function() {
      if (currentStep < 4) { currentStep++; updateStep(); }
    });
    // 初始化
    updateStep();
  })();
  ```

- 元素分层（z-index概念，SVG中通过DOM顺序实现）：
  1. 底层：三角形高亮填充（半透明）
  2. 中层：三角形边、圆、辅助线
  3. 上层：点、直角标记、角度弧线
  4. 顶层：文字标签、标注
