[分步序列]
- 初始状态（步骤 0）：显示底面 BCED（半透明浅蓝填充）、线段 AF（蓝色）、三棱锥 A'-FED 的棱线（A'D、A'E 实线，A'F 虚线）、点标签 A'、B、C、D、E、F、G、A
- 步骤 1：点击「下一步」→ 从 A'向底面作垂线 A'H（红色），垂足 H 落在 AF 上（红色圆点），显示标签 H，在 H 点处显示直角符号表示 A'H⊥底面
- 步骤 2：点击「下一步」→ 连接 A'G、GF（绿色实线），平面 A'GF 用半透明绿色填充，高亮显示
- 步骤 3：点击「下一步」→ 在平面 A'GF 与平面 BCED 交线 GF 附近显示垂直符号⊥（红色），标注"平面 A'GF⊥平面 BCED"
- 步骤 4：点击「下一步」→ 显示结论文本框："命题(1)(3)均正确"，所有关键元素保持高亮

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 底部左侧 (x=320, y=455)，灰色背景，点击返回上一状态
  - 「下一步」按钮：位于 SVG 底部右侧 (x=460, y=455)，蓝色背景，点击进入下一状态
  - 步骤指示器：位于两按钮之间 (x=400, y=460)，显示"步骤 X/4"
- 教师操作流程：
  1. 初始状态展示基础几何结构，教师介绍题目背景
  2. 点击「下一步」展示垂线 A'H，引导学生观察 H 落在 AF 上，验证命题(1)
  3. 点击「下一步」高亮平面 A'GF，为命题(3)做铺垫
  4. 点击「下一步」展示垂直符号，直观呈现两平面垂直关系，验证命题(3)
  5. 点击「下一步」显示结论，总结两个命题均正确
  6. 教师可随时点击「上一步」回退复习关键步骤

[技术实现]
- JS 库选择：原生 SVG（立体几何图形适合用 SVG 路径和多边形精确绘制，无需复杂 3D 库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +------------------------------------------+
  |                                          |
  |              A'                          |
  |               *                          |
  |              /|\                         |
  |             / | \                        |
  |            /  |  \                       |
  |     B *---*----*---* A                  |
  |        D  G    E                         |
  |          \   |   /                       |
  |           \  |  /                        |
  |            \ | /                         |
  |             \|/                          |
  |              * H                         |
  |              F                           |
  |              C                           |
  |                                          |
  |    [◀上一步]  步骤 1/4  [下一步▶]         |
  +------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用 currentState 变量(0-4)跟踪当前步骤，steps 数组存储每步需显示的元素 ID 列表
  2. 坐标计算：所有坐标预先计算好硬编码，确保立体透视效果一致
  3. 动画曲线：元素出现使用 fade-in 动画（opacity 0→1，duration 300ms）
  4. 事件绑定：按钮点击事件绑定到 stepForward/stepBackward 函数，更新 currentState 并调用 renderState()
  5. 平面填充：用<polygon>元素配合 fill-opacity 实现半透明效果
  6. 虚线绘制：用 stroke-dasharray="5,5"实现
- ID 命名规范：所有交互元素 ID 必须以 scene2-为前缀（如 scene2-base-bced、scene2-plane-agf、scene2-btn-next）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
