[分步序列]
本场景为连续交互模式，无分步导航，状态由滑块位置θ决定：

- 初始状态（θ=0°）：
  - A'与 A 重合，三棱锥退化为平面图形
  - 体积 V=0
  - 夹角φ显示初始值
  - 滑块手柄在最左侧

- 中间状态（0°<θ<180°）：
  - A'位置随θ变化：A'绕 DE 轴旋转，在透视图中沿椭圆轨迹移动
  - 体积 V = (1/3)×底面积×高，高 = AG×sin(θ)
  - 夹角φ随θ连续变化
  - 两条曲线实时绘制到当前位置

- 特殊状态 1（θ=90°）：
  - 体积达到最大值，绿色圆点标记
  - A'在最高点位置
  - 体积曲线达到峰值

- 特殊状态 2（φ=90°时）：
  - 夹角曲线上的点变绿色
  - 显示"垂直!"提示框
  - 验证命题(4)：存在垂直位置

- 最终状态（θ=180°）：
  - A'旋转到另一侧与平面 ABC 共面
  - 体积 V=0
  - 滑块手柄在最右侧

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：
  - 滑块轨道：水平线段，范围 0°-180°，长度 380px
  - 滑块手柄：圆形按钮，可左右拖拽，拖拽时实时更新θ值
  - 滑块数值显示：实时显示当前θ值（整数度）
- 教师操作流程：
  1. 初始状态展示题目条件，三棱锥退化
  2. 缓慢拖动滑块，引导学生观察体积数值变化
  3. 停在θ=90°，强调"此时体积最大"，验证命题(2)正确
  4. 继续拖动，观察夹角变化，当出现"垂直!"提示时停下
  5. 说明命题(4)"不可能垂直"是错误的（因为存在垂直位置）
  6. 可来回拖动，让学生理解连续变化过程

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单，无需复杂库；拖拽交互用原生事件即可；曲线用 SVG path 绘制
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │                    三棱锥立体图区                            │
  │                    (y=50-250)                               │
  │         A'                                                   │
  │        / | \                                                 │
  │       /  |  \                                                │
  │      F---D---E                                               │
  │                     θ指示器                                  │
  ├──────────────────────┬──────────────────────────────────────┤
  │   体积 V-θ曲线图      │     夹角φ-θ曲线图                    │
  │   (50,280)-(380,400)  │     (420,280)-(750,400)             │
  │   [蓝色正弦曲线]      │     [红色变化曲线]                   │
  │   ●最大值点(绿)        │     ●垂直点(绿)+提示框               │
  ├──────────────────────┴──────────────────────────────────────┤
  │                    旋转角θ [━━━━●━━━━] 90°                 │
  │                    (滑块控件 y=440-490)                     │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态管理：单一状态变量 theta（0-180），所有视觉元素基于 theta 计算位置
  2. A'坐标计算：设 G 为旋转中心，A'轨迹为椭圆（透视效果）
     - A'x = Gx + AG × cos(θ) × scale_x
     - A'y = Gy - AG × sin(θ) × scale_y（透视压缩）
  3. 体积计算：V(θ) = V_max × sin(θ)，V_max 为θ=90°时的体积
  4. 夹角计算：用向量法计算 A'E 与 BD 的夹角，φ(θ) = arccos(...)
  5. 曲线绘制：预计算 0-180°的体积和夹角值数组，用 SVG path 绘制，用 clipPath 实现"绘制到当前位置"效果
  6. 拖拽事件：mousedown/mousemove/mouseup 实现滑块拖拽，touch 事件支持移动端
  7. 垂直检测：当 |φ - 90°| < 2°时显示垂直提示
- ID 命名规范：
  - 所有元素 ID 以 scene3- 为前缀
  - 示例：scene3-pyramid-base, scene3-point-A', scene3-slider, scene3-volume-curve, scene3-angle-curve
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
- 动画性能：使用 requestAnimationFrame 更新滑块拖拽时的视觉反馈
