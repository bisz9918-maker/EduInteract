[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）+ 步骤 6 拖拽 P 点
- 控件说明：
  - 「上一步」按钮：位于 SVG 底部左侧 (x=320, y=455)，返回上一状态
  - 「下一步」按钮：位于 SVG 底部右侧 (x=480, y=455)，进入下一状态
  - 步骤指示器：位于底部中央 (x=400, y=455)，显示「步骤 X/6」
  - P 点拖拽：步骤 6 激活，鼠标按下 P 点后沿椭圆路径约束移动
- 教师操作流程：
  1. 点击「下一步」逐步展示椭圆各元素构建过程
  2. 每步暂停讲解该元素的几何意义
  3. 步骤 5 时强调∠PFM 和∠MFB 的红色高亮，说明 FM 平分∠PFB
  4. 步骤 6 拖拽 P 点，让学生观察无论 P 在椭圆上何处，角度平分关系始终成立

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript
  - 原因：几何元素以线段、圆点、椭圆为主，SVG 原生支持良好；无需复杂动画库；代码轻量易维护
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |                    Y 轴                          |
  |                    |                             |
  |              P     |         D                   |
  |               \    |         |                   |
  |                \   |         M                   |
  |     A ----------O--|----F---B|--------l----------|
  |                /   |         |                   |
  |               /    |                             |
  |                    |                             |
  |                                                  |
  |                                                  |
  |                                                  |
  |        [◀上一步]   步骤 X/6   [下一步▶]          |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用 scene1-currentStep 变量跟踪当前步骤 (0-6)，每步对应一组可见元素 ID
  2. 坐标计算：
     - 椭圆参数方程：x=400+200*cos(t), y=250-100*sin(t)
     - P 点初始 t=60°（第一象限）
     - D 点：直线 AP 与 x=600 交点，用参数方程求解
     - M 点：BD 中点，(B+D)/2
  3. 拖拽实现：监听 P 点 mousedown/mousemove/mouseup，将鼠标 x 坐标反算椭圆参数 t，更新 P 及相关元素
  4. 角度弧线：用 SVG <path> 绘制圆弧，起点/终点由向量角度计算
  5. 事件绑定：按钮点击切换步骤，显示/隐藏对应元素组
- ID 命名规范：所有元素 ID 以 scene1- 为前缀
  - scene1-ellipse, scene1-axis-x, scene1-axis-y
  - scene1-point-a, scene1-point-b, scene1-point-f, scene1-point-p, scene1-point-d, scene1-point-m, scene1-point-o
  - scene1-line-l, scene1-line-ap, scene1-line-fm, scene1-line-pf, scene1-line-fb
  - scene1-label-a, scene1-label-b, scene1-label-f, scene1-label-p, scene1-label-d, scene1-label-m, scene1-label-o, scene1-label-l
  - scene1-arc-angle1, scene1-arc-angle2, scene1-label-angle1, scene1-label-angle2
  - scene1-btn-prev, scene1-btn-next, scene1-step-indicator
  - scene1-checkmark（绿色验证标记）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
