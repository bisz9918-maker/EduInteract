[图示主题与整合说明]
- 本图示主题：结论④分析（PM=BM 的可能性）
- 整合内容：线段 PM 和 BM 长度关系的动态分析；判断是否存在 P 点使 PM=BM
- 教学价值：教师可通过拖拽滑块连续改变 P 点位置，实时观察 PM 和 BM 长度变化规律，配合长度差曲线图直观判断是否存在零点（即 PM=BM 的情况）。学生可理解参数化分析方法和函数零点思想。

[分步序列]
本场景为连续交互模式，无固定步骤，状态随滑块连续变化：

- 初始状态（θ=0.5π，P 在椭圆上顶点）：
  - 显示完整几何结构：椭圆、坐标轴、A、B、O、F、切线 l
  - P 点位于 (280,130)（上顶点位置）
  - 计算并显示 D、M 点位置
  - 绘制线段 PM（蓝色）、BM（绿色）
  - 显示|PM|和|BM|数值标签
  - 长度差曲线图预绘制完整曲线（θ从 0.1π到 0.9π）
  - 滑块位于中间位置

- 拖拽滑块向左（θ减小，P 向右移动）：
  - P 点沿椭圆顺时针移动
  - D、M 点位置实时更新
  - PM、BM 线段长度变化
  - |PM|、|BM|数值实时更新
  - 曲线图上标记当前θ对应的位置点（红色圆点）

- 拖拽滑块向右（θ增大，P 向左移动）：
  - P 点沿椭圆逆时针移动
  - 同上实时更新

- 观察结论：
  - 长度差曲线始终在 x 轴上方（或下方），无零点
  - 说明不存在θ使|PM|=|BM|
  - 结论④正确

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：
  1. 滑块（slider）：位于 SVG 底部 (100,460)-(400,480)，控制离心角θ从 0.1π到 0.9π连续变化
  2. 数值显示区：位于 (420,470)，实时显示当前θ角度值、|PM|长度、|BM|长度
  3. 曲线图标记点：在长度差曲线上用红色圆点标记当前θ对应的位置

- 教师操作流程：
  1. 初始状态展示 P 在上顶点时的几何结构和长度值
  2. 缓慢拖拽滑块，让学生观察 P 点移动时 PM 和 BM 长度的变化
  3. 引导学生注意长度差曲线始终不为零（无交点）
  4. 得出结论：不存在 P 点使 PM=BM，结论④正确

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单，无需复杂库；SVG 便于动态更新坐标和样式

- 画布尺寸：800 × 500 px（固定）

- 布局草图（ASCII）：

- 关键实现要点：
  1. 参数化 P 点坐标：P(280+200cosθ, 250-120sinθ)，θ∈(0,π)
  2. 直线 AP 方程：两点式求 AP 与 x=520 的交点 D
  3. M 为 BD 中点：M = ((Bx+Dx)/2, (By+Dy)/2)
  4. 距离公式：|PM| = sqrt((Px-Mx)²+(Py-My)²)，|BM|同理
  5. 预计算长度差曲线：θ从 0.1π到 0.9π，步长 0.01π，计算 90 个点
  6. 曲线图坐标映射：θ→x 轴，|PM-BM|→y 轴（适当缩放）
  7. 实时更新：slider 的 input 事件触发所有元素坐标和标签更新

- ID 命名规范：
  - 所有元素 ID 以 scene3- 为前缀
  - 示例：scene3-ellipse, scene3-point-p, scene3-segment-pm, scene3-label-pm, scene3-slider, scene3-curve-diff
