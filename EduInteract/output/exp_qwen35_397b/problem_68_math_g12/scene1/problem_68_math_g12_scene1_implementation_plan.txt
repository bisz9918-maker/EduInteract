[技术实现]
- JS库选择：原生SVG（几何图形简单，无需复杂库）
- 画布尺寸：800×500px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +------------------------------------------+
  |                                          |
  |         C(290,211)                       |
  |        /|                                |
  |       / | CD                             |
  |      /  |                                |
  |     /   |                                |
  |    /    |                                |
  |   O-----D--------B--------P              |
  |  A      |                                |
  |                                          |
  |         [控件栏 y=450~490]               |
  |      [◀上一步] [下一步▶] 步骤 X/4        |
  +------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量currentStep(0-4)跟踪当前步骤，数组steps存储每步显示的元素ID列表
  2. 坐标计算：C点坐标通过几何关系预计算(290,211)，D点为C在AB上的垂足(290,280)
  3. 动画曲线：元素淡入用CSS transition opacity 0.3s ease
  4. 事件绑定：按钮点击事件切换currentStep，调用updateScene()更新显示状态
  5. 元素ID规范：所有元素ID以"scene1-"为前缀（如scene1-circle-o、scene1-line-oc、scene1-label-cd）
  6. IIFE隔离：所有JS代码包在(function() { ... })()中，避免全局污染
- C点坐标计算验证：
  - cos(∠COP) = OC/OP = 2/4 = 0.5 → ∠COP = 60°
  - Cx = 250 + 80×cos(60°) = 250 + 40 = 290
  - Cy = 280 - 80×sin(60°) = 280 - 69.28 ≈ 211（向上为y减小）
- CD长度验证：
  - △OCD∽△OPC → CD/PC = OC/OP
  - PC = √(OP²-OC²) = √(16-4) = √12 = 2√3
  - CD = PC × OC/OP = 2√3 × 2/4 = √3
