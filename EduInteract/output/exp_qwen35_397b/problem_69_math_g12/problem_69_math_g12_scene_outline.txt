    **题目原文：**

    如图，已知三棱柱 ABC-A₁B₁C₁ 的六个顶点都在球 O 的球面上，若 AA₁⊥平面 A₁B₁C₁，A₁B₁⊥B₁C₁，AA₁=8，A₁B₁=6，A₁C₁=2√34，则球 O 的体积为 ______。

    **题目分析：**

    本题考查直三棱柱的外接球问题。关键信息：
    1. 三棱柱为直棱柱（AA₁⊥底面）
    2. 底面 A₁B₁C₁ 是直角三角形（A₁B₁⊥B₁C₁，直角在 B₁）
    3. 六个顶点共球，求外接球体积

    解题核心思路：
    - 先由勾股定理求 B₁C₁
    - 直角三角形外心在斜边中点
    - 直棱柱外接球球心在上下底面外心连线的中点
    - 利用勾股定理求球半径 R
    - 代入球体积公式 V = (4/3)πR³

    **图示规划说明：**

    共设计 2 个图示场景：
    - SCENE_1：展示三棱柱立体结构、已知条件标注、底面直角三角形性质
    - SCENE_2：展示外接球球心位置、半径推导的几何关系

    两个场景形成递进：从理解几何体结构 → 推导外接球半径。

    <TEXT_3>
    **教学要点：**

    本图示展示外接球半径的推导过程，是解题的核心环节。

    **讲解引导：**

    1. **外心定位原理**：
       - 直角三角形的外心在斜边中点
       - 底面 A₁B₁C₁ 的外心 O₁ 是 A₁C₁ 的中点
       - O₁A₁ = O₁C₁ = O₁B₁ = A₁C₁/2 = √34

    2. **球心定位原理**：
       - 直棱柱的外接球球心在上下底面外心连线的中点
       - O 是 O₁O₂ 的中点
       - OO₁ = AA₁/2 = 8/2 = 4

    3. **半径计算**：
       - 在直角三角形 OO₁A₁ 中，∠OO₁A₁ = 90°
       - R² = OO₁² + O₁A₁² = 4² + (√34)² = 16 + 34 = 50
       - R = 5√2

    4. **球体积计算**：
       - V = (4/3)πR³ = (4/3)π(5√2)³ = (4/3)π×250√2 = (1000√2/3)π

    **完整解答：**

    由题意，底面 A₁B₁C₁ 为直角三角形，A₁C₁ 为斜边。

    B₁C₁ = √(A₁C₁² - A₁B₁²) = √(136 - 36) = √100 = 10

    底面外接圆半径 r = A₁C₁/2 = √34

    球心 O 到平面 A₁B₁C₁ 的距离 d = AA₁/2 = 4

    球半径 R = √(r² + d²) = √(34 + 16) = √50 = 5√2

    球体积 V = (4/3)πR³ = (1000√2/3)π

    **课堂讲解建议：**

    - 先让学生回顾直角三角形外心的性质
    - 引导学生思考：直棱柱外接球的球心在哪里？为什么？
    - 强调"化空间为平面"的思想：将三维问题转化为直角三角形 OO₁A₁ 求解
    - 最后验证答案的合理性
    </TEXT_3>
