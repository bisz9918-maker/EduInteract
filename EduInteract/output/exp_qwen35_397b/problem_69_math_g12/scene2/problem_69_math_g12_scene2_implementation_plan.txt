[分步序列]
- 初始状态（步骤 0）：显示三棱柱线框图（9 条棱线 + 6 个顶点标签 A,B,C,A₁,B₁,C₁），无辅助线
- 步骤 1：点击「下一步」→ 显示底面斜边 A₁C₁（虚线），标注中点 O₁（蓝色圆点 + 标签），显示标注"A₁C₁=2√34"和"O₁A₁=√34"
- 步骤 2：点击「下一步」→ 显示顶面斜边 AC，标注中点 O₂（蓝色圆点 + 标签），显示线段 O₁O₂（虚线）
- 步骤 3：点击「下一步」→ 标注 O₁O₂ 中点 O（蓝色圆点 + 标签"球心 O"），连接 OA₁（红色粗线，标注"R"）
- 步骤 4：点击「下一步」→ 高亮直角三角形 OO₁A₁（绿色虚线边框），标注"OO₁=4"（半高）、"O₁A₁=√34"、"OA₁=R"
- 步骤 5：点击「下一步」→ 右侧公式区显示完整计算：R²=4²+(√34)²=16+34=50 → R=5√2 → V=(4/3)πR³=(1000√2/3)π

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 底部左侧 (x=320, y=455)，灰色背景，点击回退到前一状态
  - 「下一步」按钮：位于 SVG 底部右侧 (x=460, y=455)，蓝色背景，点击进入下一状态
  - 步骤指示器：位于两按钮之间 (x=400, y=455)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始展示三棱柱，让学生观察几何结构
  2. 点击「下一步」展示底面外心 O₁，讲解"直角三角形外心在斜边中点"
  3. 点击「下一步」展示顶面外心 O₂，说明上下对称
  4. 点击「下一步」展示球心 O，讲解"球心在 O₁O₂ 中点"
  5. 点击「下一步」高亮直角三角形，引导学生用勾股定理求 R
  6. 点击「下一步」显示完整计算，得出最终体积

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单，无需复杂库；SVG 便于精确控制坐标和样式；原生 JS 足够实现分步状态切换
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |    C₁                                            |
  |     *                                            |
  |     | \                                          |
  |     |   \ A₁                                     |
  |     |     *                                       |
  |     |    /                                        |
  |    O₁*---/---- O₂                                 |
  |     | /      *                                    |
  |     |/        \                                   |
  |     *----------* A                                |
  |    C          /                                   |
  |              /                                    |
  |             O * (球心)                            |
  |                                                  |
  |                              [公式区]             |
  |                              R²=4²+(√34)²        |
  |                              =50                 |
  |                              R=5√2               |
  |                                                  |
  |    [◀上一步]  步骤 X/5  [下一步▶]                |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用 currentState 变量(0-5)跟踪当前步骤，steps 数组存储每步需显示的元素 ID 列表
  2. 坐标计算：所有顶点坐标硬编码，O₁/O₂/O 通过中点公式计算确保精确
  3. 动画曲线：元素出现用 opacity 过渡(0→1, 300ms)，无需复杂位移动画
  4. 事件绑定：按钮点击事件切换 currentState，调用 render() 更新显示
  5. 元素显隐：用 display:none / display:block 或 opacity 控制
- ID 命名规范：所有元素 ID 以 scene2- 为前缀
  - 顶点：scene2-A, scene2-B, scene2-C, scene2-A1, scene2-B1, scene2-C1
  - 棱线：scene2-edge-AA1, scene2-edge-BB1, scene2-edge-CC1, scene2-edge-AB, scene2-edge-BC, scene2-edge-CA, scene2-edge-A1B1, scene2-edge-B1C1, scene2-edge-A1C1
  - 辅助点：scene2-O1, scene2-O2, scene2-O
  - 辅助线：scene2-OO1, scene2-O1A1, scene2-OA1
  - 标签：scene2-label-O1, scene2-label-O2, scene2-label-O, scene2-label-formula
  - 按钮：scene2-btn-prev, scene2-btn-next, scene2-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
