    **题目原文：**

    如图所示，闭合开关后将变阻器的滑片向右移动，下列说法正确的是（）

    A.电路总电阻变小
    B.弹簧测力计示数变小
    C.电磁铁的磁性增强
    D.电流表读数变大

    **题目分析：**

    本题综合考查电路动态分析与电磁铁磁性强弱的影响因素。核心逻辑链为：滑片移动 → 电阻变化 → 电流变化 → 磁性变化 → 受力变化 → 测力计示数变化。

    **整体讲解思路：**

    1. 首先识别电路结构：定值电阻、滑动变阻器、电磁铁线圈串联，电流表测总电流
    2. 分析滑片右移时变阻器接入电阻的变化
    3. 根据欧姆定律判断电流变化
    4. 理解电磁铁磁性强弱与电流大小的关系
    5. 分析铁球受力：重力（向下）、弹簧拉力（向上）、电磁铁吸引力（向下）
    6. 得出测力计示数变化结论

    - SCENE_2：铁球受力分析图，展示重力、拉力、吸引力的平衡关系及变化

    **教学说明：**

    本图示用于讲解电路动态分析的因果链条。教师应引导学生按以下步骤观察：

    1. **识别电路结构**：强调三者串联（定值电阻、变阻器、电磁铁线圈），电流表测串联电流

    2. **滑片移动分析**：提问学生"滑片向右移动时，接入电路的电阻丝长度如何变化？"引导学生得出电阻变大的结论

    3. **欧姆定律应用**：根据 I = U/R 总，电源电压不变，总电阻变大，故电流变小

    4. **电磁铁磁性**：强调磁性强弱与电流大小成正比（匝数、铁芯不变时），电流减小则磁性减弱

    **关键公式：**

    - 串联总电阻：R 总 = R 定 + R 变 + R 线圈
    - 欧姆定律：I = U / R 总

    **教学说明：**

    本图示用于讲解铁球的受力平衡关系。教师应强调：

    1. **受力分析**：铁球受三个力作用
       - 重力 G：竖直向下，大小不变
       - 弹簧拉力 F 拉：竖直向上，等于测力计示数
       - 电磁铁吸引力 F 吸：竖直向下，随磁性变化

    2. **平衡条件**：铁球静止，合力为零
       - 向上力 = 向下力
       - F 拉 = G + F 吸（注意：吸引力向下，与重力同向）

    **更正：** 重新分析受力方向——电磁铁在铁球下方，吸引力应向下。但根据常见题型，电磁铁通常在铁球下方吸引铁球向下，此时：
    - 若电磁铁在铁球**下方**：F 拉 = G + F 吸，F 吸减小则 F 拉减小
    - 若电磁铁在铁球**上方**：F 拉 = G - F 吸，F 吸减小则 F 拉增大

    根据题图，电磁铁在铁球**下方**，故吸引力向下，F 拉 = G + F 吸。当 F 吸减小时，F 拉减小，测力计示数变小。

    **正确答案：B**

    **完整解答：**

    1. 滑片右移 → 变阻器接入电阻变大
    2. 总电阻变大 → 电流变小（A 错、D 错）
    3. 电流变小 → 电磁铁磁性减弱（C 错）
    4. 磁性减弱 → 对铁球吸引力减小
    5. F 拉 = G + F 吸，F 吸减小 → F 拉减小 → 测力计示数变小（B 对）
