[图示主题与整合说明]
- 本图示主题：电路动态变化与电磁铁磁性变化的关联演示
- 整合的内容：滑片移动过程、变阻器电阻变化、电流表示数变化、电磁铁磁性强弱变化（用磁感线疏密表示）
- 教学价值：教师可按因果链条逐步推导，从滑片移动到最终磁性变化，分步展示有助于学生理解逻辑关系。学生可直观看到"滑片右移→电阻变大→电流变小→磁性减弱"的完整物理过程

[分步序列]
- 步骤 0（初始状态）：显示完整电路图，所有元件静止，滑片 P 在变阻器中间位置，电流表指针居中，磁感线正常密度，标注基础元件名称（U、A、P）
- 步骤 1：蓝色箭头出现在滑片右侧指向右方，滑片 P 从 x=120 缓慢移动到 x=160（动画 1 秒），高亮变阻器右半部分为红色
- 步骤 2：在变阻器下方显示红色文字"电阻变大"，在控件栏上方显示公式"R 总=R 定+R 变+R 线圈"，变阻器接入电路的电阻丝部分用红色加粗显示
- 步骤 3：电流表指针向左偏转 15 度（蓝色），在电流表左侧显示蓝色文字"电流变小"，公式区更新为"I=U/R 总"，强调电流与电阻的反比关系
- 步骤 4：电磁铁周围的绿色磁感线从 5 条减少到 2 条（间距变大表示变稀疏），在电磁铁右侧显示绿色文字"磁性减弱"，弹簧测力计示数略微减小（铁球上移 3px）
- 步骤 5（结论）：完整因果链以箭头形式展示在底部："滑片右移 → 电阻变大 → 电流变小 → 磁性减弱"，所有高亮保持，教师可总结

- "A"(45,240) 与 "电流变小"(40,210)：水平距离 5px，垂直距离 30px → 需调整，将"电流变小"移至 (30,200)
- "P"(120,355) 与 "右移箭头"(150,390)：水平距离 30px，垂直距离 35px → 无冲突
- "电阻变大"(180,400) 与 其他标签：周围无其他标签 → 无冲突
- "磁性减弱"(590,220) 与 "电磁铁"(590,340)：垂直距离 120px → 无冲突
- "铁球"(670,150) 与 弹簧测力计：铁球在测力计下方，标签在右侧 → 无冲突

解决方案：将"电流变小"标签从 (40,210) 调整至 (30,200)，确保与"A"标签有足够间距

[交互方案]

  - 上一步按钮：位置 (500,455)，80×30px，灰色背景，点击返回上一状态

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：电路图以几何形状和路径为主，SVG 缩放不失真；无需复杂动画库，原生 CSS transition 和 JS 控制足够
- 画布尺寸：800×500px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +----------------------------------------------------------+
  |  [弹簧测力计]                                            |
  |       |                                                  |
  |     [铁球]                                               |
  |                                                          |
  |  [定值电阻]                    [电磁铁]  [磁感线]        |
  |       |                         |||||   ~~~~~~          |
  |  [电流表]                       |||||   ~~~~~~          |
  |       |                         |||||                    |
  |  [滑动变阻器]←[滑片 P]→          |||||                    |
  |       |                          |||                     |
  |  [电源]--[开关]------------------+                       |
  |                                                          |
  |                    [公式区]                              |
  +----------------------------------------------------------+
  |  [上一步]  [下一步]              [步骤指示器]             |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用 currentState 变量 (0-5) 跟踪当前步骤，steps 数组存储每步的显示配置
  2. 滑片动画：使用 CSS transition 实现滑片从 x=120 到 x=160 的平滑移动
  3. 指针偏转：电流表指针用 transform: rotate() 实现，初始 0 度，步骤 3 变为 -15 度
  4. 磁感线疏密：用 opacity 和 display 控制 5 条磁感线的显示数量，步骤 4 只显示 2 条
  5. 事件绑定：按钮点击事件调用 stepForward()/stepBackward() 函数更新状态
  6. IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
- ID 命名规范：所有元素 ID 以 scene1- 为前缀
  - scene1-power, scene1-switch, scene1-ammeter, scene1-resistor-fixed
  - scene1-rheostat, scene1-slider-p, scene1-electromagnet
  - scene1-spring-scale, scene1-iron-ball
  - scene1-mag-line-1~5 (5 条磁感线)
  - scene1-btn-prev, scene1-btn-next, scene1-step-indicator
  - scene1-label-u, scene1-label-a, scene1-label-p
  - scene1-label-res-up, scene1-label-current-down, scene1-label-mag-weak
  - scene1-formula-box
