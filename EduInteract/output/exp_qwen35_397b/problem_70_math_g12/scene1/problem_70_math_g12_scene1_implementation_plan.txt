[图示主题与整合说明]
- 本图示主题：四棱锥基础结构与已知垂直关系展示
- 整合内容：四棱锥立体结构、PA⊥底面、底面菱形性质、BD⊥平面 PAC 的推导过程
- 教学价值：教师可逐步展示四棱锥中垂直关系的传递链条，从 PA⊥底面出发，通过底面菱形对角线互相垂直的性质，推导出 BD⊥平面 PAC，进而得到 BD⊥PC，为后续判断平面 MBD⊥平面 PCD 的条件做铺垫。分步展示帮助学生理解立体几何中"线线垂直→线面垂直→线线垂直"的逻辑推理过程。

[视觉元素清单]
- 四棱锥框架：由 8 条棱线构成的立体图形，顶点 P 在左上，底面 ABCD 呈菱形透视
- 可见棱（实线#000000）：PB、PC、BC、CD 共 4 条
- 不可见棱（虚线#888888）：PA、PD、AB、DA、AC 共 5 条
- 对角线 BD（虚线#2e7d32）：步骤 2 开始高亮显示
- 顶点标签：P、A、B、C、D 五个大写字母，黑色#000000，字号 16px
- 垂直符号：红色#c62828 直角标记，15×15px
- 高亮色：PA 高亮时用#1565c0 蓝色，BD 高亮时用#2e7d32 绿色
- 结论文字：蓝色#1565c0，字号 14px，位于左上角区域

[分步序列]
- 初始状态（步骤 0）：显示基础四棱锥框架
  - 显示所有 8 条棱线（4 条实线可见棱 + 4 条虚线不可见棱）
  - 显示两条对角线 AC、BD（均为虚线#888888）
  - 显示 5 个顶点标签 P、A、B、C、D
  - 不显示任何垂直符号和结论文字

- 步骤 1：高亮 PA⊥底面
  - 棱 PA 颜色从#888888 变为#1565c0（蓝色高亮）
  - 在 A 点附近显示红色#c62828 直角符号（表示 PA 垂直于底面）
  - 在直角符号右侧显示文字"PA⊥底面"（#c62828）
  - 其他元素保持不变

- 步骤 2：高亮底面菱形对角线 AC⊥BD
  - 对角线 BD 颜色从#888888 变为#2e7d32（绿色高亮）
  - 在 AC 与 BD 交点附近显示红色#c62828 直角符号
  - 在直角符号右侧显示文字"AC⊥BD"（#c62828）
  - PA 保持高亮状态，步骤 1 的垂直符号和文字保留

- 步骤 3：展示 BD⊥平面 PAC
  - 在画布左上角 (50,20) 显示结论文字"BD⊥平面 PAC"（#1565c0）
  - 平面 PAC 区域（三角形 PAC）用#1565c0 填充，透明度 15%
  - 步骤 1、2 的所有高亮和标记保留

- 步骤 4：展示 BD⊥PC
  - 在画布左上角 (50,45) 显示结论文字"BD⊥PC"（#1565c0）
  - 棱 PC 用#1565c0 高亮显示（加粗或变色）
  - 所有之前的高亮、标记、结论文字保留
  - 完成垂直关系传递链条的展示

[交互方案]
- 交互类型：分步按钮导航
- 控件说明：
  - 「◀ 上一步」按钮：位于 SVG 内底部左侧 (x=320, y=460)，点击返回上一状态
  - 「下一步 ▶」按钮：位于 SVG 内底部右侧 (x=480, y=460)，点击进入下一状态
  - 步骤指示器：位于两按钮之间 (x=400, y=465)，显示"步骤 X/4"
- 教师操作流程：
  1. 初始展示四棱锥基础结构，让学生识别各顶点和棱
  2. 点击「下一步」高亮 PA，讲解 PA 垂直于底面 ABCD 的已知条件
  3. 点击「下一步」高亮 BD，讲解底面是菱形，对角线互相垂直
  4. 点击「下一步」展示 BD⊥平面 PAC，讲解线面垂直的判定（BD 垂直于平面 PAC 内的两条相交直线 PA 和 AC）
  5. 点击「下一步」展示 BD⊥PC，讲解线面垂直的性质（垂直于平面则垂直于平面内任意直线）
  6. 教师可随时点击「上一步」回退复习关键步骤

[技术实现]
- JS 库选择及原因：原生 SVG。理由：四棱锥为静态几何图形，只需简单的线条绘制和颜色切换，原生 SVG 足够胜任且代码简洁，无需引入额外库。
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  | (50,20) 结论文字区                                |
  | BD⊥平面 PAC                                       |
  | BD⊥PC                                             |
  |                                                   |
  |         P(140,70)                                 |
  |        / |  \                                     |
  |       /  |   \                                    |
  |      D   |    C                                   |
  |     /    |     \                                  |
  |    A-----+------B                                 |
  |         (底面菱形)                                 |
  |                                                   |
  |                                                   |
  |                                                   |
  |              [◀ 上一步]  步骤 X/4  [下一步 ▶]      |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentState 记录当前步骤 (0-4)，数组 steps 存储每步的显示配置
  2. 坐标计算：所有顶点坐标硬编码，确保立体透视效果一致
  3. 虚线实现：SVG stroke-dasharray="5,5" 实现虚线效果
  4. 动画曲线：颜色切换用 CSS transition: fill 0.3s, stroke 0.3s 实现平滑过渡
  5. 事件绑定：按钮点击事件绑定到 updateScene() 函数，根据 currentState 更新各元素显示状态
  6. 平面填充：用<polygon>元素绘制三角形 PAC，fill="#1565c0" fill-opacity="0.15"
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀
  - scene1-vertex-p, scene1-vertex-a, scene1-vertex-b, scene1-vertex-c, scene1-vertex-d
  - scene1-edge-pa, scene1-edge-pb, scene1-edge-pc, scene1-edge-pd
  - scene1-edge-ab, scene1-edge-bc, scene1-edge-cd, scene1-edge-da
  - scene1-diag-ac, scene1-diag-bd
  - scene1-label-p, scene1-label-a, scene1-label-b, scene1-label-c, scene1-label-d
  - scene1-perp-symbol-1, scene1-perp-text-1 (PA⊥底面)
  - scene1-perp-symbol-2, scene1-perp-text-2 (AC⊥BD)
  - scene1-conclusion-1 (BD⊥平面 PAC)
  - scene1-conclusion-2 (BD⊥PC)
  - scene1-plane-pac (平面 PAC 填充区域)
  - scene1-btn-prev, scene1-btn-next, scene1-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
