[视觉元素清单]
- 四棱锥 P-ABCD：6 条棱线（PA/PB/PC/AB/BC 实线#000000，PD/CD/DA/BD 虚线#888888）
- 动点 M：红色圆点# c62828，r=6，位于 PC 线段上
- 平面 MBD：三角形填充#1565c0 透明度 20%
- 平面 PCD：三角形填充#2e7d32 透明度 20%
- 线段 DM：#c62828 实线，连接 D 和 M
- 线段 BM：#000000 实线，连接 B 和 M
- 二面角标记：弧线+角度值θ，位于两平面交线 CD 附近
- 垂直符号：直角标记，仅当 DM⊥PC 时显示
- 顶点标签：P/A/B/C/D 各点标签，偏移方向见坐标表
- 动点标签 M：跟随 M 点移动
- 角度显示区：右侧显示当前二面角度数
- 滑块控件：底部水平滑块控制 M 位置

[分步序列]
本场景为连续拖拽交互，无分步导航，状态连续变化：
- 初始状态：M 位于 PC 中点（50% 位置），显示四棱锥、平面 MBD、平面 PCD、DM/BM 连线，右侧显示当前二面角度数（约 60°）
- 拖拽状态：教师拖动滑块，M 沿 PC 线段从 P 向 C 移动，平面 MBD 随之变形，二面角θ实时变化
- 垂直状态：当 M 移动到使 DM⊥PC 的位置（约 PC 的 65% 处）时，系统自动高亮 DM 线# c62828 加粗，M 点放大，显示垂直符号"⊥"，右侧显示"垂直"标记
- 越界状态：M 继续移动超过垂直位置后，高亮和垂直符号消失

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：
  - 滑块轨道：水平线段 (100,460)-(500,460)，#888888
  - 滑块手柄：圆形 r=12，可拖拽，控制 M 在 PC 上的位置（0%=P，100%=C）
  - 角度显示：右侧 (700,150) 显示当前二面角度数θ
  - 垂直标记：(700,180) 显示"⊥"，仅当 DM⊥PC 时显示
- 教师操作流程：
  1. 初始状态展示四棱锥和两个平面
  2. 拖动滑块，M 从 P 向 C 移动，学生观察二面角θ变化
  3. 当接近垂直位置时，系统高亮提示
  4. 停在垂直位置，强调"当 DM⊥PC 时，平面 MBD⊥平面 PCD"
  5. 可继续拖动验证其他位置不满足垂直条件

[技术实现]
- JS 库选择：原生 SVG（几何图形绘制简洁，支持交互事件）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +------------------------------------------+
  |  P                                       |
  |   \           角度显示区                  |
  |    \         θ=___°  ⊥                   |
  |     M(动点)                               |
  |    / \                                    |
  |   D---C                                   |
  |  /     \                                  |
  | A-------B                                 |
  |                                            |
  |  [滑块轨道 ====================]           |
  |         M 位置：P ←→ C                     |
  +------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：M 位置用 0-1 的参数 t 表示，M = P + t*(C-P)
  2. 坐标计算：PC 线段参数方程，M 点坐标 = (150+500t, 80+240t)
  3. 二面角计算：平面 MBD 法向量 n1 = BM×BD，平面 PCD 法向量 n2 = PC×PD，cosθ = |n1·n2|/(|n1|*|n2|)
  4. 垂直判断：DM·PC = 0 时垂直，即 (M-D)·(C-P) = 0，解得 t ≈ 0.65
  5. 动画曲线：拖拽时实时更新，无需缓动
  6. 事件绑定：滑块 mousedown/mousemove/mouseup 实现拖拽
- ID 命名规范：所有交互元素 ID 必须以 scene2- 为前缀（如 scene2-point-m、scene2-plane-mbd、scene2-slider）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中
