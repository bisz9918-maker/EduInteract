    **题目原文：**

    已知正六边形 A₁A₂⋅⋅⋅A₆ 内接于圆 O，点 P 为圆 O 上一点，向量 $\overrightarrow{OP}$ 与 $\overrightarrow{OA_{i}}$ 的夹角为 θᵢ（i=1，2，⋅⋅⋅，6），若将 θ₁，θ₂，⋅⋅⋅，θ₆ 从小到大重新排列后恰好组成等差数列，则该等差数列的第 3 项为 $\underline{\hspace{5em}}$.

    **题目分析：**

    本题核心是理解向量夹角的定义（两向量间最小角，范围 [0°, 180°]），以及正六边形的对称性。正六边形相邻顶点与圆心连线的夹角为 60°，六个顶点方向角分别为 0°, 60°, 120°, 180°, 240°, 300°。

    **整体讲解思路：**

    1. 首先展示正六边形结构，明确各顶点的位置关系
    2. 引入点 P，定义向量夹角 θᵢ
    3. 利用对称性，只需考虑 P 在弧 A₁A₂ 上的情况
    4. 建立 6 个夹角与 P 位置角 φ 的函数关系
    5. 根据等差数列条件求解 φ
    6. 验证并得出第 3 项

    **图示规划说明：**

    - SCENE_1：正六边形基本结构与角度标注，分步展示各顶点方向角及向量夹角定义
    - SCENE_2：点 P 在弧上移动时，6 个夹角 θᵢ 的动态变化及排序演示，帮助学生发现等差数列条件

    **教学要点：**

    本图示帮助学生建立正六边形的几何模型，理解向量夹角的定义。

    **讲解引导：**

    1. 正六边形内接于圆，相邻顶点与圆心连线的夹角为 360°/6 = 60°
    2. 以 OA₁ 为基准（方向角 0°），各顶点方向角依次为 0°, 60°, 120°, 180°, 240°, 300°
    3. 向量夹角定义为两向量间的最小角，范围 [0°, 180°]
    4. 设 OP 的方向角为 φ，由对称性只需考虑 φ ∈ [0°, 60°]（即 P 在弧 A₁A₂ 上）

    **关键公式：**

    当 φ ∈ [0°, 60°] 时，6 个夹角分别为：
    - θ₁ = φ
    - θ₂ = 60° - φ
    - θ₃ = 120° - φ
    - θ₄ = 180° - φ
    - θ₅ = 120° + φ（因为 240° - φ > 180°，取 360° - (240° - φ)）
    - θ₆ = 60° + φ（因为 300° - φ > 180°，取 360° - (300° - φ)）

    **完整解答：**

    当 φ ∈ [0°, 30°] 时，6 个夹角从小到大排序为：
    φ, 60°-φ, 60°+φ, 120°-φ, 120°+φ, 180°-φ

    成等差数列的条件：
    - 公差 d = (60°-φ) - φ = 60° - 2φ
    - 公差 d = (60°+φ) - (60°-φ) = 2φ

    联立得：60° - 2φ = 2φ ⟹ 4φ = 60° ⟹ φ = 15°

    验证：d = 2φ = 30°

    等差数列为：15°, 45°, 75°, 105°, 135°, 165°

    **第 3 项 = 75°**

    **课堂讲解建议：**

    1. 先用 SCENE_1 建立几何模型，明确正六边形结构和向量夹角定义
    2. 用 SCENE_2 拖拽点 P，让学生观察角度变化规律，猜测等差数列成立的位置
    3. 引导学生建立代数关系，求解 φ = 15°
    4. 验证数列为 15°, 45°, 75°, 105°, 135°, 165°，公差为 30°
    5. 强调对称性的应用：只需考虑 P 在弧 A₁A₂ 上的情况
