[图示主题与整合说明]
- 本图示主题：点 P 移动时 6 个夹角的变化规律及等差数列条件
- 整合的内容：点 P 位置拖拽、6 个夹角 θᵢ 实时计算与显示、排序后的数列、等差条件验证
- 教学价值：教师可通过拖拽滑块直观展示点 P 在圆弧 A₁A₂ 上移动时，向量 OP 与各半径 OAᵢ 夹角的变化规律。当 φ=15° 时，6 个夹角排序后恰好构成等差数列，学生可观察到这一特殊位置，理解等差数列条件的几何意义。

[分步序列]
本场景为连续拖拽交互，无分步导航，状态随滑块位置实时变化：
- 初始状态（φ=15°）：点 P 位于弧 A₁A₂ 中点（φ=15°），显示 6 个夹角值分别为 15°,45°,75°,105°,135°,165°，排序后为等差数列（公差 30°），等差提示高亮显示「等差数列成立！」
- 拖拽状态（φ 可变）：教师拖拽滑块手柄，点 P 沿弧 A₁A₂ 移动，6 个夹角值实时更新，排序数列和公差同步计算
- 非等差状态（φ≠15°）：当 φ 偏离 15° 时，排序后的数列不再满足等差条件，等差提示隐藏或显示「非等差数列」

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：
  - 水平滑块：位于 SVG 底部 y=460，范围 0°-60°，对应点 P 在弧 A₁A₂ 上的位置
  - 滑块手柄：红色圆形，可左右拖拽，拖拽时实时更新 φ 值
  - 当前值显示：滑块上方显示「φ = ?°」
- 教师操作流程：
  1. 初始状态 φ=15°，展示等差数列成立的情况
  2. 拖拽滑块手柄向左（φ 减小），观察夹角值变化，数列不再等差
  3. 拖拽滑块手柄向右（φ 增大），观察夹角值变化，数列不再等差
  4. 回到 φ=15°，强调这是唯一满足等差条件的位置
  5. 引导学生思考：为什么 φ=15° 时恰好构成等差数列？

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（圆、线段、弧），原生 SVG 足够；拖拽交互用原生事件处理即可，无需额外库
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +----------------------------------------------------------+
  |  [几何区 400×400]        [数值面板 330×330]              |
  |       A₃    A₂           ┌─────────────────────┐          |
  |         \  /             │ 夹角值：            │          |
  |      A₄--O--A₁   →       │ θ₁ = 15°            │          |
  |         /  \             │ θ₂ = 45°            │          |
  |       A₅    A₆           │ ...                 │          |
  |                          │ 排序后：15,45,...   │          |
  |                          │ 公差 d = 30°        │          |
  |                          │ [等差数列成立！]    │          |
  |                          └─────────────────────┘          |
  |                                                            |
  |  φ = 15°                                                   |
  |  0° [━━━━━━━━●━━━━━━━━] 60°                               |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 坐标计算：正六边形顶点按 60° 间隔计算，Aᵢ 的角度为 (i-1)×60°
  2. 点 P 位置：P 的角度 = φ（相对于 OA₁），坐标 = (200+120×cosφ, 200-120×sinφ)
  3. 夹角计算：θᵢ = |φ - (i-1)×60°|，若>180° 则用 360° 减去该值
  4. 排序算法：将 6 个夹角值排序，检查相邻差值是否相等
  5. 拖拽事件：mousedown/mousemove/mouseup 或 touch 事件，限制手柄在轨道范围内
  6. 等差判断：排序后检查 θ₍₂₎-θ₍₁₎ = θ₍₃₎-θ₍₂₎ = ... = θ₍₆₎-θ₍₅₎
- ID 命名规范：所有交互元素 ID 以 `scene2-` 为前缀
  - scene2-circle-o, scene2-hexagon, scene2-point-p, scene2-line-op
  - scene2-slider, scene2-slider-handle, scene2-panel-values, scene2-panel-sorted
  - scene2-label-a1 ~ scene2-label-a6, scene2-label-theta1 ~ scene2-label-theta6
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
