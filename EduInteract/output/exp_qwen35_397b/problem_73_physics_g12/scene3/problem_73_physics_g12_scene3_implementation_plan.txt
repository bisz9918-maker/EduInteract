[图示主题与整合说明]
- 本图示主题：能量转化关系与电量计算（第三问）
- 整合的步骤/概念：
  1. 能量守恒定律：重力势能减少 = 动能增加 + 电能消耗
  2. 电量公式推导：q = ∫Idt = BLx/R
  3. 几何关系：h = x·sinθ
  4. 联立求解：由能量守恒求位移 x，再求电量 q
- 教学价值：教师可通过分步展示，帮助学生理解电磁感应中的能量转化过程，掌握电量计算的推导逻辑，避免学生直接套公式而不理解物理意义

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript
  - 原因：本场景以静态框图和公式为主，无需复杂动画或坐标系，原生 SVG 足够实现且性能最优
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────────┐
  │  [重力势能] ←───→ [动能]                                    │ y=60~200
  │      ↑              ↓                                       │
  │      └──────→ [电能] ←──────┘                               │
  │                                                             │
  │  ─────────────────────────────────────────────────────────  │ y=240 分隔线
  │                                                             │
  │  能量守恒方程：mgh = ½mv_m² + Q_电                          │ y=260
  │  几何关系：h = x·sinθ                                       │ y=300
  │  电量推导：q = ∫Idt = BLx/R                                 │ y=340
  │  求解步骤1：由能量守恒求 x                                  │ y=380
  │  求解步骤2：代入求 q                                        │ y=420
  │                                                             │
  │  ─────────────────────────────────────────────────────────  │ y=450 分隔线
  │                                                             │
  │           [◀上一步]          [下一步▶]                      │ y=460~490
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-3），每个状态对应一组可见元素
  2. 元素可见性：所有公式元素初始 display="none"，通过 setState 函数控制显示
  3. 按钮状态：步骤0时上一步按钮禁用（opacity:0.5，pointer-events:none），步骤3时下一步按钮禁用
  4. 高亮效果：通过修改 stroke-width 和 stroke 属性实现框图高亮
  5. 事件绑定：按钮点击事件绑定到 setState 函数，传入目标状态
- ID 命名规范：
  - 重力势能框：scene3-box-potential
  - 动能框：scene3-box-kinetic
  - 电能框：scene3-box-electric
  - 箭头1：scene3-arrow1
  - 箭头2：scene3-arrow2
  - 能量守恒方程：scene3-formula-energy
  - 几何关系式：scene3-formula-geometry
  - 电量推导式：scene3-formula-charge
  - 求解步骤1：scene3-step1
  - 求解步骤2：scene3-step2
  - 上一步按钮：scene3-btn-prev
  - 下一步按钮：scene3-btn-next
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
- MathJax 集成：公式使用 MathJax 渲染，需引入 CDN：https://cdn.jsdelivr.net/npm/mathjax@3/es5/tex-svg.js
