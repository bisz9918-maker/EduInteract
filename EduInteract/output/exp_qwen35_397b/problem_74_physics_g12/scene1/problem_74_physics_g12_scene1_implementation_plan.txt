[分步序列]
- 初始状态（步骤0）：显示题目基础条件
  · 天花板、滑轮、绳索系统
  · 磁场区域（虚线框+磁感线×）
  · 线圈abcd在磁场下方（ab边恰在y=160磁场下边界）
  · 砝码m₂悬挂右侧
  · 所有基础标签：a,b,c,d,B,h,l,m₁,m₂
  · 公式区显示：「问题：求线圈匀速运动速度v」

- 步骤1：ab边刚进入磁场 — 高亮ab边，显示感应电流方向，显示安培力方向
  · ab边加粗变为#1565c0蓝色（线宽4px）
  · 显示逆时针感应电流箭头（4段蓝色箭头沿线圈）
  · 显示安培力F_A箭头（红色向下，作用于ab边中点）
  · 新增标签：I（电流）、F_A（安培力）
  · 公式区显示：「感应电流方向：逆时针（楞次定律）」

- 步骤2：受力分析 — 显示线圈和砝码的受力情况
  · 保留步骤1所有元素
  · 线圈受力：重力m₁g箭头（向下，从线圈中心）、拉力T箭头（向上，从ab边中点）、安培力F_A（已显示）
  · 砝码受力：重力m₂g箭头（向下，从砝码中心）、拉力T箭头（向上，从砝码顶部）
  · 新增标签：m₁g、m₂g、T（两处）
  · 公式区显示：「线圈受力：T向上，m₁g向下，F_A向下」

- 步骤3：匀速条件 — 显示平衡方程
  · 保留步骤2所有元素
  · 高亮平衡关系：对线圈 T = m₁g + F_A，对砝码 T = m₂g
  · 公式区显示：「匀速→平衡：对线圈 T = m₁g + F_A；对砝码 T = m₂g」
  · 联立方程用不同颜色高亮：m₂g = m₁g + F_A（#c62828红色）

- 步骤4：速度求解 — 显示最终计算过程
  · 保留步骤3所有元素
  · 显示安培力公式：F_A = BIl = B²l²v/R
  · 代入数据求解v
  · 公式区显示：「F_A = BIl = B²l²v/R → m₂g = m₁g + B²l²v/R → v = (m₂-m₁)gR/(B²l²)」
  · 最终结果：v = 4 m/s（用#2e7d32绿色高亮）

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  · 「上一步」按钮：位于(250,455)，宽120px，高30px，点击返回上一状态
  · 「下一步」按钮：位于(430,455)，宽120px，高30px，点击进入下一状态
  · 步骤指示器：位于(380,445)，显示「步骤 X/4」
- 教师操作流程：
  1. 初始状态展示题目装置图，教师介绍物理情景
  2. 点击「下一步」进入步骤1，讲解ab边切割磁感线产生感应电流，用右手定则判断电流方向
  3. 点击「下一步」进入步骤2，分析线圈和砝码的受力情况
  4. 点击「下一步」进入步骤3，推导匀速运动的平衡条件
  5. 点击「下一步」进入步骤4，代入安培力公式求解速度
  6. 可随时点击「上一步」回退复习关键概念

[技术实现]
- JS 库选择：原生 SVG（简单几何图形首选，无需额外库）
- 画布尺寸：800 × 500 px（固定画布）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────────┐
  │  天花板 (y=30)                                              │
  │     ○左滑轮(200,50)                    ○右滑轮(600,50)      │
  │         │                                    │              │
  │    ╔═══════════╗ 磁场区域                     │              │
  │    ║ ×  ×  ×  ║ B                            │              │
  │    ║ ×  ×  ×  ║ h                            │              │
  │    ║ ×  ×  ×  ║                              │              │
  │    ╚═══════════╝                              │              │
  │         │                                    │              │
  │    ┌─────────┐ 线圈abcd                       │              │
  │    │ a     b │←I                              │    □ m₂     │
  │    │         │  F_A↓                          │              │
  │    │ d     c │  m₁g↓                          │    m₂g↓     │
  │    └─────────┘  T↑                            │    T↑       │
  │         m₁     l                              │              │
  │                                                                 │
  │  [公式显示区 y=410~435]                                        │
  │                                                                 │
  │  [◀上一步]  步骤 X/4  [下一步▶]  (y=445~485)                   │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-4) 跟踪当前步骤，数组 steps 存储每步显示的元素ID列表
  2. 坐标计算：所有元素坐标硬编码，确保与布局坐标表一致
  3. 动画曲线：元素显示/隐藏使用 CSS transition (opacity 0.3s ease)
  4. 事件绑定：按钮点击事件绑定到 stepChange 函数，更新 currentStep 并调用 renderStep()
  5. 元素分组：用 SVG <g> 元素按功能分组（如线圈组、磁场组、受力分析组），便于批量显示/隐藏
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀
  · scene1-ceiling, scene1-pulley-left, scene1-pulley-right
  · scene1-magnetic-field, scene1-coil, scene1-weight
  · scene1-label-a, scene1-label-b, scene1-label-B, scene1-label-h
  · scene1-current-arrow, scene1-force-fa, scene1-force-m1g, scene1-force-t
  · scene1-btn-prev, scene1-btn-next, scene1-step-indicator
  · scene1-formula-box
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
