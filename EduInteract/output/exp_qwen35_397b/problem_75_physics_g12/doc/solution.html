problem_75_physics_g12

场景导航：Scene 1 | Scene 2 | Scene 3 | Scene 4

题目原文：

如图所示，一平行板电容器水平放置，板间距离为 d，上极板开有一小孔，三个质量均为 m、带电荷量均为 +q 的带电小球，其间用长为 L 的绝缘轻杆相连，处于竖直状态，已知 d=3L。今使下端小球恰好位于小孔中，且由静止释放，让三球竖直下落。当下端小球到达下极板时，速度恰好为零。试求：
（1）两极板间的电压
（2）小球运动的最大速度

题目分析：

本题是带电体在重力场和电场复合场中的运动问题，核心是能量守恒和受力分析。

关键物理过程：

  1. 初始状态：三球竖直排列，最下端小球恰在上极板小孔处
  2. 下落过程：小球依次进入电场，受到向上的电场力
  3. 最终状态：下端小球到达下极板时速度为零

解题思路：

  • 第 (1) 问：用动能定理，重力做功与电场力做功之和为零
  • 第 (2) 问：分析合力变化，找到速度最大的位置（合力为零时）

图示规划：

  • SCENE_1：展示电容器结构与三球初始位置，标注关键尺寸 d=3L
  • SCENE_2：分步展示下落过程，三球依次进入电场，电场力逐步增大
  • SCENE_3：能量分析图，展示重力做功与电场力做功的关系
步骤 1/4

教学要点：

本图示帮助学生建立题目的空间模型，理解初始状态。

引导步骤：

  1. 首先展示平行板电容器，强调水平放置、板间距离为 d
  2. 添加上极板小孔，说明小球从此处开始下落
  3. 展示三球系统，强调：
  • 三球质量相同（均为 m）
  • 三球带电量相同（均为 +q）
  • 用绝缘轻杆相连（杆长均为 L）
  1. 标注 d=3L 的关键关系

关键问题：

  • 小球带正电，电场方向如何？（上极板电势高，电场向下）
  • 小球进入电场后受什么力？（重力向下，电场力向上）
步骤 0/3

教学要点：

本图示展示下落过程的动态变化，帮助学生理解电场力如何随进入电场的小球数变化。

分阶段分析：

阶段 1（下落 0→L）：

  • 0 个小球在电场中
  • 合力 F = 3mg（向下）
  • 小球加速下落

阶段 2（下落 L→2L）：

  • 1 个小球在电场中（最下端小球）
  • 合力 F = 3mg - qE（向下，减小）
  • 小球继续加速，但加速度减小

阶段 3（下落 2L→3L）：

  • 2 个小球在电场中
  • 合力 F = 3mg - 2qE
  • 若 3mg < 2qE，合力向上，小球开始减速

阶段 4（下落 3L 时）：

  • 3 个小球都在电场中
  • 合力 F = 3mg - 3qE
  • 速度恰好为零

关键问题：

  • 速度最大的位置在哪里？（合力为零时）
  • 为什么最终速度为零？（电场力做负功，消耗了重力势能）
步骤 0/5

教学要点：

本图示用能量方法求解第 (1) 问，并分析第 (2) 问的最大速度。

第 (1) 问：求电压 U

用动能定理：WG + WE = ΔE_k = 0

  1. 重力做功：
  • 最下端小球下落 3L
  • 中间小球下落 2L（从初始位置 L 高处到下极板）
  • 最上端小球下落 L（从初始位置 2L 高处到上极板）
  • W_G = mg·3L + mg·2L + mg·L = 6mgL

更正：三球作为一个整体，重心下落距离为 3L

  • W_G = 3mg × 3L = 9mgL
  1. 电场力做功：
  • 电场强度 E = U/d = U/(3L)
  • 最下端小球：全程在电场中，位移 3L，W_E1 = -qE·3L = -qU
  • 中间小球：下落 2L 后进入电场，在电场中位移 2L，W_E2 = -qE·2L = -2qU/3
  • 最上端小球：下落 L 后进入电场，在电场中位移 L，W_E3 = -qE·L = -qU/3
  • W_E = -qU - 2qU/3 - qU/3 = -2qU
  1. 动能定理：
  • 9mgL - 2qU = 0
  • U = 9mgL/(2q)

第 (2) 问：求最大速度

速度最大时，合力为零：

  • 当 2 个小球在电场中时：3mg = 2qE = 2qU/(3L)
  • 代入 U = 9mgL/(2q)：3mg = 2q·9mgL/(2q·3L) = 3mg ✓

最大速度出现在下落 2L 处（第 2 个小球刚进入电场时）。

用动能定理求 v_max：

  • 从初始到下落 2L：
  • W_G = 3mg·2L = 6mgL
  • W_E = -qU·L/(3L) - qU·0 = -qU/3 = -3mgL/2
  • (1/2)·3m·v_max² = 6mgL - 3mgL/2 = 9mgL/2
  • v_max = √(3gL)

总结与课堂讲解建议：

完整解答：

(1) 两极板间的电压：
由动能定理：WG + WE = 0

  • 重力做功：W_G = 3mg × 3L = 9mgL
  • 电场力做功：W_E = -qU(1 + 2/3 + 1/3) = -2qU
  • 9mgL - 2qU = 0
  • U = 9mgL/(2q)

(2) 小球运动的最大速度：
速度最大时合力为零，此时 2 个小球在电场中：

  • 3mg = 2qE = 2qU/(3L)
  • 最大速度出现在 s = 2L 处
  • 由动能定理：(1/2)·3m·v_max² = 6mgL - qU/3
  • v_max = √(3gL)

课堂讲解建议：

  1. 先用 SCENE_1 建立空间模型
  2. 用 SCENE_2 展示下落过程，强调电场力随进入电场的小球数变化
  3. 用 SCENE_3 进行能量分析，推导电压 U
  4. 用 SCENE_4 直观展示速度变化，找到最大速度位置
  5. 最后总结解题方法：复合场问题优先考虑能量守恒

易错点提醒：

  • 电场力做功要分段计算，不是简单的 -qU
  • 最大速度位置不是中点，而是合力为零的位置
  • 三球作为整体分析，但电场力要分别计算
