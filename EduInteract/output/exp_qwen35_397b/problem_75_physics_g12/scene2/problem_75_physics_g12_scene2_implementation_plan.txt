[图示主题与整合说明]
- 本图示主题：三球下落过程与受力分析动态图
- 整合内容：下落过程分阶段展示、各阶段进入电场的小球数量、电场力变化、合力变化、速度变化趋势
- 教学价值：教师可通过分步演示，清晰展示三球系统在电场中下落的动态过程，帮助学生理解：(1)不同阶段进入电场的小球数量不同导致电场力变化；(2)合力如何随电场力变化而改变；(3)速度先增大后减小的变化趋势；(4)能量转化关系。教师可配合讲解每一步的受力情况和运动状态。

[分步序列]
步骤0（初始状态）：
- 显示电容器、电场区域、三球系统（初始位置）
- 球1恰好在上极板小孔处(y=155)
- 所有小球显示重力箭头mg（绿色向下）
- 无电场力箭头（尚未进入电场）
- 合力箭头向下，长度表示3mg
- 速度箭头长度为0（静止）
- 信息面板：阶段1，n=0，F合=3mg，v=0

步骤1（下落L，第一球进入电场）：
- 三球系统整体下移35px：球1(400,190)、球2(400,155)、球3(400,120)
- 球1、球2显示电场力箭头qE（红色向上）
- 球3仍只显示重力箭头
- 合力箭头向下，长度表示3mg-2qE
- 速度箭头有一定长度（速度增大中）
- 信息面板：阶段2，n=2，F合=3mg-2qE，v增大

步骤2（下落2L，第二球进入电场）：
- 三球系统整体下移70px（相对初始）：球1(400,225)、球2(400,190)、球3(400,155)
- 三个小球均显示电场力箭头qE（红色向上）
- 合力箭头向下，长度表示3mg-3qE（较小）
- 速度箭头较长（接近最大速度）
- 信息面板：阶段3，n=3，F合=3mg-3qE，v继续增大

步骤3（下落3L，到达下极板，速度为零）：
- 三球系统整体下移105px（相对初始）：球1(400,260)、球2(400,225)、球3(400,190)
- 球1接触下极板
- 三个小球均显示电场力箭头
- 合力箭头向上（减速阶段），长度表示3qE-3mg
- 速度箭头长度为0
- 信息面板：阶段4，n=3，F合=3qE-3mg（向上），v=0

[标签冲突检查]
- 标签"mg"：各球重力箭头末端右侧(球x+15, 球y+30)，间距>50px → 无冲突
- 标签"qE"：各球电场力箭头末端右侧(球x+15, 球y-30)，间距>50px → 无冲突
- 标签"F合"：合力箭头末端右侧，单独位置 → 无冲突
- 标签"v"：速度箭头末端上方，球1右侧 → 无冲突
- 标签"d=3L"：左侧(210,210) → 无冲突
- 标签"L"（两个）：右侧(435,102)和(435,137)，间距35px → 无冲突
- 阶段标签(650,100)、n标签(650,130)、合力标签(650,160)、速度标签(650,190)：垂直间距30px → 无冲突
- 图例区(620,250)起，与信息面板间距60px → 无冲突
- 所有标签距画布边缘≥20px → 符合要求

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于(320,465)，点击返回上一状态（步骤0时禁用）
  - 「下一步」按钮：位于(420,465)，点击进入下一状态（步骤3时禁用）
  - 步骤指示器：位于(380,465)，显示"步骤 X/3"
- 教师操作流程：
  1. 初始加载显示步骤0，教师讲解初始状态和受力情况
  2. 点击「下一步」到步骤1，讲解第一球进入电场后的受力变化
  3. 点击「下一步」到步骤2，讲解三球全部进入电场但仍在加速
  4. 点击「下一步」到步骤3，讲解减速过程和最终状态
  5. 可随时点击「上一步」回退复习关键概念

[技术实现]
- JS 库选择：原生 SVG（简单几何图形和箭头，无需额外库）
- 画布尺寸：800×500 px
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |   [电容器区域]           [信息面板]              |
  |   上极板 y=140           阶段：1/2/3/4           |
  |   ||||电场||||           n=0/1/2/3               |
  |   ○ 球3                  F合=...                 |
  |   | 杆                   v=...                   |
  |   ○ 球2                                          |
  |   | 杆                   [图例区]                |
  |   ○ 球1                  mg↓ 绿色                |
  |   下极板 y=280           qE↑ 红色                |
  |                          F合 蓝色                |
  |                          v 灰色                  |
  |                                                  |
  |              [◀上一步] 步骤X/3 [下一步▶]         |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep(0-3) 跟踪当前步骤
  2. 坐标计算：每个步骤三球位置 = 初始位置 + (0, step×35)
  3. 电场力显示判断：小球y坐标 > 140（上极板位置）时显示qE箭头
  4. 合力计算：F合 = 3mg - n×qE（n为电场内小球数），方向由正负决定
  5. 速度箭头长度：步骤0和3为0，步骤1和2逐渐增长
  6. 动画过渡：使用 CSS transition 或 requestAnimationFrame 实现平滑移动
  7. 按钮状态：步骤0禁用上一步，步骤3禁用下一步
- ID 命名规范：所有元素 ID 以 scene2- 为前缀
  - scene2-plate-top, scene2-plate-bottom
  - scene2-ball1, scene2-ball2, scene2-ball3
  - scene2-rod1, scene2-rod2
  - scene2-arrow-mg1, scene2-arrow-qe1, scene2-arrow-fnet, scene2-arrow-v
  - scene2-label-stage, scene2-label-n, scene2-label-fnet, scene2-label-v
  - scene2-btn-prev, scene2-btn-next, scene2-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
