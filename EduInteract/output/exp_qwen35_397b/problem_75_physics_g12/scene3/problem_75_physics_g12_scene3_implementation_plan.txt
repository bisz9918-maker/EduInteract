[图示主题与整合说明]
- 本图示主题：能量分析与动能定理图示（平行板电容器中三带电小球下落问题）
- 整合内容：重力做功计算、电场力做功计算、动能定理方程、电压 U 的求解、最大速度位置分析
- 教学价值：教师可逐步展示能量转化过程，帮助学生理解动能定理在多物体系统中的应用，通过分步动画清晰呈现各小球的重力做功和电场力做功，最后汇总得到电压 U 的表达式和最大速度位置

[分步序列]
- 初始状态（步骤0）：显示平行板电容器、三小球初始位置（蓝色）、连接杆、板间距离 d 标注、杆长 L 标注
- 步骤1：点击「下一步」→ 显示三小球最终位置（绿色半透明）、右侧显示三条下落距离标注箭头及 3L/2L/L 标签
- 步骤2：点击「下一步」→ 显示重力做功条形图（绿色，长度100px）及 W_G = 9mgL 标签，公式区显示"重力做功：W_G = mg·3L + mg·2L + mg·L = 9mgL"
- 步骤3：点击「下一步」→ 显示电场力做功条形图（红色，长度80px）及 W_E = -2qU 标签，公式区显示"电场力做功：W_E = -qU - qU = -2qU"（第一球全程在电场，第二、三球部分在电场，等效为两球全程）
- 步骤4：点击「下一步」→ 显示动能定理方程 W_G + W_E = ΔE_k，ΔE_k 标签显示，公式区显示"9mgL - 2qU = 0"，然后高亮显示结果"U = 9mgL/(2q)"（蓝色加粗）
- 步骤5：点击「下一步」→ 显示最大速度分析：高亮第二球刚进入电场时的位置（用黄色圆圈标记），公式区显示"v_max 位置：第二球刚进入电场时"，解释此时重力做功最大而电场力做功尚未完全抵消

[技术实现]
- JS 库选择：原生 SVG（简单几何图形首选，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  [左侧位置对比图]    |  [右侧能量条]  [公式区]   |
  |  极板 + 三球系统     |  W_G 条形      公式推导   |
  |  初始(蓝) 最终(绿)   |  W_E 条形      U = ...    |
  |  距离标注 3L/2L/L    |  ΔE_k 条形     v_max 分析 |
  |                      |                           |
  |                      |                           |
  |  [控件栏 y=440-490]  |                           |
  |  [◀上一步] 步骤X/5 [下一步▶]                     |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-5），每个状态对应一个 render 函数
  2. 坐标计算：所有元素坐标预先定义在配置对象中，避免硬编码
  3. 动画曲线：使用 CSS transition 实现平滑过渡（opacity、transform）
  4. 事件绑定：按钮点击事件绑定到 state 切换函数，更新视图
  5. 元素显示控制：每个状态定义 visibleElements 数组，控制哪些元素 display:block/none
- ID 命名规范：所有交互元素 ID 必须以 scene3- 为前缀
  - scene3-plate-top, scene3-plate-bottom
  - scene3-ball1-initial, scene3-ball2-initial, scene3-ball3-initial
  - scene3-ball1-final, scene3-ball2-final, scene3-ball3-final
  - scene3-rod1, scene3-rod2
  - scene3-dist-3L, scene3-dist-2L, scene3-dist-L
  - scene3-bar-WG, scene3-bar-WE, scene3-bar-DEk
  - scene3-formula1, scene3-formula2, scene3-formula3, scene3-formula4
  - scene3-btn-prev, scene3-btn-next, scene3-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
- 公式渲染：简单公式直接用 SVG text 元素，复杂分数用<tspan>分行或 Unicode 字符
