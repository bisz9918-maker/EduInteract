[图示主题与整合说明]
- 本图示主题：物理过程三阶段运动状态示意图（动量守恒问题）
- 整合内容：初始状态、C 滑离 A 瞬间状态、最终状态三个关键阶段的物块位置和速度标注
- 教学价值：教师可通过分步展示，清晰呈现 C 在 A、B 上滑动的完整物理过程。步骤 0 展示初始条件，步骤 1 展示 C 滑离 A 的临界状态（此时 A 获得速度 vA，C 速度变为 vC），步骤 2 展示最终状态（C 停在 B 上共同运动，A 分离）。学生可直观理解动量守恒在不同阶段的应用，教师可控制讲解节奏，随时回退复习。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 (320,475)，宽 70px，高 25px，点击返回上一状态
  - 「下一步」按钮：位于 (410,475)，宽 70px，高 25px，点击进入下一状态
  - 步骤指示器：位于两按钮之间 (395,480)，显示 "1/3" 格式
- 教师操作流程：
  1. 初始加载显示步骤 0，教师讲解题目初始条件（C 以 v0=25m/s 滑上 A）
  2. 点击「下一步」切换到步骤 1，讲解 C 滑离 A 瞬间的临界状态，引入 vA 和 vC 两个待求速度
  3. 点击「下一步」切换到步骤 2，讲解最终状态（C 停在 B 上，B、C 共同速度 v=2.5m/s，A 分离）
  4. 可随时点击「上一步」回退复习，强化学生对各阶段状态的理解

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（矩形、线段、箭头），无需复杂库；原生实现轻量、加载快、易维护
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌────────────────────────────────────────────────────────────────────┐
  │                                                                    │
  │   [状态 0]          [状态 1]          [状态 2]                     │
  │   C→v0              C→vC              C                            │
  │  ┌───┬───┐         ┌───┬───┐         ┌───┐  ┌───┬───┐            │
  │  │ A │ B │         │ A │ B │         │ A │  │ B │ C │            │
  │  └───┴───┘         └───┴───┘         └───┘  └───────┘            │
  │  ═══════════════════════════════════════════════════════════      │
  │    vA↓               vA↓              v=2.5m/s                    │
  │   初始状态         C 滑离 A 瞬间        最终状态                    │
  │                                                                    │
  │              [◀上一步]  2/3  [下一步▶]                            │
  └────────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0/1/2) 跟踪当前步骤，数组 steps 存储各步骤的显示/隐藏元素 ID 列表
  2. 坐标计算：所有元素坐标硬编码在 SVG 中，确保精确对齐；三状态水平排列，间距 50px
  3. 动画曲线：步骤切换使用 CSS transition，opacity 从 0→1 用时 300ms，ease-out 曲线
  4. 事件绑定：按钮点击事件绑定到 updateStep() 函数，更新 currentStep 并调用 renderStep()
  5. 按钮状态：步骤 0 时禁用「上一步」，步骤 2 时禁用「下一步」，用 opacity:0.5 和 pointer-events:none 实现
- ID 命名规范：
  - 状态 0 元素：scene1-s0-xxx（如 scene1-s0-blockA、scene1-s0-arrow-v0）
  - 状态 1 元素：scene1-s1-xxx（如 scene1-s1-blockA、scene1-s1-arrow-vA）
  - 状态 2 元素：scene1-s2-xxx（如 scene1-s2-blockA、scene1-s2-arrow-v）
  - 控件元素：scene1-btn-prev、scene1-btn-next、scene1-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
- 箭头绘制：使用 SVG <marker> 定义箭头，<line> + marker-end 实现带箭头的线段
- 地面阴影：使用 SVG <pattern> 定义斜线填充，或直接绘制多条 <line>
