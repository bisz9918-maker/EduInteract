[图示主题与整合说明]
- 本图示主题：动量守恒矢量关系图（场景 2）
- 整合的步骤/概念：
  1. 初始总动量：C 以 v0=25m/s 运动，p0=m0·v0=2 kg·m/s
  2. 阶段一末：C 滑离 A 瞬间，动量分解为 C 的动量 (m0·vC') 和 A+B 的动量 ((mA+mB)·vAB)
  3. 阶段二末：C 停在 B 上，动量重新分配为 A 的动量 (mA·vA) 和 B+C 的动量 ((m0+mB)·v)
  4. 完整动量守恒方程展示
- 教学价值：教师可通过分步展示，让学生直观理解动量守恒定律在两阶段过程中的应用。矢量箭头长度与动量大小成正比，帮助学生建立"动量是矢量且守恒"的物理直觉，避免纯代数推导的抽象性。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 上一步按钮：位于 (320,455)，80×30px，灰色背景，点击后退到前一状态

- 教师操作流程：
  1. 初始状态展示系统总动量，强调"守恒"的起点
  2. 点击下一步，展示阶段一末动量分解，讲解 C 与 A+B 的动量分配
  3. 点击下一步，展示阶段二末动量重新分配，讲解 C 滑上 B 后的变化
  4. 点击下一步，完整方程呈现，总结两阶段动量守恒的数学表达

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库）
- 画布尺寸：800×500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +------------------------------------------+
  |  步骤 1/4                      (顶部)    |
  |                                          |
  |  =  ────────────────→  m₀v₀=2   (行 1)   |
  |                                          |
  |  =  ──→───────→  m₀vC'  (mA+mB)vAB (行 2)|
  |                                          |
  |  =  ────────→───→  mAvA  (m₀+mB)v  (行 3)|
  |                                          |
  |         [◀上一步] [下一步▶]   (底部)      |
  +------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用 currentStep 变量（0-3）管理 4 个状态
  2. 所有 SVG 元素预创建，通过 display/opacity 控制显示隐藏
  3. 箭头使用 SVG <marker> 定义箭头样式，复用
  4. 按钮事件绑定：onclick 触发 stepChange 函数
  5. 动画效果：箭头出现时使用 CSS transition 实现长度渐变
- ID 命名规范：所有元素 ID 以 scene2- 为前缀
  - scene2-row1-arrow, scene2-row2-arrow-c, scene2-row2-arrow-ab, ...
  - scene2-btn-prev, scene2-btn-next, scene2-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
