[技术实现]
- JS库选择：原生SVG（几何图形简单，无需复杂库）
- 画布尺寸：800×500px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |   [左侧标注区]    [靶MN放大图]    [公式区]       |
  |   x:100-400      x:420-580      x:620-780       |
  |   y₁,y₂,Δy       靶矩形+填充     公式文本        |
  |                                                  |
  |                                                  |
  |                                                  |
  |  [控件栏 y=440-490]                              |
  |  [◀上一步]  [步骤X/4]  [下一步▶]                |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用currentState变量(0-4)跟踪当前步骤，steps数组存储每步的可见元素ID列表
  2. 坐标计算：所有元素坐标硬编码，确保与布局表一致
  3. 动画曲线：元素出现使用fade-in动画（opacity 0→1，300ms）
  4. 事件绑定：按钮点击事件切换状态，调用updateDisplay()刷新可见性
  5. ID命名规范：所有元素ID以scene3-为前缀（如scene3-target-rect, scene3-point-p1, scene3-label-y1）
  6. IIFE隔离：所有JS代码包裹在(function() { ... })()中，避免全局污染
  7. 元素可见性：用CSS class"visible"控制显示/隐藏，而非display:none（保持布局稳定）
- CDN引入：无需外部库，纯原生SVG+JS实现
