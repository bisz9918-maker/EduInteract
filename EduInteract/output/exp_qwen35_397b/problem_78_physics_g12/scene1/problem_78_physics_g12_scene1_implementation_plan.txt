[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 (280,455)，尺寸 100×35px，点击后返回上一状态（步骤 0 时禁用）
  - 「下一步」按钮：位于 (420,455)，尺寸 100×35px，点击后进入下一状态（步骤 3 时禁用）
  - 步骤指示文本：位于 (390,465)，显示当前步骤"步骤 X/3"
- 教师操作流程：
  1. 初始加载显示步骤 0（基础装置图），教师引导学生观察导轨结构
  2. 点击「下一步」进入步骤 1，磁场区域高亮，教师讲解磁场区域定义和高度 d
  3. 点击「下一步」进入步骤 2，导体棒参数显示，教师讲解两棒的质量和电阻差异
  4. 点击「下一步」进入步骤 3，等效电路出现，教师讲解电磁感应等效电路模型
  5. 可随时点击「上一步」回退复习关键概念

[技术实现]
- JS 库选择：原生 SVG
  - 原因：几何图形简单（线段、矩形、文字），无需复杂动画库；SVG 缩放不失真，适合教学图示；代码简洁易维护
- 画布尺寸：800×500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  [主装置区 500px 宽]      |  [等效电路区 200px]   |
  |                           |                       |
  |    R=3Ω                   |   +---------------+   |
  |   +----+                  |   | 等效电路      |   |
  |   |    |                  |   |               |   |
  |   +----+                  |   |  E=BLv       R  |   |
  |    |  |                   |   |   +---+      +---+|
  |  a |  | M                 |   |   |   |------|   ||
  |  ==|  |                   |   |   +---+      +---+|
  |    |  |                   |   |     |             |
  |  b |  | N                 |   |   R_棒           |
  |  ==|  |                   |   |   +---+          |
  |    |  |                   |   |   |   |          |
  |  L₁|  |----               |   |   +---+          |
  |  ~~~~B~~~~ d=0.5m         |   +---------------+   |
  |  L₂|  |----               |                       |
  |                           |                       |
  +--------------------------------------------------+
  |           [◀上一步]  步骤 X/3  [下一步▶]          |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-3) 跟踪当前步骤，每个步骤对应一组可见元素
  2. 元素分组：将相关元素放入 <g> 组，通过 display 属性控制显示/隐藏
     - scene1-base：基础导轨和电阻（始终显示）
     - scene1-magnetic：磁场区域相关（步骤 1+ 显示）
     - scene1-params：导体棒参数标签（步骤 2+ 显示）
     - scene1-circuit：等效电路（步骤 3 显示）
  3. 按钮状态：步骤 0 时禁用「上一步」，步骤 3 时禁用「下一步」（opacity:0.5, pointer-events:none）
  4. 动画效果：使用 CSS transition 实现淡入效果（opacity 从 0 到 1，duration 0.3s）
  5. 事件绑定：按钮点击事件绑定到 updateStep() 函数，更新 currentStep 并刷新显示
- ID 命名规范：所有元素 ID 以 scene1- 为前缀
  - scene1-rail-left, scene1-rail-right
  - scene1-resistor-top, scene1-rod-a, scene1-rod-b
  - scene1-magnetic-area, scene1-line-l1, scene1-line-l2
  - scene1-label-B, scene1-label-d, scene1-label-M, scene1-label-N
  - scene1-circuit-box, scene1-circuit-source, scene1-circuit-r-internal, scene1-circuit-r-external
  - scene1-btn-prev, scene1-btn-next, scene1-step-indicator
- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染
