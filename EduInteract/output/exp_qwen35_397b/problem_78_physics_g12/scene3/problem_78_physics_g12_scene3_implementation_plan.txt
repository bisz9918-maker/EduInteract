[图示主题与整合说明]
- 本图示主题：两棒运动时序与能量转化
- 整合的步骤/概念：运动时间轴、自由落体与匀速阶段对比、能量守恒关系、焦耳热计算与分配
- 教学价值：教师可逐步展示两棒从同时释放到 b 穿出/a 进入的关键时序关系，帮助学生理解"b 穿出时 a 正好进入"这一条件的物理意义；通过能量转化流程图直观展示重力势能→电能→焦耳热的转化过程；热量分配图帮助学生理解并联电路中焦耳热的分配规律

[分步序列]
- 初始状态（步骤 0）：显示时间轴主线、三个时间点标记(t=0, t₁, t₂)、标题"两棒运动时序与能量转化"。两棒轨迹线淡色显示。能量转化框和热量分配柱隐藏。
- 步骤 1：点击「下一步」→ 显示 a 棒和 b 棒的初始位置标记（M 和 N 处），a 棒在 y=80，b 棒在 y=100（N 低于 M）。显示文字标注"t=0：两棒同时释放"。
- 步骤 2：点击「下一步」→ a 棒位置下移至 y=130，b 棒位置下移至 y=140（L₁ 位置）。显示标注"t₁：b 棒进入磁场"。磁场区域高亮显示。
- 步骤 3：点击「下一步」→ a 棒位置下移至 y=180（L₁ 位置），b 棒位置下移至 y=180（L₂ 位置）。显示标注"t₂：b 穿出磁场，a 正好进入"。这是关键条件的可视化。
- 步骤 4：点击「下一步」→ 显示能量转化流程图（三个框和两个箭头），显示热量分配柱状图（三根柱子高度不同），显示公式框"Q_b = m_b·g·d = 0.1×10×0.5 = 0.5J"和"Q_R = Q_b × (R_并/R_总)"。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 (280,455)，100×35px，蓝色背景，白色文字。点击后返回上一状态，步骤 0 时禁用。
  - 「下一步」按钮：位于 (420,455)，100×35px，蓝色背景，白色文字。点击后进入下一状态，步骤 4 时禁用。
  - 步骤指示器：显示"步骤 X/4"，位于两按钮之间 (400,470)
- 教师操作流程：
  1. 初始展示时间轴，讲解两棒同时释放的初始条件
  2. 点击「下一步」展示两棒初始位置，强调 M、N 高度不同
  3. 点击「下一步」展示 b 棒进入磁场时刻，讲解此时 a 棒仍在自由落体
  4. 点击「下一步」展示关键条件"b 穿出时 a 正好进入"，这是解题突破口
  5. 点击「下一步」展示能量转化和热量分配，讲解 Q=mgh 和并联电路热量分配

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript。理由：本场景以静态图示和简单位移动画为主，无需复杂图表库；SVG 适合精确坐标控制，便于多场景合并时避免冲突。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌────────────────────────────────────────────────────┐
  │  时间轴：t=0 ────── t₁ ────── t₂                  │ y=20-80
  │  棒位置示意：[a 轨迹][b 轨迹][磁场区]              │ y=80-200
  │                                                    │
  │  能量转化：[重力势能]→[电能]→[焦耳热]             │ y=220-300
  │                                                    │
  │  热量分配：[R柱][Ra柱][Rb柱]    [公式框]          │ y=340-420
  │                                                    │
  │  [        ◀上一步    步骤 X/4    下一步▶        ]  │ y=440-490
  └────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-4) 跟踪当前步骤，每个步骤对应一组元素的显示/隐藏状态
  2. 坐标计算：所有元素坐标硬编码，确保与布局表一致
  3. 动画曲线：棒位置移动使用 CSS transition，duration 300ms，ease-out
  4. 事件绑定：按钮点击事件绑定到 stepChange 函数，更新 currentStep 并调用 render()
  5. 按钮状态：步骤 0 时禁用「上一步」，步骤 4 时禁用「下一步」
- ID 命名规范：所有交互元素 ID 必须以 scene3- 为前缀
  - scene3-timeline, scene3-time-label-0, scene3-time-label-1, scene3-time-label-2
  - scene3-rod-a-track, scene3-rod-b-track
  - scene3-rod-a-pos, scene3-rod-b-pos
  - scene3-magnetic-zone
  - scene3-energy-box-1, scene3-energy-box-2, scene3-energy-box-3
  - scene3-energy-arrow-1, scene3-energy-arrow-2
  - scene3-heat-bar-r, scene3-heat-bar-ra, scene3-heat-bar-rb
  - scene3-formula-box
  - scene3-btn-prev, scene3-btn-next, scene3-step-indicator
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
