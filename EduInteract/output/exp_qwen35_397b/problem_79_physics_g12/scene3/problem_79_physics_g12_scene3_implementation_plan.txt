[技术实现]
- JS 库选择：原生 SVG（几何图形简单，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  | F 作用阶段          |        v-t 图像            |
  | [M 受力图]          |     v ↑                    |
  | [M 撤去后图]        |       |                    |
  |                     |       |                    |
  | a_M1, a_m 标注      |       |____ M 图线        |
  |                     |      /    \                |
  |                     |     /      \___           |
  |                     |    /___________\__ m 图线 |
  |                     |   0   t₀      t₁  → t     |
  |                     |   [阴影面积=L]            |
  +--------------------------------------------------+
  |              [◀上一步]  步骤 X/3  [下一步▶]       |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用 currentState 变量（0-3）管理步骤状态
  2. 坐标计算：v-t 图线坐标根据物理公式计算
     - a_m = μg = 1 m/s²
     - a_M1 = (F-μmg)/M = 3 m/s²
     - a_M2 = -μmg/M = -1/3 m/s²
     - 临界条件：v_M(t₁) = v_m(t₁)，且位移差 = L
  3. 动画曲线：元素淡入用 CSS transition opacity 0.3s ease
  4. 事件绑定：按钮点击事件切换状态，更新显示元素
  5. ID 命名规范：所有元素 ID 以 scene3- 为前缀（如 scene3-M-phase1, scene3-vt-M-line）
  6. IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局污染

- 物理数值计算（用于 v-t 图坐标映射）：
  - 设 t₀ 为 F 作用时间，t₁ 为临界时刻
  - v_m(t) = a_m × t = t（因 a_m=1）
  - v_M(t) = a_M1 × t₀ + a_M2 × (t-t₀) = 3t₀ - (1/3)(t-t₀)
  - 临界条件 v_M(t₁) = v_m(t₁)：3t₀ - (1/3)(t₁-t₀) = t₁
  - 位移差 = L：∫(v_M - v_m)dt = 1.6
  - 解得：t₀ = 0.8s（最小作用时间）

  - M 的 v-t 图线：#1565c0 实线
  - m 的 v-t 图线：#2e7d32 实线
  - F 作用阶段背景：#e3f2fd（透明度 10%）
  - F 撤去后阶段背景：#ffebee（透明度 10%）
  - 临界点标记：#c62828 实心圆
  - 位移面积填充：#888888（透明度 15%）
