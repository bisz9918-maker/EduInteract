[图示主题与整合说明]
- 本图示主题：两种浮力情景对比——展示甲物块在乙悬挂和丙放置两种情况下的位置关系
- 整合的步骤/概念：整合了题目原图的左右两种情景、水面位置标注、甲浸没深度对比、排开水体积对比
- 教学价值：教师可使用此图示进行课堂讲解，通过分步展示帮助学生理解：(1)两种情景下甲物块上表面均与水面相平；(2)甲排开水的体积相同，故浮力相等；(3)乙悬挂时受浮力，丙放置时不受浮力，导致系统受力不同

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于(320,455)，点击后返回上一状态（步骤0时禁用）
  - 「下一步」按钮：位于(400,455)，点击后进入下一状态（步骤3时变为「重新开始」）
  - 步骤指示文本：位于(400,440)，显示当前步骤名称
- 教师操作流程：
  1. 加载图示后，教师先展示步骤0的基础框架，让学生观察左右两图的整体结构
  2. 点击「下一步」进入步骤1，讲解甲、乙、丙三个物块的位置关系
  3. 点击「下一步」进入步骤2，强调两种情况下甲的上表面都与水面相平
  4. 点击「下一步」进入步骤3，用绿色虚线框标出甲排开水的体积，说明两者V排相同，故浮力相等
  5. 教师可随时点击「上一步」回退复习，或在步骤3点击「重新开始」循环讲解

[技术实现]
- JS库选择及原因：原生SVG + 原生JavaScript
  - 原因：本图示为简单几何图形（矩形、线段），无需复杂库；SVG便于精确控制坐标和样式；原生JS足够实现分步状态切换
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +----------------------------------------------------------+
  |  [左图：乙悬挂]              [右图：丙放置]               |
  |     甲                           丙                       |
  |   ~~~~~水面~~~~~              ~~~~~水面~~~~~              |
  |     甲                           甲                       |
  |     |                            |                        |
  |     乙                           |                        |
  |   ~~~~~~水下虚线~~~~~~        ~~~~~~水下虚线~~~~~~        |
  |                                                          |
  |              [步骤指示] [◀上一步] [下一步▶]               |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-3) 跟踪当前步骤，数组 stepStates 存储每步的显示/隐藏配置
  2. 坐标计算：所有元素使用绝对坐标（SVG viewBox="0 0 800 500"），确保跨浏览器一致
  3. 动画曲线：标签淡入使用 CSS transition opacity 0.3s ease-in-out
  4. 事件绑定：按钮点击事件绑定到 scene1-btn-prev 和 scene1-btn-next，使用 addEventListener
  5. 状态切换逻辑：每步切换时，根据 stepStates[currentStep] 设置各元素的 display 属性
- ID命名规范：
  - 左图甲物块：scene1-left-jia
  - 左图乙物块：scene1-left-yi
  - 左图绳子：scene1-left-rope
  - 左图水面线：scene1-left-water
  - 左图V排框：scene1-left-vdisp
  - 右图甲物块：scene1-right-jia
  - 右图丙物块：scene1-right-bing
  - 右图水面线：scene1-right-water
  - 右图V排框：scene1-right-vdisp
  - 标签：scene1-label-jia-left, scene1-label-yi, scene1-label-jia-right, scene1-label-bing, scene1-label-water-left, scene1-label-water-right, scene1-label-vdisp-left, scene1-label-vdisp-right
  - 按钮：scene1-btn-prev, scene1-btn-next
  - 步骤指示：scene1-step-indicator
- IIFE隔离：所有JS代码包在 (function() { ... })() 中，避免全局变量污染
