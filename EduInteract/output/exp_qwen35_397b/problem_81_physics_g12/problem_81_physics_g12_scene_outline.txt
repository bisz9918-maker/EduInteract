    **题目原文：**

    如图所示，A、B 两物体的质量都为 m，拉 A 物体的细线与水平方向的夹角为 30°时处于静止状态，不考虑摩擦力，设弹簧的劲度系数为 k．若悬线突然断开后，A 在水平面上做周期为 T 的简谐运动，当 B 落地时，A 恰好将弹簧压缩到最短，求：
    （1）A 振动时的振幅；
    （2）B 落地时的速度．

    **题目分析：**

    本题是简谐运动与自由落体运动的综合问题。关键物理过程：
    1. 初始静止状态：系统平衡，通过受力分析可求弹簧初始伸长量
    2. 悬线断开后：A 在弹簧作用下做简谐运动，B 做自由落体运动
    3. 时间关联：B 落地时刻 = A 第一次压缩到最短的时刻

    **整体讲解思路：**

    第一步：分析初始平衡状态，求出弹簧初始伸长量 x₀，这是确定振幅的关键
    第二步：确定 A 的简谐运动特征（平衡位置、振幅、周期）
    第三步：分析时间关系，B 下落时间对应 A 振动的哪个阶段
    第四步：联立求解振幅和 B 的落地速度

    **图示规划说明：**

    共设计 3 个图示：
    - SCENE_1：初始状态受力分析图，展示 A、B 的受力及弹簧初始伸长
    - SCENE_2：A 的简谐运动过程，展示平衡位置、振幅、振动轨迹
    - SCENE_3：时间关系对比图，展示 B 下落时间与 A 振动相位的对应关系
    </TEXT_1>

    <TEXT_2>
    **教学说明：**

    本图示用于讲解初始平衡状态的受力分析，教师应引导学生：

    1. 观察系统静止时的受力特点：A、B 都处于平衡状态

    2. 对 B 分析：T = mg（竖直方向平衡）

    3. 对 A 分析：水平方向弹簧弹力与绳张力的水平分量平衡
       - F_弹 = T·cos30°
       - kx₀ = mg·cos30° = mg·(√3/2)

    4. 得出弹簧初始伸长量：x₀ = (mg·√3)/(2k)

    **关键公式：**
    - 对 B：T = mg
    - 对 A 水平方向：kx₀ = T·cos30°
    - 解得：x₀ = (mg·√3)/(2k)

    此伸长量 x₀ 是后续确定振幅的基础。
    </TEXT_2>

    **教学说明：**

    本图示用于讲解简谐运动的振幅确定，教师应引导学生理解：

    1. **平衡位置的确定**：弹簧原长处为平衡位置（无外力时）

    2. **初始位置的特点**：悬线断开瞬间，A 在弹簧伸长 x₀ 处，速度为 0

    3. **振幅的定义**：从平衡位置到最大位移的距离

    4. **关键结论**：由于 A 从最大伸长处（速度为 0）开始运动，该位置即为振动的一个端点，因此：
       - 振幅 A = x₀ = (mg·√3)/(2k)

    5. **运动过程**：初始位置（最大伸长）→ 平衡位置 → 最大压缩位置

    **重要提示：**

    简谐运动中，从一端点运动到另一端点的时间为 T/2，但从端点到平衡位置的时间为 T/4。

    <TEXT_4>
    **教学说明：**

    本图示用于建立两个运动的时间关联，教师应引导学生：

    1. **分析 A 的运动时间**：
       - A 从最大伸长位置运动到最大压缩位置
       - 这是简谐运动的半个周期
       - 时间 t = T/2

    2. **分析 B 的运动**：
       - B 做自由落体运动
       - 下落时间 t = T/2
       - 落地速度 v = gt = g·(T/2) = gT/2

    3. **联立求解**：

    **问题（1）振幅：**
    - A = x₀ = (mg·√3)/(2k)

    **问题（2）B 落地速度：**
    - v = g·t = g·(T/2) = gT/2

    **完整解答：**

    （1）A 振动时的振幅 A = (√3·mg)/(2k)

    （2）B 落地时的速度 v = gT/2

    **课堂讲解建议：**

    强调本题的关键是抓住"时间关联"——B 落地时刻恰好对应 A 运动到最大压缩位置，这是联立两个运动的桥梁。
    </TEXT_4>
