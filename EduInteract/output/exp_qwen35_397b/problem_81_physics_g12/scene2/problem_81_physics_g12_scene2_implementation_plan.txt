[分步序列]
- 步骤0（初始状态）：显示墙面、弹簧（伸长至x=200，红色#c62828）、物体A在初始位置(200,170)、初始位置虚线及标签"x₀"标注。等待教师触发。
- 步骤1（点击下一步）：显示平衡位置虚线(320,150)-(320,250)及标签"平衡位置"（蓝色#1565c0）。弹簧变为原长状态（蓝色），物体A移至平衡位置(320,170)。
- 步骤2（点击下一步）：显示振动轨迹双向箭头(200,330)-(440,330)，表示A将做往复运动。物体A从平衡位置动画移回初始位置。
- 步骤3（点击下一步）：显示最大压缩位置虚线(440,150)-(440,250)及标签"最大压缩"（绿色#2e7d32）。物体A移至最大压缩位置(440,170)，弹簧压缩状态（绿色）。
- 步骤4（点击下一步）：显示振幅双箭头(320,270)-(200,270)及标签"A"和"A = x₀"。显示周期T标签(320,355)。显示数轴及三个刻度。总结振幅等于初始伸长量。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "上一步"按钮：位于(250,450)，90×30px，步骤0时禁用，步骤1-4可点击回退
  - "下一步"按钮：位于(360,450)，90×30px，步骤4时禁用，步骤0-3可点击前进
- 教师操作流程：
  1. 步骤0：讲解初始状态，弹簧被拉伸x₀，系统静止
  2. 步骤1：点击"下一步"，展示平衡位置（弹簧原长），说明这是振动的中心
  3. 步骤2：点击"下一步"，展示振动轨迹，说明A将做往复运动
  4. 步骤3：点击"下一步"，展示最大压缩位置，说明运动对称性
  5. 步骤4：点击"下一步"，展示振幅定义和结论A=x₀，配合数轴总结

[技术实现]
- JS 库选择及原因：原生 SVG。理由：几何元素简单（矩形、线段、折线），无需复杂库，轻量且易于精确控制坐标。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |   墙面  弹簧~~~[A]                               |
  |    |      |    |                                 |
  |   初始  平衡  最大                                |
  |   位置  位置  压缩                                |
  |                                                  |
  |         <--------振动轨迹------->                |
  |              周期 T                              |
  |                                                  |
  |   |----|----|----|----|----|  数轴               |
  |   初始     平衡     压缩                          |
  |                                                  |
  |          [◀上一步] [下一步▶]                     |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-4) 跟踪当前步骤，每个步骤对应一组元素显示/隐藏状态
  2. 坐标计算：弹簧折线路径根据物体A位置动态生成，使用 polyline 的 points 属性
  3. 动画曲线：物体A移动使用 CSS transition 或 requestAnimationFrame 实现平滑移动（duration 500ms，ease-in-out）
  4. 事件绑定：按钮点击事件绑定到 stepForward() 和 stepBackward() 函数
  5. 元素显隐：通过 display 属性或 opacity 控制各步骤元素的显示/隐藏
- ID 命名规范：所有交互元素 ID 必须以 scene2- 为前缀
  - scene2-wall, scene2-spring, scene2-blockA
  - scene2-dash-initial, scene2-dash-equilibrium, scene2-dash-compressed
  - scene2-label-initial, scene2-label-equilibrium, scene2-label-compressed
  - scene2-arrow-vibration, scene2-arrow-amplitude
  - scene2-axis, scene2-axis-tick-initial, scene2-axis-tick-equilibrium, scene2-axis-tick-compressed
  - scene2-btn-prev, scene2-btn-next
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
