[图示主题与整合说明]
- 本图示主题：B 自由落体与 A 简谐运动的时间关联
- 整合的步骤/概念：B 下落时间计算、A 振动相位分析、两者时间等量关系
- 教学价值：教师可逐步展示两个独立运动的时间关联，帮助学生理解"当 B 落地时，A 恰好将弹簧压缩到最短"这一关键条件的物理含义。通过分步动画，学生能直观看到 B 的自由落体过程与 A 的简谐运动相位变化，建立 t = T/2 的等量关系，进而求解振幅和速度。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位置 (250, 455)，尺寸 100×35，点击后回退到前一状态
  - 「下一步」按钮：位置 (450, 455)，尺寸 100×35，点击后进入下一状态
  - 步骤指示器：显示当前步骤（如"步骤 2/5"）
- 教师操作流程：
  1. 初始状态展示 B 自由落体的基本条件（高度 h）
  2. 点击「下一步」，B 下落动画演示，引出时间 t 和末速度 v
  3. 点击「下一步」，展示 A 的简谐运动，说明从最大伸长到最大压缩需时 T/2
  4. 点击「下一步」，建立时间等量关系 t = T/2，显示相关公式
  5. 点击「下一步」，代入求解得到最终答案 v = gT/2

[技术实现]
- JS 库选择及原因：
  - 原生 SVG：用于绘制几何图形、正弦曲线、箭头等，轻量且易于动画
  - 原生 JavaScript：状态管理和事件处理，无需额外库
  - 无需 D3.js 或 Three.js，本场景为 2D 静态图 + 简单动画

- 画布尺寸：800 × 500 px（固定）

- 布局草图：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │  [B 自由落体]                    [A 简谐运动]               │
  │     B□                              ~~~正弦曲线~~~          │
  │     │ h                             ·起点 A                 │
  │     │                               --------平衡位置        │
  │     │ t                             ·终点 A                 │
  │     ↓ v                               T/2                   │
  │     B□                                                      │
  │                                                             │
  │  ─────────────────────────────────────────────────────────  │
  │  t=0              t=T/2                  t=T                │
  │                     (时间轴)                                │
  │                                                             │
  │  [h = ½gt²]  [v = gt]  [t = T/2]  [v = gT/2]               │
  │                                                             │
  │              [◀ 上一步]          [下一步 ▶]                 │
  └─────────────────────────────────────────────────────────────┘
  ```

- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-4），steps 数组存储每步的可见元素 ID 列表
  2. 坐标计算：所有元素使用绝对坐标（SVG viewBox="0 0 800 500"）
  3. 动画曲线：B 下落使用 ease-in 缓动（模拟重力加速），SVG animateMotion 或 JS requestAnimationFrame
  4. 事件绑定：按钮点击事件切换状态，更新各元素 display/opacity 属性
  5. 公式渲染：使用 SVG text 元素，数学符号用 Unicode 字符（½、²等）

- ID 命名规范：
  - 所有交互元素 ID 必须以 scene3- 为前缀
  - 示例：scene3-b-initial, scene3-b-final, scene3-h-label, scene3-v-arrow, scene3-a-curve, scene3-timeline, scene3-formula1, scene3-btn-prev, scene3-btn-next

- IIFE 隔离：
