[图示主题与整合说明]
- 本图示主题：各阶段能量变化对比分析
- 整合内容：三个阶段的势能变化量、动能变化量的可视化对比
  - 阶段 1：A 球下落 L 高度，A 势能减少，B/C 势能增加，系统获得动能
  - 阶段 2：B 球下落 L 高度，B 势能减少，C 势能增加，系统动能变化
  - 阶段 3：C 球下落 L 高度，C 势能减少，全部转化为动能
- 教学价值：教师可逐阶段展示能量转化过程，通过条形图直观对比各阶段能量变化量，帮助学生理解机械能守恒定律在多体系统中的应用

[分步序列]
- 初始状态（步骤 0）：显示阶段 1 能量分析
  - 显示：阶段 1 标题、基线、ΔEp 减条形（3mgL）、ΔEp 增条形（1.5mgL）、ΔEk 条形（1.5mgL）
  - 显示：阶段 1 方程框 "3mgL = 1.5mgL + ½(6m)v₁²"
  - 隐藏：阶段 2、3 的所有元素
  - 按钮状态："上一步"禁用，"下一步"启用

- 步骤 1：点击「下一步」→ 显示阶段 2 能量分析
  - 隐藏：阶段 1 的所有元素
  - 显示：阶段 2 标题、基线、ΔEp 减条形（2mgL）、ΔEp 增条形（0.5mgL）、ΔEk 条形（1.5mgL）
  - 显示：阶段 2 方程框 "2mgL = 0.5mgL + ½(3m)(v₂²-v₁²)"
  - 按钮状态："上一步"启用，"下一步"启用

- 步骤 2：点击「下一步」→ 显示阶段 3 能量分析
  - 隐藏：阶段 2 的所有元素
  - 显示：阶段 3 标题、基线、ΔEp 减条形（mgL）、ΔEk 条形（mgL）
  - 显示：阶段 3 方程框 "mgL = ½m(v₃²-v₂²)"
  - 按钮状态："上一步"启用，"下一步"启用

- 步骤 3：点击「下一步」→ 三阶段对比汇总
  - 显示：所有三个阶段标题、基线、条形图
  - 显示：所有三个方程框
  - 添加：汇总标题 "三阶段能量对比"（y=30）
  - 按钮状态："上一步"启用，"下一步"禁用（或循环回步骤 0）

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀上一步」按钮：位于 (280,450)，80×30px，点击返回上一状态
  - 「下一步▶」按钮：位于 (440,450)，80×30px，点击进入下一状态
  - 步骤指示器：位于 (400,465)，显示当前步骤 "1/4"、"2/4" 等
- 教师操作流程：
  1. 初始加载显示阶段 1，教师讲解 A 球下落过程的能量转化
  2. 点击「下一步」切换到阶段 2，讲解 B 球下落过程
  3. 点击「下一步」切换到阶段 3，讲解 C 球下落过程
  4. 点击「下一步」查看三阶段对比，总结能量守恒规律
  5. 可随时点击「上一步」回退复习

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript
  - 原因：条形图为简单几何图形，SVG 矢量渲染清晰；无需复杂动画库
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |              三阶段能量对比分析                   | y=30~50
  |                                                  |
  |   阶段 1        阶段 2        阶段 3              | y=60
  |    |             |             |                 |
  |   [██]          [██]          [██]               | y=70~250
  |   [██] ΔEp      [██] ΔEp      [██] ΔEp           | 条形图区
  |   [██]          [██]          [██]               |
  |----|------------|------------|---- 基线 y=150     |
  |   [██]          [██]          [██]               |
  |   [██] ΔEk      [██] ΔEk      [██] ΔEk           |
  |                                                  |
  |  ┌──────────┐  ┌──────────┐  ┌──────────┐        | y=320~390
  |  │ 方程 1   │  │ 方程 2   │  │ 方程 3   │        | 方程框区
  |  └──────────┘  └──────────┘  └──────────┘        |
  |                                                  |
  |         [◀上一步]  2/4  [下一步▶]                | y=450~480 控件栏
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0~3) 跟踪当前步骤
  2. 所有元素按步骤分组，用 display:none/block 控制显示
  3. 条形图高度按比例计算：1mgL = 60px（势能减少向下，增加向上）
  4. 按钮点击事件绑定，更新 currentStep 并刷新显示
  5. 步骤 0 和步骤 3 时禁用相应按钮（添加 disabled 样式）
- ID 命名规范：所有交互元素 ID 必须以 scene2- 为前缀
  - scene2-stage1-group, scene2-stage2-group, scene2-stage3-group
  - scene2-bar-p1-dec, scene2-bar-p1-inc, scene2-bar-p1-kek
  - scene2-eq1, scene2-eq2, scene2-eq3
  - scene2-btn-prev, scene2-btn-next, scene2-step-indicator
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中
