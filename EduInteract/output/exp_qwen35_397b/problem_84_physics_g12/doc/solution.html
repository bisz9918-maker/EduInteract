场景导航：Scene 1 | Scene 2 | Scene 3

题目原文：

如图所示，宽度$L=1m$的足够长的$U$形金属框架水平放置，右端接有$R=0.8Ω$的电阻$R$，框架处在竖直向上的匀强磁场中，磁感应强度$B=1T$，框架导轨上放置一根质量$m=0.2Kg$、电阻$r=0.2Ω$的金属金属棒$ab$，棒$ab$与导轨间的动摩擦因数为$μ=0.5$，现用一恒力$F=3N$的力使棒从静止开始沿导轨运动(棒始终与导轨接触良好且垂直)，经过一段时间棒获得稳定速度，此过程中，通过棒的电量$q=2.8C$(框架电阻不计，$g=10m⋅s^{−2}$)问：

$(1)$棒$ab$达到的稳定速度是多大？

$(2)$从开始到速度稳定时，电阻$R$产生的热量是多少？

题目分析：

本题是电磁感应中的动力学与能量综合问题。核心物理过程：金属棒在恒力作用下加速运动，切割磁感线产生感应电动势，形成感应电流，进而产生安培力阻碍运动。当安培力与摩擦力之和等于外力时，棒达到稳定速度（匀速运动）。

整体讲解思路：

  1. 首先分析物理情景：装置结构、受力情况、运动过程
  2. 推导稳定速度的条件：合力为零时速度稳定
  3. 利用能量守恒求解热量：外力做功 = 动能增量 + 摩擦生热 + 焦耳热
  4. 根据电量与位移关系求位移

图示规划说明：

  • SCENE_1：物理情景与受力分析图（整合装置结构、磁场方向、受力标注）
  • SCENE_2：运动过程动态图（展示速度从 0 增加到稳定值的过程，安培力随速度变化）
  • SCENE_3：能量转化关系图（展示能量守恒关系）

教学说明：

本图示帮助学生建立物理情景的直观认识。教师应引导学生：

  1. 观察装置结构：U 形框架、金属棒、电阻构成闭合回路
  2. 理解磁场方向：竖直向上，与框架平面垂直
  3. 分析受力：金属棒受三个水平力
  • 向左的恒力 F（动力）
  • 向右的安培力 F_A（阻力，由电磁感应产生）
  • 向右的摩擦力 f（阻力）

关键公式：

感应电动势：$E = BLv$

感应电流：$I = \frac{E}{R+r} = \frac{BLv}{R+r}$

安培力：$F_A = BIL = \frac{B^2L^2v}{R+r}$

摩擦力：$f = μmg = 0.5 × 0.2 × 10 = 1N$

稳定条件：

当 $F = F_A + f$ 时，加速度为零，速度达到稳定值

教学说明：

本图示展示从静止到稳定速度的动态过程，帮助学生理解"稳定速度"的物理含义。

引导学生观察：

  1. 初始状态（v=0）：安培力为零，合力最大，加速度最大
  2. 加速过程：速度增加 → 安培力增加 → 合力减小 → 加速度减小
  3. 稳定状态：安培力增大到使合力为零，加速度为零，速度不再变化

稳定速度求解：

稳定时 $F = F_A + f$

$F_A = F - f = 3 - 1 = 2N$

由 $F_A = \frac{B^2L^2v}{R+r}$ 得：

$v = \frac{F_A(R+r)}{B^2L^2} = \frac{2 × (0.8+0.2)}{1^2 × 1^2} = 2m/s$

答案 (1)：稳定速度为 2 m/s

能量输入：外力做功
步骤 1/4

教学说明：

本图示展示能量守恒关系，帮助学生理解电磁感应过程中的能量转化。

能量守恒方程：

$W_F = ΔE_k + Q_f + Q_总$

其中：

  • $W_F = F·x$（外力做功）
  • $ΔE_k = \frac{1}{2}mv^2$（动能增量）
  • $Q_f = f·x = μmgx$（摩擦生热）
  • $Q_总 = Q_R + Q_r$（总焦耳热）

求位移 x：

由电量公式 $q = \bar{I}·t = \frac{ΔΦ}{R+r} = \frac{BLx}{R+r}$

得 $x = \frac{q(R+r)}{BL} = \frac{2.8 × 1}{1 × 1} = 2.8m$

计算各能量：

$W_F = Fx = 3 × 2.8 = 8.4J$

$ΔE_k = \frac{1}{2}mv^2 = \frac{1}{2} × 0.2 × 2^2 = 0.4J$

$Q_f = μmgx = 0.5 × 0.2 × 10 × 2.8 = 2.8J$

$Q_总 = W_F - ΔE_k - Q_f = 8.4 - 0.4 - 2.8 = 5.2J$

电阻 R 产生的热量：

$Q_R = Q_总 × \frac{R}{R+r} = 5.2 × \frac{0.8}{1} = 4.16J$

答案 (2)：电阻 R 产生的热量为 4.16 J

总结与课堂讲解建议：

完整解答：

(1) 稳定速度 v = 2 m/s

(2) 电阻 R 产生的热量 Q_R = 4.16 J

讲解建议：

  1. 先用 SCENE_1 建立物理情景，明确受力分析
  2. 用 SCENE_2 动态演示加速过程，理解"稳定速度"的含义
  3. 用 SCENE_3 展示能量转化，强调能量守恒是求解热量的关键
  4. 强调两个核心关系：
  • 力的平衡：F = F_A + f（稳定条件）
  • 能量守恒：WF = ΔEk + Qf + Q总
  1. 提醒学生注意：焦耳热按电阻比例分配，QR : Qr = R : r

易错点提示：

  • 安培力方向判断（用左手定则，阻碍相对运动）
  • 电量与位移的关系：$q = \frac{BLx}{R+r}$
  • 焦耳热分配：串联电路中 Q ∝ R
