- 步骤 1：点击「下一步」→ 显示三个一级分支路径和三个一级输出矩形（动能ΔE_k 绿色、摩擦热 Q_f 橙色、焦耳热 Q_总 红色），显示标题"能量去向：三分支"
- 步骤 2：点击「下一步」→ 从 Q_总 矩形延伸出两个二级分支路径，显示 Q_R（深红）和 Q_r（紫色）矩形，显示标题"焦耳热按电阻比例分配"
- 步骤 3：点击「下一步」→ 底部显示完整能量守恒方程"W_F = ΔE_k + Q_f + Q_R + Q_r"及数值"8.4J = 0.4J + 2.8J + 4.16J + 1.04J"，显示标题"能量守恒验证"
- 教师可随时点击「上一步」回退复习

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 内底部左侧 (530,460)，点击后回退到前一状态
  - 「下一步」按钮：位于 SVG 内底部右侧 (650,460)，点击后进入下一状态
  - 步骤指示器：显示当前步骤序号（如"步骤 1/4"）
- 教师操作流程：
  1. 初始状态展示外力做功，讲解能量来源
  2. 点击「下一步」展示能量三分支，讲解能量分配
  3. 点击「下一步」展示焦耳热细分，讲解电阻比例分配
  4. 点击「下一步」展示完整方程，验证能量守恒
  5. 可随时点击「上一步」回退复习关键概念

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript
  - 桑基图分支路径用 SVG path 绘制贝塞尔曲线
  - 矩形用 SVG rect 元素
  - 状态切换用 display 属性控制元素可见性
  - 无需外部库，轻量且易于控制
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────────┐
  │                                                             │
  │    ┌─────┐                                                  │
  │    │ W_F │──→┌─────┐ (ΔE_k)                                │
  │    │8.4J │   │0.4J │                                       │
  │    └─────┘──→┌─────┐ (Q_f)                                 │
  │              │2.8J │                                       │
  │              └─────┘──→┌─────┐ (Q_总)                      │
  │                        │5.2J │──→┌────┐ (Q_R)              │
  │                        └─────┘   │4.16│                    │
  │                                  └────┘                    │
  │                                  ┌────┐ (Q_r)              │
  │                                  │1.04│                    │
  │                                  └────┘                    │
  │                                                             │
  │         W_F = ΔE_k + Q_f + Q_R + Q_r                       │
  │         8.4J = 0.4J + 2.8J + 4.16J + 1.04J                 │
  │                                                             │
  │         [◀上一步]                    [下一步▶]              │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  - 状态机设计：用 currentState 变量跟踪当前步骤（0-3）
  - 元素分组：将各步骤元素放入不同<g>组，用 display 控制显示/隐藏
  - 分支路径：用 SVG path 绘制三次贝塞尔曲线，起点和终点矩形边缘，控制点使曲线平滑
  - 线宽比例：分支路径 stroke-width 与能量值成正比（W_F=8.4J 对应最宽，ΔE_k=0.4J 对应最窄）
  - 动画效果：元素出现时用 opacity 过渡（0→1，300ms）
  - 按钮状态：第一步禁用「上一步」，最后一步禁用「下一步」
- ID 命名规范：所有交互元素 ID 必须以 scene3- 为前缀
  - scene3-wf-rect, scene3-wf-label, scene3-wf-value
  - scene3-ek-rect, scene3-ek-label, scene3-ek-value
  - scene3-qf-rect, scene3-qf-label, scene3-qf-value
  - scene3-qt-rect, scene3-qt-label, scene3-qt-value
  - scene3-qr-rect, scene3-qr-label, scene3-qr-value
  - scene3-qr2-rect, scene3-qr2-label, scene3-qr2-value
  - scene3-path-ek, scene3-path-qf, scene3-path-qt, scene3-path-qr, scene3-path-qr2
  - scene3-equation, scene3-btn-prev, scene3-btn-next, scene3-step-indicator
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中
