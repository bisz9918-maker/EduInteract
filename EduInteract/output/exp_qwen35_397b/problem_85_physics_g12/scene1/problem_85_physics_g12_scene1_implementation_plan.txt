冲突检查：
- "氧气"(210,110) 与 "T₁=280K"(50,100)：水平距离 160px → 无冲突
- "氧气"(210,110) 与 "a"(210,145)：垂直距离 35px → 无冲突（≥20px）
- "a"(210,145) 与 "H/4"(90,155)：水平距离 120px → 无冲突
- "b"(565,220) 与 "H"(630,230)：水平距离 65px → 无冲突
- "b"(565,220) 与 "H/2"(650,230)：水平距离 85px → 无冲突
- "H"(630,230) 与 "H/2"(650,230)：水平距离 20px → 边界情况，H/2 调整至 (655,230)
- "H"(630,230) 与 "P₀"(680,100)：垂直距离 130px → 无冲突
- "A"(210,250) 与 "氮气"(380,350)：距离 √(170²+100²)≈197px → 无冲突
- "S_A=4S_B"(400,420) 与 控件区 y=440：垂直距离 20px → 无冲突
- "T₁=280K"(50,100) 与 左边缘 x=0：距离 50px → 无冲突
- "P₀"(680,100) 与 右边缘 x=800：距离 120px → 无冲突

结论：所有标签间距 ≥ 20px，无重叠冲突。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - "上一步"按钮：位于 (280,455)，80×30px，灰色背景，步骤 0 时禁用，步骤 1-4 启用
  - "下一步"按钮：位于 (440,455)，80×30px，蓝色背景 (#1976d2)，步骤 0-3 显示"下一步"，步骤 4 变为"重新开始"
- 教师操作流程：
  1. 初始加载显示步骤 0（基础气缸结构），教师介绍装置整体
  2. 点击"下一步"→步骤 1，展示活塞位置，讲解初始状态
  3. 点击"下一步"→步骤 2，显示气体区域，区分氧气和氮气
  4. 点击"下一步"→步骤 3，展示尺寸关系，讲解 S_A=4S_B 和初始位置
  5. 点击"下一步"→步骤 4，显示温度压强，完成初始状态参量标注
  6. 教师可随时点击"上一步"回退复习任一概念

- JS 库选择：原生 SVG（简单几何图形首选，无需额外库）
- 画布尺寸：800×500px（固定）
- 布局草图：
  ```

  +--------------------------------------------------+
  | T₁=280K                          P₀              | y=100
  |                                                    |
  |   +----A----+              +----B----+            |

  |   |  [a]    |              |  [b]    |  H, H/2    | y=80-380

  +--------------------------------------------------+
  |            [◀上一步]    [下一步▶]                 | y=440-490
  ```

- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-4) 跟踪当前步骤，数组 steps[5] 存储每步需显示的元素 ID 列表
  2. 坐标计算：气缸高 H=300px，活塞 a 的 y=80+H/4=155，活塞 b 的 y=80+H/2=230
  3. 氮气区域多边形：需精确计算活塞下方连通区域的顶点坐标
  4. 事件绑定：按钮点击事件切换步骤，更新元素 display 属性
  5. 按钮状态：步骤 0 禁用"上一步"，步骤 4"下一步"文字变为"重新开始"
- ID 命名规范：所有元素 ID 以 scene1- 为前缀
