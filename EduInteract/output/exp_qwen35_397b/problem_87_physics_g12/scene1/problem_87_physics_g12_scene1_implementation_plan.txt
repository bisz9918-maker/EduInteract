[图示主题与整合说明]
- 本图示主题：A 球受力分析——四力平衡的直观呈现
- 整合的步骤/概念：整合了 A 球静止时受到的重力、支持力、电场力、库仑力四个力的矢量表示
- 教学价值：教师可使用此图示逐步展示受力分析过程，从已知条件到各力矢量，最终呈现四力平衡状态。分步展示有助于学生理解每个力的来源、方向和平衡条件，建立完整的受力图景。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 底部左侧 (x=320, y=460)，点击后返回上一状态
  - 「下一步」按钮：位于 SVG 底部右侧 (x=480, y=460)，点击后进入下一状态
  - 步骤指示器：位于底部中央 (x=400, y=460)，显示"步骤 X/6"
- 教师操作流程：
  1. 初始状态展示题目基础条件（斜面、电场、两球位置）
  2. 点击「下一步」展示重力，讲解重力方向始终竖直向下
  3. 点击「下一步」展示支持力，讲解支持力垂直于接触面
  4. 点击「下一步」展示电场力，讲解负电荷受力与电场方向相反
  5. 点击「下一步」展示库仑力，讲解同种电荷相斥、B 球带正电
  6. 点击「下一步」展示平衡状态，讲解四力合力为零的平衡条件

[技术实现]
- JS 库选择及原因：原生 SVG。理由：本场景为静态几何图形+箭头矢量，无需复杂动画或交互，原生 SVG 轻量且易于精确控制坐标。
- 画布尺寸：800 × 500 px（固定画布）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  E→ 电场线区域 (y=80~330)                        |
  |                                                  |
  |         A●  [N]  [F_C]                           |
  |        / |  \                                    |
  |       /  |mg \                                   |
  |   B● /   |    \[F_E]                             |
  |  [L]    37°                                      |
  |                                                  |
  |              [合力为零]                          |
  |                                                  |
  |        [◀上一步]  步骤X/6  [下一步▶]             |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-5) 跟踪当前步骤，数组 steps 存储每步应显示的元素 ID 列表
  2. 坐标计算：斜面倾角 37°，垂直斜面方向的角度为 90°-37°=53°（从水平逆时针）
  3. 箭头绘制：使用 SVG <marker> 定义箭头头部，线段使用 <line> 元素
  4. 事件绑定：按钮点击事件切换 currentStep，调用 updateDisplay() 函数更新可见性
  5. 元素可见性：使用 CSS display 或 SVG visibility 控制元素显示/隐藏
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀
  - scene1-incline（斜面）
  - scene1-field-line-1~6（电场线）
  - scene1-ball-a（A 球）
  - scene1-ball-b（B 球）
  - scene1-label-a/b/l（标签）
  - scene1-force-mg/n/fe/fc（四个力矢量）
  - scene1-btn-prev/next（按钮）
  - scene1-step-indicator（步骤指示器）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
