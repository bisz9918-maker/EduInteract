    **题目原文：**

    如图所示，两根等高光滑的四分之一圆弧轨道，半径为 r，间距为 L，轨道电阻不计，在轨道顶端连有一阻值为 R 的电阻，整个装置处在一竖直向上的匀强磁场中，磁感应强度为 B，现有一根长度稍大于 L，电阻为 $\frac{1}{3}R$，质量为 m 的金属棒从轨道最低位置 cd 开始，在拉力作用下以速度 v₀ 向右沿轨道做匀速圆周运动至 ab 处，求：
    （1）初始时刻 cd 两端的电压；
    （2）在该过程中 R 上产生的热量；
    （3）拉力做的功．

    **题目分析：**

    本题是电磁感应与圆周运动、能量守恒的综合题。核心物理过程：金属棒在圆弧轨道上匀速运动，切割磁感线产生感应电动势，形成闭合回路，产生感应电流。

    **关键知识点：**
    1. 动生电动势：E = BLv⊥（v⊥为垂直于磁场和导体棒方向的有效速度分量）
    2. 闭合电路欧姆定律：I = E/(R + r)，路端电压 U = IR
    3. 焦耳热计算：Q = I²Rt（需注意电流随时间变化）
    4. 能量守恒：拉力做功 = 重力势能增加 + 回路总焦耳热

    **整体讲解思路：**
    - 先分析装置结构和运动特点（匀速圆周运动）
    - 再分析速度分解，确定有效切割速度
    - 然后分析电路，计算电压和热量
    - 最后用能量守恒求拉力做功

    **图示规划说明：**
    共设计 3 个图示：
    - SCENE_1：装置结构与运动轨迹（展示轨道、磁场、金属棒位置变化）
    - SCENE_2：速度分解与感应电动势（展示任意位置的速度分解和有效切割速度）
    - SCENE_3：等效电路与能量转化（展示电路结构和能量分配关系）
    </TEXT_1>

    **SCENE_2 教学说明：**

    本图示用于分析感应电动势的产生机制。教师应引导学生：

    1. 理解速度分解：金属棒做匀速圆周运动，速度 v₀ 沿圆弧切线方向
    2. 确定有效切割速度：只有垂直于磁场方向的速度分量才切割磁感线
    3. 观察变化规律：拖动滑块，发现 vₓ 随位置变化

    **关键公式推导：**

    设金属棒位置与水平方向夹角为θ：

    1. 速度分解：vₓ = v₀·cosθ（水平分量，有效切割速度）
    2. 感应电动势：E = BLvₓ = BLv₀·cosθ
    3. 初始时刻（θ = 0°）：E₀ = BLv₀（最大值）
    4. 末时刻（θ = 90°）：E = 0（最小值）

    **讲解要点：**
    - 初始时刻 cd 处，速度水平向右，vₓ = v₀，电动势最大
    - 随金属棒上升，vₓ 逐渐减小，电动势逐渐减小
    - 到达 ab 处，速度竖直向上，vₓ = 0，电动势为零

    <TEXT_4>
    **SCENE_3 教学说明：**

    本图示用于分析电路和能量关系。教师应引导学生：

    1. 识别等效电路：金属棒相当于电源（有内阻 R/3），外电路为电阻 R
    2. 应用闭合电路欧姆定律计算电流
    3. 理解热量分配与电阻成正比
    4. 应用能量守恒求拉力做功

    **完整解答：**

    **（1）初始时刻 cd 两端的电压：**

    初始时刻，金属棒在 cd 位置，速度水平向右：

    1. 感应电动势：E₀ = BLv₀
    2. 回路总电阻：R_总 = R + R/3 = 4R/3
    3. 回路电流：I₀ = E₀/R_总 = BLv₀/(4R/3) = 3BLv₀/(4R)
    4. cd 两端电压（路端电压）：U_cd = I₀·R = 3BLv₀/4

    **（2）R 上产生的热量：**

    由于电动势随时间变化 E = BLv₀·cosθ，需用能量守恒求解：

    1. 金属棒匀速运动，动能不变
    2. 重力势能增加：ΔE_p = mgr
    3. 设回路总焦耳热为 Q_总，则 Q_R = (R/(R + R/3))·Q_总 = (3/4)Q_总
    4. 由能量守恒：W_F = ΔE_p + Q_总

    由于电流变化，直接积分较复杂，通常题目会给出时间或角度关系。若金属棒匀速圆周运动，角速度ω = v₀/r，运动时间 t = (π/2)·(r/v₀) = πr/(2v₀)

    平均电动势法或积分法：
    Q_总 = ∫(E²/R_总)dt = ∫₀^(πr/2v₀) (BLv₀·cosθ)²/(4R/3) dt

    由于θ = ωt = (v₀/r)t，dθ = (v₀/r)dt：

    Q_总 = (3/4R)·B²L²v₀²·(r/v₀)·∫₀^(π/2) cos²θ dθ
    Q_总 = (3B²L²vr/4R)·(π/4) = 3πB²L²v₀r/(16R)

    因此 Q_R = (3/4)·Q_总 = 9πB²L²v₀r/(64R)

    **（3）拉力做的功：**

    由能量守恒：

    W_F = ΔE_p + Q_总 = mgr + 3πB²L²v₀r/(16R)

    **课堂讲解建议：**
    - 第（1）问较简单，可直接计算
    - 第（2）问涉及变电流，强调用能量观点或积分法
    - 第（3）问是能量守恒的直接应用，注意拉力做功转化为两部分能量
