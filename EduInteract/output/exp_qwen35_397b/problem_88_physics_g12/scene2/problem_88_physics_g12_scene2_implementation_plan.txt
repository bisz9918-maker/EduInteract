[图示主题与整合说明]
- 本图示主题：金属棒速度分解与有效切割速度分析
- 整合内容：任意位置的速度矢量、速度分解（水平分量和竖直分量）、有效切割速度、感应电动势计算
- 教学价值：教师可通过滑块拖动金属棒在圆弧轨道上的位置，直观展示速度方向随位置变化的规律，帮助学生理解为什么只有水平分速度 vx 是有效切割速度，以及感应电动势 E=BLvx 随角度变化的动态过程

[分步序列]
本场景为连续拖拽滑块交互，无分步导航，状态连续变化：
- 初始状态（θ=0°）：金属棒在圆弧最低点(180,140)，速度 v₀ 水平向右，vx=v₀，vy=0，E=BLv₀（最大值）
- 中间状态（θ=45°）：金属棒在圆弧中点(307,193)，速度 v₀ 沿45°切线方向，vx=v₀*cos45°，vy=v₀*sin45°，E=BLv₀*cos45°
- 最终状态（θ=90°）：金属棒在圆弧最高点(360,320)，速度 v₀ 竖直向上，vx=0，vy=v₀，E=0（最小值）

教师可拖动滑块在0°~90°之间任意位置停留，观察各物理量的实时变化

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：
  - 滑块（input type="range"）：位于 SVG 底部中央，范围0~90，控制金属棒位置角度θ
  - 角度数值显示：位于滑块右侧，实时显示当前θ值（如"θ = 45°"）
- 教师操作流程：
  1. 初始状态θ=0°，金属棒在最低点，展示最大感应电动势
  2. 缓慢拖动滑块，观察金属棒沿圆弧运动
  3. 在关键角度（如30°、45°、60°）停留，讲解速度分解关系
  4. 拖动到θ=90°，展示感应电动势为零的临界情况
  5. 引导学生总结 E=BLv₀cosθ 的变化规律

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单，无需复杂库；SVG 便于矢量图形绘制和动态更新
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |   B↑                    公式区                   |
  |   ↑                                            |
  |   |    圆弧轨道          E = BLvₓ               |
  |   |   ╱                                       |
  |   |  ╱  金属棒                                |
  |   | ╱   →v₀                                  |
  |   |╱   ↘                                     |
  |   O──────→ 基准线                              |
  |      θ                                        |
  |                                                  |
  |                                                  |
  |        [滑块━━━━━━━━━━━━] θ = 0°                |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态管理：单一状态变量 theta（0~90），所有元素位置由 theta 计算得出
  2. 坐标计算：
     - 金属棒中心：x = 180 + 180*sin(theta), y = 320 - 180*cos(theta)
     - 速度方向：切线方向，角度 = theta（相对于水平）
     - vx 长度：60 * cos(theta) px
     - vy 长度：60 * sin(theta) px
     - 感应电动势：E = B * L * v₀ * cos(theta)
  3. 事件绑定：滑块 input 事件监听，实时更新所有元素位置
  4. 动画：无需额外动画，滑块拖动即实时更新
  5. IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中
- ID 命名规范：
  - scene2-arc-track（圆弧轨道）
  - scene2-rod（金属棒）
  - scene2-arrow-v0（速度矢量）
  - scene2-arrow-vx（水平分量）
  - scene2-arrow-vy（竖直分量）
  - scene2-field-b（磁场箭头组）
  - scene2-angle-arc（角度弧线）
  - scene2-label-theta（角度标签）
  - scene2-formula（公式显示）
  - scene2-slider（滑块控件）
  - scene2-slider-value（角度数值显示）
