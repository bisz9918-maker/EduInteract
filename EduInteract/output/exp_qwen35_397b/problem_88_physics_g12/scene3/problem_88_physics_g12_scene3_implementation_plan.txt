[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：电路图和框图均为简单几何图形，原生 SVG 足够实现，无需额外库依赖
- 画布尺寸：800×500px（固定）
- 布局草图：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │  [等效电路图]                    [能量转化框图]              │
  │   ┌─────┐                          ┌──────────────┐        │
  │   │  E  │───[R/3]───I───[R]───     │   W_F        │        │
  │   └─────┘                          └──────┬───────┘        │
  │      │                                    │                │
  │      └─────────────────────────           ▼                │
  │                               ┌─────────────────────┐      │
  │                               │  ΔE_p  │   Q_总     │      │
  │                               └─────────────────────┘      │
  │                                                            │
  │   [热量分配区]                                             │
  │   ┌─────────────────────────────────────────────┐          │
  │   │  Q_R = 3Q_0    Q_棒 = Q_0    比例 3:1       │          │
  │   └─────────────────────────────────────────────┘          │
  │                                                            │
  │                    [◀上一步] 步骤 X/5 [下一步▶]             │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-5），数组存储每步的可见元素 ID 列表
  2. 坐标计算：所有元素使用绝对坐标，避免相对定位导致的偏移
  3. 动画曲线：使用 CSS transition 实现淡入淡出（opacity 0→1，duration 300ms）
  4. 事件绑定：按钮点击事件绑定到 updateScene() 函数，更新当前状态并重绘
  5. 电阻符号绘制：使用 SVG polyline 绘制标准折线电阻符号（5 段折线）
  6. 电池符号绘制：使用 SVG line 绘制长短线表示正负极

- ID 命名规范：
  - 所有元素 ID 必须以 scene3- 为前缀
  - 示例：scene3-battery-E, scene3-resistor-R3, scene3-resistor-R, scene3-current-I, scene3-voltage-Ucd
  - 能量框图：scene3-box-Wf, scene3-box-Ep, scene3-box-Qtotal, scene3-box-heat-dist
  - 按钮：scene3-btn-prev, scene3-btn-next, scene3-step-indicator

- IIFE 隔离：
  ```javascript
  (function() {
    // 所有 JS 代码包裹在此
    let currentState = 0;
    const totalSteps = 5;
    
    function updateScene() {
      // 根据 currentState 显示/隐藏对应元素
    }
    
    // 事件绑定
    document.getElementById('scene3-btn-next').addEventListener('click', function() {
      if (currentState < totalSteps) {
        currentState++;
        updateScene();
      }
    });
    
    // 初始化
    updateScene();
  })();
  ```
