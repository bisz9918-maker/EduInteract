- 步骤 3：在步骤 2 基础上 → 显示 E₂ 区域轨迹段 2（红色曲线，从虚线 ab 到 Q 点），轨迹渐显动画

[标签冲突检查]
- 标签"O"：坐标 (65,440)
- 标签"x"：坐标 (760,415)
- 标签"y"：坐标 (70,40)
- 标签"P"：坐标 (55,220)
- 标签"Q"：坐标 (580,440)
- 标签"a"：坐标 (300,40)
- 标签"b"：坐标 (300,450)
- 标签"E₁"：坐标 (180,80)
- 标签"E₂"：坐标 (520,100)
- 标签"h"：坐标 (45,320)
- 标签"L"：坐标 (190,470)

冲突检查结果：
- "O"与"P"：垂直距离 180px → 无冲突
- "O"与"Q"：水平距离 515px → 无冲突
- "a"与"E₁"：垂直距离 40px，水平距离 120px → 无冲突
- "b"与"L"：垂直距离 20px，水平距离 110px → 无冲突（间距足够）
- "P"与"h"：水平距离 10px → 需调整 h 标签至 (35,320)，确保间距≥15px
- "Q"与"L"：水平距离 390px → 无冲突
- "E₁"与"E₂"：水平距离 340px → 无冲突

解决方案：h 标注文字位置调整为 (35,320)，确保与 P 点标签有足够间距

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 内底部左侧 (x=280, y=455)，宽 80px，高 30px，浅灰色背景 (#e0e0e0)
  - 「下一步」按钮：位于 SVG 内底部右侧 (x=440, y=455)，宽 80px，高 30px，浅蓝色背景 (#bbdefb)
  - 步骤指示器：位于两按钮之间 (x=380, y=460)，显示「步骤 X/5」
- 教师操作流程：
  1. 初始展示坐标系和电场分布，讲解电场区域划分
  2. 点击「下一步」显示 P 点，说明粒子初始位置
  3. 点击「下一步」展示 E₁ 区域轨迹，讲解粒子在水平电场中的加速运动
  4. 点击「下一步」展示 E₂ 区域轨迹，讲解类平抛运动
  5. 点击「下一步」显示 Q 点，说明粒子离开位置
  6. 点击「下一步」高亮分界线，总结两个区域的运动特点
  7. 可随时点击「上一步」回退复习

[技术实现]
- JS 库选择：原生 SVG（简单几何图形和曲线，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  | y                                                |
  | ^      E₁              |           E₂            |
  | |    →→→→→            |            ↓↓↓          |
  | |    →→→→→   ab       |            ↓↓↓          |
  | | P  →→→→→   |        |  轨迹      ↓↓↓    Q     |
  | |    →→→→→   |        |  ~~~~~~~~  ↓↓↓    ●     |
  | |    →→→→→   |        |            ↓↓↓          |
  | |    →→→→→   |        |            ↓↓↓          |
  | +---------------------+------------+-----------> x
  | O            b        L            Q            |
  |                                                |
  |      [◀上一步]  步骤 X/5  [下一步▶]            |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量 (0-5)，每个步骤对应显示/隐藏特定元素组
  2. 轨迹动画：使用 SVG path 的 stroke-dasharray 和 stroke-dashoffset 实现渐显效果
  3. 坐标计算：所有元素坐标预先计算好，硬编码在 SVG 中
  4. 事件绑定：按钮点击事件切换 currentStep，调用 updateDisplay() 函数更新可见性
  5. 高亮效果：通过修改 CSS class 或内联 style 实现线宽/颜色变化
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀
  - scene1-axis-x, scene1-axis-y, scene1-line-ab, scene1-point-a, scene1-point-b
  - scene1-point-p, scene1-point-q, scene1-label-p, scene1-label-q
  - scene1-field-e1-1~8, scene1-field-e2-1~6
  - scene1-trajectory-1, scene1-trajectory-2
  - scene1-label-e1, scene1-label-e2, scene1-label-h, scene1-label-l
  - scene1-btn-prev, scene1-btn-next, scene1-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
