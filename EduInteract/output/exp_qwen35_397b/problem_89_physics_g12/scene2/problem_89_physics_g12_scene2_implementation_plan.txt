[图示主题与整合说明]
- 本图示主题：带电粒子在分区域电场中的运动——速度矢量分解与分析
- 整合内容：P 点、ab 边界、Q 点三处的速度矢量，E₂ 区域速度分解（水平分量 vₓ、竖直分量 vᵧ）
- 教学价值：教师可通过分步展示，帮助学生理解粒子在不同电场区域的速度变化规律，特别是类平抛运动的速度分解方法，从静止加速到匀速再到曲线运动的速度矢量演变过程

[分步序列]
- 初始状态（步骤 0）：显示坐标系、虚线 ab、P 点、Q 点、运动轨迹（灰色曲线）、E₁ 和 E₂ 电场线及标签。所有速度矢量隐藏。
- 步骤 1：点击「下一步」→ 在 P 点上方显示「v=0」标签，表示粒子初始静止状态。
- 步骤 2：点击「下一步」→ 隐藏 v=0 标签，在 ab 边界处显示 v₁ 矢量（蓝色水平箭头，从 (380,280) 到 (440,280)）及标签「v₁」，表示粒子穿过 E₁ 区域后的速度。
- 步骤 3：点击「下一步」→ 隐藏 v₁ 矢量及标签，在 Q 点显示速度分解：vₓ 水平分量（蓝色箭头）、vᵧ 竖直分量（绿色箭头）、分解辅助虚线矩形。显示标签「vₓ」「vᵧ」。
- 步骤 4：点击「下一步」→ 在步骤 3 基础上，显示 Q 点合速度 v（红色箭头，从 (600,420) 到 (660,360)）、θ 角弧及标签、公式标注「v = √(vₓ² + vᵧ²)」。完成速度分解分析。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 内底部左侧 (280,455)，灰色背景，点击返回上一状态
  - 「下一步」按钮：位于 SVG 内底部右侧 (440,455)，蓝色背景，点击进入下一状态
  - 步骤指示器：位于两按钮之间 (380,460)，显示「步骤 X/4」
- 教师操作流程：
  1. 初始状态展示题目基础条件（轨迹、电场区域、关键点）
  2. 点击「下一步」展示 P 点初速度为零
  3. 点击「下一步」展示 ab 边界处粒子获得水平速度 v₁
  4. 点击「下一步」展示 Q 点速度分解为水平和竖直分量
  5. 点击「下一步」展示合速度及计算公式
  6. 可随时点击「上一步」回退复习关键概念

[技术实现]
- JS 库选择：原生 SVG（简单几何图形和箭头，无需额外库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  | y                                                |
  | ^                                                |
  | |     E₁          ab         E₂                  |
  | |    →→→→→        |        ↓↓↓↓↓                 |
  | |    →→→→→        |        ↓↓↓↓↓     公式区      |
  | P•   →→→→→        |        ↓↓↓↓↓                  |
  | |    →→→→→        |        ↓↓↓↓↓                  |
  | |    →→→→→        v        ↓↓↓↓↓                  |
  | |              轨迹曲线      ↓↓↓↓↓                 |
  | |                          ↓↓↓↓↓                 |
  | +--------------------------+----• Q----> x       |
  | O                          b                     |
  |                                                  |
  |         [◀上一步]  步骤 X/4  [下一步▶]           |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量 (0-4)，steps 数组存储每步显示的元素 ID 列表
  2. 坐标计算：所有元素坐标硬编码，确保与布局表一致
  3. 动画曲线：使用 CSS transition 实现箭头淡入淡出 (opacity 0→1，300ms ease)
  4. 事件绑定：按钮点击事件切换状态，更新显示元素和步骤指示器
  5. 箭头绘制：使用 SVG marker-end 定义箭头样式，path 元素绘制矢量
  6. 抛物线轨迹：使用 SVG path 二次贝塞尔曲线 Q 命令
- ID 命名规范：所有元素 ID 以 scene2- 为前缀，如 scene2-p-point、scene2-v1-arrow、scene2-q-vx 等
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
