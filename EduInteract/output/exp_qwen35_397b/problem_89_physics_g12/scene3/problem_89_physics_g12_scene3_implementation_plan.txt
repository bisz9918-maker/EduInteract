[图示主题与整合说明]
- 本图示主题：运动参数关系探究
- 整合内容：电场强度 E₁、E₂ 和初始高度 h 对轨迹和 Q 点位置的影响
- 教学价值：教师通过拖动滑块实时展示参数变化对粒子运动轨迹的影响，帮助学生理解：
  1. E₁ 增大 → 粒子在 E₁ 区域加速更快 → 进入 E₂ 时 x 方向速度更大 → Q 点更靠右
  2. E₂ 增大 → 粒子在 E₂ 区域向下加速更快 → 下落时间更短 → Q 点更靠左
  3. h 增大 → 下落高度更大 → 在 E₂ 区域运动时间更长 → Q 点更靠右
  教师可引导学生观察规律，培养物理直觉和定量分析能力

[交互方案]
- 交互类型：连续拖拽滑块（三个独立滑块）
- 控件说明：
  1. E₁滑块：位于底部左侧(50,445)-(230,455)，范围50-200 N/C，初始值100
  2. E₂滑块：位于底部中间(280,445)-(460,455)，范围50-250 N/C，初始值150
  3. h滑块：位于底部右侧(510,445)-(690,455)，范围0.2-1.0 m，初始值0.5
  4. 坐标显示框：右下角(550,475)-(780,495)，显示"Q点：(x.xx, 0) m"

- 教师操作流程：
  1. 初始状态展示默认参数下的粒子运动轨迹
  2. 拖动E₁滑块，引导学生观察：E₁增大→轨迹在E₂区域更平缓→Q点右移
  3. 拖动E₂滑块，引导学生观察：E₂增大→轨迹在E₂区域更陡峭→Q点左移
  4. 拖动h滑块，引导学生观察：h增大→P点上移→Q点右移
  5. 结合坐标显示框的数值变化，引导学生定量分析关系

[技术实现]
- JS库选择：原生SVG + 原生JavaScript
  - 原因：几何图形简单，无需复杂库；SVG便于动态更新轨迹路径；原生JS足够处理滑块交互

- 画布尺寸：800 × 500 px（固定）

- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  y                                               |
  |  ↑    E₁         |        E₂                     |
  |  |    →→→        |        ↓                      |
  |  |    →→→   ab   |        ↓                      |
  |  P●   →→→   |    |        ↓                      |
  |  |           |    |        ↓                      |
  |  |___________|____|________↓______ Q●___→ x     |
  |  O           b    |                               |
  |              L    |                               |
  |                                                          |
  |  E₁=[100]      E₂=[150]      h=[0.5]                    |
  |  [====●====]   [====●====]   [====●====]                |
  |                              Q点：(x.xx, 0) m           |
  +--------------------------------------------------+
  ```

- 关键实现要点：
  1. 状态管理：维护三个参数状态{E1, E2, h}，每次滑块变化触发重绘
  2. 轨迹计算：
     - E₁区域(0≤x≤L)：粒子做匀加速直线运动，轨迹为水平线段
     - E₂区域(x>L)：粒子做类平抛运动，轨迹为抛物线
     - 物理公式：
       * v₁ = √(2qE₁L/m)（出E₁时x方向速度）
       * t₂ = √(2mh/qE₂)（在E₂区域运动时间）
       * x_Q = L + v₁×t₂ = L + 2√(E₁Lh/E₂)
     - 轨迹参数方程（E₂区域）：
       * x(t) = L + v₁×t
       * y(t) = h - 0.5×(qE₂/m)×t²
       * 消去t得：y = h - (qE₂/2m)×((x-L)/v₁)²
  3. 坐标映射：物理坐标→画布像素坐标
     - x轴：物理0→画布80px，物理L_max→画布650px
     - y轴：物理0→画布380px，物理h_max→画布80px
  4. 事件绑定：
     - 滑块mousedown：开始拖拽，记录初始位置
     - 滑块mousemove：更新手柄位置和参数值，重绘轨迹
     - 滑块mouseup：结束拖拽
     - 滑块mouseleave：结束拖拽
  5. 动画优化：使用requestAnimationFrame平滑更新轨迹

- IIFE隔离：所有JS代码包在(function() { ... })()中，避免全局变量污染

- 物理常量简化：
  - 设q/m = 1 C/kg（比荷归一化，不影响定性规律）
  - L = 0.4 m（固定值）
  - 这样公式简化为：
    * v₁ = √(2E₁L)
    * t₂ = √(2h/E₂)
    * x_Q = L + 2√(E₁Lh/E₂)
