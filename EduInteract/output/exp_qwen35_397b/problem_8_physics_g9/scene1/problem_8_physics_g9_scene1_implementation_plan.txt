[分步序列]
- 初始状态（步骤0）：显示原电路实物图，包含所有元件（电源、开关、L₁、L₂、电压表）及导线连接，所有标签可见。电压表接线柱用小红点标记。
- 步骤1：点击「下一步」→ 显示蓝色电流路径箭头（4个箭头沿导线方向），高亮显示电流从电源正极→L₁→开关→L₂→电源负极的完整路径。箭头带轻微脉动动画。
- 步骤2：点击「下一步」→ 电压表连接线变为红色加粗（#c62828，4px），清晰显示电压表并联在L₂两端。L₂灯泡添加淡黄色发光效果（fill-opacity从0.2增至0.6）。
- 步骤3：点击「下一步」→ 显示虚线外框包围整个电路，顶部中央显示"串联电路"文字标注。电压表V符号放大1.2倍并加粗，强调测量对象。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 按钮"上一步"：位置(320,455)，尺寸80×30px，灰色背景#9e9e9e，白色文字
  - 按钮"下一步"：位置(400,455)，尺寸80×30px，蓝色背景#1565c0，白色文字
  - 步骤指示器：位置(500,460)，显示"步骤 X/3"，黑色文字12px
- 教师操作流程：
  1. 初始展示完整电路图，让学生识别各元件
  2. 点击"下一步"展示电流路径，讲解串联电路电流特点
  3. 点击"下一步"高亮电压表并联关系，讲解电压表测量原理
  4. 点击"下一步"总结电路结构，为后续故障分析做铺垫
  5. 可随时点击"上一步"回退复习

[技术实现]
- JS库选择：原生SVG（电路图为静态几何图形，无需复杂动画库）
- 画布尺寸：800×500px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +------------------------------------------+
  |  开关      串联电路        L₁            |
  |    \                        |            |
  |     \                       |            |
  |      \                      |            |
  |       \                     |            |
  |        \                    |            |
  |         \              电压表|            |
  |          \                   |            |
  |           \                  |            |
  |            \                 |            |
  |  L₂---------+----------------+  电源      |
  |                                          |
  |         [上一步] [下一步] 步骤1/3         |
  +------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用currentState变量（0-3），每次点击更新状态并重绘
  2. 元素分组：将各步骤元素放入<g>组，通过display控制显示/隐藏
  3. 箭头动画：使用CSS @keyframes实现脉动效果（opacity 0.6→1.0循环）
  4. 事件绑定：按钮点击事件绑定到updateState函数
  5. ID命名规范：所有元素ID以scene1-为前缀（如scene1-bulb-l1、scene1-arrow-1）
  6. IIFE隔离：所有JS代码包在(function() { ... })()中，避免全局污染
- 配色规格：
  - 背景：#ffffff
  - 导线及元件轮廓：#000000
  - 电流路径：#1565c0
  - 电压表连接：#c62828
  - 元件标签：#000000 黑体14px
  - 灯泡填充：#fff9c4（透明度20%）
  - 电压表填充：#e3f2fd
