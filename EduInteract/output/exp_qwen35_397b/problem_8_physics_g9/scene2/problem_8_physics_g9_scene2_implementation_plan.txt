[图示主题与整合说明]
- 本图示主题：四种故障情况对比分析（电路故障诊断）
- 整合的内容：四个选项（L1 短路、L1 断路、L2 短路、L2 断路）对应的电路状态、灯的亮灭情况、电压表示数、电流路径
- 教学价值：教师可点击不同选项按钮，直观展示每种故障下的电路现象，帮助学生理解串联电路中短路/断路对电路的影响，以及电压表测量原理。通过对比四种情况，学生能快速匹配题目条件（一灯亮一灯不亮、电压表有示数）找出正确答案。

[视觉元素清单]

- L2 灯泡：圆形灯座 + 内部叉丝，位置 (80,280)，正常时灰色 #9e9e9e，亮时黄色 #ffd54f 加发光效果

[分步序列]
本场景为多状态切换交互，无分步导航，通过 4 个按钮切换状态：

状态 0（初始/无选择）：
- 显示基础电路图（所有元件灰色，无电流，电压表指针归零）
- 现象框显示"请选择一个选项查看对应现象"
- 所有按钮为默认灰色状态

状态 A（点击按钮 A：L1 短路）：
- L1 位置显示红色短路符号（波浪线）
- L1 不亮（灰色），L2 亮（黄色发光）
- 电流路径：电源→L2→开关→（跳过 L1）→电源，蓝色箭头显示
- 电压表：指针偏转（绿色），显示有示数（约 3V）
- 现象框文字：
  "A. L₁短路
   • L₁：不亮（被短路）
   • L₂：亮
   • 电压表：有示数
   • 电流：有电流通过 L₂"

状态 B（点击按钮 B：L1 断路）：
- L1 位置显示红色×标记
- L1 不亮（灰色），L2 不亮（灰色）
- 无电流路径（整个电路断开）
- 电压表：指针归零（灰色），无示数
- 现象框文字：
  "B. L₁断路
   • L₁：不亮
   • L₂：不亮（电路断开）
   • 电压表：无示数
   • 电流：无电流"

状态 C（点击按钮 C：L2 短路）：
- L2 位置显示红色短路符号（波浪线）
- L1 亮（黄色发光），L2 不亮（灰色）
- 电流路径：电源→（跳过 L2）→开关→L1→电源，蓝色箭头显示
- 电压表：指针归零（灰色），无示数（电压表被短路）
- 现象框文字：
  "C. L₂短路
   • L₁：亮
   • L₂：不亮（被短路）
   • 电压表：无示数（被短路）
   • 电流：有电流通过 L₁"

状态 D（点击按钮 D：L2 断路）：
- L2 位置显示红色×标记
- L1 不亮（灰色），L2 不亮（灰色）
- 无电流路径（整个电路断开）
- 电压表：指针偏转（绿色），显示有示数（测电源电压）
- 现象框文字：
  "D. L₂断路
   • L₁：不亮
   • L₂：不亮（电路断开）
   • 电压表：有示数（测电源电压）
   • 电流：无电流通过灯"

[标签冲突检查]
所有标签及其预计坐标：
- "L₁"：(425,85) — 右上角，远离其他元素
- "L₂"：(65,325) — 左下角，远离其他元素
- "S"：(95,75) — 开关上方，独立区域
- "V"：(260,205) — 电压表表盘内部中央
- "A"：(140,467) — 按钮 A 中央
- "B"：(240,467) — 按钮 B 中央
- "C"：(340,467) — 按钮 C 中央
- "D"：(440,467) — 按钮 D 中央
- "现象分析"：(495,105) — 现象框顶部
- 现象内容文字：(495,140) 起多行 — 现象框内部

冲突检查结果：
- L₁(425,85) 与 L₂(65,325)：距离 >200px，无冲突
- L₁(425,85) 与 S(95,75)：x 距离 330px，无冲突
- L₂(65,325) 与电压表(200,180)：距离 >100px，无冲突
- 所有按钮标签 y 坐标相同 (467)，x 间距 100px，无冲突
- 现象框内文字与电路图完全分离（x≥480 vs x≤400），无冲突
- 电压表内部"V"标签在表盘中央，不与指针冲突（指针旋转范围在刻度区）

结论：所有标签位置分散，间距均≥20px，无重叠冲突。

[交互方案]
- 交互类型：多状态切换（4 个按钮）
- 控件说明：
  - 按钮 A（位置 (100,450)-(180,485)）：选择"L₁短路"故障
  - 按钮 B（位置 (200,450)-(280,485)）：选择"L₁断路"故障
  - 按钮 C（位置 (300,450)-(380,485)）：选择"L₂短路"故障
  - 按钮 D（位置 (400,450)-(480,485)）：选择"L₂断路"故障
- 教师操作流程：
  1. 初始状态展示基础电路，让学生观察电路结构
  2. 依次点击 A/B/C/D 按钮，展示每种故障的现象
  3. 引导学生对比四种情况，找出符合题目条件（一灯亮一灯不亮、电压表有示数）的选项
  4. 正确答案为 A（L₁短路），此时 L₂亮、L₁不亮、电压表有示数

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：电路图由简单几何形状（线段、圆形、矩形）组成，SVG 矢量图形适合精确绘制且易于动画控制；无需复杂库
- 画布尺寸：800×500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  [电路图区 ~450px 宽]    |  [现象框 300×300]     |
  |                          |                       |
  |     S    L1              |  +-----------------+  |
  |    /      O              |  |  现象分析       |  |
  |   |      /               |  |                 |  |
  |   O L2  [V] 电压表       |  | • L1: 亮/不亮   |  |
  |   |      |               |  | • L2: 亮/不亮   |  |
  |   |______|___ 电源       |  | • 电压表：示数  |  |
  |                          |  | • 电流：有/无   |  |
  |                          |  +-----------------+  |
  |                          |                       |
  |  [A] [B] [C] [D] 按钮    |                       |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentState 存储当前选中状态（null/'A'/'B'/'C'/'D'）
  2. 元件状态控制：
     - 灯泡亮灭：切换 fill 颜色和 filter（发光效果用 SVG feGaussianBlur）
     - 电流路径：显示/隐藏箭头组（marker-end 箭头）
     - 电压表指针：旋转 transform，颜色切换绿/灰
     - 故障标记：显示/隐藏×或波浪线
  3. 事件绑定：4 个按钮点击事件，调用 updateState(state) 函数
  4. 按钮高亮：选中按钮背景变蓝，其他恢复灰色
  5. 现象文字：动态更新 textContent
- ID 命名规范：所有元素 ID 以 scene2- 为前缀
  - scene2-btn-a, scene2-btn-b, scene2-btn-c, scene2-btn-d（按钮）
  - scene2-l1, scene2-l2（灯泡）
  - scene2-voltmeter-needle（电压表指针）
  - scene2-fault-mark（故障标记）
  - scene2-current-arrows（电流箭头组）
  - scene2-phenomenon-box（现象框）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
