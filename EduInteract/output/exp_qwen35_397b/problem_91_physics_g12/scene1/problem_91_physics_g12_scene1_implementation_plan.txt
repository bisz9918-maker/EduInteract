[图示主题与整合说明]
- 本图示主题：三带电小球系统受力分析总览
- 整合的内容：三球位置关系、各球所受库仑力方向、整体加速度方向、外力 F 方向
- 教学价值：教师可逐步展示受力分析过程，从初始状态到各球受力，再到合力方向，符合认知递进规律。通过分步揭示库仑力的方向判断（同种电荷相斥、异种电荷相吸），帮助学生理解为何 C 球必须带负电才能使系统保持等边三角形构型一起加速运动。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - "上一步"按钮：位于 SVG 内底部左侧 (320, 455)，80×30px，点击后退到前一状态
  - "下一步"按钮：位于 SVG 内底部中间 (420, 455)，80×30px，点击前进到下一状态
  - 步骤指示：位于 SVG 内底部右侧 (520, 465)，显示"步骤 X/4"
- 教师操作流程：
  1. 初始状态展示三球位置和加速度方向，讲解题目条件
  2. 点击"下一步"展示 A 球受力，讲解同种电荷相斥（F_BA 向上）、异种电荷相吸（F_CA 引力）
  3. 点击"下一步"展示 B 球受力，对称分析
  4. 点击"下一步"展示 C 球受力，说明 C 受两个引力和外力 F
  5. 点击"下一步"展示合力方向，说明三球加速度相同，系统保持构型

[技术实现]
- JS 库选择：原生 SVG（简单几何图形首选，无需额外库）
- 画布尺寸：800×500px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                    a→                            |
  |                                                  |
  |    A●                                           |
  |     | \                                         |
  |     |  \                                        |
  |     |   \                                       |
  |    B●----●C  →F                                 |
  |                                                  |
  |                                                  |
  |                                                  |
  |              [上一步] [下一步]  步骤 X/4         |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：currentStep 变量（0-4），每个步骤对应一组元素的显示/隐藏状态
  2. 元素 ID 命名：所有元素以 scene1- 为前缀，如 scene1-ball-a、scene1-force-fba
  3. 箭头绘制：使用 SVG marker-end 定义箭头，line 元素绘制箭身
  4. 虚线样式：stroke-dasharray="5,5"
  5. 事件绑定：按钮点击事件切换 currentStep，调用 updateDisplay() 更新各元素 display 属性
  6. IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
- ID 命名规范：
  - 球：scene1-ball-a, scene1-ball-b, scene1-ball-c
  - 边框：scene1-triangle-border
  - 标签：scene1-label-a, scene1-label-b, scene1-label-c, scene1-label-qa, scene1-label-qb, scene1-label-qc
  - 加速度：scene1-arrow-a, scene1-label-a-accel
  - 外力：scene1-arrow-f, scene1-label-f
  - 库仑力：scene1-force-fba, scene1-force-fca, scene1-force-fab, scene1-force-fcb, scene1-force-fac, scene1-force-fbc
  - 合力箭头：scene1-net-a, scene1-net-b, scene1-net-c
  - 控件：scene1-btn-prev, scene1-btn-next, scene1-step-indicator
