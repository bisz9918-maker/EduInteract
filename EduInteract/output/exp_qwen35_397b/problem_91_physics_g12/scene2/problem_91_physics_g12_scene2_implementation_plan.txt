- 步骤 2：点击「下一步」→ F_CA 分解为 F_CAx（水平向右虚线箭头）和 F_CAy（竖直向下虚线箭头）。标签：F_CAx、F_CAy

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 底部左侧 (x=350, y=460)，宽 80px，高 30px
  - 「下一步」按钮：位于 SVG 底部右侧 (x=450, y=460)，宽 80px，高 30px
  - 步骤指示器：位于两按钮之间 (x=430, y=465)，显示「步骤 X/5」
- 教师操作流程：
  1. 初始状态展示 A 球受两库仑力，讲解受力来源
  2. 点击「下一步」添加坐标系，建立正交分解参考
  3. 点击「下一步」展示 F_CA 分解，讲解分力方向
  4. 点击「下一步」标注 60° 角，讲解等边三角形几何关系
  5. 点击「下一步」竖直方向平衡，导出电荷量关系方程
  6. 点击「下一步」水平方向合力，导出加速度表达式

[技术实现]
- JS 库选择及原因：原生 SVG（简单几何图形和矢量箭头，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |    A(+q)         坐标系          C               |
  |      o-----------x                               |
  |      | \         |                               |
  |  F_BA|  \ F_CA   y                               |
  |      |   \       |                               |
  |      |    \      |                               |
  |      |     \     |                               |
  |      |      \    |                               |
  |      |       \   |                               |
  |      o--------o  |                               |
  |    B(+q)        |                               |
  |                                                  |
  |                                      [60°]       |
  |                                                  |
  |                                                  |
  |              [◀上一步]  步骤 X/5  [下一步▶]       |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用 currentStep 变量 (0-5) 跟踪当前步骤，steps 数组存储每步显示的元素 ID 列表
  2. 坐标计算：A 球 (250,200)，B 球 (250,350)，C 球 (510,275)，等边三角形边长≈150px
  3. 矢量箭头：用 SVG <marker> 定义箭头，<line> + <marker-end> 绘制
  4. 虚线分力：stroke-dasharray="5,5" 实现虚线效果
  5. 角度弧线：SVG <path> 用圆弧命令 A 绘制 60° 弧
  6. 事件绑定：按钮点击事件切换步骤，更新元素 display 属性
  7. 高亮效果：步骤 4-5 用 stroke 颜色变化高亮相关矢量
- ID 命名规范：所有元素 ID 以 scene2- 为前缀
  - scene2-ball-a, scene2-ball-b, scene2-ball-c
  - scene2-line-ab, scene2-line-ac, scene2-line-bc
  - scene2-arrow-fba, scene2-arrow-fca
  - scene2-arrow-fcax, scene2-arrow-fcay
  - scene2-axis-x, scene2-axis-y
  - scene2-arc-60deg
  - scene2-label-a, scene2-label-b, scene2-label-c
  - scene2-label-fba, scene2-label-fca, scene2-label-fcax, scene2-label-fcay
  - scene2-label-q-a, scene2-label-q-b
  - scene2-label-r-ab, scene2-label-r-ac, scene2-label-r-bc
  - scene2-btn-prev, scene2-btn-next, scene2-step-indicator
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
