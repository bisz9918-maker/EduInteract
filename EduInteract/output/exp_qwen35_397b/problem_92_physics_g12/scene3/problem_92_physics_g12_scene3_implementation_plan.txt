[分步序列]
- 初始状态（步骤 0）：显示中心线 RO、PS 界面虚线、点电荷 Q（蓝色圆）、荧光屏 EF（绿色线段）、标签 Q/O/E/F。粒子入射点用小圆标记在 PS 界面与中心线交点附近
- 步骤 1：点击「下一步」→ 显示红色圆弧轨迹（从 PS 界面到荧光屏），圆弧圆心为 O 点，展示粒子在点电荷电场中的圆周运动路径
- 步骤 2：点击「下一步」→ 显示蓝色虚线轨道半径 r（从 O 点到轨迹上粒子位置），标注几何关系：入射点到 O 的水平距离、竖直偏离 y（紫色双箭头），标签 r 和 y 出现
- 步骤 3：点击「下一步」→ 显示绿色库仑力 F 箭头（从粒子位置指向 O 点）、红色速度 v 箭头（沿轨迹切线方向），标签 F 和 v 出现，展示受力与速度方向关系
- 步骤 4：点击「下一步」→ 显示公式框（左上角），内容：kQq/r² = mv²/r，下方显示 Q 的表达式：Q = mv²r/(kq)，完成推导链条

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 步骤指示器：显示「步骤 X/5」，位于控件栏中央
  - 「上一步」按钮：位于左侧，点击回退到前一状态
  - 「下一步」按钮：位于右侧，点击进入下一状态
  - 重置按钮：位于最右侧，点击回到初始状态
- 教师操作流程：
  1. 初始状态展示基础设置（点电荷、荧光屏、中心线）
  2. 点击「下一步」展示圆弧轨迹，讲解粒子为何做圆周运动
  3. 点击「下一步」展示半径和几何关系，讲解如何确定轨道半径
  4. 点击「下一步」展示库仑力和速度矢量，讲解受力方向与速度方向的关系
  5. 点击「下一步」展示公式，推导点电荷电量 Q 的表达式
  6. 可随时点击「上一步」回退复习关键步骤

[技术实现]
- JS 库选择及原因：原生 SVG（几何图形精确、标签清晰、无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────┐
  │ [公式框]                                    标题区       │ y=10~110
  │                                                          │
  │                    PS 界面                               │
  │                      │                                   │
  │         圆弧轨迹←───●───→v                              │ y=200~300
  │                    │ \                                   │
  │                    │  \ F                                │
  │                    │   \                                 │
  │  ──────────────────┼────●───────[荧光屏 EF]─────         │ y=250 中心线
  │                    │    O(Q)                             │
  │                                                          │
  │                                                          │
  │                                                          │
  │  [◀上一步]    步骤 X/5    [下一步▶]    [重置]            │ y=440~490
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用 currentState 变量 (0-4) 跟踪当前步骤，steps 数组存储每步显示的元素 ID 列表
  2. 坐标计算：圆弧轨迹用 SVG path 的 A 命令，圆心 O(600,250)，半径根据几何关系计算
  3. 动画曲线：元素淡入用 CSS transition opacity 0.3s ease
  4. 事件绑定：按钮点击事件切换状态，调用 updateScene() 函数更新显示
  5. 元素显隐：每步用 display:none/block 控制元素显示，避免重复创建
- ID 命名规范：所有交互元素 ID 必须以 scene3- 为前缀
  - scene3-center-line, scene3-ps-interface, scene3-charge-q, scene3-screen-ef
  - scene3-arc-trajectory, scene3-radius-r, scene3-force-f, scene3-velocity-v
  - scene3-particle, scene3-geo-y, scene3-formula-box
  - scene3-btn-prev, scene3-btn-next, scene3-btn-reset, scene3-step-indicator
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
