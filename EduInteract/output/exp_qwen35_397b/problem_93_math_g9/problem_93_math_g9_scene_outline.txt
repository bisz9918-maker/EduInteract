    **题目原文：**

    如图 1，已知线段 AB=8，点 C 是 AB 上的一动点（不包括 A、B），在 AB 同侧作两个等边三角形 ACD 和 BCE，连 DE，点 P、F 分别是 DE 和 BE 的中点，连接 AF，分别交 DC、CE 于 G、H．

    （1）写出图中所有的相似三角形（除等边三角形 ACD 和 BCE 外）；

    （2）当点 C 在 AB 中点时，如图 2，求 CP 的长及 AG：GH：HF；

    （3）点 M、N 是线段 AB 上两点，且 AM=BN=2，当点 C 从点 M 向点 N 运动时，求点 P 所经过的路径长．

    **题目分析：**

    本题是综合性几何题，涉及等边三角形性质、相似三角形判定、中点性质、动点轨迹等核心知识点。

    **整体讲解思路：**

    1. 第 (1) 问：通过观察图形结构，利用等边三角形的 60°角和平行线性质，找出相似三角形对
    2. 第 (2) 问：利用 C 为中点的特殊条件，结合中位线定理和相似比计算线段长度和比例
    3. 第 (3) 问：分析动点 P 的轨迹特征，确定轨迹为线段，计算路径长度

    **图示规划说明：**

    - Scene 1：主几何结构图，整合等边三角形构造、中点定义、相似三角形高亮识别
    - Scene 2：中点特殊情况，展示 CP 长度和 AG:GH:HF 比例关系
    - Scene 3：动点 P 的轨迹，展示 C 从 M 到 N 运动时 P 的路径

    **引导步骤：**

    1. 强调 C 为 AB 中点时，AC=CB=4，两个等边三角形边长相等
    2. 观察 DE 与 AB 的位置关系：DE∥AB（因为∠CDE=∠CAB=60°）
    3. 推导 CP 长度：
       - 等边三角形高为 (√3/2)×边长 = 2√3
       - P 为 DE 中点，CP 为两等边三角形顶点连线的一半
       - CP = 2√3
    4. 推导 AG:GH:HF：
       - 利用相似三角形和截线定理
       - 通过坐标法或向量法计算得 AG:GH:HF = 2:1:1

    **关键公式：**

    等边三角形高公式：h = (√3/2) × 边长

    当 C 为中点时：CP = 2√3，AG:GH:HF = 2:1:1

    **教学说明：**

    本图示用于讲解第 (3) 问——动点 P 的轨迹长度计算。

    **引导步骤：**

    1. 明确 M、N 位置：AM=BN=2，故 MN = AB - AM - BN = 8 - 2 - 2 = 4
    2. 分析 P 点运动特征：
       - P 是 DE 的中点
       - 当 C 移动时，D、E 分别绕 A、B 旋转，但 D、E 始终在过 A、B 的 60°射线上
       - DE 中点 P 的轨迹是一条平行于 AB 的线段
    3. 关键洞察：P 点轨迹长度等于 C 点移动距离
       - 因为 P 的水平位移与 C 的水平位移相等
       - C 从 M 到 N 移动距离为 4
       - 故 P 的轨迹长度 = 4

    **关键公式：**

    轨迹长度 = MN = AB - AM - BN = 8 - 2 - 2 = 4
