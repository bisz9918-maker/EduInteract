[图示主题与整合说明]
- 本图示主题：动点 P 的轨迹分析
- 整合内容：点 C 从 M 到 N 运动时 P 点的轨迹路径、轨迹长度计算
- 教学价值：教师可通过滑块拖动直观展示动点 C 在 MN 上运动时，P 点（DE 中点）的轨迹形成过程。学生能观察到 P 点轨迹是一条平行于 AB 的线段，理解轨迹长度的几何意义。滑块交互让抽象的"动点轨迹"概念可视化，便于课堂讲解第(3)问的路径长计算。

[分步序列]
本场景为连续拖拽滑块交互，无分步导航，定义以下状态：

- 初始状态（滑块在最左端）：
  - C 点在 M 位置 (250,400)，对应 AC=2
  - D 点坐标：A(100,400)，C(250,400)，等边三角形 ACD，D 在 AC 中垂线上方
    D = ((100+250)/2, 400 - 150×√3/2) = (175, 400-130) = (175, 270)
  - E 点坐标：B(700,400)，C(250,400)，等边三角形 BCE，E 在 BC 中垂线上方
    BC=450px=6 单位，E = ((700+250)/2, 400 - 450×√3/2) = (475, 400-390) = (475, 10)
  - P 为 DE 中点：P = ((175+475)/2, (270+10)/2) = (325, 140)
  - 轨迹线部分显示：从起点到当前 P 点水平投影位置
  - 显示标签：A、B、M、N、C、P、AM=2、BN=2、MN=4

- 拖动过程（滑块从 250 移动到 550）：
  - C 点 x 坐标 = 滑块位置，y=400
  - 实时计算 D、E 坐标（等边三角形顶点公式）
  - 实时计算 P 为 DE 中点
  - 轨迹线从起点 (250,250) 延伸到当前 P 的 x 坐标位置
  - C、P 标签跟随移动

- 终点状态（滑块在最右端）：
  - C 点在 N 位置 (550,400)，对应 AC=6
  - D 点：A(100,400)，C(550,400)，D = (325, 400-450×√3/2) = (325, 10)
  - E 点：B(700,400)，C(550,400)，E = (625, 400-150×√3/2) = (625, 270)
  - P 为 DE 中点：P = ((325+625)/2, (10+270)/2) = (475, 140)
  - 轨迹线完整显示：(250,250)-(550,250)，长度 300px=4 单位
  - 显示"轨迹长度=4"标注

[标签冲突检查]
所有标签坐标及间距检查：

固定标签：
- 标签"A"：(95, 420)
- 标签"B"：(705, 420)
- 标签"M"：(245, 420)
- 标签"N"：(555, 420)
- 标注"AM=2"：(175, 385)
- 标注"BN=2"：(625, 385)
- 标注"MN=4"：(400, 385)
- 标注"轨迹长度=4"：(400, 235)

动态标签（初始状态 C 在 M）：
- 标签"C"：(250, 420) — 与 M 标签 (245,420) 间距 5px，需调整
  → 解决方案：C 标签初始偏移至 (250, 435)，向下再移 15px 避免与 M 重叠
- 标签"P"：(325, 120) — P 点上方 20px

动态标签（终点状态 C 在 N）：
- 标签"C"：(550, 435) — 与 N 标签 (555,420) 间距 15px，垂直错开 15px，安全
- 标签"P"：(475, 120) — P 点上方 20px

冲突检查结果：
- "M"(245,420) 与 "AM=2"(175,385)：水平距离 70px，垂直 35px → 无冲突
- "N"(555,420) 与 "BN=2"(625,385)：水平距离 70px，垂直 35px → 无冲突
- "MN=4"(400,385) 与 轨迹线 y=250：垂直距离 135px → 无冲突
- "轨迹长度=4"(400,235) 与 轨迹线 y=250：垂直距离 15px → 安全
- 所有 AB 下方标签 y=420~435，与 AB 线段 y=400 间距 20px → 安全

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：
  - 滑块轨道：位于 SVG 内底部 y=470，从 x=100 到 x=700，对应 C 点从 M 到 N 的运动范围
  - 滑块手柄：圆形按钮，可左右拖动，位置映射 C 点 x 坐标
  - 滑块范围：250~550（对应 M 到 N）
- 教师操作流程：
  1. 初始状态：图示加载后 C 在 M 点，P 在轨迹起点，教师讲解题目条件 AM=2、BN=2、MN=4
  2. 拖动滑块：教师缓慢向右拖动滑块，学生观察 C 点移动时，两个等边三角形形状变化，P 点沿水平轨迹移动
  3. 轨迹绘制：随着滑块拖动，红色轨迹线从起点逐渐延伸到当前 P 点位置
  4. 到达终点：滑块拖到最右端，C 在 N 点，完整轨迹线显示，教师讲解轨迹长度=MN=4
  5. 可来回拖动：教师可左右拖动滑块反复演示，强化"轨迹是线段"的概念

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单，无需复杂库；SVG 便于动态更新坐标；原生 JS 足够处理滑块事件和坐标计算
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |                    P 轨迹线 (y=250)              |
  |                    轨迹长度=4                     |
  |         D                          E             |
  |          \                        /              |
  |           \                      /               |
  |            \                    /                |
  |             \                  /                 |
  |              \                /                  |
  |               \              /                   |
  |                \            /                    |
  |                 \          /                     |
  |                  \        /                      |
  |                   \      /                       |
  |                    \    /                        |
  |                     \  /                         |
  |                      \/                          |
  |   A----M----C--------N--------B   (y=400)        |
  |   AM=2      MN=4          BN=2                   |
  |                                                  |
  |  [滑块轨道 ========================]  (y=470)    |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 坐标计算函数：
     - 等边三角形顶点：给定底边两端点 (x1,y)、(x2,y)，顶点坐标为 ((x1+x2)/2, y - |x2-x1|×√3/2)
     - P 点：DE 中点坐标 ((Dx+Ex)/2, (Dy+Ey)/2)
  2. 滑块事件绑定：
     - mousedown/touchstart：开始拖动
     - mousemove/touchmove：更新滑块位置，限制在 250~550 范围
     - mouseup/touchend：结束拖动
  3. 实时更新：
     - 滑块位置 → C 点 x 坐标
     - C 点 → D、E 坐标（等边三角形公式）
     - D、E → P 坐标（中点公式）
     - P 点 y 坐标恒为 250（轨迹是水平线）
     - 轨迹线从 (250,250) 延伸到 (Px, 250)
  4. 状态机：无需复杂状态机，单一状态由滑块位置参数 t∈[0,1] 控制
- ID 命名规范：
  - 所有元素 ID 以 "scene3-" 为前缀
  - 例如：scene3-ab-line, scene3-m-point, scene3-n-point, scene3-c-point, scene3-d-point, scene3-e-point, scene3-p-point, scene3-de-line, scene3-tri-acd, scene3-tri-bce, scene3-trajectory-line, scene3-slider-track, scene3-slider-handle, scene3-label-a, scene3-label-b, scene3-label-m, scene3-label-n, scene3-label-c, scene3-label-p, scene3-anno-am2, scene3-anno-bn2, scene3-anno-mn4, scene3-anno-traj-len
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
