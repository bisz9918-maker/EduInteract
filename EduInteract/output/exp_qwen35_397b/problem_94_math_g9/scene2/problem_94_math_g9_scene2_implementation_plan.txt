[图示主题与整合说明]
- 本图示主题：四个选项的折叠验证对比
- 整合的内容：选项 A/B/C/D 的图形展示、折叠动画、正确/错误标识
- 教学价值：教师可点击不同选项卡，让学生观察每个选项的折叠过程，直观理解为什么只有选项 A 能正确折叠成三棱柱，其他选项为何失败。通过对比分析，帮助学生掌握三棱柱展开图的特征。

[视觉元素清单]

  - 三角形：填充 #fff3e0（浅橙，透明度 30%），轮廓 #000000 实线

- 选项卡按钮：
  - 默认状态：白色背景，黑色文字

[分步序列]
本场景采用多状态切换模式，四个状态对应四个选项：

状态 0（初始/选项 A）：
- 平面图形区：显示选项 A 的展开图（三矩形 + 上下各一三角形）
- 折叠结果区：显示成功折叠的三棱柱 3D 图
- 标识：绿色✓ + "正确"文字
- 选项卡 A 高亮

状态 1（选项 B）：
- 平面图形区：显示选项 B 的展开图（三矩形 + 上方两三角形）
- 折叠结果区：显示折叠失败动画（两三角形重叠）
- 标识：红色✗ + "错误：两底面重叠"
- 选项卡 B 高亮

状态 2（选项 C）：
- 平面图形区：显示选项 C 的展开图（三矩形 + 左下三角形 + 右上矩形）
- 折叠结果区：显示折叠失败动画（结构无法封闭）
- 标识：红色✗ + "错误：无法形成封闭立体"
- 选项卡 C 高亮

状态 3（选项 D）：
- 平面图形区：显示选项 D 的展开图（仅三矩形，无三角形）
- 折叠结果区：显示折叠失败动画（缺少底面）
- 标识：红色✗ + "错误：缺少底面"
- 选项卡 D 高亮

[交互方案]
- 交互类型：多状态切换（选项卡式）
- 控件说明：
  - 选项卡 A：位置 (120,450)，点击显示选项 A 的折叠验证
  - 选项卡 B：位置 (220,450)，点击显示选项 B 的折叠验证
  - 选项卡 C：位置 (320,450)，点击显示选项 C 的折叠验证
  - 选项卡 D：位置 (420,450)，点击显示选项 D 的折叠验证
- 教师操作流程：
  1. 初始显示选项 A（正确答案），让学生观察正确展开图特征
  2. 点击选项卡 B，展示错误原因（两三角形在同一侧导致重叠）
  3. 点击选项卡 C，展示错误原因（结构无法封闭）
  4. 点击选项卡 D，展示错误原因（缺少底面）
  5. 回到选项卡 A，总结三棱柱展开图的正确特征

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单，无需复杂 3D 库；SVG 可精确控制坐标和动画
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [800 × 500 画布]
  +--------------------------------------------------+
  | [标题：折叠验证]                    [折叠结果区]  |
  |                                                  |
  | [平面图形区]           (3D 三棱柱/错误动画)      |
  | (当前选项的展开图)                               |
  |                                                  |
  |                              [✓/✗ 标识]          |
  |                              [错误说明]          |
  |                                                  |
  | [A] [B] [C] [D]  ← 选项卡按钮栏                  |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量 (0-3) 跟踪当前选中选项
  2. 坐标计算：平面图形区矩形宽度 60px，高度 120px；三角形底边 60px，高 40px
  3. 动画曲线：折叠动画使用 ease-in-out 缓动，持续时间 800ms
  4. 事件绑定：每个选项卡按钮绑定 click 事件，切换状态并更新视图
  5. SVG 分组：平面图形和 3D 结果分别用<g>分组，通过 display 控制显示
- ID 命名规范：
  - 所有元素 ID 以 scene2- 为前缀
  - 示例：scene2-plane-group, scene2-3d-group, scene2-tab-a, scene2-checkmark, scene2-cross
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
- 状态数据：使用对象数组存储四个选项的图形数据和错误信息
