[分步序列]
本场景为连续拖拽交互，无分步导航，状态由滑块位置 x 决定：

- 初始状态（x=5，乙出发 4h）：
  - 显示完整坐标系和两条轨迹线
  - 甲船位置点显示在 (560, 320)，标注"甲船"、"y_甲=100"
  - 乙船位置点显示在 (560, 108)，标注"乙船"、"y_乙=320"
  - 绿色双向箭头连接两点，标注"总距离=420"
  - 滑块手柄停在 x=5 位置，下方标注"乙出发 4h"

- 拖拽状态（x 从 1 到 6 连续变化）：
  - 甲船位置：当 x<4 时，y_甲=400-100x；当 x≥4 时，y_甲=100(x-4)
  - 乙船位置：当 x≥1 时，y_乙=80(x-1)
  - 实时更新两船位置点、垂线、距离箭头和数值标签
  - 总距离 = y_甲 + y_乙（两船在 B 港两侧，距离叠加）

- 关键时间点：
  - x=1：乙刚出发，y_乙=0，y_甲=300
  - x=4：甲到达 B 港，y_甲=0，y_乙=240
  - x=5：乙出发 4h，y_甲=100，y_乙=320，总距离=420
  - x=6：甲到达 C 港，y_甲=200，y_乙=400，总距离=600

[交互方案]
- 交互类型：连续拖拽滑块（x=1 到 x=6）
- 控件说明：
  - 滑块轨道：位于 SVG 底部 y=460-475，宽度 600px（x=100 到 700）
  - 滑块手柄：圆形 r=10px，可左右拖拽，默认位置 x=5（对应画布 x=560）
  - 刻度标记：在 x=1,2,3,4,5,6 位置显示短竖线
- 教师操作流程：
  1. 初始状态默认显示 x=5（乙出发 4h），教师讲解此时两船位置
  2. 拖拽滑块向左（x 减小），观察两船逐渐靠近 B 港的过程
  3. 拖拽滑块向右（x 增大），观察两船远离 B 港、距离增大的过程
  4. 停在 x=5，强调此时总距离=420km，验证选项④错误（题目说 220km）

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（线段、圆点、文字），无需复杂库；原生 SVG 交互性能好，代码简洁
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  y/km                                            |
  |   ^                                              |
  | 400|------------------------------------         |
  |   | \                                  \         |
  | 300|  \                                  \       |
  |   |   \                                  \       |
  | 200|    \                                  \     |
  |   |     \                                  \     |
  | 100|      \                                  \   |
  |   |       \                                  \   |
  |   0+--------+--------+--------+--------+-----> x/h|
  |     0       1        4        5        6          |
  |                                    乙出发 4h      |
  |                                                   |
  |  [滑块轨道 ==========●==========]  x=1~6         |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：单一状态变量 sliderX（1-6），所有元素位置由 sliderX 计算得出
  2. 坐标计算：
     - 甲船 y 坐标：sliderX < 4 ? 400 - 100*sliderX : 100*(sliderX - 4)
     - 乙船 y 坐标：sliderX >= 1 ? 80*(sliderX - 1) : 0
     - 画布 x 坐标：80 + (sliderX / 6) * 640
     - 画布 y 坐标：420 - (y 值 / 400) * 360
  3. 动画曲线：拖拽时实时更新，无需缓动
  4. 事件绑定：mousedown/mousemove/mouseup 实现拖拽，touch 事件支持移动端
  5. 数值显示：动态更新 textContent，保留整数
- ID 命名规范：所有元素 ID 以 scene2- 为前缀
  - scene2-slider-track, scene2-slider-handle, scene2-ship-a-point, scene2-ship-b-point, scene2-distance-arrow, scene2-label-y-a, scene2-label-y-b, scene2-label-total
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
