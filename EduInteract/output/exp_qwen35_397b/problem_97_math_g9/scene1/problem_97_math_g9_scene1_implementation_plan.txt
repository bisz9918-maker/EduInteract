[图示主题与整合说明]
- 本图示主题：二次函数 y = ax² + bx + 1 图像特征分析
- 整合的内容：开口方向判断 a 的符号、对称轴位置判断 b 的符号、与 y 轴交点验证
- 教学价值：教师可逐步引导学生观察抛物线特征，从图像直观提取系数符号信息，配合分步按钮控制讲解节奏，帮助学生建立"形→数"的转化思维

[视觉元素清单]
- 坐标系：x 轴 (100,380)-(700,380)，y 轴 (400,80)-(400,450)，黑色实线 stroke-width=2
- 原点标签"O"：坐标 (385,395)，黑色 14px

- a<0 标注：矩形 (520,110,70,35)，绿色 #2e7d32 填充 opacity=0.2，文字"a < 0"白色
- b<0 标注：矩形 (520,160,70,35)，绿色 #2e7d32 填充 opacity=0.2，文字"b < 0"白色
- 结论框：矩形 (500,220,180,80)，绿色边框，内含"y=ax+b 不经过第三象限"

[分步序列]
- 初始状态（步骤 0）：显示坐标系、抛物线、原点 O、轴标签 x/y、与 y 轴交点及标注"1"
- 步骤 1：点击「下一步」→ 显示开口方向红色箭头，右侧出现"a < 0"绿色标注框
- 步骤 2：点击「下一步」→ 显示对称轴灰色虚线及标签，右侧出现"b < 0"绿色标注框
- 步骤 3：点击「下一步」→ 显示结论框"∵ a<0, b<0 ∴ y=ax+b 不经过第三象限"，高亮答案 C

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 上一步按钮：位于 (280,465)，宽 100px，高 35px，浅灰色背景
  - 下一步按钮：位于 (420,465)，宽 100px，高 35px，蓝色背景
  - 步骤指示器：位于 (390,465)，显示"步骤 X/3"
- 教师操作流程：
  1. 初始展示基础图像，让学生观察抛物线整体形态
  2. 点击「下一步」高亮开口方向，引导学生得出 a<0
  3. 点击「下一步」显示对称轴，引导学生分析对称轴位置与 b 的关系
  4. 点击「下一步」总结结论，完成从图像到系数符号的推理

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                    y                             |
  |                    |                             |
  |         对称轴     |           a<0 标注          |
  |           ||       |           b<0 标注          |
  |    ___---'''''---__|          结论框            |
  |  ''                 |                           |
  | /                   |                           |
  |-+---------O---------+---------- x               |
  |                     |                           |
  |                     |                           |
  |                     |                           |
  |        [上一步] 步骤 [下一步]                    |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-3) 跟踪当前步骤
  2. 各元素初始 display="none"，根据 currentStep 控制显示/隐藏
  3. 抛物线用 SVG path 绘制，通过计算关键点坐标确保开口向下、顶点在第二象限
  4. 按钮点击事件绑定，更新 currentStep 并刷新视图
  5. 边界处理：步骤 0 时禁用「上一步」，步骤 3 时禁用「下一步」
- ID 命名规范：所有元素 ID 以 scene1- 为前缀，如 scene1-xaxis, scene1-yaxis, scene1-parabola, scene1-arrow-open, scene1-symaxis, scene1-label-a, scene1-label-b, scene1-conclusion, scene1-btn-prev, scene1-btn-next, scene1-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
