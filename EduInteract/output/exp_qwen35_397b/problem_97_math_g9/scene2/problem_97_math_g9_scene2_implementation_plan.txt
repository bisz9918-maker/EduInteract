[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 (280,460)，返回上一状态
  - 「下一步」按钮：位于 (420,460)，进入下一状态
  - 步骤指示器：位于 (360,460)，显示"步骤 X/4"
- 教师操作流程：
  1. 初始展示坐标系和已知条件，引导学生回忆 a、b 符号的判断方法
  2. 点击「下一步」展示截距，强调 b<0 意味着直线与 y 轴交于负半轴
  3. 点击「下一步」展示完整直线，说明 a<0 意味着直线从左上到右下倾斜
  4. 点击「下一步」高亮象限，引导学生观察直线经过第二、三、四象限，不经过第一象限

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  | [条件框]                    [结论框]  Ⅰ          |
  |  a<0,b<0                  不经过第一象限         |
  |                                                  |
  |     Ⅱ                    |           Ⅰ          |
  |                          |                       |
  |                          |                       |
  |--------------------------O----------------------x|
  |                          |                       |
  |     Ⅲ                    |           Ⅳ          |
  |                    [截距点]                      |
  |                                                  |
  |              [直线 y=ax+b]                       |
  |                                                  |
  |         [上一步]  步骤 X/4  [下一步]             |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量 (0-3) 跟踪当前步骤
  2. 元素分组：将不同步骤的元素放入不同的<g>组，通过 display 属性控制显示/隐藏
  3. 坐标计算：直线端点根据 a<0、b<0 的条件确定，确保穿过第二、三、四象限
  4. 事件绑定：按钮点击事件切换状态，更新各组元素的 display 属性
  5. 动画效果：直线绘制可使用 stroke-dasharray 动画实现渐变出现效果
- ID 命名规范：所有元素 ID 以 scene2- 为前缀（如 scene2-axis-x、scene2-line、scene2-point-b）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
