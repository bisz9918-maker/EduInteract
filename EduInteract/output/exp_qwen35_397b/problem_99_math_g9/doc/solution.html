题目原文：

如图，D是等边△ABC边AB上的一点，且AD=1，BD=2，现将△ABC折叠，使点C与D重合，折痕EF，点E、F分别在AC和BC上，若BF=1.25，则CE=（ ）

A．7/5 B．2/3 C．5/6 D．1/2

题目分析：

本题是等边三角形折叠问题，核心考点：

  1. 折叠的对称性质：折痕是对应点连线的垂直平分线
  2. 折叠后对应线段相等：CE=DE，CF=DF
  3. 等边三角形性质：三边相等，三角均为60°

整体讲解思路：

  1. 首先明确已知条件：等边△ABC边长为3（AD+BD=1+2=3）
  2. 理解折叠的几何意义：C点沿EF折叠后与D点重合
  3. 利用折叠性质建立等量关系
  4. 通过设未知数CE=x，利用几何关系列方程求解

教学说明：

本图示是本题的核心，教师应重点讲解折叠的对称性质：

折叠的关键性质：

  1. 折叠前后对应线段相等：CE=DE，CF=DF
  2. 折痕EF是对应点连线CD的垂直平分线
  3. 折叠前后图形全等：△CEF≌△DEF

引导学生观察：

  • 折叠后，原来的CE变成了DE
  • 折叠后，原来的CF变成了DF
  • 这些等量关系是解题的关键

核心公式：

  • CE = DE（设CE=x，则DE=x）
  • CF = DF（CF=3-BF=3-1.25=1.75，故DF=1.75）

教学说明：

本图示展示解题的计算过程，教师应引导学生：

解题步骤：

  1. 设CE=x，由折叠性质得DE=x
  1. 在等边△ABC中，AC=3，故AE=AC-CE=3-x
  1. 在△ADE中，已知：
  • AD=1
  • AE=3-x
  • DE=x
  • ∠A=60°
  1. 由余弦定理：

DE² = AD² + AE² - 2·AD·AE·cos60°
x² = 1² + (3-x)² - 2·1·(3-x)·(1/2)

  1. 化简方程：

x² = 1 + 9 - 6x + x² - 3 + x
0 = 7 - 5x
x = 7/5

答案：A．7/5
