[分步序列]
- 步骤0（初始状态）：显示等边△ABC实线边框，顶点标签A、B、C，折痕EF（灰色虚线表示折叠前位置）
- 步骤1：点击「下一步」→ 显示点D及标注"1"（AD）、"2"（BD），D点用实心小圆标记
- 步骤2：点击「下一步」→ 显示点F及标注"1.25"（BF），F点用实心小圆标记
- 步骤3：点击「下一步」→ 显示点E，折叠后△DEF变为蓝色实线，折叠前CE、CF保持灰色虚线
- 步骤4：点击「下一步」→ 在CE左侧显示红色"?"标注，高亮CE线段（加粗或闪烁动画），表示待求量

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 按钮"◀ 上一步"：位于SVG内左下角(20,460)，返回上一状态
  - 按钮"下一步 ▶"：位于SVG内右下角(680,460)，进入下一状态
  - 步骤指示器：位于底部中央(380,460)，显示"步骤 X/4"
- 教师操作流程：
  1. 初始展示基础三角形，讲解题目背景
  2. 点击"下一步"展示D点位置及AD=1、BD=2，讲解点D分割AB的比例
  3. 点击"下一步"展示F点及BF=1.25，讲解已知条件
  4. 点击"下一步"展示折叠效果，讲解折叠性质（CE=DE，CF=DF）
  5. 点击"下一步"高亮待求CE，引导学生思考如何求解

[技术实现]
- JS 库选择：原生SVG（简单几何图形，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +------------------------------------------+
  |              C(425,50)                   |
  |             /   \                        |
  |            /     \                       |
  |           E-------F                      |
  |          / \     / \                     |
  |         /   \   /   \                    |
  |        A-----D-------B                   |
  |        (400)  (425)                      |
  |                                          |
  |  [◀ 上一步]    步骤 1/4    [下一步 ▶]    |
  +------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量currentStep(0-4)跟踪当前步骤，steps数组存储每步显示的元素ID列表
  2. 坐标计算：所有顶点坐标预计算为常量，避免运行时计算
  3. 动画曲线：元素出现使用fade-in（opacity 0→1，300ms ease-out）
  4. 事件绑定：按钮点击事件绑定到stepChange函数，更新currentStep并刷新显示
  5. 边界处理：步骤0时禁用"上一步"，步骤4时禁用"下一步"
- ID 命名规范：所有元素ID以scene1-为前缀
  - scene1-tri-abc（△ABC边框）
  - scene1-line-ef（折痕EF）
  - scene1-line-de、scene1-line-df（折叠后边）
  - scene1-line-ce、scene1-line-cf（折叠前虚线边）
  - scene1-point-a~f（顶点标记圆）
  - scene1-label-a~f（顶点标签）
  - scene1-anno-ad、scene1-anno-bd、scene1-anno-bf（长度标注）
  - scene1-anno-ce-q（待求标注）
  - scene1-btn-prev、scene1-btn-next（导航按钮）
  - scene1-step-indicator（步骤指示器）
- IIFE 隔离：所有JS代码包在(function() { ... })()中，避免全局变量污染
