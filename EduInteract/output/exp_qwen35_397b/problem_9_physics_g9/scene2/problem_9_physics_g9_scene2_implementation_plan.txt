[分步序列]
本场景为连续拖拽交互，无分步导航，状态随滑块实时变化：

- 初始状态（滑块默认值）：
  - 电源电压 U = 3.0V（滑块 1 手柄在中间位置）
  - R₁ = 6.0Ω（滑块 2 手柄在 60% 位置）
  - R₂ = 3.0Ω（滑块 3 手柄在 60% 位置）
  - 计算显示：P₁ = 3²/6 = 1.5W，P₂ = 3²/3 = 3.0W
  - 柱状图：L₁高度 30px（1.5W 比例），L₂高度 60px（3.0W 比例）
  - 结论："L₂更亮"

- 交互状态 1（拖动滑块 1 - 电源电压）：
  - 电压范围 0-6V，实时显示当前电压值
  - 功率公式中的 U 值实时更新
  - P₁、P₂计算结果实时变化
  - 柱状图高度随功率实时缩放
  - 结论文本根据 P₁与 P₂大小关系动态切换

- 交互状态 2（拖动滑块 2 - R₁阻值）：
  - 阻值范围 0-10Ω，实时显示当前阻值
  - P₁ = U²/R₁ 实时计算
  - L₁柱状图高度变化
  - 亮度对比结论可能变化

- 交互状态 3（拖动滑块 3 - R₂阻值）：
  - 阻值范围 0-5Ω，实时显示当前阻值
  - P₂ = U²/R₂ 实时计算
  - L₂柱状图高度变化
  - 亮度对比结论可能变化

[交互方案]
- 交互类型：连续拖拽滑块（3 个独立滑块）
- 控件说明：
  - 滑块 1：电源电压 U，范围 0-6V，步长 0.1V，初始 3.0V
  - 滑块 2：R₁阻值，范围 0-10Ω，步长 0.1Ω，初始 6.0Ω
  - 滑块 3：R₂阻值，范围 0-5Ω，步长 0.1Ω，初始 3.0Ω
- 教师操作流程：
  1. 初始状态展示默认参数下的功率计算和亮度对比
  2. 拖动滑块 1 改变电压，观察 P₁、P₂同时变化（平方关系）
  3. 拖动滑块 2 改变 R₁，观察 P₁变化（反比关系），L₁亮度变化
  4. 拖动滑块 3 改变 R₂，观察 P₂变化（反比关系），L₂亮度变化
  5. 引导学生发现：电压相同时，电阻越小功率越大，灯泡越亮

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无需额外库，滑块和柱状图用 SVG 实现足够）
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [800×500 画布]
  ┌─────────────────────────────────────────────────────────────┐
  │ [滑块 1:电压]    [滑块 2:R₁]    [滑块 3:R₂]                 │ y=20-60
  ├─────────────────────────────────────────────────────────────┤
  │  ┌─────────────────────────────────────────────────────┐    │
  │  │ P₁ = U²/R₁ = ___W    P₂ = U²/R₂ = ___W              │    │ y=140-220
  │  └─────────────────────────────────────────────────────┘    │
  │                                                             │
  │     [电路图区：电源、L₁、L₂、S₁、S₂、导线]                    │ y=100-280
  │                                                             │
  │  ┌─────────────────────────────────────────────────────┐    │
  │  │  亮度对比                                            │    │
  │  │  ││        ││                                       │    │
  │  │  ││ L₁     ││ L₂              [L₂更亮]              │    │ y=260-420
  │  │  ││        ││                                       │    │
  │  │  └────────┴────────┘                                 │    │
  │  │    0    3W    6W                                     │    │
  │  └─────────────────────────────────────────────────────┘    │
  ├─────────────────────────────────────────────────────────────┤
  │ [控件栏预留区域 y=440-490]                                   │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：单一状态对象存储{voltage, r1, r2}，任何滑块变化触发重新计算
  2. 功率计算：P1 = voltage² / r1，P2 = voltage² / r2（避免除零，r1/r2最小 0.1Ω）
  3. 柱状图高度：height = (power / 6) × 120px（最大 6W 对应 120px）
  4. 结论判断：if (p1 > p2) "L₁更亮" else if (p2 > p1) "L₂更亮" else "一样亮"
  5. 滑块手柄拖拽：mousedown/mousemove/mouseup 事件，限制在轨道范围内
  6. 数值实时更新：滑块拖动时同步更新数值显示、公式结果、柱状图高度、结论文本
- ID 命名规范：
  - 滑块 1：scene2-slider-voltage, scene2-slider-voltage-handle, scene2-voltage-value
  - 滑块 2：scene2-slider-r1, scene2-slider-r1-handle, scene2-r1-value
  - 滑块 3：scene2-slider-r2, scene2-slider-r2-handle, scene2-r2-value
  - 公式：scene2-formula-p1, scene2-formula-p2, scene2-result-p1, scene2-result-p2
  - 柱状图：scene2-bar-l1, scene2-bar-l2, scene2-bar-label-l1, scene2-bar-label-l2
  - 结论：scene2-conclusion
  - 电路图：scene2-circuit-group, scene2-lamp-l1, scene2-lamp-l2, scene2-switch-s1, scene2-switch-s2
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
