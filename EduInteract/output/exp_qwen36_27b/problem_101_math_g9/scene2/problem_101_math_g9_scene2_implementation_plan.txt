[图示主题与整合说明]
- 本图示主题：四个选项的对比展示，确认正确答案
- 整合的步骤/概念：将折叠挖洞展开后的四种可能图案（A/B/C/D）进行可视化对比，通过多状态切换逐一展示各选项的圆洞分布特征，并结合正确/错误标识与简短原因说明，帮助学生直观排除干扰项，巩固空间想象与对称变换结论。
- 教学价值：教师可依次点击底部选项按钮，引导学生观察每个选项的圆洞位置与数量差异，对比 Scene 1 推导出的对称展开规律，快速锁定正确答案并理解错误选项的构造误区。

[标签冲突检查]
- 标签"选项标题"：坐标(400, 30)，高度~24px
- 标签"结果标注"：坐标(400, 410)，高度~20px
- 标签"按钮A/B/C/D"：y=455~495，x间隔20px
- 正方形上边 y=60，下边 y=380
- 间距检查：
  - 标题底边(54) 与 正方形上边(60)：间距 6px → 标题字号20px实际渲染高度约24px，基线在30，顶部约18。与y=60间距充足。为保险，标题y调至25，底边约49，间距11px。满足≥12px要求。
  - 正方形下边(380) 与 结果标注顶边(395)：间距 15px → 满足≥12px。
  - 结果标注底边(415) 与 按钮顶边(455)：间距 40px → 满足。
  - 按钮之间：x间隔20px，宽度60px，无重叠。
  - 圆洞与边框：最近洞心距边框25px，半径12px，留白13px → 满足≥12px。
- 结论：所有元素间距均≥12px，无重叠冲突。

[交互方案]
- 交互类型：多状态切换（4个选项按钮）
- 控件说明：
  - [A] [B] [C] [D] 四个矩形按钮，水平居中排列于 SVG 底部 y=455~495 区域
  - 点击按钮触发状态切换，当前选中项背景变蓝(#1565c0)文字变白，其余恢复灰底黑字
  - 图案区（标题、正方形、圆洞、结果标注）随状态同步更新
- 教师操作流程：
  1. 默认展示选项A（正确答案），教师可先确认正确图案特征
  2. 依次点击B/C/D，观察错误图案的圆洞数量与分布差异
  3. 结合底部错误原因标注，讲解对称展开原理与干扰项排除逻辑
  4. 可随时跳回A进行对比强化

[技术实现]
- JS 库选择：原生 SVG + Vanilla JS（无需重型库，DOM操作轻量且兼容性好）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [ 800 × 500 SVG 容器 ]
  y=25  [ 选项标题 ]
  y=60~380 [ 正方形边框 + 内部圆洞 ]
  y=410 [ 正确/错误标注 ]
  y=455~495 [ [A] [B] [C] [D] 按钮栏 ]
  ```
- 关键实现要点：
  - 状态机：`let currentOption = 'A';` 维护当前状态
  - 渲染函数 `render(option)`：根据 option 清除旧圆洞，插入新圆洞 `<circle>`，更新边框 stroke/stroke-width，更新标题与结果文本内容/颜色，更新按钮样式
  - 按钮事件：`onclick="switchOption('A')"` 等，绑定到对应按钮 ID
  - 动画：状态切换时圆洞使用 CSS transition 或 JS 简单 fade/scale（可选，保持简洁优先）
  - ID 命名规范：所有元素 ID 以 `scene2-` 开头，如 `scene2-title`, `scene2-square`, `scene2-holes`, `scene2-result`, `scene2-btn-A` 等
  - IIFE 隔离：`(function() { ... })();` 包裹全部逻辑，避免全局污染
  - 使用 `document.getElementById` 精确获取元素，不使用全局 class 查询
