[图示主题与整合说明]
- 本图示主题：正方形与菱形重叠关系及阴影面积的分步计算
- 整合的步骤/概念：正方形边长推导 → 菱形高的计算 → 勾股定理求水平偏移 → 重叠梯形面积 → 阴影面积结论
- 教学价值：教师通过分步按钮导航，逐步展示从已知条件到最终答案的完整推导过程。每一步都有明确的视觉变化（高亮、标注出现），帮助学生理解每个推导环节的逻辑关系。教师可随时回退复习任意步骤。

JS 库选择：原生SVG（无需外部库）
- 原因：本题为简单几何图形（正方形、菱形、辅助线），原生SVG完全满足需求，无需引入D3.js等重型库
- 所有元素用SVG原生标签（<rect>, <line>, <polygon>, <text>, <circle>, <path>）实现

画布尺寸：800 × 500 px（固定）

关键实现要点：

1. 状态机设计：
   - 使用全局变量 `currentStep`（0~5）跟踪当前步骤
   - 每个步骤对应一个渲染函数 `renderStep(step)`，根据step值决定显示哪些元素
   - 元素通过CSS class控制显隐（.step-0, .step-1, ...）或直接操作SVG元素的display属性

2. SVG元素组织：
   - 使用<defs>定义可复用的样式
   - 基础图形（正方形、菱形）始终显示
   - 步骤专属元素放在独立的<g>组中，通过group的display属性控制
   - 阴影区域用<polygon>实现，通过修改fill和opacity实现颜色切换

3. 坐标计算：
   - 所有坐标已预先计算好，硬编码在JS中
   - 单位换算：1数学单位 = 30px
   - 正方形：B(280,340), C(430,340), A(280,190), D(430,190)
   - 菱形：P(370,220), Q(520,220), C(430,340), B(280,340)
   - 交点E(430,220), 垂足F(370,340)

4. 动画曲线：
   - 元素出现使用CSS transition（opacity: 0→1，duration: 0.3s）
   - 高亮效果使用stroke-width变化（2px→3px）
   - 颜色切换使用fill/opacity渐变

5. 事件绑定：
   - 按钮点击事件：`document.getElementById('scene1-next-btn').addEventListener('click', ...)`
   - 键盘支持：←→方向键控制上一步/下一步

6. ID命名规范：
   - 所有交互元素ID以 `scene1-` 为前缀
   - 示例：`scene1-next-btn`, `scene1-prev-btn`, `scene1-step-indicator`, `scene1-shade-area`, `scene1-trapezoid-highlight`
   - JS中使用 `document.getElementById()` 而非 `querySelectorAll`

7. IIFE隔离：
   - 所有JS代码包裹在 `(function() { 'use strict'; ... })();` 中
   - 避免全局变量污染，多场景合并时互不干扰

8. 阴影区域多边形顶点（按顺时针）：
   - A(280,190) → B(280,340) → P(370,220) → E(430,220) → D(430,190) → 闭合

9. 梯形BPEC多边形顶点（按顺时针）：
   - B(280,340) → P(370,220) → E(430,220) → C(430,340) → 闭合
