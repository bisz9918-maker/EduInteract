    **题目原文：**

    如图，已知⊙O是等腰Rt△ABC的外接圆，点D是$\stackrel\frown{AC}$上一点，BD交AC于点E，若BC=4，AD=$\frac{4}{5}$，则AE的长是（  ）

    A．3    B．2    C．1    D．1.2

    **题目分析：**

    本题是一道圆与等腰直角三角形综合的几何题，核心考点包括：
    - 直径所对圆周角为直角
    - 同弧所对圆周角相等
    - 相似三角形的判定与性质
    - 勾股定理

    **整体讲解思路：**

    1. 首先引导学生从题目条件出发，明确△ABC是等腰直角三角形，AB为外接圆直径，AC = BC = 4
    2. 利用"直径所对圆周角为直角"发现∠ADB = 90°，在Rt△ADB中用勾股定理求出BD = 28/5
    3. 利用"同弧所对圆周角相等"和对顶角相等，证明△ADE ~ △BCE
    4. 由相似比建立方程组，解得AE = 1

    **图示规划说明：**

    本题所有推导均围绕同一幅几何图形展开，因此规划为**一个交互式图示**，采用分步按钮导航，从展示基础图形逐步推进到得出结论，帮助学生在同一视觉框架下理解完整的推理链条。

    **本图示教学说明：**

    **步骤0→步骤1：引导学生读图，明确已知条件**

    教师操作：展示初始图形后，点击"下一步"添加已知条件标注。

    引导要点：
    - 让学生观察图形，找出题目中提到的所有点和线段
    - 强调△ABC是**等腰直角三角形**，因此AC = BC = 4
    - 指出AB是外接圆的**直径**，O为圆心（AB中点）
    - 明确待求量：AE的长度

    **步骤1→步骤2：发现关键性质——直径所对圆周角为直角**

    教师操作：点击"下一步"，展示∠ADB = 90°。

    引导要点：
    - 提问："AB是直径，那么圆上任意一点与A、B形成的角是多少度？"
    - 引导学生回忆**直径所对圆周角为直角**这一重要定理
    - 因此∠ADB = 90°，△ADB是直角三角形
    - 这是解题的关键突破口

    **步骤2→步骤3：勾股定理求BD**

    教师操作：点击"下一步"，展示BD的计算过程。

    推导过程：
    1. 在Rt△ABC中，AC = BC = 4，由勾股定理得 AB = $\sqrt{4^2 + 4^2} = 4\sqrt{2}$
    2. 在Rt△ADB中，AD = $\frac{4}{5}$，AB = $4\sqrt{2}$
    3. 由勾股定理：$BD^2 = AB^2 - AD^2 = 32 - \frac{16}{25} = \frac{784}{25}$
    4. 所以 $BD = \frac{28}{5}$

    **步骤3→步骤4：证明△ADE ~ △BCE**

    教师操作：点击"下一步"，高亮两个相似三角形。

    引导要点：
    - 观察△ADE和△BCE，寻找对应角相等的关系
    - ∠DAE = ∠CBE（同弧DC所对的圆周角相等）
    - ∠AED = ∠BEC（对顶角相等）
    - 由AA相似判定：△ADE ~ △BCE
    - 让学生理解：圆中的相似三角形往往通过"同弧所对圆周角相等"来发现

    **步骤4→步骤5：利用相似比求解AE**

    教师操作：点击"下一步"，展示完整求解过程。

    推导过程：
    1. 由△ADE ~ △BCE得：$\frac{AD}{BC} = \frac{AE}{BE} = \frac{DE}{CE}$
    2. 代入已知：$\frac{4/5}{4} = \frac{1}{5}$，即相似比为 $\frac{1}{5}$
    3. 所以 $BE = 5AE$，$CE = 5DE$
    4. 由 $AE + CE = AC = 4$，得 $AE + 5DE = 4$
    5. 由 $BE + DE = BD = \frac{28}{5}$，得 $5AE + DE = \frac{28}{5}$
    6. 由(4)得 $DE = \frac{4 - AE}{5}$，代入(5)：$5AE + \frac{4 - AE}{5} = \frac{28}{5}$
    7. 化简：$25AE + 4 - AE = 28$，即 $24AE = 24$
    8. 解得 **AE = 1**，答案为 **C**

    **课堂讲解建议：**

    - 本题的核心思路是"发现直角→勾股定理→相似三角形→比例方程"，教师应重点引导学生发现∠ADB = 90°这一关键
    - 相似三角形的发现是本题难点，建议让学生先观察图形，尝试找出相等的角
    - 最后的比例方程求解涉及代数运算，可在黑板上详细展开
    - 可追问学生：如果AD取其他值，AE会如何变化？引导学生思考一般规律
