    **题目原文：**

    如图，AB为半圆的直径，且AB=4，半圆绕点B顺时针旋转45°，点A旋转到A′的位置，则图中阴影部分的面积为（）
    A.π   
    B.2π      
    C.3π
    D.4π

    **题目分析：**

    本题是一道几何旋转面积问题，核心考点是理解"旋转扫过的面积"与"扇形面积"的关系。

    已知条件：
    - AB 为半圆直径，AB = 4
    - 半圆绕点 B 顺时针旋转 45°
    - A 旋转到 A'

    关键思路：阴影部分的面积等于扇形 ABA' 的面积。这是因为旋转前后两个半圆面积相等，阴影部分 = 旋转后半圆面积 - 两半圆重叠部分 = 原半圆面积 - 两半圆重叠部分 = 扇形 ABA' 的面积。

    扇形 ABA' 的半径为 AB = 4，圆心角为 45°，面积为 (45/360) × π × 4² = 2π。

    **整体讲解思路：**

    1. 首先让学生观察图形，理解旋转过程
    2. 引导学生发现阴影面积与扇形面积的关系
    3. 通过面积等式推导得出结论
    4. 计算扇形面积得到答案

    **图示规划说明：**

    本题规划为两个图示：
    - SCENE_1：旋转过程演示，帮助学生直观理解半圆绕 B 点旋转 45° 的过程，以及阴影区域的形成
    - SCENE_2：面积关系推导，通过颜色填充和面积标注，展示阴影面积 = 扇形 ABA' 面积的推导过程

    **教学说明（SCENE_2）：**

    本图示用于展示面积推导的完整逻辑链条，帮助学生理解为什么阴影面积等于扇形面积。

    讲解要点：

    1. **步骤 0**：建立面积关系的基础。
       - 设原半圆面积为 S₁，旋转后半圆面积为 S₂
       - 强调：S₁ = S₂（旋转不改变图形面积）
       - 两个半圆的半径都是 AB/2 = 2，所以 S₁ = S₂ = (1/2) × π × 2² = 2π

    2. **步骤 1**：写出阴影面积的表达式。
       - 阴影面积 = S₂ - 重叠部分

    3. **步骤 2**：等量代换。
       - 因为 S₁ = S₂，所以：阴影面积 = S₁ - 重叠部分
       - 引导学生观察：S₁ - 重叠部分 = 原半圆中"少掉"的部分
       - 这部分恰好等于扇形 ABA' 的面积

    4. **步骤 3**：建立与扇形的联系。
       - 阴影面积 = 扇形 ABA' 的面积
       - 用相同颜色填充阴影区域和扇形区域，强调面积相等

    5. **步骤 4**：代入公式计算。
       - 扇形面积公式：S = (n/360) × πr²
       - 其中 n = 45°（圆心角），r = AB = 4（半径）
       - S = (45/360) × π × 4² = (1/8) × π × 16 = 2π

    6. **步骤 5**：得出答案。
       - 阴影面积 = 2π
       - 正确选项：B

    **关键公式：**

    扇形面积公式：S = (n/360) × πr²

    其中 n 为圆心角度数，r 为半径。

    **课堂讲解建议：**

    - 在步骤 2 到步骤 3 的过渡处，可以停顿让学生思考：为什么 S₁ - 重叠部分 = 扇形 ABA' 的面积？
    - 可以引导学生用"割补法"理解：把阴影部分"补"到原半圆中"少掉"的位置，恰好填满扇形 ABA'
    - 强调本题的解题技巧：遇到旋转面积问题，优先考虑"旋转扫过的扇形面积"
