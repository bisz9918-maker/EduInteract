[图示主题与整合说明]
- 本图示主题：阴影面积 = 扇形 ABA' 面积的推导与计算
- 整合的步骤/概念：面积关系等式推导 → 扇形面积公式 → 代入计算 → 得出答案
- 教学价值：教师通过分步按钮逐步展示"旋转不改变面积"→"阴影面积 = 重叠部分抵消"→"阴影面积 = 扇形面积"→"代入公式计算"的完整逻辑链条，帮助学生理解这道经典几何题的核心思路——利用旋转不变性将不规则阴影面积转化为规则扇形面积

[分步序列]

初始状态（步骤 0）— 面积关系建立：
- 显示直径 AB（黑色实线）
- 显示点 A(315,225)、B(465,225)、A'(359,119)（黑色圆点 r=4）
- 显示原半圆 S₁（#e3f2fd 填充 30%，黑色轮廓 2px）
- 显示旋转后半圆 S₂（#fff3e0 填充 30%，黑色轮廓 2px）— 两个半圆颜色叠加处自然显示重叠
- 标注：A、B、A'、AB=4
- 公式文本框显示："S₁ = S₂（旋转不改变面积）"
- 步骤指示器："步骤 0 / 5"

步骤 1 — 阴影面积表达式：
- 视觉变化：S₂ 的非重叠部分（阴影区域）填充为 #9e9e9e opacity=0.8，重叠部分恢复为 S₁ 的浅蓝色
- 新增标注：在阴影区域内标注"阴影"
- 公式文本框显示："阴影面积 = S₂ − 重叠部分"
- 步骤指示器："步骤 1 / 5"

步骤 2 — 等量代换：
- 视觉变化：S₁ 中不与 S₂ 重叠的部分（原半圆"少掉"的部分）用 #fff3e0 高亮填充 opacity=0.5
- 公式文本框显示："∵ S₁ = S₂，∴ 阴影面积 = S₁ − 重叠部分"
- 步骤指示器："步骤 2 / 5"

步骤 3 — 扇形面积关联：
- 视觉变化：显示扇形 ABA'（#2e7d32 填充 20%，#2e7d32 轮廓 2px），扇形弧从 A 到 A'
- 阴影区域与扇形区域用相同绿色强调面积相等
- 公式文本框显示："阴影面积 = 扇形 ABA' 的面积"
- 步骤指示器："步骤 3 / 5"

步骤 4 — 公式计算：
- 视觉变化：扇形 ABA' 填充加深为 #2e7d32 opacity=0.35
- 公式文本框显示：
  "S = (n/360) × πr²"
  "n = 45°，r = AB = 4"
  "S = (45/360) × π × 4² = 2π"
- 步骤指示器："步骤 4 / 5"

步骤 5 — 最终答案：
- 视觉变化：扇形 ABA' 填充加深为 #2e7d32 opacity=0.5
- 公式文本框显示：
  "S = 2π"（#c62828 红色 20px 加粗）
  "正确答案：B"（#c62828 红色 18px 加粗）
- 步骤指示器："步骤 5 / 5"

[技术实现]
- JS 库选择：原生 SVG（简单几何图形首选，无需额外库）
  - 原因：本题仅需绘制半圆、扇形、线段、圆点等基本几何元素，原生 SVG 完全满足需求，无需引入 D3.js 或 Canvas
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  ┌──────────────────────────────────────────────────────┐ y=0
  │                                                      │
  │              A' ●                                    │ y=100
  │              /|                                       │
  │             / |  扇形ABA' (步骤3+)                    │
  │            /  |                                       │
  │    S₂(橙) /   |                                       │ y=150
  │          /____|                                       │
  │         /  S₁(蓝) \                                   │
  │        /          \                                   │ y=200
  │       /            \                                  │
  │  ●───A──────────────B───●                             │ y=225
  │      AB=4           │                                 │
  │                     │ 阴影区域(灰)                     │ y=250
  │                     │                                  │
  │                     │                                  │ y=300
  │                     │                                  │
  │                     │                                  │ y=350
  │  ┌─────────────────────────────────────┐              │
  │  │  公式文本框 (推导公式/计算过程)       │              │ y=370
  │  │                                     │              │
  │  └─────────────────────────────────────┘              │ y=425
  │                                                      │
  │     [◀ 上一步]    步骤 0/5    [下一步 ▶]              │ y=455
  │                                                      │ y=490
  └──────────────────────────────────────────────────────┘ y=500
  ```
- 关键实现要点：
  1. **状态机设计**：用变量 `currentStep` (0~5) 管理当前步骤，每个步骤对应一组视觉状态
  2. **SVG 元素管理**：
     - 原半圆：`<path d="M 315,225 A 75,75 0 0,1 465,225" />`
     - 旋转后半圆：`<path d="M 315,225 A 75,75 0 0,1 465,225" transform="rotate(-45, 465, 225)" />`
     - 扇形 ABA'：`<path d="M 315,225 A 150,150 0 0,0 359,119 L 465,225 Z" />`
     - 阴影区域：用 `<mask>` 实现 S₂ 减去 S₁ 重叠部分
  3. **阴影区域绘制（mask 方案）**：
     ```xml
     <defs>
       <mask id="scene2-shadow-mask">
         <!-- 白色=显示：旋转后半圆 -->
         <path d="M 315,225 A 75,75 0 0,1 465,225" transform="rotate(-45,465,225)" fill="white"/>
         <!-- 黑色=隐藏：原半圆 -->
         <path d="M 315,225 A 75,75 0 0,1 465,225" fill="black"/>
       </mask>
     </defs>
     <path d="M 315,225 A 75,75 0 0,1 465,225" transform="rotate(-45,465,225)"
           fill="#9e9e9e" opacity="0.8" mask="url(#scene2-shadow-mask)" id="scene2-shadow"/>
     ```
  4. **步骤切换逻辑**：
     - `nextStep()`: currentStep++，更新各元素可见性/颜色/公式文本
     - `prevStep()`: currentStep--，同上
     - 每个步骤的视觉变化通过修改 SVG 元素的 `fill`、`opacity`、`display` 属性实现
  5. **公式文本更新**：用 `innerHTML` 更新公式文本框内容，支持多行显示（`<br>` 换行）
  6. **按钮状态管理**：步骤0时「上一步」禁用（`opacity=0.4, pointer-events=none`），步骤5时「下一步」禁用
  7. **动画过渡**：元素颜色/透明度变化用 CSS `transition: all 0.4s ease` 实现平滑过渡
- ID 命名规范：所有交互元素 ID 以 `scene2-` 为前缀
  - `scene2-semi1`（原半圆）
  - `scene2-semi2`（旋转后半圆）
  - `scene2-shadow`（阴影区域）
  - `scene2-sector`（扇形 ABA'）
  - `scene2-formula-box`（公式文本框）
  - `scene2-formula-text`（公式文本）
  - `scene2-step-indicator`（步骤指示器）
  - `scene2-btn-prev`（上一步按钮）
  - `scene2-btn-next`（下一步按钮）
  - `scene2-highlight-s1`（S₁ 非重叠部分高亮，步骤2）
- IIFE 隔离：所有 JS 代码包在 `(function() { ... })()` 中，避免全局污染
- 事件绑定：用 `document.getElementById('scene2-btn-next').addEventListener('click', ...)` 而非 querySelectorAll
