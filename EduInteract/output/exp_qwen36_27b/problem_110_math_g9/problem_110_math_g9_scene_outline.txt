    **题目原文：**

    如图，∠3=30°，为了使白球反弹后能将黑球直接撞入袋中，那么击打白球时，必须保证∠1的度数为（）
    A.30°
    B.60°
    C.90°
    D.45°

    **题目分析：**

    本题以台球反弹为背景，考查两个核心几何知识点：
    1. **反射定律**：入射角等于反射角，即∠1 = ∠2
    2. **互余角关系**：台球桌为矩形，相邻两边互相垂直，因此∠2 + ∠3 = 90°

    解题逻辑链：∠3 = 30° → ∠2 = 90° - 30° = 60° → ∠1 = ∠2 = 60° → 答案选B

    **整体讲解思路：**

    通过一个交互式图示，分步引导学生从直观观察走向抽象推理：先认识台球桌的几何结构，再理解反射定律，最后利用互余关系求出答案。

    **图示规划：**

    规划1个交互式场景，整合台球桌几何结构、反射定律和角度计算三个层次，采用分步按钮导航方式，逐步揭示解题关键。

    **本图示教学说明：**

    **步骤0→步骤1：建立直观感知**

    教师引导学生观察台球桌的几何结构——这是一个矩形，四个角是直角。让学生注意白球和黑球的位置，以及右下角的袋口。

    当运动轨迹出现时，提问学生："白球是怎么运动的？它先碰到哪条边？反弹后经过哪里？最终要去哪里？"引导学生用语言描述轨迹：白球→上边反弹→黑球→右下角袋口。

    **步骤1→步骤2：认识角度标注**

    角度出现后，教师解释：
    - ∠1是入射光线与桌边的夹角（入射角）
    - ∠2是反射光线与桌边的夹角（反射角）
    - ∠3是反射光线与右边框的夹角，题目已知为30°

    提问："题目给了我们什么条件？要求我们求什么？"

    **步骤2→步骤3：理解反射定律**

    这是本题的第一个关键知识点。教师强调：

    1. 台球反弹遵循反射定律：入射角等于反射角
    2. 即 **∠1 = ∠2**
    3. 法线（虚线）垂直于桌面边缘，入射光线和反射光线关于法线对称

    可类比光线反射或镜面反射帮助学生理解。

    **步骤3→步骤4：利用互余关系**

    这是本题的第二个关键知识点。教师引导学生观察：

    1. 台球桌是矩形，上边与右边互相垂直，夹角为90°
    2. 反射光线（从碰撞点到右下角袋口的线）将右上角的90°分成两部分：∠2和∠3
    3. 因此 **∠2 + ∠3 = 90°**
    4. 已知∠3 = 30°，所以 **∠2 = 90° - 30° = 60°**

    **步骤4→步骤5：得出结论**

    综合两个知识点：

    1. 由反射定律：∠1 = ∠2
    2. 由互余关系：∠2 = 60°
    3. 所以 **∠1 = 60°**，答案选 **B**

    **课堂讲解建议：**

    - 在步骤3和步骤4之间可稍作停顿，让学生先自己思考∠2怎么求
    - 可追问："如果∠3是45°，∠1会是多少？"引导学生发现一般规律：∠1 = 90° - ∠3
    - 可让学生尝试在黑板上画出类似的台球反弹图，巩固反射定律的理解
