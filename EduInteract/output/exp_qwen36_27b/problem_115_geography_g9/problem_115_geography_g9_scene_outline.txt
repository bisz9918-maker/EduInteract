    **第1题讲解要点：**

    1. 引导学生理解"地球另一端"即对跖点的概念——从地表某点穿过地心到达的另一点
    2. 对跖点坐标计算规则：
       - 纬度：数值相同，南北半球相反（30°N → 30°S）
       - 经度：与原经度相加为180°，东西经相反（120°E → 180°-120°=60°W）
    3. 因此面包超人家的位置为（30°S，60°W）

    **第2题讲解要点：**

    1. 咸蛋超人（30°N，120°E）：北半球、东半球、北温带（23.5°N-66.5°N之间）
    2. 面包超人（30°S，60°W）：南半球、西半球、南温带（23.5°S-66.5°S之间）
    3. 两地关于地心对称，纬度数值相同但南北相反，经度互补且东西相反
    4. 教师可引导学生观察：两地是否在同一温度带？（都是温带，但一个是北温带，一个是南温带）

    **交互操作建议：**

    - 步骤0：先让学生观察咸蛋超人的位置，思考"地球另一端"在哪里
    - 步骤1：展示遁地路线，帮助学生建立空间想象
    - 步骤2：揭示答案，同时展示坐标推导过程
    - 步骤3：对比两地特征，引导学生总结对跖点的规律

    **第3题讲解要点：**

    1. 首先读取E点和F点的坐标：
       - E点：（0°，20°E）
       - F点：（66.5°N，40°E）
    2. 方向判断方法：
       - 南北方向：比较纬度——E点纬度0° < F点纬度66.5°N，所以E在F的南方
       - 东西方向：比较经度——E点经度20°E < F点经度40°E，所以E在F的西方
    3. 综合：E点位于F点的西南方向

    **第4题讲解要点：**

    1. 条件分析：
       - "东部是东半球，西部是西半球"→该点位于东西半球分界线上
       - 东西半球分界线为20°W和160°E
       - 20°W以东为东半球，以西为西半球→该点在20°W上
    2. 条件分析：
       - "北部四季变化明显"→北部为温带（有四季变化）
       - "南部有太阳直射现象"→南部为热带（有太阳直射）
       - 温带和热带的分界线是回归线（23.5°）
       - 北部是温带、南部是热带→该点在北回归线23.5°N上
    3. 综合定位：（23.5°N，20°W）→对应图中乙点
    4. 答案：B．乙点

    **课堂讲解建议：**

    - 第3题：强调经纬网上方向判断的基本方法——"经线指示南北，纬线指示东西"，先判断南北再判断东西
    - 第4题：引导学生逐条分析条件，每条条件缩小范围，最终定位到唯一交点。这是典型的"条件叠加定位法"
    - 可让学生先独立分析每条条件，再综合判断，培养逻辑推理能力
    - 提醒学生注意：东西半球分界线是20°W和160°E，不是0°和180°

    **完整解答总结：**

    1. 面包超人家的位置：（30°S，60°W）
    2. 咸蛋超人（30°N，120°E）位于北半球、东半球、北温带；面包超人（30°S，60°W）位于南半球、西半球、南温带
    3. E点位于F点的西南方向
    4. 符合条件的点是乙点（23.5°N，20°W），答案选B

    **核心知识点回顾：**

    - 对跖点坐标计算：纬度取反，经度互补（和为180°）
    - 经纬网上方向判断：经线指示南北，纬线指示东西
    - 东西半球分界线：20°W和160°E
    - 五带划分：热带（23.5°N-23.5°S）、温带（23.5°-66.5°）、寒带（66.5°-90°）
    - 条件叠加定位法：逐条分析条件，缩小范围，最终定位
