    **题目原文：**

    看图判断A点在B点的方向为（  ）

    A．西北 B．西南 C．东北 D．东南

    **题目分析：**

    本题考察学生在**斜向经纬网图**中确定点的经纬度坐标，并根据坐标判断两点之间相对方向的能力。

    核心知识点：
    1. 斜向经纬网中经线和纬线的识别
    2. 180°经线两侧东西经的判断（180°以西为西经，以东为东经）
    3. 根据经纬度判断方向：纬度决定南北，经度决定东西
    4. 跨越180°经线时东西方向的判断（取劣弧/短弧方向）

    **解题思路：**

    1. 从左图读取A点坐标：A位于140°E经线与20°N纬线的交点
    2. 从左图读取B点坐标：B位于160°W经线与60°N纬线的交点
    3. 纬度比较：20°N < 60°N，A在B的**南方**
    4. 经度比较：从160°W向东到140°E，跨越180°经线，距离为20°+40°=60°（劣弧），A在B的**东方**
    5. 综合：A在B的**东南方向**，答案为D

    **图示规划说明：**

    规划一个交互式图示场景，通过分步按钮导航，引导学生：
    - 先识别斜向经纬网中的经线和纬线
    - 确定A、B两点的经纬度坐标
    - 分别判断南北方向和东西方向
    - 综合得出结论

    右图（标准矩形经纬网）作为辅助参考图，可在最后一步展示，帮助学生对比理解斜向经纬网与标准经纬网的关系。

    **教学说明：**

    本图示通过分步导航，帮助学生掌握斜向经纬网中方向判断的完整流程。

    **引导步骤：**

    1. **步骤0-1：识别纬线**
       - 引导学生观察：纬线是水平方向的线，纬度值从下到上递增（20°→40°→60°），说明是北纬
       - 提问：纬线指示什么方向？（东西方向）

    2. **步骤2：识别经线与东西经判断**
       - 引导学生观察：经线是斜向的线，180°经线在中间
       - 关键讲解：180°经线以西为西经（W），以东为东经（E）
       - 提问：180°左侧的160°、140°是东经还是西经？（西经）

    3. **步骤3-4：读取A、B坐标**
       - A点：位于180°东侧的140°经线与20°纬线交点 → A(140°E, 20°N)
       - B点：位于180°西侧的160°经线与60°纬线交点 → B(160°W, 60°N)

    4. **步骤5：南北方向判断**
       - 纬度比较：20°N < 60°N，A的纬度更低，所以A在B的南方
       - 口诀："北纬度数大的在北，南纬度数大的在南"

    5. **步骤6：东西方向判断（难点）**
       - 经度比较：B在160°W，A在140°E
       - 方法：计算劣弧（短弧）方向
         - 从160°W向东到180°：20°
         - 从180°向东到140°E：40°
         - 合计向东60°（劣弧）
       - 结论：A在B的东方
       - 口诀："跨越180°经线时，取劣弧方向判断东西"

    6. **步骤7：综合结论**
       - A在B的南方 + A在B的东方 = A在B的**东南方向**
       - 答案：D

    **课堂讲解建议：**
    - 重点强调180°经线两侧东西经的判断，这是学生容易出错的地方
    - 东西方向判断时，务必强调"劣弧原则"——取两点间较短的弧段来判断方向
    - 可让学生练习：B点在A点的什么方向？（西北方向）
