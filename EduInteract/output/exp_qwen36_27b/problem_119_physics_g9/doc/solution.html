problem_119_physics_g9

场景导航：Scene 1

题目原文：

如图所示的电路中，闭合开关S，当滑动变阻器的滑片P向右滑动时（ ）

A、灯L₁变亮，灯L₂变暗
B、灯L₂变亮，灯L₁亮度不变
C、灯L₁和L₂均变暗
D、灯L₁亮度变化，灯L₂亮度不变

题目分析：

本题考查并联电路的动态分析。电路结构为：滑动变阻器与灯泡L₂串联构成一条支路，灯泡L₁单独构成另一条支路，两条支路并联后与开关S、电源串联。

核心知识点：

  1. 并联电路各支路电压相等，等于电源电压
  2. 欧姆定律 I = U/R
  3. 灯泡亮度由实际功率决定，P = UI = I²R

解题思路：

  1. 识别电路结构：L₁支路与（变阻器+L₂）支路并联
  2. 滑片P右移 → 变阻器接入电阻减小 → L₂支路总电阻减小
  3. 并联支路电压不变（等于电源电压）
  4. L₁支路：R不变、U不变 → I不变 → 亮度不变
  5. L₂支路：R减小、U不变 → I增大 → 亮度变亮
  6. 结论：选B

图示规划：

本题设计一个交互式电路图场景，通过拖拽滑片P来直观展示并联电路中各支路的独立性和动态变化规律。学生可以亲手操作滑片，观察电阻变化如何影响各支路电流和灯泡亮度，从而深刻理解"并联电路各支路互不影响"这一核心概念。

实时数据
U = 6.0V I₂ = 0.20A
I₁ = 0.60A R_P = 20Ω

教学说明——SCENE_1：交互式并联电路动态分析

一、电路结构识别（引导学生观察）

  1. 首先请学生观察电路图，识别电路的连接方式
  2. 引导学生找到两个关键节点（并联的分流点和汇流点）
  3. 明确两条支路：
  • 支路1：灯泡L₁单独一条支路
  • 支路2：滑动变阻器与灯泡L₂串联
  1. 强调：两条支路并联，并联后与开关S、电源串联

二、并联电路的核心规律（板书要点）

  1. 并联电路各支路两端电压相等，且等于电源电压：

$$U_1 = U_2 = U$$

  1. 各支路电流独立，互不影响
  2. 干路电流等于各支路电流之和：

$$I = I_1 + I_2$$

三、动态分析过程（配合拖拽操作）

  1. 滑片P向右移动时，变阻器接入电阻R_P减小
  2. 分析L₁支路：
  • L₁两端电压 $U_1 = U$（电源电压，不变）
  • L₁电阻 $R_1$ 不变
  • 由欧姆定律：$I_1 = \frac{U_1}{R_1} = \frac{U}{R_1}$ → I₁不变
  • 灯泡L₁的实际功率 $P_1 = U_1 I_1$ → P₁不变，亮度不变
  1. 分析L₂支路：
  • L₂支路总电阻 $R_{总2} = R_P + R_2$，RP减小 → R总2减小
  • L₂支路两端电压 $U_2 = U$（不变）
  • 由欧姆定律：$I_2 = \frac{U_2}{R_{总2}} = \frac{U}{R_P + R_2}$ → I₂增大
  • 灯泡L₂的实际功率 $P_2 = I_2^2 R_2$ → P₂增大，亮度变亮

四、结论

灯L₁亮度不变，灯L₂变亮，故选 B。

五、课堂讲解建议

  1. 先让学生独立观察电路图，尝试说出电路结构
  2. 教师引导学生用"节点法"或"电流路径法"确认并联关系
  3. 让学生预测滑片右移后两灯亮度变化，并说明理由
  4. 操作交互图示，拖拽滑片P，验证预测
  5. 强调关键结论：并联电路中，一条支路的电阻变化不影响另一条支路的电流和电压
  6. 可进一步提问：如果滑片左移会怎样？如果L₁也串联一个变阻器呢？引导学生举一反三

总结与拓展

完整解答：

本题电路为并联电路，L₁支路与（变阻器+L₂）支路并联。

滑片P向右滑动时：

  • 变阻器接入电阻减小
  • L₁支路：电压不变、电阻不变 → 电流不变 → 亮度不变
  • L₂支路：电压不变、总电阻减小 → 电流增大 → 亮度变亮

正确答案：B

易错点提醒：

  1. 学生容易误认为滑片移动会影响整个电路，导致L₁也变化。需强调并联支路的独立性。
  2. 学生可能混淆串联和并联的动态分析方法。串联电路中一处电阻变化会影响整个电路电流，而并联电路中各支路独立。
  3. 灯泡亮度由实际功率决定，不是由电阻或电压单独决定。

拓展思考题：

  1. 若滑片P向左滑动，两灯亮度如何变化？（L₁不变，L₂变暗）
  2. 若在L₁支路也串联一个滑动变阻器，同时调节两个滑片，能否让两灯亮度相同？
  3. 若电源电压可变，如何调节使两灯同时变亮？
