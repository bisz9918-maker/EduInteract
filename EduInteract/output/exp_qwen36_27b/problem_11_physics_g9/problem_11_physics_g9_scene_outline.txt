    **题目原文：**

    如图所示，$A$是悬挂在弹簧测力计下的条形磁铁，$B$是螺线管。闭合开关，待弹簧测力计示数稳定后，将滑动变阻器的滑片缓慢向右移动的过程中，下列说法正确的是（）

    A. 电压表示数变大，电流表示数也变大

    B. 电压表示数变小，电流表示数也变小

    C. 螺线管上端是N极，弹簧测力计示数变小

    D. 螺线管上端是S极，弹簧测力计示数变大

    **题目分析：**

    本题综合考查电磁学多个知识点：电路分析、安培定则、磁极间相互作用、欧姆定律、弹簧测力计受力分析。

    **核心知识点：**
    1. 电路结构：电源、开关S、定值电阻$R_0$、电流表A、螺线管B、滑动变阻器R串联；电压表V并联在滑动变阻器R两端
    2. 安培定则（右手螺旋定则）：判断通电螺线管的磁极
    3. 磁极间相互作用：同名磁极相斥，异名磁极相吸
    4. 欧姆定律：滑片移动引起电阻变化，进而引起电流变化
    5. 弹簧测力计示数 = 磁铁重力 - 磁斥力（或 + 磁引力）

    **解题关键步骤：**
    1. 判断电流方向：从电源正极流出，经滑动变阻器→$R_0$→电流表→螺线管下端流入
    2. 用安培定则判断螺线管极性：电流从下端流入，螺线管上端为N极
    3. 分析磁极作用：磁铁A下端为N极，螺线管B上端为N极，同名相斥
    4. 滑片右移：滑动变阻器接入电阻变小→总电阻变小→电流变大→螺线管磁性增强→斥力增大→测力计示数变小
    5. 电压表测滑动变阻器两端电压：R变小，分压变小，电压表示数变小

    **正确答案：C**

    **图示规划说明：**

    本题需要一套交互式图示来完整展示电路结构、极性判断过程和动态变化。规划为一个综合场景，通过分步按钮导航，从初始状态逐步推进到动态分析，帮助学生建立完整的物理图像。

    **Scene 1 教学说明：**

    **步骤0：展示初始状态**

    教师引导学生观察整个装置，识别所有元件：
    - 电路部分：电源、开关S、滑动变阻器R、定值电阻$R_0$、电流表A、螺线管B、电压表V
    - 电磁部分：弹簧测力计、条形磁铁A（注意磁极方向：上S下N）、螺线管B
    - 强调电压表V是并联在滑动变阻器R两端的

    **步骤1：标注电流方向**

    引导学生追踪电流路径：
    1. 电流从电源正极（长线端）流出
    2. 经过滑动变阻器R（从左端流入，从滑片流出）
    3. 经过定值电阻$R_0$
    4. 经过电流表A
    5. 从螺线管B的下端流入，上端流出
    6. 经过开关S，回到电源负极

    关键点：螺线管中电流是从**下端流入、上端流出**，这是后续判断磁极的关键。

    **步骤2：安培定则判断磁极**

    引导学生使用右手螺旋定则：
    1. 用右手握住螺线管
    2. 四指沿电流方向弯曲（从下端流入，绕线方向）
    3. 大拇指指向螺线管的N极

    结论：**螺线管上端为N极，下端为S极**。

    此时可提问学生：磁铁A下端是什么极？（N极）螺线管B上端是什么极？（N极）同名磁极之间是什么作用？（相斥）

    **步骤3：磁力分析**

    明确受力关系：
    - 磁铁A受到三个力：重力G（向下）、弹簧拉力$F_{示}$（向上）、磁斥力$F_{斥}$（向上）
    - 平衡时：$F_{示} + F_{斥} = G$，即 $F_{示} = G - F_{斥}$
    - 同名磁极相斥，斥力方向向上，抵消部分重力

    **步骤4：滑片右移的动态分析**

    这是本题的核心，引导学生逐步推理：

    1. **电阻变化**：滑片向右移动 → 滑动变阻器接入电路的电阻R变小
    2. **电流变化**：总电阻 $R_{总} = R + R_0 + R_B$ 变小 → 由欧姆定律 $I = \frac{U}{R_{总}}$，电流I变大 → **电流表示数变大**
    3. **电压变化**：电压表测R两端电压 $U_R = I \cdot R$。虽然I变大，但R变小更多（串联分压原理：R占总电阻比例减小）→ **电压表示数变小**
    4. **磁力变化**：电流变大 → 螺线管磁性增强 → 对磁铁的斥力增大 → **$F_{斥}$变大**
    5. **测力计示数**：$F_{示} = G - F_{斥}$，$F_{斥}$变大 → **$F_{示}$变小**

    **选项分析：**
    - A：电压表示数变大（×，应变小），电流表示数变大（√）→ 错误
    - B：电压表示数变小（√），电流表示数变小（×，应变大）→ 错误
    - C：螺线管上端是N极（√），弹簧测力计示数变小（√）→ **正确**
    - D：螺线管上端是S极（×，应为N极），弹簧测力计示数变大（×，应变小）→ 错误

    **课堂讲解建议：**
    - 在步骤2和步骤3之间可暂停，让学生先自己判断磁极和磁力方向
    - 步骤4的动态变化是难点，建议反复播放动画，让学生观察各物理量的联动变化
    - 可追问：如果滑片向左移动，各物理量如何变化？（电阻变大→电流变小→磁性减弱→斥力减小→测力计示数变大）
