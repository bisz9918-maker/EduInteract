    **题目原文：**

    如图所示，电源电压不变，灯的电阻不变，滑动变阻器的滑片P在移动过程中，电流表的最小示数为0.2A，电压表的最大示数为4V，当滑片P滑到中点时，灯L的功率达到最大，且灯的最大功率与最小功率之比为9：4．下列结论正确的是（  ）
    A．电源电压为10V
    B．灯的电阻为20Ω
    C．滑动变阻器的最大电阻为40Ω
    D．电路消耗的最大功率为1.8W

    **题目分析：**

    本题是一道典型的串联电路动态分析问题，核心考点包括：
    - 串联电路的电流、电压规律
    - 滑动变阻器对电路的影响
    - 电功率的计算与极值分析

    **电路结构：**
    - 电源、电流表A、滑动变阻器R、灯泡L、开关S串联
    - 电压表V并联在滑动变阻器两端（测量滑动变阻器左端到滑片P之间的电压）
    - 滑动变阻器采用"限流式"接法：左端和滑片P接入电路

    **关键条件解读：**
    1. 电流表最小示数0.2A → 滑片在最右端（接入电阻最大）时
    2. 电压表最大示数4V → 滑片在最右端时，滑动变阻器两端电压最大
    3. 滑片在中点时灯功率最大 → 滑片只能在中点至最右端之间移动，中点处接入电阻最小（R/2），电流最大
    4. 灯的最大功率与最小功率之比为9:4

    **解题思路：**
    - 由条件1和2：I_min = 0.2A，U_Vmax = I_min × R = 4V，得 R = 20Ω
    - 由条件3和4：设灯电阻为R_L，滑片在中点时接入R/2，在最右端时接入R
    - P_max/P_min = [(R_L+R)/(R_L+R/2)]² = 9/4，解得 R_L = R/2 = 10Ω
    - 电源电压 U = I_min × (R_L + R) = 0.2 × 30 = 6V
    - 电路最大功率 = U²/(R_L + R/2) = 36/20 = 1.8W → 选项D正确

    **图示规划：**
    设计一个交互式电路图，通过拖动滑片P观察电路参数变化，帮助学生直观理解滑动变阻器对电路的影响，以及功率极值的物理意义。

    **教学说明：**

    **一、引导学生观察电路结构**

    1. 首先让学生识别电路中的各个元件及其连接方式
    2. 强调这是一个串联电路：电源→电流表→滑动变阻器→灯泡→开关→电源
    3. 指出电压表并联在滑动变阻器两端，测量的是滑动变阻器左端到滑片P之间的电压
    4. 说明滑动变阻器的接法：左端和滑片P接入电路，接入电阻为左端到滑片P之间的电阻

    **二、利用交互演示滑片移动的影响**

    1. 将滑片P置于中点位置，让学生观察此时的电表示数
    2. 拖动滑片P向右移动，引导学生观察：
       - 电流表示数逐渐减小（因为总电阻增大）
       - 电压表示数逐渐增大（因为滑动变阻器分得的电压增大）
       - 灯泡逐渐变暗（因为功率减小）
    3. 将滑片P移到最右端，标注此时的已知条件：I_min = 0.2A，U_Vmax = 4V

    **三、推导关键物理量**

    1. 由 U_Vmax = I_min × R，得 R = 4V / 0.2A = 20Ω
    2. 由题意"滑片在中点时灯功率最大"，说明滑片只能在中点至最右端之间移动
    3. 滑片在中点时，接入电阻为 R/2 = 10Ω，此时电流最大，灯功率最大
    4. 滑片在最右端时，接入电阻为 R = 20Ω，此时电流最小，灯功率最小
    5. 利用功率比 P_max/P_min = 9/4，列方程求解 R_L：
       - P_max = [U/(R_L + R/2)]² × R_L
       - P_min = [U/(R_L + R)]² × R_L
       - P_max/P_min = [(R_L + R)/(R_L + R/2)]² = 9/4
       - 解得 R_L = R/2 = 10Ω
    6. 电源电压 U = I_min × (R_L + R) = 0.2 × (10 + 20) = 6V

    **四、验证选项**

    - A：电源电压为10V → 错误，应为6V
    - B：灯的电阻为20Ω → 错误，应为10Ω
    - C：滑动变阻器的最大电阻为40Ω → 错误，应为20Ω
    - D：电路消耗的最大功率 = U²/(R_L + R/2) = 36/20 = 1.8W → 正确

    **五、课堂讲解建议**

    1. 先让学生独立分析电路结构，识别串并联关系
    2. 利用交互图示演示滑片移动过程，让学生直观感受电路参数变化
    3. 引导学生列出已知条件，逐步推导未知量
    4. 强调"滑片在中点时功率最大"这一条件的含义：滑片移动范围受限
    5. 最后验证各选项，得出结论
