[图示主题与整合说明]
- 本图示主题：六个物块连接体的整体法与隔离法受力分析
- 整合的步骤/概念：题目原图展示 → 整体受力分析（F与总摩擦力平衡） → 单个物块摩擦力计算 → 隔离法（4-5-6号物块隔离体） → 3号与4号间压力的求解结论
- 教学价值：教师通过分步按钮引导学生从"整体法"过渡到"隔离法"，逐步理解连接体问题的解题思路。每一步都有明确的视觉变化和底部文字提示，教师可随时回退复习前一步，适合课堂互动讲解。

[分步序列]

步骤0（初始状态）：
- 显示元素：六个物块(1~6)、地面线+斜线、F箭头、F标签、物块编号
- 所有物块正常显示（黑色轮廓、浅灰填充）
- 底部文字提示：无（或显示"点击「下一步」开始分析"）
- 控件栏：显示"上一步"(禁用)、"0/4"、"下一步"

步骤1（整体法）：
- 新增元素：蓝色整体框、F=6N标签、f_总=6N标签、"整体"标签
- 视觉变化：整体框从物块周围淡入（opacity 0→1，300ms）
- F=6N标签：位于F箭头下方(80,205)，蓝色
- f_总=6N标签：位于整体框下方居中(400,295)，蓝色，带向左小箭头
- 底部文字提示："整体匀速运动 → 合力为零 → f_总 = F = 6N"
- 控件栏：显示"上一步"、"1/4"、"下一步"

步骤2（单块摩擦力）：
- 移除元素：整体框、F=6N标签、f_总=6N标签、"整体"标签（淡出）
- 新增元素：6个f=1N箭头（各物块下方）、6个f=1N标签
- 箭头位置：每个物块中心x坐标处，从y=255到y=275，向左箭头
- 标签位置：箭头右侧约15px处
  - 物块1：(230,270)
  - 物块2：(322,270)
  - 物块3：(414,270)
  - 物块4：(506,270)
  - 物块5：(598,270)
  - 物块6：(690,270)
- 底部文字提示："6个相同物块 → 每个摩擦力 f = 6N ÷ 6 = 1N"
- 控件栏：显示"上一步"、"2/4"、"下一步"

步骤3（隔离法）：
- 移除元素：步骤2的6个f=1N箭头和标签（淡出）
- 视觉变化：1、2、3号物块淡化（轮廓#cccccc，填充#fafafa，300ms过渡）
- 新增元素：绿色隔离体框、N=?箭头、N=?标签、"隔离体"标签、4-6号物块下方绿色f=1N箭头和标签
- 隔离体框：包围4、5、6号物块(391,188)-(595,268)
- N箭头：从(372,220)到(401,220)，向右，绿色
- N=?标签：(370,200)，绿色
- 4-6号f=1N箭头：绿色，位置同步骤2对应物块
- 4-6号f=1N标签：绿色，位置同步骤2对应物块
- 底部文字提示："隔离4-5-6号物块 → 分析其受力"
- 控件栏：显示"上一步"、"3/4"、"下一步"

步骤4（结论）：
- 视觉变化：N=?标签变为"N=3N"（绿色加粗，字号16px）
- 新增元素：3-4接触面红色高亮线、摩擦力汇总标签
- 3-4接触面：x=401处垂直线，y=205~250，红色(#c62828,3px)
- 摩擦力汇总标签：(480,315)，绿色，"向左摩擦力 = 3×1N = 3N"
- 底部文字提示："隔离体匀速运动 → N = 3f = 3N → 答案：B. 3N"
- 控件栏：显示"上一步"、"4/4"、"下一步"(禁用)

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于控件栏左侧(x=280~370)，点击返回上一步，步骤0时禁用
  - 步骤指示器：位于控件栏中央(x=390~410)，显示"当前步/总步数"（如"2/4"）
  - 「下一步」按钮：位于控件栏右侧(x=430~520)，点击进入下一步，步骤4时禁用
- 教师操作流程：
  1. 图示加载后显示步骤0（题目原图），教师可先让学生观察题目
  2. 点击「下一步」进入步骤1，讲解整体法思路，配合底部文字提示
  3. 点击「下一步」进入步骤2，讲解每个物块的摩擦力计算
  4. 点击「下一步」进入步骤3，讲解隔离法思路，观察4-5-6号物块的受力
  5. 点击「下一步」进入步骤4，展示最终结论和答案
  6. 随时点击「上一步」回退到任意步骤复习

[技术实现]
- JS 库选择：原生 SVG（简单几何图形、箭头、矩形框，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |                                                  |
  |   F→ [1][2][3][4][5][6]                         |  ← 物块区 y=205~250
  |   ↓        |  |  |  |  |  |                     |
  |  ===地面线=======================================  ← y=250
  |   / / / / / / / / / / / / / / / / / / / / / / /  ← 斜线 y=250~270
  |                                                  |
  |   [f=1N][f=1N][f=1N][f=1N][f=1N][f=1N]          |  ← 摩擦力标注 y=270
  |                                                  |
  |   f_总=6N / 向左摩擦力=3N                        |  ← 汇总标注 y=295~315
  |                                                  |
  |                                                  |
  |   底部文字提示区（每步不同内容）                   |  ← y=415
  |                                                  |
  |   [◀上一步]  [2/4]  [下一步▶]                    |  ← 控件栏 y=455~485
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. **状态机设计**：用变量 `currentStep` (0~4) 管理当前步骤，每个步骤对应一个渲染函数 `renderStep(n)`
  2. **元素显隐控制**：通过 SVG 元素的 `opacity` 属性实现淡入淡出动画（CSS transition 300ms）
  3. **坐标计算**：物块位置固定，箭头和标签位置基于物块坐标计算，确保精确对齐
  4. **事件绑定**：按钮点击事件更新 `currentStep` 并调用 `renderStep(currentStep)`
  5. **按钮状态**：步骤0时「上一步」禁用（opacity=0.4, pointer-events=none），步骤4时「下一步」禁用
  6. **物块淡化**：步骤3-4中，1-3号物块的 `stroke` 和 `fill` 通过 CSS class 切换
  7. **箭头绘制**：使用 SVG `<line>` + `<polygon>` 绘制实心三角箭头，箭头头部尺寸 10×8px
  8. **地面斜线**：用循环生成多条 `<line>`，间距12px，45°角，从地面线向下延伸20px
  9. **文字居中**：底部文字提示使用 `text-anchor="middle"` 居中显示
- ID 命名规范：所有交互元素 ID 以 `scene1-` 为前缀
  - 物块：`scene1-block-1` ~ `scene1-block-6`
  - F箭头：`scene1-force-f`
  - 整体框：`scene1-whole-box`
  - 隔离体框：`scene1-isolate-box`
  - N箭头：`scene1-normal-force`
  - 接触面高亮：`scene1-contact-highlight`
  - 摩擦力箭头：`scene1-friction-1` ~ `scene1-friction-6`
  - 底部提示：`scene1-hint-text`
  - 按钮：`scene1-prev-btn`、`scene1-next-btn`
  - 步骤指示器：`scene1-step-indicator`
- IIFE 隔离：所有 JS 代码包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染
