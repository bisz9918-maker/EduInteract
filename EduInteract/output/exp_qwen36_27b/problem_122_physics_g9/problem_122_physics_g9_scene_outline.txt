    **题目原文：**

    图为某均匀金属薄板，现测得接线柱A、B之间的电阻为R．如果将该电阻板均匀分成9块，并挖去其中一小块，则此时A、B之间的电阻变为（  ）
    A 、8R/9  B 、7R/6  C 、9R/8  D 、6R/7

    **题目分析：**

    本题考察电阻网络的等效电阻计算。核心在于将均匀金属薄板抽象为电阻网络模型，然后分析挖去一小块后电阻的变化。

    **整体讲解思路：**

    1. 首先引导学生观察原图：一块矩形金属薄板，左右两侧分别接有接线柱A和B，板子被虚线划分为3×3=9个小块，其中第二行第三列（中间行最右侧）的小块被挖去（用斜线阴影表示）。

    2. 将金属板抽象为电阻网络：每小块视为一个电阻r，采用"3列串联"模型——每列3个电阻并联，3列串联。

    3. 完整板子时：每列等效电阻为r/3，3列串联总电阻R = r/3 + r/3 + r/3 = r，即每小块电阻r = R。

    4. 挖去第二行第三列小块后：第三列只剩2个电阻并联，等效电阻变为r/2。总电阻 = r/3 + r/3 + r/2 = 7r/6 = 7R/6。

    5. 答案为B、7R/6。

    **图示规划说明：**

    规划一个交互式图示，通过分步按钮导航展示从完整板子到挖去一块后的电阻变化过程。图示整合了金属板示意图和等效电路图，帮助教师直观呈现电阻网络的建模和计算过程。

    **本图示教学说明：**

    **步骤0→步骤1：从直观到抽象**

    教师引导学生观察完整金属板，然后展示3×3网格划分。提问："如果将这块均匀金属板分成9个相同的小块，每个小块的电阻是多少？"引导学生理解每小块电阻为r。

    **步骤1→步骤2：建立等效电路模型**

    这是本题的关键步骤。教师应引导学生思考电流的流向：电流从A流入，从B流出，主要沿水平方向流动。因此可以将板子视为3列串联的结构：

    1. 每列有3个小块并联，等效电阻为 r/3
    2. 3列串联，总电阻 R = r/3 + r/3 + r/3 = r
    3. 由此得出每小块电阻 r = R

    强调"3列串联"模型的合理性：电流主要从A流向B，同一列的3个小块可以视为并联。

    **步骤2→步骤3：识别挖去位置**

    高亮第二行第三列的小块，引导学生确认挖去的位置。提问："挖去这个小块后，哪一列的电阻会发生变化？"引导学生关注第三列。

    **步骤3→步骤4：计算新电阻**

    挖去第三列中间的小块后，第三列只剩2个小块并联：

    1. 第一列：仍为3个并联，等效电阻 r/3
    2. 第二列：仍为3个并联，等效电阻 r/3
    3. 第三列：变为2个并联，等效电阻 r/2
    4. 总电阻 R' = r/3 + r/3 + r/2 = 7r/6

    代入 r = R，得 R' = 7R/6。

    **关键公式：**

    完整板子：R = r/3 + r/3 + r/3 = r

    挖去后：R' = r/3 + r/3 + r/2 = 7r/6 = 7R/6

    **课堂讲解建议：**

    - 在步骤2，可让学生先自己推导完整板子的等效电阻，再与图示对比
    - 在步骤4，可让学生思考：如果挖去的是其他位置的小块，电阻会如何变化？（例如挖去第一列或第二列的小块）
    - 强调"3列串联"模型的近似性：实际上垂直方向也有电流，但对于初中物理，此模型已足够准确
    - 最终答案：B、7R/6
