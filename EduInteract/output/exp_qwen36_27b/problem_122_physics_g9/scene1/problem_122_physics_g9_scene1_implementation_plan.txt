[图示主题与整合说明]
- 本图示主题：均匀金属薄板挖去一小块后的等效电阻计算——从完整板子到电阻变化的完整过程
- 整合的步骤/概念：完整金属板展示 → 3×3网格划分与电阻标注 → 3列串联等效电路建模 → 挖去小块的高亮标记 → 挖去后的等效电路与电阻计算
- 教学价值：教师通过分步导航，逐步引导学生从直观图形（金属板）过渡到抽象电路（等效电路），理解电阻网络的建模方法。每一步都有明确的视觉变化，帮助学生建立"几何结构→电路模型→数学计算"的思维链条。

步骤2（等效电路建模）：
- 点击「下一步」→
- 右侧出现完整等效电路：
  - 左端节点(440,250)、右端节点(720,250)
  - 3列并联组（每列3个电阻矩形框）

- 左侧金属板保持不变
- 按钮状态：两者均可用

步骤3（高亮挖去块）：
- 点击「下一步」→

- 步骤2的蓝色公式淡出
- 按钮状态：两者均可用

步骤4（最终计算）：
- 点击「下一步」→
- 左侧金属板：挖去小块变为空白（红色高亮消失，"r"标签消失，保留斜线阴影表示空缺）
- "挖去"文字保留
- 右侧等效电路：
  - 列3中间电阻完全消失（框和打叉都消失）
  - 列3只剩上、下2个电阻并联
  - 列3上方标注由"r/3"变为"r/2"（绿色）
- 电路下方出现绿色公式："R' = r/3 + r/3 + r/2 = 7r/6 = 7R/6"
- 按钮状态："上一步"可用，"下一步"禁用

[技术实现]
- JS 库选择：原生 SVG（本场景为几何图形+电路图，SVG最适合精确绘制和动画控制）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  +--------------------------------------------------+
  |  金属板区(50~400)     |  等效电路区(430~760)     |
  |                      |                          |
  |   A ○──┌──────────┐  |  每小块电阻为r           |
  |       │  r  r  r  │  |                          |
  |       ├───────────┤  |  ┌───┐  ┌───┐  ┌───┐   |
  |       │  r  r  r  │  |  │r/3│──│r/3│──│r/2│   |
  |       ├───────────┤  |  └───┘  └───┘  └───┘   |
  |   B ○──└──────────┘  |                          |
  |                      |  R = r/3+r/3+r/3 = r    |
  |                      |  R' = r/3+r/3+r/2=7R/6  |
  |                      |                          |
  +--------------------------------------------------+
  |              ◀ 上一步    下一步 ▶                |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 `currentStep` (0~4) 跟踪当前步骤，每个步骤对应一个渲染函数 `renderStep(n)`
  2. 元素显隐：用 SVG 的 `opacity` 属性配合 CSS transition 实现淡入淡出动画（duration: 0.4s）
  3. 坐标计算：所有元素坐标已精确规划，直接用绝对坐标定位
  4. 动画曲线：使用 `ease-in-out` 缓动函数
  5. 事件绑定：按钮点击事件绑定到 `prevStep()` 和 `nextStep()` 函数
  6. 打叉标记：用两条交叉线段实现，覆盖在电阻框上
  7. 斜线阴影：用 SVG `<pattern>` 定义斜线图案，填充到挖去小块区域
  8. 公式渲染：用 SVG `<text>` 元素，支持基本数学符号（分数用上下标表示）
- ID 命名规范：所有交互元素 ID 以 `scene1-` 为前缀
  - 按钮：`scene1-prev-btn`、`scene1-next-btn`
  - 金属板：`scene1-plate`
  - 接线柱：`scene1-terminal-a`、`scene1-terminal-b`
  - 网格线：`scene1-grid-v1`、`scene1-grid-v2`、`scene1-grid-h1`、`scene1-grid-h2`
  - 小块：`scene1-cell-{row}-{col}`（如 `scene1-cell-2-3` 为挖去块）
  - 等效电路列：`scene1-circuit-col1`、`scene1-circuit-col2`、`scene1-circuit-col3`
  - 电阻：`scene1-resistor-{col}-{pos}`（如 `scene1-resistor-3-mid`）
  - 公式：`scene1-formula-step2`、`scene1-formula-step4`
- IIFE 隔离：所有 JS 代码包裹在 `(function() { 'use strict'; ... })();` 中
- CSS 过渡：为所有动态元素添加 `transition: opacity 0.4s ease-in-out, fill 0.4s ease-in-out, stroke 0.4s ease-in-out;`
