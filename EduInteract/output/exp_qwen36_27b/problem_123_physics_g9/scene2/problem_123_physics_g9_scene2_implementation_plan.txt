[图示主题与整合说明]
- 本图示主题：展示打开开关M后的完整变化过程及最终结论，通过分步动画演示水的流动和气体压强变化
- 整合的步骤/概念：打开开关M → 水从甲流入乙 → 乙气体被压缩压强增大 → 气体流向丙 → 丙水位下降 → 水从丙流向甲 → 最终平衡状态 → 气体体积变化对比 → 结论展示
- 教学价值：教师可通过分步按钮逐步引导学生观察物理过程的连锁反应，清晰展示因果关系，从开关操作到最终结论形成完整认知链条，辅助讲解连通器原理与气体压强变化规律

[分步序列]
- 初始状态（步骤0）：显示三个容器、初始水位线（虚线）、连通管、关闭的开关M、容器名标签、初始气体体积标注V乙₀、V丙₀。无流动箭头。
- 步骤1：点击「下一步」→ 开关M变为打开状态，中间管出现蓝色向下箭头，标注"水流入乙"（临时标签，3秒后淡出）。
- 步骤2：点击「下一步」→ 乙水位线从y=220平滑上移至y=240（实线#2e7d32），乙气体空间缩小，显示标注"乙气体被压缩，压强增大"及P乙↑。
- 步骤3：点击「下一步」→ 左侧气体连通管出现红色向下箭头，标注"气体流向丙"，显示P丙↑。
- 步骤4：点击「下一步」→ 丙水位线从y=360平滑下移至y=380（实线#2e7d32），丙气体空间增大，右侧水连通管出现蓝色向上箭头，标注"丙水位下降"。
- 步骤5：点击「下一步」→ 甲水位线从y=80上移至y=70（实线#2e7d32），显示最终气体体积V乙'、V丙'，显示变化量△V乙、△V丙（红色加粗）。
- 步骤6：点击「下一步」→ 底部显示结论文本"V乙减少，V丙增大，且△V乙 > △V丙"（红色加粗16px），高亮答案B。所有临时标注淡出，保留最终状态元素。
（教师可随时点击「上一步」回退复习，状态机支持双向导航）

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于控件栏左侧，点击返回上一状态，步骤0时禁用
  - 「下一步 ▶」按钮：位于控件栏右侧，点击进入下一状态，步骤6时禁用
  - 步骤指示器：控件栏中央显示"步骤 X / 6"
- 教师操作流程：教师点击「下一步 ▶」逐步展示物理过程，配合讲解每个步骤的因果关系；可随时点击「◀ 上一步」回退复习关键节点；最终步骤展示结论与答案，完成教学闭环

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无需外部库，轻量高效，适合几何图形与分步动画）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  y=40  [甲容器]  M开关
  y=140  |
  y=180  [乙容器]  ← 左气管(220)  中管(310)  右水管(400) →
  y=280  |
  y=320  [丙容器]
  y=420  |
  y=430  [结论文本]
  y=450  [◀ 上一步] [步骤 X/6] [下一步 ▶]
  y=490  [控件栏底部]
  ```
- 关键实现要点：
  - 状态机设计：使用数组 `steps[0..6]` 存储每步的可见元素ID列表与属性变化，通过 `currentStep` 索引控制渲染
  - 坐标计算：所有元素坐标预计算并硬编码，动画使用 `requestAnimationFrame` 实现水位线平滑移动（线性插值）
  - 动画曲线：水位变化使用 `ease-in-out` 曲线，箭头出现使用 `fade-in` 透明度渐变
  - 事件绑定：按钮点击绑定 `handleStepChange(direction)`，更新 `currentStep` 并调用 `renderStep()`
  - 防重叠保障：所有标签位置经冲突检查，SVG 元素按 z-index 顺序绘制（背景→容器→水位→管道→箭头→标签→控件）
- ID 命名规范：所有交互元素与 SVG 节点 ID 以 `scene2-` 为前缀（如 `scene2-container-jia`, `scene2-waterline-yi-init`, `scene2-btn-next`）
- IIFE 隔离：所有 JS 代码包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染
- 数学公式渲染：使用 Unicode 字符与 HTML 实体（如 `△`、`↑`、`₀`、`′`），无需 MathJax，保持轻量
