[图示主题与整合说明]
- 本图示主题：利用安培定则判断电磁铁甲的磁极极性
- 整合的步骤/概念：电源正负极识别 → 电流方向标注 → 右手螺旋定则应用 → 电磁铁a、b两端磁极判定
- 教学价值：教师通过分步导航，逐步引导学生从电路基础（电源极性）出发，追踪电流方向，应用右手螺旋定则，最终判定电磁铁两端磁极。每一步都有明确的视觉变化，符合认知递进规律，适合课堂逐层讲解。

[分步序列]
- 初始状态（步骤0）：
  显示元素：螺线管铁芯+线圈、永磁体、磁感线、电源符号、开关S（断开状态）、导线、端点标签"a"/"b"/"c"/"d"、物体标签"甲"/"乙"、开关标签"S"、电源标签"+"/"-"
  开关S处于断开状态（折线向上翘起）
  无电流箭头、无右手示意、无磁极标签

- 步骤1（闭合开关）：
  点击「下一步」→ 开关S从断开状态动画过渡到闭合状态（折线放下，与导线连通）
  视觉变化：开关S的折线从 (140,310)-(160,290)-(180,310) 变为 (140,310)-(180,310)
  其余元素不变

- 步骤2（高亮电流方向）：
  点击「下一步」→ 沿导线和线圈出现蓝色电流方向箭头
  导线右路：从电源正极(280,360)→(360,360)→(360,240)到b端，箭头方向向上
  导线左路：从a端(100,240)→(100,310)→开关→(220,310)→(220,360)到电源负极，箭头方向向下
  线圈上：7个蓝色小箭头，标注电流环绕方向（从前面看，电流向上绕）
  新增元素坐标：
    - 右路导线箭头：(320,360)方向左→右，(360,300)方向下→上
    - 左路导线箭头：(100,275)方向上→下，(160,310)方向右→左，(220,335)方向上→下
    - 线圈箭头：7个，分别位于 x=120,157,194,231,268,305,342 处，标注从前面向上

- 步骤3（安培定则示意）：
  点击「下一步」→ 在螺线管上叠加右手螺旋定则示意
  新增元素：
    - 简化右手图形：覆盖在螺线管上，四指弯曲方向与电流方向一致（从前面看向上弯曲）
    - 大拇指：绿色粗箭头，从螺线管中心指向左端(a端)，坐标从(230,210)到(130,210)
    - 辅助文字"大拇指→N极"：(130, 195)，灰色#888888
  右手图形坐标范围：x=100~360, y=150~270，填充#2e7d32透明度20%

- 步骤4（磁极标注）：
  点击「下一步」→ 在a端和b端分别标注磁极
  新增元素：
    - "N极"标签：(85, 165)，红色#c62828，粗体，字号16px
    - "S极"标签：(375, 165)，蓝色#1565c0，粗体，字号16px
  同时高亮螺线管两端：a端红色光晕，b端蓝色光晕
  完成电磁铁极性判断

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀上一步」按钮：位于控件栏左侧 (250,455)-(370,485)，点击回退到上一步骤，步骤0时禁用（灰色）
  - 「下一步▶」按钮：位于控件栏右侧 (430,455)-(550,485)，点击进入下一步骤，步骤4时禁用（灰色）
- 教师操作流程：
  1. 图示加载后显示步骤0（完整电路图，开关断开），教师可先让学生观察电路结构
  2. 点击「下一步▶」进入步骤1，开关S闭合，教师讲解电路连通
  3. 点击「下一步▶」进入步骤2，电流方向箭头出现，教师讲解电流从正极流向负极的路径
  4. 点击「下一步▶」进入步骤3，右手螺旋定则示意出现，教师讲解安培定则的应用方法
  5. 点击「下一步▶」进入步骤4，磁极标签出现，教师总结电磁铁a端为N极、b端为S极
  6. 可随时点击「◀上一步」回退到任意步骤复习

[技术实现]
- JS 库选择：原生 SVG（简单几何图形绘制，无需额外库，轻量高效）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────┐
  │                    图示区 800×440                          │
  │                                                            │
  │         a    ~~~~~~~~    b      ~~~~    c    ~~~~~~~~    d │
  │          ┌───────────────┐   ╲╱╲╱   ┌───────────────┐     │
  │          │  螺线管(甲)   │    ╲╱    │   永磁体(乙)   │     │
  │          └───────────────┘   ╱╲╱    └───────────────┘     │
  │               甲                    乙                     │
  │                                                            │
  │          S              +                                 │
  │           ╲            ──                                  │
  │            ╲── ── ────                                    │
  │              ╲                                            │
  └────────────────────────────────────────────────────────────┘
  ┌────────────────────────────────────────────────────────────┐
  │              控件栏 y=440~490                              │
  │         [◀ 上一步]              [下一步 ▶]                 │
  └────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. **状态机设计**：用变量 `currentStep` (0~4) 管理当前步骤，每个步骤对应一组SVG元素的显示/隐藏/动画
  2. **开关动画**：步骤0→1时，开关S的折线路径从断开状态 `M140,310 L160,290 L180,310` 平滑过渡到闭合状态 `M140,310 L180,310`，使用 SVG `<animate>` 或 JS 修改 `d` 属性
  3. **线圈绘制**：用7段正弦曲线模拟线圈缠绕，每匝宽度约37px，x坐标从120到342，y坐标在175~245之间波动
  4. **磁感线绘制**：4条向外弯曲的贝塞尔曲线，从b端(360,180~240)出发，向外凸出到x≈410，再回到c端(460,180~240)，曲线方程用 `C` 命令
  5. **电流箭头**：步骤2出现，用 SVG `<marker>` 定义箭头，沿导线和线圈放置，蓝色#1565c0
  6. **右手示意**：步骤3出现，用简化路径绘制手形轮廓+大拇指箭头，绿色#2e7d32，填充透明度20%
  7. **磁极标签**：步骤4出现，带淡入动画（opacity从0到1，持续0.5s）
  8. **按钮状态**：步骤0时「上一步」禁用（opacity=0.4，pointer-events=none），步骤4时「下一步」禁用
  9. **事件绑定**：按钮点击事件绑定到 `handleStepChange(direction)` 函数，direction为-1或+1
- ID 命名规范：所有交互元素 ID 以 `scene1-` 为前缀
  - `scene1-solenoid-core`：螺线管铁芯
  - `scene1-solenoid-coil`：螺线管线圈
  - `scene1-permanent-magnet`：永磁体
  - `scene1-magnetic-field`：磁感线
  - `scene1-battery`：电源符号
  - `scene1-switch`：开关S
  - `scene1-wire-left`：左路导线
  - `scene1-wire-right`：右路导线
  - `scene1-current-arrows`：电流箭头组
  - `scene1-hand-rule`：右手螺旋示意
  - `scene1-pole-n`：N极标签
  - `scene1-pole-s`：S极标签
  - `scene1-btn-prev`：上一步按钮
  - `scene1-btn-next`：下一步按钮
- IIFE 隔离：所有 JS 代码包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染
