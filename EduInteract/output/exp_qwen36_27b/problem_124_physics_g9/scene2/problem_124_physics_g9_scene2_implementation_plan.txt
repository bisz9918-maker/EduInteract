[分步序列]
- 初始状态（步骤0）：
  * 显示电磁铁甲（螺线管），标注a端为N极（红色）、b端为S极（蓝色）
  * 显示永磁体乙（矩形），c、d端无标注
  * 显示b、c之间的磁感线（黑色实线，向外弯曲排斥状）
  * 显示电池、开关、导线
  * 显示甲、乙标签
  * 按钮：上一步（禁用）、下一步（启用）

- 步骤1（磁感线分析）：
  * 高亮b、c之间的磁感线区域，用红色虚线框标注(300,100)-(500,300)
  * 显示推理文字"磁感线向外弯曲→同名磁极相互排斥"（绿色，位置350,330）
  * 按钮：上一步（启用）、下一步（启用）

- 步骤2（推断c极）：
  * 在c端标注"S极"（蓝色，位置460,200）
  * 显示推理文字"b为S极 → c也为S极"（绿色，位置350,360）
  * 按钮：上一步（启用）、下一步（启用）

- 步骤3（推断d极）：
  * 在d端标注"N极"（红色，位置740,200）
  * 显示推理文字"c为S极 → d为N极"（绿色，位置350,390）
  * 按钮：上一步（启用）、下一步（启用）

- 步骤4（最终结论）：
  * 高亮a端和d端（绿色框，线宽3px，填充透明度10%）
  * 显示结论"a端和d端都是N极 → 选B"（绿色，位置350,420）
  * 显示四个选项A、B、C、D（位置100,400-700,430）
  * B选项用绿色高亮（背景填充透明度20%）
  * 其他选项用灰色显示
  * 按钮：上一步（启用）、下一步（禁用）

[技术实现]
- JS 库选择：原生 SVG（简单几何图形和文字标注，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────────┐
  │                                                             │
  │   a(N)              b(S)        c(S)              d(N)      │
  │   ┌─────────────┐    ╱╲        ╱╲    ┌─────────────┐       │
  │   │  ~~~~~~~~   │   ╱  ╲      ╱  ╲   │             │       │
  │   │  螺线管     │──╱    ╲────╱    ╲──│  永磁体     │       │
  │   │             │ ╱      ╲  ╱      ╲ │             │       │
  │   └─────────────┘╱        ╲╱        ╲└─────────────┘       │
  │                    磁感线区域                              │
  │                                                             │
  │   ┌───┐    ┌───┐                                           │
  │   │电池│───│开关│─── 导线连接                               │
  │   └───┘    └───┘                                           │
  │                                                             │
  │   甲                推理文字区域                乙           │
  │                                                             │
  │   选项A    选项B(绿)    选项C    选项D                      │
  │                                                             │
  │              [◀上一步]        [下一步▶]                     │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  * 状态机设计：5个状态（0-4），每个状态对应不同的视觉元素显示/隐藏/高亮
  * 坐标计算：所有元素位置固定，按布局坐标表精确实现
  * 动画曲线：步骤切换使用淡入淡出效果（opacity 0→1，duration 300ms）
  * 事件绑定：按钮点击事件触发状态切换，更新SVG元素显示
  * 磁感线绘制：使用SVG path绘制向外弯曲的曲线，模拟排斥效果
  * 线圈绘制：使用SVG path绘制螺旋线，模拟螺线管外观
- ID 命名规范：所有交互元素ID以 `scene2-` 为前缀（如 `scene2-solenoid`、`scene2-magnet`、scene2-btn-prev`、`scene2-btn-next`）
- IIFE 隔离：所有JS代码包裹在 (function() { ... })() 中，避免全局污染
