[图示主题与整合说明]
- 本图示主题：功、功率、机械效率的公式推导与选项逐项分析
- 整合的步骤/概念：有用功计算（W_有用=fS）、总功计算（W_总=3FS）、功率计算（P=3Fυ）、机械效率计算（η=f/3F）、四个选项（A/B/C/D）的正误逐项判定
- 教学价值：教师通过分步按钮逐步展示每个物理量的推导过程，逐项验证选项正误，最终引导学生得出"选项A为唯一错误选项"的结论。分步展示避免信息过载，便于课堂节奏控制。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位置(290,450)-(370,482)，点击回退到上一步骤，步骤0时禁用
  - 「下一步 ▶」按钮：位置(430,450)-(510,482)，点击进入下一步骤，步骤5时禁用
  - 步骤指示文字：位置(380,468)，显示"步骤 X/5"
- 教师操作流程：
  1. 图示加载后显示步骤0（四个灰色选项），教师可先让学生观察题目
  2. 点击「下一步」逐步展示每个选项的分析过程
  3. 每步左侧推导区显示公式推导，右侧对应选项高亮并显示判定结果
  4. 到达步骤5后显示最终答案
  5. 可随时点击「上一步」回退到任意步骤进行复习
  6. 教师可配合讲解，在每步停留足够时间让学生理解

[技术实现]
- JS 库选择：原生 SVG（本场景为卡片式文字展示，无需复杂绘图库，原生SVG足以实现）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+ 800px
  |  推导过程              |  选项判定               |
  |                       |                         |
  |  [动态公式内容区]      |  ┌──────────────────┐  |
  |                       |  │ A 有用功为GS   ✗ │  |
  |  W_有用 = fS          |  ├──────────────────┤  |
  |  重力不做功           |  │ B 拉力做功为3FS ✓ │  |
  |                       |  ├──────────────────┤  |
  |                       |  │ C 功率为3Fυ   ✓ │  |
  |                       |  ├──────────────────┤  |
  |                       |  │ D 效率为f/3F  ✓ │  |
  |                       |  └──────────────────┘  |
  |                       |                         |
  |  ┌──────────────────────────────────────────┐  |
  |  │           答案：A                        │  |
  |  └──────────────────────────────────────────┘  |
  |                       |                         |
  |  [◀上一步]  步骤2/5  [下一步▶]                  |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep（0~5）记录当前步骤，每个步骤对应一组视觉状态
  2. 步骤数据：用数组存储每个步骤的推导内容、激活选项、判定结果
  3. 渲染函数：renderStep(step) 根据步骤编号更新推导区文本、选项卡片样式、判定标记、结论栏显隐
  4. 按钮事件：上一步按钮绑定 currentStep--，下一步按钮绑定 currentStep++，边界检查（0和5时禁用对应按钮）
  5. 动画过渡：选项卡片样式变化使用 CSS transition（0.3s ease），推导区文本淡入效果
  6. 公式渲染：使用 SVG <text> 元素，下标用 <tspan baseline-shift="sub"> 实现（如 W_有用）
  7. 判定标记：用 SVG <text> 显示 ✓/✗ 符号，颜色根据正误切换
- ID 命名规范：所有交互元素 ID 以 scene2- 为前缀
  - scene2-step-indicator（步骤指示）
  - scene2-prev-btn（上一步按钮）
  - scene2-next-btn（下一步按钮）
  - scene2-derivation-area（推导内容区）
  - scene2-option-A（选项A卡片组）
  - scene2-option-B（选项B卡片组）
  - scene2-option-C（选项C卡片组）
  - scene2-option-D（选项D卡片组）
  - scene2-conclusion-bar（结论栏）
  - scene2-divider（分隔虚线）
- JS 中用 getElementById 获取元素，不使用 querySelectorAll 配合全局 class
- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
