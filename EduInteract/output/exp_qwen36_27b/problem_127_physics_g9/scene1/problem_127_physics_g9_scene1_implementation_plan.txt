[图示主题与整合说明]
- 本图示主题：光通过平行玻璃砖的正确折射光路分步演示
- 整合的步骤/概念：入射光线展示 → 第一次折射（空气→玻璃，折射角小于入射角）→ 第二次折射（玻璃→空气，折射角大于入射角）→ 完整光路与平行关系结论（出射光线∥入射光线，存在侧移）
- 教学价值：教师可通过分步按钮逐步展示光的折射过程，帮助学生理解每次折射的规律（光密→光疏/光疏→光密时折射角的变化），最终得出"平行玻璃砖出射光线与入射光线平行"的结论。分步展示避免信息过载，每步聚焦一个物理规律。

[技术实现]
- JS 库选择：原生 SVG（无需额外库）
  原因：本场景为简单几何图形（线段、弧线、矩形、文本），原生 SVG 完全满足需求，无需引入 D3.js 等重型库，保持代码轻量。

- 画布尺寸：800 × 500 px（固定）

- 布局草图（ASCII）：
  ```
  ┌──────────────────────────────────────────────────────┐
  │                                                      │
  │         空气                                         │
  │           \                                          │
  │            \ i₁                                      │
  │             \|                                       │
  │  ┌───────────┼──────────────────────┐                │
  │  │  玻璃      \                      │                │
  │  │             \ r₁                  │                │
  │  │              \i₂                  │                │
  │  └───────────────┼──────────────────┘                │
  │                  \                                   │
  │                   \ r₂                               │
  │                    \                                 │
  │                     \  ∥                             │
  │                      \                               │
  │                       空气                            │
  │                                                      │
  │              入射光线 ∥ 出射光线                      │
  │                                                      │
  │        [◀上一步]          [下一步▶]                   │
  └──────────────────────────────────────────────────────┘
  ```

- 关键实现要点：
  1. 状态机设计：
     - 当前步骤变量 `currentStep`（0~3）
     - 每个步骤对应一组可见元素列表
     - 切换步骤时，隐藏上一步骤独有的元素，显示新步骤独有的元素
     - 使用 CSS class `.step-hidden { opacity: 0; pointer-events: none; }` 控制显隐
     - 元素显隐使用 CSS transition（opacity 0.4s ease）实现平滑过渡

  2. 角度弧线绘制（SVG path）：
     - 使用 SVG `<path>` 的 `A`（椭圆弧）命令绘制
     - 入射角i₁：`M 330 130 A 40 40 0 0 0 298.6 145.6`（从法线上方到入射光线方向）
     - 折射角r₁：`M 330 200 A 30 30 0 0 0 347.7 185.0`（从法线下方到折射光线方向）
     - 入射角i₂：`M 389 240 A 30 30 0 0 1 361.3 255.0`（从法线上方到玻璃内光线方向）
     - 折射角r₂：`M 389 310 A 40 40 0 0 0 420.3 285.0`（从法线下方到出射光线方向）
     - 精确坐标通过三角函数计算：x = cx + r*cos(θ), y = cy + r*sin(θ)

  3. 箭头标记（SVG marker）：
     - 定义 `<marker id="scene1-arrow">` 在 `<defs>` 中
     - 光线线段设置 `marker-end="url(#scene1-arrow)"`
     - 箭头颜色 #1565c0，大小适中（markerWidth=10, markerHeight=7）

  4. 按钮交互：
     - 按钮使用 SVG `<rect>` + `<text>` 组合
     - 点击事件绑定到 `<g>` 元素
     - 步骤0时"上一步"按钮置灰（fill=#bdbdbd, text=#757575），步骤3时"下一步"按钮置灰
     - 按钮 hover 效果：rect fill 变深

  5. 高亮效果：
     - 步骤3时入射光线和出射光线线宽从 2.5px 增至 3.5px
     - 使用 CSS class `.highlight { stroke-width: 3.5px; }` 切换

- ID 命名规范：所有交互元素 ID 以 `scene1-` 为前缀
  - 玻璃砖：`scene1-glass`
  - 入射光线：`scene1-incident-ray`
  - 上表面法线：`scene1-normal-top`
  - 入射角弧线：`scene1-arc-i1`
  - 折射光线：`scene1-refract-ray`
  - 下表面法线：`scene1-normal-bottom`
  - 出射光线：`scene1-emerge-ray`
  - 按钮上一步：`scene1-btn-prev`
  - 按钮下一步：`scene1-btn-next`
  - 各标签和弧线均加 `scene1-` 前缀

- IIFE 隔离：所有 JS 代码包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染

- JS 中用 `document.getElementById('scene1-xxx')` 获取元素，不使用 `querySelectorAll` 配合全局 class
