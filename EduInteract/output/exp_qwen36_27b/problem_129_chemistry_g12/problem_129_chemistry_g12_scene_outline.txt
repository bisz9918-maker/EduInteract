    **题目原文：**

    "长征"火箭发射使用的燃料是偏二甲肼(C₂H₈N₂)，并使用四氧化二氮作为氧化剂，这种组合的两大优点是既能在短时间内产生巨大能量将火箭送上太空，产物又不污染空气(产物都是空气成分)。某校外研究性学习小组拟将此原理设计为原电池，如图所示，结合学习过的电化学原理分析其设计方案，下列说法正确的是( )

    A. B为正极
    B. 从a口通入四氧化二氮气体
    C. 从d口排出的是NO气体
    D. A极发生的电极反应式：C₂H₈N₂－16e⁻＋8H₂O===CO₂＋N₂＋16H⁺

    **题目分析：**

    本题考查原电池的工作原理，核心知识点包括：
    1. 根据电子流向判断正负极（电子从负极流向正极）
    2. 负极发生氧化反应（燃料被氧化），正极发生还原反应（氧化剂被还原）
    3. 电极反应式的书写与配平（酸性介质中）
    4. 产物判断（题目提示"产物都是空气成分"，即N₂、CO₂、H₂O）

    **整体讲解思路：**

    首先引导学生观察原电池装置图，从电子流向入手判断正负极；然后根据正负极性质推断气体进出口；最后通过电极反应式的配平验证选项。图示规划为两个scene：Scene 1展示原电池装置结构与工作原理（电子流向、正负极、气体流向）；Scene 2展示电极反应式的逐步配平过程。

    **图示规划说明：**

    - Scene 1：原电池装置交互式图示，通过分步导航逐步揭示电子流向、正负极判断、气体进出口
    - Scene 2：电极反应式配平演示，分步展示负极和正极反应式的推导过程

    **Scene 2 教学说明：**

    本图示用于详细讲解电极反应式的配平过程，并验证选项D的正误。

    **讲解步骤：**

    1. **步骤0——明确环境**：强调电解质为H₂SO₄溶液，即**酸性介质**。在酸性介质中配平电极反应式时，用H⁺和H₂O来配平H和O，不能用OH⁻。

    2. **步骤1——确定反应物**：
    - 负极（A极）：燃料偏二甲肼C₂H₈N₂被氧化
    - 正极（B极）：氧化剂四氧化二氮N₂O₄被还原

    3. **步骤2——确定产物**：
    - 根据题目"产物都是空气成分"，推断产物为CO₂、N₂、H₂O
    - 负极：C₂H₈N₂中的C被氧化为CO₂（C从-1价→+4价），N被氧化为N₂（N从-2价→0价）
    - 正极：N₂O₄中的N被还原为N₂（N从+4价→0价）

    4. **步骤3——配平电极反应式**：

    **负极反应式配平：**
    - 先写骨架：C₂H₈N₂ → CO₂ + N₂
    - 配C：C₂H₈N₂ → 2CO₂ + N₂
    - 配N：已平衡（左右各2个N）
    - 算电子转移：C从-1→+4，每个C失5e⁻，2个C共失10e⁻；N从-2→0，每个N失2e⁻，2个N共失4e⁻；总计失16e⁻
    - 加电子：C₂H₈N₂ → 2CO₂ + N₂ + 16e⁻
    - 酸性介质配电荷（右边加16H⁺）：C₂H₈N₂ → 2CO₂ + N₂ + 16H⁺ + 16e⁻
    - 配H和O（左边加4H₂O）：C₂H₈N₂ + 4H₂O → 2CO₂ + N₂ + 16H⁺ + 16e⁻
    - 验证：左边C=2,H=16,N=2,O=4；右边C=2,H=16,N=2,O=4 ✓

    **正极反应式配平：**
    - 先写骨架：N₂O₄ → N₂
    - 算电子转移：N从+4→0，每个N得4e⁻，2个N共得8e⁻
    - 加电子：N₂O₄ + 8e⁻ → N₂
    - 酸性介质配电荷（左边加8H⁺）：N₂O₄ + 8H⁺ + 8e⁻ → N₂
    - 配O（右边加4H₂O）：N₂O₄ + 8H⁺ + 8e⁻ → N₂ + 4H₂O
    - 验证：左边N=2,O=4,H=8；右边N=2,O=4,H=8 ✓

    5. **步骤4——验证选项D**：
    - 选项D给出的反应式：C₂H₈N₂ - 16e⁻ + 8H₂O → CO₂ + N₂ + 16H⁺
    - 错误1：CO₂系数应为2（配C原子）
    - 错误2：H₂O系数应为4而非8（配H和O原子）
    - **正确反应式**：C₂H₈N₂ + 4H₂O - 16e⁻ → 2CO₂ + N₂ + 16H⁺
    - 故选项D错误

    **总反应式：** 负极×1 + 正极×2（使电子数相等为16e⁻）
    C₂H₈N₂ + 2N₂O₄ → 2CO₂ + 3N₂ + 4H₂O

    **课堂互动建议：** 配平时可让学生先尝试自己配平，再对照图示逐步验证。重点强调酸性介质中用H⁺和H₂O配平的方法。

    **总结与答案：**

    **正确答案：A**

    **各选项判断汇总：**

    | 选项 | 内容 | 判断 | 理由 |
    |------|------|------|------|
    | A | B为正极 | ✓正确 | 电子从A流向B，B为电子流入极，即正极 |
    | B | 从a口通入四氧化二氮 | ✗错误 | a口对应负极A，应通入燃料C₂H₈N₂ |
    | C | 从d口排出NO气体 | ✗错误 | 产物为空气成分，应排出N₂和H₂O，不含NO |
    | D | A极反应式H₂O系数为8 | ✗错误 | 正确系数为4，且CO₂系数应为2 |

    **核心知识点总结：**
    1. 原电池中，电子从负极流向正极（外电路）
    2. 负极发生氧化反应（失电子），正极发生还原反应（得电子）
    3. 燃料电池中，燃料在负极被氧化，氧化剂在正极被还原
    4. 酸性介质中电极反应式用H⁺和H₂O配平
    5. 配平时遵循：原子守恒、电荷守恒、电子守恒

    **教学建议：**
    - 本题是典型的燃料电池原电池题，可类比氢氧燃料电池帮助学生理解
    - 强调"产物都是空气成分"这一关键信息对判断产物的作用
    - 电极反应式配平是难点，建议多练习类似题目巩固
