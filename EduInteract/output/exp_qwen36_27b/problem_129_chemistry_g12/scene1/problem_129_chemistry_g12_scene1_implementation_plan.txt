[技术实现]
- JS 库选择：原生 SVG（简单几何图形+标注，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌──────────────────────────────────────────────┐
  │                                              │
  │              ⚡灯泡(400,50)                   │
  │             /          \                     │
  │      e⁻→   /            \   ←e⁻              │
  │    ────────              ────────            │
  │   ↑A       │              │       B↑         │
  │  c←        │              │        →d        │
  │   │        │              │        │         │
  │   │  电极A │   H₂SO₄      │  电极B │         │
  │   │        │              │        │         │
  │   │        │              │        │         │
  │   └────────┴──────────────┴────────┘         │
  │   a→                              ←b         │
  │                                              │
  │   通入C₂H₈N₂              通入N₂O₄           │
  │   排出CO₂、N₂             排出N₂、H₂O        │
  │                                              │
  │              步骤 0 / 4                       │
  │         [◀ 上一步]  [下一步 ▶]                │
  └──────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. **状态机设计**：用变量 `currentStep` (0-4) 管理当前步骤，每个步骤对应一组可见/隐藏的元素
  2. **元素显隐控制**：使用 SVG `<g>` 分组，通过 `display: none` / `display: block` 或 `opacity` 动画控制各步骤元素
  3. **灯泡发光效果**：步骤1起，在灯泡周围添加 `<circle>` 光晕元素，使用 `opacity` 从0到0.4的过渡动画（0.5s ease-in）
  4. **箭头颜色切换**：步骤3/4时，将入口/出口箭头的 `stroke` 属性从黑色切换为绿色/橙色，使用 CSS transition
  5. **按钮状态管理**：步骤0时"上一步"按钮 `disabled`，步骤4时"下一步"按钮 `disabled`
  6. **坐标计算**：所有元素使用绝对坐标定位，导线使用 `<polyline>` 或 `<path>` 绘制折线
  7. **电子流向箭头**：使用 SVG `<marker>` 定义箭头头部，蓝色粗线 `stroke-width="3"`
  8. **文字渲染**：使用 `<text>` 元素，`text-anchor` 控制对齐，`dominant-baseline` 控制垂直对齐
- ID 命名规范：所有交互元素 ID 以 `scene1-` 为前缀，如 `scene1-electrode-a`、`scene1-electrode-b`、`scene1-bulb`、`scene1-wire-a`、`scene1-wire-b`、`scene1-step-indicator`、`scene1-btn-prev`、`scene1-btn-next`、`scene1-e-flow-left`、`scene1-e-flow-right`、`scene1-label-negative`、`scene1-label-positive` 等
- IIFE 隔离：所有 JS 代码包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染
