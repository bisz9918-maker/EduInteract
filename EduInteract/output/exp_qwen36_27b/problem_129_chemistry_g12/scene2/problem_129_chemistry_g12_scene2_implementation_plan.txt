[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无需外部库，化学方程式用SVG `<tspan>` 实现上下标）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+  y=0
  |              H₂SO₄溶液（酸性介质）                |  y=72
  +----------------------+---------------------------+
  |   负极（A极）        |       正极（B极）          |  y=42
  |                      |                           |
  |  [左栏内容区]         |    [右栏内容区]            |  y=85~430
  |  反应物/产物/配平     |    反应物/产物/配平        |
  |                      |                           |
  +----------------------+---------------------------+
  |         总反应式（步骤4显示）                      |  y=340
  |  ┌──────────────────────────────────────┐        |
  |  │  选项D判断框（步骤4显示）              │        |  y=370~425
  |  └──────────────────────────────────────┘        |
  +--------------------------------------------------+  y=430
  |  [◀ 上一步]    步骤 X/4    [下一步 ▶]            |  y=460~490
  +--------------------------------------------------+  y=500
  ```
- 关键实现要点：
  1. 状态机设计：5个状态（step 0~4），每个状态对应一组SVG元素的显示/隐藏
  2. 化学公式渲染：使用SVG `<text>` + `<tspan baseline-shift="sub" font-size="0.75em">` 实现下标（如H₂O中的2），`<tspan baseline-shift="super" font-size="0.75em">` 实现上标（如H⁺中的+）
  3. 动画曲线：新元素出现使用CSS transition opacity 0.4s ease-in，配平系数出现使用CSS @keyframes pulse（放大1.2倍再恢复，0.3s）
  4. 事件绑定：按钮点击事件绑定到 `scene2-prev-btn` 和 `scene2-next-btn`，更新 `currentStep` 变量并调用 `renderStep(step)`
  5. 步骤渲染函数 `renderStep(step)`：根据step值，设置各元素组的 `display` 或 `opacity` 属性
  6. 按钮状态管理：step=0时禁用上一步，step=4时禁用下一步，通过 `pointer-events: none` 和 `opacity: 0.4` 实现
- ID 命名规范：所有交互元素ID以 `scene2-` 为前缀
  - `scene2-svg`：主SVG容器
  - `scene2-step-group-0` ~ `scene2-step-group-4`：各步骤元素组
  - `scene2-prev-btn`：上一步按钮
  - `scene2-next-btn`：下一步按钮
  - `scene2-step-indicator`：步骤指示器文本
  - `scene2-left-panel`：左栏背景
  - `scene2-right-panel`：右栏背景
  - `scene2-divider`：分隔虚线
  - `scene2-title-neg`：负极标题
  - `scene2-title-pos`：正极标题
  - `scene2-electrolyte`：电解质标注
  - `scene2-overall-reaction`：总反应式
  - `scene2-option-d-box`：选项D判断框
- IIFE 隔离：所有JS代码包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染
