    **题目原文：**

    分子式为C$_{5}$H$_{11}$Cl的卤代烃，其分子中含有两个—CH$_{3}$，两个—CH$_{2}$—，一个—CH—和一个—Cl，它可能的结构有（  ）

    A. 2种  B. 3种  C. 4种  D. 5种

    **题目分析：**

    本题考察卤代烃的同分异构体计数。关键在于：
    1. 分子式为C$_{5}$H$_{11}$Cl，即5个碳原子、11个氢原子、1个氯原子
    2. 基团约束：两个—CH$_{3}$（甲基）、两个—CH$_{2}$—（亚甲基）、一个—CH—（次甲基）、一个—Cl（氯原子）
    3. 验证原子守恒：2×CH$_{3}$ + 2×CH$_{2}$ + 1×CH + 1×Cl = 5C + (6+4+1)H + 1Cl = C$_{5}$H$_{11}$Cl ✓

    **整体讲解思路：**

    采用"碳骨架分类→Cl定位→条件验证"的三步法：
    1. 首先枚举5个碳原子的所有碳骨架类型（直链、单支链、双支链）
    2. 在每种骨架上尝试放置Cl原子，生成所有可能的卤代烃结构
    3. 逐一验证每种结构的基团组成是否满足题目条件
    4. 统计符合条件的结构数目，得出答案

    **图示规划说明：**

    规划两个图示：
    - Scene 1：碳骨架分类与Cl放置分析——分步展示三种碳骨架，在每种骨架上标注Cl的可能位置，并验证基团组成
    - Scene 2：符合条件的结构汇总——清晰展示全部4种符合条件的结构式，便于学生对照记忆
    </TEXT_1>

    **Scene 1 教学说明：碳骨架分类与Cl定位分析**

    **引导思路：**

    1.  **第一步：理解碳骨架分类**
        - 引导学生思考：5个碳原子可以组成几种不同的碳链结构？
        - 展示三种碳骨架：直链（正戊烷）、单支链（异戊烷）、双支链（新戊烷）
        - 强调：碳骨架不同，即使Cl放在"相同位置"，得到的也是不同的化合物

    2.  **第二步：直链骨架分析（正戊烷 C-C-C-C-C）**
        - 引导学生观察对称性：C1和C5等效，C2和C4等效，C3独立
        - 因此只有3种不等效的Cl放置位置
        - 逐一验证：
        - Cl在C1位：Cl-CH$_{2}$-CH$_{2}$-CH$_{2}$-CH$_{2}$-CH$_{3}$ → CH$_{3}$×1、CH$_{2}$×4 → ✗不符合
        - Cl在C2位：CH$_{3}$-CH(Cl)-CH$_{2}$-CH$_{2}$-CH$_{3}$ → CH$_{3}$×2、CH$_{2}$×2、CH×1 → ✓符合
        - Cl在C3位：CH$_{3}$-CH$_{2}$-CH(Cl)-CH$_{2}$-CH$_{3}$ → CH$_{3}$×2、CH$_{2}$×2、CH×1 → ✓符合
        - **直链骨架贡献2种符合条件的结构**

    3.  **第三步：异戊烷骨架分析（2-甲基丁烷）**
        - 骨架结构：
        ```
            C
            |
        C-C-C-C
        ```
        - 标注4个不等效位置：支链甲基、主链C2（连接支链的碳）、主链C3、主链末端甲基
        - 逐一验证：
        - Cl在支链甲基上：(ClCH$_{2}$)(CH$_{3}$)CH-CH$_{2}$-CH$_{3}$ → CH$_{3}$×2、CH$_{2}$×2、CH×1 → ✓符合
        - Cl在主链C2上：CH$_{3}$-C(Cl)(CH$_{3}$)-CH$_{2}$-CH$_{3}$ → 该碳为季碳，无CH → ✗不符合
        - Cl在主链C3上：CH$_{3}$-CH(CH$_{3}$)-CH(Cl)-CH$_{3}$ → CH$_{3}$×3、CH×2 → ✗不符合
        - Cl在主链末端甲基上：CH$_{3}$-CH(CH$_{3}$)-CH$_{2}$-CH$_{2}$Cl → CH$_{3}$×2、CH$_{2}$×2、CH×1 → ✓符合
        - **异戊烷骨架贡献2种符合条件的结构**

    4.  **第四步：新戊烷骨架分析（2,2-二甲基丙烷）**
        - 骨架结构：中心碳连接4个甲基
        - 所有4个甲基等效，只有1种Cl放置位置
        - Cl在任意甲基上：Cl-CH$_{2}$-C(CH$_{3}$)$_{3}$ → CH$_{3}$×3、CH$_{2}$×1 → ✗不符合
        - **新戊烷骨架贡献0种符合条件的结构**

    5.  **第五步：汇总结论**
        - 直链骨架：2种
        - 异戊烷骨架：2种
        - 新戊烷骨架：0种
        - **总计：4种，答案选C**

    **关键教学点：**
    - 碳骨架分类是解题的第一步，必须穷尽所有可能的碳链结构
    - 利用对称性判断等效位置，避免重复计数
    - 基团组成验证是筛选的关键步骤，不能遗漏

    **Scene 2 教学说明：结构汇总展示**

    **引导思路：**

    1.  **逐一展示每种结构**
        - 引导学生观察每种结构的碳骨架类型和Cl的位置
        - 强调结构①和②属于直链骨架，结构③和④属于异戊烷骨架
        - 注意结构①和②虽然Cl位置不同，但碳骨架相同；结构③和④虽然都属于异戊烷骨架，但Cl位置不同

    2.  **基团组成验证**
        - 对每种结构，引导学生数出CH$_{3}$、CH$_{2}$、CH、Cl的数量
        - 确认每种结构都满足题目条件：CH$_{3}$×2、CH$_{2}$×2、CH×1、Cl×1

    3.  **系统命名（拓展）**
        - 结构①：2-氯戊烷（Cl在直链第2位）
        - 结构②：3-氯戊烷（Cl在直链第3位）
        - 结构③：1-氯-2-甲基丁烷（Cl在支链甲基上，主链为丁烷）
        - 结构④：1-氯-3-甲基丁烷（Cl在主链末端甲基上，主链为丁烷）
        - 命名规则：选择含Cl的最长碳链为主链，编号使Cl的位置编号最小

    4.  **总结与答案**
        - 4种符合条件的结构，答案选C
        - 强调解题方法：碳骨架分类→Cl定位→条件验证
        - 提醒学生注意对称性判断等效位置，避免重复或遗漏

    **课堂讲解建议：**
    - 在Scene 1分析完所有骨架后，切换到Scene 2进行汇总
    - 让学生尝试独立写出4种结构的结构式，再与图示对照
    - 可提问：如果题目条件改为"三个CH$_{3}$"，答案会怎样变化？引导学生思考条件变化对结果的影响
