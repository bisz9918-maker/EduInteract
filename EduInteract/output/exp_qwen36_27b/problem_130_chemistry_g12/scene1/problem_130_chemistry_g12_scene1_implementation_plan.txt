# Scene 1 Implementation Plan

<SCENE_VISION_STORYBOARD_AND_TECHNICAL_PLAN>

[图示主题与整合说明]
- 本图示主题：碳骨架分类与Cl原子定位分析——逐步展示三种碳骨架上Cl的可能位置及条件验证
- 整合的步骤/概念：
  1. 碳骨架分类（正戊烷/异戊烷/新戊烷三种C5骨架）
  2. 各骨架上Cl的等效位置标注（识别不等效氢）
  3. 基团组成验证（检查CH₃、CH₂、CH、Cl数量是否匹配题目条件）
  4. 符合条件的结构筛选（最终得出4种结构）
- 教学价值：教师可通过分步导航，引导学生从碳骨架分类入手，逐步分析每种骨架上Cl的可能位置，通过基团验证筛选符合条件的结构，最终得出答案。分步设计帮助学生建立系统性的有机化学结构分析思维。

步骤1：聚焦直链骨架（正戊烷）
- 直链骨架放大移至左侧区域（中心约250,220），其他骨架缩小置灰移至右下角
- 标注5个碳的位置编号：C1(150,200)、C2(200,200)、C3(250,200)、C4(300,200)、C5(350,200)
- 标注3个不等效位置组：
  - 位置①：C1/C5等效（末端甲基），用蓝色椭圆框标注
  - 位置②：C2/C4等效（仲碳），用蓝色椭圆框标注
  - 位置③：C3（中心仲碳），用蓝色椭圆框标注
- 右侧显示验证表格，逐行展示3种Cl取代情况：
  - 行1：Cl在C1/C5 → CH₃×1, CH₂×4, CH×0, Cl×1 → ✗不符合（CH₃不足）
  - 行2：Cl在C2/C4 → CH₃×2, CH₂×2, CH×1, Cl×1 → ✓符合（绿色高亮）
  - 行3：Cl在C3 → CH₃×2, CH₂×2, CH×1, Cl×1 → ✓符合（绿色高亮）
- 在骨架图上用绿色Cl圆标记符合条件的C2和C3位置
- 步骤指示"步骤 2/5"

步骤2：聚焦异戊烷骨架（2-甲基丁烷）
- 异戊烷骨架放大移至左侧区域（中心约250,220），其他骨架缩小置灰
- 异戊烷骨架坐标：
  - C主链：C1(180,220)、C2(230,220)、C3(280,220)、C4(330,220)
  - C支链：C5(230,170)（连在C2上）
- 标注4个不等效位置：
  - 位置①：C1/C5等效（两个连在C2上的甲基），蓝色椭圆框
  - 位置②：C2（叔碳），蓝色椭圆框
  - 位置③：C3（仲碳），蓝色椭圆框
  - 位置④：C4（末端甲基），蓝色椭圆框
- 右侧验证表格展示4种Cl取代情况：
  - 行1：Cl在C1/C5 → CH₃×2, CH₂×2, CH×1, Cl×1 → ✓符合（1-氯-2-甲基丁烷）
  - 行2：Cl在C2 → CH₃×3, CH₂×1, CH×0, Cl×1 → ✗不符合（CH₃过多）
  - 行3：Cl在C3 → CH₃×3, CH₂×0, CH×2, Cl×1 → ✗不符合（CH₃过多）
  - 行4：Cl在C4 → CH₃×2, CH₂×2, CH×1, Cl×1 → ✓符合（1-氯-3-甲基丁烷）

关键实现要点：

1. 状态机设计：
   - 当前步骤状态：currentStep（0~4）
   - 状态切换函数：goToStep(step)
   - 每步渲染函数：renderStep0() ~ renderStep4()
   - 步骤切换时清除主图区内容，重新渲染当前步骤元素

2. 碳骨架绘制函数：
   - drawLinearSkeleton(cx, cy, scale)：直链骨架，cx/cy为中心坐标，scale为缩放比例
   - drawIsoSkeleton(cx, cy, scale)：异戊烷骨架
   - drawNeoSkeleton(cx, cy, scale)：新戊烷骨架
