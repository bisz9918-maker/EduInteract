[图示主题与整合说明]
- 本图示主题：4种符合条件的卤代烃结构式汇总展示
- 整合的步骤/概念：分子式为C₅H₁₁Cl且含有两个—CH₃、两个—CH₂—、一个—CH—和一个—Cl的所有同分异构体（共4种），逐一展示其结构式、系统命名和基团组成验证

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位置(260,455)-(390,485)，点击回退到上一步骤，步骤0时禁用
  - 「下一步 ▶」按钮：位置(410,455)-(540,485)，点击进入下一步骤，步骤5时变为「重新开始」
  - 步骤指示文字：位置(400,470)，显示"X/5"格式
- 教师操作流程：
  1. 图示加载后显示4个空白结构框，教师可先让学生猜测可能的结构数量
  2. 点击「下一步」逐一展示每种结构，配合讲解碳骨架类型和氯原子位置
  3. 每展示一种结构时，引导学生验证基团组成是否符合题目条件
  4. 到达步骤5时，4种结构全部高亮，显示答案"4种，选C"
  5. 可随时点击「上一步」回退复习，或点击「重新开始」从头演示

[技术实现]
- JS 库选择：原生 SVG（化学结构式为简单几何图形+文字，无需复杂库）
- 画布尺寸：800 × 500 px（SVG viewBox="0 0 800 500"）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌──────────────────────────────────────────────────────┐
  │              符合条件的4种结构                        │  y=10~40
  ├──────────────────────┬───────────────────────────────┤
  │ ① 直链骨架           │ ② 直链骨架                    │  y=55~215
  │  CH3-CH(Cl)-CH2-CH2-CH3 │  CH3-CH2-CH(Cl)-CH2-CH3    │
  │  2-氯戊烷             │  3-氯戊烷                    │
  │  CH3×2✓ CH2×2✓ CH×1✓ Cl×1✓ │ CH3×2✓ CH2×2✓ CH×1✓ Cl×1✓│
  ├──────────────────────┼───────────────────────────────┤
  │ ③ 异戊烷骨架          │ ④ 异戊烷骨架                  │  y=235~395
  │    CH3                  │    CH3                      │
  │    |                    │    |                        │
  │  ClCH2-CH-CH2-CH3      │  CH3-CH-CH2-CH2Cl          │
  │  1-氯-2-甲基丁烷       │  1-氯-3-甲基丁烷            │
  │  CH3×2✓ CH2×2✓ CH×1✓ Cl×1✓ │ CH3×2✓ CH2×2✓ CH×1✓ Cl×1✓│
  ├──────────────────────┴───────────────────────────────┤
  │                    4种，选C                           │  y=405~440
  ├──────────────────────────────────────────────────────┤
  │     ◀ 上一步          1/5         下一步 ▶           │  y=440~490
  └──────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：currentStep (0~5)，每个步骤对应一组视觉状态
  2. 结构框状态管理：每个框有3种状态——空白（灰色边框）、高亮（蓝色边框+内容）、已展示（灰色边框+半透明内容）
  3. 化学结构式绘制：使用SVG `<line>` 绘制碳链键，`<text>` 标注基团，下标用 `<tspan baseline-shift="sub" font-size="75%">` 实现
  4. 动画过渡：框边框颜色和高亮背景使用CSS transition（0.3s ease），结构内容出现使用opacity动画
  5. 事件绑定：按钮点击事件切换currentStep，更新所有结构框的视觉状态
  6. 步骤0特殊处理：框内显示"点击下一步查看"提示文字，步骤1时替换为结构式
  7. 步骤5特殊处理：所有框绿色高亮，答案标签淡入显示，"下一步"按钮文字变为"重新开始"
  8. 重新开始逻辑：点击后currentStep=0，所有框恢复空白状态，答案标签隐藏

- ID 命名规范：所有交互元素ID以 `scene2-` 为前缀
  - 结构框：`scene2-box-1` ~ `scene2-box-4`
  - 结构内容组：`scene2-content-1` ~ `scene2-content-4`
  - 系统命名：`scene2-name-1` ~ `scene2-name-4`
  - 基团验证：`scene2-verify-1` ~ `scene2-verify-4`
  - 答案标签：`scene2-answer`
  - 上一步按钮：`scene2-prev-btn`
  - 下一步按钮：`scene2-next-btn`
  - 步骤指示：`scene2-step-indicator`
  - 提示文字：`scene2-hint-1` ~ `scene2-hint-4`

- IIFE 隔离：所有JS代码包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染
- 下标实现：SVG中CH₃用 `<text>CH<tspan baseline-shift="sub" font-size="75%">3</tspan></text>` 格式
