    **题目原文：**

    如图所示，将两烧杯用导线如图相连，Pt、Cu、Zn、C分别为四个电极，当闭合开关后，则以下叙述正确的是（ ）

    A. C电极为电解池的阳极
    B. Cu电极附近OH⁻浓度增大
    C. Na⁺移向Pt电极
    D. Pt电极上有O₂生成

    **题目分析：**

    本题考察原电池与电解池的组合装置分析。核心知识点包括：
    1. 原电池与电解池的判断
    2. 电极名称的确定（正负极、阴阳极）
    3. 电极反应式的书写
    4. 离子移动方向的判断

    **整体讲解思路：**

    首先引导学生观察装置图，判断哪部分是原电池、哪部分是电解池。右侧烧杯中Zn和C在稀H₂SO₄中，Zn比C活泼且能与酸反应，故右侧为原电池；左侧烧杯由原电池供电，为电解池。

    然后确定各电极名称：原电池中Zn为负极、C为正极；电解池中与负极相连的Pt为阴极、与正极相连的Cu为阳极。

    接着分析各电极反应：
    - Zn（负极）：Zn - 2e⁻ → Zn²⁺
    - C（正极）：2H⁺ + 2e⁻ → H₂↑
    - Pt（阴极）：2H₂O + 2e⁻ → H₂↑ + 2OH⁻
    - Cu（阳极）：Cu - 2e⁻ → Cu²⁺（活性电极自身被氧化）

    最后判断离子移动方向：阳离子（Na⁺）向阴极（Pt）移动，阴离子（Cl⁻）向阳极（Cu）移动。

    **图示规划说明：**

    规划一个交互式图示，通过分步按钮导航，从原始装置图逐步展示原电池/电解池的判断、电极名称标注、电子/离子流向、电极反应式，最终得出正确答案。

    **教学说明：**

    本图示通过分步导航，帮助学生系统理解原电池-电解池组合装置的分析方法。

    **步骤0→步骤1：装置识别**
    引导学生观察装置，思考：哪个烧杯能自发进行氧化还原反应？右侧烧杯中Zn能与稀H₂SO₄反应（Zn + H₂SO₄ → ZnSO₄ + H₂↑），故右侧为原电池；左侧烧杯由原电池供电，为电解池。

    **步骤1→步骤2：电极判断**
    - 原电池中，活泼金属Zn为负极，惰性电极C为正极
    - 电解池中，与原电池负极相连的电极为阴极（Pt），与原电池正极相连的电极为阳极（Cu）
    - 电子流向：从负极（Zn）经导线流向阴极（Pt），从阳极（Cu）经导线流向正极（C）

    **步骤2→步骤3：离子移动**
    在电解池中，阳离子向阴极移动，阴离子向阳极移动。因此Na⁺向Pt电极（阴极）移动，Cl⁻向Cu电极（阳极）移动。在原电池中，H⁺向正极（C）移动。

    **步骤3→步骤4：电极反应与选项分析**
    各电极反应式：
    1. Zn（负极）：Zn - 2e⁻ → Zn²⁺
    2. C（正极）：2H⁺ + 2e⁻ → H₂↑
    3. Pt（阴极）：2H₂O + 2e⁻ → H₂↑ + 2OH⁻
    4. Cu（阳极）：Cu - 2e⁻ → Cu²⁺（注意：Cu是活性电极，自身被氧化，而非Cl⁻放电）

    选项分析：
    - A错误：C是原电池的正极，不是电解池的电极
    - B错误：Cu是阳极，Cu被氧化为Cu²⁺，不产生OH⁻
    - C正确：Na⁺向阴极（Pt）移动
    - D错误：Pt是阴极，产生H₂而非O₂

    **课堂讲解建议：**
    1. 先让学生独立判断原电池和电解池，再逐步验证
    2. 强调活性电极（Cu）作阳极时的特殊性——电极自身被氧化
    3. 提醒学生注意离子移动方向的规律：阳离子向阴极，阴离子向阳极
