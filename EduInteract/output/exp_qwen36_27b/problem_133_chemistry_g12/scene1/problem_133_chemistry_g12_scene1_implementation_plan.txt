[图示主题与整合说明]
- 本图示主题：密闭容器中活塞两侧气体体积变化的三阶段演示
- 整合的步骤/概念：初始状态（体积比1:3）→ 反应过程（点燃引爆，2H₂+O₂→2H₂O(l)）→ 最终状态（活塞居中，体积比1:1）→ 两种过量情况的代数推导（H₂过量得7:2，O₂过量得4:5）
- 教学价值：教师可按教学节奏逐步展开，先展示物理过程（活塞移动），再引导学生理解化学反应对气体体积的影响，最后通过代数推导得出两种可能的体积比，帮助学生建立"化学计量→体积变化→力学平衡"的跨学科思维

[技术实现]
- JS 库选择：原生 SVG + CSS Transition（无需外部库，简单几何图形和文本完全可用原生SVG实现，活塞移动用CSS transition实现平滑动画，火焰效果用SVG SMIL动画或CSS keyframes实现）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+  y=0
  |                                                  |
  |  +--------------------------------------------+  |  y=100
  |  |  空气  |        H₂、O₂的混合气             |  |
  |  |        |                                   |  |
  |  |        |        (火焰/方程式)               |  |
  |  |        |                                   |  |
  |  |        |      (推导文本框)                  |  |
  |  |        |                                   |  |
  |  +--------+-----------------------------------+  |  y=350
  |  |  {1}   |           {3}                     |  |  大括号
  |  |   1    |            3                      |  |  体积标注
  |  | 活塞   |                                   |  |
  |  +--------+-----------------------------------+  |
  |                    (提示文字)                     |  y=430
  |                                                  |
  |     [◀ 上一步]    步骤 0/4    [下一步 ▶]         |  y=460
  |                                                  |
  +--------------------------------------------------+  y=500
  ```
- 关键实现要点：
  1. **状态机设计**：用变量 `currentStep` (0~4) 管理当前步骤，每个步骤对应一组元素的显示/隐藏/位置状态
  2. **活塞移动动画**：用 CSS `transition: x 0.8s ease-in-out` 实现活塞从x=240到x=400的平滑移动
  3. **区域填充联动**：活塞移动时，左右填充区域的宽度同步变化（左侧width = pistonX - 80，右侧x = pistonX，width = 720 - pistonX）
  4. **大括号动态生成**：用 SVG `<path>` 绘制大括号，根据活塞位置动态计算起点和终点
  5. **火焰效果**：用多个同心圆+径向渐变模拟火焰，配合 CSS `@keyframes` 实现呼吸闪烁动画（scale 和 opacity 交替变化）
  6. **推导文本框**：用 `<foreignObject>` 或纯 SVG `<text>` 多行文本实现，步骤3和步骤4切换时替换内容
  7. **按钮状态管理**：步骤0时"上一步"按钮disabled（opacity=0.5），步骤4时"下一步"按钮disabled
  8. **元素显隐**：用 CSS `opacity` 和 `visibility` 控制元素显示/隐藏，配合 transition 实现淡入淡出效果
