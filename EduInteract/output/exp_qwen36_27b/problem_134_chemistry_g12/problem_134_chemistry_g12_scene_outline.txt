    **题目原文：**

    有机物烃A、B和C的结构如下图，下列有关说法正确的是

    A．A的二氯代物结构有两种

    B．B的分子式为C₆H₁₂

    C．与C互为同分异构体且属于芳香烃的有机物可能使酸性高锰酸钾溶液褪色

    D．A、B、C中只有C的最简式为CH

    **题目分析：**

    本题考察学生对三种笼状烃（正四面体烷、棱柱烷、立方烷）的立体结构理解，以及基于结构推导分子式、同分异构体、二氯代物等性质的能力。

    - **A（正四面体烷）**：正四面体结构，4个顶点为碳原子，分子式C₄H₄
    - **B（棱柱烷）**：三棱柱结构，6个顶点为碳原子，分子式C₆H₆
    - **C（立方烷）**：立方体结构，8个顶点为碳原子，分子式C₈H₈

    **整体讲解思路：**

    1. 首先引导学生观察三个分子的立体结构，理解每个顶点代表一个碳原子，每个碳原子形成3个C-C键，剩余1个价键连接氢原子
    2. 推导各分子的分子式和最简式
    3. 逐项分析四个选项，重点讲解A的二氯代物数目和C的同分异构体

    **图示规划：**

    - Scene 1：三个分子的结构展示与分子式推导（分步交互）
    - Scene 2：选项分析——二氯代物与同分异构体（分步交互）

    **Scene 1 教学说明：**

    本图示帮助学生建立对三种笼状烃立体结构的直观认识，并推导其分子式。

    **讲解要点：**

    1. **引导学生观察结构**：让学生数出每个分子的顶点数（即碳原子数）和边数（即C-C键数）
       - A：4个顶点，6条边 → 4个碳原子
       - B：6个顶点，9条边 → 6个碳原子
       - C：8个顶点，12条边 → 8个碳原子

    2. **推导氢原子数**：每个碳原子在笼状结构中形成3个C-C键（因为每个顶点连接3条边），碳为四价，故每个碳原子还连接1个氢原子
       - A：4个H → C₄H₄
       - B：6个H → C₆H₆
       - C：8个H → C₈H₈

    3. **最简式对比**：三个分子的分子式分别为C₄H₄、C₆H₆、C₈H₈，化简后最简式均为CH
       - 由此可直接判断**选项D错误**（不是只有C的最简式为CH，三者都是）

    **过渡到下一场景**：接下来分析选项A（二氯代物）和选项C（同分异构体），需要更细致的结构分析。

    **Scene 2 教学说明：**

    本图示逐项分析四个选项，帮助学生理解每个选项的判断依据。

    **逐项讲解要点：**

    **选项A：A的二氯代物结构有两种**

    1. 正四面体烷C₄H₄中，4个碳原子完全等价（正四面体的对称性）
    2. 二氯代物即两个H被Cl取代：C₄H₂Cl₂
    3. 在正四面体中，任意两个顶点之间的关系完全相同（都是相邻的，边长相等）
    4. 通过旋转操作，任意两个顶点的位置都可以重合
    5. 因此，二氯代物只有**1种**结构
    6. **结论：选项A错误**

    **选项B：B的分子式为C₆H₁₂**

    1. 棱柱烷有6个碳原子（6个顶点）
    2. 每个碳原子形成3个C-C键，连接1个H
    3. 分子式为C₆H₆，不是C₆H₁₂
    4. **结论：选项B错误**

    **选项C：与C互为同分异构体且属于芳香烃的有机物可能使酸性高锰酸钾溶液褪色**

    1. 立方烷分子式为C₈H₈
    2. 寻找分子式为C₈H₈的芳香烃同分异构体
    3. 苯乙烯（C₆H₅-CH=CH₂）：分子式为C₈H₈，含苯环（芳香烃），含碳碳双键
    4. 碳碳双键可被酸性KMnO₄氧化，使溶液褪色
    5. **结论：选项C正确**

    **选项D：A、B、C中只有C的最简式为CH**

    1. A：C₄H₄ → 最简式CH
    2. B：C₆H₆ → 最简式CH
    3. C：C₈H₈ → 最简式CH
    4. 三者最简式相同，均为CH
    5. **结论：选项D错误**

    **课堂讲解建议：**

    - 在讲解选项A时，可让学生动手操作（如用模型或想象旋转），理解正四面体的对称性
    - 在讲解选项C时，可拓展介绍其他C₈H₈的芳香烃同分异构体（如乙苯C₆H₅-CH₂CH₃，但乙苯分子式为C₈H₁₀，不符合；邻二甲苯C₆H₄(CH₃)₂，分子式为C₈H₁₀，也不符合），强调苯乙烯是常见的C₈H₈芳香烃同分异构体
    - 总结：本题正确答案为**C**
