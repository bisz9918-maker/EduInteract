    **题目原文：**

    用如图所示装置分别进行如下实验，测定溶液导电性变化．以下哪个选项为导电性先增大后减弱的为（  ）

    A．向醋酸溶液中加入氨水
    B．向AgNO₃溶液中加入HCl
    C．向盐酸溶液中加入NaCl溶液
    D．向H₂SO₄溶液中加入BaCl₂溶液

    **题目分析：**

    本题考查溶液导电性与离子浓度的关系。溶液导电性取决于溶液中自由移动离子的浓度和所带电荷数。离子浓度越大，导电性越强。

    **解题关键：**
    - 理解弱电解质与强电解质的区别
    - 分析各选项中反应的离子方程式
    - 判断反应前后离子浓度的变化趋势

    **正确答案：A**

    - A选项：醋酸（弱电解质）+ 氨水（弱电解质）→ 醋酸铵（强电解质），离子浓度先大幅增加；过量氨水稀释溶液，导电性后减弱
    - B选项：Ag⁺ + Cl⁻ → AgCl↓，离子浓度持续减小，导电性一直减弱
    - C选项：两种强电解质混合，离子浓度持续增加或稳定，导电性不会减弱
    - D选项：Ba²⁺ + SO₄²⁻ → BaSO₄↓，离子浓度持续减小，导电性一直减弱

    **整体讲解思路：**
    1. 先展示实验装置，说明灯泡亮度反映溶液导电性强弱
    2. 用离子微观图示展示四个选项中离子浓度的变化过程
    3. 引导学生对比分析，找出"先增大后减弱"的选项

    **图示规划：**
    - Scene 1：实验装置图 + 导电原理说明（静态展示）
    - Scene 2：四个选项的离子变化对比图（分步导航，逐步展示每个选项的离子浓度变化）

    **Scene 2 教学说明：**

    本图示通过分步导航，逐一分析四个选项中离子浓度的变化趋势，最终对比得出结论。

    **讲解要点：**

    **选项A（正确答案）：**
    1. 醋酸（CH₃COOH）是弱电解质，部分电离：CH₃COOH ⇌ CH₃COO⁻ + H⁺，离子浓度低
    2. 氨水（NH₃·H₂O）也是弱电解质，部分电离：NH₃·H₂O ⇌ NH₄⁺ + OH⁻
    3. 两者反应：CH₃COOH + NH₃·H₂O → CH₃COONH₄ + H₂O
    4. 醋酸铵是强电解质，完全电离：CH₃COONH₄ → CH₃COO⁻ + NH₄⁺
    5. 离子浓度大幅增加，导电性增强（灯泡变亮）
    6. 继续加入过量氨水，溶液体积增大，离子被稀释，导电性略有下降（灯泡稍暗）
    7. **结论：导电性先增大后减弱 ✓**

    **选项B：**
    1. AgNO₃是强电解质，完全电离：AgNO₃ → Ag⁺ + NO₃⁻
    2. HCl是强电解质，完全电离：HCl → H⁺ + Cl⁻
    3. 反应：Ag⁺ + Cl⁻ → AgCl↓（沉淀）
    4. Ag⁺和Cl⁻结合成沉淀，离子浓度持续减小
    5. **结论：导电性一直减弱 ✗**

    **选项C：**
    1. HCl和NaCl都是强电解质
    2. 混合后无化学反应，离子浓度持续增加或保持稳定
    3. **结论：导电性不会减弱 ✗**

    **选项D：**
    1. H₂SO₄是强电解质：H₂SO₄ → 2H⁺ + SO₄²⁻
    2. BaCl₂是强电解质：BaCl₂ → Ba²⁺ + 2Cl⁻
    3. 反应：Ba²⁺ + SO₄²⁻ → BaSO₄↓（沉淀）
    4. Ba²⁺和SO₄²⁻结合成沉淀，离子浓度持续减小
    5. **结论：导电性一直减弱 ✗**

    **课堂讲解建议：**
    - 引导学生先写出各选项的离子方程式
    - 分析反应前后离子种类和数量的变化
    - 特别注意弱电解质与强电解质的区别
    - 强调"先增大后减弱"的关键：弱电解质反应生成强电解质，离子浓度先大幅增加；过量试剂稀释溶液，离子浓度后下降
