[图示主题与整合说明]
- 本图示主题：基于碳原子四价原则，逐步推断星际有机分子的碳链键型分布，并分析各选项
- 整合的步骤/概念：
  1. 球棍模型的结构识读（原子种类识别、碳链编号）
  2. 从C1端开始逐步推断每个碳碳键的类型（三键/单键交替）
  3. 标注①②③处的键型/原子特征
  4. 结合推断结果分析四个选项的正误
- 教学价值：教师可通过分步按钮引导学生逐步完成推理过程，从识读模型→逐碳推断键型→标注关键位置→分析选项，帮助学生理解碳原子四价原则在有机分子结构推断中的应用

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位置(300, 465)，尺寸(90, 25)，点击后返回上一步骤（步骤0时禁用）
  - 「下一步 ▶」按钮：位置(410, 465)，尺寸(90, 25)，点击后进入下一步骤（步骤10时禁用）
  - 步骤指示器：位置(395, 455)，显示"步骤 X / 10"文字
- 教师操作流程：
  1. 图示加载后显示步骤0（原始球棍模型），教师可点击「下一步 ▶」开始讲解
  2. 每点击一次「下一步 ▶」，图示进入下一步骤，显示对应的推理过程和视觉变化
  3. 教师可随时点击「◀ 上一步」回退到前一步骤进行复习
  4. 到达步骤10后，显示所有选项的判断结果，「下一步 ▶」按钮禁用
  5. 教师可配合推理提示框中的文字进行课堂讲解

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无需外部库，简单几何图形用SVG最适宜）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |                  推理提示框                       |  y=50-110
  |           (200,50)----------------(600,110)      |
  |                                                  |
  |   C1  C2  C3  C4  C5  C6  C7  C8   ③           |  y=175(标签)
  |   ●---●---●---●≡≡≡●---●≡≡≡●---●≡≡≡●    ⊘       |  y=200(碳链)
  |   |                                        |     |
  |   H                                       ③     |  y=235-245(标注)
  |   ○                                         ⊘    |  y=255(H/③原子)
  |                                                  |
  |           选项结果列表                            |  y=290-370
  |       (180,290)----------------(750,370)         |
  |                                                  |
  |  图例框                                          |  y=380-440
  |  +--------+                                      |
  |  | 白球=H |                                      |
  |  | 黑球=C |        ◀上一步  下一步▶              |  y=460-490
  |  | 斜纹=③ |                                      |
  |  +--------+                                      |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用全局变量`currentStep`（0-10）跟踪当前步骤，每个步骤对应一个渲染函数
  2. 键型渲染：
     - 单键：单条`<line>`元素
     - 三键：三条`<line>`元素，y坐标分别为196、200、204
     - 初始状态所有碳碳键为灰色单线，根据步骤动态更新
  3. 高亮效果：使用SVG `<circle>` 元素的`stroke`属性添加蓝色光晕（stroke="#1565c0", stroke-width="4"）
  4. 斜纹填充：使用SVG `<pattern>` 定义斜线图案，应用于③处原子
  5. 动画过渡：键型变化使用CSS transition（0.3s ease），高亮效果使用opacity渐变
  6. 事件绑定：按钮点击事件绑定到`goToStep(currentStep ± 1)`函数
  7. 步骤指示器：实时更新"步骤 X / 10"文字
- ID 命名规范：所有交互元素ID以`scene1-`为前缀
  - 碳原子：`scene1-c1` ~ `scene1-c8`
  - 氢原子：`scene1-h`
  - ③原子：`scene1-atom3`
  - 键：`scene1-bond-c1c2` ~ `scene1-bond-c7c8`、`scene1-bond-ch`、`scene1-bond-c8a3`
  - 标签：`scene1-label-c1` ~ `scene1-label-c8`、`scene1-label-h`
  - 标注：`scene1-mark-1`、`scene1-mark-2`、`scene1-mark-3`
  - 推理提示框：`scene1-hint-box`
  - 图例框：`scene1-legend`
  - 选项结果：`scene1-options`
  - 导航按钮：`scene1-prev-btn`、`scene1-next-btn`
  - 步骤指示器：`scene1-step-indicator`
- IIFE 隔离：所有JS代码包裹在`(function() { ... })()`中，避免全局污染
