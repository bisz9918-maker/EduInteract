[图示主题与整合说明]
- 本图示主题：豌豆遗传实验的四种处理流程总览
- 整合的步骤/概念：处理①（生长素处理得无籽果实）、处理②（杂交得有籽果实）、处理③（花药离体培养得单倍体）、处理④（秋水仙素处理得二倍体）的完整流程
- 教学价值：教师通过分步高亮四种处理方式，帮助学生逐一理解每种处理的含义、操作对象和结果，避免信息过载。流程图布局清晰展示从亲本植株到不同处理结果的逻辑关系。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位置(250,450)，大小120×40，点击回退到前一步状态，步骤0时禁用
  - 「下一步 ▶」按钮：位置(530,450)，大小120×40，点击前进到下一步状态，步骤4时禁用
  - 步骤指示器：位置(390,470)，显示当前步骤"步骤 X/4"
- 教师操作流程：
  1. 图示加载后显示步骤0（灰色低透明度框架），教师介绍题目背景
  2. 点击「下一步 ▶」进入步骤1，高亮处理①，教师讲解生长素处理得无籽果实的原理
  3. 点击「下一步 ▶」进入步骤2，高亮处理②，教师讲解杂交得有籽果实的原理
  4. 点击「下一步 ▶」进入步骤3，高亮处理③，教师讲解花药离体培养得单倍体的原理
  5. 点击「下一步 ▶」进入步骤4，高亮处理④，教师讲解秋水仙素处理得二倍体的原理
  6. 可随时点击「◀ 上一步」回退复习任意步骤

- JS 库选择：原生 SVG（简单流程图，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌──────────────────────────────────────────────────────────────────────┐
  │                                                                      │
  │  ┌──────────┐                          ┌──────────────┐              │

  │  │  (aabb)  │                          └──────────────┘              │
  │  │  [简图]   │                                                        │
  │  └─────┬─────┘                          ┌──────────────┐              │
  │        │ 处理② ──────────────→         │ 有种子豆荚   │              │
  │        │ (Y形汇合)                      └──────────────┘              │
  │  ┌─────┴─────┐                                                        │

  │  │  (AABB)   │  处理③ ──────→ ┌──────────┐ 处理④ ──→ ┌──────────┐   │

  │                                                                      │
  │                    ┌──────────┐              ┌──────────┐           │
  │                    │◀ 上一步  │              │下一步 ▶  │           │
  │                    └──────────┘              └──────────┘           │
  └──────────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：维护当前步骤变量`currentStep`（0-4），每个步骤对应一组CSS类切换
  2. 箭头绘制：使用SVG `<path>` 元素，处理②使用3段path形成Y形
  3. 箭头头部：使用SVG `<marker>` 定义箭头，通过`marker-end`属性应用
  4. 动画过渡：使用CSS `transition` 实现颜色/透明度/线宽的平滑过渡（0.3s ease）
  5. 事件绑定：按钮点击事件更新`currentStep`并调用`updateScene(step)`函数
  6. 植株简图：用SVG `<path>` 绘制茎（曲线）、叶（椭圆）、豆荚（弯曲形状）
  7. 按钮禁用状态：步骤0时「上一步」按钮disabled，步骤4时「下一步」按钮disabled
- ID 命名规范：所有交互元素ID以`scene1-`为前缀
  - `scene1-plant-a-box`、`scene1-plant-b-box`
  - `scene1-result-no-seed`、`scene1-result-with-seed`、`scene1-result-haploid`、`scene1-result-diploid`
  - `scene1-arrow-1`、`scene1-arrow-2-top`、`scene1-arrow-2-bottom`、`scene1-arrow-2-main`、`scene1-arrow-3`、`scene1-arrow-4`
  - `scene1-label-1`、`scene1-label-2`、`scene1-label-3`、`scene1-label-4`
  - `scene1-btn-prev`、`scene1-btn-next`、`scene1-step-indicator`
- IIFE 隔离：所有JS代码包裹在 `(function() { 'use strict'; ... })();` 中
- SVG defs中定义4种颜色的marker（箭头头部）：灰色、蓝色、红色、绿色
