[图示主题与整合说明]
- 本图示主题：静摩擦力分析——整体法与隔离法的分步演示
- 整合的步骤/概念：初始状态装置展示 → 初始状态整体受力分析 → 初始状态隔离A受力分析 → 操作动画（5号钩码移至A上） → 最终状态整体受力分析 → 最终状态隔离A受力分析 → 摩擦力变化对比结论
- 教学价值：教师通过分步按钮控制节奏，引导学生从"整体法"到"隔离法"逐步分析静摩擦力，直观展示钩码移动前后摩擦力的变化，帮助学生理解受力分析逻辑和静摩擦力的动态平衡。

[技术实现]
- JS 库选择：原生 SVG（简单几何图形和箭头绘制，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                  装置示意图                       |
  |  滑轮      木块A      木块B      滑轮            |
  |   O--------[A]------[B]--------O                |
  |   |          |        |        |                |
  |  [4]       实验台    实验台    [1]              |
  |  [5]      (阴影)    (阴影)    [2]              |
  |                                               [3]
  |                                                |
  |              受力箭头/结论区域                  |
  |                                                |
  |           [◀ 上一步] [下一步 ▶]                |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  - 状态机设计：使用全局变量`currentStep`（0-6）控制显示状态，每个步骤对应一组SVG元素的显示/隐藏/属性变化
  - 坐标计算：所有元素坐标预计算，步骤3钩码5移动使用SVG `<animate>` 或 JS 定时器实现平滑过渡
  - 箭头绘制：使用SVG `<marker>` 定义箭头头部，线宽和颜色按步骤切换
  - 高亮框：使用`stroke-dasharray`实现虚线效果，`opacity`控制显示/隐藏
  - 事件绑定：按钮点击事件更新`currentStep`并调用`renderStep()`函数重绘
  - ID 命名规范：所有交互元素ID以`scene1-`为前缀（如`scene1-btn-next`、`scene1-block-a`、`scene1-weight-5`）
  - IIFE 隔离：所有JS代码包裹在`(function() { ... })()`中，避免全局污染
  - 动画曲线：步骤3钩码移动使用`ease-in-out`曲线，时长500ms
