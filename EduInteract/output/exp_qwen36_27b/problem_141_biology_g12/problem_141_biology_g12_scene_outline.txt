    **题目原文：**

    开两性花的二倍体陆地棉（一年生植物）易得黄萎病，研究人员已从海岛棉分离出抗黄萎病基因S，发现整合到陆地棉的2号染色体或线粒体上的基因S能表达出等效的抗性，但线粒体上的基因S表达的抗性会逐代减弱。通过基因工程得到的幼苗可能有以下多种类型，若幼苗线粒体DNA中含有S基因，则成熟后植株生殖细胞的细胞质也含有S基因。回答下列问题：

    （1）符合长期种植要求的种子（幼苗）是图示中的___________。

    （2）为了快速地获得更多的符合生产要求的种子，将基因工程得到的幼苗全部种植，逐步进行如下实验：

    实验①：将所有具抗性的植株自交得到的种子记为自交系一代，每株的所有种子单独种植在一起可得到一个株系，检测并记录其抗性。

    实验②：同时还将所有具有抗性的植株作为父本（其精子内的线粒体不会进入卵细胞）分别与无抗性的植株杂交得到的种子记为杂交系一代，每株的所有种子单独种植在一起可得到一个株系，检测并记录其抗性。

    在实验①中，进行自交的目的是：a．通过检测自交系一代的抗性，将类型e植株与_______________________（填上图中的序号）区分；b．同时起到_____________________的作用。实验②中检测到的杂交系一代株系抗性及比例的结果可分为_______种类型。若同一株系的自交系一代和杂交系一代都表现为___________________，则其对应的自交系一代就是符合要求的种子。

    **题目分析：**

    本题核心考查**核基因遗传（孟德尔遗传）与细胞质遗传（母系遗传）的区别**，以及转基因植株的筛选策略。

    图中6种类型（a-f）的关键区别在于：
    - **核基因S状态**：2号染色体上是否整合S基因（纯合/杂合/无）
    - **线粒体S状态**：线粒体DNA上是否整合S基因

    各类型归纳：
    - **a、b**：核S杂合 + 线粒体S（有抗性）
    - **c**：无核S + 线粒体S（有抗性，但抗性逐代减弱）
    - **d**：核S纯合 + 无线粒体S（有抗性，可稳定遗传）
    - **e**：核S杂合 + 无线粒体S（有抗性，但自交会分离）
    - **f**：无核S + 无线粒体S（无抗性）

    **整体讲解思路：**

    1. 先让学生观察原图，识别6种类型的核基因和线粒体基因状态
    2. 理解"符合长期种植要求"的含义：抗性需稳定遗传→需要核基因S纯合且无线粒体S干扰→答案为d
    3. 通过自交实验区分e（核S杂合+无线粒体S）与a、b（核S杂合+线粒体S）：e自交后代会出现无抗性个体（1/4），而a、b自交后代因线粒体S母系遗传全部有抗性
    4. 通过杂交实验（父本×无抗性母本f），后代线粒体来自母本f（无S），所以抗性仅由核基因决定，可进一步验证核基因状态

    **图示规划：**

    - **Scene 1**：6种植株类型总览与筛选——帮助学生直观识别各类型基因状态，理解筛选标准
    - **Scene 2**：自交与杂交遗传实验分析——动态展示不同植株的自交/杂交后代分离情况，理解实验设计原理
    </TEXT_1>

    **Scene 1 教学说明：**

    本图示帮助学生直观识别6种转基因植株类型的基因状态，并理解筛选符合长期种植要求植株的逻辑。

    **引导步骤：**

    1. **步骤0→步骤1**：让学生先观察原图，尝试自己识别各类型的核基因和线粒体基因状态。然后展示标注，核对学生的判断。强调图例的含义。

    2. **步骤1→步骤2**：提问"哪些植株有抗性？"引导学生回答a、b、c、d、e（只要有S基因就有抗性）。展示绿色高亮验证。

    3. **步骤2→步骤3**：提问"哪些植株符合长期种植要求？为什么？"引导学生思考：
        - 线粒体S的抗性会逐代减弱，所以不能依赖线粒体S
        - 核S杂合（a、b、e）自交后代会分离，不是所有后代都有抗性
        - 只有d（核S纯合+无线粒体S）能稳定遗传抗性

    4. **步骤4**：展示对比表格，总结各类型特征，强化理解。

    **关键知识点：**
    - 核基因遗传遵循孟德尔定律，可稳定遗传（纯合子）
    - 线粒体基因母系遗传，且本题中抗性逐代减弱
    - 符合长期种植要求 = 核S纯合 + 无线粒体S = d

    图示主题：自交与杂交实验的遗传图解——区分不同植株类型并筛选符合要求种子

    整合内容：
    - 展示自交实验（实验①）的遗传过程：不同植株自交后代的基因型和表现型
    - 展示杂交实验（实验②）的遗传过程：不同植株作为父本与f杂交的后代
    - 对比自交和杂交结果，理解实验设计目的
    - 展示如何通过实验结果筛选出d类型对应的自交系一代

    交互类型：多状态切换 — 选择理由：需要在自交和杂交两种实验模式间切换对比，同时每种模式下可选择不同植株类型观察结果，3个按钮（自交-核S杂合有线粒体S / 自交-核S杂合无线粒体S / 杂交）足以覆盖核心对比

    交互设计：
    - **状态1（自交：a/b类型）**：展示a或b类型（核S杂合+线粒体S）自交的遗传图解
        - 亲本：核S杂合（Ss）+ 线粒体S
        - 配子：核配子1/2 S、1/2 s；线粒体全部带S
        - 后代：核基因型1/4 SS、1/2 Ss、1/4 ss；但所有后代都有线粒体S
        - 表现型：全部有抗性（因为线粒体S母系遗传）
        - 结论框："自交后代全部有抗性（线粒体S掩盖了核基因分离）"

    - **状态2（自交：e类型）**：展示e类型（核S杂合+无线粒体S）自交的遗传图解
        - 亲本：核S杂合（Ss）+ 无线粒体S
        - 配子：核配子1/2 S、1/2 s；线粒体无S
        - 后代：核基因型1/4 SS、1/2 Ss、1/4 ss；无线粒体S
        - 表现型：3/4有抗性（SS+Ss）、1/4无抗性（ss）
        - 结论框："自交后代3:1分离（无��粒体S掩盖，核基因分离显现）"
        - 对比提示："与a/b自交结果对比→可区分e与a/b"

    - **状态3（杂交：d作为父本×f作为母本）**：展示d类型作为父本与f杂交的遗传图解
        - 父本d：核S纯合（SS）+ 无线粒体S → 精子核基因全部为S，精子无线粒体
        - 母本f：无核S（ss）+ 无线粒体S → 卵细胞核基因为s，卵细胞线粒体无S
        - 后代：核基因型全部Ss；无线粒体S
        - 表现型：全部有抗性
        - 结论框："杂交后代全部有抗性→父本为核S纯合（d类型）"
        - 补充说明："若父本为e（核S杂合），杂交后代1:1分离；若父本为c（无核S），杂交后代全部无抗性→共3种类型"

    - 后代群体：多个小圆形表示后代个体，用颜色区分表现型
    - 比例标注：分数或百分比标注各基因型/表现型比例
    - 结论框：总结性文字框
    - 状态切换按钮：顶部3个按钮

    - 后代标注：基因型比例、表现型比例

    - 状态按钮文字

    - 蓝高亮 #1565c0：用于标注含S基因的染色体/配子/后代

    **Scene 2 教学说明：**

    本图示通过动态遗传图解展示自交和杂交实验的原理，帮助学生理解如何通过实验区分不同植株类型并筛选出符合要求的种子。

    **引导步骤：**

    1. **状态1（自交a/b）**：
        - 展示a或b类型自交的遗传过程
        - 强调：线粒体S母系遗传→所有后代都有线粒体S→全部有抗性
        - 提问："虽然核基因分离了，但为什么后代全部有抗性？"

    2. **状态2（自交e）**：
        - 展示e类型自交的遗传过程
        - 强调：无线粒体S→核基因分离直接表现为抗性分离→3:1
        - 对比状态1："为什么e和a/b的自交结果不同？"→引出实验①目的a的答案：**a、b**
        - 补充：自交还能起到**纯化（筛选纯合子）**的作用→实验①目的b的答案

    3. **状态3（杂交d×f）**：
        - 展示d作为父本与f杂交的遗传过程
        - 强调：精子无线粒体→后代线粒体来自母本f（无S）→抗性仅由核基因决定
        - 提问："如果父本是e或c，杂交结果会怎样？"
        - 引导学生推导：
            - 父本e（Ss）：后代1/2 Ss（有抗性）、1/2 ss（无抗性）→1:1
            - 父本c（ss）：后代全部ss（无抗性）→全部无抗性
            - 父本d（SS）：后代全部Ss（有抗性）→全部有抗性
        - 所以杂交结果可分为**3种类型**
        - 最后提问："如何判断哪个自交系一代是符合要求的？"→答案：**自交系一代和杂交系一代都表现为全部有抗性**

    **完整答案总结：**
    - （1）**d**
    - （2）实验①目的a：**a、b**（或a和b）
    - （2）实验①目的b：**纯化（或筛选纯合子/鉴定纯合子）**
    - （2）杂交系一代类型数：**3**
    - （2）判断标准：**全部有抗性（或全部表现为抗性）**

    **课堂讲解建议：**
    - 先让学生独立观察原图，尝试填写答案
    - 再用Scene 1确认各类型基因状态
    - 用Scene 2逐步展示实验原理，验证学生的答案
    - 强调核基因遗传与细胞质遗传的根本区别
