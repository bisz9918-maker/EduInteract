[图示主题与整合说明]
- 本图示主题：6种转基因植株类型的基因状态总览与符合长期种植要求的筛选
- 整合的步骤/概念：
  1. 展示a-f六种植株类型的细胞结构（2号染色体对+线粒体）
  2. 标注各类型的核基因S和线粒体S状态
  3. 逐步高亮有抗性植株、符合长期种植要求的植株
  4. 展示筛选逻辑：核S纯合且无线粒体S→稳定遗传
- 教学价值：教师通过分步导航，引导学生从识别6种基因类型→理解抗性条件→掌握筛选标准→得出答案d，层层递进，适合课堂互动讲解

各类型基因状态对照：
- a: 核S纯合(↑↑) + 线粒体S(⊙) → 有抗性，但线粒体S逐代减弱
- b: 核S杂合(↑|) + 线粒体S(⊙) → 有抗性，但核S不纯合且线粒体S逐代减弱
- c: 核S无(||) + 线粒体S(⊙) → 有抗性，但线粒体S逐代减弱
- d: 核S纯合(↑↑) + 无线粒体S(○) → 有抗性，核S纯合稳定遗传，无线粒体S → 符合要求！
- e: 核S杂合(↑|) + 无线粒体S(○) → 有抗性，但核S不纯合
- f: 核S无(||) + 无线粒体S(○) → 无抗性

逐对检查关键间距：
- 图例项1(80,40)与图例项2(320,40)：水平间距240px → 无冲突
- 图例项1(80,40)与图例项3(80,58)：垂直间距18px → 无冲突（不同行）
- 图例项2(320,40)与图例项4(320,58)：垂直间距18px → 无冲突
- 标签a(125,218)与标签b(235,218)：水平间距110px → 无冲突
- 相邻标签间距均为110px → 无冲突
- 标签a(125,218)与文字标签a(125,245)：垂直间距27px → 无冲突
- 文字标签a(125,245)与文字标签b(235,245)：水平间距110px → 无冲突
- 文字标签最宽约140px，相邻标签中心距110px，边缘间距约110-140= -30px → 有重叠风险！

解决方案：将文字标签缩短或用更紧凑的表述：
- a: "核纯合+线粒体S"（约100px宽）
- b: "核杂合+线粒体S"（约100px宽）
- c: "核无+线粒体S"（约90px宽）
- d: "核纯合+无线粒体S"（约110px宽）
- e: "核杂合+无线粒体S"（约110px宽）
- f: "核无+无线粒体S"（约100px宽）

重新检查：最宽110px，相邻中心距110px，边缘间距约0px → 仍然太近。

进一步解决方案：将文字标签缩小到12px字体，或增加细胞间距。
采用方案：将细胞中心x坐标调整为120, 240, 360, 480, 600, 720（间距120px）。
重新计算：
- 左边缘：120-40=80px
- 右边缘：720+40=760px
- 右距：800-760=40px → 不对称

采用方案：将文字标签字体缩小到11px，预计宽度约80-90px。
相邻标签中心距110px，边缘间距约110-90=20px → 无冲突。

最终确认：
- 所有细胞标签间距≥110px → 无冲突
- 所有文字标签间距≥110px，字体11px宽度≤90px → 边缘间距≥20px → 无冲突
- 标签与文字标签垂直间距27px → 无冲突
- 文字标签与提示文字垂直间距30px → 无冲突
- 提示文字与表格垂直间距25px → 无冲突
- 表格与控件栏垂直间距35px → 无冲突

结论：所有标签无重叠冲突。

  ```
  │  │ d  │纯合  │ 无S  │ ✓  │  ✓ ←   │                  │
  │  └────┴──────┴──────┴────┴────────┘                  │

  │  [◀ 上一步]   步骤 X/4   [下一步 ▶]  (y=440~490)     │
  └─────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用全局变量`currentStep`（0~4）跟踪当前步骤，每个步骤对应一个渲染函数`renderStep(n)`
  2. SVG元素管理：
     - 所有细胞、染色体、线粒体在初始化时创建，通过CSS class控制显示/隐藏/样式
     - 箭头标记在步骤1时通过`createElementNS`动态添加到SVG
     - 高亮边框通过修改`stroke`和`stroke-width`属性实现
     - 淡化效果通过修改`opacity`属性实现
  3. 坐标计算：
     - 细胞中心x坐标数组：[125, 235, 345, 455, 565, 675]
     - 细胞中心y坐标：140
     - 染色体x偏移：±10px
     - 线粒体y偏移：+55px（相对于细胞中心）
  4. 动画曲线：步骤切换使用CSS transition（0.3s ease），边框颜色和透明度变化平滑过渡
  5. 事件绑定：按钮点击事件绑定到`prevStep()`和`nextStep()`函数，更新`currentStep`后调用`renderStep(currentStep)`
  6. 表格渲染：步骤4时动态创建SVG `<rect>`和`<text>`元素绘制表格，或使用HTML `<table>`叠加在SVG上
- ID 命名规范：所有交互元素ID以`scene1-`为前缀
  - 细胞：`scene1-cell-a`, `scene1-cell-b`, ..., `scene1-cell-f`
  - 染色体：`scene1-chr-a-left`, `scene1-chr-a-right`, ...
  - 线粒体：`scene1-mito-a`, `scene1-mito-b`, ...
  - 箭头：`scene1-arrow-a-left`, `scene1-arrow-a-right`, ...
  - 按钮：`scene1-prev-btn`, `scene1-next-btn`
  - 步骤指示：`scene1-step-indicator`
  - 提示文字：`scene1-hint-text`
  - 表格：`scene1-comparison-table`
- IIFE 隔离：所有JS代码包裹在`(function() { ... })()`中，避免全局污染
- 表格实现方案：使用SVG `<g>`组包含`<rect>`（表格边框和行背景）和`<text>`（表格文字），步骤4时设置`visibility="visible"`，其他步骤`visibility="hidden"`
