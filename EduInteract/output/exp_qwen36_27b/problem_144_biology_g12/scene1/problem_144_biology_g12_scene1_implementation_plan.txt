[图示主题与整合说明]
- 本图示主题：果蝇杂交实验流程与F₂表型比例展示
- 整合的步骤/概念：P代亲本选择（♀棒眼×♂圆眼，均为纯种）→ F₁代表型（待填空白）→ F₂代表型比例（♀圆眼:♀棒眼:♂圆眼:♂棒眼 = 1:1:1:1）→ 关键比例高亮（圆眼:棒眼 = 1:1，与常染色体3:1不符）
- 教学价值：教师通过分步按钮引导学生逐步观察杂交实验的三代递进关系，从亲本选择到F₁表型推断，再到F₂比例分析，最终引导学生发现"圆眼:棒眼 = 1:1"这一关键比例与常染色体遗传的3:1不符，为后续推断基因位于X染色体做铺垫。分步展示符合认知递进逻辑，空白待填设计激发学生思考。

[技术实现]
- JS 库选择：原生 SVG（简单几何图形和图标绘制，无需额外库）
  - 原因：本场景主要为静态图形展示+分步淡入动画，原生 SVG 完全胜任，无需引入 D3.js 等重型库
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +------------------------------------------------------------------+
  |  P    ♀棒眼(纯种)    ×    ♂圆眼(纯种)          F₂ 表型比例       |
  |  (50)  (160)         (240)  (310)               (570)            |
  |                                                                   |
  |         ↓ (虚线)                                                  |
  |                                                                   |
  |  F₁   ___眼（♀♂）(235)                                          |
  |                                                                   |
  |         ↓ (虚线)  F₁雌雄交配(282)                                |
  |                                                                   |
  |  F₂   ♀圆  ♀棒  ♂圆  ♂棒       [柱][柱][柱][柱]                |
  |       (120) (200) (280) (360)   470  530  590  650              |
  |       1  :  1  :  1  :  1       1    1    1    1                |
  |                                                                   |
  |  步骤3高亮: ┌──────────────────────┐                              |
  |             │ 圆眼:棒眼 = 1:1      │  (570,135)                   |
  |             │ (与常染色体3:1不符)  │  (570,160)                   |
  |             └──────────────────────┘                              |
  |                                                                   |
  |                    ┌──────────┐                                   |
  |  [◀ 上一步]  步骤0/3  [下一步 ▶]       (y=460~496)               |
  |    (250)      (400)     (550)                                   |
  +------------------------------------------------------------------+
  ```
- 关键实现要点：
  1. **状态机设计**：用变量 `currentStep`（0~3）管理当前步骤。每个步骤对应一个元素集合，切换时根据步骤显示/隐藏对应元素。
  2. **元素可见性控制**：每个步骤新增元素用 CSS class `.scene1-step-N` 标记（N=0~3），切换步骤时遍历所有元素，根据当前步骤设置 `opacity` 和 `visibility`。
  3. **动画实现**：
     - 淡入动画：CSS `transition: opacity 0.3s ease-in`，从 `opacity:0` 到 `opacity:1`
     - 柱状图生长动画：CSS `transition: height 0.4s ease-out`，从 `height:0` 到 `height:140`，配合 `transform-origin: bottom`
     - 高亮脉冲动画：CSS `@keyframes pulse { 0%,100% { transform: scale(1); } 50% { transform: scale(1.05); } }`，duration 500ms
  4. **果蝇图标复用**：定义 SVG `<defs>` 中的 `<g id="scene1-fly-body">` 作为基础模板，通过 `<use>` 复用，仅改变眼睛形状（圆/棒）和性别符号颜色。
  5. **按钮事件绑定**：用 `addEventListener('click', ...)` 绑定按钮点击事件，更新 `currentStep` 并调用 `updateScene()` 函数。
  6. **按钮禁用状态**：步骤0时"上一步"按钮 `disabled=true`，步骤3时"下一步"按钮 `disabled=true`，用 CSS 改变禁用样式。
- ID 命名规范：所有交互元素 ID 以 `scene1-` 为前缀：
  - `scene1-btn-prev`：上一步按钮
  - `scene1-btn-next`：下一步按钮
  - `scene1-step-indicator`：步骤指示器
  - `scene1-p-group`：P代元素组
  - `scene1-f1-group`：F₁代元素组
  - `scene1-f2-group`：F₂代元素组
  - `scene1-chart-group`：柱状图元素组
  - `scene1-highlight-group`：高亮元素组
  - `scene1-fly-female-bar`：♀棒眼果蝇图标
  - `scene1-fly-male-round`：♂圆眼果蝇图标
  - 等等
- JS 隔离：所有 JS 代码包裹在 IIFE `(function() { 'use strict'; ... })();` 中，避免全局污染
- CSS 隔离：所有 CSS 选择器以 `#scene1-container` 为前缀，避免多场景合并时样式冲突
