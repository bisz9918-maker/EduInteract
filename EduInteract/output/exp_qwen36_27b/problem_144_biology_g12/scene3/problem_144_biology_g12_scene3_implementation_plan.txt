[图示主题与整合说明]
- 本图示主题：果蝇遗传验证实验设计——两个独立验证方案
- 整合的步骤/概念：从F₂果蝇中选择材料，设计两个不同的杂交实验来验证"棒眼为隐性、基因位于X染色体"的推断。方案1（F₂♀棒眼×F₂♂棒眼→后代全棒眼）和方案2（F₂♀圆眼×F₂♂棒眼→1:1:1:1）均可独立证明该推断。
- 教学价值：教师通过分步展示两个验证方案，帮助学生理解遗传学验证实验的设计思路，掌握棋盘格（Punnett Square）法推导后代基因型和表型比例的方法。

[交互方案]

- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：位于底部左侧(250,450)，点击后回退到上一步，步骤0时禁用
  - "下一步 ▶"按钮：位于底部右侧(430,450)，点击后进入下一步，步骤3时禁用
- 教师操作流程：
  1. 初始状态显示题目要求，教师引导学生思考验证实验的设计思路
  2. 点击"下一步"展示方案1，教师讲解方案1的杂交组合、配子推导和预期结果
  3. 点击"下一步"展示方案2，教师讲解方案2的杂交组合、棋盘格推导和1:1:1:1比例
  4. 点击"下一步"高亮两个方案并显示总结，教师强调两个方案均可独立验证推断
  5. 可随时点击"上一步"回退复习任意步骤

[技术实现]

- JS 库选择：原生 SVG（本场景为静态遗传学图示，无需复杂动画或3D，原生 SVG 最轻量高效）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  +--------------------------------------------------+
  |  从F₂中选择材料，设计两个不同的杂交实验验证推断   |  y=15~55
  |  ----------------------------------------------  |  y=55 分隔线
  |  +----------方案1----------+  +----------方案2----------+  y=65~93
  |  | F₂♀棒眼(XᵇXᵇ)×F₂♂棒眼(XᵇY) |  | F₂♀圆眼(XᴮXᵇ)×F₂♂棒眼(XᵇY) |  y=110~146
  |  |  +---+---+              |  |  +---+---+---+          |  y=170~280/310
  |  |  |XᵇXᵇ|XᵇY|             |  |  |XᴮXᵇ|XᴮY|            |
  |  |  |棒眼♀|棒眼♂|            |  |  |圆眼♀|圆眼♂|            |
  |  |  +---+---+              |  |  +-----+-----+          |
  |  |                        |  |  |XᵇXᵇ|XᵇY|            |
  |  |                        |  |  |棒眼♀|棒眼♂|            |
  |  |                        |  |  +-----+-----+          |
  |  |  [后代全为棒眼]         |  |  [♀圆:♀棒:♂圆:♂棒=1:1:1:1] |  y=300~336/340~376

  |                                                      |
  |         [◀ 上一步]    [下一步 ▶]                     |  y=450~480
  +--------------------------------------------------+
  ```

- 关键实现要点：
  1. 状态机设计：使用 `currentStep` 变量（0~3）跟踪当前步骤，每个步骤对应一组 CSS 类的切换
  2. 显示/隐藏控制：使用 CSS 类 `.scene3-hidden { opacity: 0; pointer-events: none; }` 和 `.scene3-visible { opacity: 1; }` 配合 `transition: opacity 0.4s ease` 实现淡入淡出
  3. 高亮效果：步骤3时，方案1和方案2的标题框添加 `.scene3-highlight` 类，边框加粗至3px，背景透明度加深
  4. 按钮状态：步骤0时上一步按钮添加 `disabled` 属性并设置灰色样式；步骤3时下一步按钮同理
  5. 基因型上标：使用 SVG `<tspan baseline-shift="super" font-size="0.75em">` 实现上标效果，如 `X<tspan baseline-shift="super" font-size="0.75em">b</tspan>`
  6. 棋盘格绘制：使用 `<rect>` 绘制格子，`<line>` 绘制分隔线，`<text>` 添加文字标注
  7. 事件绑定：按钮点击事件绑定到 `handleStepChange(direction)` 函数，direction 为 +1 或 -1

- ID 命名规范：所有交互元素 ID 以 `scene3-` 为前缀
  - `scene3-btn-prev`：上一步按钮
  - `scene3-btn-next`：下一步按钮
  - `scene3-plan1-group`：方案1区域容器（g 元素）
  - `scene3-plan2-group`：方案2区域容器（g 元素）
  - `scene3-summary-text`：总结文字
  - `scene3-title-text`：题目要求文字
  - `scene3-divider`：分隔线
  - `scene3-plan1-title`：方案1标题框
  - `scene3-plan2-title`：方案2标题框
  - `scene3-plan1-punnett`：方案1棋盘格
  - `scene3-plan2-punnett`：方案2棋盘格
  - `scene3-plan1-result`：方案1预期结果框
  - `scene3-plan2-result`：方案2预期结果框

- IIFE 隔离：所有 JS 代码包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染
