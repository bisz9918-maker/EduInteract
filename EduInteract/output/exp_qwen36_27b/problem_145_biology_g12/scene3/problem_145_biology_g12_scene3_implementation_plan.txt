[图示主题与整合说明]
- 本图示主题：Ⅱ-3与Ⅱ-4后代两病兼患概率的遗传图解计算
- 整合的步骤/概念：①确定Ⅱ-3和Ⅱ-4的完整基因型；②分别计算甲病和乙病的发病概率；③综合计算两病兼患概率
- 教学价值：教师通过分步按钮导航，逐步展示基因型推导和概率计算过程，避免信息过载。每一步都有明确的视觉变化，帮助学生理解遗传概率的推导逻辑。最终得出两病兼患概率为1/16。

[技术实现]
- JS 库选择：原生 SVG（无需额外库）。原因：遗传图解主要是文本和简单图形（矩形、线条、圆点），不需要复杂动画或3D效果。SVG 文本渲染质量好，易于实现分步显示/隐藏。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌──────────────────────────────────────────────────┐
  │  标题："步骤X：..."                               │ y=35
  │                                                  │
  │  ┌──────────┐                    ┌──────────┐   │ y=60~115
  │  │ Ⅱ-3卡片  │                    │ Ⅱ-4卡片  │   │
  │  └──────────┘                    └──────────┘   │
  │                                                  │
  │  ┌──────────────────────────────────────────┐   │ y=135~360
  │  │          计算框（灰色背景）                │   │
  │  │                                          │   │
  │  │   各步骤内容（互斥显示）                   │   │
  │  │                                          │   │
  │  └──────────────────────────────────────────┘   │
  │                                                  │
  │  ┌──────────────────────────────────────────┐   │ y=375~420
  │  │         答案卡片（仅步骤5显示）            │   │
  │  └──────────────────────────────────────────┘   │
  ```

- 关键实现要点：
  1. **状态机设计**：使用 `currentStep` 变量（0~5）跟踪当前步骤。`updateStep(step)` 函数负责：
     - 隐藏所有步骤组（`display:none`）
     - 显示当前步骤组（`display:block`）
     - 更新Ⅱ-3和Ⅱ-4卡片文字内容
     - 更新按钮状态（启用/禁用、文字）
     - 更新步骤指示器文字
     - 控制答案卡片显示/隐藏
  2. **坐标计算**：所有元素坐标已在布局坐标表中精确规划，直接硬编码到 SVG 元素中。
  3. **动画曲线**：步骤切换时使用 CSS `transition: opacity 0.3s ease` 实现淡入淡出效果。先设置 `opacity:0`，切换后设置 `opacity:1`。
  4. **事件绑定**：使用 `addEventListener('click', ...)` 绑定按钮点击事件。上一步按钮点击时 `currentStep--`，下一步按钮点击时 `currentStep++`，边界检查防止越界。
  5. **上标/下标处理**：使用 SVG `<tspan baseline-shift="super" font-size="10">` 实现上标（如 X^B 中的 B），`<tspan baseline-shift="sub" font-size="10">` 实现下标。
  6. **按钮禁用状态**：通过设置 `pointer-events="none"` 和修改 `fill`/`fill` 颜色实现视觉和交互上的禁用效果。
  7. **步骤内容互斥**：每个步骤的内容放在独立的 `<g>` 组中，通过 JS 控制 `display` 属性实现互斥显示。

- **ID 命名规范**：所有交互元素 ID 以 `scene3-` 为前缀：
  - `scene3-svg`：SVG 容器
  - `scene3-title`：标题文字
  - `scene3-card-ii3`：Ⅱ-3卡片组
  - `scene3-card-ii3-label`：Ⅱ-3卡片文字
  - `scene3-card-ii4`：Ⅱ-4卡片组
  - `scene3-card-ii4-label`：Ⅱ-4卡片文字
  - `scene3-calc-box`：计算框组
  - `scene3-step0` ~ `scene3-step5`：各步骤内容组
  - `scene3-answer-card`：答案卡片组
  - `scene3-answer-text`：答案文字
  - `scene3-btn-prev`：上一步按钮
  - `scene3-btn-prev-label`：上一步按钮文字
  - `scene3-btn-next`：下一步按钮
  - `scene3-btn-next-label`：下一步按钮文字
  - `scene3-step-indicator`：步骤指示器

- **IIFE 隔离**：所有 JS 代码包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染。使用 `document.getElementById()` 获取元素，不使用 `querySelectorAll` 配合全局 class。
