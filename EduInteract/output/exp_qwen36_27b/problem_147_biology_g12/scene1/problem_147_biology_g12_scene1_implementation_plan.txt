[图示主题与整合说明]
- 本图示主题：PCR三阶段（变性、复性、延伸）的动态过程演示
- 整合的步骤/概念：原始DNA双链展示 → 95°C变性解旋 → 55°C引物结合（含引物Ⅰ和引物Ⅱ的设计与定位） → 72°C延伸合成新链 → 循环一次后的产物
- 教学价值：教师可通过分步按钮引导学生逐步理解PCR每个温度阶段的作用和分子变化，直观展示DNA双链如何被复制，帮助学生掌握PCR原理及半保留复制的特点

[分步序列]

步骤0（初始状态）：展示原始DNA双链
- 显示标题"PCR过程演示"
- 显示a链（蓝色水平线，y=100，x=150~650），标注5'→3'方向
- 显示b链（红色水平线，y=140，x=150~650），标注3'→5'方向
- 显示氢键（灰色虚线，连接a链和b链，x=180,220,260,300,340,380,420,460,500,540,580,620）
- 显示碱基序列标注（简化：a链上方标注"G-G-···-T-C"，b链下方标注"C-C-···-A-G"）
- 显示a链标签（左上方）、b链标签（左下方）
- 温度标签显示"常温"，阶段标签显示"原始DNA"
- 底部显示步骤指示器"0/4"和导航按钮

步骤1（95°C变性）：双链解开
- 点击「下一步」
- a链向上移动到y=70，b链向下移动到y=170（分离动画，0.5秒）
- 氢键虚线逐条消失（从中间向两侧，0.3秒延迟）
- 温度标签变为"95°C"（橙色大字体）
- 阶段标签变为"变性"
- 两条单链保持水平，间距增大
- 步骤指示器变为"1/4"

步骤2（55°C复性）：引物结合
- 点击「下一步」
- 温度标签变为"55°C"
- 阶段标签变为"复性"
- 引物Ⅰ（蓝色加粗线段）从右侧飞入，结合到a链3'端（x=580~650, y=70）
- 引物Ⅱ（红色加粗线段）从左侧飞入，结合到b链3'端（x=150~220, y=170）
- 引物结合处用对应颜色10%透明度填充高亮
- 显示引物Ⅰ标签（上方）、引物Ⅱ标签（下方）
- 步骤指示器变为"2/4"

步骤3（72°C延伸）：新链合成
- 点击「下一步」
- 温度标签变为"72°C"
- 阶段标签变为"延伸"
- DNA聚合酶图标（紫色椭圆）出现在引物Ⅰ的5'端（x=580, y=70）
- 新链（绿色线段）从引物Ⅰ的3'端开始向左延伸（5'→3'方向），逐步绘制动画（0.8秒）
- 同时，另一条新链从引物Ⅱ的3'端开始向右延伸
- 显示合成方向箭头（绿色，沿新链方向）
- 步骤指示器变为"3/4"

步骤4（循环一次完成）：展示产物
- 点击「下一步」
- 温度标签变为"完成"
- 阶段标签变为"循环一次"
- 展示两个子代DNA分子：
  - 上方分子：a链（蓝色母链）+ 新合成链（绿色）
  - 下方分子：b链（红色母链）+ 新合成链（绿色）
- 标注"母链"（蓝色/红色）和"新链"（绿色）
- 显示文字说明"半保留复制"
- 步骤指示器变为"4/4"

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于SVG底部左侧(x=300, y=445)，灰色背景，点击返回上一步
  - 「▶ 下一步」按钮：位于SVG底部右侧(x=430, y=445)，蓝色背景，点击进入下一步
  - 步骤指示器：位于SVG底部中央(x=400, y=460)，显示"当前步/总步数"
- 教师操作流程：
  1. 图示加载后显示原始DNA双链（步骤0），教师可先讲解DNA双螺旋结构
  2. 点击「下一步」进入变性阶段，讲解高温如何使氢键断裂
  3. 点击「下一步」进入复性阶段，讲解引物如何与模板链结合
  4. 点击「下一步」进入延伸阶段，讲解DNA聚合酶如何合成新链
  5. 点击「下一步」展示循环一次后的产物，讲解半保留复制
  6. 可随时点击「上一步」回退复习任意步骤

[技术实现]
- JS 库选择：原生SVG（简单几何图形和动画，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────────┐
  │                    PCR过程演示                              │ y=25
  │                                                             │
  │  95°C    a链 5'══════════════════════════════════3'         │ y=70~100
  │  变性    b链 3'══════════════════════════════════5'         │ y=140~170
  │           ↑氢键虚线连接                                     │
  │           引物Ⅱ      引物Ⅰ                                  │
  │                                                             │
  │           [DNA聚合酶] → 新链延伸方向                         │
  │                                                             │
  │                                                             │
  │                                                             │
  │                                                             │
  │                                                             │
  │                                                             │
  │                                                             │
  │                                                             │
  │                                                             │
  │                                                             │
  │                                                             │
  │                    ◀上一步  0/4  下一步▶                     │ y=445~475
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用currentStep变量（0~4）跟踪当前步骤，每个步骤对应一组SVG元素的显示/隐藏/位置状态
  2. 坐标计算：DNA链使用SVG line元素，氢键使用虚线stroke-dasharray，引物使用加粗line
  3. 动画曲线：使用CSS transition（0.5s ease-in-out）实现链分离、引物飞入、新链延伸动画
  4. 事件绑定：按钮点击事件触发stepForward()和stepBackward()函数，更新currentStep并重绘SVG
  5. 新链延伸动画：使用requestAnimationFrame逐步增加line的x2坐标，模拟合成过程
  6. 温度标签和阶段标签：使用textContent动态更新，配合CSS过渡效果
- ID 命名规范：所有交互元素ID以scene1-为前缀
  - scene1-dna-chain-a（a链）
  - scene1-dna-chain-b（b链）
  - scene1-hydrogen-bonds（氢键组）
  - scene1-primer-1（引物Ⅰ）
  - scene1-primer-2（引物Ⅱ）
  - scene1-new-chain-1（新链1）
  - scene1-new-chain-2（新链2）
  - scene1-polymerase（聚合酶图标）
  - scene1-temp-label（温度标签）
  - scene1-stage-label（阶段标签）
  - scene1-step-indicator（步骤指示器）
  - scene1-btn-prev（上一步按钮）
  - scene1-btn-next（下一步按钮）
  - scene1-label-a（a链标签）
  - scene1-label-b（b链标签）
  - scene1-label-primer1（引物Ⅰ标签）
  - scene1-label-primer2（引物Ⅱ标签）
  - scene1-label-5top（5'上标记）
  - scene1-label-3top（3'上标记）
  - scene1-label-3bottom（3'下标记）
  - scene1-label-5bottom（5'下标记）
  - scene1-label-mother（母链标签）
  - scene1-label-new（新链标签）
  - scene1-title（标题）
- IIFE 隔离：所有JS代码包裹在(function() { ... })()中，避免全局污染
- SVG元素使用setAttribute和getAttribute操作，不依赖querySelectorAll
