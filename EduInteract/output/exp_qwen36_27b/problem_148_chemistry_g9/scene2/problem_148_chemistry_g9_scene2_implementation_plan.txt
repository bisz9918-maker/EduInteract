[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位置(280,450)，大小110×30，点击返回上一步，步骤0时禁用
  - 「下一步 ▶」按钮：位置(410,450)，大小110×30，点击进入下一步，步骤5时禁用
- 教师操作流程：
  1. 初始状态展示四个灰色选项，教师介绍题目背景
  2. 点击「下一步」逐项分析选项A（化合价变化），讲解为何错误
  3. 点击「下一步」分析选项B（含氢化合物判断），讲解为何错误
  4. 点击「下一步」分析选项C（质量比计算），讲解为何正确
  5. 点击「下一步」分析选项D（分子个数比），讲解为何正确
  6. 点击「下一步」进入总结画面，讨论单选题答案选择
  7. 可随时点击「上一步」回退复习任意步骤

[技术实现]
- JS 库选择：原生 SVG（本场景以矩形卡片和文本为主，无需复杂图形库，SVG 文本渲染清晰且易于样式控制）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |  CH₄ + H₂O →(高温) CO + 3H₂                      |  y=10~70 方程式区
  |                                                  |
  | +------------------+  +------------------+       |
  | | A. 反应前后各...  |  | B. 该反应中含...  |       |  y=80~240 选项A/B
  | | [分析内容]        |  | [分析内容]        |       |
  | |              ✗错误|  |         ✗错误     |       |
  | +------------------+  +------------------+       |
  |                                                  |
  | +------------------+  +------------------+       |
  | | C. 该反应中乙...  |  | D. 该反应中丙...  |       |  y=260~420 选项C/D
  | | [分析内容]        |  | [分析内容]        |       |
  | |              ✓正确|  |         ✓正确     |       |
  +------------------+  +------------------+       |
  |        若为单选题，标准答案通常为D               |  y=435 总结提示
  |         [◀ 上一步]  [下一步 ▶]                   |  y=450~480 控件区
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 `currentStep`（0~5）跟踪当前步骤，每个步骤对应一组视觉状态
  2. 卡片状态管理：每个卡片有 `idle`（灰色）、`active`（蓝色高亮）、`correct`（绿色）、`wrong`（红色）四种状态
  3. 步骤切换函数 `goToStep(n)`：根据目标步骤更新所有卡片状态和分析内容
  4. 按钮事件绑定：「上一步」调用 `goToStep(currentStep - 1)`，「下一步」调用 `goToStep(currentStep + 1)`
  5. 边界处理：步骤0时禁用「上一步」，步骤5时禁用「下一步」
  6. 动画过渡：卡片状态切换使用 CSS transition（0.3s ease），边框颜色和背景色平滑变化
  7. 文本内容切换：分析内容通过 SVG `<text>` 元素的 `display` 属性控制显隐
- ID 命名规范：所有交互元素 ID 以 `scene2-` 为前缀
  - `scene2-eq-text`：方程式文本
  - `scene2-card-a`、`scene2-card-b`、`scene2-card-c`、`scene2-card-d`：四个选项卡片
  - `scene2-analysis-a`、`scene2-analysis-b`、`scene2-analysis-c`、`scene2-analysis-d`：各卡片分析内容组
  - `scene2-verdict-a`、`scene2-verdict-b`、`scene2-verdict-c`、`scene2-verdict-d`：各卡片正误标记
  - `scene2-summary-text`：总结提示文本
  - `scene2-btn-prev`、`scene2-btn-next`：导航按钮
- IIFE 隔离：所有 JS 代码包裹在 `(function() { ... })()` 中，避免全局污染
- SVG 元素使用 `document.getElementById` 精确获取，不使用 `querySelectorAll` 配合全局 class
