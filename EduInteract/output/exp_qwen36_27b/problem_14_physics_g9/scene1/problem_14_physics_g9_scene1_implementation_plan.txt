[分步序列]
- 初始状态（步骤0）：显示滑轮组基础结构、地面、墙壁、物体A。标注已知条件：F=5N（蓝箭头左）、v物=1m/s（绿箭头右）、G=50N（黑箭头下）、η=80%（右上框）。绳子为细黑线。
- 步骤1：点击「下一步」→ 绳子3段变为蓝色加粗（#1565c0, stroke-width=3）。绳子中点上方出现①②③标记。右侧公式框显示：v绳 = n·v物 = 3×1m/s = 3m/s。
- 步骤2：点击「下一步」→ 物体A上叠加受力箭头：N=50N（上）、G=50N（下）、f=?（红左）、T=?（蓝右）。底部出现提示文字（#888888）："匀速直线运动 → 合力为0 → T = f"。
- 步骤3：点击「下一步」→ 右侧公式框更新为效率推导：η = W有用/W总 = f·s物/(F·s绳) = f/(nF) → 80% = f/(3×5N) → f = 12N。同时受力图中 f=? 更新为 f=12N，T=? 更新为 T=12N。
- 步骤4：点击「下一步」→ 右侧公式框更新为功率与功计算：P = F·v绳 = 5N×3m/s = 15W；W有用(10s) = f·s物 = 12N×(1m/s×10s) = 120J。
- 步骤5：点击「下一步」→ 底部弹出4张选项卡片：A(合力5N)×红、B(f=12N)✓绿、C(P=5W)×红、D(W=500J)×红。公式框淡出或保持。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于(320,450)，点击返回上一状态，禁用时置灰
  - 「下一步 ▶」按钮：位于(420,450)，点击进入下一状态，最后一步禁用
- 教师操作流程：教师按「下一步」逐步展开结构→运动→受力→计算→选项判定，可随时点击「上一步」回退至任意中间状态进行对比讲解。按钮状态随步骤自动更新。

[技术实现]
- JS 库选择：原生 SVG + Vanilla JavaScript（无需外部依赖，轻量且精确控制矢量图形与动画）
- 画布尺寸：800 × 500 px（固定 viewBox）
- 布局草图（ASCII）：
  ```
  [ 墙壁 ] [定滑轮]----[动滑轮]----[物体A]
   |        |  ①②③   |           |
   |________|__________|___________|____ 地面
   0~480px (主图区)    500~780px (公式框)
   ----------------------------------------
   [选项A] [选项B] [选项C] [选项D] (y=400)
          [◀上一步] [下一步▶] (y=450)
  ```
- 关键实现要点：
  - 状态机：`currentStep` (0~5)，`renderStep(step)` 函数根据 step 值切换 SVG 元素 visibility/opacity/stroke-width/textContent
  - 动画：使用 CSS transition (0.3s ease) 实现元素淡入/颜色切换/箭头长度变化
  - 坐标计算：所有元素绝对定位，公式框内容通过 innerHTML 替换实现多行公式排版
  - 事件绑定：按钮 click 触发 `step++`/`step--`，边界检查禁用按钮
- ID 命名规范：所有交互与核心元素 ID 以 `scene1-` 为前缀（如 `scene1-pulley-fixed`, `scene1-box-formula`, `scene1-btn-next`, `scene1-label-f`）
- IIFE 隔离：全部 JS 逻辑封装在 `(function() { 'use strict'; ... })();` 中，避免全局污染
- 公式渲染：使用 Unicode 字符与 HTML 实体（如 `&eta;`, `&middot;`, `&sup2;`）配合 CSS 排版，避免引入 MathJax 增加加载负担
