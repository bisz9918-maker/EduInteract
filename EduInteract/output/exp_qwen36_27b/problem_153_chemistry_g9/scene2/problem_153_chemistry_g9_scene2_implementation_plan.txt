[图示主题与整合说明]
- 本图示主题：混合气体通过各装置前后的成分变化追踪表
- 整合的步骤/概念：初始成分（H₂、N₂、HCl、H₂O、CO、CO₂）→ 通过A装置（NaHCO₃溶液，除去HCl，生成H₂O和CO₂）→ 通过B装置（CuO加热，除去H₂和CO，生成H₂O和CO₂）→ 通过C装置（澄清石灰水，除去CO₂）→ 通过D装置（浓硫酸，除去H₂O）→ 最终仅剩N₂
- 教学价值：教师通过分步按钮逐行填充表格，配合SCENE_1的装置演示，帮助学生系统梳理每一步气体成分的变化，理解各装置的作用原理，最终得出正确答案

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于(250,445)，点击回退到上一步，步骤0时禁用
  - 「下一步 ▶」按钮：位于(430,445)，点击进入下一步，步骤5时禁用
  - 步骤指示器：位于(390,455)，显示"当前步/总步"（如"1/5"）
- 教师操作流程：
  1. 图示加载后显示空表格框架（步骤0）
  2. 教师点击「下一步」逐行填充气体成分变化
  3. 每步右侧同步显示对应装置的作用说明
  4. 教师可随时点击「上一步」回退复习
  5. 到达步骤5时显示完整答案和总结

[技术实现]
- JS 库选择：原生 SVG（表格和标记均为简单几何形状，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  +------------------------------------------------------------------+
  |  表头: H₂  N₂  HCl  H₂O  CO  CO₂                                |
  |  ┌────────┬────┬────┬────┬────┬────┬────────┐  ┌──────────────┐ |
  |  │  初始  │ ●  │ ●  │ ●  │ ●  │ ●  │ ●  │  │  装置说明       │ |
  |  ├────────┼────┼────┼────┼────┼────┤  ├──────────────┤ |
  |  │通过A后 │ ●  │ ●  │ ✗  │ ●  │ ●  │ ●  │  │ A: HCl      │ |
  |  ├────────┼────┼────┼────┼────┼────┤  ├──────────────┤ |
  |  │通过B后 │ ✗  │ ●  │ ✗  │ ●  │ ✗  │ ●  │  │ B: H₂,CO   │ |
  |  ├────────┼────┼────┼────┼────┼────┤  ├──────────────┤ |
  |  │通过C后 │ ✗  │ ●  │ ✗  │ ●  │ ✗  │ ✗  │  │ C: CO₂     │ |
  |  ├────────┼────┼────┼────┼────┼────┤  ├──────────────┤ |
  |  │通过D后 │ ✗  │ ●  │ ✗  │ ✗  │ ✗  │ ✗  │  │ D: H₂O     │ |
  |  ├────────┼────┼────┼────┼────┼────┤  ├──────────────┤ |
  |  │  最终  │ ✗  │ ●  │ ✗  │ ✗  │ ✗  │ ✗  │  │ 最终: N₂   │ |
  |  └────────┴────┴────┴────┴────┴────┘  └──────────────┘ |
  |  ┌──────────────────────────────────────────────────────┐       |
  |  │  答案：A→HCl, B→H₂+CO, C→CO₂, D→H₂O, 最终→N₂       │       |
  |  └──────────────────────────────────────────────────────┘       |
  |              [◀ 上一步]  1/5  [下一步 ▶]                        |
  +------------------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：当前步骤变量 currentStep（0~5），每步对应一个状态对象，包含：
     - 每行每列的标记类型（存在/已除去/含新生成）
     - 右侧说明框的文本内容
     - 底部答案框的显示状态
  2. 表格渲染：使用 SVG `<rect>` 绘制表格线和背景，`<text>` 绘制文字，`<circle>` 绘制圆点，两条 `<line>` 交叉绘制叉号
  3. 动画效果：单元格标记出现时使用 CSS transition（opacity 0→1，duration 300ms），圆点使用 scale 动画
  4. 事件绑定：按钮点击事件绑定到 renderStep(currentStep) 函数，根据当前步骤渲染对应状态
  5. 按钮状态管理：步骤0时「上一步」disabled，步骤5时「下一步」disabled
- ID 命名规范：所有交互元素 ID 以 `scene2-` 为前缀
  - 表格容器：`scene2-table`
  - 按钮：`scene2-prev-btn`、`scene2-next-btn`
  - 步骤指示器：`scene2-step-indicator`
  - 右侧说明框：`scene2-info-panel`
  - 底部答案框：`scene2-answer-box`
  - 单元格：`scene2-cell-{row}-{col}`（如 `scene2-cell-0-0` 表示初始行H₂列）
- IIFE 隔离：所有 JS 代码包裹在 `(function() { ... })()` 中，避免全局污染
- 化学式下标处理：使用 SVG `<tspan baseline-shift="sub" font-size="0.75em">` 实现下标效果（如 H₂ 中的 2）
