[图示主题与整合说明]
- 本图示主题：化学方程式推导与四个选项的逐一分析
- 整合的步骤/概念：从微观粒子图推导化学方程式 2A₂ + B₂ → 2AB₂ → 判断反应类型（化合反应）→ 四个选项（A/B/C/D）的正误逐一分析

[交互方案]

- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. "◀ 上一步"按钮：位于控件栏左侧 (295, 452)，点击回到上一步骤，步骤0时禁用
  2. "下一步 ▶"按钮：位于控件栏右侧 (410, 452)，点击进入下一步骤，步骤4时禁用
  3. 步骤指示器：位于两按钮之间 (400, 470)，显示 "当前步 / 总步数"（如"0 / 4"）
- 教师操作流程：
  1. 图示加载后显示初始状态（步骤0），展示化学方程式和四个灰色待分析选项
  2. 教师点击"下一步"，依次分析选项A→B→C→D
  3. 每步当前选项卡片变色（绿=正确，红=错误），右侧弹出解释框说明理由
  4. 底部辅助图示区同步显示对应的辅助说明（分子结构/对比图/数量标注）
  5. 教师可随时点击"上一步"回退复习之前内容
  6. 到达步骤4后，所有选项分析完成，下一步按钮禁用

- 画布尺寸：800 × 500 px（固定）

- 关键实现要点：

  1. **状态机设计**：
     - 使用全局变量 `currentStep`（0~4）跟踪当前步骤
     - `renderStep(step)` 函数根据步骤号更新所有视觉元素
     - 每个步骤定义一个配置对象，包含：选项卡片样式、解释框内容、辅助图示内容

  2. **步骤配置数据结构**：
     ```javascript
     const stepConfigs = [
       { // 步骤0
         options: [null, null, null, null],  // null=灰色待分析
         explain: null,                       // 不显示解释框
         reactionLabel: false,                // 不显示化合反应标签
         auxType: 'microscopic'               // 辅助图示类型
       },
       { // 步骤1
         options: ['correct', null, null, null],
         explain: '两种物质生成一种物质，属于化合反应',
         reactionLabel: true,
         auxType: 'combination'
       },
       { // 步骤2
         options: ['correct', 'wrong', null, null],
         explain: '生成物AB₂由不同种原子构成，是化合物而非单质',
         reactionLabel: true,
         auxType: 'compound'
       },
       { // 步骤3
         options: ['correct', 'wrong', 'wrong', null],
         explain: '反应前分子为A₂、B₂，反应后为AB₂，分子种类发生改变',
         reactionLabel: true,
         auxType: 'molecule-change'
       },
       { // 步骤4
         options: ['correct', 'wrong', 'wrong', 'wrong'],
         explain: '参加反应的A₂为2个，B₂为1个，比例为2:1而非4:1',
         reactionLabel: true,
         auxType: 'ratio'
       }
     ];
     ```

  3. **SVG 元素更新策略**：
     - 选项卡片：通过修改 rect 的 fill 和 stroke 属性切换样式
     - 解释框：通过修改 visibility 和 y 属性控制显示/隐藏和位置
     - 辅助图示区：清空 group 内子元素，根据 auxType 重新绘制
     - 按钮：通过修改 fill 和 pointer-events 控制启用/禁用状态

  4. **分子绘制函数**：
     - `drawA2(group, cx, cy, scale=1)`：绘制A₂分子（两白圈+连线）
     - `drawB2(group, cx, cy, scale=1)`：绘制B₂分子（两黑圈+连线）
     - `drawAB2(group, cx, cy, scale=1)`：绘制AB₂分子（一黑两白+V形连线）
     - scale 参数控制分子大小（辅助图示区用 scale=1，放大图用 scale=1.5）

  5. **动画过渡**：
     - 解释框出现：使用 CSS transition（opacity 0→1，transform translateX）
     - 选项卡片变色：使用 CSS transition（fill/stroke 0.3s ease）
     - 辅助图示切换：淡入淡出（opacity 0→1，0.3s）

  6. **事件绑定**：
     - 上一步按钮：`onclick="scene2PrevStep()"`
     - 下一步按钮：`onclick="scene2NextStep()"`
     - 在 IIFE 内部定义，通过 `document.getElementById` 绑定

- **ID 命名规范**：所有交互元素 ID 以 `scene2-` 为前缀
  - `scene2-eq`：化学方程式文本
  - `scene2-reaction-label`：化合反应标签
  - `scene2-opt-a` / `scene2-opt-b` / `scene2-opt-c` / `scene2-opt-d`：四个选项卡片
  - `scene2-opt-a-text` / `scene2-opt-a-result`：选项A的文字和结果
  - `scene2-explain-box`：解释框矩形
  - `scene2-explain-text`：解释框文字
  - `scene2-aux-group`：辅助图示区容器
  - `scene2-btn-prev`：上一步按钮
  - `scene2-btn-next`：下一步按钮
  - `scene2-step-indicator`：步骤指示器

- **IIFE 隔离**：所有 JS 代码包裹在 `(function() { ... })()` 中，避免全局污染
  - 状态变量 `currentStep` 在闭包内
  - 渲染函数 `renderStep()` 在闭包内
  - 按钮回调通过闭包访问状态变量
