[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于(250,455)，尺寸100×30，点击返回上一步，步骤0时禁用
  - 「下一步 ▶」按钮：位于(450,455)，尺寸100×30，点击进入下一步，步骤5时禁用
  - 步骤指示器：位于(400,470)，显示"当前步/总步数"（如"1/5"）
- 教师操作流程：
  1. 初始状态展示四个坐标图，教师可先让学生观察并猜测
  2. 点击「下一步」逐一分析A/B/C/D四个选项，每步显示化学方程式、正误判断和原因
  3. 点击「上一步」可回退复习任意步骤
  4. 到达步骤5显示总结，正确答案C高亮显示

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无需外部库，简单几何图形和状态切换用原生即可实现）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +---------------------------------------------------+
  |  A(左上)                    B(右上)               |
  |  [坐标图 320×95]           [坐标图 320×95]        |
  |                                                   |
  |  C(左下)                    D(右下)               |
  |  [坐标图 320×95]           [坐标图 320×95]        |
  |                                                   |
  |  ─────────── 分析区 ───────────                   |
  |  化学方程式（居中）                               |
  |  正误标记（居中）                                 |
  |  原因说明（居中）                                 |
  |                                                   |
  |  ─────────── 控件区 ───────────                   |
  |     [◀ 上一步]        [下一步 ▶]                  |
  |                    步骤指示器                     |
  +---------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：定义6个状态（step 0~5），每个状态对应一组视觉配置（高亮图、分析区文字、按钮状态）
  2. 状态数据表：用JS数组存储每个步骤的配置（highlightGraph、equation、judgment、reason、btnPrevDisabled、btnNextDisabled）
  3. 坐标计算：所有图形元素使用绝对坐标，SVG内直接定义path/line/polyline
  4. 动画曲线：步骤切换时使用CSS transition（0.3s ease）实现边框颜色、透明度、文字淡入淡出
  5. 事件绑定：按钮点击事件绑定到renderStep(currentStep ± 1)函数
  6. 文字换行：原因说明文本较长，使用SVG <text>的<tspan>分行或CSS white-space处理
- ID 命名规范：所有交互元素ID以 scene1- 为前缀
  - scene1-graph-a, scene1-graph-b, scene1-graph-c, scene1-graph-d（四个图的容器）
  - scene1-eq-text（化学方程式文本）
  - scene1-judgment-text（正误标记文本）
  - scene1-reason-text（原因说明文本）
  - scene1-step-indicator（步骤指示器）
  - scene1-btn-prev（上一步按钮）
  - scene1-btn-next（下一步按钮）
- IIFE 隔离：所有JS代码包裹在 (function() { ... })() 中，避免全局污染
