[图示主题与整合说明]
- 本图示主题：两种放置方式（叠放与并排）的对比与整体受力分析，揭示滑动摩擦力与接触面积和速度无关
- 整合的步骤/概念：
  1. 展示图甲（叠放）与图乙（并排）的初始状态及已知条件
  2. 对图甲进行整体受力分析，建立 F₁ 与摩擦力的平衡关系
  3. 对图乙进行整体受力分析，建立 F₂ 与摩擦力的平衡关系
  4. 对比两图的压力与摩擦系数，得出 F₂ = F₁ = 100N 的结论
  5. 澄清常见误区（接触面积、速度不影响滑动摩擦力）
- 教学价值：教师可通过分步按钮控制讲解节奏，先让学生观察现象，再逐步引导受力分析，最后通过对比得出结论并纠正易错点，符合认知递进规律。

[分步序列]
- 初始状态（步骤0）：
  - 显示：地面、图甲(A叠B)、图乙(A并B)、推力F₁/F₂、速度V₁/V₂、木块标签A/B、图注
  - 隐藏：所有受力分析箭头(重力/支持力/摩擦力)、关系式文本框
  - 目的：展示题目原始场景与已知条件

- 步骤1（图甲受力分析）：
  - 显示：图甲的重力2mg(向下)、支持力N₁(向上)、摩擦力f₁(向左)
  - 显示：关系式文本框(左栏) "F₁ = f₁ = μ·2mg = 100N"
  - 隐藏：图乙受力箭头、右侧关系式
  - 目的：建立叠放状态下的力平衡关系

- 步骤2（图乙受力分析）：
  - 显示：图乙的重力2mg(向下)、支持力N₂(向上)、摩擦力f₂(向左)
  - 显示：关系式文本框(右栏) "F₂ = f₂ = μ·2mg"
  - 隐藏：左侧关系式(或保留，视空间而定，建议保留以便对比)
  - 目的：建立并排状态下的力平衡关系

- 步骤3（对比结论）：
  - 高亮：N₁与N₂标签变黄底#fff9c4，F₁与F₂标签同步高亮
  - 显示：中央关系式文本框 "N₁=N₂=2mg, μ相同 → f₁=f₂ → F₂=F₁=100N"
  - 附加：在V₁/V₂标签旁添加小字提示"速度不影响摩擦力"
  - 目的：通过对比压力与摩擦系数，得出推力相等的结论

- 步骤4（易错提醒）：
  - 显示：下方卡片 "❌ 接触面积变大→摩擦力变大(错误)  ❌ 速度变大→摩擦力变大(错误)"
  - 显示：下方卡片 "✅ 滑动摩擦力只与压力和接触面粗糙程度有关"
  - 目的：澄清常见误区，巩固正确概念

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」：位于(250,450)，点击返回上一状态，步骤0时禁用
  - 「下一步 ▶」：位于(450,450)，点击进入下一状态，步骤4时禁用
- 教师操作流程：
  1. 初始展示题目场景，提问学生观察两图差异
  2. 点击「下一步」逐步添加受力箭头，引导学生分析平衡条件
  3. 点击「下一步」展示对比结论，强调压力与摩擦系数相同
  4. 点击「下一步」展示易错提醒，纠正错误认知
  5. 可随时点击「上一步」回退复习任意步骤

[技术实现]
- JS 库选择：原生 SVG + Vanilla JS（无需外部库，轻量高效，适合静态几何与分步动画）
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [ 图甲区域 x=50~350 ]  [ 图乙区域 x=450~750 ]
  [ 木块/力/速度/标签 ]  [ 木块/力/速度/标签 ]
  [ 地面线 y=300 ]
  [ 关系式文本框 y=380~420 (动态居中/分栏) ]
  [ 导航按钮 y=450~490 ]
  ```
- 关键实现要点：
  1. 状态机：`currentStep` (0~4)，`updateScene(step)` 函数根据步骤显示/隐藏/高亮对应 SVG 元素
  2. 元素分组：使用 `<g id="scene1-forces-甲">`、`<g id="scene1-forces-乙">`、`<g id="scene1-formula">` 等分组，便于批量控制 `display` 或 `opacity`
  3. 动画：使用 CSS `transition: opacity 0.3s ease` 实现平滑淡入淡出
  4. 事件绑定：按钮点击触发 `currentStep++/--` 并调用 `updateScene()`
  5. 高亮效果：步骤3通过添加 class `.highlight` (fill:#fff9c4) 实现标签背景高亮
- ID 命名规范：所有交互元素 ID 以 `scene1-` 为前缀（如 `scene1-btn-next`, `scene1-forces-甲`, `scene1-formula-box`）
- IIFE 隔离：所有 JS 代码包裹在 `(function() { ... })();` 中，避免全局污染
