[图示主题与整合说明]
- 本图示主题：利用平移法求阶梯状多边形周长
- 整合的步骤/概念：展示原图及边长标注 → 水平边平移关系（h+f+d=b） → 垂直边平移关系（a+e=c+g） → 周长公式推导与计算结果
- 教学价值：教师可通过分步导航控制讲解节奏，直观演示“平移补全”思想，帮助学生理解不规则图形周长转化为规则矩形周长加额外边的计算逻辑，强化空间想象与代数代换能力。

[分步序列]
- 初始状态（步骤0）：
  - 显示完整多边形轮廓（黑色实线）。
  - 显示8个边长字母标签（a~h）。
  - 底部显示已知条件文本："b=50米, c=30米, g=10米"。
  - 按钮状态：「上一步」禁用，「下一步」可用。
- 步骤1（水平边关系）：
  - 点击「下一步」触发。
  - 边 h, f, d, b 高亮为蓝色（#1565c0）。
  - 出现蓝色垂直虚线，将 h, f, d 向下平移投影至底部水平线，视觉上拼合成长度等于 b 的线段。
  - 底部文本替换为："h + f + d = b = 50米"（蓝色）。
  - 按钮状态：「上一步」「下一步」均可用。
- 步骤2（垂直边关系）：
  - 点击「下一步」触发。
  - 边 a, g, e, c 高亮为红色（#c62828）。
  - 出现红色水平虚线，将 a, e 向右平移投影至右侧垂直线，视觉上拼合成长度等于 c+g 的线段。
  - 图形右侧出现文本："a + e = c + g = 40米"（红色）。
  - 底部文本保持步骤1内容或淡出（建议淡出步骤1文本，仅保留步骤2文本在右侧，底部清空）。
  - 按钮状态：「上一步」「下一步」均可用。
- 步骤3（周长计算）：
  - 点击「下一步」触发。
  - 所有高亮虚线淡出。
  - 整个多边形轮廓高亮为绿色（#2e7d32），线宽加粗至3px。
  - 底部显示公式："周长 = 2(b + c + g) = 2×(50+30+10) = 180米"（绿色）。
  - 右侧步骤2文本保留或淡出（建议保留以作参考）。
  - 按钮状态：「上一步」可用，「下一步」禁用。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」：位于 (330, 455)，点击回退至上一状态，恢复对应视觉元素。
  - 「下一步 ▶」：位于 (410, 455)，点击推进至下一状态，触发新元素显示/高亮/文本替换。
- 教师操作流程：
  1. 初始展示图形与已知条件，引导学生观察。
  2. 点击「下一步」演示水平边平移，讲解 h+f+d=b。
  3. 再次点击演示垂直边平移，讲解 a+e=c+g。
  4. 最后点击展示周长公式与计算结果，总结方法。
  5. 可随时点击「上一步」回顾任意步骤。

[技术实现]
- JS 库选择：原生 SVG + Vanilla JS。无需重型库，SVG 原生支持路径、虚线、文本锚点、CSS 过渡动画，性能最佳且代码轻量。
- 画布尺寸：800 × 500 px（固定 viewBox）。
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |                  (y=0~180)                       |
  |           [d]                         [c]        |
  |      +-------+                          |        |
  |      |       |                          |        |
  | [h]  |       |                  [e]     |        |
  |  +---+       +---+              |       |        |
  |  |   |       |   |              |       |        |
  | [a] |   [g]  |   | [f]          |       |        |
  |  |   |       |   |              |       |        |
  |  +---+-------+---+--------------+-------+        |
  |                  [b]                              |
  |              (y=350~380)                          |
  |           [已知条件/等式/公式]                     |
  |              (y=420)                              |
  |                                                  |
  |        [◀ 上一步]      [下一步 ▶]                |
  |              (y=455)                              |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  - 状态机：使用变量 `currentStep` (0~3) 管理状态。`renderStep(step)` 函数根据 step 值切换 SVG 元素的 `display`、`stroke`、`opacity` 属性。
  - 动画：使用 CSS `transition: all 0.4s ease` 实现高亮颜色切换与虚线淡入淡出。
  - 坐标计算：所有点坐标硬编码在 JS 数组中，便于维护。虚线通过 `<line>` 元素动态生成或预设 `opacity:0` 后切换。
  - 事件绑定：按钮绑定 `click` 事件，更新 `currentStep` 并调用 `renderStep()`。边界检查（step<0 或 step>3 时禁用对应按钮）。
- ID 命名规范：所有交互元素及关键 SVG 元素 ID 以 `scene1-` 为前缀，例如 `scene1-poly`, `scene1-label-a`, `scene1-btn-next`, `scene1-eq-horz`。
- IIFE 隔离：全部 JS 逻辑包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染。
- CSS 样式内联或 `<style>` 块限定在 `#scene1-container` 下，防止多场景合并时样式冲突。
