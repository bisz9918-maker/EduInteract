[图示主题与整合说明]
- 本图示主题：系统计数法——按组合规模分类数出所有长方形
- 整合的步骤/概念：原始图形展示 → 基本长方形编号 → 按组合规模（单个/两个/三个/四个）逐类高亮计数 → 总数汇总
- 教学价值：教师通过分步按钮控制讲解节奏，学生能清晰看到每一类长方形是如何组合形成的，理解"4+3+2+1=10"的系统计数逻辑，避免遗漏或重复

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位置(310,455)-(410,491)，点击回退到前一步状态，步骤0时禁用
  - 「下一步 ▶」按钮：位置(430,455)-(530,491)，点击进入下一步状态，步骤5时变为禁用
- 教师操作流程：
  1. 展示初始图形，引导学生观察四个基本长方形
  2. 点击「下一步」逐步展示每一类长方形组合，配合口头讲解
  3. 每一步暂停让学生思考，再点击继续
  4. 到达步骤5展示总数算式和答案
  5. 可随时点击「上一步」回退复习任意步骤

[技术实现]
- JS 库选择：原生 SVG（简单矩形和线条图形，无需复杂库；SVG 原生支持 fill-opacity 实现半透明高亮；事件绑定简单直接）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+  y=0
  |                                                  |
  |    请按顺序数出所有长方形（步骤0显示）            |  y=80
  |                                                  |
  |  +---+---+-------+------+    计数               |  y=120
  |  | ① | ② |   ③  |   ④  |                       |
  |  |   |   |       |      |    单个：4个          |  y=180
  |  |   |   |       |      |    两个组合：3个      |  y=230
  |  |   |   |       |      |    三个组合：2个      |  y=280
  |  +---+---+-------+------+    四个组合：1个      |  y=330
  |                                                  |  y=340
  |                                                  |
  |         4 + 3 + 2 + 1 = 10                       |  y=410
  |              答案：C. 10                          |  y=435
  |                                                  |
  |      [◀ 上一步]    [下一步 ▶]                    |  y=455~491
  +--------------------------------------------------+  y=500
  ```
- 关键实现要点：
  1. **状态机设计**：用变量 `currentStep`（0~5）跟踪当前步骤，每个步骤对应一组高亮矩形的显示/隐藏
  2. **高亮矩形管理**：用 SVG `<g>` 分组管理每一步的高亮矩形，通过 `display: none/block` 控制显隐
     - `scene1-step1-group`：4个蓝色矩形
     - `scene1-step2-group`：3个红色矩形
     - `scene1-step3-group`：2个绿色矩形
     - `scene1-step4-group`：1个紫色矩形
  3. **计数面板激活**：通过修改 text 元素的 fill 和 font-weight 实现激活效果
  4. **按钮状态管理**：步骤0时上一步按钮 disabled，步骤5时下一步按钮 disabled
  5. **动画过渡**：高亮矩形出现时使用 CSS transition（opacity 0.3s ease-in）
  6. **事件绑定**：按钮点击事件绑定到 `handlePrev()` 和 `handleNext()` 函数
- ID 命名规范：所有交互元素 ID 以 `scene1-` 为前缀
  - `scene1-svg`：主 SVG 容器
  - `scene1-outline`：大长方形外框
  - `scene1-div1`, `scene1-div2`, `scene1-div3`：三条分割线
  - `scene1-label1`~`scene1-label4`：编号标签①②③④
  - `scene1-step1-group`~`scene1-step4-group`：各步高亮组
  - `scene1-count-title`：计数面板标题
  - `scene1-count1`~`scene1-count4`：四行计数文字
  - `scene1-formula`：算式文字
  - `scene1-answer`：答案文字
  - `scene1-hint`：提示文字
  - `scene1-prev-btn`：上一步按钮
  - `scene1-next-btn`：下一步按钮
- IIFE 隔离：所有 JS 代码包裹在 `(function() { ... })()` 中，避免全局污染
