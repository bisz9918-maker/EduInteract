[图示主题与整合说明]
- 本图示主题：通过同一区域铺设对比，直观展示地砖面积与所需块数的反比例关系
- 整合的步骤/概念：
  1. 认识两种地砖（2dm 和 3dm）的边长差异
  2. 计算两种地砖的面积（4 dm² 和 9 dm²）
  3. 用 6dm×6dm 标准区域分别铺设，对比块数（4块 vs 9块）
  4. 推导总面积和所需块数，得出答案 900
- 教学价值：教师通过分步按钮逐步引导学生观察地砖大小→面积计算→铺设对比→反比例推导，每一步都有明确的视觉变化，帮助学生理解"面积越大，所需块数越少"的反比例关系

[分步序列]

步骤0（初始状态）：
- 显示：2dm地砖（左侧）、3dm地砖（右侧）、边长标签"2dm"和"3dm"
- 不显示：面积计算、铺设区域、推导公式
- 视觉焦点：两种地砖的大小对比
- 教师引导："同学们看，这两种地砖哪个大？"

步骤1（点击"下一步"）：
- 新增：面积计算标签"2×2=4 dm²"（2dm地砖下方）和"3×3=9 dm²"（3dm地砖下方）
- 高亮：面积数值"4 dm²"用红色、"9 dm²"用蓝色
- 动画：面积标签从下方淡入（opacity 0→1，duration 400ms）
- 教师引导："我们来计算一下面积，2dm地砖面积是4平方分米，3dm地砖面积是9平方分米"

步骤2（点击"下一步"）：
- 替换：隐藏步骤0-1的地砖，显示两个6dm×6dm区域
- 左区域：蓝色系，用3dm地砖（150px）2×2排列铺满，标注"4块"
- 右区域：红色系，用2dm地砖（100px）3×3排列铺满，标注"9块"
- 中间标注"对比"
- 动画：两个区域从中心向外展开（scale 0→1，duration 500ms），网格线逐条出现
- 教师引导："我们用同样大小的6dm×6dm区域来铺地砖，看！3dm地砖只需要4块，2dm地砖需要9块"

步骤3（点击"下一步"）：
- 变化：两个区域缩小并上移（左区域180×180，右区域180×180）
- 新增：推导公式和答案
  - "总面积 = 400 × 9 = 3600 dm²"
  - "2dm地砖 = 3600 ÷ 4 = 900 块"
  - 答案"900"绿色高亮放大显示
- 动画：公式逐行淡入（每行间隔300ms），答案最后弹出（scale 0.5→1，bounce效果）
- 教师引导："题目说3dm地砖需要400块，总面积就是400×9=3600平方分米。那么2dm地砖需要3600÷4=900块！答案是900"

[标签冲突检查]

步骤0-1标签：
- "2dm"：(115, 185)
- "3dm"：(490, 155)
- "2×2=4 dm²"：(200, 260)
- "3×3=9 dm²"：(600, 255)
- "2dm"与"3dm"间距：√((490-115)²+(155-185)²) ≈ 377px → 无冲突
- "2dm"与"2×2=4 dm²"间距：√((200-115)²+(260-185)²) ≈ 116px → 无冲突
- "3dm"与"3×3=9 dm²"间距：√((600-490)²+(255-155)²) ≈ 134px → 无冲突
- "2×2=4 dm²"与"3×3=9 dm²"间距：√((600-200)²+(255-260)²) ≈ 400px → 无冲突

步骤2标签：
- 左区域标题"6dm×6dm"：(230, 40)
- 右区域标题"6dm×6dm"：(570, 40)
- 左区域块数"4块"：(230, 370)
- 右区域块数"9块"：(570, 370)
- 中间"对比"：(350, 200)
- 左标题与右标题间距：340px → 无冲突
- 左块数与右块数间距：340px → 无冲突
- 标题与块数垂直间距：330px → 无冲突
- "对比"与左标题间距：√((350-230)²+(200-40)²) ≈ 184px → 无冲突
- "对比"与右标题间距：√((570-350)²+(200-40)²) ≈ 234px → 无冲突

步骤3标签：
- 左块数"4块"：(190, 240)
- 右块数"9块"：(610, 240)
- 公式1"总面积..."：(400, 300)
- 公式2"2dm地砖..."：(400, 350)
- 答案"900"：(400, 410)
- 左块数与公式1间距：√((400-190)²+(300-240)²) ≈ 219px → 无冲突
- 公式1与公式2间距：50px → 无冲突（行间距足够）
- 公式2与答案间距：60px → 无冲突
- 答案与控件栏间距：455-410=45px → 无冲突

结论：所有标签间距均 ≥ 20px，无冲突。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  1. "◀上一步"按钮：位于(250,455)，100×36px，点击返回上一步骤，步骤0时禁用（灰色）
  2. "下一步▶"按钮：位于(450,455)，100×36px，点击进入下一步骤，步骤3时禁用（灰色）
  3. 步骤指示"1/4"：位于(400,455)，显示当前步骤/总步骤数
- 教师操作流程：
  1. 页面加载显示步骤0（两种地砖对比），教师提问引导学生观察
  2. 点击"下一步"进入步骤1，展示面积计算，教师讲解面积公式
  3. 点击"下一步"进入步骤2，展示铺设对比，教师引导学生数块数
  4. 点击"下一步"进入步骤3，展示推导过程和答案，教师总结反比例关系
  5. 可随时点击"上一步"回退到任意步骤复习

- 关键实现要点：
  1. 状态机设计：当前步骤 currentStep (0~3)，通过 renderStep(step) 函数渲染对应步骤
  2. 步骤切换：点击按钮时 currentStep++/--，调用 renderStep(currentStep)
  3. 动画实现：使用 CSS transition 实现淡入（opacity）、缩放（transform: scale）、位移（transform: translate）
  4. 地砖网格绘制：用 SVG <line> 元素绘制虚线网格，3dm区域2条线（x=230, y=200），2dm区域4条线（x=520,620, y=150,250）
  5. 步骤3缩小动画：左区域从(80,50,300,300)缩放到(100,40,180,180)，右区域从(420,50,300,300)缩放到(520,40,180,180)，使用 CSS transform-origin 控制缩放中心
  6. 按钮禁用状态：步骤0时"上一步"按钮 opacity=0.4 pointer-events=none，步骤3时"下一步"按钮同理
  7. 事件绑定：按钮使用 onclick 绑定，不依赖全局 class

- ID 命名规范：所有交互元素 ID 以 scene1- 为前缀
  - scene1-step-prev：上一步按钮
  - scene1-step-next：下一步按钮
  - scene1-step-indicator：步骤指示文本
  - scene1-tile-2dm：2dm地砖元素
  - scene1-tile-3dm：3dm地砖元素
  - scene1-area-left：左铺设区域
  - scene1-area-right：右铺设区域
  - scene1-formula-1：推导公式1
  - scene1-formula-2：推导公式2
  - scene1-answer：答案元素
  - scene1-label-*：各类标签元素

- IIFE 隔离：所有 JS 代码包裹在 (function() { 'use strict'; ... })() 中，避免全局污染
