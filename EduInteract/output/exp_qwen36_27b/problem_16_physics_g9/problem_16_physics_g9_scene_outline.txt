    **题目原文：**

    如图所示，电源电压恒定，闭合开关后，将滑动变阻器的滑片向右端移动的过程中，下列说法正确的是（  ）

    A．电流表示数变小，电压表V$_{1}$示数变大

    B．小灯泡变暗，电压表V$_{2}$示数变小

    C．电压表V$_{1}$和电压表V$_{2}$示数之和不变

    D．电路的总功率变大

    **题目分析：**

    本题是一道典型的初中物理动态电路分析题，考查串联电路中滑动变阻器滑片移动时各电表示数的变化规律。

    **电路结构：**
    - 电源、开关、小灯泡、滑动变阻器组成串联电路
    - 电流表串联在电路中，测量电路总电流
    - 电压表V$_{1}$并联在小灯泡两端，测灯泡电压
    - 电压表V$_{2}$并联在滑动变阻器两端，测变阻器电压

    **核心知识点：**
    1. 串联电路电流处处相等：I = I$_{灯}$ = I$_{变}$
    2. 串联电路电压分配：U = U$_{灯}$ + U$_{变}$
    3. 欧姆定律：I = U / R$_{总}$
    4. 串联分压：U$_{灯}$ = I × R$_{灯}$，U$_{变}$ = I × R$_{变}$
    5. 电功率：P = UI

    **解题思路：**
    滑片右移 → R$_{变}$增大 → R$_{总}$增大 → I减小（电流表示数变小）→ U$_{灯}$ = I×R$_{灯}$减小（V$_{1}$示数变小，灯泡变暗）→ U$_{变}$ = U - U$_{灯}$增大（V$_{2}$示数变大）→ P = UI减小

    **正确答案：C**（V$_{1}$ + V$_{2}$ = U = 恒定值）

    **图示规划说明：**

    本题需要两个核心图示：
    - **Scene 1**：交互式电路图——完整呈现原电路，支持滑片拖动，实时显示各电表示数变化，帮助学生直观理解动态过程
    - **Scene 2**：变量关系分析图——用分步按钮展示逻辑推导链条，从"滑片右移"到最终结论的完整推理过程
    </TEXT_1>

    **Scene 1 教学说明：**

    本图示是课堂讲解的核心工具，教师可按以下步骤引导学生：

    **第一步：认识电路结构**
    - 引导学生识别电路中的各元件：电源、开关、灯泡、滑动变阻器、电流表、两个电压表
    - 明确连接方式：灯泡与变阻器**串联**
    - 明确各电表测量对象：
      - 电流表测**电路总电流**
      - V$_{1}$测**灯泡两端电压**
      - V$_{2}$测**变阻器两端电压**

    **第二步：操作滑片，观察现象**
    - 让滑片从中间向右移动，引导学生观察：
      - 电流表示数**变小**
      - V$_{1}$示数**变小**（灯泡变暗）
      - V$_{2}$示数**变大**
      - V$_{1}$ + V$_{2}$ **始终不变**（等于电源电压）
    - 提问：为什么V$_{1}$和V$_{2}$一个变大一个变小，但它们的和不变？

    **第三步：引导学生总结规律**
    - 串联电路中，各用电器两端电压之和等于电源电压
    - 即 U$_{灯}$ + U$_{变}$ = U$_{电源}$ = 恒定值
    - 这就是选项C正确的根本原因

    **关键公式：**
    1. R$_{总}$ = R$_{灯}$ + R$_{变}$
    2. I = U / R$_{总}$
    3. U$_{灯}$ = I × R$_{灯}$
    4. U$_{变}$ = I × R$_{变}$ = U - U$_{灯}$
    5. U$_{灯}$ + U$_{变}$ = U（恒定）

    **Scene 2 教学说明：**

    本图示用于系统梳理解题逻辑，教师可按以下步骤讲解：

    **步骤0：明确已知条件**
    - 电源电压恒定（U不变）
    - 滑片向右移动（这是引发一切变化的起点）

    **步骤1：分析电阻变化**
    - 滑片右移 → 变阻器接入电路的电阻丝变长 → R$_{变}$增大
    - 串联电路：R$_{总}$ = R$_{灯}$ + R$_{变}$ → R$_{总}$增大

    **步骤2：分析电流变化**
    - 由欧姆定律：I = U / R$_{总}$
    - U不变，R$_{总}$增大 → I减小
    - **电流表示数变小**

    **步骤3：分析电压变化**
    - 灯泡电压：U$_{灯}$ = I × R$_{灯}$，I减小，R$_{灯}$不变 → U$_{灯}$减小
    - **V$_{1}$示数变小**
    - 变阻器电压：U$_{变}$ = U - U$_{灯}$，U不变，U$_{灯}$减小 → U$_{变}$增大
    - **V$_{2}$示数变大**
    - 关键发现：U$_{灯}$ + U$_{变}$ = U = 恒定值
    - **V$_{1}$ + V$_{2}$ 不变**

    **步骤4：分析功率和亮度**
    - 总功率：P = UI，U不变，I减小 → P减小
    - 灯泡功率：P$_{灯}$ = I²R$_{灯}$，I减小 → P$_{灯}$减小 → **灯泡变暗**

    **步骤5：逐项判断选项**
    1. A：电流表↓（✓），V$_{1}$↑（✗，实际是↓）→ **错误**
    2. B：灯泡变暗（✓），V$_{2}$↓（✗，实际是↑）→ **错误**
    3. C：V$_{1}$ + V$_{2}$ = U = 恒定 → **正确**
    4. D：P = UI，I减小 → P减小（✗，不是变大）→ **错误**

    **最终答案：C**

    **课堂讲解建议：**
    - 先让学生用Scene 1的交互图观察现象，形成直观感受
    - 再用Scene 2的逻辑链进行理论推导，建立因果关系
    - 强调"串联电路电压之和等于电源电压"这一不变量，是解题的关键突破口
    - 可引导学生思考：如果滑片向左移动，各量如何变化？（反向验证理解）
