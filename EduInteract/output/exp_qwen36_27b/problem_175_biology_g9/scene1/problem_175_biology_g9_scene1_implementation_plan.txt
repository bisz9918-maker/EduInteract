**步骤0（初始状态）**：

**步骤2（验证选项A）**：

- 特征解析框显示："③蕨类：有根茎叶+输导组织→植株较高大（C错在'矮小'）；④苔藓：有茎叶无根+无输导组织→叶仅一层细胞，易受有毒气体伤害（D张冠李戴，描述实为④的特征）"

- 按钮：「◀上一步」可用，「下一步▶」可用

**步骤5（总结）**：
- 点击「下一步▶」
- 所有分支高亮取消，恢复默认样式
- 仅保留选项A的绿色 ✓ 高亮状态
- 特征解析框显示："✅ 正确答案：A\n核心考点：①裸子植物属于种子植物，适应干旱陆地生活；②藻类'只能'在水中表述绝对；③蕨类有输导组织植株较高大；④苔藓无根无输导组织，叶单层细胞"
- 按钮：「◀上一步」可用，「下一步▶」禁用（已达最后一步）

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「◀上一步」按钮：位于 SVG 底部左侧 (280,465)，点击回退到上一步状态，步骤0时禁用
  - 「下一步▶」按钮：位于 SVG 底部右侧 (430,465)，点击进入下一步状态，步骤5时禁用
  - 步骤指示器：位于按钮上方 (350,455)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始展示分类树和选项，引导学生观察
  2. 点击"下一步"揭示①②③④对应类群，讲解分类逻辑
  3. 依次点击"下一步"验证每个选项，配合特征解析框讲解
  4. 最后一步展示总结，强调核心考点
  5. 可随时点击"上一步"回退复习任意步骤

- 关键实现要点：
  1. **状态机设计**：定义6个状态（step 0-5），每个状态对应一组视觉元素可见性/样式配置
  2. **状态切换函数**：`setStep(n)` 根据步骤编号更新所有元素状态
  3. **淡入动画**：类群名称使用 CSS transition opacity 0.3s ease-in，依次延迟 200ms
  4. **高亮切换**：通过修改节点边框颜色/线宽实现分支高亮，使用 CSS class 切换
  5. **选项状态管理**：每个选项图标维护独立状态（none/correct/wrong），用 SVG circle+text 实现
  6. **特征解析框内容**：每个步骤对应不同的文本内容，通过 innerHTML 或 SVG text 更新
  7. **按钮禁用逻辑**：步骤0时"上一步"disabled，步骤5时"下一步"disabled
- ID 命名规范：所有交互元素 ID 以 `scene1-` 为前缀
  - 节点：`scene1-node-root`, `scene1-node-noseed`, `scene1-node-seed`, `scene1-node-noleaf`, `scene1-node-leaf`, `scene1-node-vascular`, `scene1-node-nowascular`
  - 标注：`scene1-label-1`, `scene1-label-2`, `scene1-label-3`, `scene1-label-4`
  - 类群名：`scene1-group-1`, `scene1-group-2`, `scene1-group-3`, `scene1-group-4`

  - 选项图标：`scene1-icon-a`, `scene1-icon-b`, `scene1-icon-c`, `scene1-icon-d`
  - 解析框：`scene1-analysis-box`
  - 按钮：`scene1-btn-prev`, `scene1-btn-next`
  - 步骤指示器：`scene1-step-indicator`

- IIFE 隔离：所有 JS 代码包裹在 `(function() { 'use strict'; ... })();` 中
