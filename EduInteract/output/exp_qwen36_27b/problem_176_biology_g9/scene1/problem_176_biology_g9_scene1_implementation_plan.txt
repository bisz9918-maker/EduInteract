[图示主题与整合说明]
- 本图示主题：上臂血液循环与丝带扎紧效应的分步演示
- 整合的步骤/概念：
  1. 上臂血管基础结构（动脉与静脉的位置关系）
  2. 血液流动方向标注（静脉回心向上，动脉离心向下）
  3. 丝带扎紧后血管的膨胀/变扁变化
  4. 血管类型判断与含氧量比较，得出正确答案
- 教学价值：教师可通过分步按钮控制讲解节奏，从基础结构逐步深入到现象分析和结论推导，帮助学生理解血液循环原理及血管类型判断方法

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位置(250,450)，尺寸(100×36)，灰色背景#e0e0e0，黑色文字，步骤0时禁用
  - 「下一步 ▶」按钮：位置(450,450)，尺寸(100×36)，蓝色背景#1565c0，白色文字，步骤3时禁用
  - 步骤指示器：位置(370,460)，文字"步骤 X / 3"，黑色#000000，14px
- 教师操作流程：
  1. 图示加载后显示步骤0（基础结构），教师可讲解上臂血管的基本布局
  2. 点击「下一步 ▶」进入步骤1，展示血液流动方向，教师可讲解动脉离心、静脉回心的概念
  3. 点击「下一步 ▶」进入步骤2，展示丝带扎紧后的血管变化，教师可讲解血流阻断原理
  4. 点击「下一步 ▶」进入步骤3，展示完整分析和正确答案，教师可总结血管类型判断方法
  5. 随时点击「◀ 上一步」回退到任意前一步骤复习

[技术实现]
- JS 库选择：原生 SVG（简单几何图形和线条，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────┐
  │                    上臂                              │ (35)
  │  ┌─────────────────────────────────────┐            │
  │  │                                     │            │
  │  │   ④      静脉（回心）  动脉（离心）  ③          │ (160)
  │  │   ↑                               ↓            │
  │  │   │                               │            │

  │  │──────────────── 丝带 ──────────────│  丝带      │ (230)
  │  │         丝带阻断血流               │            │
  │  │   │                               │            │
  │  │   │                               │            │

  ```
- 关键实现要点：
  1. 状态机设计：使用当前步骤变量 currentStep (0-3)，每个步骤对应一组可见元素和样式
  2. 血管分段绘制：步骤2需要将每条血管分为丝带上方段和下方段，分别设置不同线宽和颜色
  3. 动画实现：使用 CSS transition 实现线宽变化（0.5s ease）和元素淡入（opacity 0→1，0.5s）
  4. 事件绑定：按钮点击事件切换 currentStep，调用 renderStep(currentStep) 重绘
  5. 按钮状态管理：步骤0时「上一步」disabled，步骤3时「下一步」disabled
  6. 总结面板内容：使用 SVG <text> 元素逐行渲染，确保文字左对齐
- ID 命名规范：所有交互元素 ID 以 `scene1-` 为前缀
  - 按钮：`scene1-prev-btn`、`scene1-next-btn`
  - 步骤指示器：`scene1-step-indicator`
  - 血管段：`scene1-vein-upper`、`scene1-vein-lower`、`scene1-artery-upper`、`scene1-artery-lower`
  - 箭头：`scene1-vein-arrow`、`scene1-artery-arrow`
  - 编号：`scene1-label-1`、`scene1-label-2`、`scene1-label-3`、`scene1-label-4`
  - 总结面板：`scene1-summary-panel`
  - 高亮框：`scene1-answer-highlight`
- IIFE 隔离：所有 JS 代码包裹在 (function() { 'use strict'; ... })() 中，避免全局污染
