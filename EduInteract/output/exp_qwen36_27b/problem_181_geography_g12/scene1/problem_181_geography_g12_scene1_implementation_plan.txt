[图示主题与整合说明]
- 本图示主题：三圈环流剖面图（图甲）——展示从赤道到北极的气压带与风带分布
- 整合的步骤/概念：低纬/中纬/高纬三个环流圈的气流运动方向、七个关键标注点（A-F、N）、气压带名称与纬度、风带名称、气压带成因（热力/动力）
- 教学价值：教师可通过分步导航，逐步引导学生识别剖面图中的各个气压带和风带，理解气流上升/下沉与气压带形成的关系，并区分热力原因与动力原因，符合从已知到未知的认知递进规律。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于控件栏左侧，点击回退至上一状态（步骤0时禁用）
  - 「步骤 0/5」指示器：位于控件栏中间，显示当前步骤
  - 「下一步 ▶」按钮：位于控件栏右侧，点击前进至下一状态（步骤5时禁用）
- 教师操作流程：
  1. 图示加载后显示基础框架（步骤0），教师讲解三圈环流整体结构。
  2. 点击「下一步」逐步高亮赤道低压带→副热带高压带→副极地低压带→极地高压带，配合讲解气流上升/下沉与气压带形成。
  3. 同步显示风带名称，讲解近地面风向。
  4. 最后一步展示成因，对比热力原因（A/C/N）与动力原因（E）。
  5. 可随时点击「上一步」回顾任意阶段。

[技术实现]
- JS 库选择：原生 SVG + CSS + Vanilla JS（无需外部库，轻量高效，适合静态几何+分步显隐）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |                  [图甲 三圈环流剖面图]             |
  |                                                  |
  |      N(700,120)                                  |
  |     /  F(580,180)  高纬环流圈                     |
  |    /   /  E(460,240)  中纬环流圈                  |
  |   /   /   /  D(340,300)                           |
  |  /   /   /   /  C(220,360)  低纬环流圈            |
  | /   /   /   /   /  B(160,390)                     |
  |/___/___/___/___/___A(100,420)                     |
  |  标签区(左/下/右)                                  |
  |                                                  |
  |              [◀ 上一步] [步骤 0/5] [下一步 ▶]     |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  - 状态机：`currentStep` 变量（0~5），点击按钮时增减并调用 `updateView(step)`
  - 显隐控制：CSS 类 `.hidden { opacity: 0; pointer-events: none; }` 与 `.visible { opacity: 1; transition: opacity 0.4s ease; }`
  - 高亮动画：气压带区域使用 `<path>` 填充，通过切换 CSS 类改变 `fill` 和 `stroke` 颜色及透明度
  - 箭头绘制：SVG `<marker>` 定义箭头，`<path>` 使用 `d` 属性绘制曲线（`Q` 或 `C` 命令模拟环流弯曲）
  - 事件绑定：按钮 `addEventListener('click', ...)`，禁用状态用 `disabled` 属性
- ID 命名规范：所有交互元素及关键图形 ID 以 `scene1-` 为前缀（如 `scene1-ground`, `scene1-cell1`, `scene1-label-A`, `scene1-btn-next`）
- IIFE 隔离：所有 JS 代码包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染
- 防重叠保障：严格按布局坐标表实现，标签使用 `text-anchor="start/middle/end"` 对齐，确保视觉居中且不压线
