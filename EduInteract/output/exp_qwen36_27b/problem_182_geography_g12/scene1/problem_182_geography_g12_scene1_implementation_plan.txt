[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于(250,455)，120×30px，点击回退到上一步骤，步骤0时禁用
  - 「下一步 ▶」按钮：位于(430,455)，120×30px，点击进入下一步骤，步骤3（最终步骤）时禁用
  - 步骤指示器：位于(380,465)，显示"步骤 X/3"，12px灰色文字
- 教师操作流程：
  1. 图示加载后显示步骤0（完整经纬网+五点），教师可先让学生观察全图
  2. 点击「下一步」进入步骤1，高亮A/B点并展示方向判断，教师讲解相对方向
  3. 点击「下一步」进入步骤2，右侧出现公式推导，教师逐步讲解正午太阳高度计算
  4. 点击「下一步」进入步骤3，赤道高亮+结论展示，教师总结答案
  5. 可随时点击「上一步」回退到任意步骤复习

[技术实现]
- JS 库选择：原生 SVG（本场景为简单几何图形+文本标注，无需复杂库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  ┌──────────────────────────────────────────────────────────────┐
  │  180°  120°  60°   0°   60°  120°  180°                     │
  │  ┌─────────────────────────────────────────┐                 │
  90°│                                       │                 │
  60°│              D         E              │                 │
  30°│         A                          │                 │
   0°│              C                      │  ┌──────────┐    │
  30°│              B                      │  │ 公式/结论 │    │
  60°│                                       │  │ 区域     │    │
  90°│                                       │  └──────────┘    │
  │  └─────────────────────────────────────────┘                 │
  │                                                              │
  │           ◀ 上一步          步骤 X/3        下一步 ▶         │
  └──────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 `currentStep` (0~3) 管理当前步骤，每个步骤对应一组SVG元素的显示/隐藏
  2. 元素分组：用 `<g>` 标签按步骤分组（如 `<g id="scene1-step1">`），通过 `display:none/block` 控制显隐
  3. 箭头绘制：使用 `<marker>` 定义箭头头部，`<line>` 绘制箭身
  4. 公式区域切换：步骤2和步骤3共用同一背景框，通过切换内部 `<text>` 元素内容实现
  5. 按钮状态管理：步骤0时「上一步」禁用（opacity=0.5, pointer-events=none），步骤3时「下一步」禁用
  6. 经纬线绘制：经线用实线，纬线用 `stroke-dasharray="6,4"` 虚线
  7. 坐标计算：经线x = 80 + i * (500/6)，纬线y = 60 + j * (320/6)，i,j=0~6
- ID 命名规范：所有SVG元素和交互元素ID以 `scene1-` 为前缀
  - 经纬网：`scene1-grid`, `scene1-meridian-{i}`, `scene1-parallel-{j}`
  - 点：`scene1-point-A`, `scene1-point-B`, `scene1-point-C`, `scene1-point-D`, `scene1-point-E`
  - 标签：`scene1-label-A`, `scene1-label-B`, ...
  - 步骤组：`scene1-step1-group`, `scene1-step2-group`, `scene1-step3-group`
  - 按钮：`scene1-prev-btn`, `scene1-next-btn`
  - 步骤指示器：`scene1-step-indicator`
  - 公式区域：`scene1-formula-bg`, `scene1-formula-content`, `scene1-conclusion-content`
  - 赤道高亮：`scene1-equator-highlight`
  - 方向箭头：`scene1-direction-arrow`
- IIFE 隔离：所有JS代码包裹在 `(function() { 'use strict'; ... })();` 中
- 事件绑定：按钮使用 `addEventListener('click', ...)` 绑定，不使用内联事件处理器
