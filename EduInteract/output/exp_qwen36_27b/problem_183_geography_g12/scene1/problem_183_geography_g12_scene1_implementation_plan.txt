[图示主题与整合说明]

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：位于(250,465)，80×25px，灰色背景，点击回到上一步骤（步骤0时禁用）
  - "步骤 X/4"指示器：位于(400,480)，显示当前步骤编号
  - "下一步 ▶"按钮：位于(550,465)，80×25px，蓝色背景(#1565c0)，点击进入下一步骤（步骤4时禁用）
- 教师操作流程：
  1. 图示加载后显示步骤0（基础公转图），教师可先让学生观察整体
  2. 点击"下一步"进入步骤1，引导学生观察A位置地轴倾斜方向与太阳直射点的关系，得出"夏至"结论
  3. 点击"下一步"进入步骤2，同理分析C位置，得出"冬至"结论
  4. 点击"下一步"进入步骤3，标注B和D的节气，展示公转方向
  5. 点击"下一步"进入步骤4，展示完整结论面板，总结二分二至日
  6. 可随时点击"上一步"回退到任意步骤复习

[技术实现]
- JS 库选择：原生 SVG（本场景为静态几何图形+分步显示，无需复杂动画库，原生 SVG 最轻量高效）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  ┌──────────────────────────────────────────────────────┐
  │              地球公转示意图 (y=22)                     │
  │                                                      │
  │                    D (y=55)                          │
  │                      ⊙                               │
  │                     /|\                              │
  │                    / | \                             │
  │                   /  |  \                            │
  │                  /   |   \                           │
  │                 /    |    \                          │
  │                /     |     \                         │
  │      A ⊙───────┼──────⊙ 太阳 ──────⊙ C              │
  │              (y=240)  (y=240)   (y=240)             │
  │                \     |     /                         │
  │                 \    |    /                          │
  │                  \   |   /                           │
  │                   \  |  /                            │
  │                    \ | /                             │
  │                     \|/                              │
  │                      ⊙                               │
  │                    B (y=380)                         │
  │                                                      │
  │         ┌─────────────────────────────┐              │
  │         │  A=夏至  B=秋分  C=冬至  D=春分 │ (步骤4)   │
  │         └─────────────────────────────┘              │
  │                                                      │
  │     [◀ 上一步]    步骤 0/4    [下一步 ▶]             │
  └──────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：维护当前步骤变量 currentStep（0~4），每个步骤对应一组可见元素
  2. 元素显隐控制：使用 CSS class `.hidden { display: none; }` 控制步骤专属元素的显示/隐藏
  3. 地球高亮：步骤1/2中通过修改地球描边颜色（stroke）和线宽（stroke-width）实现高亮
  4. 箭头标记：使用 SVG `<marker>` 定义箭头头部，红色箭头用 `marker-end`
  5. 按钮状态：步骤0时"上一步"按钮 disabled，步骤4时"下一步"按钮 disabled
  6. 过渡动画：元素出现时使用 CSS transition（opacity 0→1，duration 0.3s）
- ID 命名规范：所有交互元素 ID 以 `scene1-` 为前缀
  - 地球：`scene1-earth-a`、`scene1-earth-b`、`scene1-earth-c`、`scene1-earth-d`
  - 太阳：`scene1-sun`
  - 轨道：`scene1-orbit`
  - 步骤1元素：`scene1-step1-arrow`、`scene1-step1-label`
  - 步骤2元素：`scene1-step2-arrow`、`scene1-step2-label`
  - 步骤3元素：`scene1-step3-equinox-b`、`scene1-step3-equinox-d`、`scene1-step3-arrows`
  - 步骤4元素：`scene1-step4-panel`、`scene1-step4-text`
  - 控件：`scene1-btn-prev`、`scene1-btn-next`、`scene1-step-indicator`
- IIFE 隔离：所有 JS 代码包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染
- SVG 结构：使用 `<defs>` 定义箭头标记和样式，使用 `<g>` 分组管理各步骤元素
