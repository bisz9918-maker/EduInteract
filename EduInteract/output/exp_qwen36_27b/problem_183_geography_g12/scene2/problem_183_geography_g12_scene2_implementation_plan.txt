[图示主题与整合说明]
- 本图示主题：节气与地理现象的关系——夏至与冬至对比
- 整合的步骤/概念：夏至时的昼夜长短/极昼极夜/正午太阳高度 → 冬至时的昼夜长短/极昼极夜/正午太阳高度 → 对比总结
- 教学价值：教师通过切换夏至/冬至两个状态，直观展示地球光照侧视图中地轴倾斜方向变化如何导致昼夜长短、极昼极夜范围、正午太阳高度的差异，帮助学生理解地球公转与地理现象之间的因果关系，对应题目第二问的三个填空

[分步序列]
本场景为多状态切换交互，共2个状态：

- 初始状态（状态1：夏至/A）：
  1. 地球圆显示，地轴向右倾斜23.5°（北端倾向太阳）
  2. 晨昏线垂直通过圆心，昼半球在右侧（#fff9c4），夜半球在左侧（#37474f）
  3. 北极圈内昼半球侧高亮蓝色（#1565c0），标注"极昼"
  4. 南极圈内夜半球侧高亮红色（#c62828），标注"极夜"
  5. 南回归线以南区域显示正午太阳高度角弧线，标注"约43°"
  6. 太阳光线从右侧射入，太阳图标在(460,250)
  7. 信息面板显示：
     - 标题："夏至（A）"
     - "北半球：昼长夜短"
     - "北极圈：极昼"
     - "南极圈：极夜"
     - "南回归线以南：正午太阳高度较小"
     - "正午太阳高度角：约43°"
  8. 「夏至(A)」按钮高亮选中，「冬至(C)」按钮未选中
  9. 答案提示区显示："北半球昼最短→C | 南极圈极夜→A | 南回归线以南太阳高度最大→C"

- 状态2（冬至/C）：点击「冬至(C)」按钮切换
  1. 地轴向左倾斜23.5°（北端背离太阳）—— 动画：地轴旋转180°（0.4s ease）
  2. 晨昏线位置不变，但极昼极夜范围翻转
  3. 北极圈内夜半球侧高亮红色（#c62828），标注"极夜"
  4. 南极圈内昼半球侧高亮蓝色（#1565c0），标注"极昼"
  5. 南回归线以南区域正午太阳高度角弧线变大，标注"约90°"
  6. 信息面板更新：
     - 标题："冬至（C）"
     - "北半球：昼短夜长"
     - "北极圈：极夜"
     - "南极圈：极昼"
     - "南回归线以南：正午太阳高度最大"
     - "正午太阳高度角：约90°"
  7. 「冬至(C)」按钮高亮选中，「夏至(A)」按钮未选中
  8. 答案提示区不变（始终显示完整答案对照）

[技术实现]
- JS 库选择：原生 SVG（本场景为静态几何图形+简单状态切换，无需复杂动画库，原生 SVG 最轻量且精确控制每个元素）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────┐
  │                    [ 夏至(A) ] [ 冬至(C) ]                 │ ← 切换按钮 y=15~50
  │                                                            │
  │  北极圈  N          昼半球          太阳光线    信息面板    │
  │    ○────╱│╲─────────┼──────────────→→→→→→→  ┌──────────┐  │
  │          │ │         │      太阳    →→→→→→→  │ 夏至(A)   │  │
  │  晨昏线  │ │  赤道───┼───北回归线  →→→→→→→  │北半球:   │  │
  │    │     │ │         │      ○     →→→→→→→  │昼长夜短  │  │
  │  夜半球  │ │  南回归线│              →→→→→→→  │北极圈:   │  │
  │          │ │         │                    └──────────┘  │
  │    ○────╲│╱─────────┼───────────────────────────────────  │

  │              └──────────────────────────────┘              │
  └────────────────────────────────────────────────────────────┘
  ```

- 关键实现要点：
  1. **状态机设计**：用变量 `currentScene = 'summer' | 'winter'` 管理当前状态，切换时调用 `updateScene(state)` 函数
  2. **地轴动画**：使用 SVG `<animateTransform>` 或 JS 操作 `transform` 属性，旋转中心为地球圆心(250,250)，旋转角度从+23.5°到-23.5°，时长0.4s，ease-in-out
  3. **极昼极夜高亮切换**：用两个 `<path>` 元素分别表示北极圈和南极圈的高亮区域，通过切换 `fill` 颜色（#1565c0 ↔ #c62828）和 `opacity` 实现
  4. **正午太阳高度角**：用 SVG `<path>` 绘制弧线，夏至时弧角约43°，冬至时约90°，切换时更新 `d` 属性和标注文字
  5. **信息面板更新**：切换状态时，用 JS 更新 `<text>` 元素的 `textContent`，配合淡入淡出效果
  6. **按钮样式切换**：选中态 `fill="#2e7d32"` + `fill-opacity="0.8"` + 白字，未选中态 `fill="#e0e0e0"` + 黑字
  7. **事件绑定**：两个按钮绑定 `click` 事件，调用 `switchTo('summer')` 或 `switchTo('winter')`
  8. **太阳光线箭头**：用 SVG `<marker>` 定义箭头，光线线段 `marker-end="url(#arrow)"`
