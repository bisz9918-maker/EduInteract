- 本图示主题：北极俯视图日照综合分析——太阳直射点定位、时间计算、正午太阳高度与自转线速度

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于控件栏左侧 (x=100, y=450)，点击返回上一步，步骤0时禁用
  - 步骤指示器：位于控件栏中央 (x=350, y=455)，显示"步骤 X/5"文字
  - 「下一步 ▶」按钮：位于控件栏右侧 (x=600, y=450)，点击进入下一步，步骤5时禁用
- 教师操作流程：
  1. 图示加载后显示步骤0（基础日照图），教师可先让学生观察整体
  2. 点击「下一步」逐步展示晨昏线、直射点、时间计算、正午太阳高度、线速度比较
  3. 每步右侧推导区同步显示推导过程和答案，教师配合讲解
  4. 可随时点击「上一步」回退复习前面步骤
  5. 到达步骤5后展示完整结论，教师总结知识点

[技术实现]
- JS 库选择：原生 SVG（本场景为几何图形+标注，SVG最适合精确控制每个元素位置和样式）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  +-------------------------------------------------------------+
  |  [日照图区域 x:50~460]        [推导文本区 x:500~740]        |
  |                                                             |
  |       晨昏线          E(280,170)      步骤1: 晨昏线标注     |
  |     /--------\      /-----------\     步骤2: 直射点推导     |
  |    |  夜半球  |    |   昼半球    |     步骤3: 时间计算      |
  |    |  (阴影)  | F  |     G      |     步骤4: 正午太阳高度  |
  |     \--------/      \-----------/     步骤5: 线速度比较     |
  |       E点切点         180°经线                                |
  |                                                             |
  |  0°经线(左)    圆心(280,250)    180°经线(右)                |
  |                                                             |
  |  [自转方向箭头]                                              |
  |                                                             |
  |  +-------------------------------------------------------+  |
  |  |  [◀上一步]     步骤 X/5     [下一步▶]                  |  |
  |  +-------------------------------------------------------+  |
  +-------------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：定义6个状态（步骤0~5），每个状态对应一组可见/隐藏/高亮元素
  2. 状态切换函数：showStep(n) 根据步骤编号更新所有元素可见性和样式
  3. 晨昏线绘制：使用SVG path `M 280,90 Q 260,250 280,410` 绘制弧线
  4. 夜半球填充：使用SVG path定义封闭区域 + hatch图案填充
  5. 极昼区域：使用SVG clipPath裁剪60°N以北的昼半球部分
  6. 动画效果：步骤5中E/F/G点脉冲动画使用CSS @keyframes scale
  7. 线速度箭头：从E/F/G点向外画不同长度的箭头（E:30px, F:50px, G:70px）
  8. 事件绑定：按钮click事件调用showStep(currentStep ± 1)
  9. 按钮禁用状态：步骤0时「上一步」disabled，步骤5时「下一步」disabled
- ID 命名规范：所有交互元素ID以 `scene2-` 为前缀
  - scene2-svg：主SVG容器
  - scene2-equator：赤道圆
  - scene2-lat60：60°N纬线
  - scene2-lat30：30°N纬线（步骤2显示）
  - scene2-meridian-0：0°经线
  - scene2-meridian-180：180°经线
  - scene2-meridian-90e：90°E经线
  - scene2-meridian-90w：90°W经线
  - scene2-terminator：晨昏线
  - scene2-night：夜半球填充
  - scene2-polar-day：极昼区域
  - scene2-point-e：E点
  - scene2-point-f：F点
  - scene2-point-g：G点
  - scene2-rotation-arrow：自转方向箭头
  - scene2-sun-rays：太阳光线组
  - scene2-direct-point：直射点星号标记
  - scene2-label-*：各类标签
  - scene2-derivation：右侧推导文本区
  - scene2-btn-prev：上一步按钮
  - scene2-btn-next：下一步按钮
  - scene2-step-indicator：步骤指示器
  - scene2-conclusion：底部结论栏
- IIFE 隔离：所有JS代码包裹在 (function() { 'use strict'; ... })() 中，避免全局污染
