    根据四季形成的原理，完成下图中的填空：

    - 公转 → ( )平面

    - → ( )变化 和 ( )变化
    - → 地面受热多少变化

    **题目分析：**

    本题以流程图形式考查四季形成的完整因果链条，属于高中地理（G12）核心知识点。学生需要理解从地球运动（自转、公转）到四季交替之间各环节的逻辑关系。

    **正确答案：**
    1. 自转 → **赤道**平面
    2. 公转 → **黄道**平面
    3. 两平面交汇 → **黄赤**交角
    4. 直射点回归 → **正午太阳高度**变化 和 **昼夜长短**变化
    5. 地面受热多少变化 → **气温**变化

    **整体讲解思路：**

    四季形成原理是一个典型的因果链条，讲解时应从因到果逐步推进。首先明确地球自转产生赤道平面、公转产生黄道平面，两平面不重合形成黄赤交角（约23°26'），这是四季形成的根本原因。黄赤交角导致太阳直射点在南北回归线之间往返移动（回归运动），进而引起正午太阳高度和昼夜长短的周期性变化，最终造成地面受热不均和气温变化，形成四季交替。

    **教学说明：**

    本图示以交互式流程图形式呈现四季形成的完整因果链条。教师可按以下步骤引导学生：

    1. **从已知出发**：初始只显示"自转"和"公转"，提问学生"地球自转产生了什么平面？公转又产生了什么平面？"引导学生回答"赤道平面"和"黄道平面"

    2. **引出核心概念**：点击下一步填入答案后，继续推进到两平面交汇，提问"这两个平面重合吗？"引导学生理解两平面存在夹角，即"黄赤交角"（约23°26'）

    3. **理解因果传递**：从黄赤交角开始，逐步展示其对太阳直射点位置的影响，再进一步影响正午太阳高度和昼夜长短

    4. **联系生活实际**：最后引导学生思考"为什么正午太阳高度和昼夜长短的变化会导致四季？"——因为地面受热多少不同，气温随之变化

    **关键公式/数据：**
    - 黄赤交角 ≈ 23°26'
    - 太阳直射点移动范围：南北回归线之间（23°26'N ~ 23°26'S）

    **易错点提醒：**
    - 学生常混淆"赤道平面"和"黄道平面"的对应关系（自转→赤道，公转→黄道）
    - "正午太阳高度"和"昼夜长短"两个变化是并列关系，都受直射点回归影响

    **引导步骤：**

       - 秋分（180°）：直射赤道（0°）

    - 如果没有黄赤交角（地轴垂直于轨道面），直射点将永远在赤道，不会有四季
    - 黄赤交角是四季形成的**根本原因**

    **完整解答总结：**

    四季形成的因果链条：

    1. 地球**自转**产生**赤道平面**，地球**公转**产生**黄道平面**
    2. 赤道平面与黄道平面不重合，二者夹角为**黄赤交角**（约23°26'）
    3. 黄赤交角导致太阳**直射点在南北回归线之间往返移动**（回归运动）
    4. 直射点回归引起**正午太阳高度**和**昼夜长短**的周期性变化
    5. 上述两变化导致**地面受热多少**发生周期性变化
    6. 地面受热变化引起**气温**的周期性变化
    7. 气温的周期性变化最终表现为**四季交替**

    **记忆口诀：**
    自转赤道公转黄，两相交角黄赤当；
    直射回归高度昼，受热气温四季忙。

    **教学建议：**
    - 先用SCENE_1的流程图建立整体框架，再用SCENE_2的公转图深入理解核心概念
    - 强调黄赤交角是四季形成的根本原因，其他环节都是其衍生结果
    - 可结合当地实际气候数据，让学生感受四季变化的真实性
