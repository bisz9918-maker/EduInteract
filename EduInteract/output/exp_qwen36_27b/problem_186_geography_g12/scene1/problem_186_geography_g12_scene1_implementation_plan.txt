[图示主题与整合说明]
- 本图示主题：四季形成原理的完整因果链条流程图
- 整合的步骤/概念：从地球自转/公转到四季交替的全部逻辑环节，包括赤道平面、黄道平面、黄赤交角、直射点回归、正午太阳高度变化、昼夜长短变化、地面受热变化、气温变化
- 教学价值：教师可按讲解节奏逐步揭示因果链条的每个环节，帮助学生理解四季形成的完整逻辑过程。每一步填入一个关键概念，配合颜色高亮引导学生关注当前讲解的因果路径。

- 关键实现要点：
  1. **状态机设计**：维护 currentStep 变量（0~8），每个步骤对应一组激活的方框和箭头。使用状态数组定义每步的激活元素列表。
  2. **SVG 元素结构**：
     - 使用 <defs> 定义箭头标记（marker），分别定义灰色、蓝色、绿色箭头
     - 方框使用 <rect rx="4"> 实现圆角矩形
     - 箭头使用 <line> 元素，通过 marker-end 引用箭头标记
     - 文字使用 <text> + <tspan>，填空部分用独立 <tspan> 以便单独控制样式
  3. **样式切换**：通过 JS 修改 SVG 元素的 class 或直接修改 style 属性实现颜色切换。使用 CSS class 管理激活/未激活状态。
  4. **角度示意图**：使用 <line>、<path>（弧线）、<text> 元素组合，初始 display="none"，步骤3时改为 display="block"。
  5. **动画过渡**：使用 CSS transition 实现颜色和填充的平滑过渡（0.3s ease）。
  6. **事件绑定**：按钮点击事件绑定到 updateStep(step +/- 1) 函数，边界检查防止越界。

- ID 命名规范：所有交互元素 ID 以 `scene1-` 为前缀：
  - 方框：scene1-box-rotation, scene1-box-revolution, scene1-box-equatorial, scene1-box-ecliptic, scene1-box-obliquity, scene1-box-direct, scene1-box-solar, scene1-box-daynight, scene1-box-heat, scene1-box-temp, scene1-box-seasons
  - 箭头：scene1-arrow-1 ~ scene1-arrow-11
  - 填空文字：scene1-fill-equatorial, scene1-fill-ecliptic, scene1-fill-obliquity, scene1-fill-solar, scene1-fill-daynight, scene1-fill-temp
  - 控件：scene1-btn-prev, scene1-btn-next, scene1-step-indicator
  - 角度示意图：scene1-angle-diagram

- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染。
