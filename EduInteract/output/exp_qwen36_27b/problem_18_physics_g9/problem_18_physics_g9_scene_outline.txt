    **题目原文：**

    如图所示，浸在水中的A物体的质量为3kg，B物体的质量为2kg，且整体处于静止状态，弹簧测力计自身重力不计．下列说法正确的是（  ）
    A. 弹簧测力计的示数为19.6N
    B. 物体A浸在水中的体积为500cm³
    C. 物体A处于非平衡状态
    D. 物体B受到的重力和B对绳的拉力是一对平衡力

    **题目分析：**

    本题是一道初中物理综合题，考查定滑轮特点、受力分析、二力平衡、阿基米德原理（浮力）等知识点。装置由定滑轮、悬挂的物体B、弹簧测力计、浸在水中的物体A组成，整体处于静止状态。

    **整体讲解思路：**

    1. 先分析物体B的受力，利用二力平衡求出绳子拉力
    2. 利用定滑轮特点（不省力），得出弹簧测力计示数
    3. 再分析物体A的受力（三力平衡），求出浮力
    4. 利用阿基米德原理求出物体A排开水的体积
    5. 逐一判断四个选项

    **本图示教学说明：**

    本图示通过分步导航，引导学生从直观装置图逐步深入到受力分析和计算。

    **步骤讲解要点：**

    1. **步骤0（展示装置）**：引导学生观察装置结构——定滑轮、绳子、物体B、弹簧测力计、浸在水中的物体A。强调"整体静止"这一关键条件。

    2. **步骤1（分析B）**：
       - 提问：物体B受几个力？方向如何？
       - 引导学生得出：B受重力G_B（向下）和绳子拉力T（向上），二力平衡
       - 计算：G_B = m_B·g = 2kg × 9.8N/kg = 19.6N，故 T = 19.6N

    3. **步骤2（分析A）**：
       - 提问：物体A受几个力？
       - 引导学生得出：A受重力G_A（向下）、浮力F_浮（向上）、弹簧测力计拉力F拉（向上），三力平衡
       - 强调定滑轮不省力，F拉 = T = 19.6N
       - 计算：G_A = 3kg × 9.8N/kg = 29.4N，F_浮 = G_A - F拉 = 29.4N - 19.6N = 9.8N

    4. **步骤3（计算V排）**：
       - 回顾阿基米德原理：F_浮 = ρ_水·g·V_排
       - 计算：V_排 = F_浮 / (ρ_水·g) = 9.8N / (1000kg/m³ × 9.8N/kg) = 0.001m³ = 1000cm³

    5. **步骤4（判断选项）**：
       - A：弹簧测力计示数 = F拉 = 19.6N ✓ 正确
       - B：V_排 = 1000cm³ ≠ 500cm³ ✗ 错误
       - C：A静止，处于平衡状态 ✗ 错误
       - D：B的重力作用在B上，B对绳的拉力作用在绳上，不是同一物体，不是平衡力 ✗ 错误

    **课堂建议：**
    - 在步骤1和步骤2之间，可暂停让学生先自行分析A的受力，再点击按钮验证
    - 强调"定滑轮不省力"是连接B和A受力的关键桥梁
    - 选项D是常见易错点，需强调平衡力的条件：同体、等大、反向、共线

    <TEXT_3>
    **完整解答：**

    正确答案：**A**

    **推导过程：**

    1. 物体B静止，受重力G_B和绳子拉力T，二力平衡：
       G_B = m_B·g = 2kg × 9.8N/kg = 19.6N
       T = G_B = 19.6N

    2. 定滑轮不省力，弹簧测力计示数等于绳子拉力：
       F示 = T = 19.6N
       故选项A正确。

    3. 物体A静止，受重力G_A、浮力F_浮、弹簧拉力F拉，三力平衡：
       G_A = m_A·g = 3kg × 9.8N/kg = 29.4N
       F拉 = F示 = 19.6N
       F_浮 = G_A - F拉 = 29.4N - 19.6N = 9.8N

    4. 由阿基米德原理：
       V_排 = F_浮 / (ρ_水·g) = 9.8N / (1000kg/m³ × 9.8N/kg) = 0.001m³ = 1000cm³
       故选项B错误（500cm³ ≠ 1000cm³）。

    5. 物体A静止，处于平衡状态，故选项C错误。

    6. 平衡力必须作用在同一物体上。B的重力作用在B上，B对绳的拉力作用在绳上，不是同一物体，故不是一对平衡力，选项D错误。

    **课堂讲解建议：**
    - 本题核心是受力分析，务必让学生养成"先画受力图再列方程"的习惯
    - 定滑轮的特点是"改变力的方向但不省力"，这是解题关键
    - 浮力计算中注意单位换算：1m³ = 10⁶cm³
    - 选项D考查平衡力的概念，可延伸讲解平衡力与相互作用力的区别
    </TEXT_3>
