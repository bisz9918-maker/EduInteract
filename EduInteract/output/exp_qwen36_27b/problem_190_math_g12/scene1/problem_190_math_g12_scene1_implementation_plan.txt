[分步序列]
- 初始状态（步骤0）：
  - 显示四棱锥P-ABCD完整结构（5个顶点、8条棱、5个顶点标签）
  - 实线棱黑色2px，虚线棱黑色1.5px虚线
  - 无高亮、无标注文字
  - 等待教师触发交互

- 步骤1：点击「下一步」→
  - 平面PAB区域填充蓝色半透明（#1565c0，20%透明度）
  - 直线DC变为红色加粗（#c62828，3px）
  - 右侧出现提示文字："命题①：平面PAB内是否存在直线与DC平行？"（位置：520,100）
  - 视觉变化：平面PAB高亮 + 直线DC高亮 + 命题提示

- 步骤2：点击「下一步」→
  - 在平面PAB内出现绿色虚线l（位置：(180,210)-(300,240)）
  - 直线l左上方出现标签"l"（位置：170,200）
  - 右侧出现假设文字："假设：l⊂平面PAB，l∥DC"（位置：520,140，绿色）
  - 视觉变化：新增绿色虚线l + 假设文字

- 步骤3：点击「下一步」→
  - 右侧推导链逐步出现（灰色文字）：
    - "l∥DC"（位置：520,200）
    - "⇒ DC∥平面PAB（线面平行判定）"（位置：520,240）
    - "⇒ DC∥AB（线面平行性质）"（位置：520,280）
  - 推导箭头用#888888虚线连接各推导步骤
  - 视觉变化：推导链文字逐行出现（可加淡入动画）

- 步骤4：点击「下一步」→
  - 绿色虚线l变为红色并添加打叉效果（X标记）
  - 右侧出现矛盾标记："矛盾！题设：AB与DC不平行"（位置：520,340，红色粗体）
  - 出现结论文字："命题① ✓ 正确"（位置：520,390，绿色粗体）
  - 视觉变化：l变红打叉 + 矛盾标记 + 结论

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位置(200,455)，尺寸100×36px，点击返回上一步骤，步骤0时禁用
  - 「下一步 ▶」按钮：位置(500,455)，尺寸100×36px，点击进入下一步骤，步骤4时禁用
  - 步骤指示器：位置(350,470)，显示"步骤 X/4"文字
- 教师操作流程：
  1. 初始状态展示四棱锥结构，教师可先介绍四棱锥的基本概念
  2. 点击「下一步」高亮平面PAB和直线DC，引出命题①的问题
  3. 点击「下一步」展示反证法假设，在平面PAB内画出假设直线l
  4. 点击「下一步」展示推导链，逐步引导学生理解线面平行的判定和性质
  5. 点击「下一步」展示矛盾和结论，完成反证法证明
  6. 可随时点击「上一步」回退到任意步骤进行复习或重新讲解

[技术实现]
- JS 库选择：原生 SVG（简单几何图形绘制，无需额外库，轻量高效）
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────────┐
  │                                                             │
  │           P                                                 │
  │          /|\                                                │
  │         / | \                                               │
  │        /  |  \                                              │
  │       /   D   \                                             │
  │      /   / \   \                                            │
  │     A---/---\---C                                           │
  │        \   /   /                                            │
  │         \ B /                                               │
  │          \ /                                                │
  │                                                             │
  │                    命题①：...                               │
  │                    假设：...                                 │
  │                    推导1...                                  │
  │                    推导2...                                  │
  │                    推导3...                                  │
  │                    矛盾！...                                 │
  │                    命题① ✓ 正确                             │
  │                                                             │
  │              [◀ 上一步]    步骤 X/4    [下一步 ▶]            │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：5个状态（步骤0-4），用全局变量currentStep跟踪当前步骤
  2. 每个步骤的元素通过CSS类控制显示/隐藏（.step-0、.step-1等）
  3. 步骤切换时添加淡入动画（opacity 0→1，transition 0.3s）
  4. 步骤4中直线l变红打叉：修改stroke-color为#c62828，添加X标记SVG元素
  5. 按钮禁用状态：步骤0时「上一步」disabled，步骤4时「下一步」disabled
  6. 四棱锥棱线用SVG <line>元素，平面PAB用<polygon>元素
  7. 虚线用stroke-dasharray="8,4"属性
  8. 推导链文字用<text>元素，箭头用<line>或<path>元素
- ID 命名规范：所有交互元素ID以scene1-为前缀
  - scene1-pyramid（四棱锥容器）
  - scene1-vertex-p、scene1-vertex-a、scene1-vertex-b、scene1-vertex-c、scene1-vertex-d
  - scene1-edge-pa、scene1-edge-pb、scene1-edge-pc、scene1-edge-ab、scene1-edge-bc
  - scene1-edge-pd、scene1-edge-ad、scene1-edge-cd
  - scene1-plane-pab（平面PAB填充）
  - scene1-line-dc（直线DC高亮）
  - scene1-line-l（假设直线l）
  - scene1-label-l（标签l）
  - scene1-prop-text（命题提示文字）
  - scene1-assume-text（假设文字）
  - scene1-derive-1、scene1-derive-2、scene1-derive-3（推导文字）
  - scene1-contradict（矛盾标记）
  - scene1-conclusion（结论文字）
  - scene1-btn-prev（上一步按钮）
  - scene1-btn-next（下一步按钮）
  - scene1-step-indicator（步骤指示器）
- IIFE 隔离：所有JS代码包裹在(function() { ... })()中，避免全局污染
- 事件绑定：按钮点击事件通过getElementById获取元素后绑定click事件
