    **题目原文：**

    如图，过点P作圆O的割线PBA与切线PE，E为切点，连接AE，BE，∠APE的平分线分别与AE、BE相交于C、D，若∠AEB=40°，则∠PCE等于______．

    **题目分析：**

    本题综合考查以下核心知识点：
    1. **弦切角定理**：切线与弦的夹角等于所夹弧对应的圆周角
    2. **角平分线性质**：将角平分为两个相等的角
    3. **三角形内角和与外角定理**
    4. **圆周角性质**：同弧所对的圆周角相等

    **解题关键思路：**

    设∠APE = 2α，由角平分线得∠APC = ∠EPC = α。

    由弦切角定理：∠PEA = ∠EBA（切线PE与弦EA的夹角等于弧EA所对圆周角∠EBA）。

    在△PAC中，∠PCA = 180° - α - ∠EAB。

    因为E、C、A共线，∠PCE = 180° - ∠PCA = α + ∠EAB。

    又在△PBE中，由P、B、A共线得∠PBE = 180° - ∠EBA，结合弦切角∠PEB = ∠EAB，可得2α = ∠EBA - ∠EAB。

    因此∠PCE = (∠EBA - ∠EAB)/2 + ∠EAB = (∠EBA + ∠EAB)/2 = (180° - 40°)/2 = **70°**。

    本图示通过分步导航，帮助教师完整呈现从已知条件到最终答案的推导链条。

    **步骤讲解要点：**

    1. **步骤0（基础图形）**：引导学生识别图中的关键元素——圆O、切线PE、割线PBA、弦AE和BE、角平分线PC。强调P-B-A共线，E为切点，C在AE上，D在BE上。

    2. **步骤1（已知条件）**：高亮∠AEB = 40°。引导学生思考：∠AEB是圆周角，对应弧AB。由三角形内角和，在△ABE中，∠EAB + ∠EBA = 180° - 40° = 140°。

    3. **步骤2（弦切角定理）**：这是本题的核心定理。引导学生观察：
       - PE是切线，EA是弦 → ∠PEA = ∠EBA（弦切角等于所夹弧EA对应的圆周角）
       - PE是切线，EB是弦 → ∠PEB = ∠EAB（弦切角等于所夹弧EB对应的圆周角）
       用不同颜色同时高亮相等的角对，帮助学生建立直观对应关系。

    4. **步骤3（角平分线与角度关系）**：
       - PC平分∠APE，设∠APE = 2α，则∠APC = ∠EPC = α
       - 在△PBE中：∠PBE = 180° - ∠EBA（P、B、A共线），∠PEB = ∠EAB（弦切角），∠BPE = 2α
       - 由三角形内角和：(180° - ∠EBA) + ∠EAB + 2α = 180°，得2α = ∠EBA - ∠EAB

       - 在△PAC中：∠PCA = 180° - α - ∠EAB
       - 因为E、C、A共线：∠PCE = 180° - ∠PCA = α + ∠EAB
       - 代入α = (∠EBA - ∠EAB)/2：∠PCE = (∠EBA - ∠EAB)/2 + ∠EAB = (∠EBA + ∠EAB)/2

    **完整解答总结：**

    **答案：∠PCE = 70°**

    **完整推导过程：**

    1. 设∠APE = 2α，由PC平分∠APE，得∠APC = ∠EPC = α

    2. 由弦切角定理：
       - ∠PEA = ∠EBA（切线PE与弦EA的夹角 = 弧EA所对圆周角）
       - ∠PEB = ∠EAB（切线PE与弦EB的夹角 = 弧EB所对圆周角）

    3. 在△PBE中，P、B、A共线，故∠PBE = 180° - ∠EBA
       由三角形内角和：∠PBE + ∠BPE + ∠PEB = 180°
       即(180° - ∠EBA) + 2α + ∠EAB = 180°
       得：2α = ∠EBA - ∠EAB

    4. 在△PAC中：∠PCA = 180° - ∠APC - ∠PAC = 180° - α - ∠EAB
       因为E、C、A共线：∠PCE = 180° - ∠PCA = α + ∠EAB

    5. 代入α：∠PCE = (∠EBA - ∠EAB)/2 + ∠EAB = (∠EBA + ∠EAB)/2

    6. 在△ABE中：∠EAB + ∠EBA = 180° - ∠AEB = 180° - 40° = 140°

    7. 所以：∠PCE = 140°/2 = **70°**

    **教学延伸：**

    本题揭示了一个有趣的几何不变量：∠PCE = (180° - ∠AEB)/2，即∠PCE仅由∠AEB决定，与点P的位置（即∠APE的大小）无关。教师可引导学生验证这一结论，加深对弦切角定理和角度关系的理解。
