步骤1（高亮递推关系）：
- 三角形中第3行的 1/3 用蓝色#1565c0高亮（背景色块）
- 从 1/3 位置(300,180)绘制两条蓝色弯曲箭头：

  - 箭头2：指向第4行 1/12 位置(250,240)
- 右侧显示等式框(520,100)-(720,140)，内容："1/3 = 1/4 + 1/12"
- 步骤说明："递推关系：上一行的数 = 下一行左右相邻两数之和"
- 点击"切换"可循环查看其他递推关系（1/2→1/3+1/6，1/4→1/5+1/20等）

步骤2（推导第6行第1个数）：

- 第6行第1个位置(100,360)显示 1/6，绿色#2e7d32高亮
- 虚线占位框消失，替换为实际数字
- 步骤说明："第6行第1个数：两端规律 → 1/6"

步骤3（推导第6行第2个数）：
- 第5行第1个数 1/5(120,300)用蓝色#1565c0高亮
- 第6行第1个数 1/6(100,360)用红色#c62828高亮
- 右侧显示计算式框(520,100)-(720,160)：
  - "1/5 = 1/6 + ?"
  - "? = 1/5 - 1/6 = 1/30"
- 第6行第2个位置(200,360)显示 1/30，绿色#2e7d32高亮
- 步骤说明："第6行第2个数：1/5 - 1/6 = 1/30"

步骤4（推导第6行完整）：
- 第6行全部6个数显示：1/6, 1/30, 1/60, 1/60, 1/30, 1/6
- 对称位置用相同颜色标注：
  - 第1、6个（1/6）：绿色#2e7d32
  - 第2、5个（1/30）：蓝色#1565c0
  - 第3、4个（1/60）：橙色#ef6c00
- 右侧显示等式框(520,100)-(720,140)："第6行：1/6, 1/30, 1/60, 1/60, 1/30, 1/6"
- 步骤说明："第6行完整（对称性）：1/6, 1/30, 1/60, 1/60, 1/30, 1/6"

步骤5（第2个数通项公式）：
- 三角形缩小至左侧区域（缩放至约70%），位置左移
- 右侧推导面板(540,60)-(750,400)显示：
  - 标题："第2个数通项公式"
  - 推导过程（分3行，不同颜色）：
    - "a(n,2) = a(n-1,1) - a(n,1)" （黑色）
    - "= 1/(n-1) - 1/n" （蓝色#1565c0）
    - "= 1/[n(n-1)]" （绿色#2e7d32，加粗）
  - 验证："当n=6时：1/[6×5] = 1/30 ✓"（灰色小字）
- 三角形中第2列的数（1/2, 1/6, 1/12, 1/20, 1/30）用绿色#2e7d32高亮
- 步骤说明："第2个数通项：a(n,2) = 1/[n(n-1)]"

步骤6（第3个数通项公式）：
- 三角形保持缩小状态
- 右侧推导面板更新：
  - 标题："第3个数通项公式"
  - 推导过程（分4行，不同颜色）：
    - "a(n,3) = a(n-1,2) - a(n,2)" （黑色）
    - "= 1/[(n-1)(n-2)] - 1/[n(n-1)]" （蓝色#1565c0）
    - "= [n - (n-2)] / [n(n-1)(n-2)]" （灰色）
    - "= 2/[n(n-1)(n-2)]" （绿色#2e7d32，加粗）
  - 验证："当n=4时：2/[4×3×2] = 1/12 ✓"（灰色小字）
- 三角形中第3列的数（1/6, 1/12, 1/30）用绿色#2e7d32高亮
- 步骤说明："第3个数通项：a(n,3) = 2/[n(n-1)(n-2)]"

[技术实现]
- JS 库选择：原生 SVG + MathJax
  - SVG：绘制三角形数阵、箭头、高亮框、推导面板等矢量图形
  - MathJax：渲染分数和数学公式（1/1, 1/2, 1/6, 1/[n(n-1)] 等）
  - 原因：SVG 适合静态几何布局，MathJax 确保数学公式美观渲染
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────────┐
  │                                                             │
  │  第1行    1/1                                               │
  │  第2行  1/2   1/2                                           │
  │  第3行 1/3  1/6  1/3                                        │
  │  第4行 1/4 1/12 1/12 1/4                                    │
  │  第5行 1/5 1/20 1/30 1/20 1/5                               │
  │  第6行 ────────────────────────  [推导面板区]               │
  │         (虚线占位/逐步显示)         │                       │
  │                                       │  通项公式推导        │
  │                                       │  a(n,2)=...         │
  │                                       │  a(n,3)=...         │
  │                                                             │
  │  步骤说明文字居中显示                                         │
  │  ┌──────────┐  步骤X/6  ┌──────────┐                        │
  │  │◀ 上一步  │           │ 下一步 ▶ │                        │
  │  └──────────┘           └──────────┘                        │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. **状态机设计**：7个状态（步骤0-6），每个状态定义独立的视觉元素集合
     - 状态对象数组：`states[0..6]`，每个包含 `elements`, `highlights`, `arrows`, `panel` 属性
     - 当前状态索引 `currentStep`，初始为0
  2. **SVG 元素管理**：
     - 三角形数字使用 `<text>` 元素，ID 命名 `scene1-row{r}-col{c}`
     - 高亮使用 `<rect>` 半透明背景覆盖在数字下方
     - 箭头使用 `<path>` 带 `<marker-end>` 箭头标记
     - 推导面板使用 `<g>` 分组，步骤5-6时切换内容
  3. **MathJax 渲染**：
     - 使用 MathJax 3 的 `tex2svg` API 异步渲染分数
     - 预渲染所有分数字符串，缓存 SVG 结果
     - 分数文本使用 `<foreignObject>` 嵌入 MathJax 输出
  4. **动画曲线**：
     - 元素出现：opacity 0→1，duration 300ms，ease-in
     - 高亮切换：fill-opacity 0→0.2，duration 200ms
     - 箭头绘制：stroke-dasharray 动画，duration 400ms
  5. **事件绑定**：
     - 按钮点击：`onclick` 绑定 `prevStep()` / `nextStep()` 函数
     - 步骤1切换按钮：循环切换递推关系示例（3组：1/3→1/4+1/12, 1/2→1/3+1/6, 1/4→1/5+1/20）
  6. **响应式考虑**：固定800×500画布，不随窗口缩放
- ID 命名规范：所有交互元素 ID 以 `scene1-` 为前缀
  - 按钮：`scene1-prev-btn`, `scene1-next-btn`, `scene1-toggle-btn`
  - 步骤指示器：`scene1-step-indicator`
  - 三角形数字：`scene1-row{r}-col{c}`（如 `scene1-row3-col2`）
  - 高亮层：`scene1-highlight-row{r}-col{c}`
  - 箭头：`scene1-arrow-{id}`
  - 推导面板：`scene1-panel-title`, `scene1-panel-content`
  - 步骤说明：`scene1-step-desc`
- IIFE 隔离：所有 JS 代码包裹在 `(function() { 'use strict'; ... })();` 中
- 分数渲染方案：
  - 简单分数（如 1/2, 1/3）使用 SVG `<text>` 直接渲染，分子在上分母在下中间横线
  - 复杂公式（如 1/[n(n-1)]）使用 MathJax 渲染
  - 自定义 `renderFraction(numerator, denominator, x, y)` 函数生成 SVG 分数元素
