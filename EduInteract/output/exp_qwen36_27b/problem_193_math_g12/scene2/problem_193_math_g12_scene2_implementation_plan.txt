[图示主题与整合说明]
- 本图示主题：体积计算与参数a的求解——半圆锥与三棱锥体积公式应用
- 整合的步骤/概念：半圆锥体积公式 → 三棱锥体积公式 → 总体积表达式 → 代入求解a
- 教学价值：教师通过分步按钮导航，逐步引导学生理解三视图对应的几何体结构，逐层推导体积公式，最终代入已知条件求解未知参数a。每步聚焦一个计算环节，避免信息过载，适合课堂板书式讲解。

[分步序列]

初始状态（步骤0）：
- 显示完整几何体透视图（半圆锥+三棱锥），无高亮
- 显示所有尺寸标注：r=1、底=2、高=1、a
- 显示标签"半圆锥"（灰色）、"三棱锥"（灰色）
- 右侧公式区空白，仅显示步骤标题"步骤0：观察几何体结构"
- 按钮状态："上一步"禁用，"下一步"可用

步骤1：点击「下一步」→
- 半圆锥部分高亮：蓝色#1565c0填充透明度0.25，边框加粗
- 标签"半圆锥"变为蓝色#1565c0
- 右侧出现公式框1（蓝色边框），显示：
  V_半圆锥 = ½ × ⅓πr²h = ½ × ⅓π × 1² × a = πa/6
- 步骤标题更新为"步骤1：半圆锥体积"

步骤2：点击「下一步」→
- 三棱锥部分高亮：绿色#2e7d32填充透明度0.25，边框加粗
- 标签"三棱锥"变为绿色#2e7d32
- 半圆锥保持蓝色高亮（稍淡，透明度0.15）
- 右侧出现公式框2（绿色边框），显示：
  V_三棱锥 = ⅓ × S_底 × h = ⅓ × (½ × 2 × 1) × a = a/3
- 步骤标题更新为"步骤2：三棱锥体积"

步骤3：点击「下一步」→
- 几何体两部分同时保持高亮（蓝+绿，透明度各0.15）
- 右侧出现公式框3（黑色边框），显示：
  V_总 = V_半圆锥 + V_三棱锥 = πa/6 + a/3 = (π+2)a/6
- 步骤标题更新为"步骤3：总体积表达式"

步骤4：点击「下一步」→
- 几何体保持高亮
- 右侧出现公式框4（红色边框，红色填充），显示：
  (π+2)a/6 = (π+2)/6  →  a = 1
  其中"a = 1"用红色#c62828、20px、加粗显示
- 步骤标题更新为"步骤4：求解参数a"
- "下一步"按钮禁用

[技术实现]
- JS 库选择：
  - 原生SVG：绘制几何体透视图、尺寸标注线、公式框（轻量、精确控制）
  - MathJax 3（CDN）：渲染LaTeX数学公式（专业公式排版）
  - 原因：SVG适合几何图形精确绘制，MathJax是数学公式渲染的标准方案，无需重型框架
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+ 800px
  |  [几何体透视图]        [步骤标题]                 |
  |  (x:20~290)          (x:320~780)                 |
  |                                                   |
  |   半圆锥(蓝)          [公式框1: V_半圆锥]         |
  |   ┌─────┐            (步骤1显示)                  |
  |   │  ●  │            [公式框2: V_三棱锥]         |
  |   │ /|\ │            (步骤2显示)                  |
  |   │/ | \│            [公式框3: V_总]             |
  |  半圆 三角            (步骤3显示)                  |
  |   底面               [公式框4: a=1]              |
  |   r=1 底=2           (步骤4显示,红色)             |
  |   a  高=1                                                   |
  |                                                   |
  |                                                   |
  |  ───────────────────────────────────────────────  | y=440
  |  [◀上一步]    步骤 X/4    [下一步▶]              |
  |           (y:440~490)                            |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：5个状态（步骤0~4），用全局变量`currentStep`跟踪，每个状态对应一组可见/隐藏/高亮的元素
  2. 步骤切换函数`goToStep(n)`：
     - 隐藏所有公式框
     - 重置几何体高亮
     - 根据n显示对应公式框和高亮
     - 更新按钮状态和步骤指示
  3. 几何体高亮：通过切换SVG元素的fill-opacity和stroke属性实现
     - 步骤0：无高亮（fill-opacity=0）
     - 步骤1：半圆锥fill-opacity=0.25
     - 步骤2：半圆锥fill-opacity=0.15，三棱锥fill-opacity=0.25
     - 步骤3~4：两者fill-opacity=0.15
  4. 公式框显示/隐藏：通过CSS类`.formula-hidden`（opacity=0, visibility=hidden）和`.formula-visible`（opacity=1, visibility=visible）切换，配合CSS transition实现淡入效果（0.3s ease）
  5. MathJax渲染：使用`MathJax.typesetPromise()`在公式框显示后异步渲染，确保公式正确显示
  6. 事件绑定：按钮click事件绑定`prevStep()`和`nextStep()`函数
  7. 尺寸标注线：使用SVG `<line>`元素，stroke-dasharray="4,3"实现虚线效果
  8. 半圆弧绘制：使用SVG `<path>`的A命令绘制上半圆弧 `M 100,310 A 55,55 0 0,1 210,310`
- ID 命名规范：所有交互元素ID以 `scene2-` 为前缀
  - 几何体：`scene2-cone-half`（半圆锥组）、`scene2-cone-tri`（三棱锥组）、`scene2-vertex`（顶点）
  - 标签：`scene2-label-r`、`scene2-label-base`、`scene2-label-h1`、`scene2-label-a`、`scene2-label-halfcone`、`scene2-label-tricone`
  - 公式框：`scene2-formula-box1`~`scene2-formula-box4`
  - 公式内容：`scene2-formula-content1`~`scene2-formula-content4`
  - 按钮：`scene2-btn-prev`、`scene2-btn-next`
  - 步骤指示：`scene2-step-indicator`
  - 步骤标题：`scene2-step-title`
- JS中用`document.getElementById()`而非`querySelectorAll`配合全局class，避免多场景合并时跨场景污染
- IIFE隔离：所有JS代码包裹在`(function() { 'use strict'; ... })();`中，确保变量和函数不泄露到全局作用域
- MathJax配置：在IIFE内部通过`window.MathJax`配置，使用`tex-chtml`输出格式，确保与SVG兼容
