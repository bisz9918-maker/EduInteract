[视觉元素清单]
- 四面体ABCD线框：4个顶点（圆点，r=3，#000000），6条棱（AB/AD/BC/BD/CD为实线#000000 2px，AC为虚线#888888 1.5px）
- AD棱高亮：步骤1起变为#1565c0，3px实线
- BC棱高亮：步骤1起变为#c62828，3px实线
- 垂直符号：L形折线，位于AD右侧、BC上方区域，表示AD⊥BC的异面垂直关系
- 长度标注：AD=2c（蓝色，AD左侧）、BC=2（红色，BC下方）
- 约束标注：AB+BD=2a（绿色，AB/BD下方）、AC+CD=2a（绿色，AC/CD上方）
- 公垂线段h：橙色虚线，连接AD中点与BC中点附近，标注h
- 顶点标签：A/B/C/D，黑色16px粗体，分别位于各顶点外侧

[分步序列]
- 初始状态（步骤0）：
  显示四面体ABCD的完整线框结构
  - 4个顶点A(260,380)、B(410,300)、C(540,260)、D(260,100)
  - 6条棱：AB(实线黑)、AC(虚线灰)、AD(实线黑)、BC(实线黑)、BD(实线黑)、CD(实线黑)

  - 步骤指示"步骤 0/4"
  - 「上一步」按钮禁用，「下一步」按钮可用

  - AD棱高亮为蓝色(#1565c0)，线宽加粗至3px

  - 步骤指示"步骤 2/4"

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位置(310,455)，80×32px，点击回退到上一步骤，步骤0时禁用（灰色）
  - 「下一步」按钮：位置(410,455)，80×32px，点击进入下一步骤，步骤4时禁用（灰色）
  - 步骤指示文字：位置(400,440)，显示"步骤 X/4"
- 教师操作流程：
  1. 图示加载后显示步骤0（四面体线框），教师可讲解四面体的基本结构
  2. 点击「下一步」进入步骤1，AD和BC高亮，出现垂直符号，教师讲解异面垂直关系
  3. 点击「下一步」进入步骤2，出现长度标注，教师讲解已知长度条件
  4. 点击「下一步」进入步骤3，出现约束条件标注，教师讲解椭圆定义的几何意义
  5. 点击「下一步」进入步骤4，出现公垂线段h，教师为体积公式V=1/6·AD·BC·h做铺垫
  6. 随时点击「上一步」回退复习任意步骤

[技术实现]
- JS 库选择：原生 SVG（简单几何线框图，无需复杂库，轻量高效）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |                    (空白)                        |
  |              D(260,100)                          |
  |              ●                                   |
  |              | \                                 |
  |              |  \ CD                             |
  |              |   \                               |
  |      AD=2c   |    \                              |
  |        |     |     \ AC(虚线)                    |
  |        |     |      \                           |
  |        |     |       \                          |
  |        |     ●--------● h(橙虚线)                |
  |        |    /|        |                         |
  |        |   / |        |                         |
  |        |  /  |        |                         |
  |        | /   |        |                         |
  |        ●----●--------●                          |
  |       A    B        C                           |
  |     (260,380)(410,300)(540,260)                 |
  |                                                |
  |              AB+BD=2a                          |
  |                                                |
  |         [上一步]  步骤 X/4  [下一步]            |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：当前步骤currentStep（0~4），每个步骤对应一组可见元素集合
  2. 元素显隐控制：通过SVG元素的opacity或display属性控制，步骤推进时新增元素淡入（transition: opacity 0.4s）
  3. 棱高亮切换：步骤1时AD和BC的stroke/stroke-width属性变化，带CSS transition动画
  4. 按钮状态管理：步骤0时「上一步」disabled，步骤4时「下一步」disabled
  5. 顶点坐标常量定义：在IIFE内部定义顶点坐标对象，便于统一修改
  6. 垂直符号绘制：用SVG polyline绘制L形折线，表示异面垂直
  7. 公垂线段：橙色虚线，stroke-dasharray="6,4"
- ID 命名规范：所有交互元素ID以`scene1-`为前缀
  - 棱：scene1-edge-ab, scene1-edge-ac, scene1-edge-ad, scene1-edge-bc, scene1-edge-bd, scene1-edge-cd
  - 顶点：scene1-vert-a, scene1-vert-b, scene1-vert-c, scene1-vert-d
  - 标签：scene1-label-a, scene1-label-b, scene1-label-c, scene1-label-d, scene1-label-ad, scene1-label-bc, scene1-label-ab-bd, scene1-label-ac-cd, scene1-label-h
  - 符号：scene1-perp-symbol
  - 公垂线：scene1-common-perp
  - 按钮：scene1-btn-prev, scene1-btn-next
  - 步骤指示：scene1-step-indicator
- IIFE 隔离：所有JS代码包裹在(function(){ ... })()中，避免全局污染
- CSS transition用于元素淡入效果：.scene1-fade-in { transition: opacity 0.4s ease-in; }
