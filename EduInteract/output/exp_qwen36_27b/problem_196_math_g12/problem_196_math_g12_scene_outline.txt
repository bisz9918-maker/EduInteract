    **题目原文：**

    如图所示，已知AP是圆O的切线，P为切点，AC是圆O的割线，与圆O交于B，C两点，圆心O在∠PAC的内部，点M是BC的中点．则∠OAM+∠APM的大小为______．

    **题目分析：**

    本题是一道圆的综合几何题，核心考点包括：
    - 切线的性质（切线与半径垂直）
    - 垂径定理（圆心到弦中点的连线垂直于弦）
    - 四点共圆的判定与性质
    - 圆周角定理

    **整体讲解思路：**

    1. 首先引导学生识别题目中的已知条件：切线 AP、割线 AC、中点 M
    2. 添加关键辅助线 OP 和 OM，利用切线性质和垂径定理得到两个直角
    3. 由两个直角发现 A、P、O、M 四点共圆（以 OA 为直径）
    4. 利用同弧所对圆周角相等，将 ∠OAM 转化为 ∠OPM
    5. 最终得到 ∠OAM + ∠APM = ∠OPM + ∠APM = ∠OPA = 90°

    **图示规划说明：**

    **教学说明：**

    本图示通过分步导航，完整展示从题目条件到结论的推导过程。教师可按以下步骤引导学生：

    1. **步骤 0（观察题目）**：请学生识别图中的已知条件——AP 是切线，AC 是割线，M 是 BC 中点。提问："从这些条件，你能想到哪些几何性质？"

    2. **步骤 1（切线性质）**：引导学生回忆切线性质——切线与过切点的半径垂直。因此 OP ⊥ AP，即 ∠OPA = 90°。强调辅助线 OP 的添加是解题的关键第一步。

    3. **步骤 2（垂径定理）**：引导学生回忆垂径定理——圆心到弦中点的连线垂直于弦。因为 M 是 BC 中点，所以 OM ⊥ BC，即 OM ⊥ AC，∠OMA = 90°。

    4. **步骤 3（四点共圆）**：提问学生："∠OPA = 90° 且 ∠OMA = 90°，这意味着什么？"引导学生发现 A、P、O、M 四点共圆（以 OA 为直径）。这是本题的核心突破口。

    5. **步骤 4（结论推导）**：利用四点共圆的性质——同弧所对的圆周角相等。弧 OM 所对的圆周角 ∠OAM = ∠OPM。因此：

    ∠OAM + ∠APM = ∠OPM + ∠APM = ∠OPA = 90°

    **课堂讲解建议：**
    - 在步骤 3 处可适当停顿，让学生自己发现四点共圆
    - 强调"构造四点共圆"是解决此类角度和问题的常用技巧
    - 可补充提问："如果 M 不是 BC 中点，结论还成立吗？"帮助学生理解条件的必要性
