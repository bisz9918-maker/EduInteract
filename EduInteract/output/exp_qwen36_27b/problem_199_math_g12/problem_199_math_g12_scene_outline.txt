    **题目原文：**

    如图，在直角坐标平面内有一个边长为a，中心在原点O的正六边形ABCDEF，AB∥Ox．直线L：y=kx+t(k为常数)与正六边形交于M、N两点，记△OMN的面积为S，则函数S=f(t)的奇偶性为 ______．

    **题目分析：**

    本题考察函数奇偶性的判断，核心在于理解几何图形的对称性与函数参数变化之间的关系。

    关键知识点：
    1. 正六边形关于其中心（原点O）中心对称
    2. 直线 y=kx+t 中参数 t 的变化相当于直线的上下平移
    3. 当 t→-t 时，直线变为 y=kx-t，与原直线关于原点对称
    4. 中心对称图形的交点也具有对称性
    5. 三角形面积公式 S = |x₁y₂ - x₂y₁|/2

    **整体讲解思路：**

    本题的解题关键在于利用正六边形的**中心对称性**。当 t 变为 -t 时，直线 y=kx+t 变为 y=kx-t，两条直线关于原点对称。由于正六边形本身关于原点对称，因此新直线与六边形的交点 M'、N' 恰好是原交点 M、N 关于原点的对称点。而由对称点构成的三角形 OM'N' 与原三角形 OMN 面积相等，故 f(-t) = f(t)，S=f(t) 为**偶函数**。

    **图示规划说明：**

    规划一个交互式图示场景，通过分步按钮导航，从展示基础图形开始，逐步引导学生观察正六边形的中心对称性、直线参数 t 变化时的对称关系、交点的对称性，最终得出面积不变的结论。整个过程在一个场景中完成，避免拆分。

    **本图示的教学说明：**

    **步骤0——呈现题目原图：**

    教师首先展示题目原始图形，引导学生确认以下信息：
    1. 正六边形 ABCDEF 的中心在原点 O
    2. AB 边平行于 x 轴（即 AB∥Ox）
    3. 直线 L: y=kx+t 与六边形交于 M、N 两点
    4. △OMN 的面积记为 S

    提问学生：题目要求判断 S=f(t) 的奇偶性，我们需要比较什么？引导学生回答：比较 f(t) 与 f(-t) 的关系。

    **步骤1——揭示正六边形的中心对称性：**

    点击「下一步」，展示正六边形关于原点的中心对称性。

    教师讲解要点：
    1. 正六边形是中心对称图形，对称中心就是其中心 O（原点）
    2. 各顶点关于原点对称：A↔D、B↔E、C↔F
    3. 六边形边界上任意一点 P，其关于原点的对称点 P' 也在六边形边界上

    这是解题的核心几何性质，务必让学生充分理解。

    **步骤2——展示 t→-t 时直线的对称变换：**

    点击「下一步」，展示当参数 t 变为 -t 时，直线从 y=kx+t 变为 y=kx-t。

    教师讲解要点：
    1. 直线 y=kx+t 上任意一点 (x, y) 关于原点的对称点为 (-x, -y)
    2. 将 (-x, -y) 代入 y=kx+t，得 -y = k(-x) + t，即 y = kx - t
    3. 因此直线 y=kx-t 是直线 y=kx+t 关于原点的对称直线

    **步骤3——交点的对称性：**

    点击「下一步」，展示新直线与六边形的交点 M'、N' 与原交点 M、N 关于原点对称。

    教师讲解要点：
    1. 由于六边形关于原点对称，且直线 L' 是直线 L 关于原点的对称直线
    2. 因此 L' 与六边形的交点 M'、N' 就是 L 与六边形交点 M、N 关于原点的对称点
    3. 若 M(x₁, y₁)、N(x₂, y₂)，则 M'(-x₁, -y₁)、N'(-x₂, -y₂)

    **步骤4——面积相等与结论：**

    点击「下一步」，展示 △OMN 与 △OM'N' 面积相等。

    教师讲解推导：
    1. △OMN 的面积：S = f(t) = |x₁y₂ - x₂y₁| / 2
    2. △OM'N' 的面积：f(-t) = |(-x₁)(-y₂) - (-x₂)(-y₁)| / 2
    3. 化简：f(-t) = |x₁y₂ - x₂y₁| / 2 = f(t)
    4. 结论：f(-t) = f(t)，故 S = f(t) 为**偶函数**

    **课堂讲解建议：**

    - 在步骤1处可暂停，让学生自己验证正六边形的中心对称性
    - 在步骤3处可提问：为什么 M'、N' 一定在六边形上？引导学生思考中心对称图形的性质
    - 在步骤4处可让学生动手计算验证，加深理解
    - 最后可拓展提问：如果图形不是正六边形而是其他中心对称图形（如圆、正方形），结论是否仍然成立？答案是肯定的，因为核心在于中心对称性
