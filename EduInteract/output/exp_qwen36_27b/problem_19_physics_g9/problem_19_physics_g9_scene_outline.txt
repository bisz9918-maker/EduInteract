    **题目原文：**

    如图所示，AB为铅笔芯，其电阻与长度成正比，当两个电流表均接0-0.6A量程时，改变滑片P在铅笔芯上的位置，两个电流表示数的最大比值为3：1，滑片P允许滑动的长度范围cd为12cm．当两个电表均接0-3A时，改变滑片P在铅笔芯上的位置，则：（  ）

    A．两个电流表示数的最大比值变为19：1
    B．两个电流表示数的最大比值变为29：1
    C．滑片P允许滑动的长度范围为22.4cm
    D．滑片P允许滑动的长度范围为21.6cm

    **题目分析：**

    本题核心考查并联电路的动态分析。铅笔芯AB被滑片P分成AP和PB两段，这两段**并联**在电源两端。电流表A₁测AP段电流，A₂测PB段电流。由于电阻与长度成正比，滑片P的位置决定了两段电阻的大小，从而影响电流分配。

    关键物理关系：
    - 设铅笔芯总长为L，单位长度电阻为ρ，滑片P距A端为x
    - R_AP = ρx，R_PB = ρ(L-x)
    - 两段并联，电压均为U
    - I₁ = U/(ρx)，I₂ = U/(ρ(L-x))
    - I₁/I₂ = (L-x)/x

    电流表量程限制了滑片P的滑动范围：当某支路电流达到量程上限时，滑片不能再向该方向移动。

    **整体讲解思路：**

    1. 首先通过交互式电路图让学生理解电路结构（并联）和滑片P的作用
    2. 通过拖动滑片P观察电流变化规律，建立I₁/I₂ = (L-x)/x的关系
    3. 分析0-0.6A量程下的限制条件，求出L和U/(ρL)
    4. 迁移到0-3A量程，计算新的最大比值和滑动范围
    5. 对比两种量程的结果，得出结论

    **图示规划：**

    共规划2个scene：
    - Scene 1：交互式电路图——展示电路结构、滑片P拖动、实时电流显示
    - Scene 2：两种量程对比分析——展示计算过程和结果对比

    **Scene 1 教学说明：**

    本图示是讲解本题的核心工具，帮助教师引导学生从直观观察走向定量分析。

    **引导学生观察的步骤：**

    1. **认识电路结构**
    - 让学生观察电路图，识别各元件：电源、开关、两个电流表、铅笔芯
    - 提问：滑片P将铅笔芯分成了几段？这两段是如何连接的？
    - 引导学生发现：AP段和PB段**并联**在电源两端

    2. **理解电流分配**
    - 拖动滑片P到中间位置，观察I₁ = I₂，比值为1:1
    - 拖动滑片P向左移动，观察I₁增大、I₂减小，比值增大
    - 拖动滑片P向右移动，观察I₁减小、I₂增大，比值减小
    - 引导学生总结：I₁/I₂ = (L-x)/x，x越小比值越大

    3. **理解量程限制**
    - 切换到0-0.6A量程，拖动滑片P直到某电流表达到0.6A
    - 观察此时滑片P的位置即为允许滑动的端点
    - 两个端点之间的范围即为cd = 12cm

    4. **建立数学关系**
    - 设铅笔芯总长为L，单位长度电阻为ρ
    - I₁ = U/(ρx)，I₂ = U/(ρ(L-x))
    - 当I₁ = 0.6A时，x最小；当I₂ = 0.6A时，x最大
    - 最大比值3:1对应x最小：(L-x_min)/x_min = 3，得x_min = L/4
    - 最小比值1:3对应x最大：(L-x_max)/x_max = 1/3，得x_max = 3L/4
    - cd = x_max - x_min = L/2 = 12cm，所以L = 24cm
    - 由I₁_max = 4U/(ρL) = 0.6A，得U/(ρL) = 0.15A

    **关键公式：**
    - I₁ = U/(ρx)，I₂ = U/(ρ(L-x))
    - I₁/I₂ = (L-x)/x
    - L = 24cm，U/(ρL) = 0.15A

    **Scene 2 教学说明：**

    本图示用于展示完整的计算推导过程和两种量程的对比结果。

    **分步讲解要点：**

    1. **回顾已知条件（步骤0）**
    - 由0-0.6A量程：最大比值3:1，cd=12cm
    - 推导：x_min = L/4，x_max = 3L/4
    - cd = L/2 = 12cm → **L = 24cm**
    - I₁_max = 4U/(ρL) = 0.6A → **U/(ρL) = 0.15A**

    2. **计算0-3A量程下的x_min'（步骤1）**
    - 当I₁ = 3A时，滑片P最靠左
    - I₁ = U/(ρx_min') = 3A
    - x_min' = U/(3ρ) = (U/(ρL)) × L/3 = 0.15 × 24/3 = **1.2cm**

    3. **计算0-3A量程下的x_max'（步骤2）**
    - 当I₂ = 3A时，滑片P最靠右
    - I₂ = U/(ρ(L-x_max')) = 3A
    - L - x_max' = U/(3ρ) = 1.2cm
    - x_max' = 24 - 1.2 = **22.8cm**

    4. **计算最大比值（步骤3）**
    - 最大比值出现在x最小时
    - I₁/I₂ = (L-x_min')/x_min' = (24-1.2)/1.2 = 22.8/1.2 = **19**
    - 即最大比值为 **19:1** → 选项A正确

    5. **计算滑动范围（步骤4）**
    - cd' = x_max' - x_min' = 22.8 - 1.2 = **21.6cm** → 选项D正确

    6. **总结对比（步骤5）**

    | 物理量 | 0-0.6A量程 | 0-3A量程 |
    |--------|-----------|----------|
    | 最大电流 | 0.6A | 3A |
    | x_min | 6cm | 1.2cm |
    | x_max | 18cm | 22.8cm |
    | 滑动范围cd | 12cm | 21.6cm |
    | 最大比值 | 3:1 | 19:1 |

    **最终答案：A、D**

    **课堂讲解建议：**
    - 强调量程扩大5倍（0.6A→3A），但滑动范围不是简单扩大5倍
    - 引导学生思考：为什么最大比值从3:1变为19:1？因为x_min从L/4缩小到L/20，比值(L-x_min)/x_min显著增大
    - 提醒学生注意：本题中两个电流表量程相同，所以限制条件对称
