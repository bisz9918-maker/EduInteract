[图示主题与整合说明]
- 本图示主题：杠杆平衡条件下，通过比较力臂大小判断最小动力
- 整合的步骤/概念：
  1. 展示杠杆原图（支点O、重物G、四个力F₁-F₄）
  2. 标注阻力G与阻力臂OA
  3. 逐一绘制四个力的力臂（从O点向各力作用线作垂线）
  4. 对比力臂长度，得出结论：力臂最长者（F₃）所需动力最小
- 教学价值：教师可通过分步导航，引导学生从直观图形过渡到力臂概念，理解“动力×动力臂=阻力×阻力臂”中，动力臂越长则动力越小的物理规律。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于(280,450)，点击返回上一状态，步骤0时禁用
  - 「下一步」按钮：位于(420,450)，点击进入下一状态，步骤4时禁用
- 教师操作流程：
  1. 初始展示题目图形，教师讲解杠杆结构
  2. 点击「下一步」高亮阻力与阻力臂，讲解阻力侧条件
  3. 点击「下一步」展示F₃力臂，讲解竖直向上时力臂最长
  4. 点击「下一步」展示其余力臂，对比长度差异
  5. 点击「下一步」显示结论，总结最小力判断依据
  6. 可随时点击「上一步」回退复习任意步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无需外部库，轻量高效）
- 画布尺寸：800 × 500 px

- 关键实现要点：
  1. 状态机设计：使用变量 `currentStep` (0-4) 控制显示状态，每个步骤对应一组SVG元素的显示/隐藏/样式变更
  2. 坐标计算：所有元素坐标预计算并硬编码，确保精确对齐
  3. 动画曲线：步骤切换时使用 CSS transition (0.3s ease) 实现平滑淡入/颜色变化
  4. 事件绑定：按钮点击事件更新 `currentStep` 并调用 `renderStep()` 函数重绘
  5. 力臂垂线绘制：使用 SVG `<line>` 元素，`stroke-dasharray="5,5"` 实现虚线效果
  6. 双箭头标注：使用 SVG `<marker>` 定义箭头，`marker-start` 和 `marker-end` 实现双箭头
  7. 直角符号：使用 SVG `<polyline>` 绘制小折线表示垂直
- ID 命名规范：所有交互元素 ID 以 `scene1-` 为前缀（如 `scene1-lever`, `scene1-btn-next`, `scene1-arm-l3`）
- IIFE 隔离：所有 JS 代码包裹在 `(function() { ... })()` 中，避免全局污染
