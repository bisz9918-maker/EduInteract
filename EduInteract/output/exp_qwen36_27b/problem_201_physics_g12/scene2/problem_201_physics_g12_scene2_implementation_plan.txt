步骤1（第2问：竖直位移）：
- 点击「下一步」→
- 左侧图示：h标注线高亮为蓝色#1565c0（线宽加粗至2px），A点和B点之间竖直连线高亮
- 右侧推导区（替换步骤0内容）：
  - 步骤标题(400,260)："（2）竖直方向位移"
  - 推导公式(400,290)-(780,350)：
    "竖直方向：v_Ay = v₀，v_By = 0，a = -g"
    "v_By² - v_Ay² = 2(-g)h"
    "0 - v₀² = -2gh"
  - 结果框(400,360)-(780,400)：蓝色背景#e3f2fd，蓝色文字#1565c0
    "h = v₀²/(2g)"
- 控件：上一步可用，步骤指示"1/4"，下一步可用

步骤2（第3问：重力做功）：
- 点击「下一步」→
- 左侧图示：重力箭头高亮为红色#c62828（线宽加粗至2px），"mg"标签同步高亮
- 右侧推导区：
  - 步骤标题(400,260)："（3）重力做功"
  - 推导公式(400,290)-(780,350)：
    "W_G = -mgh"
    "W_G = -mg · v₀²/(2g)"
  - 结果框(400,360)-(780,400)：红色背景#ffebee，红色文字#c62828
    "W_G = -mv₀²/2"
- 控件：上一步可用，步骤指示"2/4"，下一步可用

步骤3（第4问：电场力做功）：
- 点击「下一步」→
- 左侧图示：电场力箭头高亮为绿色#2e7d32（线宽加粗至2px），"qE"标签同步高亮
- 右侧推导区：
  - 步骤标题(400,260)："（4）电场力做功（动能定理）"
  - 推导公式(400,290)-(780,370)：
    "动能定理：W_G + W_电 = ΔE_k"
    "ΔE_k = ½m(2v₀)² - ½mv₀² = ³⁄₂mv₀²"
    "W_电 = ³⁄₂mv₀² - (-½mv₀²)"
  - 结果框(400,380)-(780,420)：绿色背景#e8f5e9，绿色文字#2e7d32
    "W_电 = 2mv₀²"
- 控件：上一步可用，步骤指示"3/4"，下一步可用

步骤4（第5问：电势差）：

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：位置(280,455)-(370,485)，点击返回上一步，步骤0时禁用
  - 步骤指示文字：位置(380,455)-(420,485)，显示当前步骤"X/4"
  - "下一步 ▶"按钮：位置(430,455)-(520,485)，点击进入下一步，步骤4时禁用
- 教师操作流程：
  1. 图示加载后显示步骤0（已知条件+问题列表），教师可先让学生观察题目
  2. 点击「下一步」逐步展示每问的推导过程，配合口头讲解
  3. 每步结果用不同颜色高亮，便于学生区分记忆
  4. 可随时点击「上一步」回退复习前面步骤
  5. 到达步骤4后显示全部答案汇总，教师可做总结

[技术实现]
- JS 库选择：
  - 原生 SVG：左侧粒子运动图示（电场线、粒子、箭头、轨迹曲线），简单几何图形首选
  - MathJax 3（CDN）：右侧推导区数学公式渲染，支持行内和独立公式
  - 原生 JavaScript：步骤导航状态机、按钮事件绑定、元素显隐控制
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+------------------------+
  |  E→                                              |  [已知条件框]          |
  |  →  B→  v_B=2v₀                                  |  [问题列表]            |
  |  →  /                                            |                        |
  |  → /                                             |  [步骤标题]            |
  |  →/  h                                           |  [推导公式区]          |
  |  →/                                              |                        |
  |  →A↑ v₀                                          |  [结果框-彩色]         |
  |  →|  mg                                          |                        |
  |  →|  qE→                                         |  [答案汇总框-步骤4]    |
  |  →                                              |                        |
  |                                                  |                        |
  +--------------------------------------------------+------------------------+
  |                                                  |                        |
  |                    [◀上一步] [0/4] [下一步▶]     |                        |
  +--------------------------------------------------+------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：currentStep 变量(0-4)，每个步骤对应一组视觉元素显隐/样式变化
  2. SVG 元素通过 id 控制显隐和样式（如 scene2-h-line, scene2-gravity-arrow）
  3. 右侧推导区用 HTML div 容器，通过 innerHTML 或 class 切换更新内容
  4. MathJax 使用 MathJax.typesetPromise() 在内容更新后重新渲染公式
  5. 按钮事件：点击「下一步」→ currentStep++ → 更新视图；点击「上一步」→ currentStep-- → 更新视图
  6. 边界处理：步骤0时上一步按钮 disabled，步骤4时下一步按钮 disabled
  7. 动画过渡：使用 CSS transition 实现元素淡入淡出（opacity 0→1，duration 300ms）
- ID 命名规范：所有交互元素 ID 以 `scene2-` 为前缀
  - SVG 元素：scene2-e-field, scene2-point-a, scene2-point-b, scene2-v0-arrow, scene2-vb-arrow, scene2-trajectory, scene2-h-line, scene2-gravity-arrow, scene2-electric-arrow
  - HTML 元素：scene2-known-box, scene2-question-list, scene2-step-title, scene2-formula-area, scene2-result-box, scene2-answer-summary
  - 控件元素：scene2-prev-btn, scene2-next-btn, scene2-step-indicator
- JS 中用 document.getElementById() 而非 querySelectorAll 配合全局 class
- IIFE 隔离：所有 JS 代码包在 (function() { 'use strict'; ... })() 中，避免全局污染
