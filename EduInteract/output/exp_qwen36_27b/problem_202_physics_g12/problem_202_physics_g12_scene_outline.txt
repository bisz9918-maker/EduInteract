**题目原文：**

如图所示的直角坐标系中，第Ⅰ、Ⅳ象限内存在着垂直纸面向里的匀强磁场，在$x=-2L$与$y$轴之间第Ⅱ、Ⅲ象限内存在大小相等，方向相反的匀强电场，场强方向如图所示。在$A(-2L,L)$到$C(-2L,0)$的连线上连续分布着电荷量为$+q$、质量为$m$的粒子。从$t=0$时刻起，这些带电粒子依次以相同的速度$v_{0}$沿$x$轴正方向射出。从$A$点射出的粒子刚好沿如图所示的运动轨迹（轨迹与$x$轴的交点为$OC$的中点）从$y$轴上沿$x$轴正方向进入磁场。不计粒子的重力及它们间的相互作用，不考虑粒子间的碰撞。

（1）求电场强度$E$的大小；

（2）若匀强磁场的磁感应强度$B=\frac{8mv_{0}}{5qL}$，求从$A'$点进入磁场的粒子返回到直线$x=-2L$时的位置坐标；

（3）在$AC$间还有哪些位置的粒子，经过电场后也能沿$x$轴正方向进入磁场。

**题目分析：**

本题核心考查带电粒子在匀强电场中的类平抛运动和在匀强磁场中的匀速圆周运动。题目设置了电场与磁场分区的复合场环境，粒子需依次经历电场偏转、磁场偏转、再返回电场的完整过程。

**整体讲解思路：**

1. **第（1）问**：利用从$A$点出发的粒子"沿$x$轴正方向进入磁场"这一关键条件（即在$y$轴处$v_y=0$），结合粒子在电场中$x$方向匀速、$y$方向匀变速的特点，建立方程求解$E$。

2. **第（2）问**：先确定$A'$点坐标，再分析粒子在磁场中的圆周运动（求半径、圆心、轨迹），粒子从磁场返回电场后再次做类平抛运动，最终求回到$x=-2L$时的坐标。

3. **第（3）问**：推广第（1）问的思路，分析粒子在电场中多次穿越$x$轴的情况，找出所有满足"在$y$轴处$v_y=0$"的初始位置。

**第（1）问讲解要点：**

**核心思路**：利用"粒子从$y$轴上沿$x$轴正方向进入磁场"这一条件，即在$x=0$处$v_y=0$。

**推导步骤：**

1. 粒子从$A(-2L,L)$出发，在第Ⅱ象限（$y>0$）受电场力向下，做类平抛运动：
   - $x$方向：匀速，$v_x=v_0$
   - $y$方向：初速为0，加速度$a=\frac{qE}{m}$向下

2. 粒子轨迹与$x$轴交于$OC$中点，即$x=-L$处。从$A$到该点：
   - $x$方向位移：$L=v_0t_1$，得$t_1=\frac{L}{v_0}$
   - $y$方向位移：$L=\frac{1}{2}at_1^2=\frac{1}{2}\cdot\frac{qE}{m}\cdot\frac{L^2}{v_0^2}$

3. 解得：$E=\frac{2mv_0^2}{qL}$

4. 验证：粒子在第Ⅲ象限（$y<0$）电场向上，加速度向上，大小仍为$a=\frac{qE}{m}$。从$x=-L$到$x=0$，时间$t_2=\frac{L}{v_0}=t_1$。$y$方向速度变化：$v_{y2}=v_{y1}+at_2=-at_1+at_1=0$，满足条件。

**教师引导建议：**
- 引导学生先找出题目中的关键条件："沿$x$轴正方向进入磁场"意味着什么？
- 让学生画出粒子在第Ⅱ象限和第Ⅲ象限的受力分析
- 强调$x$方向始终匀速这一重要特点
- 通过验证步骤加深学生对对称性的理解

**第（2）问讲解要点：**

**核心思路**：分三段分析——磁场中半圆运动→电场中返回运动。

**推导步骤：**

1. 确定$A'$点坐标：
   - 粒子在第Ⅲ象限的$y$位移：$y=v_{y1}t_2+\frac{1}{2}at_2^2=-at_1\cdot t_1+\frac{1}{2}at_1^2=-\frac{1}{2}at_1^2=-L$
   - 所以$A'$点坐标为$(0,-L)$

2. 粒子在磁场中做匀速圆周运动：
   - 半径：$R=\frac{mv_0}{qB}=\frac{mv_0}{q\cdot\frac{8mv_0}{5qL}}=\frac{5L}{8}$
   - 圆心位置：从$A'(0,-L)$出发，速度向右，洛伦兹力向上（左手定则），圆心在$(0,-L+R)=(0,-\frac{3L}{8})$
   - 粒子做半圆运动后回到$y$轴，位置为$(0,-L+2R)=(0,\frac{L}{4})$，速度方向向左

3. 粒子从$(0,\frac{L}{4})$以$v_0$向左进入电场（第Ⅱ象限）：
   - $x$方向：从$x=0$到$x=-2L$，时间$t=\frac{2L}{v_0}$
   - $y$方向：初速$v_y=0$，加速度$a=\frac{qE}{m}=\frac{2v_0^2}{L}$向下
   - $y$位移：$\Delta y=\frac{1}{2}at^2=\frac{1}{2}\cdot\frac{2v_0^2}{L}\cdot\frac{4L^2}{v_0^2}=4L$（向下）

4. 最终位置：$y=\frac{L}{4}-4L=-\frac{15L}{4}$，坐标为$\left(-2L,-\frac{15L}{4}\right)$

**教师引导建议：**
- 强调左手定则判断洛伦兹力方向
- 引导学生理解粒子在磁场中做半圆运动的几何关系
- 注意粒子从磁场返回电场时速度方向的反转

**第（3）问讲解要点：**

**核心思路**：推广第（1）问的分析，考虑粒子在电场中多次穿越$x$轴的情况。

**推导步骤：**

1. 设粒子从$(-2L, y_0)$出发，$0 < y_0 \leq L$。

2. 粒子要沿$x$轴正方向进入磁场，需在$x=0$处$v_y=0$。

3. **情况一**：粒子在第Ⅱ象限运动一次，在第Ⅲ象限运动一次（即第（1）问的情形）
   - 在第Ⅱ象限：$y_0=\frac{1}{2}at_1^2$，$t_1=\sqrt{\frac{2y_0}{a}}$
   - 在第Ⅲ象限：需$t_2=t_1$使$v_y=0$
   - 总$x$位移：$2L=v_0(t_1+t_2)=2v_0t_1$
   - 得$t_1=\frac{L}{v_0}$，$y_0=\frac{1}{2}a\cdot\frac{L^2}{v_0^2}=\frac{1}{2}\cdot\frac{2v_0^2}{L}\cdot\frac{L^2}{v_0^2}=L$
   - 即$y_0=L$（从$A$点出发）

4. **情况二**：粒子在第Ⅱ象限运动两次，在第Ⅲ象限运动一次
   - 第Ⅱ象限第一次：$y_0=\frac{1}{2}at_1^2$
   - 第Ⅲ象限：粒子从$y=0$出发，$v_y=-at_1$，加速度向上，做对称运动后回到$y=0$，时间$t_2=2t_1$
   - 第Ⅱ象限第二次：$v_y$从$at_1$减到$0$，时间$t_3=t_1$
   - 总$x$位移：$2L=v_0(t_1+t_2+t_3)=v_0(4t_1)$
   - 得$t_1=\frac{L}{4v_0}$，$y_0=\frac{1}{2}a\cdot\frac{L^2}{16v_0^2}=\frac{L}{4}$

5. **一般情况**：粒子在第Ⅱ象限运动$n$次，在第Ⅲ象限运动$n-1$次
   - 总$x$位移：$2L=v_0\cdot 2nt_1$（其中每次在第Ⅱ象限时间$t_1$，每次在第Ⅲ象限时间$2t_1$）
   - 实际上，总时间为$t_{total}=nt_1+(n-1)\cdot 2t_1=(3n-2)t_1$... 

   让我重新推导：
   - 第Ⅱ象限每次运动时间$t_1$，第Ⅲ象限每次运动时间$2t_1$
   - 若粒子在第Ⅱ象限运动$k+1$次，在第Ⅲ象限运动$k$次
   - 总时间：$t_{total}=(k+1)t_1+k\cdot 2t_1=(3k+1)t_1$
   - $2L=v_0(3k+1)t_1$
   - $t_1=\frac{2L}{v_0(3k+1)}$
   - $y_0=\frac{1}{2}at_1^2=\frac{1}{2}\cdot\frac{2v_0^2}{L}\cdot\frac{4L^2}{v_0^2(3k+1)^2}=\frac{4L}{(3k+1)^2}$

   当$k=0$：$y_0=4L$（超出范围，舍去）
   当$k=1$：$y_0=4L/9$
   
   等等，让我重新检查。

   实际上，更简洁的推导：
   - 粒子在电场中运动，$x$方向始终匀速$v_0$
   - 要使得在$x=0$处$v_y=0$，粒子在$y$方向的运动必须是"对称"的
   - 粒子从$y=y_0$出发，$v_y=0$，最终在$x=0$处$v_y=0$
   - $y$方向的运动由电场决定：在$y>0$时$a$向下，在$y<0$时$a$向上
   - 这相当于一个"振荡"运动，粒子在$x$方向匀速前进的同时，在$y$方向做往复运动

   关键观察：粒子在$y$方向的运动周期与$x$方向位移的关系。
   
   从$y=y_0$出发到第一次到达$y=0$：时间$t_1=\sqrt{\frac{2y_0}{a}}$，$x$位移$x_1=v_0t_1$
   
   从$y=0$出发再回到$y=0$（一个完整振荡）：时间$T=2t_1$，$x$位移$\Delta x=v_0T=2v_0t_1=2x_1$
   
   粒子需要在$x=2L$处$v_y=0$，即$y$方向完成整数个"半振荡"。
   
   若粒子完成$2k-1$个半振荡（$k=1,2,3,...$）：
   - 总时间：$t_{total}=(2k-1)t_1$
   - $2L=v_0(2k-1)t_1$
   - $t_1=\frac{2L}{v_0(2k-1)}$
   - $y_0=\frac{1}{2}at_1^2=\frac{1}{2}\cdot\frac{2v_0^2}{L}\cdot\frac{4L^2}{v_0^2(2k-1)^2}=\frac{4L}{(2k-1)^2}$

   当$k=1$：$y_0=4L$（超出范围$[0,L]$，舍去）
   
   这似乎不对。让我重新思考。

   实际上，从$A$点出发的粒子，$y_0=L$，我们已验证满足条件。此时$t_1=\frac{L}{v_0}$。
   
   代入$y_0=\frac{1}{2}at_1^2$：$L=\frac{1}{2}\cdot\frac{2v_0^2}{L}\cdot\frac{L^2}{v_0^2}=L$，正确。
   
   对于一般情况，设粒子在到达$y$轴前穿越$x$轴$2k$次（$k=0,1,2,...$）：
   - $k=0$：不穿越$x$轴，粒子一直在第Ⅱ象限。但这不可能使$v_y=0$（除非$y_0=0$，但此时粒子沿$x$轴运动，$v_y$始终为0）。
   - $k=1$：穿越$x$轴2次（下去再上来），即第Ⅱ→第Ⅲ→第Ⅱ。总时间$t_{total}=t_1+2t_1+t_1=4t_1$。$2L=4v_0t_1$，$t_1=\frac{L}{2v_0}$。$y_0=\frac{1}{2}a(\frac{L}{2v_0})^2=\frac{L}{4}$。
   - $k=2$：穿越$x$轴4次。总时间$t_{total}=t_1+2t_1+2t_1+t_1=6t_1$。$2L=6v_0t_1$，$t_1=\frac{L}{3v_0}$。$y_0=\frac{1}{2}a(\frac{L}{3v_0})^2=\frac{L}{9}$。
   
   一般地：$y_0=\frac{L}{k^2}$，$k=1,2,3,...$

**答案**：在$AC$间，初始位置为$y_0=\frac{L}{k^2}$（$k=1,2,3,...$）的粒子，即$y_0=L$、$\frac{L}{4}$、$\frac{L}{9}$、$\frac{L}{16}$、...的粒子，经过电场后也能沿$x$轴正方向进入磁场。

- 通过图示观察不同$y_0$值对应的轨迹差异
- 让学生总结规律：$y_0=\frac{L}{k^2}$
