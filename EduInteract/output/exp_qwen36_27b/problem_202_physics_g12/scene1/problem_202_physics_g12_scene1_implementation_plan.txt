[技术实现]
- JS 库选择：原生SVG（无需额外库）
  - 原因：本场景为二维几何图形+曲线轨迹，SVG原生支持path、circle、line、text等元素，无需D3.js或Canvas；交互逻辑简单（步骤切换），无需复杂动画库

- 画布尺寸：800 × 500 px（固定）

- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │  y                                                          │
  │  ↑    E(Ⅱ)    |    B(×××)                                   │
  │  │   ↓↓ ↓↓ ↓↓  |   × × × × ×                                │
  │  │   ↓↓ ↓↓ ↓↓  |   × × × × ×                                │
  │  │ A ●──→v₀    |   × × × × ×                                │
  │  │   ↓↓ ↓↓ ↓↓  |   × × × × ×                                │
  │  └─────────────┼────────────────────────→ x                 │
  │  │   ↓↓ ↓↓ ↓↓  |   × × × × ×                                │
  │  │ C ●   ●────●A'  × × × × ×                                │
  │  │   ↓↓ ↓↓ ↓↓  |   × × × × ×                                │
  │  │             |   × × × × ×                                │
  │  │   ↓↓ ↓↓ ↓↓  |                                            │
  │  │             |                                            │
  │  │ ●(终点)     |                                            │
  │  │             |                                            │
  │  └─────────────┴────────────────────────                    │
  │           ◀上一步  步骤0/6  下一步▶                          │
  └─────────────────────────────────────────────────────────────┘
  ```

- 关键实现要点：
  1. **状态机设计**：
     - 全局变量 currentStep = 0（范围0~6）
     - 每个步骤对应一组SVG元素的显示/隐藏状态
     - 使用CSS class `.step-N` 控制元素可见性（opacity: 0/1 + transition）
     - 步骤切换函数：goToStep(n) 更新currentStep并切换class

  2. **SVG元素组织**：
     - 使用<defs>定义箭头marker（#arrow-red, #arrow-blue, #arrow-orange）
     - 使用<g>分组管理同类元素（#axes, #field-lines, #field-markers, #points, #trajectories, #vectors, #labels）
     - 每个步骤新增元素放在独立的<g class="step-N">组中

  3. **轨迹绘制**：
     - 抛物线：使用SVG cubic bezier path（C命令）
     - 圆弧：使用SVG arc path（A命令），M 485,230 A 40,40 0 0,1 485,151
     - 磁场圆弧动画：使用stroke-dasharray和stroke-dashoffset实现绘制效果

  4. **动画曲线**：
     - 元素出现：opacity 0→1，transition: opacity 0.5s ease-in
     - 圆弧绘制：stroke-dashoffset从全长到0，transition: stroke-dashoffset 1s ease
     - 点高亮：r从4到6再回到4，使用CSS @keyframes pulse

  5. **事件绑定**：
     - 按钮点击事件：document.getElementById('scene1-btn-prev').addEventListener('click', ...)
     - 键盘支持：←→键控制步骤切换

  6. **ID 命名规范**：
