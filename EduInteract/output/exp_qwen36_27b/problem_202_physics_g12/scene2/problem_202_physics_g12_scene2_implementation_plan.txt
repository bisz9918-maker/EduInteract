- 本图示主题：不同初始位置出发的粒子在电场中的运动轨迹对比（第3问推广分析）
- 整合的步骤/概念：粒子在Ⅱ、Ⅲ象限电场中多次穿越x轴的振荡运动，发现y₀=L/k²（k=1,2,3,...）时粒子在y轴处v_y=0的规律

[分步序列]
本场景为连续拖拽交互，无分步导航，但有状态变化：

- 初始状态（加载完成）：
  * 显示完整坐标系、电场区域、磁场区域、边界线
  * 显示A、C点标签
  * 显示特殊位置标记（绿色光晕点）和特殊值标签
  * 滑块默认在y₀=L位置（手柄y=113）
  * 显示从A点出发的粒子轨迹（绿色虚线，满足条件）
  * 显示v₀箭头和vy=0指示
  * 判断结果："✓ 满足条件（v_y=0）"
  * 公式提示框显示

- 拖动滑块状态（y₀连续变化）：
  * 粒子出发点随滑块上下移动
  * 粒子轨迹实时更新（抛物线形状变化）
  * 当y₀接近特殊值（误差<2%）时：
    - 轨迹变为绿色虚线
    - 判断结果变为"✓ 满足条件（v_y=0）"
    - 对应特殊位置标记光晕增强
  * 当y₀远离特殊值时：
    - 轨迹变为红色虚线
    * 判断结果变为"✗ 不满足条件（v_y≠0）"
    * vy指示箭头显示非零方向

- 点击快捷按钮状态：
  * 滑块跳转到对应特殊值位置
  * 轨迹立即更新为绿色（满足条件）
  * 对应特殊位置标记高亮闪烁

- 点击"叠加轨迹"按钮状态：
  * 显示所有特殊位置（L, L/4, L/9, L/16）的轨迹叠加
  * 每条轨迹用不同透明度区分（0.4, 0.6, 0.8, 1.0）
  * 再次点击取消叠加

[技术实现]
- JS 库选择：原生 SVG（简单几何图形、坐标轴、箭头等）+ 原生 JavaScript（交互逻辑）
  * 理由：本场景主要是2D几何图形和曲线绘制，SVG足以胜任，无需引入重型库
  * 粒子轨迹使用SVG <path>元素，通过计算抛物线点序列生成d属性
- 画布尺寸：800 × 500 px（SVG viewBox="0 0 800 500"）
- 布局草图：
  ```
  [图示区 800×440]
  ┌─────────────────────────────────────────────────────────────┐
  │  x=-2L    E↓    E↓    E↓    E↓        y    B(×××)         │
  │   |      │     │     │     │       │    × × ×             │
  │   | A●──→│     │     │     │       │    × × ×   y₀=L/k²   │
  │   |  │   │     │     │     │       │    × × ×             │
  │   |  │   │     │     │     │       │                       │
  │   |  │   │     │     │     │    O──┼──→ x                  │
  │   |  │   │     │     │     │       │                       │
  │   |  │   │     │     │     │       │    × × ×             │
  │   |  │   │     │     │     │       │    × × ×             │

  [控件栏 800×60 (y=440~500)]
  │ y₀=?  [y₀=L] [y₀=L/4] [y₀=L/9] [y₀=L/16] [叠加轨迹] 结果:✓满足 │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. **坐标映射函数**：
     * physToCanvas(x, y)：物理坐标(x/L, y/L)→画布坐标(px, py)
     * canvas_x = 80 + (x_phys + 2.5) × 213.33
     * canvas_y = 430 - (y_phys + 1.5) × 126.67
  
  2. **粒子轨迹计算**：
     * 给定y₀，计算粒子在电场中的运动轨迹
     * 分段计算：每次穿越x轴为一段抛物线
     * 加速度a = 2v₀²/L（由第1问结果）
     * 在Ⅱ象限：y(t) = y₀ - a/2 × t²，v_y(t) = -a × t
     * 在Ⅲ象限：y(t) = v_y0 × t + a/2 × t²，v_y(t) = v_y0 + a × t
     * 采样点生成：每段抛物线采样50个点，用SVG <path>的Q/T命令或polyline绘制
  
  3. **特殊值检测**：
     * 计算k = sqrt(L/y₀)，检查k是否接近整数（误差<0.05）
     * 是→满足条件，绿色轨迹；否→不满足条件，红色轨迹
  
  4. **滑块交互**：
     * mousedown/mousemove/mouseup事件绑定到滑块手柄
     * touchstart/touchmove/touchup支持移动端
     * 拖动时更新y₀值，重新计算并绘制轨迹
  
  5. **叠加轨迹**：
     * 预计算k=1,2,3,4的轨迹点序列
     * 切换时显示/隐藏对应的<path>元素
     * 不同透明度区分：opacity = 0.3 + k×0.2
  
  6. **动画效果**：
     * 特殊位置标记光晕：CSS动画pulse效果
     * 轨迹颜色切换：CSS transition 0.3s
     * 判断结果切换：淡入淡出
  
  7. **状态管理**：
     * 全局状态对象：{ y0: 1.0, showOverlay: false, isSpecial: true }
     * 状态变化时调用render()重绘

- **ID 命名规范**：所有交互元素ID以 `scene2-` 为前缀
  * scene2-svg：主SVG容器
  * scene2-slider-track：滑块轨道
  * scene2-slider-handle：滑块手柄
  * scene2-particle-start：粒子出发点
  * scene2-particle-trajectory：粒子轨迹path
  * scene2-velocity-v0：v₀箭头
  * scene2-velocity-vy：vy箭头
  * scene2-result-label：判断结果标签
  * scene2-btn-l：快捷按钮y₀=L
  * scene2-btn-l4：快捷按钮y₀=L/4
  * scene2-btn-l9：快捷按钮y₀=L/9
  * scene2-btn-l16：快捷按钮y₀=L/16
  * scene2-btn-overlay：叠加轨迹按钮
  * scene2-overlay-trajectories：叠加轨迹组
  * scene2-special-marks：特殊位置标记组
  * scene2-formula-box：公式提示框

- IIFE 隔离：所有JS代码包裹在 (function() { 'use strict'; ... })(); 中
- 事件绑定使用addEventListener，避免内联事件处理器
- 使用requestAnimationFrame优化拖动时的重绘性能
