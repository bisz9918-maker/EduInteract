[图示主题与整合说明]
- 本图示主题：向心力需求与各力供给的关系图——通过ω²-Force图直观展示三个临界角速度的物理意义
- 整合的步骤/概念：
  1. 物体A和B所需向心力随ω²线性增长（F_A = 0.2mω²，F_B = 0.1mω²）
  2. 最大静摩擦力 f_max = 0.5mg 作为第一道"力供给"上限
  3. AB绳最大张力 T_AB_max = 2mg 作为第二道供给
  4. A的总供给能力 f_max + T_AB_max = 2.5mg 为最终极限
  5. 三个临界角速度 ω_0²=25、ω_1²=100/3≈33.3、ω_2²=125 的物理意义
- 教学价值：教师通过拖动滑块改变ω²值，学生可实时观察向心力需求曲线与力供给水平线的交点关系，直观理解"当需求超过供给时发生什么"，从而深刻理解三个临界条件的物理本质

[分步序列]
本场景为连续拖拽交互，无分步导航。状态由滑块位置决定：

- 初始状态（ω²=0）：
  - 显示完整坐标系、所有曲线和水平线
  - 高亮线在x=100（ω²=0）位置
  - 交点A和B都在原点(100,380)
  - 显示框显示"ω = 0.00 rad/s"
  - 临界标注线和临界点默认隐藏（当滑块接近时淡入）

- 拖动过程（ω²从0增大）：
  - 高亮线向右移动
  - 交点A沿F_A曲线上升，交点B沿F_B曲线上升
  - 显示框实时更新ω值
  - 当ω²接近25（±3范围内）：ω_0临界标注线和点淡入，显示"AB绳开始有弹力"
  - 当ω²接近33.3（±3范围内）：ω_1临界标注线和点淡入，显示"OB绳开始有弹力"
  - 当ω²接近125（±5范围内）：ω_2临界标注线和点淡入，显示"A开始滑动"
  - 已过临界点的标注保持显示，未到达的保持隐藏

- 快捷按钮点击：
  - 点击ω_0：滑块跳到ω²=25，高亮线到x=200，ω_0标注高亮
  - 点击ω_1：滑块跳到ω²=33.3，高亮线到x=233，ω_1标注高亮
  - 点击ω_2：滑块跳到ω²=125，高亮线到x=600，ω_2标注高亮

- 教师操作流程：
  1. 初始状态展示完整图表，说明横纵轴含义
  2. 缓慢拖动滑块从0开始增大，观察F_A和F_B曲线上的交点上升

  5. 继续拖动到ω_2=125，讲解"此时A的静摩擦力+AB绳最大张力仍不足以提供向心力，A开始滑动"
  6. 可使用快捷按钮快速跳转到各临界点进行比较

[技术实现]
- JS 库选择：原生 SVG（本场景为二维函数图，SVG足以胜任，无需引入D3等重型库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  +---------------------------------------------------+
  |  [当前ω值显示框]                                  |
  |                                                   |
  |  F/(mg) ↑                                         |
  |  3.0  |                                          *| F_A标签
  |  2.5  |-----------*---------------------------*---| 总供给线
  |  2.0  |-----------*---------------------------*---| T_AB_max
  |  1.5  |                                          |
  |  1.0  |                                          |
  |  0.5  |-----------*-----------*-----------------*---| f_max
  |  0    |*-----------*-----------*-----------------*--→ ω²
  |       0   25(ω_0)  33.3(ω_1)  100  125(ω_2)  150  |
  |                                                   |
  |  [图例: F_A  F_B]                                 |
  |  [滑块轨道: |●---------------------------------|] |
  |  [ω²= X.X]  [ω_0]  [ω_1]  [ω_2]                 |
  +---------------------------------------------------+
  ```
- 关键实现要点：
  1. **坐标映射函数**：
     - ω²_to_x(omega2) = 100 + omega2 * 4
     - F_to_y(F_mg) = 380 - F_mg * 106.67
     - F_A(omega2) = 0.02 * omega2（以mg为单位）
     - F_B(omega2) = 0.01 * omega2（以mg为单位）
  
  2. **状态机设计**：
     - 状态由当前ω²值决定
     - 临界点可见性：当|ω² - 临界值| < 阈值时淡入（opacity 0→1）
     - ω_0阈值：±3，ω_1阈值：±3，ω_2阈值：±5
  
  3. **滑块事件绑定**：
     - mousedown/touchstart：开始拖拽
     - mousemove/touchmove：更新ω²值，重绘高亮线和交点
     - mouseup/touchend：结束拖拽
     - 限制拖拽范围在轨道内
  
  4. **快捷按钮事件**：
     - click：设置目标ω²值，带动画过渡（0.3s ease-out）
     - 过渡期间禁用拖拽
  
  5. **动画曲线**：
     - 滑块跳转：ease-out，0.3s
     - 临界标注淡入：opacity 0→1，0.5s
  
  6. **SVG元素ID命名**：
     - scene2-axis-x, scene2-axis-y
     - scene2-curve-fa, scene2-curve-fb
     - scene2-line-fmax, scene2-line-tabmax, scene2-line-total
     - scene2-crit-omega0-line, scene2-crit-omega0-point, scene2-crit-omega0-label
     - scene2-crit-omega1-line, scene2-crit-omega1-point, scene2-crit-omega1-label
     - scene2-crit-omega2-line, scene2-crit-omega2-point, scene2-crit-omega2-label
     - scene2-highlight-line, scene2-highlight-point-a, scene2-highlight-point-b
     - scene2-display-box, scene2-display-text
     - scene2-slider-track, scene2-slider-handle
     - scene2-btn-omega0, scene2-btn-omega1, scene2-btn-omega2
     - scene2-legend-box, scene2-legend-fa, scene2-legend-fb
  
  7. **IIFE隔离**：所有JS代码包裹在 (function() { 'use strict'; ... })() 中
  8. **getElementById**：所有DOM操作使用 getElementById，不使用 querySelectorAll 配合全局class
