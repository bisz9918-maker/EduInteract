    **题目原文：**

    如图所示，现在有一个小物块，质量为m=80g，带正电荷q=2×10⁻⁴C，放在水平轨道上M点，物块与水平轨道之间的滑动摩擦系数μ=0.2，轨道处在一个水平向左的匀强电场中，E=10³V/m，在水平轨道的末端N处，连接一个光滑的半圆形轨道，半径为R=40cm，取g=10m/s²，求：
    （1）要使小物块能够运动到轨道的最高点L，那么M、N间的距离S至少多大？
    （2）如果在（1）题的位置释放小物块，当它运动到P（轨道中点）点时对轨道的压力等于多少？

    **题目分析：**

    本题综合考查带电粒子在复合场（电场+重力场）中的运动，核心知识点包括：
    - 水平轨道上的匀加速直线运动（电场力与摩擦力的合力）
    - 竖直圆周运动的临界条件（最高点最小速度）
    - 动能定理在曲线运动中的应用
    - 圆周运动中向心力的来源分析

    **整体讲解思路：**

    1. 首先让学生理解物理场景：物块带正电，电场向左，故电场力向左；物块从M点由静止释放，在电场力作用下向左加速，经过水平轨道MN后进入光滑半圆轨道。
    2. 第（1）问的关键是"恰好到达最高点L"的临界条件——在L点轨道支持力为零，仅由重力提供向心力。然后用动能定理从M到L列方程求解S。
    3. 第（2）问先用动能定理从M到P求速度，再在P点用向心力公式求轨道支持力。

    **图示规划说明：**

    规划两个图示场景：
    - **Scene 1**：整体物理场景与运动过程，整合物块从M到L的完整运动轨迹及关键点（P、L）的受力分析，采用分步按钮导航逐步展示。
    - **Scene 2**：能量分析与方程求解，整合动能定理在M→L和M→P两个过程中的应用，采用分步按钮导航逐步展示方程推导。

    **Scene 1 教学说明：**

    本图示展示完整的物理场景和物块运动过程，教师可按以下步骤引导学生：

    1. **步骤0（场景认知）**：让学生观察轨道结构——水平轨道MN与光滑半圆轨道NL相连，电场水平向左。强调物块带正电，所以电场力方向与电场方向相同（向左）。

    2. **步骤1（水平运动受力）**：引导学生分析物块在水平轨道上的受力。电场力 $F = qE = 2\times 10^{-4} \times 10^3 = 0.2\text{N}$ 向左，摩擦力 $f = \mu mg = 0.2 \times 0.08 \times 10 = 0.16\text{N}$ 向右。合力 $F_{\text{合}} = 0.2 - 0.16 = 0.04\text{N}$ 向左，物块做匀加速直线运动。

    3. **步骤2（P点受力）**：物块进入半圆轨道后，在P点（与圆心等高）受三个力：重力向下、电场力向左、轨道支持力向右指向圆心。向心力由支持力与电场力的水平合力提供：$F_N - qE = \frac{mv_P^2}{R}$。

    4. **步骤3（L点受力）**：在最高点L，物块受重力向下、电场力向左、轨道支持力向下（指向圆心）。

    5. **步骤4（临界条件）**：强调"恰好到达最高点"意味着在L点轨道支持力为零，此时仅重力提供向心力：$mg = \frac{mv_L^2}{R}$，由此得临界速度 $v_L = \sqrt{gR} = \sqrt{10 \times 0.4} = 2\text{m/s}$。

    **教学提示**：在步骤2和步骤4之间，教师可暂停让学生思考"为什么L点的临界条件只考虑重力而不考虑电场力？"引导学生理解：在L点，向心力方向竖直向下（指向圆心），而电场力水平向左，不提供向心力。

    **Scene 2 教学说明：**

    本图示聚焦能量分析与方程求解，教师可按以下步骤讲解：

    1. **步骤0（M→L能量分析）**：引导学生识别从M到L过程中各力做功情况。强调：
       - 电场力做功与路径无关，只与水平位移有关，从M到L水平位移为 $S+R$，故 $W_E = qE(S+R)$
       - 摩擦力只在水平轨道上做功，$W_f = -\mu mgS$
       - 重力做功与竖直高度差有关，从M到L上升 $2R$，故 $W_G = -mg \cdot 2R$

    2. **步骤1（动能定理方程）**：根据动能定理 $W_{\text{总}} = \Delta E_k$，列出完整方程。让学生理解方程左边是各力做功之和，右边是动能变化（初速为0）。

    3. **步骤2（求解S）**：将临界条件 $v_L^2 = gR$ 代入，逐步化简求解。提醒学生注意单位统一（质量用kg，长度用m）。最终答案 $S = 18\text{m}$。

    4. **步骤3（M→P能量分析）**：类似地分析从M到P的过程。注意此时重力做功为 $-mgR$（上升高度为R而非2R）。

    5. **步骤4（求解P点速度）**：代入 $S=18\text{m}$ 计算P点速度。强调这是中间结果，还需进一步求支持力。

    6. **步骤5（P点支持力）**：在P点，向心力方向水平向右指向圆心。水平方向受力：支持力 $F_N$ 向右，电场力 $qE$ 向左。故向心力方程为 $F_N - qE = \frac{mv_P^2}{R}$。解得 $F_N = 2.6\text{N}$。根据牛顿第三定律，物块对轨道的压力大小也为2.6N，方向水平向左。

    **教学提示**：
    - 在步骤0中，可提问学生"为什么电场力做功用 $S+R$ 而不是 $S$？"引导学生理解从M到L的水平总位移。
    - 在步骤5中，可提问"为什么P点的向心力方程是 $F_N - qE$ 而不是 $F_N + qE$？"引导学生画图分析力的方向。

    **完整解答总结：**

    **已知条件：**
    - $m = 80\text{g} = 0.08\text{kg}$
    - $q = 2 \times 10^{-4}\text{C}$
    - $\mu = 0.2$
    - $E = 10^3\text{V/m}$
    - $R = 40\text{cm} = 0.4\text{m}$
    - $g = 10\text{m/s}^2$

    **第（1）问解答：**

    1. L点临界条件：$mg = \frac{mv_L^2}{R}$，得 $v_L = \sqrt{gR} = 2\text{m/s}$

    2. 从M到L用动能定理：
    $qE(S+R) - \mu mgS - mg \cdot 2R = \frac{1}{2}mv_L^2$

    3. 代入 $v_L^2 = gR$：
    $qES + qER - \mu mgS - 2mgR = \frac{1}{2}mgR$

    4. 整理求解：
    $S = \frac{\frac{5}{2}mgR - qER}{qE - \mu mg} = \frac{0.72}{0.04} = 18\text{m}$

    **第（2）问解答：**

    1. 从M到P用动能定理：
    $qE(S+R) - \mu mgS - mgR = \frac{1}{2}mv_P^2$

    2. 代入 $S = 18\text{m}$：
    $\frac{1}{2}mv_P^2 = 0.48\text{J}$，得 $v_P^2 = 12$

    3. P点向心力方程：
    $F_N - qE = \frac{mv_P^2}{R}$

    4. 求解支持力：
    $F_N = 0.2 + \frac{0.08 \times 12}{0.4} = 2.6\text{N}$

    由牛顿第三定律，物块对轨道的压力大小为 **2.6N**，方向水平向左。

    **课堂讲解建议：**
    - 先用Scene 1建立物理场景的直观认识，再进入Scene 2进行定量计算
    - 强调动能定理在曲线运动中的优势——无需分析中间过程的加速度变化
    - 提醒学生注意：电场力做功只看水平位移，重力做功只看竖直高度差
    - 第（2）问中P点的向心力分析是易错点，需重点讲解力的方向判断
