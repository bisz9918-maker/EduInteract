[图示主题与整合说明]
- 本图示主题：匀强电场中两球多次弹性碰撞的运动过程动画
- 整合的步骤/概念：初始状态展示 → A加速追赶B → 第一次碰撞及速度交换 → A重新加速追赶 → 第二次碰撞 → 第三次碰撞 → 规律总结
- 教学价值：教师可通过分步按钮逐步展示每次碰撞前后的状态变化，直观呈现弹性碰撞中速度交换的规律，帮助学生理解匀强电场中带电粒子的运动与碰撞过程。教师可随时前进或回退，配合课堂讲解节奏。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于控件栏左侧，x=250, y=455，宽度100px，高度36px
  - 「步骤X/7」文字：位于控件栏中央，x=400, y=473，显示当前步骤编号
  - 「下一步 ▶」按钮：位于控件栏右侧，x=450, y=455，宽度100px，高度36px
  - 按钮样式：#1565c0蓝色背景，白色文字，圆角4px，14px字体
  - 禁用状态：步骤0时「上一步」灰色禁用，步骤7时「下一步」灰色禁用
- 教师操作流程：
  1. 页面加载后显示步骤0（初始状态），教师可讲解题目条件
  2. 点击「下一步 ▶」逐步展示A球加速、碰撞、速度交换等过程
  3. 每步停留讲解后继续点击，或点击「◀ 上一步」回退复习
  4. 到达步骤7后展示规律总结，教师可据此归纳通式
  5. 可随时在任意步骤间来回切换

[技术实现]
- JS 库选择：原生SVG（无需额外库）
  - 原因：本场景为简单几何图形（圆、线、箭头、矩形），原生SVG完全满足需求，无需引入D3.js等重型库
  - 数学公式使用HTML文本渲染（如"v₀ = √(2qEL/m)"），无需MathJax
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+ y=0
  |                    E →                           | y=110 电场线1
  |              →                                   | y=170 电场线2
  |  A(+q,m)         B(m)                            | y=228 球标签
  |  ●──────────────●─────────────────────────────── | y=250 水平面
  |  ↑              ↑                                | y=278 球标签
  |              →                                   | y=330 电场线3
  |              →                                   | y=390 电场线4
  |                                                  |
  |  [◀ 上一步]  步骤0/7  [下一步 ▶]                 | y=455 控件栏
  +--------------------------------------------------+ y=500
  ```
- 关键实现要点：
  1. 状态机设计：使用全局变量`currentStep`（0~7）跟踪当前步骤，每个步骤定义一个状态对象，包含A球x坐标、B球x坐标、速度箭头可见性、标签可见性、碰撞光晕可见性、总结框可见性等
  2. 坐标计算：每个步骤的球位置、箭头长度、标签位置预先定义在状态对象中，切换步骤时直接读取并更新SVG元素属性
  3. 动画曲线：球位置变化使用CSS transition（0.5s ease-in-out），碰撞光晕使用CSS animation（0.3s淡入+0.3s淡出），总结框使用CSS transition（0.5s opacity）
  4. 事件绑定：两个按钮分别绑定click事件，更新currentStep后调用renderStep()函数重绘当前步骤
  5. 速度箭头绘制：使用SVG `<line>` + `<polygon>`（箭头头部），箭头从球右侧边缘(x+r, y)开始，长度根据速度倍数设定（v₀=40px, 2v₀=80px, 3v₀=120px）
  6. 碰撞光晕：使用SVG `<circle>`，设置opacity=0.3，碰撞步骤显示，其他步骤隐藏
  7. 电场线箭头：使用SVG `<marker>`定义箭头标记，应用于电场线末端
  8. 间距标注：使用SVG `<line>` + 两端箭头标记 + 中间文字
- ID 命名规范：所有交互元素ID以`scene1-`为前缀
  - 球：`scene1-ball-a`、`scene1-ball-b`
  - 标签：`scene1-label-a`、`scene1-label-q`、`scene1-label-ma`、`scene1-label-b`、`scene1-label-mb`
  - 速度箭头：`scene1-arrow-va`、`scene1-arrow-vb`
  - 速度标注：`scene1-text-va`、`scene1-text-vb`
  - 碰撞光晕：`scene1-collision-glow`
  - 碰撞文字：`scene1-text-collision`
  - 总结框：`scene1-summary-box`
  - 间距标注：`scene1-label-l`、`scene1-line-l`
  - 电场标识：`scene1-label-e`
  - 控件：`scene1-btn-prev`、`scene1-btn-next`、`scene1-step-text`
  - 电场线：`scene1-fieldline-1` ~ `scene1-fieldline-4`
  - 水平面：`scene1-ground`
- JS 隔离：所有JS代码包裹在IIFE中 `(function() { 'use strict'; ... })();`
- SVG元素操作：使用`document.getElementById()`获取元素，通过setAttribute()更新属性，不使用querySelectorAll配合全局class
