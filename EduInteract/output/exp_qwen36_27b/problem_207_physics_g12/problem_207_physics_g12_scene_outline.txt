    **题目原文：**

    如图所示，一倾角α=37°、长度为9m的固定斜面，其底端与长木板B上表面等高，原来B静止在粗糙水平地面上，左端与斜面接触但不粘连，斜面底端与木板B的上表面接触处圆滑，一可视为质点的小滑块A从斜面顶端处由静止开始下滑，最终A刚好未从木板B上滑下。已知A、B的质量相等，木板B的长度L=3m，A与斜面、B上表面间的动摩擦因数均为μ₁=0.5，B与地面的动摩擦因数为μ₂，重力加速度g取10m/s²。

    （1）通过计算分析当A滑上B的上表面后，B是否仍保持静止；

    （2）若B仍然静止，求出μ₂的最小值；若B滑动，求出μ₂的值。

    **题目分析：**

    本题是经典的"滑块-木板"模型，涉及两个运动阶段：

    **阶段一：A在斜面上匀加速下滑**
    - A受重力、斜面支持力、斜面摩擦力
    - 沿斜面方向：mgsinα - μ₁mgcosα = ma₁
    - 可求出A到达斜面底端时的速度v₀

    **阶段二：A滑上B后，A与B的相对运动**
    - A在B上受摩擦力减速，B受A给的摩擦力可能加速
    - 关键条件"A刚好未从B上滑下"意味着：A滑到B右端时，A与B恰好共速
    - 需要判断B是否滑动，这取决于μ₂的大小

    **整体讲解思路：**

    本题的解题关键在于理解两个阶段的衔接和"刚好未滑下"的物理含义。图示规划为两个场景：

    1. **SCENE_1**：展示斜面阶段——A的受力分析与下滑运动，计算到达底端的速度
    2. **SCENE_2**：展示木板阶段——A滑上B后的受力分析、运动过程，利用共速条件和相对位移求解μ₂

    两个场景分别对应题目的两个核心物理过程，帮助教师逐步引导学生完成分析。

    **SCENE_2 教学说明：**

    本图示是本题的核心，展示A滑上B后的复杂运动过程。教师可按以下步骤讲解：

    **步骤0——明确初始条件**
    - A以v₀=6m/s滑上B的左端，B初始静止
    - 强调A和B质量相等（均为m）

    **步骤1——分别受力分析**
    - **对A**：竖直方向mg=mg（平衡），水平方向只受B给的摩擦力μ₁mg向左
    - **对B**：竖直方向受A的压力mg和自身重力mg，总压力2mg；水平方向受A给的摩擦力μ₁mg向右、地面摩擦力μ₂×2mg向左
    - 关键：B受到的地面正压力是2mg（A和B的总重力）

    **步骤2——判断B是否滑动**
    - 先假设B静止，则A在B上做匀减速运动，加速度a_A = -μ₁g = -5m/s²
    - A减速到0的位移：s = v₀²/(2μ₁g) = 36/10 = 3.6m
    - 但B只有3m长，3.6m > 3m，说明A会滑出B，与"刚好未滑下"矛盾
    - **结论：B必须滑动**

    **步骤3——利用共速条件求解μ₂**
    - 设共速时间为t，共速速度为v
    - 共速条件：v = v₀ + a_A·t = a_B·t
    - 即 6 - 5t = a_B·t，得 t = 6/(5 + a_B)
    - 相对位移条件：s_A - s_B = L = 3m
    - s_A = v₀t + ½a_A·t² = 6t - 2.5t²
    - s_B = ½a_B·t²
    - 代入得：6t - ½(5 + a_B)t² = 3
    - 将t = 6/(5+a_B)代入，解得 a_B = 1 m/s²
    - 由 a_B = (μ₁mg - μ₂·2mg)/(2m) = (μ₁ - 2μ₂)g/2
    - 代入：(0.5 - 2μ₂)×5 = 1，解得 **μ₂ = 0.15**
    - 验证：t = 1s，v = 1m/s，s_A = 3.5m，s_B = 0.5m，s_A - s_B = 3m ✓

    **课堂讲解建议：**
    - 在步骤2中，先让学生猜测B是否滑动，再引导他们用假设法验证
    - 在步骤3中，强调"刚好未滑下"的物理含义：相对位移等于板长，且此时共速
    - 可让学生思考：如果μ₂更大或更小，会发生什么？

    **完整解答总结：**

    **第（1）问：B是否保持静止？**

    假设B静止，A在B上以a_A = -μ₁g = -5m/s²减速。

    A减速到0的位移：s = v₀²/(2|a_A|) = 36/10 = 3.6m

    由于3.6m > L = 3m，A会滑出B，与题意"刚好未滑下"矛盾。

    **因此B不可能保持静止，B会滑动。**

    **第（2）问：求μ₂的值**

    由上述分析，B滑动。设A、B共速时速度为v，时间为t。

    A的加速度：a_A = -μ₁g = -5 m/s²

    B的加速度：a_B = (μ₁mg - μ₂·2mg)/(2m) = (μ₁ - 2μ₂)g/2

    共速条件：v₀ + a_A·t = a_B·t → 6 - 5t = a_B·t → t = 6/(5 + a_B)

    相对位移：s_A - s_B = L = 3m

    即 6t - ½(5 + a_B)t² = 3

    代入t = 6/(5+a_B)，解得 a_B = 1 m/s²

    由 (0.5 - 2μ₂)×5 = 1，得 **μ₂ = 0.15**

    **验证：** t = 1s，v = 1m/s，s_A = 3.5m，s_B = 0.5m，s_A - s_B = 3m = L ✓

    **教学要点回顾：**
    - 本题是"滑块-木板"经典模型，核心是相对运动分析
    - "刚好未滑下"等价于"相对位移等于板长且共速"
    - 解题时先用假设法判断B是否滑动，再列方程求解
    - 注意B受地面摩擦力时，正压力为A和B的总重力2mg
