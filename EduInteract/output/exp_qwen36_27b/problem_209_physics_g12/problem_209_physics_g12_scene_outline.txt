    **题目原文：**

    如图（a），一物块在t=0时刻滑上一固定斜面，其运动的v-t图线如图（b）所示．若重力加速度g、斜面的倾角θ及图中的v₀、v₁、t₁均为已知量，求物块与斜面间的动摩擦因数．

    **题目分析：**

    本题是高中物理经典题型，综合考查牛顿第二定律与运动学图像的结合。核心思路是：通过 v-t 图像的斜率求出上滑和下滑两个阶段的加速度，再结合受力分析列出牛顿第二定律方程，联立求解动摩擦因数 μ。

    **关键物理过程：**
    - 上滑阶段（0 ~ t₁）：物块沿斜面向上减速，加速度 a₁ = -v₀/t₁，受力为重力分力 mg sinθ 和摩擦力 μmg cosθ，两者同向（均沿斜面向下）
    - 下滑阶段（t₁ ~ 3t₁）：物块沿斜面向下加速，加速度大小为 v₁/(2t₁)，受力为重力分力 mg sinθ（沿斜面向下）和摩擦力 μmg cosθ（沿斜面向上）

    **整体讲解思路：**
    1. 先引导学生观察 v-t 图像，识别两个运动阶段及其加速度
    2. 再对每个阶段进行受力分析，列出牛顿第二定律方程
    3. 联立两方程消去 g sinθ，解出动摩擦因数 μ

    **图示规划说明：**
    本题规划两个交互式图示：
    - Scene 1：斜面受力分析图——分步展示上滑与下滑两个阶段的受力情况，帮助学生直观理解摩擦力方向的变化
    - Scene 2：v-t 图像分析图——分步标注图像中的关键点、斜率（加速度），建立图像与物理量的对应关系
    </TEXT_1>

    **Scene 1 教学说明：斜面受力分析**

    本图示的核心教学目标是让学生理解**摩擦力方向随运动方向改变而反转**这一关键概念。

    讲解建议：

    1. **步骤0（初始状态）**：引导学生观察斜面结构，确认倾角 θ 的含义。提问："物块在斜面上会受到哪些力？"

    2. **步骤1（上滑阶段）**：
       - 引导学生逐一识别各力：重力 mg（竖直向下）、支持力 N（垂直斜面向上）、摩擦力 f（沿斜面向下，与运动方向相反）
       - 强调重力分解：mg sinθ 沿斜面向下，mg cosθ 垂直斜面向下
       - 指出上滑时，重力分力 mg sinθ 与摩擦力 f 方向相同，均阻碍物块上滑
       - 列出方程：$mg\sin\theta + \mu mg\cos\theta = ma_1$
       - 由牛顿第二定律：$a_1 = g\sin\theta + \mu g\cos\theta$（大小）

    3. **步骤2（下滑阶段）**：
       - **重点强调**：摩擦力方向变为沿斜面向上（与运动方向相反），这是学生最容易出错的地方
       - 重力分力 mg sinθ 方向不变（仍沿斜面向下），此时它促进下滑
       - 列出方程：$mg\sin\theta - \mu mg\cos\theta = ma_2$
       - 由牛顿第二定律：$a_2 = g\sin\theta - \mu g\cos\theta$（大小）

    4. **对比总结**：让学生对比两个阶段的受力图，发现唯一变化的是摩擦力 f 的方向，从而理解"摩擦力总是阻碍相对运动"的本质。

    **Scene 2 教学说明：v-t 图像分析**

    本图示的核心教学目标是让学生掌握**从 v-t 图像斜率提取加速度**的方法，并将运动学量与动力学方程建立联系。

    讲解建议：

    1. **步骤0（初始状态）**：
       - 引导学生识别图像中的关键信息：纵轴截距 v₀（初速度）、横轴截距 t₁（速度为零的时刻）、终点 (3t₁, -v₁)
       - 提问："图像分为几段？每段代表什么运动？"
       - 明确：0 ~ t₁ 为上滑减速阶段，t₁ ~ 3t₁ 为下滑加速阶段

    2. **步骤1（上滑阶段分析）**：
       - 引导学生计算斜率：$a_1 = \frac{\Delta v}{\Delta t} = \frac{0 - v_0}{t_1 - 0} = -\frac{v_0}{t_1}$
       - 强调负号表示加速度方向与正方向（沿斜面向上）相反
       - 加速度大小：$|a_1| = \frac{v_0}{t_1}$

    3. **步骤2（下滑阶段分析）**：
       - 引导学生计算斜率：$a_2 = \frac{\Delta v}{\Delta t} = \frac{-v_1 - 0}{3t_1 - t_1} = -\frac{v_1}{2t_1}$
       - 注意时间间隔是 2t₁（从 t₁ 到 3t₁）
       - 加速度大小：$|a_2| = \frac{v_1}{2t_1}$
       - 提问："为什么 |a₁| > |a₂|？"引导学生理解上滑时重力分力和摩擦力同向，下滑时反向

    4. **步骤3（综合关联）**：
       - 将 Scene 1 的受力方程与 Scene 2 的运动学结果联立：
       
       上滑：$g\sin\theta + \mu g\cos\theta = \frac{v_0}{t_1}$
       
       下滑：$g\sin\theta - \mu g\cos\theta = \frac{v_1}{2t_1}$
       
       - 两式相减：$2\mu g\cos\theta = \frac{v_0}{t_1} - \frac{v_1}{2t_1} = \frac{2v_0 - v_1}{2t_1}$
       
       - 解得：$\mu = \frac{2v_0 - v_1}{2gt_1\cos\theta}$

    **完整解答与课堂讲解建议**

    **完整解答：**

    1. 由 v-t 图像得：
       - 上滑阶段加速度大小：$a_1 = \frac{v_0}{t_1}$
       - 下滑阶段加速度大小：$a_2 = \frac{v_1}{2t_1}$

    2. 由牛顿第二定律：
       - 上滑：$mg\sin\theta + \mu mg\cos\theta = ma_1$，即 $g\sin\theta + \mu g\cos\theta = \frac{v_0}{t_1}$
       - 下滑：$mg\sin\theta - \mu mg\cos\theta = ma_2$，即 $g\sin\theta - \mu g\cos\theta = \frac{v_1}{2t_1}$

    3. 两式相减得：$2\mu g\cos\theta = \frac{v_0}{t_1} - \frac{v_1}{2t_1} = \frac{2v_0 - v_1}{2t_1}$

    4. 解得动摩擦因数：$\mu = \frac{2v_0 - v_1}{2gt_1\cos\theta}$

    **课堂讲解建议：**

    - **导入**：先展示 Scene 2 的 v-t 图像，让学生描述物块的运动过程，激活已有知识
    - **受力分析**：切换到 Scene 1，分步讲解上滑和下滑的受力差异，重点强调摩擦力方向的变化
    - **图像分析**：回到 Scene 2，逐步计算两阶段加速度，建立图像与物理量的联系
    - **综合求解**：将两场景的结论联立，完成代数推导
    - **拓展思考**：可提问"若 μ 很大，物块能否下滑？"引导学生思考临界条件（mg sinθ = μmg cosθ，即 μ = tanθ）

    **常见学生错误提醒：**
    - 下滑阶段时间间隔误算为 3t₁（正确应为 2t₁）
    - 摩擦力方向判断错误（下滑时仍认为沿斜面向下）
    - 加速度符号处理混乱（建议统一用大小列方程，方向由受力分析确定）
