[技术实现]
- JS 库选择：原生 SVG（v-t 图像为简单几何图形，无需复杂库）+ MathJax 3（方程组公式渲染）
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  ┌──────────────────────────────────────────────────────────┐
  │  v↑                                                      │
  │  │ v₀ ●                                                  │
  │  │    ╲ a₁=-v₀/t₁ (蓝)                                  │
  │  │     ╲                                                 │
  │  │      ╲                                                │
  │  │       ● t₁                                            │
  │  O────────╲─────────────────────────────────────────────→t│
  │  │         ╲                                             │
  │  │          ╲ a₂=-v₁/(2t₁) (红)                         │
  │  │           ╲                                           │
  │  │            ╲                                          │
  │  │             ● 3t₁                                     │
  │  -v₁                                                  │
  │                                                       │
  │  ┌────────────────────────────────────┐                │
  │  │ g sinθ + μg cosθ = v₀/t₁          │ (步骤3)        │
  │  │ g sinθ - μg cosθ = v₁/(2t₁)       │                │
  │  └────────────────────────────────────┘                │
  │                                                       │
  │         [◀ 上一步]   [下一步 ▶]                        │
  │                   步骤 X / 3                           │
  └──────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：4 个状态（0-3），每个状态定义哪些 SVG 元素可见/高亮
  2. 状态切换函数 `scene2-setStep(n)`：根据 n 值更新各元素 visibility/stroke/opacity
  3. 上滑段高亮：将上滑线段 stroke 改为 #1565c0，stroke-width 改为 3px
  4. 下滑段高亮：将下滑线段 stroke 改为 #c62828，stroke-width 改为 3px
  5. 斜率三角形：用 SVG `<polygon>` 或 3 条 `<line>` 绘制，stroke-dasharray="4,3"
  6. 方程组：用 MathJax 渲染到 div 容器中，步骤 3 时 display:block，其他步骤 display:none
  7. 按钮事件：点击时调用 scene2-setStep(currentStep ± 1)，并更新按钮禁用状态
  8. 动画过渡：元素出现/消失使用 CSS transition opacity 0.3s ease
- ID 命名规范：所有交互元素 ID 以 `scene2-` 为前缀
  - `scene2-svg`：主 SVG 容器
  - `scene2-axis-t`、`scene2-axis-v`：坐标轴
  - `scene2-line-up`、`scene2-line-down`：上滑/下滑图线段
  - `scene2-point-v0`、`scene2-point-t1`、`scene2-point-3t1`：关键点
  - `scene2-label-v0`、`scene2-label-t1`、`scene2-label-3t1`、`scene2-label-v1`：关键标签
  - `scene2-triangle-up`、`scene2-triangle-down`：斜率三角形组
  - `scene2-label-dv-up`、`scene2-label-dt-up`、`scene2-label-dv-down`、`scene2-label-dt-down`：Δv/Δt 标签
  - `scene2-label-a1`、`scene2-label-a2`：加速度标注
  - `scene2-equation-box`：方程组容器
  - `scene2-btn-prev`、`scene2-btn-next`：导航按钮
  - `scene2-step-indicator`：步骤指示器
  - `scene2-projection-h`、`scene2-projection-v`：虚线投影
- IIFE 隔离：所有 JS 代码包裹在 `(function() { 'use strict'; ... })();` 中
- MathJax 配置：在方程组显示时调用 `MathJax.typesetPromise()` 渲染公式
