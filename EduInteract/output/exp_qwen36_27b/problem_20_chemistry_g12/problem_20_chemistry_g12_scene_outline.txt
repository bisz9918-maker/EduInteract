    **题目原文：**

    将C棒、Fe棒平行插入饱和NaCl溶液中（如图所示）．下列叙述符合事实的是（ ）

    A．断开 K₂，闭合 K₁时，Fe 电极反应为：2H⁺+2e⁻=H₂↑

    B．断开 K₂，闭合 K₁时，C电极反应为：2Cl⁻-2e⁻=Cl₂↑

    C．断开 K₁，闭合 K₂时，Fe 电极反应为：Fe-2e⁻=Fe²⁺

    D．断开 K₁，闭合 K₂时，C电极反应为：2Cl⁻-2e⁻=Cl₂↑

    **题目分析：**

    本题考察电化学中原电池与电解池的判断及电极反应式的书写。装置中有两个开关：K₁直接连接两电极（无电源），K₂串联直流电源。关键在于根据开关状态判断装置类型，再确定电极反应。

    **整体讲解思路：**

    1. 先引导学生观察装置图，识别关键元件：C棒（惰性电极）、Fe棒（活泼金属）、饱和NaCl溶液（中性电解质）、两个开关及电源
    2. 分析K₁闭合时的原电池模式：Fe作负极被氧化，C作正极发生吸氧腐蚀
    3. 分析K₂闭合时的电解池模式：C接电源正极作阳极，Fe接电源负极作阴极
    4. 逐项判断选项，得出正确答案D

    **图示规划说明：**

    本图示以装置图为核心，通过多状态切换展示三种工作状态（初始/原电池/电解池），直观呈现电极极性、电子流向、离子迁移方向和电极反应式，帮助学生对比理解两种电化学装置的本质区别。

    **本图示教学说明：**

    本图示通过三种状态的切换，完整呈现该电化学装置在不同开关配置下的工作原理。

    **状态0（初始状态）的教学引导：**

    教师应引导学生仔细观察装置图，识别以下关键信息：
    1. 两个电极材料不同：C为惰性电极，Fe为活泼金属
    2. 电解质为饱和NaCl溶液（中性环境）
    3. 两条支路：K₁支路无电源，K₂支路有直流电源
    4. 电源极性：左正右负（长线为正，短线为负）

    **状态1（闭合K₁，原电池模式）的教学要点：**

    1. 判断装置类型：无外接电源，构成原电池
    2. 判断电极：Fe比C活泼，Fe作负极，C作正极
    3. 负极反应：Fe失去电子被氧化，Fe - 2e⁻ = Fe²⁺
    4. 正极反应：中性溶液中发生吸氧腐蚀，O₂ + 2H₂O + 4e⁻ = 4OH⁻
    5. 电子流向：从负极Fe经导线流向正极C
    6. 离子迁移：阴离子向负极移动，阳离子向正极移动

    **重点强调：** 饱和NaCl溶液为中性环境，正极不是H⁺得电子生成H₂，而是O₂得电子生成OH⁻（吸氧腐蚀）。这是学生常犯的错误。

    **状态2（闭合K₂，电解池模式）的教学要点：**

    1. 判断装置类型：有外接电源，构成电解池
    2. 判断电极：C接电源正极→阳极，Fe接电源负极→阴极
    3. 阳极反应：Cl⁻在阳极失电子，2Cl⁻ - 2e⁻ = Cl₂↑
    4. 阴极反应：H⁺在阴极得电子，2H⁺ + 2e⁻ = H₂↑（H⁺来自水的电离）
    5. 电子流向：电源负极→阴极Fe，阳极C→电源正极
    6. 离子迁移：阴离子向阳极移动，阳离子向阴极移动

    **重点强调：** 电解池中电极极性由外接电源决定，与电极材料活泼性无关。阳极发生氧化反应，阴极发生还原反应。

    **选项逐项分析：**

    1. **选项A**：断开K₂，闭合K₁时，Fe作负极，反应为Fe - 2e⁻ = Fe²⁺，而非H⁺得电子。A错误。
    2. **选项B**：断开K₂，闭合K₁时，C作正极，发生还原反应（O₂得电子），而非Cl⁻失电子。B错误。
    3. **选项C**：断开K₁，闭合K₂时，Fe作阴极，发生还原反应（H⁺得电子），而非Fe失电子。C错误。
    4. **选项D**：断开K₁，闭合K₂时，C作阳极，Cl⁻失电子生成Cl₂，2Cl⁻ - 2e⁻ = Cl₂↑。D正确。

    **课堂讲解建议：**

    1. 先展示初始状态，让学生观察装置结构，提问"这个装置能构成原电池吗？能构成电解池吗？"
    2. 切换到原电池模式，引导学生判断电极和书写电极反应式，特别强调中性溶液中的吸氧腐蚀
    3. 切换到电解池模式，引导学生根据电源极性判断阴阳极，书写电极反应式
    4. 最后回到选项，逐项分析，得出正确答案D
    5. 可进一步提问："如果将饱和NaCl溶液换成稀硫酸，电极反应会有什么变化？"以拓展学生思维
