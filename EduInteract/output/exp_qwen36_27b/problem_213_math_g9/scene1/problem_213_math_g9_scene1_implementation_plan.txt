[图示主题与整合说明]
- 本图示主题：自行车链条连接规律与总长度计算
- 整合的步骤/概念：单节链条结构展示 → 双节连接重叠分析 → 三节连接规律归纳 → n节通项公式推导 → 100节代入计算
- 教学价值：教师通过分步按钮控制讲解节奏，从具体实例（1节、2节、3节）引导学生观察重叠规律，归纳出通项公式 L = 1.7n + 0.8，最后代入 n=100 得出答案 170.8cm。教师可随时回退复习任意步骤。

[视觉元素清单]

1. 链条节（核心图形）

   - 样式：fill=#c62828，fill-opacity=0.2

4. 公式文本框

   - 样式：rect fill=#e3f2fd，stroke=#1565c0，stroke-width=1.5，rx=8
   - 文本：fill=#1565c0，font-size=16px，居中

5. 省略号

6. 控件栏

   - 按钮样式：rect rx=6，fill=#e3f2fd，stroke=#1565c0

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：位置 (280,455)-(390,485)，点击后 currentStep--，更新视图
  - "下一步 ▶"按钮：位置 (410,455)-(520,485)，点击后 currentStep++，更新视图
  - 步骤指示文字：位置 (400, 475)，显示"步骤 X/4"
  - 步骤0时"上一步"按钮禁用（灰色）
  - 步骤4时"下一步"按钮禁用（灰色）
- 教师操作流程：
  1. 页面加载后显示步骤0（1节链条），教师讲解单节链条结构
  2. 点击"下一步 ▶"进入步骤1，讲解双节连接和重叠概念
  3. 点击"下一步 ▶"进入步骤2，引导学生观察三节链条的重叠规律
  4. 点击"下一步 ▶"进入步骤3，归纳n节通项公式
  5. 点击"下一步 ▶"进入步骤4，代入n=100得出答案
  6. 可随时点击"◀ 上一步"回退到任意步骤复习

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  +--------------------------------------------------+
  |              步骤标题 (y=38)                      |
  |                                                  |
  |     尺寸标注线/标签 (y=128~165)                   |
  |                                                  |
  |         链 条 图 形 区 (y=170~210)                |
  |                                                  |
  |     总长标注线/标签 (y=238~283)                   |
  |                                                  |
  |  +------------------------------------------+    |
  |  |         公式文本框 (y=328~393)            |    |
  |  +------------------------------------------+    |
  |                                                  |
  |  +----------+  步骤 X/4  +----------+            |
  |  | ◀ 上一步 |            | 下一步 ▶ |            |
  |  +----------+            +----------+            |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：currentStep 变量（0~4），每个步骤对应一组预定义的链条数据
  2. 链条数据定义：每个步骤的圆孔坐标数组、连接线路径、标注位置
  3. 视图更新函数 renderStep(step)：清除旧图形 → 绘制新链条 → 更新标注 → 更新公式 → 更新按钮状态
  4. 动画：步骤切换时使用 CSS transition 或 requestAnimationFrame 实现淡入淡出效果（300ms）
  5. 事件绑定：按钮 click 事件触发 stepNext() / stepPrev()
  6. 按钮禁用逻辑：步骤0禁用"上一步"，步骤4禁用"下一步"
- ID 命名规范：所有交互元素 ID 以 `scene1-` 为前缀
  - `scene1-chain-group`：链条图形组
  - `scene1-dimensions-group`：尺寸标注组
  - `scene1-formula-box`：公式文本框
  - `scene1-formula-text`：公式文本
  - `scene1-step-title`：步骤标题
  - `scene1-btn-prev`：上一步按钮
  - `scene1-btn-next`：下一步按钮
  - `scene1-step-indicator`：步骤指示
  - `scene1-svg`：SVG容器
- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
- SVG 箭头标记：定义 <marker id="scene1-arrow"> 用于标注线两端
