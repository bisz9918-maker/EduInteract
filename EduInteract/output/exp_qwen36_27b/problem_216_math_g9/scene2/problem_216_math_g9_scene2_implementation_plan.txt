[图示主题与整合说明]
- 本图示主题：五个结论的逐一验证——基于完整抛物线图像，判断每个结论的正误
- 整合的步骤/概念：
  1. 结论① 4ac < b² 的验证（判别式与交点个数关系）
  2. 结论② 3a + c > 0 的验证（代入计算）
  3. 结论③ x > 0 时单调性的验证（图像观察）
  4. 结论④ y > 0 时 x 取值范围的验证（图像观察）
  5. 结论⑤ 方程根的验证（交点坐标）
  6. 最终统计正确结论个数
- 教学价值：教师通过分步按钮控制讲解节奏，逐步引导学生理解每个结论的判断依据，从图像特征到代数推导，培养数形结合思维。每步验证后即时显示 ✓/✗ 标记，帮助学生建立清晰的判断逻辑。

- 按钮状态："◀上一步" 禁用（灰色），"下一步▶" 可用

步骤1（验证结论① 4ac < b²）：
- 视觉变化：
  - 点(-1,0)和点(3,0)高亮（变为绿色 #2e7d32，r=6px）
  - 推导文字框显示："Δ = b² - 4ac > 0（两个交点）⇒ b² > 4ac ⇒ 4ac < b² ✓"
  - 结论①旁显示绿色 ✓（#2e7d32，20px）
- 新增元素坐标：推导文字框(60,375)-(520,425)，标记(755,78)

步骤2（验证结论② 3a + c > 0）：
- 视觉变化：
  - 清除步骤1的高亮（点恢复黑色r=4px）
  - 推导文字框更新："由 a - b + c = 0，b = -2a ⇒ 3a + c = 0，故 3a + c > 0 不成立 ✗"
  - 结论②旁显示红色 ✗（#c62828，20px）
- 新增元素坐标：推导文字框(60,375)-(520,425)，标记(755,133)

步骤3（验证结论③ 单调性）：
- 视觉变化：
  - 清除步骤2的标记（但保留①的✓和②的✗）
  - 显示蓝色半透明填充区域（0 < x < 1，即画布x∈(160,215)抛物线与x轴之间）
  - 显示红色半透明填充区域（x > 1，即画布x∈(215,325)抛物线与x轴之间）
  - 推导文字框更新："0 < x < 1 时 y 递增，x > 1 时 y 递减，故结论③错误 ✗"
  - 结论③旁显示红色 ✗
- 新增元素坐标：蓝色填充(160,340)-(215,120)区域，红色填充(215,340)-(325,120)区域

步骤4（验证结论④ y > 0 的范围）：
- 视觉变化：
  - 清除步骤3的蓝/红色填充
  - 显示绿色半透明填充区域（-1 < x < 3 且 y > 0，即画布x∈(105,325)抛物线弧与x轴之间）
  - 推导文字框更新："y > 0 对应 -1 < x < 3，结论④正确 ✓"
  - 结论④旁显示绿色 ✓
- 新增元素坐标：绿色填充区域覆盖抛物线弧下方至x轴

步骤5（验证结论⑤ 方程的根）：
- 视觉变化：
  - 清除步骤4的绿色填充
  - 点(-1,0)和点(3,0)高亮（变为绿色 #2e7d32，r=6px）
  - 推导文字框更新："方程 ax²+bx+c=0 的根 = 抛物线与x轴交点横坐标：x₁=-1, x₂=3 ✓"
  - 结论⑤旁显示绿色 ✓
- 新增元素坐标：推导文字框(60,375)-(520,425)，标记(755,298)

步骤6（总结）：
- 视觉变化：
  - 清除步骤5的高亮
  - 推导文字框替换为答案框："正确结论：①④⑤，共 3 个 → 答案 B"
  - 答案框：(200,380)-(380,420)，浅绿背景，绿色粗体16px
  - 结论卡片中①④⑤的✓变为加粗绿色，②③的✗保持红色
- 按钮状态："◀上一步" 可用，"下一步▶" 禁用

[技术实现]
- JS 库选择：原生 SVG（无需额外库，抛物线用 SVG path 绘制，交互用原生 DOM 操作）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+------------------------+
  |                                                  |  结论卡片              |
  |         y                                        |  ┌──────────────────┐  |
  |         ↑                                        |  │ ① 4ac < b²    ✓ │  |
  |         |         (1,4)                          |  ├──────────────────┤  |
  |         |           ●                            |  │ ② 3a+c > 0    ✗ │  |
  |         |         /   \                          |  ├──────────────────┤  |
  |         |       /       \                        |  │ ③ 单调性       ✗ │  |
  |         |     /           \                      |  ├──────────────────┤  |
  |         |   ●               ●(3,0)               |  │ ④ -1<x<3      ✓ │  |
  |         |  /                   \                 |  ├──────────────────┤  |
  |         | /                       \              |  │ ⑤ 两根         ✓ │  |
  |    (-1,0)●                           \           |  └──────────────────┘  |
  |         /                               \        |                        |
  |        /                                 \       |                        |
  |-------●----------●----------●-------------●----→ x                       |
  |      -1          O          1             3     |                        |
  |                                                  |                        |
  |  ┌──────────────────────────────────────────┐   |                        |
  |  │ 推导文字框（显示当前步骤推导过程）        │   |                        |
  |  └──────────────────────────────────────────┘   |                        |
  |                                                  |                        |
  |              ┌──────────┐    ┌──────────┐       |                        |
  |              │◀ 上一步  │    │ 下一步 ▶ │       |                        |
  |              └──────────┘    └──────────┘       |                        |
  +--------------------------------------------------+------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：currentStep (0~6)，每个步骤对应一组视觉元素的显示/隐藏/高亮状态
  2. 抛物线绘制：SVG path `M 105,340 Q 215,120 325,340`（二次贝塞尔曲线近似抛物线）
  3. 区间填充：使用 SVG `<path>` 封闭区域 + `<polygon>` 实现半透明填充
     - 步骤3蓝色区域：x∈(160,215)，上边界为抛物线弧，下边界为x轴
     - 步骤3红色区域：x∈(215,325)，上边界为抛物线弧，下边界为x轴
     - 步骤4绿色区域：x∈(105,325)，上边界为抛物线弧，下边界为x轴
  4. 动画过渡：使用 CSS transition（0.3s ease）实现元素淡入淡出和高亮切换
  5. 事件绑定：按钮 click 事件触发 stepForward()/stepBackward()，更新 currentStep 并重绘
  6. 推导文字更新：每个步骤预定义文字内容，切换时更新 SVG text 元素
  7. 判断标记：每个结论对应一个 SVG text 元素，初始为空字符串，步骤触发时设置 ✓ 或 ✗
- ID 命名规范：所有交互元素 ID 以 `scene2-` 为前缀
  - 按钮：`scene2-prev-btn`、`scene2-next-btn`
  - 抛物线：`scene2-parabola`
  - 对称轴：`scene2-axis`
  - 关键点：`scene2-pt-neg1`、`scene2-pt-0`、`scene2-pt-3`、`scene2-pt-vertex`
  - 结论标记：`scene2-mark-1` ~ `scene2-mark-5`
  - 推导文字：`scene2-derivation-text`
  - 填充区域：`scene2-fill-blue`、`scene2-fill-red`、`scene2-fill-green`
  - 答案框：`scene2-answer-box`
- IIFE 隔离：所有 JS 代码包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染
- SVG 命名空间：`xmlns="http://www.w3.org/2000/svg"`，viewBox="0 0 800 500"
