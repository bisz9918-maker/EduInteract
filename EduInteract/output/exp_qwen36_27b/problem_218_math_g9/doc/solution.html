题目原文：

如图，将一副直角三角板摆放，点$C$在$EF$上，$AC$经过点$D$，已知∠$A$=∠$EDF$=90°，$AB$=$AC$，∠$E$=30°，∠$BCE$=40°，则∠$CDF$=（ ）

A．$20^{\circ}$ B．$25^{\circ}$ C．$30^{\circ}$ D．$35^{\circ}$

题目分析：

本题涉及两个特殊直角三角板的摆放关系：

  • △ABC 是等腰直角三角板（∠A=90°，AB=AC），故 ∠ABC=∠ACB=45°
  • △DEF 是含30°角的直角三角板（∠EDF=90°，∠E=30°），故 ∠F=60°

关键几何关系：

  • 点C在线段EF上，即E、C、F三点共线
  • AC经过点D，即A、D、C三点共线

解题思路：

  1. 由等腰直角三角形得 ∠ACB = 45°
  2. 由 ∠BCE = 40°，得 ∠ACE = ∠ACB + ∠BCE = 45° + 40° = 85°
  3. 由E、C、F共线，得 ∠ACF = 180° - ∠ACE = 180° - 85° = 95°
  4. 由A、D、C共线，得 ∠DCF = ∠ACF = 95°
  5. 在△CDF中，∠CDF = 180° - ∠DCF - ∠F = 180° - 95° - 60° = 25°

答案：B．$25^{\circ}$

步骤 0/5

教学说明：

本图示通过分步导航完整展示从已知条件到求解∠CDF的推导过程。

引导建议：

  1. 步骤0（初始观察）：请学生观察图形，识别两个三角板的类型。提问："△ABC是什么三角形？△DEF呢？"引导学生回忆等腰直角三角板和30°-60°-90°三角板的特征。
  1. 步骤1（分析△ABC）：强调AB=AC意味着△ABC是等腰直角三角形，因此∠ACB=∠ABC=45°。这是解题的第一个关键。
  1. 步骤2（计算∠ACE）：引导学生观察∠ACE由哪两个角组成。∠ACE = ∠ACB + ∠BCE = 45° + 40° = 85°。提醒学生注意角的加法关系。
  1. 步骤3（利用共线关系）：强调点C在EF上，即E、C、F三点共线，所以∠ECF=180°（平角）。因此∠ACF = 180° - ∠ACE = 95°。同时指出A、D、C共线，所以∠DCF = ∠ACF = 95°。
  1. 步骤4（分析△DEF）：由∠EDF=90°、∠E=30°，得∠F=60°。这是第二个关键数据。
  1. 步骤5（求解）：在△CDF中，利用三角形内角和定理：∠CDF = 180° - ∠DCF - ∠F = 180° - 95° - 60° = 25°。

关键知识点：

  • 等腰直角三角形的性质（两底角相等且各为45°）
  • 30°-60°-90°三角形的角度关系
  • 三点共线与平角（180°）
  • 三角形内角和定理（180°）

易错点提醒：

  • 学生可能忽略A、D、C共线这一条件，导致无法将∠ACF转化为∠DCF
  • 学生可能混淆∠ACE和∠ACF的关系，需注意它们互补（和为180°）
