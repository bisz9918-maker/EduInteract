[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）

  - 「上一步」按钮：位于(260,455)-(360,480)，点击返回上一步骤，步骤0时禁用
  - 「下一步」按钮：位于(440,455)-(540,480)，点击进入下一步骤，步骤3时禁用

- 教师操作流程：
  1. 图示加载后显示基础环流图（步骤0），教师可先让学生观察整体结构
  2. 点击「下一步」进入步骤1，高亮上升/下沉气流，标注温度分布，教师讲解"受热上升、冷却下沉"原理
  3. 点击「下一步」进入步骤2，标注四处气压高低，教师讲解"近地面高压对应冷却区，低压对应受热区；高空相反"
  4. 点击「下一步」进入步骤3，显示选项A和B并标记错误，教师引导学生分析错误原因
  5. 可随时点击「上一步」回退到任意步骤复习

[技术实现]
- JS 库选择：原生 SVG（本场景为简单几何图形+文字标注，无需复杂库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  ┌─────────────────────────────────────────────────────┐
  │                                                     │
  │         ①  ←──────────────────────→  ①            │ y=62
  │    d ──────────────────────────────── c             │ y=80
  │    │                                    │           │
  │  ④│                                    │②          │
  │    │        高空                        │           │ y=210
  │    │                                    │           │
  │    │                                    │           │
  │    ▼                                    ▲           │
  │    a ──────────────────────────────── b             │ y=340
  │    │  ③  →──────────────────────→  ③  │           │
  │    └────────── 地面 ──────────────────┘             │ y=375
  │                                                     │
  │         低温              高温                      │ y=395
  │                    结论文字                         │ y=408
  │    ┌──────────────┐  ┌──────────────┐              │ y=390~425
  │    │   选项A ✗    │  │   选项B ✗    │              │
  │    └──────────────┘  └──────────────┘              │
  │                    最终结论                         │ y=438
  │                                                     │
  │         [◀上一步]  步骤 X/3  [下一步▶]              │ y=455~480
  └─────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量`currentStep`（0~3）管理当前步骤，每个步骤对应一组显示/隐藏/高亮的元素
  2. SVG元素用`<g>`分组管理，每组对应一个步骤的专属元素，通过CSS class控制显隐
  3. 箭头用`<line>`+`<marker-end>`实现箭头头部
  4. 地面平行四边形用`<polygon>`绘制
  5. 标签背景用`<rect>`+`<text>`组合实现
  6. 红色叉号用`<text>`字符"✗"或SVG路径绘制
  7. 按钮用`<rect>`+`<text>`+`<a>`或`<g>`+click事件实现
  8. 步骤切换时，隐藏/显示对应`<g>`组，用CSS transition实现淡入淡出效果
  9. 箭头高亮通过切换stroke颜色和stroke-width实现
- ID 命名规范：所有交互元素ID以`scene1-`为前缀
  - `scene1-circulation`：环流框架组
  - `scene1-ground`：地面平行四边形
  - `scene1-points`：四个点
  - `scene1-labels`：四个点名标签
  - `scene1-arrows`：四个箭头
  - `scene1-arrow-labels`：四个箭头编号
  - `scene1-step1`：步骤1专属元素组
  - `scene1-step2`：步骤2专属元素组
  - `scene1-step3`：步骤3专属元素组
  - `scene1-prev-btn`：上一步按钮
  - `scene1-next-btn`：下一步按钮
  - `scene1-step-indicator`：步骤指示文字
- IIFE 隔离：所有 JS 代码包在 `(function() { ... })()` 中，避免全局污染
