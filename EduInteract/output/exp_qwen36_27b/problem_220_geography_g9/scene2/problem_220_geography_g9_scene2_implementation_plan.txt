[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  * 「上一步」按钮：位于(280,455)，点击后回退到前一步骤，隐藏当前步骤新增元素
  * 「下一步」按钮：位于(440,455)，点击后进入下一步骤，显示新增元素并高亮相关箭头
  * 步骤指示文本：位于(400,468)，显示"步骤 X/3"，当前步骤高亮
- 教师操作流程：
  1. 图示加载后显示基础环流图（步骤0），教师可先讲解环流图的基本结构
  2. 点击「下一步」进入步骤1，展示纬度对应和气压带标注，教师讲解副热带高压和副极地低压的形成
  3. 点击「下一步」进入步骤2，展示风带和冷暖气流相遇，教师讲解中纬西风和极地东风的相遇形成极锋
  4. 点击「下一步」进入步骤3，展示下沉原因分析和选项判断，教师讲解选项C正确、选项D错误的原因
  5. 教师可随时点击「上一步」回退到任意步骤进行复习

[技术实现]
- JS 库选择：原生 SVG（简单几何图形和箭头，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌────────────────────────────────────────────────────────────┐
  │                                                            │
  │                    ①                                       │
  │  d ──────────────────────────────── c                      │
  │  │                                  │                      │
  │  │ ④                                │ ②                    │
  │  │                                  │                      │
  │  a ──────────────────────────────── b                      │
  │  ③                                  │                      │
  │  ┌──────────────────────────────────────┐                  │
  │  │         地面（灰色平行四边形）         │                  │
  │  └──────────────────────────────────────┘                  │
  │                                                            │
  │  [步骤1-3新增元素：纬度、气压带、风带、极锋、选项判断]       │
  │                                                            │
  │  ┌────────────────────────────────────────────────────┐    │
  │  │  [上一步]    步骤 X/3    [下一步]                   │    │
  │  └────────────────────────────────────────────────────┘    │
  └────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  * 状态机设计：使用当前步骤索引（0-3）控制显示/隐藏元素
  * 每个步骤的元素用独立的 SVG group（<g>）包裹，通过显示/隐藏 group 实现步骤切换
  * 箭头使用 SVG <line> 元素配合 <marker-end> 定义箭头头部
  * 高亮效果通过修改 stroke 颜色和 stroke-width 实现
  * 波浪线使用 SVG <path> 元素绘制正弦曲线
  * 选项文本框使用 SVG <rect> + <text> 组合
  * 按钮使用 HTML <button> 元素，通过 CSS 定位在 SVG 底部
  * 步骤指示文本实时更新
- ID 命名规范：所有交互元素 ID 以 `scene2-` 为前缀
  * 环流框架：scene2-loop-frame
  * 地面：scene2-ground
  * 顶点：scene2-point-a, scene2-point-b, scene2-point-c, scene2-point-d
  * 箭头：scene2-arrow-1, scene2-arrow-2, scene2-arrow-3, scene2-arrow-4
  * 标签：scene2-label-a, scene2-label-b, scene2-label-c, scene2-label-d
  * 箭头编号：scene2-num-1, scene2-num-2, scene2-num-3, scene2-num-4
  * 步骤1元素：scene2-step1-group（包含纬度和气压带标签）
  * 步骤2元素：scene2-step2-group（包含风带、极锋相关元素）
  * 步骤3元素：scene2-step3-group（包含原因分析和选项判断）
  * 按钮：scene2-prev-btn, scene2-next-btn
  * 步骤指示：scene2-step-indicator
- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
