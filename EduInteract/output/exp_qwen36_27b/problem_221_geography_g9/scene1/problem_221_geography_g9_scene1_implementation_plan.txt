[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于底部左侧，点击返回上一步骤，禁用状态（步骤0时）
  - 「下一步 ▶」按钮：位于底部右侧，点击进入下一步骤，禁用状态（步骤3时）
  - 步骤指示器：底部中央显示"步骤 X / 3"
- 教师操作流程：
  1. 初始展示基础地图，引导学生观察经纬网与晨昏线。
  2. 点击「下一步」逐步揭示东西半球分界、甲地时间、直射点位置、昼长计算过程。
  3. 配合讲解，可随时回退复习关键步骤。

[技术实现]
- JS 库选择：原生 SVG + Vanilla JS（无需外部库，轻量高效）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [地图区 150-650, 50-400]
  [标签区 左侧/上方]
  [控件栏 y=440-490]
  ```
- 关键实现要点：
  - 状态机：`currentStep` (0-3)，控制各元素 `display` 或 `opacity`。
  - 晨昏线：`<line x1="300" y1="100" x2="400" y2="350" />`
  - 阴影区：`<polygon points="150,50 300,100 400,350 150,400" />` + `<pattern>` 斜线填充
  - 动画：步骤切换时新增元素使用 `transition: opacity 0.5s` 淡入效果。
  - 事件绑定：按钮点击更新 `currentStep`，重绘/显示对应步骤元素。
- ID 命名规范：所有元素 ID 以 `scene1-` 前缀（如 `scene1-map-box`, `scene1-point-jia`, `scene1-step1-west-hemisphere`）。
- IIFE 隔离：`(function() { ... })();` 包裹所有逻辑，避免全局污染。
