[图示主题与整合说明]
- 本图示主题：太阳能电池板与墙面夹角计算（第5问）
- 整合的步骤/概念：晨昏线与经线夹角→太阳直射点纬度→正午太阳高度计算→电池板最佳倾角

  - 「◀ 上一步」按钮：位置(100,450)，尺寸150×30px，点击回到上一步骤，步骤0时禁用（灰色）

  1. 图示加载后显示步骤0（地球侧视图基础条件），教师讲解晨昏线与经线夹角的概念
  2. 点击「下一步」进入步骤1，展示太阳直射点位置和太阳光线，讲解直射点纬度与晨昏线夹角的关系
  3. 点击「下一步」进入步骤2，展示正午太阳高度计算公式和结果，讲解计算过程
  4. 点击「下一步」进入步骤3，展示建筑物墙面和太阳能电池板，讲解电池板最佳倾角的确定方法

[技术实现]
- JS 库选择：原生 SVG（简单几何图形绘制，无需额外库，性能好）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +-------------------------------------------------------------+
  |  [地球侧视图]                    [公式/结论区]              |
  |                                                             |
  |       晨昏线10°              H=90°-|31°-(-10°)|=49°        |
  |      /          \           正午太阳高度：49°               |
  |     |    上海    |           电池板与墙面夹角=49°           |
  |     |    31°N   |           太阳直射点纬度=10°S            |
  |     |           |                                         |
  |     |  直射点   |           墙面    太阳能电池板           |
  |     |  10°S    |          |      /  （⊥太阳光线）          |
  |     |           |          |     /  49°                    |
  |     |___________|          |____/__________________________|
  |                                                             |
  |                    地面线─────────────────────────          |
  |                                                             |
  |  [◀ 上一步]        步骤 X/3        [下一步 ▶]              |
  +-------------------------------------------------------------+
  ```
- 关键实现要点：
  1. **状态机设计**：用变量 `currentStep` (0-3) 管理当前步骤，每个步骤对应一组可见元素
  2. **元素显隐控制**：每个元素添加 `data-step` 属性，表示其首次出现的步骤号。切换步骤时，遍历所有元素，`step <= currentStep` 的显示，否则隐藏
  3. **动画效果**：新增元素使用 CSS transition（opacity 0→1，duration 0.4s）实现淡入效果
  4. **按钮状态管理**：步骤0时"上一步"按钮 disabled（opacity=0.5），步骤3时"下一步"按钮 disabled
  5. **SVG 元素创建**：使用 `document.createElementNS('http://www.w3.org/2000/svg', 'tag')` 创建 SVG 元素
  6. **角度弧线绘制**：使用 SVG `<path>` 的弧命令 `A` 绘制角度标注弧线
  7. **太阳光线箭头**：使用 SVG `<marker>` 定义箭头，应用到 `<line>` 元素
  8. **坐标计算**：
     - 电池板终点：(580 + 80×sin(49°), 280 - 80×cos(49°)) ≈ (642, 226)
     - 太阳高度角弧线：从水平方向(0°)到太阳光线方向(49°)，圆心(180,161)
     - 夹角弧线：从垂直方向(270°)到电池板方向(270°+49°=319°)，圆心(580,280)
- ID 命名规范：所有交互元素 ID 以 `scene3-` 为前缀
  - 按钮：`scene3-prev-btn`、`scene3-next-btn`
  - 步骤指示：`scene3-step-indicator`
  - 地球元素：`scene3-earth-circle`、`scene3-equator`、`scene3-noon-line`、`scene3-morning-line`、`scene3-terminator`
  - 上海相关：`scene3-shanghai-point`、`scene3-shanghai-label`
  - 太阳相关：`scene3-sun-point`、`scene3-sun-label`、`scene3-sun-rays`
  - 公式相关：`scene3-formula`、`scene3-solar-height-label`、`scene3-solar-height-arc`
  - 建筑相关：`scene3-ground-line`、`scene3-wall`、`scene3-wall-label`、`scene3-panel`、`scene3-panel-label`、`scene3-angle-arc`、`scene3-angle-label`
  - 结论：`scene3-conclusion-label`、`scene3-derivation-label`
- IIFE 隔离：所有 JS 代码包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染
