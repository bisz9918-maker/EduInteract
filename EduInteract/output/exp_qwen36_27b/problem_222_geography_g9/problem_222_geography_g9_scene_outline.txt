    **题目原文：**

    读经纬网图和材料，回答下列问题．

    材料：新加坡时间8月26日晚，首届青年奥运会在新加坡（1°N，104°E）美丽的滨海湾落下帷幕．南京市（32°N，118°E）市长季建业从国际奥委会主席罗格手中接过奥运五环旗，而青奥会也将进入名副其实的"南京时间"．（新华网新加坡8月25日电）

    （1）图中①点在③点的________方向．

    （2）首届青年奥运会举办城市新加坡的经纬度位置与图中比较接近的是________（序号）写出①的经纬度________．

    **题目分析：**

    本题是一道初中地理经纬网判读题，考查三个核心知识点：① 根据经纬网确定点的经纬度坐标；② 根据经纬度判断两点之间的相对方向；③ 将实际地点的经纬度与图中点位进行匹配。

    **整体讲解思路：**

    1. 首先引导学生认识经纬网图的结构——经线（竖线）表示东西方向，纬线（横线）表示南北方向，0°经线（本初子午线）左侧为西经（W），右侧为东经（E），0°纬线（赤道）上方为北纬（N），下方为南纬（S）。
    2. 逐点读出①②③④的经纬度坐标。
    3. 利用经纬度判断①相对于③的方向。
    4. 将新加坡（1°N，104°E）与图中各点比较，找出最接近的点。

    **图示规划说明：**

    本题只需一个交互式经纬网图示，通过分步按钮导航整合"读坐标→判方向→比位置"三个教学环节，避免拆分为多个相似图示。

    **本图示教学说明：**

    **步骤0→步骤1：认识经纬网结构**

    教师引导学生观察：
    1. 图中竖线是经线，横线是纬线，它们构成经纬网
    2. 中间的0°经线（本初子午线）是东西经的分界线——左侧为西经（W），右侧为东经（E）
    3. 中间的0°纬线（赤道）是南北纬的分界线——上方为北纬（N），下方为南纬（S）
    4. 经度从0°向两侧递增，纬度从赤道向两极递增

    **步骤2：读出各点坐标**

    教师逐点引导学生读坐标：
    1. ①点：位于120°W与90°W之间正中，纬度在0°线上 → **105°W, 0°**
    2. ②点：位于90°E与120°E之间正中，纬度在0°线上 → **105°E, 0°**
    3. ③点：位于90°E与120°E之间正中，纬度在30°N线上 → **105°E, 30°N**
    4. ④点：位于120°W与150°W之间正中，纬度在30°N线上 → **135°W, 30°N**

    强调读坐标的方法：先看经线（左右位置确定东西经和度数），再看纬线（上下位置确定南北纬和度数）。

    **步骤3：判断方向**

    教师引导学生用"经纬度比较法"判断①在③的方向：
    1. 比较纬度：①为0°，③为30°N → ①在③的**南方**
    2. 比较经度：①为105°W，③为105°E → ①在③的**西方**（西经在东经的西侧）
    3. 综合：**西南方向**

    提示学生：判断方向时，先南北后东西，最后组合。

    **步骤4：匹配新加坡位置**

    教师引导学生将新加坡（1°N, 104°E）与图中各点比较：
    1. 新加坡纬度1°N ≈ 0°，经度104°E ≈ 105°E
    2. ②点坐标为(105°E, 0°)，与新加坡(104°E, 1°N)最为接近
    3. 结论：**②点**最接近新加坡

    **答案总结：**
    - （1）①点在③点的**西南**方向
    - （2）新加坡最接近**②**；①的经纬度为**105°W, 0°**（或写作(0°, 105°W)）

    **课堂讲解建议：**
    - 本题关键是教会学生"读经纬网"的基本功，方向判断和地点匹配都是在此基础上进行的
    - 可让学生先在纸上练习读其他点的坐标，再验证
    - 方向判断可补充口诀："北纬在北，南纬在南；东经在东，西经在西"
