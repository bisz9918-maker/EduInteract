[图示主题与整合说明]
- 本图示主题：经纬网图上四点的坐标判读、方向判断与地点匹配
- 整合的步骤/概念：① 经纬网基础结构展示（经线/纬线/0°经线/赤道）；② 逐点读出①②③④的经纬度坐标；③ 判断①点在③点的方向；④ 将新加坡（1°N，104°E）与图中各点匹配
- 教学价值：教师通过分步导航，引导学生从认识经纬网结构开始，逐步学会读取坐标、判断方向、匹配地理位置，每一步都有明确的视觉反馈，便于课堂节奏控制

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于控件栏左侧，点击返回上一步骤，步骤0时禁用
  - 「步骤 X/4」指示器：位于控件栏中央，显示当前步骤序号
  - 「下一步 ▶」按钮：位于控件栏右侧，点击进入下一步骤，步骤4时禁用
- 教师操作流程：
  1. 图示加载后显示步骤0（基础经纬网），教师介绍经纬网结构
  2. 点击「下一步」进入步骤1，讲解东西经/南北纬的划分
  3. 点击「下一步」进入步骤2，引导学生逐点读取坐标
  4. 点击「下一步」进入步骤3，讲解方向判断方法
  5. 点击「下一步」进入步骤4，完成新加坡位置匹配
  6. 随时点击「上一步」回退复习

- 画布尺寸：800 × 500 px

  └──────────────────────────────────────────────────────────────┘

- 关键实现要点：
  1. 状态机设计：currentStep变量（0~4），切换时更新SVG元素的显示/隐藏/样式
  2. 步骤切换函数：showStep(n)，根据n值设置各元素的CSS class
  3. CSS class管理：
     - .step1-elements：步骤1及之后显示的元素（W/E/N/S标注、绿色0°线）
     - .step2-elements：步骤2及之后显示的元素（坐标标签）
     - .step3-elements：步骤3及之后显示的元素（方向箭头、推理框3）
     - .step4-elements：步骤4显示的元素（新加坡标记、推理框4）
     - 各元素初始opacity=0，通过CSS transition实现淡入
  4. 坐标标签依次淡入：使用CSS animation-delay（0s, 0.3s, 0.6s, 0.9s）
  5. 推理文字框切换：步骤3和步骤4共用同一位置，切换时更新文本内容
  6. 方向箭头：使用SVG <line> + <marker>实现虚线箭头
  7. 新加坡星形：使用SVG <polygon>绘制五角星（5个顶点计算）
  8. 按钮事件绑定：addEventListener('click')绑定上一步/下一步按钮
  9. 边界检查：步骤0时禁用上一步，步骤4时禁用下一步
- ID 命名规范：所有交互元素ID以 `scene1-` 为前缀
  - scene1-grid（网格容器）
  - scene1-meridian-0（0°经线）
  - scene1-equator（0°纬线）
  - scene1-point-1, scene1-point-2, scene1-point-3, scene1-point-4（四个点）
  - scene1-label-w, scene1-label-e, scene1-label-n, scene1-label-s（东西南北标注）
  - scene1-coord-1, scene1-coord-2, scene1-coord-3, scene1-coord-4（坐标标签）
  - scene1-direction-arrow（方向箭头）
  - scene1-direction-label（西南方向标注）
  - scene1-reasoning-box（推理文字框）
  - scene1-singapore-star（新加坡星形）
  - scene1-singapore-label（新加坡标签）
  - scene1-btn-prev, scene1-btn-next, scene1-step-indicator（控件）
- IIFE 隔离：所有JS代码包裹在 (function() { 'use strict'; ... })(); 中
- 事件委托：按钮点击事件直接绑定到具体元素，不使用全局class选择器
