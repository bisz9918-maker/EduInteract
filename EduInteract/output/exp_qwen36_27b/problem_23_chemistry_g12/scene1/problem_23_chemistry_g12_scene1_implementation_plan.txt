[图示主题与整合说明]
- 本图示主题：H₂O₂分子的"书页型"空间结构及其极性分析
- 整合的步骤/概念：展示H₂O₂分子结构 → 标注化学键类型（O-O非极性键、O-H极性键） → 展示分子极性（正负电荷中心不重合） → 补充说明晶体中的分子间作用力（氢键、范德华力）
- 教学价值：教师可通过分步交互，引导学生从宏观分子构型逐步深入到微观化学键性质与分子极性，最后延伸至晶体中的作用力类型，符合化学认知递进规律，便于课堂逐层讲解与提问。

  - H2与第二分子的O1'之间出现蓝色虚线，标注"氢键"
  - 右下方出现文本"范德华力"

- 标签"非极性键"：(350,195) vs 标签"极性键"(左)：(250,165) → 间距~112px → 无冲突

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」：x=250, y=450, w=120, h=40，点击返回上一状态，步骤0时禁用
  - 「下一步 ▶」：x=430, y=450, w=120, h=40，点击进入下一状态，步骤3时禁用
- 教师操作流程：
  1. 初始展示分子骨架，提问"观察H₂O₂的空间构型特点"
  2. 点击下一步，高亮化学键，讲解"O-O为非极性键，O-H为极性键"
  3. 点击下一步，展示电荷分布，讲解"正负电荷中心不重合，故为极性分子"
  4. 点击下一步，展示分子间作用力，总结"晶体中存在的作用力类型"，对应选项B分析

[技术实现]
- JS 库选择：原生 SVG + Vanilla JS（无需外部库，轻量且精确控制几何与样式）
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [ 800 × 500 SVG 画布 ]
  +--------------------------------------------------+
  |  [极性结论文本/晶体作用力总结]                    |
  |                                                  |
  |      H1          O1==O2          H2              |
  |     /  \        /    \        /    \             |
  |   平面1      书页型      平面2                 |
  |                                                  |
  |                          (第二分子虚影+氢键)     |
  |                                                  |
  |              [◀ 上一步]  [下一步 ▶]              |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  - 状态机：`let currentStep = 0; const maxStep = 3;`
  - 每个步骤对应一组 CSS class 或 SVG 元素的 `opacity`/`visibility`/`stroke` 属性切换
  - 使用 `requestAnimationFrame` 或 CSS transition 实现平滑高亮/淡入效果（duration: 0.3s）
  - 按钮点击事件绑定 `updateScene(step)` 函数，根据 step 值更新 DOM
  - 第二分子在步骤3通过 `opacity: 0.6` 淡入，氢键虚线同步绘制
- ID 命名规范：所有交互元素及关键 SVG 元素 ID 以 `scene1-` 为前缀，例如：
  - `scene1-btn-prev`, `scene1-btn-next`
  - `scene1-bond-oo`, `scene1-bond-oh1`, `scene1-bond-oh2`
  - `scene1-label-nonpolar`, `scene1-label-polar1`, `scene1-label-polar2`
  - `scene1-charge-dplus-h1`, `scene1-charge-dminus-o1` 等
  - `scene1-molecule2`, `scene1-hbond-line`, `scene1-label-hbond`
- JS 隔离：全部代码包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染
- 事件绑定：使用 `document.getElementById` 获取元素，不依赖 `querySelectorAll` 全局扫描
- 响应式：SVG 使用 `viewBox="0 0 800 500"`，容器宽度100%自适应，高度按比例锁定
