[图示主题与整合说明]
- 本图示主题：三个容器的初始状态与反应条件对比
- 整合的步骤/概念：展示甲、乙、丙三个容器的初始物质的量（0.2 mol NO₂ / 0.1 mol N₂O₄）、容积条件（恒容/恒压）、反应方程式 2NO₂ ⇌ N₂O₄，帮助学生理解等效平衡问题的初始条件差异
- 教学价值：教师通过分步导航逐步引导学生关注不同条件——先认识容器外观，再关注初始物质差异，接着理解容积条件（恒容vs恒压），最后联系反应方程式理解气体分子数变化对平衡的影响。分步呈现避免信息过载，便于课堂逐层深入讲解

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于(250,455)，尺寸120×30px，点击返回上一步，步骤0时禁用
  - 「下一步 ▶」按钮：位于(430,455)，尺寸120×30px，点击进入下一步，步骤3时禁用
- 教师操作流程：
  1. 页面加载显示步骤0（三个空容器），教师介绍三个容器的基本设置
  2. 点击「下一步」进入步骤1，容器内出现初始物质，教师讲解各容器初始物质的量差异
  3. 点击「下一步」进入步骤2，出现恒容/恒压条件标注，教师讲解容积条件的不同
  4. 点击「下一步」进入步骤3，显示反应方程式和分子数变化提示，教师联系反应特点分析平衡移动
  5. 可随时点击「上一步」回退到任意步骤复习

[技术实现]
- JS 库选择：原生 SVG（简单几何图形绘制，无需额外库）+ MathJax（用于化学方程式中下标和可逆符号的渲染）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌──────────────────────────────────────────────────┐
  │                                                  │
  │         恒容              恒压         恒容      │ y≈110-120
  │                                                  │
  │   ┌──────┐    ┌──────┐    ┌──────┐              │ y≈140
  │   │      │    │ 活塞 │    │      │              │ y≈125-140
  │   │  甲  │    │      │    │  丙  │              │
  │   │      │    │  乙  │    │      │              │ y≈140-260
  │   └──────┘    └──────┘    └──────┘              │
  │                                                  │
  │    甲          乙          丙                    │ y≈285
  │                                                  │
  │                                                  │
  │         2NO₂(g) ⇌ N₂O₄(g)                       │ y≈370
  │         气体分子数减少                            │ y≈405
  │                                                  │
  │     [◀ 上一步]      [下一步 ▶]                   │ y≈455-485
  └──────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. **状态机设计**：用变量 `currentStep`（0~3）管理当前步骤，每个步骤对应一组元素的显示/隐藏/样式变化
  2. **元素显隐**：通过 CSS class 控制 opacity 和 visibility，配合 transition 实现淡入淡出动画
  3. **容器绘制**：
     - 甲/丙：SVG `<rect>` 元素
     - 乙：SVG `<path>` 绘制圆柱轮廓（两侧竖线+底部横线+顶部椭圆弧线），活塞用 `<rect>` 填充 #888888
  4. **高亮效果**：步骤1时通过修改 stroke 属性实现边框颜色变化（#000000 → #1565c0，线宽 2px → 3px）
  5. **化学式渲染**：NO₂ 和 N₂O₄ 的下标使用 SVG `<tspan baseline-shift="sub">` 实现，可逆符号 ⇌ 使用 Unicode 字符
  6. **按钮状态**：步骤0时「上一步」按钮 disabled（灰色），步骤3时「下一步」按钮 disabled
  7. **事件绑定**：按钮点击事件更新 `currentStep` 并调用 `renderStep(currentStep)` 函数重绘
- ID 命名规范：所有交互元素 ID 以 `scene1-` 为前缀，如 `scene1-container-jia`、`scene1-container-yi`、`scene1-container-bing`、`scene1-btn-prev`、`scene1-btn-next`、`scene1-substance-jia`、`scene1-condition-yi` 等
- IIFE 隔离：所有 JS 代码包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染
