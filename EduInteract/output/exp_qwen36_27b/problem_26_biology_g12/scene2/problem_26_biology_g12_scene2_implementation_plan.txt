[分步序列]
- 初始状态（步骤0）：显示亲本杂交式（小翅♀ AAXᵇXᵇ × 残翅♂ aaXᴮY）及向下箭头1。画布其余区域留白，等待教师触发。
- 步骤1：点击「下一步」→ 显示F1雌雄基因型及表现型（♀ AaXᴮXᵇ长翅、♂ AaXᵇY小翅），同时出现橙色标注框"F1有两种翅型"。亲本与箭头1保持显示。
- 步骤2：点击「下一步」→ 显示F1互交式（♀ AaXᴮXᵇ × ♂ AaXᵇY）及向下箭头2，指向下方棋盘格区域。上方元素保持。
- 步骤3：点击「下一步」→ 展开4×4棋盘格，显示♀/♂配子标题，16个格子依次填入基因型。网格线为#888888虚线，外框为#000000实线。
- 步骤4：点击「下一步」→ 棋盘格各基因型按表现型填充背景色（长翅蓝#1565c0、小翅红#c62828、残翅绿#2e7d32，透明度20%）。右侧出现表现型统计条（长翅6/16、小翅6/16、残翅4/16），底部居中显示橙色简化比例"长翅:小翅:残翅 = 3:3:2"。
（教师可随时点击「上一步」回退至任意步骤复习）

[技术实现]
- JS 库选择：原生 SVG + Vanilla JS。原因：本场景以静态几何图形、文本标注和分步显隐为主，SVG 原生支持精确坐标定位、文本渲染、路径箭头及透明度填充，无需引入重型库，加载快且易于维护。
- 画布尺寸：800 × 500 px（固定 viewBox="0 0 800 500"）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  y=60  : 小翅♀ AAXᵇXᵇ × 残翅♂ aaXᴮY
  y=75↓ :  ↓
  y=95  : [F1有两种翅型]
  y=135 : ♀ AaXᴮXᵇ(长翅)      ♂ AaXᵇY(小翅)
  y=165 : ♀ AaXᴮXᵇ × ♂ AaXᵇY
  y=180↓:  ↓
  y=215 :    AXᵇ   AY   aXᵇ   aY
  y=230 : ┌───┬───┬───┬───┐  长翅 6/16 [蓝]
  y=255 : │AXᴮ│   │   │   │  小翅 6/16 [红]
  y=305 : │AXᵇ│   │   │   │  残翅 4/16 [绿]
  y=355 : │aXᴮ│   │   │   │
  y=405 : │aXᵇ│   │   │   │
  y=430 : └───┴───┴───┴───┘
  y=415 :       长翅:小翅:残翅 = 3:3:2
  y=450 : [◀ 上一步]  1/4  [下一步 ▶]
  ```
- 关键实现要点：
  1. 状态机设计：维护 `currentStep` (0~4) 变量。`render(step)` 函数根据 step 值控制各 SVG 元素的 `display` 或 `opacity` 属性。步骤切换时添加 0.3s 淡入动画（CSS transition）。
  2. 棋盘格生成：使用 JS 循环生成 4×4 网格的 `<rect>` 和 `<text>` 元素，坐标按 50px 步长计算。基因型数据存为二维数组 `genotypes[4][4]`，表现型映射函数 `getPhenotype(geno)` 返回对应颜色类名。
  3. 事件绑定：按钮点击触发 `prevStep()` / `nextStep()`，边界检查（step<0 或 step>4 拦截），更新按钮禁用状态与步骤指示器文本。
  4. 文本渲染：上标基因符号（如 Xᴮ、Xᵇ）使用 Unicode 上标字符或 `<tspan baseline-shift="super">` 实现，确保跨浏览器一致。
- ID 命名规范：所有交互元素及关键图形 ID 均以 `scene2-` 为前缀（如 `scene2-parents`, `scene2-f1-box`, `scene2-grid`, `scene2-btn-next`）。JS 中严格使用 `document.getElementById('scene2-xxx')` 获取节点，禁止使用 `querySelectorAll` 配合全局 class，防止多场景合并时 DOM 污染。
- IIFE 隔离：全部 JS 逻辑包裹在 `(function() { 'use strict'; ... })();` 中，避免全局变量泄漏。
