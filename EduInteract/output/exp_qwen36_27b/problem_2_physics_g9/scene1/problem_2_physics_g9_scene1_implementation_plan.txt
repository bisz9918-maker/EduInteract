[图示主题与整合说明]
- 本图示主题：小车下滑、碰撞木块的全过程动态演示，含能量转化与运动状态分析
- 整合的步骤/概念：小车沿斜面下滑（重力势能→动能）、碰撞瞬间动能传递、木块在粗糙木板减速（动能→内能）、光滑木板假设（动能守恒）
- 教学价值：教师可通过分步按钮逐步展示物理过程，配合右侧实时变化的能量柱状图，直观讲解机械能转化、碰撞传递及摩擦力做功对动能的影响，帮助学生建立“过程-能量”对应关系。

[分步序列]
- 初始状态（步骤0）：小车静止于斜面顶端(240,205)，木块静止于(420,330)。能量图：小车PE=300(满)，KE=0，Total=300；木块全0。显示标签"小车"、"木块"、"斜面"、"木板"。
- 步骤1（小车下滑）：点击「下一步」→ 小车沿斜面平滑移动至底端(280,335)，速度箭头出现指向右下方。能量图动画：小车PE降至0，KE升至300，Total保持300。显示标注"重力势能→动能"。
- 步骤2（碰撞瞬间）：点击「下一步」→ 小车移动至(380,335)撞击木块，碰撞区域显示红色半透明高亮。能量图：小车KE降至150，木块KE升至150，木块Total=150。显示标注"动能传递"。
- 步骤3（粗糙木板）：点击「下一步」→ 木块向右滑动至(500,330)并停下，小车静止于碰撞点。摩擦力虚线箭头出现在木块下方指向左。能量图：木块KE逐渐降至0，Total降至0。显示标注"摩擦力做功"。
- 步骤4（光滑木板假设）：点击「下一步」→ 场景切换提示，木块从碰撞点匀速滑至(530,330)并保持运动状态（箭头持续）。能量图：木块KE保持150不变，Total保持150。显示标注"光滑→动能不变"。
（教师可随时点击「上一步」回退至任意步骤复习）

[技术实现]
- JS 库选择：原生 SVG + Vanilla JS。几何图形简单，状态切换明确，无需重型库，原生DOM操作性能最佳且易于维护。
- 画布尺寸：800 × 500 px（固定SVG viewBox）
- 布局草图：
  ```
  [图示区 800×440]
  ┌──────────────────────────────────────────────────────────────────────┐
  │ 斜面/小车/木块/标注 (x:20~560)   │  能量柱状图面板 (x:580~780)       │
  │                                │  ┌────────────────────────────┐    │
  │                                │  │ 能量柱状图                 │    │
  │                                │  │ PE(蓝) KE(红) 总(绿)       │    │
  │                                │  │ ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓ │    │
  │                                │  │                            │    │
  │                                │  └────────────────────────────┘    │
  └──────────────────────────────────────────────────────────────────────┘
  [控件栏 y:440~490]
  ┌──────────────────────────────────────────────────────────────────────┐
  │          ◀ 上一步        步骤说明文本        下一步 ▶                │
  └──────────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  - 状态机：`let currentStep = 0;` 控制渲染。`renderStep(step)` 函数根据step值更新小车/木块坐标、箭头显隐、能量柱高度。
  - 动画：使用 CSS `transition: all 0.6s ease-in-out` 实现柱状图高度平滑变化和小车/木块位移。碰撞高亮使用 `opacity` 过渡。
  - 坐标计算：小车沿斜面运动使用参数方程 `x = 240 + t*40, y = 205 + t*130` (t∈[0,1])。水平运动直接更新 `x`。
  - 事件绑定：按钮绑定 `click` 事件，更新 `currentStep` 并调用 `renderStep()`。禁用边界按钮（step=0时禁用上一步，step=4时禁用下一步）。
- ID 命名规范：所有交互元素及关键图形ID均以 `scene1-` 为前缀（如 `scene1-cart`, `scene1-block`, `scene1-bar-pe-cart`, `scene1-btn-next`, `scene1-step-desc`）。
- IIFE 隔离：全部JS逻辑包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染。
