[图示主题与整合说明]
- 本图示主题：剪去正方形后的凹字形图形及各边长度标注
- 整合的步骤/概念：展示题目原图（凹字形）→ 逐段标注各边长度 → 计算总周长

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  1. 「◀ 上一步」按钮：位置(280,458)，80×30px，点击后返回上一步骤（步骤0时禁用）
  2. 「下一步 ▶」按钮：位置(440,458)，80×30px，点击后进入下一步骤（步骤3时禁用）
  3. 步骤指示文字：位置(400,442)，显示"步骤 1/4"格式（步骤0显示"步骤 1/4"，步骤3显示"步骤 4/4"）
- 教师操作流程：
  1. 图示加载后显示步骤0（题目图形+已知条件），教师讲解图形结构
  2. 点击「下一步」进入步骤1，讲解上边和两侧竖边的长度推导
  3. 点击「下一步」进入步骤2，讲解凹进去三条边的长度
  4. 点击「下一步」进入步骤3，所有边高亮，显示周长计算式，得出结论24厘米
  5. 可随时点击「上一步」回退到任意步骤重新讲解

[技术实现]
- JS 库选择：原生 SVG + CSS + JavaScript（无需外部库，图形简单，交互为分步按钮）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌────────────────────────────────────────────────────────────┐
  │                                                            │
  │                    "6"(绿)                                  │
  │              ┌──────────────────────────────────┐          │
  │              │                                  │          │
  │   "4"(蓝)    │                                  │  "1"(绿) │
  │              │                                  │          │
  │              │      "2"(蓝)                     │  "2"(绿) │
  │              │                                  │          │
  │              │                                  │  "1"(绿) │
  │              └──────────────────────────────────┘          │
  │                    "6"(蓝)                                  │
  │                                                            │
  │              4+6+1+2+2+2+1+6=24 (红)                       │
  │                                                            │
  │              ◀上一步    步骤 X/4    下一步▶                │
  └────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：
     - 变量 currentStep（0~3），初始值0
     - 每个步骤对应一组可见元素集合
     - 步骤切换时更新元素可见性（CSS class切换）
  2. SVG结构：
     - <svg viewBox="0 0 800 500">
     - <path id="scene1-shape"> 凹字形轮廓
     - 多个 <text> 元素，初始opacity=0，通过添加.visible class显示
     - 控件栏用 <g> 包裹，包含按钮rect和text
  3. CSS过渡动画：
     - 标签淡入：.scene1-label { opacity:0; transition: opacity 0.3s ease; }
     - .scene1-label.visible { opacity:1; }
     - 边高亮：#scene1-shape { stroke:#000; stroke-width:2; transition: stroke 0.5s, stroke-width 0.5s; }
     - #scene1-shape.highlighted { stroke:#c62828; stroke-width:3; }
  4. 事件绑定：
     - 按钮点击事件绑定到 updateStep() 函数
     - updateStep() 根据 currentStep 值切换各元素可见性
     - 按钮禁用状态通过 disabled 属性和CSS样式控制
  5. 步骤可见性映射：
     - 步骤0：scene1-label-left, scene1-label-bottom, scene1-label-inner
     - 步骤1：步骤0 + scene1-label-top, scene1-label-tr, scene1-label-br
     - 步骤2：步骤1 + scene1-label-cut-top, scene1-label-cut-left, scene1-label-cut-bottom
     - 步骤3：步骤2 + scene1-perimeter（计算式）+ shape高亮
- ID 命名规范：所有交互元素ID以 `scene1-` 为前缀
  - scene1-shape（凹字形轮廓）
  - scene1-label-left（左边"4"）
  - scene1-label-bottom（下边"6"）
  - scene1-label-inner（凹内"2"）
  - scene1-label-top（上边"6"）
  - scene1-label-tr（右上竖边"1"）
  - scene1-label-br（右下竖边"1"）
  - scene1-label-cut-top（凹上横"2"）
  - scene1-label-cut-left（凹左竖"2"）
  - scene1-label-cut-bottom（凹下横"2"）
  - scene1-perimeter（周长计算式）
  - scene1-step-indicator（步骤指示）
  - scene1-prev-btn（上一步按钮）
  - scene1-next-btn（下一步按钮）
- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
- JS 中使用 getElementById 获取元素，不使用 querySelectorAll 配合全局 class
