[图示主题与整合说明]
- 本图示主题：圆等分扇形后剪拼成近似长方形的完整变换过程及周长计算
- 整合的步骤/概念：①圆的等分（16个扇形）→②扇形展开→③交替排列成近似长方形→④标注长方形的长与宽→⑤周长公式推导与数值计算
- 教学价值：教师通过分步导航，逐步展示圆转化为近似长方形的几何变换过程，帮助学生理解"圆的面积公式推导"背后的思想方法，同时引出周长计算问题。每一步都有明确的认知目标，便于教师控制讲解节奏。

[视觉元素清单]

1. 圆（步骤0-1显示）
   - 类型：SVG circle
   - 位置：cx=180, cy=230, r=110
   - 样式：stroke=#000000, stroke-width=2, fill=none（步骤0）；步骤1后显示扇形填充
   - 标签：圆心"O"在(180,230)处，font-size=16px，黑色

2. 半径标注（步骤0显示）
   - 类型：SVG line + text
   - 位置：线从(180,230)到(290,230)，虚线 #888888
   - 标签："r = 10cm" 在(245,218)，font-size=14px，黑色

3. 扇形（步骤1-3显示）
   - 类型：16个 SVG path（扇形弧）
   - 位置：从圆心(180,230)辐射，每个扇形夹角22.5°
   - 样式：交替填充 #e0e0e0（透明度0.3）和 #ffffff，stroke=#000000, stroke-width=1
   - 步骤2中扇形向外"弹出"，沿径向移动约30px
   - 步骤3中扇形移动到右侧拼合位置

4. 变换箭头（步骤2显示）
   - 类型：SVG line + polygon（箭头）
   - 位置：从(310,230)到(390,230)，箭头指向右
   - 样式：stroke=#888888, stroke-width=2, 虚线

5. 近似长方形（步骤3-5显示）
   - 类型：由16个扇形拼合而成的 SVG group
   - 位置：x范围420~700，y范围160~280
   - 上边：8个扇形尖端朝上，形成锯齿状上边缘
   - 下边：8个扇形尖端朝下，形成锯齿状下边缘
   - 左右两侧：扇形的弧边形成近似直线
   - 样式：保持交替着色，外框 stroke=#000000, stroke-width=2

6. 长方形标注（步骤4-5显示）
   - 上边长标注："πr = 31.4cm" 在(560,145)，font-size=14px，蓝色 #1565c0，加粗
   - 下边长标注："πr = 31.4cm" 在(560,300)，font-size=14px，蓝色 #1565c0，加粗
   - 左边宽标注："r = 10cm" 在(405,220)，font-size=14px，红色 #c62828，加粗
   - 右边宽标注："r = 10cm" 在(715,220)，font-size=14px，红色 #c62828，加粗
   - 标注线：蓝色/红色细线，与对应边平行，偏移5px

7. 周长公式（步骤5显示）
   - 类型：SVG text（多行）
   - 位置：(400,350) 开始，居中对齐
   - 内容：

     第2行："= 2 × (31.4 + 10)" 黑色，font-size=16px
     第3行："= 82.8 cm" 绿色 #2e7d32，font-size=18px，加粗
   - 外框：绿色虚线矩形框，突出显示

8. 控件栏（始终显示）

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |  步骤0-1:              步骤3-5:                  |
  |                                                  |
  |    .———.                                         |
  |   /  O  \        →      ┌──────────┐            |
  |  |  r=10 |              │ πr=31.4cm │            |
  |   \_____/              │  锯齿状   │            |
  |                        │  扇形拼合  │            |
  |                        │  锯齿状   │            |
  |                        └──────────┘            |
  |                        r=10    r=10             |
  |                                                  |
  |                        C = 2×(πr+r) = 82.8cm    |
  |                                                  |
  |              (步骤 X/5) [◀上一步] [▶下一步]      |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：当前步骤 currentStep (0~5)，每个步骤对应一组可见元素和动画
  2. 扇形生成：使用 SVG path 的弧命令 A 绘制每个扇形，角度间隔22.5°
     - 扇形路径：M 180,230 L x1,y1 A 110,110 0 0,1 x2,y2 Z
     - 其中(x1,y1)和(x2,y2)由极坐标转换：x = 180 + 110*cos(θ), y = 230 + 110*sin(θ)
  3. 步骤2扇形弹出动画：CSS transform translate 沿径向方向移动30px
  4. 步骤3扇形拼合动画：CSS transform translate 将每个扇形从左侧圆位置平移到右侧长方形位置
     - 上排扇形（偶数索引）：尖端朝上，弧边朝下
     - 下排扇形（奇数索引）：尖端朝下，弧边朝上
     - 每个扇形在长方形中的宽度 = 280/8 = 35px
  5. 动画曲线：弹出用 ease-out，拼合用 ease-in-out，标注淡入用 ease-in
  6. 事件绑定：按钮 click 事件触发 stepForward() / stepBackward()
  7. 禁用状态：步骤0时上一步按钮 disabled，步骤5时下一步按钮 disabled

- ID 命名规范：所有交互元素 ID 以 scene1- 为前缀
  - scene1-circle：圆元素
  - scene1-center-label：圆心O标签
  - scene1-radius-line：半径标注线
  - scene1-radius-label：r=10cm标签
  - scene1-sectors-group：扇形组
  - scene1-sector-{0..15}：各扇形元素
  - scene1-arrow：变换箭头
  - scene1-rectangle-group：长方形拼合组
  - scene1-top-label：上边长标注
  - scene1-bottom-label：下边长标注
  - scene1-left-label：左边宽标注
  - scene1-right-label：右边宽标注
  - scene1-formula-group：公式文本组
  - scene1-step-indicator：步骤指示器
  - scene1-btn-prev：上一步按钮
  - scene1-btn-next：下一步按钮

- IIFE 隔离：所有 JS 代码包裹在 (function() { 'use strict'; ... })(); 中
- CSS 动画使用 transition 和 transform 实现平滑过渡
- 扇形拼合坐标计算：
  - 长方形区域：x=420~700, y=160~280
  - 每个扇形在拼合后的宽度 = 280/8 = 35px
  - 上排扇形（索引0,2,4,6,8,10,12,14）：尖端在 y=160，弧边在 y=280
  - 下排扇形（索引1,3,5,7,9,11,13,15）：尖端在 y=280，弧边在 y=160
  - 每个扇形在长方形中的 x 起始位置 = 420 + (索引/2) * 35
