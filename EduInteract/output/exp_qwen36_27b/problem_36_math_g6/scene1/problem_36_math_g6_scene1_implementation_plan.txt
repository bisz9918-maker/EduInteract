- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+  y=0
  |                                                  |
  |    (A)    (B)                                    |  y=50
  |   /   \  /   \        面积推导框                 |
  |  |  A  ||  B  |       ┌──────────┐              |  y=100
  |  |     ||     |       │          │              |
  ```

- 关键实现要点：

  1. SVG 结构：
     - 使用 `<svg viewBox="0 0 800 500">` 作为容器
     - 三个圆用 `<circle>` 元素
     - 直线a用 `<line>` 元素
     - 重叠区域用 `<path>` 配合 clip-path 或手动计算交集区域
     - 直线a下方覆盖区域用 `<path>` 绘制裁剪后的半圆和整圆

  2. 重叠区域绘制方案：
     - 重叠区域①（圆A∩圆B）：使用 SVG clip-path，将灰色矩形裁剪为两圆交集
       具体：创建两个 clipPath（圆A和圆B），用 `<rect clip-path="url(#clipA)" clip-path="url(#clipB)">` 不可行
       改用：绘制灰色填充的圆A，再用圆B的 clip-path 裁剪 → 得到交集
       实际方案：用 `<circle>` 填充灰色，设置 clip-path 为另一个圆的裁剪区域
     - 重叠区域②（圆B∩圆C）：同理

  3. 直线a下方覆盖区域绘制方案：
     - 圆A下半部分：用 `<path>` 绘制半圆弧 + 直径线段
     - 圆B下半部分：同理
     - 圆C全部：直接填充整个圆
     - 使用 clip-path 将区域限制在 y ≥ 200 的半平面

  4. 状态机设计：
     ```javascript
     const stateManager = {
       currentStep: 0,
       totalSteps: 5,
       steps: [step0, step1, step2, step3, step4, step5],
       render(step) { /* 根据步骤渲染对应元素 */ }
     };
     ```
     每个步骤定义一个渲染函数，控制各元素的 visibility/opacity/display

  5. 动画曲线：
     - 元素出现：opacity 从 0 到 1，duration 300ms，ease-in
     - 文字出现：逐行淡入，每行延迟 100ms
     - 使用 CSS transition 或 requestAnimationFrame

  6. 事件绑定：
     - 按钮点击事件绑定到 stateManager.prev() / stateManager.next()
     - 步骤指示器实时更新

  7. ID 命名规范：
     - 所有交互元素 ID 以 `scene1-` 为前缀
     - 示例：`scene1-circle-a`, `scene1-circle-b`, `scene1-circle-c`,
       `scene1-line-a`, `scene1-overlap-1`, `scene1-overlap-2`,
       `scene1-below-highlight`, `scene1-text-area`,
       `scene1-btn-prev`, `scene1-btn-next`, `scene1-step-indicator`

  8. IIFE 隔离：
     ```javascript
     (function() {
       'use strict';
       // 所有 scene1 的 JS 代码
       // 使用 getElementById('scene1-xxx') 获取元素
       // 不使用 querySelectorAll 配合全局 class
     })();
     ```

  9. 重叠区域精确绘制（关键难点）：
     - 圆A(180,200) r=65 与 圆B(280,200) r=65 的交集：
       两圆圆心距 d=100，半径相等 r=65
       交集边界由两段圆弧组成
       交点计算：x = (180+280)/2 = 230（对称轴）
       y = 200 ± sqrt(65² - 50²) = 200 ± sqrt(4225-2500) = 200 ± sqrt(1725) ≈ 200 ± 41.5
       交点：(230, 158.5) 和 (230, 241.5)
       用 SVG path 绘制：M 230,158.5 A 65,65 0 0,1 230,241.5 A 65,65 0 0,1 230,158.5 Z
       （需要精确计算圆弧的 sweep-flag 和 large-arc-flag）

     - 圆B(280,200) r=65 与 圆C(370,290) r=65 的交集：
       圆心距 d = sqrt(90²+90²) = sqrt(16200) ≈ 127.28
       交点需要解方程组，用数值方法计算
       在 JS 中动态计算交点坐标，生成 path 数据

  10. 直线a下方区域精确绘制：
      - 圆A下半圆：M 115,200 A 65,65 0 0,0 245,200 Z（下半圆弧+直径）
      - 圆B下半圆：M 215,200 A 65,65 0 0,0 345,200 Z
      - 圆C全部：直接填充 circle(370,290) r=65
      - 用 clip-path 限制在 y ≥ 200 区域
