    **题目原文：**

    如图，小旗的顶点用数对表示为（5，7），现在将小旗绕点O，顺时针方向旋转90°，现在小旗的顶点可以用数对（   ）表示。

    A．（7，5）  B．（10，3）  C．（9，3）  D．（1，3）

    **题目分析：**

    本题考察平面直角坐标系中图形绕某点顺时针旋转90°的坐标变换。核心知识点包括：

    1. 在坐标系中准确读取点的坐标
    2. 理解"绕点O顺时针旋转90°"的几何含义
    3. 掌握旋转后坐标的计算方法

    **关键观察：**
    - 旋转中心O的坐标为(5, 3)，位于旗杆底部
    - 小旗顶点坐标为(5, 7)，位于旗杆顶部上方
    - 顶点(5,7)到旋转中心O(5,3)的距离为4个单位（竖直方向）

    **解题思路：**
    - 方法一（几何直观）：顶点(5,7)在O的正上方4个单位，顺时针旋转90°后，应转到O的正右方4个单位，即(5+4, 3) = (9, 3)
    - 方法二（公式法）：点(x,y)绕点(a,b)顺时针旋转90°后，新坐标为(a + (y-b), b - (x-a))

    **图示规划：**

    **关键公式提示：**
    点$(x, y)$绕点$(a, b)$顺时针旋转$90°$后，新坐标为：
    $$(a + (y - b),\ b - (x - a))$$

    $$新坐标 = (5 + (7-3),\ 3 - (5-5)) = (5+4,\ 3-0) = (9,\ 3)$$

    **SCENE_2 教学说明：**

    本图示通过动态演示帮助学生理解旋转的几何过程，教师可按以下步骤引导：

    1. **步骤0（回顾初始状态）**：展示旋转前的小旗，复习关键信息：旋转中心O(5,3)，顶点(5,7)，顶点在O正上方4个单位

    2. **步骤1（观察旋转过程）**：播放旋转动画，引导学生观察：
       - 顶点(5,7)沿什么轨迹移动？（以O为圆心、4为半径的圆弧）
       - 旋转方向是什么？（顺时针，即钟表指针方向）
       - 旋转了多少度？（90°）
       - 提问引导："顶点原来在O的正上方，顺时针转90°后，应该在O的什么方向？"引导学生回答"正右方"

    3. **步骤2（确认旋转结果）**：旋转完成后，引导学生读取新顶点坐标(9,3)。提问验证：
       - "新顶点在O的什么方向？"→ 正右方
       - "新顶点到O的距离是多少？"→ 4个单位（旋转不改变距离）
       - "坐标从(5,7)变成了(9,3)，x增加了4，y减少了4，这符合什么规律？"

    4. **步骤3（总结坐标变换规律）**：展示坐标变换公式，引导学生理解：
       - 顶点(5,7)在O(5,3)的正上方，相对位置为(0, 4)
       - 顺时针旋转90°后，相对位置变为(4, 0)
       - 新坐标 = O的坐标 + 新相对位置 = (5,3) + (4,0) = (9,3)

    5. **步骤4（确认答案）**：展示四个选项，确认正确答案为C.(9,3)

    **通用公式总结：**

    点$(x, y)$绕点$(a, b)$顺时针旋转$90°$的坐标变换公式：

    $$新坐标 = (a + (y - b),\ b - (x - a))$$

    推导过程：
    1. 计算相对位置：$(x - a,\ y - b)$
    2. 顺时针旋转$90°$：$(y - b,\ -(x - a)) = (y - b,\ a - x)$
    3. 加回中心坐标：$(a + y - b,\ b + a - x) = (a + (y - b),\ b - (x - a))$

    **本题代入验证：**
    $$x = 5,\ y = 7,\ a = 5,\ b = 3$$
    $$新坐标 = (5 + (7 - 3),\ 3 - (5 - 5)) = (5 + 4,\ 3 - 0) = (9,\ 3)$$

    **课堂讲解建议：**
    - 先让学生用几何直观方法解题（正上方→正右方），再引入公式法验证
    - 强调旋转的两个不变量：①旋转中心不动 ②点到旋转中心的距离不变
    - 可让学生动手在方格纸上画一画，加深理解
    - 拓展提问：如果逆时针旋转90°，顶点坐标会是多少？（答案：(1,3)，即选项D）
