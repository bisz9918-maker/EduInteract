[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于(250, 455)，100×35px，灰色背景(#9e9e9e)，白色文字，步骤0时禁用
  - 「下一步 ▶」按钮：位于(450, 455)，100×35px，蓝色背景(#1565c0)，白色文字，步骤5时禁用
- 教师操作流程：
  1. 图示加载后显示步骤0（俯视图L形+参考视图），教师可先让学生观察整体结构
  2. 点击「下一步」逐步分析每个位置，配合口头讲解推理过程
  3. 每步高亮当前分析格和参考视图中对应列，帮助学生建立三视图对应关系
  4. 到达步骤5展示汇总答案，教师可强调"5个正方体"的结论
  5. 可随时点击「上一步」回退到任意步骤进行复习或重新讲解

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库，轻量高效）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +---------------------------------------------------+  y=0
  |              从正面看                              |
  |         +---+---+---+                             |
  |         |   |   |   |                             |  主视图缩略图
  |         +---+---+---+                             |  (328,50)-(433,120)
  |         |   |   |   |                             |
  |         +---+---+---+                             |
  |              从上面看                              |
  |         +-------+-------+-------+                 |
  |         |   2   |   1   |   1   |                 |  俯视图L形
  |         +-------+-------+-------+                 |  (260,150)-(500,230)
  |         |   1   |                       从左边看  |
  |         +-------+                       +---+---+ |  左视图缩略图
  |                                       |   |   |   |  (540,198)-(610,268)
  |                                       +---+---+ |
  |                                               |
  |              2 + 1 + 1 + 1 = 5                |  汇总算式
  |              共 5 个正方体                     |  答案
  |                                               |
  |     [◀ 上一步]              [下一步 ▶]        |  控件栏 y=455
  +---------------------------------------------------+  y=500
  ```
- 关键实现要点：
  1. 状态机设计：currentStep变量（0~5），每个步骤对应一组视觉状态
  2. 状态切换函数：renderStep(step)根据步骤号更新所有元素的颜色、透明度、可见性
  3. 俯视图格子用SVG <rect>元素，通过修改fill/fill-opacity/stroke/stroke-width实现状态切换
  4. 参考视图格子同样用<rect>，通过修改stroke和opacity实现高亮
  5. 数字标注用<text>元素，通过opacity=0/1控制显示/隐藏，配合CSS transition实现淡入
  6. 汇总算式和答案用<text>元素，步骤5时opacity从0过渡到1
  7. 按钮用SVG <rect>+<text>组合，点击事件绑定step++/step--
  8. 按钮禁用状态：fill变浅灰色(#e0e0e0)，cursor变default，点击不响应
  9. CSS transition：所有状态变化使用0.3s ease过渡动画
- ID 命名规范：所有交互元素ID以 `scene2-` 为前缀
  - 俯视图格子：scene2-cell-1-1, scene2-cell-1-2, scene2-cell-1-3, scene2-cell-2-1
  - 层数数字：scene2-num-1-1, scene2-num-1-2, scene2-num-1-3, scene2-num-2-1
  - 主视图格子：scene2-front-left-top, scene2-front-left-bottom, scene2-front-mid, scene2-front-right
  - 左视图格子：scene2-left-left-top, scene2-left-left-bottom, scene2-left-right
  - 汇总算式：scene2-summary
  - 答案文字：scene2-answer
  - 按钮：scene2-btn-prev, scene2-btn-next
- IIFE 隔离：所有 JS 代码包裹在 (function() { 'use strict'; ... })() 中，避免全局污染
