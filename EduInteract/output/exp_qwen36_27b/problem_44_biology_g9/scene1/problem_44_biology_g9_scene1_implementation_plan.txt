[图示主题与整合说明]
- 本图示主题：不同器官结构中的血流方向与血液成分动态变化模型
- 整合的步骤/概念：选项A（毛细血管网）、选项B（小肠）、选项C（肾小球）、选项D（胰岛）四种情境的血流路径、血管类型判定及物质交换对比
- 教学价值：教师可通过分步切换四种生理情境，在统一的"甲→乙→丙"视觉骨架上对比讲解不同器官的血液成分变化规律，帮助学生理解"结构决定功能"的生物学核心概念，并逐一排除错误选项

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：(260,450)-(340,480)，点击回到上一步，步骤0时禁用（灰色不可点击）
  - 步骤指示文字：(400,465)，显示"步骤 X/4"
  - 「下一步 ▶」按钮：(460,450)-(540,480)，点击进入下一步，步骤4时禁用（灰色不可点击）
- 教师操作流程：
  1. 图示加载后显示初始状态（步骤0），基础骨架"甲→乙→丙"灰色轮廓
  2. 教师点击「下一步▶」进入步骤1，讲解选项A（毛细血管网），观察血管颜色变化和结论
  3. 继续点击「下一步▶」依次验证选项B、C、D
  4. 可随时点击「◀上一步」回退到任意步骤复习
  5. 在步骤4确认D为正确答案后，可回退对比各选项差异

[技术实现]
- JS 库选择：原生 SVG（简单几何图形+文字，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────┐
  │                    选项标题（居中）                         │ y=45
  │                                                            │
  │         甲              乙              丙                 │
  │    ────→  ┌──────────┐  →────         ┌──────────────┐    │
  │           │          │                │  选项A        │    │ y=60
  │           │   ？     │                │  若乙为肺泡... │    │ y=115
  │           │          │                │  ✗ 错误       │    │ y=155
  │    ────→  └──────────┘  →────         └──────────────┘    │ y=170
  │                                                            │
  │              ↓O₂      ↑营养物质                            │ y=340
  │                                                            │
  │                                                            │
  │         ┌────────┐  步骤 1/4  ┌────────┐                  │ y=450
  │         │◀上一步  │            │ 下一步▶│                  │ y=480
  │         └────────┘            └────────┘                  │
  └────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：定义5个状态（step0~step4），每个状态包含完整的视觉配置对象
  2. 状态切换函数：`goToStep(step)` 根据步骤索引更新所有动态元素
  3. 血管颜色切换：通过修改 SVG path 的 fill 属性实现（红色# c62828 20%透明 / 蓝色#1565c0 20%透明 / 灰色#888888）
  4. 文字更新：通过修改 SVG text 元素的 textContent 实现
  5. 成分箭头显示/隐藏：通过修改 SVG group 的 visibility 或 opacity 实现
  6. 按钮禁用状态：步骤0时「上一步」按钮 opacity=0.4 且 pointer-events=none，步骤4时「下一步」同理
  7. 动画过渡：使用 CSS transition 实现颜色和平滑切换（0.3s ease）
- ID 命名规范：所有交互元素 ID 以 `scene1-` 为前缀
  - `scene1-vessel-jia`：甲血管 path
  - `scene1-vessel-jia-label`：甲血管类型标签
  - `scene1-structure-yi`：乙结构框
  - `scene1-yi-name`：乙框内器官名
  - `scene1-yi-subname`：乙框内副名
  - `scene1-vessel-bing`：丙血管 path
  - `scene1-vessel-bing-label`：丙血管类型标签
  - `scene1-arrows-group`：成分变化箭头组
  - `scene1-conclusion-box`：结论提示框
  - `scene1-conclusion-title`：结论标题
  - `scene1-conclusion-text`：结论正文
  - `scene1-conclusion-badge`：正确/错误标识
  - `scene1-btn-prev`：上一步按钮
  - `scene1-btn-next`：下一步按钮
  - `scene1-step-indicator`：步骤指示文字
- IIFE 隔离：所有 JS 代码包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染
