[图示主题与整合说明]
- 本图示主题：血液流经器官的通用结构模型与血流方向认知
- 整合的步骤/概念：原图结构还原（a入血血管→b器官→c出血血管）、a/b/c生物学含义标注、血流方向指示、物质交换概念引入、血液成分变化示意
- 教学价值：教师可通过4步递进讲解，从直观图形到抽象概念，帮助学生理解"血液流经不同器官后成分会发生变化"这一核心生物学原理，为后续分析心脏、肺、小肠、组织细胞等具体情境做铺垫

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  1. 「◀ 上一步」按钮：位置(250,450)，尺寸100×36px，灰色背景，点击返回上一步
  2. 「步骤 X/3」指示器：位置(400,462)，尺寸60×20px，纯文本显示当前步骤
  3. 「下一步 ▶」按钮：位置(500,450)，尺寸100×36px，蓝色背景 #1565c0，点击进入下一步
- 教师操作流程：
  1. 图示加载后显示步骤0（原图轮廓），教师可先让学生观察图形结构
  2. 点击「下一步」进入步骤1，讲解a/b/c的生物学含义
  3. 点击「下一步」进入步骤2，讲解物质交换概念
  4. 点击「下一步」进入步骤3，引出核心问题，过渡到具体器官分析
  5. 随时点击「上一步」回退复习
  6. 步骤0时「上一步」按钮禁用，步骤3时「下一步」按钮禁用

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库，性能好，易于动画控制）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +---------------------------------------------------+
  |                                                    |
  |        a                    b                    c |
  |       ──→          ┌───────┐          ──→        |
  |                    │       │                       |
  |                    │   b   │                       |
  |                    │       │                       |
  |                    └───────┘                       |
  |                                                    |
  |     入血血管      器官/组织       出血血管          |
  |                                                    |
  |              血液流经不同器官后，成分如何变化？      |
  |                                                    |
  |           [◀ 上一步]  步骤 0/3  [下一步 ▶]         |
  +---------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 `currentStep` (0~3) 管理当前步骤，每个步骤对应一个渲染函数 `renderStep(n)`
  2. 步骤切换逻辑：
     - 点击「下一步」：currentStep++，若>3则currentStep=3，调用renderStep(currentStep)
     - 点击「上一步」：currentStep--，若<0则currentStep=0，调用renderStep(currentStep)
  3. 动画实现：使用 CSS transition 和 SVG animate 元素
     - 淡入动画：CSS opacity 0→1，transition 0.3s
     - 填充展开：SVG rect width 从0到目标值，animate 0.5s
     - 虚线箭头展开：SVG line x1/x2 动画，animate 0.4s
  4. 按钮状态管理：
     - 步骤0时「上一步」按钮 disabled（灰色不可点击）
     - 步骤3时「下一步」按钮 disabled
  5. 坐标计算：所有坐标基于800×500画布绝对定位，SVG viewBox="0 0 800 500"
  6. 事件绑定：按钮使用 onclick 绑定到全局命名空间函数

- ID 命名规范：所有交互元素 ID 以 `scene1-` 为前缀
  - SVG容器：`scene1-svg`
  - 上一步按钮：`scene1-prev-btn`
  - 下一步按钮：`scene1-next-btn`
  - 步骤指示器：`scene1-step-indicator`
  - 血管a组：`scene1-vessel-a`
  - 圆形b组：`scene1-organ-b`
  - 血管c组：`scene1-vessel-c`
  - 标签组：`scene1-label-a`, `scene1-label-b`, `scene1-label-c`
  - 步骤1标签：`scene1-label-inflow`, `scene1-label-organ`, `scene1-label-outflow`
  - 步骤2元素：`scene1-exchange-arrows`, `scene1-label-exchange`
  - 步骤3元素：`scene1-fill-a`, `scene1-fill-c`, `scene1-question-text`

- IIFE 隔离：所有 JS 代码包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染
