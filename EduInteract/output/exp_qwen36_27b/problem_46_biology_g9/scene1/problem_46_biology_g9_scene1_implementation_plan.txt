- 本图示主题：DNA分子双螺旋结构平面展开图，标注关键化学键和碱基配对关系

[技术实现]
- JS 库选择：原生 SVG（本场景为静态几何图形+简单动画，无需复杂库，SVG原生支持路径、渐变、动画）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────┐
  │              DNA分子结构示意图                              │ y=22
  ├────────────────────────────────────────────────────────────┤
  │  5' ─────────────────────────────────────────────────── 3' │ y=100
  │  │ C │ T │ G │ C │  ················  │ C │ T │ T │ A │  │ y=115~145
  │  │:  │:  │:  │:  │                    │:  │:  │:  │:  │  │ y=145~255
  │  │ G │ A │ C │ G │  ················  │ G │ A │ A │ T │  │ y=255~285
  │  3' ─────────────────────────────────────────────────── 5' │ y=300
  │         ①↑              ②→                                │
  │                                                          │
  │  ┌──────────────────────────────────────────────────┐    │ y=345
  │  │  已知C=30%，G=C=30%  (步骤4显示)                  │    │
  │  │  C+G=60%，A+T=40%，(C+G)/(A+T)=3:2               │    │ y=390
  │  └──────────────────────────────────────────────────┘    │
  │                     步骤 0/4                              │ y=435
  │               [◀ 上一步]  [▶ 下一步]                      │ y=455
  └────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. **状态机设计**：用变量 `currentStep` (0~4) 管理当前步骤，每个步骤对应一个渲染函数 `renderStep(n)`
  2. **SVG元素管理**：所有SVG元素用 `document.createElementNS('http://www.w3.org/2000/svg', 'tag')` 创建，按步骤分组（g标签），通过显示/隐藏控制可见性
  3. **动画实现**：步骤3的氢键断裂动画使用 CSS transition 或 requestAnimationFrame
     - 氢键缩短：修改 line 的 y1/y2 属性，从完整长度渐变为0
     - 双链分离：修改上方链g的 transform="translate(0,-30)"，下方链 transform="translate(0,30)"
     - 使用 transition: all 0.8s ease-in-out 实现平滑动画
  4. **坐标计算**：碱基位置用数组存储，氢键位置由碱基位置自动计算
  5. **事件绑定**：按钮点击事件绑定到 `handlePrev()` 和 `handleNext()` 函数，更新 `currentStep` 后调用 `renderStep(currentStep)`
  6. **ID 命名规范**：所有交互元素 ID 以 `scene1-` 为前缀，如 `scene1-btn-next`、`scene1-btn-prev`、`scene1-step-indicator`、`scene1-hbond-1`~`scene1-hbond-8`、`scene1-base-top-1`~`scene1-base-top-8`、`scene1-base-bottom-1`~`scene1-base-bottom-8`
  7. **IIFE 隔离**：所有 JS 代码包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染
  8. **按钮禁用逻辑**：步骤0时「上一步」disabled，步骤4时「下一步」disabled，通过设置 opacity=0.5 和 pointer-events=none 实现
