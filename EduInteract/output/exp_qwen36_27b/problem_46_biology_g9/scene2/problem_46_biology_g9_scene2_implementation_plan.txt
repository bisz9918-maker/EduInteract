[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀上一步」按钮：位置(250,450)，尺寸90×30，点击回到上一步骤，步骤0时禁用
  - 「步骤指示」文字：位置(400,465)，显示"步骤 X/4"
  - 「下一步▶」按钮：位置(460,450)，尺寸90×30，点击进入下一步骤，步骤4时禁用
- 教师操作流程：
  1. 图示加载后显示亲代DNA（步骤0），教师讲解15N标记的亲代DNA结构
  2. 点击「下一步」展示复制1次结果，讲解半保留复制机制（每条母链作为模板）
  3. 点击「下一步」展示复制2次结果，引导学生观察DNA数量和组成变化
  4. 点击「下一步」展示复制3次结果，让学生数含15N和14N的DNA数量
  5. 点击「下一步」展示统计结论，验证选项D错误（含14N的DNA占100%而非3/4）
  6. 可随时点击「上一步」回退复习任意步骤

[技术实现]
- JS库选择：原生SVG（简单几何图形绘制，无需额外库，性能最优）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │              DNA半保留复制过程                               │ y=25
  ├─────────────────────────────────────────────────────────────┤
  │ 亲代  [====15N====]  15N                                     │ y=60-96
  │         [====15N====]  15N                                   │
  │                    ↘                                        │
  │ 复制1次  [15N/14N]  [14N/15N]    2个DNA                     │ y=125-161
  │                    ↘                                        │
  │ 复制2次  [15/14][14/15][14/14][14/14]                       │ y=200-236
  │ 4个DNA                  ↘                                   │
  │ 复制3次  [15/14][14/15][14/14]...[14/14]  (8个)             │ y=275-311
  │ 8个DNA                                                         │
  │                                                              │
  │ 选项D验证结论...              ┌─────统计─────┐               │
  │                               │ 复制X次      │               │ y=350-430
  │                               │ 含14N: X/X   │               │
  │                               └──────────────┘               │
  ├─────────────────────────────────────────────────────────────┤
  │         [◀上一步]    步骤 X/4    [下一步▶]                   │ y=450-480
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. **状态机设计**：用变量`currentStep`（0-4）跟踪当前步骤，每个步骤对应一组可见元素
  2. **DNA分子渲染**：每个DNA分子由2个rect（上链+下链）组成，15N链用#1565c0实色，14N链用#e3f2fd填充+#1565c0边框
  3. **逐步显示逻辑**：
     - 步骤0：仅显示亲代DNA
     - 步骤1：显示亲代+复制1次的2个DNA+箭头
     - 步骤2：显示亲代+复制1次+复制2次的4个DNA+箭头
     - 步骤3：显示全部8个DNA+箭头
     - 步骤4：显示统计结论+选项D验证
  4. **动画效果**：新出现的DNA分子使用CSS transition（opacity 0→1，duration 0.5s）淡入效果
  5. **统计面板更新**：根据currentStep动态更新文本内容
  6. **按钮状态管理**：步骤0时「上一步」禁用（opacity=0.5, pointer-events=none），步骤4时「下一步」禁用
  7. **复制箭头**：使用SVG path绘制带箭头的曲线，marker-end定义箭头形状
- ID命名规范：所有交互元素ID以`scene2-`为前缀
  - `scene2-btn-prev`、`scene2-btn-next`、`scene2-step-indicator`
  - `scene2-parent-dna`、`scene2-gen1-group`、`scene2-gen2-group`、`scene2-gen3-group`
  - `scene2-stats-panel`、`scene2-stats-content`、`scene2-stats-conclusion`
  - `scene2-option-d-verify`
- IIFE隔离：所有JS代码包裹在`(function() { 'use strict'; ... })();`中，避免全局污染
- SVG namespace：`http://www.w3.org/2000/svg`
- 事件绑定：使用`addEventListener`绑定按钮点击事件，不内联onclick
