    **题目原文：**

    如图为尿液形成流程图，其中甲、乙表示结构，a、b表示液体。下列叙述不正确的是（）

    A.若用麻药麻痹正常人的乙处，则b中会有蛋白质
    B.a、b表示的液体分别为原尿和尿液
    C.肾小球、甲和乙共同构成肾单位
    D.血液流经肾脏后，动脉血变为静脉血，尿素减少

    **题目分析：**

    本题考查尿液形成的过程及肾单位的结构功能，属于初中生物（九年级）泌尿系统核心知识点。

    题目给出的流程图展示了尿液形成的简化过程：血液流进肾小球中 → 甲 → 形成a → 乙 → 形成b。学生需要根据所学知识推断甲、乙分别代表什么结构，a、b分别代表什么液体，然后判断四个选项的正误。

    **关键知识点：**
    1. 肾单位由肾小球、肾小囊、肾小管三部分组成
    2. 尿液形成包括两个过程：肾小球的滤过作用（形成原尿）和肾小管的重吸收作用（形成尿液）
    3. 甲 = 肾小囊，乙 = 肾小管，a = 原尿，b = 尿液
    4. 肾小球滤过作用会阻挡大分子蛋白质和血细胞
    5. 血液流经肾脏后，氧气被消耗（动脉血→静脉血），尿素随尿液排出（尿素减少）

    **答案：A**（麻药麻痹肾小管会影响重吸收，但蛋白质在肾小球阶段就不会被滤过到原尿中，所以b中不会有蛋白质）

    **整体讲解思路：**
    1. 先引导学生观察题目流程图，推断甲、乙、a、b的含义
    2. 通过Scene 1的交互式流程图，逐步揭示各结构/液体的名称
    3. 通过Scene 2的肾单位结构详图，深入讲解滤过作用和重吸收作用
    4. 结合两个图示逐一分析四个选项，重点讲解A选项为什么错误

    **图示规划：**
    - Scene 1：交互式尿液形成流程图（与题目原图对应，逐步标注）
    - Scene 2：肾单位结构与功能详图（展示滤过和重吸收过程）

    **Scene 2 教学说明：**

    本图示展示肾单位的详细结构和尿液形成的微观机制，是讲解本题核心知识点的重点图示。

    **讲解要点：**

    1. **步骤0：肾单位结构**
       - 讲解肾单位由三部分组成：肾小球（毛细血管球）、肾小囊（双层杯状结构）、肾小管（弯曲管状）
       - 强调：肾单位是肾脏的基本功能单位

    2. **步骤1：滤过作用**
       - 讲解肾小球的滤过作用：血液流经肾小球时，除血细胞和大分子蛋白质外，其他小分子物质（水、无机盐、葡萄糖、尿素）滤过到肾小囊腔形成原尿
       - 关键点：蛋白质和血细胞**不能**通过肾小球滤过膜

    3. **步骤2：重吸收作用**
       - 讲解肾小管的重吸收作用：原尿流经肾小管时，全部葡萄糖、大部分水、部分无机盐被重吸收回血液
       - 剩余物质（水、无机盐、尿素）形成尿液
       - 关键点：葡萄糖被**全部**重吸收，所以正常尿液中不含葡萄糖

    4. **步骤3：血液成分变化**
       - 血液流经肾脏后：氧气被消耗（动脉血→静脉血），尿素随尿液排出（尿素减少）
       - 入球小动脉：动脉血，含尿素
       - 出球小动脉及肾小管周围毛细血管：静脉血，尿素减少

    5. **步骤4：选项分析**
       - **A选项（错误）**：麻药麻痹肾小管会影响重吸收功能，但蛋白质在肾小球阶段就不会被滤过到原尿中，所以即使肾小管功能异常，b（尿液）中也不会有蛋白质。**这就是本题答案。**
       - **B选项（正确）**：a = 原尿，b = 尿液，符合尿液形成过程
       - **C选项（正确）**：肾单位 = 肾小球 + 肾小囊（甲）+ 肾小管（乙）
       - **D选项（正确）**：血液流经肾脏后，氧气消耗（动脉血→静脉血），尿素排出（尿素减少）

    **课堂讲解建议：**
    - 重点讲解A选项为什么错误，这是本题的难点
    - 可以提问学生："如果肾小球发炎，滤过膜通透性增大，尿液中会出现什么？"（答案：蛋白质和血细胞，即蛋白尿和血尿）
    - 对比滤过作用和重吸收作用的区别，帮助学生建立清晰的概念
    </TEXT_3>

    <TEXT_4>
    **完整解答总结：**

    **答案：A**

    **解析：**

    1. 根据尿液形成过程推断：
       - 甲 = 肾小囊（收集肾小球滤过的液体）
       - 乙 = 肾小管（对原尿进行重吸收）
       - a = 原尿（肾小球滤过形成）
       - b = 尿液（肾小管重吸收后形成）

    2. 逐项分析：
       - **A. 错误**：肾小球滤过作用会阻挡大分子蛋白质，所以原尿中不含蛋白质。即使肾小管被麻药麻痹影响重吸收功能，尿液中也不会有蛋白质（因为原尿中本来就没有）。**若肾小球发炎导致滤过膜通透性增大，尿液中才可能出现蛋白质。**
       - **B. 正确**：a为原尿，b为尿液
       - **C. 正确**：肾单位由肾小球、肾小囊（甲）、肾小管（乙）三部分组成
       - **D. 正确**：血液流经肾脏时，氧气被组织细胞消耗（动脉血→静脉血），尿素随尿液排出体外（尿素减少）

    **教学提示：**
    - 本题核心考点是区分肾小球滤过作用和肾小管重吸收作用的功能差异
    - 学生易错点：混淆"肾小管病变"和"肾小球病变"对尿液成分的影响
    - 拓展：肾小球病变→蛋白尿/血尿；肾小管病变→糖尿（重吸收功能障碍）
