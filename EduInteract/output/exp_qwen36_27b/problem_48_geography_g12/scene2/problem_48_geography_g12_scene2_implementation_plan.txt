[技术实现]
- JS 库选择：原生 SVG（适合几何图形绘制和动画控制）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────────┐
  │                                                             │
  │           地球球体区              计算说明区                │
  │         (280,240)中心              (520,100)-(760,400)      │
  │                                                             │
  │    北极(280,85)                                              │
  │       *                                                      │
  │      / \                                                     │
  │     /   \                                                    │
  │    | M |  ← M点(340,140)                                     │
  │    |   |                                                     │
  │    | O |  ← 地心(280,240)                                    │
  │    |   |                                                     │
  │    | M'|  ← M'点(220,340)                                    │
  │     \   /                                                    │
  │      \ /                                                     │
  │       *                                                      │
  │    南极(280,405)                                              │
  │                                                             │
  │  ┌─────────────────────────────────────────────────────┐    │
  │  │  ◀ 上一步    步骤 X/5    下一步 ▶                   │    │
  │  └─────────────────────────────────────────────────────┘    │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  * 状态机设计：6个状态（步骤0-5），每个状态对应一组可见元素
  * 坐标计算：地球球体用椭圆模拟3D透视，经纬线用椭圆弧表示
  * 动画曲线：元素出现使用淡入效果（opacity 0→1，时长0.5s）
  * 事件绑定：按钮点击事件触发状态切换，更新SVG元素可见性
  * 地球绘制：使用SVG ellipse元素，经纬线用path绘制椭圆弧
  * 对称线：使用SVG line元素，stroke-dasharray实现虚线效果
  * 高亮效果：M'点使用SVG animate元素实现脉冲动画
- ID 命名规范：所有交互元素ID以 `scene2-` 为前缀
  * 地球球体：`scene2-earth`
  * M点：`scene2-point-m`
  * M'点：`scene2-point-m-prime`
  * 地心：`scene2-center`
  * 对称线：`scene2-symmetry-line`
  * 上一步按钮：`scene2-prev-btn`
  * 下一步按钮：`scene2-next-btn`
  * 步骤指示器：`scene2-step-indicator`
  * 说明区文本：`scene2-explanation`
- IIFE 隔离：所有JS代码包裹在 `(function() { ... })()` 中，避免全局污染
