[图示主题与整合说明]
- 本图示主题：南极投影图条件解读与太阳直射点坐标推导

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」：位于底部左侧(100,450)，点击回退至上一状态，步骤0时禁用
  - 「步骤 X / 6」：位于底部居中(350,455)，显示当前步骤编号
  - 「下一步 ▶」：位于底部右侧(600,450)，点击推进至下一状态，步骤6时禁用
- 教师操作流程：
  1. 初始展示基础图，提问学生观察要素
  2. 点击「下一步」逐步揭示条件，配合口头讲解
  3. 每步停留，引导学生思考推导逻辑
  4. 可随时点击「上一步」回顾前序条件
  5. 最终步展示结论，核对答案

[技术实现]
- JS 库选择：原生 SVG + Vanilla JS。无需重型库，SVG 适合几何图形与路径动画，JS 控制状态切换与 DOM 更新，轻量高效。
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  +--------------------------------------------------+
  |  [极地投影图]           |  [信息面板]            |
  |  (中心320,250)         |  (520,60)-(770,410)    |
  |  同心圆+经线+阴影+MA   |  动态文本说明           |
  |                       |                         |
  |                       |  [步骤6: 直射点标记]     |
  +--------------------------------------------------+
  |  [◀ 上一步]    [步骤 X/6]    [下一步 ▶]          |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  - 状态机：数组 `steps[0..6]` 存储每步的视觉配置（高亮元素ID、新增标签文本/坐标、面板内容）
  - 渲染：SVG 元素预生成，通过 CSS class 控制显隐/高亮（如 `.highlight-blue`, `.hidden`）
  - 动画：步骤切换时，新增元素使用 CSS `transition` 或 `@keyframes` 淡入/缩放，时长 0.3s
  - 事件绑定：按钮 `click` 触发 `updateStep(direction)`，更新 `currentStep` 索引并重绘
  - 坐标计算：极坐标转直角坐标函数 `polarToCartesian(cx, cy, r, angleDeg)`，角度0°为右，顺时针增加
  - ID 命名规范：所有交互/图形元素 ID 以 `scene1-` 开头，如 `scene1-point-o`, `scene1-circle-70s`, `scene1-shaded`, `scene1-btn-next`
  - IIFE 隔离：`(function() { 'use strict'; ... })();` 包裹全部逻辑，避免全局污染
  - 响应式：SVG `viewBox="0 0 800 500"`，容器 `width: 100%; height: auto;` 保持比例
