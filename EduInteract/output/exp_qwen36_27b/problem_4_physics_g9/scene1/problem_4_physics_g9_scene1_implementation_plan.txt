- 步骤2（对比灯泡路径）：

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  * 「◀ 上一步」按钮：位于(260,460)，尺寸100×25px，步骤0时禁用（灰色），其他步骤可点击，点击后回退到上一步
  * 「下一步 ▶」按钮：位于(440,460)，尺寸100×25px，步骤3时禁用（灰色），其他步骤可点击，点击后进入下一步
  * 提示文字：位于(400,445)，居中显示，随步骤变化更新内容
- 教师操作流程：
  1. 图示加载后显示步骤0（完整电路，开关断开），教师可先让学生观察电路结构
  2. 点击「下一步」进入步骤1，开关闭合，红色短路路径高亮，教师讲解"电流可以不经过灯泡直接回到负极"
  3. 点击「下一步」进入步骤2，蓝色灯泡路径叠加显示，教师对比讲解"灯泡被短路，电流主要走短路路径"
  4. 点击「下一步」进入步骤3，结论文字框出现，教师总结"S闭合后发生短路，A正确B错误"
  5. 随时可点击「上一步」回退复习任意步骤

[技术实现]
- JS 库选择：原生 SVG（电路图为静态几何图形+简单动画，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────┐
  │                    电池组 (+)                               │
  │  ┌──────────────────────┐                                  │
  │  │  ─ ─ ─ ─ ─ ─ ─ ─ ─  │  ──────── 导线 ────────→ D ●    │
  │  └──────────────────────┘                                  │
  │  (-)                                                       │
  │   │                                                        │
  │   │ 导线                                                   │
  │   │                                                       │
  │   ▼                                                       │
  │  ┌──────┐          ● C ─── L₂ ─── ● D                     │
  │  │  S   │                                    │ 导线 b      │
  │  └──┬───┘                                    │            │
  │     │ 导线 M                                  ▼            │
  │     └──────────────────────→ ● B ─── L₁ ─── ●             │
  │                            ▲            │                  │
  │                            │ 导线 a      │                  │
  │                            ● A ──────────┘                  │
  │                                                             │
  │                    [结论框]                                  │
  │                                                             │
  │           ◀ 上一步          下一步 ▶                         │
  └────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. **状态机设计**：用变量 `currentStep` (0-3) 管理当前步骤，每个步骤对应一组视觉状态
  2. **开关动画**：步骤0→1时，闸刀line的终点坐标从(160,320)过渡到(110,360)，使用CSS transition或JS动画
  3. **路径高亮**：用与原始导线同路径的<path>元素叠加，通过显示/隐藏控制高亮效果
  4. **箭头实现**：使用SVG `<marker>` 定义红色和蓝色箭头，在<path>上设置 `marker-mid` 和 `marker-end`
  5. **灯泡填充**：通过修改circle的fill属性实现半透明蓝色/灰色填充
  6. **结论框动画**：步骤3时从右侧滑入（CSS transform: translateX）
  7. **按钮状态**：步骤0时「上一步」disabled，步骤3时「下一步」disabled
- ID 命名规范：所有交互元素ID以 `scene1-` 为前缀，如：
  * `scene1-switch-blade`（闸刀）
  * `scene1-wire-short`（短路路径高亮线）
  * `scene1-wire-bulb`（灯泡路径高亮线）
  * `scene1-bulb-l1`（灯泡L₁外壳）
  * `scene1-bulb-l2`（灯泡L₂外壳）
  * `scene1-conclusion-box`（结论文字框）
  * `scene1-btn-prev`（上一步按钮）
  * `scene1-btn-next`（下一步按钮）
  * `scene1-hint-text`（提示文字）
  * `scene1-arrow-short-*`（短路路径箭头）
  * `scene1-arrow-bulb-*`（灯泡路径箭头）
- IIFE 隔离：所有JS代码包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染
- 事件绑定：按钮点击事件通过 `document.getElementById('scene1-btn-next').addEventListener('click', ...)` 绑定
