    图1-9中，北半球是东半球，南半球是西半球，回答下列问题：(10分）

    小题1：(1) 写出A,B的经度数：A ______ ，B ______ 。

    小题2：(2) 根据图中阴影（黑夜）位置，判断这一天的日期为 ______ 。

    小题3：(3) 在北半球上，画出恰当的阴影（黑夜）部分。

    小题4：（4）当甲地是22日16点时，乙地是 ______ 月 ______ 日 ______ 时，C点昼长 ______ 小时。

    小题5：(5) 此时，太阳直射的纬度是 ______ ，该日北京（39°N, 116°E）的正午太阳高度是 ______ 。

    小题6：(6) 此时，地球距太阳远近情况是 ______ 。

    本题是一道典型的地球光照图综合题，考查经度计算、日期判断、时间计算、太阳直射点、正午太阳高度等多个知识点。题目给出两个半球图：右图为北半球且为东半球（20°W向东至160°E），左图为南半球且为西半球（160°E向东至20°W），两图在20°W经线处相接。

    **关键信息提取：**
    - 东半球范围：20°W → 160°E（跨度180°）
    - 西半球范围：160°E → 20°W（跨度180°）
    - 图中每个半球有5条经线（含边界），经度间隔 = 180°/4 = 45°
    - 南半球图中阴影覆盖大部分区域，南极圈内为极昼，北极圈内为极夜 → 太阳直射南回归线（23°26'S），日期为12月22日（冬至）

    **教学说明——地球光照图综合分析**

    本图示整合了本题全部6个小题的解答，教师可通过分步导航逐步讲解。以下是各步骤的教学要点：

    **步骤0：展示原图，引导学生观察**

    教师应引导学生注意以下关键信息：
    1. 题目条件"北半球是东半球，南半球是西半球"——这意味着右图显示的是东半球（20°W→160°E），左图显示的是西半球（160°E→20°W）
    2. 两图在20°W经线处相接
    3. 南半球图中有阴影（黑夜），北半球图中无阴影（需要学生补充）
    4. 图中标注了N、S、甲、乙、A、B、C等关键点

    **步骤1：经度计算（小题1）**

    讲解要点：
    1. 东半球从20°W向东到160°E，跨度180°
    2. 图中每个半球有5条经线（含边界），即4个间隔
    3. 经度间隔 = 180° ÷ 4 = 45°
    4. 右图（东半球）经线从左到右：20°W → 25°E → 70°E → 115°E → 160°E
    5. 因此 **A = 160°E**
    6. 左图（西半球）经线从左到右：160°E → 115°W → 70°W → 25°W → 20°W
    7. B位于从左数第3条经线上，因此 **B = 70°W**

    **步骤2：日期判断与北半球阴影绘制（小题2、小题3）**

    讲解要点：
    1. 观察南半球阴影：南极圈内为极昼（无阴影），说明太阳直射南半球
    2. 北极圈内应为极夜（全黑夜），对应日期为 **12月22日（冬至）**
    3. 在北半球图上绘制阴影：北极圈（66°34'N）以北区域全部填充为黑夜
    4. 昼夜分界线（晨昏线）经过极点，与经线重合

    引导学生思考：为什么冬至日北极圈内是极夜？因为太阳直射南回归线，北半球昼短夜长，北极圈内全天不见太阳。

    **步骤3：时间计算（小题4）**

    讲解要点：
    1. 甲地位于160°E经线上，乙地位于25°E经线上
    2. 经度差 = 160°E - 25°E = 135°
    3. 时间差 = 135° ÷ 15°/h = 9小时
    4. 乙在甲的西侧，时间比甲晚9小时
    5. 甲为22日16时 → 乙 = 22日16时 - 9时 = **22日7时**
    6. C点位于赤道上，赤道全年昼夜平分，**昼长 = 12小时**

    提醒学生：计算时间时注意"东加西减"原则——东边时间早，西边时间晚。

    **步骤4：太阳直射点、正午太阳高度、地球位置（小题5、小题6）**

    讲解要点：
    1. 冬至日太阳直射 **南回归线（23°26'S）**
    2. 北京正午太阳高度计算：
       - 公式：H = 90° - |当地纬度 - 直射点纬度|
       - H = 90° - |39°N - (-23°26')| = 90° - 62°26' = **27°34'**
    3. 地球公转：1月初为近日点，7月初为远日点
    4. 12月22日接近1月初，因此地球 **距太阳较近**

    **课堂讲解建议：**

    - 在步骤1中，可让学生先自行推算经度间隔，再验证答案
    - 在步骤2中，可让学生先在纸上尝试绘制北半球阴影，再点击按钮对照
    - 在步骤3中，强调经度差与时间差的换算关系（15°=1小时）
    - 在步骤4中，可补充正午太阳高度公式的推导过程，帮助学生理解
    - 全程注意引导学生从图中提取信息，培养读图能力
