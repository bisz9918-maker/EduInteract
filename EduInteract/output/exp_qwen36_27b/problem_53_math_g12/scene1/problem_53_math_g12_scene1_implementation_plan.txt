[图示主题与整合说明]
- 本图示主题：四棱锥 P-ABCD 的立体结构及辅助线添加过程，展示由线面平行推导线线平行的空间推理
- 整合的步骤/概念：① 四棱锥基本结构展示 ② 已知条件标注（M、N 位置，CM:MA=1:4） ③ 辅助线 ME ∥ AD 的添加 ④ 辅助线 NE 的添加及 NE ∥ PD 的推导 ⑤ 平面 MNE ∥ 平面 PAD 的结论展示
- 教学价值：教师通过分步导航，逐步引导学生从已知条件出发，通过添加辅助线、推导平行关系，最终得出 NC:NP = 1:4 的结论。每一步都有明确的视觉变化，帮助学生理解空间几何中的线面平行推导线线平行的推理过程。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位置 (250,455)，尺寸 100×36，点击返回上一步
  - 「下一步 ▶」按钮：位置 (450,455)，尺寸 100×36，点击进入下一步
  - 步骤指示器：位置 (370,465)，显示 "步骤 X / 3"，当前步骤高亮
  - 步骤圆点指示器：4 个圆点 (310,465)、(340,465)、(370,465)、(400,465)，当前步骤圆点高亮
- 教师操作流程：
  1. 图示加载后显示步骤0（四棱锥基本结构+已知条件）
  2. 教师点击「下一步 ▶」逐步展示辅助线添加和推理过程
  3. 每步都有明确的视觉变化，配合讲解
  4. 可随时点击「◀ 上一步」回退复习
  5. 步骤3展示最终答案 NC:NP = 1:4

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无需外部库，简单几何图形用 SVG 最清晰）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |                    P                             |
  |                   /|\                            |
  |                  / | \                           |
  |                 /  |  \                          |
  |                /   |   \                         |
  |               /    |    \                        |
  |              /     |     \                       |
  |             /      |      \                      |
  |            /       |       \                     |
  |    D------+--------+--------+---C                |
  |           |        |        |                    |
  |           |   M----+----N   |                    |
  |           |        |        |                    |
  |    A------+--------+--------+---B                |
  |                                                  |
  |                                                  |
  |                                                  |
  |                                                  |
  |     [◀ 上一步]  步骤 X/3  [下一步 ▶]             |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：currentStep 变量（0-3），每个步骤对应一组可见元素
  2. 元素管理：每个步骤的元素用数组存储，切换步骤时根据 currentStep 显示/隐藏
  3. 动画实现：CSS transition（opacity 0.5s ease-in），新增元素初始 opacity=0，添加 class 后 opacity=1
  4. 坐标计算：M、N、E 的坐标通过比例公式计算（已预计算）
  5. 线段分段高亮：PC 分为 PN 和 NC 两段，CD 分为 CE 和 ED 两段，步骤3分别设置不同颜色
  6. 平面填充：SVG polygon 元素，fill-opacity="0.2"
  7. 事件绑定：按钮 click 事件触发 stepForward()/stepBackward() 函数
  8. 边界处理：步骤0时「上一步」禁用，步骤3时「下一步」禁用
- ID 命名规范：所有交互元素 ID 以 `scene1-` 为前缀
  - scene1-btn-prev、scene1-btn-next、scene1-step-indicator
  - scene1-vertex-p、scene1-vertex-a、scene1-vertex-b、scene1-vertex-c、scene1-vertex-d
  - scene1-edge-pa、scene1-edge-pb、scene1-edge-pc、scene1-edge-ab、scene1-edge-bc
  - scene1-edge-pd、scene1-edge-ad、scene1-edge-cd
  - scene1-diag-ac、scene1-point-m、scene1-point-n、scene1-seg-mn
  - scene1-point-e、scene1-seg-me、scene1-seg-ne
  - scene1-plane-mne、scene1-label-cm-ma、scene1-label-me-ad
  - scene1-label-ne-pd、scene1-label-plane-parallel
  - scene1-label-nc-np-q、scene1-label-ce-ed、scene1-label-answer
  - scene1-pc-np、scene1-pc-nc、scene1-cd-ce、scene1-cd-ed
- IIFE 隔离：所有 JS 代码包在 (function() { 'use strict'; ... })() 中
