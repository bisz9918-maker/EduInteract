    **题目原文：**

    如图，AC=5cm，CD=3cm，DF=6cm，则从长方体表面上的点A到点F的最短距离等于______．

    **题目分析：**

    本题是经典的"长方体表面最短路径"问题。核心思想是将长方体表面展开为平面图形，利用"两点之间线段最短"的原理求解。

    **关键信息：**
    - 长方体中，A 为左下前顶点，C 为右下前顶点，D 为右下后顶点
    - E 为右上前顶点，B 为右上后顶点
    - F 在右侧后竖棱 BD 上，且 DF = 6cm
    - AC = 5cm（长方体的长），CD = 3cm（长方体的宽）

    **解题思路：**
    从 A 到 F 沿长方体表面行走，有多种展开方式。需要比较不同展开方式下的直线距离，取最小值。

    主要两种展开方式：
    1. **展开前面和右面**（沿棱 CE 展开）：水平距离 = AC + CD = 8cm，垂直距离 = DF = 6cm，距离 = √(8² + 6²) = 10cm
    2. **展开底面和右面**（沿棱 CD 展开）：水平距离 = AC = 5cm，垂直距离 = CD + DF = 9cm，距离 = √(5² + 9²) = √106 ≈ 10.3cm

    最短距离为 **10cm**。

    **图示规划：**
    - Scene 1：3D 长方体视图，标注已知条件和问题
    - Scene 2：展开图对比，展示两种展开方式并计算最短路径
    </TEXT_1>

    **教学说明：**

    本图示是解题的核心，展示"展开法"求表面最短路径的完整过程。

    **引导步骤：**

    1. **展开方式 1（前面 + 右面）：**
       - 将前面和右面沿公共棱 CE 展开到同一平面
       - 展开后，A、C、D 在一条直线上，AD = AC + CD = 5 + 3 = 8cm
       - F 在 D 的正上方，DF = 6cm
       - 构成直角三角形 ADF，AF = √(AD² + DF²) = √(8² + 6²) = √100 = **10cm**

    2. **展开方式 2（底面 + 右面）：**
       - 将底面和右面沿公共棱 CD 展开到同一平面
       - 展开后，A、C 在一条直线上，AC = 5cm
       - F 在 D 的正上方，CF = CD + DF = 3 + 6 = 9cm
       - 构成直角三角形 ACF，AF = √(AC² + CF²) = √(5² + 9²) = √106 ≈ **10.3cm**

    3. **比较结论：**
       - 10cm < 10.3cm，故最短距离为 **10cm**
       - 对应展开方式 1，即路径经过前面和右面

    **关键公式：**
    - 勾股定理：直角三角形中，斜边² = 两直角边² 之和
    - 展开方式 1：AF = √((AC+CD)² + DF²) = √(8² + 6²) = 10cm
    - 展开方式 2：AF = √(AC² + (CD+DF)²) = √(5² + 9²) = √106 ≈ 10.3cm

    **课堂讲解建议：**
    - 强调"展开"的本质是将曲面路径转化为平面直线
    - 让学生动手画图，加深理解
    - 可追问：是否还有其他展开方式？（如经过上面，但通常不是最短）
    - 总结方法：长方体表面最短路径 → 展开为平面 → 勾股定理计算 → 比较取最小
