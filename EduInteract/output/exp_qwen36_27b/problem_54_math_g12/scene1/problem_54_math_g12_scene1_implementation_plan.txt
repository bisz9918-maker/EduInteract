[图示主题与整合说明]
- 本图示主题：长方体表面最短路径问题 — 从点A到点F的最短表面距离

[分步序列]
- 初始状态（步骤0）：仅显示长方体线框图（9条可见实线棱 + 3条隐藏虚线棱），无任何标注。教师可让学生观察图形结构。
- 步骤1：点击「下一步」→ 出现6个顶点标签（A、C、D、E、B、F），每个标签紧邻对应顶点外侧。教师引导学生认识各顶点位置。
- 步骤2：点击「下一步」→ 出现3个蓝色长度标注：AC=5cm（AC线段下方）、CD=3cm（CD线段右下方）、DF=6cm（DF线段右侧）。教师讲解已知条件。
- 步骤3：点击「下一步」→ A点出现绿色高亮圆点（起点），F点出现红色高亮圆点（终点），同时显示一条灰色虚线路径从A经C、D到F，表示"沿表面的路径"。教师强调起点和终点。
- 步骤4：点击「下一步」→ 底部显示问题文字"求A到F的最短表面距离"。教师正式提出问题，引导学生思考展开法求解。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于(280,460)，宽80×高32px，点击返回上一步骤，步骤0时禁用
  - 「步骤 X/4」指示：位于(400,472)，显示当前步骤编号
  - 「下一步 ▶」按钮：位于(440,460)，宽80×高32px，点击进入下一步骤，步骤4时禁用
- 教师操作流程：
  1. 图示加载后显示步骤0（仅线框），教师让学生观察长方体结构
  2. 点击「下一步」逐步展示顶点、已知条件、起点终点、问题
  3. 可随时点击「上一步」回退复习
  4. 到达步骤4后，教师可基于此图示进一步讲解展开法求解

[技术实现]
- JS 库选择：原生 SVG（无需额外库，简单几何绘图+步骤切换完全够用）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |                    800×500 画布                   |
  |                                                   |
  |              [长方体3D透视图]                      |
  |           A━━━━━━C        B                       |
  |           │      │       /│                       |
  |           │      E━━━━━━/ │                       |
  |           │     /│     /  │                       |
  |           A━━━━/ D━━━━━━F │                       |
  |                /│       /  │                      |
  |               /  └──────/   │                     |
  |                                                   |
  |          问题文字（步骤4显示）                      |
  |                                                   |
  |    [◀上一步]   步骤 X/4   [下一步▶]               |
  |          y=440~490 控件栏区域                      |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. **状态机设计**：用变量 `currentStep`（0~4）跟踪当前步骤，每个步骤对应一组可见元素
  2. **元素分组**：SVG中使用 `<g>` 分组，每组对应一个步骤新增的元素，通过 `display:none/block` 控制显隐
     - `scene1-step0`：长方体线框（始终可见）
     - `scene1-step1`：顶点标签 A/C/D/E/B/F
     - `scene1-step2`：长度标注 AC=5cm/CD=3cm/DF=6cm
     - `scene1-step3`：起点A高亮圆、终点F高亮圆、表面路径虚线
     - `scene1-step4`：问题文字
  3. **按钮事件绑定**：上一步/下一步按钮绑定 click 事件，更新 `currentStep` 后调用 `updateVisibility()`
  4. **按钮禁用逻辑**：步骤0时上一步按钮 `disabled=true`，步骤4时下一步按钮 `disabled=true`
  5. **动画过渡**：元素出现时使用 CSS `opacity` 从0到1的过渡（0.3s ease），增强视觉效果
  6. **虚线路径**：用 `<polyline>` 绘制 A→C→D→F 的折线路径，`stroke-dasharray="6,4"`
- ID 命名规范：所有交互元素 ID 以 `scene1-` 为前缀
  - `scene1-step1-group`、`scene1-step2-group`、`scene1-step3-group`、`scene1-step4-group`
  - `scene1-btn-prev`、`scene1-btn-next`、`scene1-step-indicator`
  - `scene1-vertex-A`、`scene1-vertex-C`、`scene1-vertex-D`、`scene1-vertex-E`、`scene1-vertex-B`、`scene1-point-F`
  - `scene1-label-ac`、`scene1-label-cd`、`scene1-label-df`
  - `scene1-highlight-a`、`scene1-highlight-f`、`scene1-path-dashed`
  - `scene1-question-text`
- IIFE 隔离：所有 JS 代码包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染
