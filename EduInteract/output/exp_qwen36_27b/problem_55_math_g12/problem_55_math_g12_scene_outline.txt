    **题目原文：**

    如图，抛物线C：$y^{2}=2px(p＞0)$的焦点为F，A为C上的点，以F为圆心，$\frac{p}{2}$为半径的圆与线段AF的交点为B，∠AFx=60°，A在y轴上的射影为N，则∠$ONB=\underline{\hspace{2em}}\underline{\hspace{2em}}\underline{\hspace{2em}}$．

    **题目分析：**

    本题是解析几何综合题，涉及抛物线的定义、焦点坐标、圆的方程、直线与抛物线的交点、点在坐标轴上的射影等知识点。核心目标是求∠ONB的度数。

    **关键条件梳理：**
    1. 抛物线 $y^2 = 2px$ 的焦点为 $F(\frac{p}{2}, 0)$
    2. 以 F 为圆心、$\frac{p}{2}$ 为半径的圆
    3. ∠AFx = 60°（直线 AF 与 x 轴正方向夹角为 60°）
    4. B 是圆与线段 AF 的交点（即 FB = $\frac{p}{2}$）
    5. N 是 A 在 y 轴上的射影（即 AN ⊥ y 轴，N 在 y 轴上）

    **整体讲解思路：**

    首先引导学生理解题意，明确各点的几何位置关系。然后通过坐标法求解：利用直线 AF 的参数方程与抛物线方程联立求出点 A 的坐标，进而确定点 B 和点 N 的坐标，最后利用向量夹角公式或三角函数求出 ∠ONB = 30°。

    **教学说明：抛物线与角度问题的分步讲解**

    本图示通过分步导航的方式，帮助教师逐步引导学生理解题意并求解。以下是各步骤的讲解要点：

    **步骤 0：展示抛物线和焦点**
    - 引导学生回忆抛物线 $y^2 = 2px$ 的标准形式，开口向右，顶点在原点
    - 强调焦点 F 的坐标为 $(\frac{p}{2}, 0)$，这是抛物线的基本性质

    **步骤 1：添加圆**
    - 圆的圆心为 F$(\frac{p}{2}, 0)$，半径为 $\frac{p}{2}$
    - 引导学生观察：圆恰好过原点 O（因为 FO = $\frac{p}{2}$ = 半径）
    - 圆的方程为 $(x - \frac{p}{2})^2 + y^2 = (\frac{p}{2})^2$

    **步骤 2：确定点 A**
    - ∠AFx = 60°，即直线 AF 与 x 轴正方向夹角为 60°
    - 直线 AF 的斜率为 $\tan 60° = \sqrt{3}$
    - 用参数法：从 F 出发，设 AF 上任意点为 $(\frac{p}{2} + t\cos 60°, t\sin 60°) = (\frac{p}{2} + \frac{t}{2}, \frac{t\sqrt{3}}{2})$
    - 代入抛物线方程：$(\frac{t\sqrt{3}}{2})^2 = 2p(\frac{p}{2} + \frac{t}{2})$
    - 化简得：$3t^2 - 4pt - 4p^2 = 0$
    - 解得 $t = 2p$（取正根，因为 A 在 F 的右上方）
    - 故 A 的坐标为 $(\frac{3p}{2}, p\sqrt{3})$

    **步骤 3：确定点 B**
    - B 是圆与线段 AF 的交点，即 FB = $\frac{p}{2}$（圆的半径）
    - 从 F 出发沿 AF 方向走 $\frac{p}{2}$ 的距离
    - B 的坐标：$(\frac{p}{2} + \frac{p}{2}\cos 60°, \frac{p}{2}\sin 60°) = (\frac{3p}{4}, \frac{p\sqrt{3}}{4})$

    **步骤 4：确定点 N**
    - N 是 A 在 y 轴上的射影，即 AN ⊥ y 轴
    - 故 N 的坐标为 $(0, p\sqrt{3})$（与 A 同纵坐标，横坐标为 0）

    **步骤 5：求解 ∠ONB**
    - 方法一（向量法）：
      - $\vec{NO} = (0, -p\sqrt{3})$
      - $\vec{NB} = (\frac{3p}{4}, \frac{p\sqrt{3}}{4} - p\sqrt{3}) = (\frac{3p}{4}, -\frac{3p\sqrt{3}}{4})$
      - $\cos \angle ONB = \frac{\vec{NO} \cdot \vec{NB}}{|\vec{NO}| \cdot |\vec{NB}|} = \frac{9p^2/4}{p\sqrt{3} \cdot 3p/2} = \frac{\sqrt{3}}{2}$
      - 故 ∠ONB = 30°

    - 方法二（几何观察）：
      - 观察 NB 的斜率：$\frac{-\frac{3p\sqrt{3}}{4}}{\frac{3p}{4}} = -\sqrt{3}$
      - 即 NB 与 x 轴正方向夹角为 120°（或 -60°）
      - NO 沿 y 轴负方向，与 x 轴正方向夹角为 270°（或 -90°）
      - 故 ∠ONB = |120° - 90°| = 30°

    **课堂讲解建议：**
    - 在步骤 2 处可暂停，让学生尝试自己计算点 A 的坐标
    - 在步骤 5 处可引导学生思考是否有更简洁的几何方法（如利用特殊角的三角函数值）
    - 强调本题中 p 是参数，但最终角度与 p 无关，体现了几何问题的不变量思想
