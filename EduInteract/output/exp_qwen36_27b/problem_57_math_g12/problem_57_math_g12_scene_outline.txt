    **题目原文：**

    如图，直线PO⊥平面M，垂足为O，直线PA是平面M的一条斜线，斜足为A，其中∠APO=α，过点P的动直线PB交平面M于点B，∠APB=β，则下列说法正确的是______

    ①若α=0°，β=90°，则动点B的轨迹是一个圆；

    ②若α≠0°，β=90°，则动点B的轨迹是一条直线；

    ③若α≠0°，β≠90°且α+β=90°，则动点B的轨迹是抛物线；

    ④α≠0°，β≠90°且α+β＞90°，则动点B的轨迹是椭圆；

    ⑤α≠0°，β≠90°且α+β＜90°，则动点B的轨迹是双曲线．

    **题目分析：**

    本题核心是**圆锥截线（圆锥曲线）**的空间几何理解。关键洞察：

    1. 以P为顶点、PA为轴线、所有与PA夹角为β的直线PB构成一个**圆锥面**
    2. 平面M截此圆锥面，截线即为动点B的轨迹
    3. 圆锥轴线PA与平面M的夹角为 θ = 90° − α（因为PO⊥平面M，∠APO = α）
    4. 圆锥截线分类标准（比较半顶角β与轴线-平面夹角θ）：
       - β = 90°：圆锥退化为过P垂直于PA的平面，截线为**直线**
       - β = θ，即 α + β = 90°：截线为**抛物线**
       - β > θ，即 α + β > 90°：截线为**椭圆**
       - β < θ，即 α + β < 90°：截线为**双曲线**

    **整体讲解思路：**

    先通过Scene 1让学生理解题目的空间几何结构（PO⊥平面M、PA斜线、PB动直线、角度α和β的含义），再通过Scene 2动态展示圆锥面的形成以及不同参数下截线类型的变化，从而逐一判断五个说法的正误。

    **图示规划：** 共2个scene。Scene 1展示基础几何结构并标注关键角度；Scene 2通过滑块交互动态演示圆锥截线类型的变化规律。
    </TEXT_1>

    **Scene 2 教学说明：**

    本图示是解题的核心，通过动态展示圆锥截线类型的变化，逐一验证五个说法。

    **圆锥截线分类原理：**

    设圆锥半顶角为β，圆锥轴线PA与截面M的夹角为θ = 90° − α。

    | 条件 | 几何含义 | 截线类型 |
    |------|----------|----------|
    | β = 90° | 圆锥退化为平面 | 直线 |
    | β = θ，即α+β=90° | 截面平行于圆锥的一条母线 | 抛物线 |
    | β > θ，即α+β>90° | 截面与所有母线相交 | 椭圆 |
    | β < θ，即α+β<90° | 截面与部分母线不相交 | 双曲线 |

    **逐一判断：**

    1. **说法①（α=0°，β=90°）**：α=0°意味着PA与PO重合，即PA⊥平面M。此时β=90°，PB⊥PA，即PB在过P且垂直于PA的平面内，该平面平行于平面M，故PB与平面M无交点，B不存在，轨迹为空集。**❌错误**

    2. **说法②（α≠0°，β=90°）**：β=90°时，所有满足PB⊥PA的直线PB构成过P且垂直于PA的平面。该平面与平面M相交于一条直线（因为α≠0°，PA不垂直于平面M，故两平面不平行）。**✅正确**

    3. **说法③（α+β=90°）**：此时β = 90°−α = θ，截面平行于圆锥的一条母线，截线为抛物线。**✅正确**

    4. **说法④（α+β>90°）**：此时β > 90°−α = θ，截面与圆锥的所有母线都相交，截线为椭圆。**✅正确**

    5. **说法⑤（α+β<90°）**：此时β < 90°−α = θ，截面与圆锥的部分母线不相交，截线为双曲线。**✅正确**

    **最终答案：②③④⑤**

    **课堂讲解建议：**
    - 在步骤1（说法①）处重点强调"轨迹不存在"与"轨迹是圆"的区别，这是常见的陷阱
    - 在步骤3-5处，可引导学生回忆圆锥曲线的统一定义（到定点与定直线距离之比为常数e），建立与解析几何的联系
    - 总结时强调：圆锥截线类型由"圆锥半顶角"与"轴线-平面夹角"的相对大小决定，这是空间几何中的重要模型
