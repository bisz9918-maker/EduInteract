[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位置(260,455)，尺寸120×30px，点击回退到上一步骤，步骤0时禁用
  - 「下一步 ▶」按钮：位置(420,455)，尺寸120×30px，点击前进到下一步骤，步骤4时禁用
  - 步骤指示器：位置(390,465)，文本"步骤 X / 4"，居中显示
- 教师操作流程：
  1. 图示加载后显示步骤0（仅平面M和点P），教师可先让学生观察基础结构
  2. 点击「下一步 ▶」逐步添加垂线PO、斜线PA、动直线PB、圆锥面与截线
  3. 每步添加后，教师可暂停讲解新增元素的几何意义
  4. 如需回顾，点击「◀ 上一步」回退
  5. 到达步骤4后，教师可结合截线概念讲解题目中5个选项的判断依据

[技术实现]
- JS 库选择：原生SVG（本场景为纯几何图形，无需复杂坐标系或3D，原生SVG最轻量且精确控制每个元素）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |                    P  ●                          |
  |                   /  \                           |
  |                  / α\  \ β                       |
  |                 /    \  \                        |
  |                /      \  \                       |
  |               /        \  \                      |
  |              /          \  \                     |
  |             /            \  \                    |
  |            /              \  \                   |
  |           /                \  \                  |
  |          /                  \  \                 |
  |    A ●--/--------------------\--● B              |
  |   /  \  /                    \  /  \             |
  |  /    \/                      \/    \            |
  | /    O●                        /      \           |
  |/     / \                      /        \          |
  |-------------------------------------------- M    |
  |                                                  |
  |         [◀ 上一步]  步骤 X/4  [下一步 ▶]         |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. **状态机设计**：维护全局变量`currentStep`（0~4），每个步骤对应一组SVG元素的显示/隐藏状态
  2. **元素显隐控制**：使用CSS类`.scene1-hidden`（opacity:0, visibility:hidden）和`.scene1-visible`（opacity:1, visibility:visible），配合CSS transition实现淡入效果（transition: opacity 0.5s ease）
  3. **弧线绘制**：α弧线和β弧线使用SVG `<path>`的`A`命令（椭圆弧），根据角度计算起点和终点坐标
     - α弧线：从PO方向（正下方，角度90°）到PA方向（角度≈122°），r=35
     - β弧线：从PA方向（角度≈122°）到PB方向（角度≈64°），r=48
  4. **圆锥面椭圆**：使用SVG `<ellipse>`，设置`transform="rotate(32, 255, 215)"`使其长轴垂直于PA方向
  5. **截线曲线**：使用SVG `<path>`的`Q`命令（二次贝塞尔曲线），控制点(350,325)使曲线呈弧形
  6. **按钮事件绑定**：使用`addEventListener('click', ...)`绑定按钮点击事件，更新`currentStep`并调用`updateScene()`函数
  7. **按钮禁用逻辑**：步骤0时禁用「上一步」，步骤4时禁用「下一步」，通过设置`disabled`属性和CSS样式实现
- ID 命名规范：所有交互元素ID以`scene1-`为前缀
  - `scene1-plane-m`、`scene1-point-p`、`scene1-point-o`、`scene1-point-a`、`scene1-point-b`
  - `scene1-line-po`、`scene1-line-pa`、`scene1-line-pb`、`scene1-line-ab`
  - `scene1-angle-alpha`、`scene1-angle-beta`、`scene1-right-angle`
  - `scene1-cone`、`scene1-section`
  - `scene1-label-p`、`scene1-label-o`、`scene1-label-a`、`scene1-label-b`、`scene1-label-m`、`scene1-label-alpha`、`scene1-label-beta`
  - `scene1-btn-prev`、`scene1-btn-next`、`scene1-step-indicator`
- JS 中统一使用`document.getElementById('scene1-xxx')`获取元素，不使用`querySelectorAll`配合全局class
- IIFE 隔离：所有JS代码包裹在`(function() { 'use strict'; ... })();`中，避免全局污染
- 步骤元素分组：
  - 步骤0元素：plane-m, point-p, label-p, label-m
  - 步骤1新增：line-po, point-o, right-angle, label-o
  - 步骤2新增：line-pa, point-a, angle-alpha, label-a, label-alpha
  - 步骤3新增：line-pb, point-b, line-ab, angle-beta, label-b, label-beta
  - 步骤4新增：cone, section
