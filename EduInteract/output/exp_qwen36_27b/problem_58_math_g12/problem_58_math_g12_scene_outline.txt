    **题目原文：**

    （r77五•广东）选做题：如图，点A、B、C是圆O上的点，且AB=4，∠ACB=37°，则圆O的面积等于______．

    **题目分析：**

    本题考查圆周角定理的应用以及利用三角函数求圆的半径。

    **核心知识点：**
    1. 圆周角定理：同弧所对的圆心角等于圆周角的两倍
    2. 垂径定理：垂直于弦的直径平分弦
    3. 直角三角形中的三角函数关系
    4. 圆的面积公式 S = πr²

    **解题思路：**
    1. 连接OA、OB，由圆周角定理得 ∠AOB = 2∠ACB = 74°
    2. 作OD⊥AB于D，由垂径定理得 AD = BD = 2，且 ∠AOD = ∠AOB/2 = 37°
    3. 在Rt△AOD中，sin(37°) = AD/OA = 2/r，得 r = 2/sin(37°)
    4. 取 sin(37°) ≈ 3/5，则 r = 10/3，圆面积 S = π × (10/3)² = 100π/9

    **图示规划说明：**

    本题所有解题步骤均围绕同一圆O展开，通过逐步添加辅助线（半径、垂线）来揭示几何关系。因此规划为**一个交互式图示**，采用分步按钮导航，从原图逐步推进到最终结论，帮助教师完整呈现解题过程。

    **本图示教学说明：**

    **步骤0→步骤1：引入半径，建立圆心与弦的联系**

    教师引导学生观察：要求圆的面积，关键是求半径。如何把已知的弦AB和角∠ACB与半径联系起来？

    操作：点击「下一步」，添加半径OA和OB。

    引导语：「连接圆心O到弦AB的两个端点A和B，我们就得到了半径OA和OB。现在OA = OB = r，这是我们要求的未知量。」

    **步骤1→步骤2：应用圆周角定理**

    操作：点击「下一步」，标注圆心角∠AOB = 74°。

    引导语：「注意观察：∠ACB是弧AB所对的圆周角，∠AOB是弧AB所对的圆心角。根据圆周角定理，圆心角等于同弧所对圆周角的两倍。」

    关键公式：
    $$\angle AOB = 2 \times \angle ACB = 2 \times 37^\circ = 74^\circ$$

    强调：这是本题的核心定理，学生必须掌握。

    **步骤2→步骤3：作垂线，构造直角三角形**

    操作：点击「下一步」，添加垂线OD⊥AB。

    引导语：「在等腰△AOB中，从顶点O作底边AB的垂线OD。根据垂径定理，OD平分AB，所以AD = BD = 2。同时，OD也平分顶角，所以∠AOD = ∠AOB/2 = 37°。」

    关键推导：
    1. OD⊥AB，由垂径定理：AD = BD = AB/2 = 2
    2. OD平分∠AOB：∠AOD = ∠AOB/2 = 37°

    **步骤3→步骤4：在Rt△AOD中求半径**

    操作：点击「下一步」，高亮Rt△AOD，显示计算过程。

    引导语：「现在我们在Rt△AOD中，已知∠AOD = 37°，对边AD = 2，斜边OA = r。利用正弦函数：」

    关键公式：
    $$\sin 37^\circ = \frac{AD}{OA} = \frac{2}{r}$$
    $$r = \frac{2}{\sin 37^\circ}$$

    取 $\sin 37^\circ \approx \frac{3}{5}$，则：
    $$r = \frac{2}{3/5} = \frac{10}{3}$$

    **步骤4→步骤5：计算圆面积**

    操作：点击「下一步」，显示最终答案。

    引导语：「有了半径，直接代入圆面积公式：」

    关键公式：
    $$S = \pi r^2 = \pi \times \left(\frac{10}{3}\right)^2 = \frac{100\pi}{9}$$

    **课堂讲解建议：**

    1. 在步骤2处可暂停，让学生先自己推导∠AOB的度数，再确认答案
    2. 在步骤3处可提问：「为什么OD平分AB？」引导学生回忆垂径定理
    3. 在步骤4处可强调：sin(37°) ≈ 3/5 是常用近似值，建议学生记忆
    4. 讲解完毕后可回退到步骤0，让学生尝试独立复述解题思路
