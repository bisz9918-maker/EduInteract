    **题目原文：**

    (2010•肥城市模拟)如图，为了测量河的宽度，在河的一岸边选取两点A，B，观察对岸的点C，测得∠CAB=75°，∠CBA=45°，且AB=96米，则河的宽度为 ______．（√2=1.4，√3=1.7，精确到米）

    **题目分析：**

    本题是一道利用解三角形知识解决实际测量问题的经典题目。核心考点包括：
    - 三角形内角和定理
    - 正弦定理的应用
    - 直角三角形中三角函数的运用
    - 通过作辅助线（垂线）将斜三角形问题转化为直角三角形问题

    **整体讲解思路：**

    1. 首先引导学生理解题意：河的宽度即两条平行河岸之间的垂直距离
    2. 从C点向AB所在直线作垂线CD，CD即为所求河宽
    3. 在△ABC中，利用内角和求出∠ACB=60°
    4. 用正弦定理求出BC（或AC）的长度
    5. 在Rt△BCD中，利用CD=BC·sin45°求出河宽
    6. 代入近似值计算最终结果

    **图示规划说明：**

    本题规划为1个交互式图示场景，整合题目原图、辅助线添加、角度标注和计算过程，通过分步按钮导航引导学生逐步理解解题思路。

    **本图示教学说明：**

    本图示通过分步导航的方式，完整呈现了利用解三角形知识测量河宽的解题过程。

    **步骤引导要点：**

    1. **步骤0→步骤1（理解题意）**：引导学生观察图形，明确A、B在同一河岸，C在对岸，河的宽度即C到AB所在直线的垂直距离。标注已知条件时，强调∠CAB=75°、∠CBA=45°、AB=96米这三个已知量。

    2. **步骤1→步骤2（作辅助线）**：提问学生"如何求河的宽度？"引导学生想到从C向AB作垂线。添加垂线CD后，说明CD即为所求河宽，同时指出D为垂足，∠CDB=90°。

    3. **步骤2→步骤3（求∠ACB）**：利用三角形内角和定理，∠ACB=180°-∠CAB-∠CBA=180°-75°-45°=60°。这一步为后续使用正弦定理做准备。

    4. **步骤3→步骤4（正弦定理求BC）**：在△ABC中，由正弦定理得：

        BC/sin∠CAB = AB/sin∠ACB

        即 BC/sin75° = 96/sin60°

        其中 sin75° = sin(45°+30°) = sin45°cos30° + cos45°sin30° = (√6+√2)/4

        sin60° = √3/2

        所以 BC = 96 × sin75° / sin60° = 96 × (√6+√2)/4 ÷ (√3/2) = 48(√6+√2)/√3

    5. **步骤4→步骤5（求河宽CD）**：在Rt△BCD中，∠CBD=45°，所以：

        CD = BC × sin45° = 48(√6+√2)/√3 × √2/2 = 48(√12+2)/(2√3) = 48(2√3+2)/(2√3) = 48(√3+1)/√3 = 48 + 48/√3 = 48 + 16√3

        代入√3=1.7，得 CD ≈ 48 + 16×1.7 = 48 + 27.2 = 75.2 ≈ 75（米）

    **课堂讲解建议：**

    - 在步骤2添加辅助线时，可让学生先在草稿纸上尝试作图，再与图示对照
    - 步骤4中正弦定理的应用是本题关键，可回顾正弦定理的公式和适用条件
    - 步骤5中sin75°的计算可提前板书推导过程，帮助学生理解特殊角的三角函数值
    - 最终结果75米可引导学生思考：这个宽度是否合理？是否符合实际河流的宽度范围？
    - 可拓展提问：如果只知道AB和两个角度，能否求出河宽？强调"两角一边"可以唯一确定三角形
