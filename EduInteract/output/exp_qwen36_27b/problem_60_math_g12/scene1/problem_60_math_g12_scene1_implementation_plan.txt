[图示主题与整合说明]
- 本图示主题：圆中切线性质 $PC \cdot PD = PO^2$ 的几何动态演示
- 整合的步骤/概念：圆的切线几何结构构建、切线交点动态追踪、线段长度实时计算、乘积等式恒成立验证
- 教学价值：教师可通过拖动滑块改变点P在圆周上的位置，直观展示无论P如何移动，$PC \cdot PD$ 始终等于 $PO^2$（即半径平方），帮助学生从动态变化中理解几何不变量，为后续类比椭圆性质奠定直观基础。

[分步序列]
- 初始状态（步骤0）：
  - 显示圆O、直径AB、切线AC/BD、直角标记。
  - 点P位于 $\theta=110^\circ$ 处（左上方），切线CD与AC/BD交于C、D。
  - 显示线段PO、PC、PD。
  - 右侧面板显示初始计算值：PC≈84.9, PD≈169.7, PO=120.0, PC·PD≈14400, PO²=14400。
  - 底部显示结论 $PC \cdot PD = PO^2$。
  - 滑块位于对应角度位置，等待交互。
- 拖拽交互状态（动态）：
  - 教师拖动滑块，$\theta$ 在 $10^\circ \sim 170^\circ$ 范围内连续变化。
  - 点P沿圆周平滑移动，切线CD随之旋转，交点C、D沿竖直线上下滑动。
  - 线段PC、PD、PO长度实时更新。
  - 面板数值实时刷新，始终显示 $PC \cdot PD \approx PO^2$（允许微小浮点误差，显示为相等）。
  - 结论公式保持高亮，强化不变量认知。
- 边界状态提示：
  - 当 $\theta \to 0^\circ$ 或 $180^\circ$ 时，切线趋于水平，C、D趋于无穷远。滑块限制在 $10^\circ \sim 170^\circ$ 避免溢出画布。

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：
  - 滑块（scene1-slider）：水平放置于底部 y=460，范围 10~170，控制点P的极角 $\theta$。
  - 提示文字（scene1-hint）：滑块上方显示“拖动滑块改变点P位置”，字号14px，灰色。
- 教师操作流程：
  1. 初始加载后，图示展示标准几何结构，面板显示验证等式。
  2. 教师拖动滑块，点P沿圆周移动，切线CD动态调整。
  3. 教师引导学生观察：尽管PC、PD、PO长度各自变化，但乘积 $PC \cdot PD$ 始终等于 $PO^2$。
  4. 教师可暂停在任意位置，强调几何不变性，为椭圆类比做铺垫。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无需重型库，几何计算简单，性能最优）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +------------------------------------------------------------+
  |  [几何区 x:20~560]              [数值面板 x:580~780]       |
  |  C o------------------o D      |  PC = 84.9                |
  |   \                   /        |  PD = 169.7               |
  |    \      P          /         |  PO = 120.0               |
  |     \    o          /          |                           |
  |      \   / \      /           |  PC·PD = 14400             |
  |       \ /   \    /            |  PO²  = 14400              |
  |  A o---O-----o B              |                           |
  |      |     |  |               |  ✓ 等式恒成立              |
  |      |     |  |               +----------------------------+
  |      |     |  |
  +------------------------------------------------------------+
  |              [  ◄──── scene1-slider ────►  ]               |
  |                     PC·PD = PO² (高亮结论)                 |
  +------------------------------------------------------------+
  ```
- 关键实现要点：
  - 状态机：无需复杂状态机，采用事件驱动（input事件监听滑块值）。
  - 坐标计算：
    - $P_x = 280 + 120\cos\theta$, $P_y = 250 - 120\sin\theta$
    - 切线方程：$(x-280)\cos\theta - (y-250)\sin\theta = 120$
    - $y_C = 250 + \frac{(160-280)\cos\theta - 120}{\sin\theta}$
    - $y_D = 250 + \frac{(400-280)\cos\theta - 120}{\sin\theta}$
    - 距离公式计算 PC, PD, PO。
  - 动画曲线：滑块拖动时直接更新（requestAnimationFrame 或 直接 DOM 更新），无需缓动，保证实时性。
  - 事件绑定：`scene1-slider` 的 `input` 事件触发 `updateGeometry(angle)` 函数。
  - 数值格式化：保留1位小数，乘积与平方显示整数或1位小数，确保视觉相等。
- ID 命名规范：所有交互元素及关键图形元素 ID 以 `scene1-` 为前缀（如 `scene1-circle`, `scene1-point-p`, `scene1-slider`, `scene1-panel-pc` 等）。
- IIFE 隔离：全部 JS 代码包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染。
- 防溢出处理：$\theta$ 限制在 $[10^\circ, 170^\circ]$，避免切线交点超出画布边界。
