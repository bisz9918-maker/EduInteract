    **题目原文：**

    如图，在半径为3的球面上有$A$、$B$、$C$三点，$\angle ABC=90^{\circ}$，$BA=BC$，球心$O$到平面$ABC$的距离是$\frac{3\sqrt{2}}{2}$，则$B$、$C$两点的球面距离是______．

    **题目分析：**

    本题是立体几何中球面距离的经典问题，核心考点包括：
    1. 球心到截面距离与截面圆半径的关系：$R^2 = r^2 + d^2$
    2. 直角三角形外接圆半径等于斜边的一半
    3. 球面距离公式：$s = R \cdot \theta$（$\theta$为球心角，弧度制）

    **整体讲解思路：**

    解题分两大阶段：
    - **第一阶段**：利用球心到平面距离公式，求出截面圆半径，进而求出$BC$的长度
    - **第二阶段**：在$\triangle BOC$中求球心角$\angle BOC$，再用球面距离公式求答案

    **图示规划说明：**

    规划两个图示：
    - **Scene 1**：球体与截面圆的空间关系图（3D视角），展示球体、截面圆、$\triangle ABC$、球心到平面的距离，逐步推导截面圆半径和$BC$长度
    - **Scene 2**：球心角与球面距离的剖面图（2D视角），展示$\triangle BOC$为等边三角形，计算球面距离

    **完整解答：**

    1. 设$BA = BC = x$，则$AC = x\sqrt{2}$（等腰直角三角形斜边）
    2. $\triangle ABC$外接圆半径$r = \frac{AC}{2} = \frac{x\sqrt{2}}{2}$（直角三角形外接圆直径为斜边）
    3. 由$R^2 = r^2 + d^2$：$9 = r^2 + \left(\frac{3\sqrt{2}}{2}\right)^2 = r^2 + \frac{9}{2}$
    4. 得$r^2 = \frac{9}{2}$，$r = \frac{3\sqrt{2}}{2}$
    5. 故$\frac{x\sqrt{2}}{2} = \frac{3\sqrt{2}}{2}$，得$x = 3$，即$BC = 3$
    6. 在$\triangle BOC$中，$OB = OC = R = 3$，$BC = 3$，故$\triangle BOC$为等边三角形
    7. $\angle BOC = 60^\circ = \frac{\pi}{3}$
    8. 球面距离$s = R \cdot \angle BOC = 3 \times \frac{\pi}{3} = \pi$

    **答案：$\pi$**
    </TEXT_1>

    **Scene 1 教学说明：**

    本图示展示球体与截面圆的空间关系，是解题的第一阶段。

    **引导步骤：**

    1. **步骤0**：先让学生观察球体，明确已知条件——球半径$R=3$

    2. **步骤1**：引入截面圆的概念。提问学生：球心到截面的距离$d=\frac{3\sqrt{2}}{2}$是什么意思？引导学生理解这是球心$O$到平面$ABC$的垂线段长度

    3. **步骤2**：在截面圆上展示$\triangle ABC$。引导学生观察：$\angle ABC=90^\circ$且$BA=BC$，说明$\triangle ABC$是等腰直角三角形。关键知识点：**直角三角形的外接圆直径等于斜边**，即$r = \frac{AC}{2}$

    4. **步骤3**：展示核心公式$R^2 = r^2 + d^2$。这是球体截面问题中最常用的关系式。代入已知数据：
    $$9 = r^2 + \left(\frac{3\sqrt{2}}{2}\right)^2 = r^2 + \frac{9}{2}$$
    解得$r^2 = \frac{9}{2}$，即$r = \frac{3\sqrt{2}}{2}$

    5. **步骤4**：由$r = \frac{AC}{2} = \frac{3\sqrt{2}}{2}$，得$AC = 3\sqrt{2}$。再由等腰直角三角形$AC = BC\sqrt{2}$，得$BC = 3$

    **教学提示：** 强调公式$R^2 = r^2 + d^2$的几何意义——球心、截面圆心、截面圆上任意一点构成直角三角形。这是学生容易遗忘的知识点。

    **Scene 2 教学说明：**

    本图示展示球面距离的计算过程，是解题的第二阶段。

    **引导步骤：**

    1. **步骤0**：从Scene 1过渡，回顾已求得$BC=3$。现在关注球心$O$与$B$、$C$三点的关系

    2. **步骤1**：连接$OB$、$OC$、$BC$形成$\triangle BOC$。引导学生观察三边长度：
    - $OB = R = 3$（球半径）
    - $OC = R = 3$（球半径）
    - $BC = 3$（上一步求得）
    - **三边相等！**

    3. **步骤2**：得出$\triangle BOC$是等边三角形，故$\angle BOC = 60^\circ = \frac{\pi}{3}$（弧度）。强调球面距离公式中的角度必须用**弧度制**

    4. **步骤3**：应用球面距离公式：
    $$s = R \cdot \theta = 3 \times \frac{\pi}{3} = \pi$$
    最终答案为$\pi$

    **教学提示：**
    - 球面距离的本质是球面上两点间沿大圆弧的最短距离
    - 公式$s = R\theta$中$\theta$必须是弧度，这是学生常犯的错误（误用角度制）
    - 可以补充：若$\angle BOC$不是特殊角，需用余弦定理求$\cos\angle BOC = \frac{OB^2 + OC^2 - BC^2}{2 \cdot OB \cdot OC}$

    **课堂总结建议：**
    本题的解题链条为：球心距公式→截面圆半径→弦长BC→球心角→球面距离。建议教师在黑板上画出完整的逻辑链，帮助学生建立立体几何中球体问题的通用解题框架。
