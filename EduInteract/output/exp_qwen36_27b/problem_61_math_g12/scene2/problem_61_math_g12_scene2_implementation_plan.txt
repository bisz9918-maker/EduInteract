[图示主题与整合说明]
- 本图示主题：球心角∠BOC与球面距离的计算
- 整合的步骤/概念：△BOC的构造 → 等边三角形判定 → 球心角求解 → 球面距离公式应用
- 教学价值：教师通过分步按钮引导学生从已知边长关系出发，逐步发现△BOC为等边三角形，进而求出球心角∠BOC=60°=π/3，最后代入球面距离公式s=R·θ得出答案π。分步展示逻辑递进清晰，便于学生跟随推理过程。

坐标计算说明：
- 圆心O(400,240)，半径R=160px
- B点：O左下方，与垂直向下方向夹角30°向左 → (400-160×sin30°, 240+160×cos30°) = (320, 378.6) ≈ (320, 379)
- C点：O右下方，与垂直向下方向夹角30°向右 → (400+160×sin30°, 240+160×cos30°) = (480, 378.6) ≈ (480, 379)
- 验证：OB=OC=√(80²+139²)≈160，BC=160，△BOC为等边三角形 ✓
- OB中点(360,309.5)，垂直偏移左侧15px → (347, 302)
- OC中点(440,309.5)，垂直偏移右侧15px → (453, 302)
- BC中点(400,379)，偏移下方16px → (400, 395)

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀上一步」按钮：位于控件栏左侧，点击回退到前一步骤，步骤0时禁用（灰色）
  - 「下一步▶」按钮：位于控件栏右侧，点击进入下一步骤，步骤3时禁用（灰色）
  - 步骤指示器：控件栏中央显示"步骤 X/3"文字
- 控件栏位置：SVG内底部，y=440~490区域，使用position:absolute叠在SVG上
- 教师操作流程：
  1. 图示加载后显示步骤0（球心O和两点B、C，标注已知边长）
  2. 教师点击「下一步▶」进入步骤1，△BOC三条边出现，引导学生观察三边相等
  3. 教师点击「下一步▶」进入步骤2，扇形高亮∠BOC，标注等边三角形和角度值
  4. 教师点击「下一步▶」进入步骤3，红色弧BC和公式框出现，展示球面距离计算
  5. 教师可随时点击「◀上一步」回退到任意步骤复习

[技术实现]
- JS 库选择：原生SVG（简单几何图形，无需额外库，性能最优）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |                  图示区 800×440                   |
  |                                                  |
  |           . - ~ ~ ~ - .                          |
  |        .                 .                       |
  |       |                   |                      |
  |       |        O          |      公式框           |
  |       |      /   \        |     s=R·θ             |
  |       |     /  ∠  \       |     =3×π/3            |
  |       |    /_______\      |     = π (绿色)        |
  |        .    B   C   .     |                       |
  |           ' - ~ ~ ~ - '                          |
  |                                                  |
  +--------------------------------------------------+
  |              控件栏 y=440~490                     |
  |     [◀上一步]    步骤 X/3    [下一步▶]            |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. **状态机设计**：用变量currentStep（0~3）跟踪当前步骤，每个步骤对应一组可见元素
  2. **元素显隐控制**：使用CSS类.step0、.step1、.step2、.step3控制元素可见性，通过切换currentStep更新类名
  3. **SVG弧路径计算**：
     - 扇形区域：M 400,240 L 420,274.6 A 40,40 0 0,1 380,274.6 Z（r=40，角度60°~120°）
     - 角度弧线：M 420,274.6 A 30,30 0 0,1 380,274.6（r=30，角度60°~120°）
     - 弧BC：M 320,379 A 160,160 0 0,1 480,379（r=160，短弧，顺时针）
     - 角度计算：起点(400+R×cos60°, 240+R×sin60°)，终点(400+R×cos120°, 240+R×sin120°)
  4. **动画实现**：使用CSS transition（opacity 0.5s ease-in）实现淡入效果，弧BC使用stroke-dasharray/stroke-dashoffset动画
  5. **事件绑定**：按钮点击事件更新currentStep，重新渲染对应步骤的元素
  6. **公式框渲染**：使用SVG rect+text组合，三行文本分别定位
- ID 命名规范：所有交互元素ID以 `scene2-` 为前缀
  - scene2-circle（大圆）
  - scene2-point-o、scene2-point-b、scene2-point-c（三个点）
  - scene2-label-o、scene2-label-b、scene2-label-c（点标签）
  - scene2-label-ob、scene2-label-oc、scene2-label-bc（边长标签）
  - scene2-line-ob、scene2-line-oc、scene2-line-bc（三条边）
  - scene2-sector（扇形区域）
  - scene2-angle-arc（角度弧线）
  - scene2-label-angle（∠BOC标签）
  - scene2-label-equilateral（等边△标注）
  - scene2-arc-bc（弧BC）
  - scene2-formula-box（公式框）
  - scene2-formula-line1、scene2-formula-line2、scene2-formula-line3（公式文本）
  - scene2-btn-prev、scene2-btn-next（导航按钮）
  - scene2-step-indicator（步骤指示器）
- JS 中用 document.getElementById 而非 querySelectorAll 配合全局 class
- IIFE 隔离：所有JS代码包裹在 (function() { 'use strict'; ... })() 中，避免全局污染
