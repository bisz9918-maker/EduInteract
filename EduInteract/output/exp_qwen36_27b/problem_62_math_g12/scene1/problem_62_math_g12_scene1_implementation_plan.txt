[图示主题与整合说明]
- 本图示主题：四面体ABCD中过中点连线EF的平面α与棱BC、AD的交点关系及面积性质
- 整合的步骤/概念：
  1. 四面体ABCD的空间结构（2D投影）
  2. E、F分别为AB、CD中点的标注
  3. 平面α过EF与BC、AD交于G、H的动态关系
  4. 结论②验证：α∥BD时GF∥EH∥BD
  5. 结论①反例：α∥BD时GF∥EH不相交
  6. 结论③验证：G在线段BC上、H在AD延长线上的情况
  7. 结论④验证：S△EFG=S△EFH恒成立
- 教学价值：教师通过分步导航逐步展示不同平面α位置下的几何关系，每一步聚焦一个结论的验证，帮助学生理解空间几何中平面截四面体的性质

[分步序列]

初始状态（步骤0）：
- 显示四面体ABCD的线框结构（6条棱线，4个顶点标签A、B、C、D）
- 显示中点E（AB中点）、F（CD中点），标注"E""F"
- 用虚线连接EF
- 不显示平面α、交点G、H、面积标签
- 步骤说明文字："四面体ABCD，E、F分别为AB、CD的中点"

步骤1（一般位置）：
- 点击「下一步」→ 平面α出现（半透明填充 #1565c0 15%）
- 交点G出现在BC上(260,364)，交点H出现在AD上(694,218)
- 高亮四边形EGFH边界（#1565c0 实线 2px）
- △EFG用#1565c0 20%透明填充，△EFH用#2e7d32 20%透明填充
- 显示面积标签：S△EFG = S△EFH（数值相等）
- 显示平面标签"α"
- 步骤说明文字："平面α过EF交BC于G、AD于H → S△EFG = S△EFH（结论④✓）"

步骤2（α∥BD的特殊位置）：
- 点击「下一步」→ 平面α旋转至平行于BD
- G移动至BC中点(220,340)，H移动至AD中点(540,145)
- GF、EH用#1565c0加粗3px高亮，BD用#c62828加粗3px高亮
- 显示平行标注"GF∥EH∥BD"（#c62828）
- 在GF和EH旁显示"∥"符号
- 标注"GF与EH不相交"（说明结论①错误）
- 面积标签仍显示S△EFG = S△EFH
- 步骤说明文字："α∥BD时 GF∥EH∥BD（结论②✓），GF与EH不相交（结论①✗）"

步骤3（G在线段BC上、H在AD延长线上）：
- 点击「下一步」→ 平面α旋转至G仍在线段BC上但H在AD延长线上
- G移动至(180,316)（BC上靠近B），H移动至(736,278)（AD延长线上D的外侧）
- 用红色高亮H在AD延长线上的位置
- AD线段延长部分用虚线显示
- 面积标签仍显示S△EFG = S△EFH（验证面积仍相等）
- 步骤说明文字："G在线段BC上，H在AD延长线上（结论③✓），面积仍相等（结论④✓）"

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于控件栏左侧(200,455)，点击返回上一步骤
  - 步骤说明文字：位于控件栏中央(400,470)，显示当前步骤对应的结论验证内容
  - 「下一步 ▶」按钮：位于控件栏右侧(500,455)，点击进入下一步骤
- 教师操作流程：
  1. 图示加载后显示步骤0（四面体基础结构），教师介绍题目背景
  2. 点击「下一步」进入步骤1，展示平面α一般位置，讲解结论④（面积相等）
  3. 点击「下一步」进入步骤2，展示α∥BD的特殊位置，讲解结论②（平行）和结论①的反例
  4. 点击「下一步」进入步骤3，展示H在AD延长线上的情况，讲解结论③和再次验证结论④
  5. 可随时点击「上一步」回退复习任意步骤
  6. 步骤0时「上一步」按钮禁用，步骤3时「下一步」按钮禁用

[技术实现]
- JS 库选择：原生 Canvas 2D（通用绘图，支持半透明填充、动态坐标变化、无需额外依赖）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |                    A(400,50)                     |
  |                   /    \                         |
  |                  /      \                        |
  |           E(260,165)    H(694,218)               |
  |          /  \      \  /      \                   |
  |         /    \      \/        \                  |
  |    B(120,280)  \  /  α(430,240)\  D(680,240)    |
  |          \      \/              /                |
  |           \    / \            /                  |
  |            \  /   \          /                   |
  |      G(260,364)   F(500,320)                    |
  |            \      / \        /                   |
  |             \    /   \      /                    |
  |              \  /     \    /                     |
  |               C(320,400)                       |
  |                                                |
  |  [◀上一步]  步骤说明文字  [下一步▶]             |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：定义4个状态（step0~step3），每个状态包含G、H坐标、显示元素列表、高亮元素列表
  2. 坐标计算：
     - 步骤0：G、H不显示
     - 步骤1：G=(260,364)，H=(694,218)
     - 步骤2：G=(220,340)，H=(540,145)
     - 步骤3：G=(180,316)，H=(736,278)
  3. 动画曲线：使用requestAnimationFrame实现G、H位置的平滑过渡（easeInOut，时长500ms）
  4. 事件绑定：按钮点击事件触发状态切换，更新画布内容
  5. 绘制顺序（从后到前）：
     - 背景 → 虚线棱(BD、CD) → 实线棱(AB、AC、AD、BC) → 平面α填充 → △EFG填充 → △EFH填充 → 四边形EGFH边界 → 线段EF → 中点E、F → 交点G、H → 顶点标签 → 中点标签 → 交点标签 → 面积标签 → 平行标注 → 控件栏
  6. 面积计算：使用2D投影坐标计算三角形面积（叉积公式），显示数值验证相等
  7. 平行标注：步骤2中在GF、EH、BD旁绘制"∥"符号（使用Canvas text或绘制平行线段）
- ID 命名规范：所有交互元素ID以 scene1- 为前缀
  - scene1-canvas：Canvas元素
  - scene1-prev-btn：上一步按钮
  - scene1-next-btn：下一步按钮
  - scene1-step-info：步骤说明文字
  - scene1-container：容器元素
- IIFE 隔离：所有JS代码包裹在 (function() { 'use strict'; ... })() 中，避免全局污染
