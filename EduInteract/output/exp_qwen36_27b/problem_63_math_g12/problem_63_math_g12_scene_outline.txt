    **题目原文：**

    如图，F为双曲线$\frac{x^{2}}{a^{2}}-\frac{y^{2}}{b^{2}}=1$（b＞a＞0）的右焦点，过F作直线l与圆$x^{2}+y^{2}=b^{2}$切于点M，与双曲线交于点P，且M恰为线段PF的中点，则双曲线的渐近线方程是______．

    **题目分析：**

    本题综合考查双曲线的几何性质、圆的切线性质、三角形中位线定理以及双曲线定义。核心思路是利用几何关系建立 a 与 b 的比例关系，从而求出渐近线斜率。

    **关键知识点：**
    - 双曲线焦点坐标：F(c, 0)，其中 $c = \sqrt{a^2 + b^2}$
    - 圆的切线性质：圆心到切点的连线垂直于切线
    - 三角形中位线定理
    - 双曲线定义：$||PF'| - |PF|| = 2a$

    **解题核心步骤：**
    1. 由切线性质得 OM ⊥ l，在 Rt△OMF 中，|OM| = b，|OF| = c，故 |MF| = $\sqrt{c^2 - b^2} = a$
    2. M 为 PF 中点，故 |PF| = 2|MF| = 2a
    3. 引入左焦点 F'，连接 PF'，OM 为 △PFF' 的中位线，故 |PF'| = 2|OM| = 2b
    4. 由双曲线定义：|PF'| - |PF| = 2a，代入得 2b - 2a = 2a，即 b = 2a
    5. 渐近线方程为 $y = \pm\frac{b}{a}x = \pm 2x$

    **图示规划说明：**

    本题所有几何元素均在同一坐标系中，核心推导围绕中位线关系展开。规划为 **一个交互式图示**，通过分步按钮导航，从题目条件逐步推导到结论，帮助教师完整呈现解题思路。

    **教学说明——Scene 1：双曲线与圆的综合几何关系**

    **整体讲解策略：**

    本图示通过 6 个递进步骤，完整呈现从题目条件到最终结论的推导过程。教师可按以下步骤引导学生：

    **步骤 0：观察题目图形**
    - 引导学生识别图中的所有几何元素：双曲线、圆、直线 l、各关键点
    - 提问：F 是什么点？圆方程是什么？直线 l 有什么特殊性质？

    **步骤 1：利用切线性质**
    - 强调：圆的切线性质——圆心到切点的连线垂直于切线
    - 引导学生发现：OM ⊥ l，且 |OM| = b（M 在圆上）
    - 此时 Rt△OMF 的三个顶点都已确定

    **步骤 2：计算 |MF|**
    - 在 Rt△OMF 中应用勾股定理
    - 关键代换：c² = a² + b²（双曲线基本关系）
    - 得出 |MF| = a，这是一个简洁而重要的结论

    **步骤 3：利用中点条件**
    - M 是 PF 中点，故 |PF| = 2|MF| = 2a
    - 引导学生思考：|PF| = 2a 与双曲线定义中的 2a 有什么关系？

    **步骤 4：引入左焦点，构造中位线（关键步骤）**
    - 这是解题的突破口：连接 PF'，观察 △PFF'
    - O 是 FF' 中点（原点是对称中心），M 是 PF 中点（已知）
    - 由中位线定理：OM = $\frac{1}{2}$|PF'|，即 |PF'| = 2|OM| = 2b
    - 强调：中位线定理是连接几何条件与代数关系的关键桥梁

    **步骤 5：应用双曲线定义**
    - 双曲线定义：对于右支上的点 P，|PF'| - |PF| = 2a
    - 代入已知：2b - 2a = 2a
    - 解得：b = 2a
    - 引导学生验证：题目条件 b > a > 0，b = 2a 满足此条件

    **步骤 6：写出渐近线方程**
    - 双曲线 $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$ 的渐近线为 $y = \pm\frac{b}{a}x$
    - 代入 b = 2a，得 $y = \pm 2x$
    - 在图中展示渐近线，观察其与双曲线的关系

    **板书建议：**

    教师在讲解时可配合板书以下关键公式：

    1. 在 Rt△OMF 中：$|MF| = \sqrt{|OF|^2 - |OM|^2} = \sqrt{c^2 - b^2} = \sqrt{a^2 + b^2 - b^2} = a$

    2. M 为 PF 中点：$|PF| = 2|MF| = 2a$

    3. OM 为 △PFF' 中位线：$|PF'| = 2|OM| = 2b$

    4. 双曲线定义：$|PF'| - |PF| = 2a \Rightarrow 2b - 2a = 2a \Rightarrow b = 2a$

    5. 渐近线方程：$y = \pm\frac{b}{a}x = \pm 2x$

    **易错点提醒：**
    - 学生可能忘记双曲线中 c² = a² + b² 的关系
    - 中位线定理的应用是本题难点，需重点讲解为何 OM 是中位线
    - 双曲线定义中 |PF'| - |PF| = 2a 的符号问题（P 在右支上，|PF'| > |PF|）

    **答案：$y = \pm 2x$**
