[分步序列]
- 初始状态（步骤0）：显示直四棱柱完整线框图（实线/虚线区分可见性），8个顶点标签就位。无高亮，无辅助线。
- 步骤1：点击「下一步」→ 底面对角线AC以蓝色#1565c0高亮显示（2.5px实线），其余元素不变。
- 步骤2：点击「下一步」→ 上底面对角线B₁D₁以红色#c62828高亮显示（2.5px实线），AC保持蓝色。
- 步骤3：点击「下一步」→ 底面添加辅助线BD（灰色虚线），在B₁D₁中点(400,120)和BD中点(340,300)处出现灰色平行箭头，右侧显示文本"B₁D₁ ∥ BD"。
- 步骤4：点击「下一步」→ AC与BD交点(400,300)处出现绿色直角标记，右下方显示文本"AC ⊥ BD"，提示底面对角线垂直条件。
- 步骤5：点击「下一步」→ 图形下方居中显示绿色加粗结论"底面ABCD的对角线互相垂直"，同时AC与B₁D₁短暂闪烁绿色#2e7d32强调垂直结论。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于(250,450)，宽120px，高40px，步骤0时禁用
  - 「下一步 ▶」按钮：位于(430,450)，宽120px，高40px，步骤5时禁用
  - 步骤指示器：位于(400,445)上方，显示"步骤 X / 5"
- 教师操作流程：教师点击「下一步」逐步推进推导过程，每步停留讲解对应几何关系；可随时点击「上一步」回退复习；步骤5展示完整结论后按钮禁用，可刷新或重置重新开始。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无需外部库，轻量高效，适合静态几何+分步显隐控制）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [ 800×500 SVG 画布 ]
  y=65  A₁
  y=110 B₁          D₁
  y=120 ────B₁D₁(红)────
  y=195 C₁
  y=210         B₁D₁∥BD
  y=270 A
  y=300 ────BD(灰虚)────
  y=310 B          D
  y=320     AC⊥BD
  y=375 C
  y=420 底面ABCD的对角线互相垂直
  y=440 [◀上一步] [步骤指示] [下一步▶]
  ```
- 关键实现要点：
  - 状态机：`let currentStep = 0; const maxStep = 5;` 控制各元素 `display` 或 `opacity` 属性
  - 元素显隐：使用 SVG `<g>` 分组，按步骤添加/移除 `class="visible"`，CSS 控制 `opacity: 0/1` 过渡动画（0.3s ease）
  - 坐标计算：所有顶点、线段、标签坐标硬编码写入 SVG，避免运行时计算误差
  - 事件绑定：按钮绑定 `click` 事件，调用 `nextStep()` / `prevStep()` 更新状态并重绘
  - 动画曲线：高亮线段使用 `stroke-width` 和 `stroke` 颜色渐变过渡，直角标记使用 `scale` 弹出动画
- ID 命名规范：所有交互元素及关键图形 ID 均以 `scene1-` 为前缀（如 `scene1-ac`, `scene1-b1d1`, `scene1-btn-next`, `scene1-step-indicator`）
- IIFE 隔离：全部 JS 逻辑包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染
- CSS 样式内联或 `<style>` 块限定于 `#scene1-container` 作用域
