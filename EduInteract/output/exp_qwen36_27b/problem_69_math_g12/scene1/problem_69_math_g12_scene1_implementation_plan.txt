[图示主题与整合说明]
- 本图示主题：直三棱柱ABC-A₁B₁C₁与其外接球O的空间关系展示
- 整合的步骤/概念：三棱柱基本结构 → 已知条件标注 → 底面外接圆构造 → 顶面外接圆构造 → 球心与球半径定位 → 完整外接球展示
- 教学价值：教师通过分步按钮逐步引导学生从三棱柱结构认知到外接球构造，每一步都有明确的认知递进关系。学生可以直观理解"直角三角形外接圆圆心在斜边中点"、"球心在上下底面外接圆圆心连线中点"等关键几何性质，最终推导出球半径 R = √(r² + (h/2)²) = 5√2，进而计算球体积。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位置 x=250, y=450, 宽100px, 高30px，步骤0时禁用
  - 步骤指示器：位置 x=370, y=455，显示 "步骤 0/5" ~ "步骤 5/5"
  - 「下一步 ▶」按钮：位置 x=450, y=450, 宽100px, 高30px，步骤5时禁用
- 教师操作流程：
  1. 页面加载后显示步骤0（三棱柱线框），教师介绍三棱柱的基本结构
  2. 点击「下一步」进入步骤1，讲解已知条件（边长、垂直关系）
  3. 点击「下一步」进入步骤2，讲解底面直角三角形的外接圆构造
  4. 点击「下一步」进入步骤3，讲解顶面外接圆
  5. 点击「下一步」进入步骤4，讲解球心定位方法
  6. 点击「下一步」进入步骤5，展示完整外接球，总结结论
  7. 可随时点击「上一步」回退到任意步骤复习

[技术实现]
- JS 库选择：原生 SVG（简单几何图形绘制，无需额外库）
  - 原因：本场景涉及直线、圆、椭圆、多边形等基本几何元素，原生 SVG 完全胜任，无需引入 D3.js 或 Three.js
  - 数学符号（√34 等）使用 HTML 实体或 Unicode 字符直接渲染
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+ y=0
  |                                                  |
  |              C(310,130)                          |
  |           /-----------\                          |
  |          /  M(415,175) \                         |
  |         /---------------\                        |
  |        C                 A(520,220)              |
  |       /|------------------\                      |
  |      / |  B(400,220)       \                     |
  |     /  |                    \                    |
  |    /   |                     \                   |
  |   /    |         O(415,255)   \                  |
  |  /     |                       \                 |
  | /  C₁  |      M₁(415,335)       \                |
  |/   \   |                         /               |
  |     \  |------------------------/                |
  |      \ |  B₁(400,380)  A₁(520,380)              |
  |       \|----------------------------------------/|
  |                                                  |
  |  [◀上一步]  步骤 X/5  [下一步▶]                  | y=445~485
  +--------------------------------------------------+ y=500
  ```
- 关键实现要点：
  1. **状态机设计**：用变量 `currentStep`（0~5）管理当前步骤，每个步骤对应一组 SVG 元素的显示/隐藏状态
  2. **元素可见性控制**：使用 CSS class `.step-N` 控制元素在步骤 N 及之后可见，通过切换父容器 class 实现
  3. **椭圆外接圆**：底面/顶面外接圆在斜二测投影中为椭圆，使用 SVG `<ellipse>` 元素，rx=117px, ry=58px
  4. **外接球椭圆**：rx=163px, ry=130px（考虑斜二测 y 方向压缩），fill="rgba(21,101,192,0.2)"
  5. **绘制顺序（z-order）**：球体 → 三棱柱线框 → 外接圆 → 圆心/球心 → 标注线段 → 文字标签
  6. **动画过渡**：元素出现时使用 CSS `opacity` 从 0 到 1 的过渡动画（duration: 0.4s, ease-in）
  7. **按钮状态**：步骤0时「上一步」按钮 disabled，步骤5时「下一步」按钮 disabled
  8. **事件绑定**：按钮点击事件更新 `currentStep`，重新渲染对应步骤的 SVG 元素
- ID 命名规范：所有交互元素 ID 以 `scene1-` 为前缀
  - 按钮：`scene1-prev-btn`、`scene1-next-btn`
  - 步骤指示器：`scene1-step-indicator`
  - SVG 容器：`scene1-svg-container`
  - 三棱柱组：`scene1-prism`
  - 底面外接圆：`scene1-base-circle`
  - 顶面外接圆：`scene1-top-circle`
  - 球体：`scene1-sphere`
  - 各顶点：`scene1-vert-A1`、`scene1-vert-B1` 等
- IIFE 隔离：所有 JS 代码包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染
