    **题目原文：**

    如图所示，闭合开关后将变阻器的滑片向右移动，下列说法正确的是（）

    A. 电路总电阻变小
    B. 弹簧测力计示数变小
    C. 电磁铁的磁性增强
    D. 电流表读数变大

    **题目分析：**

    本题综合考查欧姆定律、电磁铁磁性强弱的影响因素、弹簧测力计受力分析等知识点。电路由电源、开关、滑动变阻器、定值电阻、电流表和电磁铁线圈串联组成；弹簧测力计悬挂铁球置于电磁铁正上方。

    **核心逻辑链：**

    滑片右移 → 滑动变阻器接入电阻变大 → 电路总电阻变大 → 电流变小（欧姆定律） → 电磁铁磁性减弱 → 对铁球吸引力减小 → 弹簧测力计示数变小

    **受力分析关键点：**

    铁球受三个力：向下的重力 G、向下的电磁铁吸引力 F_吸、向上的弹簧拉力 F_弹。平衡时 F_弹 = G + F_吸。当 F_吸 减小时，F_弹 减小，即弹簧测力计示数变小。

    **答案：B**

    **整体讲解思路：**

    通过一个综合图示，以分步动画方式展示从"滑片移动"到"弹簧测力计示数变化"的完整因果链。先让学生观察电路结构，再逐步推进：电阻变化 → 电流变化 → 磁性变化 → 受力变化 → 结论。每一步都配合视觉高亮和数值变化，帮助学生建立清晰的物理因果链条。

    **本图示教学说明：**

    本图示以分步动画形式呈现完整的因果推理链，教师可按以下步骤引导学生：

    1. **步骤0（建立整体认知）**：让学生先观察整个装置，识别电路中的各个元件，理解电磁铁与铁球的空间关系。提问："电磁铁通电后会对铁球产生什么作用？"引导学生回答"吸引力"。

    2. **步骤1（电阻与电流变化）**：点击"下一步"，滑片右移。引导学生观察：
       - 滑动变阻器接入电路的电阻丝长度变长 → 电阻变大
       - 根据欧姆定律 $I = \frac{U}{R}$，电源电压不变，总电阻变大 → 电流变小
       - 电流表指针左偏，直观验证电流减小

    3. **步骤2（磁性变化）**：磁感线由密变疏，直观展示"电流减小 → 磁性减弱"。强调电磁铁磁性强弱与电流大小的正相关关系。

    4. **步骤3（受力分析——关键难点）**：这是本题最容易出错的地方。重点讲解：
       - 铁球受三个力：重力 G（向下，不变）、电磁铁吸引力 F_吸（向下，减小）、弹簧拉力 F_弹（向上）
       - 平衡方程：$F_弹 = G + F_吸$
       - 当 F_吸 减小时，F_弹 也减小
       - 弹簧测力计示数即为 F_弹，所以示数变小
       - **易错提醒**：学生常误以为"吸引力减小，弹簧示数变大"，需强调吸引力是向下的，它和重力同向，共同由弹簧拉力平衡

    5. **步骤4（选项判断与结论）**：逐一判断四个选项：
       - A：总电阻变大，非变小 → ✗
       - B：弹簧测力计示数变小 → ✓（正确答案）
       - C：磁性减弱，非增强 → ✗
       - D：电流变小，非变大 → ✗

    **课堂讲解建议：**
    - 在步骤3处可暂停，让学生先自行分析受力，再揭示答案，增强参与感
    - 可让学生用手比划力的方向，加深理解"吸引力向下"这一关键点
    - 强调解题策略：遇到此类题，先画受力分析图，再列平衡方程，最后判断变化

    **本图示教学说明：**

    本图示是 Scene 1 中受力分析部分的独立放大，专门针对本题的核心难点——弹簧测力计示数变化方向。

    **教学要点：**

    1. **为什么单独做一个受力分析图？** 因为这是学生最容易出错的地方。很多学生会直觉地认为"吸引力减小，弹簧示数应该变大"，这是因为没有正确分析力的方向。

    2. **引导学生观察的关键：**
       - 重力 G 始终不变（灰色箭头长度不变）
       - 吸引力 F_吸 方向向下（与重力同向），当它减小时，弹簧需要提供的拉力也减小
       - 弹簧拉力 F_弹 方向向上，平衡向下的两个力

    3. **平衡方程推导：**
       - 铁球静止，合力为零
       - 向上力 = 向下力
       - $F_弹 = G + F_吸$
       - 当 $F_吸$ 减小时，$F_弹$ 也减小
       - 弹簧测力计示数 = $F_弹$，所以示数变小

    4. **对比两种状态：** 通过状态切换，让学生直观看到箭头长度的变化，理解"吸引力减小 → 弹簧拉力减小 → 示数变小"的关系。

    **易错点强调：**
    - 错误理解1："吸引力减小，铁球被拉得更轻，所以示数变大"——错在混淆了力的方向
    - 错误理解2："吸引力是向上的"——错在搞错了电磁铁对铁球的作用方向（电磁铁在铁球下方，吸引铁球向下）
    - 正确理解：电磁铁在铁球下方，通电后吸引铁球向下，这个力与重力同向，都由弹簧拉力来平衡

    **课堂讲解建议：**
    - 先让学生猜测弹簧测力计示数如何变化，记录答案
    - 再展示本图示，通过对比两种状态，验证或纠正学生的猜测
    - 最后回到 Scene 1 的完整流程，巩固整体因果链

    **完整解答与总结：**

    **解题步骤：**

    1. 滑片向右移动 → 滑动变阻器接入电路的电阻丝长度增加 → 接入电阻变大
    2. 电路总电阻 $R_总 = R_定 + R_滑$ 变大 → 选项 A 错误
    3. 由欧姆定律 $I = \frac{U}{R_总}$，电源电压不变，总电阻变大 → 电流变小 → 选项 D 错误
    4. 电磁铁磁性强弱与电流大小成正比 → 电流变小 → 磁性减弱 → 选项 C 错误
    5. 铁球受力分析：$F_弹 = G + F_吸$，磁性减弱 → $F_吸$ 减小 → $F_弹$ 减小 → 弹簧测力计示数变小 → 选项 B 正确

    **答案：B**

    **知识点总结：**
    - 滑动变阻器：滑片移动方向与接入电阻变化的关系
    - 欧姆定律：$I = \frac{U}{R}$，电压不变时，电阻与电流成反比
    - 电磁铁：磁性强弱与电流大小、线圈匝数、有无铁芯有关
    - 受力分析：正确判断力的方向和大小变化

    **教学建议：**
    - 先使用 Scene 1 展示完整因果链，建立整体认知
    - 再使用 Scene 2 深入讲解受力分析这一难点
    - 最后回到 Scene 1 的结论步骤，完成选项判断
    - 可让学生课后练习类似题目，巩固"滑片移动→电阻变化→电流变化→磁性变化→受力变化"的分析思路
