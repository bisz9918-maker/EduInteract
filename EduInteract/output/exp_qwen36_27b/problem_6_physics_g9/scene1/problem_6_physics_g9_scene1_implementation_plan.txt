[图示主题与整合说明]
- 本图示主题：滑动变阻器滑片右移引起的电路与电磁铁连锁变化全过程
- 整合的步骤/概念：电路结构展示 → 滑片右移动画 → 电阻/电流变化 → 电磁铁磁性变化 → 铁球受力分析 → 弹簧测力计示数变化结论
- 教学价值：教师通过分步导航，引导学生逐步推理物理量之间的因果关系（R↑→I↓→磁性↓→F_吸↓→F_弹↓），直观展示抽象的电磁学原理与力学平衡的结合，帮助学生理解选项判断依据。

[分步序列]
- **初始状态（步骤0）**：
  - 显示完整电路图（滑片在左，接入电阻小）。
  - 电流表指针偏右（I₁大）。
  - 电磁铁周围磁感线密集（蓝色）。
  - 弹簧测力计指针示数 F₁（较大）。
  - 铁球与电磁铁间距正常。
- **步骤1（滑片右移）**：
  - 动画：滑片从 x=130 移动到 x=170。
  - 视觉变化：滑动变阻器接入部分（左段）红色高亮范围变长，标注"R↑"。
  - 电流表指针向左偏转（I↓），标注"I↓"。
- **步骤2（磁性减弱）**：
  - 动画：磁感线由密变疏（透明度降低或数量减少）。
  - 视觉变化：蓝色标注"磁性减弱"出现。
  - 铁球与电磁铁间吸引力箭头（红色）变短，标注"F_吸↓"。
- **步骤3（受力分析）**：
  - 视觉变化：在铁球上叠加受力分析箭头。
  - G（灰色，向下，不变）。
  - F_吸（红色，向下，较短）。
  - F_弹（绿色，向上，较短）。
  - 显示平衡方程：F_弹 = G + F_吸（灰色辅助线对齐）。
- **步骤4（结论）**：
  - 动画：弹簧测力计指针从 F₁ 移动到 F₂（向上移动，示数变小）。
  - 视觉变化：右侧弹出结论框。
  - 结论框内容："弹簧测力计示数变小 ✓"（绿色）。
  - 选项判断：A.总电阻变小✗ / B.示数变小✓ / C.磁性增强✗ / D.电流变大✗。

[技术实现]
- **JS 库选择**：原生 SVG + JavaScript（无需外部库，轻量且精确控制）。
- **画布尺寸**：800 × 500 px。
- **布局草图**：
  ```
  [ 电路图区域 (x:100-520) ] [ 机械装置区域 (x:520-580) ] [ 结论/标签区域 (x:600-760) ]
  | 定值电阻 |               | 弹簧测力计 |                  |                      |
  | 电流表   |               | 铁球       |                  | 结论框 (步骤4)       |
  | 滑动变阻器|              | 电磁铁     |                  |                      |
  | 电源/开关|               | 磁感线     |                  |                      |
  --------------------------------------------------------------
  [ 控件栏：◀上一步 | 步骤 X/4 | 下一步▶ ] (y:460-490)
  ```
- **关键实现要点**：
  - **状态机**：使用变量 `currentStep` (0-4) 管理状态。每个步骤对应一组 SVG 元素的属性更新（位置、透明度、颜色、显示/隐藏）。
  - **动画**：使用 CSS transitions 或 JS `requestAnimationFrame` 实现平滑过渡（滑片移动、指针偏转、箭头伸缩、磁感线淡入淡出）。
  - **坐标计算**：
    - 滑片位置：`x = 130 + step * 10` (步骤1时 x=170)。
    - 电流表指针角度：`angle = 45 - step * 15` (初始45°，步骤1后30°)。
    - 弹簧指针位置：`y = 100 + step * 5` (初始100，步骤4后120，示数变小意味着弹簧缩短，指针向上？不，弹簧测力计示数变小意味着拉力变小，弹簧缩短，指针向上移动。初始 F₁ 大，指针偏下。F₂ 小，指针偏上。所以 y 减小。`y = 110 - step * 2` 在步骤4生效)。
    - 磁感线透明度：`opacity = 1 - step * 0.2` (步骤2后变淡)。
  - **事件绑定**：按钮点击事件触发 `updateScene(step)` 函数。
  - **ID 命名规范**：所有交互元素 ID 以 `scene1-` 为前缀（如 `scene1-slider`, `scene1-ammeter-needle`, `scene1-btn-next`）。
  - **IIFE 隔离**：所有 JS 代码包裹在 `(function() { ... })();` 中，避免全局污染。
