[图示主题与整合说明]
- 本图示主题：铁球受力分析的独立放大图——弹簧测力计示数变化原理
- 整合的步骤/概念：铁球三力平衡分析 → 平衡方程推导 → 电磁铁吸引力变化对弹簧拉力的影响 → 两种状态（滑片初始位置 vs 滑片右移后）的受力与读数对比
- 教学价值：教师可通过状态切换按钮，直观展示滑片右移导致电流减小、磁性减弱、吸引力下降，进而使弹簧测力计示数变小的完整因果链。箭头长度变化与测力计指针联动，强化“力的大小可视化”与“平衡方程动态验证”的课堂讲解效果。

[分步序列]
- 初始状态（步骤0/状态1）：
  - 显示铁球、三个力箭头（G固定，F_吸₁长90px，F_弹₁长140px）
  - 右侧显示方程框：$F_{弹1} = G + F_{吸1}$
  - 测力计指针位于 y=250，右侧标注读数 "F₁"
  - 顶部标题显示："状态1（滑片初始位置）"
  - 比较标注隐藏
- 步骤1（点击「状态2 ▶」）：
  - 触发平滑过渡动画（0.6s ease-in-out）
  - F_吸箭头缩短至50px，F_弹箭头缩短至90px，G箭头不变
  - 方程框更新为：$F_{弹2} = G + F_{吸2}$
  - 测力计指针上移至 y=220，读数更新为 "F₂"
  - 顶部标题更新："状态2（滑片右移后）"
  - 淡入比较标注："F_吸↓"、"F_弹↓"、"F₂ < F₁"
- 步骤2（点击「◀ 状态1」）：
  - 反向平滑过渡回状态1，所有元素恢复初始位置与文本
  - 比较标注淡出

[交互方案]
- 交互类型：多状态切换（2个状态按钮）
- 控件说明：
  - 「◀ 状态1」按钮：位于(300,450)，点击切换至滑片初始位置状态
  - 「状态2 ▶」按钮：位于(420,450)，点击切换至滑片右移后状态
  - 按钮组置于SVG底部 y=440~490 区域，不额外撑高容器
- 教师操作流程：
  1. 初始加载显示状态1，教师讲解三力平衡及初始方程
  2. 点击「状态2 ▶」，箭头与指针平滑变化，教师结合动画讲解“电流减小→磁性减弱→吸引力下降→弹簧拉力减小”的因果链
  3. 点击「◀ 状态1」回退，反复对比强化理解
  4. 配合板书或口述，指出比较标注的结论

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无需外部库，轻量高效，适合几何图形与状态切换动画）
- 画布尺寸：800 × 500 px（固定 viewBox）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  y=30  : 状态标题（居中）
  y=80~380: 左侧铁球+三力箭头 | 右侧测力计+方程框
  y=450 : [◀ 状态1] [状态2 ▶] （SVG底部控件区）
  ```
- 关键实现要点：
  - 状态机设计：`let currentState = 1;` 维护状态，按钮点击触发 `switchState(target)`
  - 坐标计算：箭头终点、指针位置、文本内容均通过状态变量映射数组/对象获取
  - 动画曲线：使用 `requestAnimationFrame` 或 CSS `transition` 实现 0.6s ease-in-out 平滑过渡。SVG 元素属性变化可通过 JS 动态修改 `y1/y2` 属性配合 CSS `transition: all 0.6s ease-in-out;`
  - 事件绑定：按钮绑定 `click` 事件，防抖处理避免快速点击导致动画错乱
  - 文本更新：方程框与读数标签使用 `textContent` 或 `innerHTML` 更新，配合 `<tspan>` 实现下标
- ID 命名规范：所有交互元素与关键图形 ID 均以 `scene2-` 为前缀，例如：
  - `scene2-ball`, `scene2-arrow-g`, `scene2-arrow-f-abs`, `scene2-arrow-f-spring`
  - `scene2-equation-box`, `scene2-scale-pointer`, `scene2-reading`
  - `scene2-btn-state1`, `scene2-btn-state2`, `scene2-title`
- IIFE 隔离：所有 JS 代码包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染
- 样式隔离：CSS 选择器均以 `#scene2-container` 或 `[id^="scene2-"]` 限定作用域
