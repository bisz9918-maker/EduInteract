    **题目原文：**

    如图所示，在四棱锥$P$－$ABCD$中，$PA$⊥底面$ABCD$，且底面各边都相等，$M$是$PC$上的一动点，当点$M$满足________时，平面$MBD$⊥平面$PCD$。（只要填写一个你认为是正确的条件即可）

    **题目分析：**

    本题是立体几何中的平面垂直判定问题。核心思路是：要证明平面$MBD$⊥平面$PCD$，需要在其中一个平面内找到一条直线垂直于另一个平面。

    **关键推导链：**
    1. 底面各边相等 → 底面$ABCD$是菱形 → 对角线$AC$⊥$BD$
    2. $PA$⊥底面$ABCD$ → $PA$⊥$BD$
    3. 由$AC$⊥$BD$且$PA$⊥$BD$ → $BD$⊥平面$PAC$ → $BD$⊥$PC$
    4. 若再添加条件$DM$⊥$PC$（或$BM$⊥$PC$），则$PC$垂直于平面$MBD$内的两条相交直线$BD$和$DM$ → $PC$⊥平面$MBD$
    5. $PC$在平面$PCD$内 → 平面$MBD$⊥平面$PCD$

    **答案：** $DM$⊥$PC$（或$BM$⊥$PC$，或$M$为$PC$上使$DM$⊥$PC$的点）

    **整体讲解思路：**

    通过一个交互式四棱锥图示，分步引导学生从已知条件出发，逐步推导出$BD$⊥$PC$这一关键结论，再引导学生思考还需要什么条件才能使平面$MBD$⊥平面$PCD$，最终得出答案。整个过程强调"线面垂直→面面垂直"的判定逻辑。

    **本图示教学说明：**

    本图示通过分步导航，完整呈现从已知条件到结论的推导过程。教师可按以下步骤引导学生：

    **步骤0→1：理解底面性质**
    - 引导学生观察底面$ABCD$各边相等，得出底面是菱形
    - 强调菱形对角线互相垂直：$AC$⊥$BD$
    - 这是后续推导的基础

    **步骤1→2：利用线面垂直**
    - 回顾已知条件$PA$⊥底面$ABCD$
    - 引导学生得出$PA$⊥$BD$（线面垂直→线线垂直）

    **步骤2→3：推导关键结论$BD$⊥$PC$**
    - 由$AC$⊥$BD$且$PA$⊥$BD$，且$AC$与$PA$相交于$A$，得出$BD$⊥平面$PAC$
    - 因为$PC$在平面$PAC$内，所以$BD$⊥$PC$
    - **这是本题最关键的中间结论**，教师应重点强调

    **步骤3→4：引入动点$M$，引导学生思考**
    - 提出问题：要使平面$MBD$⊥平面$PCD$，需要什么条件？
    - 引导学生回忆面面垂直的判定定理：一个平面内有一条直线垂直于另一个平面
    - 已知$BD$⊥$PC$，若再使$DM$⊥$PC$，则$PC$垂直于平面$MBD$内的两条相交直线

    **步骤4→5：添加条件$DM$⊥$PC$**
    - 展示$M$移动到使$DM$⊥$PC$的位置
    - 强调此时$PC$⊥平面$MBD$（线面垂直判定：$PC$垂直于平面内两条相交直线$BD$和$DM$）

    **步骤5→6：得出面面垂直结论**
    - 因为$PC$⊥平面$MBD$，且$PC$在平面$PCD$内
    - 所以平面$MBD$⊥平面$PCD$（面面垂直判定定理）

    **板书建议：**
    教师在讲解时可配合板书写出关键推导：
    1. 底面各边相等 → $ABCD$为菱形 → $AC$⊥$BD$
    2. $PA$⊥底面$ABCD$ → $PA$⊥$BD$
    3. $AC$⊥$BD$，$PA$⊥$BD$，$AC$∩$PA$=$A$ → $BD$⊥平面$PAC$ → $BD$⊥$PC$
    4. 若$DM$⊥$PC$，则$PC$⊥平面$MBD$（$BD$∩$DM$=$D$）
    5. $PC$⊂平面$PCD$ → 平面$MBD$⊥平面$PCD$

    **注意事项：**
    - 学生可能直接想到$BM$⊥$PC$作为答案，这也是正确的，教师可引导学生验证
    - 强调"只要填写一个条件"，答案不唯一
    - 本题核心考点：线面垂直的判定与性质、面面垂直的判定

    **完整解答与课堂总结：**

    **答案：** $DM$⊥$PC$（或$BM$⊥$PC$）

    **完整证明：**

    ∵ 底面$ABCD$各边相等
    ∴ 底面$ABCD$是菱形
    ∴ $AC$⊥$BD$

    ∵ $PA$⊥底面$ABCD$，$BD$⊂底面$ABCD$
    ∴ $PA$⊥$BD$

    ∵ $AC$⊥$BD$，$PA$⊥$BD$，$AC$∩$PA$=$A$
    ∴ $BD$⊥平面$PAC$

    ∵ $PC$⊂平面$PAC$
    ∴ $BD$⊥$PC$

    当$DM$⊥$PC$时：
    ∵ $BD$⊥$PC$，$DM$⊥$PC$，$BD$∩$DM$=$D$
    ∴ $PC$⊥平面$MBD$

    ∵ $PC$⊂平面$PCD$
    ∴ 平面$MBD$⊥平面$PCD$

    **课堂讲解建议：**
    1. 先让学生独立审题，找出已知条件和待求结论
    2. 引导学生回忆面面垂直的判定定理
    3. 逐步推导$BD$⊥$PC$这一关键结论
    4. 让学生思考还需要什么条件，鼓励多种答案
    5. 最后总结：立体几何中"线线垂直→线面垂直→面面垂直"的递进关系
