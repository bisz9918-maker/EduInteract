[图示主题与整合说明]
- 本图示主题：导体棒在倾斜U形框架上的电磁感应运动过程与受力分析
- 整合的步骤/概念：三维透视展示U形框架与导体棒、受力分析（重力/支持力/安培力）、运动过程动态演示（速度增大）、平衡状态推导（最大速度）、电功率计算与发热效果
- 教学价值：教师可通过分步导航逐层讲解物理过程，从静态结构到动态受力，再到公式推导与数值计算，帮助学生建立完整的电磁感应物理图景

[分步序列]
- 初始状态（步骤0）：
  - 显示U形框架（三条黑线）
  - 显示导体棒MN（初始位置）
  - 显示磁场B箭头及标签
  - 显示倾角θ标注（虚线+弧线+标签）
  - 显示宽度L标注
  - 公式区显示标题"已知条件"
  - 控件栏显示「下一步 ▶」

- 步骤1（受力分析）：
  - 点击「下一步 ▶」
  - 从导体棒中心引出三个力箭头：mg（红，下）、N（绿，左上）、F_安（红，左上沿斜面）
  - 标注各力符号
  - 公式区显示"受力分析"标题
  - 控件栏显示「◀ 上一步」「下一步 ▶」

- 步骤2（运动过程）：
  - 点击「下一步 ▶」
  - 导体棒MN沿斜面下滑动画（2秒内从初始位置移动到下方位置）
  - 速度v箭头出现并逐渐变长（表示v增大）
  - 电流I箭头出现在导体棒上（N→M方向）
  - 公式区显示：
    - E = BLv
    - I = BLv/R
    - F_安 = B²L²v/R
  - 控件栏显示「◀ 上一步」「下一步 ▶」

- 步骤3（平衡状态）：
  - 点击「下一步 ▶」
  - 导体棒停止在最大速度位置
  - 公式区新增：
    - 平衡方程：mg sinθ = F_安
    - 推导：v_m = mgR sinθ / (B²L²) = 5 m/s
  - 速度v箭头保持最大长度
  - 控件栏显示「◀ 上一步」「下一步 ▶」

- 步骤4（电功率）：
  - 点击「下一步 ▶」
  - 导体棒显示发热效果（红色渐变填充）
  - 公式区新增：
    - P = I²R = B²L²v_m²/R = 5 W
  - 控件栏显示「◀ 上一步」

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」：返回上一状态，隐藏当前步骤新增元素
  - 「下一步 ▶」：进入下一状态，显示新增元素并触发动画
- 教师操作流程：
  1. 初始展示题目结构，讲解U形框架、磁场、倾角等已知条件
  2. 点击下一步，展示受力分析，讲解重力、支持力、安培力的方向
  3. 点击下一步，演示导体棒下滑过程，讲解感应电动势、电流、安培力随速度增大
  4. 点击下一步，展示平衡状态，讲解最大速度的推导过程
  5. 点击下一步，展示电功率计算，讲解发热效果与功率公式

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无需外部库，轻量高效）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  +--------------------------------------------------+
  |                  图示区 800×440                   |
  |  [U形框架]        [公式区]                        |
  |  [导体棒]        [E=BLv]                         |
  |  [力箭头]        [I=BLv/R]                       |
  |  [θ/L标注]       [F_安=...]                      |
  |                          [mg sinθ=F_安]          |
  |                          [v_m=5m/s]              |
  |                          [P=5W]                  |
  +--------------------------------------------------+
  |              控件栏 800×60 (y=440~500)            |
  |           [◀ 上一步]     [下一步 ▶]               |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  - 状态机：使用变量 `currentStep` (0-4) 管理当前步骤，每个步骤对应一组显示/隐藏逻辑
  - 动画：步骤2使用 CSS transition 或 requestAnimationFrame 实现导体棒下滑动画（2秒）
  - 坐标计算：导体棒位置沿导轨方向移动，保持与导轨垂直
  - 事件绑定：按钮点击事件更新 `currentStep` 并调用 `renderStep()` 函数
  - 公式显示：使用 SVG `<text>` 元素，分步添加/移除
  - 发热效果：步骤4使用 SVG `<linearGradient>` 填充导体棒
- ID 命名规范：所有元素 ID 以 `scene1-` 为前缀，如 `scene1-rod`, `scene1-btn-next`, `scene1-formula-e`
- IIFE 隔离：所有 JS 代码包裹在 `(function() { ... })()` 中，避免全局污染
