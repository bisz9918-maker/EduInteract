    **题目原文：**

    如图所示，线圈 abcd 每边长 l=0.20m，线圈质量 m₁=0.10kg、电阻 R=0.10Ω，砝码质量 m₂=0.14kg．线圈上方的匀强磁场磁感强度 B=0.5T，方向垂直线圈平面向里，磁场区域的宽度为 h=l=0.20m．砝码从某一位置下降，使 ab 边进入磁场开始做匀速运动．求：
    （1）线圈做匀速运动的速度．
    （2）从 ab 进入磁场到线圈穿出磁场过程中产生的热量．

    **题目分析：**

    本题是电磁感应中的经典"导体切割磁感线"问题，涉及动生电动势、安培力、受力平衡和能量守恒等核心知识点。

    **关键物理过程：**
    - 砝码 m₂ 通过滑轮系统拉动线圈 m₁ 向上运动
    - 当线圈 ab 边进入磁场后，ab 边切割磁感线产生感应电动势 E = Blv
    - 感应电流在磁场中受到安培力，方向向上（阻碍运动）
    - 题目条件"ab 边进入磁场开始做匀速运动"意味着受力平衡

    **整体讲解思路：**
    1. 首先通过装置图让学生理解物理场景：滑轮系统、磁场区域、线圈运动方向
    2. 通过分步动画展示线圈穿过磁场的完整过程，理解两个阶段（ab 切割和 cd 切割）
    3. 进行受力分析，建立平衡方程求解速度
    4. 利用能量守恒求解热量

    **图示规划说明：**
    - Scene 1：装置结构与运动过程演示（分步动画展示线圈穿过磁场的完整过程）
    - Scene 2：受力分析与速度计算（受力分析图 + 公式推导）
    - Scene 3：能量转化与热量计算（能量守恒分析）

    **Scene 2 教学说明：受力分析与速度计算**

    **教学目标：** 通过受力分析建立平衡方程，求解线圈匀速运动的速度。

    **引导步骤：**

    1. **步骤0（装置概览）**：回顾装置结构，明确 m₂ 拉动 m₁ 向上运动

    2. **步骤1（砝码受力分析）**：
       - 砝码 m₂ 匀速下降，受力平衡
       - 受力：重力 m₂g 向下，绳子拉力 T 向上
       - 平衡方程：**m₂g = T**

    3. **步骤2（线圈受力分析）**：
       - 线圈 m₁ 匀速上升，受力平衡
       - 受力：重力 m₁g 向下，绳子拉力 T 向上，安培力 F_安 向下
       - 平衡方程：**T = m₁g + F_安**
       - 强调：安培力方向向下，因为安培力阻碍线圈向上运动

    4. **步骤3（联立求解）**：
       - 由两式消去 T：m₂g = m₁g + F_安
       - 安培力：F_安 = BIl
       - 感应电流：I = E/R = Blv/R
       - 代入得：F_安 = B²l²v/R
       - 平衡方程：m₂g = m₁g + B²l²v/R

    5. **步骤4（求解速度）**：
       - 整理得：v = (m₂ - m₁)gR / (B²l²)
       - 代入数值：v = (0.14 - 0.10) × 10 × 0.10 / (0.5² × 0.20²)
       - 计算：v = 0.04 / 0.01 = **4 m/s**

    **关键理解点：**
    - 安培力的方向判断是易错点，需用左手定则仔细判断
    - 两个物体通过绳子连接，拉力 T 大小相等
    - 匀速运动意味着合力为零，这是列平衡方程的依据

    **Scene 3 教学说明：能量转化与热量计算**

    **教学目标：** 利用能量守恒定律求解线圈穿过磁场过程中产生的热量。

    **引导步骤：**

    1. **步骤0（过程回顾）**：
       - 回顾 Scene 1 中的运动过程
       - 明确：从 ab 进入磁场到线圈完全穿出磁场

    2. **步骤1（位移分析）**：
       - 第一阶段：ab 边从磁场上边界运动到下边界，位移 = l
       - 第二阶段：cd 边从磁场上边界运动到下边界，位移 = l
       - 总位移 = 2l = 0.40m
       - 强调：由于 h = l，两个阶段是连续的，中间没有间隙

    3. **步骤2（能量分析）**：
       - 线圈匀速运动，动能不变
       - 系统重力势能减少：砝码下降 2l，线圈上升 2l
       - 重力势能减少量：ΔE_p = m₂g × 2l - m₁g × 2l = (m₂ - m₁)g × 2l
       - 能量转化：重力势能减少全部转化为焦耳热

    4. **步骤3（能量方程）**：
       - 能量守恒：(m₂ - m₁)g × 2l = Q
       - 这是最简洁的解法

    5. **步骤4（计算结果）**：
       - Q = (0.14 - 0.10) × 10 × 2 × 0.20
       - Q = 0.04 × 10 × 0.40
       - Q = **0.16 J**

    **补充：方法二（焦耳定律验证）**
    - 感应电流：I = Blv/R = 0.5 × 0.20 × 4 / 0.10 = 4 A
    - 每个阶段时间：t = l/v = 0.20/4 = 0.05 s
    - 每个阶段热量：Q₁ = I²Rt = 16 × 0.10 × 0.05 = 0.08 J
    - 总热量：Q = 2Q₁ = **0.16 J**（结果一致）

    **关键理解点：**
    - 能量守恒法是解决此类问题最简洁的方法
    - 匀速运动时动能不变，重力势能减少全部转化为热量
    - 总位移是 2l 而非 l，这是易错点
    - 两种方法结果一致，可以互相验证

    **完整解答总结：**

    **第（1）问：线圈做匀速运动的速度**

    1. 线圈 ab 边切割磁感线产生感应电动势：E = Blv
    2. 感应电流：I = E/R = Blv/R
    3. ab 边受到的安培力：F_安 = BIl = B²l²v/R，方向向下
    4. 对砝码 m₂：m₂g = T（匀速下降）
    5. 对线圈 m₁：T = m₁g + F_安（匀速上升）
    6. 联立得：m₂g = m₁g + B²l²v/R
    7. 解得：v = (m₂ - m₁)gR / (B²l²)
    8. 代入数值：v = (0.14 - 0.10) × 10 × 0.10 / (0.5² × 0.20²) = **4 m/s**

    **第（2）问：产生的热量**

    1. 从 ab 进入磁场到线圈穿出磁场，线圈上升总距离为 2l
    2. 线圈匀速运动，动能不变
    3. 由能量守恒：(m₂ - m₁)g × 2l = Q
    4. 代入数值：Q = (0.14 - 0.10) × 10 × 2 × 0.20 = **0.16 J**

    **课堂讲解建议：**

    1. **先展示 Scene 1**，让学生理解物理场景和运动过程，强调两个阶段的连续性
    2. **再展示 Scene 2**，引导学生进行受力分析，注意安培力方向的判断
    3. **最后展示 Scene 3**，用能量守恒求解热量，强调总位移为 2l
    4. **易错点提醒**：
       - 安培力方向判断（左手定则）
       - 总位移是 2l 而非 l
       - 能量守恒中要考虑两个物体的重力势能变化
    5. **拓展思考**：如果 h ≠ l，情况会如何变化？让学生思考一般情况
