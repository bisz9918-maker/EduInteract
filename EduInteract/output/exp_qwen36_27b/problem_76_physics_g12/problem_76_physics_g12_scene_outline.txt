    **题目原文：**

    如图所示，在光滑水平面上有两个并排放置的木块A、B，已知m$_{A}$=0.5kg，m$_{B}$=0.3kg。现有质量m$_{0}$=0.08kg的小物块C以初速v$_{0}$=25m/s在A表面沿水平方向向右滑动，由于C与A、B间均有摩擦，C最终停在B上，B、C最后的共同速度v=2.5m/s。求：

    （1）A木块的最终速度的大小；
    （2）C物块滑离A木块的瞬时速度大小。

    **题目分析：**

    本题是典型的动量守恒问题，涉及多物体、多阶段的相互作用过程。核心物理过程分为两个阶段：

    1. **第一阶段**：C在A上滑动。C受向左摩擦力减速，A和B（并排放置）受向右摩擦力一起加速。C滑离A时，A和B具有相同速度v$_{AB}$。
    2. **第二阶段**：C在B上滑动。C继续减速，B加速，最终C停在B上，B、C达到共同速度v=2.5m/s。此时A已分离，以v$_{A}$=v$_{AB}$匀速运动。

    **整体讲解思路：**

    本题的关键是识别两个动量守恒的系统：
    - **全过程**：A+B+C系统动量守恒（水平面光滑，无外力）
    - **第二阶段**：B+C系统动量守恒（C滑上B后，A已分离）

    通过两个动量守恒方程联立求解，即可得到两个未知量v$_{A}$和v$_{C}$。

    **图示规划说明：**

    本大纲规划两个图示场景：
    - **场景1**：物理过程动态演示，分步展示三个关键状态（初始→C滑离A→最终），帮助学生建立物理过程的直观认识
    - **场景2**：动量守恒分析图，用动量柱状图展示两个阶段的动量守恒关系，辅助理解方程建立
    </TEXT_1>

    **教学说明：**

    本图示用于展示动量守恒方程的建立和求解过程。教师应按以下步骤引导：

    1. **步骤0**：让学生列出所有已知量和未知量，明确求解目标。

    2. **步骤1→步骤2**：
       - 引导学生识别全过程的动量守恒系统：A+B+C（水平面光滑，无外力）
       - 初始状态：只有C有动量，p$_{初}$ = m$_{0}$v$_{0}$ = 0.08 × 25 = 2 kg·m/s
       - 最终状态：A以v$_{A}$运动，B和C以共同速度v运动，p$_{末}$ = m$_{A}$v$_{A}$ + (m$_{B}$+m$_{0}$)v
       - 列方程：m$_{0}$v$_{0}$ = m$_{A}$v$_{A}$ + (m$_{B}$+m$_{0}$)v
       - 代入求解：2 = 0.5v$_{A}$ + 0.38×2.5 = 0.5v$_{A}$ + 0.95
       - 得：v$_{A}$ = (2-0.95)/0.5 = **2.1 m/s**

    3. **步骤3→步骤4**：
       - 引导学生识别第二阶段的动量守恒系统：B+C（C滑上B后，A已分离，B+C系统水平方向无外力）
       - 初始状态（C刚滑上B）：C动量为m$_{0}$v$_{C}$，B动量为m$_{B}$v$_{A}$（因为C滑离A时A、B速度相同）
       - 最终状态：B和C共同速度v，总动量为(m$_{B}$+m$_{0}$)v
       - 列方程：m$_{0}$v$_{C}$ + m$_{B}$v$_{A}$ = (m$_{B}$+m$_{0}$)v
       - 代入求解：0.08v$_{C}$ + 0.3×2.1 = 0.38×2.5
       - 0.08v$_{C}$ + 0.63 = 0.95
       - 得：v$_{C}$ = (0.95-0.63)/0.08 = **4 m/s**

    **关键教学点：**
    - 为什么全过程用A+B+C系统？（水平面光滑，系统不受外力）
    - 为什么第二阶段用B+C系统？（A已分离，B+C系统水平方向无外力）
    - 为什么C滑离A时A和B速度相同？（C在A上滑动时，A推B，两者一起加速）
    - 为什么A的最终速度等于C滑离A时A的速度？（C滑离A后，A不受摩擦力，水平面光滑，A匀速运动）

    **课堂讲解建议：**
    先让学生用场景1理解物理过程，再用场景2列方程求解。强调动量守恒的条件（系统不受外力或合外力为零），以及正确选择系统的重要性。

    **完整解答总结：**

    **（1）求A木块的最终速度v$_{A}$：**

    对A+B+C全过程应用动量守恒定律：
    $$m_{0}v_{0} = m_{A}v_{A} + (m_{B}+m_{0})v$$

    代入数据：
    $$0.08 \times 25 = 0.5 \times v_{A} + (0.3+0.08) \times 2.5$$
    $$2 = 0.5v_{A} + 0.95$$
    $$v_{A} = \frac{2-0.95}{0.5} = 2.1 \text{ m/s}$$

    **（2）求C物块滑离A木块的瞬时速度v$_{C}$：**

    对B+C系统（C滑上B到最终）应用动量守恒定律：
    $$m_{0}v_{C} + m_{B}v_{A} = (m_{B}+m_{0})v$$

    代入数据：
    $$0.08 \times v_{C} + 0.3 \times 2.1 = (0.3+0.08) \times 2.5$$
    $$0.08v_{C} + 0.63 = 0.95$$
    $$v_{C} = \frac{0.95-0.63}{0.08} = 4 \text{ m/s}$$

    **答案：**
    （1）A木块的最终速度大小为 **2.1 m/s**
    （2）C物块滑离A木块的瞬时速度大小为 **4 m/s**

    **教学反思建议：**
    - 本题难点在于正确选择动量守恒的系统。教师应强调：全过程选A+B+C，第二阶段选B+C。
    - 学生容易混淆C滑离A时A和B的速度关系，需结合场景1的动画反复强调。
    - 可拓展提问：如果水平面不光滑，动量还守恒吗？（不守恒，因为有外力摩擦力）
