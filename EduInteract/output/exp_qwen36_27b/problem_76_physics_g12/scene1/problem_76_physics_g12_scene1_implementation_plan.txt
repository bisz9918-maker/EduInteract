[图示主题与整合说明]
- 本图示主题：C物块在木块A、B上滑动的全过程动态演示
- 整合的步骤/概念：初始状态→C在A上滑动→C滑离A瞬间→C在B上滑动→最终C停在B上（共5个步骤，0~4）
- 教学价值：教师通过分步按钮逐步展示多阶段物理过程，帮助学生理解每个阶段的速度变化、受力情况和动量守恒关系。教师可随时回退复习任意步骤。

C物块在各步骤中的位置：
- 步骤0：(180,240)-(220,280) — 在A左端上方
- 步骤1：(300,240)-(340,280) — 在A右端上方（滑动中）
- 步骤2：(340,240)-(380,280) — 刚好离开A右端
- 步骤3：(420,240)-(460,280) — 在B上滑动

[视觉元素清单]
- 地面：黑色实线(y=360) + 45°斜线阴影(y=360~390)，贯穿画布左右
- 木块A：矩形(160,280)-(360,360)，填充#e3f2fd(10%透明度)，黑色轮廓2px
- 木块B：矩形(360,280)-(560,360)，填充#e8f5e9(10%透明度)，黑色轮廓2px；步骤4右移至(430,280)-(630,360)
- 小物块C：矩形(40×40)，填充#fff3e0(20%透明度)，黑色轮廓2px，随步骤移动
- 速度箭头：有向线段+箭头头部，带数值标签
  - v_0：蓝色#1565c0，步骤0显示
  - v_C：蓝色#1565c0，步骤1~3显示
  - v_A：绿色#2e7d32，步骤4显示
  - v_BC：红色#c62828，步骤4显示
- 摩擦力箭头：灰色#888888虚线箭头，步骤1和步骤3显示

- 颜色/样式：严格沿用spec中声明的配色规则

[分步序列]

初始状态（步骤0）：
- 显示：地面、木块A(160,280)-(360,360)、木块B(360,280)-(560,360)、小物块C(180,240)-(220,280)
- 显示：A/B/C标签、质量标注(m_A=0.5kg, m_B=0.3kg, m_0=0.08kg)
- 显示：v_0蓝色速度箭头(220,260)→(320,260)，标签"v_0=25m/s"在(260,242)
- 不显示：摩擦力箭头、v_A/v_C/v标签
- 步骤指示器："步骤 0/4"

步骤1（C在A上滑动）：
- 点击「下一步▶」
- C从(180,240)平滑移动到(300,240)（CSS transition 0.6s ease-in-out）
- 显示：C受向左摩擦力f（灰色虚线箭头从C中心向左）
- 显示：A和B受向右摩擦力f（灰色虚线箭头从A中心向右）
- 显示：v_C蓝色速度箭头（比v_0短，表示减速），标签"v_C"在箭头上方
- 隐藏：v_0箭头和"v_0=25m/s"标签
- 步骤指示器："步骤 1/4"

步骤2（C滑离A瞬间）：
- 点击「下一步▶」
- C从(300,240)平滑移动到(340,240)（刚好离开A右端）
- 隐藏：摩擦力箭头
- 高亮：三个物体的速度箭头同时显示
  - v_C蓝色箭头（C的速度，待求）
  - v_AB绿色箭头（A和B共同速度，此时A和B速度相同）
- 显示："v_C=?"标签在C速度箭头上方
- 显示："v_A=?"标签在A速度箭头上方
- 步骤指示器："步骤 2/4"

步骤3（C在B上滑动）：
- 点击「下一步▶」
- C从(340,240)平滑移动到(420,240)（滑上B）
- 显示：C受向左摩擦力f（灰色虚线箭头）
- 显示：B受向右摩擦力f（灰色虚线箭头）
- 隐藏：A的速度箭头和"v_A=?"标签（A已匀速运动）
- 步骤指示器："步骤 3/4"

步骤4（最终状态）：
- 点击「下一步▶」
- C从(420,240)平滑移动到(490,240)（停在B上）
- B从(360,280)-(560,360)平滑右移至(430,280)-(630,360)（与A分离）
- 隐藏：摩擦力箭头
- 显示：v_A绿色速度箭头从A中心(260,300)→(310,300)，标签"v_A=?"在(285,288)
- 显示：v_BC红色速度箭头从B中心(530,300)→(610,300)，标签"v=2.5m/s"在(570,288)
- 步骤指示器："步骤 4/4"

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于SVG底部(280,445)-(390,475)，点击返回上一步骤，步骤0时禁用
  - 「下一步 ▶」按钮：位于SVG底部(410,445)-(520,475)，点击进入下一步骤，步骤4时禁用
  - 步骤指示器：位于SVG底部中心(400,460)，显示"步骤 X/4"
- 教师操作流程：
  1. 页面加载显示步骤0（初始状态），教师讲解题目条件
  2. 点击「下一步▶」逐步展示C的滑动过程，每步配合讲解受力分析和速度变化
  3. 在步骤2高亮显示待求量v_C和v_A，引导学生思考
  4. 在步骤4展示最终状态，引出动量守恒方程
  5. 可随时点击「◀ 上一步」回退到任意步骤复习

[技术实现]
- JS 库选择：原生SVG（简单几何图形+CSS动画，无需额外库）
- 画布尺寸：800×500px固定
- 布局草图（ASCII）：

- 关键实现要点：
  1. 状态机设计：currentStep变量(0~4)，切换时更新C/B位置、显示/隐藏对应元素
  2. 坐标计算：C的x坐标在各步骤中分别为180/300/340/420/490，B在步骤4中x偏移+70
  3. 动画曲线：CSS transition { transform: 0.6s ease-in-out }，使用transform: translateX()移动元素
  4. 事件绑定：按钮click事件触发stepForward()/stepBackward()函数
  5. 元素显隐：通过classList.toggle('hidden')控制，.hidden { opacity: 0; pointer-events: none; }
  6. 按钮禁用：步骤0时「上一步」disabled，步骤4时「下一步」disabled
- ID命名规范：所有交互元素ID以scene1-为前缀
  - scene1-block-a, scene1-block-b, scene1-block-c
  - scene1-arrow-v0, scene1-arrow-vc, scene1-arrow-va, scene1-arrow-vbc
  - scene1-friction-c, scene1-friction-ab
  - scene1-label-a, scene1-label-b, scene1-label-c
  - scene1-label-ma, scene1-label-mb, scene1-label-m0
  - scene1-label-v0, scene1-label-va, scene1-label-vc, scene1-label-v
  - scene1-btn-prev, scene1-btn-next, scene1-step-indicator
  - scene1-ground, scene1-ground-hatch
- IIFE隔离：所有JS包裹在(function(){ ... })()中，避免全局污染
- SVG结构：
  - <defs>定义箭头marker、地面阴影pattern
  - <g id="scene1-ground">地面线和阴影
  - <g id="scene1-blocks">木块A、B、C（含标签）
  - <g id="scene1-arrows">速度箭头和摩擦力箭头
  - <g id="scene1-labels">数值标签
  - <g id="scene1-controls">按钮和步骤指示器
