**题目原文：**

如图1所示，平行金属板A和B的距离为d，它们的右端安放着垂直金属板的靶 MN．现在A、B板上加上如图2所示的方波形电压，t=O时A板比B板的电势高，电压的正向值为U$_{0}$，反向值也为U$_{0}$，现有由质量为m的带正电且电荷量为q的粒子组成的粒子束，从AB的中点O以平行于金属板方向OO′的某一初速射入．设粒子能全部打在靶MN上，而且所有粒子在AB间的飞行时间均为T，不计重力影响，试问：

（1）在距靶MN的中心O′点多远的范围内有粒子击中？

（2）要使粒子能全部打在靶MN上，电压U$_{0}$的数值应满足什么条件？（写出U$_{0}$，m、d、q，T的关系式即可）．

（3）电场力对每个击中靶MN的带电粒子所做的总功是否相等？若相等，请证明并求出此功的数值；若不相等，求出此功的数值范围．

**题目分析：**

本题是带电粒子在周期性方波电场中的偏转问题，核心在于：
- 粒子水平方向匀速运动（飞行时间均为T）
- 粒子竖直方向受周期性电场力，加速度大小为 a = qU₀/(md)
- 电压周期为T，正向（A板电势高）持续2T/3，反向持续T/3
- 不同时刻进入的粒子，其竖直方向运动轨迹不同

**整体讲解思路：**

1. 首先展示物理装置和电压波形，帮助学生建立物理模型
2. 然后分析典型时刻（t=0、t=T/3、t=2T/3）进入的粒子的运动轨迹，找出最大偏转
3. 最后总结击中范围、U₀条件和电场力做功

**图示规划说明：**

共规划3个场景：
- Scene 1：物理装置与电压波形（建立模型）
- Scene 2：粒子运动轨迹分析（核心推导）
- Scene 3：击中范围与结论总结（回答问题）

**Scene 2 教学说明：**

本图示是解题的核心，教师应按以下步骤引导学生分析：

1. **分析t=0时刻进入的粒子**：
   - 0~2T/3阶段：电场向下，加速度a=qU₀/(md)向下
     - v_y(2T/3) = a·(2T/3) = 2qU₀T/(3md)
     - y(2T/3) = ½a(2T/3)² = 2qU₀T²/(9md)
   - 2T/3~T阶段：电场向上，加速度-a向上
     - v_y(T) = 2qU₀T/(3md) - a·(T/3) = qU₀T/(3md)
     - y(T) = 2qU₀T²/(9md) + [2qU₀T/(3md)]·(T/3) - ½a(T/3)² = 7qU₀T²/(18md)

2. **分析t=T/3时刻进入的粒子**：
   - 0~T/3：向下加速；T/3~2T/3：向上加速；2T/3~T：向下加速
   - 最终偏转 y = qU₀T²/(6md) = 3qU₀T²/(18md)

3. **分析t=2T/3时刻进入的粒子**：
   - 0~T/3：向上加速；T/3~T：向下加速
   - 最终偏转 y = -qU₀T²/(18md)（负号表示向上偏转）

4. **对比三条轨迹**：
   - 最大向下偏转：7qU₀T²/(18md)
   - 最大向上偏转：qU₀T²/(18md)
   - 所有粒子末竖直速度相同：v_y = qU₀T/(3md)

**关键结论**：
- 击中范围从O'上方qU₀T²/(18md)到下方7qU₀T²/(18md)
- 总范围宽度：8qU₀T²/(18md) = 4qU₀T²/(9md)

**Scene 3 教学说明：**

本图示总结三个问题的答案，教师应按以下步骤讲解：

**问题（1）：击中范围**

粒子击中靶的范围是从O'点上方 $\frac{qU_0T^2}{18md}$ 到下方 $\frac{7qU_0T^2}{18md}$。

总范围宽度为：$\frac{8qU_0T^2}{18md} = \frac{4qU_0T^2}{9md}$

**问题（2）：U₀条件**

要使粒子全部打在靶上，最大偏转不能超过d/2：

$\frac{7qU_0T^2}{18md} \leq \frac{d}{2}$

解得：$U_0 \leq \frac{9md^2}{7qT^2}$

**问题（3）：电场力做功**

所有粒子在电场中飞行时间均为T，且电压周期也为T。

通过分析发现，所有粒子的末竖直速度均为 $v_y = \frac{qU_0T}{3md}$。

根据动能定理，电场力做功等于动能变化：

$W = \Delta E_k = \frac{1}{2}mv_y^2 = \frac{1}{2}m\left(\frac{qU_0T}{3md}\right)^2 = \frac{q^2U_0^2T^2}{18md^2}$

因此，电场力对每个粒子的做功**相等**，数值为 $\frac{q^2U_0^2T^2}{18md^2}$。

**课堂讲解建议：**

1. 强调"电压周期=飞行时间"这一关键条件，它保证了所有粒子经历相同的电压变化模式
2. 引导学生理解为什么不同时刻进入的粒子末速度相同（加速度时间积分相同）
3. 电场力做功相等是一个重要结论，体现了能量守恒的深刻内涵
