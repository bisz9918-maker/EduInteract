[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位置(200,455)，尺寸110×30px，点击回退到前一步骤，步骤0时不可用
  - 「步骤 X/4」指示文本：位置(370,455)，显示当前步骤编号
  - 「下一步 ▶」按钮：位置(490,455)，尺寸110×30px，点击进入下一步骤，步骤4时不可用
- 教师操作流程：
  1. 图示加载后显示步骤0（靶MN放大图+击中范围），教师可先讲解粒子偏转的直观现象
  2. 点击「下一步」进入步骤1，右侧出现答案1框，教师讲解击中范围的计算公式
  3. 点击「下一步」进入步骤2，出现答案2框，教师讲解电压U₀的约束条件推导
  4. 点击「下一步」进入步骤3，出现答案3框，教师讲解电场力做功的相等性证明
  5. 点击「下一步」进入步骤4，三个答案框同时高亮并显示对勾，教师总结三个问题的最终答案
  6. 讲解过程中可随时点击「上一步」回退复习任意步骤

[技术实现]
- JS 库选择：
  - 原生SVG：绘制靶MN、标注线、圆点、矩形等几何图形（轻量、精确控制）
  - MathJax 3（CDN）：渲染公式中的分数、下标等数学符号（如 qU₀T²/(18md)）
  - 原因：SVG适合静态几何图形，MathJax专为数学公式设计，两者结合满足本场景需求
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +------------------------------------------------------------------+
  |  左侧区域(0~280px)              右侧区域(280~800px)               |
  |                                                                  |
  |   M                      [问题1：击中范围]  ← 步骤1出现           |
  |    |                      ┌─────────────────┐                    |
  |    |  P_max上  y_max上    | y_max上=...      |                    |
  |    |  ●───────┤          | y_max下=...      |                    |
  |    |          │          | 总范围=...       |                    |
  |    |  O' ●────┤          └─────────────────┘                    |
  |    |          │                                                 |
  |    |          │          [问题2：电压条件]  ← 步骤2出现           |
  |    |          │          ┌─────────────────┐                    |
  |    |          │          | 最大偏转≤d/2    |                    |
  |    |          │          | U₀≤9md²/(7qT²) |                    |
  |    |          │          └─────────────────┘                    |
  |    |          │                                                 |
  |    |          │          [问题3：电场力做功] ← 步骤3出现          |
  |    |          │          ┌─────────────────┐                    |
  |    |          │          | 末速度相同       |                    |
  |    |          │          | W=...           |                    |
  |    |          │          └─────────────────┘                    |
  |    |  P_max下  y_max下                                         |
  |    |  ●───────┤                                                 |
  |    |          │                                                 |
  |    N          │                                                 |
  |                                                                  |
  |  ───────────────────────────────────────────────────────────────  |
  |              [◀上一步]    步骤 X/4    [下一步▶]                   |
  |                          y=440~490                               |
  +------------------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `currentStep`（0~4）管理当前步骤，每个步骤对应一个渲染函数 `renderStep(n)`
  2. 淡入动画：答案框出现时使用CSS transition `opacity: 0→1`，持续时间0.4s，ease-in
  3. 高亮动画：步骤4时三个答案框边框加粗+填充色加深，使用CSS transition `stroke-width: 2→3px`
  4. 脉冲动画：步骤4时击中范围区域透明度循环，使用 `@keyframes pulse` 动画
  5. 按钮状态管理：步骤0时「上一步」disabled，步骤4时「下一步」disabled，使用CSS类 `.disabled`
  6. MathJax渲染：每个答案框内的公式使用独立的 `<span class="mathjax-formula">` 容器，步骤切换时调用 `MathJax.typesetPromise()` 重新渲染
  7. 坐标计算：所有元素坐标基于布局坐标表硬编码，不依赖动态计算
  8. 事件绑定：按钮点击事件绑定到 `handlePrev()` 和 `handleNext()` 函数，更新 `currentStep` 后调用 `renderStep()`

- ID 命名规范：所有交互元素ID以 `scene3-` 为前缀
  - `scene3-target-mn`：靶MN线段
  - `scene3-center-o`：中心点O'
  - `scene3-hit-range`：击中范围填充区域
  - `scene3-pmax-top`：P_max上标记点
  - `scene3-pmax-bottom`：P_max下标记点
  - `scene3-answer-box-1`：答案1框
  - `scene3-answer-box-2`：答案2框
  - `scene3-answer-box-3`：答案3框
  - `scene3-btn-prev`：上一步按钮
  - `scene3-btn-next`：下一步按钮
  - `scene3-step-indicator`：步骤指示文本
  - `scene3-math-1`、`scene3-math-2`、`scene3-math-3`：MathJax公式容器

- IIFE 隔离：所有JS代码包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染
- CDN引入：
  ```html
  <script src="https://cdn.jsdelivr.net/npm/mathjax@3/es5/tex-mml-chtml.js" defer></script>
  ```
