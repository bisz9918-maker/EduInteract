[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于底部左侧 (100,450)-(250,480)，点击回退到上一步骤，步骤0时禁用
  - 「步骤 X/4」指示：位于底部居中 (350,455)-(450,475)，显示当前步骤编号
  - 「下一步 ▶」按钮：位于底部右侧 (550,450)-(700,480)，点击进入下一步骤，步骤3时禁用
- 教师操作流程：
  1. 图示加载后显示步骤0（初始状态），教师可先介绍题目背景
  2. 点击「下一步」进入步骤1，聚焦物块m的受力分析，讲解摩擦力计算
  3. 点击「下一步」进入步骤2，聚焦木板M的受力分析，讲解牛顿第三定律
  4. 点击「下一步」进入步骤3，综合两个加速度公式，推导出临界条件 F > 4N
  5. 可随时点击「上一步」回退复习任意步骤

[技术实现]
- JS 库选择：原生 SVG（简单几何图形和箭头绘制，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  +--------------------------------------------------+
  |                    图示区 800×440                  |
  |                                                   |
  |  [物理场景区 60~520]    [公式区 540~760]          |
  |  地面+木板+物块+力箭头    公式框1                  |
  |  (步骤0-3逐步展开)       公式框2                  |
  |                       公式框3                     |
  |                                                   |
  +--------------------------------------------------+
  |              控件栏 800×60 (y=440~500)             |
  |  [◀上一步]    步骤 0/4    [下一步▶]               |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 `currentStep`（0~3）管理当前步骤，每个步骤对应一组可见元素
  2. 元素显隐：通过 CSS class `.step-N` 控制元素可见性，步骤N时显示 `.step-0` ~ `.step-N` 的元素
  3. 箭头绘制：使用 SVG `<line>` + `<polygon>`（箭头头部）组合
  4. 公式框：使用 SVG `<rect>`（圆角）+ `<text>` 多行文本
  5. 高亮效果：通过改变 stroke-width 和 stroke-color 实现
  6. 按钮交互：点击事件切换 `currentStep`，更新按钮状态和元素可见性
  7. 动画过渡：使用 CSS transition 实现元素淡入效果（opacity 0→1，duration 0.3s）
- ID 命名规范：所有交互元素 ID 以 `scene1-` 为前缀，如 `scene1-btn-prev`、`scene1-btn-next`、`scene1-step-indicator`、`scene1-block-m`、`scene1-board-M`、`scene1-formula-box-1` 等
- IIFE 隔离：所有 JS 代码包裹在 `(function() { ... })()` 中，避免全局污染
