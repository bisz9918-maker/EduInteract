    **题目原文：**

    一个大物块甲，先后两次分别在小物块乙和小物块丙的作用下，其上表面恰好与水面相平，甲、乙之间用绳连接，如图所示。则下列说法错误的是（）

    A. 两种情况下，甲物块所受浮力相等

    B. 绳的拉力与丙物块的重力大小相等

    C. 乙物块的密度比水小

    D. 乙物块的质量比丙物块大

    **题目分析：**

    本题是初中物理浮力综合题，考查阿基米德原理、物体浮沉条件及受力平衡分析。题目给出两种情景：

    - **左图**：物块甲漂浮，上表面与水面齐平，甲下方用细绳悬挂物块乙，乙完全浸没在水中
    - **右图**：物块甲漂浮，上表面与水面齐平，甲上方放置物块丙，丙在水面以上

    关键条件：两种情况下甲的上表面**恰好与水面相平**，意味着甲排开水的体积相同，因此甲所受浮力相等。

    **整体讲解思路：**

    1. 首先引导学生观察两种情景的共同点（甲上表面与水面齐平）和不同点（乙在下方悬挂 vs 丙在上方放置）
    2. 通过浮力公式 F_浮 = ρ_水·g·V_排 得出甲在两种情况下浮力相等
    3. 分别对两种情况进行受力分析，建立平衡方程
    4. 联立方程推导出各物理量之间的关系，逐一判断选项

    **图示规划：**

    - **场景1**：题目情景对比图，同时展示左右两种情况，通过分步导航高亮关键条件
    - **场景2**：受力分析图，分别展示两种情景下各物块的受力情况，通过分步导航逐步添加力的标注和平衡方程
    </TEXT_1>

    **场景1教学说明：**

    本场景用于帮助学生建立对题目情景的直观认识，重点引导学生发现两种情景的**共同条件**。

    **讲解要点：**

    1. 步骤0：让学生整体观察两幅图，提问"两幅图有什么相同和不同之处？"

    2. 步骤1：高亮水面线，强调水面是参考基准，两种情况水面在同一水平线上

    3. 步骤2：这是**最关键的一步**——高亮甲的上表面与水面重合。引导学生得出：甲排开水的体积 V_排 在两种情况下相同。根据阿基米德原理：

        F_浮 = ρ_水 · g · V_排

        因为 V_排 相同，所以甲在两种情况下所受浮力相等。**这直接验证了选项A正确。**

    4. 步骤3：对比乙和丙的位置差异——乙在水中（受浮力），丙在水面上（不受浮力）。这是后续受力分析的重要区别。

    5. 步骤4：总结关键结论，为下一场景的受力分析做铺垫。

    **场景2教学说明：**

    本场景是解题的核心，通过逐步受力分析，推导出各选项的正误。

    **讲解要点：**

    1. **步骤0-1：左图甲的受力分析**

       甲受到三个力：重力 G_甲（向下）、浮力 F_浮甲（向上）、绳子对甲的拉力 T（向下）。

       平衡方程：**F_浮甲 = G_甲 + T** ……①

    2. **步骤2：左图乙的受力分析**

       乙受到三个力：重力 G_乙（向下）、浮力 F_浮乙（向上）、绳子对乙的拉力 T（向上）。

       平衡方程：**G_乙 = F_浮乙 + T**，即 **T = G_乙 - F_浮乙** ……②

    3. **步骤3：右图甲+丙整体的受力分析**

       将甲和丙视为整体，受到总重力 (G_甲 + G_丙)（向下）和浮力 F_浮甲'（向上）。

       平衡方程：**F_浮甲' = G_甲 + G_丙** ……③

    4. **步骤4：联立推导——判断选项B**

       由场景1已知 F_浮甲 = F_浮甲'（甲排开水体积相同）。

       联立①和③：G_甲 + T = G_甲 + G_丙

       得：**T = G_丙**

       → **选项B正确**（绳的拉力等于丙的重力）

    5. **步骤5：进一步推导——判断选项D**

       由②和 T = G_丙：G_丙 = G_乙 - F_浮乙

       即：**G_乙 = G_丙 + F_浮乙**

       因为 F_浮乙 > 0（乙浸没在水中），所以 G_乙 > G_丙，即 **m_乙 > m_丙**

       → **选项D正确**

    6. **步骤6：分析乙的密度——判断选项C**

       绳子对乙提供向上的拉力 T > 0，由②：T = G_乙 - F_浮乙 > 0

       即 G_乙 > F_浮乙

       代入：ρ_乙 · V_乙 · g > ρ_水 · V_乙 · g

       得：**ρ_乙 > ρ_水**

       即乙的密度**大于**水的密度，而非小于。

       → **选项C错误，这就是本题答案！**

    **课堂总结：**

    本题的关键突破口是"甲上表面与水面相平"这一条件，由此得出甲在两种情况下浮力相等，进而通过受力分析建立方程组，逐一验证选项。学生容易在选项C上出错，误认为乙能"拉"甲下沉说明乙密度小，实际上乙密度大才能提供足够的拉力。
