    **题目原文：**

    如图所示，质量分别为3m、2m、m的三个小球A、B、C用两根长为L的轻绳相连，置于倾角为30°、高为L的固定光滑斜面上，A球恰能从斜面顶端外竖直落下，弧形挡板使小球只能竖直向下运动，碰撞过程中没有动能损失，小球落地后均不再反弹．由静止开始释放它们，不计所有摩擦，求：
    （1）A球刚要落地时的速度大小
    （2）C球刚要落地时的速度大小．
    （3）在B球运动过程中，两绳对B球做的总功为多少．

    **题目分析：**

    本题是一道多体连接系统的能量守恒与功的综合题，核心在于理解三个阶段的运动过程：

    1. **第一阶段**：A球从斜面顶端竖直下落距离L，同时B、C沿斜面向上各移动距离L。此时A落地。系统为A+B+C。
    2. **第二阶段**：B球从斜面顶端竖直下落距离L，同时C沿斜面向上移动距离L。此时B落地。系统为B+C。
    3. **第三阶段**：C球从斜面顶端竖直下落距离L。此时C落地。系统为C单独。

    斜面倾角30°，高为L，故斜面长度为 $L/\sin 30° = 2L$。初始时A在顶端，B在斜面中点，C在底端，正好两绳各长L铺满斜面。

    **整体讲解思路：**

    - 先通过图示让学生直观理解三个阶段的运动过程，明确每个阶段哪些球参与运动、运动方向如何
    - 对每个阶段列能量守恒方程求解速度
    - 对第三问，用动能定理分析B球全程的受力做功

    **图示规划：**

    - **Scene 1**：三阶段运动过程总览（分步导航），展示每个阶段小球位置变化、运动方向、系统组成及能量守恒方程
    - **Scene 2**：B球的受力与功分析（分步导航），聚焦B球在两个阶段的受力情况，用动能定理求解绳子对B做的总功

    **Scene 1 教学说明：三阶段运动过程与能量守恒**

    本图示帮助学生直观理解三球系统的三阶段运动过程，并配合能量守恒求解各阶段末速度。

    **讲解要点：**

    1. **引导学生观察初始状态**：三球用轻绳相连铺满斜面，A恰在顶端可竖直下落。斜面高L、倾角30°，故斜面长2L，两绳各长L正好铺满。

    2. **第一阶段（点击"下一步"）**：
    - A竖直下落L，B沿斜面上移L，C沿斜面上移L
    - 系统为A+B+C，机械能守恒
    - A重力势能减少：$3mgL$
    - B重力势能增加：$2mg \cdot L \sin 30° = mgL$
    - C重力势能增加：$mg \cdot L \sin 30° = \frac{1}{2}mgL$
    - 能量守恒：$3mgL = mgL + \frac{1}{2}mgL + \frac{1}{2}(6m)v_1^2$
    - 解得：$v_1 = \sqrt{\frac{gL}{2}}$

    3. **第二阶段（点击"下一步"）**：
    - A已落地退出系统，B竖直下落L，C沿斜面上移L
    - 系统为B+C，机械能守恒
    - B重力势能减少：$2mgL$
    - C重力势能增加：$mg \cdot L \sin 30° = \frac{1}{2}mgL$
    - 初动能：$\frac{1}{2}(3m)v_1^2 = \frac{3}{4}mgL$
    - 能量守恒：$2mgL - \frac{1}{2}mgL + \frac{3}{4}mgL = \frac{1}{2}(3m)v_2^2$
    - 解得：$v_2 = \sqrt{\frac{3gL}{2}}$

    4. **第三阶段（点击"下一步"）**：
    - B已落地退出系统，C竖直下落L
    - 系统为C单独，机械能守恒
    - C重力势能减少：$mgL$
    - 初动能：$\frac{1}{2}mv_2^2 = \frac{3}{4}mgL$
    - 能量守恒：$mgL + \frac{3}{4}mgL = \frac{1}{2}mv_3^2$
    - 解得：$v_3 = \sqrt{\frac{7gL}{2}}$

    **课堂提示：** 强调每个阶段的"系统"不同，初动能要继承上一阶段的末速度。弧形挡板的作用是保证球从斜面运动转为竖直下落时不损失动能。

    **Scene 2 教学说明：B球受力与功的分析**

    本图示聚焦第三问——求两绳对B球做的总功。核心方法是**动能定理**。

    **讲解要点：**

    1. **明确思路**：对B球用动能定理，$W_{\text{总}} = \Delta E_k$。B球受三个力：重力、绳AB的拉力、绳BC的拉力。总功 = 重力功 + 两绳拉力功。

    2. **B球全程状态**：
    - 初态：静止，$v = 0$
    - 末态：B落地瞬间，速度为第二阶段末速度 $v_2 = \sqrt{3gL/2}$
    - 动能变化：$\Delta E_k = \frac{1}{2}(2m)v_2^2 - 0 = m \cdot \frac{3gL}{2} = \frac{3}{2}mgL$

    3. **重力对B做的功（分两阶段）**：
    - 第一阶段：B沿斜面上移L，重力做负功 $W_{g1} = -2mg \cdot L \sin 30° = -mgL$
    - 第二阶段：B竖直下落L，重力做正功 $W_{g2} = 2mg \cdot L = 2mgL$
    - 重力总功：$W_g = W_{g1} + W_{g2} = -mgL + 2mgL = mgL$

    4. **动能定理列式**：
    - $W_g + W_{\text{绳}} = \Delta E_k$
    - $mgL + W_{\text{绳}} = \frac{3}{2}mgL$
    - $W_{\text{绳}} = \frac{1}{2}mgL$

    **课堂提示：**
    - 强调不需要分别求出两根绳的拉力（实际上拉力是变力，很难直接积分求功），动能定理巧妙避开了这个难点
    - 引导学生思考：为什么两绳对B做的总功是正值？（因为绳AB在第一阶段对B做正功，帮助B上滑；绳BC在第一阶段对B做负功，在第二阶段也对B做负功，但总效果是正功）
    - 可以追问：如果分别求每根绳的功，需要用什么方法？（需要分析系统加速度和张力，复杂得多）

    **完整解答总结：**

    **（1）A球刚要落地时的速度大小：**

    第一阶段，系统A+B+C机械能守恒：
    $$3mgL = 2mg \cdot L \sin 30° + mg \cdot L \sin 30° + \frac{1}{2}(6m)v_1^2$$
    $$3mgL = mgL + \frac{1}{2}mgL + 3mv_1^2$$
    $$v_1 = \sqrt{\frac{gL}{2}}$$

    **（2）C球刚要落地时的速度大小：**

    第二阶段，系统B+C机械能守恒：
    $$2mgL - mg \cdot L \sin 30° + \frac{1}{2}(3m)v_1^2 = \frac{1}{2}(3m)v_2^2$$
    $$\frac{3}{2}mgL + \frac{3}{4}mgL = \frac{3}{2}mv_2^2$$
    $$v_2 = \sqrt{\frac{3gL}{2}}$$

    第三阶段，C单独机械能守恒：
    $$mgL + \frac{1}{2}mv_2^2 = \frac{1}{2}mv_3^2$$
    $$mgL + \frac{3}{4}mgL = \frac{1}{2}mv_3^2$$
    $$v_3 = \sqrt{\frac{7gL}{2}}$$

    **（3）两绳对B球做的总功：**

    对B球用动能定理：
    $$W_g + W_{\text{绳}} = \Delta E_k$$
    $$mgL + W_{\text{绳}} = \frac{1}{2}(2m)v_2^2 = \frac{3}{2}mgL$$
    $$W_{\text{绳}} = \frac{1}{2}mgL$$

    **课堂讲解建议：**
    - 先用Scene 1让学生建立三阶段运动的直观认识，再逐阶段列能量方程
    - 第三问先用Scene 2展示动能定理思路，强调"不求拉力直接求功"的巧妙之处
    - 可引导学生总结：多体连接问题中，整体用能量守恒求速度，个体用动能定理求功，是常用策略
