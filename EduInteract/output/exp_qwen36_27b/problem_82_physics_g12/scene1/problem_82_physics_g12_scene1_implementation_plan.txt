[图示主题与整合说明]
- 本图示主题：三球连接系统三阶段运动过程与能量守恒分析
- 整合的步骤/概念：初始状态展示 → 第一阶段（A下落，B、C上滑）→ 第二阶段（B下落，C上滑）→ 第三阶段（C下落）→ 各阶段能量守恒方程与速度结果
- 教学价值：教师可通过分步按钮逐步推进，清晰展示每个运动阶段中系统组成变化、小球位置变化、能量守恒方程的建立与求解结果。已落地小球以灰色淡化处理，活跃系统用绿色虚线框圈出，帮助学生理解"系统"概念的动态变化。

[分步序列]

步骤0（初始状态）：
- 显示斜面（三角形轮廓）、地面线、弧形挡板、角度弧线
- 球A(3m) 在斜面顶端 (392,200)，蓝色填充
- 球B(2m) 在斜面中点 (236,290)，蓝色填充
- 球C(m) 在斜面底端 (80,380)，蓝色填充
- 绳A-B 连接 A-B，绳B-C 连接 B-C
- 所有几何标注显示：L(绳A-B)、L(绳B-C)、L(斜面高)、30°、2L(斜面长)
- 球标签：A(3m)、B(2m)、C(m)
- 信息面板：标题"初始状态"，系统说明"三球静止，即将释放"，无方程无结果
- 无运动箭头，无系统虚线框

步骤1（第一阶段：A下落，B、C上滑）：
- 点击「下一步」触发
- 球A 从 (392,200) 竖直下落到 (392,380)，动画 0.8s ease-in-out
- 球B 从 (236,290) 沿斜面上移到 (392,200)，动画 0.8s ease-in-out
- 球C 从 (80,380) 沿斜面上移到 (236,290)，动画 0.8s ease-in-out
- 绳A-B 和 绳B-C 跟随球移动
- 三球均为蓝色填充（活跃）
- 系统虚线框出现：矩形 (210,175)-(410,400)，绿色虚线
- 运动箭头出现：
  - 箭头A：(392,220)→(392,360)，竖直向下
  - 箭头B：(250,280)→(378,210)，沿斜面向上
  - 箭头C：(95,370)→(221,300)，沿斜面向上
- 信息面板：
  - 标题："第一阶段"
  - 系统说明："系统：A + B + C"
  - 方程框显示：3mgL − 2mgL·sin30° − mgL·sin30° = ½·6m·v₁²
  - 结果：v₁ = √(gL/2)（红色加粗）

步骤2（第二阶段：B下落，C上滑）：
- 点击「下一步」触发
- 球A 从 (392,380) 左移到 (345,380)，变为灰色（已落地），动画 0.5s
- 球B 从 (392,200) 竖直下落到 (392,380)，动画 0.8s ease-in-out
- 球C 从 (236,290) 沿斜面上移到 (392,200)，动画 0.8s ease-in-out
- 绳A-B 隐藏（A已落地，绳断开）
- 绳B-C 跟随球移动
- 球A 灰色（#888888，透明度10%），球B和球C 蓝色填充（活跃）
- 系统虚线框更新：矩形 (370,185)-(415,400)，绿色虚线
- 运动箭头更新：
  - 箭头A 隐藏
  - 箭头B：(392,220)→(392,360)，竖直向下
  - 箭头C：(250,280)→(378,210)，沿斜面向上
- 信息面板：
  - 标题："第二阶段"
  - 系统说明："系统：B + C"
  - 方程框显示：2mgL − mgL·sin30° = ½·3m·(v₂² − v₁²)
  - 结果：v₂ = √(3gL/2)（红色加粗）

步骤3（第三阶段：C下落）：
- 点击「下一步」触发
- 球B 从 (392,380) 左移到 (310,380)，变为灰色（已落地），动画 0.5s
- 球C 从 (392,200) 竖直下落到 (392,380)，动画 0.8s ease-in-out
- 绳B-C 隐藏（B已落地，绳断开）
- 球A和球B 灰色，球C 蓝色填充（活跃）
- 系统虚线框更新：矩形 (375,365)-(410,400)，绿色虚线
- 运动箭头更新：
  - 箭头B 隐藏
  - 箭头C：(392,220)→(392,360)，竖直向下
- 信息面板：
  - 标题："第三阶段"
  - 系统说明："系统：C"
  - 方程框显示：mgL = ½·m·(v₃² − v₂²)
  - 结果：v₃ = √(7gL/2)（红色加粗）

逐对间距检查：
- "A(3m)"(415,185) 与 "L"斜面高(415,290)：间距=105px → 无冲突 ✓
- "A(3m)"(415,185) 与 "L"绳A-B(315,225)：间距=√(100²+40²)≈108px → 无冲突 ✓
- "B(2m)"(215,270) 与 "2L"(250,245)：间距=√(35²+25²)≈43px → 无冲突 ✓
- "B(2m)"(215,270) 与 "L"绳B-C(155,325)：间距=√(60²+55²)≈82px → 无冲突 ✓
- "L"绳A-B(315,225) 与 "2L"(250,245)：间距=√(65²+20²)≈68px → 无冲突 ✓
- "L"绳B-C(155,325) 与 "30°"(115,365)：间距=√(40²+40²)≈57px → 无冲突 ✓
- "C(m)"(55,395) 与 "30°"(115,365)：间距=√(60²+30²)≈67px → 无冲突 ✓
- "L"斜面高(415,290) 与 "L"绳A-B(315,225)：间距=√(100²+65²)≈119px → 无冲突 ✓
- "2L"(250,245) 与 "L"绳B-C(155,325)：间距=√(95²+80²)≈124px → 无冲突 ✓

结论：所有标签间距均 ≥ 40px，无冲突。

动态标签（跟随球移动）冲突检查：
- 步骤1：A(392,380)→标签(415,365)，B(392,200)→标签(370,180)，C(236,290)→标签(215,310)
  - "A(3m)"(415,365) 与 "L"斜面高(415,290)：间距=75px → 无冲突 ✓
  - "B(2m)"(370,180) 与 "A(3m)"(415,365)：间距=√(45²+185²)≈191px → 无冲突 ✓
- 步骤2：A(345,380)→标签(368,365)灰色，B(392,380)→标签(370,365)，C(392,200)→标签(370,180)
  - "A(3m)"(368,365) 与 "B(2m)"(370,365)：间距=2px → 冲突！
  - 解决方案：步骤2中A已落地灰色，将A标签移到(325,365)（左上方），B标签移到(415,365)（右上方）
  - 调整后："A(3m)"(325,365) 与 "B(2m)"(415,365)：间距=90px → 无冲突 ✓
- 步骤3：A(345,380)→标签(325,365)灰色，B(310,380)→标签(290,365)灰色，C(392,380)→标签(415,365)
  - "A(3m)"(325,365) 与 "B(2m)"(290,365)：间距=35px → 无冲突 ✓
  - "B(2m)"(290,365) 与 "C(m)"(415,365)：间距=125px → 无冲突 ✓

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于 SVG 内底部 (250,450)，100×36px，点击回退到上一步骤，步骤0时禁用
  - 「下一步 ▶」按钮：位于 SVG 内底部 (450,450)，100×36px，点击推进到下一步骤，步骤3时禁用
- 教师操作流程：
  1. 页面加载显示初始状态（步骤0），三球静止在斜面上
  2. 教师点击「下一步 ▶」进入第一阶段，观察A球下落、B/C球上滑的动画过程，同时右侧显示能量方程和速度结果
  3. 继续点击「下一步 ▶」进入第二阶段，A球变灰（已落地），B球下落、C球上滑
  4. 继续点击「下一步 ▶」进入第三阶段，B球变灰，C球单独下落
  5. 如需回顾，点击「◀ 上一步」回退到任意步骤
  6. 教师可配合讲解，强调每个阶段的"系统"变化（虚线框范围缩小）和能量守恒方程的差异

[技术实现]
- JS 库选择：
  - 原生 SVG：绘制斜面、小球、绳子、箭头等所有几何图形，轻量且精确控制
  - MathJax 3（CDN）：渲染信息面板中的数学公式（含分数、根号、希腊字母等）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+-----------------------------------+
  |                                                  |                                   |
  |         弧形挡板  A(3m)                          |      信息面板区域                 |
  |            ___                                    |                                   |
  |           /   \                                  |  阶段标题                         |
  |          /     \                                 |  系统说明                         |
  |         /  B(2m)\                                |                                   |
  |        /         \                               |  +---------------------------+   |
  |       /           \                              |  |  能量守恒方程             |   |
  |      /  C(m)       \                             |  |  (MathJax渲染)            |   |
  |     /_______________\                            |  +---------------------------+   |
  |    /  30°           |                            |                                   |
  |   /_________________|___________________________|  速度结果 (红色加粗)              |

  |                      |                            |                                   |
  +--------------------------------------------------+-----------------------------------+
  |                                                  |                                   |
  |              [◀ 上一步]              [下一步 ▶]  |                                   |
  +--------------------------------------------------+-----------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：
     - 当前步骤 state = 0~3
     - 每个步骤定义：球位置、球颜色、绳子可见性、系统框位置、运动箭头、信息面板内容
     - 状态切换函数 renderStep(step) 统一处理所有视觉更新
  2. 坐标计算：
     - 斜面几何：左下角(80,380)，右上角(392,200)，斜边长=√(312²+180²)=360px=2L
     - L_pixel = 180px（斜面高），绳长 = 180px
     - 球位置按步骤预定义，无需实时物理计算
  3. 动画曲线：
     - 球移动：CSS transition transform 0.8s ease-in-out
     - 已落地球偏移：CSS transition 0.5s ease
     - 系统框/箭头淡入淡出：CSS transition opacity 0.4s ease
     - 信息面板内容切换：先淡出(0.2s)→更新内容→淡入(0.3s)
  4. 事件绑定：
     - 按钮点击事件绑定到 handlePrev() 和 handleNext()
     - 步骤0时禁用"上一步"，步骤3时禁用"下一步"
     - 按钮禁用状态用 opacity=0.4 + pointer-events:none
  5. MathJax 渲染：
     - 使用 MathJax.typesetPromise() 在每次步骤切换后重新渲染方程区域
     - 方程内容预定义为 LaTeX 字符串数组
  6. SVG marker 定义：
     - 在 <defs> 中定义箭头头部 marker（蓝色 #1565c0）
     - 运动箭头线段使用 marker-end 属性
