[图示主题与整合说明]
- 本图示主题：导体棒运动过程的速度变化与能量守恒分析
- 整合的步骤/概念：v-t速度-时间图像 → 能量转化关系图 → 电量与位移关系推导 → 能量守恒方程与热量分配计算

[分步序列]

初始状态（步骤0）：v-t速度-时间图像
- 显示元素：v-t坐标图（横轴t、纵轴v、原点O）
- v-t曲线从(120,370)出发，斜率逐渐减小，渐近于y=170（对应v=2m/s）
- 水平虚线标注渐近线v=2m/s
- 标签：t、v、O、0、v=2m/s
- 视觉效果：曲线用#1565c0蓝色2.5px绘制，渐近线用同色1px虚线
- 教师讲解：导体棒从静止开始加速，加速度逐渐减小，最终达到稳定速度v=2m/s

步骤1：能量转化关系图
- 隐藏步骤0元素，显示能量流向图
- 左侧Fx输入框（红色）：标注"恒力做功Fx"
- 箭头从Fx框指向右侧三个输出框
- 三个输出框垂直排列：
  - 上方：动能增量½mv²（蓝色框）
  - 中间：总焦耳热Q_总（绿色框）
  - 下方：摩擦生热fx（灰色框）
- 教师讲解：恒力F做功Fx转化为三部分——动能增量、回路焦耳热、摩擦生热

步骤2：电量与位移关系推导
- 隐藏步骤1元素，显示电量推导大框
- 框内公式推导：
  - q = ΔΦ/(R+r)
  - = BLx/(R+r)
  - 代入：2.8C = 1T × 1m × x / (0.8Ω + 0.2Ω)
  - 结果：x = 2.8m（加粗高亮）
- 教师讲解：通过电量q与磁通量变化的关系，求出导体棒的位移x=2.8m

步骤3：能量守恒方程与热量分配（最终步骤）
- 隐藏步骤2元素，显示：
  - 上方左侧：能量守恒方程框（红色）
    - Fx = ½mv² + Q_总 + fx
    - 代入：3×2.8 = ½×0.2×2² + Q_总 + 0.5×0.2×10×2.8
    - 结果：Q_总 = 5.2J（加粗）
  - 上方右侧：热量分配框（绿色）
    - Q_R = Q_总 × R/(R+r)
    - 代入：= 5.2 × 0.8/(0.8+0.2)
    - 结果：Q_R = 4.16J（加粗）
  - 下方：能量条状图
    - 总条Fx=8.4J，分三段：动能0.4J(蓝)、总热量5.2J(绿)、摩擦热2.8J(灰)
    - 各段上方标注数值，用引线连接
  - 底部：最终答案框（黄色高亮）
    - Q_R = 4.16J（红色加粗）
- 教师讲解：由能量守恒求出总焦耳热Q_总=5.2J，再按电阻比例分配得R上热量Q_R=4.16J

- 关键实现要点：
  1. **状态机设计**：用全局变量`currentStep`（0~3）跟踪当前步骤，每个步骤对应一组SVG元素的显示/隐藏
  2. **步骤切换**：点击按钮时，先隐藏当前步骤所有元素（CSS class `scene2-hidden`：opacity=0, visibility=hidden），再显示目标步骤元素（CSS class `scene2-visible`：opacity=1, visibility=visible），配合CSS transition实现0.3s淡入淡出
  3. **v-t曲线绘制**：使用SVG `<path>`元素，用贝塞尔曲线`C`命令绘制平滑曲线。控制点计算：从(120,370)出发，用`C 180,370 250,250 320,200`等分段贝塞尔曲线逼近指数增长曲线，最终渐近于y=170
  4. **能量条状图比例计算**：总宽700px，按Fx=8.4J分配：动能0.4J→34px、总热量5.2J→433px、摩擦热2.8J→233px
  5. **按钮状态管理**：步骤0时"上一步"按钮disabled（灰色不可点击），步骤3时"下一步"按钮disabled
