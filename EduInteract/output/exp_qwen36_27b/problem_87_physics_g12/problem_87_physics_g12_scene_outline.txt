    **题目原文：**

    如图所示，一光滑绝缘斜面固定在水平向右的匀强电场中，斜面的倾角为37°，斜面上有A、B两个小球，B球固定，A球恰好处于静止，两球相距为L，两球的质量均为m，带电量的大小均为q，A带负电，静电力常量为k．（已知sin37°=0.6，cos37°=0.8）求：
    （1）B球的电性及匀强电场的电场强度大小；
    （2）释放B球的一瞬间，B球的加速度大小．

    **题目分析：**

    本题是带电小球在匀强电场和库仑力共同作用下的受力平衡与动力学问题。核心考点包括：
    - 电场力方向的判断（负电荷受力与电场方向相反）
    - 斜面上力的正交分解
    - 库仑定律的应用
    - 牛顿第二定律的瞬时性

    **整体讲解思路：**

    1. 首先引导学生观察题目原图，明确物理场景：斜面、匀强电场、两个带电小球
    2. 对A球进行受力分析，判断B球电性，列平衡方程求电场强度E
    3. 释放B球瞬间，对B球进行受力分析，求合力和加速度

    **图示规划说明：**

    规划两个交互式图示：
    - **Scene 1**：A球受力分析——逐步展示A球所受各力，通过力的分解推导平衡方程，确定B球电性和电场强度
    - **Scene 2**：B球释放瞬间的受力与加速度——展示B球受力，计算合力与加速度

    两个图示共享相同的场景基础（斜面、电场线），但聚焦不同小球的受力分析。

    **Scene 1 教学说明：A球受力分析**

    本图示用于引导学生完成第（1）问的求解。教师应按以下步骤讲解：

    1. **步骤0→步骤1（重力分析）**：
       - 引导学生观察A球受重力mg，方向竖直向下
       - 将重力正交分解：沿斜面方向分力为 $mg\sin37° = 0.6mg$（沿斜面向下），垂直斜面方向分力为 $mg\cos37° = 0.8mg$（垂直斜面向下）

    2. **步骤1→步骤2（电场力分析）**：
       - 强调A带负电，匀强电场水平向右，因此A受到的电场力方向水平向左，大小为 $qE$
       - 将电场力正交分解：沿斜面方向分力为 $qE\cos37° = 0.8qE$（沿斜面向上），垂直斜面方向分力为 $qE\sin37° = 0.6qE$（垂直斜面向下）

    3. **步骤2→步骤3（库仑力分析与电性判断）**：
       - 提问学生：A球静止，沿斜面方向重力分力向下，电场力分力向上，是否已经平衡？
       - 引导学生思考：如果只有重力和电场力，$0.6mg$ 与 $0.8qE$ 不一定相等，需要第三个力来平衡
       - 关键推理：库仑力必须沿斜面向上才能帮助平衡（因为电场力分力 $0.8qE$ 沿斜面向上，如果库仑力也向上，则 $0.8qE + F_{库} = 0.6mg$；如果库仑力向下，则 $0.8qE = 0.6mg + F_{库}$，两种情况都可能，但题目说"恰好静止"暗示需要库仑力补充）
       - 结论：库仑力沿斜面向上 → B对A为斥力 → A、B带同种电荷 → **B球带负电**

    4. **步骤3→步骤4（支持力与完整受力图）**：
       - 添加支持力N，方向垂直斜面向上
       - 此时A球受力完整：重力、电场力、库仑力、支持力

    5. **步骤4→步骤5（列平衡方程求解）**：
       - 沿斜面方向平衡：$mg\sin37° = qE\cos37° + \frac{kq^2}{L^2}$
       - 代入数值：$0.6mg = 0.8qE + \frac{kq^2}{L^2}$
       - 解得：$E = \frac{0.6mg - \frac{kq^2}{L^2}}{0.8q} = \frac{3mg - \frac{5kq^2}{L^2}}{4q}$

    **教学提示**：在步骤3判断B球电性时，可让学生先猜测再推理，增强参与感。强调"恰好静止"意味着所有力的合力为零，这是列平衡方程的依据。

    **Scene 2 教学说明：B球释放瞬间的加速度**

    本图示用于引导学生完成第（2）问的求解。教师应按以下步骤讲解：

    1. **步骤0→步骤1（重力分析）**：
       - B球与A球质量相同，均为m，重力mg竖直向下
       - 分解：沿斜面方向 $mg\sin37° = 0.6mg$（沿斜面向下），垂直斜面方向 $mg\cos37° = 0.8mg$

    2. **步骤1→步骤2（电场力分析）**：
       - B球带负电（由第1问已确定），电场水平向右，故电场力水平向左，大小为 $qE$
       - 分解：沿斜面方向 $qE\cos37° = 0.8qE$（沿斜面向上），垂直斜面方向 $qE\sin37° = 0.6qE$

    3. **步骤2→步骤3（库仑力分析）**：
       - 关键对比：A球受到的库仑力沿斜面向上（B对A的斥力），则B球受到的库仑力沿斜面向下（A对B的斥力），方向相反
       - 大小仍为 $F_{库} = \frac{kq^2}{L^2}$（牛顿第三定律）

    4. **步骤3→步骤4（支持力与完整受力图）**：
       - 添加支持力 $N_B$，垂直斜面向上
       - B球受力完整

    5. **步骤4→步骤5（合力与加速度计算）**：
       - 沿斜面方向合力：$F_{合} = mg\sin37° + \frac{kq^2}{L^2} - qE\cos37°$
       - 代入 $E = \frac{0.6mg - \frac{kq^2}{L^2}}{0.8q}$：
       - $F_{合} = 0.6mg + \frac{kq^2}{L^2} - 0.8q \cdot \frac{0.6mg - \frac{kq^2}{L^2}}{0.8q}$
       - $F_{合} = 0.6mg + \frac{kq^2}{L^2} - \left(0.6mg - \frac{kq^2}{L^2}\right)$
       - $F_{合} = \frac{2kq^2}{L^2}$
       - 由牛顿第二定律：$a = \frac{F_{合}}{m} = \frac{2kq^2}{mL^2}$
       - 加速度方向：沿斜面向下

    **教学提示**：
    - 强调"释放瞬间"的含义：此时两球位置尚未改变，距离仍为L，库仑力大小不变
    - 对比A球和B球的库仑力方向：A受到的库仑力沿斜面向上，B受到的库仑力沿斜面向下，这是牛顿第三定律的体现
    - 化简过程中，$0.6mg$ 项恰好消去，这是一个巧妙的设计，可引导学生观察这一现象

    **完整解答总结：**

    **第（1）问：**
    - B球带负电
    - 匀强电场强度大小：$E = \frac{0.6mg - \frac{kq^2}{L^2}}{0.8q} = \frac{3mgL^2 - 5kq^2}{4qL^2}$

    **第（2）问：**
    - 释放B球瞬间，B球的加速度大小：$a = \frac{2kq^2}{mL^2}$
    - 加速度方向：沿斜面向下

    **课堂讲解建议：**

    1. **引入阶段**：先让学生观察原图，识别物理场景中的关键元素（斜面、电场、带电小球），明确已知条件
    2. **第（1）问讲解**：使用Scene 1逐步展示A球受力，重点引导学生推理B球电性，这是本题的关键突破口
    3. **第（2）问讲解**：使用Scene 2展示B球受力，强调与A球受力的对比（特别是库仑力方向相反），利用牛顿第三定律
    4. **总结阶段**：回顾两个问题的解题思路，强调受力分析的一般方法：①确定研究对象 ②分析所有受力 ③正交分解 ④列方程求解
    5. **拓展思考**：可提问学生"如果斜面不光滑，结果会如何变化？"或"如果B球带正电，A球能否静止？"以深化理解
