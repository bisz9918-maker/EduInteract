    **题目原文：**

    如图所示，两根等高光滑的四分之一圆弧轨道，半径为r，间距为L，轨道电阻不计，在轨道顶端连有一阻值为R的电阻，整个装置处在一竖直向上的匀强磁场中，磁感应强度为B，现有一根长度稍大于L，电阻为$\frac{1}{3}R$，质量为m的金属棒从轨道最低位置cd开始，在拉力作用下以速度$v_0$向右沿轨道做匀速圆周运动至ab处，求：
    （1）初始时刻cd两端的电压；
    （2）在该过程中R上产生的热量；
    （3）拉力做的功。

    **题目分析：**

    本题综合考查电磁感应中的动生电动势、闭合电路欧姆定律、焦耳热计算以及能量守恒定律。核心难点在于：金属棒沿圆弧轨道做匀速圆周运动时，速度方向不断变化，导致切割磁感线的有效速度分量随之变化，感应电动势是随角度变化的函数，热量计算需要对时间积分。

    **整体讲解思路：**

    1. 首先通过三维/侧视图帮助学生建立空间模型，理解轨道结构、磁场方向和金属棒运动轨迹
    2. 分析初始时刻（cd位置）的动生电动势和电路，求解cd两端电压
    3. 分析任意角度位置的感应电动势表达式，通过积分计算R上的热量
    4. 利用能量守恒定律求解拉力做的功

    **图示规划：**

    共规划2个图示场景：
    - Scene 1：轨道结构与运动过程分析（侧视图+速度分解+感应电动势变化）
    - Scene 2：等效电路与能量守恒分析（电路图+能量关系）
    </TEXT_1>

    **Scene 1 教学说明：轨道结构与运动过程分析**

    **引导观察要点：**

    1.  **建立空间模型**：引导学生观察四分之一圆弧轨道的结构，明确轨道半径为r、间距为L，磁场竖直向上。金属棒横跨两根轨道，长度稍大于L。

    2.  **初始时刻分析（步骤1）**：
        - 金属棒在cd位置时，速度v₀水平向右，磁场B竖直向上，金属棒水平放置
        - 三者互相垂直，满足E=BLv的条件
        - 初始感应电动势：$E = BLv_0$
        - 用右手定则判断感应电流方向：从d流向c

    3.  **任意位置分析（步骤2-3）**：
        - 金属棒做匀速圆周运动，速度大小恒为v₀，但方向不断变化
        - 在任意角度θ处（从最低点cd算起），速度方向沿圆弧切线，与水平方向夹角为θ
        - 将速度分解：水平分量$v_x = v_0\cos\theta$，竖直分量$v_y = v_0\sin\theta$
        - 只有水平分量切割竖直磁场产生电动势，竖直分量平行于磁场不切割
        - 任意位置感应电动势：$E = BLv_0\cos\theta$
        - 当θ=0（cd位置）时，E=BLv₀（最大）；当θ=π/2（ab位置）时，E=0

    4.  **电动势变化规律（步骤4）**：
        - E-θ图像为余弦曲线从θ=0到θ=π/2的一段
        - 帮助学生直观理解电动势从最大值逐渐减小到零的过程

    **Scene 2 教学说明：等效电路与能量守恒分析**

    **第（1）问：初始时刻cd两端的电压**

    1.  初始时刻金属棒在cd位置，感应电动势$E = BLv_0$
    2.  金属棒相当于电源，内阻$r_{内} = \frac{1}{3}R$，外电阻为$R$
    3.  总电阻$R_{总} = R + \frac{1}{3}R = \frac{4}{3}R$
    4.  回路电流$I = \frac{E}{R_{总}} = \frac{BLv_0}{\frac{4}{3}R} = \frac{3BLv_0}{4R}$
    5.  cd两端电压即路端电压（外电阻R两端电压）：$U_{cd} = IR = \frac{3BLv_0}{4}$

    **第（2）问：R上产生的热量**

    1.  任意角度θ处，感应电动势$E = BLv_0\cos\theta$
    2.  回路电流$I = \frac{3BLv_0\cos\theta}{4R}$
    3.  R上的瞬时功率$P_R = I^2R = \frac{9B^2L^2v_0^2\cos^2\theta}{16R}$
    4.  金属棒做匀速圆周运动，角速度$\omega = \frac{v_0}{r}$，时间元$dt = \frac{r}{v_0}d\theta$
    5.  R上产生的热量：
        $$Q_R = \int_0^{\pi/2} P_R \, dt = \int_0^{\pi/2} \frac{9B^2L^2v_0^2\cos^2\theta}{16R} \cdot \frac{r}{v_0} \, d\theta$$
        $$= \frac{9B^2L^2v_0r}{16R} \int_0^{\pi/2} \cos^2\theta \, d\theta = \frac{9B^2L^2v_0r}{16R} \cdot \frac{\pi}{4} = \frac{9\pi B^2L^2v_0r}{64R}$$

    **第（3）问：拉力做的功**

    1.  根据能量守恒：拉力做功 = 重力势能增加 + 电路总焦耳热
    2.  重力势能增加：$\Delta E_p = mgr$
    3.  电路总焦耳热：总电阻为$\frac{4}{3}R$，R上热量占总热量的$\frac{R}{\frac{4}{3}R} = \frac{3}{4}$
    4.  故$Q_{总} = \frac{Q_R}{3/4} = \frac{4}{3}Q_R = \frac{3\pi B^2L^2v_0r}{16R}$
    5.  拉力做功：$W_F = mgr + \frac{3\pi B^2L^2v_0r}{16R}$

    **课堂讲解建议：**

    - 强调"cd两端电压"是路端电压而非电动势，学生容易混淆
    - 热量计算中的积分是本题难点，可先引导学生理解为什么需要积分（电动势随角度变化），再逐步推导
    - 能量守恒法是求解拉力做功的最简便方法，对比直接对拉力积分的方法，突出能量法的优势
    - 提醒学生注意：金属棒做匀速圆周运动，动能不变，拉力做功全部转化为重力势能和焦耳热
