[图示主题与整合说明]
- 本图示主题：带电粒子在E₁电场中的匀加速直线运动
- 整合的步骤/概念：粒子从P(0,h)静止出发 → 受力分析（F=qE₁沿x轴正方向） → 匀加速直线运动过程 → 到达虚线ab时的速度计算 v=√(2qE₁L/m)
- 教学价值：教师可通过分步导航，从初始条件逐步引导学生理解带电粒子在匀强电场中的运动规律，每一步聚焦一个物理概念（受力→运动→速度），便于课堂逐层讲解和提问

[分步序列]
- 初始状态（步骤0）：
  显示：坐标系(x轴、y轴、原点O)、P点(100,160)、虚线ab(x=320)、E₁电场线(5条蓝色)、E₂电场线(5条红色淡化)、粒子(静止在P点，带"+q"和"m"标签)、距离标注h和L、区域标签E₁和E₂、点标签a和b
  不显示：力矢量、运动轨迹、速度矢量、公式标注

- 步骤1（受力分析）：点击「下一步▶」
  新增：力矢量F=qE₁（红色箭头，从粒子(100,160)沿x轴正方向到(160,160)）
  新增：标签"F=qE₁"在力箭头上方(135,140)
  新增：标签"a₁=qE₁/m"在力箭头下方(135,185)，绿色加粗
  粒子保持静止在P点

- 步骤2（运动过程）：点击「下一步▶」
  新增：运动轨迹（蓝色实线，从(100,160)到(320,160)）
  动画：粒子沿轨迹从(100,160)平滑移动到(320,160)，持续时间1秒
  跟随："+q"标签从(115,148)移动到(335,148)，"m"标签从(115,175)移动到(335,175)
  隐藏：力矢量F和标签"F=qE₁"、"a₁=qE₁/m"（步骤1元素淡出）

- 步骤3（到达ab线）：点击「下一步▶」
  新增：速度矢量v（绿色箭头，从(320,160)沿x轴正方向到(400,160)）
  新增：标签"v=√(2qE₁L/m)"在速度箭头上方(360,140)，绿色加粗
  粒子停留在ab线上(320,160)

- 回退：点击「◀上一步」可逐步回退到上一状态，元素按逆序消失

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于(280,460)，120×35px，点击回退到上一状态，步骤0时禁用
  - 「下一步 ▶」按钮：位于(400,460)，120×35px，点击前进到下一状态，步骤3时禁用
- 教师操作流程：
  1. 图示加载后显示步骤0（初始条件），教师可先让学生观察整体布局
  2. 点击「下一步▶」进入步骤1，讲解粒子受力分析（F=qE₁，a₁=qE₁/m）
  3. 点击「下一步▶」进入步骤2，展示粒子运动过程（轨迹动画）
  4. 点击「下一步▶」进入步骤3，展示到达ab线时的速度
  5. 可随时点击「◀上一步」回退复习任意步骤

[技术实现]
- JS 库选择：原生 SVG（本场景为几何图形、箭头、线段等，原生 SVG 完全胜任，无需额外库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  ┌──────────────────────────────────────────────────────────────┐
  │ y↑                                                           │
  │ │  E₁              a      E₂                                │
  │ │  →→→           ┊      ↓↓                                  │
  │ │  →→→  P●+q    ┊      ↓↓                                  │
  │ │  →→→  │m      ┊      ↓↓                                  │
  │ │  →→→  ────────┊──────→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→→│
  │ │  →→→  F→      ┊      ↓↓                                  │
  │ │  →→→          ┊      ↓↓                                  │
  │ │               ┊      ↓↓                                  │
  │ │               b      Q                                  │
  │ O└──────────────┴──────────────────────────────────────────→x│
  │   ←── L ──→                                          │
  │                                                       │
  │              ┌──────────┐  ┌──────────┐              │
  │              │◀ 上一步  │  │ 下一步 ▶│              │
  │              └──────────┘  └──────────┘              │
  └──────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用全局变量 `currentStep`（0~3）管理当前步骤，每个步骤对应一组可见元素
  2. 元素显隐控制：通过 CSS class `.step-N-only` 控制各步骤专属元素的显示/隐藏，初始隐藏步骤1~3元素
  3. 粒子动画：步骤2中粒子从(100,160)到(320,160)使用 CSS transition（transform: translateX(220px)，duration: 1s，ease-in）
  4. 跟随标签："+q"和"m"标签与粒子绑定在同一 `<g>` 组内，粒子移动时标签自动跟随
  5. 按钮状态：步骤0时「上一步」disabled，步骤3时「下一步」disabled，通过 JS 动态切换
  6. 箭头绘制：使用 SVG `<marker>` 定义箭头头部，电场线、力矢量、速度矢量复用不同 marker
  7. 虚线绘制：虚线ab使用 `stroke-dasharray="8,4"`
  8. E₂电场线淡化：使用 `opacity="0.4"`
- ID 命名规范：所有交互元素 ID 以 `scene1-` 为前缀，例如：
  - `scene1-particle`（粒子组）
  - `scene1-force-arrow`（力矢量）
  - `scene1-velocity-arrow`（速度矢量）
  - `scene1-trajectory`（运动轨迹）
  - `scene1-btn-prev`（上一步按钮）
  - `scene1-btn-next`（下一步按钮）
  - `scene1-field-e1`（E₁电场线组）
  - `scene1-field-e2`（E₂电场线组）
  - `scene1-dashed-ab`（虚线ab）
  - `scene1-label-f`（F=qE₁标签）
  - `scene1-label-a1`（a₁=qE₁/m标签）
  - `scene1-label-v`（v=√(2qE₁L/m)标签）
- JS 隔离：所有 JS 代码包裹在 `(function() { 'use strict'; ... })();` IIFE 中，避免全局污染
- 事件绑定：按钮使用 `addEventListener('click', ...)` 绑定，不使用内联 onclick
