[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于 SVG 底部左侧 (280,470)，点击回退到上一步骤，步骤0时禁用
  - 「下一步 ▶」按钮：位于 SVG 底部右侧 (420,470)，点击进入下一步骤，步骤3（最后一步）时禁用
  - 步骤指示文字：位于 SVG 底部中央 (400,455)，显示当前步骤如"1/4"
- 教师操作流程：
  1. 页面加载显示步骤0（实物图），教师介绍各元件名称
  2. 点击「下一步 ▶」进入步骤1，教师讲解电流路径和串联电路概念
  3. 点击「下一步 ▶」进入步骤2，教师讲解电压表的测量对象
  4. 点击「下一步 ▶」进入步骤3，教师对比实物图与标准电路图
  5. 可随时点击「◀ 上一步」回退复习任意步骤

[技术实现]
- JS 库选择：原生 SVG（简单几何图形和电路符号绘制，无需额外库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  步骤0-2（实物图居中）：
  ┌────────────────────────────────────────────────────┐
  │                                                    │
  │         开关              L₁                      │
  │         [___]           (⊗)                       │
  │          /  \         /    \                      │
  │         /    \_______/      \                     │
  │        /                    \                     │
  │       /          V           \                    │
  │      /         [____]         \                   │
  │     /           |  |           \                  │
  │    /            |  |            \                 │
  │   (⊗) L₂       |  |             电源              │
  │                                                    │
  │                                                    │
  │         ◀ 上一步      1/4      下一步 ▶           │
  └────────────────────────────────────────────────────┘

  步骤3（左右分栏）：
  ┌────────────────────────────────────────────────────┐
  │     实物图                    标准电路图            │
  │                                                    │
  │   [缩小实物图]    │   ┌──────────────┐            │
  │                   │   │      L₁      │            │
  │                   │   │    ┌──⊗──┐   │            │
  │                   │   │    │      │   │            │
  │                   │   │  开关    L₂  │   V         │
  │                   │   │    │      │   │            │
  │                   │   │    └──┬──┘   │            │
  │                   │   │       电源    │            │
  │                   │   └──────────────┘            │
  │                                                    │
  │         ◀ 上一步      4/4      下一步 ▶(禁用)     │
  └────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. **状态机设计**：用变量 `currentStep`（0~3）管理当前步骤，每个步骤对应一组 SVG 元素的显示/隐藏/样式变化
  2. **SVG 元素管理**：所有元素预先创建，通过 `display` 属性或 `opacity` 控制可见性，避免重复创建/销毁
  3. **电流路径箭头**：用 SVG `<marker>` 定义箭头，在蓝色路径线上设置 `marker-mid` 和 `marker-end`
  4. **实物图绘制**：用 SVG `<rect>`、`<circle>`、`<line>`、`<path>` 组合绘制各元件图标
  5. **标准电路符号**：电源用两条平行线（一长一短），灯泡用圆圈内加叉，电压表用圆圈内加"V"
  6. **步骤3左右分栏**：用 `<g>` 分组管理左侧实物图和右侧标准电路图，通过变换实现缩放
  7. **按钮状态管理**：步骤0时"上一步"禁用，步骤3时"下一步"禁用，用 `opacity` 和 `pointer-events` 控制
  8. **动画过渡**：步骤切换时使用 CSS `transition` 实现淡入淡出效果（opacity 0.3s ease）
- ID 命名规范：所有交互元素 ID 以 `scene1-` 为前缀
  - 按钮：`scene1-prev-btn`、`scene1-next-btn`
  - 步骤指示：`scene1-step-indicator`
  - 实物图分组：`scene1-physical-diagram`
  - 标准电路图分组：`scene1-standard-diagram`
  - 电流路径：`scene1-current-path`
  - 电压表高亮：`scene1-voltmeter-highlight`
  - 各标签：`scene1-label-power`、`scene1-label-switch`、`scene1-label-l1`、`scene1-label-l2`、`scene1-label-voltmeter` 等
- IIFE 隔离：所有 JS 代码包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染
