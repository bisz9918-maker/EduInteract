[图示主题与整合说明]
- 本图示主题：四种故障选项的电路状态对比分析（场景2）
- 整合的概念：串联电路中L₁与L₂的四种故障状态（L₁短路、L₁断路、L₂短路、L₂断路）对灯泡亮灭和电压表示数的影响，通过逐步对比判定正确答案

[分步序列]

步骤0（初始状态 — 正常情况）：
- 显示完整电路图：电源、开关（闭合态）、L₁、L₂、电压表V
- L₁亮（黄色填充+光晕），L₂亮（黄色填充+光晕）
- 电压表放大表盘：指针偏转到1.5V位置（旋转90°，指向上方）
- 电流箭头：四条边上均显示蓝色箭头，指示电流方向（右→上→左→下→右的回路）
- 状态描述文字："正常情况：两灯都亮，电压表有示数（约1.5V）"
- 无判定标记

步骤1（选项A：L₁短路）：
- L₁处增加红色短路线(385,140)→(415,140)，L₁灭（灰色填充，无光晕）
- L₂保持亮（黄色填充+光晕）
- 电压表放大表盘：指针偏转到3V位置（旋转0°，指向右方），标注"≈3V"
- 电流箭头：保持显示（电流绕过L₁，经短路线→开关→L₂→电源）
- 状态描述文字："A. L₁短路：L₁不亮，L₂亮，电压表有示数(≈3V) ✓ 符合题意"
- 判定标记：绿色"✓"

步骤2（选项B：L₁断路）：
- 移除短路线，L₁处显示红色"×"标记(400,120)，L₁灭
- 上边导线在(385,120)处断开，右边导线在(415,120)处断开
- L₂灭（灰色填充，无光晕）
- 电压表放大表盘：指针回到0V位置（旋转180°，指向左方），标注"=0"
- 电流箭头：全部隐藏（电路断开，无电流）
- 状态描述文字："B. L₁断路：两灯都不亮，电压表无示数 ✗ 不符合"
- 判定标记：红色"✗"

步骤3（选项C：L₂短路）：
- 移除断路标记，恢复L₁灯泡（灭态，灰色）
- L₂处增加红色短路线(165,340)→(195,340)，L₂灭
- L₁亮（黄色填充+光晕）
- 电压表放大表盘：指针回到0V位置（旋转180°，指向左方），标注"=0"
- 电流箭头：保持显示（电流经L₁→开关→短路线→电源）
- 状态描述文字："C. L₂短路：L₂不亮，L₁亮，电压表无示数 ✗ 不符合"
- 判定标记：红色"✗"

步骤4（选项D：L₂断路）：
- 移除短路线，L₂处显示红色"×"标记(180,320)，L₂灭
- 左边导线在(165,320)处断开，下边导线在(195,320)处断开
- L₁灭（灰色填充，无光晕）
- 电压表放大表盘：指针偏转到3V位置（旋转0°，指向右方），标注"≈3V"
- 电流箭头：全部隐藏（电路断开，电压表串联入电路但电流极小）
- 状态描述文字："D. L₂断路：两灯都不亮，电压表有示数 ✗ 不符合"
- 判定标记：红色"✗"

步骤5（结论）：
- 恢复完整电路图，L₁处显示红色短路线，L₁灭，L₂亮（与步骤1相同）

- 隐藏状态描述文字，显示结论框(100,385)-(700,430)：

[技术实现]
- JS 库选择：原生 SVG（电路图由简单几何图形组成，无需第三方库；指针旋转用SVG transform实现）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  ┌──────────────────────────────────────────────────────────────────┐
  │  [主电路图区域 x:80~520, y:60~380]    [电压表放大 x:540~760]    │
  │                                                                  │
  │    S(开关)                    L₁(灯泡)                           │
  │    ──/ ──                    ──⊗──          ┌─────────┐          │
  │       │                           │         │  电压表  │          │
  │       │                           │         │  放大    │          │
  │    V  │                           │         │  表盘    │          │
  │   (○) │                           │         └─────────┘          │
  │       │                           │                               │
  │       │                           │                               │
  │    L₂(灯泡)                   电源                               │
  │    ──⊗──                    ──| |──                               │
  │                                                                  │
  │  ───────────────────────────────────────────────────────────────  │
  │  状态描述文字区域 (y:390~430)                                     │
  │  ───────────────────────────────────────────────────────────────  │
  │  [◀ 上一步]    步骤 X/5    [下一步 ▶]   (y:440~490)              │
  └──────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. **状态机设计**：用变量`currentStep`（0~5）跟踪当前步骤，每个步骤对应一组视觉状态
  2. **状态渲染函数**：`renderStep(step)`根据步骤编号更新：
     - 灯泡亮灭状态（填充色、光晕显示/隐藏）
     - 短路/断路标记的显示/隐藏
     - 导线断开的显示（用clip-path或分段绘制）
     - 电流箭头的显示/隐藏
     - 电压表指针旋转角度（0V→180°, 1.5V→90°, 3V→0°）
     - 状态描述文字内容
     - 结论框的显示/隐藏（仅步骤5）
  3. **电压表指针旋转**：SVG `<line>`元素，用`transform="rotate(angle, 650, 180)"`控制角度
     - 角度映射：0V→180°, 1.5V→90°, 3V→0°
     - 用`setAttribute('transform', ...)`动态更新
  4. **动画过渡**：指针旋转用CSS transition（0.5s ease），灯泡亮灭用opacity过渡（0.3s）
  5. **事件绑定**：按钮点击事件绑定到`prevStep()`和`nextStep()`函数，更新`currentStep`后调用`renderStep()`
  6. **导线断开处理**：断路时将完整导线替换为两段短线段（断点两侧各留5px间隙）
- ID 命名规范：所有交互元素ID以`scene2-`为前缀
  - `scene2-switch`（开关）
  - `scene2-lamp-l1`（L₁灯泡组）
  - `scene2-lamp-l2`（L₂灯泡组）
  - `scene2-voltmeter-circuit`（电路图中电压表）
  - `scene2-voltmeter-large`（放大表盘组）
  - `scene2-needle`（电压表指针）
  - `scene2-wire-top`（上边导线）
  - `scene2-wire-right`（右边导线）
  - `scene2-wire-bottom`（下边导线）
  - `scene2-wire-left`（左边导线）
  - `scene2-short-l1`（L₁短路线）
  - `scene2-short-l2`（L₂短路线）
  - `scene2-break-l1`（L₁断路标记）
  - `scene2-break-l2`（L₂断路标记）
  - `scene2-arrows`（电流箭头组）
