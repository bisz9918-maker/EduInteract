[分步序列]

步骤1（整体受力分析）：
- 在步骤0基础上，新增：
  - 整体虚线框（灰色虚线矩形，包围三球）

  - 标签"F"在箭头右端

- 按钮状态：「上一步」可用，「下一步」可用

步骤2（求解F，最终状态）：
- 在步骤1基础上，新增：
  - 方程文本框（浅绿色背景，位于图示下方）
  - 文本框内用MathJax渲染：
    - 第一行：$F = Ma = 3ma$
    - 第二行：代入 $a = \sqrt{3}k\frac{q^2}{mr^2}$
    - 第三行（加粗、醒目）：$F = 3\sqrt{3}k\frac{q^2}{r^2}$
- 按钮状态：「上一步」可用，「下一步」禁用

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于控件栏左侧，x=250, y=445，尺寸120×40，点击回到上一步
  - 「下一步 ▶」按钮：位于控件栏右侧，x=430, y=445，尺寸120×40，点击进入下一步
  - 步骤指示器：位于控件栏中央，x=370, y=455，显示"步骤 X / 3"
- 教师操作流程：
  1. 页面加载后显示步骤0（基础条件），教师讲解三球系统已知条件
  2. 点击「下一步」进入步骤1，讲解整体法思路（虚线框圈出整体，内力抵消，仅外力F）
  3. 点击「下一步」进入步骤2，展示牛顿第二定律方程和最终答案
  4. 可随时点击「上一步」回退复习

[技术实现]
- JS 库选择：
  - 原生 SVG：绘制几何图形（小球、虚线、箭头、虚线框），轻量且精确控制
  - MathJax 3（CDN）：渲染方程文本框中的数学公式
- 画布尺寸：800 × 500 px（SVG viewBox="0 0 800 500"）
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────┐
  │  y=0~55:  加速度a箭头 ──────────→ a                        │
  │                                                            │
  │  y=80~130: 整体虚线框上边 ──────────────────────────────── │
  │                    A(+q,m)                                 │
  │                   (250,130)                                │
  │                    ╱  r                                    │
  │                   ╱                                        │
  │  y=130~230:  r  ╱                                          │
  │              ╱  ╲                                          │
  │             ╱   ╲  C(-2q,m)                                │
  │            ╱     ╲(423,230)  ───F──→                       │
  │           ╱       ╲                                        │
  │          ╱   r     ╲                                       │
  │         ╱           ╲                                      │
  │  y=230~330: B(+q,m)                                        │
  │         (250,330)                                          │
  │                                                            │
  │  y=360:  整体虚线框下边 ────────────────────────────────── │
  │                                                            │
  │  y=375~420: ┌─ 方程文本框 (F=3√3kq²/r²) ───────────────┐  │
  │            └─────────────────────────────────────────────┘  │
  │                                                            │
  │  y=430~490: [◀ 上一步]  步骤 X/3  [下一步 ▶]              │
  └────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. **状态机设计**：用变量 `currentStep`（0/1/2）管理当前步骤，每个步骤对应一组SVG元素的显示/隐藏
  2. **元素显隐**：通过CSS类 `.step0`, `.step1`, `.step2` 控制元素可见性，步骤N显示所有 `.step0`~`.stepN` 元素
  3. **箭头绘制**：使用SVG `<marker>` 定义箭头头部，`<line>` 绘制箭杆
  4. **MathJax渲染**：步骤2激活时，调用 `MathJax.typesetPromise()` 渲染方程文本框内的公式
  5. **动画过渡**：新增元素使用CSS `opacity` 从0到1的淡入动画（duration=0.4s），增强视觉引导
  6. **按钮状态**：步骤0时「上一步」disabled，步骤2时「下一步」disabled
- ID 命名规范：所有交互元素ID以 `scene2-` 为前缀
  - 小球：`scene2-ball-a`, `scene2-ball-b`, `scene2-ball-c`
  - 虚线：`scene2-line-ab`, `scene2-line-ac`, `scene2-line-bc`
  - 箭头：`scene2-arrow-a`, `scene2-arrow-f`
  - 整体框：`scene2-box-whole`
  - 方程框：`scene2-eq-box`
  - 按钮：`scene2-btn-prev`, `scene2-btn-next`
  - 步骤指示：`scene2-step-indicator`
- IIFE 隔离：所有JS代码包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染
- MathJax CDN：`<script src="https://cdn.jsdelivr.net/npm/mathjax@3/es5/tex-mml-chtml.js"></script>`
