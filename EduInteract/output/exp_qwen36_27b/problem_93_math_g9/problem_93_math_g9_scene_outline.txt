    **题目原文：**

    如图1，已知线段AB=8，点C是AB上的一动点（不包括A、B），在AB同侧作两个等边三角形ACD和BCE，连DE，点P、F分别是DE和BE的中点，连接AF，分别交DC、CE于G、H．

    （1）写出图中所有的相似三角形（除等边三角形ACD和BCE外）；

    （2）当点C在AB中点时，如图2，求CP的长及AG：GH：HF；

    （3）点M、N是线段AB上两点，且AM=BN=2，当点C从点M向点N运动时，求点P所经过的路径长．

    **题目分析：**

    本题是一道几何综合题，核心考点包括：
    - 等边三角形的性质（三边相等、三角均为60°）
    - 相似三角形的判定（AA判定法）
    - 中点性质与坐标法计算
    - 动点轨迹问题

    **整体讲解思路：**

    1. 首先展示完整的基础图形，让学生熟悉所有点和线段的关系
    2. 通过分步高亮，引导学生发现三对相似三角形，并理解其判定依据（对应角相等）
    3. 切换到C在中点的特殊情况，利用对称性和坐标法计算CP长度和线段比
    4. 通过拖拽动画展示C从M到N运动时P的轨迹，发现P的纵坐标不变，轨迹为水平线段

    **教学说明——相似三角形识别：**

    本图示帮助学生系统识别题目中的三对相似三角形。

    **讲解要点：**

    1. 引导学生先观察基础图形，确认所有已知条件：
       - △ACD和△BCE是等边三角形，所以∠DAC=∠ACD=∠ADC=60°，∠CBE=∠BCE=∠BEC=60°
       - ∠DCE = 180° - ∠ACD - ∠BCE = 180° - 60° - 60° = 60°

    2. 第一对相似：△ADG ∽ △AFB
       - ∠DAG = ∠FAB（公共角）
       - ∠ADG = ∠ADC = 60°，∠ABF = ∠CBE = 60°
       - 由AA判定法，△ADG ∽ △AFB

    3. 第二对相似：△CHE ∽ △CFA
       - ∠HCE = ∠FCA（公共角）
       - ∠CEH = ∠BEC = 60°，∠CAF = ∠DAC = 60°
       - 由AA判定法，△CHE ∽ △CFA

    4. 第三对相似：△DCE ∽ △ACF
       - ∠DCE = 60°，∠CAF = 60°，所以∠DCE = ∠CAF
       - ∠CDE = ∠ACF（可通过角度计算验证）
       - 由AA判定法，△DCE ∽ △ACF

    **课堂引导建议：**
    - 在步骤0时，让学生先自己尝试找出相似三角形，再逐步验证
    - 每高亮一对相似三角形时，强调"对应角相等"这一判定依据
    - 提醒学生注意：等边三角形的60°角是寻找相似的关键线索

    **教学说明——C在中点时的计算：**

    本图示展示C在AB中点这一特殊情况下的两个计算。

    **讲解要点：**

    1. CP长度的计算：
       - 当C在AB中点时，AC = CB = 4
       - △ACD和△BCE均为边长4的等边三角形
       - 由对称性，D和E关于过C的垂线对称，DE水平
       - P为DE中点，故P在C的正上方
       - CP即为等边三角形的高：CP = 4 × √3 / 2 = 2√3

    2. AG:GH:HF的计算（坐标法）：
       - 建立坐标系：A(0,0)、B(8,0)、C(4,0)
       - D(2, 2√3)、E(6, 2√3)
       - P为DE中点：P(4, 2√3)
       - F为BE中点：B(8,0)、E(6,2√3)，故F(7, √3)
       - 直线AF过A(0,0)和F(7,√3)，方程为 y = (√3/7)x
       - 直线DC过D(2,2√3)和C(4,0)，方程为 y = -√3(x-4)
       - G为AF与DC交点：联立解得 G(3.5, √3/2)
       - 直线CE过C(4,0)和E(6,2√3)，方程为 y = √3(x-4)
       - H为AF与CE交点：联立解得 H(14/3, 2√3/3)
       - 计算各段长度比：AG:GH:HF = 3:1:2

    **课堂引导建议：**
    - 先让学生观察图形的对称性，猜测CP的长度
    - 坐标法是计算线段比的有效工具，引导学生理解如何建立坐标系
    - 强调联立方程求交点的方法
    - 最终比值3:1:2可以通过图形直观验证（GH最短，AG和HF较长且AG=HF×1.5）

    **教学说明——点P的轨迹：**

    本图示通过拖拽动画展示动点P的轨迹，帮助学生理解动点问题的核心思路。

    **讲解要点：**

    1. 确定M、N的位置：
       - AM = 2，所以M在A右侧2单位处，即M的坐标为(2, 0)
       - BN = 2，所以N在B左侧2单位处，即N的坐标为(6, 0)
       - C的运动范围：从x=2到x=6

    2. 用参数法分析P的轨迹：
       - 设C的坐标为(t, 0)，其中t ∈ [2, 6]
       - A(0, 0)，C(t, 0)，所以AC = t
       - △ACD为等边三角形，D的坐标为(t/2, t√3/2)
       - B(8, 0)，C(t, 0)，所以BC = 8 - t
       - △BCE为等边三角形，E的坐标为((8+t)/2, (8-t)√3/2) = (4+t/2, (8-t)√3/2)
       - P为DE中点：
         * P的x坐标 = (t/2 + 4 + t/2) / 2 = (t + 4) / 2 = t/2 + 2
         * P的y坐标 = (t√3/2 + (8-t)√3/2) / 2 = 8√3/4 = 2√3
       - 所以P的坐标为(t/2 + 2, 2√3)

    3. 关键发现——不变量：
       - P的纵坐标始终为2√3，与t无关！
       - 这意味着P始终在水平线y = 2√3上运动
       - 当t从2变到6时，P的x坐标从3变到5
       - P的轨迹是从(3, 2√3)到(5, 2√3)的水平线段

    4. 路径长度：
       - 路径长度 = 5 - 3 = 2

    **课堂引导建议：**
    - 先让学生拖拽观察，提出猜想："P似乎在一条水平线上运动"
    - 引导学生用参数法验证猜想，发现纵坐标为不变量
    - 强调"不变量"在动点问题中的重要性
    - 总结：解决动点轨迹问题的关键是找到动点坐标与参数的关系，然后消去参数得到轨迹方程
