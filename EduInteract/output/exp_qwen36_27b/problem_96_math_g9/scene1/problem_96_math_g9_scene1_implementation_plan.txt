[图示主题与整合说明]
- 本图示主题：正方体展开图的面关系分析——标注相对面与相邻面
- 整合的步骤/概念：展开图展示 → 面编号标识 → 相对面配对 → 相邻关系高亮 → 关键结论推导
- 教学价值：教师可通过分步交互，引导学生从直观观察展开图，逐步建立空间想象能力，理解正方体折叠后各面的相对与相邻关系，为解答“墨水在哪个盒子”提供逻辑支撑。

[分步序列]
- 初始状态（步骤0）：
  - 显示完整展开图（6个正方形、边框、折叠虚线、内部图案）
  - 无编号、无高亮、无提示文字
  - 按钮：「上一步」禁用，「下一步」可用
- 步骤1（标注面编号）：
  - 点击「下一步」→ 6个面中心依次淡入编号文字（面1、面2、面3、面4、圆圈面、底面）
  - 提示文字显示：“已标注各面编号，观察图案分布”
- 步骤2（标注相对面）：
  - 点击「下一步」→ 编号保留，新增3组彩色虚线框配对相对面
  - 蓝色框：面1与面3
  - 红色框：面2与面4
  - 绿色框：圆圈面与底面
  - 提示文字显示：“相对面：面1↔面3，面2↔面4，圆圈面↔底面”
- 步骤3（标注相邻关系）：
  - 点击「下一步」→ 相对面框保留，圆圈面周围4个面（面1~4）出现蓝色实线高亮边框
  - 提示文字显示：“圆圈面与面1、面2、面3、面4均相邻”
- 步骤4（关键结论）：
  - 点击「下一步」→ 面3与面4边框变为绿色高亮，强调二者相邻且均与圆圈面相邻
  - 提示文字显示：“面3与面4相邻，且都与圆圈面相邻 → 折叠后位置关系确定”
  - 按钮：「下一步」禁用，「上一步」可用

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」：位于(300,450)，点击回退至上一状态，步骤0时禁用
  - 「▶ 下一步」：位于(450,450)，点击推进至下一状态，步骤4时禁用
- 教师操作流程：
  1. 展示初始展开图，提问学生观察图案
  2. 点击「下一步」逐步添加编号、相对面、相邻面、结论
  3. 配合提示文字讲解空间折叠逻辑
  4. 可随时回退复习任意步骤

[技术实现]
- JS 库选择：原生 SVG + Vanilla JS（无需外部库，轻量高效，适合静态几何与分步状态切换）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [ 800 × 500 画布 ]
  ┌──────────────────────────────────────────────────────────────┐
  │                                                              │
  │              ┌─────┐                                         │
  │              │圆圈面│                                         │
  │              └──┬───┘                                         │
  │  ┌─────┐┌─────┐├─────┤┌─────┐                                │
  │  │ 面1 ││ 面2 ││ 面3 ││ 面4 │                                │
  │  └──┬───┘└──┬───┘└─────┘└─────┘                                │
  │     │       │                                                 │
  │  ┌─────┐    │                                                 │
  │  │底面 │    │                                                 │
  │  └─────┘    │                                                 │
  │                                                              │
  │           [ 提示文字区域 y=380 ]                              │
  │                                                              │
  │        [◀ 上一步]          [▶ 下一步]                        │
  │           y=450              y=450                           │
  └──────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  - 状态机：`let currentStep = 0; const maxStep = 4;`
  - 元素显隐控制：通过 CSS `opacity` 和 `display` 控制各步骤元素淡入/淡出（transition: 0.3s ease）
  - 坐标计算：所有图形基于预设坐标表硬编码，确保像素级对齐
  - 事件绑定：按钮点击触发 `updateStep(delta)` 函数，更新 `currentStep` 并重绘对应状态
  - 防抖/边界检查：步骤0禁用上一步，步骤4禁用下一步，按钮样式同步更新（opacity: 0.5 + pointer-events: none）
- ID 命名规范：所有交互元素及关键图形 ID 以 `scene1-` 为前缀（如 `scene1-face1`, `scene1-btn-next`, `scene1-hint-text`）
- IIFE 隔离：全部 JS 逻辑包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染
- 渲染方式：SVG `<g>` 分组管理各步骤元素，通过 `setAttribute('opacity', val)` 控制可见性，保持 DOM 结构稳定
