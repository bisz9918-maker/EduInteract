[图示主题与整合说明]
- 本图示主题：从二次函数 y=ax²+bx+1 的图象判断系数 a、b 的符号
- 整合的步骤/概念：展示抛物线图象 → 高亮开口方向判断 a<0 → 高亮对称轴位置判断 b<0 → 总结结论
- 教学价值：教师通过分步按钮引导学生逐步观察抛物线的开口方向和对称轴位置，推理出系数 a、b 的符号，为后续判断一次函数 y=ax+b 的图象经过哪些象限奠定基础

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位置 (260,450)-(360,480)，点击后回退到上一步，隐藏当前步骤新增元素
  - 「下一步 ▶」按钮：位置 (440,450)-(540,480)，点击后进入下一步，显示该步骤新增元素
  - 步骤指示文字：位置 (400,465)，显示 "步骤 X/3"
- 教师操作流程：
  1. 图示加载后显示抛物线基础图象（步骤 0），教师可先让学生观察图象特征
  2. 点击「下一步」进入步骤 1，红色箭头和 "a<0" 标注出现，教师讲解开口方向与系数 a 的关系
  3. 点击「下一步」进入步骤 2，对称轴虚线和推导过程出现，教师讲解对称轴位置与系数 b 的关系
  4. 点击「下一步」进入步骤 3，绿色总结框出现，教师总结 a<0、b<0 的结论
  5. 随时点击「上一步」回退到任意步骤复习

[技术实现]
- JS 库选择：原生 SVG（本场景为坐标系和函数图，元素数量适中，原生 SVG 足够且轻量）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  +---------------------------------------------------+
  |                    y                              |
  |                    ↑                              |
  |              /----|----\                          |
  |            /    (a<0)  \                          |
  |           |      ↓      |                         |
  |     -----(1)----|-------\---- x                   |
  |   /      |      |        \    →                   |
  |  /       |  O   |         \                       |
  | /        |      |          \                      |
  |/         | 对称轴|           \                     |
  +----------+------+------------+--------------------+
  |  推导文字  |      |   总结框   |                    |
  |           |      |  [a<0]    |                    |
  |           |      |  [b<0]    |                    |
  |           |      |           |                    |
  |     ◀上一步    步骤X/3    下一步▶                 |
  +---------------------------------------------------+
  ```
- 关键实现要点：
  1. **状态机设计**：维护当前步骤变量 `currentStep`（0~3），每个步骤对应一组 SVG 元素的显示/隐藏
  2. **元素分组**：用 `<g>` 标签将每个步骤的元素分组（`scene1-step1`、`scene1-step2`、`scene1-step3`），通过 CSS `opacity` 控制显隐
  3. **动画效果**：新增元素使用 CSS transition `opacity 0.5s ease-in` 实现淡入效果
  4. **坐标计算**：数学坐标 (x,y) → 画布坐标 (420+x*70, 350-y*70)
  5. **抛物线绘制**：用 SVG `<path>` 的 cubic bezier 曲线近似：`M 175,403 C 250,403 250,123 315,123 C 380,123 380,403 455,403`
  6. **箭头绘制**：用 `<path>` 绘制箭头杆 + 箭头头部三角形
  7. **按钮状态**：步骤 0 时「上一步」禁用（opacity=0.4, pointer-events=none），步骤 3 时「下一步」禁用
  8. **事件绑定**：按钮点击事件更新 `currentStep`，调用 `updateScene()` 函数更新所有元素的显隐状态

- **ID 命名规范**：所有交互元素 ID 以 `scene1-` 为前缀
  - `scene1-step1-group`：步骤 1 元素组
  - `scene1-step2-group`：步骤 2 元素组
  - `scene1-step3-group`：步骤 3 元素组
  - `scene1-btn-prev`：上一步按钮
  - `scene1-btn-next`：下一步按钮
  - `scene1-step-indicator`：步骤指示文字
  - `scene1-svg`：主 SVG 容器

- IIFE 隔离：所有 JS 代码包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染
