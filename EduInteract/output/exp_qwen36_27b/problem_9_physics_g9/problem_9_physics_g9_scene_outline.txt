    **题目原文：**

    如图所示电路，已知电源电压为3V，灯泡L₁标有"6V 6W"，灯L₂标有"3V 3W"，下列有关说法正确的是（）

    A. S₂断开，S₁接b，L₁可以正常发光

    B. S₂断开，S₁接a，L₂的功率为3W

    C. S₂断开，S₁接a，L₂更亮

    D. S₂闭合，S₁接b，L₂更亮

    **题目分析：**

    本题考察电路连接方式的分析及电功率的计算。核心在于理解单刀双掷开关S₁和旁路开关S₂在不同组合下对电路结构的影响。

    **关键数据：**
    - 电源电压 U = 3V
    - L₁：额定6V 6W → R₁ = U²/P = 36/6 = 6Ω
    - L₂：额定3V 3W → R₂ = U²/P = 9/3 = 3Ω

    **电路结构分析：**
    - S₂断开，S₁接a：L₁与L₂串联
    - S₂断开，S₁接b：仅L₁接入电路
    - S₂闭合，S₁接b：L₁与L₂并联

    **图示规划：**

    规划一个交互式电路图示，通过多状态切换展示三种开关组合下的电路连接方式、电流路径和灯泡功率，帮助教师直观对比各选项对应的电路情况。

    **教学说明——SCENE_1：电路开关状态分析**

    **引导学生观察的步骤：**

    1. **先展示原始电路图（初始状态）**

    引导学生识别电路中的元件：电源（3V）、两个灯泡（L₁和L₂）、两个开关（S₁为单刀双掷开关，S₂为普通开关）。让学生先理解S₁接a和接b分别意味着什么，S₂闭合和断开分别意味着什么。

    2. **切换到状态1：S₂断开，S₁接a（对应选项B和C）**

    - 观察蓝色电流路径：电流从电源正极出发，依次经过L₁和L₂，再经S₁回到负极。L₁和L₂**串联**。
    - 计算：总电阻 R = R₁ + R₂ = 6Ω + 3Ω = 9Ω
    - 电路电流 I = U/R = 3V/9Ω = 1/3 A
    - L₁功率：P₁ = I²R₁ = (1/3)² × 6 = 2/3 W
    - L₂功率：P₂ = I²R₂ = (1/3)² × 3 = 1/3 W
    - **结论：P₁ > P₂，L₁更亮。选项B说L₂功率为3W（错误，实际为1/3W），选项C说L₂更亮（错误，L₁更亮）。**

    3. **切换到状态2：S₂断开，S₁接b（对应选项A）**

    - 观察蓝色电流路径：电流从电源正极出发，经过L₁后经S₁(b)回到负极。L₂不在回路中。
    - L₁两端电压为3V，但L₁额定电压为6V，所以**L₁不能正常发光**（实际功率P₁ = U²/R₁ = 9/6 = 1.5W，远小于额定功率6W）。
    - **结论：选项A说L₁可以正常发光（错误）。**

    4. **切换到状态3：S₂闭合，S₁接b（对应选项D）**

    - 观察蓝色电流路径：出现**两条并联路径**。
      - 路径1：电源正极→L₁→S₁(b)→负极
      - 路径2：电源正极→S₂→L₂→S₁(b)→负极
    - L₁和L₂**并联**，两端电压均为3V。
    - L₁功率：P₁ = U²/R₁ = 9/6 = 1.5W
    - L₂功率：P₂ = U²/R₂ = 9/3 = 3W
    - **结论：P₂ > P₁，L₂更亮。选项D正确！**

    **关键公式回顾：**
    - 电阻计算：R = U²/P（由额定电压和额定功率）
    - 串联电路：I相同，P = I²R，电阻大的功率大
    - 并联电路：U相同，P = U²/R，电阻小的功率大

    **完整解答与课堂讲解建议：**

    **第一步：计算灯泡电阻**

    由额定值计算电阻：
    - L₁：R₁ = U₁²/P₁ = 6²/6 = 6Ω
    - L₂：R₂ = U₂²/P₂ = 3²/3 = 3Ω

    **第二步：逐项分析**

    **选项A：S₂断开，S₁接b**

    仅L₁接入电路，L₁两端电压为3V。L₁额定电压为6V，3V < 6V，所以L₁**不能正常发光**。A错误。

    **选项B：S₂断开，S₁接a**

    L₁与L₂串联，总电阻R = 6 + 3 = 9Ω，电流I = 3/9 = 1/3 A。L₂功率P₂ = I²R₂ = (1/3)² × 3 = 1/3 W ≠ 3W。B错误。

    **选项C：S₂断开，S₁接a**

    同上，P₁ = (1/3)² × 6 = 2/3 W，P₂ = 1/3 W。P₁ > P₂，**L₁更亮**。C说L₂更亮，错误。

    **选项D：S₂闭合，S₁接b**

    L₁与L₂并联，两端电压均为3V。P₁ = 3²/6 = 1.5W，P₂ = 3²/3 = 3W。P₂ > P₁，**L₂更亮**。D正确。

    **答案：D**

    **课堂讲解建议：**

    1. 先让学生独立分析电路结构，画出三种开关状态下的等效电路图
    2. 使用交互式图示逐一展示三种状态，让学生观察电流路径的变化
    3. 强调串联和并联电路中功率比较的不同方法：串联看电阻（P=I²R），并联看电阻倒数（P=U²/R）
    4. 提醒学生注意"正常发光"的含义：实际电压等于额定电压
    5. 可进一步提问：如果电源电压改为6V，各选项结论会如何变化？
