[图示主题与整合说明]
- 本图示主题：等腰直角三角形外接圆及已知条件的几何推导

[分步序列]
- 步骤0（初始状态）：显示圆O、弦AB/AC/BC/AD/BD、点A/B/C/D/E/O。所有图形为黑色主线，仅显示顶点标签A/B/C/D/E/O。无高亮、无数值标注。
- 步骤1（标注已知）：
  → 弦BC高亮为蓝色(#1565c0)，弦AD高亮为蓝色(#1565c0)
  → 出现标签BC=4(490,165)、AD=4/5(230,230)
  → 出现等长标记（AC与BC各一条单斜杠）
  → 出现直角标记C及标签∠C=90°(420,115)
- 步骤2（推导直径）：
  → 弦AB高亮为红色(#c62828)，恢复BC/AD为黑色
  → 出现标签AB为直径(400,290)、AB=4√2(400,270)
  → 圆心O标签保持显示
- 步骤3（圆周角性质）：
  → 圆、弦AC、弦BC、点C、点E透明度降为0.25（淡化）
  → △ADB区域填充红色20%透明度，并添加绿色虚线描边
  → 出现直角标记D及标签∠ADB=90°(275,225)
  → 弦AB/AD/BD保持不透明并高亮为红色
- 步骤4（计算BD）：
  → 恢复圆、AC、BC、C、E的不透明度（或保持淡化以突出△ADB）
  → Rt△ADB中AD与AB保持标注，新增标签BD=28/5(410,210)
  → BD弦高亮为蓝色(#1565c0)或红色(#c62828)作为最终结论
  → 步骤指示显示最终状态

（教师可随时点击「上一步」回退复习，状态机维护当前步骤索引0~4）

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「上一步」按钮：位置(280,460)，大小80×30。点击后步骤索引减1，回退到上一状态。
  2. 「下一步」按钮：位置(440,460)，大小80×30。点击后步骤索引加1，进入下一状态。
  3. 步骤指示文本：位置(400,475)，显示"步骤 X / 4"。
- 教师操作流程：
  1. 教师展示步骤0，让学生观察基本图形；
  2. 点击「下一步」进入步骤1，引导学生识别已知条件BC=4和AD=4/5；
  3. 点击「下一步」进入步骤2，提问"为什么AB是直径"，引导学生发现∠C=90°；
  4. 点击「下一步」进入步骤3，强调同弧所对圆周角相等，∠ADB=90°；
  5. 点击「下一步」进入步骤4，在Rt△ADB中应用勾股定理求出BD=28/5；
  6. 可随时回退复习关键步骤。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：纯几何图形，无复杂函数绘图或3D，原生SVG性能最佳且易于精确控制每个元素的显隐/颜色/透明度。
- 画布尺寸：800×500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |         C(400,100)                               |
  |        /    \                                    |
  |       /      \                                   |
  |   D(256,208)  \                                  |
  |     /    E(288,213)\                             |
  |    /        \      \                             |
  |   A(250,250)-O-(400,250)-B(550,250)              |
  |                                                  |
  |   [圆O: 圆心(400,250) R=150]                     |
  |                                                  |
  |                                                  |
  |   [控件栏 y=440~490]                             |
  |   [◀上一步]  步骤 X/4  [下一步▶]                 |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：维护变量 `currentStep`（0~4）。每次点击按钮时更新索引，调用 `renderStep()` 根据状态显隐/修改元素。
  2. 元素显隐：所有步骤专属元素（标签、标记、高亮）初始 `display:none` 或 `opacity:0`，由 `renderStep` 统一控制。
  3. 高亮实现：通过切换元素的 `stroke` 颜色和 `stroke-width` 实现。淡化效果通过设置 `opacity` 或 `stroke-opacity` 实现。
  4. 动画曲线：无需复杂动画，状态切换为即时切换（或0.3s CSS transition），保持教学节奏清晰。
  5. 事件绑定：上一步/下一步按钮绑定 click 事件，更新状态机后重新渲染。
  6. 坐标计算：E点为AC与BD交点，已预计算为(288,213)；D点坐标根据AD=4/5及圆几何关系计算为(256,208)。代码中直接使用这些常量坐标，无需运行时计算。
- ID命名规范：所有SVG元素及控件ID必须以 `scene1-` 为前缀。例如：
  - 圆：`scene1-circle-o`
  - 弦AB：`scene1-chord-ab`
  - 标签BC=4：`scene1-label-bc`
  - 按钮：`scene1-btn-prev`、`scene1-btn-next`
  - 步骤指示：`scene1-step-indicator`
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })()` 中，避免多场景合并时全局变量污染。
