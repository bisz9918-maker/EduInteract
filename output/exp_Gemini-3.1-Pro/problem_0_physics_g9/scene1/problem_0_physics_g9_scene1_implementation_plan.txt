[图示主题与整合说明]
- 本图示主题：杠杆动态失衡过程与力矩变化分析
- 整合的步骤/概念：初始平衡条件、等距移动过程、力矩改变量对比、最终失衡状态
- 教学价值：教师可通过分步动画，将抽象的力矩变化具象化为面积对比（柱状图），帮助学生直观理解“减小的力矩大，则剩余力矩小，导致该端上翘”的物理逻辑，有效突破教学难点。

[视觉元素清单]
- 杠杆系统：黑色粗线杠杆，黑色三角支点。
- 人物图形：使用简单的 SVG Path 绘制火柴人。大人（#1565c0），小孩（#c62828）。
- 重力向量：带箭头的线段，大人重力长 90px，小孩重力长 45px，保持竖直向下。
- 力臂标注：水平虚线（#888888），两端带短竖线，下方居中放置文本标签。
- 移动距离 $\Delta L$：在杠杆上方紧贴杠杆的绿色（#2e7d32）粗线段，表示移动轨迹。
- 力矩对比图：
  - 大人矩形：左侧坐标轴标 $G_{大人}$，底部标 $\Delta L$，内部文本 $\Delta M_{大人}$。
  - 小孩矩形：左侧坐标轴标 $G_{小孩}$，底部标 $\Delta L$，内部文本 $\Delta M_{小孩}$。
  - 填充色 #2e7d32（透明度 30%），边框分别为蓝色和红色。

[分步序列]
- 初始状态（步骤0）：显示杠杆水平平衡，大人在 x=200，小孩在 x=650。显示重力箭头和初始力臂 $L_{大人}, L_{小孩}$。图表区和结论区为空白。
- 步骤1（等距移动）：点击「下一步」。大人平移至 x=280，小孩平移至 x=570。重力箭头跟随平移。杠杆上出现两段绿色的 $\Delta L$ 轨迹线。力臂 $L_{大人}$ 缩短至 (280-350)，$L_{小孩}$ 缩短至 (350-570)。
- 步骤2（力矩对比）：点击「下一步」。上方区域淡入力矩对比柱状图（矩形），展示 $\Delta M_{大人}$ 的面积明显大于 $\Delta M_{小孩}$ 的面积，中间出现“$>$”符号。
- 步骤3（最终状态）：点击「下一步」。杠杆绕支点(350,300)顺时针旋转 8 度。大人、小孩及 $\Delta L$ 轨迹随杠杆旋转。重力箭头保持竖直向下，但位置跟随人物更新。力臂标注淡出。中心位置淡入结论文本：“剩余力矩：小孩端 > 大人端，小孩端下沉”。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：在 SVG 内部底部（y=460 区域）居中放置两个按钮，使用绝对定位覆盖在 SVG 上。
- 教师操作流程：教师首先介绍初始平衡条件（步骤0）；点击下一步演示两人移动（步骤1）；再次点击引导学生观察力矩减小量的面积对比（步骤2）；最后点击展示杠杆失衡的最终结果（步骤3），验证推导。

[技术实现]
- JS 库选择：原生 SVG + 原生 JS（使用 CSS transition 实现平滑动画）。无需引入外部动画库，现代浏览器对 SVG 属性的 CSS 过渡支持良好。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```text
  [图表区 y: 20-180] (力矩对比矩形)
  [结论区 y: 180-220] (最终结论文本)
  [主图区 y: 220-420] (杠杆、人物、重力、力臂)
  [控件区 y: 450-490] (上一步/下一步按钮)
  ```
- 关键实现要点：
  - 状态机设计：定义 `currentStep` (0~3)，每次点击按钮更新状态并调用 `renderStep(step)` 函数。
  - 旋转与保持竖直：将杠杆、大人、小孩、$\Delta L$ 放入 `<g id="scene1-lever-system">` 中，步骤3时对该组应用 `transform: rotate(8deg)`（需设置 `transform-origin: 350px 300px`）。
  - 重力箭头独立更新：重力箭头不放入旋转组，而是通过 JS 直接更新其 `x1, y1, x2, y2` 属性，并利用 CSS `transition: all 0.5s` 实现平滑移动。
    - 步骤1：大人箭头平移至 x=260，小孩箭头平移至 x=590。
    - 步骤3：计算旋转后人物基点的新坐标，更新箭头位置。大人箭头更新为 x=260.68, y=240.26~330.26；小孩箭头更新为 x=587.84, y=305.60~350.60。
  - ID 命名规范：所有元素 ID 均以 `scene1-` 开头（如 `scene1-adult`, `scene1-chart`），确保全局唯一。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免变量污染。
