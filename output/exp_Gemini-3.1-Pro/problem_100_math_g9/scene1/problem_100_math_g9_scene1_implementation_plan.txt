[图示主题与整合说明]
- 本图示主题：图①和图②底面拼接失败的 3D 验证
- 整合的步骤/概念：整合了图①和图②的展开图识别与 3D 折叠过程，对比展示直角三角形无法拼合成正三角形。
- 教学价值：教师可通过拖拽滑块，直观展示 2D 展开图向 3D 几何体折叠的动态过程。通过切换图①和图②，清晰对比两种错误图形在折叠后的空间位置关系（重叠或发散），帮助学生理解正三棱柱底面的空间构成条件。

[视觉元素清单]
- 元素名：3D 展开图模型 | 位置：场景中心 | 标签：边长“2”、四个“60°”标签、四个直角标记
- 颜色/样式：
  - 背景：#ffffff
  - 矩形面：蓝高亮 #1565c0，透明度 30%，黑色边框
  - 阴影三角形面：红高亮 #c62828，透明度 30%，黑色边框

[分步序列]
- 初始状态（展开率 0%）：显示 2D 展开图平铺在 xy 平面上。相机处于斜视角度 (0, -8, 10)。
- 拖拽滑块（0% -> 100%）：
  - 上下四个阴影三角形绕水平边缘向内折叠 90°。
  - 左右两个侧面矩形（连同三角形）绕垂直边缘向内折叠 120°（注：为实现 3D 闭合成正三棱柱，侧面实际需向内折起 120° 使得二面角为 60°，大纲中的“60度”指代的是最终形成的几何特征角）。
  - 相机平滑过渡到正俯视角度 (0, 0, 12)。
- 最终状态（展开率 100%）：
  - 图①状态下：俯视图清晰显示四个直角三角形在顶部和底部向外发散并交叉，无法填满标准正三角形轮廓。
  - 图②状态下：俯视图清晰显示四个直角三角形在顶部和底部向内重叠，同样无法形成标准正三角形。

[标签冲突检查]
- 标签“2”：位于中间矩形底部外侧，周围无其他标签，无冲突。
- 标签“60°”：位于各自三角形的锐角内部，随 3D 模型移动，无冲突。
- 直角标记：位于各自三角形的直角内部，随 3D 模型移动，无冲突。
- 2D UI 控件：分布在画布最顶部和最底部，不遮挡居中的 3D 模型。

[交互方案]
- 交互类型：多状态切换（图① / 图②） + 连续拖拽滑块
- 控件说明：
  - 顶部状态按钮（`scene1-btn-fig1`, `scene1-btn-fig2`）：点击切换当前显示的图形结构，实时更新 3D 模型的顶点数据。
  - 底部滑块（`scene1-slider-fold`）：拖拽控制折叠进度（0~100）。
- 教师操作流程：教师首先展示图①的展开图，拖动滑块演示折叠过程，在 100% 时指出顶部三角形发散交叉的错误；然后点击“图②”按钮，模型瞬间切换为图②的折叠状态，指出三角形重叠的错误。支持随时拖回滑块查看中间过程。

[技术实现]
- JS 库选择及原因：Three.js（用于 3D 建模、折叠动画和相机控制），CSS2DRenderer（用于将 HTML 标签完美挂载到 3D 空间坐标上，防止重叠和透视变形）。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500 (Three.js Canvas)]
  [顶部绝对定位：图① | 图② 按钮]
  [底部绝对定位：展开 0% ======O====== 100% 折叠 滑块]
  ```
- 关键实现要点：
  - **层级模型 (Scene Graph)**：构建 `CenterRect -> LeftHinge -> LeftRect -> TopLeftHinge -> TopLeftTriangle` 的父子层级结构。折叠动画只需改变 Hinge 的 `rotation` 属性，Three.js 会自动计算所有子元素的复杂空间坐标。
  - **几何体更新**：切换图①/图②时，只需更新四个 Triangle Mesh 的 `BufferGeometry` 顶点坐标，无需重建整个场景。
  - **折叠角度**：侧面 Hinge 绕 y 轴旋转 `t * 120°`，上下三角形 Hinge 绕 x 轴旋转 `t * 90°`。
  - **相机动画**：在滑块 `oninput` 事件中，使用 `camera.position.lerpVectors` 在斜视和俯视之间插值，并始终 `camera.lookAt(0,0,0)`。
  - **ID 命名规范**：所有 DOM 元素 ID 以 `scene1-` 开头。
  - **IIFE 隔离**：所有逻辑封装在 `(function() { ... })()` 中。
