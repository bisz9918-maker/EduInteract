[图示主题与整合说明]

- 步骤1：点击「下一步」→ 高亮直角 △B1OC1（蓝色填充+边框）。出现 ∠B1C1O 圆弧及"60°"（蓝色）。推导面板更新计算过程。
- 步骤2：点击「下一步」→ 移除上一步高亮。高亮直角 △D1E1C1（蓝色）。出现正方形C1处直角符号。出现 ∠D1C1E1 圆弧及"30°"（蓝色）。出现 D1E1 边长"1/2"（蓝色）。推导面板更新。
- 步骤3：点击「下一步」→ 移除上一步高亮。高亮正立正方形 D1E1E2B2（蓝色）。出现 B2E2 边长"1/2"（蓝色）。推导面板更新。
- 步骤4：点击「下一步」→ 移除上一步高亮。高亮直角 △B2E2C2（蓝色）。B1C1 和 B2C2 线段加粗变红。∠B1C1O 和 ∠B2C2E2 圆弧变红。出现 ∠B2C2E2="60°"（红色）。出现 B2C2 边长"√3/3"（蓝色）。推导面板更新。

[技术实现]
- JS 库选择：原生 SVG（绘制几何图形） + MathJax（CDN引入，用于推导面板的数学公式渲染）。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [-------------------------------------------------]
  [  y轴                                推导面板    ]
  [   ^                                 (MathJax)   ]
  [   |   A1                                        ]
  [   |  /  \                                       ]
  [   | /    D1---B2                                ]
  [ B1 /      |   | \ A2                            ]
  [   |       |   |  \                              ]
  [ --O---C1--E1--E2--C2--D2-----> x轴              ]
  [                                                 ]
  [           [上一步] [下一步]                     ]
  [-------------------------------------------------]
  ```
- 关键实现要点：
  - 状态机设计：定义 `currentStep` 变量（0~5），每次点击按钮更新变量并调用 `renderStep()` 函数。
  - 元素显隐：通过修改 SVG 元素的 `opacity` 或 `display` 属性控制各步骤元素的出现与消失。
  - 公式渲染：推导面板使用 `foreignObject` 嵌套 `div`，每次更新 `innerHTML` 后调用 `MathJax.typesetPromise()` 重新渲染公式。
  - ID 命名规范：所有交互元素和图形元素 ID 均以 `scene1-` 为前缀（如 `scene1-btn-next`, `scene1-tri-b1oc1`）。
  - IIFE 隔离：所有 JavaScript 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
