[分步序列]
- 初始状态（步骤0）：显示所有基础图形、顶点标签、∠BAC 直角标记、∠DAF 直角标记（黑色）、∠DAE 45° 标记（黑色）。隐藏 ∠EAF 标记、等长标记、高亮多边形和文本框。
- 步骤1（角度推导）：点击「下一步」。∠DAF 直角标记和 ∠DAE 标记变为绿色（#2e7d32）并加粗。显示 ∠EAF 45° 标记（绿色）。右上角文本框出现，显示角度推导过程（得出 ∠DAE = ∠EAF）。
- 步骤2（全等条件）：点击「下一步」。线段 AD 变为蓝色加粗，AF 变为红色加粗，AE 变为绿色加粗。显示 AD 和 AF 的双刻度线。文本框更新，列出 SAS 全等条件。
- 步骤3（得出结论）：点击「下一步」。显示 △AED（蓝色半透明填充）和 △AEF（红色半透明填充）。线段 DE 变为蓝色加粗，EF 变为红色加粗。显示 DE 和 EF 的单刻度线。文本框更新，得出全等结论和 DE=EF。

[技术实现]
- JS 库选择及原因：原生 SVG。本场景主要由直线、圆弧和多边形组成，原生 SVG 能够完美处理这些几何图形，且配合 CSS transition 可以轻松实现颜色、透明度和线宽的平滑动画过渡。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×440]
      A
     /|\ \
    / | \  \
   F  |  \   \
   |  |   \    \
   B--E----D----C
  [文本框 580x100 区域]
  [控件栏 800×60，y=440~500]
    [上一步] [下一步]
  ```
- 关键实现要点：
  - 使用绝对定位的 HTML `<div>` 作为文本框，方便实现富文本排版（换行、颜色高亮）。
  - 维护一个 `currentState` 变量（0~3），每次点击按钮更新变量并调用 `updateState()` 函数。
  - `updateState()` 函数中，根据当前状态设置各个 SVG 元素的 `stroke`、`stroke-width`、`opacity` 和 `fill-opacity` 属性。
  - 为所有需要动画的 SVG 元素添加 `style="transition: all 0.3s ease;"`，实现平滑过渡。
- ID 命名规范：所有元素 ID 均以 `scene1-` 开头，如 `scene1-line-ad`、`scene1-poly-aed`、`scene1-btn-next` 等。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
