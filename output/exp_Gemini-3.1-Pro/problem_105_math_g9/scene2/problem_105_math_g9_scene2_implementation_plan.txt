[图示主题与整合说明]
- 本图示主题：利用旋转变换证明 △ABF ≌ △ACD 并推导线段间的关系
- 整合的步骤/概念：同角的余角相等、旋转变换（△ACD 旋转至 △ABF）、直角三角形的构造与性质（勾股定理与等量代换）
- 教学价值：教师可通过分步动画，直观展示图形的旋转过程，帮助学生理解线段和角度是如何通过全等变换进行转移的，最终在 Rt△EBF 中利用勾股定理得出线段平方和的关系。

[视觉元素清单]
- 基础图形：△ABC 及内部连线，黑色实线 2px。
- 旋转动画元素：独立的 △ACD 色块（蓝色 #1565c0，透明度 20%），包裹在可旋转的 `<g>` 标签中。
- 旋转轨迹：点 C 到 B、点 D 到 F 的圆弧，灰色虚线 #888888。
- 角度标记：
  - ∠BAC, ∠DAF：直角折线标记。
  - ∠BAF（红 #c62828）, ∠CAD（蓝 #1565c0）：圆弧标记。
  - ∠C, ∠ABF：圆弧标记及 "45°" 文本。
  - ∠EBF：直角折线标记（绿 #2e7d32）。
- 边长标记：BF 与 CD 上的等长短划线（Tick marks）。
- 高亮区域：△ABF（红 #c62828，透明度 20%），△EBF（绿 #2e7d32，透明度 20%）。

[分步序列]
- 初始状态（步骤0）：显示基础图形及所有顶点标签。
- 步骤1：点击「下一步」→ 高亮 ∠BAC 和 ∠DAF 的直角标记；随后显示 ∠BAF（红色弧）和 ∠CAD（蓝色弧），表示同角的余角相等。
- 步骤2：点击「下一步」→ 高亮 △ACD（蓝色半透明）；显示 C->B 和 D->F 的灰色虚线轨迹弧；触发动画，将 △ACD 绕点 A 顺时针旋转 90°（在 SVG 坐标系中顺时针 90° 即可将 C 映射到 B）使其与 △ABF 重合。
- 步骤3：点击「下一步」→ 旋转完成，将重合处的 △ABF 高亮为红色半透明；在 BF 和 CD 上显示等长短划线；显示 ∠C 和 ∠ABF 的 45° 标记。
- 步骤4：点击「下一步」→ 高亮 ∠EBF 的直角标记；高亮直角 △EBF（绿色半透明）；在右侧空白处显示结论文本（BE² + CD² = DE² 的推导）。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：在 SVG 底部 (y=460) 居中放置两个按钮，用于控制步骤 0-4 的切换。
- 教师操作流程：教师点击“下一步”逐步引导学生观察角度相等、旋转过程、边角转移，最后得出直角三角形的勾股定理结论。可随时点击“上一步”回退重新演示旋转动画。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。图形由简单的直线、多边形和圆弧组成，原生 SVG 的 `<path>` 和 `transform` 动画足以完美实现，无需引入外部库。
- 画布尺寸：800 × 500 px
- 布局草图：
  [图示区 800×450]
    (A 在上方居中，B,E,D,C 在下方水平排列，F 在 B 正上方)
    (右侧大片空白用于放置推导结论文本)
  [控件栏 800×50] (包含上一步/下一步按钮)
- 关键实现要点：
  - 坐标系：SVG 默认坐标系（向下为 Y 正轴）。
  - 旋转动画：使用 CSS `transition: transform 1s ease-in-out;`，通过 JS 切换 class 实现 `transform: rotate(90deg)`。注意 `transform-origin` 必须设置为点 A 的坐标 `400px 130px`。
  - 轨迹圆弧：使用 SVG `<path>` 的 `A` (椭圆弧) 指令绘制。例如 C 到 B 的弧：`M 600 330 A 282.8 282.8 0 0 1 200 330`。
  - 状态机：定义 `currentStep` 变量，在 `updateState()` 函数中根据当前步骤控制各 SVG 元素的 `opacity` 或 `display` 属性。
- ID 命名规范：所有交互元素 ID 必须以 `scene2-` 为前缀（如 `scene2-btn-next`, `scene2-triangle-acd`）。
- IIFE 隔离：所有 JS 代码包裹在 `(function() { ... })()` 中。
