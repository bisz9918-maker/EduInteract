题目分析：
本题综合考查了圆的基本性质（直径所对的圆周角、同弧所对的圆周角）、相似三角形的判定与性质以及勾股定理的应用。解题的核心在于通过圆的性质发现隐含的直角和相等的圆周角，从而构建相似三角形，将几何问题转化为代数方程求解。

整体讲解思路：

  1. 挖掘隐含条件：由等腰Rt△ABC的外接圆可知，斜边AB即为圆的直径。根据“直径所对的圆周角是直角”，可得∠ADB=90°。
  2. 寻找相似关系：在△ADE和△BCE中，除了已知的∠ADE=∠BCE=90°外，通过同弧（弧CD）所对的圆周角相等，可得∠DAE=∠CBE，从而证明△ADE ∽ △BCE。
  3. 代数转化求解：利用相似比AD:BC=1:5，设所求线段AE=x，将Rt△ADE的其他边用含x的代数式表示，最后在Rt△ADE中应用勾股定理列方程求解。

图示规划说明：
本题的推理过程环环相扣，适合在同一个几何图形上进行逐步推演。因此规划一个分步导航的交互图示，带领学生从初始条件出发，逐步添加辅助标记（直角、等角、代数表达式），直观呈现从几何推理到代数计算的完整思维过程。

教学讲解建议：

步骤0：审题与条件梳理
引导学生观察图形，明确已知条件。特别强调“等腰Rt△ABC的外接圆”这一关键信息，这是解题的突破口。

步骤1：挖掘隐含直角

  • 提问：既然是直角三角形的外接圆，那么圆心O在哪里？斜边AB与圆有什么关系？
  • 引导得出：斜边AB即为圆的直径。
  • 追问：根据圆的性质，直径所对的圆周角是多少度？
  • 结论：∠ADB = 90°。同时原有的∠ACB = 90°。这样我们就得到了两个直角三角形△ADE和△BCE的基础条件。

步骤2：发现相似三角形

  • 引导：在△ADE和△BCE中，已经有一对直角相等（∠ADE = ∠BCE = 90°），要证明它们相似，还需要找什么？（另一对角相等）
  • 提示：观察图形中的圆周角，有没有同弧所对的角？
  • 结论：弧CD所对的圆周角 ∠DAE 和 ∠CBE 相等。因此，△ADE ∽ △BCE。

步骤3：利用相似比进行代数转化

  • 讲解：既然三角形相似，对应边就成比例。已知 AD = 4/5，BC = 4，所以相似比为 1:5。
  • 设未知数：设我们要求的 AE = x。
  • 推导：因为 AC = 4，所以 CE = 4 - x。根据相似比 DE : CE = 1 : 5，可以得出 DE = (4 - x) / 5。

步骤4：勾股定理求解

  • 总结：现在我们把目光集中在 Rt△ADE 上。它的三边分别是 AD = 4/5，AE = x，DE = (4 - x) / 5。
  • 列方程：根据勾股定理 $AE^2 = AD^2 + DE^2$，得到方程 $x^2 = (

rac{4}{5})^2 + [
rac{4-x}{5}]^2$。

  • 解方程：
  1. $25x^2 = 16 + (4-x)^2$
  2. $25x^2 = 16 + 16 - 8x + x^2$
  3. $24x^2 + 8x - 32 = 0$
  4. $3x^2 + x - 4 = 0$
  5. $(3x+4)(x-1) = 0$
  • 得出结论：解得 x = 1 或 x = -4/3（舍去）。所以 AE 的长为 1，正确答案选 C。
