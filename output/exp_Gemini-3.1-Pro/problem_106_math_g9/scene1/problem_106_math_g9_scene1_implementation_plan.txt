[图示主题与整合说明]
- 本图示主题：利用圆周角定理与相似三角形求解线段长度
- 整合的步骤/概念：直径所对圆周角、同弧所对圆周角、相似三角形判定与性质、勾股定理列方程
- 教学价值：通过分步动画，教师可以引导学生逐步发现隐藏的直角、相等的圆周角，从而识别相似三角形，并利用相似比将未知线段转化，最后在直角三角形中利用勾股定理建立方程。图示清晰地展示了每一步的几何关系，避免了学生在复杂图形中迷失。

[分步序列]
- 初始状态（步骤0）：显示基础图形（圆O，△ABC，线段AD, BD），所有点及点名，已知长度"4"和"4/5"。
- 步骤1：点击「下一步」→ 高亮直径AB（变蓝加粗），出现蓝色直角标记 ∠ACB 和 ∠ADB。
- 步骤2：点击「下一步」→ 高亮弧CD（变红加粗），出现红色圆周角标记 ∠DAE 和 ∠CBE。△ADE 出现蓝色半透明填充，△BCE 出现红色半透明填充。
- 步骤3：点击「下一步」→ 出现绿色代数表达式标签：AE旁的"x"，CE旁的"4-x"，DE旁的"(4-x)/5"。
- 步骤4：点击「下一步」→ △ADE 边框变蓝加粗，底部出现蓝色方程文本 "(4/5)² + [(4-x)/5]² = x²"。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：底部居中放置两个按钮，控制步骤0到4的切换。
- 教师操作流程：教师首先展示原图，然后点击下一步引导学生发现直径对应的直角，再下一步找出同弧对应的相等圆周角并识别相似三角形，接着下一步展示利用相似比转化边长，最后一步列出勾股定理方程。

[技术实现]
- JS 库选择及原因：原生 SVG。图形由简单的线段、圆弧和多边形组成，SVG 能够完美实现精确的坐标定位和高质量的矢量渲染，且易于通过 CSS 控制状态和动画。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  +------------------------------------------------+
  |                                                |
  |                   C(400,100)                   |
  |                  / \                           |
  |                 /   \                          |
  |                /     \                         |
  |       D(256,208)      \                        |
  |             / \_       \                       |
  |            /    \_E     \                      |
  |           /       \_     \                     |
  |          /          \_    \                    |
  | A(250,250)----O(400,250)---B(550,250)          |
  |                                                |
  |            (4/5)² + [(4-x)/5]² = x²            |
  |                                                |
  |             [◀上一步] [下一步▶]                |
  +------------------------------------------------+
  ```
- 关键实现要点：
  - 使用 `data-step` 属性控制元素的显示与隐藏，配合 CSS `transition` 实现平滑的透明度过渡。
  - 弧CD使用 `<path>` 的 `A` 指令绘制：`M 400 100 A 150 150 0 0 0 256 208`。
  - 角度标记使用精确计算的 `<path>` 绘制，确保与线段完美贴合。
  - 状态机：维护一个 `currentStep` 变量（0-4），点击按钮时更新该变量，并遍历所有带有 `data-show-step` 或类似属性的 DOM 元素，根据当前步骤决定其 `opacity` 或 `stroke-width`。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-btn-next`, `scene1-arc-cd`）。
- IIFE 隔离：所有 JS 代码必须包裹在 `(function() { ... })()` 中，避免全局变量污染。
