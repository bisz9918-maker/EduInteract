[分步序列]
- 初始状态（步骤0）：显示点 A, B, C, M, N 及其标签，显示线段 MN, AM, AN, BM, BN。隐藏所有角度弧线、多边形填充和右侧公式。
- 步骤1：点击「下一步」→ 高亮线段 BM 和 AN（加粗），显示 M 点处的两个角 $x$ 弧线及标签，显示 N 点处的两个角 $y$ 弧线及标签。
- 步骤2：点击「下一步」→ 取消线段高亮。显示 $	riangle AMN$ 的蓝色填充，高亮其三边。显示 A 点处的角 $\alpha$ 弧线及标签。右侧浮现公式 1（$	riangle AMN$ 内角和）。
- 步骤3：点击「下一步」→ 隐藏 $	riangle AMN$ 填充及边高亮。显示 $	riangle BMN$ 的红色填充，高亮其三边。显示 B 点处的角 $eta$ 弧线及标签。右侧浮现公式 2（$	riangle BMN$ 内角和）。
- 步骤4：点击「下一步」→ 隐藏 $	riangle BMN$ 填充及边高亮。右侧依次浮现公式 3（两式相加）和公式 4（化简结果）。
- 步骤5：点击「下一步」→ 显示 $	riangle CMN$ 的绿色填充，高亮其三边。显示 C 点处的 $\angle MCN$ 弧线。右侧依次浮现公式 5、公式 6 和结论“选项 C 正确”。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：在画布底部 (y=460) 居中放置两个按钮。
  - `scene1-btn-prev`：上一步，回退到上一个状态。
  - `scene1-btn-next`：下一步，推进到下一个状态。
- 教师操作流程：教师在讲解时，首先展示基础图形，然后点击“下一步”引导学生观察角平分线带来的等角关系；继续点击展示两个大三角形的内角和方程；再点击展示方程的代数处理过程；最后点击展示目标三角形的内角和并得出最终结论。

[技术实现]
- JS 库选择及原因：原生 SVG 用于绘制几何图形（线段、多边形、圆弧），原生 DOM 操作用于控制公式的显示与隐藏，MathJax 用于渲染右侧的数学公式。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 500×500] | [公式区 300×440]
  (几何图形)        | (推导方程)
  ---------------------------------
  [控件栏 800×60，底部居中按钮]
  ```
- 关键实现要点：
  - 状态机设计：定义 `currentStep` 变量（0-5），编写 `updateScene()` 函数，根据 `currentStep` 的值设置各 SVG 元素和公式 DOM 的 `opacity` 或 `display` 属性。
  - 坐标计算：所有几何坐标已在计划中硬编码，直接使用。角度弧线使用 SVG `<path>` 的 `A` 指令绘制。
  - 动画曲线：使用 CSS `transition: opacity 0.3s ease, stroke-width 0.3s ease` 实现元素的平滑显隐和高亮。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-poly-amn`, `scene1-eq1`）。
- IIFE 隔离：所有 JS 代码包裹在 `(function() { ... })()` 中，避免全局变量污染。
