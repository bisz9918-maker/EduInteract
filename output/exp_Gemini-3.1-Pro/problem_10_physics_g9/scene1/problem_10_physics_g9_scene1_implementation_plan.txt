[图示主题与整合说明]
- 本图示主题：液体体积、密度、压强与压力的关系推导
- 整合的步骤/概念：通过分步动画，依次对比两个容器中液体的体积、推导密度关系、对比底部压强，最后利用“割补法”直观对比底部压力与液体总重力的关系。
- 教学价值：教师可以通过分步导航，引导学生一步步进行逻辑推理，特别是最后一步的“割补法”辅助线，能将抽象的压力公式转化为直观的体积对比，极大地降低了理解难度。

[视觉元素清单]
- 容器与桌面：黑色实线，stroke-width: 2。
- 液体：多边形填充，颜色 #1565c0，默认透明度 0.3。
- 深度 h 标注：黑色双向箭头，配合水平虚线指示液面和底部。
- 速度与拉力标注：黑色单向箭头与斜体文本。
- 辅助圆柱（割补法）：矩形填充，颜色 #2e7d32，透明度 0.4；两侧边界为 #888888 虚线。
- 动态标签（V, P, N）：黑色或红色文本，使用 HTML <sub> 标签实现下标，或 SVG <tspan baseline-shift="sub">。
- 结论文本：HTML <div>，绝对定位在 SVG 上方，字体大小 20px，颜色 #c62828，加粗。

[分步序列]
- 初始状态（步骤0）：显示桌面、两个容器、内部液体（透明度 0.3）、h 标注、v/2v/F1/F2 标注。隐藏所有动态标签和辅助圆柱，结论文本为空。
- 步骤1（体积与密度）：点击「下一步」。
  - 视觉变化：左右液体透明度提升至 0.6，凸显体积差异。显示标签 V₁ 和 V₂。
  - 结论文本显示："由于 m₁ = m₂ 且 V₁ < V₂，可得 ρ₁ > ρ₂"
- 步骤2（底部压强）：点击「下一步」。
  - 视觉变化：液体透明度恢复 0.3。h 标注的箭头变为红色，左右容器底部的线段加粗并变为红色（高亮受力面积和深度）。显示标签 P₁ 和 P₂。
  - 结论文本显示："由于 ρ₁ > ρ₂ 且 h 相同，根据 P = ρgh 可得 P₁ > P₂"
- 步骤3（底部压力）：点击「下一步」。
  - 视觉变化：底部红线恢复黑色，h 箭头恢复黑色。显示左右绿色的辅助圆柱（透明度 0.4）及垂直虚线。左侧绿柱在蓝液体内部（说明 N₁ < G），右侧绿柱超出蓝液体范围（说明 N₂ > G）。显示标签 N₁ 和 N₂。
  - 结论文本显示："割补法：N₁ = ρ₁ghS₁ < G，N₂ = ρ₂ghS₂ > G，故 N₁ < N₂"

- P1 标签 (250,325) vs 桌面 (300)：位于桌面下方 25px，无冲突。

所有标签均已精确规划，确保在任何步骤下都不会发生重叠。

[交互方案]
- 交互类型：分步按钮导航（◀ 上一步 / 下一步 ▶）。
- 控件说明：在 SVG 容器底部（Y=450~490 区域）居中放置两个按钮。
- 教师操作流程：教师首先展示题目初始状态，然后点击“下一步”依次讲解体积与密度的关系、压强的关系，最后通过“割补法”动画直观讲解压力的关系。可随时点击“上一步”回退。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript。SVG 非常适合绘制精确的几何图形和处理透明度叠加。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```text
  [图示区 800×500]
    (150,260) h箭头
    (250,220) 左容器及液体      (550,220) 右容器及液体
    (250,325) P1/N1标签         (550,325) P2/N2标签
    (400,380) 结论推导文本区
  [控件栏 Y=450] ◀ 上一步 | 下一步 ▶
  ```
- 关键实现要点：
  - 使用一个 `currentStep` 变量（0~3）记录当前状态。
  - 编写 `updateScene()` 函数，根据 `currentStep` 控制各个 SVG 元素的 `opacity`、`stroke` 等属性，以及更新结论文本的 `innerHTML`。
  - 按钮点击事件中更新 `currentStep` 并调用 `updateScene()`，同时处理按钮的禁用状态（如步骤 0 时禁用“上一步”）。
  - ID 命名规范：所有元素 ID 必须以 `scene1-` 为前缀（如 `scene1-liquid-left`, `scene1-btn-next`）。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
