[图示主题与整合说明]
- 本图示主题：整体受力分析与二力平衡
- 整合的步骤/概念：将容器与液体视为一个整体，分析竖直方向的重力与支持力平衡，水平方向的摩擦力与拉力平衡，并强调滑动摩擦力与速度无关。
- 教学价值：教师可通过分步展示，引导学生逐步完成受力分析。先竖直后水平，最后通过二力平衡得出拉力相等的结论，同时利用视觉上的“划掉速度”来纠正学生“速度大则拉力大”的常见误区。

[视觉元素清单]
- 容器与桌面：黑色描边，初始状态显示内部液体（下半部分灰色填充）。
- 整体化遮罩：步骤1时，容器整体填充 #888888（透明度 20%），表示视为一个整体。
- 速度向量：蓝色箭头，带有 v 和 2v 标签。
- 竖直力向量：灰色箭头，G_total 和 N_table，分别从重心上下延伸。
- 摩擦力向量：红色箭头，f1 和 f2，在接触面处向左。
- 拉力向量：绿色箭头，F1 和 F2，在容器右侧面向右。
- 否定标记：红色叉号，用于划掉速度标签。

[分步序列]
- 初始状态（步骤0）：显示容器（带液体）、桌面、速度向量 v 和 2v。推导文本区为空。
- 步骤1：点击「下一步」→ 容器变为整体填充（灰色半透明）。出现竖直方向的 G_total 和 N_table 向量。文本区显示：“竖直方向受力平衡：G_total = N_table”。
- 步骤2：点击「下一步」→ 出现水平向左的摩擦力 f1 和 f2 向量。文本区显示：“压力相同、接触面相同 ⇒ f1 = f2”。
- 步骤3：点击「下一步」→ 出现水平向右的拉力 F1 和 F2 向量。速度向量 v 和 2v 变淡（opacity: 0.3）并出现红色叉号。F1, f1, F2, f2 向量开始闪烁。文本区显示：“匀速直线运动 ⇒ 二力平衡 ⇒ F1 = f1, F2 = f2 ⇒ F1 = F2”。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：在 SVG 容器内部底部（y=450~490 区域）居中放置两个按钮。
- 教师操作流程：教师点击“下一步”逐步引导学生分析受力。第一步分析竖直方向，第二步分析摩擦力，第三步分析拉力并得出结论。可随时点击“上一步”回退。

[技术实现]
- JS 库选择：原生 SVG + 原生 JS。推导文本区使用绝对定位的 HTML `<div>` 叠加在 SVG 上，使用 HTML 实体（如 `&rArr;`、`<sub>`）渲染公式，轻量且高效。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×390]
    (左容器及受力)      (右容器及受力)
  [推导文本区 800×60 (y=390~450)]
  [控件栏 800×50 (y=450~500)]
    [上一步] [下一步]
  ```
- 关键实现要点：
  - 状态机：定义 `currentStep` (0~3)，每次点击按钮更新状态并调用 `renderStep()`。
  - 动画：使用 CSS `transition: opacity 0.3s ease` 实现向量的平滑显隐。
  - 闪烁效果：通过动态添加/移除 CSS class `.scene2-blinking` 实现，利用 `@keyframes` 控制 opacity 在 1 和 0.3 之间交替。
  - ID 命名规范：所有 DOM 元素的 ID 均以 `scene2-` 开头（如 `scene2-btn-next`, `scene2-vec-f1`），避免全局冲突。
  - 代码隔离：所有逻辑封装在 `(function() { ... })()` 立即执行函数中。
