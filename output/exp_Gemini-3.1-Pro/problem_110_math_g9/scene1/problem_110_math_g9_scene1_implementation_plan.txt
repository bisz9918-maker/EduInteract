[图示主题与整合说明]
- 本图示主题：台球反弹的几何原理与角度计算
- 整合的步骤/概念：反射定律（∠1=∠2）、直角三角形的构造、直角三角形两锐角互余的计算。
- 教学价值：教师可以通过分步导航，引导学生从物理现象（台球反弹）抽象出几何模型（直角三角形），并逐步推导角度，逻辑清晰，避免信息过载。

[分步序列]
- 初始状态（步骤0）：显示台球桌、球袋、白球、黑球、入射/反射轨迹、法线、∠1/∠2/∠3 的黑色圆弧及对应标签 "1", "2", "3"。隐藏三角形、直角符号和推导文本。
- 步骤1（反射原理）：
  - 视觉变化：∠1 和 ∠2 的圆弧及标签变为蓝色（#1565c0），线宽加粗。
  - 新增元素：左侧推导文本区出现第一行 "反射定律：∠1 = ∠2"。
- 步骤2（直角三角形）：
  - 视觉变化：显示右上角的直角三角形（绿色半透明填充）。
  - 新增元素：右上角出现直角符号（90°）。
- 步骤3（计算 ∠2）：
  - 视觉变化：∠3 的圆弧变为红色（#c62828），线宽加粗。标签 "3" 更新为红色的 "30°"。
  - 新增元素：左侧推导文本区出现第二行 "在直角三角形中，" 和第三行 "∠2 = 90° - 30° = 60°"。
  - 标签更新：∠2 的标签更新为蓝色的 "60°"。
- 步骤4（得出结论）：
  - 视觉变化：∠1 和 ∠2 闪烁或轻微放大以强调。
  - 新增元素：左侧推导文本区出现第四行 "因此，∠1 = ∠2 = 60°"。
  - 标签更新：∠1 的标签更新为蓝色的 "60°"。

[交互方案]
- 交互类型：分步按钮导航。
- 控件说明：在 SVG 底部 (y=450) 放置两个按钮「◀ 上一步」和「下一步 ▶」。
- 教师操作流程：教师点击“下一步”逐步展示反射定律、构造直角三角形、代入数值计算、得出最终结论。每一步配合口头讲解，节奏完全可控。

[技术实现]
- JS 库选择：原生 SVG。SVG 非常适合绘制精确的几何图形、线段、圆弧和文本，且易于通过 DOM 操作修改颜色和文本内容。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  +------------------------------------------------+
  |                                                |
  |   [推导文本区]         (P) ∠1|∠2  (A)        |
  |   反射定律...             /  |  \   |        |
  |   在直角三角形...        /   |   \  |        |
  |   ∠2 = ...              O    |    * |        |
  |   因此...              /     |     \|        |
  |                                    (B)∠3     |
  |                                                |
  |             [ ◀ 上一步 ] [ 下一步 ▶ ]          |
  +------------------------------------------------+
  ```
- 关键实现要点：
  - 状态机设计：定义 `currentStep` (0-4)，编写 `updateScene()` 函数，根据 `currentStep` 的值控制各元素的 `display`、`stroke`、`fill` 和 `textContent` 属性。
  - 圆弧绘制：使用 SVG `<path>` 的 `A` (Arc) 指令。例如 ∠2 的圆弧：`M 557 80 A 30 30 0 0 0 542 106`。
  - 动画过渡：可以为元素的 `opacity` 和 `stroke` 添加 CSS `transition`，使步骤切换更平滑。
  - ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-arc1`, `scene1-text-step1`）。
  - IIFE 隔离：所有 JS 代码包裹在 `(function() { ... })()` 中，避免全局变量污染。
  - 箭头标记：使用 `<defs><marker id="scene1-arrow"...>` 定义箭头，并在轨迹线上使用 `marker-end="url(#scene1-arrow)"`。
