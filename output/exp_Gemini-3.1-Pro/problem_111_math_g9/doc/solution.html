题目分析：
本题是一道经典的几何与三角函数结合题，核心在于利用等腰三角形性质和垂直平分线的性质进行角度推导，发现特殊的“黄金三角形”（顶角为36°的等腰三角形）。通过连接BE，可以构造出相似三角形，从而利用相似比求出未知线段的长度，最后在直角三角形中利用三角函数定义求出cosA的值。

整体讲解思路：

  1. 角度推导：从已知等腰△ABC和∠C=72°出发，求出∠A和∠ABC均为36°和72°。
  2. 利用垂直平分线：DE是AB的垂直平分线，连接BE，得到AE=BE，进而推导出∠ABE=36°，∠EBC=36°，∠BEC=72°。
  3. 相似三角形求解：发现△BCE也是等腰三角形，且与△ABC相似。设BC=x，则AE=BE=BC=x，EC=4-x。利用相似比列方程求出x。
  4. 三角函数计算：在Rt△ADE中，已知AD=2，AE=x，代入求出cosA。

图示规划说明：
为了保持视觉连贯性并避免重复，我们将所有几何推导步骤整合在一个交互式图示中。通过分步按钮导航，教师可以引导学生逐步添加辅助线、标注角度、高亮相似三角形，并最终聚焦到直角三角形计算cosA。

教学说明与引导要点：

本图示通过分步导航，帮助学生理清复杂的几何关系。教师在操作时可按以下逻辑引导：

  1. 初始状态与基础角度：

引导学生观察已知条件，提问：“已知AB=AC，∠C=72°，你能求出其他两个内角吗？”
点击下一步，展示∠ABC=72°，∠A=36°。

  1. 垂直平分线的应用：

提问：“D是AB中点，DE⊥AB，这说明DE是什么线？它有什么性质？”
点击下一步，连接BE，强调垂直平分线上的点到线段两端距离相等，即AE=BE。

  1. 深入推导角度与线段关系：

提问：“既然AE=BE，那么∠ABE是多少？剩下的∠EBC和∠BEC呢？”
点击下一步，展示角度计算：∠ABE=∠A=36°，∠EBC=72°-36°=36°，∠BEC=180°-72°-36°=72°。
引导学生发现：△BCE也是等腰三角形，所以BC=BE=AE。

  1. 相似三角形与方程：

提问：“观察△BCE和△ABC，它们的内角分别是多少？这说明了什么？”
点击下一步，高亮两个相似三角形。
讲解推导：

  1. 因为∠C=∠C，∠BEC=∠ABC=72°，所以△BCE ∽ △ABC。
  2. 设BC=x，则AE=x，EC=4-x。
  3. 根据相似比：BC / AB = EC / BC，即 x / 4 = (4-x) / x。
  4. 化简得 x^2 + 4x - 16 = 0。
  5. 解得 x = -2 ± 2√5。因为x>0，所以 x = 2√5 - 2。
  1. 回归目标计算cosA：

提问：“我们现在知道了AE的长度，题目要求cosA，应该在哪个三角形中求？”
点击下一步，高亮Rt△ADE。
讲解推导：

  1. 在Rt△ADE中，AD是AB的一半，所以 AD = 2。
  2. AE = x = 2√5 - 2。
  3. cosA = AD / AE = 2 / (2√5 - 2) = 1 / (√5 - 1) = (√5 + 1) / 4。

总结：
本题正确答案为 C。
