[图示主题与整合说明]
- 本图示主题：利用垂直平分线与相似三角形求解cosA
- 整合的步骤/概念：等腰三角形角度计算、垂直平分线性质、辅助线添加、相似三角形比例关系、直角三角形三角函数计算
- 教学价值：教师可以通过分步导航，像“剥洋葱”一样引导学生逐步发现隐藏的几何关系。从基础角度推导，到利用垂直平分线构造等腰三角形，再到发现相似三角形并列出方程求解边长，最后回归直角三角形求三角函数值，逻辑链条清晰，视觉反馈直观。

[分步序列]
- 步骤0（初始状态）：显示△ABC、直线DE、直角标记、AD与DB的等长标记。显示标签A,B,C,D,E。显示边长AB="4", AC="4"。显示∠C="72°"。右侧显示已知条件。
- 步骤1（基础角度）：蓝高亮填充△ABC。显示∠ABC="72°"和∠A="36°"。右侧显示角度计算过程。
- 步骤2（垂直平分线）：移除△ABC填充。绿高亮加粗直线DE。出现辅助线BE。红高亮加粗AE、BE。添加AE、BE的红色等长标记。右侧显示垂直平分线性质。
- 步骤3（角度推导）：隐藏∠ABC="72°"。显示∠ABE="36°"、∠EBC="36°"、∠BEC="72°"。红高亮加粗AE、BE、BC。添加BC的红色等长标记。右侧显示等腰三角形推导。
- 步骤4（相似三角形）：移除红高亮加粗。蓝高亮填充△BCE，蓝高亮描边△ABC。隐藏AC="4"。显示AE="x", EC="4-x", BC="x"。右侧显示相似三角形比例方程及求解结果。
- 步骤5（计算目标）：移除蓝高亮。红高亮填充Rt△ADE。隐藏AB="4"，显示AD="2"。隐藏AE="x"，显示AE="2√5-2"。右侧显示cosA的最终计算过程。

[标签冲突检查]
- 标签"D"(245, 245) 与 边长"AB=4"(220, 250)：间距约25px，无冲突。
- 标签"E"(365, 280) 与 边长"AC=4"(370, 250)：间距约30px，无冲突。
- 标签"E"(365, 280) 与 角度"∠BEC=72°"(340, 320)：间距约47px，无冲突。
- 边长"AE=x"(305, 205) 与 边长"AD=2"(265, 190)：分别在不同线段的外侧，间距约42px，无冲突。
- 角度"∠ABC=72°"(245, 365) 与 角度"∠ABE=36°"(235, 345) / "∠EBC=36°"(265, 370)：若同时显示会重叠。解决方案：步骤3中隐藏∠ABC，再显示∠ABE和∠EBC。
- 边长"AC=4" 与 "AE=x", "EC=4-x"：若同时显示会重叠。解决方案：步骤4中隐藏AC=4。

[交互方案]
- 交互类型：分步按钮导航
- 控件说明：底部居中放置两个按钮「◀ 上一步」和「下一步 ▶」，附带当前步骤指示器（如 1 / 6）。
- 教师操作流程：教师点击“下一步”逐步展示推导过程。每一步右侧的文本区会同步更新对应的数学推导，配合左侧图形的高亮和标注变化，方便教师按逻辑顺序讲解。

[技术实现]
- JS 库选择：原生 SVG（用于精确绘制几何图形、圆弧、高亮遮罩） + 原生 JavaScript（控制状态机和DOM显示隐藏）。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  +---------------------------------------------------------+
  |  [SVG 图示区 500x450]         [HTML 文本区 250x300]     |
  |       A                       【已知条件】              |
  |      / \                      △ABC 中，AB = AC = 4      |
  |     /   \                     ∠C = 72°                  |
  |  D /-----\ E                  DE 垂直平分 AB            |
  |   /       \                                             |
  |  /         \                                            |
  | B-----------C                                           |
  |                                                         |
  |             [ ◀ 上一步 ]  1 / 6  [ 下一步 ▶ ]           |
  +---------------------------------------------------------+
  ```
- 关键实现要点：
  - 状态机设计：定义 `currentStep` 变量（0-5），编写 `updateScene()` 函数，根据当前步骤控制各 SVG 元素的 `display` 或 `opacity` 属性，以及更新右侧 HTML 文本内容。
  - 坐标计算：所有坐标已在计划中硬编码，直接使用，无需在 JS 中进行复杂的三角函数计算。
  - 圆弧绘制：使用 SVG `<path>` 的 `A` (elliptical arc) 指令绘制角度标记。
  - ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-tri-abc`, `scene1-btn-next`）。
  - 隔离性：所有 JS 代码封装在 `(function() { ... })()` 立即执行函数中，避免变量污染。
  - 动画过渡：可为高亮遮罩（如 `fill-opacity`）添加简单的 CSS `transition` 以提升视觉体验。
