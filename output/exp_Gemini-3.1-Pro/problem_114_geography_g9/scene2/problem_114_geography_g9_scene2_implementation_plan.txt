[图示主题与整合说明]
- 本图示主题：极地俯视图中的纬度分布与太阳直射规律
- 整合的步骤/概念：将极地投影图（俯视图）的纬度圈层结构与地球侧视图中的太阳直射范围进行几何对齐与逻辑映射。通过水平虚线，将极地投影中各纬度圈的底部与侧视图中对应的北半球纬度线精准对齐，直观展示两者的等价关系。
- 教学价值：帮助学生建立空间转换能力，理解极地俯视图中的同心圆实际上对应着地球侧视图中的不同纬度线，进而将侧视图中易于理解的太阳直射规律（回归线之间）映射回极地俯视图，破解“A点/B点直射次数”的判断难点。

[视觉元素清单]

[分步序列]
- 初始状态（步骤0）：仅显示极地俯视图的基础线框（3个同心圆、十字辅助线、中心极点及"90°"标签）。
- 步骤1（常规纬度标注）：在极地俯视图上依次出现纬度标签（66.5°、23.5°、0°）。同时出现A点（绿色 #2e7d32）及其标签，B点（绿色）及其标签。
- 步骤2（直射规律映射）：引入右侧的地球侧视图及4条水平对齐虚线。显示直射区域背景色和静态太阳光线。启动动画：直射光线和直射点在南北回归线（y=269至331）之间平滑上下移动。
- 步骤3（结论分析）：保持动画运行。侧视图中赤道变蓝加粗，出现“一年两次直射”；南北回归线变红加粗，出现“一年一次直射”。极地图中A点旁出现蓝色“A: 两次”，B点旁出现红色“B: 一次”。底部居中出现结论文本“选项A、B均错”。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：在SVG画布底部（y=460~490区域）居中放置两个按钮及步骤指示器（如“步骤 1 / 3”）。
- 教师操作流程：教师点击“下一步”逐步引导学生从极地俯视图的认知，过渡到侧视图的对应，再通过动画观察直射点移动，最后得出A、B两点的直射次数结论。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript。SVG非常适合精确的几何图形、线条对齐和高质量文本渲染。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800x450]
  左侧：极地俯视图 (cx=220)      右侧：地球侧视图 (cx=600)
       (同心圆)  ----虚线对齐---->  (水平纬度线)
                 ----虚线对齐---->
  [控件区 800x50]
           [上一步]  步骤 0 / 3  [下一步]
  ```
- 关键实现要点：
  - 使用 `<g>` 标签对不同步骤的元素进行分组（如 `id="scene2-step1"`），通过JS控制 `opacity` 或 `display` 实现分步显示。
  - 动画实现：使用 `requestAnimationFrame`，根据 `Date.now()` 计算正弦值，动态更新直射点 `<circle>` 的 `cy` 属性和直射光线 `<line>` 的 `y1`, `y2` 属性。公式：`y = 300 + 31 * Math.sin(time / 500)`。
  - 状态机：维护 `currentStep` 变量，每次点击按钮更新变量并调用 `updateView()` 函数，该函数根据当前步骤显示/隐藏对应的 `<g>` 组。
- ID 命名规范：所有元素 ID 必须以 `scene2-` 为前缀（如 `scene2-polar-eq`, `scene2-btn-next`）。
- IIFE 隔离：所有 JS 代码必须包裹在 `(function() { ... })()` 中，避免全局变量污染。
