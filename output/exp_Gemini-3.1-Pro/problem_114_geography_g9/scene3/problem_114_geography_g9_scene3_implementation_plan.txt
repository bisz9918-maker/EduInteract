[图示主题与整合说明]
- 本图示主题：经度推算与东西半球的划分
- 整合的步骤/概念：整合了基于自转方向的经度推算过程，以及经度坐标在东西半球平面图上的映射。
- 教学价值：教师可以通过分步演示，清晰地向学生展示如何根据地球自转方向推算经度，并将极地投影下的点映射到常规的经纬网平面图上，直观判断其所在半球。

[分步序列]
- 初始状态（步骤0）：显示左右两幅极地图的基础结构（圆、8等分线、0°和180°标签、自转箭头、A点和B点及其基础标签）。平面图隐藏。
- 步骤1：点击「下一步」→ 左图中，一条绿色动态弧线从0°沿顺时针方向（自转方向）生长，依次经过并显示“45°E”、“90°E”，最终停在A点，显示“135°E”。
- 步骤2：点击「下一步」→ 右图中，一条绿色动态弧线从0°沿逆时针方向（自转方向）生长，经过一个扇区到达B点，显示“45°E”。
- 步骤3：点击「下一步」→ 下方展开世界经纬网平面图，绘制出20°W和160°E分界线，并用红蓝两色高亮东西半球。随后，A点和B点从极地图中的位置动态飞入平面图的对应经度位置（A到135°E，B到45°E），并显示带经度的标签，直观证明两者均在东半球。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：底部居中放置两个按钮，用于控制步骤的前进和后退。
- 教师操作流程：教师首先展示极地图，提问学生如何根据自转方向推算经度。点击下一步，演示A点的推算过程；再点击下一步，演示B点的推算过程。最后点击下一步，展开平面图，将极地坐标映射到平面坐标，总结东西半球的判断方法。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。SVG 适合绘制精确的几何图形和地图网格。动画可通过 CSS transition 和 SVG stroke-dasharray/stroke-dashoffset 实现，无需引入外部库。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  (200,120)左极地图    (600,120)右极地图
  
  (400,340)世界经纬网平面图
  [控件栏（y=460，居中两个按钮）]
  ```
- 关键实现要点：
  - 极地图的扇区使用 SVG `<line>` 绘制，通过三角函数计算端点坐标。
  - 动态弧线使用 SVG `<path>` 的 `stroke-dasharray` 和 `stroke-dashoffset` 属性实现生长动画。
  - 飞入动画通过在 SVG 中创建两个新的点元素，初始位置设为极地图中点的坐标，在步骤3时通过修改 `cx` 和 `cy` 属性配合 CSS `transition` 平滑移动到平面图目标坐标。
  - 状态机：使用一个变量 `currentStep` 记录当前步骤，每次点击按钮更新状态，并根据状态控制各元素的 `opacity` 和位置。
- ID 命名规范：所有交互元素 ID 必须以 `scene3-` 为前缀（如 `scene3-left-map`, `scene3-btn-next`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
