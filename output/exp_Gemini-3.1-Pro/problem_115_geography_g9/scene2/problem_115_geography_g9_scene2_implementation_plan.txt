[视觉元素清单]

- 点：甲、乙、丙、丁、E、F，黑色圆点，半径 4px。
- 标签：
  - 经度：初始为 20°, 0°, 20°, 40°，步骤1后补全为 20°W, 0°, 20°E, 40°E。
  - 纬度：初始为 66.5°, 23.5°, 0°, 23.5°，步骤1后补全为 66.5°N, 23.5°N, 0°, 23.5°S。
- 方向指示标：十字坐标系，标注 N, S, W, E。
- 动态箭头：蓝色 #1565c0，带箭头线段。
- 色块遮罩：
  - 西半球：左侧 #888888 (10%透明度)
  - 东半球：右侧 #c62828 (10%透明度)
  - 北温带：上方 #2e7d32 (10%透明度)
  - 热带：下方 #c62828 (10%透明度)

[分步序列]
- 步骤0（初始状态）：展示题目原图的二维经纬网，包含甲乙丙丁EF各点及基础刻度（无 N/S/E/W）。
- 步骤1（补全坐标）：根据刻度变化规律，动态添加 N/S、E/W 符号。明确 0° 经线和 0° 纬线（加粗显示）。
- 步骤2（判断方向）：高亮 F 点和 E 点（蓝色）。从 F 点向南画箭头至与 E 点同纬度 (560,260)，再向西画箭头至 E 点 (440,260)，最后合成一条从 F 指向 E 的西南方向箭头。
- 步骤3（半球界线）：清除方向箭头。高亮 20°W 经线（红色 #c62828）。在其左侧区域显示灰色遮罩及“西半球”，右侧区域显示红色遮罩及“东半球”。
- 步骤4（温度带界线）：高亮 23.5°N 纬线（绿色 #2e7d32）。在其上方区域显示绿色遮罩及“北温带（四季分明）”，下方区域显示红色遮罩及“热带（有太阳直射）”。
- 步骤5（锁定交点）：20°W 与 23.5°N 两条高亮线的交点处，点“乙”变为红色，放大并闪烁，得出最终答案。

[交互方案]
- 交互类型：分步按钮导航
- 控件说明：底部居中放置两个按钮：“◀ 上一步” 和 “下一步 ▶”。
- 教师操作流程：教师点击“下一步”逐步展示解题逻辑，从补全坐标到判断方向，再到叠加半球和温度带界线，最后锁定交点。可随时点击“上一步”回退。

[技术实现]
- JS 库选择及原因：原生 SVG，适合绘制精确的几何图形、线段和文本，且易于实现 CSS 动画和状态切换。
- 画布尺寸：800 × 500 px。
- 布局草图：
  [图示区 800×440]
  [控件栏 800×60，包含上一步/下一步按钮]
- 关键实现要点：
  - 状态机设计：定义 `currentStep` 变量（0-5），每次点击按钮更新状态，并调用 `updateScene()` 函数。
  - 动画实现：使用 CSS `transition` 控制透明度（`opacity`）和颜色变化。箭头绘制使用 SVG `<path>` 或 `<line>` 配合 `marker-end`。
  - 闪烁效果：使用 CSS `@keyframes` 为乙点添加 `scale` 和 `opacity` 的脉冲动画。
  - ID 命名规范：所有交互元素 ID 必须以 `scene2-` 为前缀（如 `scene2-btn-next`, `scene2-point-e`）。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，防止变量污染。
