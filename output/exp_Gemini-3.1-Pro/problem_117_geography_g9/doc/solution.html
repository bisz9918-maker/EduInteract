场景导航：Scene 1 | Scene 2

题目：
下列选项正确的是（ ）
A． 甲、乙两地在同一条纬线上
B． 甲、乙两地在同一条经线上
C． 甲在乙的西南方
D． 乙在甲的正东方

题目分析：
本题考查经纬网图中坐标的判读以及两点间相对方向的判定。解题的核心在于根据经纬度的变化规律（“北大北纬，南大南纬；东大东经，西大西经”）准确读出甲、乙两地的经纬度坐标，然后再将两点置于全局坐标系中比较其相对位置。

整体讲解思路：

  1. 首先引导学生观察局部经纬网图，利用经纬度数值的递增方向，判断出东西经和南北纬，并计算出网格间距，从而得出甲、乙两地的精确坐标。
  2. 接着，将求得的甲、乙两地坐标放入一个以赤道和本初子午线为基准的全局直角坐标系中，通过直观的几何位置关系，判断两地的相对方向，逐一验证选项。

教学说明与推导过程：
在得出甲、乙两地的精确坐标后，我们需要判断它们的相对位置。

  1. 甲地坐标为 (30°S, 40°W)，位于南半球、西半球。
  2. 乙地坐标为 (30°N, 40°E)，位于北半球、东半球。
  3. 显然它们既不在同一条纬线上（30°S ≠ 30°N），也不在同一条经线上（40°W ≠ 40°E），故选项 A、B 错误。
  4. 接下来，我们将两点放在以赤道和本初子午线为坐标轴的平面图中，以乙地为参照物，观察甲地的方向。

总结与课堂讲解建议：

  1. 通过坐标系的可视化，学生可以直观地看到：从乙地出发，必须向南走、向西走才能到达甲地。
  2. 因此，甲地在乙地的西南方向，选项 C 正确。
  3. 同理，乙地在甲地的东北方向，选项 D 错误。
  4. 最终正确答案为 C。教师在讲解时，可强调“以谁为参照物，就在谁的位置建立方向标”这一通用解题技巧。
