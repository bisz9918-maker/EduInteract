[图示主题与整合说明]
- 本图示主题：甲乙两地局部经纬网坐标判读
- 整合的步骤/概念：经度与纬度变化规律的识别、网格间距推算、具体坐标的确定
- 教学价值：教师可以通过分步导航，引导学生观察经纬度数值的递增方向，从而推断出南北纬和东西经，并计算出隐藏的刻度值，最终确定具体坐标。这种逐步推导的视觉化展示，能有效帮助学生掌握经纬网判读的核心逻辑。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：在画布底部（Y=450区域）居中放置两个按钮，用于控制步骤（0-4）的前进和后退。
- 教师操作流程：教师首先展示原图，让学生观察甲地的纬度数值变化；点击“下一步”展示纬度推导过程；再次点击展示经度推导过程；接着对乙地进行同样的引导和推导。

[技术实现]
- JS 库选择及原因：原生 SVG。由于本场景主要由直线、文本和简单的箭头组成，SVG 能够提供最清晰的渲染效果和最方便的 DOM 操作，非常适合实现这种带有简单状态切换的图示。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  (左侧网格区)       (右侧网格区)
  [甲坐标框]         [乙坐标框]
  [控件栏: ◀上一步  下一步▶]
  ```
- 关键实现要点：
  - 使用 `<g>` 标签将不同步骤的元素分组，通过控制 `display` 或 `opacity` 属性来实现步骤的切换。
  - 箭头可以使用 `<path>` 配合 `<marker>` 来绘制，确保箭头样式美观。
  - 状态机设计：定义一个全局变量 `currentStep` (0-4)，每次点击按钮更新该变量，并调用一个 `updateView()` 函数。该函数根据 `currentStep` 的值，设置各组元素的可见性以及刻度文字的颜色。
  - ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-step1-group`, `scene1-btn-next`）。
  - IIFE 隔离：所有 JS 代码必须包裹在 `(function() { ... })()` 中，避免全局变量污染。
