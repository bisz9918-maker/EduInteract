[图示主题与整合说明]
- 本图示主题：甲乙两地全局相对方位判定
- 整合的步骤/概念：坐标系定位、参照物方向标建立、相对方向分解与判定。
- 教学价值：教师可通过分步演示，引导学生从建立全局坐标系开始，准确标定两点位置，再以目标点为中心建立局部方向标，最后通过向量分解直观得出相对方向，将抽象的经纬度方位判定转化为严密的几何作图过程。

[分步序列]
- 初始状态（步骤0）：显示全局坐标轴（赤道、本初子午线），以及 N, S, E, W 字母和轴名称。
- 步骤1：点击「下一步」→ 绘制甲点、乙点，显示连接坐标轴的灰色虚线及对应的经纬度刻度标签，显示甲乙两点的坐标文本。
- 步骤2：点击「下一步」→ 在乙点处以动画形式展开绿色的局部十字方向标，并显示局部"北、南、东、西"标签。
- 步骤3：点击「下一步」→ 从乙点向甲点绘制红色主箭头（带动画），随后依次绘制蓝色向南分量箭头和向西分量箭头，最后在主箭头旁浮现红色"西南"结论标签。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：在 SVG 底部 (y=460) 居中放置两个按钮，控制步骤 0-3 的切换。
- 教师操作流程：教师首先介绍全局坐标系（步0），然后标定甲乙两地位置（步1），接着引导学生在乙地建立参照系（步2），最后通过向量分解演示方向判定过程（步3）。

[技术实现]
- JS 库选择及原因：原生 SVG。该场景主要由直线、虚线、箭头和文本构成，SVG 能够完美保证图形清晰度，且易于通过 DOM 操作实现分步动画（如 stroke-dashoffset 实现线条生长动画）。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×450]
    (N)
     |
  ---+---(E)
     |
    (S)
  [控件栏 800×50，包含 上一步/下一步 按钮]
  ```
- 关键实现要点：
  - 状态机设计：定义 `currentStep` 变量（0-3），每次点击按钮更新状态，并调用 `updateScene()` 函数控制各元素的 `opacity` 或 `stroke-dashoffset`。
  - 动画曲线：使用 CSS `transition: all 0.5s ease-in-out` 实现元素的平滑显隐。对于箭头，可使用 SVG `stroke-dasharray` 配合 CSS 动画实现生长效果。
  - ID 命名规范：所有交互元素 ID 必须以 `scene2-` 为前缀（如 `scene2-btn-next`, `scene2-arrow-main`）。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
