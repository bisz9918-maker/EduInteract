[视觉元素清单]
- 电源：左侧长竖线（正极），右侧短粗竖线（负极）。标签 `+` (315,175), `-` (335,175)。
- 开关S：左端点 (230,200)，右端点 (270,200)，闸刀初始倾斜。标签 `S` (250,170)。
- 定值电阻R0：标准矩形框。标签 `R0` (280,350)。
- 电流表A：圆形，内部带 `A` 标签，底部带红色指针（绕圆心底部旋转）。
- 电压表V：圆形，内部带 `V` 标签，底部带红色指针。
- 滑动变阻器R：标准矩形框，内部右侧部分（从滑片到右端）用浅蓝色 `rgba(21, 101, 192, 0.2)` 填充表示有效电阻。滑片为带箭头的折线。标签 `R` (470,210)。
- 螺线管B：浅灰色矩形铁芯，黑色实线表示正面线圈（左下到右上倾斜），灰色曲线表示背面线圈。标签 `B` (530,380)。
- 条形磁铁A：矩形，中间分割，上半部标 `S`，下半部标 `N`。标签 `A` (565,185)。
- 弹簧测力计：外框，内部有刻度线和红色指针。
- 导线：黑色实线连接各元件。
- 动态元素（初始隐藏）：
  - 电流箭头：蓝色 `#1565c0` 三角形，分布在各段导线上。
  - 螺线管极性：红色 `#c62828` 文本 `N` (600,235) 和 `S` (600,410)。
  - 右手定则示意：蓝色弧形箭头环绕螺线管，直箭头向上标示“大拇指(N极)”。
  - 受力箭头：重力 $G$（绿色 `#2e7d32`，向下），拉力 $F_{拉}$（绿色，向上），斥力 $F_{斥}$（红色 `#c62828`，向上）。
  - 磁感线：红色半透明曲线，分布在螺线管两侧。

[分步序列]
- 步骤0（初始状态）：显示完整电路图和力学装置。开关S断开。滑片位于 x=440 处。电表指针归零（偏左-45度）。无电流、无磁场、无受力分析。
- 步骤1（安培定则）：点击「下一步」。开关S闭合。导线上出现蓝色电流箭头。电表指针偏转至初始示数（0度）。螺线管右侧出现右手定则示意图。螺线管上下两端浮现红色的 `N` 和 `S` 极性标注。
- 步骤2（受力分析）：点击「下一步」。条形磁铁A外发黄光高亮。质心处出现受力箭头：向下的 $G$，向上的 $F_{拉}$ 和 $F_{斥}$。右侧浮现平衡方程：$F_{拉} = G - F_{斥}$。
- 步骤3（电路动态变化）：点击「下一步」。滑片向右平移至 x=480。滑动变阻器内的浅蓝色有效电阻区域变短。电流表指针向右偏转（示数变大），电压表指针向左偏转（示数变小）。导线上的电流箭头变粗（stroke-width 增加），表示电流增大。
- 步骤4（力学响应）：点击「下一步」。螺线管周围出现红色的磁感线。向上的斥力 $F_{斥}$ 箭头变长，向上的拉力 $F_{拉}$ 箭头变短。弹簧测力计内部指针上移（示数变小）。顶部空白区浮现结论文本：“滑片右移 → R减小 → I增大 → 磁性增强 → F_斥增大 → F_拉减小。选C”。

[交互方案]
- 交互类型：分步按钮导航
- 控件说明：在 SVG 画布内部底部 (y=460) 放置三个按钮：「◀ 上一步」、「重置」、「下一步 ▶」。
- 教师操作流程：教师首先展示题目初始状态，引导学生观察电路连接；点击下一步闭合开关，引导学生用右手定则判断磁极；再次点击分析磁铁受力情况；接着点击演示滑片移动带来的电路参数变化；最后点击展示最终的力学响应，得出正确选项。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript。SVG 非常适合绘制电路图、几何图形和矢量箭头，且易于通过 DOM 操作实现平移、旋转和路径动画。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  +---------------------------------------------------+
  |          [结论文本区]               [悬挂点]      |
  |                                     [测力计]      |
  |   +---[S]---[电源]---+              [磁铁A]       |
  |   |                  |               | F拉, F斥   |
  |   |            +-[R]-+               V G          |
  |   |            |     |             [螺线管B]      |
  |   |            +-(V)-+             [右手示意]     |
  |   |                  |                            |
  |   +---[R0]-----(A)---+                            |
  |                                                   |
  |             [ ◀ 上一步 ] [ 重置 ] [ 下一步 ▶ ]      |
  +---------------------------------------------------+
  ```
- 关键实现要点：
  - 状态机设计：定义全局变量 `scene1_currentStep = 0`，最大值为 4。每次点击按钮更新 step 值，并调用 `scene1_updateState()` 函数。
  - 动画实现：为 SVG 元素添加 `style="transition: all 0.5s ease;"`，通过 JS 修改元素的 `transform` (如滑片的 `translateX`，指针的 `rotate`)、`opacity` (显示/隐藏)、`d` 属性 (箭头长度变化) 和 `width` (有效电阻区域变化) 来实现平滑过渡。
  - 坐标计算：滑片移动时，不仅要移动滑片本身 `<g>`，还要同步修改连接滑片的导线 `<line>` 的 `x2` 属性，以及有效电阻填充 `<rect>` 的 `x` 和 `width` 属性。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-slider`, `scene1-ammeter-ptr`），确保多场景整合时无冲突。
- IIFE 隔离：所有 JS 代码必须包裹在 `(function() { ... })();` 中，避免污染全局变量空间。
