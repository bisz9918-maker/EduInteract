题目原文：
如图所示，电源电压不变，灯的电阻不变，滑动变阻器的滑片P在移动过程中，电流表的最小示数为0.2A，电压表的最大示数为4V，当滑片P滑到中点时，灯L的功率达到最大，且灯的最大功率与最小功率之比为9：4．下列结论正确的是（ ）
A．电源电压为10V
B．灯的电阻为20Ω
C．滑动变阻器的最大电阻为40Ω
D．电路消耗的最大功率为1.8W

题目分析：
本题是一道经典的动态电路极值问题。首先需要正确识别电路连接方式：灯泡 L 与滑动变阻器串联，电流表测主电路电流，电压表测滑动变阻器两端的电压。
题目中的关键突破口在于“当滑片P滑到中点时，灯L的功率达到最大”。由于串联电路中电阻越小电流越大，灯泡功率越大，这说明滑片 P 的可移动范围受限，其能接入电路的最小电阻状态即为滑片在中点时。因此，滑片 P 是在中点到最右端之间移动。

  1. 状态1（滑片在最右端）： 变阻器接入全部电阻 $R$，此时总电阻最大，电流最小 $I_{min} = 0.2 ext{A}$，变阻器分压最大 $U_{max} = 4 ext{V}$。由此可求出变阻器最大阻值 $R = U_{max} / I_{min} = 20\Omega$。
  2. 状态2（滑片在中点）： 变阻器接入一半电阻 $R/2 = 10\Omega$，此时电流最大 $I_{max}$，灯泡功率最大。
  3. 功率关系： 根据灯泡功率比 $P_{max} : P_{min} = 9 : 4$，由 $P = I^2 R_L$ 可推导出电流比 $I_{max} : I_{min} = 3 : 2$，从而得出 $I_{max} = 0.3 ext{A}$。

最后，利用电源电压不变列出等式：$I_{min}(R_L + R) = I_{max}(R_L + R/2)$，即可解出 $R_L$ 和 $U$，进而求出电路最大功率。

整体讲解思路：

  1. 电路识别与动态过程演示： 首先引导学生看懂电路图，明确各电表测量的对象。通过动态演示滑片移动，直观展示电阻变化引起的电流、电压和灯泡亮度的变化，帮助学生建立物理情景的直观感受，并锁定两个关键的极值状态。
  2. 数形结合与方程求解： 在明确了两个极值状态的物理量后，除了使用纯代数方程求解，还可以引入 $U-I$ 图像。将两个状态转化为坐标系中的两个点，利用“电源电压不变”这一隐含的线性关系（$U_R = U - I R_L$），通过图像的截距和斜率直观求解，加深对闭合电路欧姆定律的理解。

图示规划说明：

  • 图示1： 交互式动态电路图。通过拖拽滑块，实时联动显示变阻器有效接入长度、电表示数变化趋势及灯泡亮度，重点对比“中点”和“右端”两个状态。
  • 图示2： $U-I$ 关系图像。采用分步切换，展示从已知极值点到推导极值点，再到连线求截距（电源电压）和斜率（灯泡电阻）的完整数形结合解题过程。

教学说明与推导过程：
本图示旨在通过数形结合的方法，将抽象的代数方程转化为直观的几何图像，帮助学生掌握利用 $U-I$ 图像求解动态电路问题的高级技巧。

引导步骤：

  1. 定位状态 1（右端点）：

引导学生回顾图示 1 的结论：当滑片在最右端时，变阻器全部接入。已知 $I_1 = 0.2 ext{A}$，$U_1 = 4 ext{V}$。计算变阻器最大阻值：$R =
rac{U1}{I1} =
rac{4 ext{V}}{0.2 ext{A}} = 20\Omega$。在坐标系中描出点 $A(0.2, 4)$。

  1. 推导并定位状态 2（中点）：

当滑片在中点时，变阻器接入阻值为 $R_2 =
rac{R}{2} = 10\Omega$。根据灯泡功率比推导电流：$
rac{P{max}}{P{min}} =
rac{I2^2 RL}{I1^2 RL} =
rac{9}{4}$，解得 $I_2 =
rac{3}{2} I1 = 0.3 ext{A}$。计算此时变阻器两端电压：$U2 = I2 imes R2 = 0.3 ext{A} imes 10\Omega = 3 ext{V}$。在坐标系中描出点 $B(0.3, 3)$。

  1. 连线求解（核心）：

根据串联电路电压规律：$U = U_R + I R_L$，变形得到 $U_R = -R_L I + U$。这表明 $U_R$ 与 $I$ 是一次函数关系，图像是一条直线。连接 $A$、$B$ 两点并延长交于纵轴。纵截距即为当 $I=0$ 时的电压，也就是电源电压 $U$。从图中可直接读出或通过斜率算出 $U = 6 ext{V}$。直线的斜率绝对值即为定值电阻（灯泡）的阻值：$R_L = |
rac{\Delta U}{\Delta I}| =
rac{4 - 3}{0.3 - 0.2} = 10\Omega$。

  1. 验证选项：

A 错误（电源电压为 6V）；B 错误（灯的电阻为 10Ω）；C 错误（最大电阻为 20Ω）。计算最大功率：$P_{总max} = U imes I_{max} = 6 ext{V} imes 0.3 ext{A} = 1.8 ext{W}$，D 正确。

总结：
本题通过“滑片在中点时功率最大”这一隐含条件，巧妙地限定了滑片的有效移动范围。解题的核心在于抓住电源电压不变和灯泡电阻不变这两个不变量，列出两个状态下的方程。
在课堂讲解时，建议：

  1. 先定性后定量：先通过图示 1 让学生定性理解电路的动态变化过程，明确“中点”和“右端”对应的物理极值状态。
  2. 多解法启发：在完成基础的代数方程求解后，务必引入图示 2 的 $U-I$ 图像法。图像法不仅能简化计算，更能培养学生将代数关系几何化的物理直觉，对解决更复杂的动态电路问题大有裨益。

最终得出正确答案为 D。
