[图示主题与整合说明]
- 本图示主题：动态电路的等效分析与极值状态演示
- 整合的步骤/概念：电路实物/原理图识别、滑片移动时的电阻变化、电流表与电压表示数变化趋势、灯泡功率的极值状态（中点与右端）。
- 教学价值：教师可以通过拖拽滑块，直观展示滑动变阻器接入电阻的变化如何引起全电路电流、电压的重新分配，以及灯泡功率（亮度）的非线性变化。帮助学生建立“局部变化引起全局变化”的动态电路思维，并验证题目中 9:4 的功率极值比例。

[视觉元素清单]
- 电路导线：黑色 #000000，线宽 2px。
- 电源、开关、电表、灯泡轮廓：黑色 #000000，线宽 2px。
- 滑动变阻器底框：黑色 #000000，线宽 2px，无填充。
- 变阻器有效电阻段：红色 #c62828，线宽 6px，从 x=300 到 x=px。
- 变阻器无效电阻段：灰色 #888888，线宽 4px，虚线 (4,4)，从 x=px 到 x=500。
- 电压表测量范围指示线：蓝色 #1565c0，线宽 2px，带两端短竖线。
- 灯泡发光效果：黄色 #fbc02d，圆形填充，置于灯泡底层，透明度随功率 P_L 在 0.3 到 1.0 之间变化。
- 文本标签：字体大小 14px-16px，颜色与对应元素一致（如 U_V 标签用蓝色，R_P 用红色）。

[分步序列]
- 初始状态（右端极值）：滑片 P 位于右端 (px=500)。
  - 变阻器有效电阻最长 (R_P = 20.0 Ω)。
  - 电流最小 (I = 0.20 A)，电压表最大 (U_V = 4.00 V)。
  - 灯泡最暗 (P_L = 0.40 W，发光透明度 0.3)。
- 交互状态（向左拖拽）：教师用鼠标/手指拖拽滑片 P 向左移动。
  - 红色有效电阻段实时变短，灰色无效段变长。
  - 蓝色测量范围指示线实时缩短。
  - 数据面板中 R_P 减小，I 增大，U_V 减小，P_L 增大。
  - 灯泡发光透明度实时增加，亮度提升。
- 最终状态（中点极值）：滑片 P 被限制到达中点 (px=400)。
  - 变阻器有效电阻减半 (R_P = 10.0 Ω)。
  - 电流最大 (I = 0.30 A)，电压表最小 (U_V = 3.00 V)。
  - 灯泡最亮 (P_L = 0.90 W，发光透明度 1.0)。
  - 验证题目条件：最大功率 0.9W 与最小功率 0.4W 之比恰好为 9:4。

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：滑片 P 本身作为可拖拽控件。在滑片 P 及附近区域添加透明的扩大点击区（cursor="ew-resize"），方便教师操作。
- 教师操作流程：教师在讲解时，直接用鼠标按住滑片 P 向左拖动，引导学生观察红色电阻段的变化，同时观察右侧数据面板中电流、电压的实时变化趋势，最后停在中点，强调功率 9:4 的极值关系。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。电路图由标准几何图形构成，原生 SVG 渲染清晰且易于绑定拖拽事件，无需引入庞大的外部库。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +---------------------------------------------------+
  |       U=6V            S                           |
  |   +---||||---+-------/  -------+       [状态数据] |
  |   |          |                 |       R_P = ...  |
  |  (A) 0.20A   |                (L)      I   = ...  |
  |   |          |                 |       U_V = ...  |
  |   |         (V) 4.00V          |       P_L = ...  |
  |   |          |                 |                  |
  |   |          +--------+--------+                  |
  |   |                   | P                         |
  |   |                   V                           |
  |   +----------[========|--------] R                |
  |                中点      右端                     |
  |              |___U_V__|                           |
  +---------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态计算函数：`updateScene(px)`，根据 `px` (400~500) 计算 $R_p = (px - 300) / 10$。
  2. 物理量计算：$I = 6 / (10 + R_p)$，$U_V = I 	imes R_p$，$P_L = I^2 	imes 10$。
  3. DOM 更新：获取各 SVG 元素的 ID，实时更新滑片 `x1/x2`、有效/无效电阻线段的 `x1/x2`、测量指示线的宽度、灯泡发光圆的 `opacity`，以及各文本标签的 `textContent`。
  4. 拖拽事件：在 SVG 根元素上监听 `mousemove/touchmove` 和 `mouseup/touchend`，在滑片 group 上监听 `mousedown/touchstart`。计算鼠标 x 坐标相对于 SVG 的位置，并用 `Math.max(400, Math.min(500, x))` 限制范围。
- ID 命名规范：所有元素 ID 必须以 `scene1-` 为前缀（如 `scene1-slider-group`, `scene1-text-i`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
