# Scene 2 Implementation Plan

[图示主题与整合说明]
- 本图示主题：滑动变阻器的电压-电流（U-I）关系图像分析
- 整合的步骤/概念：将电路的两个极端状态映射为 U-I 坐标系中的两个点，利用图像的斜率和截距求解电源电压和灯泡电阻。
- 教学价值：教师可以通过分步展示，引导学生从已知极值点出发，推导第二个状态点，进而通过两点连线，直观地揭示纵截距代表电源电压、斜率代表灯泡电阻的物理意义，实现数形结合的深度教学。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：在 SVG 底部（y=460 区域）居中放置两个按钮，控制步骤 0~4 的切换。
- 教师操作流程：教师首先展示空坐标系，点击下一步引出已知极值点A；讲解推导过程后点击下一步引出点B；接着点击下一步连线并延长，讲解纵截距的物理意义（电源电压）；最后点击下一步展示斜率三角形，讲解斜率的物理意义（灯泡电阻）。

[技术实现]
- JS 库选择及原因：原生 SVG。坐标系和几何图形简单，SVG 具有完美的矢量渲染效果和 DOM 操控便利性。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×450]
    (150,40) Y轴顶点
      |
      |   (150,100) U=6V
      |      \
      |       \  (390,200) A点
      |        \
      |         \ (510,250) B点
      |          \
  (150,400)-------+---------+-------- X轴 (660,400)
  
  [控件栏 800×50]
       [◀上一步] [下一步▶]
  ```
- 关键实现要点：
  1. 使用 `<g>` 标签按步骤对元素进行分组，如 `<g id="scene2-step1">`。
  2. 状态机设计：定义 `currentStep` 变量（0-4），点击按钮时更新变量，并遍历所有步骤组，`step <= currentStep` 的组设为 `opacity: 1`，否则 `opacity: 0`。添加 `transition: opacity 0.5s` 实现平滑过渡。
  3. 步骤3中隐藏刻度"6"：给刻度"6"单独设置 ID `scene2-tick-6`，在 `currentStep >= 3` 时设为 `opacity: 0`。
  4. ID 命名规范：所有元素 ID 必须以 `scene2-` 为前缀，避免与其他场景冲突。
  5. JS 代码包裹在 IIFE `(function() { ... })()` 中，避免污染全局变量。
