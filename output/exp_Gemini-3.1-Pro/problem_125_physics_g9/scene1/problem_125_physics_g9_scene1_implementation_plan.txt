[视觉元素清单]
- 主光轴：黑色实线，贯穿画布。
- 凸透镜：黑色空心椭圆，带有垂直中轴线（虚线）。
- 关键点：O, F, 2F，黑色小圆点，带文本标签。
- 蜡烛（物）：红色矩形（烛身）+ 橙色路径（烛焰），带“蜡烛”标签。
- 像：倒立的红色矩形+橙色路径，尺寸按放大率动态计算。
- 光屏：灰色填充（#eeeeee），黑色边框的平行四边形（模拟3D透视），带支架和“光屏”标签。
- 特殊光线：蓝色实线（#1565c0），包含两条：
  1. 平行于主光轴，经透镜折射后过右侧焦点F。
  2. 过光心O，方向不改变。
  光线在像点交汇后继续延伸一小段。光线上带有方向箭头。

[分步序列]
- 初始状态（步骤0）：还原题目原图。蜡烛在左侧 2F 之外（x=130，高度60）。光屏在右侧 F 与 2F 之间（x=535）。两条光线交汇于光屏上，形成倒立缩小的实像（高度30）。
- 步骤1（蜡烛变短）：点击「下一步」。蜡烛高度平滑降低至30。平行光线的高度随之降低，过光心光线的倾角变小。光屏位置不变，交汇点（像）在光屏上向上移动（y坐标从330变为315），像高度变为15。验证选项A。
- 步骤2（物距减小）：点击「下一步」。蜡烛高度恢复为60，并向右平移至 F 与 2F 之间（x=265）。光路图动态更新，像向右移动至 x=670，像高度变大为120。光屏随之向右平移至 x=670 以承接清晰的像。验证选项B、C（物近像远像变大）。

[技术实现]
- JS 库选择及原因：使用 D3.js (v7)。D3 提供了强大的数据绑定和过渡动画（transition）功能，非常适合处理光路图、蜡烛、光屏等多个元素在不同状态间的平滑插值动画。
- 画布尺寸：800 × 500 px，相对定位容器。
- 布局草图：
  ```text
  [图示区 800×500]
  --------------------------------------------------
  |                                                |
  |      蜡烛          凸透镜          光屏        |
  |       |              |             / /         |
  |       |              |            / /          |
  |-------|----.----.----|----.----.-|-/-----------| 主光轴
  |      130  220  310  400  490  580 535          |
  |           2F   F    O    F    2F               |
  |                                                |
  |                                                |
  |           [◀ 上一步] [步骤指示] [下一步 ▶]     | 控件栏 (y=460)
  --------------------------------------------------
  ```
- 关键实现要点：
  1. **状态机设计**：定义一个包含 3 个状态对象的数组，每个对象存储该状态下的关键参数（蜡烛x、蜡烛h、光屏x、像x、像h）。
  2. **坐标计算**：像的位置和大小严格按照透镜成像公式计算（f=90，O点x=400）。
  3. **动画曲线**：使用 `d3.transition().duration(1000).ease(d3.easeCubicInOut)` 实现平滑过渡。在过渡过程中，使用 `tween` 函数实时更新光线的 `d` 属性，确保光线始终连接蜡烛尖端、透镜和像尖端。
  4. **ID 命名规范**：所有 DOM 元素 ID 必须以 `scene1-` 开头（如 `scene1-svg`, `scene1-candle`）。
  5. **IIFE 隔离**：整个脚本包裹在 `(function() { ... })()` 中，避免全局变量污染。
