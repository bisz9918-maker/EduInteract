[图示主题与整合说明]
- 本图示主题：光屏表面的漫反射与镜面反射对比
- 整合的步骤/概念：对应题目选项D，通过对比光滑表面（镜面反射）与粗糙表面（漫反射）的光路差异，直观解释为何光屏需要选用较粗糙的材质，以便从不同方向都能观察到像。
- 教学价值：教师可通过切换两种表面的反射状态，清晰展示平行光在不同材质表面的反射规律，帮助学生建立“漫反射使光线射向四面八方”的物理图像。

[分步序列]
- 初始状态（状态1）：默认显示“光滑玻璃板（镜面反射）”。展示平行的蓝色入射光线打在水平直线上，反射出平行的红色光线。右上方眼睛1高亮显示“能看到光”，左上方眼睛2置灰显示“看不到光”。底部说明文字显示“镜面反射：只能在特定方向观察到”。
- 状态2：点击“粗糙光屏 (漫反射)”按钮。表面切换为锯齿状，反射光线变为向四面八方发散。三个不同位置的眼睛图标均显示“能看到”。底部说明文字切换为“漫反射：可以从不同方向观察到”。

[标签冲突检查]
- 标签"平行入射光线"：(150, 110) vs 入射光线1起点(100,150) -> 间距 > 40px，无冲突。
- 标签"光滑/粗糙表面"：(680, 355) vs 表面终点(650,350) -> 间距 30px，无冲突。
- 状态2眼睛1标签"能看到"：(75, 145) vs 入射光线1起点(100,150) -> 文本宽度约40px(占据55-95)，与光线起点(100)错开，无冲突。
- 状态2眼睛2标签"能看到"：(475, 100) vs 入射光线4/5 -> 入射光线在y=100处不存在，无冲突。
- 状态2眼睛3标签"能看到"：(720, 207) vs 画布右边缘(800) -> 距离边缘80px，足够容纳文本，无冲突。
- 状态1眼睛2标签"看不到光"：(350, 50) vs 反射光束 -> 反射光束最左侧在y=80时x约为422，距离350有70px以上间距，无冲突。

[交互方案]
- 交互类型：多状态切换（2个按钮）。
- 控件说明：在 SVG 底部 (y=460) 放置两个按钮：“状态1：光滑玻璃板 (镜面反射)” 和 “状态2：粗糙光屏 (漫反射)”。
- 教师操作流程：教师首先展示状态1，说明如果光屏是光滑的，只有在特定角度才能看到像；然后点击状态2按钮，展示粗糙表面如何将光线散射到各个方向，从而解释为何全班同学都能从不同角度看到光屏上的像。

[技术实现]
- JS 库选择及原因：原生 SVG。光路图和几何图形非常适合使用 SVG 的 `<line>` 和 `<path>` 标签实现，且易于添加 `<marker>` 箭头和控制显隐。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
    (标题)
    (眼睛图标及标签区)
    (入射光线)  (反射光线)
    (表面区 y=350)
    (说明文字区 y=410)
  [控件栏 y=460 绝对定位]
    [光滑表面按钮] [粗糙表面按钮]
  ```
- 关键实现要点：
  - 使用 `<g>` 标签将状态1和状态2的特有元素分别编组（如 `<g id="scene2-state1">` 和 `<g id="scene2-state2">`）。
  - 切换状态时，通过修改对应 `<g>` 标签的 `display` 属性（`block` / `none`）实现无缝切换。
  - 光线箭头使用 `<defs>` 中定义的 `<marker id="scene2-arrow-blue">` 和 `<marker id="scene2-arrow-red">`，通过 `marker-end` 属性附加到线段上。
  - 锯齿表面的反射光线角度需在视觉上与局部斜率保持物理逻辑的一致性（已在坐标规划中精确计算）。
- ID 命名规范：所有元素 ID 均以 `scene2-` 为前缀，如 `scene2-btn-state1`。
- IIFE 隔离：所有 JS 逻辑封装在 `(function() { ... })()` 中，避免变量污染。
