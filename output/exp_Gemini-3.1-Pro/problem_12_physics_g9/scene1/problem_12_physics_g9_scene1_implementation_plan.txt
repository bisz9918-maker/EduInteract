[图示主题与整合说明]
- 本图示主题：弹簧测力计的受力分析与作用力传递

[分步序列]
- 初始状态（步骤0）：显示测力计A和B（透明度 100%），以及左右两端的初始淡拉力箭头（灰色）。隐藏所有彩色受力箭头和读数标签。
- 步骤1（分析A）：测力计A保持 100% 透明度，测力计B淡化（透明度 30%）。隐藏初始淡拉力箭头。显示手拉A力（红色，向左）及其标签，显示B拉A力（蓝色，向右，y=250）及其标签。显示A读数标签"读数: 8N"。
- 步骤2（相互作用）：测力计A和B均恢复 100% 透明度。显示局部放大虚线圈。B拉A力上移至 y=235，显示A拉B力（蓝色，向左，y=265）及其标签。隐藏手拉A力和A读数标签（聚焦于挂钩处）。
- 步骤3（分析B）：测力计B保持 100% 透明度，测力计A淡化（透明度 30%）。隐藏局部放大圈和B拉A力。A拉B力移至中心线 y=250，显示手拉B力（红色，向右）及其标签。显示B读数标签"读数: 8N"。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：在 SVG 底部（y=460）居中放置两个按钮，用于切换步骤（0-3）。
- 教师操作流程：教师首先展示整体画面，然后点击“下一步”隔离测力计A进行受力分析，得出挂钩处的拉力；再次点击“下一步”聚焦挂钩，讲解作用力与反作用力；最后点击“下一步”隔离测力计B，得出其读数和右手拉力。

[技术实现]
- JS 库选择及原因：原生 SVG + MathJax。SVG 适合绘制精确的几何图形和箭头，易于通过 DOM 操作实现透明度、位置的动画过渡；MathJax 用于渲染带有下标的物理符号。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×450]
  (170)手拉A <--- (190)测力计A(350) ---> B拉A(490)
                   (400)挂钩交汇处
  (310)A拉B <--- (450)测力计B(610) ---> 手拉B(730)
  [控件栏 800×50，包含 上一步/下一步 按钮]
  ```
- 关键实现要点：
  - 状态机设计：定义一个 `currentStep` 变量（0-3），每次点击按钮更新变量并调用 `updateScene()` 函数。
  - 动画过渡：在 SVG 元素上使用 CSS `transition: all 0.5s ease`，实现透明度变化和箭头位置移动的平滑动画。
  - 箭头绘制：定义 `<defs><marker>` 用于箭头的头部，方便复用。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-scaleA`, `scene1-force-handA`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
