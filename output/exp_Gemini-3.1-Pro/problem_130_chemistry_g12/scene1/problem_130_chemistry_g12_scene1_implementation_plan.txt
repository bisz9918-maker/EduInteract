[分步序列]
- 初始状态（步骤0）：所有碎片在顶部碎片库，显示成键数标签。组装区和收集区为空。
- 步骤1：点击「下一步」→ >CH- 移动至组装区中心(400, 140)，显示">CH- (核心)"标签。
- 步骤2：点击「下一步」→ 两个 -CH3 和 -Cl 移动至组装区三个分支的末端（L3, R3, B3），显示虚线连接，并出现"对称分支"标签。
- 步骤3：点击「下一步」→ 两个 -CH2- 插入左侧分支（L1, L2），实线连接形成 2-氯戊烷。收集区显示结构1及名称。
- 步骤4：点击「下一步」→ 两个 -CH2- 分别插入左右分支（L1, R1），实线连接形成 3-氯戊烷。收集区显示结构2及名称。
- 步骤5：点击「下一步」→ 两个 -CH2- 分别插入左侧和下方分支（L1, B1），实线连接形成 1-氯-2-甲基丁烷。收集区显示结构3及名称。
- 步骤6：点击「下一步」→ 两个 -CH2- 均插入下方分支（B1, B2），实线连接形成 1-氯-3-甲基丁烷。收集区显示结构4及名称。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。SVG 非常适合绘制化学键和带有精确坐标的基团框，且利用 CSS `transition: transform 0.5s` 可以轻松实现基团平滑移动的动画效果。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  [CH3]  [CH3]  [CH2]  [CH2]  [CH]  [Cl]          | (碎片库 y=50)
  |                                                  |
  |             [CH3]--[CH2]--[CH]--[CH3]            | (组装区 y=140~320)
  |                             |                    |
  |                           [Cl]                   |
  | - - - - - - - - - - - - - - - - - - - - - - - - -| (分割线 y=340)
  |  结构1        结构2        结构3        结构4    | (收集区 y=390)
  +--------------------------------------------------+
  [控件栏： ◀上一步  步骤 3 / 6  下一步▶ ] (y=460~490)
  ```
- 关键实现要点：
  1. **状态机设计**：定义一个包含7个状态的数组，每个状态记录6个碎片的 `[x, y]` 坐标、需要显示的实线/虚线ID列表、以及收集区结构的透明度。
  2. **平滑动画**：SVG 中的碎片使用 `<g>` 标签，通过 JS 修改其 `style.transform = "translate(x px, y px)"`，配合 CSS `transition` 实现平滑移动。
  3. **化学键连接**：预先在 SVG 中绘制所有可能的实线和虚线（位于碎片图层下方），在状态切换时通过修改 `opacity` 来显示或隐藏对应的键，避免复杂的动态坐标计算。
  4. **收集区掩码**：收集区的微缩结构式中，水平化学键使用一条贯穿的直线，在每个文本标签后放置一个白色的 `<rect>` 作为背景掩码，使化学键在文字处断开，保证可读性。
  5. **ID 命名规范**：所有交互元素 ID 必须以 `scene1-` 为前缀。
  6. **IIFE 隔离**：所有 JS 代码封装在 `(function() { ... })()` 中。
