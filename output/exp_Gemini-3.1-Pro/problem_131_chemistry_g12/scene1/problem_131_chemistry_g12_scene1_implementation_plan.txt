[视觉元素清单]
- 基础装置：左烧杯、右烧杯、Pt/Cu/Zn/C电极、上下导线、电流表、开关（#000000）。
- 动态元素：电子(e⁻)及流向箭头（#1565c0）、气泡动画（#2e7d32）、电极溶解效果（白色遮盖）。
- 微观粒子：Na⁺, Cl⁻, H⁺, OH⁻, Zn²⁺, SO₄²⁻ 带有正负电荷符号的圆形图标及移动箭头（#2e7d32）。
- 标签：溶液标签、极性标签、反应式。
- 高亮颜色严格遵循规格：原电池相关（#c62828），电解池相关（#1565c0），离子/气泡（#2e7d32）。

[分步序列]
- 初始状态（步骤0）：显示基础装置（烧杯、电极、导线、电流表、闭合开关）及溶液标签、电极标签。
- 步骤1：点击「下一步」→ 左右两侧出现高亮背景框。右侧红框标注“原电池（自发反应）”，左侧蓝框标注“电解池（非自发）”。
- 步骤2：点击「下一步」→ 出现极性标签（右侧Zn负极、C正极；左侧Cu阴极、Pt阳极）。导线上出现动态移动的电子(e⁻)，方向为 Zn → Cu，以及 Pt → C。
- 步骤3：点击「下一步」→ 各电极旁浮现反应式。Zn电极出现变细溶解效果；C极、Cu极、Pt极表面出现绿色气泡动画向上浮动。
- 步骤4：点击「下一步」→ 溶液中出现离子图标及移动箭头。右侧 H⁺ 移向 C极，SO₄²⁻ 移向 Zn极；左侧 Na⁺ 移向 Cu极，Cl⁻ 移向 Pt极。Cu电极附近出现高密度的 OH⁻ 图标并闪烁。

- Cu标签(270,180) vs Cu阴极(260,125)：y轴距离55px，无冲突。

- 垂直导线(x=140, 240, 580, 680) vs 极性标签：极性标签分别放置在 x=110, 260, 540, 700，完美避开导线，无重叠。
- 左右高亮框(边界在x=390和x=410) vs 反应式：反应式完全包含在各自的高亮框内，中间留有20px间隙，无冲突。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：在 SVG 底部 (y=460) 居中放置两个按钮，控制 currentStep (0~4)。
- 教师操作流程：教师点击“下一步”逐步展示装置识别、极性判断、电极反应和离子移动，配合口头推导讲解。

[技术实现]
- JS 库选择及原因：原生 SVG。电化学装置主要由规则几何图形和连线组成，SVG 的 `<animateMotion>` 和 `<animate>` 非常适合实现电子流向和气泡动画。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×450]
  [控件栏 800×50 (y=450~500)]
  ```
- 关键实现要点：
  - 状态机设计：定义 `updateStep(step)` 函数，通过修改对应 SVG 元素的 `display`、`opacity` 属性来切换状态。
  - 动画实现：电子移动使用 `<animateMotion>` 绑定到导线路径上；气泡使用 `<circle>` 配合 `<animate attributeName="cy">` 和 `opacity` 实现循环上升。
  - 溶解效果：在 Zn 电极边缘叠加一个与背景色相同的锯齿状多边形，在步骤3时显示，模拟电极消耗。
  - ID 命名规范：所有元素 ID 必须以 `scene1-` 为前缀（如 `scene1-btn-next`, `scene1-pt-reaction`）。
  - IIFE 隔离：所有 JS 代码包裹在 `(function() { ... })()` 中，避免全局变量污染。
