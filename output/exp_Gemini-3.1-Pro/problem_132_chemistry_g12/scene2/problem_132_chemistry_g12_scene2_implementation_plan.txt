[图示主题与整合说明]
- 本图示主题：苯环上一溴代物同分异构体种数的判断
- 整合的步骤/概念：识别分子中的苯环区域、排除非苯环的含氮杂环、分别分析两个独立苯环的对称性及等效氢种类、最终汇总异构体总数。
- 教学价值：教师可通过分步演示，引导学生先“找对区域”（只看苯环），再“找准位置”（分析等效氢），避免学生被复杂的整体结构干扰，清晰展示“3+2=5”的逻辑推导过程。

[视觉元素清单]
- 分子骨架：使用黑色(#000000)实线绘制单键，双键使用内部偏移4px的平行线段绘制。
- 苯环高亮遮罩：使用 SVG `<polygon>`，右上苯环填充 #1565c0（透明度0.2），左下苯环填充 #2e7d32（透明度0.2）。
- 杂环置灰遮罩：使用 SVG `<polygon>`，填充 #888888（透明度0.5），并配有“含氮杂环 (非苯环)”的指示箭头。
- H原子标记：使用 SVG `<circle>` (r=12) 配合居中 `<text>`。颜色分别为：a(#c62828), b(#1565c0), c(#2e7d32), d(#f57c00), e(#6a1b9a)。
- 文本说明：使用无衬线字体，关键数字使用红色(#c62828)加粗突出。

[分步序列]
- 初始状态（步骤0）：仅显示罂粟碱的分子骨架结构（包含OCH3和N原子标签），无任何高亮或额外标记。
- 步骤1（锁定苯环）：点击「下一步」，出现左下和右上的彩色透明多边形高亮苯环；同时含氮杂环区域出现灰色半透明遮罩，并弹出“含氮杂环 (非苯环)”的文字及箭头，明确取代反应的发生区域。
- 步骤2（分析右上苯环）：点击「下一步」，在右上苯环外侧伸出3根C-H键，显示带有a, b, c字母的红、蓝、绿圆形标记；右侧淡入文本框“右上方苯环：无对称性，3种等效氢”。
- 步骤3（分析左下苯环）：点击「下一步」，在左下苯环外侧伸出2根C-H键，显示带有d, e字母的橙、紫圆形标记；左侧淡入文本框“左下方苯环：无对称性，2种等效氢”。
- 步骤4（得出结论）：点击「下一步」，底部中央淡入大字号结论文本“一溴代物同分异构体总数 = 3 + 2 = 5 种”。

[交互方案]
- 交互类型：分步按钮导航。
- 控件说明：在 SVG 容器底部 (y=470) 绝对定位一个 `div`，包含「上一步」和「下一步」两个按钮。
- 教师操作流程：教师首先展示原分子，提问取代位置；点击下一步排除杂环；再分两次点击分别引导学生观察两个苯环的对称性并数出等效氢；最后点击展示总和，完成教学闭环。

[技术实现]
- JS 库选择：原生 SVG。分子结构由多边形和线段组成，SVG 能提供最精确的坐标控制和最高清的渲染，且易于通过 CSS 控制各元素的透明度实现动画。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  (100,300)左侧说明      (400,250)分子主体      (600,180)右侧说明
  [控件栏 (400,470) 上一步 | 下一步]
  ```
- 关键实现要点：
  1. 状态机设计：定义 `let currentStep = 0`，最大值为 4。每次点击按钮更新 `currentStep` 并调用 `updateState()` 函数。
  2. 动画实现：为所有需要显隐的 SVG 元素（如高亮多边形、H原子组、文本框）添加 `style="transition: opacity 0.5s ease;"`，在 `updateState()` 中根据当前步骤设置 `opacity` 为 1 或 0。
  3. 双键绘制：不使用复杂的路径，直接在主多边形内部按规划好的偏移坐标绘制独立的 `<line>` 元素表示双键。
- ID 命名规范：所有交互元素 ID 必须以 `scene2-` 为前缀（如 `scene2-ring-left`, `scene2-btn-next`）。
- IIFE 隔离：所有 JS 代码包裹在 `(function() { ... })()` 中，避免全局变量污染。
