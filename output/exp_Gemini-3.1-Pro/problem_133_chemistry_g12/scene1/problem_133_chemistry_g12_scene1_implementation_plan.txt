[图示主题与整合说明]
- 本图示主题：活塞移动前后的气体状态与物理量变化
- 整合的步骤/概念：初始状态与最终状态的体积对比、压强变化推导、右侧气体物质的量计算
- 教学价值：教师可通过分步动画，直观展示引爆前后活塞移动的物理过程，引导学生逐步推导体积、压强和物质的量的变化关系，将抽象的气体状态方程（PV=nRT）具象化，突破思维难点。

[分步序列]
- 初始状态（步骤0）：活塞位于刻度1（x=245）。左侧空气区宽145，右侧混合气区宽445（绿色）。左侧参数显示 `V = 1, P = P₀`；右侧参数显示 `V = 3, P = P₀, n = 3`。
- 步骤1：点击「下一步」→ 活塞平滑移动至刻度2（x=395）。左侧空气区变宽（w=295），右侧气体区变窄（w=295）且颜色变为红色（剩余气体）。左侧参数更新为 `V = 2`；右侧参数更新为 `V = 2`。
- 步骤2：点击「下一步」→ 左侧空气区高亮（透明度升至40%）。左侧参数更新为 `V = 2, P = 0.5P₀`；右侧参数同步更新为 `V = 2, P = 0.5P₀`。
- 步骤3：点击「下一步」→ 右侧气体区高亮（透明度升至40%），左侧恢复正常。右侧参数更新为 `V = 2, P = 0.5P₀, n = 1`。

[标签冲突检查]
- 刻度标签：x坐标分别为 100, 250, 400, 550, 700，间距 150px，字宽约 10px，无冲突。
- 区域内部标签："空气"与"O₂, H₂混合气"，分别在活塞两侧的矩形中心，初始间距 > 200px，最终间距 > 200px，无冲突。
- 状态参数标签：位于容器上方 y=150，左右两侧标签中心点初始相距 305px，最终相距 305px，文本最大宽度约 150px，无冲突。
- 活塞与标签：活塞移动过程中，内部标签和上方参数标签跟随区域中心点同步平移，始终保持在各自区域的正中央，不会与活塞重叠。

[交互方案]
- 交互类型：分步按钮导航
- 控件说明：在 SVG 底部（y=460）居中放置两个按钮：「◀ 上一步」和「下一步 ▶」。
- 教师操作流程：教师首先展示初始状态，讲解引爆前的体积和物质的量比例；点击下一步展示引爆后活塞居中的最终状态；再次点击引导学生分析左侧空气等温膨胀的压强变化；最后点击推导右侧剩余气体的物质的量，完成解题逻辑闭环。

[技术实现]
- JS 库选择及原因：原生 SVG + CSS Transitions。图形简单规整，原生 SVG 配合 CSS `transition` 属性即可实现平滑的活塞移动和颜色渐变动画，无需引入庞大的外部库。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
    (上方参数区 y=150)
    V=1, P=P₀                V=3, P=P₀, n=3
    +---------+---------------------------+
    |         |                           |
    |  空气   |       O₂, H₂混合气        |
    |         |                           |
    +---------+---------------------------+
    0         1         2         3         4
    (下方刻度区 y=350)
    
  [控件栏 y=460]
       [◀ 上一步] [下一步 ▶]
  ```
- 关键实现要点：
  - 使用 `scene1-` 前缀命名所有 DOM 元素的 ID。
  - 维护一个 `currentStep` 变量（0~3），点击按钮时更新该变量并调用 `updateState()` 函数。
  - `updateState()` 根据当前步骤，修改活塞的 `x` 属性、左右矩形的 `x` 和 `width` 属性、矩形的 `fill` 和 `fill-opacity` 属性。
  - 文本内容通过修改 `textContent` 实现更新，文本的 `x` 坐标随矩形中心点同步计算并更新。
  - 为 SVG 元素添加 `style="transition: all 0.5s ease;"` 实现平滑动画过渡。
  - 所有代码封装在 IIFE 中，避免全局变量污染。
