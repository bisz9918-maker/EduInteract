[图示主题与整合说明]
- 本图示主题：烃C的芳香族同分异构体及其化学性质
- 整合的步骤/概念：展示立方烷（C8H8）的芳香族同分异构体（苯乙烯）的结构式，并分析其侧链碳碳双键的还原性，从而解释为什么它能使酸性高锰酸钾溶液褪色，对应选项C的解析。
- 教学价值：教师可通过多状态切换，先引导学生推导C8H8的芳香族同分异构体结构，再展示其特征官能团（碳碳双键）的化学性质，直观呈现结构决定性质的化学核心观念。

[视觉元素清单]

- 苯乙烯结构式：正六边形内含圆圈表示苯环，右上角连出折线表示乙烯基（单键+双键）。

- 颜色/样式：

  - 主线（分子结构、箭头、烧杯）：#000000，线宽 2px

  - 褪色后溶液：透明度 0

[分步序列]
- 初始状态（状态1：分子式与异构体）：
  - 显示立方烷模型及其标签（烃C，C8H8）。
  - 显示转化箭头及“同分异构体”文本。
  - 显示苯乙烯结构式及其标签（苯乙烯，C8H8）。
  - 隐藏碳碳双键标注、反应箭头、烧杯及相关标签、结论对勾与文本。
- 状态2（状态2：官能团性质）：
  - 碳碳双键线条颜色变为红色（#c62828）并加粗。
  - 出现“碳碳双键”标注及引线。
  - 出现指向烧杯的反应箭头。
  - 出现烧杯及紫色液体、“酸性KMnO4溶液”标签。
  - 触发动画：紫色液体逐渐变为透明（褪色），同时出现“褪色”文本标签。
  - 出现绿色对勾及“选项C 正确”结论文本。

[交互方案]
- 交互类型：多状态切换（2个状态按钮）
- 控件说明：底部居中放置两个按钮：“状态1：同分异构体” 和 “状态2：化学性质”。
- 教师操作流程：教师首先展示状态1，讲解立方烷的分子式并推导其芳香族同分异构体；随后点击状态2，高亮双键并展示其能使高锰酸钾褪色的性质，最后得出选项C正确的结论。

[技术实现]
- JS 库选择及原因：原生 SVG。分子结构、箭头和简单几何图形使用 SVG 绘制最为清晰且易于实现动画（如颜色渐变和透明度过渡）。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
    (立方烷)  --同分异构体-->  (苯乙烯) -> [烧杯]
      烃C                        苯乙烯
     C8H8                       C8H8
                 [对勾] 选项C 正确
  [控件栏： 按钮1 | 按钮2 ]
  ```
- 关键实现要点：
  - 立方烷的绘制需精确计算前后正方形的顶点坐标，并用 `stroke-dasharray` 实现被遮挡边的虚线效果。
  - 苯乙烯的绘制利用正六边形顶点坐标，乙烯基的折线需精确计算角度，双键使用两条平行的 `<line>`。
  - 状态切换时，通过修改 SVG 元素的 `opacity` 属性实现显隐，通过修改 `stroke` 属性实现高亮。
  - 褪色动画可通过 CSS `transition: fill-opacity 1s ease` 实现。
  - ID 命名规范：所有交互元素 ID 必须以 `scene3-` 为前缀（如 `scene3-cubane`, `scene3-styrene-double-bond`）。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
