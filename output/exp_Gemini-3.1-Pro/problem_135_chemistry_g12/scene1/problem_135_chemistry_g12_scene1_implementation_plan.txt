[图示主题与整合说明]
- 本图示主题：醋酸中加入氨水时的导电性变化动态演示（宏微观结合）
- 整合的步骤/概念：将宏观的实验现象（灯泡亮度）、微观的离子浓度变化（放大镜中的粒子种类与密度）以及抽象的数学关系（导电性-体积坐标曲线）三者完美整合在同一时间轴上。
- 教学价值：教师可通过拖动滑块，连续展示滴加氨水全过程。帮助学生直观理解“弱电解质反应生成强电解质导致导电性增强”以及“继续加水稀释导致导电性减弱”的核心考点，实现宏观、微观、符号的三重表征。

[视觉元素清单]
- 宏观装置：黑色主线（#000000）绘制电池、灯泡、广口瓶、电极和导线。灯泡光晕使用 #c62828，透明度动态变化。
- 微观视图：放大镜内随机分布粒子。CH3COOH（#888888实心），CH3COO-（#c62828实心），NH4+（#1565c0实心），NH3·H2O（#888888虚线边框，内部透明）。
- 坐标曲线：X轴和Y轴为黑色带箭头线段。曲线为 #2e7d32（绿色实线），动点为 #c62828（红色实心圆）。
- 控件区：底部居中放置一个 range 滑块，带有三个关键节点的文字提示。

[分步序列]
本场景采用连续拖拽滑块（0-100）的交互方式，以下为三个典型状态：
- 初始状态（滑块=0，纯醋酸）：
  - 宏观：灯泡微弱发光（光晕透明度 0.2）。
  - 微观：放大镜内充满 CH3COOH 分子（约12个），极少量 CH3COO-（约1个）。
  - 曲线：动点位于起点 (480, 380)。
- 中间状态（滑块=50，恰好反应）：
  - 宏观：灯泡最亮（光晕透明度 0.8）。
  - 微观：CH3COOH 分子消失，充满 CH3COO- 和 NH4+ 离子（各约12个），分布密集。
  - 曲线：动点到达最高点 (600, 270)。
- 最终状态（滑块=100，氨水过量）：
  - 宏观：灯泡变暗（光晕透明度 0.5）。
  - 微观：离子间距变大（模拟体积增大稀释），出现 NH3·H2O 分子（约5个）。
  - 曲线：动点下降至终点 (720, 320)。

[交互方案]
- 交互类型：连续拖拽滑块。
- 控件说明：底部居中一个 `<input type="range">`，ID为 `scene1-slider`，范围 0-100，初始值 0。
- 教师操作流程：教师在讲解时，缓慢向右拖动滑块，引导学生同时观察左侧灯泡亮度、右上角微观粒子变化以及右下角坐标曲线上动点的轨迹，从而建立宏观现象、微观本质与数学图像的联系。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript。无需外部库，性能最佳。
- 画布尺寸：800 × 500 px。
- 布局草图：
  [左侧：宏观装置 300x350] [右上：微观放大镜 300x200]
  [左侧：宏观装置 300x350] [右下：坐标曲线 300x200]
  [底部：滑块控件区 800x50]
- 关键实现要点：
  1. 曲线方程：设滑块值为 v (0-100)。
     当 0 <= v <= 50 时，y = 380 - 110 * (v/50)^0.8；
     当 50 < v <= 100 时，y = 270 + 50 * ((v-50)/50)^1.2。
     x 坐标始终为 x = 480 + v * 2.4。
  2. 动点更新：监听滑块 `input` 事件，实时计算 (x, y) 并更新动点 `<circle>` 的 `cx`, `cy`。
  3. 光晕更新：灯泡光晕的 `opacity` 根据 v 计算，0-50 递增 (0.2->0.8)，50-100 递减 (0.8->0.5)。
  4. 微观粒子动画：预先在放大镜内生成固定数量的四种粒子 DOM 元素。根据 v 的值，动态调整各组粒子的 `opacity`。例如，CH3COOH 的透明度随 v (0->50) 从 1 降至 0；CH3COO- 和 NH4+ 随 v (0->50) 从 0 升至 1。当 v > 50 时，为了模拟稀释，可以让所有离子的坐标相对于圆心向外偏移（距离乘以 1 + (v-50)/100），超出放大镜半径的予以隐藏（或使用 clip-path 裁剪），同时显示 NH3·H2O 粒子。
  5. ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀，如 `scene1-slider`, `scene1-dot`, `scene1-glow`。
  6. IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
