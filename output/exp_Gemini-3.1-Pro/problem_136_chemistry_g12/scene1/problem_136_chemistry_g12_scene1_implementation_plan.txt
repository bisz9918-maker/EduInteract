[分步序列]
- 初始状态（步骤0）：显示所有原子，所有化学键均为灰色单线。显示底部原有标签及指示线。
- 步骤1：点击「下一步」→ H与C1高亮（蓝色发光或描边），H-C1键变为蓝色单线。显示提示框1“氢(H)化合价为1”。
- 步骤2：点击「下一步」→ C1与C2高亮，C1-C2键变为蓝色三线。显示提示框2“碳(C)化合价为4，需再形成3个键”。隐藏提示框1。
- 步骤3：点击「下一步」→ 依次将后续化学键变为蓝色单线/三线交替（C2-C3单，C3-C4三...直到C9-③三键）。显示提示框3“单键-三键-单键-三键...交替”。隐藏提示框2。
- 步骤4：点击「下一步」→ 出现绿框①和绿框②圈出对应化学键。显示提示框4a“①为三键（排除B）”（红色字）和提示框4b“②为单键（确认C正确）”（绿色字）。隐藏提示框3。
- 步骤5：点击「下一步」→ C9与③高亮。显示提示框5a“原子③需形成三键，而Cl/F只能形成单键（排除D）”（红色字）和提示框5b“分子含杂原子，非烃类（排除A）”（红色字）。隐藏绿框及提示框4a/4b。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：底部居中放置两个按钮，控制步骤 0 到 5 的切换。
- 教师操作流程：教师首先展示题目原始模型，然后点击“下一步”逐步推导H-C键、C-C键，展示单三键交替规律，最后结合规律判断①②键的类型，并推断原子③的性质，完成所有选项的解析。

[技术实现]
- JS 库选择及原因：原生 SVG。分子结构为简单的几何图形（圆、线段），SVG 能够轻松实现精确的坐标定位、线条样式（单线/三线）以及斜纹填充（pattern）。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  (100~200) 提示框区域
  (250)     分子链区域 H-C-C-C-C-C-C-C-C-C-③
  (310)     底部标签区域
  (450~490) [◀上一步] [下一步▶]
  ```
- 关键实现要点：
  - 使用 `<pattern>` 定义原子③的斜纹填充。
  - 化学键使用 `<g>` 元素封装，单键包含1条 `<line>`，三键包含3条平行的 `<line>`（Y轴偏移 -4, 0, +4）。
  - 状态机：定义 `currentStep` 变量，`updateScene()` 函数根据当前步骤控制各元素的 `display` 或 `opacity` 属性，以及化学键的颜色和类型。
  - 步骤3的动画可以使用简单的 `setTimeout` 序列来实现交替出现的视觉效果，或者直接在状态切换时全部显示。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-bond-1`，`scene1-hint-1`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
