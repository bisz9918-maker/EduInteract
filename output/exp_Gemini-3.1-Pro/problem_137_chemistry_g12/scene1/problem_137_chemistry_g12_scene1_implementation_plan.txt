[视觉元素清单]
- 基础分子骨架：使用 `<line>` 绘制单键，双键使用两条平行的 `<line>`（间距约4px）。颜色 #000000，线宽 2px。
- 氧原子标签：在对应坐标绘制 r=12 的白色 `<circle>` 作为背景，上方绘制 `<text>` "O"，颜色 #000000。
- 碳原子编号（步骤1）：在各碳原子顶点附近绘制文本（1-21），颜色 #1565c0，字号 14px。
- 碳骨架高亮（步骤1）：在主链和支链的碳碳键下方绘制线宽 10px、透明度 0.4 的蓝色线条（#1565c0）。
- 酯基高亮（步骤2、4）：在3个酯基的键下方绘制线宽 12px、透明度 0.4 的红色线条（#c62828）。
- 双键高亮（步骤2、4）：在4个碳碳双键下方绘制线宽 12px、透明度 0.4 的绿色线条（#2e7d32）。
- 手性碳标记（步骤3）：在 C3(330, 250) 和 C4(365, 270) 旁边绘制红色星号 "*"（#c62828，粗体，字号 20px）。
- 手性基团高亮（步骤3）：以 C3 为中心，向四个方向的基团分别绘制蓝、绿、黄、红色的粗线条（线宽 12px，透明度 0.4）覆盖其键。
- 反应类型标签（步骤4）：
  - "加成反应(消耗4mol H₂)、氧化反应"：位于 (525, 170)，带指示线指向右侧双键。
  - "取代/水解反应(消耗3mol NaOH)"：位于 (325, 390)，带指示线指向底部酯基。

[分步序列]
- 初始状态（步骤0）：显示完整的有机物A键线式结构。底部文本：“观察有机物A的键线式结构，依次验证四个选项。”
- 步骤1（验证选项A-数碳）：显示碳骨架高亮（蓝色粗线），依次淡入碳原子编号 1 到 21。底部文本：“验证选项A：高亮主链和支链的碳骨架并编号，得出总碳数为21。”
- 步骤2（验证选项A-不饱和度）：隐藏碳编号和骨架高亮。淡入3个酯基高亮（红色）和4个双键高亮（绿色）。底部文本：“验证选项A：3个酯基(红)提供3个不饱和度，4个双键(绿)提供4个不饱和度。总不饱和度为7，推导分子式为 C₂₁H₃₀O₆，选项A错误。”
- 步骤3（验证选项B）：隐藏酯基和双键高亮。在 C3 和 C4 处淡入红色星号。C3 处淡入一条向下的虚线连接 H 原子。淡入 C3 周围四个基团的不同颜色高亮（蓝、绿、黄、红）。底部文本：“验证选项B：含有2个手性碳原子(标*)。以左侧手性碳为例，连接4个不同基团，选项B正确。”
- 步骤4（验证选项C和D）：隐藏手性相关元素。重新显示4个双键高亮（绿色）和3个酯基高亮（红色）。淡入反应类型标签及指示线。底部文本：“验证选项C和D：4个双键可发生加成(消耗4mol H₂)和氧化反应；3个酯基可发生取代/水解反应(消耗3mol NaOH)。选项C错误，D正确。”

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：在 SVG 内部底部 (y=470) 放置两个按钮，用于在 0-4 步之间切换。
- 教师操作流程：教师点击“下一步”逐一验证选项，配合底部动态文本解释每个选项的判断依据。可随时点击“上一步”回退。

[技术实现]
- JS 库选择：原生 SVG + 原生 JS。SVG 非常适合绘制清晰的化学键线式和实现平滑的透明度动画。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
    (150~650, 150~350) 分子结构主体
    (525, 170) 反应标签1
    (325, 390) 反应标签2
    (400, 420) 动态说明文本
    (400, 470) [◀上一步] [下一步▶]
  ```
- 关键实现要点：
  - 使用 `<g>` 标签对不同步骤的元素进行分组（如 `id="scene1-step1-elements"`），通过 JS 控制 `opacity` 实现淡入淡出。
  - 高亮线条使用 `<path>` 或 `<line>`，设置 `stroke-width="12"`, `stroke-linecap="round"`, `opacity="0.4"`，并放置在基础黑色骨架的下层（DOM 树中靠前的位置），以实现完美的荧光笔高亮效果。
  - 双键的绘制：主线连接顶点，副线在主线的一侧平移约 4-5px，长度略短。
  - ID 命名规范：所有元素 ID 均以 `scene1-` 开头，避免冲突。
  - 状态机：定义 `currentStep` 变量，`updateStep()` 函数根据当前步骤控制各组元素的 `opacity` 和底部文本内容。
  - 代码封装：所有 JS 代码放在 IIFE `(function() { ... })()` 中。
