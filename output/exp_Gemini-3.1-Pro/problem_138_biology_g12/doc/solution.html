（1）处理①的方法是。

（3）处理③所运用的生技术，其过程和生命活动用文字和箭头可简要表示为_。
（4）处理④的原理是。
（5）若将豌豆子叶的绿色基因（b）提取出来，整合到某种花菜细胞的DNA上，让该种花菜植株的花轴、花柄和花均呈绿色以提高基经济价值。将豌豆子叶的绿色基因（b）送入某种花菜的体细胞，最常用的运输工具是__。

题目分析与讲解思路：
本题综合考查了植物的果实与种子发育、遗传规律、单倍体育种及基因工程等知识。

  1. 果实与种子的发育来源：豆荚（果皮）由母本子房壁发育而来，其基因型和表型与母本完全一致；种子（胚）由受精卵发育而来，其基因型由双亲共同决定。
  2. 遗传规律的应用：F1代自交，子代基因型的概率计算。
  3. 单倍体育种：花药离体培养获得单倍体，秋水仙素处理使染色体加倍。
  4. 基因工程：质粒作为最常用的运载体。

图示规划说明：
为了清晰展示这些抽象的生物学过程，我们规划了三个图示：

  • 图示1：展示植株甲的处理①（无子果实发育）和处理②（杂交过程及后代基因型分析），帮助学生直观理解母本组织与受精卵发育的区别。
  • 图示2：展示植株乙的单倍体育种过程（处理③和④），呈现从花粉到单倍体再到二倍体的细胞学变化。
  • 图示3：展示基因工程的基本操作，即目的基因与运载体的重组与导入。

教学说明：
在讲解处理③和④时，重点在于理清“单倍体育种”的细胞学机制。

  1. 处理③是花药离体培养，利用了植物细胞的全能性。要强调花粉是减数分裂的产物，其发育成的植株是单倍体，高度不育。
  2. 处理④是秋水仙素处理，其作用机理是抑制细胞分裂前期纺锤体的形成，从而导致染色体不能移向细胞两极，引起细胞内染色体数目加倍。
  3. 引导学生观察染色体数目的变化：N -> 2N。

教学说明：
第（5）问涉及基因工程的基础知识。

  1. 基因工程的核心步骤之一是构建基因表达载体。
  2. 目的基因（豌豆子叶绿色基因b）需要与运载体结合才能稳定导入受体细胞并表达。
  3. 最常用的运载体是质粒（存在于细菌细胞质中的环状DNA分子）。
  4. 通过图示帮助学生建立“目的基因 + 质粒 = 重组质粒 -> 导入受体细胞”的直观印象。
