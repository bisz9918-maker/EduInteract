[图示主题与整合说明]
- 本图示主题：基因型与花色表型的对应关系
- 整合的步骤/概念：转录翻译过程、四种基因型组合（A_bb、aaB_、A_B_、aabb）对应的代谢途径及最终花色
- 教学价值：教师可以通过点击不同基因型按钮，直观展示基因如何通过控制酶的合成来控制代谢过程，进而控制生物体的性状（花色）。特别是双显性情况下的上位性效应（mRNA结合阻断翻译），通过动态高亮和阻断动画，帮助学生深刻理解基因间的相互作用。

[分步序列]
- 初始状态（默认）：显示完整的生化途径图，所有元素为黑色实线，无叉号，无高亮。表型结果指示显示"请选择基因型"。
- 状态1 (A_bb 紫花)：
  - 基因A、mRNA(右)、酶A、白色前体、紫色色素及右侧相关箭头高亮为紫色 #800080。
  - 基因B到mRNA(左)的箭头变为灰色虚线，显示阻断叉号1。
  - 左侧其余路径及中间结合路径变为灰色虚线。
  - 表型结果指示："当前表型：紫花"（紫色）。
- 状态2 (aaB_ 蓝花)：
  - 基因B、mRNA(左)、酶B、白色前体、蓝色色素及左侧相关箭头高亮为蓝色 #1565c0。
  - 基因A到mRNA(右)的箭头变为灰色虚线，显示阻断叉号2。
  - 右侧其余路径及中间结合路径变为灰色虚线。
  - 表型结果指示："当前表型：蓝花"（蓝色）。
- 状态3 (A_B_ 白花)：
  - 基因A、基因B、mRNA(左/右)及转录箭头保持黑色实线。
  - 显示 mRNA结合高亮框（红色虚线框），强调两种mRNA结合。
  - 酶A、酶B翻译箭头变为灰色虚线，显示阻断叉号3和叉号4。
  - 下游酶及色素路径全部变为灰色虚线。
  - 表型结果指示："当前表型：白花"（灰色）。
- 状态4 (aabb 白花)：
  - 基因A、基因B转录箭头变为灰色虚线，显示阻断叉号1和叉号2。
  - 所有下游路径（mRNA、酶、色素及中间结合）全部变为灰色虚线。
  - 表型结果指示："当前表型：白花"（灰色）。

[交互方案]
- 交互类型：多状态切换（4个按钮）。
- 控件说明：
  - 按钮1："A_bb 紫花"
  - 按钮2："aaB_ 蓝花"
  - 按钮3："A_B_ 白花"
  - 按钮4："aabb 白花"
  - 按钮放置在 SVG 内部底部的控件区（y=460），水平居中排列，间距 20px。
- 教师操作流程：教师在讲解不同基因型时，点击对应按钮。图示会动态更新路径颜色、添加阻断叉号，直观展示该基因型下哪些生化反应能进行，哪些被阻断，从而推导出最终的花色表型。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。生化途径图由清晰的节点和连线组成，SVG 非常适合绘制此类关系图，且易于通过 CSS 类控制颜色和虚线样式的切换。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
    (400,40) 表型结果指示
    (250,80)基因B       (550,80)基因A
       ↓①                 ↓①
    (250,160)mRNA  ↘  ↙ (550,160)mRNA
       ↓②        中间文字       ↓②
    (250,260)酶B        (550,260)酶A
       ↓                 ↓
  蓝色素 ← 白色前体物质 → 紫色素
  
  [控件栏 y=460]
  [A_bb 紫花] [aaB_ 蓝花] [A_B_ 白花] [aabb 白花]
  ```
- 关键实现要点：
  - 使用 `<g>` 标签对左侧路径、右侧路径、中间路径进行分组，方便统一管理。
  - 定义 CSS 类如 `.path-active-purple { stroke: #800080; fill: #800080; }`, `.path-inactive { stroke: #888888; stroke-dasharray: 5,5; }`, `.hidden { display: none; }`。
  - JS 状态机：编写一个 `updateState(state)` 函数，根据传入的基因型状态，重置所有元素的类名，然后为特定路径添加高亮或置灰类名，并控制对应叉号的显示/隐藏。
  - 箭头使用 `<marker>` 定义，确保箭头颜色能随路径颜色变化（使用 `fill="context-stroke"` 或针对不同颜色定义多个 marker）。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀，如 `scene1-btn-Abb`, `scene1-path-geneB-mRNA`。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
