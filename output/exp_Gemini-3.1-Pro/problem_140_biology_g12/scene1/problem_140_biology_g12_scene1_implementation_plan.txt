- 本图示主题：果蝇M的染色体组成及基因定位

[视觉元素清单]
- 染色体基础样式：底层黑色路径（stroke-width="22"）叠加表层灰色路径（stroke="#dbdbdb", stroke-width="20"），形成带1px黑色描边的染色体效果。
- 基因位点：白色线段（stroke="#ffffff", stroke-width="2"），精确垂直于染色体路径。
- 标签文本：黑色（#000000），字号16px。
- 步骤1高亮色：红色（#c62828），用于1、2号染色体及相关标签。
- 步骤2高亮色：黄色（#fbc02d）圆圈，用于标记E基因。
- 步骤3高亮色：蓝色（#1565c0），用于3-6号染色体及相关标签。

[分步序列]
- 初始状态（步骤0）：显示所有染色体（灰色 #dbdbdb），显示所有编号（1-8）和基因标签（B, b, V, v, R, r, E）。
- 步骤1：点击「下一步」→ 1号、2号染色体表层颜色变为红色（#c62828）。左下出现"X染色体"（280, 400）带虚线指向1号，右下出现"Y染色体"（520, 400）带虚线指向2号。底部出现"同源染色体"（400, 450）及连接两者的弧线。
- 步骤2：点击「下一步」→ 保持步骤1的染色体高亮与标签。E基因位点出现黄色圆圈高亮（cx=372.5, cy=310, r=15），左侧出现"伴性遗传基因"（260, 315）及指向E的红色箭头。
- 步骤3：点击「下一步」→ 1、2号恢复灰色，隐藏步骤1、2的所有附加标签。3、4、5、6号染色体表层颜色变为蓝色（#1565c0）。顶部出现"常染色体"（400, 70）及指向两侧蓝色染色体的蓝色箭头。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：在 SVG 容器内底部（y=460）居中放置两个按钮。
- 教师操作流程：教师首先展示果蝇完整核型图，讲解基本组成；点击下一步，高亮性染色体，讲解X和Y的异型同源特征；再次点击，聚焦X染色体上的E基因，引入伴性遗传概念；最后点击，高亮常染色体，对比常染色体基因的分布。

[技术实现]
- JS 库选择：原生 SVG。SVG 的 `<path>` 配合 `stroke-width` 和 `stroke-linecap="round"` 是绘制染色体形态的最佳方案。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
    (顶部) 常染色体标签及箭头 (步骤3)
    (左上) 3,4号染色体及基因
    (右上) 5,6号染色体及基因
    (中心) 7,8号点状染色体
    (左下) 1号(X)染色体及E基因
    (右下) 2号(Y)染色体
    (底部) X/Y及同源染色体标签 (步骤1)
  [控件栏 绝对定位在底部 y=460]
    [◀ 上一步] [下一步 ▶]
  ```
- 关键实现要点：
  1. **描边技巧**：每个染色体由两个重叠的 `<path>` 组成。底层黑色（宽22px），表层灰色/高亮色（宽20px），利用宽度差自然形成 1px 的黑色描边，无需复杂的轮廓计算。
  2. **状态机设计**：使用 `let state = 0` 记录当前步骤（0~3）。`update()` 函数中先重置所有染色体颜色为 `#dbdbdb` 并隐藏所有附加标签（`opacity="0"`），然后根据当前 state 重新赋予特定染色体高亮色并显示对应标签。
  3. **ID 命名规范**：所有元素 ID 必须以 `scene1-` 开头（如 `scene1-chr3-fg`, `scene1-btn-next`），确保多场景整合时不冲突。
  4. **IIFE 隔离**：所有 JS 逻辑封装在 `(function() { ... })()` 中。
