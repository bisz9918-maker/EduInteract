[图示主题与整合说明]
- 本图示主题：6种幼苗基因型分析与理想种子筛选
- 整合的步骤/概念：识别6种细胞的核基因与质基因状态，明确长期种植的稳定遗传要求（核基因为纯合子SS且无质基因干扰）。
- 教学价值：教师可通过切换不同状态，引导学生分别观察核基因和质基因的分布，最终推导出符合长期种植要求的理想种子类型。

[视觉元素清单]
- 细胞外框：6个黑色空心圆，线宽1.5px。
- 染色体：黑色竖线，线宽2px。
- 线粒体：黑色空心圆，线宽1.5px。
- S基因：黑色实心圆，半径3px。
- 细胞代号标签：a, b, c, d, e, f，字号18px，加粗，位于细胞正下方。
- 动态标签：字号14px，颜色随状态变化（红/蓝/绿）。
- 图例：包含4种图例项，字号14px，黑色。
- 状态说明文本：字号16px，黑色，居中对齐。
- 颜色/样式：
  - 默认：#000000
  - 核基因S高亮：#c62828 (红)
  - 质基因S高亮：#1565c0 (蓝)
  - 理想种子d高亮：边框 #2e7d32 (绿) 粗框(线宽4)，背景 #2e7d32 透明度20%

[分步序列]
- 初始状态（状态1）：核基因抗性。
  - 视觉变化：细胞 a, b, d, e 的核S基因（染色体上的点）高亮为红色（#c62828），并放大至R=4。
  - 动态标签：a, d 下方显示红色文本"核纯合(SS)"；b, e 下方显示红色文本"核杂合(S-)"。
  - 状态说明："状态1：核基因抗性。细胞 a, b, d, e 含有核基因S，表现为抗性且遗传稳定。"
- 状态2：质基因抗性。
  - 视觉变化：所有核S基因恢复黑色R=3。细胞 a, b, c 的质S基因（线粒体上的点）高亮为蓝色（#1565c0），并放大至R=4。
  - 动态标签：a, b, c 下方显示蓝色文本"质抗性(减弱)"。
  - 状态说明："状态2：质基因抗性。细胞 a, b, c 含有质基因S，表现为抗性但会逐代减弱。"
- 状态3：理想种子。
  - 视觉变化：所有基因点恢复黑色R=3。细胞 d 的外框变为绿色（#2e7d32）线宽4，内部填充绿色（透明度0.2）。
  - 动态标签：d 下方显示绿色加粗文本"理想种子"。
  - 状态说明："状态3：理想种子。细胞 d 核基因为纯合子且无质基因干扰，符合长期种植要求。"

[交互方案]
- 交互类型：多状态切换（3个按钮）。
- 控件说明：
  - 按钮1「核基因抗性」：位于 (200, 460)，点击切换至状态1。
  - 按钮2「质基因抗性」：位于 (400, 460)，点击切换至状态2。
  - 按钮3「理想种子」：位于 (600, 460)，点击切换至状态3。
- 教师操作流程：教师首先点击「核基因抗性」讲解核基因的稳定遗传，接着点击「质基因抗性」讲解质基因的缺陷，最后点击「理想种子」总结出符合条件的细胞d。

[技术实现]
- JS 库选择及原因：原生 SVG。图形均为简单几何图形（圆、线段），SVG 易于实现且支持 DOM 操作和 CSS 过渡动画。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  (100,160)  (220,160)  (340,160)  (460,160)  (580,160)  (700,160)
     (a)        (b)        (c)        (d)        (e)        (f)
  [动态标签区 y=245]
  [图例区 y=320~360]
  [状态说明区 y=410]
  [控件栏 y=460, 3个按钮]
  ```
- 关键实现要点：
  - 使用 `<g>` 标签对每个细胞进行分组，方便统一定位。
  - 状态切换时，通过修改 SVG 元素的 `fill`, `r`, `stroke`, `stroke-width` 属性实现高亮动画，可配合 CSS `transition` 实现平滑过渡。
  - 动态标签和状态说明文本通过修改 `textContent` 和 `fill` 颜色进行更新。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-cell-a`, `scene1-btn-state1`）。
- IIFE 隔离：所有 JS 代码包裹在 `(function() { ... })()` 中。
