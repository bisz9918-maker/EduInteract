[图示主题与整合说明]
- 本图示主题：基因控制毛色的代谢途径及基因型推导
- 整合的步骤/概念：将题目图1的代谢途径与A、B、C三对基因的相互作用结合，逐步推导各表型对应的基因型，并解答第(1)(2)问。
- 教学价值：教师可通过分步演示，引导学生从基础代谢途径出发，逐步加入基因的促进/抑制作用，理清多基因互作的逻辑，最终完成复杂基因型的推导，降低认知负荷。

[视觉元素清单]
- 物质节点框：3个矩形（黑边白底），内部文字为“白色物质”、“棕色物质”、“黑色物质”。
- 基础转化箭头：2条黑色实线箭头，上方带有“酶”字标签。
- 基因B及作用：绿色（#2e7d32）文本“B”及垂直向下的绿色实线箭头。
- 基因C及作用：蓝色（#1565c0）文本“C”及垂直向下的蓝色实线箭头。
- 基因A及作用：红色（#c62828）文本“A”及水平向右的红色虚线箭头（带“抑制”标签）。
- 右侧推导文本：黑色基础字体，其中关键基因位点使用对应颜色高亮（B相关用绿色，C相关用蓝色，A相关用红色）。

[分步序列]
- 初始状态（步骤0）：显示左侧基础代谢途径（白色、棕色、黑色物质框，转化箭头1、2，酶1、2）。右侧仅显示标题“基因型与表型推导”。
- 步骤1：点击「下一步」→ 左侧出现基因B、C及其促进箭头；右侧出现“无A基因 (aa) 时：”及对应的3种基因型推导（黑色、棕色、白色）。
- 步骤2：点击「下一步」→ 左侧出现基因A、抑制箭头及“抑制”标签；右侧出现“有A基因 (A_) 时：”及对应的基因型推导（白色）。
- 步骤3：点击「下一步」→ 右侧出现第(1)问和第(2)问的解答文本，展示纯合棕色猪基因型及正常黑色猪单杂合交配的比例。

[标签冲突检查]
- “酶1” (160,260) 与 “B促进箭头” (160,185-245)：箭头终点在 y=245，酶标签在 y=260，转化箭头在 y=270。无重叠，间距合理。
- “酶2” (300,260) 与 “C促进箭头” (300,185-245)：同上，无重叠。
- “抑制” (110,160) 与 “A抑制箭头” (y=170)：文本在箭头上方10px，无重叠。
- “基因A” (60,175) 与 “A抑制箭头”起点 (75,170)：文本右侧边缘约在 x=68，箭头起点在 x=75，无重叠。
- 右侧推导文本各行：Y坐标分别为 100, 130, 160, 190, 240, 270, 320, 360, 390, 420。行间距最小为 30px，字体大小 16px，绝对无重叠。最底部文本在 y=420，不侵占 y=450 开始的控件区。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：底部居中放置两个按钮及步骤指示器（如 1 / 4）。
- 教师操作流程：教师首先展示基础代谢途径，然后点击“下一步”引入B、C基因并推导无A时的毛色；接着点击“下一步”引入A基因的抑制作用并推导有A时的毛色；最后点击“下一步”展示具体题目的解答。可随时点击“上一步”回退。

[技术实现]
- JS 库选择及原因：原生 SVG。图形均为简单的矩形、线条和文本，原生 SVG 性能好且易于实现精确的坐标控制和颜色高亮（使用 `<tspan>`）。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  +-----------------------------------------+--------------------------------+
  |                                         |  基因型与表型推导              |
  |      抑制                               |                                |
  |   A -----> B             C              |  无A基因 (aa) 时：             |
  |            |             |              |    aa B_ C_  → 黑色            |
  |            v             v              |    aa B_ cc  → 棕色            |
  |  +----+   酶   +----+   酶   +----+     |    aa bb __  → 白色            |
  |  |白色| -----> |棕色| -----> |黑色|     |                                |
  |  +----+        +----+        +----+     |  有A基因 (A_) 时：             |
  |                                         |    A_ __ __  → 白色 (A抑制B)   |
  |                                         |                                |
  |                                         |  (1) 纯合棕色猪: aaBBcc        |
  |                                         |  (2) 正常黑色猪单杂合交配:     |
  |                                         |      aaBBCc × aaBBCc → 3:1     |
  |                                         |      aaBbCC × aaBbCC → 3:1     |
  +-----------------------------------------+--------------------------------+
  [控件栏 y=450~490: ◀上一步  1 / 4  下一步▶]
  ```
- 关键实现要点：
  - 使用 `<marker>` 定义不同颜色的箭头头部（黑色、绿色、蓝色、红色）。
  - 为不同步骤的元素添加 `class="scene1-step-1"`, `class="scene1-step-2"` 等。
  - JS 维护 `currentStep` 变量（0-3），更新时遍历所有带有步骤 class 的元素，根据其步骤编号与 `currentStep` 的大小关系，设置 `opacity`（配合 CSS `transition: opacity 0.3s` 实现平滑过渡）。
  - 右侧文本中的彩色基因型使用 `<tspan fill="...">` 实现。
- ID 命名规范：所有交互元素和关键图形 ID 必须以 `scene1-` 为前缀（如 `scene1-btn-prev`, `scene1-step-text`）。
- IIFE 隔离：所有 JS 逻辑封装在 `(function() { ... })()` 中，避免全局变量污染。
