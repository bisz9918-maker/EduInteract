[图示主题与整合说明]
- 本图示主题：突变体染色体组成及减数分裂配子推导
- 整合的步骤/概念：甲、乙、丙三种突变体的染色体行为，减数分裂产生配子的种类及比例，以及与纯合棕色猪(aaBBcc)测交后代的表型比例推导。
- 教学价值：教师可通过切换三种突变体，直观对比不同染色体变异类型（易位/缺失、三体、重复）在减数分裂时的分离情况，清晰展示配子比例的推导过程及测交后代表型比例的计算，帮助学生攻克遗传学难点。

[视觉元素清单]
- 染色体：#888888，线宽3px。
- 基因位点：C基因点 #1565c0，c基因点 #c62828，半径4px。
- 表现型文字高亮：黑色(Cc)用 #000000，黑青色(Ccc)用 #1565c0，棕色(cc/ccc)用 #f57c00。
- 突变体甲染色体：
  - 左侧同源染色体：(160,120)-(160,220) 带C点(160,160)；(180,120)-(180,220) 带c点(180,160)
  - 右侧染色体：(240,120)-(240,220) 带c点(240,160)；(260,170)-(260,220) 无点(短染色体)
- 突变体乙染色体：
  - 左侧三体：(150,120)-(150,220) 带C点(150,160)；(170,120)-(170,220) 带c点(170,160)；(190,120)-(190,220) 带c点(190,160)
  - 右侧同源染色体：(250,120)-(250,220)；(270,120)-(270,220) 无点
- 突变体丙染色体：
  - 左侧同源染色体：(160,120)-(160,220) 带C点(160,160)；(180,120)-(180,220) 带c点(180,145)和c点(180,175)
  - 右侧同源染色体：(240,120)-(240,220)；(260,120)-(260,220) 无点

[分步序列]
- 状态1（突变体甲）：
  - 细胞内显示甲的染色体。
  - 配子区显示4个圆圈：C, c, Cc, cc。比例文本：1 : 1 : 1 : 1。
  - 表格显示4行推导数据，结论显示“黑色 : 黑青色 : 棕色 = 1 : 1 : 2”。
- 状态2（突变体乙）：
  - 细胞内显示乙的染色体。
  - 配子区显示4个圆圈：C, Cc, c, cc。比例文本：1 : 2 : 2 : 1。
  - 表格显示4行推导数据，结论显示“黑色 : 黑青色 : 棕色 = 1 : 2 : 3”。
- 状态3（突变体丙）：
  - 细胞内显示丙的染色体。
  - 配子区显示2个圆圈：C (x=160), cc (x=240)。比例文本：1 : 1 (冒号在x=200)。隐藏配子3、4及多余比例文本。
  - 表格显示前2行推导数据，隐藏第3、4行文本。结论显示“黑色 : 棕色 = 1 : 1”。

[标签冲突检查]
- 甲染色体标签：C(145,165)与c(195,165)间距50px，c(225,165)与前一个c间距30px。无冲突。
- 乙染色体标签：C(135,165)、c(170,145)、c(205,165)。中间的c标签置于基因点上方(y=145)，左右标签在两侧(y=165)，完美错开。无冲突。
- 丙染色体标签：C(145,165)、c(195,150)、c(195,180)。右侧两个c标签上下错开30px。无冲突。
- 表格文本：各列中心x坐标相差90~100px，文本最大宽度约75px。无冲突。
- 配子圆圈及比例：圆圈间距60px，半径20px，边缘间距20px。无冲突。

[交互方案]
- 交互类型：多状态切换（3个按钮）
- 控件说明：底部居中放置三个按钮“突变体甲”、“突变体乙”、“突变体丙”。
- 教师操作流程：初始显示突变体甲，教师讲解甲的染色体组成及配子产生；点击“突变体乙”按钮，画面平滑切换至乙的数据，对比三体分离情况；点击“突变体丙”按钮，展示重复变异的分离情况。

[技术实现]
- JS 库选择及原因：原生 SVG，适合绘制静态及简单的状态切换几何图形（染色体、细胞、表格），DOM 操作简便。
- 画布尺寸：800 × 500 px
- 布局草图：
  [左侧：细胞及染色体 300x200]  [右侧：推导表格 360x250]
  [左下：配子及比例 300x100]    [右下：结论文本]
  [底部：三个切换按钮 800x40]
- 关键实现要点：
  - 使用 SVG `<g>` 标签对甲、乙、丙的染色体、配子、表格内容进行分组。
  - 状态切换时，通过修改对应 `<g>` 元素的 `display` 属性（'none' 或 'block'）实现内容的显示与隐藏。
  - 按钮点击事件中更新按钮的激活样式（如背景色变化），并触发对应状态组的显示。
  - ID 命名规范：所有元素 ID 均以 `scene2-` 为前缀，如 `scene2-btn-jia`, `scene2-group-yi`。
  - 所有 JS 代码封装在 IIFE 中，避免全局变量污染。
