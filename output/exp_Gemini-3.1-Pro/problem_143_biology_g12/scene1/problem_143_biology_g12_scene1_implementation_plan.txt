[图示主题与整合说明]
- 本图示主题：草原生态系统食物网在人类干预前后的能量流动与分配计算
- 整合的步骤/概念：食物网拓扑结构、干预前的能量逐级计算、干预后的能量逐级计算、狮子总能量对比
- 教学价值：教师可通过分步导航，按营养级逐级向学生展示能量的流动与分配比例，直观对比人类干预（鼠类爆发）前后各营养级及最终顶级捕食者（狮子）所获能量的显著变化，从而引出生态系统平衡与面积需求的关系。

[视觉元素清单]
- 节点：圆角矩形，包含生物名称。草背景淡绿，其他淡灰。边框黑色。
- 连线：黑色实线，末端带箭头。
- 能量数值框：附着在节点偏移位置的小文本框，显示如 "300" 或 "10"。
  - 草：绿色 `#2e7d32`
  - 干预前（步骤1、2）：蓝色 `#1565c0`
  - 干预后（步骤3、4）：红色 `#c62828`
- 动态流动粒子：在对应步骤中，沿连线移动的小圆点（干预前蓝色，干预后红色），表示能量流动。
- 底部计算面板：大号字体展示狮子获得能量的加和公式及最终结论。

[分步序列]
- 初始状态（步骤0）：展示完整的食物网结构。高亮“草”节点（绿色边框加粗），显示初始能量数值框“300”。隐藏其他能量数值和底部面板。
- 步骤1（干预前-初级消费者）：
  - 视觉变化：高亮草到羚羊、斑马、鼠的连线（变蓝）。
  - 新增元素：在羚羊、斑马、鼠的标签位置显示蓝色数值框“10”。
  - 动画：蓝色粒子从草流向这三个节点。
- 步骤2（干预前-中高级消费者）：
  - 视觉变化：高亮后续所有连线（变蓝）。
  - 新增元素：显示野狗“1”、蛇“1”、食蛇动物“0.1”、狮子“1.11”的蓝色数值框。
  - 底部面板：显示蓝色公式 `狮子获得能量 = 0.5(羚羊) + 0.5(斑马) + 0.1(野狗) + 0.01(食蛇动物) = 1.11 万千焦`。
- 步骤3（干预后-初级消费者）：
  - 视觉变化：重置中高级消费者能量和连线高亮。高亮“鼠”节点（红色边框加粗，表示大量繁殖）。草到初级消费者的连线变红。
  - 数值更新：羚羊“5”、斑马“5”、鼠“20”（红色数值框）。
  - 动画：红色粒子从草流向这三个节点（流向鼠的粒子更密集）。
- 步骤4（干预后-中高级消费者）：
  - 视觉变化：高亮后续所有连线（变红）。
  - 数值更新：显示野狗“0.5”、蛇“2”、食蛇动物“0.2”、狮子“0.57”的红色数值框。
  - 底部面板：显示红色公式 `狮子获得能量 = 0.25(羚羊) + 0.25(斑马) + 0.05(野狗) + 0.02(食蛇动物) = 0.57 万千焦`，并在下方追加结论 `面积需求 = 1.11 / 0.57 = 37/19 倍`。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：在 SVG 底部 (y=450~490) 放置两个按钮，控制步骤 0 到 4 的切换。
- 教师操作流程：教师点击“下一步”逐步推进能量流动的计算过程，先讲解干预前的平均分配，再讲解干预后鼠类占比增加导致的能量重新分配，最后对比狮子获得的总能量，得出面积需求增加的结论。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。食物网是由节点和连线组成的标准图结构，SVG 的 `<rect>`, `<path>`, `<text>` 非常适合精确控制坐标和样式，且易于实现连线动画（`stroke-dasharray` 或沿路径运动）。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×380]
    (草) ---> (羚羊) ---> (野狗) ---> (狮子)
         |--> (斑马) -/            /
         |--> (鼠) ---> (蛇) ---> (食蛇动物)
  [计算面板区 800×60] (y=380~440)
  [控件栏 800×60] (y=440~500, 包含上一步/下一步按钮)
  ```
- 关键实现要点：
  - 状态机设计：定义 `currentStep` (0-4)，每次步骤切换时调用 `renderStep(step)` 函数，统一更新所有节点、连线、数值框的可见性和样式。
  - 坐标计算：严格按照布局坐标表绘制 SVG 元素。贝塞尔曲线使用 `<path d="M x1 y1 Q cx cy x2 y2">`。
  - 动画：能量流动粒子可以使用 `<circle>` 配合 `<animateMotion>` 沿 `<path>` 运动，或者使用 CSS `stroke-dasharray` 和 `stroke-dashoffset` 实现连线生长动画。
  - ID 命名规范：所有元素 ID 以 `scene1-` 开头，如 `scene1-node-grass`, `scene1-edge-grass-antelope`, `scene1-btn-next`。
  - IIFE 隔离：所有逻辑封装在 `(function() { ... })()` 中，避免全局变量污染。
