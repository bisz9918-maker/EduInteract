[图示主题与整合说明]
- 本图示主题：常染色体遗传假设的证伪
- 整合的步骤/概念：纯种亲本杂交在常染色体假设下的F1、F2代基因型及表型推导，理论与实际比例的冲突。
- 教学价值：教师可通过分步推导，引导学生利用反证法，直观地看到常染色体假设下推导出的理论比例（3:1）与题目实际给出的比例（1:1:1:1）存在不可调和的矛盾，从而严谨地得出基因不可能仅位于常染色体上的结论。

- 步骤1：点击「下一步」→ 显示右侧标题“假设：控制眼型的基因位于常染色体”，显示右侧P代基因型（AA、aa、乘号及果蝇图标）。
- 步骤2：点击「下一步」→ 显示右侧P到F1的箭头，显示右侧F1代基因型“Aa (表型一致)”。
- 步骤3：点击「下一步」→ 显示右侧F1到F2的箭头及“雌雄交配”标注，显示右侧F2代基因型“1AA : 2Aa : 1aa”及理论比例“理论表型比例 3 : 1”。
- 步骤4：点击「下一步」→ 显示底部对比区域：左侧出现“实际比例 1:1:1:1”，右侧出现“理论比例 3:1”，中间出现大红叉“❌”，下方出现结论“结论：假设不成立，不可能位于常染色体”。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：在 SVG 容器内底部 (y=460~490) 居中放置两个按钮，控制当前步骤 (step 0 到 4)。
- 教师操作流程：教师首先结合左侧图解强调已知条件，随后点击“下一步”逐步展开右侧的常染色体假设推导，最后一步展示理论与实际的矛盾，完成反证法的教学闭环。

[技术实现]
- JS 库选择：原生 SVG。图形简单且结构规整，原生 SVG 配合 CSS opacity 过渡即可实现完美的动画效果。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  -----------------------------------------
  | 已知条件：纯种亲本 | 假设：基因在常染色体上 |
  | P  ♀棒眼 × ♂圆眼   | P    AA   ×   aa     |
  |        ↓           |       \   /          |
  | F1  ___眼(♀ ♂)     | F1      Aa           |
  |        ↓           |         ↓            |
  | F2 ♀圆 ♀棒 ♂圆 ♂棒 | F2 1AA : 2Aa : 1aa   |
  |    [1 : 1 : 1 : 1] |    理论表型比例 3:1  |
  |-----------------------------------------|
  |   实际比例 1:1:1:1  ❌   理论比例 3:1     |
  |          结论：不可能位于常染色体         |
  -----------------------------------------
  [控件栏： ◀上一步   下一步▶ ]
  ```
- 关键实现要点：
  - 使用 `<g>` 标签将不同步骤的元素分组（如 `id="scene1-step1-group"`）。
  - 通过 JS 监听按钮点击事件，修改 `currentStep` 变量，并动态调整各组的 `opacity` 属性（结合 CSS `transition: opacity 0.5s` 实现淡入淡出）。
  - 果蝇图标使用 `<defs>` 定义 `<g id="scene1-icon-bar">` 和 `<g id="scene1-icon-round">`，通过 `<use>` 标签复用，保持代码整洁。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-btn-next`）。
- IIFE 隔离：所有 JS 代码必须包裹在 `(function() { ... })()` 中，避免全局变量污染。
