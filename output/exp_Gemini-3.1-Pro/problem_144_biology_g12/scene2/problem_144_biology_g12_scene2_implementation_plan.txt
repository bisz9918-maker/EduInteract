- 本图示主题：X染色体遗传推导与显隐性判断

[视觉元素清单]
- 文本元素：所有文本使用原生 SVG `<text>` 标签。基因型中的上标（如 X^B）使用 `<tspan dy="-8" font-size="0.7em">B</tspan><tspan dy="8"> </tspan>` 实现。
- 线段与箭头：使用 SVG `<line>` 和 `<marker>` 实现向下箭头。
- 颜色/样式：
  - 背景：#ffffff
  - 主文本与线条：#000000
  - X染色体基因型（X^B, X^b）：#1565c0（蓝色高亮）
  - 正确结论（✅及文字）：#2e7d32（绿色高亮）
  - 错误结论（❌及文字）：#c62828（红色高亮）
  - 分隔线：#888888 虚线（stroke-dasharray="5,5"）

[标签冲突检查]
- 左侧 P标签 (60, 140) 与 左侧 P内容 (230, 140)：P内容最大宽度约 250px（左边缘在 105），与 P标签（右边缘约 70）间距 > 30px，无冲突。
- 右侧 P标签 (440, 140) 与 右侧 P内容 (620, 140)：P内容最大宽度约 250px（左边缘在 495），与 P标签（右边缘约 450）间距 > 40px，无冲突。
- 右侧 F2表型 (620, 320) 与 分隔线 (400, 70-420)：F2表型文本最长，约 360px（左边缘在 440），与分隔线 (400) 间距 40px，无冲突。
- 结论：所有元素均在各自的半区内居中或左对齐，Y轴间距充足（最小 40px），无任何重叠风险。

[交互方案]
- 交互类型：分步按钮导航
- 控件说明：在 SVG 底部（y=450~490）放置一个绝对定位的 `div` 控件栏，包含「◀ 上一步」、「下一步 ▶」按钮和「步骤 x / 5」的文本指示器。
- 教师操作流程：教师首先介绍两种假设，然后点击下一步展示假设一的亲本，再点击下一步直接展示假设一的推导结果并指出矛盾；接着点击下一步展示假设二的亲本，逐步推导F1和F2，最终验证假设二成立。

[技术实现]
- JS 库选择及原因：原生 SVG 和 Vanilla JS。布局规整，文本排版为主，原生 SVG 的 `<text>` 和 `<tspan>` 足以完美实现上标和精确定位，无需引入庞大的外部库。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  --------------------------------------------------
  |           假设基因位于X染色体，推导显隐性            |
  |        假设一：棒眼显性   |    假设二：圆眼显性        |
  |  P   ♀棒眼... × ♂圆眼...  |  P   ♀棒眼... × ♂圆眼...   |
  |             ↓           |             ↓            |
  |  F1       ...           |  F1       ...            |
  |             ↓           |             ↓            |
  |  F2       ...           |  F2       ...            |
  |      ❌ 与实际比例不符    |      ✅ 与实际比例相符     |
  --------------------------------------------------
  [控件栏： ◀ 上一步 | 步骤 0 / 5 | 下一步 ▶ ]
  ```
- 关键实现要点：
  - 使用 CSS 类控制元素的显示与隐藏（如 `.scene2-hidden { opacity: 0; pointer-events: none; }`，结合 `transition: opacity 0.3s` 实现平滑过渡）。
  - 状态机设计：定义一个 `currentStep` 变量（0-5），每次点击按钮更新变量，并遍历所有受控元素，根据其绑定的 `data-step` 属性决定是否移除隐藏类。
  - ID 命名规范：所有交互元素 ID 必须以 `scene2-` 为前缀（如 `scene2-left-p`, `scene2-btn-next`）。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
