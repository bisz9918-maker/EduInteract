[分步序列]
- 初始状态（步骤0）：显示左侧 P 世代元素（标签、雌雄图标、基因型、杂交符号）。
- 步骤1：点击「下一步」→ 显示 P至F1 箭头，以及 F1 世代元素（标签、雌雄图标、基因型、杂交符号）。
- 步骤2：点击「下一步」→ 显示 F1至F2 箭头，以及 F2 拆分元素（标签、常染色体推导、性染色体推导）。
- 步骤3：点击「下一步」→ 显示 F2 组合元素（标签、灰红计算、黑白计算、比例结果）。
- 步骤4：点击「下一步」→ 显示中间分割线，以及右侧上半部分（提取个体标题、提取雌性、提取雄性）。
- 步骤5：点击「下一步」→ 显示右侧下半部分概率树状图（概率计算标题、常染色体分支、性染色体分支、最终概率框及文本）。

[交互方案]
- 交互类型：分步按钮导航
- 控件说明：在 SVG 底部 (y=460) 放置 HTML 按钮。
  - `scene2-btn-prev`：◀ 上一步
  - `scene2-step-text`：步骤指示器 (如 "步骤 0 / 5")
  - `scene2-btn-next`：下一步 ▶
- 教师操作流程：教师点击“下一步”逐步展示遗传推导过程，先讲亲本到F1，再讲F2的拆分与组合，最后讲特定个体的概率计算，逻辑清晰。

[技术实现]
- JS 库选择：原生 SVG（适合静态图形、文本排版和简单的显示/隐藏动画）。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  左侧 (0-400): P -> F1 -> F2 推导
  右侧 (400-800): F2 提取与概率计算
  [控件栏 y=460~490]
  ```
- 关键实现要点：
  - 使用 `<g>` 标签将每一步的元素分组，如 `<g id="scene2-step1">`。
  - 状态机设计：定义 `currentStep` 变量（0-5），根据其值设置对应组的 `display` 属性（'none' 或 'block'）或 `opacity`。
  - 果蝇图标可以使用 `<defs>` 定义模板，通过 `<use>` 引用并覆盖颜色属性，或者直接用函数生成 SVG 字符串插入。为简单起见，直接在 SVG 中写入 4 个独立的 `<g>` 组合。
  - 上下标处理：使用 `<tspan baseline-shift="super" font-size="0.8em">` 实现基因型中的上标（如 X^R）。
- ID 命名规范：所有交互元素 ID 必须以 `scene2-` 为前缀。
- IIFE 隔离：所有 JS 代码包裹在 `(function() { ... })()` 中。
