[图示主题与整合说明]
- 本图示主题：白眼雄果蝇M的三种来源假设及测交实验验证
- 整合的步骤/概念：将环境改变、基因突变、染色体不分离三种假设下的遗传图解及实验结果预测整合在同一面板中，通过状态切换进行对比。
- 教学价值：教师可通过切换三种假设，直观展示不同机制下M果蝇的基因型差异，以及这些差异如何导致测交实验结果的不同，帮助学生理解假说-演绎法在遗传学探究实验中的应用。

[视觉元素清单]
- 标题与固定文本：黑色 #000000，14px/16px，居中对齐。
- 遗传图解箭头：黑色 #000000，stroke-width="1.5"，带 marker-end。
- 正常基因/染色体：蓝色高亮 #1565c0。
- 突变基因/异常染色体：红色高亮 #c62828。
- 环境影响框：绿色高亮 #2e7d32，stroke-dasharray="4 4"，fill="none"。
- XO细胞图：黑色圆圈 (r=35)，内部包含2对V型常染色体、1对点状常染色体、1条棒状X染色体。底部标签 "XO(雄性，不育)" 用红色 #c62828。
- 不育叉号：红色 #c62828，大号字体 (30px)，表示无法产生配子。

[分步序列]
- 初始状态（状态1：环境改变）：
  - 左侧：卵 `X^R` (蓝)，精 `Y` (蓝)。F1 `X^RY` (蓝)。显示绿色虚线框。说明 "环境改变引起表现型变化，基因型未变" (绿)。
  - 右侧：M配子 `X^R` 和 `Y`。F2 结果 `X^RX^r (红眼雌)` 和 `X^rY (白眼雄)`。结论 "出现红眼雌果蝇" (蓝)。
- 状态2（基因突变）：
  - 左侧：卵 `X^r` (红)。精 `Y` (蓝)。F1 `X^rY` (红/蓝)。隐藏绿色虚线框。说明 "亲本雌果蝇发生基因突变产生X^r卵细胞" (红)。
  - 右侧：M配子 `X^r` 和 `Y`。F2 结果 `X^rX^r (白眼雌)` 和 `X^rY (白眼雄)`。结论 "子代全为白眼" (红)。
- 状态3（染色体不分离）：
  - 左侧：卵 `O` (红)。精 `X^r` (蓝)。F1 `X^rO` (红/蓝)。说明 "减数分裂时X染色体不分离产生O卵细胞" (红)。显示 XO 细胞图。
  - 右侧：隐藏M配子和F2结果，在M配子位置显示红色大叉 `×`。结论 "M果蝇不育，无子代" (红)。

[标签冲突检查]
- 左侧P (100,90) 与 乘号 (200,90) 与 左侧P雄 (300,90)：间距 100px，文本宽度约 80px，无冲突。
- 左侧F1说明 (200,300) 与 XO细胞图 (200,360)：XO图半径 35px (占据 325~395)，说明文本在 y=300，间距 25px，无冲突。
- 右侧箭头起点 (y=100) 与 终点 (y=140)：避开了文本区域 (y=90 和 y=160)，无冲突。
- 基因型上标处理：使用 `<tspan dy="-5" font-size="0.7em">`，不会增加整体行高导致重叠。

[交互方案]
- 交互类型：多状态切换（3个按钮）。
- 控件说明：在 SVG 底部 (y=460) 放置三个按钮："环境改变"、"基因突变"、"染色体不分离"。
- 教师操作流程：教师点击不同按钮，图示动态切换左侧的产生机制和右侧的测交结果，对比三种假设的异同。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。遗传图解主要是文本和简单连线，原生 SVG 的 `<text>` 和 `<path>` 配合 `<tspan>` 处理上下标最为高效。
- 画布尺寸：800 × 500 px。
- 布局草图：
  [图示区 800×440]
  | 左侧：M果蝇产生机制 (x:0-400) | 右侧：测交实验验证 (x:400-800) |
  [控件栏 800×60 (y:440-500)]
  | [环境改变] [基因突变] [染色体不分离] |
- 关键实现要点：
  - 状态机设计：定义 `updateState(stateIndex)` 函数，根据索引更新各个文本元素的 `innerHTML` (处理 `<tspan>`) 和颜色属性。
  - 基因型格式化：编写辅助函数 `formatGenotype(str)`，自动将 `X^R` 转换为带 `<tspan>` 的 SVG 文本。
  - 显隐控制：通过修改元素的 `display` 属性 (`block` 或 `none`) 控制环境框、XO细胞图、不育叉号的显示与隐藏。
- ID 命名规范：所有交互元素 ID 必须以 `scene3-` 为前缀（如 `scene3-left-gamete-egg`, `scene3-btn-env`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
