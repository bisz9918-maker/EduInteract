[分步序列]
- 初始状态（步骤0）：显示图例、反应前后的矩形框、甲乙丙丁的初始微观模型、反应箭头及"高温"条件。
- 步骤1（识别分子）：
  - 出现从图例到甲、乙对应原子的灰色虚线引导线。
  - 模型下方出现化学式：CH₄(140,260), H₂O(260,260), CO(545,260), H₂(660,260)。
  - 底部(y=340)出现未配平方程式：`CH₄ + H₂O → CO + H₂`。
- 步骤2（配平方程式）：
  - 左侧甲、乙中的6个H原子闪烁或高亮轮廓。
  - 右侧淡入新增的两个丁模型（丁新1、丁新2），带有蓝色轮廓。
  - 方程式更新：`→` 变为 `=`，`H₂` 变为 `<tspan fill="#1565c0">3</tspan>H₂`。
- 步骤3（分析选项A、B）：
  - 方程式上方(y=315)出现化合价：C(-4), H(+1), C(+2), H(0)，红色显示。右侧出现"A ✗"。
  - 方程式下方出现蓝色圆角矩形背景高亮 CH₄+H₂O 区域，标注"化合物"；高亮 3H₂ 区域，标注"单质"。右侧出现"B ✗"。
- 步骤4（分析选项C、D）：
  - 底部(y=400)出现计算式：`乙(H₂O)与丁(3H₂)质量比 = 18 : (3×2) = 3 : 1`，右侧出现"C ✓"。
  - 底部(y=430)出现计算式：`丙(CO)与丁(3H₂)分子数比 = 1 : 3`，右侧出现"D ✓"。

[技术实现]
- JS 库选择：原生 SVG + 原生 JS。SVG 非常适合绘制精确的分子模型和文本排版。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800x450]
    [图例 600-760, 20-120]
    [反应前 50-350, 120-260] [箭头] [反应后 450-750, 120-260]
    [方程式及标注区 y=315~430]
  [控件栏 800x50, y=450-500]
  ```
- 关键实现要点：
  - 使用 `<pattern>` 定义碳原子的条纹填充。
  - 使用 CSS class 控制元素的显示/隐藏（`opacity: 0` 到 `opacity: 1`，配合 `transition` 实现平滑动画）。
  - JS 维护一个 `currentStep` 变量（0-4），点击按钮时更新变量并调用 `updateStep()` 函数，该函数根据当前步骤为各 SVG 元素添加/移除 `.scene1-visible` 类。
- ID 命名规范：所有元素 ID 以 `scene1-` 开头，如 `scene1-btn-next`, `scene1-eq-ch4`。
- IIFE 隔离：所有 JS 代码包裹在 `(function() { ... })()` 中。
