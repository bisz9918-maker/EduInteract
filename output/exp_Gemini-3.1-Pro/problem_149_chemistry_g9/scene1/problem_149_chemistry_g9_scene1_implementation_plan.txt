[图示主题与整合说明]
- 本图示主题：化学反应微观过程与粒子分析
- 整合的步骤/概念：反应前后粒子对比、识别并去除剩余反应物、确定反应类型、推导化学方程式微观比例
- 教学价值：教师可通过分步演示，引导学生从纷繁复杂的微观粒子图中，清晰地剥离出未参与反应的“干扰项”，从而直观地得出实际发生反应的粒子比例，最终推导出宏观的化学反应方程式和反应类型。

[视觉元素清单]
- 背景：#ffffff
- 主线/容器边框：#000000，2px宽
- a原子：空心大圆，r=15，边框 #000000，填充 #ffffff
- b原子：实心小圆，r=8，边框 #000000，填充 #000000
- c原子：网格大圆，r=15，边框 #000000，填充 url(#scene1-grid)（需在defs中定义网格pattern）
- 分子组合：
  - a2分子：两个a原子相切（中心距30）

  - ab2分子：中心一个a原子，两侧各相切一个b原子（中心距23）

- 红高亮：#c62828，用于步骤3的实线框
- 绿高亮：#2e7d32，用于步骤4中强调化学计量数（1, 2, 2）
- 辅助线：#888888 虚线，用于连接剩余分子

[分步序列]
- 初始状态（步骤0）：显示图例、甲图容器及内部4个分子、乙图容器及内部3个分子、中间反应箭头。所有高亮和等式均隐藏。
- 步骤1（识别剩余）：显示甲图下方a2分子和乙图左下a2分子的蓝色高亮虚线框，显示连接两者的灰色虚线，并显示标签"剩余未反应的分子"。
- 步骤2（实际反应）：隐藏步骤1的高亮框、连线和标签。将甲图下方a2分子和乙图左下a2分子的透明度降至 0.2（淡化），突出显示实际发生反应的粒子。
- 步骤3（生成物分析）：在步骤2基础上，显示乙图中两个ab2分子的红色高亮框，并在乙图上方显示红色标签"生成物: 2个 ab2 分子"。
- 步骤4（反应类型与方程式推导）：保持步骤3状态，在画布下方（y=400区域）淡入微观反应等式：
  - 绿色数字"1" + a2分子图形 + "+" + 绿色数字"2" + b2分子图形 + "→" + 绿色数字"2" + ab2分子图形
  - 等式下方淡入文字："单质 + 单质 → 化合物 (化合反应)"

[交互方案]
- 交互类型：分步按钮导航
- 控件说明：在 SVG 底部 (y=470) 放置两个按钮「◀ 上一步」和「下一步 ▶」。
- 教师操作流程：教师点击“下一步”逐步引导学生观察：先找两边都有的剩余物（步1），剔除剩余物看实际反应（步2），聚焦生成物特征（步3），最后总结规律得出方程式（步4）。可随时点击“上一步”回退。

[技术实现]
- JS 库选择：原生 SVG。微观粒子均为标准几何图形（圆、矩形、直线），SVG 结构清晰，易于通过 DOM 操作控制显示/隐藏和透明度。
- 画布尺寸：800 × 500 px。
- 布局草图：
  [顶部 800x80：图例区]
  [中部 800x270：甲图、箭头、乙图]
  [下部 800x100：反应等式及文字结论]
  [底部 800x50：控件栏]
- 关键实现要点：
  - 使用 `<defs>` 定义 a、b、c 原子的基础样式（特别是 c 原子的 pattern），以及 a2、b2、ab2 分子的 `<g>` 组合，通过 `<use>` 标签在各处复用，保持代码简洁。
  - 状态机设计：定义 `currentStep` (0-4)，在 `updateStep()` 函数中根据当前步数统一设置各元素的 `display` 或 `opacity` 属性。
  - 动画过渡：可为分子的 `opacity` 属性添加 CSS `transition: opacity 0.5s` 实现平滑淡化效果。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-mol-a2-remain`, `scene1-step1-hl` 等）。
- IIFE 隔离：所有 JS 逻辑封装在 `(function() { ... })()` 中。
