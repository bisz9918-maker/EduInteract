[分步序列]
- 初始状态（步骤0）：显示图例、反应前后外框、箭头、A/B1/C/D1模型及A/B/C/D标签。底部面板空。
- 步骤1（写出化学式）：在A、B、C、D标签下方分别淡入显示化学式 CH₄、O₂、CO₂、H₂O。
- 步骤2（方程式配平）：在 y=310 处淡入未配平方程式。随后动画淡入 B2(O₂) 和 D2(H₂O) 模型（带蓝色发光），方程式中 O₂ 和 H₂O 前面出现蓝色系数 "2"。
- 步骤3（辨析选项A）：底部面板淡入原子统计信息。左侧显示"反应前：C=1, H=4, O=4"（数字绿色），右侧显示"反应后：C=1, H=4, O=4"（数字绿色）。下方居中显示结论"反应前后原子数目不变，选项A正确"（"正确"蓝色）。
- 步骤4（辨析选项B）：在方程式下方 (y=340) 淡入相对分子质量：CH₄ 下方显示 "16"，2O₂ 下方显示 "2×32=64"。底部面板切换内容为："m(A) : m(B) = 16 : 64 = 1 : 4"，结论"选项B错误 (非 8:1)"（"错误"和"8:1"红色）。
- 步骤5（辨析选项C与D）：底部面板切换内容为两行。第一行："选项C：方程式未配平，错误"（"未配平"红色）。第二行："选项D：反应物含化合物和单质，生成物均为化合物，不符合置换反应定义，错误"（"置换反应"红色）。

[技术实现]
- JS 库选择：原生 SVG（适合绘制精确的分子模型和几何图形） + 原生 JS。
- 画布尺寸：800 × 500 px。
- 布局草图：
  [图例区 620-780, 20-100]
  [反应前框 60-320] [点燃箭头] [反应后框 420-740]
  [化学式 130/250/510/660, y=260]
  [化学方程式 y=310]
  [相对分子质量 y=340]
  [底部信息面板 50-750, y=360-430]
  [控件栏 y=450-490]
- 关键实现要点：
  1. 使用 `<pattern>` 定义碳原子的斜纹填充。
  2. 使用 `<g>` 标签将原子组合成分子模型，方便整体定位和控制显隐。
  3. 状态机设计：定义 `currentStep` (0-5)，编写 `updateScene()` 函数，根据当前步骤控制各元素的 `opacity` 或 `display` 属性，实现淡入淡出效果。
  4. 文本中的下标使用 `<tspan baseline-shift="sub" font-size="0.7em">` 实现。
- ID 命名规范：所有交互元素 ID 以 `scene1-` 为前缀，如 `scene1-btn-next`, `scene1-model-b2`。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
