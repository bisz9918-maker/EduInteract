场景导航：Scene 1

题目：现有氢气、氮气、氯化氢、水蒸汽、一氧化碳和二氧化碳混合气体，依次通过下图A、B、C、D装置（假设每步都充分反应），各装置依次除去的气体和最后得到的气体分别是（ ）
A．HCl、CO、H₂、CO₂、H₂O、N₂
B．CO₂、CO、H₂、HCl、H₂O、N₂
C．HCl、CO、H₂、H₂O、CO₂、N₂
D．H₂、CO、CO₂、HCl、N₂、H₂O

题目分析：
本题考查常见气体的净化与除杂。解答此类问题的关键是明确每种试剂的作用，以及气体通过水溶液时会带出水蒸气这一隐含条件。

整体讲解思路：
通过动态图示，模拟混合气体依次通过四个装置的过程。在每个装置处暂停，引导学生分析当前装置中试剂的化学性质，判断哪种气体被消耗（除去），哪种气体生成或透传，最终推导出各装置除去的气体顺序及最后剩余的气体。

初始混合气体：H₂、N₂、HCl、H₂O、CO、CO₂

教学引导说明：

利用上述图示，教师可按以下步骤引导学生：

  1. 分析装置A：提问碳酸氢钠溶液能吸收混合气体中的哪种成分？讲解 NaHCO₃ 能与酸性气体 HCl 反应：NaHCO₃ + HCl = NaCl + H₂O + CO₂↑。注意它不吸收 CO₂，反而会生成 CO₂。因此装置A除去了 HCl。
  2. 分析装置B：提问加热的氧化铜有什么化学性质？混合气体中谁能与它反应？讲解 CuO 具有氧化性，能与还原性气体发生反应：H₂ + CuO = Cu + H₂O 和 CO + CuO = Cu + CO₂。结论：装置B除去了 H₂ 和 CO。
  3. 分析装置C：经过B之后，气体中含有 N₂、H₂O、CO₂。澄清石灰水专门用于检验和吸收 CO₂：Ca(OH)₂ + CO₂ = CaCO₃↓ + H₂O。因此装置C除去了 CO₂。
  4. 分析装置D：现在只剩下 N₂ 和 H₂O。浓硫酸具有强吸水性，用于干燥气体。因为气体通过A和C的水溶液时会带出水蒸气，B中反应也会生成水蒸气，所以除水必须放在最后一步。装置D除去了 H₂O。
  5. 得出结论：经过上述四步，最后收集到的气体只剩下不参与任何反应的 N₂。综合来看，依次除去的气体是：HCl、（CO、H₂）、CO₂、H₂O，最后得到 N₂。对照选项，正确答案为 A。
