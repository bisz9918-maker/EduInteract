[图示主题与整合说明]
- 本图示主题：混合气体依次通过除杂装置的成分变化过程
- 整合的步骤/概念：整合了装置A除HCl、装置B除还原性气体(H2、CO)、装置C除CO2、装置D除水蒸气的完整流程及气体成分的演变。
- 教学价值：教师可通过分步演示，清晰地向学生展示每一步中哪种气体被吸收或反应，以及剩余气体的成分变化。气体标签直接“飞入”吸收剂中消失的动画设计，能极大增强学生对除杂原理的直观理解。

[视觉元素清单]
- 装置A：包含瓶身、瓶颈、黑色橡胶塞、浅灰色半透明液体(碳酸氢钠)、长进气管(左侧深入液体)、短出气管(右侧)。
- 装置B：包含硬质玻璃管、左右橡胶塞、黑色椭圆表示CuO粉末、酒精灯(含底座、灯体、橙色火焰)、铁架台(底座、铁夹、铁柱)。
- 装置C：结构同A，液体为浅灰色半透明(澄清石灰水)。
- 装置D：结构同A，液体为浅蓝色半透明(浓硫酸)。
- 气体标签：圆角矩形背景+白色文字。配色：HCl(#c62828)、H2与CO(#f57c00)、CO2(#2e7d32)、H2O(#1565c0)、N2(#888888)。
- 高亮样式：当前反应装置的边框变为 #1565c0，线宽 4px，并带有蓝色外发光(drop-shadow)。

[分步序列]
- 初始状态（步骤0）：
  - 显示完整装置图。无高亮。
  - 气体标签位于最左侧进气口上方：H2(35,80), N2(85,80), HCl(35,105), H2O(85,105), CO(35,130), CO2(85,130)。
  - 底部文本：“初始混合气体：H2、N2、HCl、H2O、CO、CO2”。
- 步骤1（通过装置A）：
  - 高亮装置A瓶身。
  - 气体移动：所有气体向右移动。HCl 移动至 (120,280) 即装置A液体中，并渐隐消失(opacity:0)。其余气体移至 x=175~225 区域。
  - 底部文本：“装置A：碳酸氢钠溶液吸收 HCl 气体”及方程式。
- 步骤2（通过装置B）：
  - 高亮装置B玻璃管。
  - 气体移动：剩余气体向右移动。H2 和 CO 移动至 (330,185) 即CuO粉末处，并渐隐消失。其余气体移至 x=435~485 区域。
  - 底部文本：“装置B：氧化铜与 H2、CO 发生还原反应”及方程式。
- 步骤3（通过装置C）：
  - 高亮装置C瓶身。
  - 气体移动：剩余气体向右移动。CO2 移动至 (520,280) 即装置C液体中，并渐隐消失。其余气体移至 x=575~625 区域。
  - 底部文本：“装置C：澄清石灰水吸收 CO2 气体”及方程式。
- 步骤4（通过装置D）：
  - 高亮装置D瓶身。
  - 气体移动：剩余气体向右移动。H2O 移动至 (680,280) 即装置D液体中，并渐隐消失。N2 移至最右侧出气口 (750,100)。
  - 底部文本：“装置D：浓硫酸吸收水分（干燥气体）。最后得到的气体是 N2”。

[标签冲突检查]
- 装置标签(y=350,370) 与 文本解说区(y=390)：装置标签最低点在 y=380 左右，与文本区 y=390 间距 10px，无冲突。
- 气体标签(y=80~130) 与 导管(y=180)：气体标签最高在 y=140，与导管间距 40px，无冲突。
- "氧化铜"标签(330,150) 与 气体标签：步骤1气体在 x=200 附近，步骤2气体在 x=460 附近，完美避开 x=330 区域，无冲突。
- 装置B铁架台(x=265) 与 导管连接处：导管连接在橡胶塞(x=250)，铁架台立柱在 x=265，无重叠冲突。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：底部居中放置两个按钮，控制步骤 0 到 4 的切换。
- 教师操作流程：教师点击“下一步”，引导学生观察哪种气体“掉入”了当前装置并消失，同时结合底部出现的化学方程式讲解除杂原理。可随时点击“上一步”回退，气体标签会平滑飞回原位。

[技术实现]
- JS 库选择：原生 SVG + CSS Transitions。气体移动和消失仅需修改 SVG `<g>` 的 `transform` 和 `opacity` 属性，配合 `transition: all 0.8s ease-in-out` 即可实现极其流畅的物理飞入动画。
- 画布尺寸：800 × 500 px。
- 布局草图：
  [图示区 800×390：上方气体标签，中间导管，下方四个装置]
  [文本区 800×60：居中显示当前步骤说明和方程式]
  [控件栏 800×50：底部居中两个按钮]
- 关键实现要点：
  - 状态机设计：定义一个包含 5 个状态的数组，每个状态记录各气体标签的 `(x, y, opacity)` 目标值、当前高亮的装置 ID、以及底部要显示的 HTML 文本。
  - 动画曲线：使用 CSS `transition` 实现平滑过渡，使气体被吸收的过程具有视觉吸引力。
  - 文本更新：底部文本区使用绝对定位的 HTML `<div>`，方程式中的上下标使用 `<sub>` 标签实现。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-gas-hcl`, `scene1-btn-next`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
