[图示主题与整合说明]
- 本图示主题：化学反应微观过程与实质分析
- 整合的步骤/概念：识别过量物质、提取净反应、物质分类（单质/化合物）、反应类型判断（化合反应）、反应物微粒个数比。
- 教学价值：教师可以通过分步动画，引导学生从复杂的微观示意图中排除未反应的干扰微粒，提取出真正的净反应方程式，进而直观地判断物质类别和反应类型，最后逐一验证选项，逻辑清晰，视觉冲击力强。

[视觉元素清单]
- 容器与基础UI：左右两个矩形框（stroke #000000, fill none），主箭头（stroke #000000），底部标签“反应前”、“反应后”。
- 原子模型：
  - 白色原子（○）：半径10px，fill #ffffff，stroke #000000，stroke-width 2px。
  - 黑色原子（●）：半径10px，fill #000000，stroke #000000，stroke-width 2px。
- 分子模型（使用 `<g>` 组合并设置 transform）：
  - 白白分子（单质）：两个白色原子，cx分别为 -8 和 8，cy为 0。
  - 黑黑分子（单质）：两个黑色原子，cx分别为 -8 和 8，cy为 0。
  - 白黑白分子（化合物）：中心黑色原子 cx=0, cy=0；两个白色原子 cx=-12, cy=12 和 cx=12, cy=12。
- 高亮与标注：
  - 干扰项高亮：蓝色虚线圆圈（stroke #1565c0, stroke-dasharray 4, fill none, r=22），蓝色指示箭头和文本（fill #1565c0）。
  - 核心结论高亮：红色文本“单质”、“化合物”、“多变一 → 化合反应”（fill #c62828）。
  - 比例高亮：绿色文本“参加反应的分子个数比 2:1”（fill #2e7d32）。

[分步序列]
- 初始状态（步骤0）：显示左右容器、主箭头、“反应前/后”标签，以及容器内的所有分子（按初始坐标和旋转角度放置）。隐藏其他所有元素。
- 步骤1（排除干扰）：点击「下一步」。出现蓝色虚线圈，高亮左侧2个和右侧2个未反应的白白分子。淡入蓝色文本“未反应的分子”及指向虚线圈的指示箭头。
- 步骤2（净反应）：点击「下一步」。未反应的分子及其蓝色高亮提示的透明度降低至 20%。真正参与反应的分子（左侧2个白白、1个黑黑，右侧2个白黑白）触发平移和旋转动画，移动至 y=310~315 区域形成净反应方程式。同时淡入净反应的“+”和“→”符号。
- 步骤3（物质分类与反应类型）：点击「下一步」。在净反应分子下方淡入红色标签“单质”、“单质”、“化合物”。在净反应箭头上方淡入红色标签“多变一 → 化合反应”。
- 步骤4（选项分析）：点击「下一步」。在下方依次淡入三行结论文本：“生成物只有化合物 (排除B)”、“反应前后分子种类发生改变 (排除C)”、“参加反应的分子个数比 2:1 (排除D)”（其中2:1使用绿色高亮）。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：在 SVG 内部底部（y=460~490）居中放置两个按钮。
- 教师操作流程：教师首先引导学生观察反应前后的微粒变化；点击下一步，指出两边都有的微粒是没有参与反应的；再次点击，提取出真正的反应过程，让学生直观看到“2个白白 + 1个黑黑 = 2个白黑白”；接着点击，标注物质分类，引出化合反应概念；最后点击，逐一核对题目选项，完成解题。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。SVG 的 `<g>` 标签配合 CSS `transform: translate(x, y) rotate(deg)` 和 `transition: all 0.8s ease` 可以极其简单且高性能地实现分子的平移和旋转动画，无需引入额外的动画库。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```text
  [图示区 800×500]
  +---------------------------------------------------+
  |      未反应的分子↓                  ↓未反应的分子   |
  |  +-----------------+         +-----------------+  |
  |  |  oo         oo  |         |  o@o        oo  |  |
  |  |       @@        |  ---->  |                 |  |
  |  |  oo         oo  |         |  oo        o@o  |  |
  |  +-----------------+         +-----------------+  |
  |        反应前                       反应后        |
  |                                                   |
  |                 多变一 -> 化合反应                |
  |        oo   oo   +   @@   ---->   o@o   o@o       |
  |        单质        单质             化合物        |
  |                                                   |
  |              生成物只有化合物 (排除B)             |
  |           反应前后分子种类发生改变 (排除C)        |
  |           参加反应的分子个数比 2:1 (排除D)        |
  |                                                   |
  |              [ ◀ 上一步 ] [ 下一步 ▶ ]            |
  +---------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：定义 `currentStep` (0~4)，每次点击按钮更新状态并调用 `updateScene()`。
  2. 动画实现：为所有分子组 `<g>` 添加 `style="transition: transform 0.8s ease, opacity 0.8s ease;"`。在 JS 中通过修改 `element.style.transform` 触发平移和旋转。
  3. ID 命名规范：所有元素 ID 必须以 `scene1-` 为前缀，例如 `scene1-mol-left-ww1`、`scene1-btn-next`。
  4. IIFE 隔离：所有 JS 代码包裹在 `(function() { ... })()` 中，避免全局变量污染。
