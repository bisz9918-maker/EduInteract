[图示主题与整合说明]
- 本图示主题：溶解度曲线的意义及溶液状态的动态转化
- 整合的步骤/概念：整合了曲线上/下点的意义、加水稀释的影响、降温结晶过程、以及不饱和溶液转化为饱和溶液的路径。
- 教学价值：教师可以通过分步导航，按题目设问顺序（Q1~Q4）逐步展示图像上的动态变化，将抽象的溶液状态转化（如加水、降温、加溶质、蒸发）具象化为坐标系中的点移动和箭头指向，帮助学生直观理解溶解度曲线的物理意义。

[分步序列]
- 初始状态（步骤0）：显示坐标系、溶解度曲线、辅助虚线、坐标轴标签（t1, t2, t3, S1, S2）以及点 A、B、M。所有点为黑色。
- 步骤1（讲Q1）：
  - 点 A 变为红色（#c62828），点 B 变为蓝色（#1565c0）。
  - 点 A 左上角 (300, 100) 出现公式 "S2/(100+S2) × 100%"（带红色边框的提示框）。
  - 点 B 右侧 (620, 280) 出现蓝色文字 "不饱和状态"。
- 步骤2（讲Q2）：
  - 隐藏步骤1的提示框和文字。
  - 顶部居中 (400, 60) 出现提示框 "恒温加水20g"。
  - 溶解度曲线闪烁 3 次（强调溶解度不变）。
  - 点 A 处出现向下虚线箭头至 (450, 220)；点 B 处出现向下虚线箭头至 (600, 370)。
  - 在 (520, 250) 出现对比不等式 "S2/(120+S2) > S1/(120+S1)"。
- 步骤3（讲Q3）：
  - 隐藏步骤2的提示框、箭头和不等式。
  - 演示降温过程：点 A 沿曲线向左下方滑动至点 C (250, 300)。
  - 滑动路径用绿色（#2e7d32）加粗高亮。
  - 点 A 滑动过程中，下方不断出现向下掉落的小颗粒动画（表示溶质析出）。
  - 在 (250, 200) 出现绿色提示框 "仍为饱和，但溶解度减小"。
- 步骤4（讲Q4）：
  - 隐藏步骤3的提示框和动画，重置点 A 位置。
  - 高亮点 M 为蓝色（#1565c0）。
  - 出现水平向左的绿色箭头：(450, 300) -> (260, 300)，上方 (350, 290) 标注 "降温至 t1℃"。
  - 出现竖直向上的绿色箭头：(450, 300) -> (450, 160)，右侧 (460, 225) 标注 "加溶质 (S2-S1)g"。
  - 在 M 点右下方 (480, 330) 出现蒸发图标，下方 (480, 350) 标注 "恒温蒸发溶剂"。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 底部居中放置两个按钮："◀ 上一步" 和 "下一步 ▶"。
  - 按钮样式：现代扁平化设计，禁用状态置灰。
- 教师操作流程：
  - 初始展示题目基础图形。
  - 点击“下一步”讲解第一问，展示 A、B 点的意义。
  - 再次点击讲解第二问，展示加水稀释对浓度的影响。
  - 再次点击讲解第三问，动态演示降温结晶过程。
  - 最后点击讲解第四问，展示不饱和溶液转化为饱和溶液的三种方法。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。SVG 适合绘制精确的几何图形和曲线，原生 JS 配合 requestAnimationFrame 适合实现点沿曲线滑动和颗粒掉落动画，无需引入庞大的外部库。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```text
  +--------------------------------------------------+
  |                                                  |
  |  溶解度(克)                                      |
  |   ^                                              |
  |   |           [提示框/公式区]                    |
  | S2+-----------------------A                      |
  |   |                      /|                      |
  |   |                     / |                      |
  |   |                    /  |                      |
  | S1+----------C--------M---B                      |
  |   |         /         |   |                      |
  |   |        /          |   |                      |
  |   +--------+----------+---+----------------->    |
  |  O         t1         t2  t3          温度(℃)    |
  |                                                  |
  |             [ ◀ 上一步 ] [ 下一步 ▶ ]            |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  - 状态机设计：定义 `currentStep` 变量（0-4），每次点击按钮更新状态，并调用 `renderStep(step)` 函数。
  - 动画实现：点 A 沿曲线滑动可使用 SVG `<animateMotion>` 或 JS 逐帧更新坐标。曲线路径需精确定义 `d="M 120 370 Q 200 320 250 300 Q 350 260 450 150 Q 500 90 530 40"`。
  - 颗粒掉落：在步骤3中，使用 `requestAnimationFrame` 动态生成小圆点，赋予随机水平偏移和向下的垂直速度，超出一定范围后移除。
  - 步骤切换清理：每个步骤函数开头需重置上一个步骤的特有元素（隐藏提示框、重置点位置、清除动画定时器），确保状态切换干净。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-point-a`, `scene1-btn-next`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
