    <TEXT_1>
    题目：
    下列各组变化中，每一步转化在一定条件下均能一步实现的是
    A．①②
    B．①③
    C．②③
    D．①②③

    题目分析：
    本题考查初中化学常见物质的相互转化。解答此类题目的关键是熟悉常见物质的化学性质，并能写出对应的化学方程式。如果某一步转化无法通过一个反应直接生成目标产物，则该转化不能“一步实现”。

    整体讲解思路：
    1. 逐一分析三个转化图中的每一步反应。
    2. 对于图①，写出碳酸钙分解、氧化钙化水、氢氧化钙吸收二氧化碳的方程式，验证其均可一步实现。
    3. 对于图②，重点分析氧化铁到硫酸亚铁的转化。氧化铁与稀硫酸反应生成的是硫酸铁（Fe2(SO4)3）而非硫酸亚铁（FeSO4），因此该步无法一步实现。
    4. 对于图③，写出水电解、镁燃烧、氧化镁与酸反应生成水的方程式，验证其均可一步实现。
    5. 综合得出结论，①③符合题意，选择B。

    图示规划说明：
    将三个转化图并列展示，通过分步导航，依次对每个转化图的每一步进行验证。正确的转化用绿色箭头和勾号标识，并配以化学方程式；错误的转化用红色箭头和叉号标识，并给出错误原因，直观呈现判断过程。
    </TEXT_1>

    图示主题：初中常见物质转化关系的逐一验证
    整合内容：整合了①、②、③三个转化图的判定过程及对应的化学方程式。
    交互类型：分步按钮导航 — 选择理由：物质转化需要逐图、逐步进行验证，分步导航能完美契合教师带学生一步步写方程式、判断正误的教学节奏。
    交互设计：
    步骤0：初始状态，并排展示①、②、③三个转化图，所有箭头为黑色默认状态。
    步骤1：验证图①。依次将图①的三个箭头变为绿色，并在图下方或旁边浮现对应的三个化学方程式（CaCO3高温分解、CaO加水、Ca(OH)2加CO2），每个方程式后出现绿色勾号，图①下方显示“①均能实现”。
    步骤2：验证图②。将 Fe→Fe2O3 箭头变绿；将 Fe2O3→FeSO4 箭头变红，并出现红色叉号。旁边浮现解析：“Fe2O3 + 3H2SO4 = Fe2(SO4)3 + 3H2O，生成物是硫酸铁而非硫酸亚铁”。图②下方显示“②不能实现”。
    步骤3：验证图③。依次将图③的三个箭头变为绿色，浮现对应的三个化学方程式（水电解、镁燃烧、MgO加酸），每个方程式后出现绿色勾号，图③下方显示“③均能实现”。
    步骤4：高亮图①和图③，得出最终结论选项B。
    视觉元素：
    1. 三个三角形布局的转化图（与原题图一致）：
       - 图①：CaCO3(上) → CaO(左下) → Ca(OH)2(右下) → CaCO3(上)
       - 图②：Fe(上) → Fe2O3(左下) → FeSO4(右下) → Fe(上)
       - 图③：H2O(上) → O2(左下) → MgO(右下) → H2O(上)
    2. 动态浮现的化学方程式文本框。
    3. 判定图标（绿色✔，红色✖）。
    标签：各物质的化学式、化学方程式、①②③序号。
    颜色/样式：

    红高亮 #c62828（用于不能一步实现的箭头、错误提示文本及✖图标）

    <TEXT_2>
    本图示的教学说明：
    1. 引导学生观察三个转化图，明确“一步实现”的含义，即只需要发生一个化学反应就能转化为目标物质。

    2. 讲解图①时，点击“下一步”，带领学生复习“碳酸钙-氧化钙-氢氧化钙”这一经典的钙三角转化，强调反应条件（如高温煅烧）。

    3. 讲解图②时，重点引导学生思考氧化铁（Fe2O3）与酸反应的产物。铁的氧化物中铁的化合价在反应中不变，Fe2O3中铁为+3价，与稀硫酸反应生成+3价的硫酸铁（Fe2(SO4)3），而不是+2价的硫酸亚铁（FeSO4）。这是本题的易错点。

    4. 讲解图③时，复习水、氧气、氧化物之间的转化，特别是氧化镁如何一步转化为水（通过与酸发生复分解反应生成盐和水，如 MgO + 2HCl = MgCl2 + H2O）。

    5. 最后结合验证结果，得出正确答案B。
    </TEXT_2>
