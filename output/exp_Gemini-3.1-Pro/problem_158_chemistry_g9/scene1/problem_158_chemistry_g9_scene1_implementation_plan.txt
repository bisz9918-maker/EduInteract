[图示主题与整合说明]
- 本图示主题：初中常见物质转化关系的逐一验证
- 整合的步骤/概念：整合了①、②、③三个转化图的判定过程及对应的化学方程式。
- 教学价值：教师可以通过分步导航，带领学生逐一分析每个转化图中的每一步反应是否能一步实现，并展示对应的化学方程式和错误原因，最后得出综合结论。这种逐步揭示的方式完美契合课堂提问与讲解的节奏。

[视觉元素清单]
- 物质化学式：SVG `<text>`，黑色 #000000，字号 18px，`text-anchor="middle"`。
- 转化箭头：SVG `<line>` 或 `<path>`，带有 `<marker>` 箭头。默认黑色 #000000，线宽 2px。
- 序号：SVG `<text>`，黑色 #000000，字号 16px。
- 方程式与解析文本：SVG `<text>`，字号 14px，`text-anchor="middle"`。正确的用绿色 #2e7d32，错误的用红色 #c62828。
- 判定图标：SVG 绘制的 ✔（绿色 #2e7d32）和 ✖（红色 #c62828）。
- 高亮背景框：SVG `<rect>`，圆角 `rx=10`，填充 #1565c0，透明度 0.1，边框 #1565c0。
- 最终结论：SVG `<text>`，蓝色 #1565c0，字号 20px，加粗。

[分步序列]
- 初始状态（步骤0）：显示图①、②、③的基础结构（化学式、黑色箭头、序号）。下方区域空白。
- 步骤1：验证图①。图①的三个箭头变为绿色 #2e7d32。图①下方依次浮现三个方程式（带绿色✔），以及结论“①均能实现”。
- 步骤2：验证图②。图②的 Fe→Fe2O3 箭头变绿；Fe2O3→FeSO4 箭头变红 #c62828，并在箭头中央出现红色✖。图②下方浮现红色解析文本及结论“②不能实现”。
- 步骤3：验证图③。图③的三个箭头变为绿色 #2e7d32。图③下方依次浮现三个方程式（带绿色✔），以及结论“③均能实现”。
- 步骤4：得出结论。图①和图③底层出现蓝色高亮背景框，底部中央浮现“结论：选项 B (①③)”。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：在 SVG 容器底部（y=450~490）居中放置两个按钮。
- 教师操作流程：教师点击“下一步”依次展示图①、图②、图③的验证过程，配合板书或口头讲解化学方程式，最后点击“下一步”展示最终选项。可随时点击“上一步”回退。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。图形均为简单几何线段和文本，原生 SVG 易于控制样式和动画，无需引入外部库。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
    (图①)       (图②)       (图③)
    方程式       解析         方程式
    结论         结论         结论
         [最终结论：选项 B]
  [控件栏： ◀上一步  下一步▶ ]
  ```
- 关键实现要点：
  - 使用 `<marker>` 定义三种颜色的箭头（黑、绿、红），通过 JS 切换 `<line>` 的 `marker-end` 属性和 `stroke` 颜色。
  - 所有的动态文本和高亮框初始设置 `opacity="0"`，通过 CSS `transition: opacity 0.5s` 实现平滑的淡入淡出效果。
  - 维护一个 `currentStep` 变量（0-4），在按钮点击事件中更新，并调用 `updateState()` 函数统一管理所有元素的可见性和颜色状态。
  - ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-arrow1-1`, `scene1-eq1`）。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
