[视觉元素清单]

- 颜色/样式：背景 #ffffff，主线 #000000，蓝高亮 #1565c0，红高亮 #c62828，绿高亮 #2e7d32，未激活图表透明度 30%。

[分步序列]
- 初始状态（步骤0）：显示A、B、C、D四个图表的坐标系和原图曲线，透明度均为100%。隐藏所有边框、修正曲线、方程式和解析标签。
- 步骤1（分析A）：图A保持100%透明度并显示蓝色边框，图B、C、D透明度降至30%。图A显示方程式，并用动画绘制红色虚线修正曲线，显示解析标签。
- 步骤2（分析B）：图B保持100%透明度并显示蓝色边框，图A、C、D透明度降至30%。图B显示方程式，动画绘制红色虚线，显示解析标签。
- 步骤3（分析C）：图C保持100%透明度并显示蓝色边框，图A、B、D透明度降至30%。图C显示方程式，动画绘制绿色实线覆盖原图，依次显示三个解析标签。
- 步骤4（分析D）：图D保持100%透明度并显示蓝色边框，图A、B、C透明度降至30%。图D显示原理文本，动画绘制红色虚线，显示解析标签。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：在 SVG 底部（y=460~490）居中放置两个按钮，用于控制步骤的前进和后退。
- 教师操作流程：教师首先展示四个原图，让学生思考。然后点击“下一步”，依次放大并剖析每个选项，展示化学方程式，动态画出正确的图像趋势，并给出文字解释。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript。SVG 非常适合绘制坐标系、几何图形和路径动画，且易于控制各个图表的透明度和显示状态。
- 画布尺寸：800 × 500 px。
- 布局草图：
  [图A区 320x210]  [图B区 320x210]
  [图C区 320x210]  [图D区 320x210]
  [ ◀上一步   下一步▶ ]
- 关键实现要点：
  1. 使用 `<g>` 标签将每个图表的所有元素分组（如 `id="scene1-group-a"`），便于统一控制透明度。
  2. 修正曲线使用 `<path>` 标签，通过 `stroke-dasharray` 和 `stroke-dashoffset` 实现线条绘制动画。
  3. 状态机设计：定义一个 `currentStep` 变量（0~4），每次点击按钮更新变量，并调用 `updateState()` 函数。
  4. `updateState()` 函数根据当前步骤，设置各组的 `opacity`，控制边框的 `display`，并触发对应步骤的动画和文本显示。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
