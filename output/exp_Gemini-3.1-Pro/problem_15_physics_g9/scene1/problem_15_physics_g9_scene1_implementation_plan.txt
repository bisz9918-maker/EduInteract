[图示主题与整合说明]
- 本图示主题：叠放与平放状态下的整体受力分析对比
- 整合的步骤/概念：整合了图甲（叠放）和图乙（平放）的初始状态、垂直方向受力（重力与支持力）、水平方向受力（推力与摩擦力）以及匀速运动条件下的二力平衡。
- 教学价值：教师可通过分步演示，引导学生使用整体法分析受力，理解滑动摩擦力只与压力和接触面有关，与接触面积和运动速度无关，最后通过二力平衡得出推力大小。

[分步序列]
- 初始状态（步骤0）：显示桌面、木块A和B、速度V₁和V₂、推力F₁和F₂、图甲图乙文本。提示文本：“初始状态：观察图甲（叠放）和图乙（平放）的受力与运动情况。”
- 步骤1：点击「下一步」→ 显示图甲和图乙的整体高亮矩形，显示垂直方向的 G_总 和 N 箭头及标签。提示文本：“整体法分析：将A和B看作整体。两图总重力相同，对桌面的压力相同。”
- 步骤2：点击「下一步」→ 显示水平方向的摩擦力 f₁ 和 f₂ 箭头及标签。提示文本：“摩擦力分析：压力和接触面粗糙程度相同，因此滑动摩擦力 f₁ = f₂。”
- 步骤3：点击「下一步」→ 将 F₁、f₁、F₂、f₂ 的箭头线宽加粗至 4px（高亮平衡力），将 V₁、V₂ 的透明度降至 0.3（淡化速度）。提示文本：“二力平衡：匀速直线运动时推力与摩擦力平衡。F₁=f₁，F₂=f₂，得出 F₁=F₂=100N。速度大小不影响滑动摩擦力。”

[技术实现]
- JS 库选择及原因：原生 SVG。图形均为简单的矩形、线段和箭头，SVG 易于实现且支持 CSS 动画和状态切换。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800x440]
  左侧：图甲（叠放）      右侧：图乙（平放）
  [提示文本区 y=450]
  [控件栏 y=480，上一步/下一步按钮]
  ```
- 关键实现要点：
  - 使用 `<defs>` 定义箭头 marker，方便复用。
  - 使用 CSS class 控制元素的显示/隐藏（如 `.step-1-show { opacity: 0; transition: opacity 0.3s; }`，在对应步骤添加 `.active` 类使其 `opacity: 1`）。
  - 步骤状态机：维护一个 `currentStep` 变量（0~3），点击按钮时更新变量并调用 `updateScene()` 函数更新所有元素的样式和提示文本。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-btn-next`, `scene1-f1-arrow`）。
- IIFE 隔离：所有 JS 代码包裹在 `(function() { ... })()` 中。
