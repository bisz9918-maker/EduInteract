[图示主题与整合说明]
- 本图示主题：利用平移和投影法转化不规则图形的周长
- 整合的步骤/概念：将不规则多边形的水平线段和竖直线段分别进行平移，证明分散的线段长度之和等于规则的已知线段长度。水平方向上，顶部各线段平移后与底部线段重合；竖直方向上，左右两侧的线段平移后可以拼接成等长的两条线段。最终通过代换完成周长计算。
- 教学价值：教师可以通过分步动画，直观地向学生展示“线段平移不改变长度”的几何思想，化繁为简，将未知边长的求和转化为已知边长的计算，帮助学生建立空间想象力和代数代换思维。

[分步序列]
- 初始状态（步骤0）：显示楼房多边形及所有基础标签。隐藏所有克隆体、轨迹线、辅助线和结论文本。
- 步骤1（水平线段）：点击「下一步」。
  - 视觉变化：h, f, d, b 线段高亮为蓝色（#1565c0，4px）。
  - 动画：出现 h, f, d 的克隆体及标签，分别向下平移至 y=320（即 b 所在水平线）。同时淡入灰色虚线轨迹。
  - 结论：在底部 (350, 395) 淡入蓝色文本 `h + f + d = b = 50`。
- 步骤2（竖直线段）：点击「下一步」。
  - 视觉变化：恢复 h, f, d, b 为默认黑色。隐藏步骤1的克隆体、轨迹线和结论1。a, e 高亮为红色（#c62828，4px），g, c 高亮为绿色（#2e7d32，4px）。淡入右侧竖直辅助线 (x=650)。
  - 动画：出现 a, e, g, c 的克隆体及标签。a 平移至 (640,220)-(640,340)；e 平移至 (640,20)-(640,220)；g 平移至 (660,20)-(660,100)；c 平移至 (660,100)-(660,340)。同时淡入对应的灰色虚线轨迹。
  - 结论：在辅助线底部 (650, 395) 淡入文本 `a + e = g + c = 10 + 30 = 40`（a+e部分红色，g+c部分绿色）。
- 步骤3（综合计算）：点击「下一步」。
  - 视觉变化：保持步骤2的线段高亮状态，隐藏步骤2的克隆体、轨迹线和结论2。
  - 动画：在底部区域依次淡入三行综合计算公式。
    - 行1：`P = a + b + c + d + e + f + g + h` (全黑)
    - 行2：`P = (h + f + d) + b + (a + e) + (g + c)` (对应分组使用蓝、蓝、红、绿)
    - 行3：`P = 50 + 50 + 40 + 40 = 180` (对应数值使用蓝、蓝、红、绿，180为黑色加粗)

[交互方案]
- 交互类型：分步按钮导航。
- 控件说明：在 SVG 容器底部 (y=460~490) 放置三个按钮：「◀ 上一步」、「下一步 ▶」、「↺ 重置」。
- 教师操作流程：教师首先展示原图，让学生思考如何求周长。点击「下一步」演示水平线段的平移重合，讲解水平方向的等量代换；再次点击「下一步」演示竖直线段的投影拼接，讲解竖直方向的等量代换；最后点击「下一步」展示完整的公式推导和计算过程。可随时点击「上一步」回退复习。

[技术实现]
- JS 库选择：原生 SVG + GSAP (用于平滑的平移和淡入淡出动画)。GSAP 能极大地简化多元素的并发动画和状态管理。
- 画布尺寸：800 × 500 px。
- 布局草图：
  [图示区 800×460]
    - 左侧 (150~550)：楼房多边形
    - 右侧 (650)：竖直投影辅助线
    - 底部 (380~460)：结论与公式展示区
  [控件栏 800×40] (绝对定位在底部)
- 关键实现要点：
  1. 状态机设计：定义 `currentState` (0~3)，每次点击按钮时，根据目标状态执行对应的 GSAP 动画序列 (Timeline) 或直接设置状态。
  2. 元素克隆：在 SVG 中预先定义好所有克隆体线段和标签，初始设置为 `opacity: 0`。动画时改变其 `transform` 或 `x/y` 属性并淡入。
  3. 轨迹线：预先绘制好所有虚线轨迹，初始 `opacity: 0`，在对应步骤中与克隆体同步淡入。
  4. 颜色过渡：使用 GSAP 的 `stroke` 属性动画，实现线段从黑色平滑过渡到高亮颜色。
- ID 命名规范：所有元素 ID 必须以 `scene1-` 为前缀，如 `scene1-poly`, `scene1-line-a`, `scene1-btn-next`。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
