[图示主题与整合说明]
- 本图示主题：地砖面积计算与总面积守恒法
- 整合的步骤/概念：展示两种地砖的单块面积计算，以及通过“总面积不变”来求解的过程。
- 教学价值：教师可以通过分步展示，清晰地向学生解释如何先求出总面积，再利用总面积不变的原理求出新地砖的数量，帮助学生建立面积守恒的几何直观。

[分步序列]
- 初始状态（步骤0）：显示 3dm地砖、2dm地砖、各自的边长标签、健身房矩形及其标签。所有公式和网格隐藏。
- 步骤1：点击「下一步」→ 3dm地砖高亮（填充 #1565c0, 20%），显示 3dm面积公式。健身房内出现 3dm网格，下方显示总面积公式。
- 步骤2：点击「下一步」→ 2dm地砖高亮（填充 #2e7d32, 20%），显示 2dm面积公式。
- 步骤3：点击「下一步」→ 健身房内的 3dm网格切换为更密集的 2dm网格，下方显示最终计算公式。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：底部居中放置两个按钮，"上一步" 和 "下一步"，用于控制步骤 0 到 3 的切换。
- 教师操作流程：教师首先介绍题目中的两种地砖和健身房。点击"下一步"讲解3dm地砖的面积和健身房总面积的计算；再次点击"下一步"讲解2dm地砖的面积；最后点击"下一步"展示通过总面积除以单块面积得出所需2dm地砖的数量。

[技术实现]
- JS 库选择及原因：原生 SVG 即可满足所有几何图形、网格和文本的绘制，无需引入外部库，性能最佳。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +---------------------------------------------------+
  |                                 健身房            |
  |   +----+                      +---------------+   |
  |   |    |                      |               |   |
  |3dm|    | 3×3=9 dm²            |               |   |
  |   +----+                      |               |   |
  |                               |               |   |
  |                               |               |   |
  |    +--+                       +---------------+   |
  | 2dm|  | 2×2=4 dm²                                 |
  |    +--+                  总面积 = 9 × 400 = 3600 dm²|
  |                          所需块数 = 3600 ÷ 4 = 900 块|
  |                                                   |
  |             [◀上一步] [下一步▶]                   |
  +---------------------------------------------------+
  ```
- 关键实现要点：
  - 使用 `<pattern>` 元素定义两种网格，通过修改健身房矩形的 `fill` 属性来切换网格显示。
  - 维护一个 `currentStep` 变量（0-3），在按钮点击时更新，并调用 `updateScene()` 函数。
  - `updateScene()` 函数根据 `currentStep` 控制各个元素的 `opacity` 或 `display` 属性，实现平滑的过渡效果（可配合 CSS `transition: opacity 0.3s`）。
  - ID 命名规范：所有元素 ID 以 `scene1-` 开头，例如 `scene1-tile-3dm`, `scene1-grid-pattern-3dm`。
  - IIFE 隔离：所有逻辑封装在 `(function() { ... })()` 中。
