[图示主题与整合说明]
- 本图示主题：平行线间不同图形的面积计算与比较
- 整合的步骤/概念：提取公共高、读取各图形底边长度、应用面积公式计算、面积大小比较
- 教学价值：教师可以通过分步导航，引导学生先观察图形的共同点（等高），然后逐一分析每个图形的底边长度并计算面积，最后进行直观比较，帮助学生深刻理解面积公式的应用及等高图形面积的决定因素。

[技术实现]
- JS 库选择及原因：原生 SVG 用于绘制几何图形、线条和尺寸标注，易于控制样式和动画；MathJax 用于渲染数学公式；原生 JS 控制状态机和 DOM 元素的 opacity 切换。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800x470]
    (y=95)  上刻度标签
    (y=120) 上平行线
    (y=120~320) 图形区域 & 高h
    (y=320) 下平行线
    (y=350) 下刻度标签
    (y=370) 尺寸标注线
    (y=420) 面积公式
    (y=450) 结论文本
  [控件栏 y=470-500]
    [上一步] [下一步]
  ```
- 关键实现要点：
  - 使用 `step` 变量记录当前状态 (0-5)。
  - 每次状态改变时，调用 `updateState()` 函数，根据 `step` 值批量设置各元素的 `opacity`、`stroke`、`fill` 等属性。
  - 尺寸标注线可通过 `<g>` 组合 `<line>` 和 `<text>`，整体控制透明度。
  - MathJax 公式在页面加载时自动渲染，通过外层 `<div>` 的 `opacity` 控制显隐，避免渲染时的闪烁。
  - ID 命名规范：所有元素 ID 必须以 `scene1-` 为前缀（如 `scene1-fig1`, `scene1-s1`）。
  - IIFE 隔离：所有 JS 代码包裹在 `(function() { ... })()` 中。
