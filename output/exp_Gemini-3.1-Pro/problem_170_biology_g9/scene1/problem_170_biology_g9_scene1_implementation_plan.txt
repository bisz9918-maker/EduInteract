[视觉元素清单]
- 题目原图（左侧）：1个大圆包含3个小圆，线条#000000 2px，默认填充#f5f5f5（透明度30%）。
- 动态解析图（右侧）：根据步骤显示A/B/C/D对应的韦恩图，线条#000000 2px。
- 颜色/样式：
  - 蓝高亮：#1565c0（透明度20%填充），用于步骤0左侧原图逻辑强调。
  - 错误高亮：#c62828（透明度20%填充），用于A/B/C选项图形填充。
  - 正确高亮：#2e7d32（透明度20%填充），用于D选项图形填充。
  - 文本标签：字体大小14px-16px，居中对齐（text-anchor="middle"），颜色#333333。

[分步序列]
- 初始状态（步骤0）：左侧显示题目原图，所有圆填充蓝色高亮（#1565c0, 20%），下方显示文本“逻辑：Ⅰ包含Ⅱ、Ⅲ、Ⅳ，且Ⅱ、Ⅲ、Ⅳ并列”。右侧空白，提示“请点击「下一步」逐一解析选项”。
- 步骤1（解析A）：左侧恢复默认灰色填充。右侧出现A选项图形（四个分离的圆），填充红色高亮（#c62828, 20%），下方显示文本“A选项：纯并列关系，无包含”。
- 步骤2（解析B）：右侧切换为B选项图形（四个同心圆），填充红色高亮，下方显示文本“B选项：层级包含关系”。
- 步骤3（解析C）：右侧切换为C选项图形（大圆含两中圆，一中圆含一小圆），填充红色高亮，下方显示文本“C选项：内部存在嵌套，非纯并列”。
- 步骤4（解析D）：右侧切换为D选项图形（大圆含三个分离小圆），填充绿色高亮（#2e7d32, 20%），下方显示文本“D选项：完全符合原图逻辑”。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：在SVG内部底部（y=450~490）居中放置两个按钮，控制步骤0-4的切换。
- 教师操作流程：教师首先停留在步骤0，讲解原图的逻辑关系；然后依次点击“下一步”，逐个展示A、B、C选项的韦恩图，指出其与原图逻辑不符之处（标红）；最后展示D选项，验证其完全匹配（标绿）。

[技术实现]
- JS 库选择及原因：原生 SVG。图形均为标准圆形和文本，原生 SVG 易于实现且性能极佳，方便通过 DOM 操作切换显示状态。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  |      左侧 (x:0-350)      |       右侧 (x:350-800)       |
  |       题目原图           |         选项解析韦恩图       |
  |       逻辑结论           |         匹配结果结论         |
  [控件栏 (y:450-490) ◀上一步  下一步▶]
  ```
- 关键实现要点：
  - 使用 `<g>` 标签将左侧原图、右侧A/B/C/D图分别编组。
  - 状态机设计：定义 `currentStep` (0-4)，每次切换时更新各组的 `display` 属性或 `opacity`。
  - 颜色切换：步骤0时，左侧原图的 `<circle>` 填充色设为蓝色高亮；步骤1-4时，恢复为默认灰色。
  - 动画过渡：可为 `<g>` 标签添加 CSS `transition: opacity 0.3s ease` 实现平滑切换。
  - ID 命名规范：所有元素 ID 均以 `scene1-` 开头（如 `scene1-group-left`, `scene1-group-a`, `scene1-btn-next`）。
  - IIFE 隔离：所有 JS 逻辑封装在 `(function() { ... })()` 中。
