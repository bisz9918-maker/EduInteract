[分步序列]
- 初始状态（步骤0）：显示完整的神经元A、B、C轮廓（无填充），显示电流计、导线、所有基础标签（a,b,c,d,A,B,C）和突触小泡。底部提示：“观察突触结构图，判断各选项的正误。”
- 步骤1：点击「下一步」→ 神经元A、B、C分别填充蓝、绿、红色（20%透明度）。底部提示：“图示包含3个神经元：神经元A、神经元B、神经元C。”
- 步骤2：点击「下一步」→ 保持神经元高亮，出现突触1框及标签、突触2框及标签。底部提示：“图示包含2个突触：A与B形成突触1，B与C形成突触2。因此说法①错误。”
- 步骤3（最终步骤）：点击「下一步」→ 主图组（神经元及小泡）以(400,250)为中心放大1.5倍；同时隐藏电流计、导线、a/b/c/d标签及突触框；突触小泡变为橙色(#ff9800)并略微放大；出现“突触小泡”标签及指向线。底部提示：“放大观察：A、B末端膨大且含有突触小泡，为轴突末梢；C为细胞体或树突。因此说法⑤正确。”

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：底部居中放置文本提示区（高度约40px），其下方放置“上一步”和“下一步”按钮。
- 教师操作流程：教师首先展示原图让学生观察；点击下一步，通过颜色区分让学生清晰看到3个神经元；再次点击，框选出2个突触，打破学生“3个神经元必有3个突触”的思维定势；最后点击放大突触部位，引导学生通过突触小泡的位置来判断轴突和树突。

[技术实现]
- JS 库选择及原因：原生 SVG。图形为不规则生物结构，使用 SVG Path 绘制最为精确且易于实现缩放动画。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×440]
    (电流计在顶部)
    (神经元B居中，A在左下，C在右侧)
  [提示文本区 800×30]
  [控件栏 800×30 (上一步/下一步按钮)]
  ```
- 关键实现要点：
  1. **SVG Path 绘制**：使用平滑曲线(C/Q)精确勾勒神经元轮廓。
     - B: `M 150 210 L 330 210 C 350 170, 390 160, 420 180 C 450 200, 450 260, 420 280 C 390 300, 350 290, 330 250 L 150 250 Z`
     - C: `M 460 150 C 430 190, 430 270, 460 310 C 480 320, 500 280, 550 260 L 700 260 L 700 220 L 550 220 C 500 200, 480 140, 460 150 Z`
     - A: `M 150 380 L 280 310 C 290 280, 320 270, 340 280 C 360 290, 360 320, 340 330 C 320 340, 290 350, 270 350 L 150 420 Z`
  2. **状态机设计**：定义 `currentStep` (0-3)，每次点击按钮更新状态并调用 `updateView()`。
  3. **CSS 动画**：
     - 神经元填充使用 `transition: fill 0.5s, fill-opacity 0.5s;`
     - 步骤3的放大效果通过给包裹神经元的 `<g id="scene1-zoom-group">` 添加 class 实现：`.zoomed { transform: scale(1.5); transform-origin: 400px 250px; }`，并配合 `transition: transform 0.8s ease;`。
     - 元素的显隐使用 `opacity` 配合 `transition` 实现淡入淡出，避免突兀。
- ID 命名规范：所有元素 ID 必须以 `scene1-` 为前缀（如 `scene1-neuron-a`, `scene1-btn-next`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
