[图示主题与整合说明]
- 本图示主题：演示刺激不同位点时兴奋的传导方向及电流计指针的偏转情况
- 整合的步骤/概念：整合了刺激b点和c点时的电位变化过程，直观展示兴奋在神经纤维上的双向传导与在突触间的单向传递特性。
- 教学价值：教师可通过切换不同刺激点，引导学生观察兴奋传导路径与电流计指针偏转次数的关系，从而深刻理解突触单向传递的原理及实验现象，有效破解题目中的难点（判断说法②）。

[分步序列]
- 状态1：静息状态
  - 显示所有静态元素（神经元、导线、电流计、标签、刺激箭头）。
  - 电流计指针竖直指向0刻度。
  - 隐藏所有动态元素（闪电、兴奋波、阻断标记）。
- 状态2：刺激b点
  - t=0s：b点出现红色闪电。兴奋波从b点(330,250)向两侧传导。
  - t=1.3s：向左的兴奋波到达a点(200,250)，电流计指针向左偏转并回正。
  - t=0.7s~1.2s：向右的兴奋波到达突触前膜(400,250)，停顿模拟突触延搁，随后跨越突触到达C(410,250)。
  - t=3.1s：兴奋波在C上继续传导到达d点(600,250)，电流计指针向右偏转并回正。
  - 结论：指针偏转2次。
- 状态3：刺激c点
  - t=0s：c点出现红色闪电。兴奋波从c点(450,250)向两侧传导。
  - t=1.5s：向右的兴奋波到达d点(600,250)，电流计指针向右偏转并回正。
  - t=0.4s：向左的兴奋波到达突触后膜(410,250)并停止，突触间隙(405,250)出现红色阻断标记"X"。兴奋无法到达a点。
  - 结论：指针仅偏转1次。

[交互方案]
- 交互类型：多状态切换（3个按钮）
- 控件说明：
  - 按钮1 `scene2-btn-rest`：“静息状态”，点击后重置所有动画，指针归零。
  - 按钮2 `scene2-btn-stim-b`：“刺激b点”，点击后触发状态2的动画序列。
  - 按钮3 `scene2-btn-stim-c`：“刺激c点”，点击后触发状态3的动画序列。
- 教师操作流程：教师先展示静息状态，然后点击“刺激b点”让学生观察完整的双向传导和两次偏转；接着点击“刺激c点”，重点观察突触处的单向阻断现象和一次偏转，从而得出正确结论。

[技术实现]
- JS 库选择：原生 SVG + 原生 JS `requestAnimationFrame`。无需引入外部动画库，通过时间戳计算状态，轻量且性能好。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×440]
    (电流计在顶部居中，神经元在中间偏下)
  [控件栏 800×60]
    (包含三个按钮，水平居中)
  ```
- 关键实现要点：
  - 动画循环：使用 `requestAnimationFrame` 维护一个 `animationTime` 变量。每次点击刺激按钮时，重置 `startTime`。
  - 坐标计算：兴奋波的 `cx` 坐标根据 `animationTime` 和预设的速度（如 100px/s）线性计算。
  - 指针动画：使用 `Math.sin` 函数在特定时间窗口内计算旋转角度，实现平滑的偏转和回正效果（如 `angle = 30 * Math.sin(progress * Math.PI)`）。
  - 状态机：定义 `currentState` 变量（'rest', 'stim-b', 'stim-c'），在动画循环中根据状态执行不同的逻辑分支。
- ID 命名规范：所有元素 ID 均以 `scene2-` 开头（如 `scene2-pointer`, `scene2-wave-left`），确保无全局冲突。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
