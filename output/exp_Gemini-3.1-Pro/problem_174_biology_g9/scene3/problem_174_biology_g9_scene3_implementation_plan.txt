[图示主题与整合说明]
- 本图示主题：演示兴奋性与抑制性神经递质的作用机制及受体的本质
- 整合的步骤/概念：整合了说法③（抑制性递质的逻辑推理）和说法④（受体本质的微观展示）
- 教学价值：教师可通过分步动画，直观展示兴奋性递质如何传递兴奋，以及抑制性递质如何阻断兴奋传递，最后通过局部放大图揭示受体的微观结构（糖蛋白），帮助学生建立从宏观现象到微观机制的完整认知。

[视觉元素清单]
- 神经元A、B、C：使用 SVG Path 绘制，主线 #000000，默认填充 #ffffff，线宽 2px。
- 兴奋性神经递质：绿色圆形（#2e7d32），宏观半径 3px，微观半径 8px。
- 抑制性神经递质：蓝色方形（#1565c0），宏观边长 6px。
- 兴奋状态高亮：神经元路径的填充色变为红色（#c62828，透明度 0.3）。
- 突触后膜受体：黑色（#000000）Y型线条，线宽 3px。
- 放大辅助线：灰色（#888888）虚线，线宽 1.5px，stroke-dasharray="5,5"。
- 刺激图标：黑色箭头，带有“刺激”文字标签。

[分步序列]
- 初始状态（步骤0）：显示左侧宏观的神经元A、B、C及其标签。无刺激，无递质，无高亮。右侧微观图隐藏。
- 步骤1（刺激B）：点击「下一步」。
  - 出现指向B的刺激箭头。
  - 神经元B填充变为红色高亮（表示兴奋）。
  - B的突触小体释放绿色圆形递质，移动至B与C的间隙。
  - 递质到达后，神经元C填充变为红色高亮（表示兴奋传递）。
- 步骤2（同时刺激A和B）：点击「下一步」。
  - 隐藏步骤1的递质和高亮。
  - 出现指向A和B的刺激箭头。
  - 神经元A填充变为红色高亮。
  - A的突触小体释放蓝色方形递质（抑制性），移动至A与B的间隙。
  - 神经元B**不**变红（被抑制），B不释放递质，神经元C**不**变红。
- 步骤3（受体微观放大）：点击「下一步」。
  - 隐藏宏观图的刺激箭头、递质和高亮。
  - 出现灰色虚线，连接B-C突触间隙至右侧区域。
  - 右侧淡入显示微观的突触前膜、突触后膜及Y型受体。
  - 突触前膜释放绿色圆形递质，向下移动并精确嵌入Y型受体的凹槽中。
  - 显示“受体(糖蛋白)”标签及指引线。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：底部居中放置两个按钮，控制步骤 0 到 3 的切换。
- 教师操作流程：教师首先展示突触结构；点击下一步，演示正常兴奋传递过程；再次点击，演示抑制性递质的作用机制，引导学生推理说法③；最后点击，展示受体微观结构，讲解说法④的受体化学本质。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript。SVG 适合绘制不规则的神经元路径和微观结构，且便于通过 CSS/JS 控制填充色和位置动画，无需引入庞大的外部库。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  +-------------------+-------------------+
  |      B            |                   |
  |  ====(   )        |   [微观放大区]    |
  |          (   )====|                   |
  |      A   C        |                   |
  |   //(  )          |                   |
  +-------------------+-------------------+
  [控件栏 ◀上一步 | 下一步▶ (y=450-490)]
  ```
- 关键实现要点：
  - 状态机设计：定义 `currentStep` 变量（0-3），每次切换步骤时先重置所有动画和高亮状态，再根据当前步骤触发相应的入场动画。
  - 路径绘制：使用 `d` 属性精确绘制神经元轮廓，例如 B 的突触小体使用贝塞尔曲线 `C` 绘制膨大结构。
  - 动画实现：使用 CSS `transition` 实现高亮颜色的渐变；使用 Web Animations API (`element.animate()`) 或 CSS `@keyframes` 实现神经递质的平移运动。
  - ID 命名规范：所有元素 ID 必须以 `scene3-` 为前缀（如 `scene3-neuron-b`, `scene3-btn-next`）。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
