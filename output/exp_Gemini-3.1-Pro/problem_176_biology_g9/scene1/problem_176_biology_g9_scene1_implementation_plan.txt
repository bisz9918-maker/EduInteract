[图示主题与整合说明]
- 本图示主题：血管结扎后的形态变化与血液成分分析
- 整合的步骤/概念：通过模拟丝带扎紧上臂后的血管形态变化（膨胀与变扁），结合血流方向推断血管类型（动脉/静脉），并进一步对比体循环中动静脉的含氧量差异。
- 教学价值：教师可通过分步演示，引导学生从“观察现象（血管形变）”到“逻辑推理（血流方向 -> 血管定性 -> 含氧量分析）”，将抽象的生物学概念具象化，完美契合逐步引导的教学需求。

[视觉元素清单]
- 丝带：黑色粗线段（stroke-width: 4），贯穿左右血管。
- 血管：使用 SVG `<path>` 绘制，初始状态为等宽矩形，填充 `rgba(0,0,0,0.05)`，边框 `#000000`。
- 箭头：黑色线段加多边形箭头，指示血流方向。
- 编号标签：使用 Unicode 字符（①②③④），黑色，字号 20px。
- 动态标签：“静脉”、“动脉”、“含氧量低”、“含氧量高”，初始透明度为 0，按步骤淡入。
- 颜色/样式：
  - 动脉血（含氧高）高亮：`#c62828`（红色）
  - 静脉血（含氧低）高亮：`#1565c0`（蓝色）
  - 辅助说明文字：`#888888` 或 `#000000`

[分步序列]
- 初始状态（步骤0）：显示丝带、两条等宽的正常血管、血流箭头、编号①②③④及“丝带”标签。血管呈半透明灰色。
- 步骤1（分析静脉）：点击「下一步」。左侧血管发生形变（①处膨胀变宽，④处变扁变窄），模拟血液自下而上流动受阻。左侧箭头上方淡入显示“静脉”标签。
- 步骤2（分析动脉）：点击「下一步」。右侧血管发生形变（③处膨胀变宽，②处变扁变窄），模拟血液自上而下流动受阻。右侧血管上方淡入显示“动脉”标签。
- 步骤3（分析含氧量）：点击「下一步」。左侧静脉血管填充色平滑过渡为蓝色（`#1565c0`），下方淡入“含氧量低”标签；右侧动脉血管填充色平滑过渡为红色（`#c62828`），下方淡入“含氧量高”标签。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：在 SVG 内部底部（y=470 区域）居中放置两个按钮，用于控制步骤（0~3）的前进与后退。
- 教师操作流程：教师首先展示初始图，提问学生结扎后的现象；点击下一步展示静脉形变并讲解血流方向；再次点击展示动脉形变；最后点击展示含氧量对比，完成整个逻辑闭环。

[技术实现]
- JS 库选择及原因：使用原生 SVG + 原生 JavaScript。血管的形变可以通过直接修改 SVG `<path>` 的 `d` 属性配合 CSS `transition` 实现平滑过渡，无需引入外部重型库，性能最佳且代码精简。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```text
  [图示区 800×500]
    (300,30)静脉        (500,30)动脉
       ↑                  |
      | |                | |
  ④   | |            ③  ( ) 膨胀
  ----| |----------------| |---- 丝带
  ①   ( ) 膨胀       ②  | |
      | |                | |
       |                  ↓
  (300,390)含氧量低   (500,440)含氧量高
  
  [控件栏: ◀上一步  下一步▶] (y=470)
  ```
- 关键实现要点：
  1. **路径动画**：为保证 CSS `transition` 在 `d` 属性上生效，正常状态和结扎状态的路径必须具有相同数量和类型的指令节点。
     - 左侧正常：`M 290 100 L 290 220 L 290 230 L 290 240 L 290 360 L 310 360 L 310 240 L 310 230 L 310 220 L 310 100 Z`
     - 左侧结扎：`M 295 100 L 295 220 L 298 230 L 280 240 L 280 360 L 320 360 L 320 240 L 302 230 L 305 220 L 305 100 Z`
     - 右侧正常：`M 490 100 L 490 220 L 490 230 L 490 240 L 490 360 L 510 360 L 510 240 L 510 230 L 510 220 L 510 100 Z`
     - 右侧结扎：`M 480 100 L 480 220 L 498 230 L 495 240 L 495 360 L 505 360 L 505 240 L 502 230 L 520 220 L 520 100 Z`
  2. **状态机设计**：维护一个 `currentStep` 变量（0-3），每次点击按钮更新该变量，并调用 `updateState()` 函数统一更新所有元素的 DOM 属性和 CSS 类名。
  3. **ID 命名规范**：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-left-vessel`, `scene1-btn-next`），防止跨场景污染。
  4. **IIFE 隔离**：所有 JS 逻辑必须包裹在 `(function() { ... })()` 中执行。
