[图示主题与整合说明]
- 本图示主题：光照图综合解析
- 整合的步骤/概念：晨昏线判读、太阳高度计算、地方时推导、昼夜长短判断。
- 教学价值：通过分步交互，引导学生从复杂的二维光照图中逐步提取关键信息。利用高亮和动态标签，将抽象的空间几何关系（如晨昏线与经纬线的交点、太阳直射点位置）与具体的时间、昼夜长短计算公式对应起来，帮助教师清晰展示解题的逻辑推导链条。

[视觉元素清单]
- 地球基础网格：黑色 (#000000)，线宽 1px，纬线使用 stroke-dasharray="5,5"。
- 夜半球阴影：黑色 (#000000)，20% 透明度。路径为 `M 255 86.5 A 160 160 0 0 0 345 393.5 L 255 86.5 Z`。
- 晨昏线：初始黑色，步骤1高亮为红色 (#c62828)，线宽 3px。
- 太阳光线：初始黑色，步骤2高亮为橙色 (#f57f17)，线宽 2px，带箭头。
- 经线高亮：步骤3将中央经线和左侧30°W经线高亮为蓝色 (#1565c0)，线宽 3px。
- 南半球高亮：步骤4显示，绿色 (#2e7d32)，20% 透明度。路径为 `M 140 240 A 160 160 0 0 0 460 240 L 140 240 Z`。
- 动态标签：6:00, 12:00, 4:00, 经度差标注，随步骤出现，颜色与当前步骤的高亮色一致，后续步骤变为黑色。
- 信息面板：位于右侧的 HTML div，用于显示每步的推导公式和文字说明。

[分步序列]
- 初始状态（步骤0）：显示地球基础网格、夜半球阴影、晨昏线、太阳光线及基础点位标签（A, B, C, N, S, 73°41'N）。信息面板提示“请点击「下一步」开始解析光照图”。隐藏所有动态标签和高亮。
- 步骤1（晨昏线与A点）：
  - 视觉变化：晨昏线高亮变红；出现红色自转方向弧形箭头；A点右下方出现红色“6:00”标签。
  - 面板内容：说明左夜右昼，该线为晨线。A点位于赤道与晨线交点，地方时为6:00，太阳高度为0°。
- 步骤2（直射点与C点）：
  - 视觉变化：晨昏线恢复黑色，保留“6:00”标签（变黑）。太阳光线高亮变橙色；“73°41'N”标签加粗变橙；C点右下方出现橙色“12:00”标签。
  - 面板内容：晨昏线与73°41′N相切，推导直射点纬度为16°19′N。C点在平分昼半球的经线上，地方时为12:00，正午太阳高度为73°41′。
- 步骤3（B点昼长）：
  - 视觉变化：太阳光线恢复黑色，保留“12:00”标签（变黑）。左侧30°W经线和中央经线高亮变蓝；赤道下方出现蓝色经度差标注“30° (2小时)”；B点左下方出现蓝色“4:00”标签。
  - 面板内容：相邻经线经度差为30°。B点在A点以西30°，推导B点日出时间为4:00，计算昼长为16小时。
- 步骤4（A点夜长与南半球）：
  - 视觉变化：经线恢复黑色，保留“4:00”标签（变黑）。南半球区域出现绿色半透明高亮覆盖。
  - 面板内容：A点在赤道上，全年昼夜平分，夜长12小时。南半球阴影面积大于高亮(昼)面积，结论为南半球昼短夜长。

[交互方案]
- 交互类型：分步按钮导航。
- 控件说明：在 SVG 容器底部（y=450~490 区域）放置一个绝对定位的控制栏，包含「◀ 上一步」、「下一步 ▶」按钮，以及居中的步骤指示器（如“步骤 1 / 4”）。
- 教师操作流程：教师点击“下一步”逐步展示推导过程，图示会自动高亮相关几何元素并弹出对应的数值标签，右侧面板同步显示推导逻辑，方便教师结合图示进行讲解。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript。本图示主要由标准几何图形（圆、椭圆弧、直线、路径）构成，原生 SVG 配合 CSS 过渡动画即可完美实现，无需引入额外库。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```text
  [---------------------------------------------------------]
  [  [左侧 500x400: 地球光照图]      [右侧 240x320: 信息面板]  ]
  [                                                         ]
  [                                                         ]
  [  [底部 800x50: 控件栏 (上一步 / 步骤指示 / 下一步)]        ]
  [---------------------------------------------------------]
  ```
- 关键实现要点：
  - 状态机设计：定义一个 `currentStep` 变量（0-4），编写 `updateScene(step)` 函数。每次步骤切换时，根据 step 值更新各 SVG 元素的 `stroke`、`opacity`、`display` 属性，并更新右侧信息面板的 `innerHTML`。
  - 坐标计算：夜半球阴影和南半球高亮使用 SVG `<path>` 的 `A` (Arc) 指令精确绘制半圆区域。
  - 动画过渡：为 SVG 元素的 `stroke`、`opacity` 属性添加 CSS `transition: all 0.3s ease`，使高亮和元素的出现更加平滑。
  - ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-terminator`, `scene1-info-panel`），确保多场景整合时不发生冲突。
  - IIFE 隔离：所有 JavaScript 代码必须包裹在 `(function() { ... })()` 中。
