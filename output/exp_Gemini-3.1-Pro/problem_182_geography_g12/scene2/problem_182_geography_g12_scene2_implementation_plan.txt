[图示主题与整合说明]
- 本图示主题：地方时推算与夜半球范围绘制
- 整合的步骤/概念：两地地方时换算、飞行后时间计算、晨昏线定位、夜半球阴影绘制
- 教学价值：教师可以通过分步演示，清晰地向学生展示如何根据已知经线的地方时推算其他经线的地方时，以及如何根据特定时间点确定晨昏线和夜半球的范围，将抽象的时间计算与直观的经纬网图形结合。

[分步序列]
- 初始状态（步骤0）：显示经纬网底图、经纬度标签、回归线/极圈虚线、点A~E及其标签。隐藏所有高亮线、时间标签和阴影。
- 步骤1：点击「下一步」→ 高亮 0° 经线（蓝色），显示顶部标签 "12:00"；高亮 120°E 经线（蓝色），显示顶部标签 "12:00 + 8h = 20:00"。
- 步骤2：点击「下一步」→ 保持经线高亮，将 120°E 顶部标签更新为 "20:00 + 3h = 23:00"。
- 步骤3：点击「下一步」→ 清空步骤1和2的蓝色高亮和标签。高亮点 A，在 60°W 顶部显示绿色标签 "14:00"；用绿色虚线高亮 0° 经线并显示 "18:00 昏线"；用绿色虚线高亮 180°E 经线并显示 "6:00 晨线"。
- 步骤4：点击「下一步」→ 保持步骤3的显示，在 0° 到 180°E 之间（x=400 到 x=700）添加半透明黑色阴影，并在阴影中央显示 "夜半球"。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：在 SVG 底部 (y=460) 居中放置两个按钮，用于控制步骤 0 到 4 的切换。
- 教师操作流程：教师首先展示基础经纬网；点击下一步，讲解根据 0° 经线 12:00 推算 120°E 的时间；再次点击，讲解加上飞行时间后的到达时间；接着点击下一步，转换到第4问，根据 A 点 14:00 推算晨昏线位置；最后点击下一步，展示夜半球的范围。

[技术实现]
- JS 库选择及原因：原生 SVG。经纬网、线段、点和矩形阴影非常适合用 SVG 绘制，DOM 操作简单，易于实现状态切换和样式控制。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
    (y=55)  时间标签区
    (y=85)  经度标签区
    (x=100~700, y=100~400) 经纬网主图区
  [控件栏]
    (y=460) ◀上一步  下一步▶
  ```
- 关键实现要点：
  - 使用 `<g>` 标签对不同步骤的元素进行分组，通过控制 `display` 属性或 `opacity` 来实现步骤切换。
  - 维护一个 `currentStep` 变量（0-4），每次点击按钮更新该变量，并调用 `updateState()` 函数更新各组的可见性。
  - 按钮状态控制：在步骤 0 时禁用“上一步”，在步骤 4 时禁用“下一步”。
  - ID 命名规范：所有元素 ID 以 `scene2-` 开头，例如 `scene2-step1-group`, `scene2-btn-next`。
  - IIFE 隔离：所有逻辑封装在 `(function() { ... })()` 中。
