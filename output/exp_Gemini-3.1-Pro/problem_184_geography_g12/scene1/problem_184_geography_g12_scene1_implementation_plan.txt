[图示主题与整合说明]
- 本图示主题：地球公转与两分两至节气判断
- 整合的步骤/概念：整合了题目左图的公转轨道、地轴倾斜方向、太阳位置，以及A、B、C、D四个位置的节气判断。通过动态高亮和光线辅助，帮助学生理解太阳直射点变化与节气的关系。
- 教学价值：教师可通过分步按钮，按时间顺序（冬至→春分→夏至→秋分）逐步演示地球在公转轨道上的位置，结合地轴倾斜和太阳直射光线，引导学生推断各位置的节气，理清公转过程。

[视觉元素清单]
- 公转轨道：黑色实线椭圆，无填充。
- 太阳：红色（#c62828）圆形填充，四周带放射状光芒线条。
- 地球（A/B/C/D）：蓝色（#1565c0）圆形轮廓，内部填充透明度20%的蓝色。
- 地轴：灰色（#888888）虚线，倾斜角约23.5°（向右倾斜）。
- 赤道：蓝色（#1565c0）实线，与地轴垂直。
- 公转方向箭头：黑色，分布在椭圆轨道的四个象限，指示逆时针方向。
- 文本标签：黑色，字体大小16px。
- 高亮状态：当前步骤的地球轮廓加粗并变为绿色（#2e7d32），填充绿色（透明度20%）。
- 太阳直射光线：红色（#c62828）实线加箭头。

[分步序列]
- 初始状态（步骤0）：展示完整的公转轨道、太阳、四个地球（含地轴、赤道）、公转方向箭头及基础标签（A/B/C/D/太阳）。无高亮，无节气标签。
- 步骤1（冬至日）：
  - 视觉变化：地球D高亮（绿色）。
  - 新增元素：从太阳(545,230)向地球D(655,230)发射3条红色平行光线。
  - 新增标签：在地球D下方(680,280)显示绿色文本“冬至 (12月22日前后)”。
- 步骤2（春分日）：
  - 视觉变化：地球A高亮（绿色），地球D恢复原样，光线消失。
  - 新增标签：在地球A上方(400,35)显示绿色文本“春分 (3月21日前后)”。
- 步骤3（夏至日）：
  - 视觉变化：地球B高亮（绿色），地球A恢复原样。
  - 新增元素：从太阳(495,230)向地球B(145,230)发射3条红色平行光线。
  - 新增标签：在地球B下方(120,280)显示绿色文本“夏至 (6月22日前后)”。
- 步骤4（秋分日）：
  - 视觉变化：地球C高亮（绿色），地球B恢复原样，光线消失。
  - 新增标签：在地球C下方(400,430)显示绿色文本“秋分 (9月23日前后)”。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：底部居中放置两个按钮“◀ 上一步”和“下一步 ▶”，以及步骤指示器（如“1 / 4”）。
- 教师操作流程：教师点击“下一步”依次展示冬至、春分、夏至、秋分的位置，结合光线直射半球（北半球或南半球）和公转方向，引导学生推断节气。可随时点击“上一步”回退对比。

[技术实现]
- JS 库选择及原因：原生 SVG。图形均为标准几何图形（椭圆、圆、线段），SVG 易于实现精确的坐标控制、DOM 节点操作和样式切换。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×450]
    (A)
  (B)  (Sun)  (D)
    (C)
  [控件栏 800×50 (y=450~500)]
    [◀上一步] [状态指示] [下一步▶]
  ```
- 关键实现要点：
  - 使用 `<ellipse>` 绘制轨道。
  - 使用 `<g>` 标签对每个地球进行分组，组内包含 `<circle>`(轮廓/填充)、`<line>`(地轴/赤道)、`<text>`(标签)。
  - 地轴倾斜计算：倾斜角23.5°，dx = r * sin(23.5°)，dy = r * cos(23.5°)。
  - 状态机设计：定义 `currentStep` (0~4)，每次步骤切换时，先重置所有地球样式并隐藏所有动态元素（光线、节气标签），然后根据 `currentStep` 显示对应的高亮和元素。
  - ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-earth-a`, `scene1-btn-next`）。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
