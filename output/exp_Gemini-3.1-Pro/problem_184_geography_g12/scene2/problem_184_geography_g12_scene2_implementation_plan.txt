[图示主题与整合说明]
- 本图示主题：北极俯视日照图的综合判读

[分步序列]
- 初始状态（步骤0）：显示基础经纬网、晨昏线、夜半球、太阳光线、自转箭头、点E/F/G及基础标签。
- 步骤1（判读节气）：高亮逆时针自转箭头（变红加粗），北极圈内填充半透明黄色显示极昼。右上角出现结论标签“极昼现象 → 夏至日 (6月22日)”。
- 步骤2（直射点与时间）：高亮中间的太阳光线和180°经线（变红加粗）。180°处出现“直射点”和“12:00”标签。绘制从180°向顺时针方向（西）60°的红色虚线（120°E，终点490,396），并用红色弧形箭头连接，标注“-4小时”。120°E末端出现标签“120°E (北京时间 8:00)”。
- 步骤3（太阳高度与昼夜）：高亮北回归线（变红加粗）。在直射点(520,240)处向左右两侧延伸绿色箭头，标注“正午太阳高度向南北递减”。在(447,350)处标记蓝点“佛山”，并标注“佛山 (昼长夜短)”。
- 步骤4（线速度比较）：取消步骤3的高亮。用蓝色粗线同时高亮赤道、北回归线、北极圈。在右上方沿-30°方向分别标注“大(565,145)”、“中(510,175)”、“小(460,205)”。左下角出现结论标签“自转线速度：G > E > F”。

[标签冲突检查]
- "0°" (190, 245) vs 自转箭头 (x≈202)：0°在箭头左侧，无冲突。
- "180°" (540, 255) vs "12:00" (540, 230)：分别在180°经线上下方，间距25px，无冲突。
- "G" (590, 235) vs "直射点" (590, 260)：分别在180°经线上下方，无冲突。
- "E" (410, 115) vs 北回归线：标签在点右侧，不遮挡线条。
- "F" (410, 175) vs 北极圈：标签在点右侧，不遮挡线条。
- "佛山" (435, 365) vs 120°E辅助线 (x≈465)：标签设为右对齐（text-anchor="end"），向左延伸，避开右侧的辅助线，无冲突。
- 结论标签均放置在画布边缘空白区（右上角、左下角），无冲突。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：底部居中放置两个按钮，控制步骤0-4的切换。
- 教师操作流程：教师点击“下一步”逐步展示解题逻辑，先判读节气，再计算时间，接着分析太阳高度，最后比较线速度。可随时点击“上一步”回退。

[技术实现]
- JS 库选择及原因：原生 SVG。日照图由标准的圆、线段和椭圆弧构成，SVG 能够精确控制坐标和层级，非常适合此类几何图形的绘制和动态高亮。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  [控件栏（上一步 / 下一步），位于 y=450~490 区域]
  ```
- 关键实现要点：
  - 使用 `<path>` 的 `A` 指令绘制晨昏线（`M 400 60 A 60 180 0 0 0 400 420`）和夜半球阴影（`M 400 60 A 60 180 0 0 0 400 420 A 180 180 0 0 1 400 60 Z`）。
  - 状态机设计：定义 `currentStep` 变量，每次点击按钮更新变量并调用 `updateState()` 函数。
  - `updateState()` 中通过修改 SVG 元素的 `display` 或 `opacity` 属性来控制各步骤元素的显隐。
  - ID 命名规范：所有元素 ID 以 `scene2-` 为前缀（如 `scene2-btn-next`, `scene2-terminator`）。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
