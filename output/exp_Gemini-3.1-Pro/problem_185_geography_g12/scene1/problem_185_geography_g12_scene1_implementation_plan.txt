[图示主题与整合说明]
- 本图示主题：通过极地俯视图推导A、B经度及昼夜长短，确定直射点经度与日出时间
- 整合的步骤/概念：经度推算、昼夜弧长计算、直射点经度推导、日出时间计算
- 教学价值：教师可通过分步展示，引导学生从已知条件（15°夹角、30°N）逐步推导出隐藏的地理信息（经度、昼夜弧、时间），将复杂的空间几何关系转化为清晰的平面逻辑推导过程。

[分步序列]
- 初始状态（步骤0）：显示极地圆、十字经线、OA、OB、15°夹角及对应的基础标签（N, 45°E, 45°W, A, B, 15°）。
- 步骤1（经度推断）：点击「下一步」→ 出现逆时针自转箭头。左侧经线端点出现 `135°E`，底部经线端点出现 `135°W`。A点外侧出现 `120°E`，B点外侧出现 `30°W`。
- 步骤2（昼夜分布）：点击「下一步」→ 出现红色加粗的昼弧（A→底部→B）和蓝色加粗的夜弧（B→顶部→A）。圆内出现红字 `昼弧 210°` 和蓝字 `夜弧 150°`。
- 步骤3（直射点与时间）：点击「下一步」→ 顶部经线半轴（中心至45°E）变为蓝色加粗，外侧出现蓝字 `0:00`；底部经线半轴（中心至135°W）变为红色加粗，外侧出现红字 `12:00`。
- 步骤4（日出时间）：点击「下一步」→ 底部空白区域依次淡入计算公式：`夜长 = (150° / 360°) × 24h = 10小时` 和 `日出时间 = 0:00 + (10h / 2) = 5:00`。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：在 SVG 底部 (y=470 区域) 放置两个按钮，控制 `currentStep` (0~4)。
- 教师操作流程：教师首先展示基础图，引导学生观察已知条件；点击下一步，演示自转方向并推导经度；再次点击，划分昼夜弧并计算弧长；接着点击，找出昼夜弧中点确定时间和直射点；最后点击，展示日出时间的计算过程。

[技术实现]
- JS 库选择及原因：原生 SVG。该场景主要由标准几何图形（圆、线段、圆弧）和文本组成，SVG 的 `<path>` 标签非常适合绘制精确的昼夜圆弧，且原生实现轻量高效。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```text
  [图示区 800×470]
       0:00
       45°E
        |
  A ----+---- B
        |
      135°W
      12:00
  (公式计算区)
  [控件栏 800×30]
  ```
- 关键实现要点：
  - 使用 SVG `<path>` 的 `A` (Arc) 指令绘制昼夜弧。昼弧路径：`M 255 171 A 150 150 0 1 0 545 171`；夜弧路径：`M 545 171 A 150 150 0 0 0 255 171`。
  - 状态机设计：定义 `updateStep(step)` 函数，通过修改对应 SVG 元素的 `opacity` 或 `display` 属性来实现元素的显隐。可以为不同步骤的元素添加对应的 class（如 `step1-elem`, `step2-elem`），在 JS 中统一控制。
  - ID 命名规范：所有元素 ID 以 `scene1-` 开头，如 `scene1-btn-prev`, `scene1-day-arc`。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
