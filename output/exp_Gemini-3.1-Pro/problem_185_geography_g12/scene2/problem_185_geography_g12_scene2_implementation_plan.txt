[图示主题与整合说明]
- 本图示主题：通过晨昏线与纬线相切推导太阳直射点纬度
- 整合的步骤/概念：将抽象的“晨昏线与70°N相切”条件转化为直观的侧视几何关系，通过分步添加晨昏线、极昼区和垂直的太阳光线，展示直射点纬度与相切纬度的互余关系。
- 教学价值：教师可通过分步演示，引导学生观察相切点、晨昏线倾角与太阳直射光线的几何垂直关系，从而直观理解“直射点纬度 = 90° - 相切纬度”的计算原理。

[分步序列]
- 初始状态（步骤0）：显示地球侧视图基础线条（地球轮廓、地轴、赤道、30°N、70°N）及对应标签。
- 步骤1：点击「下一步」→ 显示晨昏线（与70°N左端点相交并过地心）、极昼区域（70°N以北弓形填充）。左下角出现文本：“晨昏线与70°N纬线圈相切”及“⇒ 极昼范围为 70°N ~ 90°N”。
- 步骤2：点击「下一步」→ 显示三条平行的太阳光线（垂直于晨昏线射入）、直角符号、直射点（光线与地球表面交点）及“20°N”标签。左下角追加文本：“⇒ 直射点纬度 = 90° - 70° = 20°”及“直射点在北半球 (20°N)”。

[交互方案]
- 交互类型：分步按钮导航。
- 控件说明：在 SVG 底部（y=460~490）居中放置两个按钮：“◀ 上一步” 和 “下一步 ▶”。
- 教师操作流程：教师首先展示地球基础纬线，提问相切的含义；点击下一步，展示晨昏线和极昼区，讲解相切的几何表现；再次点击下一步，引入太阳光线，利用直角关系推导出直射点纬度。

[技术实现]
- JS 库选择：原生 SVG + 原生 JS。SVG 非常适合精确的几何绘图和箭头标记。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  +------------------------------------------------+
  |                                                |
  |         (晨昏线)      N                        |
  |             \        |                         |
  |              \   (极昼区)                      |
  |      70°N ----\------|---------                |
  |                \     |                         |
  |                 \    |                         |
  |      30°N -------\---|------------   (20°N)    |
  |                   \  |             /           |
  |                    \ |           /             |
  |      赤道 ----------\|---------*--<--- 太阳光  |
  |                      \       /                 |
  |                       \    /                   |
  |                        \ /                     |
  |  (计算过程文本)          \                      |
  |                          |                     |
  |                          S                     |
  |                                                |
  |             [◀ 上一步] [下一步 ▶]              |
  +------------------------------------------------+
  ```
- 关键实现要点：
  - 使用 `<g>` 标签和 CSS class (`step1`, `step2`) 控制元素的显示与隐藏，通过 `opacity` 和 `transition` 实现平滑过渡。
  - 太阳光线的箭头使用 `<marker>` 定义，并通过 `marker-mid` 属性附加到由三点构成的折线路径上（例如 `M 650 159 L 580 184.5 L 400 250`），确保箭头位于光线中段且方向正确。
  - 极昼区使用 SVG `path` 的 `A` (Arc) 指令绘制弓形：`M 348.7 109.1 A 150 150 0 0 1 451.3 109.1 Z`。
  - ID 命名规范：所有交互元素和 marker ID 必须以 `scene2-` 为前缀（如 `scene2-arrow-red`），避免跨场景冲突。
  - 脚本封装：所有 JS 逻辑放在 IIFE `(function() { ... })()` 中。
