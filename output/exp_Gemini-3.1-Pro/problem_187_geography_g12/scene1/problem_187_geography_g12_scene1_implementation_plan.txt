[图示主题与整合说明]
- 本图示主题：太阳能热水器倾角与正午太阳高度角的几何关系
- 整合的步骤/概念：热水器倾角定义、太阳光线垂直照射原理、正午太阳高度角互余关系、夏至日纬度推导公式。
- 教学价值：通过动态辅助线和直角三角形的高亮，将抽象的地理公式转化为直观的平面几何证明，帮助学生真正理解 α + H = 90° 的由来，从而轻松掌握纬度推导过程。

[视觉元素清单]
- 基础图形：地面（#000000，带 #888888 剖面阴影）、集热板（#000000，加粗）、支架（#000000）。
- 角度标注：倾角 α 和高度角 H 的弧线及文本（#1565c0 蓝高亮）。
- 太阳光线：三条平行带箭头的线段（#c62828 红高亮），以及垂直符号（#c62828）。
- 辅助线与面：光线延长线（#c62828 虚线），直角三角形填充（rgba(21, 101, 192, 0.1)）。
- 右侧文本：使用 HTML 渲染，重点公式使用 #c62828 和 #1565c0 高亮。

[分步序列]
- 初始状态（步骤0）：显示地面、集热板、支架、倾角 α 及其标签。右侧显示已知条件。
- 步骤1：点击「下一步」→ 出现三条太阳光线、垂直符号及光线标签。右侧追加显示“垂直照射”的文字说明。
- 步骤2：点击「下一步」→ 出现光线延长线、高度角 H 及其标签，同时高亮显示由光线、集热板和地面构成的直角三角形。右侧追加显示互余关系公式 α + H = 90°。
- 步骤3（最终步骤）：点击「下一步」→ 保持左侧图形不变，右侧追加显示夏至日正午太阳高度角公式，并推导出最终的纬度公式 φ = α + 23°26'。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：底部居中放置两个按钮，中间显示当前步骤指示器（如“步骤 1 / 4”）。
- 教师操作流程：教师首先介绍初始的集热板倾角，然后点击“下一步”引入太阳光线讲解垂直照射原理，再次点击“下一步”通过辅助线和高亮三角形直观证明角度互余关系，最后点击“下一步”结合公式推导出纬度。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 HTML/JS。几何图形简单，原生 SVG 即可完美实现高质量渲染和动画过渡；右侧公式推导使用原生 HTML 配合 CSS 样式，易于排版和高亮。
- 画布尺寸：800 × 500 px（左侧 SVG 占 480px 宽度，右侧 HTML div 占 300px 宽度，底部 50px 为控件栏）。
- 布局草图：
  ```
  [----------------- 800x500 -----------------]
  [      左侧 SVG 几何剖面图 (480x450)        ] [ 右侧 HTML ]
  [      (集热板、光线、辅助线、角度)         ] [ 公式推导区]
  [                                           ] [ (300x380) ]
  [-------------------------------------------]
  [         控件栏 (上一步 / 下一步)          ]
  [-------------------------------------------]
  ```
- 关键实现要点：
  - 使用 opacity 和 CSS transition 实现元素的平滑显隐。
  - 垂直符号的坐标计算：基于交点 (263.5, 300) 和方向向量精确计算折线的三个顶点。
  - 状态机设计：定义 currentStep 变量，在 updateScene() 函数中根据当前步骤统一控制 SVG 元素和右侧 HTML 文本块的 display 或 opacity 属性。
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀（如 scene1-ray1, scene1-step2-text）。
- IIFE 隔离：所有 JS 代码封装在 (function() { ... })() 中，避免全局变量污染。
