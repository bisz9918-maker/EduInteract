[分步序列]
- 初始状态（步骤0）：全局定位。地图处于默认缩放级别（k=1），显示完整的世界地图和①②③④四个定位点及其基础标签。
- 步骤1：点击「下一步」→ ①地特征。地图平滑缩放并平移至东亚区域（k=3），显示①地高亮色块，弹出“沪宁杭工业基地”标签及工厂图标。
- 步骤2：点击「下一步」→ ③地特征。地图平滑缩放并平移至西欧区域（k=3），显示③地高亮色块，出现红色的“北大西洋暖流”箭头及标签，弹出“北海渔场”标签及鱼图标。
- 最终步骤（步骤3）：点击「下一步」→ ④地特征。地图平滑缩放并平移至太平洋中部及北美西海岸（k=2.5），显示从④地指向北美西海岸的虚线，北美西海岸出现高亮色块，弹出“美国西海岸高新技术工业基地”标签及工厂图标。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - `scene3-btn-prev`：位于底部控件区左侧，点击回退到上一个区域状态。
  - `scene3-btn-next`：位于底部控件区右侧，点击进入下一个区域状态。
- 教师操作流程：教师首先展示全局分布，然后依次点击“下一步”，地图会自动飞到对应区域，配合弹出的标签讲解该地的工业或洋流特征。

[技术实现]
- JS 库选择及原因：使用 D3.js (v7) 和 TopoJSON Client (v3) 通过 CDN 引入。D3 提供了强大的地理投影（geoEquirectangular）和平滑缩放（d3.zoom）功能，非常适合实现地图的 Pan & Zoom 交互。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```text
  [图示区 800×500]
  +------------------------------------------------+
  |                                                |
  |   ③(西欧)       ②(中亚)     ①(东亚)    ④(太平洋)|
  |                                                |
  |                                                |
  |                                                |
  +------------------------------------------------+
  [控件栏 y=450~490，绝对定位，不占文档流]
  [ ◀ 上一步 ]                              [ 下一步 ▶ ]
  ```
- 关键实现要点：
  1. **投影设置**：使用 `d3.geoEquirectangular().rotate([-150, 0]).scale(127.32).translate([400, 250])`。将中心经度设为 150°E，确保①②③④及美国西海岸都在同一连续视野内，不会跨越地图边缘。
  2. **双层 SVG 架构**：
     - `mapGroup`：包含地图路径，受 `d3.zoom` 的 `transform` 影响，实现缩放和平移。
     - `overlayGroup`：包含所有点、高亮圈、连线和文本标签。**不直接受 transform 缩放**。
  3. **动态坐标计算**：在 `zoom.on("zoom")` 事件中，通过 `e.transform.apply([baseX, baseY])` 实时计算基础坐标在当前缩放下的屏幕像素坐标，并更新 `overlayGroup` 中元素的 `x/y` 属性。这彻底解决了缩放时文本变形、线宽改变和标签重叠的问题。
  4. **状态机动画**：定义 4 个状态的目标 `k, x, y`，切换状态时调用 `svg.transition().duration(1000).call(zoom.transform, d3.zoomIdentity.translate(...).scale(k))` 实现平滑的“飞行”效果，并通过透明度过渡显示/隐藏对应状态的标签。
- ID 命名规范：所有交互元素 ID 必须以 `scene3-` 为前缀（如 `scene3-svg`, `scene3-btn-next`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
