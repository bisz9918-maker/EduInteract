[图示主题与整合说明]
- 本图示主题：太阳直射点回归运动与地球光照联动演示
- 整合的步骤/概念：将抽象的太阳直射点回归运动轨迹（左图）与具象的地球光照侧视图（右图）无缝联动。通过时间滑块，展示直射点纬度变化如何导致晨昏线摆动、昼夜长短变化（以白城为例）以及极昼极夜范围的扩大与缩小。
- 教学价值：教师可通过拖拽滑块，平滑演示一年四季的连续变化过程，并在二分二至点（①②③④）停留，直观解释“直射点位置”、“晨昏线倾角”、“特定纬度昼夜比例”及“正午太阳高度分布”四者之间的几何物理联系，化解空间想象难题。

[视觉元素清单]
- 左侧坐标系：包含三条水平纬线（#888888虚线，赤道为实线），折线轨迹（#888888虚线），四个关键节点（黑色小圆点），以及一个表示当前直射点的红色大圆点（#c62828）。
- 右侧地球：黑色圆轮廓，内部包含5条关键纬线（#888888虚线，赤道实线）。
- 晨昏线与夜半球：晨昏线为黑色实线，夜半球为由晨昏线和左侧圆弧构成的封闭路径，填充 #1565c0 (opacity: 0.3)。
- 白城标记：位于 y=114 的水平线段，被晨昏线分割为两部分。左侧夜弧为深灰色（#555555），右侧昼弧为绿色加粗（#2e7d32），直观对比昼夜长短。
- 太阳光线：5条水平射线（#888888），其中中心光线（#c62828加粗）始终对准直射点。
- 极昼极夜标签：动态文本，当滑块靠近夏至/冬至时，在北极/南极上方显示“极昼”或“极夜”（#c62828）。
- 太阳高度箭头：两个与地球表面相切的红色箭头（#c62828），从直射点分别向正北、正南延伸，末端带有“递减”字样。

[分步序列]
本图示采用连续拖拽交互，核心状态如下：
- 初始状态（滑块=0，春分①）：直射点在左图(60,220)；右图晨昏线垂直，夜半球占据左半圆；白城昼夜弧等长；中心光线指向赤道。
- 状态A（滑块=90，夏至②）：直射点移至左图(120,120)；右图晨昏线顺时针倾斜23.5°；白城昼弧达到最长，夜弧最短；北极圈内全部在白昼区（显示“极昼”标签）；中心光线指向北回归线。
- 状态B（滑块=180，秋分③）：同初始状态，直射点在左图(180,220)。
- 状态C（滑块=270，冬至④）：直射点移至左图(240,320)；右图晨昏线逆时针倾斜23.5°；白城昼弧最短；北极圈内全部在黑夜区（显示“极夜”标签）；中心光线指向南回归线。
- 附加状态（开启“正午太阳高度”开关）：在右图直射点处出现两个红色切线箭头，分别向北和向南延伸，直观展示太阳高度角向南北两侧递减的规律，箭头随直射点上下移动而同步移动。

[交互方案]
- 交互类型：连续拖拽滑块 + 状态开关。
- 控件说明：
  1. 时间滑块（`scene1-time-slider`）：位于底部居中，范围 0-360，对应一年圆周角。下方带有“春分(①) - 夏至(②) - 秋分(③) - 冬至(④) - 春分(①)”的刻度提示。
  2. 太阳高度开关（`scene1-altitude-toggle`）：复选框，位于滑块右侧，控制是否显示正午太阳高度递减箭头。
- 教师操作流程：教师可缓慢拖动滑块，引导学生观察左图直射点纬度与右图晨昏线倾角的同步变化；在②和④处停留，重点讲解白城昼夜长短的极值及极区的极昼极夜现象；勾选开关，结合红色箭头讲解正午太阳高度的纬度分布规律。

[技术实现]
- JS 库选择：原生 SVG + Vanilla JS。SVG 的 DOM 结构非常适合几何图形的精确绘制和属性的实时更新。
- 画布尺寸：800 × 500 px（SVG 占 800×440，底部 60px 留给绝对定位的控件栏）。
- 布局草图：
  ```
  [左侧：回归运动折线图 320×440] | [右侧：地球光照侧视图 480×440]
  [控件栏：时间滑块 (0-360) | [ ] 显示正午太阳高度规律 ]
  ```
- 关键实现要点：
  1. 状态计算：设滑块值为 $	heta$ (0~360)。直射点纬度角 $\alpha = 23.5^\circ 	imes \sin(	heta 	imes \pi / 180)$。
  2. 左图动点：$cx = 60 + 	heta 	imes (240/360)$，$cy = 220 - 100 	imes \sin(	heta 	imes \pi / 180)$。
  3. 右图晨昏线：倾角即为 $\alpha$。晨昏线端点为 $(560 \mp 150\sin\alpha, 220 \mp 150\cos\alpha)$。
  4. 夜半球路径：使用 SVG Path 的 Arc 指令 `M x1 y1 A 150 150 0 0 0 x2 y2 Z`，利用 `sweep-flag=0` 完美绘制左半圆弧与晨昏线围成的动态封闭区域。
  5. 白城昼夜弧：计算 y=114 处晨昏线的交点 $x_t = 560 - 106 	imes 	an\alpha$。夜弧为 (454, 114) 到 $(x_t, 114)$，昼弧为 $(x_t, 114)$ 到 (666, 114)。
  6. 太阳高度箭头：起点为直射点 $(x_c, y_c)$，利用切线向量 $(-\sin\alpha, -\cos\alpha)$ 和 $(\sin\alpha, \cos\alpha)$ 计算箭头终点，确保箭头始终与地球表面相切。
- ID 命名规范：所有元素 ID 均以 `scene1-` 开头（如 `scene1-slider`, `scene1-terminator`）。
- 作用域隔离：所有 JS 逻辑封装在 `(function() { ... })()` 中，通过 `document.getElementById` 获取元素，绑定 `input` 和 `change` 事件实现实时渲染。
