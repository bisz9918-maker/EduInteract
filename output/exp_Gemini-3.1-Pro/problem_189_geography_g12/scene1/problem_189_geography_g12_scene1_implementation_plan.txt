[图示主题与整合说明]
- 本图示主题：太阳直射点移动轨迹与季节变化规律
- 整合的步骤/概念：将东西半球的经纬度判读、太阳直射点在南北回归线之间的移动轨迹、节气变化、极夜现象以及地球公转的远日点位置整合在一个动态交互图中。
- 教学价值：教师可通过分步演示，清晰地向学生展示直射点跨越东西半球的连续运动过程，帮助学生建立空间直观概念，理解直射点纬度变化与正午太阳高度、极昼极夜现象的内在联系。

[分步序列]
- 初始状态（步骤0）：显示东西半球基础线稿、赤道、回归线、极圈、经线网格，以及 A-F 的黑色小圆点（无标签）。
- 步骤1「半球与经纬度」：点击「下一步」→ 高亮显示关键经线（20°W, 70°E, 160°E, 110°W），并在对应位置淡入显示经度数值标签。
- 步骤2「直射点轨迹与节气」：点击「下一步」→ 动态绘制 F→E→D 和 C→B→A 的蓝色轨迹线及箭头，A-F 点变为红色高亮，淡入显示对应的节气标签（如“A(冬至)”）。
- 步骤3「直射点位置与地理现象」：点击「下一步」→ A 点放大闪烁，旁边出现“直射南回归线”提示；左下角淡入极夜示意小图；C、D 点放大闪烁，上方出现“直射北回归线”提示，并向南北两侧伸出绿色渐变箭头。
- 步骤4「公转特定位置」：点击「下一步」→ 隐藏步骤3的特有提示（极夜图、绿色箭头、直射提示文字），在 C 到 B 的轨迹上淡入显示“远日点”红色标记及“远日点(7月初)”标签。

[交互方案]
- 交互类型：分步按钮导航
- 控件说明：在 SVG 底部（Y=460 区域）居中放置两个按钮：“◀ 上一步” 和 “下一步 ▶”。
- 教师操作流程：教师首先展示基础经纬网，点击下一步引导学生判读关键经线；再次点击展示直射点移动轨迹与节气对应关系；接着点击展示特定节气（冬至、夏至）的地理现象（极夜、太阳高度变化）；最后点击展示远日点在轨迹上的具体位置。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript。SVG 非常适合绘制精确的几何图形、曲线和文本，且易于通过 CSS 控制动画和状态切换。
- 画布尺寸：800 × 500 px（固定尺寸）。
- 布局草图：
  ```
  [图示区 800×450]
    (极夜小图)   (东半球)   (西半球)
  [控件栏 800×50，包含上一步/下一步按钮]
  ```
- 关键实现要点：
  - 使用 `<clipPath>` 配合圆形路径来裁剪半球内部的纬线和经线，确保线条不会超出半球轮廓，代码更简洁精确。
  - 经线使用 `<ellipse>` 元素，通过设置不同的 `rx` (75, 130) 来模拟 30° 间隔的经线投影。
  - 轨迹线使用 SVG `<path>` 的二次贝塞尔曲线 (`Q` 和 `T` 指令) 绘制，确保 S 型曲线平滑穿过各个关键点。
  - 状态机设计：定义 `currentStep` 变量（0-4），每次点击按钮更新变量，并通过修改 SVG 根元素的 `class`（如 `step-1`, `step-2`）配合 CSS 预设的 `opacity` 和 `transition` 来实现元素的平滑显示/隐藏。
  - ID 命名规范：所有元素 ID 均以 `scene1-` 开头（如 `scene1-btn-next`, `scene1-path-east`），所有 JS 代码封装在 IIFE 中，防止全局变量污染。
