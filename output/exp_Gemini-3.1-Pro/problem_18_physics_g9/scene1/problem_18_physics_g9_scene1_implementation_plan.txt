[图示主题与整合说明]
- 本图示主题：系统受力分析与浮力计算
- 整合的步骤/概念：物体B的受力平衡、弹簧测力计读数、平衡力概念辨析、物体A的受力平衡及排开水体积的计算。
- 教学价值：教师可通过分步动画，引导学生逐步剖析复杂系统的受力情况，按照“先分析B -> 再看绳子 -> 最后分析A”的逻辑顺序，有效突破平衡力辨析和浮力计算的教学难点。

[分步序列]
- 初始状态（步骤0）：显示完整的物理装置。右侧显示基础已知条件：$m_A=3	ext{kg}, m_B=2	ext{kg}$。隐藏所有受力向量。
- 步骤1（分析物体B）：高亮物体B（边框加粗）。在B上出现向下的重力 $G_B$ 和向上的拉力 $T$ 向量。右侧浮现计算：$G_B = m_B g = 19.6	ext{N}$，因静止所以 $T = G_B = 19.6	ext{N}$。得出测力计示数为 $19.6	ext{N}$（验证选项A）。
- 步骤2（辨析平衡力）：保留 $G_B$，隐藏向上的 $T$，显示“B对绳子的拉力 $T'$”（方向向下）。右侧文字强调：这两个力作用在不同物体上，不是平衡力（验证选项D）。
- 步骤3（分析物体A状态）：恢复步骤1的拉力 $T$，隐藏 $T'$。取消B的高亮，高亮物体A。右侧显示文字：“静止状态 = 平衡状态”（验证选项C）。
- 步骤4（计算浮力与体积）：在物体A上出现向下的重力 $G_A$、向上的拉力 $T$ 和向上的浮力 $F_浮$。右侧浮现计算：$G_A = 29.4	ext{N}$，$F_浮 = G_A - T = 9.8	ext{N}$。接着展示体积推导：$V_排 = F_浮 / (ho_{水} g) = 1000	ext{cm}^3$（验证选项B）。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：在 SVG 容器底部（y=460区域）居中放置两个按钮。

[技术实现]
- JS 库选择及原因：原生 SVG 用于绘制物理装置和向量箭头，MathJax 用于渲染右侧的物理公式。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +-------------------+-------------------------+
  |                   |  已知: mA=3kg, mB=2kg   |
  |    / / / / / /    |                         |
  |       (O)         |  [动态推导公式区域]     |
  |      |   |        |  GB = mB * g = 19.6N    |
  |     [B]  |        |  ...                    |
  |          §        |                         |
  |     |   [A]   |   |                         |
  |     |~~~~~~~~~|   |                         |
  |     |_________|   |                         |
  +-------------------+-------------------------+
  [控件栏: ◀上一步  下一步▶]
  ```
- 关键实现要点：
  - 状态机设计：定义 `currentStep` 变量（0-4），编写 `updateScene()` 函数统一管理各步骤的 UI 状态。
  - SVG 元素控制：通过修改 SVG 元素的 `display` 或 `opacity` 属性来显示/隐藏向量箭头和高亮效果。
  - 动态公式渲染：右侧推导区域使用一个 `div` 容器（绝对定位在 SVG 上方右侧），在 `updateScene()` 中更新其 `innerHTML`，并调用 `MathJax.typesetPromise()` 重新渲染公式。
  - ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-btn-next`, `scene1-vector-gb`）。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
