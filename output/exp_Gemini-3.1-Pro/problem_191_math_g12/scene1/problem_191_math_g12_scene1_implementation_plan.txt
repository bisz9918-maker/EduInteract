  - 步骤4文本：$	riangle PCE$ 内角和 $= 180^\circ$
  - 步骤5文本：$x + (y + 40^\circ) + (x + y) = 180^\circ$ $\Rightarrow 2(x+y) = 140^\circ$ $\Rightarrow \angle PCE = 70^\circ$

[分步序列]
- 初始状态（步骤0）：显示圆O、所有线段、所有字母标签、$\angle AEB$ 及其 $40^\circ$ 标注。公式区为空。
- 步骤1（弦切角）：线段 PE 和 BE 加粗并变为蓝色 #1565c0。显示 $\angle PEB$ 和 $\angle EAB$ 的蓝色弧线及标签 $y$。右上角显示步骤1文本。
- 步骤2（角平分线）：线段 PE 和 BE 恢复默认。线段 PC 加粗并变为绿色 #2e7d32。显示 $\angle EPC$ 和 $\angle APC$ 的绿色弧线及标签 $x$。右上角追加步骤2文本。
- 步骤3（外角定理）：线段 PC 恢复默认。显示 $	riangle PCA$ 的黄色半透明填充。$\angle PCE$ 处显示红色弧线及标签 $x+y$。右上角追加步骤3文本。
- 步骤4（内角和定理）：隐藏 $	riangle PCA$ 填充，显示 $	riangle PCE$ 的黄色半透明填充。高亮 $	riangle PCE$ 的三个内角（$\angle EPC$ 绿色，$\angle PEC$ 包含蓝色y和黑色40°，$\angle PCE$ 红色）。右上角追加步骤4文本。
- 步骤5（得出结论）：保持步骤4的图形状态。右上角追加步骤5的最终计算过程和结果 $70^\circ$，结果文本加粗并标红。

[标签冲突检查]
- P(-20,-10) 与 x标签(+15,+40)/(+35,+25)：P在点左上，x在点下方/右下，间距 > 40px，无冲突。
- E(-20,+10) 与 40°(+30,-10) 与 y(+5,-30)：E在左下，40°在右侧，y在正上偏左。间距 > 25px，无冲突。
- A(+20,+5) 与 y(-40,-10)：A在右下，y在左上，间距 > 50px，无冲突。
- C(0,+25) 与 x+y(-23,-10)：C在正下，x+y在左上，间距 > 30px，无冲突。
- B(+20,-11) 与 D(+20,0)：B(310,131)，D(290,194)，两点Y坐标相差63px，标签均在右侧，不会重叠。无冲突。
- 结论：所有标签分布合理，无遮挡风险。

[交互方案]
- 交互类型：分步按钮导航
- 控件说明：在 SVG 内部底部 (y=460) 居中放置两个按钮「◀ 上一步」和「下一步 ▶」。
- 教师操作流程：教师点击“下一步”逐步展示几何推理过程，每点击一次，图形中高亮对应的角和线段，并在右上角显示对应的推理依据和公式，配合口头讲解。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript。几何图形简单，原生 SVG 的 `<path>` 和 `<polygon>` 足以实现，且易于控制样式和动画。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  +-------------------------------------------------+
  |  P                                 [推导公式区] |
  |   \ .                              1. ...       |
  |    \   .                           2. ...       |
  |     \     B                        3. ...       |
  |      \      .                                   |
  |       D        .                                |
  |        \          .                             |
  |         \            .                          |
  |          E------------C-------------A           |
  |                                                 |
  |             [◀ 上一步] [下一步 ▶]               |
  +-------------------------------------------------+
  ```
- 关键实现要点：
  - 坐标系：SVG 默认坐标系，原点在左上角。
  - 角度弧线绘制：使用 SVG `<path>` 的 `A` (elliptical arc) 指令。通过起点、终点坐标和半径计算路径。
  - 状态机：定义 `currentStep` 变量 (0-5)。编写 `updateScene()` 函数，根据 `currentStep` 控制各 SVG 元素的 `display`、`stroke`、`fill-opacity` 属性，以及公式区文本的显示。
  - ID 命名规范：所有元素 ID 必须以 `scene1-` 开头，例如 `scene1-btn-next`, `scene1-angle-y1`, `scene1-poly-pca`。
  - 隔离：所有逻辑封装在 `(function() { ... })()` 中。
