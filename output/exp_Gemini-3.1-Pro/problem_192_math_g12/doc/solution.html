（2）第n行第3个数（从左往右数）为$\underline{\hspace{5em}}$.

题目分析

本题考查归纳推理与数列的递推关系。观察“牛顿调和三角形”，我们需要将其转化为数学符号表示。设第 $n$ 行第 $k$ 个数为 $a_{n,k}$。

根据题意，我们可以提取出两个核心条件：

  1. 边界条件：每行两端的数均为 $

rac{1}{n}$，即 $a{n,1} = a{n,n} =
rac{1}{n}$。

  1. 递推关系：每个数是它下一行左右相邻两数的和，即 $a_{n,k} = a_{n+1,k} + a_{n+1,k+1}$。

整体讲解思路

  1. 首先引导学生观察图形，将文字描述的规则可视化，特别是将“每个数是它下一行左右相邻两数的和”转化为递推公式，并变形为“下一行的数 = 上一行的数 - 下一行相邻的数”，即 $a_{n+1,k+1} = a_{n,k} - a_{n+1,k}$。这是向下递推求解的关键。
  2. 利用变形后的递推公式，结合第一列的已知条件 $a_{n,1} =

rac{1}{n}$，推导第二列的通项公式，进而求出第6行第2个数。

  1. 继续利用递推公式，结合第二列的通项公式，推导第三列的通项公式，解答第二问。

教学说明：推导第2列与第3列的通项公式

在明确了递推关系 $a_{n,k} = a_{n-1,k-1} - a_{n,k-1}$ （即当前数 = 右上方的数 - 左侧的数）之后，我们可以逐列向右推导。

推导步骤：

  1. 求第2列的通项公式：已知第1列 $a_{n,1} =

rac{1}{n}$。对于第2列的数 $a{n,2}$，根据减法递推关系有 $a{n,2} = a{n-1,1} - a{n,1}$。代入第1列的公式得 $a_{n,2} =
rac{1}{n-1} -
rac{1}{n} =
rac{n - (n-1)}{n(n-1)} =
rac{1}{n(n-1)}$ （$n \ge 2$）。由此可得第6行第2个数 $a_{6,2} =
rac{1}{6 imes 5} =
rac{1}{30}$。

  1. 求第3列的通项公式：现在我们已知第2列 $a_{n,2} =

rac{1}{n(n-1)}$。对于第3列的数 $a{n,3}$，再次使用减法递推关系 $a{n,3} = a{n-1,2} - a{n,2}$。代入第2列的公式得 $a_{n,3} =
rac{1}{(n-1)(n-2)} -
rac{1}{n(n-1)}$。提取公因式 $
rac{1}{n-1}$，得到 $a_{n,3} =
rac{1}{n-1} \left(
rac{1}{n-2} -
rac{1}{n}
ight) =
rac{1}{n-1} \cdot
rac{n - (n-2)}{n(n-2)} =
rac{2}{n(n-1)(n-2)}$ （$n \ge 3$）。

第1列通项：
观察可知，第 $n$ 行第 1 个数为 $a_{n,1} = rac{1}{n}$
第2列推导：
由递推关系 $a_{n,k} = a_{n-1,k-1} - a_{n,k-1}$，得：
$a_{n,2} = a_{n-1,1} - a_{n,1} = rac{1}{n-1} - rac{1}{n} = rac{1}{n(n-1)}$
代入计算：
第 7 行第 2 个数为 $a_{7,2} = rac{1}{7 imes 6} = rac{1}{42}$
第3列推导：
同理，$a_{n,3} = a_{n-1,2} - a_{n,2} = rac{1}{(n-1)(n-2)} - rac{1}{n(n-1)}$
$= rac{n - (n-2)}{n(n-1)(n-2)} = rac{2}{n(n-1)(n-2)}$

总结

本题的解答关键在于：

  1. 符号化：将图形中的位置关系转化为二维数列的索引 $a_{n,k}$。
  2. 转化递推关系：将题目中“下生上”的加法关系（$a_{n,k} = a_{n+1,k} + a_{n+1,k+1}$），转化为更具操作性的“上减下”的减法关系（$a_{n,k} = a_{n-1,k-1} - a_{n,k-1}$），从而实现从已知的第一列向右逐列推进。
  3. 代数化简：在求相邻两项之差时，注意提取公因式，保证化简过程的准确性。

课堂讲解建议：

  • 引入时，可以让学生先自己算一算第6行的所有数字，体会手动计算的繁琐，从而引出寻找通项公式的必要性。
  • 在推导 $a_{n,2}$ 和 $a_{n,3}$ 时，强调“作差”的动作，这与数列中常见的裂项相消法有异曲同工之妙。
  • 拓展思考：可以引导学有余力的学生猜想第 $k$ 列的通项公式 $a_{n,k}$ 的一般形式。实际上，它与组合数有密切关系：$a_{n,k} =

rac{1}{k \cdot C_{n}^{k}}$。这展示了牛顿调和三角形与帕斯卡三角形（杨辉三角）之间深刻的内在联系。
