[图示主题与整合说明]
- 本图示主题：牛顿调和三角形的结构与递推规则
- 整合的步骤/概念：三角形数阵的整体布局、边界条件（两端为1/n）、加法递推规则（下两数之和等于上数）、减法递推规则（上数减左下数等于右下数，解题关键）。
- 教学价值：教师可通过分步演示，引导学生从观察整体数阵规律开始，逐步聚焦到边界特征，再深入剖析相邻三个数之间的加法关系，最后通过逆向思维推导出用于解题的减法递推公式，逻辑清晰，视觉焦点明确。

[分步序列]
- 初始状态（步骤0）：显示前5行分数构成的三角形数阵、左侧行号及虚线引导线。右侧留白。
- 步骤1：点击「下一步」→ 左右两端的9个分数（1/1, 1/2, 1/3, 1/4, 1/5）底部出现蓝色透明高亮框。右侧淡入边界公式 $a_{n,1} = a_{n,n} = rac{1}{n}$。
- 步骤2：点击「下一步」→ 蓝色高亮框消失。第3行左侧1/3、第4行左侧1/4和1/12底部出现红色透明高亮框。出现两条红色加法箭头（从1/4和1/12指向上方的1/3）和红色"+"号。右侧淡入加法公式 $a_{n,k} = a_{n+1,k} + a_{n+1,k+1}$ 及具体实例 $rac{1}{3} = rac{1}{4} + rac{1}{12}$。
- 步骤3：点击「下一步」→ 红色高亮框保留。加法箭头和"+"号消失，出现红色减法箭头（从1/3指向1/12，从1/4指向1/12）和红色"-"号。右侧淡入减法公式 $a_{n+1,k+1} = a_{n,k} - a_{n+1,k}$ 及具体实例 $rac{1}{12} = rac{1}{3} - rac{1}{4}$。

[标签冲突检查]
- 分数节点间距：同行相邻分数水平间距 80px，上下行相邻分数垂直间距 60px。分数包围盒约 40x40px，间距充足，无冲突。
- 行号引导线与分数：引导线终点 x 坐标距离最左侧分数中心至少 30px，分数半宽约 20px，无重叠。
- 箭头与分数：箭头起点和终点均设置在距离分数中心 15-20px 处，避免箭头刺穿分数文本。
- 运算符号与分数：加法"+"号位于 (300,260)，左右分数在 (260,260) 和 (340,260)，距离 40px，无冲突；减法"-"号位于 (280,230)，上下分数在 (300,200) 和 (260,260)，距离约 36px，无冲突。
- 公式与分数：右侧公式中心 x=650，最右侧分数中心 x=540，水平间距 110px，公式半宽约 75px，无重叠。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：底部居中放置“上一步”和“下一步”按钮。
- 教师操作流程：教师首先展示完整的数阵，让学生观察规律（步骤0）；点击下一步，引导学生发现边界全为1/n的规律（步骤1）；再次点击，聚焦局部三个数，讲解题目给定的加法生成规则（步骤2）；最后点击，引导学生进行逆向思维，推导出用于计算未知项的减法规则（步骤3）。

[技术实现]
- JS 库选择及原因：使用原生 SVG 绘制高亮框、引导线和箭头；使用 MathJax 渲染分数和公式（通过绝对定位的 HTML div 覆盖在 SVG 上），确保数学公式的专业排版。
- 画布尺寸：800 × 500 px，`position: relative`。
- 布局草图：
  ```
  [图示区 800×500]
  | 第1行 ---      1/1             | 公式区
  | 第2行 ---    1/2  1/2          | (边界公式)
  | 第3行 ---  1/3  1/6  1/3       | (加法公式)
  | 第4行 --- 1/4 1/12 1/12 1/4    | (减法公式)
  | 第5行 ---1/5 1/20 1/30 1/20 1/5|
  [控件栏（上一步 / 下一步）]
  ```
- 关键实现要点：
  - 状态机设计：定义 `currentStep` (0-3)，每次点击按钮更新状态并调用 `renderStep()`。
  - 坐标计算：分数坐标严格按照布局坐标表，使用 CSS `left`, `top` 配合 `transform: translate(-50%, -50%)` 实现中心对齐。
  - 动画过渡：SVG 元素的 `opacity` 和 HTML 元素的 `opacity` 使用 CSS `transition: opacity 0.3s ease` 实现平滑淡入淡出。
  - ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-frac-r1c1`, `scene1-arrow-add1`）。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
