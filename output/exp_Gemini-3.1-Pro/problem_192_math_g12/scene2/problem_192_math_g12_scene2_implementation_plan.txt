[图示主题与整合说明]
- 本图示主题：逐列推导牛顿调和三角形的通项公式
- 整合的步骤/概念：展示数阵前3列的结构，通过相邻项的递推关系（$a_{n,k} = a_{n-1,k-1} - a_{n,k-1}$）分步推导第1列、第2列、第3列的通项公式，并代入计算具体数值。
- 教学价值：教师可通过分步导航，引导学生观察数阵规律，结合右侧的代数推导面板，将几何位置关系转化为代数递推公式，清晰展示化简过程，帮助学生掌握由特殊到一般的数学归纳思想。

[分步序列]
- 初始状态（步骤0）：显示左侧数阵（第6行第2列显示为“?”），右侧推导面板为空。无高亮和箭头。
- 步骤1：点击「下一步」→ 第1列出现蓝色半透明高亮背景；右侧面板出现蓝色推导文本（第1列通项 $a_{n,1} = rac{1}{n}$）。
- 步骤2：点击「下一步」→ 第2列出现红色半透明高亮背景；出现红色箭头指示 $a_{3,2}$ 的递推来源（从 $a_{2,1}$ 和 $a_{3,1}$ 指向 $a_{3,2}$）；右侧面板出现红色推导文本（第2列通项推导）。
- 步骤3：点击「下一步」→ 数阵中第6行第2列的“?”变为“$rac{1}{30}$”；出现红色箭头指示其递推来源（从 $a_{5,1}$ 和 $a_{6,1}$ 指向 $a_{6,2}$）；右侧面板出现红色计算过程文本。
- 步骤4：点击「下一步」→ 第3列出现绿色半透明高亮背景；出现绿色箭头指示 $a_{4,3}$ 的递推来源；右侧面板出现绿色推导文本（第3列通项推导）。

[交互方案]
- 交互类型：分步按钮导航
- 控件说明：底部居中放置两个按钮「◀ 上一步」和「下一步 ▶」。
- 教师操作流程：教师首先引导学生观察数阵左侧已知数值，点击“下一步”总结第1列规律；再次点击展示第2列的递推关系及通项化简过程；接着点击展示具体位置的代入计算，验证公式；最后点击展示第3列的推导，完成由特殊到一般的归纳教学。

[技术实现]
- JS 库选择：原生 SVG（绘制高亮线和箭头） + 原生 HTML/CSS（布局） + MathJax（渲染数学公式，通过 CDN 引入）。
- 画布尺寸：800 × 500 px，相对定位容器。
- 布局草图：
  ```
  [左侧数阵区 0-300] | [右侧推导面板区 320-800]
    1/1             |  第1列通项：...
     1/2  1/2       |
      1/3  1/6  1/3 |  第2列推导：...
       ...          |
  -----------------------------------------
  [控件栏 800×40，包含 上一步 / 下一步 按钮]
  ```
- 关键实现要点：
  - 状态机设计：定义 `currentStep` (0-4)，每次点击按钮更新状态，通过控制对应 DOM 元素的 `style.opacity` 或 `style.display` 实现元素的显隐过渡。
  - 坐标计算：数阵元素使用绝对定位的 HTML div，利用 `transform: translate(-50%, -50%)` 确保坐标点即为元素中心，方便与 SVG 箭头精确对齐。
  - MathJax 渲染：在页面加载完成后调用 `MathJax.typesetPromise()` 渲染所有公式。对于步骤3中动态变化的文本（“?”变为“1/30”），可预先准备两个重叠的 div，通过切换透明度实现，避免重新调用 MathJax 导致闪烁。
  - ID 命名规范：所有元素 ID 必须以 `scene2-` 为前缀（如 `scene2-btn-next`, `scene2-col1-highlight`）。
  - 作用域隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
