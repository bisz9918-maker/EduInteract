[图示主题与整合说明]
- 本图示主题：三视图还原空间几何体及拆解
- 整合的步骤/概念：从二维三视图到三维几何体的生成，再到几何体的结构拆解与底面积分析。
- 教学价值：教师可通过分步演示，帮助学生建立从二维到三维的空间想象力，直观理解复杂组合体的构成，为后续体积计算提供清晰的几何模型和参数对应关系。

[分步序列]
- 初始状态（步骤0）：左侧显示完整的2D三视图。右侧3D区仅显示在XZ平面上的底面（半圆+三角形），并标注底面尺寸（半径1，三角形底2高1）。
- 步骤1：点击「下一步」→ 3D区中，从底面向上拉伸出顶点，生成完整的半圆锥和三棱锥组合体。显示组合体的高，并标注为 $a$。
- 步骤2：点击「下一步」→ 3D区中，半圆锥沿Z轴负方向平移，三棱锥沿Z轴正方向平移，两者分离，直观展示拆解过程。
- 步骤3：点击「下一步」→ 在拆解开的半圆锥下方浮现底面积公式 $S_1 = rac{1}{2}\pi \cdot 1^2$，在三棱锥下方浮现 $S_2 = rac{1}{2} \cdot 2 \cdot 1$，并在两者之间标注共同的高 $h=a$。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶） + 3D视角拖拽旋转。
- 控件说明：底部居中放置两个按钮，控制步骤0~3的切换。右侧3D区域支持鼠标左键拖拽旋转视角，滚轮缩放。
- 教师操作流程：教师首先引导学生观察左侧三视图，点击下一步生成3D立体图形；再次点击下一步拆解图形，讲解组合体的构成；最后点击下一步展示底面积公式，引导学生进行体积计算。可随时拖拽3D图形全方位展示。

[技术实现]
- JS 库选择及原因：
  - 左侧2D视图：原生 SVG，适合绘制精确的二维几何图形和标注。
  - 右侧3D视图：Three.js (CDN引入)，适合实现3D几何体的生成、拆解动画及视角控制。
  - 数学公式：MathJax (CDN引入)，用于渲染 $S_1$, $S_2$ 等公式。
- 画布尺寸：800 × 500 px（左侧SVG 260×500，右侧Three.js 540×500）。
- 布局草图：
  ```
  [------------------------------------------------]
  [  正视图  侧视图  |                             ]
  [                 |      Three.js 3D 交互区     ]
  [      俯视图      |                             ]
  [------------------------------------------------]
  [             ◀上一步    下一步▶               ]
  ```
- 关键实现要点：
  - **3D建模**：半圆锥使用 `CylinderGeometry` (角度设为Math.PI) 配合旋转实现；三棱锥使用 `BufferGeometry` 自定义顶点和面。
  - **动画系统**：使用 `requestAnimationFrame` 配合简单的线性插值 (lerp) 实现顶点拉伸（步骤1）和平移拆解（步骤2）的平滑过渡。
  - **3D标签**：使用 HTML 元素绝对定位叠加在 Canvas 上，在 `render` 循环中通过 `camera.updateMatrixWorld()` 和 `Vector3.project(camera)` 将3D坐标实时转换为屏幕2D坐标，更新标签位置。
  - **ID 命名规范**：所有 DOM 元素 ID 以 `scene1-` 开头，如 `scene1-btn-next`, `scene1-3d-container`。
  - **IIFE 隔离**：所有逻辑封装在 `(function() { ... })()` 中。
