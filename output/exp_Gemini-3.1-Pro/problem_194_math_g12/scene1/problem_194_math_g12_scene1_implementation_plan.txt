[图示主题与整合说明]
- 本图示主题：四面体体积的等价转换与椭球面轨迹的引入
- 整合的步骤/概念：异面直线垂直的性质、四面体体积的分割法、距离和为定值的空间轨迹（椭球面）
- 教学价值：教师可通过 3D 交互和分步演示，帮助学生直观理解异面直线的公垂线，以及动点满足距离和为定值时在空间中形成的椭球面轨迹，从而将抽象的体积最值问题转化为几何体上的距离最值问题。

[视觉元素清单]
- 四面体线框：黑色 #000000，其中 AC, CD 为虚线（辅助线 #888888 风格），其余为实线。
- 截面 $	riangle EBC$：多边形面，蓝色高亮 #1565c0，填充透明度 20%，双面渲染。
- 垂线 EF：红色高亮 #c62828，线宽 2px。
- 椭球面：以 A, D 为焦点的旋转椭球面，绿色高亮 #2e7d32，填充透明度 10%，附加 #2e7d32 虚线网格。
- 文本标签：使用 CSS2DRenderer 实现，黑色 14px 字体，无背景。
- 公式面板：左上角绝对定位的 HTML 元素，半透明白底，用于显示当前步骤的推导公式。

[分步序列]
- 初始状态（步骤0）：显示四面体 ABCD 的线框及顶点标签 A, B, C, D。显示长度标签 "2c" 和 "2"。公式面板隐藏。
- 步骤1：点击「下一步」。出现点 E 及标签，显示截面 EBC（蓝色半透明）。公式面板出现，显示：$V = rac{1}{3} S_{	riangle EBC} \cdot AD$。
- 步骤2：点击「下一步」。出现点 F 及标签，显示连线 EF（红色）及长度标签 "d"。公式面板更新为：$V = rac{1}{3} \cdot rac{1}{2} BC \cdot d \cdot AD = rac{2}{3} c d$。
- 步骤3：点击「下一步」。高亮折线 A-B-D 和 A-C-D（变为绿色加粗）。出现包络 B, C 两点的椭球面（绿色半透明）。公式面板追加显示：$AB+BD=2a$，点 B, C 轨迹为椭球面。

[标签冲突检查]
- 标签 "A"(-15, 15) 与 "D"(-15, -15)：Y轴距离 4 个单位，屏幕投影距离远，无冲突。
- 标签 "B"(15, 15) 与 "C"(15, -15)：Z轴距离 2 个单位，无冲突。
- 标签 "E"(-15, 0) 与 "2c"(-20, 0)：E 在 y=-0.5，若 2c 在中点 y=0 会很接近。解决方案：将 "2c" 移至 y=1 处，彻底错开。
- 标签 "F"(15, 0) 与 "2"(0, 20)：两者都在 BC 中点 F 处。解决方案：F 放在右侧，"2" 放在正下方，方向正交，无冲突。
- 标签 "d"(0, -15)：在 EF 中点，周围空间开阔，无冲突。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶） + 3D 视角控制。
- 控件说明：
  - 3D 场景：支持鼠标左键拖拽旋转，滚轮缩放，右键平移。
  - 底部控件栏：y=450~490 区域居中放置「◀ 上一步」和「下一步 ▶」按钮。
- 教师操作流程：教师可先旋转 3D 视图让学生看清四面体结构，然后依次点击「下一步」展示体积的分割、公垂线的作法，最后展示椭球面轨迹，配合左上角公式进行讲解。

[技术实现]
- JS 库选择及原因：Three.js（用于 3D 几何体、材质和椭球面渲染），CSS2DRenderer（用于 3D 空间中不随视角变形的 2D 文本标签），MathJax（用于左上角公式面板的数学公式渲染）。
- 画布尺寸：800 × 500 px，固定尺寸。
- 布局草图：
  ```
  [图示区 800×500 (Three.js WebGL + CSS2D)]
  [左上角：绝对定位公式面板，距左20px，距上20px]
  [控件栏：绝对定位在底部 y=450，居中，包含2个按钮]
  ```
- 关键实现要点：
  - 坐标系：Y轴向上，A(0,-2,0), D(0,2,0)。
  - 椭球面生成：使用 `THREE.SphereGeometry(1, 32, 32)`，然后应用 `scale.set(3.464, 4, 3.464)` 变形为椭球面。
  - 状态机设计：定义 `step = 0~3`，在 `updateScene()` 函数中根据 `step` 统一设置各 Object3D 的 `visible` 和 `material.color`。
  - 标签渲染：引入 `CSS2DRenderer`，将其 DOM 元素绝对定位覆盖在 WebGL 画布上，并设置 `pointer-events: none` 以免阻挡 OrbitControls。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-btn-next`, `scene1-formula`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
