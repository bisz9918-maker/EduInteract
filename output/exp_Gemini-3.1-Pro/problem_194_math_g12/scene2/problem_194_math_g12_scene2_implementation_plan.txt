[图示主题与整合说明]
- 本图示主题：截面圆半径变化与弦心距最大化的动态演示
- 整合的步骤/概念：展示四面体体积最大化问题中，底面三角形的高（即弦心距 $d$）如何随截面高度 $z$ 变化。通过 3D 到 2D 的联动，直观呈现椭球面平行截面半径 $R$ 与弦心距 $d$ 的勾股关系，帮助学生理解最值在截面位于中点时取得。
- 教学价值：教师可通过拖动滑块，动态展示截面平移过程，引导学生观察 $R$ 和 $d$ 的同步增减规律，化抽象的 3D 空间最值问题为直观的 2D 平面几何计算。

[分步序列]
- 交互方式为连续拖拽滑块，无离散步骤，状态随滑块连续变化。
- 初始状态：滑块位于 $z=50$ 处。3D 视图显示偏下的截面，2D 视图显示对应的圆、弦及直角三角形。极值提示隐藏。
- 拖拽过程：教师向左拖动滑块（$z 	o 0$），截面上升，3D 和 2D 中的圆半径 $R$ 增大，弦心距 $d$ 同步增大。
- 极值状态：滑块到达正中间（$z=0$）。截面位于椭球正中央，圆达到最大。极值提示文本浮现：“z=0 时，半径 R 与弦心距 d 达到最大”。
- 继续拖拽：滑块越过中点（$z < 0$），截面继续上升，圆半径 $R$ 缩小，$d$ 缩小。

[交互方案]

  - 位于 SVG 容器底部（y=460 区域），绝对定位。
  - 左侧文本“截面高度 z”，右侧动态显示当前 z 值（如“z = 50”）。
- 教师操作流程：教师在讲解时，缓慢拖动滑块，让学生观察右侧 2D 视图中直角三角形 $	riangle EFC$ 的变化，强调 $BC=2$（半弦长为1）是定值，因此 $d = \sqrt{R^2 - 1}$，从而得出 $d$ 随 $R$ 单调递增的结论。最后将滑块停在 $z=0$ 处，展示最值。

[技术实现]
- JS 库选择：原生 SVG + Vanilla JS（性能好，无需额外依赖，适合几何作图）。
- 画布尺寸：800 × 500 px。
- 布局草图：
  [3D 视图区 (0-400)] | [2D 视图区 (400-800)]
  [       滑块控件区 (y=450~490)       ]
- 关键实现要点：
  - 比例尺设定：设 $a=140, c=100$，则 $b=\sqrt{140^2-100^2} \approx 98$。半弦长 1 单位对应 40px。
  - 核心计算逻辑（在 `oninput` 事件中）：
    1. 读取 $z \in [-100, 100]$。
    2. 计算当前半径 $R = 98 	imes \sqrt{1 - (z/140)^2}$。
    3. 计算弦心距 $d = \sqrt{R^2 - 40^2}$。
  - 3D 投影逻辑：
    - 采用简单的斜二测投影变体：`projX = 200 + x - 0.5y`, `projY = 220 - z + 0.3y`。
    - 3D 截面圆通过生成 50 个点的 `<path>` 绘制：$x = R\cos	heta, y = R\sin	heta$，代入投影公式。
    - 3D 坐标：$E=(0,0,z)$, $F=(0,d,z)$, $B=(-40,d,z)$, $C=(40,d,z)$。
  - 2D 视图更新：
    - 直接更新 `<circle>` 的 `r` 属性为 $R$。
    - 更新 $F(600, 220+d)$, $B(560, 220+d)$, $C(640, 220+d)$ 的坐标。
    - 同步更新所有相关线段和标签的 `x`, `y` 属性。
  - 极值提示：判断 `Math.abs(z) < 2`，若成立则将提示文本的 `opacity` 设为 1，否则设为 0。
- ID 命名规范：所有元素 ID 均以 `scene2-` 开头，如 `scene2-circle-3d`, `scene2-line-ef-2d`。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
