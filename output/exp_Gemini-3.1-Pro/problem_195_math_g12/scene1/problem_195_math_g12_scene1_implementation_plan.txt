[图示主题与整合说明]
- 本图示主题：切割线定理与勾股定理的综合应用
- 整合的步骤/概念：题目初始条件展示、切割线定理求PC、切线性质推导直角、勾股定理求直径及半径。

[分步序列]
- 初始状态（步骤0）：显示圆O，线段AC, PA, PC，点及字母标签，显示数值 PA=2, PB=1。隐藏其他推导数值和高亮。
- 步骤1（切割线定理）：点击「下一步」→ 线段 PA 和 PC 高亮为蓝色（#1565c0，加粗），显示数值标签 PC=4。
- 步骤2（切线性质）：点击「下一步」→ 线段 AC 和 PA 高亮为红色（#c62828，加粗），PC 恢复黑色。A点处出现红色直角符号。
- 步骤3（勾股定理）：点击「下一步」→ 显示三角形 PAC 的蓝色半透明填充，线段 PA, AC, PC 边框变为蓝色。显示数值标签 AC=2√3。
- 步骤4（得出结论）：点击「下一步」→ 线段 OA 叠加绿色高亮（#2e7d32，加粗），显示数值标签 R=√3。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：底部居中放置两个按钮，控制步骤 0~4 的切换。
- 教师操作流程：教师首先展示题目基础图形，然后依次点击“下一步”，配合口头讲解切割线定理、切线性质、勾股定理，逐步推导出最终半径。

[技术实现]
- JS 库选择及原因：原生 SVG。本题图形为标准几何图形（圆、线段），SVG 能够完美保证清晰度，且方便通过 DOM 操作修改颜色、线宽和透明度来实现高亮动画。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  +------------------------------------------------+
  |                                                |
  |                     C                          |
  |                    /|                          |
  |                   / |                          |
  |                  /  |                          |
  |                 /   | AC=2√3                   |
  |             PC=4    O                          |
  |               /     |                          |
  |              B      | R=√3                     |
  |             /       |                          |
  |            /        |                          |
  |           P----PA=2-A                          |
  |                                                |
  |           [ 上一步 ]  [ 下一步 ]               |
  +------------------------------------------------+
  ```
- 关键实现要点：
  - 使用 `<svg>` 标签构建图形，所有元素按层级排列（填充层在最下，线段层在中，点和文本层在最上）。
  - 定义一个 `updateStep(step)` 函数，使用 `switch(step)` 逻辑控制各个 SVG 元素的 `stroke`, `stroke-width`, `fill`, `opacity` 等属性。
  - 文本标签使用 `<text>` 元素，特殊符号直接使用 Unicode（如 `√3`）。
  - ID 命名规范：所有元素 ID 以 `scene1-` 开头，例如 `scene1-btn-next`, `scene1-line-pa`。
  - IIFE 隔离：整个脚本包裹在 `(function() { ... })()` 中，避免全局变量污染。
