题目原文：
如图，将△ABC沿着它的中位线DE折叠后，点A落到点A′，若∠C=120°，∠A=26°，则∠A′DB的度数是．

题目分析：
本题考查了三角形中位线定理、平行线的性质、三角形内角和定理以及折叠的性质。解题的核心在于通过“还原”折叠前的图形，理清各个角之间的位置与数量关系。
已知条件给出了△ABC的两个内角，利用内角和可求出∠B。中位线DE平行于BC，利用平行线性质可将∠B转移至∠ADE。最后，根据折叠前后图形全等的性质，得到∠A'DE = ∠ADE，再结合平角定义即可求出目标角∠A'DB。

整体讲解思路：
首先引导学生将折叠的图形还原，补全完整的△ABC，从而直观看到中位线DE与底边BC的关系。接着在△ABC中求出∠B，利用中位线平行性质得到∠ADE。随后再次演示折叠过程，利用全等性质得出∠A'DE。最后利用A、D、B三点共线的平角关系，计算出最终结果。

图示规划说明：
本题所有的几何推导均在同一个图形结构上进行，因此规划一个综合性的交互图示。通过分步动画，依次展示“展开还原”、“平行线同位角”、“折叠全等”和“平角计算”的完整逻辑链条，避免图形割裂，帮助学生建立连贯的几何直观。

教学讲解建议与推导过程

在课堂讲解时，教师可按照图示的步骤进行如下引导：

  1. 读题与还原：提问“题目说沿着中位线折叠，但图中并没有完整的三角形。为了看清全貌，我们首先应该做什么？”操作图示展开图形。讲解“我们将点A'还原到原来的位置A，这样完整的△ABC就出现了，D、E分别是AB、AC的中点。”

  3. 中位线的核心作用：提问“题目特别强调DE是中位线，中位线有什么重要性质？”操作图示。讲解“中位线DE平行于底边BC。因为DE∥BC，所以同位角相等，即∠ADE = ∠B = 34°。”
  4. 折叠的本质：提问“折叠操作在几何中意味着什么？”操作图示演示折叠。讲解“折叠就是轴对称，折叠前后的两个三角形完全重合。因此，∠A'DE = ∠ADE = 34°。”
  5. 平角收尾：提问“最后，观察点A、D、B的位置关系，如何求出∠A'DB？”操作图示。讲解“因为D在边AB上，所以A、D、B三点共线，构成一个180°的平角。目标角 ∠A'DB = 180° - 34° - 34° = 112°。”
