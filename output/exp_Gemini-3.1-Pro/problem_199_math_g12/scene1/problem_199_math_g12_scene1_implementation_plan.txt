[图示主题与整合说明]
- 本图示主题：利用中心对称性探究三角形面积函数的奇偶性
- 整合的步骤/概念：正六边形与直线的交点、直线 $y=kx+t$ 与 $y=kx-t$ 的中心对称关系、交点与三角形的中心对称性、面积相等的结论。
- 教学价值：教师可以通过分步演示，引导学生从代数方程的参数变化（$t$ 到 $-t$）联想到几何图形的中心对称，直观地将抽象的函数奇偶性转化为可视化的几何面积相等问题，降低理解难度。

[分步序列]
- 初始状态（步骤0）：显示坐标系、正六边形及其顶点标签、直线 L、交点 M 和 N、△OMN（蓝色填充）。隐藏 L'、M'、N'、△OM'N' 及辅助线。
- 步骤1：点击「下一步」→ 直线 L' 出现，交点 M' 和 N' 出现，△OM'N'（红色填充）淡入。展示 $t$ 变为 $-t$ 后的几何图形。
- 步骤2：点击「下一步」→ 原点 O 放大并变为绿色。辅助虚线 MM' 和 NN' 从 M、N 出发，穿过原点 O 延伸至 M'、N'，动态绘制，直观揭示中心对称关系。
- 步骤3：点击「下一步」→ △OMN 与 △OM'N' 同时开始呼吸闪烁（透明度在 0.2 到 0.6 之间循环）。底部 (400,420) 处淡入结论文本 "$f(t) = f(-t)$ (偶函数)"。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：在 SVG 底部 (y=460) 居中放置两个按钮，控制步骤 0~3 的切换。
- 教师操作流程：教师首先展示初始题意（步骤0），讲解面积 $S=f(t)$ 的定义；点击下一步（步骤1）引入 $f(-t)$ 对应的图形；再次点击（步骤2）引导学生观察对称性，通过辅助线验证；最后点击（步骤3）总结全等三角形面积相等，得出偶函数结论。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。图形均为简单多边形和线段，SVG 的 DOM 结构非常适合分步控制显示/隐藏和 CSS 动画。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×450]
    (包含坐标系、六边形、直线及三角形)
  [控件栏 800×50]
    (居中放置 ◀上一步 / 下一步▶ 按钮)
  ```
- 关键实现要点：
  1. 状态机设计：定义 `currentStep` 变量（0-3），每次点击按钮更新状态，并调用 `updateScene()` 函数。
  2. 动画控制：使用 CSS `transition: opacity 0.5s` 控制元素的淡入淡出。辅助线的动态绘制可使用 SVG `stroke-dasharray` 和 `stroke-dashoffset` 配合 CSS `animation` 实现。
  3. 闪烁效果：在步骤3为两个三角形添加 CSS `animation: blink 1.5s infinite alternate`。
  4. ID 命名规范：所有元素 ID 必须以 `scene1-` 为前缀（如 `scene1-line-L`、`scene1-btn-next`）。
  5. IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
