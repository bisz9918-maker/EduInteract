[图示主题与整合说明]
- 本图示主题：等效电路分析与电流分配原理
- 整合的步骤/概念：识别复杂电路的连接方式、画出标准等效并联电路图、探究滑动变阻器滑片移动对并联支路电阻及电流的反比例影响。
- 教学价值：教师可通过分步演示，引导学生从复杂的实物连线图中抽象出标准的并联电路模型，降低认知难度；随后通过拖拽滑片，直观展示电阻变化与电流变化的动态反比关系，帮助学生深刻理解 $I \propto 1/R$ 的物理规律。

[分步序列]
- 初始状态（步骤0）：显示原始电路图。滑片 P 位于正中间 (x=250)。右侧图表区隐藏。
- 步骤1：点击「下一步」→ 在原始电路图上叠加动态电流箭头。主干路（黑色箭头）从电源正极出发向上分流；左支路（红色箭头）经 A1、AP 段到达 P 点；右支路（蓝色箭头）经 A2、BP 段到达 P 点；汇合后经中间导线回到负极。高亮显示 A1 支路（红色）和 A2 支路（蓝色）。
- 步骤2：点击「下一步」→ 平滑淡出原始电路，淡入等效电路。等效电路采用标准并联布局，左侧为主干路，中间为支路1（含 A1、$R_{AP}$），右侧为支路2（含 A2、$R_{BP}$）。右侧图表区仍隐藏。
- 步骤3（最终步骤）：点击「下一步」→ 显示右侧图表区，激活滑片 P 控件。拖动滑片时，实时更新 $R_{AP}$ 和 $R_{BP}$ 的柱状图高度，以及 $I_1$ 和 $I_2$ 的柱状图高度，直观展示反比关系。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）结合 拖拽/滑块。
- 控件说明：
  - 底部导航按钮：控制步骤 0-3 的切换，位于 (400, 460)。
  - 滑片 P 位置滑块：位于右侧图表区 (500, 110)，仅在步骤 3 激活，用于改变 P 点位置（模拟值 10-90）。
- 教师操作流程：教师首先展示原始电路（步0），点击下一步演示电流走向以启发学生识别并联关系（步1），再点击下一步展示标准等效电路（步2），最后点击下一步并拖动滑块，结合右侧柱状图讲解电阻与电流的动态反比关系（步3）。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。电路图由简单的线段、矩形和圆形组成，原生 SVG 渲染清晰且易于通过 DOM 操作实现淡入淡出和属性更新；图表部分用简单的 SVG `<rect>` 即可实现，无需引入复杂图表库。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  +-------------------+-------------------+
  |                   |                   |
  |   (原始电路 /     |   [滑片 P 控件]   |
  |    等效电路)      |                   |
  |                   |   [R 柱状图]      |
  |   x: 50~450       |                   |
  |                   |   [I 柱状图]      |
  |                   |   x: 450~750      |
  +-------------------+-------------------+
  [控件栏: 上一步 / 下一步 (y=460)]
  ```
- 关键实现要点：
  - 状态机设计：定义 `currentStep` 变量，通过更新父容器的 `class` (如 `step-0`, `step-1`) 来控制不同 SVG 组的 `opacity` 和 `pointer-events`，实现平滑过渡。
  - 动画曲线：电流箭头使用 SVG `<animateMotion>` 沿 `<path>` 运动，设置 `repeatCount="indefinite"`。
  - 坐标计算：滑块 `input` 事件触发时，读取 `value` (10-90)，计算 $h_{RAP} = 60 	imes (v/100)$，更新对应 `<rect>` 的 `height` 和 `y` 属性。电流高度 $h_{I1} = 80 	imes (10/v)$。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-btn-next`, `scene1-slider-p`, `scene1-rect-rap`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
