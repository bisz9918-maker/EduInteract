[图示主题与整合说明]
- 本图示主题：滑动范围与电流比值的定量计算
- 整合的步骤/概念：0.6A量程下的长度计算、3A量程下的新范围计算、新最大电流比值计算。
- 教学价值：通过分步展示，将复杂的物理过程（两次量程变化、端点移动、比例计算）拆解为直观的几何线段关系，帮助教师引导学生理解反比关系和对称性在电路中的应用，避免信息一次性堆砌导致认知超载。

[视觉元素清单]
- 铅笔芯主线段：黑色，粗细 6px。
- 0.6A量程点(c, d)：蓝色 #1565c0，半径 4px。高亮时半径变为 6px。
- 3A量程点(c', d')：红色 #c62828，半径 4px。高亮时半径变为 6px。
- 测距线（括号）：使用 SVG path 绘制，形如 `M x1 y-5 L x1 y L x2 y L x2 y-5`。线宽 1.5px。
- 测距文本：使用 SVG text，居中对齐 (`text-anchor="middle"`)，字号 14px。
- 公式推导框：HTML `div` 元素，绝对定位在 SVG 上方，使用 MathJax 渲染数学公式。

[分步序列]
- 初始状态（步骤0）：
  - 显示：铅笔芯 AB 线段，点 A、B 及其标签。总长 L 标注（文本为 "L"）。
  - 公式框："设铅笔芯总长度为 $L$。"
- 步骤1（引入0.6A条件）：
  - 显示：新增点 c、d 及其标签。
  - 高亮：点 c 放大。
  - 公式框："0.6A量程下，滑片在 $c$ 点时电流最大：<br>$I_1 = 0.6	ext{A}, I_2 = 0.2	ext{A}$<br>$\Rightarrow R_{Ac} : R_{cB} = I_2 : I_1 = 1 : 3$<br>$\Rightarrow Ac : cB = 1 : 3$"
- 步骤2（计算总长）：
  - 显示：新增 0.6A 标注（Ac="6cm", cd="12cm", dB="6cm"）。总长 L 标注更新为 "L = 24cm"。
  - 高亮：cd 线段（在主线上方叠加蓝色粗线）。
  - 公式框："由对称性，滑片在 $d$ 点时 $dB : Ad = 1 : 3$。<br>中间滑动范围 $cd = L - Ac - dB = L/2 = 12	ext{cm}$。<br>解得 $L = 24	ext{cm}$，则 $Ac = dB = 6	ext{cm}$。"
- 步骤3（引入3A条件）：
  - 显示：新增点 c' 及其标签，Ac' 标注（"1.2cm"）。
  - 高亮：点 c' 放大。取消 cd 线段高亮。
  - 公式框："3A量程下，滑片在 $c'$ 点时电流最大为 3A。<br>根据反比关系：$R_{Ac'} 	imes 3	ext{A} = R_{Ac} 	imes 0.6	ext{A}$<br>$\Rightarrow Ac' = Ac 	imes rac{0.6}{3} = 6	ext{cm} 	imes 0.2 = 1.2	ext{cm}$"
- 步骤4（计算新范围）：
  - 显示：新增点 d' 及其标签，c'd' 标注（"21.6cm"），d'B 标注（"1.2cm"）。
  - 高亮：c'd' 线段（在主线上方叠加红色粗线）。
  - 公式框："同理 $d'B = 1.2	ext{cm}$。<br>新的滑动范围 $c'd' = L - Ac' - d'B = 24 - 1.2 - 1.2 = 21.6	ext{cm}$。"
- 步骤5（计算新比值）：
  - 显示：保持步骤4的所有元素。
  - 高亮：点 c' 放大。
  - 公式框："在 $c'$ 点时，两电流表示数比值最大：<br>$Ac' = 1.2	ext{cm}, c'B = 24 - 1.2 = 22.8	ext{cm}$<br>$I_1 : I_2 = R_{c'B} : R_{Ac'} = c'B : Ac' = 22.8 : 1.2 = 19 : 1$"

[交互方案]

[技术实现]
- JS 库选择及原因：原生 SVG 用于绘制精确的几何图形和标注；MathJax (CDN) 用于渲染公式推导框中的数学公式。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
    (150,40)  +-------------------------+
              |       公式推导框        |
              +-------------------------+
    (100,225) A  c'       c              d       d'  B
    (100,250) |*-*--------*--------------*-------*-*| (铅笔芯)
    (100,290) |<-6cm->|<-------12cm------->|<-6cm->| (0.6A标注)
    (100,340) |1.2|   |<-------21.6cm----->|   |1.2| (3A标注)
    (100,390) |<-------------L = 24cm------------->| (总长标注)

  [控件栏 800×40, y=450]
           [◀ 上一步]    步骤 2 / 5    [下一步 ▶]
  ```
- 关键实现要点：
  - 状态机设计：定义一个 `currentStep` 变量（0-5），每次点击按钮更新该变量，并调用 `updateScene()` 函数。
  - `updateScene()` 函数根据 `currentStep` 控制各 SVG 元素的 `opacity` 或 `display` 属性，并更新公式框的 `innerHTML`。
  - MathJax 渲染：每次更新公式框内容后，必须调用 `MathJax.typesetPromise([document.getElementById('scene2-formula-box')])` 重新渲染公式。
  - 动画过渡：可以为 SVG 元素的 `opacity` 添加 CSS `transition: opacity 0.3s ease` 实现平滑显示。
- ID 命名规范：所有交互元素 ID 必须以 `scene2-` 为前缀（如 `scene2-line-ab`, `scene2-btn-next`）；JS 中用 `document.getElementById` 获取元素。
- IIFE 隔离：所有 JS 代码必须包裹在 `(function() { ... })()` 中，避免全局变量污染。
