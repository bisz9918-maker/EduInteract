[图示主题与整合说明]
- 本图示主题：缓慢拉动活塞过程中的动态变化与受力分析
- 整合的步骤/概念：活塞位移与水银柱高度的几何关系、气体等温膨胀、拉力F的非单调变化规律
- 教学价值：教师可通过拖动滑块，连续展示活塞上移过程中，各段水银柱高度的动态变化，以及右侧同步生成的拉力-位移函数曲线。直观揭示拉力先增大后减小至零的非直观物理规律，帮助学生理解极值点和零点的物理意义。

[视觉元素清单]

- 几何变化量标注线（x, 4x, h'）：绿色 #2e7d32，两端带箭头，旁边附带绿色文本。

- 状态文本：黑色，字号 14px。

[分步序列]
- 交互类型为连续拖拽滑块，无离散步骤，呈现平滑的连续状态变化。
- 初始状态 (x=0)：活塞在 y=145，B管水银底面在 y=370。拉力 F=0，动点在原点 (380, 250)。
- 拖拽过程 (0 < x < 0.98)：活塞上移，水银柱变短，F 箭头逐渐变长，动点沿曲线爬升至最高点。
- 极值状态 (x=0.98)：F 箭头达到最长，动点到达 (525, 94)。
- 下降过程 (0.98 < x < 2)：活塞继续上移，F 箭头逐渐变短，动点沿曲线下降。
- 零点状态 (x=2)：F 箭头消失，动点到达 X 轴 (676, 250)。
- 负值过程 (x > 2)：F 箭头反向（向下），动点进入第四象限。

[交互方案]
- 交互类型：拖拽/滑块
- 控件说明：底部中央放置一个 `<input type="range">` 滑块，ID 为 `scene2-slider-x`，范围 0 到 2.4，步长 0.01。滑块左侧显示 "活塞位移 x:"，右侧实时显示数值。
- 教师操作流程：教师在讲解时，缓慢向右拖动滑块，引导学生观察左侧水银柱高度的变化，同时观察右侧拉力 F 随位移 x 的非单调变化曲线，重点停顿在 x=0.98 和 x=2 处进行受力分析。

[技术实现]
- JS 库选择及原因：原生 SVG。由于涉及大量几何图形的动态坐标更新和简单的函数曲线绘制，原生 SVG 的 DOM 操作最为直接高效，且易于实现高质量的矢量渲染。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [左侧图示区 350×440] [右侧图表区 450×440]
  [       滑块控件区 800×60 (y=440~500)      ]
  ```
- 关键实现要点：
  - 状态计算函数：`calcState(x)`，输入位移 x，计算出 `F_val = 90 - 3*x - 2520/(28+x)`。
  - 坐标映射：左侧 Y 坐标按 `1cm = 15px` 映射；右侧 X 坐标按 `1cm = 148px` 映射，Y 坐标按 `1cmHg = 1500px` 映射。
  - 曲线生成：在初始化时，循环 x 从 0 到 2.4，步长 0.05，生成 SVG `<path>` 的 `d` 属性字符串。
  - 动态更新：监听滑块的 `input` 事件，实时计算新的几何坐标和 F 值，更新对应的 SVG 元素的属性（如 `y`, `height`, `points`, `d` 等）和文本内容。
- ID 命名规范：所有交互元素 ID 必须以 `scene2-` 为前缀，例如 `scene2-piston`, `scene2-mercury`, `scene2-curve`。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
