场景导航：Scene 1

如图所示，质量为m，带电量为q的粒子，以初速度v$_{0}$，从A点竖直向上射入真空中的沿水平方向的匀强电场中，粒子通过电场中B点时，速率v$_{B}$=2v$_{0}$，方向与电场的方向一致，问：
（1）水平方向和竖直方向分别作什么运动？
（2）从A到B竖直方向位移是多少？
（3）从A到B重力做的功是多少？
（4）从A到B电场力做的功是多少？
（5）A，B两点的电势差是多少？

题目分析与整体讲解思路：
本题考查带电粒子在复合场（重力场和匀强电场）中的运动。由于重力和电场力都是恒力，且方向相互垂直，最自然的方法是采用运动的合成与分解。

  • 竖直方向：粒子受向下的重力，有向上的初速度 $v_0$，且在 B 点竖直分速度为零，因此做竖直上抛运动（匀减速直线运动）。
  • 水平方向：粒子受向右的恒定电场力，初速度为零，因此做初速度为零的匀加速直线运动。

在讲解时，首先引导学生进行受力分析，明确两个方向的受力情况，从而得出运动性质（解决问1）。接着利用竖直方向的运动学公式求出位移（解决问2）。然后利用动能定理或功的定义分别计算重力和电场力做功（解决问3、4）。最后通过电场力做功与电势差的关系求出电势差（解决问5）。

图示规划说明：
规划一个包含分步导航的综合图示。通过步骤切换，依次展示：初始状态与轨迹 → 受力分析 → 速度分解与运动性质 → 位移与做功情况。这样可以在同一物理情境下，将运动学和动力学特征完美结合，帮助学生建立清晰的物理图像。

步骤 1 / 4

教学说明与推导过程：

1. 运动性质分析（对应步骤 1、2）
引导学生观察粒子的受力情况：

  • 竖直方向：粒子受到竖直向下的重力 $mg$，且有竖直向上的初速度 $v_0$。在 B 点时，速度方向水平，说明竖直方向速度减为 0。因此，竖直方向做匀减速直线运动（竖直上抛运动）。
  • 水平方向：粒子受到水平向右的电场力 $qE$，初速度为 0。因此，水平方向做初速度为零的匀加速直线运动。

2. 竖直方向位移（对应步骤 3）
在竖直方向上，利用匀变速直线运动的速度位移公式：
$0 - v_0^2 = -2gh$
解得竖直方向位移：
$h =
rac{v_0^2}{2g}$

3. 重力做功（对应步骤 3）
粒子从 A 到 B，竖直向上运动，重力做负功：
$W_G = -mgh = -mg \cdot
rac{v_0^2}{2g} = -
rac{1}{2}mv_0^2$
（也可以直接对竖直方向应用动能定理：$W_G = 0 -
rac{1}{2}mv_0^2 = -
rac{1}{2}mv_0^2$）

4. 电场力做功（对应步骤 3）
对水平方向应用动能定理。水平方向只有电场力做功，初动能为 0，末速度为 $2v_0$：
$W_E =
rac{1}{2}m(2v0)^2 - 0 = 2mv0^2$

5. A、B 两点电势差（对应步骤 3）
根据电场力做功与电势差的关系式 $W_E = qU_{AB}$，可得：
$U_{AB} =
rac{W_E}{q} =
rac{2mv_0^2}{q}$

总结：
本题的关键在于将复杂的曲线运动分解为两个相互垂直的直线运动。通过分别研究两个方向的受力、运动规律和能量转化，可以清晰地求解各个物理量。
