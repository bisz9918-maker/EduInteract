[图示主题与整合说明]
- 本图示主题：带电粒子在电场中的类平抛运动及出射后的匀速直线运动
- 整合的步骤/概念：题目初始场景、电场中的抛物线轨迹与侧移量 $y$、出射速度分解、无场区直线轨迹与总侧移量 $Y$、反向延长线过中点的几何关系
- 教学价值：教师可通过分步导航，清晰地展示粒子在电场中受力偏转的过程、出射时的速度分解，以及出射后在无场区做匀速直线运动的轨迹。最后通过反向延长线和相似三角形的高亮，直观推导出侧移量 $y$ 与总侧移量 $Y$ 之间的几何比例关系，帮助学生突破难点。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：在 SVG 底部（y=450~490 区域）居中放置两个按钮：“上一步”和“下一步”，以及步骤指示器（如“1 / 4”）。
- 教师操作流程：教师首先介绍题目初始条件（步骤0）；点击“下一步”讲解粒子在电场中的受力与抛物线偏转（步骤1）；再次点击讲解出射速度的矢量分解（步骤2）；最后点击讲解无场区的匀速直线运动，并通过反向延长线和相似三角形推导 y 与 Y 的关系（步骤3）。

[技术实现]
- JS 库选择及原因：原生 SVG。本场景主要由几何线段、二次贝塞尔曲线、多边形和文本构成，原生 SVG 能够完美且高效地实现这些矢量图形，且易于通过 DOM 操作控制各元素的显示与隐藏。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×440]
  极板在左侧，MN在中，PS在右。
  轨迹从左上向右下延伸。
  [控件栏 800×60]
  底部居中放置 ◀上一步 / 下一步▶ 按钮。
  ```
- 关键实现要点：
  - 状态机设计：定义一个 `currentStep` 变量（0~3），每次点击按钮更新该变量，并调用 `updateScene()` 函数。
  - `updateScene()` 函数根据 `currentStep` 的值，控制各 SVG 元素（通过 ID 获取）的 `display` 或 `opacity` 属性。
  - 抛物线轨迹使用 `<path d="M 200 150 Q 280 150 360 210" fill="none" />` 实现。
  - 相似三角形使用 `<polygon>` 标签，在步骤3时将其 `opacity` 从 0 设为 0.15。
  - 矢量箭头可通过 `<marker>` 定义箭头样式，附加到 `<line>` 或 `<path>` 上。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀，例如 `scene1-traj-parabola`, `scene1-btn-next`。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
