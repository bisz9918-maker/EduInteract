[图示主题与整合说明]
- 本图示主题：圆盘上物体的受力随角速度变化的动态演变
- 整合的步骤/概念：A、B两物体的受力分析、静摩擦力达到最大值的临界状态、两根细绳出现弹力及断裂的临界状态
- 教学价值：教师可通过拖动滑块连续改变角速度，直观展示向心力需求增加时，静摩擦力先增大至饱和，随后绳子张力依次介入的动态物理过程，帮助学生理解临界状态的判定。

[视觉元素清单]
- 圆盘：灰色半透明填充 `rgba(204,204,204,0.5)`，黑色描边
- 物块 A、B：深灰色填充 `rgba(153,153,153,0.8)`，黑色描边
- 细绳：黑色实线，断裂时 OB 绳中间留出 20px 空隙并显示红色“断裂”字样
- 摩擦力向量 $f_A, f_B$：#c62828（红高亮），线宽 2px，带箭头
- AB绳张力向量 $T_{AB}$：#1565c0（蓝高亮），线宽 2px，带箭头
- OB绳张力向量 $T_{OB}$：#2e7d32（绿高亮），线宽 2px，带箭头
- 辅助线：#888888 虚线，用于标记半径 $r_A, r_B$ 及其垂直引导线

[分步序列]
- 状态1（$\omega \in [0, 5)$）：仅有红色的 $f_A, f_B$ 向量，随 $\omega$ 增大而变长。面板提示“靠静摩擦力提供向心力”。
- 状态2（$\omega = 5$）：$f_A$ 达到最大长度（40px）。面板提示“A 的摩擦力达到最大，AB绳即将产生张力”。
- 状态3（$\omega \in (5, 5.77)$）：$f_A$ 保持不变，蓝色的 $T_{AB}$ 向量在 A 和 B 上出现并变长，$f_B$ 加速变长。
- 状态4（$\omega = 5.77$）：$f_B$ 达到最大长度（40px）。面板提示“B 的摩擦力达到最大，OB绳即将产生张力”。
- 状态5（$\omega \in (5.77, 10]$）：$f_A, f_B$ 保持不变，绿色的 $T_{OB}$ 向量出现并变长，$T_{AB}$ 继续变长。当 $\omega=10$ 时，面板提示“OB绳达到最大张力，即将断裂”。
- 状态6（$\omega > 10$）：OB 绳中间断开显示“断裂”，物块 A、B 及 AB 绳整体向右滑动（偏移量 $\Delta = (\omega-10)	imes 20$），$T_{OB}$ 消失。面板提示“OB绳断裂，物体向外滑动！”。

- $T_{AB}$ 作用于 A 标签 (y=295) vs $T_{OB}$ 作用于 B 标签 (y=295)：x 坐标分别在 640 和 520 附近，间距 > 40px。无冲突。

- 物块 A 标签 (715, 275) vs $T_{AB}$ 作用于 A 标签 (y=295)：y 方向错开 20px，x 方向错开 > 15px。无冲突。

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：底部居中放置一个 `<input type="range">` 滑块，范围 0 到 12，步长 0.01。
- 教师操作流程：教师缓慢向右拖动滑块，引导学生观察左侧数据面板中各力数值的变化，以及右侧圆盘上力向量的动态生长。在 $\omega=5, 5.77, 10$ 三个临界点暂停，结合面板的状态提示进行重点讲解。最后拖动到 10 以上展示断裂结果。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。图形均为简单几何体和直线，原生 SVG 性能好且易于通过 DOM 操作更新属性。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +-------------------------+--------------------------------+
  | [数据面板]              |                                |
  | ω: 0.00 rad/s           |           [圆盘]               |
  | f_A: 0.00 mg            |                                |
  | f_B: 0.00 mg            |      O-------B-------A         |
  | T_AB: 0.00 mg           |                                |
  | T_OB: 0.00 mg           |                                |
  | 状态: ...               |                                |
  +-------------------------+--------------------------------+
  |                 [滑块: 0 -------- 12]                  |
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  - 状态机设计：在 `input` 事件监听器中，根据 $\omega$ 的值进入不同的 `if-else` 分支，计算 $f_A, f_B, T_{AB}, T_{OB}$ 的数值（单位 mg）。
  - 坐标计算：定义比例尺 `1mg = 80px`。根据力的大小动态更新 SVG `<line>` 的 `x2` 属性，并同步更新对应 `<text>` 标签的位置。
  - 断裂动画：当 $\omega > 10$ 时，计算偏移量 `delta = (omega - 10) * 20`，将 A、B 及相关向量的 x 坐标统一加上 `delta`，并隐藏 $T_{OB}$ 向量，将 OB 绳分为两段绘制。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-slider`, `scene1-vec-fa`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
