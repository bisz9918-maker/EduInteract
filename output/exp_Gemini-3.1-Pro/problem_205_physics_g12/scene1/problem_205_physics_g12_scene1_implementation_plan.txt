[图示主题与整合说明]
- 本图示主题：物块在复合场中的运动及关键点受力分析
- 整合的步骤/概念：整合了初始场景、最高点L临界受力、M到L过程位移关系、P点受力及M到P过程位移关系。
- 教学价值：教师可以通过分步导航，先引导学生分析最高点L的临界条件，再通过动能定理建立M到L的方程；接着切换到P点进行受力分析，最后建立M到P的动能定理方程。图示清晰地分离了不同阶段的受力和位移，避免了传统静态图上信息过载和重叠的问题。

[分步序列]
- 初始状态（步骤0）：显示电场线、轨道、M点物块及基础标签（E, M, N, P, L, O, R, m）。
- 步骤1（L点临界条件）：保持步骤0，新增L点物块，显示向下的重力 $mg$、向左的速度 $v_L$，以及临界条件文本 $N=0$。
- 步骤2（M到L动能定理）：保持步骤1，新增M到L的轨迹高亮，显示水平位移 $S$ 和竖直位移 $2R$。在MN段显示虚影物块及电场力 $qE$、摩擦力 $f$。
- 步骤3（P点受力分析）：隐藏步骤1和2的新增元素。保持步骤0，新增P点物块，显示向右的弹力 $N_P$、向左的电场力 $qE$、向上的速度 $v_P$。
- 步骤4（M到P动能定理）：保持步骤3，新增M到P的轨迹高亮，显示水平位移 $S+R$ 和竖直位移 $R$。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：在SVG底部（y=460区域）居中放置两个按钮，用于切换步骤0至4。
- 教师操作流程：教师首先展示题目初始状态；点击下一步，分析物块到达最高点L的临界受力；再次点击，展示M到L的运动过程并列出动能定理方程；随后点击下一步，清空L点信息，转而分析P点的受力情况；最后一步展示M到P的运动过程，辅助列出第二个动能定理方程。

[技术实现]
- JS 库选择及原因：原生 SVG。本场景主要由几何线条、箭头和文本构成，SVG 在处理矢量图形、箭头标记（marker）和精确坐标定位方面最为高效，且易于通过 DOM 操作控制各步骤元素的显隐。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×450]
  - 背景：贯穿的水平电场线
  - 左侧：半圆轨道及P、L点受力分析
  - 右侧：水平轨道及M点
  - 中间偏右：竖直位移标注线（x=380）
  - 下方：水平位移标注线（y=380, y=420）
  [控件栏 800×50]
  - 居中：◀上一步 | 下一步▶
  ```
- 关键实现要点：
  - 使用 `<marker>` 定义箭头，方便在 `<line>` 和 `<path>` 中复用。
  - 将不同步骤的元素分组到不同的 `<g>` 标签中（如 `id="scene1-step1-group"`），通过修改 `display` 属性实现状态切换。
  - 轨迹高亮使用 `<path>`，设置 `stroke-width: 7`, `stroke: #1565c0`, `opacity: 0.3`，并使用 `fill="none"`。
  - 所有的坐标必须严格按照【布局坐标表】执行，确保零重叠。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀，例如 `scene1-btn-prev`, `scene1-step1-group`。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
