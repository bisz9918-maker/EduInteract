[图示主题与整合说明]
- 本图示主题：A、B两球在匀强电场中的加速与弹性碰撞过程
- 整合的步骤/概念：电场环境、带电小球的匀加速运动、完全弹性碰撞（等质量速度交换）、匀速与匀加速的追及问题。
- 教学价值：教师可通过分步按钮，将连续复杂的物理过程拆解为关键节点（两次碰撞前后），清晰展示速度的突变和位移的比例关系（$L$ 与 $4L$），帮助学生直观理解物理规律。

[视觉元素清单]
- 匀强电场：两条贯穿左右的黑色实线，末端带箭头，标签 $E$。
- 运动基准线：灰色虚线（#888888）。
- 质点A：红色（#c62828）圆形，包含上方标签 "m, +q" 和下方标签 "A"。
- 质点B：蓝色（#1565c0）圆形，包含上方标签 "m" 和下方标签 "B"。
- 速度向量：附着在小球上方的水平向右箭头，A球为红色，B球为蓝色。标签如 $v_1, 2v_1$。
- 位移标注：黑色尺寸线（两端有垂直短线），下方居中标注 $L$ 和 $4L$。

[分步序列]
- 初始状态（步骤0）：A球在 x=100，B球在 x=200。显示 $L$ 标注。无速度箭头。
- 步骤1（第一次碰撞前）：A球移动至 x=180，B球在 x=200。A球显示红色速度箭头（长40，标签 $v_1$），B球无速度。
- 步骤2（第一次碰撞后）：A球在 x=180，B球在 x=200。A球速度消失，B球显示蓝色速度箭头（长40，标签 $v_1$）。
- 步骤3（第二次碰撞前）：A球移动至 x=580，B球移动至 x=600。显示 $4L$ 标注。A球显示红色速度箭头（长80，标签 $2v_1$），B球显示蓝色速度箭头（长40，标签 $v_1$）。
- 步骤4（第二次碰撞后）：A球在 x=580，B球在 x=600。A球显示红色速度箭头（长40，标签 $v_1$），B球显示蓝色速度箭头（长80，标签 $2v_1$）。

[标签冲突检查]
- A球与B球属性标签：碰撞时两球圆心相距20px（x=180与200）。A球标签向左偏（x-10），B球标签向右偏（x+10），两者间距至少40px，**无冲突**。
- A球与B球速度箭头：A球速度箭头固定在 y=170，B球速度箭头固定在 y=130。两者垂直错开40px，即使在追及过程中 x 坐标重合，也**绝不冲突**。
- 速度标签与箭头：标签统一放置在箭头上方10px处，不会压到箭头本身，**无冲突**。
- 位移标注与小球：小球在 y=230，位移标注在 y=275，垂直错开45px，**无冲突**。

[交互方案]
- 交互类型：分步按钮导航。
- 控件说明：底部控件区（y=450）包含三个元素：
  1. `scene1-btn-prev`：◀ 上一步
  2. `scene1-step-text`：当前状态文本（如“步骤 1/4：第一次碰撞前”）
  3. `scene1-btn-next`：下一步 ▶
- 教师操作流程：教师点击“下一步”逐步推进物理过程，配合动画讲解每次碰撞前后的速度交换和位移关系。可随时点击“上一步”回退。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。图形简单，原生 SVG 配合 CSS `transition` 即可实现平滑的位移动画。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×440]
  --------------------------------- (y=80) 电场线 E
         v1(蓝)
         --->
             2v1(红)
             ------>
       m,+q    m
        A      B
  - - - ● - - -● - - - - - - - - - - (y=230) 基准线
        |-- L -|------- 4L -------|  (y=275) 位移标注
  --------------------------------- (y=380) 电场线 E
  
  [控件栏 800×60] (y=440~500)
       [◀ 上一步]  状态文本  [下一步 ▶]
  ```
- 关键实现要点：
  - 使用 `<g>` 标签将小球、属性标签、名称标签组合在一起，通过修改 `<g>` 的 `transform="translate(x, 0)"` 来实现整体移动。
  - 为 `<g>` 添加 `style="transition: transform 1s ease-in-out"` 实现平滑动画。
  - 速度箭头和位移标注根据 `currentStep` 的值控制 `opacity`（0 或 1），同样使用 `transition: opacity 0.3s` 实现淡入淡出。
  - 数学符号（如 $v_1$）直接使用 SVG `<text>` 配合 `<tspan baseline-shift="sub">` 实现，无需引入外部库。
  - ID 命名规范：所有元素 ID 必须以 `scene1-` 开头。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
