[图示主题与整合说明]
- 本图示主题：A、B两球运动的 v-t 图像及相遇规律
- 整合的步骤/概念：展示A球和B球在多次碰撞过程中的速度-时间图线，利用图线下面积表示位移，直观揭示“面积相等即相遇”的几何规律，并推导第n次碰撞的时间和位移通式。
- 教学价值：教师可以通过逐步绘制 v-t 图像，引导学生观察每次碰撞前后速度的交换，以及利用面积相等快速求解追及相遇的时间，避免繁琐的运动学公式计算，最后总结出通式规律。

[视觉元素清单]
- 坐标轴：v轴和t轴，黑色 #000000，带箭头。
- 刻度线及标签：t轴上的 t1, 3t1, 5t1, 7t1；v轴上的 v1, 2v1, 3v1, 4v1。黑色，字号 14px。
- 辅助虚线：连接各个关键坐标点到坐标轴的灰色虚线 #888888，stroke-dasharray="4,4"。
- A球图线：红色 #c62828，stroke-width="3"。
- B球图线：蓝色 #1565c0，stroke-width="3"。
- 面积高亮：A球面积填充 #c62828，透明度 20%；B球面积填充 #1565c0，透明度 20%。重叠部分自然混合。
- 面积标签：L, 4L, 8L, 12L，黑色加粗，字号 16px。
- 规律总结文本：黑色，字号 16px，显示第n次碰撞的通式。
- 图例：红线代表“A球”，蓝线代表“B球”。

[分步序列]
- 初始状态（步骤0）：显示坐标轴、原点、图例。不显示任何图线和刻度。等待教师点击。
- 步骤1（第一次碰撞）：
  - 显示 t1, v1 刻度及对应的辅助虚线。
  - 绘制 0~t1 段的A图线和B图线。
  - 高亮A图线下的三角形面积，显示标签 L。
- 步骤2（第二次碰撞）：
  - 显示 3t1, 2v1 刻度及对应的辅助虚线。
  - 绘制 t1~3t1 段的A图线和B图线。
  - 高亮该段A和B图线下的面积（红蓝半透明叠加），显示标签 4L。
- 步骤3（第三次碰撞）：
  - 显示 5t1, 3v1 刻度及对应的辅助虚线。
  - 绘制 3t1~5t1 段的A图线和B图线。
  - 高亮该段面积（红蓝半透明叠加），显示标签 8L。
- 步骤4（规律总结）：
  - 显示 7t1, 4v1 刻度及对应的辅助虚线。
  - 绘制 5t1~7t1 段的A图线和B图线。
  - 高亮该段面积（红蓝半透明叠加），显示标签 12L。
  - 在左上角空白处显示通式文本（分四行）：
    “第 n 次碰撞 (n≥2):”
    “碰撞时刻: t = (2n-1)t₁”
    “该段位移: Δx = 4(n-1)L”
    “总位移: x = (2n²-2n+1)L”

[交互方案]
- 交互类型：分步按钮导航。
- 控件说明：在 SVG 内部底部（y=450~490 区域）居中放置两个按钮：“◀ 上一步” 和 “下一步 ▶”。
- 教师操作流程：教师首先展示空白坐标系，讲解题意；点击“下一步”展示第一次碰撞前的运动和位移；再次点击展示第二次碰撞前的运动，引导学生观察面积重叠（位移相等）即代表相遇；继续点击展示第三次碰撞，验证规律；最后点击展示通式，完成教学闭环。教师可随时点击“上一步”回退。

[技术实现]
- JS 库选择及原因：原生 SVG。图示完全由直线、多边形和文本构成，SVG 能够提供最清晰的渲染效果，且非常容易通过 DOM 操作实现分组显示/隐藏和半透明叠加。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  (左上角：规律公式文本)
  (右上角：图例)
  (中央：v-t坐标系及阶梯状图线)
  [控件栏] (绝对定位在底部 y=460 处，包含上一步/下一步按钮)
  ```
- 关键实现要点：
  - 将每个步骤的视觉元素（线段、多边形、文本、辅助线）放入对应的 `<g>` 标签中，如 `<g id="scene2-step1">`。
  - 维护一个 `currentStep` 变量（初始为 0，最大为 4）。
  - 编写 `updateScene()` 函数，根据 `currentStep` 的值，将对应步骤的 `<g>` 标签设置为 `display: block`，其余设置为 `display: none`。
  - 按钮点击事件中更新 `currentStep` 并调用 `updateScene()`，同时处理按钮的禁用状态（如 step=0 时禁用“上一步”）。
  - ID 命名规范：所有交互元素 ID 必须以 `scene2-` 为前缀，避免跨场景污染。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
  - 文本中的下标（如 t₁）使用 `<tspan baseline-shift="sub" font-size="0.8em">1</tspan>` 实现，确保跨浏览器兼容性。
