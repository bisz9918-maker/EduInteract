[图示主题与整合说明]
- 本图示主题：滑块A与木板B的相对运动及位移几何关系
- 整合的步骤/概念：B静止的假设检验、A与B的真实受力分析、共速状态下的运动过程及位移关系
- 教学价值：教师可通过分步演示，清晰地向学生展示假设法的矛盾之处，随后通过真实的受力分析引导出正确的相对运动过程，最后利用直观的线段图总结出位移的几何关系（$x_A = x_B + L$），帮助学生跨越相对运动的认知障碍。

[分步序列]
- 初始状态（步骤0）：显示地面、初始位置的木板B和滑块A，A上附着向右的蓝色速度矢量 $v_1$。
- 步骤1（假设B静止）：隐藏 $v_1$，显示A受向左的红色摩擦力 $f_1$。A向右滑动至 x=488 处变成半透明虚影。上方出现灰色虚线标注 "3.6m"，并在虚影上方弹出红色矛盾提示 "3.6m > 3m, 滑出木板!"。
- 步骤2（真实受力）：清除虚影、3.6m标注和矛盾提示。A回到初始位置。保留A上的 $f_1$，同时在B上显示向右的 $f_1'$ 和向左的 $f_2$（均为红色矢量）。
- 步骤3（相对运动）：隐藏所有受力矢量。A和B同时向右运动，B加速、A减速，最终在 B(320,220) 和 A(540,190) 处停止（A刚好在B的最右端）。在A右侧出现蓝色速度矢量 $v_{共}$。
- 步骤4（位移关系）：保持步骤3的最终位置。向下展开三条灰色竖直虚线（x=200, 320, 560）。依次绘制水平双向箭头：先画 $x_B$（蓝色，200-320），再画 $L=3m$（绿色，320-560），最后在下方画 $x_A$（蓝色，200-560），直观呈现 $x_A = x_B + L$。

[交互方案]
- 交互类型：分步按钮导航
- 控件说明：在 SVG 底部 (y=460) 居中放置两个按钮：「◀ 上一步」和「下一步 ▶」，以及步骤指示器（如 "1 / 5"）。
- 教师操作流程：教师点击“下一步”逐步推进逻辑：先展示初始状态 -> 演示假设法的矛盾 -> 分析真实受力 -> 播放相对运动动画 -> 总结位移几何关系。可随时点击“上一步”回退重新讲解。

[技术实现]
- JS 库选择及原因：原生 SVG + CSS Transition。SVG 适合绘制几何图形和矢量箭头，原生 JS 控制 class 或属性配合 CSS transition 即可实现流畅的步骤切换和位移动画，无需引入重型库。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  (50,250) ---------------------------------------- (750,250) 地面
           [ A ]
           [       B       ]
  
           <-- xB --> <------- L ------->
           <------------- xA ------------>
  
  [控件栏 y=460: ◀ 上一步 | 步骤 1/5 | 下一步 ▶]
  ```
- 关键实现要点：
  - 状态机设计：定义 `currentStep` (0-4)，每次步骤切换时调用 `renderStep(step)` 函数。
  - 动画控制：步骤1和步骤3包含位移动画，可使用 CSS `transition: transform 1s ease` 实现平滑移动。
  - 坐标系：SVG 内部坐标系直接对应布局坐标表，无需复杂转换。
  - 箭头绘制：使用 `<marker>` 定义箭头样式，方便复用于速度和受力矢量。
  - ID 命名规范：所有元素 ID 必须以 `scene2-` 为前缀（如 `scene2-blockA`, `scene2-btn-next`）。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
