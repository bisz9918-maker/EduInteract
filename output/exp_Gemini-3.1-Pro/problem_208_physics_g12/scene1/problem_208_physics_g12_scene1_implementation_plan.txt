[图示主题与整合说明]
- 本图示主题：带电粒子在正交电磁场中的匀速直线运动（速度选择器）
- 整合的步骤/概念：极板结构、电场线、磁场方向、粒子的受力分析（电场力与洛伦兹力平衡）
- 教学价值：教师可以通过分步展示，引导学生逐步完成受力分析，理清二力平衡的逻辑关系，并直观看到粒子在平衡状态下的匀速直线运动轨迹。

[视觉元素清单]
- 极板及接线柱：黑色 `#000000`，线宽 4px（极板）和 2px（接线柱）。
- 中心虚线：黑色 `#000000`，线宽 2px，虚线样式 `5,5`。
- 电场线 E：灰色 `#888888`，虚线箭头，向下。
- 磁场 B0：灰色 `#888888`，用 `×` 表示垂直纸面向里。
- 离子：红色 `#c62828` 填充，内部白色 `+` 号。
- 速度矢量 v0：蓝色 `#1565c0`，水平向右箭头。
- 电场力 FE：绿色 `#2e7d32`，竖直向下箭头。
- 洛伦兹力 FB：绿色 `#2e7d32`，竖直向上箭头。
- 标签：使用 SVG `<text>`，下标使用 `<tspan dy="4" font-size="0.7em">` 实现（如 `v<tspan dy="4" font-size="0.7em">0</tspan>`）。

[分步序列]
- 初始状态（步骤0）：显示极板、接线柱、中心虚线、电场线 E 及标签。离子位于 (290, 250)，显示速度矢量 v0 及标签。隐藏磁场 B0、电场力 FE、洛伦兹力 FB。离子静止。
- 步骤1：点击「下一步」→ 显示电场力 FE 矢量及标签。
- 步骤2：点击「下一步」→ 显示磁场 B0 阵列及标签。
- 步骤3：点击「下一步」→ 显示洛伦兹力 FB 矢量及标签。延迟 0.5 秒后，播放离子（连同其上的所有矢量）从 x=290 匀速平移至 x=600 的动画，耗时 2 秒。

[标签冲突检查]
- 电场标签 E (210, 330) 与最左侧电场线 (240, 160~340)：间距 30px，无冲突。
- 磁场标签 B0 (190, 180) 与最左侧磁场× (220, 180)：间距 30px，无冲突。
- 速度标签 v0 (355, 235) 与磁场× (340, 220)：间距约 21px，无冲突。
- 电场力标签 FE (305, 295) 与磁场× (280, 280)：间距约 29px，无冲突。
- 洛伦兹力标签 FB (305, 205) 与磁场× (280, 220)：间距约 29px，无冲突。
- 结论：所有标签均已错开，无重叠。动画过程中标签随离子平移，由于电场线和磁场阵列是均匀分布的，且标签位于矢量末端附近，不会与背景元素产生严重遮挡。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：在 SVG 内部底部（y=450~490）放置两个按钮。
- 教师操作流程：教师首先介绍初始的电场环境和入射粒子；点击下一步，引导学生分析粒子受到的电场力；再次点击，引入磁场；最后点击，分析洛伦兹力并得出二力平衡结论，观察粒子匀速直线穿过极板的动画。

[技术实现]
- JS 库选择及原因：原生 SVG 和原生 JavaScript。场景主要由基础几何图形和简单的平移动画组成，原生 SVG 即可完美胜任，无需引入额外库，保证加载速度和兼容性。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  +------------------------------------------------+
  |                                                |
  |          +                                     |
  |      ==========(上极板)==========              |
  |  B0×   ×   ×   ×   ×   ×   ×                   |
  |      |   |   |   |   |                         |
  | - - -O- -|- -|- -|- -|- - - - - - - -          |
  |      |   |   |   |   |                         |
  |  E↓  ×   ×   ×   ×   ×   ×   ×                 |
  |      ==========(下极板)==========              |
  |          -                                     |
  |                                                |
  |             [上一步] [下一步]                  |
  +------------------------------------------------+
  ```
- 关键实现要点：
  - 使用 `<g id="scene1-ion-group">` 将离子、速度矢量、力矢量及其标签组合在一起，便于统一控制平移。
  - 状态机：使用 `currentState` 变量记录当前步骤（0~3）。每次状态改变时，更新各元素的 `opacity`。
  - 动画实现：在步骤 3 时，通过修改 `ion-group` 的 `style.transform` 属性（如 `translate(600px, 250px)`），配合 `style.transition = 'transform 2s linear'` 实现平滑动画。初始状态和回退时，将其设为 `translate(290px, 250px)` 并清除 transition。
  - ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-btn-next`, `scene1-fe-group`）。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
