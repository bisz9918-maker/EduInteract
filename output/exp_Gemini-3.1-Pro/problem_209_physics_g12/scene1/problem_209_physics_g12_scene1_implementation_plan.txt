[图示主题与整合说明]
- 本图示主题：v-t图像分析与加速度求解
- 整合的步骤/概念：v-t图像的展示、上滑阶段加速度的计算、下滑阶段加速度的计算
- 教学价值：教师可以通过分步展示，引导学生观察v-t图像中不同线段的斜率含义，并结合已知坐标点推导上滑和下滑阶段的加速度大小，帮助学生建立图像与物理公式之间的联系。

[分步序列]
- 初始状态（步骤0）：
  - 显示完整的坐标轴、辅助线、文本标签。
  - 上滑图线和下滑图线均为黑色，线宽 2px。
  - 隐藏所有公式文本。
  - 按钮状态：「上一步」禁用，「下一步」启用。
- 步骤1（上滑阶段）：
  - 触发：点击「下一步」。
  - 视觉变化：上滑图线变为红色 (#c62828)，线宽加粗至 4px。
  - 出现元素：在右侧 (550, 120) 处淡入显示上滑加速度公式 $a_1 = rac{v_0}{t_1}$，颜色为红色。
  - 按钮状态：「上一步」启用，「下一步」启用。
- 步骤2（下滑阶段）：
  - 触发：点击「下一步」。
  - 视觉变化：保持上滑图线高亮及公式显示；下滑图线变为蓝色 (#1565c0)，线宽加粗至 4px。
  - 出现元素：在右侧 (550, 200) 处淡入显示下滑加速度公式 $a_2 = rac{v_1}{3t_1 - t_1} = rac{v_1}{2t_1}$，颜色为蓝色。
  - 按钮状态：「上一步」启用，「下一步」禁用。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：在 SVG 画布底部 (y=450) 居中放置两个按钮，分别用于控制步骤的前进和后退。
- 教师操作流程：
  1. 初始展示完整图像，讲解题目背景和坐标轴含义。
  2. 点击「下一步」，引导学生关注 0~t1 阶段，结合高亮的红线和右侧公式，讲解上滑加速度的计算。
  3. 再次点击「下一步」，引导学生关注 t1~3t1 阶段，结合高亮的蓝线和右侧公式，讲解下滑加速度的计算。
  4. 可随时点击「上一步」回退，进行对比或复习。

[技术实现]
- JS 库选择及原因：
  - 原生 SVG：用于绘制坐标轴、图线、辅助线和简单文本，性能好且易于控制样式。
  - MathJax (CDN)：用于高质量渲染右侧的加速度分数公式。
- 画布尺寸：800 × 500 px，相对定位容器。
- 布局草图：
  ```
  [图示区 800x500]
  +---------------------------------------------------+
  |  v                                                |
  |  ^                                                |
  |  |                                                |
  | v0 \                  [公式区]                    |
  |  |  \                 a1 = v0 / t1 (红)           |
  |  |   \                                            |
  |  |    \               a2 = v1 / 2t1 (蓝)          |
  |  |     \                                          |
  | 0+------\---------+---------------------> t       |
  |  |       t1        \ 3t1                          |
  |  |                  \                             |
  |  |                   \                            |
  |-v1 - - - - - - - - - -+                           |
  |                                                   |
  |                                                   |
  |            [◀上一步]  [下一步▶]                   |
  +---------------------------------------------------+
  ```
- 关键实现要点：
  - 状态机设计：定义 `currentStep` 变量 (0, 1, 2)，编写 `updateScene(step)` 函数，根据 step 值统一设置所有元素的样式和显示状态。
  - 动画过渡：对 SVG 线条的 `stroke` 和 `stroke-width` 属性，以及公式容器的 `opacity` 属性添加 CSS `transition`，实现平滑的视觉过渡。
  - 公式渲染：在 HTML 中预先写好 MathJax 格式的公式，页面加载后调用 `MathJax.typesetPromise()` 进行渲染。
- ID 命名规范：所有交互元素和需控制样式的元素均以 `scene1-` 为前缀，例如 `scene1-line-up`、`scene1-formula-down`、`scene1-btn-next`。
- IIFE 隔离：所有 JavaScript 逻辑封装在 `(function() { ... })()` 中，避免全局变量污染。
