场景导航：Scene 1

将C棒、Fe棒平行插人饱和NaCl溶液中（如图所示）．下列叙述符合事实的是（ ）
A．断开 K2，闭合 K1时，Fe 电极反应为：2 H+ + 2e- = H2↑
B．断开 K2，闭合 K1时，C电极反应为：2Cl- - 2e- = Cl2↑
C．断开 K1，闭合 K2时，Fe 电极反应为：Fe - 2e- = Fe2+
D．断开 K1，闭合 K2时，C电极反应为：2Cl- - 2e- = Cl2↑

题目分析与整体讲解思路：

本题考查电化学基础知识，核心在于判断不同开关状态下构成的装置类型（原电池或电解池），并据此写出正确的电极反应式。

讲解时，可分为两步引导学生：

  1. 分析 A、B 选项（原电池模式）： 当闭合 K1、断开 K2 时，装置没有外接电源，C棒、Fe棒和饱和NaCl溶液构成原电池。由于Fe的活泼性大于C，Fe作负极，C作正极。饱和NaCl溶液呈中性，发生吸氧腐蚀。
  2. 分析 C、D 选项（电解池模式）： 当闭合 K2、断开 K1 时，装置接入了直流电源，构成电解池。根据电源符号，左侧为正极，右侧为负极。因此C棒接正极为阳极，Fe棒接负极为阴极。溶液中的氯离子在阳极放电，水中的氢离子在阴极放电。

图示规划说明：

设计一个包含三个步骤的交互图示。从初始状态开始，分别演示闭合 K1 和闭合 K2 时的电路连通情况、电子流向以及电极反应。通过高亮和动画，帮助学生直观区分原电池和电解池的工作原理。

0 / 2 : 初始状态

教学说明与讲解要点：

  1. 引导观察初始状态： 让学生明确装置的基本构成：左边是惰性电极（碳棒），右边是活性电极（铁棒），电解质是中性的饱和食盐水。注意观察 K2 所在支路的电源正负极（左正右负）。
  2. 讲解步骤 1（闭合 K1）： 提问：闭合 K1 时，构成了什么装置？（原电池）。分析：铁比碳活泼，所以 Fe 是负极，失去电子发生氧化反应：$Fe - 2e^- = Fe^{2+}$。C 是正极。纠错：因为是中性溶液（饱和 NaCl），所以发生的是吸氧腐蚀，正极反应为 $O_2 + 2H_2O + 4e^- = 4OH^-$。结论：选项 A 中 Fe 电极反应错误（写成了析氢腐蚀），选项 B 中 C 电极反应错误。
  3. 讲解步骤 2（闭合 K2）： 提问：断开 K1，闭合 K2 时，构成了什么装置？（电解池）。分析：根据电源符号，C 棒连接正极，作阳极；Fe 棒连接负极，作阴极。推导：阳极（C棒）处溶液中的阴离子 $Cl^-$ 失电子放电，反应为 $2Cl^- - 2e^- = Cl_2\uparrow$；阴极（Fe棒）处溶液中的阳离子 $H^+$ 得电子放电（或写成水放电），反应为 $2H_2O + 2e^- = H_2\uparrow + 2OH^-$。注意，阴极是受保护的，Fe 本身不参与反应。结论：选项 C 中 Fe 电极反应错误，选项 D 中 C 电极反应正确。

最终解答：

正确答案为 D。
