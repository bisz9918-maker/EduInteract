[图示主题与整合说明]
- 本图示主题：不同开关状态下的电化学装置（原电池与电解池）原理演示
- 整合的步骤/概念：展示初始装置状态，闭合 K1 构成的原电池回路及反应（吸氧腐蚀），闭合 K2 构成的电解池回路及反应（电解食盐水）。
- 教学价值：教师可通过分步演示，清晰对比原电池和电解池的回路差异、电子流向及电极反应，帮助学生直观理解选项 A、B、C、D 的正误。

[分步序列]
- 初始状态（步骤0）：
  - 显示烧杯、溶液、电极、所有导线、电源。
  - K1 断开，K2 断开。
  - 隐藏极性标签、反应式、高亮线和电子流向。
- 步骤1（闭合 K1，原电池）：
  - K1 闭合，K2 断开。
  - 高亮上支路及两侧垂直导线（绿色）。
  - 电子流向：蓝色电子从 Fe 极出发，沿右侧导线向上，经上支路向左，再沿左侧导线向下到达 C 极。
  - 左侧极性标签显示 "正极"，右侧显示 "负极"。
  - 左侧反应式显示 "O₂ + 2H₂O + 4e⁻ = 4OH⁻"，右侧显示 "Fe - 2e⁻ = Fe²⁺"。
- 步骤2（闭合 K2，电解池）：
  - K1 断开，K2 闭合。
  - 高亮下支路及两侧垂直导线（红色）。
  - 电子流向：蓝色电子从 C 极出发向上，经下支路向右到达电源正极；同时从电源负极出发向右，沿右侧导线向下到达 Fe 极。
  - 左侧极性标签显示 "阳极"，右侧显示 "阴极"。
  - 左侧反应式显示 "2Cl⁻ - 2e⁻ = Cl₂↑"，右侧显示 "2H₂O + 2e⁻ = H₂↑ + 2OH⁻"。

[交互方案]
- 交互类型：分步按钮导航
- 控件说明：在 SVG 底部（y=450~490）放置居中的控制栏，包含 "◀ 上一步" 按钮、状态指示文本（如 "0 / 2 : 初始状态"）和 "下一步 ▶" 按钮。
- 教师操作流程：教师首先展示初始断路状态，讲解装置构成；点击下一步闭合 K1，引导学生分析原电池的电极和反应，判断选项 A、B；再点击下一步切换到闭合 K2，分析电解池的电极和反应，判断选项 C、D。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。SVG 非常适合绘制清晰的电路图和几何图形，且方便通过 JS 控制电子流动动画。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×450]
    (K1) ----/ ----
    (K2) --/ --+|--
     |          |
    [C]        [Fe]
  |==================|
  |   饱和NaCl溶液   |
  |__________________|
  [控件栏 800×50，包含 上一步/下一步 按钮]
  ```
- 关键实现要点：
  - 使用 SVG `<path>` 绘制导线，高亮效果通过在原导线下方叠加一条较粗的带颜色 `<path>` 实现，通过 CSS `opacity` 控制显示/隐藏。
  - 电子流动动画：使用 JS 动态更新 SVG `<circle>` 的位置，或者使用 CSS `stroke-dasharray` 动画实现虚线流动效果。
  - 反应式文本：推荐使用 HTML `<div>` 绝对定位覆盖在 SVG 上方，方便使用 `<sub>` 和 `<sup>` 标签渲染化学式的上下标。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-btn-next`, `scene1-highlight-k1`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
