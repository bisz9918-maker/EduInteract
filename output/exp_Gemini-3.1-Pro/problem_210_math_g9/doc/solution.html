题目分析：
本题考查动图形问题中的函数图像。关键在于分析三角形在穿过正方形的过程中，重叠部分形状的变化，并据此求出面积 $S$ 关于时间 $t$ 的分段函数解析式。由于三角形和正方形边长均为1，设运动速度为1，则时间 $t$ 在数值上等于三角形右顶点的位移。整个过程可分为四个阶段，每个阶段重叠部分的几何形状不同，导致面积函数的解析式和图像凹凸性发生变化。

整体讲解思路：

  1. 引导学生观察三角形穿过正方形的完整物理过程，识别出四个不同的几何阶段（以三角形的顶点进入或离开正方形边界为临界点）。
  2. 针对每个阶段，分析重叠部分的几何形状（直角三角形或四边形）。
  3. 利用面积公式或割补法，列出每个阶段的 $S(t)$ 表达式，重点分析二次项系数的正负，从而判断抛物线的开口方向（即图像的凹凸性）。
  4. 结合解析式，排除错误选项，得出正确答案。

图示规划说明：

本图示的教学说明：

引入与演示：首先向学生展示初始状态（$t=0$），然后缓慢拖动滑块，让学生观察上方几何图形的运动，建立直观的物理过程印象。

第一阶段 ($0 \le t \le 0.5$)：将滑块停在 $0.25$ 左右。引导学生观察重叠部分是一个直角三角形。

  1. 指出底边长为 $t$，由于等边三角形内角为 $60^\circ$，高为 $\sqrt{3}t$。
  2. 推导面积 $S =

rac{1}{2} \cdot t \cdot \sqrt{3}t =
rac{\sqrt{3}}{2}t^2$。

  1. 强调这是一个二次函数，且二次项系数为正，因此下方图像是一段开口向上的抛物线。

第二阶段 ($0.5 < t \le 1$)：将滑块拖过 $0.5$。提问重叠部分的形状变化（变成了四边形）。

  1. 讲解此时直接计算四边形面积较复杂，可采用“割补法”：重叠面积 = 三角形总面积 - 留在左侧外部的小直角三角形面积。
  2. 推导外部小三角形底边为 $1-t$，面积为 $

rac{\sqrt{3}}{2}(1-t)^2$。

  1. 得出 $S =

rac{\sqrt{3}}{4} -
rac{\sqrt{3}}{2}(1-t)^2$。

  1. 强调二次项系数变为负，图像转为开口向下的抛物线。

对称性分析：继续拖动滑块到 $t>1$ 的阶段。引导学生发现，三角形穿出正方形的过程与进入的过程是完全对称的。因此，$1 < t \le 1.5$ 对应开口向下的抛物线，$1.5 < t \le 2$ 对应开口向上的抛物线。

总结图像特征：结合下方完整的 $S-t$ 图像，总结曲线的凹凸性变化（上凹 -> 下凹 -> 下凹 -> 上凹），这与选项D的钟形曲线完全吻合。

总结：

本题是一道经典的动图形面积函数问题。解题的核心在于准确识别几何图形在运动过程中的临界点（即三角形顶点与正方形边界相交的时刻），并将整个运动过程划分为若干个几何特征一致的阶段。
