[图示主题与整合说明]
- 本图示主题：全等三角形已知条件推导与判定选项验证
- 整合的步骤/概念：整合了已知条件的提取、隐含内错角的推导，以及四个选项（SAS, 线段加减转SAS, ASA, SSA）的逐一验证过程。
- 教学价值：教师可通过分步导航，引导学生先提取题干中的已知条件，再逐一分析四个选项是否能构成全等三角形的判定定理，特别是最后通过动态圆弧直观展示 SSA 的不确定性，帮助学生突破易错点。

[视觉元素清单]
- 基础图形：黑色 (#000000) 线段绘制四边形 ABCD、对角线 BD、线段 AE、CF。线宽 2px。
- 标签文本：黑色，字号 18px，斜体（数学点名）。
- 已知条件高亮（步骤1起）：
  - AB, CD 边：红色 (#c62828)，线宽 4px。
  - 平行标记（>）和相等标记（|）：红色 (#c62828)。
  - ∠ABE, ∠CDF：蓝色 (#1565c0) 扇形填充（透明度 0.2）及边框（线宽 2px）。
- 选项B高亮（步骤2）：BE, FD 边，绿色 (#2e7d32)，线宽 4px。
- 选项C高亮（步骤3）：BF, DE 边，绿色 (#2e7d32)，线宽 3px，分别在 BD 线段的下方和上方偏移 5px 绘制，避免完全重叠。
- 选项D高亮（步骤4）：∠1, ∠2，绿色 (#2e7d32) 扇形填充（透明度 0.2）及边框。
- 选项A高亮（步骤5）：
  - AE, CF 边：橙色 (#f57c00)，线宽 4px。
  - 备选边 AE'：橙色虚线 (#f57c00)，线宽 3px，从 (280, 130) 到 (400, 250)。
  - 轨迹圆弧：橙色虚线，以 A 为圆心，从 E(304, 298) 画弧到 E'(400, 250)。
  - 歧义三角形填充：△ABE 和 △ABE' 填充橙色 (#f57c00)，透明度 0.15。

[分步序列]
- 初始状态（步骤0）：显示基础图形（ABCD, BD, AE, CF）和所有基础标签。文本区显示：“本题探讨全等三角形的判定条件。请点击「下一步」开始推导。”
- 步骤1（已知条件）：显示 AB, CD 红色高亮及标记，显示 ∠ABE, ∠CDF 蓝色高亮。文本区显示：“已知条件：AB=CD (边S)，且 AB∥CD 推出内错角 ∠ABE=∠CDF (角A)。”
- 步骤2（验证选项B）：保持步骤1，显示 BE, FD 绿色高亮。文本区显示：“选项B：添加 BE=FD，结合已知条件构成 SAS（边角边），判定 △ABE ≌ △CDF 成立。”
- 步骤3（验证选项C）：保持步骤1，显示 BF, DE 绿色偏移线。文本区显示：“选项C：添加 BF=DE，两边同时减去 EF 得到 BE=FD，同样构成 SAS，判定成立。”
- 步骤4（验证选项D）：保持步骤1，显示 ∠1, ∠2 绿色高亮。文本区显示：“选项D：添加 ∠1=∠2，结合已知条件构成 ASA（角边角），判定成立。”
- 步骤5（验证选项A）：保持步骤1，显示 AE, CF 橙色高亮，展示 AE' 虚线、轨迹圆弧及 E' 标签，填充两个可能的三角形。文本区显示：“选项A：添加 AE=CF，构成 SSA（边边角）。如图，AE=AE'，存在两种可能的三角形，无法唯一判定全等。”

- 标签"E"(304, 318) 与 标签"E'"(400, 270)：间距 > 100px，无冲突。
- 标签"F"(496, 182) 与 标签"2"(529, 316)：间距 > 130px，无冲突。
- 标签"1"(271, 184) 与 线段AE/AB：已精确计算角度，位于角平分线附近，无冲突。
- 标签"2"(529, 316) 与 线段CF/CD：已精确计算角度，位于角平分线附近，无冲突。
- 结论：所有标签均已根据周围线段走向进行了反向偏移，相互之间间距充足（≥ 30px），无任何重叠冲突。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - `scene1-btn-prev`：上一步按钮，回退到上一个逻辑状态。
  - `scene1-btn-next`：下一步按钮，推进到下一个逻辑状态。
  - `scene1-step-indicator`：显示当前步骤进度（如 0 / 5）。
- 教师操作流程：教师首先展示原图，点击下一步引导学生找出隐含的已知条件（平行推内错角）；随后依次点击下一步，逐个分析 B、C、D 选项为何成立；最后一步展示 A 选项的 SSA 陷阱，利用动态出现的圆弧和备选点 E' 强调 SSA 无法判定全等的原因。

[技术实现]
- JS 库选择及原因：原生 SVG。本场景主要由直线、多边形和简单的圆弧组成，原生 SVG 能够完美且清晰地实现，同时方便通过 DOM 操作控制各元素的显示与隐藏。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  +--------------------------------------------------+
  |                                                  |
  |        A +-------------------------+ D           |
  |         / \                       / \            |
  |        /   \                     /   \           |
  |       /  1  \ F               E /  2  \          |
  |      /       \                 /       \         |
  |     /         \               /         \        |
  |  B +-------------------------+ C                 |
  |                                                  |
  |  [文本描述区：显示当前步骤的判定定理和结论]      |
  |                                                  |
  |             [◀ 上一步]  0 / 5  [下一步 ▶]        |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  - 状态机设计：定义一个 `currentStep` 变量（0-5），每次点击按钮更新该变量，并调用 `updateState()` 函数。
  - `updateState()` 函数内部：先隐藏所有高亮和辅助元素，然后根据 `currentStep` 的值，按需显示对应的 SVG 元素并更新文本区的 `innerHTML`。
  - 偏移线段实现：步骤3中的 BF 和 DE 采用平行偏移算法，通过计算 BD 向量的法向量，将线段在垂直方向平移 5px，避免与原对角线完全重叠。
  - 圆弧绘制：步骤5的轨迹圆弧使用 SVG `<path>` 的 `A` (elliptical arc) 指令，起点为 E(304, 298)，终点为 E'(400, 250)，半径为 169.7，sweep-flag 设为 0。
- ID 命名规范：所有 DOM 元素 ID 均以 `scene1-` 开头，例如 `scene1-svg`, `scene1-line-ab`, `scene1-text-desc` 等。
- IIFE 隔离：所有 JavaScript 代码包裹在 `(function() { ... })();` 中，避免全局变量污染。
