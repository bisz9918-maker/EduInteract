[视觉元素清单]
- 基础图形：三角形ABC及内部线段DE, DF, EF。主线颜色 #000000，实线，2px。
- 顶点及标签：A, B, C, D, E, F。点为黑色实心圆（r=2），标签为黑色文本（18px）。
- 高亮多边形：5个独立的 `<polygon>` 元素，用于高亮对应的三角形。颜色 #1565c0，填充透明度 0.2，边框 3px。
- 记录列表：右侧文本列表，黑色 18px。结论文本为红色 #d32f2f，24px，加粗。

[分步序列]
- 步骤0（初始）：显示主图（三角形ABC及内部线段），列表区仅显示标题“已找到的三角形：”，无任何高亮。
- 步骤1：主图高亮显示小三角形△ADE，列表区淡入出现“1. △ADE”。
- 步骤2：主图高亮显示小三角形△BDF，列表区淡入出现“2. △BDF”。
- 步骤3：主图高亮显示小三角形△CEF，列表区淡入出现“3. △CEF”。
- 步骤4：主图高亮显示小三角形△DEF，列表区淡入出现“4. △DEF”。
- 步骤5：主图高亮显示大三角形△ABC，列表区淡入出现“5. △ABC”。
- 步骤6（总结）：取消主图的当前高亮，列表区显示全部5项，并淡入出现红色加粗结论“总计：5 个”。

[标签冲突检查]
- A(340,80) 与 D(220,230): 垂直距离 150px，无冲突。
- B(120,400) 与 F(300,400): 水平距离 180px，无冲突。
- C(480,400) 与 F(300,400): 水平距离 180px，无冲突。
- D(220,230) 与 E(420,230): 水平距离 200px，无冲突。
所有标签均向图形外侧偏移（A上，B左下，C右下，D左上，E右上，F下），且相互之间距离充足，无任何重叠风险。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：底部居中放置两个按钮，控制步骤0-6的切换。
- 教师操作流程：教师点击“下一步”，带领学生逐个找出三角形，右侧列表同步记录。
- 附加交互（悬停复习）：在任意步骤，当鼠标悬停在右侧已显示的列表项（如“1. △ADE”）上时，主图对应三角形会高亮显示；鼠标移开时恢复当前步骤的默认高亮状态。这极大方便了教师在总结阶段进行回顾。

[技术实现]
- JS 库选择及原因：原生 SVG。由于全是直线多边形，SVG 的 `<polygon>` 和 `<line>` 标签最适合，且方便通过 DOM 操作实现悬停高亮。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  +-------------------+-----------------+
  |        A          | 已找到的三角形：|
  |       / \         | 1. △ADE         |
  |      D---E        | 2. △BDF         |
  |     / \ / \       | 3. △CEF         |
  |    B---F---C      | 4. △DEF         |
  |                   | 5. △ABC         |
  |                   |                 |
  |                   | 总计：5 个      |
  +-------------------+-----------------+
  [控件栏: ◀上一步  下一步▶]
  ```
- 关键实现要点：
  - 状态机设计：定义 `currentStep` (0-6)。`updateStep()` 函数根据当前步骤控制 5 个高亮多边形和 6 个文本元素的 `opacity` 或 `display`。
  - 悬停联动：为 5 个列表项文本（`<text>` 元素，需设置 `cursor: pointer` 和 `pointer-events: all`）绑定 `mouseenter` 和 `mouseleave` 事件。触发时覆盖默认的高亮显示逻辑。
  - 动画过渡：为高亮多边形和列表文本添加 CSS `transition: opacity 0.3s ease`，使出现和消失更加平滑。
  - ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀，如 `scene1-btn-prev`, `scene1-poly-1`, `scene1-list-1`。
  - IIFE 隔离：所有 JS 代码包裹在 `(function() { ... })()` 中，避免全局变量污染。
