场景导航：Scene 1

题目：如图，在△ABC中，AB、AC的垂直平分线分别交BC于点E、F，若∠BAC=110°，则∠EAF为（ ）
A．35°
B．40°
C．45°
D．50°

题目分析与整体讲解思路：
本题核心考查线段垂直平分线的性质以及三角形内角和定理。解题的关键在于将未知的角度 $\angle EAF$ 与已知角度 $\angle BAC$ 联系起来。

  1. 首先，利用线段垂直平分线的性质（垂直平分线上的点到线段两端点的距离相等），可以得到 $EA = EC$，$FA = FB$。
  2. 根据“等边对等角”，得出 $\angle EAC = \angle C$，$\angle FAB = \angle B$。
  3. 利用三角形内角和定理，由 $\angle BAC = 110^\circ$ 求出底角和 $\angle C + \angle B = 180^\circ - 110^\circ = 70^\circ$。
  4. 经过等量代换，得到 $\angle EAC + \angle FAB = 70^\circ$。
  5. 最后，观察顶点 $A$ 处的角度构成，通过角度的和差关系 $\angle EAF = \angle BAC - (\angle EAC + \angle FAB)$ 即可求出结果。

图示规划说明：
设计一个分步导航的交互图示，将上述逻辑链条拆解为连贯的视觉推导过程。通过高亮颜色区分左右两侧的垂直平分线及其对应的等腰三角形，帮助学生直观理解角度的等量代换关系，最后聚焦于顶点 $A$ 处的角度拆分。

教学讲解建议：

  1. 引入与审题：点击【步骤 0】，引导学生观察图形，明确已知条件是 $\angle BAC = 110^\circ$ 以及两条垂直平分线。
  1. 左侧推导：点击【步骤 1】和【步骤 2】，提问：“垂直平分线能带来什么性质？”引导学生得出 $EA=EC$，进而根据“等边对等角”得出 $\angle EAC = \angle C$。
  1. 右侧推导：点击【步骤 3】和【步骤 4】，同理分析右侧，得出 $FA=FB$，进而得出 $\angle FAB = \angle B$。
  1. 整体代换：点击【步骤 5】，引导学生将视线放回大三角形 $ riangle ABC$ 中。已知顶角 $\angle BAC = 110^\circ$，则底角和 $\angle C + \angle B = 70^\circ$。因为前面的等角代换，所以 $\angle EAC + \angle FAB = 70^\circ$。
  1. 得出结论：点击【步骤 6】，观察顶点 $A$ 处的角度构成。$\angle BAC$ 由 $\angle EAC, \angle EAF, \angle FAB$ 三部分组成。用总角减去两边的角，即 $110^\circ - 70^\circ = 40^\circ$，故选 B。
