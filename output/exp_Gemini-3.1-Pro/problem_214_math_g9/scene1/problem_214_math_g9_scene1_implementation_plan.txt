[图示主题与整合说明]
- 本图示主题：垂直平分线性质与角度代换推导
- 整合的步骤/概念：垂直平分线性质、等腰三角形等边对等角、三角形内角和、角度和差计算
- 教学价值：通过分步高亮和动画，引导学生逐步完成从线段相等、角度相等到最终角度和差的代换过程，将复杂的几何推导拆解为清晰的视觉逻辑，避免初始信息过载。

[视觉元素清单]
- 基础图形：△ABC 及线段 GE, HF, AE, AF（默认黑色 #000000，线宽 2px）。
- 左侧高亮（蓝 #1565c0）：线段 GE, AE, CE（高亮时线宽 3px）；G 处直角标记；AE, CE 上的单刻度线；∠C 与 ∠EAC 的扇形（透明度 20%）。
- 右侧高亮（红 #c62828）：线段 HF, AF, BF（高亮时线宽 3px）；H 处直角标记；AF, BF 上的单刻度线；∠B 与 ∠FAB 的扇形（透明度 20%）。
- 目标高亮（绿 #2e7d32）：∠EAF 的扇形（透明度 20%）及 40° 文本。
- 刻度线规格：AG, GC 为黑色单刻度；AH, HB 为黑色双刻度。
- 角度扇形规格：∠C, ∠B 半径 35；∠EAC, ∠FAB, ∠EAF 半径 60（三者完美拼接）；∠BAC 弧线半径 75。

[分步序列]
- 初始状态（步骤0）：显示基础图形、黑色刻度线、∠BAC 绿色弧线及 110° 标签。底部公式：`已知 \angle BAC = 110^\circ`。
- 步骤1：点击「下一步」→ 蓝色高亮 GE, AE, CE，显示 G 处蓝色直角标记及 AE, CE 蓝色刻度线。底部公式：`ecause GE 	ext{ 垂直平分 } AC \quad 	herefore EA = EC`。
- 步骤2：点击「下一步」→ 保持步骤1，显示 ∠C 和 ∠EAC 的蓝色扇形。底部公式：`	herefore \angle EAC = \angle C`。
- 步骤3：点击「下一步」→ 红色高亮 HF, AF, BF，显示 H 处红色直角标记及 AF, BF 红色刻度线。底部公式：`ecause HF 	ext{ 垂直平分 } AB \quad 	herefore FA = FB`。
- 步骤4：点击「下一步」→ 保持步骤3，显示 ∠B 和 ∠FAB 的红色扇形。底部公式：`	herefore \angle FAB = \angle B`。
- 步骤5：点击「下一步」→ 整体高亮 △ABC（添加浅黄色 #fff59d 透明度 0.3 的背景填充）。底部公式：`\angle C + \angle B = 180^\circ - 110^\circ = 70^\circ \Rightarrow \angle EAC + \angle FAB = 70^\circ`。
- 步骤6：点击「下一步」→ 显示 ∠EAF 的绿色扇形及 40° 标签。底部公式：`\angle EAF = \angle BAC - (\angle EAC + \angle FAB) = 110^\circ - 70^\circ = 40^\circ`。

- 40° 标签 (400, 150) 与 AE, AF 线段：文本位于两线段之间（间距约 29px），通过添加白色 text-shadow 确保可读性，无冲突。
- 标签 E (328, 335), F (472, 335) 与底边 BC (y=310)：位于底边下方，无冲突。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：底部区域 (y=420~490) 居中显示当前步骤的推导公式（使用 MathJax 渲染），公式下方放置「上一步」和「下一步」按钮。
- 教师操作流程：教师首先介绍题目已知条件，然后点击「下一步」逐步引导学生观察垂直平分线带来的线段相等，进而推导角度相等，最后通过内角和与角度相减得出最终结果。

[技术实现]
- JS 库选择：原生 SVG（用于精确绘制几何图形、扇形和刻度线） + MathJax（CDN 引入，用于高质量渲染底部数学公式）。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×420]
    (包含居中的几何图形及所有标注)
  [控件栏 800×80]
    (居中显示 MathJax 公式)
    ([上一步] [下一步] 按钮)
  ```
- 关键实现要点：
  1. 坐标计算：所有坐标已精确计算并平移以完美居中。SVG 路径需严格按照计划中的坐标绘制。
  2. 扇形绘制：使用 SVG 的 `A` (Arc) 指令绘制扇形，确保 ∠EAC(蓝), ∠EAF(绿), ∠FAB(红) 半径均为 60，实现视觉上的完美拼接。
  3. 状态机设计：定义 `currentStep` 变量（0-6），每次点击按钮更新变量并调用 `updateScene()` 函数。
  4. 动画过渡：为 SVG 元素的 `opacity` 和 `stroke-width` 添加 CSS `transition: all 0.3s ease`，实现平滑的高亮显隐效果。
  5. ID 命名规范：所有 DOM 元素 ID 必须以 `scene1-` 为前缀（如 `scene1-btn-next`, `scene1-arc-eac`），避免全局污染。
  6. IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
