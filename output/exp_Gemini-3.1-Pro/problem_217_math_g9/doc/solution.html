场景导航：Scene 1

题目原文：
如图，二次函数$y={{x}^{2}}-2x-3$的图像与$x$轴交于$A,B$两点，与$y$轴交于点$C$，下列说法:$①$ $AB=4;$ $②$ $\angle ABC={{45^\circ }};$ $③$当$0< x<2$时，$-4\le y<-3$；$④$当$x>1$时，$y$随$x$的增大而增大，其中结论正确的个数有（ ）
A．1个 B．2个 C．3个 D．4个

题目分析与整体讲解思路：

本题是一道二次函数的综合判断题，考查了二次函数与坐标轴的交点、二次函数图像上的几何性质、二次函数在特定区间上的最值及值域、以及二次函数的单调性。

讲解时，可以依托二次函数的图像，逐一验证四个结论：

  1. 首先令 $y=0$ 求出 $A, B$ 的坐标，从而计算线段 $AB$ 的长度，验证结论①。
  2. 接着令 $x=0$ 求出 $C$ 的坐标，观察 $ riangle OBC$ 的两条直角边 $OB$ 和 $OC$ 的长度，利用等腰直角三角形的性质验证结论②。
  3. 然后找到函数的顶点坐标，结合 $x=0$ 和 $x=2$ 时的函数值，观察 $0 < x < 2$ 时图像的最低点和最高点，验证结论③。
  4. 最后画出对称轴，观察对称轴右侧（$x>1$）图像的走向，验证结论④。

图示规划说明：

为了让学生直观地理解这四个结论的推导过程，我们将设计一个包含四个步骤的交互式图示。图示以二次函数图像为基础，通过分步导航，依次高亮展示与四个结论相关的几何元素和函数区间，帮助学生建立代数推导与几何直观的联系。

初始状态

本图示通过分步演示，完整呈现了四个结论的验证过程。教师在讲解时可按以下步骤引导：

  1. 验证结论①：引导学生令 $y=0$，解方程 $x^2-2x-3=0$。得出 $x_1=-1, x_2=3$，对应点 $A(-1,0), B(3,0)$。计算 $AB = 3 - (-1) = 4$，结论①正确。
  2. 验证结论②：引导学生令 $x=0$，求出 $y=-3$，得到点 $C(0,-3)$。观察直角三角形 $ riangle OBC$，指出 $OB=3, OC=|-3|=3$。因为 $OB=OC$ 且 $\angle BOC=90^\circ$，所以 $ riangle OBC$ 是等腰直角三角形。从而得出 $\angle OBC=45^\circ$，即 $\angle ABC=45^\circ$，结论②正确。
  3. 验证结论③：将函数化为顶点式 $y=(x-1)^2-4$，指出顶点坐标为 $(1,-4)$。引导学生观察当 $0 < x < 2$ 时的图像段。当 $x=1$ 时取得最小值 $y=-4$；当 $x=0$ 时 $y=-3$；当 $x=2$ 时 $y=-3$。因为 $x$ 的取值范围是开区间 $(0,2)$，所以最大值不能取到 $-3$，即 $-4 \le y < -3$，结论③正确。
  4. 验证结论④：指出抛物线的对称轴为 $x=1$。抛物线开口向上，在对称轴右侧（$x>1$），图像呈上升趋势。因此当 $x>1$ 时，$y$ 随 $x$ 的增大而增大，结论④正确。

综上所述，四个结论均正确，故选 D。
