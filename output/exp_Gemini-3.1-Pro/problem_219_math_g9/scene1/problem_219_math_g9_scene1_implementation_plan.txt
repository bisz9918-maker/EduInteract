[图示主题与整合说明]
- 本图示主题：利用面积割补法证明反比例函数图像上梯形与三角形面积相等
- 整合的步骤/概念：反比例函数图像点面积性质（S_△OAD = S_△OBC = k/2）、四边形 ODAB 的两种面积分割方式、等量代换推导结论。
- 教学价值：教师可通过分步演示，清晰地向学生展示复杂的四边形如何被拆解为已知面积的三角形和待求面积的图形，利用“局部-整体”的割补法直观推导出 S₁=S₂ 的结论。支持拖拽动点 A、B，帮助验证结论在任意位置均成立，加深学生对反比例函数几何性质的理解。

[视觉元素清单]
- 坐标系：黑色实线，2px，带箭头。
- 曲线：黑色实线，2px。
- 辅助线段（AD, BC, OA, OB, AB, OD, OC, CD）：未高亮时为 #888888 虚线，2px。
- 动点 A、B：黑色描边，白色填充，半径 6px，鼠标悬停时变为手型（cursor: pointer）。
- 梯形 ABCD (S₁)：蓝色高亮 #1565c0，填充透明度 30%。
- △OAB (S₂)：绿色高亮 #2e7d32，填充透明度 30%。
- △OAD 与 △OBC：红色高亮 #c62828，填充透明度 30%。
- 四边形 ODAB 轮廓：黑色实线，3px（仅步骤2、3显示）。
- 文本标签：黑色，16px sans-serif。右侧公式区使用 20px 字体，支持 HTML <sub> 标签。

[分步序列]
- 步骤 0（初始状态）：
  - 视觉：显示坐标系、曲线、所有辅助线。高亮梯形 ABCD（蓝色 S₁）和 △OAB（绿色 S₂）。
  - 文字区："观察梯形 ABCD (S₁) 与 △OAB (S₂) 的面积关系。<br><br>提示：可拖动点 A、B 改变图形形状。"
- 步骤 1（性质回顾）：
  - 视觉：隐藏蓝绿高亮。高亮 △OAD 和 △OBC（红色）。
  - 文字区："根据反比例函数性质：<br><br>S<sub>△OAD</sub> = S<sub>△OBC</sub> = k/2"
- 步骤 2（第一种分割）：
  - 视觉：显示四边形 ODAB 的黑色加粗外轮廓。内部高亮 △OAD（红色）和 △OAB（绿色 S₂）。
  - 文字区："分割四边形 ODAB (方式一)：<br><br>S<sub>四边形ODAB</sub> = S<sub>△OAD</sub> + S<sub>2</sub>"
- 步骤 3（第二种分割）：
  - 视觉：保持四边形 ODAB 黑色加粗外轮廓。内部高亮梯形 ABCD（蓝色 S₁）和 △OBC（红色）。
  - 文字区："分割四边形 ODAB (方式二)：<br><br>S<sub>四边形ODAB</sub> = S<sub>1</sub> + S<sub>△OBC</sub>"
- 步骤 4（得出结论）：
  - 视觉：隐藏黑色加粗外轮廓。同时高亮梯形 ABCD（蓝色 S₁）和 △OAB（绿色 S₂）。
  - 文字区："因为 S<sub>△OAD</sub> = S<sub>△OBC</sub><br>且 S<sub>四边形ODAB</sub> 面积固定<br><br>所以 S<sub>1</sub> = S<sub>2</sub><br><br>即 S<sub>1</sub> : S<sub>2</sub> = 1 : 1"

[标签冲突检查]
- O (85,415) vs C (80,325)：间距 90px > 20px，无冲突。
- C (80,325) vs D (80,205)：间距 120px > 20px，无冲突。
- A (215,185) vs D (80,205)：间距 135px > 20px，无冲突。
- B (365,305) vs C (80,325)：间距 285px > 20px，无冲突。
- S₁ (200,270) vs S₂ (220,300)：间距 36px > 20px，无冲突。
- 动态冲突规避：拖拽 A、B 时，C、D 的 y 坐标随之改变。由于限制了 A 的 x 范围 [140, 240] 和 B 的 x 范围 [280, 400]，A 始终在 B 的左上方，C 始终在 D 的下方，确保标签不会重叠。S₁ 和 S₂ 的坐标通过顶点坐标动态计算中心点，始终保持在各自多边形内部。

[交互方案]
- 交互类型：分步按钮导航 + 拖拽动点。
- 控件说明：
  - 底部居中放置三个按钮：`<button id="scene1-btn-prev">◀ 上一步</button>`、`<span id="scene1-step-indicator">第 0 / 4 步</span>`、`<button id="scene1-btn-next">下一步 ▶</button>`。
  - 动点 A、B：支持鼠标拖拽。
- 教师操作流程：教师首先在步骤 0 介绍题目背景，并拖动 A、B 点展示一般性；然后点击“下一步”逐步展示面积相等的红色三角形；接着通过步骤 2 和 3 展示四边形的两种不同割补方式；最后在步骤 4 得出等量代换结论。

[技术实现]
- JS 库选择：原生 SVG + 原生 JS。无需引入外部库，原生 SVG 处理多边形和拖拽非常高效。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  +-------------------------+--------------------+
  | y                       |                    |
  | ^                       |  [右侧文字区]      |
  | | D       A             |  S_ODAB = ...      |
  | |                       |                    |
  | | C             B       |                    |
  | |                       |                    |
  | O--------------------->x|                    |
  +-------------------------+--------------------+
  |      [◀ 上一步] 第 0/4 步 [下一步 ▶]         |
  +----------------------------------------------+
  ```
- 关键实现要点：
  - 坐标映射：定义 `mathToScreen(x, y)` 和 `screenToMath(sx, sy)`，便于处理反比例函数曲线和拖拽逻辑。
  - 拖拽逻辑：监听 SVG 的 `mousedown`, `mousemove`, `mouseup` 事件。拖拽时，根据鼠标的 x 坐标计算对应的 y 坐标（保持在曲线上），并更新 A、B 点坐标。同时更新 C、D 点坐标（C.y = B.y, D.y = A.y）。
  - 动态更新：每次拖拽更新坐标后，重新计算并设置所有相关 `<line>`, `<polygon>`, `<text>` 的属性。
  - 状态机：使用变量 `currentStep` (0-4) 记录当前步骤。编写 `updateStep()` 函数，根据当前步骤控制各个多边形（梯形、三角形）的 `display` 或 `opacity` 属性，并更新右侧文字区的 HTML 内容。
- ID 命名规范：所有 DOM 元素 ID 均以 `scene1-` 开头（如 `scene1-svg`, `scene1-poly-abcd`, `scene1-text-panel`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })();` 中，避免全局变量污染。
