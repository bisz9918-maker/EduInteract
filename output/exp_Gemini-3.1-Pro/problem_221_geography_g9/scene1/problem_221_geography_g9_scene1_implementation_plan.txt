[分步序列]
- 初始状态（步骤0）：显示基础底图（经纬网、黑夜阴影、晨昏线、甲乙两点及基础坐标标签）。
- 步骤1：点击「下一步」→ 出现 30°W 经线，顶部出现向西递增箭头，底部出现西半球范围指示，推断甲地经度及半球位置。
- 步骤2：点击「下一步」→ 出现自转方向箭头，晨昏线变红加粗并标注“晨线”，甲地旁出现“6:00”标签。
- 步骤3：点击「下一步」→ 北半球白昼区域黄色高亮，显示直射北半球结论，赤道上出现向东推算直射点经度的箭头及结果。
- 步骤4：点击「下一步」→ 乙地所在 23.5°S 纬线变绿加粗，甲乙之间出现经度差指示，乙地旁出现“日出 6:30”，底部居中显示昼长计算公式。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：在 SVG 内部底部 (y=450) 居中放置两个按钮，用于控制步骤切换 (0~4)。
- 教师操作流程：教师首先展示原图让学生观察，然后依次点击“下一步”，逐步引导学生完成经度判断、晨线与时间推导、直射点计算、最后得出昼长，每一步配合图上的高亮和标注进行讲解。

[技术实现]
- JS 库选择及原因：原生 SVG。地理图表主要由直线、多边形和文本构成，原生 SVG 能够完美实现精确的坐标控制和高质量的矢量渲染，且易于通过 DOM 操作实现分步动画。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
    (150,80) +-------------------------+ (650,80)
             |          地图区         |
             |                         |
             +-------------------------+ (650,320)
             
             [ 昼长计算公式文本 (400,390) ]
             
             [ ◀上一步 ] [ 下一步▶ ] (y=450)
  ```
- 关键实现要点：
  - 使用 `<pattern>` 定义黑夜阴影的斜线纹理。
  - 维护一个 `currentStep` 状态变量 (0-4)。
  - 将各步骤的专属元素分别放入 `<g id="scene1-step1-elements">` 等分组中，通过切换 `display` 或 `opacity` 属性实现步骤切换。
  - 晨昏线和 23.5°S 纬线的高亮可以通过在对应步骤中叠加一条粗的彩色线条实现，避免修改基础线条属性。
  - ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
