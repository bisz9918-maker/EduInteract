[图示主题与整合说明]
- 本图示主题：正午太阳高度与墙面太阳能电池板安装倾角
- 整合的步骤/概念：从抽象的太阳高度角计算，到具体的设备垂直受光安装，最后通过严谨的几何辅助线推导，证明电池板与墙面的夹角 α 等于太阳高度角 H。
- 教学价值：教师可以通过分步演示，将复杂的空间角度关系转化为直观的平面几何证明，帮助学生跨越“光线垂直”到“夹角相等”的认知障碍。

- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。几何图形简单且需要精确控制坐标和层级，原生 SVG 是最佳选择。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  +-----------------------------------------+
  |        |                  [解释文本框]  |
  |        |                  (450,20)      |
  |        |                                |
  | 外墙   W(200,250)                       |
  | (x=200)| \ 电池板                       |
  |        |  \                             |
  |        |   \ α                          |
  |        |    P(340,304)                  |
  |        |     \ 延长线        光线1 /    |
  |        |      \                   /     |
  |        |       \ β             H /      |
  |--------O--------E-----------------------|
  |       地面 (y=400)                      |
  +-----------------------------------------+
  [控件栏: ◀ 上一步 | 下一步 ▶] (y=460)
  ```
- 关键实现要点：
  - 使用 CSS `transition: opacity 0.5s ease;` 实现元素的平滑显隐。
  - 扇形路径使用 SVG `path` 的 `A` (Arc) 指令精确绘制，注意 `sweep-flag` 的方向（SVG中顺时针为正）。
  - 解释框使用绝对定位的 `div`，通过 JS 动态更新 `innerHTML`，支持简单的 HTML 标签（如 `<b>`, `&deg;`, `&triangle;`）。
  - ID 命名规范：所有元素 ID 必须以 `scene3-` 为前缀（如 `scene3-ray1`, `scene3-btn-next`）。
  - IIFE 隔离：所有 JS 逻辑封装在 `(function() { ... })();` 中，避免全局变量污染。
