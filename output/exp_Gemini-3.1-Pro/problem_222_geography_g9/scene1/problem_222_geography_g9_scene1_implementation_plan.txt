- 本图示主题：经纬网图坐标判读与方向判断

[分步序列]
- 初始状态（步骤0）：显示经纬网格、度数文本、点①②③④及其点名标签。
- 步骤1（经纬划分）：点击「下一步」。0°经线和0°纬线加粗变蓝（#1565c0）。在0°经线顶部两侧浮现"W"和"E"，在0°纬线右侧上下浮现"N"和"S"。
- 步骤2（读取坐标）：点击「下一步」。依次在①②③④四个点旁边浮现其坐标文本（蓝色）：①(0°, 120°W)在下方，②(0°, 120°E)在下方，③(30°N, 120°E)在上方，④(30°N, 120°W)在上方。
- 步骤3（判断方向）：点击「下一步」。高亮③和①。从③点(645,165)画一条向下的红色箭头至(645,240)，标注"正南"；画一条向右的红色箭头至(700,165)，用灰色虚线连接右边缘和左边缘，再从左边缘(100,165)画红色箭头至①点附近(155,165)，在右侧箭头旁标注"正东"；最后从③点画一条指向右下方的红色箭头至(680,200)，标注"东南"。
- 步骤4（定位新加坡）：点击「下一步」。在坐标(608,334)处绘制一个红色星号，并在左上方(550,310)显示"新加坡(1°N, 104°E)"。用绿色虚线圆圈圈出新加坡和点②，圆心在(624,337)，半径25px。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：在 SVG 底部（Y=450~490）居中放置两个按钮：“◀ 上一步”和“下一步 ▶”。
- 教师操作流程：
  1. 初始展示原图，让学生观察经纬网。
  2. 点击下一步，展示东西经、南北纬的划分界线。
  3. 点击下一步，公布四个点的坐标，核对学生答案。
  4. 点击下一步，动态演示从③到①的方向判断过程（先南后东，合成东南）。
  5. 点击下一步，标出新加坡位置，直观展示其与②点最近。

[技术实现]
- JS 库选择及原因：原生 SVG。经纬网、点、线、箭头等均为标准几何图形，SVG 易于实现精确的像素级定位和 DOM 动画控制。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800x440]
    (经纬网 100~700, 100~400)
  [控件栏 800x60]
    (上一步) (下一步)
  ```
- 关键实现要点：
  - 状态机设计：定义 `currentStep` 变量（0-4），每次点击按钮更新状态，并调用 `renderStep(step)` 函数更新各元素的 `display` 或 `opacity` 属性。
  - 坐标计算：严格按照布局坐标表中的像素坐标绘制。箭头和辅助线需避开网格线，采用微调后的坐标（如 X=645, Y=165）。
  - 动画：使用 CSS `transition: opacity 0.5s ease` 控制元素的淡入淡出效果。
  - ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-grid`, `scene1-point1`, `scene1-btn-next`）。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
