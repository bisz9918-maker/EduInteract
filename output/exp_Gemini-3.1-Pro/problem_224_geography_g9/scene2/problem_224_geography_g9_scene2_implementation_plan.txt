[图示主题与整合说明]
- 本图示主题：太阳直射点定位与北京时间计算
- 整合的步骤/概念：通过晨昏线与经纬网的几何关系，推导太阳直射点的精确经纬度，并利用经度差推算北京时间（120°E地方时）。
- 教学价值：教师可通过分步演示，引导学生从“找晨昏线切点”到“定直射纬度”，再到“找平分昼半球经线定直射经度”，最后“跨经度计算时间”，将抽象的空间几何与时间计算具象化、步骤化，有效突破教学难点。

- 步骤1：点击「下一步」→ 出现南回归线（23.5°S）红色高亮及“直射纬度: 23.5°S”标签。
- 步骤2：点击「下一步」→ 出现45°W蓝色高亮及顶部“12:00”标签；在B点(350,244)出现太阳图标及“直射点 (45°W, 23.5°S)”标签。
- 步骤3：点击「下一步」→ 出现120°E绿色虚线及顶部“120°E”、底部“23:00”标签；在图下方出现跨度指示线及“经度差165°，相差11小时”标签。

[标签冲突检查]
- 标签"12:00"(350,50) 与 标签"45°"(350,70)：垂直错开20px，无冲突。
- 标签"直射点 (45°W, 23.5°S)"(365,235) 与 点B标签(355,255)：分别位于y=244的上方和下方，无冲突。
- 标签"直射点..."(365,235) 与 45°E经线(x=475)：文本较长会穿过经线。解决方案：为该文本添加白色描边 (`stroke="white" stroke-width="3" paint-order="stroke"`) 确保可读性。
- 标签"直射纬度: 23.5°S"(150,238) 与 135°W经线(x=225)：文本会穿过经线。解决方案：同上，添加白色描边。

- 标签"120°E"(579,50) 与 标签"135°"(600,70)：水平错开21px，垂直错开20px，无冲突。

[交互方案]
- 交互类型：分步按钮导航
- 控件说明：在SVG底部（y=450~490区域）居中放置两个按钮：“◀ 上一步” 和 “下一步 ▶”。
- 教师操作流程：教师首先展示夜半球，引导学生观察晨昏线与极圈的相切点D；点击“下一步”展示直射纬度推导结果；再次点击展示平分昼半球的经线及直射点完整坐标；最后点击展示北京时间（120°E）的位置及时间推算过程。

[技术实现]
- JS 库选择及原因：原生 SVG。本场景主要由直线、多边形和简单文本构成，SVG 的 DOM 结构非常适合分步控制元素的显示与隐藏（通过控制 `opacity` 或 `display` 属性）。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800x440]
    (顶部经度标签)
    +-----------------------------------------+ (右侧纬度标签)
    | \ 夜半球阴影 /                          |
    |  \          /                           |
    |   \   D    /                            |
    |    \      /                             |
    |     \    /                              |
    |      \  /                               |
    |   A   / B(太阳)                 C      |
    |       /\                                |
    |      /  \                               |
    |   E /    \ F                            |
    +-----------------------------------------+
          <---- 经度差165° ---->
                               | 120°E
  [控件栏 800x60 (y=440~500)]
         [◀ 上一步] [下一步 ▶]
  ```
- 关键实现要点：
  1. 状态机设计：定义 `currentStep` 变量（0~3），点击按钮时更新变量并调用 `updateScene()` 函数。
  2. 元素分组：将属于特定步骤的 SVG 元素放入对应的 `<g id="scene2-stepX">` 中，通过 JS 统一控制组的 `opacity` 实现淡入淡出动画（`transition: opacity 0.3s`）。
  3. 文本遮挡处理：所有可能与网格线重叠的文本，必须使用 `paint-order="stroke"` 配合白色描边，保证文字清晰。
  4. 箭头绘制：使用 `<marker>` 定义箭头样式，应用于跨度指示线。
- ID 命名规范：所有交互元素 ID 必须以 `scene2-` 为前缀（如 `scene2-btn-next`, `scene2-step1-group`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
