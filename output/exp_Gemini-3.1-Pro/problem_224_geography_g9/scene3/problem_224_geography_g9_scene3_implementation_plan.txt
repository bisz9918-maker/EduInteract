- 纬度标签：90°、66.5°、23.5°、赤道、23.5°、66.5°、90°，位于右侧 (x=710)

[分步序列]
- 初始状态：显示基础经纬网、晨昏线、所有点及标签。底部结论框隐藏。
- 状态1（正午太阳高度）：
  - 高亮显示 66.5°N 纬线，高亮 C、D 两点（#c62828）。
  - D点左侧出现标注框：“当前即正午，太阳高度=0°”。
  - C点右侧出现标注框：“正午太阳高度=0°”。
  - 底部结论框显示：“H = 90° - (66.5° + 23.5°) = 0°”（文字颜色 #c62828）。
- 状态2（地方时）：
  - 高亮显示 45°W 经线，高亮 B、D 两点（#1565c0）。
  - 隐藏状态1的专属标注框。
  - 底部结论框显示：“同经度地方时相等（12:00）”（文字颜色 #1565c0）。
- 状态3（线速度）：
  - 高亮显示 66.5°N 和 66.5°S 两条纬线，高亮 A、C、D 三点（#2e7d32）。
  - 底部结论框显示：“纬度绝对值相等，线速度相等”（文字颜色 #2e7d32）。

[交互方案]
- 交互类型：多状态切换（3个按钮）
- 控件说明：
  - 按钮1：“正午太阳高度”，位置居中偏左
  - 按钮2：“地方时”，位置居中
  - 按钮3：“线速度”，位置居中偏右
  - 控件栏整体位于 y=460
- 教师操作流程：教师点击不同按钮，图示即时切换到对应的高亮状态和结论，方便针对性地讲解各个地理特征的规律。

[技术实现]
- JS 库选择及原因：原生 SVG。地理光照图由规则的线段和点组成，SVG 易于实现精确的像素级定位、高亮和状态切换。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
    (100,80) ------------------------ (700,80)
       |                                |
       |          D(400,120)  C(550,120)|
       |         /|                     |
       |        / |                     |
       |       /  B(400,269)            |
       |      /   |                     |
    (100,341)E--A(250,341)------------F(700,341)
       |                                |
    (100,380) ------------------------ (700,380)
    
    [结论文本框 (225,400)-(575,440)]
    
    [控件栏 y=460: 按钮1 | 按钮2 | 按钮3 ]
  ```
- 关键实现要点：
  - 使用 `<g>` 标签对不同状态的高亮元素进行分组（如 `id="scene3-state1-group"`），通过 JS 控制 `display` 属性实现状态切换。
  - 纬线 y 坐标按真实纬度比例计算（中心 y=230，比例 1.667px/度），确保视觉比例与地理事实一致。
  - 按钮点击事件中，先隐藏所有状态组，再显示目标状态组，并更新按钮的激活样式。
  - ID 命名规范：所有交互元素 ID 必须以 `scene3-` 为前缀。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
