[分步序列]
- 初始状态（步骤0）：显示基础经纬网、点A/B/C/D及其字母标签。经纬度标签仅显示数值（如120, 140, 80, 60）。
- 步骤1（判读坐标）：
  - 经纬度标签增加N/S/E/W后缀（如120°E, 80°N）。
  - 高亮0°纬线（红）和180°经线（蓝）。
  - 在各点旁边显示完整坐标标注（如A: 80°N, 140°E）。
- 步骤2（判断方向）：
  - 隐藏坐标标注和高亮线。
  - 在C点显示十字方向标（标出北、东）。
  - 绘制C到A的红色箭头，旁边标注“正北”。
  - 绘制C到B的蓝色箭头，旁边标注“东北”。
- 步骤3（南北半球）：
  - 隐藏步骤2的箭头和方向标。
  - 高亮0°纬线（红），显示北半球色块（红20%）和南半球色块（蓝20%），并居中显示大字标签“北半球”、“南半球”。
- 步骤4（东西半球）：
  - 隐藏南北半球色块和0°高亮。
  - 高亮160°E经线（蓝），显示东半球色块（红20%）和西半球色块（蓝20%），并居中显示大字标签“东半球”、“西半球”。
- 步骤5（划分纬度带）：
  - 隐藏步骤4的色块和高亮线。
  - 绘制30°N, 60°N, 30°S虚线。
  - 显示低纬度色块（红20%）、中纬度色块（蓝20%）、高纬度色块（绿20%），并居中显示大字标签“低纬度”、“中纬度”、“高纬度”。

[交互方案]
- 交互类型：分步按钮导航。
- 控件说明：底部控件栏（Y=450~490）包含“◀ 上一步”按钮、“状态指示文本”和“下一步 ▶”按钮。
- 教师操作流程：教师点击“下一步”依次展示坐标判读、方向判断、南北半球、东西半球、纬度带划分。可随时点击“上一步”回退。

[技术实现]
- JS 库选择及原因：原生 SVG。本题主要涉及简单的几何图形（线段、圆点、矩形色块、箭头）和文本，SVG 能够完美且清晰地实现，且易于通过 DOM 操作控制各元素的显示与隐藏。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×440]
    (经纬网及各步骤高亮内容居中显示)
  [控件栏 800×60]
    (上一步)  步骤 1 / 5  (下一步)
  ```
- 关键实现要点：
  - 使用 `<svg>` 绘制所有图形元素。将不同步骤的元素分组到不同的 `<g>` 标签中（如 `<g id="scene1-step1">`）。
  - 状态机设计：定义一个 `currentStep` 变量（0到5）。
  - 编写 `updateScene()` 函数，根据 `currentStep` 控制各 `<g>` 组的 `display` 属性（'none' 或 'block'），并更新按钮状态和步骤指示文本。
  - 箭头绘制：使用 `<marker>` 定义箭头头部，方便在 `<line>` 中复用。
  - ID 命名规范：所有元素 ID 以 `scene1-` 开头。
  - IIFE 隔离：所有逻辑封装在 `(function() { ... })()` 中。
