[图示主题与整合说明]
- 本图示主题：冬至日太阳照射情况与地方时分析（注：原大纲描述为“夏至日”，但根据提供的原图，北极点处于夜半球，太阳直射南半球，实际为“冬至日”。为保证教学图示的科学性与原图完全一致，本计划已将相关文案修正为“冬至日”、“南回归线”、“昼短夜长”、“极夜”等正确特征）。
- 整合的步骤/概念：太阳直射点判定、昼夜长短分布规律、特殊点（正午与子夜）的地方时判定。
- 教学价值：教师可通过分步导航，引导学生先观察直射点位置，再分析昼夜长短的纬度分布，最后推导特殊经线的地方时，层层递进，化解空间几何认知难点。

[视觉元素清单]
- 基础图形：地球轮廓（白底黑边）、晨昏线（黑色直线）、夜半球阴影（黑色，20%透明度）。
- 经纬网：赤道、南北回归线、南北极圈均为倾斜直线；经线为连接N、S两点的椭圆弧（使用SVG Arc，ry=161防止截断）。

- 关键点：N、S、A、B、C 黑色实心小圆点及对应文本标签。

  - 主线：#000000

[分步序列]
- 初始状态（步骤0）：显示地球轮廓、经纬网、晨昏线、夜半球阴影、太阳光线及N、S、A、B、C所有基础标注。隐藏所有彩色高亮和解析标签。
- 步骤1（直射点与节气）：点击「下一步」。中心太阳光线变为红色加粗，并延伸红色虚线至(240,240)。南回归线变为红色加粗。显示红色标签“直射点”和“南回归线”。
- 步骤2（昼夜长短）：点击「下一步」。保留步骤1状态。北回归线的昼弧段(291,123)至(400,170)高亮为黄色，夜弧段(400,170)至(560,240)高亮为蓝色。显示蓝色标签“昼短夜长”。北极圈高亮为蓝色，显示蓝色标签“极夜”。
- 步骤3（地方时判定）：点击「下一步」。保留前序状态。高亮经过B点的左半圆弧（昼半球中央经线）为黄色加粗，显示黄色标签“12:00 (正午)”。高亮经过C点的右半圆弧（夜半球中央经线）为蓝色加粗，显示蓝色标签“24:00 (子夜)”。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：在SVG画布底部（y=450~490区域）居中放置两个按钮。
- 教师操作流程：教师首先展示原图让学生观察；点击下一步，引导学生看中心光线直射南回归线，得出冬至日结论；再次点击，对比北半球昼夜弧长，讲解昼短夜长及极夜现象；最后点击，标出昼夜半球中央经线，推导B、C两点的地方时。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。本场景主要由几何线段、圆弧和文本组成，SVG 的 `<path>` 和 `<line>` 标签能完美、精确地实现这些静态和高亮元素，无需引入庞大的外部库。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×450]
    (左侧)太阳光线 -> (居中)地球及经纬网、阴影
  [控件栏 800×50]
    [ ◀ 上一步 ]  [ 下一步 ▶ ]
  ```
- 关键实现要点：
  - 经线绘制：使用 SVG 的 `A` (Arc) 指令，起点为 N(464,93)，终点为 S(336,387)，设置 `x-axis-rotation` 为 -23.5。为防止浮点数精度导致距离略大于 `2*ry` 而被 SVG 截断，`ry` 统一设置为 161。
  - 状态机设计：定义 `currentStep` 变量（0~3），每次点击按钮更新变量并调用 `updateView()` 函数。
  - 元素控制：在 `updateView()` 中，通过修改对应 SVG 元素的 `opacity` 或 `stroke` 属性来实现高亮和显示/隐藏。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-btn-next`, `scene1-tropic-capricorn`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
