[图示主题与整合说明]
- 本图示主题：经纬网与时间、日期推导
- 整合的步骤/概念：晨昏线判读、地方时计算、经度间隔推断、日期分界线定位、直射点经度推导

[视觉元素清单]

- 阴影区：#1565c0，透明度 0.2。
- 晨昏线AO/BO：#c62828，3px 加粗。
- 夜半球遮罩：#000000，透明度 0.1。
- 文本标签：点名和纬度为黑色 14px；时间推导为红色 #c62828 14px；经度推导为蓝色 #1565c0 14px。
- 底部解说文本：位于 y=430，居中，#333333，16px。

[分步序列]
- 初始状态（步骤0）：显示基础网格、阴影区、点A/O/B及纬度标签。底部说明："观察原始经纬网与阴影区（阴影区与全球其他地区日期不同）。"
- 步骤1：高亮AO、BO，显示夜半球遮罩。底部说明："AO为昏线，BO为晨线。昏线与晨线之间的区域为夜半球。"
- 步骤2：显示B点时间(6:00)和O点时间(0:00)。底部说明："B点位于赤道与晨线交点，地方时为6:00。O点平分夜半球，地方时为0:00。"
- 步骤3：显示经度间隔标注线及说明，显示A点时间(20:00)。底部说明："O到B相差6小时，跨3个间隔，故每个间隔为2小时（30°）。推导A点地方时为20:00。"
- 步骤4：显示180°经度标签。底部说明："阴影区日期不同，其边界必为0:00经线和180°经线。O点为0:00，故阴影左边界（A点所在经线）为180°。"
- 步骤5：显示150°W、120°W标签及直射点结论框。底部说明："向东推导，O点经度为120°W。正午12:00所在经线比O点早12小时，即向东180°，为60°E。"

[标签冲突检查]
- B点附近：B标签(685,95)，0°标签(710,105)，6:00标签(700,80)。三者分别在左、右、上，无冲突。
- A点附近：A标签(185,178)，20:00标签(200,155)，180°标签(200,85)。垂直方向错开，无冲突。
- O点附近：O标签(415,325)，0:00标签(400,345)。分别在右侧和正下方，无冲突。
- 顶部经度：180°(200,85)，150°W(300,85)，120°W(400,85)。水平间距100px，无冲突。
- 结论框：位于(450,180)至(650,260)，该区域内无其他标签或关键点，无冲突。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：在 SVG 容器底部（y=460）放置 HTML 按钮和步骤指示器（如 1 / 6）。
- 教师操作流程：教师点击“下一步”按钮，图示依次叠加显示推导过程的关键信息，配合底部的动态文本进行逻辑讲解。可随时点击“上一步”回退。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形和状态切换，无需复杂库）。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800x420]
  [解说文本区 y=430]
  [控件栏 y=460]
  ```
- 关键实现要点：
  - 使用 `<g>` 标签将不同步骤的元素分组，通过 JS 控制组的 `display` 或 `opacity` 属性实现步骤切换。
  - 状态机设计：定义一个 `currentStep` 变量（0-5），每次点击按钮更新变量并调用 `updateScene()` 函数。
  - `updateScene()` 函数根据 `currentStep` 决定哪些元素可见，并更新底部的解说文本。
  - 动画：可为元素的 `opacity` 添加 CSS `transition: opacity 0.3s ease`，使步骤切换更平滑。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-step1-group`, `scene1-btn-next`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
