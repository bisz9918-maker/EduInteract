[图示主题与整合说明]
- 本图示主题：H$_{2}$O$_{2}$的分子构型及作用力分析
- 整合的步骤/概念：分子空间构型展示、极性键与非极性键区分、分子极性判断、氢键与范德华力
- 教学价值：教师可以通过分步演示，清晰地向学生展示H$_{2}$O$_{2}$独特的“半展开书本”空间构型，逐步剖析其内部的化学键类型，推导其极性，并最终扩展到分子间作用力，符合从微观结构到宏观性质的认知规律。

[视觉元素清单]
- O原子：圆形，填充 #c62828（红色），半径 12px。标签“O”在原子侧下方。
- H原子：圆形，填充 #1565c0（蓝色），半径 8px。标签“H”在原子外侧。
- 非极性键（O-O）：线段，#000000（黑色），粗实线（stroke-width: 4）。
- 极性键（O-H）：线段，#000000（黑色），实线（stroke-width: 3）。

- 氢键（步骤3）：虚线，#2e7d32（绿色），stroke-dasharray="5,5"，stroke-width: 3。

[分步序列]
- 初始状态（步骤0）：居中展示单个 H$_{2}$O$_{2}$ 分子（mol1）的“半展开书本”构型，包含两个相交的半平面、O原子、H原子及化学键。隐藏高亮、电荷中心和第二个分子。
- 步骤1：点击「下一步」→ 高亮中间的 O-O 键，并在下方显示“非极性键”标签；高亮两侧的 O-H 键，并在外侧显示“极性键”标签。
- 步骤2：点击「下一步」→ 隐藏步骤1的高亮和标签。显示正电荷中心(+)和负电荷中心(-)，用箭头连接两者，并在右侧显示结论文本“正负电荷中心不重合 → 极性分子”。
- 步骤3：点击「下一步」→ 隐藏步骤2的电荷中心和结论。mol1 缩小（scale 0.75）并向左平移（translate -120px），同时右侧淡入第二个分子 mol2（scale 0.75, translate 120px）。在 mol1 的 O 原子和 mol2 的 H 原子之间显示绿色虚线，标注“氢键”，并在下方显示“分子间还存在范德华力”。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：在 SVG 容器底部（y=450~490 区域）居中放置两个 HTML 按钮。
- 教师操作流程：教师首先展示分子基础构型，讲解其空间结构；点击“下一步”引导学生分析化学键类型；再次点击“下一步”通过电荷中心不重合推导分子极性；最后点击“下一步”引入分子间作用力（氢键和范德华力），完成知识点的层层递进。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript。几何图形和连线使用 SVG 实现最为精确且易于控制动画。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×450]
    (步骤0-2: 居中展示单个分子)
    (步骤3: 左侧分子1 ---氢键--- 右侧分子2)
  [控件栏 800×50]
    [ ◀ 上一步 ] [ 下一步 ▶ ]
  ```
- 关键实现要点：
  - 状态机设计：维护 `currentStep` 变量（0~3），点击按钮时更新变量，并为 SVG 根元素切换对应的 CSS class（如 `step-0`, `step-1` 等）。
  - 动画过渡：利用 CSS `transition: transform 0.8s ease, opacity 0.8s ease` 实现分子平移缩放、元素淡入淡出的平滑动画。
  - 坐标系变换：mol1 和 mol2 使用 `<g>` 分组，通过 `transform-origin: 400px 220px` 确保缩放中心正确。步骤3的氢键直接画在全局坐标系中，其端点坐标已根据 mol1 和 mol2 的变换矩阵预先计算好（起点 310,220，终点 475,145），确保动画完成后精准连接。
  - ID 命名规范：所有元素 ID 均以 `scene1-` 开头（如 `scene1-mol1`, `scene1-btn-next`），防止跨场景污染。
  - IIFE 隔离：所有逻辑代码封装在 `(function() { ... })()` 中。
