[图示主题与整合说明]
- 本图示主题：甲与丙的等效平衡及转化率分析
- 整合的步骤/概念：通过动画展示甲容器中 NO₂ 的“极限转化”过程，直观证明甲与丙在恒温恒容条件下的初始状态等效，进而推导出两者达到完全相同的平衡状态，最后结合等效平衡结论分析转化率的数学关系（α + β = 1）。
- 教学价值：教师可通过分步演示，将抽象的“等效平衡”概念具象化为分子的合并与拆分过程，帮助学生直观理解为什么甲和丙最终状态相同，并清晰展示转化率互补的逻辑，有力反驳易错选项。

- 反应方程式：黑色文本，居中显示。

- 状态文本：甲初始为 #c62828（红色），丙初始为 #1565c0（蓝色），平衡时为黑色。
- 分子示意图：
  - NO₂ 分子：#c62828 红色小圆（r=8）。
  - N₂O₄ 分子：#1565c0 蓝色大圆（r=12）。
- 关系符号：
  - 极限转化箭头：#888888 虚线箭头。
  - 等效平衡等号：黑色大号文本 "="。
- 结论文本区：黑色 HTML 文本，支持粗体和换行。

[分步序列]
- 初始状态（步骤0）：
  - 视觉：显示容器甲（含4个红圆，文本"0.2 mol NO₂"）和容器丙（含2个蓝圆，文本"0.1 mol N₂O₄"）。关系符号隐藏。
  - 结论文本："初始状态：甲充入 0.2 mol NO₂，丙充入 0.1 mol N₂O₄。两容器体积、温度相同。"
- 步骤1（极限转化）：
  - 视觉：甲中文本变为"0.1 mol N₂O₄"（蓝色）。甲中4个红圆两两向中心移动并淡出，同时2个蓝圆淡入（模拟 2NO₂ → N₂O₄）。两容器中间出现灰色虚线箭头，上方标注"极限转化"。
  - 结论文本："极限转化：假设甲中的 NO₂ 完全反应，将生成 0.1 mol N₂O₄，此时甲与丙的物质状态完全一致。"
- 步骤2（等效平衡）：
  - 视觉：甲和丙的文本均变为"平衡混合物"（黑色）。甲中上方1个蓝圆拆分为2个红圆向两侧移动，下方1个蓝圆保持不变；丙中上方1个蓝圆同样拆分为2个红圆向两侧移动，下方1个蓝圆保持不变。两容器呈现完全对称的混合状态（2红1蓝）。中间符号变为大号 "="，上方标注"等效平衡"。
  - 结论文本："等效平衡：由于极限状态相同且条件（恒温恒容）相同，甲与丙最终将达到完全相同的平衡状态。"
- 步骤3（转化率探讨）：
  - 视觉：图形保持步骤2的平衡状态不变。
  - 结论文本："转化率分析：设甲中 NO₂ 转化率为 α，丙中 N₂O₄ 转化率为 β。根据等效平衡原理，α + β = 1。若 α = β = 50%，则转化率相同，故选项C“不可能相同”错误。"

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：在 SVG 画布底部（y=450~490）居中放置两个按钮，控制步骤 0~3 的切换。
- 教师操作流程：教师首先展示初始状态，讲解题意；点击“下一步”演示极限转化过程，强调等效的前提；再次点击展示最终平衡状态，得出甲丙等效的结论；最后点击展示转化率的数学关系，完成对选项C的辨析。

[技术实现]
- JS 库选择及原因：原生 SVG + HTML + CSS Transitions。图形简单，原生 SVG 配合 CSS transition 即可实现平滑的分子移动和淡入淡出动画，无需引入额外库，性能最佳。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
    (400,50) 反应方程式
  [甲容器] (400,210) [丙容器]
  [结论文本区 600×80]
  [控件栏: 上一步 | 下一步]
  ```
- 关键实现要点：
  - 状态机设计：定义 currentStep (0-3)，每次步骤变化时调用 updateScene(step) 函数。
  - 动画实现：通过修改 SVG 元素的 cx, cy, opacity 属性，并在 CSS 中设置 transition: all 0.8s ease-in-out 来实现平滑动画。
  - 文本更新：结论文本区使用 HTML div，通过 innerHTML 切换内容，支持简单的 HTML 标签（如 sub）。
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀（如 scene1-jia-rect, scene1-btn-next）。
- IIFE 隔离：所有 JS 代码封装在 (function() { ... })() 中，避免全局变量污染。
