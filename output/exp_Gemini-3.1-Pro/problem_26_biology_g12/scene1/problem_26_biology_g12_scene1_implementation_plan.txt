[图示主题与整合说明]
- 本图示主题：F₂代实验数据分析与遗传方式推导
- 整合的步骤/概念：表格数据展示、总比例计算、性别差异分析、遗传定律及染色体定位推导

[视觉元素清单]
- 表格线：原生 SVG `<line>`，颜色 #000000，线宽 1px。
  - 横线：y=60, 100, 180, 260, 340 (x:40-440)；y=140, 220, 300 (x:40-240)
  - 竖线：x=40, 140, 240, 340, 440 (y:60-340)

- 蓝高亮框：原生 SVG `<rect>`，位置 (240,100)，宽 200，高 240，填充 #1565c0，透明度 0.2。
- 红高亮框：原生 SVG `<rect>`，位置 (40,100)，宽 200，高 240，填充 #c62828，透明度 0.2。
- 结论文本：原生 SVG `<text>`，颜色 #2e7d32，字号 16px，左对齐 (`text-anchor="start"`)。

[分步序列]
- 初始状态（步骤0）：仅显示完整的数据表格，无高亮框，无结论文本。
- 步骤1：点击「下一步」→ 出现蓝高亮框（覆盖右侧两列），右侧出现结论1文本（总比例分析及自由组合定律）。
- 步骤2：点击「下一步」→ 蓝高亮框消失，出现红高亮框（覆盖左侧两列），右侧出现结论2文本（性别差异分析）。
- 步骤3：点击「下一步」→ 红高亮框消失，右侧出现结论3文本（染色体定位最终结论）。

[标签冲突检查]
- 表格文本：均在各自单元格中心（100x40 或 100x80 的空间），文本最大宽度约 60px，高度 14px，四周留白充足，无冲突。
- 结论文本与表格：表格右边缘在 x=440，结论文本从 x=470 开始，间距 30px，无冲突。
- 结论文本之间：结论1（y=120~195），结论2（y=235~310），结论3（y=350~400），垂直间距至少 40px，无冲突。
- 控件栏与图形：控件栏在 y=450~490，表格和结论文本最下方在 y=400 左右，垂直间距 50px，无冲突。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：底部居中放置两个按钮，用于控制步骤 0 到 3 的切换。
- 教师操作流程：教师首先展示原始表格让学生观察；点击下一步，引导学生看总比例，得出两对基因和自由组合定律；再点击下一步，引导学生看雌雄差异，发现伴性遗传的线索；最后点击下一步，总结出两对基因的具体位置。

[技术实现]
- JS 库选择及原因：原生 SVG。因为本场景主要是静态表格的绘制、简单矩形高亮和文本的显示隐藏，原生 SVG 配合简单的 CSS 类切换（控制 `opacity`）即可完美实现，无需引入庞大的外部库。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```text
  [图示区 800×500]
  +-----------------------------------------+
  |  +-----------------+  结论1：           |
  |  | F2表现型 | 数量 |  长翅:小翅:残翅... |
  |  +----------+------+  → 自由组合定律    |
  |  | 长翅♀    | 548  |                    |
  |  | 长翅♂    | 256  |  结论2：           |
  |  | 小翅♀    | 0    |  小翅仅雄性有...   |
  |  | 小翅♂    | 239  |  长翅雌雄不等...   |
  |  | 残翅♀    | 153  |                    |
  |  | 残翅♂    | 168  |  结论3：           |
  |  +-----------------+  一对在常染色体... |
  |                       另一对在X染色体...|
  |           [上一步] [下一步]             |
  +-----------------------------------------+
  ```
- 关键实现要点：
  - 使用 SVG 的 `<g>` 标签将不同步骤的元素分组，例如 `<g id="scene1-step1-elements">`。
  - 状态机设计：定义一个 `currentStep` 变量（0-3），点击按钮时更新该变量，并调用 `updateView()` 函数。
  - `updateView()` 函数根据 `currentStep` 设置各分组的 `display` 或 `opacity` 属性，实现元素的显示和隐藏。
  - 动画过渡：可以为高亮框和文本添加 CSS `transition: opacity 0.3s ease`，使切换更平滑。
  - ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀，如 `scene1-btn-prev`, `scene1-highlight-blue`。
  - IIFE 隔离：整个脚本包裹在 `(function() { ... })()` 中。
