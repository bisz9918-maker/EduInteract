[视觉元素清单]
- 世代标签：P, F₁, F₂（黑色，加粗）
- 基因型与表现型文本：使用 SVG `<text>`，上下标使用 `<tspan dy="...">` 实现。
- 连线：使用 SVG `<path>` 和 `<line>`，颜色 #888888。P到F1为虚线 `stroke-dasharray="4,4"`，分支线为实线。
- 高亮颜色：长翅相关文本使用蓝色 #1565c0，小翅相关文本使用红色 #c62828，残翅相关文本使用绿色 #2e7d32。
- 比例框：`<rect>` 边框颜色 #000000，填充透明或极浅灰色，内部文本加粗。

[分步序列]
- 初始状态（步骤0）：仅显示 P 世代（P 标签、小翅♀(AAXᵇXᵇ)、×、残翅♂(aaXᴮY)）。
- 步骤1：点击「下一步」→ 显示 P到F1连线、F1 标签、长翅♀(AaXᴮXᵇ)、×、小翅♂(AaXᵇY)。长翅♀和小翅♂文本带有轻微放大动画以高亮“两种翅型”。
- 步骤2：点击「下一步」→ 显示 F2 标签、常染色体 3/4 A_、1/4 aa 及其分支线。
- 步骤3：点击「下一步」→ 显示性染色体 1/2 Xᴮ_ (长翅相关)、1/2 Xᵇ_ (小翅相关)、1 (任何性染色体) 及其分支线。
- 步骤4：点击「下一步」→ 显示结果 长翅 (3/8)、小翅 (3/8)、残翅 (1/4) 及其连线，同时在底部淡入显示最终比例框和文本“长翅 : 小翅 : 残翅 = 3 : 3 : 2”。

[标签冲突检查]
- P世代：小翅♀ (250,50) 与 残翅♂ (550,50) 间距 300px，中间有 × (400,50)，无冲突。
- F1世代：长翅♀ (250,120) 与 小翅♂ (550,120) 间距 300px，中间有 × (400,120)，无冲突。
- F2常染色体与性染色体：3/4 A_ (220,200) 右边缘约 250，1/2 Xᴮ_ (440,170) 左边缘约 360，间距 > 100px，连线空间充足，无冲突。
- F2性染色体与结果：1/2 Xᴮ_ (440,170) 右边缘约 520，长翅 (680,170) 左边缘约 630，间距 > 100px，无冲突。
- 垂直间距：F2 各分支 y 坐标分别为 170, 200, 230, 300，最小间距 30px，文本高度约 20px，无重叠。
- 底部比例框：y=360~400，F2 最低元素 y=300，垂直间距 60px，无冲突。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：在 SVG 底部 (y=450~490) 放置两个按钮，用于控制步骤 0 到 4 的切换。
- 教师操作流程：教师首先展示亲本，点击下一步展示 F1 并强调两种翅型；接着点击下一步展示 F2 的常染色体分离；再点击下一步展示性染色体分离；最后点击下一步展示组合结果和最终比例，完成整个反交实验的推导。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。遗传图解主要是文本和简单连线，原生 SVG 的 `<text>` 和 `<tspan>` 非常适合处理上下标，且易于控制精确坐标和动画。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
    P:   小翅♀  ×  残翅♂
           \      /
    F1:  长翅♀  ×  小翅♂
             |
    F2:    - 3/4 A_ - 1/2 Xᴮ_ - 长翅(3/8)
          /         \ 1/2 Xᵇ_ - 小翅(3/8)
         /
         \
           - 1/4 aa - 1 (X)   - 残翅(1/4)
           
       [ 长翅 : 小翅 : 残翅 = 3 : 3 : 2 ]
  [控件栏： ◀上一步   下一步▶ ]
  ```
- 关键实现要点：
  - 使用 `opacity` 和 `transition` 实现元素的淡入淡出。
  - 维护一个 `currentStep` 状态变量（0-4），每次点击按钮更新状态，并遍历所有受控元素，根据其 `data-step` 属性决定是否显示（`opacity: 1` 或 `0`）。
  - 上下标处理：例如 `X<tspan dy="-5" font-size="12">B</tspan><tspan dy="5"> </tspan>`，注意恢复基线。
  - ID 命名规范：所有交互元素 ID 必须以 `scene3-` 为前缀（如 `scene3-btn-next`, `scene3-f1-text`）。
  - IIFE 隔离：所有 JS 代码包裹在 `(function() { ... })()` 中，避免全局变量污染。
