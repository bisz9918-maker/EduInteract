[图示主题与整合说明]
- 本图示主题：甲病和乙病的遗传方式推导及后代概率计算
- 整合的步骤/概念：将系谱图分为左右两个家族，分别推导甲病（常染色体隐性）和乙病（显性，可能伴X）的遗传方式，最后结合两者计算特定后代的患病概率。
- 教学价值：通过分步高亮系谱图中的关键个体（如“无中生有”、“有中生无”），引导学生掌握遗传病推导的经典逻辑，避免视线分散，最后落实到基因型和概率计算。

[视觉元素清单]
- 节点：正常个体（白底黑边）、甲病（黑底黑边）、乙病（灰底 #999999 黑边）。XX男性为白底方块中心加小圆圈。
- 连线：黑色实线，线宽 2px。包含婚配线（水平）和子代线（垂直及水平分支）。
- 标签：个体标号（如 Ⅰ1、Ⅱ3），字体大小 14px，颜色 #333333。
- 高亮框：使用半径 r=22 的圆环，甲病推导用红色（stroke #c62828, fill rgba(198,40,40,0.2)），乙病推导用蓝色（stroke #1565c0, fill rgba(21,101,192,0.2)）。
- 基因型标签：在 III-2 和 III-3 下方显示，绿色 #2e7d32，字体 14px。

[分步序列]
- 初始状态（步骤0）：显示完整系谱图。顶部标题：“甲病和乙病的遗传方式推导”。无高亮。
- 步骤1：点击「下一步」→ 顶部标题变为“Ⅰ1、Ⅰ2正常，生出患甲病Ⅱ3 → 甲病为隐性遗传”（红色）。红高亮 I-1、I-2、II-3。
- 步骤2：点击「下一步」→ 顶部标题变为“Ⅱ10正常，生出患甲病Ⅲ4 → 甲病只能是常染色体隐性”（红色）。红高亮 II-10、III-4。
- 步骤3：点击「下一步」→ 顶部标题变为“Ⅰ3、Ⅰ4患乙病，生出正常Ⅱ8 → 乙病为显性遗传”（蓝色）。蓝高亮 I-3、I-4、II-8。
- 步骤4：点击「下一步」→ 顶部标题变为“Ⅰ3患病，其女儿Ⅱ9患病；(Ⅱ7患病) → 符合伴X显性特征”（蓝色）。蓝高亮 I-3、II-7、II-9。
- 步骤5：点击「下一步」→ 顶部标题变为“计算 Ⅲ2 和 Ⅲ3 生出正常孩子的概率”（绿色）。隐藏所有高亮。在 III-2 下方显示基因型“aa”，在 III-3 下方显示“AABb 或 AAX^BX^b”。底部显示公式：“正常概率 = 1 × 1/2 = 1/2”。

[技术实现]
- JS 库选择及原因：原生 SVG。系谱图由规则的几何图形和连线组成，SVG 的 DOM 结构非常适合绑定 class 进行状态切换和高亮动画。
- 画布尺寸：800 × 500 px。
- 布局草图：
  [图示区 800×500]
  顶部 (y=40): 动态结论文本
  中部 (y=100~340): 左右两个家族的系谱图
  底部 (y=420): 概率计算公式
  [控件栏 (y=460~490)]
- 关键实现要点：
  1. 使用 `<g>` 标签对节点、连线、高亮框进行分组，确保层级正确（高亮框在最底层，连线在中层，节点在顶层）。
  2. 状态机设计：定义 `currentStep` 变量（0-5），每次点击按钮更新变量，并通过 `document.querySelectorAll` 配合特定的 class（如 `.scene1-step1-hl`）控制元素的 `opacity`。
  3. 上标实现：使用 `<tspan dy="-5" font-size="10">` 实现 X^B 等基因型的上标显示。
  4. ID 命名规范：所有交互元素和关键节点均以 `scene1-` 为前缀，如 `scene1-btn-next`、`scene1-title`。
  5. IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
