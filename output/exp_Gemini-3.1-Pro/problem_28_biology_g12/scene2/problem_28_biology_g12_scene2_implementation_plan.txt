[图示主题与整合说明]
- 本图示主题：白毛与黑毛性状的伴性遗传分析
- 整合的步骤/概念：整合了第6问中“白毛♂ × 黑毛♀ → 雌性全白，雄性全黑”的交叉遗传现象及基因型推导。
- 教学价值：教师可通过分步演示，先展示交叉遗传的表型特征，再推导基因型，最后通过完整的遗传图解和染色体传递路径动画，直观揭示伴X显性遗传的本质。

[视觉元素清单]
- 小鼠图标：使用 SVG 椭圆组合（身体、头部、耳朵、尾巴）。白毛填充 `#ffffff` 描边 `#000000`，黑毛填充 `#424242` 描边 `#000000`。
- 基因型文本：使用 `<tspan>` 实现上标，如 `X<tspan dy="-5" font-size="12">B</tspan>`。
- 交叉遗传箭头：粗实线带箭头，红色 `#c62828`（父传女），蓝色 `#1565c0`（母传子）。
- 遗传图解连线：
  - X^B 路径：红色 `#c62828` 实线。
  - Y 路径：蓝色 `#1565c0` 实线。
  - X^b 路径：灰色 `#888888` 虚线。
- 文本框：半透明白色背景 `rgba(255,255,255,0.9)`，灰色边框，圆角。

[分步序列]
- 初始状态（步骤0）：仅显示 P代标签、P代小鼠图标及表现型标签（白毛♂、黑毛♀）、杂交符号。
- 步骤1：点击「下一步」→ 显示 F1代标签、F1代小鼠图标及表现型标签。出现红蓝交叉遗传曲线箭头，并在中央显示步骤1文本框（“交叉遗传：父亲的性状传给女儿，母亲的性状传给儿子”）。
- 步骤2：点击「下一步」→ 隐藏交叉遗传箭头和步骤1文本框。显示 P代和 F1代的基因型。在中央显示步骤2文本框（推导过程）。
- 步骤3（最终步骤）：点击「下一步」→ 隐藏步骤2文本框。显示配子（带圆圈）和完整的遗传图解连线。连线带有从上到下的绘制动画，直观展示染色体的传递路径。

[标签冲突检查]
- P代标签与基因型：标签在 y=115，基因型在 y=135，间距 20px，无冲突。
- F1代标签与基因型：标签在 y=385，基因型在 y=405，间距 20px，无冲突。
- 配子之间：X^B(200) 与 Y(300) 间距 100px，X^b左(500) 与 X^b右(600) 间距 100px，无冲突。
- 文本框与连线/箭头：步骤1文本框宽度 400px (x=200~600)，交叉遗传箭头控制点在 x=150 和 x=650，完美避开；步骤2文本框显示时，中间区域无任何连线，无冲突；步骤3显示连线时文本框隐藏，无冲突。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：底部中央放置两个按钮，控制步骤 0~3 的切换。
- 教师操作流程：教师先展示亲本（步0），点击下一步展示子代并引出交叉遗传概念（步1），再点击下一步引导学生推导基因型（步2），最后点击下一步展示完整的染色体传递过程（步3）。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。图形简单且需要精确的连线和动画控制，原生 SVG 是最佳选择。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```text
  [图示区 800×440]
    (y=80)   P代:  白毛♂(250)   ×(400)   黑毛♀(550)
    (y=220)  配子: X^B(200) Y(300)      X^b(500) X^b(600)
    (y=350)  F1代:      白毛♀(300)        黑毛♂(500)
  [控件栏 800×60] (y=440~500)
    [上一步] [下一步]
  ```
- 关键实现要点：
  - 状态机：使用 `currentStep` 变量记录当前步骤 (0-3)。
  - 显隐控制：为不同步骤的元素分组（如 `<g id="scene2-step1-elements">`），通过切换 CSS 类 `.hidden { display: none; }` 控制显隐。
  - 连线动画：为步骤3的连线添加 CSS 动画 `stroke-dasharray` 和 `stroke-dashoffset`，在进入步骤3时触发动画（可通过重新添加 class 实现）。
  - ID 命名规范：所有元素 ID 均以 `scene2-` 开头，如 `scene2-btn-next`，防止冲突。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
