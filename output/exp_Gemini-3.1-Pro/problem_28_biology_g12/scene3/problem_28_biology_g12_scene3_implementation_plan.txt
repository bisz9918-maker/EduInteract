[图示主题与整合说明]
- 本图示主题：两对相对性状的遗传及上位效应分析
- 整合的步骤/概念：整合了第7问中亲本基因型推导、两对基因的自由组合计算，以及无毛基因对毛发形状基因的上位掩盖作用。

[视觉元素清单]
- 布局框架：左侧推导区、右侧分支图区、底部图例区，由虚线分隔。
- 文本元素：所有推导逻辑和分支结果，使用不同颜色区分基因对（A/a为蓝色 #1565c0，D/d为绿色 #2e7d32）。
- 分支线：连接交配组合与子代概率的实线，颜色与基因对对应。
- 上位效应遮罩：一个半透明的红色矩形（#c62828，opacity: 0.3），用于在步骤4中盖住 "1/4 aaDd" 中的 "Dd" 部分，同时将 "(无毛)" 文字变为红色，直观展示上位效应。

[分步序列]
- 初始状态（步骤0）：显示左侧标题、右侧标题、分隔线，以及底部文本1和文本2（图例说明）。
- 步骤1：点击「下一步」→ 左侧出现步骤1的3行推导文本（分析亲本基因型）。
- 步骤2：点击「下一步」→ 左侧出现步骤2的推导文本及带边框的最终亲本组合结论。
- 步骤3：点击「下一步」→ 右侧出现 A/a 和 D/d 的交配文本、分支线及各自的子代概率结果（蓝色和绿色部分）。
- 步骤4：点击「下一步」→ 右侧出现组合等号和最终结果。随后在 "1/4 aaDd (无毛)" 上出现红色遮罩盖住 "Dd"，"(无毛)" 变红。底部出现文本3（结论）。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：在 SVG 底部 (y=450~490) 放置两个按钮，控制步骤 0 到 4 的切换。
- 教师操作流程：教师首先介绍两对基因及上位效应概念（步0）；然后引导学生逐步推导亲本基因型（步1-2）；接着利用分支法演示两对基因的独立遗传计算（步3）；最后组合结果并强调上位效应对最终表现型的影响，得出符合自由组合定律的结论（步4）。

[技术实现]
- JS 库选择及原因：原生 SVG。由于全是文本、简单线段和矩形，原生 SVG 配合 DOM 操作足以高效实现，无需引入庞大的外部库。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800x500]
  +-------------------+-----------------------+
  | 亲本基因型推导    | 分支法遗传图解        |
  |                   |                       |
  | 亲本: 卷毛x直毛   | Aa x Aa      dd x DD  |
  | 卷毛... -> Aadd   |   |--3/4 A_ -- 100% Dd|
  | 子代... -> AaD_   |   |                   |
  |                   |   |--1/4 aa -- 100% Dd|
  | 子代... -> DD     |                       |
  | [ Aadd x AaDD ]   |                       |
  +-------------------+-----------------------+
  | 基因：...                                 |
  | 上位效应：...                             |
  | 结论：...                                 |
  +-------------------------------------------+
  [控件栏: ◀上一步 | 下一步▶]
  ```
- 关键实现要点：
  - 使用 `<g>` 标签将不同步骤的元素分组，通过修改 `display` 或 `opacity` 属性实现步骤切换。
  - 步骤4的上位效应动画：先显示完整的 "1/4 aaDd (无毛)"，然后通过 CSS transition 或 setTimeout 延迟 300ms 显示红色遮罩，并将 "(无毛)" 的 `fill` 属性改为红色，增强视觉冲击力。
  - ID 命名规范：所有交互元素 ID 必须以 `scene3-` 为前缀（如 `scene3-step1-group`, `scene3-mask`）。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
