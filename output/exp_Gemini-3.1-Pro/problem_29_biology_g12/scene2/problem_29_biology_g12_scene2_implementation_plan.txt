[视觉元素清单]
- DNA双链：由两条平行的水平线段组成，长度30px，间距6px（即y-3和y+3）。
- 复制连接线：使用 #888888 虚线（stroke-dasharray="4,4"），从父代单链的中心连接到子代对应单链的中心。
- 颜色/样式：
  - 背景：#ffffff
  - 未标记母链（黑链）及常规文字：#000000
  - 32P标记新链（红链）及高亮数据：#c62828
  - 辅助连接线：#888888 虚线，线宽 1px
  - DNA链线宽：3px

[分步序列]
- 初始状态（步骤0）：显示 C0 DNA、"0次循环"标签。统计面板显示：当前循环次数 0，总单链数 2，未标记单链数 2，比例 1。
- 步骤1：点击「下一步」→ 显示 C1 的 2 个 DNA、"1次循环"标签，以及从 C0 到 C1 的虚线连接。统计面板更新：次数 1，总单链 4，未标记 2，比例 1/2。
- 步骤2：点击「下一步」→ 显示 C2 的 4 个 DNA、"2次循环"标签及连接线。统计面板更新：次数 2，总单链 8，未标记 2，比例 1/4。
- 步骤3：点击「下一步」→ 显示 C3 的 8 个 DNA、"3次循环"标签及连接线。统计面板更新：次数 3，总单链 16，未标记 2，比例 1/8。
- 步骤4：点击「下一步」→ 将整个树状图（DNA和连线）的透明度降至 0.1。在左侧区域居中显示「规律总结面板」（HTML Div），展示指数增长规律和比例公式。统计面板更新为代数形式（n, 2^{n+1}, 2, 1/2^n）。

- DNA与统计面板：最右侧的 C3 DNA 中心在 x=530，右边缘为 545。统计面板固定在 x=560。间距 15px，无冲突。

[交互方案]
- 交互类型：分步按钮导航（◀ 上一步 / 下一步 ▶）
- 控件说明：底部居中放置两个按钮。
- 教师操作流程：教师点击“下一步”逐代展示DNA复制过程，引导学生观察红色新链的增加和黑色母链的保留。最后一步展示公式，完成从具象到抽象的推导。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 HTML/JS。SVG 非常适合绘制精确的线条和树状结构，HTML Div 适合实现带格式的文本面板（如上标、列表）。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  | 0次   [=]                 [图例] |
  |                          [统计] |
  | 1次  [=]       [=]       [面板] |
  |                          [220 ] |
  | 2次 [=] [=]   [=] [=]    [x280] |
  |                          [    ] |
  | 3次 = = = =   = = = =    [    ] |
  [控件栏 ◀ 上一步   下一步 ▶        ]
  ```
- 关键实现要点：
  - 状态机设计：定义一个 `currentStep` 变量（0-4），每次点击按钮更新该变量，并调用 `renderStep()` 函数。
  - DOM 结构：SVG 放在底层，统计面板和规律总结面板使用 `position: absolute` 覆盖在 SVG 之上。
  - 动画效果：使用 CSS `transition: opacity 0.3s ease` 实现元素的淡入淡出。
  - ID 命名规范：所有元素 ID 必须以 `scene2-` 为前缀（如 `scene2-tree-group`, `scene2-stats-panel`）。
  - IIFE 隔离：所有 JS 代码必须包裹在 `(function() { ... })()` 中，避免全局变量污染。
