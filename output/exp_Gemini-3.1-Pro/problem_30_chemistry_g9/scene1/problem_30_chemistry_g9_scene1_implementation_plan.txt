[图示主题与整合说明]
- 本图示主题：初中化学物质推断过程动态演示
- 整合的步骤/概念：整合了寻找突破口（Y）、推断 N、推断 X 和 M 的完整逻辑链条。通过高亮反应连线和备选物质，直观展示物质间的反应关系。
- 教学价值：教师可以利用分步导航，像“剥洋葱”一样，一步步引导学生观察反应特征（如 Y 能发生 4 个反应），并在右侧备选物质中进行筛选，最终完成整个网络图的推断。

[视觉元素清单]
- 节点：5个圆形（X, Y, M, N, 铁），默认填充 `#f5f5f5`，边框 `#000000`。
- 连线：5条实线，1条带箭头的线，默认 `#000000` 2px。
- 备选物质卡片：5个圆角矩形，默认白底黑框。
- 物质标签：4个文本标签（X, Y, M, N 对应的物质），初始透明度为 0。
- 辅助虚线：5条贝塞尔曲线，`stroke-dasharray="5,5"`，初始透明度为 0。
- 颜色规范：
  - 默认状态：填充 `#f5f5f5`，边框/文本 `#000000`
  - 蓝高亮（当前推断）：填充 `rgba(21, 101, 192, 0.2)`，边框/文本/线条 `#1565c0`，线条加粗至 3px
  - 绿高亮（已确认）：填充 `rgba(46, 125, 50, 0.2)`，边框/文本/线条 `#2e7d32`

[分步序列]
- 初始状态（步骤0）：显示原题网络图（X, Y, M, N, 铁）和右侧 5 个备选物质卡片。所有元素为默认样式。标签和辅助虚线隐藏。
- 步骤1（突破口 Y）：点击「下一步」。节点 Y、卡片 3（稀盐酸）变为蓝高亮。与 Y 相连的 4 条线变为蓝色加粗。显示 Y 标签（稀盐酸）和 Y-卡3 的蓝色辅助虚线。
- 步骤2（推断 N）：点击「下一步」。节点 Y、卡片 3、Y 标签及辅助线变为绿高亮。Y 的 4 条连线恢复黑色（除 Y-N 外）。节点 N、卡片 2（氧化铁）变为蓝高亮。Y-N 连线和 N-铁 箭头变为蓝色加粗。显示 N 标签（氧化铁）和 N-卡2 的蓝色辅助虚线。
- 步骤3（推断 X 和 M）：点击「下一步」。节点 N、卡片 2、N 标签及辅助线变为绿高亮。Y-N、N-铁 连线恢复黑色。节点 X 和 M、卡片 4 和 5 变为蓝高亮。X-M 连线变为蓝色加粗。显示 X、M 标签和对应的蓝色辅助虚线。
- 步骤4（推断完成）：点击「下一步」。节点 X 和 M、卡片 4 和 5、标签及辅助线变为绿高亮。X-M 连线恢复黑色。节点 铁、卡片 1 变为绿高亮，并显示 铁-卡1 的绿色辅助虚线。全图推断完成。

[标签冲突检查]
- 标签"X" (120, 135) 与 标签"Y" (280, 135)：间距 160px，X 标签宽约 110px，Y 标签宽约 50px，无冲突。
- 标签"M" (200, 365) 与 标签"N" (360, 365)：间距 160px，M 标签宽约 110px，N 标签宽约 50px，无冲突。
- 标签"Y" (280, 135) 与 辅助线 Y-卡3：原计划辅助线从节点顶部(280, 155)向上出发会穿过标签。解决方案：辅助线起点改为标签顶部 (280, 120)，完美避开。
- 标签"X" (120, 135) 与 辅助线 X-卡4：同上，起点改为 (120, 120)。
- 标签"M" (200, 365) 与 辅助线 M-卡5：起点改为标签底部 (200, 380) 向下出发，避开标签。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：在 SVG 内部底部（y=450~490）放置一个绝对定位的 `div`，包含「上一步」按钮、步骤指示器（如“步骤 1 / 4”）和「下一步」按钮。
- 教师操作流程：教师首先展示原题，引导学生寻找连线最多的节点 Y。点击「下一步」高亮 Y，解释其对应稀盐酸。再次点击「下一步」高亮 N，解释其推断理由。依此类推，逐步完成整个关系图的推导。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。SVG 非常适合绘制节点、连线和贝塞尔曲线，且易于通过 DOM 操作修改颜色和样式。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  +---------------------------------------------------+
  |  (X)----------(Y)----------(铁)      [卡片1 铁]   |
  |    \          / \          /         [卡片2 氧]   |
  |     \        /   \        /          [卡片3 盐]   |
  |      \      /     \      /           [卡片4 钙]   |
  |       \    /       \    /            [卡片5 钠]   |
  |        (M)          (N)                           |
  |                                                   |
  |             [◀上一步] 步骤 0 / 4 [下一步▶]        |
  +---------------------------------------------------+
  ```
- 关键实现要点：
  - 状态机设计：定义一个包含 5 个状态的数组，每个状态对象详细记录所有节点、连线、卡片、标签和辅助线的样式（default, blue, green, hidden）。
  - 箭头标记：在 `<defs>` 中定义黑色和蓝色的 `<marker>`，用于 N-铁 的箭头，通过切换 `marker-end` 属性实现高亮。
  - 动画过渡：为 SVG 元素的 `fill`, `stroke`, `opacity` 添加 CSS `transition: all 0.3s ease`，使状态切换平滑自然。
  - ID 命名规范：所有元素 ID 必须以 `scene1-` 为前缀（如 `scene1-node-x`, `scene1-btn-next`）。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
