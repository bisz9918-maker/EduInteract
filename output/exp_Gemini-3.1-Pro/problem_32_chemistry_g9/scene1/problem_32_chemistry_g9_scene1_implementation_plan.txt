[图示主题与整合说明]
- 本图示主题：分子运动与反应产生白烟现象
- 整合的步骤/概念：操作活塞a、c，展示HCl与NH3气体分子的扩散过程，以及由于分子运动速率与质量成反比，NH3运动更快，导致在靠近A瓶处相遇并反应生成氯化铵白烟的现象。
- 教学价值：教师可通过分步控制，引导学生先观察活塞操作，再对比两种分子的扩散速度，最后观察相遇位置和反应产物，将宏观现象与微观分子运动规律完美结合。

[分步序列]
- 初始状态（步骤0）：活塞a、b、c均处于关闭状态（与导管垂直）。HCl分子在烧瓶A内随机微小运动，NH3分子在烧瓶B内随机微小运动。白烟及对应标签隐藏。
- 步骤1：点击「下一步」→ 活塞a和c旋转90度变为开启状态（与导管平行）。分子仍在瓶内运动，提示学生观察活塞状态。
- 步骤2：点击「下一步」→ 气体开始扩散。HCl分子沿导管A向下向右移动，NH3分子沿导管B向下向左移动。NH3分子的移动速度设为HCl分子的1.5倍。
- 步骤3：点击「下一步」→ 两种分子在导管 x=350 处（距离A瓶较近）相遇。相遇处逐渐显现灰色云雾状“白烟”，并淡入显示标签“白烟(NH4Cl)”。分子停止移动。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：在 SVG 底部 (y=460~490) 居中放置两个按钮。
- 教师操作流程：教师首先展示初始装置，讲解各部分名称；点击下一步打开活塞，引导学生思考气体将如何运动；再次点击下一步，展示分子扩散过程，强调速度差异；最后点击下一步，展示相遇点和白烟生成，得出分子运动速率与质量成反比的结论。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript (requestAnimationFrame)。SVG 适合绘制清晰的化学仪器和导管，原生 JS 足以处理分子的路径动画和状态机，无需引入庞大库。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800x500]
    (A)         (B)
   /   \       /   \
  | HCl |     | NH3 |
   \___/       \___/
     |           |滴管
     |c         a|
     +-----*-----+
           |白烟
           |b
        |¯¯¯¯¯|
        | 水  |
        |_____|
  [控件栏 y=460~490]
  ```
- 关键实现要点：
  - 状态机设计：使用 currentStep 变量记录当前步骤 (0-3)，根据步骤更新活塞旋转角度、分子位置和白烟透明度。
  - 分子动画：为每个分子对象存储当前坐标 (x, y) 和目标路径节点。在 requestAnimationFrame 循环中，若处于步骤0或1，分子在瓶内做随机布朗运动（限制在圆形区域内）；若处于步骤2，分子沿预定导管路径匀速移动，NH3 的步长设为 HCl 的 1.5 倍。
  - 坐标计算：烧瓶内部随机点生成需使用极坐标 r * cos(theta) 确保不出界。导管路径使用简单的状态机（向下 -> 转向 -> 向中间）。
  - ID 命名规范：所有元素 ID 以 scene1- 开头，如 scene1-flask-a, scene1-valve-c, scene1-btn-next。
  - IIFE 隔离：所有逻辑封装在 (function() { ... })() 中。
