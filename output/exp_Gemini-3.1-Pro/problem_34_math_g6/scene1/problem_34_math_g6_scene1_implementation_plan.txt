[图示主题与整合说明]
- 本图示主题：利用平移法求不规则图形周长
- 整合的步骤/概念：展示原图形 -> 高亮周长 -> 平移线段 -> 展示等效周长及计算
- 教学价值：教师可通过分步演示，直观地向学生展示如何通过线段平移，将不规则图形的周长转化为规则图形（长方形）的周长加上额外的线段，从而简化计算过程。

[视觉元素清单]
- 基础图形：`polygon`，顶点为 250,80 -> 550,80 -> 550,130 -> 450,130 -> 450,230 -> 550,230 -> 550,280 -> 250,280。填充 #000000（透明度10%），描边 #000000（2px）。
- 初始周长高亮：与基础图形相同的 `polygon`，描边 #1565c0（4px），无填充。
- 移动线段：`line`，起点 450,130，终点 450,230。描边 #c62828（4px）。
- 辅助虚线：三条 `line`（平移轨迹1、2和原位置虚线），描边 #888888（2px，虚线 `stroke-dasharray="5,5"`）。
- 完整长方形高亮：`rect`，左上角 250,80，宽 300，高 200。描边 #1565c0（4px），无填充。
- 额外线段：两条 `line`，分别在 y=130 和 y=230，x 从 450 到 550。描边 #2e7d32（4px）。
- 文本标签："4", "6", "2"，字体大小 18px，颜色 #000000。
- 计算公式文本：三行文本，字体大小 18px，颜色 #000000，`text-anchor="middle"`。

[分步序列]
- 初始状态（步骤0）：显示基础图形、标签"4"、"6"、"2"。隐藏所有高亮、移动线段、虚线和计算公式。
- 步骤1（识别周长）：显示初始周长高亮（蓝色 #1565c0），帮助学生明确周长包含哪些线段。
- 步骤2（线段平移）：隐藏初始周长高亮。显示移动线段（红色 #c62828）在 x=450。触发动画：移动线段平移至 x=550。同时显示原位置虚线和平移轨迹虚线（灰色 #888888）。
- 步骤3（等效转化）：隐藏移动线段。显示完整长方形高亮（蓝色 #1565c0）和两条额外线段（绿色 #2e7d32），强调平移后周长由完整长方形周长和两条额外线段组成。
- 步骤4（得出结论）：依次淡入显示三行计算公式，得出最终周长 24。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：在 SVG 底部 (y=450 区域) 放置“上一步”和“下一步”按钮。
- 教师操作流程：教师点击“下一步”逐步引导学生观察周长、演示平移过程、分析等效周长构成，最后展示计算结果。可随时点击“上一步”回退。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。图形均为简单多边形和线段，SVG 的 DOM 操作和 CSS 过渡动画（`transition`）足以实现平滑的平移和淡入淡出效果，无需引入庞大的外部库。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
    (250,80) +------------------------+ (550,80)
             |                        |
             |                        + (550,130)
             |                        |
        4    |            +-----------+ (450,130)
             |            | 2
             |            +-----------+ (450,230)
             |                        |
             |                        + (550,230)
             |                        |
   (250,280) +------------------------+ (550,280)
                         6
             原长方形周长 = (6 + 4) × 2 = 20
             多出的两条线段 = 2 + 2 = 4
             总周长 = 20 + 4 = 24
  [控件栏（上一步/下一步按钮，在SVG内底部 y=460）]
  ```
- 关键实现要点：
  - 使用 CSS `transition: transform 1s ease-in-out, opacity 0.5s` 实现平移和渐变动画。
  - 状态机设计：定义 `currentStep` 变量（0-4），每次点击按钮更新状态，并调用 `updateScene()` 函数。
  - `updateScene()` 函数根据 `currentStep` 设置各 SVG 元素的 `opacity` 和 `transform` 属性。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-shape`, `scene1-btn-next`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
