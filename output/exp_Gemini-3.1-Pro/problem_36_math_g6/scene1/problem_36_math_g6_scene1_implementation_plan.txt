[视觉元素清单]
- 基础图形：圆A、圆B、圆C（黑线透明底），直线a（黑实线），辅助线BC（灰虚线），初始重叠区（灰填充 20%透明度）
- 高亮区域-下方：直线a下方的三个圆的并集（蓝色 #1565c0，10%透明度）
- 高亮区域-上方：直线a上方的A、B圆的并集（蓝色 #1565c0，30%透明度）
- 高亮重叠-全部：A与B、B与C的重叠区（红色 #c62828，50%透明度）
- 高亮重叠-上方：A与B在直线a上方的重叠区（红色 #c62828，60%透明度）
- 遮罩层：白色半透明矩形（y=200至500，80%不透明度），用于淡化直线a下方的图形

[分步序列]
- 初始状态（步骤0）：显示基础图形（三个圆、直线a、辅助线BC、灰色初始重叠区）。文本提示已知条件。
- 步骤1：显示“高亮区域-下方”（带标签 9）和“高亮区域-上方”（带标签 2S-7）。文本推导上方区域面积。
- 步骤2：激活“遮罩层”淡化下方图形，仅保留上方区域高亮。文本提示上方区域的构成。
- 步骤3：隐藏遮罩层和上方高亮，显示“高亮重叠-全部”（带标签 (S-2)/2）。文本推导总重叠面积及单处重叠面积。
- 步骤4：重新激活遮罩层和上方高亮，隐藏全部重叠，显示“高亮重叠-上方”（带标签 (S-2)/4）。文本推导上方重叠面积。
- 步骤5：保持步骤4状态，新增标签 S/2（左/右）。文本展示最终容斥原理方程并求解。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：底部居中放置两个按钮，控制 0~5 共 6 个状态的切换。
- 教师操作流程：教师点击“下一步”逐步展示面积推导过程，配合底部文本框的公式进行讲解。

[技术实现]
- JS 库选择及原因：原生 SVG，适合实现精确的几何图形、clipPath 裁剪（用于精确高亮半圆和重叠区）及透明度叠加。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×360] (包含圆、直线及各类高亮)
  [文本区 800×80] (y=360~440，显示当前步骤的推导文字)
  [控件栏 800×50] (y=450~500，包含上一步/下一步按钮)
  ```
- 关键实现要点：
  1. 使用 `<clipPath>` 实现区域高亮：定义 `clip-below-a` (y>200) 和 `clip-above-a` (y<200) 裁剪矩形，以及 `clip-circle-a` 和 `clip-circle-b` 裁剪圆。
  2. 状态机设计：定义 `currentStep` 变量（0-5），每次切换时统一更新各 SVG `<g>` 组的 `display` 属性和文本框的 `innerHTML`。
  3. 遮罩淡化：使用一个覆盖下半部 (y=200~500) 的白色半透明 `<rect>` 实现下方图形的淡化，比逐个修改元素透明度更简洁高效。
- ID 命名规范：所有元素 ID 必须以 `scene1-` 为前缀（如 `scene1-btn-next`, `scene1-hl-above`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
