[图示主题与整合说明]
- 本图示主题：中心投影与影子长度的动态关系
- 整合的步骤/概念：路灯、物体、点光源光线、影子长度、距离 a 的动态变化
- 教学价值：教师可通过拖动物体或滑动滑块，直观展示物体与光源距离（a）的变化如何影响光线倾斜度，进而改变影子长度，帮助学生理解中心投影的几何规律。

[视觉元素清单]
- 地面：#000000，2px实线，带有斜线阴影。
- 路灯：#000000，4px实线。标签"路灯"位于(110, 230)。
- 光源：#fbc02d，圆形填充。标签"光源"位于(150, 55)。
- 物体：#000000，2px实线框，内部可填充#eeeeee。标签"物体"位于(x-35, 230)。
- 光线：#fbc02d，2px实线，从(150,80)连接至(x_s,380)。
- 影子：#c62828，6px加粗实线。标签"影子"位于((x+x_s)/2, 360)。
- 距离a：#1565c0，2px实线双向箭头。标签"a"位于((150+x)/2, 440)。辅助虚线#888888。

[分步序列]
- 初始状态（单一状态，连续交互）：
  显示路灯、物体（x=350）、光线、影子（长度100）、距离a。
  教师可直接拖动物体或底部滑块。
  - 当 a 变小（物体左移，如x=250）：光线变陡，影子变短（长度50）。
  - 当 a 变大（物体右移，如x=500）：光线变缓，影子变长（长度175）。

[标签冲突检查]
- "光源"：(150, 55)，周围无其他元素，无冲突。
- "路灯"：(110, 230)，在路灯左侧，无冲突。
- "物体"：(x-35, 230)，在物体左侧，与路灯(150)的最小距离为 250-35-150 = 65px，无冲突。
- "影子"：((x+x_s)/2, 360)，在影子上方。当x=250时，x_s=300，中心为275，物体右边缘为260，间距15px，无冲突。
- "a"：((150+x)/2, 440)，在箭头下方，无冲突。

[交互方案]
- 交互类型：连续拖拽/滑块
- 控件说明：
  - 滑块：位于 SVG 底部控件区（y=460），范围 250 到 500，初始值 350。
  - 拖拽：物体本身支持鼠标拖拽水平移动。
- 教师操作流程：教师在讲解时，拖动物体靠近或远离路灯，引导学生观察光线角度的变化以及影子长度的对应变化，从而得出"a越小，影子越短；a越大，影子越长"的结论。

[技术实现]
- JS 库选择及原因：原生 SVG。SVG 适合绘制几何图形和处理简单的拖拽交互，DOM 操作直观。
- 画布尺寸：800 × 500 px
- 布局草图：
  [图示区 800×440]
  [控件栏 800×60，包含一个居中的 range input]
- 关键实现要点：
  - 状态变量：`objectX`，初始值 350。
  - 坐标计算：
    - 光源 `L(150, 80)`
    - 物体顶部 `T(objectX, 280)`
    - 根据相似三角形或斜率计算光线与地面交点 `S(x_s, 380)`：
      `(380 - 80) / (x_s - 150) = (280 - 80) / (objectX - 150)`
      `300 / (x_s - 150) = 200 / (objectX - 150)`
      `x_s = 150 + 1.5 * (objectX - 150)`
  - 动画/更新：监听滑块的 `input` 事件和物体的 `mousedown`/`mousemove`/`mouseup` (及 touch 对应事件)，实时更新 `objectX`，并重新计算 `x_s`，更新光线、影子、物体、距离 a 及其标签的 SVG 属性（`x`, `y`, `x1`, `y1`, `x2`, `y2` 等）。
  - ID 命名规范：使用 `scene1-` 前缀，如 `scene1-object`, `scene1-ray`, `scene1-shadow`, `scene1-slider`。
  - IIFE 隔离：所有逻辑封装在 `(function() { ... })()` 中。
