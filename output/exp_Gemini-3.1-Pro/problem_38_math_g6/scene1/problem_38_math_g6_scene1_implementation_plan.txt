[图示主题与整合说明]
- 本图示主题：两个立体图形的三视图动态投影对比
- 整合的步骤/概念：整合了从前面、上面、左面三个方向观察并生成二维投影的完整过程，通过 3D 到 2D 的平滑过渡（压平动画），直观展示降维过程，避免孤立的静态图片。
- 教学价值：教师可通过点击按钮自由切换视角，动态演示 3D 积木如何投影为 2D 平面图形。双视口对比设计和红色闪烁高亮能有效帮助学生发现两个图形在不同视角下的形状差异。

[视觉元素清单]
- 图1 (3D 积木组)：7 个小正方体。材质颜色 `#1565c0`（透明度 0.7，开启 transparent），黑色边缘线宽 1.5px（使用 EdgesGeometry）。
- 图2 (3D 积木组)：5 个小正方体。材质颜色 `#2e7d32`（透明度 0.7，开启 transparent），黑色边缘线宽 1.5px。
- 投影幕布 (背景网格)：在每个场景中包含 3 个正交的半透明网格面（XY, XZ, YZ 平面），颜色 `#f5f5f5`，网格线 `#888888`，模拟三维坐标系角落，作为投影背景。
- 差异高亮边框：SVG 路径，颜色 `#c62828`，线宽 4px，带 CSS 闪烁动画（`flashRed` keyframes）。

[分步序列]
- 初始状态（步骤0）：斜二测视角。相机位于 (4, 3, 5) 看向原点。积木保持 3D 立体形态（缩放 1,1,1）。隐藏所有高亮轮廓。
- 步骤1（点击「从前面看」）：相机平滑移动至 (0, 0, 6)，积木 Z 轴缩放平滑过渡至 0.01（压平效果）。动画结束后，显示图1和图2的“前面高亮”SVG 路径并闪烁。
- 步骤2（点击「从上面看」）：相机平滑移动至 (0, 6, 0)，相机 up 向量平滑过渡至 (0,0,-1)，积木 Y 轴缩放平滑过渡至 0.01。动画结束后，显示“上面高亮”SVG 路径并闪烁。
- 步骤3（点击「从左面看」）：相机平滑移动至 (-6, 0, 0)，相机 up 向量平滑过渡至 (0,1,0)，积木 X 轴缩放平滑过渡至 0.01。动画结束后，显示“左面高亮”SVG 路径并闪烁。

[标签冲突检查]
- 本场景无动态文本标签。
- 固定的“图1”和“图2”标题位于视口顶部空白区，不会与居中的 3D 图形冲突。
- SVG 高亮路径严格贴合 2D 投影轮廓外边缘，不会相互遮挡。

[交互方案]
- 交互类型：多状态切换（4个按钮）。
- 控件说明：底部控件栏包含「复原」、「从前面看」、「从上面看」、「从左面看」四个按钮。
- 教师操作流程：教师首先展示 3D 初始状态，然后依次点击三个视角按钮。每次点击后，图形会平滑压平为 2D 投影，并闪烁红框，教师可借此引导学生观察并得出“三个视角的形状均不相同”的结论。

[技术实现]
- JS 库选择及原因：使用 Three.js 实现 3D 积木的渲染和正交相机的平滑过渡；使用原生 SVG 叠加层实现精确的 2D 轮廓高亮闪烁。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图1 视口 400x450] | [图2 视口 400x450]
  [       SVG 高亮覆盖层 (穿透点击)      ]
  [ 控件栏: 复原 | 前面 | 上面 | 左面  ]
  ```
- 关键实现要点：
  1. **双场景双视口**：创建两个独立的 `THREE.Scene`，共用一个 `WebGLRenderer`。在 `render` 循环中通过 `renderer.setViewport` 分别渲染左半区(0, 50, 400, 450)和右半区(400, 50, 400, 450)，彻底杜绝两个图形在侧视图中重叠。
  2. **正交相机与压平动画**：使用 `OrthographicCamera`（frustumSize 设为 6）。视角切换时，使用 `lerp` 平滑插值相机位置，使用 `slerp` 插值相机四元数（避免万向节死锁）。同时使用 `lerp` 将积木的对应轴 `scale` 缩放至 0.01，实现完美的 3D 到 2D 压平视觉效果。
  3. **SVG 精确高亮**：预先计算好 3 个视角下 2D 投影的精确屏幕坐标路径。例如图1前面路径（中心200,225，单位75px）：`M 87.5 300 L 312.5 300 L 312.5 225 L 237.5 225 L 237.5 150 L 87.5 150 Z`。通过 CSS class 控制其 `opacity` 和 `animation` 实现闪烁。
  4. **ID 命名规范**：所有 DOM 元素 ID 必须以 `scene1-` 开头（如 `scene1-container`, `scene1-btn-front`）。
  5. **IIFE 隔离**：所有逻辑封装在 `(function() { ... })()` 中。
