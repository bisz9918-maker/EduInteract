前提条件：

同一物体在相同水平地面上做匀速直线运动，因此物体受到的滑动摩擦力 \(f\) 均相等。

图(1) 定滑轮：

定滑轮不省力，绳子张力 \(T_1 = F_1\)。

物体匀速运动，受力平衡：\(T_1 = f\)

结论：\(F_1 = f\)

图(2) 动滑轮（省力）：

将滑轮和物体看作整体，受向右的摩擦力 \(f\) 和两段绳子向左的拉力 \(F_2\)。

受力平衡：\(2F_2 = f\)

结论：\(F_2 = rac{1}{2}f\)

图(3) 动滑轮（费力）：

物体受力平衡，绳子张力 \(T_3 = f\)。

对滑轮受力分析，受向右的拉力 \(F_3\) 和两段绳子向左的张力 \(T_3\)。

受力平衡：\(F_3 = 2T_3 = 2f\)

结论：\(F_3 = 2f\)

最终结论：

因为 \(F_2 = 0.5f\), \(F_1 = f\), \(F_3 = 2f\)

所以 \(F_2 < F_1 < F_3\)，选 D。
