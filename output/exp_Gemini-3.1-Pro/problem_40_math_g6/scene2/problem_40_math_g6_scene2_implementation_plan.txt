- 本图示主题：选项A的3D折叠验证
- 整合的步骤/概念：将选项A的平面展开图动态折叠成3D正方体，并与题目原图进行视角比对，验证相邻面的位置关系。

[视觉元素清单]
- 题目原图(3D)：一个完整的正方体，正面为心形，右面为笑脸，上面为星形。边框黑色 #000000，面填充白色 #ffffff。
- 选项A展开图(3D)：由6个正方形面组成，按选项A的布局排列。
  - Base (底面)：星形
  - Face1 (前面)：心形
  - Face2 (右面)：笑脸
  - Face3 (上面)：星形
  - Face4 (后面)：心形
  - Face5 (左面)：笑脸
- 折痕辅助线：在展开图的相邻面之间绘制 #888888 虚线，指示折叠位置。
- 高亮边框：折叠完成（滑块100%）时，Face1、Face2、Face3的边框变为绿色 #2e7d32 并加粗。

[分步序列]
- 初始状态（滑块=0%）：右侧显示选项A的完全平铺展开图。所有面在同一平面上。隐藏成功提示。
- 拖拽滑块（0% -> 100%）：展开图各面绕折痕旋转。Face1向上折叠，Face2~5依次向内折叠。折叠角度与滑块值成正比（0到90度）。
- 匹配视角（滑块=100%）：折叠成完整正方体。由于初始设置了固定的等轴测视角，折叠完成时，右侧正方体的正面（心形）、右面（笑脸）、上面（星形）刚好与左侧的题目原图完美对齐。此时这三个面的边框高亮为绿色 #2e7d32，底部显示“视角匹配成功！”。

[标签冲突检查]
- "题目原图" (150, 380) 与 "选项A展开图" (500, 380)：水平间距 350px > 20px，无冲突。
- "折叠进度" (350, 445) 与 滑块 (250, 465)：垂直间距 20px，无冲突。
- 滑块 (250, 465) 与 "成功提示" (300, 485)：垂直间距 20px，无冲突。
- 3D模型投影与所有HTML标签：3D模型主要在 y=100~300 范围内渲染，HTML标签在 y=380 及以下，完全隔离，无冲突。

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：底部居中放置一个 `<input type="range">`，范围 0-100。
- 教师操作流程：教师首先让学生观察左侧原图和右侧展开图。然后缓慢拖动滑块，让学生观察每个面是如何折叠并在空间中定位的。当滑块拖到100%时，引导学生对比左右两个正方体，确认图案位置完全一致，从而验证选项A是正确的。

[技术实现]
- JS 库选择及原因：Three.js (用于3D建模、层级旋转和等轴测视角渲染)。
- 画布尺寸：800 × 500 px (3D Canvas 800x440, 底部留白给HTML控件)。
- 布局草图：
  ```
  [图示区 800x440]
    (左侧: 3D原图)      (右侧: 3D展开图/折叠动画)
       题目原图             选项A展开图
  [控件区 800x60]
       折叠进度: X%
       [========O--------]
       视角匹配成功！(100%时显示)
  ```
- 关键实现要点：
  1. **图案纹理**：使用 Canvas 2D API 动态生成心形、笑脸、星形的纹理，作为 `THREE.CanvasTexture` 应用到 `MeshBasicMaterial` 上。
  2. **层级结构与折叠逻辑**：
     - 构建父子层级：`Base -> Hinge1 -> Face1 -> Hinge2 -> Face2 -> Hinge3 -> Face3` (Face4, Face5 也挂载在相应层级)。
     - 将 Hinge 的 position 设置在面的边缘，实现绕边旋转。
     - 旋转公式：`angle = (sliderValue / 100) * (Math.PI / 2)`。
     - `hinge1.rotation.x = angle`
     - `hinge2.rotation.y = -angle`
     - `hinge3.rotation.x = angle`
     - `hinge4.rotation.y = -angle`
     - `hinge5.rotation.y = -angle`
  3. **统一视角**：创建一个 `sceneGroup` 包含左侧原图和右侧展开图，设置 `sceneGroup.rotation.set(Math.PI / 6, -Math.PI / 4, 0)` 实现等轴测视角。右侧展开图的根节点初始设置 `rotation.x = -Math.PI / 2` 使其平铺在地面上。
  4. **高亮反馈**：监听滑块 input 事件，当值为 100 时，修改 Face1, Face2, Face3 的 `EdgesGeometry` 材质颜色为 `#2e7d32`，并显示成功提示文本。
- ID 命名规范：所有交互元素 ID 必须以 `scene2-` 为前缀（如 `scene2-slider`, `scene2-container`）。
- IIFE 隔离：所有 JS 代码包裹在 `(function() { ... })()` 中。
