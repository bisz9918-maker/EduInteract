[图示主题与整合说明]
- 本图示主题：中心投影下影长随距离变化的动态演示
- 整合的步骤/概念：整合了小亮的运动轨迹、光线传播路径、影子的形成以及影子长度的动态变化过程。
- 教学价值：教师可以通过拖动滑块，直观地向学生展示小亮从A点走到B点过程中，光线角度的变化如何导致影子长度先变短后变长，帮助学生理解中心投影的规律，轻松得出正确答案。

[视觉元素清单]
- 地面：水平线段，#000000，2px宽。
- 路灯杆：垂直线段，#000000，4px宽。
- 光源：实心圆，#000000，半径6px。标签"光源"在(500, 80)，居中对齐。
- 点A：实心圆，#000000，半径4px。标签"A"在(250, 425)，居中对齐。
- 点B：实心圆，#000000，半径4px。标签"B"在(650, 425)，居中对齐。
- 小亮：垂直线段，#1565c0（蓝高亮），6px宽，圆角端点。标签"小亮"在(x, 285)，居中对齐。
- 光线：射线（线段），#888888，2px宽，虚线(5,5)。
- 影子：水平线段，#c62828（红高亮），6px宽，圆角端点。标签"影子"在((x+S_x)/2, 425)，居中对齐。

[分步序列]
- 初始状态：滑块在最左侧，小亮位于A点(x=250)。光线从(500,100)经过小亮头顶(250,300)到达地面(125,400)。影子在小亮左侧，长度为125px。
- 拖动滑块向右：小亮向路灯移动(250 < x < 500)。光线变陡，影子长度逐渐变短。
- 到达路灯正下方：小亮位于(x=500)。光线垂直向下，影子长度为0（S_x=500）。
- 继续拖动向右：小亮向B点移动(500 < x <= 650)。影子出现在小亮右侧，光线变平缓，影子长度逐渐变长。到达B点时，影子端点在(725,400)，长度为75px。

[标签冲突检查]
- 标签"光源"：(500, 80)。周围无其他元素，无冲突。
- 标签"A"：(250, 425)。
- 标签"B"：(650, 425)。
- 标签"小亮"：(x, 285)。随小亮移动，始终在小亮正上方15px，不会与其他标签冲突。
- 标签"影子"：((x+S_x)/2, 425)。
  - 当 x=250 时，影子中心在 187.5。"影子"与"A"(250) 间距 62.5px > 20px，无冲突。
  - 当 x=500 时，影子中心在 500。"影子"与"A"、"B" 间距均 > 100px，无冲突。
  - 当 x=650 时，影子中心在 687.5。"影子"与"B"(650) 间距 37.5px > 20px，无冲突。
  - 结论：所有标签在整个动态过程中均无重叠冲突。

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：在SVG底部（y=460区域）居中放置一个 `<input type="range">` 滑块，范围 min="250" max="650" value="250" step="1"。滑块前可加文字提示"移动小亮："。
- 教师操作流程：教师在讲解时，缓慢拖动滑块，引导学生观察影子长度的连续变化（先变短，过路灯后变长），从而直观得出"先变短后变长"的结论。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。图形简单，仅需更新几个坐标属性，原生 SVG 性能好且易于实现。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  ------------------------------------------------
  |                      光源(500,100)           |
  |                        |                     |
  |                        |                     |
  |       小亮(x,300)       |                     |
  |         |              |                     |
  | 影子    |              |                     |
  |-------A(250)---------路灯(500)-------B(650)--| 地面(y=400)
  ------------------------------------------------
  [控件栏: 移动小亮 [========O-----------] ] (y=460)
  ```
- 关键实现要点：
  - 监听滑块的 `input` 事件，获取当前小亮的 x 坐标。
  - 计算影子端点坐标 `S_x = 1.5 * x - 250`。
  - 更新小亮线段的 `x1`, `x2` 属性。
  - 更新光线线段的 `x2` 属性为 `S_x`。
  - 更新影子线段的 `x1` 为 `x`，`x2` 为 `S_x`。
  - 更新"小亮"标签的 `x` 属性。
  - 更新"影子"标签的 `x` 属性为 `(x + S_x) / 2`。
- ID 命名规范：所有元素 ID 以 `scene1-` 开头，如 `scene1-slider`, `scene1-xiaoliang`, `scene1-shadow` 等。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
