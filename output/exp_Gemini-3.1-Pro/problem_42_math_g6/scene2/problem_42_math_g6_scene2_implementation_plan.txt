[图示主题与整合说明]
- 本图示主题：3D 几何体构建与三视图投影验证
- 整合的步骤/概念：整合了 3D 模型搭建、正投影原理展示、以及与原题三视图的对比验证。
- 教学价值：教师可通过分步演示，让学生清晰观察几何体在主、左、俯三个方向的投影规律。3D 场景支持自由旋转，帮助学生建立空间想象力，验证 5 个小正方体的组合方式与题目给定的三视图完全一致。

[视觉元素清单]
- 3D 坐标系与空间网格：`GridHelper`，位于 y = 0，颜色 `#cccccc`。
- 5 个 3D 小正方体：`BoxGeometry`，填充色 `#1565c0`（透明度 0.8），边缘线 `#000000`。
- 三个半透明投影面：`PlaneGeometry`，填充色 `#f5f5f5`（透明度 0.5，双面），边缘虚线 `#888888`。
- 动态虚线投影射线：`LineDashedMaterial`，颜色 `#888888`，连接正方体顶点与投影面。
- 2D 投影轮廓（阴影）：`PlaneGeometry`，填充色 `#c62828`（透明度 0.2，双面），边缘线 `#000000`。
- 文本标签：使用 Canvas 绘制文字生成 `CanvasTexture`，作为 `Sprite` 材质。

[分步序列]
- 初始状态（步骤0）：显示 3D 网格和 3 个投影面。5 个正方体位于高空 (y=5) 隐藏。射线和阴影隐藏。相机位于等轴测视角 (5, 5, 5)。
- 步骤1（构建模型）：点击「下一步」，5 个正方体平滑下落到目标位置，组合成目标几何体。
- 步骤2（主视图验证）：点击「下一步」，相机平滑移动到正前方 (0, 0, 10)，`up` 向量为 (0, 1, 0)。主视图的投影射线出现（虚线流动动画），随后主视图阴影在后方投影面 (z=-2.5) 显现。
- 步骤3（左视图验证）：点击「下一步」，相机平滑移动到左侧方 (-10, 0, 0)，`up` 向量为 (0, 1, 0)。左视图的投影射线出现，左视图阴影在右方投影面 (x=2.5) 显现。主视图射线隐藏（阴影保留）。
- 步骤4（俯视图验证）：点击「下一步」，相机平滑移动到正上方 (0, 10, 0)，`up` 向量平滑过渡为 (0, 0, -1)。俯视图的投影射线出现，俯视图阴影在下方投影面 (y=-1.5) 显现。左视图射线隐藏（阴影保留）。
（教师可随时点击「上一步」回退，回退时撤销对应阴影和射线，相机移回上一位置）

[标签冲突检查]
- 主视图标签：坐标 (0, 2.8, -2.5)
- 左视图标签：坐标 (2.5, 2.8, 0)
- 俯视图标签：坐标 (0, -1.5, -2.5)
- 冲突检查：三个标签在 3D 空间中分布于不同的投影面边缘，两两之间直线距离均大于 2.5 个单位。在正交相机的各个标准视角下，标签均位于屏幕边缘空白处，绝不会与几何体或投影阴影重叠。无冲突。

[交互方案]
- 交互类型：分步按钮导航（◀ 上一步 / 下一步 ▶）。
- 控件说明：底部居中放置半透明面板，包含上一步、下一步按钮及当前步骤指示文本（如“步骤 2/4：主视图验证”）。
- 教师操作流程：教师点击“下一步”逐步演示几何体的搭建和三个方向的投影过程。在任意步骤，教师均可使用鼠标拖拽旋转、缩放 3D 场景，从不同角度向学生展示投影的对应关系。点击步骤按钮时，系统会自动接管相机并平滑过渡到标准正交视角。

[技术实现]
- JS 库选择及原因：使用 `Three.js` 构建 3D 场景和正交投影；使用 `OrbitControls` 实现鼠标自由旋转；使用 `TWEEN.js` 实现相机位置、`up` 向量及正方体下落的平滑动画。
- 画布尺寸：800 × 500 px。
- 布局草图：
  [图示区 800×500 (全屏 3D Canvas)]
  [控件栏 (y=450~490，绝对定位，包含 2 个按钮和 1 个文本标签)]
- 关键实现要点：
  1. 相机设置：必须使用 `OrthographicCamera`，确保在正视投影面时，3D 几何体与 2D 阴影完美重合，无透视变形。
  2. 动画过渡：使用 `TWEEN.Tween` 同时对 `camera.position` 和 `camera.up` 进行插值，并在 `onUpdate` 中调用 `camera.lookAt(0,0,0)`，确保视角切换平滑。
  3. 射线动画：投影射线使用 `LineDashedMaterial`，在 `requestAnimationFrame` 中不断递减 `dashOffset`，实现虚线向投影面流动的视觉效果。
  4. 阴影防闪烁：2D 阴影平面需稍微偏离投影面（如 z=-2.49），避免 Z-fighting 闪烁。
- ID 命名规范：所有交互元素 ID 必须以 `scene2-` 为前缀（如 `scene2-btn-next`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
