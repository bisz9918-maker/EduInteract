[图示主题与整合说明]
- 本图示主题：昆虫的完全变态与不完全变态发育路径解析
- 整合的步骤/概念：将题目原图的拓扑结构与两种不同的发育路径（蝗虫/蟋蟀的不完全变态，蚊/家蚕的完全变态）进行动态映射，并逐一验证选项。
- 教学价值：教师可通过分步导航，先展示原图，再分别剥离出两种发育路径，通过高亮和动态标签，帮助学生直观理解节点B、C、D在不同昆虫发育过程中的具体含义，最终建立统一的发育模型，轻松破解此类识图题。

[视觉元素清单]
- 节点：A, B, C, D（带字母的圆形，默认黑边灰底 `rgba(0,0,0,0.1)`）
- 箭头：5条有向线段，需定义4种颜色的SVG marker（黑、蓝、红、灰）
- 标签：SVG text，使用 `text-anchor="middle"` 和 `dominant-baseline="central"`
- 信息面板：绝对定位的 HTML div，带圆角和阴影，背景 `#f8f9fa`
- 颜色/样式：
  - 背景：#ffffff
  - 默认/主线：#000000（2px）
  - 不完全变态高亮：#1565c0（蓝，4px）
  - 完全变态高亮：#c62828（红，4px）
  - 弱化辅助线：#888888（灰，2px，虚线 `stroke-dasharray="5,5"`）

[分步序列]
- 初始状态（步骤0）：
  - 显示节点A, B, C, D及所有黑色箭头（2px）。
  - 仅显示A节点标签“卵”（黑色）。
  - 信息面板提示：“请点击‘下一步’查看不同昆虫的发育路径，并验证选项。”
- 步骤1（不完全变态）：
  - 高亮路径 A→B→D→A（蓝色，4px），节点A, B, D蓝色边框。
  - 弱化路径 D→C, C→A（灰色虚线，2px），节点C灰色虚线边框。
  - 新增标签：B旁“若虫”（蓝色），D旁“成虫”（蓝色）。
  - 信息面板：展示不完全变态路径，验证选项B（正确）和D（错误）。
- 步骤2（完全变态）：
  - 高亮路径 A→B→D→C→A（红色，4px），节点A, B, C, D红色边框。
  - 弱化路径 D→A（灰色虚线，2px）。
  - 更新标签：B旁“幼虫”（红色），D旁“蛹”（红色），C旁“成虫”（红色）。
  - 信息面板：展示完全变态路径，验证选项A（正确）和C（正确）。
- 最终步骤（步骤3）：
  - 恢复全图黑色（2px），所有节点黑色边框。
  - 更新标签为双重身份：B旁“若虫 / 幼虫”，D旁“成虫 / 蛹”，C旁“无 / 成虫”（均为黑色）。
  - 信息面板：总结发育模型，指出本题选D。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：底部居中放置两个按钮和状态指示器（如 1 / 4）。
- 教师操作流程：教师首先展示原图，引导学生回忆两种发育类型；点击下一步，剥离出不完全变态路径，结合左侧面板解析选项B和D；再次点击，剥离出完全变态路径，解析选项A和C；最后点击总结，展示统一模型，得出答案。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。图形为简单几何节点和连线，原生 SVG 性能好且易于控制状态和动画。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```text
  [图示区 800×500]
  +-------------------------------------------------+
  |  [信息面板]             卵(A)                   |
  |  +--------+               O                     |
  |  | 不完全 |             / ^ \                   |
  |  | 变态...|           /   |   \                 |
  |  +--------+   若虫(B) O   |   O (C)成虫         |
  |                       \   |   ^                 |
  |                         \ | /                   |
  |                           O                     |
  |                         成虫(D)                 |
  |                                                 |
  |               [◀ 上一步] 1 / 4 [下一步 ▶]       |
  +-------------------------------------------------+
  ```
- 关键实现要点：
  - 状态机设计：定义 `currentStep` (0~3)，每次点击按钮更新状态，并调用 `updateScene()` 统一渲染。
  - 箭头绘制：使用 `<line>` 配合 `<marker>`，需预先在 `<defs>` 中定义4种颜色的箭头 marker。
  - 动画过渡：为 SVG 元素的 `stroke`, `stroke-width`, `fill` 添加 CSS `transition: all 0.3s ease` 实现平滑切换。
  - ID 命名规范：所有元素 ID 必须以 `scene1-` 为前缀（如 `scene1-node-a`, `scene1-edge-ab`, `scene1-info-panel`）。
  - IIFE 隔离：所有 JS 代码包裹在 `(function() { ... })()` 中。
