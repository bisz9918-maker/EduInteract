- 本图示主题：DNA分子结构、酶的作用位点及碱基比例计算

[视觉元素清单]
- DNA双链：由实线、虚线和文本组成。左侧为固定部分，右侧分为上下两组以便动画分离。
- 酶切动画元素：①处的白色遮罩矩形（模拟断键），②处的剪刀图标。
- 高亮元素：步骤2的C/G碱基橙色圆形背景，步骤3的顶部单链蓝色半透明高亮框。
- 文本解析：右侧区域，分3组，分别对应选项A、选项B双链比例、选项B单链比例。
- 颜色/样式：背景 #ffffff，主线 #000000，虚线 #888888，蓝高亮 #1565c0，红高亮 #c62828，橙高亮 #f57c00。

[分步序列]
- 初始状态（步骤0）：显示完整的DNA结构、标签①和②。右侧文本区为空。
- 步骤1（酶的作用）：点击「下一步」。
  - 视觉变化：①处出现红色剪刀，顶部骨架出现白色断口；②处出现蓝色剪刀，中间虚线骨架透明度变为0，右侧DNA上半部分（骨架、碱基、上半段氢键）向上平移30px，下半部分向下平移30px（模拟解旋）。
  - 右侧显示：选项A的解析文本（指出①为磷酸二酯键，②为氢键，A错误）。
- 步骤2（双链碱基比例）：点击「下一步」。
  - 视觉变化：DNA结构恢复初始状态（闭合、无断口、隐藏剪刀）。所有C和G碱基（共8个）背后出现橙色圆形高亮。
  - 右侧显示：选项B双链比例的推导过程（C=G=30%，A=T=20%）。
- 步骤3（单链碱基比例）：点击「下一步」。
  - 视觉变化：隐藏C/G高亮。顶部单链（包含骨架和碱基）出现蓝色半透明高亮框。
  - 右侧显示：选项B单链比例的推导过程（单链比例等于双链比例，为3:2，B正确）。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：底部居中放置“上一步”、“下一步”按钮及步骤指示器（如 1 / 4）。
- 教师操作流程：教师首先结合初始图示讲解题目已知条件；点击下一步，配合动画讲解解旋酶和限制酶的作用位点；再次点击下一步，结合高亮讲解双链碱基比例的计算；最后点击下一步，讲解单链比例的推导，得出最终结论。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。SVG 非常适合绘制线条、文本和精确的几何图形，且原生支持 CSS `transition`，实现平移和透明度动画非常简单高效。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [左侧：DNA结构图 (x:50-450)]  [右侧：解析文本区 (x:460-780)]
  C T G C ...... C T T A       【选项A分析】
  | | | |   ②->  | | | |       ①处为磷酸二酯键...
  G A C G ...... G A A T       ...
  
  [底部：控件栏 (y:450-480) ◀上一步  1/4  下一步▶]
  ```
- 关键实现要点：
  - 使用 `<g>` 标签对右侧DNA的上下两部分进行分组（`scene1-top-right` 和 `scene1-bottom-right`），通过修改 `transform` 属性实现解旋动画。
  - 氢键在右侧部分需分为上下两段绘制，以便跟随上下骨架分离。
  - 状态机设计：定义 `currentStep` 变量（0-3），每次点击按钮更新变量并调用 `updateScene()` 函数，该函数根据当前步骤设置各元素的 `opacity`、`transform` 和高亮状态。
  - ID 命名规范：所有元素 ID 均以 `scene1-` 开头，如 `scene1-dna-group`、`scene1-btn-next`。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
