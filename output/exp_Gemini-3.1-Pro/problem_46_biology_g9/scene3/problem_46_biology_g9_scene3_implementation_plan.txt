[图示主题与整合说明]
- 本图示主题：DNA半保留复制与同位素标记
- 整合的步骤/概念：展示DNA在含14N的培养液中连续复制3次的过程，通过树状图清晰呈现每一代DNA分子的链组成（15N母链与14N新链），直观推导出含14N的DNA分子比例。
- 教学价值：教师可通过分步演示，引导学生观察半保留复制的特点，理解“无论复制多少次，含有母链的DNA分子始终只有2个，而所有新合成的DNA分子都含有新链”，从而轻松判断选项D的错误。

[视觉元素清单]
- 颜色/样式：背景 #ffffff，主线 #000000，红高亮 #c62828（15N母链），蓝高亮 #1565c0（14N新链），辅助线 #888888 虚线。
- DNA分子：由两条平行的水平线段组成，长40px，间距8px（即 y-4 和 y+4），线宽 4px。
- 复制连线：从父代DNA底部中心（y+10）连接到子代DNA顶部中心（y-15）的灰色虚线。
- 文本标签：字体大小 14px，结论文本 16px。

[分步序列]
- 初始状态（步骤0）：显示图例、亲代标签、亲代DNA（两条红链）。隐藏其他所有元素。
- 步骤1：点击「下一步」→ 显示第1代标签、第1代DNA（2个，红蓝杂合）、从亲代到第1代的连线。
- 步骤2：点击「下一步」→ 显示第2代标签、第2代DNA（4个，2个杂合，2个纯蓝）、从第1代到第2代的连线。
- 步骤3：点击「下一步」→ 显示第3代标签、第3代DNA（8个，2个杂合，6个纯蓝）、从第2代到第3代的连线。同时在底部淡入显示结论文本：“复制3次后，共8个DNA分子。含14N的分子有8个，占比 100%。”及“选项D错误”。

[标签冲突检查]
- 第3代DNA分子横向排列：x坐标分别为 120, 200, 280, 360, 440, 520, 600, 680。每个宽度40px，相邻间距40px，无重叠。
- 代数标签与DNA分子：代数标签固定在 x=60，最左侧的第3代DNA在 x=120（左边缘 x=100），间距20px以上，无重叠。
- 图例与亲代DNA：图例在 x=650~730，亲代DNA在 x=400，距离极远，无重叠。
- 结论文本与第3代DNA：第3代DNA在 y=320，结论文本在 y=390，垂直间距70px，无重叠。
- 结论文本与控件栏：结论文本在 y=420，控件栏在 y=460，垂直间距40px，无重叠。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：在 SVG 底部（y=460）放置两个按钮，控制复制代数的展示。
- 教师操作流程：教师首先介绍亲代DNA的同位素标记情况，然后点击“下一步”逐代展示复制结果，引导学生观察新链的合成和母链的分配，最后在第3代展示完毕后，总结含14N的DNA分子比例，从而判断选项正误。

[技术实现]
- JS 库选择及原因：原生 SVG。树状图结构固定，使用原生 SVG 的 `<line>` 和 `<g>` 标签即可轻松实现，无需引入复杂库，性能好且易于控制动画。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  (60,85)亲代         (400,80) =
  (60,165)第1代       (240,160) =       (560,160) =
  (60,245)第2代     =       =       =       =
  (60,325)第3代   =   =   =   =   =   =   =   =
  
                  结论：含14N的分子占比 100%
  [控件栏：上一步 | 下一步]
  ```
- 关键实现要点：
  - 状态机设计：定义 `currentStep` 变量（0~3），根据步骤控制对应层级 DOM 元素的 `opacity` 或 `display` 属性。
  - 动画过渡：为 SVG 元素的 `opacity` 添加 CSS `transition: opacity 0.5s ease`，实现平滑淡入淡出。
  - ID 命名规范：所有元素 ID 以 `scene3-` 开头，如 `scene3-gen1-group`, `scene3-btn-next`。
  - IIFE 隔离：所有逻辑封装在 `(function() { ... })()` 中。
