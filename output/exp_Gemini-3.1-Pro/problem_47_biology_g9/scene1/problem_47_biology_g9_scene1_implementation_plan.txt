[视觉元素清单]
- 流程图节点：黑色文字，步骤1中相关节点高亮为 #f57f17。
- 肾单位解剖图：初始为浅灰色/低饱和度轮廓，随步骤高亮。入球/出球小动脉（#c62828），肾静脉（#1565c0），肾小囊/肾小管（#f57f17，20%透明度填充，实线描边）。
- 微观粒子：蛋白质（紫色 #6a1b9a，r=5），葡萄糖（绿色 #2e7d32，r=4），尿素（黄色 #fbc02d，r=4），水/无机盐（浅蓝，r=3）。

[分步序列]
- 初始状态（步骤0）：显示左侧流程图、左下角图例、右侧肾单位解剖图（静止、基础配色）。隐藏所有粒子、虚线和结论文本。
- 步骤1（验证选项B、C）：
  - 视觉变化：流程图“甲”、“a”高亮橙色，解剖图“肾小囊”高亮橙色。出现虚线连接甲与肾小囊、a与肾小囊内部。显示标签“甲：肾小囊”、“a：原尿”。
  - 动画：浅蓝色粒子从肾小球滤过到肾小囊。
  - 随后“乙”、“b”高亮，解剖图“肾小管”高亮。虚线连接乙与肾小管、b与集合管。显示标签“乙：肾小管”、“b：尿液”。
  - 出现虚线大框包围肾小球、肾小囊、肾小管，标注“肾单位”。
- 步骤2（验证选项A）：
  - 视觉变化：聚焦滤过与重吸收。
  - 动画：紫色粒子（蛋白质）在肾小球内运动并从出球小动脉离开（不进入肾小囊），上方显示文本“大分子蛋白质、血细胞无法通过”。绿色粒子（葡萄糖）在肾小管中段向外移动消失（重吸收），右侧显示文本“葡萄糖、水、无机盐被重吸收”。
  - 交互：在肾小管(530, 250)处出现红色“×”模拟麻痹。绿色粒子重吸收动画停止，改为顺着肾小管一直流入集合管底部。
  - 结论：集合管底部显示文本“尿液中出现葡萄糖，无蛋白质”。
- 步骤3（验证选项D）：
  - 视觉变化：入球/出球小动脉变为鲜红，毛细血管网渐变过渡，肾静脉变为暗红。
  - 动画：黄色粒子（尿素）从入球小动脉进入，大量滤过进入肾小管并随尿液排出，仅极少量进入肾静脉。
  - 结论：肾静脉旁显示文本“动脉血变静脉血，尿素减少”。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：底部居中放置两个按钮，控制步骤 0 -> 1 -> 2 -> 3 的切换。
- 教师操作流程：教师首先展示题目和静态结构（步0）；点击下一步讲解对应关系和原尿/尿液形成（步1）；再点击下一步通过麻痹实验动画讲解重吸收作用及蛋白质去向（步2）；最后点击下一步总结血液流经肾脏的整体变化（步3）。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript (`requestAnimationFrame`)。SVG 适合绘制复杂的解剖路径和保持文本清晰，利用 SVG Path 的 `getPointAtLength()` API 可以极其方便地实现粒子沿弯曲血管和肾小管运动的动画，无需引入庞大的外部动画库。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```text
  [流程图区 20~380, 40~80]      [文本提示区 400~780, 40~80]
  [图例区 20~150, 250~400]      [肾单位解剖图区 350~650, 100~400]
                                [结论文本区 640~780, 200~400]
  [控件栏 300~500, 450~490]
  ```
- 关键实现要点：
  1. 路径动画：定义一条隐藏的 SVG `<path id="scene1-tubule-path">`，在 JS 中通过 `path.getTotalLength()` 和 `path.getPointAtLength(progress)` 计算粒子坐标，更新 `<circle>` 的 `cx` 和 `cy`。
  2. 状态机：使用一个 `currentStep` 变量记录当前步骤，每次切换步骤时调用 `renderStep(step)` 函数，该函数负责显示/隐藏对应的 DOM 元素（如虚线、文本框、红叉）并切换动画标志位。
  3. 麻痹逻辑：在步骤2中，设置一个 `isParalyzed` 标志。当粒子运动到重吸收点（如 progress = 0.4）时，若 `isParalyzed` 为 false，则粒子改变运动方向（X轴减小）并逐渐降低透明度；若为 true，则继续沿原 path 运动到终点。
- ID 命名规范：所有元素 ID 必须以 `scene1-` 开头，例如 `scene1-btn-next`, `scene1-path-tubule`。
- IIFE 隔离：所有 JS 代码必须包裹在 `(function() { ... })()` 中，避免全局变量污染。
