[分步序列]
- 初始状态（步骤0）：显示基础底图（赤道、70°S、经线网、阴影区、线段MA）。显示标签 O, 70°, B, M, A。
- 步骤1：点击「下一步」→ 出现顺时针自转箭头。180°经线和经线B变蓝加粗。出现标签 "180°" 和 "0时"。
- 步骤2：点击「下一步」→ 切点M处出现红色圆点并闪烁（pulse动画）。经线B的标签更新为 "0时(120°W)"。
- 步骤3：点击「下一步」→ 沿赤道外侧依次出现经度标签（150°W, 90°W, 60°W, 30°W, 0°, 30°E）。60°E经线变为红色加粗虚线，出现标签 "12时(60°E)"。
- 步骤4：点击「下一步」→ 出现夜半球遮罩（左上区域）。MA线段向左下延伸至A'形成完整晨昏线，并变为绿色加粗。70°S圈内填充红色半透明，出现 "极昼" 标签。60°E经线上出现红点，并标注 "直射点(20°S, 60°E)"。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：在 SVG 底部 (y=460) 居中放置两个按钮，使用绝对定位，不影响 SVG 画布大小。
- 教师操作流程：教师首先展示原图，引导学生观察；点击下一步展示自转和日期分界线；再点击下一步分析切点M的时间；接着推导直射点经度；最后推导直射点纬度并总结。

[技术实现]
- JS 库选择及原因：原生 SVG。本场景主要由几何图形（圆、线段、扇形路径）构成，原生 SVG 的 `<path>`, `<circle>`, `<line>` 配合 CSS transition 即可完美实现，无需引入庞大的外部库，性能最佳且易于控制。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  (400,240) 为极点，半径 180 的圆占据主体偏上位置，下方留出空间展示直射点标签。
  [控件栏]
  底部 y=460 区域居中放置 ◀上一步 / 下一步▶ 按钮。
  ```
- 关键实现要点：
  - 状态机设计：定义 `currentStep` 变量（0-4），每次点击按钮更新变量，并调用 `updateState()` 函数。
  - `updateState()` 函数中，根据 `currentStep` 控制各 SVG 元素的 `opacity` 和 `stroke/fill` 属性。
  - 动画曲线：使用 CSS `transition: all 0.5s ease-in-out` 实现平滑过渡。
  - 闪烁动画：为切点M定义 CSS `@keyframes pulse { 0% { r: 3; opacity: 1; } 50% { r: 6; opacity: 0.5; } 100% { r: 3; opacity: 1; } }`。
  - ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-night-mask`, `scene1-btn-next`）。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
