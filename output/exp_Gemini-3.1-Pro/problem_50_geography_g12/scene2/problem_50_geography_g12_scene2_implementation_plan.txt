[图示主题与整合说明]
- 本图示主题：侧视剖面图中的线速度与正午太阳高度对比
- 整合的步骤/概念：将抽象的线速度（由自转半径决定）与正午太阳高度角（太阳光线与地平面的夹角）整合在同一个地球侧视剖面图中进行分步对比。
- 教学价值：教师可以通过分步演示，先让学生直观看到不同纬度的自转半径长度差异从而理解线速度大小关系，然后再切换到正午太阳高度的几何视角，避免两类辅助线同时出现导致画面混乱，帮助学生建立清晰的空间几何直觉。

[视觉元素清单]
- 基础底图：地球轮廓（#e3f2fd 填充，透明度0.3，#000000 描边），夜半球（#000000 填充，透明度0.1）
- 辅助线：地轴、赤道、晨昏线（#888888，虚线 dasharray 5,5）
- 全局光线：5条水平向左箭头（#c62828，透明度0.4）
- 关键点及标签：A、B、C点（#c62828 填充）。标签文本（#000000，14px）
- 步骤2元素（线速度）：自转半径（#1565c0，粗细2px）。结论文本“线速度 A > B = C”（#1565c0，粗体，16px）
- 步骤3元素（太阳高度）：地平面切线（#2e7d32，粗细2px），特定太阳光线（#c62828，粗细2px），角度弧线及H标签（#2e7d32）。结论文本“正午太阳高度 A > C > B”（#2e7d32，粗体，16px）

[分步序列]
- 初始状态（步骤0）：显示基础底图、辅助线、全局太阳光线。标出“赤道”、“地轴”、“晨昏线”、“太阳光线”标签。
- 步骤1（定位）：在步骤0基础上，出现A、B、C三点，并显示其名称及纬度标签（15°N, 75°S, 75°N）。
- 步骤2（线速度对比）：在步骤1基础上，画出A、B、C三点的蓝色自转半径。左侧空白区出现蓝色结论文本“线速度 A > B = C”。
- 步骤3（正午太阳高度对比）：隐藏步骤2的自转半径和结论文本。将全局太阳光线透明度降至0.1。画出A、B、C三点的绿色地平面切线、红色正午太阳光线、绿色角度弧线及度数（H=90°, H=0°, H=30°）。左侧空白区出现绿色结论文本“正午太阳高度 A > C > B”。

[标签冲突检查]
- A点组：A标签(515, 215)，15°N(515, 245)，H=90°(555, 205)。A在点左上，15°N在左下，H=90°在右上。间距>20px，无冲突。
- C点组：C标签(425, 65)，75°N(410, 85)，H=30°(480, 85)。C在点左上，75°N在左下，H=30°在右侧。切线穿过中间，文本分布在切线两侧，无冲突。
- B点组：B标签(335, 430)，75°S(365, 430)，H=0°(400, 400)。B在左下，75°S在右下，H=0°在右上。无冲突。
- 结论文本：位于(80, 380)和(80, 410)。地球最左侧边缘x=170，文本完全位于左侧纯白背景区，绝不遮挡图形。
- 底部控件：位于y=460~490区域。最下方的B点标签在y=430，距离控件区有30px安全余量，无冲突。

[交互方案]
- 交互类型：分步按钮导航
- 控件说明：在SVG内部底部（y=460）居中放置两个按钮“◀ 上一步”和“下一步 ▶”，以及中间的状态指示器“步骤 1 / 4”。
- 教师操作流程：教师点击“下一步”依次展示定位、线速度辅助线、太阳高度辅助线，配合口头讲解引导学生对比几何线段长度和夹角大小。

[技术实现]
- JS 库选择：原生 SVG（最适合精确的几何线段、切线和弧线绘制）。
- 画布尺寸：800 × 500 px，`position: relative`。
- 布局草图：
  ```
  [图示区 800×450]
    (左侧空白)    (地球剖面)    (太阳光线)
    结论文本区      A/B/C点
  [控件栏 800×50] 居中按钮区
  ```
- 关键实现要点：
  - 使用 `<defs>` 定义箭头 marker，方便复用。
  - 使用 CSS `opacity` 和 `transition: opacity 0.3s` 控制各步骤元素的显隐（通过给父 `<g>` 标签切换 class 或直接修改 style）。
  - 角度弧线使用 SVG `<path>` 的 `A` (elliptical arc) 指令精确绘制。
- ID 命名规范：所有 DOM 元素的 ID 必须以 `scene2-` 开头（如 `scene2-svg`, `scene2-btn-next`, `scene2-step2-group`）。
- IIFE 隔离：所有 JavaScript 逻辑必须包裹在 `(function() { ... })();` 中，内部使用 `document.getElementById` 获取元素，维护一个 `currentStep` 变量控制状态机。
