[视觉元素清单]
- 经纬网基础：中心点 O，经线 OA、OC，纬线弧（赤道、南回归线、南极圈）。主线 #000000，辅助线 #888888 虚线。
- 黑夜阴影：由赤道弧、OC 线段和 ABC 线段围成的封闭区域，填充 #000000，透明度 20%。
- 晨线 ABC：连接 A、B、C 的直线段。
- 自转箭头：位于赤道外侧的顺时针弧形箭头。
- 文本标签：使用 SVG `<text>`，字体大小 14px-16px，关键结论使用 HTML `<div>` 面板。
- 颜色规范：背景 #ffffff，蓝高亮 #1565c0，红高亮 #c62828，绿高亮 #2e7d32。

[分步序列]
- 初始状态（步骤0）：显示经纬网基础、黑夜阴影、晨线 ABC、自转箭头、点 A/B/C/O 及其基础字母标签、"0°" 标签。隐藏所有推导标签和高亮。
- 步骤1（定极点）：自转箭头变为蓝高亮 #1565c0 并加粗；显示标签 "南极点(90°S)"、"赤道"、"南回归线"、"南极圈"。
- 步骤2（定晨线）：黑夜阴影区添加 CSS 摇摆动画（绕 O 点旋转 0°->3°->0°）模拟自转；晨线 ABC 变为红高亮 #c62828 并加粗；显示红色标签 "晨线(日出)"。
- 步骤3（定节气）：C 点变为红高亮圆点；显示极昼高亮区（南极圈内填充蓝高亮 #1565c0，透明度 30%）；左上角弹出结论面板，显示文本 "南极圈及其以南出现极昼 → 冬至日 (12月22日)"。
- 步骤4（定时间）：A 点变为红高亮圆点；显示红色标签 "6:00" 和 "0:00(24:00)"。
- 步骤5（定经度）："0°" 标签变为绿高亮 #2e7d32 并放大；显示绿色标签 "90°W"；绘制 12:00 绿色虚线经线及太阳图标，显示绿色标签 "12:00" 和 "90°E"；结论面板追加文本 "太阳直射点坐标：(23.5°S, 90°E)"。

[标签冲突检查]
- 标签"A"(350, 120) 与 "0°"(330, 100) 与 "6:00"(380, 120)：三者分别位于 A 点的左下、左上、右侧，间距均 > 20px，无冲突。
- 标签"C"(530, 400) 与 "0:00"(530, 440) 与 "南极圈"(560, 380)：分别位于 C 点的正上、正下、右上，无冲突。
- 标签"O"(665, 435) 与 "南极点"(665, 455)：上下排列，无冲突。
- 标签"晨线"(400, 180) 与 阴影区：位于 ABC 线段右侧（白昼区），不与阴影重叠。
- 标签"赤道"(280, 380) 与 阴影区：叠加在阴影区上方，由于阴影仅 20% 透明度，且可为文本添加白色 text-shadow，可读性良好，无严重冲突。
- 结论面板(30, 30) 与 图形主体：图形主体集中在右下角（O点在 650, 420），左上角完全留白，面板放置于此完美避开所有图形。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：在 SVG 容器内部底部（y=460 区域）居中放置两个按钮。
- 教师操作流程：教师点击“下一步”按钮，图示依次展示定极点、定晨线、定节气、定时间、定经度的逻辑推导过程，配合动画和高亮引导学生视线。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。本场景主要由基础几何图形（线段、圆弧、多边形）构成，原生 SVG 能够精确控制坐标和层级，且易于通过 CSS 实现高亮和动画。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  | [结论面板]                                       |
  |                                                  |
  |    0° A                                          |
  |      \ .                                         |
  |       \  . B           12:00                     |
  |        \   .             |                       |
  |         \    .           |                       |
  |  (阴影)  \     . C       |                       |
  |           \      .       |                       |
  |------------D-------+-----O (南极点)              |
  | 90°W                                             |
  |                                                  |
  |             [◀上一步] [下一步▶]                  |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. **坐标计算**：严格按照布局坐标表绘制 SVG 路径。圆弧使用 `A rx ry x-axis-rotation large-arc-flag sweep-flag x y` 指令，注意 SVG 坐标系 y 轴向下，顺时针 sweep-flag 为 1。
  2. **状态机设计**：使用 `currentStep` 变量记录当前步骤（0-5）。编写 `updateScene()` 函数，根据 `currentStep` 的值，通过修改 DOM 元素的 `style.display` 或 `classList` 来控制元素的显隐和高亮状态。状态更新应是累加的（前面的高亮在后续步骤中保持）。
  3. **动画实现**：步骤 2 的阴影微转动画通过 CSS `@keyframes` 实现，动态添加 class 触发。
  4. **ID 命名规范**：所有元素 ID 必须以 `scene1-` 开头，例如 `scene1-btn-next`, `scene1-shadow`, `scene1-label-pole`。
  5. **IIFE 隔离**：所有 JS 代码必须包裹在 `(function() { ... })()` 中，防止变量污染全局作用域。
  6. **层级控制**：在 SVG 中，后定义的元素层级更高。应先绘制阴影和极昼高亮区，再绘制经纬网线段，最后绘制文本标签和高亮关键点，确保文本不被遮挡。
