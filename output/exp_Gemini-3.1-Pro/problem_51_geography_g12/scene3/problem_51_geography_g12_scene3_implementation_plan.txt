[图示主题与整合说明]
- 本图示主题：新旧一天范围的全球视角计算
- 整合的步骤/概念：通过极地俯视图，定位 0:00 经线和 180° 经线，顺时针（向东）划定新一天范围，并计算其占全球的比例。
- 教学价值：帮助学生从局部视角的抽象时间计算，过渡到全球视角的直观面积/角度占比计算，清晰展示“新一天”是如何在地球上分布的。

[视觉元素清单]
- 极地经纬网：包含赤道、回归线、极圈，以及 8 条经线（每 45° 一条）。主经线实线，辅助经线虚线。
- 关键经线高亮：90°W 和 180° 经线在步骤 1 变为红色（#c62828）加粗。
- 扇形填充区：表示新一天的范围，蓝色（#1565c0），透明度 30%。
- 弧形箭头：指示向东（顺时针）方向，绿色（#2e7d32）。
- 角度标注弧线：在扇形内部标示 270° 的跨度，绿色（#2e7d32）。
- 文本标签：经度标签（黑色）、0:00 和日界线标签（红色）、向东和 270° 标签（绿色）。
- 计算面板：在右侧空白区域显示推导过程。

[分步序列]
- 初始状态（步骤0）：显示完整的极地俯视经纬网，标出 0°, 90°E, 180°, 90°W 经线及标签。
- 步骤1（定位分界线）：点击「下一步」→ 90°W 经线变为红色加粗，左侧出现红色标签“0:00 (新一天起点)”；180° 经线变为红色加粗，下方出现红色标签“国际日期变更线”。
- 步骤2（划定新一天）：点击「下一步」→ 出现蓝色半透明扇形，从 90°W 顺时针展开至 180°。同时在经纬网外侧上方出现绿色弧形箭头及标签“向东 (顺时针)”。
- 步骤3（计算比例）：点击「下一步」→ 扇形内部出现绿色 270° 标注弧线及标签。右侧计算面板淡入，显示：
  “新一天范围计算：”
  “1. 起点: 90°W (0:00)”
  “2. 终点: 180° (日界线)”
  “3. 跨越经度: 90° + 180° = 270°” (绿色)
  “4. 比例: 270° / 360° = 3/4” (绿色加粗)

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：底部居中放置两个按钮，控制步骤 0 到 3 的切换。
- 教师操作流程：教师首先展示基础经纬网，点击下一步定位两条关键分界线，再次点击展示新一天在地球上的实际覆盖范围，最后点击展示具体的数学计算过程，完成从图形到数值的推导。

[技术实现]
- JS 库选择及原因：原生 SVG。SVG 非常适合绘制几何图形、弧线、扇形，且易于通过 CSS 控制动画和状态切换。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  +---------------------------------------------------+
  |                     向东(顺时针)                  |
  |                          0°                       |
  |                  . - ~ ~ ~ - .                    |
  |              . '       |       ' .                |
  |            /           |           \   计算面板   |
  | 0:00     /             |             \            |
  | 90°W ---|--------------O--------------|--- 90°E   |
  |          \             |             /            |
  |            \           |           /              |
  |              .         |         .                |
  |                ' - . _ | _ . - '                  |
  |                       180°                        |
  |                   国际日期变更线                  |
  |                                                   |
  |               [上一步]   [下一步]                 |
  +---------------------------------------------------+
  ```
- 关键实现要点：
  - 扇形绘制：使用 SVG `<path>` 的 `A` (Arc) 指令，路径为 `M 320 230 L 160 230 A 160 160 0 1 1 320 390 Z`（大弧标志设为 1，因为 270° > 180°）。
  - 动画过渡：扇形展开可以使用 `stroke-dasharray` 技巧或简单的 `opacity` 淡入。为保持简单稳定，建议使用 `opacity` 和 `transition` 实现淡入效果。
  - 状态机设计：定义 `currentStep` 变量（0-3），每次点击按钮更新变量，并遍历所有带有 `data-step` 属性的 DOM 元素，根据其出现的步骤范围控制 `opacity` 或 `display`。
  - ID 命名规范：所有交互元素 ID 必须以 `scene3-` 为前缀（如 `scene3-sector`，`scene3-btn-next`）。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
