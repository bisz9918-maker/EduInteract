[图示主题与整合说明]
- 本图示主题：根据南半球阴影推断晨昏线、日期及太阳直射点

- 教学价值：帮助学生建立空间几何与时间计算的联系，清晰展示晨昏线在投影图上的形态，以及极夜现象与直射点纬度的对应关系。

[技术实现]
- JS 库选择：原生 SVG（适合精确的几何路径绘制和 clip-path 裁剪）。
- 画布尺寸：800 × 500 px。
- 布局草图：
  [左侧 50~470：南半球投影图及辅助线]  [右侧 520~780：分步推导文字区]
  [底部 460~500：上一步/下一步 按钮控件区]
- 关键实现要点：
  1. 使用 `<clipPath id="scene2-hemisphere-clip">` 定义南半球半圆轮廓，用于精确裁剪阴影区域和极夜区域，确保边缘平滑无溢出。
  2. 经线使用精确的 SVG 椭圆弧指令 (`A`) 绘制，保证透视准确性。
  3. 状态机设计：定义 `currentStep` (0~4)，在 `updateState()` 中通过修改元素的 `opacity` 属性实现显示/隐藏，可配合 CSS `transition: opacity 0.3s` 实现平滑过渡。
  4. ID 命名规范：所有元素 ID 均以 `scene2-` 开头（如 `scene2-terminator-hl`, `scene2-text-step1`），确保全局唯一性。
  5. 代码封装：所有逻辑包裹在 `(function() { ... })()` 立即执行函数中，避免变量污染。
