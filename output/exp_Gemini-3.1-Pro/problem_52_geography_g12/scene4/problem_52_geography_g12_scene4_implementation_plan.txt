[图示主题与整合说明]
- 本图示主题：地方时计算与赤道昼长
- 整合的步骤/概念：对应题目(4)，将抽象的地方时计算过程（经度差 -> 时间差 -> 东加西减）转化为直观的数轴可视化，并结合小地球仪展示赤道昼长的固定规律。
- 教学价值：教师可通过分步演示，引导学生一步步完成时间计算的逻辑推导，避免死记硬背公式，同时直观复习赤道昼夜平分的知识点。

[视觉元素清单]
- 颜色/样式沿用规格：背景 #ffffff / 主线 #000000 / 蓝高亮 #1565c0 (经度数轴、赤道线) / 红高亮 #c62828 (甲乙C点位、最终时间结果) / 绿高亮 #2e7d32 (经度差、时间差计算过程及箭头) / 辅助线 #888888 虚线。
- 经度数轴：蓝色实线，灰色刻度及标签。
- 甲、乙、C点：红色实心圆点（r=4），红色加粗标签。
- 经度差括号：绿色实线路径，无填充。
- 计算箭头：绿色实线，末端带绿色箭头（使用 SVG marker）。
- 小地球仪：黑色外轮廓，浅灰背景 #f8f9fa，内部灰色虚线椭圆示意经线。

[分步序列]
本场景采用累加式分步显示，共 5 个状态（步0至步4）：
- 初始状态（步0）：显示经度数轴、刻度及标签（140°W, 0°, 100°E）、甲乙点位及标签。
- 步骤1：点击「下一步」→ 淡入甲地已知时间"22日 16:00"（含辅助虚线）、上方绿色经度差括号及标签"经度差 240°"。
- 步骤2：点击「下一步」→ 淡入底部居中的绿色时间差计算公式："时间差 = 240° ÷ 15°/h = 16小时"。
- 步骤3：点击「下一步」→ 淡入从甲指向乙的绿色箭头及标签"东加西减：向东 +16h"，同时在乙地下方淡入计算过程"16:00 + 16h = 32:00"及红色最终结果"即 23日 8:00"（含辅助虚线）。
- 步骤4：点击「下一步」→ 在数轴上方淡入小地球仪、蓝色赤道、红色C点及标签，以及下方红色结论文本"赤道全年昼夜平分，C点昼长12小时"。

[交互方案]
- 交互类型：分步按钮导航。
- 控件说明：在 SVG 内部底部（y=450区域）放置两个按钮「◀ 上一步」和「下一步 ▶」。
- 教师操作流程：教师点击“下一步”逐步展示时间计算的逻辑链条（找经度差 -> 算时间差 -> 定方向加减 -> 得出结果），最后展示赤道昼长规律。可随时点击“上一步”回退重新讲解。

[技术实现]
- JS 库选择：原生 SVG 即可完美实现所有几何图形、连线和文本排版。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
    (y=90)  [小地球仪及C点]
    (y=185) 赤道全年昼夜平分...
    (y=235) ┌────── 经度差 240° ──────┐
    (y=290)    ──── 向东 +16h ────>
    (y=320) ──甲(140°W)───0°───乙(100°E)──
    (y=365)  22日16:00        16:00+16h=32:00
    (y=390)                   即 23日 8:00
    (y=400)    时间差 = 240° ÷ 15°/h = 16小时
  [控件栏 y=450] [◀ 上一步] [下一步 ▶]
  ```
- 关键实现要点：
  - 状态机设计：维护 `currentStep` 变量（0~4）。
  - 动画实现：将每步新增的元素分组（如 `<g id="scene4-step1">`），通过 CSS 类 `.active` 控制 `opacity` 实现淡入淡出效果（`transition: opacity 0.5s ease`）。
  - 箭头绘制：在 `<defs>` 中定义 `<marker id="scene4-arrowhead">`，在 `<line>` 中通过 `marker-end` 引用。
- ID 命名规范：所有 DOM 元素 ID 必须以 `scene4-` 为前缀（如 `scene4-step1`、`scene4-btn-next`）。
- IIFE 隔离：所有 JS 逻辑必须封装在 `(function() { ... })()` 中，避免全局变量污染。
