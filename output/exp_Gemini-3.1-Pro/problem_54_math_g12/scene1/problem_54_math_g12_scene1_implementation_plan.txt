[图示主题与整合说明]
- 本图示主题：长方体表面两点间最短路径的不同展开方式对比
- 整合的步骤/概念：整合了长方体的3D结构展示、三种不同的相邻面展开过程（前+右、底+右、底+后），以及对应直角三角形的构建和路径长度计算。
- 教学价值：通过分步动画和3D到2D的映射，帮助学生直观理解“表面最短路径”本质上是展开平面两点间的直线距离。分类讨论三种展开方式，培养学生全面思考和对比寻优的数学思维。

[分步序列]
- 初始状态（步骤0）：显示3D长方体，高亮顶点A、C、D、F，标注边长5, 3, 6。右侧空白。底部提示“初始状态：长方体及各边长”。
- 步骤1：3D图中高亮前面和右面，显示右面绕CE棱展开的半透明轮廓，绘制红色路径A-F_1。右侧显示2D图1（前右面展开），包含直角三角形、边长标注及公式 `AF = √(8² + 6²) = 10`。
- 步骤2：3D图中高亮底面和右面，显示右面绕CD棱展开的半透明轮廓，绘制红色路径A-F_2。右侧显示2D图2（底右面展开），包含直角三角形、辅助线、边长标注及公式 `AF = √(11² + 3²) = √130`。
- 步骤3：3D图中高亮底面和后面，显示后面绕底后棱展开的半透明轮廓，绘制红色路径A-F_3。右侧显示2D图3（底后面展开），包含直角三角形、边长标注及公式 `AF = √(5² + 9²) = √106`。
- 步骤4（结论）：3D图中恢复基础长方体，并将步骤1的最短路径折叠回3D表面（A -> P(200,275) -> F）。右侧居中显示三个计算结果，高亮最小值 10。

[交互方案]
- 交互类型：分步按钮导航
- 控件说明：底部居中放置「◀ 上一步」和「下一步 ▶」按钮，中间显示当前步骤文本（如“步骤 1/4：前右面展开”）。
- 教师操作流程：教师点击“下一步”逐一展示三种展开方式，引导学生观察3D到2D的转换并计算路径长度，最后在步骤4总结对比得出最短路径。

[技术实现]
- JS 库选择：原生 SVG（最适合精确的几何图形绘制和多边形填充）。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [左侧 3D投影区 400×450] | [右侧 2D展开区 400×450]
  [       控件栏 (y=450~500) 包含上/下一步按钮      ]
  ```
- 关键实现要点：
  1. 状态机设计：使用 `currentState` (0-4) 控制显示逻辑。将不同步骤的 SVG 元素分组 (`<g>`)，通过切换 `display` 属性实现状态切换。
  2. 3D投影计算：已预先计算好斜二测投影坐标，代码中直接使用绝对坐标绘制多边形和线段，无需实时矩阵运算。
  3. 层级控制：在 SVG 中，先绘制高亮填充多边形（`scene1-stepX-3d-fills`），再绘制基础长方体线框，最后绘制展开轮廓和红色路径，确保线条不被填充色遮挡。
  4. ID 命名规范：所有元素 ID 均以 `scene1-` 开头（如 `scene1-btn-next`, `scene1-2d-step1`），避免全局冲突。
  5. 模块化：所有 JS 代码封装在 IIFE 中。
