[图示主题与整合说明]
- 本图示主题：利用抛物线定义构造等边三角形求解角度
- 整合的步骤/概念：抛物线基础图形、准线辅助线、线段长度转化（|AF|与|AB|）、等边三角形判定、目标角计算
- 教学价值：教师可以通过分步导航，像在黑板上板书一样，一步步引导学生观察线段关系，利用抛物线定义将折线转化为直线段，最终发现隐藏的等边三角形，逻辑清晰，视觉直观。

- 步骤2：点击「下一步」→ 取消上步高亮。蓝色高亮线段AN和NM，在NM上方出现标签"p/2"，展示|AF|=|AN|+p/2。
- 步骤3：点击「下一步」→ 取消上步高亮。蓝色高亮半径FB，出现标签"p/2"。同时红色高亮线段AB和AN，并在AB、AN上出现等长标记（短横线），展示|AB|=|AN|。
- 步骤4：点击「下一步」→ 取消上步高亮。蓝色高亮线段AN和x轴的(350,380)-(530,380)段提示平行。出现∠NAB的弧线和"60°"标签。
- 步骤5：点击「下一步」→ 取消上步高亮。出现△ABN的红色半透明填充。出现∠ANB的弧线和"60°"标签，展示等边三角形结论。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：在SVG内部底部（y=450~490区域）居中放置一个绝对定位的div，包含「◀ 上一步」按钮、步骤指示文本（如"步骤 0 / 6"）和「下一步 ▶」按钮。
- 教师操作流程：教师在讲解时，每讲完一个逻辑推导节点，点击「下一步」展示对应的辅助线或高亮关系，配合口头解释，引导学生逐步得出结论。

[技术实现]
- JS 库选择及原因：原生 SVG。本场景主要由精确的几何线段、圆和二次贝塞尔曲线（抛物线）构成，SVG 的 DOM 结构非常适合分步控制元素的显示/隐藏和透明度动画。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +------------------------------------------------+
  |                                                |
  |    M--N-------A                                |
  |       |      /                                 |
  |       |     /                                  |
  |       |    B                                   |
  |       |   /                                    |
  |       O--F-------- x                           |
  |                                                |
  |                                                |
  |      [◀ 上一步]  步骤 0 / 6  [下一步 ▶]        |
  +------------------------------------------------+
  ```
- 关键实现要点：
  1. 抛物线绘制：使用精确的二次贝塞尔曲线 `<path d="M 676.7 100 Q 210 300 410 500" />`，完美拟合顶点在(350,380)且p=120的抛物线。
  2. 状态机设计：定义 `currentStep` 变量（0-6），在 `updateStep()` 函数中根据当前步骤，通过修改对应 SVG 元素的 `style.opacity` 或 `style.display` 实现状态切换，并添加 `transition: opacity 0.3s` 实现平滑过渡。
  3. 高亮层分离：为需要高亮的线段（如AF、AM等）创建独立的 `<line>` 元素，设置较粗的 `stroke-width` 和高亮颜色，置于基础图形之上，通过控制其透明度实现高亮效果，不影响基础图形。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-btn-next`, `scene1-hl-af`）。
- IIFE 隔离：所有 JS 代码包裹在 `(function() { ... })()` 中，避免全局变量污染。
