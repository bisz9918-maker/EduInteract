[图示主题与整合说明]
- 本图示主题：圆与正六边形的无限嵌套及半径递推关系推导
- 整合的步骤/概念：圆的内接正六边形构造、正六边形内切圆构造、基本三角形提取、半径比例几何推导、多层无限嵌套演示。
- 教学价值：教师可以通过分步导航，先引导学生观察第一层嵌套的几何关系，通过提取基本三角形推导出内外圆半径的比例关系（$\cos 30^\circ$），最后通过动画展示无限嵌套过程，帮助学生建立极限与无穷等比数列的直观概念。

[分步序列]
- 初始状态（步骤0）：显示外圆 C1 和内接正六边形 H1。隐藏其他所有元素。
- 步骤1：点击「下一步」→ 显示内切圆 C2。
- 步骤2：点击「下一步」→ 显示点 O, A, B 及对应标签。显示辅助线 OA(虚线), OB(虚线)。显示三角形 OAB 的蓝色半透明填充。高亮显示边 AB(蓝色实线)。
- 步骤3：点击「下一步」→ 显示点 M 及标签。显示垂线 OM(红色实线)。将 OA 变为红色实线。显示 R1, R2 标签。显示 30° 弧线及标签。显示 M 处的直角符号。
- 步骤4：点击「下一步」→ 淡出（隐藏）步骤2和3中添加的所有辅助线、高亮填充、点和标签（保留 C1, H1, C2）。然后通过 JS 定时器，每隔 300ms 依次显示 H2, C3, H3, C4, H4, C5, H5, C6, H6，展示无限嵌套过程。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：在 SVG 容器底部（y=450~490）放置一个绝对定位的 `div`，包含两个按钮。
- 教师操作流程：教师首先展示初始图形，点击下一步展示第一层内切圆；再次点击提取出基本三角形进行局部放大分析；第三次点击作出垂线，引导学生利用 30° 角的余弦值推导内外圆半径比；最后点击展示无限嵌套动画，引出无穷等比数列求和的考点。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。图形均为标准几何图形（圆、多边形、线段），SVG 能够提供最清晰的矢量渲染，且 DOM 操作控制显示/隐藏非常方便。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  +------------------------------------------------+
  |                                                |
  |                   [图示区]                     |
  |             (圆和正六边形居中显示)             |
  |                                                |
  |                                                |
  |                                                |
  |                                                |
  |                                                |
  |         [ ◀ 上一步 ]      [ 下一步 ▶ ]         |
  +------------------------------------------------+
  ```
- 关键实现要点：
  - 状态机设计：定义 `currentStep` 变量（0~4）。编写 `updateScene()` 函数，根据 `currentStep` 设置各 SVG 元素的 `style.display` 或 `style.opacity`。
  - 动画控制：步骤 4 的顺序显示使用 `setTimeout` 数组实现。在 `updateScene()` 中，如果进入步骤 4，则触发动画函数；如果离开步骤 4（如点击上一步），必须清除所有未执行的 `setTimeout`，并重置嵌套图形的显示状态。
  - 坐标计算：所有坐标已在计划中硬编码，直接写入 SVG 元素的属性中，无需在 JS 中动态计算。
  - ID 命名规范：所有元素 ID 均以 `scene1-` 开头，如 `scene1-c1`, `scene1-btn-next`。
  - IIFE 隔离：所有 JS 代码包裹在 `(function() { ... })();` 中，避免全局变量污染。
