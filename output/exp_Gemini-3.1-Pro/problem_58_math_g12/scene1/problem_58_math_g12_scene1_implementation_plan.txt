[图示主题与整合说明]
- 本图示主题：利用圆周角定理和直角三角形求外接圆半径
- 整合的步骤/概念：题目初始条件展示、作直径构造直角三角形、圆周角相等转换、计算半径与面积。
- 教学价值：教师可以通过分步导航，引导学生一步步观察辅助线的添加、圆周角的等量代换，以及最终在直角三角形中利用三角函数求解的过程，逻辑清晰，视觉直观。

[分步序列]
- 初始状态（步骤0）：显示圆O、点O、△ABC。高亮弦AB并标注"4"，标记∠ACB并标注"30°"。右侧面板显示已知条件和求解目标。（注：原题描述∠ACB=37°疑似笔误，本图示采用标准角30°进行演示，并在文本中加以说明）。
- 步骤1（作直径）：点击「下一步」。出现点D，绘制绿色实线BD。右侧面板更新：作直径BD。
- 步骤2（构造直角三角形）：点击「下一步」。绘制灰色虚线AD，红色高亮△ABD区域，在点A处出现红色直角标记。右侧面板更新：直径所对圆周角为90°。
- 步骤3（圆周角转换）：点击「下一步」。蓝色加粗高亮弧AB，同时蓝色高亮∠ACB和∠ADB，在D点处出现"30°"标签。右侧面板更新：同弧所对圆周角相等。
- 步骤4（计算半径）：点击「下一步」。右侧面板展示三角函数计算过程：BD = AB / sin(30°) = 8，得出半径 R = 4。
- 步骤5（计算面积）：点击「下一步」。右侧面板展示面积公式 S = πR² = 16π，得出最终结论。

[交互方案]
- 交互类型：分步按钮导航。
- 控件说明：在SVG容器底部（y=450~490）放置两个按钮：「◀ 上一步」和「下一步 ▶」。
- 教师操作流程：教师首先展示初始题目条件，随后每次点击「下一步」，图示区会动态增加辅助线或高亮关键几何关系，右侧文本区同步出现对应的推导公式，完美配合教师的口述讲解节奏。

[技术实现]
- JS 库选择：原生 SVG（用于精确绘制几何图形） + 原生 HTML/CSS（用于右侧文本面板和底部按钮）。无需引入外部库。
- 画布尺寸：800 × 500 px（固定尺寸，SVG与HTML容器重叠布局）。
- 布局草图：
  ```text
  +-------------------------------------------------+
  |  [SVG 图示区 450x450]      [HTML 文本面板]      |
  |          B .               +---------------+    |
  |       .     .              | 步骤 3:       |    |
  |    D .   O   . A           | ∠ADB = ∠ACB   |    |
  |       .     .              | = 30°         |    |
  |          C                 +---------------+    |
  |                                                 |
  |  [控件栏]      (◀ 上一步)  (下一步 ▶)           |
  +-------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：定义 `currentStep` 变量（0-5），每次点击按钮更新变量，并调用 `updateScene()` 函数。
  2. 动画与显示：为 SVG 元素（如 `<g id="scene1-step1">`）和 HTML 文本块设置 `transition: opacity 0.5s`。在 `updateScene()` 中根据当前步骤切换元素的 `opacity`（0 或 1）。
  3. 坐标系：SVG 采用默认坐标系（左上角为0,0，向右向下为正）。所有坐标已在表中精确计算，直接硬编码写入 SVG 属性。
  4. ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-btn-next`, `scene1-step1-group`）。
  5. 作用域隔离：所有 JS 代码必须包裹在 `(function() { ... })()` 中，避免全局变量污染。
