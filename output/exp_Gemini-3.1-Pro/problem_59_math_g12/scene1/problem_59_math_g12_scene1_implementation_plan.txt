[图示主题与整合说明]
- 本图示主题：利用正弦定理求解河宽的几何推导过程
- 整合的步骤/概念：题目已知条件标注、计算第三角、作高线表示河宽、利用正弦定理和直角三角形求解。
- 教学价值：教师可以通过分步展示，引导学生理清“找条件-求角-求边-求高”的逻辑链条，将复杂的解三角形问题拆解为清晰的步骤，避免一次性呈现过多信息导致认知过载。

[视觉元素清单]
- 河岸线：上下两条水平黑色实线 (#000000)。
- △ABC：黑色实线 (#000000) 连接 A, B, C。
- 顶点标签：A, B, C, D，黑色字体 (#000000)。
- 已知条件：
  - ∠CAB = 75°：蓝色 (#1565c0) 圆弧及文本。
  - ∠CBA = 45°：蓝色 (#1565c0) 圆弧及文本。
  - AB = 96：蓝色 (#1565c0) 文本。
- 推导条件：
  - ∠C = 60°：绿色 (#2e7d32) 圆弧及文本。
- 目标高线：
  - CD：红色 (#c62828) 虚线。
  - 直角符号：红色 (#c62828) 折线。
  - h：红色 (#c62828) 文本。
- 高亮区域：
  - △ABC：#1565c0 填充，透明度 10%。
  - △ACD：#c62828 填充，透明度 10%。

[分步序列]
- 初始状态（步骤0）：显示河岸线，△ABC，顶点 A, B, C 标签。提示文本为空。
- 步骤1：点击「下一步」→ 显示已知条件（∠A=75°, ∠B=45°, AB=96）。提示文本：“已知：∠CAB = 75°, ∠CBA = 45°, AB = 96”。
- 步骤2：点击「下一步」→ 显示推导条件（∠C=60°）。提示文本：“计算第三角：∠C = 180° - 75° - 45° = 60°”。
- 步骤3：点击「下一步」→ 显示高线 CD，垂足 D，直角符号，河宽 h。提示文本：“作高线 CD，设河宽为 h”。
- 步骤4：点击「下一步」→ 高亮 △ABC 区域，加粗边 AC（蓝色）。提示文本：“在 △ABC 中，由正弦定理得：AC / sin 45° = AB / sin 60°”。
- 步骤5：点击「下一步」→ 取消 △ABC 高亮，高亮 △ACD 区域，加粗边 CD（红色）。提示文本：“在 Rt△ACD 中，h = AC · sin 75°”。

[交互方案]

- 控件说明：
  - 底部控件栏（y=450~490），包含“上一步”和“下一步”按钮。

- 教师操作流程：教师点击“下一步”逐步展示解题逻辑，配合底部的提示文本进行讲解。可随时点击“上一步”回退复习。

[技术实现]
- JS 库选择及原因：原生 SVG。由于图形主要是简单的几何线段、多边形和文本，SVG 能够提供高质量的矢量渲染，并且非常容易通过 CSS 控制透明度和过渡动画。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×440]
    (上河岸) ------------------------- C -------------------------
                                      /|\
                                     / | \
                                    /  |  \
                                   /   |   \
                                  /    |    \
    (下河岸) --------------------A-----D-----B--------------------
  [提示文本区 y=420]
  [控件栏 y=450~490 (上一步) (下一步)]
  ```
- 关键实现要点：
  - 使用 `<g>` 标签对不同步骤的元素进行分组，通过控制 `opacity` 实现显示/隐藏。
  - 添加 CSS `transition: opacity 0.3s ease` 实现平滑过渡。
  - 维护一个 `currentStep` 变量（0~5），在按钮点击事件中更新，并调用 `updateScene()` 函数。
  - `updateScene()` 根据 `currentStep` 设置各组的 `opacity` 和提示文本的内容。同时处理按钮的禁用状态（步骤0禁用“上一步”，步骤5禁用“下一步”）。
  - ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-step1-group`, `scene1-btn-next`）；JS 中用 `document.getElementById` 获取元素。
  - IIFE 隔离：所有 JS 代码必须包裹在 `(function() { ... })()` 中，避免全局变量污染。
