[图示主题与整合说明]
- 本图示主题：圆中切线性质的几何证明
- 整合的步骤/概念：整合了切线长定理、角平分线性质、直角三角形射影定理的逐步推导过程。
- 教学价值：教师可以通过分步演示，引导学生观察切线长定理带来的线段和角度相等关系，进而发现直角三角形及斜边上的高，最终利用射影定理得出结论。

[分步序列]
- 初始状态（步骤0）：显示圆O，直径AB，切线AC, BD, CD，切点P，以及所有对应的点和标签。底部显示说明文字：“初始状态：圆O，直径AB，切线AC、BD、CD，切点为P。”
- 步骤1：点击「下一步」→ 显示辅助线OC, OD, OP。底部显示说明文字：“连接辅助线：连接OC、OD、OP。”
- 步骤2：点击「下一步」→ 高亮AC和PC（蓝色），BD和PD（红色）。显示蓝色角度弧线（∠AOC, ∠POC）和红色角度弧线（∠BOD, ∠POD）。底部显示说明文字：“由切线长定理可知：AC=PC，BD=PD，且OC平分∠AOP，OD平分∠BOP。”
- 步骤3：点击「下一步」→ 显示O点和P点的直角标记。在画布下方(400,400)处淡入显示结论文本“结论: PC · PD = OP²”。底部显示说明文字：“推导结论：∠COD = 90°，且OP⊥CD，由射影定理得 PC·PD = OP²。”

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 底部控件区（y=450~490）居中放置两个按钮：“上一步”和“下一步”。
  - 按钮上方或中间放置一段文本，用于显示当前步骤的说明。
- 教师操作流程：教师在讲解时，首先展示初始题目条件，然后点击“下一步”逐步引导学生思考辅助线的作法、切线长定理的应用，最后得出直角和射影定理的结论。可随时点击“上一步”回顾。

[技术实现]
- JS 库选择及原因：原生 SVG 和原生 JavaScript。图形均为基础几何图形，SVG 能够提供高质量的矢量渲染，且易于通过 DOM 操作实现动画和状态切换。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×450]
    (圆和切线图形居中偏上，结论文本在图形下方)
  [控件栏 800×50]
    (说明文本 + 上一步/下一步按钮，绝对定位在底部)
  ```
- 关键实现要点：
  - 使用一个 `currentStep` 变量记录当前状态（0-3）。
  - 每次步骤切换时，通过修改 SVG 元素的 `opacity` 属性来实现元素的显示和隐藏，可配合 CSS `transition: opacity 0.5s` 实现平滑过渡。
  - 角度弧线和直角标记的精确 SVG Path 数据如下（代码 Agent 可直接使用）：
    - 弧线AOC: `M 375 250 A 25 25 0 0 1 378.35 237.5`
    - 弧线POC: `M 378.35 237.5 A 25 25 0 0 1 387.5 228.35`
    - 弧线POD: `M 387.5 228.35 A 25 25 0 0 1 412.5 228.35`
    - 弧线BOD: `M 412.5 228.35 A 25 25 0 0 1 425 250`
    - 直角标记O: `M 400 250 L 382.68 240 L 392.68 222.68 L 410 232.68 Z`
    - 直角标记P: `M 340 146 L 350 163.32 L 367.32 153.32 L 357.32 136 Z`
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀，例如 `scene1-btn-next`, `scene1-line-oc`, `scene1-text-desc` 等。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
