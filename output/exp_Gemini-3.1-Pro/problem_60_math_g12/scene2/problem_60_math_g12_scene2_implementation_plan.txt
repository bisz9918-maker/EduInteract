[图示主题与整合说明]
- 本图示主题：椭圆中类比结论的动态验证
- 整合的步骤/概念：整合了椭圆的切线、焦点连线以及 $PC \cdot PD$ 与 $PF_1 \cdot PF_2$ 乘积相等的动态数值验证。
- 教学价值：教师可通过拖动滑块连续改变点 P 的位置，实时展示切线和焦点连线的动态变化，并通过右侧数据面板直观验证 $PC \cdot PD = PF_1 \cdot PF_2$ 这一类比结论，帮助学生深刻理解椭圆的几何性质。

[分步序列]
- 初始状态（步骤0）：
  - 显示椭圆、长轴 AB、焦点 F₁、F₂、中心 O。
  - 动点 P 位于 $	heta = 2.09$ (约 120°) 处，即 (230, 156.5)。
  - 显示切线 AC、BD，以及切线段 PC、PD 和焦点连线 PF₁、PF₂。
  - 右侧数据面板显示初始长度和乘积，验证 $PC \cdot PD = PF_1 \cdot PF_2 = 27216.0$。
- 交互状态：
  - 拖动底部滑块，改变参数 $	heta \in [0.3, 2.84]$。
  - 点 P 在椭圆上半部分平滑移动。
  - 点 C 和 D 分别在直线 $x=140$ 和 $x=500$ 上滑动。
  - 线段 PC, PD, PF₁, PF₂ 实时跟随更新。
  - 数据面板中的数值实时更新，乘积始终保持相等。

[标签冲突检查]
- A(125, 270) 与 C(120, y_C)：y_C 始终在上半平面 (y < 250)，A 在 y=270，无冲突。
- B(515, 270) 与 D(520, y_D)：y_D 始终在上半平面 (y < 250)，B 在 y=270，无冲突。
- F₂(176, 270) 与 A(125, 270)：x 间距 51px，无冲突。
- O(320, 270) 与 F₂(176, 270)：x 间距 144px，无冲突。
- F₁(464, 270) 与 O(320, 270)：x 间距 144px，无冲突。
- P 标签：动态计算偏移量 `(Px + 15*cosθ, Py - 15*sinθ)`，始终位于椭圆外侧，且 P 始终在 y < 250 区域，不会与底部轴线上的标签冲突。

[交互方案]
- 交互类型：连续拖拽滑块。
- 控件说明：在 SVG 容器底部 (y=460) 放置一个 `<input type="range">` 滑块，范围 `min="0.3" max="2.84" step="0.01"`，初始值 `2.09`。
- 教师操作流程：教师在讲解时，缓慢拖动滑块，引导学生观察图形的动态变化，并注意右侧数据面板中 $PC \cdot PD$ 和 $PF_1 \cdot PF_2$ 的数值虽然各自的因子在变，但乘积始终相等，从而直观验证结论。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。图形简单，原生 SVG 性能好且易于实现 DOM 更新。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```text
  [图示区 800×500]
  +-----------------------------------------+---------+
  |                                         | 数据面板|
  |          P                              | PC=...  |
  |       /  |  \                           | PD=...  |
  |    C /   |   \ D                        | PC·PD=..|
  |    |/    |    \|                        |         |
  |----A--F2-O--F1-B------------------------| PF1=... |
  |    |           |                        | PF2=... |
  |                                         | PF1·PF2=|
  |                                         |         |
  |  [滑块: 拖动改变 P 点位置]              |         |
  +-----------------------------------------+---------+
  ```
- 关键实现要点：
  - 坐标计算：
    - $P_x = 320 + 180 \cos	heta$, $P_y = 250 - 108 \sin	heta$
    - $C_y = 250 - 108 rac{1+\cos	heta}{\sin	heta}$
    - $D_y = 250 - 108 rac{1-\cos	heta}{\sin	heta}$
  - 数据更新：使用 `Math.hypot` 计算像素距离，直接展示。为避免浮点数显示差异，乘积可统一使用 `(PC * PD).toFixed(1)`。
  - ID 命名规范：所有元素 ID 以 `scene2-` 开头，如 `scene2-point-p`, `scene2-slider`。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
