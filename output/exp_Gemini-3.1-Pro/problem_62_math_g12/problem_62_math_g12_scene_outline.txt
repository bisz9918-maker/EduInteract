    题目原文：
    如图，在四面体ABCD中，E，F分别为AB，CD的中点，过EF任作一个平面α分别与直线BC，AD相交于点G，H，则下列结论正确的是______． 
    ①对于任意的平面α，都有直线GF，EH，BD相交于同一点；
    ②存在一个平面α₀，使得GF∥EH∥BD；
    ③存在一个平面α₀，使得点G在线段BC上，点H在线段AD的延长线上；
    ④对于任意的平面α，都有S_{△EFG}=S_{△EFH}．

    【题目分析与整体讲解思路】
    本题考查空间立体几何中的截面问题、线面关系以及空间向量的应用。
    - 对于①和②，主要考察空间中直线的交点问题。$GF \subset 平面BCD$，$EH \subset 平面ABD$，两平面的交线为 $BD$。因此 $GF$ 与 $EH$ 若相交，交点必在 $BD$ 上。但当 $G, H$ 分别为 $BC, AD$ 中点时，$GF \parallel BD$ 且 $EH \parallel BD$，此时两者平行不相交，故①错②对。
    - 对于③和④，最有效的方法是引入空间向量。以 $\vec{AB}, \vec{AC}, \vec{AD}$ 为基底，利用 $E, F, G, H$ 四点共面，可推导出 $\vec{BG} = \lambda \vec{BC}$ 且 $\vec{AH} = \lambda \vec{AD}$，即 $G, H$ 在各自线段上的分点比相同，从而判断③错。
    - 进一步利用向量加法得到 $\vec{EG} + \vec{EH} = 2\lambda \vec{EF}$，说明 $GH$ 的中点始终在直线 $EF$ 上，进而得出 $G, H$ 到 $EF$ 的距离相等，证明④对。

    【图示规划说明】
    本题设计两个交互图示：
    1. **截面动态演示**：通过拖拽滑块改变截面 $\alpha$ 的位置，直观展示交线 $GF, EH$ 与 $BD$ 的位置关系，帮助学生理解①和②的判定，并初步感知 $G, H$ 的同步运动。
    2. **向量法推导**：通过分步动画，逐步展示向量关系的推导过程，以及 $GH$ 中点在 $EF$ 上的几何意义，严谨证明③和④。
    </TEXT_1>

    【教学说明：向量法推导与面积证明】
    在直观感知后，我们需要用严谨的数学语言来证明③和④。
    引导学生使用空间向量：

    1. **表示向量 EF**：
       $\vec{EF} = \vec{EA} + \vec{AD} + \vec{DF}$
       $\vec{EF} = \vec{EB} + \vec{BC} + \vec{CF}$
       两式相加，利用 $E, F$ 为中点（$\vec{EA}+\vec{EB}=\vec{0}$，$\vec{DF}+\vec{CF}=\vec{0}$），得到 $2\vec{EF} = \vec{AD} + \vec{BC}$，即 $\vec{EF} = rac{1}{2}(\vec{AD} + \vec{BC})$。
    2. **分析共面条件（判断③）**：
       设 $\vec{BG} = \lambda \vec{BC}$，$\vec{AH} = \mu \vec{AD}$。
       因为 $E, F, G, H$ 四点共面，所以向量 $\vec{EF}, \vec{EG}, \vec{EH}$ 共面。
       推导可得 $\lambda = \mu$。这意味着 $G$ 和 $H$ 在各自线段上的位置比例始终相同。如果 $G$ 在线段 $BC$ 上（$0 \le \lambda \le 1$），那么 $H$ 必然在线段 $AD$ 上，不可能在延长线上。因此③错误。
    3. **证明面积相等（判断④）**：
       由 $\lambda = \mu$，我们计算 $\vec{EG} + \vec{EH}$：
       $\vec{EG} + \vec{EH} = (\vec{EB} + \lambda \vec{BC}) + (\vec{EA} + \lambda \vec{AD}) = \lambda(\vec{BC} + \vec{AD}) = 2\lambda \vec{EF}$。
       取 $GH$ 的中点 $M$，则 $\vec{EG} + \vec{EH} = 2\vec{EM}$。
       所以 $\vec{EM} = \lambda \vec{EF}$，这说明向量 $\vec{EM}$ 与 $\vec{EF}$ 共线，即中点 $M$ 始终在直线 $EF$ 上。
       既然 $GH$ 的中点在 $EF$ 上，那么 $G$ 和 $H$ 到直线 $EF$ 的距离必然相等。
       底边 $EF$ 相同，高相等，因此 $S_{	riangle EFG} = S_{	riangle EFH}$ 恒成立，④正确。
    </TEXT_2>

    【总结】
    综上所述，正确的结论是②和④。

    课堂讲解建议：
    1. 先利用图示 1 建立直观的几何表象，让学生看到截面的动态变化，打破“交线必然相交”的思维定势，理解平行是相交的特殊情况（极限状态）。
    2. 在讲解③和④时，由于纯几何方法寻找垂线较为困难，强烈建议引导学生使用空间向量（图示 2）。这不仅能快速破解本题，也是解决复杂立体几何问题的通用利器。
    3. 强调向量加法的几何意义（平行四边形法则与中点公式），这是理解 $\vec{EG} + \vec{EH} = 2\vec{EM}$ 的关键。
