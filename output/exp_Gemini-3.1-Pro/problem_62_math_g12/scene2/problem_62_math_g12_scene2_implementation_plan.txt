[图示主题与整合说明]
- 本图示主题：空间向量推导及 GH 中点轨迹证明
- 整合的步骤/概念：向量 EF 的分解、G 和 H 位置参数的统一、GH 中点 M 在 EF 上的证明、等底等高三角形面积证明。

[分步序列]
- 初始状态（步骤0）：
  - 显示：四面体线框，截面 EGFH，点 A,B,C,D,E,F,G,H 及其标签。高亮向量 AD, BC。
  - 文本面板：“初始状态：四面体 ABCD 中，E, F 为中点。截面 EGFH 交 BC 于 G，交 AD 于 H。”
- 步骤1（表示 EF）：
  - 变化：新增向量 EA, DF, EB, CF (灰色虚线箭头) 和向量 EF (红色箭头)。
  - 文本面板：“向量 EF 的分解：<br>EF = EA + AD + DF<br>EF = EB + BC + CF<br>相加得：2EF = (EA+EB) + (AD+BC) + (DF+CF)<br>因 E, F 为中点，EA+EB=0, DF+CF=0<br>故 EF = 1/2(AD + BC)”
- 步骤2（共面推导）：
  - 变化：隐藏 EA, DF, EB, CF。显示向量 EG, EH (绿色箭头)。
  - 文本面板：“设 BG = λ BC, AH = μ AD<br>EG = EB + BG = 1/2 AB + λ BC<br>EH = EA + AH = -1/2 AB + μ AD<br>因 E, G, F, H 共面，存在 x, y 使 EF = x EG + y EH<br>代入推导可得 λ = μ。”
- 步骤3（中点共线）：
  - 变化：显示线段 GH，标记中点 M 及其标签。显示向量 EM (绿色箭头)。
  - 文本面板：“取 GH 中点 M。<br>EM = 1/2(EG + EH)<br>代入 EG 和 EH 表达式：<br>EM = 1/2(λ BC + μ AD)<br>因 λ = μ，EM = λ * 1/2(BC + AD) = λ EF<br>结论：点 M 在直线 EF 上。”
- 步骤4（面积相等）：
  - 变化：显示垂线段 GG', HH'，点 G', H' 及其标签，直角符号。高亮 △MGG' 和 △MHH'。高亮 △EFG 和 △EFH。
  - 文本面板：“作 GG' ⊥ EF, HH' ⊥ EF。<br>在 △MGG' 和 △MHH' 中：<br>∠G'MG = ∠H'MH, ∠MG'G = ∠MH'H = 90°<br>MG = MH<br>所以 △MGG' ≌ △MHH'，得 GG' = HH'。<br>结论：S_△EFG = S_△EFH (等底等高)。”

[交互方案]
- 交互类型：分步按钮导航

[技术实现]
- JS 库选择及原因：原生 SVG。由于本场景主要由直线、多边形和箭头组成，SVG 能够提供高质量的矢量渲染，且通过控制 DOM 元素的 `opacity` 属性结合 CSS `transition` 可以轻松实现平滑的步骤切换动画。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  +--------------------------------------------------+
  |                                 [推导文本面板]   |
  |        A                        +--------------+ |
  |       /|\                       | EF=...       | |
  |      / | \                      |              | |
  |     /  |  H                     +--------------+ |
  |    E   |   \                                     |
  |   / \  |    \                                    |
  |  /   G' M H' \                                   |
  | B--G---+------D                                  |
  |  \      \    /                                   |
  |   \      F  /                                    |
  |    \      /                                     |
  |     -------C                                     |
  |                                                  |
  |             [◀ 上一步]  [下一步 ▶]               |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  - 状态机设计：定义 `currentStep` 变量（0-4），编写 `updateScene()` 函数，根据当前步骤设置各 SVG 元素的 `opacity`（0 或 1）和文本面板的 `innerHTML`。
  - 箭头标记：在 `<defs>` 中定义三种颜色的 `<marker>`（blue, red, green），供不同向量的 `marker-end` 引用。
  - 动画过渡：为所有 SVG 元素添加 `style="transition: opacity 0.5s ease;"`，实现平滑显示/隐藏。
  - 文本面板：使用绝对定位的 `<div>` 放置在 (500, 50) 处，背景半透明，确保不遮挡底层可能存在的线条。
- ID 命名规范：所有交互元素 ID 必须以 `scene2-` 为前缀（如 `scene2-vec-ef`, `scene2-btn-next`）。
- IIFE 隔离：所有 JS 代码必须包裹在 `(function() { ... })()` 中。
