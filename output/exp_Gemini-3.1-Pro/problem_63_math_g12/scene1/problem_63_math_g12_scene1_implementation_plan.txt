[图示主题与整合说明]
- 本图示主题：双曲线与圆的综合几何推导
- 整合的步骤/概念：题目基础条件展示、切线性质与勾股定理应用、三角形中位线定理、双曲线定义。
- 教学价值：教师可通过分步点击，逐步添加辅助线和长度标注，引导学生跟随推导过程，从切线性质得出线段长度，再利用中位线定理和双曲线定义最终求出渐近线方程，避免一次性展示过多信息导致认知超载。

- 步骤2：点击「下一步」→ 线段PM变为红色，显示标签a(PM旁)。
- 步骤3：点击「下一步」→ 出现左焦点F'及标签，出现线段F'P(蓝色)和F'F(加粗或高亮)。显示标签2b(F'P旁)。
- 步骤4：点击「下一步」→ 线段F'P和PF加粗闪烁或高亮。左上角依次出现公式1和公式2。渐近线变为黑色实线加粗，左上角出现公式3。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：在SVG内部底部（y=460区域）居中放置两个按钮「◀ 上一步」和「下一步 ▶」，以及步骤指示器（如 1 / 5）。
- 教师操作流程：教师首先展示题目初始图形，讲解题意；点击下一步，引导学生观察切线性质并得出MF长度；再次点击，利用中位线性质得出PM长度；第三次点击，构造中位线F'P并得出其长度；最后点击，结合双曲线定义得出a与b的关系，最终求出渐近线方程。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。SVG 非常适合绘制精确的几何图形（线段、圆、二次曲线），且易于通过 DOM 操作实现分步动画和样式切换，无需引入庞大的外部库。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  (左上角留白用于显示推导公式)
  (中央偏右为双曲线、圆及几何辅助线主体)
  [控件栏 居中于 y=460 处，包含 上一步 / 下一步 按钮]
  ```
- 关键实现要点：
  - 坐标系转换：定义数学坐标到屏幕坐标的映射函数（如 `sx = 400 + x`, `sy = 250 - y`），方便后续调整。
  - 双曲线绘制：使用 `<path>` 元素，通过 JS 生成一系列点（参数方程 x = ±a*cosh(t), y = b*sinh(t)）并拼接成 `M ... L ...` 路径。
  - 状态机设计：定义一个 `currentStep` 变量（0-4），每次点击按钮更新该变量，并调用 `updateScene()` 函数。该函数根据当前步骤控制各 SVG 元素的 `display`、`stroke`、`stroke-width` 等属性。
  - 动画过渡：可为 SVG 元素添加 `transition: all 0.3s ease` 实现平滑的颜色和透明度变化。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-btn-next`, `scene1-line-om`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
