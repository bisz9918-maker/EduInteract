[图示主题与整合说明]
- 本图示主题：异面直线垂直向底面直线垂直的转化与证明
- 整合的步骤/概念：直四棱柱的空间结构展示、异面直线的平移转化（$B_1D_1$ 平移至 $BD$）、线面垂直辅助面（$BB_1D_1D$）的构建与证明逻辑。
- 教学价值：教师可通过分步按钮，配合讲解节奏，逐步展示异面直线如何通过平移转化为共面直线，并利用直四棱柱的侧棱垂直性质构建辅助面，最终将空间线面垂直问题降维到底面几何图形的对角线垂直问题。支持轻微拖拽旋转，帮助学生建立清晰的空间想象。

[分步序列]
- 初始状态（步骤0）：显示 3D 直四棱柱骨架，高亮异面直线 $AC$（红）和 $B_1D_1$（蓝）。隐藏其他辅助元素和 2D 视图。
- 步骤1（平移找平行）：点击「下一步」，触发平移轨迹面动画，线段 $B_1D_1$ 向下平移至 $BD$ 位置，显示蓝色的 $BD$ 线段。
- 步骤2（线面垂直条件）：点击「下一步」，高亮绿色侧棱 $BB_1$，显示中心辅助垂线 $OO_1$，并在 $OO_1$ 与 $OC$ 之间显示直角符号1，直观表达侧棱与底面直线的垂直关系。
- 步骤3（构建对角面）：点击「下一步」，填充半透明蓝色对角面 $BB_1D_1D$，在底面中心 $O$ 处显示闪烁的直角符号2（表示 $AC \perp BD$）。
- 步骤4（得出结论）：点击「下一步」，右下角弹出 2D 底面视图，清晰展示对角线互相垂直的菱形结构。

[交互方案]
- 交互类型：分步按钮导航 + 3D视角轻微拖拽
- 控件说明：底部居中放置两个按钮 `[◀ 上一步]` 和 `[下一步 ▶]`，位于 y=460 区域。
- 拖拽交互：在 SVG 区域按下鼠标并左右拖动，可改变 3D 模型的 Y 轴旋转角度（限制在 $\pm 30^\circ$ 内，即 $\pm 0.5$ 弧度，确保 A 点始终在后方，无需动态计算虚实线遮挡）。
- 教师操作流程：教师首先展示初始异面直线，拖拽视角让学生看清空间位置；然后逐点击下一步，配合动画讲解平移、垂直条件和辅助面构建，最后展示 2D 结论。

[技术实现]
- JS 库选择：原生 SVG + 原生 JS。通过自定义轻量级 3D 投影函数实现 3D 渲染和拖拽旋转，无需引入庞大的 3D 引擎，保证代码简洁和样式完全可控。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
    (380, 240) 3D直四棱柱主图区
                                  (680, 350)
                                  2D底面视图区
  [控件栏 y=460~490: ◀ 上一步 | 下一步 ▶]
  ```
- 关键实现要点：
  1. **3D投影函数**：
     ```javascript
     let angleY = 0; // 拖拽更新此值，限制在 [-0.5, 0.5]
     function project(x, y, z) {
         let rx = x * Math.cos(angleY) - z * Math.sin(angleY);
         let rz = x * Math.sin(angleY) + z * Math.cos(angleY);
         return { x: 380 + rx - rz * 0.5, y: 330 - y + rz * 0.3 };
     }
     ```
  2. **统一更新机制**：编写 `updatePaths()` 函数，遍历所有 3D 元素（线段、多边形、直角符号点），调用 `project()` 计算最新 2D 坐标并更新 SVG 的 `d` 或 `points` 属性。拖拽和动画时均调用此函数。
  3. **平移动画**：使用 `requestAnimationFrame` 改变平移线段的 Y 坐标（从 180 到 0），并在 `updatePaths()` 中实时渲染平移线和半透明轨迹面。
  4. **ID 命名规范**：所有元素 ID 必须以 `scene1-` 开头，如 `scene1-prism-solid`, `scene1-btn-next`。
  5. **作用域隔离**：所有 JS 代码封装在 `(function() { ... })()` 中。
