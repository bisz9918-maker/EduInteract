[图示主题与整合说明]
- 本图示主题：正三角形翻折过程中的空间几何关系推导
- 整合的步骤/概念：整合了线面垂直证明（命题3）、射影位置分析（命题1）和锥体体积最值分析（命题2）。
- 教学价值：通过2.5D透视投影和动态翻折滑块，帮助学生直观建立空间观念，理解翻折过程中不变量（如垂直关系）与变量（如高、体积）的动态联系。

[分步序列]
- 初始状态（步骤0）：显示基础底面和翻折面 A'DE。隐藏所有高亮、垂线和直角标记。教师可拖动滑块演示翻折。
- 步骤1（命题3）：点击「下一步」。高亮线段 A'G 和 FG（蓝色），显示 ∠A'GE 和 ∠FGE 的直角标记。填充平面 A'GF 和 BCED（蓝色透明）。揭示平面 A'GF ⊥ 平面 BCED。
- 步骤2（命题1）：点击「下一步」。清除步骤1的高亮。显示垂足 H 和垂线 A'H（红色），显示 ∠A'HF 直角标记。拖动滑块可观察 H 始终在线段 AF 上移动。
- 步骤3（命题2）：点击「下一步」。保留 A'H（红色）。高亮三棱锥 A'-FED 的边（绿色）并填充侧面。拖动滑块观察高 A'H 变化，直观感受体积最值。

[交互方案]
- 交互类型：分步按钮导航 + 拖拽滑块
- 控件说明：
  1. 底部左侧：[◀ 上一步] [下一步 ▶] 按钮，用于切换 0-3 步骤。
  2. 底部右侧：[翻折角度 θ] 滑块，范围 0 到 180，默认 60。
- 教师操作流程：教师首先使用滑块让学生观察翻折过程，建立空间感。然后依次点击下一步，结合高亮元素讲解线面垂直、射影位置和体积最值。在任何步骤均可滑动滑块验证结论的普适性。

[技术实现]
- JS 库选择及原因：原生 SVG。本场景的 3D 投影可通过简单的仿射变换公式精确计算，使用原生 SVG 配合 JS 动态更新 DOM 属性，既轻量又能保证极高的渲染清晰度和完美的标签定位。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```text
  +------------------------------------------------+
  |                                                |
  |                      A'                        |
  |                     /| \                       |
  |                   /  |   \                     |
  |                 /    |     \                   |
  |               B      H-------A                 |
  |                 \    |     /                   |
  |                   \  |   /                     |
  |                     \| /                       |
  |                      C                         |
  |                                                |
  +------------------------------------------------+
  | [◀ 上一步] [下一步 ▶]        翻折角度: [====O--] |
  +------------------------------------------------+
  ```
- 关键实现要点：
  1. **2.5D 投影公式**：
     设 θ 为翻折角度（弧度）。
     Hx = 500 + 160 * cos(θ)
     Hy = 220 - 20 * cos(θ)
     A'x = Hx
     A'y = Hy - 160 * sin(θ)
     通过此公式，保证了在 2D 投影中，垂线 A'H 始终是绝对垂直的，极大地增强了视觉上的几何严谨性。
  2. **状态机设计**：定义 `currentStep` (0-3)，每次步骤切换或滑块拖动时，调用统一的 `updateScene()` 函数。该函数先根据 θ 更新 A' 和 H 的坐标及相关线段/多边形的 `d` 或 `points` 属性，然后根据 `currentStep` 控制各元素的 `display` 或 `opacity`。
  3. **直角标记计算**：编写辅助函数 `drawRightAngle(p1, p2, p3)`，利用向量归一化计算出正交的偏移点，生成 `<path>` 的 `d` 属性，确保在任何角度下直角标记都贴合线段。
- ID 命名规范：所有 DOM 元素 ID 必须以 `scene1-` 开头，例如 `scene1-svg`, `scene1-point-a`, `scene1-slider`。
- IIFE 隔离：所有逻辑封装在 `(function() { ... })()` 中。
