[图示主题与整合说明]
- 本图示主题：异面直线垂直的向量分析（命题4）
- 整合的步骤/概念：整合了空间直角坐标系的建立、动点坐标的参数化表示、向量数量积的代数计算与异面直线垂直的几何判定。
- 教学价值：教师可通过拖动滑块连续改变翻折角度，让学生直观观察到空间中异面直线相对位置的变化。同时，右侧面板实时显示向量坐标和数量积的计算过程，帮助学生建立“几何直观”与“代数计算”之间的桥梁。当数量积为0时，图形中出现直角标记和高亮提示，深刻揭示了“向量数量积为0”与“异面直线垂直”的等价关系。

[视觉元素清单]
- 3D坐标系：包含x, y, z三根带箭头的实线射线，黑色，线宽1.5。
- 底面梯形BCED：包含线段BC, CE, DB（黑色实线，线宽1.5），以及ED（黑色虚线，线宽1.5）。
- 辅助底面线：FG（黑色虚线，线宽1）。
- 翻折三角形A'DE：包含线段A'D, A'F（黑色实线，线宽1.5），A'G（黑色虚线，线宽1.5）。
- 目标向量 $\vec{A'E}$：从A'指向E的带箭头线段，蓝色 #1565c0，线宽3。
- 目标向量 $\vec{BD}$：从B指向D的带箭头线段，红色 #c62828，线宽3。
- 平移向量 $\vec{EB'}$：从E指向B'的带箭头线段，红色虚线 #c62828，线宽2。仅在垂直状态下高亮显示。

[分步序列]
本场景采用连续拖拽滑块的交互方式，无离散步骤，主要分为以下状态：
- 初始状态（$	heta = 0^\circ$）：滑块在最左侧。A'点位于底面（坐标为(286,163)）。右侧面板显示当前 $\cos	heta = 1.00$，数量积为 -2.00，结论为“不垂直”。
- 拖拽过程状态（$0^\circ < 	heta < 180^\circ$ 且 $	heta 
eq 70.5^\circ$）：随着滑块拖动，A'点在空间中划出圆弧，$\vec{A'E}$ 随之转动。右侧面板的坐标、$\cos	heta$ 和数量积数值实时更新。
- 垂直临界状态（$	heta \approx 70.5^\circ$）：当滑块拖动到使 $\cos	heta = 1/3$ 时（具有吸附效果），数量积变为 0.00。此时触发视觉突变：
  1. 结论文字变为红色加粗的“$\vec{A'E} \perp \vec{BD}$”。
  2. 出现从E指向B'的红色虚线向量 $\vec{EB'}$。
  3. E点处出现红色的直角标记。
  4. 向量 $\vec{A'E}$ 和 $\vec{BD}$ 增加发光效果（或加粗）。

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：
  - 底部滑块（`<input type="range">`）：ID为 `scene2-slider`，范围 0-180，步长 0.5。用于控制翻折角度 $	heta$。
- 教师操作流程：
  1. 教师首先展示初始状态，指出异面直线 $A'E$ 和 $BD$ 的初始位置。
  2. 引导学生观察右侧面板的向量坐标参数化表示，解释 $\cos	heta$ 在坐标中的作用。
  3. 缓慢拖动底部滑块，让学生观察数量积数值的变化趋势。
  4. 当滑块接近 70.5° 时，放慢速度，展示数量积归零的瞬间，以及画面中出现的直角标记，强调代数结果与几何现象的完美契合。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。因为本场景的 3D 效果可以通过简单的仿射变换（投影矩阵）在 2D SVG 中完美实现，且原生 SVG 对线条、箭头、标签的像素级控制更精确，无需引入庞大的 3D 库。MathJax 用于右侧面板的公式渲染。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 500×450] [数据面板 280×380]
  [控件栏 800×50 (滑块居中)]
  ```
- 关键实现要点：
  1. **3D到2D投影函数**：实现 `project(x, y, z)` 函数，使用基向量 $\vec{u}_x = (1, 0)$, $\vec{u}_y = (-0.3, 0.8)$, $\vec{u}_z = (0, -1)$，缩放系数 $s=70$，原点偏移 $(250, 260)$。
  2. **状态更新机制**：监听滑块 `input` 事件，计算新的 $	heta$。如果 $|1 - 3\cos	heta| < 0.05$，则强制 $	heta = \arccos(1/3)$，并设置 `isPerpendicular = true`（吸附效果）。
  3. **DOM 更新**：根据新的 $	heta$ 计算 A' 的 3D 坐标，调用投影函数得到 2D 坐标，更新 SVG 中所有与 A' 相关的线段（A'E, A'D, A'F, A'G）的 `x1, y1, x2, y2` 属性。
  4. **数据面板更新**：直接修改 HTML 元素的 `innerText`（如 `scene2-theta-val`, `scene2-cos-val`, `scene2-dot-val`），避免频繁调用 MathJax 重新渲染，保证拖拽流畅度。
  5. **直角标记绘制**：当 `isPerpendicular` 为真时，计算 $\vec{EA'}$ 和 $\vec{EB'}$ 的单位向量，按 15px 长度生成正方形的四个顶点，更新 `<polygon>` 的 `points` 属性并设为可见。
- ID 命名规范：所有交互元素 ID 必须以 `scene2-` 为前缀（如 `scene2-svg`, `scene2-slider`, `scene2-vec-ae`）。
- IIFE 隔离：所有 JS 代码包裹在 `(function() { ... })()` 中。
