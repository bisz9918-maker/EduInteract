[图示主题与整合说明]
- 本图示主题：利用切线性质与直角三角形求解线段长度
- 整合的步骤/概念：题目初始状态、添加辅助线OC、标注切线垂直关系、分析Rt△OCP、分析Rt△OCD并求解目标线段
- 教学价值：教师可通过分步导航，引导学生逐步观察几何图形，从已知条件出发，通过作辅助线（半径），利用切线性质得到直角三角形，进而通过解直角三角形求出目标线段长度，逻辑清晰，符合课堂推导节奏。

[分步序列]
- 初始状态（步骤0）：显示圆O、直线段AP、切线PC、垂线段CD、所有点及字母标签、D点直角符号。高亮已知线段 OB 和 BP（蓝色），并在其下方显示下划括号及长度标注 "2"。
- 步骤1（辅助线）：点击「下一步」，出现辅助线 OC（灰色虚线），随后 OC 被高亮（蓝色），并在 OC 左侧出现长度标注 "2"。
- 步骤2（切线性质）：点击「下一步」，高亮切线 PC 和半径 OC（加粗），在 C 点处出现直角符号，并在右上角空白处（如 (480, 150)）淡入文本 "∠OCP = 90°"。
- 步骤3（解直角三角形OCP）：点击「下一步」，高亮 △OCP 区域（红色半透明），在 OP 下方出现大括号及长度标注 "4"。在 O 点处出现角度弧线及标注 "60°"。
- 步骤4（求解CD）：点击「下一步」，取消 △OCP 高亮，改为高亮 △OCD 区域（绿色半透明）。CD 线段变为绿色加粗，并在 CD 右侧出现长度标注 "√3"。

[交互方案]
- 交互类型：分步按钮导航（◀ 上一步 / 下一步 ▶）
- 控件说明：在 SVG 内部底部 (y=450~490) 居中放置两个按钮，用于控制步骤 0~4 的前后切换。
- 教师操作流程：教师首先展示原图和已知条件（步骤0），然后点击下一步引导学生作辅助线（步骤1），接着点击下一步强调切线性质得出直角（步骤2），再点击下一步在直角三角形中利用边长关系求出角度（步骤3），最后点击下一步在小直角三角形中求出目标线段（步骤4）。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。几何图形简单，SVG 易于实现精确的坐标控制、DOM 动画和高质量渲染。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
    (C点在上方，圆在左侧，P点在右侧)
    (底部留白用于放置大括号和长度标注)
  [控件栏 (y=460)]
    [◀ 上一步] [下一步 ▶]
  ```
- 关键实现要点：
  - 坐标计算：使用精确的像素坐标，C点坐标可通过 `300 + 150*cos(60°)` 和 `320 - 150*sin(60°)` 精确计算。
  - 状态机设计：定义 `currentStep` 变量（0~4），每次点击按钮更新变量并调用 `updateScene()` 函数。
  - 动画控制：通过修改 SVG 元素的 `opacity`、`stroke`、`stroke-width` 等属性实现状态切换，可配合 CSS `transition: all 0.3s ease` 实现平滑过渡。
  - 括号绘制：使用 SVG `<path>` 绘制带有贝塞尔曲线的下划大括号。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-btn-next`, `scene1-line-oc`, `scene1-area-ocp`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
