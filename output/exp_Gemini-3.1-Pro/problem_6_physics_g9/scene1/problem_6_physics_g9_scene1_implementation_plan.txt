[图示主题与整合说明]
- 本图示主题：滑动变阻器调节对电路、电磁铁磁性及受力平衡的综合影响
- 整合的步骤/概念：整合了滑动变阻器阻值变化、欧姆定律（电流变化）、电磁铁磁性强弱变化、以及铁球受力平衡分析。
- 教学价值：教师可以通过拖动滑块，直观展示“电阻增大 -> 电流减小 -> 磁性减弱 -> 磁力减小 -> 拉力减小”的完整物理因果链条，帮助学生建立多物理量联动的综合思维。

[视觉元素清单]
- 电路导线：黑色 #000000，2px实线。
- 有效电阻高亮：红色 #c62828，半透明填充于变阻器左侧。
- 电流表指针：红色 #c62828，随电流变化旋转。
- 磁感线：蓝色 #1565c0，分布在电磁铁两侧，透明度随电流变化。
- 铁球受力：
  - 重力 G：绿色 #2e7d32，长度固定。
  - 磁力 F_磁：蓝色 #1565c0，向下，长度随磁性变化。
  - 拉力 F_拉：红色 #c62828，向上，长度等于 G + F_磁。
- 弹簧测力计：包含外框、刻度线、折线弹簧和红色指针。

[分步序列]
本场景为连续拖拽交互，主要展示以下极端状态及其中间过渡：
- 初始状态（滑片在最左侧 x=260）：
  - 有效电阻最短，电流最大。
  - 电流表指针偏转角最大（45°）。
  - 磁感线最清晰（透明度1.0）。
  - 磁力 F_磁 最长（40px），拉力 F_拉 最长（80px）。
  - 弹簧伸长量最大，测力计示数最大。
- 拖动过程（滑片向右移动）：
  - 有效电阻高亮区域变长。
  - 电流表指针逆时针回转。
  - 磁感线逐渐变淡。
  - 磁力 F_磁 箭头变短，拉力 F_拉 箭头同步变短。
  - 弹簧收缩，测力计指针上移。
- 最终状态（滑片在最右侧 x=390）：
  - 有效电阻最长，电流最小。
  - 电流表指针偏转角最小（27°）。
  - 磁感线最暗（透明度0.52）。
  - 磁力 F_磁 最短（16px），拉力 F_拉 最短（56px）。
  - 弹簧伸长量最小，测力计示数最小。

[交互方案]
- 交互类型：拖拽/滑块
- 控件说明：在 SVG 底部 (y=460) 放置一个 `<input type="range">` 滑块，宽度 300px，用于模拟拖动变阻器滑片。
- 教师操作流程：教师在讲解时，缓慢向右拖动底部滑块，引导学生观察电路中电阻的变化，随后观察电流表指针、电磁铁磁感线、受力箭头长度以及测力计指针的连锁反应。

[技术实现]
- JS 库选择及原因：原生 SVG + Vanilla JS。SVG 非常适合绘制电路图和矢量箭头，且易于通过 JS 动态修改属性（长度、旋转、透明度）。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +-------------------------------------------------+
  |       [定值电阻 R]               [弹簧测力计]   |
  |  (A)                             [铁球]         |
  |       [滑动变阻器 R']            [电磁铁]       |
  |       [电源 E]--[开关 S]                        |
  |                                                 |
  |            <-- 拖动滑片调节电阻 -->             |
  +-------------------------------------------------+
  ```
- 关键实现要点：
  - 状态映射：定义变量 `t` (0到1) 绑定滑块值。
  - 坐标计算：滑片 X 坐标 `x = 260 + 130 * t`。
  - 物理量计算：电流 `I = 1 - 0.6 * t`。
  - 动画更新：通过 `requestAnimationFrame` 或直接在 `input` 事件中更新 DOM。
    - 电流表指针：`transform="rotate({15 + 30 * I}, 150, 230)"`
    - 磁感线透明度：`opacity="{0.2 + 0.8 * I}"`
    - F_磁 长度：`L_mag = 40 * I`，更新 `<line>` 的 y2。
    - F_拉 长度：`L_pull = 40 + L_mag`，更新 `<line>` 的 y2。
    - 弹簧指针：`y = 40 + L_pull`。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀，如 `scene1-slider`, `scene1-f-mag`。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
