[图示主题与整合说明]
- 本图示主题：四棱锥中线面垂直与面面垂直的推导过程
- 整合的步骤/概念：整合了底面菱形对角线互相垂直、线面垂直的性质，逐步推导线线垂直、线面垂直，最终寻找并得出使平面 MBD ⊥ 平面 PCD 的条件。
- 教学价值：几何证明的推导具有强烈的逻辑先后顺序。通过分步高亮和添加辅助线，教师可以控制节奏，引导学生在复杂的 3D 投影图形中理清垂直关系的传递逻辑，克服空间想象的困难。

[视觉元素清单]
- 基础图形：四棱锥的所有顶点和边（实线/虚线区分可见性），颜色 #000000。
- 辅助线 AC：#888888，虚线。
- 辅助线 OQ：#1565c0，虚线（用于展示异面直线垂直）。
- 红色高亮（基础垂直关系）：#c62828，线宽 3px。
- 蓝色高亮（推导垂直关系）：#1565c0，线宽 3px，平面填充 rgba(21, 101, 192, 0.2)。
- 绿色高亮（目标平面）：#2e7d32，平面填充 rgba(46, 125, 50, 0.2)。
- 直角标记：使用 SVG Path 绘制的透视平行四边形折线，颜色与当前步骤的高亮色一致。

[分步序列]
- 初始状态（步骤0）：显示四棱锥基础图形（点、实线、虚线、标签），无任何高亮和辅助线。
- 步骤1（底面对角线垂直）：显示辅助线 AC。高亮线段 AC 和 BD（红色）。显示直角标记 RA1（AC ⊥ BD）。
- 步骤2（线面垂直推线线垂直）：恢复 AC, BD 默认样式。高亮线段 PA 和 BD（红色）。显示直角标记 RA2, RA3（PA ⊥ 底面）。
- 步骤3（推导 BD ⊥ PC）：恢复 PA, BD 默认样式。显示平面 PAC（蓝色半透明）。高亮线段 PC 和 BD（蓝色）。显示辅助线 OQ 和直角标记 RA4（异面直线垂直）。
- 步骤4（目标面面垂直）：隐藏平面 PAC、辅助线 OQ 和 RA4。恢复 PC, BD 默认样式。显示平面 MBD 和平面 PCD（绿色半透明）。
- 步骤5（添加条件）：保持平面 MBD, PCD 绿色高亮。高亮线段 PC 和 DM（蓝色）。显示直角标记 RA5（DM ⊥ PC）。
- 步骤6（得出结论）：保持步骤5的视觉状态。在底部空白处显示结论文本：“结论：当 DM ⊥ PC (或 BM ⊥ PC) 时，平面 MBD ⊥ 平面 PCD”。

[交互方案]
- 交互类型：分步按钮导航。
- 控件说明：在 SVG 内部底部（y=460 区域）放置两个按钮：“◀ 上一步” 和 “下一步 ▶”。
- 教师操作流程：教师在讲解时，每讲完一个逻辑推导环节，点击“下一步”展示对应的辅助线和垂直关系高亮，引导学生逐步得出最终结论。可随时点击“上一步”回退复习。

[技术实现]
- JS 库选择及原因：原生 SVG。3D 几何图形的 2D 投影由固定坐标实现，SVG 非常适合处理多边形填充（平面）、线段样式切换以及精确的直角标记绘制。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
    (200,80) P
       |\
       | \  M (431,163)
       |  \
    D  |...\... C (620,230)
       |    \
    A (200,380)--- B (500,380)
  
  [结论文本区 y=415]
  [控件栏 y=460，居中两个按钮]
  ```
- 关键实现要点：
  1. 状态机设计：定义全局变量 `currentStep` (0~6)。
  2. 样式更新：编写 `updateState()` 函数，每次步骤切换时，先将所有元素重置为步骤0的默认样式（隐藏辅助线/平面/标记，恢复线宽和颜色），然后使用 `switch(currentStep)` 语句精确应用当前步骤需要的高亮和显示逻辑。
  3. 直角标记绘制：利用 3D 投影在 2D 上的仿射变换性质，直角标记在 2D 画布上表现为平行四边形。通过计算两条相交线段的方向向量，按比例延伸即可绘制出完美的透视直角标记。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-line-pa`, `scene1-plane-pac`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
