- 本图示主题：导体棒下滑过程的受力与运动状态动态变化

[分步序列]
- 初始状态（步骤0）：显示 3D 视图（导轨、MN、B、L、θ）和侧视图（斜面、导体棒截面、θ）。隐藏受力、速度、加速度和电流。
- 步骤1（受力分析）：侧视图中出现重力 mg、支持力 N，以及重力的两个分力 mg_x 和 mg_y，并绘制平行四边形虚线。
- 步骤2（运动与安培力）：3D 视图中出现感应电流 I 和较短的速度 v 箭头（长度30）；侧视图中出现较短的安培力 F_A 箭头（长度20）、较短的速度 v 箭头（长度30）、较长的加速度 a 箭头（长度60）。
- 步骤3（动态变化）：3D 视图中 v 箭头变长（长度60）；侧视图中 F_A 箭头变长（长度35），v 箭头变长（长度60），a 箭头变短（长度30）。
- 步骤4（最大速度）：3D 视图中 v 箭头最长（长度90，标签变为 v_m）；侧视图中 F_A 箭头长度达到与 mg_x 相等（长度50），v 箭头最长（长度90，标签变为 v_m），a 箭头消失（长度为0）。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：底部居中放置两个按钮（y=460区域），用于在步骤 0 到 4 之间切换。
- 教师操作流程：教师首先展示初始物理情境（步骤0），点击下一步进行基础受力分析（步骤1），再次点击展示运动产生的安培力及初始加速度（步骤2），接着点击展示速度增加带来的动态变化（步骤3），最后点击展示受力平衡的最大速度临界状态（步骤4）。

[技术实现]
- JS 库选择及原因：原生 SVG。因为涉及大量的矢量箭头、线段和简单的几何图形，SVG 的 DOM 操作和 CSS 属性动画（如 `transition`）非常适合实现箭头长度的平滑过渡。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  [ 左侧 3D 视图 ] [ 右侧 侧视受力分析 ]
  [      ◀上一步      下一步▶      ]
  ```
- 关键实现要点：
  - 使用 `document.createElementNS` 创建 SVG 元素。
  - 为所有动态元素（如箭头 `line` 的 `x2`, `y2` 属性，以及标签的 `x`, `y` 属性）添加 CSS `transition: all 0.5s ease`，实现长度和位置的平滑过渡。
  - 状态机设计：定义一个 `currentStep` 变量（0-4），每次点击按钮更新变量，并调用 `updateState()` 函数。
  - `updateState()` 函数根据当前步骤设置各元素的 `opacity` 和箭头的终点坐标。
  - ID 命名规范：所有元素 ID 必须以 `scene1-` 为前缀（如 `scene1-side-FA`）。
  - IIFE 隔离：所有 JS 代码包裹在 `(function() { ... })()` 中。
