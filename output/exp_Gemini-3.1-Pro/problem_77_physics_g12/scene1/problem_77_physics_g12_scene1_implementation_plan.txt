[图示主题与整合说明]
- 本图示主题：交变电压下的电场与受力变化
- 整合的步骤/概念：整合题目图1和图2，展示电压变化如何导致电场方向和粒子受力方向的周期性翻转。

[分步序列]
- 交互类型为连续拖拽滑块，无离散分步。
- 状态1 (U > 0，即 t 在 [0, 2/3) 或 [1, 5/3) 周期)：
  - 极板A显红色，极板B显蓝色。
  - 电场线箭头向下。
  - 粒子受力箭头向下，指向 (200,190)，标签 F 在 (215,190)。
- 状态2 (U < 0，即 t 在 [2/3, 1) 或 [5/3, 2] 周期)：
  - 极板A显蓝色，极板B显红色。
  - 电场线箭头向上。
  - 粒子受力箭头向上，指向 (200,110)，标签 F 在 (215,110)。

[交互方案]
- 交互类型：连续拖拽滑块。
- 控件说明：
  - 底部居中放置一个 `<input type="range">`，范围 0 到 2，步长 0.01。
  - 滑块旁显示当前时间值，如 "时间 t: 0.50 T"。
- 教师操作流程：教师拖动滑块，游标在 U-t 图上移动。当游标跨越 2T/3、T 等关键点时，上方极板颜色、电场线方向和受力箭头瞬间翻转，直观展示交变电场的特性。

[技术实现]
- JS 库选择及原因：原生 SVG。图形均为简单几何图形和折线，SVG 易于实现且支持 DOM 属性直接修改（如颜色、路径），性能良好。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  (极板与粒子区域 y:50-250)
  (U-t波形图区域 y:250-450)
  [控件栏 y:460-490]
  ```
- 关键实现要点：
  - 监听滑块 `input` 事件，获取当前 t 值。
  - 更新游标的 x 坐标：`cursor.setAttribute('x1', 200 + t * 180)`，`x2` 同理。
  - 判断电压极性：`let isPositive = (t % 1.0 < 2/3);`（注意处理浮点数精度，或直接用条件判断）。
  - 根据 `isPositive` 更新极板颜色（`fill` 属性）。
  - 更新电场线箭头方向（修改 `<path>` 的 `d` 属性，或切换不同方向的 marker）。
  - 更新受力箭头 F 的路径和标签位置。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀，如 `scene1-slider`, `scene1-plateA`, `scene1-cursor`。
- IIFE 隔离：所有 JS 代码包裹在 `(function() { ... })()` 中。
