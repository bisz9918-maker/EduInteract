[图示主题与整合说明]
- 本图示主题：纵向速度变化与电场力做功
- 整合的步骤/概念：通过运动学图像（v_y-t 和 a-t）证明不同时刻射入电场的粒子，在经过相同飞行时间 T 后，具有相同的末速度，从而证明电场力做功相等。
- 教学价值：教师可通过分步演示，先展示两个特殊时刻（t=0 和 t=2T/3）射入粒子的速度-时间图像，直观发现末速度相同；再切换到加速度-时间图像，利用面积积分的几何意义，推广到任意时刻射入的粒子，逻辑严密，化抽象为直观。

- 文本标签：所有文本使用 `stroke: white; stroke-width: 3px; paint-order: stroke;` 以防止被图线或网格线遮挡。分数使用单行形式（如 aT/3）以保证排版整洁。

[分步序列]
- 初始状态（步骤0）：显示空的坐标系，X轴标签为 t，Y轴标签为 v_y。显示原点 O。
- 步骤1（t0=0的速度）：点击「下一步」。出现蓝色 t0=0 速度线，以及对应的刻度（2aT/3, aT/3, 2T/3, T）和辅助虚线。
- 步骤2（t0=2T/3的速度）：点击「下一步」。出现红色 t0=2T/3 速度线，以及对应的刻度（-aT/3, T/3）和辅助虚线。在两线交点 (450,220) 处显示一个明显的圆点，强调末速度相同。
- 步骤3（面积积分证明）：点击「下一步」。隐藏所有 v_y-t 相关的折线、辅助线和 Y 轴特定刻度。Y轴标签切换为 a。显示 a-t 方波图像，显示刻度（a, -a, 5T/3, 2T）。高亮 0~T 周期内的正向面积（蓝色半透明）和负向面积（红色半透明）。

[标签冲突检查]
- Y轴标签（aT/3, 2aT/3, -aT/3, a, -a）统一设置 x=140, text-anchor: end，与 Y 轴 (x=150) 保持 10px 间距，绝不重叠。
- X轴标签（T/3, 2T/3, T, 5T/3, 2T）统一设置 y=305, text-anchor: middle，位于 X 轴 (y=280) 下方 25px，绝不重叠。
- Step3 中，方波的垂直虚线会穿过 2T/3 (x=350) 和 T (x=450) 的标签位置。解决方案：所有文本应用 `stroke: white; stroke-width: 3px; paint-order: stroke;`，形成白色描边保护层，确保文本在虚线上方清晰可读。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：在 SVG 底部 (y=450 区域) 居中放置两个按钮。
- 教师操作流程：教师点击“下一步”逐步展示 t=0 和 t=2T/3 粒子的速度图像，引导学生观察末速度相同的现象；最后一步切换到 a-t 图像，通过面积代数和解释其内在物理规律。

[技术实现]
- JS 库选择及原因：原生 SVG。图形均为简单的折线、矩形和文本，原生 SVG 性能好且易于实现精确的像素级控制和动画过渡。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×440]
    Y轴 (150,400)->(150,60)
    X轴 (150,280)->(780,280)
    折线图/方波图在此区域绘制
  [控件栏 800×60]
    [◀上一步] [下一步▶] (居中于 y=460)
  ```
- 关键实现要点：
  - 使用 CSS class 控制不同步骤元素的 `display` 或 `opacity` 属性，配合 `transition` 实现平滑过渡。
  - 维护一个 `currentStep` 变量 (0~3)，点击按钮时更新该变量并调用渲染函数更新视图。
  - ID 命名规范：所有元素 ID 必须以 `scene3-` 为前缀（如 `scene3-line-t0`，`scene3-btn-next`）。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
