场景导航：Scene 1 | Scene 2 | Scene 3

题目原文：
如图所示，电阻忽略不计的、两根平行的光滑金属导轨竖直放置，其上端接一阻值为3Ω的定值电阻R。在水平虚线L$_{1}$、L$_{2}$间有一与导轨所在平面垂直的匀强磁场B，磁场区域的高度为d=0.5m。导体棒a的质量m$_{a}$=0.2kg、电阻R$_{a}$=3Ω；导体棒b的质量m$_{b}$=0.1kg、电阻R$_{b}$=6Ω，它们分别从图中M、N处同时由静止开始在导轨上无摩擦向下滑动，且都能匀速穿过磁场区域，当b刚穿出磁场时a正好进入磁场。已知金属棒始终与导轨接触良好且导轨足够长，设重力加速度为g=10m/s$^{2}$。（不计a、b之间的作用）求：
（1）a、b两棒在磁场中运动的速度大小之比；
（2）b棒穿过磁场过程，电阻R上产生的焦耳热。

题目分析与整体讲解思路：
本题是一道经典的电磁感应与力学、电路综合题。核心难点有两个：一是理清两根金属棒在不同阶段的运动过程及时间上的衔接关系；二是准确画出两棒分别在磁场中运动时的等效电路图，特别容易遗漏在磁场外的另一根棒也接入了电路。

讲解思路分为三步：

  1. 运动学过程分析：通过动画演示a、b两棒的下落过程，明确b在磁场中匀速运动时，a在磁场外做自由落体运动；b刚出磁场、a刚进磁场的临界状态，从而建立两棒速度与时间的运动学关系。
  2. 等效电路与受力分析：分别针对b在磁场中和a在磁场中两种状态，画出等效电路图，利用平衡条件列出安培力与重力的关系式，进而求出速度之比。
  3. 能量转化分析：针对b穿过磁场的过程，利用能量守恒定律，将重力势能的减少量转化为电路中的总焦耳热，再结合并联电路的电流分配规律求出电阻R上的热量。

图示规划说明：

  • 图示1：利用分步导航展示双棒下落的完整物理过程，帮助学生建立直观的运动图景。
  • 图示2：利用多状态切换，对比展示b在磁场中和a在磁场中两种情况下的实物图与等效电路图，突破电路结构的认知难点。
  • 图示3：展示b在磁场中运动时的电路图，通过分布导航展示电流分配与能量转化的逻辑链条。

教学说明：
在明确了运动过程后，我们需要分别分析两棒在磁场中匀速运动时的受力和电路情况。

引导学生观察：

  1. 当b在磁场中时，b切割磁感线相当于电源，此时a在磁场外，但a依然在导轨上，因此a与定值电阻R形成并联关系。
  2. 同理，当a在磁场中时，a相当于电源，此时b在磁场下方，b与定值电阻R形成并联关系。

推导步骤：

  1. 当b在磁场中匀速运动时：等效电阻 $R_{外b} =

rac{R \cdot Ra}{R + Ra} = 1.5 \Omega$，总电阻 $R{总b} = Rb + R{外b} = 7.5 \Omega$，安培力与重力平衡 $mb g =
rac{B^2 L^2 vb}{R{总b}}$。

  1. 当a在磁场中匀速运动时：等效电阻 $R_{外a} =

rac{R \cdot Rb}{R + Rb} = 2 \Omega$，总电阻 $R{总a} = Ra + R{外a} = 5 \Omega$，安培力与重力平衡 $ma g =
rac{B^2 L^2 va}{R{总a}}$。

  1. 联立两式求速度比：$

rac{va}{vb} =
rac{ma R{总a}}{mb R{总b}} =
rac{0.2 imes 5}{0.1 imes 7.5} =
rac{4}{3}$。

教学说明：
最后，我们来计算b棒穿过磁场过程中电阻R上产生的焦耳热。

引导学生思考：b棒匀速穿过磁场，动能不变，减少的重力势能去哪了？全部转化为电路中的电能，进而转化为焦耳热。

推导步骤：

  1. 运动学参数求解：设b到达磁场时间为 $t_1$，穿过磁场时间为 $t_2$；$v_b = g t_1$，穿过磁场位移 $d = v_b t_2$；a到达磁场时速度 $va = g(t1 + t2) = vb + g t2 = vb +

rac{gd}{vb}$；代入 $va =
rac{4}{3} vb$，解得 $vb = \sqrt{3gd} = \sqrt{15} ext{ m/s}$。

  1. 能量守恒：b棒匀速运动，重力做功全部转化为总焦耳热，$Q_{总} = m_b g d = 0.1 imes 10 imes 0.5 = 0.5 ext{ J}$。
  2. 热量分配：b在磁场中时，外电路R与Ra并联，且 $R = R_a = 3 \Omega$；干路电流 $I_b$ 等分为两半，流过R的电流 $I_R =

rac{1}{2} Ib$；外电路总热量 $Q{外} = Q_{总} imes
rac{R{外b}}{R{总b}} = 0.5 imes
rac{1.5}{7.5} = 0.1 ext{ J}$；R与Ra发热相等，故 $Q_R =
rac{1}{2} Q_{外} = 0.05 ext{ J}$。

总结：
本题完整解答如下：
（1）a、b两棒在磁场中运动的速度大小之比为 $4:3$。
（2）b棒穿过磁场过程，电阻R上产生的焦耳热为 $0.05 ext{ J}$。

课堂讲解建议：

  1. 强烈建议利用图示1的动画让学生看清“b出a进”这一关键时刻两棒的空间位置，这是解题的运动学基础。
  2. 在画等效电路时，务必强调“不在磁场中的棒依然在导轨上，构成闭合回路的一部分”，图示2的对比切换能很好地强化这一认知。
  3. 能量分配计算时，先算总热量，再按电阻比例分配，比直接用公式算 $I^2 R t$ 更简便，图示3的能量流向图有助于培养这种全局能量观。
