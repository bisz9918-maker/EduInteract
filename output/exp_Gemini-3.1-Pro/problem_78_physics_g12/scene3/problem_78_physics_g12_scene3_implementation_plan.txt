[图示主题与整合说明]
- 本图示主题：b棒穿过磁场时的能量转化与热量分配
- 整合的步骤/概念：整合了重力做功转化为电能的过程，以及并联电路中的电流分配和热量分配比例。
- 教学价值：教师可以通过分步演示，清晰地向学生展示从机械能到电能再到内能的转化路径，并通过等效电路图直观推导出各支路的热量分配比例，帮助学生理清复杂的能量与电路综合计算逻辑。

[分步序列]
- 初始状态（步骤0）：显示左侧等效电路图（导线、电阻R、Ra、Rb、电池Eb），以及干路电流Ib的箭头和标签。右侧空白。
- 步骤1：点击「下一步」→ 右侧上方出现能量转化框图（重力做功 → 总热量 Q总 = 0.5J）。
- 步骤2：点击「下一步」→ 电路图中出现支路电流Ia和IR的箭头及标签，电路下方出现推导结论文本 "R = Ra = 3Ω ⇒ IR = Ia"。
- 步骤3：点击「下一步」→ 电路图中的电阻R及其标签高亮变为红色；右侧下方出现热量分配柱状图（显示80%、10%、10%的比例），以及底部最终结论文本 "QR = 10% Q总 = 0.05J"。

[交互方案]
- 交互类型：分步按钮导航。
- 控件说明：在SVG内部底部（y=450区域）放置一个绝对定位的 `div`，包含「上一步」、「下一步」、「重置」三个按钮。
- 教师操作流程：教师首先结合左侧电路图讲解b棒切割磁感线相当于电源；点击下一步，讲解重力做功全部转化为焦耳热；再次点击，分析并联电路的电流分配关系；最后点击，展示热量分配比例并得出最终电阻R的热量，完成整个逻辑链条的推导。

[技术实现]
- JS 库选择及原因：原生 SVG。本场景主要由规则的几何图形（矩形、线段）、箭头和文本组成，原生 SVG 能够完美实现精确的坐标定位和高质量的矢量渲染，且便于通过 CSS 控制透明度实现分步动画。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  +-------------------+-------------------+
  |                   |  [重力做功]       |
  |     R=3Ω          |      ↓            |
  |  +---[R]---+      |  [总热量=0.5J]    |
  |  |   <--IR |      |                   |
  |  |  Ra=3Ω  |      | |                 |
  |  +--[Ra]---+      | | 80%             |
  |  |   <--Ia |      | |___  10%  10%    |
  |  +-[Eb]-[Rb]-+    | |   | |  | |  |   |
  |       Ib-->       | +---+----+----+-- |
  |                   |  b棒  a棒  电阻R  |
  | R=Ra=3Ω => IR=Ia  | QR=10%Q总=0.05J   |
  +-------------------+-------------------+
  [控件栏：上一步 | 下一步 | 重置]
  ```
- 关键实现要点：
  1. 使用 `<g>` 标签将不同步骤的元素分组（如 `id="scene3-step1-group"`），通过 JS 控制 `opacity` 或 `display` 属性实现分步显示。
  2. 箭头可以使用 `<marker>` 定义，或者直接使用 `<path>` 绘制简单的折线箭头，以确保颜色和大小的精确控制。
  3. 文本中的下标（如 $R_a$、$Q_总$）使用 `<tspan baseline-shift="sub" font-size="0.7em">` 实现。
  4. 柱状图的绘制直接使用 `<rect>`，高度按比例计算（最大高度100px对应80%）。
- ID 命名规范：所有 DOM 元素的 ID 均以 `scene3-` 开头（如 `scene3-btn-next`, `scene3-rect-R`），避免与其他场景冲突。
- IIFE 隔离：所有 JS 逻辑封装在 `(function() { ... })()` 中。
