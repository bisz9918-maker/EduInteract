[图示主题与整合说明]
- 本图示主题：撤去拉力前后的运动过程与速度-时间图象
- 整合的步骤/概念：将木板与物块的两阶段相对运动（加速拉开、减速追赶）与 $v-t$ 图象同步结合，直观展示图象斜率代表加速度、图象包围面积代表相对位移的物理意义。
- 教学价值：教师可通过分步播放，引导学生观察拉力存在与否对两物体加速度的影响，并利用图象面积直观证明相对位移等于木板长度 $L$ 这一临界条件。

[分步序列]
- 初始状态（步骤0）：t=0。M 位于 x=100，m 位于 x=230。拉力 F 隐藏。v-t 图象仅显示坐标轴，曲线和面积隐藏。
- 步骤1（施加拉力加速）：点击「下一步」。M 平移至 x=196，m 平移至 x=262。F 出现并随 M 平移。v-t 图象中，M 曲线画至 (300,276)，m 曲线画至 (300,372)，两者之间的三角形面积（第一阶段相对位移）高亮显示。
- 步骤2（撤去拉力临界点）：点击「下一步」。模型位置不变，拉力 F 消失。图象中出现 t=0.8, v=2.4, v=0.8 的灰色虚线及对应数值标签。
- 步骤3（减速与追赶）：点击「下一步」。M 继续平移至 x=460，m 平移至 x=430（m 的右边缘刚好与 M 的左边缘对齐，表示滑落临界点）。v-t 图象中，M 曲线延伸至 (600,300)，m 曲线延伸至 (600,300)，包围的面积继续扩大。
- 步骤4（达到共速）：点击「下一步」。模型位置不变。图象中出现 t=2.0, v=2.0 的虚线及标签，标记“共速点”。显示文本“总面积 = 相对位移 L = 1.6m”。

[交互方案]
- 交互类型：分步按钮导航
- 控件说明：底部居中放置两个按钮「◀ 上一步」和「下一步 ▶」，位于 y=460~490 区域。
- 教师操作流程：教师点击「下一步」逐步演示物理过程。步骤1讲解拉力作用下的加速拉开；步骤2强调撤去拉力的临界状态；步骤3讲解撤去拉力后的减速追赶；步骤4总结共速条件与图象面积的几何意义。可随时点击「上一步」回退对比。

[技术实现]
- JS 库选择及原因：使用 D3.js (v7)。D3 的 transition 机制非常适合处理 SVG 元素的平滑动画（如矩形的 x 属性平移、path 的 d 属性形变、多边形 points 的渐变）。
- 画布尺寸：800 × 500 px。
- 布局草图：
  [物理模型动画区 800×220]
  [v-t 图象区 800×240]
  [控件栏 800×40，包含上一步/下一步按钮]
- 关键实现要点：
  1. 状态机设计：定义一个包含 5 个状态（0-4）的数组，每个状态记录 M 的 x 坐标、m 的 x 坐标、F 的透明度及偏移量、两条 path 的 d 属性字符串、area 的 points 字符串、各辅助线/标签的透明度。
  2. 动画实现：点击按钮更新当前步骤索引，使用 `d3.select().transition().duration(1000)` 将各元素过渡到新状态的属性值。
  3. Path 动画技巧：为了让折线平滑生长，初始状态的 d 属性设为 `M 100 420 L 100 420 L 100 420`，步骤1设为 `M 100 420 L 300 276 L 300 276`，步骤3设为 `M 100 420 L 300 276 L 600 300`。保持节点数量一致，D3 即可自动插值实现平滑绘制。
  4. 相对位移面积动画：同理，多边形 points 初始为四个重合点 `100,420 100,420 100,420 100,420`，随步骤逐渐展开为四边形。
- ID 命名规范：所有交互元素 ID 必须以 `scene2-` 为前缀（如 `scene2-rect-M`, `scene2-path-vM`, `scene2-btn-next`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
