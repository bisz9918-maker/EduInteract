[图示主题与整合说明]
- 本图示主题：甲物块的浮力与受力对比分析（判断选项A、B）
- 整合的步骤/概念：整合了两种情境下甲物块的排开液体体积对比、受力分析（重力、浮力、拉力/压力）以及平衡方程的建立。
- 教学价值：教师可以通过分步展示，引导学生先观察体积得出浮力相等，再分别对左右两种情况的甲物块进行受力分析，最后通过等式代换得出拉力与丙重力的关系，逻辑清晰，避免学生在复杂受力中迷失。

[视觉元素清单]
- 水体与水纹：浅蓝色 `#e3f2fd` (透明度 30%)，水纹虚线 `#888888`。
- 物块（甲、乙、丙）：黑框 `#000000`，初始白底 `#ffffff`。
- 浮力向量（F浮甲）：红色 `#c62828`，带箭头线段。
- 重力/压力向量（G甲、N）：蓝色 `#1565c0`，带箭头线段。
- 拉力向量（T）：绿色 `#2e7d32`，带箭头线段。
- 文本标签：使用原生 SVG `<text>`，方程使用 HTML `<div>` 绝对定位。

[分步序列]
- 初始状态（步骤0）：显示水体、左右物块及连接绳。物块白底，无任何受力向量和方程。
- 步骤1：左右甲物块填充色变为 `#bbdefb`（高亮浸入部分）。出现左右两边的红色 $F_{浮甲}$ 向量及标签。顶部出现文本“排开水的体积相同，$F_{浮甲}$ 相等”。
- 步骤2：左侧甲物块出现蓝色 $G_甲$ 和绿色 $T$ 向量及标签。底部左侧出现方程 $F_{浮甲} = G_甲 + T$。
- 步骤3：右侧甲物块出现蓝色 $G_甲$ 和蓝色 $N$ 向量及标签。底部右侧出现方程 $F_{浮甲} = G_甲 + G_丙$。
- 步骤4：底部中央出现最终推导方程 $T = G_丙$。同时左侧 $T$ 向量和右侧 $N$ 向量的线宽加粗（或闪烁）以强调结论。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：底部中央 (y=470) 放置两个按钮，控制步骤 0-4 的切换。
- 教师操作流程：教师点击“下一步”依次引导学生观察浮力、分析左侧受力、分析右侧受力、最后得出结论，符合课堂推导逻辑。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。图形均为简单几何体和直线箭头，原生 SVG 性能好且易于精确控制坐标和动画。
- 画布尺寸：800 × 500 px。
- 布局草图：
  [图示区 800×500]
  - 顶部 (y=50-100)：结论文本区
  - 中部 (y=100-380)：左右双栏受力图示区
  - 底部 (y=390-440)：方程推导区
  - 控件栏 (y=450-490)：SVG 内底部绝对定位的 HTML 按钮
- 关键实现要点：
  - 状态机设计：定义 `currentStep` 变量，每次点击按钮更新状态，通过 `setAttribute` 或 `style.display` 控制元素的显隐和颜色。
  - 箭头绘制：使用 SVG `<marker>` 定义箭头，方便复用。
  - 动画过渡：可为物块的 `fill` 属性和向量的 `opacity` 添加 CSS `transition` 实现平滑过渡。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-left-jia`, `scene1-btn-next`）。
- IIFE 隔离：所有 JS 代码必须包裹在 `(function() { ... })()` 中，避免全局变量污染。
