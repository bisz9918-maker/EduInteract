    题目原文：
    如图所示，A、B两物体的质量都为m，拉A物体的细线与水平方向的夹角为30°时处于静止状态，不考虑摩擦力，设弹簧的劲度系数为k．若悬线突然断开后，A在水平面上做周期为T的简谐运动，当B落地时，A恰好将弹簧压缩到最短，求：
    （1）A振动时的振幅；
    （2）B落地时的速度．

    **题目分析与整体讲解思路：**
    本题是一道经典的静力学与动力学结合的问题。解题过程可分为两个阶段：
    1. **初始静止状态**：系统处于平衡状态。通过对B和A分别进行受力分析，可以求出绳子的拉力，进而求出弹簧的初始弹力。由于细线断开后A从静止开始做简谐运动，此时弹簧的伸长量即为简谐运动的振幅。
    2. **细线断开后的运动过程**：细线断开后，A和B的运动相互独立，但通过**时间**联系在一起。A在水平方向做简谐运动，从最大正位移处（最右端）向左运动；B在竖直方向做自由落体运动。题目中“A恰好将弹簧压缩到最短”是寻找时间关系的关键点。

    **图示规划说明：**
    - **图示1**：利用分步导航，带领学生一步步完成初始状态的受力分析，直观推导出振幅的大小。
    - **图示2**：利用时间滑块，动态演示A的简谐运动和B的自由落体运动的同步过程，帮助学生建立两个独立运动之间的时间关联。
    </TEXT_1>

    **细线断开后的运动学关联：**
    细线断开后，拉力消失。
    1. **物体A**：在弹簧弹力作用下做简谐运动。释放点为最大位移处，此时速度为零。当弹簧被“压缩到最短”时，A到达另一侧的最大位移处。
       从最右端（最大伸长）到最左端（最大压缩）所需的时间为半个周期，即 $t = rac{T}{2}$。
       （注：考虑到简谐运动的周期性，一般情况为 $t = (n + rac{1}{2})T$，其中 $n = 0, 1, 2, \dots$。通常中学物理若无特别说明“第一次”，需考虑多解，但演示时以第一次为主最为直观。）
    2. **物体B**：做初速度为零的自由落体运动。
       下落时间与A运动时间相同，即 $t$。
    
    本图示通过滑块控制时间，让学生直观看到两个不同性质的运动是如何在同一时间轴上同步进行的。

    **总结与课堂讲解建议：**
    1. **振幅的求解**：
       根据受力平衡求出弹簧初始拉力 $F_k = rac{\sqrt{3}}{2}mg$。
       由胡克定律得初始伸长量 $x_0 = rac{\sqrt{3}mg}{2k}$。
       故振幅 $A = rac{\sqrt{3}mg}{2k}$。

    2. **落地速度的求解**：
       A压缩到最短所需时间 $t = (n + rac{1}{2})T$，其中 $n = 0, 1, 2, \dots$
       B做自由落体运动，落地速度 $v = gt = rac{(2n+1)gT}{2}$。
    
    **教学提醒**：在讲解第二问时，务必引导学生思考简谐运动的**周期性**。虽然图示中为了直观只演示了第一次压缩到最短的情况 ($n=0$)，但数学表达上必须包含所有可能的情况。可以提问：“如果B下落得足够高，A有没有可能往复运动多次后，B才落地？”以此引出多解的讨论。
