场景导航：Scene 1 | Scene 2

题目：
如图所示，质量分别为3m、2m、m的三个小球A、B、C用两根长为L的轻绳相连，置于倾角为30°、高为L的固定光滑斜面上，A球恰能从斜面顶端外竖直落下，弧形挡板使小球只能竖直向下运动，碰撞过程中没有动能损失，小球落地后均不再反弹．由静止开始释放它们，不计所有摩擦，求：
（1）A球刚要落地时的速度大小
（2）C球刚要落地时的速度大小．
（3）在B球运动过程中，两绳对B球做的总功为多少．

题目分析：
本题考查连接体系统在多阶段运动中的机械能守恒定律及动能定理的应用。由于不计摩擦且碰撞无动能损失，系统在不同阶段满足机械能守恒。

整体讲解思路：

  1. 分析系统的三个运动阶段：A下落、B下落、C下落。利用位移关系确定各小球的高度变化。
  2. 针对每个阶段，明确参与运动的系统成员，利用机械能守恒定律求解末速度。
  3. 针对B球，利用动能定理求解变力（绳子拉力）做的总功，避免复杂的受力分析。

图示规划说明：

  • 图示1：通过分步动画演示系统的三个运动阶段，直观展示各小球的位移关系，辅助列出机械能守恒方程。
  • 图示2：聚焦B球的初末状态，通过高度差和末速度，引导使用动能定理求解绳子做功。

本图示用于讲解第一问和第二问，重点引导学生观察每个阶段中“哪些球在运动”以及“它们的高度变化”。

讲解要点与推导步骤：

  1. 第一阶段（A落地前）：A、B、C共同运动，位移均为 $L$。
  • A高度下降 $L$，B、C高度均上升 $L \sin 30^\circ = 0.5L$。
  • 系统机械能守恒：$mA gL - mB g(0.5L) - m_C g(0.5L) =

rac{1}{2}(mA + mB + mC)vA^2$

  • 代入质量：$3mgL - 2mg(0.5L) - mg(0.5L) =

rac{1}{2}(6m)v_A^2$

  • 解得 A球刚要落地时的速度：$v_A = \sqrt{

rac{gL}{2}}$

  1. 第二阶段（A落地后至B落地前）：A静止，B、C共同运动，位移均为 $L$。
  • B高度下降 $L$，C高度上升 $L \sin 30^\circ = 0.5L$。
  • B、C系统机械能守恒：$mB gL - mC g(0.5L) =

rac{1}{2}(mB + mC)v_B^2 -
rac{1}{2}(mB + mC)v_A^2$

  • 代入质量与 $v_A$：$2mgL - 0.5mgL =

rac{1}{2}(3m)v_B^2 -
rac{1}{2}(3m)(
rac{gL}{2})$

  • 解得 B球刚要落地时的速度：$v_B = \sqrt{

rac{3gL}{2}}$

  1. 第三阶段（B落地后至C落地前）：A、B静止，C单独下落，位移为 $L$。
  • C高度下降 $L$。
  • C球机械能守恒：$m_C gL =

rac{1}{2}mC vC^2 -
rac{1}{2}mC vB^2$

  • 代入质量与 $v_B$：$mgL =

rac{1}{2}m v_C^2 -
rac{1}{2}m(
rac{3gL}{2})$

  • 解得 C球刚要落地时的速度：$v_C = \sqrt{

rac{7gL}{2}}$

本图示用于讲解第三问，引导学生跳出复杂的受力过程，运用动能定理从全局视角求解变力做功。

讲解要点与推导步骤：

  1. 受力复杂性：在B球运动过程中，绳子的拉力 $T_{AB}$ 和 $T_{BC}$ 是变化的，且方向也在改变，直接用功的定义式 $W=Fs$ 求解非常困难。
  2. 动能定理应用：考察B球从静止释放到刚要落地的全过程。
  • 初末状态：初速度为 $0$，末速度为 $v_B = \sqrt{

rac{3gL}{2}}$。

  • 重力做功：B球初始位于斜面中点，高度为 $L \sin 30^\circ = 0.5L$；最终落至地面，高度为 $0$。重力做正功 $W_G = m_B g (0.5L) = 2mg imes 0.5L = mgL$。
  • 动能变化：$\Delta E_k =

rac{1}{2}mB vB^2 - 0 =
rac{1}{2}(2m)(
rac{3gL}{2}) = 1.5mgL$。

  1. 求解绳子总功：
  • 根据动能定理：$W_{总} = W_G + W_{绳} = \Delta E_k$
  • 代入数据：$mgL + W_{绳} = 1.5mgL$
  • 解得两绳对B球做的总功：$W_{绳} = 0.5mgL$

总结：本题通过巧妙的物理过程拆解，将复杂的连接体问题转化为分阶段的机械能守恒问题。在求解变力做功时，动能定理展现了其关注初末状态、化繁为简的强大优势。课堂上建议教师多引导学生观察各阶段的“不变量”（如系统机械能）和“几何约束”（如位移关系）。
