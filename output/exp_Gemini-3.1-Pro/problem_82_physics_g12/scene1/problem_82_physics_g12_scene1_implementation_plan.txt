- 本图示主题：系统多阶段运动过程与速度求解
- 整合的步骤/概念：展示系统从初始状态到A、B、C三球依次落地的四个关键节点，清晰呈现各阶段的位移关系与系统状态，辅助讲解机械能守恒定律在多阶段过程中的应用。

[视觉元素清单]

[标签冲突检查]
- "2L"文本(330,180) vs C球S1(377,236)：间距>50px，无冲突。
- "L"文本(645,243) vs A球S3(610,336)：间距>90px，无冲突。
- 速度矢量(525,280-320) vs 竖直轨道(550,136-350)：间距25px，无冲突。
- 质量标签(3m, 2m, m)：置于球体内部（白字），彻底消除与外部元素的冲突。
- 落地后球体堆叠：通过在落地后将先落地的球向右平移30px（A到580、610，B到580），完美避免球体和标签重叠。
- 标签"A","B","C"在落地后统一置于球体正下方(y=365)，处于地面(y=350)下方的空白区域，互不干扰。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 底部居中放置两个按钮，位置在 y=460 附近。
  - 按钮样式：简洁的现代风格，禁用状态置灰。
- 教师操作流程：
  1. 初始展示题目物理情景，讲解几何关系（2L, L, 30°）。
  2. 点击“下一步”，演示A球落地过程，引导学生列出系统机械能守恒方程求解v_A。
  3. 再次点击“下一步”，演示绳AB松弛，B、C系统继续运动至B落地，求解v_B。
  4. 最后点击“下一步”，演示绳BC松弛，C球自由落体至落地，求解v_C。
  5. 可随时点击“上一步”回退，对比不同阶段的系统状态。

[技术实现]
- JS 库选择及原因：原生 SVG + Vanilla JS。物理过程主要为直线运动和简单的状态切换，原生 SVG 的 `<path>` 和 `<circle>` 配合 CSS `transition` 即可实现极其流畅的动画，无需引入重型库。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```text
  +--------------------------------------------------+
  |                                                  |
  |         2L                 (挡板)                |
  |        /                     \                   |
  |       /                       A(3m) - - - - -    |
  |      /                        |               |  |
  |     B(2m)                     |               L  |
  |    /                          |               |  |
  |   /                           |               |  |
  |  C(m) 30°                     v               |  |
  |-----------------------------------------------|--|
  |                                                  |
  |             [◀ 上一步]  [下一步 ▶]               |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  - 状态机设计：定义 `step = 0, 1, 2, 3`，每次点击按钮更新 `step` 并调用 `updateScene()`。
  - 动画实现：为所有动态元素的 `cx`, `cy`, `d`, `opacity`, `transform` 属性添加 CSS `transition: all 0.6s ease-in-out`。
  - 绳索形变：绳索统一使用 `<path>`，直线状态使用 `M x1 y1 Q (x1+x2)/2 (y1+y2)/2 x2 y2`，松弛状态改变控制点坐标，利用 CSS 自动补间实现平滑弯曲动画。
  - 文本跟随：将球体和其内部文字放入同一个 `<g>` 标签中一起移动，外部标签"A","B","C"单独使用 `<text>` 并通过 JS 同步更新坐标。
- ID 命名规范：所有交互元素和动态图形 ID 必须以 `scene1-` 为前缀（如 `scene1-ball-a`, `scene1-btn-next`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
