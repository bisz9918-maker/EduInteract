[分步序列]
- 初始状态（状态1：受力分析法）：
  - 显示斜面、轨道、地面。
  - 显示B球在斜面初态(292,280)和竖直轨道中间态(500,280)。
  - 显示初态受力：T_AB、T_BC、2mg。
  - 显示中间态受力：T_BC、2mg。
  - 右上角文本提示：“受力分析法：绳子拉力为变力，直接求功困难”。
- 状态2（动能定理法）：
  - 隐藏所有受力箭头和中间态B球。
  - 初态B球变为半透明（opacity: 0.3），显示标签“v=0”。
  - 显示末态B球在地面(500,385)，实心。
  - 显示高度辅助线及“0.5L”标注。
  - 显示末态速度矢量“v_B”。
  - 右上角文本提示：“动能定理法：W_G + W_绳 = ΔE_k，W_G = 2mg × 0.5L”。

[交互方案]
- 交互类型：多状态切换（2个按钮）
- 控件说明：在SVG底部（y=460）居中放置两个按钮：“受力分析法”、“动能定理法”。
- 教师操作流程：教师首先展示状态1，引导学生发现受力复杂、变力做功难求；然后点击“动能定理法”按钮切换到状态2，展示只需关注初末状态和高度差，从而顺利列出动能定理方程。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。图形简单，SVG 易于实现精确坐标控制和矢量箭头绘制。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×450]
  [控件栏 800×50 (y=450~500)]
  ```
- 关键实现要点：
  - 使用 `<g>` 标签将状态1和状态2的特有元素分别编组，通过切换 `display` 或 `opacity` 属性实现状态切换。
  - 预定义 SVG `<defs>` 中的箭头 marker（红色、绿色、灰色），方便复用。
  - ID 命名规范：所有元素 ID 以 `scene2-` 为前缀（如 `scene2-btn-state1`, `scene2-group-state2`）。
  - IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
