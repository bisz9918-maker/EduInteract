[图示主题与整合说明]
- 本图示主题：子弹击打滑块及弹簧压缩全过程动态演示
- 整合的步骤/概念：整合了系统的初始运动状态、子弹射入滑块的完全非弹性碰撞过程、以及小车与滑块发生相对滑动并压缩弹簧的过程。
- 教学价值：教师可通过分步导航，精准控制讲解节奏，逐步剖析每个阶段的受力情况（如摩擦力方向）、速度变化（碰撞前后的突变）及能量转化（相对位移与弹性势能的关系），帮助学生建立清晰的物理过程图像。

[分步序列]
- 初始状态（步骤0）：展示小车(x=150)、滑块(x=380)、弹簧处于原长。显示速度向量 v1(车)、v1(滑块) 向右，v0(子弹) 向左。
- 步骤1（子弹击中滑块）：点击「下一步」。子弹射入滑块并留在其中（外部子弹隐藏，滑块内显示子弹）。滑块速度向量更新为 v2（向右），小车速度仍显示为 v1。
- 步骤2（弹簧压缩）：点击「下一步」。小车向右移动至 x=250，滑块向右移动至 x=450。小车速度大于滑块，弹簧被压缩。接触面出现红色摩擦力标识（滑块受向右的 f，小车受向左的 f'）。
- 步骤3（共速与锁定）：点击「下一步」。小车向右移动至 x=350，滑块向右移动至 x=510。系统达到共同速度 v3。高亮显示相对位移 d（通过灰色虚线对比滑块当前位置与未压缩时的理论位置）。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：在 SVG 内底部（y=450~490）居中放置三个元素：上一步按钮、状态指示文本（如"步骤 0 / 3"）、下一步按钮。
- 教师操作流程：
  1. 初始展示步骤0，讲解系统初始状态。
  2. 点击"下一步"进入步骤1，演示子弹瞬间击中滑块的完全非弹性碰撞，速度突变。
  3. 点击"下一步"进入步骤2，演示小车速度大于滑块，弹簧开始压缩，并指出摩擦力方向。
  4. 点击"下一步"进入步骤3，演示达到共速，弹簧压缩量为d，讲解能量守恒。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。SVG 非常适合绘制几何图形和物理模型，且易于通过 DOM 操作实现平滑动画。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  [控件栏（y=450~490，包含上一步/下一步按钮，绝对定位叠在SVG上）]
  ```
- 关键实现要点：
  - 状态机设计：定义 4 个状态的配置对象（包含小车x坐标、滑块x坐标、各元素透明度等）。
  - 动画实现：使用 `requestAnimationFrame` 实现状态间的平滑过渡（插值计算），每次更新坐标和透明度，并重绘弹簧路径。
  - 弹簧绘制：编写 `drawSpring(x1, x2, y, coils)` 函数，根据两端点坐标动态生成 zigzag 路径的 `d` 属性。
  - 坐标系：所有运动元素（小车、滑块）使用 `<g>` 分组，通过 `transform="translate(x, 0)"` 移动，组内元素使用相对坐标，极大简化坐标计算。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-cart`, `scene1-btn-next`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
