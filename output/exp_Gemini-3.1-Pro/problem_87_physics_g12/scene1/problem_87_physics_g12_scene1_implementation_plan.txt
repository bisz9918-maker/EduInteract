[视觉元素清单]

- 距离标注：平行于斜面的黑色括号及标签 L。
- 矢量箭头：

  - 电场力及分力：#1565c0（蓝色），实线为主力，虚线为分力。
  - 库仑力：#c62828（红色），实线。
  - 合力：#ff8f00（橙色），加粗实线。

[分步序列]
- 初始状态（步骤0）：显示斜面、电场线、A球、B球、L标注。文本区显示：“初始状态：A球静止，B球固定”。
- 步骤1：点击「下一步」→ 高亮A球。出现A球的重力mg、分力mg sin 37°，电场力F_E、分力qE cos 37°。文本区显示：“A球受重力与电场力，均有沿斜面向下的分力”。
- 步骤2：点击「下一步」→ 出现A球受到的库仑力F_c（沿斜面向上）。文本区显示：“A球静止，必受B球沿斜面向上的库仑斥力
结论：B球带负电
平衡方程：F_c = mg sin 37° + qE cos 37°”。
- 步骤3：点击「下一步」→ 淡化A球的受力。高亮B球。出现B球受到的三个力（平行错开显示以防重叠）：mg sin 37°、qE cos 37°、F_c'。文本区显示：“释放B球瞬间，B球受三个沿斜面向下的力
(重力分力、电场力分力、A对B的库仑斥力)”。
- 步骤4：点击「下一步」→ B球的三个力通过动画首尾相接（矢量叠加），随后出现橙色大箭头 F_合 覆盖它们。文本区显示：“B球合力：F_合 = mg sin 37° + qE cos 37° + F_c'
由于 F_c' = F_c
所以 F_合 = 2F_c
加速度 a = 2kq² / (mL²)”。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。SVG 极其适合绘制带箭头的矢量线段、处理精确坐标和实现平滑的 CSS `transform` 动画（用于步骤4的矢量首尾相接拼接）。
- 画布尺寸：800 × 500 px。
- 布局草图：
  [图示区 800×450]
  - 左上角：推导文本区
  - 中部/右侧：斜面及受力分析图
  [控件栏 800×50 (y=450-500)]
  - 居中：◀上一步 | 下一步▶
- 关键实现要点：
  - 状态机：定义 `currentStep` (0-4)，每次步骤切换时更新各 SVG 元素的 `opacity` 和 `transform` 属性。
  - 坐标计算：严格按照布局坐标表中的像素值绘制 `<line>` 和 `<path>`（用于箭头）。
  - 动画设计：步骤4中，B球的三个力原本是平行错开的，通过修改其 `x1, y1, x2, y2` 或应用 `transform: translate(...)`，使其在 0.5 秒内平滑移动到首尾相接的位置，然后再淡入 `F_合` 箭头。
  - ID 命名规范：所有元素 ID 必须以 `scene1-` 为前缀（如 `scene1-btn-next`, `scene1-vector-mg`）。
  - 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
