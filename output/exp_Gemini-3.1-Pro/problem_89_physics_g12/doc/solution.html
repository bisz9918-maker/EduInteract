problem_89_physics_g12

场景导航：Scene 1

题目：如图所示，在直角坐标系xoy中，虚线ab将第一象限分成两块区域，左边区域匀强电场沿x轴正方向，电场强度E$_{1}$，右边区域匀强电场方向沿y轴负方向，电场强度E$_{2}$。现一个质量为m（重力忽略不计），电荷量为q的正粒子静止放在y轴上的P（0，h）点，粒子在电场力的作用下运动，最后从x轴上的Q点离开电场区域，已知虚线ab距y轴的距离L，求：
（1）粒子穿过E$_{1}$电场区域的速度；
（2）粒子经过Q点的速度大小；
（3）Q点的坐标。

题目分析与整体讲解思路：
本题考查带电粒子在组合电场中的运动。整个物理过程可分为两个阶段：

  1. 第一阶段（在 $E_1$ 区域中）：粒子由静止开始，在水平向右的匀强电场中做匀加速直线运动。可通过运动学公式或动能定理求出到达边界线 $ab$ 时的速度。
  2. 第二阶段（在 $E_2$ 区域中）：粒子以第一阶段的末速度作为初速度，垂直进入竖直向下的匀强电场，做类平抛运动。利用运动的合成与分解，将运动分解为水平方向的匀速直线运动和竖直方向的初速度为零的匀加速直线运动，从而求出运动时间、水平位移以及落地时的速度。

图示规划说明：
规划一个完整的交互式图示，通过分步动画演示粒子的运动轨迹。先展示第一阶段的直线加速，再展示第二阶段的类平抛运动，并在关键节点（边界处、落地点Q）高亮速度矢量和位移关系，帮助学生直观理解分段运动的特征及运动的独立性。

教学讲解要点与推导过程：

1. 粒子穿过 $E_1$ 电场区域的速度
引导学生观察步骤1。粒子在 $E_1$ 区域仅受水平向右的电场力，做初速度为零的匀加速直线运动。
应用动能定理：
$qE_1 L =
rac{1}{2}mv_1^2 - 0$
解得：
$v_1 = \sqrt{
rac{2qE_1 L}{m}}$

2. 粒子经过 Q 点的速度大小
引导学生观察全过程（或直接使用动能定理）。粒子从 P 到 Q 的整个过程中，电场力 $E_1$ 和 $E_2$ 都做正功。
对全过程应用动能定理：
$qE1 L + qE2 h =
rac{1}{2}mv_Q^2 - 0$
解得：
$v_Q = \sqrt{
rac{2q(E1 L + E2 h)}{m}}$
(注：也可在讲解完第3问后，通过 $v_Q = \sqrt{v_x^2 + v_y^2}$ 进行合成验证)

3. Q 点的坐标
引导学生观察步骤2。粒子进入 $E_2$ 区域后，做类平抛运动。

  • 竖直方向：做初速度为零的匀加速直线运动。

加速度 $a_y =
rac{qE_2}{m}$
竖直位移 $h =
rac{1}{2}a_y t^2$
解得运动时间 $t = \sqrt{
rac{2hm}{qE_2}}$

  • 水平方向：做匀速直线运动。

在 $E_2$ 区域的水平位移 $\Delta x = v_1 t = \sqrt{
rac{2qE_1 L}{m}} \cdot \sqrt{
rac{2hm}{qE_2}} = 2\sqrt{
rac{E1 L h}{E2}}$

  • 坐标计算：

Q点的横坐标 $x_Q = L + \Delta x = L + 2\sqrt{
rac{E1 L h}{E2}}$
因此，Q点的坐标为 $(L + 2\sqrt{
rac{E1 L h}{E2}}, 0)$
