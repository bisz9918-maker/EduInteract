[图示主题与整合说明]
- 本图示主题：带电粒子在组合电场中的分段运动过程
- 整合的步骤/概念：整合了粒子在第一区域的匀加速直线运动、在第二区域的类平抛运动，以及最终速度和位移的矢量关系。
- 教学价值：教师可以通过分步演示，清晰地向学生展示粒子在不同电场区域的受力情况和运动轨迹，帮助学生将复杂的组合运动分解为简单的直线运动和类平抛运动，并直观理解速度的矢量合成。

[分步序列]
- 初始状态（步骤0）：显示坐标系、边界线ab、E1和E2电场线、P点、h标注、L标注。粒子静止在P点。隐藏所有轨迹、速度矢量和Δx标注。
- 步骤1（第一阶段）：点击「下一步」。E1电场线高亮（加粗或透明度增加）。粒子从P点匀加速运动到边界点(300,150)，同时绘制轨迹1。到达边界后，显示速度矢量v1。
- 步骤2（第二阶段）：点击「下一步」。E1恢复正常，E2电场线高亮。粒子从边界点做类平抛运动到达Q点，同时绘制轨迹2（抛物线）。
- 步骤3（终点状态）：点击「下一步」。E2恢复正常。在Q点显示速度vQ及其分量vx, vy，并画出辅助平行四边形。同时在下方显示Δx标注。

[交互方案]
- 交互类型：分步按钮导航
- 控件说明：底部居中放置两个按钮：「◀ 上一步」和「下一步 ▶」。
- 教师操作流程：
  1. 初始画面介绍题目背景、坐标系和两个电场区域。
  2. 点击「下一步」，演示粒子在E1中的加速过程，强调水平电场力做正功，获得水平速度v1。
  3. 点击「下一步」，演示粒子在E2中的类平抛过程，强调竖直电场力导致竖直方向加速，水平方向匀速。
  4. 点击「下一步」，展示最终到达Q点时的速度合成，以及水平总位移的构成（L + Δx），辅助讲解相关公式。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript。SVG 非常适合绘制精确的几何图形、矢量和抛物线（使用二次贝塞尔曲线 Q），且易于通过 CSS 和 JS 控制动画和状态。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  +------------------------------------------------+
  | y                                              |
  | ^               a                              |
  | |               |                              |
  | |    E1(蓝)     |      E2(绿)                  |
  | |  -------->    |      |  |  |                 |
  | P.==============>v1    v  v  v                 |
  | |               |       .                      |
  | |h              |        .                     |
  | |               |         .                    |
  | |               |          . Q   vx            |
  | O---------------+-----------.-----> x          |
  |                 b           |   /              |
  |    <--- L --->  | <- Δx ->  v  v               |
  |                             vy vQ              |
  |                                                |
  |           [◀ 上一步] [下一步 ▶]                |
  +------------------------------------------------+
  ```
- 关键实现要点：
  - 抛物线轨迹使用 SVG path: `<path d="M 300 150 Q 450 150 600 350" .../>`。
  - 动画实现：使用 CSS `stroke-dasharray` 和 `stroke-dashoffset` 配合 `transition` 实现轨迹的绘制动画。粒子的移动可以通过 JS `requestAnimationFrame` 计算当前进度，或者简单地使用 Web Animations API 沿路径移动。为保证兼容性和简单性，可直接在 JS 中根据时间 t (0到1) 计算粒子坐标：
    - 阶段1: `x = 100 + 200*t`, `y = 150`
    - 阶段2: `x = 300 + 300*t`, `y = 150 + 200*t*t`
  - 状态机：定义 `currentStep` (0-3)，每次点击按钮更新状态。向前切换时触发动画，向后切换时直接瞬间恢复到对应状态的初始样式，避免复杂的反向动画逻辑。
  - 箭头标记：使用 `<defs><marker>` 定义不同颜色和方向的箭头，方便在 `<line>` 和 `<path>` 中复用 (`marker-end="url(#...)"`)。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀，例如 `scene1-btn-next`, `scene1-particle`, `scene1-path1`。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中，避免全局变量污染。
