[图示主题与整合说明]
- 本图示主题：整体与隔离法结合求解带电小球系统的电荷量与外力
- 整合的步骤/概念：整合了系统整体的加速度方向分析、小球A的受力分析（正交分解）、以及整体法的受力分析。
- 教学价值：教师可通过分步导航，清晰地展示从“整体运动状态”到“个体受力分析（定性+定量）”再到“整体受力求外力”的完整物理思维过程，避免一次性展示过多信息导致学生认知超载。

[视觉元素清单]
- 几何图形：小球A、B、C（带填充和描边），等边三角形辅助线，整体边界框。
- 矢量箭头：加速度a，外力F，库仑力F_BA、F_CA，分力F_CAx、F_CAy。
- 文本标签：A, B, C, +q, -Q, r, a, F, F_BA, F_CA, F_CAx, F_CAy, F=3ma。
- 颜色/样式：
  - 背景：#ffffff
  - 辅助线：#888888 虚线
  - 正电荷（A、B）：边框 #c62828 实线，填充 rgba(198, 40, 40, 0.3)
  - 负电荷（C）：边框 #1565c0 实线，填充 rgba(21, 101, 192, 0.3)
  - 力矢量（F_BA, F_CA, F）：#000000 实线箭头

  - 整体边界框：#888888 粗虚线，带圆角 rx=20
  - 高亮状态：A球边框加粗（stroke-width: 3），B、C球透明度降低（opacity: 0.3）。

[分步序列]
- 初始状态（步骤0）：显示小球A、B、C，辅助线及r，A和B的+q标签，C的外力F，整体加速度a。隐藏其他受力分析和整体框。
- 步骤1：点击「下一步」→ 高亮小球A，降低B、C透明度。显示F_BA（向上）和F_CA（指向C），显示C的-Q标签。
- 步骤2：点击「下一步」→ 在步骤1基础上，显示F_CA的正交分力F_CAx和F_CAy。
- 步骤3：点击「下一步」→ 取消A的高亮，恢复B、C透明度。隐藏F_BA, F_CA, F_CAx, F_CAy。显示整体边界框，并在下方显示结论文本 "F = 3ma"。

[交互方案]
- 交互类型：分步按钮导航
- 控件说明：在SVG底部（y=460）居中放置两个按钮「◀ 上一步」和「下一步 ▶」，中间显示当前步骤「步骤 0 / 3」。
- 教师操作流程：教师首先介绍题目初始条件（步骤0）；点击下一步，引导学生隔离A球定性分析受力，得出C带负电（步骤1）；再次点击，进行定量正交分解（步骤2）；最后点击，使用整体法求出外力F（步骤3）。

[技术实现]
- JS 库选择：原生 SVG。由于全是基础几何图形、直线箭头和文本，原生 SVG 配合 DOM 操作最轻量且清晰。
- 画布尺寸：800 × 500 px。
- 布局草图：
  [图示区 800×450]
  [控件栏 800×50，包含 上一步、步骤指示、下一步]
- 关键实现要点：
  - 使用 `<defs>` 定义箭头 marker，方便复用。
  - 将不同步骤的元素分组放入 `<g>` 标签，通过控制 `display` 或 `opacity` 属性实现步骤切换。
  - 状态机设计：定义 `currentStep` 变量（0~3），每次点击按钮更新变量并调用 `updateScene()` 函数，该函数根据当前步骤设置各元素的可见性和样式。
  - ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀，例如 `scene1-ball-a`, `scene1-force-fba`。
  - IIFE 隔离：所有 JS 代码包裹在 `(function() { ... })()` 中。
