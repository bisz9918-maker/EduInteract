[图示主题与整合说明]
- 本图示主题：寻找图1中的相似三角形
- 整合的步骤/概念：利用等边三角形的角相等推导平行线，进而找出两对相似三角形
- 教学价值：教师可以通过分步导航，逐步引导学生观察相等的角，推导出平行线，最后识别出相似三角形，帮助学生理清复杂的几何证明逻辑。

[分步序列]
- 初始状态（步骤0）：显示基础图形和所有点、标签。隐藏所有高亮元素。
- 步骤1：点击「下一步」→ 显示扇形 ∠ACD 和 ∠CBE，线段 DC 和 BE 加粗并变为蓝色（#1565c0），得出 DC || BE。
- 步骤2：点击「下一步」→ 隐藏扇形，保持线段 DC 和 BE 蓝色加粗，显示多边形 △ACG 和 △ABF，得出第一对相似三角形。
- 步骤3：点击「下一步」→ 隐藏步骤2的高亮，恢复 DC 和 BE 原样。显示扇形 ∠DAC 和 ∠ECB，线段 AD 和 CE 加粗并变为红色（#c62828），得出 AD || CE。
- 步骤4：点击「下一步」→ 隐藏扇形，保持线段 AD 和 CE 红色加粗，显示多边形 △ADG 和 △CHG，得出第二对相似三角形。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：底部居中放置两个按钮「上一步」和「下一步」。
- 教师操作流程：教师在讲解时，点击「下一步」逐步展示平行的推导和相似三角形的识别，配合高亮颜色引导学生视线。可随时点击「上一步」回退复习。

[技术实现]
- JS 库选择及原因：原生 SVG。几何图形简单，SVG 的 DOM 结构便于直接通过 JS 修改属性（如 stroke、fill、opacity）来实现状态切换。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×450]
    (包含几何图形和高亮多边形)
  [控件栏 800×50]
    (上一步) (下一步)
  ```
- 关键实现要点：
  - 使用 path 绘制扇形，利用 SVG 的 A 指令（Arc）。
  - 维护一个全局变量 currentStep (0-4)。
  - 编写 updateState() 函数，根据 currentStep 的值，设置各高亮元素的 display 或 opacity，以及线段的 stroke 和 stroke-width。
  - 按钮点击事件中更新 currentStep 并调用 updateState()，同时更新按钮的禁用状态（步骤0禁用上一步，步骤4禁用下一步）。
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀，如 scene1-btn-prev, scene1-arc-acd, scene1-line-dc 等。
- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中。
