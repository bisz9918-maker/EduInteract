[图示主题与整合说明]
- 本图示主题：当动点 C 位于线段 AB 中点时的线段及比例计算
- 整合的步骤/概念：证明 $	riangle DCE$ 为等边三角形，作辅助线 CP 并求其长度，利用 $	riangle ACG \sim 	riangle ABF$ 和 $	riangle ADG \sim 	riangle CHG$ 两次相似三角形的性质，推导出线段比例 AG:GH:HF = 3:1:2。
- 教学价值：教师可通过分步导航，引导学生逐步拆解复杂的几何图形，理清从局部等边三角形到全局相似三角形的推导逻辑，避免学生面对复杂图形时产生畏难情绪。

[视觉元素清单]

[分步序列]
- 初始状态（步骤0）：显示基础图形（不含 CP），显示点 A~H, P 及其标签，显示 AC=4, CB=4。文本区显示初始条件。
- 步骤1：点击「下一步」→ 高亮 $	riangle DCE$（多边形 D-C-E，蓝色 #1565c0 填充及加粗边框）。文本区更新，推导 $	riangle DCE$ 为等边三角形。
- 步骤2：点击「下一步」→ 清除步骤1高亮。显示辅助线 CP（蓝色虚线）、垂直符号及长度标注 $2\sqrt{3}$。文本区更新，计算 CP 长度。
- 步骤3：点击「下一步」→ 保持 CP 显示（可转为细灰线或保持原样）。高亮 $	riangle ACG$ 和 $	riangle ABF$（红色 #c62828 填充及加粗边框）。显示长度标注 CG=1。文本区更新，推导 AG=GF 且 CG=1。
- 步骤4：点击「下一步」→ 清除步骤3高亮。高亮 $	riangle ADG$ 和 $	riangle CHG$（红色 #c62828 填充及加粗边框）。显示长度标注 DG=3。文本区更新，推导 AG=3GH。
- 步骤5：点击「下一步」→ 清除步骤4高亮。加粗并分别着色线段 AG（红色 #c62828）、GH（蓝色 #1565c0）、HF（绿色 #2e7d32）。文本区更新，综合得出 AG:GH:HF = 3:1:2。

[交互方案]
- 交互类型：分步按钮导航（◀ 上一步 / 下一步 ▶）。
- 控件说明：在 SVG 底部 (y=450~490) 放置一个绝对定位的 div，包含两个按钮和一个状态指示器（如 "步骤 1 / 5"）。
- 教师操作流程：教师点击“下一步”逐步展示推导过程，配合右侧文本区的数学公式进行讲解。可随时点击“上一步”回退。

[技术实现]
- JS 库选择及原因：原生 SVG 配合原生 JS。图形由直线和多边形组成，SVG 的 DOM 结构非常适合通过 JS 控制元素的 `display`、`stroke` 和 `fill` 属性来实现分步动画。文本区使用 MathJax 渲染数学公式。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800x500]
    (150,380) A ---------------- C(350,380) ---------------- B(550,380)
               \                / \                /
                \              /   \              /
                 \            /     \            /
                  D(250,207)---P---E(450,207)
    + 结论文本区 (580, 150) 宽200px
  [控件栏 800x40, y=450~490]
    [◀ 上一步]  [ 步骤 0 / 5 ]  [下一步 ▶]
  ```
- 关键实现要点：
  1. 状态机设计：定义 `currentStep` 变量（0~5）。编写 `updateScene()` 函数，根据 `currentStep` 的值，控制各个 SVG 元素（高亮多边形、辅助线、长度标签）的 `display` 属性，以及右侧文本区对应步骤 div 的显示/隐藏。
  2. 文本区预渲染：右侧文本区的 6 个步骤内容（包含 MathJax 公式）在 HTML 中预先写好，分别包裹在 `id="scene2-text-stepX"` 的 div 中，通过 JS 切换 `display: block/none`，避免 MathJax 动态渲染带来的闪烁和延迟。
  3. 坐标精确性：严格按照布局坐标表中的数值绘制 SVG 元素，确保图形比例与原题一致。
- ID 命名规范：所有交互元素和需要 JS 控制的元素 ID 必须以 `scene2-` 为前缀（如 `scene2-poly-dce`, `scene2-line-cp`, `scene2-btn-next`）。
- IIFE 隔离：所有 JS 代码必须包裹在 `(function() { ... })()` 中，避免变量污染全局作用域。
