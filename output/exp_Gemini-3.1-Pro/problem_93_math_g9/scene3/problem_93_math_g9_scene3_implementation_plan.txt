[图示主题与整合说明]
- 本图示主题：点C运动时点P的轨迹与路径长探究
- 整合的步骤/概念：展示点C在M到N之间连续运动时，等边三角形的动态变化以及点P的水平运动轨迹，辅助讲解坐标与几何推导。
- 教学价值：教师可通过拖拽滑块，直观向学生展示“无论C点如何移动，P点高度始终不变，且P点的水平位移恰好是C点位移的一半”这一核心结论，化抽象的代数推导为直观的几何动画。

[视觉元素清单]
- 基础图形：线段AB，点A、B、M、N及其标签。
- 动态图形：点C，△ACD，△BCE，线段DE，点P及其标签。
- 轨迹与辅助线：P点的完整轨迹虚线，P点已走过的红色实线轨迹，P点到AB的灰色虚线垂线。
- 实时数据面板：位于左上角，包含4行文本：
  1. 已知: AM = BN = 2, AB = 8 (黑色)
  2. 点C水平位移: 0.00 (蓝色 #1565c0)
  3. 点P水平位移: 0.00 (红色 #c62828)
  4. 结论: P点高度不变，位移为C的一半 (黑色)
- 颜色/样式：背景 #ffffff，主线 #000000，蓝高亮 #1565c0，红高亮 #c62828，绿高亮 #2e7d32，辅助线 #888888 虚线。

[分步序列]
- 初始状态：滑块位于最左侧（x_c = 280），点C与点M重合。显示所有基础图形和动态图形的初始位置。P点位于轨迹最左端(340, 142.15)。数据面板显示位移均为0.00。
- 交互状态（拖拽中）：教师向右拖拽滑块，点C向N点平滑移动。△ACD变大，△BCE变小。点P沿水平轨迹线向右移动，身后留下红色加粗轨迹线。数据面板实时更新C和P的位移数值（C位移从0增至4，P位移从0增至2）。
- 最终状态：滑块位于最右侧（x_c = 520），点C与点N重合。红色轨迹线完全覆盖灰色虚线底线。数据面板显示C位移为4.00，P位移为2.00。

[标签冲突检查]
- A(145,370) 与 M(270,370)：间距 125px > 20px → 无冲突。
- M(270,370) 与 N(530,370)：间距 260px > 20px → 无冲突。
- N(530,370) 与 B(655,370)：间距 125px > 20px → 无冲突。
- C(x_c,390) 与 A,M,N,B(y=370)：Y轴错开 20px → 无冲突。
- D(x_d-15,y_d-10) 与 P(x_p,y_p-20)：D点和P点水平间距始终 ≥ 120px → 无冲突。
- E(x_e+15,y_e-10) 与 P(x_p,y_p-20)：E点和P点水平间距始终 ≥ 120px → 无冲突。
- 数据面板(40,50) 与 动态图形：D点最左侧X坐标为220，数据面板最右侧X坐标约200，两者在水平方向完全错开 → 无冲突。

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：在SVG底部（y=460区域）放置一个 `<input type="range">` 滑块，范围 280 到 520，步长 1。左侧配有文字说明“拖动点C (M → N)”。
- 教师操作流程：教师在讲解时，缓慢拖动底部滑块，引导学生观察P点的运动轨迹。通过左上角的实时数据面板，教师可以直观地指出P点位移与C点位移的 1:2 关系，以及P点高度始终不变的几何特征。

[技术实现]
- JS 库选择及原因：原生 SVG。SVG 的 DOM 结构非常适合绑定滑块事件并实时更新几何图形的坐标属性（如 x, y, points, d），性能优异且代码轻量。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```text
  [图示区 800×500]
  +------------------------------------------------+
  | 数据面板                                       |
  | 点C位移: 0.00                                  |
  | 点P位移: 0.00                                  |
  |                                                |
  |        D                                       |
  |       / \       P                              |
  |      /   \......+----------E                   |
  |     /     \     |         / \                  |
  |    /       \    |        /   \                 |
  | A-M---------C---+-------N-----B                |
  |                                                |
  |          [ 拖动点C (M → N) 0===|===0 ]         |
  +------------------------------------------------+
  ```
- 关键实现要点：
  1. 监听滑块的 `input` 事件，获取当前滑块值 `c_x`。
  2. 根据公式计算各点坐标：
     `D_x = 80 + c_x / 2`
     `D_y = 350 - (c_x - 160) * Math.sqrt(3) / 2`
     `E_x = 320 + c_x / 2`
     `E_y = 350 - (640 - c_x) * Math.sqrt(3) / 2`
     `P_x = 200 + c_x / 2`
     `P_y = 142.15` (固定值)
  3. 更新 SVG 元素的属性：
     - `scene3-point-c` 的 `cx`
     - `scene3-label-c` 的 `x`
     - `scene3-poly-acd` 和 `scene3-poly-bce` 的 `points`
     - `scene3-line-de` 的 `x1, y1, x2, y2`
     - `scene3-point-p` 和 `scene3-label-p` 的坐标
     - `scene3-path-p-active` 的 `x2`
     - `scene3-line-p-perp` 的 `x1, x2`
  4. 更新文本面板的数值：C位移 = `((c_x - 280) / 60).toFixed(2)`，P位移 = `((P_x - 340) / 60).toFixed(2)`。
- ID 命名规范：所有元素 ID 必须以 `scene3-` 为前缀（如 `scene3-slider-c`, `scene3-poly-acd`）。
- IIFE 隔离：所有 JS 代码包裹在 `(function() { ... })()` 中，避免变量污染。
