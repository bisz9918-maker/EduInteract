[图示主题与整合说明]
- 本图示主题：甲乙两船的实际运动轨迹与距离-时间图象的动态联动
- 整合的步骤/概念：将一维的海岸线物理运动与二维的距离-时间函数图象结合，通过时间变量 t 的同步动画，直观展示相遇、到达、距离变化等抽象数学关系。
- 教学价值：教师可通过分步动画，引导学生观察图象拐点与实际物理位置的对应关系，降低从图象提取物理信息的认知负荷。

[分步序列]
- 初始状态（步骤0，t=0）：地图上甲在A港，乙隐藏。图象上甲动点在(0,400)，乙动点隐藏。显示AB距离标注"400km"。
- 步骤1（t=4）：点击「下一步」，动画演示甲从A移动到B，图象上甲动点移动到(4,0)。显示甲速短标签"v_甲=100km/h"。
- 步骤2（t=6）：点击「下一步」，动画演示甲从B移动到C，乙从B移动到A。图象上甲动点移动到(6,200)，乙动点从(1,0)移动到(6,400)。显示乙速短标签"v_乙=80km/h"和BC距离标注"200km"。
- 步骤3（t=5）：点击「下一步」，时间回退至t=5。地图上甲在B右侧100km(x=600)，乙在B左侧320km(x=180)。显示橙色距离高亮区和底部距离标注"相距 420 km"。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：底部居中放置「上一步」和「下一步」按钮，中间显示当前步骤（如 1 / 4）。
- 教师操作流程：教师点击下一步，触发时间 t 的平滑过渡动画，引导学生观察地图与图象的同步变化，并在关键节点展示短标签辅助讲解。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JS。SVG 适合绘制精确的几何图形和折线，原生 JS 的 `requestAnimationFrame` 可实现流畅的时间驱动动画。
- 画布尺寸：800 × 500 px
- 布局草图：
  [地图区 800×180]
  [图象区 800×270]
  [控件栏 800×50]
- 关键实现要点：
  - 状态机设计：定义 `currentStep` (0~3) 和对应的目标时间 `targetT` (0, 4, 6, 5)。
  - 动画循环：在 `requestAnimationFrame` 中使用插值 `t += (targetT - t) * 0.05` 平滑更新当前时间 `t`。
  - 坐标映射：
    - 地图甲 x = 100 + 100*t (t<=4), 500 + 100*(t-4) (t>4)
    - 地图乙 x = 500 - 80*(t-1) (t>1)
    - 图象甲 x = 100 + 80*t, y = 240 + 40*t (t<=4), 400 - 40*(t-4) (t>4)
    - 图象乙 x = 100 + 80*t, y = 400 - 32*(t-1) (t>1)
  - 元素显隐：根据 `currentStep` 控制短标签和特定标注的 `opacity`。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀（如 `scene1-btn-next`, `scene1-jia-dot`）。
- IIFE 隔离：所有 JS 代码封装在 `(function() { ... })()` 中。
