[图示主题与整合说明]
- 本图示主题：二次函数系数符号推导与一次函数图象绘制
- 整合的步骤/概念：二次函数开口方向、对称轴位置、参数符号推导、一次函数斜率与截距、一次函数图象所在象限
- 教学价值：教师可以通过分步导航，引导学生一步步从二次函数图象推导出 $a, b$ 的符号，进而绘制出一次函数图象并判断其经过的象限，逻辑清晰，视觉直观，完美契合课堂逐步推导的教学节奏。

[分步序列]
- 初始状态（步骤0）：显示坐标系、抛物线、y轴交点1及标签 $y=ax^2+bx+1$。右侧面板为空。
- 步骤1（推导a）：抛物线高亮（线宽增加或发光），右侧面板出现文本：“1. 抛物线开口向下 $\Rightarrow a < 0$”。
- 步骤2（推导b）：绘制对称轴虚线，高亮其与x轴的交点。右侧面板出现文本：“2. 对称轴在y轴左侧 $\Rightarrow x = -rac{b}{2a} < 0$”，稍微延迟后出现 “$\Rightarrow b < 0$”。
- 步骤3（定位截距）：一个红点从原点 (300,250) 移动到 (300,350)，标记为 $(0, b)$。右侧面板出现文本：“3. 一次函数截距 $b < 0$ $\Rightarrow$ 交于y轴负半轴”。
- 步骤4（绘制直线）：以动画形式从左上 (50,183) 到右下 (500,483) 绘制直线 $y=ax+b$。右侧面板出现文本：“4. 一次函数斜率 $a < 0$ $\Rightarrow$ 直线从左上到右下”。
- 步骤5（确认象限）：依次用绿色半透明色块高亮第二、三、四象限，最后用灰色半透明色块高亮第一象限并闪烁，显示标签“第一象限”。右侧面板出现结论文本：“5. 图象不经过第一象限”。

[交互方案]
- 交互类型：分步按钮导航
- 控件说明：在 SVG 内底部 (y=460~490) 居中放置两个按钮：“◀ 上一步” 和 “下一步 ▶”。
- 教师操作流程：教师点击“下一步”逐步展示推导过程，配合右侧出现的文本进行讲解。可随时点击“上一步”回退复习。

[技术实现]
- JS 库选择：原生 SVG + D3.js（用于路径生成、动画和数据绑定） + MathJax（用于右侧面板和标签的数学公式渲染）。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [图示区 800×500]
  +-------------------------+-----------------+
  |          y              | 1. 开口向下...  |
  |    / \   ^              |                 |
  |   /   \  |              | 2. 对称轴...    |
  |  /     \ | 1            |                 |
  | /       \|              | 3. 截距 b<0...  |
  |-+--------+--------> x   |                 |
  |/         |O             | 4. 斜率 a<0...  |
  |          |              |                 |
  |          * (0,b)        | 5. 不经过第一...|
  |          | \            |                 |
  +-------------------------+-----------------+
  [控件栏： ◀ 上一步 | 下一步 ▶ ]
  ```
- 关键实现要点：
  - 使用 D3.js 的 `d3.line()` 生成抛物线路径，通过采样点绘制平滑曲线。
  - 状态机设计：定义 `currentStep` 变量（0-5），每次点击按钮更新状态，并调用 `updateScene()` 函数。
  - `updateScene()` 中根据 `currentStep` 控制各元素的 `opacity` 和动画。
  - 动画曲线：使用 `d3.transition().duration(800)` 实现平滑过渡。
  - MathJax 渲染：在右侧面板使用 `foreignObject` 嵌入 HTML `div`，调用 `MathJax.typesetPromise()` 渲染公式。
  - ID 命名规范：所有元素 ID 必须以 `scene1-` 为前缀，如 `scene1-parabola`, `scene1-line`。JS 中使用 `d3.select('#scene1-xxx')` 获取元素。
  - IIFE 隔离：所有 JS 代码必须包裹在 `(function() { ... })()` 中，避免全局变量污染。
