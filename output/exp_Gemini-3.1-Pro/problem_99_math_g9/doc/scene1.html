已知条件：
等边 $ riangle ABC$ 中，
$AD = 1$
$BD = 2$
$BF = rac{5}{4}$
求 $CE$ 的长度。
步骤 1：折叠性质
将 $ riangle CEF$ 沿 $EF$ 折叠，点 $C$ 与点 $D$ 重合。
根据折叠全等性质：
$ riangle CEF \cong riangle DEF$
$\angle EDF = \angle C = 60^\circ$
步骤 2：边长代换
设 $CE = x$，则 $DE = x$。
等边三角形边长 $AB = AD + BD = 3$。
$AE = AC - CE = 3 - x$
$CF = BC - BF = 3 - rac{5}{4} = rac{7}{4}$
$DF = CF = rac{7}{4}$
步骤 3：角度转换
在平角 $\angle ADB$ 中：
$\angle ADE + \angle BDF = 180^\circ - \angle EDF = 120^\circ$
在 $ riangle ADE$ 中：
$\angle ADE + \angle AED = 180^\circ - \angle A = 120^\circ$
因此，$\angle AED = \angle BDF$。
步骤 4：相似求解
由于 $\angle A = \angle B = 60^\circ$，且 $\angle AED = \angle BDF$，
所以 $ riangle ADE \sim riangle BFD$。
对应边成比例：
$ rac{AE}{BD} = rac{DE}{FD}$
$ rac{3-x}{2} = rac{x}{7/4}$
解得：$x = rac{7}{5}$
