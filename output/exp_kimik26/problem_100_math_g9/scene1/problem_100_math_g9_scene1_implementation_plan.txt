[分步序列]
- 步骤0（初始状态）：显示立体图大版完整线框 + 顶点标签A-F + 说明文字"下底面""上底面""侧面""侧棱"。无填充，无展开图，无立体图小版。
- 步骤1（点击下一步）：下底面△ABC与上底面△DEF填充蓝色（#1565c0, fill-opacity:0.2）；三个侧面ABED/BCFE/ACFD填充绿色（#2e7d32, fill-opacity:0.15）；新增文字标注"正三角形底面"（蓝色，位于下底面正下方）和"矩形侧面"（绿色，位于前侧面下方）。立体图大版位置不变。
- 步骤2（点击下一步）：立体图大版通过CSS transition在400ms内缩小0.5倍并上移至小版位置（y≈120）。随后展开图各面从立体图小版对应位置通过JS动画"展开"：中矩形ABED保持基准平移至展开图位置；左矩形绕AD边向左旋转展平；右矩形绕BE边向右旋转展平；上底面绕DE边向上翻转；下底面绕AB边向下翻转。动画时长600ms，使用CSS transition on transform（translate/rotate）。动画完成后显示展开图顶点标签A-F。
- 步骤3（点击下一步）：在展开图上方显示红色约束文字"正三角形边长 = 矩形宽度"；在展开图右侧显示"两个底面全等"和"三个侧面全等"。同时立体图小版保持可见但降低透明度（opacity:0.3）作为参照。教师可点击「上一步」回退至任意步骤复习。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript（无需外部库）。理由：场景为静态几何图形+简单CSS transition动画，DOM操作即可满足，避免引入冗余依赖。
- 画布尺寸：800×500px（SVG viewBox="0 0 800 500"）
- 布局草图：
  ```
  [主图区 800×430]
    步骤0-1: 立体图大版居中 (y=85~320)
    步骤2-3: 立体图小版居上 (y=45~170) + 展开图居下 (y=200~435)
  [控件区 800×60 @ y=440~490]
    [上一步] [步骤 X/4] [下一步]
  ```
- 关键实现要点：
  1. 状态机设计：变量 `scene1_step` ∈ {0,1,2,3}，每次点击按钮更新状态，通过 `updateScene()` 函数根据状态切换元素的 CSS class（如 `.show-step-0` `.show-step-1` 等）。
  2. 立体图大小切换：大版与小版定义为两组独立的 `<g>` 元素，步骤0-1显示大版隐藏小版，步骤2-3通过CSS transition在大版上应用 `transform: scale(0.5) translate(0, -180px)` 或直接切换显示组。建议直接切换显示组以避免复杂矩阵计算。
  3. 展开动画：步骤2中，展开图各面初始状态为 `opacity:0`，通过JS在短暂延迟后（立体图缩小完成后）依次设置各面的 `transform` 和 `opacity`。使用 `transition: transform 0.6s ease-out, opacity 0.3s`。
  4. 填充高亮：步骤1中，底面和侧面polygon元素添加class `.highlight-blue` / `.highlight-green`，设置 `fill:#1565c0; fill-opacity:0.2` 和 `fill:#2e7d32; fill-opacity:0.15`。
  5. 文字标签显隐：所有说明文字和约束文字初始 `opacity:0` 或 `display:none`，通过状态class控制显示。
  6. 事件绑定：按钮绑定 `click` 事件，更新 `scene1_step` 后调用 `updateScene()`。
- ID命名规范：所有元素ID必须以 `scene1-` 为前缀。例如：`scene1-solid-large`（立体图大版组）、`scene1-solid-small`（立体图小版组）、`scene1-net-group`（展开图组）、`scene1-net-rect-mid`（中矩形）、`scene1-net-base-top`（展开图上底面）、`scene1-label-a-large`（立体图大版A标签）、`scene1-label-a-net`（展开图A标签）、`scene1-text-base`（"正三角形底面"文字）、`scene1-constraint-eq`（"正三角形边长=矩形宽度"文字）、`scene1-btn-prev`、`scene1-btn-next`、`scene1-step-indicator`。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })()` 中，避免全局变量污染。
