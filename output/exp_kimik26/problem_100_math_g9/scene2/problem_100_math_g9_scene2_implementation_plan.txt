# Scene 2 Implementation Plan

<SCENE_VISION_STORYBOARD_AND_TECHNICAL_PLAN>

[图示主题与整合说明]
- 本图示主题：正方形网格中四个展开图能否围成正三棱柱的逐图判定
- 整合的步骤/概念：图①②③④的网格展示 → 阴影三角形类型识别（直角三角形 vs 锐角三角形/正三角形） → 侧面形状识别（是否为矩形） → 折叠闭合示意 → 判定结论汇总 → 正确答案高亮
- 教学价值：教师通过分步导航，引导学生逐个观察四个图形的底面三角形类型和侧面形状，建立"正三棱柱展开图必须满足底面为正三角形且侧面为矩形"的判据，最后汇总对比得出选项B（③和④）的正确结论。

[视觉元素清单]
- 网格背景：步骤0和步骤5中每个图形区域内部绘制浅灰色网格线（#dddddd，线宽1px），网格单元20px，仅作为视觉参考，不占据主坐标。
- 展开图外轮廓：所有矩形、多边形外轮廓使用主线#000000，线宽2px。
- 阴影三角形：
  - 步骤0：统一使用原阴影色#a0a0a0，透明度40%。
  - 步骤1~2（错误判定）：红高亮#c62828，填充透明度30%。
  - 步骤3~4（正确判定）：绿高亮#2e7d32，填充透明度25%。
- 侧面高亮：步骤3中三个侧面使用绿高亮#2e7d32描边，线宽2px；步骤4中三个矩形侧面使用蓝高亮#1565c0描边，线宽2px（表示轴对齐矩形侧面）。
- 折叠示意线：步骤1~2中使用辅助线#888888虚线（dash 4,4），线宽1px，表示折痕位置。
- 角度标注：使用小弧线（半径12px）+ 文字，步骤1~2中标注90°、60°、30°。
- 直角符号：步骤3~4中在矩形角上绘制L形直角符号（边长8px，线宽2px），步骤3中因侧面倾斜，直角符号需随矩形边旋转。
- ×/√标记：
  - 红色×：两条对角线交叉，线宽3px，颜色#c62828，大小60×60（放大视图）或40×40（总览）。
  - 绿色√：折线勾形，线宽4px，颜色#2e7d32，大小50×50（放大视图）或40×40（总览）。
- 选项高亮：步骤5中选项B背景使用#1565c0填充，透明度15%，圆角4px。
- 文字标签：所有文字使用 sans-serif 字体，黑色#000000，字号14px（标注）或16px（结论）。

[技术实现]
- JS库选择：原生 SVG（使用 HTML 内嵌 SVG 元素），无需额外库。原因：本场景以静态几何图形和分步显示/隐藏为主，不涉及复杂动画、函数绘图或3D，原生SVG足够且轻量。
- 画布尺寸：800×500 px（固定）。
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  步骤0/5: 2×2网格                                 |
  |  +--------+  +--------+                            |
  |  |  图①   |  |  图②   |                            |
  |  +--------+  +--------+                            |
  |  +--------+  +--------+                            |
  |  |  图③   |  |  图④   |                            |
  |  +--------+  +--------+                            |
  |  步骤1~4: 左侧导航栏 + 右侧放大区                  |
  |  +----+  +------------------------------------+    |
  |  |缩略|  |                                    |    |
  |  |图①|  |         放大图形与标注              |    |
  |  |缩略|  |                                    |    |

  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `currentStep`（0~5），每一步对应一个状态。所有SVG元素按步骤分组，使用 `<g>` 标签包裹，并设置 `id="scene2-step0"` 到 `id="scene2-step5"`。切换步骤时，先隐藏所有步骤组（`display:none`），再显示当前步骤组（`display:block`）。
  2. 左侧导航栏：在步骤1~4中始终显示。四个缩略图使用独立的 `<g>` 元素，当前步骤对应的缩略图添加蓝色边框矩形（`stroke:#1565c0; stroke-width:3; fill:none`）。
  3. 缩略图绘制：在导航栏内为每个图形建立独立的局部坐标系（使用 `<g transform="translate(x,y) scale(0.4)">` 等方式缩放），复用主图的几何定义或单独定义简化版。
  4. 角度标注弧线：使用 `<path>` 绘制小圆弧（半径12px），例如90°角画四分之一圆弧，60°和30°角画相应角度的圆弧。文字标注使用 `<text>` 元素，通过 `x`、`y` 精确定位。
  5. 直角符号：轴对齐的直角符号直接画L形（两条垂直线段，各8px）。倾斜的直角符号（步骤3左/右侧面）需要使用 `<g transform="rotate(angle, cx, cy)">` 旋转后再画L形。
  6. ×/√标记：使用 `<path>` 绘制。×为两条对角线；√为折线（从左上到右下再到右上）。
  7. 按钮状态：步骤0时禁用"上一步"（填充#aaaaaa，pointer-events:none），步骤5时禁用"下一步"。
  8. 颜色变量：在CSS或JS中定义颜色常量，确保与规格一致：
     - bg: #ffffff
     - mainLine: #000000
     - gridLine: #dddddd
     - defaultShadow: #a0a0a0
     - blueHighlight: #1565c0
     - redHighlight: #c62828
     - greenHighlight: #2e7d32
     - auxLine: #888888
- ID命名规范：所有交互元素和分组ID必须以 `scene2-` 为前缀。例如：
  - 步骤分组：`scene2-step0`, `scene2-step1`, ..., `scene2-step5`
  - 导航栏缩略图：`scene2-thumb1`, `scene2-thumb2`, `scene2-thumb3`, `scene2-thumb4`
  - 当前高亮边框：`scene2-thumb1-border`
  - 按钮：`scene2-btn-prev`, `scene2-btn-next`
  - 步骤指示器：`scene2-step-indicator`
  - 主显示区图形元素：`scene2-fig1-left-rect`, `scene2-fig1-shadow-tri-left` 等
  - JS中严格使用 `document.getElementById()` 获取元素，避免使用 `querySelectorAll` 配合全局class，防止多场景合并时跨场景污染。
- IIFE隔离：所有JavaScript代码包裹在立即执行函数表达式中：
  ```javascript
  (function() {
    // 所有变量和函数定义在此作用域内
    var currentStep = 0;
    // ...
  })();
  ```
- 响应式说明：本场景为固定尺寸800×500的教学图示，不针对容器缩放做响应式处理，确保坐标精确可控。
