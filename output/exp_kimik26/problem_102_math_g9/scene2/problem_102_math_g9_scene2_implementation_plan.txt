[图示主题与整合说明]
- 本图示主题：抛物线参数 b 的动态变化与交点位置判定
- 整合内容：
  1. 抛物线 y=x²-bx+2 随 b 连续变化的动态演示；
  2. 与直线 AB 两交点的实时计算与位置判定（是否分别落在线段 AN 与 BM 上）；
  3. 有效区间 [5/2, 11/3] 在底部数轴上的可视化；
  4. 临界状态 b=5/2（过点 B）与 b=11/3（过点 M）的一键跳转与高亮。
- 教学价值：教师通过拖动滑块展示抛物线随参数 b 的平移与变形，引导学生观察交点何时恰好落在目标线段上，从而自主发现临界值，理解"包含端点"的区间含义。

[视觉元素清单]

[分步序列/关键状态]
本场景为连续滑块交互，无固定分步。定义以下关键状态供教师讲解时参考：
- 初始状态（b=0）：抛物线开口向上，顶点(0,2)。与直线AB交于两点（约x≈-1.62与x≈0.62），均不在目标线段上，交点红色，状态显示"不满足条件"。
- 临界状态1（b=5/2=2.50）：点击"b=5/2"按钮跳转。抛物线过点B(2,1)，右交点恰好落在线段BM端点B，左交点落在AN内部(x=-0.5)。两交点均满足条件（绿色），状态"满足条件"。交点B高亮闪烁2秒（半径放大至8px）。
- 临界状态2（b=11/3≈3.67）：点击"b=11/3"按钮跳转。抛物线过点M(3,0)，右交点恰好落在线段BM端点M，左交点落在AN内部(x≈-0.33)。两交点均满足条件（绿色），状态"满足条件"。交点M高亮闪烁2秒。
- 中间状态（如b=3.0）：抛物线介于两临界之间，两交点分别严格位于AN与BM内部，均绿色，状态"满足条件"。
- 超出状态（b<2.5或b>11/3）：至少一个交点脱离目标线段，该交点变红，状态"不满足条件"。
教师可自由拖动滑块在[0,5]间连续探索，也可随时点击临界按钮定位关键节点。

- 控件说明：

  2. 临界跳转按钮1："b = 5/2（过点B）"，位于(220,475)，宽160px。点击后滑块自动跳至b=2.5，交点B高亮闪烁2秒（半径5px→8px→5px，白色描边加粗）。
  3. 临界跳转按钮2："b = 11/3（过点M）"，位于(440,475)，宽160px。点击后滑块自动跳至b≈3.67，交点M高亮闪烁2秒。
- 教师操作流程：
  1. 初始展示b=0的不满足状态，说明抛物线恒过(0,2)；
  2. 向右拖动滑块，观察抛物线右移、交点变化；
  3. 当交点接近B时，点击"b=5/2"按钮精确定位第一个临界，强调"包含端点"；
  4. 继续拖动至中间某值（如b=3），确认两交点均在绿色线段上；
  5. 点击"b=11/3"按钮定位第二个临界；
  6. 继续拖动观察超出状态，总结有效区间。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本场景以2D几何图形为主，无复杂数据绑定或3D需求，原生SVG路径操作足够高效，且便于教师后续直接修改参数。
- 画布尺寸：800×500px（SVG viewBox="0 0 800 500"）
- 布局草图：
  ```
  [主图区 0≤y≤375]
    y轴(313,25-373)  x轴(197-603,315)
    A(-1,4)●───────N(0,3)●────────────B(2,1)●───────M(3,0)●
            ＼ 绿色AN ／  ＼  绿色BM  ／
             ＼      /    ＼        /
              ＼    /      ＼      /
               ＼  /   抛物线＼    /
                ＼/    (动态) ＼  /
                 ●(0,2)定点   ＼/
                               
  [控制区 375≤y≤500]
    b = 2.50    [满足条件]          (状态文字)
    |====●====================|      (滑块 0~5)
    0                        5
    |----[====]----------------|     (数轴，绿色区间为有效范围)
    [b=5/2(过点B)]  [b=11/3(过点M)] (临界按钮)
  ```
- 关键实现要点：
  1. 坐标转换：mathToScreen(x,y) → (313+x*58, 315-y*58)。所有数学坐标通过此函数映射到SVG像素坐标。
  2. 抛物线路径生成：遍历x∈[-2,5]步长0.05，计算y=x²-bx+2。若连续两点y均在[-1.5,5.5]内（允许少量越界保证曲线连贯）则用L连线，否则M移动。超出可视域的点不绘制。
  3. 交点计算：解x²-(b-1)x-1=0，得x=((b-1)±√((b-1)²+4))/2，y=-x+3。小根为左交点，大根为右交点。
  4. 状态判定：左交点x∈[-1,0]则onAN=true；右交点x∈[2,3]则onBM=true。valid=onAN&&onBM。
  5. 交点标注位置算法：左交点标注坐标(screenX-12, screenY-18)，text-anchor="end"；若screenY<120则改为(screenX-12, screenY+18)避免与A标签冲突。右交点标注坐标(screenX+12, screenY+18)，text-anchor="start"；若screenY>300则改为(screenX+12, screenY-18)避免与M/B标签冲突。
  6. 数轴映射：b值→像素x = 150 + b/5*500。有效区间矩形x∈[400, 516.7]。
  7. 临界高亮：点击按钮后设置highlightTimer=2000ms，在requestAnimationFrame循环中根据剩余时间计算交点半径（5+3*sin(π*t/200)）和描边宽度（1+2*(1-t/2000)），时间到后恢复默认。
  8. 性能：使用单一requestAnimationFrame循环，仅在滑块input事件或按钮点击时标记needsRedraw=true，避免每帧无意义重绘。
- ID命名规范：所有SVG元素及控件ID必须以`scene2-`为前缀。例如：scene2-parabola-path、scene2-intersection-1、scene2-slider-thumb、scene2-btn-critical-b、scene2-axis-x。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，全局仅暴露必要事件监听器（通过DOM元素oninput/onclick属性或内部IIFE绑定）。
- 引入方式：HTML内嵌SVG，CSS内嵌于style标签，JS内嵌于script标签。无需外部CDN（除如需MathJax则本场景不需要）。
