[图示主题与整合说明]
- 本图示主题：正方形序列的递推规律与边长计算（等比数列通项）
- 整合的步骤/概念：题意感知 → 第一个大正方形的直角三角形分析（30°-60°-90°） → D₁纵坐标推导（邻边垂直+正弦） → 小正方形边长确定 → 第二个大正方形边长a₂推导 → 递推规律发现 → 等比数列通项与最终答案
- 教学价值：教师通过分步导航，可按照"已知条件→局部分析→递推发现→一般结论"的认知递进讲解；每一步仅聚焦当前推导所需的几何元素，其余淡化，避免信息过载；支持随时回退复习。

[分步序列]
- 步骤0（题意感知）：
  显示所有正方形（统一浅灰填充rgba(192,192,192,0.2)，黑色边框1.5px）、坐标系、全部点标签。
  绿色高亮：标注"a₁=1"在(138,370)，30°角弧+文字"30°"在(135,324)。
  红色虚线：水平线(150,250)-(550,250)，文字"B₁C₁ ∥ B₂C₂ ∥ B₃C₃"在(350,235)。
  底部提示："观察图形，注意大正方形与小正方形交替放置的规律"

- 步骤1（聚焦第一个大正方形）：
  淡化后续正方形（A₂B₂C₂D₂、D₂E₃E₄B₃、A₃B₃C₃D₃透明度降至15%，边框#888888）。
  高亮A₁B₁C₁D₁：蓝色边框#1565c0 2.5px，填充rgba(21,101,192,0.15)。
  显示直角标记在O(120,420)。
  30°角弧保持红色显示。
  底部提示："在Rt△OB₁C₁中，∠C₁B₁O = 30°，B₁C₁ = 1"

- 步骤2（分析夹角）：
  保持步骤1的高亮状态。
  新增：在C₁处画60°角弧（红色，半径20px），文字"60°"在(165,400)。
  底部提示："直角三角形两锐角互余，∠OC₁B₁ = 60°"

- 步骤3（推导D₁纵坐标）：
  保持A₁B₁C₁D₁蓝色高亮。
  高亮边C₁D₁：蓝色粗实线2.5px（从C₁到D₁）。
  新增垂线D₁E₁：灰色虚线(311,350)-(311,420)。
  新增标注"D₁E₁ = 1/2"（绿色文字在(331,385)）。
  底部提示："C₁D₁ ⊥ B₁C₁，故C₁D₁与x轴夹角30°，D₁E₁ = C₁D₁·sin30° = 1/2"

- 步骤4（小正方形边长）：
  A₁B₁C₁D₁恢复普通样式（浅灰填充）。
  高亮小正方形D₁E₁E₂B₂：红色边框#c62828 2.5px，填充rgba(198,40,40,0.15)。
  其余大正方形保持淡化。
  标注"边长 = 1/2"（红色文字在(346,335)）。
  新增水平灰色虚线从y轴(120,350)到B₂(381,350)，标注"y_B₂ = 1/2"（黑色文字在(200,340)）。
  底部提示："小正方形D₁E₁E₂B₂的边长等于D₁的纵坐标，即1/2"

- 步骤5（推导a₂）：
  淡化小正方形D₁E₁E₂B₂（恢复普通）。
  高亮A₂B₂C₂D₂：蓝色边框+浅蓝填充。
  新增垂线B₂H₂：灰色虚线(381,350)-(381,420)，垂足标记H₂在(395,435)（此时E₂标签隐藏），直角标记在(381,420)。
  标注"B₂H₂ = 1/2"（黑色文字在(401,385)）。
  在C₂处画60°角弧（蓝色，半径15px），文字"60°"在(392,400)。
  显示推导公式："a₂ = B₂H₂ / sin60° = (1/2)/(√3/2) = √3/3"（红色18px文字在(420,320)）。
  标注"a₂ = √3/3"（红色文字在(425,368)）。
  底部提示："在Rt△B₂H₂C₂中，a₂ = B₂H₂ / sin60° = √3/3"

- 步骤6（发现递推规律）：
  同时高亮A₂B₂C₂D₂（蓝色）、D₂E₃E₄B₃（红色）、A₃B₃C₃D₃（蓝色）。
  A₁B₁C₁D₁和D₁E₁E₂B₂淡化至透明度30%。
  新增垂线D₂E₃（灰色虚线）和B₃H₃（灰色虚线），直角标记在H₃。
  快速标注：
    - "D₂E₃ = √3/6"（绿色，(512,400)）
    - "边长 = √3/6"（红色，(510,350)）
    - "B₃H₃ = √3/6"（黑色，(555,400)）
    - "a₃ = 1/3"（红色，(585,355)）
  右侧显示递推关系文本（红色18px加粗，左对齐x=620）：
    第一行："递推关系："
    第二行："aₙ₊₁ = aₙ · √3/3"
    第三行："公比 q = √3/3"
  底部提示："观察规律：每个大正方形边长是前一个的√3/3倍"

- 步骤7（通项与答案）：
  所有正方形恢复普通样式（浅灰填充，黑色边框），避免遮挡公式。
  右侧显示通项与答案文本（左对齐x=620）：
    第一行："通项公式："（黑色18px）
    第二行："aₙ = (√3/3)ⁿ⁻¹"（黑色18px加粗）
    第三行："a₂₀₁₆ = (√3/3)²⁰¹⁵"（绿色#2e7d32，20px加粗）
    第四行："答案：C"（绿色#2e7d32，20px加粗，背景填充rgba(46,125,50,0.15)矩形）
  底部提示："等比数列通项公式：aₙ = a₁·qⁿ⁻¹，代入n=2016"

- JS库选择：原生SVG + 原生JavaScript。原因：本场景为纯2D几何图形，以多边形、线段、文本、路径为主，状态切换逻辑简单，无需引入D3/Three.js等重型库；原生SVG可精确控制每个元素的显隐、颜色、透明度。
- 画布尺寸：800 × 500 px（SVG viewBox="0 0 800 500"）
- 布局草图：
  ```
  +--------------------------------------------------------+
  |  [y轴↑]                                                |
  |    A₁                                                  |
  |       ╱  ╲ 大正方形                                     |
  |  B₁ ╱      ╲  D₁  B₂  A₂    B₃  A₃                     |
  |    ╱  ╲____╱╲__╱╲____╱╲__╱╲____╱                      |
  |   O  C₁ E₁ E₂ C₂ E₃ E₄ C₃  [x轴→]                     |
  |                                                        |
  |              （右侧公式文本区：步骤6-7）                  |
  |                                                        |
  |--------------------------------------------------------|
  |         步骤提示文字 (400,450)                          |
  |    [◀ 上一步]          [下一步 ▶]     (300,465)/(420,465)|
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `let currentStep = 0;` 共8个状态（0~7）。定义配置对象 `stepConfig`，每个步骤记录需要显示/隐藏的元素ID列表、需要添加/移除的CSS类名、以及提示文字内容。
  2. 元素组织：SVG中使用 `<g id="scene1-group-name">` 分组管理。例如：
     - `scene1-square-large-1`（A₁B₁C₁D₁）
     - `scene1-square-small-1`（D₁E₁E₂B₂）
     - `scene1-square-large-2`（A₂B₂C₂D₂）
     - `scene1-square-small-2`（D₂E₃E₄B₃）
     - `scene1-square-large-3`（A₃B₃C₃D₃）
     - `scene1-angle-30`、`scene1-angle-60-c1`、`scene1-angle-60-c2`
     - `scene1-perp-d1e1`、`scene1-perp-b2h2`、`scene1-perp-d2e3`、`scene1-perp-b3h3`
     - `scene1-label-h2`、`scene1-label-h3`
     - `scene1-formula-recurrence`、`scene1-formula-general`
     - `scene1-answer-highlight`
  3. 样式切换：通过切换CSS类实现高亮/淡化。例如 `.highlight-blue { stroke: #1565c0; stroke-width: 2.5px; fill: rgba(21,101,192,0.15); }`、`.dimmed { opacity: 0.15; }`、`.hidden { display: none; }`。
  4. 动画：本场景以状态切换为主，不需要复杂动画。元素出现/隐藏使用直接切换（或可选0.2s CSS transition）。
  5. 事件绑定：按钮绑定 `click` 事件，调用 `goToStep(n)` 函数。函数内先移除所有动态类，再根据 `stepConfig[n]` 应用新的类和显隐状态，更新提示文字和按钮禁用状态。
  6. 垂足标签互斥：步骤5中通过JS隐藏 `scene1-label-e2`，显示 `scene1-label-h2`；步骤6中隐藏 `scene1-label-e4`，显示 `scene1-label-h3`。
  7. 公式文本定位：使用 `<text x="620" y="..." text-anchor="start">` 实现左对齐，避免多行文本复杂布局；或使用 `<foreignObject>` 嵌入HTML div实现自动换行（推荐用foreignObject保证排版整洁）。
- ID命名规范：所有SVG元素及JS变量均以 `scene1-` 为前缀，例如 `scene1-square-large-1`、`scene1-btn-prev`、`scene1-btn-next`、`scene1-step-hint`。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免全局命名空间污染，确保多场景合并时互不干扰。
