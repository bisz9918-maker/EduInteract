[视觉元素清单]
- 三角形ABC：等腰直角三角形，A置顶，BC水平底边，黑色2px边线
- 点D、E：在BC上，顺序B-E-D-C，黑色小圆点（r=3）
- 点F：旋转生成点，在B正上方，步骤2后出现
- 连线AD、AE、AF、BF、EF：按步骤出现，颜色见上表
- 角度弧线：∠BAC（90°）、∠DAE（45°）、∠DAF（90°），用SVG arc绘制
- 直角符号：∠FBE处绘制12×12小正方形
- 旋转轨迹：灰色虚线圆弧，圆心A，从D到F
- 等长标记：对应边上绘制垂直短横线（tick marks）
- 颜色/样式沿用spec配色：
  - 主线 #000000 2px
  - 蓝高亮 #1565c0，fill-opacity 0.2（△ADC）
  - 红高亮 #c62828，fill-opacity 0.2（△ABF）
  - 绿高亮 #2e7d32（等量关系、全等、推导文字）
  - 辅助线 #888888 虚线 1px（轨迹、预告线、方向箭头）

[分步序列]
- 初始状态（步骤0）：展示等腰直角△ABC（A置顶，BC水平），点D、E在BC上（B-E-D-C），连接AD、AE。标注顶点A/B/C/D/E。标注∠BAC=90°、∠DAE=45°。标注AB=AC（绿色）。所有元素黑色主线，无填充。
- 步骤1（高亮待旋转三角形）：△ADC填充蓝色（#1565c0，透明度20%），边AD、DC变为蓝色2px。新增AF预告虚线（灰色虚线从A到F），标注AD=AF（绿色）。在A处绘制逆时针旋转方向箭头（灰色虚线弧+箭头）。
- 步骤2（旋转动画）：△ABF以淡入/展开动画出现，填充红色（#c62828，透明度20%），边AF、BF红色2px。F标签出现。绘制旋转轨迹圆弧（灰色虚线，从D到F）。连接EF（黑色1px）。此时△ADC可保持半透明蓝色或淡出为浅灰，表示"来源"。
- 步骤3（全等关系）：标注△ABF≌△ACD（绿色，右侧）。在BF和DC上绘制等长标记（红色tick），标注BF=DC（绿色）。标注∠ABF=∠C=45°（绿色，BF右侧）。高亮对应边/角。
- 步骤4（直角推导）：标注∠ABC=45°（绿色，B右上方）。在B处绘制∠FBE=90°直角符号，标注∠FBE=90°。显示推导式"∠FBE=∠ABF+∠ABC=90°"（绿色，右侧）。高亮∠ABF和∠ABC区域。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于SVG内底部(280,455)，100×36px，点击回退到上一状态
  - 「下一步」按钮：位于SVG内底部(420,455)，100×36px，点击推进到下一状态
  - 步骤指示器：位于(360,430)，显示当前步骤编号"步骤 X/5"
- 教师操作流程：
  1. 教师展示步骤0，说明题目条件（等腰直角△ABC，∠DAE=45°）
  2. 点击「下一步」进入步骤1，引导学生观察△ADC，提出"将△ADC旋转"的构想
  3. 点击「下一步」进入步骤2，播放旋转动画，C→B，D→F，直观展示变换
  4. 点击「下一步」进入步骤3，标注全等关系，建立BF=DC、∠ABF=∠C=45°
  5. 点击「下一步」进入步骤4，推导∠FBE=90°，为后续结论判断提供关键依据
  6. 可随时点击「上一步」回退复习任意步骤

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：本场景为纯几何图形与分步状态切换，无需复杂数据绑定或3D，原生SVG路径、多边形、文本即可满足，且便于精确控制每个元素的显隐和颜色。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  
         A
        / \
       /   \
      /     \
     F       \
     |        \
     |         \
     |          \
     B---E---D---C
  
  [控件栏 y=440~490，绝对定位在SVG上方]
  [  ◀ 上一步 ]  [ 步骤 1/5 ]  [ 下一步 ▶  ]
  ```
- 关键实现要点：
  1. 状态机设计：定义state变量（0~4），每步用一个配置对象描述各元素的display/opacity/color属性。点击按钮时state增减，调用render()函数根据当前状态更新所有SVG元素的属性。
  2. 旋转轨迹：用SVG `<path>` 绘制圆弧，d="M 460 340 A 228 228 0 0 1 180 180"（圆心A，半径228，从D到F顺时针）。步骤2中以stroke-dasharray动画绘制。
  3. 三角形填充：使用`<polygon>`定义△ADC和△ABF，初始opacity=0，步骤1/2中通过CSS transition或JS动画将opacity提升至0.2。
  4. 角度弧线：使用`<path>`画弧，计算起始角和终止角（基于向量方向），确保弧线不与其他图形重叠。
  5. 直角符号：在B处绘制小正方形path，边长12px，方向沿BF和BC。
  6. 等长标记tick：在各边中点处绘制垂直于边的短线段（8px），步骤3中显示。
  7. 动画曲线：旋转轨迹使用ease-in-out，三角形填充使用ease，持续时间300-500ms。
  8. 事件绑定：上一步/下一步按钮绑定click事件，更新state并调用render。
- ID命名规范：所有SVG元素和交互元素ID必须以`scene1-`为前缀。例如：`scene1-tri-abc`、`scene1-point-a`、`scene1-btn-prev`、`scene1-label-bac`。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免多场景合并时变量污染。
