[图示主题与整合说明]
- 本图示主题：屋架结构中的中位线与直角三角形性质
- 整合的步骤/概念：屋架基础结构识图 → 已知条件标注（AB=8m、∠A=30°、D为AB中点） → 垂直与平行关系发现（DE⊥AC、BC⊥AC、DE∥BC） → 解法一（三角函数法在Rt△ADE中求DE） → 解法二（中位线定理法先求BC再求DE） → 结论验证（DE=2m，选项B）
- 教学价值：教师可通过分步导航按课堂节奏逐步展开，尤其在步骤3与步骤4可灵活进退对比两种解法，帮助学生建立"一题多解"的几何思维；屋架实景图增强学生空间感知与数学应用意识。

[分步序列]
- 初始状态（步骤0）「屋架结构」：显示△ABC外框（黑色实线+淡金填充）、线段BC、DE、AB、AC；显示点标签A、B、C、D、E；所有线段等宽等色，无额外标注；帮助学生建立屋架整体直观印象。
- 步骤1「已知条件」：AB边变为蓝色#1565c0且线宽增至3px；在A点处显示蓝色角度弧（∠A=30°）及标签"30°"；在D点显示蓝色中点标记；在AB中点上方显示蓝色标签"AB = 8m"；所有已知信息以蓝色高亮，与黑色轮廓形成区分。
- 步骤2「垂直与平行」：在C点和E点显示红色直角符号；DE和BC变为红色#c62828且线宽增至3px；在DE与BC之间显示红色文字"DE ∥ BC"及红色虚线指示；引导学生发现DE⊥AC、BC⊥AC，从而推出DE∥BC的关键几何关系。
- 步骤3「解法一：三角函数」：BC和AC淡化（#888888虚线，opacity 0.4），△ABC淡金填充隐藏；显示△ADE淡红色填充；AD边显示蓝色标签"AD = 4m"；DE保持红色高亮；在下方显示公式"在Rt△ADE中，AD = AB/2 = 4m"和"DE = AD·sin30° = 4×(1/2) = 2m"；聚焦Rt△ADE的直接求解路径。
- 步骤4「解法二：中位线」：恢复BC和AC为黑色实线，恢复△ABC淡金填充；DE淡化（#888888虚线）；BC显示红色标签"BC = 4m"；BC恢复红色高亮；在下方显示公式"在Rt△ABC中，BC = AB·sin30° = 8×(1/2) = 4m"和"DE = BC/2 = 2m（三角形中位线定理）"；展示整体视角下的中位线定理应用。
- 步骤5「结论」：所有线段恢复黑色实线（DE线宽3px）；DE左侧显示绿色加粗标签"DE = 2m"；下方显示结论公式"DE = 2m"和"正确答案：B"；在y=415区域显示选项A/B/C/D四个按钮，B选项以绿色高亮框标注，其余选项灰色淡化；完成题目闭环。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「上一步」按钮：位于画布底部中央偏左（CSS绝对定位，left:280px, top:455px, width:80px, height:32px），点击回退到上一教学步骤。
  2. 「步骤指示器」：位于两按钮之间（left:370px, top:455px），显示当前步骤编号如"步骤 2/6"，不可点击。
  3. 「下一步」按钮：位于画布底部中央偏右（left:440px, top:455px, width:80px, height:32px），点击前进到下一教学步骤。
- 教师操作流程：
  1. 课堂开始时点击「下一步」从步骤0进入步骤1，引导学生识别已知条件；
  2. 继续点击「下一步」依次展示垂直平行关系、两种解法；
  3. 讲解解法一时，若学生理解困难，可点击「上一步」回到步骤2巩固平行关系；
  4. 讲解解法二后，可点击「上一步」回到步骤3对比两种方法；
  5. 最后进入步骤5，确认答案为B选项。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：本场景为静态几何图形与分步显隐控制，无复杂动画或数据驱动绘图，原生SVG足以保证轻量与精确控制。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |                                                  |
  |              B(500,95)                           |
  |             / \                                  |
  |            /   \                                 |
  |      D(340,207.5)                               |
  |          / |     \                               |
  |         /  |       \                             |
  |        /   |         \                           |
  |   A(180,300)-E(340,300)-C(500,300)              |
  |                                                  |
  |    [公式文本区: y=340~430]                       |
  |    [选项按钮区: y=401~429, 步骤5显示]            |
  |                                                  |
  |    [◀上一步] [步骤 X/6] [下一步▶]  y=455~487    |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量`let currentStep = 0;`记录当前步骤（0~5）。`updateScene()`函数根据currentStep统一控制所有元素的显隐与样式。
  2. 元素分组管理：为每个步骤创建独立的SVG `<g>`分组（如`id="scene1-step1-group"`），分组内包含该步骤新增的所有元素（标签、符号、高亮线段等）。步骤切换时通过设置`display: none/block`或`visibility: hidden/visible`控制整组显隐。
  3. 线段高亮与淡化：对AB、BC、AC、DE四条关键线段，准备多套样式类（.normal / .highlight-blue / .highlight-red / .highlight-green / .dimmed），通过`setAttribute('class', ...)`切换。
  4. 填充控制：△ABC填充和△ADE填充使用独立的多边形元素，通过`opacity`属性或`display`控制显隐。
  5. 公式文本：使用两个SVG `<text>`元素（id="scene1-formula-line1"、"scene1-formula-line2"），步骤切换时修改其`textContent`和`display`属性。
  6. 选项按钮：使用四个`<g>`组，每个包含`<rect>`和`<text>`，步骤5时整体显示，并通过填充色区分B选项与其他选项。
  7. 事件绑定：上一步/下一步按钮绑定`click`事件，修改currentStep后调用updateScene()；同时更新步骤指示器文本。
  8. 边界处理：currentStep限制在0~5范围，上一步在0时禁用，下一步在5时禁用（或循环，建议禁用）。
  9. 动画曲线：无需复杂动画，步骤切换使用即时显隐；如需柔和过渡，可在CSS中为相关元素添加`transition: opacity 0.3s ease`。
- ID命名规范：所有SVG元素及JS变量均以`scene1-`为前缀。例如：`scene1-tri-abc`、`scene1-segment-ab`、`scene1-segment-de`、`scene1-label-ab`、`scene1-angle-a`、`scene1-rightangle-c`、`scene1-step2-group`、`scene1-formula-line1`、`scene1-option-b`等。JS中严格使用`document.getElementById()`获取元素，禁止全局class选择器，避免多场景合并时跨场景污染。
- IIFE隔离：所有JavaScript代码包裹在`(function() { ... })();`中，变量与函数不暴露到全局作用域。
