[图示主题与整合说明]
- 本图示主题：半圆旋转与阴影面积的等价转化
- 整合的步骤/概念：原半圆初始状态 → 绕点B顺时针旋转45°的动态过程 → 阴影区域识别 → 面积等量关系推导（S阴影=S扇形ABA′） → 扇形面积公式计算
- 教学价值：教师通过分步导航精确控制每一步的视觉呈现，引导学生从直观旋转操作逐步过渡到代数化面积转化，最终理解"等积代换"的核心思想。

[分步序列]
- 步骤0（初始）：显示原半圆轮廓（蓝）、直径AB（蓝）、点A与点B标签、AB=4长度标注。旋转后半圆、A′、轨迹、角度均隐藏。原半圆无填充。
- 步骤1（旋转）：点击「下一步」→ 显示灰色虚线轨迹弧（A绕B旋转到A′的圆弧）、红色旋转后半圆轮廓（以A′B为直径）、红色直径A′B、A′点标签、A′B=4标注、B点处45°角度弧及"45°"文本。视觉呈现两半圆的位置关系。
- 步骤2（阴影）：点击「下一步」→ 旋转后半圆填充rgba(198,40,40,0.2)（红色半透明），原半圆填充white（白色）。由于原半圆在SVG上层，重叠区域被白色覆盖，仅露出旋转后半圆与原半圆的非重叠部分（阴影区域）。阴影区域以红色半透明高亮。
- 步骤3（转化）：点击「下一步」→ 扇形ABA′以绿色半透明rgba(46,125,50,0.2)填充显示（位于最底层）。在原半圆内标注S₁，旋转后半圆内标注S₂，两半圆之间上方标注S₁=S₂。在阴影区标注S阴影，扇形区内标注S扇形，重叠区标注S重叠。右侧显示推导等式：
  S阴影 + S重叠 = S半圆′
  S扇形 + S重叠 = S半圆
  ∵ S半圆 = S半圆′
  ∴ S阴影 = S扇形ABA′
- 步骤4（计算）：点击「下一步」→ 扇形ABA′轮廓加粗（stroke="#2e7d32" stroke-width="3"），在扇形半径BA′旁标注"R=4"（位置约(360,240)）。右侧显示计算公式 S = (45/360)·π·4² = 2π，答案"2π"以绿色24px加粗高亮。教师可随时点击「上一步」回退复习。

[交互方案]

  1. 「◀ 上一步」按钮：位置(250,460)，大小100×30，点击回退到上一步骤，步骤0时禁用。
  2. 「下一步 ▶」按钮：位置(450,460)，大小100×30，点击前进到下一步，步骤4时禁用。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript（无需外部库）。原因：本题为纯几何图形与分步状态切换，SVG路径、填充、显示/隐藏操作原生API完全足够，引入D3等库反而增加复杂度。
- 画布尺寸：800 × 500 px（SVG viewBox="0 0 800 500"）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  公式/推导区(右上)                                |
  |                                                  |
  |        A′(280,150)                               |
  |         /\                                       |
  |        /  \  旋转后半圆(红)                       |
  |       /    \                                     |
  |      /  S₂  \                                    |
  |     /        \                                   |
  |    /    扇形  \                                  |
  |   /   (绿色)   \                                 |
  |  /              \                                |
  | A(210,350)------B(450,350)                       |
  |   原半圆(蓝)      \                              |
  |                    \ 45°                         |
  |                     \                            |
  +--------------------------------------------------+
  |  [◀ 上一步]    步骤 k/5    [下一步 ▶]           |  y=440~490
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：变量 `let currentStep = 0;`（范围0~4）。每步用一个配置对象定义各元素的 `display`/`opacity`/`fill`/`stroke` 状态。
  2. 绘制顺序（SVG中从先到后，即底层到顶层）：扇形(path) → 旋转后半圆(path) → 原半圆(path) → 所有线段/弧/标签(text)。此顺序确保步骤2中白色原半圆能遮盖旋转后半圆的重叠区，露出阴影。
  3. 路径数据（d属性）：
     - 原半圆：M 210 350 A 120 120 0 0 0 450 350 Z（sweep-flag=0，SVG y向下时经过视觉上方）
     - 旋转后半圆：M 280 150 A 120 120 0 0 1 450 320 Z（sweep-flag=1，经过右上方）
     - 扇形：M 450 350 L 210 350 A 240 240 0 0 1 280 150 Z
     - 轨迹弧：M 210 350 A 240 240 0 0 1 280 150
     - 角度弧：以B(450,350)为圆心，半径35，从BA方向(180°)到BA′方向(225°)的短弧，使用A命令绘制。
  4. 动画曲线：步骤1中A′的出现可添加简单CSS transition（opacity 0.3s ease），轨迹弧使用stroke-dasharray动画（1s内从虚线变为实线再恢复虚线，或直接用opacity淡入）。
  5. 事件绑定：按钮绑定click事件，调用 `goToStep(n)` 函数，该函数遍历所有受控元素，根据目标步骤设置属性。
  6. 步骤切换逻辑：
     ```javascript
     const steps = [
       // step0: 仅显示原半圆、AB、A、B、AB=4
       // step1: +轨迹、旋转后半圆、A′B、A′、A′B=4、45°
       // step2: +旋转后半圆fill红色半透明、原半圆fill白色
       // step3: +扇形fill绿色半透明、所有面积符号、推导文字
       // step4: +扇形stroke加粗、计算公式、答案高亮
     ];
     ```
  7. 禁用状态：步骤0时「上一步」disabled=true，步骤4时「下一步」disabled=true。
- ID命名规范：所有交互元素ID必须以 `scene1-` 为前缀。例如：`scene1-semicircle-original`、`scene1-semicircle-rotated`、`scene1-sector`、`scene1-line-ab`、`scene1-line-apb`、`scene1-arc-trace`、`scene1-angle-arc`、`scene1-label-a`、`scene1-label-b`、`scene1-label-ap`、`scene1-text-ab4`、`scene1-text-apb4`、`scene1-text-angle`、`scene1-text-s1`、`scene1-text-s2`、`scene1-text-seq`、`scene1-text-shadow`、`scene1-text-sector`、`scene1-text-overlap`、`scene1-formula-derive`、`scene1-formula-calc`、`scene1-answer`、`scene1-btn-prev`、`scene1-btn-next`、`scene1-step-indicator`。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免多场景合并时的全局变量污染。
