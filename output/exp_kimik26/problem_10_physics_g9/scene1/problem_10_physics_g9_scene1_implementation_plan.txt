[图示主题与整合说明]
- 本图示主题：圆台容器正反放置的液体体积差异与密度关系
- 整合的步骤/概念：容器几何特征 → 相同深度下的液体体积对比 → 密度公式推导 → 结论①（ρ₁＞ρ₂）
- 教学价值：教师通过分步控制，引导学生先观察形状差异，再直观比较液体体积，最后利用密度公式完成推导。图示将运动学量（F₁、F₂、v、2v）灰色淡化处理，避免干扰本场景核心目标。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  * 「上一步」按钮：位于 (280, 455)，宽90高32，点击回退到上一状态
  * 「下一步」按钮：位于 (430, 455)，宽90高32，点击推进到下一状态
  * 步骤指示器：位于 (400, 472)，显示当前步骤如 "步骤 1/4"
- 教师操作流程：
  1. 教师展示步骤0，说明题目条件（质量相同、深度相同、容器相同但放置方式相反）
  2. 点击「下一步」进入步骤1，引导学生观察液体占据空间的大小差异
  3. 点击「下一步」进入步骤2，给出体积关系 V₁<V₂ 并引入密度公式，强调m相同
  4. 点击「下一步」进入步骤3，完成 ρ₁>ρ₂ 推导，标记结论①正确
  5. 可随时点击「上一步」回退复习

[技术实现]
- JS 库选择：原生 SVG（通过 JavaScript 操作 DOM 属性），无需外部库。理由：本场景为静态几何图形与分步显隐，SVG 多边形、路径、文本即可满足，轻量且精确。
- 画布尺寸：800 × 500 px（SVG viewBox="0 0 800 500"）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  v ←        2v ←                                 |  y=170
  |    ┌──────────┐      ┌──┐                        |  y=200
  |    │          │      │  │                        |
  |  m │   ρ₁     │      │  │ m                     |  y=235
  |    │  ┌────┐  │      │  │                       |  y=250
  |    │  │液体│  │      │  │                       |
  |  h │  │    │  │      │  │    F₂ →              |  y=300
  |  ↑ │  └────┘  │      │  │                       |
  |    └──────────┘      └──┘    F₁ →              |  y=350
  |  桌面~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~    |
  |         V₁              V₂                       |  y=375
  |              V₁ < V₂                             |
  |                        [ ρ = m / V ]             |  y=385
  |                        ① ρ₁ > ρ₂ ✓             |  y=430
  |                                                  |
  |        [◀上一步]  步骤 1/4  [下一步▶]           |  y=455
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 `currentStep`（0~3）控制四步状态，每步定义显隐元素列表，避免逐个硬编码。
  2. 元素显隐：所有可能变化的 SVG 元素初始设置 `display:none` 或 `opacity:0`，根据 `currentStep` 切换。液体高亮通过修改 `fill-opacity` 和 `stroke-width` 实现。
  3. 动画曲线：步骤切换时，新增元素使用 200ms 的 opacity 淡入（CSS transition 或 JS requestAnimationFrame），液体高亮使用 300ms 的 fill-opacity 过渡，提升视觉流畅感。
  4. 事件绑定：上一步/下一步按钮绑定 click 事件，更新 `currentStep` 后调用 `renderStep()` 统一渲染。
  5. 按钮边界：步骤0 时禁用「上一步」，步骤3 时禁用「下一步」。
- ID 命名规范：所有 SVG 元素及控件 ID 必须以 `scene1-` 为前缀，例如 `scene1-container-left`、`scene1-liquid-left`、`scene1-btn-next`、`scene1-step-indicator`。JS 中严格使用 `document.getElementById` 获取元素，禁止全局 class 查询，避免多场景合并时跨场景污染。
- IIFE 隔离：所有 JavaScript 代码包裹在 `(function() { ... })()` 立即执行函数中，内部变量不泄露全局作用域。
- 坐标计算说明：液体液面宽度通过线性插值计算。左侧容器上底140下底80高150，液面在 y=250（距底部100），液面宽 = 80 + (140-80)*(100/150) = 120；右侧容器上底80下底140高150，液面宽 = 140 - (140-80)*(100/150) = 100。液体多边形顶点据此确定。
