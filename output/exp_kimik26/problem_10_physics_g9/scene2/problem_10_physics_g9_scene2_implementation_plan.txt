[图示主题与整合说明]
- 本图示主题：水平方向受力平衡与滑动摩擦力的决定因素（结论②）
- 整合的步骤/概念：
  1) 两容器总质量相同 → 总重力 G₁=G₂ → 桌面支持力 F_N₁=F_N₂；
  2) 滑动摩擦力 f=μF_N，μ 与 F_N 均相同 → f₁=f₂，且与速度无关；
  3) 匀速直线运动 → 水平方向二力平衡 F=f → F₁=F₂。
- 教学价值：教师通过分步导航，先建立竖直方向力相等，再引入水平方向摩擦力，最后得出拉力相等，层层递进，避免一次性信息过载；右侧容器的 2v 在第二步被刻意淡化，强化“滑动摩擦力与速度无关”的物理观念。

[分步序列]
- 步骤0（初始状态）：显示桌面、两容器及液体、速度箭头 v 与 2v、拉力箭头 F₁ 与 F₂。此时仅呈现题目运动情景，等待教师开始讲解。
- 步骤1（竖直方向力）：点击「下一步」→ 出现重力箭头 G₁/G₂（黑色向下）和支持力箭头 F_N₁/F_N₂（黑色向上）；同时出现等式 G₁=G₂、F_N₁=F_N₂。教师可强调“总质量相同，故重力相等，支持力也相等”。
- 步骤2（水平方向摩擦力）：点击「下一步」→ 出现摩擦力箭头 f₁/f₂（红色向左）；出现公式 f₁=μF_N₁、f₂=μF_N₂ 及高亮等式 f₁=f₂（红色加粗）；出现气泡“滑动摩擦力与运动速度无关”；同时右侧速度标签 2v 及其箭头透明度降至 0.4（淡化处理）。教师可强调“μ 与 F_N 均相同，摩擦力相等，且与速度无关”。
- 步骤3（二力平衡结论）：点击「下一步」→ 出现平衡等式 F₁=f₁、F₂=f₂（绿色）；出现结论卡片“② F₁ = F₂ ✓”（绿色高亮）。教师可总结“匀速直线运动 → 拉力等于摩擦力 → F₁=F₂，结论②正确”。
- 教师可随时点击「上一步」回退至任意步骤复习。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）

  1. 「上一步」按钮：位于画布底部 x=300, y=455，宽 80×32。点击回退到上一分步，隐藏当前步新增元素。

- 教师操作流程：
  1. 教师打开图示，学生看到步骤0的两容器匀速运动情景；
  2. 教师点击「下一步」进入步骤1，讲解竖直方向重力与支持力相等；
  3. 再点击「下一步」进入步骤2，讲解摩擦力决定因素，并指出 2v 被淡化（与摩擦无关）；
  4. 再点击「下一步」进入步骤3，得出 F₁=F₂ 的结论②；
  5. 若学生有疑问，教师随时点击「上一步」回退复习。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无外部库）。理由：本场景为静态几何图形与箭头，SVG 的 <line>、<polygon>、<text>、<marker> 足以精确绘制；无需复杂数学计算或 3D 渲染。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图（ASCII）：
  ```
  +----------------------------------------------------------+
  | 800×500 画布                                              |
  |                                                          |
  |  f₁=μF_N₁    f₁=f₂    f₂=μF_N₂        ← 公式/等式(y135) |
  | +----------------------------------+                     |
  | |  滑动摩擦力与运动速度无关        |    ← 气泡(y170)     |
  | +----------------------------------+                     |
  |      ↗ v                ↗ 2v           ← 速度(y235)     |
  |    +------+            +------+                         |
  |   /  液体  \          /  液体  \       ← 容器(y250~350)  |
  |  |          |        |          |                       |
  |   \        /          \        /                        |
  |    +------+            +------+                         |
  |  ← f₁    → F₁      ← f₂    → F₂      ← 水平力(y290)    |
  |    ↑        ↑          ↑        ↑                       |
  |   G₁      F_N₁       G₂      F_N₂    ← 竖直力(y325)    |
  |                                                          |
  |  G₁=G₂              F_N₁=F_N₂          ← 等式(y385)    |
  |  F₁=f₁              F₂=f₂              ← 平衡(y405)    |
  |                                                          |
  |       +-----------------------+                         |
  |       |    ② F₁ = F₂ ✓       |       ← 结论(y408)     |
  |       +-----------------------+                         |
  | ________________________________________________        |
  | \\\\ 桌面斜线阴影 ////////////////////////////////        |
  |                                                          |
  |      [上一步]   步骤 1/4   [下一步]    ← 控件(y455)     |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：变量 `currentStep` 取 0~3。`showStep(n)` 函数遍历所有分步元素，仅显示步骤 ≤ n 的元素；步骤 ≥ n+1 的元素隐藏。使用 CSS class `.active` 控制 opacity 0→1 过渡（transition: opacity 0.3s ease）。
  2. 箭头标记：在 SVG <defs> 中预定义三个 <marker>（scene2-arrow-black、scene2-arrow-blue、scene2-arrow-red），分别用于支持力/重力、拉力/速度、摩擦力。
  3. 2v 淡化：步骤2时通过 JS 将 `scene2-velocity-right-arrow` 与 `scene2-velocity-right-label` 的 opacity 设为 0.4；回退到步骤0/1 时恢复为 1.0。
  4. 事件绑定：`scene2-btn-prev` 与 `scene2-btn-next` 的 click 事件修改 `currentStep` 并调用 `showStep`；边界检查防止越界。
  5. 控件栏：使用一个绝对定位的 div 覆盖在 SVG 上方（pointer-events: none），按钮单独设置 pointer-events: auto，确保不额外撑高容器。
- **ID 命名规范**：所有 SVG 元素及控件 ID 必须以 `scene2-` 为前缀，例如 `scene2-container-left`、`scene2-force-f1-arrow`、`scene2-btn-prev`。JS 中统一使用 `document.getElementById` 获取，禁止 querySelectorAll 配合全局 class，避免多场景合并时跨场景污染。
- IIFE 隔离：所有 JavaScript 逻辑包裹在 `(function() { ... })();` 中，变量不泄露全局作用域。
