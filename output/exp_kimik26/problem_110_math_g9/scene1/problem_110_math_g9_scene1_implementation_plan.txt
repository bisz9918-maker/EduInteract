[图示主题与整合说明]
- 本图示主题：台球反弹入袋的角度推导与反射定律应用
- 整合的步骤/概念：题目条件展示 → 入射路径与法线标注 → 反射定律（∠1=∠2） → 角度互余关系（∠2+∠3=90°） → 联立求解（∠1=60°，选B）
- 教学价值：教师通过分步导航，逐步揭示几何要素，引导学生从直观图形过渡到形式化推导，理解反射定律在台球问题中的迁移应用。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「上一步」按钮：位于(280,460)，宽80高28。点击回退到上一状态，步骤0时禁用（opacity 0.3）。
  2. 「下一步」按钮：位于(440,460)，宽80高28。点击推进到下一状态，步骤4时禁用。
  3. 「重置」按钮：位于(680,460)，宽60高28。点击立即回到步骤0。
  4. 步骤指示器：位于(400,490)，显示"步骤 k/4"。
- 教师操作流程：
  1. 教师加载图示，默认步骤0，向学生展示题目条件（台球桌、两球位置、∠3=30°）。
  2. 点击「下一步」进入步骤1，讲解入射路径与法线，提问入射角∠1位置。
  3. 点击「下一步」进入步骤2，添加反射路径，引出反射定律∠1=∠2。
  4. 点击「下一步」进入步骤3，添加直角符号，引导学生发现∠2与∠3互余。
  5. 点击「下一步」进入步骤4，展示完整推导和答案B，总结解题思路。
  6. 可随时点击「上一步」回退复习，或「重置」从头开始。

[技术实现]
- JS库选择：原生 SVG + 原生 JavaScript。理由：本场景为静态几何图形与简单状态切换，无需复杂绘图库；SVG的marker、path、dasharray完美支持箭头、弧线、虚线。
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  标题区（无文字，纯图示）                           |
  |  +------------------------------------------+     |
  |  |  台球桌 (120,40)-(680,340)                |     |
  |  |  [白球]        O(撞击点)      [黑球] → 袋口 |     |
  |  |    ↖          |法线          ↗   ∠3=30°   |     |
  |  |      ↖      ∠1|∠2          ↗              |     |
  |  |        ↖      |          ↗                |     |
  |  +------------------------------------------+     |
  |       推导文字区 (y=375~435)                       |
  |  [◀上一步]  步骤 2/4  [下一步▶]        [重置]     |  <- 控件栏 y=450~490
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：变量 `let currentStep = 0;` 共5个状态（0~4）。每步一个配置对象，记录各元素ID的显隐、透明度、线宽。
  2. 元素显隐控制：使用 `setAttribute('display', 'none'/'inline')` 或 `style.opacity`。路径/弧线/标签分组管理。
  3. 箭头实现：SVG `<marker>` 定义 arrow-blue 和 arrow-red，分别用于蓝路径和红路径，viewBox="0 0 10 10"，refX="9"，避免箭头与端点重叠。
  4. 角度弧线：使用 `<path>` 画弧（A指令）+ `<path>` 画扇形填充（从圆心到弧两端）。∠1、∠2、∠3的弧线用不同半径避免重叠。
  5. 动画曲线：状态切换无复杂动画，直接瞬时切换（或可选0.2s CSS transition on opacity/stroke-width）。
  6. 事件绑定：按钮 `onclick` 绑定 `prevStep()` / `nextStep()` / `resetStep()`。
  7. 按钮禁用逻辑：步骤0时上一步禁用（`disabled=true`，样式变灰）；步骤4时下一步禁用。
- ID命名规范：所有交互元素ID必须以 `scene1-` 为前缀。例如：
  - `scene1-table-frame`
  - `scene1-cue-ball`
  - `scene1-black-ball`
  - `scene1-incident-path`
  - `scene1-reflect-path`
  - `scene1-target-path`
  - `scene1-normal-line`
  - `scene1-angle1-arc`
  - `scene1-angle1-label`
  - `scene1-angle2-arc`
  - `scene1-angle2-label`
  - `scene1-angle3-arc`
  - `scene1-angle3-label`
  - `scene1-right-angle`
  - `scene1-derive-text`
  - `scene1-prev-btn`
  - `scene1-next-btn`
  - `scene1-reset-btn`
  - `scene1-step-indicator`
  JS中严格使用 `document.getElementById('scene1-xxx')` 获取元素，禁止全局class选择器，避免多场景合并时跨场景污染。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，变量不泄露全局作用域。
