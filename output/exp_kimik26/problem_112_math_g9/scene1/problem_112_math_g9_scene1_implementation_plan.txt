[图示主题与整合说明]
- 本图示主题：三角形旋转中的角度关系推导（△OAB 绕 O 逆时针旋转 70° 至 △OCD）
- 整合的步骤/概念：题目条件展示 → 旋转角与对应边关系 → 全等性质与对应角相等 → △OAB 内角和计算 ∠AOB → 利用旋转角求 ∠AOD → 答案呈现
- 教学价值：教师通过「上一步/下一步」控制推导节奏，每步聚焦一个认知环节（旋转性质→全等→内角和→角度差），学生可跟随视觉高亮逐步理解几何逻辑

[交互方案]
- 交互类型：分步按钮导航（◀ 上一步 / 下一步 ▶）
- 控件说明：
  1. 「上一步」按钮：位于底部控件栏左侧，中心 (300, 465)，尺寸 100×35px。点击回退到上一推导步骤，步骤0时禁用（置灰）。
  2. 「下一步」按钮：位于底部控件栏右侧，中心 (500, 465)，尺寸 100×35px。点击前进到下一推导步骤，步骤4时禁用（置灰）。
  3. 步骤指示器：位于底部控件栏居中，(400, 490)，显示当前步骤编号如 "步骤 1/5"。
- 教师操作流程：
  1. 教师加载图示，向学生展示题目图形（步骤0），说明已知条件。
  2. 点击「下一步」进入步骤1，讲解旋转角相等与对应边相等。
  3. 点击「下一步」进入步骤2，讲解全等三角形对应角相等，得出 ∠B=50°。
  4. 点击「下一步」进入步骤3，在△OAB中利用内角和计算 ∠AOB=30°，观察蓝色填充区域。
  5. 点击「下一步」进入步骤4，通过角度差计算 ∠AOD=40°，观察红色填充区域，确认答案为 C。
  6. 可随时点击「上一步」回退复习，形成闭环讲解。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无需外部库）。理由：本场景为纯几何图形（线段、圆弧、扇形、文本），SVG 原生元素完全覆盖；状态切换逻辑简单，原生 JS 即可高效管理。
- 画布尺寸：800 × 500 px（固定），控件栏位于 SVG 内底部 y=440~490 区域，使用绝对定位覆盖，不撑高容器。
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------------+
  |  公式/提示区(左)        几何图形区(中右)                 |
  |  (20,120)              O●-----------------------●B      |
  |                        |\                     /        |
  |                        | \                   /         |
  |                        |  \                 /          |
  |                        |   \    △OAB       /           |
  |                        |    \   (蓝色)     /            |
  |                        |     \           /             |
  |                        |      \         /              |
  |                        C●------\-------●D              |
  |                          \      \     /                |
  |                           \      \   /                 |
  |                            \  △OCD \ /                  |
  |                             \(红色) ●A                  |
  |                                                        |
  |                                        答案:C.40°(右下)|
  +--------------------------------------------------------+
  | [控件栏 y=440~490]  [◀上一步]  步骤 1/5  [下一步▶]     |
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `currentStep`（0~4），每个步骤对应一个 `<g id="scene1-step-k">` 分组。切换步骤时，通过添加/移除 CSS class（如 `.visible` / `.hidden`）控制 `opacity` 和 `pointer-events`，配合 `transition: opacity 0.3s ease` 实现淡入淡出。
  2. 扇形填充绘制：使用 SVG `<path>` 的 `d="M x0 y0 L x1 y1 A rx ry 0 0 1 x2 y2 Z"` 绘制扇形。角度填充区域与弧线标注使用不同半径层（小半径0~55px用于∠AOB/∠AOD，中半径60~80px用于∠BOD，大半径80~110px用于∠AOC），避免重叠遮挡。
  3. 弧线箭头：使用 `<path>` 的 `d` 属性绘制圆弧，末端添加 `<polygon>` 箭头；箭头方向通过计算弧线终点切线角度确定。
  4. 等长 tick 标记：计算边线单位法向量，在距顶点约50~60px处绘制8px垂直短线。
  5. 按钮状态管理：步骤0时「上一步」置灰（disabled + opacity 0.4），步骤4时「下一步」置灰；步骤指示器文本随 `currentStep` 动态更新。
  6. 坐标计算：O点固定为旋转中心，其余顶点通过极坐标计算（O + 长度×(cosθ, sinθ)），确保旋转几何关系严格正确（OA=OC=250px，OB=OD=240px，旋转角70°）。
  7. 动画曲线：所有显隐过渡使用 CSS `transition: opacity 0.3s ease-in-out`，无复杂动画，保证课堂讲解的即时响应。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀。例如：
  - 三角形分组：`scene1-tri-oab`、`scene1-tri-ocd`
  - 角度弧线：`scene1-arc-a`、`scene1-arc-aoc`、`scene1-arc-aob`、`scene1-arc-aod`
  - 步骤分组：`scene1-step-0` ~ `scene1-step-4`
  - 按钮：`scene1-btn-prev`、`scene1-btn-next`
  - 标签：`scene1-label-o`、`scene1-label-angle-a` 等
  - JS 中严格使用 `document.getElementById` 获取元素，禁止全局 class 选择器，避免多场景合并时跨场景污染。
- IIFE 隔离：所有 JavaScript 代码包裹在 `(function() { ... })()` 立即执行函数中，内部变量不污染全局作用域。
