[分步序列]
- 初始状态（步骤0）「原题图示」：显示极点O、经线OP(到220,280)、经线OQ、纬线L(圆心400,120)、P点(220,280)红、Q点(580,280)蓝、标签O/L/P/Q、P旁标注"45°"、Q旁标注"15°E"。无额外元素，帮助学生读图识题。
- 步骤1「方向判断规则」：在步骤0基础上，新增地球自转方向箭头（绿色逆时针弧线在O上方，半径50），标签"顺自转方向为东"(400,30)、"东"(460,55)、"西"(330,55)。建立"顺自转方向为东，逆为西"的基准。
- 步骤2「第4题：经度差30°」：P点沿纬线向西移动至(400,280)（15°W位置），经线OP重绘为垂直线，纬线L变为圆心(490,120)的圆弧；P旁标注变为"15°W"（红色）；叠加0°经线(400,80)-(480,360，灰色虚线)和20°W经线(400,80)-(380,360，绿色虚线)；东半球区域浅蓝填充（20°W右侧四边形）；高亮显示P(15°W)和Q(15°E)均位于20°W以东（东半球），右侧标注B选项"P、Q两点都位于东半球"为正确（蓝色边框），D选项"P点在Q点的正东方"打×（红色删除线，因P在Q正西方）。
- 步骤3「第5题：经度差60°」：P点恢复至(220,280)（45°W位置），经线OP恢复斜线，纬线L恢复圆心(400,120)；P旁标注变为"45°W"（红色）；保持20°W界线；西半球区域浅红填充（20°W左侧三角形）；显示P(45°W)位于20°W以西（西半球），Q(15°E)位于东半球；右侧标注A选项"P点位于西半球，Q点位于东半球"为正确（蓝色边框）。
- 步骤4「总结对比」：显示完整图示（P在45°W，Q在15°E，20°W界线，0°经线，160°E经线）；底部标注东西半球范围公式"东半球：20°W→0°→160°E"；右侧并排提示两题结论（第4题选B，第5题选A），强化20°W界线的划分作用。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  1. 「上一步」按钮：位置(280,455)，宽80高30，点击回退到上一状态
  2. 「步骤指示器」：位置(400,475)，显示当前步骤如"步骤 2/5"
  3. 「下一步」按钮：位置(440,455)，宽80高30，点击进入下一状态
- 教师操作流程：
  1. 教师展示步骤0，让学生观察原图并识别O、L、P、Q及已知经度
  2. 点击「下一步」进入步骤1，讲解北极自转方向（逆时针）与方向判断规则
  3. 点击「下一步」进入步骤2，讲解第4题：P西移至15°W，引入20°W界线，观察P、Q均在东半球，确认B正确、D错误
  4. 点击「下一步」进入步骤3，讲解第5题：P恢复45°W，观察P在西半球、Q在东半球，确认A正确
  5. 点击「下一步」进入步骤4，总结东西半球划分公式，对比两题结论
  6. 可随时点击「上一步」回退复习关键概念（如20°W界线的位置、方向判断规则）

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：本场景为静态几何图示与分步状态切换，无需复杂数据绑定或3D渲染，原生SVG可精确控制每个几何元素和标签的显隐/属性，避免引入不必要库体积。
- 画布尺寸：800×500 px（SVG viewBox="0 0 800 500"）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  [顺自转方向为东]  (步骤1)                        |
  |       [西]  ←↺  [东]   自转箭头(步骤1)            |
  |         O(极点)                                   |
  |        / \                                       |
  |       /   \   经线OP    经线OQ                   |
  |      /     \                                      |
  |   L /       \                                     |
  |    P---------Q   纬线L(圆弧)                      |
  |   /|         |\                                   |
  |  / |  东半球  | \  选项标注(步骤2-3)               |
  | /  | (步骤2) |  \                                |
  |/   |         |   \                               |
  |   20°W      0°    160°E  辅助经线(步骤2-4)        |
  |   [西半球(步骤3)]                                 |
  |              [东半球：20°W→0°→160°E] (步骤4)      |
  |                                                  |
  |       [上一步]  [步骤 X/5]  [下一步]              |
  +--------------------------------------------------+
  控件栏在 y=455~485（SVG内底部）
  ```
- 关键实现要点：
  1. 状态机设计：定义全局变量 `currentStep`（0~4），数组 `stepConfigs` 描述每步显隐的元素ID列表。每次切换步骤时，遍历所有元素，根据当前步骤配置设置 `display` 或 `visibility`。
  2. P点移动与纬线切换：步骤2中P点从(220,280)变为(400,280)，同时经线OP从斜线变垂直线，纬线圆弧圆心从(400,120)变为(490,120)。通过预先定义两组SVG元素（op-line-original / op-line-step2 / arc-original / arc-step2），按步骤显隐对应组，避免运行时复杂计算。
  3. 选项标注：步骤2显示B（正确）和D×（错误），步骤3显示A（正确）。使用绝对定位的`<text>`或`<g>`元素，步骤切换时显隐。
  4. 半球填充：使用`<polygon>`元素，步骤2显示东半球浅蓝填充，步骤3显示西半球浅红填充，步骤4可同时显示两者或隐藏填充以突出公式。
  5. 动画曲线：状态切换不使用动画（或仅用100ms淡入淡出），确保教师控制节奏时响应即时；若需强调P点移动，可在步骤0→1→2过渡时用200ms透明度渐变。
  6. 事件绑定：上一步/下一步按钮绑定click事件，更新currentStep后调用renderStep()重绘。按钮在步骤0禁用「上一步」，步骤4禁用「下一步」。
- ID命名规范：所有交互元素ID必须以 `scene1-` 为前缀。例如：
  - 极点：`scene1-pole-o`
  - P点：`scene1-point-p`
  - Q点：`scene1-point-q`
  - 经线OP原线：`scene1-meridian-op-original`
  - 经线OP步骤2：`scene1-meridian-op-step2`
  - 纬线原弧：`scene1-arc-l-original`
  - 纬线步骤2弧：`scene1-arc-l-step2`
  - 自转箭头：`scene1-rotation-arrow`
  - 20°W经线：`scene1-meridian-20w`
  - 0°经线：`scene1-meridian-0`
  - 160°E经线：`scene1-meridian-160e`
  - 东半球填充：`scene1-fill-eastern`
  - 西半球填充：`scene1-fill-western`
  - 选项B：`scene1-option-b`
  - 选项D：`scene1-option-d`
  - 选项A：`scene1-option-a`
  - 上一步按钮：`scene1-btn-prev`
  - 下一步按钮：`scene1-btn-next`
  - 步骤指示器：`scene1-step-indicator`
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })()` 中，避免全局命名空间污染，确保多场景合并时互不干扰。
