[图示主题与整合说明]
- 本图示主题：极地投影图的综合判读与应用（自转方向·经纬定位·半球划分·太阳直射）
- 整合的步骤/概念：
  1. 地球自转方向与南北极判断（北逆南顺）；
  2. 南北半球位置判断（选项 C 分析）；
  3. 极地投影图经度判读（0°/180° 定位，自转方向定东西经）；
  4. 东西半球划分与 A、B 点半球归属（选项 D 分析）；
  5. 纬度判读与太阳直射范围（选项 A、B 分析）；
  6. 四个选项正误总结。
- 教学价值：教师通过分步导航，可严格遵循"先定南北→再定坐标→最后综合"的认知递进，精准控制每一步呈现时机，随时回退复习，适合课堂多步骤推导讲解。

[分步序列]
- 初始状态（步骤0）：显示左右双图完整框架（3同心圆+8经线），仅显示0°、180°标注、自转方向箭头（黑色）、A/B点（黑色圆点），底部列出A-D四个选项（无标记）。其余标注隐藏。
- 步骤1（自转方向与南北极）：点击「下一步」→ 左图逆时针箭头加粗变蓝(#1565c0)，添加蓝色"北极（北半球）"标签(200,45)；右图顺时针箭头加粗变绿(#2e7d32)，添加绿色"南极（南半球）"标签(600,45)。
- 步骤2（南北半球判断）：点击「下一步」→ A点圆点变蓝并放大（半径4→6px），添加蓝色"北半球"标签(120,100)；B点圆点变绿并放大，添加绿色"南半球"标签(680,260)；选项C左侧出现绿色对勾图标，提示可直接锁定答案。
- 步骤3（经度判读）：点击「下一步」→ 左右两图所有8条经线外侧标注度数（45°间隔），东经标注用蓝色、西经标注用绿色；左图A点旁标注"135°W"(120,145)，右图B点旁标注"45°W"(665,240)。
- 步骤4（东西半球划分）：点击「下一步」→ 两图上用#888888虚线画出20°W与160°E经线弧段，标注"东半球"(左150,100/右550,100)和"西半球"(左250,100/右650,100)区域；A(135°W)与B(45°W)均落在西半球；选项D左侧出现红色叉号（因D说"A在东半球"错误）。
- 步骤5（纬度与太阳直射）：点击「下一步」→ 标注纬线度数"45°N"(265,125)、"45°S"(535,235)、"赤道"(320,295)/(680,295)；两图内侧（赤道至23.5°纬线间）显示黄色半透明直射带；底部添加说明"太阳直射范围：23.5°N—23.5°S"；选项A、B左侧出现红色叉号（A/B均无直射）。
- 步骤6（总结）：点击「下一步」→ 四个选项最终标记完整（仅C为绿色对勾，A/B/D为红色叉号）；左下角显示总结口诀："判读口诀：①北逆南顺定极点 ②自转方向定东西 ③20°W-160°E分东西半球 ④回归线之间有直射"。
- 教师可随时点击「上一步」回退复习，步骤指示器实时更新。

- 控件说明：
  - 「◀ 上一步」按钮：位置(300,455)，宽90×高32，点击回退到上一步骤，步骤0时禁用

  2. 点击「下一步」进入步骤1，讲解"北逆南顺"规律；
  3. 继续点击「下一步」依次推进，每步聚焦一个知识点；

  5. 步骤6总结时，四个选项标记一目了然，配合口诀强化记忆。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript（无需外部库）。理由：本场景以静态几何图形和标签为主，无复杂函数图或3D，原生SVG足够；状态切换通过CSS class控制display/opacity，简单高效。
- 画布尺寸：800 × 500 px（SVG），控件栏在SVG内底部y=440~490区域，使用HTML按钮position:absolute叠在SVG上方。
- 布局草图（ASCII）：
  ```
  [标题区 y=0-30]
     北极俯视图（逆时针）          南极俯视图（顺时针）
  
  [主图区 y=30-310]
     ┌─────────────┐              ┌─────────────┐
     │   北极      │              │   南极      │
     │  ○ 经线网   │              │  ○ 经线网   │
     │  ●A        │              │  ●B        │
     │  ↺ 自转    │              │  ↻ 自转    │
     └─────────────┘              └─────────────┘
  
  [选项/辅助区 y=310-440]
     ✓ A. ...
     ✗ B. ...
     ✓ C. ...
     ✗ D. ...
     [步骤6口诀文字]
  
  [控件栏 y=440-500]
        ◀ 上一步   步骤 2/6   下一步 ▶
  ```
- 关键实现要点：
  1. 状态机设计：变量 `let currentStep = 0;` 范围0-6，每次点击按钮时更新，调用 `renderStep()` 函数。
  2. 元素分组：将每步新增元素分别包裹在 `<g id="scene1-step-X">` 中（X=1..6），通过CSS类 `.hidden { display: none; }` 控制显示/隐藏。步骤0的基础元素始终显示。
  3. 高亮切换：步骤1-2的箭头/点高亮通过切换stroke-width和stroke-color实现（如从#000到#1565c0），使用CSS transition: all 0.3s ease。
  4. 选项标记：对勾/叉号用SVG `<text>` 或 `<path>` 绘制（对勾用✓字符，叉号用✗字符），初始隐藏，对应步骤时显示。
  5. 太阳直射带：用SVG `<path>` 画环形扇区（或两个arc组成），fill="#ffeb3b", fill-opacity="0.2"。
  6. 经线标注：步骤3一次性显示16个text标签（每图8个），预先定义在SVG中，默认隐藏。
  7. 事件绑定：上一步/下一步按钮绑定click事件，更新currentStep后调用renderStep()，同时更新按钮disabled状态和步骤指示器文本。
  8. 步骤6布局微调：当进入步骤6时，通过JS动态调整选项区y坐标（整体上移或口诀放在左侧空白区），避免口诀与选项重叠。具体：口诀放在左图正下方偏左(50,310)，选项保持原位置，因口诀宽度350px不侵入选项x范围。
- ID命名规范：所有交互元素ID必须以 `scene1-` 为前缀。例如：
  - `scene1-map-north`（左图容器）
  - `scene1-map-south`（右图容器）
  - `scene1-point-a`（A点圆点）
  - `scene1-point-b`（B点圆点）
  - `scene1-arrow-north`（左图自转箭头）
  - `scene1-arrow-south`（右图自转箭头）
  - `scene1-option-a` ~ `scene1-option-d`（选项文字）
  - `scene1-mark-a` ~ `scene1-mark-d`（选项对勾/叉号）
  - `scene1-btn-prev`、`scene1-btn-next`、`scene1-step-indicator`
  - `scene1-step-1` ~ `scene1-step-6`（每步元素组）
  - JS中严格使用 `document.getElementById('scene1-xxx')` 获取元素，禁止querySelectorAll配合全局class。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免多场景合并时变量污染。
- 动画曲线：元素出现使用 opacity 0→1，transition: opacity 0.3s ease；高亮颜色变化使用 transition: stroke 0.3s ease, stroke-width 0.3s ease。
