[图示主题与整合说明]
- 本图示主题：经纬网定位、方向判断与半球五带综合读图
- 整合的步骤/概念：
  1) 在标准经纬网中定位甲、乙、丙、丁、E、F六点；
  2) 利用经纬网判断E相对于F的方向（西南）；
  3) 东西半球划分（20°W与160°E界线）及图示区域所属半球；
  4) 五带划分（北寒带、北温带、热带）及典型特征；
  5) 综合条件定位（20°W与23.5°N交点→乙点）。
- 教学价值：教师可按"定位→方向→半球→五带→综合"的认知递进讲解，分步展示避免信息过载，每步聚焦单一知识模块，便于学生跟随。

[分步序列]
- 步骤0「基础定位」（初始状态）：
  显示完整经纬网、所有经纬度标注、甲/乙/丙/丁/E/F六点及其名称标签。右侧说明区显示六点坐标列表。教师可带领学生快速定位各点。

- 步骤1「方向判断」：
  点击「下一步」→ E点与F点外圈分别出现蓝色/红色描边（r=6）；从F(500,100)向下绘制灰色虚线至(500,190)，再向左绘制灰色虚线至E(380,190)，并在E侧加箭头；在折线中点上方显示蓝色结论"西南方向"。右侧说明区更新为E、F坐标及方向判断逻辑。教师可讲解"经线指南北、纬线指东西"的定向方法。

- 步骤2「东西半球」：
  点击「下一步」→ 隐藏步骤1的方向指引线；20°W经线加粗变为红色（3px）；20°W以东（x=140~520）覆盖蓝色半透明色块并标注"东半球"，20°W以西（x=80~140）覆盖红色半透明色块并标注"西半球"。右侧说明区更新为东西半球分界线及范围说明。教师可强调"20°W以东、160°E以西为东半球"。

- 步骤3「五带划分」：
  点击「下一步」→ 隐藏步骤2的半球色块；在网格上覆盖三条横向色带：北寒带（y=60~100，紫色）、北温带（y=100~190，绿色）、热带（y=190~370，橙黄）；并在各带中央标注特征"极昼极夜""四季变化明显""太阳直射"。右侧说明区更新为五带范围及特征。教师可对照纬线讲解回归线与极圈的意义。

- 步骤4「综合定位」：
  点击「下一步」→ 隐藏步骤3的五带色块与特征标签；同时高亮20°W经线（红色3px）与23.5°N纬线（绿色3px），乙点外圈出现绿色高亮圆环（r=10），并在乙点上方显示绿色结论"乙点（正确答案）"。右侧说明区更新为三个条件的逐条验证。教师可总结"20°W东侧东半球/西侧西半球、23.5°N北侧北温带/南侧热带"的交汇逻辑。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「◀ 上一步」按钮：位于(260,455)，宽90×高34，点击回退到上一分步，在步骤0时禁用（透明度降低）。
  2. 步骤指示器：位于(400,472)，显示当前步骤序号"步骤 1/5"（步骤0显示"基础定位"）。
  3. 「下一步 ▶」按钮：位于(470,455)，宽90×高34，点击前进到下一分步，在步骤4时变为"完成"或禁用。
- 教师操作流程：
  1. 教师打开图示，学生看到完整经纬网与六点定位（步骤0）；
  2. 教师点击「下一步」进入方向判断，讲解E在F的西南方向（步骤1）；
  3. 教师点击「下一步」进入东西半球，讲解20°W界线与半球范围（步骤2）；
  4. 教师点击「下一步」进入五带划分，讲解回归线、极圈与五带特征（步骤3）；
  5. 教师点击「下一步」进入综合定位，验证乙点满足全部三个条件（步骤4）；
  6. 可随时点击「上一步」回退复习。

[技术实现]
- JS库选择：原生SVG（简单几何与静态分步展示首选，无需引入外部库，减少依赖）
- 画布尺寸：800 × 500 px（固定画布，SVG viewBox="0 0 800 500"）
- 布局草图：
  ```
  +--------------------------------------------------+
  |          经纬网定位与半球五带综合读图               |  y=10~50
  |  +------------------------+  +----------------+  |
  |  |                        |  |  右侧说明区     |  |
  |  |      经纬网主图区       |  |  标题          |  |
  |  |  (x:80~520, y:60~400)  |  |  内容...       |  |
  |  |                        |  |                |  |
  |  |  虚线网格 + 六点标注    |  |  每步更新      |  |
  |  |                        |  |                |  |
  |  +------------------------+  +----------------+  |
  |       [◀ 上一步]  步骤 1/5  [下一步 ▶]          |  y=450~490
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `let currentStep = 0;` 控制0~4共5个状态。`updateStep(step)` 函数负责根据状态显隐对应SVG元素组（通过设置 `display` 或 `opacity`）。
  2. 元素分组：每个步骤的专属元素包在一个 `<g id="scene1-step{k}-group">` 中，步骤切换时统一控制该组的显隐，避免逐个操作DOM。
  3. 动画曲线：步骤切换时，新增元素使用CSS transition `opacity: 0→1` 持续300ms（ease-out），高亮线条使用CSS transition `stroke-width: 1.5→3` 持续300ms，保证视觉平滑。
  4. 事件绑定：按钮绑定 `click` 事件，调用 `prevStep()` / `nextStep()`，内部做边界检查（0与4）并更新按钮禁用状态。
  5. 右侧说明区：使用一个 `<foreignObject>` 或 `<text>` 组，每步替换内部HTML或text内容；建议用 `<foreignObject x="540" y="60" width="240" height="340">` 内嵌HTML段落，便于多行排版。
  6. 点高亮：通过给对应 `<circle>` 添加/移除CSS类（如 `.highlight-blue { stroke: #1565c0; stroke-width: 2px; r: 6; }`）实现，利用CSS transition过渡。
- ID命名规范：所有交互元素ID必须以 `scene1-` 为前缀。例如：
  - 网格组：`scene1-grid-group`
  - 点甲：`scene1-point-jia`
  - 步骤1组：`scene1-step1-group`
  - 步骤2 20°W高亮线：`scene1-step2-line-20w`
  - 按钮：`scene1-btn-prev`、`scene1-btn-next`
  - 说明区：`scene1-info-panel`
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免全局变量污染，确保多场景合并时互不干扰。
- 坐标计算：经纬线位置使用固定像素坐标（经线x: 140/260/380/500；纬线y: 100/190/280/370），不采用动态计算，保证代码agent可直接硬编码实现。
