[图示主题与整合说明]
- 本图示主题：极地经纬网图中A、B两点相对方位判读
- 整合的步骤/概念：①极地投影图基本特征识别（北极/经度排列/纬度分布）；②A、B两点经纬度定位；③南北方向判断（纬度比较）；④东西方向判断（结合地球自转方向与经度比较）；⑤十字方向标综合得出"西南"结论
- 教学价值：教师通过分步导航控制课堂节奏，可随时回退至东西方向判定这一易错环节进行强化讲解。图示将抽象的方位判读拆解为可视化的逻辑链，降低学生认知负荷。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：本场景为静态几何图示与分步状态切换，无需复杂数学计算或数据可视化，原生SVG足以高效绘制网格、箭头、弧线，且文件体积小、渲染快。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------------+
  |  140°  经度标注        极地投影网格          60° 纬度标注 |
  |  160°  (左侧)      +---------------+        40°  (右侧) |
  |  180°              |  B ●          |        20°        |
  |  160°W             |    ↗ 网格线   |                   |
  |  140°W             |       ↘       |   A(160°E,20°N)   |
  |  120°W             |  A ●          |   B(170°E,60°N)   |
  |                    +---------------+   说明文字...      |
  |  [地球自转弧]                                          |
  |                                                        |
  |              [◀ 上一步]  [步骤 X/6]  [下一步 ▶]         |
  +--------------------------------------------------------+
  控件栏位于 y=440~490（SVG内绝对定位）
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `currentStep`（0~5），每次点击按钮增减，调用 `renderStep()` 根据状态显隐/变色元素。
  2. 元素显隐：所有步骤专属元素初始 `display:none` 或 `opacity:0`，`renderStep()` 中通过 `setAttribute('display', 'block'/'none')` 或切换CSS class控制。
  3. 箭头绘制：使用SVG `<marker>` 定义箭头头部（红、蓝、绿三种），在 `<line>` 或 `<path>` 上引用。
  4. 地球自转弧：使用 `<path d="M195,140 A25,25 0 0,0 145,140" />`，配合 `<marker>` 在左端加箭头。
  5. 高亮切换：经线/纬线通过切换 `class` 改变 `stroke` 和 `stroke-dasharray`，避免重绘坐标。
  6. 动画曲线：状态切换无需复杂动画，直接显隐即可；如需平滑过渡，可对 `opacity` 做200ms CSS transition。
  7. 事件绑定：按钮绑定 `onclick`，在IIFE内部处理，避免全局污染。
- ID命名规范：所有交互元素ID必须以 `scene1-` 为前缀。例如：
  - 经线：`scene1-meridian-140e`、`scene1-meridian-160e` ...
  - 纬线：`scene1-parallel-60n`、`scene1-parallel-40n`、`scene1-parallel-20n`
  - 点：`scene1-point-a`、`scene1-point-b`
  - 箭头：`scene1-arrow-north`、`scene1-arrow-south`、`scene1-arrow-west`、`scene1-arrow-southwest`
  - 标签：`scene1-label-a`、`scene1-label-b`、`scene1-label-north` ...
  - 按钮：`scene1-btn-prev`、`scene1-btn-next`
  - 步骤指示器：`scene1-step-indicator`
  - 右侧说明文字：`scene1-note-step1`、`scene1-note-step2` ...
  JS中严格使用 `document.getElementById` 获取元素，禁止 `querySelectorAll` 配合全局class。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })()` 中，确保变量不泄漏到全局作用域，避免多场景合并时跨场景污染。
