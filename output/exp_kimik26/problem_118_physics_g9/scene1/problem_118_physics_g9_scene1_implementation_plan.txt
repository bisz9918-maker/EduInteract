[分步序列]
- 初始状态（步骤0）：显示完整电路图。所有基础元件可见：导线、电源(+-)、开关S、R₁及标签、R₂及标签、滑片P及标签、A及标签、V₁及标签与接线柱、V₂及标签与接线柱。无高亮、无测量标注、无动画。等待教师触发。
- 步骤1：点击「下一步」→ 电流路径高亮出现。沿导线绘制蓝色#1565c0粗线（线宽3px），覆盖：底部左段(360,300)→(250,300)、左侧(250,300)→(250,150)、顶部(250,150)→(550,150)、右侧(550,150)→(550,300)、底部右段(550,300)→(380,300)。5段导线中点各加一个蓝色箭头指示方向（左、上、右、下、左）。同时A右侧出现标注"测总电流I"(580,250)。
- 步骤2：点击「下一步」→ 电表测量对象标注出现。A右侧保持"测总电流I"(580,250)。V₁测量范围：R₂接入部分（左端到滑片P）用红色#c62828半透明填充(rect 320,140-430,160, opacity 0.15)，上方标注"U₁"(375,125)。V₂测量范围：电源外围用绿色#2e7d32虚线框(rect 350,280-390,320)，下方标注"U₂"(370,335)。
- 步骤3：点击「下一步」→ 滑片P向左滑动动画。滑片P从(430,150)平滑移动到(360,150)，耗时0.5s；P标签同步从(430,100)移至(360,100)；V₁右接线柱同步从(300,105)-(430,150)更新为(300,105)-(360,150)；R₂接入部分（左端到滑片新位置）用蓝色#1565c0填充(rect 320,140-360,160, opacity 0.2)；R₂未接入部分（滑片新位置到右端）改为灰色#888888虚线(360,150)-(500,150)；V₁测量范围红色填充同步缩短为(320,140)-(360,160)；顶部出现标注"R₂接入↓"(340,105)。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶ / 重置）
- 控件说明：
  1. 「上一步」按钮：位置(300,455)，宽80×高30。点击回退到上一分步，步骤0时禁用。
  2. 「下一步」按钮：位置(400,455)，宽80×高30。点击前进到下一分步，步骤4时禁用。
  3. 「重置」按钮：位置(500,455)，宽80×高30。点击回到步骤0初始状态。
  4. 步骤指示器：位置(400,485)，显示当前步骤文字如"步骤 1 / 5"。
- 教师操作流程：
  1. 教师展示步骤0，让学生识别电路元件和连接方式。
  2. 点击「下一步」进入步骤1，讲解电流从电源正极出发的完整回路，蓝色高亮辅助学生追踪路径。
  3. 点击「下一步」进入步骤2，讲解三个电表的测量对象，红色/绿色范围框明确V₁和V₂的测量区间。
  4. 点击「下一步」进入步骤3，播放滑片左移动画，观察接入电阻变短，强调"R₂接入↓"。
  5. 点击「下一步」进入步骤4，总结电表示数变化趋势：I↑、U₁↓、U₂不变。可随时点击「上一步」回退复习关键帧。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：电路图由简单几何形状（线段、矩形、圆圈、多边形）构成，无需复杂绘图库；分步状态切换通过显示/隐藏SVG元素实现，逻辑简单。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  V₁○                                              |
  |   /\                                              |
  |  /  \  R₂[========P=======]  ○A                   |
  | /    \                                            |
  |R₁      \                                          |
  | |       \                                         |
  | |        +-------------------+                    |
  | |                             |                   |
  | +----+  电源 +-  S            |                   |
  |      |                        |                   |
  |      V₂○                      |                   |
  |                                 |                   |
  |                                 |                   |
  |      [◀上一步] [下一步▶] [重置]  |  ← y=440~490 控件栏 |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：变量`currentStep`（0~4），`showStep(n)`函数根据步骤索引控制所有SVG元素的`display`或`visibility`属性。步骤3的滑片移动通过预定义两组坐标（初始/移动后），用CSS `transition`或SVG `<animate>`实现0.5s平滑动画。
  2. 坐标计算：滑片P移动距离70px（从x=430到x=360），P标签同步移动；V₁右接线柱终点同步更新；接入电阻填充矩形宽度从110px缩放到40px；未接入部分导线从实线变为灰色虚线。
  3. 动画曲线：滑片移动使用`ease-in-out`缓动函数，时长500ms，增强视觉流畅感。
  4. 事件绑定：三个按钮分别绑定`click`事件，调用`prevStep()`、`nextStep()`、`resetStep()`。每次状态变更后更新步骤指示器文字和按钮禁用状态。
  5. 电流路径高亮：步骤1使用5段独立`<path>`或`<line>`元素，设置`stroke="#1565c0" stroke-width="3"`，每段中点叠加`<polygon>`箭头。箭头方向通过旋转实现（左箭头point-left，上箭头point-up等）。
  6. 电表范围指示：V₁测量范围使用`<rect>`填充`fill="#c62828" fill-opacity="0.15"`；V₂测量范围使用`<rect>`设置`stroke="#2e7d32" stroke-dasharray="4,2" fill="none"`。
  7. 变化趋势箭头：步骤4的I↑/U₁↓使用`<line>`配`<marker>`箭头；U₂不变使用水平`<line>`。
- **ID命名规范**：所有交互元素ID必须以`scene1-`为前缀。例如：`scene1-wire-left`、`scene1-resistor-r1`、`scene1-ammeter-a`、`scene1-voltmeter-v1`、`scene1-slider-p`、`scene1-step1-current-path`、`scene1-step2-u1-fill`、`scene1-btn-prev`、`scene1-btn-next`、`scene1-btn-reset`。
- IIFE隔离：所有JavaScript代码包裹在`(function() { ... })();`中，避免多场景合并时的全局变量污染。
