    **题目原文**

    如图所示的电路中，闭合开关S，当滑动变阻器的滑片P向右滑动时（　　）

    A、灯L₁变亮，灯L₂变暗
    B、灯L₂变亮，灯L₁亮度不变
    C、灯L₁和L₂均变暗
    D、灯L₁亮度变化，灯L₂亮度不变

    **题目分析**

    本题是一道初中物理动态电路分析题，核心考查点包括：
    1. 电路结构的识别（串联与并联的判断）
    2. 滑动变阻器的工作原理及接入电阻的变化
    3. 并联电路的电压、电流特点
    4. 欧姆定律与电功率公式的综合应用

    解题的关键在于正确判断L₁、L₂与滑动变阻器的连接方式，明确各元件所在支路，再分别分析滑片移动对各支路的影响。

    **整体讲解思路**

    1. 先引导学生识别电路结构：电流从电源正极流出，在左侧节点分成两条支路，L₁单独在一条支路，L₂与滑动变阻器串联后在另一条支路，两条支路并联。
    2. 分析滑片P向右滑动时，滑动变阻器接入电路的电阻变化。
    3. 利用"并联支路互不影响"的特点，判断L₁亮度变化。
    4. 对L₂所在支路，用欧姆定律分析电流变化，再用功率公式判断亮度变化。
    5. 综合得出正确选项。

    **SCENE_1 教学说明：如何引导学生观察与分析**

    本图示通过分步导航将动态电路分析拆解为6个认知阶段，教师可按以下要点引导学生：

    1. **识图阶段（步骤0-1）**：先让学生独立观察电路图，尝试画出电流路径。很多学生会误认为L₁与L₂是串联关系，或误认为滑动变阻器在干路。通过步骤1的双色电流箭头，让学生亲眼看到电流"分叉"与"汇合"，从而确认并联结构。此时可提问："如果去掉L₁，L₂还能亮吗？"强化并联概念。

    2. **电阻变化阶段（步骤2）**：让学生关注滑动变阻器的接线方式。图中滑动变阻器左端与滑片P接入电路，当P向右滑动时，接入电路的电阻丝长度缩短，电阻减小。此处可配合手势模拟滑片移动，加深印象。关键要强调：判断的是"接入电阻"，不是滑动变阻器的"总电阻"。

    3. **L₁支路分析（步骤3）**：这是本题最容易得出正确判断的环节。利用并联电路"各支路两端电压相等且等于电源电压"的特点，直接得出L₁两端电压不变。结合功率公式 P₁ = U²/R₁，因为U和R₁都不变，所以P₁不变，亮度不变。此处要反复强调"并联支路互不影响"这一核心规律。

    4. **L₂支路分析（步骤4）**：这是本题的难点。引导学生按逻辑链推导：
       - 该支路总电阻 R总 = R变 + R_L₂
       - R变减小 → R总减小
       - 支路电压U不变（并联特点）→ 由欧姆定律 I₂ = U/R总 → I₂增大
       - 由功率公式 P₂ = I₂²·R_L₂ → P₂增大 → L₂变亮
       
       注意：此处不能用 P = U²/R 直接判断L₂功率，因为L₂两端电压 U_L₂ = I₂·R_L₂ 会随电流变化而变化，不是定值。必须用 P = I²R 或先求电流再求功率。

    5. **结论阶段（步骤5）**：综合两条支路的分析，得出"L₂变亮，L₁亮度不变"，对应选项B。此时可让学生回顾其他选项为何错误：
       - A错在认为L₁变亮（并联支路互不影响）
       - C错在认为L₁变暗（同理）
       - D错在认为L₁亮度变化且L₂不变（与事实相反）

    **关键公式回顾**

    - 欧姆定律：I = U/R
    - 电功率：P = UI = I²R = U²/R
    - 并联电路特点：U₁ = U₂ = U电源，I干 = I₁ + I₂
    </TEXT_2>

    **完整解答**

    1. 识别电路结构：闭合开关S后，电流从电源正极流出，在左侧节点分成两条支路。一条支路只有L₁；另一条支路为滑动变阻器与L₂串联。两条支路并联后回到电源负极。

    2. 判断电阻变化：滑片P向右滑动时，滑动变阻器接入电路的电阻丝长度变短，接入电阻R变减小。

    3. 分析L₁：由于并联电路各支路两端电压相等且等于电源电压，L₁两端电压U₁ = U电源，保持不变。根据 P₁ = U₁²/R₁，L₁的实际功率不变，因此**灯L₁亮度不变**。

    4. 分析L₂：L₂所在支路的总电阻 R总 = R变 + R_L₂，因R变减小而减小。该支路电压等于电源电压，根据欧姆定律 I₂ = U/R总，支路电流I₂增大。再根据 P₂ = I₂²·R_L₂，L₂的实际功率增大，因此**灯L₂变亮**。

    5. 结论：正确选项为 **B**。

    **课堂讲解建议**

    - **易错点提醒**：学生常犯的错误是把L₂两端电压当成不变（误以为可以用P=U²/R直接判断L₂功率）。要强调L₂与滑动变阻器串联，L₂两端电压只是支路电压的一部分，会随电流变化。
    - **拓展变式**：讲完原题后，可让学生思考——若滑片P向左滑动，结果如何？（答案：L₂变暗，L₁亮度不变。）若将L₁短路，两灯亮度如何变化？
    - **方法提炼**：总结动态电路分析"三步法"：①识结构（串/并联）→ ②判电阻（滑片移动方向）→ ③用规律（欧姆定律+功率公式）。
    - **板书配合**：建议在黑板上同步画出等效电路图（两并联支路），并写出L₂支路的推导链条：R变↓ → R总↓ → I₂↑ → P₂↑ → 变亮。
