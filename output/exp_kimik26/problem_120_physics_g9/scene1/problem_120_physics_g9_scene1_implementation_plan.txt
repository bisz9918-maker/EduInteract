# Scene 1 Implementation Plan

[图示主题与整合说明]
- 本图示主题：串联电路（电源-开关-灯泡-滑动变阻器-电流表）的三状态动态分析
- 整合的步骤/概念：
  ① 电路结构识别（元件布局、电流方向、电流表/电压表测量对象）；
  ② 左端极端状态（滑片P在a端，R_slide=0，电流最大，灯泡最亮）；
  ③ 右端极端状态（滑片P在b端，R_slide=R_max，I_min=0.2A，U_vmax=4V，灯泡最暗）；
  ④ 中点状态（滑片P在中点，R_slide=R_max/2，题目给定灯功率最大）；
  ⑤ 三状态并列对比（左侧简图+右侧参数表，便于学生总结规律）。
- 教学价值：教师通过分步导航，引导学生从"识图"到"极端分析"再到"对比归纳"，符合物理电学动态电路的认知递进；灯泡亮度光晕直观反映功率变化，表格对比强化定量关系。

[技术实现]
- JS库选择：原生 SVG（电路图由基本几何图形组成，SVG 的矢量特性最适合元件绘制和状态切换；无需引入外部库，减少依赖）
- 画布尺寸：800 × 500 px（固定画布，SVG viewBox="0 0 800 500"）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  电源U    开关S        灯泡L                      |  y=30~100
  |    |        |            |                        |
  |   A←───────┼────────────┘                        |  y=100~200
  |    |       V                                      |
  |    └───────┬────────────┐                        |  y=200~300
  |         [====R====P===]  变阻器R                  |
  |          a             b                          |
  |                                                   |  y=300~430
  |  [步骤4时显示对比表或简图]                        |
  |                                                   |
  |     [◀ 上一步]  [下一步 ▶]  [重置]               |  y=440~490 控件栏
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `let currentStep = 0;` 控制当前步骤（0~4）。`updateScene(step)` 函数负责根据步骤值显示/隐藏/移动元素。所有步骤特定元素使用 CSS class 控制显示（如 `.step1-only`, `.step2-only` 等），通过 `element.classList.add/remove('hidden')` 切换。
  2. 滑片移动动画：使用 SVG 的 `<animateTransform>` 或 CSS `transition: transform 0.5s ease-out`。推荐 CSS transition：给滑片组 `<g id="scene1-slider-group">` 设置 `transition: transform 0.5s ease-out`，通过 JS 修改 `transform="translate(x, 0)"` 实现平移。滑片初始在中点，步骤1 translate(-150,0)，步骤2 translate(150,0)，步骤3 translate(0,0)。
  3. 灯泡光晕切换：三个光晕 `<circle>` 元素分别对应亮/中/暗，默认 `opacity="0"`，对应步骤时通过 JS 设置 `opacity` 值（步骤1: 0.5, 步骤2: 0.2, 步骤3: 0.35），并配合 CSS transition `opacity 0.5s ease` 实现淡入淡出。
  4. 主电路图淡化（步骤4）：给主电路根组 `<g id="scene1-main-circuit">` 设置 CSS transition `opacity 0.5s ease`，步骤4时设置 `opacity="0.15"`；同时隐藏所有步骤标注（通过 class `.step-annotation` 统一控制）。
  5. 对比表格绘制：步骤4时显示 `<g id="scene1-comparison-table">`，包含 `<rect>` 做单元格背景、`<text>` 做文字。表格使用绝对坐标定位，列宽严格按坐标表分配。简图使用 `<g>` 组封装，每个简图内部使用缩小比例的元件符号。
  6. 电流路径高亮：步骤0时显示 `<path id="scene1-current-path" stroke="#1565c0" stroke-width="4" opacity="0.3" fill="none"/>`，覆盖在导线正上方（相同路径坐标）。
  7. 事件绑定：按钮使用 HTML `<button>` 元素，通过 `position: absolute` 叠在 SVG 容器上方（容器设 `position: relative`）。按钮点击事件调用 `nextStep()` / `prevStep()` / `resetStep()`。
  8. 按钮状态管理：`nextStep()` 中若 `currentStep >= 4` 则返回；`prevStep()` 中若 `currentStep <= 0` 则返回；同步更新按钮 `disabled` 属性和步骤指示器文本。
