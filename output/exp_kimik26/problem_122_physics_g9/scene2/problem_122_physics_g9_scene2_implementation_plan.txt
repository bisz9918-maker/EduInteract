[图示主题与整合说明]
- 本图示主题：带洞均匀金属薄板（3×3挖去中心块）的上半部分等效电阻网络及串并联化简
- 整合的步骤/概念：
  1. 将原薄板沿水平中线分为上下对称两半，取上半部分等效为6节点8支路1断开的电阻网络；
  2. 左端A→C双路径并联化简（直接通路A-C与绕行通路A-E-C）；
  3. 右端D→B双路径并联化简（直接通路D-B与绕行通路D-F-B）；
  4. 中间串联C-D电阻R，合成上半部分总电阻7R/3；
  5. 上下两半并联，最终等效电阻为7R/6。
- 教学价值：教师可逐步揭示“局部并联→串联合成→整体并联”的完整逻辑链，避免学生一次性面对复杂网络而迷失；每步回退功能便于复习巩固。

[分步序列]
- 初始状态（步骤0）：展示上半部分等效电路网络。6个节点A/B/C/D/E/F用圆点标出；7条电阻支路用锯齿线+R标注；E-F支路以红色叉号标为断开。所有元素黑色默认显示。
- 步骤1：点击「下一步」→ 直接通路A-C导线与电阻变为蓝色#1565c0高亮（3px）；绕行通路A-E-C两条导线与电阻变为绿色#2e7d32高亮（3px）；右侧弹出等效电阻框"= 2R/3"（绿边白底）。
- 步骤2：点击「下一步」→ 隐藏E节点及其相连的三条支路（A-E、E-C、E-F左/右段、断开叉号）；A-C支路保留但电阻标签由"R"变为"2R/3"，电阻符号变为绿色加粗高亮；右侧弹出框隐藏。电路简化为A-[2R/3]-C-D-[...]-B。
- 步骤3：点击「下一步」→ 直接通路D-B导线与电阻变为蓝色#1565c0高亮（3px）；绕行通路D-F-B两条导线与电阻变为绿色#2e7d32高亮（3px）；右侧弹出等效电阻框"= 2R/3"。
- 步骤4：点击「下一步」→ 隐藏F节点及其相连的三条支路（D-F、F-B、E-F相关已隐藏）；D-B支路保留但电阻标签由"R"变为"2R/3"，电阻符号变为绿色加粗高亮；右侧弹出框隐藏；在电路下方显示计算式"2R/3 + R + 2R/3 = 7R/3"。电路简化为A-[2R/3]-C-[R]-D-[2R/3]-B。
- 步骤5：点击「下一步」→ 在步骤4电路正下方（y=290~410）画出完全相同的下半部分简化电路（A2-[2R/3]-C2-[R]-D2-[2R/3]-B2），节点与电阻标注同上半；中间绘制水平对称轴虚线y=240表示上下并联；右下角显示最终结果框"7R/6"，框内可附加小字"(7R/3)//(7R/3)"（可选）。
- 教师可随时点击「上一步」回退到任意步骤复习。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「上一步」按钮：位置(280,455)，90×32px，点击回退到上一状态，步骤0时禁用（灰显）。
  2. 「下一步」按钮：位置(430,455)，90×32px，点击前进到下一状态，步骤5时禁用（灰显）。
  3. 步骤指示器：位置(400,485)，显示当前步骤编号如"步骤 2/6"。
- 教师操作流程：
  1. 教师加载图示，默认步骤0，向学生展示上半部分等效网络拓扑；
  2. 点击「下一步」进入步骤1，讲解左端A→C的两条并联路径，观察蓝/绿高亮；
  3. 点击「下一步」进入步骤2，看到左端化简为单个等效电阻2R/3，强调并联公式；
  4. 点击「下一步」进入步骤3，讲解右端D→B的两条并联路径；
  5. 点击「下一步」进入步骤4，看到右端化简为2R/3，并读出串联计算式；
  6. 点击「下一步」进入步骤5，展示上下对称并联，得出最终答案7R/6；
  7. 可随时回退复习任意步骤。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：本场景以静态几何图形和状态切换为主，无需复杂动画或数据驱动绘图；原生SVG可精确控制每个元素的显隐、颜色、描边宽度，避免引入不必要的库体积。
- 画布尺寸：800×500 px（固定）。
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  C--------D        上半电路(y=70~190)            |
  |  /\    /\                                        |
  | /  \  /  \      节点A/B/C/D/E/F                  |
  |A----E-X-F----B                                   |
  |                                                  |
  |  计算式 / 对称轴虚线(y=240)                       |
  |                                                  |
  |  C2-------D2       下半电路(y=290~410, 仅步骤5)  |
  |  /\    /\                                        |
  | /  \  /  \                                       |
  |A2----------B2                                    |
  |                                          [7R/6]  |
  |                                                  |
  |      [◀上一步]  [下一步▶]     步骤 k/6            |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量`currentStep`（0~5），每一步对应一个显隐配置数组，记录每个SVG元素组的`display`属性（true/false）及样式覆盖（颜色、描边宽度）。
  2. 元素分组：将每一步需要显隐的元素按功能分组，赋予group ID，如`scene2-step1-highlight-blue`、`scene2-step1-highlight-green`、`scene2-equiv-box`等，通过控制group的`display`属性实现批量显隐。
  3. 坐标计算：斜向电阻符号使用SVG `<g transform="translate(cx,cy) rotate(angle)">`包裹锯齿线路径，angle通过`Math.atan2(dy,dx)*180/Math.PI`计算。
  4. 动画曲线：本场景无需连续动画，状态切换使用即时显隐（display:none/block）。如需柔和过渡，可在CSS中为相关元素添加`transition: opacity 0.2s`。
  5. 事件绑定：上一步/下一步按钮绑定click事件，更新`currentStep`后调用`render()`函数，根据状态表更新所有元素的显隐和样式。
  6. 按钮禁用逻辑：步骤0时禁用「上一步」，步骤5时禁用「下一步」，通过添加/移除`disabled`类实现灰显。
- ID命名规范：所有交互元素ID必须以`scene2-`为前缀。例如：`scene2-node-a`、`scene2-resistor-ac`、`scene2-highlight-blue-ac`、`scene2-equiv-box-left`、`scene2-btn-prev`、`scene2-btn-next`、`scene2-step-indicator`。
- IIFE隔离：所有JavaScript代码包裹在`(function() { ... })()`中，避免多场景合并时的全局变量污染。
- 电阻符号绘制函数：封装一个`drawResistor(x1,y1,x2,y2,label,groupId)`函数，自动计算中点、角度，绘制导线段、锯齿线符号及标签，简化重复代码。
