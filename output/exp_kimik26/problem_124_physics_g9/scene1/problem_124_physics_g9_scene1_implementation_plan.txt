[图示主题与整合说明]
- 本图示主题：电磁铁与永磁体磁极判断的综合分析
- 整合的步骤/概念：磁感线方向与磁极关系、永磁体极性推导、安培定则（右手螺旋定则）判断电磁铁极性、选项验证
- 教学价值：教师通过分步导航，可逐步引导学生从观察磁感线走向开始，依次推导永磁体极性、运用安培定则判断电磁铁极性，最终验证选项。每一步可随时回退复习，适合课堂逐步讲解。

[分步序列]
- 初始状态（步骤0）：显示完整装置图。螺线管、永磁体、电源、开关、导线、线圈、所有字母标签（a,b,c,d,甲,乙,S,+,-）均可见。磁感线以灰色（#888888）实线显示，无箭头。无高亮、无极性标注、无提示框。教师可在此步介绍装置组成。
- 步骤1（磁感线分析）：点击「下一步」。磁感线变为蓝色（#1565c0）并加粗，动态绘制箭头（从b指向c）。提示框显示"磁感线从N极发出，进入S极"。在b端右侧弹出红色"N"圆框，在c端左下方弹出蓝色"S"圆框。教师讲解磁感线方向与磁极关系。
- 步骤2（永磁体极性推导）：点击「下一步」。永磁体乙添加浅红填充（#c62828，opacity=0.2）和红色边框高亮。在d端右侧弹出红色"N"圆框。提示框更新为"永磁体两端极性相反"。教师讲解由c=S推导出d=N。
- 步骤3（安培定则应用）：点击「下一步」。电磁铁甲添加浅蓝填充（#1565c0，opacity=0.2）和蓝色边框高亮。在螺线管正上方出现右手示意图（简化手形，大拇指指向右）。在螺线管正面中央出现蓝色向上电流箭头。在a端左侧弹出蓝色"S"圆框。提示框更新为"右手握住螺线管，四指指向电流方向，大拇指指向N极"。教师讲解安培定则，验证b=N和a=S。
- 步骤4（结论与选项）：点击「下一步」。装置下方出现四个选项A/B/C/D。D选项高亮（绿色背景）。提示框更新为"正确答案：D、b、d两端都是N极"。汇总四端极性：a=S（蓝）、b=N（红）、c=S（蓝）、d=N（红）。教师总结解题思路。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  1. 「上一步」按钮：位于底部(280,452)，宽100px。点击后回退到上一状态，隐藏当前步骤新增的元素，恢复上一步的提示文字和高亮状态。
  2. 「下一步」按钮：位于底部(420,452)，宽100px。点击后前进到下一状态，按序列显示新元素、高亮和提示。
  3. 步骤指示器：位于按钮上方(400,445)，显示"步骤 X/5"。
- 教师操作流程：
  1. 教师打开图示，步骤0展示完整装置，向学生介绍电磁铁甲、永磁体乙、开关和电源。
  2. 点击「下一步」进入步骤1，引导学生观察磁感线方向，讲解"磁感线从N极发出，进入S极"，得出b=N、c=S。
  3. 点击「下一步」进入步骤2，讲解永磁体两端极性相反，由c=S推出d=N。
  4. 点击「下一步」进入步骤3，展示右手定则示意图，讲解四指指向电流方向（向上）、大拇指指向N极（向右），验证b=N，同时得出a=S。
  5. 点击「下一步」进入步骤4，展示四个选项，高亮D选项，总结正确答案。
  6. 讲解过程中可随时点击「上一步」回退复习关键推导环节。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本场景以静态几何图形和状态切换为主，无需复杂数据绑定或3D渲染，原生SVG性能最优，实现简洁。
- 画布尺寸：800×500 px（固定）。
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  [提示框]                                        |  y=8~44
  |        [右手示意图]                              |  y=55~135 (步骤3)
  |  a  [螺线管甲]  b      c [永磁体乙] d            |  y=145~205
  |     / / / / /        (磁感线)                    |  y=125~235
  |        甲              乙                        |  y=245
  |  S  [电源]                                       |  y=265~300
  |  [选项A] [选项B] [选项C] [选项D]                 |  y=305~343 (步骤4)
  |                                                  |
  |        [◀ 上一步]  [下一步 ▶]                   |  y=452~486
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量`currentStep`（0~4），每一步对应一个显示配置对象，定义该步应显示的元素ID列表、高亮元素ID、提示文字内容。切换步骤时遍历所有元素，根据配置设置`display`或`visibility`属性。
  2. 坐标计算：所有SVG元素使用绝对坐标（px）定义在viewBox="0 0 800 500"内，确保缩放一致性。
  3. 动画曲线：磁感线箭头使用SVG `<animate>`或CSS `stroke-dasharray`动画实现"动态绘制"效果，持续时间500ms，ease-out曲线。
  4. 事件绑定：上一步/下一步按钮绑定click事件，调用`goToStep(n)`函数。函数内先移除所有步骤相关的class，再根据目标步骤添加对应class。
  5. 高亮实现：使用SVG的`class`切换，预定义`.highlight-red`（fill:#c62828;fill-opacity:0.2;stroke:#c62828;stroke-width:2）和`.highlight-blue`（fill:#1565c0;fill-opacity:0.2;stroke:#1565c0;stroke-width:2）。
  6. 极性标注圆框：使用`<g>`包裹`<circle>`和`<text>`，初始`display:none`，对应步骤时设为`display:block`。
  7. 提示框：使用一个`<g id="scene1-hint-group">`，内部`<rect>`做背景，`<text>`做文字。切换步骤时更新textContent并淡入（CSS transition opacity 200ms）。
  8. 选项区域：步骤4才显示，D选项使用`.correct-option`类（fill:#2e7d32;fill-opacity:0.2;stroke:#2e7d32;stroke-width:2）。
- ID命名规范：所有交互元素ID必须以`scene1-`为前缀。例如：`scene1-solenoid-body`、`scene1-magnet-body`、`scene1-field-line-top`、`scene1-pole-b-n`、`scene1-pole-c-s`、`scene1-hand-group`、`scene1-hint-text`、`scene1-option-d`、`scene1-btn-prev`、`scene1-btn-next`。
- IIFE隔离：所有JavaScript代码包裹在`(function() { ... })()`中，避免全局变量污染，确保多场景合并时互不干扰。
- CSS命名：所有样式类以`scene1-`为前缀，如`.scene1-highlight-red`、`.scene1-show`等。
