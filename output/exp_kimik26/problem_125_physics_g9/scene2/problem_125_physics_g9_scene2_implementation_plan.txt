[图示主题与整合说明]
- 本图示主题：物距连续变化对凸透镜成像的影响（验证选项B、C）
- 整合的步骤/概念：
  1. 物距 u > 2f 时成倒立缩小实像（照相机原理）——对应题目原图状态；
  2. 物距 u = 2f 时成倒立等大实像；
  3. f < u < 2f 时成倒立放大实像（投影仪原理）；
  4. u = f 时不成像（像在无穷远处）；
  5. u < f 时成正立放大虚像（放大镜原理）。
- 教学价值：教师通过拖动蜡烛滑块，让学生直观观察"物近像远像变大"的因果联系，并回退到题目初始状态（u>2f）验证B、C选项错误。

[视觉元素清单]
- 主光轴：水平虚线贯穿画面，作为所有光学元件的基准线。
- 凸透镜：位于画布中心 x=400，用两条对称弧线表示双凸透镜，描边黑色 2px。
- 焦点标记：F 与 2F 在透镜左右两侧对称放置，绿色实心圆点（r=4px），标签统一放在主轴下方 y=270，避免与像重叠。
- 蜡烛（物体）：蓝色线条图标，底部落在主轴上，主体宽 20px、高 40px，火焰高 10px，总高 60px。随滑块在 x∈[160,360]（对应物距 u∈[240,40]）范围内水平移动。
- 光屏：绿色竖立矩形，宽 20px、高 60px，底部在主轴上。当 u>f 时显示，位置由透镜公式实时计算；当 u≤f 时隐藏。
- 实像：红色实线绘制的倒立蜡烛轮廓，宽 15px，高度 = 物高 50px × (v/u)，底部在主轴上，顶部向上延伸。位于光屏处。
- 虚像：红色虚线绘制的正立蜡烛轮廓，宽 10px，高度 = 物高 50px × (|v|/u)，底部在 y=245（略高于主轴，避免与焦点圆点重叠），位于透镜左侧（物体同侧）。仅当 u<f 时显示。
- 不成像提示：u=f 时在透镜右侧显示文本"不成像（像在无穷远处）"，红色。
- 信息面板：底部背景区，三列布局，实时显示 u、v、成像性质、实际应用。
- 滑块控件：轨道在 y=465，范围 x=160~360，带 3f/2f/f/0.5f 刻度；蓝色圆形手柄（r=12px）跟随蜡烛位置。

[分步序列]
本场景为连续滑块交互，无离散步骤按钮。以下列出教师讲解时的关键停靠状态（教师拖动滑块至对应位置即可停留讲解）：

- 状态 0（初始/题目状态）：蜡烛在 x=160（u=3f=240），光屏在 x=520（v=1.5f=120）。实像高 25px，倒立缩小。信息面板显示"物距 u = 240 mm，像距 v = 120 mm，成像性质：倒立缩小实像，应用：照相机"。此状态用于验证选项 C 错误（当前不是投影仪原理）。
- 状态 1（u=2f）：蜡烛在 x=240（u=2f=160），光屏在 x=560（v=2f=160）。实像高 50px，倒立等大。信息面板更新为"倒立等大实像，应用：测焦距"。
- 状态 2（f<u<2f，投影仪）：蜡烛在 x=280（u=1.5f=120），光屏在 x=640（v=3f=240）。实像高 100px，倒立放大。信息面板更新为"倒立放大实像，应用：投影仪"。
- 状态 3（u=f）：蜡烛在 x=320（u=f=80）。光屏与实像均隐藏，显示"不成像（像在无穷远处）"提示。信息面板更新为"不成像，应用：探照灯"。
- 状态 4（u<f，放大镜）：蜡烛在 x=340（u=0.5f=40），虚像位于 x=320（v=−f=−80），虚像高 100px，正立放大。信息面板更新为"正立放大虚像，应用：放大镜"。
- 回退验证：教师将蜡烛从 3f 向透镜缓慢移动，学生可观察到像逐渐变大、光屏逐渐远离，从而验证选项 B 错误（靠近凸透镜时像变大，而非变小）。

[交互方案]
- 交互类型：连续拖拽/滑块（严格遵循 scene_outline 声明）
- 控件说明：
  - 滑块手柄：位于底部轨道 y=465，x 随蜡烛位置变化。教师可鼠标按下并水平拖动手柄，蜡烛同步在主光轴上左右移动。
  - 轨道刻度：3f、2f、f、0.5f，帮助教师快速定位关键物距。
- 约束与反馈：
  1. 拖拽范围限制：手柄 x∈[160,360]（对应 u∈[240,40]），超出边界不响应。
  2. 实时计算：系统根据透镜公式 1/u + 1/v = 1/f（f=80px）实时计算像距 v 与放大率 m=v/u。
  3. 光屏自动移动：光屏 x = min(400 + v, 760)。当 v 对应 x≤760 时精确到位；当 x>760 时固定在 760，像高仍按实际 m 计算，确保物理规律正确。
  4. 像的切换：
     - u>f：显示红色实像（实线，倒立），隐藏虚像与不成像提示。
     - u=f：隐藏光屏、实像、虚像，显示"不成像（像在无穷远处）"提示。
     - u<f：隐藏光屏与实像，显示红色虚像（虚线，正立），位于透镜左侧 x=400+v（v 为负值）。
  5. 信息面板实时更新：物距 u、像距 v（取绝对值）、成像性质（正倒/大小/虚实）、实际应用（照相机/测焦距/投影仪/探照灯/放大镜）。
- 教师操作流程：
  1. 教师先展示初始状态（u=3f），说明题目原图为照相机原理，验证 C 错误；
  2. 教师缓慢将蜡烛向右（靠近透镜）拖动，让学生观察光屏向右移动、实像变大，验证 B 错误；
  3. 教师依次停在 2f、1.5f、f、0.5f 四个关键点，讲解成像规律变化；
  4. 教师可自由回退到任意位置复习。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无需额外库，直接操作 SVG DOM 属性即可满足实时拖拽与几何计算）。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图：
  ```
  +--------------------------------------------------+
  |  光学装置区 (y=50~350)                            |
  |                                                  |
  |     2F   F      O      F   2F                    |
  |      ·   ·     )(      ·   ·      [光屏]         |
  |  [蜡烛]---------------------------[实像]          |
  |           <=========== 主光轴 ==========>         |
  |                                                  |
  +--------------------------------------------------+
  |  信息面板 (y=380~440)                             |
  |  物距 u=xxx   成像性质:xxx   应用:xxx             |
  |  像距 v=xxx                                      |
  +--------------------------------------------------+
  |  滑块控件区 (y=440~490)                           |
  |  3f----2f----f----0.5f   [○] 可拖动              |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 坐标系与比例：以 px 为单位，设焦距 f=80px。物距 u = 400 − candleX，像距 v = u×f/(u−f)，放大率 m = v/u。
  2. 拖拽实现：在滑块手柄（scene2-slider-handle）上绑定 mousedown/touchstart，在 window 上绑定 mousemove/touchmove 与 mouseup/touchend。移动时计算新 x = clamp(event.clientX − offsetX, 160, 360)，更新蜡烛、手柄位置，并调用 updateOptics()。
  3. updateOptics() 逻辑：
     - 计算 u、v、m；
     - 更新信息面板文本（scene2-info-u, scene2-info-v, scene2-info-nature, scene2-info-app）；
     - 若 u>f：光屏 x = min(400+v, 760)，实像高 = 50×m，更新实像 path 的 d 属性，显示实像，隐藏虚像与不成像提示；
     - 若 u===f（容差±1px）：隐藏光屏、实像、虚像，显示不成像提示；
     - 若 u<f：隐藏光屏与实像，虚像 x = 400+v，虚像高 = 50×|m|，更新虚像 path 的 d 属性，显示虚像。
  4. 像的绘制：使用 SVG path 绘制简化蜡烛轮廓（主体矩形+顶部火焰），通过 scale(1, 放大率) 或重新计算顶点实现高度变化。实像倒置可通过火焰向下绘制实现；虚像正立与物体同向。
  5. 性能：拖拽过程中直接修改 SVG 属性（setAttribute），不使用 CSS 动画，确保 60fps 实时反馈。
- ID 命名规范：所有交互元素 ID 必须以 scene2- 为前缀，例如：
  - scene2-axis, scene2-lens, scene2-candle-group, scene2-screen, scene2-real-image, scene2-virtual-image, scene2-no-image-text, scene2-slider-track, scene2-slider-handle, scene2-info-panel, scene2-info-u, scene2-info-v, scene2-info-nature, scene2-info-app。
- IIFE 隔离：所有 JavaScript 代码包裹在 (function() { ... })() 中，避免多场景合并时全局变量污染。
