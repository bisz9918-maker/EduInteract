[图示主题与整合说明]
- 本图示主题：漫反射与镜面反射对比（验证D选项）
- 整合内容：粗糙光屏的漫反射原理、光滑玻璃板的镜面反射原理、从不同方向观察的效果差异
- 教学价值：教师通过状态切换，让学生直观理解为什么光屏应选用粗糙表面（漫反射使各个方向都能看到像），而光滑玻璃板因镜面反射导致只有在特定方向才能看到像，不适合做光屏。

[分步序列]
本场景采用多状态切换（2个状态），无分步导航。

- 状态1「粗糙光屏（漫反射）」（初始状态）：
  - 左栏所有元素以正常亮度显示（opacity = 1.0）
  - 右栏所有元素以暗淡显示（opacity = 0.25）
  - 按钮1处于激活/选中样式（如背景色加深或边框高亮）
  - 显示内容：粗糙表面、3条蓝色入射光线、5条红色散射反射光线、2只绿色眼睛图标、"各个方向都能看到"标注、底部"漫反射 → 光屏应选用粗糙表面"

- 状态2「光滑玻璃板（镜面反射）」：
  - 右栏所有元素以正常亮度显示（opacity = 1.0）
  - 左栏所有元素以暗淡显示（opacity = 0.25）
  - 按钮2处于激活/选中样式
  - 显示内容：光滑表面、3条蓝色入射光线、3条红色平行反射光线、1只绿色眼睛图标（可见）、1只灰色眼睛图标（不可见）、"只有在特定方向才能看到"标注、底部"镜面反射 → 不适合做光屏"

（教师点击底部两个切换按钮即可在两种反射模型间即时切换，对比讲解。）

- 控件说明：
  - 「粗糙光屏（漫反射）」按钮：位置(180, 455)，大小200×36。点击后切换到状态1，左栏高亮，右栏暗淡。
  - 「光滑玻璃板（镜面反射）」按钮：位置(420, 455)，大小200×36。点击后切换到状态2，右栏高亮，左栏暗淡。
- 教师操作流程：
  1. 初始加载显示状态1（漫反射），教师讲解粗糙光屏如何让各个方向都看到像。
  2. 点击「光滑玻璃板（镜面反射）」按钮切换到状态2，讲解镜面反射的定向性以及为什么光滑玻璃板不适合。
  3. 可反复点击两个按钮，在两种反射模型间快速切换对比，强化学生理解。

[技术实现]
- JS 库选择：原生 SVG（简单几何图形、光线、箭头、图标均适合用SVG绘制），无需额外库。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +----------------------------------------------------------+
  |         粗糙光屏                    光滑玻璃板             |
  |                                                          |
  |    \   |   /                  \   |   /                  |
  |     \  |  /                    \  |  /                   |
  |      \ | /                      \ | /                    |
  |       \|/                        \|/                     |
  |        ▼                          ▼                      |
  |   [==========]              [==========]                 |
  |    /  |  \                    |  |  |                    |
  |   /   |   \                   |  |  |                    |
  |  ●    ●                      ●   ○                     |
  | 可见  可见                  可见  不可见                 |
  |                                                          |
  |  漫反射→光屏应选用粗糙表面   镜面反射→不适合做光屏        |
  |                                                          |
  |    [粗糙光屏(漫反射)]    [光滑玻璃板(镜面反射)]          |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. **分组管理**：使用两个 `<g>` 元素分别包裹左栏（`scene3-left-panel`）和右栏（`scene3-right-panel`）的所有元素，便于整体控制透明度。
  2. **箭头定义**：在 `<defs>` 中定义 arrow-blue 和 arrow-red 两个 marker，分别用于入射光线和反射光线。
  3. **眼睛图标**：用 `<ellipse>`（rx=15, ry=10）作外框，`<circle>`（r=5）作眼珠，组合成眼睛图标。
  4. **状态切换逻辑**：维护变量 `currentState`（1或2）。切换时：
     - 若状态1：左栏 opacity=1.0，右栏 opacity=0.25；按钮1添加 active 类，按钮2移除 active 类。
     - 若状态2：左栏 opacity=0.25，右栏 opacity=1.0；按钮2添加 active 类，按钮1移除 active 类。
  5. **过渡动画**：为左右两栏的 `<g>` 元素添加 CSS transition: opacity 0.3s ease，使切换有平滑过渡效果。
  6. **控件定位**：两个按钮用 HTML `<button>` 元素，通过 `position: absolute` 定位在 SVG 容器底部（y=455），不额外撑高容器。
  7. **法线始终可见**：法线作为辅助线，其透明度可随所属栏位变化，或始终保持在0.5以上以确保可见性。
- **ID 命名规范**：所有交互元素 ID 必须以 `scene3-` 为前缀。例如：
  - 左栏分组：`scene3-left-panel`
  - 右栏分组：`scene3-right-panel`
  - 粗糙表面：`scene3-rough-surface`
  - 光滑表面：`scene3-smooth-surface`
  - 入射光线1：`scene3-incident-ray-left-1`
  - 反射光线1：`scene3-reflect-ray-left-1`
  - 按钮1：`scene3-btn-rough`
  - 按钮2：`scene3-btn-smooth`
  - JS 中获取元素使用 `document.getElementById`，不使用 `querySelectorAll` 配合全局 class，避免多场景合并时跨场景污染。
- IIFE 隔离：所有 JavaScript 代码包裹在 `(function() { ... })()` 中，确保变量不污染全局作用域。
