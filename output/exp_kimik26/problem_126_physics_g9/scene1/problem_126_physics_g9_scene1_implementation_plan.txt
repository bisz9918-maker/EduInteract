[图示主题与整合说明]
- 本图示主题：水平滑轮组的绳子段数判定及运动学关系
- 整合的步骤/概念：装置结构展示 → 绳子段数标注（n=3） → 物体位移与绳端位移关系（S与3S） → 物体速度与绳端速度关系（υ与3υ）
- 教学价值：教师通过分步导航，按"整体装置→局部高亮→运动关系"的递进顺序讲解，可随时回退复习，便于学生理解滑轮组中绳端移动距离/速度与物体移动距离/速度的倍数关系

[分步序列]
- 初始状态（步骤0）：显示完整装置图
  - 可见元素：桌面、物体A（标签A）、滑轮组（3个滑轮）、墙面、绳子（灰色/黑色）、拉力F箭头（标签F）、重力G箭头（标签G）、摩擦力f箭头（标签f）
  - 隐藏元素：数字1/2/3、n=3、所有位移/速度箭头及标签、关系式
  - 教师讲解：介绍装置结构，指出已知量G、f、F

- 步骤1：点击「下一步」→ 数绳子段数
  - 变化：绳子从灰色变为蓝色高亮；依次出现红色数字"1"（段1中点下方）、"2"（段2中点上方）、"3"（段3中点下方）；出现绿色"n=3"标签在滑轮组上方
  - 教师讲解：引导学生数承担拉力的绳子段数，得出n=3

- 步骤2：点击「下一步」→ 位移关系
  - 变化：保持步骤1所有元素；新增蓝色S箭头（物体A下方）、红色虚线3S箭头（绳端下方）、灰色辅助虚线、标签S和3S、位移关系式"s绳 = 3S"
  - 教师讲解：物体移动S，绳端移动3S，绳端移动距离是物体的3倍

- 步骤3：点击「下一步」→ 速度关系
  - 变化：保持步骤2所有元素；新增蓝色υ箭头（物体A上方）、红色3υ箭头（绳端上方）、标签υ和3υ、速度关系式"υ绳 = 3υ"
  - 教师讲解：物体速度为υ，绳端速度为3υ，绳端速度是物体的3倍
  - 最终结论：由此可推导拉力做功W=Fs绳=F·3S=3FS，功率P=F·3υ=3Fυ，机械效率η=fs/(3FS)=f/(3F)

[技术实现]
- JS库选择：原生SVG（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  800×500 画布
  +--------------------------------------------------------+
  |  [速度区]  υ→    A      滑轮组      墙    F→    3υ→   |  y=210-250
  |                                                        |
  |  [主图区]  ┌───┐  ○  ○  ○  |╱╱╱╱╱╱╱╱╱╱╱╱╱╱╱╱╱╱╱╱╱╱╱╱╱ |  y=260-380
  |  桌面 ─────│ A │───────────────○──○──○──│──────────── |  y=340
  |            └───┘               1  2  3                |
  |  [位移区]  S→              3S→(虚线)                  |  y=390-430
  |                                                        |
  |  [控件区]        [◀上一步]  [下一步▶]   步骤 1/4       |  y=440-490
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `let currentStep = 0;`（范围0~3），每步定义显示元素ID列表
  2. 元素显隐控制：所有可选元素初始 `display: none`，根据currentStep切换为 `display: block/inline`
  3. 绳子高亮：步骤0绳子stroke="#000000"，步骤1及之后stroke="#1565c0"，通过JS动态修改属性
  4. 箭头绘制：使用SVG `<marker>` 定义箭头头部，复用于所有箭头
  5. 虚线：3S箭头使用 `stroke-dasharray="6,4"`，辅助线使用 `stroke-dasharray="4,4"`
  6. 墙面阴影：使用 `<pattern>` 定义45°斜线填充，或手动绘制多条斜线
  7. 动画曲线：无需复杂动画，直接显隐切换即可；如需平滑过渡，可加0.3s CSS transition
  8. 事件绑定：按钮点击事件直接修改currentStep并调用render()函数
- ID命名规范：
  - 所有SVG元素和JS变量ID必须以 `scene1-` 为前缀
  - 示例：`scene1-obj-a`、`scene1-pulley-1`、`scene1-rope-seg-1`、`scene1-rope-arc-1`、`scene1-label-f`、`scene1-arrow-f`、`scene1-btn-prev`、`scene1-btn-next`、`scene1-step-text`
  - JS中获取元素使用 `document.getElementById('scene1-xxx')`，禁止使用 `querySelectorAll`
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免多场景合并时全局变量污染
- 代码结构建议：
  ```javascript
  (function() {
    const STEP_ELEMENTS = [
      ['scene1-rope-seg-1', 'scene1-rope-seg-2', 'scene1-rope-seg-3', 'scene1-rope-seg-4', 'scene1-rope-arc-1', 'scene1-rope-arc-2', 'scene1-rope-arc-3', 'scene1-obj-a', 'scene1-pulley-1', 'scene1-pulley-2', 'scene1-pulley-3', 'scene1-wall', 'scene1-arrow-f', 'scene1-arrow-g', 'scene1-arrow-f', 'scene1-label-a', 'scene1-label-f', 'scene1-label-g', 'scene1-label-f'],
      // ... 每步新增元素
    ];
    let currentStep = 0;
    function render() { /* 显隐控制 */ }
    document.getElementById('scene1-btn-next').addEventListener('click', function() { if(currentStep < 3) { currentStep++; render(); } });
    document.getElementById('scene1-btn-prev').addEventListener('click', function() { if(currentStep > 0) { currentStep--; render(); } });
    render();
  })();
  ```
