[图示主题与整合说明]
- 本图示主题：光通过玻璃砖的折射光路正误判断（四选项对比）
- 整合的步骤/概念：
  1. 总览四个选项光路；
  2. 逐项分析 A（不平行，错）、B（平行有侧移，对）、C（错误全反射，错）、D（未折射，错）；
  3. 得出唯一正确选项 B。
- 教学价值：教师通过分步导航，逐一聚焦每个选项，引导学生观察入射光与出射光的平行关系、侧向位移、全反射条件及折射必然性，避免四图同时高亮造成的视觉干扰。

[交互方案]
- 交互类型：分步按钮导航（◀ 上一步 / 下一步 ▶）。
- 控件说明：
  1. 「上一步」按钮：id="scene2-btn-prev"，位置 (320,460)，宽 80×32；点击回退到上一分析步骤，步骤 0 时禁用。
  2. 「下一步」按钮：id="scene2-btn-next"，位置 (420,460)，宽 80×32；点击前进到下一分析步骤，步骤 5 时禁用或显示 "完成"。

- 教师操作流程：
  1. 教师展示步骤 0（总览），让学生快速浏览四个选项；
  2. 点击「下一步」进入步骤 1，聚焦 A，讲解"不平行即错误"；
  3. 继续点击「下一步」依次讲解 B（正确光路特征）、C（全反射条件）、D（折射必然性）；
  4. 最后进入步骤 5，确认答案 B；可随时点击「上一步」回退复习。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript。原因：本场景为静态几何图形组合，仅需控制 stroke/stroke-opacity/fill-opacity/display 属性及少量辅助元素的显隐，无需复杂数学计算或动画库。
- 画布尺寸：800 × 500 px（SVG viewBox="0 0 800 500"）。
- 布局草图：
  ```
  +--------------------------------------------------------+
  |  [A 玻璃砖+光路]          [B 玻璃砖+光路]               |
  |   A                        B                           |
  |                                                        |
  |  [C 玻璃砖+光路]          [D 玻璃砖+光路]               |
  |   C                        D                           |
  |                                                        |
  |           [ 分析文字框 / 结论文字 ]                      |
  |                                                        |
  |           [◀ 上一步]    [下一步 ▶]     步骤 k/5         |
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机：用变量 `let currentStep = 0;` 记录当前步骤（0~5）。`updateScene(step)` 函数根据步骤统一更新所有元素的 class 或 style。
  2. 元素分组：每个选项的光路、玻璃砖、法线、辅助标注分别包裹在 `<g id="scene2-group-a">` 等容器中，通过设置组的 `opacity` 实现整体淡化。
  3. 光路颜色切换：为每条光路线段设置 `class="scene2-ray"`，通过 JS 修改 `stroke` 和 `stroke-width`。
  4. 辅助标注显隐：所有步骤专属元素（平行符号、d 箭头、不平行文字、应折射虚线等）初始 `display:none`，在对应步骤中设为 `display:block`。
  5. 分析文字更新：使用一个 `<text>` 元素（id="scene2-analysis-text"）和一个 `<text>` 图标元素（id="scene2-analysis-icon"），根据步骤切换内容、颜色及位置。
  6. 按钮状态：在 `updateScene` 中检查 `currentStep`，设置 `disabled` 属性及样式（opacity 0.4）。
  7. 动画曲线：无需 CSS 动画，直接切换属性以保证教学演示的即时响应；如需柔和过渡，可在 CSS 中给相关元素添加 `transition: opacity 0.2s, stroke 0.2s;`。
- ID 命名规范：所有 SVG 元素及 JS 变量均以 `scene2-` 为前缀，例如 `scene2-brick-a`、`scene2-ray-a-incident`、`scene2-annotation-parallel-b1`、`scene2-btn-prev`、`scene2-analysis-text`。
- IIFE 隔离：所有 JavaScript 包在 `(function() { ... })();` 中，避免多场景合并时污染全局作用域。
- SVG marker 定义：在 `<defs>` 中定义箭头标记 `<marker id="scene2-arrowhead" ...>`，供所有光路线段复用。
