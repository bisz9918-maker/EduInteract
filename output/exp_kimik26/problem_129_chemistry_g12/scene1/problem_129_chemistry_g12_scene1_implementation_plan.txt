[图示主题与整合说明]
- 本图示主题：偏二甲肼-四氧化二氮原电池装置综合分析与选项验证
- 整合的步骤/概念：装置结构识别 → 电子流向与正负极判断 → 反应物通入方向（a/b口） → 负极氧化反应式书写 → 正极还原反应式书写 → 产物排出方向（c/d口） → 四个选项正误验证
- 教学价值：教师可使用此图示按线性递进节奏讲解，每步聚焦一个判断要点；学生可先独立观察装置，再跟随教师点击逐步揭示分析过程，最终完成选项验证。分步导航支持随时回退复习。

[分步序列]
- 初始状态（步骤0）：显示完整原电池装置图（电池槽、电极A/B、导线、灯泡、液面线、电解质填充、进出口管道及箭头），标注基础元素A、B、H₂SO₄、a、b、c、d。隐藏电子流向、反应式、选项卡片。引导文字显示"观察原电池装置，思考各部件作用"。
- 步骤1（电子流向与电极判断）：显示外电路电子箭头（B→A，金黄色）及e⁻标签；在箭头旁标注"电子流出→负极"（红色，B极上方右侧）和"电子流入→正极"（蓝色，A极上方左侧）；在B极旁红色标注"负极（氧化反应）"，在A极旁蓝色标注"正极（还原反应）"。引导文字更新为"根据电子流向判断正负极：电子流出的一极为负极"。
- 步骤2（反应物通入方向）：高亮a口（蓝色标注"N₂O₄（氧化剂）→ 正极A"）和b口（红色标注"C₂H₈N₂（还原剂）→ 负极B"）。引导文字更新为"氧化剂通入正极，还原剂通入负极"。
- 步骤3（负极反应式）：在B极右侧弹出反应式文本框（红边框），内容："负极（氧化反应）" + "C₂H₈N₂ + 8H₂O → 2CO₂↑ + N₂↑ + 16H⁺ + 16e⁻" + "C: -2 → +4  N: -2 → 0"。引导文字更新为"负极发生氧化反应，偏二甲肼失去电子"。
- 步骤4（正极反应式）：在A极左侧弹出反应式文本框（蓝边框），内容："正极（还原反应）" + "N₂O₄ + 8H⁺ + 8e⁻ → N₂ + 4H₂O" + "总：C₂H₈N₂ + 2N₂O₄ → 2CO₂ + 3N₂ + 4H₂O" + "N: +4 → 0"。引导文字更新为"正极发生还原反应，四氧化二氮得到电子"。
- 步骤5（产物排出方向）：高亮c口（蓝色标注"N₂"）和d口（红色标注"N₂ + CO₂"）。引导文字更新为"产物均为空气成分，无污染排放"。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：本场景以几何图形、文本标签和简单显示/隐藏为主，无需复杂数据绑定或3D渲染，原生SVG性能最优且文件体积小。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------------+
  |  正极反应框(左)    灯泡    负极反应框(右)              |
  |       |         (400,55)       |                       |
  |       |            |           |                       |
  |  c口←[===A===] 液面 [===B===]→d口                      |
  |       |            |           |                       |
  |  a口→[=========H₂SO₄=========]←b口                     |
  |                                                        |
  |              [引导文字区 (步骤0-5)]                     |
  |     [A][B][C][D] 选项卡片 (步骤6)                      |
  |              [◀ 上一步] [下一步 ▶]                     |
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `currentStep`（0~6），每步对应一个显示元素集合。定义 `stepElements` 数组，每个元素记录该步应显示/隐藏的SVG元素ID列表。
  2. 初始化：所有步骤专属元素设置 `display: none` 或 `visibility: hidden`，仅步骤0元素可见。
  3. 切换逻辑：`updateStep(newStep)` 函数先隐藏当前步所有专属元素，再显示新步元素，同时更新引导文字和按钮禁用状态。
  4. 动画效果：元素出现使用CSS transition（opacity 0→1，duration 300ms，ease-out），增强课堂演示流畅感。
  5. 事件绑定：按钮绑定click事件，使用IIFE隔离作用域。
  6. 化学式下标：使用SVG `<tspan>` 的 `baseline-shift="sub"` 和 `font-size="10px"` 实现下标效果（如CO₂、N₂O₄、H₂SO₄等）。
  7. 箭头绘制：电子箭头使用SVG `<path>` 的marker-end指向左向箭头；气体管道箭头使用 `<polygon>` 三角形。
  8. 选项卡片：使用 `<foreignObject>` 或SVG `<rect>` + `<text>` 组合实现，正确项填充#1565c0，错误项填充#ffffff描边#c62828。
- ID命名规范：所有交互元素ID必须以 `scene1-` 为前缀。例如：`scene1-cell-tank`、`scene1-electrode-a`、`scene1-electrode-b`、`scene1-bulb`、`scene1-electron-arrow-1`、`scene1-electron-arrow-2`、`scene1-label-a`、`scene1-label-h2so4`、`scene1-step1-neg-label`、`scene1-step1-pos-label`、`scene1-step2-a-gas`、`scene1-step2-b-gas`、`scene1-step3-rxn-box`、`scene1-step3-rxn-text`、`scene1-step4-rxn-box`、`scene1-step4-rxn-text`、`scene1-step5-c-product`、`scene1-step5-d-product`、`scene1-step6-card-a`、`scene1-step6-card-b`、`scene1-step6-card-c`、`scene1-step6-card-d`、`scene1-guide-text`、`scene1-btn-prev`、`scene1-btn-next`、`scene1-step-indicator`。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免多场景合并时的全局变量污染。
