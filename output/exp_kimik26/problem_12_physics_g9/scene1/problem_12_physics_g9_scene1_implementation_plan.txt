[分步序列]
- 步骤0（观察装置）：显示两个弹簧测力计A、B及S型挂钩连接；A读数窗口显示"8N"，B读数窗口显示"?"；左右两侧显示水平向外拉力箭头；显示标签A、B、甲、乙。分析区、相互作用力、结论框全部隐藏。目的：呈现题目基础条件，引发学生思考B的读数是多少。
- 步骤1（A受力分析）：在步骤0基础上，左下A分析框出现（淡入）。框内显示简化A线段、左向箭头标注"F_手A = 8N"、右向箭头标注"F_B→A = 8N"，下方绿色文字"二力平衡：F_手A = F_B→A"。目的：讲解A处于平衡状态，两端受力相等。
- 步骤2（B受力分析）：在步骤1基础上，右下B分析框出现（淡入）。框内显示简化B线段、左向箭头标注"F_A→B = 8N"、右向箭头标注"F_手B = 8N"，下方绿色文字"二力平衡：F_A→B = F_手B"。目的：讲解B同样处于平衡状态，两端受力相等。
- 步骤3（相互作用力）：在步骤2基础上，中间下方出现紫色双向箭头（左箭头从(400,375)指向(330,375)，右箭头从(400,375)指向(470,375)），上方标注"作用力与反作用力"，下方标注"F_A→B = F_B→A = 8N"。同时挂钩连接处添加半透明高亮圆（圆心(400,145)，半径25px，紫色填充透明度15%）。目的：强调牛顿第三定律，A对B的力与B对A的力大小相等。
- 步骤4（得出结论）：在步骤3基础上，B的读数窗口由"?"变为"8N"（数字切换动画）；右下角绿色结论框出现，内有三行文字："B的读数 = 8N"（16px加粗）、"手对A的拉力 = 8N"、"手对B的拉力 = 8N"。目的：汇总结论，对应选项A（8N，8N）。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「◀ 上一步」按钮：位置(330,455)-(420,485)，点击回退到上一步骤，步骤0时禁用（透明度50%）
  2. 「下一步 ▶」按钮：位置(450,455)-(540,485)，点击前进到下一步，步骤4时禁用（透明度50%）

- 教师操作流程：
  1. 教师展示步骤0，让学生观察装置并思考B的读数
  2. 点击「下一步」进入步骤1，讲解A的受力平衡，强调F_手A与F_B→A大小相等
  3. 点击「下一步」进入步骤2，讲解B的受力平衡，强调F_A→B与F_手B大小相等
  4. 点击「下一步」进入步骤3，高亮挂钩处，讲解作用力与反作用力关系，建立F_A→B = F_B→A的桥梁
  5. 点击「下一步」进入步骤4，B读数变为8N，展示结论框，得出答案A
  6. 可随时点击「上一步」回退，复习受力分析逻辑

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：本场景以几何图形、箭头、文字标签为主，无复杂函数图或3D，原生SVG足够且轻量；通过classList控制显示/隐藏，CSS transition实现淡入效果。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------------+
  |                                                        |
  |     "A"              "B"                               |
  |      |                |                                |
  |    [8N]            [?]        <- 装置图区 y=50~210     |
  |    +-O-- ~~~~  --O-+                                   |
  |    | ~~~~~~~~~~~~ |                                    |
  |    +----O---O-----+                                   |
  |    "甲"         "乙"                                   |
  |   <---       --->                                     |
  |                                                        |
  |  +----------------+    +----------------+              |
  |  | 对A受力分析    |    | 对B受力分析    |  <- 分析区    |
  |  |  <--  -->     |    |  <--  -->     |    y=220~430  |
  |  | 二力平衡      |    | 二力平衡      |              |
  |  +----------------+    +----------------+              |
  |       <---->                                           |
  |    作用力与反作用力                                    |
  |                    +----------------+                  |
  |                    | 结论框         |                  |
  |                    +----------------+                  |
  |                                                        |
  |      [◀ 上一步]  [下一步 ▶]      <- 控件区 y=440~490  |
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：定义常量STATE_COUNT=5，当前状态currentState（0~4）。每次点击按钮时更新currentState，调用render()函数根据状态显示/隐藏对应元素。
  2. 元素显隐控制：所有步骤相关元素初始display:none。render()中使用element.style.display = 'block'/'none'切换。步骤1~4的元素使用CSS opacity transition（0.3s ease）实现淡入。
  3. 弹簧锯齿线生成：用JS循环生成polyline点坐标，周期6px，振幅3px，y坐标在baseY±3之间交替。
  4. S型挂钩：SVG path使用二次贝塞尔曲线 Q 350,115 390,145 Q 440,175 490,145（从310,145到490,145）。
  5. 箭头标记：在SVG <defs>中定义三个marker（蓝色箭头、红色箭头、紫色箭头），供line元素引用。
  6. 步骤4数字切换：B读数文字元素先缩放淡出（scale 1.2→1, opacity 1→0，0.2s），然后更换textContent为"8N"，再淡入（opacity 0→1，0.2s）。
  7. 按钮禁用状态：步骤0时上一步按钮添加disabled类（opacity:0.5, pointer-events:none）；步骤4时下一步按钮同理。
  8. 挂钩高亮（步骤3）：一个circle元素，圆心(400,145)，半径25px，填充紫色#6a1b9a透明度15%，初始隐藏，步骤3显示。
- ID命名规范：所有交互元素ID必须以scene1-为前缀。例如：scene1-device-a、scene1-force-arrow-a-left、scene1-analysis-box-a、scene1-conclusion-box、scene1-btn-prev、scene1-btn-next。
- IIFE隔离：所有JavaScript代码包裹在 (function() { ... })() 中，避免全局变量污染，确保多场景合并时互不干扰。
- 事件绑定：使用document.getElementById('scene1-btn-prev').addEventListener('click', ...)绑定点击事件，不用内联onclick。
