题目原文

分子式为C₅H₁₁Cl的卤代烃，其分子中含有两个—CH₃，两个—CH₂—，一个—CH—（如题图所示）和一个—Cl，它可能的结构有(　　)

A. 2种　　B. 3种　　C. 4种　　D. 5种

题目分析

本题考查有机物的同分异构体推断，核心是根据分子中特定基团的数量约束来计数符合条件的C₅H₁₁Cl结构。解题的关键在于识别—CH—是唯一含三个碳-碳连接位点的基团，因此它必然充当分子的分支点。教师可引导学生先分析各基团的"自由价键数"，再以—CH—为中心枚举其三个连接位的所有可能组合，排除无法成链的方案，最后将有效组合转化为具体分子结构并验证。

整体讲解思路

  1. 先展示题目给出的6个结构基团，让学生明确每种基团在分子中的连接能力（—CH₃和—Cl各提供1个连接位，—CH₂—提供2个，—CH—提供3个）。
  2. 强调—CH—的三价特性，确定其为分子骨架的分支点。
  3. 枚举—CH—三个连接位的所有组合（从{2×—CH₃, 2×—CH₂—, 1×—Cl}中选取3个），共5种数学组合，排除其中1种无法成链的情况。
  4. 将剩余4种有效组合逐一展开为完整分子结构，并用颜色标注各碳原子类型，验证基团数量是否与题意一致。
  5. 给出系统命名，确认答案为4种（选C）。

本图示（SCENE_2）的教学说明

本图示用于将SCENE_1中得到的4种有效连接方案转化为具体可识别的分子结构。教师在讲解时应引导学生完成以下观察：

  1. 从抽象组合到具体结构：让学生根据SCENE_1中的组合②~⑤，尝试自己画出碳骨架，再与图示对照。
  2. 颜色编码的一致性：强调蓝色始终代表甲基碳、绿色代表亚甲基碳、橙色代表次甲基碳、紫色代表氯，这种颜色映射在两个图示中完全一致。
  3. 基团计数验证：每展示一种结构，带领学生逐碳计数，确认—CH₃、—CH₂—、—CH—、—Cl的数量严格满足题目要求（2、2、1、1）。
  4. 系统命名复习：利用本图示复习卤代烃的系统命名规则（选含氯最长链、编号使氯位次最小等）。

四种结构的推导对应关系

  • 组合②（CH₃+CH₃+CH₂）→ 1-氯-3-甲基丁烷：ClCH₂CH₂CH(CH₃)₂
  • 组合③（CH₂+CH₂+Cl）→ 3-氯戊烷：CH₃CH₂CH(Cl)CH₂CH₃
  • 组合④（CH₂+CH₂+CH₃）→ 1-氯-2-甲基丁烷：ClCH₂CH(CH₃)CH₂CH₃
  • 组合⑤（CH₃+CH₂+Cl）→ 2-氯戊烷：CH₃CH(Cl)CH₂CH₂CH₃

关键提醒

  • 2-氯戊烷与3-氯戊烷是直链骨架上的位置异构，学生容易漏掉其中一种。
  • 1-氯-2-甲基丁烷与1-氯-3-甲基丁烷是支链骨架（异戊烷骨架）上的位置异构，注意区分氯在伯碳还是仲碳，以及甲基支链的相对位置。
  • 可提醒学生：若从"戊烷3种骨架→一氯代物"角度思考，正戊烷给出2种（2-氯、3-氯），异戊烷给出2种（1-氯-2-甲基、1-氯-3-甲基），新戊烷给出0种（其唯一一氯代物不含—CH—），总计4种。两种思路可相互印证。

总结与课堂讲解建议

完整解答

分子式C₅H₁₁Cl对应戊烷的一氯代物。题目要求分子中必须含有2个—CH₃、2个—CH₂—、1个—CH—和1个—Cl。由于—CH—是唯一具有3个碳连接位点的基团，它必然充当碳骨架的分支点。以—CH—为中心枚举其3个连接位的所有可能组合，排除"2个—CH₃ + 1个—Cl"这一无法使剩余2个—CH₂—成链的方案后，剩余4种有效组合，恰好对应4种分子结构：

  1. 2-氯戊烷：CH₃CH(Cl)CH₂CH₂CH₃
  2. 3-氯戊烷：CH₃CH₂CH(Cl)CH₂CH₃
  3. 1-氯-2-甲基丁烷：ClCH₂CH(CH₃)CH₂CH₃
  4. 1-氯-3-甲基丁烷：ClCH₂CH₂CH(CH₃)₂

因此答案为 C. 4种。

课堂讲解建议

  1. 先放后收：先让学生尝试用"基团拼搭法"自己画，5分钟后用SCENE_1统一梳理思路，避免学生陷入盲目枚举。
  2. 双轨验证：讲完基团法后，可让学生用"戊烷骨架法"（正戊烷、异戊烷、新戊烷的一氯代物）再数一遍，两种方法结果一致（4种），能增强学生信心。
  3. 易错点强调：
  • 不要漏掉3-氯戊烷（学生常只想到2-氯戊烷）。
  • 区分1-氯-2-甲基丁烷与1-氯-3-甲基丁烷时，可让学生先找最长碳链，再确定氯和甲基的位次。
  • 新戊烷的一氯代物（ClCH₂C(CH₃)₃）虽然也是C₅H₁₁Cl，但其分子中无—CH—基团（中心碳为季碳），故不符合题意，这是常见的干扰项。
  1. 拓展提问：若题目改为"含有两个—CH₃、两个—CH₂—、一个—CH—和一个—Br"，答案是否改变？（结构种类不变，只是卤素替换，帮助学生迁移。）
