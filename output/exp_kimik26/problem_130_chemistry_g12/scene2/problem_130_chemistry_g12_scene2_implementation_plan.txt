[图示主题与整合说明]
- 本图示主题：分子式 C₅H₁₁Cl 且含两个 —CH₃、两个 —CH₂—、一个 —CH— 与一个 —Cl 的四种同分异构体结构验证
- 整合的步骤/概念：2-氯戊烷、3-氯戊烷、1-氯-2-甲基丁烷、1-氯-3-甲基丁烷的展开结构简式；碳原子基团类型颜色标注；基团数量实时验证表
- 教学价值：教师通过分步导航逐一举例，每步聚焦一种结构，配合右侧计数表即时验证基团数量是否符合题意，避免四种结构同时呈现造成信息过载；悬停高亮帮助学生识别不同基团在分子中的连接环境

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）+ 步骤0快捷跳转按钮 + 悬停高亮提示
- 控件说明：
  1. 「◀ 上一步」按钮：位于 (220,450)-(340,480)，点击回退到上一分步，步骤0时禁用（opacity 0.4）
  2. 「下一步 ▶」按钮：位于 (460,450)-(580,480)，点击前进到下一分步，步骤4时禁用
  3. 步骤指示器：位于 (400,465)，显示"步骤 n/4"
  4. 步骤0四个名称按钮：2×2网格，点击可直接跳转到对应步骤（1~4）
- 教师操作流程：
  1. 教师打开图示，首先看到步骤0概览，可简要说明"共有4种符合条件"
  2. 点击「下一步」进入步骤1，展示2-氯戊烷，引导学生观察主链、Cl位置、各基团颜色
  3. 鼠标悬停在任意基团上，该基团高亮并弹出tooltip显示基团类型与连接环境
  4. 引导学生查看右侧验证表，确认2/2/1/1全部符合，打勾
  5. 继续点击「下一步」依次展示步骤2~4，对比直链与支链、Cl位置变化对结构的影响
  6. 可随时点击「上一步」回退复习，或点击步骤0的按钮快速跳转

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript。原因：化学结构简式以文本标签和线段为主，无需复杂绘图库；原生SVG文本渲染清晰，便于精确控制每个原子和化学键的位置
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +----------------------------------------------------------+
  |                                                          |
  |   结构名称/标题 (285,100)            [验证表]            |
  |                                      (560,140)           |
  |                                                          |
  |      CH3 — CH — CH2 — CH2 — CH3                        |
  |     (85,200)  ↑                                    |
  |              Cl (185,155)                                |
  |                                                          |
  |      C1   C2   C3   C4   C5                              |
  |                                                          |
  |                                                          |
  |   [◀ 上一步]      步骤 1/4      [下一步 ▶]               |
  |   (220,465)       (400,465)     (580,465)                |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：变量 `currentStep`（0~4），`showStep(n)` 函数负责切换。所有步骤相关的 SVG 元素按步骤分组（class 如 `scene2-step-0`、`scene2-step-1` 等），切换时先隐藏所有组，再显示目标组。
  2. 坐标计算：主链基团采用等距网格（x = 85 + i×100, y = 200），化学键统一为水平方向从 (x_i+30, 200) 到 (x_{i+1}-30, 200)，垂直方向从 (x, 188) 到 (x, 170)。所有步骤复用同一套坐标模板，仅替换基团类型文本和 Cl/支链位置。
  3. 动画曲线：步骤切换使用 200ms 的 opacity 淡入淡出（CSS transition: opacity 0.2s ease），避免生硬跳转。
  4. 事件绑定：上一步/下一步按钮绑定 click；每个基团 `<g>` 元素绑定 mouseenter/mouseleave 实现悬停高亮；tooltip 使用一个绝对定位的 `<div>`，在 mouseenter 时更新内容并显示，mouseleave 时隐藏。
  5. 验证表绘制：使用 SVG `<rect>` 和 `<text>` 绘制，避免 foreignObject 兼容性问题。表头背景 `#f5f5f5`，数据行交替留白，符合/不符合通过 JS 动态设置文本内容和颜色。
  6. 步骤0按钮跳转：为四个概览按钮分别绑定 click → `showStep(1..4)`，实现快捷导航。
- **ID 命名规范**：所有交互元素 ID 必须以 `scene2-` 为前缀。例如：
  - 容器：`scene2-container`
  - SVG 画布：`scene2-svg`
  - 标题文本：`scene2-title`
  - 基团组：`scene2-group-ch3-c1`、`scene2-group-ch-c2` 等
  - 化学键：`scene2-bond-h-c1c2`、`scene2-bond-v-c2cl` 等
  - 验证表：`scene2-table`、`scene2-table-row-ch3` 等
  - 按钮：`scene2-btn-prev`、`scene2-btn-next`
  - 指示器：`scene2-step-indicator`
  - Tooltip：`scene2-tooltip`
  - 步骤组：`scene2-step-0`、`scene2-step-1`、…、`scene2-step-4`
- IIFE 隔离：所有 JavaScript 代码包裹在 `(function() { ... })()` 中，避免多场景合并时的全局变量污染。内部使用 `document.getElementById` 获取元素，禁止依赖全局 class 选择器。
