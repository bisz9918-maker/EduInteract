[分步序列]
- 步骤0（极性总览）：显示完整装置图（烧杯、电极、导线、电流表、开关、溶液标签、电极名称标签），并显示四个极性标注（阳极、阴极、负极、正极）。等待教师点击「下一步」。
- 步骤1（原电池反应）：在右侧烧杯外侧弹出原电池半反应式——Zn极左侧显示"Zn - 2e⁻ → Zn²⁺"（红边框文本框），C极右上方显示"2H⁺ + 2e⁻ → H₂↑"（蓝边框文本框），C极旁弹出H₂气泡。教师可讲解原电池自发反应。
- 步骤2（电解池反应）：在左侧烧杯外侧弹出电解池半反应式——Pt极左侧显示"2Cl⁻ - 2e⁻ → Cl₂↑"（蓝边框），Cu极右侧显示"2H₂O + 2e⁻ → H₂↑ + 2OH⁻"（红边框），Pt极旁弹出Cl₂气泡，Cu极旁弹出H₂气泡；Cu反应式中的"OH⁻"用绿色#2e7d32高亮。教师讲解外加电源驱动的电解反应。
- 步骤3（离子移动）：在两烧杯内部用虚线箭头展示离子迁移方向——左侧NaCl溶液中Na⁺（红箭头）移向Cu极、Cl⁻（蓝箭头）移向Pt极；右侧稀H₂SO₄中H⁺（红箭头）移向C极、SO₄²⁻（蓝箭头）移向Zn极；各箭头旁标注离子符号。教师讲解离子定向迁移规律。
- 步骤4（验证选项A）：底部选项卡片A-D出现，卡片A高亮（加粗边框），其余卡片置灰；C电极右侧显示红色叉号"×"，强调C为原电池正极而非电解池阳极。教师说明A错误。
- 步骤5（验证选项B）：卡片B高亮，其余置灰；Cu极反应式中的"OH⁻"保持绿色高亮，卡片B内部右侧显示绿色对勾"✓"；Cu极下方显示绿色对勾。教师说明B正确（阴极H⁺放电后OH⁻剩余）。
- 步骤6（验证选项C）：卡片C高亮，其余置灰；Pt极左侧显示红色叉号"×"，表示Na⁺并不移向Pt极（Na⁺箭头仍指向Cu极作为对照）。教师说明C错误（Na⁺移向阴极Cu）。
- 步骤7（验证选项D）：卡片D高亮，其余置灰；Pt极左上方显示"O₂"并叠加红色叉号"×"，强调Pt为惰性阳极、Cl⁻优先放电生成Cl₂而非O₂。教师说明D错误，完成全部验证。
（教师可随时点击「上一步」回退到任意步骤复习。）

[技术实现]
- JS库选择：原生 SVG + 原生 JavaScript（无外部库）。理由：本场景以静态几何图形、文本框、箭头为主，SVG的path/rect/text/marker足以满足；分步状态切换通过控制各g元素的display/opacity实现，无需复杂动画库。
- 画布尺寸：800 × 500 px（SVG viewBox="0 0 800 500"）
- 布局草图（ASCII）：
  ```
  +----------------------------------------------------------+
  |  顶部导线/电流表A/开关                                    |
  |       A                                                  |
  |  o---( )---o        (反应式框步骤1-2出现)                 |
  |  |        |                                              |
  |  |   _/   |                                              |
  |  |        |                                              |
  | +----------+            +----------+      [选项卡片]      |
  | | Pt    Cu |            | Zn    C  |      A B C D        |
  | | |      | |            | |      | |      (步骤4显)       |
  | | |      | |            | |      | |                     |
  | | |      | |            | |      | |                     |
  | +----------+            +----------+                     |
  | NaCl溶液                稀H₂SO₄                          |
  |                                                          |
  |              [上一步]  [下一步]                           |
  |                 步骤 X / 8                               |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 `currentStep`（0~7）控制当前步骤。每步对应一个 SVG `<g>` 分组（id="scene2-step0" ~ "scene2-step7"），通过设置 `display: none/block` 或 `opacity` 切换可见性。步骤4~7的选项卡片共用同一组元素，通过JS动态修改对应卡片的stroke/fill实现高亮。
  2. 坐标计算：所有坐标已在布局坐标表中精确到像素，代码agent直接按表实现。反应式文本框使用 `<foreignObject>` 或 SVG `<text>` + `<rect>` 背景实现；离子箭头使用 `<line>` + `<marker>` 定义箭头头部。
  3. 动画曲线：步骤切换时新增元素使用 CSS transition `opacity 0.3s ease` 淡入，无需复杂动画。离子箭头在步骤3可用 stroke-dasharray 动画实现"绘制"效果（可选）。
  4. 事件绑定：上一步/下一步按钮绑定 `click` 事件，更新 `currentStep` 后调用 `renderStep()` 函数，该函数遍历所有步骤分组设置显示状态，并更新按钮disabled状态（步骤0时上一步禁用，步骤7时下一步禁用）。
  5. 颜色与样式：严格使用大纲指定色值——背景#ffffff、主线#000000、蓝高亮#1565c0、红高亮#c62828、绿高亮#2e7d32、辅助线#888888。反应式框背景统一使用 rgba(200,200,200,0.2)。
  6. 气泡实现：使用 `<circle>` + `<animate>`（或CSS动画）实现轻微上下浮动，表示气体逸出。
- ID命名规范：所有 SVG 元素及 JS 变量必须以 `scene2-` 为前缀。例如：
  - 分组：`scene2-step0`, `scene2-step1`, ..., `scene2-step7`
  - 电极：`scene2-elec-pt`, `scene2-elec-cu`, `scene2-elec-zn`, `scene2-elec-c`
  - 反应式框：`scene2-rxn-pt`, `scene2-rxn-cu`, `scene2-rxn-zn`, `scene2-rxn-c`
  - 选项卡片：`scene2-opt-a`, `scene2-opt-b`, `scene2-opt-c`, `scene2-opt-d`
  - 按钮：`scene2-btn-prev`, `scene2-btn-next`
  - JS中仅用 `document.getElementById('scene2-xxx')` 获取元素，禁止全局class选择器，避免多场景合并时跨场景污染。
- IIFE隔离：所有 JavaScript 代码包裹在 `(function() { ... })();` 中，内部状态（currentStep等）不暴露到全局作用域。
