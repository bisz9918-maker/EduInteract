[图示主题与整合说明]
- 本图示主题：罂粟碱（papaverine）分子结构解析及苯环可取代位点分析
- 整合的步骤/概念：
  1) 异喹啉母核与苄基侧链的骨架识别；
  2) 分子式 C20H21NO4 的原子计数推导；
  3) 左侧苯环（异喹啉苯并环）可取代氢分析（5-位、8-位）；
  4) 右侧苯环（3,4-二甲氧基苄基）可取代氢分析（2'-位、5'-位、6'-位）；
  5) 一溴代物同分异构体总数汇总（2 + 3 = 5 种）。
- 教学价值：教师可按照"整体→局部→结论"的认知递进节奏，通过分步导航逐步展开分子结构信息，避免学生一次性面对高密度结构式而产生认知过载。高亮与淡化对比帮助学生快速定位当前讲解的局部骨架。

[分步序列]
- 步骤0（初始状态）：展示完整罂粟碱结构式，所有原子、化学键、OCH3标签、N标签、CH2标签均100%透明度显示。无高亮、无面板、无氢标记。
- 步骤1（骨架识别-母核）：点击「下一步」→ 异喹啉母核（左下苯环+右下吡啶环）高亮（蓝#1565c0，15%透明度填充），其余所有键/原子/标签透明度降至30%。在母核右侧显示标签"异喹啉母核"。
- 步骤2（骨架识别-侧链与取代基）：点击「下一步」→ 异喹啉母核高亮移除，苄基侧链（CH2桥+上方苯环）高亮（绿#2e7d32，15%透明度填充），四个OCH3以红色小圆高亮（20%透明度）。在侧链右侧显示标签"3,4-二甲氧基苄基"，在甲氧基附近显示标签"甲氧基取代基"。其余未高亮元素透明度30%。
- 步骤3（分子式推导）：点击「下一步」→ 高亮移除，所有结构恢复100%透明度。在结构式右下方弹出原子计数面板（520,240）。面板内逐行显示：
  - C：异喹啉母核 9C + 苄基侧链 7C + 四个OCH3 4C = 20C
  - H：异喹啉母核剩余 4H + 苄基侧链 5H + 四个OCH3 12H = 21H
  - N：1N
  - O：四个OCH3 4O
  - 汇总分子式：C20H21NO4（粗体显示）。
  每行以200ms间隔依次出现，形成累加动画。
- 步骤4（左侧苯环可取代位分析）：点击「下一步」→ 原子计数面板隐藏。整体结构淡化至30%，仅左侧苯环（异喹啉苯并部分，左下苯环）保持100%透明度并以(350,270)为中心放大1.1倍。在左下苯环的上顶点(350,246)标红色圆圈+"H"+"5-H"标签；在下顶点(350,294)标红色圆圈+"H"+"8-H"标签。在画面底部显示说明文字："左侧苯环可取代位：5-H、8-H，二者化学环境不同，贡献2种一溴代物"。
- 步骤5（右侧苯环可取代位分析）：点击「下一步」→ 左侧苯环恢复淡化，右侧苯环（上方苯环）保持100%透明度并以(450,195)为中心放大1.1倍。在上方苯环的右下顶点(470.8,207)标红色圆圈+"H"+"2'-H"标签；在左上顶点(429.2,183)标红色圆圈+"H"+"5'-H"标签；在左下顶点(429.2,207)标红色圆圈+"H"+"6'-H"标签。在画面底部显示说明文字："右侧苯环可取代位：2'-H、5'-H、6'-H，三者彼此不等价，贡献3种一溴代物"。
- 步骤6（结论汇总）：点击「下一步」→ 所有氢标记和放大效果移除，整体结构恢复100%透明度。在画面底部居中显示：
  - "一溴代物同分异构体总数"
  - "2 + 3 = 5 种"（粗体大字）
  - "1 mol 该化合物完全燃烧消耗 O2：23.25 mol"
  - "正确答案：A"

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于控件区左侧 (300,460)，宽80高30，灰色背景，点击回退到上一状态。
  - 「步骤指示器」：位于控件区居中 (400,455)，显示当前步骤编号（如"步骤 3 / 6"）。
  - 「下一步」按钮：位于控件区右侧 (420,460)，宽80高30，蓝色背景，点击前进到下一状态。
  - 步骤0时「上一步」禁用；步骤6时「下一步」禁用或变为「完成」。
- 教师操作流程：
  1. 教师打开图示，学生看到完整罂粟碱结构（步骤0）。
  2. 教师点击「下一步」，讲解异喹啉母核位置（步骤1）。
  3. 教师点击「下一步」，讲解苄基侧链与甲氧基（步骤2）。
  4. 教师点击「下一步」，引导学生一起数原子，面板逐行出现（步骤3）。
  5. 教师点击「下一步」，聚焦左侧苯环，分析5-H与8-H（步骤4）。
  6. 教师点击「下一步」，聚焦右侧苯环，分析2'-H、5'-H、6'-H（步骤5）。
  7. 教师点击「下一步」，展示总数5种及耗氧量23.25 mol，得出答案A（步骤6）。
  8. 教师可随时点击「上一步」回退到任意步骤复习。

[技术实现]
- JS库选择：原生SVG（DOM操作）+ 原生JavaScript。原因：有机分子结构以线条、多边形、文本为主，SVG的矢量特性可确保化学键清晰锐利；无需复杂物理引擎或3D渲染，原生JS足以控制透明度、显隐、transform。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |         上方苯环 + OCH3（顶部/右侧）              |
  |              |                                   |
  |             CH2                                  |
  |              |                                   |
  |    左下苯环--吡啶环(N)                            |
  |    (OCH3×2)                                      |
  |                                                  |
  |              [原子计数面板] (步骤3)               |
  |                                                  |
  |         [汇总结论] (步骤6)                        |
  |                                                  |
  |  [◀上一步]  步骤 X/6  [下一步▶]                  |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `currentStep`（0~6），每次点击按钮时更新状态，调用 `renderStep()` 函数。`renderStep()` 根据当前步骤设置各SVG元素的 `opacity`、`display`、`transform` 属性。
  2. 元素分组：将分子各部分用 `<g>` 分组，如 `scene1-group-isoquinoline`（异喹啉母核）、`scene1-group-benzyl`（苄基侧链）、`scene1-group-och3`（四个甲氧基）、`scene1-panel-count`（原子计数面板）、`scene1-group-left-ring`（左侧苯环可取代位）、`scene1-group-right-ring`（右侧苯环可取代位）。通过控制组的显隐简化状态切换。
  3. 放大动画：步骤4和步骤5使用 SVG `transform="translate(cx,cy) scale(1.1) translate(-cx,-cy)"`，配合 CSS `transition: transform 0.3s ease` 实现平滑放大。
  4. 原子计数面板动画：步骤3中使用 `setTimeout` 链或 `async/await` 逐行显示C/H/N/O计数，每行间隔200ms，最后显示分子式。
  5. 氢标记：红色圆圈使用 `<circle>`，白色"H"使用 `<text>` 居中于圆心，位点编号标签 `<text>` 放在圆圈外侧指定偏移位置。
  6. 淡化效果：非当前高亮元素统一设置 `opacity: 0.3`，当前高亮元素 `opacity: 1`，过渡时间0.3s。
  7. 按钮状态：步骤0禁用「上一步」；步骤6禁用「下一步」并可选显示「重新开始」。
- ID命名规范：所有SVG元素及JS变量必须以 `scene1-` 为前缀。例如：`scene1-bond-1`、`scene1-label-och3-top`、`scene1-highlight-isoquinoline`、`scene1-btn-prev`、`scene1-btn-next`、`scene1-panel-count`。JS中严格使用 `document.getElementById` 获取元素，禁止使用全局class选择器，避免多场景合并时跨场景污染。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })()` 立即执行函数中，不暴露全局变量。
- 化学键坐标常量：在JS顶部定义所有顶点坐标常量（如 `const ISO_V1 = {x:350, y:246}`），便于维护和微调，避免魔法数字。
