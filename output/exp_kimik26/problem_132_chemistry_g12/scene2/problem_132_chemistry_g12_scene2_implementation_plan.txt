[图示主题与整合说明]
- 本图示主题：含氮有机物（罂粟碱 C20H21NO4）完全燃烧耗氧量的计算过程
- 整合的步骤/概念：
  1) 燃烧反应方程式的配平（C/H/N 原子守恒）；
  2) 氧原子守恒法逐步计算所需 O2 的物质的量；
  3) 快捷公式 n(O2) = x + y/4 − z/2 的代入验证。
- 教学价值：教师可通过分步导航，逐层展示从配平到守恒再到公式验证的完整逻辑链，帮助学生建立规范的有机物燃烧耗氧量计算思维，并对比理解原子守恒法与快捷公式的一致性。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript。理由：本场景以静态文本、几何图形和显隐控制为主，无需复杂绘图库；原生 SVG 的 text/tspan 可精确控制化学式下标，原生 JS 足以驱动状态机。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |  800×500 画布                                     |
  |                                                  |
  |   [蓝底]C20H21NO4 + O2 → CO2 + H2O + N2         |  y=30~110
  |            C守恒  H守恒  N守恒                    |  y=115
  |  ------------------------------------------------|  y=145
  |   ① 产物总O = 20×2 + 10.5 = 50.5                |  y=180
  |   ② 分子内O = 4                                 |  y=220
  |   ③ 需O2 = (50.5 − 4)/2 = 23.25 mol             |  y=260
  |      [蓝底高亮]                                   |
  |  ------------------------------------------------|  y=310
  |   +----------------------------------------+     |  y=325~415
  |   |           快捷公式                      |     |
  |   |    n(O2) = x + y/4 − z/2              |     |
  |   |    = 20 + 21/4 − 4/2 = 23.25 mol      |     |
  |   +----------------------------------------+     |
  |  [上一步]   步骤 1/4   [下一步]                  |  y=440~490
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1) 状态机设计：使用变量 `currentStep`（取值1~4），每次点击按钮时更新状态并调用 `renderStep()`。
  2) 显隐控制：对每组元素设置初始 `display: none` 或 `opacity: 0`，在 `renderStep()` 中通过 `setAttribute('display', 'block/inline')` 或修改 `opacity` 控制。步骤切换时新出现元素使用 CSS transition 或 JS 定时器实现 300ms 淡入。
  3) 化学式下标：使用 SVG `<tspan baseline-shift="sub" font-size="14px">` 实现，如 C₂₀H₂₁NO₄。
  4) 关键数字红色高亮：在计算式与公式文本中，将 20、21、4、23.25 等数字用 `<tspan fill="#c62828" font-weight="bold">` 包裹。
  5) 高亮背景块：使用 `<rect>` 元素，通过 `rx="4"` 实现圆角；高亮块在 SVG 中先于对应文本绘制（即 DOM 中 rect 在 text 之前），确保文字压在背景块上方。
  6) 按钮交互：为「上一步」「下一步」rect/text 绑定 `click` 事件；步骤1时禁用「上一步」（fill 置灰 #bdbdbd），步骤4时禁用「下一步」。
  7) 坐标计算：所有文本基线位置已在坐标表中精确给出，代码 agent 直接采用；化学式宽度因字体略有浮动，但整体从 x=178 起始、总宽约 470px，在 800px 画布中左右留白充足，无需动态计算。
- ID 命名规范：所有交互元素 ID 必须以 `scene2-` 为前缀。例如：`scene2-reactant-text`、`scene2-co2-highlight`、`scene2-calc-row3`、`scene2-formula-card`、`scene2-btn-prev`、`scene2-btn-next` 等。JS 中严格使用 `document.getElementById` 获取元素，禁止全局 class 选择，避免多场景合并时跨场景污染。
- IIFE 隔离：所有 JavaScript 代码包裹在 `(function() { ... })()` 立即执行函数中，内部变量与函数不污染全局作用域。
