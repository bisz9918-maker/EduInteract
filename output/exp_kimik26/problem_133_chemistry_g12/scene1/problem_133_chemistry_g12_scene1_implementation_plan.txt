[图示主题与整合说明]
- 本图示主题：密闭容器内气体反应前后状态变化与活塞移动
- 整合的步骤/概念：
  1. 初始充入状态——标准状况下，左侧空气体积1、右侧H₂与O₂混合气体体积3，活塞偏左；
  2. 点燃爆炸瞬间——右侧气体点燃引爆，活塞先向左弹出（左侧暂时膨胀）；
  3. 恢复室温平衡——温度恢复后，活塞右滑并最终静止于容器正中央，左右体积均为2，右侧剩余过量气体（H₂或O₂）。
- 教学价值：教师可按课堂节奏分步呈现，先让学生观察初始体积比，再强调"先左弹"的瞬时现象，最后聚焦"右滑至中央"的关键数据，引导学生利用同温同压下体积比等于物质的量之比进行计算。

[分步序列]
- 初始状态（步骤0）：
  • 显示元素：容器外框、活塞在x=250、左侧蓝色填充(100~250)、右侧红色填充(250~700)、左/右尺寸线
  • 显示标签："空气"(175,145)、"H₂、O₂"(475,145)、"V=1"(175,355)、"V=3"(475,355)、"总体积 = 4"(400,385)、"同温同压"(400,125)、"标准状况"(120,125)
  • 隐藏元素：点燃引爆、左弹箭头、步骤2相关标签
  • 教学提示：教师可在此步让学生确认初始体积比为1:3，总体积为4。

- 步骤1（点燃瞬间）：
  • 触发：点击「下一步」
  • 视觉变化：
    - 活塞从x=250动画移动至x=200（左弹，历时500ms，ease-out）
    - 左侧填充区宽度从150px扩展至100px（x=100~200）
    - 右侧填充区起点从x=250变为x=200，宽度从450px收缩至500px（x=200~700）
    - 左尺寸线终点从250变为200；右尺寸线起点从250变为200
    - 新增显示："点燃引爆"(475,240)、左弹箭头(240,240)→(210,240)
  • 保留标签："空气"、"H₂、O₂"、"V=1"、"V=3"、"总体积=4"、"同温同压"、"标准状况"
  • 教学提示：教师强调"活塞先左弹"——爆炸瞬间气体急剧膨胀，推动活塞向左。

- 步骤2（恢复平衡）：
  • 触发：点击「下一步」
  • 视觉变化：
    - 活塞从x=200动画移动至x=400（右滑，历时800ms，ease-in-out）
    - 左侧填充区宽度变为300px（x=100~400）
    - 右侧填充区起点变为x=400，宽度变为300px（x=400~700），颜色由红变绿(#2e7d32 opacity 0.2)
    - 左尺寸线终点变为400；右尺寸线起点变为400
    - 隐藏："H₂、O₂"、"V=1"、"V=3"、"标准状况"、"点燃引爆"、左弹箭头
    - 新增显示："空气"(250,145)、"剩余气体"(550,140)、"(H₂或O₂)"(550,158)、"V=2"(250,355)、"V=2"(550,355)、"恢复至原温度"(120,125)
    - 保留："总体积=4"(400,385)、"同温同压"(400,125)
  • 教学提示：教师引导学生注意右侧体积从3收缩到2，说明有气体参与反应被消耗，且剩余1份气体；结合反应方程式2H₂+O₂=2H₂O，讨论H₂与O₂的体积比可能为4:5或7:2（对应选项C：③④）。

[交互方案]
- 交互类型：分步按钮导航（◀ 上一步 / 下一步 ▶）
- 控件说明：
  1. 「上一步」按钮：位于SVG底部偏左（left:280px, top:448px），点击后回退到上一状态，步骤0时禁用（置灰）。
  2. 「下一步」按钮：位于SVG底部偏右（left:430px, top:448px），点击后前进到下一状态，步骤2时禁用（置灰）。
  3. 步骤指示器：位于两按钮之间偏下（left:370px, top:478px），显示当前步骤文本如"步骤 1 / 3"。
- 教师操作流程：
  1. 教师打开图示，默认显示步骤0，讲解初始条件（左1右3，同温同压）。
  2. 点击「下一步」进入步骤1，观察活塞左弹动画，讲解"先左弹"的物理现象。
  3. 再次点击「下一步」进入步骤2，观察活塞右滑至中央，讲解体积变化数据（右3→2），引导学生列方程求解H₂与O₂体积比。
  4. 可随时点击「上一步」回退，复习前一状态的关键信息。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript（无外部库）。理由：本场景仅涉及简单几何图形（矩形、线段、文字）和基础属性动画，原生SVG足以胜任，无需引入D3.js等重型库，保持代码轻量。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  0    100        250        400        700    800
  |-----+----------+----------+----------+-----| x
  20    |                                    |   标题/状态区(y=20~100)
        |  [标准状况]      [同温同压]       |
  125   |    ·             ·               |
        |  [空气]                       [H₂、O₂]
  145   |    ·                           ·   |
        |  +----------------------------+    |
  160   |  |\\\\\\\\\\\\\\\\|            |    |  容器外框(y=160~320)
        |  |  左侧填充    |   右侧填充   |    |
  240   |  |            | [点燃引爆]   |    |  步骤1内部标签
        |  |            |              |    |
  320   |  +----------------------------+    |
        |    ·                           ·   |
  338   |  - - - - - -    - - - - - - - - -  |  尺寸线
        |    ·                           ·   |
  355   |   V=1                         V=3  |

  490   |                                    |
  500   +------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `var currentStep = 0;`（取值0/1/2），每次点击按钮时更新状态并调用 `renderStep()` 统一渲染。
  2. 活塞与填充区动画：使用 `requestAnimationFrame` 实现平滑插值动画。定义目标x坐标（步骤0:250，步骤1:200，步骤2:400），在300~800ms内线性或ease插值，每帧更新活塞line的x1/x2、填充区rect的x/width、尺寸线line的x2/x1。
  3. 元素显隐控制：为每个步骤相关的SVG元素组设置CSS类 `.scene1-hidden { display: none; }`，在 `renderStep()` 中通过 `classList.add/remove` 切换。避免使用 `style.display` 硬编码，便于维护。
  4. 颜色切换：步骤2右侧填充区颜色从#c62828变为#2e7d32，通过setAttribute('fill', color)在renderStep时切换。
  5. 按钮状态：步骤0时禁用「上一步」（opacity:0.4, pointer-events:none），步骤2时禁用「下一步」。
  6. 事件绑定：使用 `document.getElementById('scene1-btn-prev').addEventListener('click', ...)` 和 next 按钮，避免使用内联onclick。
- ID命名规范：所有SVG元素及HTML控件ID必须以 `scene1-` 为前缀。例如：
  - 容器外框：`scene1-container-frame`
  - 活塞：`scene1-piston`
  - 左侧填充：`scene1-left-fill`
  - 右侧填充：`scene1-right-fill`
  - 上一步按钮：`scene1-btn-prev`
  - 下一步按钮：`scene1-btn-next`
  - 步骤指示器：`scene1-step-indicator`
  - 标签类：`scene1-label-air`、`scene1-label-h2o2`、`scene1-label-ignite`、`scene1-label-remaining` 等
  - 箭头：`scene1-arrow-left-bounce`
  - 尺寸线：`scene1-dim-left`、`scene1-dim-right`
  JS中严格使用 `document.getElementById` 获取元素，禁止全局class选择器，防止多场景合并时跨场景污染。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 立即执行函数中，避免全局变量泄漏。
