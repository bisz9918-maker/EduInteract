[图示主题与整合说明]
- 本图示主题：反应后物质的量推导与氢氧混合气过量计算
- 整合的步骤/概念：①初始物质的量设定（空气与混合气体积比1:3）②利用左侧空气等温变化推导最终压强P₂=P₁/2，进而求出右侧剩余总物质的量n_末=1 mol ③氢氧反应方程式与体积变化本质（H₂O为液态）④H₂过量时的计算（体积比7:2）⑤O₂过量时的计算（体积比4:5）⑥结论与选项匹配（答案C）
- 教学价值：教师通过分步导航，可逐步展示从已知条件→气体定律推导→化学反应本质→分类讨论→结论的完整逻辑链；两种过量情况的左右对比布局，便于学生直观比较；关键数值与正确答案的高亮设计，强化记忆点。

[分步序列]
- 初始状态（步骤0 / 第1步）：显示容器示意图（空气:混合气=1:3），右侧显示比例式"n(空气)∶n(混)=1∶3"及设定"设n(空气)=1 mol，n(混)=3 mol"。底部控件栏可用，选项区隐藏。
- 步骤1（第2步）：点击"下一步"→ 容器图隐藏，上部居中显示公式"P₁V₁/n₁ = P₂V₂/n₂"及完整推导过程：左侧空气V₁=1→V₂=1（活塞中央）得P₂=P₁/2；右侧代入得n_末=1 mol。结论"n_末 = 1 mol"用红色高亮框突出。
- 步骤2（第3步）：点击"下一步"→ 推导内容隐藏，上部居中显示化学方程式"2H₂ + O₂ → 2H₂O(l)"，下方红色标注"H₂O为液态，不占气体体积"，再下方说明"反应后气体总物质的量减少：3 mol → 1 mol"。
- 步骤3（第4步）：点击"下一步"→ 方程式隐藏，下部左侧显示绿色计算框（情况一：H₂过量），展示完整代数推导：设O₂=y，H₂=3−y；O₂完全反应，剩余H₂=(3−y)−2y=1；解得y=2/3，H₂=7/3；结果V(H₂)∶V(O₂)=7∶2，对应选项④。右框隐藏。选项区显示（不高亮）。
- 步骤4（第5步）：点击"下一步"→ 左框隐藏，下部右侧显示紫色计算框（情况二：O₂过量），展示完整代数推导：设H₂=x，O₂=3−x；H₂完全反应，剩余O₂=(3−x)−x/2=1；解得x=4/3，O₂=5/3；结果V(H₂)∶V(O₂)=4∶5，对应选项③。选项区显示（不高亮）。
- 步骤5（第6步 / 最终步）：点击"下一步"→ 上部显示结论标题"结论：两种过量情况"及大字号红色高亮"答案 C. ③④"；下部左右两框同时显示（各框标题+结果行保留，中间推导可简化或完整展示）；选项区A/B/C/D并列，选项C外加红色高亮框。教师可点击"上一步"回退至任意步骤复习。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「◀ 上一步」按钮：位于底部控件栏左侧(280,455)-(380,485)，点击后回退至上一步，state=0时禁用（灰色）。
  2. 步骤指示器：位于底部控件栏居中(400,475)，显示当前步骤序号"X / 6"。
  3. 「下一步 ▶」按钮：位于底部控件栏右侧(420,455)-(520,485)，点击后前进至下一步，state=5时禁用（灰色）。
- 教师操作流程：
  1. 教师打开图示，首先呈现步骤0（初始条件），向学生说明容器左右两侧的气体体积比。
  2. 点击「下一步」进入步骤1，讲解理想气体状态方程比例式的应用，强调左侧空气压强变化如何决定右侧剩余物质的量。
  3. 点击「下一步」进入步骤2，写出氢氧反应方程式，特别强调水在标准状况下为液态，这是气体物质的量减少的关键。
  4. 点击「下一步」进入步骤3，展示H₂过量的完整计算过程，得出体积比7:2（选项④）。
  5. 点击「下一步」进入步骤4，展示O₂过量的完整计算过程，得出体积比4:5（选项③）。
  6. 点击「下一步」进入步骤5，并列展示两种结果，高亮正确答案C（③④），完成闭环讲解。讲解过程中可随时点击「上一步」回退复习关键推导。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本场景以几何图形、文本标签、矩形框的显示/隐藏为主，无复杂函数绘图、3D或粒子动画，原生SVG足以满足需求，且无需引入外部CDN依赖，加载更快、兼容性更好。
- 画布尺寸：800 × 500 px（固定画布，SVG viewBox="0 0 800 500"）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |  [通用推导区 y=40~210]                           |
  |   步骤0: 容器图(左) + 比例/设定(右)              |
  |   步骤1: 公式 + 推导 + 高亮结论                  |
  |   步骤2: 化学方程式 + 液态水标注                 |
  |   步骤5: 结论标题 + 答案高亮                     |
  +--------------------------------------------------+
  |  [计算框区 y=220~410]                            |
  |   +----------------------+  +------------------+ |
  |   | 左框(绿):情况一      |  | 右框(紫):情况二  | |
  |   | H₂过量              |  | O₂过量           | |
  |   | 推导...             |  | 推导...          | |
  |   | 结果 7:2            |  | 结果 4:5         | |
  |   +----------------------+  +------------------+ |
  +--------------------------------------------------+
  |  [选项区 y=413~438]   A    B    [C]    D        |
  +--------------------------------------------------+
  |  [控件栏 y=445~485]  [◀上一步] 2/6 [下一步▶]    |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用全局变量 `var scene2_state = 0;`（范围0~5），共6个状态。每个状态对应一个SVG `<g>` 组（id="scene2-step0" ~ "scene2-step5"），组内包含该步骤全部视觉元素。`updateScene()` 函数根据当前state设置对应组的 `display="block"`，其余组 `display="none"`。
  2. 步骤5特殊处理：步骤5需要同时显示左右两框（scene2-left-box 和 scene2-right-box）以及选项区高亮。为避免与步骤3/4的独立显示逻辑冲突，左右框作为独立组（不嵌套在step3/step4内），通过状态判断在步骤3显示左框、步骤4显示右框、步骤5同时显示两者。
  3. 化学方程式下标：使用 `<tspan baseline-shift="sub" font-size="0.7em">` 实现H₂、O₂、H₂O中的下标2，确保化学式规范。
  4. 高亮框实现：使用 `<rect>` 元素，fill="rgba(198,40,40,0.15)"，stroke="#c62828"，stroke-width="2"，rx="4"；文字叠在矩形上方（SVG中后定义的元素在上层）。
  5. 按钮禁用样式：通过JS动态修改按钮rect的fill属性（启用时#1565c0，禁用时#cccccc）及pointer-events。
  6. 动画曲线：无需复杂动画，状态切换直接显示/隐藏即可；如需柔和过渡，可在CSS中设置 `transition: opacity 0.2s ease`（若用HTML overlay方式），但SVG内建议直接用display切换以保证清晰。
  7. 事件绑定：上一步/下一步按钮绑定click事件，调用 `scene2_prev()` / `scene2_next()`，内部修改state并调用 `updateScene()`。
- ID命名规范：所有交互元素及SVG节点ID必须以 `scene2-` 为前缀。例如：
  - 步骤组：`scene2-step0`, `scene2-step1`, ..., `scene2-step5`
  - 左框：`scene2-left-box`
  - 右框：`scene2-right-box`
  - 按钮：`scene2-prev-btn`, `scene2-next-btn`
  - 指示器：`scene2-step-indicator`
  - 高亮框：`scene2-highlight-n末`, `scene2-highlight-answer`, `scene2-highlight-optionC`
  - JS中严格使用 `document.getElementById()` 获取元素，禁止用 `querySelectorAll` 配合全局class，避免多场景合并时跨场景选择器污染。
- IIFE隔离：所有JavaScript代码必须包裹在立即执行函数表达式中：
  ```javascript
  (function() {
    var state = 0;
    var maxState = 5;
    function updateScene() { ... }
    function scene2_prev() { ... }
    function scene2_next() { ... }
    // 事件绑定
    document.getElementById('scene2-prev-btn').addEventListener('click', scene2_prev);
    document.getElementById('scene2-next-btn').addEventListener('click', scene2_next);
    updateScene();
  })();
  ```
