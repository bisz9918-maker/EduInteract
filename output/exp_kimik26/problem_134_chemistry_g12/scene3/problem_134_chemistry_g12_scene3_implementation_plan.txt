[图示主题与整合说明]
- 本图示主题：立方烷（C）的芳香烃同分异构体及性质分析
- 整合的步骤/概念：立方烷分子式确认 → 苯乙烯结构书写与分子式对比 → 碳碳双键识别 → 酸性高锰酸钾氧化性质 → 选项C正确性判断
- 教学价值：教师通过分步导航，引导学生从同分异构体概念出发，识别苯乙烯中的碳碳双键官能团，再联系烯烃的氧化性质，最终判断选项C的正确性。图示将抽象的有机物结构与性质判断可视化，适合课堂逐步推演。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript。理由：本场景以静态几何图形（立方体线框、苯环六边形、线段双键、烧杯路径）为主，无复杂函数图或3D渲染，原生SVG足以保证清晰度且无需引入额外库，减少加载开销。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图（ASCII）：
  ```
  +----------------------------------------------------------+
  |                                                          |
  |   C（立方烷）              苯乙烯                         |
  |      |                      |                            |
  |   [立方烷线框]          [苯环]=[CH=CH2]                  |
  |   C₈H₈                 芳香烃  C₆H₅-CH=CH₂               |
  |                        分子式：C₈H₈                      |
  |                              碳碳双键（步骤2红）          |
  |                                                          |
  |      [烧杯]           可使酸性高锰酸钾溶液褪色            |
  |     KMnO₄                     选项 C ✓                   |
  |                                                          |
  |           底部说明文字（随步骤变化）...                    |
  |                                                          |
  |        [上一步]   步骤 X/5   [下一步]                     |
  +----------------------------------------------------------+
  画布 800×500，控件栏在底部 y=440~490（SVG 内绝对定位）
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `let currentStep = 0;` 记录当前步骤（0~4）。`renderStep()` 函数根据 currentStep 设置各元素的 `display` 或 `opacity` 属性。所有需动态显示的元素初始 `opacity: 0` 或 `visibility: hidden`，由状态机控制显隐。
  2. 坐标计算：苯环六边形顶点使用三角函数计算（中心+半径+60°间隔），避免硬编码误差。双键内侧平行线通过计算边的法向量偏移4px得到。
  3. 动画曲线：元素淡入使用 CSS transition `opacity 0.3s ease-in-out`；双键高亮使用 CSS transition `stroke 0.2s ease, stroke-width 0.2s ease`。
  4. 事件绑定：上一步/下一步按钮绑定 `click` 事件，修改 currentStep 后调用 renderStep()。所有事件处理在 IIFE 内部完成，避免全局污染。
  5. 烧杯绘制：使用 SVG `<path>` 绘制梯形轮廓，溶液使用 `<path>` 填充底部梯形，设置 `fill-opacity="0.3"`。
  6. 立方烷虚线：被遮挡的三条棱使用 `stroke-dasharray="4,4"` 和 `opacity="0.5"` 表示。
- ID 命名规范：所有交互元素和可控制显示的元素 ID 必须以 `scene3-` 为前缀。例如：`scene3-cube-frame`、`scene3-benzene-hex`、`scene3-vinyl-double-top`、`scene3-vinyl-double-bottom`、`scene3-beaker`、`scene3-solution`、`scene3-label-double-bond`、`scene3-label-conclusion`、`scene3-btn-prev`、`scene3-btn-next`、`scene3-step-text`。JS 中严格使用 `document.getElementById` 获取元素，禁止跨场景选择器。
- IIFE 隔离：所有 JavaScript 代码包裹在 `(function() { ... })();` 中，确保变量和函数不泄漏到全局作用域，避免多场景合并时的命名冲突。
