[图示主题与整合说明]
- 本图示主题：选项A（醋酸与氨水反应）的离子浓度变化与导电性曲线
- 整合的步骤/概念：弱电解质初始电离 → 中和反应生成强电解质盐 → 恰好中和时离子浓度最大 → 过量弱碱稀释 → 导电性先增后减的定量曲线
- 教学价值：教师通过分步导航，可逐帧展示溶液中分子/离子的消长与灯泡亮度的因果关系，最后叠加导电性-体积曲线，帮助学生建立微观粒子行为与宏观导电性之间的定量联系

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步 ▶）
- 控件说明：
  1. 「◀ 上一步」按钮：位置(290,452)，宽85×高30，点击回退到上一状态，步骤0时禁用
  2. 「下一步 ▶」按钮：位置(425,452)，宽85×高30，点击前进到下一状态，步骤4时禁用
  3. 步骤指示器：位置(390,472)，显示"步骤 X / 4"
- 教师操作流程：教师先展示步骤0说明弱电解质电离不完全；点击「下一步」逐帧展示反应进程，引导学生观察灯泡亮度与离子数量的关系；到达步骤4时，将学生注意力引向下方曲线图，总结"先增后减"规律；可随时点击「上一步」回退复习关键帧

[技术实现]
- JS库选择：原生SVG（所有元素均为几何图形、曲线和简单粒子，SVG的DOM操作即可满足，无需引入外部库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [800×500 画布]
  +--------------------------------------------------+
  |  溶液标题(190,125)                                 |
  |  +----------------+     电池(340,55)               |
  |  |   烧杯装置      |     灯泡(340,120)              |
  |  |  (120,150)     |     图例(310,195~288)          |
  |  |   溶液+粒子     |                                |
  |  +----------------+                                |
  |       状态说明(190,305)                            |
  |  曲线图区(y=315~435)                               |
  |  Y轴(420,320~420)  X轴(420~760,420)               |
  |  曲线(440,400→600,330→720,380)                    |
  |  中和点垂线(600,330~420)  标签(600,308)            |
  +--------------------------------------------------+
  |  [◀上一步]  步骤 X/4  [下一步▶]  (y=452~472)      |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：变量 currentStep（0~4），每一步通过一个配置对象定义：particles（各类型粒子id列表）、bulbOpacity、titleText、statusText、curvePoint、curveColor
  2. 粒子显示/隐藏：每个粒子赋予独立ID（如 scene2-p-ch3cooh-1），通过切换 CSS class "hidden"（opacity:0）或 "visible"（opacity:1）实现，加 transition: opacity 0.3s 实现淡入淡出
  3. 灯泡亮度：直接修改灯泡 circle 元素的 fill-opacity 属性（0.3→0.6→1.0→0.5）
  4. 曲线图当前点：用一个可移动的 circle 元素（scene2-curve-dot），通过 setAttribute('cx', x) / setAttribute('cy', y) 切换位置；步骤4时额外给曲线 path 加 class "highlight" 变蓝色
  5. 中和点垂线与标签：步骤2及以后显示（display: block），步骤0-1隐藏（display: none）
  6. 按钮禁用状态：通过添加/移除 disabled 属性及对应CSS样式（opacity: 0.4, cursor: not-allowed）实现
  7. 事件绑定：上一步/下一步按钮绑定 click 事件，调用 updateScene(step) 函数
- ID命名规范：所有交互元素ID必须以 scene2- 为前缀，例如 scene2-beaker-outline、scene2-bulb、scene2-p-ch3cooh-1、scene2-curve-path、scene2-btn-prev、scene2-btn-next
- IIFE隔离：所有JavaScript代码包裹在 (function() { ... })() 中，避免多场景合并时全局变量污染
