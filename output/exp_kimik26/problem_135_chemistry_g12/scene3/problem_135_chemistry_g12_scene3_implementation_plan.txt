[图示主题与整合说明]
- 本图示主题：四个选项（A/B/C/D）的溶液导电性变化曲线汇总对比
- 整合的步骤/概念：
  1. 选项A（醋酸+氨水）：弱电解质反应生成强电解质盐，导电性先增大后稀释减小
  2. 选项B（AgNO₃+HCl）：强电解质间反应生成沉淀和强酸，离子浓度基本不变
  3. 选项C（盐酸+NaCl溶液）：强电解质混合，离子总量增加，导电性逐渐增大
  4. 选项D（H₂SO₄+BaCl₂）：生成沉淀且溶液体积增大，导电性逐渐减小
- 教学价值：教师先通过四条曲线整体对比建立全局认知（"哪条是先增后减？"），再逐个高亮分析局部反应原理，最后回到整体进行总结性提问，符合"整体—局部—整体"的认知规律

[分步序列]
- 步骤0（初始状态）：
  - 四条曲线均以2px实线、100%不透明度显示
  - 右侧四个卡片仅显示选项标签行（圆点+标签文字），方程式和原理文字透明度为0（隐藏）
  - 所有卡片边框1px，不透明度100%
  - 步骤指示器显示"步骤 0/5"
  - 教学用途：教师引导学生观察四条曲线整体形态，提问"哪条曲线呈现先增大后减小的趋势？"

- 步骤1（高亮选项A）：
  - 曲线A：stroke-width从2px变为4px，保持100%不透明度
  - 曲线B/C/D：stroke-width保持2px，不透明度降至30%
  - 卡片A：展开显示方程式（2行）和原理文字，边框加粗至2px，背景填充rgba(21,101,192,0.1)
  - 卡片B/C/D：保持仅显示标签，不透明度降至30%
  - 步骤指示器显示"步骤 1/5"
  - 教学用途：教师讲解醋酸与氨水反应生成强电解质醋酸铵，导电性先因生成强电解质而增大，后因过量氨水稀释而减小

- 步骤2（高亮选项B）：
  - 曲线B：stroke-width变为4px，100%不透明度
  - 曲线A/C/D：stroke-width 2px，不透明度30%
  - 卡片B：展开显示方程式和原理，边框2px，背景填充rgba(198,40,40,0.1)
  - 卡片A/C/D：仅显示标签，不透明度30%
  - 步骤指示器显示"步骤 2/5"
  - 教学用途：教师讲解AgNO₃与HCl反应生成AgCl沉淀和HNO₃，离子总浓度变化不大，导电性基本不变

- 步骤3（高亮选项C）：
  - 曲线C：stroke-width变为4px，100%不透明度
  - 曲线A/B/D：stroke-width 2px，不透明度30%
  - 卡片C：展开显示方程式和原理，边框2px，背景填充rgba(46,125,50,0.1)
  - 卡片A/B/D：仅显示标签，不透明度30%
  - 步骤指示器显示"步骤 3/5"
  - 教学用途：教师讲解向盐酸中加入NaCl溶液，强电解质叠加使离子浓度增大，导电性逐渐增大

- 步骤4（高亮选项D）：
  - 曲线D：stroke-width变为4px，100%不透明度
  - 曲线A/B/C：stroke-width 2px，不透明度30%
  - 卡片D：展开显示方程式和原理，边框2px，背景填充rgba(123,31,162,0.1)
  - 卡片A/B/C：仅显示标签，不透明度30%
  - 步骤指示器显示"步骤 4/5"
  - 教学用途：教师讲解H₂SO₄与BaCl₂反应生成BaSO₄沉淀和HCl，虽然生成强酸但溶液体积增大且沉淀带走离子，导电性逐渐减小

- 步骤5（总结回顾）：
  - 四条曲线均恢复为2px实线、100%不透明度（同步骤0）
  - 右侧四个卡片均恢复为仅显示标签、100%不透明度、1px边框
  - 步骤指示器显示"步骤 5/5"
  - 教学用途：教师进行总结性提问，让学生再次确认正确答案为A，巩固"先增后减"对应的曲线特征与反应原理

  5. 可随时点击「上一步」回退到任意步骤复习

[技术实现]
- JS库选择：原生SVG + 原生JavaScript（场景为静态几何图形与简单状态切换，无需引入D3/Three.js等重型库，减少依赖）
- 画布尺寸：800×500 px（固定画布，SVG viewBox="0 0 800 500"）
- 布局草图：
  ```
  +----------------------------------------------------------+
  |  ↑导电性（相对）                                          |
  |  |    图例 +----+                                         |
  |  |         |A B |      选项分析                            |
  | D↓        |C D |      +----------------------+           |
  |  |   C↑    +----+      | ● A. 醋酸+氨水       |           |
  |  |    B───  A  ∧       |   [方程式]            |           |
  |  |              ╲      |   [原理]              |           |
  |  +---------------→     +----------------------+           |
  |    加入试剂体积        | ● B. AgNO₃+HCl       |           |
  |                        |   [方程式]            |           |
  |                        |   [原理]              |           |
  |                        +----------------------+           |
  |                        | ● C. 盐酸+NaCl       |           |
  |                        |   [方程式]            |           |
  |                        |   [原理]              |           |
  |                        +----------------------+           |
  |                        | ● D. H₂SO₄+BaCl₂     |           |
  |                        |   [方程式]            |           |
  |                        |   [原理]              |           |
  |                        +----------------------+           |
  |                                                           |
  |            [◀ 上一步]  步骤 0/5  [下一步 ▶]               |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `currentStep`（范围0~5），每次点击按钮时更新状态并调用 `renderStep()` 函数
  2. 元素显隐控制：通过切换CSS类名实现，定义 `.highlight`（stroke-width:4px, opacity:1）、`.dimmed`（opacity:0.3）、`.hidden-text`（opacity:0）等类
  3. 动画曲线：所有过渡使用CSS `transition: all 0.3s ease`，确保曲线粗细和透明度变化平滑
  4. 按钮禁用逻辑：`currentStep === 0` 时给上一步按钮添加 `disabled` 类；`currentStep === 5` 时给下一步按钮添加 `disabled` 类
  5. 卡片内容切换：每个卡片内的方程式/原理文本初始 `opacity:0`，高亮时通过添加 `.expanded` 类变为 `opacity:1`；同时卡片背景色和边框色通过对应颜色类切换
  6. 坐标计算：曲线A使用SVG path的二次贝塞尔命令 `Q` 实现平滑拱形；其余曲线使用 `line` 元素
  7. 图例与曲线颜色严格对应：A蓝#1565c0、B红#c62828、C绿#2e7d32、D紫#7b1fa2
- ID命名规范（scene3-前缀）：
  - 坐标轴：scene3-axis-x, scene3-axis-y, scene3-axis-x-label, scene3-axis-y-label
  - 曲线：scene3-curve-a, scene3-curve-b, scene3-curve-c, scene3-curve-d
  - 图例：scene3-legend-box, scene3-legend-a-line, scene3-legend-a-text（以此类推B/C/D）
  - 卡片：scene3-card-a, scene3-card-b, scene3-card-c, scene3-card-d
  - 卡片内容：scene3-card-a-title, scene3-card-a-eq1, scene3-card-a-eq2, scene3-card-a-principle（以此类推B/C/D）
  - 控件：scene3-btn-prev, scene3-btn-next, scene3-step-indicator
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })()` 中，避免全局变量污染，确保多场景合并时互不干扰
