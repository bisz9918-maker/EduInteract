[图示主题与整合说明]
- 本图示主题：星际分子球棍模型的原子组成与物质类别判断
- 整合的步骤/概念：图例识别 → 氢原子端位定位 → 碳链骨架识别 → 第三种原子X确认 → 烃类定义应用（排除选项A）→ 成键特征分析（排除选项D）
- 教学价值：教师通过分步导航，引导学生从宏观模型逐步聚焦到微观原子种类，再叠加化学概念（烃类定义、卤素成键特征），形成"观察→识别→推理→结论"的完整逻辑链，适合课堂边讲边点。

[分步序列]
- 步骤0（初始状态）：显示完整球棍模型（H-C9-X）、化学键、标记①②③、图例框。无高亮、无结论、无选项标记。教师可在此让学生整体观察分子结构。
- 步骤1（点击下一步）：H球外圈出现蓝色高亮（#1565c0, 3px, 发光），显示引线+标签"氢原子"（H球正上方）。引导学生确认左端白球为氢原子。
- 步骤2（点击下一步）：隐藏H高亮和"氢原子"标签；所有9个C球同时出现蓝色高亮外圈，显示引线+标签"碳原子"（碳链中点上方）。引导学生识别碳链骨架。
- 步骤3（点击下一步）：隐藏C高亮和"碳原子"标签；X球出现蓝色高亮外圈，显示引线+标签"第三种原子X"（X球右上方）。引导学生确认分子含三种不同原子。
- 步骤4（点击下一步）：隐藏X高亮和"第三种原子X"标签；结论框显示两行绿色文字："该分子含有C、H、X三种元素" / "而烃类仅由C、H两种元素组成"；右下角选项A框变红，文字"A · 烃类 → 错误"。完成选项A的排除。
- 步骤5（点击下一步/最终）：结论框追加第三行绿色文字："X与碳原子之间将形成三键，而Cl、F通常只能形成单键"；选项D框变红，文字"D · Cl/F → 错误"。完成选项D的排除，为后续分析选项B、C做铺垫。
- 教师可随时点击「上一步」回退到任意步骤复习。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于底部中央偏左 (310,455)，90×34px，圆角，背景#1565c0，文字白色。点击回退到上一状态，step0时禁用（opacity 0.4）。
  - 「下一步」按钮：位于底部中央偏右 (480,455)，90×34px，样式同上。点击推进到下一状态，step5时禁用或变为「完成」。
  - 步骤指示文本：位于两按钮下方居中 (440,495)，显示"步骤 X / 5"，字号12px，颜色#666。
- 教师操作流程：
  1. 教师展示步骤0，让学生观察完整分子模型和图例。
  2. 点击「下一步」进入步骤1，讲解左端白球为氢原子。
  3. 继续点击「下一步」依次展示碳原子、第三种原子X。
  4. 进入步骤4，引导学生根据"三种原子"推出"不是烃类"，观察选项A变红。
  5. 进入步骤5，补充成键知识排除卤素，观察选项D变红。
  6. 可随时回退到前面步骤，让学生复述推理链。

[技术实现]
- JS库选择：原生 SVG + 原生 JavaScript。原因：本场景为静态几何图形（圆、线、文本）的分步显隐切换，无需复杂绘图库；SVG的DOM操作可直接控制每个元素的display/opacity/stroke，配合CSS transition实现平滑高亮。
- 画布尺寸：800 × 500 px（SVG viewBox="0 0 800 500"）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |     ○——●——●——●——●——①——●——●——②——●——●——③/☓        |  y=100~220
  |    H  C1 C2 C3 C4    C5 C6 C7    C8 C9  X        |
  |                                                  |
  |   ┌─────────┐    ┌──────────────────┐  ┌──────┐ |  y=300~430
  |   │ 图例    │    │   结论文本框      │  │选项A │ |
  |   │ ○ H    │    │   （步骤4/5显示） │  │选项D │ |
  |   │ ● C    │    │                   │  └──────┘ |
  |   │ ☓ X    │    └──────────────────┘           |
  |   └─────────┘                                   |
  |          [◀上一步]      [下一步▶]                |  y=440~490
  |                  步骤 X / 5                      |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：变量 `currentStep`（0~5）。每步用一个配置对象定义 `{ show: ['id1','id2'], hide: ['id3'], highlight: ['ball-h'] }`，通过统一函数 `renderStep()` 遍历显隐。
  2. 高亮实现：为每个球预置一个外圈 `<circle class="highlight-ring">`（r=20, stroke=#1565c0, fill=none, stroke-width=3, filter="url(#glow)"），默认 `display:none`；高亮时改为 `display:block` 并添加CSS动画（0.3s ease-out放大+发光）。
  3. 斜线纹理：SVG `<pattern id="scene1-hatch">` 内嵌 `<rect fill="#d7ccc8"/>` + `<line stroke="#8d6e63"/>`（patternTransform="rotate(45)"），X球 fill="url(#scene1-hatch)"。
  4. 结论文本逐行显示：步骤4时两行同时淡入（opacity 0→1, 0.4s）；步骤5时第三行追加滑入（translateY 10px→0, 0.3s）。
  5. 选项标记：步骤4/5时对应 `<rect>` 背景从透明过渡到 #c62828@0.2，文字颜色同步变红。
  6. 事件绑定：按钮绑定 `click` 事件，修改 `currentStep` 后调用 `renderStep()`；键盘左右箭头键同步支持切换。
  7. 动画曲线：高亮外圈使用 `cubic-bezier(0.25, 0.1, 0.25, 1)`；文本使用 `ease-out`；整体过渡时长 0.3~0.5s，避免过快导致学生跟不上。
- ID命名规范：所有SVG元素及控件ID必须以 `scene1-` 为前缀。示例：
  - 球体：`scene1-ball-h`, `scene1-ball-c1` ~ `scene1-ball-c9`, `scene1-ball-x`
  - 化学键：`scene1-bond-1` ~ `scene1-bond-10`
  - 标记：`scene1-marker-1`, `scene1-marker-2`, `scene1-marker-3`
  - 高亮外圈：`scene1-hl-h`, `scene1-hl-c1` ~ `scene1-hl-c9`, `scene1-hl-x`
  - 标签：`scene1-label-h`, `scene1-label-c`, `scene1-label-x`
  - 引线：`scene1-lead-h`, `scene1-lead-c`, `scene1-lead-x`
  - 图例组：`scene1-legend-group`
  - 结论组：`scene1-conclusion-group`
  - 选项A/D：`scene1-opt-a`, `scene1-opt-d`
  - 按钮：`scene1-btn-prev`, `scene1-btn-next`
  - 步骤文本：`scene1-step-text`
  - JS中严格使用 `document.getElementById('scene1-xxx')` 获取元素，禁止全局class选择器，避免多场景合并时跨场景污染。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，变量不泄露全局作用域。
