[图示主题与整合说明]
- 本图示主题：化合物A（绿藻胶质中提取的脂肪酶抑制剂）的分子骨架展示、官能团识别与化学式 C₂₁H₂₆O₆ 的分步验证
- 整合的步骤/概念：
  1. 完整键线式分子结构展示
  2. 三个乙酸酯基（–OCOCH₃）的识别与高亮
  3. 三个碳碳双键（C=C）的识别与高亮
  4. 一个碳碳三键（C≡C）的识别与高亮
  5. 21个碳原子的分区编号（乙酰基6C红色编号 + 主链/侧链15C黑色编号）
  6. 氢原子分区计数（乙酰基9H、双键氢、饱和碳氢等）
  7. 氧原子计数与化学式结论 C₂₁H₂₆O₆
- 教学价值：教师通过分步按钮控制课堂节奏，逐步揭示官能团、原子计数过程，最终验证选项A的正确性；可随时回退复查任意步骤。

[分步序列]

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 (320,470)，宽80×高30，点击回退到上一状态
  - 「下一步」按钮：位于 (480,470)，宽80×高30，点击推进到下一状态
  - 步骤标题文本：位于 (400,455)，随步骤更新
- 教师操作流程：
  1. 教师打开图示，展示步骤0完整分子，让学生观察结构。
  2. 点击「下一步」进入步骤1，引导学生寻找酯基，观察红色高亮与虚线框。
  3. 继续点击「下一步」依次揭示双键、三键、碳编号、氢计数。
  4. 最后一步展示化学式结论，验证选项A。
  5. 讲解过程中可随时「上一步」回退到任意官能团步骤复习。

[技术实现]
- JS库选择：原生 SVG + 原生 JavaScript。原因：键线式分子结构由大量精确坐标的线段、圆圈、文本组成，SVG的声明式图形最适合；无需复杂数据绑定或3D，D3/Three.js过重。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图（ASCII）：
  ```
  0    100  200  300  400  500  600  700  800
  +----+----+----+----+----+----+----+----+  y=0
  |         分子结构区（键线式）   | 计数表 |  y=140
  |    C1~C5  C5(中心)  C11~C20   | 原子计数 |
  |       \   |   /    |           | C | 21 |  y=180
  |        \  |  /     |           | H | 26 |  y=220
  |         \ | /      |           | O |  6 |  y=260
  |    酯基×3 C=C×3 C≡C×1         +--------+  y=300
  |                               化学式结论  y=330
  |  [红]酯基 [蓝]C=C [绿]C≡C [黄]碳编号   y=415
  |        ◀上一步    下一步▶               y=470
  +----+----+----+----+----+----+----+----+  y=500
  ```
- 关键实现要点：
  1. 状态机设计：变量 `let currentStep = 0;`（范围0~6）。每步用一个配置对象描述应显示的元素ID集合、颜色类名、文本内容。
  2. 元素显隐：所有可选元素（高亮键、虚线框、编号、标注、表格数字）初始 `display:none` 或 `opacity:0`，由状态机统一切换。
  3. 键的高亮：为每条可高亮的键设置独立ID（如 `scene1-bond-c3c4`），通过切换CSS类改变 `stroke` 和 `stroke-width`。
  4. 双键/三键绘制：双键画两条平行线（水平双键y偏移±2px；倾斜双键沿法向偏移）；三键画三条平行线（水平三键y偏移±3px,0）。
  5. 编号圆圈：`<circle>` + `<text>` 组合，放在 `<g id="scene1-numbers">` 中统一控制显隐。
  6. 计数表数字：使用 `<text>` 元素，初始 `opacity:0`，到达对应步骤时 `opacity:1` 并可选加简单淡入过渡（CSS transition 0.3s）。
  7. 按钮事件：上一步/下一步按钮绑定 `click`，更新 `currentStep` 后调用 `renderStep()` 重绘状态。边界检查：currentStep<0 则置0，>6 则置6。
  8. 动画曲线：无需复杂动画，仅使用 CSS `transition: opacity 0.3s ease, stroke 0.3s ease` 实现淡入和颜色平滑过渡。
- ID命名规范：所有交互元素ID必须以 `scene1-` 为前缀。示例：
  - 键：`scene1-bond-c1c2`, `scene1-bond-c3c4-main`, `scene1-bond-c3c4-sub`
  - 原子/官能团组：`scene1-group-ester-left`, `scene1-group-ester-up`, `scene1-group-ester-down`
  - 虚线框：`scene1-box-acetyl-left`, `scene1-box-acetyl-up`, `scene1-box-acetyl-down`
  - 编号组：`scene1-number-1` ~ `scene1-number-21`
  - 标注文本：`scene1-label-ester`, `scene1-label-cc-double`, `scene1-label-cc-triple`
  - 表格数字：`scene1-table-c`, `scene1-table-h`, `scene1-table-o`
  - 化学式结论：`scene1-formula-result`
  - 按钮：`scene1-btn-prev`, `scene1-btn-next`
  - 标题：`scene1-step-title`
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免多场景合并时全局变量污染。
