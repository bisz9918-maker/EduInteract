[图示主题与整合说明]
- 本图示主题：手性碳原子识别与官能团反应计量分析（有机化合物A的结构与性质判断）
- 整合的步骤/概念：
  1. 手性碳原子定位与四基团展示（选项B判断）
  2. H₂加成位点识别与计量累加（选项C中5 mol H₂验证）
  3. NaOH水解位点识别与计量累加（选项C中3 mol NaOH验证）
  4. 反应类型（加成/取代/氧化）位点分类展示（选项D验证）
  5. 综合结论：错误选项为B（仅含1个手性碳）
- 教学价值：教师可先引导学生观察分子对称性，确认手性碳数目；再逐类验证H₂和NaOH的定量关系；最后总结反应类型，形成"结构→官能团→性质→判断"的完整解题闭环。分步导航允许教师根据课堂节奏暂停、回退、重点讲解。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「上一步」按钮：位置(280,470)，宽80×高32，圆角矩形。点击后回退到前一步，清除当前步新增元素，恢复前一步状态。在步骤0时禁用（opacity 0.4，pointer-events none）。
  2. 「步骤指示」文本：位置(400,470)，显示"步骤 X/5"，font-size 14px，#666666。
  3. 「下一步」按钮：位置(520,470)，宽80×高32，圆角矩形。点击后进入下一步，触发该步元素的显示/高亮动画。在步骤5时禁用。
- 教师操作流程：
  1. 教师打开图示，步骤0显示完整分子，先让学生整体观察结构，识别官能团种类。
  2. 点击「下一步」进入步骤1：黄色高亮手性碳，四基团标签展开。教师提问"该碳连接几个不同基团？"，引导学生确认只有1个手性碳，从而判断选项B错误。
  3. 点击「下一步」进入步骤2：蓝色高亮所有双键/三键，累加H₂计量。教师带领学生数C=C（3个）和C≡C（1个），计算3×1+1×2=5 mol。
  4. 点击「下一步」进入步骤3：红色高亮三个酯基，展示水解位点。教师确认每个酯基消耗1 mol NaOH，共3 mol。
  5. 点击「下一步」进入步骤4：分类展示三类反应位点。教师总结加成（不饱和键）、取代（酯基水解）、氧化（不饱和键）均可发生。
  6. 点击「下一步」进入步骤5：综合结论"错误选项：B"。教师回顾整题，确认A/C/D正确，B错误。
  7. 讲解过程中可随时「上一步」回退，针对学生疑问重复展示某一步。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript。原因：分子结构为静态几何图形（线段、文本、椭圆），无需复杂数据绑定或3D渲染；原生SVG可精确控制每个化学键和标签的显示/隐藏，性能最优。
- 画布尺寸：800 × 500 px（固定画布，SVG viewBox="0 0 800 500"）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]

  |            | |                                         |
  ```

- 关键实现要点：
  1. 状态机设计：定义全局变量 `let currentStep = 0;`，共6个状态（0~5）。每步用一个配置对象描述该步应显示的元素ID列表、应添加的class列表。避免使用大量if-else，改用 `stepConfig[step].showIds` 和 `stepConfig[step].hideIds` 批量控制。
  2. 元素分组与显隐：将每步新增的视觉元素（高亮、标签、箭头）分别包裹在 `<g id="scene2-step1-group">` 等组元素中。切换步骤时直接设置对应组的 `display` 属性为 `block`/`none`，实现批量显隐。
  3. 坐标计算：所有化学键坐标硬编码在SVG的 `<line>` 或 `<path>` 中，确保与布局坐标表完全一致。双键/三键使用多条平行线段实现。
  4. 动画曲线：标签和高亮出现时使用简单CSS transition（opacity 0→1，duration 300ms，ease-out），不依赖复杂动画库。在对应group上添加class `fade-in`。
  5. 事件绑定：上一步/下一步按钮绑定click事件，调用 `goToStep(step)` 函数。函数内先 `currentStep = step`，然后遍历所有step-group设置display，更新按钮禁用状态，更新步骤指示文本。
  6. 右侧面板状态：B/C/D三项的边框颜色和标记（√/×）也分步控制，使用单独的 `<text>` 和 `<rect>` 元素，通过display或stroke属性切换。
  7. 结论面板（步骤5）：使用一个覆盖在B/C/D上方的 `<g id="scene2-conclusion-panel">`，默认display:none，步骤5时display:block。
