[图示主题与整合说明]
- 本图示主题：豌豆杂交实验的遗传分析（处理①②及F2代性状分离比计算）
- 整合的步骤/概念：
  1. 处理①：对植株甲去雄套袋但未授粉，形成无种子豆荚（母本保护实验对照）
  2. 处理②：植株甲（♀aabb）×植株乙（♂AABB）杂交，形成有种子豆荚
  3. F1代性状判断：豆荚颜色由母本果皮基因型决定（aa→黄色），子叶颜色由F1胚基因型决定（Bb→黄色）
  4. F1（AaBb）自交得F2，豆荚颜色分离比（黄:绿=1:3，即黄色占1/4）
  5. F2胚基因型比例：通过4×4 Punnett方格计算AABb占2/16=1/8
- 教学价值：教师可通过分步导航，按"实验操作→F1性状判断→F2遗传图解"的逻辑链逐层展开，随时回退强调"母本性状/胚性状"这一易混淆点，以及双杂合子自交的比例计算。

  1. 状态机设计：维护变量 `currentStep`（0~5）。`setStep(n)` 函数负责切换：先给所有受控元素添加 `transition: opacity 0.3s` 的CSS类，然后按步骤配置表设置各元素的 `opacity`（1 / 0.3 / 0）和 `stroke` 高亮色。
  2. 分组管理：使用SVG `<g id="scene1-step-X-group">` 包裹每步骤新增元素，通过控制组的 `display` 或 `opacity` 实现批量显隐。
  3. 高亮实现：通过JS动态修改目标元素的 `style.stroke` 和 `style.strokeWidth`，而非切换CSS类，避免全局class在多场景合并时污染。
  4. 按钮禁用逻辑：在 `setStep` 内检查 `currentStep`，若为0则禁用「上一步」（`disabled=true`，`opacity=0.4`）；若为5则禁用「下一步」。
  5. 过渡动画：所有透明度变化使用CSS `transition: opacity 0.3s ease`，描边颜色变化使用 `transition: stroke 0.3s ease`，确保视觉平滑。
  6. Punnett方格生成：使用JS循环生成16个 `<rect>` 和 `<text>`，避免手写冗余代码；高亮格子通过索引判断（行0列1、行1列0）单独设置样式。
- ID命名规范：所有交互元素ID必须以 `scene1-` 为前缀。例如：
  - 植株甲组：`scene1-plant-a`
  - 植株乙组：`scene1-plant-b`

- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })()` 中，避免变量污染全局作用域，确保多场景合并时互不干扰。
