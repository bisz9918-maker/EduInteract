（1）图中①、②过程合称_____________。图示反映了基因与生物性状的关系是____________。

（2）用纯合紫花和纯合蓝花为亲本杂交得F$_{1}$，F$_{1}$自交得F$_{2}$，将F$_{2}$中的白花个体收获后，每株的所有种子单独种植在一起得到一个株系，所有株系中，子代表现出紫花：蓝花：白花=3：3：10的株系比例为______，若让子代所有紫花植株测交，后代的性状及比例是______________________。

（3）现有一株白花植株，在种植过程中发现白花植株因基因突变使其一个白色花瓣上出现蓝色斑点，此植株可能的基因型有__________________。

---

**题目分析与整体讲解思路**

本题是一道典型的**基因互作**遗传题，核心在于理解两对独立遗传的基因通过控制酶合成影响同一代谢途径，且存在特殊的mRNA水平抑制机制。

**关键突破口：**
1. 基因A控制酶A合成，进而产生紫色色素；基因B控制酶B合成，进而产生蓝色色素。
2. **A和B同时存在时**，两种mRNA结合，导致酶A和酶B都不能合成，白色前体物质无法转化，表现为白花。
3. 因此表现型与基因型的对应关系为：
   - **A_bb** → 紫花
   - **aaB_** → 蓝花
   - **A_B_** → 白花（mRNA结合，两种酶均不能合成）
   - **aabb** → 白花（无酶A也无酶B）

**图示规划：**
- **图示1**：生化途径与基因型-表现型对应关系（帮助学生理解特殊的mRNA抑制机制）。
- **图示2**：完整遗传杂交图解与F$_{2}$代表现型比例（展示P→F$_{1}$→F$_{2}$的完整遗传流程）。
- **图示3**：白花株系自交筛选、测交推导及体细胞突变分析（覆盖第（2）（3）小题的深入推导）。

    **教学要点：**

    教师应引导学生重点观察"mRNA结合"这一特殊机制，这是本题区别于普通9:3:3:1题型的核心。

    **讲解递进：**
    1. 先让学生回顾中心法则：基因通过转录产生mRNA，再通过翻译合成蛋白质（酶）。
    2. 提问：如果植株只有基因A（A_bb），能否合成酶A？花色是什么？（能，紫花）只有基因B（aaB_）呢？（能，蓝花）
    3. 关键提问：A和B同时存在（A_B_）时，按常规思路应该是什么颜色？（学生可能猜测紫花或蓝花）
    4. 揭示本题特殊机制：两种mRNA结合，导致两种酶都不能合成，前体物质无法转化，最终表现为白花。这是一种发生在翻译水平的基因互作。
    5. 总结基因与性状的两层关系：①基因通过控制酶的合成来控制代谢过程，进而控制生物性状；②多对基因共同控制一对相对性状（多因一效）。
    6. 强调aabb也是白花，但机制不同（缺乏两种酶，而非mRNA结合）。

    **教学要点：**

    本图示展示经典的双杂合子杂交过程，重点是F$_{2}$代表现型比例的变形。

    **讲解步骤：**
    1. 明确亲本选择：纯合紫花基因型为AAbb，纯合蓝花基因型为aaBB（学生需根据色素路径反推）。
    2. P代杂交得F$_{1}$，基因型全为AaBb。由于A和B同时存在，mRNA结合导致两种酶都不能合成，F$_{1}$表现型为白花。
    3. F$_{1}$自交得F$_{2}$，按自由组合定律，基因型比例为9:3:3:1。
    4. **表现型归类**是本题关键：
       - 9份A_B_ → 白花（mRNA结合，两种酶均不能合成）
       - 3份A_bb → 紫花（有酶A，无酶B）
       - 3份aaB_ → 蓝花（有酶B，无酶A）
       - 1份aabb → 白花（无酶A也无酶B）
    5. 因此F$_{2}$表现型比例为**白花:紫花:蓝花 = 10:3:3**。
    6. 特别强调：白花包括两类不同基因型（A_B_和aabb），这在后续第（2）小题中至关重要，学生容易忽略aabb也是白花。

    <TEXT_4>
    **教学要点与完整解答：**

    本图示聚焦第（2）（3）小题的深入推导，教师需引导学生注意条件概率和基因型拆解。

    **第（2）小题讲解：**
    1. F$_{2}$白花个体共5种基因型，它们在全部F$_{2}$中的比例分别为1/16、2/16、2/16、4/16、1/16。由于白花总计占10/16，因此在**白花群体中的比例**需用条件概率重新计算：
       - AABB : AABb : AaBB : AaBb : aabb = 1 : 2 : 2 : 4 : 1
    2. 逐一分析各基因型自交结果：
       - AABB自交 → 全白花
       - AABb自交 → 3白花 : 1紫花（无蓝花）
       - AaBB自交 → 3白花 : 1蓝花（无紫花）
       - **AaBb自交 → 3紫花 : 3蓝花 : 10白花** ✓
       - aabb自交 → 全白花
    3. 只有AaBb自交能产生三种表现型且比例为3:3:10。因此所求株系比例 = AaBb在白花的比例 = **4/10 = 2/5**。
    4. 紫花测交推导：
       - AaBb自交后代中，紫花（A_bb）的基因型及比例为 **1/3 AAbb : 2/3 Aabb**。
       - AAbb × aabb → 后代全为Aabb（紫花）。
       - Aabb × aabb → 后代1/2 Aabb（紫花）: 1/2 aabb（白花）。
       - 汇总计算：紫花 = 1/3 × 1 + 2/3 × 1/2 = 2/3；白花 = 2/3 × 1/2 = 1/3。
       - 因此测交后代性状及比例为 **紫花 : 白花 = 2 : 1**。

    **第（3）小题讲解：**
    1. 白花植株的基因型为A_B_或aabb。出现蓝色斑点意味着该突变细胞表现为蓝花，即细胞基因型为**aaB_**（有B无A，能合成酶B但不能合成酶A）。
    2. 若原植株为aabb：体细胞发生b→B突变，变为aaBb，可产生蓝色斑点。
    3. 若原植株为A_B_：需A→a突变，且突变后细胞中仍有B基因。
       - AaBb → 某个细胞A突变为a → aaBb ✓
       - AaBB → 某个细胞A突变为a → aaBB ✓
       - AABb → 单个A突变为a后仍为AaBb（白花），需两个A均突变才得aaBb，一般不考虑 ✗
       - AABB → 同理，一般不考虑 ✗
    4. 因此此植株可能的基因型为 **AaBb、AaBB、aabb**。

    **课堂讲解建议：**
    - 第（1）小题注意区分"基因的表达"（转录+翻译）与"中心法则"（包含DNA复制）的表述差异。
    - 第（2）小题中，"在白花个体中"的比例是最高频失分点，务必让学生先算白花总占比10/16，再用各基因型除以10/16。
    - 测交时强调紫花群体内部的比例是1/3 AAbb和2/3 Aabb，不能直接用1/16和2/16计算。
    - 第（3）小题可联系"体细胞突变→克隆扩增形成斑点"的发育生物学概念，帮助学生建立跨章节联系。
    </TEXT_4>
