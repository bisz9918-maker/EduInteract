[图示主题与整合说明]
- 本图示主题：X与Y染色体减数分裂未分离导致异常子代X^E X^e Y的形成
- 整合内容：①亲本基因型展示（♂M：X^E Y，♀白眼：X^e X^e）；②正常减数分裂产生正常配子；③正常受精及正常子代基因型；④异常减数分裂（MⅠ期X与Y未分离）产生异常精子X^E Y及空精子；⑤异常精子与正常卵细胞结合形成X^E X^e Y
- 教学价值：教师通过分步导航，先建立"正常减数分裂→正常受精→正常子代"的基准认知，再对比呈现"异常减数分裂→异常受精→异常子代"的因果链条，帮助学生理解染色体不分离与子代基因型的对应关系

[分步序列]
- 步骤0（初始状态）：显示标题、父方背景框及内部所有元素（♂M、X^E Y、X棒、Y棒）、母方背景框及内部所有元素（♀白眼、X^e X^e、两条X棒）。配子、子代、箭头、异常标记均隐藏。教师可在此介绍亲本基因型。
- 步骤1（正常减数分裂）：在步骤0基础上，显示父方到配子的箭头（父方→X^E、父方→Y）和母方到配子的箭头（母方→X^e），以及三个正常配子圆形（X^E、Y、X^e）及其标签。教师讲解正常减数分裂产生配子的过程。
- 步骤2（正常受精与子代）：在步骤1基础上，显示四条受精箭头（X^E→X^E X^e、X^e→X^E X^e、Y→X^e Y、X^e→X^e Y）和两个正常子代圆形（X^E X^e、X^e Y）及其内部小染色体和标签。教师讲解正常受精结果。
- 步骤3（异常减数分裂）：隐藏步骤1-2的正常配子和正常子代及相关箭头。保留亲本。高亮父方性染色体（加粗描边或发光滤镜），显示未分离弧形箭头及"MI未分离"标签。显示异常配子：异常精子X^E Y（带红色虚线外框）及其标签、空精子O及其标签和"不含性染色体"说明，以及父方到异常配子的箭头（红色实线到X^E Y，灰色虚线到O）。母方配子X^e仍显示。教师讲解MⅠ期X与Y未分离的异常行为。
- 步骤4（异常受精与目标子代）：在步骤3基础上，显示异常受精箭头（X^E Y→异常子代，红色；X^e→异常子代，红色）和异常子代圆形X^E X^e Y（红色高亮边框、红色半透明填充、内部三个小染色体）及其标签"即题目所述个体"。教师点明此即为题目中X^E X^e Y个体的形成原因。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「◀ 上一步」按钮：位置(320, 455)，尺寸80×32。点击后回退到上一个步骤，步骤0时禁用。
  2. 「下一步 ▶」按钮：位置(420, 455)，尺寸80×32。点击后前进到下一个步骤，步骤4时禁用。
  3. 步骤指示器：位置(400, 490)，显示当前步骤编号（如"步骤 1/5"）。
- 教师操作流程：
  1. 教师打开图示，首先呈现步骤0（亲本），向学生介绍雄果蝇M和白眼雌蝇的基因型。
  2. 点击「下一步」进入步骤1，讲解正常减数分裂产生配子的过程。
  3. 点击「下一步」进入步骤2，讲解正常受精产生的子代基因型，建立基准认知。
  4. 点击「下一步」进入步骤3，重点讲解异常减数分裂：X与Y在MⅠ期未分离，产生异常精子X^E Y和空精子。
  5. 点击「下一步」进入步骤4，展示异常精子与正常卵细胞结合形成X^E X^e Y，回扣题目。
  6. 可随时点击「上一步」回退复习关键步骤。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript。原因：本场景以几何图形、流程箭头和状态切换为主，无复杂函数绘图或3D需求，原生SVG足以胜任，且无需额外加载CDN库，保证离线可用性。数学公式（X^E等）使用普通文本配合<tspan>偏移模拟上标，避免引入MathJax增加复杂度。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |              标题 (y=30)                          |
  |  +------------------+        +------------------+ |
  |  | ♂M  X^E Y        |        | ♀白眼 X^e X^e    | |  亲本区 y=55~145
  8  |  [蓝X] [绿Y]     |        | [红X] [红X]      | |
  0  +------------------+        +------------------+ |
  0  |       ↓              ↓              ↓         |  箭头区 y=145~205
  |  |    (X^E)   (Y)            (X^e)            | |  配子区 y=205~255
  |  |       ↘    ↓            ↙   ↓             | |
  |  |         (X^E X^e)   (X^e Y)                | |  子代区 y=315~410
  |  |              (X^E X^e Y)  [高亮]           | |
  |                                                  |
  |        [◀ 上一步]  [下一步 ▶]   步骤 X/5        |  控件区 y=455~490
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：定义常量 `const STATE_COUNT = 5;`，当前状态 `let currentStep = 0;`。每个步骤对应一个显示元素集合。
  2. 元素分组：将SVG元素按步骤分组，使用 `<g>` 标签包裹，赋予ID如 `scene2-step1-group`、`scene2-step2-group` 等。每个组初始 `opacity: 0` 或 `display: none`，通过JS切换。
  3. 状态切换动画：使用 CSS transition `transition: opacity 0.3s ease-in-out`。切换步骤时，先淡出当前步骤独有元素，再淡入新步骤元素。共享元素（如亲本）始终保持显示。
  4. 异常标记动画：步骤3中的未分离弧形箭头使用 CSS `@keyframes pulse` 实现轻微透明度脉冲（0.6↔1.0，周期1.5s），吸引学生注意力。
  5. 高亮效果：步骤3-4中父方性染色体使用 CSS `filter: drop-shadow(0 0 4px #c62828)` 实现发光高亮。
  6. 按钮状态：根据 `currentStep` 更新按钮 `disabled` 属性和样式类。步骤0禁用「上一步」，步骤4禁用「下一步」。
  7. 箭头绘制：使用 `<line>` 或 `<path>` 配合 `<marker>` 定义箭头头部。正常箭头黑色，异常箭头红色。
  8. 子代内部染色体：在子代圆形 `<g>` 内使用 `<rect>` 绘制小染色体棒，通过坐标定位在圆心区域。
- ID 命名规范：所有交互元素ID必须以 `scene2-` 为前缀。例如：
  - 父方框：`scene2-father-box`
  - 母方框：`scene2-mother-box`
  - 正常精子X^E组：`scene2-sperm-xe-group`
  - 异常精子：`scene2-sperm-xey-group`
  - 空精子：`scene2-sperm-o-group`
  - 正常子代1：`scene2-offspring-female`
  - 正常子代2：`scene2-offspring-male`
  - 异常子代：`scene2-offspring-abnormal`
  - 上一步按钮：`scene2-btn-prev`
  - 下一步按钮：`scene2-btn-next`
  - 步骤指示器：`scene2-step-indicator`
  - 未分离箭头：`scene2-nondisjunction-arrow`
  JS中严格使用 `document.getElementById` 获取元素，禁止全局class选择，避免多场景合并时污染。
- IIFE 隔离：所有 JavaScript 代码包裹在 `(function() { ... })();` 中，变量不污染全局作用域。事件监听器在DOMContentLoaded后绑定。
