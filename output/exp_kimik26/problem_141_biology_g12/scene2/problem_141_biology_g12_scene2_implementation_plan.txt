[图示主题与整合说明]
- 本图示主题：实验①自交遗传分析——区分b与e
- 整合的步骤/概念：b植株（核基因Ss，无线粒体S）自交遗传图解、e植株（核基因Ss+线粒体S⁺）自交遗传图解、后代结果对比、自交目的a（区分e与b）和目的b（纯化获得纯合子）的推导
- 教学价值：教师通过分步导航，先展示b自交的3:1分离比，再展示e自交的全部抗性（无分离），通过并列对比让学生直观理解"自交可区分b与e"的原理；最后以连续自交柱状图说明纯化作用。每步可回退，适合课堂边讲边点。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：遗传图解以几何图形（矩形、圆、线、文本）为主，无需复杂图表库；原生SVG可精确控制每个元素的坐标和显隐，避免引入D3等库增加体积。
- 画布尺寸：800 × 500 px（SVG viewBox="0 0 800 500"）
- 布局草图：
  ```
  [图示区 800×500]
  +----------------------------------------+
  |  步骤标题（顶部居中）                   |
  |                                        |
  |  [主内容区：遗传图解/对比图/柱状图]      |
  |  [y=50~430 区域]                       |
  |                                        |
  |  [结论文字（步骤3/4）]                  |
  |                                        |
  |  [◀上一步]  [步骤 X/4]  [下一步▶]      |  <- 控件区 y=440~490
  +----------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 `currentStep`（0~4）控制当前步骤。每步对应一个渲染函数 `renderStep0()` ~ `renderStep4()`，先清空主内容组（`scene2-main-group`），再绘制该步元素。
  2. 坐标计算：所有坐标硬编码为常量对象（如 `B_MOTHER_BOX = {x:150, y:90, w:120, h:45}`），避免魔法数字。
  3. 动画曲线：步骤切换时无需复杂动画，直接显隐即可（课堂讲解追求清晰而非炫动）。若需过渡，可用CSS `transition: opacity 0.2s`。
  4. 事件绑定：按钮绑定 `click` 事件，修改 `currentStep` 后调用 `render()`。按钮禁用状态通过 `disabled` 属性 + opacity 样式控制。
  5. 步骤0~4的元素分组：使用SVG `<g id="scene2-stepX">` 包裹每步元素，通过设置 `display: none/block` 切换，比频繁DOM操作更高效。
  6. 文本居中：所有文本使用 `text-anchor="middle"` + `dominant-baseline="middle"`，确保坐标即为视觉中心。
  7. 纯化柱状图计算：柱总高200px，按比例分配。P代：Ss=200；F1：SS=50, Ss=100, ss=50；F2：SS=75, Ss=50, ss=75；F3：SS=87.5, Ss=25, ss=87.5。使用堆叠rect从底部向上绘制。
- ID命名规范：所有SVG元素ID必须以 `scene2-` 为前缀。例如：
  - 母本框：`scene2-p-mother-box`
  - F1格1：`scene2-f1-cell1`
  - 线粒体标记：`scene2-mito-marker-mother`
  - 按钮：`scene2-btn-prev`、`scene2-btn-next`
  - 主内容组：`scene2-main-group`
