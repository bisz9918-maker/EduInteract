[图示主题与整合说明]
- 本图示主题：实验②杂交分析与自交-杂交综合筛选
- 整合的步骤/概念：
  1) 实验②设计原理（父本为抗性植株、母本为无抗性植株，精子无线粒体）；
  2) 三种代表性父本（d、e、c）的杂交遗传图解，突出精子只传核基因不传线粒体S+；
  3) 杂交结果三类汇总表；
  4) 自交系一代与杂交系一代的二维筛选矩阵，绿色高亮符合长期种植要求的c、f。
- 教学价值：教师通过分步导航，先让学生理解"精子无线粒体"这一关键限制，再逐一看清d、e、c（b/f）的杂交后代差异，最后通过二维矩阵联立自交与杂交结果，锁定核基因纯合且无线粒体S依赖的类型c、f，强化"核遗传稳定、细胞质遗传不稳定"的科学思维。

[分步序列]
- 初始状态（步骤0）——实验②设计说明：
  显示步骤标题"实验②：抗性植株作父本 × 无抗性植株作母本"；中央流程图（父本框→×→母本框→后代框）；父本框内文字"抗性植株（父本）"+小字"含核S或线粒体S+"（S+红色），母本框内"无抗性植株（母本）"+小字"核ss，无线粒体S"；下方红色关键条件框内文字"关键：精子内的线粒体不会进入卵细胞"；最下方精子示意图（椭圆内仅含小竖线，无线粒体）及标签"精子仅含核基因"。

- 步骤1——d父本杂交：
  标题"步骤1：父本d（ss，线粒体S+）的杂交"；父本框内两条黑色竖线（ss）+红色实心圆线粒体；母本框内两条黑色竖线（ss）+灰色空心圆线粒体；精子区一个精子（内含黑色小竖线s），标注"精子（仅核s）"；卵细胞区一个卵细胞（内含黑色小竖线s+空心线粒体）；后代框内两条黑色竖线（ss）+空心线粒体，文字"全部ss，全部无抗性"（红色）；底部结论"父本d → 杂交系一代全部无抗性"。

- 步骤2——e父本杂交：
  标题"步骤2：父本e（Ss，线粒体S+）的杂交"；父本框内一蓝箭头竖线（S）+一黑色竖线（s）+红色实心圆线粒体；精子区两个精子并列，左精子含蓝色小箭头竖线（S）标注"1/2"，右精子含黑色小竖线（s）标注"1/2"，均无线粒体；卵细胞区同步骤1；后代框分左右两区，左区"Ss（抗）"（一蓝一黑竖线，绿色文字），右区"ss（不抗）"（两黑竖线，黑色文字），总文字"1抗 : 1不抗"；底部结论"父本e → 杂交系一代表现型比例 1:1"。

- 步骤3——b/c/f父本杂交（以c为代表）：
  标题"步骤3：父本c（SS，无线粒体S）的杂交——b、f结果相同"；父本框内两条蓝色箭头竖线（SS）+灰色空心圆线粒体；精子区一个精子（含蓝色小箭头竖线S），无线粒体；卵细胞区同前；后代框内全部"Ss"（一蓝一黑竖线）+空心线粒体，文字"全部Ss，全部抗性"（绿色）；底部额外备注文字"注：b（Ss, 无线粒体S）和f（SS, 线粒体S+）的杂交结果与c相同，后代均为Ss且全抗"。

- 步骤4——杂交结果3种类型汇总：
  标题"步骤4：实验②杂交结果汇总"；中央汇总表（170,100）起，3列4行：
  表头：父本类型 | 杂交系一代表现 | 比例
  行1：d | 全部无抗性 | 0:1
  行2：e | 1抗 : 1不抗 | 1:1
  行3：b、c、f | 全部抗性 | 1:0
  表头浅灰底，文字黑色；行2比例"1:1"蓝色高亮，行3"全部抗性"绿色高亮。

- 步骤5——综合筛选矩阵：
  标题"步骤5：自交系一代 × 杂交系一代 综合筛选"；矩阵表格（150,90）起，4列×3行：
  列标题（y=90~140）：(空) | 杂交全抗 | 杂交有分离 | 杂交全不抗
  行1（y=140~210，自交全抗）：自交全抗 | c、f（绿色高亮） | — | d
  行2（y=210~280，自交有分离）：自交有分离 | — | b、e | —
  矩阵下方绿色结论框（220,320）文字"符合长期种植要求：自交全抗 + 杂交全抗 → 亲本类型 c、f"。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「上一步」按钮：位置(280, 455)，宽80高32，灰色背景，点击回退到前一步；
  2. 步骤指示器：位置(400, 470)，文字如"步骤 2/6"，黑色；
  3. 「下一步」按钮：位置(480, 455)，宽80高32，蓝色背景#1565c0白色文字，点击进入下一步。
- 教师操作流程：
  1. 教师打开图示，默认步骤0，讲解实验②的杂交设计原理，强调红色关键条件"精子无线粒体"；
  2. 点击「下一步」进入步骤1，展示d父本杂交，引导学生发现"线粒体S+无法通过精子传递，后代全不抗"；
  3. 继续点击「下一步」到步骤2，展示e父本杂交，得到1:1分离比；
  4. 步骤3展示c父本（代表b/c/f）杂交，后代全抗；
  5. 步骤4汇总三类结果，形成系统认识；
  6. 步骤5呈现二维矩阵，绿色高亮"自交全抗+杂交全抗"对应c、f，完成综合筛选；
  7. 可随时点击「上一步」回退复习任意步骤。

[技术实现]
- JS库选择：原生 SVG（使用 <svg>、<g>、<rect>、<text>、<line>、<path>、<ellipse>、<marker>），无需额外库。理由：本场景以几何框图、箭头、表格为主，无复杂函数曲线或3D，原生SVG足够且轻量。
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  步骤标题 (400,35)                                |
  |  [主图区 y=80~420]                                |
  |   步骤0: 流程图 + 关键条件框 + 示意图             |
  |   步骤1-3: 父本框 ←→ 母本框                       |
  |            ↓      ↓                              |
  |          精子区  卵细胞区                         |
  |            \      /                              |
  |            [后代框]                               |
  |   步骤4: 汇总表格（居中）                         |
  |   步骤5: 筛选矩阵 + 结论框（居中）                |
  |                                                  |
  |  [控件栏 y=450~490]                               |
  |    [◀上一步]   步骤 X/6   [下一步▶]              |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：变量 `let currentStep = 0;`（范围0~5），数组 `stepGroups` 存储6个 `<g>` 的ID，通过设置 `display: block/none` 切换。
  2. 坐标计算：所有坐标使用绝对像素，严格遵循坐标表；遗传图解中染色体竖线、箭头、线粒体圆均使用固定坐标，不依赖动态计算。
  3. 动画曲线：步骤切换不使用动画（直接切换），保证课堂讲解的即时性；如需柔和过渡，可添加0.2s CSS opacity过渡。
  4. 事件绑定：按钮绑定 `onclick`，上一步判断 `currentStep > 0` 则减1，下一步判断 `< 5` 则加1，随后调用 `renderStep()` 更新 `display` 与指示器文字。
  5. 表格绘制：步骤4汇总表与步骤5矩阵使用 `<rect>` + `<text>` 逐格绘制，避免HTML表格与SVG层级混乱；绿色高亮单元格使用 `fill="#2e7d32" fill-opacity="0.2" stroke="#2e7d32" stroke-width="2"`。
  6. 箭头标记：在 `<defs>` 中定义 `<marker id="scene3-arrowhead">` 供配子传递线复用。
  7. 精子无线粒体强调：步骤1-3精子图形内部仅绘制小竖线（核），不绘制红色圆；步骤0精子示意图同样无线粒体，与父本框内红色线粒体形成视觉对比。
- ID命名规范：所有SVG元素及JS变量均以 `scene3-` 为前缀。例如：
  - 父本框：`id="scene3-father-box"`
  - 精子区：`id="scene3-sperm-zone"`
  - 步骤组0：`id="scene3-step-0"`
  - 上一步按钮：`id="scene3-btn-prev"`
  - 下一步按钮：`id="scene3-btn-next"`
  - 指示器：`id="scene3-step-indicator"`
  JS中严格使用 `document.getElementById('scene3-xxx')`，禁止全局class选择，防止多场景合并时污染。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，对外不暴露任何变量。
