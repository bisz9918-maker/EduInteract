场景导航：Scene 1 | Scene 2

完整题目原文：

林肯郡卷毛猪毛发的颜色受独立遗传且完全显性的三对基因A—a、B—b、C一c控制，研究发现，体细胞中C基因数少于c基因数时，C基因的表达减弱而形成黑青色突变体。基因与性状之间的关系如图1所示，黑青毛突变体体细胞中C、c基因与染色体的组成如图2所示。请回答：

(1)根据图1推断纯合棕色猪的基因型为_。

(2)图1中，某些基因型相同的正常黑色林肯郡卷毛猪杂交后代出现了两种表现型，子代的表现型及比例为或__。

(3)今有多只纯种林肯郡卷毛猪，请设计一个简便的杂交实验，以确定基因型为aaBbCcc的林肯郡卷毛猪属于图2中的哪一种突变体(假设实验过程中不存在突变与染色体互换，各型配子活力相同)。实验步骤:。
结果与结论：I．若子代中，则该突变体为突变体甲。Ⅱ．若子代中，则该突变体为突变体乙。Ⅲ．若子代中_，则该突变体为突变体丙。

题目分析与整体讲解思路：

本题核心考查多对等位基因对性状的控制、染色体变异（数目变异与结构变异）以及遗传实验设计。讲解时应先帮助学生建立"代谢途径→基因型→表现型"的对应关系，再过渡到染色体层面的变异分析。

图1代谢途径解读：

  1. 白色物质在酶1作用下转化为棕色物质，酶1由B基因控制；棕色物质在酶2作用下转化为黑色物质，酶2由C基因控制。
  2. A基因对B基因具有抑制作用，因此基因型为A_时，B基因无法表达，不能合成棕色物质，表现为白色。
  3. 当基因型为aa时，A的抑制解除。若同时bb，则缺乏酶1，仍表现为白色；若Bcc，则棕色物质积累，表现为棕色；若BC_，则黑色物质积累，表现为黑色。
  4. 黑青色突变体的条件是：aaB_且C基因数少于c基因数（即C表达减弱）。

问题(1)解答：

纯合棕色猪需满足aaB_cc且纯合，因此基因型为aaBBcc。

问题(2)解答：

正常黑色猪的基因型为aaBC。相同基因型杂交后代只出现两种表现型，说明三对基因中只有一对处于杂合状态（另外两对纯合）。

  • 若Bb杂合、CC纯合（基因型为aaBbCC），自交后代中B_:bb = 3:1，表现型为黑色:白色 = 3:1。
  • 若Bb纯合、Cc杂合（基因型为aaBBCc），自交后代中C_:cc = 3:1，表现型为黑色:棕色 = 3:1。

问题(3)整体思路：

三种突变体的基因型均为aaBbCcc，但C、c基因在染色体上的排列方式不同，导致减数分裂时产生的配子类型和比例不同。通过与纯种棕色猪（aaBBcc）杂交，根据子代表现型及比例即可区分。棕色猪只产生含c的一种配子，因此子代的C/c基因组成完全由突变体提供的配子决定。

图示规划说明：

本题的讲解需要两类核心图示：第一类展示代谢途径与表现型的对应关系（覆盖第(1)(2)问），第二类展示三种突变体的染色体组成、减数分裂过程及杂交鉴定结果（覆盖第(3)问）。两个图示分别对应SCENE1和SCENE2。

步骤 1/6

本图示教学说明（对应SCENE_2）：

本图示用于讲解第(3)问——通过杂交实验鉴定三种染色体组成不同的黑青毛突变体。教师应引导学生关注"相同基因型、不同染色体排列→不同配子类型→不同杂交结果"这一核心逻辑链。

三种突变体的染色体本质：

  1. 突变体甲：属于染色体数目变异（三体）。体细胞中该号染色体有三条，分别携带C、c、c。减数分裂时三条染色体随机分离，产生含1条或2条该染色体的配子。
  2. 突变体乙：属于染色体结构变异（易位或重复）。C基因与c基因位于同一条染色体上，另一条同源染色体携带c。减数分裂时两条染色体正常分离。
  3. 突变体丙：属于染色体结构变异（重复）。一条染色体携带C，另一条同源染色体上重复了两个c基因（cc）。减数分裂时两条染色体正常分离。

配子类型推导（关键步骤）：

  1. 突变体甲：三条染色体（C、c、c）随机分配。产生的配子及比例为 C : c : Cc : cc = 1 : 2 : 2 : 1（其中C、c为含1条该染色体的配子，Cc、cc为含2条该染色体的配子）。
  2. 突变体乙：配子类型及比例为 Cc（同时含C和c）: c = 1 : 1。
  3. 突变体丙：配子类型及比例为 C : cc = 1 : 1。

杂交实验设计：

让待鉴定的突变体（aaBbCcc）与多只纯种棕色猪（aaBBcc）杂交。选择aaBBcc的原因是：

  • 棕色猪只产生一种含c的配子，不会引入额外的C基因干扰判断；
  • B基因为BB，可确保子代均为B_，排除B基因对表现型的影响；
  • 子代的C/c基因组成完全由突变体提供的配子决定。

子代表现型推断：

  1. 突变体甲：配子C、c、Cc、cc分别与c结合，子代基因型为Cc（黑色）、cc（棕色）、Ccc（黑青色）、ccc（棕色）。表现型及比例为 黑色 : 黑青色 : 棕色 = 1 : 2 : 3。
  2. 突变体乙：配子Cc、c分别与c结合，子代基因型为Ccc（黑青色）、cc（棕色）。表现型及比例为 黑青色 : 棕色 = 1 : 1（无黑色子代）。
  3. 突变体丙：配子C、cc分别与c结合，子代基因型为Cc（黑色）、ccc（棕色）。表现型及比例为 黑色 : 棕色 = 1 : 1（无黑青色子代）。

课堂讲解建议：

  • 先让学生观察三种突变体的染色体图，找出"基因数量相同、排列位置不同"这一关键差异。
  • 强调突变体乙和丙的杂交结果虽然都是1:1，但表现型组合完全不同（一个有黑青色、一个有黑色），这是鉴定的核心依据。
  • 提醒学生注意题目条件"各型配子活力相同"，这意味着突变体甲产生的含2条染色体的配子（Cc、cc）也能正常参与受精。
步骤 1 / 6

完整解答汇总与课堂讲解建议：

答案：

(1) aaBBcc

(2) 黑色:白色 = 3:1 或 黑色:棕色 = 3:1

(3) 实验步骤：让该突变体与多只纯种棕色猪（aaBBcc）杂交，观察并统计子代的表现型及比例。

结果与结论：

  • I. 若子代中黑色:黑青色:棕色 = 1:2:3，则该突变体为突变体甲。
  • II. 若子代中黑青色:棕色 = 1:1（无黑色），则该突变体为突变体乙。
  • III. 若子代中黑色:棕色 = 1:1（无黑青色），则该突变体为突变体丙。

讲解节奏建议：

  1. 先用SCENE_1讲解代谢途径，确保学生能熟练根据基因型判断表现型（尤其是A的抑制作用和C的催化作用）。
  2. 问题(2)中强调"两种表现型"意味着只有一对基因杂合，引导学生排除aaBbCc（会产生三种表现型）的情况。
  3. 过渡到SCENE_2时，先让学生观察三种突变体的染色体图，提问"基因数量相同，为什么表现型相同但遗传行为不同？"
  4. 讲解减数分裂时，重点分析突变体甲的三体分离（三条染色体随机分配产生四种配子），这是学生最容易出错的地方。
  5. 最后通过汇总表强调：乙和丙虽然都是1:1，但表现型组合完全不同，这是设计实验的巧妙之处。
