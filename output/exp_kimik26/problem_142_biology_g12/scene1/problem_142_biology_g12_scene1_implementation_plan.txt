[图示主题与整合说明]
- 本图示主题：三对独立遗传基因（A-a、B-b、C-c）控制林肯郡卷毛猪毛发颜色的代谢途径及表现型推断
- 整合的步骤/概念：
  1. 图1代谢途径的完整展示（白色物质→棕色物质→黑色物质，A抑制B，B控制酶1，C控制酶2）
  2. 问题(1)：按A→B→C的逻辑递进讲解，推断纯合棕色猪的基因型为aaBBcc
  3. 问题(2)：两种正常黑色猪自交后代出现两种表现型的杂交分析（aaBbCC→黑:白=3:1；aaBBCc→黑:棕=3:1）
- 教学价值：教师通过分步导航控制课堂节奏，按代谢途径的逻辑链（抑制→合成→再合成）逐步引导学生理解基因型与表现型的对应关系，并随时回退强调关键节点

[分步序列]
- 初始状态（步骤0）：展示完整代谢途径。三个物质框（白、棕、黑）水平排列，两条反应箭头（白→棕→黑），A抑制线指向酶1，所有酶标签正常显示。无表格、无杂交图。教师可在此整体介绍代谢途径。
- 步骤1：点击「下一步」→ A基因抑制路径高亮。A标签变红(#c62828)，"抑制"标签变红，抑制线加粗至3px且变红，T型末端加粗。酶1箭头及B相关标签变淡（opacity=0.4）。其他元素正常。教师讲解"A_时B被抑制，无法合成棕色物质，表现型为白色"。
- 步骤2：点击「下一步」→ B基因路径高亮。B标签（抑制对象）变绿(#2e7d32)，"酶1"和"B基因控制"变绿，反应箭头1（白→棕）加粗至3px且变绿，棕色物质框边框变绿。A相关元素恢复正常。教师讲解"aaB_时合成棕色物质，aabb时无棕色物质"。
- 步骤3：点击「下一步」→ C基因路径高亮。C标签变蓝(#1565c0)，"酶2"和"C基因控制"变蓝，反应箭头2（棕→黑）加粗至3px且变蓝，黑色物质框边框变蓝。B相关元素恢复正常。教师讲解"C_时棕色→黑色，cc时停留棕色"。
- 步骤4：点击「下一步」→ 代谢途径淡化（opacity=0.3）移至背景，下方出现表现型-基因型对应表。表格4行：白色行(A_B_,A_bb,aabb)、棕色行(aaB_cc，背景高亮#fff3e0)、黑色行(aaB_C_)、黑青色行(aaB_Ccc)。表格下方出现绿色结论框"∴ 纯合棕色基因型：aaBBcc"。教师讲解问题(1)的推断过程。
- 步骤5：点击「下一步」→ 代谢途径和表格隐藏，显示左右并排两个杂交分析图。左侧：aaBbCC自交分支法，结果黑色:白色=3:1。右侧：aaBBCc自交分支法，结果黑色:棕色=3:1。教师讲解问题(2)的两种杂交情况。
- 最终步骤：即步骤5，展示所有结论。教师可随时点击「上一步」回退复习。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：本场景以静态几何图形、路径、文本为主，无复杂函数图或3D，原生SVG足够且轻量，便于精确控制每个元素的显示/隐藏和高亮状态。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  A抑制B                                           |
  |    ↓                                              |
  |  [白色物质] --酶1(B)--> [棕色物质] --酶2(C)--> [黑色物质] |
  |                                                   |
  |         （步骤0-3：代谢途径区域，y=80~200）         |
  |                                                   |
  |  +------------------------------------------+     |
  |  | 表现型 | 基因型      | 条件              |     |
  |  | 白色   | A_B_...    | A_或bb           |     |
  |  | 棕色   | aaB_cc     | cc（高亮）       |     |
  |  | 黑色   | aaB_C_     | C_               |     |
  |  | 黑青色 | aaB_Ccc    | C<c              |     |
  |  +------------------------------------------+     |
  |       ∴ 纯合棕色基因型：aaBBcc                    |
  |         （步骤4：表格区域，y=295~445）              |
  |                                                   |
  |  [① aaBbCC自交]        [② aaBBCc自交]            |
  |       ↓                      ↓                   |
  |    3:1黑:白              3:1黑:棕                |
  |         （步骤5：杂交图区域，y=285~425）           |
  |                                                   |
  |       [◀上一步]  [步骤 X/6]  [下一步▶]            |
  +--------------------------------------------------+
  [控件栏 y=440~490，HTML absolute覆盖]
  ```
- 关键实现要点：
  1. 状态机设计：定义变量 `let currentStep = 0;`，共6个状态（0~5）。`updateStep(step)` 函数统一控制所有视觉变化。
  2. SVG分组管理：使用 `<g>` 元素分组——`scene1-group-metabolism`（代谢途径）、`scene1-group-table`（表格）、`scene1-group-conclusion`（结论框）、`scene1-group-hybrid-left`（左侧杂交图）、`scene1-group-hybrid-right`（右侧杂交图）。通过设置 `display: none/block` 或 `opacity` 控制显隐。
  3. 高亮实现：为需要高亮的子元素设置独立ID（如 `scene1-a-label`、`scene1-inhibit-line`、`scene1-enzyme1-arrow` 等），在对应步骤通过JS修改其 `stroke`、`stroke-width`、`fill`、`opacity` 属性。使用CSS transition实现0.3s平滑过渡。
  4. 步骤0-3的高亮策略：
     - 步骤1：A相关元素（A标签、抑制标签、抑制线、T型线）设为红色加粗；酶1箭头、B标签、棕色框设为opacity=0.3
     - 步骤2：B相关元素（B标签、酶1标签、酶1箭头、棕色框边框）设为绿色加粗；A相关恢复正常
     - 步骤3：C相关元素（C标签、酶2标签、酶2箭头、黑色框边框）设为蓝色加粗；B相关恢复正常
  5. 步骤4：代谢途径组opacity=0.3，表格组和结论框display=block。表格行2（棕色行）背景设为#fff3e0，文字颜色#2e7d32。
  6. 步骤5：代谢途径组和表格组display=none，左右杂交图组display=block。
  7. 箭头标记：在SVG `<defs>` 中定义 `<marker id="scene1-arrowhead">` 作为反应箭头末端。
  8. 事件绑定：上一步/下一步按钮绑定 `click` 事件，调用 `updateStep(currentStep - 1)` / `updateStep(currentStep + 1)`，并做边界检查（0≤step≤5）。
- ID命名规范：所有SVG元素和JS变量ID必须以 `scene1-` 为前缀。例如：`scene1-white-box`、`scene1-enzyme1-arrow`、`scene1-table-row2`、`scene1-btn-prev`、`scene1-btn-next`。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免多场景合并时全局变量污染。
