[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：系谱图为静态几何图形与简单状态切换，无需复杂数学计算或3D渲染，原生SVG足以保证清晰度与性能，且便于精确控制每个元素的显示/隐藏/透明度。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  0    100   200   300   400   500   600   700   800
  +-----+-----+-----+-----+-----+-----+-----+-----+  0
  |     |     |  Ⅰ-1  ×  Ⅰ-2  |     |  图例  |     |  40
  |     |     |   □———○   |     |     | [甲病男]|     |  80
  |     |     |    |      |     |     | [乙病女]|     |  120
  |     |  □———○   ○   ○   ○   □   | [正常男]|     |  160
  |     |  Ⅱ-3 Ⅱ-4  Ⅱ-5  Ⅱ-6  Ⅱ-7 | [正常女]|     |  200
  |     |    |  ○———□              |         |     |  240
  |     |   Ⅲ-8 Ⅲ-9               |         |     |  280
  |  步骤说明文字区域（宽580px）      |         |     |  320
  |  .............................  |         |     |  400
  |        [◀上一步] [下一步▶]       |         |     |  450
  +-----+-----+-----+-----+-----+-----+-----+-----+  500
  ```
  （注：□=男性，○=女性，×=婚配线，——=连线，图例在右侧x=655~790区域）

- 关键实现要点：
  1. **状态机设计**：定义常量 `STEP_0=0, STEP_1=1, STEP_2=2, STEP_3=3`，当前状态 `currentStep`。每次点击按钮时调用 `renderStep(step)`，根据步骤号设置各元素的 `display`/`opacity`/`stroke` 属性。
  2. **元素分组管理**：
     - `group-pedigree`：系谱图基础元素（始终显示）
     - `group-step1`：步骤1高亮框、推导箭头、淡化遮罩
     - `group-step2`：步骤2高亮框、推导箭头、XO标记、淡化遮罩
     - `group-step3`：基因型标注文本
  3. **淡化效果实现**：对非目标个体，设置 `opacity: 0.35` 并将轮廓色改为 `#888888`；对目标个体保持 `opacity: 1` 和 `#000000` 轮廓。使用CSS transition实现300ms淡入淡出。
  4. **高亮框绘制**：使用SVG `<rect>`（对方形）或 `<circle>`（对圆形），描边 `#2e7d32`，线宽3px，无填充，位置为原符号外扩8px（方形：x-4,y-4,w+8,h+8；圆形：r+8）。
  5. **推导箭头**：使用SVG `<path>` 配合 `<marker>` 定义箭头头部。路径使用 `M` 和 `L` 指令绘制折线。

     - `pattern-jia`：45°斜线，#1565c0，线宽2px，间隔4px
     - `pattern-yi`：圆点阵列，#c62828，半径2.5px，间隔6px
  7. **按钮状态**：在步骤0时禁用「上一步」，在步骤3时禁用「下一步」。
  8. **文字换行**：步骤说明文字使用 `<foreignObject>` 内嵌 `<div>` 实现自动换行，或预先将长文本拆分为多个 `<text>` 或 `<tspan>` 元素。
