[图示主题与整合说明]
- 本图示主题：Ⅱ-5性染色体异常（XO）的成因及异常配子结合结果
- 整合的步骤/概念：
  1. 正常男性减数分裂产生X^B与Y正常精子的对照；
  2. 父亲（Ⅰ-1，X^BY）在减数第一次分裂时X与Y不分离的动态过程；
  3. 异常配子类型（O精子与X^BY精子）的形态示意；
  4. 母亲（Ⅰ-2）正常减数分裂产生X^b卵子，与父亲O精子结合形成Ⅱ-5（X^bO）的过程；
  5. 另一种异常配子X^BY与母亲正常卵子（X^B或X^b）结合的两种存活结果（X^BX^BY、X^bX^BY）。
- 教学价值：教师通过分步导航，按"正常对照→异常分裂→受精形成Ⅱ-5→另一种结果"的时间线讲解，帮助学生理解减数分裂不分离导致性染色体异常的机制，并直观对比两种异常配子的不同命运。

[分步序列]
- 初始状态（步骤0）：显示左侧正常男性减数分裂完整流程（精原细胞X^BY→减Ⅰ配对→减Ⅱ分离为X^B和Y→正常精子X^B与Y）。右侧完全空白。标题为"步骤0：正常男性减数分裂（对照）"。
- 步骤1：点击「下一步」→ 左侧替换为父亲（Ⅰ-1）异常减数分裂。精原细胞不变；减Ⅰ细胞中X与Y未分离，加红色虚线闪烁高亮框及"不分离"标签；减Ⅱ左细胞为空（O），右细胞含X^BY；底部精子左为虚线空心圆标注"O"，右为X^BY精子。标题更新为"步骤1：父亲减数分裂Ⅰ不分离"。
- 步骤2：点击「下一步」→ 右侧出现母亲（Ⅰ-2）正常减数分裂流程（卵原细胞X^BX^b→减Ⅰ分离→减Ⅱ得X^b→X^b卵子）；中间出现水平受精箭头，左侧O精子与右侧X^b卵子指向中央合子；合子显示为绿色外框大圆，内部仅含X^b，上方标注"Ⅱ-5"，下方标注"X^bO"。标题更新为"步骤2：Ⅱ-5（X^bO）的形成"。
- 步骤3：点击「下一步」→ 隐藏步骤2的中央合子及受精箭头；右侧母亲卵子变为两个（X^B在x=600，X^b在x=680）；从父亲X^BY精子（x=210）向右分出两条斜箭头分别指向下方两个合子；从两个母亲卵子向左分出斜箭头指向对应合子；左合子A（x=320）内含X^B+X^B+Y，标注"X^BX^BY"及"存活个体"；右合子B（x=480）内含X^b+X^B+Y，标注"X^bX^BY"及"存活个体"。标题更新为"步骤3：另一种异常配子的受精结果"。

- 关键实现要点：
  1. 状态机设计：变量 `currentStep` ∈ {0,1,2,3}，初始化0。每步对应一个SVG `<g>` 组（id="scene2-step0" ~ "scene2-step3"），组内包含该步所有专属元素。切换步骤时，隐藏所有组，仅显示当前步骤组。共用元素（如父亲精原细胞在步骤0和1均显示）可放在独立组或重复绘制（重复绘制更简单，避免跨组管理）。
  2. 坐标计算：所有坐标严格按布局坐标表实现，细胞用`<circle cx cy r>`，染色体用`<path d>`预定义X形和Y形路径，通过`transform="translate(x,y) scale(s)"`复用。
  3. 动画曲线：不分离高亮使用CSS `@keyframes scene2-blink { 0%,100%{opacity:1} 50%{opacity:0.3} }`，动画时长1s，infinite循环。分步切换不使用过渡动画，直接显示/隐藏，确保教学节奏清晰。
  4. 事件绑定：上一步/下一步按钮绑定click事件，更新`currentStep`后调用`updateScene()`。`updateScene()`内使用`getElementById`获取各组，设置`style.display = 'none'/'block'`。
  5. 箭头标记：在SVG `<defs>` 中定义`<marker id="scene2-arrowhead" viewBox="0 0 10 10" refX="9" refY="5" markerWidth="6" markerHeight="6" orient="auto"><path d="M 0 0 L 10 5 L 0 10 z" fill="#000000"/></marker>`，步骤2受精箭头可另定义绿色marker。
- **ID命名规范**：所有SVG元素及JS变量均以 `scene2-` 为前缀。例如：`scene2-father-spermatogonium`、`scene2-step1-group`、`scene2-highlight-rect`、`scene2-btn-prev`、`scene2-btn-next`。JS中严格使用 `document.getElementById` 获取元素，禁止全局class选择，避免多场景合并时污染。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，内部变量不泄露全局作用域。若需暴露接口，仅挂载单一对象到window（如 `window.scene2Controller`），但本场景为自包含交互，无需外部接口。
