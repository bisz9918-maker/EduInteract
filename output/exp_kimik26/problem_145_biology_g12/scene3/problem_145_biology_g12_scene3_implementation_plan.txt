[图示主题与整合说明]
- 本图示主题：Ⅱ-3与Ⅱ-4婚配生育两病兼患孩子的概率计算
- 整合的步骤/概念：
  1. 通过系谱图局部定位Ⅱ-3、Ⅱ-4及其父母Ⅰ-1、Ⅰ-2、Ⅱ-5，建立表型背景；
  2. 推导Ⅱ-3（AaX^BY）与Ⅱ-4（aa，1/2 X^BX^B 或 1/2 X^BX^b）的基因型；
  3. 用Punnett square计算甲病（常染色体显性）概率 P=1/2；
  4. 用三层概率分支树计算乙病（伴X隐性）概率 P=1/8；
  5. 联合概率 P(两病兼患)=1/16，高亮展示最终结果。
- 教学价值：教师通过分步导航，可逐层展开从基因型→单病概率→联合概率的完整推导链，学生能跟随每一步的视觉聚焦点理解条件分支与乘法原理。

[分步序列]
- 初始状态（步骤0）：展示系谱图局部（Ⅰ-1、Ⅰ-2、Ⅱ-3、Ⅱ-4、Ⅱ-5）及代际标签、人物编号；右侧显示Ⅱ-3和Ⅱ-4的表型说明文字；底部控件栏显示「上一步」（禁用态/隐藏）、「步骤 0/4」、「下一步」。
- 步骤1：点击「下一步」→ 系谱图保留，右侧新增基因型推导文字块。
  • Ⅱ-3推导：父亲Aa×母亲aa，Ⅱ-3患甲病→Aa；不患乙病→X^BY；综合AaX^BY（蓝色粗体）。
  • Ⅱ-4推导：不患甲病→aa；父亲X^BY×母亲X^BX^b（因Ⅱ-5患乙病）→Ⅱ-4为1/2 X^BX^B或1/2 X^BX^b（红色粗体）。
  • 系谱图中Ⅱ-3、Ⅱ-4分别加蓝色/红色外圈描边（r=12的圆圈，线宽2px，无填充）以高亮当前分析对象。
- 步骤2：点击「下一步」→ 系谱图和基因型推导隐藏，进入甲病概率计算画面。
  • 显示Punnett square（Aa×aa）：左上Aa、右上Aa、左下aa、右下aa。
  • 右侧标注「1/2 患甲病（Aa）」和「1/2 正常（aa）」。
  • 底部显示蓝色粗体结论「∴ P(甲病) = 1/2」。
- 步骤3：点击「下一步」→ 甲病画面隐藏，进入乙病概率分支树。
  • 根节点「Ⅱ-4」；第一层分支「1/2 X^BX^B」（左上）和「1/2 X^BX^b」（右下）。
  • 仅下侧分支继续：第二层「1/2 女」和「1/2 男」。
  • 仅男孩分支继续：第三层「1/2 X^B（正常）」和「1/2 X^b（患乙病）」。
  • 末端标注：X^BX^B分支P=0；女孩分支P=0（父亲传X^B）；X^B男孩P=0；X^b男孩P=1/8。
  • 底部红色粗体结论「P(乙病) = 1/2 × 1/2 × 1/2 = 1/8」。
  • 灰色虚线注释：「注：女孩不可能患乙病，父亲Ⅱ-3必传X^B」。
- 步骤4：点击「下一步」→ 乙病分支树隐藏，进入联合概率总结画面。
  • 左侧显示「P(甲病) = 1/2」（蓝色），中间大号「×」，右侧「P(乙病) = 1/8」（红色）。
  • 下方依次显示公式行「P(两病兼患) = P(甲病) × P(乙病)」、「= 1/2 × 1/8」。
  • 大号绿色粗体「= 1/16」配高亮框（绿边框+浅绿填充）。
  • 底部结论文字「∴ Ⅱ-3与Ⅱ-4生育两病兼患孩子的概率为 1/16」。
  • 「下一步」按钮变为禁用态或隐藏（或改为「完成」）。
- 教师可随时点击「上一步」回退到任意步骤复习；每步切换时元素组以opacity过渡0.25s淡入淡出。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  • 「上一步」按钮：位置(260,452)，尺寸90×32px，点击后currentStep减1，回退到前一步画面。
  • 「步骤指示器」文本：位置(370,472)，显示"步骤 X/4"，居中于两按钮之间。
  • 「下一步」按钮：位置(450,452)，尺寸90×32px，点击后currentStep加1，进入下一步画面；在步骤4时禁用或变为「完成」。
- 教师操作流程：
  1. 教师打开图示，默认步骤0，向学生指出系谱图中Ⅱ-3（患甲病男性）和Ⅱ-4（正常女性）的位置及表型。
  2. 点击「下一步」进入步骤1，讲解基因型推导逻辑：Ⅱ-3由父母基因型及自身表型确定为AaX^BY；Ⅱ-4由甲病表型得aa，由Ⅱ-5患乙病推断母亲为携带者，从而Ⅱ-4有1/2概率为携带者。
  3. 点击「下一步」进入步骤2，展示Aa×aa的Punnett square，得出P(甲病)=1/2。
  4. 点击「下一步」进入步骤3，展开乙病三层分支树，强调女孩不可能患乙病（父亲传X^B），只有X^BX^b母亲生男孩且传X^b时才患病，计算得P(乙病)=1/8。
  5. 点击「下一步」进入步骤4，展示联合概率公式，高亮最终结果1/16，完成讲解。
  6. 讲解过程中可随时点击「上一步」回退复习关键推导节点。

  ```
  |       [◀上一步]  步骤X/4  [下一步▶]                     |
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 `let currentStep = 0;` 记录当前步骤（0~4）。每步对应一个SVG `<g>` 分组（id="scene3-step0-group" 至 "scene3-step4-group"），分组内包含该步所有视觉元素。切换步骤时，先隐藏所有分组（设置 `display: none` 或 `opacity: 0`），再显示目标分组（`display: block` 或 `opacity: 1`），配合CSS transition实现0.25s淡入淡出。
  2. 系谱图复用：步骤0和步骤1都需要系谱图。将系谱图放在独立分组 `scene3-pedigree-group` 中，步骤0和步骤1同时显示该分组；步骤2~4隐藏该分组。
  3. 高亮效果：步骤1中Ⅱ-3和Ⅱ-4的高亮外圈，作为独立 `<circle>` 元素放在 `scene3-step1-group` 内，仅步骤1显示。
  4. SVG pattern定义：在 `<defs>` 中定义两个pattern：
     - `id="scene3-pattern-甲病"`：蓝斜线（#1565c0，线宽1px，角度45°）。
     - `id="scene3-pattern-乙病"`：红点填充（#c62828，圆点阵列，半径1.5px，间距4px）。
  5. 按钮状态管理：
     - 步骤0时，「上一步」按钮设置 `disabled` 或 `opacity: 0.4`。
     - 步骤4时，「下一步」按钮设置 `disabled` 或文本改为「完成」。
  6. 坐标计算：所有坐标硬编码于SVG元素属性中，严格遵循布局坐标表，确保代码agent可直接复制坐标值。
  7. 事件绑定：为「上一步」和「下一步」按钮绑定 `click` 事件，调用 `updateStep(newStep)` 函数更新状态机与画面。
- **ID 命名规范**：所有交互元素及分组 ID 必须以 `scene3-` 为前缀。例如：
  - 分组：`scene3-pedigree-group`, `scene3-step0-group`, `scene3-step1-group`, `scene3-step2-group`, `scene3-step3-group`, `scene3-step4-group`
  - 按钮：`scene3-btn-prev`, `scene3-btn-next`
  - 指示器：`scene3-step-indicator`
  - pattern：`scene3-pattern-甲病`, `scene3-pattern-乙病`
  - 系谱个体：`scene3-pedigree-i1`, `scene3-pedigree-i2`, `scene3-pedigree-ii3`, `scene3-pedigree-ii4`, `scene3-pedigree-ii5`
  - JS中严格使用 `document.getElementById` 获取元素，禁止用 `querySelectorAll` 配合全局class，避免多场景合并时跨场景污染。
- IIFE 隔离：所有 JavaScript 代码包裹在 `(function() { ... })();` 中，变量不污染全局作用域。
