[图示主题与整合说明]
- 本图示主题：果蝇性染色体异常类型与减数分裂染色体行为
- 整合的步骤/概念：题目原图四种异常类型 → 正常果蝇体细胞染色体组成 → 正常减数第一次分裂中期（染色体组数） → 正常减数第二次分裂后期（染色体数） → XXY雌果蝇特殊减数分裂联会与分离 → 四种配子类型总结
- 教学价值：教师通过分步导航，带领学生先建立性染色体异常类型的直观认知，再回归正常减数分裂夯实基础，最后深入XXY特殊减数分裂，形成“异常→正常→特殊异常”的认知递进。每一步可暂停讲解，支持回退复习。

[视觉元素清单]
- 场景标题：SVG text，位置(400, 32)，font-size 18px，font-weight bold，#000000
- 细胞轮廓：circle 或 ellipse，stroke #000000，stroke-width 2px，fill #ffffff（死亡类型 fill #e0e0e0，opacity 0.4）
- 染色体：path 绘制的 V 形棒状，stroke-width 3px，linecap round
  - 常染色体（Ⅱ、Ⅲ、Ⅳ）：stroke #666666
  - X 染色体：stroke #1565c0（蓝高亮）
  - Y 染色体：stroke #c62828（红高亮），臂长比 X 短约 30%

- 赤道板：line，stroke #888888，stroke-dasharray "6,4"
- 箭头：path 绘制的单向箭头，stroke #2e7d32（绿高亮），用于步骤4示意分离路径
- 卡片外框：rect，stroke #000000，stroke-width 1.5px，fill none（死亡类型 fill #e0e0e0，opacity 0.4）
- 配子圆：circle，stroke #2e7d32，stroke-width 2px，fill #ffffff
- 结论高亮背景：rect，fill #2e7d32，opacity 0.15，rx=4，位于结论文字后方
- 控件按钮：rect，fill #f5f5f5，stroke #cccccc，rx=4；文字 #333333
- 所有标签文字：font-family "Microsoft YaHei", "PingFang SC", sans-serif

[分步序列]
- 初始状态（步骤0）：显示四种性染色体异常果蝇卡片（XXY、XO、XXX、OY）。每张卡片内绘制细胞圆和染色体模式图（3对常染色体+性染色体），卡片底部标注类型、性别与育性。XXX 与 OY 卡片背景灰色半透明并标“死亡”。场景标题为“果蝇性染色体异常类型”。
- 步骤1：点击「下一步」→ 隐藏步骤0卡片，显示正常果蝇体细胞。左右两个细胞分别展示雌性（6+XX）与雄性（6+XY）染色体组成，细胞上方标注“2个染色体组”，下方标注“♀ 2n=8 (6+XX)”与“♂ 2n=8 (6+XY)”。
- 步骤2：点击「下一步」→ 切换为减数第一次分裂中期。中央一个细胞，内部4对同源染色体（含XX）配对排列在赤道板虚线上。染色体上方标注“Ⅱ、Ⅲ、Ⅳ、X”，细胞左侧标注“n=2”，下方绿色高亮标注“染色体组数 = 2”。
- 步骤3：点击「下一步」→ 切换为减数第二次分裂后期。两个相连的圆形子细胞，每极各4条染色体（着丝点已分裂）。左侧标注“4条”，右侧标注“4条”，下方绿色高亮标注“染色体数 = 8”。
- 步骤4：点击「下一步」→ 切换为 XXY 雌果蝇减数分裂。左右两个细胞并列，分别展示两种联会方式：左细胞“Xʳ-Y配对，Xʳ游离”，右细胞“Xʳ-Xʳ配对，Y游离”。中间标“或”。细胞下方分别用文字说明联会方式。用绿色箭头从性染色体指向细胞两极，示意分离方向。
- 步骤5：点击「下一步」→ 切换为四种配子总结。四个等大的配子圆横向排列，内部分别标注“Xʳ”、“XʳXʳ”、“XʳY”、“Y”。圆下方重复标注配子基因型。底部绿色高亮文字“四种配子类型”。
- 教师可随时点击「上一步」回退至任意步骤复习。

- 控件说明：

  2. 「下一步」按钮：位于 SVG 内底部 (440, 452)，宽 80×高 28。点击后 currentStep 加 1，隐藏当前步骤组，显示后一步骤组，更新步骤指示器。

- 边界处理：currentStep=0 时「上一步」按钮置灰禁用；currentStep=5 时「下一步」按钮置灰禁用。
- 教师操作流程：教师打开图示后，步骤0自动呈现四种异常类型，可指着卡片讲解；点击「下一步」依次进入正常体细胞、减Ⅰ中期、减Ⅱ后期、XXY联会、配子总结。在步骤2和步骤3暂停，提问学生染色体组数/染色体数目；在步骤4暂停，让学生思考两种联会方式产生的配子差异；步骤5用于归纳答案。

[技术实现]
- JS 库选择：原生 SVG（优先）+ 原生 JavaScript。理由：本场景以静态染色体模式图和分步显隐为主，无复杂函数绘图或3D需求，SVG 的矢量图形最适合绘制染色体、细胞圆和标签，且缩放清晰。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图：
  ```
  +--------------------------------------------------+
  |  场景标题 (y=32)                                  |
  +--------------------------------------------------+
  |                                                  |
  |  主图区 (y=40~430)                               |
  |  ┌──────────────────────────────────────────┐   |
  |  │  步骤0: [XXY] [XO] [XXX] [OY] 卡片       │   |
  |  │  步骤1: [♀体细胞]      [♂体细胞]          │   |
  |  │  步骤2: [   减Ⅰ中期细胞   ]               │   |
  |  │  步骤3: [减Ⅱ左]    [减Ⅱ右]               │   |
  |  │  步骤4: [联会方式1] 或 [联会方式2]         │   |
  |  │  步骤5: (Xʳ) (XʳXʳ) (XʳY) (Y)            │   |
  |  └──────────────────────────────────────────┘   |
  |                                                  |
  +--------------------------------------------------+
  |  [◀ 上一步]      步骤 X / 6      [下一步 ▶]     |
  |  控件区 (y=445~485)                               |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `let scene1_currentStep = 0;`，取值范围 0~5。每一步对应一个 SVG `<g id="scene1-step{k}-group">`，初始仅 step0-group 设置 `visibility: visible`，其余为 `hidden`。
  2. 切换逻辑：`scene1_showStep(idx)` 函数遍历 0~5，将目标 group 设为 visible，其余 hidden，并同步更新按钮禁用状态和指示器文字。
  3. 染色体绘制：使用 SVG `<path>` 绘制 V 形染色体。以着丝粒为基准点，两臂按角度展开。常染色体灰色 #666666；X 染色体蓝色 #1565c0；Y 染色体红色 #c62828 且臂长缩短。着丝粒用 `<circle r="3" fill="#000"/>`。
  4. 上标文字：Xʳ、Xᴿ 等使用 SVG `<text>` 内嵌 `<tspan baseline-shift="super" font-size="0.7em">r</tspan>` 实现，避免引入 MathJax 减少依赖。
  5. 高亮背景：结论文字（如“染色体组数 = 2”）后方放置 `<rect>`，fill="#2e7d32"，opacity="0.15"，rx="4"，尺寸略大于文字 bounding box（可通过预估或 getBBox 动态设置）。
  6. 动画曲线：分步切换不使用复杂动画，直接显隐；若需柔和过渡，可对 group 添加 CSS `transition: opacity 0.25s ease`，但计划中以即时切换为主，保证课堂节奏。
  7. 事件绑定：按钮使用 `onclick="scene1_showStep(scene1_currentStep - 1)"` 和 `+1`，在 IIFE 内定义，避免全局污染。
- ID 命名规范：
  - 步骤组：`scene1-step0-group` ~ `scene1-step5-group`
  - 按钮：`scene1-btn-prev`、`scene1-btn-next`
  - 指示器：`scene1-step-indicator`
  - 标题：`scene1-title`
  - 细胞/染色体：`scene1-s0-c1-cell`（step0 card1 cell）、`scene1-s2-chr-II`（step2 chromosome II）等
  - 获取方式：`document.getElementById`，禁止 querySelectorAll 配合全局 class
- IIFE 隔离：所有 JavaScript 包在 `(function() { ... })();` 中，内部变量不暴露全局。
