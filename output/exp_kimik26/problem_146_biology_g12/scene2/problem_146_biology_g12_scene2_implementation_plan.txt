[图示主题与整合说明]
- 本图示主题：XXY白眼雌果蝇与红眼雄果蝇的伴性遗传杂交（Punnett square推导）
- 整合的步骤/概念：
  1) 亲本性染色体组成与表现型；
  2) XXY雌果蝇产生的4种雌配子与红眼雄果蝇产生的2种雄配子；
  3) 4×2杂交棋盘格及8种子代基因型；
  4) 子代表现型与致死类型（XXX、YY/OY）标注；
  5) 提取目标答案——红眼雌果蝇的两种基因型 XᴿXʳ 与 XᴿXʳY。
- 教学价值：教师通过分步导航，逐步展示从亲本→配子→棋盘格→表现型→结论的完整遗传推导链条，可随时回退复习任意环节。

[分步序列]
步骤0（初始状态 / 显示为"步骤 1/5"）：亲本展示
- 显示元素：雌果蝇圆及"♀"、雄果蝇圆及"♂"、亲本基因型标签（XʳXʳY、XᴿY）、亲本表现型标签（白眼雌、红眼雄）、杂交"×"符号
- 隐藏元素：配子圆、连接线、棋盘格、表现型标签、答案框
- 教师讲解点：介绍亲本的性染色体组成与表现型

步骤1（"步骤 2/5"）：配子形成
- 视觉变化：
  - 6个配子圆及内部基因型文字淡入出现（雌配子4个纵向在棋盘格左侧，雄配子2个横向在棋盘格上方）
  - 两条虚线连接线从亲本圆边缘绘制到配子标题区（雌：从(80,190)→(80,240)→(313,240)；雄：从(80,380)→(80,70)→(438,70)）
- 教师讲解点：XXY雌果蝇减数分裂产生4种配子，红眼雄果蝇产生2种配子

步骤2（"步骤 3/5"）：杂交棋盘格
- 视觉变化：
  - 棋盘格外框、列线、行线绘制完成
  - 8个格子内的基因型文字逐个显示（或整体淡入）
  - 配子与格子之间的对应关系可通过教师口述或短暂高亮提示
- 教师讲解点：每种雌配子与每种雄配子随机结合，得到8种子代基因型

步骤3（"步骤 4/5"）：子代表现型与致死判定
- 视觉变化：
  - 8个格子内的表现型标签全部显示
  - 致死格子（(2,1) XXX致死、(4,2) OY致死）添加浅灰背景填充 rgba(128,128,128,0.2)
  - 红眼表现型文字使用蓝色 #1565c0，白眼表现型文字使用红色 #c62828
  - 致死标记文字使用灰色 #666666
- 教师讲解点：结合SCENE_1知识，XXX与OY（无X）个体致死，存活子代有6种

步骤4（"步骤 5/5"）：提取答案——红眼雌果蝇基因型
- 视觉变化：
  - 右侧弹出答案框（x=690,y=140,w=100,h=240）
  - 两个红眼雌果蝇所在格子（(1,1) XᴿXʳ 和 (3,1) XᴿXʳY）添加浅绿背景填充 rgba(46,125,50,0.2)，边框加粗为绿色 #2e7d32
  - 答案框内文字"红眼雌果蝇"、"基因型："、"XᴿXʳ"、"XᴿXʳY"依次显示，答案基因型文字使用绿色 #2e7d32 并加粗
  - 非目标格子（除(1,1)和(3,1)外）透明度降至30%，视觉聚焦答案
- 教师讲解点：从存活子代中筛选红眼雌果蝇，其基因型为 XᴿXʳ 和 XᴿXʳY

[技术实现]
- JS库选择：原生 SVG（所有元素为几何图形、文字、表格，SVG最为直接，无需引入外部库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  800×500 画布
  ┌────────────────────────────────────────────────────────────┐
  │  [雌圆♀] XʳXʳY 白眼雌      [Xᴿ圆]    [Y圆]               │
  │      ×                         ↓         ↓                │
  │  [雄圆♂] XᴿY 红眼雄      ┌─────────────────────┐         │
  │                            │ XᴿXʳ │ XʳY        │         │
  │  [Xʳ圆]→                 │红眼雌│白眼雄      │         │
  │  [XʳXʳ圆]→               ├──────┼─────────────┤         │
  │  [XʳY圆]→                │XXX   │ XʳXʳY      │         │
  │  [Y圆]→                  │致死  │白眼雌      │         │
  │                            ├──────┼─────────────┤         │
  │                            │XᴿXʳY│ XʳYY       │ [答案框]│
  │                            │红眼雌│白眼雄      │ XᴿXʳ   │
  │                            ├──────┼─────────────┤ XᴿXʳY  │
  │                            │XᴿY   │ YY         │         │
  │                            │红眼雄│OY致死      │         │
  │                            └─────────────────────┘         │
  │  [◀ 上一步]  步骤 X/5  [下一步 ▶]                         │
  └────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `scene2.currentStep`（取值0~4），每次点击按钮时更新状态并调用 `scene2.render()` 重新渲染可见性。
  2. 分组管理：SVG内使用 `<g>` 元素按步骤分组，ID分别为 `scene2-group-step0` ~ `scene2-group-step4`。`render()` 函数根据 `currentStep` 设置各组的 `display` 属性（`block`/`none`）。步骤4的高亮效果通过给特定格子添加/移除高亮class实现。
  3. 坐标计算：棋盘格采用固定坐标，格子中心已精确计算（列中心453/598，行中心140/220/300/380），基因型文字统一在中心y-8，表现型在中心y+12。
  4. 动画曲线：配子出现使用 `opacity` 0→1 过渡，时长200ms；棋盘格基因型使用短延迟（50ms）逐个淡入；步骤4答案框从右侧滑入（`transform: translateX(20px)` → `translateX(0)`），时长300ms，使用 `ease-out`。
  5. 事件绑定：上一步/下一步按钮通过 `getElementById('scene2-btn-prev')` 和 `getElementById('scene2-btn-next')` 获取，绑定 `click` 事件。按钮禁用状态通过添加/移除 `disabled` 属性控制。
  6. 颜色动态切换：红眼/白眼表现型文字在步骤3才显示，直接按蓝/红着色；致死格子背景通过 `<rect>` 填充实现，步骤3显示；步骤4时非目标格子透明度通过设置 `opacity: 0.3` 实现。
- ID命名规范：所有交互元素ID必须以 `scene2-` 为前缀，例如 `scene2-female-circle`、`scene2-grid-cell-11`、`scene2-btn-next` 等。JS中严格使用 `getElementById` 获取元素，禁止跨场景选择器。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })()` 立即执行函数中，避免全局变量污染。
