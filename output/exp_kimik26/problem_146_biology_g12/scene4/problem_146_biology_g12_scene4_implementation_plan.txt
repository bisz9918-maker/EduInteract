[图示主题与整合说明]
- 本图示主题：M白眼雄果蝇出现原因的实验验证与结果预测
- 整合的步骤/概念：
  1. 三种互斥假说（环境改变 / 基因突变 / X染色体不分离）的并列对比；
  2. 每种假说下M果蝇的基因型推导；
  3. 统一的测交实验设计（M × 正常白眼雌 X^r X^r）；
  4. 三种不同的遗传图解与预期结果。
- 教学价值：教师可在课堂上通过顶部按钮快速跳转三种假说，学生能直观对比“相同杂交组合、不同基因型”导致的截然不同结果，强化对基因型-表现型关系、基因突变、染色体变异三大知识点的区分。

[分步序列]
本场景为"多状态切换"交互，无分步导航，共3个互斥状态：

- 初始状态（状态1：环境改变）：
  - 按钮1高亮（蓝底白字），按钮2/3灰底黑字。
  - 假说标题显示"假说一：环境改变引起表现型变化，但基因型未变"。
  - M卡片：基因型"X^R Y"（X^R蓝色，Y黑色），眼睛蓝色（提示基因型为红眼基因），表现型"白眼雄"。
  - 雌卡片：基因型"X^r X^r"，眼睛红色，表现型"白眼雌"。
  - 配子区：M配子"X^R"（蓝）、"Y"（黑）；雌配子"X^r"（红）。
  - 子代区：子代1 "X^R X^r" + "♀ 红眼"（蓝色）；子代2 "X^r Y" + "♂ 白眼"（红色）。
  - 结果框：浅蓝填充，文字"子代雌蝇全为红眼（X^R X^r），雄蝇全为白眼（X^r Y）"。

- 状态2（基因突变）：点击按钮2切换。
  - 按钮2高亮（红底白字），其余灰底。
  - 假说标题显示"假说二：亲本果蝇发生基因突变"。
  - M卡片：基因型"X^r Y"（X^r红色，Y黑色），眼睛红色，表现型"白眼雄"。
  - 雌卡片不变。
  - 配子区：M配子"X^r"（红）、"Y"（黑）；雌配子"X^r"（红）。
  - 子代区：子代1 "X^r X^r" + "♀ 白眼"（红色）；子代2 "X^r Y" + "♂ 白眼"（红色）。
  - 结果框：浅红填充，文字"子代无论雌雄全为白眼（X^r X^r、X^r Y）"。

- 状态3（X染色体不分离）：点击按钮3切换。
  - 按钮3高亮（绿底白字），其余灰底。
  - 假说标题显示"假说三：亲本雌果蝇减数分裂时X染色体不分离"。
  - M卡片：基因型"X^r O"（X^r红色，O黑色），眼睛红色，表现型"白眼雄（不育）"。
  - 雌卡片不变。
  - 配子区：隐藏（M不育无配子）。
  - 子代区：隐藏子代文本，显示不育标记组（大♂+红色禁止圈斜线）及"无子代（XO雄性不育）"。
  - 结果框：浅绿填充，文字"无子代产生（XO雄性不育）"。

[交互方案]
- 交互类型：多状态切换（3个按钮）。
- 控件说明：
  - 「环境改变」按钮：位置(60,12)-(260,48)，点击切换到状态1。
  - 「基因突变」按钮：位置(310,12)-(510,48)，点击切换到状态2。
  - 「X染色体不分离」按钮：位置(560,12)-(760,48)，点击切换到状态3。
- 教师操作流程：
  1. 教师先讲解题干背景（F1出现一只白眼雄果蝇M）。
  2. 点击「环境改变」按钮，展示第一种假说的基因型与预期结果，引导学生思考"如果基因型没变，子代应该出现什么比例"。
  3. 点击「基因突变」按钮，对比第二种假说，强调"基因突变后基因型改变，子代表现型全部改变"。
  4. 点击「X染色体不分离」按钮，展示第三种假说，联系SCENE_1中XO不育的知识点，得出"无子代"结论。
  5. 反复切换三种状态，让学生对比三种预期结果的差异，理解如何通过一次简便的测交实验区分三种原因。

[技术实现]
- JS库选择：原生SVG（无需外部库，本场景全部为静态几何图形、文本和颜色切换，SVG+原生JS足以高效实现）。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------------+
  |  [环境改变]    [基因突变]    [X染色体不分离]   y=12~48  |
  |              假说标题（居中）                  y=66      |
  |  +-------+         ×         +-------+                 |
  |  |M基因型|                   |雌基因型|    y=85~158    |
  |  |       |                   |       |                 |
  |  |  ♂    |        ↓          |   ♀   |    y=175~238   |
  |  +-------+                   +-------+                 |
  |  配子      X^R  Y      ×      X^r        y=278~330     |
  |       +---------------------+                          |
  |       | 子代1      子代2    |            y=340~402     |
  |       | X^R X^r   X^r Y     |                          |
  |       | ♀红眼    ♂白眼     |                          |
  |       +---------------------+                          |
  |  [结果预测总结框]                          y=408~438   |
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：定义 `let currentState = 1;`，状态数据用数组 `states[3]` 存储，每个状态对象包含所有可变文本、颜色、display标志。
  2. 渲染函数 `render()`：根据 `currentState` 遍历更新所有带 `scene4-` 前缀的SVG元素属性（textContent、fill、stroke、display）。
  3. 上标处理：基因型文本（如 X^R Y）使用 `<tspan>` 实现，例如 `<tspan>X</tspan><tspan dy="-6" font-size="14">R</tspan><tspan dy="6"> </tspan><tspan>Y</tspan>`，通过 `innerHTML` 更新。
  4. 按钮样式切换：通过修改按钮rect的fill属性和text的fill属性实现高亮/未选中状态。
  5. 显示/隐藏控制：状态3需隐藏配子文本和子代文本，显示不育标记组；状态1/2则相反。使用 `display = "none" / "block"` 控制。
  6. 事件绑定：三个按钮分别绑定 `onclick` 事件，更新 `currentState` 后调用 `render()`。
  7. 动画：本场景无需复杂动画，状态切换即时更新即可；如需柔和过渡，可在CSS中为相关元素添加 `transition: fill 0.3s, opacity 0.3s`。
- ID命名规范：所有交互元素ID必须以 `scene4-` 为前缀，例如 `scene4-btn-env`、`scene4-btn-mut`、`scene4-btn-nondis`、`scene4-m-genotype`、`scene4-offspring-box`、`scene4-sterile-mark`、`scene4-result-text` 等。JS中严格使用 `document.getElementById` 获取元素，禁止全局class选择器，避免多场景合并时跨场景污染。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，变量不泄露全局作用域。
