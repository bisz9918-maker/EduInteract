[图示主题与整合说明]
- 本图示主题：PCR一轮循环的分子过程（变性→复性→延伸→产物）
- 整合的步骤/概念：
  1. 引物Ⅱ序列的推导与书写（与a链3'端互补且反向平行，序列为5'-G-A-OH）
  2. 55°C复性时引物Ⅰ、引物Ⅱ在两条模板链上的正确位置（引物Ⅰ在b链3'端左侧，引物Ⅱ在a链3'端右侧且3'-OH端朝左）
  3. 72°C延伸时DNA聚合酶从引物3'端沿模板链向5'端方向合成新链（引物Ⅰ向右延伸、引物Ⅱ向左延伸）
  4. 循环一次后生成的两个DNA分子（各含一条原始模板链和一条新合成链，即半保留复制）
- 教学价值：教师通过分步导航精确控制课堂节奏，逐步揭示PCR的分子机制。关键细节（引物方向性、3'-OH延伸位点、反向平行、半保留复制）通过颜色区分（蓝=原始模板链，红=新合成链，绿=引物）和分步动画强化学生理解。可随时回退复习。

[视觉元素清单]
- DNA模板链（a链、b链）：水平线段，两端带方向箭头（5'/3'标签），蓝色 #1565c0，线宽3px
- 新合成链：水平线段，红色 #c62828，线宽3px，与模板链反向平行
- 引物：较短水平线段，绿色 #2e7d32，线宽4px，末端标注-OH（3'端）
- 碱基字母：G/C/T/A，等宽字体 monospace 16px，颜色与所在链一致（蓝/红/绿）
- 碱基配对氢键：灰色 #888888 竖线，线宽1px，连接上下链对应碱基
- 温度标注框：圆角矩形，填充 #f5f5f5，边框 #888888，文字"95°C 变性"/"55°C 复性"/"72°C 延伸"
- DNA聚合酶图标：金色圆形 #ffd700，直径24px，黑色边框，内部可简写"E"或不填
- 省略号：三个中点"···"或中文省略号"……"，等宽字体，表示中间碱基序列
- 高亮信息框：步骤4右侧，浅黄背景 #fff3cd，15%透明度，用于展示产物序列结论
- 所有文字标签：黑色 #000000， sans-serif 字体（如 Arial, Helvetica）

[分步序列]
- 步骤0（初始状态）：展示原始双链DNA
  - 显示元素：a链（蓝，y=150）、b链（蓝，y=190）、碱基配对竖线（灰）、5'/3'方向标签、a链/b链点名标签、引物Ⅰ标签（右侧，绿）、引物Ⅱ横线（右侧，黑）
  - 步骤标题："原始双链DNA"
  - 教师引导：观察两条链的反向平行关系，确认a链5'→3'从左到右，b链3'→5'从左到右

- 步骤1（95°C变性）：点击「下一步」
  - 视觉变化：
    - 温度标注框显示"95°C 变性"
    - 碱基配对竖线变为虚线并淡出（氢键断裂）
    - b链整体向下平移到y=260，向右平移到x=300~620（与a链水平分离）
    - a链微调到y=160
    - 引物Ⅰ、引物Ⅱ标签隐藏
    - b链的碱基和方向标签随链移动到新位置
  - 步骤标题："95°C 变性 — 氢键断裂，双链解开"
  - 教学强调：高温破坏氢键，不涉及磷酸二酯键断裂

- 步骤2（55°C复性）：点击「下一步」
  - 视觉变化：
    - 温度标注框变为"55°C 复性"
    - 引物Ⅰ（绿）从画布右侧飞入到b链下方（y=300, x=300~420），与b链3'端左侧配对，出现配对竖线（x=340,380）
    - 引物Ⅱ（绿）在a链上方（y=120, x=380~500）出现，序列揭示为OH-A-G-5'（即5'-G-A-OH的反向平行放置，3'-OH端朝左），与a链3'端右侧配对，出现配对竖线（x=420,460）
    - 引物Ⅱ的碱基A与a链T配对，G与C配对
  - 步骤标题："55°C 复性 — 引物与模板互补配对"
  - 教学强调：引物Ⅱ的推导（与a链3'端互补且反向平行），验证3'-OH端朝向决定延伸方向

- 步骤3（72°C延伸）：点击「下一步」
  - 视觉变化：
    - 温度标注框变为"72°C 延伸"
    - 两个DNA聚合酶图标（金色圆）分别出现在左侧（x=340,y=105）和右侧（x=500,y=325）
    - "DNA聚合酶"标签在顶部出现
    - 新链1（红）从引物Ⅰ的3'-OH端（x=420）开始向右延伸，逐步显示碱基（G,G,···,T,C）和3'标签，直至与b链等长（x=300~620），同时逐步出现与b链的配对竖线
    - 新链2（红）从引物Ⅱ的3'-OH端（x=380）开始向左延伸，逐步显示碱基（C,C,···,A,G）和5'标签，直至与a链等长（x=180~500），同时逐步出现与a链的配对竖线
    - 延伸动画可用0.5s的逐步显示（clip-path或逐碱基opacity）模拟
  - 步骤标题："72°C 延伸 — DNA聚合酶沿5'→3'方向合成新链"
  - 教学强调：DNA聚合酶只能从3'-OH端延伸；引物Ⅰ向右延伸（沿b链5'端方向），引物Ⅱ向左延伸（沿a链5'端方向）

- 步骤4（循环一次产物）：点击「下一步」
  - 视觉变化：
    - 隐藏引物Ⅰ、引物Ⅱ单独元素及DNA聚合酶图标
    - 隐藏步骤3的分散布局，重组为两个完整双链：
      - 产物1（左侧）：新链2（红，上，y=140，3'-C-C-···-A-G-5'）+ a链（蓝，下，y=180，5'-G-G-···-T-C-3'），恢复配对竖线
      - 产物2（右侧）：新链1（红，上，y=280，5'-G-G-···-T-C-3'）+ b链（蓝，下，y=320，3'-C-C-···-A-G-5'），恢复配对竖线
    - 右侧信息框出现，标题"循环一次产物"，内容说明两个DNA分子各含一条原始链（蓝）和一条新链（红），即半保留复制
    - 温度标注框隐藏
  - 步骤标题："循环一次产物 — 半保留复制"
  - 教学强调：每个子代DNA分子都保留一条亲代链；若原料带放射性标记，新链（红）具放射性

  3. 点击「下一步」进入复性步骤，引导学生推导引物Ⅱ序列（5'-G-A-OH），观察引物Ⅱ的3'-OH端朝左的设计意图
  4. 点击「下一步」进入延伸步骤，强调DNA聚合酶的移动方向与3'-OH延伸
  5. 点击「下一步」进入产物步骤，总结半保留复制结果，可回退到任意步骤复习

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本场景为静态几何图形（线段、文字、矩形）的分步显示/隐藏，无复杂函数绘图或3D，原生SVG性能最优且无需额外库加载。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------------+
  |  标题"PCR一轮循环"                                      |
  |  步骤标题                                               |
  |                                                         |
  |      新链2(红)  ← 引物Ⅱ(绿)  ← 延伸方向（步骤3）        |
  |      a链(蓝)              [DNA聚合酶标签]               |
  |         ↑ 配对竖线                                      |
  |  [温度框]                                               |
  |                                                         |
  |      b链(蓝)  → 引物Ⅰ(绿)  → 新链1(红)                 |
  |         ↓ 配对竖线         [酶图标]                     |
  |                                                         |
  |      产物1(左双链)        产物2(右双链)   [信息框]      |
  |                                                         |
  |  [◀ 上一步]    步骤 X/5    [下一步 ▶]                   |
  +--------------------------------------------------------+
  [控件栏 y=440~490]
  ```
- 关键实现要点：
  1. 状态机设计：用变量 `currentStep`（0~4）控制当前步骤。每步用一个SVG `<g>` 分组（id="scene1-step0" ~ "scene1-step4"），通过CSS `display` 或 `opacity` 切换可见性。
  2. 坐标计算：所有碱基使用统一x网格 [180,220,260,320,420,460,500]（左链）和 [300,340,380,440,540,580,620]（右链），y坐标按步骤固定，确保上下对齐。
  3. 动画曲线：
     - 变性（步骤1）：b链平移使用CSS `transition: transform 0.6s ease-out`
     - 复性（步骤2）：引物飞入使用 `transition: transform 0.5s cubic-bezier(0.34, 1.56, 0.64, 1)`（轻微回弹）
     - 延伸（步骤3）：新链碱基逐个显示，用JS `setInterval` 每200ms显示一个碱基，模拟聚合酶延伸；配对竖线同步出现
     - 产物（步骤4）：整体淡入淡出 `transition: opacity 0.4s ease`
  4. 事件绑定：按钮绑定 `click` 事件，更新 `currentStep` 后调用 `renderStep()` 函数，该函数控制各分组的显隐和CSS类名。
  5. 引物Ⅱ方向处理：引物Ⅱ线段从(380,120)到(500,120)，左端标"-OH"（3'端），右端标"5'"，碱基从左到右为A、G。虽然序列名为5'-G-A-OH，但在图中反向平行放置时3'-OH朝左，需在计划中明确说明此绘制方式。
  6. 氢键断裂效果：步骤1中，原有配对竖线先变为 `stroke-dasharray="4,4"`，再 `opacity: 0`，持续0.4s。
  7. 步骤4信息框：使用SVG `<foreignObject>` 或 `<rect>` + `<text>` 实现，内部用 `<tspan>` 分行显示两个产物的序列说明。
- ID命名规范：所有交互元素ID必须以 `scene1-` 为前缀。例如：
  - 分组：`scene1-step0-group`, `scene1-step1-group`, ..., `scene1-step4-group`
  - 按钮：`scene1-btn-prev`, `scene1-btn-next`
  - 步骤指示器：`scene1-step-indicator`
  - 链元素：`scene1-strand-a`, `scene1-strand-b`, `scene1-strand-new1`, `scene1-strand-new2`
  - 引物：`scene1-primer1`, `scene1-primer2`
  - 酶图标：`scene1-enzyme-left`, `scene1-enzyme-right`
  - JS中严格使用 `document.getElementById`，禁止用 `querySelectorAll` 配合全局class，避免多场景合并时跨场景污染。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，不污染全局命名空间。
- 响应式说明：画布固定800×500，外层容器建议 `max-width: 800px; margin: 0 auto;`，SVG设置 `viewBox="0 0 800 500" preserveAspectRatio="xMidYMid meet"`。
