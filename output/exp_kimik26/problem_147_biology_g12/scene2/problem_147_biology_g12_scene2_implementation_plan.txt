[图示主题与整合说明]
- 本图示主题：PCR扩增中³²P标记DNA的放射性分布与比例计算
- 整合的步骤/概念：
  1. 循环一次（n=1）后，2个DNA分子均为杂合分子（一蓝一红），全部含放射性；
  2. 循环n次后，DNA分子总数2^n、总单链数2^(n+1)、含³²P单链数2^(n+1)−2、不含³²P单链数恒为2；
  3. 不含放射性单链占总单链比例的公式推导与动态验证：2/2^(n+1)=1/2^n；
  4. 随n增大，原始无标记链比例指数下降的视觉直观化。
- 教学价值：教师通过拖动滑块连续改变循环次数n，让学生实时观察"分子数倍增而原始链数恒定"的强烈对比，建立定量直觉；在n=1,2,3等整数锚点暂停，让学生口算验证；快速拖至n=10观察比例趋近于0，理解PCR扩增的指数特性。

[交互方案]
- 交互类型：连续拖拽滑块（水平拖动条，范围n=1~10，整数步进）。
- 控件说明：
  · 滑块轨道：位于SVG内底部y=445区域，长度500px（x=150~650），教师可拖动圆形按钮改变n值；
  · 滑块按钮：直径20px的蓝色圆形，位置随n线性映射；
  · 刻度标签：轨道左端标注"1"，右端标注"10"；
  · 当前值显示：滑块按钮正上方大字体显示"n = 当前值"。
- 教师操作流程：
  1. 页面加载后呈现n=1初始状态，教师先讲解PCR第一轮后DNA分子的杂合特点；
  2. 教师缓慢向右拖动滑块，学生观察DNA图标数量倍增、颜色组成变化、统计数值跳变、饼图扇形比例变化；
  3. 在n=2、n=3处暂停，让学生口算验证统计值与比例；
  4. 快速拖至n=10，引导学生观察不含放射性单链比例已降至约0.1%，强调"原始模板链始终只有2条"这一核心结论；
  5. 可反复来回拖动，对比不同n值的状态。

[技术实现]
- JS库选择及原因：原生SVG + 原生JavaScript。本场景以几何图形（线段、矩形、圆形、路径）和文本为主，无需复杂图表库；原生SVG可精确控制每个元素的坐标与属性，性能足够支持滑块拖动时的实时重绘。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +----------------------------------------------------------+
  |  DNA示意图区(20,30)        |  统计面板(300,30)           |
  |  [蓝红][蓝红]...            |  [DNA分子总数] [总单链数]   |
  |  [红红][红红]...            |  [含³²P链数] [不含³²P链数]  |
  |                             |                             |
  |        饼图(400,235)        |  图例                       |
  |         [蓝/红]             |  [蓝]不含³²P                |
  |                             |  [红]含³²P                  |
  |  [公式背景区(20,305)]                                    |
  |       特点文字（仅n=1）                                  |
  |       不含³²P单链比例 = 2/2^(n+1) = 1/2^n = ...          |
  |                                                          |
  |  循环次数 n    [========●====]    1        10            |
  |                      n = 3                               |
  +----------------------------------------------------------+
  [控件栏在SVG内底部 y=440~490，不额外占空间]
  ```
- 关键实现要点：
  1. 状态机设计：仅一个状态变量currentN（整数1~10），滑块拖动时实时更新；所有视觉元素根据currentN重绘或更新属性。
  2. DNA示意图动态生成：
     · n≤4时，按网格坐标生成全部2^n个DNA图标；前2个为蓝红（含原始链），其余为红红；
     · n>4时，清空网格，改为绘制2个代表性图标（1蓝红+1红红）及3行文字标签（"2个"、"2^n−2个"、"总计 2^n 个DNA"）。
  3. 饼图扇形计算：使用SVG path的arc命令。设比例p=1/Math.pow(2,n)，蓝色扇形角度=p×2π。计算终点坐标(x1,y1)=(400+55*sin(2π*p), 235-55*cos(2π*p))，path d="M 400 235 L 400 180 A 55 55 0 (p>0.5?1:0) 1 x1 y1 Z"；红色扇形为剩余部分。
  4. 统计数值更新：直接修改textContent，数值较大时（如1024）自动缩小字号或保持28px（28px可容纳4位数字）。
  5. 特点文字显隐：n===1时设置opacity=1，否则opacity=0；使用CSS transition实现淡入淡出。
  6. 滑块事件绑定：在滑块按钮上绑定mousedown→mousemove→mouseup；mousemove时根据鼠标x坐标（限制在150~650）计算n=1+Math.round((x-150)/500*9)，调用updateScene(n)。同时支持触摸事件。
  7. 坐标映射：滑块按钮cx = 150 + (n-1)*(500/9)。
  8. 动画曲线：无需缓动，直接瞬时更新以保证滑块拖动的实时响应性；仅特点文字的显隐使用0.2s ease过渡。
- ID命名规范：所有交互元素ID必须以scene2-为前缀，例如scene2-dna-group、scene2-stat-value-0、scene2-pie-blue、scene2-slider-thumb、scene2-formula-text等；JS中严格使用document.getElementById获取元素，禁止querySelectorAll配合全局class，避免多场景合并时跨场景污染。
- IIFE隔离：所有JavaScript代码包裹在(function() { ... })()中，不暴露全局变量；如需暴露场景控制接口，挂载到window.scene2Controller。
