[图示主题与整合说明]
- 本图示主题：甲烷与水反应制水煤气的微观示意图识读与化学方程式配平
- 整合内容：①原子图例识别 → ②分子组成与化学式判断 → ③反应前后原子数目守恒检查 → ④化学方程式配平与书写
- 教学价值：教师通过分步控制，引导学生从宏观示意图逐步深入到微观原子守恒，最终理解配平过程。步骤3故意展示"氢原子不守恒"引发认知冲突，步骤4通过补充虚线分子完成配平，强化"原子数目守恒"这一核心概念。

[分步序列]
- 初始状态（步骤0）：展示完整微观示意图。显示左框（反应前）含甲(CH₄)和乙(H₂O)，右框（反应后）含丙(CO)和丁(H₂)，中间箭头+"高温"，右侧原子图例，底部有"反应前"/"反应后"标签。所有分子以球棍模型呈现。
- 步骤1（识别原子）：点击"下一步"。图例中的白球、黑球、斜线球依次闪烁高亮（蓝色边框#1565c0，持续约400ms，间隔200ms），同时示意图中所有对应原子同步高亮（同蓝色边框）。帮助建立颜色-原子映射。闪烁3轮后保持常亮高亮状态。
- 步骤2（识别分子）：点击"下一步"。四个分子下方分别浮现化学式标签：甲→CH₄、乙→H₂O、丙→CO、丁→H₂（蓝色#1565c0，淡入动画300ms）。同时每个分子外围出现灰色虚线框，圈出其原子组成（虚线#888，淡入300ms）。
- 步骤3（原子守恒检查）：点击"下一步"。在示意图下方展开原子计数表格（从y=500外滑入到y=320，动画400ms）。表格统计反应前后C、H、O原子数：反应前C=1、H=6、O=1；反应后C=1、H=2、O=1。氢原子反应后数目"2"用红色#c62828高亮，并在表格右侧显示红色"2≠6"，引发认知冲突。其他原子行显示黑色。
- 步骤4（配平方程式）：点击"下一步"。在右框内原有丁分子上下方各补充一个虚线轮廓的丁分子（虚线#888，淡入300ms），表示还需2个H₂。原子计数表格中反应后H数目从"2"变为"6"，颜色变为绿色#2e7d32，右侧红色"2≠6"消失，显示绿色"="或保持空白表示平衡。表格中所有数字变为绿色。下方浮现配平后的化学方程式：CH₄ + H₂O →(高温) CO + 3H₂（淡入400ms）。
- 教师可随时点击"上一步"回退到任意步骤复习。

- 教师操作流程：
  1. 教师打开图示，展示步骤0完整示意图，提问学生反应前后有哪些分子。
  2. 点击"下一步"进入步骤1，引导学生观察三种原子的颜色对应关系。
  3. 点击"下一步"进入步骤2，让学生说出每个分子的化学式，验证虚线框内的原子组成。

  6. 可随时回退到步骤3，对比配平前后的原子数目变化。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：本场景以静态几何图形和分步显隐为主，无需复杂数据绑定或3D渲染，原生SVG足以高效实现球棍模型、表格和简单动画。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  800×500 画布
  ┌─────────────────────────────────────────────────────────────┐
  │  左框[反应前]          高温           右框[反应后]    图例   │
  │  ┌─────────┐         ───→          ┌─────────┐   ○氢原子  │
  │  │  甲  乙  │                       │  丙  丁  │   ●氧原子  │
  │  │ CH₄ H₂O │                       │ CO  H₂  │   ◎碳原子  │
  │  └─────────┘                       └─────────┘           │
  │  反应前                              反应后                │
  │                                                            │
  │       ┌─────────────────────────────────────┐              │
  │       │  原子种类 │ 反应前数目 │ 反应后数目  │              │
  │       │    C     │     1      │     1      │              │
  │       │    H     │     6      │   2  2≠6   │              │
  │       │    O     │     1      │     1      │              │
  │       └─────────────────────────────────────┘              │
  │              CH₄ + H₂O →(高温) CO + 3H₂                   │
  │                                                            │
  │         [◀上一步]      步骤 X/4      [下一步▶]             │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用变量currentStep（0~4），每一步定义showElements和hideElements数组，通过classList控制显隐。
  2. 斜线纹理：使用SVG <pattern>定义斜线填充，id="scene1-carbon-pattern"，patternUnits="userSpaceOnUse"，内画45°斜线。
  3. 步骤1闪烁动画：使用setInterval循环3次，每次给对应原子添加蓝色stroke，setTimeout移除。或纯CSS @keyframes定义flash动画，通过add/remove class触发。
  4. 步骤3表格滑入：CSS transition transform: translateY(180px) → translateY(0)，duration 400ms，ease-out。
  5. 步骤4数字变色：直接修改textContent和setAttribute('fill', '#2e7d32')。
  6. 虚线分子：使用stroke-dasharray="4,4"和fill="none"的circle，或半透明填充+虚线边框。
  7. 按钮状态：步骤0禁用上一步（disabled + opacity 0.4），步骤4禁用下一步。
  8. 所有动画元素初始状态为opacity:0或display:none，由JS在对应步骤控制。
- ID命名规范：
  - 左框：scene1-box-left
  - 右框：scene1-box-right
  - 甲分子组：scene1-mol-jia
  - 乙分子组：scene1-mol-yi
  - 丙分子组：scene1-mol-bing
  - 丁分子组：scene1-mol-ding
  - 图例组：scene1-legend
  - 表格：scene1-table
  - 方程式：scene1-equation
  - 按钮：scene1-btn-prev、scene1-btn-next
  - 步骤指示：scene1-step-indicator
  - 所有步骤相关元素添加data-step属性，便于批量控制
- IIFE隔离：所有JavaScript代码包裹在 (function() { ... })() 中，避免全局变量污染。
