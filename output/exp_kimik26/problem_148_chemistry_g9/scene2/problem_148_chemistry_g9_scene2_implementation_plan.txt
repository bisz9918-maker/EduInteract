[图示主题与整合说明]
- 本图示主题：基于配平方程式的选项逐一辨析（甲烷制水煤气反应）
- 整合的步骤/概念：①化合价变化分析 ②化合物与单质辨析 ③质量比计算 ④分子个数比确定 ⑤正误结论汇总
- 教学价值：教师通过分步导航，带领学生逐个验证四个选项，从定性判断（化合价、物质分类）到定量计算（质量比、分子个数比），最后汇总结论，形成完整的解题思维链。

[分步序列]
- 步骤0（初始状态）：显示配平方程式（顶部），四个选项卡片呈灰色未激活状态（虚线边框#888888），仅显示选项标题文字，无正误标记，无分析内容。教师可在此引导学生读题并写出配平方程式。
- 步骤1（辨析A）：点击"下一步"→ A卡片边框变为蓝色(#1565c0)实线，其余保持灰色。顶部方程式各物质上方出现化合价标注（C⁻⁴、H⁺¹、O⁻²等）。方程式下方出现红色弧线箭头连接C(-4)→C(+2)和H(+1)→H(0)，箭头下方标注变化说明。A卡片内部出现三行分析文本。A卡片右下角出现红色"×"。教师讲解：碳、氢化合价均发生变化，A错误。
- 步骤2（辨析B）：点击"下一步"→ A卡片恢复灰色，B卡片边框变蓝色。B卡片内部出现4行分类表格，CH₄和H₂O两行背景绿色高亮，右下角显示"共 2 种"。B卡片右下角出现红色"×"。教师讲解：含氢元素的化合物只有CH₄和H₂O两种，H₂是单质不是化合物，B错误。
- 步骤3（辨析C）：点击"下一步"→ B卡片恢复灰色，C卡片边框变蓝色。C卡片内部出现三行质量比计算式，逐步展示1×18:3×2=3:1的推导。C卡片右下角出现绿色"√"。教师讲解：乙(H₂O)相对分子质量18，丁(H₂)相对分子质量2且系数为3，质量比18:6=3:1，C正确。
- 步骤4（辨析D）：点击"下一步"→ C卡片恢复灰色，D卡片边框变蓝色。D卡片内部出现三行文本，直接从方程式系数读取分子个数比1:3。D卡片右下角出现绿色"√"。教师讲解：丙(CO)系数1，丁(H₂)系数3，分子个数比1:3，D正确。
- 步骤5（结论汇总）：点击"下一步"→ 四个卡片同时展示各自的正误标记（A×、B×、C√、D√）。C、D卡片边框变为绿色(#2e7d32)实线高亮。卡片区下方出现结论汇总文字"正确选项：C、D"（绿色加粗）。教师总结本题的解题要点。
（教师可随时点击"上一步"回退到任意步骤复习。）

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. "上一步"按钮：位于控件区左侧(x=280,y=455,w=80,h=32)，点击后回退一个步骤，到步骤0时禁用（透明度50%）。
  2. "下一步"按钮：位于控件区右侧(x=440,y=455,w=80,h=32)，点击后前进一个步骤，到步骤5时禁用（透明度50%）。
  3. 步骤指示器：位于两按钮之间偏下(x=375,y=495)，显示当前步骤编号"步骤 X/5"。
- 教师操作流程：
  1. 教师加载图示，处于步骤0，向学生展示题目和配平方程式。
  2. 点击"下一步"进入步骤1，讲解选项A的化合价变化分析。
  3. 依次点击"下一步"进入步骤2~4，分别讲解B、C、D四个选项。
  4. 点击"下一步"进入步骤5，展示最终结论。
  5. 讲解过程中可随时点击"上一步"回退，复习之前的分析过程。

[技术实现]
- JS库选择：原生 SVG + 原生 JavaScript。理由：本场景以静态图形、文本标签和状态切换为主，无复杂动画或数据可视化，原生SVG足以满足需求，无需引入外部库。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图：
  ```
  [800×500 画布]
  +--------------------------------------------------+
  |  顶部方程式区 (y=20~105)                          |
  |    CH₄ + H₂O  ==高温==  CO + 3H₂                 |
  |    (步骤1显示化合价标注和变化箭头)                  |
  +--------------------------------------------------+
  |  中部卡片区 (y=120~400)                           |
  |  +------------------+  +------------------+       |
  |  | 卡片A            |  | 卡片B            |       |
  |  | (选项A分析)      |  | (选项B分析)      |       |
  |  +------------------+  +------------------+       |
  |  +------------------+  +------------------+       |
  |  | 卡片C            |  | 卡片D            |       |
  |  | (选项C分析)      |  | (选项D分析)      |       |
  |  +------------------+  +------------------+       |
  +--------------------------------------------------+
  |  结论区 (y=405~430)                               |
  |         正确选项：C、D  (步骤5显示)                |
  +--------------------------------------------------+
  |  控件区 (y=445~490)                               |
  |    [上一步]   步骤 X/5   [下一步]                 |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：定义currentStep变量（0~5），共6个状态。每个状态对应一组元素的显示/隐藏、颜色、边框样式。render()函数根据currentStep统一更新所有视觉属性。
  2. 元素显隐控制：所有步骤专属元素（化合价标注、箭头、卡片内容、正误标记、结论汇总）初始状态为display:none或opacity:0。render()中通过setAttribute('display', 'none'/'block')或切换CSS类控制。步骤5之前的正误标记保持隐藏。
  3. 卡片边框切换：通过修改stroke和stroke-dasharray属性实现。未激活：stroke="#888888" stroke-dasharray="4,2"；激活（蓝）：stroke="#1565c0" stroke-dasharray="none"；正确高亮（绿，仅步骤5的C、D）：stroke="#2e7d32" stroke-dasharray="none" stroke-width="3"。
  4. 动画曲线：状态切换时使用CSS transition: opacity 0.25s ease-in-out，让内容淡入淡出，避免突兀。SVG元素可通过添加/移除CSS类实现。
  5. 事件绑定：上一步/下一步按钮绑定click事件。按钮在边界状态（步骤0的上一步、步骤5的下一步）添加disabled样式（opacity:0.4，cursor:not-allowed）。
  6. 化合价标注位置：使用绝对坐标定位，确保不遮挡方程式文本。变化箭头使用SVG <path>的Q二次贝塞尔曲线指令绘制弧线（如Q 400,115 520,82）。
  7. 表格实现：使用SVG <rect>做行背景，<text>做内容。列对齐通过固定x坐标实现：col1=440, col2=525, col3=610, col4=695。
- ID命名规范：所有交互元素ID必须以scene2-为前缀。
  - 卡片：scene2-card-a, scene2-card-b, scene2-card-c, scene2-card-d
  - 方程式：scene2-eq-ch4, scene2-eq-h2o, scene2-eq-co, scene2-eq-h2, scene2-eq-condition
  - 化合价：scene2-val-c-ch4, scene2-val-h-ch4, scene2-val-h-h2o, scene2-val-o-h2o, scene2-val-c-co, scene2-val-o-co, scene2-val-h-h2
  - 箭头：scene2-arrow-c, scene2-arrow-h, scene2-arrow-label-c, scene2-arrow-label-h
  - 卡片内容：scene2-content-a-1~3, scene2-table-b-header, scene2-table-b-row1~4, scene2-table-b-count, scene2-content-c-1~3, scene2-content-d-1~3
  - 标记：scene2-mark-a, scene2-mark-b, scene2-mark-c, scene2-mark-d
  - 结论：scene2-summary
  - 控件：scene2-btn-prev, scene2-btn-next, scene2-step-indicator
- IIFE隔离：所有JavaScript代码包裹在 (function() { ... })() 中，避免全局命名空间污染，确保多场景合并时互不干扰。
