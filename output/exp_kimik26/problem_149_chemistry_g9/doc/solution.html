problem_149_chemistry_g9

场景导航：Scene 1

完整题目原文

下图是某化学反应的微观模拟图，a、b、c分别表示三种质子数不同的原子，请回答：

（1）图乙中含有的粒子中属于反应生成的有_种粒子
（2）该反应属于_反应（填基本反应类型）
（3）写出一个和图中所示相符的化学反应方程式

题目分析

本题以微观模拟示意图为载体，综合考查化学反应的实质、质量守恒定律、反应类型判断及化学方程式书写。解题的核心在于：

  1. 准确识别反应前后各类粒子的种类与数量
  2. 判断哪些粒子实际参与了反应，哪些是反应后剩余的反应物
  3. 从微观角度理解"分子分裂为原子，原子重新组合成新分子"的反应实质
  4. 根据反应物和生成物的类别判断基本反应类型

整体讲解思路

建议采用"观察→分析→建模→结论"的递进路径：

  1. 先引导学生观察图甲（反应前）和图乙（反应后），识别三种原子的大小差异和分子的构成方式
  2. 通过对比甲乙两图，发现反应后仍有a₂分子存在，从而判断并非所有反应物都完全反应
  3. 借助"分子拆分—原子重组"的动画演示，帮助学生建立化学反应实质的微观模型
  4. 运用原子守恒原理，确认生成物的种类和数量
  5. 最后根据物质类别特征判断反应类型，并书写配平的化学方程式

图示规划说明

设计一个分步按钮导航式交互图示，将粒子识别、反应过程演示、生成物判断、反应类型分析、方程式书写整合在同一视觉主题下，通过7个递进步骤完成从题意理解到解答完毕的完整认知过程。

步骤0：观察反应前后的微观示意图

本图示的教学说明与讲解要点

步骤0-1：反应前粒子识别

引导学生首先观察原子图例，明确a、b、c是三种不同的原子（质子数不同即元素种类不同）。在图甲中，要求学生逐一识别分子种类：

  1. 由b和c两种原子构成的bc分子，共2个
  2. 由两个a原子构成的a₂分子，共4个

强调"分子由原子构成，不同原子以一定比例结合形成化合物分子，同种原子结合形成单质分子"。

步骤2：关键提问——所有粒子都参与反应了吗？

这是本题的第一个易错点。不要直接告诉学生答案，而是让学生对比图甲和图乙，数一数a₂分子的数量变化：

  • 图甲中有4个a₂分子
  • 图乙中仍有2个a₂分子

由此引导学生发现：只有2个a₂分子实际参与了反应，另外2个a₂分子是剩余的反应物。这一发现对正确回答问题（1）至关重要——避免将剩余的a₂误认为生成物。

步骤3-4：化学反应的微观实质

利用动画演示分子拆分和原子重组的过程，帮助学生建立核心概念：

  1. 化学反应中，分子可以再分，分裂成原子
  2. 原子是化学变化中的最小粒子，种类和数目在反应前后不变（质量守恒定律的微观解释）
  3. 原子重新组合，形成新的分子，从而产生新物质

此处可暂停动画，让学生手动"拖拽"原子进行重组，验证只有特定的组合方式才能形成稳定的a₂c分子和b单质。

步骤5-6：区分生成物与剩余物

图乙中存在三类粒子，必须用颜色明确区分：

  • 生成物（彩色高亮）：a₂c分子（新生成的化合物）、b原子（新生成的单质）
  • 剩余反应物（灰色淡化）：未参与反应的a₂分子

回答问题（1）时，反复强调"反应生成的"只包括a₂c和b，共2种粒子。剩余的a₂不是生成物，不要计入。

步骤7：置换反应的判断逻辑

引导学生从物质类别角度总结反应特征：

  1. 反应物：a₂是单质，bc是化合物
  2. 生成物：b是单质，a₂c是化合物
  3. 反应特征：单质 + 化合物 → 新单质 + 新化合物
  4. 结论：属于置换反应

可简要对比其他基本反应类型（化合反应"多变一"、分解反应"一变多"、复分解反应"双交换"），强化置换反应"一单一化→新一单新一化"的独特特征。

步骤8：从抽象模型到具体方程式

先展示抽象形式的配平方程式：

2bc + 2a₂ → 2a₂c + 2b

再建立颜色对应关系：a（蓝色）= H，b（绿色）= Cu，c（红色）= O，从而写出具体实例：

H₂ + CuO → H₂O + Cu（条件：加热）

强调方程式必须配平，且反应条件（加热）不可遗漏。也可鼓励学生思考其他合理的置换反应实例，但需满足图中1:1:2的原子比例关系。

完整解答与课堂总结

答案

  1. （1）2
  2. （2）置换
  3. （3）H₂ + CuO → H₂O + Cu（或 2H₂ + 2CuO → 2H₂O + 2Cu，条件：加热）

核心考点回顾

  1. 微观粒子识别：能够根据原子大小和连接方式判断分子种类（单质分子 vs 化合物分子）
  2. 反应物与剩余物：通过对比反应前后粒子数量，判断哪些反应物完全反应、哪些有剩余
  3. 化学反应实质：分子分裂为原子，原子重新组合成新分子，原子种类、数目、质量均不变
  4. 基本反应类型：掌握置换反应"单质 + 化合物 → 新单质 + 新化合物"的判断依据
  5. 化学方程式书写：能根据微观示意图写出配平的化学方程式，并标注反应条件

课堂讲解建议

  1. 先放后收：先让学生独立观察图甲和图乙2-3分钟，尝试自行统计粒子种类和数量，教师不要过早提示
  2. 制造认知冲突：故意提问"图乙中的a₂分子是生成物吗？"引发讨论，再通过图示验证
  3. 动手配平：在步骤8时，先让学生尝试配平"bc + a₂ → a₂c + b"，发现原子不守恒后，再调整为"2bc + 2a₂ → 2a₂c + 2b"，体会配平的意义
  4. 举一反三：课后让学生自己画一个化合反应的微观示意图，巩固对反应类型本质的理解
