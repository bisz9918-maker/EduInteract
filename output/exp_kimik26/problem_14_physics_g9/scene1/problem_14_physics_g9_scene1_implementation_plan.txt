[图示主题与整合说明]
- 本图示主题：水平滑轮组的机械效率综合分析
- 整合的步骤/概念：滑轮组装置认知 → 承担拉力绳子段数 n 的确定 → 摩擦力公式推导与计算 → 拉力功率推导与计算 → 有用功计算 → 匀速运动合力分析 → 四选项正误对比
- 教学价值：教师通过分步导航在同一装置图上逐层叠加分析元素，学生可清晰看到从识图到计算再到判断的完整逻辑链；回退功能便于教师根据课堂节奏重复讲解关键步骤。

- 步骤2「求摩擦力」：
  * 装置新增：摩擦力f箭头（红色，460,365→390,365），标签f=12N(425,385)
  * 推导区更新：显示公式推导 η=W_有/W_总=(f·s_物)/(F·s_绳)=f/(n·F)，代入f=0.8×3×5=12N（12N绿色高亮）
  * 选项表格显示单行：B | f=12N | ✓正确（绿底）

- 步骤3「求功率」：
  * 装置新增：v_绳箭头（蓝色，110,290→80,290），标签v_绳=3m/s(95,315)

  * 选项表格显示单行：C | P=15W | ✗错误（红底）

- 步骤4「求有用功」：
  * 装置无新增元素（摩擦力箭头已显示）
  * 推导区更新：W_有=f·s_物=f·v_物·t=12×1×10=120J（120J绿色高亮）；选项D错因提示：误用重力G算得500J（500J红色高亮）
  * 选项表格显示单行：D | W_有=120J | ✗错误（红底）

- 步骤5「合力分析」：

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  * 「◀ 上一步」按钮：位置(280,455)，90×30px，点击回退到前一步，步骤0时禁用（灰色）
  * 步骤指示器：位置(400,475)，显示当前步骤编号如"步骤 1 / 7"
  * 「下一步 ▶」按钮：位置(520,455)，90×30px，点击前进到下一步，步骤6时禁用（灰色）
- 教师操作流程：
  1. 教师打开图示，默认显示步骤0（题目条件），向学生介绍已知条件
  2. 点击「下一步」进入步骤1，观察3段绳子高亮，确定n=3
  3. 继续点击「下一步」依次展示摩擦力推导、功率推导、有用功推导、合力分析
  4. 每步右侧推导区同步更新公式，装置图叠加新的力/速度箭头
  5. 可随时点击「上一步」回退复习，如学生不理解功率计算，可回退到步骤3重新讲解
  6. 最后一步显示完整选项对比表格，完成整题讲解

[技术实现]
- JS库选择：原生 SVG + 原生 JavaScript。原因：本场景以静态几何图形、线段、箭头、文本为主，无复杂函数曲线或3D，原生SVG足够且轻量；状态切换通过显示/隐藏元素实现，无需D3/React。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------------+
  |  [装置区 0~480px]              [推导区 500~780px]      |
  |                                +--------------------+  |
  |  η=80%                         | 公式推导文本框     |  |
  |                                | （步骤动态更新）   |  |
  |    ○---===---○  [A]            |                    |  |
  |   定滑轮   动滑轮  物体A        +--------------------+  |
  |  F←  v_物→  f←  3F→            +--------------------+  |
  |                                | 选项表格（步骤6）  |  |
  |                                +--------------------+  |
  |                                                        |
  |  [地面+墙面]                                           |
  +--------------------------------------------------------+
  |         [◀ 上一步]  步骤 X/7  [下一步 ▶]               |
  +--------------------------------------------------------+
  画布 800×500，控件栏在底部 y=440~490（绝对定位叠在SVG上）
  ```

- 关键实现要点：
  1. 状态机设计：用变量 `currentStep`（0~6）记录当前步骤，每次点击按钮时更新状态并调用 `renderStep()`。
  2. 元素显隐控制：所有动态元素（箭头、标签、推导文本、表格）初始 `display:none` 或 `visibility:hidden`，`renderStep()` 根据 `currentStep` 设置对应元素的显隐。
  3. 步骤1绳子闪烁动画：使用 JS `setInterval` 控制3段绳子的 `opacity` 在300ms周期内0.3↔1.0切换，循环3次后清除interval并设为opacity=1。也可用CSS `@keyframes` 定义 `blink` 动画，播放3次后移除class。
  4. 推导区文本更新：每步预先定义好文本内容数组 `derivationTexts[step]`，切换步骤时清空推导区并插入对应文本节点，关键数字用 `<tspan>` 或 `<span>` 包裹设置颜色。
  5. 表格动态生成：步骤2-5生成单行表格，步骤6生成完整四行表格，用JS动态创建/替换DOM节点。
  6. 按钮禁用逻辑：`currentStep===0` 时禁用「上一步」，`currentStep===6` 时禁用「下一步」，通过添加/移除 `disabled` class 改变样式。
  7. 坐标计算：所有箭头用 `<line>` + `<polygon>`（箭头尖端）组合，方向通过坐标差计算；力箭头长度与标注数值成正比（示意性质，非严格比例）。

- ID命名规范：所有交互元素ID必须以 `scene1-` 为前缀。
  * 装置元素：`scene1-pulley-fixed`、`scene1-pulley-movable`、`scene1-object-a`、`scene1-rope-up`、`scene1-rope-mid`、`scene1-rope-down`、`scene1-arrow-f`、`scene1-arrow-f-friction`、`scene1-arrow-3f`、`scene1-arrow-v-object`、`scene1-arrow-v-rope`
  * 标签：`scene1-label-eta`、`scene1-label-n`、`scene1-label-f`、`scene1-label-friction`、`scene1-label-3f`、`scene1-label-v-object`、`scene1-label-g`、`scene1-label-a`、`scene1-label-v-rope`
  * 推导区：`scene1-derivation-box`、`scene1-derivation-text`
  * 表格：`scene1-option-table`
  * 按钮：`scene1-btn-prev`、`scene1-btn-next`、`scene1-step-indicator`

- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免全局变量污染，确保多场景合并时互不干扰。
