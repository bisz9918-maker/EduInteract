[图示主题与整合说明]
- 本图示主题：CO 与 H₂ 还原 Fe₂O₃ 的反应原理及产物对比
- 整合的步骤/概念：
  1. 图甲加热还原装置的结构认知（铁架台、水平玻璃管、氧化铁、酒精灯、导管）；
  2. CO 还原 Fe₂O₃ 的反应路径与化学方程式；
  3. H₂ 还原 Fe₂O₃ 的反应路径与化学方程式；
  4. 等体积条件下两种还原剂的计量数对比，为后续实验设计铺垫。
- 教学价值：教师可通过分步导航，先让学生熟悉实验装置，再分别展示两种气体的还原过程，最后并列对比化学计量关系，形成从宏观装置→微观反应→定量对比的完整认知链。

[分步序列]
- 初始状态（步骤0）：显示图甲装置全貌（铁架台、玻璃管、橡胶塞、导管、氧化铁、酒精灯、火焰），显示标签"图甲""氧化铁""酒精灯"。右侧方程式区仅显示背景框，无内容。装置处于静态认知状态。
- 步骤1：点击「下一步」→ 
  1) 左侧出现蓝色 CO 进气箭头（从左导管指向玻璃管）和蓝色 CO₂ 出气箭头（从玻璃管指向右导管）；
  2) 显示标签"CO"（左导管上方）、"CO₂"（右导管上方）、"Fe"（氧化铁下方，绿色）、"高温"（火焰右侧）；
  3) 氧化铁颜色可略微变暗示意反应；
  4) 右侧显示 CO 方程式标题（蓝色）、方程式文本（"Fe₂O₃ + 3CO → 2Fe + 3CO₂"，其中"3CO"和"3CO₂"蓝色加粗）、高温标注、说明文字。
- 步骤2：点击「下一步」→ 
  1) 隐藏步骤1的 CO 箭头、CO/CO₂ 标签、CO 方程式；
  2) 左侧出现红色 H₂ 进气箭头和红色 H₂O 出气箭头；
  3) 显示标签"H₂"（左导管上方）、"H₂O"（右导管上方），保留"Fe"和"高温"；
  4) 右侧显示 H₂ 方程式标题（红色）、方程式文本（"Fe₂O₃ + 3H₂ → 2Fe + 3H₂O"，其中"3H₂"和"3H₂O"红色加粗）、高温标注、说明文字。
- 步骤3（最终步骤）：点击「下一步」→ 
  1) 保留装置图和"Fe""高温"标签，隐藏所有气体箭头与气体标签；
  2) 右侧并列显示 CO 方程式（上方，蓝色高亮计量数）和 H₂ 方程式（下方，红色高亮计量数），中间以虚线分隔；
  3) 在计量数"3CO"和"3H₂"背后分别显示蓝色/红色半透明高亮框；
  4) 下方显示对比结论：标题"计量关系对比"、内容"还原 1 mol Fe₂O₃ 均需 3 mol 还原剂"、"等体积混合时，CO 与 H₂ 还原能力相同"、绿色加粗结论"为后续实验设计提供理论依据"。
（教师可随时点击「上一步」回退复习，步骤切换有过渡动画。）

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「◀ 上一步」按钮：位于 SVG 内底部 (290,448)，宽 80×30，点击后回退到上一状态；
  2. 「下一步 ▶」按钮：位于 SVG 内底部 (430,448)，宽 80×30，点击后前进到下一状态；
  3. 步骤指示器：4 个圆点位于 (360~420, 488)，当前步骤圆点填充 #1565c0，其余填充 #cccccc。
- 教师操作流程：
  1. 教师打开图示，学生观察步骤0的装置结构，教师可指着各部件讲解；
  2. 点击「下一步」进入步骤1，教师讲解 CO 还原过程，观察蓝色气体流向和方程式；
  3. 点击「下一步」进入步骤2，教师讲解 H₂ 还原过程，对比红色路径与 CO 路径的异同；
  4. 点击「下一步」进入步骤3，教师引导学生关注计量数"3"的对比，得出等体积还原能力相同的结论，为原题第(2)问的实验装置选择做铺垫；
  5. 讲解中可随时回退到任意步骤复习。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript。理由：本场景以静态几何装置、文本标签和简单箭头为主，无需复杂数据绑定或 3D 渲染，原生 SVG 足以保证清晰度且加载轻量。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +----------------------------------------------------------+
  |                                                          |
  |   [氧化铁]                    +----------------------+   |
  |      ↓ Fe                     |  CO/H₂ 方程式        |   |
  |  =============   图甲         |  （步骤1/2/3切换）    |   |
  | (玻璃管)                      |                      |   |
  |   [酒精灯]🔥 高温             |  对比结论            |   |
  |                              |                      |   |
  |  CO →        → CO₂          +----------------------+   |
  |                                                          |
  |         [◀ 上一步]    [下一步 ▶]                        |
  |            ●  ○  ○  ○                                    |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：定义全局变量 `currentStep`（0~3），每次点击按钮时更新状态，调用 `renderStep()` 函数根据状态显隐元素。
  2. 元素显隐：所有步骤相关元素设置 `opacity` 和 `pointer-events` 过渡，transition 时长 250ms，使用 CSS class 切换（如 `.scene1-hidden { opacity: 0; pointer-events: none; }`）。
  3. 箭头流动动画：气体箭头使用 `stroke-dasharray: 8,4` 配合 CSS `@keyframes flow { to { stroke-dashoffset: -12; } }` 实现持续流动感，仅在对应步骤激活。
  4. 方程式下标：直接使用 Unicode 下标字符（₂、₃）避免复杂 tspan 偏移计算，确保跨浏览器一致性。
  5. 计量数高亮框：使用绝对定位的 rect 元素置于 text 下方，通过 `opacity` 控制显隐，步骤3时从 scale(0.9) 放大到 scale(1) 增强视觉焦点。
  6. 按钮状态：步骤0 时「上一步」置灰（opacity=0.4，pointer-events=none），步骤3 时「下一步」置灰或变为「完成」。
  7. 事件绑定：按钮绑定 `click` 事件，直接操作 `currentStep` 并触发渲染，避免复杂事件委托。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀。例如：
  - 装置组：`scene1-apparatus`
  - 玻璃管：`scene1-tube`
  - 氧化铁：`scene1-fe2o3`
  - 酒精灯：`scene1-lamp`
  - 火焰：`scene1-flame`
  - CO 进气箭头组：`scene1-co-in-arrow`
  - CO₂ 出气箭头组：`scene1-co2-out-arrow`
  - H₂ 进气箭头组：`scene1-h2-in-arrow`
  - H₂O 出气箭头组：`scene1-h2o-out-arrow`
  - CO 方程式组：`scene1-eq-co`
  - H₂ 方程式组：`scene1-eq-h2`
  - 对比组：`scene1-compare`
  - 上一步按钮：`scene1-btn-prev`
  - 下一步按钮：`scene1-btn-next`
  - 步骤指示器容器：`scene1-step-dots`
  JS 中严格使用 `document.getElementById` 获取元素，禁止全局 class 查询，防止多场景合并时跨场景污染。
- IIFE 隔离：所有 JavaScript 代码包裹在 `(function() { ... })();` 中，变量不污染全局作用域。
