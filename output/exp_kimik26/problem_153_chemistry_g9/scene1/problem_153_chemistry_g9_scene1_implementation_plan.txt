[图示主题与整合说明]
- 本图示主题：混合气体依次通过净化装置的流程与成分变化
- 整合的步骤/概念：装置A/B/C/D的试剂识别、四步化学反应原理、每步气体成分动态更新、最终选项判定

[分步序列]
- 步骤0（初始状态）：
  - 显示完整装置流程图 A→B→C→D，所有试剂标签、导管、箭头可见
  - 左侧显示全部6种气体：H₂、N₂、HCl、H₂O、CO、CO₂，均为白底黑字
  - 中区方程式显示："混合气体依次通过 A→B→C→D 装置"
  - 中区三列面板：进入=H₂、N₂、HCl、H₂O、CO、CO₂；除去=（空）；剩余=H₂、N₂、HCl、H₂O、CO、CO₂
  - 下区选项面板隐藏
  - 步骤指示："0/5"

- 步骤1（通过装置A）：
  - 装置A边框高亮：线宽4px，颜色#1565c0
  - 方程式更新："NaHCO₃ + HCl = NaCl + H₂O + CO₂↑"
  - 三列面板：进入=H₂、N₂、HCl、H₂O、CO、CO₂；除去=HCl（红底#ffcdd2）；剩余=H₂、N₂、H₂O、CO、CO₂（CO₂标注"生成↑"蓝底#bbdefb）
  - 左侧更新：HCl标签变红（或添加删除线），CO₂标签变蓝提示生成
  - 步骤指示："1/5"

- 步骤2（通过装置B）：
  - 装置B边框高亮（A恢复普通线宽）
  - 方程式更新："H₂ + CuO ≜ Cu + H₂O" 与 "CO + CuO ≜ Cu + CO₂"（两行显示，行距18px，整体居中）
  - 三列面板：进入=H₂、N₂、H₂O、CO、CO₂；除去=H₂、CO（红底）；剩余=N₂、H₂O、CO₂（H₂O和CO₂标注"生成"蓝底）
  - 左侧更新：仅保留 N₂（白底）、H₂O（蓝底生成）、CO₂（蓝底生成）；H₂和CO变红移除
  - 步骤指示："2/5"

- 步骤3（通过装置C）：
  - 装置C边框高亮
  - 方程式更新："CO₂ + Ca(OH)₂ = CaCO₃↓ + H₂O"
  - 三列面板：进入=N₂、H₂O、CO₂；除去=CO₂（红底）；剩余=N₂、H₂O
  - 左侧更新：N₂、H₂O（CO₂变红移除）
  - 步骤指示："3/5"

- 步骤4（通过装置D）：
  - 装置D边框高亮
  - 方程式更新："浓 H₂SO₄ 吸收水蒸气"
  - 三列面板：进入=N₂、H₂O；除去=H₂O（红底）；剩余=N₂（绿底#c8e6c9）
  - 左侧更新：仅保留 N₂（绿底高亮）
  - 步骤指示："4/5"

- 步骤5（得出结论）：
  - 所有装置恢复普通线宽，无高亮
  - 方程式更新："最终剩余气体：N₂"
  - 三列面板显示最终结论：进入=（空）；除去=（空）；剩余=N₂（绿底）
  - 下区选项面板显示：
    - A. HCl、CO、H₂、CO₂、H₂O、N₂ → 绿底#c8e6c9，标注"✓ 正确"
    - B. CO₂、CO、H₂、HCl、H₂O、N₂ → 白底
    - C. HCl、CO、H₂、H₂O、CO₂、N₂ → 红底#ffcdd2，右侧标注"错：C、D作用颠倒"
    - D. H₂、CO、CO₂、HCl、N₂、H₂O → 白底
  - 步骤指示："5/5"

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「◀ 上一步」按钮：位置(280,455)，宽120px高35px，点击后 currentStep 减1，调用 updateScene() 回退到上一步视觉状态。
  2. 「下一步 ▶」按钮：位置(420,455)，宽120px高35px，点击后 currentStep 加1，调用 updateScene() 推进到下一步视觉状态。
  3. 步骤指示文本：位置(400,445)，显示"步骤 X/5"，随按钮点击同步更新。
- 边界处理：currentStep=0 时「上一步」按钮置灰禁用；currentStep=5 时「下一步」按钮置灰禁用（或变为「重新开始」）。
- 教师操作流程：
  1. 教师展示步骤0，让学生观察初始装置与混合气体成分。
  2. 点击「下一步」进入步骤1，讲解A装置除去HCl并生成CO₂的原理，观察左侧与三列面板变化。
  3. 继续点击「下一步」依次讲解B、C、D装置，每步观察气体成分如何被除去或生成。
  4. 到达步骤5，展示四个选项，高亮正确答案A，并点明C选项的错误原因（C、D装置作用颠倒）。
  5. 可随时点击「上一步」回退到任意步骤复习。

[技术实现]
- JS库选择：原生 SVG + 原生 JavaScript。原因：装置图为固定几何图形（矩形、路径、线段、多边形），无需复杂数学计算或3D渲染，原生SVG足够轻量且清晰；状态切换通过JS操作DOM属性即可。
- 画布尺寸：800×500 px（沿用规定）。
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------------+
  |  当前气体成分   A[碳酸氢钠] → B[氧化铜] → C[澄清石灰水] → D[浓硫酸] |
  |  H₂            (175,70)   (285,95)   (465,70)   (575,70) |
  |  N₂                 |          |          |          |  |
  |  HCl                |  酒精灯  |          |          |  |
  |  H₂O                |   🔥     |          |          |  |
  |  CO                 |          |          |          |  |
  |  CO₂                |          |          |          |  |
  |  +--------------------------------------------------+  |
  |  |         化学方程式面板 (居中 y=215)               |  |
  |  +--------------------------------------------------+  |
  |  |  进入气体    →    除去气体    →    剩余气体       |  |
  |  |  (180,245)       (380,245)        (580,245)       |  |
  |  +--------------------------------------------------+  |
  |  [选项面板，仅步骤5显示，y=375~435]                     |
  |                                                        |
  |              [◀ 上一步]  步骤 X/5  [下一步 ▶]          |
  |              (280,455)   (400,445)  (420,455)          |
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `let currentStep = 0;` 记录当前步骤（0~5）。`updateScene(step)` 函数作为唯一状态更新入口，根据 step 值批量设置各元素的 `display`、`stroke-width`、`stroke`、`fill`、`textContent`。
  2. 装置高亮：给每个装置容器组（g元素）设置ID如 `scene1-device-a`。高亮时将该组的矩形/路径 stroke 设为 #1565c0，stroke-width 设为4px；非高亮步骤恢复为 #000000 和 2px。
  3. 气体标签颜色：左侧6个气体标签使用 `rect`+`text` 组合，ID如 `scene1-gas-h2`。通过修改 rect 的 fill 属性实现白底/红底/绿底/蓝底切换。
  4. 方程式与三列面板：方程式文本元素ID `scene1-equation`，直接修改 textContent。三列列表使用6个文本元素（每列2行，足够显示所有气体），通过换行符或独立tspan实现多行。
  5. 选项面板：默认 `display: none`，步骤5时设为 `display: block`。正确选项A的 rect 背景设为 #c8e6c9，错误选项C的 rect 背景设为 #ffcdd2，并显示错误原因文本。
  6. 动画曲线：无需复杂动画，状态切换为即时切换（0ms），保证教师课堂控制的即时响应。如需柔和过渡，可对 fill 和 stroke 添加 CSS transition: all 0.2s ease。
  7. 事件绑定：按钮绑定 `onclick`，上一步执行 `if(currentStep>0){currentStep--; updateScene(currentStep);}`，下一步执行 `if(currentStep<5){currentStep++; updateScene(currentStep);}`。
- ID命名规范：所有交互元素ID必须以 `scene1-` 为前缀。例如：
  - 装置A：`scene1-device-a`
  - 装置B玻璃管：`scene1-device-b-tube`
  - 气体HCl标签：`scene1-gas-hcl`
  - 方程式文本：`scene1-equation`
  - 进入列表：`scene1-panel-in`
  - 除去列表：`scene1-panel-out`
  - 剩余列表：`scene1-panel-left`
  - 选项A：`scene1-option-a`
  - 上一步按钮：`scene1-btn-prev`
  - 下一步按钮：`scene1-btn-next`
  - JS中严格使用 `document.getElementById('scene1-xxx')` 获取元素，禁止 querySelectorAll 配合全局class，避免多场景合并时跨场景污染。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，变量不污染全局作用域。
