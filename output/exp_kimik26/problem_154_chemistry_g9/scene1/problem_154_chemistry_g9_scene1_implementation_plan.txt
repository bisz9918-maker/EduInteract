[图示主题与整合说明]
- 本图示主题：初中化学物质转化关系分步推断与验证（酸碱盐综合推断题）
- 整合的步骤/概念：
  1. 从题干特征描述（最常见酸、人体最多物质、蓝色不溶物）确定突破口；
  2. 推断 B=HCl、D=H₂O、G=Cu(OH)₂；
  3. 通过反应①（A+B→E+D）推断 A 为碱（NaOH）、E 为盐（NaCl）；
  4. 通过反应②（B+C→D+F）推断 C 为 CuO、F 为 CuCl₂；
  5. 通过反应③（F+A→E+G）验证复分解反应；
  6. 汇总三问答案。
- 教学价值：教师可控制课堂节奏，每步聚焦单一推断环节，学生跟随框图高亮和右侧面板说明，建立"已知→未知"的逻辑链条；框图与方程式同步呈现，强化宏观物质转化与微观方程式的关联。

[分步序列]
步骤 0 — 题意感知（初始状态）：
- 显示完整框图，8 个框均显示字母（A、B、C、E、D、F、E、G）。
- 连线全部显示为黑色 1.5px。
- B、D、G 框右侧分别悬浮小标签："最常见酸"、"人体最多物质"、"蓝色不溶物"（虚线框，#888888）。
- 右侧面板标题："推断提示"，内容："从特征描述找突破口" + 三条题干原文。
- 按钮可用：下一步；上一步禁用。

步骤 1 — 确定突破口：
- B 框蓝高亮，框内文字变为 "HCl"；D 框蓝高亮，文字变为 "H₂O"；G 框蓝高亮，文字变为 "Cu(OH)₂"。
- B、D、G 右侧悬浮标签消失。
- 右侧面板标题："突破口确定"，内容列出三条推断依据：
  ① 最常见酸 → HCl；② 人体最多物质 → H₂O；③ 蓝色不溶物 → Cu(OH)₂。

步骤 2 — 分析反应①（A+B→E+D）：
- A→①、B→①、①→E1、①→D 四条连线红高亮（3px #c62828）。
- 反应编号 "①" 红底高亮。
- A 框绿高亮，文字变为 "碱\nNaOH"（两行）；E1 框绿高亮，文字变为 "NaCl"。
- B、D 保持蓝高亮。
- 右侧面板：标题"反应①分析"，展示方程式 "NaOH + HCl → NaCl + H₂O"，说明 "酸 + 碱 → 盐 + 水"。

步骤 3 — 分析反应②（B+C→D+F）：
- 反应①连线恢复黑色 1.5px，"①" 恢复默认。
- B→②、C→②、②→D、②→F 四条连线红高亮。
- 反应编号 "②" 红底高亮。
- C 框绿高亮，文字变为 "CuO"；F 框绿高亮，文字变为 "CuCl₂"。
- B、D 保持蓝高亮；A、E1 保持绿高亮。
- 右侧面板：标题"反应②分析"，展示方程式 "CuO + 2HCl → CuCl₂ + H₂O"，说明 "金属氧化物 + 酸 → 盐 + 水"。

步骤 4 — 验证反应③（F+A→E+G）：
- 反应②连线恢复黑色 1.5px，"②" 恢复默认。
- A→③（顶部绕行）、F→③（底部绕行）、③→E2、③→G 四条连线红高亮；反应③竖线本身 3px #c62828。
- 反应编号 "③" 红底高亮。
- E2 框绿高亮，文字变为 "NaCl"；A、F 保持绿高亮；G 保持蓝高亮。
- 右侧面板：标题"反应③验证"，展示方程式 "CuCl₂ + 2NaOH → Cu(OH)₂↓ + 2NaCl"，说明 "两种化合物互相交换成分，生成另外两种化合物 → 复分解反应"。

步骤 5 — 答案汇总：
- 所有连线恢复黑色 1.5px，所有反应编号恢复默认。
- 所有框保持高亮状态（蓝/绿），显示最终化学式：A="NaOH"、B="HCl"、C="CuO"、D="H₂O"、E1="NaCl"、F="CuCl₂"、E2="NaCl"、G="Cu(OH)₂"。
- 右侧面板：标题"答案汇总"，列表形式：
  （1）C 物质的化学式为 CuO；
  （2）反应③的基本类型是 复分解反应；
  （3）A 物质所属类别为 碱。
  正确答案使用 #2e7d32 粗体。
- 下一步按钮变为"重新开始"或循环回步骤 0。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  • 「◀ 上一步」按钮：位于 (300, 455)，宽 80，高 32；点击回退到上一步骤，步骤 0 时禁用（opacity 0.4）。
  • 「下一步 ▶」按钮：位于 (420, 455)，宽 80，高 32；点击前进到下一步，步骤 5 时文字变为「重新开始」，点击回到步骤 0。
  • 步骤指示器：位于 (400, 445)，显示 "步骤 X / 6"，12px #666666。
- 教师操作流程：
  1. 教师打开图示，学生观察步骤 0 的原始框图和题干特征提示；
  2. 教师点击「下一步」进入步骤 1，引导学生从特征描述确定 B、D、G；
  3. 依次点击「下一步」，每步聚焦一个反应，观察框图高亮和右侧面板方程式；
  4. 到达步骤 5 后，教师可点击「重新开始」回顾完整推导链，或点击「上一步」回退到任意环节进行追问。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无外部库）。原因：本场景为静态框图与简单状态切换，SVG path/rect/text 足以描述所有几何与文本，无需 D3/Canvas；化学方程式使用 Unicode 下标（如 H₂O）即可满足初中化学显示需求。
- 画布尺寸：800 × 500 px（SVG viewBox="0 0 800 500"）。
- 布局草图（ASCII）：
  ```
  0    100   200   300   400   500   600   700   800
  +-----+-----+-----+-----+-----+-----+-----+-----+ 0
  | [A]       [E]       [E] |  推断说明面板      |
  |   \①    /   \③    /   |  ┌─────────────┐   |
  |    \  /      \  /      |  │ 标题        │   |
  | [B]---[D]      [G]      |  │ 依据/方程式 │   |
  |    /② \                |  │ ...         │   |
  | [C]     [F]             |  └─────────────┘   |
  |                         |                    |
  +-------------------------+--------------------+ 430
  |        [◀上一步] [下一步▶]                     | 500
  ```
- 关键实现要点：
  1. 状态机：用变量 `currentStep`（0~5），`updateScene(step)` 函数统一渲染。所有视觉变化（颜色、文字、显隐）通过修改 SVG 元素的 attribute 和 textContent 完成，避免重绘整个 SVG。
  2. 元素预创建：所有框、线、标签在初始化时全部创建并设置默认样式；步骤切换时仅修改 class 或 style，保证性能与过渡平滑。
  3. 高亮实现：使用 CSS class（如 .highlight-blue、.highlight-green、.highlight-red）控制 stroke、fill、font-weight；连线高亮通过切换 stroke-width 和 stroke 颜色实现。
  4. 化学式换行：A 框在步骤 2 显示 "碱\nNaOH"，使用 SVG `<tspan>` x="0" dy="1.2em" 实现第二行。
  5. 箭头 marker：在 `<defs>` 中定义 arrow-black（默认）和 arrow-red（高亮），步骤切换时修改 path 的 marker-end 属性。
  6. 右侧面板内容：使用 foreignObject 嵌入 HTML div，或直接用 SVG text/tspan 组；推荐 foreignObject 以便使用 HTML 的 `<ul>`、`<b>` 等语义标签，简化多行文本排版。
  7. 按钮事件：上一步/下一步绑定 click，更新 currentStep 后调用 updateScene；步骤 0 和步骤 5 时分别禁用/改变按钮文字。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀，例如：
  • `scene1-box-a`、`scene1-box-b`、...、`scene1-box-g`
  • `scene1-line-a-to-r1`、`scene1-line-r1-to-e1`
  • `scene1-panel-title`、`scene1-panel-content`
  • `scene1-btn-prev`、`scene1-btn-next`
  JS 中严格使用 `document.getElementById` 获取元素，禁止 querySelectorAll 配合全局 class。
- IIFE 隔离：所有 JavaScript 包在 `(function() { ... })()` 中，避免多场景合并时变量污染。
