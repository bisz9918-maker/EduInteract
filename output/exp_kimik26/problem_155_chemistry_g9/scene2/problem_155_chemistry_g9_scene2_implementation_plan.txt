[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本场景以静态几何图形和状态切换为主，无复杂动画或数据可视化，原生SVG足以满足需求，无需引入额外库。
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  左侧装置区(30~330)        右侧选项区(340~780)    |
  |  反应方程式(y=278~318)     卡片A(y=65~150)       |
  |  容器1+容器2(y=135~215)    卡片B(y=160~245)      |
  |  温度标注(y=245~252)       卡片C(y=255~340)      |
  |  固体颗粒(y=195~212)       卡片D(y=350~435)      |
  |                                                   |
  |              [◀ 上一步]  [下一步 ▶]              |
  |              (300,450)   (460,450)               |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `currentStep`（0~4），每次点击按钮时更新状态，调用 `renderStep()` 统一渲染。
  2. 渲染策略：`renderStep()` 根据 currentStep 值：
     - 设置四个选项卡片的边框颜色、opacity、正误标记和理由文本的 display 属性
     - 显示/隐藏左侧装置的高亮元素（虚线箭头、容器高亮框、温度虚线等）
     - 更新按钮禁用状态和步骤指示文字
  3. 坐标计算：所有元素使用绝对像素坐标，不依赖动态计算，确保代码agent可直接复用。
  4. 动画曲线：本场景以状态切换为主，无需复杂动画。卡片和高亮元素的显示/隐藏使用直接切换（或可选0.2s CSS transition）。
  5. 事件绑定：按钮绑定 click 事件，更新 currentStep 后调用 renderStep。
  6. 文本换行：选项文本和理由文本使用 SVG foreignObject 内嵌 div，利用 CSS 自动换行，避免手动计算 tspan。
  7. 固体颗粒：容器1和容器2内的固体颗粒使用静态 circle 数组，坐标预先定义，无需动态生成。
- ID命名规范：
  - 装置元素：`scene2-reactor-1`, `scene2-reactor-2`, `scene2-pipe-inlet`, `scene2-pipe-outlet`, `scene2-pipe-connect`
  - 标签：`scene2-label-y-in`, `scene2-label-y-out`, `scene2-label-t1`, `scene2-label-t2`, `scene2-label-900c`, `scene2-label-600c`
  - 选项卡片：`scene2-card-a`, `scene2-card-b`, `scene2-card-c`, `scene2-card-d`
  - 卡片内部：`scene2-mark-a`, `scene2-reason-a` 等
  - 高亮元素：`scene2-highlight-path`, `scene2-highlight-reactor2`, `scene2-highlight-outlet`, `scene2-highlight-temp-line1`
  - 按钮：`scene2-btn-prev`, `scene2-btn-next`, `scene2-step-indicator`
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })()` 中，避免全局污染。
