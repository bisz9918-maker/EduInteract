题目分析：本题通过微观示意图考查化学反应的基本类型及特征。学生需要从微观角度识别反应物和生成物的分子构成，区分参与反应和未参与反应的分子，进而判断反应类型并分析各选项正误。

整体讲解思路：

  1. 首先引导学生观察反应前后的微观示意图，识别反应前后的分子种类和数量。
  2. 关键步骤是区分"反应前存在的分子"和"实际参与反应的分子"——反应后仍有2个由两个白圈构成的分子未变化，说明它们没有参与反应。
  3. 根据参与反应的分子种类和生成物种类，判断反应类型为化合反应（多变一）。
  4. 逐一分析四个选项，重点纠正学生容易混淆的"反应前分子总数"与"参加反应的分子数"的区别。

步骤 0/6

本图示的教学说明：教师应首先引导学生观察反应前后的微观示意图，重点区分"反应前存在的分子总数"与"实际参加反应的分子数"。这是学生最容易出错的地方——图中反应前有4个白分子，但反应后仍有2个白分子未变化，说明只有2个白分子参加了反应。

讲解要点：

  1. 让学生先独立数出反应前后的分子种类和数量，建立直观印象。
  2. 通过高亮对比，明确参与反应的是2个A₂分子和1个B₂分子，未参与反应的是2个A₂分子。
  3. 引导学生写出简化方程式：2A₂ + B₂ → 2A₂B，从而判断属于化合反应（多变一）。
  4. 分析选项D时，强调"参加反应"四字的关键性，纠正学生将"反应前总数"误认为"参加反应数"的错误。

关键结论：

  • 反应类型：化合反应（两种物质生成一种物质）
  • 参加反应的分子个数比：n(A₂) : n(B₂) = 2 : 1
  • 生成物为化合物，反应前后分子种类发生改变

课堂讲解建议：在步骤1停留时间稍长，确保学生理解"未参与反应的分子"概念；在步骤6可让学生先猜测比值，再通过图示验证，增强互动性。
