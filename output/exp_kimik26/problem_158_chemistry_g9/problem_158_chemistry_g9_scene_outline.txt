    ① CaCO₃ ↔ CaO → Ca(OH)₂
    ② Fe ↔ Fe₂O₃ → FeSO₄

    A．①②　B．①③　C．②③　D．①②③

    **题目分析：**
    本题考查初中化学物质之间的转化关系，核心判断标准是"每一步转化是否均能在一定条件下一步实现"。三组转化分别涉及钙的化合物、铁及其化合物、水与氧气及氧化镁的转化。解题关键在于准确回忆各物质的主要化学性质，尤其要注意反应前后元素化合价是否变化、反应类型是否允许直接得到目标产物。

    **整体讲解思路：**
    1. 先让学生整体观察三个"物质三角"，明确每组涉及三种物质及转化方向。
    2. 按组别逐步分析，对每一步转化写出（或口述）反应方程式，判断是否能一步完成。
    3. 重点突破②组中 Fe₂O₃ → FeSO₄ 的陷阱：复分解反应中化合价不变，+3价铁无法直接变为+2价。
    4. 注意③组中 MgO → H₂O 的易错点：金属氧化物与酸反应可生成水，不要局限于分解反应。
    5. 综合判断，确定正确选项。

    本图示采用"总览→聚焦→结论"的递进结构，建议教师按以下方式引导学生：

    1. **步骤0（总览）**：让学生先观察三个三角图，识别每组涉及的物质，回忆这些物质所属的化合物类别（如CaCO₃是盐、CaO是碱性氧化物、Ca(OH)₂是碱）。此时不急于判断，只建立框架。

    2. **步骤1（①组分析）**：重点引导学生回忆碳酸钙的高温分解（工业制生石灰）、生石灰的熟化、以及氢氧化钙与二氧化碳的反应。三个反应都是初中化学核心反应，可让学生口头默写方程式：
       - CaCO₃ → CaO + CO₂↑（高温）
       - CaO + H₂O → Ca(OH)₂
       - Ca(OH)₂ + CO₂ → CaCO₃↓ + H₂O
       确认三个方向均可一步实现后，在①组下方标注绿色结论。

    3. **步骤2（②组分析）**：这是本题的陷阱和难点。先让学生思考Fe₂O₃如何变成FeSO₄。多数学生会直接写"加稀硫酸"，此时教师应追问："氧化铁与稀硫酸反应的产物是什么？"引导学生注意到Fe₂O₃中铁为+3价，与酸反应发生的是复分解反应（非氧化还原），价态不变，生成的是Fe₂(SO₄)₃而非FeSO₄。要得到Fe²⁺，必须额外加入还原剂（如铁粉），这就不是"一步"了。此处要充分利用图示中的红色叉号和说明弹框，强化学生的错误认知纠正。

    4. **步骤3（③组分析）**：前两个转化较简单，学生容易判断。MgO→H₂O是易错点，学生可能认为MgO不溶于水且不与水反应生成水，就判断不能实现。教师需提示：金属氧化物与酸反应生成盐和水，MgO + 2HCl → MgCl₂ + H₂O，水是生成物之一，该反应一步完成，符合题意。

    5. **步骤4（结论）**：综合三组判断，确定只有①和③满足"每一步均能一步实现"的条件，对应选项B。此时可让学生回顾②组的错误本质——化合价在复分解反应中保持不变。

    <TEXT_3>
    **完整解答：**

    1. **①组（钙三角）**：
       - CaCO₃ → CaO：高温煅烧分解，一步实现。
       - CaO → Ca(OH)₂：与水反应（熟化），一步实现。
       - Ca(OH)₂ → CaCO₃：通入CO₂或加入可溶性碳酸盐，一步实现。
       - **结论：①符合题意。**

    2. **②组（铁及其化合物）**：
       - Fe → Fe₂O₃：在潮湿空气中缓慢氧化（生锈），一步实现。
       - Fe₂O₃ → FeSO₄：Fe₂O₃与稀硫酸反应生成Fe₂(SO₄)₃和H₂O，铁元素保持+3价，**不能直接生成FeSO₄（Fe²⁺）**。若要先还原再反应，或先反应再加铁粉还原，均需两步以上。
       - **结论：②不符合题意。**

    3. **③组（水、氧气、氧化镁）**：
       - H₂O → O₂：通电分解，一步实现。
       - O₂ → MgO：镁条在氧气中点燃，一步实现。
       - MgO → H₂O：MgO与稀盐酸（或稀硫酸）反应生成盐和水，一步实现。
       - **结论：③符合题意。**

    **答案：B．①③**

    **课堂讲解建议：**

    - 本题核心考查点是"一步反应"的严格性和元素化合价在反应中的变化规律。讲解时要反复强调：判断物质转化能否一步实现，不仅要记得反应物，更要准确判断生成物。

    - 讲解②组时，务必强调**复分解反应中元素化合价不变**这一原则。这是学生判断物质转化能否一步实现的重要工具。可板书对比：
      - Fe₂O₃ + 3H₂SO₄ → Fe₂(SO₄)₃ + 3H₂O（+3价不变）
      - Fe + H₂SO₄ → FeSO₄ + H₂↑（0价→+2价，置换反应）

    - 讲解③组时，注意纠正学生"只有分解反应才能生成水"的思维定式。金属氧化物与酸反应也是生成水的重要途径。可让学生列举还有哪些氧化物与酸反应能生成水，进行知识迁移。

    - 可拓展讨论：若②组中Fe₂O₃→FeSO₄改为Fe₂O₃→Fe₂(SO₄)₃，是否②组就能全部一步实现？（从反应角度可以，但Fe→Fe₂O₃在初中通常指生锈，严格来说铁在氧气中燃烧生成的是Fe₃O₄，仍存细微争议，可作为开放性讨论点，培养学生批判性思维。）
