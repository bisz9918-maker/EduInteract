[图示主题与整合说明]
- 本图示主题：化学实验图像判断——四个选项的原理分析与图像对比
- 整合内容：题目总览（步骤0）→ A选项饱和石灰水+CaO的溶质质量变化（步骤1）→ B选项KMnO₄加热的固体质量变化（步骤2）→ C选项CaCO₃高温煅烧的固体质量变化（步骤3）→ D选项O₂溶解度随温度变化（步骤4）→ 正确答案总结（步骤5）

[分步序列]
- 初始状态（步骤0）「题目总览」：
  - 显示 2×2 网格，A/B/C/D 四图均匀分布
  - 所有曲线以灰色虚线显示（题目原图）
  - 每图下方标注选项字母，坐标轴标注横纵坐标含义
  - 教师引导学生观察横纵坐标与曲线趋势

- 步骤1「分析A：饱和石灰水 + CaO」：
  - 切换为左右分栏
  - 左侧：烧杯示意图（溶液浅蓝填充）+ CaO方块 + 化学方程式
  - 右侧：坐标系内灰色虚线（水平直线，题目原图）与蓝色实线（先下降后水平，正确曲线）对比
  - 红色批注出现："溶剂减少、温度升高导致溶质析出"

- 步骤2「分析B：加热高锰酸钾」：
  - 左侧：试管+酒精灯装置示意图 + 化学方程式
  - 右侧：坐标系内灰色虚线（斜降至0，题目原图）与蓝色实线（降至非零值，正确曲线）对比
  - 红色批注出现："反应后仍有固体剩余，质量不可能为零"

- 步骤3「分析C：高温煅烧碳酸钙」：
  - 左侧：坩埚+高温火焰+CO₂逸出箭头 + 化学方程式
  - 右侧：坐标系内蓝色实线高亮显示（水平→下降→水平），即题目原图本身正确
  - 绿色"正确"标记出现，三段标注"预热""分解""反应完全"

- 步骤4「分析D：氧气溶解性」：
  - 左侧：水槽+倒扣集气瓶示意图
  - 右侧：坐标系内灰色虚线（上升直线，题目原图）与蓝色实线（下降直线，正确曲线）对比
  - 红色批注出现："气体溶解度随温度升高而减小"

- 步骤5「结论」：
  - 回到 2×2 网格，四图再次呈现
  - A/B/D 图右上角红色"✗"，C图右上角绿色"✓"
  - C图外框绿色高亮，背景浅绿填充
  - 底部中央显示"正确选项：C"

[技术实现]
- JS库选择：原生 SVG + 原生 JavaScript（无外部库）。理由：本场景以静态几何图形和状态切换为主，SVG路径、文本、矩形即可满足，无需复杂绘图库；状态切换通过显示/隐藏 SVG <g> 组实现，逻辑简单。
- 画布尺寸：800 × 500 px（固定），SVG 使用 viewBox="0 0 800 500"
- 布局草图：
  ```
  +--------------------------------------------------+
  |              步骤标题 (400,28)                    |
  |  +------------------+  +------------------------+ |
  |  |                  |  |                        | |
  |  |   实验装置区      |  |     坐标系/图像区       | |  ← 步骤1-4
  |  |   280×390        |  |     460×390            | |
  |  |                  |  |                        | |
  |  +------------------+  +------------------------+ |
  |  +------------------+--------------------------+ |
  |  |   A图    |   B图   |   C图    |   D图       | |  ← 步骤0/5
  |  |  (360×190 each in 2×2)                     | |
  |  +---------------------------------------------+ |
  |       [◀ 上一步]  ●●●●●●  [下一步 ▶]            |
  |                    步骤名称                      |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：变量 `currentStep` 取值 0~5，对应6个步骤。初始化 `currentStep = 0`。
  2. 分组管理：SVG 内使用 6 个 `<g id="scene1-step0-group">` ~ `<g id="scene1-step5-group">`，每个组包含该步骤全部视觉元素。切换步骤时，遍历 6 个组，仅当前步骤组设置 `display: block`，其余 `display: none`。
  3. 标题与控件更新：JS 中维护数组 `stepTitles = ['题目总览','选项A：饱和石灰水 + CaO','选项B：加热高锰酸钾','选项C：高温煅烧碳酸钙','选项D：氧气溶解性','正确答案']`，切换时更新标题文本和步骤名称文本。
