[图示主题与整合说明]
- 本图示主题：长方形分类计数——按组成块数逐一找出所有长方形
- 整合的步骤/概念：题目原图展示 → 单块长方形（4个）→ 2块拼成的长方形（3个）→ 3块拼成的长方形（2个）→ 4块拼成的大长方形（1个）→ 算式汇总 4+3+2+1=10
- 教学价值：教师通过分步导航控制讲解节奏，每步只聚焦一类长方形，避免一次性展示过多图形造成学生视觉混乱；右侧统计面板实时同步当前类别数量，最后汇总呈现完整算式，帮助学生建立"分类枚举、不重不漏"的计数思想。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  * 「◀ 上一步」按钮：位于底部左侧（中心x=305,y=470），宽100×高30。点击后当前步骤减1，回到上一步的视觉状态。步骤0时禁用。
  * 「下一步 ▶」按钮：位于底部右侧（中心x=495,y=470），宽100×高30。点击后当前步骤加1，进入下一步的视觉状态。步骤5时禁用。
  * 步骤指示器：位于两按钮正上方（x=400,y=440），显示"步骤 N / 5"，文字14px灰色#666666。
- 教师操作流程：
  1. 教师打开图示，学生看到题目原图（步骤0）。
  2. 教师点击「下一步」，进入步骤1，讲解"单块长方形有4个"，左侧4个小长方形依次（或同时）高亮，右侧同步显示"单块：4个"。
  3. 教师继续点击「下一步」，依次进入步骤2-4，每步聚焦一类组合长方形，左侧高亮对应组合，右侧同步更新统计。
  4. 进入步骤5，左侧恢复初始图形，右侧展示完整算式 4+3+2+1=10 和答案 C。
  5. 教师可随时点击「上一步」回退，让学生回顾某一类别的长方形有哪些。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无需外部库）。理由：本场景为简单几何图形和状态切换，SVG的rect/line/text元素配合opacity/stroke属性即可满足所有视觉需求，引入D3等库反而增加冗余。
- 画布尺寸：800 × 500 px（固定画布，SVG设置viewBox="0 0 800 500"）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------------+
  |                                                        |
  |   +-------------------图形区 (~x:0-520)----------------+   +------统计区 (~x:520-800)------+
  |   |                                                    |   |  长方形分类计数               |
  |   |    +----------------------------------------+      |   |                               |
  |   |    |        |        |          |        |      |   |  ▸ 单块：4个  (步骤1蓝)       |
  |   |    |   ①    |   ②    |    ③     |   ④    |      |   |  ▸ 两块：3个  (步骤2蓝)       |
  |   |    |        |        |          |        |      |   |  ▸ 三块：2个  (步骤3蓝)       |
  |   |    +----------------------------------------+      |   |  ▸ 四块：1个  (步骤4蓝)       |
  |   |                                                    |   |  ---------------------        |
  |   |                                                    |   |  4+3+2+1=10（个）(步骤5红)   |
  |   |                                                    |   |  答案：C      (步骤5红)       |
  |   +----------------------------------------------------+   +-------------------------------+
  |                                                        |
  |              步骤 N / 5                                |
  |           [◀ 上一步]  [下一步 ▶]                       |
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：定义变量 `currentStep`（范围0-5）。`updateScene(step)`函数为唯一状态更新入口，根据step值统一设置所有元素的opacity、fill、stroke、font-weight属性，避免分散修改导致状态不一致。
  2. 高亮块管理：10个高亮rect（4个基础区+6个组合区）初始opacity=0。每步通过切换对应rect的opacity实现"显示哪类组合"。所有高亮rect的fill统一为#1565c0，fill-opacity=0.2，stroke=#1565c0，stroke-width=3。
  3. 统计文字管理：右侧统计行初始opacity=0。步骤1-4时，当前行opacity=1且fill=#1565c0、font-weight=bold；已讲过的行opacity=1但fill=#888888、font-weight=normal；未讲到的行opacity=0。步骤5时所有行opacity=1且fill=#888888，算式和答案opacity=1且fill=#c62828。
  4. 按钮状态：步骤0时prev按钮disabled=true；步骤5时next按钮disabled=true；其余步骤两按钮均可用。禁用状态通过CSS类切换样式（背景变灰、文字变浅）。
  5. 过渡动画：所有opacity变化使用CSS transition: opacity 0.3s ease，使步骤切换有平滑淡入淡出效果。高亮块的stroke-width变化也加transition。
  6. 事件绑定：按钮绑定click事件，调用`changeStep(delta)`（delta=+1或-1），内部校验边界后调用`updateScene(currentStep)`。
- ID 命名规范：所有交互元素ID必须以 `scene1-` 为前缀：
  * 外框：scene1-rect-outer
  * 分割线：scene1-line-div1, scene1-line-div2, scene1-line-div3
  * 基础区域高亮：scene1-zone-1, scene1-zone-2, scene1-zone-3, scene1-zone-4
  * 组合高亮：scene1-combo-12, scene1-combo-23, scene1-combo-34, scene1-combo-123, scene1-combo-234, scene1-combo-1234
  * 编号：scene1-label-1, scene1-label-2, scene1-label-3, scene1-label-4
  * 右侧文字：scene1-title, scene1-hint, scene1-stat-1~4, scene1-formula, scene1-answer
  * 控件：scene1-step-indicator, scene1-btn-prev, scene1-btn-next
  * JS中严格使用document.getElementById获取元素，禁止querySelectorAll配合全局class，避免多场景合并时跨场景污染。
- IIFE 隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，变量不污染全局作用域。
