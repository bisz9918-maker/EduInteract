[图示主题与整合说明]
- 本图示主题：规律探究——长方形个数与竖线数量的关系
- 整合内容：线段计数模型、竖线选两条确定一个长方形、通用公式 n(n+1)/2、可拓展的分割数量验证
- 教学价值：教师通过拖动滑块改变小长方形个数 n（2–6），让学生从特殊（n=4，即题目原图）到一般，直观观察长方形总数随 n 的变化规律，理解组合计数原理 C(n+1,2)。当 n=4 时红色高亮提示"这就是题目中的图形"，建立图示与题目的直接关联。
- 原图说明：题目图片显示一个大长方形被 3 条竖线分为 4 个小长方形（宽度不完全相等）。本教学图示采用等宽小长方形，以便清晰展示通用规律，n=4 时与题意对应。

[交互方案]
- 交互类型：连续拖拽/滑块（range input）
- 控件说明：
  - 滑块轨道：水平灰色轨道，位于画布中部 y=277~293，x=250~550
  - 滑块按钮：蓝色圆形按钮，直径 20px，在轨道上滑动
  - 数值标签：按钮正上方实时显示 "n = X"
  - 范围：n ∈ [2, 6]，步长 1，初始值 4
- 教师操作流程：
  1. 教师展示初始状态 n=4，指出"这就是题目中的图形"，引导学生数出 10 个长方形
  2. 教师向左拖动滑块到 n=3 或 n=2，让学生观察长方形总数减少，建立"竖线越少、长方形越少"的直觉
  3. 教师向右拖动滑块到 n=5、n=6，让学生发现总数依次为 15、21，引出规律
  4. 教师回到 n=4，结合公式 "(n+1)×n÷2" 与算式 "4+3+2+1=10"，总结组合计数原理

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无需额外库，简单几何图形直接操作 DOM 即可）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------------+
  |                                                        |
  |    +------------------------------------------+        |
  |    |  |  |  |  |  |  |  |  |  |  |  |  |  |  |        |
  |    +------------------------------------------+        |
  |    |  |  |  |  |  |  |  |  |  |  |  |  |  |  |        |
  |    1  2  3  4  5  6  7                               |
  |                                                        |
  |              小长方形个数 n                            |
  |                 n = 4                                  |
  |    |----------o-------------------------------|        |
  |              滑块                                      |
  |                                                        |
  |         ★ 这就是题目中的图形 (n=4时)                   |
  |            竖线总数 = n + 1 = 5                        |
  |       长方形总数 = (n+1) × n ÷ 2                       |
  |                  = 10                                  |
  |         4 + 3 + 2 + 1 = 10  (n=4时)                    |
  |                                                        |
  +--------------------------------------------------------+
  画布 800×500，滑块与公式均位于 SVG 内，无额外控件栏
  ```
- 关键实现要点：
  1. 状态机设计：仅维护一个变量 `currentN`（2–6），初始值为 4
  2. 动态重绘策略：每次滑块变化时，清空并重建内部竖线、小长方形填充、竖线短标记、竖线编号四组元素（避免残留）
  3. 坐标计算：小长方形宽度 `w = 360 / currentN`；竖线 x 坐标 `x_i = 220 + i * w`（i=0~currentN）
  4. 滑块实现：使用 HTML `<input type="range" min="2" max="6" step="1" value="4">`，通过 CSS 自定义轨道和按钮样式，绝对定位覆盖在 SVG 上方（left:250px, top:270px, width:300px）
  5. 动画曲线：无需复杂动画，滑块拖动时图形和公式即时同步更新（响应 input 事件）
  6. 事件绑定：监听 range input 的 `input` 事件，触发 `updateScene(n)` 函数
  7. n=4 特判：在 `updateScene` 中判断，若 n===4 则显示特殊标记和本题算式，否则隐藏（display:none 或 opacity:0）
  8. 公式更新：直接修改对应 text 元素的 textContent，计算结果使用绿色加粗字体
- ID 命名规范：所有交互元素 ID 必须以 `scene2-` 为前缀
  - 外框：`scene2-rect-border`
  - 小长方形填充容器组：`scene2-fill-group`
  - 内部竖线组：`scene2-divider-group`
  - 竖线标记组：`scene2-tick-group`
  - 竖线编号组：`scene2-tick-label-group`
  - 滑块标签：`scene2-slider-label`
  - 滑块数值：`scene2-slider-value`
  - 特殊标记：`scene2-formula-special`
  - 竖线公式：`scene2-formula-lines`
  - 总数公式：`scene2-formula-total`
  - 计算结果：`scene2-formula-result`
  - 本题算式：`scene2-formula-example`
  - JS 中统一使用 `document.getElementById` 获取元素，禁止跨场景选择器
- IIFE 隔离：所有 JavaScript 代码包裹在 `(function() { ... })();` 中，避免全局变量污染
