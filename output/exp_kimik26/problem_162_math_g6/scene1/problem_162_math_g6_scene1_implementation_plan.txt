[图示主题与整合说明]
- 本图示主题：三图形周长比较与平移法推导
- 整合的步骤/概念：
  1. 图形A（长方形）周长直接计算，作为基准；
  2. 图形B（阶梯形）通过线段平移转化为等周长长方形；
  3. 图形C（凹字形）通过线段平移后发现凹陷处多出两段竖直边；
  4. 三者周长数值对比，得出C周长最长的结论。
- 教学价值：教师通过分步按钮控制每一步的呈现，先让学生观察三个图形的外观差异，再逐步揭示B和C的平移法原理，最后通过算式对比自然得出答案。分步导航避免信息过载，适合课堂讲解节奏。

[分步序列]
- 步骤0（初始状态）：
  显示元素：图形A/B/C黑色轮廓、全部尺寸标注（10×3、6×3）、字母标签A/B/C。
  隐藏元素：所有高亮边框、填充、算式、箭头、虚线长方形、结论。
  教师操作：引导学生观察三个图形外观，提问哪个周长最长。

- 步骤1（图形A周长计算）：
  变化：A边框变为蓝色#1565c0（3px），A内部填充蓝色15%，显示算式A"周长 = 2×(10+6) = 32"（蓝色，位于A下方）。
  教师操作：讲解长方形周长公式，确认A的周长为32。

- 步骤2（图形B平移转化）：
  变化：A恢复黑色原始状态（隐藏蓝色边框/填充/算式）；B边框变为绿色#2e7d32（3px），B内部填充绿色15%；显示灰色虚线长方形(325,150)-(475,240)；显示6条平移箭头（3条向上、3条向右，灰色虚线）；显示算式B"周长 = 2×(10+6) = 32"（绿色，位于B下方）。
  教师操作：讲解平移法——所有水平短边向上平移合成顶边，所有竖直短边向右平移合成右边，B的周长等于同尺寸长方形周长32。

- 步骤3（图形C平移与多余边）：
  变化：B恢复黑色原始状态（隐藏绿色边框/填充/算式/虚线长方形/箭头）；C边框变为红色#c62828（3px），C内部填充红色15%；显示向上箭头（从内横边中点指向顶边）；凹陷处两段内竖边加粗红色3px高亮；显示h标注（左右各一，红色）；显示算式C"周长 = 2×(10+6) + 2h = 32 + 2h"（红色，位于C下方）。
  教师操作：讲解C的平移——顶部内横边向上平移可与顶边对齐，但凹陷处多出两段竖直边（各长h），无法通过平移抵消，因此C的周长比长方形多2h。

- 步骤4（结论对比）：
  变化：同时显示三个算式（A蓝、B绿、C红）；C保持红色高亮（边框+填充+内竖边+h标注）；A和B恢复黑色原始状态；显示结论文本"周长最长的是 C"（红色加粗，位于画布底部中央）。
  教师操作：对比三个算式A=32、B=32、C=32+2h，因为h>0，所以C周长最长，得出答案。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「◀ 上一步」按钮：位于画布底部中央偏左 (300,455)，宽80×高30。点击回退到上一个步骤，步骤0时禁用（置灰）。
  2. 「下一步 ▶」按钮：位于画布底部中央偏右 (420,455)，宽80×高30。点击前进到下一个步骤，步骤4时禁用（置灰）。
  3. 步骤指示器：位于两按钮下方居中 (400,490)，显示"步骤 X/4"，黑色14px。
- 教师操作流程：
  1. 加载后处于步骤0，教师先让学生观察三个图形；
  2. 点击「下一步」进入步骤1，讲解A的周长；
  3. 点击「下一步」进入步骤2，讲解B的平移法；
  4. 点击「下一步」进入步骤3，讲解C的平移法与多余边；
  5. 点击「下一步」进入步骤4，总结对比得出结论；
  6. 可随时点击「上一步」回退复习。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本场景为静态几何图形与简单的显示/隐藏状态切换，无需复杂绘图库或动画引擎，原生SVG性能最优且文件体积最小。
- 画布尺寸：800 × 500 px（固定），控件栏通过HTML绝对定位叠在SVG底部（y=440~490），不额外撑高容器。
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------------+
  |                                                        |
  |   [图形A]          [图形B]          [图形C]            |
  |   长方形           阶梯形           凹字形             |
  |   (80,150)        (325,150)        (570,150)           |
  |                                                        |
  |   10                10                10               |
  |   A                 B                 C                |
  |   算式A             算式B             算式C            |
  |                                                        |
  |              结论：周长最长的是 C                      |
  |                                                        |
  |        [◀ 上一步]    步骤 X/4    [下一步 ▶]            |
  +--------------------------------------------------------+
  宽度：800px
  ```
- 关键实现要点：
  1. 状态机设计：定义全局变量 `currentStep`（0~4）。用一个配置对象 `stepConfig` 定义每个步骤要显示/隐藏的元素ID列表，或给每个SVG元素设置 `data-steps` 属性（如 `data-steps="1,4"` 表示在步骤1和4显示）。推荐后者，代码更清晰。
  2. 渲染函数 `renderStep(step)`：遍历所有带 `data-steps` 的元素，检查当前步骤是否在属性值中，设置 `style.display = 'block'` 或 `'none'`。高亮边框/填充/原始轮廓通过显示不同层实现（原始黑线始终显示，高亮层叠在上面）。
  3. 按钮状态：步骤0时禁用「上一步」，步骤4时禁用「下一步」，通过添加/移除 `disabled` class 实现置灰样式。
  4. 箭头标记：在SVG `<defs>` 中定义灰色箭头标记 `<marker id="scene1-arrowhead-gray">`，箭头线使用 `marker-end="url(#scene1-arrowhead-gray)"`。
  5. 填充区域：使用 `<polygon>` 或 `<rect>` 配合 `fill-opacity="0.15"`，叠在图形底层（z-index通过SVG绘制顺序控制，先画填充，再画边框）。
  6. 坐标计算：所有坐标已精确规划，代码agent直接按坐标表实现，无需动态计算。
- ID命名规范：所有交互元素ID必须以 `scene1-` 为前缀。例如：
  - 图形：`scene1-fig-a`、`scene1-fig-b`、`scene1-fig-c`
  - 高亮边框：`scene1-hl-a`、`scene1-hl-b`、`scene1-hl-c`
  - 填充：`scene1-fill-a`、`scene1-fill-b`、`scene1-fill-c`
  - 标签：`scene1-label-10-a`、`scene1-label-6-a`、`scene1-label-a`
  - 算式：`scene1-formula-a`、`scene1-formula-b`、`scene1-formula-c`
  - 结论：`scene1-conclusion`
  - 箭头：`scene1-arrow-b-up-1`、`scene1-arrow-b-right-1`、`scene1-arrow-c-up`
  - 高亮线段：`scene1-highlight-c-left`、`scene1-highlight-c-right`
  - h标注：`scene1-h-left`、`scene1-h-right`
  - 虚线长方形：`scene1-dashed-rect-b`
  - 按钮：`scene1-btn-prev`、`scene1-btn-next`
  - 指示器：`scene1-step-indicator`
  - 箭头标记：`scene1-arrowhead-gray`
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })()` 中，避免全局变量污染，确保多场景合并时互不干扰。
- 事件绑定：使用 `document.getElementById('scene1-btn-prev').addEventListener('click', ...)` 和 `document.getElementById('scene1-btn-next').addEventListener('click', ...)`。
