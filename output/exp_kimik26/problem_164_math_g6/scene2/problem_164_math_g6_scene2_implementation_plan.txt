[图示主题与整合说明]
- 本图示主题：选项三视图对比验证与排除法应用
- 整合的步骤/概念：将题目给出的三视图（正面矩形、侧面带竖线矩形、上面梯形）与三个候选物体①②③的三视图进行并排对比，通过对比标记（✓/✗）直观展示匹配/不匹配关系，帮助教师用排除法讲解为何③是正确答案。
- 教学价值：教师可先让学生观察题目三视图特征，再逐一切换选项进行验证。通过红叉绿勾的即时反馈，强化"长对正、高平齐、宽相等"的三视图对应关系，训练空间想象与排除推理能力。

[分步序列]

  · 底部三个按钮均为默认状态（白底黑字）

  · 右栏三个视图外围出现红色虚线框
  · 中间显示红色说明文字："含三角形"、"侧面不符"、"不是梯形"

  · 右栏三个视图轮廓触发蓝色描边闪烁动画（#1565c0，闪烁1次，600ms）

[交互方案]
- 交互类型：多状态切换（3个状态按钮，对应3个选项）
- 控件说明：
  · 按钮"①"：位置(250,440)，尺寸80×40。点击切换到物体①的三视图对比状态。
  · 按钮"②"：位置(360,440)，尺寸80×40。点击切换到物体②的三视图对比状态。
  · 按钮"③"：位置(470,440)，尺寸80×40。点击切换到物体③的三视图对比状态。
- 教师操作流程：
  1. 教师先引导学生观察左栏题目三视图特征（正面矩形、侧面有竖线、上面梯形）。
  2. 教师点击按钮"①"，右栏显示①的三视图，中间出现三个红叉，教师讲解"正面不是矩形而是凹字形，侧面也不是题目中的样子，上面更不是梯形"。
  3. 教师点击按钮"②"，右栏显示②的三视图，中间出现三个红叉，教师讲解"正面出现了三角形，侧面虽然是矩形但与题目侧面不符，上面是三角形不是梯形"。
  4. 教师点击按钮"③"，右栏显示③的三视图，中间出现三个绿勾并触发蓝色闪烁，教师总结"正面矩形匹配，侧面下部矩形上部窄梯形匹配，上面梯形匹配，所以答案是③"。
  5. 教师可反复点击三个按钮来回对比，强化排除法思路。

[技术实现]
- JS库选择：原生SVG（所有图形均为基本几何形状，SVG路径简单直接，无需引入外部库，减少依赖）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------------+
  |        题目视图                                    选项视图        |
  |                                                                    |
  |   +----------+         (○)         +----------+                   |
  |   |  正面    |        正面          |  正面    |                   |
  |   |  矩形    |         ✓            |  矩形    |                   |
  |   +----------+                      +----------+                   |
  |                                                                    |
  |   +----------+         (○)         +----------+                   |
  |   |  侧面    |        侧面          | 下部矩形 |                   |
  |   | 带竖线   |         ✓            | +上部梯形|                   |
  |   +----------+                      +----------+                   |
  |                                                                    |
  |   +----------+         (○)         +----------+                   |
  |   |  上面    |        上面          |  梯形    |                   |
  |   |  梯形    |         ✓            |          |                   |
  |   +----------+                      +----------+                   |
  |                                                                    |
  |              [  ①  ]   [  ②  ]   [  ③  ]                          |
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：定义4个状态常量（STATE_NONE=0, STATE_1=1, STATE_2=2, STATE_3=3），currentState变量记录当前状态。点击按钮时调用setState(newState)函数切换。
  2. 切换逻辑：setState函数先清除所有动态元素（隐藏右栏视图、清除标记、清除说明文字、移除高亮框），再根据新状态创建对应SVG元素。使用display或visibility属性控制显隐，避免频繁创建销毁DOM。
  3. 坐标计算：所有视图坐标硬编码在配置对象中，按"题目/选项+视图类型+状态"三级索引，如coords.option[1].front = {x:640, y:55, w:80, h:100, type:'concave'}。
  4. 动画曲线：状态③的蓝色闪烁使用CSS @keyframes，定义blink动画（0% stroke-opacity:0; 50% stroke-opacity:1; 100% stroke-opacity:0），时长600ms，ease-in-out，播放1次。通过给右栏视图组添加class="scene2-blink"触发。
  5. 事件绑定：三个按钮分别绑定click事件，调用setState(1/2/3)。在IIFE内部定义函数，避免全局污染。
  6. 对比标记绘制：✓用path "M-6,0 L-2,4 L6,-6"配合transform="translate(x,y)"；✗用两条line "M-6,-6 L6,6"和"M6,-6 L-6,6"配合transform。
  7. 不匹配虚线框：在选项视图外围画rect，比视图各大5px，stroke-dasharray="5,5"，初始display=none，错误状态时显示。
  8. 匹配绿色填充：选项视图元素初始fill=none，状态③时改为fill=#2e7d32, fill-opacity=0.2。
- ID命名规范：所有交互元素ID必须以scene2-为前缀。
  · 题目视图组：scene2-left-group
  · 题目-正面：scene2-left-front
  · 题目-侧面：scene2-left-side
  · 题目-上面：scene2-left-top
  · 选项视图组：scene2-right-group
  · 选项-正面：scene2-right-front
  · 选项-侧面：scene2-right-side
  · 选项-上面：scene2-right-top
  · 对比标记-正面：scene2-mark-front
  · 对比标记-侧面：scene2-mark-side
  · 对比标记-上面：scene2-mark-top
  · 对比说明-正面：scene2-note-front
  · 对比说明-侧面：scene2-note-side
  · 对比说明-上面：scene2-note-top
  · 提示文字：scene2-hint-text
  · 按钮①：scene2-btn-1
  · 按钮②：scene2-btn-2
  · 按钮③：scene2-btn-3
  · 虚线框组：scene2-error-frames
  · 绿色填充组：scene2-match-fill
- IIFE隔离：所有JavaScript代码包裹在 (function() { ... })() 中，所有变量和函数均为局部作用域。
