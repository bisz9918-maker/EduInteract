[图示主题与整合说明]
- 本图示主题：正方形地砖面积与铺设数量的反比例关系
- 整合的步骤/概念：题意呈现（两种地砖对比）→ 单块面积计算 → 健身房总面积推导 → 2dm地砖所需块数计算 → 反比例规律总结
- 教学价值：教师可按照"感知差异→计算面积→建立总量→求解未知→抽象规律"的认知链条逐步讲解，分步导航支持课堂节奏控制，学生能跟随视觉增量逐步理解反比例本质

[分步序列]
- 初始状态（步骤0 / 题意呈现）：显示标题、3dm正方形外框（浅蓝填充）、2dm正方形外框（浅红填充）、健身房矩形（浅灰填充）、边长标签"3dm"和"2dm"、健身房标签"健身房（总面积不变）"、健身房内部虚线。隐藏网格、面积标签、块数标签、所有算式、选项、关系式。
- 步骤1（单块面积）：在步骤0基础上，显示3dm和2dm的内部网格线，显示面积标签"9dm²"和"4dm²"，显示单块面积算式"3×3=9 (dm²)"和"2×2=4 (dm²)"。
- 步骤2（总面积）：隐藏步骤1的单块面积算式（保留网格和面积标签），3dm正方形外框加粗至3px（高亮已知条件），显示"400块"标签，显示总面积算式"9 × 400 = 3600 (dm²)"。
- 步骤3（所求块数）：2dm正方形外框加粗至3px（高亮所求问题），显示"900块"标签，显示所求算式"3600 ÷ 4 = 900 (块)"，显示选项"A.600    B.900    C.1200    D.1800"且B以绿色高亮。保留步骤2的400块和总面积算式，形成完整推导链。
- 步骤4（规律总结）：隐藏网格线、面积标签、块数标签、所有算式、选项，仅保留两个正方形外框（恢复2px）、边长标签、健身房矩形及标签。显示反比例关系式"单块面积 × 块数 = 总面积（一定）"（绿色加粗），显示说明"两种相关联的量成反比例关系"。
- 教师可随时点击「◀ 上一步」「下一步 ▶」回退或前进，步骤指示器实时更新"步骤 X / 5"。

[交互方案]
- 交互类型：分步按钮导航（◀ 上一步 / 下一步 ▶）
- 控件说明：
  1. 「◀ 上一步」按钮：位于画布底部(310, 465)，宽80×高28。点击回退到上一步骤，步骤0时禁用（opacity=0.4）。
  2. 「下一步 ▶」按钮：位于画布底部(410, 465)，宽80×高28。点击前进到下一步骤，步骤4时禁用（opacity=0.4）。
  3. 步骤指示器：位于按钮上方(400, 450)，显示"步骤 X / 5"，14px灰色文本。
- 教师操作流程：教师打开图示后处于步骤0，向学生展示题意（两种地砖、同一健身房）；点击「下一步」进入步骤1，讲解单块面积计算；继续点击推进至步骤2讲解总面积，步骤3讲解所求块数并揭示答案B，步骤4抽象出反比例规律。讲解中可随时回退复习。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript。理由：本场景仅涉及简单几何图形（矩形、线段、文本）和显隐切换，无需复杂图表库；原生SVG对矩形、虚线、文本支持完善，且便于通过class/ID控制显隐。
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |         正方形地砖面积与铺设数量 (y=30)            |
  |                                                  |
  |   +-----------+ 150×150       +------+ 100×100   |
  |   |  9dm²     |               | 4dm² |           |
  |   | (3×3网格) |               |(2×2) |           |
  |   +-----------+               +------+           |
  | 3dm←  400块                 2dm←  900块          |
  |                                                  |
  |   +--------------------------------------+       |
  |   |      健身房（总面积不变）             |       |
  |   +--------------------------------------+       |
  |                                                  |
  |        9 × 400 = 3600 (dm²)   (步骤2)            |
  |        3600 ÷ 4 = 900 (块)    (步骤3)            |
  |        A.600  B.900  C.1200  D.1800  (步骤3)     |
  |        单块面积 × 块数 = 总面积（一定）(步骤4)    |
  |        两种相关联的量成反比例关系      (步骤4)    |
  |                                                  |
  |              步骤 X / 5         (y=450)          |
  |            [◀上一步] [下一步▶]  (y=465)          |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `currentStep`（0~4），每次点击按钮时更新状态，调用 `renderStep()` 函数根据状态显隐元素。
  2. 元素显隐控制：为每个步骤相关的SVG元素设置 `display` 属性（或CSS class `.hidden` / `.visible`），避免使用opacity造成不可点击或视觉残留。
  3. 高亮控制：步骤2将3dm正方形 `stroke-width` 设为3，步骤3将2dm正方形 `stroke-width` 设为3；步骤3通过 `<tspan fill="#2e7d32" font-weight="bold">` 高亮选项B；步骤4将关系式设为绿色。
  4. 按钮禁用逻辑：`currentStep === 0` 时禁用「上一步」，`currentStep === 4` 时禁用「下一步」，通过设置 `disabled` 属性和CSS样式反馈。
  5. 步骤指示器：动态更新文本内容 `步骤 ${currentStep + 1} / 5`。
  6. 坐标计算：所有坐标硬编码为像素值，确保代码agent直接复制即可，无需动态计算。
- ID 命名规范：所有SVG元素和HTML控件ID必须以 `scene1-` 为前缀，例如 `scene1-square-3dm`、`scene1-formula-total`、`scene1-btn-prev`、`scene1-btn-next`。JS中严格使用 `document.getElementById` 获取元素，禁止全局class选择器，避免多场景合并时跨场景污染。
- IIFE 隔离：所有JavaScript代码包裹在 `(function() { ... })()` 立即执行函数中，变量不泄露全局作用域。
