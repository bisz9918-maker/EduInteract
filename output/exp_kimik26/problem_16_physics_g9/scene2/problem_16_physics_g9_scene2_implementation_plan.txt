[图示主题与整合说明]
- 本图示主题：滑动变阻器滑片右移时动态电路的全流程推导与选项判断
- 整合的步骤/概念：①滑动变阻器局部变化（滑片右移→接入电阻变大）→②总电阻与电流变化→③电压表V2与灯泡亮度变化→④电压表V1变化→⑤电路总功率变化→⑥四个选项的正误判断
- 教学价值：教师通过分步导航带领学生走完“局部→整体→局部”的动态分析链条，每步只聚焦一个物理量变化，降低认知负荷；可随时回退到任意步骤重新强调因果关系

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「◀ 上一步」按钮：位置(300,452)，宽90高36。点击后状态-1，回退到上一步，隐藏当前步骤新增的元素。
  2. 「下一步 ▶」按钮：位置(410,452)，宽90高36。点击后状态+1，展示下一步的视觉变化。
  3. 步骤指示文本：位置(400,445)，显示当前步骤编号（如"步骤: 2/6"）。
- 教师操作流程：
  1. 教师打开图示，学生看到完整电路和四个选项（步骤0）。
  2. 教师点击「下一步」进入步骤1，讲解“滑片右移→接入电阻丝变长→R滑变大”，配合局部放大框让学生看清滑片移动方向。
  3. 继续点击「下一步」进入步骤2，讲解总电阻与电流变化，观察电流表旁蓝色箭头。
  4. 依此类推，每步只讲一个物理量，直到步骤6得出正确选项B。
  5. 若学生某步没听懂，教师点击「上一步」回退重新讲解。
- 边界处理：步骤0时「上一步」禁用（opacity 0.4，pointer-events none）；步骤6时「下一步」禁用。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：本场景以静态几何图形、文本标签和显隐控制为主，无需复杂数学计算或3D渲染，原生SVG足够轻量且可控。
- 画布尺寸：800×500 px（固定）。
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |  电路图区(20,30~340,330)    |  推导区(360,40~580,320) |
  |  [矩形回路+元件+V1+V2]      |  [公式逐行显示]         |
  |  [局部放大框(步骤1)]        |                        |
  +--------------------------------------------------+
  |  选项区(20,350~770,415)                             |
  |  [ A框 ][ B框 ][ C框 ][ D框 ]                       |
  +--------------------------------------------------+
  |  控件区(y=440~490)                                  |
  |        [◀上一步]  步骤:X/6  [下一步▶]              |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `let currentStep = 0;`（范围0~6）。每步用一个配置对象数组 `stepsConfig` 描述该步应显示的元素ID列表。切换步骤时，先隐藏所有“步骤专属元素”，再显示当前步对应的元素。
  2. 元素显隐：所有步骤专属元素（局部放大框、推导公式、趋势箭头、选项高亮）初始 `display:none` 或 `opacity:0`（配合CSS transition）。通过切换class `scene2-visible` 控制出现/消失，transition时长200ms。
  3. 滑片动画：步骤0→1时，主图滑片从x=200移动到x=230，使用SVG的 `<animate>` 或JS的 `requestAnimationFrame` 修改 `transform` 或 `x1/x2` 属性，时长300ms，ease-out。
  4. 下标实现：使用SVG `<tspan baseline-shift="sub" font-size="10">` 实现 R滑、V₁、V₂ 等下标。
  5. 选项换行：选项文字较长，使用SVG `<foreignObject>` 嵌入 `<div style="font-size:11px; line-height:1.3;">`，利用HTML自动换行；或手动拆分为多行 `<tspan>`。
  6. 按钮禁用：步骤0时给「上一步」加 `disabled` class；步骤6时给「下一步」加 `disabled` class。
- ID命名规范：所有SVG元素及HTML控件ID必须以 `scene2-` 为前缀。例如：
  - 回路导线：`scene2-wire-top`、`scene2-wire-right` 等
  - 滑片：`scene2-rheostat-arm`
  - 局部放大框：`scene2-zoom-box`
  - 推导公式行1左：`scene2-formula-rtotal`
  - 推导公式行1右：`scene2-arrow-rtotal-up`
  - 选项A框：`scene2-option-a`
  - 按钮：`scene2-btn-prev`、`scene2-btn-next`
  - 获取元素时统一使用 `document.getElementById`，禁止 `querySelectorAll` 配合全局class，避免多场景合并时跨场景污染。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，不暴露全局变量（除必要的DOM事件绑定外）。
- 配色CSS变量（可选）：在 `<style>` 中定义 `:root { --scene2-red: #c62828; --scene2-blue: #1565c0; --scene2-green: #2e7d32; }`，便于维护。
