[图示主题与整合说明]
- 本图示主题：物质跨膜运输方式分类概念树
- 整合的步骤/概念：
  1) 概念树整体结构还原（根节点→一级分支→二级分支→示例框）；
  2) 序号①②③④的生物学含义标注（①主动运输、②协助扩散、③葡萄糖进入红细胞、④小肠上皮细胞吸收葡萄糖）；
  3) 三种运输方式（自由扩散、协助扩散、主动运输）的核心特征归纳（浓度梯度方向、载体需求、能量消耗）；
  4) 四个选项的正误判断与错误原因高亮。
- 教学价值：教师通过分步展开概念树，由整体到局部逐步建立知识框架；在特征对比步骤中强化三种方式的区别；最后通过选项判断检验学生理解，并直观展示错误选项的问题所在。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「◀ 上一步」按钮：位置(280,456)，大小90×28。点击后回退到上一个步骤，隐藏当前步骤新增的元素，支持教师随时回退复习。
  2. 「下一步 ▶」按钮：位置(430,456)，大小90×28。点击后前进到下一个步骤，触发新元素的淡入/滑入动画。
  3. 步骤指示器：位置(400,494)。显示当前步骤编号（如"步骤 3 / 6"），帮助教师掌握讲解进度。
- 教师操作流程：
  1. 课堂开始时展示步骤0（仅根节点），口述"今天我们来梳理物质跨膜运输方式"。
  2. 点击「下一步」进入步骤1，引导学生观察一级分支，提问"①代表什么运输方式？"（答案：主动运输）。
  3. 点击「下一步」进入步骤2，继续展开被动运输的子分支，提问"②代表什么？"（答案：协助扩散），并指出③④是待填的示例框。
  4. 点击「下一步」进入步骤3，三个特征标签弹出，教师带领学生逐行对比三种方式的异同（浓度梯度方向、载体、能量）。
  5. 点击「下一步」进入步骤4，示例框填充完整，教师强调"葡萄糖进入红细胞是协助扩散，小肠上皮细胞吸收葡萄糖是主动运输"——这是学生最容易混淆的点。
  6. 点击「下一步」进入步骤5，展示四个选项，教师先让学生独立思考，然后公布正确答案B，并用红色高亮讲解A/C/D的错误原因（A错在协助扩散不耗能；C错在大分子通过胞吞胞吐；D错在小肠上皮细胞吸收葡萄糖是主动运输①而非协助扩散②）。

[技术实现]
- JS库选择：原生 SVG + 原生 JavaScript。原因：本场景为静态树状结构的分步展示，无复杂绘图、无数据驱动、无3D，原生SVG足以高效实现，且便于教师直接嵌入课件系统。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +----------------------------------------------------------+
  |                    [物质跨膜运输方式]                      |  y=27~63
  |                          /    \                          |
  |                         /      \                         |
  |              [被动运输]        [①主动运输]               |  y=102~138
  |               /      \              |                    |
  |              /        \             |                    |
  |    [自由扩散]  [②协助扩散]        [④]                  |  y=182~218
  |       |          |                  |                    |
  |  [氧气进入红]   [③]             [小肠上皮...]           |  y=262~298
  |   [特征标签]  [特征标签]        [特征标签]               |  y=175~245
  |                                                          |
  |  [选项A] [选项B] [选项C] [选项D]                         |  y=355~420
  |                                                          |
  |        [◀ 上一步]    [下一步 ▶]                          |  y=456~484
  |                    步骤 1 / 6                            |  y=494
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `currentStep`（0~5），每个状态对应一组元素的 `display`/`opacity` 配置。点击按钮时更新状态并调用 `renderStep()`。
  2. 元素显隐控制：所有步骤相关元素初始 `opacity: 0` 或 `visibility: hidden`。进入某步骤时，通过添加/移除 CSS class（如 `.scene1-visible`）触发 `transition: opacity 0.3s ease, transform 0.3s ease` 动画。
  3. 动画曲线：
     - 节点出现：`opacity 0→1`，`translateY(-8px)→translateY(0)`，duration 300ms。
     - 连线出现：`opacity 0→1`，duration 250ms，delay 100ms（晚于节点）。
     - 特征标签弹出：`scale(0.9)→scale(1)`，`opacity 0→1`，duration 300ms。
     - 选项滑入：`translateY(15px)→translateY(0)`，`opacity 0→1`，duration 350ms，stagger 80ms。
  4. 文本内容切换：③④示例框的文字在步骤4时通过 JS 修改 `textContent`，同时移除虚线边框 class、添加实线边框 class。
  5. 选项高亮：步骤5时给选项B添加 `.scene1-correct` class（蓝色背景），给A/C/D添加 `.scene1-incorrect` class（红色背景）。关键词高亮通过内部 `<tspan>` 的 `fill` 和 `font-weight` 属性实现。
  6. 事件绑定：上一步/下一步按钮绑定 `click` 事件，更新 `currentStep` 后边界检查（0 ≤ step ≤ 5），然后调用渲染函数。
- ID命名规范：所有 SVG 元素及 JS 变量 ID 必须以 `scene1-` 为前缀。例如：`scene1-root-box`、`scene1-root-text`、`scene1-passive-box`、`scene1-active-box`、`scene1-free-box`、`scene1-assisted-box`、`scene1-oxygen-box`、`scene1-ex3-box`、`scene1-ex3-text`、`scene1-ex4-box`、`scene1-ex4-text`、`scene1-feature-free`、`scene1-feature-assisted`、`scene1-feature-active`、`scene1-option-a`、`scene1-option-b`、`scene1-option-c`、`scene1-option-d`、`scene1-btn-prev`、`scene1-btn-next`、`scene1-step-indicator`。
- IIFE隔离：所有 JavaScript 代码包裹在 `(function() { ... })()` 中，避免多场景合并时的全局变量污染。
