[图示主题与整合说明]
- 本图示主题：三种跨膜运输方式的细胞膜截面机制对比
- 整合的步骤/概念：
  1. 自由扩散（氧气过膜）：顺浓度梯度、不需载体、不耗能
  2. 协助扩散（葡萄糖进红细胞）：顺浓度梯度、需要载体、不耗能
  3. 主动运输（葡萄糖进小肠上皮细胞）：逆浓度梯度、需要载体、消耗ATP
- 教学价值：教师可在同一膜结构背景下，通过底部三按钮快速切换三种运输方式，引导学生从"浓度梯度方向""载体参与""能量消耗"三个维度进行对比，强化对被动运输与主动运输本质区别的理解。右侧信息面板实时同步当前状态的三个判别维度，便于学生建立知识框架。

[视觉元素清单]
- 磷脂双分子层：由上下两层亲水头部（浅蓝圆 #90caf9，r=8，描边黑）和向内延伸的疏水尾部（#888888虚线）构成，横向贯穿主图区中央（x=50~490），形成膜屏障。
- 膜外/膜内区域：以脂双层为界，上方为膜外，下方为膜内，分别标注文字。
- 氧气分子（状态1）：蓝色小圆点 #1565c0，r=6，膜外15个、膜内5个，体现顺浓度梯度。
- 葡萄糖分子（状态2/3）：绿色圆点 #2e7d32，r=8，数量分布体现浓度差（状态2膜外多膜内少；状态3膜外少膜内多）。
- 载体蛋白（状态2/3）：橙色跨膜结构 #ed6c02，中心(280,230)，垂直椭圆rx=22,ry=48，位于脂双层中央。
- ATP/ADP+Pi（状态3）：ATP为红色星形 #c62828（30×30），位于膜内侧载体旁；水解后变为ADP（小星形20×20）和Pi（小圆r=6）。
- 浓度梯度背景：高浓度侧用对应分子颜色的10%透明度填充整个半区（膜外或膜内），低浓度侧无填充。
- 运输方向箭头：位于主图区右侧x=480，纵向箭头指示物质移动方向；状态1/2为绿色，状态3为红色。
- 信息面板：右侧固定区域，含标题+三个维度卡片，卡片内文字颜色根据状态变化（绿色表示"顺/不需要/不消耗"，红色表示"逆/需要/消耗ATP"）。
- 配色沿用规格：背景#fff、主线#000、蓝#1565c0、绿#2e7d32、红#c62828、辅助线#888、填充透明度20%（实际使用10%避免过浓）。

[分步序列]
本场景为"多状态切换"交互，共3个状态，无时间序列步骤。教师通过底部按钮随时切换，反复对比。

- 状态1（自由扩散）——初始默认状态：
  * 显示元素：磷脂双分子层、膜外/膜内标签、氧气分子群（膜外15个蓝色小圆+膜内5个）、O₂标签、膜外高浓度背景（蓝10%透明度）、膜内低浓度无填充、绿色向下运输箭头、信息面板标题"自由扩散"。
  * 信息面板维度值："顺浓度梯度"（绿色）、"不需要载体"（绿色）、"不消耗能量"（绿色）。
  * 按钮样式：按钮1激活（背景#1565c0，白字），按钮2/3非激活（背景#e0e0e0，黑字）。
  * 动画：1个氧气分子从膜外(300,120)缓慢直线穿过脂双层间隙，到达膜内(300,340)，循环往复，表示直接穿过。

- 状态2（协助扩散）：
  * 点击按钮2切换。氧气分子群、O₂标签、蓝色背景淡出；葡萄糖分子群（膜外12个绿色+膜内4个）、葡萄糖标签、载体蛋白、载体蛋白标签、膜外高浓度背景（绿10%透明度）淡入。
  * 信息面板标题变为"协助扩散（②）"；维度值："顺浓度梯度"（绿）、"需要载体"（绿）、"不消耗能量"（绿）。
  * 按钮样式：按钮2激活（背景#2e7d32，白字），其余非激活。
  * 动画：1个葡萄糖分子从膜外(300,120)移动到载体蛋白上端(280,190)，短暂停留后随载体构象变化（椭圆rx在22~28之间轻微缩放模拟构象改变）移动到载体下端(280,270)，再进入膜内(300,340)，循环往复。

- 状态3（主动运输）：
  * 点击按钮3切换。葡萄糖分子群重新分布（膜外4个+膜内12个），膜内高浓度背景（绿10%透明度）显示，膜外为低浓度。ATP图标、ATP标签、ADP+Pi图标及标签显示。运输箭头变为红色。
  * 信息面板标题变为"主动运输（①）"；维度值："逆浓度梯度"（红色）、"需要载体"（红色）、"消耗ATP"（红色）。
  * 按钮样式：按钮3激活（背景#c62828，白字），其余非激活。
  * 动画：1个葡萄糖分子从膜外(300,120)移动到载体上端；同时ATP图标闪烁一次后分裂为ADP+Pi（ATP透明度降为0，ADP和Pi透明度升为1，并向下微移5px表示能量释放）；载体构象变化将葡萄糖运送到膜内(300,340)；循环往复。

[交互方案]
- 交互类型：多状态切换（3个状态按钮）
- 控件说明：
  1. 按钮"自由扩散"：位置(60,450)，宽200高36。点击切换到状态1，展示氧气自由扩散过程。
  2. 按钮"协助扩散（②）"：位置(300,450)，宽200高36。点击切换到状态2，展示葡萄糖经载体顺浓度梯度运输。
  3. 按钮"主动运输（①）"：位置(540,450)，宽200高36。点击切换到状态3，展示葡萄糖经载体逆浓度梯度运输并消耗ATP。
- 教师操作流程：
  1. 教师先讲解状态1（自由扩散），让学生观察氧气直接穿过磷脂双分子层，确认右侧三个维度均为"不需要/不消耗/顺梯度"。
  2. 点击按钮2切换到协助扩散，引导学生对比：同样是顺梯度、不耗能，但多了载体蛋白参与。提问：为什么葡萄糖不能直接穿过？
  3. 点击按钮3切换到主动运输，引导学生重点观察浓度梯度方向反转（膜内高、膜外低），以及ATP水解供能。提问：如果没有ATP，葡萄糖还能逆梯度进入吗？
  4. 反复点击三个按钮，让学生快速对比三种方式在三个维度上的差异，完成知识框架建构。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：本场景以静态几何图形和简单状态切换为主，无需复杂数据绑定或3D渲染。原生SVG可精确控制每个分子、载体、标签的显隐与位置，性能足够，且避免引入不必要的外部依赖。
- 画布尺寸：800×500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------------+
  |                    [场景标题]                            |  y=0~40
  |  [膜外]                                    [信息面板]    |  
  |   ······O₂  高浓度                        +----------+  |  y=50~180
  |   ·  ·  ·                                 | 标题     |  |  膜外区
  |  =============== 脂双层 ================== | 浓度梯度 |  |  y=180~280
  |   ·  ·  ·                                 | 载体蛋白 |  |  膜区
  |   ······葡萄糖  低浓度                    | 能量     |  |  y=280~420
  |   [膜内]                       [载体]     +----------+  |  膜内区
  |                                            [ATP/ADP]   |  
  |  [自由扩散] [协助扩散（②）] [主动运输（①）]            |  y=440~490
  +--------------------------------------------------------+
  主图区x=20~520        信息面板x=540~780        控件区底部
  ```
- 关键实现要点：
  1. 状态机设计：定义state变量（1/2/3），切换时调用renderState(state)函数。该函数负责：
     - 设置所有元素的display属性（显隐）
     - 更新信息面板文字内容和颜色
     - 更新按钮激活样式（通过切换class）
     - 启动/停止对应状态的动画循环
  2. 动画实现：使用requestAnimationFrame + 时间戳计算。每个状态有独立的动画函数：
     - 状态1：氧气粒子从膜外直线运动到膜内，超出边界后重置。
     - 状态2：葡萄糖粒子移动到载体→停留→随载体缩放→移动到膜内。
     - 状态3：同状态2路径，但同步ATP透明度变化（1→0）和ADP+Pi透明度变化（0→1），并添加ADP/Pi向下微移。
  3. 载体构象变化：通过动态修改ellipse的rx属性（22→28→22）模拟开合，周期约800ms。
  4. 事件绑定：三个按钮分别绑定onclick，调用switchState(n)。使用IIFE隔离作用域。
  5. 过渡效果：分子群的显隐使用CSS transition opacity 300ms，避免突兀切换。背景色块同样使用opacity过渡。
  6. 分子位置：为避免每次切换重新计算，将三种状态的分子坐标分别预定义为数组（oxygenOut/free、glucoseOutFacil/glucoseInFacil等），在初始化时创建对应的SVG circle元素并设置好坐标，切换状态时只需控制display/opacity。
- ID命名规范：所有交互元素ID必须以`scene2-`为前缀。例如：
  - 按钮：scene2-btn-free、scene2-btn-facil、scene2-btn-active
  - 分子组：scene2-oxygens、scene2-glucoses-facil、scene2-glucoses-active
  - 载体：scene2-carrier
  - ATP：scene2-atp、scene2-adp、scene2-pi
  - 信息面板：scene2-panel-title、scene2-val-gradient、scene2-val-carrier、scene2-val-energy
  - 动画粒子：scene2-anim-particle
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免多场景合并时的变量污染。
- 容器要求：SVG的viewBox="0 0 800 500"，preserveAspectRatio="xMidYMid meet"。控件按钮使用HTML div绝对定位叠加在SVG容器上（bottom:10px），不占用SVG内部空间，但视觉上位于y=440~490区域。
