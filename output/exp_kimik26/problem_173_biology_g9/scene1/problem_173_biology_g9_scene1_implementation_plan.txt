[图示主题与整合说明]
- 本图示主题：自然界碳循环简图中生态系统成分（生产者、消费者、分解者）的判定与生理过程标注
- 整合的步骤/概念：
  1. 原图框架展示（甲、乙、丙与大气CO₂的位置及箭头关系）
  2. 生产者判定（甲与大气双向交换）
  3. 消费者判定（丙以甲为食，呼吸作用释放CO₂）
  4. 分解者判定（乙接收甲和丙的碳，分解作用归还大气）
  5. 各箭头生理过程名称完整标注
  6. 正确答案呈现与选项对比
- 教学价值：教师通过分步导航，引导学生从箭头方向关系逐步推断甲、乙、丙的生态系统成分，建立碳循环概念模型。每一步聚焦一个判定突破口，符合逻辑递进的认知顺序，支持随时回退复习。

[分步序列]
- 步骤0（初始状态）：展示原图框架。大气节点（浅蓝底）、甲/乙/丙节点（白底黑框），显示全部7条箭头但不标注生理过程。所有节点等权重显示，无高亮。隐藏所有标签（除节点内文字）。
- 步骤1（判定生产者）：聚光灯效果——甲节点高亮（绿底绿框），甲↔大气的双向箭头高亮（绿色，线宽3px）。其余所有节点和箭头透明度降至30%。显示提示文字"甲与大气存在双向碳交换：吸收CO₂（光合作用）、释放CO₂（呼吸作用）→ 确定甲为生产者"。显示"生产者"标签于甲节点正下方(200,265)。
- 步骤2（判定消费者）：聚光灯效果——丙节点高亮（红底红框），甲→丙弧形箭头高亮（红色，线宽3px），丙→大气箭头高亮（红色，线宽3px）。其余元素透明度降至30%。显示提示文字"丙直接以甲为食，并通过呼吸作用向大气释放CO₂ → 确定丙为消费者"。显示"消费者"标签于丙节点正下方(600,265)。
- 步骤3（判定分解者）：聚光灯效果——乙节点高亮（灰底灰框），甲→乙箭头高亮（灰色，线宽3px），丙→乙箭头高亮（灰色，线宽3px），乙→大气箭头高亮（灰色，线宽3px）。其余元素透明度降至30%。显示提示文字"乙分解动植物遗体，将有机物中的碳以CO₂形式归还大气 → 确定乙为分解者"。显示"分解者"标签于乙节点正下方(400,265)。
- 步骤4（完整标注）：取消聚光灯，所有节点恢复对应颜色（甲绿、乙灰、丙红），所有箭头恢复普通线宽（1.5px）和黑色。在箭头旁标注生理过程：大气→甲旁标注"光合作用"(250,140)，甲→大气旁标注"呼吸作用"(330,140)，乙→大气旁标注"分解作用"(430,140)，丙→大气旁标注"呼吸作用"(530,165)，甲→丙弧形下方标注"摄食"(400,300)。三个身份标签（生产者、消费者、分解者）保持显示。
- 步骤5（得出结论）：保持步骤4的完整概念图。在图示下方(y=340~406)呈现四个选项A/B/C/D。正确答案A高亮显示（绿色文字或绿色背景），其余选项为普通灰色。选项文字：A. 甲为生产者，乙为分解者，丙为消费者；B. 甲为消费者，乙为分解者，丙为生产者；C. 甲为分解者，乙为生产者，丙为消费者；D. 甲为生产者，乙为消费者，丙为分解者。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于(300,460)，宽90px，高32px。点击回退到上一分步，第一步时禁用（opacity: 0.5）。
  - 「下一步」按钮：位于(410,460)，宽90px，高32px。点击前进到下一分步，最后一步时禁用。
  - 步骤指示器：位于两按钮上方居中(400,455)，显示当前步骤编号，如"1 / 6"。
- 教师操作流程：
  1. 教师打开图示，初始状态（步骤0）展示完整碳循环框架，让学生观察甲、乙、丙与大气间的箭头关系。
  2. 点击「下一步」进入步骤1，聚焦甲节点与双向箭头，提问"谁能吸收大气中的CO₂？"引导学生得出甲是生产者。
  3. 继续点击「下一步」进入步骤2，聚焦丙节点与摄食/呼吸箭头，判定消费者。
  4. 继续点击「下一步」进入步骤3，聚焦乙节点与分解箭头，判定分解者。
  5. 步骤4展示完整生理过程标注，建立概念图。
  6. 步骤5呈现四个选项，高亮正确答案A，完成讲解。
  7. 讲解过程中可随时点击「上一步」回退，重新聚焦某个判定突破口。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：本场景为静态几何图示与分步状态切换，无复杂动画或数据可视化，原生SVG足以高效绘制节点、箭头、标签，且无需引入外部库，加载轻量、可控性强。
- 画布尺寸：800 × 500 px（固定画布，控件栏位于SVG内底部y=440~490区域）
- 布局草图（ASCII）：
  ```
  y=0    +------------------------------------------------+
         |                                                |
         |           [大气中的二氧化碳]                   |
         |              (325,40-475,80)                   |
         |           /    |    \                         |
         |    光合作用    |     呼吸作用(丙)              |
         |         /      |      \                       |
         |        /   分解作用    \                      |
         |       /        |        \                     |
         |    [甲] -----> [乙] <----- [丙]               |
         |   (150,200)  (350,200)  (550,200)             |
         |      |          |          |                  |
         |   生产者     分解者      消费者               |
         |      |          |          |                  |
         |       \_________|_________/                   |
         |            摄食                               |
         |                                                |
         |    A. 甲生产者,乙分解者,丙消费者               |
         |    B. ...                                      |
         |    C. ...                                      |
         |    D. ...                                      |
         |                                                |
         |       [上一步]  步骤  [下一步]                 |
         |       (300,460)      (410,460)                 |
  y=500  +------------------------------------------------+
  ```
- 关键实现要点：
  1. **状态机设计**：维护变量 `currentStep`（0~5）。每一步通过一个配置对象定义：哪些元素高亮、哪些元素淡化、哪些标签显示、提示文字内容。切换步骤时统一应用class。
  2. **聚光灯效果**：使用CSS class `.dimmed { opacity: 0.3; transition: opacity 0.3s; }` 和 `.highlight { stroke-width: 3px; transition: stroke-width 0.3s; }`。非目标元素添加dimmed，目标元素添加highlight。
  3. **箭头绘制**：在SVG `<defs>` 中定义 `<marker>` 箭头头部（id="scene1-arrowhead"），所有path通过 `marker-end="url(#scene1-arrowhead)"` 添加箭头。双向箭头由两条独立path实现，各带一个marker。
  4. **弧形箭头**：甲→丙使用 `<path d="M 200 240 Q 400 320 600 240" />`，箭头marker指向终点方向。
  5. **标签显隐**：所有过程标签、身份标签、选项标签初始 `display: none` 或 `visibility: hidden`，在对应步骤通过JS切换为可见。
  6. **按钮状态**：第一步时禁用「上一步」，最后一步时禁用「下一步」，通过设置 `disabled` 属性和CSS样式反馈。
  7. **动画曲线**：状态切换使用CSS transition（opacity 0.3s ease, stroke-width 0.3s ease），营造平滑的聚光灯转移效果。
  8. **事件绑定**：按钮点击事件直接绑定在DOM元素上，更新currentStep后调用 `renderStep()` 函数重绘状态。
- **ID命名规范**：所有SVG元素及交互控件ID必须以 `scene1-` 为前缀。例如：`scene1-atmosphere-node`、`scene1-arrow-jia-atm`、`scene1-label-photosynthesis`、`scene1-btn-prev`、`scene1-btn-next`。JS中严格使用 `document.getElementById` 获取元素，禁止跨场景选择器。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免全局变量污染，确保多场景合并时互不干扰。
