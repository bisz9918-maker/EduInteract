[图示主题与整合说明]
- 本图示主题：抑制性递质作用机制与突触后膜受体（对应题目选项③④）
- 整合的步骤/概念：
  1) 正常状态下B神经元受刺激可产生兴奋并向下传递；
  2) A与B同时受刺激时，A释放抑制性递质，与B突触后膜受体结合；
  3) B突触后膜发生超极化，兴奋被阻断，C不兴奋；
  4) 突触后膜受体放大展示，揭示其化学本质为糖蛋白（Y形蛋白质+外侧糖链）。
- 教学价值：教师通过分步导航，由表及里地引导学生理解"抑制性递质阻断突触传递"的功能现象，再深入到分子层面的受体结构，建立结构与功能相适应的生命观念。

[分步序列]
- 步骤0（初始状态/静息）：显示左侧A→B突触完整结构（A轴突、A突触小体及内部蓝色小泡、突触前膜、突触间隙、突触后膜、B细胞体、B轴突）；显示左右两侧虚线框，右侧框内仅显示灰色标题"突触后膜局部放大（待展示）"；显示静态标签（A、B、突触前膜、突触间隙、突触后膜）。
- 步骤1（仅刺激B，正常兴奋）：在步骤0基础上，B轴突上方出现黄色电位脉冲（闪电波形），表示B产生动作电位可正常向下传递；新增标签"兴奋传递"。
- 步骤2（A、B同时受刺激，A释放抑制性递质）：保留步骤1元素；A突触小泡释放3个红色抑制性递质小圆，通过SVG animate从A小体底部（y≈150）下落到突触间隙（y≈175）；新增标签"抑制性递质"。
- 步骤3（抑制性递质结合，B超极化，兴奋阻断）：红色递质到达突触后膜并停留；突触后膜上方出现蓝色半透明覆盖层表示超极化；B轴突上黄色脉冲消失，出现红色阻断符号（禁止圆圈）；新增标签"超极化"、"兴奋被阻断"。
- 步骤4（受体分子结构放大）：左侧图保持步骤3最终状态但适当降低透明度（0.4）作为背景；右侧虚线框高亮，内部显示磷脂双分子层（波浪线+浅蓝填充）、Y形受体蛋白、橙色糖链；新增标签"受体"、"糖链"、"糖蛋白"、"细胞内"；用虚线从受体指向"糖蛋白"标签。

  2. 「下一步」按钮：位置(460,455)-(540,485)，圆角矩形，蓝色背景，点击推进到下一状态；

- 教师操作流程：

  2. 点击「下一步」进入步骤1，说明仅刺激B时兴奋可正常传递；
  3. 点击「下一步」进入步骤2，展示A释放抑制性递质（红色）进入间隙；
  4. 点击「下一步」进入步骤3，讲解递质与受体结合后B发生超极化，兴奋被阻断，因此C不兴奋；

  6. 可随时点击「上一步」回退复习。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本场景以静态几何图形和分步显示/隐藏为主，递质下落动画可用SVG原生<animate>或CSS transition实现，无需引入外部重型库。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +----------------------------------------------------------+
  |  左侧虚线框(35,55-385,405)    |  右侧虚线框(415,55-765,405)|
  |                               |                            |
  |      A轴突                    |    [步骤4显示]              |
  |       |                       |    ~~~~~~~~~~ 突触间隙       |
  |    (A小体) 突触前膜            |         |Y|   受体          |
  |    ○○○○○                      |        / \   糖链          |
  |    --------                   |    ~~~~~~~~~~ 细胞内         |
  |    突触间隙                    |                            |
  |    --------                   |                            |
  |    突触后膜                    |                            |
  |    [B细胞体]                  |                            |
  |       |→B轴突                 |                            |
  |                               |                            |
  +----------------------------------------------------------+
  |        [上一步]    步骤 0/4    [下一步]                    |
  |        (260,455)   (380,472)   (460,455)                  |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：维护变量`currentStep`（0~4），每步对应一个SVG `<g>`分组（id如`scene3-step0-group`），通过设置`display`属性控制显隐；
  2. 步骤0~3的左侧图与步骤4的右侧图：步骤4时左侧组整体设置`opacity:0.4`作为背景，右侧组`opacity:1`高亮显示；
  3. 递质释放动画：步骤2的3个红色小圆使用SVG `<animateTransform>`或CSS `@keyframes`实现从y=150到y=175的下落，时长800ms，ease-out；
  4. 超极化覆盖层：步骤3使用SVG `<path>`绘制突触后膜上方弧面，通过CSS `transition: opacity 0.5s`淡入；
  5. 按钮事件：为「上一步」「下一步」绑定click事件，更新`currentStep`后调用`renderStep()`，在函数内遍历各step-group设置显隐；
  6. 边界处理：当currentStep=0时禁用「上一步」，currentStep=4时禁用「下一步」。
- ID命名规范：所有交互元素ID必须以`scene3-`为前缀，例如：`scene3-synapse-a-axon`、`scene3-receptor-y-shape`、`scene3-btn-prev`、`scene3-btn-next`、`scene3-step0-group`等；JS中严格使用`document.getElementById`获取元素，禁止全局class选择，避免多场景合并时跨场景污染。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，对外不暴露任何全局变量。
