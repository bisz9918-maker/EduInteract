[视觉元素清单]
- 分类树框架：10条折线（polyline）连接所有节点；节点分为矩形框（分类标准）与圆形框（末端编号①②③④）。
- 类群名称标签：4个纯文本标签，步骤1时依次淡入（opacity 0→1，每项延迟150ms）。
- 分支高亮：步骤1时，对当前聚焦的末端节点（①/②/③/④）施加蓝色#1565c0填充（circle r=18，fill-opacity 0.2，stroke #1565c0，stroke-width 3），并同步将该节点到根节点路径上的所有连线设为stroke #1565c0、stroke-width 4。四个节点依次高亮，每个持续700ms，间隔250ms。
- 特征对比卡片：4个圆角矩形（rx=4），背景#f5f5f5，边框#000000 1px。卡片内分三行文本（结构特征/生活环境/繁殖方式），标题16px bold，内容12px。步骤2时整体opacity 0→1（transition 0.5s）。讲解某一类群时，对应卡片边框变为#1565c0、宽度3px（依次高亮，与步骤1顺序一致）。
- 选项辨析区：4个矩形框，步骤3时从下方滑入（transform translateY(20px)→0，opacity 0→1，transition 0.4s）。A框边框/背景绿#2e7d32（背景透明度10%）；B/C/D框边框/背景红#c62828（背景透明度10%）。错误选项框内第二行以11px红色文字标注错误原因：B框内标注"错误：'只能'过于绝对，藻类也可生活在潮湿环境"；C框内标注"错误：'都'不准确，蕨类可长得高大"；D框内标注"错误：类群错位，③蕨类有真正的根"。
- 配色沿用：背景#ffffff；树线#000000 2px；蓝高亮#1565c0；绿#2e7d32；红#c62828；辅助虚线#888888（本scene中用于错误选项框内错误关键词下方的虚线装饰）；卡片背景#f5f5f5；文字#000000。

[分步序列]
- 步骤0（初始状态）：显示完整分类树（全部节点+连线+节点标签），不显示类群名称、特征卡片、选项区。控件栏显示"下一步"。
- 步骤1（类群判定）：
  1. 在①右侧显示"裸子植物"，①节点蓝高亮（circle放大+蓝色填充），根→①路径加粗变蓝，持续700ms；
  2. 在②右侧显示"藻类植物"，②节点蓝高亮，根→②路径加粗变蓝，持续700ms；
  3. 在③右侧显示"蕨类植物"，③节点蓝高亮，根→③路径加粗变蓝，持续700ms；
  4. 在④右侧显示"苔藓植物"，④节点蓝高亮，根→④路径加粗变蓝，持续700ms；
  5. 高亮结束后所有末端节点保持浅蓝填充（fill-opacity 0.15）作为已学标记。
- 步骤2（特征对比）：右侧2×2卡片网格淡入。随后依次将藻类/苔藓/蕨类/裸子卡片边框蓝高亮（每项800ms），帮助学生将分类位置与特征关联。
- 步骤3（选项辨析）：底部选项区滑入。A框绿色标记正确；B/C/D框红色标记错误，并在各自框内第二行以红色小字标注错误原因。教师可指向各选项，结合左侧分类树与右侧卡片讲解错因。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于(300,455)，宽80×高30，点击回退到上一分步，步骤0时禁用（opacity 0.4）。
  - 「步骤指示器」：位于(390,470)，显示"步骤 1/4"样式文本，随状态更新。
  - 「下一步」按钮：位于(440,455)，宽80×高30，点击进到下一分步，步骤3（最后一步）时变为「完成」或禁用。
- 教师操作流程：
  1. 教师打开图示，学生看到完整分类树，建立整体印象；
  2. 点击「下一步」，依次观察四个末端节点蓝高亮与类群名称出现，确认①②③④分别对应哪类植物；
  3. 点击「下一步」，右侧卡片出现，教师可结合卡片内容逐一提问"藻类有无输导组织？""蕨类靠什么繁殖？"；
  4. 点击「下一步」，选项区滑入，教师带领学生用排除法分析：A正确，B错在"只能"，C错在"都"，D错在把苔藓特征安到蕨类上。随时可点「上一步」回退到特征卡片或分类树复习。

[技术实现]
- JS库选择：原生 SVG + 原生 JavaScript（无外部库）。理由：本场景以静态树状图、矩形卡片和文本为主，动画仅为淡入/滑入/边框色切换，原生JS与CSS transition即可满足，无需引入D3等重型库。
- 画布尺寸：800 × 500 px（固定SVG viewBox="0 0 800 500"）。
- 布局草图（ASCII）：
  ```
  +----------------------------------------------------------+
  |                     无果实植物                           |
  |            _________|_________                           |
  |           |                   |                          |
  |        无种子              有种子                        |
  |       /     \                |                           |
  |   无茎叶   有茎叶            ① 裸子植物                  |
  |      |    /     \                                        |
  |      ② 有输导 无输导    [藻类卡片] [苔藓卡片]            |
  |    藻类  组织   组织                                     |
  |            |     |      [蕨类卡片] [裸子卡片]            |
  |            ③     ④                                     |
  |          蕨类   苔藓                                     |
  |                                                          |
  | [A正确..] [B错误..]    <- 步骤3选项区（2×2）             |
  | [C错误..] [D错误..]                                      |
  |                                                          |
  |        [上一步] 步骤X/4 [下一步]   <- y=440~490控件栏    |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机：用变量 `let currentStep = 0;` 控制0~3四步。`goToStep(n)` 函数先隐藏所有步骤专属元素（类群名称、卡片、选项区），再按n值显示对应元素并触发动画。
  2. 步骤1依次高亮：使用 `async/await` 或 Promise 链控制时序。定义 `highlightBranch(endId, labelId, pathIds, delay)` 函数，在指定delay后给末端circle添加 `.highlight-blue` 类（CSS定义 fill: rgba(21,101,192,0.2); stroke: #1565c0; stroke-width: 3;），同时给路径polyline添加 `.path-highlight` 类（stroke: #1565c0; stroke-width: 4;）。四个分支按顺序调用，间隔250ms。
  3. 步骤2卡片淡入：给 `#scene1-cards-container` 设置 `opacity: 0; visibility: hidden;`，步骤2时移除隐藏态并添加 `.fade-in` 类（transition: opacity 0.5s ease）。卡片高亮同样使用async顺序控制。
  4. 步骤3选项滑入：给 `#scene1-options-container` 设置 `transform: translateY(20px); opacity: 0;`，步骤3时添加 `.slide-up` 类（transition: all 0.4s ease; transform: translateY(0); opacity: 1;）。
  5. 按钮状态：在 `goToStep` 内更新按钮 disabled 属性与样式。步骤0时上一步禁用，步骤3时下一步文字变为"完成"或禁用。
  6. 所有文字使用 SVG `<text>` 元素，中文设置 `font-family: "Microsoft YaHei", "PingFang SC", sans-serif;`。卡片内多行文本使用 `<foreignObject>` 嵌入 div，便于排版三行内容；或直接使用多个 `<text>` 元素纵向排列（推荐后者，避免foreignObject兼容性风险）。
- ID命名规范：所有交互元素ID必须以 `scene1-` 为前缀。示例：
  - 节点：`scene1-tree-root`、`scene1-tree-node-seedless`、`scene1-tree-node-seed`、`scene1-tree-end-1`
  - 连线：`scene1-path-root-seedless`、`scene1-path-seedless-nostem`
  - 卡片：`scene1-card-algae`、`scene1-card-moss`、`scene1-card-fern`、`scene1-card-gymnosperm`
  - 选项：`scene1-option-a`、`scene1-option-b`、`scene1-option-c`、`scene1-option-d`
  - 控件：`scene1-btn-prev`、`scene1-btn-next`、`scene1-step-indicator`
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免多场景合并时全局变量污染。
