[图示主题与整合说明]
- 本图示主题：动脉血与静脉血的含氧量差异及选项正误判断
- 整合内容：基于"丝带扎紧上臂"实验现象，先通过含氧量条形图定性对比四段血管（①②③④）的血液含氧量，再切换到选项判断视图，逐一标注A/B/D错误原因并高亮正确选项C
- 教学价值：教师先用状态1引导学生建立"静脉血含氧低、动脉血含氧高"的直观认知，再切换到状态2进行选项辨析，强化"①④为静脉、②③为动脉"的核心结论

[分步序列]
本场景采用"多状态切换"交互，共2个状态，无步骤序列，通过底部按钮切换：

- 状态1（含氧量对比）——初始状态：
  - 显示标题"含氧量对比"
  - 显示四个横向含氧量指示条：①④为蓝色短条，②③为红色长条
  - 显示血管编号标签①②③④
  - 右侧显示图例：蓝色=静脉血（含氧低），红色=动脉血（含氧高）
  - 底部按钮"含氧量对比"为激活态（蓝色背景），"选项判断"为非激活态

- 状态2（选项判断）——点击"选项判断"按钮切换：
  - 隐藏状态1所有元素
  - 显示标题"选项判断"
  - 显示四个选项框A/B/C/D纵向排列
  - A/B/D旁显示红色"×"及错误原因
  - C框绿色高亮背景，旁显示绿色"√"及正确原因
  - 底部按钮"选项判断"为激活态（绿色背景），"含氧量对比"为非激活态

- 教师可随时点击按钮在两个状态间自由切换，配合讲解

[技术实现]
- JS库选择：原生SVG + 原生JavaScript（场景为静态图形切换，无需复杂绘图库）
- 画布尺寸：800×500 px（SVG固定尺寸）
- 布局草图：
  ```
  +--------------------------------------------------+
  |              [标题区 y=30~70]                      |
  |  状态1: "含氧量对比"    状态2: "选项判断"          |
  +--------------------------------------------------+
  |  [主图区 y=80~430]                                |
  |  状态1内容:                                        |
  |   左区: ①蓝短条 ②红长条 ③红长条 ④蓝短条         |
  |   右区: 图例(蓝=静脉低 红=动脉高)                  |
  |  状态2内容:                                        |
  |   A框 B框 C框(绿底) D框 纵向排列                   |
  |   每框含: 字母+文本+对错标记+原因                  |
  +--------------------------------------------------+
  |  [控件区 y=440~490]                               |
  |       [含氧量对比]  [选项判断]                     |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态管理：使用变量 `currentState`（1或2），点击按钮时更新状态并调用 `render()`
  2. SVG结构：使用两个 `<g>` 分组，id分别为 `scene2-state1` 和 `scene2-state2`，通过设置 `display` 属性控制显隐
  3. 按钮激活态：通过JS动态修改按钮class，切换背景色和文字色
  4. 所有SVG元素ID必须以 `scene2-` 为前缀，如 `scene2-bar-1`、`scene2-option-c` 等
  5. 选项框C的绿色背景使用 `fill="rgba(46,125,50,0.15)"` 实现半透明效果
  6. 对错标记使用大号粗体文本（font-size="20px", font-weight="bold"），√和×直接使用Unicode字符
  7. 所有文本使用 `dominant-baseline="middle"` 确保垂直居中
- ID命名规范：
  - 状态1组：scene2-state1-group
  - 状态2组：scene2-state2-group
  - 含氧条：scene2-bar-1, scene2-bar-2, scene2-bar-3, scene2-bar-4
  - 血管标签：scene2-label-1, scene2-label-2, scene2-label-3, scene2-label-4
  - 选项框：scene2-option-a, scene2-option-b, scene2-option-c, scene2-option-d
  - 按钮：scene2-btn-state1, scene2-btn-state2
- IIFE隔离：所有JS代码包裹在 `(function() { ... })()` 中，避免全局污染
