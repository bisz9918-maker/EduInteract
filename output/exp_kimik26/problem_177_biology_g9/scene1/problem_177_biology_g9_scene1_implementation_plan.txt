[图示主题与整合说明]
- 本图示主题：染色体、DNA、基因与蛋白质的层次关系及概念辨析
- 整合的步骤/概念：图甲结构解析（染色体/DNA/蛋白质标注）→ 成分区分（DNA蓝色高亮、蛋白质红色警示）→ 图乙包含关系展示（嵌套圆①②③）→ 图甲与图乙的概念对应映射（虚线箭头）→ 四个选项的正误判断（A错误标红、B/C/D正确标绿）
- 教学价值：教师通过分步导航控制课堂节奏，从直观结构到抽象关系再到选项辨析，形成清晰的认知递进；可随时回退强化关键概念（如蛋白质不含遗传信息、染色体⊃DNA⊃基因的包含逻辑）

[分步序列]
- 步骤1（基础结构/初始状态）：显示图甲全部元素（染色体[1]、DNA[2]、蛋白质[3]、DNA[4]）及对应标签[1][2][3][4]，图甲标题"图甲"显示；所有线条为黑色，蛋白质为浅灰；图乙、箭头、选项区均隐藏。教师引导学生观察染色体的化学组成结构。
- 步骤2（成分区分）：[2]双螺旋上线/下线及[4]两条平行线变为蓝色#1565c0（线宽加粗至2.5px）；[3]三个蛋白质椭圆填充变为#ffcdd2、描边变为#c62828（红色高亮警示）；在图甲下方出现说明文字"DNA（遗传信息的载体）"(200,255)和"蛋白质（不含遗传信息）"(200,270)。教师讲解染色体由DNA和蛋白质组成，强调遗传信息储存在DNA中。
- 步骤3（包含关系）：图乙三个嵌套圆①②③出现，标注标签①②③，图乙标题"图乙"显示；在图乙下方出现说明文字"染色体 ⊃ DNA ⊃ 基因"(600,255)。教师讲解三者的包含逻辑，引导学生推断各圆代表的概念。
- 步骤4（对应映射）：三条灰色虚线折线箭头出现——从[1]染色体右侧(230,150)经拐点(400,150)/(400,180)连至①左侧(505,180)；从[2]DNA右侧(300,160)经拐点(450,160)/(450,180)连至②左侧(538,180)；从"基因"标签(340,175)经拐点(480,175)/(480,180)连至③左侧(570,180)。图甲DNA链上方出现"基因"标签(340,175)。教师明确两图表达的是同一概念体系。
- 步骤5（选项辨析）：选项区背景及四个选项卡片出现——A卡片(红底红框)显示"A．图甲中的[3]和[4]都含有特定的遗传信息"，B/C/D卡片(绿底绿框)分别显示对应文本；步骤指示器更新为"(5/5)"。教师指出A错误（蛋白质[3]不含遗传信息），B/C/D正确，可回退至步骤2观察[3]的红色警示与A选项的对应关系。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「◀ 上一步」按钮：位置(280,465)，宽100高28，点击回退到上一步骤，步骤1时禁用（opacity:0.5，pointer-events:none）
  2. 「下一步 ▶」按钮：位置(420,465)，宽100高28，点击前进到下一步骤，步骤5时禁用
  3. 步骤指示器文本：位置(400,455)，显示当前步骤如"(1/5)"
- 教师操作流程：教师点击「下一步」依次展开成分区分高亮→包含关系图示→对应映射箭头→选项辨析；在任意步骤可点击「上一步」回退复习；讲解A选项错误时，可回退到步骤2让学生观察[3]蛋白质的红色高亮，建立"蛋白质不含遗传信息"的直观印象。

[技术实现]
- JS库选择：原生SVG（所有图形为简单几何形状、路径和文本，无需引入外部库，减少依赖）
- 画布尺寸：800 × 500 px（固定画布，SVG viewBox="0 0 800 500"）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |              染色体、DNA、基因关系示意图            |  y=10-40
  |                                                  |
  |   图甲                    图乙                    |  y=50-300
  |  +--------+            +--------+                 |
  |  | [1]X形 |            |   ①    |                 |
  |  |  DNA[2]| ~波浪线~   |  ②③   |                 |
  |  | 蛋白[3]|            | 嵌套圆  |                 |
  |  |  DNA[4]|            |        |                 |
  |  +--------+            +--------+                 |
  |                                                  |
  |  [选项辨析区：A(红) B(绿) C(绿) D(绿)]            |  y=310-440
  |                                                  |
  |        [◀ 上一步]  (1/5)  [下一步 ▶]             |  y=450-490
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：变量 `currentStep`（1~5），`renderStep()`函数根据currentStep设置各元素的display/opacity/stroke/fill属性；所有步骤切换通过修改class或style实现，不使用CSS动画保持简洁。
  2. 元素显隐控制：给每组元素设置data-step属性（如data-step="3"表示步骤3出现），renderStep()中统一遍历显示/隐藏。
  3. 高亮切换：步骤2时给[2][4]元素添加class "dna-highlight"（stroke:#1565c0, stroke-width:2.5），给[3]元素添加class "protein-warning"（fill:#ffcdd2, stroke:#c62828）。
  4. 虚线箭头：使用SVG `<path>` 配合 `stroke-dasharray="6,4"` 和 `<marker>` 定义箭头头部；初始状态 `display:none`，步骤4时显示。
  5. 选项卡片：使用 `<foreignObject>` 或SVG `<rect>` + `<text>` 实现；A卡片class "option-wrong"（红），B/C/D卡片class "option-correct"（绿）。
  6. 按钮禁用逻辑：步骤1时上一步按钮添加disabled类，步骤5时下一步按钮添加disabled类。
  7. 坐标计算：所有坐标为绝对像素坐标，直接写入SVG属性，不依赖动态计算。
- ID命名规范：所有交互元素ID必须以 `scene1-` 为前缀。例如：`scene1-chromosome-1`、`scene1-dna-2-top`、`scene1-dna-2-bottom`、`scene1-protein-3-1`、`scene1-protein-3-2`、`scene1-protein-3-3`、`scene1-dna-4-top`、`scene1-dna-4-bottom`、`scene1-circle-1`、`scene1-circle-2`、`scene1-circle-3`、`scene1-label-1`、`scene1-label-2`、`scene1-label-3`、`scene1-label-4`、`scene1-label-gene`、`scene1-label-circle-1`、`scene1-label-circle-2`、`scene1-label-circle-3`、`scene1-arrow-1-to-1`、`scene1-arrow-2-to-2`、`scene1-arrow-gene-to-3`、`scene1-option-a`、`scene1-option-b`、`scene1-option-c`、`scene1-option-d`、`scene1-btn-prev`、`scene1-btn-next`、`scene1-step-indicator`。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })()` 中，避免全局变量污染，确保多场景合并时互不干扰。
