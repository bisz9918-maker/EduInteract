[图示主题与整合说明]
- 本图示主题：比较吸入气与呼出气成分的实验装置及气体流向演示
- 整合的步骤/概念：
  1. 实验装置结构认知（试管1、试管2、石灰水、M管、夹子X/Y、左右导管）。
  2. 吸气过程演示：X开启、Y关闭，空气经试管1吸入，气体流向与气泡动画。
  3. 呼气过程演示：X关闭、Y开启，呼出气体经试管2排出，气体流向、气泡动画及石灰水变浑浊效果。
  4. 现象对比与结论：两试管状态对比，突出CO₂含量差异。
- 教学价值：教师通过分步导航控制课堂节奏，可逐帧演示吸气/呼气时气体流向、夹子开闭状态及石灰水变化，帮助学生建立"呼出气CO₂含量高于吸入气"的直观认知，并对应选择题选项C的正确性。

[分步序列]
- 步骤0（装置结构）：
  * 显示完整装置：试管1、试管2、M管、左右导管、石灰水（均澄清）
  * 所有部件名称标签显示（试管1、试管2、石灰水、M、夹子X、夹子Y）
  * 虚线标注线连接标签与对应部件
  * 夹子X和Y均为灰色（初始未激活）
  * 无气体箭头、无气泡、无动态标签
  * 底部仅「下一步」可点击，「上一步」禁用（opacity 0.4）

- 步骤1（吸气过程）：
  * 点击「下一步」触发
  * 夹子X变为绿色（开启状态），夹子Y保持红色（关闭状态）
  * 左侧导管外出现绿色箭头（空气流入），标注"空气"显示
  * 试管1内出现绿色气泡上升动画（从y=350向y=260上升，循环生成）
  * M管左段出现绿色箭头（从试管1方向指向M接口，x=210→x=380）
  * 试管1石灰水保持澄清
  * 强调：空气中CO₂极少，石灰水不变浑浊
  * 「上一步」「下一步」均可点击

- 步骤2（呼气过程）：
  * 点击「下一步」触发
  * 夹子X变为红色（关闭状态），夹子Y变为绿色（开启状态）
  * 步骤1的绿色箭头、气泡、"空气"标签隐藏
  * M管右段出现红色箭头（从M接口指向试管2，x=420→x=590）
  * 试管2内出现红色气泡上升动画（从y=350向y=260上升，循环生成）
  * 右侧导管外出现红色箭头（呼出气排出），标注"呼出气"显示
  * 试管2石灰水开始渐变浑浊（颜色从#1565c0过渡到#b09090，同时白色沉淀颗粒逐渐显现）
  * 强调：呼出气中CO₂使石灰水变浑浊
  * 「上一步」「下一步」均可点击

- 步骤3（现象对比与结论）：
  * 点击「下一步」触发
  * 停止所有气泡动画，保持步骤2的静态视觉（X红关、Y绿开、试管2浑浊）
  * 试管1旁显示"澄清"标签（绿色文字），试管2旁显示"浑浊"标签（红色文字）
  * 画布顶部显示结论文字："呼出气中CO₂含量 > 吸入气中CO₂含量"
  * 结论文字上方显示选项C高亮："C．X关闭，Y开启，试管1澄清，试管2浑浊"
  * 所有箭头保持静态显示（红色呼气箭头保留，绿色吸气箭头仍隐藏）
  * 「下一步」变为「重新开始」，点击后回到步骤0
  * 「上一步」可回退到步骤2

  2. 点击「下一步」进入步骤1，讲解吸气过程：观察X开启（绿）、Y关闭（红），空气经试管1流入，石灰水保持澄清

  4. 点击「下一步」进入步骤3，总结现象对比，强调呼出气CO₂更多，对应选项C正确
  5. 可随时点击「上一步」回退复习关键步骤

[技术实现]
- JS库选择：原生SVG + 原生JavaScript（无外部库）。理由：本场景为2D静态几何装置+简单气泡动画，SVG的path/line/circle/text足以表达所有视觉元素，无需引入D3/Canvas等重型库，保持代码轻量且易于教师直接嵌入课件。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------------+
  |  [选项C高亮 y=28]  [结论文字 y=50]                      |
  |                                                        |
  |  空气入口(120,105)                    呼出气出口(670,105)|
  |       |                                        |       |
  |       v                                        v       |
  |  [左导管]  [夹子X](260,70)  [M管+M](400,68)  [夹子Y](540,70) [右导管] |
  |       |        |              |              |        |       |
  |       |   +----+--------------+--------------+----+   |       |
  |       |   |                                       |   |       |
  |    [试管1]                                     [试管2]       |
  |    |    |     澄清(245,220)    浑浊(555,220)    |    |       |
  |    |    |                                       |    |       |
  |    +----+                                       +----+       |
  |    石灰水(400,325)                                石灰水      |
  |                                                        |
  |              [控件栏 y=450-490]                         |
  |           [◀ 上一步]    [下一步 ▶]                      |
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量`currentStep`（0-3）管理当前步骤，每个步骤对应一个`renderStep()`函数，负责显示/隐藏对应元素、更新颜色、启停动画。
  2. 气泡动画：使用`requestAnimationFrame`实现。为每个气泡对象维护{x, y, r, speed}状态，每帧更新y坐标（y -= speed），当y < 260（液面）时重置到y=350并随机化x偏移（导管中心±5px）。步骤1仅在试管1生成绿色气泡，步骤2仅在试管2生成红色气泡，步骤3停止生成并隐藏所有气泡。
  3. 颜色过渡：石灰水变浑浊使用JS插值。在步骤2进入时，启动一个持续1.5s的动画，将试管2石灰水的RGB从(21,101,192)插值到(176,144,144)，同时逐步显示白色沉淀颗粒（通过递增颗粒元素的opacity）。
  4. 箭头与标签显隐：所有动态元素（箭头、气泡、动态标签）初始`display: none`或`opacity: 0`，通过`setAttribute('display', 'block')`或CSS transition控制显隐。
  5. 夹子状态：通过`setAttribute('fill', color)`直接修改夹子矩形的填充色，无过渡动画，确保状态切换明确。
  6. 事件绑定：按钮绑定`click`事件，调用`goToStep(step)`函数，内部先`cancelAnimationFrame`停止当前动画，再更新`currentStep`，最后调用`renderStep()`。
- ID命名规范：所有SVG元素及JS变量ID必须以`scene1-`为前缀。例如：`scene1-tube1`、`scene1-tube2`、`scene1-lime1`、`scene1-lime2`、`scene1-m-pipe`、`scene1-clip-x`、`scene1-clip-y`、`scene1-arrow-in-left`、`scene1-arrow-in-m`、`scene1-arrow-out-m`、`scene1-arrow-out-right`、`scene1-bubble-group`、`scene1-precipitate-group`、`scene1-label-air`、`scene1-label-exhale`、`scene1-label-clear`、`scene1-label-turbid`、`scene1-conclusion`、`scene1-option-c`、`scene1-btn-prev`、`scene1-btn-next`。
- IIFE隔离：所有JavaScript代码包裹在`(function() { ... })()`中，避免全局变量污染，确保多场景合并时互不干扰。
- 按钮样式：CSS中定义`.scene1-btn { position: absolute; font-size: 14px; cursor: pointer; border: 1px solid #333; border-radius: 4px; background: #f5f5f5; }`，禁用状态加`.scene1-btn-disabled { opacity: 0.4; cursor: not-allowed; }`。
