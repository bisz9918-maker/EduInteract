[图示主题与整合说明]
- 本图示主题：并联电路的电流路径追踪与元件作用分析
- 整合的步骤/概念：从原始电路识别元件 → 追踪电流路径（干路→分流→支路1/支路2→汇合→干路） → 判定电路结构为并联 → 确定电流表测量对象（L₁支路） → 确定开关控制范围（干路，控制整个电路） → 逐项验证A/B/C/D四个选项
- 教学价值：教师可按照"看电路→追电流→定结构→判选项"的线性递进节奏讲解，每步只高亮当前分析对象，其余部分灰色弱化，降低学生认知负荷；支持随时回退重复关键步骤

[分步序列]
- 步骤0（初始状态）：显示电源、开关、电流表、L₁、L₂及全部黑色导线；显示元件标签+、-、S、L₁、L₂；电流表圆内显示"A"；无高亮、无箭头、无节点标记、无选项卡片
- 步骤1（识别元件）：所有元件轮廓描边变为#1565c0（蓝色），线宽3px，持续1s后恢复黑色；教师可在此步让学生说出各元件名称
- 步骤2（追踪干路上段）：干路上段导线(440,90)→(360,90)→(360,160)高亮为#1565c0线宽3px；显示分流点J1圆点(360,160)及标签"J1"；在该段导线添加2个蓝色电流箭头（(400,90)向左、(360,125)向下）；其余导线变为#888888灰色
- 步骤3（左支路路径）：支路1全部导线高亮为#1565c0；添加支路1电流箭头（(280,160)向左、(200,240)向下、(350,380)向右）；显示标签"支路1"；电流表与L₁保持正常色；其余非相关导线保持灰色
- 步骤4（右支路路径）：支路2全部导线高亮为#1565c0；添加支路2电流箭头（(430,160)向右、(500,240)向下、(450,380)向左）；显示标签"支路2"；支路1保持蓝色；其余导线灰色
- 步骤5（汇合与干路下段）：显示汇合点J2圆点(400,380)及标签"J2"；干路下段导线高亮为#1565c0；添加干路下段电流箭头（(460,380)向右、(520,280)向上）；开关描边高亮；所有电流路径现在均为蓝色
- 步骤6（确认并联结构）：两支路导线保持蓝色；L₁支路区域填充10%蓝色(#1565c0, opacity0.1)，L₂支路区域填充10%绿色(#2e7d32, opacity0.1)；L₁、L₂灯泡外圈添加15%黄色发光(#ffeb3b, opacity0.15)；在电路下方显示结论文字"L₁与L₂并联"(350,430)绿色粗体；若选项A已显示则将其卡片边框标红
- 步骤7（电流表测量对象）：支路1导线（电流表→L₁段）描边变为橙色#ed6c02线宽3px；电流表圆环与L₁圆环描边变为橙色；在支路1左侧显示结论"电流表与L₁串联，测L₁电流"(120,200)；若选项B已显示则将其卡片边框标绿并显示"√"
- 步骤8（开关控制范围）：干路上段与干路下段导线描边变为紫色#7b1fa2线宽3px；开关描边变为紫色；在开关右侧显示结论"开关在干路，控制整个电路"(560,200)；若选项D已显示则将其卡片边框标红并显示"×"
- 步骤9（选项验证）：在右侧显示A/B/C/D四个选项卡片；A卡片红框，文字后标红色"×"及"串联→错误"；B卡片绿框，文字后标绿色"√"及"测L₁电流→正确"；C卡片红框，文字后标红色"×"及"测L₂电流→错误"；D卡片红框，文字后标红色"×"及"只控制L₂→错误"；主电路保持全亮状态（所有导线黑色，元件正常色）

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步 ▶）
- 控件说明：
  1. 「◀ 上一步」按钮：位于控件栏左侧(240,450)，宽100高36，点击后退一个步骤，步骤0时禁用
  2. 步骤显示：位于控件栏中央(400,473)，显示"步骤 X/9"，文字居中
  3. 「下一步 ▶」按钮：位于控件栏右侧(460,450)，宽100高36，点击前进一个步骤，步骤9时禁用
- 教师操作流程：
  1. 教师打开图示，学生观察步骤0的完整电路
  2. 教师点击「下一步」进入步骤1，引导学生识别各元件
  3. 继续点击「下一步」，依次展示电流追踪路径（步骤2→5），每步只高亮当前分析的导线，其余灰色弱化
  4. 步骤6展示并联结构结论，步骤7展示电流表作用，步骤8展示开关作用
  5. 步骤9展示四个选项的正误判断，教师可据此总结
  6. 讲解过程中可随时点击「上一步」回退复习关键步骤
  7. 从步骤9可连续点击「上一步」回到步骤0重新演示

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：电路图由简单几何图形（线段、圆、多边形、文本）组成，无需复杂图表库；原生SVG可精确控制每个元件的描边颜色、线宽、透明度，便于分步高亮
- 画布尺寸：800×500px（SVG viewBox="0 0 800 500"）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  +-(电源)-+                                       |
  |  |  +  -  |        干路                            |
  |  +--------+         |                              |
  |      |              v                              |
  |  [电流表A] ←-- 分流点J1 --→ [L₂]                  |
  |      |                       |                     |
  |     L₁                       |                     |
  |      |                       |                     |
  |      +---- 汇合点J2 ---------+                     |
  |              |                                     |
  |             [开关S] → 回电源                       |
  |                                                    |
  |  [选项A] [选项B] [选项C] [选项D]  ← 步骤9显示      |
  |                                                    |
  |  [◀ 上一步]   步骤 X/9   [下一步 ▶]               |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量`currentStep`（0~9）记录当前步骤，每次点击按钮时更新状态并调用`renderStep()`
  2. 渲染逻辑：`renderStep()`根据`currentStep`值，遍历所有可高亮元素（导线、元件、标签、箭头、填充区、选项卡片），设置对应的class（如`highlight-blue`、`highlight-gray`、`hidden`等）
  3. 导线高亮：给每段导线设置独立ID（如scene1-wire-main-top-1、scene1-wire-branch1-1等），通过JS直接修改stroke和stroke-width
  4. 电流箭头：预先用`<g>`包裹所有箭头并设置`visibility:hidden`，步骤2-5时根据当前追踪路径显示对应箭头组
  5. 选项卡片：步骤9前设置`display:none`，步骤9时显示并添加正确/错误的颜色class
  6. 结论标签：步骤6-8分别显示不同文字，使用同一个text元素，通过JS修改textContent和x/y坐标
  7. 动画曲线：导线高亮使用CSS transition（stroke 0.3s ease, stroke-width 0.3s ease）；箭头出现使用opacity transition（0.3s ease）
  8. 事件绑定：按钮绑定click事件，更新currentStep后调用renderStep()
- ID命名规范：所有交互元素ID必须以`scene1-`为前缀。例如：
  - 导线：scene1-wire-main-top-1、scene1-wire-branch1-1、scene1-wire-branch2-1、scene1-wire-main-bottom-1
  - 元件：scene1-comp-battery、scene1-comp-switch、scene1-comp-ammeter、scene1-comp-l1、scene1-comp-l2
  - 节点：scene1-node-j1、scene1-node-j2
  - 箭头组：scene1-arrows-main、scene1-arrows-branch1、scene1-arrows-branch2
  - 标签：scene1-label-j1、scene1-label-j2、scene1-label-branch1、scene1-label-branch2、scene1-label-conclusion
  - 填充区：scene1-fill-branch1、scene1-fill-branch2、scene1-glow-l1、scene1-glow-l2
  - 选项：scene1-option-a、scene1-option-b、scene1-option-c、scene1-option-d
  - 按钮：scene1-btn-prev、scene1-btn-next、scene1-step-display
- IIFE隔离：所有JavaScript代码包裹在`(function() { ... })()`中，避免多场景合并时变量污染
