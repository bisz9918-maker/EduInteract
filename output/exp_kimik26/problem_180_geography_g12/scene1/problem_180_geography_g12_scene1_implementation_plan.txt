[分步序列]
- 初始状态（Step 0）：展示完整光照图基础要素。显示地球圆、地轴N-S、五条灰色虚线纬线、晨昏线（黑色2px）、三组太阳光线、A/B/C/73°41′原始标注。右侧面板标题"题图初识"，内容简述本图是西半球侧视光照图，太阳光线从右侧水平射入。无高亮无填充。

- Step 1（晨昏线判读）：点击「下一步」。视觉变化：①晨昏线由黑色变为红色#c62828并加粗至2.5px；②左侧夜半球填充蓝色#1565c0（15%透明度），右侧昼半球填充浅黄#fff9c4（20%透明度），填充区域以晨昏线为界、以圆弧为边界，严格限制在地球圆内（使用SVG clipPath）；③在北极点上方添加逆时针自转箭头（蓝色圆弧，圆心240,55，半径30）；④在晨昏线左侧中部(180,200)添加"晨线"标签。右侧面板更新为"晨昏线判读"，说明晨昏线是昼夜半球分界线，左侧为夜半球，右侧为昼半球，地球自转方向为逆时针（北极上空），左侧晨昏线由夜入昼为晨线。

- Step 2（直射点推导）：点击「下一步」。视觉变化：①切点(192,67)高亮为深橙色圆点（直径10px，加白色描边）；②在右侧昼半球添加太阳直射点标记★（深橙色星形，中心320,182，直径12px）；③在直射点右上方(335,175)添加"16°19′N"标签。右侧面板更新为"直射点推导"，展示互余公式：δ = 90° − 73°41′ = 16°19′N，说明切点纬度与直射点纬度互余，此时太阳直射16°19′N。

- Step 3（太阳高度计算）：点击「下一步」。视觉变化：①A点(240,230)高亮为蓝色圆点（直径10px，加发光滤镜）；②C点(396,298)高亮为红色圆点（直径10px，加发光滤镜）；③两点高亮同时存在。右侧面板更新为"太阳高度计算"，分两部分：A位于晨线上，太阳高度 = 0°；C点位于南回归线(23°26′S)且处于正午经线，正午太阳高度公式 H = 90° − |23°26′ + 16°19′| = 50°15′。

- Step 4（昼夜长短分析）：点击「下一步」。视觉变化：①B点(220,162)高亮为绿色圆点（直径10px，加发光滤镜），A/C恢复普通状态；②在A点旁添加标注"夜长12h"(270,235)；③在B点旁添加标注"昼长约13h"(170,140)。右侧面板更新为"昼夜长短分析"，说明B位于北回归线晨线，推导昼长约13小时、日出约5:30；A位于赤道，夜长12小时（昼夜平分）；总结南半球此时"昼短夜长，纬度越高昼越短，南极附近极夜"。

- Step 5（区时计算）：点击「下一步」。视觉变化：①叠加三条紫色虚线经线#4a148c（1px）：160°E线(100,150)-(380,310)、110°W地轴线(240,60)-(240,400)、20°W线(380,150)-(100,310)；②在20°W经线右上端外侧(395,130)标注"12:00"，在160°E经线左上端外侧(85,130)标注"0:00"；③在地轴N标签右侧(255,45)标注"110°W"。右侧面板更新为"区时计算"，说明西半球右界20°W为昼半球中央（12:00），左界160°E为夜半球中央（0:00）；展示120°E与20°W经度差140°，时间差9h20m；计算北京时间 = 12:00 + 9h20m = 21:20。

- 最终步骤即Step 5，展示全部结论。教师可随时点击「上一步」回退至任意步骤复习。

[技术实现]
- JS库选择：原生SVG（优先）+ 原生JavaScript。理由：本场景以几何图形、路径填充和状态切换为主，无复杂函数绘图或3D需求，原生SVG足以保证清晰度且无需额外CDN依赖。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------------+
  |  N                                                     |
  |    ☀ ← ← ← 太阳光线                                    |
  |    .  .  . 北极圈 --------------- 北极圈                |
  |    .  B  . 北回归线 ------------- 北回归线              |
  |    .     . 赤道 ----------------- 赤道                  |
  |    .  A  . 南回归线 ------------- 南回归线              |
  |    .     . 南极圈 --------------- 南极圈                |
  |  S                                                     |
  |                                                        |
  |  [信息面板: 490,20-790,420]                            |
  |                                                        |
  |  [◀ 上一步]  [Step X/5]  [下一步 ▶]                    |  y=455-485
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `let currentStep = 0;`，范围0-5。`updateScene()`函数根据currentStep设置各元素的display/opacity属性。
  2. 昼夜半球填充：使用SVG `<path>` 绘制。夜半球路径由"晨昏线段(192,67)-(288,393) + 左半圆弧（从393逆时针到67）"组成；昼半球路径由"晨昏线段(288,393)-(192,67) + 右半圆弧（从67逆时针到393）"组成。使用 `<clipPath id="scene1-earth-clip">` 限制填充不超出地球圆。
  3. 发光高亮效果：在 `<defs>` 中定义滤镜 `<filter id="scene1-glow">`，使用 `<feGaussianBlur>` 和 `<feMerge>` 为A/B/C/切点高亮添加外发光。
  4. 自转箭头：使用 `<path d="M ..." marker-end="url(#scene1-arrowhead)" />` 绘制逆时针圆弧，箭头朝向由path方向决定。
  5. 经线绘制（Step 5）：三条过圆心(240,230)的直线，使用stroke-dasharray实现虚线效果。
  6. 信息面板：使用SVG `<foreignObject>` 嵌入HTML div，便于多行文本和公式排版；或直接分层（SVG在下，绝对定位HTML在上）。推荐后者：SVG占满800×500，右侧面板用绝对定位div覆盖在SVG上方(x=490,y=20,w=300,h=400)，避免foreignObject兼容性问题。
  7. 按钮实现：使用绝对定位HTML button元素覆盖在SVG底部(y=455)。
  8. 动画曲线：状态切换使用200ms ease-in-out淡入（opacity 0→1），避免生硬跳转。
  9. 事件绑定：上一步/下一步按钮绑定click事件，调用`updateScene(currentStep ± 1)`。
