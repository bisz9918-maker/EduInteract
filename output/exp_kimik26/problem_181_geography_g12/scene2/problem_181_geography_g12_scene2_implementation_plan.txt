[图示主题与整合说明]
- 本图示主题：半球气压带风带极地投影模式图与季节移动（图乙解析）

[分步序列]
- 步骤0（基础模式图）：显示极地投影底图、4个气压带圆环、a与b红点、全部经纬度标注、气压带名称、a/b标签、图例。隐藏所有箭头、风带名称、结论框。
- 步骤1（水平气压梯度力）：显示3条灰色虚线径向箭头（a处由30°指向0°向外，b处由30°指向60°向内，极地处由90°指向60°向外）。标注"水平气压梯度力：由高压指向低压"。
- 步骤2（北半球风向与判断）：新增3条蓝色实线箭头（a处东北信风：从东北指向西南；b处西南风：从西南指向东北；极地东风：从东北指向西南）。显示风带名称（信风带/西风带/极地东风带）与风向标注（东北风/西南风）。左侧添加标注"风向相对于水平气压梯度力向右偏转 → 北半球"。保留灰色虚线箭头（opacity降至0.3）。
- 步骤3（南北半球对比）：新增2条灰色半透明箭头表示南半球风向（a处东南信风：从东南指向西北；b处西北风：从西北指向东南）。添加标注"北右南左"。北半球蓝色箭头保持 fully opaque。
- 步骤4（季节移动—北半球夏季）：所有气压带圆环半径整体减小10px（向极点/中心平移），a/b标记与风向箭头同步内移10px。显示绿色向上虚线箭头（北移指示）与标注"太阳直射点北移 → 气压带风带北移 → 北半球夏季"。
- 步骤5（季节移动—北半球冬季）：所有气压带圆环半径从原始位置整体增大10px（向赤道/外侧平移），a/b标记与风向箭头同步外移10px。显示绿色向下虚线箭头（南移指示）与标注"太阳直射点南移 → 气压带风带南移 → 北半球冬季"。
- 步骤6（综合判断）：高亮a、b红点（外圈加粗红色圆环）。左侧显示结论框："半球：北半球（风向右偏）"、"季节：夏季（气压带北移）"、"a处 = 图甲B处（东北信风带）"。底部可提示教师根据图乙实际位置调整季节结论。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于(310,455)，宽80×高30，点击回退到上一步骤。
  - 「下一步 ▶」按钮：位于(410,455)，宽80×高30，点击前进到下一步骤。
  - 步骤标题文本：位于画布顶部中央(400,25)，随步骤切换更新内容。
- 教师操作流程：
  1. 教师展示步骤0，让学生识别极地投影结构、气压带位置、a/b所在风带。
  2. 点击「下一步」进入步骤1，讲解水平气压梯度力的方向（高压→低压，垂直于气压带）。
  3. 点击「下一步」进入步骤2，对比灰色虚线与蓝色实线，讲解地转偏向力"北右"规律，确定北半球。
  4. 点击「下一步」进入步骤3，叠加南半球灰色箭头，强化"北右南左"对比记忆。
  5. 点击「下一步」进入步骤4，观察气压带整体北移，联系太阳直射点北移，推断夏季。
  6. 点击「下一步」进入步骤5，观察南移，建立季节移动双向认知。
  7. 点击「下一步」进入步骤6，综合得出图乙的半球与季节结论，关联图甲B处信风带。
  8. 可随时点击「上一步」回退复习。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：图形为同心圆、径向线、箭头等基础几何，无需复杂数据绑定或3D，原生SVG性能最佳且可控。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图：
  ```
  [步骤标题区]        y=10~35
  [                    ]
  [   极地投影主图区    ]   y=40~430，中心(400,220)
  [   （同心圆+气压带   ]   右侧y=310~420放图例
  [    +风向箭头）      ]   左侧y=80~200放步骤6结论框
  [                    ]
  [◀上一步] [下一步▶]   y=455~485，底部中央
  ```
- 关键实现要点：
  1. 状态机设计：用变量 `let currentStep = 0;` 控制0~6共7个状态。每步用一个配置对象数组 `stepConfig`，定义该步需显示的元素ID列表。
  2. 元素显隐：所有可选元素（箭头、标签、结论框）初始 `display:none` 或 `visibility:hidden`。切换步骤时遍历配置数组，设置对应元素为 `display:block` 或 `visibility:visible`。
  3. 气压带移动动画（步骤4/5）：使用SVG `<circle>` 元素的 `r` 属性，通过CSS `transition: r 0.6s ease` 或JS `requestAnimationFrame` 平滑过渡。步骤4所有气压带 `r -= 10`；步骤5所有气压带 `r += 10`（相对于原始值）。a/b标记及风向箭头坐标同步平移（通过transform translate或重新计算坐标）。
  4. 箭头绘制：使用SVG `<marker>` 定义箭头头部（蓝色、灰色、绿色三种），`<line>` 或 `<path>` 设置 `marker-end`。
  5. 事件绑定：按钮绑定 `click` 事件，更新 `currentStep` 后调用 `renderStep()`。`renderStep()` 负责统一更新所有元素的显隐、位置、文本内容。
  6. 步骤标题更新：`renderStep()` 同步更新顶部标题文本，如 "步骤2：北半球风向与判断"。
- ID命名规范：所有元素ID必须以 `scene2-` 为前缀。例如：`scene2-circle-0deg`、`scene2-arrow-gradient-a`、`scene2-label-wind-ne`、`scene2-btn-prev`、`scene2-step-title`。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免全局污染。
- 颜色变量（在代码注释中声明，便于维护）：
  - 低压带：#c62828
  - 高压带：#1565c0
  - 北半球风向：#1565c0
  - 南半球风向：#9e9e9e
  - 水平气压梯度力：#888888
  - 季节移动指示：#2e7d32
  - 高亮/标记：#c62828
