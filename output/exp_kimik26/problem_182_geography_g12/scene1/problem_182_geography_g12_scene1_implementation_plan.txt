[图示主题与整合说明]
- 本图示主题：世界经纬网基础定位与相对方位判定
- 整合内容：矩形世界经纬网（经度180°→120°W→60°W→0°→60°E→120°E→180°，纬度90°N→60°N→30°N→0°→30°S→60°S→90°S）；A/B/C/D/E五点经纬度判读；A点相对于B点的方向判断；A与B之间的经度差和纬度差分解
- 教学价值：教师通过分步导航，先让学生建立经纬网读图意识，再逐步引入坐标标注、方向箭头和辅助分解线，帮助学生理解"西北方向"的空间分解过程（经度差60°+纬度差60°），最后完成五点定位总结

[视觉元素清单]
- 经纬网：7条经线（x=120,220,320,420,520,620,720）+ 7条纬线（y=80,140,200,260,320,380,440），0°经线与赤道加粗1.5px，其余1px实线，颜色#000000
- 五个标记点：A(320,200)、B(420,320)、C(420,260)、D(520,140)、E(620,140)，统一#c62828实心圆直径6px
- 高亮圆：步骤1显示A/B高亮（圆心同点，半径20px，fill:#1565c0, opacity:0.15）；步骤3显示C/D/E高亮，同样式
- 方向箭头：步骤2显示，从B(420,320)指向A(320,200)，#1565c0实线2px，末端箭头marker
- 辅助分解线：步骤2显示，垂直虚线(320,200)-(320,320) + 水平虚线(320,320)-(420,320)，#888888 1px虚线（stroke-dasharray:4,4）
- 标签：所有文字使用#000000，12px无衬线字体（font-family:sans-serif）
- 坐标标签格式：A(60°W, 30°N)、B(0°, 30°S)、C(0°, 0°)、D(60°E, 60°N)、E(120°E, 60°N)

[分步序列]
- 初始状态（步骤0）：展示完整矩形经纬网，所有经度/纬度标注，A/B/C/D/E五个红色标记点及其字母标签。等待教师触发交互。
- 步骤1：点击「下一步」→ A、B两点出现蓝色半透明高亮圆（半径20px）；A点右下方弹出坐标标签"A(60°W, 30°N)"，B点右上方弹出坐标标签"B(0°, 30°S)"。引导学生建立坐标意识。
- 步骤2：点击「下一步」→ 绘制从B指向A的蓝色方向箭头；绘制灰色直角辅助虚线（A垂直向下到(320,320)，再水平向右到B）；箭头旁标注"西北方向"；水平虚线下方标注"经度差60°"；垂直虚线左侧标注"纬度差60°"。展示方向分解。
- 步骤3：点击「下一步」→ C、D、E三点出现蓝色半透明高亮圆；三点旁分别弹出坐标标签"C(0°, 0°)"、"D(60°E, 60°N)"、"E(120°E, 60°N)"。完成五点定位总结。
- 教师可随时点击「上一步」回退到任意步骤复习。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于控件栏左侧(300,465)，宽80px，高28px。当前步骤>0时可用，点击回退到上一状态。
  - 「下一步」按钮：位于控件栏右侧(420,465)，宽80px，高28px。当前步骤<3时可用，点击前进到下一状态。
  - 步骤指示器：位于两按钮上方居中(400,455)，显示"步骤 X/4"。
- 教师操作流程：
  1. 教师展示步骤0（原图全貌），让学生识别经纬网结构和五个点的大致位置。
  2. 点击「下一步」进入步骤1，高亮A、B并显示坐标，提问学生两点的经纬度。
  3. 点击「下一步」进入步骤2，出现方向箭头和辅助虚线，讲解"西北方向"是如何由经度差和纬度差共同决定的。
  4. 点击「下一步」进入步骤3，高亮剩余三点并显示坐标，完成全部五点定位总结。
  5. 可随时点击「上一步」回退复习。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：本场景为静态几何图示与简单显隐控制，无需复杂动画库；SVG适合绘制精确坐标网格和矢量箭头；原生JS足以管理4状态状态机。
- 画布尺寸：800 × 500 px（SVG画布），控件栏叠放在SVG容器底部（y=460~490区域，position:absolute）。
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |  180°  120°W  60°W   0°   60°E  120°E  180°      |  <- 经度标注区 y=55
  | 90°N ┌──────────────────────────────────────┐     |
  | 60°N │      D(●)        E(●)                │     |
  | 30°N │   A(●)                                 │     |
  |  0°  │      C(●)                              │     |
  | 30°S │      B(●)                              │     |
  | 60°S │                                        │     |
  | 90°S └──────────────────────────────────────┘     |
  |        ↑ 纬度标注区 x=90                          |
  |                                                   |
  |              [步骤 1/4]                           |  <- 步骤指示器 y=455
  |           [上一步]  [下一步]                      |  <- 控件栏 y=465
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：定义全局变量 `let state = 0;`（范围0~3）。每个状态对应一组元素的显隐。使用 `setState(n)` 函数统一切换，先隐藏所有动态元素，再按新状态显示对应元素。
  2. 元素分组：将所有动态元素按步骤分组包裹在SVG `<g>` 中，赋予id如 `scene1-step1-group`、`scene1-step2-group` 等，通过设置 `display:none` 或 `display:block` 控制。
  3. 箭头实现：使用SVG `<marker>` 定义箭头头部，id为 `scene1-arrowhead`，在方向箭头line的 `marker-end` 属性中引用。
  4. 高亮圆动画：使用CSS transition控制opacity从0到1，时长200ms，提升视觉平滑度。
  5. 按钮状态：在 `setState` 中同步更新按钮disabled状态和步骤指示器文字。
  6. 事件绑定：上一步/下一步按钮绑定click事件，调用 `setState(state - 1)` 或 `setState(state + 1)`。
- ID命名规范：所有SVG元素和交互元素ID必须以 `scene1-` 为前缀。例如：`scene1-grid-main`、`scene1-point-a`、`scene1-highlight-a`、`scene1-step1-group`、`scene1-btn-prev`、`scene1-btn-next`。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免多场景合并时变量污染。
