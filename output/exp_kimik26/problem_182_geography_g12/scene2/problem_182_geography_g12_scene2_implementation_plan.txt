[图示主题与整合说明]
- 本图示主题：正午太阳高度相等的条件与太阳直射点位置（第(1)问）
- 整合的步骤/概念：侧视地球局部示意图 → 引入平行太阳光线 → 标注A(30°N)与B(30°S)两地正午太阳高度角 → 展示公式推导与结论
- 教学价值：教师通过分步导航，从几何直观（光线入射）过渡到公式 H = 90° − |φ − δ|，帮助学生理解"两地纬度关于赤道对称时，太阳直射赤道则正午太阳高度相等"这一核心结论

[分步序列]
- 步骤0（初始状态）：显示地球圆弧、地轴、赤道线、A/B红点、观测竿、基础标签（A、B、30°N、30°S、0°、赤道）。隐藏太阳光线、地平线、角度弧、公式。教师可讲解两地纬度位置。
- 步骤1（太阳光线）：点击「下一步」→ 从右侧射入5条平行太阳光线（虚线箭头），光线与赤道垂直。新增标签"太阳光线"。教师讲解太阳直射赤道。
- 步骤2（正午太阳高度角）：点击「下一步」→ 显示A、B两地地平线切线，绘制正午太阳高度角弧线（蓝色），标注两地均为60°，高亮显示角度相等。教师讲解H=60°的几何意义。
- 步骤3（公式推导与结论）：点击「下一步」→ 在底部显示公式"H = 90° − |φ − δ|"，高亮"δ = 0°"，绿色标注结论"太阳直射赤道"。教师完成公式验证与结论总结。
- 教师可随时点击「上一步」回退复习。

[技术实现]
- JS库选择：原生SVG（简单几何与路径绘制，无需复杂库）
- 画布尺寸：800 × 500 px（SVG容器）
- 布局草图：
  ```
  [图示区 800×500]
  +----------------------------------------+
  |  地球圆弧(左凸)  太阳光线(右→左)        |
  |     A点(30°N)  ← 60° 角弧              |
  | 赤道线 ──────────────────── 0°          |
  |     B点(30°S)  ← 60° 角弧              |
  |                                        |
  |     H = 90° − |φ − δ|                  |
  |         δ = 0°  太阳直射赤道            |
  |              [上一步] [1/4] [下一步]    |
  +----------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 `currentStep`（0~3），每步控制一组元素的 `display` 或 `visibility` 属性。
  2. 元素分组：将每步新增元素包在 `<g id="scene2-step1">` 等组中，通过组的 `style.display` 批量切换。
  3. 箭头标记：在 `<defs>` 中定义 arrow marker，太阳光线末端引用。
  4. 弧线绘制：A点弧 `M 260 172.3 A 20 20 0 0 0 250 155`（圆心A，凸向左上）；B点弧 `M 260 287.7 A 20 20 0 0 1 250 305`（圆心B，凸向左下）。
  5. 动画曲线：无需复杂动画，直接显示/隐藏即可；如需柔和过渡，可用CSS `transition: opacity 0.3s`。
  6. 事件绑定：按钮 `onclick` 调用 `setStep(n)`，更新 `currentStep` 并刷新各组显示状态，同时更新步骤指示器文本。
- ID命名规范：所有元素ID以 `scene2-` 为前缀，如 `scene2-earth-arc`、`scene2-step1-rays`、`scene2-btn-prev` 等。JS中用 `getElementById` 获取。
- IIFE隔离：所有JS包在 `(function() { ... })()` 中执行，避免多场景合并时污染全局作用域。
