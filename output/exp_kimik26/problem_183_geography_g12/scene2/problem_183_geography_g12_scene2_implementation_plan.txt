[技术实现]
- JS 库选择：原生 SVG（简单几何图形、路径填充、虚线、箭头标记均可直接通过 SVG 元素实现，无需额外库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  步骤0: 标题+题目文字+小公转图（y=50~420）        |
  |  步骤1/2: 单地球光照图（y=60~420）                |
  |  步骤3: 左地球(220,170) + 右地球(580,170)         |
  |         + 对比表格(y=290~460)                     |
  |                                                  |
  |  [控件栏 y=440~490]                              |
  |   [◀ 上一步]      步骤 X/4      [下一步 ▶]       |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 `currentStep`（0~3）控制当前显示的分步。每步对应一个 `<g id="scene2-stepX">` 元素组，通过设置 `display: block/none` 切换可见性。
  2. 坐标计算：
     - 地轴端点：圆心 + R*(±sin23.5°, ∓cos23.5°)（注意SVG y轴向下）
     - 极圈端点：中点（圆心 ± R*sin66.5° * 地轴单位向量）± R*cos66.5° * 赤道单位向量
     - 晨昏线始终为竖直线 x = 圆心x
     - 昼/夜半球填充使用 SVG `<path>` 画半圆：M 圆心x,圆心y-R A R,R 0 0,1 圆心x,圆心y+R Z（配合clip或直接用半圆路径）
  3. 动画曲线：分步切换不使用动画，直接显示/隐藏（教师课堂讲解用，瞬时切换更利于控制节奏）。如需强调，可在步骤切换时给新出现的元素组加 0.2s 的 opacity 过渡。
  4. 事件绑定：
     - 按钮点击事件绑定在 `scene2-btn-prev` 和 `scene2-btn-next`
     - 步骤0时禁用「上一步」，步骤3时「下一步」可循环回步骤0或禁用（建议禁用，保持4步闭环）
  5. 正午太阳高度示意：用 `<polyline>` 画两条线段（径向线+水平线），再用 `<path>` 画小角度弧（arc）示意夹角。
  6. 对比表格：使用 SVG `<rect>` 画单元格边框，`<text>` 填充文字。表头行填充 `#e3f2fd`。列宽 116px（700/6），行高 35px。第6列标题较长，设置 `font-size="11px"` 并适当换行（使用 `<tspan>`）。
- ID 命名规范：
  - 步骤组：`scene2-step0` ~ `scene2-step3`
  - 地球圆：`scene2-earth`
  - 地轴：`scene2-axis`
  - 晨昏线：`scene2-terminator`
  - 太阳光线组：`scene2-sunrays-right`、`scene2-sunrays-left`
  - 按钮：`scene2-btn-prev`、`scene2-btn-next`
