[图示主题与整合说明]
- 本图示主题：北极俯视日照图综合判读（夏至日）
- 整合的步骤/概念：日照图基础要素 → 日期判读（夏至日/6月22日） → 太阳直射点坐标定位（23°26′N, 180°） → 地方时与北京时间计算（8:00） → 佛山昼夜长短与正午太阳高度（昼长夜短，89°37′） → 全球正午太阳高度纬度分布规律（从北回归线向南北两侧递减） → 地表E/F/G自转线速度比较（G > E > F）
- 教学价值：教师可在同一张日照图上，通过分步递进完成从基础判读到规律应用的全部教学，避免相似图示重复拆分；学生能建立"一张日照图 → 多层信息提取"的综合思维

[分步序列]
- 步骤0（初始状态）：展示北极俯视日照图全貌。显示元素：赤道圆、北回归线、北极圈、0°与180°经线、90°W/E经线（可选）、晨昏线、夜半球阴影、自转箭头、E/F/G三点及标签、基础经纬标签。右侧面板显示标题与引导语。教师讲解基础判读方法（北极俯视、逆时针自转、晨昏线区分昼夜）。
- 步骤1（日期判读）：点击「下一步」→ 北极圈内部出现极昼高亮（#c62828填充10%+描边加粗），显示标签"北极圈极昼"(140,95)和"夏至日 6月22日"(140,115)。右侧面板切换为日期判读结论（节气夏至、日期6月22日、答案D）。教师讲解：北极圈极昼→夏至日→6月22日。
- 步骤2（太阳直射点）：点击「下一步」→ 显示3条太阳光线箭头从右侧射入，北回归线与180°经线交点(400,250)出现红色五角星太阳直射点，显示坐标标签"23°26′N, 180°"(400,225)。右侧面板切换为直射点判读（昼半球中央经线180°+北回归线）。教师讲解直射点定位方法。
- 步骤3（时间计算）：点击「下一步」→ 显示120°E和30°W经线，0°经线高亮为#1565c0并标注"0:00/24:00"(85,230)，180°经线高亮为#c62828并标注"12:00"(475,230)，120°E经线高亮为#2e7d32并标注"北京时间 8:00"(175,430)。右侧面板展示时差推导（60°÷15°=4h，12:00−4h=8:00）。教师讲解地方时计算。
- 步骤4（佛山地理现象）：点击「下一步」→ 主图保持，右侧面板切换为佛山信息（23°03′N、昼长夜短、正午太阳高度公式H=90°−|23°03′−23°26′|≈89°37′）。教师讲解北半球夏至日昼夜长短与正午太阳高度计算。
- 步骤5（全球分布规律）：点击「下一步」→ 右侧面板内展开正午太阳高度纬度分布简图，绘制从北回归线向南北两侧递减的折线（赤道66°34′→北回归线90°→北极圈46°52′→北极点23°26′），曲线下淡蓝填充。右侧面板标注规律文字。教师讲解全球分布规律。
- 步骤6（自转线速度）：点击「下一步」→ E、F、G三点高亮（半径放大至6px），右侧面板显示横向柱状图（G最长、E次之、F最短）及结论"G > E > F"。教师讲解纬度与线速度关系。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript（无外部库）。原因：本场景以静态几何图形和分步显示/隐藏为主，无需复杂动画或数据驱动绘图，原生SVG性能最优且零依赖。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------------+
  |                                                        |
  |    [日照图主图区]                      [信息面板]      |
  |     圆心(280,250)                      x:560-780       |
  |     半径180（赤道）                    y:20-420        |
  |                                                        |
  |        N • (280,250)                                   |
  |           ┌─────────────┐                              |
  |          /  北回归线     \                             |
  |         /  E•        F•   \                            |
  |        |   北极圈  •N      |        步骤结论/公式/简图  |
  |        |   夜半球          |                           |
  |        |  ///////////////  |                           |
  |         \ /////////////// /                            |
  |          \/////////////// /                            |
  |           ───────────────                              |
  |                G                                       |
  |                                                        |
  +--------------------------------------------------------+
  |              [◀ 上一步]  步骤 X/7  [下一步 ▶]          |
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：维护currentStep变量（0~6），每一步通过updateScene(step)统一更新所有元素的opacity/display属性。
  2. 晨昏线与夜半球绘制：晨昏线采用大圆投影圆弧（圆心偏移至右侧画布外），夜半球用clipPath或精确path闭合（赤道左半圆+晨昏线大圆弧），确保与北极圈在(210,250)精确相切。
  3. 坐标计算：所有经纬线端点、标签位置均按圆心(280,250)和对应半径/角度精确计算，避免手绘偏差。
  4. 动画曲线：使用CSS transition: opacity 0.3s ease 控制元素淡入淡出，避免突兀切换。
  5. 事件绑定：上一步/下一步按钮绑定click事件，更新currentStep并调用updateScene；边界检查（currentStep≤0时禁用上一步，≥6时禁用下一步）。
  6. 右侧面板切换：每个步骤对应一个g元素（scene2-panel-step0~step6），通过display属性block/none切换，避免频繁DOM操作。
  7. 高亮效果：步骤1北极圈描边加粗+填充；步骤3经线变色（0°→#1565c0，180°→#c62828，120°E→#2e7d32）；步骤6三点半径放大。
- ID命名规范：所有交互元素ID必须以scene2-为前缀。例如：scene2-svg、scene2-twilight、scene2-point-e、scene2-panel-step3、scene2-btn-next、scene2-label-bjtime。JS中严格使用getElementById获取，禁止querySelectorAll配合全局class。
- IIFE隔离：所有JavaScript代码包裹在 (function() { ... })() 中，避免多场景合并时变量污染。
- SVG defs：在defs内定义箭头marker（scene2-arrowhead绿色、scene2-arrowhead-red红色），供自转箭头和太阳光线复用。
