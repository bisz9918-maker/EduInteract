[图示主题与整合说明]
- 本图示主题：球面最短距离与大圆航线航向变化（北极俯视图）
- 整合的步骤/概念：
  ① 步骤0建立北极俯视基础图（30°N纬线圈、主经线、A/B两点），让学生定位；
  ② 步骤1叠加沿30°N纬线的150°劣弧（灰色虚线），制造"沿纬线飞是否最短"的认知冲突；
  ③ 步骤2揭示大圆劣弧（红色实线，凸向北极点），标注最北点M，建立"大圆=球面最短"概念；
  ④ 步骤3在大圆路径两端标注切线航向箭头（A端西北、B端西南），总结"先向西北，再向西南"的航向变化规律。
- 教学价值：教师通过四步递进，引导学生从直观路径到抽象大圆，再到航向分析，符合"直观→冲突→建构→应用"的认知规律。分步按钮允许教师随时回退复习。

[分步序列]
- 步骤0（基础图）：显示北极俯视图基础要素——30°N纬线圈（黑实线）、四条主经线（黑实线）、北极点、A点（蓝）与B点（红）及其点名标签、四条经度标签、30°N标签。此时不显示任何路径，等待教师建立空间定位。
- 步骤1（纬线路径）：点击「下一步」→ 沿30°N纬线圈绘制从A到B的150°劣弧（灰色虚线，顺时针经过圆下方），并显示标注"沿纬线飞行（非最短距离）"(280,400)。教师可提问：沿这条线飞是最短距离吗？
- 步骤2（大圆劣弧）：点击「下一步」→ 绘制过A、B的大圆劣弧（红色实线二次贝塞尔曲线，控制点(400,143)，中点即最北点M(400,168)），在M处绘制绿色圆点并标注"M"；同时显示红色标注"大圆劣弧 = 球面最短距离"(280,220)。教师可对比两条路径的凸向差异。
- 步骤3（航向标注）：点击「下一步」→ 在大圆路径A端绘制绿色切线箭头指向西北（屏幕右上方），标注"西北"(268,180)；在B端绘制绿色切线箭头指向西南（屏幕左上方），标注"西南"(515,180)；在M点附近标注转向示意；在图下方显示总结文字"先向西北，再向西南"(320,360)。教师可总结大圆航线的航向变化规律。
- 回退机制：教师可随时点击「上一步」回退到任意步骤复习，所有元素按当前步骤重新渲染。

[交互方案]
- 交互类型：分步按钮导航（◀ 上一步 / 下一步 ▶）
- 控件说明：
  1. 「上一步」按钮：位置(280,455)，尺寸100×32，点击后步骤减1（最小为0），对应元素隐藏/显示。
  2. 「下一步」按钮：位置(420,455)，尺寸100×32，点击后步骤加1（最大为3），对应元素显示。
  3. 步骤指示文本：位置(400,448)，显示当前步骤编号（如"步骤 1 / 4"）。
- 教师操作流程：
  1. 加载后呈现步骤0，教师讲解A、B在北极俯视图中的位置（120°E与30°W）；
  2. 点击「下一步」进入步骤1，展示纬线路径，教师提问"沿纬线飞是否最短？"；
  3. 点击「下一步」进入步骤2，展示大圆劣弧与最北点M，教师讲解球面最短距离概念；
  4. 点击「下一步」进入步骤3，展示航向箭头与方向标注，教师总结大圆航线航向变化规律；
  5. 可随时点击「上一步」回退，配合学生疑问反复讲解。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本场景为静态几何图示与分步显隐，无复杂动画或数据绑定，原生SVG足以高效绘制圆、线、贝塞尔曲线与文本，避免引入冗余库。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |                    45°E                            |
  |                      |                             |
  |         A ●          |          ● B                |
  |        /             |             \               |
  |       /   大圆劣弧   |              \              |
  |      /      (红)     |               \             |
  |     /         M●     |                \            |
  |    /                 |                 \           |
  |   /                  |                  \          |
  |  /                   |                   \         |
  | 135°E ---------------●--------------- 45°W         |
  |                      |                             |
  |                   135°W                            |
  |                                                    |
  |        [沿纬线飞行]  [先向西北...]                  |
  |                                                    |
  |              [◀ 上一步] [下一步 ▶]                 |
  +--------------------------------------------------+
  画布 800×500，控件栏 y=440~490
  ```
- 关键实现要点：
  1. 状态机设计：用变量 `currentStep`（0~3）控制四步状态。每步维护一个元素ID列表（`step0Ids`, `step1Ids`, `step2Ids`, `step3Ids`），切换步骤时遍历对应列表设置 `display` 属性（或 `opacity` + `visibility`）。
  2. 大圆劣弧坐标计算：采用二次贝塞尔曲线近似，控制点取(400,143)，确保中点恰好经过最北点M(400,168)。路径命令：`M 226 193 Q 400 143 574 193`。
  3. 纬线路径绘制：使用SVG arc命令，从A(226,193)到B(574,193)，半径180，大弧标志0，顺时针扫掠标志1：`M 226 193 A 180 180 0 0 1 574 193`。
  4. 航向箭头绘制：A端沿贝塞尔切线方向（控制点-A向量归一化后延伸30px），B端同理反向；箭头头部用小型三角形path实现。
  5. 动画曲线：本场景无需复杂动画，元素直接显隐即可。如需平滑过渡，可为path添加CSS `transition: opacity 0.3s ease`。
  6. 事件绑定：按钮绑定 `click` 事件，更新 `currentStep` 后调用 `renderStep()` 函数统一渲染。
  7. 按钮禁用逻辑：`currentStep===0` 时禁用「上一步」；`currentStep===3` 时禁用「下一步」（或隐藏）。
- **ID命名规范**：所有交互元素ID必须以 `scene2-` 为前缀。例如：
  - 纬线圈：`scene2-lat30`
  - A点：`scene2-point-a`
  - 大圆劣弧：`scene2-great-circle`
  - 上一步按钮：`scene2-btn-prev`
  - 下一步按钮：`scene2-btn-next`
  - JS中严格使用 `document.getElementById('scene2-xxx')` 获取元素，禁止全局class选择，避免多场景合并时跨场景污染。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，变量不泄露全局作用域。
