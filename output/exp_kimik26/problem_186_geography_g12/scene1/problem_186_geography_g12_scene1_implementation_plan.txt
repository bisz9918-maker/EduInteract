[图示主题与整合说明]
- 本图示主题：地球公转、黄赤交角与四季形成的因果链条
- 整合内容：将题目原始填空流程图（6个空）与地球运动机制（自转/赤道面、公转/黄道面、黄赤交角23°26′、直射点回归、昼夜长短与正午太阳高度变化、地面受热差异、气温变化）整合为8步分步导航图示
- 教学价值：教师可按照因果逻辑逐步展开，从地球运动→空间交角→太阳直射点移动→昼夜与太阳高度变化→地面受热→气温→四季，每步聚焦单一概念，左侧流程图与右侧机制图同步联动，便于学生建立完整知识链条

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 步骤指示器：SVG text元素，id="scene1-step-indicator"，位于(400,452)，显示"步骤 X/7"
  2. 「◀ 上一步」按钮：SVG foreignObject内button，或SVG rect+text，id="scene1-btn-prev"，位于(290,460)，宽100×高32，#1565c0背景，#ffffff文字；步骤0时disabled（#bdbdbd）
  3. 「下一步 ▶」按钮：id="scene1-btn-next"，位于(420,460)，宽100×高32；步骤7时disabled
- 教师操作流程：
  1. 教师打开图示，学生看到步骤0的完整流程图（留白）与轨道轮廓，建立问题意识。
  2. 教师点击「下一步」进入步骤1，讲解地球自转与赤道面，左侧"自转"与"赤道平面"高亮，右侧出现自转地球示意图。
  3. 继续点击「下一步」依次展开公转/黄道面→黄赤交角→直射点回归→昼夜长短与正午太阳高度→气温变化。
  4. 最后一步呈现完整答案，教师可点击「上一步」回退到任意步骤复习。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：本场景以几何图形、路径、文本为主，无复杂函数图或3D，原生SVG足够；状态切换通过classList控制显示/隐藏，配合CSS transition实现淡入淡出。
- 画布尺寸：800×500 px（SVG viewBox="0 0 800 500"）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |  +------------------+  +------------------------+ |
  |  |  自转    公转    |  |                        | |
  |  |  （赤道）平面    |  |    机制示意图区         | |

  |  |   （黄赤）交角   |  |                        | |

  |  | （昼夜长短）变化 |  |                        | |

  |  |   地面受热...    |  |                        | |
  |  |   （气温）变化   |  |                        | |
  ```

- 关键实现要点：
  1. 状态机设计：变量 `let currentStep = 0;`（范围0~7）。每次点击按钮时更新currentStep，调用`renderStep()`函数。`renderStep()`内用switch或if-else根据currentStep设置各元素的display/opacity class。
  2. 元素显隐策略：所有视觉元素预先在SVG中定义，默认`display:none`或`opacity:0`；通过添加/移除`scene1-active`类控制。使用CSS `.scene1-active { opacity: 1; transition: opacity 0.3s; }`实现淡入。
  3. 流程图高亮：给每个流程图框设置id（如scene1-box-zizhuan、scene1-box-chidao等），高亮时添加class `scene1-highlight`（改变fill和stroke）。
  4. 流程图文字切换：每个框内使用`<text>`元素，步骤切换时通过JS修改textContent或innerHTML（使用tspan设置答案颜色）。例如步骤1时，赤道平面框.innerHTML = '（<tspan fill="#1565c0" font-weight="bold">赤道</tspan>）平面'。
  5. 大地球与轨道图切换：步骤1-3显示大地球组（g id="scene1-big-earth-group"），步骤4+显示轨道组（g id="scene1-orbit-group"），两组互斥显示。
  6. 晨昏线计算：步骤5中，晨昏线垂直于日地连线。日地连线向量(dx,dy)，晨昏线方向(-dy,dx)。通过SVG line的x1,y1,x2,y2绘制，长度略大于地球直径（如地球r=15，线长取40px，两端超出地球）。
  7. 角度弧绘制：步骤3中，使用SVG path的A命令绘制圆弧。起点(620,220)，终点(620+25*cos(23.5°), 220-25*sin(23.5°))，大弧标志0， sweep-flag 0。
  8. 事件绑定：按钮绑定click事件，更新currentStep并调用renderStep()。在IIFE内部定义，避免全局污染。
- ID命名规范：所有交互元素ID必须以`scene1-`为前缀。例如：
  - 流程图框：`scene1-box-zizhuan`、`scene1-box-gongzhuan`、`scene1-box-chidao`、`scene1-box-huangdao`、`scene1-box-jiaojiao`、`scene1-box-zhishe`、`scene1-box-zhouye`、`scene1-box-gaodu`、`scene1-box-shoure`、`scene1-box-qiwen`、`scene1-box-siji`
  - 右侧图形组：`scene1-big-earth-group`、`scene1-orbit-group`、`scene1-sun`、`scene1-earth-chun`、`scene1-earth-xia`、`scene1-earth-qiu`、`scene1-earth-dong`
  - 控件：`scene1-btn-prev`、`scene1-btn-next`、`scene1-step-indicator`
  - 标签：`scene1-label-taiyang`、`scene1-label-beijixing`、`scene1-label-chidao`、`scene1-label-huangdao`、`scene1-label-angle`、`scene1-label-chunfen`等
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，所有DOM查询使用`document.getElementById`并配合`scene1-`前缀ID，严禁使用`querySelectorAll`配合全局class，防止多场景合并时跨场景污染。
