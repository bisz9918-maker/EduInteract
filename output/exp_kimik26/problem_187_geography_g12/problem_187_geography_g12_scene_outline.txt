    下图为北半球四地点在6月22日不同时刻测到的当地太阳位于正南方时的太阳能热水器倾角示意图。

    （1）该日四地点中正午太阳高度由大到小的排序是________，该日四地点中昼长时间由长到短的排序是________。
    （2）②地的地理坐标是________，④地在①地________方向。
    （3）若①地在大陆上，其附近的著名工业基地是________工业基地，若④地为陆地，其附近的著名工业基地是________。

    本题是一道综合考查地球运动（正午太阳高度、地方时计算）与世界区域地理的高考地理题。解题核心链条为：
    1. 太阳能热水器倾角与正午太阳高度互余，由倾角求出四地正午太阳高度；

    3. 利用夏至日（6月22日）太阳直射北回归线（23°26′N），由正午太阳高度公式求出四地纬度；
    4. 根据四地经纬度坐标进行空间定位，进而分析昼长、相对方位及区域地理事物。

    - 图示2：地方时与世界时的经度推算
    - 图示3：世界地图定位、昼长比较与区域地理特征

    教学说明：热水器倾角原理与正午太阳高度计算

    教师应引导学生首先明确太阳能热水器的工作原理——集热板需尽量垂直于太阳光线以获得最大能量。因此，当正午太阳位于正南方时，向南倾斜的集热板与水平地面的夹角（倾角α）和正午太阳高度角H互为余角，即α + H = 90°。

    讲解要点：
    1. 让学生观察题目图中四地热水器的倾斜程度：A地最接近水平，D地次之，B、C两地倾斜最陡。直观上可初步判断A地正午太阳最高，B、C两地正午太阳最低。
    2. 在步骤1中，教师可指示太阳光线，强调"太阳在正南方"意味着光线从正南方向水平射来，与地面形成夹角H。
    3. 利用互余关系计算四地正午太阳高度：
       - H_A = 90° - 6°34′ = 83°26′
       - H_B = 90° - 26°34′ = 63°26′
       - H_C = 90° - 26°34′ = 63°26′
       - H_D = 90° - 13°34′ = 76°26′
    4. 得出结论并回答第（1）题第一空：正午太阳高度由大到小为 **A > D > B = C**。

    注意提醒学生：倾角越小，正午太阳高度越大，纬度越低（后续将验证）。

    教学说明：地方时、世界时与经度推算

    本题的关键突破口在于理解"当地太阳位于正南方"即表示当地地方时为正午12:00。教师应强调：对于北半球北回归线以北地区，全年正午太阳均在正南方（北极点除外）。

    讲解要点：
    1. 明确世界时（UTC）以0°经线的地方时为基准。
    2. 地球自转角速度为15°/h，因此经度每差15°，地方时相差1小时。
    3. 遵循"东加西减"原则：地方时比世界时早（数值大）的地点位于东经；地方时比世界时晚（数值小）的地点位于西经。
    4. 四地经度计算：
       - A地：12:00 - 4:00 = +8h → 120°E
       - B地：12:00 - 8:00 = +4h → 60°E
       - C地：12:00 - 12:00 = 0h → 0°
       - D地：12:00 - 24:00 = -12h（或视为+12h）→ 180°
    5. 特别提醒D地：世界时24:00即次日0:00，与地方时12:00相差12小时，对应180°经线（国际日期变更线附近），需注意日期变化。

    至此，四地经度已全部确定。

    教学说明：纬度计算、全球定位与区域地理特征

    在确定四地经度后，教师需引导学生利用夏至日太阳直射北回归线这一条件，推算四地纬度。

    讲解要点：
    1. 正午太阳高度公式：**H = 90° - |φ - δ|**，其中δ为太阳直射点纬度（6月22日δ = 23°26′N）。
    2. 由于四地均位于北回归线以北（正午太阳在正南方），公式可简化为 **H = 90° - (φ - δ)**，进而得到 **φ = δ + (90° - H) = 23°26′N + 热水器倾角**。
    3. 四地纬度计算：
       - A：23°26′ + 6°34′ = **30°N**
       - B：23°26′ + 26°34′ = **50°N**
       - C：23°26′ + 26°34′ = **50°N**
       - D：23°26′ + 13°34′ = **37°N**
    4. 结合SCENE_2的经度结果，四地完整坐标为：
       - A(30°N, 120°E)
       - B(50°N, 60°E)
       - C(50°N, 0°)
       - D(37°N, 180°)
    5. 回答第（1）题：夏至日北半球昼长随纬度升高而增长，因此昼长排序为 **B = C > D > A**。
    6. 回答第（2）题：②地（B地）坐标为 **(50°N, 60°E)**；④地（D地）相对于①地（A地），纬度更高且经度更大（从120°E到180°），故位于 **东北** 方向。
    7. 回答第（3）题：A地(30°N, 120°E)位于我国长江三角洲，附近著名工业基地为 **沪宁杭工业基地**。D地(37°N, 180°)位于北太平洋中部，若题目设定其为陆地，需结合具体地图进一步定位；实际该坐标附近无大型著名工业基地分布。
    8. 回答第（4）题：C地(50°N, 0°)位于英国附近，附近的著名渔场是 **北海渔场**，该国气候深受 **北大西洋暖流** 影响，暖流起到增温增湿作用。

    教师可在世界地图上引导学生观察四地的海陆位置，建立"坐标→定位→区域特征"的综合思维链条。
