[图示主题与整合说明]
- 本图示主题：太阳能热水器倾角与正午太阳高度的互余关系及四地角度计算
- 整合的步骤/概念：①热水器倾角的几何定义（水平地面、向南倾斜的集热板、正午太阳光线）；②倾角α与正午太阳高度H的互余关系推导（借助辅助垂线证明α+H=90°）；③四地（A/B/C/D）正午太阳高度的具体计算（H=90°−α）；④计算结果的排序结论（A>D>B=C）
- 教学价值：教师通过分步控制，先让学生观察原题四地倾角差异，再放大几何模型建立直观认知，接着推导互余公式，最后代入计算并排序，形成"直观→原理→计算→结论"的完整认知链

[分步序列]
- 初始状态（步骤0）：显示题目原始四个热水器侧视图并列卡片。每个卡片含地面线、倾斜集热板（按实际角度绘制）、倾角数值（红）、地点A/B/C/D（黑粗）、世界时（灰）。顶部标题"6月22日四地太阳能热水器倾角示意图"。教师可引导学生观察四地倾角差异。
- 步骤1：点击「下一步」→ 切换为原理放大图。左半部显示单个热水器几何模型：水平地面线、向南倾斜的集热板（代表性角度~35°，浅灰填充）、从右上射向左下的太阳光线（蓝箭头）。标注北/南方向、α（集热板与地面夹角，红）、H（光线与地面夹角，蓝）。右半部文字说明几何模型各要素定义。教师讲解倾角和太阳高度角的物理意义。
- 步骤2：点击「下一步」→ 在几何模型上添加辅助垂线（从集热板南端垂直向下到地面，灰虚线）和直角符号。高亮两个α角（集热板处和光线与垂线处，红），推导互余关系。右半部显示推导公式："∵ 集热板⊥太阳光线"、"∵ 垂线⊥地面"、"∴ α+H=90°"（红粗）、"∴ H=90°−α"（绿粗）。教师讲解几何推导过程。
- 步骤3：点击「下一步」→ 切换为四地计算并列卡片。每列含：地点标题、小图（按实际倾角绘制）、α值（红）、计算式"90°−α"（90°蓝，α红）、计算结果H（绿粗）、世界时小字（灰）。教师带领学生逐列计算。
- 步骤4：点击「下一步」→ 显示排序结论。顶部四地结果框（绿框，含地点和H值），用蓝箭头连接 A→D→B=C。中部大标题"正午太阳高度由大到小"，下部排序结果"A > D > B = C"（绿粗，20px），底部对齐标注四个数值。教师总结第(1)问第一空答案。

- JS 库选择：原生 SVG（使用 <svg> 元素配合 <line>、<path>、<rect>、<text>、<polygon> 等），无需外部库。原因：本场景以静态几何图形和分步显隐为主，无复杂动画或数据绑定，原生 SVG 足够轻量且精确。
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  步骤标题（顶部居中）                               |
  |                                                   |
  |  [主图区 y=60~420]                                |
  |  +----------------------------------------------+ |
  |  |  步骤0: 四地并列卡片 (y=80~350)               | |
  |  |  步骤1-2: 左几何图(50~380) + 右文字(400~750)  | |
  |  |  步骤3: 四地计算卡片 (y=60~380)               | |
  |  |  步骤4: 结果框+排序结论 (y=80~350)            | |
  |  +----------------------------------------------+ |
  |                                                   |
  |  [控件栏 y=440~490]                               |
  |     [◀ 上一步]   步骤 X/5   [下一步 ▶]            |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 `currentStep`（0~4）控制当前步骤。每步对应一个显隐配置对象，定义该步应显示的 SVG 元素 ID 列表。切换步骤时，先隐藏所有步骤元素，再显示当前步骤元素。
  2. 元素组织：为每个步骤的元素组包裹在 `<g id="scene1-step0">`、`<g id="scene1-step1">`... 中，通过控制 `<g>` 的 `display` 属性（block/none）实现整组显隐。
  3. 坐标计算：集热板端点按倾角用三角函数计算（长度固定90~130px，角度按实际值）。太阳光线斜率确保垂直于集热板（斜率乘积为-1）。
  4. 角度弧绘制：使用 SVG `<path>` 的 `A` 命令绘制圆弧，圆心在夹角顶点，半径20~25px，起始角和终止角根据线段斜率计算。
  5. 颜色动态：步骤2中公式高亮通过预置 `<text>` 元素的 `fill` 属性实现，无需动画。
  6. 按钮状态：步骤0时给上一步按钮添加 `disabled` class（opacity: 0.5，pointer-events: none）；步骤4时同理禁用下一步按钮。
  7. 事件绑定：按钮点击事件在 IIFE 内绑定，直接操作 `currentStep` 并调用 `renderStep()`。
- ID 命名规范：所有 SVG 元素和控件 ID 必须以 `scene1-` 为前缀。例如：
  - 步骤组：`scene1-step0-group`、`scene1-step1-group`...
  - 几何元素：`scene1-ground-line`、`scene1-collector-panel`、`scene1-sun-ray`
  - 标签：`scene1-alpha-label`、`scene1-H-label`
  - 按钮：`scene1-prev-btn`、`scene1-next-btn`
  - 指示器：`scene1-step-indicator`
- IIFE 隔离：所有 JavaScript 包在 `(function() { ... })()` 中，避免全局变量污染，确保多场景合并时互不干扰。
- 响应式：SVG 使用 `viewBox="0 0 800 500"` 配合 `width="100%"` 保持比例缩放，但内部坐标严格按 800×500 设计。
