[图示主题与整合说明]
- 本图示主题：全球正午太阳高度角随纬度变化规律
- 整合的步骤/概念：将夏至日（C、D）、冬至日（A、F）、春秋分（B、E）三个节气的正午太阳高度角纬度分布曲线整合在同一坐标系中。通过多状态切换，教师可对比三条折线的顶点位置（直射点纬度）和两侧递减趋势，直观得出"由直射点向南北两侧递减"的共性规律，以及顶点随太阳直射点季节移动的差异。
- 教学价值：教师先展示单条曲线讲解该节气的分布特征，再切换对比三条曲线，引导学生发现规律共性；配合底部按钮可反复切换，强化记忆。

[视觉元素清单]
- 坐标系：直角坐标系，横轴纬度（90°S→90°N），纵轴正午太阳高度角h（0°→90°）。轴线黑色2px，带箭头。
- 刻度与网格：横轴7个刻度（90°S、66°34′S、23°26′S、赤道、23°26′N、66°34′N、90°N），纵轴3个刻度（0°、45°、90°）。5条垂直参考虚线（回归线、极圈、赤道），1条水平参考虚线（h=45°）。辅助线颜色#888888，stroke-dasharray="4,3"，opacity 0.5。
- 三条折线：
  - 夏至（绿 #2e7d32）：顶点(478,100)即23°26′N/h=90°，向90°N递减至(700,337)，向66°34′S递减至(178,420)。
  - 冬至（红 #c62828）：顶点(322,100)即23°26′S/h=90°，向90°S递减至(100,337)，向66°34′N递减至(622,420)。
  - 春秋分（蓝 #1565c0）：顶点(400,100)即赤道/h=90°，向两极递减至(100,420)与(700,420)。
- 直射点标记：当前状态对应的顶点处绘制圆点（r=6，stroke-width=2，fill=white），上方标注纬度名称。
- 图例：右上角，始终显示，说明三色曲线含义。
- 配色：背景#ffffff；主线#000000；夏至绿#2e7d32；冬至红#c62828；春秋分蓝#1565c0；辅助线#888888。
- 文字：坐标轴标签12px黑色；标题16px黑色加粗；直射点标签12px加粗，颜色与曲线一致。

[状态序列]
- 初始状态（状态1 — 夏至）：
  - 三条曲线均显示：夏至曲线 opacity=1、stroke-width=3px；冬至与春秋分曲线 opacity=0.15、stroke-width=2px。
  - 夏至直射点标记(478,100)及标签"23°26′N" opacity=1；其余直射点标记及标签 opacity=0。
  - 「夏至」按钮为选中样式（背景#2e7d32，文字白色）；其余按钮为未选中样式。
- 状态2 — 冬至（点击「冬至」按钮）：
  - 300ms动画过渡：冬至曲线 opacity 0.15→1、stroke-width 2→3；夏至曲线 opacity 1→0.15、stroke-width 3→2。
  - 冬至直射点标记(322,100)及标签"23°26′S"淡入；夏至标记及标签淡出。
  - 「冬至」按钮切换为选中样式。
- 状态3 — 春秋分（点击「春秋分」按钮）：
  - 300ms动画过渡：春秋分曲线 opacity 0.15→1、stroke-width 2→3；其余两条曲线 opacity 1→0.15、stroke-width 3→2。
  - 春秋分直射点标记(400,100)及标签"赤道"淡入；其余标记及标签淡出。
  - 「春秋分」按钮切换为选中样式。
- 教师可随时点击任意按钮切换状态，无顺序限制。

[交互方案]
- 交互类型：多状态切换（3个按钮）
- 控件说明：
  - 「夏至」按钮：位于底部按钮容器左位，点击切换至夏至高亮状态。
  - 「冬至」按钮：位于底部按钮容器中位，点击切换至冬至高亮状态。
  - 「春秋分」按钮：位于底部按钮容器右位，点击切换至春秋分高亮状态。
  - 按钮容器：position:absolute，left:50%，bottom:15px，transform:translateX(-50%)，display:flex，gap:10px。
- 教师操作流程：
  1. 加载后默认显示夏至状态，教师讲解夏至日正午太阳高度角由北回归线向两侧递减。
  2. 点击「冬至」按钮，曲线交叉淡入淡出，教师对比冬至顶点移至南回归线。
  3. 点击「春秋分」按钮，展示春秋分顶点在赤道，向两极对称递减至0°。
  4. 可反复点击任意按钮，让学生观察三条曲线的异同，归纳出"由直射点纬度向南北两侧递减"的规律。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript（无外部库）。理由：图形为简单折线与坐标系，无需复杂数据绑定或3D渲染；原生JS即可控制opacity动画与状态切换，减少依赖。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图：
  ```
  +--------------------------------------------------+
  |          全球正午太阳高度角随纬度变化规律          |  y=0~55
  |                                                  |
  |  正午太阳高度角 h                                 |  y=55~420
  |  (纵轴)    ^                                     |
  |            |    蓝● 春秋分曲线                    |
  |       90° -|   /\                                 |
  |            |  /  \      绿● 夏至曲线              |
  |       45° -| /    \      /\                       |
  |            |/      \    /  \    红● 冬至曲线      |
  |        0° -+--------\--/----\--/----  纬度        |
  |       90°S  23°S 赤道 23°N  66°N 90°N            |
  |                                                  |
  |  [图例] 夏至  冬至  春秋分                        |  y=95~180
  |                                                  |
  |        [夏至] [冬至] [春秋分]                     |  y=450~485
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机：用变量 `currentState` 存储 0(夏至)/1(冬至)/2(春秋分)。点击按钮时更新状态，调用 `renderState()`。
  2. 动画过渡：所有曲线、标记、标签的opacity变化通过CSS `transition: opacity 300ms ease-in-out` 实现。切换状态时只需修改元素的class或style.opacity，浏览器自动补间。
  3. 曲线绘制：使用SVG `<path>` 的 `d` 属性，用 `M` 和 `L` 命令绘制折线。三条路径始终存在于DOM中，通过opacity控制显隐权重。
  4. 按钮样式切换：通过添加/移除 `.active` class 改变背景色与文字色。
  5. 坐标计算：横轴600px对应180°纬度，比例尺 3.333 px/°；纵轴320px对应90°高度角，比例尺 3.556 px/°。所有关键点坐标按此比例预先计算并硬编码在path中。
  6. 事件绑定：按钮使用 `onclick` 绑定切换函数。
- ID命名规范：所有SVG元素及按钮ID必须以 `scene2-` 为前缀。例如：`scene2-curve-summer`、`scene2-curve-winter`、`scene2-curve-equinox`、`scene2-marker-summer`、`scene2-label-summer`、`scene2-btn-summer`、`scene2-btn-winter`、`scene2-btn-equinox`、`scene2-axis-x`、`scene2-axis-y` 等。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })()` 中，避免全局变量污染，确保多场景合并时互不干扰。
