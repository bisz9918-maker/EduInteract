[分步序列]

- 步骤3：点击「下一步」→ 右侧虚线框内容替换为A隔离分析，标题"物体A受力分析"；框内绘制A简图（蓝色矩形，580,230）；从简图底部向下绘制红色箭头G_A（长60px）标注"G_A=29.4N"；从简图顶部偏左向上绘制绿色箭头T（长40px）标注"T=19.6N"；从简图顶部偏右向上绘制蓝色箭头F_浮（长20px）标注"F_浮=9.8N"；下方标注"G_A = T + F_浮"。教师讲解A的三力平衡，建立方程并计算浮力。
- 步骤4：点击「下一步」→ 装置图上叠加力箭头与数值：B左侧标G_B=19.6N（红色向下箭头）和T=19.6N（绿色向上箭头）；A左侧标T=19.6N（绿色向上箭头），右侧标G_A=29.4N（红色向下箭头）和F_浮=9.8N（蓝色向上箭头）；绳子左右两侧分别标绿色"T"；弹簧测力计右侧标注绿色"示数=19.6N"。右侧显示结论框（浅绿背景），列出四个选项的判断：A正确（绿色✓），B/C/D错误（红色✗，并给出正确值）。教师总结力的传递路径与最终答案。

[技术实现]
- JS 库选择：原生 SVG（使用 <svg>、<line>、<circle>、<rect>、<path>、<text>、<polygon> 绘制全部元素），无需额外库。理由：本场景为静态几何图示与简单的显示/隐藏切换，原生SVG性能最佳，无外部依赖。
- 画布尺寸：800 × 500 px（SVG viewBox="0 0 800 500"）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  装置图区(左)          |  隔离分析区(右)            |
  |  天花板/滑轮           |                           |
  |  B----滑轮----弹簧测力计 |  [步骤2/3/4显示]          |
  |        |               |  虚线框+受力箭头+等式      |
  |        A(水中)         |                           |
  |  烧杯+水               |                           |
  |                        |                           |
  |  [步骤1文字说明]        |                           |
  +--------------------------------------------------+
  |  [◀上一步]  [步骤 X/5]  [下一步▶]                |  y=440~490
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `let currentStep = 0;` 记录当前步骤（0~4）。每步对应一个显示元素ID集合，通过 `setAttribute('display', 'none'/'block')` 或 CSS class 控制显隐。
  2. 元素分组：将每步专属元素分别包裹在 `<g id="scene1-step1-group">` 等组内，初始状态除步骤0外全部 `display:none`。步骤2和步骤3共用右侧区域，互斥显示。
  3. 箭头绘制：使用 `<line>` + `<polygon>`（箭头三角形）组合封装为函数 `createArrow(x1,y1,x2,y2,color)`，自动计算箭头角度与顶点坐标。
  4. 力大小比例：G_A=29.4N对应60px，G_B=T=19.6N对应40px，F_浮=9.8N对应20px，保持3:2:2:1的视觉比例。
  5. 动画曲线：本场景无需复杂动画，步骤切换为即时显隐。如需柔和过渡，可对显隐元素添加CSS `transition: opacity 0.3s ease`。
  6. 事件绑定：上一步/下一步按钮绑定 `click` 事件，更新 `currentStep` 后调用 `renderStep()` 刷新视图。在 `renderStep()` 中根据步骤索引遍历所有步骤组，设置对应显示状态。
  7. 边界处理：当 currentStep=0 时禁用「上一步」按钮（降低透明度或置灰）；当 currentStep=4 时禁用「下一步」按钮。
- ID 命名规范：所有SVG元素及JS变量均以 `scene1-` 为前缀。例如：
  - 装置组：`scene1-device-group`
  - 步骤1绳高亮：`scene1-step1-rope-left` 等
  - 步骤2组：`scene1-step2-group`
  - B隔离体框：`scene1-step2-b-box`
  - 按钮：`scene1-btn-prev`、`scene1-btn-next`
  - 步骤文本：`scene1-step-indicator`
