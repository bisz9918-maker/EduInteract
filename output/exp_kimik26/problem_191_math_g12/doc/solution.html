场景导航：Scene 1

题目原文

如图，过点P作圆O的割线PBA与切线PE，E为切点，连接AE，BE，∠APE的平分线分别与AE、BE相交于C、D，若∠AEB=40°，则∠PCE等于．

题目分析

本题综合考查圆的切线性质（弦切角定理）、三角形内角和定理、邻补角关系以及角平分线的定义。解题的核心桥梁是弦切角定理：通过切线PE将圆外角度与圆周角建立等量关系，进而利用三角形内角和建立方程求出关键角度，最终通过角平分线和三角形内角和求得目标角∠PCE。

整体讲解思路

建议教师按照"识别已知条件 → 应用弦切角定理 → 建立方程求基础角 → 利用邻补角求∠APE → 角平分线分角 → 在目标三角形中求解"的递进逻辑进行讲解。

  1. 首先引导学生观察图形结构：识别切线PE、割线PBA、弦AE与BE、角平分线PDC。
  2. 利用弦切角定理将∠PEB、∠PEA转化为圆周角∠EAB、∠EBA。
  3. 在△AEB中利用内角和得到∠EAB + ∠EBA = 140°。
  4. 关键步骤：观察E点处∠PEA、∠PEB、∠AEB的位置关系（∠PEA = ∠PEB + 40°），联立方程求出∠EAB = 50°、∠EBA = 90°。
  5. 在△PBE中利用∠PBE与∠EBA互补求出∠APE = 40°。
  6. 利用角平分线得到∠CPE = 20°。
  7. 在△PCE中求得∠PCE = 70°。

图示规划说明

设计一个交互式几何图示，采用分步按钮导航，将上述7个认知阶段整合为一个连贯的scene。教师可通过"上一步/下一步"控制课堂节奏，每一步聚焦一个推导环节，逐步添加角度标注和几何高亮，避免信息过载。

步骤 1/7

本图示的教学说明

本图示将完整的解题推导过程整合为7个递进步骤，教师应充分利用分步导航的节奏感，引导学生在每一步聚焦一个核心环节。

如何引导学生观察

  • 步骤0：让学生独立观察图形30秒，口头说出图中的所有几何元素（圆、切线、割线、弦、角平分线），培养读图能力。
  • 步骤1：提问"切线PE与弦EB、EA分别形成了什么角？它们与圆内的圆周角有什么关系？"引导学生回忆并应用弦切角定理。
  • 步骤2-3：这是本题的难点。教师应暂停在步骤3，让学生先尝试在草稿纸上建立方程。关键要引导学生发现E点处的角度叠加关系：∠PEA = ∠PEB + ∠AEB（因为射线EB位于∠PEA的内部）。联立
  • ∠PEB + ∠PEA = 140°
  • ∠PEA - ∠PEB = 40°

解得∠PEB = 50°，∠PEA = 90°。

  • 步骤4：引导学生注意P-B-A共线，因此∠PBE与∠EBA互为邻补角。由于∠EBA = 90°，所以∠PBE = 90°。在△PBE中，∠BPE = 180° - 90° - 50° = 40°，即∠APE = 40°。
  • 步骤5：强调角平分线的定义，∠CPE = ∠APE / 2 = 20°。
  • 步骤6：聚焦△PCE，∠PEC = ∠PEA = 90°，因此∠PCE = 180° - 90° - 20° = 70°。

完整推导公式

  1. 由弦切角定理：∠PEB = ∠EAB，∠PEA = ∠EBA
  2. 在△AEB中：∠EAB + ∠EBA = 180° - 40° = 140°
  3. 由E点位置关系：∠PEA = ∠PEB + 40°
  4. 联立解得：∠EAB = 50°，∠EBA = 90°，∠PEB = 50°，∠PEA = 90°
  5. 在△PBE中：∠PBE = 180° - 90° = 90°，故∠APE = 180° - 90° - 50° = 40°
  6. PC平分∠APE：∠CPE = 20°
  7. 在△PCE中：∠PCE = 180° - 90° - 20° = 70°

课堂讲解建议

  • 在步骤3可拓展提问："如果不利用E点的角度叠加关系，还能怎样求出∠EAB和∠EBA？"（提示：利用△PEA和△PBE的内角和，结合∠APE公共，建立关于∠APE的方程。）
  • 强调弦切角定理在本题中的桥梁作用：它将圆外难以直接测量的切线角度，转化为圆内可计算的圆周角。
  • 最后可让学生总结：本题从已知角40°出发，经过弦切角转换、方程求解、邻补角计算、角平分线分角，最终得到70°，体现了"化未知为已知，逐步逼近目标"的几何解题思想。
