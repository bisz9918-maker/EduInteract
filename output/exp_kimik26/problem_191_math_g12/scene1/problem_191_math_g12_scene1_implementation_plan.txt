[图示主题与整合说明]

- 教学价值：教师可通过底部按钮精确控制每步信息呈现，随时回退复习关键定理（弦切角定理、三角形内角和、角平分线性质），符合课堂讲解节奏

[分步序列]
- 步骤0（初始状态）：显示圆O、圆心标记O、点P/A/B/E/C/D、切线PE、割线PBA、弦AE、弦BE、角平分线PDC（淡灰色1px虚线，不抢眼）、所有点标签、∠AEB=40°红色弧线及标签"40°"在(385,125)。公式区空白。
- 步骤1（弦切角定理）：点击「下一步」→ 切线PE与弦EB、EA高亮为蓝色#1565c0（线宽增至3px）；出现蓝色弧线标注∠PEB（中心365,115,半径14）和∠EAB（中心555,238,半径16），配灰色虚线连接标注"="；在(400,100)显示"∠PEB=∠EAB"，在(400,165)显示"∠PEA=∠EBA"。
- 步骤2（△AEB内角和）：点击「下一步」→ △AEB区域蓝色填充透明度15%；高亮∠EAB与∠EBA弧线（蓝色）；公式区显示"∠EAB+∠EBA=180°-40°=140°"。
- 步骤3（E点角度关系与求解）：点击「下一步」→ 在E点叠加展示∠PEA=∠PEB+40°关系（蓝色弧线∠PEA中心375,145半径20，与∠PEB弧线同显）；公式区显示"设∠PEB=x，则∠PEA=x+40°"→"x+(x+40°)=140°"→"x=50°"；随后标注∠EAB=50°在(545,232)、∠EBA=90°在(548,185)、∠PEB=50°在(375,110)、∠PEA=90°在(388,148)；在∠EBA处(532,168)和∠PEA处(358,125)添加黑色直角标记。
- 步骤4（△PBE邻补角）：点击「下一步」→ △PBE区域蓝色填充透明度15%（覆盖△AEB高亮，或两者同显）；高亮∠PBE直角标记；标注∠APE=40°弧线（中心500,58半径16）及标签在(508,65)；公式区显示"△PBE中，∠PBE=90°，∠PEB=50°，∴∠APE=40°"。
- 步骤5（角平分线分角）：点击「下一步」→ 角平分线PDC高亮为绿色#2e7d32实线2.5px；标注∠CPE=20°弧线（中心485,52半径14）及标签在(478,58)；公式区显示"PC平分∠APE，∴∠CPE=20°"。
- 步骤6（最终求解∠PCE）：点击「下一步」→ △PCE区域绿色填充透明度20%；标注∠PEC=90°（复用∠PEA直角标记，高亮）；标注∠PCE=70°绿色粗弧线（中心435,168半径14）及绿色标签"70°"在(428,162)；公式区显示"△PCE中，∠PEC=90°，∠CPE=20°，∴∠PCE=70°"；最终答案高亮。
- 教师可随时点击「上一步」回退复习。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript（本题为纯几何图形与分步显示，无需复杂图表库，原生SVG性能最佳且便于精确控制每个元素的显示/隐藏/颜色/透明度）
- 画布尺寸：800×500px（SVG viewBox="0 0 800 500"）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  P(500,40)                                       |
  |    \                                             |
  |     \        B(540,160)                          |
  |      E(351,117)   /                              |
  |       \          /                               |
  |        \        /                                |
  |         \      /                                 |
  |          \    /                                  |
  |           \  /                                   |
  |    O(420,250)                                    |
  |             圆                                   |
  |              \                                   |
  |               A(570,250)                         |
  |                                                  |
  |  公式文字区 (250,400)         控件栏 (280,455)   |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量currentStep（0~6）记录当前步骤，每步定义show()和hide()函数，切换时先hide旧步再show新步。
  2. 元素分组：按步骤将元素放入SVG <g>组，如<g id="scene1-step1-group">，通过设置display属性控制显隐。
  3. 高亮切换：步骤2/4/6的三角形高亮使用SVG polygon，步骤切换时改变fill-opacity（0→0.15/0.20或反之）。
  4. 角平分线初始状态：步骤0显示为灰色#aaaaaa虚线1px，步骤5高亮为绿色#2e7d32实线2.5px。
  5. 弧线绘制：使用SVG path的A命令绘制圆弧，需计算起点、终点、半径及大弧标志。
  6. 直角标记：使用SVG rect或path绘制小方块，旋转至与两边对齐。
  7. 动画曲线：本场景为分步切换，无需连续动画，直接显示/隐藏即可。如需平滑过渡，可使用CSS transition控制opacity（0.3s ease）。
  8. 事件绑定：按钮绑定click事件，更新currentStep并调用render()函数重新渲染。
  9. 边界处理：步骤0时「上一步」禁用（opacity 0.3, pointer-events none），步骤6时「下一步」禁用。
- ID命名规范：所有交互元素ID以scene1-为前缀，如scene1-circle-o、scene1-point-p、scene1-line-pe、scene1-arc-aeb、scene1-step2-group、scene1-btn-prev、scene1-btn-next、scene1-step-indicator。
- IIFE隔离：所有JavaScript代码包裹在(function() { ... })()中，避免全局变量污染。
