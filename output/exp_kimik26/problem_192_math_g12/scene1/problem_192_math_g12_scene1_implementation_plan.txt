[图示主题与整合说明]
- 本图示主题：牛顿调和三角形的递推规律与第6行第2个数的推导
- 整合的步骤/概念：(1) 前5行完整数阵的结构认知；(2) 递推关系"上一行数=下一行左右相邻两数之和"的可视化验证（可点击切换不同示例）；(3) 由第5行首数与第6行首数倒推第6行第2个数，展示分数减法通分过程；(4) 补全第6行并确认答案
- 教学价值：教师通过分步导航控制课堂节奏，步骤1支持点击任意父节点观察递推实例，步骤2通过"揭示计算"制造认知悬念，引导学生自主思考后再展示推导过程

[分步序列]
- 步骤0（初始状态）：
  - 显示行1~行5完整牛顿调和三角形，所有节点默认样式（白底黑框黑字）
  - 显示所有向下箭头，黑色实线，opacity=1
  - 不显示等式框、计算文本框、行6节点、"答案"标注
  - 底部仅显示「下一步 ▶」按钮（「◀ 上一步」disabled）

- 步骤1（验证递推）：
  - 点击「下一步」进入
  - 默认高亮示例：第2行第1个节点"1/2"设为蓝色高亮；其向下连接的第3行第1个"1/3"和第2个"1/6"设为绿色高亮；连接这三个节点的两条箭头设为绿色实线
  - 其余所有节点和箭头淡化（opacity=0.4）
  - 右侧等式框出现，显示"1/2 = 1/3 + 1/6"，绿色文字
  - 教师可点击行1~行4的任意节点切换示例：点击后，该节点变蓝，其下一行左右相邻两节点变绿，对应箭头变绿，等式文本更新（如点击"1/3"则显示"1/3 = 1/4 + 1/12"）
  - 底部显示「◀ 上一步」「下一步 ▶」

- 步骤2（倒推第6行）：
  - 点击「下一步」进入
  - 整体数阵淡化（opacity=0.4）
  - 仅高亮两个节点：第5行第1个"1/5"（蓝色）、第6行第1个"1/6"（蓝色）
  - 行6第2个位置显示一个虚线边框矩形（215,325)-(285,365)，内部无文字，表示待求
  - 计算文本框出现，显示"第6行第2个数 = ?"
  - 底部显示三个按钮：「◀ 上一步」「揭示计算」「下一步 ▶」
  - 点击「揭示计算」后：
    * 行6第2个位置虚线框变为实线红框，填充红色半透明，显示"1/30"红色文字
    * 计算文本框更新为："1/5 − 1/6 = 6/30 − 5/30 = 1/30"（其中"1/30"红色加粗）
    * 「揭示计算」按钮变为disabled状态（灰色）或隐藏，底部恢复为「◀ 上一步」「下一步 ▶」

- 步骤3（确认答案）：
  - 点击「下一步」进入
  - 所有节点恢复opacity=1，行1~6完整显示
  - 第6行其余数字补全：1/60, 1/60, 1/30, 1/6（默认黑白色）
  - 第6行第2个"1/30"保持红色高亮（红框+红字+红填充）
  - "答案"引线标注出现：从节点(250,325)向上到(250,315)，再向左到(205,315)，连接文本"答案"(185,315)，红色
  - 计算文本框保持显示完整减法过程
  - 底部显示「◀ 上一步」（「下一步 ▶」disabled）

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶），步骤1内部支持节点点击切换示例，步骤2内部支持「揭示计算」按钮触发子状态
- 控件说明：
  1. 「◀ 上一步」：位于底部x=295,y=452（步骤2时x=235），返回上一分步
  2. 「下一步 ▶」：位于底部x=415,y=452（步骤2时x=475），进入下一分步
  3. 「揭示计算」：仅步骤2未揭示时显示于底部中央x=355,y=452，点击后展示减法推导过程与红色高亮结果
- 教师操作流程：
  1. 步骤0展示完整数阵，教师讲解"两端为1/n"的直观规律
  2. 进入步骤1，教师先观察默认示例"1/2=1/3+1/6"，再点击其他节点（如"1/12"）验证递推关系，强化"每个数等于下一行左右相邻两数之和"
  3. 进入步骤2，教师先让学生思考"已知1/5和1/6，如何求第6行第2个数"，再点击「揭示计算」展示分数减法
  4. 进入步骤3，确认答案并补全第6行，完成教学闭环

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本场景为静态几何图形与状态切换，无复杂动画或数据可视化，原生SVG足以高效实现，避免引入不必要依赖
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                    [1/1]                           |  y=35~75
  |                 [1/2] [1/2]                        |  y=95~135
  |              [1/3] [1/6] [1/3]                     |  y=155~195
  |           [1/4][1/12][1/12][1/4]                   |  y=215~255
  |        [1/5][1/20][1/30][1/20][1/5]                |  y=265~305
  |     [1/6][1/30][1/60][1/60][1/30][1/6]             |  y=325~365
  |                                                    |
  |        [计算过程文本框: 1/5-1/6=...=1/30]          |  y=385~420
  |                                                    |
  |           [◀ 上一步] [揭示计算] [下一步 ▶]          |  y=452~488
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `currentStep` ∈ {0,1,2,3}，`step2Revealed` ∈ {false,true}。每次状态变更调用 `render()` 函数，根据状态显隐/高亮对应SVG元素
  2. 节点点击事件（步骤1）：为每个可点击父节点（行1~行4）绑定click事件，记录 `selectedNode`（如"r2c1"），`render()` 时根据selectedNode计算其两个子节点坐标并应用蓝/绿高亮
  3. 箭头高亮逻辑：步骤1中，仅保留从selectedNode到其两个子节点的箭头为绿色opacity=1，其余箭头opacity=0.4；步骤2中所有箭头opacity=0.4
  4. 节点显隐控制：行6节点使用display属性控制，步骤0/1完全不渲染；步骤2仅渲染节点1（及揭示后的节点2）；步骤3渲染全部6个
  5. 计算文本框内容切换：步骤2初始innerText="第6行第2个数 = ?"；揭示后innerHTML="1/5 − 1/6 = 6/30 − 5/30 = <b style='color:#c62828'>1/30</b>"
  6. 按钮状态同步：`render()` 中根据currentStep和step2Revealed设置各按钮的disabled与display属性
- ID命名规范：
  - 节点：`scene1-node-r{行}c{列}`，如 `scene1-node-r2c1`
  - 箭头：`scene1-arrow-r{行}c{列}-r{下行}c{下列}`
  - 等式框：`scene1-eq-box`、`scene1-eq-text`
  - 计算框：`scene1-calc-box`、`scene1-calc-text`
  - 答案标注：`scene1-answer-line`、`scene1-answer-text`
  - 按钮：`scene1-btn-prev`、`scene1-btn-next`、`scene1-btn-reveal`
  - 获取方式：document.getElementById，禁止querySelectorAll配合全局class
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })()` 中，避免多场景合并时变量污染
