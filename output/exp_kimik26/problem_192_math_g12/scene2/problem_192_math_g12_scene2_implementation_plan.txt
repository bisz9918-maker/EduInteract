[图示主题与整合说明]
- 本图示主题：牛顿调和三角形与杨辉三角的关联及通项公式推导
- 整合的步骤/概念：(1) 杨辉三角与牛顿调和三角形的并列对比展示；(2) 通过高亮对应位置引导学生发现"牛顿数 = 1/(行号 × 杨辉对应数)"的规律；(3) 写出一般通项公式 a_{n,k} = 1/(n·C_{n-1}^{k-1})；(4) 固定 k=3 推导第 n 行第 3 个数的通项并代入 n=5 验证
- 教学价值：教师可通过分步导航控制课堂节奏，在步骤1停留让学生自行发现多组对应关系；步骤2抽象出符号公式；步骤3完成具体推导与数值验证，形成完整认知链条

- 步骤2（写出通项）：

  * 公式中"C_{n-1}^{k-1}"部分使用蓝色(#1565c0)，整体等号为绿色(#2e7d32)
  * 从公式左侧画一条绿色箭头指向杨辉三角第4行区域，从公式右侧画一条红色箭头指向牛顿三角第4行区域（暗示公式对左右均适用）

- 步骤3（推导第3个数）：
  * 点击「下一步」触发
  * 仅保留第5行第3组高亮（杨辉"6"蓝，牛顿"1/30"红），其余节点恢复默认样式；仅保留第5行对应连线为绿色，其余恢复灰色虚线

[技术实现]
- JS库选择：原生 SVG + 原生 JavaScript。理由：本场景以静态几何图形、文本标签和简单状态切换为主，无需复杂图表库；公式可直接用 SVG text/tspan 渲染，避免引入 MathJax 带来的异步加载和布局不确定性
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------------+
  |                                                        |
  |    杨辉三角                    牛顿调和三角形            |
  |       |                             |                  |
  |      (1)                          [1/1]                |
  |    (1)  (1)                    [1/2][1/2]              |
  |   (1)  (2)  (1)              [1/3][1/6][1/3]           |
  |  (1) (3)  (3) (1)          [1/4][1/12][1/12][1/4]     |
  | (1)(4) (6) (4)(1)       [1/5][1/20][1/30][1/20][1/5] |
  |       |        关系式/公式区         |                 |
  |       +------------------------------+                 |
  |            [◀ 上一步]  [下一步 ▶]                     |
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用全局变量 `let currentStep = 0;` 记录当前步骤（0~3）。定义 `const steps = ['step0', 'step1', 'step2', 'step3'];`。每次点击按钮时调用 `renderStep(newStep)`，该函数根据步骤索引批量设置元素的 class 和 visibility。
  2. 节点高亮实现：为每个 SVG 节点预定义两种状态 class——默认类（如 `pascal-node`）和高亮类（如 `pascal-node-highlight`）。`renderStep` 通过 `element.classList.add/remove` 切换。高亮类通过 CSS 改变 fill、stroke、stroke-width 和 r（或 width/height）。
  3. 连线状态：15条连线统一用 `<line>` 元素，默认 class `link-line`（灰色虚线）。步骤1时，将4条对应连线改为 class `link-line-active`（绿色实线）；步骤3时仅保留1条 active，其余恢复。
  4. 公式区内容切换：公式区内预置4组 `<text>` 元素（或 `<g>` 组），分别对应4个步骤的文本内容。`renderStep` 通过 `setAttribute('display', 'none/block')` 控制显隐，避免频繁 DOM 创建销毁。
  5. 动画曲线：节点高亮切换使用 CSS transition（fill 0.3s, stroke-width 0.3s, r 0.3s），提供平滑视觉反馈；公式区文本切换使用 opacity transition（0.2s fade-in）。
  6. 事件绑定：在 IIFE 内为两个按钮绑定 `click` 事件监听器，更新 `currentStep` 后调用 `renderStep`。
  7. 公式渲染：使用 SVG `<text>` + `<tspan>` 实现下标效果。例如组合数 "C_{n-1}^{k-1}" 可写为：主文本 "C" + tspan(dy="-0.5em" font-size="0.7em") "k-1" + tspan(dy="0.5em") 回到基线 + tspan(dy="0.3em" font-size="0.7em") "n-1"。分数直接采用 "a/b" 线性写法以保清晰。
- ID命名规范：所有交互元素 ID 必须以 `scene2-` 为前缀。例如：
  * 杨辉节点：`scene2-pascal-r1c1`, `scene2-pascal-r2c1`...（r=row, c=col）
  * 牛顿节点：`scene2-newton-r1c1`, `scene2-newton-r3c2`...
  * 连线：`scene2-link-r1c1`, `scene2-link-r3c2`...
  * 公式文本组：`scene2-formula-step0`, `scene2-formula-step1`...
  * 按钮：`scene2-btn-prev`, `scene2-btn-next`
  * 步骤指示器：`scene2-step-indicator`
  * JS 中统一使用 `document.getElementById` 获取元素，禁止用 `querySelectorAll` 配合全局 class 选择，避免多场景合并时跨场景污染
- IIFE 隔离：所有 JavaScript 代码包裹在 `(function() { ... })();` 中，内部变量与函数不污染全局作用域
