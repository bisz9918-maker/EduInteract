[分步序列]
- 步骤0（初始状态-整体展示）：
  - 三个图框均为黑色实线边框（stroke=#000000, stroke-width=2），内部图形无填充（fill=none）
  - 所有尺寸标注线及数值标签显示
  - 图框标题"正视图""侧视图""俯视图"显示
  - 无对应关系虚线，无高亮填充

- 步骤1（正视图高亮）：
  - 正视图框：切换为蓝色实线边框(#1565c0, stroke-width=3)，三角形添加蓝色填充(#1565c0, fill-opacity=0.15)
  - 侧视图框：切换为灰色虚线边框(#888888, stroke-dasharray=5,5)，内部图形及标注变为灰色(#888888, opacity=0.5)
  - 俯视图框：切换为灰色虚线边框(#888888, stroke-dasharray=5,5)，内部图形及标注变为灰色(#888888, opacity=0.5)
  - 正视图标注保持黑色清晰显示
  - 无对应关系虚线

- 步骤2（侧视图高亮）：
  - 侧视图框：切换为红色实线边框(#c62828, stroke-width=3)，三角形添加红色填充(#c62828, fill-opacity=0.15)
  - 正视图框：灰色虚线边框，内部图形及标注灰色淡化
  - 俯视图框：灰色虚线边框，内部图形及标注灰色淡化
  - 侧视图标注保持黑色清晰显示
  - 无对应关系虚线

- 步骤3（俯视图高亮）：
  - 俯视图框：切换为绿色实线边框(#2e7d32, stroke-width=3)，半圆和三角形添加绿色填充(#2e7d32, fill-opacity=0.15)
  - 正视图框：灰色虚线边框，内部图形及标注灰色淡化
  - 侧视图框：灰色虚线边框，内部图形及标注灰色淡化
  - 俯视图标注保持黑色清晰显示
  - 无对应关系虚线

- 步骤4（对应关系）：
  - 三个图框均恢复黑色实线边框（stroke=#000000, stroke-width=2），内部图形无填充或保持极淡填充
  - 所有标注恢复黑色正常显示
  - 显示三条对应关系虚线（#888888, stroke-dasharray=6,4）
  - 显示"长对正""高平齐""宽相等"文字标签
  - 教师可点击"上一步"回退到任意视图单独讲解

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于(300,465)，宽80px，点击回退到上一分步状态
  - 「下一步」按钮：位于(420,465)，宽80px，点击前进到下一分步状态
  - 步骤指示器：位于(400,495)，显示当前步骤文字如"步骤 1/5"
- 教师操作流程：
  1. 教师打开图示，步骤0展示三视图全貌，建立整体认知
  2. 点击「下一步」进入步骤1，正视图高亮，教师讲解正视图形状（等腰三角形）及尺寸（底2、高a）
  3. 点击「下一步」进入步骤2，侧视图高亮，教师强调侧视图与正视图"相同"
  4. 点击「下一步」进入步骤3，俯视图高亮，教师讲解俯视图由半圆（半径1）和等腰三角形（底2、高1）组成
  5. 点击「下一步」进入步骤4，显示三视图对应关系虚线，教师讲解"长对正、高平齐、宽相等"投影规律
  6. 可随时点击「上一步」回退到任意步骤强化讲解

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：本场景为静态几何图形与CSS类切换，无需复杂动画库，原生SVG路径绘制三视图最精确，原生JS控制状态机足够轻量
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  +--------------------------------------------------------+
  |  正视图框(90,50)        侧视图框(490,50)               |
  |  +----------------+     +----------------+             |
  |  |     /\         |     |     /\         |             |
  |  |    /  \   a    |     |    /  \   a    |             |
  |  |   /    \  |    |     |   /    \  |    |             |
  |  |  /______\_|    |     |  /______\_|    |             |
  |  |   1   1        |     |   1   1        |             |
  |  +----------------+     +----------------+             |
  |  正视图                侧视图                          |
  |                                                        |
  |         俯视图框(290,250)                              |
  |         +--------------------+                         |
  |         |    ____________    |  <- 半圆（上半部分）    |
  |         |   /            \   |                         |
  |         |  (              )  |                         |
  |         |   \____________/   |                         |
  |         |    \     |     /   |  <- 三角形（下半部分）  |
  |         |     \    1    /    |                         |
  |         |      \   |   /     |                         |
  |         |       \  |  /      |                         |
  |         |        \ | /       |                         |
  |         |         \|/        |                         |
  |         |    1____|____1     |                         |
  |         +--------------------+                         |
  |                 俯视图                                 |
  |                                                        |
  |         [上一步]  步骤 X/5  [下一步]                   |
  +--------------------------------------------------------+
  控件栏区域：y=460~490
  ```
- 关键实现要点：
  1. 状态机设计：变量 `currentStep` 取值 0~4，初始化0。`updateScene()` 函数根据 currentStep 切换各元素的 CSS class。
  2. CSS类定义：
     - `.normal`：stroke=#000000, stroke-dasharray=none, fill=none, opacity=1
     - `.dimmed`：stroke=#888888, stroke-dasharray=5,5, opacity=0.5
     - `.highlight-blue`：stroke=#1565c0, stroke-width=3, fill=#1565c0, fill-opacity=0.15
     - `.highlight-red`：stroke=#c62828, stroke-width=3, fill=#c62828, fill-opacity=0.15
     - `.highlight-green`：stroke=#2e7d32, stroke-width=3, fill=#2e7d32, fill-opacity=0.15
     - `.hidden`：display=none
  3. 箭头实现：在 SVG `<defs>` 中定义 `<marker id="scene1-arrow-start">` 和 `<marker id="scene1-arrow-end">`，尺寸8×6px，用于尺寸标注线两端。
  4. 动画曲线：本场景无位移动画，仅透明度/颜色切换，使用 CSS transition（transition: all 0.3s ease）实现平滑过渡。
  5. 事件绑定：上一步/下一步按钮绑定 click 事件，调用 `prevStep()` / `nextStep()`，内部更新 currentStep 并调用 `updateScene()`。
  6. 边界控制：currentStep 最小0最大4，按钮在边界时禁用（disabled 属性）。
- ID命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀。例如：
  - 图框：`scene1-frame-front`、`scene1-frame-side`、`scene1-frame-top`
  - 图形：`scene1-tri-front`、`scene1-tri-side`、`scene1-semi-top`、`scene1-tri-top`
  - 标注线：`scene1-dim-front-base-l`、`scene1-dim-front-height` 等
  - 标签：`scene1-label-front-title`、`scene1-label-front-base-l` 等
  - 虚线：`scene1-relation-length`、`scene1-relation-height`、`scene1-relation-width`
  - 规律文字：`scene1-text-length`、`scene1-text-height`、`scene1-text-width`
  - 控件：`scene1-btn-prev`、`scene1-btn-next`、`scene1-step-indicator`
  - JS中严格使用 `document.getElementById()` 获取元素，禁止 querySelectorAll 配合全局 class，避免多场景合并时跨场景污染
- IIFE隔离：所有 JavaScript 代码包裹在 `(function() { ... })()` 立即执行函数中，变量不泄露全局作用域
