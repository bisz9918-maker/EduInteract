[分步序列]
- 步骤0（底面）：显示坐标轴、底面半圆（蓝色实线）、底面三角形（红色实线）、底面各顶点标签O/A/B/C/D、坐标轴标签x/y/z。隐藏OP、P、a、所有母线/侧棱、填充、投影图。
- 步骤1（拔高）：在步骤0基础上，显示绿色竖直线段OP，标记顶点P和高度a；从P向B/A/C/D引出绿色虚线（stroke-dasharray="4,4"），暗示底面区域向顶点收敛。教师可讲解"以底面为基础，向上拔高至公共顶点"。
- 步骤2（半圆锥）：高亮上半部分——半圆锥轮廓线加粗（蓝色），填充蓝色半透明（opacity 0.2），母线PB/PA/PC改为蓝色实线，显示"半圆锥"标签；下半部分三棱锥全面淡化（灰色#888888虚线，opacity 0.3）。教师讲解半圆锥的构成。
- 步骤3（三棱锥）：高亮下半部分——三棱锥轮廓线加粗（红色），填充红色半透明（opacity 0.2），侧棱PB/PA/PD改为红色实线，显示"三棱锥"标签；上半部分半圆锥全面淡化（灰色#888888虚线，opacity 0.3）。教师讲解三棱锥的构成。
- 步骤4（组合体）：同时显示两部分，恢复完整组合体。半圆锥与三棱锥均用实线轮廓+半透明填充（opacity均降至0.15避免叠加过深），添加深灰色偏移阴影（底面BAD复制偏移5px，rgba(0,0,0,0.1)）区分前后关系。标注公共顶点P与总高a。教师讲解组合体整体结构。
- 步骤5（投影验证）：保持组合体显示，在右侧添加正视图/侧视图/俯视图三个小视图。从3D模型特征点向对应小视图发射灰色虚线折线：P→正视图顶点、P→侧视图顶点、C→俯视图弧顶、O→俯视图圆心、D→俯视图三角形顶点。教师验证与题目三视图一致。

[交互方案]

- 控件说明：
  1. 「上一步」按钮：位于(250,455)，宽80高30，点击回退到上一分步
  2. 步骤指示器：位于(400,475)，显示当前步骤编号（如"步骤 2/6"）
  3. 「下一步」按钮：位于(470,455)，宽80高30，点击进入下一分步
- 教师操作流程：教师先点击「下一步」逐步展示建构过程；在步骤2/3分别聚焦讲解半圆锥和三棱锥；步骤4展示整体；步骤5验证三视图。可随时点击「上一步」回退复习。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本场景以3D线框图和静态填充为主，无需复杂数学计算库；SVG的path、line、text足以表达所有几何元素；原生JS状态机即可控制分步显示。
- 画布尺寸：800 × 500 px（SVG viewBox="0 0 800 500"）
- 布局草图（ASCII）：
  ```
  0    100  200  300  400  500  600  700  800
       |    |    |    |    |    |    |    |
  0  - +----+----+----+----+----+----+----+ --
       |              [P]        [正视图]     | 50
       |               |                      |
       |               | a                    |
       |               |                      |
  100 - |      [C]  半圆锥      [侧视图]       |
       |     /   \                            |
       |    /     \                           |
       |   /       \                          |
  200 - |  /         \         [俯视图]        |
       | /           |                        |
       |B------O------A                       |
       | \           /                        |
       |  \         /  三棱锥                 |
  300 - |   \       /                         |
       |    [D]                               |
       |                                      |
       |                                      |
  400 - |                                      |
       |  [上一步]  步骤X/6  [下一步]          | 控件栏
       |                                      |
  500 - +----+----+----+----+----+----+----+ --
  ```
- 关键实现要点：
  1. 投影函数：统一函数 project(x,y,z) 返回 [x_s, y_s]，所有3D坐标通过该函数映射到2D画布，确保一致性。
  2. 半圆弧生成：预计算15°步长的采样点数组，用SVG path的L命令连接，避免非标准椭圆弧的复杂计算。
  3. 状态机设计：currentStep ∈ [0,5]，每一步维护一个显示配置对象（各元素组的 visibility / opacity / stroke-dasharray / stroke-width）。点击按钮时更新currentStep并批量应用配置。
  4. 动画曲线：步骤切换使用CSS transition（opacity 0.3s ease, stroke-width 0.3s ease），避免生硬跳变；新元素从opacity 0淡入，淡化元素降至opacity 0.3。
  5. 填充区域：半圆锥填充用path="M B ...弧... A L P Z"；三棱锥分三个侧面path分别填充，便于步骤3单独高亮。
  6. 步骤5虚线：采用折线（水平段+斜向段），水平段y坐标与起点一致，斜向段连接至右侧小视图，避免穿越3D模型主体。
- ID命名规范：所有交互元素ID必须以 scene2- 为前缀。例如：scene2-axes, scene2-base-semicircle, scene2-cone-fill, scene2-pyramid-frame, scene2-label-p, scene2-btn-prev, scene2-btn-next, scene2-step-indicator。
- IIFE隔离：所有JavaScript代码包裹在 (function() { ... })() 中，避免多场景合并时的全局变量污染。
