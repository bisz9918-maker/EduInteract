- 公式文本块：使用 MathJax 渲染，包含分数、希腊字母 π、下标 V_1/V_2。步骤 0 中 V_1 与结果 πa/6 使用蓝色 #1565c0；步骤 1 中 V_2 与结果 a/3 使用红色 #c62828；步骤 2~3 中等号与最终结果使用绿色 #2e7d32。

[分步序列]
- 初始状态（步骤 0）——半圆锥体积：
  - 左侧显示半圆锥完整示意图（半圆底+轴截面三角形+辅助高线），标注 r=1、h=a、底边 2。
  - 右侧显示蓝色标题"半圆锥"与三行公式：
    V_1 = \frac{1}{2} \cdot \frac{1}{3} \pi r^2 h
    = \frac{1}{2} \cdot \frac{1}{3} \pi \cdot 1^2 \cdot a
    = \frac{\pi a}{6}  （本行蓝色高亮）
  - 控件："上一步"禁用，"下一步"启用，指示器显示"1 / 4"。

- 步骤 1——三棱锥体积：
  - 点击"下一步"，左侧半圆锥淡出，三棱锥淡入（底面等腰三角形+三条侧棱+辅助线），标注底边 2、底面高 1、锥高 a。
  - 右侧切换为红色标题"三棱锥"与三行公式：
    V_2 = \frac{1}{3} S_{\text{底}} h
    = \frac{1}{3} \cdot \left( \frac{1}{2} \cdot 2 \cdot 1 \right) \cdot a
    = \frac{a}{3}  （本行红色高亮）
  - 指示器更新为"2 / 4"。

- 步骤 2——总体积合并：
  - 点击"下一步"，左侧同时显示缩小并排的两个图形（左半圆锥+右三棱锥），保持各自颜色与标注。
  - 右侧切换为标题"总体积"与四行公式（逐行递进）：
    V = V_1 + V_2
    = \frac{\pi a}{6} + \frac{a}{3}
    = \frac{\pi a}{6} + \frac{2a}{6}
    = \frac{(\pi+2)a}{6}  （本行绿色高亮）
  - 指示器更新为"3 / 4"。

- 步骤 3——求解 a：
  - 点击"下一步"，左侧图形全部隐藏（仅保留右侧公式区）。
  - 右侧显示三行内容：
    V = \frac{\pi + 2}{6}
    \frac{(\pi+2)a}{6} = \frac{\pi+2}{6}
    \Rightarrow a = 1  （大字号，绿色高亮框包围）
  - 高亮框下方显示绿色"答案"标签。
  - 指示器更新为"4 / 4"，"下一步"禁用。

- 回退机制：教师可随时点击"上一步"回退到任意步骤复习，左侧图形与右侧公式同步反向切换。

[技术实现]
- JS 库选择：MathJax（CDN，用于渲染分数与希腊字母 π）、原生 SVG（用于几何图形）。不引入 D3/Three.js，避免过重。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图：
  ```
  +--------------------------------------------------+
  |  左侧图形区 (x:20~300)      右侧公式区 (x:340~780) |
  |  +---------------------+   +--------------------+ |
  |  |  半圆锥/三棱锥示意图 |   |  MathJax 公式块    | |
  |  |  (SVG)              |   |  (HTML absolute)   | |
  |  +---------------------+   +--------------------+ |
  |                                                  |
  |  [◀ 上一步]  [ 2 / 4 ]  [下一步 ▶]               |  y=455~491
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. **层级结构**：底层为 800×500 SVG，上方用 `position:absolute` 叠加 HTML 公式 div 与按钮控件，确保不撑高容器。
  2. **状态机**：`let currentStep = 0;` 共 4 个状态（0~3）。维护 `scene3-step-0` ~ `scene3-step-3` 四组视觉元素（每组包含左侧 SVG g 元素与右侧 formula div）。
  3. **显示/隐藏**：使用 CSS class `.scene3-hidden { opacity: 0; pointer-events: none; }` 与 `.scene3-visible { opacity: 1; }`，配合 `transition: opacity 0.3s ease`。步骤切换时先隐藏当前组、再显示目标组。
  4. **按钮状态**：`scene3-btn-prev` 与 `scene3-btn-next` 的 `disabled` 属性随 `currentStep` 更新（0 时 prev 禁用，3 时 next 禁用）。
  5. **MathJax 预渲染**：页面加载时一次性渲染所有 4 个公式容器，步骤切换仅控制容器 `display/opacity`，避免重复排版导致的闪烁。
  6. **颜色高亮**：公式中的颜色通过 MathJax `\color{#1565c0}{...}` / `\color{#c62828}{...}` / `\color{#2e7d32}{...}` 实现；最终步骤的 `a=1` 额外包裹一个绿色背景 div（`scene3-answer-box`）。
  7. **SVG 组管理**：左侧图形使用 `<g id="scene3-cone-group">`、`<g id="scene3-pyramid-group">`、`<g id="scene3-both-group">`，通过添加/移除 `scene3-hidden` class 控制显隐。
- **ID 命名规范**：所有交互元素 ID 必须以 `scene3-` 为前缀。例如：
  - SVG 组：`scene3-cone-group`, `scene3-pyramid-group`, `scene3-both-group`
  - 公式容器：`scene3-formula-0`, `scene3-formula-1`, `scene3-formula-2`, `scene3-formula-3`
  - 按钮：`scene3-btn-prev`, `scene3-btn-next`
  - 指示器：`scene3-step-indicator`
  - 高亮框：`scene3-answer-box`
  JS 中严格使用 `document.getElementById` 获取，禁止全局 class 查询，避免多场景合并时污染。
- **IIFE 隔离**：所有本场景 JS 包在 `(function() { ... })();` 中，内部变量不泄露全局作用域。
