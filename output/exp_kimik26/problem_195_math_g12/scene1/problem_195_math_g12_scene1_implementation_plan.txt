[分步序列]
- 步骤0【识图】（初始状态）：
  - 显示元素：圆O、直径AC、切线PA、割线PC（完整）、线段AB、所有点标签（P,A,B,C,O）
  - 显示标注：PA=2（蓝）、PB=1（蓝）
  - 公式面板："已知条件：PA = 2，PB = 1，PA是圆O的切线，AC是圆O的直径"
  - 所有线段为黑色实线，线宽2px

- 步骤1【发现垂直】：
  - 新增元素：A点直角符号（蓝#1565c0，12×12路径）
  - 高亮变化：PA线段变为蓝#1565c0线宽3px，AC线段变为蓝#1565c0线宽3px
  - 公式面板："切线 ⊥ 过切点的直径 → ∠PAC = 90°"，下方补充"因此△PAC是直角三角形"

- 步骤2【应用定理】：
  - 高亮变化：PA恢复黑色，AC变为灰色#888888（弱化），割线PC整体变为绿#2e7d32线宽3px
  - 公式面板："切割线定理：PA² = PB · PC"，下方显示"2² = 1 × PC"

- 步骤3【计算长度】：
  - 新增标注：PC=4（绿，位置(250, 230)）、BC=3（绿，位置(270, 195)）
  - 高亮变化：PB线段保持黑色，BC线段变为绿#2e7d32线宽3px（与PC同高亮）
  - 公式面板："PA² = PB · PC → 4 = 1 × PC → PC = 4"，下方"BC = PC − PB = 4 − 1 = 3"

- 步骤4【勾股定理】：
  - 新增元素：Rt△PAC填充（蓝#1565c0，polygon覆盖P-A-C，opacity 0.2）
  - 新增标注：AC=2√3（绿，位置(345, 255)）
  - 高亮变化：PA恢复蓝线宽3px，AC恢复蓝线宽3px，PC恢复黑色
  - 直角符号保持显示
  - 公式面板："在Rt△PAC中：AC² + PA² = PC²" → "AC² = 16 − 4 = 12" → "AC = 2√3"

- 步骤5【得出结论】：
  - 新增高亮：半径OA线段变为红#c62828线宽3px
  - 新增标注：R=√3（红，位置(345, 323.5)）
  - 高亮变化：△PAC填充可保持或略微淡化，突出半径OA
  - 公式面板："圆的半径 R = AC / 2 = 2√3 / 2 = √3"，最终答案红字大字号"R = √3"

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「◀ 上一步」按钮：位置(250, 455)，100×36px，点击回退到上一步骤，步骤0时禁用
  2. 步骤指示器：位置(360, 455)，显示当前步骤/总步骤（如"1 / 6"）
  3. 「下一步 ▶」按钮：位置(450, 455)，100×36px，点击前进到下一步，步骤5时禁用
- 教师操作流程：
  1. 教师打开图示，学生看到步骤0的完整原题图形与已知条件
  2. 教师点击「下一步」进入步骤1，引导学生观察PA⊥AC的直角关系
  3. 继续点击「下一步」，依次呈现切割线定理、长度计算、勾股定理、最终结论
  4. 讲解中可随时「上一步」回退，让学生重新观察某一步的图形特征
  5. 每一步右侧公式面板同步显示对应推导，教师可配合面板文字讲解

[技术实现]
- JS库选择：原生SVG + 原生JavaScript（无需外部库）。理由：本场景为静态几何图形与分步显隐控制，SVG原生支持所有图形元素，JavaScript直接操作DOM属性即可实现状态切换，引入D3等库反而增加体积。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  0    100  200  300  400  500  600  700  800
  0    +----+----+----+----+----+----+----+----+
  50   |         [C]                       [公式面板]  |
  100  |            圆O                      |         |
  150  |         (320,64)                    | 步骤0-5 |
  200  |            /|\                      | 推导文本|
  250  |    [B]----O(320,237)                | 动态切换|
  300  |   /       |                        |         |
  350  | [P]-------[A]                       |         |
  400  | (120,410)(320,410)                  |         |
  440  |    [◀ 上一步]  [1 / 6]  [下一步 ▶]         |
  500  +----+----+----+----+----+----+----+----+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `currentStep`（0~5），数组 `stepConfig` 定义每一步的显隐规则与高亮样式。每次点击按钮时调用 `renderStep()` 函数，根据当前步骤遍历所有元素ID，设置 `display` / `stroke` / `stroke-width` / `fill-opacity` 属性。
  2. 坐标计算：所有几何坐标硬编码（见布局坐标表），B点坐标通过PC的1/4分点计算得出(170, 323.5)。
  3. 动画曲线：无需复杂动画，元素显隐使用CSS transition（opacity 0.3s ease），线段高亮直接切换stroke属性。
  4. 事件绑定：按钮绑定click事件，更新currentStep后调用renderStep()，同时更新按钮disabled状态与步骤指示器文本。
  5. 公式面板：使用HTML div绝对定位覆盖在SVG上方（或SVG foreignObject），每一步切换innerHTML内容。数学符号使用Unicode（²、√、·）。
  6. 防重叠：所有标签使用SVG text元素，通过x/y精确定位，避免使用可能产生偏移的text-anchor之外的方式。
- **ID 命名规范**：所有交互元素ID必须以 `scene1-` 为前缀。例如：
  - 图形元素：`scene1-circle`, `scene1-line-ac`, `scene1-line-pa`, `scene1-line-pc`, `scene1-line-ab`, `scene1-line-pb`, `scene1-line-bc`, `scene1-line-oa`
  - 标签元素：`scene1-label-p`, `scene1-label-a`, `scene1-label-b`, `scene1-label-c`, `scene1-label-o`, `scene1-text-pa`, `scene1-text-pb`, `scene1-text-pc`, `scene1-text-bc`, `scene1-text-ac`, `scene1-text-r`
  - 特殊元素：`scene1-right-angle`, `scene1-triangle-fill`, `scene1-formula-panel`, `scene1-formula-text`
  - 控件元素：`scene1-btn-prev`, `scene1-btn-next`, `scene1-step-indicator`
  - JS中严格使用 `document.getElementById` 获取元素，禁止全局class选择器，避免多场景合并时跨场景污染。
- IIFE 隔离：所有JavaScript代码包裹在 `(function() { ... })()` 立即执行函数中，变量不污染全局作用域。
