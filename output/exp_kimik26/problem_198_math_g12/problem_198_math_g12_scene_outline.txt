<TEXT_1>
**题目原文**

(2011•江门一模)如图，P是圆O外一点，直线PO与圆O相交于C、D，PA、PB是圆O的切线，切点为A、B．若PC=CD=1，则四边形PADB的面积S=______．

**题目分析**

本题是一道圆的几何综合题，核心考查切线性质、勾股定理、等腰三角形对称性以及四边形面积计算。已知条件集中在割线PCD上（PC=CD=1），目标为求四边形PADB的面积。解题关键在于：

1. 由PC=CD=1快速得到圆的半径
2. 利用切线性质（切线垂直于过切点的半径）构造直角三角形求切线长PA
3. 利用图形的轴对称性（直线PD为对称轴）确定弦AB与PD垂直，并求出弦长AB
4. 利用对角线互相垂直的四边形面积公式求得结果

**整体讲解思路**

建议采用"条件聚焦→性质激活→辅助线引入→度量计算→面积求解"的递进路线。先让学生观察图形对称性（P、A、D、B的位置关系），再逐步添加辅助线（半径OA、OB，弦AB），最后将四边形面积转化为对角线乘积的一半。图示采用单场景分步导航，教师可逐步揭示推导过程。
</TEXT_1>

**本图示的教学说明**

教师在使用本图示时，建议按照以下要点引导学生观察与思考：

1. **观察对称性**：首先让学生注意整个图形关于直线PD对称，A与B对称，因此PA=PB，且后续所有与AB相关的计算只需计算一半（AE）再乘2即可。

2. **激活切线性质**：步骤1中连接OA、OB后，强调"切线垂直于过切点的半径"这一核心定理，由此得到两个直角三角形△PAO和△PBO，为勾股定理的应用创造条件。

3. **度量链推导**：
   - 由PC=CD=1，直接得到直径CD=1，半径r=1/2
   - PO = PC + CO = 1 + 1/2 = 3/2
   - 在Rt△PAO中，PA = √(PO² − OA²) = √((3/2)² − (1/2)²) = √2

4. **弦AB的引入**：步骤3是思维转折点。教师应提问："要求四边形PADB的面积，还需要知道什么？"引导学生发现AB是关键未知量。通过"到线段两端距离相等的点在其垂直平分线上"，说明P和O都在AB的垂直平分线上，因此PO⊥AB。

5. **面积法求高**：步骤4中，在Rt△PAO内部利用面积相等求斜边上的高AE：
   - S△PAO = (1/2)·PA·OA = (1/2)·PO·AE
   - AE = (PA·OA)/PO = (√2 · 1/2)/(3/2) = √2/3
   - AB = 2AE = 2√2/3

6. **面积公式选择**：步骤5中强调四边形PADB的两条对角线PD与AB互相垂直，因此使用公式 S = (1/2)·对角线₁·对角线₂ 最为快捷：
   - PD = PC + CD = 2
   - S_PADB = (1/2)·PD·AB = (1/2)·2·(2√2/3) = 2√2/3

**课堂讲解建议**

- 在步骤2完成后，可让学生口算PA的长度，检验对勾股定理的掌握。
- 在步骤3中，可短暂停顿，让学生思考"如何求AB"，再揭示辅助线。
- 若时间允许，可在最后补充坐标法验证（建立以O为原点的坐标系），增强学生解析几何意识。
- 本题结论2√2/3可让学生记忆"圆外切线+割线"类问题的典型结果形式。
