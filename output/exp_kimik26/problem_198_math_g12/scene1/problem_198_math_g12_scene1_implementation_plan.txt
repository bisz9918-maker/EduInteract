[图示主题与整合说明]
- 本图示主题：圆外切线割线综合——四边形PADB面积的分步推导
- 整合的步骤/概念：题目基础图形 → 切线性质（半径垂直切线）→ 勾股定理求切线长 → 对称性证明PO垂直平分AB → 面积法求弦长 → 对角线互相垂直求四边形面积
- 教学价值：教师通过分步导航控制课堂节奏，每步聚焦一个几何要素或定理应用，学生可清晰看到辅助线的添加逻辑与度量推导过程；支持随时回退复习关键步骤。

[分步序列]
步骤0（初始状态）——题目基础条件：
- 显示元素：圆O、割线PD、切线PA/PB、点P/A/B/C/D/O及标签、PC=1与CD=1蓝色标注。
- 不显示：任何辅助线、半径、弦、直角标记、公式。

步骤1——切线性质（半径⊥切线）：
- 动画画出半径OA、OB（蓝色，0.8s画线效果）。
- 出现直角标记A、B（绿色）。
- 出现OA=OB=1/2蓝色标注。
- 右侧出现提示1："切线性质：OA⊥PA，OB⊥PB"。

步骤2——勾股定理求切线长PA：
- 高亮Rt△PAO（浅绿透明填充+绿色边线）。
- 出现PO=3/2、PA=√2、PB=√2绿色标注。
- 右侧出现公式："PA = √(PO² − OA²) = √2"。

步骤3——对称性得PO垂直平分AB：
- 动画画出弦AB（红色）。
- 出现交点E及标签。
- 出现直角标记E（绿色，表示AB⊥PD）。
- 右侧出现提示2："PA = PB，OA = OB  ⇒  PO垂直平分AB"。

步骤4——面积法求弦长AB：
- 出现AE=√2/3、AB=2√2/3绿色标注。
- 右侧出现公式："AE = (PA · OA) / PO = √2/3"。
- （隐含：在Rt△PAO中，利用面积等式 PA·OA = PO·AE）

步骤5——四边形面积结论：
- 画出边AD、DB（红色），四边形PADB区域浅红填充（透明度15%）。
- 出现PD=2红色标注；AB=2√2/3标注由绿色切换为红色（或新增红色覆盖）。
- 右侧出现结论公式（红色加粗）："S = (1/2) · PD · AB = 2√2/3"。
- 高亮两条对角线PD与AB（红色加粗）。

[交互方案]
- 交互类型：分步按钮导航（◀ 上一步 / 下一步 ▶）。
- 控件说明：
  1. 「◀ 上一步」按钮：位于底部x=300,y=465，宽100px，高32px。点击后回退到上一步，隐藏当前步骤的辅助线与标注。
  2. 「下一步 ▶」按钮：位于底部x=480,y=465，宽100px，高32px。点击后进入下一步，以动画方式展示新增元素。
  3. 步骤指示器：位于底部中心(400,450)，显示当前步骤编号（如"步骤 1/6"）。
- 教师操作流程：
  1. 教师打开图示，向学生展示步骤0的基础图形与已知条件PC=CD=1。
  2. 点击「下一步」进入步骤1，讲解切线性质，观察半径与直角标记的出现。
  3. 继续点击「下一步」依次推导PA长度、AB位置与长度、最终面积公式。
  4. 讲解过程中可随时点击「上一步」回退，复习上一步的关键定理或标注。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本场景为纯几何图形与分步显隐，无需复杂数据绑定或3D，原生SVG性能最佳且可控性高。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图：
  ```
  +--------------------------------------------------------+
  |                                                        |
  |  B标签          圆O                     右侧公式区     |
  |   B         (圆心450,250)               [提示/公式]    |
  |   |                                    x=550列         |
  |   |                                                    |
  |   |   C---O---D                                        |
  |   |  /       \                                         |
  |   | /         \                                        |
  |  P*            A                                       |
  |   \           /                                        |
  |    \         /                                         |
  |     \       /                                          |
  |      \     /                                           |
  |       \   /                                            |
  |        \ /                                             |
  |         E                                              |
  |                                                        |
  |              [◀ 上一步]  [下一步 ▶]                    |
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：维护变量 `currentStep`（0~5）。函数 `showStep(n)` 控制显示：基础图形（base group）始终显示；步骤组 `scene1-step-i`（i=1~5）仅在 `i <= n` 时显示（`display: block`），否则隐藏（`display: none`）。回退时自动隐藏后续步骤内容。
  2. 动画实现：半径/弦的画线动画使用CSS `@keyframes` 控制 `stroke-dashoffset`；标注与公式使用CSS `opacity` 淡入（`animation: fadeIn 0.5s`）。所有动画类仅在元素首次进入某步骤时添加，回退后再次进入需重新触发动画（可通过JS动态添加/移除class实现）。
  3. 坐标计算：所有几何坐标基于比例尺 1单位=100px 精确计算，圆心(450,250)、半径50px、P(300,250)、切点A(433,297)/B(433,203)等均已通过向量点乘验证（OA⊥PA，OA·PA=0）。
  4. 事件绑定：上一步/下一步按钮绑定 `click` 事件，更新 `currentStep` 后调用 `showStep`。初始调用 `showStep(0)`。
  5. 按钮状态：步骤0时禁用「上一步」，步骤5时禁用「下一步」。
- ID命名规范：所有SVG元素与HTML控件ID必须以 `scene1-` 为前缀。例如：
  - `scene1-circle-o`、`scene1-line-pa`、`scene1-point-a`、`scene1-label-p`
  - `scene1-step-1`、`scene1-step-2`、...、`scene1-step-5`（每步一个g分组）
  - `scene1-btn-prev`、`scene1-btn-next`、`scene1-step-indicator`
  - JS中严格使用 `document.getElementById`，禁止 `querySelectorAll` 配合全局class，避免多场景合并时跨场景污染。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，变量不污染全局作用域。
- 样式隔离：所有CSS类名以 `scene1-` 为前缀（如 `.scene1-animate-draw`、`.scene1-fade-in`）。
