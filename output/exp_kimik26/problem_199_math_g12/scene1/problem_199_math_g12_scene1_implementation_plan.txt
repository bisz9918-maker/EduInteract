[图示主题与整合说明]
- 本图示主题：正六边形的几何结构与中心对称性
- 整合的步骤/概念：
  1. 中心在原点 O、边长为 a、AB ∥ Ox 的正六边形的标准放置与顶点识别；
  2. 六个顶点 A、B、C、D、E、F 的坐标标注（用 a 表示），以及对顶点连线 AD、BE、CF 均过原点的性质；
  3. 正六边形关于原点 O 的中心对称性——任取一点 P，其关于 O 的对称点 P' 仍在正六边形上，图形绕原点旋转 180° 后与自身重合。
- 教学价值：教师可先让学生观察正六边形的标准放置，再分步揭示坐标规律和对称性，为后续理解 "S=f(t) 是偶函数" 提供几何直观（中心对称图形被过中心直线截得的弦关于中心对称，导致面积函数为偶函数）。

[分步序列]
- 步骤 0（初始状态）：显示直角坐标系（x 轴、y 轴、原点 O、x/y 标签）和正六边形 ABCDEF（含顶点标签 A~F）。正六边形居中，AB 水平位于 x 轴下方。教师可在此步引导学生识别图形和顶点顺序。
- 步骤 1（点击「下一步」）：
  - 新增：六个顶点的坐标标注（绿色文字），分别显示在对应顶点外侧；
  - 新增：三条对顶点连线 AD、BE、CF（蓝色虚线），均经过原点 O；
  - 视觉强调：正六边形边框保持黑色，对顶点连线使用蓝色虚线高亮；
  - 教师可在此步讲解顶点坐标规律和对顶点共线性质。
- 步骤 2（点击「下一步」）：
  - 新增：在边 CD 上取点 P(512,202)，在边 FA 上取其关于 O 的对称点 P'(288,298)；
  - 新增：红色圆点标记 P 和 P'，红色虚线连接 PP'（经过原点 O）；
  - 视觉强调：P、P' 及连线使用红色高亮，与蓝色对顶点连线形成对比；
  - 教师可在此步讲解中心对称定义——绕原点旋转 180° 后与自身重合，为后续直线 L 截正六边形的对称性做铺垫。
- 教师可随时点击「上一步」回退到任意步骤复习。

[交互方案]
- 交互类型：分步按钮导航（◀ 上一步 / 下一步 ▶）
- 控件说明：
  1. 「上一步」按钮：位于 (300, 455)，宽 90px，高 30px。点击后回退到上一个步骤，步骤 0 时禁用（opacity 0.5）。
  2. 「步骤指示器」：位于 (400, 475)，text-anchor="middle"，显示当前步骤编号，如 "步骤 1 / 3"。
  3. 「下一步」按钮：位于 (510, 455)，宽 90px，高 30px。点击后前进到下一个步骤，步骤 2 时禁用。
- 教师操作流程：
  1. 加载页面后进入步骤 0，教师先讲解正六边形的标准放置和顶点命名；
  2. 点击「下一步」进入步骤 1，引导学生观察坐标规律和对顶点共线；
  3. 点击「下一步」进入步骤 2，通过 P 与 P' 讲解中心对称性；
  4. 可随时点击「上一步」回退，强化学生记忆。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript。原因：本场景为静态几何图形展示，无复杂函数绘图、3D 或数据可视化需求，原生 SVG 足以精确控制所有几何元素和标签位置，且无需引入外部库，加载最快。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图：
  ```
  +--------------------------------------------------+
  |                                                  |
  |     y                                            |
  |     ↑    E_______D                               |
  |     |   /         \      [正六边形居中]           |
  |     |  F     O     C                             |
  |     |   \         /                              |
  |     |    A_______B                               |
  |     +----------------→ x                         |
  |                                                  |
  |                                                  |
  |         [◀ 上一步]  步骤 1/3  [下一步 ▶]         |
  +--------------------------------------------------+
  画布 800×500，控件栏在底部 y=440~490 区域
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `currentStep`（0~2），每个步骤对应一个 SVG `<g>` 组（id="scene1-step0-base"、"scene1-step1-coords"、"scene1-step2-symmetry"），通过设置 `display: block/none` 控制显隐。
  2. 坐标计算：正六边形顶点按中心 (400,250)、外接圆半径 140px 计算，使用 `Math.cos/Math.sin` 或硬编码精确坐标（推荐硬编码以避免浮点误差）。
  3. 动画曲线：无需复杂动画，步骤切换时直接显示/隐藏对应组。如需柔和过渡，可对显隐组添加 CSS `transition: opacity 0.2s ease`。
  4. 事件绑定：为「上一步」「下一步」按钮绑定 `click` 事件，更新 `currentStep` 后调用 `renderStep()` 函数，该函数根据步骤索引控制各组的 `display` 属性，并更新按钮禁用状态和步骤指示器文本。
  5. 按钮禁用逻辑：步骤 0 时禁用「上一步」，步骤 2 时禁用「下一步」，通过设置按钮的 `disabled` 属性和 `opacity` 样式实现。
- ID 命名规范：所有 SVG 元素和控件的 ID 必须以 `scene1-` 为前缀。例如：
  - 正六边形：`scene1-hex`
  - x 轴：`scene1-axis-x`
  - A 标签：`scene1-label-a`
  - 步骤 1 组：`scene1-step1-group`
  - 上一步按钮：`scene1-btn-prev`
  - 下一步按钮：`scene1-btn-next`
  - 步骤指示器：`scene1-step-indicator`
  JS 中统一使用 `document.getElementById` 获取元素，禁止跨场景选择器。
- IIFE 隔离：所有 JavaScript 代码包裹在 `(function() { ... })();` 中，避免全局变量污染，确保多场景合并时互不干扰。
- 坐标标注字体：使用 `font-family="Times New Roman, serif"` 使坐标公式更接近数学排版风格；Unicode 字符 `√`（U+221A）用于显示根号。
