[图示主题与整合说明]
- 本图示主题：直线截正六边形与面积函数 S = f(t) 的奇偶性
- 整合的步骤/概念：
  1. 建立直角坐标系与中心在原点的正六边形 ABCDEF（AB∥Ox）；
  2. 直线 L: y = kx + t 与正六边形相交于 M、N，构成 △OMN；
  3. 通过滑块连续调节参数 t，观察直线平移、交点移动及面积 S 的实时变化；
  4. 叠加显示对称直线 L': y = kx − t，得到交点 M'、N' 及 △OM'N'；
  5. 利用原点对称关系说明 S(t) = S(−t)，得出 f(t) 为偶函数。
- 教学价值：教师可先让学生观察 t 变化时面积如何改变，再通过一键切换对称直线，直观发现 M'、N' 与 M、N 关于原点对称，两个三角形面积恒等，从而自然引出偶函数结论。

[分步序列（状态描述）]
- 状态 0（初始加载）：
  显示坐标系、正六边形、顶点标签 A~F、原点 O、直线 L（t = 50）、交点 M/N、线段 OM/ON、△OMN 蓝色填充、面积 S(t) 标签、滑块与切换按钮。

  此状态可随时进入或退出，无步骤限制。

- 状态 2（显示对称直线 L'，切换交互）：
  点击「显示对称直线 L'」按钮后，叠加显示：
  1. 直线 L'（红色实线）及其标签；
  2. 交点 M'、N'（红色圆点）及其标签；

  5. 辅助虚线 MM'、NN'（灰色）；

  7. 绿色结论文字 "f(−t) = f(t)，故 f(t) 为偶函数"。

[交互方案]
- 交互类型：连续拖拽/滑块 + 双状态切换按钮
- 控件说明：
  1. 滑块「t 值」：位于底部 x=200~500，范围 −140~140，初始 50。拖动时实时更新直线 L 位置、交点 M/N、三角形 OMN 及面积数值。
  2. 切换按钮「显示对称直线 L'」：位于底部 (550,450)，120×30。点击后在图中叠加/隐藏 L'、M'、N'、△OM'N'、辅助线及结论文字。
  3. 重置按钮（可选）：位于底部 (550,485)，一键恢复 t=50 并关闭对称显示。
- 教师操作流程：
  1. 先展示初始状态，说明直线 L 与正六边形的交点 M、N；
  2. 缓慢拖动滑块，让学生观察 t 变化时直线平移、交点移动、三角形面积变化；
  3. 将 t 调回某一正值（如 50），点击「显示对称直线 L'」；
  4. 引导学生观察 M'、N' 与 M、N 关于原点对称，两个三角形面积数值相等；
  5. 再次拖动滑块，验证对任意 t 均有 S(t)=S(−t)，得出偶函数结论。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript。理由：本场景以 2D 几何图形、线段、多边形为主，无复杂函数绘图或 3D 需求，原生 SVG 性能足够且便于精确控制坐标与样式。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图：
  ```
  0    100  200  300  400  500  600  700  800
  +----+----+----+----+----+----+----+----+
  |          [结论文字: f(-t)=f(t)]        |  y=0~50
  |    E________D          [S(t)] [S(-t)] |  y=50~140
  |   /    N'   \    L'                   |
  |  F     O-----C----                   |  y=140~260
  |   \    |     /        \  L            |
  |    A___|____B          \              |  y=260~373
  |        |                \  N          |
  |        M                 \            |  y=373~430
  |  [=======滑块=======]  [对称][重置]   |  y=430~500
  +----+----+----+----+----+----+----+----+
  ```
- 关键实现要点：
  1. 坐标系转换：数学坐标 (x, y) → 画布坐标 (400 + x, 260 − y)。正六边形边长 a = 130 px，中心即画布原点。
  2. 交点计算：编写函数 `getIntersections(k, t)`，依次求解直线 y = kx + t 与六条边（AB、BC、CD、DE、EF、FA）的交点，筛选横坐标落在对应边区间内的有效点，返回 0~2 个交点。当恰好得到 2 个交点时，按 x 升序命名为 M（左）和 N（右）。
  3. 面积计算：S = 0.5 × |M.x × N.y − N.x × M.y| / (a²)，结果保留 2 位小数，以 a² 为单位显示。
  4. 对称直线：L' 的交点无需重新计算，直接取 M' = (−M.x, −M.y)、N' = (−N.x, −N.y)。
  5. 状态管理：用布尔变量 `showSymmetric` 控制对称元素的显示/隐藏；用变量 `currentT` 记录滑块当前值。滑块 `input` 事件触发 `updateScene(currentT)`，同步更新 L、M、N、三角形、面积标签；若 `showSymmetric` 为真，同步更新 L'、M'、N'、辅助线及 S(−t)。
  6. 直线绘制：为避免线段仅显示在六边形内部导致视觉不完整，计算直线与画布边界（或一个足够大矩形）的交点作为绘制端点，使直线贯穿整个画布。
  7. 动画曲线：滑块调节为实时响应，无需缓动动画；切换按钮的显示/隐藏使用 CSS `opacity` + `transition` 或直接修改 SVG `display` 属性。
  8. 事件绑定：滑块与按钮的监听在 IIFE 内绑定，避免全局污染。
- ID 命名规范：所有 SVG 元素及控件 ID 必须以 `scene2-` 为前缀。例如：
  - `scene2-hexagon`（正六边形）
  - `scene2-line-L`（直线 L）
  - `scene2-point-M`（点 M）
  - `scene2-tri-OMN`（三角形 OMN）
  - `scene2-slider-t`（滑块）
  - `scene2-btn-symmetric`（切换按钮）
  JS 中统一使用 `document.getElementById` 获取元素，禁止跨场景使用全局 class 选择器。
- IIFE 隔离：所有 JavaScript 逻辑包裹在 `(function() { ... })();` 中，确保变量与函数不泄漏至全局作用域，便于多场景合并。
