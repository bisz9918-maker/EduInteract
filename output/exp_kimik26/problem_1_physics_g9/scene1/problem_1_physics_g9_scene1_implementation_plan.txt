[图示主题与整合说明]
- 本图示主题：杠杆四力力臂作图与大小对比
- 整合的步骤/概念：题目基础条件展示 → 阻力矩分析 → F₃/F₂/F₄/F₁ 力臂逐一作图 → 力臂长度对比与结论得出

[交互方案]
- 交互类型：分步按钮导航（◀ 上一步 / 下一步 ▶）
- 控件说明：
  · 「◀ 上一步」按钮：位于 (280,455)，宽 100px，高 36px；点击回退到上一步骤，步骤 0 时禁用（opacity 0.4，pointer-events none）
  · 「下一步 ▶」按钮：位于 (420,455)，宽 100px，高 36px；点击前进到下一步，步骤 6 时文字变为「完成」，点击后无后续动作或循环回到步骤 0
  · 步骤标题：位于 (30,40)，随步骤切换更新文字
- 教师操作流程：
  1. 教师打开图示，默认显示步骤 0（题目原图），让学生观察已知条件
  2. 点击「下一步」进入步骤 1，讲解阻力矩概念，强调顺时针方向
  3. 继续点击「下一步」，依次展示 F₃/F₂/F₄/F₁ 的力臂作图，每步重点讲解"从支点向作用线作垂线"的方法
  4. 在步骤 5 特别强调 F₁ 方向错误，无法平衡
  5. 步骤 6 汇总四个力臂，通过 d₃ 高亮得出 F₃ 最小的结论
  6. 可随时点击「上一步」回退到任意步骤复习

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript。理由：本场景为静态几何作图与分步显示，无复杂动画或数据可视化，原生 SVG 足以精确控制线段、路径、文本的显示/隐藏与样式切换，无需引入 D3 等重型库。
- 画布尺寸：800 × 500 px（SVG 容器固定宽高）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  | 步骤标题                                          |  y=20~60
  |                                                  |
  |     O--------A-----------B                       |  y=250 杠杆
  |    /\       [G]          /|\                     |
  |               |         / | \                    |
  |              |         F₄ F₃ F₂                  |  y=120~320
  |                         \ | /                    |
  |                          F₁                      |
  |                                                  |
  |         [力臂线、力矩弧线、结论框]                 |  y=50~430
  |                                                  |
  |              [◀ 上一步] [下一步 ▶]                |  y=455 控件栏
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `let currentStep = 0;` 记录当前步骤（0~6）。每步对应一个配置对象数组 `stepConfig`，描述该步应显示的元素 ID 列表、应添加高亮 class 的元素 ID、以及标题文字。
  2. 元素显隐控制：所有可选元素（力臂线、作用线、力矩弧线、标注、结论框）初始 `display: none`。切换步骤时，先全部隐藏，再根据 `stepConfig[currentStep]` 中 `showIds` 数组逐一设为 `display: block`（或 inline）。
  3. 高亮切换：高亮通过添加/移除 CSS class 实现（如 `.highlight-f3 { stroke-width: 4px; filter: drop-shadow(0 0 4px #2e7d32); }`）。切换步骤时，先移除所有力箭头的高亮 class，再给当前步骤指定的箭头添加。
  4. 坐标计算：所有关键点（垂足 P1/P2/P4、箭头终点）在计划中已精确计算，代码中直接硬编码坐标，无需运行时计算。
  5. 动画曲线：本场景无需平滑动画，直接切换显示即可。若需增强体验，可为显示/隐藏添加 200ms 的 CSS transition（opacity + display 配合）。
  6. 事件绑定：按钮绑定 `click` 事件，更新 `currentStep` 后调用 `renderStep()` 重绘界面。
  7. 按钮状态：`renderStep()` 中根据 `currentStep` 更新按钮 disabled 状态与文字（步骤 6 时下一步按钮文字改为「完成」）。
- ID 命名规范：所有 SVG 元素及控件 ID 必须以 `scene1-` 为前缀。例如：
  · 杠杆：`scene1-lever`
  · F₃ 箭头：`scene1-force-f3`
  · d₂ 垂线：`scene1-arm-d2`
  · 上一步按钮：`scene1-btn-prev`
  · 步骤标题：`scene1-step-title`
  JS 中严格使用 `document.getElementById('scene1-xxx')` 获取元素，禁止跨场景选择器。
- IIFE 隔离：所有 JavaScript 代码包裹在 `(function() { ... })();` 中，避免全局变量污染。
