[图示主题与整合说明]
- 本图示主题：力方向与力臂大小的动态关系（最小力原理验证）
- 整合的步骤/概念：
  1. 杠杆平衡模型（O为支点，A处挂重物G，B处施加变向力F）
  2. 力臂随施力角度变化的实时几何作图（作用线延长线 + 垂线）
  3. 力与力臂反比关系的数值验证（F = G·OA / d）
  4. 四力选项F₁~F₄的方向位置标记，供学生对照
- 教学价值：教师通过底部滑块实时旋转B点力的方向，引导学生观察力臂长度随角度的变化，直观发现"当力垂直于杠杆时力臂最大、所需力最小"的规律，从而理解题目中F₃（竖直向上）为正确答案。

[分步序列]
本场景为连续滑块交互，无离散分步。以下列出教学演示中的关键参考状态：

- 初始状态（滑块默认位置）：θ = 30°
  - 显示杠杆、支点、重物G、四力标记点F₁~F₄
  - 力矢量从B点出发指向右上（30°方向），#1565c0
  - 自动画出力作用线延长线（虚线）和力臂垂线（虚线）
  - 数值面板显示θ=30°、d≈2.25m、F≈4.0N
  - 角度弧线标注30°角

- 教师拖动滑块过程中（0° < θ < 180°，θ ≠ 90°）：
  - 力矢量箭头实时旋转，始终指向当前θ方向
  - 力作用线延长线随方向实时更新
  - 力臂垂线实时重绘，长度d = 4.5·sinθ（m）
  - 角度弧线实时更新扫过的角度
  - 数值面板实时更新θ、d、F三个数值
  - 所有动态元素平滑过渡（使用requestAnimationFrame，无CSS动画）

- 关键状态（θ = 90°，教师可精确拖至或点击90°刻度）：
  - 力矢量竖直向上，与F₃标记点方向重合
  - 力臂垂线与杠杆OB重合，长度d = 4.5m（最大值）
  - 力臂垂线变为#2e7d32绿色实线，线宽3px
  - 力矢量箭头变为#2e7d32绿色
  - 数值面板边框变绿，F值显示为最小值2.0N，追加"✓ 力臂最大 / 力最小"提示
  - 保持高亮2秒后恢复普通状态（或保持直到滑块离开90°）

- 边界状态参考：
  - θ → 0°：力臂d → 0，F → ∞（数值面板显示"—"或"∞"）
  - θ → 180°：力臂d → 0，F → ∞（数值面板显示"—"或"∞"）

[交互方案]
- 交互类型：连续拖拽/滑块
- 控件说明：
  1. 角度滑块：位于SVG底部居中（轨道x=200~600, y=465），拖动范围0°~180°，刻度标记0°、90°、180°。滑块按钮直径20px，#1565c0。
  2. （可选）重置按钮：位于滑块右侧（x=640, y=460），文字"重置"，点击将滑块恢复至30°初始位置。
- 教师操作流程：
  1. 教师展示初始状态（θ=30°），说明杠杆平衡条件和力臂定义
  2. 教师缓慢拖动滑块，引导学生观察力臂垂线长度随角度的变化
  3. 教师将滑块拖至90°，暂停讲解：此时力臂与OB重合，力臂最大，所需力最小
  4. 教师指出此时力方向与F₃（绿色标记点）重合，得出答案选C
  5. 教师可继续拖动至其他角度，验证力臂变短、力变大的规律
  6. 点击重置按钮恢复初始状态，供下一轮讲解

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：本场景以2D几何图形为主（线段、箭头、虚线、圆弧、矩形），无复杂数据可视化或3D需求，原生SVG足以高效实现，且便于精确控制每个元素的坐标和样式属性。
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  数值面板(600,40)                                  |
  |  +----------------+                                |
  |  | θ = 90°        |    O-------A-------B          |
  |  | d = 4.5 m      |    ▲       |       •          |
  |  | F = 2.0 N ✓    |    |      [G]     /|\         |
  |  +----------------+    |              / | \        |
  |                        |             /  |  \       |
  |                       F₄●          F₃●  F₂●      |
  |                                    F₁●           |
  |                                                  |
  |  0° --------|-------- 90° --------|-------- 180°  |
  |           [滑块轨道与按钮]                        |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 坐标系与角度转换：SVG坐标系y轴向下。大纲定义θ为"相对于水平向右逆时针"，在SVG中方向向量计算为 dx = cos(θ_rad), dy = -sin(θ_rad)。所有三角函数使用标准Math对象。
  2. 垂足与力臂计算：力作用线经过B(600,220)，方向向量v=(cosθ, -sinθ)。向量BO = (-450, 0)。投影参数t = BO·v = -450*cosθ。垂足H = B + t*v = (600 - 450*cos²θ, 220 + 450*cosθ*sinθ)。力臂长度d = 450*|sinθ| px = 4.5*|sinθ| m（按100px=1m换算）。
  3. 力作用线延长线：计算力作用线与画布四边的交点，取两个最远交点之间的线段作为延长线。或简化为：从B点沿方向向量正反各延伸足够长（如800px）。
  4. 动态更新策略：滑块input事件触发update(theta)函数，该函数一次性计算所有动态坐标，直接设置对应SVG元素的d属性（path）、x1/y1/x2/y2（line）、cx/cy（circle）、transform（text）等。不使用CSS transition，确保实时响应。
  5. 90°高亮状态检测：在update函数中判断Math.abs(theta - 90) < 1（度），若成立则切换力臂线、力矢量、数值面板的样式类（highlight）；否则移除高亮。
  6. 数值格式化：角度显示整数度；力臂显示1位小数；力大小显示1位小数；当sinθ < 0.02（接近0°或180°）时，F显示"—"避免Infinity。
  7. 四力标记点静态绘制，不参与动态更新。
  8. 滑块实现：使用HTML input type="range"，min=0, max=180, step=1，通过CSS自定义轨道和按钮样式，绝对定位在SVG上方（y=450区域）。
- ID命名规范：所有交互元素ID必须以`scene2-`为前缀。例如：
  - 杠杆：`scene2-lever`
  - 力矢量箭头：`scene2-force-vector`
  - 力臂线：`scene2-moment-arm`
  - 数值面板：`scene2-value-panel`
  - 滑块：`scene2-angle-slider`
  - 角度文本：`scene2-text-theta`
  - 力臂文本：`scene2-text-d`
  - 力大小文本：`scene2-text-F`
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免全局变量污染，确保多场景合并时互不干扰。
