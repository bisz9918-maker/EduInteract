    **完整题目原文**

    如图，圆柱形容器竖直放置，上方A管的横截面积是下方B管的4倍，中间有水银．B管下方封有一段长L=112cm的空气柱，A内水银高h₁=5cm，B内水银高h₂=10cm，水银上方有一活塞（活塞重力及摩擦都不计），大气压p=75cmHg．

    （1）封闭气体的压强为多少厘米汞柱？
    （2）现用一竖直向上的力F缓慢拉活塞，求活塞向上移动1cm时气体的压强为多少厘米汞柱；
    （3）向上缓慢拉活塞的过程中发现拉力F的大小会相应变化，求活塞向上移动多少厘米时拉力F变为零．
    （4）试通过计算，分析说明向上缓慢拉活塞的过程中，拉力F的大小应如何变化？（设向上缓慢拉活塞的过程中，B管中总有水银）

    **题目分析与整体讲解思路**

    本题是气体定律（玻意耳定律）与流体静压强平衡的综合题，核心难点在于：活塞上拉时，A、B两管水银面会重新分布，必须同时满足水银体积守恒、连接处压强平衡、活塞受力平衡和气体玻意耳定律四个条件。

    关键认知台阶：
    1. 先建立正确的压强关系。很多学生容易把B管侧的压强平衡方向搞反，导致初始压强算成70cmHg。必须强调：A管水银面在连接处上方，B管水银面在连接处下方，从A管水银面经连接处再到B管气体界面，总深度为h₁+h₂=15cm，因此p_gas = p_A + h₁ + h₂ = 90cmHg。
    2. 活塞上拉x后，由于活塞始终与水银接触，A管水银面随活塞同步上升x；根据体积守恒（A管增加的水银体积 = B管减少的水银体积），B管水银面下降4x，气体柱相应膨胀4x。
    3. 第（2）（3）（4）问可以整合为同一动态过程：建立p_gas(x)的表达式，再推导F(x)，分析其单调性。

    **图示规划说明**

    - SCENE_1：静态装置图 + 分步压强推导，解决第（1）问，纠正学生最容易出错的压强方向问题。
    - SCENE_2：动态交互图，用滑块控制活塞位移x，实时展示水银面移动、气体膨胀、压强和拉力的变化，一并解决第（2）（3）（4）问。

    **本图示的教学说明（SCENE_2）**

    本图示用于讲解第（2）（3）（4）问，核心是让学生直观看到：活塞上拉一小段距离，如何通过"体积守恒→水银面移动→气体膨胀→压强变化→拉力变化"的因果链传递。

    **关键推导步骤（教师讲解要点）**

    1. **几何关系（体积守恒）**
       设活塞上移距离为x（cm），由于活塞始终与水银接触，A管水银面同步上升x。
       A管水银柱新高度：h₁′ = 5 + x。
       由水银总体积守恒 4h₁′ + h₂′ = 30，得B管水银柱新高度：h₂′ = 10 − 4x。
       B管水银面下降4x，故封闭气柱新长度：L′ = 112 + 4x。
       **注意**：B管中总有水银的条件要求 h₂′ > 0，即 x < 2.5 cm。

    2. **压强关系**
       连接处压强平衡：p_gas = p_A + h₁′ + h₂′ = p_A + 15 − 3x。
       活塞受力平衡（向上为正）：F + p_A · 4S = p₀ · 4S，即 p_A = 75 − F/(4S)。
       联立得：p_gas = 90 − 3x − F/(4S)。

    3. **玻意耳定律**
       p_gas · L′ = p_gas0 · L₀ = 90 × 112 = 10080。
       因此 **p_gas = 10080 / (112 + 4x)**。

    4. **第（2）问：x = 1 cm 时的气体压强**
       p_gas = 10080 / 116 = 2520/29 ≈ **86.9 cmHg**（精确值可保留分数形式）。
       此时 p_A = p_gas − 15 + 3 = 86.9 − 12 ≈ 74.9 cmHg，拉力 F 极小但大于零。

    5. **第（3）问：F = 0 的临界位置**
       F = 0 时 p_A = 75 cmHg，代入得 p_gas = 90 − 3x。
       联立玻意耳定律：(90 − 3x)(112 + 4x) = 10080。
       化简得 x(2 − x) = 0，取非零解 **x = 2 cm**。
       教师应强调：x = 2 cm 是拉力由"拉"转为"压"的临界点。

    6. **第（4）问：F 的变化规律**
       将 p_gas 代入得 F 的表达式（比例形式）：
       F ∝ 90 − 3x − 10080/(112 + 4x)。
       求导可知 F 先增大后减小，在 x ≈ 0.98 cm 附近达到最大值，随后减小，在 **x = 2 cm 时 F = 0**。
       当 0 < x < 2 cm 时，F > 0，方向竖直向上（拉力）；
       当 x = 2 cm 时，F = 0；
       当 2 cm < x < 2.5 cm 时，F < 0，方向竖直向下（需向下压活塞）。
       在课堂讲解时，建议教师拖动滑块从0缓慢移到2.5，让学生观察F值由0→增大→减小→0→变负的完整过程。
    </TEXT_2>

    **总结：完整解答与课堂讲解建议**

    **各问答案汇总**

    1. 封闭气体初始压强：**p_gas = 90 cmHg**
    2. 活塞上移1cm时气体压强：**p_gas = 10080/116 = 2520/29 ≈ 86.9 cmHg**
    3. 拉力F变为零时活塞上移距离：**x = 2 cm**
    4. 拉力F的变化规律：先增大后减小，在x≈0.98cm附近达到最大值；x=2cm时F=0；0<x<2cm时F为向上的拉力，2cm<x<2.5cm时F为向下的压力（需按压活塞）。

    **课堂讲解节奏建议**

    - **引入（3分钟）**：先让学生独立做第（1）问，收集常见错误（70cmHg）。用SCENE_1的步骤2展示正确的压强路径，强调"A管水银面在连接处上方，B管水银面在连接处下方，总深度是两者相加"。
    - **探究（8分钟）**：用SCENE_2的滑块从x=0缓慢拖到x=2.5，边拖边问："B管水银面下降速度是活塞速度的多少倍？"（4倍，因为面积比4:1）。让学生先猜F是变大还是变小，再用数据面板验证。
    - **突破（5分钟）**：停在x=1cm解第（2）问；停在x=2cm解第（3）问，强调临界状态p_A=p₀；展示F-x曲线讲解第（4）问，用"先拉后压"的转折引发认知冲突，加深记忆。
    - **巩固（2分钟）**：让学生思考：如果A、B管横截面积相等，结论会如何？（水银面不移动，气体压强不变，F恒为0）通过对比强化面积比的关键作用。

    **常见学生误区预警**

    1. 压强方向搞反，初始p_gas算成70cmHg。——必须用SCENE_1的路径图纠正。
    2. 认为活塞上移x，B管水银面也下降x。——忽略体积守恒中的4倍面积因子。
    3. 认为F一直增大。——需要用SCENE_2的F-x曲线展示非单调性。
    4. 第（3）问解出x=0和x=2后，不知道舍去哪个。——强调x=0是初始状态，题目问的是"向上移动"过程中的非零位置。
