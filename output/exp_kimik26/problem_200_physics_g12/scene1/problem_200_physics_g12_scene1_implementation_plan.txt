[图示主题与整合说明]
- 本图示主题：U形连通器式容器初始装置结构与封闭气体压强分析
- 整合的步骤/概念：
  1. 装置全貌与已知条件标注（A管、B管、水银、活塞、气柱、面积比4:1）
  2. 水银体积守恒关系 4h₁+h₂=常数 的直观展示
  3. 连接处压强平衡的正确建立（从A管水银面→连接处→B管气体界面的深度路径）
  4. 初始封闭气体压强计算结果 p_gas=90 cmHg
- 教学价值：教师通过分步导航控制信息呈现节奏，先建立整体装置认知，再逐步引入面积比、压强路径和计算结论，避免学生因信息过载而混淆深度方向。

[技术实现]
- JS库选择：原生 SVG + 原生 JavaScript。理由：本场景为静态几何装置与分步显隐，无复杂动画或函数绘图，原生SVG足以精确控制每个矩形、线段、文本的显隐与高亮，无需引入重型库。
- 画布尺寸：800×500 px（固定）
- 布局草图（ASCII）：
  ```
  +----------------------------------------------------------+
  |  800×500 画布                                              |
  |                                                            |
  |   p₀=75cmHg                                                |
  |   +----------------A管外框(蓝)----------------+  h₁=5cm    |
  |   |  A                                        |  +h₁(步2)  |
  |   |  +=========活塞=========+                 |            |
  |   |  |                     | F↑              |            |
  |   |  +---------------------+                 |            |
  |   |  ~~~~~~~~~~~~~~~~~~~~~~~ 水银(h₁)         |            |
  |   +--------------------+----------------------+            |
  |                        | B管外框(红)                     |
  |   封闭气体  L=112cm    | ~~~~ 水银(h₂)       h₂=10cm     |
  |   +--------------------|----------------------+  +h₂(步2)  |
  |   |                    |                      |  p_gas(步2)|
  |   |                    |                      |            |
  |   |    封闭气体区域    |                      |            |
  |   |   (红色填充10%)    |                      |            |
  |   |                    |                      |            |
  |   +--------------------+----------------------+            |
  |                                                            |
  |   [步骤1右侧框]  [步骤2右侧文字]  [步骤3结论框]            |
  |   (x=440~740)    (x=450~730)     (x=440~740)              |
  |                                                            |
  |        ◀ 上一步      步骤 k / 4      下一步 ▶              |
  |        (280,455)     (400,475)      (420,455)              |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 `currentStep`（0~3）记录当前分步。每步用一个函数 `renderStep(n)` 控制所有元素的显隐与样式。数据驱动，避免DOM碎片化操作。
  2. 元素显隐：所有可能随步骤变化的SVG元素（面积比标签、路径箭头、右侧文字、结论框等）初始 `display:none`，由 `renderStep` 统一设置 `display:block` 或 `display:none`。
  3. 高亮实现：通过切换元素的 `stroke` 和 `stroke-width` 实现高亮。例如步骤1 A管外框 `stroke` 从 `#000000` 变为 `#1565c0`，`stroke-width` 从2变为3。
  4. 水银填充：使用 SVG `<pattern>` 定义绿色斜线，应用到A管和B管水银矩形。气体填充使用 `fill:#c62828; fill-opacity:0.1`。
  5. 尺寸标注线：用 `<line>` 画引线，`<path>` 或 `<line>` 加 `marker-end` 画双向箭头。标注文字用 `<text>`，确保 `dominant-baseline:middle` 使文字居中于标注线。
  6. 事件绑定：按钮绑定 `click` 事件，修改 `currentStep` 后调用 `renderStep`。边界检查：步骤0时禁用「上一步」，步骤3时禁用「下一步」。
  7. 动画曲线：本场景以分步显隐为主，无需复杂动画。元素出现使用瞬时切换，若需柔和过渡可对 `opacity` 做200ms线性过渡。
- ID命名规范：所有SVG元素及JS变量均以 `scene1-` 为前缀。例如：
  - A管外框：`scene1-pipe-a`
  - B管外框：`scene1-pipe-b`
  - 活塞：`scene1-piston`
  - h₁标签：`scene1-label-h1`
  - 步骤1右侧框：`scene1-step1-box`
  - 上一步按钮：`scene1-btn-prev`
  - 下一步按钮：`scene1-btn-next`
  - JS中通过 `document.getElementById('scene1-pipe-a')` 获取元素。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免全局变量污染，确保多场景合并时互不干扰。
