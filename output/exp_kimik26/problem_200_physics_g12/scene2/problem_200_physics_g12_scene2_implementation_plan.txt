[图示主题与整合说明]
- 本图示主题：活塞上拉过程中封闭气体状态与拉力 F 的动态变化
- 整合的步骤/概念：
  1. 活塞位移 x 与水银面重新分布的几何关系（A 管水银柱增长 x，B 管水银柱缩短 4x，气柱增长 4x）
  2. 封闭气体压强 p_gas 随 x 的变化（玻意耳定律，常数 10080）
  3. 活塞下方压强 p_A = p_gas − h₁′ − h₂′ 与拉力 F = (p₀ − p_A)·S_A 的联动关系
  4. 第(2)问临界点 x=1 cm、第(3)问 F=0 临界点 x=2 cm、以及 F 极大值点 x≈0.98 cm 的特殊状态
- 教学价值：教师通过拖拽单一滑块，可连续演示"一个参数驱动多个物理量同步变化"的全过程，配合实时数据面板和 F-x 曲线，帮助学生建立压强-体积-受力之间的函数图像认知。

[交互方案]
- 交互类型：连续拖拽滑块（单参数 x 驱动全图）+ 1 个切换按钮
- 控件说明：
  1. 滑块（主控件）：位于 SVG 内底部 y=440~490、x=150~650 区域。拖动范围 x∈[0, 2.5] cm，步长 0.1 cm（视觉连续）。轨道灰色，按钮蓝色圆点，当前 x 值实时显示于滑块右侧。
  2. 「显示极值点」按钮：位于滑块右侧 (680, 455)，宽 90×28 px。点击切换 F-x 曲线图及装置图中 x≈0.98 cm 绿色标记线的显示/隐藏，帮助教师讲解 F 的极大值。
- 吸附逻辑：滑块释放时，若 |x−1.0| < 0.08 则自动吸附到 1.0；若 |x−2.0| < 0.08 则自动吸附到 2.0。吸附时状态提示横幅高亮 1 秒后恢复常态。
- 教师操作流程：
  1. 教师将滑块置于 x=0，讲解初始受力平衡（F=0）。
  2. 缓慢向右拖动滑块，观察水银面、气柱、压强、拉力的同步变化，强调"A 管上升 x、B 管下降 4x"的几何约束。
  3. 在 x≈1 处稍作停留（可自动吸附），讲解第(2)问的计算结果。
  4. 继续右拖，观察 F 先增大后减小，点击「显示极值点」标记 x≈0.98 cm，讲解 F 的极值。
  5. 在 x=2 处停留（自动吸附），讲解第(3)问 F=0 的临界条件，此时 p_A=p₀。
  6. 继续拖到 x=2.5，观察 F 变负（需向下压），说明 B 管水银耗尽的边界。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无需外部库）。理由：本场景以几何图形、属性动画和简单代数计算为主，SVG 的 setAttribute 足以高效更新坐标；无需 D3/Canvas 的复杂数据绑定或绘图 API。
- 画布尺寸：800 × 500 px（固定），容器 div 相对定位，内部 SVG 绝对定位铺满；控件（滑块轨道、按钮）以 SVG 元素或 foreignObject 形式叠于底部 y=440~490 区域。
- 布局草图：
  ```
  +----------------------------------------------------------+
  | 标题(400,25)                              状态提示(350,55)|
  |                                                          |
  |  +--------------------+    +---------------------------+ |
  |  |                    |    | 实时数据面板 (465,35)     | |
  |  |   装置主图         |    |  h₁′, h₂′, L′, p_gas...  | |
  |  |   (202,145)        |    +---------------------------+ |
  |  |   至(420,420)      |    +---------------------------+ |
  |  |                    |    | F-x 曲线 (465,250)        | |
  |  |                    |    | 含x=1蓝、x=2红标记       | |
  |  +--------------------+    +---------------------------+ |
  |                                                          |
  |  [========= 滑块 x =========]  [显示极值点]  x=1.0       |
  |  0                        2.5   B管水银刚好耗尽         |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：单一状态变量 `currentX`（单位 cm），所有视觉属性均为 `currentX` 的纯函数。update(currentX) 函数统一驱动重绘。
  2. 坐标计算（1 cm = 2 px）：
     · 活塞顶 y = 154 − 2·x，底 y = 166 − 2·x
     · A 管水银顶 y = 166 − 2·x，底 y = 176（固定）
     · B 管水银顶 y = 176（固定），底 y = 196 − 8·x
     · 气体顶 y = 196 − 8·x，底 y = 420（固定）
     · p_A 文字 y = 171 − x，p_gas 文字 y = 308 − 4·x，h₂′ 文字 y = 186 − 4·x，L′ 文字 y = 308 − 4·x
  3. 物理计算：
     · L′ = 112 + 4·x
     · p_gas = 10080 / L′
     · p_A = p_gas − (5+x) − (10−4x) = p_gas − 15 + 3x
     · F_per_S = 75 − p_A
     · 趋势：若 2520/(28+x)² > 3 则 ↑，否则 ↓
  4. 动画曲线：F-x 曲线预计算 100 个采样点的 SVG path d 属性，无需每帧重算；当前点坐标 svg_x = 510 + 102·x，svg_y = 330 − 300·(F_per_S)。
  5. 事件绑定：
     · 滑块按钮监听 mousedown/touchstart，记录起始 x 与 currentX；mousemove/touchmove 时根据 dx 换算 Δx（200 px/cm），实时调用 update；mouseup/touchend 时执行吸附逻辑。
     · 「显示极值点」按钮监听 click，切换 `scene2-extreme-line` 与 `scene2-extreme-device-line` 的 visibility 属性。
  6. 吸附与提示：滑块释放后，若进入吸附区间，将 currentX 动画过渡到 1.0 或 2.0（requestAnimationFrame，200 ms ease-out），同时状态提示文字透明度 0→1→0 过渡。
  7. 颜色切换：F_per_S 的符号决定 F 箭头颜色与方向（正蓝向上、零灰、负红向下），通过 setAttribute('stroke') 与调整箭头终点 y 实现。
