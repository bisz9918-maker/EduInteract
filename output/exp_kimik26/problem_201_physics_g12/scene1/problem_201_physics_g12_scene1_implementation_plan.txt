[图示主题与整合说明]
- 本图示主题：带电粒子在匀强电场与重力场复合场中的运动分解与轨迹
- 整合的步骤/概念：电场分布 → 受力分析（重力+电场力）→ 抛物线轨迹 → 速度矢量 → 分运动性质（竖直匀减速、水平初速为零匀加速）→ 位移与公式推导
- 教学价值：教师可通过分步导航，按认知递进顺序逐层展开，随时回退到任意阶段复习；右侧区域同步显示对应说明，便于学生建立"受力—运动—公式"的完整链条。

[分步序列]
- 步骤0（基础条件）：显示3条电场线及箭头、A点、A标签、v₀箭头及标签。右侧说明区显示"基础条件：粒子从A点以初速度v₀竖直向上射入水平匀强电场"。
- 步骤1（受力分析）：在步骤0基础上，叠加重力mg箭头（绿色，从A点向下）和电场力qE箭头（蓝色，从A点向右），并显示mg、qE标签。右侧说明区显示"受力分析：重力mg竖直向下，电场力qE水平向右"。
- 步骤2（运动轨迹）：在步骤1基础上，绘制从A到B的抛物线轨迹，显示B点及B标签，叠加v_B=2v₀红色水平箭头及标签。右侧说明区显示"运动轨迹：粒子做曲线运动，到达B点时速度水平向右，大小为2v₀"。
- 步骤3（分运动解析）：在步骤2基础上，右侧出现竖直/水平两个分运动框。竖直框内标注：初速v₀↑、末速0、加速度g↓、性质"匀减速直线运动"。水平框内标注：初速0、末速2v₀→、加速度a→、性质"初速为零的匀加速直线运动"。右侧主说明区隐藏，由两个分运动框占据。
- 步骤4（位移计算）：在步骤3基础上，主图区叠加竖直位移虚线（A左侧，从y=320到y=220）标注h，水平位移虚线（A下方，从x=150到x=350）标注x。右侧区域切换为公式推导面板，逐行显示：t = v₀/g，h = v₀²/(2g)，x = v₀²/g，W_G = -mgh，W_E = qEx，U_AB = W_E/q。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本场景以几何图形、矢量箭头、虚线标注为主，无复杂函数绘图或3D需求，原生SVG性能最佳且无需额外CDN依赖。
- 画布尺寸：800 × 500 px（SVG viewBox="0 0 800 500"）
- 布局草图：
  ```
  +--------------------------------------------------+
  |  电场线 ===>                                      |
  |  电场线 ===>        B  ●────► v_B=2v₀            |
  |  电场线 ===>         ↑                           |
  |           ↑         |  轨迹                      |
  |         v₀|         |                           |
  |           ●A        |                           |
  |           ↓mg       |                           |
  |           →qE       |                           |
  |  +----------------+---------------------------+  |
  |  | 竖直方向框      |  公式/说明区             |  |
  |  | 水平方向框      |                         |  |
  |  +----------------+---------------------------+  |
  |       [◀ 上一步]  [1/5]  [下一步 ▶]            |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 轨迹生成：使用参数方程在JS中生成采样点。设A=(150,320)，竖直位移h=100px，水平位移x=200px（满足x=2h）。取g=10（像素单位），则v₀=√(2gh)≈44.7，T=v₀/g≈4.47，a=2g=20。参数t∈[0,T]，x(t)=0.5*a*t²，y(t)=v₀*t-0.5*g*t²，SVG坐标为(A.x+x(t), A.y-y(t))。生成50个点后用`<polyline>`或path的L命令连接。
  2. 状态机：用变量`currentStep`（0~4）控制。每个SVG元素/组设置`id`，在步骤切换时根据`data-show-from`和`data-show-to`属性或直接在JS中显式控制`display`属性。
  3. 动画曲线：步骤切换时，新增元素使用CSS transition `opacity 0.3s ease` 淡入，避免突兀出现。
  4. 事件绑定：按钮绑定`click`事件，更新`currentStep`后调用`renderStep()`函数，该函数遍历所有带`data-step`标记的元素，决定显示/隐藏。
  5. 右侧区域内容切换：步骤0-2显示说明文字（`<text>`或foreignObject中的HTML），步骤3显示两个分运动框（SVG `<rect>`+`<text>`），步骤4显示公式（多行`<text>`）。通过控制各内容组的`display`属性实现切换。
- ID命名规范：所有交互元素ID必须以`scene1-`为前缀，例如`scene1-btn-prev`、`scene1-btn-next`、`scene1-trajectory`、`scene1-force-mg`、`scene1-step-display`等。JS中使用`document.getElementById`获取元素。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免全局变量污染。
