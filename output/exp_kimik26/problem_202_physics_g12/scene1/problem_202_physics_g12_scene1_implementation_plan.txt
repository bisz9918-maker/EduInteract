[图示主题与整合说明]
- 本图示主题：复合场中带电粒子运动全景总览（第1场景）
- 整合内容：直角坐标系、电场/磁场分区、AC发射线段、从A点射出的粒子在电场中的偏转轨迹、磁场中的圆弧偏转、以及返回电场后的完整路径。通过5步递进展示，帮助教师建立空间场区概念并逐段剖析粒子运动。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「◀ 上一步」按钮：位于画布底部(260,455)，宽100px，高30px。点击后回退到上一分步，隐藏当前步新增的元素。
  2. 「下一步 ▶」按钮：位于画布底部(440,455)，宽100px，高30px。点击后前进到下一分步，显示该步新增的元素。
  3. 步骤指示器：位于(375,470)，显示当前步骤编号（如"步骤 2/5"）。
- 教师操作流程：
  1. 教师打开图示，首先呈现步骤0，向学生介绍坐标系、场区划分（左电右磁、上II下III）及AC发射线段。
  2. 点击「下一步」进入步骤1，讲解A点粒子在电场中的偏转轨迹，强调轨迹经过OC中点M(-L,0)并到达A′(0,-L)。
  3. 点击「下一步」进入步骤2，高亮磁场区，标注A′点速度沿x轴正方向，说明粒子即将进入磁场。
  4. 点击「下一步」进入步骤3，展示磁场中逆时针圆弧轨迹，标注离开磁场的P(0,L/4)及向左的速度方向。
  5. 点击「下一步」进入步骤4，展示粒子从P点返回电场后向左下方偏转，最终到达Q(-2L,-15L/4)的完整路径。
  6. 可随时点击「上一步」回退到任意步骤复习。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本场景为静态几何图形与分步显隐，无需复杂数学计算或3D渲染，原生SVG路径（path、line、circle、text）即可精确表达所有元素，且便于通过display属性控制分步显隐。
- 画布尺寸：800 × 500 px（SVG viewBox="0 0 800 500"）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  y轴↑  电场区(左)      |  磁场区(右)              |
  |        A●              |   × × × ×               |
  |        |               |   × × × ×               |
  |        C●              |   × × × ×               |
  |        |               |   × × × ×               |
  |  x=-2L |               |   × × × ×               |
  |        |               |   × × × ×               |
  |        |               |   × × × ×               |
  |        |               |                         |
  |        Q●              |                         |
  |                        |                         |
  |              [图例]    |                         |
  |                        |                         |
  |    [◀ 上一步]  [下一步 ▶]  步骤 1/5               |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `let currentStep = 0;` 记录当前步骤（0~4）。每步对应一个SVG `<g>` 分组（id分别为 `scene1-step0-base`、`scene1-step1-trajectory`、`scene1-step2-highlight`、`scene1-step3-arc`、`scene1-step4-return`），通过设置 `display: block/none` 控制显隐。
  2. 坐标计算：原点O=(380,180)，L=60px。所有关键点坐标硬编码，轨迹路径使用SVG path的C（三次贝塞尔）和A（圆弧）命令精确绘制。
  3. 动画曲线：本场景为分步切换，无需连续动画。步骤切换为即时显隐，确保课堂节奏由教师完全掌控。
  4. 事件绑定：为 `scene1-btn-prev` 和 `scene1-btn-next` 绑定click事件，更新currentStep并调用 `renderStep()` 函数，该函数遍历所有步骤分组设置display。
  5. 磁场圆弧计算：圆心(380, 202.5)，半径37.5px。SVG arc命令：`M 380,240 A 37.5 37.5 0 0 1 380,165`（sweep-flag=1表示经右侧半圆）。
  6. 下标与特殊字符：使用SVG `<tspan>` 实现下标（如v₀、A′、-15L/4），设置 `baseline-shift="sub"` 或 `dy="3"` 微调。
  7. 电场箭头：使用SVG `<marker>` 定义箭头头部，reuse在电场线与速度箭头上。
- ID命名规范：所有交互元素ID必须以 `scene1-` 为前缀。例如：
  - 分组：`scene1-step0-base`、`scene1-step1-trajectory`
  - 按钮：`scene1-btn-prev`、`scene1-btn-next`
  - 标签：`scene1-label-A`、`scene1-label-v0`
  - 轨迹：`scene1-path-electric`、`scene1-path-arc`、`scene1-path-return`
  - 辅助线：`scene1-guide-Ap`、`scene1-guide-Pp`、`scene1-guide-Qp`
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免多场景合并时的全局变量污染。
- 容器结构：外层div宽800px高500px，position:relative；SVG绝对定位填满；控件div绝对定位在底部(y=440~490)，pointer-events:none（按钮自身pointer-events:auto）。
