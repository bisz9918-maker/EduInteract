[图示主题与整合说明]
- 本图示主题：带电粒子在组合电磁场中的运动——电场中类平抛与磁场中圆周运动的逐步推导
- 整合的步骤/概念：第(1)问类平抛运动分解与电场强度E的求解、A'坐标确定；第(2)问磁场中圆周运动半径与圆心定位、返回x=-2L的坐标计算

[分步序列]
- 初始状态（步骤0）：显示坐标轴、边界线x=−2L、电场线、磁场"×"符号、所有点标记（A、C、M、A'、O₁、P、Q）、完整轨迹（四段全部显示，opacity=0.25，线宽1.5px）。不显示推导箭头、辅助线、公式框。等待教师点击「下一步」。
- 步骤1（电场II象限分析）：A→M轨迹高亮（opacity=1.0，线宽2.5px），其余三段淡化（opacity=0.2）。显示A点水平向右v₀箭头、竖直向下a箭头。显示水平位移标注线（y=L处从x=−2L到x=−L）及标签"L"；显示竖直位移标注线（x=−L处从y=L到y=0）及标签"L"。左侧公式框显示：L = v₀t₁，L = ½at₁²。
- 步骤2（求E与A'坐标）：M→A'轨迹高亮，其余淡化。隐藏步骤1的v₀/a箭头及位移标注（或opacity=0.2）。显示M→A'段的对称性暗示（可短暂高亮第III象限电场线）。左侧公式框更新为：v_y = at₁ = 2v₀，A'(0, −L)，E = 2mv₀²/(qL)。A'点外圈红色高亮闪烁一次。
- 步骤3（进入磁场）：A'→P圆弧高亮，其余淡化。焦点移至A'点。显示A'点水平向右v₀箭头、竖直向上洛伦兹力f箭头（绿色）。右侧公式框显示：f = qv₀B (↑)，R = mv₀/(qB)。
- 步骤4（圆周运动几何）：保持A'→P圆弧高亮。画出半径线O₁A'与O₁P（绿色），标注"R"。圆心O₁绿色十字高亮。右侧公式框更新为：B = 8mv₀/(5qL)，R = 5L/8，O₁(0, −3L/8)，P(0, L/4)。P点外圈红色高亮。
- 步骤5（返回电场）：P→Q轨迹高亮，其余淡化。显示P点水平向左v₀箭头（蓝色）。显示水平位移标注线（从x=0到x=−2L，在y≈440处）及标签"2L"；显示竖直位移标注线（在x=−2L左侧从y=L/4到y=−15L/4）及标签"4L"。左上方公式框显示：v = v₀ (←)，t = 2L/v₀，Δy = ½at² = 4L。
- 步骤6（最终结果）：P→Q保持高亮，Q点外圈红色高亮并加粗描边。所有关键点（A、M、A'、P、Q）短暂依次闪烁。左上方公式框更新为：Q(−2L, −15L/4) = (−2L, −3.75L)，文字加粗红色#c62828。展示最终答案坐标。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本场景以几何图形、路径轨迹、箭头标注为主，无复杂函数绘图或3D需求，原生SVG足以精确控制所有元素；避免引入不必要库，保持代码轻量。
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  +----------------------------------------------------------+
  |  [公式框左上/左]          坐标系主图区          [公式框右] |
  |  (20,50/120)              原点(400,277.5)      (520,120) |
  |                           y轴 |                          |
  |    A●→v₀                  |    × × × × 磁场             |
  |      ↓a                   |    × × × ×                  |
  |       ↘                   |    × × × ×                  |
  |    C——M                   |                             |
  |          ↘                |                             |
  |           ●A'             |                             |
  |            ↻ 圆弧         |                             |

  |                           |                             |

  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 坐标映射：统一函数 toPixel(x, y) = {px: 400 + x*45, py: 277.5 - y*45}，其中x,y以L为单位（如A为x=-2,y=1）。所有图形坐标通过此函数计算，确保比例一致。
  2. 轨迹路径生成：
     - A→M：参数t∈[0,1]，px=310+45*t，py=232.5+45*t²。采样10个点生成path的L序列。
     - M→A'：参数t∈[0,1]，px=355+45*t，py=277.5+45*(2*t−t²)。
     - 圆弧A'→P：SVG中圆心(400,294.375)，半径28.125，使用path的A命令：从(400,322.5)顺时针到(400,266.25)，大弧标志0， sweep-flag 1（顺时针）。
     - P→Q：参数t∈[0,1]，px=400−90*t，py=266.25+180*t²。
  3. 状态机设计：变量 currentStep ∈ [0,6]。每一步用一个配置对象定义：{highlight: ['trajectory-am'], showArrows: ['v0-a'], showLabels: ['L-h','L-v'], formulaPos: 'left', formulaText: '...'}。切换步骤时遍历配置，设置对应元素的 class 或 style。
  4. 淡化/高亮：通过CSS类 .dimmed {opacity: 0.2; stroke-width: 1.5px;} 和 .highlight {opacity: 1; stroke-width: 2.5px;} 控制。所有轨迹段默认添加 .dimmed，当前段移除 .dimmed 添加 .highlight。
  5. 公式框：使用SVG <foreignObject> 或 <rect>+<text> 实现。推荐 <foreignObject> 内嵌 <div>，便于多行公式排版。每步根据 formulaPos 显示/隐藏对应公式框，并填充相应HTML内容。
  6. 动画曲线：步骤切换时，opacity变化使用CSS transition: opacity 0.3s ease，提供平滑过渡感；关键点外圈高亮使用CSS animation: pulse 0.6s ease 2。
  7. 事件绑定：上一步/下一步按钮绑定click事件，更新currentStep后调用renderStep()。renderStep()根据当前步骤配置，批量设置元素显隐与样式。
- ID命名规范：所有交互元素ID必须以 scene2- 为前缀。例如：scene2-axis-x、scene2-axis-y、scene2-trajectory-am、scene2-trajectory-ma、scene2-arc-ap、scene2-trajectory-pq、scene2-point-a、scene2-point-m、scene2-point-ap、scene2-point-p、scene2-point-q、scene2-center-o1、scene2-arrow-v0-a、scene2-arrow-a、scene2-arrow-v0-ap、scene2-arrow-f、scene2-arrow-v-p、scene2-formula-left、scene2-formula-right、scene2-formula-topleft、scene2-btn-prev、scene2-btn-next、scene2-step-indicator。
- IIFE隔离：所有JavaScript代码包裹在 (function() { ... })() 中，避免全局变量污染，确保多场景合并时互不干扰。
