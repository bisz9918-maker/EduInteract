[图示主题与整合说明]
- 本图示主题：满足条件的多解粒子轨迹族与通式归纳
- 整合的步骤/概念：展示从直线 x=-2L 上不同位置发射的带电粒子，在交变电场中经多次"半周期"偏转后恰好沿 x 轴正方向进入磁场的多解情形。通过 k=1,2,3,4 四条典型轨迹的逐层揭示，引导学生发现半周期数与水平位移的定量关系，最终归纳出通项公式 y0=L/k²。
- 教学价值：教师可借助分步导航，先让学生回顾 k=1（A 点）的熟悉轨迹，再逐步展示 k=2、k=3 的"往返"构造，体会"到达 y 轴时 vy=0"的隐含条件；最后一步并列呈现轨迹族与通式推导，形成从特殊到一般的认知闭环。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript。理由：本场景以几何轨迹和分步状态切换为主，无需复杂数据绑定或 3D；原生 SVG path 动画（stroke-dasharray/stroke-dashoffset）足以实现描边效果，避免引入额外库体积。
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  y  |    第Ⅱ象限电场      |    磁场 B (× × ×)    |
  |  ↑  |    ↓ E              |    第Ⅰ象限            |
  |     |                     |                       |
  |  ←——O————————————————————→ x                      |
  |     |  A·                 |                       |
  |     |  ·  k=1 轨迹(红)    |                       |
  |     |    ·                |                       |
  |     |  C· · · k=2 轨迹(蓝)|                       |
  |     |    ·   ·            |                       |
  |     |      · · k=3(绿)    |  [通式推导框]         |
  |     |        ·            |  [右侧 530~780]       |
  |     |  · · · k=4(紫)      |                       |
  |     |                     |  [图例]               |
  |     |  x=-2L              |  [右下 445~520]       |

  |      控件栏 y=460~493                             |
  +--------------------------------------------------+
  ```

- 关键实现要点：
  1. 状态机设计：用变量 `currentStep`（0~4）管理步骤，每步定义 `enter()` 和 `exit()` 函数，分别处理元素显隐、透明度、动画触发。
  2. 轨迹生成：用 JavaScript 函数 `generateTrajectory(k, L, originX, originY)` 根据参数方程计算点序列。对第Ⅱ象限段（ay<0）：y_screen = y0 − ½·a·t² 映射；对第Ⅲ象限段（ay>0）：根据初速度 vy 积分映射。生成点序列后用 `L x y` 拼接成 path 的 `d` 属性。
  3. 描边动画：轨迹 path 初始设置 `stroke-dasharray="总长度" stroke-dashoffset="总长度"`，进入步骤时通过 CSS transition 或 requestAnimationFrame 将 offset 减至 0，实现"绘制"效果。总长度用 `path.getTotalLength()` 获取。
  4. 淡入淡出：非当前步骤的轨迹和标签统一设置 class `dimmed`（opacity 0.2~0.3），当前步骤高亮（opacity 1），过渡用 CSS `transition: opacity 0.4s ease`。
  5. 水平位移竖线：按 k 值计算分段位置 `x = −2L + i·(L/k)`（i=1,2,…,2k），在 x 轴上生成短线段，与轨迹同颜色，随步骤同步显隐。
  6. 通式框：使用 SVG `<foreignObject x="530" y="120" width="250" height="300">` 嵌入 `<div xmlns="http://www.w3.org/1999/xhtml">`，内部用 HTML 排版推导文本，避免 SVG text 排版复杂公式。
  7. 事件绑定：按钮绑定 `click` 事件，更新 `currentStep` 后调用 `renderStep()`。所有 DOM 查询使用 `getElementById`。
- ID 命名规范：所有交互元素 ID 必须以 `scene3-` 为前缀。例如：
  - 轨迹：`scene3-path-k1`, `scene3-path-k2`, `scene3-path-k3`, `scene3-path-k4`
  - 发射点：`scene3-emit-k1`, `scene3-emit-k2`, `scene3-emit-k3`, `scene3-emit-k4`
  - 终点：`scene3-end-k1`, `scene3-end-k2`, `scene3-end-k3`, `scene3-end-k4`

  - 步骤指示器：`scene3-step-indicator`
  - 通式框：`scene3-formula-box`
  - 图例：`scene3-legend`
- IIFE 隔离：所有 JavaScript 代码包裹在 `(function() { ... })();` 中，避免多场景合并时变量污染全局作用域。
