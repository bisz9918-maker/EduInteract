[图示主题与整合说明]
- 本图示主题：带电粒子在平行板电场中的偏转——装置与完整运动轨迹
- 整合的步骤/概念：
  1) 平行板电容器装置、中心线RD、界面MN与PS的空间关系；
  2) 匀强电场方向与正电荷受力方向；
  3) 电场区类平抛轨迹及出射点速度分解；
  4) 无场区匀速直线运动轨迹；
  5) MN处偏离距离y与PS处总偏离距离Y的几何标注及类平抛重要推论（出射速度反向延长线过水平位移中点）。
- 教学价值：教师通过分步导航，按“装置→电场受力→偏转轨迹→无场区运动→总偏转结论”的递进逻辑讲解，可随时回退复习关键步骤。轨迹、速度分解、距离标注分步呈现，避免信息过载。

[分步序列]
- 初始状态（步骤0）「初始条件」：
  显示平行板A、B，中心线RD（水平虚线），界面MN（板右端竖直实线）、PS（右侧竖直虚线）。标注板长L=8cm（板下双向箭头），板间距d=8cm（板左双向箭头），A、B板间电压U=300V（电场区右侧），MN与PS间距12cm（上方双向箭头）。粒子在左侧R点，标注初速度v₀=2×10⁶m/s（R点上方）。左上角标注粒子参数q=10⁻¹⁰C、m=10⁻²⁰kg。所有静态标签A、B、R、D、M、N、P、S显示。

- 步骤1「电场与受力」（点击「下一步」）：
  新增：电场区背景填充（淡蓝透明矩形）出现；5条竖直向下的匀强电场线（蓝色箭头）在板间均匀画出；标注电场强度E方向（E标签在电场区内偏上）；在板间中心位置(220,250)画出红色向下的电场力F箭头，标注F（箭头右侧）。引导学生预判粒子进入电场后将向下偏转。

- 步骤2「电场区偏转」（点击「下一步」）：
  新增：粒子从R点沿类平抛轨迹（蓝色抛物线M60,250 Q190,250 320,290）运动至MN界面处的出射点(320,290)；在MN界面处标注偏离中心线的距离y（红色双向箭头，从中心线y=250到出射点y=290，标签在箭头右侧）；在出射点画出速度分解：水平分量v₀（黑色箭头向右）、竖直分量vᵧ（红色箭头向下）、合速度v（绿色箭头向右下）；对应标签v₀在箭头下方、vᵧ在箭头左侧、v在箭头右侧偏上。步骤1中的F箭头可保留或淡化（建议保留但降低透明度至0.3，避免与速度箭头重叠）。

- 步骤3「无场区运动」（点击「下一步」）：
  新增：从出射点(320,290)继续画出沿出射速度方向的直线轨迹（蓝色实线）延伸至PS界面处的(560,386)；粒子显示在终点(560,386)；标注此段竖直位移y'（红色双向箭头，在PS左侧x=550处从y=290到y=386，标签在箭头右侧）。说明飞出电场后粒子做匀速直线运动。

- 步骤4「总偏转距离」（点击「下一步」）：
  新增：在PS界面处标注粒子位置到D点的总距离Y（绿色双向箭头，加粗，在x=565处从y=250到y=386，标签在箭头右侧）；用灰色虚线画出出射速度反向延长线，从(320,290)经过水平位移中点(220,250)延伸至(60,186)；在延长线附近标注类平抛重要推论“过水平位移中点”。Y标注高亮显示，作为两个问题的答案位置总结。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「上一步」按钮：位于控件栏左侧(250,455)，宽80×30，点击回退到上一状态，步骤0时禁用（置灰）。
  2. 步骤指示器：位于控件栏中部(360,475)，显示当前步骤文字如“步骤 1/5”。
  3. 「下一步」按钮：位于控件栏右侧(470,455)，宽80×30，点击前进到下一状态，步骤4时禁用（置灰）。
- 教师操作流程：
  1. 教师加载图示，首先呈现步骤0（装置与已知条件），向学生介绍平行板装置、几何参数和粒子初状态。
  2. 点击「下一步」进入步骤1，讲解匀强电场方向（A高B低，场强向下）及正电荷受力方向（向下），让学生预判偏转方向。
  3. 点击「下一步」进入步骤2，展示类平抛轨迹和出射点速度分解，讲解水平匀速、竖直匀加速的运动合成，标注MN处偏离距离y。
  4. 点击「下一步」进入步骤3，展示无场区匀速直线轨迹，讲解飞出电场后不受力，沿出射速度方向匀速运动，标注y'。
  5. 点击「下一步」进入步骤4，展示总偏转距离Y和反向延长线，总结两个问题的答案位置，强调类平抛“反向延长线过水平位移中点”的推论。
  6. 讲解过程中可随时点击「上一步」回退，复习关键概念。

[技术实现]
- JS库选择及原因：原生SVG + 原生JavaScript。理由：本场景以静态几何图形、路径轨迹和简单显隐控制为主，无需复杂数据驱动或3D渲染。原生SVG的<path>、<line>、<animateMotion>足以绘制抛物线轨迹和粒子运动，原生JS状态机控制各步骤元素显隐，轻量且兼容性好。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------------+
  |  q,m参数(左上)                                         |
  |       A板(上)                                          |
  |  R •-----> v₀                                          |
  |       电场区(背景淡蓝)                                  |
  |       B板(下)                                          |
  |         |        12cm          |                       |
  |         M----------------------P (虚线)                |
  |         N----------------------S (虚线)                |
  |                        Y                               |
  |  [控件栏: ◀上一步] [步骤 1/5] [下一步▶]                |
  +--------------------------------------------------------+
  画布 800×500，控件栏在底部 y=450~490，主图区 y=30~430
  ```
- 关键实现要点：
  1. 状态机设计：用变量 `scene1-currentStep`（0~4），每步对应一个显隐配置对象，记录该步应显示的元素ID列表。点击按钮时更新状态并调用 `scene1-renderStep()`。
  2. 元素分组：将所有SVG元素按步骤分装入5个<g>组（id="scene1-step0"~"scene1-step4"），每组内放该步骤新增/显示的元素。步骤切换时通过设置对应组的 `display` 属性（"block"/"none"）控制。静态元素（板、线、步骤0标签）放在独立组中始终显示。
  3. 粒子运动：步骤2的粒子沿抛物线运动使用SVG `<animateMotion>`，path引用类平抛轨迹，duration=1.5s，fill="freeze"。步骤3类似，沿直线轨迹运动。为避免重复触发，动画元素在首次进入步骤时播放，回退再前进时不重复播放（可通过JS标记`scene1-animated`状态）。
  4. 坐标计算：类平抛轨迹使用二次贝塞尔曲线 `M60,250 Q190,250 320,290`，控制点(190,250)确保中点(190,260)恰好向下偏10px（1/4总偏量），符合物理抛物线特征。无场区直线斜率0.4（竖直96px/水平240px）。
  5. 按钮禁用逻辑：步骤0时「上一步」按钮置灰（opacity 0.4, pointer-events none）；步骤4时「下一步」按钮置灰。
  6. 事件绑定：按钮绑定 `onclick` 事件，直接调用 `scene1-prevStep()` 和 `scene1-nextStep()`。
- ID命名规范：所有交互元素ID必须以 `scene1-` 为前缀。例如：
  - 粒子：`scene1-particle`
  - 轨迹路径：`scene1-trajectory-parabola`
  - 按钮：`scene1-btn-prev`、`scene1-btn-next`
  - 步骤组：`scene1-step0`、`scene1-step1`、...、`scene1-step4`
  - 状态变量在JS中使用局部变量，不挂载到全局（除入口函数外）
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })()` 中，避免多场景合并时的变量污染。
