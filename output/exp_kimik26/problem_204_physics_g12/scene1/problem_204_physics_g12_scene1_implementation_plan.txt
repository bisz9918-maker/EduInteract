[图示主题与整合说明]
- 本图示主题：水平匀速转动圆盘上两物块 A、B 的三级临界角速度递进分析
- 整合的步骤/概念：装置认知 → ω₀（AB 绳刚有弹力）→ ω₁（OB 绳刚有弹力）→ ω₂（A 刚滑动）
- 教学价值：教师通过「上一步 / 下一步」严格按临界顺序展开，每步只呈现当前临界状态的受力变化，避免一次性堆叠全部力造成学生认知过载；上方圆盘装置与下方隔离体受力图上下对照，建立整体—局部的物理直觉。

[分步序列]
步骤 0（初始状态）：
- 圆盘区：圆盘、O、A、B、参考线、转动箭头可见；AB 绳与 OB 绳均为 #888888 虚线 1px（表示存在但无张力）
- 隔离体区：左右框、标题、质点 A/B 可见；所有力箭头隐藏
- ω 值标注隐藏
- 无高亮

步骤 1（ω₀ 临界，AB 绳刚有弹力）：
- 圆盘区：物块 A 高亮（边框 3px + 发光）；AB 绳与 OB 绳保持灰色虚线（T_AB=0 临界）
- 隔离体区：
  - A 框：f_A 箭头出现（绿色，向左），标签 "f_A = 0.5mg"；T_AB 不画箭头，在 (120,370) 显示 "T_AB = 0"
  - B 框：无箭头
- ω 值：(400,280) 显示 "ω₀ = √(5g/2)"

步骤 2（ω₁ 临界，OB 绳刚有弹力）：
- 圆盘区：物块 B 高亮；AB 绳变为 #1565c0 实线 2px（已有张力）；OB 绳保持灰色虚线（T_OB=0 临界）
- 隔离体区：
  - A 框：f_A 箭头保持；T_AB 箭头出现（蓝色，向左），标签 "T_AB = mg/6"
  - B 框：f_B 箭头出现（绿色，向左），标签 "f_B = 0.5mg"；T_AB 箭头出现（蓝色，向右），标签 "T_AB = mg/6"；T_OB 不画箭头，在 (490,370) 显示 "T_OB = 0"
- ω 值：更新为 "ω₁ = √(10g/3)"

步骤 3（ω₂ 临界，A 刚滑动）：
- 圆盘区：物块 A 高亮（A 刚滑动）；AB 绳蓝色实线；OB 绳变为 #c62828 实线 2px
- 隔离体区：
  - A 框：f_A 箭头保持；T_AB 箭头保持，标签改为 "T_AB = 1.5mg"
  - B 框：f_B 箭头保持；T_AB 箭头保持，标签改为 "T_AB = 1.5mg"；T_OB 箭头出现（红色，向左），标签 "T_OB = 2mg"
- ω 值：更新为 "ω₂ = √(10g)"

教师可随时点击「上一步」回退复习。

[交互方案]
- 交互类型：分步按钮导航（◀ 上一步 / 下一步 ▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于 (310,455)，宽 90px，高 32px；点击回退到上一状态，步骤 0 时禁用
  - 「下一步 ▶」按钮：位于 (410,455)，宽 90px，高 32px；点击推进到下一状态，步骤 3 时禁用
  - 步骤指示文本：位于 (400,448)，显示当前步骤号（如「步骤 1 / 3」）
- 教师操作流程：
  1. 教师先展示步骤 0，让学生观察装置几何关系（O、B、A 位置与绳）；
  2. 点击「下一步」进入步骤 1，讲解 A 最先达到最大静摩擦，AB 绳刚要产生弹力但 T_AB=0，得出 ω₀；
  3. 点击「下一步」进入步骤 2，讲解 B 也达到最大静摩擦，OB 绳刚要产生弹力但 T_OB=0，得出 ω₁；
  4. 点击「下一步」进入步骤 3，讲解 A 即将滑动，所有绳张力达到最终值，得出 ω₂；
  5. 可随时回退复习任意临界状态。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无外部库）。理由：本场景为静态几何图形与箭头矢量，SVG 的 <line>、<circle>、<path>、<text> 完全足够，无需引入 D3/Canvas 增加复杂度；公式使用 Unicode 数学字符（ω、√、₀、₁、₂）即可清晰表达。
- 画布尺寸：800 × 500 px（SVG viewBox="0 0 800 500"）
- 布局草图：
  ```
  y=0    ┌────────────────────────────────────────┐
         │      圆盘俯视图 (y=0~260)               │
         │   转轴O ━━━ B ━━━ A (沿半径虚线)        │
         │        ↺ 转动方向                       │
         │   r_B=10cm↑      ↓r_A=20cm             │
  y=260  ├────────────────────────────────────────┤
         │         ω 值标注 (y=280)                │
  y=290  ├─────────────┬──────────────────────────┤
         │ A 的受力分析 │   B 的受力分析            │
         │  [隔离体框]  │    [隔离体框]             │
         │   ○ ← f_A   │   ○ ← f_B   → T_AB       │
         │     ← T_AB  │   ← T_OB                 │
  y=430  ├─────────────┴──────────────────────────┤
         │      [◀ 上一步]  [下一步 ▶]            │
  y=490  └────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：变量 `let currentStep = 0;`（范围 0~3）。每次点击按钮时更新 `currentStep`，调用 `renderStep()`。
  2. `renderStep()` 逻辑：根据 currentStep 设置各 SVG 元素的 `display`（或 CSS opacity + transition）。所有力箭头、标签、高亮类、绳样式均在此函数中统一更新，避免分散逻辑。
  3. 高亮实现：通过切换 class（如 `.highlight-a`、`.highlight-b`）改变 stroke-width 并添加 `filter: drop-shadow(0 0 4px currentColor)`。
  4. 绳样式切换：直接修改元素的 `stroke`、`stroke-width`、`stroke-dasharray` 属性。
  5. 按钮禁用：步骤 0 时 `scene1-btn-prev` 设 `disabled=true` 并降低透明度；步骤 3 时 `scene1-btn-next` 同理。
  6. 动画曲线：所有显隐变化使用 CSS `transition: opacity 0.3s ease`，避免突兀跳变。
  7. 事件绑定：`scene1-btn-prev` 与 `scene1-btn-next` 的 `click` 事件在 IIFE 内绑定。
- ID 命名规范：所有 SVG 元素及控件 ID 必须以 `scene1-` 为前缀。例如：
  - 圆盘：`scene1-disk`
  - 物块 A：`scene1-mass-a`
  - f_A 箭头：`scene1-arrow-fa`
  - 上一步按钮：`scene1-btn-prev`
  - 下一步按钮：`scene1-btn-next`
  - 步骤文本：`scene1-step-text`
  JS 中严格使用 `document.getElementById` 获取，禁止全局 class 查询，防止多场景合并时污染。
- IIFE 隔离：所有 JavaScript 包在 `(function() { ... })();` 中执行，不暴露全局变量。
