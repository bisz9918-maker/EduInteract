[图示主题与整合说明]
- 本图示主题：带电物块在复合场（匀强电场+重力场）中的多过程运动装置与路径分析
- 整合的步骤/概念：装置结构展示 → M→N 直线段受力与运动 → N→L 半圆周运动（第一问） → N→P 四分之一圆周运动（第二问） → L 点临界条件
- 教学价值：教师可按认知递进顺序逐步呈现，先建立装置全貌，再分过程分析受力、位移与临界条件，避免信息过载，便于学生跟随"直线+圆周"的多过程推理

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶ / 重置）
- 控件说明：
  1. 「◀ 上一步」按钮：位置(260,455)，宽90×32，点击回退到上一状态，步骤0时禁用
  2. 「下一步 ▶」按钮：位置(370,455)，宽90×32，点击前进到下一状态，步骤4时禁用
  3. 「重置」按钮：位置(480,455)，宽70×32，点击立即返回步骤0
- 教师操作流程：教师先展示步骤0让学生观察装置与已知条件；点击「下一步」进入步骤1讲解MN段受力；继续点击依次呈现圆周路径、位移分解、临界条件；可随时回退复习。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本场景为静态几何图形与简单路径高亮，无需复杂数据绑定或3D，原生SVG性能最优且易于精确控制坐标。
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  +--------------------------------------------------+
  |  E ←                                    +--------+|
  |  ←                                      |已知条件||
  |  ←                                      |m=80g  ||
  |  ←                             L        |q=...  ||
  |  ←                             ↑        +--------+|
  |  ←                      P ←—— O ——→ R(半径)       |
  |  ←                             |                  |
  |  ←                             | 2R               |
  |  ←         N==================M [m]               |
  |  ←              S            qE↑f                 |
  |                                               |
  |     [◀上一步]  [下一步▶]  [重置]                  |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机：用变量 `currentStep`（0~4），每步定义 `visibleIds` 数组控制元素显隐。
  2. 渲染函数 `render()`：根据currentStep设置对应元素的 `display` 或 `opacity`，高亮元素切换stroke-width与stroke颜色。
  3. 动画：步骤切换时新元素使用CSS transition `opacity 0→1, 200ms ease`，路径高亮使用 `stroke-dasharray` 描边动画（可选）。
  4. 事件绑定：按钮onclick更新currentStep并调用render()，边界检查（currentStep<0或>4时截断并禁用对应按钮）。
  5. SVG arc路径：半圆用 `M 300 360 A 80 80 0 0 0 300 200`；N→P弧用 `M 300 360 A 80 80 0 0 0 220 280`。
  6. 电场线箭头：使用SVG `<marker>` 定义左向箭头，marker-end附于各电场线。
  7. 已知条件框：使用 `<foreignObject>` 或纯SVG `<text>` 多行排列，推荐纯SVG text/tspan确保跨浏览器一致。
- ID命名规范：所有交互元素ID必须以 `scene1-` 为前缀，例如 `scene1-track-h`, `scene1-arc-NL`, `scene1-btn-next`, `scene1-label-qE` 等。JS中严格使用 `document.getElementById` 获取元素，禁止全局class选择器，避免多场景合并时跨场景污染。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })()` 立即执行函数中，不暴露全局变量。
