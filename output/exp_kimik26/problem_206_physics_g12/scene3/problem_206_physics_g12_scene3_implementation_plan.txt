[分步序列]
- 步骤0（初始状态）：显示x-t坐标系（轴、箭头、刻度线及全部刻度标签t, x, 0, t₁, 3t₁, 5t₁, L, 5L, 13L）；显示图例（A球、B球）；右侧仅显示标题“位移规律”及分隔线；其余元素隐藏。
- 步骤1（第一段运动）：在步骤0基础上，淡入A曲线第1段（蓝色抛物线）与B曲线第1段（红色水平线）；弹出碰撞点P₁绿色圆点；显示标签P₁及位移增量+L；右侧显示s₁ = L。
- 步骤2（第二段运动）：在步骤1基础上，淡入A曲线第2段与B曲线第2段；弹出碰撞点P₂；显示标签P₂及位移增量+4L；右侧显示s₂ = 4L；A曲线第2段线宽短暂变为4px后恢复（高亮位移增量）。
- 步骤3（第三段运动）：在步骤2基础上，淡入A曲线第3段与B曲线第3段；弹出碰撞点P₃；显示标签P₃及位移增量+8L；右侧显示s₃ = 8L；A曲线第3段线宽短暂变为4px后恢复。
- 步骤4（总位移展示）：在步骤3基础上，A曲线三段全部线宽加粗至3.5px（持续高亮）；显示A位移填充区（蓝色10%透明）；显示顶部进程文字“0 → L → 5L → 13L”；显示辅助虚线（从P₂到纵轴5L、从P₃到纵轴13L）；纵轴刻度标签L/5L/13L变为蓝色加粗；右侧显示“总位移 = 13L”。
- 步骤5（位移规律总结）：在步骤4基础上，隐藏顶部进程文字与总位移文字；右侧显示s₄ = 12L, …；显示公式框及公式 x_A=(2n²-2n+1)L；公式框以绿色高亮边框呈现；A曲线恢复线宽2.5px，填充区保持。

[交互方案]
- 交互类型：分步按钮导航（◀ 上一步 / 下一步 ▶）
- 控件说明：
  · 「上一步」按钮：位于(260,460)，宽80×高32；点击回退到上一分步，步骤0时禁用（opacity 0.4）。
  · 「下一步」按钮：位于(460,460)，宽80×高32；点击前进到下一分步，步骤5时禁用（或文案变为“完成”）。
  · 步骤指示器：位于(400,478)，显示当前步骤序号（如“步骤 2/6”对应步骤1）。
- 教师操作流程：教师点击「下一步」逐段揭示A、B运动曲线；每步可停顿讲解碰撞前后速度变化与曲线斜率关系；点击「上一步」随时回退复习；步骤4重点讲解总位移的累加过程；步骤5引导学生归纳通式。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本场景以静态折线、线段、圆和文本为主，SVG路径可直接精确控制，无需引入D3/Canvas等重型库；分步状态通过classList切换控制显示隐藏，逻辑清晰。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  x↑  图例[A球][B球]                              |
  |  13L - +  P₃(5t₁,13L)                            |
  |  5L  - +     P₂(3t₁,5L)                          |
  |  L   - +  P₁(t₁,L)                               |
  |  0   +----+----+----+----+----+  → t             |
  |       0   t₁  3t₁  5t₁                           |
  |                                                  |
  |   [A曲线蓝色]  [B曲线红色]                        |
  |                                                  |
  |        位移规律  |  s₁=L                         |
  |                  |  s₂=4L                        |
  |                  |  s₃=8L                        |
  |                  |  [公式框]                     |
  +--------------------------------------------------+
  |      [◀上一步]   步骤 k/6   [下一步▶]             |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 `currentStep`（0~5），数组 `stepElements` 记录每步应显示/隐藏的元素ID列表；切换步骤时遍历更新 `display` 属性或 `opacity`。
  2. 抛物线绘制：A曲线三段使用 `<polyline>`，点坐标预先计算硬编码（见视觉元素清单），确保数学精确性。
  3. 动画曲线：步骤1~3中曲线出现采用CSS transition（opacity 0→1，duration 400ms）；碰撞点采用scale变换（transform: scale(0)→scale(1)，transform-origin中心）。
  4. 填充区绘制：步骤4的A位移填充区使用 `<path>`，d属性为 "M120,380 {A曲线所有点} L580,380 Z"，配合CSS transition实现淡入。
  5. 按钮状态：步骤0时`scene3-btn-prev`置`disabled=true`；步骤5时`scene3-btn-next`置`disabled=true`。
  6. 步骤指示器：文本内容动态更新为 `步骤 ${currentStep+1} / 6`。
- ID命名规范：所有交互元素ID必须以 `scene3-` 为前缀，例如 `scene3-curve-a1`、`scene3-point-p1`、`scene3-btn-prev`、`scene3-panel-formula` 等；JS中严格使用 `document.getElementById` 获取元素，禁止全局class选择器，避免多场景合并时跨场景污染。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，内部变量与函数不暴露到全局作用域。
