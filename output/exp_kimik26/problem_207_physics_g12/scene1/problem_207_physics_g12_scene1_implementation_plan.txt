[图示主题与整合说明]
- 本图示主题：滑块 A 从固定斜面下滑并滑上木板 B 的完整多阶段运动过程
- 整合的步骤/概念：初始静止 → 斜面匀加速下滑 → 到达底端获得水平速度 → A 与 B 间滑动摩擦导致 A 减速、B 加速 → 最终共速且 A 刚好到达 B 右端
- 教学价值：教师通过分步导航，按时间顺序逐步揭示运动阶段与受力变化，帮助学生建立清晰的物理图景与过程分析框架；每步可自由进退，便于课堂重复讲解关键转折点（如“滑上 B 的瞬间”“共速临界条件”）

[视觉元素清单]
- 斜面：直角三角形，顶点 (80,245)、(260,380)、(80,380)。填充 #eeeeee，边框 #000000 2px。斜边长对应 9 m。
- 地面：水平粗线 (50,410)-(750,410)，线宽 3px。下方绘制灰色短斜线纹理（#888888，20% 透明度）表示粗糙地面。
- 木板 B：矩形，高度 20px，长度 75px（对应 3 m）。填充 #ffffff，边框 #000000 2px。步骤 0-2 左端 x=260；步骤 3 左端 x=268（示意性右移）；步骤 4 左端 x=273（对应 0.5 m 位移）。
- 滑块 A：小矩形 14×10px。填充 #1565c0、透明度 0.3，边框 #1565c0 1px。步骤 0 位于斜面顶端；步骤 1 位于斜面中点；步骤 2 位于斜面底端；步骤 3 位于 B 上中部；步骤 4 位于 B 右端（A 右边缘与 B 右端对齐）。
- 角度标注：在斜面底端 (260,380) 处绘制 18px 半径的 37° 弧线，标签 "α=37°" 置于弧线右下方 (275,375)。
- 加速度箭头（虚线）：a₁、a_A、a_B 均为绿色 #2e7d32，stroke-dasharray="5,3"。
- 速度箭头（实线）：v₀、v 均为红色 #c62828。
- 位移标注线（步骤 4）：x_A、x_B 为绿色 #2e7d32 双向箭头，带两端短垂线；辅助引线用 #888888 虚线。
- 文字标签：#000000，font-family: "Times New Roman", serif，字号 14px（物理量）或 16px（物体名 A/B）。下标使用 tspan 或 Unicode 下标字符。

[分步序列]
- 步骤 0（初始状态）：显示斜面、地面、B（x=260~335）、A（斜面顶端）、固定标签（"9m"、"α=37°"、"μ₁=0.5"、"L=3m"、"B"、"A"）。所有箭头、动态标签、位移标注隐藏。教师可讲解已知条件。
- 步骤 1（斜面下滑）：A 沿斜面从顶端平滑移动到中点（CSS transition 250ms）。显示绿色虚线箭头 a₁（沿斜面向下）及标签 "a₁=2m/s²"。教师讲解 A 在斜面上的受力与加速度。
- 步骤 2（到达底端）：A 继续沿斜面移动到底端 (260,380)（transition 250ms）。隐藏 a₁ 箭头及标签；显示红色实线速度箭头 v₀（水平向右）及标签 "v₀=6m/s"。教师讲解底端速度大小与方向。
- 步骤 3（滑上 B）：A 滑上 B 并移动到 B 中部（transition 250ms），B 同步示意性右移至 x=268~343。隐藏 v₀ 箭头及标签；显示绿色虚线箭头 a_A（向左）及标签 "a_A=5m/s²"、绿色虚线箭头 a_B（向右）及标签 "a_B=1m/s²"。教师讲解两者各自的摩擦力与加速度方向。
- 步骤 4（共速临界）：A 移动到 B 右端 (334,380)-(348,390)，B 右移至 x=273~348（transition 300ms）。隐藏 a_A、a_B 箭头及标签；显示红色速度箭头 v（向右）及标签 "v=1m/s"；显示 x_A 标注线（260~348, y=425）及标签 "x_A=3.5m"；显示 x_B 标注线（260~273, y=445）及标签 "x_B=0.5m"；显示 "Δx=3m" 于 (350,335)。教师讲解共速条件、相对位移恰好等于板长 L 的临界意义。

[交互方案]
- 交互类型：分步按钮导航（◀ 上一步 / 下一步 ▶）
- 控件说明：
  1. 「上一步」按钮：位于 (280,470)，宽 90px，高 28px。点击回退到上一状态，所有元素位置、箭头、标签同步反向过渡。
  2. 「下一步」按钮：位于 (430,470)，宽 90px，高 28px。点击前进到下一状态。
  3. 步骤指示器：位于 (375,470)，显示当前步骤编号（如 "步骤 2/4"）。
- 教师操作流程：教师先展示步骤 0 让学生读取题目条件；点击「下一步」依次展开各阶段运动，配合讲解加速度、速度、位移的数值与方向；可随时点击「上一步」回退到任意阶段进行重复强调或提问。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript。理由：场景以静态几何图形与简单的显隐/位移动作为主，无需复杂数据绑定或 3D 渲染，原生方案最轻量且可控性最高。
- 画布尺寸：800 × 500 px（沿用规定）。SVG 嵌入一个相对定位的容器 div（width:800px; height:500px; position:relative）。控件按钮与步骤指示器使用 position:absolute 叠在 SVG 上方，bottom:5px，不额外撑高容器。
- 布局草图（ASCII）：
  ```
  800×500 画布
  +--------------------------------------------------------+
  |  μ₁=0.5                                                |
  |                                                        |
  |      A                                                 |
  |       \                                                |
  |        \ 9m                                            |
  |         \                                              |
  |          \                                             |
  |           \                                            |
  |            \                                           |
  |             \  α=37°                                   |
  |              \____                                     |
  |  地面 ___________|B|_______________________            |
  |                  |___|                                 |
  |                  L=3m                                  |
  |                                                        |
  |       [◀ 上一步]  步骤 X/4  [下一步 ▶]                  |
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 `currentStep`（0~4）控制当前步骤。定义 `stepConfig` 数组，每个元素记录该步骤下各元素的 `display`、`x`、`y` 属性值。
  2. 坐标计算：A 与 B 的每一步坐标在计划中已精确给出，代码中直接硬编码，避免运行时复杂计算。
  3. 动画曲线：A、B 的位置变化使用 CSS `transition: all 250ms ease-in-out`（SVG 元素通过设置 `style="transition:..."` 或在外部 CSS 中定义 `.scene1-anim { transition: all 0.25s ease-in-out; }`）。箭头与标签的显隐使用 `opacity` 过渡（0→1 或 1→0），避免 display 切换导致的无法过渡问题。
  4. 事件绑定：按钮的 `onclick` 绑定到 IIFE 内部的 `goToStep(n)` 函数。`goToStep` 先检查边界（0≤n≤4），再更新 `currentStep`，然后遍历元素列表应用对应属性。
  5. 箭头绘制：使用 SVG `<marker>` 定义箭头头部（id 带 scene1- 前缀，如 `scene1-arrowhead-red`、`scene1-arrowhead-green`），路径设置 `marker-end`。
  6. 下标处理：SVG `<text>` 中使用 `<tspan dy="3" font-size="12">1</tspan>` 实现 μ₁、x_A 等下标，确保跨浏览器兼容。
- ID 命名规范：所有 SVG 元素及控件 ID 必须以 `scene1-` 为前缀，例如 `scene1-block-a`、`scene1-arrow-a1`、`scene1-btn-next`。JS 中严格使用 `document.getElementById` 获取元素，禁止全局 class 选择，防止多场景合并时跨场景污染。
- IIFE 隔离：所有 JavaScript 逻辑包裹在 `(function() { ... })();` 中，内部状态与函数不暴露到全局作用域。
