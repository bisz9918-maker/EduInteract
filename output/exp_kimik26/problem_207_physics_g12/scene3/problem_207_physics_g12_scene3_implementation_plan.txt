[图示主题与整合说明]
- 本图示主题：滑块 A 与木板 B 的速度-时间（v-t）图像及位移面积关系
- 整合的步骤/概念：在直角坐标系中依次建立坐标轴 → 绘制 A 的匀减速图线 → 绘制 B 的匀加速图线 → 标出共速点与辅助投影线 → 用填充面积直观展示 A 位移、B 位移与相对位移（木板长度 L）之间的几何关系
- 教学价值：教师通过分步导航，引导学生从“图线斜率看加速度”过渡到“图线与轴围成面积看位移”，最终理解“两图线间面积代表相对位移”这一核心结论，建立运动学图像分析的系统思维。

[分步序列]
- 步骤0（初始状态）：显示完整坐标系（横轴、纵轴、箭头、所有刻度线与刻度值）、轴标签（t/s、v/(m·s⁻¹)），并在纵轴v=6处左侧标注 v₀=6。其余元素隐藏。
- 步骤1（A的图线）：在步骤0基础上，以动画形式绘制A的v-t图线（从(120,130)到(620,355)的蓝色线段），动画结束后显示标签"A"（300,202）和"a_A=5"（435,208）。
- 步骤2（B的图线）：在步骤1基础上，以动画形式绘制B的v-t图线（从(120,400)到(620,355)的红色线段），动画结束后显示标签"B"（300,392）和"a_B=1"（435,398）。
- 步骤3（共速点）：在步骤2基础上，显示共速点圆点(620,355)，并画出水平虚线至纵轴、竖直虚线至横轴；随后显示标签"t=1s"（640,435）和"v=1m/s"（70,362）。
- 步骤4（面积与位移）：在步骤3基础上，依次淡入三个填充区域（A位移梯形、B位移三角形、相对位移三角形），并在各区域内显示对应位移标签"x_A=3.5m"（370,322）、"x_B=0.5m"（450,387）、"Δx=L=3m"（280,297）；最后显示右上角图例框（640,75）及其三项图例说明。
- 教师可随时点击「上一步」回退至任意步骤复习。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「上一步」按钮：位于(300,455)，宽80高30，点击回退一个步骤，步骤0时禁用。
  2. 「下一步」按钮：位于(420,455)，宽80高30，点击前进一个步骤，步骤4时禁用。
  3. 步骤指示器：位于(400,445)，显示当前步骤编号（如"步骤 1 / 5"）。
- 教师操作流程：教师先展示步骤0的坐标系与初速度标记，讲解横纵轴物理意义；点击「下一步」进入步骤1，观察A的减速过程与加速度标注；继续点击依次呈现B的加速、共速点、面积位移关系。在步骤4可停留较长时间，配合图例讲解三块面积的几何意义与物理对应关系。若学生某步理解困难，点击「上一步」回退重讲。

[技术实现]
- JS库选择：原生 SVG + 原生 JavaScript。理由：本场景为二维几何图形（线段、多边形、文字、虚线），无复杂函数绘图或3D需求，原生SVG足以保证清晰度与性能，且便于通过CSS类控制显隐。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  v/(m·s⁻¹)                                       |
  |    |  7                                           |
  |    |  6  · v₀=6                                   |
  |    |    /\ A                                     |
  |    |   /  \    图例框 [A][B][Δx=L]               |
  |    |  /    \                                      |
  |    | /      \                                    |
  |    |/        \                                   |
  |    +----------+-- t/s                            |
  |   0          1.0                                 |
  |                                                  |
  |              [◀上一步]  步骤 X/5  [下一步▶]       |
  +--------------------------------------------------+
  控件栏位于 y=440~490（SVG内绝对定位）
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `currentStep`（0~4），数组 `stepElements` 记录每步应显示/隐藏的SVG元素ID列表。`updateScene()` 函数根据 `currentStep` 设置对应元素的 `display` 或 `opacity`。
  2. 图线绘制动画：利用 SVG 的 `stroke-dasharray` 与 `stroke-dashoffset` 实现线段"生长"效果。在步骤1/2进入时，将目标线段dasharray设为总长度，通过JS动画（requestAnimationFrame）在约600ms内将dashoffset从总长减至0。
  3. 面积填充淡入：步骤4中的三个 `<polygon>` 元素初始 `opacity: 0`，通过CSS transition在300ms内淡入至目标透明度（0.15或0.20）。
  4. 坐标映射公式：横轴 `x = 120 + t * 500`；纵轴 `y = 400 - v * 45`。所有数据点均通过此公式计算，确保图线精确通过理论坐标。
  5. 事件绑定：按钮绑定 `click` 事件，更新 `currentStep` 后调用 `updateScene()` 与 `updateButtons()`（控制按钮disabled状态）。
- ID命名规范：所有SVG元素及控件ID必须以 `scene3-` 为前缀。例如：`scene3-axis-x`、`scene3-axis-y`、`scene3-line-a`、`scene3-line-b`、`scene3-area-a`、`scene3-area-b`、`scene3-area-delta`、`scene3-legend-box`、`scene3-btn-prev`、`scene3-btn-next`、`scene3-step-indicator`。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免多场景合并时的全局变量污染。
