    **完整题目原文**

    如图所示，两平行金属板水平放置，板间存在垂直纸面的匀强磁场和电场强度为E的匀强电场。金属板右下方以MN为上边界，PQ为下边界，MP为左边界的区域内，存在垂直纸面向外的匀强磁场，磁场宽度为d，MN与下极板等高，MP与金属板右端在同一竖直线。一个电荷量为q、质量为m的正离子以初速度v₀在两板间沿平行于金属板的虚线射入金属板间。不计粒子重力。

    (1) 已知离子恰好做匀速直线运动，求金属板间的磁感应强度B₀；
    (2) 若撤去板间磁场B₀，离子恰好从下极板的右侧边缘射出电场，方向与水平方向成30°角，离子进入磁场运动后从磁场边界点射出，求该磁场的磁感应强度B的大小。

    **题目分析**

    本题是一道典型的带电粒子在复合场中运动的综合题，涵盖三个核心物理模型：
    1. **速度选择器**（电场与磁场平衡）
    2. **类平抛运动**（仅在电场中的偏转）
    3. **匀速圆周运动**（仅在磁场中的偏转）

    解题的关键在于理清粒子在不同阶段的运动性质，做好**速度分解**与**几何约束分析**。

    **整体讲解思路**

    1. 先利用板间匀速直线运动的受力平衡求出B₀，建立电场与初速度的关系。
    2. 再分析撤去B₀后粒子在电场中的类平抛运动，重点抓住"恰好从下极板右边缘射出"和"出射方向30°"两个条件，求出粒子进入磁场时的速度大小与方向。
    3. 最后将速度方向与磁场边界条件结合，利用**左手定则**确定圆心位置，通过**几何关系**找到圆周运动半径R与磁场宽度d的联系，进而求出B。

    **SCENE_1 教学说明：板间运动分析**

    教师应引导学生按以下逻辑观察图示：

    1. **明确装置结构**：先让学生识别平行板电容器的极性（上正下负），判断板间匀强电场方向竖直向下。正离子在电场中受电场力方向与电场方向相同，即竖直向下。

    2. **第(1)问——速度选择器原理**：
       - 强调粒子"恰好做匀速直线运动"意味着**合外力为零**。
       - 板间同时存在电场和磁场，正离子受向下的电场力 F_E = qE。
       - 根据左手定则，以初速度v₀水平向右运动的正离子在垂直纸面向里的磁场B₀中，受向上的洛伦兹力 F_B = qv₀B₀。
       - 由平衡条件得：**qE = qv₀B₀**，因此 **B₀ = E/v₀**。
       - 此处可追问学生：若改变入射速度，粒子向哪侧偏转？（速度增大则洛伦兹力大于电场力，向上偏转。）

    3. **第(2)问前半段——类平抛运动**：
       - 撤去B₀后，粒子仅在恒定电场力作用下运动，初速度水平，受力竖直，符合**类平抛**条件。
       - 水平方向：匀速直线运动，x = v₀t，速度保持v₀。
       - 竖直方向：初速为零的匀加速直线运动，a = qE/m，v_y = at，y = ½at²。
       - 关键条件："恰好从下极板右侧边缘射出"说明竖直位移等于板间距离；"方向与水平成30°"给出速度偏转角。

    4. **速度分解与衔接**：
       - 在出射点M处，将速度分解为水平分量v₀与竖直分量v_y。
       - 由几何关系：**tan30° = v_y/v₀**。
       - 合速度大小：**v = v₀/cos30° = 2v₀/√3**。此速度即为粒子进入下方磁场时的初速度，是连接电场段与磁场段的关键桥梁。

    **SCENE_2 教学说明：磁场中圆周运动分析**

    教师应引导学生按以下逻辑观察图示：

    1. **明确入射条件**：粒子从M点进入磁场，速度方向与水平成30°角斜向右下方，磁场方向垂直纸面向外（用"·"表示）。

    2. **左手定则判断洛伦兹力方向**：
       - 伸开左手，让磁感线垂直穿入手心（磁场向外，手心朝向纸面内侧/远离观察者）。
       - 四指指向正电荷运动方向（斜向右下方30°）。
       - 拇指指向即为洛伦兹力方向：**向左下方**。
       - 强调洛伦兹力始终垂直于速度，因此粒子做**匀速圆周运动**，圆心位于过M点且垂直于v的方向上。

    3. **圆心定位与几何关系**：
       - 圆心O在M点的左下方，连线MO与水平方向夹角为60°（因为MO垂直于v，v与水平成30°）。
       - 以M为原点、向右为x轴、向上为y轴，圆心坐标为 **(−R/2, −R√3/2)**。
       - 圆心到左边界MP（x=0）的水平距离为 **R/2**。
       - 圆心到上边界MN（y=0）的竖直距离为 **R√3/2**。
       - 圆心到下边界PQ（y=−d）的竖直距离为 **d − R√3/2**（当R√3/2 < d时）。

    4. **边界射出条件分析**：
       - 轨迹与左边界MP的另一交点（除M外）位于 **y = −R√3** 处。
       - **若 R√3 < d**：该交点在磁场内部，粒子**从左边界MP射出**。
       - **若 R√3 > d**：粒子在到达左边界之前先到达下边界，**从下边界PQ射出**。
       - **若 R√3 = d**：粒子恰好从左下角P点射出，为临界情况。
       - 教师应根据题目给定的具体条件（如"恰好从P点射出"等）选择对应情况建立方程。

    5. **求解磁感应强度B**：
       - 核心动力学方程：**qvB = mv²/R**，即 **R = mv/(qB)**。
       - 将步骤4确定的几何关系（如 R = d/√3 等）代入，结合步骤3中得到的 v = v₀/cos30°，即可联立求解B。
       - 若题目未指定具体射出边界，需引导学生讨论两种可能性，说明B值与射出边界的对应关系。

    **总结：完整解答与课堂讲解建议**

    **完整解答梳理**

    1. **第(1)问**：
       由匀速直线运动受力平衡：
       $$qE = qv_0B_0$$
       解得：
       $$B_0 = \frac{E}{v_0}$$

    2. **第(2)问前半段（电场中偏转）**：
       撤去B₀后，粒子做类平抛运动。出射时速度方向与水平成30°，故：
       $$v = \frac{v_0}{\cos30°} = \frac{2v_0}{\sqrt{3}}$$

    3. **第(2)问后半段（磁场中圆周运动）**：
       粒子以速度v进入磁场，做匀速圆周运动，半径：
       $$R = \frac{mv}{qB}$$
       结合几何关系（圆心位置及边界约束），根据粒子实际射出的边界建立R与d的方程，代入v后即可解得B的具体表达式。

    **课堂讲解建议**

    - **强调衔接点**：板间出射速度v是连接电场段与磁场段的唯一桥梁，务必让学生明确 v = v₀/cos30° 的来源。
    - **强化几何训练**：磁场中圆周运动问题的难点不在物理公式，而在几何关系。建议带领学生现场推导圆心坐标、到各边界的距离，避免死记硬背。
    - **边界讨论**：若题目未明确射出边界，鼓励学生自己分析"粒子可能从哪条边界出去"，培养分类讨论意识。可借助图示中的临界情况（恰好过P点）帮助学生建立"半径决定出路"的直观认识。
    - **对比总结**：讲完本题后可对比三种场中运动的特点——电场中类平抛（恒力，轨迹抛物线）、磁场中圆周（变力，轨迹圆弧）、速度选择器中直线（平衡，轨迹直线），形成知识网络。
