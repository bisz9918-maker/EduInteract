[分步序列]
- 步骤0（初始状态）：显示完整v-t图线（两段均为黑色2px）、坐标轴及箭头、所有刻度线与刻度标签（v₀、t₁、3t₁、-v₁）、轴标签（t、v）、原点标签O、辅助虚线（水平+垂直）。不显示阶段标签、公式、填充区、提示文字。教师可在此步讲解题目背景与图线整体形状。
- 步骤1（上滑阶段）：点击「下一步」→ 上滑线段(200,120)-(300,250)变为红色3px；上滑三角形填充区淡入（opacity 0→0.15）；显示"上滑阶段"标签(220,175)；右侧显示公式"a₁ = v₀/t₁"(580,170)红色。教师讲解上滑过程匀减速，斜率大小为v₀/t₁。
- 步骤2（下滑阶段）：点击「下一步」→ 下滑线段(300,250)-(500,380)变为蓝色3px；下滑三角形填充区淡入；显示"下滑阶段"标签(380,330)；右侧显示公式"a₂ = v₁/(2t₁)"(580,330)蓝色。上滑阶段高亮保持。教师讲解下滑过程匀加速，时间间隔为2t₁，斜率大小为v₁/(2t₁)。
- 步骤3（汇总结论）：点击「下一步」→ 两个公式同时显示并保持；在公式后方添加浅绿色背景框(570,150)-(690,190)与(570,310)-(710,350)；显示绿色提示文字"接下来进行受力分析"(580,250)。两线段高亮与两填充区均保持。教师总结两阶段加速度，过渡到牛顿第二定律求动摩擦因数。
- 教师可随时点击「上一步」回退到任意步骤复习。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「上一步」按钮：位置(300,455)，90×32px，点击回退到上一状态，步骤0时禁用（opacity 0.4）
  2. 步骤指示器：位置(400,455)，80×32px，居中显示"步骤 X/4"文字，不可点击
  3. 「下一步」按钮：位置(500,455)，90×32px，点击前进到下一状态，步骤3时禁用（opacity 0.4）
- 教师操作流程：
  1. 教师打开图示，首先进入步骤0，向学生展示完整v-t图线，说明物块先上滑后下滑的整体过程。
  2. 点击「下一步」进入步骤1，聚焦上滑阶段，引导学生观察速度从v₀减到0，计算加速度a₁=v₀/t₁。
  3. 点击「下一步」进入步骤2，聚焦下滑阶段，引导学生观察速度从0反向增加到-v₁，历时2t₁，计算加速度a₂=v₁/(2t₁)。
  4. 点击「下一步」进入步骤3，汇总两阶段加速度，用绿色高亮提示即将进入受力分析环节。
  5. 讲解过程中可随时点击「上一步」回退，强化学生记忆。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：本场景为简单折线图与几何填充，无需复杂数据绑定或3D渲染，原生SVG性能最优且文件体积最小。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +----------------------------------------------------------+
  |  v                                                       |
  |  | v₀ ●----\                                             |
  |  |    ↑   上滑 \                                         |
  |  |    |       \         右侧公式区                        |
  |  |    |        \        [a₁ = v₀/t₁]  (步骤1~3)          |
  |  O----+---------●-------\                                |
  |  |    |       t₁        \  下滑                          |
  |  |    |                  \      [a₂ = v₁/(2t₁)] (步骤2~3)|
  |  |    |                   \                             |
  |  |   -v₁←-----------------●----→t                       |
  |  |                        ↑ 3t₁                         |
  |  |                                                       |
  |  |         [◀ 上一步] [步骤 X/4] [下一步 ▶]              |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `let currentStep = 0;` 记录当前步骤（0~3）。每次点击按钮时更新状态，调用 `renderStep()` 函数同步SVG元素显示。
  2. 元素显隐控制：为每个步骤特有的SVG元素（填充区、阶段标签、公式、提示文字）设置初始 `opacity: 0` 或 `display: none`，通过CSS transition实现淡入（transition: opacity 0.3s ease）。
  3. 线段高亮切换：上滑/下滑线段使用两个独立的`<line>`或`<path>`元素（一个黑色底版始终显示，一个高亮版通过opacity切换），或直接修改同一元素的stroke与stroke-width并添加transition。
  4. 坐标计算：t轴采用线性映射，每t₁对应100px（x: 200→300→400→500）；v轴对称分布，v₀与-v₁分别距原点130px（y: 120与380）。
  5. 动画曲线：所有opacity与stroke-width变化使用CSS `transition: all 0.3s ease`，避免生硬跳变。
  6. 事件绑定：按钮通过`onclick`绑定`prevStep()`与`nextStep()`函数，并在函数内检查边界（currentStep ≤ 0或≥ 3时禁用对应按钮）。
- **ID命名规范**：所有SVG元素及控件ID必须以`scene1-`为前缀。例如：
  - 坐标轴：`scene1-axis-t`、`scene1-axis-v`
  - 线段：`scene1-line-up`、`scene1-line-down`
  - 填充区：`scene1-fill-up`、`scene1-fill-down`
  - 标签：`scene1-label-v0`、`scene1-label-t1`、`scene1-label-upstage`
  - 公式：`scene1-formula-a1`、`scene1-formula-a2`
  - 提示：`scene1-hint-next`
  - 按钮：`scene1-btn-prev`、`scene1-btn-next`
  - 指示器：`scene1-step-indicator`
  JS中严格使用`document.getElementById()`获取元素，禁止全局class选择，避免多场景合并时跨场景污染。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 立即执行函数中，变量不污染全局作用域。
