    <TEXT_1>
    **题目原文**

    将C棒、Fe棒平行插入饱和NaCl溶液中（如图所示）。下列叙述符合事实的是（  ）

    A．断开K₂，闭合K₁时，Fe电极反应为：2H⁺ + 2e⁻ = H₂↑

    B．断开K₂，闭合K₁时，C电极反应为：2Cl⁻ - 2e⁻ = Cl₂↑

    C．断开K₁，闭合K₂时，Fe电极反应为：Fe - 2e⁻ = Fe²⁺

    D．断开K₁，闭合K₂时，C电极反应为：2Cl⁻ - 2e⁻ = Cl₂↑

    **整体分析**

    本题核心考查**原电池**与**电解池**的区分，以及不同装置中电极极性、电极反应式的判断。解题关键在于：

    1. **开关状态决定装置类型**：闭合K₁、断开K₂时，C与Fe直接相连形成**原电池**；闭合K₂、断开K₁时，外接电源接入形成**电解池**。
    2. **电极材料决定反应**：Fe为活泼金属，在原电池中作负极被氧化；在电解池中若接电源正极作阳极，活性电极优先失电子溶解。C为惰性电极，只起导电作用，不参与反应。
    3. **溶液环境决定放电顺序**：饱和NaCl溶液呈中性，原电池正极发生**吸氧腐蚀**（O₂得电子），而非析氢或Cl⁻失电子。

    **图示规划说明**

    - Scene 1（宏观电路）：通过状态切换，让学生直观看到两种开关状态分别形成原电池和电解池，明确电子流向和电极名称（正/负极 vs. 阴/阳极）。
    - Scene 2（微观反应）：分步展示两种模式下电极表面的具体反应、溶液中离子迁移方向，帮助学生从微观层面理解电极反应式的书写依据。
    </TEXT_1>

    **Scene 1 教学说明：宏观电路与装置判断**

    教师可先点击「基础装置」，让学生识别装置组成：惰性电极C、活性电极Fe、饱和NaCl溶液（中性环境）、两个开关K₁与K₂、外接直流电源（左负右正）。

    接着切换到「原电池(K₁闭)」，引导学生观察：
    1. 闭合K₁后，C与Fe通过导线直接相连，形成**原电池**（无外接电源）。
    2. 根据金属活动性，Fe比C活泼，故Fe作**负极**（失电子，发生氧化反应），C作**正极**（得电子，发生还原反应）。
    3. 电子流向只能从Fe经外电路流向C，溶液中依靠离子导电。

    再切换到「电解池(K₂闭)」，引导学生观察：
    1. 闭合K₂后，外接电源接入，装置变为**电解池**。
    2. 从电源符号可知，左侧（短线）为负极，右侧（长线）为正极。因此C棒连接电源负极，作**阴极**；Fe棒连接电源正极，作**阳极**。
    3. 电子从电源正极流出，经导线到达Fe棒；从C棒经导线流回电源负极。

    **关键提问**：为什么同样是Fe棒，在原电池中叫负极，在电解池中叫阳极？（提示：命名体系不同，但均发生氧化反应——失电子。）

    **Scene 2 教学说明：微观反应与离子迁移**

    本图示从微观角度揭示两种装置的工作机理，教师应配合Scene 1的宏观判断进行讲解。

    **步骤1：原电池（吸氧腐蚀）**

    1. 引导学生观察Fe棒：Fe作为负极，**自身失电子**被氧化为Fe²⁺进入溶液，反应为 Fe − 2e⁻ = Fe²⁺。强调A选项错误的原因：Fe电极不可能发生得电子的还原反应（2H⁺ + 2e⁻ = H₂↑）。
    2. 引导学生观察C棒：C为正极，由于溶液是中性饱和NaCl，发生**吸氧腐蚀**，溶解在溶液中的O₂在C棒表面得电子生成OH⁻，反应为 O₂ + 2H₂O + 4e⁻ = 4OH⁻。强调B选项错误的原因：C电极发生还原反应，而非Cl⁻失电子的氧化反应。
    3. 离子迁移：阳离子（Na⁺）向正极（C棒）移动，阴离子（Cl⁻）向负极（Fe棒）移动，以维持溶液电中性。

    **步骤2：电解池（活性阳极溶解）**

    1. 引导学生观察Fe棒：Fe连接电源正极作阳极。由于Fe是**活性电极**，其失电子能力远强于溶液中的Cl⁻，因此阳极反应为 Fe − 2e⁻ = Fe²⁺，而非Cl⁻放电。这是C选项正确的核心依据。
    2. 引导学生观察C棒：C连接电源负极作阴极，发生还原反应。中性溶液中H⁺浓度极低，实质是**水分子得电子**析出氢气：2H₂O + 2e⁻ = H₂↑ + 2OH⁻（若简化可写2H⁺ + 2e⁻ = H₂↑，但需向学生说明实际是水放电）。强调D选项错误的原因：C棒是阴极，发生还原反应，不可能出现Cl⁻失电子的氧化反应。
    3. 离子迁移：阳离子（Na⁺）向阴极（C棒）移动，阴离子（Cl⁻）向阳极（Fe棒）移动。

    **关键对比总结**：
    - 两种模式下Fe棒均发生氧化反应（失电子），但原因不同：原电池中因金属活泼性自发失电子；电解池中因外接电源强制其失电子。
    - C棒在两种模式下均发生还原反应（得电子），但还原剂不同：原电池中是O₂得电子；电解池中是H₂O（或H⁺）得电子。
    </TEXT_3>

    <TEXT_4>
    **完整解答与课堂建议**

    **答案：C**

    **逐项分析：**

    1. **A项错误**：断开K₂、闭合K₁时形成原电池，Fe作负极，应失电子发生氧化反应（Fe − 2e⁻ = Fe²⁺），而非得电子生成H₂。
    2. **B项错误**：原电池中C作正极，应发生还原反应。饱和NaCl溶液呈中性，正极反应为吸氧腐蚀（O₂ + 2H₂O + 4e⁻ = 4OH⁻），不是Cl⁻失电子。
    3. **C项正确**：断开K₁、闭合K₂时形成电解池，Fe接电源正极作阳极。Fe为活性电极，优先失电子溶解：Fe − 2e⁻ = Fe²⁺。
    4. **D项错误**：电解池中C接电源负极作阴极，应发生还原反应（2H₂O + 2e⁻ = H₂↑ + 2OH⁻），不是Cl⁻失电子的氧化反应。

    **课堂讲解建议：**

    - **先宏观后微观**：先用Scene 1让学生判断装置类型和电极名称，再用Scene 2剖析具体反应，符合从现象到本质的认知规律。
    - **强调“活性电极”概念**：本题易错点是学生死记“阳极Cl⁻放电”的规律，而忽略了Fe是活性金属电极。可通过Scene 2步骤2中Fe²⁺进入溶液的动画，强化“活性阳极自身溶解”的印象。
    - **对比记忆**：建议列表对比原电池与电解池的电子流向、离子移动方向、电极反应类型，帮助学生建立系统的电化学分析框架。
