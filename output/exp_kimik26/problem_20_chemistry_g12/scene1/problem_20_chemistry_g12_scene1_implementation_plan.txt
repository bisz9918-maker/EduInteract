[图示主题与整合说明]
- 本图示主题：宏观电路与双模式切换对比（原电池 vs 电解池）
- 整合内容：
  1. 基础实验装置认知（C棒、Fe棒、饱和NaCl溶液、K₁、K₂、外接电源的相对位置）
  2. 断开K₂闭合K₁时的原电池电路（电子从Fe棒经导线流向C棒，Fe为负极，C为正极）
  3. 断开K₁闭合K₂时的电解池电路（电子从电源负极→C棒，从Fe棒→电源正极；Fe为阳极，C为阴极）
- 教学价值：教师可通过底部三按钮即时切换三种状态，横向对比原电池与电解池在电极命名、电子流向、开关状态上的差异，强化“负极/正极”与“阴极/阳极”的对应关系。

[分步序列]
本场景采用「多状态切换」交互，无顺序步骤，三个状态互斥切换：

- 状态0「基础装置」（初始状态）：
  - 显示：烧杯、溶液、C棒、Fe棒、主导线、K₁（灰色断开）、K₂（灰色断开）、电源（灰色）、基础标签（C、Fe、饱和NaCl溶液、K₁、K₂、电源）
  - 隐藏：所有电子箭头、电极名称标签（正极/负极/阴极/阳极）、电源正负极标签（−/＋）
  - 色彩：所有导线/开关/电源为灰色 #888888，表示电路未接通

- 状态1「原电池(K₁闭)」：
  - 触发：点击底部「原电池(K₁闭)」按钮
  - 变化：
    1. K₁开关变为黑色闭合状态（闸刀水平），K₂保持灰色断开
    2. 电源保持灰色
    3. 主导线下方出现红色电子箭头（从Fe侧指向C侧，即向右→左），标注红色"e⁻"
    4. Fe棒右侧出现红色标签"负极（氧化）"
    5. C棒左侧出现蓝色标签"正极（还原）"
  - 其余基础元素保持不变

- 状态2「电解池(K₂闭)」：
  - 触发：点击底部「电解池(K₂闭)」按钮
  - 变化：
    1. K₂开关变为黑色闭合状态，K₁保持灰色断开
    2. 电源变为黑色高亮，并显示蓝色"−"（负极下方）、红色"＋"（正极下方）
    3. 左上行导线下方出现红色电子箭头（从K₂侧指向C侧，即向右→左），标注红色"e⁻"
    4. 右上行导线下方出现红色电子箭头（从Fe侧指向电源正极，即向左→右），标注红色"e⁻"
    5. Fe棒右侧出现红色标签"阳极（氧化）"
    6. C棒左侧出现蓝色标签"阴极（还原）"
  - 其余基础元素保持不变

[交互方案]
- 交互类型：多状态切换（3个互斥状态）
- 控件说明：
  1. 「基础装置」按钮：位置(200,455)，宽120，高30。点击切换到状态0，显示未通电的基础装置。
  2. 「原电池(K₁闭)」按钮：位置(340,455)，宽140，高30。点击切换到状态1，K₁闭合，展示原电池电子流向与电极命名。
  3. 「电解池(K₂闭)」按钮：位置(500,455)，宽140，高30。点击切换到状态2，K₂闭合，展示电解池电子流向与电极命名。
- 教师操作流程：
  1. 教师先点击「基础装置」，讲解实验器材与开关位置。
  2. 点击「原电池(K₁闭)」，引导学生观察电子从Fe流向C，确认Fe为负极（氧化）、C为正极（还原）。
  3. 点击「电解池(K₂闭)」，引导学生对比电子流向变化，确认Fe为阳极（氧化）、C为阴极（还原），强调外接电源强制改变电极极性。
  4. 可反复切换状态1/2，进行横向对比。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：电路图由简单几何（矩形、线段、路径、文本）构成，无需复杂图表库；原生SVG可精确控制每个元素的stroke/fill/display属性，状态切换轻量高效。
- 画布尺寸：800 × 500 px（SVG viewBox="0 0 800 500"）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |        电源(580,55)                               |
  |    K₂(500,65)   [电池符号]                        |
  |       |            |                             |
  |  左上行导线    右上行导线                         |
  |       |            |                             |
  |  C棒--+---K₁-----+--Fe棒    K₁(400,125)         |
  |  |               |                               |
  |  |  溶液填充      |                               |
  |  |               |                               |
  |  +---------------+  饱和NaCl溶液(400,415)         |
  |  烧杯外框                                       |
  |                                                 |
  |  [基础装置] [原电池(K₁闭)] [电解池(K₂闭)]        |
  +--------------------------------------------------+
  控件栏 y=440~490
  ```
- 关键实现要点：
  1. 状态机设计：用变量 `currentState`（0/1/2）记录当前状态。点击按钮时更新状态并调用 `renderState()`。
  2. `renderState()` 函数：根据状态批量设置SVG元素的属性：
     - 开关状态：通过切换闸刀元素的 `d` 属性（断开：斜线；闭合：水平线）和 `stroke` 颜色（灰/黑）。
     - 导线颜色：未激活状态灰色 #888888，激活状态黑色 #000000。
     - 电子箭头/标签：使用 `display: none/block` 或 `opacity: 0/1` 控制显隐。
     - 按钮选中态：给当前状态对应按钮添加绿色边框类 `active-btn`，移除其他按钮的该类。
  3. 坐标计算：所有坐标硬编码于SVG的 `x/y/x1/y1/d` 属性中，确保与布局坐标表严格一致。
  4. 动画曲线：状态切换无需复杂动画，直接瞬时切换（0.1s CSS transition on opacity/stroke 可选，增强平滑感）。
  5. 事件绑定：每个按钮绑定 `onclick` 事件，调用 `setState(n)`。
- ID命名规范：
  - 开关：scene1-switch-k1、scene1-switch-k2
  - 导线：scene1-wire-main、scene1-wire-left、scene1-wire-right
  - 电子箭头：scene1-arrow-main、scene1-arrow-left、scene1-arrow-right
  - 标签：scene1-label-c、scene1-label-fe、scene1-label-neg-ox 等
  - 按钮：scene1-btn-base、scene1-btn-battery、scene1-btn-electrolysis
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })()` 中，避免全局变量污染。
