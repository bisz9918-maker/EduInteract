[图示主题与整合说明]
- 本图示主题：正三角形匀速穿过正方形的动态过程与重叠面积 S-t 函数实时生成
- 整合的步骤/概念：
  1. 进入初期（0≤t≤0.5）：重叠区域为小三角形，面积按抛物线 S=(√3/2)t² 增长；
  2. 进入后期（0.5<t≤1）：重叠区域为四边形，面积按 S=√3/4-(√3/2)(1-t)² 继续增长至最大值 √3/4；
  3. 完全进入瞬间（t=1）：三角形整体位于正方形内，面积达到峰值；
  4. 离开初期（1<t≤1.5）：重叠区域为四边形，面积按 S=√3/4-(√3/2)(t-1)² 减小；
  5. 离开后期（1.5<t≤2）：重叠区域为小三角形，面积按 S=(√3/2)(2-t)² 减小至 0。
- 教学价值：教师通过拖拽滑块可自由停留在任意时刻，观察几何重叠区域的形状变化与函数图像上点的对应关系，尤其在 t=0.5、1、1.5 三个关键拐点处停留，讲解面积公式的分段变化与曲线凹凸性的转换。

[视觉元素清单]
- 正方形：固定于几何区中央偏下，左下角(180,300)，边长120px（对应实际边长1），填充浅灰#e0e0e0，黑色边框2px。
- 正三角形：边长120px，高104px（120×√3/2），底边在地面线Y=300上。初始t=0时右下角与正方形左下角重合，随t向右平移，速度120px/单位时间。填充蓝色半透明 rgba(21,101,192,0.15)，边框#1565c0，线宽2px。
- 重叠区域：由正方形与三角形的交集实时计算的多边形。填充红色半透明 rgba(198,40,40,0.30)，边框#c62828，线宽2px。始终位于两者交集处，不超出正方形边界。
- S-t坐标系：函数区横轴t范围[0,2]，映射到x∈[460,760]（150px/单位）；纵轴S范围[0,0.5]，映射到y∈[340,100]（480px/单位，S=0在下方）。带箭头与刻度。
- 轨迹曲线：已生成的(t,S)路径，绿色#2e7d32，线宽2.5px。随滑块拖动实时延长。
- 当前点：红色圆点#c62828，半径5px，白色描边2px，标记当前(t,S)。
- 投影虚线：从当前点向两轴作的垂线，灰色虚线#888888，线宽1px。始终显示以强化对应关系。

[分步序列]
本场景采用连续滑块交互，无离散分步。以下描述关键状态节点，教师可自由停留在任意位置：
- 初始状态（t=0）：三角形位于正方形左侧，右下角与正方形左下角重合，重叠面积为0。函数区仅显示坐标轴与原点。信息面板显示"准备进入，S=0"。
- 关键节点1（t=0.5）：三角形左下角到达正方形左下角，重叠区域为直角三角形（面积=√3/8）。函数曲线在此点前下凸、此后上凸，为第一个拐点。吸附刻度线高亮提示。
- 关键节点2（t=1）：三角形完全进入正方形，底边与正方形底边重合，面积达到最大值√3/4。函数曲线达到峰值，导数为0。
- 关键节点3（t=1.5）：三角形右下角到达正方形右下角，重叠区域再次变为直角三角形（面积=√3/8）。函数曲线在此点前上凸、此后下凸，为第二个拐点。吸附刻度线高亮提示。
- 最终状态（t=2）：三角形完全离开正方形，重叠面积为0。函数曲线闭合于横轴，形成完整的"钟形"分段抛物线。

[交互方案]
- 交互类型：连续拖拽滑块（t∈[0,2]）
- 控件说明：
  1. 时间滑块：位于底部y=448~462，轨道x=100~700。教师水平拖动蓝色圆钮控制时间t，左侧几何区三角形实时平移，重叠区域自动重绘，右侧函数区实时绘制轨迹并更新当前点。
  2. 辅助线按钮：位于底部右侧(720,445)-(790,475)。点击切换几何区内重叠区域高线（从重叠顶点向底边的垂线）的显示/隐藏，以及函数区投影虚线的显示/隐藏。
- 吸附提示：当滑块值进入关键节点±0.06范围内（t∈[0.44,0.56]、[0.94,1.06]、[1.44,1.56]），对应刻度线（x=250,400,550）高亮为红色#c62828，线宽加粗至2px，方便教师精确停靠。
- 教师操作流程：
  1. 加载后展示t=0初始状态；
  2. 缓慢向右拖动滑块，观察三角形进入正方形、重叠区域从小三角形变为四边形、面积数值增大；
  3. 在t≈0.5处停留（刻度高亮提示），讲解进入初期的面积公式与曲线凹凸性；
  4. 继续拖动至t=1，讲解面积最大值与完全进入状态；
  5. 继续拖动至t≈1.5，讲解离开初期的对称性；
  6. 拖动至t=2，完成整个S-t曲线，总结分段函数特征；
  7. 可随时反向拖动或点击辅助线按钮增强几何量与函数值的对应关系。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本场景以2D几何图形、多边形裁剪、路径绘制为主，无需复杂数据绑定或3D渲染，原生SVG性能足够且便于精确控制每个像素坐标。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |  +------------------------+  +----------------+  |
  |  |  信息面板 [30,50]      |  |                |  |
  |  |  阶段/公式/数值        |  |   S-t 坐标系   |  |
  |  +------------------------+  |   [440,40]     |  |
  |  |                        |  |                |  |
  |  |    几何动画区 [20,40]  |  |   曲线+当前点  |  |
  |  |                        |  |                |  |
  |  |    正方形 + 三角形     |  |                |  |
  |  |    重叠区域高亮        |  |                |  |
  |  |                        |  |                |  |
  |  +------------------------+  +----------------+  |
  |  [=========滑块轨道=======O=]  [辅助线]         |
  |  0   0.5   1   1.5   2                           |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：单一状态变量`t`（0~2），由滑块input事件驱动。所有视觉元素（三角形位置、重叠多边形、曲线路径、当前点、文本内容）均根据`t`实时计算重绘。
  2. 重叠多边形计算（核心算法）：
     ```
     设 scale=120, h=scale*√3/2≈104
     A=(60+scale*t, 300), B=(180+scale*t, 300), C=(120+scale*t, 300-h)
     if t≤0.5:   顶点=[(180,300), B, (180, 300-scale*√3*t)]
     if 0.5<t≤1: 顶点=[(180,300), B, C, (180, 300-scale*√3*(1-t))]
     if 1<t≤1.5: 顶点=[A, (300,300), (300, 300-scale*√3*(t-1)), C]
     if 1.5<t≤2: 顶点=[A, (300,300), (300, 300-scale*√3*(2-t))]
     ```
     将顶点数组直接写入SVG polygon的points属性。
  3. 面积函数（理论值）：
     ```javascript
     function S(t) {
       const s3 = Math.sqrt(3);
       if (t <= 0.5) return (s3/2)*t*t;
       else if (t <= 1) return s3/4 - (s3/2)*(1-t)*(1-t);
       else if (t <= 1.5) return s3/4 - (s3/2)*(t-1)*(t-1);
       else return (s3/2)*(2-t)*(2-t);
     }
     ```
  4. 坐标转换：
     - 几何区平移：三角形水平位移 = scale * t（120t 像素）。
     - 函数区横轴：tx = 460 + 150 * t。
     - 函数区纵轴：sy = 340 - 480 * S(t)。
  5. 曲线轨迹绘制：预先计算400个采样点（步长0.005），生成完整path的d属性。为支持"实时延长"效果，使用两个方案之一：
     - 方案A（推荐）：每次更新时重新生成从t=0到当前t的path d字符串（点数≤200，性能可接受）。
     - 方案B：完整绘制整条曲线但用clipPath或stroke-dasharray控制可见长度。
     本计划采用方案A，代码简洁且精确。
  6. 吸附提示：监听滑块input事件，当|t-0.5|<0.06或|t-1|<0.06或|t-1.5|<0.06时，给对应刻度线元素添加高亮class（改变stroke和stroke-width）。
  7. 信息面板更新：根据t所在区间，切换阶段文本、公式文本（使用Unicode字符如"√3"或SVG text直接写入），面积数值保留3位小数。
  8. 辅助线开关：用一个布尔变量控制，点击按钮时切换。为真时，在几何区绘制从重叠区域最上方顶点向底边Y=300的垂线（竖直线段），并在函数区显示投影虚线（可始终显示，或也受开关控制）。
  9. 动画曲线：滑块拖动时无需额外动画库，直接根据input值同步更新。若需自动演示功能，可用requestAnimationFrame驱动滑块值从0到2，但本计划以手动拖拽为主。
- ID命名规范：所有交互元素ID必须以`scene1-`为前缀。例如：
  - `scene1-square`（正方形）
  - `scene1-triangle`（三角形）
  - `scene1-overlap`（重叠区域）
  - `scene1-axis-t`（横轴）
  - `scene1-axis-s`（纵轴）
  - `scene1-curve`（轨迹曲线）
  - `scene1-current-point`（当前点）
  - `scene1-proj-x`（投影虚线X）
  - `scene1-proj-y`（投影虚线Y）
  - `scene1-info-panel`（信息面板）
  - `scene1-info-stage`（阶段文本）
  - `scene1-info-formula`（公式文本）
  - `scene1-info-value`（面积数值）
  - `scene1-slider`（滑块input）
  - `scene1-slider-thumb`（滑块按钮SVG圆）
  - `scene1-tick-0`, `scene1-tick-05`, `scene1-tick-1`, `scene1-tick-15`, `scene1-tick-2`（吸附刻度线）
  - `scene1-aux-btn`（辅助线按钮）
  - `scene1-aux-line`（几何辅助线）
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })()` 中，避免全局变量污染，确保多场景合并时互不干扰。
- CSS样式：所有选择器以`.scene1-`为前缀，与ID规范保持一致。
