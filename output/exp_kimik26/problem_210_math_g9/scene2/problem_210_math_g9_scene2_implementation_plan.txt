[图示主题与整合说明]
- 本图示主题：正方形与正三角形重合面积 S(t) 的函数图象选择题——四选项对比排除
- 整合的步骤/概念：将选项 A（线性三角）、B（光滑曲线）、C（梯形平台）、D（尖峰曲线）以 2×2 网格并列展示；通过 4 步分步导航，依次揭示 A/C/D 的错误本质并确认 B 的正确特征，帮助教师在课堂上带领学生完成“逐一排除→确认答案”的完整思维过程。
- 教学价值：教师可控制每步节奏，先让学生观察猜测，再逐步呈现排除理由，强化“面积非线性”“无平台期”“起点切线水平”“顶部圆滑”等关键几何与微积分直觉。

[分步序列]
- 步骤 0（初始状态）：四个选项 2×2 网格全部显示，所有坐标轴、曲线、标签可见。无任何高亮、遮罩或批注。教师可让学生观察并猜测。
- 步骤 1（排除 A）：
  → A 外框叠加淡红色遮罩。
  → A 图内部显示对比小插图（左上 inset）：左侧画实际重叠小三角形（t=0.3 时的真实几何），右侧画红色虚线三角形（若按 A 的线性规律应有的面积）。
  → A 图内部右侧显示红色文字“线性增长错误”。
  → 教学点：进入阶段重叠面积是二次增长（相似三角形面积比），绝非线性。
- 步骤 2（排除 C）：
  → C 外框叠加淡红色遮罩。
  → C 图中央画红色叉号（×）。
  → C 图内部右上显示红色文字“不存在平台期”。
  → 教学点：三角形与正方形底边等长，完全重合仅发生在 t=1 一个瞬间，不可能出现持续最大面积的平台。
- 步骤 3（排除 D）：
  → D 外框叠加淡红色遮罩。
  → D 图原点右上方显示红色文字“S'(0)≠0”。
  → D 图起点画红色斜切线 (460,385)-(510,320)，示意原点处切线明显不水平。
  → D 图峰值处画红色尖角（两红线交汇于顶部），示意顶部尖锐。
  → D 图峰值右侧显示红色文字“顶部尖锐”。
  → 教学点：实际 S'(0)=0（刚开始进入时变化率为零）；t=1 时导数由正变负，顶部应圆滑（导数为零），而非尖锐折点。
- 步骤 4（确认 B）：
  → B 外框添加蓝色高亮边框（3px）。
  → B 图原有黑色曲线之上叠加一条稍粗的 #2e7d32 曲线（或直接将原曲线变绿），表示验证吻合。
  → B 图右上方画绿色对勾（√）。
  → B 图上方显示绿色文字“光滑 · 对称 · 水平相切”。
  → B 图峰值右侧显示绿色文字“顶部圆滑”。
  → 教学点：B 满足所有几何特征——两端与横轴水平相切、全程光滑无折点、关于 t=1 对称、最大值点导数为零。
- 教师可随时点击「上一步」回退到任意步骤复习。

[交互方案]
- 交互类型：分步按钮导航（◀ 上一步 / 下一步 ▶）。
- 控件说明：
  1. 「◀ 上一步」按钮：位于 (290,452)，尺寸 100×36。点击后 currentStep 减 1（下限 0），隐藏当前步新增元素，回退到上一步状态。
  2. 「下一步 ▶」按钮：位于 (410,452)，尺寸 100×36。点击后 currentStep 加 1（上限 4），显示下一步新增元素。
  3. 步骤指示器：位于 (400,488)，显示“步骤 k/4”，帮助教师掌握节奏。
- 教师操作流程：
  1. 教师展示步骤 0，让学生观察四个选项并思考。
  2. 点击「下一步」进入步骤 1，讲解 A 的错误本质（非线性），配合小插图对比。
  3. 继续点击「下一步」依次排除 C（无平台）、D（起点斜率与尖顶）。
  4. 最后一步确认 B 的正确特征，可回退复习任意步骤。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript。理由：本场景以静态几何图形和简单的显示/隐藏状态切换为主，无需复杂数学计算或 3D，原生 SVG 性能最佳且可控性最强。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图（ASCII）：
  ```
  0    100  200  300  400  500  600  700  800
  +----+----+----+----+----+----+----+----+
  | [========A========] [========B========] | 20
  |   S↑  线性三角      S↑  光滑曲线        |
  |    |                |                   |
  |    +----t           +----t              | 190
  | [========C========] [========D========] | 220
  |   S↑  梯形平台      S↑  尖峰曲线        |
  |    |                |                   |
  |    +----t           +----t              | 390
  |                                       |
  |      [◀ 上一步] [下一步 ▶]             | 452
  |            步骤 1/4                    | 488
  +----+----+----+----+----+----+----+----+
  500
  ```
- 关键实现要点：
  1. 状态机：用变量 `let currentStep = 0;` 记录当前步骤。每步切换时，先隐藏所有“步骤专属”元素（统一加 class `step-only` 并按 `data-step` 属性匹配），再显示目标步元素。
  2. 元素显隐：利用 SVG 的 `display: none / inline` 或包裹在 `<g>` 中用 `classList.toggle('hidden')` 控制。避免频繁重绘，仅切换容器组的显隐。
  3. 遮罩与边框：排除遮罩用 `<rect>` 填充半透明白+红；B 的蓝色高亮边框用 `<rect>` fill=none，注意向外扩 3px（x=417,y=17,w=356,h=176）避免压边。
  4. 对勾与叉号：用 `<path>` 或 `<line>` 绘制，stroke-linecap=round 使端点圆润。
  5. 小插图：作为独立 `<g>` 嵌套在 A 坐标系内，步骤 1 时显示。内部用 `<polygon>` 画两个微型三角形，右侧三角形设置 stroke-dasharray="4,2"、stroke=#c62828、fill=none。
  6. 动画曲线（可选）：若需步骤 4 绿色曲线“描绘”效果，可用 stroke-dasharray + stroke-dashoffset CSS transition，时长 600ms，增强确认感。
  7. 按钮边界处理：上一步在 step=0 时禁用（opacity 0.4，pointer-events none）；下一步在 step=4 时禁用。
- ID 命名规范：所有交互元素 ID 必须以 `scene2-` 为前缀。示例：
  - `scene2-btn-prev`、`scene2-btn-next`、`scene2-step-indicator`
  - `scene2-graph-A`、`scene2-graph-B`、`scene2-graph-C`、`scene2-graph-D`
  - `scene2-mask-A`、`scene2-mask-C`、`scene2-mask-D`
  - `scene2-inset-A`、`scene2-cross-C`、`scene2-tangent-D`、`scene2-border-B`
  - `scene2-label-linear`、`scene2-label-platform`、`scene2-label-sharp`、`scene2-label-correct`
  - JS 中严格使用 `document.getElementById('scene2-xxx')` 获取，禁止 querySelectorAll 配合全局 class。
- IIFE 隔离：所有 JavaScript 包在 `(function() { ... })();` 中，避免多场景合并时变量污染。
