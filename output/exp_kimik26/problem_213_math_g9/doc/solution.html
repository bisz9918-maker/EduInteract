场景导航：Scene 1

题目原文

如图，自行车的链条每节长为2.5cm，每两节链条相连接部分重叠的圆的直径为0.8cm。如果某种型号的自行车链条共有100节，则这根链条没有安装时的总长度为（ ）

A．250cm　B．174.5cm　C．170.8cm　D．172cm

题目分析

本题是一道典型的"图形规律"应用题，核心在于发现"链条节数"与"重叠处数"之间的数量关系。学生最常见的错误是直接用 $100 \times 2.5 = 250\,\text{cm}$ 计算而忽略重叠部分，从而误选A。讲解时应引导学生从1节、2节、3节的具体情形入手，在视觉上建立"重叠处数 = 节数 $-$ 1"的直观认知，再归纳出一般公式并代入求解。

整体讲解思路

  1. 观察单节结构，明确已知条件（每节2.5cm，重叠圆直径0.8cm）
  2. 对比1节与2节，理解"重叠0.8cm"的实际含义
  3. 用3节链条验证规律的正确性
  4. 推广到 $n$ 节，建立总长度公式
  5. 代入 $n = 100$，求得结果并对应选项

图示规划说明

使用一个分步导航图示，从具体到抽象地展示链条结构的规律。前3步分别呈现1节、2节、3节的实物化示意图，让学生通过图形直接数出重叠处数；后2步过渡到抽象示意图和代数公式，完成从直观到抽象的认知跨越。

步骤 1/5

本图示的教学说明与讲解要点

步骤0：明确已知条件

引导学生观察1节链条的示意图，确认每节长度为 $2.5\,\text{cm}$，重叠圆的直径为 $0.8\,\text{cm}$。强调"重叠"只发生在相邻两节之间，且本题链条是"没有安装时"的状态，即首尾不闭合。

步骤1：分析2节链条（关键步骤）

这是理解整道题的核心。2节链条共有3个圆，中间1个圆为两节共享，即重叠部分。

  • 如果不重叠，总长应为 $2.5 \times 2 = 5\,\text{cm}$
  • 实际重叠了 $0.8\,\text{cm}$，所以实际总长为 $5 - 0.8 = 4.2\,\text{cm}$
  • 也可以理解为：第1节长 $2.5\,\text{cm}$，第2节只"新增"了 $2.5 - 0.8 = 1.7\,\text{cm}$

建议教师在此停顿，提问学生："为什么不是 $2.5 \times 2$？重叠部分在哪里？"让学生用手指或鼠标指出重叠的圆。

步骤2：验证3节链条

3节链条有4个圆，2处重叠。

  • 用叠加思路：$2.5 \times 3 - 0.8 \times 2 = 7.5 - 1.6 = 5.9\,\text{cm}$
  • 用递推思路：$4.2 + 1.7 = 5.9\,\text{cm}$

两种算法结果一致，说明规律可靠。此时可引导学生发现：每增加1节，总长度就增加 $1.7\,\text{cm}$。

步骤3：归纳通项公式

对于 $n$ 节链条：

  • 重叠处数为 $(n-1)$
  • 总长度公式（叠加式）：$L = 2.5n - 0.8(n-1)$
  • 化简后（递推式）：$L = 1.7n + 0.8$

两种形式都要向学生说明：前者体现"先全部相加，再减去重叠"的直观思路；后者体现"首项 + 公差"的等差数列思路（首项2.5，公差1.7）。可联系等差数列通项公式 $a_n = a_1 + (n-1)d$ 进行知识迁移。

步骤4：代入计算

当 $n = 100$ 时：
$$L = 2.5 \times 100 - 0.8 \times 99 = 250 - 79.2 = 170.8\,\text{cm}$$
或
$$L = 1.7 \times 100 + 0.8 = 170 + 0.8 = 170.8\,\text{cm}$$

答案为 C．170.8cm。

课堂建议

  1. 易错点提醒：学生最容易误选A（250cm），原因是忽略重叠。可通过图示中的红色高亮反复强调"有99处重叠，要减去99个0.8"。
  2. 一题多解：鼓励学生用两种公式分别计算，验证结果一致性，培养运算检验习惯。
  3. 变式拓展：可追问"如果链条首尾相接（闭合）安装，100节的总长度是多少？"（此时有100处重叠，长度为 $2.5 \times 100 - 0.8 \times 100 = 170\,\text{cm}$），但需注意本题明确是"没有安装时"的开链状态。
  4. 数形结合：提醒学生注意"节数"与"圆数"的关系——$n$ 节链条共有 $(n+1)$ 个圆，但计算长度时以"节数 $ imes$ 单节长 $-$ 重叠处数 $ imes$ 重叠长"最为直接，避免在圆的数量上纠缠。
