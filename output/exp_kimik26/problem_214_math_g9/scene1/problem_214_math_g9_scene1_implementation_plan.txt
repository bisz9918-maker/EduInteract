[图示主题与整合说明]
- 本图示主题：垂直平分线性质与∠EAF角度推导
- 整合的步骤/概念：1) 原题完整图形展示；2) AB垂直平分线性质（EA=EB，∠EAB=∠B）；3) AC垂直平分线性质（FA=FC，∠FAC=∠C）；4) 三角形内角和与∠EAF的角度计算（110°−70°=40°）

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本场景为纯2D几何图形，无复杂函数绘图或3D需求，SVG的path/line/circle/text足以精确控制角弧、扇形与标签，且无需引入外部库，减少加载开销。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图（ASCII）：
  ```
  0    100  200  300  400  500  600  700  800
  50   +----+----+----+----+----+----+----+----+
       |         A(400,170)                    |
  100  |        /\                             |
       |       /  \                            |
  170  |      /    \      G(550,275)           |
       |   H(250,275)  /  *                    |
  250  |    *       /  /                       |
       |     \     /  /                        |
  300  |      \   /  /                         |
       |       \ /  /                          |
  380  |--C--F---E---B--  BC水平               |
       | (100)(324)(476)(700)                  |
  400  |    标签E,F在下方                      |
       |                                       |
  430  |      [推导公式文本区]                 |
       |                                       |

  465  |   [◀上一步] 步骤k/4 [下一步▶]        |
  ```

- 关键实现要点：
  1. 状态机设计：使用变量 `let currentStep = 0;`（范围0~4）。每步用一个配置对象数组 `stepsConfig` 描述该步应显示的元素ID列表、应添加的class、应设置的文本内容。
  2. 元素分组与显隐：所有按步骤显示的元素（角弧、直角标记、等长标记、填充、公式）初始 `visibility: hidden` 或 `opacity: 0`。切换步骤时，先重置所有动态元素为隐藏/默认样式，再根据当前步骤配置激活对应元素。
  3. 角弧与扇形绘制：使用SVG `<path>` 的 `A` 弧命令。例如∠BAC弧：以A(400,170)为圆心，R=40，起点为AC方向（角度145°），终点为AB方向（角度35°），取大弧（因为>180°？不，110°<180°，取小弧）。注意SVG坐标系y向下，角度计算使用 `Math.atan2(dy, dx)`。
  4. 扇形填充（∠EAF）：使用path画扇形——从圆心A出发，画弧到起点，再画弧到终点，闭合回圆心。填充色 `#c62828`，`fill-opacity: 0.2`。
  5. 等长线段标记（tick）：计算线段中点及垂直方向单位向量，绘制长8px的垂直短线。例如EA中点(438,275)，EA方向单位向量(0.341,0.940)，垂直方向(-0.940,0.341)，从中点向两侧各延伸4px。
  6. 直角标记：在垂足处（G或H），沿两边各取10px，构造小正方形路径。例如G处：沿GA方向（单位向量）取10px得p1，沿GE方向取10px得p2，再计算p3=p1+GE方向*10，画折线p1-G-p2和p1-p3-p2。
  7. 颜色切换：通过切换CSS class实现。例如 `.scene1-highlight-blue { stroke: #1565c0; stroke-width: 2.5; }`，`.scene1-highlight-red { fill: #c62828; fill-opacity: 0.2; }`。
  8. 公式与选项更新：每步直接修改 `scene1-text-formula` 的 `textContent`，步骤4时额外设置 `scene1-options` 的HTML内容，给B选项包裹 `<tspan style="fill:#c62828;font-weight:bold;">`。
  9. 按钮状态：步骤0时禁用「上一步」，步骤4时禁用「下一步」。
  10. 动画曲线：元素显隐使用CSS `transition: opacity 0.3s ease`，避免生硬切换。
- ID命名规范：所有交互元素ID必须以 `scene1-` 为前缀。例如：`scene1-line-ab`、`scene1-perp-ge`、`scene1-arc-bac`、`scene1-fill-eab`、`scene1-text-formula`、`scene1-btn-prev`、`scene1-btn-next`。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免全局变量污染，确保多场景合并时互不干扰。
