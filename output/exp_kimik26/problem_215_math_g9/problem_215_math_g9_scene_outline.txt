    **题目原文**

    如图所示，直线 $a$ 经过正方形 $ABCD$ 的顶点 $A$，分别过顶点 $D$，$B$ 作 $DE \bot a$ 于点 $E$，$BF \bot a$ 于点 $F$，若 $DE=4$，$BF=3$，则 $EF$ 的长为（   ）

    A．1  B．5  C．7  D．12

    **题目分析**

    本题是经典的"一线三垂直"（K 型图）模型应用。核心思路是通过角度推导证明 $\triangle ADE \cong \triangle BAF$，从而将求 $EF$ 转化为求两条已知垂线段长度之和。

    **整体讲解思路**

    1. 先引导学生观察图形结构：正方形、过顶点 $A$ 的直线、两条垂线构成的两个直角三角形。
    2. 提问：$EF$ 在直线 $a$ 上由哪几段组成？（$EF = EA + AF$）
    3. 关键突破口：寻找 $EA$、$AF$ 与已知量 $DE$、$BF$ 的关系。
    4. 通过"同角的余角相等"证明 $\angle ADE = \angle BAF$，进而证明三角形全等。
    5. 利用全等三角形对应边相等，得到 $AE = BF = 3$，$AF = DE = 4$。
    6. 计算 $EF = 3 + 4 = 7$，答案选 C。

    **图示规划说明**

    本题几何结构单一，所有教学步骤围绕同一幅图形展开。采用一个分步导航图示，从原题条件逐步推进到全等证明与结论，避免相似图形的重复拆分。教师在课堂上可配合底部按钮逐步揭示推导过程，也可回退到任意步骤进行复习强调。

    **本图示的教学说明**

    **如何引导学生观察**

    1. **步骤0（原题展示）**：让学生先独立读图，说出已知条件。教师提问："图中有几个直角三角形？它们的位置关系是什么？"引导学生发现△ADE和△BAF分别位于直线a的两侧。

    2. **步骤1（直角高亮）**：强调正方形的内角∠DAB = 90°，以及两个垂足形成的直角∠AED = ∠BFA = 90°。这是后续证明全等的第一个条件（一组角相等）。

    3. **步骤2（角度推导）**：这是本题的难点和关键。教师可板书推导：
       - 因为 $\angle DAB = 90°$，所以 $\angle DAE + \angle BAF = 90°$
       - 因为 $DE \bot a$，所以 $\angle AED = 90°$，故 $\angle DAE + \angle ADE = 90°$
       - 由同角的余角相等，得 $\angle ADE = \angle BAF$
       
       在图示中，用不同颜色标注这三个角，让学生直观看到"同角"（∠DAE）和"两个余角"（∠ADE、∠BAF）的关系。

    4. **步骤3（全等证明）**：当学生发现两角相等后，引导他们检查全等条件：
       - $\angle AED = \angle BFA = 90°$（已证）
       - $\angle ADE = \angle BAF$（已证）
       - $AD = BA$（正方形边长相等）
       
       因此 $\triangle ADE \cong \triangle BAF$（AAS）。图示中用蓝红两色区分两个三角形，并用虚线连接对应顶点，帮助学生建立对应关系。

    5. **步骤4（计算结论）**：由全等得对应边相等：$AE = BF = 3$，$AF = DE = 4$。因为 $E$、$A$、$F$ 三点共线且 $A$ 在 $E$、$F$ 之间，所以 $EF = AE + AF = 3 + 4 = 7$。

    **课堂讲解建议**

    - 如果时间充裕，可在步骤0让学生先猜测EF的长度（选项中有1、5、7、12），激发探究兴趣。
    - 证明完成后，可引导学生总结"一线三垂直"模型的通用结论：当正方形一个顶点在直线上，对边两个顶点向直线作垂线时，外侧两垂足之间的距离等于两条垂线段长度之和。
    - 可进一步提问：如果直线a不经过顶点A，而是经过其他位置，结论还成立吗？（为后续拓展埋下伏笔）
