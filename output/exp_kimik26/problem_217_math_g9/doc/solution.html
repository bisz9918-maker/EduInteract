题目分析

本题以二次函数图像为载体，考查抛物线与坐标轴交点、顶点坐标、线段长度、角度判断、区间最值及单调性等多个核心知识点。解题的关键在于先通过代数计算确定图像上的关键点的坐标，再结合图像性质逐一验证四个结论。

整体讲解思路

  1. 先引导学生将函数解析式因式分解，快速求出与$x$轴交点$A,B$的坐标。
  2. 令$x=0$求出与$y$轴交点$C$的坐标。
  3. 利用对称轴公式求出顶点坐标。
  4. 在坐标系中直观验证四个结论：$AB$长度、$\angle ABC$角度、区间$01$时的单调性。
  5. 总结：四个结论全部正确，答案为D。

讲解要点

  1. 求交点与顶点：强调将函数式$y=x^2-2x-3$因式分解为$(x-3)(x+1)$，快速得到$x$轴交点$A(-1,0)$、$B(3,0)$。令$x=0$得$C(0,-3)$。顶点横坐标用公式$x=-\frac{b}{2a}=1$，代入得纵坐标$y=-4$。
  2. 验证AB长度：在$x$轴上直接计算$3-(-1)=4$，培养学生数形结合思想。
  3. 验证角度：引导学生观察$\triangle BOC$，发现$OB=3$、$OC=3$，这是解题关键。利用等腰直角三角形性质直接得到$\angle OBC=45^{\circ}$，避免使用复杂斜率公式。

完整解答

由$y=x^2-2x-3=(x-3)(x+1)$，得$A(-1,0)$、$B(3,0)$。
当$x=0$时，$y=-3$，得$C(0,-3)$。
顶点横坐标$x=-\frac{-2}{2}=1$，纵坐标$y=1-2-3=-4$。

  1. $AB=3-(-1)=4$，故①正确。
  2. 在$\triangle BOC$中，$OB=OC=3$，$\angle BOC=90^{\circ}$，故$\angle OBC=45^{\circ}$，即$\angle ABC=45^{\circ}$，故②正确。

  4. 抛物线开口向上，对称轴为直线$x=1$，当$x>1$时，$y$随$x$的增大而增大，故④正确。
