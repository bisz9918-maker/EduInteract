[分步序列]
- 步骤0（初始装置）：显示烧杯、液面、Zn、Cu、稀硫酸标签、导线、滤纸、a、b石墨棒、饱和食盐水标签。无额外标注，让学生自主识别装置组成。步骤指示器显示"步骤 1 / 5"。
- 步骤1（原电池判断）：左侧出现绿色半透明高亮覆盖原电池区域；显示"原电池"标签在烧杯上方；Zn左侧显示红色"负极(−)"和"氧化"；Cu右侧显示绿色"正极(+)"和"还原"。教师可讲解活泼金属作负极发生氧化。
- 步骤2（电解池判断）：右侧出现蓝色半透明高亮覆盖滤纸区域；显示"电解池"标签在滤纸上方；a棒左上方显示红色"阳极"（与Cu正极相连）；b棒右上方显示蓝色"阴极"（与Zn负极相连）。教师可讲解电解池阴阳极由外接电源正负极决定。
- 步骤3（电子流向）：在Zn-b导线上方（y=48）出现红色粗箭头从左指向右，标注"e⁻"；在Cu-a导线下方（y=95）出现红色粗箭头从右指向左，标注"e⁻"。教师可强调电子只在外电路导线中流动，从负极→阴极，从阳极→正极。
- 步骤4（离子移动）：原电池烧杯内出现蓝色虚线箭头从左侧指向Cu极，标注"H⁺"；滤纸内出现Cl⁻指向a极的蓝色虚线箭头、Na⁺指向b极的蓝色虚线箭头、H⁺指向b极的蓝色虚线箭头，分别标注。教师可讲解内电路靠离子移动导电，阴离子→阳极，阳离子→阴极。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「上一步」按钮：位于控件栏x=310,y=452，宽80×高32。点击回退到上一分步，步骤0时禁用（opacity=0.4）。
  2. 「下一步」按钮：位于控件栏x=410,y=452，宽80×高32。点击前进到下一分步，步骤4时禁用（opacity=0.4）。
  3. 步骤指示器：位于控件栏x=400,y=490，显示"步骤 X / 5"。
- 教师操作流程：
  1. 教师展示步骤0，让学生观察并提问"这是什么装置？"
  2. 点击「下一步」进入步骤1，揭示左侧为原电池及正负极，讲解Zn比Cu活泼故为负极。
  3. 点击「下一步」进入步骤2，揭示右侧为电解池及阴阳极，强调阳极连正极、阴极连负极。
  4. 点击「下一步」进入步骤3，展示电子流向，纠正学生"电子走溶液"的常见错误。
  5. 点击「下一步」进入步骤4，展示离子移动，完善内外电路导电机制。
  6. 可随时点击「上一步」回退到任意步骤复习或补充提问。

[技术实现]
- JS库选择：原生SVG（DOM操作）。理由：本场景为静态几何图形组合，无复杂动画、无函数绘图、无3D，原生SVG即可满足；通过控制g元素的display属性实现分步切换，性能最优。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  y=0    +--------------------------------------------------------+
         |                                                        |
  y=50   |         ┌────上导线(y=55)────┐                        |
         |         │                    │                        |
  y=100  |    锌   铜              a     b                       |
         |    │    │              │     │                        |
  y=150  |    │    │   [原电池]   │     │   [电解池]             |
         |    │    │              │     │                        |
  y=200  |   ═════液面═══════════════   │                        |
         |    │    │  ~~~~~~~~~~~~~     │                        |
  y=250  |    │    │  ~ 滤纸区域 ~      │                        |
         |    │    │  ~           ~     │                        |
  y=300  |    │    │  ~           ~     │                        |
         |    │    │  ~~~~~~~~~~~~~     │                        |
  y=350  |   [稀硫酸]    [饱和食盐水]   │                        |
         |    │    │                    │                        |
  y=400  |   └────┘                    └────┘                   |
         |                                                        |
  y=440  |              [上一步] [下一步]                        |
         |                 步骤 X / 5                             |
  y=500  +--------------------------------------------------------+
         x=0                                               x=800
  ```
- 关键实现要点：
  1. 状态机设计：变量 `currentStep` 取值为 0~4。初始化 `currentStep = 0`，仅显示 step0-group。
  2. 分组管理：每个步骤的所有新增元素包裹在独立的 `<g id="scene1-step{k}-group">` 中（k=1~4），初始 `display="none"`。步骤0的基础元素放在 `scene1-base-group` 中始终显示。
  3. 切换逻辑：`goToStep(n)` 函数先隐藏所有 step-group，再显示 step0~step-n 的 group（或仅显示 step-n-group 覆盖在 base 上）。推荐方案：仅 step1~4 用独立 group 控制显示/隐藏，base 始终显示。
  4. 按钮状态：`updateControls()` 在每次切换后更新按钮 disabled 状态和步骤指示器文字。
  5. 箭头 marker 定义：在 `<defs>` 中定义红色箭头标 `scene1-arrow-red` 和蓝色箭头标 `scene1-arrow-blue`，供电子/离子箭头复用。
  6. 动画：步骤切换时新增 group 做 150ms 的 opacity 0→1 淡入（CSS transition 或 requestAnimationFrame），增强视觉连贯性。
  7. 事件绑定：按钮绑定 `click` 事件，调用 `prevStep()` / `nextStep()`。
- ID命名规范：所有元素 ID 必须以 `scene1-` 为前缀。例如：
  - 基础元素：`scene1-beaker`、`scene1-zn-rod`、`scene1-cu-rod`、`scene1-filtersheet`、`scene1-graphite-a`、`scene1-graphite-b`、`scene1-wire-zn-b`、`scene1-wire-cu-a`
  - 标签：`scene1-label-zn`、`scene1-label-cu`、`scene1-label-dilute-acid`、`scene1-label-a`、`scene1-label-b`、`scene1-label-saturated-nacl`
  - 步骤组：`scene1-step1-group`、`scene1-step2-group`、`scene1-step3-group`、`scene1-step4-group`
  - 按钮：`scene1-btn-prev`、`scene1-btn-next`、`scene1-step-indicator`
  - marker：`scene1-arrow-red`、`scene1-arrow-blue`
  - JS中严格使用 `document.getElementById`，禁止 `querySelectorAll` 配合全局 class。
- IIFE隔离：所有 JavaScript 代码包裹在 `(function() { ... })();` 中，避免多场景合并时变量污染。
