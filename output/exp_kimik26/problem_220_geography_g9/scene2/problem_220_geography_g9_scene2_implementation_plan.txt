[图示主题与整合说明]
- 本图示主题：北半球三圈环流中的中纬环流与极锋结构
- 整合的步骤/概念：
  1) 建立全球空间框架——北半球三圈环流侧视图（0°–90°N），用颜色区分低/中/高纬环流圈；
  2) 聚焦中纬环流段（30°N–60°N），与题目原图矩形环流结构精确对应（a左下、b右下、d左上、c右上）；
  3) 在b处（60°N/副极地低压带）展开极锋细节，展示暖湿气流与冷干气流相遇、暖空气爬升；
  4) 在a处（30°N/副热带高压带）阐明④下沉气流的动力成因，与热力原因做本质区分；
  5) 选项判定，高亮C为正确答案、D为错误选项。
- 教学价值：教师可先让学生观察全球三圈环流的空间格局，再"放大"进入中纬环流局部，逐层剖析极锋形成与动力下沉的机理，最后回归题目选项验证，形成"宏观→微观→解题"的完整教学链。

[分步序列]
- 初始状态（步骤0）：显示北半球三圈环流完整侧视图。地面线横贯底部，低纬（红）、中纬（绿粗框）、高纬（蓝）三个环流圈并排分布。赤道/30°N/60°N/90°N纬度标注在地面线下方，气压带名称在纬度下方，环流圈名称在上方。中纬环流圈以绿色粗边框高亮，暗示下一步聚焦目标。教师可在此建立全球空间框架。

- 步骤1：点击「下一步」→ 全局视图淡出，中纬环流聚焦视图淡入。显示与题目原图一致的矩形环流结构：左下a、右下b、左上d、右上c。地面线、高空线、左右垂直线构成环流框。四支箭头①②③④分别标注高空风、上升气流、地面风、下沉气流。30°N与60°N纬度线、副热带高压带与副极地低压带标签同步出现。教师可对照题目原图讲解中纬环流的基本结构。

- 步骤2：点击「下一步」→ 在b处（60°N/副极地低压带）展开极锋细节。新增红色暖湿气流箭头从西南方向汇入b，蓝色冷干气流箭头从东北方向（高纬）汇入b，两者在b处相遇。极锋锯齿线绘制在b处左上方，标注"极锋"。教师可讲解极锋的形成机制与冷暖平流。

- 步骤3：点击「下一步」→ 在a处（30°N/副热带高压带）左侧弹出说明文本框，用虚线箭头指向a点附近。文本框内说明④下沉气流是"动力原因"（高空空气堆积、密度增大下沉），并括号注明"非热力冷却下沉"，与热力原因做本质区分。教师可讲解副热带高压的动力成因，为判定选项D做铺垫。

- 步骤4：点击「下一步」→ 在图示右侧出现选项判定标记。绿色圆圈对勾标注"C 正确"，说明"b处冷暖气流相遇形成极锋"；红色圆圈叉号标注"D 错误"，说明"④为动力成因，非热力原因"。教师可据此总结题目正确答案为C，并回顾中纬环流的核心知识点。

[技术实现]
- JS库选择及原因：原生SVG + 原生JavaScript。本场景以几何图形、箭头、文本标签和简单状态切换为主，无需复杂数据绑定或3D渲染。原生SVG可精确控制每个元素的坐标、描边、填充和显隐，配合原生JS状态机即可实现分步导航，避免引入不必要的库体积。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------------+
  |                                                        |
  |   步骤0: 三圈环流全局视图 (0°-90°N)                     |
  |   [低纬环流]  [中纬环流-绿框]  [高纬环流]              |
  |   赤道  30°N  60°N  90°N                               |
  |                                                        |
  |   步骤1-4: 中纬环流聚焦视图                             |
  |        d ━━━━━━━━━━━━ c  ①                             |
  |        ┃              ┃                                |
  |       ④              ②                                |
  |        ┃              ┃                                |
  |        a ━━━━━━━━━━━━ b  ③                             |
  |   30°N 副热带高压    60°N 副极地低压                    |
  |                                                        |
  |   步骤2: 极锋在b处  步骤3: 文本框在左侧                 |
  |   步骤4: C/D判定在右侧                                  |
  |                                                        |
  |              [◀上一步] [下一步▶]                       |
  |                  步骤 X/4                              |
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1) 状态机设计：定义currentStep变量（0~4），每一步对应一个数据配置对象，包含该步应显示的SVG元素ID列表。切换步骤时，先隐藏所有元素，再显示当前步骤对应的元素。
  2) 显隐控制：为每个SVG元素或元素组设置CSS类（如.step0, .step1, .step2, .step3, .step4），通过classList.add/remove控制display/opacity。建议使用opacity过渡（transition: opacity 0.3s ease）实现淡入淡出效果。
  3) 坐标计算：所有几何坐标已在布局坐标表中精确给出，代码中直接使用这些常量。箭头使用SVG <marker>定义箭头头部，绑定到path的marker-end属性。
  4) 极锋锯齿线：使用SVG <path>的L和短偏移线段组合绘制锯齿效果，或简化为带三角齿的折线路径。
  5) 文本框：使用<rect>+<text>组合，text使用<tspan>分行，避免复杂排版。
  6) 事件绑定：上一步/下一步按钮绑定click事件，更新currentStep后调用renderStep()。在renderStep()中处理按钮禁用状态（步骤0禁用上一步，步骤4禁用下一步）。
  7) 容器结构：外层div相对定位，内部SVG 800×500，控件div绝对定位在底部（top:440px, left:0, width:800px），确保控件不占用SVG绘图空间。
- ID命名规范：所有SVG元素和交互元素ID必须以scene2-为前缀。例如：
  * 地面线：scene2-ground-line
  * 中纬环流圈：scene2-mid-latitude-cell
  * 点a：scene2-point-a
  * 箭头①：scene2-arrow-1
  * 极锋线：scene2-polar-front-line
  * 文本框：scene2-info-box
  * C标记：scene2-mark-c
  * D标记：scene2-mark-d
  * 上一步按钮：scene2-btn-prev
  * 下一步按钮：scene2-btn-next
  JS中严格使用document.getElementById('scene2-xxx')获取元素，禁止querySelectorAll配合全局class，避免多场景合并时跨场景污染。
- IIFE隔离：所有JavaScript代码包裹在 (function() { ... })() 中，变量不污染全局作用域。事件监听函数也定义在IIFE内部。
