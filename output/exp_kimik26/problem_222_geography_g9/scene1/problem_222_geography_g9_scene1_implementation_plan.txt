[图示主题与整合说明]
- 本图示主题：经纬网判读、方向判断与地理位置定位
- 整合的步骤/概念：
  1. 经纬网基础认知（经线/纬线、东西经/南北纬分布规律、本初子午线与赤道）
  2. ①②③④四点经纬度坐标的读取方法（追踪线辅助）
  3. ①点相对于③点的方向判断（南北→东西→综合西南方向，含劣弧定向原理）
  4. 新加坡(1°N, 104°E)在经纬网中的定位与最近点（②点）对比
- 教学价值：教师通过分步导航控制课堂节奏，从网格基础→单点定位→方向分解→综合结论→实际定位，形成完整思维链条；学生可清晰看到每一步的图形依据，避免一次性信息过载。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本场景以静态几何图形、线条、标签的分步显示/隐藏为主，无复杂函数绘图或3D需求，原生SVG性能最优且无需额外库加载。
- 画布尺寸：800×500 px（SVG viewBox="0 0 800 500"）。
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  | 150° 120° 90° ... 0° ... 120° 150°  (顶部经度标签) |
  | 40° ┌─────────────────────────────┐              |
  | 30° │  ④                     ③   │  (右侧标注区)  |
  | 20° │                             │  经线指示南北  |
  | 10° │                             │  纬线指示东西  |
  |  0° │  ①                     ②   │              |
  | 10° └─────────────────────────────┘              |
  |      (左侧纬度标签)                               |
  | 步骤说明文字区（居中，随步骤更新）                  |
  |        [◀ 上一步]  步骤 X/8  [下一步 ▶]          |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `let currentStep = 0;` 控制0~8共9个状态。每个状态对应一个 `updateScene(step)` 函数，内部通过 `setAttribute('display', 'none'/'block')` 或 classList 切换元素显隐。
  2. 元素分组：SVG中使用 `<g id="scene1-step1-group">` 等分组包裹每步特有的元素，切换时整组显示/隐藏，避免逐个操作DOM。
  3. 高亮实现：点的高亮通过切换 `class="default-point"` / `class="highlight-point"` 实现，CSS中定义 `.highlight-point { fill: #1565c0; r: 6; filter: url(#glow); }`。
  4. 线色切换（步骤1）：给所有经线统一class `scene1-meridian`，所有纬线统一class `scene1-parallel`，步骤1时通过JS批量修改stroke属性。
  5. 脉冲动画：新加坡星形使用CSS `@keyframes scene1-pulse { 0%,100%{transform:scale(1);} 50%{transform:scale(1.3);} }`，动画绑定class `scene1-pulsing`。
  6. 箭头绘制：使用SVG `<marker>` 定义 arrow-blue、arrow-red、arrow-green 三种箭头末端，绑定到对应线条的 `marker-end` 属性。
  7. 坐标卡片：使用 `<g>` 包含 `<rect>` 背景+ `<text>` 文字，初始 `display:none`，对应步骤时显示。
  8. 按钮禁用状态：步骤0时给"上一步"添加 `disabled` 属性并切换class为 `scene1-btn-disabled`；步骤8时"下一步"同理。
  9. 说明文字更新：使用 `<text id="scene1-instruction">` 或 `<div>` 叠在SVG上方，每步通过 `textContent` 更新内容。
- ID命名规范：所有交互元素ID必须以 `scene1-` 为前缀。例如：`scene1-grid-group`、`scene1-point-1`、`scene1-meridian-120w`、`scene1-step4-ns-line`、`scene1-btn-prev`、`scene1-btn-next`、`scene1-instruction`。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免全局变量污染，确保多场景合并时互不干扰。
