[图示主题与整合说明]
- 本图示主题：地球公转轨道与二分二至日
- 整合内容：公转方向、地轴倾斜方向不变、四位置（a冬至、b春分、c夏至、d秋分）的太阳直射点、昼夜半球分布、极昼极夜范围、节气名称、北半球季节、南北半球季节对比
- 教学价值：教师通过分步导航，按节气顺序逐一讲解地球在公转轨道不同位置时的太阳直射点、昼夜长短、极昼极夜及季节变化。可自由前进/回退，便于课堂提问与复习。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「◀ 上一步」按钮：位于画布底部(270,455)，宽90高28。点击后退一个步骤，到步骤0时禁用。
  2. 「下一步 ▶」按钮：位于画布底部(430,455)，宽90高28。点击前进一个步骤，到步骤5时禁用。
  3. 步骤指示器：位于两按钮之间下方(360,482)，显示"步骤 X/5"。
- 教师操作流程：
  1. 课堂开始时保持步骤0，让学生观察整体公转轨道与四位置分布。
  2. 点击「下一步」进入步骤1（冬至），讲解直射点、极昼极夜、昼夜长短。
  3. 继续点击「下一步」依次讲解春分、夏至、秋分，每步聚焦一个位置。
  4. 进入步骤5，总结季节更替规律与南北半球季节相反。
  5. 可随时点击「上一步」回退到任意位置复习对比。

[技术实现]
- JS库选择：原生SVG（所有元素为几何图形，SVG的circle/line/path/rect/text即可满足，无需引入外部库）
- 画布尺寸：800 × 500 px（SVG viewBox="0 0 800 500"）
- 布局草图：
  ```
  +--------------------------------------------------------+
  |  [图示区 800×500]                                       |
  |                                                         |
  |      b(春分)                                            |
  |       ↑                                                 |
  |   c ← 太阳 → a      | 信息面板(170×320)                 |
  |  (夏至)   (冬至)    |  标题+多行说明文字                 |
  |       ↓             |                                   |
  |      d(秋分)        |                                   |
  |                                                         |
  |              [◀ 上一步]  [下一步 ▶]                      |
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机：用变量 `let currentStep = 0;` 记录当前步骤（0~5）。
  2. 元素分组：为每个步骤需要显示/隐藏的元素设置class，如 `scene1-step1-only`、`scene1-step2-only`、`scene1-step5-only`。步骤0的基础元素始终显示。
  3. 高亮切换：用一个独立的 `<circle class="scene1-highlight-ring"/>` 元素，通过改变cx/cy来移动到当前高亮地球，步骤0和步骤5时隐藏。
  4. 渲染函数 `renderStep()`：根据currentStep，遍历所有step-only元素设置 `display = 'none'` 或 `display = 'block'`，更新高亮环位置，更新信息面板innerHTML，更新按钮disabled状态，更新步骤指示器文字。
  5. 信息面板：使用SVG `<foreignObject>` 嵌入HTML `<div>`，便于多行文字和简单样式（text-align:left, line-height:1.6）。
  6. 按钮事件：addEventListener('click') 修改currentStep并调用renderStep()。
  7. 动画：本场景以信息切换为主，无需复杂动画。极昼极夜填充和标签出现可使用CSS transition opacity 0.3s，增强视觉平滑度。
  8. 地球内部线条裁剪：为每个地球定义 `<clipPath id="scene1-clip-earth-{a,b,c,d}">`（对应圆），赤道/回归线/极圈放在 `<g clip-path="url(...)">` 内。
  9. 地轴倾斜：所有地球统一使用相同方向向量 u=(0.342,-0.940)（约20°右倾），确保四地球地轴严格平行，体现"地轴倾斜方向不变"的核心概念。
  10. 直射光线箭头：使用SVG `<marker>` 定义红色箭头，绑定到直射光线line的marker-end。

- ID命名规范：所有SVG元素及JS访问的DOM节点ID必须以 `scene1-` 为前缀。例如：
  - `scene1-sun`、`scene1-orbit`、`scene1-earth-a`、`scene1-ray-a`
  - `scene1-panel-title`、`scene1-panel-content`
  - `scene1-btn-prev`、`scene1-btn-next`、`scene1-step-indicator`
  - JS中严格使用 `document.getElementById('scene1-xxx')`，不使用querySelectorAll或全局class选择器。

- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免全局变量污染，确保多场景合并时互不干扰。
