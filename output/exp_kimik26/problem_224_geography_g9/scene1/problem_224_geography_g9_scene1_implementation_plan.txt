[图示主题与整合说明]
- 本图示主题：太阳光照示意图综合判读（夏至日侧视矩形投影）
- 整合的步骤/概念：地球自转方向与晨昏线判读 → 昼夜半球与极昼极夜划分 → 节气判断 → 太阳直射点定位 → 地方时标注与推导 → 北京时间计算 → 正午太阳高度与自转线速度比较
- 教学价值：教师通过分步导航控制信息呈现节奏，从基础识图逐步过渡到综合计算，适合课堂讲解与学生跟读

[分步序列]
- 步骤0（初始状态）：显示矩形经纬网、晨昏线EDF（黑色）、A/B/C/D/E/F六点及字母标签、顶部经度间隔标注、右侧纬度标注。无高亮、无填充、无推导信息。用于学生读题识图。
- 步骤1（晨昏线判读）：点击「下一步」→ ① 显示绿色自转箭头与"自西向东"标注；② ED线段加粗变蓝（3px，#1565c0），DF线段加粗变红（3px，#c62828）；③ 左上角弹出图例框"ED 晨线（蓝）/ DF 昏线（红）"。教师讲解：顺着自转方向，过ED由夜入昼为晨线，过DF由昼入夜为昏线。
- 步骤2（昼夜半球与极昼极夜）：点击「下一步」→ ① EDF左侧（西侧）填充夜半球斜线阴影（多边形顶点：(80,60)→D(377,60)→E(80,373)→(80,420)）；② 北极圈以北的昼半球区域填充淡黄（D→(600,60)→(600,107)→(332,107)→D），标注极昼；③ 南极圈以南整区域填充深蓝（(80,373)→(600,373)→(600,420)→(80,420)），标注极夜。教师讲解：切点E、F与极圈的关系。
- 步骤3（节气判断）：点击「下一步」→ ① 在图右侧弹出"夏至日（6月22日前后）"红色标签；② 北回归线（y=193）中段高亮红色。教师讲解：北极圈极昼→夏至→太阳直射北回归线。
- 步骤4（太阳直射点定位）：点击「下一步」→ ① 0°经线（x=377）高亮为红色虚线；② 在北回归线与45°E交点(451,193)绘制红色五角星；③ 五角星右侧标注"(45°E, 23°26′N)"。教师讲解：0°经线平分夜半球→夜半球中央经线→昼半球中央经线（45°E）为直射经线。
- 步骤5（地方时标注）：点击「下一步」→ ① 在各点旁依次弹出地方时标签：A(260,230)"A 6时"、B(395,230)"B 9时"、C(560,100)"C 18时"、D(400,75)"D 9时"、E(100,360)"E 21时"、F(560,360)"F 18时"；② B与D同标"9时"，教师可强调同经度地方时相等。教师讲解：晨线与赤道交点A为6时，向东15°/小时推算。
- 步骤6（北京时间计算）：点击「下一步」→ ① 高亮120°E经线（x=575，红色虚线，贯穿全图）；② 在赤道下方绘制从0°到120°E的水平箭头，标注"+8小时"；③ 在右侧弹出"北京时间 17时"。教师讲解：0°经线为9时，120°E在东八区，+8小时得17时。
- 步骤7（正午太阳高度与线速度）：点击「下一步」→ ① 右侧弹出公式面板；② 依次展示正午太阳高度公式及A/B/C/D四点计算结果，高亮A与B数值相同（橙色）；③ 展示线速度规律v∝cosφ，高亮A与B同处赤道、线速度相等（橙色）。教师讲解：公式代入与纬度对比。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「◀ 上一步」按钮：位于(320, 450)，宽80×高30，点击回退到上一状态，步骤0时禁用（透明度50%）。
  2. 「下一步 ▶」按钮：位于(420, 450)，宽80×高30，点击前进到下一状态，步骤7时变为「完成」或禁用。
  3. 步骤提示文字：位于(400, 490)，居中，显示当前步骤编号与标题（如"步骤 4/7：太阳直射点定位"）。
- 教师操作流程：
  1. 教师展示步骤0，让学生观察底图并读题；
  2. 点击「下一步」进入步骤1，讲解晨昏线判读；
  3. 依课堂节奏逐次点击「下一步」，每步聚焦一个知识点；
  4. 可随时点击「上一步」回退复习；
  5. 步骤7完成后，可快速回退到步骤0重新开始。

[技术实现]
- JS库选择：原生 SVG + 原生 JavaScript。理由：本场景以静态几何图形、路径填充和文本标签为主，无复杂函数绘图或3D需求，原生SVG性能最优且无需额外CDN依赖。
- 画布尺寸：800 × 500 px（固定），控件栏通过绝对定位叠加在SVG内部底部，不额外撑高容器。
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------------+
  |              太阳光照示意图 (400,25)                    |  标题区 y=0~55
  |  135°   45°   45°   90°                                |  顶部标注 y=52
  |  +-----------------------------+  90°                   |  
  |  |  D(北极)                    |  66.5°  C              |  主图区
  |  |    \                      /|  23.5°                 |  y=60~420
  |  |     \       B             /|  0°     A              |
  |  |      \     / \           / |  23.5°                 |
  |  |       \   /   \         /  |  66.5°  E         F    |
  |  |        \ /     \       /   |  90°                   |
  |  +-----------------------------+                       |
  |     [◀ 上一步]  [下一步 ▶]                             |  控件区 y=440~490
  |              步骤 2/7：划分昼夜半球                      |
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `let currentStep = 0;` 控制0~7共8个状态。每个状态对应一组SVG元素的 `display` 属性切换。定义 `const stepElements = { 1: ['scene1-step1-arrow', 'scene1-step1-legend', ...], ... }`，在状态切换时遍历显示/隐藏。
  2. 坐标计算：晨昏线ED、DF的交点与极圈交点已预先计算好（ED与66.5°N交于约(332,107)），直接硬编码在polygon的points属性中，避免运行时三角计算。
  3. 动画曲线：本场景以分步切换为主，无需复杂动画。元素出现/隐藏使用CSS `transition: opacity 0.3s ease`，通过切换class `visible` 实现淡入淡出，保持课堂讲解的流畅性。
  4. 事件绑定：上一步/下一步按钮绑定 `click` 事件，调用 `updateScene(step)` 函数。函数内先更新 `currentStep`，再遍历所有step相关元素设置 `style.opacity` 或 `classList.toggle('hidden')`，最后更新步骤提示文字与按钮禁用状态。
  5. 夜半球斜线填充：使用SVG `<pattern>` 定义45°斜线图案（patternUnits="userSpaceOnUse"，patternTransform="rotate(45)"），步骤2时将该pattern应用于夜半球polygon的fill属性。
  6. 五角星绘制：使用 `<polygon>` 定义标准五角星路径（中心(451,193)，外半径8px），步骤4时显示。
