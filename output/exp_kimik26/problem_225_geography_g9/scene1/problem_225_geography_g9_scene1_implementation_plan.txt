[图示主题与整合说明]
- 本图示主题：经纬网结构与地理坐标读取
- 整合的步骤/概念：经度递增规律与东西经判读、纬度递增规律与南北纬判读、A/B/C/D四点坐标定位、坐标汇总

[视觉元素清单]
- 经纬网网格：6条经线（x=140,236,332,428,524,620）+ 6条纬线（y=120,176,232,288,344,400），黑色0.8px实线，构成440×280网格区域
- 四个定位点：A(236,120)、B(620,232)、C(236,316)、D(620,400)，黑色实心圆r=4px
- 点标签：A/B/C/D黑色文字，始终显示，位于各点左上方或右上方（见坐标表）
- 经度标签：120°E/140°E/160°E（蓝色）、180°/160°W/140°W（红色），位于对应经线正上方y=95处
- 纬度标签：80°/60°/40°/20°（红色）、0°/20°S（绿色），位于对应纬线左侧x=110处
- 方向说明文字：步骤1顶部蓝色"→向东递增为东经"、红色"180°以东为西经"；步骤2左侧红色"向北递增↑北纬"、绿色"向南递增↓南纬"
- 180°警示框：红色边框矩形，框住180°标签，提示易错点
- 坐标标注框：白底黑框带浅阴影，内含"点(经度, 纬度)"文字，通过灰色虚线与对应点连接
- 汇总表格：5行3列表格（表头+4行数据），浅灰背景，位于画布右下角
- 高亮样式：经线高亮用蓝色#1565c0、2px；北纬纬线高亮用红色#c62828、2px；南纬/赤道高亮用绿色#2e7d32、2px；东经点外圈蓝色描边（r=6,stroke-width=2.5）；西经点外圈红色描边
- 配色沿用规格：背景#ffffff、主线#000000、蓝高亮#1565c0、红高亮#c62828、绿高亮#2e7d32、辅助线#888888

[分步序列]
- 初始状态（步骤0）：显示空白经纬网（6经6纬黑色细线）+ 四个黑色实心点 + 四点标签(A/B/C/D) + 步骤提示"经纬网结构 — 观察网格与点的分布"。无刻度标签、无方向说明、无坐标标注。教师引导学生观察网格结构和点的大致分布。
- 步骤1（点击下一步）：所有经线加粗变为蓝色（stroke=#1565c0, width=2px）；顶部弹出经度标签（东经蓝色、西经红色）；在网格上方显示蓝色文字"→向东递增为东经"和红色文字"180°以东为西经"；在180°标签周围绘制红色边框警示框。步骤提示变为"经度判读 — 向东递增为东经，180°以东为西经"。教师讲解经度判读规律，特别强调180°经线东侧为西经这一易错点。
- 步骤2（点击下一步）：经线恢复默认黑色细线，保留经度标签（可选淡显）；所有纬线加粗变色（北纬红色、赤道及南纬绿色）；左侧弹出纬度标签（北纬红色、赤道和南纬绿色）；在网格左侧显示红色"向北递增↑北纬"和绿色"向南递增↓南纬"；赤道线特别加粗为3px绿色。步骤提示变为"纬度判读 — 向北递增为北纬，向南递增为南纬"。教师讲解纬度判读规律。
- 步骤3（点击下一步）：网格恢复默认；高亮A点（外圈蓝色描边r=6+stroke-width=2.5）；高亮140°E经线和80°N纬线（蓝色2px）；从A点向右下方引出灰色虚线到标注框(300,140)；弹出A坐标标注框显示"A(140°E, 80°N)"。步骤提示变为"A点坐标 — 140°E, 80°N"。教师演示如何读取A点坐标。
- 步骤4（点击下一步）：恢复A点默认样式，移除A标注框和虚线；高亮B点（外圈红色描边）；高亮140°W经线和40°N纬线（红色2px）；从B点向左下方引出灰色虚线到标注框(460,245)；弹出B坐标标注框显示"B(140°W, 40°N)"。步骤提示变为"B点坐标 — 140°W, 40°N"。
- 步骤5（点击下一步）：恢复B点默认样式；高亮C点（外圈蓝色描边）；高亮140°E经线（蓝色2px）和10°N位置（在0°与20°N之间，y=316，红色2px）；从C点向右下方引出灰色虚线到标注框(260,350)；弹出C坐标标注框显示"C(140°E, 10°N)"。步骤提示变为"C点坐标 — 140°E, 10°N"。
- 步骤6（点击下一步）：恢复C点默认样式；高亮D点（外圈红色描边）；高亮140°W经线（红色2px）和20°S纬线（绿色2px）；从D点向左上方引出灰色虚线到标注框(460,355)；弹出D坐标标注框显示"D(140°W, 20°S)"。步骤提示变为"D点坐标 — 140°W, 20°S"。
- 步骤7（点击下一步/最终步骤）：四点同时保持高亮（A/C蓝色外圈、B/D红色外圈）；四个坐标标注框同时显示；在右下角(640,160)弹出汇总表格，表头"点/经度/纬度"，四行数据分别列出A-D的完整坐标。步骤提示变为"坐标汇总 — 四点完整坐标对照"。教师带领学生对照表格，快速回顾四点坐标。
（教师可随时点击「上一步」回退到任意步骤复习，步骤指示器实时显示当前步骤编号。）

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 步骤 X/7 / 下一步▶）
- 控件说明：
  1. 「上一步」按钮：位于画布底部x=250,y=455，宽80×高32，灰色背景，点击回退到上一状态
  2. 步骤指示器：位于画布底部x=360,y=455，宽80×高32，显示当前步骤编号（如"步骤 3/7"），黑色文字居中
  3. 「下一步」按钮：位于画布底部x=470,y=455，宽80×高32，蓝色背景(#1565c0)，白色文字，点击前进到下一状态
- 边界处理：步骤0时「上一步」禁用（opacity=0.4, pointer-events=none）；步骤7时「下一步」禁用
- 教师操作流程：
  1. 教师打开图示，展示步骤0空白网格，提问学生观察到了什么
  2. 点击「下一步」进入步骤1，讲解经度判读规律，用红色警示框强调180°经线东侧为西经
  3. 点击「下一步」进入步骤2，讲解纬度判读规律，强调赤道是南北纬分界线
  4. 依次点击「下一步」进入步骤3-6，逐点讲解坐标读取方法（先找经线、再找纬线、写出坐标）
  5. 进入步骤7，展示汇总表格，让学生对照记忆四点坐标
  6. 可随时点击「上一步」回退到任意步骤，针对学生疑问反复讲解

  |  南纬说明                    [汇总表格] 步骤7显示        |
  |                                                          |
  |  [◀上一步]  [步骤 X/7]  [下一步▶]                       |  <- y=455
  +--------------------------------------------------------+

- 关键实现要点：
  1. 状态机设计：用变量 `currentStep`（0~7）管理当前步骤，每步定义一个配置对象，包含该步应显示的元素ID列表、高亮元素ID列表、提示文字。点击按钮时调用 `renderStep(step)` 函数，根据配置批量切换class。
  2. 元素显隐：所有可选元素（标签、标注框、虚线、表格）初始设置 `display:none` 或 `opacity:0`，通过添加/移除 `scene1-active` 或 `scene1-highlight` class 控制显示。使用CSS transition实现淡入淡出（opacity 0.2s ease）。
  3. 坐标计算：网格区域x=140~620,y=120~400，经线间距96px，纬线间距56px。C点10°N位于0°(y=344)与20°N(y=288)之间，取y=316（约中间偏下，与题图一致）。
  4. 高亮实现：经线/纬线高亮通过切换stroke颜色和stroke-width实现；点高亮通过显示一个同心的稍大圆（预置在SVG中，默认hidden）作为外圈描边，避免动态修改r导致重排。
  5. 标注框：用`<g>`包裹`<rect>`（白底黑框）+`<text>`，通过transform定位到指定坐标，虚线用`<line stroke-dasharray="4,3">`实现。
  6. 汇总表格：用SVG `<rect>` + 多条 `<line>` 画表格框线，用 `<text>` 填充内容，步骤7时整体显示。
  7. 动画曲线：所有状态切换使用CSS `transition: opacity 0.25s ease, stroke-width 0.25s ease`，无复杂动画，保证教学演示的清晰和可控。
  8. 事件绑定：上一步/下一步按钮绑定click事件，更新currentStep后调用renderStep。按钮禁用状态通过toggleAttribute('disabled')和class切换实现。
- ID命名规范：所有SVG元素和控件ID必须以 `scene1-` 为前缀。例如：
  - 经线：`scene1-lon-120e`, `scene1-lon-140e`, `scene1-lon-180`, `scene1-lon-160w`, `scene1-lon-140w`
  - 纬线：`scene1-lat-80n`, `scene1-lat-60n`, `scene1-lat-0`, `scene1-lat-20s`
  - 点：`scene1-point-a`, `scene1-point-b`, `scene1-point-c`, `scene1-point-d`
  - 点高亮外圈：`scene1-point-a-hl`, `scene1-point-b-hl` 等
  - 标签：`scene1-label-lon-120e`, `scene1-label-lat-80n`, `scene1-label-a` 等
  - 标注框：`scene1-box-a`, `scene1-box-b` 等
  - 虚线：`scene1-line-a`, `scene1-line-b` 等
  - 表格：`scene1-summary-table`
  - 按钮：`scene1-btn-prev`, `scene1-btn-next`
  - 步骤提示：`scene1-step-hint`
  - JS中严格使用 `document.getElementById('scene1-xxx')` 获取元素，禁止querySelectorAll配合全局class，避免多场景合并时跨场景污染。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })()` 立即执行函数中，不暴露全局变量。仅内部维护 `currentStep` 和步骤配置数组。
