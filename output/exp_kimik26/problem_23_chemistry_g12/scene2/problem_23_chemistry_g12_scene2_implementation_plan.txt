[图示主题与整合说明]
- 本图示主题：离子晶体X（CsCl型）晶胞的均摊法计算与配位数判断
- 整合内容：
  1. 晶胞结构识别（CsCl型：A离子在立方体8个顶点，B离子在体心）
  2. 均摊法计算晶胞中A、B离子数目，确定化学式AB
  3. 以顶点A为中心扩展2×2×2晶胞堆叠，分析其周围最近B离子的空间位置与数目（配位数=8）
  4. 对比辨析选项D的错误（配位数≠12），简要展示面心立方配位数12的示意
- 教学价值：教师通过分步导航，按"识结构→算组成→析配位→辨正误"的递进逻辑讲解，便于控制课堂节奏；配位数分析通过2×2×2堆叠直观展示8个B离子的空间来源，避免学生死记硬背。

[技术实现]

- JS库选择：原生SVG + 原生JavaScript。原因：本场景为静态几何图形（立方体、球体、线段、多边形）的分步显示/隐藏，无需复杂数学计算或3D渲染，原生SVG性能最优且可控性最高。
- 画布尺寸：800 × 500 px（沿用规格）。
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |   主图区(150,50~420,420)      信息面板(520~780)   |
  |   +---------------------+     +----------------+ |
  |   |                     |     | 图例/计算/配位 | |
  |   |   晶胞/堆叠模型      |     | 数/错误对比    | |
  |   |   (等轴测投影)       |     |                | |
  |   |                     |     |                | |
  |   +---------------------+     +----------------+ |
  |                                                  |
  |   [控件栏 y=440~490]                             |
  |        [◀上一步]  步骤 2/4  [下一步▶]            |
  +--------------------------------------------------+
  ```

- 关键实现要点：
  1. **投影函数封装**：定义函数 `project(x,y,z)` 返回 `{x: 260+60*x-34*y, y: 285+17*x+17*y-60*z}`，所有顶点、体心坐标统一由此生成，避免硬编码错误。
  2. **状态机设计**：用变量 `currentStep`（0~3）管理当前步骤。每步定义一个配置对象，包含该步应显示的元素ID列表和应隐藏的元素ID列表。点击按钮时调用 `renderStep(step)` 统一更新。
  3. **元素分组与显示控制**：
     - 将各步骤专属元素包在 `<g id="scene2-step0-group">` 等容器中，通过设置 `display:none` 或 `opacity:0` 切换。
     - 公共元素（如中心晶胞）始终显示，通过改变样式（如高亮描边）表示状态变化。
  4. **2×2×2堆叠绘制策略**：
     - 外轮廓：计算8个角点坐标，绘制12条棱（9实3虚），统一设置 `opacity=0.45`。
     - 中心晶胞：单独绘制12条棱（覆盖在外轮廓之上，opacity=1）。
     - 球体：中心晶胞8个A球和B0始终opacity=1；外围A球（外轮廓角点）和外围B球opacity=0.45。
  5. **配位多面体面绘制**：用 `<polygon>` 绘制3个可见面（顶面、右面、前面），顶点顺序为顺时针或逆时针（SVG默认非零填充，顺序不影响）。fill=#2e7d32，fill-opacity=0.12。
  6. **动画过渡**：所有opacity和显示切换使用CSS transition（`transition: opacity 0.3s ease`），避免生硬跳变。
  7. **事件绑定**：按钮绑定 `click` 事件，更新 `currentStep` 后调用 `renderStep()`。上一步在step=0时禁用，下一步在step=3时禁用。

- **ID命名规范**：
  - 所有SVG元素ID必须以 `scene2-` 为前缀。
  - 示例：`scene2-v000`（顶点A球）、`scene2-b0`（体心B球）、`scene2-edge-solid-1`（实线棱）、`scene2-label-18-1`（1/8标签）、`scene2-panel-step1`（步骤1信息面板组）、`scene2-btn-prev`（上一步按钮）、`scene2-btn-next`（下一步按钮）。
  - JS中严格使用 `document.getElementById('scene2-xxx')` 获取元素，禁止用 `querySelectorAll` 配合全局class，避免多场景合并时跨场景污染。

- **IIFE隔离**：所有JavaScript代码包裹在 `(function() { ... })();` 中，变量不污染全局作用域。

- **响应式与定位**：
  - SVG设置 `width="800" height="500" viewBox="0 0 800 500"`，确保固定比例。
  - 控件栏用HTML `div` 绝对定位叠在SVG上方（`position:absolute; left:0; top:440px; width:800px; height:60px`），不撑高容器。
