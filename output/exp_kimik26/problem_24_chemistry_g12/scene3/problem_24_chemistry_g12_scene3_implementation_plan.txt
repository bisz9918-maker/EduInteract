[图示主题与整合说明]
- 本图示主题：恒容（甲）与恒压（乙）条件下 2NO₂ ⇌ N₂O₄ 平衡对比及选项判断
- 整合内容：甲的恒容平衡状态；乙的恒压平衡状态（活塞下移、体积缩小）；平衡移动方向；c(NO₂)、N₂O₄ 百分含量、平均相对分子质量的定量比较；四个选项 A/B/C/D 的正误判断
- 教学价值：教师通过分步导航，逐步展示甲/乙从初始状态到平衡状态的差异，再依次展开三个物理量的对比，最后汇总选项判断，形成完整的推理链。学生可直观看到"恒压→体积缩小→平衡更正向→N₂O₄ 更多"的因果链条。

[分步序列]
- 初始状态（步骤0）：显示甲、乙两容器初始状态。甲为固定容积容器（恒容），乙为带活塞容器（恒压）。两容器内均标注 0.2 mol NO₂，体积均为 V。反应方程式 2NO₂ ⇌ N₂O₄ 显示在顶部中央。两容器气体均为纯 NO₂ 红色透明填充。
- 步骤1（点击下一步）：展示甲的平衡状态。甲容器内气体颜色变为红蓝混合（NO₂ 红层 opacity 0.2→0.14，N₂O₄ 蓝层 opacity 0→0.10），表示部分 NO₂ 转化为 N₂O₄。在甲容器右侧标注 n_甲（总物质的量）。乙容器保持不变。
- 步骤2（点击下一步）：展示乙的平衡状态。乙活塞从 y=46 下移至 y=116（动画 500ms，ease-out），气体区域从高度 178 压缩至 108（顶部从 y=60 变为 y=130）。乙气体蓝层 opacity 增至 0.14（平衡更正向，N₂O₄ 更多），红层 opacity 降至 0.12。在乙容器右侧标注 V'（蓝色）及向下箭头，并标注 n_乙 < n_甲。
- 步骤3（点击下一步）：在中间下方出现对比区第一行（高亮背景 rgba(21,101,192,0.1)），显示 "N₂O₄%：乙 > 甲 = 丙"，右侧旁注 "B 选项正确"（绿色）。甲、乙容器保持步骤2状态。
- 步骤4（点击下一步）：出现对比区第二行（高亮背景 rgba(198,40,40,0.1)），左侧公式 "c = n/V"，主文字 "c(NO₂)：乙 > 甲 = 丙"，右侧旁注 "A 选项错误"（红色）。
- 步骤5（点击下一步）：出现对比区第三行（高亮背景 rgba(198,40,40,0.1)），左侧公式 "M = m/n"，主文字 "M：乙 > 甲 = 丙"，右侧旁注 "D 选项错误"（红色）。
- 步骤6（点击下一步）：在画面底部中央出现选项区卡片（#f5f5f5 背景），横向排列 A.×（红）、B.√（绿，加粗高亮）、C.×（红）、D.×（红）。正确答案 B 以绿色高亮显示，其余错误选项以红色显示。对比区三行保持可见。教师可随时点击「上一步」回退复习任意步骤。

[交互方案]
- 交互类型：分步按钮导航（◀ 上一步 / 下一步 ▶）
- 控件说明：
  1. 「上一步」按钮：位于 SVG 内底部左侧（left=270, top=445），点击回退到上一分步，步骤0 时禁用。
  2. 「下一步」按钮：位于 SVG 内底部右侧（left=430, top=445），点击前进到下一分步，步骤6 时禁用。
  3. 步骤指示器：位于两按钮下方居中（400, 485），显示 "步骤 X / 6"。
- 教师操作流程：
  1. 教师加载图示，向学生展示步骤0（甲、乙初始状态相同）。
  2. 点击「下一步」进入步骤1，讲解甲在恒容下达到平衡，n_甲 减小，颜色变化示意 N₂O₄ 生成。
  3. 点击「下一步」进入步骤2，讲解乙在恒压下体积自动缩小，活塞下移，平衡更正向移动，n_乙 < n_甲。
  4. 点击「下一步」进入步骤3，高亮 N₂O₄% 对比，得出乙 > 甲 = 丙，判断 B 正确。
  5. 点击「下一步」进入步骤4，结合 c = n/V 讲解 c(NO₂) 对比，判断 A 错误。
  6. 点击「下一步」进入步骤5，结合 M = m/n 讲解平均相对分子质量对比，判断 D 错误。
  7. 点击「下一步」进入步骤6，汇总四个选项，高亮正确答案 B。
  8. 讲解过程中可随时点击「上一步」回退，强化学生理解。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无外部库）。理由：本场景以静态几何图形、文本标签和简单状态切换为主，原生 SVG 足以高效绘制容器、活塞、气体填充和标注；原生 JS 状态机即可管理 7 个步骤的显示/隐藏，无需引入 D3 等重型库。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +----------------------------------------------------------+
  |                 2NO₂ ⇌ N₂O₄                              |  y=15~45
  |                                                          |
  |   +----------------+          +----------------+         |  y=58~240
  |   | 0.2 mol        |          | 0.2 mol        |         |
  |   | NO₂            |          | NO₂            |         |
  |   |                |          |                |         |
  |   | [红/蓝混合气体]|          | [红/蓝混合气体]|         |
  |   |                |          |                |         |
  |   +----------------+          +----------------+         |
  |   甲 (恒容)   V               乙 (恒压)   V→V' ↓         |  y=260~285
  |                                                          |
  |   +------------------------------------------------+     |  y=303~373
  |   | N₂O₄%：乙 > 甲 = 丙        B 选项正确          |     |
  |   | c = n/V   c(NO₂)：乙 > 甲 = 丙   A 选项错误    |     |
  |   | M = m/n   M：乙 > 甲 = 丙        D 选项错误    |     |
  |   +------------------------------------------------+     |
  |                                                          |
  |        [ A.× ]   [ B.√ ]   [ C.× ]   [ D.× ]            |  y=385~415
  |                                                          |
  |             [◀ 上一步]      [下一步 ▶]                   |  y=445~479
  |                     步骤 X / 6                           |  y=485
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用全局对象 `state = { step: 0, maxStep: 6 }`，`render()` 函数根据 `state.step` 统一控制所有元素的 `display` 属性或 `opacity`。严禁使用多个独立变量分散控制状态。
  2. 活塞动画：步骤2 中活塞下移使用 SVG 的 `transform` 或直接用 JS `requestAnimationFrame` 逐帧更新 `y` 属性（从 46 到 116，历时 500ms，ease-out 曲线 `t*(2-t)`）。气体区域同步动画：高度从 178 压缩到 108，顶部 y 从 60 同步下移到 130。
  3. 气体颜色过渡：步骤1 和步骤2 中气体蓝层的 opacity 变化使用 CSS `transition: opacity 300ms ease`，通过切换 class 实现。
  4. 对比区出现动画：步骤3~5 中每行使用 `opacity: 0→1` 配合 `transform: translateY(8px)→0`，持续 300ms，增强视觉引导。
  5. 事件绑定：上一步/下一步按钮绑定 `click` 事件，调用 `prevStep()` / `nextStep()`，更新 `state.step` 后调用 `render()`。
  6. 按钮禁用逻辑：步骤0 时「上一步」disabled=true；步骤6 时「下一步」disabled=true。
- ID 命名规范：所有 SVG 元素和 HTML 控件 ID 必须以 `scene3-` 为前缀。示例：
  - 甲容器外框：`scene3-container-甲`
  - 乙活塞：`scene3-piston-乙`
  - 甲气体蓝层：`scene3-gas-甲-blue`
  - 对比行1：`scene3-compare-row1`
  - 选项B：`scene3-option-B`
  - 上一步按钮：`scene3-btn-prev`
  - 下一步按钮：`scene3-btn-next`
  JS 中严格使用 `document.getElementById('scene3-xxx')` 获取元素，禁止用 `querySelectorAll` 配合全局 class，避免多场景合并时跨场景污染。
- IIFE 隔离：所有 JavaScript 代码包裹在 `(function() { ... })()` 立即执行函数中，所有变量和函数均为局部作用域。
