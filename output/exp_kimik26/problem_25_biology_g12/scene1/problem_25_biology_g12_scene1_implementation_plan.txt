[图示主题与整合说明]
- 本图示主题：果蝇刚毛性状遗传——四种假说的推演与F₂验证
- 整合的步骤/概念：
  1. 题目已知条件（P、F₁、F₂表现型及目标比例2:1:1）
  2. 假说一：X染色体显性突变（与F₁全直矛盾，排除）
  3. 假说二：X染色体隐性突变（F₂比例2:1:1，吻合）
  4. 假说三：常染色体显性突变（与F₁全直矛盾，排除）
  5. 假说四：常染色体隐性突变（F₂雌性出现卷刚毛且比例不符，排除）
  6. 结论：假说二成立
- 教学价值：教师通过分步导航，带领学生逐一验证四种假说，在对比中理解"假说-演绎法"的遗传题解题逻辑。可随时回退步骤，强化错误排除的推理过程。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本场景为静态遗传图解的分步切换，无复杂动画、函数绘图或3D需求，原生SVG足以精确控制几何图形和文本布局，避免引入不必要的库体积。
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  +--------------------------------------------------+
  | [顶部条件栏 10,5-790,57] 主题+已知条件            |
  +--------------------------------------------------+
  |                                                  |
  |  [主图解区 40,65-560,430]      | [判定栏 588,72-780,428] |
  |  遗传图解/棋盘格/矛盾标注       | 目标比例/判定/原因      |
  |                                |                         |
  |                                |                         |
  +--------------------------------------------------+
  | [底部控件栏 0,440-800,490]  ◀上一步  ●●●●●●  下一步▶  |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `let currentStep = 0;` 记录当前步骤（0~5）。每个步骤对应一个SVG `<g>` 分组，id为 `scene1-step-0` 到 `scene1-step-5`。切换步骤时，隐藏所有分组，仅显示当前分组。
  2. 步骤切换函数 `showStep(n)`：先设置所有 `scene1-step-*` 的 `display='none'`，再设置 `scene1-step-${n}` 的 `display='block'`。同时更新步骤指示器圆点颜色、按钮禁用状态（步骤0时禁用上一步，步骤5时禁用下一步）、右侧判定栏内容。
  3. 右侧判定栏内容：由于各步骤右侧内容不同（步骤5为总结列表，其他为单一判定），可将右侧内容也分步骤分组，或使用JS动态更新文本内容。推荐方案：右侧判定栏的"本假说结果"、"判定标记"、"判定原因"使用JS动态修改textContent，步骤5时替换整个右侧内容为总结列表。
  4. 坐标计算：所有坐标已在布局坐标表中精确到像素，代码中直接使用绝对坐标，无需动态计算。
  5. 动画曲线：本场景为即时切换，无需CSS动画或JS动画。若需增强教学效果，可在步骤切换时添加100ms的淡入淡出（opacity过渡），但非必需。
  6. 事件绑定：为「上一步」「下一步」按钮及6个圆点绑定click事件。所有事件处理函数写在IIFE内部。
  7. 基因型上标处理：SVG中Xᴬ、Xᵃ使用 `<tspan>` 的 `baseline-shift="super"` 实现上标效果，确保A/a为上标。
- ID命名规范：
  - 步骤分组：`scene1-step-0` 到 `scene1-step-5`
  - 按钮：`scene1-btn-prev`、`scene1-btn-next`
  - 步骤指示器圆点：`scene1-dot-0` 到 `scene1-dot-5`
  - 右侧判定结果文本：`scene1-result-text`、`scene1-verdict-mark`、`scene1-verdict-reason`
  - 获取元素使用 `document.getElementById`，不使用 `querySelectorAll` 配合全局class，避免多场景合并时跨场景污染。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，不污染全局命名空间。
