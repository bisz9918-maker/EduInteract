[图示主题与整合说明]
- 本图示主题：双基因遗传系谱图的分步解析与遗传方式判断
- 整合的步骤/概念：
  1. 系谱图整体结构识别与图例说明；
  2. 甲病遗传方式判断（常染色体隐性遗传）；
  3. 乙病遗传方式判断（常染色体隐性或X染色体隐性遗传）；
  4. 甲病与乙病关键个体基因型标注。
- 教学价值：教师通过分步导航，可按照“现象→显隐判断→染色体定位→基因型标注”的递进逻辑逐步展开讲解，随时回退重讲，适合课堂投影与师生互动。

[分步序列]
- 步骤0（初始状态）：完整展示图1系谱图全部个体与连线；右侧显示图例面板；底部控件显示"步骤 0 / 6"；所有个体无高亮、无基因型标签、无推导标注；教师可悬停任意个体，其编号标签短暂放大高亮（可选微交互）。
- 步骤1（甲病显隐判断）：点击「下一步」→ 非Ⅰ1、Ⅰ2、Ⅱ3的个体及无关连线淡化（透明度40%，虚线）；Ⅰ1、Ⅰ2、Ⅱ3加蓝框高亮；在Ⅰ1-Ⅰ2婚配线上方弹出"无中生有"(120,55)；在Ⅱ3右下方弹出"甲病患儿"(170,228)并引线连接；右侧步骤说明更新为"Ⅰ1与Ⅰ2表现正常，子代Ⅱ3患甲病，符合'无中生有'→甲病为隐性遗传病"。
- 步骤2（甲病染色体定位）：点击「下一步」→ 高亮切换为Ⅱ6、Ⅰ3、Ⅱ7（蓝框），其余淡化；右侧弹出条件卡片，文本"已知：Ⅱ6携带甲病基因；Ⅰ3、Ⅱ7均无甲病基因"；在Ⅰ3旁标注假设基因型"X^A Y"(410,65)，在Ⅱ9旁标注"X^a X^a"(460,195)；在右侧卡片下方显示红色叉号(690,360)及文字"Ⅰ3无法提供X^a，与Ⅱ9患病矛盾"；在系谱图上方或右侧显示绿色箭头与文字"确认：常染色体隐性遗传"；右侧步骤说明更新。
- 步骤3（甲病基因型标注）：点击「下一步」→ 系谱图恢复完整显示（无淡化）；从各关键个体中心向外弹出甲病基因型标签（缩放淡入动画，200ms）：Ⅰ1"Aa"(110,65)、Ⅰ2"Aa"(170,65)、Ⅱ3"aa"(160,195)、Ⅱ6"Aa"(330,195)、Ⅰ3"AA"(410,65)、Ⅱ7"AA"(380,195)、Ⅱ9"aa"(460,195)；右侧步骤说明更新为各基因型推导依据。
- 步骤4（乙病显隐判断）：点击「下一步」→ 非Ⅱ5、Ⅱ6、Ⅲ2的个体及无关连线淡化；Ⅱ5、Ⅱ6、Ⅲ2加蓝框高亮；在Ⅱ5-Ⅱ6婚配线上方弹出"无中生有"(280,185)；在Ⅲ2右下方弹出"乙病患儿"(275,368)并引线；右侧步骤说明更新为"Ⅱ5与Ⅱ6正常，子代Ⅲ2患乙病→乙病为隐性遗传病"。
- 步骤5（乙病两种假设）：点击「下一步」→ 高亮扩展为乙病相关个体（Ⅱ5、Ⅱ6、Ⅲ2、Ⅲ3、Ⅱ10、Ⅱ11、Ⅲ4）；底部控件区出现两个切换按钮「常隐假设」(360,465)与「X隐假设」(440,465)，默认选中「常隐假设」；系谱图左侧弹出乙病基因型标签（常隐状态）：Ⅱ5"Bb"(230,195)、Ⅱ6"Bb"(290,195)、Ⅲ2"bb"(230,335)、Ⅲ3"bb"(290,335)、Ⅲ4"bb"(490,335)；右侧步骤说明展示两种假设的对比逻辑；教师点击「X隐假设」按钮→左侧基因型标签切换为X隐状态（Ⅱ5"X^B Y"、Ⅱ6"X^B X^b"、Ⅲ2"X^b Y"、Ⅲ3"X^b X^b"、Ⅱ10"X^b Y"、Ⅱ11"X^B X^b"、Ⅲ4"X^b Y"），系谱图无其他变化。

[技术实现]
- JS库选择：原生 SVG + 原生 JavaScript。原因：系谱图由基本几何图形（矩形、圆、线、文本）构成，无复杂函数绘图或3D需求，原生SVG即可精确控制每个元素的坐标、描边、填充与动画，且无需引入外部库，减少加载依赖。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------------+
  |  Ⅰ  ○───□          ○───□                              |  y=80
  |      |               |                                 |
  |  Ⅱ  □ ○ ■ ◎   □─○   ○ □ ● ■ □─○                      |  y=210
  |      |         |               |                       |
  |  Ⅲ  ○         ■   ●           ■   ○                   |  y=350
  |                                                        |
  |  [图例面板]    [步骤说明/条件卡片]                       |  x=620~780
  |                                                        |
  +--------------------------------------------------------+
  |        [◀ 上一步]  步骤 X / 6  [下一步 ▶]               |  y=440~490
  +--------------------------------------------------------+
  左侧0~520px：系谱图主体；右侧530~780px：图例与信息面板；底部440~490px：控件栏。
  ```
- 关键实现要点：
  1. 状态机设计：使用全局变量 `currentStep`（0~6）和 `currentHypothesis`（'auto'|'xlink'，仅在步骤5有效）。每次点击按钮调用 `renderState()`，根据状态显隐/高亮/填充对应SVG元素。
  2. 元素显隐：所有可能动态出现的元素（基因型标签、临时标注、条件卡片、假设按钮）在SVG中预先定义，初始 `display:none` 或 `opacity:0`，通过JS切换。
  3. 淡化效果：非高亮个体通过添加CSS类 `.dimmed` 实现 `opacity:0.4` 及 `stroke-dasharray:4,2`；高亮个体添加 `.highlight` 实现 `stroke:#1565c0; stroke-width:2.5px`。
  4. 动画：基因型标签弹出使用SVG原生SMIL `<animateTransform>`（scale 0→1）或CSS `transition: opacity 0.2s, transform 0.2s`；临时标注使用 `transition: opacity 0.3s` 淡入淡出。
  5. 步骤5状态切换：点击「常隐假设」或「X隐假设」时，仅切换乙病基因型标签的 `display` 属性，并更新按钮激活样式，不改变 `currentStep`。
  6. 事件绑定：所有按钮通过 `document.getElementById` 获取（如 `scene1-btn-prev`、`scene1-btn-next`），绑定 `click` 事件监听器。
  7. 悬停提示（步骤0）：为每个个体符号绑定 `mouseenter`/`mouseleave`，显示一个跟随鼠标的 `title` 或小型tooltip（如放大编号）。
- ID命名规范：所有SVG元素及JS访问的DOM节点ID必须以 `scene1-` 为前缀。示例：
  - 个体符号：`scene1-ind-I1`、`scene1-ind-II3`
  - 基因型标签：`scene1-gen-I1`、`scene1-gen-II6-auto`
  - 按钮：`scene1-btn-prev`、`scene1-btn-next`、`scene1-btn-auto`、`scene1-btn-xlink`
  - 临时标注：`scene1-note-wns-jia`、`scene1-note-patient-II3`
  - 条件卡片：`scene1-card-condition`
  - 步骤说明文本：`scene1-step-desc`
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免全局变量污染，确保多场景合并时互不干扰。
