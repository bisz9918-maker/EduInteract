[图示主题与整合说明]
- 本图示主题：两对相对性状的遗传分析——连锁与自由组合
- 整合的步骤/概念：
  1. 第(6)问：A/a（有毛/无毛）与B/b（黑毛/白毛）均位于X染色体上，表现为伴X连锁遗传；通过白毛雄性（X^abY）与有毛雌性（X^aBX^ab）的杂交，用Punnett方格展示子代基因型与表现型比例1:1:1:1。
  2. 第(7)问：C/c（直毛/卷毛）位于常染色体，A/a位于X染色体；通过卷毛（cc）与直毛（CC）杂交，结合X^AX^a × X^AY的伴X遗传，用分支法验证自由组合定律，得到直毛有毛3/4、直毛无毛1/4。
  3. 最终对比：左侧"连锁遗传"与右侧"自由组合"的核心区别——基因是否位于非同源染色体上。
- 教学价值：教师通过分步导航，先带领学生完成连锁遗传的Punnett方格推导，再切换到自由组合的分支法推导，最后并列对比两种机制，强化"非同源染色体→自由组合"的核心概念。

[视觉元素清单]
- 染色体：X染色体用蓝色#1565c0粗4px竖线，Y染色体用红色#c62828粗4px竖线，常染色体用灰色#888888粗4px竖线；基因位点用2px横线标记，标签置于染色体外侧（左或右）。
- 配子：圆形r=18px，母本配子淡蓝/淡红填充20%，内部基因型文字居中。
- Punnett方格：2×2方格，每格60×60px，黑色边框2px；格内上方为基因型（12px），下方为表现型（12px），表现型文字颜色按性别区分（雌性蓝#1565c0，雄性红#c62828）。
- 分支法：黑色实线连接节点，节点文字14px；最终结果用绿色#2e7d32标注。
- 标签文字：标题18~20px，名称/基因型14px，表现型/说明12~14px；所有文字使用sans-serif字体。
- 高亮与填充：结论文字用绿色#2e7d32；当前步骤元素opacity=1，非当前步骤元素opacity=0（隐藏）；Punnett方格中不同基因型区域可用淡色填充区分（可选）。
- 配色规则（沿用大纲）：
  - 背景 #ffffff
  - 主线 #000000：边框、连线、染色体轮廓
  - 蓝高亮 #1565c0：X染色体、显性基因A/B/C、雌性、直毛/黑毛/有毛正常表现型
  - 红高亮 #c62828：Y染色体、隐性基因a/b/c、雄性、卷毛/无毛/白毛表现型
  - 绿高亮 #2e7d32：结论标签"自由组合定律"、验证通过标记
  - 辅助线 #888888 虚线：分隔线、淡化示意
  - 填充透明度 20%：配子圆形、细胞核、Punnett方格背景区分

[分步序列]
- 初始状态（步骤0）：显示主标题"两对相对性状的遗传分析"；左右分栏标题分别为"第(6)问：伴X连锁遗传"（蓝）和"第(7)问：自由组合定律"（绿）；中央画细胞核椭圆，内含简化的常染色体（灰色棒状）、X染色体（蓝色X形）、Y染色体（红色短棒）；底部提示"点击「下一步」开始逐步分析"。
- 步骤1（第6问：亲本基因型与染色体定位）：点击「下一步」→ 左栏展示父本白毛雄性X^abY（X染色体标a、b，Y染色体红色）和母本有毛雌性X^aBX^ab（两条X染色体分别标a/B和a/b）；右栏隐藏；中央杂交符号"×"。
- 步骤2（第6问：配子与子代比例）：点击「下一步」→ 在步骤1基础上，染色体上方出现母本两种配子圆形（X^aB、X^ab），左侧出现父本配子标签（X^ab、Y）；下方出现2×2 Punnett方格，四格分别为X^aBX^ab（♀黑毛有毛）、X^abX^ab（♀白毛无毛）、X^aBY（♂黑毛有毛）、X^abY（♂白毛无毛）；底部标注比例1:1:1:1；高亮无毛个体。
- 步骤3（第7问：亲本基因型与染色体定位）：点击「下一步」→ 左栏隐藏，右栏展示两对基因位于不同染色体：常染色体（灰色，标C/c）和X染色体（蓝色，标A/a）及Y染色体（红色）；标注亲本杂交组合"卷毛 × 直毛"及基因型ccX^AX^a × CCX^AY。
- 步骤4（第7问：自由组合验证）：点击「下一步」→ 右栏展示分支法：根节点"P: 卷毛 × 直毛"分两支，左支"Cc 直毛 1"，右支"X^AX^a×X^AY"；右支再分"有毛3/4"和"无毛1/4"；交叉组合得到"直毛有毛3/4"和"直毛无毛1/4"；底部绿色结论"遵循基因的自由组合定律"。
- 步骤5（总结对比）：点击「下一步」→ 左右双栏同时展示。左栏"连锁遗传"：X染色体示意图+"两基因在同一条X上"+"子代比例由配子决定"+"例：1:1:1:1"。右栏"自由组合"：常染色体+X/Y示意图+"两基因位于非同源染色体"+"子代比例=各自比例乘积"+"3/4×1=3/4, 1/4×1=1/4"。中央"VS"标志，底部核心区别"基因是否位于非同源染色体上"。
- 教师可随时点击「上一步」回退到任意步骤复习。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本场景以几何图形（染色体、方格、分支线）和文本标签为主，无复杂函数绘图或3D需求，原生SVG即可精确控制每个元素的坐标和显示/隐藏，无需引入重量级库。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  标题区(y=0~35)                                   |
  |  +------------------+------------------+           |
  |  |   左栏内容区     |   右栏内容区     |           |
  |  |   (x=0~400)      |   (x=400~800)    |           |
  |  |                  |                  |           |
  |  |  步骤1/2:染色体  |  步骤3/4:染色体  |           |
  |  |  +Punnett方格    |  +分支法         |           |
  |  |                  |                  |           |
  |  +------------------+------------------+           |
  |  控件栏(y=440~490)  [上一步] 步骤X/5 [下一步]      |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `let currentStep = 0;` 记录当前步骤（0~5）。每一步对应一个SVG `<g>` 分组，id为 `scene4-step0` ~ `scene4-step5`。切换步骤时，将当前步骤group的display设为block，其余设为none。
  2. 坐标计算：所有坐标已在布局坐标表中精确给出，代码中直接使用绝对坐标（px），无需动态计算。
  3. 动画曲线：分步切换时无需复杂动画，直接显示/隐藏即可；如需柔和过渡，可对group设置CSS `transition: opacity 0.3s ease`，切换时改变opacity。
  4. 事件绑定：在IIFE内为按钮绑定click事件：`document.getElementById('scene4-btn-prev').addEventListener('click', ...)`。
  5. 按钮状态：在update函数中根据currentStep设置按钮disabled类和opacity。
  6. 染色体绘制：使用`<line>`绘制主干，`<line>`绘制基因位点横线，`<text>`绘制基因标签；X/Y染色体颜色通过stroke属性区分。
  7. Punnett方格：使用`<rect>`绘制外框，`<line>`绘制内部网格，`<text>`绘制基因型和表现型；表现型文字可用`tspan`或单独`<text>`控制颜色。
  8. 分支法：使用`<line>`绘制连接线，`<text>`绘制节点文字；线条使用stroke-linecap="round"使接头圆润。
- ID命名规范：所有SVG元素和HTML控件ID必须以 `scene4-` 为前缀。例如：
  - 分组：`scene4-step0`, `scene4-step1`, ...
  - 染色体：`scene4-chr-x-father`, `scene4-chr-y-father`, `scene4-chr-x1-mother`
  - 按钮：`scene4-btn-prev`, `scene4-btn-next`
  - 指示器：`scene4-step-indicator`
  - Punnett元素：`scene4-punnett-grid`, `scene4-punnett-cell1-genotype`
  - 分支法元素：`scene4-branch-root`, `scene4-branch-result1`
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免全局变量污染，确保多场景合并时互不干扰。
- 字体建议：使用系统默认无衬线字体栈 `font-family: "Segoe UI", "Microsoft YaHei", "PingFang SC", sans-serif;`，确保中文和基因型上标显示清晰。基因型中的上标（如X^aB）可使用`<tspan dy="-5" font-size="10px">`模拟，或直接使用Unicode上标字符（如Xᵃᴮ）。
