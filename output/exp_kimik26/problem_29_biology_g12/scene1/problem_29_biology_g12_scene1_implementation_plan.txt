[图示主题与整合说明]
- 本图示主题：PCR 扩增的完整循环过程（变性 → 复性 → 延伸 → 产物）
- 整合的步骤/概念：
  1. 引物Ⅱ的序列推导（基于 a 链 3' 端碱基互补配对：a 链 3' 端为 T—C，引物Ⅱ序列为 3'—A—G—5'，即 5'—G—A—3'）
  2. 复性阶段引物Ⅰ、引物Ⅱ在两条单链上的正确位置定位（反向平行配对）
  3. 延伸阶段 DNA 聚合酶沿模板链 3'→5' 方向移动，新链以 5'→3' 方向合成
  4. 循环一次后生成的两个子代 DNA 分子（半保留复制）
- 教学价值：教师可按"变性→复性→延伸→产物"的节奏逐步讲解，每步聚焦一个核心变化。学生可清晰看到引物结合位置、链延伸方向及最终半保留复制产物，解决 PCR 过程抽象难懂的问题。

[分步序列]
- 步骤 0（初始状态）：
  显示阶段0（原始 DNA 双链 + 引物Ⅰ + 引物Ⅱ横线）。其余阶段（1~4）的所有元素以 opacity=0.15 灰显。当前步骤高亮提示：阶段0右侧无高亮背景。
  教师可引导学生观察 a 链、b 链序列方向及引物Ⅰ序列，思考引物Ⅱ应如何填写。

- 步骤 1（95°C 变性）：
  点击「下一步」→ 阶段0 变为 opacity=0.15；阶段1 变为 opacity=1.0，温度背景高亮（#fff3e0 背景框）。
  视觉变化：a 链与 b 链从阶段0的紧密双链位置（y=50/75）分离到阶段1位置（y=115/140），中间用虚线箭头指示过程。氢键消失。
  教师讲解：高温使氢键断裂，双链解旋为单链。

- 步骤 2（55°C 复性）：
  点击「下一步」→ 阶段1 变为 opacity=0.15；阶段2 变为 opacity=1.0，温度背景高亮。
  视觉变化：引物Ⅰ（蓝色）出现在 b 链下方左侧（x=230~280, y=225）；引物Ⅱ（红色）出现在 a 链上方右侧（x=470~515, y=155），序列 3'—A—G—5'（OH 在左，5' 在右）。
  教师讲解：温度降低，引物与模板链反向平行配对；引物Ⅱ根据 a 链 3' 端 T—C 互补确定为 A—G。

- 步骤 3（72°C 延伸）：
  点击「下一步」→ 阶段2 变为 opacity=0.15；阶段3 变为 opacity=1.0，温度背景高亮。
  视觉变化：
  - 新链1（绿色+红色）出现在 b 链下方：左侧红色段为引物Ⅰ（x=230~280），右侧绿色段为延伸产物（x=280~480），序列 5'—G—G……T—C—3'。
  - 新链2（绿色+红色）出现在 a 链上方：左侧绿色段为延伸产物（x=280~470），右侧红色段为引物Ⅱ（x=470~510），序列 3'—C—C……A—G—5'。
  - DNA 聚合酶标注出现在 b 链与新链1之间（340,302）。
  教师讲解：DNA 聚合酶从引物 3'OH 端开始，沿 5'→3' 方向合成新链；引物Ⅱ的 3' 端朝左，因此新链2向左延伸。

- 步骤 4（循环一次产物）：
  点击「下一步」→ 阶段3 变为 opacity=0.15；阶段4 变为 opacity=1.0。
  视觉变化：左右两个完整的子代 DNA 双链出现。
  - 左侧 DNA：上链为新链 b'（绿色，5'→3'），下链为母链 a（蓝色，3'→5'）。
  - 右侧 DNA：上链为新链 a'（绿色，5'→3'），下链为母链 b（红色，3'→5'）。
  - 氢键连接配对碱基。
  教师讲解：每个子代 DNA 含一条母链和一条新链，半保留复制；循环一次后 1 个 DNA 变为 2 个。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript。原因：本图示以静态几何图形（线段、文字、虚线）为主，无复杂动画或数据可视化，原生 SVG 足够且轻量，无需引入 D3 等库。
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  阶段0: 原始双链 + 引物Ⅰ + 引物Ⅱ横线  (y=35~85)   |
  |  ↓ 虚线箭头                                       |
  |  阶段1: 95°C 变性, 单链分离  (y=100~145)           |
  |  ↓ 虚线箭头                                       |
  |  阶段2: 55°C 复性, 引物结合  (y=160~220)           |
  |  ↓ 虚线箭头                                       |
  |  阶段3: 72°C 延伸, 新链合成  (y=240~325)           |
  |  ↓ 虚线箭头                                       |
  |  阶段4: 两个子代DNA分子  (y=345~420)               |
  |                                                  |
  |  [◀上一步]  [步骤 X/5]  [下一步▶]  (y=440~490)    |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 `currentStep`（0~4）记录当前步骤。每步对应一个显示组（g 元素），通过切换组的 `opacity` 实现阶段高亮/灰显。
  2. 坐标计算：所有坐标按上述坐标表硬编码，DNA 链水平居中，碱基间距 25px，阶段间垂直间距 15~20px。
  3. 动画曲线：阶段切换时使用 CSS transition `opacity 0.4s ease`，无需复杂动画库。
  4. 事件绑定：按钮点击事件更新 `currentStep`，调用 `renderStep()` 函数，该函数遍历所有阶段组设置对应 opacity（当前步=1.0，其他步=0.15）。
  5. 温度高亮：当前步骤若为变性/复性/延伸，给温度文字添加浅橙背景矩形（#fff3e0, opacity=0.3），非当前步隐藏背景。
  6. 引物Ⅱ横线：步骤0中显示黑色横线供学生思考；步骤2起替换为红色引物Ⅱ序列。
  7. 阶段3新链颜色：使用两段 path/line 拼接，左侧一段绿色、右侧一段红色（新链2），或左侧红色、右侧绿色（新链1），中间在 x=280（新链1）或 x=470（新链2）处无缝衔接。
