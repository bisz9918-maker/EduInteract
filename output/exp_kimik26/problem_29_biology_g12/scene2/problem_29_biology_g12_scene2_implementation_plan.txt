[图示主题与整合说明]
- 本图示主题：$^{32}$P 标记下 PCR 半保留复制的链分布规律
- 整合的步骤/概念：
  1. 亲代 DNA（0 次循环）的初始状态；
  2. 循环 1 次后产生 2 个杂合 DNA（各含 1 条无放射性母链 + 1 条带 $^{32}$P 新链）；
  3. 循环 2 次后产生 4 个 DNA（2 条杂合 + 2 条全新带放射性），无放射性单链仍为 2 条；
  4. 循环 $n$ 次后的通用公式推导（DNA 数 $2^n$、总单链 $2^{n+1}$、无放射性单链恒为 2、比例 $1/2^n$）。
- 教学价值：教师通过「上一步/下一步」逐层展开树状复制图，让学生直观看到"母链数量恒定、新链指数增长"的核心规律，最终自然归纳出数学公式。右侧统计面板实时同步数据，强化数形结合。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript。理由：本场景以静态几何图形（线段、圆、文字）和显隐切换为主，无需复杂数学计算或 3D，原生 SVG 足以保证清晰度与性能，且便于通过 <g> 分组控制整层显隐。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |  左侧树状图区 (20,40)-(460,420)                   |
  |                                                  |
  |      [亲代 DNA]         +--------------------+   |
  |       a═══b             |  统计与规律        |   |
  |        / \              |  ----------------  |   |
  |       /   \             |  DNA分子数    2    |   |
  |   [DNA1] [DNA2]         |  总单链数     4    |   |
  |    / \    / \           |  无放射性链   2    |   |
  |   ...                    |  比例       1/2   |   |
  |                         +--------------------+   |
  |                                                  |
  +--------------------------------------------------+
  |  [◀ 上一步]   步骤 2 / 4   [下一步 ▶]            |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `let currentStep = 0;`（范围 0~3）。每步对应一个 SVG `<g>` 组（id 分别为 `scene2-step0` ~ `scene2-step3`），通过设置 `display: block/none` 切换。右侧面板内容同样分 4 个组切换。
  2. 分支线动画：步骤1/2中的虚线分支 path，使用 CSS `stroke-dasharray` + `stroke-dashoffset` 动画，或 JS 逐帧设置 `stroke-dashoffset` 实现"从无到有"的绘制效果，时长 400ms，增强树状展开的动态感。
  3. 按钮状态：步骤0 时「上一步」置灰（disabled），步骤3 时「下一步」置灰。
  4. 步骤3 的循环2层可选择保留但设置 `opacity: 0.25`，作为背景参考，避免画面突然清空造成跳跃感。
  5. 所有 ³²P 徽章使用 `<circle>` + `<text>` 组合，确保居中。
  6. 面板说明文字使用 `<foreignObject>` 内嵌 `<div>` 或 SVG `<text>` 配合 `tspan` 实现自动换行（推荐 foreignObject 以便中文换行控制）。
- ID 命名规范：
  - 分组：`scene2-step0`、`scene2-step1-leftdna`、`scene2-step2-dna3`、`scene2-panel-step2` 等。
  - 分支线：`scene2-branch-0to1-left`、`scene2-branch-1to2-dna1-left` 等。
  - 按钮：`scene2-btn-prev`、`scene2-btn-next`。
  - 步骤指示器：`scene2-step-indicator`。
  - 禁止出现无前缀的全局 ID。
- IIFE 隔离：所有 JS 逻辑包裹在 `(function() { ... })();` 中，避免多场景合并时变量污染。
- 事件绑定：使用 `document.getElementById('scene2-btn-next').addEventListener('click', ...)`，不依赖全局 class 选择器。
