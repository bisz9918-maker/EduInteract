[图示主题与整合说明]
- 本图示主题：光滑木板上木块的匀速直线运动与动能不变（覆盖 D 选项）
- 整合的步骤/概念：
  1. 实验装置认知（斜面、小车、木块、木板）
  2. 撞击瞬间与速度获得（小车撞击木块，木块获得水平速度 v）
  3. 光滑表面的受力分析（无摩擦 → 水平方向不受力）
  4. 牛顿第一定律应用（匀速直线运动，速度 v 保持不变）
  5. 动能公式验证（E_k = ½mv²，m 与 v 均不变 → E_k 不变，D 正确）
- 教学价值：教师通过分步导航，引导学生从力学现象逐步过渡到能量分析，建立"受力→运动状态→能量"的完整因果链，强化对牛顿第一定律和动能概念的理解。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「上一步」按钮：位于控件栏左侧(290,452)，90×36px。点击回退到上一状态，到达步骤0时禁用（opacity:0.4，pointer-events:none）。
  2. 「下一步」按钮：位于控件栏右侧(420,452)，90×36px。点击前进到下一状态，到达步骤4时禁用。

- 教师操作流程：
  1. 教师加载图示，展示步骤0的实验装置，让学生识别各部件。
  2. 点击「下一步」进入撞击瞬间（步骤1），引导学生观察木块获得速度。
  3. 点击「下一步」进入光滑表面运动（步骤2），强调"光滑=无摩擦"的受力条件。
  4. 点击「下一步」进入匀速运动（步骤3），联系牛顿第一定律，强调速度v不变。
  5. 点击「下一步」进入能量分析（步骤4），展示动能公式，逐一确认m和v不变，得出E_k不变，确认D选项正确。
  6. 讲解过程中可随时点击「上一步」回退，复习关键概念。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无需外部库）。理由：场景以静态几何图形和分步显隐为主，无复杂动画或数据可视化，原生SVG性能最优且零依赖。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------------+
  |  [公式卡片 步骤4]                                        |
  |  E_k=½mv²  [对勾]                                       |
  |                                                        |
  |     小车标签                                            |
  |       ↓                                                |
  |      [小车]                                            |
  |         \ 斜面                                          |
  |          \                                             |
  |           \____[木块]========> v   匀速文字(步骤3)       |
  |           木板  ↑        轨迹虚线    光滑标签(步骤2)      |
  |        受力文字(步骤2)                                   |
  |                                                        |
  |        D正确(步骤4)                                     |
  |                                                        |
  |  +------------------------------------------------+    |
  |  |     [◀ 上一步]    步骤 1/5    [下一步 ▶]       |  <- 控件栏 y=440~500
  |  +------------------------------------------------+    |
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `currentStep`（0~4），共5个状态。`updateScene(step)` 函数根据状态统一控制所有元素的 opacity 和 transform。
  2. 木块平移：使用 CSS `transition: transform 0.4s ease`（步骤2用ease-out模拟启动，步骤3用linear强调匀速）。通过切换 class 如 `scene3-block-pos0` ~ `scene3-block-pos4` 实现平移。
  3. 小车切换：步骤0→1时，斜面小车opacity渐变为0，平面小车opacity渐变为1。使用CSS transition: opacity 0.3s。
  4. 公式卡片内容：步骤4时卡片整体opacity渐变，内部文字无需单独动画，随卡片一起显示。
  5. 事件绑定：为「上一步」「下一步」按钮绑定 click 事件，更新 currentStep 后调用 updateScene。边界检查：currentStep < 0 或 > 4 时禁用对应按钮。
  6. 动画曲线：
     - 撞击瞬间（步骤0→1）：opacity fade，0.3s ease
     - 木块启动（步骤1→2）：transform translateX，0.4s ease-out
     - 木块匀速（步骤2→3，步骤3→4）：transform translateX，0.4s linear
     - 回退时动画反向播放
- ID 命名规范：所有交互元素 ID 必须以 `scene3-` 为前缀。例如：
  - `scene3-slope`（斜面）
  - `scene3-board`（木板）
  - `scene3-car-slope`（斜面上的小车）
  - `scene3-car-flat`（平面上的小车）
  - `scene3-block-group`（木块组，含标签和速度矢量）
  - `scene3-velocity-group`（速度矢量组）
  - `scene3-track`（运动轨迹）
  - `scene3-impact`（撞击点）
  - `scene3-formula-card`（公式卡片）
  - `scene3-checkmark`（对勾）
  - `scene3-label-smooth`（光滑标签）
  - `scene3-text-friction`（受力分析文字）
  - `scene3-text-uniform`（匀速运动文字）
  - `scene3-text-correct`（D正确文字）
  - `scene3-btn-prev`（上一步按钮）
  - `scene3-btn-next`（下一步按钮）
  - `scene3-step-indicator`（步骤指示器）
  JS 中严格使用 `document.getElementById` 获取元素，禁止 querySelectorAll 配合全局 class，避免多场景合并时跨场景污染。
- IIFE 隔离：所有 JavaScript 代码包裹在 `(function() { ... })()` 立即执行函数中，变量不污染全局作用域。
- 响应式提示：虽然画布固定800×500，但外层容器可设置 `max-width: 100%` 保持缩放适配。
