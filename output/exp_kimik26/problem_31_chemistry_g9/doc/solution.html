场景导航：Scene 1 | Scene 2 | Scene 3

题目原文

910℃以下纯铁晶体的基本结构单元如图1所示，910℃以上转变为图2所示的结构单元，在两种晶体中最邻近的铁原子间距离相同。

（1）在910℃以下的纯铁晶体中，与铁原子等距离且最近的铁原子数为 $\underline{\hspace{5em}}$ 个，在910℃以上的纯铁晶体中，与铁原子等距离且最近的铁原子数为 $\underline{\hspace{5em}}$ 个。

（2）纯铁晶体在晶型转变前后，二者基本结构单元的边长之比为（910℃以下与910℃以上之比） $\underline{\hspace{5em}}$ 。

（3）转变温度前后两者的密度之比（910℃以下与910℃以上之比） $\underline{\hspace{5em}}$ 。

题目分析

本题以纯铁的同素异形体转变为背景，考查晶体结构中的核心概念：体心立方（BCC，图1）与面心立方（FCC，图2）。关键已知条件是"两种晶体中最邻近的铁原子间距离相同"，这意味着原子半径 $r$ 在两种结构中视为相同，由此建立边长 $a$ 与 $r$ 的关系，进而求解边长比和密度比。

整体讲解思路

  1. 先让学生识别两种晶胞类型（BCC vs FCC），建立空间直观。
  2. 通过"以某个原子为中心，找等距最近邻"的方法确定配位数。
  3. 利用几何关系（体对角线、面对角线）建立 $a$ 与 $r$ 的等式，求边长比。
  4. 利用密度公式 $\rho = nM/(N_A a^3)$，结合晶胞中原子数 $n$ 和边长比，求密度比。

步骤 1/4

教学说明：配位数的判断方法

配位数（Coordination Number）是晶体结构的核心概念，指与某一原子等距离且最近的原子数目。讲解时应强调"以谁为中心"和"等距最近"两个关键词。

BCC结构（图1）讲解要点：

  1. 引导学生观察体心原子：它到8个顶点原子的距离完全相同，且没有比这更近的原子。
  2. 距离计算：体心到顶点距离为体对角线的一半，即 $d = \frac{\sqrt{3}}{2}a_1$。
  3. 体心原子的配位数为 8。
  4. 补充说明：顶点原子的配位数也是8（每个顶点原子被8个相邻晶胞共享，每个晶胞提供1个体心原子）。

FCC结构（图2）讲解要点：

  1. 建议以面心原子为观察中心（也可选择顶点原子，但面心更直观）。
  2. 一个面心原子到同一平面4个顶点距离为 $\frac{\sqrt{2}}{2}a_2$，到相邻两个面的4个面心距离也是 $\frac{\sqrt{2}}{2}a_2$，到上下层4个顶点距离同样是 $\frac{\sqrt{2}}{2}a_2$，共12个。
  3. 面心原子的配位数为 12。
  4. 强调FCC比BCC堆积更致密，配位数更高，为后续密度比小于1做铺垫。

课堂互动建议：

  • 先让学生凭空间想象猜测配位数，再用图示验证。
  • 提问："为什么BCC的体心原子不是6个最近邻而是8个？"引导学生排除"上下左右前后"的平面思维定势。
步骤 1/4

教学说明：几何截面法与边长比推导

本题的核心桥梁是"最近邻距离相同"，即两种结构中相切原子的球心距均为 $2r$。教师需要引导学生将3D晶胞问题转化为2D截面几何问题。

BCC结构推导：

  1. 在BCC中，体心原子与顶点原子相切，球心连线为体对角线的一半。
  2. 体对角线长度 = $\sqrt{3}a_1$，因此 $2r = \frac{\sqrt{3}}{2}a_1$，即 $4r = \sqrt{3}a_1$。
  3. 解得 $a_1 = \frac{4r}{\sqrt{3}}$。

FCC结构推导：

  1. 在FCC中，面心原子与顶点原子（或相邻面心原子）相切，球心连线为面对角线的一半。
  2. 面对角线长度 = $\sqrt{2}a_2$，因此 $2r = \frac{\sqrt{2}}{2}a_2$，即 $4r = \sqrt{2}a_2$。
  3. 解得 $a_2 = \frac{4r}{\sqrt{2}} = 2\sqrt{2}r$。

边长比计算：

$$\frac{a_1}{a_2} = \frac{4r/\sqrt{3}}{4r/\sqrt{2}} = \frac{\sqrt{2}}{\sqrt{3}} = \frac{\sqrt{6}}{3}$$

常见错误提醒：

  • 学生易混淆"体对角线"与"面对角线"，建议强调BCC的最近邻是"体心-顶点"，FCC的最近邻是"面心-顶点"或"面心-面心"。
  • 化简 $\frac{\sqrt{2}}{\sqrt{3}}$ 时，学生可能忘记分母有理化，需强调最终答案形式为 $\frac{\sqrt{6}}{3}$。
步骤 1/5

总结：完整解答与课堂讲解建议

答案汇总：

  1. 配位数：910℃以下（BCC）为 8；910℃以上（FCC）为 12。
  2. 边长之比：$a_1 : a_2 = \sqrt{6} : 3$（或 $\frac{\sqrt{6}}{3}$）。
  3. 密度之比：$\rho_1 : \rho_2 = 3\sqrt{6} : 8$（或 $\frac{3\sqrt{6}}{8}$）。

完整推导回顾：

  1. 配位数：BCC以体心原子为中心，8个顶点原子等距最近；FCC以面心原子为中心，12个原子等距最近（同层4面心+上下层8顶点）。
  2. 边长比：利用最近邻距离相等（均为 $2r$），BCC中 $4r = \sqrt{3}a_1$，FCC中 $4r = \sqrt{2}a_2$，得 $\frac{a_1}{a_2} = \frac{\sqrt{2}}{\sqrt{3}} = \frac{\sqrt{6}}{3}$。
  3. 密度比：BCC晶胞含2个原子，FCC晶胞含4个原子。由 $\rho = \frac{nM}{N_A a^3}$ 得：

$$\frac{\rho_1}{\rho_2} = \frac{n_1}{n_2} \cdot \left(\frac{a_2}{a_1}\right)^3 = \frac{2}{4} \cdot \left(\frac{\sqrt{3}}{\sqrt{2}}\right)^3 = \frac{1}{2} \cdot \frac{3\sqrt{3}}{2\sqrt{2}} = \frac{3\sqrt{6}}{8}$$

课堂讲解建议：

  • 引入：从铁的同素异形体（如 $\alpha$-Fe 和 $\gamma$-Fe）引入，说明温度导致晶体结构转变。
  • 空间想象：利用图示1的3D交互，让学生旋转/观察晶胞，建立BCC和FCC的空间差异。
  • 关键转折：强调"最近邻距离相同"是整道题的桥梁条件，没有此条件则无法比较。
  • 密度讨论：引导学生思考——FCC配位数更高、堆积更密，为什么密度比不是简单的配位数比？（因为晶胞边长也变了）
  • 拓展提问：如果已知铁的摩尔质量和阿伏伽德罗常数，能否求出具体密度？（可以，代入 $a$ 的具体值即可）
