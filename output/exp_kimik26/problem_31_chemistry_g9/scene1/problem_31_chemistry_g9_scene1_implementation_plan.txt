[标签冲突检查]

列出所有标签预计坐标：
- "图1"/"图2"：(280, 390)
- "BCC"/"FCC"：(420, 130)
- "a₁"/"a₂"：(380, 375)
- "d = (√3/2)a₁"/"d = (√2/2)a₂"：(480, 290)
- "配位数"：(675, 180)
- "CN = 8"/"CN = 12"：(675, 210)
- "（顶点原子也为8）"：(675, 235)
- "步骤 x/4"：(400, 435)

逐对检查：
1. "图1"(280,390) 与 "a₁"(380,375)：间距√(100²+15²)≈101px ≥ 20px → 无冲突
2. "BCC"(420,130) 与 BUL原子(380,150)：间距√(40²+20²)≈45px ≥ 20px → 无冲突
3. "d = ..."(480,290) 与 BDR原子(540,310)：间距√(60²+20²)≈63px ≥ 20px → 无冲突
4. "d = ..."(480,290) 与 FCC右面心(500,255)：间距√(20²+35²)≈40px ≥ 20px → 无冲突
5. 配位数框(600~750,160~260) 与 结构右边缘(540)：水平间距60px ≥ 20px → 无冲突
6. "步骤 x/4"(400,435) 与 上一步按钮(300~390,455~485)：垂直间距20px，但x范围错开 → 无冲突
7. 所有顶部按钮(y=10~42) 与 结构(y>120)：垂直间距>78px → 无冲突
8. 底部按钮(y=455~485) 与 结构标签(y<390)：垂直间距>65px → 无冲突

结论：所有标签间距均≥20px，无重叠冲突。

[交互方案]
- 交互类型：多状态切换（BCC/FCC）+ 每个状态内分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  1. 「BCC（910℃以下）」按钮：位置(220,10)，170×32px。点击切换到BCC状态，重置为步骤0。
  2. 「FCC（910℃以上）」按钮：位置(410,10)，170×32px。点击切换到FCC状态，重置为步骤0。
  3. 「◀ 上一步」按钮：位置(300,455)，90×30px。点击回退一步，步骤0时禁用。
  4. 「下一步 ▶」按钮：位置(410,455)，90×30px。点击前进一步，步骤3时禁用。
  5. 步骤指示器：位置(400,435)，显示当前步骤（如"步骤 2/4"）。
- 教师操作流程：
  1. 教师先点击「BCC」按钮，展示图1完整晶胞（步骤0），讲解910℃以下纯铁结构。
  2. 点击「下一步」进入步骤1，引导学生关注体心原子。
  3. 点击「下一步」进入步骤2，展示8条连线，讲解最近邻距离公式 d=(√3/2)a₁。
  4. 点击「下一步」进入步骤3，右侧框弹出CN=8，得出配位数结论。
  5. 点击「FCC」按钮切换，重复上述4步流程，对比得出CN=12。
  6. 可随时点击「上一步」回退复习。

[技术实现]
- JS库选择：原生SVG（使用<svg>、<circle>、<line>、<text>、<rect>）。理由：晶体结构为简单几何图形（球、线、框），无需复杂绘图库；原生SVG配合class切换即可实现显示/隐藏/透明度变化。
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [800×500 SVG画布]
  +--------------------------------------------------+
  |  [BCC按钮]        [FCC按钮]                        |  y=10~42
  |                                                  |
  |        BCC/FCC标签(420,130)                       |  y=130
  |                                                  |
  |    BUL●━━━━━●BUR    [配位数]                      |  y=150
  |       /┃    /┃      [  CN = 8 ]                  |  y=180~240
  |      / ┃   / ┃      [浮动框]                     |
  |   FUL●━━━━━●FUR                                  |  y=200
  |    ┃ ┃   ┃ ┃                                     |
  |    ┃ ┃   ┃ ┃    d=(√3/2)a₁                      |  y=290
  |   FDL●━━━━━●FDR                                  |  y=360
  |      /     /                                     |
  |    BDL●━━━━━●BDR    图1  a₁                      |  y=310~390
  |                                                  |
  |           步骤 2/4                               |  y=435
  |      [◀ 上一步] [下一步 ▶]                       |  y=455~485
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机：用对象 `state = { crystal: 'bcc', step: 0 }` 管理当前状态。crystal取值为'bcc'或'fcc'，step取值为0~3。
  2. 渲染函数 `render()`：根据state设置各元素的display/opacity。使用classList控制分组显示（如`.bcc-only`、`.fcc-only`、`.step-1-plus`等）。
  3. 原子高亮：通过切换class改变fill、stroke-width、r属性。普通原子class `.atom-normal`，高亮原子class `.atom-highlight`。
  4. 连线显示：BCC的8条线和FCC的12条线默认display:none，在对应状态下通过step判断显示。
  5. 相邻晶胞原子（FCC）：使用较小的半径(r=10)和opacity 0.4，与晶胞内原子区分。
  6. 按钮禁用：step=0时禁用「上一步」，step=3时禁用「下一步」，通过设置opacity 0.5和pointer-events none实现。
  7. 切换晶体类型时，step自动重置为0。
  8. 动画：所有透明度变化使用CSS transition: opacity 0.3s ease，增强视觉连贯性。
- ID命名规范：所有交互元素ID以 `scene1-` 为前缀。例如：`scene1-btn-bcc`、`scene1-btn-fcc`、`scene1-btn-prev`、`scene1-btn-next`、`scene1-atom-body`、`scene1-atom-face-top`、`scene1-bond-group`、`scene1-cn-box`、`scene1-label-distance` 等。JS中严格使用 `getElementById` 获取元素。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })()` 中，避免全局变量污染，确保多场景合并时互不干扰。
