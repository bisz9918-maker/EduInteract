[图示主题与整合说明]
- 本图示主题：晶胞边长与原子半径的几何关系及边长比 a₁:a₂ 的推导
- 整合的步骤/概念：
  1) BCC体心立方晶胞的体对角线几何分析（4r = √3 a₁）
  2) FCC面心立方晶胞的面对角线几何分析（4r = √2 a₂）
  3) 边长比 a₁/a₂ 的代数推导与化简（√6/3）
- 教学价值：教师通过分步导航，先让学生观察两种晶胞的3D结构，再分别剖析体对角线和面对角线上的原子排列，最后推导出边长比。分步呈现避免信息过载，便于课堂节奏控制。

[分步序列]
- 步骤0（初始状态）：
  - 左右并列显示BCC和FCC晶胞，正常亮度
  - 显示标题"BCC"、"FCC"，标签 a₁、a₂，图1、图2
  - 两晶胞之间上方显示提示："最近邻铁原子距离相同 = 2r"
  - 隐藏所有截面图、推导公式、高亮线
  - 步骤指示器第1个圆点激活（#1565c0填充）

- 步骤1（BCC体对角线分析）：
  - 点击「下一步」触发
  - BCC晶胞：体对角线高亮显示（#1565c0，3px实线），从(170,210)到(202,98)，穿过体心原子
  - FCC晶胞：整体透明度降至0.3（淡化）
  - 左侧显示BCC截面外框及内部几何图（矩形+对角线+3原子）
  - 显示BCC截面标注：a₁（底边）、√2a₁（左边）、4r = √3a₁（斜边）、"体对角线"标题
  - 显示BCC推导公式："4r = √3 a₁" 和 "a₁ = 4r/√3"
  - 隐藏步骤0的中央提示文字
  - 步骤指示器第2个圆点激活

- 步骤2（FCC面对角线分析）：
  - 点击「下一步」触发
  - BCC晶胞：整体透明度降至0.3（淡化），隐藏BCC截面及公式
  - FCC晶胞：面对角线高亮显示（#2e7d32，3px实线），前平面对角线从(510,210)到(590,130)，穿过前面心原子
  - 右侧显示FCC截面外框及内部几何图（正方形+对角线+3原子）
  - 显示FCC截面标注：a₂（底边/左边）、4r = √2a₂（斜边）、"面对角线"标题
  - 显示FCC推导公式："4r = √2 a₂" 和 "a₂ = 4r/√2 = 2√2 r"
  - 步骤指示器第3个圆点激活

- 步骤3（边长比推导）：
  - 点击「下一步」触发
  - BCC和FCC晶胞均恢复为正常亮度（无高亮线，或保留淡色高亮线）
  - 隐藏左右截面大图
  - 中央区域显示推导流程：
    - 左侧：a₁ = 4r/√3（位置200,300）
    - 右侧：a₂ = 2√2 r（位置600,300）
    - 中央：向下箭头/大括号（位置400,300）
    - 下方结果：a₁/a₂ = (4r/√3)/(4r/√2) = √2/√3 = √6/3（位置400,360），红色粗体24px
  - 步骤指示器第4个圆点激活

- 教师可随时点击「上一步」回退到任意步骤复习。

[交互方案]
- 交互类型：分步按钮导航（◀ 上一步 / 下一步 ▶）
- 控件说明：
  1. 「上一步」按钮：位置(260, 455)，宽90×高32，点击回退到上一步骤，步骤0时禁用（opacity 0.4）
  2. 「下一步」按钮：位置(450, 455)，宽90×高32，点击前进到下一步，步骤3时禁用（opacity 0.4）

  4. 步骤文字："步骤 1/4" ~ "步骤 4/4"，位于(400, 495)
- 教师操作流程：
  1. 教师展示步骤0，说明两种晶胞及最近邻距离条件
  2. 点击「下一步」进入步骤1，讲解BCC体对角线等于4r，推导a₁
  3. 点击「下一步」进入步骤2，讲解FCC面对角线等于4r，推导a₂
  4. 点击「下一步」进入步骤3，综合两侧结果推导边长比，强调最终化简结果√6/3
  5. 可随时回退复习某一步骤的几何关系

[技术实现]
- JS库选择：原生 SVG + 原生 JavaScript。理由：本场景为静态几何图形与分步显隐控制，无复杂动画或数据可视化，原生SVG性能最优且无需额外库加载。
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  BCC                    FCC                      |
  |  [3D晶胞线框]           [3D晶胞线框]             |
  |  a₁                     a₂                       |
  |                                                  |
  |  [截面/推导区域 - 随步骤切换]                     |
  |  步骤0: 中央提示文字                              |
  |  步骤1: [BCC截面图 + 公式]   (FCC淡化)           |
  |  步骤2: (BCC淡化)   [FCC截面图 + 公式]           |
  |  步骤3:      [中央边长比推导公式]                 |
  |                                                  |
  |        [◀ 上一步]  ●●●●  [下一步 ▶]              |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：变量 `let currentStep = 0;`（范围0~3），每次点击按钮时更新状态并调用 `renderStep()`。
  2. 分组显隐：将每步涉及的SVG元素按功能分组（如 `scene2-bcc-highlight`、`scene2-bcc-section`、`scene2-fcc-section`、`scene2-step3-formula` 等），通过切换 CSS class `hidden`（opacity:0 + pointer-events:none）或 `dimmed`（opacity:0.3）实现过渡。过渡动画使用 CSS `transition: opacity 0.3s ease`。
  3. 高亮线条动画：体对角线和面对角线使用 SVG `stroke-dasharray` + `stroke-dashoffset` 实现绘制动画（0.5s），增强视觉引导。
  4. 按钮禁用逻辑：步骤0时禁用「上一步」，步骤3时禁用「下一步」，通过添加/移除 `disabled` class 控制样式。
  5. 步骤指示器：4个圆点用 `<circle>` 元素实现，当前步骤索引之前的圆点全部填充激活色，表示进度。
  6. 公式渲染：简单代数公式使用 SVG `<text>` + `<tspan>` 直接书写（如 "4r = √3 a₁"），无需MathJax，减少依赖。
  7. 晶胞坐标计算：采用简化透视投影（x向右，深度向左上偏移0.6:0.4，z向上），所有顶点坐标硬编码在实现中，确保渲染一致。
- ID命名规范：所有交互元素及可操控SVG组必须以 `scene2-` 为前缀。例如：
  - `scene2-bcc-cell`（BCC晶胞整体组）
  - `scene2-fcc-cell`（FCC晶胞整体组）
  - `scene2-bcc-body-diagonal`（BCC体对角线）
  - `scene2-fcc-face-diagonal`（FCC面对角线）
  - `scene2-bcc-section`（BCC截面图组）
  - `scene2-fcc-section`（FCC截面图组）
  - `scene2-step3-formula`（步骤3中央公式组）
  - `scene2-hint-text`（步骤0提示文字）
  - `scene2-btn-prev`、`scene2-btn-next`
  - `scene2-indicator-0` ~ `scene2-indicator-3`
  - JS中严格使用 `document.getElementById` 获取元素，禁止全局 class 查询，避免多场景合并时跨场景污染。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，变量不污染全局作用域。
