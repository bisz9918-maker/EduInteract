[图示主题与整合说明]
- 本图示主题：晶胞密度计算与密度比推导（纯铁 BCC→FCC 相变）
- 整合内容：均摊法求晶胞原子数 → 密度通用公式 → 代入边长关系 → 密度比化简 → 数值验证
- 教学价值：教师通过分步导航，逐层揭示从微观晶胞参数到宏观密度比的完整推导链；学生可跟随步骤建立"原子数→边长→密度"的定量关联，最终通过数值验证理解 FCC 堆积更致密的事实。

[交互方案]
- 交互类型：分步按钮导航（◀ 上一步 / 下一步 ▶）
- 控件说明：
  1. 「上一步」按钮：中心(310,470)，100×34，#1565c0填充白字，步骤0时 opacity=0.4 禁用。
  2. 「下一步」按钮：中心(490,470)，100×34，#1565c0填充白字，步骤4时 opacity=0.4 禁用。
  3. 步骤指示器：两按钮上方居中(400,448)，显示 "步骤 k/5"（k 从1开始计数，对应内部状态 0~4）。
- 教师操作流程：教师先点击「下一步」从公式进入晶胞原子数讲解；再点击「下一步」进入密度比公式代入；继续点击观看化简过程；最后一步展示数值验证与物理意义。可随时回退复习任意环节。

[技术实现]
- JS库选择：原生 SVG（无需额外库）。公式中的上标、下标通过 SVG tspan 的 dy 与 font-size 属性实现；分数线通过 SVG line 元素绘制；根号使用 Unicode "√" 字符。避免引入 MathJax 以降低复杂度和加载时间。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  [常驻密度公式栏  y=15~60]                        |
  |--------------------------------------------------|
  |                                                  |
  |  [主内容区 y=75~430，按步骤切换]                  |
  |   步骤0: 符号说明(2×2)                            |
  |   步骤1: [BCC晶胞]        [FCC晶胞]               |
  |   步骤2: 密度比公式 + 代入值                      |
  |   步骤3: 四行推导 + 红色高亮框                    |
  |   步骤4: 大结果 + 三段结论                        |
  |                                                  |
  |--------------------------------------------------|
  |  [控件栏 y=440~490]   ◀ 上一步  步骤k/5  下一步 ▶ |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机：变量 currentStep ∈ {0,1,2,3,4}，初始化 0。
  2. 元素分组：每个步骤的视觉元素放入独立的 SVG <g> 中（id="scene3-step0-group" 至 "scene3-step4-group"），通过设置 display="none" / "block" 切换。
  3. 常驻元素（公式栏、按钮、指示器）始终显示，不参与步骤切换。
  4. 按钮事件：点击时更新 currentStep，隐藏所有步骤组，显示对应组，更新指示器文本，检查边界以禁用/启用按钮。
  5. 动画：步骤切换不使用过渡动画（避免认知干扰），直接瞬间切换。
  6. 晶胞绘制：后面正方形 stroke-dasharray="4,3"，前面正方形实线；原子统一用 circle，避免 path 复杂化。
  7. 文本对齐：所有标题、公式、结论使用 text-anchor="middle"，x=400 或对应区域中心；参数标签使用 text-anchor="start" 左对齐时需在坐标表中特别注明（本计划统一使用居中）。
- ID命名规范：所有交互元素 ID 必须以 `scene3-` 为前缀。例如：`scene3-formula-box`、`scene3-bcc-cell`、`scene3-fcc-cell`、`scene3-step0-group` ~ `scene3-step4-group`、`scene3-btn-prev`、`scene3-btn-next`、`scene3-step-indicator`。
- IIFE隔离：所有 JavaScript 包在 `(function() { ... })()` 中执行，避免多场景合并时变量污染。
