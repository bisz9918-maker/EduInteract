[图示主题与整合说明]
- 本图示主题：氨气溶于水引发的压强变化与酚酞变色现象（对应第(2)问）
- 整合的步骤/概念：密闭准备 → 挤水入瓶 → NH₃溶解 → B瓶压强骤降 → 打开活塞a、b → 大气压将水压入导管 → 酚酞遇碱变红
- 教学价值：教师通过分步导航，逐帧展示"挤水→溶解→降压→倒吸→变色"的完整因果链，帮助学生理解气体溶解导致压强差、压强差驱动液体流动、碱性溶液使酚酞变色三个核心知识点。

  2. 「下一步」按钮：位于画布底部(440,450)，尺寸100×36。点击前进到下一状态，步骤4时禁用。

- 教师操作流程：

  2. 点击「下一步」进入步骤1，讲解胶头滴管挤水动作，观察NH₃分子溶解消失，强调"极易溶于水"。
  3. 点击「下一步」进入步骤2，讲解气体分子减少导致压强骤降，观察红色压强箭头。
  4. 点击「下一步」进入步骤3，讲解打开活塞a、b后大气压作用，观察水流方向箭头。
  5. 点击「下一步」进入步骤4，讲解水被压入B瓶后酚酞变红，观察红色液体填充，总结氨水呈碱性。
  6. 可随时点击「上一步」回退复习。

[技术实现]
- JS库选择：原生 SVG + 原生 JavaScript。理由：本场景以静态几何装置和分步显隐为主，无需复杂数据绑定或3D渲染，原生SVG可精确控制每个图形元素的坐标和样式，且便于通过class/id切换状态。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图（ASCII）：
  ```
  0    100   200   300   400   500   600   700   800
  +-----+-----+-----+-----+-----+-----+-----+-----+  0
  |           [A]       [B]  [滴管]  标签           | 50
  |          (A瓶)    (B瓶)   |    胶头滴管        | 100
  |          HCl      NH₃     |    标签            | 150
  |            \        /     |                    | 200
  |       c----○---○----a     |  步骤标签区        | 250
  |             \   /         |  (动态)            | 300
  |              \b/  大气压  |                    | 350
  |            [烧杯] 水      |                    | 400
  |                                             | 440
  |      [◀上一步]  步骤 1/5  [下一步▶]          | 490
  +-----+-----+-----+-----+-----+-----+-----+-----+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `let currentStep = 0;` 控制0~4共5个状态。每步通过一个 `renderStep()` 函数统一更新所有元素的 display/opacity/class。
  2. 元素分组管理：将各步骤专属元素包在 `<g id="scene2-step1-group">` 等组中，通过组级 display 控制整体显隐，减少单个元素操作。
  3. 活塞状态切换：使用 SVG class 切换。关闭 class `.scene2-piston-closed` {fill:#bdbdbd; stroke:#000; stroke-width:1}；打开 class `.scene2-piston-open` {fill:#fff; stroke:#2e7d32; stroke-width:3}。步骤3时通过 `classList.replace` 切换活塞a、b。
  4. 动画实现：
     - 水滴下落：使用 CSS `@keyframes scene2-drop` 控制 transform translateY，或 JS `requestAnimationFrame` 修改 cy 属性。
     - 分子渐隐：CSS `transition: opacity 0.5s ease;` 配合 class `.scene2-fade-out` {opacity:0}。
     - 红色液体填充：使用 SVG `<clipPath>` 或 `<mask>` 配合 CSS transition 实现高度从0到目标值的展开动画；对B瓶底部液体使用 `scaleY` transform-origin设为底部。
  5. 事件绑定：上一步/下一步按钮绑定 `click` 事件，更新 `currentStep` 后调用 `renderStep()` 和 `updateButtons()`。
  6. 按钮禁用逻辑：`updateButtons()` 在步骤0时禁用「上一步」，步骤4时禁用「下一步」。
- ID命名规范：所有交互元素及SVG图形ID必须以 `scene2-` 为前缀。例如：`scene2-flask-a`、`scene2-flask-b`、`scene2-piston-a`、`scene2-piston-b`、`scene2-piston-c`、`scene2-beaker`、`scene2-molecule-group`、`scene2-water-drop`、`scene2-pressure-arrow`、`scene2-flow-arrow`、`scene2-red-liquid`、`scene2-label-nh3-soluble`、`scene2-label-pressure`、`scene2-label-atm`、`scene2-label-phenol-red`、`scene2-btn-prev`、`scene2-btn-next`、`scene2-step-text`。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免全局变量污染，确保多场景合并时互不干扰。
- 容器结构：外层 div `position:relative; width:800px; height:500px;`，内部 SVG 占满，HTML 按钮通过 `position:absolute` 叠在 SVG 上方底部区域。
