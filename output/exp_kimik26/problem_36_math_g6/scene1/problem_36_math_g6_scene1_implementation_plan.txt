[图示主题与整合说明]
- 本图示主题：三圆整体覆盖与容斥原理
- 整合的步骤/概念：
  1) 呈现三个等圆的位置关系与水平直线 a（过圆心 A、B）；
  2) 依次高亮两对重合区域（A∩B、B∩C），并标注重合面积均为 x；
  3) 列出容斥原理公式 3S − x − x = 2S + 2；
  4) 化简得到关键方程 S = 2x + 2。
- 教学价值：教师通过分步导航控制课堂节奏，每一步只呈现当前需要的视觉信息，避免信息过载；学生可直观看到“重合区域被重复计算”这一核心概念。

[分步序列]
- 步骤0（初始状态）：
  显示元素：圆A、圆B、圆C、直线a、圆心标签A/B、直线标签a、三个面积标签S。
  隐藏元素：两个重合区域、x标签、提示文本、公式框、结果文本。
  教学意图：让学生先观察三圆位置与直线a的位置关系。

- 步骤1（点击「下一步」）：
  视觉变化：AB重合区域以 #c62828 透明度35% 淡入（opacity 0→1，duration 300ms）；标签 "x" 在(390,225)处淡入。
  教学意图：指出圆A与圆B存在重合，设其面积为 x。

- 步骤2（点击「下一步」）：
  视觉变化：BC重合区域以相同红色淡入；标签 "x" 在(472,255)处淡入；提示文本 "两块重合面积相等" 在(472,295)处淡入。
  教学意图：强调两块重合面积相等，均为 x。

- 步骤3（点击「下一步」）：
  视觉变化：右侧出现公式背景框（淡入）；框内依次显示三行公式文本（逐行淡入，每行间隔150ms）。
  公式内容：
    总覆盖面积
    = 3S − x − x
    = 2S + 2
  教学意图：建立容斥原理方程。

- 步骤4（点击「下一步」）：
  视觉变化：公式框下方(600,300)处以蓝色高亮显示 "∴ S = 2x + 2"（scale 0.9→1.0 + opacity 0→1，duration 400ms，easing ease-out）。
  教学意图：展示化简结果，得到第一个关键方程。

- 教师可随时点击「上一步」回退到任意步骤复习。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「上一步」按钮：位于画布底部居中偏左 (280,460)，80×34px；点击后回退一个步骤，在步骤0时禁用（opacity 0.4，pointer-events none）。
  2. 「下一步」按钮：位于画布底部居中偏右 (440,460)，80×34px；点击后前进一个步骤，在步骤4时禁用。
  3. 步骤指示器：位于两按钮之间 (370,468)，显示 "步骤 k/4"，font-size=13px，颜色#666。
- 教师操作流程：
  1. 教师加载图示，学生看到三圆与直线a的初始布局；
  2. 教师点击「下一步」，红色重合区域1出现，讲解“A与B重合面积为x”；
  3. 教师点击「下一步」，红色重合区域2出现，讲解“两块重合面积相等”；
  4. 教师点击「下一步」，右侧出现容斥公式，讲解“总面积=3S−2x=2S+2”；
  5. 教师点击「下一步」，高亮化简结果 S=2x+2；
  6. 可随时点击「上一步」回退复习。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无需外部库）。理由：本场景为静态几何图形与简单显隐/淡入淡出动画，原生SVG路径即可精确描述透镜形交集，原生JS控制class切换足够。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  0    100  200  300  400  500  600  700  800
  +----+----+----+----+----+----+----+----+
  |         [S]    [S]                     |  120
  |                                        |  
  |    ~~~~~~直线a~~~~~~~~~~~~~~~~~~~~~>a   |  220
  |         (A)    (B)                     |  
  |          ◯───◯                         |  
  |           \ /     ◯(C)                 |  
  |            x      /\                   |  
  |                  /  \                  |  
  |                 x    [S]               |  
  |                                        |  
  |    +----------------+  +------------+  |  
  |    | 总覆盖面积     |  | ∴ S=2x+2   |  |  
  |    | =3S−x−x       |  |            |  |  
  |    | =2S+2         |  |            |  |  
  |    +----------------+  +------------+  |  
  |                                        |  
  |         [◀上一步] 步骤k/4 [下一步▶]     |  460
  +----+----+----+----+----+----+----+----+
  0                                       500
  ```

- 关键实现要点：
  1. 状态机设计：使用整数 currentStep（0~4），updateScene(step) 函数根据步骤值统一控制所有元素的显隐与动画类名。
  2. 重合区域绘制：
     - AB交集路径：M 390 187 A 60 60 0 0 1 390 253 A 60 60 0 0 0 390 187 Z
     - BC交集路径：M 445 280 A 60 60 0 0 0 500 225 A 60 60 0 0 0 445 280 Z
     使用 <path> 元素，初始 display:none，步骤触发时改为 display:block 并添加淡入CSS动画。
  3. 动画曲线：
     - 淡入：opacity 0→1，transition: opacity 300ms ease-out；
     - 结果高亮：额外添加 transform: scale(0.95)→scale(1)，transition: all 400ms cubic-bezier(0.25, 0.46, 0.45, 0.94)。
  4. 公式逐行显示：步骤3中，三行 <tspan> 初始 opacity:0，通过 setTimeout 依次（间隔150ms）添加 .visible 类触发transition。
  5. 事件绑定：上一步/下一步按钮分别绑定 click 事件，更新 currentStep 后调用 updateScene()，并更新按钮禁用状态与步骤指示器文本。
  6. 按钮禁用逻辑：
     - currentStep === 0 时，上一步按钮添加 disabled 样式；
     - currentStep === 4 时，下一步按钮添加 disabled 样式。

- ID 命名规范：
  所有交互元素 ID 必须以 `scene1-` 为前缀：
  - SVG元素：scene1-circle-a, scene1-circle-b, scene1-circle-c, scene1-line-a, scene1-overlap-ab, scene1-overlap-bc
  - 标签：scene1-label-a, scene1-label-b, scene1-label-a-line, scene1-label-s-a, scene1-label-s-b, scene1-label-s-c, scene1-label-x-ab, scene1-label-x-bc, scene1-hint-equal
  - 公式：scene1-formula-box, scene1-formula-text, scene1-formula-result
  - 控件：scene1-prev, scene1-next, scene1-step-indicator
  JS 中严格使用 document.getElementById 获取元素，禁止 querySelectorAll 配合全局 class。

- IIFE 隔离：
  所有 JavaScript 代码包裹在 (function() { ... })() 中，避免多场景合并时变量污染全局作用域。

- CSS 类建议：
  .scene1-hidden { display: none; }
  .scene1-fade-in { opacity: 1; transition: opacity 300ms ease-out; }
  .scene1-fade-out { opacity: 0; transition: opacity 200ms ease-in; }
  .scene1-highlight { fill: #c62828; fill-opacity: 0.35; }
  .scene1-formula-result { fill: #1565c0; font-size: 20px; font-weight: bold; }
