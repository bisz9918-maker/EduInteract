[分步序列]
- 初始状态（步骤0）：显示三圆与直线a的基础图形。显示元素：直线a、圆A/B/第三个圆（黑色轮廓）、圆心标签A/B、直线标签a。公式框显示提示文字："三个面积都是S的圆，桌面被覆盖面积 = 2S + 2"。
- 步骤1：点击「下一步」→ 圆A下半圆与圆B下半圆填充浅蓝色(#1565c0, 15%)，出现"S/2"标签（圆A下方280,230；圆B下方400,230）。公式框提示："圆心在a上，故下半圆面积恰为 S/2"。
- 步骤2：点击「下一步」→ 第三个圆整体填充浅绿色(#2e7d32, 15%)，出现"S"标签(480,275)。公式框提示："第三个圆整体位于直线a下方，面积为 S"。
- 步骤3：点击「下一步」→ A∩B在a下方的部分填充红色(#c62828, 50%)，出现"x/2"标签(340,215)。公式框提示："A、B圆心均在a上且半径相等，交集关于a对称，故a下方占一半，面积为 x/2"。
- 步骤4：点击「下一步」→ B∩第三个圆在a下方的部分填充红色(#c62828, 50%)，出现"x"标签(430,235)。公式框提示："该交集完全位于a下方，面积为 x"。
- 步骤5：点击「下一步」→ 公式框显示汇总公式："S/2 + S/2 + S − x/2 − x = 9"，并高亮化简结果"2S − 3x/2 = 9"。图形元素无变化。
- 步骤6：点击「下一步」→ 公式框扩展显示联立求解过程：方程① S = 2x + 2（来自Scene 1），方程② 2S − 3x/2 = 9，代入过程 2(2x+2) − 1.5x = 9 → 2.5x = 5 → x = 2, S = 6。关键步骤文字用#1565c0高亮。
- 步骤7（最终步骤）：点击「下一步」→ 公式框显示验证："总覆盖 = 3×6 − 2×2 = 14 = 2×6+2" 与 "a下方 = 3+3+6−1−2 = 9"，最终结果"S = 6"用#2e7d32绿色高亮加粗，底部显示"答案：C．6"。
（教师可随时点击「上一步」回退复习，步骤指示器实时更新）

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位置(300,450)，大小100×32，点击回退到上一分步，步骤0时禁用
  - 「下一步」按钮：位置(420,450)，大小100×32，点击前进到下一分步，步骤7时禁用
  - 步骤指示器：位置(380,485)，显示当前步骤编号"步骤 X / 7"
- 教师操作流程：
  1. 教师加载图示，向学生展示步骤0的三圆基础图形，回顾Scene 1结论
  2. 点击「下一步」进入步骤1，讲解圆A/B下半圆面积各为S/2
  3. 继续点击「下一步」依次展示第三个圆、两个交集区域的面积贡献
  4. 进入步骤5，引导学生汇总公式
  5. 进入步骤6，联立Scene 1方程求解
  6. 进入步骤7，验证答案并确认选项C
  7. 可随时点击「上一步」回退到任意步骤复习

[技术实现]
- JS库选择：原生SVG（简单几何与路径填充首选，无需引入外部库，保证轻量与Scene 1一致）
- 画布尺寸：800 × 500 px（固定画布规则）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |                                                  |
  |    A         B                                   |
  |   (○)───∩───(○)────────────────── a              |
  |    │   x/2   │                                   |
  |   S/2       S/2        S                         |
  |             │      (○)                           |
  |             └──∩────┘                            |
  |              x                                   |
  |                                                  |
  |  [公式文本框：根据步骤显示方程与提示]               |
  |                                                  |
  |        [◀上一步]  步骤 X/7  [下一步▶]             |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `currentStep`（0~7），每个步骤对应一个显示配置对象，记录该步骤应显示的元素ID列表。
  2. 半圆裁剪：使用SVG `<clipPath>` 定义半平面 `y≥190`（矩形从y=190到画布底部），对圆A/B填充应用clip-path实现下半圆填充。
  3. 交集路径计算：
     - A∩B下半：两圆交点(340,154)与(340,226)，用path绘制从(340,190)→沿圆A弧到(340,226)→沿圆B弧回到(340,190)的封闭区域。
     - B∩第三圆：两圆交点约(390,259)与(470,196)，用path绘制完整交集透镜区域（两弧封闭）。
  4. 动画曲线：步骤切换时，新增元素使用CSS transition（opacity 0→1，duration 300ms，ease-out），无位移动画避免坐标混乱。
  5. 事件绑定：按钮绑定click事件，更新currentStep后调用 `renderStep()` 函数，该函数遍历所有元素按配置显示/隐藏。
  6. 公式文本框：使用SVG `<foreignObject>` 嵌入HTML `<div>`，通过innerHTML切换各步骤的公式内容，支持复杂排版与高亮样式。
- ID命名规范：所有交互元素ID必须以 `scene2-` 为前缀，例如：
  - `scene2-circle-a`, `scene2-circle-b`, `scene2-circle-c`
  - `scene2-fill-a-lower`, `scene2-fill-b-lower`, `scene2-fill-c`
  - `scene2-overlap-ab-lower`, `scene2-overlap-bc`
  - `scene2-label-a`, `scene2-label-s2-left`, `scene2-label-x2`
  - `scene2-formula-box`, `scene2-btn-prev`, `scene2-btn-next`
  JS中严格使用 `document.getElementById('scene2-xxx')` 获取元素，禁止querySelectorAll配合全局class。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })()` 中，避免多场景合并时变量污染。
- 与Scene 1视觉连贯：三圆半径统一为70px，圆A/B圆心y坐标190（与Scene 1直线a位置一致），圆心水平间距120px，确保学生视觉认知无缝衔接。
