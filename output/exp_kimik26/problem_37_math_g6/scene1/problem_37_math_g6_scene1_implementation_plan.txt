[图示主题与整合说明]
- 本图示主题：中心投影下物体影子长度与物距关系的动态探究
- 整合的步骤/概念：1. 题目基础 setup（路灯、地面、杯子及标注 a）；2. 影子形成的光路原理；3. 相似三角形辅助线与比例推导；4. 通过滑块改变物距 a 实时观察影子长度 L 的变化规律；5. 结论验证与选项判断
- 教学价值：教师通过分步导航按「感知现象→理解原理→数学推导→实验验证」的认知递进讲解，最后一步用滑块实时演示，让学生直观验证「a 越小 → L 越短」，确定答案为 B

[分步序列]
步骤0「题意初始化」：
- 显示：灯杆、光源、光晕、地面、杯子（含h标注）、a标注
- 隐藏：影子、L标注、光线、大三角形、小三角形、公式区、滑块及数值
- 目的：教师引入题目，学生读取已知条件

步骤1「影子显现」：
- 新增显示：影子（红色半透明矩形）、L标注
- 其他保持不变
- 目的：建立 a 与影子的直观关联

步骤2「光路原理」：
- 新增显示：光线（灰色虚线，从光源经杯子顶端到影子末端）
- 其他保持不变
- 目的：解释影子成因

步骤3「相似三角形」：
- 新增显示：大三角形（灯杆-地面-光线，绿色虚线+10%透明度填充）、小三角形（杯子-影子-光线，绿色虚线+15%透明度填充）
- 其他保持不变
- 目的：展示相似关系，为推导铺垫

步骤4「公式推导」：
- 新增显示：公式区文字（右上角）
  - 第1行：「由相似三角形：」
  - 第2行：「h / H = L / (a + L)」
  - 第3行：「推导得：」
  - 第4行：「L = ah / (H − h)」（L、a、h 用 #2e7d32 高亮）
  - 第5行：「∵ H、h 为定值」
  - 第6行：「∴ L 与 a 成正相关」
- 其他保持不变
- 目的：数学推导，揭示正相关关系

步骤5「交互验证」：
- 新增显示：滑块（轨道+thumb）、滑块标签「物距 a (m)」、实时数值 a 和 L
- 所有此前元素均保持显示（三角形辅助线保留但可降低至5%透明度避免干扰，或保持原样）
- 滑块可拖动，a 范围 0.5m–5.0m，杯子、影子、光线、三角形、所有动态标注实时跟随更新
- 公式区追加第7行：「验证：a 越小 → L 越短」（#c62828）
- 目的：课堂实时验证，确认答案 B

[标签冲突检查]
固定标签坐标：
- 标签「S」：(200, 105)
- 标签「H」：(225, 255)

动态标签坐标（初始 a=2.0m）：
- 标签「a」：(280, 418)
- 标签「h」：(386, 358)
- 标签「L」：(376, 418)

公式区坐标范围：(520, 165) 至 (720, 320)

逐对检查：
- 「S」(200,105) 与 「H」(225,255)：间距 ≈ 152px → 不冲突
- 「S」(200,105) 与 光晕顶部(y=116)：文字底部约113，在光晕上方3px → 不冲突（光晕为半透明装饰）
- 「H」(225,255) 与 灯杆(200,140~380)：水平间距25px → 不冲突
- 「a」(280,418) 与 「L」(376,418)：间距 96px ≥ 20px → 不冲突
- 「a」(280,418) 与 「h」(386,358)：间距 ≈ 122px → 不冲突
- 「L」(376,418) 与 「h」(386,358)：间距 ≈ 61px → 不冲突
- 公式区(520~720, 165~320) 与 所有其他标签：水平距离均 > 100px → 不冲突

极值动态检查（a=0.5m 时最紧凑）：
- 「a」移至 (220, 418)，「L」移至 (244, 418)：间距 24px ≥ 20px → 不冲突
- 「h」移至 (266, 358)，与「a」(220,418) 间距 ≈ 68px → 不冲突

极值动态检查（a=5.0m 时最稀疏）：
- 「a」移至 (400, 418)，「L」移至 (640, 418)：间距 240px → 不冲突
- 大三角形斜边在 x=520 处 y≈300，公式区从 x=520 开始但文字在右侧，斜边向左下延伸不遮挡文字 → 不冲突

结论：所有标签布局无冲突。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶），最后一步（步骤5）嵌入滑块实时调节
- 控件说明：
  1. 「◀ 上一步」按钮：位置(260,455)，尺寸100×36，点击回退到上一分步
  2. 「下一步 ▶」按钮：位置(440,455)，尺寸100×36，点击进入下一分步
  3. 步骤指示器：位置(400,448)，显示「步骤 X / 6」，居中
  4. 滑块（步骤5出现）：轨道位置(220,424)，宽360，范围0.5~5.0，步长0.1，拖动实时改变物距a
  5. 滑块数值显示（步骤5出现）：位置(600,424)显示a值，(680,424)显示L值
- 教师操作流程：
  1. 加载后进入步骤0，教师介绍题目条件（路灯高H、杯子高h、物距a）
  2. 点击「下一步」进入步骤1，影子出现，教师提问影子与a的关系
  3. 点击「下一步」进入步骤2，光线出现，教师讲解中心投影原理
  4. 点击「下一步」进入步骤3，相似三角形出现，教师引导学生发现相似关系
  5. 点击「下一步」进入步骤4，公式出现，教师推导并强调L与a正相关
  6. 点击「下一步」进入步骤5，滑块激活，教师拖动改变a，让学生观察影子实时变长/变短，验证「a越小→L越短」，确定答案B
  7. 讲解过程中可随时点击「上一步」回退到任意步骤复习

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无外部库）。理由：本场景为2D几何图示，元素均为简单形状（线段、矩形、圆形、多边形、文本），原生SVG完全满足；无需复杂动画或数据可视化库。
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  公式区(右上)                                      |
  |     由相似三角形...                                 |
  |                                                    |
  |  S(光源)                                           |
  |   ●                                                |
  |   | 灯杆(H)                                        |
  |   |                                                |
  |   |          杯子(h)                               |
  |   |            ┌──┐                                |
  |   |            │  │                                |
  |   |            └──┘                                |
  |   |            |←─L──→| 影子(红)                   |
  +---|------------|-------|--------------------------+
  |   |←────a────→|       地面                        |
  |                                                    |
  |  [滑块区: 物距 a (m) |==========o=====| a=2.0 L=0.40]  (步骤5显示)
  |                                                    |
  |        [◀ 上一步]  步骤 3/6  [下一步 ▶]            |
  +--------------------------------------------------+
  [控件栏 y=440~490]
  ```
- 关键实现要点：
  1. 状态机设计：
     - 全局状态对象 `{ step: 0, a: 2.0 }`
     - 步骤切换函数 `setStep(n)`：更新 step，根据步骤号显示/隐藏对应元素组（通过设置 SVG g 元素或 HTML 元素的 display 属性）
     - 滑块事件监听：input 事件触发 `updateScene(aValue)`，实时重算所有动态坐标并更新 SVG 属性
  2. 坐标计算函数 `calcCoordinates(aMeter)`：
     - 输入 a（米），返回 { cupCenterX, L_px, shadowEndX, ... }
     - 所有动态元素（杯子、影子、光线、三角形、标注箭头、标签位置）均由此函数驱动
  3. 元素更新策略：
     - 杯子：更新 rect 的 x 属性（cupCenterX−12）
     - 影子：更新 rect 的 x 和 width 属性
     - 光线：更新 line 的 x2,y2（始终为 shadowEndX, 380）
     - 大三角形：更新 polygon 的 points 字符串
     - 小三角形：更新 polygon 的 points 字符串
     - 标注箭头：更新 line 的 x1,y1,x2,y2
     - 标注文字：更新 text 的 x,y 属性（通过 setAttribute）
  4. 动画曲线：无需复杂动画；滑块拖动时直接同步更新（无过渡），步骤切换时直接显示/隐藏（无淡入淡出），确保教学演示的即时响应性
  5. 事件绑定：
     - 上一步/下一步按钮绑定 click 事件
     - 滑块绑定 input 事件（实时响应拖动）
     - 所有事件处理函数内部读取当前状态，更新视图
  6. 步骤0~4的 a 值固定为 2.0m；步骤5时滑块初始值 2.0m，教师拖动后动态更新
  7. 按钮状态管理：步骤0时「上一步」禁用（disabled），步骤5时「下一步」禁用；滑块仅在步骤5时显示（display: block/flex），其他步骤隐藏（display: none）
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀，例如：
  - `scene1-lamp-pole`（灯杆）
  - `scene1-light-source`（光源）
  - `scene1-light-glow`（光晕）
  - `scene1-ground`（地面）
  - `scene1-cup`（杯子轮廓）
  - `scene1-cup-fill`（杯子填充）
  - `scene1-shadow`（影子）
  - `scene1-ray`（光线）
  - `scene1-triangle-big`（大三角形）
  - `scene1-triangle-small`（小三角形）
  - `scene1-label-s`（光源标签）
  - `scene1-label-h`（h标签）
  - `scene1-label-a`（a标签）
  - `scene1-label-l`（L标签）
  - `scene1-formula-group`（公式区容器）
  - `scene1-slider`（滑块）
  - `scene1-slider-val-a`（a数值显示）
  - `scene1-slider-val-l`（L数值显示）
  - `scene1-btn-prev`（上一步按钮）
  - `scene1-btn-next`（下一步按钮）
  - `scene1-step-indicator`（步骤指示器）
  JS 中严格使用 `document.getElementById` 获取元素，禁止 querySelectorAll 配合全局 class，避免多场景合并时跨场景污染
- IIFE 隔离：所有 JavaScript 代码包裹在 `(function() { ... })();` 中，所有变量和函数均为局部作用域
