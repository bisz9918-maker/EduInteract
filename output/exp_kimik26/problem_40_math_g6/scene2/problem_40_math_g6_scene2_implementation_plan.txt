[图示主题与整合说明]
- 本图示主题：正方体展开图相对面分析——"对面图案都相同"的选项判定
- 整合内容：
  1. 四选项总览（A/B/C/D），2×2网格展示四个1-4-1十字展开图；
  2. 按A→B→C→D顺序逐一高亮各选项的三对相对面（中1-中3、中2-中4、上-下）；
  3. 根据相对面图案是否相同，显示✗或✓；
  4. 最终步骤锁定正确答案B，显示结论文字。
- 教学价值：教师通过分步导航，带领学生先独立观察四个展开图，再逐一验证每对相对面的图案是否相同，培养空间想象能力与"隔一相对"的展开图判定技巧。学生可清晰看到错误选项至少存在一对相对面图案不同，从而理解排除过程。

[分步序列]
- 步骤0「四选项总览」：
  * 显示A/B/C/D四个展开图，全部正常透明度(opacity=1)
  * 显示所有正方形边框(1px)及内部图案
  * 显示"A"/"B"/"C"/"D"标签
  * 不显示任何高亮框、相对面标注、对错标记、结论文字
  * 教师可让学生先独立观察思考

- 步骤1「分析选项A」：
  * 选项A边框加粗为2px，其余选项透明度降至0.3
  * 在A内部：
    - A-中1与A-中3添加红色高亮（相对面1：心形-笑脸，图案不同）
    - A-中2与A-中4添加蓝色高亮（相对面2：笑脸-心形，图案不同）
    - A-上与A-下添加绿色高亮（相对面3：太阳花-太阳花，图案相同）
  * 显示A的三个相对面标注（相对面1/2/3）
  * 显示A的红色"✗"（因存在图案不同的相对面）
  * 教师讲解：A中至少有一对相对面图案不同，排除A

- 步骤2「分析选项B」：
  * 选项B边框加粗为2px，其余选项透明度降至0.3
  * 在B内部：
    - B-中1与B-中3添加红色高亮（相对面1：心形-心形，相同）
    - B-中2与B-中4添加蓝色高亮（相对面2：太阳花-太阳花，相同）
    - B-上与B-下添加绿色高亮（相对面3：笑脸-笑脸，相同）
  * 显示B的三个相对面标注
  * 显示B的绿色"✓"（三对均相同）
  * 教师讲解：B的三对相对面图案全部相同，暂时保留

- 步骤3「分析选项C」：
  * 选项C边框加粗为2px，其余选项透明度降至0.3
  * 在C内部：
    - C-中1与C-中3添加红色高亮（相对面1：心形-心形，相同）
    - C-中2与C-中4添加蓝色高亮（相对面2：笑脸-太阳花，不同）
    - C-上与C-下添加绿色高亮（相对面3：笑脸-太阳花，不同）
  * 显示C的三个相对面标注
  * 显示C的红色"✗"
  * 教师讲解：C存在图案不同的相对面，排除C

- 步骤4「分析选项D」：
  * 选项D边框加粗为2px，其余选项透明度降至0.3
  * 在D内部：
    - D-中1与D-中3添加红色高亮（相对面1：心形-太阳花，不同）
    - D-中2与D-中4添加蓝色高亮（相对面2：笑脸-笑脸，相同）
    - D-上与D-下添加绿色高亮（相对面3：太阳花-心形，不同）
  * 显示D的三个相对面标注
  * 显示D的红色"✗"
  * 教师讲解：D存在图案不同的相对面，排除D

- 步骤5「结论」：
  * 选项B边框加粗，正常透明度；其余选项透明度0.3
  * 在B内部再次高亮三对相对面（同色填充+虚线边框）
  * 显示B的三个相对面标注及绿色"✓"
  * 隐藏A/C/D的相对面标注和对错标记
  * 显示结论文字"正确答案：B"（位于四格网格正下方居中，y=420）
  * 教师总结：只有选项B满足"对面图案都相同"的条件

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  * 「上一步」按钮：位于(280, 455)，宽100×高36，圆角4px，背景#f5f5f5，边框#ccc；点击回退到上一分析步骤；在步骤0时禁用（opacity 0.4，cursor not-allowed）
  * 「下一步」按钮：位于(420, 455)，宽100×高36，圆角4px，背景#2196f3，文字白色；点击进入下一分析步骤；在步骤5时禁用

- 教师操作流程：
  1. 教师加载图示，步骤0显示四选项总览，让学生先独立观察；
  2. 点击「下一步」进入步骤1，聚焦选项A，教师引导学生发现A中存在图案不同的相对面；
  3. 继续点击「下一步」依次分析B、C、D；
  4. 到达步骤5，显示结论"正确答案：B"；
  5. 讲解过程中可随时点击「上一步」回退，重新验证某选项。

[技术实现]
- JS库选择：原生SVG（所有元素为简单几何图形与路径，无需复杂图表库）
- 画布尺寸：800 × 500 px（SVG viewBox="0 0 800 500"）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |  [A]              [B]                             |
  |  十字展开图        十字展开图                      |
  |  (太阳花/心形/笑脸) (笑脸/心形/太阳花)             |
  |                                                   |
  |  [C]              [D]                             |
  |  十字展开图        十字展开图                      |
  |                                                   |
  |         正确答案：B  （步骤5显示）                  |
  |                                                   |
  |  [◀ 上一步]    步骤 X/5    [下一步 ▶]             |
  +--------------------------------------------------+
  坐标：A(163,32)  B(425,32)  C(163,240)  D(425,240)
  按钮y=455  结论y=420  步骤文字y=490
  ```
- 关键实现要点：
  1. 状态机设计：变量 `currentStep`（0~5），每次点击按钮时更新，调用 `renderStep()` 统一渲染。
  2. 渲染逻辑 `renderStep()`：
     - 先重置所有选项为opacity=1、边框1px、隐藏所有高亮/标注/对错标记；
     - 根据currentStep，设置当前分析选项opacity=1+边框2px，其余非当前选项opacity=0.3；
     - 对当前分析选项（或步骤5的B选项），给对应正方形添加高亮class（填充+虚线边框）；
     - 显示当前选项的相对面标注和对错标记；
     - 步骤5额外显示结论文字，并隐藏A/C/D的标注和标记。
  3. 图案绘制：每个图案定义为<symbol>（id如scene2-heart、scene2-smile、scene2-flower），在正方形内用<use>引用，x/y定位使图案居中。
  4. 高亮class定义（CSS）：
     - .scene2-hl-red { fill: #ffcdd2; fill-opacity: 0.3; stroke: #c62828; stroke-width: 1; stroke-dasharray: 4,2; }
     - .scene2-hl-blue { fill: #bbdefb; fill-opacity: 0.3; stroke: #1565c0; stroke-width: 1; stroke-dasharray: 4,2; }
     - .scene2-hl-green { fill: #c8e6c9; fill-opacity: 0.3; stroke: #2e7d32; stroke-width: 1; stroke-dasharray: 4,2; }
  5. 显示/隐藏控制：所有相对面标注、对错标记、结论文字默认设置 `visibility: hidden`（或display:none），通过JS切换class名（如.scene2-show）控制显示。
  6. 动画曲线：无需复杂动画，步骤切换直接显示/隐藏（opacity变化可加0.2s transition，但非必须）。
  7. 事件绑定：上一步/下一步按钮绑定click事件，更新currentStep并调用renderStep。
- ID命名规范：所有元素ID必须以 `scene2-` 为前缀。例如：
  - 选项容器：scene2-opt-a、scene2-opt-b、scene2-opt-c、scene2-opt-d
  - 正方形：scene2-a-top、scene2-a-m1、scene2-a-m2、scene2-a-m3、scene2-a-m4、scene2-a-bottom（B/C/D同理）
  - 图案symbol：scene2-heart、scene2-smile、scene2-flower
  - 标注：scene2-a-label1、scene2-a-label2、scene2-a-label3（B/C/D同理）
  - 对错标记：scene2-a-mark、scene2-b-mark 等
  - 结论文字：scene2-conclusion
  - 按钮：scene2-btn-prev、scene2-btn-next
  - 步骤文字：scene2-step-indicator
- IIFE隔离：所有JS代码包裹在 `(function() { ... })();` 中，避免全局变量污染。
