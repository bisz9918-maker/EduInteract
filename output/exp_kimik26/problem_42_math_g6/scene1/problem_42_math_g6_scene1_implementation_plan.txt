[图示主题与整合说明]
- 本图示主题：三视图的对应关系与信息提取
- 整合内容：三视图方位识别、主视图的列高信息、左视图的行高信息、俯视图的底面布局、行列对应关系连线
- 教学价值：教师通过分步导航，引导学生先认识每个视图，再提取行列高度信息，最后建立"列对列、行对行"的对应关系，从而理解如何由三视图确定正方体个数（本题为5个）。课堂讲解节奏与分步导航完全匹配。

[分步序列]
- 初始状态（步骤0）：显示三个视图（主视图、左视图、俯视图）及其外框、内部网格线、填充格、视图名称标签。无高亮，无标注，无连线。教师可在此步让学生观察三视图的基本形状。
- 步骤1（点击下一步）：主视图外框高亮为蓝色（#1565c0，线宽3px），视图名称"从正面看"变为蓝色。显示步骤1标签：主视图上方出现"第1列"/"高=2"、"第2列"/"高=1"、"第3列"/"高=1"（蓝色）。教师讲解：主视图有3列，列高分别为2、1、1。
- 步骤2（点击下一步）：取消主视图高亮，恢复黑色外框。左视图外框高亮为绿色（#2e7d32，线宽3px），视图名称"从左面看"变为绿色。显示步骤2标签：左视图左侧出现"高=2"/"第1行(后排)"、"高=1"/"第2行(前排)"（绿色）。教师讲解：左视图反映前后两行高度，后排高2，前排高1。
- 步骤3（点击下一步）：取消左视图高亮。俯视图外框高亮为红色（#c62828，线宽3px），视图名称"从上面看"变为红色。俯视图4个填充格外框加红色粗线（stroke-width=2）。显示步骤3标签：俯视图下方出现"列1"/"列2"/"列3"，右侧出现"行1(后)"/"行2(前)"（红色）。教师讲解：俯视图是2行3列的底面布局，4个红色边框格表示有正方体投影的位置。
- 步骤4（点击下一步）：保持俯视图红色高亮。显示步骤4连线：5条灰色虚线箭头，分别连接主视图3列与俯视图3列、左视图2行与俯视图2行。教师讲解：主视图的列对应俯视图的列（列对列），左视图的行对应俯视图的行（行对行），由此可确定每个位置的高度，求和得总个数=2+1+1+1=5（后排3个：2,1,1；前排1个：1）。

[标签冲突检查]
所有标签预计坐标及检查：
- "从正面看"：(200,170)
- "从左面看"：(400,170)
- "从上面看"：(600,170)
- "第1列"：(160,155)；"高=2"(列1)：(160,128)
- "第2列"：(200,155)；"高=1"(列2)：(200,128)
- "第3列"：(240,155)；"高=1"(列3)：(240,128)
- "高=2"(左视)：(220,200)；"第1行(后排)"：(315,200)
- "高=1"(左视)：(220,240)；"第2行(前排)"：(315,240)
- "列1"：(580,295)；"列2"：(620,295)；"列3"：(660,295)
- "行1(后)"：(715,200)；"行2(前)"：(715,240)

逐对检查（仅检查距离<40px的配对）：
1. "第1列"(160,155)与"高=2"(160,128)：间距27px，垂直方向，bounding box不重叠（第1列box约y=143~167，高=2 box约y=116~140）。无冲突。
2. "高=2"(左视)(220,200)与"第1行(后排)"(315,200)：间距95px，水平方向。无冲突。
3. "高=2"(左视)(220,200)与主视图右边缘(260,200)：标签右边缘≈239.5 < 260，不进入主视图区域。无冲突。
4. "行1(后)"(715,200)与俯视图右边缘(680,200)：标签左边缘≈682.5 > 680，不进入俯视图区域。无冲突。
5. "列1"(580,295)与俯视图底部(260)：垂直间距约27px，安全。无冲突。
6. 三个视图名称标签间距200px，远大于40px。无冲突。
7. 步骤1、步骤2、步骤3标签分属不同步骤，不会同时显示，因此跨步骤标签无需检查同时显示冲突。
8. 步骤4连线与所有标签：连线经过区域主要在视图之间空白区（y=175~240，x=260~580），与步骤1标签(y=128~155)、步骤2标签(x=220~315,y=200~240)、步骤3标签(y=295或x=715)均不重叠。无冲突。

结论：所有标签无冲突，布局安全。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「上一步」按钮：位置(280,452)，大小80×32px。点击后回退到上一个步骤，隐藏当前步骤新增的元素，恢复上一步的高亮状态。
  2. 「下一步」按钮：位置(440,452)，大小80×32px。点击后前进到下一个步骤，显示新元素并更新高亮。
  3. 步骤指示器：位置(400,485)，显示当前步骤编号（如"步骤 1 / 5"对应步骤0）。
- 教师操作流程：
  1. 教师打开图示，学生看到三个视图（步骤0）。
  2. 教师点击「下一步」，主视图高亮，讲解列高信息（步骤1）。
  3. 教师点击「下一步」，左视图高亮，讲解行高信息（步骤2）。
  4. 教师点击「下一步」，俯视图高亮，讲解底面布局（步骤3）。
  5. 教师点击「下一步」，出现对应关系连线，讲解行列交叉确定每个位置高度并求和（步骤4）。
  6. 教师可随时点击「上一步」回退复习。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：本场景为静态几何网格与简单状态切换，无需复杂绘图库，原生SVG性能最优且文件体积最小。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------------+
  |                                                        |
  |     从正面看        从左面看        从上面看            |
  |        |               |               |               |
  |   +----+----+     +----+----+     +----+----+----+     |
  |   | ■ |     |     | ■ |     |     | ■ | ■ | ■ |       |
  |   | ■ | ■ | ■ |     | ■ | ■ |     | ■ |     |     |   |
  |   +----+----+     +----+----+     +----+----+----+     |
  |      主视图          左视图          俯视图             |
  |                                                        |
  |   [步骤1标签]      [步骤2标签]      [步骤3标签]        |
  |   (主视图上方)     (左视图左侧)     (俯视图下/右侧)     |
  |                                                        |
  |        ←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←           |
  |        [步骤4虚线箭头连线]                             |
  |                                                        |
  |              [◀上一步]  [下一步▶]                      |
  |                    步骤 1 / 5                          |
  +--------------------------------------------------------+
  [控件栏 y=440~490]
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `currentStep`（0~4）。`goToStep(n)` 函数统一处理状态切换：先隐藏所有步骤专属元素，再根据目标步骤显示对应元素并设置高亮。
  2. 高亮实现：通过修改 SVG 元素的 `stroke` 和 `stroke-width` 属性实现。步骤1主视图外框变蓝，步骤2左视图外框变绿，步骤3俯视图外框变红+填充格红边框。
  3. 元素显隐：所有步骤专属元素（标签、连线）初始 `display:none` 或 `opacity:0`。切换步骤时通过 JS 设置 `display` 或 `opacity`。
  4. 动画曲线：无需复杂动画，状态切换使用即时显示（duration=0）或极短淡入（opacity 0→1，duration=200ms，ease-out），保持课堂讲解的即时响应。
  5. 事件绑定：按钮绑定 `click` 事件，更新 `currentStep` 后调用 `goToStep(currentStep)`。
  6. 箭头实现：使用 SVG `<marker>` 定义箭头，id 为 `scene1-arrow-gray`，应用于步骤4的 `<line>` 元素。
- ID命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀。例如：
  - 主视图外框：`scene1-main-frame`
  - 左视图外框：`scene1-left-frame`
  - 俯视图外框：`scene1-top-frame`
  - 主视图名称：`scene1-main-label`
  - 步骤1标签组：`scene1-step1-group`
  - 步骤2标签组：`scene1-step2-group`
  - 步骤3标签组：`scene1-step3-group`
  - 步骤4连线组：`scene1-step4-group`
  - 上一步按钮：`scene1-prev-btn`
  - 下一步按钮：`scene1-next-btn`
  - 步骤指示器：`scene1-step-indicator`
  - 箭头marker：`scene1-arrow-gray`
- IIFE隔离：所有 JavaScript 代码包裹在 `(function() { ... })()` 中，避免全局变量污染。
