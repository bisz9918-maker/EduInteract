[图示主题与整合说明]
- 本图示主题：3D几何体还原与三视图验证
- 整合内容：通过等轴测3D模型逐层搭建5个正方体的空间结构，并依次验证主视图、左视图、俯视图，帮助学生建立"空间结构→三视图"的映射关系
- 教学价值：教师可控制每一步的呈现时机，先让学生观察底层4个方块的俯视图布局，再观察上层叠加，最后通过三个视角的投影图与标准视图对比，确认还原结果正确，强化空间想象能力

[分步序列]
- 步骤0（初始状态）：显示空的3D等轴测底座网格（2行3列灰色虚线网格）和方位标签"前""后""左""右"；隐藏所有方块、投影图、2D视图、高度标签、总数标签
- 步骤1（搭建底层）：在底座上显示B1(行1列1)、B2(行1列2)、B3(行1列3)、B4(行2列1)四个底层方块；底座网格可保留但透明度降至0.3；方位标签保持显示
- 步骤2（搭建上层）：在B1上方叠加B5，该位置高度变为2；新增高度标签"2"在B5右侧(340,290)；总方块数达到5个
- 步骤3（正面验证）：隐藏底座网格；显示左侧正面投影图（蓝色虚线框+蓝色半透明方格）；显示右侧标准主视图（蓝色粗外框）；新增标签"正面看"(200,290)和"主视图"(660,145)；3D模型中所有方块正面边框高亮为蓝色#1565c0线宽2px
- 步骤4（左面验证）：隐藏步骤3的正面投影图、主视图及相关标签；显示左侧左视图投影图（绿色虚线框+绿色半透明方格）；显示右侧标准左视图（绿色粗外框）；新增标签"左面看"(200,290)和"左视图"(660,145)；3D模型无面高亮（左侧面不可见）
- 步骤5（上面验证）：隐藏步骤4的左面投影图、左视图及相关标签；显示左侧俯视图投影图（红色虚线框+红色半透明方格）；显示右侧标准俯视图（红色粗外框）；新增标签"上面看"(200,290)和"俯视图"(660,145)；3D模型中所有方块顶面边框高亮为红色#c62828线宽2px
- 步骤6（完整模型）：隐藏所有投影图、2D视图、验证标签；显示全部5个方块、方位标签、高度标签"2"；新增总数标签"共5个正方体"(320,250)；底座网格可选择性以低透明度显示；模型恢复默认黑色边框

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位置(280,455)，宽90高32，点击回退到上一分步
  - 「下一步」按钮：位置(430,455)，宽90高32，点击推进到下一分步
  - 步骤指示器：位置(385,475)，显示"步骤 X/7"，用于教师确认当前讲解进度
- 教师操作流程：
  1. 教师点击「下一步」进入步骤0，展示空底座和方位，讲解"我们要在这个2行3列的底座上搭建几何体"
  2. 点击「下一步」进入步骤1，展示底层4个方块，让学生观察底层布局与俯视图的关系
  3. 点击「下一步」进入步骤2，展示上层叠加和高度标签"2"，确认总方块数
  4. 点击「下一步」进入步骤3，展示正面投影与主视图对比，验证正面看过去的形状
  5. 点击「下一步」进入步骤4，展示左面投影与左视图对比，验证左面看过去的形状
  6. 点击「下一步」进入步骤5，展示上面投影与俯视图对比，验证俯视形状
  7. 点击「下一步」进入步骤6，展示完整模型和总数标签，得出答案"5个正方体"
  8. 教师可随时点击「上一步」回退到任意步骤复习

[技术实现]
- JS库选择：原生SVG（所有元素均为多边形、矩形、文本和线条，SVG polygon/rect/text/line即可完美支持，无需引入外部库）
- 画布尺寸：800 × 500 px（固定画布，控件栏在SVG内底部y=440~490区域，使用HTML绝对定位div叠加在SVG上方）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  "后"(200,260)              "俯视图"(660,145)      |
  |      |                        [右侧标准视图]       |
  |  "左"|    [3D模型主体]            (620,160)        |
  |      |    x:242~412                                |
  |      |    y:264~432         [左侧投影图]           |
  |      |                      (180,300)              |
  |  "前"(320,430)                                     |
  |                                                    |
  |  [◀ 上一步]  步骤 X/7  [下一步 ▶]                  |
  |  (280,455)   (385,475)  (430,455)                  |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 等轴测方块生成函数：输入底面原点(baseX, baseY)，根据x_vec=(34,18)、y_vec=(-34,18)、z_vec=(0,-38)计算顶面(p0'p1'p2'p3')、正面(p0p1p1'p0')、右侧面(p1p2p2'p1')三个polygon的points字符串，返回三个<polygon>元素
  2. 2D视图生成函数：输入左上角(x,y)、方格大小cellSize、行列占用矩阵，生成<rect>组和外框<rect>，间隙2px
  3. 状态机设计：currentStep ∈ [0,6]，nextStep()和prevStep()函数控制步进，边界值钳制
  4. 渲染函数render()：根据currentStep，遍历预定义的显示清单，设置对应SVG元素的display属性（"block"/"none"），所有元素在初始化时一次性创建并append到SVG中
  5. 步骤切换动画：使用CSS transition，新增元素初始opacity:0，通过setTimeout在display:block后添加fade-in类，0.3s过渡到opacity:1
  6. 事件绑定：上一步/下一步按钮绑定click事件，更新currentStep后调用render()
- ID命名规范：所有SVG元素和控件ID必须以`scene3-`为前缀，例如：
  - 方块面：scene3-cube-b1-top、scene3-cube-b1-front、scene3-cube-b1-right
  - 底座：scene3-base-line-h0（水平线）、scene3-base-line-v0（垂直线）
  - 投影图：scene3-proj-front-group、scene3-proj-left-group、scene3-proj-top-group
  - 标准视图：scene3-ref-front-group、scene3-ref-left-group、scene3-ref-top-group
  - 标签：scene3-label-front、scene3-label-back、scene3-label-left、scene3-label-right、scene3-label-height、scene3-label-total、scene3-label-proj、scene3-label-ref
  - 按钮：scene3-btn-prev、scene3-btn-next
  - 指示器：scene3-step-indicator
  - JS中严格使用document.getElementById获取元素，禁止querySelectorAll配合全局class
- IIFE隔离：所有JavaScript代码包裹在`(function() { ... })()`立即执行函数中，避免多场景合并时的全局变量污染
