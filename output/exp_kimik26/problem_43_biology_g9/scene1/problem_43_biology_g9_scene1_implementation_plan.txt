- 步骤3（完全变态左支+蛹期）：
  - 主图变化：左支A→B→D高亮为绿色（#2e7d32，线宽3px）；B节点填充浅绿（rgba(46,125,50,0.2)），边框绿色；"幼虫期"标签变绿色；新增标注"B = 幼虫期"（绿色，(50,190)）；新增蛹节点（虚线框，(170,290)）及B→蛹、蛹→D两条灰色虚线箭头；其余元素淡化
  - 右侧变化：标题"完全变态发育"（绿色）；示意图"卵→幼虫→蛹→成虫"（四个节点，幼虫/蛹绿色）；昆虫名称"蚊、家蚕"（绿色）；选项A和C文字显示（A旁预标灰色×提示错误，C旁预标灰色√提示正确，或仅显示文字待步骤4判定）
  - 教学点：左支是完全变态，B为幼虫期，图中省略了蛹期

- 步骤4（总结）：
  - 主图变化：所有节点和箭头恢复黑色实线显示；蛹节点保持显示（灰色虚线，作为知识补充）；所有外侧标注显示；无高亮填充
  - 右侧变化：标题"选项正误总结"；四个选项逐条列出：
    - A选项（红×）："A. 如果A是蚊的卵，那么D是其发育的蛹期"
    - B选项（蓝√）："B. 如果A是蝗虫的卵，那么D是其成虫"
    - C选项（绿√）："C. 如果A是家蚕的卵，为提高蚕丝产量，应延长B时期"
    - D选项（蓝√）："D. 如果A是蟋蟀的卵，那么C期的发育需要蜕皮"
  - 底部对照表：
    | 昆虫 | 发育类型 | 阶段 |
    | 蝗虫 | 不完全变态 | 卵→若虫→成虫 |
    | 蟋蟀 | 不完全变态 | 卵→若虫→成虫 |
    | 蚊 | 完全变态 | 卵→幼虫→蛹→成虫 |
    | 家蚕 | 完全变态 | 卵→幼虫→蛹→成虫 |
  - 教学点：综合验证，明确A选项错误（蚊的D是成虫而非蛹期）

- 控件说明：
  - 「◀ 上一步」按钮：位置(280,465)，尺寸100×32，点击回退到上一状态，步骤0时禁用（opacity=0.4）
  - 步骤指示器：位置(400,465)，显示当前步骤/总步骤（如"1 / 5"），文字14px灰色
  - 「下一步 ▶」按钮：位置(520,465)，尺寸100×32，点击前进到下一状态，步骤4时禁用（opacity=0.4）

  2. 点击「下一步」进入步骤1，聚焦D→A红色循环，讲解"成虫产卵→D是成虫"

  6. 可随时点击「上一步」回退到任意步骤复习

[技术实现]
- JS库选择：原生SVG + 原生JavaScript（无外部库）。理由：本场景为静态几何图形+状态切换，无需复杂数学计算或3D，原生SVG足以高效实现，且避免外部库加载开销。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------------+
  |                                                        |
  |    [主图区 800×500]                                    |
  |                                                        |
  |         A(卵)                                          |
  |        /   \                                           |
  |       /     \          [右侧信息面板]                   |
  |   B(幼虫)   C(若虫)      标题                          |
  |       \     /            示意图/选项/表格               |
  |        \   /                                           |
  |         D(成虫)                                        |
  |                                                        |
  |    (步骤3补充蛹节点于B-D之间)                           |
  |                                                        |
  |              [◀ 上一步] [1/5] [下一步 ▶]               |
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：定义常量 STATE_COUNT=5，当前状态变量 currentStep（0~4）。每一步对应一个数据对象，描述该步应显示的元素ID列表、高亮颜色、透明度等。
  2. 元素组织：SVG中使用 `<g>` 分组，如 `scene1-main-graph`、`scene1-right-panel`、`scene1-controls`。主图内每个可独立控制的元素（节点、箭头、标签）赋予独立ID。
  3. 步骤切换动画：使用CSS transition（opacity 300ms ease, stroke 300ms ease）实现淡入淡出和颜色过渡。通过切换元素的class（如 `.active-red`、`.active-blue`、`.active-green`、`.dimmed`）控制样式。
  4. 右侧面板更新：每一步清空/隐藏上一面板内容组，显示当前步骤对应的内容组（预定义在SVG中，初始opacity=0，通过class切换显示）。
  5. 箭头marker定义：在SVG `<defs>` 中定义4个marker（黑色、红色、蓝色、绿色），供不同状态的箭头引用。
  6. 蛹节点：步骤0/1/2中隐藏（display:none），步骤3/4中显示。步骤4中蛹节点边框为#888888虚线，不填充。
  7. 按钮状态：步骤0时上一步按钮disabled；步骤4时下一步按钮disabled。通过JS动态设置disabled属性和opacity。
  8. 坐标计算：所有节点和箭头坐标硬编码（见布局坐标表），确保精确无重叠。
- ID命名规范：所有交互元素ID必须以 `scene1-` 为前缀。例如：
  - 节点：`scene1-node-a`、`scene1-node-b`、`scene1-node-c`、`scene1-node-d`、`scene1-node-pupa`
  - 箭头：`scene1-arrow-ab`、`scene1-arrow-bd`、`scene1-arrow-ac`、`scene1-arrow-cd`、`scene1-arrow-da`、`scene1-arrow-b-pupa`、`scene1-arrow-pupa-d`
  - 标签：`scene1-label-a`、`scene1-label-egg`、`scene1-label-larva`、`scene1-label-nymph`、`scene1-label-adult`、`scene1-label-oviposit`、`scene1-label-c-nymph`、`scene1-label-b-larva`
  - 右侧面板：`scene1-panel-step0`、`scene1-panel-step1`...`scene1-panel-step4`
  - 控件：`scene1-btn-prev`、`scene1-btn-next`、`scene1-step-indicator`
  - JS中严格使用 `document.getElementById` 获取元素，禁止全局class选择器跨场景操作。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免全局变量污染，确保多场景合并时互不干扰。
