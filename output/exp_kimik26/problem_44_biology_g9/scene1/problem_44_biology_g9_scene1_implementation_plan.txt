# Scene 1 Implementation Plan

<SCENE_VISION_STORYBOARD_AND_TECHNICAL_PLAN>

[图示主题与整合说明]
- 本图示主题：人体内"甲→乙→丙"血流模型的综合辨析
- 整合的步骤/概念：
  · 步骤0：通用血流框架（甲→乙→丙，乙为空白方框）
  · 步骤1：选项A辨析——毛细血管网的两种类型对比（组织处 vs 肺部）
  · 步骤2：选项B辨析——小肠处的物质交换（氧气减少、营养物质增加）
  · 步骤3：选项C辨析——肾小球的血管类型（入球小动脉→肾小球→出球小动脉）
  · 步骤4：选项D辨析——胰岛的内分泌调节（血糖升高→胰岛素分泌增加）
- 教学价值：教师可在同一通用框架下，按选项顺序逐一辨析四种生理情境。分步导航允许教师根据课堂节奏前进或回退，每步聚焦一个选项，避免信息过载，同时便于学生对比不同器官的血流差异。

[分步序列]
- 初始状态（步骤0）：显示通用血流框架
  · 显示元素：标题、甲血管(空白)、丙血管(空白)、乙方框(空白)、甲/乙/丙标签、两个血流箭头、引导文字
  · 隐藏元素：所有选项辨析内容
  · 教师操作：引导学生理解"甲流入、乙结构、丙流出"的基本关系

- 步骤1：点击「下一步」→ 选项A辨析（毛细血管网对比）
  · 视觉变化：
    - 隐藏步骤0的通用框架（保留标题）
    - 显示上下两组对比图：
      · 上组：甲(动脉血)→乙(组织处毛细血管网)→丙(静脉血)，标注"氧气进入组织细胞"
      · 下组：甲(静脉血)→乙(肺部毛细血管网)→丙(动脉血)，标注"氧气从肺泡进入血液"
    - 中间以#888888虚线分隔
    - 结论区显示红色"A"、红色"×"、结论文字"毛细血管网位置不同，丙中血液性质不同，A错误"
  · 教师操作：讲解组织处与肺部毛细血管的血流差异，强调"毛细血管网位置决定丙中血液性质"

- 步骤2：点击「下一步」→ 选项B辨析（小肠物质交换）
  · 视觉变化：
    - 隐藏步骤1内容
    - 显示单组框架：甲(动脉血)→乙(小肠)→丙(静脉血)
    - 乙方框内画小肠褶皱波浪线
    - 动画展示：红色O₂气泡从甲进入乙后数量减少（部分淡出）；绿色营养物质方块从乙进入丙增多
    - 标注"O₂"和"营养物质"
    - 结论区显示红色"B"、红色"×"、结论文字"小肠消耗氧气、吸收营养，丙中含氧量减少，B错误"
  · 教师操作：讲解小肠是消耗氧气、吸收营养物质的器官，因此丙中为含氧少的静脉血但营养丰富

- 步骤3：点击「下一步」→ 选项C辨析（肾小球血管类型）
  · 视觉变化：
    - 隐藏步骤2内容
    - 显示单组框架：甲(动脉血)→乙(肾小球)→丙(动脉血)
    - 乙方框内画肾小球毛细血管团
    - 甲上方标注"入球小动脉"，丙上方标注"出球小动脉"
    - 丙血管周围画虚线框强调，右侧标注"仍是动脉血"
    - 结论区显示红色"C"、红色"×"、结论文字"肾小球两端连接的都是动脉，丙是出球小动脉，C错误"
  · 教师操作：强调肾小球是特殊的毛细血管球，两端连接的都是动脉，丙并非静脉血管

- 步骤4：点击「下一步」→ 选项D辨析（胰岛内分泌调节）
  · 视觉变化：
    - 隐藏步骤3内容
    - 显示单组框架：甲(动脉血)→乙(胰岛)→丙(静脉血)
    - 乙方框内画胰岛细胞团
    - 方框上方标注"血糖增多→胰岛素分泌增加"
    - 动画展示：绿色胰岛素颗粒从乙（胰岛细胞）分泌并进入丙血管
    - 结论区显示绿色"D"、绿色"✓"、结论文字"胰岛素直接进入血液，丙内胰岛素增加，D正确"
  · 教师操作：讲解胰岛是内分泌腺，胰岛素直接分泌到血液中，血糖升高时分泌增加

- 最终状态：步骤4显示完毕，教师可点击「上一步」回退到任意步骤复习对比

[技术实现]
- JS库选择：原生 SVG + 原生 JavaScript（无外部库）。原因：本场景以静态几何图形和简单动画为主，原生SVG足以满足需求，无需引入D3等重型库，保持代码轻量。
- 画布尺寸：800 × 500 px（固定尺寸）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  标题：人体内血流模型辨析                         |  y=10~40
  |                                                  |
  |  步骤0/2/3/4:   甲[血管]→[  乙  ]→[血管]丙        |  y=140~220
  |  步骤1:  上组：甲→[毛细血管]→丙  (组织处)         |  y=105~155
  |          下组：甲→[毛细血管]→丙  (肺部)           |  y=225~275
  |                                                  |
  |  结论区：A × 毛细血管网位置不同...A错误           |  y=330~380
  |                                                  |
  |          [◀ 上一步]  步骤 X/4  [下一步 ▶]        |  y=440~490
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 currentStep（0~4），每次点击按钮时更新状态并调用 showStep(n) 函数。
  2. 分组显示/隐藏：每个步骤的所有视觉元素包裹在一个 SVG `<g>` 组中（id="scene1-step-0" 至 "scene1-step-4"），切换步骤时通过设置 `display: block/none` 控制整组显示或隐藏。
  3. 动画实现：步骤2的O₂气泡和营养物质、步骤4的胰岛素颗粒使用 SVG `<animate>` 元素或CSS `@keyframes` 实现平移动画。O₂气泡在乙区域使用 `opacity` 动画淡出，表示被消耗。
  4. 按钮状态：步骤0时禁用「上一步」，步骤4时禁用「下一步」，通过设置 `disabled` 属性和对应CSS样式（背景变灰）实现。
  5. 血液填充：使用 SVG `<rect>` 覆盖在血管管道内部，设置 `fill-opacity="0.15"`，确保颜色柔和不刺眼。
  6. 箭头绘制：使用 SVG `<path>` 绘制三角形箭头，或使用 `<marker>` 定义箭头端点，绑定到线段末端。
- ID命名规范：
  · 所有SVG元素ID以 `scene1-` 为前缀，如 `scene1-step-0`、`scene1-vessel-jia`、`scene1-box-yi`、`scene1-conclusion-text`
  · 按钮ID：`scene1-btn-prev`、`scene1-btn-next`
  · 步骤指示器ID：`scene1-step-indicator`
  · JS中严格使用 `document.getElementById()` 获取元素，避免使用 `querySelectorAll`
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })()` 中，防止全局命名空间污染，确保多场景合并时互不干扰。
