[图示主题与整合说明]
- 本图示主题：肾单位结构及尿液形成的过滤与重吸收过程
- 整合的步骤/概念：题目简化流程图还原 → 肾单位完整结构识别（甲=肾小囊、乙=肾小管、a=原尿、b=尿液）→ 肾小球过滤作用 → 肾小管重吸收作用 → 血液/原尿/尿液成分对比
- 教学价值：教师可先展示题目原始流程图让学生猜测结构含义，再逐步展开为完整肾单位示意图，通过分步动画呈现过滤和重吸收的动态过程，最后以成分对比表总结三种液体的差异，帮助学生建立从宏观流程到微观机制的完整认知链条

[分步序列]
- 初始状态（步骤0）：仅显示题目简化流程图。画面中央展示方框"血液流进肾小球中"，向右箭头连接"甲"，箭头上方标"形成a"；再向右箭头连接"乙"，箭头上方标"形成b"。底部步骤说明："题目流程图：请识别甲、乙、a、b分别代表什么结构或液体？"教师可引导学生回顾题目、进行猜测。
- 步骤1：点击「下一步」→ 隐藏流程图，显示完整肾单位二维示意图。左侧展示入球小动脉→肾小球（红色球体）→肾小囊（杯状包裹）→出球小动脉→肾小管外毛细血管→肾静脉，以及肾小管向下弯曲连接集合管。同时显示标签"甲（肾小囊）"、"乙（肾小管）"、"a（原尿）"、"b（尿液）"，完成题目符号与真实结构的对应。底部说明："肾单位结构：甲=肾小囊，乙=肾小管，a=原尿，b=尿液。"
- 步骤2：点击「下一步」→ 在步骤1结构图基础上，高亮肾小球与肾小囊区域（浅黄色椭圆覆盖），显示5条绿色动画箭头从肾小球内部指向肾小囊腔，象征血液中除血细胞和大分子蛋白质外的物质（水、无机盐、葡萄糖、尿素）滤过进入肾小囊腔形成原尿。显示"过滤"标注。底部说明："过滤作用：血液流经肾小球时，血浆中的水、无机盐、葡萄糖、尿素等滤过到肾小囊腔形成原尿。"
- 步骤3：点击「下一步」→ 移除过滤高亮与箭头，高亮肾小管区域（浅蓝色粗描边沿肾小管路径），显示4条绿色动画箭头从肾小管管腔指向周围毛细血管，象征全部葡萄糖、大部分水和部分无机盐被重吸收回血液；剩余物质继续向下流入集合管。显示"重吸收"标注。底部说明："重吸收作用：原尿流经肾小管时，全部葡萄糖、大部分水和部分无机盐被重吸收回血液，剩余尿素等形成尿液。"
- 步骤4（最终步骤）：点击「下一步」→ 保留步骤1的结构图（无高亮/动画箭头），在右侧显示成分对比表（血液、原尿、尿液 × 水、无机盐、葡萄糖、尿素、蛋白质），用绿色"√/多"表示存在/含量高，红色"×"表示无，绿色"少"表示含量低。底部说明："成分对比：血液含大分子蛋白质，原尿不含蛋白质但含葡萄糖，尿液不含葡萄糖且尿素浓度升高。"教师可据此带领学生判断题目选项正误。

  1. 「◀ 上一步」按钮：位置(260, 452)，宽90×高32。点击后回退到上一个步骤，隐藏当前步骤新增的元素，恢复上一步的视觉状态。教师可用于回退复习。
  2. 步骤指示器：位置(360, 472)，显示"步骤 X / 4"，仅作状态提示，不可点击。
  3. 「下一步 ▶」按钮：位置(450, 452)，宽90×高32。点击后进入下一个步骤，按分步序列显示对应元素、高亮和动画。在步骤4时按钮可禁用或变为"完成"状态。
- 教师操作流程：
  1. 课堂开始时保持步骤0，展示题目原始流程图，提问学生"甲、乙、a、b分别是什么"。
  2. 点击「下一步」进入步骤1，揭示肾单位完整结构，建立符号与解剖结构的对应关系。
  3. 点击「下一步」进入步骤2，配合过滤高亮和绿色箭头，讲解肾小球的滤过功能。
  4. 点击「下一步」进入步骤3，配合重吸收高亮和绿色箭头，讲解肾小管的重吸收功能。
  5. 点击「下一步」进入步骤4，展示成分对比表，引导学生对比血液、原尿、尿液的差异，进而判断题目四个选项的正误（重点分析A选项：麻痹乙处/肾小管，蛋白质不会出现在尿液中，因为蛋白质在肾小球已被阻挡；B选项正确；C选项肾单位由肾小球+肾小囊+肾小管构成，正确；D选项血液流经肾脏后动脉血变静脉血、尿素减少，正确。因此不正确的是A）。
  6. 可随时点击「上一步」回退到任意步骤进行复习或补充讲解。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：本场景以静态矢量图形和分步显示/隐藏为主，过滤/重吸收动画可用SVG的marker-end实现箭头，用setInterval或CSS transition实现简单位移动画，无需引入D3、Three.js等重型库。
- 画布尺寸：800 × 500 px（固定），SVG嵌入HTML，viewBox="0 0 800 500"。
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------------+
  |                                                        |
  |   左侧：肾单位结构图（x=40~460, y=50~420）              |
  |   ┌─入球小动脉→[肾小球]─出球小动脉─┐                   |
  |   │         (甲)肾小囊            │                    |
  |   │            ↓ a(原尿)          │    右侧：成分对比表  |
  |   │      ┌─────────────┐          │    （步骤4显示）    |
  |   │      │  乙(肾小管)  │          │    x=500~780       |
  |   │      │  弯曲管道   │          │                    |
  |   │      └─────────────┘          │                    |
  |   │            ↓ b(尿液)          │                    |
  |   │         [集合管]              │                    |
  |   └─肾静脉←──毛细血管─────────────┘                   |
  |                                                        |
  |   步骤说明文字（y=435，居中）                            |
  +--------------------------------------------------------+
  |   [◀ 上一步]      步骤 X / 4      [下一步 ▶]           |
  |   y=445~485                                            |
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：定义常量 STEP = {0: 'flow', 1: 'structure', 2: 'filter', 3: 'reabsorb', 4: 'table'}。维护变量 currentStep（0~4）。每一步对应一个SVG <g>组（id="scene1-step0-group"、"scene1-step1-group"等），切换步骤时通过设置 group.style.display = 'none' / 'block' 控制显隐。
  2. 坐标计算：肾小管路径使用绝对坐标path，重吸收高亮区复制肾小管外壁path并将stroke-width设为20、stroke=#e1f5fe、opacity=0.3、fill=none，置于肾小管下层（SVG渲染顺序）。
  3. 动画曲线：过滤/重吸收箭头使用SVG <line>配合<marker>定义箭头头部。动画采用JS控制：在步骤2/3激活时，用setInterval每200ms切换箭头stroke-opacity在0.3与1.0之间，形成脉冲闪烁效果；或采用CSS animation（@keyframes pulse）应用于箭头类名。避免复杂路径动画，确保性能。
  4. 事件绑定：上一步/下一步按钮绑定click事件，调用goToStep(n)函数。goToStep内部先隐藏所有步骤组，再根据目标步骤显示当前及需要保留的组（例如步骤2显示step1-group+step2-group，步骤4显示step1-group+step4-group）。更新步骤指示器innerText和步骤说明文字。
  5. 步骤0与步骤1互斥：步骤0的简化流程图和步骤1的完整结构图位于同一区域，切换时完全互斥显示，避免重叠。
  6. 表格绘制：使用SVG <rect>、<line>、<text>手动绘制，避免HTML/CSS与SVG混排导致的定位问题。表格在步骤4之前display=none。
- ID命名规范：所有SVG元素及交互控件ID必须以 scene1- 为前缀。例如：scene1-step0-box、scene1-kidney-glomerulus、scene1-filter-highlight、scene1-reabsorb-arrow-1、scene1-table-group、scene1-btn-prev、scene1-btn-next、scene1-step-indicator、scene1-step-desc。JS中严格使用document.getElementById获取元素，禁止querySelectorAll配合全局class，防止多场景合并时跨场景污染。
- IIFE隔离：所有JavaScript代码包裹在 (function() { ... })() 中，内部变量不泄露全局作用域。事件处理函数亦定义在IIFE内部。
