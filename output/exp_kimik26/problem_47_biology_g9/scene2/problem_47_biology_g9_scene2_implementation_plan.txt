- 控件说明：

- 教师操作流程：
  1. 教师展示步骤0，让学生阅读四个选项并独立思考；
  2. 点击「下一步」进入步骤1，讲解选项B，确认a为原尿、b为尿液；
  3. 继续点击「下一步」依次验证选项C（肾单位组成）和选项D（血液循环与尿素变化）；
  4. 进入步骤4，重点讲解选项A的错误原因，通过左右对比图强调"蛋白尿取决于肾小球是否正常，与肾小管麻痹无关"；
  5. 可随时点击「上一步」回退到任意步骤复习。

[技术实现]
- JS库选择：原生 SVG + 原生 JavaScript（无外部库）。原因：本场景以静态几何图形、流程图和分步显示/隐藏为主，无需复杂数学计算或3D渲染，原生SVG路径和分组即可满足，避免引入不必要的依赖。
- 画布尺寸：800 × 500 px（固定画布规则）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |  标题区（y=0~40）                                 |
  |                                                  |
  |  +------------------ 主图区（y=40~430）----------+ |
  |  |                                               | |
  |  |   步骤0: 四个选项垂直排列                      | |
  |  |   步骤1-3: 左侧图(50%) + 右侧选项文字(40%)     | |
  |  |   步骤4: 顶部选项A + 左右对比图 + 底部结论      | |
  |  |                                               | |
  |  +-----------------------------------------------+ |
  |                                                  |
  |  [◀上一步]  [1/5]  [下一步▶]   控件栏（y=440~490）|
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `currentStep`（0~4），每一步对应一个SVG `<g>` 分组（id="scene2-step0-group" ~ "scene2-step4-group"），通过设置 `display: none/block` 或 `opacity: 0/1` 切换可见性。
  2. 坐标计算：所有图形坐标使用绝对像素值，基于800×500画布。肾小囊U形弧使用SVG `path` 的 `A` 命令绘制；肾小管使用 `path` 的 `L` 命令绘制折线。
  3. 动画曲线：步骤切换时使用CSS `transition: opacity 0.3s ease-in-out`，当前步骤组淡入，其他组隐藏。
  4. 事件绑定：上一步/下一步按钮绑定 `click` 事件，更新 `currentStep` 后调用 `renderStep()` 函数，该函数遍历所有步骤组设置显示状态，并更新按钮禁用状态和步骤指示器文字。
  5. 步骤1-3的右侧选项框使用统一的坐标模板，仅文字内容和判断标记颜色不同，通过JS动态更新或预定义多个组切换。
  6. 步骤4的左右对比图使用两个独立的 `<g>` 子组，便于分别控制动画时序（如先显示左侧，延迟200ms显示右侧）。
- **ID命名规范**：所有交互元素ID必须以 `scene2-` 为前缀。例如：
  - 步骤分组：`scene2-step0-group`, `scene2-step1-group`, ..., `scene2-step4-group`
  - 图形元素：`scene2-kidney-glomerulus`, `scene2-kidney-capsule`, `scene2-kidney-tubule`
  - 按钮：`scene2-btn-prev`, `scene2-btn-next`
  - 指示器：`scene2-step-indicator`
  - 选项框：`scene2-option-a-box`, `scene2-option-b-box`, ...
  - JS中严格使用 `document.getElementById()` 获取元素，禁止全局class选择，避免多场景合并时跨场景污染。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })()` 立即执行函数中，变量不污染全局作用域。
