[图示主题与整合说明]
- 本图示主题：球面上两点间最短航线（大圆航线）的方向变化
- 整合的步骤/概念：M/N经纬定位 → 纬线向东路径（非最短）→ 大圆航线原理 → 飞行方向分解（东北→东南）→ 结论
- 教学价值：教师通过分步导航，可精确控制课堂节奏，从学生常见的"沿纬线一直向东"误区出发，逐步揭示大圆劣弧向北凸出的本质，最终得出"先东北再东南"的正确结论。每步可随时回退，便于强调关键概念。

[分步序列]
- 步骤0（初始状态）：显示平面经纬网（经线80°/120°、纬线40°/60°），标注M、N两点及基本经纬度标签。右侧显示选项A/B/C/D。教师可在此引导学生观察M、N的位置关系。
- 步骤1（定位高亮）：高亮M、N两点（加大描边或发光效果），在M点左下方显示坐标标签 "(60°N, 80°E)"，在N点右下方显示 "(60°N, 120°E)"。在两点下方绘制双向箭头并标注 "经度差 40°"。教师强调两地同纬度、经度差40°。
- 步骤2（纬线路径）：沿60°N纬线绘制从M到N的红色虚线路径，下方标注 "沿纬线：一直向东" 和 "（非最短）"。教师指出这是学生常见误区，但纬线路径并非球面最短航线。
- 步骤3（大圆航线）：绘制从M到N向北凸出的蓝色弧线（大圆劣弧），标注 "最短航线（大圆劣弧）"，弧线上方标注 "向北凸出"。教师讲解大圆航线原理：球面上两点间最短路径是过地心的大圆劣弧，北半球同纬度两点间的大圆航线向北凸出。
- 步骤4（方向分解）：在大圆航线上添加方向箭头，前半段（M→转折点）标注 "东北"，后半段（转折点→N）标注 "东南"。在弧线最北点（转折点）用绿色圆点标记。教师分解飞行方向的变化：先向东北飞，到达最北点后转向东南。
- 步骤5（结论）：右侧选项区高亮 D. 先东北再东南（绿色背景+边框），其他选项淡化（opacity=0.4）。教师确认正确答案，总结解题思路。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「◀ 上一步」按钮：位于 SVG 内底部 (280,460)，宽90×高30。点击回退到上一状态，步骤0时禁用（opacity=0.4）。
  2. 步骤指示器：位于 (380,460)，显示当前步骤如 "步骤 1/6"。
  3. 「下一步 ▶」按钮：位于 (470,460)，宽90×高30。点击前进到下一状态，步骤5时禁用（opacity=0.4）。
- 教师操作流程：
  1. 教师打开图示，学生看到初始经纬网和选项。
  2. 教师点击「下一步」进入步骤1，高亮M、N并显示坐标，讲解两地位置关系。
  3. 继续点击「下一步」进入步骤2，展示纬线路径，提问学生这是否是最短航线。
  4. 进入步骤3，展示大圆航线，讲解"向北凸出"原理。
  5. 进入步骤4，分解方向为东北→东南，在转折点处停顿强调。
  6. 进入步骤5，高亮正确选项D，总结答案。讲解过程中可随时点击「上一步」回退复习。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript。原因：本场景为二维几何图示，仅涉及基本图形（线、圆、路径、文本）和简单的显隐/高亮控制，原生SVG足以胜任，无需引入外部库，保持代码轻量。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------------+
  |  [图示区 800×500]                                      |
  |                                                        |
  |     80°        120°                                    |
  |       |          |      60°                            |
  |   M---●----------●---N  ←纬线（虚线，步骤2）            |
  |       |          |      40°                            |
  |       |          |                                     |
  |        \   ↑   /   ←大圆航线（弧线，步骤3）             |
  |         \  |  /                                        |
  |      东北 ● 东南  ←方向箭头（步骤4）                    |
  |                                                        |
  |   A.一直向东                                           |
  |   B.先东南再东北      ←选项区（右侧）                   |
  |   C.一直向西                                           |
  |   D.先东北再东南  ★（步骤5高亮）                       |
  |                                                        |
  |        [◀上一步]  [步骤X/6]  [下一步▶]                 |
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `currentStep`（0~5），每步对应一个显示配置对象，记录各元素的 visibility、opacity、stroke-width 等属性。
  2. 坐标计算：大圆航线使用二次贝塞尔曲线 `Q` 指令，控制点 (325,10)，确保弧线顶点约在 (325,80)，凸出效果明显。
  3. 动画曲线：步骤切换时，新增元素使用 CSS transition（opacity 0→1，duration 300ms，ease-out），移动元素不使用动画（直接切换位置，避免分散注意力）。
  4. 事件绑定：按钮点击事件更新 `currentStep`，调用 `renderStep()` 函数，根据配置对象批量设置各 SVG 元素和 HTML 选项的 class/属性。
  5. 选项高亮：步骤5时，给选项D的 div 添加 class `highlight-correct`（绿色背景+边框），给其他选项添加 class `dimmed`（opacity: 0.4）。
  6. 箭头绘制：使用 `<marker>` 定义箭头头部，东北/东南方向箭头通过计算切线方向绘制短线段。
- **ID 命名规范**：所有 SVG 元素和 HTML 控件 ID 必须以 `scene1-` 为前缀。例如：
  - 经线80°：`scene1-meridian-80`
  - M点：`scene1-point-m`
  - 大圆航线：`scene1-great-circle`
  - 上一步按钮：`scene1-btn-prev`
  - 选项D：`scene1-option-d`
  JS 中严格使用 `document.getElementById` 获取元素，禁止跨场景选择器。
- IIFE 隔离：所有 JavaScript 代码包裹在 `(function() { ... })()` 中，避免全局变量污染，确保多场景合并时互不干扰。
