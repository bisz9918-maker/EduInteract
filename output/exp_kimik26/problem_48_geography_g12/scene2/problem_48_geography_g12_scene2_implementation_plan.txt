[图示主题与整合说明]
- 本图示主题：地球表面某区域经纬网示意图 —— 对跖点（关于地心对称的点）坐标求解
- 整合内容：对跖点几何定义 → 地球截面展示 → 纬度变换规则（数值不变，南北纬相反） → 经度变换规则（东西经相反，互补为180°） → M(60°N, 80°E) 的对跖点坐标推导 → 结论 M'(60°S, 100°W)
- 教学价值：教师通过分步导航，先建立过地心直线的几何直观，再分别拆解纬度与经度的变换规则，最后合成完整坐标并对应选项，帮助学生从空间想象过渡到抽象坐标运算。

[分步序列]
- 步骤0（初始状态）：显示地球大圆、赤道（虚线）、地轴（虚线）、地心 O（含标签）、北极 N、南极 S、赤道标签、地轴标签。建立地球截面参考系。
- 步骤1（标注M点）：新增 M 点（蓝）、OM 半径（蓝）、M 坐标标签 "M(60°N, 80°E)"、纬度圆心角弧线及 "60°" 标注。教师讲解 M 点在地球上的位置。
- 步骤2（绘制对称线）：新增 MM' 直线（黑色实线，穿过 O）、OM' 延长线（红）、M' 点（红）、"过地心" 标签。教师讲解对跖点的几何定义：过地心的直线与地球表面的另一交点。
- 步骤3（标注M'位置）：新增 M' 临时标签 "M'"。教师确认 M' 位于南半球、圆周对面的对称位置。
- 步骤4（纬度变换）：新增左侧双向箭头（60°N↔60°S）、"60°N" 与 "60°S" 标注、纬度规则框（绿底）及文字 "纬度：数值不变，南北纬相反"。教师讲解纬度变换规则。
- 步骤5（经度变换）：新增经度示意图（轴线、0°/180°E/180°W、80°E 蓝标记、100°W 红标记、互补双向箭头）、规则文字 "经度：东西经相反，互补（和为180°）"、计算式 "180° − 80° = 100°"。教师讲解经度变换规则。
- 步骤6（完整坐标与结论）：M' 临时标签替换/增补为完整坐标 "M'(60°S, 100°W)"；新增四个选项卡片 A/B/C/D，选项 B 背景绿底高亮。教师总结对跖点坐标并点明正确答案。
- 教师可随时点击「上一步」回退复习，点击「下一步」继续推进。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「上一步」按钮：位于 SVG 内底部 (280,450)，宽100×高30，点击回退一个步骤，到步骤0时禁用。
  2. 「下一步」按钮：位于 SVG 内底部 (420,450)，宽100×高30，点击推进一个步骤，到步骤6时禁用。
  3. 步骤指示器：位于 (400,490)，显示当前步骤 "步骤 X / 6"。
- 教师操作流程：教师先展示步骤0的基础地球截面，提问“什么是对跖点？”；点击「下一步」依次揭示 M 点、对称线、M' 点、纬度规则、经度规则、最终结论；在关键步骤可点击「上一步」让学生回顾几何关系。

[技术实现]
- JS 库选择：原生 SVG（使用 <svg> + <circle> <line> <path> <text> <rect>），无需额外库。理由：本场景为静态几何图形分步显隐，无复杂动画或数据绑定，原生 SVG 最轻量且可控。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图：
  ```
  +----------------------------------------------------------+
  |                    地轴(300,70)                           |
  |                      |                                   |
  |   M(60°N,80°E)      N(295,90)        [纬度规则框]        |
  |    ·                /                [经度规则区]        |
  |     \ 60°          /                 [80°E][100°W]       |
  |      \            /                                      |
  |  -----O---------------- 赤道                             |
  |        \          \                                      |
  |         \          \        [选项A][选项B]               |
  |          ·'         S       [选项C][选项D]               |
  |         M'(60°S,100°W)                                   |
  |                                                          |
  |     [上一步]    步骤 X/6    [下一步]                     |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机：用变量 `let currentStep = 0;` 控制 0~6 共7个状态。
  2. 元素显隐：每个 SVG 元素设置 `id`，通过 `document.getElementById` 获取，根据 `currentStep` 设置 `display` 属性（`block`/`none`）或 `opacity` + `transition`。
  3. 步骤6 的 M' 完整坐标：步骤3 的 "M'" 标签在步骤6 时保持显示，新增完整坐标标签于 (365,415)，避免替换导致闪烁；或统一在步骤6 显示完整坐标并隐藏临时标签。建议步骤3显示临时标签，步骤6隐藏临时标签、显示完整坐标标签。
  4. 选项高亮：步骤6 时给选项B卡片设置填充色 `#2e7d32`、透明度 20%，文字加粗。
  5. 按钮禁用逻辑：`currentStep === 0` 时禁用「上一步」；`currentStep === 6` 时禁用「下一步」。
  6. 坐标计算：M 点角度 60°（与水平线夹角），M(280-150*cos60°, 250-150*sin60°) = (205, 120)；M' 为对径点 (355, 380)。纬度弧线使用 SVG `<path>` 的 `A` 命令绘制。
- ID 命名规范：所有交互元素 ID 必须以 `scene2-` 为前缀，例如 `scene2-earth-circle`、`scene2-point-m`、`scene2-latitude-rule-box`、`scene2-btn-prev`、`scene2-btn-next`。
- IIFE 隔离：所有 JavaScript 代码包裹在 `(function() { ... })();` 中，避免多场景合并时全局变量污染。
