    本图示展示南极点俯视图中的晨昏线与日期分界线关系。教师应引导学生关注以下要点：

    1. **判断极昼极夜**：晨昏线MA与70°S相切，说明太阳直射点纬度与70°互余，即直射20°S或20°N。结合南极点视角及切点M所在经线为0时（夜半球中央），可判断南极附近为极昼，故太阳直射20°S。

    2. **解读阴影区**：阴影区表示与全球其他地区日期不同，其两条边界经线必为0时经线和180°经线。根据地球顺时针自转（南极俯视），旧的一天从180°经线向东（顺时针）到0时经线。图中阴影区跨60°经度，位于180°与120°W之间，故120°W为0时经线，180°为国际日期变更线。

    3. **确定直射经线**：0时经线（120°W）与12时经线（太阳直射经线）相差180°，故12时经线为60°E。

    4. **太阳直射点坐标**：综合上述，太阳直射点坐标为(20°S, 60°E)。

    讲解时建议让学生先独立判断0时经线是哪一条，再通过"0时与12时相对"快速锁定直射经线。可提问：若误把180°当成0时经线，直射点会在哪里？以此强化对日期分界线的理解。

    本图示展示正午太阳高度角与地方时的定量计算，教师可结合右侧数轴逐步讲解。

    **正午太阳高度角**：
    公式为 $H = 90^\circ - |\varphi - \delta|$，其中 $\varphi$ 为当地纬度，$\delta$ 为太阳直射纬度。
    代入 $\varphi = 30.5^\circ\text{N}$，$\delta = 20^\circ\text{S}$，注意南北纬相减取绝对值和：
    $$H = 90^\circ - |30.5^\circ - (-20^\circ)| = 90^\circ - 50.5^\circ = 39.5^\circ$$

    **地方时计算**：
    太阳直射经线为60°E，其地方时为12:00。我国某地经度为114.5°E，两地经度差为：
    $$\Delta\lambda = 114.5^\circ\text{E} - 60^\circ\text{E} = 54.5^\circ$$
    经度每差1°，地方时相差4分钟：
    $$\Delta t = 54.5^\circ \times 4\,\text{min/°} = 218\,\text{min} = 3\,\text{h}\,38\,\text{min}$$
    该地位于60°E以东，地方时更早：
    $$T = 12:00 + 3\,\text{h}\,38\,\text{min} = 15:38$$
    若按北京时间（120°E）估算，时差为4小时，约为16:00。讲解时需强调"地方时"与"区时/北京时间"的区别，避免学生混用。

    **课堂建议**：
    先通过图示一建立空间概念，再通过图示二完成定量计算。可让学生先独立口算经度差，再核对时间换算，避免常见错误（如东西方向判断反、纬度差算错、忽略南北纬符号）。最后可拓展提问：若我国某地位于30.5°S，正午太阳高度角又是多少？以此巩固公式。
