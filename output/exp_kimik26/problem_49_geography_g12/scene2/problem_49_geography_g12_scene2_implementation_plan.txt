[技术实现]
- JS库选择：原生SVG（简单几何图形、文本、路径，无需复杂图表库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  0    100  200  300  400  500  600  700  800
  +----+----+----+----+----+----+----+----+
  | 标题区（如有，y=0~30）                |
  |  [左侧：太阳高度角侧视图]  [右侧：经度-时间轴] |
  |  y=60~350                               |
  |    地球圆(170,240)        经度轴(360~760,300) |
  |    P点/地平圈/光线        刻度/时间标签      |
  |    H弧线                  经度差箭头         |
  |                           换算文本(步骤3)    |
  |  [公式区：y=355~425，居中]                |
  |                                         |
  |  [控件栏：y=440~490]                     |
  |       [◀上一步]  步骤 2/4  [下一步▶]      |
  +----+----+----+----+----+----+----+----+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 `currentStep`（0~3）记录当前步骤，每步定义显示/隐藏的元素ID列表
  2. 元素显隐控制：为每步需要切换的元素设置唯一ID，通过 `setAttribute('display', 'none'/'block')` 或 `classList.toggle('hidden')` 控制
  3. 动画曲线：H标签高亮使用CSS transition（transform: scale + fill颜色变化，0.3s ease-out）；换算文本逐行淡入使用CSS opacity transition（每行延迟0.15s）
  4. 箭头marker：在SVG `<defs>` 中定义红色和绿色arrowhead marker，供光线和双向箭头复用
  5. 弧线绘制：使用SVG path的A命令，计算起点(208-22,286)和终点(208+22*cos(140.5°),286+22*sin(140.5°))，大弧标志设为0， sweep-flag设为0（逆时针）
  6. 按钮禁用态：最终步骤时给「下一步」按钮添加 `disabled` class（opacity: 0.4, pointer-events: none），步骤0时给「上一步」按钮同样处理
- ID命名规范：所有交互元素ID必须以 `scene2-` 为前缀，例如：
  * `scene2-earth-circle`
  * `scene2-sun-ray-1`
  * `scene2-formula-substitution`
  * `scene2-time-diff-arrow`
  * `scene2-btn-prev`
  * `scene2-btn-next`
  * `scene2-step-indicator`
  JS中严格使用 `document.getElementById('scene2-xxx')` 获取元素，禁止querySelectorAll配合全局class
- IIFE隔离：所有JS逻辑包裹在 `(function() { ... })()` 中，避免多场景合并时变量污染
- 响应式说明：画布固定800×500，外层容器设置 `max-width: 800px; margin: 0 auto`，确保在课件页面中居中显示
