**题目原文**

下图所示区域为昼半球，A为圆心，B点纬度为75°，其中A点西侧为东半球，东侧为西半球，据此回答下列问题。

(1) 此时太阳直射点的地理坐标是_________，C点的地理坐标是_________。此时北京时间是__________________。

(2) 图中A、B、C三点的线速度大小排列是_________(用“＞”“<”“＝”符号表示)；三点的正午太阳高度角大小排列是_________(用“＞”“<”“＝”符号表示)。

**题目分析**

本题是一道地球运动综合题，核心考查晨昏圈判读、东西半球界线、太阳直射点定位、地方时计算、地球自转线速度分布规律以及正午太阳高度角计算。解题关键在于正确理解"下图所示区域为昼半球"的含义——图中大圆为晨昏圈，圆心A为地心，圆内为昼半球。

**整体讲解思路**

1.  从题干条件出发，先确定图中的关键经线为160°E（东西半球分界线）。
2.  利用B点纬度75°及晨昏圈性质，推导出极昼/极夜边界，进而确定太阳直射纬度为15°N。
3.  结合直射经线160°E，确定太阳直射点完整坐标及C点坐标。
4.  通过经度差计算北京时间。
5.  最后分别比较三点线速度与正午太阳高度角。

课堂讲解建议配合两个核心图示：一是以晨昏圈为基础的光照图解析（定位直射点），二是以地球侧视图为基础的地理量比较（线速度+正午太阳高度角）。

**SCENE_1 教学说明**

本图示以晨昏圈光照图为核心，教师应引导学生建立"圆为晨昏圈、圆内地表为昼半球"的空间认知，这是整道题的突破口。

**讲解要点：**

1.  **东西半球经线判定**
    - 东半球范围：20°W → 0° → 160°E
    - 西半球范围：160°E → 180° → 20°W
    - 因此，西侧为东半球、东侧为西半球的经线只能是 **160°E**。在图中即垂直经线。

2.  **直射纬度推导**
    - B在晨昏圈上且纬度75°S，说明75°S是极夜边界。
    - C在晨昏圈上且纬度75°N，说明75°N是极昼边界。
    - 极昼（夜）边界纬度与直射纬度的关系：**边界纬度 = 90° - 直射纬度**
    - 故直射纬度 = 90° - 75° = **15°N**。

3.  **直射经线与直射点**
    - 昼半球中央经线即为太阳直射经线，地方时为12:00。
    - 图中160°E为昼半球中央经线，因此太阳直射点坐标为 **(15°N, 160°E)**。

4.  **C点坐标**
    - C点位于160°E经线与晨昏圈的交点，且为极昼边界，故坐标为 **(75°N, 160°E)**。

5.  **北京时间计算**
    - 北京采用120°E地方时（东八区中央经线）。
    - 160°E与120°E经度差为40°，时差为 40° × 4分钟/° = 160分钟 = **2小时40分钟**。
    - 120°E位于160°E西侧，时间更晚：12:00 - 2:40 = **9:20**。

**课堂引导语建议：**"请大家观察，如果这个大圆是晨昏圈，那么B点和C点恰好落在晨昏圈上，它们的纬度75°告诉我们什么信息？极昼极夜的边界与太阳直射点之间有什么数量关系？"

**SCENE_2 教学说明**

本图示承接SCENE_1的坐标结论，在同一地球侧视图上依次展开线速度与正午太阳高度角的比较，教师应注意引导学生区分"地球自转"与"公转/太阳辐射"两个不同视角。

**讲解要点：**

1.  **线速度比较**
    - 地球自转线速度公式：**v = ωR·cosφ**
    - A点在赤道，φ = 0°，cos0° = 1，故 **v_A = ωR**（最大）。
    - B点在75°S，C点在75°N，|φ| = 75°，cos75° ≈ 0.259，故 **v_B = v_C = ωR·cos75°**。
    - 结论：**v_A > v_B = v_C**。
    - 注意：线速度只与纬度有关，与经度、昼夜状态无关。

2.  **正午太阳高度角比较**
    - 正午太阳高度角公式：**H = 90° - |φ - δ|**，其中δ = 15°N。
    - A点（赤道，φ = 0°）：H_A = 90° - |0° - 15°| = **75°**
    - C点（75°N，φ = 75°N）：H_C = 90° - |75° - 15°| = **30°**
    - B点（75°S，φ = 75°S）：H_B = 90° - |-75° - 15°| = 90° - 90° = **0°**
    - 结论：**H_A > H_C > H_B**
    - 特别提示：B点正午太阳高度角为0°，恰好位于晨昏圈上，说明此时B点处于日出或日落时刻（但正午太阳高度角是指正午时刻的理论值，此处因纬度与直射点纬度相差90°，理论正午太阳高度为0°）。

**课堂引导语建议：**"线速度只看纬度高低，离赤道越近越快；正午太阳高度角看该点与直射点的'纬度距离'，距离越近角度越大。请同学们观察，B点和C点纬度相同，线速度相等，但为什么正午太阳高度角却大不相同？"
</TEXT_3>

**完整解答与课堂总结**

**(1) 太阳直射点、C点坐标与北京时间**

- 太阳直射点地理坐标：**(15°N, 160°E)**
- C点地理坐标：**(75°N, 160°E)**
- 北京时间：**9:20**

**(2) 线速度与正午太阳高度角排列**

- 线速度：**v_A > v_B = v_C**
- 正午太阳高度角：**H_A > H_C > H_B**

**课堂讲解建议：**

1.  **先图后数**：务必让学生在SCENE_1中先建立晨昏圈与昼半球的空间概念，再进入数值计算。若学生误判图为"完整地球"而非"昼半球"，后续全部出错。
2.  **强调160°E的判定逻辑**：东西半球分界线有两条（20°W和160°E），只有160°E满足"西侧东半球、东侧西半球"，这是易错点。
3.  **极昼边界与直射纬度的互推**：熟练掌握"极昼（夜）最低纬度 = 90° - 直射纬度"这一关系，可双向推导。
4.  **时间计算细节**：注意北京时间为120°E地方时，不是北京当地经度（116°E）的地方时，这是学生常混淆的概念。
5.  **线速度与角速度区分**：若学生追问，可补充说明三点角速度相等（ω_A = ω_B = ω_C），但线速度因半径分量不同而有差异。
