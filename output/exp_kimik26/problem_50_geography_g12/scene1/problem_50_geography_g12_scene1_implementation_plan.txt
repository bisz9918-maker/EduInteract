[图示主题与整合说明]
- 本图示主题：昼半球晨昏圈与太阳直射点定位
- 整合的步骤/概念：将东西半球界线判定（160°E）、极昼极夜边界与太阳直射纬度推导（90°-75°=15°N）、太阳直射点地理坐标确定（15°N, 160°E）、C点坐标确定、北京时间计算（160°E为12:00 → 120°E为9:20）整合为一条递进式可视化链。
- 教学价值：教师通过分步导航，可按照"空间定位 → 半球分界 → 纬度推导 → 直射点定位 → 时间计算"的认知顺序逐层展开，学生能在每一步建立清晰的空间概念，避免信息过载。

[分步序列]
- 步骤0（初始状态）：显示晨昏圈大圆（含昼半球浅橙填充）、地心A及标签、赤道及标签、垂直经线（尚未标注160°E）、B点及标签、C点及标签。建立基础空间框架，信息密度最低。
- 步骤1（半球分界）：垂直经线保持红色，新增"160°E"标签(425,115)；在圆左侧新增"东半球"标签(180,270)，右侧新增"西半球"标签(620,270)。教师讲解"A点西侧为东半球、东侧为西半球"→该经线为160°E。
- 步骤2（极昼极夜边界）：新增75°N虚线弦(310,150)-(490,150)及标签"75°N"(500,145)；新增75°S虚线弦(310,390)-(490,390)及标签"75°S"(500,395)。教师说明B(75°S)与C(75°N)分别为极夜与极昼边界。
- 步骤3（直射纬度推导）：新增15°N实线弦(260,210)-(540,210)及标签"15°N"(565,210)；在左上方新增公式文本"90° - 75° = 15°N"(220,180)；在(400,210)高亮太阳直射点（橙色星形）并新增标签"太阳直射点"(420,205)。教师推导直射纬度。
- 步骤4（坐标定位与光照）：新增直射点坐标标签"(15°N, 160°E)"(420,225)；新增C点坐标标签"C(75°N, 160°E)"(420,150)；从右侧引入三条橙色平行太阳光线（y=190/210/230）指向地球，强化直射概念。
- 步骤5（时间计算）：在圆顶上方新增时间辅助线(400,120)→(280,120)；在(400,105)标注"12:00"；在(280,115)标注"120°E"；在(280,95)标注"9:20"；在辅助线中点上方(340,100)标注"40°"，下方(340,135)标注"2h40m"；在(340,75)高亮显示"北京时间 9:20"。教师完成时间推导。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：
  1. 「上一步」按钮：位于(320,455)，宽80×高32，点击回退到上一状态。
  2. 「下一步」按钮：位于(440,455)，宽80×高32，点击推进到下一状态。
  3. 步骤指示文本：位于(400,495)，显示当前步骤名称（如"步骤 1/5：半球分界"）。
- 教师操作流程：教师点击「下一步」依次展开推导链条；可随时点击「上一步」回退复习；每一步的视觉变化聚焦单一概念，配合口头讲解。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本场景为静态几何图形与标签的分步显隐，无复杂动画或函数绘图，原生SVG性能最佳且无需额外库。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图：
  ```
  [图示区 800×430]
    顶部(y=60-140)：时间计算辅助标注（步骤5）
    中央(y=120-420)：晨昏圈大圆(R=150,圆心400,270)
      - 内部：赤道(水平)、160°E(垂直)、75°N/75°S/15°N纬线弦
      - 点：A(圆心)、B(下)、C(上)、直射点(中上)
      - 右侧入射：太阳光线(步骤4)
    左侧(x=180)：东半球标注
    右侧(x=620)：西半球标注
  [控件栏 y=440-490]
    [◀上一步] [下一步▶]
         步骤指示文本
  ```
- 关键实现要点：
  1. 状态机设计：维护变量 `currentStep`（0~5）。初始化时设置 `currentStep = 0` 并渲染对应元素。
  2. 元素显隐控制：为每个SVG元素设置 `data-step` 属性（如 `data-step="1,2,3,4,5"` 表示该元素在步骤1-5均可见）。切换步骤时遍历所有元素，若当前步骤在 `data-step` 列表中则 `style.display = 'block'`，否则 `'none'`。
  3. 高亮效果：步骤3高亮太阳直射点时，可通过改变星形 `r` 或添加 `filter: drop-shadow` 实现脉冲；步骤5高亮"北京时间 9:20"时，将该文本 `font-weight` 设为bold并添加蓝色背景矩形。
  4. 动画曲线：分步切换无需复杂动画，直接显隐即可；若需柔和过渡，可对透明度使用CSS transition（0.2s ease）。
  5. 事件绑定：上一步/下一步按钮绑定 `click` 事件，更新 `currentStep` 后调用 `renderStep()`。
- ID命名规范：所有SVG元素及控件ID必须以 `scene1-` 为前缀。例如：
  - 大圆：`scene1-circle-main`
  - A点：`scene1-point-a`
  - 赤道线：`scene1-line-equator`
  - 160°E线：`scene1-line-meridian`
  - B点：`scene1-point-b`
  - C点：`scene1-point-c`
  - 75°N纬线：`scene1-lat-75n`
  - 75°S纬线：`scene1-lat-75s`
  - 15°N纬线：`scene1-lat-15n`
  - 直射点：`scene1-sun-point`
  - 太阳光线组：`scene1-sun-rays`
  - 时间辅助线：`scene1-time-line`
  - 各文本标签：`scene1-label-xxx`
  - 按钮：`scene1-btn-prev`、`scene1-btn-next`
  - 步骤指示：`scene1-step-indicator`
  JS中严格使用 `document.getElementById` 获取元素，禁止全局class选择，避免多场景合并时跨场景污染。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，不暴露全局变量。
