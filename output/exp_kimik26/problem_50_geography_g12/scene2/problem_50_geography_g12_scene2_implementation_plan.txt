[图示主题与整合说明]
- 本图示主题：地球自转线速度与正午太阳高度角比较
- 整合的步骤/概念：
  1. 在地球侧视图上建立 A（圆心/赤道）、B（75°S）、C（75°N）三点的视觉锚点；
  2. 分步叠加自转线速度箭头，展示 v_A > v_B = v_C；
  3. 引入正午太阳高度角公式 H = 90° - |φ - δ|；
  4. 引入平行太阳光线（与水平成 15°）、地平面切线与太阳高度角弧线，展示 H_A(75°) > H_C(30°) > H_B(0°)。
- 教学价值：教师可在同一幅侧视图上先讲线速度再讲太阳高度角，利用统一的 A/B/C 空间锚点降低学生认知负荷；分步导航支持随时回退复习。

  - 光线C：过 (321,96)，端点 (520,43) 与 (160,139)
  - 光线B：过 (321,405)，端点 (520,330) 与 (120,437)
- 地平面切线：SVG <line>，stroke=#888888 stroke-width=1 stroke-dasharray=4,4
  - A：垂直线 (280,210)-(280,290)

[分步序列]
- 步骤0（初始状态）：显示地球圆、赤道线、A/B/C 三点及标签（A、B、C、赤道）。右侧空白，等待教师讲解题目背景。
- 步骤1（线速度比较）：
  - 出现绿色水平箭头：A(280,250)→(355,250)、C(321,96)→(340,96)、B(321,405)→(340,405)
  - 出现标签 ωR（A箭头上方）、ωR·cos75°（C箭头右上方、B箭头右下方）
  - 右侧出现结论文字 "v_A > v_B = v_C"（#000000，18px）
  - 教师讲解：赤道线速度最大，纬度 75° 处线速度相等且为赤道 cos75° 倍。
- 步骤2（正午太阳高度角公式）：
  - 保留步骤1元素（可略微降低透明度至 0.3，避免与后续内容争夺注意力）
  - 右上方出现公式 "H = 90° - |φ - δ|" 及 "δ = 15°N"
  - 教师讲解公式及太阳直射点纬度。
- 步骤3（三点正午太阳高度角）：
  - 出现三条橙色平行太阳光线（与水平约 15°），分别穿过 A、B、C
  - 出现三条灰色虚线地平面切线（A 垂直，B/C 倾斜 -15°）
  - 出现蓝色太阳高度角弧线：A 点 75°、C 点 30°；B 点不画弧线（H=0° 与地平面平齐）
  - 出现角度标注 "75°"、"30°"、"0°"
  - 教师讲解：A 在赤道 H=75°，C 在 75°N H=30°，B 在 75°S 恰为晨昏线 H=0°。
- 步骤4（比较结论）：
  - 三个角度值（75°、30°、0°）高亮（#c62828 加粗）
  - 右侧出现结论文字 "H_A(75°) > H_C(30°) > H_B(0°)"（#c62828，18px bold）
  - 教师总结两个地理量的比较规律。

[交互方案]
- 交互类型：分步按钮导航（◀ 上一步 / 下一步 ▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 内底部 (300,460)，宽 80px，高 30px；点击回退到上一状态。
  - 「下一步」按钮：位于 SVG 内底部 (420,460)，宽 80px，高 30px；点击推进到下一状态。
  - 步骤指示器：在两按钮之间显示 "步骤 1/4" 等文字（x=380, y=475，或合并到按钮区域）。
- 教师操作流程：
  1. 加载后呈现步骤0，教师先回顾 A/B/C 三点位置与纬度；
  2. 点击「下一步」进入步骤1，讲解线速度分布；
  3. 点击「下一步」进入步骤2，写出公式并说明 δ=15°N 的来源；
  4. 点击「下一步」进入步骤3，叠加光线与地平面，逐一推导三点太阳高度角；
  5. 点击「下一步」进入步骤4，高亮结论；
  6. 可随时点击「上一步」回退到任意步骤复习。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript。理由：本场景为静态几何图形与分步显隐，无复杂动画或数据绑定，原生 SVG 性能最佳且无需额外库。
- 画布尺寸：800 × 500 px（SVG viewBox="0 0 800 500"）
- 布局草图：
  ```
  [图示区 800×440]
  +--------------------------------------------------+
  |  公式/结论区(右)      地球圆(中左)                  |
  |  (520,120)           圆心A(280,250)               |
  |  (520,250)           C(321,96)  B(321,405)        |
  |                      赤道 y=250                   |
  |                                                   |
  |                      太阳光线(右上→左下 15°)       |
  |                      地平面切线(灰虚线)            |
  +--------------------------------------------------+
  [控件栏 y=440~490]
  +--------------------------------------------------+
  |        [◀ 上一步]  步骤 X/4  [下一步 ▶]           |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 `currentStep`（0~4），每一步定义显隐元素 ID 列表。切换步骤时遍历所有元素，按当前步骤设置 `display` 或 `visibility`。
  2. 太阳光线坐标计算：统一斜率 k = -tan(15°) ≈ -0.268。过点 (x0,y0) 的直线方程 y - y0 = k(x - x0)。取 x 范围 [120,520] 计算端点，确保光线贯穿整个主图区。
  3. 太阳高度角弧线：
     - A 点弧线：使用 SVG <path> d="M 280 275 A 25 25 0 0 0 304.1 243.5"（从垂直向下逆时针 75° 到光线方向）。
     - C 点弧线：d="M 345.1 102.5 A 25 25 0 0 0 345.1 89.5"（从 15° 方向顺时针 30° 到 -15° 方向，使用 large-arc-flag=0 sweep-flag=0）。
  4. 动画曲线：分步切换不使用动画，直接显隐（教师课件追求清晰与快速，过渡动画反而干扰）。若需柔和效果，可加 150ms opacity 过渡。
  5. 事件绑定：按钮绑定 click 事件，更新 currentStep 后调用 `renderStep()`。
  6. 元素分组：用 SVG <g> 按步骤分组（如 id="scene2-step1-group"），便于整体显隐。
- ID 命名规范：所有元素 ID 必须以 `scene2-` 为前缀。例如：
  - 地球圆：`scene2-earth-circle`
  - A点：`scene2-point-a`
  - 步骤1线速度组：`scene2-step1-velocity-group`
  - 上一步按钮：`scene2-btn-prev`
  - 下一步按钮：`scene2-btn-next`
- IIFE 隔离：所有 JS 包在 `(function() { ... })()` 中，避免多场景合并时全局变量污染。
