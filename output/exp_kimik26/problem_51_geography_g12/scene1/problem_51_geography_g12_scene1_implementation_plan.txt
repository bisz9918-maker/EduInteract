[图示主题与整合说明]
- 本图示主题：侧视光照图要素解析与冬至节气判断
- 整合的步骤/概念：地轴与极点识别 → 自转方向标注 → 晨昏线与昼夜半球判定 → 虚线（北极圈/南回归线）识别 → 北极极夜现象 → 冬至判断与太阳直射纬度确定
- 教学价值：教师通过分步导航，按"要素识别→现象分析→结论得出"的递进逻辑展开讲解，可随时回退强调关键细节（如地轴倾斜、晨昏线过地心、极夜范围等），帮助学生建立光照图判读的系统思维。

[分步序列]
- 初始状态（步骤0）：显示地球圆、地轴AO（黑色）、晨昏线BOC（黑色，与地轴同色）、0°经线（黑色弧线）、A/B/C/O四个点及字母标签、0°标签。此时晨昏线暂不红色高亮，夜半球暂不填充，呈现"素图"供学生整体感知。
- 步骤1：点击「下一步」→ 地轴AO加粗至3px并变为深蓝色(#1565c0)，0°经线淡化至#cccccc；新增标签"北极点"(300,90)、"地心"(430,290)。教师讲解地轴概念及两极位置。
- 步骤2：点击「下一步」→ 在北极点A附近出现逆时针自转方向箭头（蓝色弧箭头），新增标签"N"(345,85)、"北逆南顺"(300,150)。教师讲解自转方向判极法则。
- 步骤3：点击「下一步」→ 0°经线恢复黑色并加粗至2px，晨昏线BOC变为红色(#c62828)并加粗至2.5px；新增标签"北极圈交点"(310,185)、"南回归线交点"(470,340)。教师讲解经线与晨昏线识别。
- 步骤4：点击「下一步」→ 晨昏线左侧扇形区域填充为蓝色半透明(#1565c0, 20%)，表示夜半球；右侧标注"昼半球"(500,260)。教师讲解昼夜半球划分。
- 步骤5：点击「下一步」→ 出现北极圈虚线(240,250)-(516,150)和南回归线虚线(284,370)-(560,270)；新增标签"66°34′N"(220,245)、"23°26′S"(570,280)。教师讲解虚线代表的纬线。
- 步骤6：点击「下一步」→ 北极圈以内（A点附近）的夜半球区域额外填充一层深蓝色(#0d47a1, 30%)，高亮显示北极圈内完全处于夜半球；地轴和晨昏线保持高亮。教师引导学生观察得出"北极圈内极夜"现象。
- 步骤7（最终）：点击「下一步」→ 右侧出现太阳(620,260)及三条水平向左橙色光线箭头；新增绿色高亮标签"冬至日"(600,400)、"太阳直射23°26′S"(420,360)。教师总结：北极圈极夜→北半球冬至日→太阳直射南回归线。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  1. 「上一步」按钮：位置(280,455)，宽80高30，点击回退到上一状态，步骤0时禁用
  2. 「下一步」按钮：位置(440,455)，宽80高30，点击推进到下一状态，步骤7时禁用
  3. 步骤指示器：位置(370,460)，显示当前步骤编号如"步骤 1/8"
- 教师操作流程：教师先展示步骤0素图让学生观察→点击「下一步」依次展开地轴、自转、晨昏线、昼夜半球、纬线、极夜现象、冬至结论→讲解过程中可随时点击「上一步」回退到关键步骤（如步骤3晨昏线红色高亮、步骤6极夜高亮）进行强调。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：本场景为静态几何图形分步展示，无复杂动画或数据绑定，原生SVG足以高效绘制圆、线、弧、路径，且便于通过class/attribute控制显隐和样式。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------------+
  |                                                        |
  |     N                                                  |
  |     A  <--北极点                                       |
  |    / \  0°                                             |
  |   /   \ 经线                                           |
  |  / 夜  \    B <--北极圈交点                             |
  | |  半   |\   /                                         |
  | |  球   | \ / 晨昏线(红色)                              |
  | |       |  O 地心                                      |
  | |       | / \                                          |
  |  \     / /   \ C <--南回归线交点                        |
  |   \   / /     \                                        |
  |    \ / /       \                                       |
  |     S /         太阳 ← ☉                               |
  |        冬至日                                          |
  |                                                        |
  |  [◀上一步]  步骤 X/8  [下一步▶]                        |
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep（0~7）记录当前步骤，每步定义 showElements 和 hideElements 列表，通过 setAttribute('display', 'block'/'none') 或 classList.toggle 控制。
  2. 坐标计算：地轴倾斜角20°，晨昏线与地轴夹角23°26′，所有关键点（A、B、C、O、圆周端点、纬线端点）通过三角函数预计算，确保几何关系准确。
  3. 夜半球path：使用SVG path的A命令绘制大圆弧，从晨昏线上端(290,144)沿左侧圆弧到南端(510,376)，再直线闭合。
  4. 极夜高亮扇形：在步骤6中，用clipPath或单独path绘制北极圈以内且位于晨昏线左侧的扇形区域，填充深蓝色30%。
  5. 动画曲线：分步切换无过渡动画（直接显隐），确保课堂讲解节奏可控；如需柔和效果，可加100ms的opacity过渡。
  6. 事件绑定：上一步/下一步按钮绑定click事件，更新currentStep后调用renderStep()重绘界面。
- ID命名规范：所有SVG元素及控件ID必须以 scene1- 为前缀，例如 scene1-earth-circle、scene1-axis-ao、scene1-btn-prev、scene1-label-a 等。JS中使用 getElementById 获取元素，禁止querySelectorAll配合全局class。
- IIFE隔离：所有JavaScript代码包裹在 (function() { ... })() 中，避免多场景合并时变量污染。
