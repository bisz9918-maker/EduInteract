[图示主题与整合说明]
- 本图示主题：东西半球划分与A、B经度判定
- 整合的步骤/概念：
  1. 标准东西半球分界线（20°W、160°E）的空间概念；
  2. 题目侧视展开图中北半球对应东半球、南半球对应西半球的范围映射；
  3. 利用"经线均匀分布"推断端点经度：北半球7条经线跨180°→间隔30°→A=160°E；南半球8条经线跨140°→间隔20°→B=160°W；
  4. 进一步定位甲（140°W）、乙（130°E）、C（70°E）。
- 教学价值：教师可通过分步导航，逐步建立"分界线→半球范围→端点经度→各点经度"的认知链条，随时回退强化关键节点。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本场景为静态几何图形与分步显隐，无需复杂数学计算或3D渲染，原生SVG路径、线段、文本即可满足，减少外部依赖。
- 画布尺寸：800 × 500 px（SVG viewBox="0 0 800 500"）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------------+
  |  [标准划分示意图]          N                           |
  |     (小圆)               /  \  ←北半球半圆（蓝填充）     |
  |                         / 东 \                         |
  |    20°W | 160°E        / 半球 \                        |
  |                       /        \  A(160°E)             |
  |  东半球  |  西半球    /__________\______乙(130°E)       |
  |                      [280]C[400]      [520]            |
  |                       赤道线 y=250                     |
  |                       \__________/                     |
  |                        \  西   /  ←南半球半圆（绿填充）  |
  |                         \ 半球 /                       |
  |                          \    /                        |
  |                     B    \  /    20°W                  |
  |                   (160°W) \/                           |
  |                            S                           |
  |                         图1-9                          |
  |                                                        |
  |        [◀ 上一步]   步骤 X/5   [下一步 ▶]              |
  +--------------------------------------------------------+
  画布 800×500，控件栏在 y=440~490（SVG内绝对定位）
  ```

- 关键实现要点：
  1. 状态机设计：用变量 `currentStep` ∈ {0,1,2,3,4}，每步对应一个显隐配置对象，列出该步应显示的元素ID列表。
  2. 元素显隐：所有可能变化的元素预先在SVG中绘制，默认 `display:none` 或 `opacity:0`，通过JS切换 `class="step-visible"` 控制。避免动态创建/销毁DOM。
  3. 坐标计算：
     - 北半球经线赤道端点：等差数列，首项280，公差40，7项。
     - 南半球经线赤道端点：首项333.33（520-240×140/180），公差26.67（240×20/180），8项。
     - 经线路径：北半球用 `<line x1="400" y1="130" x2="xk" y2="250"/>`；南半球用 `<line x1="400" y1="370" x2="xk" y2="250"/>`。
  4. 半圆路径：使用SVG `<path d="M 280 250 A 120 120 0 0 1 520 250"/>`（北半球，开口向下）；南半球同理开口向上。
  5. 填充色块：使用与轮廓相同的path，加 `fill` 属性，默认 `opacity:0` 或 `display:none`，步骤0时显示。
  6. 动画曲线：分步切换不使用动画，直接显隐（教师课件追求快速响应）；如需柔和过渡，可加0.2s CSS transition on opacity。
  7. 事件绑定：按钮绑定 `click` 事件，更新 `currentStep` 后调用 `renderStep()` 统一渲染。
  8. 按钮状态：步骤0时「上一步」disabled；步骤4时「下一步」disabled；通过class控制样式。

- ID命名规范：所有交互元素ID必须以 `scene1-` 为前缀。
  - 示例：`scene1-hemi-north`、`scene1-meridian-n-01`、`scene1-point-a`、`scene1-btn-prev`、`scene1-step-text`、`scene1-highlight-20w`
  - JS中获取元素严格使用 `document.getElementById('scene1-xxx')`，禁止用 `querySelectorAll` 配合全局class，避免多场景合并时跨场景污染。

- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，不暴露全局变量。如需暴露，仅挂载到 `window.scene1 = { init: ... }`。
