    **题目原文**

    如图，在四棱锥P-ABCD中，M，N分别为AC，PC上的点，且MN∥平面PAD，若CM：MA=1：4，则NC：NP=______.

    **题目分析**

    本题是一道立体几何填空题，核心考查两个知识点：
    1. **线面平行的性质定理**：若直线平行于平面，则过该直线的平面与原平面的交线与此直线平行。
    2. **平行线分线段成比例定理**（或相似三角形性质）：在三角形中，平行于一边的直线截其他两边（或延长线），所得对应线段成比例。

    **整体讲解思路**

    1. 首先引导学生观察图形，确认点M在AC上、点N在PC上，因此线段MN位于平面PAC内。
    2. 利用已知条件MN∥平面PAD，结合平面PAC与平面PAD的交线为PA，由线面平行的性质定理推出MN∥PA。
    3. 将空间问题转化为平面问题：在△PAC中，MN∥PA，根据平行线分线段成比例定理，有CM/CA = CN/CP。
    4. 由CM:MA = 1:4，得CM/CA = 1/5，从而CN/CP = 1/5，即CN:NP = 1:4。

    **图示规划说明**

    本题为立体几何问题，涉及3D空间中的线面关系以及平面内的比例计算。为帮助教师完整讲解，设计一个交互式3D图示，通过分步导航从空间结构逐步过渡到比例计算，覆盖从理解题意到得出结论的全过程。

    **本图示的教学说明**

    教师在讲解时应引导学生按以下逻辑观察：

    1. **确认共面关系**：首先让学生确认M在AC上、N在PC上，因此MN一定在平面PAC内。这是后续应用线面平行性质定理的关键前提。

    2. **识别交线**：强调平面PAC与平面PAD相交，交线为PA。可以提问学生："经过MN且与平面PAD相交的平面是哪个？交线是什么？"

    3. **应用性质定理**：由MN∥平面PAD，且MN ⊂ 平面PAC，平面PAC ∩ 平面PAD = PA，根据线面平行的性质定理，直接得到MN∥PA。此处要特别强调定理的条件：直线必须在平面内，且两平面必须有交线。

    4. **转化到平面问题**：得到MN∥PA后，问题完全转化为在△PAC中的平面几何问题。教师可以让学生独立回忆平行线分线段成比例定理。

    5. **比例计算**：
       - 由CM:MA = 1:4，得CM/CA = 1/(1+4) = 1/5。
       - 因为MN∥PA，所以CN/CP = CM/CA = 1/5。
       - 即CN = (1/5)CP，NP = (4/5)CP。
       - 故NC:NP = 1:4。

    6. **课堂提示**：可追问学生，如果CM:MA = m:n，那么NC:NP应该等于多少？（答案为m:n）帮助学生发现一般规律，强化对比例关系的理解。
