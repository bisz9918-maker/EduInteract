[图示主题与整合说明]
- 本图示主题：四棱锥中的线面平行性质与线段比例关系
- 整合内容：题目初始条件（四棱锥P-ABCD、M∈AC、N∈PC、MN∥平面PAD、CM:MA=1:4）→ 识别平面PAC与平面PAD → 确定交线PA → 应用线面平行性质定理得MN∥PA → 将空间问题转化为平面PAC内的比例计算 → 得出NC:NP=1:4
- 教学价值：教师可通过分步导航，按“空间→平面→计算”的认知链条逐步展开，随时回退重讲关键步骤（如交线的确定、定理的应用），右侧2D示意图帮助学生完成从3D空间到2D平面的思维降维。

[分步序列]
- 步骤1/6（初始条件）：显示完整3D四棱锥（含实线/虚线棱、AC、MN），标注顶点P/A/B/C/D、点M/N，显示条件标签"CM:MA = 1:4"（AC左下）和"MN ∥ 平面PAD"（MN右上蓝色）。2D示意图隐藏。
- 步骤2/6（识别平面）：在步骤1基础上，新增平面PAC绿色半透明填充与平面PAD蓝色半透明填充；MN线宽增至2.5px以强调MN⊂平面PAC。其余不变。
- 步骤3/6（确定交线）：在步骤2基础上，交线PA变为红色4px粗线；新增标签"平面PAC ∩ 平面PAD = PA"（PA左侧，红色13px）。
- 步骤4/6（推导线线平行）：在步骤3基础上，MN变为红色；新增标签"MN ∥ PA"（MN与PA之间，红色14px加粗）和"线面平行的性质定理"（右上空白区，红色14px）。
- 步骤5/6（平面比例关系）：3D四棱锥所有元素透明度降至0.25（dimmed）；右侧显示2D示意图（△PAC、红色PA'与MN'、点M'N'），标注"CM:CA = 1:5"（A'C'下方）。
- 步骤6/6（得出结论）：在步骤5基础上，2D图中新增"CN:CP = 1:5"（P'C'右侧），并高亮显示最终答案"NC:NP = 1:4"（底部中央，18px绿色加粗，带绿色背景框）。

[技术实现]
- JS库选择：原生SVG + Vanilla JS。理由：本题为静态几何图形与分步显隐，无需复杂动画库；原生SVG可精确控制每条棱、每个多边形的显隐与样式，且便于教师直接修改坐标。
- 画布尺寸：800×500 px（SVG固定viewBox="0 0 800 500"）。
- 布局草图：
  ```
  +--------------------------------------------------+
  |  [3D四棱锥主图区  x:50~500, y:50~420]             |
  |   P(300,110)                                     |
  |   /|\                                            |
  |  / | \      [2D示意图区 x:530~770, y:90~420]     |
  | /  |  \     △P'A'C'（步骤5-6显示）               |
  |A---B---C                                        |
  | \     /                                          |
  |  D---/                                           |
  |                                                  |
  |  [标注区环绕图形外侧]                             |
  +--------------------------------------------------+
  |  [控件栏 y:440~490]  ◀ 上一步  步骤X/6  下一步 ▶  |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：变量 `currentStep` 取值为1~6。初始化 `currentStep=1`，仅显示步骤1元素。每步切换时，遍历所有带 `data-step` 属性的元素，根据 `data-step` 与 `currentStep` 的关系设置 `display` 或 `opacity`。
  2. 3D图淡化：步骤5-6时，给3D主图组（g#scene1-3d-main）添加CSS类 `dimmed`（opacity:0.25，transition:0.3s）。
  3. 2D示意图显隐：2D组（g#scene1-2d-panel）默认 `display:none`，步骤5-6时改为 `display:block` 并配合 `opacity` 过渡。
  4. 高亮过渡：所有颜色/线宽变化使用CSS `transition: all 0.3s ease`，确保教师点击时视觉反馈平滑。
  5. 事件绑定：按钮通过 `getElementById` 获取，绑定 `click` 事件；更新 `currentStep` 后调用 `renderStep()` 统一刷新视图。
- ID命名规范：所有SVG元素及JS访问的DOM节点ID必须以 `scene1-` 为前缀。例如：`scene1-3d-edge-pa`、`scene1-3d-plane-pac`、`scene1-3d-label-cmma`、`scene1-2d-tri-pac`、`scene1-2d-label-answer`、`scene1-btn-prev`、`scene1-btn-next`。禁止在JS中使用 `querySelectorAll` 配合全局class进行跨场景选择，必须使用 `getElementById`。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免全局变量污染，确保多场景合并时互不干扰。
- 坐标计算备忘：
  - M在AC上：M = (4*C + A)/5 = (348,312)
  - N在PC上：N = (4*C + P)/5 = (380,262)
  - 2D示意图中M' = (4*C2 + A2)/5 = (704,340)，N' = (4*C2 + P2)/5 = (722,296)，MN'向量(18,-44)与PA'向量(-90,220)严格平行（比例系数-5）。
