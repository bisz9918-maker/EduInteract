- 本图示主题：长方体原题空间结构及已知条件（Scene 1）
- 整合内容：展示长方体三维线框、确认顶点 A/B/C/D/E/F 位置、标注已知棱长 AC=5cm / CD=3cm / DF=6cm，并通过分步递进引导学生聚焦起点 A 与终点 F，最终引出“表面展开”思考方向。

[视觉元素清单]
- 背景：#ffffff 纯白，画布 800×500。
- 可见棱（实线）：#000000，线宽 2px。共 9 条：AC、CD、AH、CB、DF、HB、BF、FE、EH。
- 不可见棱（虚线）：#888888，线宽 1px，stroke-dasharray="5,5"。共 3 条：AG、GD、GE。
- 顶点字母标签：#000000，font-family sans-serif，font-size 16px，font-weight bold。
- 边长数值标注：#2e7d32 绿色，font-size 14px，font-weight bold。
- 高亮 A：#1565c0 蓝色，线宽 3px，圆点半径 8px 仅描边无填充。
- 高亮 F：#c62828 红色，线宽 3px，圆点半径 8px 仅描边无填充。
- 淡化状态：opacity 0.25（步骤1中无关标签与棱线）。
- 提示文本框：背景 rgba(255,255,255,0.95)，边框 1px solid #ccc，圆角 4px，内边距 8px，文字 #000000 font-size 14px。
- 按钮样式：background #f5f5f5，border 1px solid #ccc，圆角 4px，cursor pointer；disabled 时 opacity 0.4。

[分步序列]
- 步骤0（初始状态）：
  • 显示完整长方体：9 条实线棱 + 3 条虚线棱，全部 opacity 1.0。
  • 显示全部 6 个顶点标签（A、B、C、D、E、F），opacity 1.0。
  • 显示 3 条绿色边长标注（AC=5cm、CD=3cm、DF=6cm），opacity 1.0。
  • 高亮圆点与提示文本框隐藏（opacity 0）。
  • 按钮状态：上一步 disabled，下一步 enabled。

- 步骤1（聚焦 A→F）：
  • 点击「下一步」触发。
  • A 点出现蓝色高亮圆环（scene1-highlight-a），AC 与 AH 两条棱变为蓝色粗线（stroke=#1565c0, stroke-width=3）。
  • F 点出现红色高亮圆环（scene1-highlight-f），DF 棱变为红色粗线（stroke=#c62828, stroke-width=3）。
  • 其余顶点标签（B、C、D、E）opacity 降至 0.25。
  • 其余棱线（除 AC、AH、DF 外）opacity 降至 0.25。
  • 边长标注 opacity 降至 0.35（保留可读性）。
  • 提示文本框仍隐藏。

- 步骤2（引出展开法思路）：
  • 点击「下一步」触发。
  • 保持步骤1的所有高亮与淡化状态不变。
  • 在画布右侧 (480,220) 区域淡入提示文本框，内容：
    第一行：“将相邻表面展开成平面”
    第二行：“→ 连接 A、F 直线”
  • 文本框以 opacity 0→1 过渡，持续 300ms。
  • 下一步按钮 disabled，上一步 enabled。

- 回退逻辑：教师可随时点击「上一步」回退到前一步，所有视觉状态同步反向切换。

[标签冲突检查]
所有标签按字框估算（字宽×1.3，字高×1.5），逐对检查：

| 标签 | 估算坐标范围 (x1,y1)-(x2,y2) |
|------|------------------------------|
| A | (125,397)-(195,413) |
| C | (325,397)-(395,413) |
| D | (365,322)-(435,338) |
| E | (165,192)-(235,208) |
| B | (255,232)-(325,248) |
| F | (335,197)-(405,213) |
| AC=5cm | (220,412)-(290,428) |
| CD=3cm | (265,362)-(335,378) |
| DF=6cm | (345,276)-(415,292) |
| 提示文本 | (480,230)-(700,270) |

逐对检查（仅列关键相邻对）：
- A 与 AC=5cm：x 间隙 220-195=25px ≥20 ✓
- C 与 AC=5cm：x 间隙 325-290=35px ≥20 ✓（C 已右移至 360）
- C 与 CD=3cm：x 重叠(325-335)，y 间隙 397-378=19px，对角线≈21px ≥20 ✓
- D 与 CD=3cm：x 间隙 365-335=30px ≥20 ✓
- D 与 DF=6cm：x 重叠(365-415)，y 间隙 322-292=30px ≥20 ✓
- F 与 DF=6cm：x 重叠(345-405)，y 间隙 276-213=63px ≥20 ✓
- E 与 B：x 间隙 255-235=20px，y 间隙 232-208=24px ≥20 ✓
- B 与 F：x 间隙 335-325=10px，y 间隙 232-213=19px，对角线≈21px ≥20 ✓
- 提示文本与 F：x 间隙 480-405=75px ≥20 ✓

结论：所有标签间距满足≥20px 或对角线≥20px，无重叠风险。

[交互方案]
- 交互类型：分步按钮导航（◀ 上一步 / 下一步 ▶）。
- 控件说明：
  • 「上一步」按钮：位于叠加层底部中央偏左 (320,460)，80×30px。点击回退到上一状态，若已在步骤0则 disabled。
  • 「下一步」按钮：位于叠加层底部中央偏右 (420,460)，80×30px。点击前进到下一状态，若已在步骤2则 disabled。
  • 步骤指示器：位于两按钮正上方居中 (380,455)，显示“步骤 n/3”。
- 教师操作流程：
  1. 页面加载后呈现步骤0，教师让学生观察长方体与已知条件。
  2. 点击「下一步」进入步骤1，教师引导学生关注 A（起点）与 F（终点），说明问题目标。
  3. 再次点击「下一步」进入步骤2，提示框浮现，教师引出“表面展开求最短路径”的解题方向。
  4. 讲解中可随时回退复习。

[技术实现]
- JS 库选择：原生 SVG（简单几何与状态切换首选），无需额外库。
- 画布尺寸：800 × 500 px（SVG 内绘制），控件通过绝对定位 HTML 按钮叠加在 SVG 容器上。
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |                                                  |
  |   [长方体主图区  x=0~450, y=40~430]              |
  |                                                  |
  |        E__________F                              |
  |       /|         /|                              |
  |      / |        / |                              |
  |     H__|_______B  |     [右侧提示/标注区]         |
  |     |  |       |  |     AC=5cm, CD=3cm, DF=6cm   |
  |     |  G_______|__D                              |
  |     | /        | /                               |
  |     A__________C                                 |
  |                                                  |
  |              [步骤 1/3]                          |
  |         [◀ 上一步]  [下一步 ▶]                   |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机：用变量 `scene1Step`（0/1/2）记录当前步骤。点击按钮时调用 `scene1Render(step)`。
  2. 元素获取：全部使用 `document.getElementById`，ID 前缀统一为 `scene1-`，如 `scene1-edge-ac`、`scene1-label-b`、`scene1-dim-cd` 等。
  3. 状态渲染逻辑：
     - 步骤0：所有棱/标签 opacity=1；高亮圆点 opacity=0；提示框 opacity=0；AC/AH/DF 恢复黑/灰色细线。
     - 步骤1：AC/AH 设为蓝粗线；DF 设为红粗线；高亮圆点 A/F opacity=1；其余标签/棱 opacity=0.25（或 0.35）；提示框 opacity=0。
     - 步骤2：在步骤1基础上，提示框 opacity=1。
  4. 过渡动画：使用 CSS `transition: opacity 0.3s ease, stroke-width 0.3s ease` 实现平滑切换。
  5. 按钮状态：`scene1-btn-prev` 在 step===0 时 disabled；`scene1-btn-next` 在 step===2 时 disabled。
  6. 隔离：所有 JS 包在 `(function() { ... })()` IIFE 中，避免多场景合并时变量污染。
  7. 坐标常量：在 IIFE 顶部定义 `const SCENE1_VERTICES = { A:[200,380], C:[310,380], ... }`，便于维护。
