[图示主题与整合说明]
- 本图示主题：抛物线 $y^2=2px$ 中焦点弦、圆与射影的几何关系及 $\angle ONB$ 求解
- 整合的步骤/概念：题图全貌 → 已知条件高亮（$\angle AFx=60°$、圆、垂线） → 点A坐标与$AF=2p$推导 → 点B定位与线段比例 → 等边三角形$\triangle ANB$的发现 → 角度结论$\angle ONB=30°$
- 教学价值：教师可通过分步导航按课堂节奏逐步揭示几何结构，从识图、定坐标、发现隐藏等边三角形到最终角度计算，形成完整的探究式讲解链

- 步骤1「标注已知」：
  - 视觉变化：
    - 圆变为红高亮#c62828，线宽2px
    - 垂线NA变为绿高亮#2e7d32，线宽2px
    - 新增∠AFx红色扇形弧（圆心F, r=25, 0°~-60°）及标注"60°"（红，275,255）
    - 新增圆半径标注"$\frac{p}{2}$"（红，310,250）
  - 右侧推导区：显示"已知：$\angle AFx=60°$，圆半径$\frac{p}{2}$，$NA\perp y$轴"

- 步骤2「确定点A」：
  - 视觉变化：
    - 直线AF变为蓝高亮#1565c0，线宽2px
    - 抛物线变为蓝高亮#1565c0（线宽2px）
    - 新增A坐标标签"$A(\frac{3p}{2},\sqrt{3}p)$"（蓝，360,115）
    - 新增AF长度标注"$AF=2p$"（蓝，320,215）
  - 右侧推导区：显示"联立$\begin{cases}y=\sqrt{3}(x-\frac{p}{2})\\y^2=2px\end{cases}$得$A(\frac{3p}{2},\sqrt{3}p)$，由距离公式$AF=2p$"

- 步骤3「确定点B」：
  - 视觉变化：
    - 点B及线段FB、AB变为红高亮#c62828，线宽2px
    - 新增FB标注"$FB=\frac{p}{2}$"（红，255,265）
    - 新增AB标注"$AB=\frac{3p}{2}$"（红，325,175）
    - 新增B坐标标签"$B(\frac{3p}{4},\frac{\sqrt{3}p}{4})$"（红，300,225）
  - 右侧推导区：显示"$B$在$AF$上且$FB=\frac{p}{2}$，故$AB=AF-FB=\frac{3p}{2}$"

- 步骤4「发现等边三角形」：
  - 视觉变化：
    - 新增线段NB（主线黑）、线段AB已存在、线段NA已存在
    - 三边均标注长度：NA"$\frac{3p}{2}$"（绿，284,118）、NB"$\frac{3p}{2}$"（绿，235,195）、AB"$\frac{3p}{2}$"（绿，保留325,175但变绿）
    - 新增△ANB绿色填充（#2e7d32, opacity 0.2）
    - 新增∠ANB=60°弧（圆心N, r=20, 0°~60°SVG）及标注（绿，235,148）
    - 新增直角符号∠ANO（绿，path于(228,133)-(228,141)-(220,141)）
  - 右侧推导区：显示"$NA=\frac{3p}{2}$，$NB=\frac{3p}{2}$，$AB=\frac{3p}{2}$，$\therefore \triangle ANB$为等边三角形"

- 步骤5「得出结论」：
  - 视觉变化：
    - 新增∠ONB红色扇形弧（圆心N, r=28, 60°~90°SVG）及标注"$30°$"（红，205,155）
    - 新增答案"$30°$"大字体（红，20px，160,155）
    - 高亮∠ONB区域（红色弧+填充opacity 0.2）
  - 右侧推导区：显示"$\because NA\perp ON\ \therefore \angle ANO=90°$；$\angle ONB=\angle ANO-\angle ANB=90°-60°=30°$"

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步 ▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于(305,460)，宽90，高32。点击回退到前一步，隐藏当前步新增元素并恢复上一步高亮状态。
  - 「下一步 ▶」按钮：位于(495,460)，宽90，高32。点击推进到下一步，显示该步新增元素并切换高亮。
  - 步骤标题文本：位于(400,445)，显示当前步骤名称（如"步骤 2/6：确定点A"）。
- 教师操作流程：
  1. 教师加载页面，展示步骤0完整题图，引导学生识图。
  2. 点击「下一步」进入步骤1，高亮已知条件（60°角、圆、垂线），讲解题设。
  3. 继续点击「下一步」依次推进：步骤2联立求A，步骤3利用圆半径定B，步骤4发现等边三角形，步骤5得出30°结论。
  4. 可随时点击「上一步」回退复习关键推导环节。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本场景为纯2D几何图形，无复杂函数绘图或3D需求，原生SVG路径、圆、线段足以精确表达所有元素，且便于通过class/id控制显隐与高亮。
- 画布尺寸：800×500 px（SVG viewBox="0 0 800 500"）
- 布局草图：
  ```
  +--------------------------------------------------+
  |  主图区 (y=20~430)                                |
  |  y轴↑  N●───────●A                               |
  |        │ \     /  抛物线                          |
  |        │  \   /                                   |
  |        O───F●───→x                               |
  |            / \  圆                                |
  |           B   \                                   |
  |                                                |
  |  右侧推导公式区 (x=450~780)                        |
  +--------------------------------------------------+
  |  [◀ 上一步]    步骤 3/6    [下一步 ▶]  (y=440~490)|
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 `currentStep`（0~5）记录当前步骤。每步用一个配置对象数组 `stepsConfig`，定义该步需`show`的元素id列表、需`highlight`的元素id及对应颜色类（如`highlight-blue`、`highlight-red`、`highlight-green`）、需更新的右侧文本。
  2. 坐标计算：抛物线通过参数方程 $x=\frac{p}{2}t^2, y=pt$（数学坐标）映射到像素坐标 $x_p=220+x_m, y_p=280-y_m$，取t∈[-1.8,1.8]生成path的d属性。
  3. 动画曲线：步骤切换不使用复杂动画，直接通过`display`或`opacity`瞬时切换（0.2s CSS transition），保证课堂讲解节奏可控。
  4. 事件绑定：上一步/下一步按钮绑定click事件，调用`renderStep(idx)`函数。函数先清除所有高亮类，再按配置添加。
  5. 角度弧绘制：使用SVG `<path>`的`A`指令。∠AFx弧：M 288 280 A 25 25 0 0 0 275.5 258.4；∠ANB弧：M 240 133 A 20 20 0 0 1 230 150.3；∠ONB弧：M 234 157.3 A 28 28 0 0 1 220 161。
  6. 填充扇形：角度弧path使用`fill="#c62828" fill-opacity="0.2"`（或绿色对应值），配合`stroke`描边。
- ID命名规范：所有SVG元素及控件ID必须以`scene1-`为前缀。例如：`scene1-axis-x`、`scene1-parabola`、`scene1-point-a`、`scene1-angle-AFx`、`scene1-btn-prev`、`scene1-btn-next`、`scene1-formula`。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免多场景合并时变量污染。
- CSS类命名：高亮类使用 `.scene1-hl-blue`、`.scene1-hl-red`、`.scene1-hl-green`，分别设置stroke和fill颜色。
