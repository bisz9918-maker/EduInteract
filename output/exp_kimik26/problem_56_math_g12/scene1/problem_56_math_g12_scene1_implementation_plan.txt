[图示主题与整合说明]
- 本图示主题：嵌套圆与正六边形的几何构造及半径递推关系
- 整合的步骤/概念：
  1) 初始圆及其内接正六边形的展示；
  2) 边心距（垂线）的作图与 30°/60° 角的标注；
  3) 以内切圆半径生成第二层圆与正六边形；
  4) 递推公式 R_{n+1} = R_n·√3/2 的动态呈现；
  5) 第 3、4 层嵌套图形的自动生成，体现无限趋势；
  6) 递推关系与首项的总结高亮。
- 教学价值：教师可逐步引导学生观察“边心距即下一层圆的半径”这一核心几何事实，通过分步回退反复强化 30° 直角三角形的度量关系，为后续无穷等比数列求和做好几何铺垫。

[分步序列]
- 步骤 0（初始状态）：
  · 显示：圆1（黑，2px）、正六边形1（红，2px，填充 15%）、圆心点、标签 "O"、"R₁=1"。
  · 其余元素全部隐藏。
- 步骤 1（边心距与角度）：
  · 新增：正六边形1上边 V2–V3 高亮（红线 3px）；边心距垂线 O–M（灰虚线）；中点 M 小点；30° 角弧线+标签；60° 角弧线+标签；边心距数值 "√3/2"。
  · 已有元素保持。
- 步骤 2（第二层圆与正六边形）：
  · 新增：圆2（蓝，1.5px）、正六边形2（红，1.5px，填充 15%）、标签 "R₂=√3/2"（蓝色）。
  · 变化：圆1与正六边形1的 opacity 降至 0.4（降低饱和度，突出当前层）。
  · 辅助线、角度弧线保持可见但 opacity 降至 0.5。
- 步骤 3（递推公式）：
  · 新增：右侧递推公式面板淡入。标题 "递推关系"；公式 "R_{n+1} = R_n · cos30° = (√3/2)·R_n"，其中 R_{n+1} 蓝色、等号绿色；下方箭头示意 "R₁=1 → R₂=√3/2 → R₃=3/4 → …"。
  · 图形层无变化。
- 步骤 4（无限嵌套趋势）：
  · 新增：圆3（黑，1px，opacity 0.7）、正六边形3（红，1px，fill-opacity 0.1）；圆4（黑，0.5px，opacity 0.5）、正六边形4（红，0.5px，fill-opacity 0.05）；标签 "R₃"、"R₄"。
  · 变化：圆1/正六边形1、圆2/正六边形2的 opacity 进一步降至 0.25；辅助线与角度标注隐藏。
  · 右侧公式面板保持。
- 步骤 5（总结）：
  · 新增：右侧总结框（绿边框 #2e7d32，浅绿背景，opacity 0.1）。框内文本："首项 R₁ = 1"、"公比 q = √3/2"、"半径构成无穷等比数列"。
  · 变化：递推公式面板整体加绿色高亮边框；所有嵌套圆与正六边形 opacity 统一恢复至 0.6，作为背景整体可见。
  · 教师可点击「上一步」回退至任意步骤复习。

[交互方案]
- 交互类型：分步按钮导航（◀ 上一步 / 下一步 ▶）
- 控件说明：
  · 「◀ 上一步」按钮：中心(300,465)，宽110×高40。点击回退到上一状态；在步骤 0 时禁用（opacity 0.4，pointer-events none）。
  · 「下一步 ▶」按钮：中心(460,465)，宽110×高40。点击推进到下一状态；在步骤 5 时禁用。
  · 步骤指示器：位于两按钮上方中心(380,445)，显示当前步骤序号如 "1 / 6"（对应步骤 0~5 的 6 个状态）。
- 教师操作流程：
  1) 初始页面展示圆与内接正六边形，教师讲解正六边形顶点落在圆上；
  2) 点击「下一步」出现垂线与角度，教师引导学生发现 30°–60°–90° 直角三角形；
  3) 点击「下一步」生成第二层圆，教师指出边心距即新圆半径；
  4) 点击「下一步」右侧出现递推公式，教师建立代数关系；
  5) 点击「下一步」自动生成第 3、4 层，教师强调“无限继续”的极限视觉；
  6) 点击「下一步」出现总结框，教师收束几何阶段，为面积求和铺垫。
  任意时刻可点击「上一步」回退，重新观察某一层或某个角。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript。不引入 D3/Three.js 等重型库，因本场景为静态几何图形与显隐切换，原生 SVG 足够轻量且精确。公式文本使用绝对定位 HTML div 叠加，若宿主环境支持 MathJax 可在外层引入，本计划内使用 Unicode 文本保证独立运行。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------------+
  |                                                        |
  |   [几何图形区: x=0~500]          [右侧文本区: x=520~780]|
  |    同心圆+正六边形                  递推公式/总结框      |
  |    标签、角度、辅助线                                    |
  |                                                        |
  |                                                        |
  |              [控件栏: y=440~490]                        |
  |         [◀ 上一步]  步骤 k/6  [下一步 ▶]               |
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1) 状态机：变量 `let currentStep = 0;`（范围 0~5）。每次点击按钮时更新 `currentStep`，调用 `renderStep()`。
  2) `renderStep()` 逻辑：根据 currentStep 设置各元素的 `display`（或 `visibility`）与 `opacity`。使用 CSS transition: opacity 0.3s ease 实现淡入淡出。
  3) 图层顺序（SVG z-index 由 DOM 顺序决定，后渲染在上层）：
     · 底层：正六边形填充 polygon（避免遮挡线条）
     · 中层：圆 circle、正六边形轮廓 polygon、线段 line
     · 上层：角度弧线 path、点 circle、标签 text
  4) 正六边形顶点坐标在 JS 中用函数 `getHexVertices(cx, cy, r)` 计算，返回 6 个顶点字符串供 polygon 的 points 属性使用。
  5) 角度弧线使用 SVG path 的 arc 命令（A 指令）绘制，30° 弧线从方向 60° 到 90°（半径 30），60° 弧线从方向 120° 到 180°（半径 25）。
  6) 右侧文本区与总结框使用绝对定位的 HTML div，通过切换 class `scene1-visible` 控制显示/隐藏，同样使用 opacity transition。
  7) 按钮禁用状态通过添加/移除 `disabled` class 实现样式变化。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀。例如：
  · SVG 元素：`scene1-circle-1`, `scene1-hex-1`, `scene1-apothem-line`, `scene1-label-r1`
  · HTML 面板：`scene1-formula-panel`, `scene1-summary-box`
  · 按钮：`scene1-btn-prev`, `scene1-btn-next`, `scene1-step-indicator`
  · JS 中严格使用 `document.getElementById` 获取，禁止全局 class 查询，避免多场景合并污染。
- IIFE 隔离：所有 JavaScript 包在 `(function() { ... })();` 中执行，内部状态（currentStep 等）不泄漏到全局作用域。
- 容器结构示例：
  ```html
  <div id="scene1-wrapper" style="position:relative; width:800px; height:500px;">
    <svg id="scene1-svg" width="800" height="500">...</svg>

    <div id="scene1-controls" style="position:absolute; bottom:10px; left:0; width:100%; text-align:center;">
      <button id="scene1-btn-prev">◀ 上一步</button>
      <span id="scene1-step-indicator">1 / 6</span>
      <button id="scene1-btn-next">下一步 ▶</button>
    </div>
  </div>
  ```
