[图示主题与整合说明]
- 本图示主题：圆的面积构成等比数列及无穷求和
- 整合的步骤/概念：
  1) 首项圆面积 S₁=π 的识别；
  2) 第二项面积 S₂=3π/4 及面积比 3/4 的推导；
  3) 第三项与通项公式 Sₙ=π·(3/4)^(n−1) 的归纳；
  4) 无穷等比数列求和公式 S=S₁/(1−q) 及适用条件 |q|<1；
  5) 代入计算得 S=4π；
  6) 面积条形图的总和可视化，直观展示“无穷多项之和为有限值”。
- 教学价值：教师通过分步导航，可逐层揭示从“具体面积计算”到“抽象无穷求和”的完整思维链；条形图的逐节拼接帮助学生建立“极限和”的几何直觉。

[分步序列]
步骤0（初始状态）：
- 显示元素：标题、S₁公式（蓝色高亮）、条形1（蓝色填充）、S₁标签、基线
- 隐藏元素：其余公式、其余条形、数轴、方括号、辅助虚线、步骤5说明
- 教学意图：建立首项面积 S₁=π 的直观印象。

步骤1（下一步）：
- 新增显示：S₂公式、比值 "S₂/S₁ = 3/4"（红色）、条形2（红色填充）、S₂标签
- 视觉变化：条形2紧接条形1右侧，长度为其 3/4；比值文本以红色强调面积比
- 教学意图：揭示相邻面积间的定量关系。

步骤2（下一步）：
- 新增显示：S₃公式、通项公式 "Sₙ = π·(3/4)^(n−1)"（其中 "(3/4)" 红色高亮）、条形3（蓝色填充）、S₃标签
- 视觉变化：条形3长度继续缩减；通项公式完成从具体到一般的归纳
- 教学意图：归纳一般项，确认公比 q=3/4。

步骤3（下一步）：
- 新增显示：求和公式 "S = S₁/(1−q)"（绿色高亮）、条件 "|q| < 1"（绿色）
- 视觉变化：公式区出现绿色求和公式，强调无穷等比数列求和工具
- 教学意图：引入求和公式，强调收敛条件。

步骤4（下一步）：
- 新增显示：计算结果 "S = π/(1−3/4) = 4π"（其中 "4π" 绿色高亮）、条形4（红色填充）
- 视觉变化：公式推导完成，数值结果以绿色高亮；条形图新增第 4 节
- 教学意图：完成代数计算，得出有限极限值。

步骤5（下一步 / 最终状态）：
- 新增显示：步骤5说明文字、条形5、条形6、条形剩余（绿色虚线框）、数轴及 5 个刻度标签、4 条灰色辅助虚线、绿色方括号及 "总和 = 4π" 标注
- 视觉变化：所有条形拼接完毕，总长度恰好止于 4π 刻度；方括号与虚线共同框定“无穷多项累加”的极限直观
- 教学意图：几何可视化总和，强化“无穷级数收敛于有限值”的认知。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript。本场景以静态几何图形、文本标签和简单显隐控制为主，无需 D3、Canvas 或 MathJax；SVG <text> 配合 <tspan> 即可实现局部变色与简单上下标。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |              圆的面积构成等比数列                   |  y=0~40
  |  S₁ = π·R₁² = π  (蓝)                            |  y=60
  |  S₂ = π·R₂² = 3π/4      S₂/S₁ = 3/4 (红)         |  y=100
  |  S₃ = π·(3/4)² = 9π/16  Sₙ = π·(3/4)^(n-1) (红)  |  y=140
  |  S = S₁/(1-q) (绿)      |q|<1 (绿)               |  y=180
  |  S = π/(1-3/4) = 4π (绿)                         |  y=220
  |  所有圆面积之和 S = 4π                             |  y=260
  |  面积条形图（单位：π）                              |  y=300
  |  ┌──────────────────────────────────────────┐     |  y=305
  |  │ S₁  S₂  S₃                               │     |  y=325
  |  [████|▓▓▓▓▓|████|▓▓▓|██|▓|░░░░░░░░░░]     |  y=330~360
  |  +----+----+----+----+----+----+-----------+      |  y=375
  |  |    |    |    |    |    |    |           |      |  y=395
  |  0    π   2π   3π   4π                           |  y=415
  |       [◀ 上一步]  [下一步 ▶]                     |  y=455~490
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `let currentStep = 0;` 记录当前步骤（0~5）。`updateScene()` 函数根据 currentStep 遍历所有带 `data-step` 属性的 SVG 元素，设置 `display` 或 `opacity`。
  2. 元素显隐策略：为每个需按步骤控制的元素添加 `data-step-min` 和 `data-step-max`（或仅 `data-step` 表示该步骤首次出现并持续显示）。例如条形1的 data-step-min=0，条形5的 data-step-min=5。
  3. 按钮状态：在 `updateScene()` 内同步更新按钮禁用状态与步骤指示器文本。
  4. 坐标计算：条形宽度严格按 140px/π 的比例尺计算，确保 6 个具体项 + 1 个余项之和恰好为 560px（对应 4π），与数轴 4π 刻度完全对齐。
  5. 动画曲线：本场景以信息揭示为主，无需复杂动画；元素出现使用直接显隐（opacity 0→1 或 display none→block），若需柔和过渡可加 200ms CSS transition。
  6. 事件绑定：按钮点击绑定 `scene2-btn-prev` 和 `scene2-btn-next` 的 `click` 事件，在 IIFE 内部处理。
- **ID 命名规范**：所有交互元素 ID 必须以 `scene2-` 为前缀。例如：
  * `scene2-title`
  * `scene2-formula-s1`
  * `scene2-formula-ratio`
  * `scene2-bar-1` ~ `scene2-bar-rest`
  * `scene2-axis-label-pi`
  * `scene2-brace-top`
  * `scene2-btn-prev`
  * `scene2-btn-next`
  * `scene2-step-indicator`
  JS 中通过 `document.getElementById('scene2-xxx')` 获取元素，禁止跨场景选择器。
- IIFE 隔离：所有 JavaScript 代码必须包裹在 `(function() { ... })();` 中，避免全局变量污染，确保多场景合并时互不干扰。
