[图示主题与整合说明]
- 本图示主题：空间基本模型与圆锥面的形成（立体几何斜线轨迹问题）
- 整合的步骤/概念：
  1) 建立空间框架——平面 M、垂线 PO、垂足 O；
  2) 引入斜线 PA 与线面角 α；
  3) 引入动直线 PB 与锥顶角 β；
  4) PB 绕 PA 旋转生成圆锥面；
  5) 圆锥面与平面 M 的交线即为动点 B 的轨迹（默认参数下为椭圆）。
- 教学价值：教师可按照“空间框架→核心角度→动态生成→轨迹结论”的认知顺序逐步展开，随时回退到任意步骤强调几何关系，帮助学生完成从“静态线”到“动态锥面”再到“截面曲线”的思维跃迁。

[分步序列]
- 步骤 0（基础 setup）：
  显示平面 M（平行四边形浅灰填充）、点 P 与点 O、垂线段 PO（灰色虚线）。
  隐藏 PA、PB、角度弧、母线、椭圆。
  目的：建立“PO⊥平面 M”的空间框架。

- 步骤 1（添加斜线）：
  点击「下一步」→ 点 A 与斜线 PA（蓝色实线）出现；α 角度弧（PO 与 PA 之间，橙色弧）及标签 α 出现。
  目的：引入斜线 PA 与线面角 α，强调 PA 与 PO 的夹角关系。

- 步骤 2（添加动直线）：
  点击「下一步」→ 点 B 与动直线 PB（红色实线）出现；β 角度弧（PA 与 PB 之间，橙色弧）及标签 β 出现。
  目的：引入动直线 PB 与锥顶角 β，强调 PB 是“动”直线。

- 步骤 3（旋转成锥）：
  点击「下一步」→ PB 沿 PA 两侧“扫出”5 条母线（红色半透明线段，从左到右依次渐显，耗时约 600ms），随后蓝色半透明多边形填充出现，示意圆锥面。
  目的：帮助学生建立“PB 绕 PA 旋转生成圆锥面”的动态概念。

- 步骤 4（显示轨迹）：
  点击「下一步」→ 母线透明度降低（保留 PB），绿色粗线椭圆在平面 M 上高亮出现，标注“椭圆”。
  目的：揭示圆锥面与平面 M 的交线即为动点 B 的轨迹，完成从动态生成到结论的过渡。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「上一步」按钮：位于 (280,460)，宽 90px，高 30px；点击回退到上一状态。
  2. 「下一步」按钮：位于 (430,460)，宽 90px，高 30px；点击推进到下一状态。
  3. 步骤指示器：位于 (400,485)，文字如「步骤 1/5」；仅作状态提示，不可点击。
- 教师操作流程：
  教师先展示步骤 0 说明“PO 垂直于平面 M”；点击「下一步」依次出现 PA、PB、圆锥面、轨迹曲线；在任意步骤可点击「上一步」回退，重新强调关键几何关系（如 α 与 β 的位置、圆锥面的形成）。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无外部库）。理由：本场景以静态/简单渐显几何图形为主，无需复杂动画或 3D 引擎，原生 SVG 路径、线段、椭圆即可精确控制，且避免引入冗余依赖。
- 画布尺寸：800 × 500 px（沿用规定）
- 布局草图（ASCII）：
  ```
  +------------------------------------------+  y=0
  |                                          |
  |              P                           |
  |             /|\                          |
  |            / | \                         |
  |           /  |  \   PB                   |
  |          /   |   \                       |
  |         / α  | β  \                      |
  |        /     |     \                     |
  |       A      O       B                   |
  |      /       |        \                  |
  |     /    [椭圆轨迹]    \                 |
  |    /                   \                 |
  |   /  平面 M (平行四边形) \               |
  |  /                       \               |
  +------------------------------------------+  y=320~420
  |                                          |
  |    [上一步]   步骤 X/5   [下一步]        |  y=460~490
  +------------------------------------------+  y=500
  ```
- 关键实现要点：
  1. 状态机：变量 `currentStep` 取 0~4，数组 `stepElements` 记录每步应显示/隐藏的元素 ID 列表。
  2. 步骤 3 动画：使用 `setTimeout` 分 5 次（间隔 100ms）逐条将母线 opacity 从 0 过渡到 0.4，随后显示圆锥面 polygon（opacity 0→0.15，transition 300ms）。
  3. 椭圆绘制：使用 SVG `<ellipse cx="370" cy="370" rx="100" ry="55" transform="rotate(-10, 370, 370)" />`，确保其贴合平面 M 的透视感。
  4. 角度弧计算：使用 `Math.atan2(dy, dx)` 获取 PO、PA、PB 的方向角（SVG 坐标系，0° 向右，顺时针增加），再用 `A` 指令绘制圆弧；α 弧 sweep-flag=1（逆时针），β 弧 sweep-flag=1（逆时针）。
  5. 事件绑定：上一步/下一步按钮绑定 `click` 事件，调用 `renderStep(newStep)`；`renderStep` 内使用 `element.style.display = 'block'/'none'` 或 `element.style.opacity` 控制显隐。
  6. 所有几何坐标硬编码，避免运行时复杂计算，确保代码 agent 可直接复制坐标实现。
- ID 命名规范：
  - 平面 M：`scene1-plane-m`
  - 点 P/O/A/B：`scene1-point-p`、`scene1-point-o`、`scene1-point-a`、`scene1-point-b`
  - 线段 PO/PA/PB：`scene1-line-po`、`scene1-line-pa`、`scene1-line-pb`
  - 角度弧：`scene1-arc-alpha`、`scene1-arc-beta`
  - 母线组：`scene1-cone-line-1` … `scene1-cone-line-5`
  - 圆锥面：`scene1-cone-surface`
  - 轨迹椭圆：`scene1-trajectory`
  - 标签：`scene1-label-p`、`scene1-label-o`、…、`scene1-label-ellipse`
  - 按钮：`scene1-btn-prev`、`scene1-btn-next`
  - 步骤文字：`scene1-step-indicator`
- IIFE 隔离：所有 JS 逻辑包裹在 `(function() { ... })();` 中，避免多场景合并时变量污染。
