[图示主题与整合说明]
- 本图示主题：圆锥截线类型的轴截面判定（立体几何斜线轨迹问题）
- 整合内容：将3D空间关系投影为2D轴截面图，通过双滑块连续调节α（PA与PO夹角）和β（圆锥半顶角），实时展示平面M截圆锥所得轨迹类型（圆/直线/抛物线/椭圆/双曲线）的变化规律；5个预设按钮对应题目5个命题，一键定位并高亮判定结论。
- 教学价值：教师可先让学生自由拖动滑块观察"量变引起质变"的连续过程，发现α+β=90°是临界状态；再逐一点击预设按钮验证五个命题，建立空间角度关系与圆锥截线类型的牢固对应。

[分步序列/状态序列]
本场景为连续交互状态机，非线性分步。定义关键状态如下：

- 初始状态（自由探索）：α=30°, β=45°（α+β=75°<90°，椭圆情形）
  * 显示：P、O、A、平面M、PA、PO、两条母线、三个角度弧、轨迹示意框内显示椭圆
  * 实时数据：PA与平面夹角60°，半顶角45°，α+β=75°，轨迹类型"椭圆"（绿色）
  * 无按钮高亮

- 状态①（点击预设按钮①）：α=0°, β=90°
  * 变化：A与O重合于(180,350)；PA与PO重合（竖直）；母线1水平向右，母线2水平向左；β弧为四分之一圆
  * 轨迹示意：显示"无轨迹"或红色叉线（红色 #c62828）
  * 实时数据：轨迹类型"无轨迹（命题错误）"（红色）
  * 按钮①高亮（蓝色边框#1565c0，浅蓝背景#e3f2fd）

- 状态②（点击预设按钮②）：α=30°, β=90°

  * 轨迹示意：显示直线（蓝色 #1565c0）
  * 实时数据：轨迹类型"直线（命题正确）"（蓝色）
  * 按钮②高亮

- 状态③（点击预设按钮③）：α=45°, β=45°（α+β=90°）

  * 实时数据：轨迹类型"抛物线（命题正确）"（绿色）

[交互方案]
- 交互类型：连续拖拽滑块 + 预设按钮（大纲规定，未更改）
- 控件说明：
  1. α滑块：范围0°~90°，初始值30°，位于控制面板顶部(y=55~71)。拖动时实时更新A点位置、PA方向、所有角度弧、母线方向、轨迹类型。
  2. β滑块：范围0°~180°，初始值45°，位于α滑块下方(y=115~131)。拖动时实时更新母线方向、β角度弧、轨迹类型。
  3. 预设按钮①~⑤：位于控制面板中下部(y=315~477)，点击后将α、β自动动画过渡到预设值（过渡时长300ms，ease-out），同时高亮该按钮并显示命题判定结论。
- 教师操作流程：
  1. 课堂引入：展示初始状态，说明PA是圆锥轴、PB是母线、平面M截圆锥。
  2. 探究活动：让学生拖动β滑块，固定α=30°，观察β从0°增到90°再增到120°，轨迹如何从椭圆→抛物线→双曲线变化；再固定β=45°，拖动α滑块，观察α+β crossing 90°的临界现象。
  3. 命题验证：逐一点击5个预设按钮，对照实时数据区的轨迹类型和正确/错误判定，验证题目选项。特别强调④⑤两个错误命题，引导学生发现α+β与90°的大小关系决定曲线类型。
  4. 总结规律：教师拖动滑块使α+β恰好等于90°，让学生记住"和为90°是抛物线，大于90°是双曲线，小于90°是椭圆"的判定口诀。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript（无需外部库）。理由：本场景为2D几何图形，元素数量有限（<30个），原生SVG路径计算简单，无需D3/Canvas；无数学公式渲染需求，无需MathJax。
- 画布尺寸：800×500 px（SVG），控制面板用HTML absolute div覆盖。
- 布局草图：
  ```
  +-------------------------------------------------------------+
  | 画图区(0,0)-(620,500)          |  控制面板(620,20)-(780,480) |
  |                                |  α: [=========●===]  30°    |
  |      P                         |  β: [======●======]  45°    |
  |      |\                        |  +---------------------+    |
  |      | \  β                   |  | PA与平面夹角: 60°   |    |
  |      |  \                     |  | 圆锥半顶角: 45°     |    |
  |     α|   \ 母线1              |  | α + β: 75°          |    |
  |      |    \                   |  | 轨迹类型: 椭圆      |    |
  |      |     \                  |  +---------------------+    |
  |      O------A--------M        |  [① α=0°,β=90°]          |
  |           90°-α               |  [② α≠0°,β=90°]          |
  |      [轨迹示意框]             |  [③ α+β=90°]             |
  |                                |  [④ α+β>90°]             |
  |                                |  [⑤ α+β<90°]             |
  +-------------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用全局对象 `state = { alpha: 30, beta: 45, activeButton: null }` 记录当前状态。滑块input事件和按钮click事件均修改此状态，然后调用统一的 `render()` 函数重绘。
  2. 坐标计算：
     - A_x = 180 + 270 * Math.tan(alpha * Math.PI / 180)
     - 若A_x > 580，PA线段画到边界(580,350)并加箭头；若A_x < 180（α<0不可能），同理处理。
     - 母线终点：若sin(θ)>0且交点在画布内，画到交点；否则画固定长度200px。
     - 角度弧路径：使用SVG path的A命令，需根据起始角、终止角、半径计算起点/终点坐标。
  3. 动画曲线：点击预设按钮时，使用 `requestAnimationFrame` 实现300ms的ease-out过渡，让α、β从当前值平滑变化到目标值，期间每帧调用render。
  4. 轨迹类型判定函数：
     ```javascript
     function getTrajectoryType(a, b) {
       if (a === 0) {
         if (b < 90) return { type: 'circle', color: '#2e7d32', correct: null };
         if (b === 90) return { type: 'none', color: '#c62828', correct: false, msg: '命题①错误' };
       }
       if (b === 90) return { type: 'line', color: '#1565c0', correct: true, msg: '命题②正确' };
       const sum = a + b;
       if (Math.abs(sum - 90) < 0.5) return { type: 'parabola', color: '#2e7d32', correct: true, msg: '命题③正确' };
       if (sum > 90) return { type: 'hyperbola', color: '#2e7d32', correct: false, msg: '命题④错误（实际为双曲线）' };
       return { type: 'ellipse', color: '#2e7d32', correct: false, msg: '命题⑤错误（实际为椭圆）' };
     }
     ```
  5. 事件绑定：滑块用 `input` 事件（实时响应），按钮用 `click` 事件。所有事件监听器在IIFE内绑定。
  6. 轨迹示意切换：根据 `getTrajectoryType` 返回的type，显示/隐藏对应的SVG元素（circle/line/path/ellipse），并设置stroke颜色。
- ID命名规范：所有SVG元素ID必须以 `scene2-` 为前缀，例如 `scene2-point-p`、`scene2-line-pa`、`scene2-arc-alpha`、`scene2-traj-ellipse`、`scene2-slider-alpha`、`scene2-btn-1` 等。JS中严格使用 `document.getElementById` 获取元素。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免多场景合并时的全局变量污染。
- 响应式说明：本场景为固定尺寸教学图示（800×500），不适配移动端；容器使用 `position: relative` 包裹SVG和absolute控制面板，确保整体尺寸固定。
