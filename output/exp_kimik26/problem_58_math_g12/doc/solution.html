场景导航：Scene 1

题目原文

（广东）选做题：如图，点A、B、C是圆O上的点，且AB=4，∠ACB=37°，则圆O的面积等于__．

题目分析

本题考查圆周角定理与解三角形的综合应用。关键突破口在于：

  1. 圆周角∠ACB与圆心角∠AOB对应同一段弧AB，根据圆周角定理有∠AOB = 2∠ACB = 74°
  2. 在等腰三角形AOB中（OA = OB = r），已知底边AB = 4和顶角∠AOB = 74°，可通过垂径定理构造直角三角形求半径
  3. 作OD⊥AB于D，则AD = 2，∠AOD = 37°，在Rt△AOD中利用正弦关系求得半径r = 2 / sin37°
  4. 圆面积S = πr² = 4π / sin²37°

整体讲解思路

教师可按"识别定理→构造辅助线→解三角形→得出结果"的线索展开。先引导学生观察∠ACB是圆周角，它所对的弧AB对应的圆心角在哪里；再通过连接OA、OB将问题转化为等腰三角形中的计算；最后利用垂径定理和三角函数完成求解。

图示规划说明

本题仅需一个整合式交互图示，通过分步按钮导航完整呈现从题目条件到最终结论的全部推导过程。图示以题目原图为锚点，逐步叠加辅助线和标注，避免多个相似圆的重复绘制。

推导过程
已知：AB = 4，∠ACB = 37°
∠AOB = 2∠ACB = 74°
OD ⊥ AB，AD = DB = 2
在 Rt△AOD 中：
sin37° = AD/OA = 2/r
r = 2/sin37°
S = πr² = 4π/sin²37°

本图示的教学说明

教师在使用此图示时，建议按以下方式引导学生：

  1. 步骤1（审题）：让学生确认已知条件——圆O上有三点A、B、C，弦AB长度为4，圆周角∠ACB为37°。提问："要求圆的面积，我们需要知道什么？"（半径）
  1. 步骤2（圆周角定理）：点击下一步，连接OA、OB后，引导学生观察∠ACB和∠AOB对应同一段弧AB。强调圆周角定理：同弧所对圆心角是圆周角的2倍。可追问："如果C点在另一侧弧上移动，∠ACB会变吗？"（不变，巩固圆周角性质）
  1. 步骤3（垂径定理）：点击下一步，作OD⊥AB后，让学生发现两个结论：D是AB中点（AD=2），且OD平分∠AOB（∠AOD=37°）。这里可以同时复习等腰三角形"三线合一"性质。
  1. 步骤4（解三角形）：在Rt△AOD中，已知对边AD=2和角度37°，求斜边OA=r。引导学生写出 sin37° = 对边/斜边 = 2/r，解得 r = 2/sin37°。
  1. 步骤5（得出结论）：将半径代入面积公式，得到 S = πr² = 4π/sin²37°。提醒学生此题为填空题，结果保留此形式即可，无需计算近似值。

课堂讲解建议

  • 若学生基础较弱，可在步骤2停留较长时间，通过拖动C点（如实现）观察圆周角不变性
  • 步骤3到步骤4是易错点，部分学生可能误用cos37°或tan37°，需强调"已知对边求斜边用正弦"
  • 本题可与"已知弦长和弦心距求半径"类题目进行类比，帮助学生建立知识网络
  • 最终答案形式为 4π/sin²37°，可顺带复习 sin²θ 的写法规范
