problem_59_math_g12

场景导航：Scene 1

(2010•肥城市模拟)如图，为了测量河的宽度，在河的一岸边选取两点A，B，观察对岸的点C，测得∠CAB=75°，∠CBA=45°，且AB=96米，则河的宽度为 $\underline{\hspace{2em}\hspace{2em}\hspace{2em}}$．$(\sqrt{2}=1.4，\sqrt{3}=1.7，精确到米)$．

题目分析：
本题是一道解三角形的实际应用题，核心是将"河宽"转化为三角形中顶点 C 到边 AB 的垂线距离。已知三角形两角及一边，可通过正弦定理求出相关边长，再在直角三角形中利用三角函数求出高。

整体讲解思路：

  1. 引导学生建立数学模型：两岸近似平行，河宽即为对岸点 C 到本岸线段 AB 所在直线的垂直距离。
  2. 强调辅助线的作法：过 C 作 $CD \perp AB$ 于 D，则 CD 即为河宽 $h$。
  3. 先在 $\triangle ABC$ 中用内角和求出 $\angle ACB$，再用正弦定理求 AC（或 BC）。
  4. 在 $\text{Rt}\triangle ADC$（或 $\text{Rt}\triangle BDC$）中，利用 $h = AC \cdot \sin \angle A$ 求出河宽。
  5. 展示完整代入计算过程，注意近似值的使用，结果精确到米。

图示规划说明：
本节课使用一个交互式几何图示，通过分步导航将"场景还原—条件标注—辅助线添加—角度推导—正弦定理—计算求值"完整串联，避免多个相似几何图的拆分。

关键公式推导：

  1. 在 $\triangle ABC$ 中，$\angle ACB = 180^\circ - 75^\circ - 45^\circ = 60^\circ$。
  2. 由正弦定理：$\dfrac{AC}{\sin 45^\circ} = \dfrac{AB}{\sin 60^\circ}$，得 $AC = \dfrac{96 \cdot \dfrac{\sqrt{2}}{2}}{\dfrac{\sqrt{3}}{2}} = \dfrac{96\sqrt{2}}{\sqrt{3}} = 32\sqrt{6}$（米）。
  3. 在 $\text{Rt}\triangle ADC$ 中，$h = CD = AC \cdot \sin 75^\circ$。
  4. $\sin 75^\circ = \sin(45^\circ+30^\circ) = \sin 45^\circ \cos 30^\circ + \cos 45^\circ \sin 30^\circ = \dfrac{\sqrt{2}}{2} \cdot \dfrac{\sqrt{3}}{2} + \dfrac{\sqrt{2}}{2} \cdot \dfrac{1}{2} = \dfrac{\sqrt{6}+\sqrt{2}}{4}$。
  5. $h = 32\sqrt{6} \cdot \dfrac{\sqrt{6}+\sqrt{2}}{4} = 8\sqrt{6}(\sqrt{6}+\sqrt{2}) = 8(6+\sqrt{12}) = 8(6+2\sqrt{3}) = 48+16\sqrt{3}$。
  6. 代入 $\sqrt{3}=1.7$，得 $h \approx 48 + 16 \times 1.7 = 48 + 27.2 = 75.2 \approx 75$（米）。

另一种简洁解法（课堂可补充）：
利用 $h = \dfrac{AB}{\cot A + \cot B} = \dfrac{96}{\cot 75^\circ + \cot 45^\circ} = \dfrac{96}{(2-\sqrt{3})+1} = \dfrac{96}{3-\sqrt{3}} = 16(3+\sqrt{3}) = 48+16\sqrt{3} \approx 75$（米）。

步骤 0/5

完整解答回顾：
河宽约为 75 米。

课堂讲解建议：

  1. 先让学生自己画出辅助线，明确"河宽"在数学模型中对应什么线段，纠正学生可能将 CA 或 CB 误认为河宽的错误。
  2. 在步骤3求第三角时，可提问学生三角形内角和，强化基础知识的调用。
  3. 步骤4使用正弦定理时，建议教师先让学生回忆正弦定理公式 $\dfrac{a}{\sin A} = \dfrac{b}{\sin B} = \dfrac{c}{\sin C}$，再对应本题中的边和角。
  4. 步骤5的计算是难点，$\sin 75^\circ$ 的展开可简要回顾两角和公式；若课堂时间紧张，可直接给出 $\sin 75^\circ$ 的数值。注意提醒学生题目已给出 $\sqrt{2}=1.4$、$\sqrt{3}=1.7$，不要误用计算器精确值。
  5. 可补充面积法或 $h = \dfrac{AB}{\cot A + \cot B}$ 作为拓展思路，满足不同层次学生需求。
  6. 强调结果需"精确到米"，因此 75.2 应四舍五入为 75，培养学生关注题目要求的意识。
