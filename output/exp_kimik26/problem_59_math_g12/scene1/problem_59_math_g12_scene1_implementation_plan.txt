[图示主题与整合说明]
- 本图示主题：河宽测量问题的几何建模与解三角形全过程
- 整合的步骤/概念：题目场景还原 → 确定求解目标 → 添加辅助垂线 → 三角形内角推导 → 正弦定理求边 → 直角三角形求高得河宽
- 教学价值：教师通过分步导航，可按照"理解题意→建立模型→添加辅助线→推导计算→得出结论"的线性逻辑逐步讲解，每步只呈现当前所需信息，避免学生认知过载，同时可随时回退复习。

[分步序列]
- 步骤0「题意理解」（初始状态）：
  - 显示：两岸线、A/B/C 三点、△ABC 三边（黑色）、点标签 A/B/C
  - 绿色高亮：∠A 弧+标签"75°"、∠B 弧+标签"45°"、边 AB+标签"96 m"
  - 公式面板显示"已知条件"及三个已知值
  - 其余元素隐藏

- 步骤1「确定目标」：
  - 点击「下一步」→ △ABC 添加蓝色半透明填充（rgba(21,101,192,0.10)）+ 蓝色描边 2.5px，高亮三角形整体
  - 公式面板切换为"求解目标"：河宽 = 点 C 到直线 AB 的垂直距离

- 步骤2「添加辅助线」：
  - 点击「下一步」→ 从 C 向 AB 作垂线 CD（灰色虚线），垂足 D 出现并标注"D"，D 点左上方显示直角符号
  - CD 右侧中点标注"h"（黑色）
  - 公式面板切换为"辅助线"：作 CD ⊥ AB 于 D，设 CD = h

- 步骤3「求第三角」：
  - 点击「下一步」→ 在 C 点下方出现 ∠ACB 弧（蓝色），标注"60°"
  - 公式面板切换为"三角形内角和"：∠ACB = 180° − 75° − 45° = 60°

- 步骤4「正弦定理」：
  - 点击「下一步」→ 蓝色高亮边 AB、边 AC、∠ACB 弧（60°）、∠CBA 弧（45°，临时变蓝展示对角关系）
  - 公式面板切换为"正弦定理"，逐行展示：
    AC / sin45° = AB / sin60°
    AC = 96·sin45°/sin60°
    AC = 96×(√2/2)/(√3/2)
    AC = 32√6 (m)

- 步骤5「计算河宽」：
  - 点击「下一步」→ 高亮恢复：45°恢复绿色，60°恢复蓝色；当前蓝色高亮 AC 与 ∠A（75°弧）
  - CD 由灰色虚线变为红色 #c62828 实线 2.5px，标签由"h"变为红色粗体"75 m"
  - 公式面板切换为"计算河宽"，逐行展示：
    在 Rt△ADC 中：
    h = AC·sin75°
    sin75° = (√6+√2)/4
    h = 32√6×(√6+√2)/4
    h = 48 + 16√3
    h ≈ 75 (m)  ← 红色粗体

- 教师可随时点击「上一步」回退到任意步骤复习。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位置(310,455)，宽90×高32，点击回退到上一状态，步骤0时 disabled
  - 「下一步 ▶」按钮：位置(430,455)，宽90×高32，点击前进到下一状态，步骤5时 disabled
  - 步骤指示器：位置(415,495)，显示"步骤 k/5"，随当前步骤同步更新
- 教师操作流程：
  1. 教师打开图示，学生看到步骤0的基础场景与已知条件
  2. 教师点击「下一步」依次释放信息，配合公式面板讲解推导过程
  3. 需要复习时点击「上一步」回退，重新观察某一步的图形高亮与公式对应关系
  4. 步骤5得出最终结论后，可回退到步骤2重点讲解辅助线的作用

[技术实现]
- JS 库选择：原生 SVG（简单几何、路径、文本，无需引入外部库，减少依赖）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------------+
  |                                                        |
  |  上岸线 y=161  --------------------------------------  |
  |                                                        |
  |           C(251,145)                                   |
  |          / \                                           |
  |         /   \                                          |
  |        /     \                                         |
  |       /   60°  \              [公式面板]                |
  |      /           \            x=570~780               |
  |     /             \                                  |
  |    A(200,350)---D---B(440,350)                         |
  |  下岸线 y=350  --------------------------------------  |
  |    75°         45°                                     |
  |              96m                                       |
  |                                                        |
  |           [◀ 上一步]  [下一步 ▶]  步骤 k/5             |
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：变量 `currentStep` 取值 0~5，每步一个配置对象，定义该步应显示的元素ID列表、各元素的颜色/线宽/透明度属性。
  2. 元素显隐：所有可能元素在 SVG 中预定义，通过 `setAttribute('display', 'none'/'block')` 或修改 `opacity` 控制显隐，避免频繁创建/销毁 DOM。
  3. 高亮切换：通过修改元素的 `stroke`、`stroke-width`、`fill` 属性实现高亮，每步进入时先重置所有元素为默认样式，再应用当前步的高亮配置。
  4. 公式面板：使用一个 `<g id="scene1-formula-panel">` 包含多组 `<g>`（每组对应一步公式文字），每步只显示对应组。
  5. 动画曲线：无需复杂动画，步骤切换采用直接显隐（瞬时切换），符合教学课件"点击即现"的节奏；若需柔和过渡，可对 opacity 做 150ms ease 过渡。
  6. 事件绑定：按钮绑定 `click` 事件，更新 `currentStep` 后调用 `renderStep()` 统一渲染。
- **ID 命名规范**：所有 SVG 元素及交互元素 ID 必须以 `scene1-` 为前缀，例如：
  - `scene1-line-AB`、`scene1-line-CD`、`scene1-arc-A`、`scene1-label-A`、`scene1-formula-step0`、`scene1-btn-prev`、`scene1-btn-next`
  - JS 中严格使用 `document.getElementById` 获取元素，禁止全局 class 选择，避免多场景合并时跨场景污染
- IIFE 隔离：所有 JavaScript 代码包裹在 `(function() { ... })();` 中，变量不泄露全局作用域
- 几何坐标常量（在 JS 顶部定义，便于维护）：
  ```javascript
  const A = {x:200, y:350}, B = {x:440, y:350}, C = {x:251, y:161}, D = {x:251, y:350};
  ```
- 角度弧路径生成：使用辅助函数 `describeArc(cx, cy, r, startAngle, endAngle)` 计算 SVG path 的 `d` 属性，角度按数学极坐标（逆时针从正东，y向上）计算，再映射到 SVG 坐标（y向下）。
