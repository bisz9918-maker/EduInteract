[图示主题与整合说明]
- 本图示主题：电路实物图分析与电流表测量对象判断
- 整合的步骤/概念：实物图元件识别 → 关键节点标注 → 电流流向法动画追踪 → 等效电路图绘制 → 测量对象判定
- 教学价值：教师通过分步导航，引导学生从具象实物图逐步抽象到标准电路符号，再用电流流向法直观理解分流与汇合，最终通过等效电路高亮判定电流表测量对象。每步可独立讲解，也可快速跳转。

  6. 可随时回退到任意步骤复习

[技术实现]
- JS库选择：原生SVG + 原生JavaScript（无外部库）。原因：本场景以静态几何图形和简单显示/隐藏状态切换为主，SVG path绘制导线、circle绘制节点、text绘制标签即可满足；流动动画可用SVG stroke-dasharray + requestAnimationFrame实现，无需引入D3等重型库。
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  电池(+)                              开关[S]      |
  |    |                                   |          |
  |    +----->[电流表 A]                   |          |
  |    |          |                        |          |
  |    |          v                        v          |
  |    |       (节点a) <---- [灯泡 L₂] <---+          |
  |    |          |                                   |
  |    |          v                                   |
  |    +-----> [灯泡 L₁] -----> 回负极(-)             |
  |                                                   |
  |              [等效电路图（步骤3后出现）]            |
  |                                                   |
  |          "步骤提示文字"                           |
  |              [◀ 上一步]  [下一步 ▶]               |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 `currentStep`（0~4）记录当前步骤，每次点击按钮更新状态后调用 `renderStep()` 函数，根据状态显示/隐藏对应元素组。
  2. 元素分组：将每步新增元素用 `<g id="scene1-stepX-...">` 包裹，通过设置 `display: none/block` 控制显隐。
  3. 流动动画：对电流路径path设置 `stroke-dasharray="10,5"`，用 `requestAnimationFrame` 循环修改 `stroke-dashoffset`，实现箭头流动效果；仅在步骤2时启动动画，离开步骤2时停止。
  4. 高亮效果：步骤4时，对目标path复制一份并设置 `stroke-width="4" stroke="#1565c0"`，再叠加一层 `fill="rgba(21,101,192,0.15)"` 的宽path作为背景填充。
  5. 事件绑定：按钮绑定 `onclick`，更新 `currentStep` 后边界检查（0≤step≤4），然后调用渲染函数。
  6. 坐标计算：所有坐标硬编码在SVG元素中，无需动态计算。
- ID命名规范：所有交互元素ID以 `scene1-` 为前缀，例如：
  - `scene1-battery-plus`
  - `scene1-lamp-l1`
  - `scene1-ammeter`
  - `scene1-switch`
  - `scene1-node-a`
  - `scene1-path-blue`
  - `scene1-equiv-circuit`
  - `scene1-highlight-path`
  - `scene1-btn-prev`
  - `scene1-btn-next`
  - `scene1-step-text`
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })()` 中，避免全局污染。
- 按钮样式：使用HTML button元素，position:absolute定位在SVG容器底部，背景色#f0f0f0，边框1px solid #ccc，圆角4px，hover时背景色#e0e0e0。
