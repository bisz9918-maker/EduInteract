[图示主题与整合说明]

[分步序列]
- 步骤0（初始状态）：显示完整几何图形——圆、直径AB、竖直切线AC与BD、斜切线CD、点A/B/O/P/C/D及对应点名标签。右侧面板显示标题"计算面板"与提示"拖动点 P 观察变化"。所有坐标、方程、长度数值隐藏。P点可拖拽。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本场景为纯2D几何，元素为线段、圆、文本，无复杂函数绘图或3D，原生SVG性能最优且无需额外CDN依赖。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图：
  ```
  +--------------------------------------------------+
  |  主图区(0~500)              | 右侧面板(520~780)   |
  |                             |                     |
  |      D ●                    |  计算面板           |
  |       /                     |  ─────────          |
  |  C ●-/---● P                |  |PC| ≈ 69.28      |
  |  |  /    |                  |  |PD| ≈ 207.85     |
  |  | /     | PO               |                     |
  |  A●──────●──────●B          |  PC·PD = 14400     |
  |       O                     |  PO²   = 14400     |
  |      圆                     |  r²    = 14400     |
  |                             |                     |
  |                             |  PC·PD = PO² = r²  |
  |                             |                     |
  +--------------------------------------------------+
  |  [拖动点P观察变化]   [◀上一步] 步骤X/4 [下一步▶]  |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：变量 `currentStep` ∈ {0,1,2,3,4}，每步维护一个元素ID列表（`stepElements[i]`），切换步骤时遍历显示/隐藏对应元素。
  2. P点拖拽约束：监听`mousedown`→`mousemove`→`mouseup`。在`mousemove`中计算鼠标相对于圆心(300,280)的角度`theta = Math.atan2(280-my, mx-300)`（注意SVG y向下，使用`atan2(dy, dx)`其中dy=280-my）。更新P坐标：`x=300+r*cos(theta)`, `y=280-r*sin(theta)`。
  3. 几何实时计算：根据theta计算C(180, 280-r*cot(theta/2))、D(420, 280-r*tan(theta/2))。其中cot(t)=cos(t)/sin(t)，需处理sin接近0的边界（限制theta范围在(0.1, π-0.1)弧度，避免P太靠近A或B导致切线趋于水平/竖直而跑出画布）。
  4. 长度计算：PC = sqrt((xP-180)²+(yP-yC)²)，PD = sqrt((xP-420)²+(yP-yD)²)，PO = r，实时更新右侧面板数值文本。
  5. 动画曲线：无复杂动画，步骤切换使用直接显示/隐藏（opacity或display），保证教学节奏清晰；拖拽更新直接重绘，响应延迟<16ms。
  6. 事件绑定：按钮点击绑定`goPrev()`/`goNext()`；P点绑定鼠标事件；所有事件监听器在IIFE内注册，避免全局污染。
- ID命名规范：所有交互元素ID必须以`scene1-`为前缀。例如：`scene1-circle`、`scene1-point-P`、`scene1-line-PO`、`scene1-label-PC`、`scene1-panel-value-pc`、`scene1-btn-prev`、`scene1-btn-next`。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，内部变量与函数不暴露到全局作用域。
- 坐标公式备忘（供代码agent直接采用）：
  - 圆心 O = (300, 280)，半径 r = 120
  - P = (300 + r*cosθ, 280 - r*sinθ)
  - C = (180, 280 - r * cot(θ/2))
  - D = (420, 280 - r * tan(θ/2))
  - cot(t) = Math.cos(t)/Math.sin(t)，tan(t) = Math.sin(t)/Math.cos(t)
  - 限制 θ ∈ [0.15, π-0.15]（约8.6°~171.4°），防止C或D跑出画布顶部（y<0）
