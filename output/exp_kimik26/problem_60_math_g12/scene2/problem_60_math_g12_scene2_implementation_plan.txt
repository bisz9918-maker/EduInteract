[图示主题与整合说明]
- 本图示主题：椭圆中切线截距乘积的类比推导与焦半径结论
- 整合的步骤/概念：椭圆题设条件展示 → P点参数化 → 椭圆切线方程 → C与D坐标求解 → PC·PD代数计算 → 焦半径PF₁与PF₂引入 → 结论 PC·PD = PF₁·PF₂
- 教学价值：教师通过分步导航逐层展开推导，降低认知负荷；拖动P点可实时验证最终等式对椭圆上任意点成立，增强学生直观感知。

[分步序列]
- 初始状态（步骤0）：显示完整图形——椭圆、长轴AB、中心O、焦点F₁/F₂、竖直切线AC/BD、斜切线CD、点P/C/D、坐标轴。所有点标签可见。右侧面板显示椭圆标准方程 x²/a² + y²/b² = 1 及参数 a=200, b=100, c≈173, e≈0.87。隐藏PC/PD/PF₁/PF₂线段、OP连线、θ弧线、坐标标注、所有推导公式。
- 步骤1：点击「下一步」→ 显示OP连线（蓝色虚线）和θ角弧线（蓝色），高亮P点（蓝色描边加粗）。右侧面板显示 P(a·cosθ, b·sinθ) 及当前θ值、P的坐标数值。显示坐标标注 (-a,0)、(a,0)、(-c,0)、(c,0)。
- 步骤2：点击「下一步」→ 隐藏OP和θ弧线。高亮切线CD、AC、BD（线宽加粗至2.5px/2px）。右侧面板显示过P的切线方程 x·cosθ/a + y·sinθ/b = 1 及其具体形式。
- 步骤3：点击「下一步」→ 恢复切线正常线宽。显示PC、PD线段（红色，线宽2px），高亮C、D点（红色描边）。右侧面板显示交点坐标 C(-a, b·cot(θ/2))、D(a, b·tan(θ/2)) 及 |PC|、|PD| 的实时数值。
- 步骤4：点击「下一步」→ 保持PC、PD红色高亮。右侧面板追加推导：PC·PD = a²·sin²θ + b²·cos²θ，并显示数值结果。
- 步骤5：点击「下一步」→ 显示PF₁、PF₂线段（绿色，线宽2px），高亮F₁、F₂点（绿色填充）。右侧面板显示焦半径公式 PF₁ = a − e·x、PF₂ = a + e·x，推导 PF₁·PF₂ = a² − e²x² = a²·sin²θ + b²·cos²θ，并显示数值。
- 步骤6（最终）：点击「下一步」→ 右侧面板显示最终结论 PC·PD = PF₁·PF₂，同时展示两侧数值并高亮相等。所有相关线段保持高亮（PC/PD红色，PF₁/PF₂绿色）。教师可拖动P点实时验证等式恒成立。
- 回退：教师可随时点击「上一步」回退到任意步骤复习。

  1. 「◀ 上一步」按钮：位于(250,452)，宽90×高32。点击回退到上一分步，更新视觉高亮和右侧面板内容。
  2. 「下一步 ▶」按钮：位于(460,452)，宽90×高32。点击前进到下一分步，更新视觉高亮和右侧面板内容。
  3. 步骤指示器：位于(400,473)，显示"步骤 k / 7"。
  4. 提示文字：位于(400,492)，显示"拖动点P验证结论"。
  5. P点拖拽：鼠标按下P点后可在椭圆上拖动，θ约束在[60°,120°]（确保C、D始终在画布内且不进入控件区）。拖动时切线CD、交点C/D、线段PC/PD/PF₁/PF₂、所有数值与公式实时更新。
- 教师操作流程：
  1. 加载后进入步骤0，展示完整题设图形。
  2. 教师点击「下一步」逐层展开推导，每步配合右侧面板公式讲解。
  3. 到达步骤6后，教师拖动P点在椭圆上移动，引导学生观察右侧面板中 PC·PD 与 PF₁·PF₂ 两数值始终相等，验证结论的一般性。
  4. 可随时点击「上一步」回退复习关键推导步骤。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：本场景为二维几何图形，无复杂函数绘图或3D需求；公式通过foreignObject内嵌HTML显示，无需MathJax。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------------+
  |  y轴                                                   |
  |    |         C----P----------------D                   |
  |    |        /     \              /                     |
  |    |       /       \            /                      |
  |    |      /         \          /                       |
  |    |     /           \        /                        |
  |  F2A-----O-------F1---B                               |
  |    |            [椭圆轮廓]                             |
  |    |                                                   |
  |    |                                                   |
  |    +------------------------------------------------   |
  |             [右侧面板: 公式与数值]                      |
  |                                                        |
  |  [◀ 上一步]    步骤 1/7    [下一步 ▶]                  |
  |              拖动点P验证结论                           |
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 `scene2_currentStep`（0~6）记录当前分步。每步对应一个显示组（`<g id="scene2-step-k">`），通过CSS `display` 控制显隐。
  2. 椭圆参数：中心O(350,250)，a=200，b=100，c=100√3，e=√3/2。P点参数角θ初始值120°（2π/3），拖动范围限制为θ∈[60°,120°]（即[π/3, 2π/3]），确保C、D的y坐标始终≤430（不进入控件区）。
  3. 坐标计算（以O为原点的相对坐标，绘制时加偏移350,250）：
     - P：(200·cosθ, 100·sinθ)
     - C：(-200, 100·cot(θ/2))
     - D：(200, 100·tan(θ/2))
     - |PC|、|PD|：欧氏距离公式
     - PF₁ = 200·(1 − e·cosθ)，PF₂ = 200·(1 + e·cosθ)
     - PC·PD = 40000·sin²θ + 10000·cos²θ
     - PF₁·PF₂ = 40000 − 30000·cos²θ（与上式恒等）
  4. 动画曲线：无复杂动画，状态切换为即时显示/隐藏。P点拖动采用直接坐标更新（requestAnimationFrame优化），确保流畅。
  5. 事件绑定：
     - 按钮点击：document.getElementById('scene2-btn-prev').addEventListener('click', ...)
     - P点拖拽：在P的circle元素上绑定mousedown，在SVG上绑定mousemove/mouseup。拖拽时计算鼠标位置相对于O的角度，限制在[60°,120°]，更新所有动态元素。
  6. 右侧面板：使用`<foreignObject x="620" y="50" width="160" height="350">`包裹一个div，div id="scene2-panel-content"，通过innerHTML动态注入带<sup>/<sub>的HTML字符串更新公式和数值。
  7. 所有动态SVG元素（P、C、D、CD线、PC、PD、PF₁、PF₂、标签）在拖拽回调中通过setAttribute('cx', ...)、setAttribute('x1', ...)等方式更新，避免CSS transform以保证跨浏览器SVG一致性。
- ID命名规范：所有交互元素ID必须以 `scene2-` 为前缀。例如：
  - 椭圆：`scene2-ellipse`
  - P点：`scene2-point-p`
  - PC线段：`scene2-line-pc`
  - 上一步按钮：`scene2-btn-prev`
  - 下一步按钮：`scene2-btn-next`
  - 步骤1显示组：`scene2-step-1`
  - 面板div：`scene2-panel-content`
  JS中严格使用 `document.getElementById` 获取元素，禁止全局class查询，避免多场景合并时跨场景污染。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，内部变量不泄露到全局作用域。
