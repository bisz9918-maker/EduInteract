题目原文

如图，在半径为3的球面上有A、B、C三点，∠ABC = 90°，BA = BC，球心O到平面ABC的距离是 $\frac{3\sqrt{2}}{2}$，则B、C两点的球面距离是．

题目分析与整体讲解思路

本题是立体几何中"球面距离"的经典问题，核心在于将空间问题分解为两个平面问题：

  1. 利用球心到截面的距离求出截面小圆半径，再结合圆周角定理求出弦BC的长度；
  2. 在由球心和B、C两点构成的三角形中，利用三边长度求出中心角，进而计算球面距离。

关键知识点：

  • 球心到截面距离 d、球半径 R、截面圆半径 r 满足 $r = \sqrt{R^2 - d^2}$
  • 圆周角定理：直径所对圆周角为90°，反之90°圆周角所对弦为直径
  • 球面距离公式：$l = R \cdot \theta$（其中 $\theta$ 为两点与球心连线的夹角，单位为弧度）

图示规划说明

设计两个图示：

  • 图示1（SCENE_1）：立体几何关系图。展示球体、截面平面ABC、球心到平面的垂距、以及三角形ABC在截面圆上的几何关系。通过分步导航，引导学生从已知条件逐步推导出BC = 3。
  • 图示2（SCENE_2）：球面距离计算图。聚焦球心O与B、C两点构成的三角形，展示中心角∠BOC的求解过程，最终得出球面距离为π。
步骤 0 / 5

本图示教学说明（SCENE_1）

教师应引导学生按以下顺序观察：

  1. 首先确认A、B、C三点都在球面上，且满足∠ABC = 90°、BA = BC，构成等腰直角三角形。
  2. 关键观察：三点共面于平面ABC，该平面截球得到一个小圆（截面圆），A、B、C都在这个小圆上。
  3. 利用球心到截面距离公式求小圆半径：

$$r = \sqrt{R^2 - d^2} = \sqrt{3^2 - \left(\frac{3\sqrt{2}}{2}\right)^2} = \sqrt{9 - \frac{9}{2}} = \sqrt{\frac{9}{2}} = \frac{3\sqrt{2}}{2}$$

  1. 由于∠ABC = 90°且A、B、C共圆，根据圆周角定理，90°圆周角所对的弦AC必为直径。
  2. 因此 $AC = 2r = 3\sqrt{2}$。
  3. 在等腰直角三角形ABC中，$BC = \frac{AC}{\sqrt{2}} = \frac{3\sqrt{2}}{\sqrt{2}} = 3$。

讲解要点：

  • 强调"球面上的三点确定一个平面，该平面截球得小圆"这一空间到平面的转化思想。
  • 提醒学生注意：∠ABC = 90°是在平面ABC内测量的，不是在球面上测量的，因此可以直接应用平面几何的圆周角定理。
  • BC = 3 这个结论非常关键，它是连接"平面几何"与"球面距离"的桥梁。
步骤 1 / 6

本图示教学说明（SCENE_2）

教师应引导学生理解：球面距离不是直线距离（弦BC），而是过这两点的大圆劣弧长度。

  1. 明确已知：OB = OC = R = 3（球半径），BC = 3（上一步推导的弦长）。
  2. 在△BOC中，三边相等（OB = OC = BC = 3），故为等边三角形。
  3. 因此中心角 $\angle BOC = 60° = \frac{\pi}{3}$（弧度）。
  4. 应用球面距离公式：

$$l = R \cdot \theta = 3 \times \frac{\pi}{3} = \pi$$

  1. 最终答案为 π。

讲解要点：

  • 必须区分三个概念：弦长BC（直线段，长度为3）、球面距离（大圆劣弧，长度为π）、以及两点间最短路径在球面上的定义。
  • 强调"大圆"的重要性：球面上两点间的最短路径是过这两点的大圆劣弧，而非任意小圆上的弧。
  • 可以追问学生：如果误用小圆（即平面ABC的截面圆）来计算弧长，会得到什么错误结果？（小圆半径r = 3√2/2，圆心角∠BHC需另行计算，结果不是π）以此加深对"球面距离必须用大圆"的理解。

完整解答回顾：

  1. 由 $r = \sqrt{R^2 - d^2}$ 得截面圆半径 $r = \frac{3\sqrt{2}}{2}$
  2. 由圆周角定理，AC为直径，$AC = 2r = 3\sqrt{2}$
  3. 等腰直角三角形中，$BC = \frac{AC}{\sqrt{2}} = 3$
  4. △BOC为等边三角形，$\angle BOC = \frac{\pi}{3}$
  5. 球面距离 $l = R\theta = 3 \times \frac{\pi}{3} = \pi$
