[图示主题与整合说明]
- 本图示主题：球面距离与中心角∠BOC计算
- 整合内容：在半径为3的球面上，由球心O与B、C两点构成的空间三角形BOC，通过边长关系判定等边三角形，得出中心角∠BOC = 60° = π/3，最终应用球面距离公式 l = R·θ 求得球面距离为π。
- 教学价值：教师可通过分步导航，带领学生从已知弦长BC出发，逐步推导出中心角，再映射到球面大圆劣弧，建立"弦长→中心角→球面距离"的完整认知链条。每一步的视觉高亮与标注对应逻辑递进，便于课堂暂停讲解。

[分步序列]
- 步骤0（初始状态）：显示球轮廓（灰色虚线大圆）、球心O、点B与点C、连线OB与OC（蓝色实线）、连线BC（黑色实线）。显示标签O、B、C及边长标注"OB = 3"、"OC = 3"（蓝色，位于OB左侧与OC右侧）。右侧无文字。教师可在此回顾已知条件：OB、OC为球半径R=3。
- 步骤1（标注弦长）：在步骤0基础上，新增弦BC下方绿色标注"BC = 3"（(400, 385)）。强调该值由前一步（Scene 1）推导得出。教师可讲解：现已知三角形BOC的三边信息。
- 步骤2（判定等边三角形）：三边OB、OC、BC同时高亮——线宽从1.5px加粗至2.5px，三角形内部填充淡蓝色（#1565c0，透明度12%）。右侧出现绿色说明文字："∵ OB = OC = BC = 3"（(620, 190)）与"∴ △BOC 为等边三角形"（(620, 215)）。教师可讲解等边三角形的判定。
- 步骤3（标注中心角）：在O点下方出现红色角度弧线（圆心(400,250)，半径28，开口向下），弧线外侧标注"60°"（(400, 298)）。右侧出现红色说明文字"中心角 ∠BOC = 60° = π/3"（(620, 260)）。教师可讲解：等边三角形内角为60°，即球心角为π/3。
- 步骤4（绘制大圆劣弧）：在球面上方绘制过B、O、C三点的球大圆劣弧BC——红色粗弧线（三次贝塞尔：M310,360 C350,150 450,150 490,360），线宽2.5px。右侧出现红色说明"大圆劣弧 BC（球面距离路径）"（(620, 320)）。教师可讲解：球面距离是大圆劣弧的长度。
- 步骤5（得出结论）：画面底部中央出现红色粗体结论文字"球面距离 l = R·θ = 3 × π/3 = π"（(400, 418)，16px）。右侧文字保持。教师可总结公式应用，强调最终答案为π。
- 导航：教师可随时点击「◀ 上一步」回退至任意步骤复习，点击「下一步 ▶」向前推进。

[交互方案]
- 交互类型：分步按钮导航（◀ 上一步 / 下一步 ▶）。
- 控件说明：
  1. 「◀ 上一步」按钮：位于底部(280, 462)，宽100px，高32px。点击后回退一个步骤，步骤0时禁用（opacity 0.4，pointer-events none）。
  2. 「下一步 ▶」按钮：位于底部(420, 462)，宽100px，高32px。点击后前进一个步骤，步骤5时禁用。
  3. 步骤指示器：位于两按钮上方居中(400, 455)，显示"步骤 X / 6"，12px灰色。
- 教师操作流程：
  1. 教师加载图示，默认进入步骤0，展示基础几何条件。
  2. 教师点击「下一步」进入步骤1，讲解BC = 3的由来。
  3. 继续点击「下一步」依次展示等边判定、中心角、大圆劣弧、最终结论。
  4. 在任意步骤可点击「上一步」回退，重新强调前一环节的逻辑。
  5. 所有视觉变化（出现/高亮/隐藏）均由按钮点击触发，无自动播放，便于教师控制课堂节奏。

[技术实现]
- JS库选择：原生 SVG + 原生 JavaScript。理由：本场景仅涉及基本几何图形（圆、线、路径、文本）的显示/隐藏与样式切换，无需复杂数据绑定或3D渲染，原生SVG性能最优且依赖最少。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图：
  ```
  +--------------------------------------------------+
  |  球轮廓（灰色虚线大圆）                            |
  |              球心 O ●                              |
  |         蓝色半径 /   \ 蓝色半径                    |
  |               /     \                              |
  |      点 B ● ——————— ● 点 C   黑色弦 BC            |
  |       （左下）       （右下）                       |
  |              红色劣弧（步骤4，上方弧线）            |
  |                                                  |
  |  右侧信息区：等边判定 / 中心角 / 大圆路径说明       |
  |  底部结论：球面距离 l = π（步骤5）                 |
  |                                                  |
  |        [◀ 上一步]  步骤 X/6  [下一步 ▶]           |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `currentStep`（0~5）。每步对应一个配置对象，声明该步应显示的元素ID列表、应高亮的元素ID列表、应修改的样式属性。避免大量if-else嵌套。
  2. 元素分组：将每步新增的元素分别包裹在 `<g id="scene2-step1-group">` 等分组中，通过控制组的 `display` 属性（或 `opacity` + CSS transition）实现出现/隐藏。始终显示的元素（球轮廓、O/B/C点、基础连线）不放分组。
  3. 高亮实现：步骤2的三边高亮通过动态修改 `stroke-width`（1.5px → 2.5px）实现；三角形填充通过控制填充层的 `display` 实现。
  4. 坐标计算：
     - 角度弧线路径：圆心(400,250)，半径28。起点(400+28*cos(129.3°), 250+28*sin(129.3°)) ≈ (382.4, 271.8)；终点(400+28*cos(50.7°), 250+28*sin(50.7°)) ≈ (417.8, 271.6)。使用SVG `<path d="M 382.4 271.8 A 28 28 0 0 1 417.8 271.6"/>`。
     - 大圆劣弧：三次贝塞尔 `<path d="M 310 360 C 350 150 450 150 490 360"/>`。
  5. 动画曲线：元素出现使用CSS `transition: opacity 0.25s ease-out`，避免生硬跳变；线宽变化使用 `transition: stroke-width 0.2s ease`。
  6. 事件绑定：按钮绑定 `click` 事件，更新 `currentStep` 后调用 `renderStep()` 统一刷新视图。
  7. 按钮状态：在 `renderStep()` 中同步更新按钮 disabled 状态与步骤指示器文本。
- ID命名规范：所有SVG元素及控件ID必须以 `scene2-` 为前缀。例如：`scene2-point-o`、`scene2-line-ob`、`scene2-step2-fill`、`scene2-btn-prev`、`scene2-btn-next`。JS中严格使用 `document.getElementById` 获取元素，禁止全局class选择器，避免多场景合并时跨场景污染。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，不暴露全局变量。若需对外暴露接口，仅挂载到特定命名空间（如 `window.Scene2 = { reset: ... }`）。
