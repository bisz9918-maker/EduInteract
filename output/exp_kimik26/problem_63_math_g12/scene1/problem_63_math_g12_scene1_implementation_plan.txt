[图示主题与整合说明]

[分步序列]
- 步骤0（基本图形）：显示坐标系、双曲线左右两支、圆、右焦点F、两条渐近线（虚线）。标签：O、x、y、F。学生先识别基本元素。无高亮。
- 步骤1（题意展示）：点击「下一步」→ 显示直线l、切点M、双曲线交点P、中点标记（M处垂直于PF的短线）。新增标签：M、P、l。强调M为PF中点的位置关系。
- 步骤2（切线性质）：点击「下一步」→ 显示线段OM（蓝色）、M处直角标记（OM⊥l）、Rt△OMF蓝色半透明填充。新增标签：|OM|=b、|OF|=c、|MF|=a。右侧显示推导文字"c²-b²=a²"。高亮OM与直角标记。
- 步骤3（中位线构造）：点击「下一步」→ 显示左焦点F'（绿色）、线段PF'（绿色）、线段FF'（黑色）。高亮OM为△PFF'中位线（O、M分别为FF'、PF中点）。新增标签：F'、|PF'|=2b。右侧显示推导文字"|PF'|=2b，PF'∥OM，PF'⊥PF"。
- 步骤4（双曲线定义）：点击「下一步」→ 显示Rt△PFF'绿色半透明填充、P处直角标记（∠FPF'=90°）。新增标签：|PF|=2a（红色）、∠FPF'=90°。高亮PF（红色）与PF'（绿色）。右侧显示推导文字"|PF'|-|PF|=2a → 2b-2a=2a → b=2a"。
- 步骤5（结论）：点击「下一步」→ 渐近线高亮为绿色#2e7d32（加粗或实线化）。新增标签：k=2（上渐近线右侧）、k=-2（下渐近线右侧）。右侧大字体绿色显示结论"y=±2x"。所有推导完成。
- 教师可随时点击「上一步」回退到任意步骤复习。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 步骤指示器 / 下一步▶）
- 控件说明：
  1. 「上一步」按钮：位于控件栏左侧，点击回退到上一状态
  2. 步骤指示器：位于两按钮中间，显示"步骤 k/6"
  3. 「下一步」按钮：位于控件栏右侧，点击前进到下一状态
- 教师操作流程：
  1. 加载页面后自动显示步骤0（基本图形），教师讲解双曲线、圆、焦点位置
  2. 点击「下一步」进入步骤1，展示题意中的直线l、切点M、交点P
  3. 依序点击「下一步」逐步展示切线性质、中位线、双曲线定义、结论
  4. 讲解过程中可随时点击「上一步」回退，重新强调关键几何关系
  5. 步骤5显示最终结论y=±2x，完成整题讲解

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本场景为纯2D几何图形，无复杂函数绘图、无3D、无大量数据，原生SVG路径和元素即可满足，无需引入D3/Three.js等外部库，减少依赖和加载时间。
- 画布尺寸：800×500 px（固定尺寸，与容器同宽）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------------+
  |  ^y    渐近线(虚线)                    k=2              |
  |  |      /                              推导文字区      |
  |  |     /   P •                                         |
  |  |    /     •M   圆                                    |
  |  |   /      |\ /                                       |
  |  |  /       | \                                        |
  |  | /    F'--O--F------------>x                         |
  |  | \       /|\                                        |
  |  |  \     / | \                                       |
  |  |   \   /  |  \   渐近线(虚线)                        |
  |  |    \ /   |   \                                     |
  |  +---------------------------------------------------|
  |         [◀上一步]  步骤 1/6  [下一步▶]                 |
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：变量 `currentStep` ∈ {0,1,2,3,4,5}。初始化currentStep=0。
  2. 元素分组：SVG中使用`<g id="scene1-stepX">`包裹每步新增的元素（X=0~5）。步骤0的元素默认显示，其余步骤组默认`display:none`或`opacity:0`。
  3. 切换逻辑：`updateScene(step)`函数根据currentStep值，遍历所有步骤组，显示≤currentStep的组，隐藏>currentStep的组。使用CSS transition实现0.2s淡入淡出。
  4. 高亮控制：部分元素（如OM、PF、PF'、渐近线）在不同步骤有不同颜色/线宽。通过添加/移除CSS类（如`.scene1-highlight-blue`、`.scene1-highlight-green`）实现。
  5. 按钮状态：currentStep=0时「上一步」disabled；currentStep=5时「下一步」disabled。
  6. 坐标计算：双曲线路径点通过JavaScript预计算（a=35,b=70,c=35√5），生成path的d属性字符串，避免手写大量坐标。
  7. 事件绑定：按钮onclick直接调用updateScene(currentStep±1)。
- ID命名规范：所有SVG元素和JS变量ID必须以`scene1-`为前缀。例如：`scene1-axis-x`、`scene1-hyperbola-right`、`scene1-point-F`、`scene1-step-2-group`、`scene1-btn-prev`、`scene1-btn-next`。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免多场景合并时全局变量污染。
- 响应式说明：画布固定800×500，外层容器设置`max-width:800px;margin:0 auto`，保持比例。
