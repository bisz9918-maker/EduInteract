[图示主题与整合说明]
- 本图示主题：直四棱柱中空间线线垂直的转化推理
- 整合的步骤/概念：直四棱柱结构确认 → 侧棱垂直底面性质 → 连接BD证明B₁D₁∥BD → AC⊥BD⇒AC⊥B₁D₁ → 结论填空
- 教学价值：教师通过分步导航控制讲解节奏，学生可跟随每一步观察图形变化，理解"线面垂直→线线垂直→平行传递"的完整推理链

[分步序列]
- 初始状态（步骤0）：展示直四棱柱ABCD-A₁B₁C₁D₁整体框架。12条棱按可见/被遮挡分别用实线/虚线绘制；8个顶点标签显示；底面ABCD填充浅蓝15%透明度；步骤指示器显示"初始状态"。等待教师触发下一步。
- 步骤1：点击「下一步」→ 四条侧棱AA₁、BB₁、CC₁、DD₁高亮为绿色（#2e7d32，线宽2.5px，AA₁保持虚线样式）；左侧显示绿色标注"侧棱⊥底面"；步骤指示器更新为"步骤 1/4"。教师讲解直四棱柱定义。
- 步骤2：点击「下一步」→ 侧棱恢复基础样式，绿色标注隐藏；添加辅助线BD（灰色虚线）；B₁D₁和BD同时高亮为蓝色（#1565c0，线宽2.5px）；右上方显示绿色标注"B₁D₁∥BD"；步骤指示器更新为"步骤 2/4"。教师讲解平行关系。
- 步骤3：点击「下一步」→ 保持B₁D₁和BD蓝色高亮；底面对角线AC高亮为蓝色（#1565c0，线宽2.5px）；在AC与BD交点(410,330)右上方添加红色直角标记；显示红色标注"AC⊥BD"；下方显示红色推导文字"AC⊥BD 且 B₁D₁∥BD ⇒ AC⊥B₁D₁"；步骤指示器更新为"步骤 3/4"。教师讲解垂直转化。
- 步骤4（最终）：点击「下一步」→ 保持所有高亮和直角标记；隐藏推导文字，替换为红色加粗结论文字"答案：AC⊥BD（或ABCD为菱形、正方形等）"；步骤指示器更新为"步骤 4/4（结论）"。教师总结填空答案。
- 回退：教师可随时点击「上一步」回退到任意步骤复习，所有视觉元素按对应步骤重新渲染。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「上一步」按钮：位于SVG内底部(300,458)，宽80×高30px。点击回退到上一状态，步骤0时disabled（灰色）。
  2. 「下一步」按钮：位于SVG内底部(420,458)，宽80×高30px。点击前进到下一状态，步骤4时disabled（灰色）。
  3. 步骤指示器：位于(400,438)，显示当前步骤文字（如"步骤 2/4"），始终可见。
- 教师操作流程：
  1. 教师打开图示，学生看到完整直四棱柱框架（步骤0）。
  2. 教师点击「下一步」进入步骤1，讲解侧棱垂直底面的定义，学生观察四条侧棱绿色高亮。
  3. 教师点击「下一步」进入步骤2，连接BD，讲解B₁D₁∥BD的平行关系，学生观察蓝色高亮线段。
  4. 教师点击「下一步」进入步骤3，讲解AC⊥BD的条件，学生观察直角标记和推导过程。
  5. 教师点击「下一步」进入步骤4，揭示填空答案，完成讲解。
  6. 讲解过程中可随时回退复习。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：本场景为简单立体几何线条与标签，无需复杂数学计算或3D渲染，原生SVG性能最优，且便于精确控制每条棱的显隐和颜色。
- 画布尺寸：800 × 500 px（SVG viewBox="0 0 800 500"）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |  [A₁]        [D₁]                                |
  |   ●──────────●                                   |
  |  /│         /│                                   |
  | / │        / │      侧棱⊥底面  (步骤1)           |
  |●──┼───────●  │      B₁D₁∥BD    (步骤2)           |
  |[B₁]│      [C₁]│                                   |
  |   │        │  │                                   |
  |   │        │  │      AC⊥BD      (步骤3)           |
  |   │        │  │      ⇒ AC⊥B₁D₁                   |
  |   ●────────┼──●                                   |
  |  /[A]      │ /[D]                                 |
  | /          │/      答案：AC⊥BD... (步骤4)         |
  |●──────────●                                      |
  |[B]        [C]                                    |
  |                                                  |
  |              步骤 X/4                            |
  |           [上一步] [下一步]                      |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：定义变量 `let currentStep = 0;`，共5个状态（0-4）。`updateScene()`函数根据currentStep统一设置所有SVG元素的stroke、stroke-width、display属性。
  2. 元素显隐：所有步骤专属元素（高亮线段、标注文字、直角标记）初始 `display: none`，在对应步骤通过 `display: block/inline` 显示。
  3. 颜色切换：基础棱线始终存在，高亮通过叠加同位置、不同颜色的线段实现（如侧棱基础为黑色，高亮为绿色线段覆盖），避免频繁修改单条线段样式导致逻辑复杂。
  4. 事件绑定：按钮绑定 `click` 事件，修改currentStep后调用updateScene()。
  5. 动画曲线：无需复杂动画，步骤切换直接显隐（瞬时），保持教学讲解的清晰节奏。
  6. 按钮状态：步骤0时禁用「上一步」，步骤4时禁用「下一步」，通过添加/移除 `disabled` 属性和CSS样式实现。
- **ID命名规范**：所有SVG元素和交互控件ID必须以 `scene1-` 为前缀。例如：
  - 顶点标签：`scene1-label-A`, `scene1-label-B` ... `scene1-label-D1`
  - 棱线：`scene1-edge-AA1`, `scene1-edge-BB1` ... `scene1-edge-D1A1`
  - 高亮层：`scene1-hl-lateral-AA1`, `scene1-hl-blue-B1D1`, `scene1-hl-blue-AC`
  - 标注文字：`scene1-anno-lateral`, `scene1-anno-parallel`, `scene1-anno-perp`, `scene1-anno-deduce`, `scene1-anno-answer`
  - 直角标记：`scene1-right-angle-h`, `scene1-right-angle-v`
  - 控件：`scene1-btn-prev`, `scene1-btn-next`, `scene1-step-indicator`
  - JS中严格使用 `document.getElementById()` 获取元素，禁止全局class选择器，避免多场景合并时跨场景污染。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，变量不泄露全局作用域。
