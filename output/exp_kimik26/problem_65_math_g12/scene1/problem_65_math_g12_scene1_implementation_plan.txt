[图示主题与整合说明]
- 本图示主题：直角三角形与圆综合问题——从题意理解到结论得出的完整几何推导过程
- 整合的步骤/概念：
  1) 建立基础图形（Rt△ABC、以AC为直径的圆、交点D）
  2) 连接辅助线CD
  3) 利用"直径所对圆周角为直角"得到∠ADC=90°
  4) 勾股定理求斜边AB=10cm
  5) 射影定理（或相似三角形）求AD=3.6cm
  6) 作差得BD=6.4cm
- 教学价值：教师可按照线性逻辑顺序逐步展开，每步聚焦一个知识点；分步按钮支持随时回退，便于重复讲解关键步骤（如隐含直角的发现、射影定理的应用）。右侧旁注区同步显示当前步骤的公式与结论，使图形与代数推导左右对照。

[分步序列]
状态机共6个状态（currentStep = 0~5），对应步骤1/6~6/6。

- 步骤0（步骤 1/6：已知条件）——初始状态：
  - 显示：△ABC三边、圆（含浅灰填充）、点A/B/C/D/O及标签、C点直角符号、AC=6、BC=8
  - 旁注："<b>已知条件</b><br>在Rt△ABC中，∠C=90°<br>AC = 6 cm，BC = 8 cm<br>以AC为直径作圆，交斜边AB于点D"
  - 所有后续元素隐藏

- 步骤1（步骤 2/6：连接辅助线）：
  - 新增：线段CD（蓝色#1565c0，2px实线），淡入300ms
  - 旁注："<b>辅助线</b><br>连接CD<br>为利用圆的性质做准备"
  - 其余同步骤0

- 步骤2（步骤 3/6：发现隐含直角）：
  - 新增：D点直角符号（绿色#2e7d32），淡入300ms
  - 旁注："<b>发现隐含直角</b><br>∵ AC是直径<br>∴ ∠ADC = 90°<br><span style='color:#2e7d32'>（直径所对圆周角为直角）</span>"
  - 其余同步骤1

- 步骤3（步骤 4/6：计算斜边）：
  - 新增：AB=10标注（绿色#2e7d32），淡入300ms
  - 旁注："<b>计算斜边AB</b><br>由勾股定理：<br>AB² = AC² + BC²<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;= 6² + 8² = 100<br>∴ AB = 10 cm"
  - 其余同步骤2

- 步骤4（步骤 5/6：求AD）：
  - 新增：AD=3.6标注（绿色#2e7d32），淡入300ms
  - 新增：△ADC区域浅蓝色半透明填充（#1565c0, opacity 0.12），淡入400ms
  - 旁注："<b>求AD</b><br>∵ Rt△ADC ∽ Rt△ACB<br>∴ AC² = AD · AB<br>&nbsp;&nbsp;&nbsp;36 = AD × 10<br>∴ AD = 3.6 cm"
  - 其余同步骤3

- 步骤5（步骤 6/6：得出结论）：
  - 新增：BD=6.4标注（红色#c62828，加粗），淡入300ms
  - 旁注："<b>结论</b><br>BD = AB − AD<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;= 10 − 3.6<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;= <span style='color:#c62828;font-size:1.2em'><b>6.4 cm</b></span>"
  - 最终答案文字放大高亮，其余同步骤4

教师可随时点击「◀ 上一步」回退到任意步骤复习。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「◀ 上一步」按钮：位置(310, 460)，宽90×高34。点击后currentStep减1（最小为0），回退到上一步视觉状态。
  2. 「下一步 ▶」按钮：位置(420, 460)，宽90×高34。点击后currentStep加1（最大为5），推进到下一步视觉状态。
  3. 步骤指示文本：位置(400, 452)，显示"步骤 X/6"，灰色小字。
- 教师操作流程：
  1. 教师打开图示，初始显示步骤1/6（基础图形与已知条件），向学生说明题目条件。
  2. 点击「下一步」进入步骤2/6，引出辅助线CD，提问"连接CD后你能发现什么？"
  3. 点击「下一步」进入步骤3/6，揭示∠ADC=90°，强调直径所对圆周角为直角这一关键隐含条件。
  4. 点击「下一步」进入步骤4/6，计算斜边AB=10，复习勾股定理。
  5. 点击「下一步」进入步骤5/6，利用射影定理求AD=3.6，高亮△ADC与△ACB的相似关系。
  6. 点击「下一步」进入步骤6/6，得出BD=6.4，红色高亮最终答案。
  7. 若学生某步未理解，教师可随时点击「上一步」回退重讲。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本场景为静态几何图形与分步显隐，无复杂函数绘图或3D，原生SVG足够轻量且精确控制每个几何元素。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |  [步骤标题：步骤 X/6：...]          (y=20~45)     |
  |                                                  |
  |   主图区 (x=50~480)        |  旁注区 (x=520~780) |
  |                            |                     |
  |      A ●                   |  <b>已知条件</b>     |
  |      | \                   |  AC=6, BC=8...      |
  |      |  \ D●               |                     |
  |    O ●   \                 |                     |
  |      |    \                |                     |
  |      |     \               |                     |
  |   B  ●------● C            |                     |
  |                            |                     |
  |                            |                     |
  |   (y=60~420)               |   (y=60~420)        |
  |--------------------------------------------------|
  |        [◀ 上一步]  步骤 X/6  [下一步 ▶]          |
  |                  (y=450~490)                     |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：定义全局变量 `currentStep`（0~5）。`updateScene(step)` 函数根据step值设置各SVG元素的 `display` 或 `visibility` 属性。使用 `opacity` + CSS transition 实现淡入效果（transition: opacity 0.3s ease）。
  2. D点坐标计算：A(400,200), B(160,380), C(400,380)。由参数方程求得D为AB上距A 0.36倍处，即D=(314,265)。此坐标保证AD:DB=3.6:6.4=9:16，与题意一致。
  3. D点直角符号绘制：AB方向单位向量(0.8,-0.6)，CD方向（DC）单位向量(0.6,0.8)。从D出发沿两方向各取8px得P1=(320.4,260.2)、P2=(318.8,271.4)，再得内侧顶点P_inner=(325.2,266.6)。路径：`M 320,260 L 325,267 L 319,271`（取整）。
  4. △ADC填充：使用SVG `<polygon points="400,200 314,265 400,380" />`，fill="#1565c0"，fill-opacity="0.12"。
  5. 旁注区：使用SVG `<foreignObject x="520" y="70" width="260" height="320">`，内部嵌入HTML `<div>`，通过 `innerHTML` 切换每步内容。样式：font-size 14px，line-height 1.6，背景rgba(255,255,255,0.9)。
  6. 按钮禁用逻辑：当currentStep===0时，「上一步」按钮disabled=true、opacity=0.5；当currentStep===5时，「下一步」按钮disabled=true、opacity=0.5。
  7. 键盘支持（可选增强）：监听keydown事件，LeftArrow触发上一步，RightArrow触发下一步。
- ID命名规范：所有交互元素ID必须以 `scene1-` 为前缀。示例：
  - SVG容器：id="scene1-svg-container"
  - 三角形：id="scene1-triangle-abc"
  - 圆：id="scene1-circle"
  - 线段CD：id="scene1-line-cd"
  - 直角符号D：id="scene1-right-angle-d"
  - AB标注：id="scene1-label-ab"
  - AD标注：id="scene1-label-ad"
  - BD标注：id="scene1-label-bd"
  - △ADC填充：id="scene1-fill-adc"
  - 旁注div：id="scene1-note-content"
  - 上一步按钮：id="scene1-btn-prev"
  - 下一步按钮：id="scene1-btn-next"
  - 步骤指示：id="scene1-step-indicator"
  - JS中严格使用 `document.getElementById` 获取元素，禁止全局class选择器，避免多场景合并时跨场景污染。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，内部变量不污染全局作用域。
