[关键动态坐标公式]
- A′(θ): sx = 400 + 94·cosθ,  sy = 300 − 42·cosθ − 114·sinθ  （θ为弧度，radians = θ°×π/180）
- P(θ):  sx = 400 + 94·cosθ,  sy = 300 − 42·cosθ  （P始终在AF线段上）
- 旋转轨迹圆路径：以5°为步进采样72个点，用L命令连线闭合

[视觉元素清单]
- 底面正三角形ABC：黑色边线+#fff9c4淡黄填充（透明度20%），三个顶点A/B/C
- 中线AF与中位线DE：黑色实线，交点G
- 动点A′：蓝色#1565c0圆点（r=4），随滑块实时移动；A′G连线蓝色实线
- 旋转轨迹：蓝色#1565c0虚线闭合曲线（圆的斜二测投影），始终可见
- 投影系统（复选框①）：红色#c62828虚线A′P + 红色圆点P，P始终落在AF上
- 截面A′GF（复选框②）：绿色#2e7d32半透明填充三角形（透明度20%）+ 绿色边界
- 三棱锥A′-FED（复选框③）：
  · 底面边DF、EF：灰色#888实线（平时隐藏）
  · 侧棱A′D、A′E、A′F：蓝色#1565c0实线
  · 三个侧面A′FD、A′FE、A′ED：绿色#2e7d32填充（透明度15%）
- 标签：A/B/C/D/E/F/G为黑色固定标签；A′为蓝色动态标签（θ=0°时与A重合，此时A′标签隐藏避免重叠）；P为红色动态标签；边长a标注在BC下方
- 配色严格沿用scene_outline声明，无新增颜色

[分步序列（关键状态）]
本场景为连续滑块交互，以下列出教学中常用的关键帧状态，教师可拖动滑块停留在任意角度：
- 状态0（θ = 0°，初始）：A′与A重合。显示基础图形（△ABC、AF、DE、G、轨迹圆）。所有复选框默认关闭。用于建立题目初始条件。
- 状态1（θ = 90°）：A′到达最高点（屏幕坐标约(400,186)），此时A′G垂直于底面，投影P与G重合。教师可开启「显示投影」观察射影落在G点（AF中点）；开启「显示截面A′GF」观察截面与底面垂直；开启「显示三棱锥」观察体积最大时的几何体。
- 状态2（θ = 180°）：A′与F重合（屏幕坐标(306,342)）。此时A′落在底面内，三棱锥退化为平面。用于观察旋转的极限位置。
- 状态3（θ = 270°）：A′到达底面下方（屏幕坐标约(400,414)）。投影P再次与G重合。用于说明旋转的连续性。
- 自由探索：教师拖动滑块到任意θ（如45°、135°等），配合三个复选框的组合开关，观察命题(1)射影始终在线段AF上、命题(3)平面A′GF与底面是否始终垂直等。

[标签冲突检查]
固定标签坐标及间距检查：
- A: (514, 248)
- B: (226, 332)
- C: (366, 362)
- D: (350, 290)
- E: (450, 290)
- F: (286, 352)
- G: (400, 285)
- a: (306, 372)
逐对最小间距：
- D与G：50px → 无冲突
- G与E：50px → 无冲突
- E与A：76px → 无冲突
- A与C：√(148²+114²)≈187px → 无冲突
- C与a：61px → 无冲突
- a与F：√(20²+20²)≈28px → 无冲突（≥20px，通过）
- F与B：63px → 无冲突
- B与D：131px → 无冲突
动态标签检查：
- A′标签位于A′左上方(-20,-10)。θ=0°时A′与A重合，A′标签坐标(474,248)，与A标签(514,248)间距40px → 无冲突；θ=0°时A′标签隐藏（因为A′≡A）。
- P标签位于P右下方(+15,+15)。θ=90°时P=G=(400,300)，P标签(415,315)，与G标签(400,285)间距33px → 无冲突。θ=180°时P=F=(306,342)，P标签(321,357)，与F标签(286,352)间距36px → 无冲突。θ=0°时P=A=(494,258)，P标签(509,273)，与A标签(514,248)间距26px → 无冲突。
结论：所有标签无重叠冲突。

[交互方案]
- 交互类型：连续拖拽/滑块 + 复选框开关
- 控件说明：
  ① 角度滑块：位于底部x=150~550,y=472，范围0°–360°，步进1°。实时驱动A′和P的坐标更新，右侧文本显示当前角度值（如"θ = 90°"）。
  ② 复选框「显示投影」：位于(80,448)。勾选后显示红色虚线A′P与红色点P（A′在底面的射影）。
  ③ 复选框「显示截面A′GF」：位于(260,448)。勾选后以绿色半透明填充三角形A′GF并描边。
  ④ 复选框「显示三棱锥」：位于(480,448)。勾选后显示灰色底边DF/EF、蓝色侧棱A′D/A′E/A′F及三个绿色半透明侧面。
- 教师操作流程：
  1. 初始状态（θ=0°）讲解题目条件：正△ABC、中位线DE、中线AF、交点G。
  2. 缓慢拖动滑块，观察A′沿轨迹圆运动，说明A′是A绕DE旋转所得。
  3. 开启「显示投影」，拖动滑块观察P始终在线段AF上，验证命题(1)。
  4. 开启「显示截面A′GF」，观察平面A′GF与底面的关系，讨论命题(3)。
  5. 开启「显示三棱锥」，在θ=90°时强调A′到平面FED距离最大，体积最大，验证命题(2)。
  6. 自由拖动到任意角度，结合三视图思维讨论命题(4)。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript（无需外部库）。理由：场景为静态几何图形+简单参数动画，SVG的path/circle/line/polygon足以表达所有图形；滑块和复选框用原生HTML控件即可，避免引入冗余依赖。
- 画布尺寸：800 × 500 px（SVG），控件栏用HTML absolute定位叠在SVG底部y=440~490区域，不额外撑高容器。
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------------+
  |                                                        |
  |     B(246,342)                                         |
  |       ●----------------● A(494,258)                    |
  |      / \    D(370,300)   \                             |
  |     /   ●-------●--------● E(430,300)                  |
  |    /     \      G(400,300)                             |
  |   /       \    /                                       |
  |  /    F(306,342)                                       |
  | ●----------● C(366,342)                                |
  |      a                                   A′(动态)      |
  |                                         /|\            |
  |                                        / | \           |
  |                                       /  |  \          |
  |                                  轨迹圆   |   投影线    |
  |                                           |            |
  |                                          P(动态)       |
  |                                                        |
  |  [显示投影]☐  [显示截面A′GF]☐  [显示三棱锥]☐            |
  |  旋转角度 [========●========================] θ=90°    |
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机：维护全局对象state = {theta: 0, showProj: false, showSection: false, showPyramid: false}。
  2. 坐标计算函数：getAprime(thetaDeg)返回{Apx, Apy}；getP(thetaDeg)返回{Px, Py}。角度转弧度后计算三角函数。
  3. 轨迹圆绘制：预计算72个采样点（步进5°），生成SVG path的d属性字符串"M x0 y0 L x1 y1 ... Z"，在初始化时写入。
  4. 动画更新：滑块input事件触发updateScene()，重新计算A′/P坐标，更新以下元素的属性：
     - scene1-point-ap: cx, cy
     - scene1-label-ap: x, y（通过transform或x/y属性）
     - scene1-line-ag: x1,y1,x2,y2
     - scene1-line-ap-proj: x1,y1,x2,y2（若开启）
     - scene1-point-p: cx, cy（若开启）
     - scene1-label-p: x, y（若开启）
     - scene1-poly-agf: points（若开启）
     - scene1-poly-pyramid-*: points（若开启）
     - scene1-line-pyramid-*: x1,y1,x2,y2（若开启）
  5. 复选框切换：change事件设置对应SVG组<g>的display属性为"none"或"block"（推荐用class切换visibility，避免重排）。
  6. 绘制顺序（SVG元素从先到后，即z-index由低到高）：
     ① 底面△ABC（填充+边线）
     ② 三棱锥底边DF、EF（若开启）
     ③ 三棱锥侧面填充（若开启）
     ④ 三棱锥侧棱（若开启）
     ⑤ 中线AF、中位线DE
     ⑥ 旋转轨迹圆
     ⑦ A′G线段
     ⑧ 平面A′GF填充与边界（若开启，后画以覆盖底面）
     ⑨ 投影线A′P、投影点P（若开启）
     ⑩ A′点
     ⑪ 所有固定点（A/B/C/D/E/F/G）
     ⑫ 所有标签
  7. 性能：滑块步进1°，input事件高频触发，使用requestAnimationFrame节流，避免DOM操作阻塞。
- ID命名规范：所有SVG元素及JS访问的DOM节点ID必须以scene1-为前缀。例如：
  - scene1-tri-abc（底面多边形）
  - scene1-line-af（中线）
  - scene1-line-de（中位线）
  - scene1-point-ap（A′点）
  - scene1-line-ag（A′G线段）
  - scene1-path-orbit（轨迹圆）
  - scene1-point-p（投影点P）
  - scene1-line-ap-proj（投影线A′P）
  - scene1-poly-agf（截面A′GF）
  - scene1-group-pyramid（三棱锥整体组）
  - scene1-slider-theta（滑块）
  - scene1-check-proj / scene1-check-section / scene1-check-pyramid（复选框）
  JS中严格使用document.getElementById('scene1-xxx')获取元素，禁止querySelectorAll配合全局class，防止多场景合并时跨场景污染。
- IIFE隔离：所有JavaScript代码包裹在 (function() { ... })() 中，全局仅暴露必要的初始化入口（若需要）。
