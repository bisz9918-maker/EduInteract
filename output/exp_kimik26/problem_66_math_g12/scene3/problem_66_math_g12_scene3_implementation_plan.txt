[图示主题与整合说明]
- 本图示主题：异面直线 A'E 与 BD 的垂直关系分析（命题 4 的判断）
- 整合的步骤/概念：
  1) 建立 3D 空间模型，识别异面直线 A'E 与 BD；
  2) 平移法——将 BD 平移至过 E 点得直线 l，把异面直线夹角转化为相交直线夹角 α；
  3) 观察 A' 旋转过程中夹角 α 的变化（以体积最大位置为例，说明 α ≠ 90°）；
  4) 通过空间向量计算确定当 cosθ = 1/3 时 A'E ⊥ BD，从而判定命题 (4) 错误。
- 教学价值：教师可通过分步导航，逐层展示"平移—相交—测角—定垂直"的完整逻辑链，帮助学生理解异面直线垂直判定的两种方法（平移法与向量法），并纠正"异面直线不可能垂直"的直觉误区。

[分步序列]
- 步骤 0（初始状态）：
  显示底面△ABC（填充+边框）、点 A/B/C/D/E/F/G、A' 在初始旋转角位置（θ≈60°，坐标 340,169）。
  显示线段 AB、AC、BC、AF（灰虚）、DE（灰虚）、A'D（灰虚）、A'E（蓝实 3px）、BD（红实 3px）。
  隐藏 l、α 弧线、α 标签、垂直符号、A'G。
  步骤说明："异面直线 A'E（蓝）与 BD（红）的夹角如何度量？"

- 步骤 1（平移法）：
  点击「下一步」后：
  · BD 线宽降为 1px，颜色退为 #000000（或保持 #c62828 但降低不透明度至 0.4），表示"原位置"；
  · 新增平移线 l（#2e7d32 虚线），从 E(480,300) 经过 F(520,369) 延伸至 (560,438)，表示 BD 平移至过 E 点；
  · 新增夹角 α 弧线（圆心 E，半径 28px，#1565c0），位于 EA' 与 EF 之间；
  · 新增 α 标签于 (450,260)；
  · 新增线 l 标签于 (570,445)；
  · E 点高亮（#2e7d32 描边）。
  步骤说明："平移 BD 至过点 E 的直线 l，则 ∠(A'E, l) = α 即为异面直线夹角。"

- 步骤 2（角度变化与体积最大位置）：
  点击「下一步」后：
  · A' 从 (340,169) 动画移动到体积最大位置 (400,189)（θ=90°，即 A'G ⊥ AF 的位置），耗时 600ms，ease-in-out；
  · 同步更新 A'E、A'D、A'G 的端点；
  · α 弧线与标签随动至新位置（约 (470,270)）；
  · 在 A'G 与 AF 交点 G 处添加直角小符号（#2e7d32），表示 A'G ⊥ AF；
  · 在画面右侧添加文字 "α ≈ 8.5° ≠ 90°"（坐标约 600,250）。
  步骤说明："即使 A' 运动到体积最大位置（A'G⊥AF），夹角 α 仍不等于 90°，但 α 随旋转而变化。"

- 步骤 3（垂直位置的确定）：
  点击「下一步」后：
  · A' 从 (400,189) 动画移动到 (360,172)（cosθ = 1/3 的位置），耗时 600ms，ease-in-out；
  · 同步更新 A'E、A'D、A'G；
  · 移除 G 处直角符号（或保留以强调 A'G⊥AF 始终成立）；
  · 在 E 点处添加垂直符号（直角折线，#2e7d32），表示 A'E ⊥ l（即 A'E ⊥ BD）；
  · α 标签改为 "90°" 或隐藏 α 弧线改为垂直符号；
  · 在画面右侧添加文字 "cosθ = 1/3 时，A'E ⊥ BD"（坐标约 600,250）。
  步骤说明："当 cosθ = 1/3 时，A'E 与 BD 在空间中正交。故命题 (4) 错误。"

- 控件说明：
  · 「◀ 上一步」按钮：位于 (250,447)-(350,483)，点击回退到上一状态，步骤 0 时禁用；
  · 「下一步 ▶」按钮：位于 (450,447)-(550,483)，点击前进到下一状态，步骤 3 时禁用；

- 教师操作流程：
  1) 教师展示步骤 0，说明题目中的异面直线对 A'E 与 BD；
  2) 点击「下一步」进入步骤 1，讲解平移法——将 BD 平移到 l，把异面问题转化为共面夹角问题；
  3) 点击「下一步」进入步骤 2，A' 自动动画到体积最大位置，教师强调此时 α 仍不是直角，但角度在变化；
  4) 点击「下一步」进入步骤 3，A' 自动动画到垂直位置，教师指出通过向量计算可得 cosθ=1/3 时两线垂直，从而命题 (4) 不成立；
  5) 可随时点击「上一步」回退复习关键帧。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无需 D3/Three.js）。理由：场景为固定视角的 3D 投影图，所有顶点坐标已预计算，用 SVG 的 line/circle/path/text 即可精确绘制；状态切换仅需控制 visibility 和端点坐标，原生 JS 足够轻量。
- 画布尺寸：800 × 500 px（SVG viewBox="0 0 800 500"）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |                                                  |
  |     A'（上方）                                    |
  |       \                                          |
  |        \  A'E (蓝)                               |
  |         \                                        |
  |    A ----D----E--------C                         |
  |     \    |    |       /                          |
  |      \   |    |      /                           |
  |       \  |    l(绿) /                            |
  |        \ |    |    /                             |
  |         F----+----                               |
  |          \   |                                   |
  |           \  | BD (红)                           |
  |            \ |                                   |
  |             B                                    |
  |                                                  |
  |  [步骤说明文字居中显示于 y≈420]                   |
  |                                                  |
  |  [◀ 上一步]  步骤 X/4  [下一步 ▶]                |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1) 状态机设计：定义 state = 0/1/2/3，每步对应一个配置对象 { aPrime: [x,y], showL: bool, showAlpha: bool, showVert: bool, caption: string }，切换时根据状态对象更新 SVG 元素属性。
  2) 坐标计算：A' 的三个位置已预计算（步骤0: 340,169；步骤2: 400,189；步骤3: 360,172）。A'E/A'D/A'G 的端点随 A' 动态更新。
  3) 动画曲线：A' 移动使用 ease-in-out（cubic-bezier(0.4, 0, 0.2, 1)），通过 requestAnimationFrame 在 600ms 内插值端点坐标；同时更新依赖 A' 的线段端点。
  4) 事件绑定：上一步/下一步按钮绑定 click 事件，调用 setState(newState) 函数；setState 内先停止当前动画，再启动新状态的过渡。
  5) 垂直符号绘制：步骤 3 在 E(480,300) 处绘制直角折线。具体：取 EA' 单位向量 u = (-0.683,-0.729)，EF 单位向量 v = (0.501,0.865)，则 P1 = E + 12*u，P2 = E + 12*v，P3 = P1 + 12*v（或 P2 + 12*u），绘制 path "M P1 L P3 L P2"。
  6) 夹角弧线绘制：使用 SVG path 的 arc 命令，起点为 E + 28*normalize(EA')，终点为 E + 28*normalize(EF)，大弧标志 0， sweep 标志根据方向确定。
- ID 命名规范：所有 SVG 元素及控件 ID 必须以 `scene3-` 为前缀，例如 `scene3-point-A`、`scene3-line-AE`、`scene3-btn-next`、`scene3-caption`。JS 中严格使用 `document.getElementById` 获取元素，禁止全局 class 选择，避免多场景合并时污染。
- IIFE 隔离：所有 JavaScript 代码包裹在 `(function() { ... })();` 中，内部状态变量（currentStep、animationId 等）不泄露到全局作用域。
