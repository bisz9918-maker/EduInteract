[图示主题与整合说明]
- 本图示主题：椭圆基本构图与动点 P 的动态几何关系

[分步序列]
本场景为单一连续拖拽状态，无多步切换。以下描述初始状态与拖拽过程中的视觉变化：

- 初始状态（加载完成）：
  - 显示椭圆 Γ、x轴、y轴、切线 l
  - 显示静态点 A、B、F、O 及其标签
  - P 位于第一象限约 30° 参数角位置（画布坐标约(582,195)）
  - 自动计算并显示 D（AP 与 l 交点，约(610,190)）和 M（BD 中点，约(610,225)）
  - 显示线段 AP、BD、FM、PM、PB、FD
  - 显示所有动态标签 P、D、M
  - 底部控件区显示操作提示

- 拖拽交互过程（教师按住 P 拖动）：
  - P 被约束在椭圆 Γ 上运动（参数角 θ 建议限制在 [20°, 160°] 以保证 D、M 主要在可视区内；若超出，允许 D 部分超出画布顶部/底部，几何计算仍保持正确）
  - 实时更新：
    1. P 坐标随鼠标投影到椭圆边界
    2. 直线 AP 重新绘制（从 A 经过新 P 到与 l 的交点 D）
    3. D 位置更新（AP ∩ l）
    4. M 位置更新（BD 中点）
    5. 线段 BD、FM、PM、PB、FD 全部重绘
    6. 动态标签 P、D、M 跟随各自点移动（保持固定偏移方向）
  - 教师可观察：P 移动时 FM、PM、PB 的相对长度变化；∠PFB 与 ∠PFM 的关系；PM 与椭圆的位置关系（是否相切）；PM 与 ∠FPD 的关系等

- 重置操作：
  - 点击「重置」按钮，P 平滑动画回到初始位置(582,195)，所有衍生元素同步动画复位

[交互方案]
- 交互类型：连续拖拽（点 P 在椭圆上拖动）+ 重置按钮
- 控件说明：
  1. 提示文字：位于底部控件区中央，说明操作方式
  2. 重置按钮：位于底部控件区右下角，将 P 复位到初始 30° 位置
- 教师操作流程：
  1. 教师向学生展示初始构图，说明 A、B、F、l 的固定关系
  2. 教师拖动红色点 P，让学生观察 D（AP 与切线交点）和 M（BD 中点）的实时生成
  3. 教师引导学生关注蓝色高亮线段 FM、PM，观察它们与焦点 F 的关系
  4. 教师将 P 拖到不同位置（第一象限上部、下部，或第二象限），让学生猜测/验证四个结论
  5. 点击「重置」快速回到初始位置，便于重复演示

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无额外库）。理由：本场景为 2D 几何图形，元素类型简单（ellipse、line、circle、text），原生 SVG 足以高效渲染，无需引入 D3 等重型库。
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  +--------------------------------------------------+
  |  Γ: x²/a² + y²/b² = 1                            |  y=40~80
  |                                                  |
  |         P                                        |  y=80~200
  |        /                                         |
  |       /    D                                     |
  |      /     |                                     |
  |     /      M                                     |  y=200~260
  |    /       |                                     |
  |   A---O--F-B-- l                                 |  y=260
  |                                                  |  y=260~440
  |                                                  |
  +--------------------------------------------------+
  |      [拖动点 P 观察 D、M 的生成与线段关系]  [重置]|  y=450~490
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 坐标映射：椭圆中心(400,260)，像素半长轴 a=210，半短轴 b=130，焦距 c=165（由 c²=a²-b² 得）。数学坐标(x',y')与画布坐标转换：x=400+x', y=260-y'。
  2. 拖拽约束：监听 P 点的 mousedown → 进入拖拽状态；mousemove 时计算鼠标位置相对于椭圆中心的参数角 θ = atan2((260-my), (mx-400))，其中(mx,my)为鼠标坐标；将 P 约束到椭圆上：P=(400+210·cosθ, 260-130·sinθ)。建议限制 θ∈[0.35, 2.79] 弧度（约20°~160°）以避免 D 过度跑出画布。
  3. D 点计算：直线 AP 与竖直线 x=610 的交点。已知 A(190,260)、P(px,py)，参数方程求交：t=(610-190)/(px-190)，D_y=260+t·(py-260)。
  4. M 点计算：M=((610+610)/2, (260+D_y)/2)=(610, (260+D_y)/2)。
  5. 动态更新：拖拽过程中使用 requestAnimationFrame 或直接设置 SVG 属性（setAttribute）更新 P、D、M 的 cx/cy，以及各线段的 x1/y1/x2/y2，和动态标签的 x/y 坐标。
  6. 重置动画：使用 requestAnimationFrame + ease-out 曲线，在约 300ms 内将 P 从当前位置插值回初始 θ=30° 位置，中间帧同步计算 D、M 并更新。
  7. 事件绑定：拖拽事件绑定在 P 点 circle 元素上；同时给 SVG 容器绑定 mousemove/mouseup 以处理鼠标移出 P 点的情况。
- ID 命名规范：所有 SVG 元素及控件 ID 必须以 `scene1-` 为前缀。例如：
  - `scene1-ellipse-gamma`
  - `scene1-axis-x`
  - `scene1-axis-y`
  - `scene1-line-l`
  - `scene1-point-a`
  - `scene1-point-b`
  - `scene1-point-f`
  - `scene1-point-o`
  - `scene1-point-p`
  - `scene1-point-d`
  - `scene1-point-m`
  - `scene1-line-ap`
  - `scene1-segment-bd`
  - `scene1-segment-fm`
  - `scene1-segment-pm`
  - `scene1-segment-pb`
  - `scene1-segment-fd`
  - `scene1-label-a`
  - `scene1-label-b`
  - `scene1-label-f`
  - `scene1-label-o`
  - `scene1-label-p`
  - `scene1-label-d`
  - `scene1-label-m`
  - `scene1-label-l`
  - `scene1-label-x-eq-a`
