[分步序列]
- 初始状态（步骤0）：显示完整三棱柱立体图。所有可见棱为黑色实线（AA₁, BB₁, CC₁, AB, BC, A₁B₁, B₁C₁），被遮挡棱 AC 与 A₁C₁ 为灰色虚线。六个顶点字母标签显示。无数值标注、无直角符号、无底面高亮、无放大图。
- 步骤1：点击「下一步」→ 侧棱 AA₁ 右侧淡入标注 "AA₁ = 8"（红色）；在 A₁ 顶点处（A₁B₁ 与 AA₁ 夹角内侧）淡入绿色直角符号，表示 AA₁ ⊥ 底面 A₁B₁C₁；AA₁ 棱可轻微加粗或颜色变为 #1565c0 以强调。
- 步骤2：点击「下一步」→ 下底面 △A₁B₁C₁ 整体高亮：填充蓝色半透明多边形，边框加粗为蓝色实线；A₁C₁ 虚线颜色由灰色变为蓝色虚线，表示虽被遮挡但属于高亮底面；A₁B₁ 下方淡入 "A₁B₁ = 6"（红色）；B₁ 顶点处淡入绿色直角符号，表示 A₁B₁ ⊥ B₁C₁；A₁C₁ 外侧淡入 "A₁C₁ = 2√34"（红色）。
- 步骤3：点击「下一步」→ 在画布右侧（x≈480~750, y≈100~400 区域）淡入放大示意图 △A₁B₁C₁，三边均为蓝色实线；放大图顶点标注 A₁, B₁, C₁；三边外侧分别标注 "A₁B₁ = 6"、"B₁C₁ = 10"（红色，结果高亮）、"A₁C₁ = 2√34"；B₁' 处显示绿色直角符号；在放大图左下方淡入推导公式 "B₁C₁ = √((2√34)² − 6²) = 10"。主图保持步骤2的高亮状态，与放大图形成对照。
- 教师可随时点击「上一步」回退，所有元素以 opacity transition 0.3s 淡入淡出。

[交互方案]
- 交互类型：分步按钮导航（◀ 上一步 / 下一步 ▶）
- 控件说明：
  1. 「上一步」按钮：位于画布底部居中偏左 (300, 455)，宽 80px，高 32px。点击后步骤减 1（最小为 0），隐藏当前步骤新增的元素。
  2. 「下一步」按钮：位于画布底部居中偏右 (420, 455)，宽 80px，高 32px。点击后步骤加 1（最大为 3），显示下一步对应的元素。
  3. 步骤指示器：位于两按钮上方居中 (400, 448)，显示 "步骤 1/4"、"步骤 2/4" 等文字，字体 12px #666666。
- 教师操作流程：
  1. 教师展示步骤0，让学生识别几何体为三棱柱，确认六个顶点位置。
  2. 点击「下一步」进入步骤1，讲解侧棱 AA₁ 垂直于底面的条件，强调 "AA₁ = 8" 是已知高。
  3. 点击「下一步」进入步骤2，高亮底面三角形，引导学生发现底面是直角三角形，已知直角边 A₁B₁=6 和斜边 A₁C₁=2√34。
  4. 点击「下一步」进入步骤3，右侧出现放大图，教师带领学生运用勾股定理计算 B₁C₁=10，完成本场景教学目标。
  5. 可随时回退复习某一步骤。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript。理由：本场景为静态几何图形与分步显隐，无需复杂数学函数绘图或 3D 渲染，原生 SVG 足以保证清晰度与性能。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------------+
  |  C(210,35)                                             |
  |   |＼                                                   |
  |   |  ＼ A(380,205)              [放大图区域 步骤3]       |
  |   |    ＼                      C₁'(493,130)             |
  |   C₁(210,200)＼                   /＼                   |
  |   |            ＼             A₁'(710,340)/ ＼B₁'(560,380)|
  |   |              ＼                 /        ＼  /      |
  |   |                ＼             /            ＼/      |
  |   B(260,235)--------A₁(380,370)                       |
  |   |               /                                    |
  |   B₁(260,400)---A₁C₁(虚线)                             |
  |                                                        |
  |   推导公式(480,415)  [步骤3显示]                        |
  |                                                        |
  |        [◀ 上一步]  步骤 X/4  [下一步 ▶]                 |
  +--------------------------------------------------------+
  画布 800×500，控件栏 y=440~490
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `let currentStep = 0;` 记录当前步骤（0~3）。按钮点击时更新 currentStep，调用 `renderStep()` 函数根据步骤显示/隐藏元素。
  2. 元素显隐控制：所有步骤相关元素初始设置 `opacity: 0` 或 `visibility: hidden`。`renderStep()` 中通过 `element.style.opacity = '1'` 或添加/移除 CSS class `.scene1-hidden` 控制。使用 CSS transition: opacity 0.3s ease 实现平滑淡入淡出。
  3. 坐标计算：三棱柱采用自定义平行投影（非严格轴测），底面 △A₁B₁C₁ 坐标经过精确计算确保 A₁B₁ ⊥ B₁C₁（向量点积为0），且边长比例 |B₁C₁|:|A₁B₁|:|A₁C₁| = 10:6:2√34，保证图形与题意数学一致。
  4. 直角符号绘制：使用 SVG `<path>` 绘制两条垂直短线段。A₁ 处直角符号沿 AA₁（竖直向下）和 A₁B₁（左下）方向各延伸 12px，再连接形成直角；B₁ 处沿 B₁A₁（右上）和 B₁C₁（左上）方向各延伸 12px。
  5. 被遮挡棱处理：AC 与 A₁C₁ 使用 `stroke="#888888" stroke-dasharray="5,3"`。步骤2高亮底面时，A₁C₁ 颜色变为 `stroke="#1565c0"` 但仍保持虚线样式，表示其几何位置仍在后侧。
  6. 放大图定位：放大图与主图底面保持相似形，顶点坐标 B₁'(560,380), A₁'(710,340), C₁'(493,130)，通过向量缩放计算确保角度与边长比例一致。
  7. 按钮边界处理：上一步按钮在 step=0 时禁用（opacity 0.4, pointer-events none），下一步按钮在 step=3 时禁用。
- **ID 命名规范**：所有 SVG 元素及控件 ID 必须以 `scene1-` 为前缀。例如：`scene1-edge-aa1`, `scene1-label-a1b1`, `scene1-rightangle-b1`, `scene1-magnified-base`, `scene1-btn-prev`, `scene1-step-text`。JavaScript 中严格使用 `document.getElementById('scene1-xxx')` 获取元素，禁止全局 class 选择器，避免多场景合并时跨场景污染。
- IIFE 隔离：所有 JavaScript 代码包裹在 `(function() { ... })();` 立即执行函数中，内部变量与函数不污染全局作用域。事件监听器在 IIFE 内部绑定。
