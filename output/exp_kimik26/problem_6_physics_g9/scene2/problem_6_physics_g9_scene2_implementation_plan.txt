[图示主题与整合说明]
- 本图示主题：滑片右移引起的电路-磁学-力学连锁变化
- 整合的步骤/概念：局部电阻变化→总电阻变化→电路电流变化→电磁铁磁性变化→铁球电磁吸引力变化→弹簧测力计示数变化；同步整合四个选项的正误排除过程
- 教学价值：教师通过分步导航逐步推进，学生可直观追踪"R变→I变→磁性变→受力变→示数变"的完整因果链，每一步同步看到对应选项被排除或确认，强化多步骤推理能力

[分步序列]
- 步骤0（初始状态，步骤指示"1 / 5"）：
  · 显示完整装置，滑片位于x=150（偏左）
  · 电流表指针旋转+15°（对应0.4A），表盘下方或内部显示"0.4A"
  · 弹簧测力计指针位于y=90（对应2.5N）
  · 电磁铁周围3条绿色虚线磁场线完整显示，铁芯带轻微黄色光晕
  · 四个选项卡片均为灰色背景，无正误标记
  · 所有步骤标注（R变↑、R总↑、I↓、磁性减弱、受力分析图）均隐藏

- 步骤1（电阻变化，步骤指示"2 / 5"）：
  · 滑片从x=150动画平移至x=190（duration 500ms，ease-out）
  · 滑动变阻器接入段（滑片到右端）高亮：填充rgba(198,40,40,0.15)，边框#c62828线宽3px；高亮区域随滑片右移同步收缩左边界
  · 显示标注"R变↑"在滑动变阻器下方(180,295)
  · 显示标注"R总↑"在电路上方(260,105)
  · 选项A卡片变红（背景#ffcdd2，边框#c62828），内部右侧显示红色圆圈白叉"✗"
  · 其余选项保持灰色

- 步骤2（电流变化，步骤指示"3 / 5"）：
  · 电流表指针从+15°旋转至-15°（duration 400ms，ease-in-out），读数从"0.4A"变为"0.2A"
  · 显示标注"I↓"在电流表左侧(70,165)
  · 选项D卡片变红（背景#ffcdd2，边框#c62828），内部右侧显示红色圆圈白叉"✗"
  · 其余选项保持步骤1状态（A仍红，B/C灰）

- 步骤3（磁性变化，步骤指示"4 / 5"）：
  · 外侧两条磁场线（r=65, r=85）opacity从1渐变至0.2，颜色从#2e7d32变为#888888（duration 400ms）
  · 内侧磁场线（r=45）保持绿色但变淡（opacity 0.5）
  · 铁芯黄色光晕opacity从0.3降至0.08
  · 显示标注"磁性减弱"在电磁铁右侧(465,255)
  · 选项C卡片变红（背景#ffcdd2，边框#c62828），内部右侧显示红色圆圈白叉"✗"
  · 其余选项保持步骤2状态（A/D仍红，B灰）

- 步骤4（受力分析与结论，步骤指示"5 / 5"）：
  · 受力分析图组整体淡入：opacity 0→1，translateY(10px)→0（duration 400ms）
  · 铁球从(420,170)上移至(420,160)（duration 400ms），挂钩细线缩短，阴影同步上移缩小
  · 弹簧测力计指针从y=90上移至y=80（duration 400ms），示数减小
  · 显示平衡方程"F拉=G+F吸"在受力分析图下方(600,310)
  · 选项B卡片变绿（背景#c8e6c9，边框#2e7d32），内部右侧显示绿色圆圈白勾"✓"
  · 其余选项保持步骤3状态（A/C/D仍红）

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「上一步」按钮：位置(300,452)，宽80×高30，点击回退到上一状态，步骤0时禁用（opacity 0.4，cursor not-allowed）
  2. 「下一步」按钮：位置(420,452)，宽80×高30，点击推进到下一状态，步骤4时禁用
  3. 步骤指示文本：位置(380,472)，显示"步骤 X / 5"，14px灰色文字
- 教师操作流程：
  1. 教师展示步骤0，讲解题目初始条件（滑片右移的指令）
  2. 点击「下一步」进入步骤1，讲解滑动变阻器接入电阻变大的原理，观察选项A被标红排除
  3. 点击「下一步」进入步骤2，根据欧姆定律讲解电流减小，观察选项D被标红排除
  4. 点击「下一步」进入步骤3，讲解电流减小导致磁性减弱，观察选项C被标红排除
  5. 点击「下一步」进入步骤4，对铁球进行受力分析，讲解F吸减小→F拉减小→示数变小，观察选项B被标绿确认
  6. 可随时点击「上一步」回退复习任一步骤的因果逻辑

[技术实现]
- JS库选择：原生 SVG + 原生 JavaScript（无外部库）。理由：本场景以几何图形、状态切换和简单属性动画为主，无需复杂数学计算或数据绑定，原生SVG性能最优且零依赖。
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  y=40   ┌─────────────────────────────────────────────────────┐
         │  ┌──┐                                               │
  y=80   │  │A │←电流表                                         │
         │  └──┘                                               │
  y=120  │    │    ┌────┐                                      │
         │    └────│ R定│                                      │
  y=160  │         └────┘                                      │
         │           │         ┌──┐                            │
  y=200  │           └─────────│铁│←电磁铁                     │
         │                     │芯│                            │
  y=240  │    ┌────┐           │  │                            │
         │    │滑变│←──────────┘  │                            │
  y=280  │    └──┬─┘              │                            │
         │       │    开关  电源   │                            │
  y=320  │       └────────────────┘                            │
         │                              ┌─────────┐            │
  y=360  ├──────────────────────────────┤受力分析图│────────────┤
         │ [A卡片] [B卡片] [C卡片] [D卡片]  (步骤4出现)         │
  y=410  ├─────────────────────────────────────────────────────┤
         │           ◀上一步    下一步▶   步骤 X/5              │
  y=490  └─────────────────────────────────────────────────────┘
         x=0                                               x=800
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `currentStep`（0~4），每次点击按钮时更新状态并调用 `renderStep()` 函数，该函数根据当前步骤添加/移除元素的 CSS class 或直接修改 SVG 属性。
  2. 滑片动画：使用 CSS `transition: transform 0.5s ease-out` 对滑片组（`<g>`）应用 `translateX(40px)`（从150到190）。高亮区使用另一 `<rect>`，通过 JS 动态更新 `x` 和 `width` 属性实现同步收缩。
  3. 电流表指针：使用 SVG `transform="rotate(angle, 100, 160)"`，通过 JS 在步骤2时更新 angle 从15到-15。使用 CSS `transition: transform 0.4s ease-in-out` 实现平滑旋转。
  4. 磁场线消失：给外侧两条磁场线 `<path>` 添加 CSS class `.fade-field`，设置 `transition: opacity 0.4s, stroke 0.4s`，步骤3时切换 class 改变 opacity 和 stroke 颜色。
  5. 受力分析图出现：使用 CSS class `.force-hidden`（opacity:0, transform:translateY(10px)）和 `.force-visible`（opacity:1, transform:translateY(0)），过渡时间0.4s。
  6. 选项卡片：使用 HTML `<div>` 元素，position:absolute 定位在 SVG 容器上方。通过切换 class `.option-wrong`（红底）和 `.option-correct`（绿底）实现正误标记，内部用 `<span>` 显示✗或✓。
  7. 铁球与指针联动：步骤4时，铁球 `<circle>` 的 `cy` 从170变为160（CSS transition），测力计指针 `<line>` 的 `y1/y2` 从90变为80，挂钩细线 `<line>` 的 `y2` 从155变为145，三者同步动画。
  8. 按钮禁用逻辑：步骤0时给「上一步」添加 `disabled` class；步骤4时给「下一步」添加 `disabled` class。
- ID命名规范：所有交互元素 ID 必须以 `scene2-` 为前缀。例如：
