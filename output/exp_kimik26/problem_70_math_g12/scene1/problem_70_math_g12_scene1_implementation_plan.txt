[图示主题与整合说明]
- 本图示主题：四棱锥 P-ABCD 中探究平面 MBD⊥平面 PCD 的充要条件
- 整合的步骤/概念：题目条件展示 → 菱形对角线垂直 → 线面垂直（BD⊥平面PAC）→ 线线垂直（BD⊥PC）→ 目标平面分析 → 补充条件（BM⊥PC）→ 面面垂直结论
- 教学价值：教师通过分步导航精确控制推导节奏，每步只呈现当前逻辑层级的几何关系，帮助学生建立"线线→线面→面面"的空间垂直转化链条，避免一次性呈现全部辅助线导致的信息过载

[分步序列]
- 步骤0（初始状态）：
  - 显示四棱锥全部棱线（实线/虚线区分可见性）
  - 显示顶点标签 P、A、B、C、D、M（M 在 PC 的 (500,233) 处）
  - 显示 PA⊥底面直角标记（A 点处）
  - 显示底面标注"菱形ABCD（各边相等）"
  - 显示线段 BM（实线）和 MD（虚线）
  - 步骤说明："已知：PA⊥底面ABCD，底面为菱形，M是PC上的动点"

- 步骤1（菱形对角线性质）：
  - 新增：辅助线 AC（虚线 #888），交点 O（圆点）
  - 高亮：AC 和 BD 改为蓝色 2.5px 实线（暂时覆盖虚线样式以突出）
  - 新增标签：O（445,365）、AC⊥BD（460,325，蓝色）
  - 新增：O 点处直角标记
  - 步骤说明："菱形性质：对角线 AC⊥BD，交于点 O"

- 步骤2（线面垂直）：
  - 高亮：PA（蓝色 2.5px）、BD（蓝色 2.5px）
  - 新增：平面PAC 蓝色半透明填充
  - 新增标签：平面PAC（300,220，蓝色）、BD⊥平面PAC（660,150，蓝色）
  - 步骤说明："PA⊥BD 且 AC⊥BD → BD⊥平面PAC"

- 步骤3（线线垂直推导）：
  - 高亮：BD（红色 2.5px）、PC（红色 2.5px）
  - 新增标签：BD⊥PC（540,220，红色）
  - 步骤说明："由 BD⊥平面PAC，且 PC⊂平面PAC，得 BD⊥PC"

- 步骤4（目标平面分析）：
  - 新增：平面MBD 红色半透明填充、平面PCD 蓝色半透明填充
  - 高亮：交线 MD（红色 2.5px）
  - 新增标签：平面MBD（450,310，红色）、平面PCD（400,240，蓝色）
  - 步骤说明："分析平面MBD 与平面PCD，交线为 MD，探究面面垂直条件"

- 步骤5（补充垂直条件）：
  - M 点从 (500,233) 移动到垂足位置 (581,272)，动画时长 500ms，ease-in-out
  - 同步更新：BM 线段终点、MD 线段起点、平面MBD 多边形顶点
  - 高亮：BM（红色 2.5px）、PC（红色 2.5px）
  - 新增：M 点处 BM⊥PC 直角标记
  - 新增标签：PC⊥平面MBD（660,200，红色）
  - 步骤说明："补充条件 BM⊥PC，结合 BD⊥PC，得 PC⊥平面MBD"

- 步骤6（面面垂直结论）：
  - 强化显示：平面MBD 和平面PCD 的填充透明度提升至 30%，边框加粗至 2px
  - 新增标签：结论（400,60，绿色）"平面MBD⊥平面PCD"
  - 新增补充说明标签（400,80，13px #666）："条件：BM⊥PC（或 DM⊥PC、OM⊥PC 等，答案不唯一）"
  - 步骤说明："PC⊥平面MBD 且 PC⊂平面PCD → 平面MBD⊥平面PCD"

逐对检查（仅列出间距 < 80px 的组合）：
- O(445,365) 与 平面MBD(450,310)：间距 55px → 不冲突，O 在上方偏右，平面MBD 在下方
- 平面MBD(450,310) 与 平面PCD(400,240)：间距 78px → 不冲突，分别位于不同三角形内部
- M_default(515,223) 与 BD⊥PC(540,220)：间距 25px → 存在冲突风险。解决方案：将 BD⊥PC 调整为 (560, 210)，与 M_default 间距 √(45²+13²)≈47px，与 C(655,290) 间距 √(95²+80²)≈124px，通过
- M_final(596,262) 与 C(655,290)：间距 65px → 不冲突，M 在 PC 上靠近 C，标签分别位于 M 右上和 C 右上，实际显示时 M_final 与 C 不会同时与各自标签造成重叠（M 标签在 M 点右上方 15px，C 标签在 C 点右上方 15px，两点本身间距 65px，标签间距约 35px，可接受）
- BD⊥平面PAC(660,150) 与 PC⊥平面MBD(660,200)：间距 50px → 不冲突，同 x 坐标，y 差 50px，文字不会重叠
- 平面PAC(300,220) 与 D(320,290)：间距 73px → 不冲突
- 结论(400,60) 与 P(200,90)：间距 202px → 不冲突

所有标签间距均 ≥ 35px（调整后），无重叠风险。

[交互方案]

- 控件说明：
  - 「◀ 上一步」按钮：位于 (300, 470)，80×30px，点击回退到上一推导步骤
  - 「下一步 ▶」按钮：位于 (420, 470)，80×30px，点击前进到下一推导步骤
  - 步骤说明文字：位于 (400, 455)，14px，居中显示当前步骤的推导提示
- 教师操作流程：
  1. 教师打开图示，步骤0展示题目基础条件，向学生说明已知 PA⊥底面、底面为菱形
  2. 点击「下一步」进入步骤1，引导学生回忆菱形对角线垂直性质
  3. 继续点击「下一步」，逐步呈现 BD⊥平面PAC、BD⊥PC 的推导
  4. 到步骤4时，提示学生观察平面MBD 与平面PCD 的位置关系
  5. 步骤5中 M 自动移动到垂足位置，教师强调"补充 BM⊥PC"这一关键条件
  6. 步骤6呈现最终结论，教师说明答案不唯一（DM⊥PC 等亦可）
  7. 可随时点击「上一步」回退复习任意推导环节

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无外部库）。理由：本场景为简单立体几何图形与分步状态切换，无需复杂数学计算或 3D 渲染，原生 SVG 足以高效绘制所有棱线、多边形填充和标签，且无需引入额外依赖。
- 画布尺寸：800 × 500 px（SVG 容器），控件栏位于 SVG 内部 y=440~490 区域
- 布局草图（ASCII）：
  ```
  [主图区 800×440]
  +--------------------------------------------------+
  |  结论文字(400,60)                                 |
  |       P(220,100)                                  |
  |       |\                                          |
  |       | \                                         |
  |       |  \                                        |
  |       |   \ C(640,300)                            |
  |       |    *---------------------------------*    |
  |       |   / D(340,300)   M(500,233)           |   |
  |       |  /              *                     |   |
  |       | /              / \                    |   |
  |       |/              /   \                   |   |
  |       A(220,400)-----*-----B(520,400)         |   |
  |            菱形ABCD（各边相等）                |   |
  |                                                   |
  +--------------------------------------------------+
  [控件区 800×60, y=440~500]
  +--------------------------------------------------+
  |        步骤说明文字 (400,455)                      |
  |    [◀ 上一步]        [下一步 ▶]                   |
  |     (300,470)         (420,470)                   |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：定义 `currentStep`（0~6），每步维护两个列表：`showIds`（该步应显示的元素ID集合）和 `highlightIds`（该步应高亮的元素ID集合）。`render()` 函数遍历所有元素，根据当前步骤设置 `display` 或 `visibility` 属性，以及 `stroke-width` / `stroke` / `fill-opacity` 样式。
  2. M 点移动动画：步骤5中 M 从 (500,233) 移动到 (581,272)。使用 `requestAnimationFrame` 在 500ms 内插值更新：M 圆点的 cx/cy、BM 线段的 x2/y2、MD 线段的 x1/y1、平面MBD 多边形的 points 属性。动画曲线使用 ease-in-out：`t < 0.5 ? 2*t*t : -1+(4-2*t)*t`。
  3. 平面填充层级：SVG 中先绘制平面填充多边形（确保在底层），再绘制棱线（在上层），避免填充遮挡线条。
  4. 虚线高亮处理：步骤1高亮 AC 和 BD 时，将虚线临时改为蓝色实线（2.5px）以增强视觉冲击力，回退时恢复虚线样式。
  5. 事件绑定：上一步/下一步按钮绑定 `click` 事件，更新 `currentStep` 后调用 `render()`。按钮在边界状态（步骤0 或 步骤6）时禁用并置灰。
- ID 命名规范：所有 SVG 元素和控件 ID 必须以 `scene1-` 为前缀。例如：`scene1-vertex-P`、`scene1-edge-PA`、`scene1-edge-AC`、`scene1-plane-PAC`、`scene1-plane-MBD`、`scene1-label-P`、`scene1-label-AC-BD`、`scene1-rightangle-A`、`scene1-btn-prev`、`scene1-btn-next`、`scene1-step-desc`。
- IIFE 隔离：所有 JavaScript 代码包裹在 `(function() { ... })()` 中，避免全局变量污染，确保多场景合并时互不干扰。
- 响应式说明：本图示为固定 800×500 画布，容器使用 `position: relative` 包裹 SVG，控件按钮使用 `position: absolute` 定位在 SVG 上方（基于 SVG 坐标系），不额外撑高容器。
