[图示主题与整合说明]
- 本图示主题：正六边形内接圆中动点 P 与各顶点向量夹角的动态探索

[交互状态序列]
本场景为连续拖拽交互，无分步导航。以下描述关键状态与教师操作流程：

- 初始状态（加载完成）：
  - 显示圆、正六边形、圆心O、六条半径OAᵢ、六个顶点Aᵢ（黑色）
  - 动点P初始位于A₁位置（φ=0°），OP与OA₁重合
  - 右侧面板显示六个θᵢ初始值：θ₁=0°, θ₂=60°, θ₃=120°, θ₄=180°, θ₅=120°, θ₆=60°
  - 排序后数列显示：0°, 60°, 60°, 120°, 120°, 180°
  - 夹角弧线默认显示（showArcs=true），θ₁处弧线退化为点（夹角0°不绘制弧线）
  - 等差数列提示隐藏

- 教师拖拽点P：
  - 鼠标按下P点→进入拖拽模式，mousemove时计算鼠标相对圆心角度φ，将P锁定在圆周上
  - OP实时更新方向，六条夹角弧线实时更新（若开启显示）
  - 右侧面板六个θᵢ数值实时刷新（保留1位小数）
  - 排序后数列实时刷新
  - 当φ接近15°+k·30°（容差|mod30−15|<2°）时，排序数列框边框变红，第3项背景淡红，显示"✓ 构成等差数列"提示
  - 教师可引导学生观察：当P从0°向30°移动时，排序数列如何变化，何时出现等差规律

- 教师点击快捷按钮：
  - 「对齐A₁」（φ=0°）：P平滑动画移动到(440,220)，展示初始对称状态
  - 「对齐15°」（φ=15°）：P动画移动到15°位置，此时排序数列必为15°,45°,75°,105°,135°,165°（公差30°），高亮生效，教师可强调此特殊位置即为答案对应的构型
  - 「对齐30°」（φ=30°）：P动画移动到30°位置，展示非等差状态（30°,30°,90°,90°,150°,150°），与15°形成对比
  - 动画时长400ms，使用requestAnimationFrame线性插值

- 教师点击「显示/隐藏弧线」：
  - toggle弧线显示标志，立即重绘，避免多弧线重叠造成的视觉混乱
  - 按钮文字同步切换为「显示弧线」/「隐藏弧线」

[技术实现]
- JS库选择：原生 SVG + 原生 JavaScript（零外部库）。理由：本场景为纯2D几何图形（圆、多边形、线段、弧线），无复杂函数绘图或3D需求，原生SVG路径计算足够且轻量，避免引入不必要的依赖。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------------+
  |                                                        |
  |   A₃(200,81)        A₂(360,81)                        |
  |      ·                 ·                               |
  |     / \               / \                              |
  |    /   \             /   \                             |
  | A₄·-----·O·--------·A₁    |  [右侧面板]                |
  |    \   /  (280,220)  \   |  θ₁ = 15.0°                |
  |     \ /               \  |  θ₂ = 45.0°                |
  |      ·                 · |  θ₃ = 105.0°               |
  |   A₅(200,359)      A₆(360,359)  θ₄ = 165.0°          |
  |                              θ₅ = 135.0°               |
  |                              θ₆ = 75.0°                |
  |                              ————————                  |

  |                                                        |

  +--------------------------------------------------------+
  画布 800×500，底部控件区 y=440~490，右侧面板 x=560~790
  ```

- 关键实现要点：
  1. 坐标系与角度映射：数学角度φ（逆时针从x轴正方向）映射到SVG坐标：Px = 280 + 160·cos(φ·π/180)，Py = 220 − 160·sin(φ·π/180)。所有三角计算使用Math.cos/Math.sin，角度转弧度。
  2. 夹角计算：对每个顶点Aᵢ（固定角度αᵢ=(i−1)·60°），θᵢ = min(|φ−αᵢ| mod 360, 360 − |φ−αᵢ| mod 360)，结果保留1位小数。排序使用Array.prototype.sort((a,b)=>a−b)。
  3. 弧线绘制：使用SVG path的A命令。起始点(sx,sy) = (280+50·cos(αᵢ), 220−50·sin(αᵢ))，终点(ex,ey) = (280+50·cos(φ), 220−50·sin(φ))。sweep-flag根据角度差方向动态计算（确保弧线始终走较小夹角一侧）。当θᵢ<1°时跳过绘制（避免退化为点）。
  4. 扇形填充：path d="M 280 220 L sx sy A 50 50 0 0 sweep ex ey Z"，fill=#1565c0，opacity=0.1。同样θᵢ<1°时跳过。
  5. 等差数列检测：排序后数组arr，计算相邻差diffs = [arr[1]−arr[0], ..., arr[5]−arr[4]]。若所有diff与diffs[0]之差的绝对值<0.5°，则判定为等差数列。由于理论公差为30°，容差0.5°足够覆盖浮点误差。
  6. 拖拽实现：在P点上绑定mousedown → 设置dragging=true；SVG容器绑定mousemove → 若dragging，计算鼠标相对圆心(280,220)的角度Math.atan2(220−my, mx−280)，更新φ并刷新；mouseup → dragging=false。使用atan2时注意SVG y轴向下，需反转y差值。
  7. 动画实现：点击快捷按钮时，使用requestAnimationFrame。记录起始角度startφ、目标角度targetφ、起始时间t0。每帧计算进度p=(now−t0)/400，使用easeInOutQuad或简单线性插值：current = startφ + (targetφ−startφ)·p。注意角度跨0°/360°的归一化处理（选择最短路径）。
  8. 状态管理：全局状态对象state = {phi: 0, showArcs: true, isDragging: false, animating: false}。所有渲染函数读取state，避免直接操作DOM与状态不同步。
  9. 性能优化：拖拽和动画期间，每帧只更新必要的SVG属性（d、x1/y1/x2/y2、cx/cy、textContent），不重建DOM节点。六个θᵢ显示行和排序数列使用innerHTML或textContent更新。
