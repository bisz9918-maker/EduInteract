[图示主题与整合说明]
- 本图示主题：由三视图还原四棱锥直观图
- 整合的步骤/概念：①三视图并列展示与尺寸标注 ②主视图信息提取（底面长6、顶点居中、锥高2） ③侧视图信息提取（底面宽2、高2、直角特征推断投影在宽边上） ④俯视图信息提取（投影点O为长边中点） ⑤合成3D斜二测直观图并标注关键元素
- 教学价值：教师通过分步导航控制讲解节奏，每步聚焦一个视图的信息提取，逐步建立从二维视图到三维空间形体的认知过渡，最终验证顶点投影位置并生成可旋转观察的斜二测直观图

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「上一步」按钮：位置(300,455)，宽80高32。点击回退到上一分步，步骤0时禁用（opacity 0.4）。
  2. 「下一步」按钮：位置(420,455)，宽80高32。点击前进到下一分步，步骤4时禁用。
  3. 步骤指示器：位置(400,445)，显示当前步骤序号/总步骤数（如"步骤 2 / 5"）。
- 教师操作流程：
  1. 教师打开图示，学生看到三视图并列展示（步骤0）。
  2. 教师点击「下一步」，主视图高亮，讲解底边6与顶点居中关系，以及锥高2（步骤1）。
  3. 教师点击「下一步」，侧视图高亮，讲解底面宽2、锥高2、直角特征推断投影位置（步骤2）。
  4. 教师点击「下一步」，俯视图高亮，讲解投影点O是长边中点（步骤3）。
  5. 教师点击「下一步」，三视图淡出/缩小，3D直观图生成，讲解空间结构（步骤4）。
  6. 教师可随时点击「上一步」回退复习任意视图。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本场景以静态几何图形和简单透明度/位置变化为主，无需复杂数学计算或3D渲染，原生SVG足以高效实现，且避免引入不必要的库体积。
- 画布尺寸：800×500px（固定）。
- 布局草图（ASCII）：
  ```
  [标题区 y=0~35]              "由三视图还原四棱锥"
  [主图区 y=40~440]
   ┌─────────────┐  ┌─────────┐
   │  主视图      │  │ 侧视图  │   ← 步骤0~3：三视图区 y=40~360
   │  (三角形)    │  │(直角△) │
   └─────────────┘  └─────────┘
   ┌─────────────┐
   │  俯视图      │                ← 俯视图在左下
   │ (矩形+内线)  │
   └─────────────┘
            ↓ 步骤4
         [3D斜二测直观图 居中]      ← 3D图区 y=280~430
            P
           /|\
          / | \
         A--O--B
         |     |
         D-----C
  [控件栏 y=455~490]   [◀上一步] [步骤 X/5] [下一步▶]
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `currentStep`（0~4），每次点击按钮时更新状态并调用 `renderStep()`。
  2. 渲染策略：所有SVG元素预先在DOM中定义，通过添加/移除CSS类（如 `.highlight`、`.dimmed`、`.hidden`）控制显示与样式，避免频繁创建/销毁元素。
  3. 动画曲线：透明度变化使用CSS transition（opacity 0.3s ease）；3D图出现使用淡入（opacity 0→1，0.4s）；推断文字使用轻微平移（transform: translateX(10px)→0，0.3s）。
  4. 坐标计算：斜二测3D坐标按公式计算（x轴水平1:1，y轴右下45°长度减半，z轴竖直1:1），比例尺22px/单位。
  5. 事件绑定：按钮点击事件在IIFE内绑定，使用 `getElementById` 获取元素。
  6. 三视图缩小（步骤4）：使用SVG `transform="translate(x,y) scale(0.4)"` 将三视图组整体变换至左上角，或改用CSS opacity过渡淡出。
  7. 尺寸标注线：使用SVG `<line>` 或 `<path>` 绘制带箭头的尺寸线，箭头使用 `<marker>` 定义。
- ID命名规范：所有交互元素ID必须以 `scene1-` 为前缀。例如：
  - 主视图三角形：`scene1-tri-main`
  - 侧视图外框：`scene1-frame-side`
  - 3D高PO：`scene1-3d-po`
  - 按钮：`scene1-btn-prev`、`scene1-btn-next`
  - 步骤指示器：`scene1-step-indicator`
  JS中严格使用 `document.getElementById('scene1-xxx')` 获取元素，禁止跨场景选择器。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免全局命名空间污染。
- 响应式与容器：SVG设置 `width="800" height="500" viewBox="0 0 800 500"`，确保画布固定；控件按钮使用HTML绝对定位叠在SVG容器上（`position: absolute; bottom: 10px;`）。
