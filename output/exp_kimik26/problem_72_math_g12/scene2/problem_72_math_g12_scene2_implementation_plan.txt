[分步序列]
- 步骤0（初始）：显示完整3D四棱锥。底面填充#eeeeee 30%，四个侧面填充#888888 10%。显示标签P/A/B/C/D/O、尺寸AB=6/BC=2/CD=6/PO=2。高线PO红色。右侧显示提示"点击「下一步」开始分步计算"。标题"四棱锥表面积计算"。
- 步骤1（底面积）：底面高亮为已计算（填充改为#2e7d32 20%）。右侧显示底面矩形实形（120×40，标注长6、宽2）。算式区显示"S_底 = 6×2 = 12"。标题"步骤1：计算底面积"。
- 步骤2（侧面PAB）：底面保持绿色。PAB高亮为当前（#1565c0 20%），其余侧面灰色。右侧显示△PAB实形（底120、高80），标注AB=6、PO=2，底边中点标直角符号。算式区显示"S_△PAB = 1/2×6×2 = 6"。标题"步骤2：计算侧面△PAB面积"。
- 步骤3（侧面PAD）：PAB变为已计算（绿色）。PAD高亮为当前（蓝色）。右侧显示直角△PAD实形（直角在A，AD=40px，PA=72px），标AD=2、PA=√13及直角符号。3D图中显示PA=√13标签、A处红色直角符号。算式区显示"PA = √(2²+3²) = √13"和"S_△PAD = 1/2×2×√13 = √13"。标题"步骤3：计算侧面△PAD面积"。
- 步骤4（侧面PBC）：PAD变为已计算（绿色）。PBC高亮为当前（蓝色）。右侧显示直角△PBC实形（直角在B，BC=40px，PB=72px），标BC=2、PB=√13及直角符号。3D图中显示PB=√13标签、B处红色直角符号。算式区显示"S_△PBC = 1/2×2×√13 = √13"。标题"步骤4：计算侧面△PBC面积"。
- 步骤5（侧面PCD）：PBC变为已计算（绿色）。PCD高亮为当前（蓝色）。3D图中显示辅助线OM（灰色虚线）、高线PM（红色）、M点、M标签、PC=√17、PM=2√2标签、M处直角符号。右侧显示等腰△PCD实形（底120、高56.6），标CD=6、PM=2√2及直角符号。算式区显示"PM = √(2²+2²) = 2√2"和"S_△PCD = 1/2×6×2√2 = 6√2"。标题"步骤5：计算侧面△PCD面积"。
- 步骤6（汇总）：所有侧面及底面以不同淡色同时高亮（底面绿、PAB蓝、PAD红、PBC橙、PCD紫，透明度均15%~20%）。3D图中所有推导标签同时显示。右侧显示完整面积汇总列表（y=120起，6行）：
  S_底 = 6×2 = 12
  S_△PAB = 1/2×6×2 = 6
  S_△PAD = √13
  S_△PBC = √13
  S_△PCD = 6√2
  S_总 = 18 + 2√13 + 6√2（加粗放大）。
  标题"步骤6：表面积汇总"。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本场景为静态几何图形与显隐切换，无需复杂绘图库；数学公式使用Unicode字符（√、²、△等）即可满足，无需MathJax。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------------+
  |                      [标题区]                            |
  |  +------------------------+  +------------------------+  |
  |  |                        |  |                        |  |
  |  |     3D四棱锥直观图      |  |   侧面实形图 / 汇总列表  |  |
  |  |                        |  |                        |  |
  |  |   P                    |  |   △PAB / △PAD / ...    |  |
  |  |   |\                   |  |   或面积汇总文字         |  |
  |  |   | \                  |  |                        |  |
  |  |   |  \                 |  |   S_底=12              |  |
  |  |   O---A-------B        |  |   S_PAB=6              |  |
  |  |      D-------C         |  |   ...                  |  |
  |  |                        |  |                        |  |
  |  +------------------------+  +------------------------+  |
  |              [控件栏: ◀上一步] [重置] [下一步▶]           |
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量currentStep（0~6）记录当前步骤。renderStep(n)函数根据n值统一设置所有SVG元素的display/opacity和fill属性。避免分散控制导致状态不一致。
  2. 元素显隐：所有步骤相关元素（右侧实形图、推导标签、直角符号、辅助线）初始display:none，由renderStep按需显示。
  3. 面填充切换：通过修改polygon元素的fill和fill-opacity实现。已计算面统一设为#2e7d32, opacity 0.15；当前计算面设为#1565c0, opacity 0.20。
  4. 步骤6多色汇总：底面#2e7d32 20%、PAB#1565c0 20%、PAD#c62828 15%、PBC#ff8f00 15%、PCD#6a1b9a 15%，以视觉区分各面。
  5. 按钮实现：SVG内用<g>包裹<rect>+<text>模拟按钮，通过addEventListener绑定click事件。按钮在步骤边界时置灰（如步骤0时「上一步」降低opacity）。
  6. 坐标计算：3D图采用简化斜二测（x轴1:1，y深度轴向左上45°缩短一半，z轴垂直1:1；scale=30px/单位）。所有坐标已精确计算，代码agent直接硬编码。
  7. 动画曲线：步骤切换无需动画，直接瞬时切换；如需柔和过渡，可在CSS中给polygon和text加transition: opacity 0.2s ease。
  8. 事件绑定：每个按钮独立绑定，避免事件委托带来的复杂度。
- ID命名规范：所有SVG元素ID必须以scene2-为前缀。例如：scene2-face-pab、scene2-label-pa、scene2-right-pad、scene2-btn-next、scene2-ra-a（直角符号A）等。JS中严格使用getElementById获取。
- IIFE隔离：所有JavaScript代码包裹在 (function() { ... })() 中，避免全局变量污染，确保多场景合并时互不干扰。
