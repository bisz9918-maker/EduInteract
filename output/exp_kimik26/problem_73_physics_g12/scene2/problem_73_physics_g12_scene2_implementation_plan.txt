# Scene 2 Implementation Plan

<SCENE_VISION_STORYBOARD_AND_TECHNICAL_PLAN>

[图示主题与整合说明]
- 本图示主题：导体棒在倾斜U形框架上无摩擦下滑的动态过程——v-t图像与电功率计算
- 整合的步骤/概念：
  1) 速度-时间关系图像（单调递增、斜率递减、趋近水平渐近线 v_m=5 m/s）
  2) 初始状态分析（t=0 时 v=0，加速度最大 a=g·sinθ=5 m/s²）
  3) 电磁感应因果链（v↑ → E=BLv↑ → I=E/R↑ → F_安=BIL↑）
  4) 加速度随速度增大而减小的动力学解释（F_合=mg·sinθ−F_安）
  5) 匀速平衡状态（v=v_m 时 a=0，F_安=mg·sinθ=1 N）
  6) 最大速度时的电功率两种计算方法对照（P=E²/R=5 W 与 P=F_安·v_m=5 W）
- 教学价值：教师通过分步导航，带领学生从运动学图像出发，逐步深入到电磁感应因果链、动力学分析和能量转化，建立“速度变化→感应电动势→感应电流→安培力→加速度变化”的完整逻辑闭环，并用两种方法互证电功率，强化物理规律的一致性。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript（无需额外库）。理由：本场景以静态几何图形、文本标签和简单状态切换为主，原生SVG足以高效绘制坐标系、曲线和流程框；状态管理通过classList控制display/opacity即可，无需D3或Canvas。
- 画布尺寸：800 × 500 px（沿用规定）
- 布局草图（ASCII）：

- 关键实现要点：
  1. 状态机设计：定义常量`const TOTAL_STEPS = 5;`，变量`let currentStep = 0;`。每一步对应一个显示元素ID集合，用对象`stepElements`映射：{0: [...], 1: [...], ...}。切换步骤时，先隐藏所有步骤相关元素，再显示当前步骤对应的元素。
  2. v-t曲线绘制：使用SVG `<path>`，d属性用`M 60 380`开头，随后用`L`连接各数据点坐标。为获得平滑效果，数据点至少取12个（t从0到3.5s，步长0.3s左右）。曲线颜色#1565c0，线宽2.5px，填充none。
  3. 渐近线：使用SVG `<line>`，stroke-dasharray="6,4"实现虚线效果。
  4. 因果链动画：步骤2激活时，4个流程框和3个箭头依次出现。使用`setTimeout`实现stagger效果：框1立即显示，框2在200ms后显示，框3在400ms后显示，框4在600ms后显示，箭头随上方框同时显示。
  5. 淡入动画：所有步骤切换使用CSS transition：`transition: opacity 300ms ease;`。初始状态`opacity: 0; display: none;`，激活时先设`display: block`（或inline），再于下一帧设`opacity: 1`（可用requestAnimationFrame）。
  6. 步骤5功率结果高亮：大字体"P = 5 W"使用`<text>`元素，设置`font-size="20px"`，`font-weight="bold"`，`fill="#2e7d32"`，并添加`<tspan text-decoration="underline">`实现下划线。
  7. 按钮状态：当currentStep===0时，「上一步」按钮置灰（disabled）；当currentStep===TOTAL_STEPS时，「下一步」按钮置灰。
- ID命名规范：所有交互元素ID必须以`scene2-`为前缀。示例：
