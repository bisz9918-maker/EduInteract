[图示主题与整合说明]
- 本图示主题：电磁感应装置结构与线圈穿过磁场的完整运动过程
- 整合的步骤/概念：滑轮装置、磁场区域、线圈四个关键位置（ab刚进入、ab在磁场中、ab穿出/cd进入、cd在磁场中、cd穿出）、位移关系、已知条件标注、运动方向与切割边高亮
- 教学价值：教师通过分步导航，依次展示线圈从ab边进入磁场到cd边穿出磁场的完整过程，帮助学生理解切割磁感线的阶段划分、匀速运动条件以及总位移2l的几何意义，避免一次性呈现全部信息造成认知过载

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶ + 重置）
- 控件说明：
  - 「上一步」按钮：位置(280,452)，尺寸70×28，点击回退到上一状态，步骤0时禁用
  - 「步骤显示」：位置(360,452)，尺寸80×28，显示当前步骤序号如"步骤 1/6"
  - 「下一步」按钮：位置(450,452)，尺寸70×28，点击前进到下一状态，步骤5时禁用
  - 「重置」按钮：位置(530,452)，尺寸60×28，点击立即回到步骤0
- 教师操作流程：
  1. 教师打开图示，首先向学生展示步骤0的装置总览，讲解已知条件（l、h、m₁、m₂、R、B）
  2. 点击「下一步」进入步骤1，讲解ab边刚进入磁场的初始时刻，标注过程开始和运动方向
  3. 点击「下一步」进入步骤2，高亮ab边，强调ab边切割磁感线产生感应电流
  4. 点击「下一步」进入步骤3，展示ab穿出同时cd进入的关键过渡，标注位移=l，强调h=l
  5. 点击「下一步」进入步骤4，高亮cd边，说明cd边继续切割磁感线
  6. 点击「下一步」进入步骤5，展示cd穿出磁场，标注总位移=2l和过程结束，总结全过程
  7. 可随时回退到任意步骤复习关键位置

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本场景以几何图形、矩形、线段、标签为主，无复杂函数曲线或3D，原生SVG足以满足需求，且无需引入外部库减少加载开销。
- 画布尺寸：800 × 500 px（沿用规定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------------+
  |  过程结束(步骤5)                                       |
  |       左滑轮                    右滑轮                 |
  |         ○                        ○                     |
  |         |                        |                     |
  |    +----+----+------------------+-----+                |
  |    | 磁场区域 | B=0.5T           |    |                |
  |    |  ×  ×  |                   | 砝码 m₂             |
  |    |  ×  ×  | h                 |    |                |
  |    +----+----+                   +----+                |
  |         |                        |                     |
  |    +----+----+                   |                     |
  |    | a----b | ← l                |                     |
  |    | | m₁ | |                   |                     |
  |    | d----c | R                  |                     |
  |    +----+----+                   |                     |
  | 位移=l/2l(左侧)                 v↓(步骤1-5)           |
  | v↑(步骤1-5)  切割提示(右侧)                            |
  |                                                        |
  | [上一步] [步骤 1/6] [下一步] [重置]                     |  y=452
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：定义currentStep变量（0~5），每一步定义一个配置对象，包含线圈y坐标、砝码y坐标、显示/隐藏的元素ID列表、高亮边标识。
  2. 坐标计算：线圈和砝码的y坐标按步骤递增/递减。线圈边长l=65px，磁场高度h=65px，每步位移已精确计算。
  3. 动画曲线：使用CSS transition（transform或y属性过渡，时长400ms，ease-in-out）实现线圈和砝码的平滑移动。标签使用相同的过渡动画跟随移动。
  4. 元素显隐：非当前步骤的标签/箭头使用CSS opacity过渡（0→1或1→0，时长200ms），避免突兀出现/消失。
  5. 事件绑定：为「上一步」「下一步」「重置」按钮绑定click事件，更新currentStep后调用render()函数重新渲染场景。
  6. 按钮状态：步骤0时禁用「上一步」，步骤5时禁用「下一步」，通过设置opacity和pointer-events实现。
  7. 高亮边实现：在SVG中单独绘制ab边和cd边的线段元素，默认hidden，步骤2显示ab高亮边，步骤4显示cd高亮边，其余步骤隐藏。
- ID命名规范：所有交互元素ID必须以scene1-为前缀。例如：
  - scene1-coil-group（线圈整体g元素）
  - scene1-magnet-group（磁场整体g元素）
  - scene1-pulley-left、scene1-pulley-right
  - scene1-weight-group（砝码整体g元素）
  - scene1-label-m1、scene1-label-m2、scene1-label-R、scene1-label-B
  - scene1-label-a、scene1-label-b、scene1-label-c、scene1-label-d
  - scene1-arrow-up、scene1-arrow-down
  - scene1-highlight-ab、scene1-highlight-cd
  - scene1-text-start、scene1-text-end
  - scene1-text-displacement-l、scene1-text-displacement-2l
  - scene1-text-cut-ab、scene1-text-cut-cd
  - scene1-btn-prev、scene1-btn-next、scene1-btn-reset、scene1-step-display
- IIFE隔离：所有JavaScript代码包裹在 (function() { ... })() 中，避免全局变量污染，确保多场景合并时互不干扰。
