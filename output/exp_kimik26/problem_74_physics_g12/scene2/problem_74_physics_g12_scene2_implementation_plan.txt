[图示主题与整合说明]
- 本图示主题：线圈匀速穿过磁场时的受力平衡与电磁感应规律（物理·高二/高三·电磁感应综合）

- 教学价值：教师通过分步导航，带领学生从直观装置图逐步过渡到抽象公式推导，左侧线圈区与右侧砝码区形成对照，底部公式区实时呈现物理规律，符合“直观→分析→综合”的认知递进。

[分步序列]
- 步骤0（初始状态）：显示装置简图——磁场区域、线圈abcd（ab边蓝色高亮）、滑轮、绳子、砝码、m₁与m₂标签、速度v箭头、B标注、h=l与l标注。底部公式区显示提示文字"分别对线圈和砝码进行受力分析"。
- 步骤1（线圈受力图）：隐藏提示文字。在线圈区出现张力T箭头（向上，蓝）和重力m₁g箭头（向下，绿）。教师讲解线圈受向上的绳拉力与向下的重力。
- 步骤2（砝码受力图）：在砝码区出现张力T箭头（向上，蓝）和重力m₂g箭头（向下，绿）。教师讲解砝码受向上的绳拉力与向下的重力，并与线圈侧T箭头长度对比，暗示T大小相等。
- 步骤3（电磁感应分析）：在线圈ab边右侧出现感应电动势标注"ε=Blv"（蓝）和感应电流"I=Blv/R"（蓝），并显示右手定则小图标指示电流方向（a→b）。教师讲解切割磁感线产生感应电动势与电流。
- 步骤4（安培力分析）：在线圈ab边处出现安培力F_安箭头（向下，红），并显示左手定则小图标。教师讲解ab边受向下的安培力，阻碍线圈上升。
- 步骤5（列平衡方程）：底部公式区显示浅灰背景，左侧"线圈：T = m₁g + F_安"，右侧"砝码：T = m₂g"。教师引导学生对两物体分别列平衡方程。
- 步骤6（联立求解）：公式区更新为"联立：m₂g = m₁g + B²l²v/R"、"解得：v = (m₂−m₁)gR/(B²l²)"，最终结果"v = 4 m/s"以红色高亮大号字体显示。教师总结求解过程，强调最终结果。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本场景以静态几何图形、矢量箭头、分步显隐为主，无需复杂数据绑定或3D渲染，原生SVG可精确控制每个元素的坐标与样式，性能轻量且可控。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图（ASCII）：
  ```
  0    100  200  300  400  500  600  700  800
  40   +----+----+----+----+----+----+----+----+
       | 磁场区(190,100~270,180)   |  滑轮   |    |
       |    × × ×                  |  ○  ○   |    |
       |    × × ×    B             | /    \  | 砝码|
       |    × × ×                  |/      \ | 矩形|
       | 线圈 abcd (190,180~270,260)|        | m₂  |
       |  ↑T  ↓m₁g  ↓F_安          |        | ↑T  |
       |  ←v                       |        | ↓m₂g|
  330  +---------------------------+--------+----+
       |         公式推导区 (50,335~750,420)      |
  440  +------------------------------------------+
       |      [上一步]    步骤 X/7    [下一步]     |
  500  +------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量`currentStep`（0~6）控制当前步骤。每步定义显隐元素列表，通过`setAttribute('display', 'none/block')`切换。避免使用CSS类切换，防止多场景合并时样式污染。
  2. 坐标计算：所有力箭头起点/终点、标签坐标均按上述坐标表硬编码。箭头使用SVG `<line marker-end="url(#arrowhead)"/>`，在`<defs>`中定义箭头标记。
  3. 动画曲线：分步切换为即时显隐，无需补间动画，保证课堂讲解节奏可控。若需强调，可对新增元素添加0.3s淡入（opacity 0→1）。
  4. 事件绑定：上一步/下一步按钮绑定`click`事件，更新`currentStep`后调用`renderStep()`重绘界面。按钮在边界状态禁用（步骤0禁用上一步，步骤6禁用下一步）。
  5. 公式区：步骤0~4时公式区仅显示提示文字或留空；步骤5~6显示对应公式文本。使用SVG `<text>`或foreignObject内嵌HTML均可，建议统一用SVG `<text>`以保证缩放一致性。
  6. 左右手定则图标：使用简单SVG路径绘制手掌轮廓（或Unicode图标🖐/👈简化），20×20px，步骤3显示右手，步骤4显示左手，二者互斥。
- ID命名规范：所有SVG元素及控件ID必须以`scene2-`为前缀。例如：`scene2-coil-rect`、`scene2-force-T-coil`、`scene2-btn-prev`、`scene2-formula-result`。JS中严格使用`document.getElementById`获取元素。
- IIFE隔离：所有JavaScript代码包裹在`(function() { ... })();`中，避免全局变量污染，确保多场景合并时互不干扰。
