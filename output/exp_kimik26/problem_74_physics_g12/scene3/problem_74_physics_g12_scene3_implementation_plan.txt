[图示主题与整合说明]
- 本图示主题：线圈穿越磁场过程中的能量转化与焦耳热计算
- 整合的步骤/概念：初末位置高度变化 → 重力势能变化 → 系统机械能变化（动能不变） → 能量守恒求热量 → 焦耳定律验证
- 教学价值：教师通过分步导航，引导学生观察“初态—末态”的空间位移，再逐步建立势能变化、机械能减少、能量守恒、焦耳热验证的完整逻辑链。左侧装置图提供直观空间参照，右侧分析区同步呈现公式与能量流向，实现“左图右理”的板书式教学效果。

- 步骤2（重力势能分析）：左侧保持步骤1全部元素。右侧切换为“重力势能变化”标题。第一行（y=140）显示绿色向上箭头图标+“ΔE_p1 = m₁g·2l = 0.40 J”。第二行（y=220）显示红色向下箭头图标+“ΔE_p2 = m₂g·2l = 0.56 J”。
- 步骤3（系统机械能变化）：左侧保持。右侧切换为“系统机械能变化”标题。第一行（y=120）“动能不变（匀速运动）”。第二行（y=180）“ΔE = ΔE_p2 − ΔE_p1”。第三行（y=240）红色高亮“= 0.56 − 0.40 = 0.16 J”。

  2. “感应电流 I = Blv/R = 4 A”（y=160）
  3. “运动时间 t = 2l/v = 0.10 s”（y=200）

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）。
- 控件说明：
  1. 「上一步」按钮：位于SVG底部控件条中心左侧(320,470)，宽90×高34。点击后currentStep减1，回退到上一状态，所有元素按新状态重绘可见性。
  2. 步骤指示器：位于(450,470)，显示“当前步 / 总步数”（如“3 / 6”）。
  3. 「下一步」按钮：位于控件条中心右侧(580,470)，宽90×高34。点击后currentStep加1，进入下一状态。
- 教师操作流程：
  1. 教师打开图示，默认步骤0，向学生展示装置与已知条件。
  2. 点击「下一步」进入步骤1，对比初末态位置，强调“线圈上升2l、砝码下降2l”。
  3. 继续点击「下一步」依次展示势能变化、机械能减少、能量守恒结论、焦耳定律验证。每步右侧公式与左侧装置形成对照。
  4. 可随时点击「上一步」回退，复习前序逻辑。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本场景以静态几何图形、文本标签和显隐切换为主，无需复杂图表或3D，原生SVG性能最佳且可控性最强。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  左侧装置区(0~280)        |  右侧分析区(300~780)   |
  |  · 滑轮/天花板            |  · 标题/公式/框图      |
  |  · 线圈(初态黑/末态绿)    |  · 能量流向箭头        |
  |  · 砝码(初态黑/末态绿)    |  · 结论高亮框          |
  |  · 磁场/位移箭头          |                        |
  +--------------------------------------------------+
  |  [控件栏 y=440~490]                              |
  |      [◀ 上一步]     步骤 1/6     [下一步 ▶]      |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：定义全局变量 `let currentStep = 0;`，共6个状态（0~5）。每个SVG元素（或g组）通过 `class="scene3-step-k"` 标记所属状态。切换时遍历所有带 `scene3-step-*` 的元素，若其class包含当前步骤则 `display: block`（或opacity:1），否则 `display: none`（或opacity:0）。
  2. 坐标计算：所有坐标已在布局坐标表中精确给出，代码agent直接硬编码，不依赖动态计算。
  3. 动画曲线：本场景为分步显隐，无需过渡动画。若需柔和切换，可对opacity加100ms线性过渡。
  4. 事件绑定：「上一步」「下一步」按钮用addEventListener绑定click事件。上一步在currentStep===0时disabled=true；下一步在currentStep===5时disabled=true。步骤指示器文本随currentStep更新。
  5. 右侧内容管理：右侧分析区内容随步骤完全替换。建议为每一步的右侧内容包在一个 `<g id="scene3-right-step-k">` 中，统一控制显隐，避免逐行管理。
  6. 左侧淡化处理：步骤1起，初态线圈/砝码可通过修改stroke属性为#888、线宽改为1px实现淡化，而非隐藏，以保留空间参照。
- ID命名规范：所有SVG元素ID必须以 `scene3-` 为前缀。例如：
  - `scene3-coil-initial-ab`、`scene3-coil-final-ab`
  - `scene3-weight-initial`、`scene3-weight-final`
  - `scene3-arrow-coil-disp`、`scene3-arrow-weight-disp`
  - `scene3-right-step-0` ~ `scene3-right-step-5`
  - `scene3-btn-prev`、`scene3-btn-next`、`scene3-step-indicator`
  JS中严格使用 `document.getElementById` 获取元素，禁止querySelectorAll配合全局class，防止多场景合并时跨场景污染。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，内部变量不污染全局作用域。
- 控件实现：使用HTML `<div>` 绝对定位叠在SVG容器底部（`position: absolute; left: 0; top: 440px; width: 800px; height: 60px;`），内部放两个`<button>`和一个`<span>`。SVG本身用`<svg viewBox="0 0 800 500">`嵌入容器。
