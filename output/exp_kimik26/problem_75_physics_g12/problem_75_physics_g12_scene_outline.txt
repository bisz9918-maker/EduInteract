**题目原文**

如图所示，一平行板电容器水平放置，板间距离为 $d$，上极板开有一小孔，三个质量均为 $m$、带电荷量均为 $+q$ 的带电小球，其间用长为 $L$ 的绝缘轻杆相连，处于竖直状态。已知 $d=3L$，今使下端小球恰好位于小孔中，且由静止释放，让三球竖直下落。当下端小球到达下极板时，速度恰好为零。试求：

1. 两极板间的电压；
2. 小球运动的最大速度。

**题目分析**

本题的核心难点在于：三球系统在下落过程中，各球是**依次进入**电容器极板间电场区域的，因此系统所受电场力随下落位移发生**阶段性突变**。必须根据下端小球的下落距离 $x$，将全过程划分为三个阶段：

1. **阶段一**（$0 < x < L$）：仅最下端小球在电场中，受电场力 $qE$ 向上；
2. **阶段二**（$L \le x < 2L$）：下端两球在电场中，总电场力 $2qE$ 向上；
3. **阶段三**（$2L \le x \le 3L$）：三球均在电场中，总电场力 $3qE$ 向上。

由于初、末速度均为零，可先用**动能定理**对全过程列式，求出电场强度 $E$ 与极板电压 $U$；再通过**分阶段受力分析**找到合力为零的位置，进而用动能定理求最大速度。

**图示规划说明**

- **图示一**：以空间位置为主视角，通过分步导航展示三球在下落各阶段的位置、受力及合力变化，帮助学生建立"依次进入电场"的直观认知。
- **图示二**：以 $v-x$ 图像和能量分析为主视角，展示速度随位移的变化规律及动能定理在各阶段的数值关系，帮助学生理解"为何在中间阶段速度最大"。

**教学要点：分阶段受力与电压求解**

教师应引导学生观察：三球并非同时进入电场，而是随着下落**依次穿过**上极板边界。这是解题的突破口。

1. 明确电场方向：小球带正电，末速度为零说明电场力向上做负功，故电场方向竖直向上（下极板为正，上极板为负）。

2. 设电场强度为 $E$，下端球下落距离为 $x$。分阶段受力：
   - $0<x<L$：$n=1$，$F_{\text{合}} = 3mg - qE$（向下，加速）
   - $L\le x<2L$：$n=2$，$F_{\text{合}} = 3mg - 2qE$
   - $2L\le x\le 3L$：$n=3$，$F_{\text{合}} = 3mg - 3qE$（向上，减速）

3. **求电压（动能定理）**：对全过程（$x=0$ 到 $x=3L$），初末动能均为零。
   
   重力做功（三球各下落 $3L$）：
   $$W_G = 3mg \cdot 3L = 9mgL$$
   
   电场力做功（仅计算在电场中的位移，力向上、位移向下，做负功）：
   - 球1：在电场中下移 $3L$，$W_1 = -qE \cdot 3L$
   - 球2：在电场中下移 $2L$（从 $y=0$ 到 $y=2L$），$W_2 = -qE \cdot 2L$
   - 球3：在电场中下移 $L$（从 $y=0$ 到 $y=L$），$W_3 = -qE \cdot L$
   
   总电场力做功：
   $$W_E = -6qEL$$
   
   由动能定理 $W_G + W_E = 0$：
   $$9mgL - 6qEL = 0 \quad\Rightarrow\quad qE = \frac{3}{2}mg$$
   
   极板电压：
   $$U = E \cdot d = \frac{3mg}{2q} \cdot 3L = \frac{9mgL}{2q}$$

4. 关键强调：电场力做功与路径无关，只与在电场中的竖直位移有关；球2、球3初始在上极板上方，进入电场的时间有延迟。

**教学要点：最大速度求解与课堂总结**

1. **何时速度最大？**
   
   由受力分析可知：
   - $0<x<L$：$F_{\text{合}} = 3mg - qE = 1.5mg > 0$，向下加速；
   - $L\le x\le 2L$：$F_{\text{合}} = 3mg - 2qE = 0$，合力为零；
   - $2L<x\le 3L$：$F_{\text{合}} = 3mg - 3qE = -1.5mg < 0$，向上减速。
   
   因此，系统在 $x=L$ 处结束加速，在 $x=2L$ 处开始减速，**在 $L\le x\le 2L$ 的整个区间内保持最大速度**。

2. **求最大速度（动能定理）**
   
   对 $x=0$ 到 $x=L$ 过程列动能定理：
   - 重力做功：$W_G = 3mg \cdot L = 3mgL$
   - 电场力做功：仅球1在电场中下移 $L$，$W_E = -qEL = -1.5mgL$
   - 动能增量：$\Delta E_k = \frac{1}{2}(3m)v_{\max}^2$
   
   于是：
   $$3mgL - 1.5mgL = \frac{3m}{2}v_{\max}^2$$
   $$1.5mgL = 1.5mv_{\max}^2$$
   $$v_{\max} = \sqrt{gL}$$

3. **课堂讲解建议**
   
   - 先通过图示一让学生"看"到三球是依次进入电场的，避免直接列式时的位移混淆。
   - 强调球2、球3进入电场时的位移不是 $x$，而是 $x-L$ 和 $x-2L$（或直接在电场中的部分）。
   - 在图示二中，重点让学生观察 $v-x$ 图像的"平台期"——这是合力为零的直接体现，也是连接受力分析与能量分析的桥梁。
   - 总结：本题同时考查了**变力做功的分段处理**、**系统动能定理**和**极值条件的受力特征**，是一道典型的电磁学与力学综合题。
