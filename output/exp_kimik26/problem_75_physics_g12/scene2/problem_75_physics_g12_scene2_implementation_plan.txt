[图示主题与整合说明]
- 本图示主题：速度变化规律与能量转化分析（平行板电容器中带电小球下落）
- 整合内容：v-x 图像（速度随下落位移变化）、动能定理数值关系、各阶段能量分配、最大速度标注
- 教学价值：教师通过四状态分步导航，可逐点讲解 x=0、L、2L、3L 四个关键位置的能量转化过程，并清晰定位最大速度所在区间（L~2L），帮助学生建立“重力做功 vs 电场力做功”的动态平衡直觉

[交互方案]
- 交互类型：分步按钮导航（◀ 上一步 / 下一步 ▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于底部左侧 (190,457)-(310,493)，点击回退到上一状态，已在首状态时 disabled
  - 「下一步 ▶」按钮：位于底部右侧 (490,457)-(610,493)，点击前进到下一状态，已在末状态时 disabled
  - 状态指示器：位于两按钮之间上方 (400,450)，显示 "状态 n / 4"
- 教师操作流程：
  1. 教师展示初始状态，说明三球系统从静止开始下落，初始动能为零
  2. 点击「下一步」进入状态 2，讲解第一段下落（0→L）：三球均在电场外，只受重力，加速下落，到达 x=L 时速度达到最大；结合能量面板说明重力做功 3mgL，电场力尚未做功（系统质心刚进入电场），动能 1.5mgL
  3. 点击「下一步」进入状态 3，讲解第二段下落（L→2L）：三球均匀速通过电场，重力与电场力平衡，速度保持 v_max；能量面板显示电场力开始做负功，累计 -4.5mgL，但动能不变
  4. 点击「下一步」进入状态 4，讲解第三段下落（2L→3L）：三球减速，电场力做功超过重力做功，到达下极板时速度恰好为零；能量面板显示总重力做功 9mgL 与总电场力做功 -9mgL 抵消，动能为零
  5. 可随时点击「上一步」回退复习任一阶段的能量关系

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无外部库）。原因：图示以折线、坐标轴、文本和简单动画为主，SVG 的矢量特性保证缩放清晰，原生 JS 足以驱动状态机与属性动画，无需引入 D3 等重型库。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |  v↑                                               |
  |   |    加速 /                                      |
  |   |   /    匀速─── v_max=√(gL)                     |
  |   |  /         \   减速                            |
  |   | /            \                                |
  |   |/              \                               |
  |   +----+----+----+----→ x                         |
  |   0    L   2L   3L                               |
  |                                                   |
  |  +----------------------------------------------+ |
  |  | 动能定理      x = 2L                         | |
  |  | W_G+W_E=ΔE_k  ----------------               | |
  |  |               W_G = 6 mgL  (红)              | |
  |  |               W_E = -4.5 mgL (蓝)            | |
  |  |               E_k = 1.5 mgL  (绿)            | |
  |  +----------------------------------------------+ |
  |       ◀ 上一步    状态 2/4    下一步 ▶            |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `currentState`（取值 0~3），对应四个状态。状态切换时更新状态点坐标、能量数值文本、按钮 disabled 属性、状态指示器文本。
  2. 状态点动画：使用 SVG `<circle>` 元素，通过 JS 的 `requestAnimationFrame` 或 CSS `transition` 实现 300ms 的位置移动。若用 CSS transition，需设置 `<circle>` 的 `cx`、`cy` 为 CSS transition 属性；若用 JS，使用线性插值（lerp）在 300ms 内更新 `cx`、`cy` 属性。
  3. 坐标计算：x 轴 400px 对应 3L，故 L=133.33px；状态点 x 坐标：100 + state * 133.33（state=0 时 100，state=1 时 233，state=2 时 367，state=3 时 500）。y 坐标：state=0 或 3 时为 250；state=1 或 2 时为 50。
  4. 能量数据：预定义数组 `energyData = [
       {x: "0", wg: "0", we: "0", ek: "0"},
       {x: "L", wg: "3", we: "-1.5", ek: "1.5"},
       {x: "2L", wg: "6", we: "-4.5", ek: "1.5"},
       {x: "3L", wg: "9", we: "-9", ek: "0"}
     ]`，切换状态时读取对应索引数据并更新文本内容。
  5. 按钮事件：为「上一步」「下一步」绑定 click 事件，修改 `currentState` 后调用统一的 `renderState()` 函数更新所有视觉元素。
  6. 按钮 disabled 样式：通过添加/移除 CSS class（如 `.disabled`）设置背景色 #cccccc、cursor:not-allowed，并阻止点击事件。
  7. 折线绘制：使用 SVG `<polyline>` 或三段 `<line>`，分别设置 stroke 颜色。为增强当前阶段引导，可在状态切换时，将当前状态对应的折线段线宽设为 4px、opacity 1.0，其余段线宽 2px、opacity 0.6（可选，计划中保留此细节供代码 agent 参考）。
- ID 命名规范：所有交互元素 ID 必须以 `scene2-` 为前缀，例如：
  - `scene2-vx-chart`（v-x 图像组）
  - `scene2-axis-x`、`scene2-axis-y`（坐标轴）
  - `scene2-line-1`、`scene2-line-2`、`scene2-line-3`（三段折线）
  - `scene2-state-point`（当前状态点）
  - `scene2-energy-panel`（能量面板组）
  - `scene2-label-x`、`scene2-label-v`（轴标签）
  - `scene2-val-wg`、`scene2-val-we`、`scene2-val-ek`（能量数值）
  - `scene2-btn-prev`、`scene2-btn-next`（按钮）
  - `scene2-status-indicator`（状态指示器）
  JS 中严格使用 `document.getElementById` 获取元素，禁止全局 class 选择器，避免多场景合并时跨场景污染。
- IIFE 隔离：所有 JavaScript 代码包裹在 `(function() { ... })()` 立即执行函数中，内部变量不泄露到全局作用域。
