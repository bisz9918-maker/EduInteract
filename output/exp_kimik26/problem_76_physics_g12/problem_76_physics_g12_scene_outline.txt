教学图示大纲：滑块-木板模型动量守恒问题（problem_76_physics_g12）
参考原图：topic.png

============================================================
【Scene 1】初始状态（Setup）
------------------------------------------------------------
画面描述：
  - 光滑水平面（标注“光滑水平面”）。
  - 木块 A、B 并排放置在水平面上，左侧为 A，右侧为 B，二者紧密接触。
  - 小物块 C 位于 A 的左端（或 A 的上表面左端），准备向右滑动。
标注：
  - A 上方标注：m_A = 0.5 kg
  - B 上方标注：m_B = 0.3 kg
  - C 上方标注：m_0 = 0.08 kg
  - C 左侧画水平向右的速度箭头，标注：v_0 = 25 m/s
  - 三个物块用不同颜色或线型区分，便于后续跟踪。
文字说明：
  “初始时刻，C 以 v_0 = 25 m/s 的速度滑上 A 的上表面，A、B 静止。”

============================================================
【Scene 2】C 在 A 上滑动（Process 1）
------------------------------------------------------------
画面描述：
  - A、B 仍并排在一起（C 尚未滑离 A，A、B 速度相同）。
  - C 在 A 上表面中间某位置向右滑动。
  - 在 C 与 A 的接触面之间画一对摩擦力：
      * C 受到向左的滑动摩擦力 f_CA（阻碍 C 相对 A 向右运动）。
      * A 受到向右的滑动摩擦力 f_AC（作用力与反作用力）。
  - A、B 整体受到向右的力，开始向右加速；C 受到向左的力，开始减速。
标注：
  - C 的速度箭头：v_C（向右，长度略短于 v_0，表示减速）。
  - A、B 共同速度箭头：v_AB（向右，表示加速）。
  - 相对运动示意：C 相对于 A 仍向右滑动，用虚线箭头标注“相对运动方向→”。
文字说明：
  “C 在 A 上滑动时，C 减速，A 与 B 一起加速。由于 A、B 间无相对运动，二者速度相同。”

============================================================
【Scene 3】C 刚滑离 A 的临界状态（Transition / 关键状态）
------------------------------------------------------------
画面描述：
  - C 恰好到达 A 的右端（A、B 的接触面正上方或即将进入 B）。
  - 此时 C 的速度为 v_C'（待求），A 与 B 的速度为 v_A（待求，A 的最终速度）。
  - 速度箭头：
      * C：v_C'（向右）
      * A：v_A（向右）—— 此速度即为 A 的最终速度，因为此后 A 不再受水平摩擦力（水平面光滑）。
      * B：v_A（向右）—— 此时 B 仍与 A 同速。
标注：
  - 在 C 旁标注：v_C' = ? （问题 2 所求）
  - 在 A 旁标注：v_A = ? （问题 1 所求）
  - 临界位置用虚线框或高亮标出，提示“C 即将脱离 A”。
文字说明：
  “当 C 滑到 A 的右端时，C 离开 A 进入 B。此时 A 的速度达到最终值 v_A，C 的速度为 v_C'。”

============================================================
【Scene 4】C 在 B 上滑动（Process 2）
------------------------------------------------------------
画面描述：
  - A、B 已经分离（或 A 在前匀速运动，B 在后）。
  - C 位于 B 的上表面，继续向右滑动，但 B 此时也在运动。
  - 在 C 与 B 的接触面之间画摩擦力：
      * C 受到向左的滑动摩擦力 f_CB。
      * B 受到向右的滑动摩擦力 f_BC。
  - A 不受水平力，匀速向右运动（速度保持 v_A）。
  - B 在摩擦力作用下继续加速；C 继续减速。
标注：
  - A：v_A（向右，匀速）
  - B：v_B（向右，加速，箭头长度逐渐增长）
  - C：v_C（向右，减速，箭头长度继续缩短）
  - 相对运动：C 相对于 B 仍向右滑动。
文字说明：
  “C 滑上 B 后，A 以 v_A 匀速运动；B 继续加速，C 继续减速，最终 C 与 B 达到共同速度。”

============================================================
【Scene 5】最终状态（Final State）
------------------------------------------------------------
画面描述：
  - A 在左侧，以恒定速度 v_A 向右匀速运动。
  - B 与 C 在右侧，二者相对静止，一起以共同速度 v = 2.5 m/s 向右运动。
  - C 停在 B 上的某位置（可在 B 上表面中间偏左或偏右）。
标注：
  - A：v_A = ? m/s （问题 1 答案）
  - B、C 整体：v = 2.5 m/s（已知条件）
  - 各质量保持标注：m_A = 0.5 kg, m_B = 0.3 kg, m_0 = 0.08 kg
文字说明：
  “最终 C 停在 B 上，B 与 C 以 v = 2.5 m/s 共同运动，A 以 v_A 匀速运动。”

============================================================
【Scene 6】受力分析图（Free-body Diagrams）
------------------------------------------------------------
画面描述：
  分三栏分别画出 A、B、C 的受力图（隔离法）。

  (a) 木块 A：
      - 竖直向下：重力 m_A·g
      - 竖直向上：水平面支持力 N_地A，C 对 A 的压力 N_CA
      - 水平向右：C 对 A 的滑动摩擦力 f_AC
      - 水平向左：B 对 A 的弹力 N_BA（仅在 C 未滑离前存在，若需要可标出；滑离后 A 水平方向仅匀速，合外力为零）

  (b) 木块 B：
      - 竖直向下：重力 m_B·g，C 对 B 的压力 N_CB（C 在 B 上时）
      - 竖直向上：水平面支持力 N_地B
      - 水平方向：
          * C 未滑离 A 时：A 对 B 的弹力 N_AB（向右）
          * C 在 B 上时：C 对 B 的滑动摩擦力 f_BC（向右）

  (c) 物块 C：
      - 竖直向下：重力 m_0·g
      - 竖直向上：A（或 B）对 C 的支持力 N
      - 水平向左：滑动摩擦力 f（f_CA 或 f_CB）

标注：
  - 强调水平方向只有摩擦力改变水平动量（水平面光滑，无外力）。
文字说明：
  “对 A、B、C 分别进行受力分析。水平面光滑，系统水平方向合外力为零，总动量守恒。”

============================================================
【Scene 7】动量守恒关系与解题思路（Equation Map）
------------------------------------------------------------
画面描述：
  - 中央列出系统（A+B+C）水平动量守恒方程：
      m_0·v_0 = m_A·v_A + (m_B + m_0)·v
  - 标注“阶段一：C 在 A 上滑动 → A、B 共速”
      子系统（A+B+C）动量守恒：
      m_0·v_0 = (m_A + m_B)·v_A + m_0·v_C'
  - 标注“阶段二：C 滑上 B → C 与 B 最终共速”
      子系统（B+C）动量守恒：
      m_B·v_A + m_0·v_C' = (m_B + m_0)·v
  - 用箭头或流程图连接两个阶段，展示先求 v_A（由全程守恒），再求 v_C'（由阶段二守恒反推）的解题路径。
  - 右下角或左下角给出结果框：
      (1) v_A = 2.1 m/s
      (2) v_C' = 4 m/s
标注：
  - 已知量用蓝色或常规字体，未知量用红色或加粗。
  - 方程编号：Eq.1（全程）、Eq.2（阶段一）、Eq.3（阶段二）。
文字说明：
  “全过程动量守恒可直接求出 A 的最终速度 v_A；再以 B+C 为系统，利用阶段二动量守恒求出 C 滑离 A 时的瞬时速度 v_C'。”

============================================================
【Scene 8】速度-时间图像辅助说明（v-t Graph，可选）
------------------------------------------------------------
画面描述：
  - 建立 t-v 坐标系（横轴 t，纵轴 v，向右为正）。
  - 画出三条折线/曲线：
      * C 的速度曲线：从 v_0 = 25 开始，两段连续递减的斜线（先在 A 上减速，后在 B 上减速，斜率可能不同但最终斜率绝对值可能因摩擦力不同而变化；若假设摩擦系数相同则斜率相同，但通常 μ_AC 与 μ_BC 可不同）。最终 v = 2.5。
      * A 的速度曲线：从 0 开始，一段斜线上升至 v_A = 2.1，然后水平直线（匀速）。
      * B 的速度曲线：从 0 开始，第一段与 A 重合上升至 v_A = 2.1；第二段继续上升至 v = 2.5，然后与 C 重合水平。
  - 用虚线标出两个转折点：t1（C 脱离 A）、t2（C 与 B 共速）。
标注：
  - 各曲线末端标注最终速度值。
  - 斜率区域标注“受摩擦力减速/加速”。
文字说明：
  “v-t 图直观展示：C 持续减速，A 先加速后匀速，B 先与 A 同加速、后与 C 达到共同速度。”
