[图示主题与整合说明]
- 本图示主题：定量结论——击中范围、靶条件与电场力做功
- 整合的步骤/概念：
  1) 问题(1)的 y-t₀ 分段线性关系与击中范围；
  2) 问题(2) 的靶几何约束与电压上限推导；
  3) 问题(3) 的末速度统一性与动能定理求功。
- 教学价值：教师通过分步导航，按(1)(2)(3)顺序逐层展开定量结论。步骤1让学生直观看到"何时进入"决定"击中何处"；步骤2将数学范围与物理靶长对接；步骤3用 v-t 叠加图揭示"不同进入时刻、相同末速度"这一隐藏统一性，再用动能定理一锤定音。

[交互方案]

  - 「上一步」按钮：位于(250,455)，宽100×高36。点击后currentStep减1（最小为1），切换显示对应步骤组。

- 教师操作流程：
  1. 初始加载显示步骤1，教师讲解 y-t₀ 折线："进入时刻不同，竖直位移不同，在2T/3进入的粒子偏转最小，在0或T时刻进入的粒子偏转最大"。
  2. 点击「下一步」进入步骤2，教师对照装置图："最大偏转不能超过板间距的一半，否则粒子打不到靶上，由此得到电压上限"。
  3. 点击「下一步」进入步骤3，教师先让学生观察左侧 v-t 图："虽然三条曲线形状不同，但末速度完全相同"；再转到右侧动能定理："初速相同、末速相同，动能变化相同，电场力做功必然相等"。
  4. 可随时回退复习。

[技术实现]
- JS库选择：原生 SVG（矢量几何、折线、填充全部可用 SVG 精确绘制）+ MathJax（CDN 引入，用于渲染分数、下标等公式）。不引入 D3/Three.js，避免过重。
- 画布尺寸：800 × 500 px（SVG viewBox="0 0 800 500"）。
- 布局草图：
  ```
  [图示区 800×500]
  +------------------------------------------+
  |  步骤1: 单一大图(y-t₀折线，居中)          |
  |  步骤2: 左50%装置图 | 右50%推导公式       |
  |  步骤3: 左50% v-t图 | 右50%推导公式       |
  |                                          |
  |  [控件栏 y=445~495]                      |
  |       [上一步]  步骤 n/3  [下一步]       |
  +------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机：变量 `scene3_currentStep` 取值为 1/2/3。初始化显示步骤1组，隐藏步骤2、3组。
  2. 切换逻辑：`scene3-prev-btn` 与 `scene3-next-btn` 绑定 click 事件，修改 `scene3_currentStep` 后，设置三个 group 的 `display` 属性（`display="block"` / `display="none"`），并更新步骤指示器文本。
  3. 步骤2禁区斜线填充：使用 SVG `<pattern>` 定义红色斜线 pattern（patternUnits="userSpaceOnUse"，width="8" height="8"，画一条对角线），填充到禁区 rect 中，设置 fill-opacity="0.3"。
  4. 步骤1折线坐标计算：x方向550px对应T，因此2T/3对应x=150+550×2/3≈517；y方向每单位(a₀T²/18)取20px，y_max=+1对应y=220，y_min=-7对应y=380，O′线(y=0)在y=240。
  5. 步骤3 v-t折线坐标：以a₀T/3对应40px为基准。代表曲线(t₀=0)：(100,200)→(233,280)→(350,240)；参考曲线(t₀=T/3)：(100,200)→(183,240)→(283,200)→(350,240)；参考曲线(t₀=2T/3)：(100,200)→(183,160)→(350,240)。
  6. MathJax 渲染：在步骤切换后，对新显示的公式元素调用 `MathJax.typesetPromise([element])`（若使用 MathJax v3）或确保公式已预渲染为 SVG/text。为简化，也可将简单公式直接写成 Unicode/纯文本（如 qU₀T²/(18md)），但计划保留 MathJax 以支持规范中的分式与下标。
  7. 按钮状态：当 currentStep=1 时禁用「上一步」；当 currentStep=3 时禁用「下一步」（通过降低 opacity 或移除事件监听实现）。
- ID命名规范：所有交互元素 ID 必须以 `scene3-` 为前缀。例如：
  - 步骤组：`scene3-step1-group`、`scene3-step2-group`、`scene3-step3-group`
  - 按钮：`scene3-prev-btn`、`scene3-next-btn`
  - 状态文本：`scene3-step-indicator`
  - 获取元素严格使用 `document.getElementById`，禁止全局 class 查询，避免多场景合并时跨场景污染。
- IIFE隔离：所有 JavaScript 包在 `(function() { ... })()` 中执行，内部变量不泄露全局作用域。
