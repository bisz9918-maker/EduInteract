[图示主题与整合说明]
- 本图示主题：导体棒在磁场中运动时的等效电路与受力平衡分析
- 整合的步骤/概念：
  1) b棒在磁场中时的等效电路与受力平衡；
  2) a棒在磁场中时的等效电路与受力平衡；
  3) 联立两状态方程消去 B²L²，推导速度比 v_a:v_b = 4:3。
- 教学价值：教师通过分步导航，先让学生观察单根棒在磁场中的电路结构与受力，再对比两状态的关键差异（总电阻不同），最后演示联立消元得到速度比，逻辑递进清晰，避免信息过载。

[视觉元素清单]
- 导轨：黑色竖直线段，线宽 2px，表示光滑金属导轨
- 导体棒：水平线段，线宽 6px（在磁场中）或 3px（在下方导轨），颜色区分 a（#c62828 红色）与 b（#2e7d32 绿色）
- 磁场区域：灰色虚线框（#888888），内部填充 × 符号表示垂直纸面向里的磁场
- 电阻符号：矩形，定值电阻 R 为棕色（#8B4513），a 相关电阻为红色，b 相关电阻为绿色
- 电源符号：竖直方向的长短线交替组，颜色蓝色（#1565c0），标注 ε=BLv
- 电流箭头：蓝色（#1565c0）箭头沿导线方向
- 受力箭头：重力向下红色（#c62828），安培力向上蓝色（#1565c0）
- 公式文本：黑色主体，关键数值按对象着色（a相关红色，b相关绿色，结果蓝色 #1565c0）
- 背景：#ffffff，所有文字无阴影

[技术实现]
- JS库选择：原生 SVG（所有图形均为几何形状、线段、矩形、文本，SVG最为直接，无需引入外部库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  标题（居中，y=22）                               |
  |  步骤名（居中，y=44）                             |
  |  +------------------+  +------------------------+ |
  |  | 左侧面板         |  | 右侧面板               | |
  |  | (导轨+受力图)    |  | (等效电路图)           | |
  |  | x:30~340         |  | x:370~770              | |
  |  | y:50~280         |  | y:50~280               | |
  |  +------------------+  +------------------------+ |
  |  +----------------------------------------------+ |
  |  | 公式推导区 (x:40~760, y:295~430)             | |
  |  +----------------------------------------------+ |
  |        [◀ 上一步]    [下一步 ▶]                  |
  |              步骤 X / 3                          |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：变量 `currentStep` ∈ {0,1,2,3}，初始为0。每步对应一个 SVG `<g>` 分组（id="scene2-step0-group" 等），通过设置 `display="none"` 或 `display="block"` 切换可见性。
  2. 按钮状态管理：在 `updateStep()` 函数中，根据 currentStep 设置上一步/下一步按钮的 `disabled` 属性与透明度，更新步骤指示器文本。
  3. 坐标计算：所有坐标硬编码为上述坐标表中的精确值，不使用动态计算，确保代码 agent 可直接复制。
  4. 动画曲线：分步切换不使用过渡动画（避免拖慢课堂节奏），直接显示/隐藏对应分组。
  5. 事件绑定：按钮通过 `document.getElementById('scene2-btn-prev').addEventListener('click', ...)` 绑定，函数内部修改 currentStep 并调用 updateStep()。
  6. 上标/下标：SVG `<text>` 中使用 `<tspan>` 实现，如 B² 写作 `<tspan>B</tspan><tspan dy="-5" font-size="10">2</tspan><tspan dy="5"> </tspan>`；下标如 R_总b 使用正常大小写 `R_总b` 或 tspan 微调。
  7. 电流箭头与受力箭头：使用 SVG `<path>` 或 `<line>` + `<polygon>` 绘制箭头头部，颜色按规格设置。
  8. 磁场 × 符号：使用 `<text>` 元素放置 "×"，灰色 (#888888)，在磁场区域内按 15px 间隔网格排列。
- ID 命名规范：所有交互元素与分组 ID 必须以 `scene2-` 为前缀，例如：
  - 分组：`scene2-step0-group`, `scene2-step1-group`, `scene2-step2-group`, `scene2-step3-group`
  - 图形：`scene2-rail-left`, `scene2-rail-right`, `scene2-mag-field`, `scene2-rod-a`, `scene2-rod-b`
  - 电路：`scene2-circuit-power`, `scene2-circuit-res-rb`, `scene2-circuit-res-ra`, `scene2-circuit-res-r`
  - 按钮：`scene2-btn-prev`, `scene2-btn-next`
  - 指示器：`scene2-step-indicator`
  - JS 中严格使用 `document.getElementById` 获取元素，禁止全局 class 选择器，避免多场景合并时跨场景污染。
- IIFE 隔离：所有 JavaScript 代码包裹在 `(function() { ... })();` 中，变量不污染全局作用域。
