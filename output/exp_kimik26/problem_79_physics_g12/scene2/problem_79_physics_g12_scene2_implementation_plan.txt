[图示主题与整合说明]
- 本图示主题：第二问运动过程与 v-t 图像综合分析
- 整合的步骤/概念：
  1. 地面参考系俯视图——直观展示木板与物块在水平面上的绝对位置变化；
  2. F 作用阶段（0~t）——俯视图与 v-t 图同步，展示两者产生相对滑动；
  3. 撤去 F 瞬间（t 时刻）——在俯视图与 v-t 图中同时标记该关键时刻；
  4. 撤 F 后至共速（t~2.5t）——俯视图展示木板减速、物块加速直至共速，v-t 图展示蓝线转折；
  5. 临界条件——v-t 图中两块相对位移面积填充高亮，联立方程求解最小作用时间。
- 教学价值：教师通过分步导航，可逐层揭示"运动动画"与"v-t 图像"的对应关系，帮助学生建立"图像面积=相对位移"的直观认知，并在最后一步集中呈现临界方程与结论。

[分步序列]
- 步骤0（初始状态）：
  · 俯视图：木板位于 x=150~278，物块圆心位于木板右端 (278,97)；显示 M、m、L=1.6m、F 箭头及标签；地面线与阴影固定。
  · v-t 图：仅显示坐标轴（含横纵轴标签）、原点高亮小圆点、网格虚线；速度曲线隐藏。
  · 步骤说明："初始状态：木板与物块静止于光滑水平面"

- 步骤1（F 作用阶段 0~t）：
  · 俯视图：木板向右平移至 x=227~355（+77px），物块向右平移至圆心 (304,97)（+26px）；视觉上物块相对木板向左滑动。
  · v-t 图：红线从 (180,410) 绘制至 (380,370)；蓝线从 (180,410) 绘制至 (380,290)；标注 am=1、aM1=3 出现；横轴下方标注绿色 "F作用"。
  · 步骤说明："F作用阶段：a_m = 1 m/s²，a_M = 3 m/s²，两者产生相对滑动"

- 步骤2（撤 F 瞬间 t 时刻）：
  · 俯视图：位置保持步骤1状态；新增竖直虚线标记线 (304,150)-(304,168) 标记物块此时位置。
  · v-t 图：在 x=380 处新增竖直辅助虚线 (380,410)-(380,290)；标注 v_m=t、v_M=3t 出现。
  · 步骤说明："撤去F瞬间：标记t时刻两物体速度，准备进入下一阶段"

- 步骤3（撤 F 后至共速 t~2.5t）：
  · 俯视图：木板继续向右平移至 x=438~566（总位移 +288px），物块平移至圆心 (438,97)（总位移 +160px）；物块圆心恰好与木板左端对齐，示意"到达木板左端"。
  · v-t 图：红线从 (380,370) 延长至 (680,310)；蓝线从 (380,290) 转折绘制至 (680,310)；标注 a_M2=-1/3、2.5t（t共=2.5t）出现；横轴下方绿色标注替换为 "撤去F"。
  · 步骤说明："撤F后阶段：木板减速、物块加速，直至共速 v = 2.5t"

- 步骤4（临界条件）：
  · 俯视图：位置保持步骤3最终状态；右侧新增绿色文字 "物块恰好到达木板左端" (480,130)。
  · v-t 图：Δx1 三角形区域（顶点 180,410 / 380,290 / 380,370）与 Δx2 三角形区域（顶点 380,370 / 380,290 / 680,310）填充绿色（20%透明度）；标注 Δx1、Δx2；右下角依次列出结论公式："Δx = Δx₁ + Δx₂ = L = 1.6 m" (520,345)、"2.5t² = 1.6" (520,370)、绿色高亮 "t_min = 0.8 s" (520,395)。
  · 步骤说明："临界条件：相对位移总面积等于板长，解得最小作用时间 0.8 s"

[交互方案]
- 交互类型：分步按钮导航（◀ 上一步 / 下一步 ▶）
- 控件说明：
  · 「上一步」按钮：位于 (250,450)，宽 100px，高 32px；点击回退到上一状态，所有元素逆向切换。
  · 「下一步」按钮：位于 (450,450)，宽 100px，高 32px；点击推进到下一状态，触发该步骤元素的显示/移动/绘制动画。
  · 步骤说明文字：位于画布底部中心 (400,485)，随当前步骤动态更新，字体 14px，颜色 #333333。
- 教师操作流程：
  1. 教师展示步骤0，说明初始条件（光滑水平面、板长、质量、摩擦因数、拉力）。
  2. 点击「下一步」进入步骤1，讲解 F 作用时两者加速度不同，观察俯视图相对滑动与 v-t 图斜率差异。
  3. 点击「下一步」进入步骤2，强调"撤去 F"这一关键时刻，对应 v-t 图中竖直辅助线。
  4. 点击「下一步」进入步骤3，观察木板减速、物块继续加速，v-t 图蓝线转折，直至共速。
  5. 点击「下一步」进入步骤4，聚焦 v-t 图两块面积，建立"面积之和 = 相对位移 = L"的方程，得出 t_min。
  6. 可随时点击「上一步」回退，复习任意阶段。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无外部库）。理由：本场景以几何图形、折线与多边形填充为主，SVG 的 path、polyline、polygon 可直接表达所有视觉元素；状态切换逻辑简单，原生 JS 足以驾驭，无需引入 D3 等重型库。
- 画布尺寸：800 × 500 px（SVG viewBox="0 0 800 500"）
- 布局草图：
  ```
  +--------------------------------------------------+
  |  俯视图区 (y=30~170)                               |
  |  [地面阴影]                                        |
  |       [==========木板==========]●                  |
  |            M                m  F→                  |
  |            └────L=1.6m────┘                       |
  +--------------------------------------------------+
  |  v-t 图区 (y=190~430)                              |
  |  v↑                                                |
  |   │    ╱ 蓝线(M)                                   |
  |   │   ╱  ╱                                         |
  |   │  ╱  ╱  红线(m)                                 |
  |   │ ╱  ╱╱                                          |
  |   │╱  ╱                                            |
  |   └──────────────→ t                               |
  |        t   2.5t                                    |
  +--------------------------------------------------+
  |  [◀ 上一步]      步骤说明文字      [下一步 ▶]       |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `let currentStep = 0;` 记录当前步骤（0~4）。按钮点击时更新 currentStep，调用 `renderStep()` 统一渲染。
  2. 元素显隐控制：所有可能随步骤变化的 SVG 元素预先在 DOM 中创建，通过 `setAttribute('display', 'none'/'block')` 或 CSS `opacity` + `transition` 控制显隐，避免频繁创建销毁。
  3. 位移动画：俯视图木板与物块的平移使用 SVG `transform="translate(dx,0)"`，配合 CSS `transition: transform 0.5s ease-out` 实现平滑移动。
  4. 画线动画：v-t 速度曲线使用 `stroke-dasharray` 与 `stroke-dashoffset` 动画。预先计算每条折线的 `getTotalLength()`，步骤切换时从 `offset=length` 动画到 `offset=0`，持续 0.5s。
  5. 面积填充动画：步骤4 中两个 polygon 的填充通过 CSS `transition: opacity 0.4s` 从 `opacity: 0` 过渡到 `opacity: 0.2`。
  6. 事件绑定：上一步/下一步按钮绑定 `click` 事件，在事件处理器中检查边界（currentStep ≤ 0 时禁用上一步，currentStep ≥ 4 时禁用下一步）。
  7. 坐标计算：俯视图位移比例固定为 80 px/m（L=1.6m 对应 128px）。v-t 图横轴 500px 对应 2.5t，纵轴 120px 对应速度 3t，确保斜率视觉比例与物理加速度比例一致（3:1 与 1:3）。
- ID 命名规范：所有交互元素 ID 必须以 `scene2-` 为前缀。例如：
  · `scene2-plank`（木板矩形）
  · `scene2-block`（物块圆点）
  · `scene2-vt-red-line`（红线）
  · `scene2-vt-blue-line`（蓝线）
  · `scene2-area-dx1`（Δx1 填充区）
  · `scene2-area-dx2`（Δx2 填充区）
  · `scene2-btn-prev`（上一步按钮）
  · `scene2-btn-next`（下一步按钮）
  · `scene2-step-text`（步骤说明文字）
  JS 中严格使用 `document.getElementById('scene2-xxx')` 获取元素，禁止跨场景选择器。
- IIFE 隔离：所有 JavaScript 代码包裹在 `(function() { ... })();` 中，避免全局变量污染，确保多场景合并时互不干扰。
