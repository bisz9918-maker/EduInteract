[图示主题与整合说明]
- 本图示主题：两种浮力情境的装置结构与受力分析
- 整合的步骤/概念：
  1) 左图（甲+乙绳连）与右图（甲+丙叠放）的装置结构展示；
  2) 甲物块排水体积的高亮标注（V_排 = V_甲）；
  3) 左图甲、乙的隔离受力分析（重力、浮力、绳拉力）；
  4) 右图甲、丙的隔离受力分析（重力、浮力、压力/支持力）；
  5) 两图中甲所受浮力的公式对比，验证选项A正确。
- 教学价值：教师通过分步导航，可按照"认识装置→标注排水体积→隔离受力分析→对比结论"的认知递进讲解，随时回退复习，避免信息过载。

[分步序列]
- 初始状态（步骤0）：显示左右两装置的基础结构
  → 可见元素：水面线（含波浪）、水下虚线、四物块（甲左、乙左、甲右、丙右）、绳子、物块标签（甲/乙/丙）、水面标签
  → 隐藏元素：所有高亮层、受力箭头、力标签、公式结论
  → 教学用途：让学生先识别装置结构，明确甲、乙、丙位置及水面关系

- 步骤1：点击「下一步」→ 高亮排水体积
  → 新增元素：左右两图甲物块的蓝色半透明高亮层（#1565c0,opacity=0.2）；左右标注"V_排 = V_甲"（14px蓝色）
  → 教学用途：强调两图中甲均完全浸没，排开水体积等于甲自身体积，为后续浮力计算铺垫

- 步骤2：点击「下一步」→ 左图隔离受力分析
  → 新增元素：
    · 甲受力：F_甲1（蓝向上，中心→上方）、G_甲（红向下，偏左）、T（绿向下，偏右）
    · 乙受力：F_乙（蓝向上，中心→上方）、G_乙（红向下，偏左）、T（绿向上，偏右）
    · 对应6个力标签
  → 教学用途：对左图进行隔离法分析，展示甲受三力平衡、乙受三力平衡，绳拉力T为内力对

- 步骤3：点击「下一步」→ 右图隔离受力分析
  → 新增元素：
    · 甲受力：F_甲2（蓝向上，中心→上方）、G_甲（红向下，偏左）、N（绿向下，偏右，丙对甲的压力）
    · 丙受力：G_丙（红向下，偏左）、N（绿向上，偏右，甲对丙的支持力）
    · 对应5个力标签
  → 教学用途：对右图进行隔离法分析，展示甲受三力平衡、丙受二力平衡，支持力与压力为作用力反作用力

- 步骤4（最终步骤）：点击「下一步」→ 浮力对比与结论
  → 新增元素：
    · 左图下方公式："F_甲1 = ρ_水·g·V_甲"
    · 右图下方公式："F_甲2 = ρ_水·g·V_甲"
    · 中间结论："∴ F_甲1 = F_甲2"（18px加粗）
    · 下方判定："选项A正确"（16px绿色）
  → 教学用途：通过公式 explicitly 对比，验证两图中甲所受浮力相等，选项A说法正确

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  · 「◀ 上一步」按钮：位于(270,455)，宽100×高28。点击后回退到上一状态，步骤0时禁用。
  · 「下一步 ▶」按钮：位于(430,455)，宽100×高28。点击后进入下一状态，步骤4时禁用（或变为"完成"）。
  · 步骤指示器：位于(400,442)，显示"步骤 1/5"~"步骤 5/5"，提示当前进度。
- 教师操作流程：
  1) 教师打开图示，学生观察步骤0的左右装置；
  2) 点击「下一步」进入步骤1，讲解甲完全浸没，V_排 = V_甲；
  3) 点击「下一步」进入步骤2，对左图甲、乙逐一画受力箭头，讲解三力平衡；
  4) 点击「下一步」进入步骤3，对右图甲、丙逐一画受力箭头，讲解压力与支持力；
  5) 点击「下一步」进入步骤4，展示浮力公式对比，得出F_甲1=F_甲2，验证选项A正确；
  6) 可随时点击「上一步」回退到任意步骤复习。

[技术实现]
- JS库选择：原生SVG（简单几何、箭头、文字首选，无需引入外部库，减少依赖）
- 画布尺寸：800 × 500 px（固定画布，控件栏位于SVG内底部y=440~490区域）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |  左图装置区 (x:120~280)      右图装置区 (x:520~680) |
  |  ~~~~~~~~~~~~~~~~~~~~~~~~    ~~~~~~~~~~~~~~~~~~~~~  | y=150 水面线
  |  ┌────┐                      ┌──┐                 |
  |  │ 甲 │                      │丙│                 |
  |  └────┘                      └──┘                 |
  |  ┌────┐                      ┌────┐               |
  |  │ 乙 │                      │ 甲 │               |
  |  └────┘                      └────┘               |
  |  ～～～～～～～～～～        ～～～～～～～～～～  | 水下虚线
  |                                                   |
  |         [公式与结论文字区，y=360~430]              |
  |                                                   |
  |    [◀ 上一步]    步骤 1/5    [下一步 ▶]           | y=440~490 控件区
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1) 状态机设计：定义变量 `let currentStep = 0;`（范围0~4）。每一步对应一个SVG <g>组（id="scene1-step0"~"scene1-step4"），组内包含该步所有新增元素。切换步骤时，通过设置对应组的 `display` 属性（"block"/"none"）控制显隐。
  2) 箭头绘制：在SVG <defs>中预定义三个<marker>（id="scene1-arrow-blue"/"red"/"green"），viewBox="0 0 10 10"，refX="9" refY="5"，填充对应颜色。受力箭头使用<line>+marker-end实现。
  3) 坐标计算：所有坐标均为绝对像素值，严格按「布局坐标表」执行。箭头长度统一：向上箭头约70px，向下箭头约40~50px，确保视觉上长短区分（浮力最长，重力次之，拉力/压力最短）。
  4) 动画曲线：本场景为静态分步切换，无需CSS动画或JS插值。步骤切换为即时显示/隐藏，保证教师控制的即时性。
  5) 事件绑定：上一步/下一步按钮绑定click事件，调用 `updateStep(newStep)` 函数。函数内：
     - 边界检查（0≤newStep≤4）；
     - 遍历所有step组设置display；
     - 更新步骤指示器文字；
     - 更新按钮disabled状态（步骤0禁用「上一步」，步骤4禁用「下一步」）。
  6) 文字下标处理：公式中的下标（如F_甲1）直接使用字符串"F_甲1"；如需更精细排版，可用<tspan baseline-shift="sub" font-size="10">实现，但本场景直接字符串即可保证清晰度。
  7) 防遮挡：所有物块名称标签（甲/乙/丙）添加属性 `paint-order="stroke" stroke="#ffffff" stroke-width="3px" stroke-linejoin="round"`，确保受力箭头穿过物块中心时文字仍清晰可读。
- ID命名规范：所有交互元素ID必须以 `scene1-` 为前缀。例如：
  - 物块：`scene1-block-jia-left`、`scene1-block-yi`、`scene1-block-jia-right`、`scene1-block-bing`
  - 步骤组：`scene1-step0`、`scene1-step1`、...、`scene1-step4`
  - 按钮：`scene1-btn-prev`、`scene1-btn-next`
  - 步骤指示：`scene1-step-indicator`
  - 箭头marker：`scene1-arrow-blue`、`scene1-arrow-red`、`scene1-arrow-green`
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免多场景合并时的全局变量污染。内部通过 `document.getElementById` 获取元素，不使用 `querySelectorAll` 配合全局class，防止跨场景选择器干扰。
