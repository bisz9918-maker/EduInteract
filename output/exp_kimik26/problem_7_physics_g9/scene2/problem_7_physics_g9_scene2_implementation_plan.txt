[图示主题与整合说明]
- 本图示主题：平衡方程推导与选项验证（浮力与受力分析）

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「上一步」按钮：位置(250, 448)，90×30px。作用：回退到上一个推导步骤，用于教师复习或学生跟不上的情况。步骤0时disabled。
  2. 「下一步」按钮：位置(460, 448)，90×30px。作用：推进到下一个推导步骤，展示新的方程变形或结论。步骤4时disabled。
  3. 步骤指示器：位置(400, 467)。作用：显示当前步骤编号（1/5~5/5），让学生明确进度。
- 教师操作流程：
  1. 教师打开图示，学生看到左右两图的平衡方程（步骤0）。
  2. 教师点击「下一步」，出现推导结论"T = G_丙"，同时选项B卡片变绿。教师讲解：两式相减消去G_甲，得到拉力等于丙的重力，故B正确。
  3. 教师点击「下一步」，出现代入后的方程和质量比较，选项D卡片变绿。教师讲解：因为乙受到浮力，所以乙的重力大于丙的重力，即乙质量更大，D正确。
  4. 教师点击「下一步」，出现密度比较，选项C卡片变红。教师讲解：因为拉力大于0，乙的重力大于乙的浮力，说明乙的密度大于水，所以C说"乙密度比水小"是错误的。
  5. 教师点击「下一步」，出现最终总结，选项A卡片变绿（A已在Scene1验证）。教师总结：本题选C。
  6. 教师可随时点击「上一步」回退到任意步骤重新讲解。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：本场景以文本公式、矩形卡片和简单状态切换为主，无需复杂绘图或数据可视化库；原生SVG的<text>+<tspan>可精确控制公式下标和颜色，原生JS足以处理分步状态机。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |          平衡方程推导与选项验证 (y=0~40)          |
  |  +--------------------+  +--------------------+   |
  |  | 左图（甲+乙）      |  | 右图（甲+丙）      |   |
  |  | F_甲1 = G_甲 + T   |  | F_甲2 = G_甲 + G_丙|   |
  |  | G_乙 = F_乙 + T    |  |                    |   |
  |  | [G_乙 = F_乙+G_丙] |  |                    |   |
  |  | [G_乙 > F_乙]      |  |                    |   |
  |  +--------------------+  +--------------------+   |
  |  x=35~365              x=435~765                 |
  |              y=50~240                            |
  |                                                  |
  |       +------------------------------+            |
  |       | 推导结论区 (y=255~350)       |            |
  |       | T = G_丙 / G_乙>G_丙 / ...   |            |
  |       +------------------------------+            |
  |                                                  |
  |  [A]      [B]      [C]      [D]                  |
  ```

- 关键实现要点：
  1. **状态机设计**：定义 `var currentStep = 0;`（范围0~4），`updateScene(step)` 函数统一控制所有元素的显示/隐藏和样式。避免分散的状态修改。
  2. **公式下标实现**：使用SVG `<tspan>` 的 `dy` 属性实现下标。示例：

  3. **元素显隐控制**：所有步骤相关元素（左公式③④、推导结论、高亮条、卡片状态文本）初始设置 `opacity="0"` 或 `display="none"`。`updateScene` 中通过 `setAttribute('opacity', '1')` 或 `style.display = 'block'` 控制。建议统一使用opacity配合CSS transition实现淡入效果：`transition: opacity 0.3s ease`。
  4. **卡片状态切换**：卡片状态变化通过修改rect的stroke、fill、fill-opacity属性，以及状态text的textContent和fill属性实现。正确状态：stroke=#2e7d32, fill=#2e7d32, fill-opacity=0.1；错误状态：stroke=#c62828, fill=#c62828, fill-opacity=0.1。

  6. **步骤4脉冲动画**：对卡片C使用SVG SMIL动画或JS requestAnimationFrame实现轻微缩放脉冲，强调错误选项。示例SMIL：`<animateTransform attributeName="transform" type="scale" values="1;1.03;1" dur="0.6s" repeatCount="1"/>`。注意transform-origin需设为卡片中心(492, 397)。
  7. **事件绑定**：使用 `element.addEventListener('click', ...)` 绑定按钮点击。所有交互逻辑包在IIFE中。
- **ID命名规范**：所有交互元素ID必须以 `scene2-` 为前缀。例如：
  - 左公式①：`scene2-formula-left-1`
  - 推导结论1：`scene2-derivation-1`
  - 卡片B背景：`scene2-card-B-bg`
  - 卡片B状态：`scene2-card-B-status`
  - 上一步按钮：`scene2-btn-prev`
  - 下一步按钮：`scene2-btn-next`
