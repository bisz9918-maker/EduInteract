[图示主题与整合说明]
- 本图示主题：选手圆周摆动过程及最低点受力分析

[分步序列]
- 步骤0「初始状态」：显示岸边缘、O点、A点质点、绳OA、竖直参考线(虚线)、水面及填充、浮台。标注O、A、m=60kg、l=2m、α=53°、H=3.8m、浮台。此状态展示题目全部已知几何条件。
- 步骤1「摆动轨迹」：隐藏A点质点，显示B点质点、绳OB(实线)、圆弧AB(蓝色#1565c0)。新增标签B。圆弧AB以stroke-dashoffset动画画出（0.5s），质点在B点淡入。教师可讲解圆周运动轨迹。
- 步骤2「能量守恒」：新增高度差双箭头(绿色虚线，从x=70,y=164到y=212)及标签Δh=0.8m。右侧显示能量公式组：
  机械能守恒
  mgl(1−cosα) = ½mv²
  60×10×2×(1−0.6) = ½×60×v²
  v² = 16 (m²/s²)
  v = 4 m/s
  其中"v²"与"v = 4 m/s"用#1565c0高亮。教师讲解机械能守恒及最低点速度。
- 步骤3「受力分析」：在B点显示三个箭头：拉力F向上（红色#c62828）、重力mg向下（绿色#2e7d32）、速度v水平向右（蓝色#1565c0）。对应标签F、mg、v=4m/s。强调O到B连线为圆心方向（向心力方向）。教师讲解最低点受力与向心力来源。
- 步骤4「计算结果」：右侧显示向心力方程组：
  向心力方程
  F − mg = mv²/l
  F − 600 = 60×16/2
  F = 1080 N
  最终结果"F = 1080 N"以#c62828、20px、加粗高亮显示。教师给出最终答案。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「上一步」按钮：位于(280,455)，宽80×高30。点击回退到上一状态，在步骤0时禁用（opacity 0.4）。
  2. 「下一步」按钮：位于(440,455)，宽80×高30。点击前进到下一状态，在步骤4时禁用（opacity 0.4）。
  3. 步骤标题文本：位于(400,450)，显示当前步骤名称（如"步骤1：摆动轨迹"）。
- 教师操作流程：教师打开图示后处于步骤0，向学生展示题目条件；点击「下一步」依次展示摆动轨迹、能量守恒推导、受力分析、最终计算结果；可随时点击「上一步」回退复习关键步骤。

[技术实现]
- JS库选择：原生 SVG + 原生 JavaScript。理由：本场景为静态几何图形与分步显隐，无需复杂数据驱动或3D，原生SVG性能最佳且可控性高。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------------+
  |  O●                                                    |
  |  |\  l=2m                                             |
  |  | \                                                  |
  |  |  \                                                 |
  |  |   A● m=60kg                                        |
  |  |    \                                               |
  |  |     \  圆弧AB（蓝）                                |
  |  |      \                                             |
  |  |       B●  ←受力分析箭头(F↑,mg↓,v→)                |
  |  |                                                    |
  |岸|  水面 ======================================= 浮台  |
  |  |                                                    |
  |  |         [右侧公式区：能量/向心力/结果]              |
  +--------------------------------------------------------+
  |        [◀上一步]   步骤标题   [下一步▶]                |
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：维护变量 `currentStep`（0~4）。每步切换时，通过设置对应 SVG `<g>` 组的 `display` 属性（`block`/`none`）控制显隐。
  2. 元素分层：基础层（岸、水面、O点、绳OA等始终显示）+ 5个步骤组（`scene1-step0`~`scene1-step4`），每组包含该步骤新增的元素。注意步骤1需隐藏A点质点、显示B点质点。
  3. 圆弧动画：步骤1的圆弧AB使用 SVG `stroke-dasharray` 与 `stroke-dashoffset` 配合 CSS transition（0.5s ease）实现描边动画。
  4. 按钮状态：在 `showStep(n)` 函数中，根据 `n` 设置 `disabled` 与 `opacity`：n===0 时禁用「上一步」，n===4 时禁用「下一步」。
  5. 公式高亮：步骤2中 v²/v 用 `<tspan fill="#1565c0">` 包裹；步骤4结果用单独 `<text>` 元素，fill="#c62828"，font-weight="bold"。
  6. 坐标计算验证：绳长 l=120px（比例 1m=60px），角度53°，A点坐标(200-120×0.8, 92+120×0.6)=(104,164)，B点(200,212)，高度差48px（对应0.8m），与题目数据完全吻合。
- ID命名规范：所有交互元素ID必须以 `scene1-` 为前缀，例如 `scene1-arc-ab`、`scene1-arrow-f`、`scene1-btn-prev`、`scene1-step-title` 等。JS中严格使用 `document.getElementById` 获取元素，禁止全局 class 查询以避免多场景合并污染。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，对外不暴露任何变量。
