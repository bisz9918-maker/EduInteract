problem_81_physics_g12

场景导航：Scene 1 | Scene 2

题目原文

如图所示，A、B两物体的质量都为m，拉A物体的细线与水平方向的夹角为30°时处于静止状态，不考虑摩擦力，设弹簧的劲度系数为k。若悬线突然断开后，A在水平面上做周期为T的简谐运动，当B落地时，A恰好将弹簧压缩到最短，求：
（1）A振动时的振幅；
（2）B落地时的速度。

题目分析

本题是力学综合问题，涉及三个核心知识点：静力学平衡、水平弹簧振子的简谐运动、自由落体运动。解题的关键在于把握两个"衔接"：

  1. 断开前的静力学平衡决定了弹簧的初始伸长量，而这个伸长量恰好是断开后简谐运动的振幅；
  2. "当B落地时，A恰好将弹簧压缩到最短"揭示了A、B两物体运动的时间关联——B的自由落体时间等于A从最右端运动到最左端的时间（半个周期）。

整体讲解思路

  1. 先带领学生分析断开前的平衡状态，通过隔离法分别对A、B列平衡方程，求出弹簧初始弹力与伸长量；
  2. 再分析断开后的运动：A在水平方向仅受弹簧弹力，做简谐运动，平衡位置在弹簧原长处；B断开瞬间初速度为零，做自由落体；
  3. 利用时间同步条件 t_B = T/2，结合周期公式 T = 2π√(m/k)，求出振幅与落地速度。

图示规划说明

  • 图示1（SCENE_1）：展示初始平衡状态下的装置几何与受力分析，整合A的四力平衡、B的两力平衡及弹簧伸长量推导，帮助学生建立"初始伸长量即振幅"的直观认识。
  • 图示2（SCENE_2）：展示悬线断开后A的简谐振动全过程与B的自由落体过程，通过分步时间轴建立两者的同步关系，最终呈现振幅与落地速度的求解。
步骤 1/5

教学说明：初始平衡状态（对应SCENE_1）

教师可先让学生观察装置图，提问："绳子拉力与水平方向夹角30°，这个角度在图中的哪个位置？"引导学生确认几何关系。

进入受力分析时，强调隔离法的应用顺序：

  1. 先隔离B，因为B只受两个力且竖直，最容易得出 T = mg；
  2. 再隔离A，水平方向仅受弹簧弹力Fs与拉力水平分量Tcos30°，由平衡得 Fs = Tcos30° = mgcos30°；
  3. 竖直方向 N + Tsin30° = mg，可顺带求出支持力N = mg/2，虽非本题必需，但有助于学生建立完整的受力观念。

关键过渡句："弹簧此时的伸长量x₀由胡克定律给出 x₀ = F_s/k = √3 mg/(2k)。请同学们记住这个量——一旦悬线断开，A将在弹簧弹力作用下振动，而这个x₀恰恰就是振动的振幅。"

讲解时注意用蓝色高亮跟踪A的相关量，红色高亮跟踪B的相关量，绿色高亮突出最终结论，形成颜色记忆锚点。

步骤 1/5

教学说明：断开后运动过程（对应SCENE_2）

本图示的核心教学目标是让学生建立"同一时间内两个不同运动"的关联。教师讲解时可按以下步骤引导：

  1. 明确运动性质：绳子断开后，A在水平方向仅受弹簧弹力，且平衡位置恰为弹簧原长（因为无摩擦），故做简谐运动；B只受重力，从静止开始自由落体。
  1. 确定振幅：A在断开瞬间位于最右端，相对平衡位置（原长）的位移恰为初始伸长量x₀，且初速度为零，因此 振幅A = x₀ = √3 mg/(2k)。利用已知周期T = 2π√(m/k)，消去m/k，得到用T表示的振幅 A = √3 gT²/(8π²)。
  1. 建立时间关系：简谐运动具有对称性，从最大伸长（最右端）到最大压缩（最左端）恰好经过半个周期，即 t = T/2。题目条件"B落地时A恰好将弹簧压缩到最短"意味着B的自由落体时间恰好等于A运动半个周期的时间。
  1. 求解落地速度：B做自由落体，初速为零，落地速度 v = gt = gT/2。若考虑周期性多解，可补充 v = (2n+1)gT/2（n = 0,1,2,...），但中学阶段通常取n = 0。
  1. 常见误区提醒：学生容易误认为A的平衡位置仍在弹簧初始伸长处，需强调"平衡位置是合外力为零的位置"，断开后水平方向只有弹簧力，故原长位置才是平衡位置。

总结：完整解答与课堂建议

完整解答步骤

  1. 断开前，对B受力分析：T = mg。
  2. 对A水平方向：F_s = Tcos30° = mgcos30° = √3 mg/2。
  3. 由胡克定律：x₀ = F_s/k = √3 mg/(2k)。断开后A以弹簧原长为平衡位置做简谐运动，初始位移即为振幅，故 振幅A = √3 mg/(2k) = √3 gT²/(8π²)。
  4. A从最大伸长到最大压缩用时t = T/2，由题意此时间等于B落地时间。
  5. B自由落体：v = gt = gT/2（一般解v = (2n+1)gT/2）。

课堂讲解建议

  • 在SCENE_1中，务必让学生自己动手画出A的受力图，再与图示核对，强化"斜向拉力有水平分量"这一直觉。
  • 在SCENE_2中，建议先暂停在步骤0，让学生预测："A会往哪边运动？B会怎样？"再逐步播放，增强参与感。
  • 强调"恰好"二字在物理题中的常见含义——时间、位置或速度的精确匹配，本题中是时间同步。
  • 如果时间允许，可在SCENE_2步骤4中简要讨论n的物理意义：B可能在A完成多次振动后才落地，但题目未附加限制，故通常取最简单情形n = 0。
