[图示主题与整合说明]
- 本图示主题：悬线断开后物体A的简谐振动与物体B的自由落体运动之时间同步关系
- 整合的步骤/概念：
  1) 断开瞬间(t=0)A位于弹簧最大伸长处（振幅位置）、B位于初始高度；
  2) t=T/4时A向左经过平衡位置（弹簧原长）、B下落H/4；
  3) t=T/2时A到达左侧最大压缩处、B恰好落地；
  4) 由同时性得到B落地时间t=T/2，进而推导振幅A与落地速度v；
  5) 多解提示（n个全振动+半周期）。
- 教学价值：教师通过分步导航精确控制节奏，在同一画面中横向对比A的水平振动与B的竖直下落，利用时间轴强化“同时性”这一核心物理条件，并在最后一步集中呈现公式结论。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「上一步」按钮：位于(260,455)，宽90×高30，点击回退至上一状态，第一步时禁用
  2. 「下一步」按钮：位于(450,455)，宽90×高30，点击推进至下一状态，最后一步时禁用
  3. 步骤指示器：位于(360,485)，显示当前步骤序号与总步数（如“步骤 1/5”）
- 教师操作流程：
  1. 教师加载图示，首先呈现步骤0（t=0），向学生说明“悬线断开瞬间A位于弹簧最大伸长处，速度为零；B静止于高度H”
  2. 点击「下一步」进入步骤1，强调“A经过T/4到达平衡位置，同时B下落H/4”
  3. 点击「下一步」进入步骤2，强调“再经过T/4，A到达左侧最大压缩处，B恰好落地——关键的同时性”
  4. 点击「下一步」进入步骤3，展示公式结论，推导振幅与落地速度
  5. 点击「下一步」进入步骤4，补充多解提示，拓展学生思维
  6. 可随时回退复习某一步的时空对应关系

[技术实现]
- JS库选择：原生 SVG + 原生 JavaScript。理由：本场景以几何图形、状态切换和简单箭头为主，无复杂函数绘图或3D需求，原生SVG性能最佳且无需额外CDN依赖。
- 画布尺寸：800 × 500 px（固定），控件栏通过position:absolute叠加在SVG内部底部，不撑高容器。
- 布局草图（ASCII）：
  ```
  800×500 画布
  +----------------------------------------------------------+
  |  A运动区(左)          |  B下落区(右)                     |
  |  墙 弹簧 A[A]         |  ┌─滑轮支架                      |
  |  ============地面=====|  |                                |
  |  平衡位置|            |  [B] 下落轨迹虚线                |
  |                       |  |                                |
  |                       |  [B]                             |
  |                       |  |                                |
  |                       |  [B] 落地                        |
  +----------------------------------------------------------+
  |  时间轴：0--------T/4--------T/2--------------------> t   |
  |  [公式框：t=T/2, A=..., v=...]  (步骤3/4显示)             |
  +----------------------------------------------------------+
  |        [◀上一步]    步骤 X/5    [下一步▶]                |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `let currentStep = 0;` 记录当前步骤（0~4）。每步用一个配置对象描述各元素的显隐、坐标、样式。
  2. 元素显隐控制：所有可能变化的SVG元素预先在DOM中创建，通过 `setAttribute('display', 'none'/'block')` 或修改 `opacity` 切换，避免频繁创建销毁。
  3. 弹簧绘制：使用 `<polyline>` 或 `<path>` 绘制锯齿线，通过 `d` 属性动态生成三种疏密的锯齿路径。伸长/原长/压缩分别用函数 `makeSpring(x1,y1,x2,y2,coils,amp)` 生成路径数据。
  4. 时间轴高亮：当前刻度线通过改变 `stroke-width`（2px→4px）和 `stroke` 颜色（黑色→蓝色/红色）实现高亮，同时在该刻度上方显示一个小的三角形指示器。
  5. 非当前状态物体：统一使用class `ghost-outline`，设置 `stroke-dasharray="4,4"`、`opacity="0.4"`、`fill-opacity="0.1"`，当前状态物体使用class `active-body`。
  6. 公式框切换：步骤3和步骤4共用同一个背景框 `<g id="scene2-formula-group">`，内部包含多组 `<text>`，通过JS控制哪组显示。
  7. 动画曲线：本场景为离散状态切换，无需连续动画；状态切换直接呈现，保证教师讲课时的清晰与可控。若需柔和过渡，可对opacity变化添加CSS transition（0.2s ease）。
  8. 事件绑定：按钮绑定 `click` 事件，更新 `currentStep` 后调用 `renderStep()` 统一渲染。
- ID命名规范：所有交互元素ID必须以 `scene2-` 为前缀。例如：
  - `scene2-btn-prev`、`scene2-btn-next`
  - `scene2-a-body-right`、`scene2-a-body-equilibrium`、`scene2-a-body-left`
  - `scene2-b-body-top`、`scene2-b-body-mid`、`scene2-b-body-ground`
  - `scene2-spring-group`、`scene2-timeline-axis`、`scene2-formula-group`
  - JS中严格使用 `document.getElementById` 获取，禁止跨场景的全局class选择器。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免全局变量污染，确保多场景合并时互不干扰。
