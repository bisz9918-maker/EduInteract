题目原文

如图所示，质量分别为 $3m$、$2m$、$m$ 的三个小球 A、B、C 用两根长为 $L$ 的轻绳相连，置于倾角为 $30°$、高为 $L$ 的固定光滑斜面上，A 球恰能从斜面顶端外竖直落下，弧形挡板使小球只能竖直向下运动，碰撞过程中没有动能损失，小球落地后均不再反弹。由静止开始释放它们，不计所有摩擦，求：
（1）A 球刚要落地时的速度大小；
（2）C 球刚要落地时的速度大小；
（3）在 B 球运动过程中，两绳对 B 球做的总功为多少。

整体分析

本题是一道典型的多阶段连接体问题，核心难点在于正确划分运动阶段并找出各阶段的速度关联。斜面光滑且轻绳不可伸长，因此需要结合几何约束、机械能守恒与动能定理求解。

运动阶段划分

  1. 第一阶段（A 下落）：A 竖直下落，通过绳 AB 带动 B 在斜面上运动。由于 C 初始位于斜面底端，此阶段绳 BC 处于松弛状态，C 静止不动。A、B 构成速度关联系统。
  2. A 落地瞬间：A 下落高度 $L$，由绳长约束可知 B 恰好回到初始位置（沿斜面位移为零），但已获得沿斜面向上的速度。A 落地后不再反弹，绳 AB 松弛。
  3. 第二阶段（B、C 沿斜面上升）：B 以第一阶段末的速度沿斜面向上运动，绳 BC 张紧并带动 C 沿斜面向上。B 运动到斜面顶端后，在弧形挡板约束下竖直下落。
  4. 第三阶段（C 继续上升并落地）：B 落地后，C 继续沿斜面向上运动至顶端，随后竖直下落至地面。

关键物理方法

  • 速度关联：A 竖直下落与 B 沿斜面运动之间通过绳 AB 的几何约束建立速度关系。对约束方程 $s_B^2 + h_A^2 - h_A s_B = L^2$ 求导，可得 A 落地瞬间 $v_B = v_A$（大小相等）。
  • 机械能守恒：对第一阶段（A、B 系统），A 下降 $L$，B 高度不变，有 $3mgL = \frac{1}{2}(3m)v_A^2 + \frac{1}{2}(2m)v_B^2$，解得 $v_A = v_B = \sqrt{\frac{6gL}{5}}$。
  • 对 B 用动能定理求绳功：B 的整个运动过程初末动能均为零，重力对 B 做正功 $mgL$（B 从斜面中点高度 $L/2$ 下降至地面），故两绳对 B 做的总功 $W_{\text{绳}} = 0 - mgL = -mgL$。

步骤 1 / 5

Scene 2 教学说明：全运动过程分步演示

本图示是讲解本题的核心动态演示，教师应带领学生逐步观察各阶段的位置变化和速度关联。

讲解要点

  1. Step 0（初始状态）：确认三球位置关系。强调斜面高 $L$、倾角 $30°$、绳长 $L$ 的几何意义：A 在顶端，B 在中点，C 恰在底端。提问学生：释放后 C 会立即运动吗？引导学生发现 C 在底端，若 B 先下滑则绳 BC 会松弛，因此 C 第一阶段静止。
  1. Step 1（A 下落中）：展示 A 竖直下落、B 沿斜面先下滑后上滑、C 静止。重点讲解绳 AB 的几何约束：设 A 下落高度为 $h$，B 沿斜面距顶端距离为 $s$，由绳长约束得 $s^2 + h^2 - hs = L^2$。对时间求导得到速度关联式，说明 A 落地瞬间 $v_A = v_B$。
  1. Step 2（A 刚落地）：A 下落距离 $L$ 到达地面。由约束方程可知此时 $s = L$，即 B 恰好回到初始位置（高度不变）。用机械能守恒 $3mgL = \frac{1}{2}(3m)v_A^2 + \frac{1}{2}(2m)v_B^2$ 结合 $v_A = v_B$，解得 $v_A = v_B = \sqrt{6gL/5}$。这是第（1）问答案。
  1. Step 3（B 向顶端运动）：A 落地后绳 AB 松弛。B 以速度 $\sqrt{6gL/5}$ 沿斜面向上运动，绳 BC 从松弛变为张紧，开始带动 C 沿斜面向上。教师可在此提问：B 上升过程中绳 BC 对 B 做正功还是负功？（答：负功，因为拉力沿斜面向下。）
  1. Step 4（B 刚落地）：B 运动到斜面顶端后竖直下落，落地后不再反弹。此时 C 仍在斜面上某处继续向上运动。
  1. Step 5（C 刚落地）：C 运动到斜面顶端后竖直下落至地面。对 B 落地后的 C 单独用机械能守恒（或全程对系统用能量关系）可求出 C 落地速度，得到第（2）问答案。

速度关联推导（第一阶段）

绳 AB 长恒为 $L$，设 A 竖直下落高度为 $h$，B 沿斜面距顶端距离为 $s$，由几何约束：
$$s^2 + h^2 - hs = L^2$$

对时间求导：
$$2s\dot{s} + 2h\dot{h} - \dot{h}s - h\dot{s} = 0$$
$$\dot{s}(2s - h) = \dot{h}(s - 2h)$$

当 A 刚落地时，$h = L$，代入约束方程得 $s = L$，于是：
$$v_B(2L - L) = v_A(L - 2L) \Rightarrow v_B = -v_A$$

负号表示 B 沿斜面向上运动，大小满足 $|v_B| = |v_A|$。

Step 0 / 5

Scene 3 教学说明：B 球的受力分析与两绳总功

本图示专门服务于第（3）问。很多学生会试图分段计算绳 AB 和绳 BC 各自的拉力与位移，过程繁琐且易错。教师应引导学生转换思路：对 B 的整个运动过程使用动能定理，避开复杂的变力分析。

讲解步骤

  1. 明确研究对象与过程：研究 B 球从静止释放到最终落地的全过程。初态静止（动能为 0），末态落地静止（动能也为 0），因此 $\Delta E_k = 0$。
  1. 分析受力做功：
  • 重力：B 从斜面中点（高度 $L/2$）出发，最终落到地面，下降高度为 $L/2$，重力做功 $W_G = 2mg \cdot \frac{L}{2} = mgL$。
  • 斜面支持力：始终与位移垂直，不做功。
  • 两绳拉力：绳 AB 只在第一阶段对 B 做功，绳 BC 在第二阶段对 B 做功。两绳均为变力，直接计算困难，设为 $W_{T1}$ 和 $W_{T2}$。
  1. 列动能定理：

$$W_{T1} + W_{T2} + W_G = \Delta E_k = 0$$
$$W_{\text{绳总}} = -W_G = -mgL$$

  1. 强调物理思想：两绳对 B 做的总功为负，说明绳对 B 整体起"阻碍运动"的作用，这与 B 先被 A 拉动、后又拉动 C 的物理图景一致。教师可追问：若仅问绳 AB 对 B 做的功，该如何求？（答：对第一阶段单独用动能定理，$W_{AB} = \frac{1}{2}(2m)v_1^2 - 0 = \frac{6}{5}mgL$。）

关键公式

对 B 全程：
$$W_{\text{绳总}} = \Delta E_k - W_G = 0 - mgL = -mgL$$

Step 1/4

总结：完整解答与课堂讲解建议

完整解答

  1. A 刚要落地时的速度

设 A 落地时 A、B 速度大小均为 $v_1$。对 A、B 系统，由机械能守恒：
$$3mgL = \frac{1}{2}(3m)v_1^2 + \frac{1}{2}(2m)v_1^2$$
解得：
$$v_1 = \sqrt{\frac{6gL}{5}}$$

  1. C 刚要落地时的速度

A 落地后，B 以 $v_1$ 沿斜面向上运动并带动 C。对 B、C 系统从 A 落地到 C 落地的全过程，或用全程能量关系（需仔细分析各球高度变化），可得 C 落地速度。具体数值需结合 B 落地时 C 的状态进一步分析，核心方法是分阶段机械能守恒。

  1. 两绳对 B 做的总功

对 B 的全程用动能定理：
$$W_{\text{绳总}} + 2mg \cdot \frac{L}{2} = 0 - 0$$
$$W_{\text{绳总}} = -mgL$$

课堂讲解建议

  • 读题环节（配合 Scene 1）：让学生自己标注已知条件，特别注意"A 恰能从顶端外竖直落下"和"弧形挡板"的含义，确认 C 初始在斜面底端。
  • 关键提问：释放瞬间 C 动不动？为什么？（引导学生分析绳 BC 的松紧。）
  • 核心突破（配合 Scene 2）：第一阶段的速度关联是难点。建议先让学生猜测 A 和 B 的速度关系，再通过几何约束推导，最后验证机械能守恒。
  • 方法升华（配合 Scene 3）：第（3）问是"求变力功"的典型场景，务必强调"全程动能定理"的巧妙之处，避免学生陷入分段积分或求拉力的误区。
  • 拓展思考：若斜面有摩擦，上述分析方法哪些需要改变？（答：机械能守恒不再适用，需用功能关系；但动能定理仍然适用，只需加入摩擦力做功。）
