[图示主题与整合说明]
- 本图示主题：三球联动从释放到全部落地的完整运动过程（Scene 2）
- 整合的步骤/概念：A 竖直下落阶段 → A 落地瞬间 → B 沿斜面上升并拉动 C → B 竖直落地 → C 竖直落地。通过 6 个分步状态完整呈现绳张紧/松弛切换、速度方向变化、落地顺序。
- 教学价值：教师可逐帧控制讲解节奏，在关键节点（A 落地、绳 BC 突然张紧、B 落地）暂停，配合速度箭头与绳状态变化，帮助学生建立“关联运动+能量守恒”的物理图像。

[分步序列]
- 初始状态（Step 0 / 5）：三球静止在初始位置，绳 AB、BC 均为黑色实线（张紧）。显示斜面、地面、挡板、三球、两绳、所有静态标签（L×3、30°、地面、质量）。辅助竖直线全程可见。
- 步骤1（Step 1 / 5）：点击「下一步」→ A 下移至 (460,290)（约 L/2），B 下移至 (313,315)（沿斜面下滑），C 保持 (200,380)。绳 AB 仍为实线；绳 BC 变为灰色虚线（松弛）。新增水平辅助虚线 (460,290)-(430,290)。质量标签随球移动。
- 步骤2（Step 2 / 5）：点击「下一步」→ A 落至地面 (460,380)，B 回到斜面中点 (330,305)，C 保持 (200,380)。绳 AB 实线（最后张紧瞬间），绳 BC 虚线。显示 A 的蓝色竖直向下速度箭头及标签 v_A；显示 B 的红色沿斜面向上速度箭头及标签 v_B；在斜面空白处标注 v_1（表示 v_A=v_B=v_1）。A 球下方显示黄色落地星形标记。已落地 A 在后续步骤中 opacity 降为 0.3。
- 步骤3（Step 3 / 5）：点击「下一步」→ A 移至 (440,380) 并 opacity 0.3（表示已静止在地）。B 沿斜面向上至 (380,265)，C 被拉动至 (260,350)。绳 AB 变为灰色虚线且 opacity 0.3（隐藏态）；绳 BC 变为黑色实线（张紧）。显示 B、C 的速度箭头（均沿斜面向上）及标签 v_B、v_C。落地标记、v_A、v_B(旧)、v_1 隐藏。
- 步骤4（Step 4 / 5）：点击「下一步」→ A 移至 (435,380) opacity 0.3；B 落至 (460,380)；C 继续上行至 (330,305)。绳 AB 隐藏；绳 BC 实线。显示 C 的沿斜面向上速度箭头及标签 v_C。B 球下方显示黄色落地星形标记。B 在后续步骤 opacity 0.3。
- 步骤5（Step 5 / 5）：点击「下一步」→ A(435,380)、B(460,380)、C(485,380) 三球均在地面上，opacity 1.0（最终状态）。所有绳隐藏，所有速度箭头隐藏。C 球下方显示黄色落地星形标记。展示“三球全部落地”结论画面。

[交互方案]
- 交互类型：分步按钮导航（◀ 上一步 / 下一步 ▶）
- 控件说明：
  1. 「上一步」按钮：位于 SVG 底部居中偏左（约 x=280, y=455），宽 80×高 30。点击回退到上一状态，Step 0 时禁用。
  2. 「下一步」按钮：位于 SVG 底部居中偏右（约 x=440, y=455），宽 80×高 30。点击前进到下一状态，Step 5 时禁用。
  3. 步骤指示器：位于两按钮之间，显示 "Step X / 5"，font-size 14px，颜色 #333。
- 教师操作流程：
  1. 教师加载页面，展示 Step 0（静止释放前），讲解三球位置、绳长、斜面几何约束。
  2. 点击「下一步」进入 Step 1，观察 A 下降、B 下滑、BC 绳松弛，提问“为什么 BC 绳会松弛？”。
  3. 点击「下一步」进入 Step 2（关键帧），强调 A 落地瞬间两球速度大小均为 v_1，方向不同，为能量守恒方程建立图像。
  4. 点击「下一步」进入 Step 3，观察绳 BC 突然张紧，B、C 一起沿斜面向上，说明冲量/关联速度。
  5. 点击「下一步」进入 Step 4，B 落地，C 继续上升，说明 B 落地后 C 仍具速度。
  6. 点击「下一步」进入 Step 5，三球全部落地，总结全过程能量关系。可随时「上一步」回退复习。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无需外部库）。理由：本场景为静态几何图形分步切换，无复杂函数绘图或 3D，原生 SVG 性能最佳且零依赖。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |                                                  |
  |     C(m)                    B(2m)      A(3m)     |
  |      ●----------------------●----------●         |
  |       \                     /          | 挡板    |
  |        \                   /           |         |
  |         \     斜面       /            |         |
  |          \   (30°)      /             |         |
  |           \            /              |         |
  |            \          /               |         |
  |             \        /                |         |
  |              \      /                 |         |
  |               \    /                  |         |
  |                \  /                   |         |
  |                 ●---------------------●         |
  |                地面                               |
  |                                                  |
  |    [◀ 上一步]   Step X / 5   [下一步 ▶]          |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：定义数组 `scene2States[6]`，每个元素记录该 Step 下所有可交互元素的属性（display, x, y, opacity, strokeStyle 等）。切换步骤时遍历属性表批量更新 DOM。
  2. 坐标计算：斜面方向向量 (cos30°, -sin30°) = (0.866, -0.5)。B、C 沿斜面位移时按此向量计算新坐标，确保视觉一致。
  3. 动画曲线：步骤切换时球体位置变化使用 CSS `transition: cx 0.4s ease, cy 0.4s ease, opacity 0.3s ease`（对 SVG 元素通过设置 style 实现）。绳的实线/虚线切换通过更改 `stroke-dasharray` 实现。
  4. 事件绑定：按钮绑定 `click` 事件，维护变量 `scene2CurrentStep`，更新后调用 `scene2Render(step)`。边界检查：Step 0 禁用「上一步」，Step 5 禁用「下一步」。
  5. 箭头 marker：在 `<defs>` 中定义三个 marker（蓝/红/绿），供速度箭头复用。
  6. 落地星形：用 `<polygon>` 计算五角星五个外顶点和五个内顶点，中心对准球底坐标。
  7. 非当前运动球体透明度：Step 3 起 A 球 opacity 0.3；Step 4 起 A、B 球 opacity 0.3；Step 5 三球恢复 1.0，表示过程结束。
- ID 命名规范：所有 SVG 元素及控件 ID 必须以 `scene2-` 为前缀。例如：`scene2-ball-a`、`scene2-rope-ab`、`scene2-btn-prev`、`scene2-step-label`。JS 中严格使用 `document.getElementById` 获取，禁止全局 class 查询，避免多场景合并时污染。
- IIFE 隔离：所有 JavaScript 包在 `(function() { ... })()` 中，内部变量不泄露全局作用域。
