[图示主题与整合说明]
- 本图示主题：B 球的受力分析与动能定理应用
- 整合的步骤/概念：
  1. B 球在斜面上的受力分解（重力、两绳拉力、斜面支持力）；
  2. B 球运动的初末状态对比（斜面中点静止 → 地面静止）；
  3. 各力做功分析（重力正功、支持力不做功、两绳拉力总功待求）；
  4. 动能定理列式求解（W_绳 + mgL = 0，得 W_绳 = −mgL）。
- 教学价值：教师可逐步引导学生从受力图过渡到能量观点，强调“初末速度均为零”这一关键隐含条件，避免学生遗漏绳拉力做功。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「上一步」按钮：位置(280,460)，80×30px，点击回退到上一状态，Step 0 时置灰。
  2. 步骤指示器：位置(370,460)，60×30px，纯文本显示当前步骤序号（如"Step 2/4"）。
  3. 「下一步」按钮：位置(440,460)，80×30px，点击进入下一状态，Step 3 时置灰。
- 教师操作流程：
  1. 教师先展示 Step 0，让学生观察 B 球受力并口头提问；
  2. 点击「下一步」进入 Step 1，引导学生确定初末状态；
  3. 点击「下一步」进入 Step 2，让学生判断各力做功正负；
  4. 点击「下一步」进入 Step 3，带领学生列动能定理并求解；
  5. 若学生某步理解困难，点击「上一步」回退复习。

[技术实现]
- JS 库选择：原生 SVG（绘制左侧受力图）+ 原生 DOM 操作（控制右侧 HTML 内容显隐）。无需引入外部库，减少依赖并保证加载速度。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------------+
  |  左侧：B球受力图（x:0~480）      右侧：分析区（x:480~800） |
  |                                |  区域标题              |
  |   N(左上)  T₁(右上)            |  +--------+ +--------+ |
  |      ↑    ↗                   |  | 初状态 | | 末状态 | |  Step 1+
  |      \  /                     |  +--------+ +--------+ |
  |   B球●                        |  +--------------------+ |
  |      / \                      |  | 各力做功列表        | |  Step 2+
  |   T₂↙   ↓重力                 |  +--------------------+ |
  |         2mg                   |  +--------------------+ |
  |  斜面（30°）                   |  | 动能定理方程与结果  | |  Step 3+
  |                                |  +--------------------+ |
  |--------------------------------------------------------|
  |        [◀上一步]  Step X/4  [下一步▶]                   |  y:440~490
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 `currentStep`（0~3）记录当前步骤。每步切换时，通过 `display` 或 `opacity` 控制右侧各区块显隐；建议用 CSS class `.scene3-hidden { opacity: 0; pointer-events: none; }` 配合 `transition: opacity 0.3s` 实现淡入。
  2. 坐标计算：斜面倾角30°，斜面方向向量(cos30°,−sin30°)，法向方向向量(−sin30°,−cos30°)（屏幕坐标 y 向下）。四根力箭头均从圆心(300,240)出发，按固定长度（50px 或 70px）和固定角度计算终点，确保箭头方向准确。
  3. 箭头绘制：SVG 中使用 `<marker>` 定义箭头头部，分别绑定到各力线段的 `marker-end`；不同力使用不同颜色 marker。
  4. 事件绑定：按钮绑定 `click` 事件，修改 `currentStep` 后调用 `renderStep()` 更新界面。
  5. 按钮置灰逻辑：`currentStep === 0` 时禁用「上一步」；`currentStep === 3` 时禁用「下一步」。
- ID 命名规范：
  - SVG 元素：`scene3-ball-b`、`scene3-slope`、`scene3-force-gravity`、`scene3-force-t1`、`scene3-force-t2`、`scene3-force-n`、`scene3-label-2mg`、`scene3-label-t1`、`scene3-label-t2`、`scene3-label-n`、`scene3-angle-arc`、`scene3-angle-label`
  - HTML 控件与区块：`scene3-btn-prev`、`scene3-btn-next`、`scene3-step-indicator`、`scene3-panel-initial`、`scene3-panel-final`、`scene3-panel-work`、`scene3-panel-formula`
- IIFE 隔离：所有 JS 包在 `(function() { ... })()` 中，避免多场景合并时变量污染。
