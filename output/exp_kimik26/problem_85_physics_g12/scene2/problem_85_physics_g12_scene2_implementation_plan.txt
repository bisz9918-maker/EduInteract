[图示主题与整合说明]
- 本图示主题：气体状态参数对比与理想气体状态方程推导
- 整合的步骤/概念：
  1. 将氮气（蓝色）与氧气（红色）在三个关键状态（初态、过程1末态、过程2末态）的 P-V-T 参数以总表形式并列呈现；
  2. 分步推导过程(1)氮气的等压膨胀（查理定律），配合初末态体积分解示意；
  3. 分步推导过程(2)氧气的等温压缩（玻意耳定律），配合 A 气缸中氧气高度变化的局部放大示意。
- 教学价值：教师先通过总表让学生整体把握两气体的状态变化，再逐步展开公式代入与化简。分步导航允许教师在关键代数步骤暂停提问，避免单图信息过载。

[技术实现]
- JS库选择：原生 SVG（表格、示意图、公式排版全部用 SVG 元素实现），无需额外库。公式中的上下标和分数使用 SVG <tspan> 的 dy、font-size 属性或 <foreignObject> 内嵌 HTML 实现。若需更美观的数学排版，可引入 MathJax（CDN），但建议优先用原生 SVG 减少依赖。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------------+
  |  参数表格 (50,40)-(750,200)                              |
  |  +------+------+------+------+------+------+------+    |
  |  | 状态 |  P_N |  V_N |  T_N |  P_O |  V_O |  T_O |    |
  |  +------+------+------+------+------+------+------+    |
  |  | 初态 | ...  | ...  | ...  | ...  | ...  | ...  |    |
  |  | 过1  | ...  | ...  | ...  | ...  | ...  | ...  |    |
  |  | 过2  | ...  | ...  | ...  | ...  | ...  | ...  |    |
  |  +------+------+------+------+------+------+------+    |
  |                                                          |
  |  +--------------------+  +---------------------------+  |
  |  |  示意图区          |  |  公式推导区               |  |
  |  |  (50,230)-(350,400)|  |  (370,220)-(750,400)      |  |
  |  |  步骤1: 氮气对比   |  |  步骤1: 查理定律          |  |
  |  |  步骤2: 氧气压缩   |  |  步骤2: 玻意耳定律        |  |
  |  +--------------------+  +---------------------------+  |
  |                                                          |
  |              [◀ 上一步]  [下一步 ▶]                      |
  |              (280,450)   (410,450)                       |
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：定义全局变量 scene2State ∈ {0,1,2}。每次状态切换时，调用 renderScene2() 统一更新所有元素的 visibility、fill、stroke 属性。
  2. 表格高亮实现：预先在每一行上方放置一个透明矩形（fill=#fff9c4, opacity=0），需要高亮时将该行对应矩形的 opacity 设为 0.6。
  3. 公式区切换：预先绘制步骤1和步骤2的两组公式元素（分别放在 <g id="scene2-formula-1"> 和 <g id="scene2-formula-2"> 中），通过设置 display="none" / display="block" 切换。
  4. 示意图切换：同理，<g id="scene2-diagram-1"> 和 <g id="scene2-diagram-2"> 切换显示。
  5. 按钮状态：在 renderScene2() 中根据 scene2State 设置两按钮的 disabled 属性和 opacity。
  6. 动画曲线：状态切换无需复杂动画，直接瞬时切换即可；若需柔和过渡，可对高亮矩形和公式组使用 CSS transition（opacity 0.3s ease）。
  7. 事件绑定：按钮的 onclick 事件直接修改 scene2State 并调用 renderScene2()。
- ID 命名规范：
  · 表格：scene2-table、scene2-row-head、scene2-row-1、scene2-row-2、scene2-row-3、scene2-highlight-1、scene2-highlight-2、scene2-highlight-3
  · 公式区：scene2-formula-area、scene2-formula-line、scene2-formula-1、scene2-formula-2
  · 示意图：scene2-diagram-area、scene2-diagram-1、scene2-diagram-2
  · 按钮：scene2-btn-prev、scene2-btn-next、scene2-step-indicator
  · 所有交互元素 ID 必须以 scene2- 为前缀；JS 中使用 getElementById 获取，禁止 querySelectorAll 配合全局 class。
- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免多场景合并时变量污染。
