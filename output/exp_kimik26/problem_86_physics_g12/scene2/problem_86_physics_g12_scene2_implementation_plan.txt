[图示主题与整合说明]
- 本图示主题：带电微粒在平行板电容器复合场（重力场+匀强电场）中的运动临界条件与电势范围
- 整合的步骤/概念：
  1. 电场方向与电场力方向随 φ_A 正负变化的实时展示；
  2. 重力 mg（恒向下）与电场力 F_电（方向随 φ_A 改变）的矢量对比；
  3. 加速度 a = g − qφ_A/(md) 的实时数值计算与显示；
  4. 参数化轨迹的实时绘制，根据 φ_A 连续变化；
  5. 两个临界状态（φ_A = 6 V 与 φ_A = 10 V）的精确演示；
  6. 射出/打板的判定结果可视化（绿色=可射出，红色=打到极板）。
- 教学价值：教师通过拖动滑块，让学生直观感知"电势升高→电场力增大→向上偏转加剧→最终打到上极板"的完整因果链；快捷临界按钮帮助教师精准定位两个关键临界点；受力分析区始终展示三力/加速度关系，强化受力分析意识。

[状态序列]
本 scene 为连续滑块交互，无离散分步。以下列出关键状态及视觉表现：

- 初始状态（φ_A = 0 V）：
  - 电场线隐藏（φ_A=0）
  - F_电 = 0，受力区只显示 mg 箭头，F_电箭头隐藏
  - a = 10 m/s²，轨迹为向下抛物线，在 x<L 处与 A 板相交（打到 A 板，红色末段）
  - 状态提示："打到 A 板，无法射出"（红色）

- 滑动区间 φ_A ∈ (−2, 6) V：
  - φ_A < 0：电场线红色向下，F_电 红色向下，a > 2.5
  - φ_A > 0：电场线蓝色向上，F_电 蓝色向上，但 a 仍 > 2.5
  - 轨迹始终向下偏转，在 x<L 时打到 A 板，末段红色
  - 状态提示："打到 A 板，无法射出"（红色）

- 临界状态 1（φ_A = 6 V）：
  - a = 2.5 m/s²
  - 轨迹刚好经过 (700, 280)，即到达 A 板右端点
  - 末段红色，状态提示："临界：刚好到达 A 板右端，无法射出"（红色）

- 可射出区间 φ_A ∈ (6, 10) V：
  - |a| < 2.5，轨迹在 x=700 时 |y| < d/2（在板间）
  - 末段绿色，出口区域浅绿填充
  - 状态提示："可从右侧射出"（绿色）
  - 特殊点 φ_A = 8 V：a = 0，轨迹为水平直线；受力区显示金色平衡提示"a=0，重力与电场力平衡"

- 临界状态 2（φ_A = 10 V）：
  - a = −2.5 m/s²
  - 轨迹刚好经过 (700, 120)，即到达 B 板右端点
  - 末段红色，状态提示："临界：刚好到达 B 板右端，无法射出"（红色）

- 滑动区间 φ_A ∈ (10, 12] V：
  - a < −2.5，电场力大于重力，轨迹向上偏转
  - 在 x<L 时打到 B 板，末段红色
  - 状态提示："打到 B 板，无法射出"（红色）

[交互方案]
- 交互类型：连续拖拽/滑块（单滑块 + 两个快捷跳转按钮）
- 控件说明：
  1. 电势滑块：范围 φ_A ∈ [−2, 12] V，步进 0.5 V，默认 0 V；位于底部左侧
  2. 「临界1 (6V)」按钮：点击后滑块平滑过渡至 6 V（耗时 300 ms）
  3. 「临界2 (10V)」按钮：点击后滑块平滑过渡至 10 V（耗时 300 ms）
- 教师操作流程：
  1. 教师先展示 φ_A = 0 时的纯重力偏转（打到 A 板）；
  2. 向右拖动滑块，让学生观察"电场力向上逐渐增大→轨迹向下偏转减缓→最终水平→开始向上偏转"的连续过程；
  3. 点击「临界1」精准展示下极板临界；
  4. 继续拖动经过可射出绿色区间，强调"只有在此区间才能飞出"；
  5. 在 φ_A = 8 V 处停顿，悬停/自动展示平衡提示；
  6. 点击「临界2」精准展示上极板临界；
  7. 继续向右拖动，展示电场力过大导致打到 B 板的结果。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无外部库）。理由：本场景以几何图形、轨迹曲线、矢量箭头为主，SVG path 与原生 DOM 操作完全足够；滑块与数值面板使用 HTML 控件，无需引入 D3/Canvas。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  0    100        400        700    800
  +-----+----------+----------+------+  ← y=20
  |     [========B========]    |      |  ← y=120 上极板
  |  接地  · · · · · · · · ·   |d     |  ← y=200 板间/中位线
  |  ⊕→   [========A========]O |      |  ← y=280 下极板
  |  v₀   |  轨迹曲线        |  |      |
  |  m,q  |                |  |      |
  |       |                |  |      |
  |              mg↓ F_电↑  |  |      |  ← 右上角受力区
  +------------------------------+------+  ← y=350
  | φ_A [========●====] 6V 10V         |  ← y=390 滑块+按钮
  | E=...  a=...  F_电=...  [状态提示] |  ← y=435 数值面板
  | m=2.0×10⁻⁶kg, q=1.0×10⁻⁸C ...     |  ← y=475 常量
  +------------------------------------+  ← y=500
  ```
- 关键实现要点：
  1. 坐标比例尺：x 方向 600 px = 0.1 m → px_per_m_x = 6000；y 方向 160 px = 0.004 m → px_per_m_y = 40000。轨迹计算必须分别使用两个比例尺。
  2. 轨迹算法：给定 φ_A，计算 a = g − q·φ_A/(m·d)。计算总飞行时间 t_total = L/v0 = 0.04 s 与打到极板时间 t_hit = sqrt(0.004/|a|)（a≠0）。若 t_hit < t_total，则轨迹终点为击中点，状态为打板；否则终点为 x=L，状态为飞出。用 50 个等时间隔采样点生成 SVG path 的 "M...L..." 字符串。
  3. 轨迹分段：将 50 个点分为前 40 段（主体，蓝色）与后 10 段（末段，绿/红），用两个 <path> 元素叠加绘制。
  4. 状态判定：
     - a > 0 且 t_hit < t_total → 打到 A 板（红）
     - a < 0 且 t_hit < t_total → 打到 B 板（红）
     - 否则且 |y_end| < d/2 → 可射出（绿）
     - 否则 → 临界（红，文字标注"临界"）
  5. 滑块动画：点击临界按钮时，使用 requestAnimationFrame 在 300 ms 内将滑块值从当前值线性插值到目标值，期间持续触发更新函数，实现平滑过渡。
  6. 电场线显隐：φ_A === 0 时隐藏所有电场线；φ_A > 0 时显示蓝色向上箭头；φ_A < 0 时显示红色向下箭头。使用 SVG <line> + <polygon>（箭头）组合，通过设置 display 属性切换。
  7. 受力区动态：F_电箭头方向与颜色随 φ_A 符号切换；标签位置同步切换（上方/下方）以避免重叠。φ_A = 8 V 时显示平衡提示文本。
- ID 命名规范（全部以 scene2- 为前缀）：
  - SVG 元素：scene2-plate-top、scene2-plate-bottom、scene2-particle、scene2-trajectory-main、scene2-trajectory-end、scene2-field-line-1~6、scene2-force-mg、scene2-force-electric、scene2-balance-tip、scene2-exit-zone、scene2-point-o
  - HTML 控件：scene2-slider、scene2-btn-crit1、scene2-btn-crit2、scene2-val-phi、scene2-val-E、scene2-val-a、scene2-val-F、scene2-status、scene2-constants
- IIFE 隔离：所有 JavaScript 逻辑包裹在 (function() { ... })() 中，避免多场景合并时全局变量污染。
- 性能：滑块 input 事件使用节流（throttle）或直接用原生 input（现代浏览器性能足够），轨迹计算仅涉及 50 个点的简单算术，保证 60 fps 流畅度。
