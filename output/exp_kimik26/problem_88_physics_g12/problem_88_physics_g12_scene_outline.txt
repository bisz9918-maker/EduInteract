    **完整题目原文**

    如图所示，两根等高光滑的四分之一圆弧轨道，半径为 $r$，间距为 $L$，轨道电阻不计，在轨道顶端连有一阻值为 $R$ 的电阻，整个装置处在一竖直向上的匀强磁场中，磁感应强度为 $B$。现有一根长度稍大于 $L$、电阻为 $\frac{1}{3}R$、质量为 $m$ 的金属棒从轨道最低位置 $cd$ 开始，在拉力作用下以速度 $v_0$ 向右沿轨道做匀速圆周运动至 $ab$ 处。求：
    （1）初始时刻 $cd$ 两端的电压；
    （2）在该过程中 $R$ 上产生的热量；
    （3）拉力做的功。

    **题目分析**

    本题是电磁感应与圆周运动、电路、能量问题的综合题。核心难点在于：
    1. 金属棒做匀速圆周运动，速度方向时刻变化，导致切割磁感线的有效速度分量随位置变化，感应电动势不是恒定值。
    2. 需要正确建立等效电路，区分电源电动势、路端电压和内电压。
    3. 热量计算需对变化电流的平方进行积分，不能直接用恒定电流公式。
    4. 拉力做功需用功能关系，考虑重力势能变化和回路总焦耳热。

    **整体讲解思路**

    1. 先通过动态装置图帮助学生建立几何直观：金属棒水平，始终垂直于纸面方向（$y$ 轴），磁场竖直向上（$z$ 轴），速度沿圆弧切线。引导学生分解速度，找出有效切割分量。
    2. 在初始位置（最低点）定格，计算瞬时电动势和路端电压，解决第（1）问。
    3. 建立等效电路，分析电流随角度的变化规律，通过图象积分求热量，解决第（2）问。
    4. 最后通过受力分析和能量转化流程，利用功能关系求拉力做功，解决第（3）问。

    **图示规划说明**

    共设计 3 个交互式图示：
    - **SCENE 1**：动态装置图，用滑块控制金属棒从 $cd$ 到 $ab$ 的位置变化，实时展示速度分解和感应电动势的变化规律，同时整合初始时刻电压的求解。
    - **SCENE 2**：等效电路与热量计算图，通过分步导航展示电路结构、$I\text{-}\theta$ 关系曲线和积分求热量的完整过程。
    - **SCENE 3**：受力分析与能量转化图，通过分步导航展示受力分析、能量转化流程和功能关系方程，最终得出拉力做功。

    **SCENE 1 教学说明：电磁感应动态分析**

    教师应引导学生按以下顺序观察：

    1. **建立几何关系**：明确圆心 $O$ 在左上角，金属棒从最低点 $cd$（$\theta=0$）运动到最右端 $ab$（$\theta=90^\circ$），上升高度为 $r$。强调金属棒始终水平，长度为 $L$（连接两轨道）。

    2. **速度分解**：速度 $v_0$ 沿切线方向。将 $v_0$ 分解为水平向右分量 $v_x=v_0\cos\theta$ 和竖直向上分量 $v_z=v_0\sin\theta$。关键提问：哪个分量切割磁感线？（磁场竖直向上，棒水平放置，只有水平分量 $v_x$ 垂直于 $B$ 且垂直于棒，产生感应电动势。）

    3. **推导电动势**：由法拉第电磁感应定律，$\varepsilon = BLv_x = BLv_0\cos\theta$。特别验证两个端点：
       - $\theta=0$（最低点）：$\varepsilon = BLv_0$（最大）
       - $\theta=90^\circ$（最右端）：$\varepsilon = 0$（速度竖直，不切割）

    4. **求解第（1）问**：初始时刻 $\varepsilon_0 = BLv_0$。等效电路为电源（内阻 $r=\frac{R}{3}$）与外阻 $R$ 串联。总电阻 $R_{\text{总}} = R + \frac{R}{3} = \frac{4R}{3}$。电流 $I_0 = \frac{\varepsilon_0}{R_{\text{总}}} = \frac{3BLv_0}{4R}$。$cd$ 两端电压为路端电压：$U_{cd} = I_0 R = \frac{3}{4}BLv_0$。

    5. **铺垫后续问题**：拖动滑块让学生观察 $U$ 随 $\theta$ 减小，说明电流是变化的，为第（2）问的热量计算埋下伏笔。

    **SCENE 2 教学说明：热量计算**

    教师应强调以下要点：

    1. **电路模型**：金属棒相当于电源，其电阻 $\frac{R}{3}$ 是电源内阻，轨道顶端电阻 $R$ 是外电阻。轨道电阻不计。总电阻 $R_{\text{总}} = \frac{4R}{3}$。

    2. **瞬态电流**：由于 $\varepsilon$ 随 $\theta$ 变化，电流也是瞬态量。$I(\theta) = \frac{BLv_0\cos\theta}{\frac{4R}{3}} = \frac{3BLv_0}{4R}\cos\theta$。让学生观察 $I\text{-}\theta$ 曲线，确认电流从 $I_0$ 逐渐减小到 0。

    3. **热量积分**：因为电流变化，必须用积分求热量。$Q_R = \int_0^{t_{\text{末}}} I^2 R \, dt$。关键是换元：
       - 角速度 $\omega = \frac{v_0}{r}$
       - $\theta = \omega t$，$dt = \frac{r}{v_0}d\theta$
       - 运动时间对应 $\theta$ 从 $0$ 到 $\frac{\pi}{2}$

    4. **具体计算**：
       $$Q_R = \int_0^{\frac{\pi}{2}} \left(\frac{3BLv_0}{4R}\cos\theta\right)^2 R \cdot \frac{r}{v_0} d\theta = \frac{9B^2L^2v_0^2}{16R^2} \cdot R \cdot \frac{r}{v_0} \int_0^{\frac{\pi}{2}} \cos^2\theta \, d\theta$$
       利用 $\int_0^{\frac{\pi}{2}} \cos^2\theta \, d\theta = \frac{\pi}{4}$，得：
       $$Q_R = \frac{9\pi r B^2 L^2 v_0}{64R}$$

    5. **易错提醒**：学生容易误用恒定电流公式 $Q=I^2Rt$ 直接计算。应强调只有代入瞬时值并积分才是正确方法。

    **SCENE 3 教学说明：拉力做功与功能关系**

    教师应引导学生从"为什么拉力做功不等于零"切入，因为金属棒匀速上升，动能不变，但重力势能增加且回路产生焦耳热，这些能量只能来自拉力做功。

    1. **受力分析**：金属棒受四个力：
       - 重力 $mg$（竖直向下）
       - 轨道支持力 $N$（沿半径指向圆心，不做功）
       - 安培力 $F_A$（沿切线向下，阻碍运动，做负功）
       - 拉力 $F$（沿切线向上，做正功）
       强调支持力始终垂直于速度，不做功；安培力是阻力，其做功的绝对值等于回路总电能。

    2. **能量转化**：拉力的功是能量输入，转化为两部分：
       - 重力势能增加：$\Delta E_p = mgr$（上升高度为半径 $r$）
       - 回路总焦耳热：$Q_{\text{总}} = Q_R + Q_{\text{棒}}$

    3. **热量分配**：串联电路中热量按电阻分配。$\frac{Q_R}{Q_{\text{棒}}} = \frac{R}{\frac{R}{3}} = 3$，所以 $Q_{\text{棒}} = \frac{1}{3}Q_R$，$Q_{\text{总}} = \frac{4}{3}Q_R$。

    4. **功能关系方程**：
       $$W_F + W_G + W_{\text{安}} = \Delta E_k = 0$$
       其中 $W_G = -mgr$，$W_{\text{安}} = -Q_{\text{总}}$，代入得：
       $$W_F = mgr + Q_{\text{总}} = mgr + \frac{4}{3}Q_R$$
       将 $Q_R = \frac{9\pi r B^2 L^2 v_0}{64R}$ 代入：
       $$W_F = mgr + \frac{3\pi r B^2 L^2 v_0}{16R}$$

    **课堂讲解建议**

    - 建议先用 SCENE 1 的滑块让学生"玩"一下，观察电动势从最大到零的变化，建立直观感受。
    - 第（2）问是计算难点，务必强调"电流变化→必须积分"这一核心思想，可对比恒定电流的错误做法加深印象。
    - 第（3）问可引导学生思考：若忽略安培力（即无磁场），拉力做功应为 $mgr$；有磁场时额外多了克服安培力做功的部分，即 $Q_{\text{总}}$。这体现了能量守恒的完整性。
    </TEXT_4>
