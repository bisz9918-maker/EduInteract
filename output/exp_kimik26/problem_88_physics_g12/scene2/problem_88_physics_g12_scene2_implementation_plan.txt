[图示主题与整合说明]
- 本图示主题：变化电流的焦耳热计算（物理·电磁感应·交变电流热效应）
- 整合的步骤/概念：
  1. 等效电路结构（电源 ε、内阻 r=R/3、外阻 R 串联）
  2. 瞬时电流公式推导与初始值
  3. 电流随角度变化规律（I-θ 图象，θ∈[0, π/2]）
  4. 积分法求 R 上产生的热量，换元积分并得出最终结果 Q_R = 9πrB²L²v₀/(64R)
- 教学价值：教师可按照"建模→写式→画图→积分"四步节奏逐步展开，避免一次性呈现过多公式造成认知负荷；分步回退功能便于复习关键推导节点。

  · I-θ图区域坐标轴完整显示（含刻度、标签I、I₀、θ、π/4、π/2）
  · 右下区域更新为"瞬时电流表达式已建立"

    (430,315) 换元：dt = rdθ/v₀，θ: 0 → π/2
  · 右上公式保持显示

- 步骤3（点击下一步，最终步骤）：

- 教师操作流程：

  2. 点击「下一步」进入步骤1，讲解瞬时电动势和总电阻，推导出I(θ)表达式。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本场景以静态几何图形、路径曲线和文本公式为主，无复杂数据绑定或3D渲染，原生SVG性能最优，无需引入D3/Three.js等重型库。公式使用SVG <text> + Unicode字符（θ, π, ², ₀, ∫）直接渲染，避免MathJax加载延迟。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |  [等效电路图]          [瞬时公式区]                |  y=30~200
  |  电源-内阻-外阻         ε=BLv₀cosθ                |
  |  ε  I  r=R/3  R        I(θ)=I₀cosθ               |
  |                                                    |
  |  [I-θ 关系曲线]        [热量推导区]                |  y=210~430
  |  I↑                   Q_R = ∫ I²R dt             |
  |  I₀|  ╭────╮           = ...                     |
  |    | /      \          = 9πrB²L²v₀/(64R)         |
  |    |/        \                                   |
  |    +----------→θ                                 |
  |       π/4  π/2                                    |
  |                                                    |
  |        [◀ 上一步]  步骤 n/4  [下一步 ▶]           |  y=440~490
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 `currentStep`（0~3）记录当前步骤。每步用一个配置对象描述该步应显示的元素ID集合。切换步骤时，先隐藏所有"步骤专属"元素，再显示当前步对应的元素。
  2. 元素显隐：所有可能动态显示的元素初始 `visibility="hidden"` 或 `opacity="0"`。步骤切换时通过设置 `opacity` 并配合CSS transition `opacity 0.3s ease` 实现淡入。最终步骤中需淡化的元素（电路图、右上公式）通过添加CSS类 `.dimmed { opacity: 0.3; transition: opacity 0.3s; }` 实现。
  3. 余弦曲线绘制：使用SVG `<path>` 的 `d` 属性，采用三次贝塞尔曲线（C命令）连接关键控制点，确保曲线平滑下凸。路径数据：`M 100 250 C 140 255, 180 270, 210 296 C 240 322, 280 355, 320 400`。
  4. 积分区域填充：使用 `<path>` 绘制闭合区域，d="M 100 400 L 100 250 C ... 320 400 Z"，fill="#2e7d32"，fill-opacity="0.2"。仅在步骤3显示。
  5. 内阻斜线填充：在矩形内用 `<line>` 画3条斜线（从矩形左上到右下方向），stroke="#888888"。外阻横线填充同理画3条水平线，stroke="#1565c0"。
  6. 按钮定位：SVG容器设置 `position: relative`，按钮容器设置 `position: absolute; bottom: 10px; left: 0; width: 100%; text-align: center; pointer-events: none;`，按钮本身 `pointer-events: auto; display: inline-block;`。
  7. 电流箭头：使用 `<marker>` 定义箭头头部，标记在路径末端。
- ID命名规范：所有SVG元素及JS变量均以 `scene2-` 为前缀。例如：
  · 电源：`scene2-source`
  · 内阻：`scene2-internal-r`
  · 外阻：`scene2-external-r`
  · 电流箭头：`scene2-current-arrow`
  · 余弦曲线：`scene2-cosine-curve`
  · 积分填充：`scene2-integral-fill`
  · 步骤1公式组：`scene2-formula-step1`
  · 步骤2推导组：`scene2-derive-step2`
  · 步骤3推导组：`scene2-derive-step3`
  · 上一步按钮：`scene2-btn-prev`
  · 下一步按钮：`scene2-btn-next`
  · JS中通过 `document.getElementById('scene2-xxx')` 精确获取，禁止跨场景选择器。
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免全局变量污染，确保多场景合并时互不干扰。
