[图示主题与整合说明]
- 本图示主题：功能关系与拉力做功分析（电磁感应综合题第（3）问）
- 整合的步骤/概念：
  1. 金属棒在圆弧轨道上某一般位置的受力分析（重力、拉力、安培力、支持力）；
  2. 能量转化流程（拉力做功输入 → 重力势能增加 + 回路焦耳热输出）；
  3. 功能关系方程建立（W_F + W_G + W_安 = ΔE_k = 0）；
  4. 热量分配与拉力做功定量计算（W_F = mgr + 3πrB²L²v₀/(16R)）。
- 教学价值：教师通过分步导航，先让学生建立"有哪些力做功"的直观图景，再理解"能量转化去向"，最后完成定量推导，实现从定性到定量的认知递进。

[交互方案]
- 交互类型：分步按钮导航（◀ 上一步 / 下一步 ▶）
- 控件说明：
  1. 「◀ 上一步」按钮：位于控件区左侧 (300,455)-(400,485)，点击后退一个步骤，步骤0时禁用（置灰）。
  2. 步骤指示器：位于控件区中央 (450,475)，显示当前步骤文字，如"步骤 1/4"。
  3. 「下一步 ▶」按钮：位于控件区右侧 (500,455)-(600,485)，点击前进一个步骤，步骤3时禁用（置灰）。
- 教师操作流程：
  1. 教师打开图示，默认进入步骤0，讲解受力分析（四个力的方向、做功情况）。
  2. 点击「下一步」进入步骤1，讲解能量转化定性分析（输入W_F，输出重力势能和焦耳热）。
  3. 点击「下一步」进入步骤2，讲解功能关系方程，强调匀速→动能不变→W_F = mgr + Q_总。
  4. 点击「下一步」进入步骤3，讲解热量分配（棒电阻R/3，总电阻4R/3），代入Q_R结果，得到最终W_F表达式。
  5. 可随时回退复习。

[技术实现]
- JS库选择：原生 SVG（所有元素均为几何图形、箭头、文本和矩形框，SVG完全胜任，无需引入外部库）。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图（ASCII）：
  ```
  +----------------------------------------------------------+
  |  受力分析图（左半区）          |  能量流程 + 公式（右半区） |
  |  x:20~380  y:40~420           |  x:420~780  y:40~420      |
  |                               |                           |
  |      O ●----→r                |    [能量转化流程]          |
  |        |  圆弧                 |    [W_F]→[ΔEp] [Q总]      |
  |       r↓  ↗ F                 |                           |
  |      cd ●  ● ab               |    [功能关系]              |
  |        /N|                    |    W_F + W_G + W_安 = 0    |
  |       /  |mg                  |    W_F = mgr + Q_总        |
  |      F_A ↓                    |    W_F = ...（结果）        |
  |                               |                           |
  +----------------------------------------------------------+
  |        [◀ 上一步]   步骤 X/4   [下一步 ▶]                  |
  |        x:300~400   x:450      x:500~600   y:455~485       |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 `scene3-step`（0~3）记录当前步骤。每步用一个配置对象描述该步应显示的元素ID列表。
  2. 元素显隐控制：所有可切换元素初始 `visibility="hidden"` 或 `display="none"`。切换步骤时，遍历当前步配置，对目标元素设置 `visibility="visible"`。
  3. 渐进显示动画（可选）：步骤3最终结果出现时，对公式行5添加 SVG SMIL `<animate>` 或 CSS `transition` 实现文字颜色从黑色到绿色、字体从小到正常的短暂动画（时长400ms）。
  4. 箭头标记：在 `<defs>` 中定义四个方向的 arrowhead marker（黑、蓝、红、灰），供不同力箭头复用。
  5. 公式排版：使用 `<text>` 嵌套 `<tspan>` 实现多行公式，行距 25~30px，避免重叠。
  6. 按钮事件：为「上一步」「下一步」rect/text 绑定 `click` 事件，更新状态机后调用 `scene3-render()` 重绘可见性。
- ID命名规范：所有元素ID必须以 `scene3-` 为前缀。例如：
  - 圆弧：`scene3-arc`
  - 拉力箭头：`scene3-force-f`
  - 拉力标签：`scene3-label-f`
  - W_F框：`scene3-box-wf`
  - 公式行3：`scene3-formula-line3`
  - 上一步按钮：`scene3-btn-prev`
  - 下一步按钮：`scene3-btn-next`
  - 步骤指示器：`scene3-step-indicator`
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })()` 中，避免多场景合并时全局变量污染。
- 坐标硬编码：所有x、y坐标在计划中已精确到像素，代码agent直接按上表实现，不得使用自动布局算法，以确保无重叠。
