题目原文

如图所示，在直角坐标系xOy中，虚线ab将第一象限分成两块区域，左边区域匀强电场沿x轴正方向，电场强度E₁，右边区域匀强电场方向沿y轴负方向，电场强度E₂。现一个质量为m（重力忽略不计），电荷量为q的正粒子静止放在y轴上的P（0，h）点，粒子在电场力的作用下运动，最后从x轴上的Q点离开电场区域，已知虚线ab距y轴的距离L，求：

（1）粒子穿过E₁电场区域的速度；
（2）粒子经过Q点的速度大小；
（3）Q点的坐标。

题目分析

本题是带电粒子在组合电场中的运动问题，核心物理过程分为两个阶段：

  1. 粒子在E₁区域（0 ≤ x ≤ L）从静止开始做初速度为零的匀加速直线运动，电场力水平向右，获得水平速度后到达虚线ab边界；
  2. 粒子进入E₂区域（x > L）后，电场力变为竖直向下，由于初速度水平且与受力方向垂直，粒子做类平抛运动，最终到达x轴上的Q点。

整体讲解思路

  1. 先帮助学生建立清晰的空间图景：两个电场区域的方向不同，虚线ab是分界线。
  2. 分区域分析运动性质：E₁区域是直线加速，E₂区域是类平抛，强调"类平抛"与平抛运动的类比。
  3. E₁区域可用动能定理或运动学公式求末速度；E₂区域必须采用运动分解（水平匀速+竖直匀加速）。
  4. 联立两个区域的方程，注意时间t是E₂区域的分运动时间，也是联系两个方向的关键量。
  5. 求Q点速度时，可引导学生先求分速度再用勾股定理，也可直接用全程动能定理作验证。

图示规划说明

  • Scene 1 展示全局运动轨迹，帮助学生建立从P到Q的完整空间图景，分步呈现两个区域的运动特征。
  • Scene 2 聚焦E₂区域的类平抛运动，通过位移分解和速度分解突破核心难点，强化正交分解的思想方法。
步骤 1/4

Scene 1 教学说明：全局运动轨迹

本图示的核心作用是帮助学生建立"组合电场中粒子运动"的完整空间图景，避免学生混淆两个区域的受力方向。

引导学生观察的要点：

  1. 步骤0让学生先识别电场方向：E₁区域力水平向右，E₂区域力竖直向下。提问："粒子带什么电？受力方向与电场方向有什么关系？"（正电荷，同向）
  2. 步骤1强调E₁区域的运动性质：初速度为零，受力与运动方向共线，因此是匀加速直线运动。可让学生思考："为什么轨迹是直线而不是曲线？"
  3. 步骤2是关键的认知转折点：粒子进入E₂区域时速度水平，但受力竖直向下，速度与力垂直，因此做类平抛运动。此处要类比平抛运动，激活学生已有认知。
  4. 步骤3总结时，让学生明确三个待求量分别对应哪个阶段：v₁是阶段1的末速度，v_Q和Q坐标是阶段2的结果。

E₁区域公式推导：

粒子在E₁区域受电场力 F₁ = qE₁，加速度 a₁ = qE₁/m。
由运动学公式 v₁² = 2a₁L，或动能定理 qE₁L = ½mv₁²，得：
$$v_1 = \sqrt{\frac{2qE_1L}{m}}$$

初态

Scene 2 教学说明：E₂区域运动分解

本图示聚焦E₂区域，通过"放大局部"的方式帮助学生突破类平抛运动分解这一核心难点。

引导学生观察的要点：

  1. 步骤0强调进入E₂区域的初始条件：速度水平（来自E₁区域的加速），受力竖直向下。提问："这与平抛运动有什么相同点？"（初速水平，受力垂直于初速且恒定）
  2. 步骤1展示位移分解时，重点说明两个分运动的独立性：水平方向不受力→匀速直线运动；竖直方向受恒定电场力→初速为零的匀加速直线运动。两个方向的运动时间t相同（等时性）。
  3. 步骤2展示速度分解时，让学生观察：水平速度为什么不变？（水平方向不受力）竖直速度如何变化？（v_y = a₂t，随时间线性增大）合速度方向如何变化？（逐渐向下偏转）
  4. 步骤3强调联立求解的逻辑：E₂区域有4个未知量（d, t, vy, vQ），需要4个独立方程，恰好对应4个公式。

E₂区域公式推导：

  1. 竖直方向求时间：由 $h = \frac{1}{2}a_2t^2$，其中 $a_2 = \frac{qE_2}{m}$，得 $t = \sqrt{\frac{2mh}{qE_2}}$
  2. 水平方向求位移：$d = v_1t = \sqrt{\frac{2qE_1L}{m}} \cdot \sqrt{\frac{2mh}{qE_2}} = 2\sqrt{\frac{E_1Lh}{E_2}}$
  3. 竖直分速度：$v_y = a_2t = \frac{qE_2}{m}\sqrt{\frac{2mh}{qE_2}} = \sqrt{\frac{2qE_2h}{m}}$
  4. Q点合速度：$v_Q = \sqrt{v_1^2 + v_y^2} = \sqrt{\frac{2qE_1L}{m} + \frac{2qE_2h}{m}} = \sqrt{\frac{2q}{m}(E_1L + E_2h)}$
  5. Q点坐标：$Q\left(L + 2\sqrt{\frac{E_1Lh}{E_2}},\ 0\right)$

简便方法提示：

求v_Q时，也可对全程使用动能定理：$qE_1L + qE_2h = \frac{1}{2}mv_Q^2$，结果与分步计算一致，可作为课堂验证手段。

完整解答与课堂总结

（1）粒子穿过E₁电场区域的速度

粒子在E₁区域受电场力 $F_1 = qE_1$，加速度 $a_1 = \frac{qE_1}{m}$。
由动能定理 $qE_1L = \frac{1}{2}mv_1^2$，得：
$$v_1 = \sqrt{\frac{2qE_1L}{m}}$$
方向沿x轴正方向。

（2）粒子经过Q点的速度大小

粒子在E₂区域做类平抛运动。水平方向匀速：$v_x = v_1$；竖直方向匀加速：$v_y = a_2t = \sqrt{\frac{2qE_2h}{m}}$。
合速度：
$$v_Q = \sqrt{v_x^2 + v_y^2} = \sqrt{\frac{2q}{m}(E_1L + E_2h)}$$

（3）Q点的坐标

竖直方向 $h = \frac{1}{2}a_2t^2$ 解得 $t = \sqrt{\frac{2mh}{qE_2}}$。
水平方向 $d = v_1t = 2\sqrt{\frac{E_1Lh}{E_2}}$。
因此Q点坐标为：
$$Q\left(L + 2\sqrt{\frac{E_1Lh}{E_2}},\ 0\right)$$

课堂讲解建议

  1. 类比迁移：反复强调E₂区域的"类平抛"特征，与重力场中的平抛运动进行类比，降低认知难度。
  2. 分区域意识：培养学生"画一条分界线，分左右列方程"的解题习惯，避免混淆两个区域的物理量。
  3. 一题多解：在求v_Q时，展示"分步求分速度再合成"和"全程动能定理"两种方法，体现能量观点的优越性。
  4. 量纲检验：最后可带领学生快速检查最终表达式的量纲是否正确（如v的量纲是LT⁻¹，坐标的量纲是L）。
