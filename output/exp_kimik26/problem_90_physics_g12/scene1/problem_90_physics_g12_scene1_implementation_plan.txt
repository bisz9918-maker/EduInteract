[图示主题与整合说明]
- 本图示主题：玻璃管三状态变化与封闭气体压强分析全过程
- 整合的步骤/概念：
  1. 甲状态（开口向上）水银柱受力分析与压强关系 P₁=P₀+h；
  2. 乙状态（开口向下）水银柱受力分析与压强关系 P₂=P₀−h；
  3. 玻意耳定律联立求解大气压强 P₀=75 cmHg；
  4. 丙状态（开口向下+活塞）几何识别与「中间气柱」的引入；
  5. 丙状态压强链推导 P₃=80、P₄=85；
  6. 中间气柱玻意耳定律与几何关系求解活塞距离 d=7 cm。
- 教学价值：教师通过分步导航控制课堂节奏，每步只呈现当前逻辑链必需的图示与公式，避免信息过载；学生可清晰看到从受力分析→气体定律→几何约束的完整推理链条，尤其步骤4对「中间气柱」的视觉高亮能有效防止学生漏掉这段隐蔽气体。

[分步序列]
- 步骤0「题目总览」（初始状态）：
  - 左侧仅显示甲状态玻璃管（开口向上，管顶平齐，管底圆角封闭）。
  - 水银柱位于y=174~200，气柱浅蓝填充y=200~380。
  - 标注：L=62cm（左）、h=5cm（右）、l₁=35cm（右）。
  - 右侧显示「待求量」标题，下方红字"P₀ = ?"、"d = ?"。
  - 底部控件显示"步骤 0/6"。

- 步骤1「甲状态压强分析」：
  - 左侧：甲状态玻璃管，水银柱加蓝色高亮边框（#1565c0，2px）。
  - 右侧上部：水银柱隔离体方块(555,120)-(615,170)。
    - 向上绿箭头从方块底面中心(585,170)延伸至(585,100)，标注"P₁"于(585,85)。
    - 向下红箭头从方块顶面中心(585,120)延伸至(585,190)，标注"P₀+h"于(585,205)。
  - 右侧下部：公式"P₁ = P₀ + h"（y=240，蓝），提示文字"水银柱受力平衡"（y=320，灰）。

- 步骤2「乙状态压强分析」：
  - 左侧：乙状态玻璃管（开口向下，管顶圆角封闭，管底平齐开口）。
    - 气柱浅蓝填充y=60~267，水银柱y=267~293。
    - 标注：L=62cm（左）、l₂=40cm（右）、h=5cm（右）。
    - 管底下方标注"乙"。
  - 右侧上部：隔离体方块同上。
    - 向上绿箭头标注"P₀"（来自大气对水银柱底面的向上压力）。
    - 向下红箭头标注"P₂+h"（上方气体向下压强+水银柱自重等效压强）。
  - 右侧下部：公式"P₂ = P₀ − h"（y=240，蓝）。

- 步骤3「求大气压强 P₀」：
  - 左侧：甲乙两管并排缩小展示。
    - 甲管中心x=150（左135右165），标注l₁；乙管中心x=310（左295右325），标注l₂。
    - 两管水银柱均显示，气柱浅蓝填充。
  - 右侧公式区（x=460起，左对齐）：
    - 标题"玻意耳定律"（y=80，蓝）。
    - 行1："P₁V₁ = P₂V₂"（y=120）。
    - 行2："(P₀ + h) · l₁ = (P₀ − h) · l₂"（y=170，蓝高亮变量）。
    - 行3：代入"(P₀ + 5) × 35 = (P₀ − 5) × 40"（y=220）。
    - 行4：展开"35P₀ + 175 = 40P₀ − 200"（y=270，高亮数值）。
    - 结果："P₀ = 75 cmHg"（y=340，红，18px加粗）。

- 步骤4「丙状态几何」：
  - 左侧：丙状态玻璃管（开口向下）。
    - 上端气柱浅蓝y=60~241，水银柱y=241~267。
    - 活塞位于y=344~350（棕色）。
    - 中间气柱区域y=267~344使用浅绿虚线框（#888888 虚线1px）包裹，提示学生注意。
    - 标注：L=62cm（左）、l₁=35cm（右）、h=5cm（右）。
  - 右侧：
    - 提示1："塞入活塞后，水银柱与活塞之间形成新的封闭气柱"（y=120）。
    - 提示2："这段「中间气柱」是解题关键"（y=160，绿）。
    - 小示意图：绿色矩形(560,220)-(640,260)代表中间气柱。

- 步骤5「丙状态压强链」：
  - 左侧：丙状态玻璃管，中间气柱改为实色浅绿填充（透明度25%），标注"x"于右侧(250,305)（红）。
  - 右侧压强链（x=520~700）：
    - 框1（蓝）："上端气体  P₃ = 80 cmHg"（y=80~115）。
    - 向下箭头（y=115~135）。
    - 框2（灰）："水银柱  h = 5 cmHg"（y=135~170）。
    - 向下箭头（y=170~190）。
    - 框3（绿）："中间气体  P₄ = 85 cmHg"（y=190~225）。
    - 向下箭头（y=225~245，虚线，表示活塞外力平衡）。
    - 框4（黑）："大气  P₀ = 75 cmHg"（y=245~275）。
  - 推导文字（x=460）：
    - "P₃ × 35 = P₂ × 40 = 70 × 40"（y=295）。
    - "∴ P₃ = 80 cmHg"（y=325，蓝）。
    - "∴ P₄ = P₃ + h = 85 cmHg"（y=355，绿）。

- 步骤6「求活塞距离 d」：
  - 左侧：丙状态玻璃管完整标注，中间气柱标注"x = 15"（右250,305，红），活塞下方标注"d"（右250,365，红）。
  - 右侧：
    - 标题"中间气柱的玻意耳定律"（y=80）。
    - "P₀ · 17 = P₄ · x"（y=120）。
    - "75 × 17 = 85 × x"（y=160）。
    - "x = 15 cm"（y=200，红）。
    - 标题"几何关系"（y=250）。
    - "l₁ + h + x + d = L"（y=290）。
    - "35 + 5 + 15 + d = 62"（y=330，高亮）。
    - "d = 7 cm"（y=380，红，20px加粗，带轻微闪烁动画或高亮边框）。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 步骤显示 / 下一步 ▶ / 重置）。
- 控件说明：
  1. 「◀ 上一步」按钮：位于(250,455)，宽90高32。点击后currentStep减1（最小为0），回退到前一步状态，所有元素同步切换。
  2. 「步骤显示」只读文本：位于(370,455)，宽80高32，显示"步骤 k/6"。
  3. 「下一步 ▶」按钮：位于(480,455)，宽90高32。点击后currentStep加1（最大为6），前进到下一步状态。
  4. 「重置」按钮：位于(600,455)，宽70高32。点击后currentStep归零，回到步骤0。
- 教师操作流程：
  1. 课堂开始时点击「下一步」进入步骤0，展示题目总览，让学生读题并识别已知量。
  2. 点击「下一步」进入步骤1，讲解甲状态水银柱受力，强调向下的大气压力与水银自重之和等于向上的封闭气体压力。
  3. 继续点击「下一步」进入步骤2，玻璃管变为乙状态，讲解旋转后水银柱掉落，受力方向改变。
  4. 进入步骤3，展示玻意耳定律联立，带领学生代入数值解出P₀=75。
  5. 进入步骤4，引入丙状态，特别强调虚线框内的「中间气柱」，这是学生最易遗漏的隐蔽气体。
  6. 进入步骤5，分三层展示压强链，推导P₃与P₄。
  7. 进入步骤6，先由玻意耳定律求出中间气柱长度x=15，再代入几何关系求出d=7cm，完成全题。
  8. 可随时点击「上一步」回退复习，或「重置」重新开始。

[技术实现]
- JS库选择：原生 SVG + 原生 JavaScript。理由：本场景全部为静态几何图形、简单箭头与文本切换，无复杂函数绘图或3D，原生SVG性能最优且无需额外CDN依赖。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |  [左侧主图示区 0~440px]      [右侧推导区 440~800px] |
  |                                                      |
  |   ┌──┐                      ┌──────────────┐       |
  |   │  │  玻璃管               │ 受力分析/公式 │       |
  |   │██│  (甲/乙/丙)           │              │       |
  |   │██│                      │  P₁ = P₀+h   │       |
  |   │  │                      │              │       |
  |   │  │                      └──────────────┘       |
  |   └──┘                                              |
  |                                                      |
  |   [◀ 上一步] [步骤 0/6] [下一步 ▶] [重置]            |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用全局变量 `let scene1_currentStep = 0;`，范围0~6。每一步对应一个SVG `<g>` 组，ID为 `scene1-step-k`（k=0..6）。切换时遍历所有step组，设置 `display: none` 或 `display: block`。
  2. 坐标计算：玻璃管总高320px对应62cm，比例系数 `scene1_scale = 320/62 ≈ 5.161` px/cm。所有长度标注均通过此比例换算，确保视觉比例与真实物理比例一致。
  3. 动画曲线：步骤切换采用瞬时切换（无过渡动画），保证课堂讲解时响应迅速；仅在步骤6最终结果 "d = 7 cm" 上使用CSS `@keyframes pulse` 实现轻微闪烁高亮（0.8s周期，透明度0.7↔1.0），吸引学生注意。
  4. 事件绑定：按钮通过 `onclick` 属性直接绑定 `scene1_prevStep()`、`scene1_nextStep()`、`scene1_reset()` 函数。所有函数包裹在IIFE中，避免全局污染。
  5. 元素显隐：非当前步骤的辅助标注（如步骤4的虚线框、步骤5的压强链）默认 `display:none`，仅在对应步骤显示。同位置不同步骤的标签（如步骤1的P₁与步骤2的P₀）分属不同 `<g>` 组，互不干扰。
  6. 玻璃管绘制：使用 `<path>` 绘制圆角封闭端（甲管底端、乙丙管顶端），命令如 `M 205 380 A 15 15 0 0 1 235 380`；开口端使用平齐直线。
  7. 尺寸标注线：使用 `<line>` 绘制引线，`<text>` 标注数值，引线端点使用短垂线（`<line stroke="#888888" stroke-dasharray="2,2">`）连接被测段落的上下端点。
- ID命名规范：所有SVG元素及JS变量均以 `scene1-` 为前缀。例如：
  - 玻璃管外框：`scene1-tube-outline`
  - 甲状态水银柱：`scene1-mercury-a`
  - 步骤0组：`scene1-step-0`
  - 上一步按钮：`scene1-btn-prev`
  - 步骤显示文本：`scene1-step-display`
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，内部函数通过 `window.scene1_nextStep = ...` 仅暴露必要的按钮回调，防止与其他场景的脚本冲突。
