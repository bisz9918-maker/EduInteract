[图示主题与整合说明]
- 本图示主题：等边三角形三带电小球系统的整体运动关系
- 整合的步骤/概念：
  1) 建立几何直观——A、B、C 三球构成等边三角形（AB 竖直）；
  2) 标注已知条件——质量 m、间距 r、A/B 带正电 +q、C 带电性未知；
  3) 引入外力与运动——水平力 F 作用于 C，系统整体加速度 a；
  4) 整体法结论——系统合外力 F = 3ma。
- 教学价值：教师可按照"几何→已知→受力→结论"的课堂引入节奏，逐层点击展开，避免信息过载，学生注意力随步骤聚焦。

[分步序列]
- 步骤0（初始状态）：显示 A、B、C 三球及三条虚线构成的等边三角形，建立几何直观。显示 A/B/C 点名标签。
- 步骤1（点击「下一步」）：叠加已知条件——三球旁标注质量 m；A、B 球心标注 +q（红色），C 球心标注 ?（蓝色）；三边外侧标注间距 r。所有新增元素以 opacity 0→1 淡入（0.3s）。
- 步骤2（点击「下一步」）：叠加外力与运动——从 C 球中心向右绘制力 F 箭头（黑色粗线），标注 F；在三角形重心偏上位置绘制加速度 a 箭头（绿色），标注 a。淡入。
- 步骤3（点击「下一步」/最终步骤）：在图形正下方展示整体法结论公式 "F = 3ma"，字体加粗并配浅黄背景框高亮，表示系统受合外力 F，总质量 3m，故加速度 a = F/(3m)。淡入。
- 教师可随时点击「上一步」回退，对应元素以 opacity 1→0 淡出（0.2s）。

[交互方案]
- 交互类型：分步按钮导航（◀ 上一步 / 下一步 ▶）
- 控件说明：
  1. 「上一步」按钮：位于 SVG 内底部左侧 (280,460)，宽 80×30，点击回退到上一状态，步骤0 时禁用（opacity 0.4）。
  2. 「下一步」按钮：位于 SVG 内底部右侧 (440,460)，宽 80×30，点击推进到下一状态，步骤3 时禁用。
  3. 步骤指示器：位于两按钮之间 (380,470)，显示当前步骤序号 "1 / 4" ~ "4 / 4"。
- 教师操作流程：
  1. 教师打开图示，学生看到三球等边三角形（步骤0），建立空间关系；
  2. 点击「下一步」，已知条件 m、r、q 逐层出现，教师讲解题目给定条件；
  3. 点击「下一步」，F 与 a 箭头出现，教师引导学生思考外力与整体运动；
  4. 点击「下一步」，公式 F=3ma 高亮出现，教师给出整体法结论，完成引入。
  5. 可随时回退复习某一步。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript。理由：本场景为静态几何图形与分步显隐，无复杂数据绑定、函数绘图或 3D，原生 SVG 足够轻量且可控。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |                                                  |
  |        A(348,160)                                |
  |         ○ ←+q                                   |
  |        / \  m(A)                                 |
  |       /   \  r(AC)                               |
  |      /  a  \                                     |
  |     /  →   \                                     |
  |    /         ○ C(504,250) →→→→ F                 |
  |   /  ?  m(C)  ○                                  |
  |  /             \                                 |
  | /   r(BC)       \                                |
|/  m(B)           \                               |
  |○ B(348,340)                                      |
  |                                                  |
  |              F = 3ma  (步骤3显示)                |
  |                                                  |
  |    [◀ 上一步]  2 / 4  [下一步 ▶]                 |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：变量 `currentStep` ∈ {0,1,2,3}。每一步对应一组元素 ID 列表，切换时遍历显隐。
  2. 元素显隐：使用 CSS class `.scene1-hidden { opacity: 0; pointer-events: none; }` 与 `.scene1-visible { opacity: 1; transition: opacity 0.3s; }`，通过 JS 切换 class 实现淡入淡出。
  3. 箭头 marker：在 `<defs>` 中定义 arrow-black（F）与 arrow-green（a）两个 marker，供 path 的 `marker-end` 引用。
  4. 按钮禁用逻辑：`currentStep === 0` 时禁用「上一步」；`currentStep === 3` 时禁用「下一步」。
  5. 公式高亮：步骤3 时给公式 text 添加高亮 class，改变 font-weight 并附加背景 rect（#fff9c4，rx=4）。
  6. 文字居中：球心文字（+q、?）使用 `text-anchor="middle" dominant-baseline="central"` 确保严格居中。
- ID 命名规范：所有交互元素 ID 必须以 `scene1-` 为前缀。例如：
  - 球：`scene1-ball-a`、`scene1-ball-b`、`scene1-ball-c`
  - 标签：`scene1-label-a`、`scene1-label-m-a`、`scene1-label-q-a`
  - 箭头：`scene1-arrow-f`、`scene1-arrow-a`
  - 按钮：`scene1-btn-prev`、`scene1-btn-next`
  - 步骤指示：`scene1-step-indicator`
  - JS 中严格使用 `document.getElementById` 获取，禁止全局 class 查询，避免多场景合并时跨场景污染。
- IIFE 隔离：所有 JS 逻辑包在 `(function() { ... })()` 中，内部变量不泄露全局作用域。
