[图示主题与整合说明]
- 本图示主题：C球隔离受力分析与外力F推导
- 整合的步骤/概念：以C球为隔离体，展示A对C与B对C的库仑引力、利用对称性分析竖直分量抵消、合成水平库仑合力、引入外力F与加速度a、列牛顿第二定律方程、代入数据得到F的最终表达式
- 教学价值：教师通过分步导航，逐步展示从分力到合力再到运动方程的完整推导链条，突出对称性分析和矢量合成思想，帮助学生建立隔离法与正交分解的解题规范

[分步序列]
- 初始状态（步骤0）：显示等边三角形框架（A、B、C三球及AB、AC、BC虚线连线），A与B淡化（opacity 0.3），C球高亮（黑框3px）；显示角度标注30°（上下各一）；突出C为分析对象
- 步骤1：点击「下一步」→ 显示A对C的库仑引力F_AC（蓝色箭头，从C球表面沿CA方向指向A，长度100px），显示标签"F_AC"
- 步骤2：点击「下一步」→ 显示B对C的库仑引力F_BC（蓝色箭头，从C球表面沿CB方向指向B，长度100px），显示标签"F_BC"；同时显示等力标注"F_AC=F_BC"（位于两力之间左侧）
- 步骤3：点击「下一步」→ 从F_AC、F_BC箭头端点分别向水平线y=250作竖直投影虚线，两线交于(264,250)；显示抵消标记"⊗"（或文字"抵消"），表示竖直分量大小相等、方向相反、互相抵消
- 步骤4：点击「下一步」→ 显示水平向左的库仑合力F_库（紫色箭头，长度173px，从C球表面起水平向左），显示标签"F_库"及合力公式"F_库=2F_AC·cos30°"
- 步骤5：点击「下一步」→ 显示水平外力F（黑色箭头向右，长度260px，从C球表面起），显示标签"F"；显示加速度a（绿色箭头向右，位于C球正上方，长度60px），显示标签"a"
- 步骤6：点击「下一步」→ 在画面右侧显示牛顿第二定律方程"F - F_库 = ma"
- 步骤7：点击「下一步」→ 高亮显示最终结果公式"F = 3√3 kq²/r²"（绿色加粗），完成推导
（教师可随时点击「上一步」回退复习，按钮在边界步骤自动禁用）

[技术实现]
- JS库选择：原生SVG（首选）+ 原生JavaScript。理由：本场景为静态几何图形与箭头标注，SVG的矢量渲染清晰，且通过display/opacity控制显隐即可实现分步动画，无需引入重型库
- 画布尺寸：800×500 px（SVG viewBox="0 0 800 500"）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  A●        a→                                    |
  |   \       ●C━━━━━━→F                             |
  |    \    ↗  ↖                                     |
  |     \  /    \   F_库←━━━━━━                        |
  |      ●B      F_AC ↗  ↖ F_BC                      |
  |                 30°  30°                         |
  |                                                  |
  |           F-F_库=ma                              |
  |           F=3√3kq²/r²                            |
  |                                                  |
  |              [◀上一步]  [下一步▶]                 |
  +--------------------------------------------------+
  控件栏位于y=440~490（绝对定位覆盖在SVG上）
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `let currentStep = 0;`，定义数组 `stepElements` 记录每步应显示的元素ID集合
  2. 坐标计算：等边三角形边长260px，A(140,120)、B(140,380)、C(365,250)；所有力箭头从球表面起算（球心+半径×方向单位向量）
  3. 动画曲线：分步切换不使用连续动画，直接改变 `display` 属性（或opacity 0→1过渡200ms），保证课堂讲解节奏可控
  4. 事件绑定：按钮点击事件更新currentStep，调用 `renderStep()` 函数遍历所有元素，按当前步骤设置 `display: block/none`
  5. 箭头实现：使用SVG <defs>定义箭头标记（<marker>），分别定义蓝色、紫色、黑色、绿色四种arrowhead，通过marker-end引用
  6. 角度弧实现：使用SVG path的arc命令，半径30px，分别绘制150°→180°和180°→210°两段弧
- ID命名规范：所有SVG元素及控件ID必须以 `scene3-` 为前缀，例如 `scene3-ball-c`、`scene3-force-ac`、`scene3-btn-next` 等；JS中严格使用 `document.getElementById` 获取元素
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })();` 中，避免多场景合并时的全局变量污染
- 样式隔离：SVG及控件容器使用外层div `#scene3-container`，所有CSS选择器以前缀 `#scene3-container` 限定作用域
