**完整题目原文：**

如图1，已知线段AB=8，点C是AB上的一动点（不包括A、B），在AB同侧作两个等边三角形ACD和BCE，连DE，点P、F分别是DE和BE的中点，连接AF，分别交DC、CE于G、H．

（1）写出图中所有的相似三角形（除等边三角形ACD和BCE外）；

（2）当点C在AB中点时，如图2，求CP的长及AG：GH：HF；

（3）点M、N是线段AB上两点，且AM=BN=2，当点C从点M向点N运动时，求点P所经过的路径长．

**题目分析：**

本题以共底边的双等边三角形为载体，综合考查相似三角形判定、特殊位置数值计算及动点轨迹问题。核心突破口在于发现 **CG // BE**，从而得到关键相似对 △ACG ~ △ABF；同时利用绕点C的旋转全等 △ACE ≅ △DCB 建立边与角的转移。第(2)问可借助对称性大幅简化计算；第(3)问则通过坐标参数化揭示P点纵坐标为定值，轨迹为水平线段。

**整体讲解思路：**

1. 先建立图1完整构图，帮助学生识别已知条件与所有交点
2. 引导学生发现 CG // BE（可通过斜率或同位角），这是第(1)问的“题眼”
3. 利用平行线性质得出 △ACG ~ △ABF，并结合旋转说明 △ACE ≅ △DCB
4. 将点C特殊化至AB中点，利用对称性解决第(2)问的CP与比例
5. 最后通过参数化坐标探索P点运动规律，解决第(3)问轨迹长度

设计两个Scene。Scene 1 整合图1与图2，采用分步按钮导航，从一般构图逐步推进到特殊位置，覆盖第(1)(2)问；Scene 2 采用连续拖拽滑块，直观展示C在MN区间运动时P点的轨迹，覆盖第(3)问。

**Scene 1 教学说明：**

本图示整合了图1的一般状态与图2的特殊状态，教师应引导学生按以下逻辑观察：

1. **步骤0-1：建立基本认知**
   让学生快速识别已知条件：AB=8，两个等边三角形共底边AB同侧，P、F为中点。强调等边三角形带来的60°角和三边相等关系，这是后续所有角度推导的基石。

2. **步骤2：发现平行（题眼）**
   教师可提问："AF与DC交于G，你能否发现G点产生的某条线段与BE平行？"引导学生计算或观察CG与BE的斜率（均为 -√3），或利用同位角证明 CG // BE。一旦平行关系确立，△ACG ~ △ABF（AA）便自然得出：公共角∠CAG = ∠BAF，且∠ACG = ∠ABF = 60°。相似比为 AC:AB。

3. **步骤3：旋转全等**
   将△ACE绕点C顺时针旋转60°，由于CA→CD、CE→CB，旋转后△ACE与△DCB完全重合。因此△ACE ≅ △DCB（SAS），得到 AE = DB，∠CAE = ∠CDB。这一全等为理解PF与AE、DB的关系（中位线）埋下伏笔。

4. **步骤4：对称性求CP**
   当C为AB中点时，AC = CB = 4，图形关于直线x=4对称。此时D(2, 2√3)，E(6, 2√3)，故DE // AB且DE = 4。P为DE中点，故P(4, 2√3)。又C(4,0)，因此CP垂直于AB，长度即为等边三角形ACD的高：CP = 4 × √3/2 = **2√3**。

5. **步骤5：坐标法求比例**
   在图2中，F为BE中点，B(8,0)，E(6, 2√3)，故F(7, √3)。直线AF的方程为 y = (√3/7)x。联立DC方程 y = -√3(x-4) 得 G(7/2, √3/2)；联立CE方程 y = √3(x-4) 得 H(14/3, 2√3/3)。计算距离：
   - AG = √13
   - AH = 4√13/3
   - AF = 2√13
   因此 GH = AH − AG = √13/3，HF = AF − AH = 2√13/3，得 **AG : GH : HF = 3 : 1 : 2**。

**总结与课堂讲解建议：**

**完整解答：**

1. **第(1)问——相似三角形：**
   图中相似三角形主要有：
   - **△ACG ~ △ABF**。证明：由等边三角形性质知∠ACD = ∠BCE = 60°，通过坐标法或角度推导可得 CG // BE（斜率均为 -√3），从而∠ACG = ∠ABF = 60°，又∠CAG = ∠BAF为公共角，故△ACG ~ △ABF（AA）。
   - **△ACE ~ △DCB**（实为全等）。证明：将△ACE绕点C顺时针旋转60°，CA与CD重合，CE与CB重合，故△ACE ≅ △DCB（SAS），全等是相似比为1的特殊情形。

2. **第(2)问——CP与比例：**
   当C为AB中点时，AC = CB = 4。建立坐标系：A(0,0)，B(8,0)，C(4,0)，则D(2, 2√3)，E(6, 2√3)。P为DE中点，故P(4, 2√3)，因此 **CP = 2√3**。F为BE中点，得F(7, √3)。直线AF：y = (√3/7)x；直线DC：y = -√3(x−4)；直线CE：y = √3(x−4)。求得交点G(7/2, √3/2)，H(14/3, 2√3/3)。计算得 AG = √13，AH = 4√13/3，AF = 2√13，故 GH = √13/3，HF = 2√13/3，所以 **AG : GH : HF = 3 : 1 : 2**。

3. **第(3)问——轨迹长度：**
   设AC = a，则D(a/2, a√3/2)，E((8+a)/2, (8−a)√3/2)。P为DE中点，故
   $$x_P = \frac{1}{2}\left(\frac{a}{2} + \frac{8+a}{2}\right) = \frac{a+4}{2}, \quad y_P = \frac{1}{2}\left(\frac{a\sqrt{3}}{2} + \frac{(8-a)\sqrt{3}}{2}\right) = 2\sqrt{3}.$$
   因此P的纵坐标恒为 **2√3**，轨迹是一条水平线段。当C从M（AM=2，即a=2）运动到N（BN=2，即a=6）时，x_P从3变到5，故点P所经过的路径长为 **2**。

**课堂讲解建议：**

- **第(1)问**要留给学生足够的观察时间，引导他们自己发现 **CG // BE** 这一关键平行关系。可以提示学生关注斜率或同位角，避免直接告知结论。
- **第(2)问**是展示“对称性+坐标法”威力的好时机。教师可先让学生猜测CP的长度，再利用坐标精确验证，强化数形结合思想。
- **第(3)问**重在“动中求静”。通过Scene 2的拖拽交互，学生能直观看到P点沿水平线运动，此时再引入坐标参数化推导，从感性认识上升到理性证明，教学效果更佳。最后可升华：P的轨迹长度与AB总长无关，只与MN区间长度有关，体现参数变化的内在规律。
