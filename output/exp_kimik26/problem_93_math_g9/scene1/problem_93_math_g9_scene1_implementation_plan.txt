[分步序列]
- 步骤0（初始）：显示完整图1。C位于AC=3（x=345）。所有基础点线可见：AB、△ACD（黑框）、△BCE（黑框）、DE、BE、AF、DC、CE。标签A,B,C,D,E,P,F,G,H及AB=8。中点标记P,F可见。
- 步骤1：高亮△ACD（蓝填充+描边）和△BCE（绿填充+描边）。在A,C,D,B,C,E六点添加60°角弧标记；在AC,CD,DA,CB,CE,EB六边中点添加等长短斜线标记。强化等边性质。
- 步骤2：保持步骤1高亮。新增CG线段（红色，C→G），在CG与BE上加同向平行箭头，右侧显示"CG // BE"。高亮△ACG与△ABF（红色描边，线宽2.5px），右侧显示"△ACG ~ △ABF"及相似比文字"∠CAG公共，∠ACG=∠ABF=60°"。
- 步骤3：保持基础图1。高亮△ACE与△DCB（蓝色描边）。画出对应连线AE与DB（灰色虚线）。右侧显示"△ACE ≅ △DCB"及"绕点C旋转60°"。
- 步骤4：C点从x=345平滑动画至x=400（历时800ms，ease-in-out），图形过渡为对称图2。D,E,P,F,G,H及所有相关线段实时重算并更新。动画完成后：显示垂线段CP及C点直角符号；标注AC=4、CB=4、CP=2√3。此时两等边三角形对称。
- 步骤5：在图2基础上，将AF线段分为三段着色：AG（红）、GH（蓝）、HF（绿），线宽加粗至3px。在右侧空白区显示比例结论"AG:GH:HF = 3:1:2"。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  1. 「上一步」按钮：位于(300,460)，宽80×高30。点击回退到上一分步，隐藏当前步新增元素，恢复上一步状态。
  2. 「下一步」按钮：位于(420,460)，宽80×高30。点击推进到下一分步，显示该步新增元素/高亮/动画。
  3. 步骤指示器：位于(400,450)，显示"步骤 k/5"。
- 教师操作流程：
  1. 教师加载页面，学生看到完整图1基础构图（步骤0）。
  2. 教师点击「下一步」进入步骤1，引导学生观察两个等边三角形的构造与60°角。
  3. 继续点击「下一步」进入步骤2，教师讲解CG//BE的判定（同位角60°），并引出△ACG~△ABF。
  4. 步骤3展示旋转全等△ACE≅△DCB，教师可强调AE=DB的结论。
  5. 步骤4播放C移至中点的动画，教师利用对称性讲解CP⊥AB及CP=2√3。
  6. 步骤5展示AF三段比例，教师给出AG:GH:HF=3:1:2的最终结论。
  7. 讲解中可随时点击「上一步」回退到任意步骤重新强调。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本场景为纯2D几何图形，无复杂函数曲线或3D，原生SVG路径、线段、文本足以精确控制；原生JS避免引入不必要依赖，保证多场景合并时轻量且无污染。
- 画布尺寸：800 × 500 px（SVG viewBox="0 0 800 500"）。控件栏使用HTML div绝对定位叠在SVG上方，bottom:10px，不撑高容器。
- 布局草图：
  ```
  +------------------------------------------+  y=0
  |                                          |
  |         主图区（几何图形+标签）            |  y=30~430
  |              800 × 400                    |
  |                                          |
  |     D/E在上方，AB在y=320，右侧留结论区     |
  |                                          |
  +------------------------------------------+  y=430
  |        [◀上一步]  步骤k/5  [下一步▶]       |  y=440~490
  +------------------------------------------+  y=500
  ```
- 关键实现要点：
  1. 状态机：用变量 `currentStep`（0~5）控制当前步骤。每步切换时调用 `renderStep()`，根据步骤号设置各SVG元素的 `display` / `stroke` / `fill` / `opacity` 属性。
  2. 坐标计算：编写 `computeGeometry(cx)` 函数，输入C点x坐标，返回所有点坐标对象（A,B,C,D,E,P,F,G,H）。其中D,E由等边三角形高公式实时计算；G,H通过解线性方程组（线段交点）实时计算。步骤4动画使用 `requestAnimationFrame` 在800ms内将cx从345插值到400，每帧调用 `computeGeometry` 更新所有 `<line>` / `<circle>` / `<text>` 的坐标属性。
  3. 动画曲线：C点移动使用 easeInOutCubic（t<0.5 ? 4*t³ : 1-(-2*t+2)³/2），使过渡自然。
  4. 事件绑定：上一步/下一步按钮绑定click事件，更新 `currentStep` 后调用 `renderStep()`。若从步骤3进入步骤4，先启动动画，动画结束后再显示CP、直角符号等步骤4专属元素；若从步骤4回退到步骤3，立即将C重置到x=345并恢复图1所有坐标。
  5. 步骤5的AF分段：在图2状态下，利用已计算的A,G,H,F四点坐标，绘制三条独立线段（scene1-seg-AG、scene1-seg-GH、scene1-seg-HF），分别设置红/蓝/绿色，并隐藏原AF线段。
  6. 右侧结论文字：使用绝对定位的HTML div或SVG `<text>`，步骤切换时控制其 `display` 属性。步骤2与步骤3文字共用同一位置(650,150)，互斥显示。
- ID命名规范：所有SVG元素及控件ID必须以 `scene1-` 为前缀。例如：
  - 线段AB: `scene1-line-ab`
  - 点C圆: `scene1-point-c`
  - △ACD填充: `scene1-tri-acd-fill`
  - 步骤文字: `scene1-text-similar`
  - 按钮: `scene1-btn-prev`, `scene1-btn-next`
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })()` 中，避免全局变量污染。事件处理函数亦在IIFE内部定义。
