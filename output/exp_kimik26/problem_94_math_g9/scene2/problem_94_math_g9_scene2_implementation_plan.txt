[图示主题与整合说明]
- 本图示主题：三棱柱表面展开图的选项辨析与排除
- 整合的步骤/概念：面数统计 → 三角形底面位置关系检验 → 错误选项排除 → 正确答案确认并关联立体图
- 教学价值：教师通过分步导航控制课堂节奏，引导学生从"数面"到"看位置"逐步排除错误选项，最终建立展开图与立体图之间的对应关系，培养空间想象能力。

[分步序列]
- 初始状态（步骤0）：整体观察
  - 显示2×2网格四个选项（A左上、B右上、C左下、D右下）
  - 所有图形黑色轮廓，线宽2px，无填充
  - 显示选项字母A/B/C/D于各图形正下方
  - 无高亮、无排除标记、无面数标签
  - 控件栏显示"步骤 1/4"

- 步骤1：数面数
  - 点击「下一步」后变化：
  - 每个选项右下角弹出面数标签：A"5 个面"、B"5 个面"、C"4 个面"、D"3 个面"
  - C、D选项区域背景填充浅红色（#ffebee，opacity 0.3）
  - C、D中心出现红色叉号（×），表示因面数不足排除
  - A、B外框出现蓝色高亮边框（#1565c0，2px），表示保留
  - 控件栏显示"步骤 2/4"

- 步骤2：看三角形位置
  - 点击「下一步」后变化：
  - A、B中的两个三角形填充红色高亮（#c62828，opacity 0.3）
  - B选项：两三角形均位于矩形条上方（同侧），在B左侧显示红色虚线箭头（从上方三角形向下指，示意折叠冲突），标注文字"底面同侧，无法折叠"，并打上红色叉号（×）排除
  - A选项：两三角形分别位于上下两侧，标注文字"底面分居两侧"，打上绿色对勾（√）
  - C、D保持步骤1的排除状态不变
  - 控件栏显示"步骤 3/4"

- 步骤3：确认答案
  - 点击「下一步」后变化：
  - 选项A放大并移至画布中央（占宽50%、高60%），添加绿色边框（#2e7d32，3px）和大型绿色对勾
  - A右侧补充小尺寸三棱柱立体图（绿色线条绘制）
  - 用虚线箭头（#888888，虚线）连接展开图A与立体图，示意"此展开图可折叠为三棱柱"
  - 顶部显示标题"正确答案：A"
  - B、C、D三个选项缩小至30%并移至底部（y≈400），透明度降至20%，作为淡化参考
  - 控件栏显示"步骤 4/4"

- 教师可随时点击「上一步」回退至任意步骤复习

[标签冲突检查]
列出所有标签名及其预计坐标，逐对检查间距：
- 标签"A"：坐标(200, 200)
- 标签"B"：坐标(600, 200)
- 标签"C"：坐标(200, 410)
- 标签"D"：坐标(600, 410)
- 标签"5 个面"(A)：坐标(280, 170)
- 标签"5 个面"(B)：坐标(680, 170)
- 标签"4 个面"(C)：坐标(280, 370)
- 标签"3 个面"(D)：坐标(680, 370)
- 标签"底面分居两侧"(A)：坐标(200, 245)
- 标签"底面同侧，无法折叠"(B)：坐标(600, 245)
- 标签"正确答案：A"：坐标(400, 40)

逐对检查：
- "A"(200,200)与"5 个面"(280,170)：间距≈85px → 不冲突
- "A"(200,200)与"底面分居两侧"(200,245)：间距=45px → 不冲突
- "B"(600,200)与"5 个面"(680,170)：间距≈85px → 不冲突
- "B"(600,200)与"底面同侧"(600,245)：间距=45px → 不冲突
- "C"(200,410)与"4 个面"(280,370)：间距≈89px → 不冲突
- "D"(600,410)与"3 个面"(680,370)：间距≈89px → 不冲突
- "正确答案：A"(400,40)与最近标签"A"(200,200)：间距≈206px → 不冲突
- 所有排除/确认标记（叉号/对勾）位于选项中心，与最近面数标签间距>80px → 不冲突
- 结论：所有标签间距均≥45px，无重叠冲突。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于控件栏左侧(280,455)，宽80高30，点击回退到上一状态
  - 步骤指示器：位于控件栏中央(400,470)，显示当前步骤编号"步骤 X/4"
  - 「下一步」按钮：位于控件栏右侧(440,455)，宽80高30，点击前进到下一状态
  - 步骤0时「上一步」禁用（或隐藏），步骤3时「下一步」禁用（或隐藏）
- 教师操作流程：
  1. 教师展示步骤0，让学生整体观察四个选项
  2. 点击「下一步」进入步骤1，引导学生数每个图形的面数，观察C、D因面数不足被排除
  3. 点击「下一步」进入步骤2，引导学生观察A、B中三角形的位置关系，理解B因底面同侧被排除
  4. 点击「下一步」进入步骤3，确认A为正确答案，并展示展开图与立体图的对应关系
  5. 可随时回退复习关键判断依据

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。原因：本场景主要由简单几何图形（矩形、三角形、线条、路径）构成，无需复杂图表库；原生SVG可精确控制每个元素的坐标、描边、填充和透明度，且便于通过class/ID控制显示隐藏。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |  [标题区: 步骤3显示"正确答案：A"]                   |
  |                                                  |
  |  +-----------+        +-----------+              |
  |  |     A     |        |     B     |   上半区     |
  |  |  [图形]   |        |  [图形]   |   y=20~220   |
  |  |    A      |        |    B      |              |
  |  +-----------+        +-----------+              |
  |                                                  |
  |  +-----------+        +-----------+              |
  |  |     C     |        |     D     |   下半区     |
  |  |  [图形]   |        |  [图形]   |   y=240~420  |
  |  |    C      |        |    D      |              |
  |  +-----------+        +-----------+              |
  |                                                  |
  |  [控件栏: ◀上一步  步骤 X/4  下一步▶]  y=440~490  |
  +--------------------------------------------------+
  ```
  步骤3布局草图：
  ```
  +--------------------------------------------------+
  |         [正确答案：A]                              |
  |  +---------------------+    +----------------+     |
  |  |                     |    |   三棱柱       |     |
  |  |      A 放大图       |--->|   立体图       |     |
  |  |    [绿色边框+对勾]   |    |              |     |
  |  +---------------------+    +----------------+     |
  |       [B][C][D] 淡化缩略图（底部）                |
  |  [控件栏: ◀上一步  步骤 4/4  下一步▶]             |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：定义currentStep变量（0~3），每个步骤对应一个渲染函数renderStep()，根据currentStep值显示/隐藏/修改元素属性。
  2. 元素分组：将每个选项的所有图形元素（矩形、三角形）放入独立的<g>组中（如id="scene2-opt-a"），便于整体控制透明度、位移、缩放。
  3. 步骤3动画：A选项从原位置(200,120)放大并平移到(260,200)，使用CSS transition或JS requestAnimationFrame实现平滑过渡（transform: translate + scale）。
  4. 排除/确认标记：叉号和对勾使用SVG <path>绘制，或直接使用Unicode字符（×、√）配合大字号和颜色。
  5. 立体图绘制：使用绿色线条绘制三棱柱的可见边，隐藏边用#888888虚线表示，增强立体感。
  6. 事件绑定：上一步/下一步按钮绑定click事件，更新currentStep并调用renderStep()。
- ID命名规范：
  - 所有交互元素ID必须以`scene2-`为前缀
  - 示例：scene2-opt-a（A选项组）、scene2-opt-b-rect1（B选项矩形1）、scene2-btn-prev（上一步按钮）、scene2-btn-next（下一步按钮）、scene2-step-indicator（步骤指示器）、scene2-face-count-a（A面数标签）、scene2-checkmark-a（A对勾）、scene2-cross-b（B叉号）、scene2-prism-3d（立体图组）
  - JS中使用document.getElementById()获取元素，禁止querySelectorAll配合全局class
- IIFE隔离：所有JavaScript代码包裹在`(function() { ... })()`中，避免多场景合并时变量污染全局作用域。
