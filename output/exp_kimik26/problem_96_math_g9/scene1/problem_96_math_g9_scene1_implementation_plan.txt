[图示主题与整合说明]
- 本图示主题：正方体展开图的结构分析与相对面判定
- 整合内容：将正方体 1-4-1 十字展开图的六个面按题目图案标注，通过分步高亮演示“相间必相对”规律，进而推导两个阴影面（面①与面④）相邻、圆圈面（面⑤）与两阴影面均相邻的结论，帮助教师讲解空间折叠推理。
- 教学价值：教师可逐步点击导航，先让学生观察展开图原始状态，再依次验证三组相对面，最后聚焦阴影面与圆圈面的相邻关系，建立从展开图到立体图形的完整推理链。

[分步序列]
- 步骤0（初始状态）：显示完整展开图（六个面、折痕、面号、阴影三角、圆圈），无任何高亮或额外标签。教师可让学生先观察原始图案。
- 步骤1（第一组相对面）：面①（最左，阴影）与面③（左三，空白）高亮为蓝色（fill #1565c0 opacity 0.2，边框 2px #1565c0）；显示标签 "相对面" 于 (360,340)。讲解“相间必相对”——中间隔一个面必为相对面。
- 步骤2（第二组相对面）：清除步骤1高亮；面②（左二，空白）与面④（最右，阴影）高亮为红色（fill #c62828 opacity 0.2，边框 2px #c62828）；显示标签 "相对面" 于 (440,340)。继续验证相间规律。
- 步骤3（第三组相对面）：清除步骤2高亮；面⑤（上，圆圈）与面⑥（下，空白）高亮为绿色（fill #2e7d32 opacity 0.2，边框 2px #2e7d32）；显示标签 "相对面" 于 (360,340)。完成三组相对面判定。
- 步骤4（阴影面关系）：清除所有填充高亮；面①与面④改用黑色 3px 实线粗边框强调；显示标签 "相邻" 于 (400,340)。说明两阴影面并非相对，而是相邻。
- 步骤5（圆圈面关系）：保持面①④黑框；面⑤改用蓝色 3px 实线粗边框强调；添加两条虚线箭头分别从面⑤中心 (360,120) 指向面①中心 (280,200) 和面④中心 (520,200)；显示标签 "相邻" 于 (360,340)。示意圆圈面与两阴影面均相邻。
- 步骤6（总结结论）：清除所有高亮与箭头；在展开图正下方显示结论文字：第一行 "阴影面相邻"，第二行 "圆圈面与两阴影面均相邻"，居中于 (400,360) 与 (400,380)。教师可据此总结答案。

[交互方案]
- 交互类型：分步按钮导航（◀ 上一步 / 下一步 ▶）
- 控件说明：
  1. 「上一步」按钮：位于 (250,450)，宽 100×32，点击回退到上一状态。
  2. 「下一步」按钮：位于 (450,450)，宽 100×32，点击前进到下一状态。
  3. 步骤指示器：位于 (400,425)，显示当前步骤序号（如 "步骤 1 / 7"）。
- 教师操作流程：教师打开图示后处于步骤0，可先让学生观察展开图；点击「下一步」依次进入相对面验证（步骤1~3），再进入相邻关系分析（步骤4~5），最后到达总结（步骤6）。讲解过程中可随时点击「上一步」回退复习。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript。理由：场景为静态几何图形与简单显隐切换，无需复杂动画或数据驱动，原生 SVG 性能最佳且零依赖。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图（ASCII）：
  ```
  0    100  200  300  400  500  600  700  800
  +----+----+----+----+----+----+----+----+
  |                                    |  ← y=0
  |         [面⑤ 80×80]               |  ← y=80
  |            ⑤ ○                   |  ← y=120
  |  [面①][面②][面③][面④]           |  ← y=160
  |   ①▨   ②    ③    ④▨            |  ← y=200
  |         [面⑥ 80×80]               |  ← y=240
  |            ⑥                      |  ← y=280
  |                                   |
  |        （步骤标签 / 结论）          |  ← y=340~380
  |         步骤 1 / 7                |  ← y=425
  |   [◀ 上一步]    [下一步 ▶]        |  ← y=450~482
  |                                   |  ← y=500
  +----+----+----+----+----+----+----+----+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 `currentStep`（0~6）控制当前步骤。初始化 `currentStep = 0`。每点击按钮增减并限制在 [0,6] 范围。
  2. 渲染函数 `renderStep()`：根据 `currentStep` 设置各 SVG 元素的 `display` 属性（或 `visibility`）。所有步骤专属元素初始 `display:none`，由渲染函数按步骤显隐。
  3. 元素分组：将每一步需要显示的元素包在独立的 `<g id="scene1-step-X">` 中，通过切换组的 `display` 属性实现批量显隐。
  4. 斜线填充：在 `<defs>` 中定义 `<pattern id="scene1-hatch" patternUnits="userSpaceOnUse" width="8" height="8" patternTransform="rotate(45)">`，内画 1px 竖线；阴影三角用 `<polygon fill="url(#scene1-hatch)"/>`。
  5. 箭头标记：在 `<defs>` 中定义 `<marker id="scene1-arrowhead">` 供虚线箭头引用。
  6. 按钮状态：当 `currentStep === 0` 时禁用「上一步」按钮（降低 opacity）；当 `currentStep === 6` 时禁用「下一步」按钮。
  7. 步骤指示器：动态更新文本内容为 `步骤 ${currentStep+1} / 7`。
- ID 命名规范：所有 SVG 元素及 JS 变量均以 `scene1-` 为前缀，如 `scene1-face-1`、`scene1-step-1-group`、`scene1-btn-prev`、`scene1-btn-next`。JS 中严格使用 `document.getElementById` 获取元素，禁止全局 class 选择器，避免多场景合并时污染。
- IIFE 隔离：所有 JavaScript 代码包裹在 `(function() { ... })();` 中，内部变量不泄露全局作用域。
