[图示主题与整合说明]
- 本图示主题：正方体表面展开图折叠与旋转验证
- 整合的步骤/概念：
  1) 展开图五个面的空间位置关系（面②居中、面⑤上、面④下、面①左、面③右）；
  2) 折叠动画演示平面如何围合为封闭正方体；
  3) 绕垂直轴顺时针旋转 90° 的视角变换，得到与选项 A 完全一致的视图；
  4) 利用相邻面/相对面图案约束，逐一排除选项 B/C/D。
- 教学价值：教师通过分步导航，先让学生观察展开图各面图案（空白、阴影三角、圆圈），再观看折叠与旋转动画建立空间直觉，最后通过“假设—矛盾”法排除错误选项，强化正方体表面展开图的推理能力。

[分步序列]
- 步骤 0（初始状态）：
  • 左侧显示折叠完成的 3D 正方体，视角 rotateX(-15°) rotateY(0°)。可见面：正面=面②空白、顶面=面⑤圆圈、右侧面=面③阴影三角。
  • 右侧四个选项缩略图 A/B/C/D 全部显示，默认 1 px 黑框，无高亮，无叉号，无状态标签。
  • 底部显示「◀ 上一步」（禁用态/可点回退到步骤 0 本身无意义，故上一步在步骤 0 时 disabled）、「下一步 ▶」可用，步骤指示器「步骤 0 / 6」。

- 步骤 1（折叠动画）：
  • 点击「下一步」触发。
  • 左侧 3D 正方体暂时隐藏；展开图五个面（十字排列）淡入显示。
  • 播放 2 s 折叠动画：五个面通过 CSS 3D transform（rotateX/Y + translateZ）依次向上/下/左/右折起，围合成正方体，最终视角与步骤 0 相同（rotateX(-15°) rotateY(0°)）。
  • 动画结束后，展开图隐藏，3D 正方体重新显示并保持折叠姿态。
  • 右侧选项无变化。
  • 步骤指示器「步骤 1 / 6」。

- 步骤 2（旋转定位 → 匹配 A）：
  • 点击「下一步」触发。
  • 左侧正方体绕 Y 轴顺时针旋转 90°（从顶部俯视），CSS transition 约 1 s，过渡到 rotateX(-15°) rotateY(90°)。
  • 新视角可见面：正面=面①阴影三角、顶面=面⑤圆圈、右侧面=面②空白。
  • 右侧选项 A 缩略图边框变为 3 px #2e7d32 实线；A 上方显示标签「与选项 A 完全一致」。
  • 步骤指示器「步骤 2 / 6」。

- 步骤 3（排除 B）：
  • 点击「下一步」触发。
  • 左侧正方体保持步骤 2 的 A 视角不变。
  • 右侧选项 B 缩略图上方显示红色标签「矛盾」；在 B 的顶面区域画红色叉号（两条交叉线段，线宽 2 px #c62828）。
  • 教师讲解：若正面与右侧面同时为阴影，则交于顶-后-左顶点，其上方必为圆圈面，但 B 的顶面为空白，矛盾。
  • 步骤指示器「步骤 3 / 6」。

- 步骤 4（排除 C）：
  • 点击「下一步」触发。
  • 左侧正方体保持 A 视角不变。
  • 右侧选项 C 缩略图上方显示红色标签「矛盾」；在 C 的右侧面区域画红色叉号。
  • 教师讲解：正面为圆圈意味着面⑤ 转到正面，此时右侧面应为空白面，而非阴影面。
  • 步骤指示器「步骤 4 / 6」。

- 步骤 5（排除 D）：
  • 点击「下一步」触发。
  • 左侧正方体保持 A 视角不变。
  • 右侧选项 D 缩略图上方显示红色标签「矛盾」；在 D 的顶面区域画红色叉号。
  • 教师讲解：D 的顶面为阴影，与展开图中顶面（面⑤）为圆圈直接矛盾。
  • 步骤指示器「步骤 5 / 6」。

- 步骤 6（总结）：
  • 点击「下一步」触发。
  • 左侧固定显示匹配 A 的视角（rotateX(-15°) rotateY(90°)）。
  • 右侧：选项 A 保持 3 px #2e7d32 绿色实线框；选项 B/C/D 整体覆盖 #c62828、opacity 0.3 的蒙版，并保留步骤 3~5 的红色叉号。
  • 步骤指示器「步骤 6 / 6」；「下一步」按钮禁用（或变为「重新开始」）。

[交互方案]
- 交互类型：分步按钮导航（◀ 上一步 / 下一步 ▶）。
- 控件说明：
  1. 「◀ 上一步」按钮：位于 (250, 455)，宽 110×32 px。点击回退到上一状态，步骤 0 时 disabled（opacity 0.4）。
  2. 「下一步 ▶」按钮：位于 (440, 455)，宽 110×32 px。点击前进到下一状态，步骤 6 时 disabled 或文案变为「已完成」。
  3. 步骤指示器：位于 (400, 492)，显示「步骤 n / 6」。
- 教师操作流程：
  • 步骤 0：教师先让学生观察展开图各面图案，提问“折叠后正面、顶面、右侧面分别是什么？”。
  • 步骤 1：点击「下一步」播放折叠动画，验证五个面如何围合。可点击「上一步」重新观看。
  • 步骤 2：再次点击「下一步」，观看旋转动画，确认新视角与选项 A 一致。
  • 步骤 3~5：依次点击「下一步」，每步聚焦一个错误选项，教师引导学生说出排除理由，红色叉号与“矛盾”标签强化视觉反馈。
  • 步骤 6：总结视图，强调唯一正确选项为 A。教师可点击「上一步」多次回退，针对学生薄弱点重复讲解。

[技术实现]
- JS 库选择：原生 HTML/CSS/JavaScript，无需额外库。理由：正方体折叠与旋转完全可由 CSS 3D transform 实现；选项缩略图与叉号用内联 SVG 绘制即可；状态切换逻辑简单，原生 JS 足够。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |  +------------------------+  +----------------+  |
  |  |                        |  |  [A]    [B]    |  |
  |  |    3D 正方体 / 展开图   |  |  匹配    矛盾   |  |
  |  |    (左侧 55% 区域)      |  |                |  |
  |  |                        |  |  [C]    [D]    |  |
  |  |  rotateX(-15°)         |  |  矛盾    矛盾   |  |
  |  |  rotateY(0°~90°)       |  +----------------+  |
  |  +------------------------+                      |
  |         ◀ 上一步        下一步 ▶    步骤 n / 6   |
  +--------------------------------------------------+
  坐标系：左上角为 (0,0)，底部控件区 y=440~490
  ```

- 关键实现要点：
  1. 状态机设计：
     ```javascript
     const stateMap = [
       { step: 0, cubeRot: {x:-15, y:0},   net:false,  a:{hl:false}, b:{cross:null}, c:{cross:null}, d:{cross:null} },
       { step: 1, cubeRot: {x:-15, y:0},   net:true,   /* 动画由 CSS keyframes 控制 */ },
       { step: 2, cubeRot: {x:-15, y:90},  net:false,  a:{hl:true, label:'与选项 A 完全一致'} },
       { step: 3, cubeRot: {x:-15, y:90},  net:false,  b:{cross:'top', label:'矛盾'} },
       { step: 4, cubeRot: {x:-15, y:90},  net:false,  c:{cross:'right', label:'矛盾'} },
       { step: 5, cubeRot: {x:-15, y:90},  net:false,  d:{cross:'top', label:'矛盾'} },
       { step: 6, cubeRot: {x:-15, y:90},  net:false,  a:{hl:true}, b:{mask:true}, c:{mask:true}, d:{mask:true} }
     ];
     ```
     当前步骤索引 `currentStep` 控制所有元素的显隐与样式。

  2. 3D 正方体坐标计算（CSS）：
     - 容器 `#scene2-cube-container`：position:absolute; left:80px; top:80px; width:280px; height:280px; perspective:800px;
     - 正方体 `#scene2-cube`：position:absolute; left:80px; top:80px; width:120px; height:120px; transform-style:preserve-3d; transition: transform 1s ease-in-out;
     - 六个面统一尺寸 120×120，通过 `rotateX/Y/Z + translateZ(60px)` 定位到相应方位。
     - 面图案：空白面直接 background:#fff；圆圈面用 ::after 画 36px 直径 border:2px solid #1565c0 border-radius:50%；阴影三角面内嵌绝对定位 SVG（viewBox="0 0 120 120"），用 `<defs><pattern id="scene2-hatch" patternUnits="userSpaceOnUse" width="4" height="4" patternTransform="rotate(45)"><line x1="0" y1="0" x2="0" y2="4" stroke="#000" stroke-width="1"/></pattern></defs>`，再画 `<polygon points="0,0 0,120 120,120" fill="url(#scene2-hatch)"/>`（左下直角三角形，对角线从左上到右下）。

  3. 展开图折叠动画：
     - 五个 `#scene2-net-*` div，初始绝对定位在十字坐标（见坐标表），opacity:0。
     - 进入步骤 1 时：设置 opacity:1，并添加 CSS animation class（如 `fold-to-cube`），keyframes 中同时改变 `transform`（从平铺的 rotateX/Y(0deg) translateZ(0) 到对应 3D 姿态）与 `left/top`（到容器中心）。动画时长 2s，fill-mode:forwards。
     - 动画结束事件 `onanimationend` 后，隐藏 nets，显示 cube。

  4. 选项缩略图 SVG 结构（以 A 为例）：
     - viewBox="0 0 70 70"，背景透明。
     - 正面：polygon (15,30)-(45,30)-(45,60)-(15,60)，fill:#fff，stroke:#000。
     - 顶面：polygon (15,30)-(45,30)-(55,15)-(25,15)，fill:#fff，stroke:#000。
     - 右侧面：polygon (45,30)-(55,15)-(55,45)-(45,60)，fill:#fff，stroke:#000。
     - 正面阴影三角：在正面内画 polygon (15,30)-(15,60)-(45,60)，fill="url(#hatch-small)"（4px 间距 45° 斜线 pattern）。
     - 顶面圆圈：在顶面中心画 circle cx=35 cy=22 r=10，stroke:#1565c0，stroke-width:2，fill:none。
     - 叉号（步骤 3~5）：在对应面区域画两条 line，stroke:#c62828，stroke-width:2。
     - 蒙版（步骤 6）：rect 覆盖整个 70×70，fill:#c62828，fill-opacity:0.3。

  5. 事件绑定：
     - `document.getElementById('scene2-btn-prev').addEventListener('click', ...)`
     - `document.getElementById('scene2-btn-next').addEventListener('click', ...)`
     - 更新函数 `updateScene(stepIndex)`：根据 stateMap[stepIndex] 修改 cube transform、net 显隐、各 option 的 classList（如添加 `scene2-hl-green`、`scene2-cross-top`、`scene2-mask-red`）。

  6. ID 命名规范：
     - 所有交互元素 ID 必须以 `scene2-` 为前缀。
