[图示主题与整合说明]
- 本图示主题：一次函数图象的象限判断
- 整合的步骤/概念：
  1. 由二次函数图象（开口向下、对称轴在y轴左侧）推导出参数符号：a < 0，b < 0
  2. 根据 a < 0（斜率为负）和 b < 0（y轴截距在负半轴）绘制一次函数 y = ax + b 的图象
  3. 观察直线经过的象限（第二、三、四象限）
  4. 判定直线不经过第一象限，得出答案 A
- 教学价值：教师通过分步导航，引导学生从二次函数图象特征提取参数符号，再迁移到一次函数图象的绘制与象限判断，建立数形结合的思维链条

[分步序列]
- 步骤0（初始状态）：显示坐标系（x轴、y轴、原点O标签、x/y轴标签）、四个象限罗马数字标注（Ⅰ、Ⅱ、Ⅲ、Ⅳ）、辅助网格线。直线、交点、填充、结论均隐藏。
- 步骤1（绘制直线）：点击「下一步」→ 直线 y=ax+b 从左上方淡入绘制到右下方（从(167,208)到(633,408)），持续600ms；y轴交点圆点(400,308)出现；标签"(0, b)"在交点右侧淡入；斜率向下箭头在直线中部出现；直线标签"y = ax + b"在右下外侧淡入。
- 步骤2（高亮经过象限）：点击「下一步」→ 第二象限区域(120,60)-(400,260)、第三象限区域(120,260)-(400,430)、第四象限区域(400,260)-(680,430)同时以#2e7d32颜色、透明度从0%渐变到15%填充，持续400ms。
- 步骤3（标识不经过象限）：点击「下一步」→ 第一象限区域(400,60)-(680,260)以#c62828颜色、透明度从0%渐变到15%填充，持续400ms；同时标签"不经过"在第一象限上方(540,120)淡入。
- 步骤4（得出结论）：点击「下一步」→ 画布顶部中央(400,25)显示结论文本"图象不经过第一象限，选 A"，颜色#c62828，粗体，从透明度0%渐变到100%，持续300ms。
- 教师可随时点击「上一步」回退，所有动画反向执行或立即切换状态。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于(240,447)，宽120px，高36px，点击回退到上一状态
  - 「下一步 ▶」按钮：位于(440,447)，宽120px，高36px，点击前进到下一状态
  - 步骤指示器：位于(400,490)，显示当前步骤编号如"步骤 1 / 5"
- 教师操作流程：
  1. 教师展示步骤0（空白坐标系），提问学生根据二次函数图象能得出a、b的符号
  2. 点击「下一步」进入步骤1，展示直线绘制过程，讲解斜率为负、截距为负的几何意义
  3. 点击「下一步」进入步骤2，高亮直线经过的三个象限，让学生直观观察
  4. 点击「下一步」进入步骤3，高亮第一象限并标注"不经过"，形成对比
  5. 点击「下一步」进入步骤4，展示结论，完成讲解
  6. 可随时回退复习关键步骤

[技术实现]
- JS库选择：原生 SVG + 原生 JavaScript。原因：本场景为二维几何图形（坐标系、直线、矩形填充、文本标签），无复杂函数绘图或3D需求，原生SVG足以高效实现，且便于精确控制每个元素的显隐和动画。
- 画布尺寸：800 × 500 px（沿用<SCENE_2>规定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------------+
  |  结论文本(400,25)                                       |
  |       y                                                  |
  |  Ⅱ  |  Ⅰ    <- 第二/第一象限（上半部分）                  |
  |     |                                                    |
  |-----O-----x----->  x轴                                   |
  |  Ⅲ  |  Ⅳ    <- 第三/第四象限（下半部分）                  |
  |     |  \  <- 直线 y=ax+b                                  |
  |     |   \                                               |
  +--------------------------------------------------------+
  | [控件栏 y=440~500]  [◀ 上一步]  [下一步 ▶]  步骤 1/5    |
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `currentStep`（0~4），每次点击按钮时更新状态，调用 `renderStep()` 函数根据状态控制各元素的显隐和样式。
  2. 坐标计算：原点(400,260)，x轴比例尺约46.7px/单位，y轴比例尺约40px/单位。直线使用示意参数（斜率-0.5，截距-1.2），端点(167,208)和(633,408)。
  3. 动画曲线：使用CSS `transition: opacity 0.4s ease, fill-opacity 0.4s ease` 控制淡入淡出；直线绘制使用SVG `stroke-dasharray` + `stroke-dashoffset` 动画实现从左到右的绘制效果，持续600ms，使用 `cubic-bezier(0.4, 0, 0.2, 1)` 缓动。
  4. 事件绑定：按钮点击事件绑定在 `scene2-btn-prev` 和 `scene2-btn-next` 上，使用IIFE隔离作用域。
  5. 按钮状态：步骤0时「上一步」禁用（opacity 0.4，pointer-events none）；步骤4时「下一步」禁用。
  6. 象限填充实现：使用SVG `<rect>` 元素，初始 `fill-opacity="0"`，步骤2/3时通过JS设置为 `0.15`，配合CSS transition实现渐变。
- **ID命名规范**：所有交互元素ID以 `scene2-` 为前缀，例如：
  - `scene2-x-axis`（x轴）
  - `scene2-y-axis`（y轴）
  - `scene2-line`（直线）
  - `scene2-point-b`（y轴交点）
  - `scene2-label-line`（直线标签）
  - `scene2-fill-q2`（第二象限填充）
  - `scene2-fill-q3`（第三象限填充）
  - `scene2-fill-q4`（第四象限填充）
  - `scene2-fill-q1`（第一象限填充）
  - `scene2-label-notpass`（"不经过"标签）
  - `scene2-conclusion`（结论文本）
  - `scene2-btn-prev`（上一步按钮）
  - `scene2-btn-next`（下一步按钮）
  - `scene2-step-indicator`（步骤指示器）
- IIFE隔离：所有JavaScript代码包裹在 `(function() { ... })()` 中，避免多场景合并时的全局变量污染。
