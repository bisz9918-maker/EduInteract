[图示主题与整合说明]
- 本图示主题：圆内接等腰三角形与直径性质的综合应用
- 整合的步骤/概念：从已知条件（圆内接等腰△ABC、顶角120°、直径AD=6）出发，依次展示底角推导（30°）、直径所对圆周角（90°）、同弧圆周角相等的关键转化，最终在Rt△ABD中利用30°角性质求得AB=3。
- 教学价值：教师可通过分步导航控制推理节奏，每步只呈现当前推导所需的新信息，避免一次性信息过载；可随时回退到任意步骤复习逻辑链，符合几何证明"由因导果"的课堂讲解习惯。

[分步序列]
- 步骤0（初始状态）：显示圆、圆心O、五点A/B/C/D、四条弦AB/BC/AC/BD、直径AD（均黑色实线）；标注点名字母；显示已知条件：AB=BC蓝色等长标记、∠ABC=120°蓝色角度弧、AD=6蓝色标注。不显示任何推导结论与填充。
- 步骤1：点击「下一步」→ △ABC区域出现蓝色半透明填充（20%）；在∠BAC、∠BCA处出现红色30°角度弧；右侧出现推导文字"(180°−120°)/2=30°"。
- 步骤2：点击「下一步」→ 直径AD变为蓝色粗线（3px），线段BD变为红色粗线（3px）；在B点出现直角符号；∠ABD处出现红色90°角度弧；Rt△ABD区域出现红色半透明填充（20%）；△ABC蓝色填充隐藏；右侧出现推导文字"直径所对圆周角=90°"。
- 步骤3：点击「下一步」→ 圆上出现红色虚线弧AB（210°~270°，线宽3px）；∠ADB处出现红色30°角度弧；∠ACB的30°保持显示；右侧出现推导文字"同弧AB所对圆周角相等"；Rt△ABD红色填充保持。
- 步骤4（最终）：点击「下一步」→ 边AB变为绿色粗线（3px）；在AB旁出现绿色标注"AB=3"；右侧出现推导文字"AB = AD/2 = 6/2 = 3"；所有前期推导元素保持可见，形成完整逻辑链。
- 教师可随时点击「上一步」回退到任意步骤复习。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于底部(300,455)，宽80×高30。点击回退到上一状态，步骤0时禁用。
  - 「下一步」按钮：位于底部(420,455)，宽80×高30。点击前进到下一状态，步骤4时禁用。
  - 步骤指示器：位于底部中心(400,470)，显示"步骤 k/5"，随状态同步更新。
- 教师操作流程：
  1. 加载后处于步骤0，教师先讲解题目已知条件；
  2. 点击「下一步」进入步骤1，引导学生利用等腰三角形性质求底角；
  3. 继续点击「下一步」依次展示直径直角、同弧圆周角相等、最终计算；
  4. 讲解中可随时回退到上一步强调关键转化；
  5. 步骤4呈现完整结论，可停留供学生笔记。

[技术实现]
- JS库选择：原生SVG + 原生JavaScript。理由：本场景为静态几何图形与分步显隐控制，无需复杂动画或数据驱动绘图；原生SVG可精确控制每个几何元素（路径、圆弧、多边形）的坐标与样式。
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |              D(539,170)                          |
  |             /                                    |
  |            /                                     |
  |  A(261,330)---O(400,250)---C(539,330)            |
  |   \         /           /                        |
  |    \       /           /                         |
  |     \     /           /                          |
  |      \   /           /                           |
  |       \ /           /                            |
  |        B(400,410)   /                            |
  |                    /                             |
  |  [右侧推导文字区 x≈600]                          |
  |                                                  |
  |  [◀上一步]  步骤 k/5  [下一步▶]  y=455~485       |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：维护 `currentStep`（0~4）。每步用一个配置对象描述各元素的 `display`/`opacity`/`strokeWidth`/`stroke`/`fill` 目标值，避免大量 if-else。
  2. 坐标计算：圆上五点基于极坐标（圆心400,250，半径160）精确计算：A(210°)、B(270°)、C(330°)、D(30°)、O为圆心。所有角度弧、等长标记、直角符号均基于对应点坐标与方向向量计算，确保几何关系准确。
  3. 动画曲线：元素显隐使用 CSS `transition: opacity 0.3s ease`，避免生硬切换；线宽与颜色变化直接瞬时切换，保持课堂讲解节奏。
  4. 事件绑定：上一步/下一步按钮绑定 click 事件，调用 `renderStep(n)` 更新所有元素的 class 或 style。
  5. 填充层处理：△ABC 与 Rt△ABD 的填充使用 `<polygon>` 并置于线段层之下（z-index 通过 SVG 绘制顺序控制），确保边框线不被覆盖。
  6. 弧AB高亮：使用 SVG `<path>` 的 `A` 命令绘制从 A 到 B 的圆弧（半径160，large-arc-flag=0，sweep-flag=1），设置 `stroke-dasharray="6,4"` 实现虚线效果。
- ID命名规范：所有元素 ID 必须以 `scene1-` 为前缀。例如：`scene1-circle`、`scene1-point-a`、`scene1-angle-abc`、`scene1-fill-abd`、`scene1-btn-prev`、`scene1-btn-next`。
- IIFE隔离：所有 JavaScript 逻辑包裹在 `(function() { ... })()` 中，避免多场景合并时的全局变量污染。
