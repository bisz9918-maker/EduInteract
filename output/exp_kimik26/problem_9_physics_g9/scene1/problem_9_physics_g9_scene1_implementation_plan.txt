[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  1. 「◀ 上一步」按钮：位置(300,450)，90×36px，点击回退到上一状态，步骤0时禁用（opacity=0.4）
  2. 「下一步 ▶」按钮：位置(410,450)，90×36px，点击前进到下一状态，步骤3时禁用（opacity=0.4）
  3. 选项标记区A/B/C/D：位置(540~730,400~430)，仅视觉反馈当前步骤分析结果，不可点击
- 教师操作流程：
  1. 教师展示步骤0，让学生观察电路图和已知条件（电源3V，L1为6V6W，L2为3V3W）
  2. 点击「下一步」进入步骤1，引导学生观察S1接b时的电流路径，发现L1两端电压仅3V低于额定电压
  3. 点击「下一步」进入步骤2，引导学生计算串联总电阻和电流，比较两灯实际功率
  4. 点击「下一步」进入步骤3，引导学生分析并联结构，发现L2在额定电压下正常发光，功率最大
  5. 可随时点击「上一步」回退，复习前一状态的电路结构和计算过程

[技术实现]
- JS库选择：原生SVG（电路图由几何图形、线段、圆圈组成，SVG的line/circle/path/text最适合，无需引入外部库）
- 画布尺寸：800×500px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------------+
  |                                                        |
  |   [电路原理图区 60~500×80~390]                         |
  |    电源左下  L1左 L2右  S2上  S1右下                   |
  |                                                        |
  |                              [参数面板 530~750×80~380] |
  |                               当前状态计算             |
  |                               U/I/P数值               |
  |                               结论文字                 |
  |                                                        |
  |                                        [A][B][C][D]   |
  |                                        选项标记区      |
  |     [◀ 上一步]  [下一步 ▶]                             |
  +--------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：变量 `scene1-currentStep` 取值0~3，`updateScene(step)` 函数统一更新所有视觉元素
  2. 开关动画：S1/S2闸刀用SVG `<line>`元素，通过更新x2/y2属性实现旋转切换，配合CSS transition: all 0.3s ease
  3. 电流箭头：用`<path>`+`<marker>`定义箭头头部，路径stroke=#1565c0，stroke-width=3，marker-end指向电流方向
  4. 元件淡化：未接入元件设置`opacity: 0.3`和`stroke-dasharray: 4,4`，接入时恢复`opacity: 1`和`stroke-dasharray: none`
  5. 参数面板内容：用`<text>`元素分组，每组给一个class如`scene1-step1-only`，通过CSS `.scene1-step1-only { display: none; }` 控制，当前步骤移除display:none
  6. 选项标记：用`<rect>`+`<text>`+`<path>`（叉号/对勾）组合，步骤切换时更新fill、stroke和内部图标visibility
  7. 灯泡发光效果：用`<circle>`同圆心叠加在灯泡上方，fill=#2e7d32或#1565c0，opacity=0.2，默认hidden，步骤3时显示
  8. 事件绑定：按钮绑定click事件，调用`updateScene(scene1-currentStep + 1)`或`-1`，并更新按钮disabled状态
- ID命名规范：所有交互元素ID必须以`scene1-`为前缀，例如`scene1-wire-main`、`scene1-lamp-l1`、`scene1-switch-s2`、`scene1-panel-title`、`scene1-btn-prev`、`scene1-btn-next`、`scene1-opt-a`、`scene1-arrow-path1`
- IIFE隔离：所有JS代码包在 `(function() { ... })()` 中，避免多场景合并时全局变量污染
- 按钮禁用逻辑：步骤0时`scene1-btn-prev`设置disabled=true和opacity=0.4；步骤3时`scene1-btn-next`同理
