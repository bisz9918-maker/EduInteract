[图示主题与整合说明]
- 本图示主题：杠杆平衡条件动态演示——大人小孩向支点移动过程中的力矩变化
- 整合内容：整合了初始平衡状态展示、移动过程动态演示、力矩变化对比、最终结论呈现四个认知阶段
- 教学价值：教师可通过分步演示，让学生直观理解"力矩=力×力臂"的概念，以及当力臂变化时力矩如何变化，最终得出杠杆倾斜方向的判断方法

[分步序列]
- 步骤 0（初始状态）：
  - 显示：杠杆（水平黑色）、支点、大人图标、小孩图标
  - 显示：重力箭头（红色向下）、力臂虚线（灰色）
  - 显示：G_大人、G_小孩、L_大人、L_小孩 标签
  - 力矩框显示：M_大人 = G_大人 × L_大人 = 600 N·m，M_小孩 = G_小孩 × L_小孩 = 600 N·m
  - 两力矩相等，杠杆水平平衡

- 步骤 1（开始移动）：
  - 新增：移动箭头（蓝色虚线，指向支点）
  - 新增：ΔL 标签在两人中间上方
  - 力矩框不变，仍显示初始值
  - 提示文字："两人同时以相等速度向支点移动 ΔL"

- 步骤 2（移动后状态）：
  - 大人图标向右移动 40px（从 x=210 到 x=250）
  - 小孩图标向左移动 40px（从 x=605 到 x=565）
  - 力臂虚线缩短：L_大人' = L_大人 - ΔL，L_小孩' = L_小孩 - ΔL
  - 力矩框更新：M_大人' = G_大人 × (L_大人 - ΔL) = 480 N·m
  - 力矩框更新：M_小孩' = G_小孩 × (L_小孩 - ΔL) = 520 N·m

- 步骤 3（力矩对比）：
  - 高亮小孩端力矩框（#1565c0 蓝色边框）
  - 力矩框显示对比：M_大人' = 480 N·m < M_小孩' = 520 N·m
  - 新增：比较符号 "<" 在两力矩框之间
  - 提示文字："小孩端力矩更大"

- 步骤 4（结论）：
  - 杠杆变为红色并倾斜（右端下沉，约 5°）
  - 新增：下沉箭头（红色向下，在小孩端）
  - 结论文字："小孩那端下沉" 显示在画面中央
  - 答案框："答案：B" 显示在顶部

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "上一步"按钮：位置 (280,455)，作用：返回前一步骤
  - "下一步"按钮：位置 (500,455)，作用：进入下一步骤
  - 步骤指示器：位置 (380,455)，显示 "步骤 X/5"
- 教师操作流程：
  1. 从步骤 0 开始，讲解初始平衡条件（G_大人×L_大人 = G_小孩×L_小孩）
  2. 点击"下一步"到步骤 1，说明两人同时向支点移动
  3. 点击"下一步"到步骤 2，展示移动后的力臂变化
  4. 点击"下一步"到步骤 3，对比两边力矩大小
  5. 点击"下一步"到步骤 4，揭示结论：小孩那端下沉（答案 B）
  6. 可随时点击"上一步"回退复习关键步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何和动画，无需重型库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    [结论文字] (步骤 4)                   │
  │                                                         │
  │     G_大人              ΔL              G_小孩          │
  │        ↑                                 ↑              │
  │       / \                               / \             │
  │      |   |                             |   |            │
  │  大人图标                           小孩图标            │
  │      ↓   ↓                             ↓   ↓            │
  │      ────┬─────────────────────────────┬────            │ 杠杆
  │          │←── L_大人 ──→│←─ L_小孩 ─→│                  │
  │          │                              │               │
  │          └────── 支点 ──────┘                          │
  │                                                         │

  │  └─────────────────┘              └─────────────────┘  │

  │          [◀上一步]  步骤 X/5  [下一步▶]                │
  └─────────────────────────────────────────────────────────┘
  ```

- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-4) 跟踪当前步骤，updateScene() 函数根据 currentStep 显示/隐藏元素
  2. 坐标计算：所有元素坐标硬编码在配置对象中，便于调整
  3. 动画曲线：移动动画使用 requestAnimationFrame，线性插值实现平滑过渡
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateScene()
  5. SVG 元素 ID 命名：scene1-lever, scene1-fulcrum, scene1-adult, scene1-child, scene1-gravity-adult, scene1-gravity-child, scene1-arm-adult, scene1-arm-child, scene1-arrow-adult, scene1-arrow-child, scene1-deltaL, scene1-torque-box-adult, scene1-torque-box-child, scene1-torque-text-adult, scene1-torque-text-child, scene1-tilted-lever, scene1-sink-arrow, scene1-conclusion, scene1-btn-prev, scene1-btn-next, scene1-step-indicator
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染

- 初始状态：图示加载后显示步骤 0（初始平衡状态），等待教师点击"下一步"触发交互
