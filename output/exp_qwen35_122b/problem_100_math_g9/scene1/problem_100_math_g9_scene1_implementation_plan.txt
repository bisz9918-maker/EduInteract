[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮（scene1-prev）：位置(280,435)，作用：返回上一状态，步骤0时禁用
  - 下一步按钮（scene1-next）：位置(420,435)，作用：进入下一状态，步骤3时禁用
- 教师操作流程：
  1. 初始展示立体图，讲解正三棱柱的基本结构（两个正三角形底面 + 三个矩形侧面）
  2. 点击"下一步"，展示侧面展开过程，强调三个矩形并排
  3. 点击"下一步"，展示完整展开图，讲解三角形边长与矩形宽度的关系
  4. 点击"下一步"，总结正三棱柱展开图的判定标准
  5. 可随时点击"上一步"回退复习

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │                        标题 (320,20)                           │
  │                                                                │
  │   ┌──────────────┐        →        ┌──────────────────────┐   │
  │   │   立体图     │                  │      展开图          │   │
  │   │  (80,80)     │                  │     (420,80)         │   │
  │   │  240×300     │                  │      300×300         │   │
  │   └──────────────┘                  └──────────────────────┘   │
  │                                                                │
  │                                                                │
  │              [◀ 上一步]      [下一步 ▶]                        │
  │                    (280,435)    (420,435)                      │
  └────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-3) 跟踪当前步骤，updateScene() 函数根据 currentStep 显示/隐藏元素
  2. 坐标计算：立体图使用透视投影（y轴压缩0.6倍），展开图使用平面坐标
  3. 动画曲线：元素出现使用 opacity 渐变（0→1，300ms）
  4. 事件绑定：按钮点击事件调用 changeStep(delta)，更新 currentStep 后调用 updateScene()
  5. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-tri-top、scene1-rect-1、scene1-prev、scene1-next）
  6. IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局污染
  7. 元素显示控制：用 display: none / display: block 控制元素可见性，用 opacity 控制高亮效果

- 状态控制逻辑：
  ```javascript
  (function() {
    const currentStep = { value: 0 };
    const totalSteps = 4;
    
    function updateScene() {
      // 步骤0：显示立体图，隐藏展开图
      // 步骤1：显示展开图的三个矩形和折叠线
      // 步骤2：显示展开图的上下三角形和标注
      // 步骤3：高亮所有元素，显示结论文字
      
      // 更新按钮状态
      document.getElementById('scene1-prev').disabled = currentStep.value === 0;
      document.getElementById('scene1-next').disabled = currentStep.value === totalSteps - 1;
    }
    
    function changeStep(delta) {
      currentStep.value += delta;
      if (currentStep.value < 0) currentStep.value = 0;
      if (currentStep.value >= totalSteps) currentStep.value = totalSteps - 1;
      updateScene();
    }
    
    // 事件绑定
    document.getElementById('scene1-prev').addEventListener('click', () => changeStep(-1));
    document.getElementById('scene1-next').addEventListener('click', () => changeStep(1));
    
    // 初始化
    updateScene();
  })();
  ```
