[视觉元素清单]

- 图形②主体：黑色实线矩形（100×120）+ 左右两侧直角三角形（30-60-90），初始无填充
- 图形③主体：黑色实线平行四边形 + 上下两侧锐角三角形（含60°角），初始无填充
- 图形④主体：黑色实线矩形（100×120）+ 上下两侧锐角三角形（含60°角），初始无填充

- 高亮填充：

- 初始状态（步骤0）：显示四个图形①②③④的轮廓线（黑色实线），网格背景，图形编号，无填充，无判定标记，无类型标注
- 步骤1：点击「下一步」→ 图①②的直角三角形区域填充红色#c62828（20%透明度），显示"直角三角形"标注，显示"✗ 不可折叠"标记
- 步骤2：点击「下一步」→ 图③④的锐角三角形区域填充绿色#2e7d32（20%透明度），显示"锐角三角形"标注，显示"✓ 可折叠"标记
- 步骤3（结论）：点击「下一步」→ 所有图形保持当前状态，在画布顶部中央显示结论文字"答案：B．③和④"（蓝色#1565c0，字号20px），"下一步"按钮变为"重播"

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "上一步"按钮（scene2-btn-prev）：位于底部左侧，点击返回上一步状态，步骤0时禁用
  - "下一步"按钮（scene2-btn-next）：位于底部右侧，点击进入下一步状态，步骤3时变为"重播"
- 教师操作流程：
  1. 初始展示四个图形的轮廓，让学生观察差异
  2. 点击"下一步"，高亮图①②的直角三角形，讲解为什么直角三角形不能围成正三棱柱
  3. 再次点击"下一步"，高亮图③④的锐角三角形，讲解锐角三角形（正三角形）可以围成正三棱柱
  4. 最后点击"下一步"，显示答案，总结正三棱柱展开图的条件

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │                    答案：B．③和④ (步骤3显示)                │
  │                                                             │
  │   ①          ②          ③          ④                      │
  │  ┌───┐      ┌───┐      ┌───┐      ┌───┐                    │
  │  │△  │      │△  │      │ △ │      │ △ │                    │
  │  │   │      │   │      │   │      │   │                    │
  │  │   │      │   │      │   │      │   │                    │
  │  │△  │      │△  │      │ △ │      │ △ │                    │
  │  └───┘      └───┘      └───┘      └───┘                    │
  │  直角       直角       锐角       锐角                      │
  │  ✗不可      ✗不可      ✓可       ✓可                       │
  │                                                             │
  │              [◀上一步]  [下一步▶]                           │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：currentStep变量（0-3），根据步骤控制元素显示/隐藏/填充
  2. 坐标计算：四个图形等间距排列，每个图形中心x坐标分别为115、295、475、655
  3. 动画曲线：填充动画使用CSS transition（opacity 0.3s ease）
  4. 事件绑定：按钮点击事件监听，更新currentStep并调用render()函数
  5. ID命名规范：所有元素ID以scene2-为前缀（如scene2-shape-1、scene2-label-type-1等）
  6. IIFE隔离：所有JS代码包裹在(function() { ... })()中，避免全局污染
  7. 网格绘制：使用循环生成水平和垂直虚线，间距20px
  8. 三角形路径：根据原图精确计算顶点坐标，使用<path>元素绘制
  9. 填充控制：通过修改path的fill属性实现高亮效果
  10. 按钮状态：步骤0时禁用"上一步"，步骤3时"下一步"变为"重播"
