[图示主题与整合说明]
- 本图示主题：正方形折叠挖洞展开过程演示
- 整合的步骤/概念：原始正方形 → 沿对角线折叠 → 三角形挖洞 → 展开后洞的位置分布
- 教学价值：教师可通过分步演示帮助学生理解折叠变换的对称性原理，直观展示"挖洞穿透两层纸"的空间认知过程，突破学生对折叠展开问题的理解难点

[分步序列]
- 步骤0（初始状态）：
  - 显示：正方形轮廓（150,100）宽200高200
  - 标签："原始正方形"显示在(30,80)
  - 隐藏：折痕线、三角形、所有圆洞

- 步骤1：
  - 显示：正方形轮廓 + 对角线折痕虚线 + 折叠三角形（半透明蓝色填充）
  - 标签："折叠后"显示在(30,80)
  - 动画：三角形从正方形右侧向左折叠的视觉效果（可选）

- 步骤2：
  - 显示：步骤1所有元素 + 三角形三个角上的圆洞（红色轮廓）
  - 标签："挖洞"显示在(30,80)
  - 圆洞位置：
    - 洞1：(170,280) 直角顶点附近
    - 洞2：(170,120) 上锐角顶点附近
    - 洞3：(330,280) 右锐角顶点附近
  - 提示：用虚线圆圈在折叠层对应位置显示穿透效果（可选）

- 步骤3（最终状态）：
  - 显示：正方形轮廓 + 展开后的4个圆洞
  - 标签："展开后"显示在(30,80)
  - 隐藏：折叠三角形、折痕线
  - 圆洞位置（4个）：
    - 洞A：(170,280) 左下角
    - 洞B：(170,120) 左上角
    - 洞C：(330,280) 右下角
    - 洞D：(330,120) 右上角（对称位置，因折叠时穿透两层）
  - 高亮：用蓝色光晕效果强调对称关系

- 各步骤标签在同一位置但不同时显示 → 无冲突
- 圆洞无文字标签，仅用红色轮廓表示 → 无标签冲突
- 按钮标签在底部控件区，与主图区间距≥60px → 无冲突

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - scene1-prev-btn：「◀ 上一步」按钮，位置(250,440)，作用：返回上一步骤，步骤0时禁用
  - scene1-next-btn：「下一步 ▶」按钮，位置(450,440)，作用：进入下一步骤，步骤3时禁用
- 教师操作流程：
  1. 初始展示原始正方形，教师说明题目背景
  2. 点击"下一步"展示折叠过程，强调对角线折痕
  3. 点击"下一步"展示挖洞位置，解释"穿透两层纸"的概念
  4. 点击"下一步"展示展开结果，引导学生观察4个洞的对称分布
  5. 可点击"上一步"回退复习关键步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────┐
  │  步骤标签 (30,80)                                          │
  │                                                            │
  │         ┌─────────────────────────────────────┐           │
  │         │                                     │           │
  │         │           图示区 800×420            │           │
  │         │                                     │           │
  │         │     正方形/三角形/圆洞              │           │
  │         │                                     │           │
  │         └─────────────────────────────────────┘           │
  │                                                            │
  │              [◀ 上一步]  [下一步 ▶]                        │
  │                    (控件栏 y=440~480)                      │
  └────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：currentStep 变量（0-3），updateScene() 函数根据 currentStep 显示/隐藏元素
  2. 坐标计算：正方形中心(250,200)，边长200，对角线从(150,300)到(350,100)
  3. 动画曲线：元素显示/隐藏使用 opacity 过渡（0.3s ease）
  4. 事件绑定：按钮点击事件监听，边界检查（步骤0禁用prev，步骤3禁用next）
  5. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-square, scene1-fold-tri, scene1-hole1 等）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 元素 visibility 控制：使用 CSS class "hidden" { display: none; } 和 "visible" { display: block; } 切换
