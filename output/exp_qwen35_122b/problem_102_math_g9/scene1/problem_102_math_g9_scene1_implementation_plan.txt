[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "上一步"按钮：位于 (260,455)，80×30px，点击返回上一状态，步骤 0 时禁用
  - "下一步"按钮：位于 (460,455)，80×30px，点击进入下一状态，步骤 3 时禁用
- 教师操作流程：
  1. 初始展示坐标系框架，讲解坐标轴含义
  2. 点击"下一步"，展示点 A、B 及直线 AB，讲解两点确定一条直线
  3. 点击"下一步"，展示交点 M、N，讲解直线与坐标轴交点的求法
  4. 点击"下一步"，高亮线段 AN 和 BM，强调题目中两个关键交点区间

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（几何图形简单，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  ┌─────────────────────────────────────────────────────┐
  │                    SVG 画布 800×500                  │
  │                                                     │
  │           y                                         │
  │           ↑                                         │
  │      A●   │                                         │
  │    (-1,4) │                                         │
  │           │   N(0,5)●                               │
  │           │                                         │
  │  ─────────┼──────────────────────────────────→ x    │
  │     O(0,0)│                    ●B(2,1)   ●M(5,0)    │
  │           │                                         │
  │           │                                         │
  │           │                                         │
  │           │                                         │
  │  ┌─────────────────────────────────────────────┐   │
  │  │        ◀上一步      下一步▶                 │   │
  │  └─────────────────────────────────────────────┘   │
  └─────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-3) 跟踪当前步骤，每个步骤对应一组可见元素
  2. 坐标计算：定义坐标转换函数 coord(x, y) 返回屏幕坐标，便于统一计算
  3. 元素显示控制：每个元素设置 data-step 属性，表示从哪一步开始显示（-1 表示始终显示）
  4. 按钮状态：步骤 0 时禁用"上一步"，步骤 3 时禁用"下一步"
  5. 动画效果：元素出现时使用 opacity 渐变（0→1，时长 300ms）
- ID 命名规范：所有交互元素 ID 以 scene1- 为前缀（如 scene1-axis-x、scene1-point-a、scene1-prev、scene1-next）
- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染
