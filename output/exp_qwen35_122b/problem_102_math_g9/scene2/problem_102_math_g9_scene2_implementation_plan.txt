[图示主题与整合说明]
- 本图示主题：抛物线 y=x²-bx+2 随 b 值变化与直线 AB 的交点位置
- 整合的步骤/概念：整合了抛物线形态变化、与直线 AB 的交点位置变化、b 值滑块控制、交点横坐标实时显示，形成完整的参数 - 几何关系演示
- 教学价值：教师可通过拖动滑块实时观察 b 值变化时抛物线的移动轨迹，帮助学生直观理解交点在线段 AN 和 BM 上的约束条件，发现 b 的取值范围边界（b=5/2 和 b=11/3）

[分步序列]
本场景为连续拖拽交互，无分步导航，状态随滑块实时变化：

- 初始状态（b=2.5）：
  - 显示完整坐标系、直线 AB、点 A/B/M/N
  - 线段 AN 蓝高亮、线段 BM 红高亮
  - 抛物线 y=x²-2.5x+2 显示
  - 交点 P1 恰好在 N 点附近（x1≈0）
  - 交点 P2 恰好在 B 点附近（x2≈2）
  - 显示 b=2.5，x1 和 x2 的实时数值

- 拖拽过程（b 从 0 到 4 变化）：
  - 抛物线顶点位置随 b 值左右移动（顶点 x=b/2）
  - P1 在线段 AN 上从 A 向 N 移动（x1 从 -1 到 0）
  - P2 在线段 BM 上从 B 向 M 移动（x2 从 2 到 5）
  - 实时显示当前 b 值和交点横坐标 x1、x2

- 边界状态（教师引导观察）：
  - b=5/2=2.5 时：P1 在 N 点，P2 在 B 点（一个边界）
  - b=11/3≈3.67 时：P1 在 A 点，P2 在 M 点（另一个边界）
  - b<2.5 或 b>11/3 时：交点超出线段范围（用视觉提示如交点变灰）

[交互方案]
- 交互类型：连续拖拽滑块 — 选择理由：参数 b 的连续变化需要观察抛物线形态和交点位置的连续变化，滑块操作能直观展示 b 与交点位置的函数关系，帮助学生发现 b 的取值边界
- 控件说明：
  1. b 值滑块：位于底部中央 (250,450)-(550,450)，范围 0-4，拖拽改变 b 值
  2. b 值显示：滑块左侧 (245,475)，实时显示当前 b 值
  3. 交点坐标显示：右上角 (620,80)-(730,125)，显示 x1 和 x2 的实时数值
- 教师操作流程：
  1. 初始展示 b=2.5 状态，说明此时交点恰好在边界位置
  2. 向左拖动滑块减小 b 值，观察 P1 向 A 移动、P2 向 M 移动
  3. 向右拖动滑块增大 b 值，观察 P1 向 N 移动、P2 向 B 移动
  4. 引导学生发现：当 b<2.5 或 b>11/3 时，交点会超出线段范围
  5. 结合数值显示，让学生验证 b 的取值范围是 [5/2, 11/3]

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（线段、圆、路径），无需复杂图表库；原生 SVG 性能好，易于动态更新；无需额外依赖
  
- 画布尺寸：800 × 500 px

- 关键实现要点：
  1. 坐标转换函数：mathToScreen(x, y) 将数学坐标转换为 SVG 坐标
  2. 抛物线绘制：根据当前 b 值，计算 y=x²-bx+2 在 x∈[-2,6] 范围内的路径
  3. 交点计算：解方程 x²-bx+2 = kx+m（直线 AB 方程），得到两个交点横坐标
  4. 直线 AB 方程：通过 A(-1,4) 和 B(2,1)，斜率 k=(1-4)/(2-(-1))=-1，方程 y=-x+5
  5. 交点求解：x²-bx+2 = -x+5 → x²-(b-1)x-3=0，用求根公式
  6. 滑块拖拽：监听 mousedown/mousemove/mouseup 事件，计算滑块位置对应 b 值
  7. 实时更新：b 值变化时，重绘抛物线、更新交点位置和数值显示
  8. 边界检测：当交点超出线段范围时，可选用灰色显示或添加视觉提示

- ID 命名规范：所有交互元素 ID 以 scene2- 为前缀
  - scene2-axis-x, scene2-axis-y
  - scene2-point-A, scene2-point-B, scene2-point-M, scene2-point-N, scene2-point-O
  - scene2-line-AB, scene2-seg-AN, scene2-seg-BM
  - scene2-parabola, scene2-point-P1, scene2-point-P2
  - scene2-slider-track, scene2-slider-thumb
  - scene2-text-b, scene2-text-bval, scene2-text-x1, scene2-text-x1val, scene2-text-x2, scene2-text-x2val

- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染

- 抛物线绘制细节：
  - 路径生成：x 从 -2 到 6，步长 0.1，计算对应 y 值
  - 填充区域：抛物线下方用 <polygon> 或 <path> 填充，透明度 10%
  - 动态更新：b 值变化时，清除旧路径，重新生成

- 交点计算逻辑：
  - 直线 AB：y = -x + 5
  - 联立：x² - bx + 2 = -x + 5
  - 整理：x² - (b-1)x - 3 = 0
  - 求根：x = [(b-1) ± √((b-1)² + 12)] / 2
  - 较小根为 x1（对应 P1 在 AN 上），较大根为 x2（对应 P2 在 BM 上）
  - 验证：x1∈[-1,0] 且 x2∈[2,5] 时，交点在线段上
