[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：位置 (250,450)，100×35px，步骤 0 时禁用（灰色），其他步骤启用（蓝色）
  - "下一步 ▶"按钮：位置 (450,450)，100×35px，步骤 5 时禁用（灰色），其他步骤启用（蓝色）
- 教师操作流程：
  1. 初始展示屋架结构图，让学生观察图形
  2. 点击"下一步"，标注已知条件（AB=8m、∠A=30°、直角符号），引导学生识别直角三角形
  3. 点击"下一步"，高亮中点 D 并显示 AD=DB=4m，强调中点性质
  4. 点击"下一步"，高亮△ABC 并计算 BC=4m，讲解 30°角对边性质
  5. 点击"下一步"，高亮△ADE 并计算 DE=2m，应用相同性质
  6. 点击"下一步"，显示最终结论"DE=2m，故选 B"
  7. 可随时点击"上一步"回退复习某一步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px

- 关键实现要点：
  1. 状态机设计：用变量 currentStep 记录当前步骤（0-5），根据 currentStep 控制各元素的 display 属性
  2. 坐标计算：所有元素坐标已在布局坐标表中精确定义，直接按坐标绘制
  3. 动画曲线：无需复杂动画，使用 display 切换实现步骤切换
  4. 事件绑定：上一步/下一步按钮点击事件，更新 currentStep 并刷新显示
  5. 按钮状态：步骤 0 时上一步按钮 disabled，步骤 5 时下一步按钮 disabled
- ID 命名规范：所有交互元素 ID 以 scene1- 为前缀
  - 线段：scene1-line-ac, scene1-line-ab, scene1-line-bc, scene1-line-de
  - 标签：scene1-label-a, scene1-label-b, scene1-label-c, scene1-label-d, scene1-label-e
  - 标注：scene1-annot-ab, scene1-annot-angle, scene1-annot-ad, scene1-annot-db, scene1-annot-bc, scene1-annot-de
  - 符号：scene1-rt-c, scene1-rt-e（直角符号）
  - 高亮：scene1-highlight-abc, scene1-highlight-ade
  - 标记：scene1-dot-d（中点标记）
  - 结论：scene1-conclusion
  - 按钮：scene1-btn-prev, scene1-btn-next
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
