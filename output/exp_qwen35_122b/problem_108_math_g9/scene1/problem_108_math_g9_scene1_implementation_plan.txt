- "N"(665,390) 与 "∠BNA"(630,355)：距离≈50px → 无冲突

- "B"(560,180) 与 "∠B=β°"(535,220)：距离≈50px → 无冲突
- "C"(475,255) 与 "∠MCN"(485,215)：距离≈41px → 无冲突
- "∠AMB"(170,355) 与 "∠NMB"(185,365)：距离≈18px → 接近但可接受（垂直错开 10px）
- "∠BNA"(630,355) 与 "∠MNA"(615,365)：距离≈17px → 接近但可接受（垂直错开 10px）

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    图示区 800×500                       │
  │                                                         │
  │                    A(350,150)                           │
  │                   /  \                                  │
  │                  /    \                                 │
  │                 /      \                                │
  │           M(150,380)───C(465,238)───B(550,200)          │
  │            \      ╱        ╲                            │
  │             \    ╱          \                           │
  │              \  ╱            \                          │
  │               ╲╱              \                         │
  │                N(650,380)                              │
  │                                                         │
  │  ┌─────────────────────────────────────────────────┐   │
  │  │  步骤指示器: 步骤 1/5                            │   │
  │  │  [◀ 上一步]        [下一步 ▶]                    │   │
  │  └─────────────────────────────────────────────────┘   │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：currentStep 变量跟踪当前步骤（0-5），updateScene() 函数根据 currentStep 显示/隐藏元素
  2. 坐标计算：使用 SVG 绝对坐标，所有元素位置预先计算好
  3. 动画曲线：元素出现使用 opacity 过渡（0.3s ease-in-out）
  4. 事件绑定：按钮点击事件更新 currentStep 并调用 updateScene()
  5. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-line-mn、scene1-point-a、scene1-arc-amB）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 元素显示控制：通过 setAttribute('display', 'none/block') 控制元素可见性
  8. 角度弧线绘制：使用 SVG <path> 的 arc 命令绘制圆弧
