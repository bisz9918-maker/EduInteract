[图示主题与整合说明]
- 本图示主题：圆台形容器正放与倒放的液体体积及密度关系对比
- 整合的步骤/概念：容器形状对比 → 液体体积比较 → 密度关系推导
- 教学价值：教师可通过分步导航引导学生从直观的形状差异理解体积差异，再结合质量相同的前提推导密度关系，建立"形状→体积→密度"的逻辑链条

[分步序列]
- 步骤0（初始状态）：
  - 显示：桌面、桌面阴影、容器1轮廓、容器2轮廓、液面线1、液面线2、液体填充1（半透明）、液体填充2（半透明）
  - 标签：容器1、正放、容器2、倒放、h（深度相同）、m₁=m₂
  - 目的：展示题目基础条件——两个容器形状相反、液体深度相同、质量相同

- 步骤1：
  - 视觉变化：高亮液体填充区域（透明度从20%提升至40%），在液面线上方添加虚线框强调
  - 新增：无
  - 目的：引导学生关注液体部分，对比两个容器内液体的视觉差异

- 步骤2：
  - 视觉变化：在容器1右侧添加向上箭头表示"体积大"，在容器2右侧添加向下箭头表示"体积小"
  - 新增：体积标注箭头（红色）、标签"V₁＞V₂"（红色，容器1下方）
  - 目的：明确体积关系——正放容器（上宽下窄）装液体体积更大

- 步骤3：
  - 视觉变化：在容器2下方显示密度结论
  - 新增：密度结论标签"ρ₁＜ρ₂"（红色，容器2下方），显示密度公式"ρ=m/V"（顶部中央）
  - 目的：结合质量相同（m₁=m₂）和体积关系（V₁＞V₂），推导密度关系

- 步骤4（最终步骤）：
  - 视觉变化：所有结论高亮显示，添加绿色对勾标记正确判断
  - 新增：绿色对勾图标在"V₁＞V₂"和"ρ₁＜ρ₂"旁边
  - 目的：总结本场景结论，为后续分析拉力、压强、压力关系做铺垫

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "上一步"按钮：ID=scene1-prev-btn，位置(280,455)，点击后步骤减1（步骤0时禁用）
  - "下一步"按钮：ID=scene1-next-btn，位置(440,455)，点击后步骤加1（步骤4时禁用）
  - "步骤指示"文本：ID=scene1-step-indicator，位置(350,420)，显示"步骤 X/4"
- 教师操作流程：
  1. 初始展示两个容器及已知条件（深度相同、质量相同）
  2. 点击"下一步"高亮液体区域，引导学生观察体积差异
  3. 点击"下一步"显示体积关系V₁＞V₂
  4. 点击"下一步"显示密度结论ρ₁＜ρ₂
  5. 可随时点击"上一步"回退复习，巩固推理链条

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    图示标题 (y=20)                       │
  │                                                         │
  │     容器1              h              容器2              │
  │    ┌─────┐                          ┌─────┐             │
  │    │ 液体 │                          │ 液体 │             │
  │    │     │                          │     │             │
  │    └─────┘                          └─────┘             │
  │     正放              深度相同          倒放              │
  │                                                         │
  │              m₁ = m₂ (质量相同)                          │
  │                                                         │
  │   ─────────────────────────────────────────────────     │
  │                      桌面                               │
  │                                                         │
  │              步骤指示 (y=420)                           │
  │            [◀上一步]  [下一步▶]                         │
  │              (y=455)                                    │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep 记录当前步骤（0-4），每次点击按钮更新状态并重绘
  2. 坐标计算：所有元素坐标硬编码在配置对象中，确保精确到像素级
  3. 动画曲线：步骤切换使用 opacity 渐变（300ms ease-in-out）实现平滑过渡
  4. 事件绑定：按钮点击事件绑定到 scene1-prev-btn 和 scene1-next-btn
  5. ID 命名规范：所有交互元素 ID 以 scene1- 为前缀（如 scene1-tri-container1、scene1-btn-prev）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 元素显示控制：用 display 属性或 opacity 控制各步骤元素的显示/隐藏
  8. 液体填充区域：使用 SVG <polygon> 元素，坐标根据容器壁和液面计算
