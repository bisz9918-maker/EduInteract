[图示主题与整合说明]
- 本图示主题：匀速直线运动中的受力分析与拉力大小比较
- 整合的步骤/概念：整合了受力分析、摩擦力计算、拉力比较三个步骤
- 教学价值：教师可逐步展示两个容器在匀速运动时的受力情况，帮助学生理解：
  1. 匀速直线运动时合力为零的平衡条件
  2. 摩擦力与正压力的关系 f = μN
  3. 拉力与摩擦力平衡时 F = f
  4. 最终得出 F₁ = F₂ 的结论

[分步序列]
- 步骤 0（初始状态）：
  - 显示：桌面、两个容器轮廓及液体、速度箭头（左 v、右 2v）
  - 隐藏：所有受力箭头、公式文本、结论文本
  - 目的：展示题目基础条件，两个容器以不同速度匀速运动

- 步骤 1：
  - 新增：左右重力箭头 G₁、G₂（红色，向下），左右支持力箭头 N支₁、N支₂（绿色，向上）
  - 标注：G₁ = G₂（在两个重力箭头之间或下方显示）
  - 目的：展示竖直方向受力平衡，重力等于支持力

- 步骤 2：
  - 新增：左右拉力箭头 F₁、F₂（蓝色，向右），左右摩擦力箭头 f₁、f₂（灰色，向左）
  - 标注：匀速运动条件（文字提示）
  - 目的：展示水平方向受力情况

- 步骤 3：
  - 新增：公式文本 "f = μN支"
  - 高亮：支持力箭头 N支₁、N支₂ 和摩擦力箭头 f₁、f₂
  - 标注：f₁ = f₂（因为 μ 相同、N支相同）
  - 目的：说明摩擦力大小相等的物理依据

- 步骤 4（最终步骤）：
  - 新增：平衡条件文本 "F = f (匀速)"、结论文本 "F₁ = F₂"
  - 高亮：拉力箭头 F₁、F₂
  - 目的：得出最终结论，拉力大小相等

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：位置 (280,455)，作用：返回上一步骤，可回退复习
  - "下一步 ▶"按钮：位置 (500,455)，作用：进入下一步骤，逐步展示受力分析
  - 步骤指示器：位置 (380,455)，显示当前步骤 "步骤 X / 5"
- 教师操作流程：
  1. 初始展示两个容器及运动状态
  2. 点击"下一步"展示竖直方向受力（重力与支持力）
  3. 点击"下一步"展示水平方向受力（拉力与摩擦力）
  4. 点击"下一步"展示摩擦力公式及大小关系
  5. 点击"下一步"展示平衡条件及最终结论
  6. 可随时点击"上一步"回退复习某个步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形和动画，无需重型库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────┐
  │                                                         │
  │     →v                    →2v                           │
  │    ┌───┐                  ┌───┐                         │
  │   /     \                /     \                        │
  │  | 液体  |              | 液体  |                       │
  │  |       |              |       |                       │
  │   \     /                \     /                        │
  │    └───┘                  └───┘                         │
  │     F₁→←f₁                F₂→←f₂                        │
  │      ↓↑                    ↓↑                           │
  │      G₁ N支₁               G₂ N支₂                      │
  │  ──────────────────────────────────────────────────     │
  │  (桌面)                                                       │
  │                                                         │
  │  [◀上一步]  步骤 X/5  [下一步▶]                         │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep 记录当前步骤（0-4），每一步控制对应元素的 display 属性
  2. 坐标计算：所有元素坐标已在布局坐标表中精确定义，直接按坐标绘制
  3. 动画曲线：元素显示使用 opacity 渐变（0→1，300ms），增强视觉效果
  4. 事件绑定：按钮点击事件监听，更新 currentStep 并调用 updateScene() 刷新显示
  5. ID 命名规范：所有元素 ID 以 "scene2-" 为前缀（如 scene2-container-left、scene2-arrow-G1）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 元素分组：用 <g> 标签将同一步骤的元素分组，便于批量控制显示/隐藏
