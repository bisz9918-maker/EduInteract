    **题目原文：**
    如图，∠3=30°，为了使白球反弹后能将黑球直接撞入袋中，那么击打白球时，必须保证∠1的度数为（）
    A.30°
    B.60°
    C.90°
    D.45°

    **题目分析：**
    本题是一道台球反射的几何应用题，考查光的反射定律（入射角等于反射角）在几何中的运用。

    **关键几何关系：**
    1. 台球桌边框为矩形，法线（虚线）垂直于上边框
    2. ∠1 为入射角（入射路径与法线的夹角）
    3. ∠2 为反射角（反射路径与法线的夹角）
    4. 根据反射定律：∠1 = ∠2
    5. ∠2 与 ∠3 互余（因为法线垂直于边框，∠2 + ∠3 = 90°）

    **解题思路：**
    1. 由 ∠3 = 30°，得 ∠2 = 90° - 30° = 60°
    2. 由反射定律 ∠1 = ∠2，得 ∠1 = 60°
    3. 答案选 B

    - 步骤2：标注反射定律（∠1 = ∠2）
    - 步骤3：展示角度计算过程，得出结论

    **教学说明：**

    本图示通过分步交互引导学生理解台球反射问题中的几何关系。教师应按以下步骤讲解：

    **步骤0→步骤1：理解法线的作用**
    引导学生观察法线（虚线）与台球桌边框的垂直关系。强调法线是测量入射角和反射角的基准线，这是应用反射定律的前提。

    **步骤1→步骤2：认识反射定律**
    用相同颜色（红色）弧线同时高亮∠1和∠2，直观展示"入射角等于反射角"这一物理规律在几何中的体现。让学生理解为什么∠1 = ∠2。

    **步骤2→步骤3：发现互余关系**
    引导学生观察∠2和∠3的位置关系。由于法线垂直于边框，反射路径与法线的夹角（∠2）和反射路径与边框的夹角（∠3）构成直角，因此∠2 + ∠3 = 90°。

    **步骤3→步骤4：完成计算**
    展示完整的计算过程：
    1. 已知 ∠3 = 30°
    2. 由互余关系：∠2 = 90° - 30° = 60°
    3. 由反射定律：∠1 = ∠2 = 60°
    4. 因此答案为 B. 60°
