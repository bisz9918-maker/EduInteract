    **题目原文：**
    如图，△ABC中，AB=AC=4，∠C=72°，D是AB中点，点E在AC上，DE⊥AB，则cosA的值为（  ）

    A. (√5−1)/2
    B. (√5−1)/4
    C. (√5+1)/4
    D. (√5+1)/2

    **题目分析：**
    本题是一道几何计算题，核心考点包括：
    1. 等腰三角形的性质（底角相等、顶角计算）
    2. 线段垂直平分线的性质（垂直平分线上的点到线段两端距离相等）
    3. 黄金三角形的特殊角度关系（36°-72°-72°三角形）
    4. 三角函数值的计算

    **整体讲解思路：**
    本题的关键在于识别出这是一个"黄金三角形"问题。教师应引导学生：
    1. 首先从等腰三角形性质求出∠A=36°
    2. 利用DE是AB的垂直平分线，得出EA=EB
    3. 通过角度推导发现△BEC也是等腰三角形
    4. 建立边长关系，利用相似或余弦定理求解cos36°

    **教学说明：**

    本图示是讲解本题的核心可视化材料，教师应按以下步骤引导学生：

    **步骤0→步骤1：识别垂直平分线**
    引导学生观察D是AB中点且DE⊥AB，得出DE是AB的垂直平分线。强调垂直平分线的关键性质：垂直平分线上的任意一点到线段两端距离相等。

    **步骤1→步骤2：应用垂直平分线性质**
    点E在DE上，因此EA=EB。连接BE后，△ABE是等腰三角形，所以∠EBA=∠A。

    **步骤2→步骤3：角度计算**
    由△ABC是等腰三角形，∠B=∠C=72°，得∠A=180°-72°-72°=36°。
    因此∠EBA=36°，∠EBC=∠ABC-∠EBA=72°-36°=36°。
    发现∠EBC=36°，∠C=72°，所以∠BEC=180°-36°-72°=72°=∠C。
    故△BEC是等腰三角形，BE=BC。

    **步骤3→步骤4：建立边长关系**
    设AE=x，则BE=x（由步骤2），BC=x（由步骤3），EC=AC-AE=4-x。

    **步骤4→步骤5：求解cosA**
    方法一（相似三角形）：
    △ABC∽△BEC（三个角对应相等）
    所以 AB/BE = BC/EC
    即 4/x = x/(4-x)
    解得 x² = 4(4-x)，x²+4x-16=0
    x = (-4+√80)/2 = -2+2√5

    在Rt△ADE中，AD=2，AE=x=-2+2√5
    cosA = AD/AE = 2/(-2+2√5) = 1/(√5-1) = (√5+1)/4

    方法二（直接利用黄金三角形性质）：
    36°-72°-72°三角形是黄金三角形，cos36°=(√5+1)/4

    1. 先让学生独立观察图形，说出已知条件
    2. 逐步点击"下一步"，每步停顿让学生思考
    3. 重点强调"垂直平分线性质"和"角度推导"两个关键环节
    4. 最后总结：本题本质是黄金三角形的经典应用
