场景导航：Scene 1

题目原文：
如图，△OAB绕点O逆时针旋转70°到△OCD，如果∠A=100°，则∠D=50°，那么∠AOD的度数是（）
A.20°
B.30°
C.40°
D.50°

题目分析：
本题考查图形旋转的性质。关键知识点：

  1. 旋转不改变图形的形状和大小，对应角相等
  2. 旋转角等于对应点与旋转中心连线的夹角
  3. 三角形内角和为180°

已知条件梳理：

  • △OAB 绕点 O 逆时针旋转 70° 得到 △OCD
  • ∠A = 100°（原三角形内角）
  • ∠D = 50°（旋转后三角形内角）
  • 旋转角 = 70°

解题思路：

  1. 根据旋转性质，对应角相等：∠A = ∠C = 100°，∠B = ∠D = 50°
  2. 在△OAB中，利用内角和求出∠AOB = 180° - 100° - 50° = 30°
  3. 旋转角∠AOC = 70°
  4. ∠AOD = ∠AOC - ∠COD = 70° - 30° = 40°

教学说明：

本图示通过分步导航展示旋转问题的完整解题过程。教师讲解时应注意以下要点：

步骤0-1：建立旋转概念
首先展示原三角形△OAB，强调∠A=100°是已知条件。然后显示旋转后的△OCD，让学生观察两个三角形的位置关系。用蓝色弧线高亮旋转角70°，说明这是OA旋转到OC所经过的角度。

步骤2：理解旋转性质
高亮对应角关系，引导学生发现：

  • 旋转不改变图形形状，所以对应角相等
  • ∠A = ∠C = 100°，∠B = ∠D = 50°
  • ∠AOB = ∠COD（对应角）

步骤3：计算中间量
在△OAB中应用内角和定理：
$$∠AOB = 180° - ∠A - ∠B = 180° - 100° - 50° = 30°$$
用绿色标注∠AOB=30°，同时说明∠COD=30°。

步骤4：得出结论
观察∠AOD的构成：
$$∠AOD = ∠AOC - ∠COD = 70° - 30° = 40°$$
用红色高亮∠AOD，强调这是题目要求的答案。
