[图示主题与整合说明]
- 本图示主题：经纬网基础结构——极点、经线、纬线的空间关系
- 整合内容：极点 O 的识别、经线 P 和 Q 的标注、纬线 L 的展示、已知经度标注（45°和 15°E）

[分步序列]
- 步骤 0（初始状态）：空白画布，仅显示白色背景 #ffffff，等待教师点击「下一步」
- 步骤 1：显示极点 O（实心圆，坐标 400,80）及 O 标签（坐标 395,65），建立极点概念
- 步骤 2：添加两条经线 OP 和 OQ（从 O 点分别向左下、右下延伸），形成"V"字形结构
- 步骤 3：添加纬线 L（连接 P、Q 的向下凸出弧线），展示纬线与经线的相交关系
- 步骤 4：添加 P、Q 两点（经线与纬线交点）及 P、Q 标签，明确交点位置
- 步骤 5：添加 L 标签（纬线左侧）及经度标注 45°（左侧）和 15°E（右侧），完成全部标注
- 最终步骤：展示完整的经纬网结构，所有元素可见，教师可结合此图讲解经度差、半球判断等问题

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：ID scene1-btn-prev，位置 (280,455)，作用：返回上一状态
  - 「下一步」按钮：ID scene1-btn-next，位置 (500,455)，作用：进入下一状态
  - 步骤指示器：ID scene1-step-indicator，位置 (350,420)，显示当前步骤（如"步骤 1/5"）
- 教师操作流程：
  1. 初始展示空白画布，引出"经纬网由哪些基本要素构成"的问题
  2. 点击「下一步」逐步添加极点、经线、纬线、交点、标注
  3. 每步停顿讲解该要素的定义和作用
  4. 最终展示完整结构，结合经度标注讲解经度差计算、半球判断等概念
  5. 可随时点击「上一步」回退复习

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    800px                                │
  │  ┌───────────────────────────────────────────────────┐  │
  │  │                                                   │  │
  │  │              O (400,80)                           │  │
  │  │             /   \                                 │  │
  │  │            /     \                                │  │
  │  │           /       \                               │  │
  │  │    L(190)P         Q(570)                         │  │
  │  │         (250,300) (550,300)                       │  │
  │  │          45°       15°E                           │  │
  │  │        (210,360)  (570,360)                       │  │
  │  │                                                   │  │
  │  │                                                   │  │
  │  │              [步骤指示器]                         │  │
  │  │            [◀上一步][下一步▶]                     │  │
  │  └───────────────────────────────────────────────────┘  │
  │  500px                                                   │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量（0-5）跟踪当前步骤，每一步对应一个显示配置对象
  2. 坐标计算：所有元素坐标硬编码在配置对象中，确保精确到像素级
  3. 动画曲线：使用 SVG 的 opacity 属性实现淡入效果，transition: opacity 0.3s ease
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后重新渲染可见元素
  5. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-dot-O, scene1-line-OP, scene1-btn-prev）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 步骤配置：使用数组存储 6 个步骤（0-5）的显示配置，每个配置包含该步骤应显示的元素 ID 列表
