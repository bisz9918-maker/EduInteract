[分步序列]
步骤 0（初始状态）：
- 显示：极点 O、经线 OP、经线 OQ、纬线 L、P 点、Q 点
- 显示：P 点经度标注"45°"（黑色）、Q 点经度标注"15°E"（蓝色）
- 显示：纬线标签"L"（左上方）
- 隐藏：经度差标注、P 点经度结果、半球分界线、半球区域、方向结论
- 目的：展示基础经纬网图形，让学生识别已知条件

步骤 1（情况一：经度差 30°）：
- 新增：经度差弧线（绿色，PQ 之间）
- 新增：经度差标签"经度差 = 30°"（绿色，弧线上方）
- 新增：P 点经度结果"P 点经度 = 45°E"（红色，P 点下方）
- 计算逻辑：Q 为 15°E，经度差 30°，P 在 Q 西侧则 15°E-30°=15°W，P 在 Q 东侧则 15°E+30°=45°E。根据图示 P 在左侧，应为 45°E（从极点俯视，逆时针为东）
- 目的：展示第一种情况的经度差和 P 点经度计算

步骤 2（情况一：东西半球判断）：
- 新增：20°W 分界线（灰色虚线）
- 新增：160°E 分界线（灰色虚线）
- 新增：东半球区域填充（蓝色 15%，20°W-160°E 之间）
- 新增：西半球区域填充（红色 15%，两侧）
- 新增：东半球标签、西半球标签
- 高亮：P 点（45°E）在东半球区域内，Q 点（15°E）也在东半球区域内
- 结论：P、Q 两点都位于东半球
- 目的：展示东西半球划分，判断 P、Q 所在半球

步骤 3（情况二：经度差 60°）：
- 更新：经度差标签改为"经度差 = 60°"（绿色）
- 更新：P 点经度结果改为"P 点经度 = 45°W"（红色）
- 计算逻辑：Q 为 15°E，经度差 60°，P 在 Q 西侧则 15°E-60°=45°W
- 目的：展示第二种情况的经度差和 P 点经度计算

步骤 4（情况二：东西半球判断）：
- 更新：东半球区域高亮 Q 点（15°E）
- 更新：西半球区域高亮 P 点（45°W）
- 结论：P 点位于西半球，Q 点位于东半球
- 目的：展示第二种情况下 P、Q 所在半球

步骤 5（方向判断）：
- 新增：方向结论"P 在 Q 的正东方"（黑色，底部中央）
- 说明：P、Q 在同一条纬线 L 上，因此 P 在 Q 的正东方或正西方。从极点俯视，逆时针方向为东，P 在 Q 的逆时针方向，故 P 在 Q 的正东方
- 目的：总结 PQ 两点的相对位置关系

- 控件说明：
  - "◀ 上一步"按钮：位置 (260,455)，作用：返回上一步骤，可复习之前内容
  - "下一步 ▶"按钮：位置 (440,455)，作用：进入下一步骤，展示新的计算或判断

  3. 点击"下一步"展示东西半球划分，引导学生判断 P、Q 所在半球
  4. 点击"下一步"切换到情况二，展示经度差 60°时的计算

  7. 可随时点击"上一步"回退复习关键步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    800px                                │
  │  ┌───────────────────────────────────────────────────┐  │
  │  │                                                   │  │
  │  │              O (极点)                             │  │
  │  │             /   \                                 │  │
  │  │            /     \                                │  │
  │  │      L ---P-------Q--- 纬线                       │  │
  │  │         45°     15°E                              │  │
  │  │                                                   │  │
  │  │         经度差 = 30°/60°                          │  │
  │  │         P 点经度 = X°W/E                          │  │
  │  │                                                   │  │
  │  │  西半球│东半球│西半球                             │  │
  │  │  20°W      160°E                                  │  │
  │  │                                                   │  │
  │  │      [◀上一步]  步骤 X/6  [下一步▶]               │  │
  │  │                                                   │  │
  │  └───────────────────────────────────────────────────┘  │
  │                    500px                                │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-5) 跟踪当前步骤，每个步骤对应一个显示配置对象
  2. 坐标计算：所有元素使用绝对定位，通过 SVG 的 x/y 属性精确控制位置
  3. 动画曲线：步骤切换时使用 opacity 淡入淡出效果（0.3s transition）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 renderStep() 重新渲染
  5. ID 命名规范：所有元素 ID 以 scene2- 为前缀（如 scene2-极点 O、scene2-经线 OP、scene2-btn-next 等）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染
  7. 步骤配置对象示例：
     ```javascript
     const stepConfig = {
       0: { show: ['极点 O', '经线 OP', '经线 OQ', '纬线 L', 'P 点', 'Q 点', 'P 经度初始', 'Q 经度'], hide: [...] },
       1: { show: [...stepConfig[0].show, '经度差弧线', '经度差标签 30°', 'P 经度结果 45°E'], ... },
       ...
     };
     ```
  8. 半球区域使用 SVG <rect> 元素，fill-opacity 控制透明度
  9. 分界线使用 stroke-dasharray 实现虚线效果
