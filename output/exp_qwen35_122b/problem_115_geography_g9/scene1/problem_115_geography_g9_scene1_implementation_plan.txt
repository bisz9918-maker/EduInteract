[分步序列]
步骤 0（初始状态）：
- 显示：4 条经线（20°W、0°、20°E、40°E）黑色实线
- 显示：4 条纬线（66.5°N、23.5°N 虚线，0°实线，23.5°S 虚线）
- 显示：所有经度标签（20°W、0°、20°E、40°E）在经线下方
- 显示：所有纬度标签（66.5°、23.5°、0°、23.5°）在纬线右侧
- 不显示：各点、坐标标注、方向箭头、条件框

步骤 1：
- 新增：6 个点（甲、乙、丙、丁、E、F）蓝色实心圆
- 新增：6 个点标注（甲、乙、丙、丁、E、F）在各点旁
- 新增：6 个坐标标注（格式如"甲(0°,66.5°N)"）在各点旁
- 视觉变化：学生可清晰看到各点在经纬网中的位置及对应坐标

步骤 2：
- 新增：从 F 点到 E 点的红色方向箭头（斜向左下）
- 视觉变化：引导学生判断 E 点相对于 F 点的方向（西南方向）

步骤 3：
- 高亮：20°W 经线变为绿色加粗实线（线宽 3px）
- 高亮：23.5°N 纬线变为绿色加粗虚线（线宽 2px）
- 新增：条件框 1"东西半球分界：20°W"（右侧上方）
- 新增：条件框 2"北温带：四季变化明显"（右侧中间）
- 新增：条件框 3"热带：有太阳直射"（右侧下方）
- 视觉变化：突出关键地理分界线和判断条件

步骤 4（最终步骤）：
- 乙点：绿色外圈（线宽 3px）→ 符合全部条件
- 甲点：红色外圈（线宽 2px）→ 不符合（北部无四季变化，南部无太阳直射）
- 丙点：红色外圈（线宽 2px）→ 不符合（西部不是西半球）
- 丁点：红色外圈（线宽 2px）→ 不符合（南部无太阳直射）
- 视觉变化：明确展示正确答案为乙点

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：位置 (300,455)，作用：返回上一步骤，可复习之前内容
  - "下一步 ▶"按钮：位置 (450,455)，作用：进入下一步骤，展示新内容
  - 按钮样式：蓝色背景 #1565c0，白色文字，圆角 5px，尺寸 120×35px
- 教师操作流程：
  1. 初始展示经纬网框架，让学生熟悉经线纬线布局
  2. 点击"下一步"显示各点及坐标，讲解如何读取经纬度
  3. 点击"下一步"显示方向箭头，引导学生判断 E 相对于 F 的方向
  4. 点击"下一步"高亮分界线和条件框，讲解东西半球和五带特征
  5. 点击"下一步"显示最终答案，验证学生判断

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：经纬网为简单几何图形（直线、圆点、箭头、文本），原生 SVG 足以实现，无需引入重型库
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    经纬网图示区                          │
  │                                                         │
  │   66.5°  ──●甲───────────────●F  66.5°                  │
  │           │                   │                         │
  │   23.5°  ──●乙───────────────┼──────                   │
  │           │                   │                         │
  │    0°    ──●丙───────●E───────┼──────  0°               │
  │           │                   │                         │
  │  23.5°S  ──┼───────────────●丁  23.5°                   │
  │           │                   │                         │
  │          20°W   0°    20°E   40°E                       │
  │                                                         │
  │              [◀ 上一步]  [下一步 ▶]                      │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量（0-4）跟踪当前步骤，每一步对应一个状态函数
  2. 坐标计算：经纬线等距分布，经线间距 150px（150,300,450,600），纬线间距 100px（80,180,280,380）
  3. 元素显示控制：每个步骤的显示元素用数组存储，通过 toggleVisibility 函数控制
  4. 动画曲线：步骤切换使用 opacity 淡入效果（0.3s 过渡）
  5. 事件绑定：按钮点击事件绑定到 scene1-prev-btn 和 scene1-next-btn
  6. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-line-20w、scene1-point-jia、scene1-arrow-fe）
  7. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  8. 按钮状态：第一步时"上一步"按钮禁用，最后一步时"下一步"按钮禁用
