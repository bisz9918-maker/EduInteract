[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（椭圆、弧线、圆形、直线、文本），原生 SVG 足以实现，无需引入重型库
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │ 800px                                                          │
  │                                                                │
  │     ┌────────────────────────────────────────────────────┐    │
  │     │                                                    │    │
  │     │              地球球体 (200,80)-(500,380)           │    │
  │     │         A 点(红色) ────虚线──── B 点(蓝色)           │    │
  │     │              │         地心 │                      │    │
  │     │                                                    │    │
  │     │                    计算说明区                      │    │
  │     │                  (520,80)-(780,250)                │    │
  │     │                                                    │    │
  │     └────────────────────────────────────────────────────┘    │
  │                                                                │
  │              规律总结框 (200,400)-(600,440)                    │
  │                                                                │
  │              导航按钮 (300,455)-(500,485)                      │
  │                                                                │
  └────────────────────────────────────────────────────────────────┘
                              500px
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量 (0-4) 跟踪当前步骤，每一步对应一个显示配置对象
  2. 坐标计算：地球球体中心 (350,230)，半径 150px；A 点 (420,180) 对应 30°N,120°E；B 点 (280,280) 对应 30°S,60°W
  3. 动画曲线：虚线绘制使用 stroke-dasharray 和 stroke-dashoffset 实现渐显效果
  4. 事件绑定：按钮点击事件更新 currentStep，调用 renderStep() 重新渲染对应步骤元素
  5. ID 命名规范：所有元素 ID 以"scene2-"为前缀（如 scene2-earth, scene2-point-a, scene2-btn-next）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 元素显示控制：使用 display 属性或 opacity 控制各步骤元素的显示/隐藏
  8. 高亮效果：步骤 4 中 A、B 点使用 CSS animation 实现外圈闪烁效果
