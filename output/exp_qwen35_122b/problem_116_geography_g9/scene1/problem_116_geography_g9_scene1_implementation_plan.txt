[分步序列]
- 初始状态（步骤0）：
  - 显示：左图边框、右图边框、所有经线纬线、所有经纬度数值标注
  - 不显示：点A、点B、坐标框、比较箭头、结论框、点标签
  - 目的：展示基础经纬网框架

- 步骤1：点击「下一步」→
  - 新增显示：点A（蓝色圆点）、标签A、A坐标框、A坐标文本
  - 高亮：点A用蓝色 #1565c0 填充
  - 目的：引导学生读取A点坐标（130°E, 0°）

- 步骤2：点击「下一步」→
  - 新增显示：点B（红色圆点）、标签B、B坐标框、B坐标文本
  - 高亮：点B用红色 #c62828 填充
  - 目的：引导学生读取B点坐标（160°E, 60°N）

- 步骤3：点击「下一步」→
  - 新增显示：经度比较箭头、经度比较文本"130°E < 160°E"
  - 高亮：A点经度130°E和B点经度160°E用绿色虚线连接
  - 目的：比较经度，判断东西关系（A在B的西方）

- 步骤4：点击「下一步」→
  - 新增显示：纬度比较箭头、纬度比较文本"0° < 60°N"
  - 高亮：A点纬度0°和B点纬度60°N用绿色虚线连接
  - 目的：比较纬度，判断南北关系（A在B的南方）

- 步骤5（最终步骤）：点击「下一步」→
  - 新增显示：结论框、结论文本"A在B的西南"
  - 高亮：点A和点B同时用绿色边框闪烁强调
  - 目的：综合经度和纬度比较结果，得出最终方向结论

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "上一步"按钮：位于(300,455)-(390,485)，步骤>0时启用，点击返回前一步
  - "下一步"按钮：位于(410,455)-(500,485)，步骤<5时启用，点击进入下一步
- 教师操作流程：
  1. 初始展示双图框架，提问"这是两个什么类型的经纬网图？"
  2. 点击下一步，高亮A点，引导学生读取A点坐标
  3. 点击下一步，高亮B点，引导学生读取B点坐标
  4. 点击下一步，展示经度比较，提问"A点经度比B点大还是小？这意味着什么方向关系？"
  5. 点击下一步，展示纬度比较，提问"A点纬度比B点大还是小？这意味着什么方向关系？"
  6. 点击下一步，展示结论，总结"西南方向"的判断逻辑

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形和状态切换，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │                    经纬网方向判断 (300,15)                      │
  ├──────────────────┬──────────────┬──────────────────────────────┤
  │                  │              │                              │
  │   倾斜经纬网图    │   对比区     │      标准经纬网图             │
  │   (50,30)        │  (360,80)    │      (450,30)                │
  │   300×370        │  坐标对比    │      300×370                 │
  │                  │  方向箭头    │                              │
  │                  │  结论框      │                              │
  │                  │              │                              │
  ├──────────────────┴──────────────┴──────────────────────────────┤
  │                        控件栏 (y=440~490)                       │
  │              [◀ 上一步]          [下一步 ▶]                     │
  └────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-5) 跟踪当前步骤
  2. 元素分组：每个步骤显示的元素用 data-step 属性标记，如 data-step="1" 表示步骤1显示
  3. 坐标计算：所有元素使用绝对坐标，SVG 内定位
  4. 动画曲线：元素出现使用 opacity 从 0 到 1 的过渡动画（0.3s ease-in-out）
  5. 事件绑定：按钮点击事件监听，更新 currentStep 后重新渲染可见元素
  6. ID 命名规范：所有元素 ID 以 scene1- 为前缀，如 scene1-pointA、scene1-boxA、scene1-btnNext
  7. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  8. 按钮状态：currentStep=0 时禁用"上一步"，currentStep=5 时禁用"下一步"
