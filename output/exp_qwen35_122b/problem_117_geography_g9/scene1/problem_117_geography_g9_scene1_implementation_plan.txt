[分步序列]
- 步骤 0（初始状态）：
  - 显示：左图经纬网格、右图经纬网格、所有经纬度数值标签
  - 隐藏：甲点、乙点、坐标框、方向箭头、结论框、选项高亮框
  - 目的：展示题目基础条件，让学生先观察两个经纬网格

- 步骤 1：点击「下一步」→
  - 新增显示：甲点（蓝色实心圆，位置 (250,240)）、甲点标签"甲"（位置 (260,235)）、甲坐标框（位置 (265,200)-(355,230)，内容"甲（30°S，40°W）"）
  - 目的：引导学生读取甲地的经纬度坐标

- 步骤 2：点击「下一步」→
  - 新增显示：乙点（红色实心圆，位置 (550,240)）、乙点标签"乙"（位置 (560,235)）、乙坐标框（位置 (565,200)-(655,230)，内容"乙（30°N，40°E）"）
  - 目的：引导学生读取乙地的经纬度坐标

- 步骤 3：点击「下一步」→
  - 新增显示：南北方向箭头（垂直双向箭头，位置 (380,180)-(380,300)）、南北标注文字"甲在南半球，乙在北半球"（位置 (390,220)）
  - 高亮：甲点（蓝色闪烁）、乙点（红色闪烁）
  - 目的：演示南北方向判断——比较纬度，甲在南纬 30°，乙在北纬 30°，所以甲在乙的南方

- 步骤 4：点击「下一步」→
  - 新增显示：东西方向箭头（水平双向箭头，位置 (380,260)-(440,260)）、东西标注文字"甲在西经 40°，乙在东经 40°"（位置 (385,275)）
  - 目的：演示东西方向判断——比较经度，甲在西经 40°，乙在东经 40°，所以甲在乙的西方

- 步骤 5（结论）：点击「下一步」→
  - 新增显示：结论框（位置 (250,360)-(550,400)，内容"甲在乙的西南方 ✓"）
  - 高亮：甲点、乙点、南北箭头、东西箭头同时高亮
  - 目的：综合南北和东西判断，得出最终结论——甲在乙的西南方，对应选项 C 正确

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：位置 (320,450)-(390,480)，点击返回上一步骤
  - "下一步 ▶"按钮：位置 (410,450)-(480,480)，点击进入下一步骤
  - 步骤 0 时"上一步"按钮禁用，步骤 5 时"下一步"按钮禁用
- 教师操作流程：
  1. 初始展示两个经纬网格，让学生观察
  2. 点击"下一步"，逐步显示甲点坐标，引导学生读取
  3. 点击"下一步"，逐步显示乙点坐标，引导学生读取
  4. 点击"下一步"，显示南北方向判断，讲解纬度比较
  5. 点击"下一步"，显示东西方向判断，讲解经度比较
  6. 点击"下一步"，显示最终结论，总结方向判断方法
  7. 可随时点击"上一步"回退复习某个步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌────────────────────────────────────────────────────────────┐
  │  50°  40°  30°                    30°  40°  50°           │
  │  ┌────┬────┬────┐              ┌────┬────┬────┐          │
  │20°│    │    │    │            40°│    │    │    │        │
  │  ├────┼────┼────┤              ├────┼────┼────┤          │
  │30°│    │ 甲 │    │            30°│    │ 乙 │    │        │
  │  ├────┼────┼────┤              ├────┼────┼────┤          │
  │40°│    │    │    │            20°│    │    │    │        │
  │  └────┴────┴────┘              └────┴────┴────┘          │
  │                                                            │
  │              [南北箭头]  甲在南半球，乙在北半球            │

  │                                                            │
  │              [◀ 上一步]  [下一步 ▶]                        │
  └────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 currentStep 记录当前步骤（0-5），根据 currentStep 控制元素显示/隐藏
  2. 坐标计算：所有元素坐标已在布局坐标表中精确指定，直接使用
  3. 动画曲线：步骤切换使用 CSS transition（opacity 0.3s ease）实现淡入淡出效果
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateDisplay() 刷新视图
  5. ID 命名规范：所有元素 ID 以 scene1- 为前缀，如 scene1-grid-left、scene1-point-jia、scene1-btn-prev
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染
- 元素显示控制：
  - 步骤 0：显示所有网格线和经纬度标签
  - 步骤 1：+ 显示 scene1-point-jia、scene1-label-jia、scene1-coord-jia
  - 步骤 2：+ 显示 scene1-point-yi、scene1-label-yi、scene1-coord-yi
  - 步骤 3：+ 显示 scene1-arrow-ns、scene1-label-ns
  - 步骤 4：+ 显示 scene1-arrow-ew、scene1-label-ew
  - 步骤 5：+ 显示 scene1-conclusion-box
