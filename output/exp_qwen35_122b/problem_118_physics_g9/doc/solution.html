场景导航：Scene 1 | Scene 2

题目原文：
如图所示的电路中，电源电压恒定；闭合开关 S，电流表 A、电压表 V₁和 V₂的示数分别用 I、U₁和 U₂表示；当滑动变阻器 R₂的滑片 P 由如图位置向左滑动时，这三个电表示数变化量的大小分别用△I、△U₁和△U₂表示．下列判断正确的是（ ）
A. U₂/I 的值变小
B. (U₂−U₁)/I 的值不变
C. △U₁/△I 的值不变
D. △U₁和△U₂的大小相同

题目分析：
这是一道串联电路动态分析题。电路结构为：电源、开关 S、定值电阻 R₁、滑动变阻器 R₂ 串联；电流表 A 测总电流；电压表 V₁测 R₂两端电压；电压表 V₂测电源电压（即 R₁与 R₂的总电压）。

核心考点：

  1. 电路结构识别与电表测量对象判断
  2. 滑动变阻器滑片移动引起的电阻变化
  3. 欧姆定律在串联电路中的应用
  4. 物理量比值与变化量比值的物理意义

整体讲解思路：
首先通过电路结构图帮助学生识别各元件连接方式和电表测量对象；然后通过动态演示展示滑片左移时各物理量的变化趋势；最后通过公式推导分析各选项的物理意义，得出正确答案。

图示规划：

  • Scene 1：电路结构分析图（静态标注 + 分步高亮）
  • Scene 2：滑片移动动态演示图（拖拽滑块 + 数值变化显示）

Scene 1 教学说明：

本图示用于帮助学生识别电路结构和各电表的测量对象。教师应按以下步骤引导学生：

  1. 首先展示完整电路图，让学生观察整体结构
  2. 点击"下一步"，高亮主回路，引导学生确认这是一个串联电路（电源→S→R₁→R₂→电源形成闭合回路）
  3. 继续点击，依次高亮各电表，重点说明：
  • 电流表 A 串联在主回路中，测量的是总电流 I
  • 电压表 V₁并联在 R₂两端，测量的是 R₂两端电压 U₁
  • 电压表 V₂并联在电源两端，测量的是电源电压 U₂（即 R₁和 R₂的总电压）
  1. 最后总结各电表测量对象，强调 V₂测的是电源电压，因此 U₂保持不变

关键公式：

  • 串联电路总电阻：R_总 = R₁ + R₂
  • 欧姆定律：I = U₂ / (R₁ + R₂)
  • R₁两端电压：U_R1 = I × R₁
  • R₂两端电压：U₁ = I × R₂ = U₂ - U_R1

易错点提醒：
学生容易混淆 V₁和 V₂的测量对象，需要强调 V₂直接并联在电源两端，测量的是电源电压，因此无论滑片如何移动，U₂始终保持不变。

拖动滑块改变 R₂阻值 R₂ = 10Ω (50%)

Scene 2 教学说明：

本图示用于动态演示滑片移动时各物理量的变化规律。教师应引导学生观察并总结：

  1. 初始观察：展示滑片在中间位置时的各电表示数作为基准
  2. 拖拽演示：让学生亲自拖拽滑片向左移动，观察：
  • R₂接入电路的电阻变小（滑片左移，接入电阻丝长度变短）
  • 总电阻 R_总 = R₁ + R₂ 变小
  • 总电流 I = U₂ / R_总 变大（绿色↑）
  • U₁ = I × R₂，虽然 I 变大但 R₂变小更多，所以 U₁变小（红色↓）
  • U₂是电源电压，保持不变（灰色→）
  1. 反向验证：拖回滑片，观察变化是否可逆

各选项分析：

A. U₂/I 的值变小

  • U₂不变，I 变大，所以 U₂/I 变小 ✓ 正确

B. (U₂−U₁)/I 的值不变

  • U₂−U₁ = U_R1 = I × R₁
  • 所以 (U₂−U₁)/I = R₁，R₁是定值电阻，不变 ✓ 正确

C. △U₁/△I 的值不变

  • U₁ = U₂ - I × R₁
  • △U₁ = -△I × R₁
  • 所以 |△U₁/△I| = R₁，值不变 ✓ 正确

D. △U₁和△U₂的大小相同

  • U₂不变，△U₂ = 0
  • U₁变化，△U₁ ≠ 0
  • 所以两者大小不同 ✗ 错误

正确答案：A、B、C

课堂讲解建议：

  1. 先用 Scene 1 确保学生理解电路结构
  2. 用 Scene 2 动态演示变化规律，让学生直观感受
  3. 结合公式推导分析各选项，强调比值和变化量比值的物理意义
  4. 重点讲解选项 C，这是本题的难点，需要推导△U₁和△I 的关系

总结：完整解答与课堂建议

本题解答：
正确选项为 A、B、C

核心知识点回顾：

  1. 串联电路特点：电流处处相等，总电压等于各部分电压之和
  2. 欧姆定律应用：I = U/R
  3. 滑动变阻器工作原理：滑片移动改变接入电阻丝长度，从而改变电阻
  4. 物理量比值的意义：U/I 表示电阻，△U/△I 也表示电阻（动态电阻）

解题思路总结：

  1. 先判断电路结构（串联/并联）
  2. 确定各电表测量对象
  3. 分析滑片移动引起的电阻变化
  4. 根据欧姆定律推导各物理量变化
  5. 将选项中的表达式转化为已知物理量进行判断

易错点提醒：

  • 混淆电压表测量对象（V₁测 R₂，V₂测电源）
  • 忽略 U₂是电源电压保持不变
  • 不理解△U/△I 的物理意义（等于定值电阻 R₁）
