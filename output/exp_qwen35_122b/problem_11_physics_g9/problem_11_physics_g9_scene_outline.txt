    **题目原文：**
    如图所示，$\\textit{A}$是悬挂在弹簧测力计下的条形磁铁，$\\textit{B}$是螺线管。闭合开关，待弹簧测力计示数稳定后，将滑动变阻器的滑片缓慢向右移动的过程中，下列说法正确的是（）

    A.电压表示数变大，电流表示数也变大
    B.电压表示数变小，电流表示数也变小
    C.螺线管上端是N极，弹簧测力计示数变小
    D.螺线管上端是S极，弹簧测力计示数变大

    **题目分析：**
    本题是一道电磁学综合题，涉及三个核心知识点：
    1. 串联电路中滑动变阻器滑片移动对电流、电压的影响（欧姆定律）
    2. 通电螺线管极性的判断（安培定则/右手螺旋定则）
    3. 磁极间的相互作用规律（同名磁极相斥，异名磁极相吸）

    **整体讲解思路：**
    教师应分两步引导学生：首先分析电路，理解滑片右移→电阻变小→电流变大→电压表示数变小的因果关系；其次分析电磁铁，用安培定则判断螺线管上端为N极，与条形磁铁下端N极同名相斥，磁性增强导致排斥力增大，弹簧测力计示数变小。

    **图示规划说明：**
    规划 2 个交互式图示：
    - Scene 1：电路分析图示，通过拖动滑片观察电表读数变化
    - Scene 2：电磁铁与磁极相互作用图示，通过分步导航展示极性判断和力的变化

    **Scene 1 教学说明：**

    1. 引导学生观察电路连接方式：这是一个串联电路，电流依次经过电源、开关、定值电阻、滑动变阻器、螺线管、电流表回到电源负极。

    2. 明确电表测量对象：
    - 电流表 A 测量整个串联电路的电流
    - 电压表 V 测量滑动变阻器两端的电压

    3. 拖动滑片向右移动时，教师应引导学生逐步推理：
    - 滑片右移 → 滑动变阻器接入电路的电阻丝长度变短 → 电阻 R 变小
    - 总电阻 R总 = R₀ + R 变小
    - 根据欧姆定律 I = U/R总，电源电压 U 不变，总电阻变小 → 电流 I 变大 → 电流表示数变大
    - 定值电阻 R₀两端电压 U₀ = I·R₀，电流变大 → U₀变大
    - 滑动变阻器两端电压 U_R = U - U₀，U₀变大 → U_R变小 → 电压表示数变小

    4. 关键结论：滑片右移 → 电流表示数变大，电压表示数变小。因此选项 A、B 均错误。

    5. 教学提示：让学生先预测再拖动验证，强化"电阻变化→电流变化→电压分配变化"的因果推理能力。
    </TEXT_2>

    **Scene 2 教学说明：**

    1. **步骤 0-1：安培定则判断极性**
    教师引导学生用右手螺旋定则判断螺线管极性：
    - 右手握住螺线管
    - 四指弯曲方向与电流方向一致（从下端流入，上端流出）
    - 大拇指指向的方向即为螺线管的 N 极
    - 结论：螺线管上端是 N 极，下端是 S 极

    2. **步骤 2-3：标注磁极位置**
    - 螺线管：上端 N 极，下端 S 极
    - 条形磁铁：上端 S 极，下端 N 极（题目原图已标注）

    3. **步骤 4：磁极间相互作用**
    - 螺线管上端 N 极与条形磁铁下端 N 极相对
    - 根据"同名磁极相斥"，两 N 极之间产生排斥力 F 斥
    - 弹簧测力计示数 F = G - F 斥（G 为磁铁重力）

    4. **步骤 5：滑片右移后的变化**
    - 由 Scene 1 分析可知，滑片右移 → 电流 I 变大
    - 电流变大 → 螺线管磁性增强
    - 磁性增强 → 排斥力 F 斥增大
    - F 斥增大 → 弹簧测力计示数 F = G - F 斥 变小

    5. **最终结论**
    - 螺线管上端是 N 极
    - 弹簧测力计示数变小
    - 正确选项：C

    6. **课堂讲解建议**
    - 先让学生独立判断螺线管极性，再展示安培定则演示
    - 强调"电流变大→磁性增强→排斥力增大→示数变小"的完整推理链
    - 对比选项 C 和 D，明确极性判断和示数变化的因果关系
    - 提醒学生注意题目中"滑片缓慢向右移动"意味着电流逐渐变化，弹簧测力计示数逐渐减小
