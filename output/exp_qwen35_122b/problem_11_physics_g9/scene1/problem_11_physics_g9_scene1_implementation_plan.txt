[分步序列]
本场景为连续拖拽交互，无分步导航，状态随滑片位置连续变化：

- 初始状态（滑片在中间位置 x=300）：
  - 显示完整电路图，所有元件可见
  - 滑片位于滑动变阻器中间(300,140)-(300,180)
  - 电流表读数：I = 0.50 A（初始值）
  - 电压表读数：U = 5.00 V（初始值）
  - 滑片拖动区蓝色高亮，提示可拖动

- 滑片向右移动过程（x从300→380）：
  - 滑片位置实时更新
  - 滑动变阻器接入电阻减小（滑片右侧电阻丝变短）
  - 电流表读数逐渐增大（0.50A → 0.80A），数值变红#c62828提示增大
  - 电压表读数逐渐减小（5.00V → 3.20V），数值变绿#2e7d32提示减小
  - 实时显示当前电阻值、电流值、电压值

- 滑片向左移动过程（x从300→200）：
  - 滑片位置实时更新
  - 滑动变阻器接入电阻增大
  - 电流表读数逐渐减小
  - 电压表读数逐渐增大

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：
  1. 滑片箭头：位于滑动变阻器上方(200,120)-(380,140)区域，可左右拖动，蓝色#1565c0高亮
  2. 底部滑块控件：位置(250,450)-(550,470)，同步显示滑片位置，可拖动或点击定位
  3. 电表读数框：动态显示当前电流/电压值，数值变化时颜色提示（红增绿减）

- 教师操作流程：
  1. 初始展示完整电路，说明各元件名称和连接方式
  2. 拖动滑片向右，引导学生观察：滑片右移→接入电阻减小→总电阻减小→电流增大→滑动变阻器分压减小
  3. 拖动滑片向左，反向验证上述规律
  4. 结合电表颜色变化（红/绿），强化"增大/减小"的直观感受
  5. 可停在任意位置，让学生预测电表读数，再拖动验证

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（电路图适合用 SVG 绘制，交互逻辑简单无需重型库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │                        图示区 800×500                        │
  │                                                             │
  │   电源   S    ┌───R───┐         螺线管B                      │
  │   ┌─┐   ┌─┐  │ 滑片  │         ╔═══╗                       │
  │   │ │   │ │  │  ↓    │         ║   ║                       │
  │   └─┘   └─┘  └───┬───┘         ║   ║  弹簧测力计             │
  │    │     │      │ V           ║   ║    ┌───┐                │
  │    │     └──────┴─────┐       ║   ║    │ A │                │
  │    │                  │       ╚═══╝    └─N─┘                │
  │    │                  │         │                           │
  │   R₀                 A│         │                           │
  │   ┌───┐              ┌┴┐        │                           │
  │   │   │              │ │        │                           │
  │   └───┘              └┬┘        │                           │
  │    │                  │         │                           │
  │    └──────────────────┴─────────┘                           │
  │                                                             │
  │   读数:U=5.00V          读数:I=0.50A                        │
  │                                                             │
  │   滑片位置: [━━━━■━━━━━━━━]  向右移动 →                     │
  │                                                             │
  └─────────────────────────────────────────────────────────────┘
  ```

- 关键实现要点：
  1. 状态机设计：
     - 滑片位置 x ∈ [200, 380]，初始值 300
     - 接入电阻 R_接入 = R_总 × (380-x)/180
     - 总电阻 R_总 = R₀ + R_接入
     - 电流 I = U_电源 / R_总
     - 电压表读数 U_V = I × R_接入
     - 参数设定：U_电源=12V, R₀=10Ω, R_总=14Ω（最大）

  2. 坐标计算：
     - 滑片 x 坐标与拖动位置绑定
     - 电表读数根据公式实时计算
     - 数值保留两位小数

  3. 动画曲线：
     - 滑片拖动使用 requestAnimationFrame 平滑更新
     - 电表数值变化使用 CSS transition 实现渐变效果

  4. 事件绑定：
     - 滑片区域 mousedown/mousemove/mouseup 实现拖拽
     - 底部滑块同步绑定相同事件
     - 拖动时实时更新所有相关数值

  5. ID 命名规范：
     - 所有元素 ID 以 scene1- 为前缀
     - 如：scene1-slider-wiper, scene1-ammeter-display, scene1-voltmeter-display
     - 使用 getElementById 获取元素

  6. IIFE 隔离：
     - 所有 JS 代码包裹在 (function() { ... })() 中
     - 避免全局变量污染

  7. 颜色动态变化：
     - 电流增大时，数值颜色变为#c62828（红）
     - 电压减小时，数值颜色变为#2e7d32（绿）
     - 使用 CSS class 切换实现
