[图示主题与整合说明]
- 本图示主题：通电螺线管极性判断与磁极间相互作用
- 整合内容：安培定则判断螺线管极性、条形磁铁与螺线管的磁极位置、磁极间相互作用力、滑动变阻器滑片移动对电路和磁力的影响
- 教学价值：教师可逐步引导学生理解：(1) 用右手螺旋定则判断螺线管极性；(2) 分析磁极间相互作用（同名相斥）；(3) 理解滑片移动→电阻变化→电流变化→磁性变化→磁力变化→弹簧测力计示数变化的完整逻辑链

[分步序列]
- 步骤 0（初始状态）：
  - 显示完整电路图（左侧）和电磁装置（右侧）
  - 标注：A、B、S、R、R₀、V、A（电表）、磁铁 S 极和 N 极、螺线管电流方向 I
  - 磁铁 A 下端 N 极用红色标注，螺线管上端待判断
  - 弹簧测力计显示初始示数（刻度线）

- 步骤 1（右手螺旋定则）：
  - 在螺线管右侧显示右手示意图
  - 右手四指沿电流方向弯曲（蓝色箭头沿线圈）
  - 大拇指向上指向，标注"N 极方向"
  - 其他元素保持步骤 0 状态

- 步骤 2（螺线管极性）：
  - 右手示意图消失
  - 螺线管上端标注蓝色"N"（位置 660,280）
  - 螺线管下端标注"S"（位置 660,410）
  - 其他元素保持

- 步骤 3（磁铁极性确认）：
  - 强调条形磁铁下端 N 极（红色高亮闪烁）
  - 标注磁铁上端"S"（位置 550,170）、下端"N"（位置 550,240，红色）
  - 螺线管极性标注保持

- 步骤 4（磁极相互作用）：
  - 显示磁感线（灰色虚线）：螺线管外部从 N 向下到 S，内部从 S 向上到 N
  - 显示排斥力 F 斥：红色向上箭头从螺线管上端指向磁铁下端 (615,200)-(615,260)
  - 标注"F 斥"在箭头右侧 (625,230)
  - 文字提示："同名磁极相斥（N-N）"

- 步骤 5（滑片右移变化）：
  - 滑动变阻器滑片向右移动（箭头位置变化）
  - 电流表 A 示数增大（指针右偏动画）
  - 螺线管磁性增强（线圈周围蓝色光晕增强）
  - 排斥力 F 斥箭头变粗/变长
  - 弹簧测力计示数减小（弹簧缩短，刻度示数变小）
  - 绿色提示文本显示："滑片右移→R↓→I↑→磁性↑→F 斥↑→示数↓"

- 结论：
  - 高亮显示正确选项："螺线管上端是 N 极，弹簧测力计示数变小 → 选项 C 正确"
  - 螺线管 N 极标注和示数减小提示同时高亮

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：位置 (280,460)，作用：返回上一步骤
  - "下一步 ▶"按钮：位置 (500,460)，作用：进入下一步骤
  - 步骤指示器：位置 (380,465)，显示"步骤 X/6"
- 教师操作流程：
  1. 初始展示题目装置，让学生观察电路和磁铁位置
  2. 点击"下一步"，展示右手螺旋定则，讲解如何判断螺线管极性
  3. 点击"下一步"，显示螺线管 N/S 极标注
  4. 点击"下一步"，确认磁铁极性
  5. 点击"下一步"，展示磁极间排斥力
  6. 点击"下一步"，演示滑片右移后的连锁变化
  7. 最后得出结论，选择正确选项 C
  8. 可随时点击"上一步"回退复习关键步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何和动画，无需重型库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    图示区 800×500                       │
  │                                                         │
  │  [电路部分]              [电磁装置部分]                 │
  │  电源 开关 电阻          弹簧测力计                     │
  │  滑动变阻器              条形磁铁 A                     │
  │  电压表 电流表           螺线管 B                       │
  │                                                         │
  │  [右手示意图 - 步骤 1 显示]                              │
  │  [磁感线 - 步骤 4 显示]                                  │
  │  [排斥力箭头 - 步骤 4 显示]                              │
  │                                                         │
  │  ┌─────────────────────────────────────────────────┐   │
  │  │  ◀ 上一步    步骤 X/6    下一步 ▶              │   │
  │  │  (280,460)   (380,465)   (500,460)             │   │
  │  └─────────────────────────────────────────────────┘   │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-6) 跟踪当前步骤，每一步定义 showElements 和 hideElements 数组
  2. 坐标计算：所有元素用绝对定位，SVG 内用 transform 精确控制位置
  3. 动画曲线：滑片移动用 requestAnimationFrame 实现平滑过渡，弹簧长度变化用 CSS transition
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 renderStep() 重绘
  5. ID 命名规范：所有元素 ID 以"scene2-"为前缀（如 scene2-solenoid、scene2-magnet、scene2-btn-next）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 颜色定义：const COLORS = { main: '#000000', blue: '#1565c0', red: '#c62828', green: '#2e7d32', gray: '#888888' }
  8. 磁感线绘制：用 SVG path 绘制贝塞尔曲线，虚线样式 stroke-dasharray="5,5"
  9. 弹簧动画：用 scaleY 变换模拟弹簧伸缩，配合示数文本更新
