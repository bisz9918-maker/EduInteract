    **题目原文：**
    如图所示，电源电压不变，灯的电阻不变，滑动变阻器的滑片 P 在移动过程中，电流表的最小示数为 0.2A，电压表的最大示数为 4V，当滑片 P 滑到中点时，灯 L 的功率达到最大，且灯的最大功率与最小功率之比为 9：4．下列结论正确的是（  ）
    A．电源电压为 10V
    B．灯的电阻为 20Ω
    C．滑动变阻器的最大电阻为 40Ω
    D．电路消耗的最大功率为 1.8W

    **题目分析：**
    本题考查串联电路的动态分析，涉及欧姆定律、电功率计算等核心知识点。

    **电路结构：**
    - 电源、开关、灯泡 L、滑动变阻器、电流表串联
    - 电压表并联在滑动变阻器两端，测量变阻器电压

    **关键条件解读：**
    1. 电流表最小示数 0.2A → 电路总电阻最大时（变阻器阻值最大）
    2. 电压表最大示数 4V → 变阻器分压最大时（变阻器阻值最大）
    3. 滑片在中点时灯功率最大 → 此时电流最大（变阻器阻值最小）
    4. P_max : P_min = 9 : 4 → 电流平方比 I_max² : I_min² = 9 : 4

    **整体讲解思路：**
    1. 首先引导学生识别电路结构，明确各电表测量对象
    2. 分析滑动变阻器滑片移动时，电路总电阻、电流、各部分电压的变化规律
    3. 利用已知条件建立方程组，求解电源电压、灯电阻、变阻器最大阻值
    4. 验证各选项，得出正确答案

    **图示规划：**
    - Scene 1：电路结构分析与动态变化演示（整合电路识别、滑片移动影响分析）

    **Scene 1 教学说明：**

    本图示用于引导学生理解串联电路中滑动变阻器的动态变化规律。

    **讲解要点：**

    1. **电路识别（步骤 0）**
    - 引导学生识别这是一个串联电路：电源、开关、灯泡、变阻器依次串联
    - 明确电流表测干路电流，电压表测变阻器两端电压
    - 强调电压表并联位置，这是易错点

    2. **滑片移动分析（步骤 1-4）**
    - 滑片右移 → 变阻器阻值增大 → 总电阻增大 → 电流减小 → 灯变暗
    - 滑片左移 → 变阻器阻值减小 → 总电阻减小 → 电流增大 → 灯变亮
    - 电压表读数变化：U_R = I × R_变阻器，需同时考虑 I 和 R 的变化

    3. **关键条件应用（步骤 2-5）**
    - I_min = 0.2A 对应 R_变阻器 = R_max（滑片最右端）
    - U_R_max = 4V 对应 R_变阻器 = R_max（滑片最右端）
    - 灯功率最大时 I 最大，对应 R_变阻器 = 0（滑片最左端）
    - 由 P_max : P_min = 9 : 4，得 I_max² : I_min² = 9 : 4，故 I_max = 0.3A

    **公式推导：**

    当滑片在最右端（R_变阻器 = R_max）：
    - I_min = U / (R_L + R_max) = 0.2A
    - U_R_max = I_min × R_max = 4V

    当滑片在最左端（R_变阻器 = 0）：
    - I_max = U / R_L = 0.3A

    联立求解：
    - 由 U_R_max = 0.2 × R_max = 4V → R_max = 20Ω
    - 由 I_min = U / (R_L + 20) = 0.2A
    - 由 I_max = U / R_L = 0.3A
    - 解得：U = 6V，R_L = 20Ω

    **课堂引导建议：**
    - 每步停留时，先让学生预测变化趋势，再揭示答案
    - 重点强调"电压表测谁"这一易错点
    - 引导学生自己建立方程组，培养建模能力

    **完整解答与选项验证：**

    **已知条件汇总：**
    - I_min = 0.2A（变阻器最大时）
    - U_R_max = 4V（变阻器最大时）
    - I_max = 0.3A（由功率比 9:4 推出）

    **求解过程：**

    1. 求变阻器最大阻值 R_max：
    U_R_max = I_min × R_max
    4V = 0.2A × R_max
    R_max = 20Ω

    2. 求电源电压 U 和灯电阻 R_L：
    当 R_变阻器 = R_max = 20Ω 时：
    I_min = U / (R_L + 20) = 0.2A  ……①

    当 R_变阻器 = 0 时：
    I_max = U / R_L = 0.3A  ……②

    由②得：U = 0.3 × R_L
    代入①：0.3 × R_L / (R_L + 20) = 0.2
    0.3R_L = 0.2R_L + 4
    0.1R_L = 4
    R_L = 40Ω

    则 U = 0.3 × 40 = 12V

    3. 验证各选项：
    - A．电源电压为 10V → 错误，实际 U = 12V
    - B．灯的电阻为 20Ω → 错误，实际 R_L = 40Ω
    - C．滑动变阻器的最大电阻为 40Ω → 错误，实际 R_max = 20Ω
    - D．电路消耗的最大功率为 1.8W → 需计算

    4. 计算电路最大功率：
    P_max = U × I_max = 12V × 0.3A = 3.6W → 错误

    **重新检查计算：**

    由 P_L_max : P_L_min = 9 : 4
    P_L = I² × R_L
    I_max² : I_min² = 9 : 4
    I_max : I_min = 3 : 2
    I_max = 3/2 × 0.2 = 0.3A ✓

    U_R_max = I_min × R_max = 4V
    0.2 × R_max = 4
    R_max = 20Ω

    I_min = U / (R_L + R_max) = 0.2
    I_max = U / R_L = 0.3

    U = 0.3R_L
    0.3R_L / (R_L + 20) = 0.2
    0.3R_L = 0.2R_L + 4
    R_L = 40Ω
    U = 12V

    电路最大功率 P_total_max = U × I_max = 12 × 0.3 = 3.6W

    **结论：四个选项均不正确？**

    重新审题：题目说"当滑片 P 滑到中点时，灯 L 的功率达到最大"

    这意味着灯功率最大不是在 R_变阻器 = 0 时，而是在 R_变阻器 = R_max/2 时！

    **修正分析：**

    灯功率 P_L = I² × R_L = [U / (R_L + R_变阻器)]² × R_L

    要使 P_L 最大，需对 R_变阻器求导，或分析：
    当 R_变阻器 = R_L 时，P_L 最大（负载匹配原理）

    题目说中点时功率最大 → R_max/2 = R_L → R_max = 2R_L

    重新计算：
    I_min = U / (R_L + R_max) = U / 3R_L = 0.2A
    U_R_max = I_min × R_max = 0.2 × 2R_L = 4V
    → R_L = 10Ω
    → R_max = 20Ω
    → U = 0.2 × 30 = 6V

    I_max（当 R_变阻器 = 0）= U / R_L = 6 / 10 = 0.6A

    验证功率比：
    P_L_max（中点时 R_变阻器 = 10Ω）= [6/(10+10)]² × 10 = 0.09W
    P_L_min（最右端 R_变阻器 = 20Ω）= [6/(10+20)]² × 10 = 0.04W
    0.09 : 0.04 = 9 : 4 ✓

    电路最大功率 P_total_max = U × I_max = 6 × 0.6 = 3.6W

    **最终选项验证：**
    - A．电源电压为 10V → 错误，U = 6V
    - B．灯的电阻为 20Ω → 错误，R_L = 10Ω
    - C．滑动变阻器的最大电阻为 40Ω → 错误，R_max = 20Ω
    - D．电路消耗的最大功率为 1.8W → 错误，P_max = 3.6W

    **课堂讲解建议：**
    - 强调"灯功率最大"的条件是 R_变阻器 = R_L（负载匹配）
    - 引导学生理解为什么不是 R_变阻器 = 0 时灯功率最大
    - 提醒学生注意题目中的陷阱条件
