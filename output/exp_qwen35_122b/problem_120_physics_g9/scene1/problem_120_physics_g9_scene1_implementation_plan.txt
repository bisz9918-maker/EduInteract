[分步序列]
- 步骤 0（初始状态）：
  - 显示完整电路图（所有元件、导线、电表）
  - 标注各元件名称（U、S、L、R、A、V）
  - 右侧数值区空白
  - 滑片 P 显示在中间位置 (340,180)-(340,220)

- 步骤 1：
  - 高亮滑动变阻器（边框加粗为 3px，颜色 #1565c0）
  - 显示滑片移动轨迹（虚线从 (200,220) 到 (480,220)）
  - 右侧数值区显示："滑片 P 从左→右移动"
  - 变阻器阻值变化：R: 0 → R_max

- 步骤 2：
  - 滑片 P 移动到最右端 (480,180)-(480,220)
  - 高亮电压表 V（边框 #c62828 3px）
  - 右侧数值区显示：
    - "滑片在最右端 (R=R_max)"
    - "I_min = 0.2A"（蓝色）
    - "U_R_max = 4V"（红色）

- 步骤 3：
  - 滑片 P 移动到最左端 (200,180)-(200,220)
  - 高亮电流表 A（边框 #1565c0 3px）
  - 右侧数值区显示：
    - "滑片在最左端 (R=0)"
    - "I_max = ?"（蓝色，待求）
    - "灯功率 P_L 最大"（绿色）

- 步骤 4：
  - 滑片 P 移动到中点 (340,180)-(340,220)
  - 高亮灯泡 L（边框 #2e7d32 3px）
  - 右侧数值区显示：
    - "滑片在中点 (R=R_max/2)"
    - "灯功率达到最大"（绿色）
    - "P_L_max : P_L_min = 9 : 4"（绿色）

- 步骤 5（最终步骤）：
  - 所有关键元素同时高亮（变阻器、电流表、灯泡）
  - 右侧数值区显示完整推导：
    - "P = I²R_L"
    - "P_max : P_min = I_max² : I_min² = 9 : 4"
    - "I_max : I_min = 3 : 2"
    - "I_max = 1.5 × 0.2A = 0.3A"（蓝色）
  - 显示结论框："I_max = 0.3A"

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 按钮「◀ 上一步」：位于 (250,450)-(380,485)，灰色背景，点击返回上一步骤，步骤 0 时禁用
  - 按钮「下一步 ▶」：位于 (420,450)-(550,485)，蓝色背景，点击进入下一步骤，步骤 5 时显示「完成」
- 教师操作流程：
  1. 从步骤 0 开始，展示完整电路图，让学生识别各元件
  2. 点击「下一步」到步骤 1，讲解滑片移动对阻值的影响
  3. 点击「下一步」到步骤 2，分析滑片在最右端时的电路状态
  4. 点击「下一步」到步骤 3，分析滑片在最左端时的电路状态
  5. 点击「下一步」到步骤 4，讲解中点位置的特殊条件
  6. 点击「下一步」到步骤 5，展示公式推导和最终结论
  7. 可随时点击「上一步」回退复习关键步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：电路图是几何图形，SVG 最适合绘制精确的电路符号；无需复杂动画库，原生 JS 足以控制状态切换
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：

  │                        图示区 800×500                        │

  │         │                   ┌┴┐                │             │
  │         │                   │L│                │             │

  └─────────────────────────────────────────────────────────────┘

- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-5) 跟踪当前步骤
  2. 坐标计算：所有元素使用绝对坐标，滑片位置根据步骤动态更新
  3. 高亮效果：通过修改 stroke-width 和 stroke-color 实现
  4. 按钮状态：步骤 0 时禁用「上一步」，步骤 5 时「下一步」变为「完成」
  5. 数值区更新：根据 currentStep 动态显示对应的数值和公式
- ID 命名规范：所有交互元素 ID 以 scene1- 为前缀
  - 电路元件：scene1-电源、scene1-开关、scene1-灯泡、scene1-变阻器、scene1-电流表、scene1-电压表
  - 滑片：scene1-滑片
  - 按钮：scene1-btn-prev、scene1-btn-next
  - 数值区：scene1-value-display
- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
