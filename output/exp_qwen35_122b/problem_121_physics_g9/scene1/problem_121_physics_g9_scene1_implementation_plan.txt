[分步序列]
- 初始状态（步骤 0）：
  - 显示：地面线、地面阴影、六个物块（1-6）、编号 1-6、力 F 箭头、力 F 标签
  - 隐藏：所有受力分析标注、大括号、虚线框、结论框
  - 状态：题目基础条件，等待教师点击"下一步"

- 步骤 1（整体分析）：
  - 新增显示：整体大括号（绿色，包围全部 6 个物块）、整体标签、f_总箭头（红色，向左）、f_总标签（f_总=6N）
  - 视觉变化：大括号从上方框住所有物块，f_总箭头在系统中心位置向左
  - 教学要点：整体法分析，系统匀速运动→合力为 0，F=f_总=6N，每块摩擦力 f=1N

- 步骤 2（隔离分析）：
  - 新增显示：隔离虚线框（灰色，包围 4-5-6 号物块）、F_34 箭头（蓝色，从 3 号指向 4 号）、F_34 标签、f4/f5/f6 箭头（红色，各物块下方）、f4/f5/f6 标签（各 f=1N）
  - 隐藏：整体大括号、整体标签、f_总箭头、f_总标签
  - 视觉变化：虚线框圈出右侧 3 个物块作为隔离体，蓝色箭头表示 3 号对 4 号的推力
  - 教学要点：隔离 4-5-6 物块，匀速运动→合力为 0，F_34 = f4+f5+f6 = 3N

- 步骤 3（结论）：
  - 新增显示：结论框（蓝色边框）、结论文字（F_34=3N，蓝色加粗）
  - 保留：步骤 2 的所有元素
  - 视觉变化：结论框在图示下方高亮显示最终答案
  - 教学要点：3 号与 4 号物块之间的压力为 3N，对应选项 B

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮（scene1-btn-prev）：位于 (280,450)，点击返回上一步骤
  - 下一步按钮（scene1-btn-next）：位于 (380,450)，点击进入下一步骤
  - 重置按钮（scene1-btn-reset）：位于 (480,450)，点击返回初始状态
- 教师操作流程：
  1. 初始状态展示题目条件，教师引导学生观察六物块系统和外力 F
  2. 点击"下一步"进入步骤 1，讲解整体法：系统匀速→合力为 0，F=f_总=6N，每块 f=1N
  3. 点击"下一步"进入步骤 2，讲解隔离法：隔离 4-5-6，F_34=3f=3N
  4. 点击"下一步"进入步骤 3，高亮结论 F_34=3N，对应选项 B
  5. 可随时点击"上一步"回退复习，或点击"重置"重新开始

- 关键实现要点：
  1. 状态机设计：用变量 currentStep 记录当前步骤（0-3），根据步骤控制元素显示/隐藏
  2. 坐标计算：所有元素坐标按布局坐标表精确实现
  3. 动画曲线：元素出现使用 opacity 渐变（0→1，duration=300ms）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 并刷新显示
  5. ID 命名规范：所有交互元素 ID 以 scene1- 为前缀（如 scene1-block1、scene1-btn-next）
  6. JS 使用 getElementById 获取元素，避免 querySelectorAll 全局污染
  7. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中
