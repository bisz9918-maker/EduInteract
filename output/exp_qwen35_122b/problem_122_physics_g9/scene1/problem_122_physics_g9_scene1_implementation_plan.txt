[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 按钮"◀ 上一步"：位置 (320,460)，作用：返回上一状态，隐藏当前步骤新增元素
  - 按钮"下一步 ▶"：位置 (480,460)，作用：进入下一状态，显示当前步骤新增元素
  - 状态指示器：位置 (380,430)，显示"步骤 X/3"，作用：提示当前进度
- 教师操作流程：
  1. 初始展示金属板原图，引导学生观察几何结构
  2. 点击"下一步"，揭示 3 列串联关系，讲解串联概念
  3. 点击"下一步"，揭示每列内部并联关系，讲解并联概念
  4. 点击"下一步"，展示电阻计算公式，总结串并联等效计算
  5. 可随时点击"上一步"回退复习，巩固理解

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（矩形、线段、圆圈、文字），无需复杂绘图库；原生 SVG 可直接操作 DOM，适合分步显示/隐藏元素
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────┐
  │  800px                                                     │
  │                                                            │
  │   R                                                        │
  │                                                            │
  │   第 1 列    第 2 列    第 3 列                              │
  │   ┌────────┬────────┬────────┐                            │
  │ A │   r    │   r    │   r    │ B                          │
  │ ○─┤────────┼────────┼────────┤─○                          │
  │   │   r    │   r    │   r    │                            │
  │   │────────┼────────┼────────│                            │
  │   │   r    │   r    │   r    │                            │
  │   └────────┴────────┴────────┘                            │
  │                                                            │
  │                    电流箭头 →                              │
  │                                                            │
  │   步骤 X/3                                                 │
  │          ◀ 上一步    下一步 ▶                              │
  │                                                            │
  │  440-490px (控件栏区域)                                    │
  └────────────────────────────────────────────────────────────┘
  500px
  ```

- 关键实现要点：
  1. 状态机设计：用变量 currentStep 记录当前步骤（0-3），每一步定义该步骤应显示的元素 ID 列表
  2. 坐标计算：所有元素坐标按上述布局坐标表精确实现，使用 SVG 的 x、y、width、height 属性
  3. 动画曲线：无需复杂动画，元素显示/隐藏用 opacity 过渡（0.3s ease）
  4. 事件绑定：按钮点击事件绑定到 updateStep() 函数，根据 currentStep 增减元素显示
  5. ID 命名规范：所有元素 ID 以 scene1- 为前缀，如 scene1-rect-board, scene1-line-grid-h1, scene1-label-A 等
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
