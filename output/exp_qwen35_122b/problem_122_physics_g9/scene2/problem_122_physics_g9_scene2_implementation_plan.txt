[分步序列]
- 初始状态（步骤0）：显示完整金属板轮廓、接线柱A/B、内部3×3网格虚线、A/B标签、三列标签。不显示挖去标记、不显示并联弧、不显示公式框。
- 步骤1：点击「下一步」→ 在第2列第2行位置（中心400,250）显示红色叉号标记挖去位置。其他元素不变。
- 步骤2：点击「下一步」→ 显示绿色并联标注弧线（连接第2列第1行和第3行的小块），表示第2列只剩2块并联。同时第2列中间小块的灰色虚线边框变为红色虚线（表示挖去）。
- 步骤3：点击「下一步」→ 在金属板下方显示公式框，框内显示"R' = 7R/6"。同时显示计算说明文字"第1列：3块并联→r/3；第2列：2块并联→r/2；第3列：3块并联→r/3；总电阻：r/3 + r/2 + r/3 = 7r/6 = 7R/6"。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "上一步"按钮：位置(280, 460)，作用：返回前一个步骤
  - "下一步"按钮：位置(520, 460)，作用：进入下一个步骤
  - 步骤指示器：位置(400, 460)，显示"步骤 X/3"
- 教师操作流程：
  1. 初始展示完整金属板，讲解原始电阻R的电路结构（3列串联，每列3块并联）
  2. 点击"下一步"，标记挖去位置，引导学生观察哪一块被挖去
  3. 点击"下一步"，显示并联关系变化，讲解第2列从3块并联变为2块并联
  4. 点击"下一步"，显示计算公式，引导学生推导新电阻值

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────┐
  │                                                         │
  │     第1列        第2列        第3列                     │
  │       ↓           ↓           ↓                        │
  │  A ○──┌─────┬─────┬─────┐──○ B                        │
  │      │  □  │  ✗  │  □  │                              │
  │      ├─────┼─────┼─────┤                              │
  │      │  □  │  □  │  □  │                              │
  │      └─────┴─────┴─────┘                              │
  │                                                         │
  │              [R' = 7R/6]                               │
  │                                                         │
  │        ◀上一步    步骤 X/3    下一步▶                   │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  - 状态机设计：使用变量 currentStep (0-3) 跟踪当前步骤
  - 坐标计算：金属板 3×3 网格，每块 120×73px，挖去位置在第2列第2行（索引从1开始）
  - 元素显示控制：每个步骤显示/隐藏特定元素组（叉号、并联弧、公式框）
  - 动画曲线：元素出现使用 opacity 从 0 到 1 的过渡动画（0.3s ease）
  - 事件绑定：按钮点击事件监听，更新 currentStep 并调用 updateDisplay()
- ID 命名规范：所有交互元素 ID 以 scene2- 为前缀（如 scene2-metal-plate、scene2-hole-mark、scene2-step-btn-next）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
