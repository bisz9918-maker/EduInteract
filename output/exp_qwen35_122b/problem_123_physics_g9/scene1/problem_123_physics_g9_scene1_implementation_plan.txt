[分步序列]
- 初始状态（步骤0）：显示三个容器、初始水位线、气体区域、连接管、开关M、所有容器标签和气体体积标签。水体为蓝色半透明，气体区域为灰色斜线填充。开关M为红色圆形突出显示。
- 步骤1：点击「下一步」→ 在中间连通管内显示绿色水流箭头（从开关M向下），在右侧连通管内显示绿色水流箭头（从甲流向丙）。新增标签"水流"在箭头旁。
- 步骤2：点击「下一步」→ 乙水位线从y=250上升到y=230（水位上升20px），乙气体区域高度从50px减少到30px。在乙容器右侧显示红色向上箭头"↑"。V_乙标签高亮显示。
- 步骤3：点击「下一步」→ 丙水位线从y=400上升到y=380（水位上升20px），丙气体区域高度从50px减少到30px。在丙容器右侧显示红色向上箭头"↑"。V_丙标签高亮显示。同时乙丙气体区域用虚线框标注"压强增大"。
- 步骤4：点击「下一步」→ 甲水位线从y=100下降到y=120（水位下降20px）。在甲容器右侧显示红色向下箭头"↓"。右侧连通管内水流箭头方向反转（从丙流向甲）。
- 步骤5（最终状态）：点击「下一步」→ 所有水位线稳定在新位置。在图示下方显示总结文字："结论：V_乙减少，V_丙增大，且△V_乙＞△V_丙"。乙气体区域用红色边框高亮，丙气体区域用绿色边框高亮。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    大气                                  │
  │                        ▲                                │
  │  甲 ┌──────────────┐                                   │
  │     │   ~~~~~~~    │  ← 水位线 y=100                   │
  │     │      M●      │  ← 开关                          │
  │     │              │                                   │
  │     └──────┬───────┘                                   │
  │            │ 中间管                                     │
  │  乙 ┌──────┴───────┐                                   │
  │     │   ~~~~~~~    │  ← 水位线 y=250                   │
  │     │              │                                   │
  │     └──────┬───────┘                                   │
  │            │                                            │
  │  丙 ┌──────┴───────┐                                   │
  │     │   ~~~~~~~    │  ← 水位线 y=400                   │
  │     │              │                                   │
  │     └──────────────┘                                   │
  │            ▲                                            │
  │            │ 右侧连通管                                 │
  └─────────────────────────────────────────────────────────┘
  [上一步] [步骤 0/5] [下一步]
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep 记录当前步骤（0-5），updateScene() 函数根据 currentStep 显示/隐藏对应元素
  2. 坐标计算：所有元素使用绝对坐标，水位线 y 坐标根据步骤动态变化
  3. 动画曲线：水位变化使用 CSS transition 实现平滑过渡（transition: y 0.5s ease）
  4. 事件绑定：按钮点击事件绑定到 scene1-prev-btn 和 scene1-next-btn
  5. ID 命名规范：所有元素 ID 以"scene1-"为前缀（如 scene1-container-jia, scene1-waterline-jia）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 水位变化实现：用 setAttributeNS 动态修改水位线 y2 坐标和填充矩形高度
  8. 箭头显示/隐藏：用 display 属性控制箭头元素的可见性
  9. 高亮效果：用 stroke 和 stroke-width 属性实现标签高亮
