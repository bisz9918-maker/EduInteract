场景导航：Scene 1 | Scene 2

题目原文：
电磁铁甲和永磁体乙如图放置，开关S闭合后，b、c两端形成的磁感线如图中实线所示，由此可知（ ）
A、a、c两端都是N极 B、a、d两端都是N极 C、b、c两端都是N极 D、b、d两端都是N极

题目分析：
本题考察电磁学核心知识点：

  1. 安培定则（右手螺旋定则）判断电磁铁极性
  2. 磁感线形态与磁极关系（同名磁极相互排斥，磁感线向外弯曲）
  3. 磁体两端极性相反的基本性质

整体讲解思路：
本题解题逻辑链：电源极性→电流方向→线圈绕向→右手螺旋定则→电磁铁极性→磁感线形态→磁极关系→永磁体极性

图示规划：

  • SCENE_1：安培定则演示——展示如何根据电流方向和线圈绕向判断电磁铁极性
  • SCENE_2：磁感线与磁极关系——展示同名磁极排斥时的磁感线形态，帮助学生理解题目中磁感线所反映的磁极关系

SCENE_1 教学说明：

本图示用于讲解安培定则的应用，教师应按以下步骤引导学生：

  1. 观察电路连接：首先让学生识别电源正负极，明确电流从正极（右侧）流出，经过开关后进入线圈右端
  1. 追踪电流方向：引导学生观察线圈绕向，电流从右端进入后，从正面看是向上绕到背面，再从正面下来，形成螺旋流动
  1. 应用右手螺旋定则：
  • 右手握住螺线管
  • 四指弯曲方向与电流方向一致
  • 大拇指指向即为 N 极方向
  1. 得出结论：根据图中线圈绕向和电流方向，大拇指指向右端，因此 b 端为 N 极，a 端为 S 极

关键公式/原理：

  • 安培定则：右手握住螺线管，四指指向电流方向，大拇指指向 N 极
  • 电磁铁极性判断：电流方向 + 线圈绕向 → 磁极

易错点提醒：

  • 学生容易混淆电流方向与电子流动方向（本题按传统电流方向，从正极到负极）
  • 线圈绕向观察错误，需从正面视角判断电流是向上还是向下

SCENE_2 教学说明：

本图示用于讲解磁感线形态与磁极关系的判断，教师应按以下步骤引导学生：

  1. 回顾已知条件：从 SCENE_1 已知 b 端为 N 极
  1. 观察磁感线形态：
  • b、c 之间的磁感线向外弯曲
  • 磁感线不相交、不连接
  • 这是同名磁极相互排斥的典型特征
  1. 应用磁极关系规律：
  • 同名磁极：磁感线向外弯曲，相互排斥
  • 异名磁极：磁感线从 N 极指向 S 极，相互吸引
  • 题目中磁感线形态表明 b、c 为同名磁极
  1. 推断永磁体极性：
  • b 端为 N 极 → c 端也为 N 极（同名）
  • 永磁体两端极性相反 → d 端为 S 极
  1. 完整磁极分布：
  • a = S 极，b = N 极（电磁铁）
  • c = N 极，d = S 极（永磁体）

最终答案判断：

  • A：a、c 都是 N 极 → 错误（a 是 S）
  • B：a、d 都是 N 极 → 错误（a 是 S，d 是 S）
  • C：b、c 都是 N 极 → 正确
  • D：b、d 都是 N 极 → 错误（d 是 S）

正确答案：C

关键原理：

  • 磁感线从 N 极出发，回到 S 极
  • 同名磁极相互排斥，磁感线向外弯曲
  • 异名磁极相互吸引，磁感线连接两极

课堂讲解建议：
建议教师先用 SCENE1 讲解安培定则，确保学生掌握电磁铁极性判断方法，再用 SCENE2 讲解磁感线与磁极关系，最后引导学生独立完成选项判断。
