    **SCENE_1 教学说明：**

    本图示用于讲解安培定则的应用，教师应按以下步骤引导学生：

    1. **观察电路连接**：首先让学生识别电源正负极，明确电流从正极（右侧）流出，经过开关后进入线圈右端

    2. **追踪电流方向**：引导学生观察线圈绕向，电流从右端进入后，从正面看是向上绕到背面，再从正面下来，形成螺旋流动

    3. **应用右手螺旋定则**：
       - 右手握住螺线管
       - 四指弯曲方向与电流方向一致
       - 大拇指指向即为 N 极方向

    4. **得出结论**：根据图中线圈绕向和电流方向，大拇指指向右端，因此 b 端为 N 极，a 端为 S 极

    **关键公式/原理：**
    - 安培定则：右手握住螺线管，四指指向电流方向，大拇指指向 N 极
    - 电磁铁极性判断：电流方向 + 线圈绕向 → 磁极

    **易错点提醒：**
    - 学生容易混淆电流方向与电子流动方向（本题按传统电流方向，从正极到负极）
    - 线圈绕向观察错误，需从正面视角判断电流是向上还是向下

    **SCENE_2 教学说明：**

    本图示用于讲解磁感线形态与磁极关系的判断，教师应按以下步骤引导学生：

    1. **回顾已知条件**：从 SCENE_1 已知 b 端为 N 极

    2. **观察磁感线形态**：
       - b、c 之间的磁感线向外弯曲
       - 磁感线不相交、不连接
       - 这是**同名磁极相互排斥**的典型特征

    3. **应用磁极关系规律**：
       - 同名磁极：磁感线向外弯曲，相互排斥
       - 异名磁极：磁感线从 N 极指向 S 极，相互吸引
       - 题目中磁感线形态表明 b、c 为同名磁极

    4. **推断永磁体极性**：
       - b 端为 N 极 → c 端也为 N 极（同名）
       - 永磁体两端极性相反 → d 端为 S 极

    5. **完整磁极分布**：
       - a = S 极，b = N 极（电磁铁）
       - c = N 极，d = S 极（永磁体）

    **最终答案判断：**
    - A：a、c 都是 N 极 → 错误（a 是 S）
    - B：a、d 都是 N 极 → 错误（a 是 S，d 是 S）
    - C：b、c 都是 N 极 → **正确**
    - D：b、d 都是 N 极 → 错误（d 是 S）

    **正确答案：C**

    **关键原理：**
    - 磁感线从 N 极出发，回到 S 极
    - 同名磁极相互排斥，磁感线向外弯曲
    - 异名磁极相互吸引，磁感线连接两极

    **课堂讲解建议：**
    建议教师先用 SCENE_1 讲解安培定则，确保学生掌握电磁铁极性判断方法，再用 SCENE_2 讲解磁感线与磁极关系，最后引导学生独立完成选项判断。
