[分步序列]
- 初始状态（步骤0）：
  - 显示电磁铁甲（铁芯+线圈+电路），标注 a=S（蓝色）、b=N（绿色）
  - 显示永磁体乙，标注 c、d 端位置标签，不显示极性
  - 显示 b、c 之间的 4 条磁感线（黑色曲线，向外弯曲）
  - 不显示高亮框、提示框、c/d 极性标记

- 步骤1：点击「下一步」→
  - 在 b、c 之间磁感线区域添加红色虚线高亮框 (275,190)-(525,270)
  - 磁感线保持显示，高亮框突出显示关键观察区域

- 步骤2：点击「下一步」→
  - 高亮框保持显示
  - 在下方添加灰色提示框 (250,300)-(550,350)
  - 提示框内显示文字"同名磁极相互排斥"
  - 磁感线向外弯曲的形态更加明显（可轻微加粗）

- 步骤3：点击「下一步」→
  - 高亮框和提示框保持显示
  - 在 c 端上方标注"N"（绿色），表示 c 端为 N 极
  - 添加推理说明：c 与 b 为同名磁极

- 步骤4：点击「下一步」→
  - 所有元素保持显示
  - 在 d 端上方标注"S"（蓝色），表示 d 端为 S 极
  - 添加推理说明：d 与 c 为异名磁极
  - 完整展示：a=S、b=N、c=N、d=S

- 结论状态（步骤4）：
  - 完整标注所有磁极
  - 根据标注判断：a 端是 S 极，d 端是 S 极
  - 选项分析：A(a、c都是N极)× B(a、d都是N极)× C(b、c都是N极)✓ D(b、d都是N极)×
  - 正确答案：C

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（矩形、曲线、文本），无需复杂库，原生实现轻量高效
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │                         800px                                  │
  │  ┌─────────────────────────────────────────────────────────┐   │
  │  │                                                          │   │
  │  │   [电磁铁甲]                    [磁感线]        [永磁体乙] │   │
  │  │   a=S  ╔════╗                    ~~~~          ╔════╗  d=S│   │
  │  │        ║线圈║   b=N              ~~~~    c=N   ║     ║    │   │
  │  │   ~~~~ ╚════╝                    ~~~~          ╚════╝    │   │
  │  │    │  │  │                                                      │   │
  │  │    │  └──┴── 电源 ── 开关                                       │   │
  │  │                                                          │   │
  │  │              [高亮框/提示框区域]                          │   │
  │  │                                                          │   │

  │  │                                                          │   │

  │  │                                                          │   │
  │  └─────────────────────────────────────────────────────────┘   │
  │                              500px                              │
  └────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量（0-4），根据步骤控制元素显示/隐藏
  2. 坐标计算：所有元素使用绝对定位，SVG 内使用 transform 或直接坐标
  3. 动画曲线：磁感线高亮使用 opacity 渐变，提示框使用 scale 淡入
  4. 事件绑定：按钮点击事件监听，更新 currentStep 并刷新显示
  5. ID 命名规范：所有元素 ID 以 scene2- 为前缀（如 scene2-core-甲、scene2-field-line1）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 磁感线绘制：使用 SVG path 元素，bezier 曲线模拟向外弯曲形态
  8. 箭头绘制：在磁感线路径末端添加 marker 或单独绘制小三角形

- 步骤控制逻辑：
  ```javascript
  const stepElements = {
    0: ['core-甲', 'core-乙', 'field-line1-4', 'label-a/b/c/d', 'polarity-a/b'],
    1: ['highlight-box'],
    2: ['hint-box', 'hint-text'],
    3: ['polarity-c'],
    4: ['polarity-d']
  };
  
  function updateDisplay(step) {
    // 显示步骤 0 及之前的所有元素
    for (let s = 0; s <= step; s++) {
      stepElements[s].forEach(id => {
        document.getElementById('scene2-' + id).style.display = 'block';
      });
    }
    // 更新按钮状态
    document.getElementById('scene2-prev-btn').disabled = (step === 0);
    document.getElementById('scene2-next-btn').disabled = (step === 4);
    // 更新步骤指示
    document.getElementById('scene2-step-indicator').textContent = '步骤 ' + step + '/4';
  }
  ```
