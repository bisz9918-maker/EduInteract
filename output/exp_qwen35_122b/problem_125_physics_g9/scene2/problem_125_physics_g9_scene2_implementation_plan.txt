[分步序列]
本场景为连续拖拽交互，无分步导航，状态随拖拽实时更新：

- 初始状态（步骤 0）：
  - 蜡烛位于 2F 左侧约 x=220 处（u=180cm，物距大于 2f）
  - 光屏位于右侧约 x=540 处（v=140cm，像距在 f 和 2f 之间）
  - 像为倒立缩小的实像，火焰高度约 30px
  - 数值框显示：u = 180 cm, v = 140 cm
  - 成像性质框显示：成像：倒立、缩小、实像

- 拖拽过程（实时更新）：
  - 蜡烛向左拖拽（u 增大）：像向左移动（v 减小），像变小
  - 蜡烛向右拖拽（u 减小）：像向右移动（v 增大），像变大
  - 当蜡烛在 2F 处（u=2f）：像也在 2F 处（v=2f），等大倒立实像
  - 当蜡烛在 F 和 2F 之间（f<u<2f）：像在 2F 右侧（v>2f），放大倒立实像
  - 当蜡烛在 F 处（u=f）：不成像（光线平行）
  - 当蜡烛在 F 左侧（u<f）：成正立放大虚像（本场景主要演示实像，虚像情况可选显示）

- 关键状态点：
  - 状态 A（u>2f）：蜡烛在 2F 左侧，像在 f<v<2f，缩小倒立实像
  - 状态 B（u=2f）：蜡烛在 2F，像在 2F，等大倒立实像
  - 状态 C（f<u<2f）：蜡烛在 F 和 2F 之间，像在 v>2f，放大倒立实像

[交互方案]
- 交互类型：连续拖拽交互 — 拖拽蜡烛改变物距，像的位置和大小实时变化
- 控件说明：
  1. 拖拽手柄：圆形蓝色按钮，位于蜡烛主体上，直径 12px，可水平拖拽
  2. 数值显示框：右上角固定显示框，实时显示 u 和 v 的数值（单位：cm）
  3. 成像性质框：右下角固定显示框，实时显示成像性质（倒立/正立、放大/缩小、实像/虚像）
  4. 拖拽提示：蜡烛下方灰色提示文字，引导教师操作

- 教师操作流程：
  1. 图示加载后，蜡烛初始位于 2F 左侧（u>2f），显示缩小倒立实像
  2. 教师用鼠标/触控拖拽蜡烛手柄向左移动（增大物距），观察像向左移动且变小
  3. 教师拖拽蜡烛向右移动至 2F 处（u=2f），观察像等大
  4. 继续拖拽蜡烛向右至 F 和 2F 之间（f<u<2f），观察像变为放大
  5. 拖拽蜡烛接近 F 点（u→f），观察像距趋向无穷大
  6. 配合数值框和成像性质框，讲解"物远像近像变小，物近像远像变大"规律

- 关键实现要点：
  1. 状态机设计：维护蜡烛位置 x_candle（范围 100~380，不能越过透镜），根据透镜公式 1/f = 1/u + 1/v 计算像距 v，其中 u = 400 - x_candle（物距），f = 80（焦距）
  2. 坐标计算：
     - 物距 u = 400 - candleX（蜡烛中心 x 坐标）
     - 像距 v = 1 / (1/f - 1/u) = f*u / (u-f)
     - 光屏位置 x_screen = 400 + v
     - 像大小 scale = v / u（放大倍数）
     - 像火焰高度 = 40 * scale（基础高度 40px）
  3. 拖拽实现：
     - mousedown 在拖拽手柄上时设置 isDragging = true
     - mousemove 时更新蜡烛 x 坐标（限制在 100~380 范围内）
     - mouseup 时设置 isDragging = false
     - 使用 requestAnimationFrame 平滑更新
  4. 实时更新：每次蜡烛位置变化，重新计算 v、光屏位置、像大小，更新 SVG 元素属性
  5. 成像性质判断：
     - u > 2f：倒立、缩小、实像
     - u = 2f：倒立、等大、实像
     - f < u < 2f：倒立、放大、实像
     - u = f：不成像（光线平行）
     - u < f：正立、放大、虚像（本场景主要演示实像）
  6. ID 命名规范：所有交互元素 ID 以"scene2-"为前缀，如 scene2-candle, scene2-handle, scene2-screen, scene2-u-text, scene2-v-text, scene2-image-text
  7. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染

- 透镜公式实现细节：
  ```javascript
  const f = 80; // 焦距 80px
  function calculateImage(candleX) {
    const u = 400 - candleX; // 物距
    if (Math.abs(u - f) < 1) {
      return { v: Infinity, scale: Infinity, type: 'parallel' }; // u=f，光线平行
    }
    const v = (f * u) / (u - f); // 像距
    const scale = v / u; // 放大倍数
    let imageType = '';
    if (u > 2 * f) imageType = '倒立、缩小、实像';
    else if (Math.abs(u - 2 * f) < 1) imageType = '倒立、等大、实像';
    else if (u > f) imageType = '倒立、放大、实像';
    else imageType = '正立、放大、虚像';
    return { v, scale, type: imageType };
  }
  ```

- 事件绑定：
  - scene2-handle: mousedown → 开始拖拽
  - window: mousemove → 更新蜡烛位置
  - window: mouseup → 结束拖拽
  - 触摸事件同理（touchstart, touchmove, touchend）
