[图示主题与整合说明]
- 本图示主题：水平滑轮组结构与运动关系分析
- 整合的步骤/概念：滑轮组绳子段数判断（n=3）、物体与绳子移动距离关系（S绳=3S物）、速度关系（v绳=3v物）
- 教学价值：教师可逐步引导学生观察滑轮组结构，理解承担拉力的绳子段数如何决定距离和速度关系，建立n=3的完整认知链条

[分步序列]
- 步骤0（初始状态）：
  - 显示：桌面、物体A、A标签、三个滑轮、墙面、绳子主线、拉力F箭头、F标签、摩擦力f箭头、f标签
  - 隐藏：n=3标注、S物标注、S绳标注、v物标注、v绳标注、承重绳子高亮
  - 目的：展示滑轮组基础结构，让学生观察绳子走向

- 步骤1：
  - 新增：n=3标注（蓝色，位置(445,210)）、三段承重绳子高亮（蓝色加粗，覆盖在连接动滑轮的三段绳子上）
  - 高亮：三段水平绳段（从物体到动滑轮1、动滑轮1到动滑轮2、动滑轮2到定滑轮）用蓝色#1565c0加粗显示
  - 目的：引导学生识别承担拉力的绳子段数n=3

- 步骤2：
  - 新增：S物标注（绿色虚线+文字，物体下方）、S绳标注（蓝色虚线+文字，拉力F上方）
  - 显示文字："S绳 = 3 × S物"（蓝色，位置(525,120)，字体18px）
  - 目的：展示距离关系，绳子移动距离是物体移动距离的3倍

- 步骤3：
  - 新增：v物标注（绿色，物体下方S物下方）、v绳标注（蓝色，拉力F上方S绳上方）
  - 显示文字："v绳 = 3 × v物"（蓝色，位置(525,100)，字体18px）
  - 目的：展示速度关系，绳子移动速度是物体移动速度的3倍

- 结论（步骤4，可选总结页）：
  - 所有元素显示
  - 中央显示总结框："滑轮组规律：n=3 → S绳=n×S物，v绳=n×v物"
  - 目的：完整总结n=3的三种关系

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 按钮"◀ 上一步"：位置(250,455)，作用：返回上一状态，禁用状态在步骤0时
  - 按钮"下一步 ▶"：位置(450,455)，作用：进入下一状态，禁用状态在结论页时
  - 按钮样式：矩形80×35px，圆角5px，背景#1565c0，文字白色，悬停#0d47a1
- 教师操作流程：
  1. 初始展示滑轮组结构，让学生观察绳子走向
  2. 点击"下一步"，高亮三段承重绳子，讲解n=3的判断方法
  3. 点击"下一步"，显示距离关系，讲解S绳=n×S物的推导
  4. 点击"下一步"，显示速度关系，讲解v绳=n×v物的推导
  5. 可点击"上一步"回退复习任意环节
  6. 最终总结n=3的完整关系链

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────┐
  │                        800px                               │
  │  ┌──────────────────────────────────────────────────────┐  │
  │  │                                                      │  │
  │  │   [物体A]────────────[滑轮组]────[墙]                │  │
  │  │     ███              ○ ○ ○        |||               │  │
  │  │     ███              │ │ │        |||               │  │
  │  │     ███──────────────┴─┴─┴────────|||               │  │
  │  │   ─────────────────────────────────────────桌面      │  │
  │  │                                                      │  │
  │  │         F←              n=3                          │  │
  │  │                                                      │  │
  │  │                    S绳                               │  │
  │  │                                                      │  │
  │  │         f←                                           │  │
  │  │                    S物                               │  │
  │  │                                                      │  │
  │  │         ◀ 上一步      下一步 ▶                       │  │
  │  │                                                      │  │
  │  └──────────────────────────────────────────────────────┘  │
  │                        500px                               │
  └────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep 记录当前步骤（0-4），步骤0为初始，步骤4为结论
  2. 元素分组：每个步骤新增的元素用<g id="scene1-stepX">分组，通过显示/隐藏控制
  3. 坐标计算：所有坐标已在布局表中精确规划，直接硬编码
  4. 动画曲线：元素出现用 opacity 从0到1的过渡动画（0.3s ease-in-out）
  5. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateDisplay() 刷新
  6. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-obj-A、scene1-pulley1、scene1-btn-prev）
  7. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  8. 按钮禁用状态：步骤0时禁用"上一步"，步骤4时禁用"下一步"，通过 disabled 属性控制
