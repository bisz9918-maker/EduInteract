[交互方案]
- 交互类型：多状态切换（4 个按钮）
- 控件说明：
  - 按钮「选项 A」：位置 (210,450)-(300,480)，点击后高亮选项 A 边框，显示 A 的标注
  - 按钮「选项 B」：位置 (310,450)-(400,480)，点击后高亮选项 B 边框，显示 B 的标注
  - 按钮「选项 C」：位置 (410,450)-(500,480)，点击后高亮选项 C 边框，显示 C 的标注
  - 按钮「选项 D」：位置 (510,450)-(600,480)，点击后高亮选项 D 边框，显示 D 的标注
- 教师操作流程：
  1. 图示加载后默认高亮正确选项 B，教师可先讲解正确光路
  2. 点击「选项 A」按钮，讲解错误原因（出射时仍向法线偏折）
  3. 点击「选项 C」按钮，讲解错误原因（全反射误用）
  4. 点击「选项 D」按钮，讲解错误原因（忽略折射）
  5. 最后回到「选项 B」，总结正确光路特点

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │                        800 × 500 画布                          │
  │                                                                │
  │  ┌──────┐  ┌──────┐  ┌──────┐  ┌──────┐                       │
  │  │  A   │  │  B   │  │  C   │  │  D   │   四个选项并排        │
  │  │      │  │      │  │      │  │      │                       │
  │  │玻璃砖│  │玻璃砖│  │玻璃砖│  │玻璃砖│                       │
  │  │      │  │      │  │      │  │      │                       │
  │  │光路  │  │光路  │  │光路  │  │光路  │                       │
  │  │      │  │      │  │      │  │      │                       │
  │  └──────┘  └──────┘  └──────┘  └──────┘                       │
  │   标注 A     标注 B     标注 C     标注 D                        │
  │                                                                │
  │  ┌──────────────────────────────────────────────────────┐     │
  │  │   [选项 A]    [选项 B]    [选项 C]    [选项 D]        │     │
  │  └──────────────────────────────────────────────────────┘     │
  │                        控件栏 (y=440-490)                      │
  └────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 currentOption 记录当前选中的选项（'A'/'B'/'C'/'D'）
  2. 边框颜色切换：点击按钮时，将所有选项边框重置为红色，然后将选中选项边框改为对应颜色（B 为绿色，其他为红色）
  3. 标注文字显示：每个选项的标注文字始终显示，但高亮选项的标注文字加粗显示
  4. 坐标计算：四个选项水平均分，每个选项宽度 140px，间距 20px
  5. 事件绑定：每个按钮绑定 click 事件，调用 updateOption(option) 函数
  6. ID 命名规范：所有元素 ID 以 scene2- 为前缀（如 scene2-opt-A-border、scene2-btn-A 等）
  7. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染

- 初始状态：默认选中选项 B，选项 B 边框为绿色，其他选项边框为红色
