- 步骤 0（初始）：仅显示正三棱柱线框（上底面 3 条棱、下底面 3 条棱、3 条侧棱），被遮挡的棱用虚线表示。无微粒显示。

- 步骤 2：在步骤 1 基础上，高亮显示 9 条棱中点位置（B 微粒），微粒变为蓝色#1565c0 实心圆（半径 4px），并显示标签"B"。A 微粒恢复黑色。
- 步骤 3：在步骤 2 基础上，高亮显示体内中心位置（C 微粒），空心圆变为蓝色#1565c0 边框，并显示标签"C"。A、B 微粒恢复黑色。
- 步骤 4：完整显示所有微粒（A/B/C 均显示为黑色），同时显示数量统计文字"A: 6 个（顶点） B: 9 个（棱中点） C: 1 个（体内）"，位于图示上方中央。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 按钮「◀ 上一步」：位于(280,470)，100×30px，步骤 0 时灰色禁用，步骤 1-4 时蓝色可点击
  - 按钮「下一步 ▶」：位于(500,470)，100×30px，步骤 0-3 时蓝色可点击，步骤 4 时灰色禁用
- 教师操作流程：
  1. 初始展示正三棱柱线框，教师讲解几何结构
  2. 点击「下一步」→ 显示 A 微粒（顶点），教师讲解顶点微粒的共享规则
  3. 点击「下一步」→ 显示 B 微粒（棱中点），教师讲解棱中点微粒的共享规则
  4. 点击「下一步」→ 显示 C 微粒（体内），教师讲解体内微粒完全属于该晶胞
  5. 点击「下一步」→ 显示完整结构和数量统计，教师引导学生计算微粒数目之比
  6. 可随时点击「上一步」回退复习某类微粒的位置和共享规则

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    统计文字 (步骤 4 显示)                 │
  │                    A:6 B:9 C:1                          │
  │                                                         │
  │              A1                                         │
  │             /   \                                       │
  │           B2-----B3                                     │
  │          /  \   /  \                                    │
  │        A2----B1----A3                                   │
  │        |    / | \    |                                  │
  │        |   /  |  \   |                                  │
  │       B4    B6    B5                                   │
  │        |   /  |  \   |                                  │
  │        |  /   |   \  |                                  │
  │        A4----B9----A5                                   │
  │         \    / \    /                                   │
  │          \  /   \  /                                    │
  │           B7-----B8                                     │
  │            \     /                                      │
  │             \   /                                       │
  │              A6                                         │
  │                                                         │
  │                    ○ C1                                 │
  │                                                         │
  │  ● A    ● B    ○ C  (图例)                             │
  │                                                         │
  │  [◀ 上一步]              [下一步 ▶]                     │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep 记录当前步骤（0-4），updateScene() 函数根据 currentStep 更新显示
  2. 坐标计算：所有元素坐标硬编码在配置对象中，便于维护和修改
  3. 高亮效果：用 CSS class "highlight" 控制蓝色高亮，添加/移除 class 实现状态切换
  4. 事件绑定：按钮点击事件调用 nextStep()/prevStep() 更新 currentStep 并刷新场景
  5. 初始状态：页面加载时调用 updateScene() 显示步骤 0
  6. ID 命名规范：所有交互元素 ID 以"scene1-"为前缀（如 scene1-tri-top, scene1-btn-prev, scene1-mic-a1）
  7. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  8. 微粒分组：用 data-type 属性标记微粒类型（A/B/C），便于批量操作
  9. 标签显示控制：用 display 属性控制标签显示/隐藏，步骤 1-3 分别显示对应标签，步骤 4 显示所有标签
