场景导航：Scene 1

题目原文：

“长征”火箭发射使用的燃料是偏二甲肼(C₂H₈N₂)，并使用四氧化二氮作为氧化剂，这种组合的两大优点是既能在短时间内产生巨大能量将火箭送上太空，产物又不污染空气(产物都是空气成分)。某校外研究性学习小组拟将此原理设计为原电池，如图所示，结合学习过的电化学原理分析其设计方案，下列说法正确的是( )

A. B为正极
B. 从a口通入四氧化二氮气体
C. 从d口排出的是NO气体
D. A极发生的电极反应式：C₂H₈N₂－16e⁻＋8H₂O===CO₂＋N₂＋16H⁺

题目分析：

本题是一道电化学综合题，将火箭燃料反应设计为原电池，考查学生对原电池工作原理的掌握。关键信息：

  1. 燃料：偏二甲肼 (C₂H₈N₂) — 发生氧化反应
  2. 氧化剂：四氧化二氮 (N₂O₄) — 发生还原反应
  3. 电解质：H₂SO₄ 溶液（酸性环境）
  4. 产物是空气成分 — 应为 N₂、CO₂、H₂O 等

整体讲解思路：

  1. 首先引导学生观察原电池装置图，识别关键元素（电极、电解质、电子流向、进出口）
  2. 根据电子流动方向判断正负极
  3. 根据正负极判断燃料和氧化剂的通入位置
  4. 分析各选项的正确性

图示规划说明：

设计一个交互式原电池装置图，通过分步高亮和标注，帮助学生：

  • 步骤1：识别装置基本结构
  • 步骤2：观察电子流向，判断正负极
  • 步骤3：确定燃料和氧化剂的通入位置
  • 步骤4：分析电极反应和产物
步骤 1/6

教学说明：

本图示是讲解本题的核心可视化材料，教师应按以下步骤引导学生：

步骤0-1：装置识别与电子流向

首先让学生观察装置图的基本构成：两个电极、电解质溶液、外部电路（含灯泡）、气体进出口。然后聚焦电子流向——这是判断正负极的关键线索。

提问引导："电子从哪个电极流出？流向哪个电极？"

步骤2：正负极判断

根据原电池基本原理：

  • 电子流出的电极是负极（发生氧化反应，失去电子）
  • 电子流入的电极是正极（发生还原反应，得到电子）

图中 e⁻ 从 B 流向 A，因此：

  • B 是负极
  • A 是正极

此时可纠正选项 A 的错误："B为正极" — 错误！

步骤3：反应物分配

原电池中：

  • 负极发生氧化反应 → 通入燃料（被氧化）
  • 正极发生还原反应 → 通入氧化剂（被还原）

因此：

  • B 极（负极）从 b 口通入燃料 C₂H₈N₂
  • A 极（正极）从 a 口通入氧化剂 N₂O₄

此时可确认选项 B 正确："从a口通入四氧化二氮气体" — 正确！

步骤4：电极反应分析

负极（B 极）氧化反应：
C₂H₈N₂ + 4H₂O - 16e⁻ → 2CO₂ + N₂ + 16H⁺

正极（A 极）还原反应：
N₂O₄ + 8H⁺ + 8e⁻ → N₂ + 4H₂O

总反应：
C₂H₈N₂ + 2N₂O₄ → 2CO₂ + 3N₂ + 4H₂O

产物 CO₂、N₂、H₂O 均为空气成分，符合环保要求。

此时可分析选项 C 和 D 的错误：

  • C：d 口排出的是 N₂、CO₂、H₂O，不是 NO（NO 会污染空气）
  • D：A 极是正极，发生还原反应，选项给出的是氧化反应式，且反应物应该是 N₂O₄ 而非 C₂H₈N₂

步骤5：总结

正确答案：B

关键知识点回顾：

  1. 电子流向判断正负极
  2. 负极通燃料，正极通氧化剂
  3. 燃料电池产物应环保
