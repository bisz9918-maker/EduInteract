    **题目原文：**
    分子式为 C₅H₁₁Cl 的卤代烃，其分子中含有两个—CH₃，两个—CH₂—，一个 —CH— 和一个—Cl，它可能的结构有（ ）
    A. 2种  B. 3种  C. 4种  D. 5种

    **题目分析：**
    本题是有机化学同分异构体计数问题。关键约束条件：
    - 分子式：C₅H₁₁Cl（5 个碳、11 个氢、1 个氯）
    - 基团组成：2 个 —CH₃（末端甲基）、2 个 —CH₂—（亚甲基）、1 个 —CH—（次甲基，三连接）、1 个 —Cl

    **整体讲解思路：**
    1. 首先分析可能的碳骨架类型（直链戊烷 vs 支链异戊烷）
    2. 对每种骨架，系统分析氯原子在不同位置的取代
    3. 验证每种取代是否满足基团数量要求
    4. 汇总符合条件的结构数量

    **图示规划说明：**
    - Scene 1：展示两种碳骨架及其基团类型分布，分析氯代后的变化
    - Scene 2：汇总 4 种符合条件的结构，分类展示（直链 2 种 + 支链 2 种）
    </TEXT_1>

    <TEXT_2>
    **Scene 1 教学说明：**

    本图示用于引导学生系统分析碳骨架类型和氯代位置。教师应按以下步骤讲解：

    **步骤 0：碳骨架展示**
    首先展示两种可能的 C₅碳骨架：
    - 正戊烷：CH₃-CH₂-CH₂-CH₂-CH₃（直链，无分支）
    - 异戊烷：CH₃-CH(CH₃)-CH₂-CH₃（有 1 个分支点）

    **步骤 1：正戊烷氯代分析**
    正戊烷有 3 种不等效的氯代位置：
    1. 1-氯戊烷：Cl-CH₂-CH₂-CH₂-CH₂-CH₃
       - 基团：1 个 CH₃，4 个 CH₂，0 个 CH ✗（不符合）
    2. 2-氯戊烷：CH₃-CH(Cl)-CH₂-CH₂-CH₃
       - 基团：2 个 CH₃，2 个 CH₂，1 个 CH ✓（符合）
    3. 3-氯戊烷：CH₃-CH₂-CH(Cl)-CH₂-CH₃
       - 基团：2 个 CH₃，2 个 CH₂，1 个 CH ✓（符合）

    **步骤 2：异戊烷氯代分析**
    异戊烷有 4 种不等效的氯代位置：
    1. 1-氯 -2-甲基丁烷：Cl-CH₂-CH(CH₃)-CH₂-CH₃
       - 基团：2 个 CH₃，2 个 CH₂，1 个 CH ✓（符合）
    2. 2-氯 -2-甲基丁烷：CH₃-C(Cl)(CH₃)-CH₂-CH₃
       - 基团：2 个 CH₃，1 个 CH₂，0 个 CH，1 个 C ✗（不符合，出现季碳）
    3. 3-氯 -2-甲基丁烷：CH₃-CH(CH₃)-CH(Cl)-CH₃
       - 基团：3 个 CH₃，0 个 CH₂，2 个 CH ✗（不符合）
    4. 1-氯 -3-甲基丁烷：CH₃-CH(CH₃)-CH₂-CH₂Cl
       - 基团：2 个 CH₃，2 个 CH₂，1 个 CH ✓（符合）

    **步骤 3：汇总**
    符合条件的结构共 4 种：
    - 直链：2-氯戊烷、3-氯戊烷
    - 支链：1-氯 -2-甲基丁烷、1-氯 -3-甲基丁烷

    **关键教学点：**
    - 强调"不等效位置"的概念（对称位置只算 1 种）
    - 氯原子取代会改变碳的类型（CH₃→CH₂Cl，CH₂→CHCl，CH→CCl）
    - 系统枚举法：先确定骨架，再枚举取代位置，最后验证条件
    </TEXT_2>

    **总结与课堂讲解建议：**

    **完整解答：**
    分子式为 C₅H₁₁Cl 且满足基团组成要求（2 个 —CH₃，2 个 —CH₂—，1 个 —CH—，1 个 —Cl）的结构共有 **4 种**，答案为 **C**。

    **4 种结构列表：**
    1. 2-氯戊烷：CH₃-CH(Cl)-CH₂-CH₂-CH₃
    2. 3-氯戊烷：CH₃-CH₂-CH(Cl)-CH₂-CH₃
    3. 1-氯 -2-甲基丁烷：Cl-CH₂-CH(CH₃)-CH₂-CH₃
    4. 1-氯 -3-甲基丁烷：CH₃-CH(CH₃)-CH₂-CH₂Cl

    **课堂讲解建议：**
    1. 使用 Scene 1 引导学生理解系统枚举法：先骨架后取代
    2. 强调氯原子取代对碳类型的影响（CH₃→CH₂Cl 等）
    3. 使用 Scene 2 展示最终答案，帮助学生建立完整认知
    4. 可让学生尝试画出每种结构，验证基团数量
    5. 拓展思考：如果题目要求含 1 个 —CH₃，其他条件不变，有多少种结构？

    **易错点提醒：**
    - 对称位置只算 1 种（如正戊烷的 1 位和 5 位等效）
    - 氯代后碳类型会改变（CH→CCl 不再是 CH）
    - 支链结构的编号方向会影响命名，但结构本身唯一
