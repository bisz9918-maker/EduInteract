[图示主题与整合说明]
- 本图示主题：C₅H₁₁Cl 卤代烃同分异构体结构分析
- 整合的步骤/概念：
  1. 展示两种碳骨架类型（正戊烷直链、异戊烷支链）
  2. 分析每种骨架上氯原子的可能取代位置
  3. 验证每种氯代产物是否满足题目条件（两个—CH₃、两个—CH₂—、一个—CH—、一个—Cl）
  4. 汇总符合条件的结构数量
- 教学价值：教师可逐步引导学生理解碳骨架类型对同分异构体数量的影响，通过可视化方式验证每种结构是否满足基团数量要求，帮助学生掌握有机化学中同分异构体的系统分析方法

- 氯原子标记：红色"Cl"标签，加粗，出现在被取代的碳原子旁

- 正戊烷骨架：蓝色高亮 #1565c0
- 异戊烷骨架：红色高亮 #c62828
- 符合条件的氯代位置：绿色高亮 #2e7d32
- 不符合条件的位置：灰色虚线 #888888 标记

[分步序列]
- 步骤 0（初始状态）：
  - 显示标题"碳骨架类型与氯代位置分析"
  - 显示正戊烷骨架（C1-C5 五个碳原子，蓝色边框）
  - 显示异戊烷骨架（C1-C5 五个碳原子，红色边框）
  - 显示所有碳原子编号和基团类型标签
  - 不显示氯原子标记和符合/不符合标记
  - 步骤指示器显示"步骤 1/4"

- 步骤 1（正戊烷氯代位置分析）：
  - 正戊烷骨架保持显示
  - 依次在 C1、C2、C3 位置显示红色"Cl"标记（C4 与 C2 对称，C5 与 C1 对称）
  - C1 氯代（1-氯戊烷）：显示✗（不符合，会产生 3 个 CH₃）
  - C2 氯代（2-氯戊烷）：显示✓（符合，两个 CH₃、两个 CH₂、一个 CH、一个 Cl）
  - C3 氯代（3-氯戊烷）：显示✓（符合，两个 CH₃、两个 CH₂、一个 CH、一个 Cl）
  - 异戊烷骨架保持初始状态（无 Cl 标记）
  - 步骤指示器显示"步骤 2/4"

- 步骤 2（异戊烷氯代位置分析）：
  - 正戊烷骨架保持步骤 1 状态
  - 异戊烷骨架依次在 C1、C2、C3、C4、C5 位置显示红色"Cl"标记
  - C1 氯代（1-氯 -3-甲基丁烷）：显示✓（符合）
  - C2 氯代（2-氯 -3-甲基丁烷）：显示✗（不符合，会产生 3 个 CH₃）
  - C3 氯代（3-氯 -2-甲基丁烷）：显示✗（不符合，会产生 3 个 CH₃）
  - C4 氯代（1-氯 -2-甲基丁烷）：显示✓（符合）
  - C5（支链）氯代：与 C1 氯代结构相同，不计为新结构
  - 步骤指示器显示"步骤 3/4"

- 步骤 3（符合条件的结构汇总）：
  - 所有骨架和 Cl 标记保持显示
  - 高亮显示所有✓标记的结构（绿色边框）
  - 在画布右侧或底部显示汇总框：
    "符合条件的结构共 4 种：
     1. 2-氯戊烷
     2. 3-氯戊烷
     3. 1-氯 -3-甲基丁烷
     4. 1-氯 -2-甲基丁烷"
  - 步骤指示器显示"步骤 4/4"
  - 下一步按钮变灰不可点击

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮（scene1-btn-prev）：位于控件栏左侧，点击返回上一步骤，步骤 1 时变灰不可点击
  - 下一步按钮（scene1-btn-next）：位于控件栏右侧，点击进入下一步骤，步骤 4 时变灰不可点击
  - 步骤指示器：位于控件栏上方，显示当前步骤/总步骤
- 教师操作流程：
  1. 初始展示两种碳骨架，让学生识别正戊烷和异戊烷的区别
  2. 点击下一步，分析正戊烷各位置的氯代产物，引导学生判断哪些符合条件
  3. 点击下一步，分析异戊烷各位置的氯代产物，注意对称性和支链影响
  4. 点击下一步，汇总所有符合条件的结构，得出答案 C. 4 种

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无需外部库，几何图形简单，交互逻辑清晰）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    碳骨架类型与氯代位置分析              │  y=15
  ├─────────────────────────────────────────────────────────┤
  │  正戊烷骨架 C-C-C-C-C                                   │  y=40
  │    ○────○────○────○────○                                │  y=120
  │    ①    ②    ③    ④    ⑤                               │  y=145
  │   CH₃  CH₂  CH₂  CH₂  CH₃                                │  y=165
  ├─────────────────────────────────────────────────────────┤
  │  异戊烷骨架（带支链）                                    │  y=270
  │          ○⑤                                             │  y=280
  │          │                                               │
  │    ○①───○②───○③───○④                                   │  y=340
  │    ①    ②    ③    ④                                    │  y=365
  │   CH₃   CH  CH₂  CH₃                                    │  y=385
  ├─────────────────────────────────────────────────────────┤
  │                    步骤 X/4                              │  y=420
  │        [◀ 上一步]          [下一步 ▶]                    │  y=455
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量（0-3）跟踪当前步骤，每个步骤对应不同的元素显示状态
  2. 坐标计算：所有元素使用绝对坐标，碳原子圆圈中心点作为基准，键线根据相邻碳原子坐标计算
  3. 动画曲线：步骤切换时使用简单的淡入淡出效果（opacity 从 0 到 1，过渡时间 0.3s）
  4. 事件绑定：按钮点击事件绑定到 scene1-btn-prev 和 scene1-btn-next，更新 currentStep 后重新渲染
  5. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-carbon-1、scene1-cl-2、scene1-check-1 等）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染
  7. 对称性处理：正戊烷 C4 与 C2 对称、C5 与 C1 对称，异戊烷 C5 支链与 C1 氯代结构相同，这些在分析时需注意去重
  8. 基团类型验证逻辑：每种氯代后重新计算 CH₃、CH₂、CH 数量，与题目要求（2 个 CH₃、2 个 CH₂、1 个 CH）比对
