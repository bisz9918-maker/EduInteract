[图示主题与整合说明]
- 本图示主题：C₅H₁₁Cl 符合条件的 4 种同分异构体结构汇总
- 整合的步骤/概念：展示满足"两个—CH₃、两个—CH₂—、一个—CH—、一个—Cl"条件的 4 种卤代烃结构，按直链型和支链型分类对比
- 教学价值：帮助学生理解同分异构体的结构特征，通过分类对比掌握直链与支链结构的差异，强化对分子式与结构式关系的理解

[交互方案]
- 交互类型：多状态切换（3 个按钮）
- 控件说明：
  - 按钮 1 "显示全部"：id=scene2-btn-all，位置 (150,470)，显示全部 4 种结构
  - 按钮 2 "仅直链"：id=scene2-btn-chain，位置 (350,470)，仅显示直链型结构（结构 1、2）
  - 按钮 3 "仅支链"：id=scene2-btn-branch，位置 (550,470)，仅显示支链型结构（结构 3、4）
- 教师操作流程：
  1. 初始点击"显示全部"，向学生展示 4 种符合条件的结构
  2. 点击"仅直链"，突出显示直链型结构，讲解直链卤代烃的特征
  3. 点击"仅支链"，突出显示支链型结构，讲解支链卤代烃的特征
  4. 可反复切换，对比直链与支链结构的差异

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │                    直链型（2 种）        支链型（2 种）         │
  │  ┌─────────────────────────┐  ┌─────────────────────────┐  │
  │  │    结构 1    结构 2       │  │    结构 3    结构 4       │  │
  │  │   (2-氯戊烷)(3-氯戊烷)  │  │(1-氯 -2-甲基)(1-氯 -3-甲基)│  │
  │  │                         │  │   丁烷      丁烷        │  │
  │  └─────────────────────────┘  └─────────────────────────┘  │
  │                                                             │
  │              基团：2×CH₃, 2×CH₂, 1×CH, 1×Cl                │
  │        [显示全部]        [仅直链]        [仅支链]           │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentState 记录当前状态（0=全部，1=直链，2=支链）
  2. 元素分组：用 SVG 的<g>元素将每种结构及其标签分组，id 为 scene2-struct-1/2/3/4
  3. 透明度切换：通过修改 group 的 opacity 属性实现显示/隐藏（opacity=1 或 0.2）
  4. 按钮高亮：当前选中按钮添加 active 类，背景色加深
  5. ID 命名规范：所有元素 ID 以 scene2- 为前缀（如 scene2-struct-1, scene2-btn-all）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
- 颜色规格：
  - 背景：#ffffff
  - 碳链骨架：#000000，2px 实线
  - 直链高亮边框：#1565c0
  - 支链高亮边框：#c62828
  - Cl 原子及标签：#2e7d32（键）和 #c62828（文字）
  - 分类框虚线：#888888，填充透明度 15%
  - 按钮：默认 #e0e0e0，hover #bdbdbd，active #1565c0（直链）或 #c62828（支链）
