[图示主题与整合说明]
- 本图示主题：密闭容器活塞系统状态变化全过程（化学气体反应与体积变化）
- 整合内容：初始状态（体积1:3）→ 点燃反应（活塞左弹）→ 恢复温度（水蒸气凝结）→ 最终状态（体积2:2）
- 教学价值：教师可按教学节奏逐步推进，帮助学生理解：
  1. 初始体积比例关系（1:3）
  2. 点燃后气体物质的量减少导致压强降低，活塞左弹
  3. 水蒸气凝结为液体后，气体体积进一步减少
  4. 最终活塞停在中央，左右体积相等（2:2）

[分步序列]
步骤0（初始状态）：
- 显示容器边框（黑色实线）
- 活塞位于x=250位置（1/4处）
- 左侧区域填充淡蓝色，标注"空气"
- 右侧区域填充淡蓝色，标注"O₂、H₂混合气"
- 底部刻度：0（左端）、1（活塞位置）、4（右端）
- 体积标注：左侧"体积1"，右侧"体积3"
- 活塞下方标注"活塞"
- 等待教师点击"下一步"

步骤1（点燃反应）：
- 右侧区域边框变为红色粗线（stroke="#c62828", stroke-width=3），表示点燃
- 反应式"2H₂ + O₂ → 2H₂O"显示在容器上方（红色文字）
- 活塞向左移动至x=200位置（左弹效果，动画过渡）
- 右侧区域颜色加深（opacity=0.4），表示反应进行中
- 教师可点击"上一步"回退或"下一步"继续

步骤2（冷却凝结）：
- 右侧区域红色边框恢复为黑色
- 反应式文字消失
- 活塞开始向右滑动（从x=200向x=400移动，动画过渡）
- 显示水蒸气凝结示意：右侧区域出现小水滴图标（蓝色小圆点）
- 教师可点击"上一步"回退或"下一步"继续

步骤3（最终状态）：
- 活塞停在x=400位置（容器正中央）
- 左右区域各填充淡蓝色（opacity=0.2）
- 活塞边框变为绿色粗线（stroke="#2e7d32", stroke-width=3）
- 中央位置上方标注"中央"（绿色文字）
- 底部刻度更新：0、2（中央）、4
- 体积标注更新：左侧"体积2"，右侧"体积2"
- 标注"体积相等"显示在容器下方中央
- 展示最终结论：左右体积比为2:2=1:1

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：位于(250, 460)，100×30px，点击返回上一步状态，初始步骤0时禁用
  - "下一步 ▶"按钮：位于(450, 460)，100×30px，点击进入下一步状态，最终步骤3时禁用
- 教师操作流程：
  1. 图示加载后显示初始状态（步骤0），教师讲解初始体积比例1:3
  2. 点击"下一步"进入步骤1，讲解点燃反应及活塞左弹原因
  3. 点击"下一步"进入步骤2，讲解水蒸气凝结过程
  4. 点击"下一步"进入步骤3，讲解最终体积相等结论
  5. 如需复习某一步骤，可点击"上一步"回退

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    [图示区 800×500]                     │
  │                                                         │
  │         反应式：2H₂ + O₂ → 2H₂O                        │
  │              ┌─────────────────────────────┐           │
  │              │      空气    │  O₂、H₂混合气 │           │
  │              │             │               │           │
  │              │             │               │           │
  │              └─────────────────────────────┘           │
  │                0    1      2              4            │
  │                      活塞                              │
  │                                                         │
  │              [◀ 上一步]    [下一步 ▶]                   │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 currentStep（0-3）记录当前步骤
  2. 坐标计算：活塞位置根据步骤动态计算（步骤0: x=250, 步骤1: x=200, 步骤2: 动画过渡, 步骤3: x=400）
  3. 动画曲线：使用 requestAnimationFrame 实现平滑过渡（活塞移动、颜色渐变）
  4. 事件绑定：按钮点击事件监听，更新状态并重绘
  5. ID 命名规范：所有元素 ID 以"scene1-"为前缀（如 scene1-container, scene1-piston, scene1-btn-prev, scene1-btn-next）
  6. JS 隔离：所有代码包在 IIFE (function() { ... })() 中，避免全局污染
  7. 元素显示/隐藏：使用 display 或 opacity 控制各步骤元素的可见性
  8. 活塞移动动画：使用 CSS transition 或 JS 动画实现平滑移动
