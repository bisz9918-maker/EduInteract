[交互方案]
- 交互类型：多状态切换（2 个按钮）
- 控件说明：
  - 按钮 1（scene2-btn-case1）：位置 (200,380)，点击显示情况 1 计算过程
  - 按钮 2（scene2-btn-case2）：位置 (450,380)，点击显示情况 2 计算过程
- 教师操作流程：
  1. 初始状态讲解题目条件：右边 H₂+O₂总体积=3，反应后剩余=1
  2. 点击"情况 1：O₂完全反应"按钮，讲解 O₂耗尽时的计算逻辑
  3. 引导学生观察：消耗 3 体积气体（2H₂+1O₂），剩余 H₂=1
  4. 点击"情况 2：H₂完全反应"按钮，讲解 H₂耗尽时的计算逻辑
  5. 引导学生观察：消耗 3 体积气体，剩余 O₂=1/3
  6. 总结：两种情况对应选项③和④，答案选 C

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何和文本，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    2H₂ + O₂ → 2H₂O(l)                   │  y=30
  ├─────────────────────────────────────────────────────────┤
  │  情况 1：O₂完全反应          │        情况 2：H₂完全反应   │  y=80
  ├─────────────────────────────┼───────────────────────────┤
  │      初始量 | 消耗量 | 剩余量                            │  y=110
  ├─────────────────────────────┼───────────────────────────┤
  │  V(H₂)=7/3│4/3│1  │        │  V(H₂)=4/3│4/3│0           │  y=140
  │  V(O₂)=2/3│2/3│0  │        │  V(O₂)=5/3│2/3│1/3         │  y=170
  ├─────────────────────────────┼───────────────────────────┤
  │  H₂:O₂ = 7:2 (蓝框)         │  H₂:O₂ = 4:5 (红框)        │  y=250
  ├─────────────────────────────────────────────────────────┤
  │                    答案：C．③④ (绿)                      │  y=320
  ├─────────────────────────────────────────────────────────┤
  │  [情况 1：O₂完全反应]        │  [情况 2：H₂完全反应]      │  y=380
  ├─────────────────────────────────────────────────────────┤
  │  已知：右边 H₂+O₂总体积=3，反应后剩余气体体积=1          │  y=440
  └─────────────────────────────────────────────────────────┘
  ```

- 关键实现要点：
  1. 状态机设计：使用变量 currentCase 记录当前状态（0=初始，1=情况 1，2=情况 2）
  2. 元素显示/隐藏：通过 setAttribute('display', 'none'/'block') 控制 SVG 元素可见性
  3. 按钮高亮：切换时添加/移除 class 'active'，配合 CSS 边框颜色变化
  4. 坐标计算：所有元素使用绝对坐标，确保布局精确
  5. 事件绑定：使用 addEventListener 绑定按钮点击事件

- ID 命名规范：
  - 所有交互元素 ID 以 scene2- 为前缀
  - scene2-reaction（反应方程式）
  - scene2-case1-title（情况 1 标题）
  - scene2-case2-title（情况 2 标题）
  - scene2-case1-data（情况 1 数据行组）
  - scene2-case2-data（情况 2 数据行组）
  - scene2-case1-result（情况 1 结果框）
  - scene2-case2-result（情况 2 结果框）
  - scene2-case1-result-text（情况 1 结果文本）
  - scene2-case2-result-text（情况 2 结果文本）
  - scene2-btn-case1（按钮 1）
  - scene2-btn-case2（按钮 2）
  - scene2-answer（答案标注）
  - scene2-condition（条件说明框）

- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染
