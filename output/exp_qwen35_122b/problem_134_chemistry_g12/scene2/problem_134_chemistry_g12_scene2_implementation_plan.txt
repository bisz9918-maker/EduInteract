[图示主题与整合说明]
- 本图示主题：各选项判断依据分析（有机物烃A、B、C的结构化学性质）

[分步序列]
- 步骤0（初始状态）：
  - 显示标题"三种分子结构"
  - 显示分子A（正四面体）、分子B（三棱柱）、分子C（立方烷）
  - 显示各分子标签"A"、"B"、"C"和分子式"C₄H₄"、"C₆H₆"、"C₈H₈"
  - 结论区空白

- 步骤1（分析A选项）：
  - 标题变为"选项A分析"
  - 仅显示分子A（正四面体），分子B和C隐藏
  - 在分子A的两个顶点上显示高亮圆点（红色填充，透明度20%）
  - 结论区显示："A的二氯代物只有1种（任意两顶点等价）"，文字#c62828
  - 标注"选项A错误"

- 步骤2（分析B选项）：
  - 标题变为"选项B分析"
  - 显示分子B（三棱柱）
  - 在分子B旁显示红叉标记
  - 显示分子式推导："碳原子数=6，氢原子数=6"
  - 显示正确分子式"C₆H₆"，错误分子式"C₆H₁₂"用#c62828并划掉
  - 结论区显示："B的分子式为C₆H₆，不是C₆H₁₂"，文字#c62828
  - 标注"选项B错误"

- 步骤3（分析C选项）：
  - 标题变为"选项C分析"
  - 显示分子C（立方烷）和苯乙烯结构并列
  - 在苯乙烯的碳碳双键处显示红色粗线高亮
  - 显示标注"分子式均为C₈H₈"
  - 显示标注"苯乙烯含碳碳双键，可使酸性KMnO₄褪色"
  - 结论区显示："C选项正确"，文字#2e7d32
  - 标注"选项C正确"

- 步骤4（分析D选项）：
  - 标题变为"选项D分析"
  - 显示分子A、B、C并列
  - 在每个分子下方显示最简式标签"CH"
  - 显示标注"A、B、C的最简式均为CH"
  - 结论区显示："A、B、C最简式相同，都是CH"，文字#888888
  - 标注"选项D错误（不是只有C的最简式为CH）"

- 步骤5（总结正确答案）：
  - 标题变为"正确答案"
  - 显示分子A、B、C并列
  - 在中央显示绿色边框框，内有文字"C"
  - 结论区显示："正确答案：C"，文字#2e7d32，字体24px加粗

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 按钮"◀ 上一步"：位置(300,450)，作用：返回上一个步骤，步骤0时禁用
  - 按钮"下一步 ▶"：位置(450,450)，作用：进入下一个步骤，步骤5时禁用
- 教师操作流程：
  1. 初始展示三种分子结构，让学生观察
  2. 点击"下一步"进入A选项分析，讲解正四面体二氯代物
  3. 点击"下一步"进入B选项分析，讲解分子式推导
  4. 点击"下一步"进入C选项分析，讲解同分异构体和芳香烃性质
  5. 点击"下一步"进入D选项分析，讲解最简式概念
  6. 点击"下一步"显示正确答案，总结全题
  7. 可随时点击"上一步"回退复习某个选项

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │  标题区 (300,25) "选项X分析"                            │
  │                                                         │
  │  C₄H₄        C₆H₆        C₈H₈                          │
  │    ▲          ▲          ▲                             │
  │    │          │          │                             │
  │  [正四面体]  [三棱柱]  [立方烷/苯乙烯]                 │
  │    │          │          │                             │
  │    A          B          C                             │
  │                                                         │
  │  结论区 (300,350) "判断结论"                           │
  │                                                         │
  │  ┌─────────────────────────────────────────────────┐   │
  │  │  ◀ 上一步          下一步 ▶                     │   │
  │  └─────────────────────────────────────────────────┘   │
  └─────────────────────────────────────────────────────────┘
  ```

- 关键实现要点：
  1. 状态机设计：用变量 currentStep 记录当前步骤（0-5），用 switch-case 控制各步骤显示逻辑
  2. 坐标计算：所有元素坐标硬编码，确保精确到像素级
  3. 元素显示/隐藏：用 CSS display 属性控制，步骤切换时批量更新
  4. 按钮状态：步骤0时禁用"上一步"，步骤5时禁用"下一步"
  5. 动画效果：步骤切换时可添加淡入淡出效果（opacity 过渡）
  6. 事件绑定：按钮点击事件绑定到 currentStep 更新和视图刷新函数

- ID 命名规范：
  - 所有交互元素 ID 以 scene2- 为前缀
  - 分子元素：scene2-mol-a、scene2-mol-b、scene2-mol-c、scene2-mol-styrene
  - 标签元素：scene2-label-a、scene2-label-b、scene2-label-c
  - 分子式元素：scene2-formula-a、scene2-formula-b、scene2-formula-c
  - 标题元素：scene2-title
  - 结论元素：scene2-conclusion
  - 按钮元素：scene2-btn-prev、scene2-btn-next
  - 高亮元素：scene2-highlight-vertex1、scene2-highlight-vertex2
  - 标记元素：scene2-mark-cross、scene2-mark-check、scene2-mark-correct-box

- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染
