[分步序列]
- 步骤0（初始状态）：显示完整实验装置全貌
  - 显示：电池组、灯泡、烧杯、溶液区域、两个电极、三条导线
  - 显示标签：电池、灯泡、电极、待测溶液
  - 灯泡状态：暗（#ffeb3b 10%透明度，表示导电性弱）
  - 等待教师点击"下一步"

- 步骤1：标注电路连接
  - 新增：三条导线高亮（#000000 加粗至3px，短暂闪烁效果）
  - 显示电路说明文字："电路：电池→灯泡→电极→溶液→电极→电池"
  - 位置：(300,150)，标签偏移下方
  - 灯泡状态：保持暗

- 步骤2：标注溶液与电极
  - 新增：电极插入溶液部分高亮（#2196f3 30%透明度覆盖）
  - 显示说明文字："电极插入待测溶液，形成闭合回路"
  - 位置：(550,200)，标签偏移上方
  - 灯泡状态：根据溶液导电性变化（本步骤展示弱导电性状态）

- 步骤3：灯泡亮度与导电性关系
  - 灯泡状态：根据示例溶液导电性强弱变化
  - 显示导电性强说明："导电性强 → 灯泡亮（离子浓度高）"
  - 显示导电性弱说明："导电性弱 → 灯泡暗（离子浓度低）"
  - 位置：(50,450)和(200,450)

- 结论步骤：导电性强弱判断标准
  - 灯泡恢复暗状态（默认）
  - 显示总结文字："溶液导电性取决于自由移动离子的浓度和电荷"
  - 位置：(300,400)，居中显示
  - 可点击"上一步"回顾各步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（矩形、椭圆、路径），无需复杂图表库，原生实现轻量高效
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：

  └─────────────────────────────────────────────────────────────┘

- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-4) 跟踪当前步骤，每一步对应不同的元素可见性配置
  2. 坐标计算：所有元素使用绝对定位，通过 SVG transform 属性精确控制位置
  3. 动画曲线：导线高亮使用 CSS transition，透明度从 1→0.3→1 实现闪烁效果
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 renderStep() 重绘
  5. 灯泡发光：通过改变椭圆填充透明度实现，导电性强时透明度 30%，弱时 10%
  6. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-battery、scene1-bulb、scene1-beaker）
  7. JS 隔离：所有代码包裹在 IIFE (function() { ... })() 中，避免全局污染
  8. 步骤指示器：动态更新文本内容，显示当前步骤/总步骤
