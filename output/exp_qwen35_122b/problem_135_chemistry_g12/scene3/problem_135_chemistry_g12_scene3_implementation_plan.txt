[分步序列]
采用多状态切换模式，通过按钮切换显示不同选项的详细说明：

- 初始状态（步骤 0）：
  - 显示所有四个选项的曲线图（A 绿色高亮，B/C/D 黑色）
  - 显示所有选项标签和简短说明
  - 显示结论区"正确答案：A"
  - 按钮 A 处于激活状态（高亮边框）

- 状态 A（点击按钮 A）：
  - 选项 A 曲线高亮（线宽 3px，绿色）
  - 选项 A 说明文字放大显示："CH₃COOH + NH₃·H₂O → CH₃COONH₄"
  - 离子浓度变化箭头：弱电解质→强电解质→稀释效应
  - 其他选项曲线变淡（透明度 50%）

- 状态 B（点击按钮 B）：
  - 选项 B 曲线高亮（线宽 3px，黑色）
  - 选项 B 说明文字放大显示："AgNO₃ + HCl → AgCl↓ + HNO₃"
  - 沉淀符号↓红色高亮
  - 离子浓度：沉淀生成导致离子减少
  - 其他选项曲线变淡

- 状态 C（点击按钮 C）：
  - 选项 C 曲线高亮（线宽 3px，黑色）
  - 选项 C 说明文字放大显示："HCl + NaCl → 混合溶液"
  - 离子浓度：强电解质混合，离子持续增加
  - 其他选项曲线变淡

- 状态 D（点击按钮 D）：
  - 选项 D 曲线高亮（线宽 3px，黑色）
  - 选项 D 说明文字放大显示："H₂SO₄ + BaCl₂ → BaSO₄↓ + 2HCl"
  - 沉淀符号↓红色高亮
  - 离子浓度：沉淀生成导致离子减少
  - 其他选项曲线变淡

- 状态总结（点击按钮总结）：
  - 所有曲线恢复正常显示
  - 结论区放大并闪烁高亮
  - 显示完整对比表格：
    | 选项 | 反应类型 | 离子变化 | 导电性趋势 |
    | A | 弱→强电解质 | 先增后减 | 先增大后减弱 ✓ |
    | B | 沉淀反应 | 持续减少 | 先减弱 |
    | C | 混合 | 持续增加 | 持续增强 |
    | D | 沉淀反应 | 先减后稳 | 先减弱 |

  2. 点击按钮 A，详细讲解醋酸与氨水反应的本质（弱电解质生成强电解质）
  3. 依次点击 B/C/D，对比分析其他选项为什么不符合题意
  4. 最后点击总结按钮，展示完整对比表格，强化记忆

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无需额外库，图形简单）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │                    四个选项导电性变化对比                     │  y=15
  ├─────────────────────────────────────────────────────────────┤
  │  A 曲线图    B 曲线图    C 曲线图    D 曲线图                  │  y=100-350
  │  (绿色)      (黑)       (黑)       (黑)                      │
  │                                                              │
  │  弱→强→稀释  沉淀↓     混合       沉淀↓                      │  y=335
  ├─────────────────────────────────────────────────────────────┤
  │              正确答案：A                                     │  y=380-420
  ├─────────────────────────────────────────────────────────────┤
  │  [A]  [B]  [C]  [D]  [总结]                                  │  y=450
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentMode 记录当前状态 ('A'/'B'/'C'/'D'/'summary')
  2. 曲线绘制：使用 SVG path 元素，平滑曲线用 quadraticCurveTo 或 bezierCurveTo
  3. 高亮效果：通过修改 stroke-width 和 stroke 颜色实现
  4. 淡出效果：通过修改 opacity 属性实现（其他选项设为 0.5）
  5. 按钮激活状态：添加/移除 'active' class，改变边框颜色
  6. 结论区闪烁：用 setInterval 实现淡入淡出动画
- ID 命名规范：所有元素 ID 以 scene3- 为前缀
  - 曲线：scene3-curve-A, scene3-curve-B, scene3-curve-C, scene3-curve-D
  - 按钮：scene3-btn-A, scene3-btn-B, scene3-btn-C, scene3-btn-D, scene3-btn-summary
  - 说明文字：scene3-desc-A, scene3-desc-B, scene3-desc-C, scene3-desc-D
  - 结论区：scene3-conclusion
- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
