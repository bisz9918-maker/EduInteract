[分步序列]
步骤 0（初始状态）：
- 显示：完整分子结构（氢原子球 +10 个碳原子球 + 原子③球）
- 显示：所有化学键线段（单线表示）
- 显示：标签"氢原子"、"碳原子"、"①"、"②"、"③"
- 隐藏：键计数标签、键类型标签
- 目的：展示分子结构全貌，让学生观察整体结构

步骤 1（标注原子类型）：
- 显示：同步骤 0
- 新增：无（此步骤主要确认原子识别）
- 高亮：氢原子球和碳原子球用蓝色边框闪烁 1 次
- 目的：确认学生能识别氢原子（白色）和碳原子（黑色）

步骤 2（分析碳原子价键规律）：
- 显示：同步骤 1
- 新增：在每个碳原子（C1-C10）上方显示已形成的键数标签
  - C1：显示"3"（连接 H、C2、下方一个键）
  - C2-C9：显示"2"（左右各一个键，下方一个键，共 3 个，但图示中只有左右键，实际显示左右键数）
  - 修正：根据图示，每个碳原子只显示左右连接的键，C1 连接 H 和 C2，显示"2"；C2-C9 连接左右碳，显示"2"；C10 连接 C9 和原子③，显示"2"
  - 实际键计数：C1=2（左 H+ 右 C2），C2-C9=2（左 + 右），C10=2（左 C9+ 右③）
- 显示：灰色虚线从碳原子向下延伸，表示潜在的成键位置
- 目的：引导学生观察碳原子成键数，引出碳原子四价原则

步骤 3（推导①处化学键类型）：
- 显示：同步骤 2
- 高亮：键 6-7（①处）用蓝色 #1565c0 加粗显示（stroke-width=4）
- 新增：在①下方显示"C-C 双键"标签（绿色 #2e7d32）
- 分析：C6 已连接 C5 和 C7，需要 4 个键，故①处为双键
- 目的：展示如何根据碳原子四价原则推导化学键类型

步骤 4（推导②处化学键类型）：
- 显示：同步骤 3
- 高亮：键 9-10（②处）用蓝色 #1565c0 加粗显示（stroke-width=4）
- ①处键保持蓝色高亮
- 新增：在②下方显示"C-C 单键"标签（绿色 #2e7d32）
- 分析：C9 已连接 C8 和 C10，C10 已连接 C9 和原子③，②处为单键
- 目的：继续展示化学键类型推导

步骤 5（分析③处原子特征）：
- 显示：同步骤 4
- 高亮：原子③球用红色 #c62828 边框闪烁
- 新增：在③旁边显示"一价原子"标签（红色 #c62828）
- 分析：原子③只与 C10 形成一个键，为一价原子，可能是 H、F、Cl 等
- 目的：分析末端原子的价键特征

结论（选项判断）：
- 显示：同步骤 5
- 高亮：选项 B"①处的化学键表示碳碳双键"用绿色 #2e7d32 边框高亮
- 显示：在图示上方显示结论"正确答案：B"
- 显示：其他选项 A、C、D 用红色 #c62828 标记为错误
- 目的：总结推导结果，确认正确选项

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮（scene1-prev-btn）：位于控件栏左侧，点击返回上一步，步骤 0 时禁用
  - 下一步按钮（scene1-next-btn）：位于控件栏右侧，点击进入下一步，步骤 5 后变为"完成"
- 教师操作流程：
  1. 点击"下一步"展示分子结构全貌（步骤 0）
  2. 点击"下一步"确认原子类型识别（步骤 1）
  3. 点击"下一步"展示碳原子键计数（步骤 2），讲解碳原子四价原则
  4. 点击"下一步"推导①处键类型（步骤 3），引导学生理解推导逻辑
  5. 点击"下一步"推导②处键类型（步骤 4）
  6. 点击"下一步"分析③处原子特征（步骤 5）
  7. 点击"下一步"展示结论和正确选项（结论）
  8. 可随时点击"上一步"回退复习

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：分子结构为简单几何图形（圆形、线段、文本），原生 SVG 即可实现，无需引入重型库
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：

  │                    800px 宽度                           │

- 关键实现要点：
  1. 状态机设计：使用变量 currentStep 记录当前步骤（0-5，结论为 6）
  2. 坐标计算：所有元素坐标按布局坐标表精确实现
  3. 动画曲线：高亮效果使用 CSS transition，stroke-width 从 2 过渡到 4
  4. 事件绑定：按钮点击事件绑定到 scene1-prev-btn 和 scene1-next-btn
  5. 元素显示控制：使用 display:none/block 或 opacity 控制元素显示/隐藏
  6. 高亮效果：使用 CSS class 切换实现颜色和高亮状态

- ID 命名规范：
  - 所有交互元素 ID 以 scene1- 为前缀
  - 球体：scene1-ball-H, scene1-ball-C1~C10, scene1-ball-3
  - 键线段：scene1-bond-0~10
  - 标签：scene1-label-H, scene1-label-C, scene1-label-1, scene1-label-2, scene1-label-3
  - 键计数标签：scene1-count-C1~C10
  - 键类型标签：scene1-bond-type-1, scene1-bond-type-2
  - 按钮：scene1-prev-btn, scene1-next-btn

- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染

- 状态切换逻辑：
  ```javascript
  function updateScene(step) {
    // 根据 step 显示/隐藏相应元素
    switch(step) {
      case 0:
        // 显示基础结构
        break;
      case 1:
        // 高亮原子识别
        break;
      case 2:
        // 显示键计数
        document.getElementById('scene1-counts').style.display = 'block';
        break;
      case 3:
        // 高亮①键，显示键类型
        break;
      case 4:
        // 高亮②键，显示键类型
        break;
      case 5:
        // 高亮原子③
        break;
      case 6:
        // 显示结论
        break;
    }
    // 更新按钮状态
    document.getElementById('scene1-prev-btn').disabled = (step === 0);
    document.getElementById('scene1-next-btn').textContent = (step === 6) ? '完成' : '下一步 ▶';
  }
  ```
