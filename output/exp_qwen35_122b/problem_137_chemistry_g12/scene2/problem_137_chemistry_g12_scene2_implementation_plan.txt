[图示主题与整合说明]
- 本图示主题：手性碳原子的识别与判断
- 整合内容：手性碳定义说明、分子中手性碳的定位、手性碳的判断标准
- 教学价值：教师可引导学生从手性碳定义出发，逐步在复杂分子中识别 sp³ 碳原子，验证其连接的四个基团是否不同，最终确认手性碳。此图示帮助学生建立从抽象定义到具体应用的认知桥梁。

[分步序列]
- 步骤 0（初始状态）：
  - 显示左侧手性碳定义示意图（中心碳 C* 连接 R₁/R₂/R₃/R₄ 四个不同基团）
  - 显示右侧分子骨架，三个候选碳 C1/C2/C3 均以灰色显示
  - 判断结果框显示："手性碳定义：中心 sp³ 碳原子连接 4 个不同的取代基"
  - 步骤指示器显示："步骤 1 / 4"

- 步骤 1（候选碳原子展示）：
  - 左侧定义图保持不变
  - 右侧分子骨架中，C1/C2/C3 三个 sp³ 碳原子高亮显示（黄色闪烁效果）
  - 判断结果框显示："步骤 1：识别分子中的 sp³ 碳原子（候选手性碳）"
  - 步骤指示器显示："步骤 2 / 4"

- 步骤 2（逐一验证连接基团）：
  - 左侧定义图保持不变
  - 右侧聚焦 C2 碳原子，显示其连接的四个取代基（用蓝/红/绿/橙四色区分）
  - C1 和 C3 变暗（透明度 50%），突出 C2
  - 判断结果框显示："步骤 2：验证 C2 连接的四个基团是否不同"
  - 步骤指示器显示："步骤 3 / 4"

- 步骤 3（确认手性碳）：
  - 左侧定义图保持不变
  - 右侧 C2 碳原子以绿色高亮圆点标记，四个取代基保持四色显示
  - C1 和 C3 恢复灰色但保持低透明度
  - 判断结果框显示："步骤 3：C2 连接 4 个不同基团 → 是手性碳（C*）"
  - 步骤指示器显示："步骤 4 / 4"

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于底部左侧 (280,440)，点击返回上一状态
  - 「下一步 ▶」按钮：位于底部右侧 (460,440)，点击进入下一状态
  - 步骤指示器：位于底部中央 (380,445)，显示当前步骤/总步骤
- 教师操作流程：
  1. 初始展示手性碳定义，让学生理解基本概念
  2. 点击"下一步"展示分子中所有 sp³ 碳候选
  3. 点击"下一步"聚焦特定碳原子，展示其四个取代基
  4. 点击"下一步"确认该碳是否为手性碳
  5. 可随时点击"上一步"回退复习，巩固理解

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何和状态切换，无需重型库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │ 800×500 画布                                                   │
  │                                                                │
  │ ┌────────────────────┐  ┌────────────────────┐                │
  │ │   手性碳定义区     │  │   分子局部放大区   │                │
  │ │   (20,40)-(380,380)│  │   (420,40)-(780,380)│               │
  │ │                    │  │                    │                │
  │ │    R₁   R₂         │  │  C1──C2──C3        │                │
  │ │      \ /           │  │      |             │                │
  │ │       C*           │  │    取代基          │                │
  │ │      / \           │  │                    │                │
  │ │    R₃   R₄         │  │                    │                │
  │ │                    │  │                    │                │
  │ └────────────────────┘  └────────────────────┘                │
  │                                                                │
  │ ┌──────────────────────────────────────────────────────────┐  │
  │ │              控件栏 (y=420~480)                           │  │
  │ │        ◀ 上一步      步骤 X / 4      下一步 ▶            │  │
  │ └──────────────────────────────────────────────────────────┘  │
  └────────────────────────────────────────────────────────────────┘
  ```

- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-3) 跟踪当前步骤，updateDisplay() 函数根据 currentStep 更新各元素可见性和样式
  2. 坐标计算：所有元素位置按布局坐标表精确设置，SVG 元素使用绝对坐标
  3. 动画曲线：取代基高亮使用 CSS transition (0.3s ease) 实现平滑过渡
  4. 事件绑定：按钮点击事件绑定到 scene2-btn-prev 和 scene2-btn-next，边界检查防止越界
  5. ID 命名规范：所有元素 ID 以 scene2- 为前缀（如 scene2-center-carbon, scene2-candidate-c2, scene2-btn-prev 等）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染

  - scene2-def-bg: 左侧定义区背景

  - scene2-def-text: 定义说明文字
  - scene2-mol-bg: 右侧分子区背景

  - scene2-candidate-c1/c2/c3: 三个候选碳

  - scene2-result-box: 判断结果框
  - scene2-result-text: 结果框内文字
  - scene2-control-bg: 控件栏背景
  - scene2-btn-prev: 上一步按钮

  - scene2-step-indicator: 步骤指示器
