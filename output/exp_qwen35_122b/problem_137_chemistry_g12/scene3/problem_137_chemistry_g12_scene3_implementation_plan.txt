[分步序列]
- 步骤 0（初始状态）：
  - 显示：分子结构图（全黑）、官能团统计区（显示"C=C × 5"和"-COO- × 3"）
  - 隐藏：反应方程式区、计量关系区
  - 目的：让学生先识别分子中的官能团种类和数量

- 步骤 1（点击"下一步"）：
  - 新增显示：C=C 双键高亮（5 个红色框）、H₂反应方程式区
  - H₂反应方程式："C=C + H₂ → C-C"（加成反应）
  - 新增标签："5 mol H₂"（绿色粗体，位于方程式右侧）
  - 目的：展示碳碳双键与氢气的加成反应及计量关系

- 步骤 2（点击"下一步"）：
  - 新增显示：-COO- 酯基高亮（3 个蓝色框）、NaOH 反应方程式区
  - NaOH 反应方程式："-COO- + NaOH → -COONa + -OH"（水解反应）
  - 新增标签："3 mol NaOH"（绿色粗体，位于方程式右侧）
  - 目的：展示酯基与 NaOH 的水解反应及计量关系

- 步骤 3（点击"下一步"）：
  - 新增显示：计量关系结论区
  - 结论文本："1 mol A 最多消耗 5 mol H₂和 3 mol NaOH"
  - 高亮：同时高亮 C=C 和-COO- 区域，用箭头指向结论
  - 目的：综合展示定量计算结果，对应选项 C 的判断

- "5 mol H₂"(250,330) 与 "3 mol NaOH"(580,330)：水平间距 330px → 无冲突
- "3 mol NaOH"(580,330) 与 结论标签(400,395)：对角间距约 80px → 无冲突
- 所有标签与分子结构图边缘间距 ≥ 40px → 无冲突

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：位于(250,450)，点击返回上一步状态，第一步时置灰不可点击
  - "下一步 ▶"按钮：位于(420,450)，点击进入下一步状态，最后一步时变为"完成"
- 教师操作流程：
  1. 初始展示分子结构，引导学生识别官能团
  2. 点击"下一步"展示 H₂消耗计算，讲解加成反应
  3. 点击"下一步"展示 NaOH 消耗计算，讲解水解反应
  4. 点击"下一步"展示综合结论，引导学生判断选项 C 的正确性
  5. 可随时点击"上一步"回退复习某个反应类型

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何和文本，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │  [分子结构 80,80-480,280]        [官能团统计 520,80-750,180] │
  │                                                             │
  │  [H₂方程式 80,300-400,360]     [NaOH 方程式 420,300-750,360]│
  │                                                             │
  │  [计量结论 80,370-750,420]                                 │
  │                                                             │
  │              [◀ 上一步]        [下一步 ▶]                   │
  │                    (250,450)    (420,450)                   │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep(0-3) 跟踪当前步骤
  2. 元素显示控制：每个步骤对应的元素用 class="step-1""step-2"等标记，通过 toggleClass 控制显示
  3. 坐标计算：分子结构图需根据实际化学键位置精确绘制，双键用平行线表示
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后刷新视图
  5. ID 命名规范：所有元素 ID 以"scene3-"为前缀（如 scene3-mol-struct、scene3-btn-prev、scene3-btn-next）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 分子结构绘制：根据图片中的实际结构，用 SVG 路径绘制碳链骨架，双键用两条平行线段表示
