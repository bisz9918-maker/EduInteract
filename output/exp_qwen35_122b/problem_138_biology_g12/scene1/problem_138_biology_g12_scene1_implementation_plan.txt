[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何和状态切换，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │  植株甲框(50,60)          处理①→无种子豆荚(370,90)              │
  │  [花图标]                 [豆荚图标]                            │
  │  aa bb                    无种子豆荚                            │
  │  黄色豆荚、绿色子叶                                             │
  │                                                                 │
  │  植株乙框(50,280)    处理②→有种子豆荚(370,200)                  │
  │  [花图标]            [豆荚+种子图标]                            │
  │  AA BB               有种子豆荚                                 │
  │  绿色豆荚、黄色子叶                                             │
  │                                                                 │
  │              处理③→单倍体(370,310)→处理④→二倍体(690,310)        │
  │              [小植株] n        [大植株] 2n                      │
  │              单倍体植株        二倍体植株                        │
  │                                                                 │
  │  [原理①]    [原理②]    [原理③]    [原理④]                       │
  │  [◀上一步]          [下一步▶]                                   │
  └────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：currentStep 变量（0-5），updateScene() 函数根据 currentStep 更新元素样式
  2. 坐标计算：所有元素使用绝对坐标，通过 SVG transform 或直接属性设置
  3. 动画曲线：元素高亮使用 CSS transition（0.3s ease）实现平滑过渡
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateScene()
  5. ID 命名规范：所有交互元素 ID 以 scene1- 为前缀（如 scene1-prev-btn、scene1-arrow1、scene1-box1 等）
  6. IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局污染
  7. 元素高亮：通过修改 stroke、stroke-width、fill 属性实现，使用 CSS class 或 inline style
  8. 原理框显示：通过设置 display="none"/"block"控制显示隐藏
