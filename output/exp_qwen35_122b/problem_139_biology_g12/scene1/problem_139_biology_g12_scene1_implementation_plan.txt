[图示主题与整合说明]
- 本图示主题：基因表达与花色形成生化机制
- 整合内容：
  - 基因 B 的表达路径（转录→翻译→酶 B→蓝色色素）
  - 基因 A 的表达路径（转录→翻译→酶 A→紫色色素）
  - A、B 基因同时存在时的互作效应（mRNA 结合抑制酶合成）
  - 不同基因型对应的花色表现型
- 教学价值：教师可通过分步展示，引导学生理解从基因到蛋白再到代谢产物的完整链条，理解基因互作对性状的影响

[分步序列]
- 步骤 0（初始状态）：
  - 显示：白色前体物质（中央圆）
  - 显示：基因 A 框、基因 B 框（灰色，未激活状态）
  - 隐藏：所有箭头、mRNA、酶、色素
  - 目的：展示基础条件，等待教师开始讲解

- 步骤 1：激活基因 B 路径
  - 视觉变化：基因 B 框变为蓝色高亮
  - 新增：转录箭头 B（黑色实线）
  - 新增：转录标注"①"
  - 新增：mRNA B（淡蓝色椭圆）
  - 目的：展示基因 B 的转录过程

- 步骤 2：基因 B 翻译
  - 视觉变化：mRNA B 高亮
  - 新增：翻译箭头 B
  - 新增：翻译标注"②"
  - 新增：酶 B（绿色边框不规则形）
  - 目的：展示 mRNA 翻译为酶 B

- 步骤 3：酶 B 催化蓝色色素
  - 视觉变化：酶 B 高亮
  - 新增：催化箭头 B（酶 B→白色前体）
  - 新增：产物箭头 B（白色前体→蓝色色素）
  - 新增：蓝色色素圆（红色填充）
  - 新增：蓝色色素标签
  - 目的：展示酶 B 催化白色前体生成蓝色色素

- 步骤 4：激活基因 A 路径
  - 视觉变化：基因 A 框变为蓝色高亮
  - 新增：转录箭头 A
  - 新增：转录标注"①"
  - 新增：mRNA A（淡蓝色椭圆）
  - 目的：展示基因 A 的转录过程

- 步骤 5：基因 A 翻译
  - 视觉变化：mRNA A 高亮
  - 新增：翻译箭头 A
  - 新增：翻译标注"②"
  - 新增：酶 A（绿色边框不规则形）
  - 目的：展示 mRNA 翻译为酶 A

- 步骤 6：酶 A 催化紫色色素
  - 视觉变化：酶 A 高亮
  - 新增：催化箭头 A（酶 A→白色前体）
  - 新增：产物箭头 A（白色前体→紫色色素）
  - 新增：紫色色素圆（绿色填充）
  - 新增：紫色色素标签
  - 目的：展示酶 A 催化白色前体生成紫色色素

- 步骤 7（结论）：展示互作效应
  - 视觉变化：mRNA B 和 mRNA A 同时高亮
  - 新增：mRNA 互作线（虚线连接两条 mRNA）
  - 新增：互作说明框（底部中央）
  - 新增：互作说明文字
  - 酶 A、酶 B 变为灰色（表示不能合成）
  - 目的：总结 A、B 基因同时存在时的抑制效应

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "上一步"按钮：位于控件栏左侧 (280,450)-(380,480)，点击返回上一状态
  - "下一步"按钮：位于控件栏右侧 (420,450)-(520,480)，点击进入下一状态
  - 步骤指示器：显示当前步骤/总步骤数（如"步骤 3/7"）
- 教师操作流程：
  1. 初始状态展示白色前体物质和两个基因框
  2. 点击"下一步"逐步展示基因 B 路径（转录→翻译→催化）
  3. 继续点击"下一步"展示基因 A 路径
  4. 最后一步展示互作效应，总结基因型与表现型关系
  5. 可随时点击"上一步"回退复习某个环节

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：图示为几何图形和箭头，SVG 最适合绘制矢量图形，原生 JS 足以处理状态切换
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    图示区 800×500                       │
  │                                                         │
  │   基因 B框          基因 A框                              │
  │     ████              ████                              │
  │      │                │                                 │
  │      ▼①               ▼①                                │
  │    (mRNA)          (mRNA)                               │
  │      │                │                                 │
  │      ▼②               ▼②                                │
  │    酶 B              酶 A                                │
  │      ╲                ╱                                 │
  │       ╲              ╱                                  │
  │        ▼            ▼                                   │
  │         ● 白色前体物质                                   │
  │        ╱            ╲                                   │
  │       ╱              ╲                                  │
  │      ▼                ▼                                 │
  │   蓝色色素          紫色色素                             │
  │                                                         │
  │        ═══════════════                                  │
  │        mRNA 互作线（虚线）                               │
  │                                                         │
  │   ┌─────────────────────────────────┐                  │
  │   │  A、B 基因同时存在时，两种 mRNA 结合 │                  │
  │   │     使酶 A、酶 B 不能合成          │                  │
  │   └─────────────────────────────────┘                  │
  │                                                         │
  │   ┌────────┐              ┌────────┐                   │
  │   │ 上一步 │              │ 下一步 │                   │
  │   └────────┘              └────────┘                   │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep 记录当前步骤（0-7），每个步骤对应一个元素显示配置对象
  2. 坐标计算：所有元素使用绝对坐标，通过 SVG 的 x,y 属性精确控制位置
  3. 动画曲线：使用 CSS transition 实现元素淡入淡出（opacity: 0→1）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 renderStep() 重绘
  5. ID 命名规范：所有元素 ID 以"scene1-"为前缀（如 scene1-geneB-box、scene1-mRNA-B）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
- 元素显示配置（每个步骤）：
  - step0: {geneB:0.3, geneA:0.3, whitePre:1, others:0}
  - step1: {geneB:1, transB:1, mRNA_B:1, others:0}

  - step3: {geneB:1, mRNA_B:1, enzymeB:1, catalyzeB:1, bluePig:1, others:0}
