[分步序列]
- 步骤 0（初始状态）：
  - 显示：实验台、木块 A、木块 B、两侧滑轮、轻线、两侧钩码组
  - 显示：木块标签"A"、"B"，钩码标签"1"、"2"、"3"、"4"、"5"
  - 隐藏：所有力箭头（T_A、T_B、f_AB、f_B台）及其标签
  - 目的：展示系统整体结构，让学生观察初始配置

- 步骤 1：
  - 新增显示：T_A 箭头（蓝色，从 A 左侧向左），标签"T_A=2mg"（蓝色，箭头上方）
  - 说明：左侧 4、5 号钩码共 2 个，产生 2mg 拉力，通过轻线作用于木块 A

- 步骤 2：
  - 新增显示：T_B 箭头（蓝色，从 B 右侧向右），标签"T_B=3mg"（蓝色，箭头上方）
  - 说明：右侧 1、2、3 号钩码共 3 个，产生 3mg 拉力，通过轻线作用于木块 B

- 步骤 3：
  - 新增显示：f_AB 箭头（红色，从 A 底面向右），标签"f_AB"（红色，箭头下方）
  - 说明：A 静止，水平方向合力为零，f_AB 与 T_A 平衡，故 f_AB = T_A = 2mg，方向向右

- 步骤 4（最终步骤）：
  - 新增显示：f_B台 箭头（红色，从 B 底面向左），标签"f_B台"（红色，箭头下方）
  - 说明：B 静止，水平方向受 T_B 向右、f_AB 向左（A 对 B 的反作用力）、f_B台向左，合力为零
  - 结论：f_B台 = T_B - f_AB = 3mg - 2mg = mg，方向向左

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "上一步"按钮：位于控件栏左侧 (260,450)-(360,480)，灰色，步骤 0 时禁用，点击返回上一步
  - "下一步"按钮：位于控件栏右侧 (440,450)-(540,480)，蓝色，点击进入下一步，步骤 4 时显示"完成"
- 教师操作流程：
  1. 初始展示系统结构，让学生观察 A、B 叠放关系及两侧钩码数量
  2. 点击"下一步"，展示左侧拉力 T_A，引导学生分析 A 的受力
  3. 点击"下一步"，展示右侧拉力 T_B，引导学生分析 B 的受力
  4. 点击"下一步"，展示 A、B 间静摩擦力 f_AB，讲解静摩擦力的平衡作用
  5. 点击"下一步"，展示 B 与实验台间静摩擦力 f_B台，完成整体受力分析
  6. 可点击"上一步"回退复习任意步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    800px 宽度                           │
  │  ┌───────────────────────────────────────────────────┐  │
  │  │                                                   │  │
  │  │     滑轮○                    木块 A              ○滑轮│
  │  │      │                        ┌─────┐            │  │
  │  │      │                        │  A  │            │  │
  │  │      │                        └─────┘            │  │
  │  │      │                          │                │  │
  │  │      │                          ▼ T_A            │  │
  │  │      │                        ┌─────┐            │  │
  │  │      │                        │  B  │────────────┼──┼→ T_B
  │  │      │                        └─────┘            │  │
  │  │      ▼                                           ▼  │
  │  │   钩码 4,5                                      钩码 1,2,3│
  │  │                                                   │  │

  │  │           (260,450)                  (440,450)   │  │
  │  └───────────────────────────────────────────────────┘  │
  │                      500px 高度                         │
  └─────────────────────────────────────────────────────────┘
  ```

- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量（0-4）跟踪当前步骤，每一步定义需要显示的元素 ID 列表
  2. 坐标计算：所有元素使用绝对坐标，通过 SVG 的 x、y 属性精确控制位置
  3. 动画曲线：力箭头使用 opacity 从 0 到 1 的淡入动画，duration=300ms，ease="ease-out"
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateDisplay() 刷新显示
  5. ID 命名规范：所有元素 ID 以"scene1-"为前缀，如 scene1-blockA、scene1-arrowTA、scene1-btnNext
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染
