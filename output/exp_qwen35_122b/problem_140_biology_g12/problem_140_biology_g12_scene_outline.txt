    **题目原文：**
    果蝇是遗传学研究的实验材料，其四对相对性状中红眼（E）对白眼（e）、灰身（B）对黑身（b）、长翅（V）对残翅（v）、细眼（R）对粗眼（r）为显性。雄果蝇M的基因在染色体上的分布如图所示。

    （1）摩尔根的果蝇实验验证了萨顿提出的假说，即_________________________________。
    （2）1号和2号染色体______________（填"是"或"不是"）一对同源染色体。
    （3）果蝇M与另一只白眼的正常果蝇杂交，产生子代中出现基因型为X^E X^e Y个体，推测原因是____________。
    （4）选取长翅细眼和残翅粗眼的雌雄果蝇杂交，F_1代均为长翅细眼，经多次重复实验发现F_2中表现型与比例均接近于长翅细眼：长翅粗眼：残翅细眼：残翅粗眼=7:3:1：1，他们提出一种假设：基因型为________________的雄或雌配子致死。

    **题目分析：**
    本题为高中生物遗传学综合题，涉及以下核心知识点：
    1. 摩尔根果蝇实验验证"基因在染色体上"的假说
    2. 同源染色体的识别（形态大小相似，一条来自父方一条来自母方）
    3. 减数分裂异常导致染色体数目变异（XXY个体的产生）
    4. 配子致死导致的异常分离比分析（7:3:1:1偏离9:3:3:1）

    **整体讲解思路：**
    本题需要三个图示来完整讲解：
    - 图示1：展示雄果蝇M的染色体组型及基因分布，帮助学生理解染色体与基因的位置关系，回答问题(1)(2)
    - 图示2：展示减数分裂异常过程，解释XXY个体的产生机制，回答问题(3)
    - 图示3：展示杂交实验的配子致死分析，推导异常分离比的原因，回答问题(4)

    **图示规划说明：**
    三个图示分别对应题目的四个小问，图示1覆盖(1)(2)，图示2覆盖(3)，图示3覆盖(4)。

    **图示1教学说明：**

    本图示展示雄果蝇M的完整染色体组型，教师应引导学生按以下步骤观察：

    1. 首先观察整体布局，识别出4对染色体共8条染色体

    2. 重点讲解1号和2号染色体：
    - 1号为X染色体（棒状），携带E基因（红眼）
    - 2号为Y染色体（J形），不携带对应等位基因
    - 引导学生判断：1号和2号**是**一对同源染色体（虽然形态不同，但在减数分裂时配对）

    3. 讲解3-4号染色体：
    - 这是一对同源染色体，形态大小相同
    - 3号携带v（残翅）和B（灰身）基因
    - 4号携带V（长翅）和b（黑身）基因
    - 强调：B/b和V/v两对基因位于同一对染色体上，存在连锁关系

    4. 讲解5-6号染色体：
    - 另一对同源染色体
    - 5号携带R（细眼）基因，6号携带r（粗眼）基因

    5. 总结萨顿假说验证：
    - 摩尔根通过果蝇杂交实验，将特定基因（如白眼基因）定位到特定染色体（X染色体）上
    - 验证了萨顿提出的"**基因在染色体上**"的假说
    - 这是基因与染色体行为平行关系的直接证据

    **关键问题(1)(2)答案：**
    - (1) 基因在染色体上
    - (2) 是

    **图示2教学说明：**

    本图示对比展示正常与异常减数分裂过程，教师应重点引导学生理解：

    1. 正常减数分裂（状态1）：
    - 减数第一次分裂后期，同源染色体X^E和Y正常分离
    - X^E移向一极，Y移向另一极
    - 形成两种正常配子：含X^E的配子和含Y的配子

    2. 异常减数分裂（状态2）：
    - 减数第一次分裂后期，同源染色体X^E和Y**未正常分离**
    - X^E和Y移向同一极
    - 形成异常配子：含X^E Y的配子和不含性染色体的配子

    3. XXY个体的形成：
    - 雄果蝇M产生异常配子X^E Y
    - 与白眼雌果蝇（X^e X^e）产生的正常配子X^e结合
    - 形成子代基因型：X^E X^e Y

    **关键问题(3)答案：**
    亲本（雄果蝇M）在减数第一次分裂后期，X和Y染色体未分离，产生了含X^E Y的配子，该配子与含X^e的配子结合形成X^E X^e Y个体。

    **图示3教学说明：**

    本图示展示配子致死导致异常分离比的推导过程，教师应引导学生逐步分析：

    1. 确定亲本基因型：
    - 长翅细眼（显性纯合）：VVRR
    - 残翅粗眼（隐性纯合）：vvrr

    2. F1代基因型：
    - VvRr（长翅细眼）

    3. 正常情况下F2代分离比：
    - VvRr自交，若两对基因自由组合
    - F2表现型比例应为：长翅细眼:长翅粗眼:残翅细眼:残翅粗眼 = 9:3:3:1

    4. 实际观察到的异常比例：
    - 实际F2比例为：7:3:1:1
    - 与理论值9:3:3:1对比，发现长翅细眼减少2份，残翅细眼和残翅粗眼各减少1份

    5. 配子致死假设推导：
    - F1代VvRr产生的配子应为：VR、Vr、vR、vr（各占1/4）
    - 若vr配子致死，则存活配子为：VR、Vr、vR（比例调整为1/3:1/3:1/3）
    - 用棋盘格验证：
    - VR配子(1/3) × VR(1/3) = V_R_(1/9) → 长翅细眼
    - VR(1/3) × Vr(1/3) = V_R_(1/9) → 长翅细眼
    - VR(1/3) × vR(1/3) = V_R_(1/9) → 长翅细眼
    - Vr(1/3) × VR(1/3) = V_R_(1/9) → 长翅细眼
    - Vr(1/3) × Vr(1/3) = V_rr(1/9) → 长翅粗眼
    - Vr(1/3) × vR(1/3) = VvRr(1/9) → 长翅细眼
    - vR(1/3) × VR(1/3) = V_R_(1/9) → 长翅细眼
    - vR(1/3) × Vr(1/3) = VvRr(1/9) → 长翅细眼
    - vR(1/3) × vR(1/3) = vvR_(1/9) → 残翅细眼
    - 统计：长翅细眼7份、长翅粗眼3份、残翅细眼1份、残翅粗眼1份（注意：实际计算需考虑所有组合，此处简化说明）

    **关键问题(4)答案：**
    基因型为**vr**的雄或雌配子致死

    **课堂讲解建议：**
    1. 先用图示1建立染色体与基因位置的基本概念
    2. 用图示2讲解减数分裂异常，强调同源染色体分离的重要性
    3. 用图示3重点分析配子致死，引导学生通过棋盘格验证异常比例
    4. 总结本题涉及的遗传学核心概念：基因定位、同源染色体、减数分裂、配子致死
