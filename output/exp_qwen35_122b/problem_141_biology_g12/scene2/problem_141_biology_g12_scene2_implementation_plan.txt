[图示主题与整合说明]
- 本图示主题：染色体遗传与线粒体遗传的稳定性对比
- 整合内容：整合了染色体稳定遗传与线粒体不稳定遗传的对比展示，包括四代传递过程的可视化
- 教学价值：教师可通过分步演示，让学生直观理解为什么染色体整合的基因 S 能稳定遗传，而线粒体整合的基因 S 会逐代减弱，帮助学生理解细胞质遗传的特点

[分步序列]
- 步骤 0（初始状态）：
  - 显示：标题、左右区域背景框、左右标题
  - 左侧：显示"亲代"标签、亲代染色体（两条带箭头的蓝色竖线）、亲代抗性条（100% 绿色）
  - 右侧：显示"亲代"标签、亲代线粒体（红色实心圆，opacity=1.0）、亲代抗性条（100% 绿色）
  - 遗传箭头：不显示
  - 子代内容：全部隐藏

- 步骤 1（点击"下一步"）：
  - 新增：左侧"子一代"标签、子一代染色体（两条蓝色竖线）、子一代抗性条（100% 绿色）
  - 新增：右侧"子一代"标签、子一代线粒体（红色实心圆，opacity=0.7）、子一代抗性条（60% 绿色）
  - 新增：左侧遗传箭头 1（亲代→子一代）、右侧遗传箭头 1（亲代→子一代）
  - 抗性变化：右侧抗性条从 100% 变为 60%

- 步骤 2（点击"下一步"）：
  - 新增：左侧"子二代"标签、子二代染色体（两条蓝色竖线）、子二代抗性条（100% 绿色）
  - 新增：右侧"子二代"标签、子二代线粒体（红色实心圆，opacity=0.4）、子二代抗性条（30% 绿色）
  - 新增：左侧遗传箭头 2（子一代→子二代）、右侧遗传箭头 2（子一代→子二代）
  - 抗性变化：右侧抗性条从 60% 变为 30%

- 步骤 3（点击"下一步"）：
  - 新增：左侧"子三代"标签、子三代染色体（两条蓝色竖线）、子三代抗性条（100% 绿色）
  - 新增：右侧"子三代"标签、子三代线粒体（红色实心圆，opacity=0.1）、子三代抗性条（0% 灰色）
  - 新增：左侧遗传箭头 3（子二代→子三代）、右侧遗传箭头 3（子二代→子三代）
  - 抗性变化：右侧抗性条从 30% 变为 0%（灰色表示无抗性）

- 步骤 4（最终步骤，点击"下一步"）：
  - 高亮：左侧所有抗性条闪烁 2 次（强调稳定）
  - 高亮：右侧子三代抗性条变为灰色并闪烁 2 次（强调消失）
  - 新增：底部总结文字"结论：染色体遗传稳定 vs 线粒体遗传不稳定"
  - 步骤指示器显示"步骤 5/5"

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "上一步"按钮：scene2-btn-prev，位于 (250, 455)，点击后步骤减 1，返回上一状态
  - "下一步"按钮：scene2-btn-next，位于 (460, 455)，点击后步骤加 1，进入下一状态
  - 步骤指示器：scene2-step-indicator，位于 (350, 465)，显示当前步骤"步骤 X/5"
- 教师操作流程：
  1. 初始展示亲代状态，教师讲解染色体和线粒体整合 S 基因的初始状态
  2. 点击"下一步"展示子一代，教师讲解染色体稳定传递、线粒体开始减弱
  3. 继续点击"下一步"逐代展示，强调线粒体抗性逐代递减
  4. 最终步骤高亮对比，教师总结两种遗传方式的稳定性差异
  5. 可随时点击"上一步"回退复习特定代际

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何和状态切换，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │                        标题（居中）                              │
  │  染色体遗传（稳定）                    线粒体遗传（逐代减弱）       │
  │ ┌──────────────────────┐  ┌──────────────────────┐              │
  │ │    亲代              │  │    亲代              │              │
  │ │   ||  || (染色体)     │  │    ● (线粒体)        │              │
  │ │   ████ (100%)        │  │   ████ (100%)        │              │
  │ │      ↓               │  │      ↓               │              │
  │ │    子一代            │  │    子一代            │              │
  │ │   ||  || (染色体)     │  │    ● (70%)          │              │
  │ │   ████ (100%)        │  │   ████ (60%)         │              │
  │ │      ↓               │  │      ↓               │              │
  │ │    子二代            │  │    子二代            │              │
  │ │   ||  || (染色体)     │  │    ● (40%)          │              │
  │ │   ████ (100%)        │  │   ████ (30%)         │              │
  │ └──────────────────────┘  └──────────────────────┘              │
  │                    [◀上一步]  步骤 1/5  [下一步▶]                  │
  └────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep 记录当前步骤（0-4），每个步骤对应一个状态对象，包含该步骤应显示/隐藏的元素 ID 列表
  2. 坐标计算：所有元素使用绝对定位，通过 CSS transform 或直接设置 x/y 属性
  3. 动画曲线：抗性条宽度变化使用 CSS transition（0.3s ease），线粒体 opacity 变化使用 CSS transition
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateScene() 函数刷新显示
  5. ID 命名规范：所有元素 ID 以 scene2- 为前缀，如 scene2-chrom-parent、scene2-mito-f1、scene2-btn-prev 等
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染
  7. 抗性条宽度计算：用 CSS 的 width 属性控制，100%=60px，60%=36px，30%=18px，0%=0px（灰色背景）
  8. 线粒体透明度：用 CSS 的 opacity 属性控制，亲代=1.0，子一代=0.7，子二代=0.4，子三代=0.1
