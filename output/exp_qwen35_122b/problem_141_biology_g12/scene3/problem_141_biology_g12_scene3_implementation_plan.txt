[图示主题与整合说明]
- 本图示主题：自交与杂交实验设计及结果预测

  3. 如何通过实验结果反推亲本类型
  4. 最终判断符合长期种植要求种子的双重标准

[分步序列]
- 步骤0（初始状态）：
  - 显示标题"实验设计与结果预测"
  - 显示实验①框及自交流程图（抗性植株→自交→自交系一代）
  - 显示实验②框及杂交流程图（无抗性♀×抗性♂→杂交系一代）
  - 显示结果表格表头（亲本类型/染色体S/线粒体S/自交结果/杂交结果）
  - 判断标准框隐藏

- 步骤1：
  - 结果表格填充a-f六行数据
  - a行：两条染色体S+/线粒体S+ | 自交：全抗性 | 杂交：全抗性
  - b行：一条染色体S+/线粒体S+ | 自交：3:1分离 | 杂交：全抗性
  - c行：无染色体S/线粒体S+ | 自交：全无抗性 | 杂交：全无抗性
  - d行：两条染色体S+/线粒体S- | 自交：全抗性 | 杂交：全抗性
  - e行：一条染色体S+/线粒体S- | 自交：3:1分离 | 杂交：全抗性
  - f行：无染色体S/线粒体S- | 自交：全无抗性 | 杂交：全无抗性

- 步骤2：
  - 高亮表格b行和e行的自交结果（3:1分离），用红色粗框
  - 显示文字标注："自交目的a：通过自交系一代的抗性，将e与b/c区分"
  - 标注位置：(50,350) 字号12px #c62828

- 步骤3：
  - 高亮表格d行（两条染色体S+），用绿色粗框
  - 显示文字标注："自交目的b：筛选纯合体（d类型）"
  - 标注位置：(50,350) 字号12px #2e7d32

- 步骤4：
  - 表格杂交结果列按结果类型分组高亮：
    - 全抗性组（a、b、d、e）：绿色背景
    - 全无抗性组（c、f）：灰色背景
  - 显示文字标注："杂交系一代结果类型：2种（全抗性/全无抗性）"
  - 标注位置：(50,350) 字号12px #2e7d32

- 步骤5：
  - 判断标准框显示，粗绿框高亮
  - 表格中d行同时用绿色粗框高亮（自交全抗性+杂交全抗性）
  - 显示文字："符合要求的种子：d类型的自交后代"
  - 标注位置：(300,385) 字号14px #2e7d32 粗体

- 步骤6（最终状态）：
  - 所有高亮保留
  - 在d行旁边添加✓标记
  - 显示总结文字："d类型：染色体纯合S+，线粒体S-，抗性稳定遗传"
  - 标注位置：(300,405) 字号12px #000000

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（矩形、圆形、箭头、文字），无需复杂图表库
  - 状态管理：用变量 currentStep 记录当前步骤（0-6）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │                    实验设计与结果预测                          │ (15)
  ├──────────────────────┬─────────────────────────────────────────┤
  │   实验①：自交        │          实验②：杂交                    │ (65)
  │   [抗性]→自交→[子代] │  [无抗♀]×[抗♂]→[子代]                  │ (90-180)
  ├──────────────────────┴─────────────────────────────────────────┤
  │           结 果 预 测 表 格 (6行×5列)                          │ (200-340)
  ├─────────────────────────────────────────────────────────────────┤
  │  符合要求的条件：自交系一代全抗性 + 杂交系一代全抗性            │ (360-420)
  ├─────────────────────────────────────────────────────────────────┤
  │              [◀上一步]        [下一步▶]                         │ (450-480)
  └─────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：currentStep 变量控制显示内容，updateScene() 函数根据 currentStep 更新 DOM
  2. 坐标计算：所有元素使用绝对定位，坐标硬编码在 CSS 或 SVG 属性中
  3. 高亮效果：用 class "highlight-green" 和 "highlight-red" 控制边框颜色
  4. 按钮禁用：用 disabled 属性和 class "disabled" 控制按钮状态
  5. ID 命名规范：所有元素 ID 以 "scene3-" 为前缀（如 scene3-table-row-d, scene3-btn-next）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 表格数据：用数组存储6行数据，动态生成表格内容
  8. 动画过渡：高亮变化用 CSS transition 实现平滑效果（0.3s ease）
