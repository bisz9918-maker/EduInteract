- 本图示主题：生态系统能量流动计算演示（非洲草原食物网）

[分步序列]
- 初始状态（步骤0）：
  - 显示完整食物网结构（所有节点和箭头）
  - 草节点能量值显示"300"万千焦
  - 其他节点能量值显示"?"
  - 公式区显示："已知：生产者固定太阳能 = 300 万千焦"
  - 数值区显示："传递效率 = 10%"
  - 结论区显示："等待计算..."
  - 上一步按钮禁用，下一步按钮启用

- 步骤1（平衡状态能量关系）：
  - 草节点能量值保持"300"
  - 公式区显示："平衡状态：输入能量 = 输出能量"
  - 公式区追加："输出能量形式 = 热能（呼吸作用）"
  - 数值区显示："生态系统能量最终通过呼吸作用以热能形式散失"
  - 结论区显示："问题(1)答案：输入=输出；热能"
  - 所有箭头显示为默认黑色

- 步骤2（人类干预前能量分配）：
  - 草节点能量值"300"
  - 羚羊、斑马、鼠能量值显示"100"（300÷3，平均分配）
  - 公式区显示："干预前：三种初级消费者平均摄食"
  - 公式区追加："E_羚羊 = E_斑马 = E_鼠 = 300 ÷ 3 = 100 万千焦"
  - 数值区显示："初级消费者各得 100 万千焦"
  - 草→羚羊、草→斑马、草→鼠箭头高亮为红色

- 步骤3（人类干预前狮群能量计算）：
  - 野狗能量值显示"10"（(100+100)×10%÷2 = 10）
  - 蛇能量值显示"10"（100×10% = 10）
  - 食蛇动物能量值显示"1"（10×10% = 1）
  - 狮子能量值显示"1.875"
  - 公式区显示："狮群能量 = Σ(各路径能量)"
  - 公式区追加："路径1: 羚羊→狮子 = 100×10% = 10"
  - 公式区追加："路径2: 斑马→狮子 = 100×10% = 10"
  - 公式区追加："路径3: 羚羊→野狗→狮子 = 100×10%×10%÷2 = 0.5"
  - 公式区追加："路径4: 斑马→野狗→狮子 = 100×10%×10%÷2 = 0.5"
  - 公式区追加："路径5: 鼠→蛇→食蛇动物→狮子 = 100×10%×10%×10% = 0.125"
  - 公式区追加："E_狮 = 10×10% + 10×10% + 0.5 + 0.5 + 0.125 = 1.875 万千焦"
  - 数值区显示："狮群总能量 = 1.875 万千焦"
  - 羚羊→狮子、斑马→狮子、羚羊→野狗、斑马→野狗、野狗→狮子、鼠→蛇、蛇→食蛇动物、食蛇动物→狮子箭头依次高亮

- 步骤4（人类干预后能量重新分配）：
  - 鼠能量值显示"200"（300×2/3）
  - 羚羊、斑马能量值显示"50"（300×1/3÷2）
  - 野狗能量值显示"5"（(50+50)×10%÷2）
  - 蛇能量值显示"20"（200×10%）
  - 食蛇动物能量值显示"2"（20×10%）
  - 公式区显示："干预后：鼠类占本营养级 2/3"
  - 公式区追加："E_鼠 = 300×2/3 = 200 万千焦"
  - 公式区追加："E_羚羊 = E_斑马 = 300×1/3÷2 = 50 万千焦"
  - 数值区显示："鼠类能量大增，羚羊斑马能量减少"
  - 草→鼠箭头高亮红色，草→羚羊、草→斑马箭头变为绿色（已完成）

- 步骤5（人类干预后狮群能量计算）：
  - 狮子能量值显示"1.4"
  - 公式区显示："干预后狮群能量计算："
  - 公式区追加："路径1: 羚羊→狮子 = 50×10% = 5"
  - 公式区追加："路径2: 斑马→狮子 = 50×10% = 5"
  - 公式区追加："路径3: 羚羊→野狗→狮子 = 50×10%×10%÷2 = 0.25"
  - 公式区追加："路径4: 斑马→野狗→狮子 = 50×10%×10%÷2 = 0.25"
  - 公式区追加："路径5: 鼠→蛇→食蛇动物→狮子 = 200×10%×10%×10% = 0.2"
  - 公式区追加："E_狮 = 5×10% + 5×10% + 0.25 + 0.25 + 0.2 = 1.4 万千焦"
  - 数值区显示："干预后狮群能量 = 1.4 万千焦"
  - 所有到狮子的路径箭头高亮

- 步骤6（生态影响结论）：
  - 狮子能量值保持"1.4"
  - 公式区显示："生态影响分析："
  - 公式区追加："面积倍数 = E_原 / E_新 = 1.875 / 1.4 ≈ 1.34 倍"
  - 公式区追加："密度变化：能量减少 → 种群密度下降"
  - 数值区显示："捕食区域需扩大至 1.34 倍"
  - 结论区显示："狮群能量 1.4 万千焦；面积倍数 1.34；密度下降"
  - 结论区高亮显示最终答案

- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量（0-6），存储每个步骤的显示数据对象
  2. 坐标计算：所有节点和箭头坐标预先计算并存储在常量对象中
  3. 箭头高亮：通过修改 SVG path 元素的 stroke 和 stroke-width 属性实现
  4. 文本更新：通过修改 SVG text 元素的 textContent 属性实现
  5. 按钮状态：根据 currentStep 值启用/禁用按钮
  6. 事件绑定：使用 addEventListener 绑定按钮点击事件

- ID 命名规范：所有交互元素 ID 以 scene2- 为前缀
  - 节点：scene2-node-grass, scene2-node-antelope, scene2-node-zebra, scene2-node-rat, scene2-node-wilddog, scene2-node-snake, scene2-node-snakeeater, scene2-node-lion

  - 能量标签：scene2-energy-grass, scene2-energy-antelope, scene2-energy-zebra, scene2-energy-rat, scene2-energy-wilddog, scene2-energy-snake, scene2-energy-snakeeater, scene2-energy-lion
  - 区域：scene2-formula-area, scene2-value-area, scene2-conclusion-area
  - 控件：scene2-prev-btn, scene2-next-btn, scene2-step-indicator

- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染
