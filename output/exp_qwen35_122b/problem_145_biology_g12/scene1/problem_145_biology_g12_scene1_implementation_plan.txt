[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：位于(260,450)-(340,480)，点击返回前一个步骤，步骤0时禁用
  - "下一步 ▶"按钮：位于(460,450)-(540,480)，点击进入下一个步骤，步骤5时禁用
- 教师操作流程：
  1. 初始展示完整系谱图，让学生先观察整体结构
  2. 点击"下一步"进入步骤1，高亮甲病患者，引导学生观察传递特征
  3. 点击"下一步"进入步骤2，展示甲病推理结论
  4. 点击"下一步"进入步骤3，切换高亮到乙病患者
  5. 点击"下一步"进入步骤4，展示乙病推理结论
  6. 点击"下一步"进入步骤5，展示最终结论
  7. 可随时点击"上一步"回退复习某个推理环节

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：系谱图为几何图形（矩形、圆形、线条），原生 SVG 足以实现，无需引入重型库
  - 动画效果：使用 SVG 的 class 切换和 CSS transition 实现高亮、显示/隐藏效果

- 画布尺寸：800 × 500 px

- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-5) 跟踪当前步骤
  2. 元素 ID 命名：所有元素 ID 以 scene1- 为前缀，如 scene1-individual-1、scene1-line-parent-1-2
  3. 高亮实现：通过添加/移除 CSS class "highlight" 实现绿色边框
  4. 显示/隐藏：通过 CSS display 属性控制推理框和标注的显示
  5. 按钮状态：步骤0时禁用"上一步"，步骤5时禁用"下一步"
  6. 斜线/网格填充：使用 SVG <pattern> 定义斜线和网格填充样式
  7. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染

- ID 命名规范示例：
  - 个体：scene1-individual-1, scene1-individual-2, ..., scene1-individual-9
  - 连接线：scene1-line-spouse-1-2, scene1-line-child-1-2, scene1-line-spouse-3-4, ...
  - 世代标记：scene1-generation-I, scene1-generation-II, scene1-generation-III
  - 图例：scene1-legend-box, scene1-legend-1, scene1-legend-2, scene1-legend-3
  - 推理框：scene1-reasoning-box-1, scene1-reasoning-box-2, scene1-reasoning-box-3
  - 按钮：scene1-btn-prev, scene1-btn-next
