[交互方案]
- 交互类型：多状态切换（4 个按钮）
- 控件说明：
  - 按钮 1"XXY"：位置 (150,450)，点击切换至 XXY 状态
  - 按钮 2"XO"：位置 (300,450)，点击切换至 XO 状态
  - 按钮 3"XXX"：位置 (450,450)，点击切换至 XXX 状态
  - 按钮 4"OY"：位置 (600,450)，点击切换至 OY 状态
- 教师操作流程：
  1. 初始展示 XXY 类型（雌性可育），讲解正常雌性染色体组成
  2. 点击"XO"按钮，展示 XO 类型（雄性不育），对比说明缺少一条 X 染色体的影响
  3. 点击"XXX"按钮，展示 XXX 类型（死亡），说明三条 X 染色体导致死亡
  4. 点击"OY"按钮，展示 OY 类型（死亡），说明缺少 X 染色体导致死亡
  5. 可反复点击各按钮对比四种类型的差异

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    [顶部标题：XXY]                      │  y=50
  │                                                         │
  │              ┌───────────────────────────┐              │
  │              │        细胞轮廓            │              │
  │              │    ┌───┐  ┌───┐  ┌───┐    │              │
  │              │    │常 │  │常 │  │常 │    │  常染色体    │
  │              │    └───┘  └───┘  └───┘    │              │
  │              │                           │              │
  │              │    X      X       Y       │  性染色体    │
  │              │  (蓝)   (蓝)    (红)      │              │
  │              └───────────────────────────┘              │  y=200
  │                                                         │
  │              [底部状态标签：雌性，可育]                  │  y=350
  │                                                         │
  │  ┌──────┐  ┌──────┐  ┌──────┐  ┌──────┐                │
  │  │ XXY  │  │  XO  │  │ XXX  │  │  OY  │                │  y=450
  │  └──────┘  └──────┘  └──────┘  └──────┘                │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentScene 记录当前状态 (0-3)，对应 XXY/XO/XXX/OY
  2. 坐标计算：所有元素使用绝对坐标，染色体根据状态动态显示/隐藏
  3. 动画曲线：状态切换时使用 opacity 渐变 (0→1)，过渡时间 0.3s
  4. 事件绑定：4 个按钮分别绑定 click 事件，切换状态并更新显示
  5. ID 命名规范：所有元素 ID 以"scene1-"为前缀（如 scene1-cell, scene1-btn-xxl, scene1-chr-x1 等）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 染色体显示逻辑：根据 currentScene 值决定显示哪些染色体元素（设置 display 属性）
  8. 按钮高亮逻辑：根据 currentScene 值设置对应按钮边框颜色，其他按钮恢复灰色
