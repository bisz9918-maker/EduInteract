[图示主题与整合说明]
- 本图示主题：正常果蝇减数分裂染色体行为
- 整合内容：整合减数第一次分裂中期（同源染色体排列在赤道板）和减数第二次分裂后期（着丝粒分裂，姐妹染色单体分离）两个关键时期

[分步序列]

  - 染色体组数标签："染色体组数：2"

  - 按钮状态：上一步启用，下一步启用

  - 总结框内容：

  - 按钮状态：上一步启用，下一步禁用

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：位于 (250,455)，点击返回上一状态，第一步时禁用
  - "下一步 ▶"按钮：位于 (450,455)，点击进入下一状态，最后一步时禁用
- 教师操作流程：
  1. 初始展示减数分裂细胞基本结构
  2. 点击"下一步"展示减Ⅰ中期染色体排列，讲解同源染色体行为
  3. 点击"下一步"展示减Ⅱ后期染色体分离，讲解着丝粒分裂和姐妹染色单体分离
  4. 点击"下一步"展示总结，强化染色体数量变化规律
  5. 可随时点击"上一步"回退复习关键概念

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形（椭圆、线段、X 形染色体）用 SVG 绘制最清晰，状态切换用 JS 控制元素显示/隐藏，无需重型动画库

- 画布尺寸：800 × 500 px

- 布局草图（ASCII）：
```
┌─────────────────────────────────────────────────────────────┐
│                      时期标题 (320,60)                       │
│                                                             │
│              ╭─────────────────────────╮                    │
│             ╱    减数分裂细胞图示        ╲                   │
│            │   ┌───────────────────┐    │                   │
│            │   │   染色体排列区     │    │                   │
│            │   │   (赤道板区域)     │    │                   │
│            │   └───────────────────┘    │                   │
│             ╲                           ╱                    │

│    └──────────────┘              └──────────────┘           │
└─────────────────────────────────────────────────────────────┘
```

- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-3) 跟踪当前步骤，updateScene() 函数根据 currentStep 显示/隐藏对应元素
  2. 坐标计算：所有元素坐标硬编码在 SVG 属性中，确保精确位置
  3. 动画曲线：染色体移动用 SVG transform 的 translate 和 rotate，过渡用 CSS transition (0.5s ease)
  4. 事件绑定：按钮点击事件监听器在 DOMContentLoaded 后绑定，调用 updateScene()
  5. ID 命名规范：所有交互元素 ID 以 scene2- 为前缀（如 scene2-cell, scene2-chromo-1, scene2-prev-btn）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染

- 染色体绘制细节：
  - X 形染色体：用 4 条线段组成，每条线段从着丝粒向四个方向延伸
  - 着丝粒：SVG circle 元素，fill="#2e7d32"
  - 染色体填充：polygon 元素，fill="#1565c0" fill-opacity="0.15"

- 减Ⅱ后期次级细胞：
  - 用两个椭圆表示，左细胞中心 (280,240)，右细胞中心 (520,240)
  - 每个细胞内显示 4 条单体染色体（3 常 +1 性）
  - 用箭头表示染色单体向两极移动
