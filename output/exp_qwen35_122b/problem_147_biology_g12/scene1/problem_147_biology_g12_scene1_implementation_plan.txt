[图示主题与整合说明]
- 本图示主题：PCR 技术扩增 DNA 的全过程演示
- 整合的内容：PCR 三个温度阶段（变性 95°C→复性 55°C→延伸 72°C）及循环一次后的产物
- 教学价值：教师可通过分步按钮逐步展示 PCR 的变性、复性、延伸三个关键步骤，帮助学生理解 DNA 半保留复制的分子机制，特别是引物结合的位置和新链合成的方向

[视觉元素清单]
- 标题 text：居中顶部，字体 18px，黑色
- 原始 DNA 双链（步骤 0）：
  - a 链骨架：polyline (150,100)-(550,100)，stroke="#000000"，stroke-width=2
  - a 链碱基：text 元素，G(170,90)、G(210,90)、T(430,90)、C(470,90)，fill="#1565c0"
  - b 链骨架：polyline (150,120)-(550,120)，stroke="#000000"，stroke-width=2
  - b 链碱基：text 元素，C(170,135)、C(210,135)、A(430,135)、G(470,135)，fill="#c62828"
  - 氢键：line 元素，(170,100)-(170,120)、(210,100)-(210,120)、(430,100)-(430,120)、(470,100)-(470,120)，stroke="#888888"，stroke-dasharray="3,3"
- 95°C 变性阶段（步骤 1）：
  - 双链分离为两条单链
  - a 链上移至 y=195-215 区域
  - b 链下移至 y=235-255 区域
  - 氢键消失
- 55°C 复性阶段（步骤 2）：
  - 引物Ⅰ：结合到 b 链 3'端右侧，碱基 G(490,250)、G(530,250)，fill="#2e7d32"
  - 引物Ⅱ：结合到 a 链 3'端右侧，碱基 C(490,190)、C(530,190)，fill="#2e7d32"
  - 引物与模板间显示氢键（虚线）
- 72°C 延伸阶段（步骤 3）：
  - DNA 聚合酶图标出现在中间位置 (300,315)
  - 新链从引物 3'端延伸，用灰色 (#888888) 表示
  - 形成两个完整的 DNA 双链分子
- 结论状态（步骤 4）：
  - 产物 DNA1：左侧，含原始 a 链（蓝色）+ 新合成 b 链（灰色）
  - 产物 DNA2：右侧，含原始 b 链（红色）+ 新合成 a 链（灰色）
  - 显示"半保留复制"结论

[分步序列]
- 步骤 0（初始状态）：
  - 显示原始 DNA 双链（a 链 5'-G-G-...-T-C-3'，b 链 3'-C-C-...-A-G-5'）
  - 显示引物Ⅰ序列 5'-G-G-OH（右侧空白处）
  - 引物Ⅱ位置留空（下划线待填）
  - 温度标签 95°C、55°C、72°C 均显示但灰色

- 步骤 1（95°C 变性）：
  - 高亮 95°C 温度标签（黄色背景）
  - DNA 双链解旋分离为两条单链
  - 氢键消失（虚线变为透明）
  - a 链上移，b 链下移，中间留出空间

- 步骤 2（55°C 复性）：
  - 高亮 55°C 温度标签
  - 引物Ⅰ结合到 b 链 3'端（绿色高亮）
  - 引物Ⅱ结合到 a 链 3'端（绿色高亮，显示序列 5'-C-C-...-T-C-3'）
  - 引物与模板间显示氢键（虚线）

- 步骤 3（72°C 延伸）：
  - 高亮 72°C 温度标签
  - DNA 聚合酶图标出现（中间位置）
  - 从引物 3'-OH 端延伸合成新链（灰色）
  - 显示延伸方向箭头

- 步骤 4（结论状态）：
  - 显示循环一次后生成的两个 DNA 分子
  - 左侧 DNA：原始 a 链（蓝色）+ 新合成链（灰色）
  - 右侧 DNA：原始 b 链（红色）+ 新合成链（灰色）
  - 显示"半保留复制"结论标签

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：位于底部左侧 (280,455)，点击返回上一状态
  - "下一步 ▶"按钮：位于底部右侧 (420,455)，点击进入下一状态
- 教师操作流程：
  1. 初始展示原始 DNA 和引物Ⅰ，讲解 PCR 的前提条件
  2. 点击"下一步"进入 95°C 变性，讲解氢键断裂、双链分离
  3. 点击"下一步"进入 55°C 复性，讲解引物结合的位置和方向
  4. 点击"下一步"进入 72°C 延伸，讲解 DNA 聚合酶的作用和新链合成
  5. 点击"下一步"进入结论状态，讲解半保留复制的特点
  6. 可随时点击"上一步"回退复习某个阶段

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：DNA 结构为简单几何图形（线段、文字），无需复杂图表库；原生 SVG 便于控制每个元素的显示/隐藏和样式变化
- 画布尺寸：800 × 500 px
- 布局草图：
  ```

  │              [◀ 上一步]    [下一步 ▶]                    │  y=455
  └─────────────────────────────────────────────────────────┘
  ```

- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量（0-4）跟踪当前步骤，每一步对应一个状态函数
  2. 坐标计算：所有元素坐标已在布局坐标表中定义，直接硬编码
  3. 动画曲线：使用 CSS transition 实现元素移动（opacity 和 transform），过渡时间 0.5s
  4. 事件绑定：按钮点击事件调用 updateStep() 函数，根据 currentStep 更新显示
  5. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-dna-a-chain、scene1-prev-btn）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 状态更新函数：updateStep(n) 函数根据 n 值显示/隐藏对应元素，高亮当前温度标签
