    **题目原文：**

    甲烷和水反应可以制水煤气（混合气体），其反应的微观示意图如图所示．根据微观示意图得出的结论正确的是（  ）

    A. 反应前后各元素的化合价均不变
    B. 该反应中含氢元素的化合物有3种
    C. 该反应中乙和丁的质量比为3：1
    D. 该反应中丙和丁的分子个数比为1：3

    **题目分析：**

    本题通过微观示意图考查学生对化学反应本质的理解，包括：
    1. 从微观粒子模型识别化学式
    2. 书写并配平化学方程式
    3. 分析化合价变化
    4. 计算质量比和分子个数比

    **整体讲解思路：**

    1. 首先引导学生识别图例，理解三种原子的表示方法
    2. 从反应前后的微观模型写出各物质的化学式
    3. 配平化学方程式：CH₄ + H₂O → CO + 3H₂
    4. 逐一分析四个选项的正误

    **图示规划说明：**

    本设计规划2个核心图示：
    - Scene 1：反应前后分子结构对比与化学方程式推导（分步导航）
    - Scene 2：选项分析与结论验证（多状态切换）

    <TEXT_2>
    **Scene 1 教学说明：**

    本图示的核心目标是帮助学生从微观示意图推导出化学方程式，这是解决本题的基础。

    **引导策略：**

    1. **步骤0-1（图例识别）**：首先让学生观察图例，明确三种圆圈分别代表什么原子。强调微观示意图中"不同形状/颜色代表不同元素"的约定。

    2. **步骤2-5（分子识别）**：引导学生数清每个分子中的原子个数，写出化学式。关键提问：
       - "甲分子中有几个什么原子？" → 1个C + 4个H → CH₄
       - "乙分子呢？" → 1个O + 2个H → H₂O
       - "丙和丁分别是什么？" → CO 和 H₂

    3. **步骤5（方程式配平）**：重点讲解如何配平。学生容易忽略H₂前面的系数3，需要强调：
       - 反应前氢原子总数：4（CH₄）+ 2（H₂O）= 6个
       - 反应后氢原子总数：2×3（3个H₂）= 6个 ✓
       - 因此H₂前面必须写系数3

    4. **步骤6（原子守恒验证）**：用连线动画直观展示"化学反应前后原子种类和个数不变"这一核心规律。

    **关键公式：**

    化学方程式：CH₄ + H₂O → CO + 3H₂

    原子守恒验证：
    - 碳原子：反应前1个 = 反应后1个 ✓
    - 氢原子：反应前6个 = 反应后6个 ✓
    - 氧原子：反应前1个 = 反应后1个 ✓

    **常见错误提醒：**

    学生容易犯的错误：
    1. 忽略H₂的系数3，写成 CH₄ + H₂O → CO + H₂（未配平）
    2. 将H₂误认为化合物（实际上是单质）
    3. 数原子个数时遗漏

    **Scene 2 教学说明：**

    本图示用于逐一分析四个选项，帮助学生掌握判断依据和解题方法。

    **各选项分析要点：**

    **选项A：反应前后各元素的化合价均不变**

    化合价分析表：
    | 元素 | 反应前 | 反应后 | 变化 |
    |------|--------|--------|------|
    | C | -4（CH₄中） | +2（CO中） | 变化 |
    | H | +1（CH₄、H₂O中） | 0（H₂中） | 变化 |
    | O | -2（H₂O中） | -2（CO中） | 不变 |

    结论：**错误** — C和H的化合价都发生了变化

    教学提示：强调"单质中元素化合价为0"，H₂是单质，所以H的化合价从+1变为0。

    **选项B：该反应中含氢元素的化合物有3种**

    含氢物质分类：
    - CH₄：含氢，**化合物** ✓
    - H₂O：含氢，**化合物** ✓
    - H₂：含氢，**单质** ✗（不是化合物）

    结论：**错误** — 含氢化合物只有2种（CH₄和H₂O）

    教学提示：区分"含氢物质"和"含氢化合物"，H₂是单质不是化合物。

    **选项C：该反应中乙和丁的质量比为3：1**

    质量比计算：
    - 乙（H₂O）：相对分子质量 = 18，系数 = 1，质量 = 18×1 = 18
    - 丁（H₂）：相对分子质量 = 2，系数 = 3，质量 = 2×3 = 6
    - 质量比 = 18 : 6 = 3 : 1

    结论：**正确**

    教学提示：强调质量比 = （相对分子质量×系数）之比，不是简单的分子个数比。

    **选项D：该反应中丙和丁的分子个数比为1：3**

    分子个数统计：
    - 丙（CO）：1个分子
    - 丁（H₂）：3个分子
    - 分子个数比 = 1 : 3

    结论：**正确**

    教学提示：分子个数比直接看化学方程式的系数比。

    **完整解答：**

    本题正确选项为 **C 和 D**（若为单选题，则D更直接对应微观示意图的直观信息）。

    **课堂讲解建议：**

    1. 先完成Scene 1的方程式推导，确保学生理解反应本质
    2. 按A→B→C→D顺序逐一分析，每个选项讲清判断依据
    3. 重点强调易错点：
       - 单质与化合物的区分（选项B）
       - 质量比与分子个数比的区别（选项C vs D）
       - 化合价变化的判断（选项A）
    4. 总结微观示意图题的解题步骤：识图→写式→配平→分析
