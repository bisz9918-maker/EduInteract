[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（圆形、矩形、线段），无需复杂绘图库，原生 SVG 即可实现所有元素，性能好且代码简洁

- 画布尺寸：800 × 500 px

- 布局草图（ASCII）：
```
┌────────────────────────────────────────────────────────────────┐
│  图例区：○氢原子    ●氧原子    ◍碳原子                         │  y=10-55
├────────────────────────────────────────────────────────────────┤
│                                                                │
│  ┌──────────────┐              ┌──────────────┐               │
│  │  反应前      │   高温→      │  反应后      │               │  y=100-300
│  │  CH₄  H₂O    │              │  CO   H₂×3   │               │
│  └──────────────┘              └──────────────┘               │
│                                                                │
│  反应前              反应后                                    │  y=330
├────────────────────────────────────────────────────────────────┤
│  化学方程式：CH₄ + H₂O → CO + 3H₂                              │  y=360-420
├────────────────────────────────────────────────────────────────┤
│              [◀ 上一步]    [下一步 ▶]                          │  y=440-490
└────────────────────────────────────────────────────────────────┘
```

- 关键实现要点：
  1. 状态机设计：用变量 currentStep 记录当前步骤（0-6），根据 currentStep 控制各元素显示/隐藏/高亮
  2. 坐标计算：所有元素坐标按布局坐标表精确实现，原子直径40px，分子内原子间距根据分子结构计算
  3. 动画曲线：原子守恒连线使用 SVG 虚线，可添加 stroke-dashoffset 动画实现连线绘制效果
  4. 事件绑定：上一步/下一步按钮点击事件，更新 currentStep 后调用 renderStep() 重绘
  5. 高亮效果：使用 SVG filter 或外圈圆实现蓝色外发光效果
  6. ID 命名规范：所有元素 ID 以 scene1- 为前缀，如 scene1-atom-h、scene1-mol-ch4、scene1-prev-btn 等
  7. IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染

- 原子守恒连线具体路径（步骤6）：
  - 碳原子：scene1-atom-c-甲(150,160) → scene1-atom-c-丙(570,150)
  - 氧原子：scene1-atom-o-乙(250,240) → scene1-atom-o-丙(610,150)
  - 氢原子：甲的4个氢(150,120)(190,160)(150,200)(110,160) + 乙的2个氢(230,250)(270,250) → 3个H₂的6个氢
