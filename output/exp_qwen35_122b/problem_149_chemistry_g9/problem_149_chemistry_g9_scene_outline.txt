    **题目原文：**
    下图是某化学反应的微观模拟图，a b c 分别表示三种质子数不同的原子，请回答：

    （1）图乙中含有的粒子中属于反应生成的有_________种粒子
    （2）该反应属于_________反应（填基本反应类型）
    （3）写出一个和图中所示相符的化学反应方程式 __________

    **题目分析：**
    本题通过微观粒子模拟图考查学生对化学反应本质的理解。需要学生：
    1. 识别反应前后的粒子种类和数量变化
    2. 区分反应物、生成物和未反应的剩余物
    3. 判断反应类型（置换反应）
    4. 写出符合微观示意图的化学方程式

    **关键观察点：**
    - 图甲（反应前）：4 个 a₂分子 + 2 个 cb 分子
    - 图乙（反应后）：2 个 a₂分子（剩余）+ 2 个 a₂b 分子（生成）+ 2 个 c 原子（生成）
    - 实际参与反应：2 个 a₂分子 + 2 个 cb 分子 → 2 个 a₂b 分子 + 2 个 c 原子
    - 反应类型：置换反应（单质 + 化合物 → 新单质 + 新化合物）

    **图示规划：**
    设计 1 个交互式图示，通过分步按钮导航展示反应前后的粒子变化，帮助学生直观理解反应过程、识别生成物、判断反应类型。

    **图示 1 教学说明：**

    本图示通过微观粒子模拟展示化学反应的本质过程，教师应按以下步骤引导学生：

    **步骤 0-1：识别反应物**
    1. 引导学生观察图甲，识别两种反应物：a₂分子（单质）和 cb 分子（化合物）
    2. 提问："图甲中共有几种粒子？各有多少？"
    3. 高亮参与反应的粒子（2 个 a₂和 2 个 cb），强调并非所有粒子都参与反应

    **步骤 2-3：识别生成物**
    1. 展示图乙，引导学生对比反应前后粒子变化
    2. 提问："图乙中哪些粒子是新生成的？如何判断？"
    3. 关键判断依据：图甲中没有、图乙中出现的粒子即为生成物
    4. 结论：生成物有 2 种——a₂b 分子和 c 原子

    **步骤 4：判断反应类型**
    1. 引导学生分析反应物和生成物的类别
    2. 反应物：a₂（单质）+ cb（化合物）
    3. 生成物：a₂b（化合物）+ c（单质）
    4. 结论：单质 + 化合物 → 新单质 + 新化合物，属于**置换反应**

    **第（3）问：书写化学方程式**
    1. 根据微观示意图，反应实质为：a₂ + cb → a₂b + c
    2. 配平后：2a₂ + 2cb → 2a₂b + 2c（或简化为 a₂ + cb → a₂b + c）
    3. 举例说明符合该类型的实际反应：
       - H₂ + CuO → Cu + H₂O（氢气还原氧化铜）
       - Zn + 2HCl → ZnCl₂ + H₂↑（锌与盐酸反应）
       - Fe + CuSO₄ → FeSO₄ + Cu（铁与硫酸铜反应）

    **易错点提醒：**
    - 学生容易将剩余物误认为生成物，需强调"新生成"的判断标准
    - 置换反应的特征是"单换单"，即单质置换出化合物中的另一种单质
    - 书写方程式时要注意配平和物质状态符号
