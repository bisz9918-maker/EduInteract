    **题目原文：**
    如图所示，重为 50N 的物体 A 在拉力 F 作用下沿水平面做匀速直线运动．已知滑轮组机械效率为 80%，物体运动的速度为 1m/s，下列分析计算正确的是（  ）
    A．物体所受合力为 5N
    B．物体受到的摩擦力为 12N
    C．拉力 F 做功的功率为 5W
    D．在 10s 内机械所做的有用功为 500J

    **题目分析：**
    本题考查水平滑轮组的力学分析，核心知识点包括：
    1. 匀速直线运动的受力特点（合力为零）
    2. 滑轮组绳子段数 n 的判断
    3. 机械效率公式 η = W_有/W_总 = f/(nF)
    4. 功率计算 P = Fv
    5. 功的计算 W = Fs

    **整体讲解思路：**
    教师应先引导学生观察滑轮组结构，确定承担拉力的绳子段数 n=3，然后逐步分析各选项。重点在于理解水平滑轮组中，有用功是克服摩擦力做的功，而非提升重物做的功。

    **图示规划说明：**

    - Scene 1：滑轮组结构与受力分析（展示绳子段数、力的传递关系）
    - Scene 2：机械效率与功的计算推导（展示公式推导和数值计算过程）

    **Scene 1 教学说明：**

    **引导学生观察要点：**
    1. 首先让学生识别滑轮组类型：这是一个水平放置的滑轮组，用于克服摩擦力而非提升重物

    2. 绳子段数 n 的判断方法：
    - 数直接连接动滑轮的绳子段数
    - 从图中可清晰看到有 3 段绳子承担拉力，故 n=3

    3. 匀速直线运动的受力特点：
    - 物体做匀速直线运动 → 处于平衡状态 → 合力为 0
    - 水平方向：拉力通过滑轮组传递的力 = 摩擦力
    - 这是判断选项 A 的关键

    **关键公式推导：**
    对于水平滑轮组：
    - 总功：W_总 = F·s_绳 = F·n·s_物
    - 有用功：W_有 = f·s_物（克服摩擦力做功）
    - 机械效率：η = W_有/W_总 = (f·s_物)/(F·n·s_物) = f/(nF)

    **选项 A 分析：**
    物体做匀速直线运动，根据牛顿第一定律，合力为 0，故 A 错误。

    **选项 B 分析：**
    由 η = f/(nF) 得：
    f = η·n·F = 0.8 × 3 × 5N = 12N
    故 B 正确。

    **Scene 2 教学说明：**

    **计算步骤讲解：**

    1. **摩擦力计算（选项 B）：**
    由机械效率公式 η = W_有/W_总 = f·s_物/(F·s_绳) = f·s_物/(F·n·s_物) = f/(nF)
    代入数据：0.8 = f/(3×5)
    解得：f = 0.8×3×5 = 12N
    故选项 B 正确。

    2. **功率计算（选项 C）：**
    绳子自由端速度：v_绳 = n·v_物 = 3×1m/s = 3m/s
    拉力功率：P = F·v_绳 = 5N×3m/s = 15W
    故选项 C 错误（题目说 5W）。

    3. **10s 内有用功计算（选项 D）：**
    物体运动距离：s = v·t = 1m/s×10s = 10m
    有用功：W_有 = f·s = 12N×10m = 120J
    故选项 D 错误（题目说 500J）。

    **课堂讲解建议：**
    - 强调水平滑轮组与竖直滑轮组的区别：有用功是克服摩擦力做功，不是克服重力做功
    - 提醒学生注意绳子段数 n 的判断方法（数连接动滑轮的绳子段数）
    - 功率计算时注意区分 v_绳 和 v_物 的关系
    - 最终答案：B

    **易错点提醒：**
    1. 误认为有用功是克服重力做功（本题是水平运动，重力不做功）
    2. 绳子段数 n 数错（应数连接动滑轮的段数，不是总段数）
    3. 功率计算时忘记 v_绳 = n·v_物 的关系
    4. 机械效率公式记错（水平滑轮组：η = f/(nF)；竖直滑轮组：η = G/(nF)）
