- 步骤0（初始状态）：显示滑轮组完整结构（墙壁、两个滑轮、物体A、地面、三段绳子），显示顶部已知条件标签（η=80%、v=1m/s、G=50N）

- 步骤4（最终状态）：显示结论框，绿色高亮，内容为：
  - "✓ 匀速直线运动 → 合力为 0"
  - "✓ 选项 D 正确：10s内有用功 = 50N × 1m/s × 10s = 500J"
  - 其他选项错误原因简要标注

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步" 按钮：位置 (250,455)，作用：返回上一步骤，可复习之前内容
  - "下一步 ▶" 按钮：位置 (450,455)，作用：进入下一步骤，展示新的分析内容
  - 步骤指示器：位置 (350,420)，显示 "步骤 X / 5"
- 教师操作流程：
  1. 初始展示滑轮组结构，让学生观察并数绳子段数
  2. 点击"下一步"，高亮显示 n=3，确认绳子段数
  3. 点击"下一步"，显示拉力 F 和摩擦力 f 的方向
  4. 点击"下一步"，展示受力平衡分析
  5. 点击"下一步"，得出最终结论，引导学生判断选项

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │  η=80%  v=1m/s                              G=50N      │  y=120-165
  │                                                         │
  │  [墙壁]══○═══════════════○══════════[ 物体 A ]          │  y=150-320
  │          定滑轮    绳子    动滑轮                        │
  │                                                         │
  │  ←F=5N                                                  │  y=215-230
  │                                                         │
  │  ─────────────────────────────────────────────────────  │  y=350 地面
  │                          f→                             │  y=345
  │                                                         │
  │              步骤 X / 5                                 │  y=420
  │        [◀ 上一步]    [下一步 ▶]                         │  y=455
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-4) 跟踪当前步骤
  2. 元素显示控制：每个步骤对应的元素用 data-step 属性标记，通过 CSS display 控制显示/隐藏
  3. 坐标计算：所有元素使用绝对坐标，SVG 内定位
  4. 动画曲线：步骤切换使用 opacity 渐变 (0.3s ease)
  5. 事件绑定：按钮点击事件监听，更新 currentStep 并刷新显示
  6. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-wall, scene1-pulley-fixed, scene1-pulley-movable, scene1-obj-A, scene1-rope-1/2/3, scene1-arrow-F, scene1-arrow-f, scene1-label-n3, scene1-btn-prev, scene1-btn-next）
  7. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  8. 按钮状态：第一步时"上一步"按钮禁用，最后一步时"下一步"按钮禁用
