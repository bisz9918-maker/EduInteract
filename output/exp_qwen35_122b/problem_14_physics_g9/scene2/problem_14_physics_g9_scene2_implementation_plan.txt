[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "上一步"按钮：scene2-btn-prev，位于 (280,455)，点击返回上一状态
  - "下一步"按钮：scene2-btn-next，位于 (420,455)，点击进入下一状态
- 教师操作流程：
  1. 初始展示已知条件和滑轮组示意图，引导学生识别已知量
  2. 点击下一步，展示机械效率公式，讲解公式含义
  3. 点击下一步，展示摩擦力计算过程和结果，标记选项 B 正确
  4. 点击下一步，展示功率计算过程和结果，标记选项 C 错误
  5. 点击下一步，展示有用功计算过程和结果，标记选项 D 错误
  6. 点击下一步，展示完整选项判断结论，标记选项 A 错误
  7. 可随时点击上一步回退复习某个计算步骤

[技术实现]
- JS 库选择：原生 JavaScript + 原生 SVG，无需额外库，场景为静态布局 + 状态切换
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │  [已知条件框 250×140]        [公式推导区 250×40]  [滑轮组图]   │
  │  已知：                    η=f/(nF)           ┌───────┐       │
  │  F=5N                      (动态高亮)         │ 滑轮  │       │
  │  η=80%                                         │ 组   │       │
  │  v=1m/s                                        └───────┘       │
  │  n=3                                          (右上)          │
  │                                                                │
  │  [计算过程区 250×100]        [选项判断区 240×115]             │
  │  f=12N                     ┌────┐ ┌────┐                      │
  │  P=15W                     │ A  │ │ B  │                      │
  │  W=120J                    │ ×  │ │ √  │                      │
  │                            └────┘ └────┘                      │
  │                            ┌────┐ ┌────┐                      │
  │                            │ C  │ │ D  │                      │
  │                            │ ×  │ │ ×  │                      │
  │                            └────┘ └────┘                      │
  │                                                                │
  │                    [◀上一步]  [下一步▶]                        │
  └────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：currentStep 变量 (0-5)，控制各区域显示内容
  2. 坐标计算：所有元素使用绝对定位，坐标按布局坐标表精确设置
  3. 动画曲线：步骤切换使用淡入淡出效果 (opacity 0→1，200ms)
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后重绘各区域
  5. 高亮逻辑：当前步骤公式框边框加粗 (3px)，其他公式框边框正常 (2px)
  6. 选项标记：根据步骤动态显示√或×标记，使用不同颜色区分
- ID 命名规范：所有交互元素 ID 以 scene2- 为前缀（如 scene2-knowledge-box、scene2-formula-η、scene2-btn-prev、scene2-btn-next）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局污染
