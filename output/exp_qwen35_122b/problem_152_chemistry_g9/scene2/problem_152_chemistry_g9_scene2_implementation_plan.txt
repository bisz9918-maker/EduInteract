[图示主题与整合说明]
- 本图示主题：测定空气中氧气含量实验过程动态演示
- 整合内容：红磷燃烧、气体消耗、冷却、水倒吸的完整实验过程
- 教学价值：教师可通过分步演示，让学生直观理解实验原理——红磷燃烧消耗氧气导致瓶内气压降低，冷却后打开止水夹，外界大气压将水压入集气瓶，进入的水的体积即为消耗氧气的体积

[分步序列]
步骤0（初始状态）：
- 显示：集气瓶（内有少量水至瓶底）、燃烧匙内红磷、导管连接、止水夹关闭、烧杯内水
- 隐藏：火焰、白烟、集气瓶内上升水位、导管内水流、气压箭头
- 止水夹颜色：#c62828红色（关闭）
- 水位：集气瓶内水位在瓶底（y=350）

步骤1（点燃红磷，瓶内燃烧）：
- 新增：红磷上方显示火焰（#ff5722渐变，闪烁动画）
- 红磷逐渐变小（透明度降低）
- 止水夹保持关闭（红色）
- 其他同步骤0

步骤2（燃烧结束，白烟产生）：
- 火焰消失
- 红磷消失
- 新增：瓶内弥漫白烟（#888888灰色粒子群，随机分布）
- 白烟标签显示
- 止水夹保持关闭（红色）

步骤3（冷却至室温）：
- 白烟逐渐沉淀（透明度降低，向下移动）
- 新增：瓶内气压箭头（#888888灰色，从瓶壁向中心收缩，表示气压降低）
- 气压标签"气压↓"显示在箭头旁
- 止水夹保持关闭（红色）

步骤4（打开止水夹）：
- 止水夹颜色变为#2e7d32绿色（打开状态）
- 止水夹标签"止水夹（开）"显示
- 白烟继续沉淀
- 气压箭头保持显示

步骤5（水倒吸入集气瓶）：
- 新增：导管内水流箭头（#1565c0蓝色，从烧杯指向集气瓶）
- 集气瓶内水位从y=350逐渐上升至y=320（刻度1处）
- 烧杯内水位略微下降
- 水位上升动画（0.5秒过渡）

步骤6（结论）：
- 水位稳定在刻度1处
- 新增：结论文字"氧气约占空气体积的1/5"显示在画布上方
- 刻度1处高亮（#ff9800橙色边框）
- 所有元素稳定显示

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮（scene2-btn-prev）：位于控件栏左侧，点击返回前一步骤，步骤0时禁用（灰色）
  - 下一步按钮（scene2-btn-next）：位于控件栏右侧，点击进入下一步骤，步骤6时禁用
  - 步骤指示器（scene2-step-indicator）：位于控件栏中央，显示"步骤 X/7"
- 教师操作流程：
  1. 图示加载后显示初始状态（步骤0），教师讲解实验装置
  2. 点击"下一步"→步骤1，讲解点燃红磷
  3. 点击"下一步"→步骤2，讲解燃烧产生白烟（五氧化二磷）
  4. 点击"下一步"→步骤3，讲解冷却和气压变化
  5. 点击"下一步"→步骤4，讲解打开止水夹
  6. 点击"下一步"→步骤5，讲解水倒吸现象
  7. 点击"下一步"→步骤6，总结结论：氧气约占空气体积1/5
  8. 可随时点击"上一步"回退复习某一步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何和状态切换，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │                        图示区 800×500                          │
  │                                                                │
  │   [集气瓶]                    [导管]        [烧杯]             │
  │   ┌─────┐                     ─────         ┌─────┐           │
  │   │  ○  │◄───────止水夹──────►│             │ 水  │           │
  │   │ 燃烧 │                     │             │     │           │
  │   │ 匙   │                     │             └─────┘           │
  │   └──┬──┘                     │                               │
  │      │ 刻度1234               │                               │
  │      │ 水位                   │                               │
  │      └────────────────────────┘                               │
  │                                                                │
  │   [控件栏 y=440~490]                                          │
  │   ┌────────┐  步骤 X/7  ┌────────┐                            │
  │   │ 上一步 │            │ 下一步 │                            │
  │   └────────┘            └────────┘                            │
  └────────────────────────────────────────────────────────────────┘
  ```

- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-6) 跟踪当前步骤
  2. 元素显示控制：每个步骤对应一组元素的 show/hide 状态，使用 CSS class "step-N" 标记
  3. 坐标计算：所有元素使用绝对定位，坐标已在布局坐标表中精确定义
  4. 动画曲线：水位上升使用 CSS transition (0.5s ease)，火焰使用 CSS animation (闪烁)
  5. 事件绑定：按钮点击事件更新 currentStep，调用 updateDisplay() 刷新显示
  6. ID 命名规范：所有元素 ID 以 scene2- 为前缀（如 scene2-jar、scene2-flame、scene2-btn-prev）
  7. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  8. 按钮禁用状态：步骤0时上一步按钮 disabled，步骤6时下一步按钮 disabled

- updateDisplay() 函数逻辑：
  ```javascript
  function updateDisplay() {
    // 更新步骤指示器
    document.getElementById('scene2-step-indicator').textContent = `步骤 ${currentStep + 1}/7`;
    
    // 更新按钮状态
    document.getElementById('scene2-btn-prev').disabled = (currentStep === 0);
    document.getElementById('scene2-btn-next').disabled = (currentStep === 6);
    
    // 根据 currentStep 显示/隐藏元素
    // 示例：火焰只在步骤1显示
    document.getElementById('scene2-flame').style.display = (currentStep === 1) ? 'block' : 'none';
    // 示例：止水夹颜色
    document.getElementById('scene2-clip').setAttribute('fill', currentStep >= 4 ? '#2e7d32' : '#c62828');
    // ... 其他元素状态更新
  }
  ```
