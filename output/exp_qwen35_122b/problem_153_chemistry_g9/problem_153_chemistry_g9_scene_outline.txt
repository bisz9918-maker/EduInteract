    **题目原文**：
    现有氢气、氮气、氯化氢、水蒸汽、一氧化碳和二氧化碳混合气体，依次通过下图A、B、C、D装置（假设每步都充分反应），各装置依次除去的气体和最后得到的气体分别是（  ）

    **题目分析**：
    本题考察气体除杂实验装置的理解，涉及四个串联装置：
    1. 装置A：碳酸氢钠溶液洗气瓶——吸收酸性气体HCl
    2. 装置B：加热的氧化铜硬质玻璃管——氧化还原性气体H₂和CO
    3. 装置C：澄清石灰水洗气瓶——吸收二氧化碳CO₂
    4. 装置D：浓硫酸洗气瓶——吸收水蒸气H₂O

    **整体讲解思路**：
    教师应引导学生按气体流动方向（从左到右）依次分析每个装置的作用，理解"除杂"与"转化"的区别，最终确定剩余气体为氮气。

    **图示规划说明**：
    本套图示包含2个场景：
    - Scene 1：完整装置串联图，展示气体流向和各装置位置关系
    - Scene 2：分步除杂过程演示，通过按钮导航逐步展示每个装置除去的成分

    <TEXT_3>
    **图示2教学说明**：

    本图示通过分步导航展示除杂全过程，教师应按以下步骤讲解：

    **步骤0：初始状态**
    展示混合气体成分：H₂、N₂、HCl、H₂O、CO、CO₂六种气体

    **步骤1：装置A（碳酸氢钠溶液）**
    - 除去：HCl（氯化氢）
    - 原理：HCl + NaHCO₃ → NaCl + H₂O + CO₂
    - 注意：此处会生成少量CO₂，但不影响后续处理

    **步骤2：装置B（加热氧化铜）**
    - 除去：H₂、CO（还原性气体）
    - 原理：H₂ + CuO → Cu + H₂O；CO + CuO → Cu + CO₂
    - 关键：H₂和CO被氧化，分别生成H₂O和CO₂，这两种产物将在后续装置中被除去

    **步骤3：装置C（澄清石灰水）**
    - 除去：CO₂（包括原有的和B中生成的）
    - 原理：CO₂ + Ca(OH)₂ → CaCO₃↓ + H₂O
    - 现象：石灰水变浑浊

    **步骤4：装置D（浓硫酸）**
    - 除去：H₂O（包括原有的和B中生成的）
    - 原理：浓硫酸吸水性（物理变化）

    **步骤5：最终结果**
    - 剩余气体：N₂（氮气）
    - 原因：氮气化学性质稳定，不与上述任何试剂反应

    **答案**：选项C（HCl、CO、H₂、H₂O、CO₂、N₂）
    </TEXT_3>

    <TEXT_4>
    **课堂讲解建议**：

    1. **先整体后局部**：先用Scene 1建立装置串联的整体印象，再用Scene 2深入讲解每个步骤

    2. **强调顺序重要性**：除杂顺序不可颠倒，如先除H₂O再除CO₂会导致水蒸气再次混入

    3. **区分"除去"与"转化"**：装置B不是直接除去H₂和CO，而是将其转化为H₂O和CO₂，再在后续装置中除去

    4. **易错点提醒**：
    - 装置B加热条件下反应，常温下H₂、CO不与CuO反应
    - 装置C石灰水变浑浊是CO₂的特征反应
    - 浓硫酸只能吸水，不能吸收其他气体

    5. **拓展思考**：若改变装置顺序，哪些气体可能无法完全除去？
