[分步序列]
- 步骤0（初始状态）：显示所有四个装置（A、B、C、D）的完整结构、试剂名称标注、气体流向箭头（灰色#888880），入口标注"混合气体→"，出口标注"→N₂"（灰色）。等待教师点击"下一步"开始讲解。

- 步骤1：高亮装置A（边框#1565c0加粗至4px），气体流向箭头变为蓝高亮#1565c0，在装置A右侧显示红高亮#c62828标注"除去HCl"，入口箭头高亮。讲解：混合气体首先通过碳酸氢钠溶液，除去氯化氢气体。

- 步骤2：高亮装置B（边框#1565c0加粗至4px），酒精灯火焰高亮，气体流向箭头蓝高亮，在装置B右侧显示红高亮#c62828标注"除去H₂、CO"。讲解：气体通过加热的氧化铜，氢气和一氧化碳被氧化除去。

- 步骤3：高亮装置C（边框#1565c0加粗至4px），气体流向箭头蓝高亮，在装置C右侧显示红高亮#c62828标注"除去CO₂"。讲解：气体通过澄清石灰水，二氧化碳被吸收除去。

- 步骤4：高亮装置D（边框#1565c0加粗至4px），气体流向箭头蓝高亮，在装置D右侧显示红高亮#c62828标注"除去H₂O"。讲解：气体通过浓硫酸，水蒸气被吸收除去。

- 步骤5（最终状态）：所有装置边框恢复正常，出口标注"→N₂"变为绿高亮#2e7d32加粗，在出口处显示绿高亮标注"最终剩余：N₂"。讲解：经过四步除杂后，最终剩余的气体是氮气。

  - 按钮"上一步"：位于(260,455)-(350,485)，点击返回上一步骤

  - 步骤指示器：位于(360,460)-(400,480)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始展示全景，让学生观察四个装置的串联结构
  2. 点击"下一步"依次高亮每个装置，讲解该装置的除杂作用
  3. 每步配合红高亮标注被除去的气体
  4. 最后一步用绿高亮展示最终剩余气体
  5. 可随时点击"上一步"回退复习

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌────────────────────────────────────────────────────────────────┐
  │  混合气体→  [A]====>[B]====>[C]====>[D]====>→N₂              │
  │           洗气瓶  玻璃管  洗气瓶  洗气瓶                        │
  │           NaHCO₃  CuO    Ca(OH)₂  浓H₂SO₄                      │
  │                                                                │
  │                                                                │
  │                                                                │
  │                                                                │
  │                   [上一步]  步骤X/5  [下一步]                   │
  └────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：currentStep变量(0-5)，updateScene()函数根据currentStep更新高亮状态
  2. 坐标计算：所有元素使用绝对坐标，SVG元素通过setAttribute更新
  3. 动画曲线：高亮效果使用CSS transition(0.3s ease)实现平滑过渡
  4. 事件绑定：按钮点击事件监听，更新currentStep后调用updateScene()
  5. ID命名规范：所有元素ID以"scene1-"为前缀（如scene1-device-a、scene1-arrow-1等）
  6. IIFE隔离：所有JS代码包裹在(function() { ... })()中，避免全局污染
  7. 高亮实现：通过添加/移除CSS类(highlight-blue、highlight-red、highlight-green)控制元素样式
  8. 步骤指示器：实时更新文本内容显示"步骤 X/5"
