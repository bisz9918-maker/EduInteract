[分步序列]
- 步骤 0（初始状态）：
  * 显示反应前方框及内部 5 个分子（4 个 A₂ + 1 个 B₂）
  * 显示反应箭头
  * 显示"反应前"、"反应后"标签
  * 显示 A 原子、B 原子图例
  * 反应后方框为空（仅显示边框）

- 步骤 1（展示反应后）：
  * 在反应后方框内显示 4 个分子（2 个 AB₂ + 2 个 A₂剩余）
  * 其他元素保持不变
  * 视觉变化：右侧方框内出现分子

- 步骤 2（高亮实际反应分子）：
  * 在反应前区域：2 个 A₂分子（左上、中上）和 1 个 B₂分子用蓝色边框高亮（#1565c0）
  * 在反应前区域：2 个 A₂剩余分子（左下、右下）用红色虚线边框标记（#c62828）
  * 在反应后区域：2 个 AB₂分子用绿色半透明填充高亮（#2e7d32，opacity 0.2）
  * 在反应后区域：2 个 A₂剩余分子用红色虚线边框标记（#c62828）
  * 视觉变化：添加高亮效果，帮助学生区分参加反应与未反应的分子

- 步骤 3（总结反应类型）：
  * 在图示下方显示反应方程式："2A₂ + B₂ → 2AB₂"
  * 在方程式下方显示结论："化合反应：两种物质生成一种物质"
  * 高亮效果保持显示
  * 视觉变化：添加文字结论

- 教师操作流程：

  2. 点击"下一步"展示反应后状态，引导学生对比前后变化

  5. 可随时点击"上一步"回退复习关键步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  * 原因：分子结构为简单几何图形（圆形组合），SVG 最适合绘制此类矢量图形，且易于控制每个元素的显示/隐藏和高亮效果
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │                        800px                                   │
  │  ┌──────────────┐      ←→      ┌──────────────┐               │
  │  │  反应前      │   反应       │   反应后     │               │
  │  │  [4A₂+1B₂]   │              │  [2AB₂+2A₂]  │   500px       │
  │  │              │              │              │               │
  │  └──────────────┘              └──────────────┘               │
  │       反应前                          反应后                   │
  │                                                                │
  │  ○ A原子  ● B原子                                              │
  │                                                                │
  │         2A₂ + B₂ → 2AB₂                                       │
  │      化合反应：两种物质生成一种物质                            │
  │                                                                │
  │         [◀ 上一步]        [下一步 ▶]                           │
  └────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-3) 跟踪当前步骤
  2. 坐标计算：分子位置在方框内均匀分布，使用固定坐标确保一致性
  3. 动画曲线：高亮效果使用 CSS transition 实现平滑过渡（0.3s ease）
  4. 事件绑定：按钮点击事件更新 currentStep，根据步骤显示/隐藏对应元素
  5. 元素 ID 命名：所有元素 ID 以 scene1- 为前缀（如 scene1-box-left, scene1-mol-a2-1）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 高亮实现：通过添加/移除 CSS class 实现边框颜色和填充效果变化
