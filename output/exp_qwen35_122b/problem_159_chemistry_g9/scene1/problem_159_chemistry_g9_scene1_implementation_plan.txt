  4. 点击下一步，展示错误原因，总结知识点

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何和状态切换，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │                        图示区 800×500                          │
  │                                                                │
  │  ┌────────────────────┐           ┌──────────────────────┐    │
  │  │   坐标系区         │           │   右侧分析区         │    │
  │  │   (50,50)-(450,350)│           │   (500,50)-(780,350) │    │
  │  │                    │           │                      │    │
  │  │   纵轴↑            │           │   [化学方程式]       │    │
  │  │   │   原图───→     │           │   [错误原因]         │    │
  │  │   │   正确───→     │           │                      │    │
  │  │   └────────→横轴   │           │                      │    │
  │  └────────────────────┘           └──────────────────────┘    │
  │                                                                │
  │  ┌────────────────────────────────────────────────────────┐   │
  │  │              控件栏 (y=440~490)                        │   │
  │  │    状态：0/3    [◀ 上一步]  [下一步 ▶]                │   │
  │  └────────────────────────────────────────────────────────┘   │
  └────────────────────────────────────────────────────────────────┘
  ```

- 关键实现要点：
  1. 状态机设计：用变量 currentState (0-3) 跟踪当前状态，updateDisplay() 函数根据状态显示/隐藏对应元素
  2. 坐标计算：所有元素使用绝对像素坐标，SVG 元素用 id 命名便于操作
  3. 动画曲线：状态切换使用 opacity 过渡 (0.3s ease) 实现淡入淡出效果
  4. 事件绑定：按钮点击事件调用 changeState(delta) 函数，更新状态并刷新显示
  5. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-curve-original、scene1-btn-next）
  6. IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局污染

- 元素 ID 命名列表：
  - scene1-axis-x、scene1-axis-y（坐标轴）
  - scene1-label-xaxis、scene1-label-yaxis、scene1-label-origin（轴标签）
  - scene1-curve-original、scene1-label-original（原图曲线）
  - scene1-curve-correct、scene1-label-correct（正确曲线）
  - scene1-box-equation、scene1-text-equation（方程式区）
  - scene1-box-reason、scene1-text-reason-title、scene1-text-reason-1/2/3（原因区）
  - scene1-status-text（状态指示）
  - scene1-btn-prev、scene1-btn-next（按钮）
  - scene1-controls-bg（控件栏背景）

- 状态显示逻辑：
  - 状态 0：显示坐标系 + 原图曲线
  - 状态 1：状态 0 元素 + 方程式区
  - 状态 2：状态 1 元素 + 正确曲线
  - 状态 3：状态 2 元素 + 原因区
