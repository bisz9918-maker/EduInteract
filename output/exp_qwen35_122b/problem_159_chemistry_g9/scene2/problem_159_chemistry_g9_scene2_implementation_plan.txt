[分步序列]
- 初始状态（步骤 0）：显示坐标系 + 原图曲线（蓝色直线从(60,100)下降到(440,350)），右侧显示"选项 B：加热高锰酸钾制氧气"标题
- 步骤 1：点击「化学方程式」→ 右侧显示化学方程式"2KMnO₄ → K₂MnO₄ + MnO₂ + O₂↑"，方程式下方标注"固体产物：K₂MnO₄ + MnO₂"
- 步骤 2：点击「正确曲线」→ 左侧显示正确曲线（绿色折线：从(60,100)下降到(250,250)后水平延伸至(440,250)），原图曲线变淡或隐藏
- 步骤 3：点击「错误原因」→ 右侧显示错误原因分析："错误：固体质量不会降为 0！正确：反应后剩余固体为 K₂MnO₄和 MnO₂，质量不为 0"，同时高亮正确曲线的水平段

[交互方案]
- 交互类型：多状态切换（4 个按钮）
- 控件说明：
  - 按钮 1「原图曲线」：位置 (50,420)，显示原图蓝色直线曲线
  - 按钮 2「化学方程式」：位置 (140,420)，显示化学反应方程式
  - 按钮 3「正确曲线」：位置 (230,420)，显示绿色正确曲线
  - 按钮 4「错误原因」：位置 (320,420)，显示错误原因分析文字
- 教师操作流程：
  1. 点击「原图曲线」展示题目中的错误曲线
  2. 点击「化学方程式」讲解反应原理
  3. 点击「正确曲线」对比正确图像
  4. 点击「错误原因」总结错误点，强化记忆

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单曲线绘制，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │                        800 × 500 画布                          │
  │                                                                │
  │  ┌──────────────────────┐    ┌─────────────────────────────┐  │
  │  │   坐标系 + 曲线      │    │      方程式/分析区          │  │
  │  │   (50,50)-(450,380)  │    │      (500,100)-(750,400)    │  │
  │  │                      │    │                             │  │
  │  │   y 轴               │    │   2KMnO₄ → ...              │  │
  │  │   │  原图/正确曲线   │    │   错误原因分析文字          │  │
  │  │   │                  │    │                             │  │
  │  │   └─────────x 轴     │    │                             │  │
  │  └──────────────────────┘    └─────────────────────────────┘  │
  │                                                                │
  │  [原图] [方程式] [正确] [错误原因]  ← 状态切换按钮 (y=420)     │
  └────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep 记录当前状态 (0-3)，点击按钮时更新状态并刷新视图
  2. 曲线绘制：原图曲线用直线 path "M 60,100 L 440,350"；正确曲线用折线 path "M 60,100 L 250,250 L 440,250"
  3. 元素显示控制：用 CSS class "hidden" 控制元素显隐，激活状态按钮添加 "active" class
  4. 坐标计算：y 轴 60~350 对应质量 0~初始值，x 轴 60~440 对应时间 0~反应结束
  5. ID 命名规范：所有元素 ID 以 "scene2-" 为前缀（如 scene2-curve-original、scene2-curve-correct、scene2-btn-0 等）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 按钮激活态：点击按钮时移除其他按钮的 active 类，添加当前按钮的 active 类
