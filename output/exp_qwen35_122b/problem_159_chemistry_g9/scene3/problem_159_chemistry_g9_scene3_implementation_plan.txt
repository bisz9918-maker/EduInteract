[分步序列]
- 初始状态（状态 0）：
  - 显示：完整坐标系、三段曲线（蓝高亮）、坐标轴标签、原点
  - 隐藏：阶段标注框、化学方程式、CO₂标注、正确标记
  - 标题："原图曲线"
  - 用途：展示题目原图，让学生观察曲线特征

- 状态 1：
  - 显示：状态 0 所有元素 + 化学方程式区域 + 化学方程式"CaCO₃ △→ CaO + CO₂↑"
  - 隐藏：阶段标注框、CO₂标注、正确标记
  - 标题："化学方程式"
  - 用途：展示反应原理，建立曲线与化学反应的联系

- 状态 2：
  - 显示：状态 1 所有元素 + 阶段①标注框 + "加热初期"文字
  - 高亮：曲线段①（加粗或闪烁）
  - 标题："阶段 1 分析"
  - 用途：解释第一阶段曲线水平的原因——加热初期尚未达到分解温度，固体质量不变

- 状态 3：
  - 显示：状态 2 所有元素 + 阶段②标注框 + "分解进行"文字 + CO₂逸出标注（红色）
  - 高亮：曲线段②（加粗或闪烁）
  - 标题："阶段 2 分析"
  - 用途：解释第二阶段曲线下降的原因——CaCO₃分解产生 CO₂气体逸出，固体质量减少

- 状态 4：
  - 显示：状态 3 所有元素 + 阶段③标注框 + "反应完成"文字 + 正确标记"✓"（绿色）
  - 高亮：曲线段③（加粗或闪烁）
  - 标题："阶段 3 分析"
  - 用途：解释第三阶段曲线水平的原因——CaCO₃完全分解，剩余 CaO 固体质量恒定；验证选项 C 正确

[交互方案]
- 交互类型：多状态切换（5 个状态，通过上一步/下一步按钮导航）
- 控件说明：
  - "上一步"按钮 (scene3-btn-prev)：位于底部中央偏左，点击切换到前一个状态，初始状态时禁用
  - "下一步"按钮 (scene3-btn-next)：位于底部中央偏右，点击切换到下一个状态，最终状态时禁用
- 教师操作流程：
  1. 初始展示原图曲线，引导学生观察曲线特征（三段式）
  2. 点击"下一步"展示化学方程式，建立反应原理认知
  3. 点击"下一步"逐阶段分析：阶段 1（加热初期质量不变）→ 阶段 2（分解进行质量减少）→ 阶段 3（反应完成质量恒定）
  4. 最终状态显示绿色正确标记，验证选项 C 正确
  5. 可随时点击"上一步"回退复习，强化理解

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（线段、矩形、文本），无需复杂绘图库；原生实现轻量高效
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │                        状态标题 (320,30)                        │
  │                                                                │
  │  ┌─────────────────────────────┐  ┌──────────────────────┐    │
  │  │                             │  │   化学方程式区域      │    │
  │  │      坐标系 (50,50)         │  │   (560,80)           │    │
  │  │                             │  │   CaCO₃ → CaO+CO₂↑   │    │
  │  │   纵轴                      │  │                      │    │
  │  │   ↑                         │  │   ✓ 正确标记         │    │
  │  │   │    曲线                 │  └──────────────────────┘    │
  │  │   │   ──┐                   │                              │
  │  │   │      └───               │                              │
  │  │   └────────────────→        │                              │
  │  │      横轴                   │                              │
  │  └─────────────────────────────┘                              │
  │                                                                │
  │   阶段①     阶段②      阶段③                                  │
  │  (120,100) (250,180)  (380,230)                               │
  │                                                                │
  ├────────────────────────────────────────────────────────────────┤
  │                    控件栏 (y=440~490)                          │
  │                        [上一步] [下一步]                       │
  └────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 currentState (0-4) 跟踪当前状态，updateDisplay() 函数根据 currentState 显示/隐藏对应元素
  2. 坐标计算：所有元素坐标严格按布局坐标表实现，使用 SVG 绝对定位
  3. 动画曲线：阶段高亮使用 CSS transition，line-width 从 2px 过渡到 4px，duration 0.3s
  4. 事件绑定：按钮点击事件监听，更新 currentState 后调用 updateDisplay()，同时更新按钮禁用状态
  5. 文本渲染：化学方程式下标使用 <tspan baseline-shift="sub" font-size="70%">₃</tspan> 实现
  6. 垂直文本：纵轴标签"固体质量/g"使用 transform="rotate(-90)" 实现垂直排列
- ID 命名规范：所有交互元素 ID 以 scene3- 为前缀
  - 曲线：scene3-curve
  - 阶段标注框：scene3-stage1-box, scene3-stage2-box, scene3-stage3-box
  - 阶段文字：scene3-stage1-text, scene3-stage2-text, scene3-stage3-text
  - 化学方程式：scene3-equation
  - CO₂标注：scene3-co2-label
  - 正确标记：scene3-correct-mark
  - 按钮：scene3-btn-prev, scene3-btn-next
  - 状态标题：scene3-status-title
- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染
