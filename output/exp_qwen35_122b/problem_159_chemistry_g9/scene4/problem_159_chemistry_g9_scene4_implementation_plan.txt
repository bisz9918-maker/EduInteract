[视觉元素清单]

- 正确曲线：SVG 路径，绿色 (#2e7d32)，线宽 3px，从 (80,100) 到 (370,320) 的下降曲线（正确）

[分步序列]
- 初始状态（步骤 0）：显示坐标系、原图蓝色上升曲线、"原图"标签、右侧说明区显示"气体溶解度规律"
- 步骤 1：点击「溶解度规律」→ 右侧说明区高亮显示"气体溶解度随温度升高而降低"，添加辅助虚线说明趋势
- 步骤 2：点击「正确曲线」→ 显示绿色下降曲线（正确曲线），隐藏原图曲线或变淡，"正确"标签出现
- 步骤 3：点击「错误原因」→ 原图曲线位置显示红色"×"标记，右侧显示错误原因分析文字

  4. 点击「错误原因」总结原图错在哪里

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │                    图示区 800×500                              │
  │  ┌─────────────────────┐  ┌─────────────────────────────────┐  │
  │  │   坐标系区域        │  │      说明文字区域               │  │
  │  │   (40,40)-(450,420) │  │      (480,50)-(780,380)         │  │
  │  │                     │  │                                 │  │
  │  │   y                 │  │   气体溶解度规律                │  │
  │   │  ↑                │  │   气体溶解度随温度升高而降低     │  │
  │   │  │  原图(蓝)↗     │  │                                 │  │
  │   │  │  正确(绿)↘     │  │   错误原因分析                  │  │
  │   │  │                │  │   原图曲线上升，与实际规律相反   │  │
  │   │  └────────→x      │  │                                 │  │
  │  └─────────────────────┘  └─────────────────────────────────┘  │
  │                                                                 │
  │  ┌─────────────────────────────────────────────────────────┐   │
  │  │  [原图曲线] [溶解度规律] [正确曲线]                      │   │
  │  │  [错误原因]                                              │   │
  │  └─────────────────────────────────────────────────────────┘   │
  └────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 currentStep 记录当前状态 (0-3)
  2. 曲线绘制：使用 SVG <path>元素，d 属性定义曲线路径
  3. 状态切换：点击按钮时更新 currentStep，显示/隐藏对应元素
  4. 按钮高亮：当前状态按钮添加 active 类，改变背景色
  5. ID 命名规范：所有元素 ID 以 scene4- 为前缀（如 scene4-curve-original、scene4-btn-0）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 曲线坐标计算：
     - 原图曲线（错误）：起点 (80,320)，终点 (370,100)，使用贝塞尔曲线模拟上升
     - 正确曲线：起点 (80,100)，终点 (370,320)，使用贝塞尔曲线模拟下降
- 颜色规范：
  - 背景：#ffffff
  - 主线：#000000
  - 原图曲线（蓝高亮）：#1565c0
  - 错误标记（红高亮）：#c62828
  - 正确曲线（绿高亮）：#2e7d32
  - 辅助线：#888888 虚线
  - 说明区背景：#f5f5f5
