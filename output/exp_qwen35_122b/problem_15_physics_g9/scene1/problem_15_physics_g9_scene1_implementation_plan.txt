[图示主题与整合说明]
- 本图示主题：两种放置方式的受力对比分析（叠放 vs 并放）
- 整合内容：图甲（叠放）与图乙（并放）的完整对比，包括木块位置、推力方向、速度标注、受力分析箭头

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：位于(280,450)，100×35px，点击返回上一步骤，步骤0时禁用
  - "下一步 ▶"按钮：位于(420,450)，100×35px，点击进入下一步骤，步骤4时禁用
- 教师操作流程：
  1. 初始展示两种摆放方式，让学生观察差异
  2. 点击"下一步"展示推力，强调 F₁=100N 已知，F₂待求
  3. 点击"下一步"展示速度，引导学生注意速度不同
  4. 点击"下一步"进行受力分析，讲解正压力和摩擦力
  5. 点击"下一步"展示结论，强调匀速运动时推力=摩擦力，且滑动摩擦力与速度无关

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌────────────────────────────────────────────────────────────┐
  │                                                            │
  │    图甲区域(50-400)              图乙区域(450-800)         │
  │    ┌─────────────┐              ┌─────────────┐            │
  │    │   B         │              │ A │ B       │            │
  │    │  ┌─────┐    │              └───┴─────────┘            │
  │    │  │  A  │    │              F₂→                        │
  │    │  └─────┘    │              ─────────────────          │
  │    F₁→          │              地面                         │
  │    ───────────  │                                          │
  │    地面         │                                          │
  │                                                            │
  │                                                            │
  │                                                            │
  │         [◀ 上一步]        [下一步 ▶]                       │
  └────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：currentStep 变量（0-4），控制各元素显示/隐藏
  2. 坐标计算：所有元素按布局坐标表精确实现
  3. 动画曲线：元素出现使用 opacity 渐变（0→1，duration=300ms）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 并刷新显示
  5. ID 命名规范：所有元素 ID 以"scene1-"为前缀（如 scene1-block-a-left、scene1-arrow-f1）
  6. IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局污染
  7. 元素分组：使用 SVG <g> 元素按步骤分组，便于批量控制显示/隐藏
