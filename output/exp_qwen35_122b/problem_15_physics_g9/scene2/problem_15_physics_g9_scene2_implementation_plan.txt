[图示主题与整合说明]
- 本图示主题：滑动摩擦力公式推导与结论验证
- 整合内容：滑动摩擦力公式 f = μN、两种情况（叠放与并放）的正压力计算、摩擦力比较、最终结论
- 教学价值：教师可通过分步导航引导学生理解滑动摩擦力与速度无关、只与正压力有关的物理规律，通过对比两种放置方式的正压力相同，推导出 F₂ = F₁ = 100N 的结论

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何和动画，无需复杂库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │  滑动摩擦力公式：f = μN                                    │  y=20~100
  ├─────────────────────────────────────────────────────────────┤
  │  ┌───────────────┐              ┌───────────────┐           │  y=120~320
  │  │    图甲       │              │    图乙       │           │
  │  │   [B]         │              │  [A][B]       │           │
  │  │   [A]  →F₁    │              │   →F₂         │           │
  │  │   ↓N₁ ←f₁     │              │  ↓N₂↓N₂'←f₂←f₂'│           │
  │  │  ───────────  │              │  ───────────  │           │
  │  └───────────────┘              └───────────────┘           │
  ├─────────────────────────────────────────────────────────────┤
  │  推导区：f = μN → f₁ = 100N → f₂ = μN₁ = f₁ → F₂ = 100N    │  y=350~410
  ├─────────────────────────────────────────────────────────────┤
  │              [F₂ = 100N (选项 B)]                           │  y=410~460
  ├─────────────────────────────────────────────────────────────┤
  │        [◀ 上一步]                        [下一步 ▶]         │  y=470~500
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-5) 跟踪当前步骤，每一步定义要显示/高亮的元素 ID 列表
  2. 坐标计算：所有元素用绝对坐标，SVG 内使用 viewBox="0 0 800 500"
  3. 动画曲线：元素出现用 opacity 从 0 到 1 的过渡动画（duration=300ms）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateScene() 刷新显示
  5. ID 命名规范：所有元素 ID 以 scene2- 为前缀（如 scene2-block-a-1、scene2-arrow-f1、scene2-eq-1 等）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 元素显示控制：用 display="none" 或 opacity 控制元素可见性，逐步显示
  8. 高亮效果：关键等式用 stroke 或 fill 颜色变化实现高亮
