[图示主题与整合说明]
- 本图示主题：楼房平面图周长计算的"平移法"演示
- 整合内容：整合了原图展示、水平边关系分析、垂直边关系分析、周长计算四个认知步骤
- 教学价值：教师可通过分步演示，引导学生理解"平移法"的核心思想——将不规则图形的边通过平移转化为规则矩形的边，从而简化周长计算。从直观感知到抽象计算，逐步建立几何推理能力。

步骤2（垂直边对齐分析）：

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 按钮"◀ 上一步"：位于(260,455)-(380,480)，灰色#9e9e9e，点击返回上一步骤，步骤0时禁用
  - 按钮"下一步 ▶"：位于(420,455)-(540,480)，蓝色#1565c0，点击进入下一步骤，步骤3时禁用
- 教师操作流程：
  1. 初始展示图形和已知条件，让学生观察图形结构
  2. 点击"下一步"进入步骤1，讲解水平边的平移关系（h+f+d=b）
  3. 点击"下一步"进入步骤2，讲解垂直边的对齐关系（a=c, e=g）
  4. 点击"下一步"进入步骤3，展示完整计算过程和答案
  5. 如需复习某一步骤，可点击"上一步"回退

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（线段组合），无需复杂绘图库；原生 SVG 便于精确控制坐标和样式；原生 JS 足以实现状态切换


- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-3) 跟踪当前步骤
  2. 坐标计算：所有元素坐标硬编码，确保精确对齐
  3. 样式切换：通过修改 SVG 元素的 stroke、stroke-width、fill 属性实现高亮
  4. 元素显示/隐藏：通过设置 display="none" 或 display="block" 控制
  5. 按钮状态：步骤0时禁用"上一步"，步骤3时禁用"下一步"
  6. 动画效果：可使用 CSS transition 实现高亮颜色的平滑过渡

- ID 命名规范：所有交互元素 ID 以"scene1-"为前缀
  - 线段：scene1-seg-a, scene1-seg-b, ..., scene1-seg-h
  - 标签：scene1-label-a, scene1-label-b, ..., scene1-label-h
  - 数值：scene1-value-b, scene1-value-c, scene1-value-g
  - 箭头：scene1-arrow-h, scene1-arrow-f, scene1-arrow-d, scene1-arrow-a, scene1-arrow-e
  - 公式：scene1-formula
  - 按钮：scene1-btn-prev, scene1-btn-next

- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染
