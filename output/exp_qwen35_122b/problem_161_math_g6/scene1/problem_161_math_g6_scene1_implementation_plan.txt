[分步序列]
- 步骤 0（初始状态）：
  - 显示：大长方形外框、3 条竖线、4 个小长方形、编号标签 ①②③④
  - 计数信息：显示"单个：4 个"（蓝色高亮）
  - 高亮：无

- 步骤 1：
  - 显示：基础图形 + 编号标签
  - 计数信息：显示"单个：4 个"
  - 高亮：4 个小长方形分别用蓝色边框 #1565c0 高亮（3px），内部填充 20% 透明度
  - 视觉变化：4 个小长方形依次出现蓝色高亮边框

- 步骤 2：
  - 显示：基础图形 + 编号标签
  - 计数信息：显示"两个组合：3 个"（红色高亮）
  - 高亮：①+②组合、②+③组合、③+④组合 用红色边框 #c62828 高亮（3px），内部填充 20% 透明度
  - 视觉变化：蓝色高亮消失，出现 3 个红色高亮组合框

- 步骤 3：
  - 显示：基础图形 + 编号标签
  - 计数信息：显示"三个组合：2 个"（绿色高亮）
  - 高亮：①+②+③组合、②+③+④组合 用绿色边框 #2e7d32 高亮（3px），内部填充 20% 透明度
  - 视觉变化：红色高亮消失，出现 2 个绿色高亮组合框

- 步骤 4：
  - 显示：基础图形 + 编号标签
  - 计数信息：显示"四个组合：1 个"（绿色高亮）
  - 高亮：①+②+③+④整体大长方形用绿色边框 #2e7d32 高亮（3px），内部填充 20% 透明度
  - 视觉变化：显示整体大长方形的绿色高亮边框

- 步骤 5（最终状态）：
  - 显示：基础图形 + 编号标签 + 汇总公式
  - 计数信息：显示"总计：4+3+2+1=10 个"（黑色加粗）
  - 高亮：无（或所有类别同时用不同颜色边框显示）
  - 视觉变化：显示完整计算公式，强调分类统计法

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：位于 (280,450)，点击返回上一状态，步骤 0 时禁用
  - "下一步 ▶"按钮：位于 (500,450)，点击进入下一状态，步骤 5 时禁用
- 教师操作流程：
  1. 初始展示基础图形，让学生观察长方形结构
  2. 点击"下一步"逐步展示单个长方形计数（4 个）
  3. 继续点击展示两个组合、三个组合、四个组合的计数
  4. 最后展示汇总公式，强调分类统计思想

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    图示区 800×500                        │
  │                                                         │
  │     ┌─────────────────────────────────────────┐        │
  │     │  ①    │   ②   │        ③        │   ④   │        │
  │     │       │       │                  │       │        │
  │     │       │       │                  │       │        │
  │     └─────────────────────────────────────────┘        │
  │                                                         │
  │          计数信息：单个：4 个 / 两个组合：3 个...         │
  │                                                         │
  │              [◀ 上一步]      [下一步 ▶]                 │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：currentStep 变量（0-5），updateScene() 函数根据 currentStep 更新高亮元素
  2. 坐标计算：所有元素使用固定像素坐标，高亮框根据组合类型动态计算位置
  3. 动画曲线：高亮边框使用 CSS transition 实现淡入淡出效果（0.3s ease）
  4. 事件绑定：按钮点击事件监听，边界状态禁用按钮
  5. 高亮组合定义：
     - 单个：[①],[②],[③],[④]
     - 两个组合：[①+②],[②+③],[③+④]
     - 三个组合：[①+②+③],[②+③+④]
     - 四个组合：[①+②+③+④]
- ID 命名规范：所有交互元素 ID 以 scene1- 为前缀
  - 高亮框：scene1-highlight-1, scene1-highlight-2, ...
  - 按钮：scene1-prev-btn, scene1-next-btn
  - 计数文本：scene1-count-text
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局污染
