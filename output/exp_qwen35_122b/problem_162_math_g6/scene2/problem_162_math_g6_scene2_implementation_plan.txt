- 本图示主题：平移法详解（图形B阶梯形周长计算）
- 整合内容：动态展示阶梯边的平移过程，说明为什么阶梯形周长等于长方形周长

[视觉元素清单]
- 原始阶梯图形：黑色实线轮廓，线宽2px，包含底边(350,350)-(550,350)、左侧边(350,180)-(350,350)以及右上方的阶梯边（约5级台阶）
- 目标长方形：蓝色虚线矩形(350,180)-(550,350)，线宽2px，表示平移后的最终形状
- 平移轨迹箭头：灰色虚线，带箭头指示平移方向，水平边向上平移，垂直边向右平移
- 已平移部分：绿色(#2e7d32)高亮显示，表示已完成平移的边
- 未平移部分：保持黑色，表示待平移的边
- 滑块控件：左侧垂直区域，用于控制平移进度0%-100%
- 参考图形A：左上角小尺寸长方形，用于对比周长
- 标签：仅显示数值"10"、"6"、"周长：32"及进度百分比，无解释性句子

[分步序列]
- 初始状态（步骤0）：
  - 显示原始阶梯图形（黑色实线）
  - 显示底边标签"10"和左侧边标签"6"
  - 显示参考图形A及其周长"32"
  - 滑块位于0%位置
  - 周长数值显示"周长：32"
  - 说明文字："拖动滑块，观察阶梯边如何平移成长方形"

- 步骤1（滑块拖拽至25%）：
  - 最下方的水平阶梯边开始向上平移，显示灰色轨迹箭头
  - 最左侧的垂直阶梯边开始向右平移，显示灰色轨迹箭头
  - 已平移部分显示为绿色
  - 进度显示"25%"
  - 说明文字："水平边向上平移，垂直边向右平移"

- 步骤2（滑块拖拽至50%）：
  - 约一半的水平边和垂直边已完成平移，显示为绿色
  - 平移轨迹箭头清晰可见
  - 进度显示"50%"
  - 说明文字："平移过程中，总长度保持不变"

- 步骤3（滑块拖拽至75%）：
  - 大部分边已完成平移
  - 仅剩少数阶梯边未平移
  - 进度显示"75%"
  - 说明文字："所有边平移后形成完整长方形"

- 最终步骤（滑块拖拽至100%）：
  - 所有阶梯边完成平移
  - 阶梯图形完全重合于蓝色虚线长方形轮廓
  - 所有平移后的边显示为绿色
  - 进度显示"100%"
  - 说明文字："阶梯形周长 = 长方形周长 = 2×(10+6) = 32"
  - 高亮显示最终长方形，强调周长相等

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：
  - 滑块：位于左侧(60,220)-(200,240)，范围0-100，控制平移进度
  - 进度显示：滑块下方显示当前百分比
  - 周长数值：右上角动态显示当前周长（始终为32，强调不变性）
- 教师操作流程：
  1. 初始展示阶梯图形和参考长方形A
  2. 引导学生观察阶梯形的不规则边界
  3. 缓慢拖动滑块，边拖边讲解："看，这些水平边向上平移，垂直边向右平移"
  4. 拖至50%时暂停："平移过程中，边的总长度变了吗？没有！"
  5. 拖至100%："现在阶梯形完全重合于长方形，所以周长相等"
  6. 对比图形A的周长，得出结论

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何动画，无需重型库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │  A        [滑块区]                    [阶梯图形区]              │
  │  □      平移进度                       ┌──────────┐            │
  │ 周长=32  [====○====]                  │  阶梯形   │            │
  │          0%                           │  →长方形 │            │
  │                                       └──────────┘            │
  │                              周长：32                          │
  │                                                                │
  │  拖动滑块，观察阶梯边如何平移成长方形                          │
  └────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：滑块值(0-100) → 映射到平移进度 → 计算哪些边已平移
  2. 坐标计算：阶梯边均匀分布，5级台阶，每级水平=40px，垂直=34px
  3. 动画曲线：滑块拖动时实时更新，无缓动（直接响应）
  4. 事件绑定：slider input 事件 → 更新所有相关元素
  5. ID 命名规范：所有元素 ID 以"scene2-"为前缀（如 scene2-stair-base, scene2-slider, scene2-progress-text）
  6. IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局污染
  7. 平移逻辑：progress/100 * 总边数 = 已平移边数，已平移边显示绿色并移动到目标位置
  8. 轨迹箭头：根据进度动态显示/隐藏，已完成的轨迹逐渐淡出
