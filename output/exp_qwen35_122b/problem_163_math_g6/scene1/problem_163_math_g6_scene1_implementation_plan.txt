[图示主题与整合说明]
- 本图示主题：三角形 ABC 中 AB 边上的高识别
- 整合内容：整合了①三角形 ABC 展示 ②AB 边识别 ③高的定义演示 ④正确答案确认 ⑤错误选项排除 共 5 个步骤
- 教学价值：教师可通过分步导航引导学生理解"三角形的高"的定义——从顶点向对边（或对边延长线）作垂线，垂线段即为高。通过对比错误选项，强化对高的概念理解。

[视觉元素清单]
- 三角形 ABC：由线段 AB、BC、AC 组成，黑色实线（线宽 2px）
- AB 边：步骤 1 高亮为蓝色（#1565c0，线宽 3px）
- 高 CD：步骤 2-3 显示，绿色（#2e7d32，线宽 3px）
- AB 延长线：灰色虚线（#888888，线宽 1px）
- 垂足直角符号：D 点处黑色折线（线宽 1px）

- 顶点标记：A、B、C、D、E 为黑色实心圆点（直径 4px）

- 正确标记✓：绿色（#2e7d32）
- 错误标记✗：红色（#c62828）

[分步序列]
- 步骤 0（初始状态）：
  - 显示三角形 ABC（黑色实线）
  - 显示所有顶点 A、B、C（黑色圆点）
  - 显示顶点标签 A、B、C
  - 显示选项区三个选项框及文字
  - 等待教师点击"下一步"

- 步骤 1：
  - 高亮 AB 边为蓝色（#1565c0，线宽 3px）
  - 显示 AB 延长线（灰色虚线）
  - 显示 D 点及标签 D
  - 新增提示文字"AB 边所在直线"（位于 AB 下方）
  - 教师讲解：先确定我们要找的是哪条边上的高

- 步骤 2：
  - 从 C 点向 AB 延长线作垂线 CD（绿色，线宽 3px）
  - 显示垂足 D 处的直角符号
  - 显示 E 点、线段 EB 及标签 E
  - 教师讲解：从顶点 C 向 AB 边所在直线作垂线

- 步骤 3：
  - 高亮线段 CD，标注"高"字（位于 CD 右侧）
  - 强调 CD⊥AB（直角符号闪烁或加粗）
  - 教师讲解：这条垂线段 CD 就是 AB 边上的高

- 步骤 4（最终状态）：
  - 选项 1（A.CB）旁显示红色✗，线段 CB 短暂闪烁红色
  - 选项 2（B.CD）旁显示绿色✓，线段 CD 高亮绿色
  - 选项 3（C.EB）旁显示红色✗，线段 EB 短暂闪烁红色
  - 显示结论文字"正确答案：B．CD"（位于图形区下方）
  - 教师讲解：对比选项，CB 是边不是高，EB 与 AB 不垂直，只有 CD 是从 C 到 AB 的垂线段

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：位于 (250,450)-(370,480)，点击返回上一状态，步骤 0 时禁用
  - "下一步 ▶"按钮：位于 (430,450)-(550,480)，点击进入下一状态，步骤 4 时变为"完成"
- 教师操作流程：
  1. 加载图示，显示三角形 ABC 基础图形
  2. 点击"下一步"→ 高亮 AB 边，讲解"找哪条边上的高"
  3. 点击"下一步"→ 作垂线 CD，讲解"高的定义"
  4. 点击"下一步"→ 标注"高"，强化概念
  5. 点击"下一步"→ 对比选项，确认答案
  6. 可随时点击"上一步"回退复习

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │                        图示标题区 (可选)                        │
  ├──────────────────────────────┬─────────────────────────────────┤
  │                              │                                 │
  │     主图形区 (500×350)        │      选项对比区 (200×280)        │
  │     三角形 ABC + 高 CD        │      A.CB  ✗                    │
  │                              │      B.CD  ✓                    │
  │                              │      C.EB  ✗                    │
  │                              │                                 │
  ├──────────────────────────────┴─────────────────────────────────┤
  │                    控件区 (◀上一步  下一步▶)                    │
  └────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：currentStep 变量 (0-4)，updateScene() 函数根据 currentStep 控制元素显示/隐藏/高亮
  2. 坐标计算：所有元素使用绝对坐标，SVG 中用 x、y 属性精确控制
  3. 动画曲线：使用 CSS transition 实现高亮颜色渐变（0.3s ease）
  4. 事件绑定：按钮点击事件监听，步骤 0 禁用上一步，步骤 4 禁用下一步
  5. ID 命名规范：所有元素 ID 以"scene1-"为前缀（如 scene1-tri-ab、scene1-btn-next）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 直角符号绘制：用 polyline 绘制 L 形折线，坐标 (385,335)-(400,350)-(400,335)
  8. 虚线绘制：用 stroke-dasharray="5,5"实现灰色虚线
