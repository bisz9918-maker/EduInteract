[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：位置(250,455)，作用：返回上一步骤
  - "步骤 X/6"文本：位置(400,455)，作用：显示当前步骤
  - "下一步 ▶"按钮：位置(550,455)，作用：进入下一步骤
- 教师操作流程：
  1. 初始展示三个视图，让学生观察
  2. 点击"下一步"，依次高亮每个视图，引导学生理解每个视图的含义
  3. 三个视图同时高亮时，引导学生综合推断
  4. 最后展示立体图形，验证推断结果

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │                        图示区 800×500                          │
  │                                                                │
  │   [正面视图]  [侧面视图]  [上面视图]      [立体图形]           │
  │      矩形        矩形        梯形           四棱柱             │
  │     (80,120)   (220,120)   (360,140)      (520,150)           │
  │                                                                │
  │        正面        侧面        上面         立体图             │
  │                                                                │
  │   ─────────────────────────────────────────────────────────   │
  │                                                                │
  │              ◀ 上一步    步骤 X/6    下一步 ▶                  │
  │              (250,455)    (400,455)    (550,455)              │
  │                                                                │
  └────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量（0-5）跟踪当前步骤
  2. 坐标计算：所有元素使用绝对坐标，SVG 内定位
  3. 动画曲线：使用 CSS transition 实现高亮效果（0.3s ease）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 并刷新视图
  5. ID 命名规范：所有交互元素 ID 以"scene1-"为前缀（如 scene1-view-front, scene1-btn-prev）
  6. JS 使用 getElementById 而非 querySelectorAll，避免多场景合并时跨场景污染
  7. IIFE 隔离：所有 JS 包在 (function() { ... })() 中

- SVG 元素 ID 命名：
  - scene1-view-front：正面视图框
  - scene1-view-side：侧面视图框
  - scene1-view-top：上面视图框
  - scene1-solid：立体图形
  - scene1-line1：连接线1
  - scene1-line2：连接线2
  - scene1-line3：连接线3
  - scene1-label-front：正面标签
  - scene1-label-side：侧面标签
  - scene1-label-top：上面标签
  - scene1-label-solid：立体图标签
  - scene1-label-conclusion：结论标签
  - scene1-hint-text：提示文字
  - scene1-btn-prev：上一步按钮
  - scene1-btn-next：下一步按钮
  - scene1-step-display：步骤显示文本
