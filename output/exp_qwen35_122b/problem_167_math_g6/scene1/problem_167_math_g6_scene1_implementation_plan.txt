[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │                        图示区 800×500                          │
  │                                                                │
  │    甲标签                    乙标签                            │
  │      ↓                        ↓                               │
  │  ┌────────────────────────────────────────────────────────┐   │
  │  │  甲三角形(蓝)  │  空白  │  乙1(红) │  乙2(红)           │   │
  │  │                │        │          │                    │   │
  │  └────────────────────────────────────────────────────────┘   │
  │      ↓底=2              ↓底=1    ↓底=1                        │
  │      高=2               高=1     高=1                          │
  │                                                                │
  │    甲面积=2              乙面积=1                              │
  │           甲面积 > 乙面积                                      │
  │                                                                │
  │              [上一步]        [下一步]                          │
  │              (控件栏 y=440~490)                                │
  └────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量跟踪当前步骤（0-3），根据步骤控制元素显示/隐藏
  2. 坐标计算：网格每格50px，甲三角形顶点(200,200)-(300,200)-(300,300)，乙三角形1顶点(450,200)-(500,200)-(500,250)，乙三角形2顶点(550,200)-(600,200)-(600,250)
  3. 动画曲线：标注线使用 opacity 渐变（0→1），0.3秒过渡
  4. 事件绑定：上一步/下一步按钮点击事件，更新 currentStep 并刷新显示状态
  5. 元素显示控制：使用 display 或 opacity 控制各步骤元素的显示/隐藏
- ID 命名规范：所有交互元素 ID 以 scene1- 为前缀，如 scene1-grid、scene1-tri-a、scene1-tri-b1、scene1-tri-b2、scene1-label-a、scene1-label-b、scene1-btn-prev、scene1-btn-next
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局污染
