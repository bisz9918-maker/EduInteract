[分步序列]
步骤0（初始状态）：
- 显示：大圆、左小圆、右小圆、水平直径线
- 隐藏：所有直径标注线、所有公式文本
- 目的：展示基础图形，让学生观察三个圆的排列关系

步骤1（点击"下一步"）：
- 新增显示：d₁标注线、d₂标注线、D标注线
- 新增显示：标签"d₁"、"d₂"、"D"
- 高亮：三标注线用蓝高亮#1565c0
- 目的：标注三个圆的直径，明确符号表示

步骤2（点击"下一步"）：
- 新增显示：公式文本框内的三行公式：
  - "C₁ = πd₁"（左小圆周长）
  - "C₂ = πd₂"（右小圆周长）
  - "C = πD"（大圆周长）
- 高亮：三公式用蓝高亮#1565c0
- 目的：展示周长公式，建立符号与公式的对应

步骤3（点击"下一步"）：
- 高亮：水平直径线用蓝高亮#1565c0
- 高亮：三直径标注线同时蓝高亮
- 新增显示：关系式 "d₁ + d₂ = D"（红高亮#c62828）
- 目的：强调直径的几何关系（两小圆直径之和等于大圆直径）

步骤4（点击"下一步"）：
- 新增显示：推导过程（红高亮#c62828）：
  - "C₁ + C₂ = πd₁ + πd₂"
  - "     = π(d₁ + d₂)"
  - "     = πD"
  - "     = C"
- 高亮：左小圆、右小圆、大圆依次蓝高亮闪烁
- 目的：展示代数推导过程，将直径关系代入周长公式

步骤5（点击"下一步"）：
- 新增显示：结论框（绿高亮#2e7d32）：
  - "结论：两小圆周长和 = 大圆周长"
  - "答案：A．一样长"
- 高亮：三个圆同时绿高亮#2e7d32
- 目的：呈现最终结论，完成推理闭环

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：位于(280,450)，点击返回上一状态，步骤0时禁用
  - "下一步 ▶"按钮：位于(620,450)，点击进入下一状态，步骤5时禁用
- 教师操作流程：
  1. 初始展示图形，提问"观察图中三个圆的排列，你能发现什么？"
  2. 点击下一步，标注直径符号，提问"如何用符号表示这三个直径？"
  3. 点击下一步，显示周长公式，复习圆周长公式
  4. 点击下一步，强调直径关系，引导学生发现d₁+d₂=D
  5. 点击下一步，展示推导过程，带领学生完成代数运算
  6. 点击下一步，呈现结论，回答问题"一样长"

- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：

- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-5) 跟踪当前步骤
  2. 元素分组：用 SVG <g> 标签将相关元素分组（如 diameter-labels、formulas、derivation、conclusion）
  3. 显示控制：根据 currentStep 控制各组的 display 属性（block/none）
  4. 高亮切换：用 CSS class 控制高亮样式（.highlight-blue, .highlight-red, .highlight-green）
  5. 按钮状态：步骤0时禁用上一步，步骤5时禁用下一步
  6. 坐标计算：圆心位置根据直径关系精确计算（左小圆直径100，右小圆直径140，大圆直径240）

- ID 命名规范：
  - 所有元素 ID 前缀：scene1-
  - 示例：scene1-circle-large, scene1-circle-left, scene1-circle-right, scene1-line-diameter, scene1-label-d1, scene1-label-d2, scene1-label-D, scene1-formula-box, scene1-text-c1, scene1-text-c2, scene1-text-C, scene1-text-derivation1-4, scene1-text-conclusion, scene1-btn-prev, scene1-btn-next

- IIFE 隔离：
