[交互方案]

  5. 可随时点击"上一步"回退复习关键步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────┐
  │                                                         │
  │                    北                                   │
  │                     ↑                                   │
  │                     │                                   │
  │              巡洋舰 ●                                   │
  │                ↗   │40°                                │
  │              /     │                                   │
  │    西 ←─────●──────┼──────→ 东                         │
  │          雷达站    │                                   │
  │                    │                                   │
  │                    ↓                                   │
  │                    南                                   │
  │                                                         │
  │                              50 km                      │
  │                              ─────                      │
  │                                                         │
  │              [上一步]  步骤 1/4  [下一步]               │
  └─────────────────────────────────────────────────────────┘
  ```

- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-3) 跟踪当前步骤
  2. 坐标计算：
     - 巡洋舰射线终点：(400 + 141×sin(40°), 250 - 141×cos(40°)) ≈ (500, 150)
     - 角度弧线：SVG path "M 400,190 A 60,60 0 0 1 446,206"（近似40°圆弧）
  3. 元素 ID 命名：所有元素以 scene1- 为前缀（如 scene1-north-axis, scene1-angle-arc）
  4. 高亮切换：通过修改 stroke 颜色和 stroke-width 实现
  5. 显示/隐藏：通过 setAttribute('display', 'none'/'block') 控制
  6. 按钮禁用：步骤0禁用"上一步"，步骤3禁用"下一步"
  7. IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局污染

- SVG 元素 ID 规范：
  - scene1-north-axis：正北轴
  - scene1-south-axis：正南轴
  - scene1-east-axis：正东轴
  - scene1-west-axis：正西轴
  - scene1-ship-ray：巡洋舰射线
  - scene1-angle-arc：角度弧线
  - scene1-angle-text：40°标注
  - scene1-radar-point：雷达站中心点
  - scene1-ship-point：巡洋舰位置点
  - scene1-conclusion-text：结论文本
  - scene1-prev-btn：上一步按钮
  - scene1-next-btn：下一步按钮
  - scene1-step-indicator：步骤指示器
