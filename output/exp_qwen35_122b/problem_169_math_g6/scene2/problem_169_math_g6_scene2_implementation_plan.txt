[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀上一步"按钮：位于 (250,455)，点击返回上一状态，步骤 0 时禁用
  - "下一步▶"按钮：位于 (500,455)，点击进入下一状态，步骤 3 时禁用
- 教师操作流程：
  1. 初始展示基础坐标和比例尺，教师讲解坐标系和比例尺概念
  2. 点击"下一步"高亮比例尺，强调"1 段=50km"的基准
  3. 点击"下一步"显示分段标记，引导学生数出 2 段
  4. 点击"下一步"显示计算过程和结果，总结"2 × 50km = 100km"
  5. 可随时点击"上一步"回退复习关键步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────┐
  │                    北                                    │
  │                     ↑                                    │
  │                     │                                    │
  │              巡洋舰 ● (496,135)                          │
  │                 ╱  40°                                   │
  │               ╱                                          │
  │             ╱                                            │
  │  西 ←─────●─────→ 东                                     │
  │        (400,250) 雷达站                                  │
  │             │                                            │
  │             │                                            │
  │             ↓                                            │
  │                    南                                    │
  │                                                          │
  │                                    ┌──────┐ 50km         │
  │                                    └──────┘              │
  │                                                          │
  │         [◀上一步]                    [下一步▶]           │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：currentStep 变量 (0-3)，updateScene() 函数根据 currentStep 显示/隐藏对应元素
  2. 坐标计算：巡洋舰点坐标通过三角函数计算：x=400+150*sin(40°)≈496, y=250-150*cos(40°)≈135
  3. 分段标记位置：线段 (400,250)-(496,135) 的中点 (448,192) 和终点 (496,135)
  4. 元素显示/隐藏：通过 setAttribute('display', 'none'/'block') 控制
  5. 按钮状态：步骤 0 禁用上一步，步骤 3 禁用下一步
  6. 动画曲线：元素出现使用 opacity 渐变 (0→1)，时长 300ms
- ID 命名规范：所有交互元素 ID 以 scene2- 为前缀（如 scene2-line-north, scene2-btn-next, scene2-label-100km）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
