problem_16_physics_g9

场景导航：Scene 1

题目原文：

如图所示，电源电压恒定，闭合开关后，将滑动变阻器的滑片向右端移动的过程中，下列说法正确的是（ ）

A．电流表示数变小，电压表 V₁ 示数变大

B．小灯泡变暗，电压表 V₂ 示数变小

C．电压表 V₁ 和电压表 V₂ 示数之和不变

D．电路的总功率变大

题目分析：

本题是一道串联电路动态分析题，考查学生对欧姆定律和电功率公式的综合运用能力。

电路结构识别：

  • 这是一个串联电路：电源 → 开关 → 小灯泡 → 滑动变阻器 → 电流表 → 回到电源
  • 电压表 V₁ 并联在滑动变阻器两端，测量滑动变阻器两端电压
  • 电压表 V₂ 并联在小灯泡两端，测量小灯泡两端电压
  • 电流表 A 串联在电路中，测量电路总电流

关键变化过程：
滑动变阻器滑片向右移动 → 接入电路的电阻变大 → 电路总电阻变大 → 总电流变小

整体讲解思路：

  1. 首先引导学生识别电路连接方式和各电表测量对象
  2. 分析滑片移动引起的电阻变化
  3. 根据欧姆定律推导电流变化
  4. 根据 U = IR 推导各部分电压变化
  5. 根据 P = UI 推导功率变化
  6. 逐一判断选项正误

图示规划说明：
本道题设计 1 个交互式图示场景，整合电路结构展示和动态变化分析。通过分步按钮导航，从静态电路识别逐步推进到动态变化分析，帮助学生建立"电阻变化→电流变化→电压变化→功率变化"的完整推理链条。

教学说明：

本图示是讲解本题的核心可视化材料，教师应按以下步骤引导学生：

步骤 0：电路结构识别
引导学生观察电路连接方式，提问：

  • "这是一个串联还是并联电路？"（串联）
  • "电压表 V₁ 测量哪部分的电压？"（滑动变阻器两端）
  • "电压表 V₂ 测量哪部分的电压？"（小灯泡两端）
  • "电流表测量什么？"（电路总电流）

步骤 1：电阻变化分析
点击"下一步"，显示滑片右移动画。提问：

  • "滑片向右移动，滑动变阻器接入电路的电阻如何变化？"（变大）
  • 强调：滑片右移 → 接入电阻丝长度增加 → 电阻变大

步骤 2：电流变化分析
点击"下一步"，显示电流表示数变化。引导学生推导：

  • 电源电压 U 恒定
  • 总电阻 R总 = RL + R滑，R滑变大 → R_总变大
  • 根据欧姆定律：I = U / R_总
  • U 不变，R_总变大 → I 变小
  • 结论：电流表示数变小

步骤 3：电压变化分析
点击"下一步"，显示两电压表示数变化。引导学生推导：

  • V₂ 测量灯泡电压：UL = I × RL
  • I 变小，RL 不变 → UL 变小
  • 结论：V₂ 示数变小
  • V₁ 测量滑动变阻器电压：UR = U - UL
  • U 恒定，UL 变小 → UR 变大
  • 结论：V₁ 示数变大

步骤 4：功率变化分析
点击"下一步"，显示灯泡亮度和总功率变化。引导学生推导：

  • 灯泡实际功率：PL = I² × RL
  • I 变小 → P_L 变小 → 灯泡变暗
  • 电路总功率：P_总 = U × I
  • U 恒定，I 变小 → P_总变小

步骤 5：选项判断
点击"下一步"，汇总结论，逐一判断选项：

  • A：电流表示数变小 ✓，V₁ 示数变大 ✓ → 正确
  • B：灯泡变暗 ✓，但 V₂ 示数变小（选项说变小是对的，但 B 选项整体需要判断）→ 实际上 B 也是正确的描述，但题目是单选，需要看原题意图
  • C：V₁ + V₂ = U（电源电压），和不变 ✓ → 但这是串联电路电压规律，需要确认
  • D：总功率变大 ✗（实际变小）

讲解建议：

  • 每一步都要先让学生思考，再揭示答案
  • 强调推理链条：电阻→电流→电压→功率
  • 提醒学生注意串联电路电压规律：U = U₁ + U₂

完整解答：

电路分析：

  • 串联电路：电源 → 开关 → 灯泡 L → 滑动变阻器 R → 电流表 A → 电源
  • V₁ 测滑动变阻器电压，V₂ 测灯泡电压，A 测总电流

滑片右移时的变化：

  1. R滑 ↑ → R总 ↑
  2. I = U/R_总 → I ↓（电流表示数变小）
  3. UL = I×RL → U_L ↓（V₂ 示数变小）
  4. UR = U - UL → U_R ↑（V₁ 示数变大）
  5. PL = I²RL → P_L ↓（灯泡变暗）
  6. P总 = UI → P总 ↓（总功率变小）

选项判断：

  • A：电流表示数变小 ✓，V₁ 示数变大 ✓ → 正确
  • B：灯泡变暗 ✓，V₂ 示数变小 ✓ → 描述正确，但需确认题目是否为单选
  • C：V₁ + V₂ = U（电源电压恒定）→ 和不变 ✓
  • D：总功率变大 ✗（实际变小）

课堂讲解建议：

  1. 先让学生独立分析，再对照图示讲解
  2. 强调"抓关键变量"：滑片移动→电阻变化是起点
  3. 引导学生建立推理链条，避免跳跃式思维
  4. 提醒学生注意串联电路电压分配规律
  5. 对于多选题，需要仔细审题确认题目要求
