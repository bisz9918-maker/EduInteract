[分步序列]
步骤 0（初始状态）：
- 显示完整电路图（所有元件、导线、标签）
- 开关处于闭合状态
- 滑片在中间位置 (550,150)
- 所有电表显示初始读数（可用虚线框或"?"表示未知）
- 无高亮、无变化指示箭头
- 教师讲解：识别电路结构，各元件连接方式，电表测量对象

步骤 1（滑片右移，电阻变大）：
- 滑片从 (550,150) 移动到 (620,150)
- 显示红色右向箭头 (550,140)-(620,140)
- 滑动变阻器 R 加蓝色高亮边框
- 文字提示"R 接入电阻变大"
- 教师讲解：滑片右移→接入电路的电阻丝长度增加→R 变大

步骤 2（总电流变小）：
- 电流表 A 加蓝色高亮边框
- 电流表旁显示绿色↓箭头 (760,220)
- 文字提示"I = U/R总，R总变大→I 变小"
- 教师讲解：串联电路总电阻 R总=R+R_L，R 变大→R总变大→I=U/R总变小

步骤 3（V₁变大、V₂变小）：
- 电压表 V₁和 V₂加蓝色高亮边框
- V₁旁显示红色↑箭头 (500,80)
- V₂旁显示绿色↓箭头 (500,440)
- 文字提示"U₁=IR，U₂=IR_L"
- 教师讲解：V₂测灯泡电压 U₂=I×R_L，I 变小→U₂变小；V₁测变阻器电压 U₁=U-U₂，U₂变小→U₁变大

步骤 4（灯泡变暗、总功率变小）：
- 灯泡 L 加蓝色高亮边框
- 灯泡旁显示"变暗"文字 (160,410)
- 电源旁显示"P 总=UI，I 变小→P 总变小" (200,250)
- 教师讲解：灯泡功率 P_L=I²R_L，I 变小→P_L变小→灯泡变暗；总功率 P 总=UI，I 变小→P 总变小

步骤 5（结论汇总）：
- 所有变化指示箭头保持显示
- 中央显示结论框：
  "结论：A 正确 ✓
   A. 电流表示数变小，电压表 V₁示数变大"
- 其他选项标记为错误：
  "B. × (灯泡变暗✓，但 V₂示数变小✓)
   C. × (V₁+V₂=U 恒定)
   D. × (总功率变小)"
- 教师讲解：逐项分析选项，得出正确答案 A

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：scene1-prev-btn，位置 (250,450)-(350,480)，点击返回前一步骤，步骤 0 时禁用
  - "下一步 ▶"按钮：scene1-next-btn，位置 (450,450)-(550,480)，点击进入下一步骤，步骤 5 时禁用
- 教师操作流程：
  1. 加载图示，从步骤 0 开始讲解电路结构
  2. 点击"下一步"进入步骤 1，讲解滑片移动与电阻变化
  3. 继续点击"下一步"依次讲解电流、电压、功率变化
  4. 到达步骤 5 后，结合结论框逐项分析选项
  5. 如需回顾，点击"上一步"返回前序步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（电路图适合用 SVG 绘制，交互逻辑简单无需重型框架）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    800 × 500 SVG 画布                    │
  │                                                         │
  │   V₁(450,60)                    滑动变阻器 R            │
  │     ○                             ┌─────┐              │
  │      \                           │  ▓▓▓ │滑片→         │
  │       \────虚线───────────────────└─────┘              │
  │                                                         │
  │  开关    电源              导线                    电流表│
  │   ─┐    ┌─┐                                          ○ A│
  │     └───┤ │───────────────────────────────────────────   │
  │         └─┘                                             │
  │                                                         │
  │   灯泡 L                                    V₂          │
  │    ┌───┐                                          ○    │
  │    │ × │─────────────────────────────────────虚线────   │
  │    └───┘                                                │
  │                                                         │
  │            ┌─────────────────────────────────────┐      │
  │            │      ◀ 上一步      下一步 ▶          │      │
  │            │      (250,450)    (450,450)         │      │
  │            └─────────────────────────────────────┘      │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-5) 跟踪当前步骤，updateScene() 函数根据 currentStep 显示/隐藏对应元素
  2. 坐标计算：所有元素使用绝对坐标，滑片移动用 transform="translate(x,0)"实现
  3. 动画曲线：滑片移动使用 CSS transition (0.5s ease) 实现平滑动画
  4. 事件绑定：按钮点击事件调用 updateScene()，更新 currentStep 后重绘
  5. 高亮效果：用 class="highlight"添加蓝色边框，步骤切换时动态添加/移除
  6. 变化指示：用 class="indicator-up/down"控制箭头显示，颜色用 CSS 变量
- ID 命名规范：所有元素 ID 以 scene1- 为前缀，如 scene1-wire-main、scene1-slide-r、scene1-ammeter、scene1-volt1、scene1-volt2、scene1-lamp、scene1-prev-btn、scene1-next-btn
- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染
