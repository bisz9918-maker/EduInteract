- 本图示主题：概念包含关系的集合图表示（生物学概念层级关系）

[分步序列]
步骤 0（初始状态）：
- 显示：大圆Ⅰ（轮廓 + 浅灰填充）
- 标签：仅显示"Ⅰ"
- 隐藏：三个小圆、所有关系标注
- 按钮状态：上一步禁用，下一步启用
- 教学目的：展示整体概念框架，引出"Ⅰ代表什么概念"

步骤 1：
- 显示：三个小圆Ⅱ、Ⅲ、Ⅳ（轮廓 + 浅灰填充）
- 标签：显示"Ⅱ"、"Ⅲ"、"Ⅳ"
- 隐藏：所有关系标注
- 按钮状态：上一步启用，下一步启用
- 教学目的：展示大概念内部的三个子概念，观察它们的位置关系

步骤 2：
- 显示：三条蓝色包含箭头（从大圆中心指向三个小圆中心）
- 标签：显示"包含"文字（位于箭头汇聚区上方）
- 高亮：大圆Ⅰ轮廓变为蓝色 3px
- 按钮状态：上一步启用，下一步启用
- 教学目的：明确Ⅰ与Ⅱ、Ⅲ、Ⅳ之间的包含关系

步骤 3：
- 显示：灰色虚线框包围三个小圆
- 标签：显示"并列关系"文字（位于虚线框下方）
- 高亮：三个小圆轮廓变为红色 2px
- 按钮状态：上一步启用，下一步启用
- 教学目的：明确Ⅱ、Ⅲ、Ⅳ之间是并列关系，互不重叠

步骤 4（结论）：
- 显示：所有元素（大圆、三小圆、包含箭头、并列虚线框）
- 高亮：大圆蓝色，三小圆红色，箭头蓝色，虚线灰色
- 标签：所有标签 + "总结：Ⅰ是大概念，Ⅱ/Ⅲ/Ⅳ是并列子概念"（底部新增总结文字）
- 按钮状态：上一步启用，下一步禁用
- 教学目的：完整展示概念关系结构，强化记忆

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮（scene1-btn-prev）：位于控件栏左侧，点击返回上一状态，步骤 0 时禁用
  - 下一步按钮（scene1-btn-next）：位于控件栏右侧，点击进入下一状态，步骤 4 时禁用
  - 步骤指示器（scene1-step-indicator）：位于控件栏中央，显示当前步骤（如"步骤 1/5"）
- 教师操作流程：
  1. 初始展示大圆Ⅰ，提问"这个圆代表什么概念？"
  2. 点击下一步，展示三个小圆，提问"这三个小圆与大方圆是什么关系？"
  3. 点击下一步，显示包含箭头，讲解"大概念包含小概念"
  4. 点击下一步，显示并列虚线框，讲解"子概念之间是并列关系"
  5. 点击下一步，展示完整结构，总结概念层级关系
  6. 可点击上一步回退复习任意环节

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图：
```
┌─────────────────────────────────────────────────────────┐
│                    图示区 800×500                        │
│                                                         │
│              ┌─────────────────────────┐                │
│              │         大圆Ⅰ            │                │
│              │    ┌─────┐              │                │
│              │    │ Ⅱ   │              │                │
│              │ ┌──┴──┐  └─────┐        │                │
│              │ │ Ⅲ  │   │ Ⅳ  │        │                │
│              │ └────┘   └─────┘        │                │
│              └─────────────────────────┘                │
│                                                         │
│          ┌─────────────────────────────────┐            │
│          │  ◀上一步   步骤 1/5   下一步▶    │  控件栏    │
│          └─────────────────────────────────┘            │
└─────────────────────────────────────────────────────────┘
```

- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-4) 跟踪当前步骤
  2. 元素显示控制：每个步骤对应的元素用 data-step 属性标记，通过 CSS display 控制显隐
  3. 坐标计算：使用 SVG 的 cx/cy/r 属性直接定位圆形，text 元素用 x/y 定位
  4. 动画曲线：元素出现使用 opacity 过渡（0→1，duration 300ms）
  5. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateDisplay()
  6. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-circle-major, scene1-circle-2, scene1-btn-prev）
  7. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染

- CSS 样式要点：
  - 圆填充：fill="rgba(220,220,220,0.15)"
  - 圆轮廓：stroke="#000000" stroke-width="2"（小圆）或 "3"（大圆）
  - 蓝色高亮：stroke="#1565c0"
  - 红色高亮：stroke="#c62828"
  - 虚线：stroke-dasharray="5,5"
  - 过渡动画：transition="opacity 0.3s ease"
  - 按钮样式：background="#1565c0" color="white" border="none" border-radius="4px"
  - 禁用状态：opacity="0.5" cursor="not-allowed"
