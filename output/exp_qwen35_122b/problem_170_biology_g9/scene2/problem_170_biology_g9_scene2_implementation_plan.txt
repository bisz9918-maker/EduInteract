[图示主题与整合说明]
- 本图示主题：生物学概念层次关系图示分析（问题 170，九年级）
- 整合的步骤/概念：
  1. 理解题目图示：一个大圆 I 包含三个并列小圆 II、III、IV，表示"I 是大概念，包含三个并列子概念"
  2. 逐一分析四个选项的概念关系
  3. 通过对比排除错误选项，确认正确答案
- 教学价值：教师可逐步引导学生理解集合关系图的解读方法，培养概念层次分析能力，通过对比排除法训练逻辑推理

[视觉元素清单]

[分步序列]
步骤 0（初始状态）：
- 显示：标题"概念关系图示分析"、完整选项表格（A/B/C/D 四行）、四个空白示意图占位符（灰色虚线圆）
- 隐藏：所有判断标记、结论区
- 目的：展示题目全貌，让学生先理解表格内容

步骤 1（分析选项 A）：
- 显示：选项 A 示意图（红色边框大圆 I 包含三个并列小圆 II/III/IV）
- 显示：选项 A 标签"A: 四者并列"
- 显示：选项 A 结果"✗"（红色）
- 高亮：表格中选项 A 行背景淡红色
- 解释：鱼类、爬行类、鸟类、哺乳类是脊椎动物的四个并列类别，没有大概念包含关系，与图示不符

步骤 2（分析选项 B）：
- 显示：选项 B 示意图（红色边框，但标注说明是层层包含关系）
- 显示：选项 B 标签"B: 层层包含"
- 显示：选项 B 结果"✗"（红色）
- 高亮：表格中选项 B 行背景淡红色
- 解释：细胞核包含染色体，染色体包含 DNA，DNA 包含基因，是层层包含而非并列，与图示不符

步骤 3（分析选项 C）：
- 显示：选项 C 示意图（红色边框，标注说明关系复杂）
- 显示：选项 C 标签"C: 关系复杂"
- 显示：选项 C 结果"✗"（红色）
- 高亮：表格中选项 C 行背景淡红色
- 解释：种子包含胚和种皮，胚又包含子叶，关系复杂不符合简单的一包含三并列结构

步骤 4（分析选项 D）：
- 显示：选项 D 示意图（蓝色边框大圆 I 包含三个并列小圆 II/III/IV）
- 显示：选项 D 标签"D: 包含并列"
- 显示：选项 D 结果"✓"（绿色）
- 高亮：表格中选项 D 行背景淡绿色
- 解释：微生物包含病毒、细菌、真菌，三者是并列的微生物类别，与图示完全相符

最终步骤（结论）：
- 显示：结论区绿色边框矩形，内文"正确答案：D"
- 高亮：选项 D 示意图边框变为绿色 #2e7d32
- 所有错误选项保持红色标记，正确选项保持绿色标记
- 目的：强化正确答案，形成完整记忆

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步" 按钮：位置 (280, 440)，点击返回上一步骤，第一步时禁用
  - "下一步 ▶" 按钮：位置 (420, 440)，点击进入下一步骤，最后一步时变为"完成"或禁用
- 教师操作流程：
  1. 初始展示题目表格，让学生先读题
  2. 点击"下一步"逐一分析每个选项，每步讲解一个选项的判断理由
  3. 引导学生观察示意图与表格内容的对应关系
  4. 到达结论步骤时，强调正确答案 D 的理由
  5. 可随时点击"上一步"回退复习某个选项的分析

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（圆形、矩形、文本），无需复杂动画或数据可视化库
  - 原生 SVG 可直接在 HTML 中嵌入，性能好，易于控制

- 画布尺寸：800 × 500 px（固定）

- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-5) 跟踪当前步骤
  2. 元素显示/隐藏：通过 CSS display 或 opacity 控制各步骤元素的可见性
  3. 高亮效果：用 CSS class 切换（如 .highlight-a, .highlight-d）
  4. 按钮状态：第一步禁用"上一步"，最后一步禁用"下一步"
  5. 坐标计算：所有元素按布局坐标表精确放置

- ID 命名规范：
  - 所有交互元素 ID 前缀：scene2-
  - 示例：scene2-table, scene2-diagram-a, scene2-diagram-b, scene2-diagram-c, scene2-diagram-d
  - 按钮：scene2-btn-prev, scene2-btn-next
  - 结论区：scene2-conclusion
  - 步骤相关元素：scene2-step-N-*（N 为步骤号）

- IIFE 隔离：
  ```javascript
  (function() {
      // 所有 JS 代码在此闭包内
      const currentStep = 0;
      // ... 其他逻辑
  })();
  ```

- 事件绑定：
  - 按钮点击事件在 DOMContentLoaded 后绑定
  - 使用 addEventListener 而非 onclick 属性
