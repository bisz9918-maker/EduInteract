[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于 (280,450)-(380,480)，点击返回上一步骤，第一步时禁用
  - 「下一步 ▶」按钮：位于 (420,450)-(520,480)，点击进入下一步骤，最后一步时变为「完成」
- 教师操作流程：
  1. 初始展示完整概念图，让学生观察整体结构
  2. 点击「下一步」逐步高亮各组分，配合讲解 DNA 的层次结构
  3. 步骤 4 详细标注各组分名称和数量
  4. 步骤 5 展示选项判断结果，引导学生理解正确选项 B

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形和文本，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │                    DNA 组成层次结构概念图                      │
  │                                                             │
  │   [A] + [B 糖] + [C 磷酸]  →  [D( )]  →  [E DNA]           │
  │                                                             │
  │              ↑标注文字（各步骤显示）                          │
  │                                                             │
  │  选项区：                                                    │
  │  A．A 表示的碱基有 5 种          ✗                            │
  │  B．D 表示脱氧核苷酸            ✓                            │
  │  C．D 表示的结构有 8 种          ✗                            │
  │  D．B 表示的是核糖              ✗                            │
  │                                                             │
  │              [◀ 上一步]  [下一步 ▶]                          │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用 currentStep 变量（0-5）跟踪当前步骤
  2. 方框 ID 命名：scene1-box-A、scene1-box-B、scene1-box-C、scene1-box-D、scene1-box-E
  3. 标注 ID 命名：scene1-label-1、scene1-label-2、scene1-label-3、scene1-label-4A/B/C
  4. 选项标记 ID：scene1-option-A-mark、scene1-option-B-mark 等
  5. 按钮 ID：scene1-btn-prev、scene1-btn-next
  6. 每个步骤定义显示/隐藏/高亮的元素列表
  7. 使用 class 控制高亮样式（.highlight-blue、.highlight-green）
  8. 按钮点击事件更新 currentStep，重新渲染各元素状态
  9. IIFE 隔离所有 JS 代码，避免全局污染

- 状态更新函数设计：
  function updateStep(step) {
    // 1. 重置所有高亮
    // 2. 根据 step 显示对应标注
    // 3. 高亮对应方框
    // 4. 步骤 5 显示选项标记
    // 5. 更新按钮状态
  }

- 动画曲线：高亮效果使用 CSS transition（0.3s ease）实现平滑过渡
