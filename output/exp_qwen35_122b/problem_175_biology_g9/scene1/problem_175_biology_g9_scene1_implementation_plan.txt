[分步序列]
- 步骤0（初始状态）：显示完整的分类图框架，所有节点框和连线可见（黑色），①②③④四个终端节点用虚线框标记，右侧特征框区域空白，等待识别
- 步骤1：点击「下一步」→ 高亮"有种子"分支路径（无果实植物→有种子→①），蓝色#1565c0显示节点框和连线；终端①框变为实线绿框#2e7d32，显示类群名称"裸子植物"；右侧特征框显示"①裸子植物：有种子繁殖，适应干旱陆地生活"（绿色高亮）
- 步骤2：点击「下一步」→ 蓝色高亮切换至"无种子→无茎叶"分支路径；终端②框变为实线绿框#2e7d32，显示类群名称"藻类植物"；右侧特征框显示"②藻类植物：无根茎叶分化，主要生活在水中"（绿色高亮），同时步骤1高亮恢复为黑色
- 步骤3：点击「下一步」→ 蓝色高亮切换至"无种子→有茎叶→无输导组织"分支路径；终端④框变为实线绿框#2e7d32，显示类群名称"苔藓植物"；右侧特征框显示"④苔藓植物：有茎叶但无输导组织，无真正的根"（绿色高亮），同时步骤2高亮恢复为黑色
- 步骤4：点击「下一步」→ 蓝色高亮切换至"无种子→有茎叶→有输导组织"分支路径；终端③框变为实线绿框#2e7d32，显示类群名称"蕨类植物"；右侧特征框显示"③蕨类植物：有根茎叶分化，有输导组织"（绿色高亮），同时步骤3高亮恢复为黑色
- 步骤5（结论）：点击「下一步」→ 所有四个终端节点①②③④同时显示类群名称（裸子植物、藻类植物、苔藓植物、蕨类植物），所有终端框变为实线绿框#2e7d32；右侧显示完整特征总结框，列出四个类群的关键特征对比；蓝色高亮消失，恢复全图黑色

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 按钮"上一步"：ID scene1-btn-prev，位置(300,455)，作用：返回上一状态，高亮路径回退
  - 按钮"下一步"：ID scene1-btn-next，位置(420,455)，作用：进入下一状态，高亮路径前进
  - 状态指示器：ID scene1-step-indicator，位置(350,420)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始展示完整分类图框架，让学生观察整体结构
  2. 点击"下一步"逐步高亮每个分支，讲解对应类群特征
  3. 可点击"上一步"回退复习，巩固记忆
  4. 最终步骤展示完整分类体系，总结四个类群的关键区别

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（分类图为简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │                        800px                                   │
  │  ┌──────────────────────────────────────────────────────────┐  │
  │  │                                                          │  │
  │  │              无果实植物                                   │  │
  │  │                  │                                       │  │
  │  │         ┌────────┴────────┐                              │  │
  │  │      无种子              有种子①                          │  │
  │  │         │                  │                              │  │
  │  │    ┌────┴────┐             │                              │  │
  │  │  无茎叶②   有茎叶           │                              │  │
  │  │               │             │                              │  │
  │  │         ┌─────┴─────┐       │                              │  │
  │  │    有输导③    无输导④       │                              │  │
  │  │                                                          │  │
  │  │  特征框区域（右侧）                                        │  │
  │  │                                                          │  │
  │  └──────────────────────────────────────────────────────────┘  │
  │  ┌──────────────────────────────────────────────────────────┐  │
  │  │        上一步          [步骤 X/5]          下一步          │  │
  │  └──────────────────────────────────────────────────────────┘  │
  │                              500px                             │
  └────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：currentStep 变量（0-5），每一步定义高亮路径数组和特征文本
  2. 坐标计算：所有节点框、连线、标签坐标按布局坐标表精确实现
  3. 高亮动画：使用 SVG 的 class 切换实现蓝色高亮（.highlight-blue）和绿色终端框（.highlight-green）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 并调用 renderStep() 重绘
  5. 边界检查：第一步禁用"上一步"，最后一步禁用"下一步"
  6. ID 命名规范：所有交互元素 ID 以 scene1- 为前缀（如 scene1-tri-abc、scene1-btn-prev）
  7. IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局污染
  8. 特征文本显示：使用 SVG text 元素，初始 opacity=0，对应步骤时 opacity=1
