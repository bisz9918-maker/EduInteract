[分步序列]
- 步骤0（初始状态）：
  - 显示左血管（垂直线段，蓝色 #1565c0）、右血管（垂直线段，红色 #c62828）
  - 显示丝带（水平线段，灰色 #888888）横穿两血管
  - 显示左血管向上箭头（蓝色）、右血管向下箭头（红色）
  - 显示标注①②③④（圆形+数字）
  - 显示"丝带"文字标注
  - 等待教师点击"下一步"

- 步骤1：
  - 左血管高亮（加粗至6px，蓝色 #1565c0）
  - 左血管左侧显示标签"静脉：血液向心脏流动"
  - 左血管箭头闪烁高亮
  - 教师讲解：静脉血液流向心脏（向上）

- 步骤2：
  - 右血管高亮（加粗至6px，红色 #c62828）
  - 右血管右侧显示标签"动脉：血液离心脏流动"
  - 右血管箭头闪烁高亮
  - 教师讲解：动脉血液离心脏流动（向下）

- 步骤3：
  - 丝带下方区域高亮（y>250 区域加淡绿色背景 #e8f5e9）
  - 标注①周围显示绿色膨胀提示框"①膨胀：静脉血积聚"
  - 标注②周围显示灰色变扁提示框"②变扁：动脉血流空"
  - 教师讲解：丝带阻断静脉回流，①处静脉血积聚膨胀；动脉血被阻断，②处变扁

- 步骤4：
  - 丝带上区域高亮（y<250 区域加淡红色背景 #ffebee）
  - 标注③周围显示绿色膨胀提示框"③膨胀：动脉血积聚"
  - 标注④周围显示灰色变扁提示框"④变扁：静脉血流空"
  - 教师讲解：丝带阻断动脉供血，③处动脉血积聚膨胀；静脉血被阻断，④处变扁

- 步骤5（最终步骤）：
  - 显示结论框，内容为：
    "结论：左血管=静脉（血向心脏），右血管=动脉（血离心脏）
     ①④为静脉血（蓝色），②③为动脉血（红色）
     正确选项：C．血管①中血液的含氧量比血管③低"
  - 左血管和标注①④保持蓝色高亮
  - 右血管和标注②③保持红色高亮
  - 教师总结：静脉血含氧量低，动脉血含氧量高

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "上一步"按钮：ID=scene1-prev-btn，位置(300,460)，作用：返回上一步状态
  - "下一步"按钮：ID=scene1-next-btn，位置(500,460)，作用：进入下一步状态
  - 步骤指示器：ID=scene1-step-indicator，位置(380,460)，显示"步骤 1/6"
- 教师操作流程：
  1. 初始展示题目原图，让学生观察丝带和血管位置
  2. 点击"下一步"，高亮左血管并标注"静脉"，讲解静脉血流方向
  3. 点击"下一步"，高亮右血管并标注"动脉"，讲解动脉血流方向
  4. 点击"下一步"，展示丝带下方阻断效果，讲解①膨胀②变扁的原因
  5. 点击"下一步"，展示丝带上阻断效果，讲解③膨胀④变扁的原因
  6. 点击"下一步"，显示结论，引导学生选择正确答案C

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────┐
  │                                                         │
  │     ④                    ③                             │
  │     │                    │                             │
  │     │←静脉              动脉→│                         │
  │     │                    │                             │
  │     │        ────────────┼─────────── 丝带             │
  │     │                    │                             │
  │     │                    │                             │
  │     ①                    ②                             │
  │                                                         │
  │  [结论框显示在底部]                                      │
  │                                                         │
  │  ─────────────────────────────────────────────────────  │
  │  [◀上一步]  步骤 1/6  [下一步▶]                         │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 currentStep 记录当前步骤（0-5），每一步对应不同的元素显示/隐藏状态
  2. 坐标计算：所有元素使用绝对坐标，通过 SVG 的 x/y 属性精确控制位置
  3. 动画曲线：使用 CSS transition 实现高亮效果（0.3s ease-in-out）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 并调用 updateScene() 函数刷新显示
  5. 元素高亮：通过改变 stroke-width、stroke 颜色和添加背景色实现
  6. 提示框显示：通过设置 opacity 从 0 到 1 实现淡入效果
