[分步序列]
- 步骤 0（初始状态）：显示完整电路图，所有元件清晰可见，无高亮，无电流箭头。电源、开关、电流表、L₁、L₂及导线全部显示，标签完整。

- 步骤 1（识别连接方式）：
  - L₁支路导线高亮为蓝色 (#1565c0，线宽 3px)：从分支点 (650,170) 经 L₁灯泡到汇合点 (435,350)
  - L₂支路导线高亮为绿色 (#2e7d32，线宽 3px)：从分支点 (650,170) 经 L₂灯泡到汇合点 (435,350)
  - 在两条支路上添加红色电流箭头，显示电流分流
  - 在分支点旁显示文字标签"分流点"（灰色，14px）
  - 在汇合点旁显示文字标签"汇合点"（灰色，14px）
  - 视觉变化：两条独立电流路径清晰可见，展示并联特征

- 步骤 2（电流表位置）：
  - 恢复步骤 1 的高亮颜色为黑色
  - 高亮汇合点到电流表的导线为蓝色 (#1565c0，线宽 3px)：(435,350)-(160,300)
  - 高亮电流表本身为蓝色边框 (#1565c0，线宽 3px)
  - 在电流表旁显示文字标签"测干路总电流"（蓝色，14px）
  - 在电流表下方显示文字标签"I = I₁ + I₂"（蓝色，14px）
  - 视觉变化：突出电流表位于两条支路汇合之后，测量的是总电流

- 步骤 3（开关控制范围）：
  - 恢复步骤 2 的高亮颜色为黑色
  - 高亮电源正极到分支点的导线为红色 (#c62828，线宽 3px)：(490,70)-(580,130)-(650,170)
  - 高亮开关 S 为红色边框 (#c62828，线宽 3px)
  - 在开关旁显示文字标签"控制整个电路"（红色，14px）
  - 在电源旁显示文字标签"干路"（红色，14px）
  - 视觉变化：突出开关位于干路，控制整个电路的通断

- 步骤 4（结论总结）：
  - 同时显示所有关键信息：
    - L₁支路蓝色高亮 + L₂支路绿色高亮
    - 电流表蓝色高亮
    - 开关红色高亮
  - 在图示右侧显示结论框（白色背景，黑色边框）：
    - "L₁与 L₂并联"（黑色，16px）
    - "电流表测干路总电流"（黑色，16px）
    - "开关控制整个电路"（黑色，16px）
  - 在结论框下方显示选项判断：
    - "A 错误：L₁、L₂是并联，非串联"（红色，14px）
    - "B 错误：电流表测总电流，非仅 L₁"（红色，14px）
    - "C 错误：电流表测总电流，非仅 L₂"（红色，14px）
    - "D 错误：开关控制整个电路，非仅 L₂"（红色，14px）
  - 视觉变化：完整展示电路分析结论，明确各选项正误

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮：位于 SVG 底部左侧 (100,450)，灰色背景，文字"◀ 上一步"
  - 下一步按钮：位于 SVG 底部右侧 (650,450)，灰色背景，文字"下一步 ▶"
  - 步骤指示器：位于 SVG 底部中央 (350,450)，显示"步骤 1/5"
- 教师操作流程：
  1. 初始展示完整电路图，让学生观察整体结构
  2. 点击"下一步"进入步骤 1，高亮两条支路，讲解并联特征
  3. 点击"下一步"进入步骤 2，高亮电流表，讲解测量对象
  4. 点击"下一步"进入步骤 3，高亮开关，讲解控制范围
  5. 点击"下一步"进入步骤 4，展示完整结论和选项判断
  6. 可随时点击"上一步"回退复习某个环节

- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量 (0-4) 跟踪当前步骤，根据步骤值控制各元素的 display/class 属性
  2. 坐标计算：所有导线用 SVG <line>、<polyline>、<path> 元素，坐标按布局表精确设置
  3. 动画曲线：高亮切换使用 CSS transition (0.3s ease)，电流箭头使用 SVG <animate> 或 JS 定时器实现流动效果
  4. 事件绑定：上一步/下一步按钮绑定 click 事件，更新 currentStep 并调用 updateStep() 函数刷新显示
  5. ID 命名规范：所有元素 ID 以 scene1- 为前缀，如 scene1-battery、scene1-switch、scene1-lamp1、scene1-ammeter、scene1-wire-xxx
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 高亮实现：通过切换元素的 stroke 属性和 stroke-width 实现高亮效果，使用 class 控制 (如 .highlight-blue、.highlight-green、.highlight-red)
  8. 结论框：步骤 4 时显示，使用 SVG <rect> + <text> 组合，初始 display="none"
