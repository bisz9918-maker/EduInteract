[交互方案]

- 控件说明：
  - 上一步按钮：位于控件栏左侧(250,460)，80×30px，点击返回上一步状态
  - 下一步按钮：位于控件栏右侧(470,460)，80×30px，点击进入下一步状态
- 教师操作流程：
  1. 初始展示地球基础网格，讲解经纬线系统
  2. 点击下一步，展示昼夜半球与阳光入射，讲解昼夜成因
  3. 点击下一步，高亮晨昏线，讲解晨昏线概念
  4. 点击下一步，标注A/B/C三点，讲解各点位置特征
  5. 点击下一步，完成全部标注，配合讲解太阳高度角、昼夜长短计算

[技术实现]
- JS 库选择：原生 SVG（简单几何首选，适合绘制圆形、直线、曲线、多边形等地理图示元素）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌────────────────────────────────────────────────────────┐
  │                                                        │
  │           N                                            │
  │         73°41'                                         │
  │      ╭─────────────╮                                   │
  │     ╱    B    ╱│╲   ╲                                  │
  │    ╱        ╱  │  ╲   ╲                                │
  │   │   夜   ╱   │A   ╲  昼 │                            │
  │   │   半   ╲   │    ╲  半 │                            │
  │   │   球   ╲  │     ╲ 球  │                            │
  │    ╲        ╲  │      ╲   ╱                            │
  │     ╲        ╲ │       ╲ ╱                              │
  │      ╰─────────────╯                                   │
  │           S                                            │
  │                                                        │
  │              ←←← 阳光                                  │
  │                                                        │
  │  ┌────────────────────────────────────────────────┐   │
  │  │          ◀上一步      下一步▶                  │   │
  │  └────────────────────────────────────────────────┘   │
  └────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量（0-4）跟踪当前步骤，steps 数组存储每步应显示的元素 ID 列表
  2. 坐标计算：所有元素使用绝对坐标，地球圆心(400,250)，半径180px
  3. 晨昏线绘制：使用 SVG path 绘制 S 形曲线，从北极附近经 A 点到南极附近
  4. 昼夜半球填充：使用 SVG polygon 或 clipPath 实现晨昏线两侧的填充
  5. 动画曲线：步骤切换使用 opacity 渐变（0.3s ease-in-out）实现平滑过渡
  6. 事件绑定：上一步/下一步按钮绑定 click 事件，更新 currentStep 并调用 updateDisplay()
  7. ID 命名规范：所有交互元素 ID 以 scene1- 为前缀（如 scene1-earth, scene1-晨昏线，scene1-prev-btn）
  8. JS 使用 getElementById 获取元素，避免 querySelectorAll 跨场景污染
  9. IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中
