[分步序列]
- 初始状态（步骤0）：显示地球轮廓、夜半球填充、赤道、经线群、晨昏线、N/S点、A/B/C三点、太阳光线、73°41'标注。等待教师触发交互。

- 步骤1：点击「下一步」→ A点高亮圈（红色虚线圆，闪烁效果）出现，A点太阳高度标注"A: 0°"显示在A点右下方。讲解：晨昏线上的点太阳高度为0°。

- 步骤2：点击「下一步」→ C点高亮圈（绿色虚线圆，闪烁效果）出现，C点太阳高度标注"C: 73°41'"显示在C点左上方。讲解：C点接近直射点，太阳高度最大，等于90°减去纬度差。

- 步骤3：点击「下一步」→ B点纬线高亮（蓝色虚线），B点昼弧（蓝色填充30%）和夜弧（灰色填充30%）显示，B点昼长标注"B昼长=16h"显示在B点上方。讲解：B点所在纬线昼弧约占2/3，昼长=24×(昼弧角度/360)≈16小时。

- 步骤4：点击「下一步」→ 南半球对称纬线的昼弧（绿色填充20%）和夜弧（灰色填充30%）显示，南半球标注"南半球昼短夜长"显示在右侧。讲解：南北半球昼夜状况相反，北半球昼长夜短时，南半球昼短夜长。

- 结论（步骤5）：点击「下一步」→ 所有标注同时显示，汇总答案：(1)A点0°，C点73°41'；(2)B点昼长16小时，A点夜长12小时；(3)南半球昼短夜长；(4)北京时间计算（根据经度差）。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮：位于SVG底部左侧(100,460)，作用：返回前一步骤
  - 下一步按钮：位于SVG底部右侧(650,460)，作用：进入下一步骤
  - 步骤指示器：位于SVG底部中央(350,460)，显示"步骤 k/5"
- 教师操作流程：
  1. 初始展示基础光照图，让学生观察晨昏线、昼夜分布
  2. 点击"下一步"，逐步高亮A/B/C点，讲解太阳高度概念
  3. 继续点击"下一步"，展示B点纬线的昼弧夜弧，讲解昼长计算
  4. 最后展示南半球对比，强调南北半球昼夜状况相反
  5. 可随时点击"上一步"回退复习关键概念

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂计算库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    图示区 800×500                       │
  │                                                         │
  │           N                                            │
  │            ●                                           │
  │          /   \                                         │
  │         |  ●B |                                        │
  │        |   ○   |                                       │
  │       |    A    |                                      │
  │      |     ○     |                                     │
  │       |    ○C    |  →→→ 太阳光线                       │
  │        |   ○   |                                       │
  │         |     |                                        │
  │          \   /                                         │
  │            ●                                           │
  │           S                                            │
  │                                                         │
  │  [◀上一步]          步骤 k/5           [下一步▶]        │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 currentStep 记录当前步骤（0-5），每一步对应一个显示配置对象
  2. 坐标计算：地球中心(400,250)，半径180，各点坐标按三角函数计算椭圆投影位置
  3. 动画曲线：高亮圈使用 CSS keyframes 实现闪烁效果（opacity 0.3→1→0.3，周期1s）
  4. 事件绑定：按钮点击事件更新 currentStep，调用 renderStep() 重新渲染对应元素
  5. ID 命名规范：所有交互元素 ID 以 scene2- 为前缀（如 scene2-circle-earth、scene2-btn-next、scene2-label-A）
  6. IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局污染
  7. 元素显示控制：使用 display: none/block 或 opacity 控制各步骤元素的显示/隐藏
  8. 晨昏线绘制：使用 SVG path 绘制倾斜椭圆弧，角度约 23.5°（黄赤交角）
  9. 昼弧夜弧：使用 SVG path 绘制椭圆弧段，fill 属性控制填充色和透明度
