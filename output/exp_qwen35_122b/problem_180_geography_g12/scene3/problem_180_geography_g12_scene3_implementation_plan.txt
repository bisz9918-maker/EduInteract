  - 说明：最终得出北京时间

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮（scene3-prev-btn）：位于 (220,450)，点击返回上一步，步骤 0 时禁用
  - 下一步按钮（scene3-next-btn）：位于 (480,450)，点击进入下一步，步骤 5 时变为「完成」
- 教师操作流程：
  1. 初始展示基础光照图，让学生观察 A/B/C 点位置
  2. 点击下一步，高亮 C 点经线，讲解正午地方时概念
  3. 点击下一步，标注西半球范围，复习经度范围知识
  4. 点击下一步，展示时间计算框，逐步推导 C 点经度
  5. 点击下一步，引入 120°E 经线，计算经度差
  6. 点击下一步，完成时间换算，得出北京时间结论
  7. 可随时点击上一步回顾关键步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何和文本标注，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │ 800px                                                          │
  │                                                                │
  │     73°41'                                                     │
  │        N                    ┌──────────────────┐              │
  │        ●                    │  时间计算框      │              │
  │       /│\                   │                  │              │
  │      / │ \                  │  步骤 1...       │              │
  │     /  │  \                 │  步骤 2...       │              │
  │    ●───┼───●───────●        │  步骤 3...       │              │
  │   B   │   A      C         │  步骤 4...       │              │
  │    \  │  /                 │  步骤 5...       │              │
  │     \ │ /                  └──────────────────┘              │
  │      \│/                                                       │
  │        S                                                       │
  │                                                                │
  │  ←←← 太阳光线                                                  │
  │                                                                │
  │                   [◀上一步]  [下一步▶]                         │
  │                                                                │
  └────────────────────────────────────────────────────────────────┘
                              500px
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep 记录当前步骤（0-5），每一步根据 currentStep 控制元素显示/隐藏
  2. 坐标计算：所有元素使用绝对定位，SVG 内元素用 x/y 属性精确控制
  3. 动画曲线：元素出现使用 opacity 过渡（0→1，duration 300ms）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 renderStep() 重绘
  5. ID 命名规范：所有交互元素 ID 以 scene3- 为前缀（如 scene3-circle-earth、scene3-line-c-meridian、scene3-prev-btn、scene3-next-btn）
  6. IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局污染
  7. 时间计算框内容：用 innerHTML 逐步追加文本，每步追加对应步骤内容
  8. 经度差弧线：用 SVG path 绘制贝塞尔曲线，连接 C 点经线与 120°E 经线
