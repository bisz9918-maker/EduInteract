[图示主题与整合说明]
- 本图示主题：极地俯视图中的气压带风带分布及半球季节判断
- 整合内容：整合极地俯视图的半球判断（根据风向偏转方向）、季节判断（根据气压带位置偏移）、气压带风带的平面分布识别
- 教学价值：教师可引导学生先观察风向偏转判断半球，再观察气压带位置判断季节，分步推理帮助学生建立地理空间思维

[分步序列]
- 步骤 0（初始状态）：显示完整极地俯视图基础图，包括经线、纬度圈、气压带椭圆、a/b 两点及风向箭头，无偏转标注和结论文字
- 步骤 1：高亮 a、b 两点的风向箭头（加粗至 3px，颜色加深），其他元素正常显示
- 步骤 2：在 b 点附近显示"右偏"标注（红色粗体），在 a 点附近显示"左偏"标注（绿色粗体）
- 步骤 3：在左侧显示"北半球：风向右偏"结论（红色粗体），同时高亮 b 点所在区域
- 步骤 4：高亮副热带高气压带椭圆（边框加粗至 3px），显示气压带位置向北偏移的提示箭头
- 步骤 5：在左侧显示"夏季：气压带北移"结论（绿色粗体），完成全部推理展示

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：位置 (320,460)，作用：返回上一推理步骤
  - "下一步 ▶"按钮：位置 (460,460)，作用：进入下一推理步骤
  - 步骤指示器：位置 (380,430)，显示"步骤 X/5"
- 教师操作流程：
  1. 展示基础图，引导学生观察 a、b 两点风向
  2. 点击下一步，高亮风向箭头，强调观察重点
  3. 点击下一步，显示偏转方向标注，讲解地转偏向力
  4. 点击下一步，得出半球判断结论
  5. 点击下一步，高亮气压带位置，讲解季节偏移规律
  6. 点击下一步，得出季节判断结论，完成推理

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    图示区 800×500                       │
  │                                                         │
  │   [结论区]              [极地俯视图区]                  │
  │   北半球：风向右偏      (中心 550,250)                  │
  │   夏季：气压带北移      经线辐射 + 纬度圈 + 气压带       │
  │                                                         │
  │   [图例]                a/b 点 + 风向箭头               │
  │                                                         │
  │   ┌─────────────────────────────────────────────────┐  │
  │   │  ◀ 上一步    步骤 X/5    下一步 ▶              │  │
  │   └─────────────────────────────────────────────────┘  │
  │   (控件栏 y=430~490)                                    │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：currentStep 变量 (0-5)，updateScene() 函数根据 currentStep 控制元素显示/隐藏/高亮
  2. 坐标计算：以 (550,250) 为极点中心，经线按 0°/90°/180°/270° 辐射，纬度圈用 SVG circle
  3. 动画曲线：元素出现使用 opacity 渐变 (0→1)，高亮使用 stroke-width 变化
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateScene()
  5. ID 命名规范：所有元素 ID 以 scene2- 为前缀（如 scene2-circle-30deg、scene2-arrow-a）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 初始状态：页面加载后自动显示步骤 0，按钮根据当前步骤启用/禁用（步骤 0 禁用上一步，步骤 5 禁用下一步）
