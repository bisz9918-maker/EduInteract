[分步序列]
步骤0（初始状态）：
- 显示完整经纬网框架（7条经线、7条纬线）
- 显示经度标注（180°W, 120°W, 60°W, 0°, 60°E, 120°E, 180°E）在底部
- 显示纬度标注（90°N, 60°N, 30°N, 0°, 30°S, 60°S, 90°S）在左侧
- 显示B、C、D、E四个点（蓝色实心圆）
- 隐藏所有路径线段和计算框

步骤1：
- 高亮显示 B→C 路径（红色线段）
- 在 B→C 路径左侧显示"纬度差 30°"标签（坐标 420, 283）

步骤2：
- 显示经线距离计算框（红色边框，坐标 350, 350）
- 框内文字："经线距离公式：距离 = 纬度差 × 111km"

步骤3：
- 在经线距离框内补充计算结果："B→C距离 = 30° × 111km = 3330km"

步骤4：
- 高亮显示 D→E 路径（绿色线段）
- 在 D→E 路径上方显示"经度差 60°"标签（坐标 650, 100）
- 在 D→E 路径上方补充"纬度 60°N"标签（坐标 650, 85）

步骤5：
- 显示纬线距离计算框（绿色边框，坐标 550, 150）
- 框内文字："纬线距离公式：距离 = 经度差 × 111 × cos(纬度)"

步骤6：
- 在纬线距离框内补充计算结果："D→E距离 = 60° × 111 × cos60° = 60 × 111 × 0.5 = 3330km"

步骤7：
- 显示速度计算框（蓝色边框，坐标 350, 400）
- 框内文字："飞机速度 = 3330km ÷ 3h = 1110km/h"

步骤8（最终步骤）：
- 显示时间计算框（绿色边框，坐标 550, 250）
- 框内文字："D→E时间 = 3330km ÷ 1110km/h = 3小时"
- 高亮显示两个路径的等距对比（B→C和D→E都是3330km）

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形和文本标注，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
```
┌────────────────────────────────────────────────────────────────┐
│                        经纬网示意图                              │
│  90°N  ─────────────────────────────────────────────────────   │
│   60°N  ────────────────────────────────────────────────────   │
│          D●───────────────────────●E                            │
│   30°N  ────────────────────────────────────────────────────   │
│              A●                                                  │
│    0°   ─────────────────────────────────────────────────────   │
│                      ●C                                          │
│  30°S  ─────────────────────────────────────────────────────   │
│                      ●B                                          │
│  60°S  ─────────────────────────────────────────────────────   │
│  90°S  ─────────────────────────────────────────────────────   │
│       180°W 120°W 60°W   0°   60°E 120°E  180°E                 │
│                                                                  │
│  [经线距离框]                    [纬线距离框]                    │

│              步骤指示器        [上一步]  [下一步]                │
└────────────────────────────────────────────────────────────────┘
```

- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-8) 跟踪当前步骤
  2. 坐标计算：经纬网采用等间距布局，经线间距 133px，纬线间距 67px
  3. 元素显示控制：每个步骤控制特定元素的 opacity 或 display 属性
  4. 事件绑定：按钮点击事件监听，更新 currentStep 并刷新显示
  5. 动画效果：元素出现时使用淡入动画（opacity 0→1，过渡时间 0.3s）

- ID 命名规范：
  - 所有交互元素 ID 以 scene3- 为前缀
  - 经线：scene3-meridian-0 至 scene3-meridian-6
  - 纬线：scene3-parallel-0 至 scene3-parallel-6
  - 点：scene3-point-B, scene3-point-C, scene3-point-D, scene3-point-E
  - 路径：scene3-path-BC, scene3-path-DE
  - 计算框：scene3-box-meridian, scene3-box-parallel, scene3-box-speed, scene3-box-time
  - 标签：scene3-label-B, scene3-label-C, scene3-label-D, scene3-label-E, scene3-label-lat-diff, scene3-label-lon-diff, scene3-label-lat-60n
  - 控件：scene3-btn-prev, scene3-btn-next, scene3-step-indicator

- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染
