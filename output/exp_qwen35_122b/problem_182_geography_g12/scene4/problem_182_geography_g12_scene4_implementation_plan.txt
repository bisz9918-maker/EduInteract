[图示主题与整合说明]

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（线条、圆形、矩形），无需复杂图表库，原生实现轻量高效
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │  180°  120°W  60°W    0°    60°E  120°E   180°             │ ← 经度标签
  │  ┌───────────────────────────────────────────────────────┐  │
  │  │                    90°N                               │  │
  │  │  ─────────────────────────────────────────────────    │  │ ← 纬线90°N
  │  │                        D         E                    │  │
  │  │  ─────────────────────────────────────────────────    │  │ ← 纬线60°N
  │  │                        A                              │  │
  │  │  ─────────────────────────────────────────────────    │  │ ← 纬线30°N
  │  │                        C                              │  │
  │  │  ─────────────────────────────────────────────────    │  │ ← 赤道
  │  │                        B                              │  │
  │  │  ─────────────────────────────────────────────────    │  │ ← 纬线30°S
  │  │                                                       │  │
  │  │  ─────────────────────────────────────────────────    │  │ ← 纬线60°S
  │  │                                                       │  │
  │  │  ─────────────────────────────────────────────────    │  │ ← 纬线90°S
  │  │                    90°S                               │  │
  │  └───────────────────────────────────────────────────────┘  │
  │  夜半球区域(阴影)  │  昼半球区域                            │
  │  (180°~30°E)       │                                        │
  │                                                            │
  │  [◀ 上一步]  步骤X/6  [下一步 ▶]                           │ ← 控件栏
  └─────────────────────────────────────────────────────────────┘
  ```

- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0~6) 跟踪当前步骤，每一步定义显示/隐藏的元素ID列表
  2. 坐标计算：经度→x = 100 + (经度+180)×600/360；纬度→y = 50 + (90-纬度)×400/180
  3. 元素显示控制：通过 setElementVisible(stepNumber, elementId, true/false) 函数控制各步骤元素可见性
  4. 阴影填充：使用 SVG <rect> 元素，设置 fill="#c62828" 和 opacity="0.3"
  5. 事件绑定：上一步/下一步按钮点击事件，更新 currentStep 并刷新显示
  6. 步骤指示器：实时更新显示"步骤X/6"

- ID 命名规范：所有交互元素 ID 以 scene4- 为前缀
  - 经线：scene4-meridian-180, scene4-meridian-120w, scene4-meridian-60w, scene4-meridian-0, scene4-meridian-60e, scene4-meridian-120e, scene4-meridian-180r
  - 纬线：scene4-latitude-90n, scene4-latitude-60n, scene4-latitude-30n, scene4-latitude-0, scene4-latitude-30s, scene4-latitude-60s, scene4-latitude-90s
  - A点相关：scene4-point-a, scene4-label-a, scene4-label-a-coord, scene4-label-a-time
  - 晨昏线：scene4-terminator-dawn, scene4-label-dawn, scene4-label-dawn-time, scene4-terminator-dusk, scene4-label-dusk, scene4-label-dusk-time
  - 夜半球：scene4-night-hemisphere, scene4-label-night, scene4-label-day
  - 控件：scene4-prev-btn, scene4-next-btn, scene4-step-indicator
  - 说明框：scene4-explanation-1, scene4-explanation-2, scene4-explanation-3

- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染
