[分步序列]
本场景为连续拖拽交互，无分步导航，实时反馈：

- 初始状态（滑块位置0）：
  - 地球位于A点（夏至）
  - 太阳直射点：23.5°N（曲线最高点）
  - 北半球昼长：最长（条形图绿色条满格）
  - 北半球夜长：最短（条形图灰色条最短）
  - 南极圈：极夜状态
  - 南回归线以南正午太阳高度：较小（曲线最低点）

- 拖拽过程（滑块位置0→25→50→75→100）：
  - 地球沿轨道从A→B→C→D→A连续移动
  - 太阳直射点纬度：23.5°N→0°→23.5°S→0°→23.5°N连续变化
  - 北半球昼长：最长→12小时→最短→12小时→最长连续变化
  - 南极圈状态：极夜→无极昼极夜→极昼→无极昼极夜→极夜
  - 南回归线以南正午太阳高度：较小→中等→最大(90°)→中等→较小连续变化

- 关键位置（滑块位置对应点）：
  - 位置0（A点/夏至）：直射23.5°N，昼最长，南极圈极夜，南回归线高度最小
  - 位置25（B点/秋分）：直射0°，昼夜等长12小时，无极昼极夜，南回归线高度中等
  - 位置50（C点/冬至）：直射23.5°S，昼最短，南极圈极昼，南回归线高度最大(90°)
  - 位置75（D点/春分）：直射0°，昼夜等长12小时，无极昼极夜，南回归线高度中等
  - 位置100（回到A点）：循环

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：
  - 滑块：id="scene2-slider"，位置(340,450)-(780,470)，范围0-100，步长1
  - 作用：拖动滑块控制地球在公转轨道上的位置，实时联动所有数据面板
- 教师操作流程：
  1. 初始展示地球在A点（夏至），讲解此时太阳直射北回归线，北半球昼最长
  2. 缓慢拖动滑块从0→25，观察地球移动到B点（秋分），直射点回到赤道，昼夜等长
  3. 继续拖动25→50，地球到C点（冬至），直射南回归线，北半球昼最短，南极圈极昼
  4. 继续拖动50→75→100，完成一个公转周期，强调循环规律
  5. 可反复拖动，让学生观察任意位置对应的直射点纬度、昼夜长短、太阳高度

- 关键实现要点：
  1. 状态机设计：用单一变量 `earthPosition` (0-100) 表示地球在轨道上的位置，所有视觉元素根据此变量计算
  2. 坐标计算：
     - 地球位置：根据椭圆参数方程 x=160+140*cos(θ), y=250+100*sin(θ)，其中θ=2π*(earthPosition/100-0.25)
     - 太阳直射点纬度：y=80+27.5*sin(2π*earthPosition/100)
     - 昼长：根据直射点纬度计算，夏至15h→冬至9h线性插值
     - 正午太阳高度：南回归线以南地区，冬至时90°，夏至时最小
  3. 动画曲线：使用 SVG path 的 smooth curve，地球移动用 requestAnimationFrame 实现平滑过渡
  4. 事件绑定：slider 的 input 事件触发所有元素重绘，地球位置、曲线上的点、条形图高度同步更新
  5. ID 命名规范：所有元素 ID 以"scene2-"为前缀，如 scene2-orbit, scene2-sun, scene2-earth, scene2-slider, scene2-lat-curve, scene2-day-bar, scene2-night-bar, scene2-height-curve
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染

- 地球位置计算函数：
  ```javascript
  function getEarthPosition(p) {
    // p: 0-100, 0=A(夏至), 25=B(秋分), 50=C(冬至), 75=D(春分), 100=A
    const angle = 2 * Math.PI * (p / 100 - 0.25);
    return {
      x: 160 + 140 * Math.cos(angle),
      y: 250 + 100 * Math.sin(angle)
    };
  }
  ```

- 太阳直射点纬度计算：
  ```javascript
  function getDeclination(p) {
    // 返回纬度值，正为北，负为南
    return 23.5 * Math.sin(2 * Math.PI * p / 100);
  }
  ```

- 昼长计算（北半球）：
  ```javascript
  function getDayLength(p) {
    // 夏至15h, 冬至9h, 春秋分12h
    const declination = getDeclination(p);
    return 12 + 3 * Math.sin(2 * Math.PI * p / 100);
  }
  ```

- 南回归线以南正午太阳高度：
  ```javascript
  function getNoonHeight(p) {
    // 冬至(直射南回归线)时90°, 夏至时最小
    const declination = getDeclination(p);
    return 90 - Math.abs(declination + 23.5);
  }
  ```
