[分步序列]
- 步骤 0（初始状态）：显示基础日照图
  - 显示：赤道/30°/60°纬线圈，0°/180°/90°E/90°W经线，北极点，夜半球阴影（半透明蓝色）
  - 显示：E、F、G 三点位置（小圆点）
  - 显示：经纬度标签（0°、180°、60°N、赤道）
  - 隐藏：晨昏线高亮、直射点标记、太阳光线、昼夜半球标签、直射点坐标标签
  - 状态指示："步骤 1/5"

- 步骤 1：高亮晨昏线
  - 新增：晨昏线（黑色粗线，从左上到右下）
  - 新增：晨昏线标签"晨昏线"
  - 高亮：晨昏线加粗闪烁效果
  - 说明：晨昏线是昼夜半球的分界线，此图中晨昏线与经线圈重合，说明是二分日
  - 状态指示："步骤 2/5"

- 步骤 2：标注太阳直射点
  - 新增：太阳光线（红色平行箭头，从右侧射入）
  - 新增：太阳光线标签"太阳光线"
  - 新增：直射点标记（绿色实心圆，位于 G 点位置）
  - 新增：直射点标签"直射点(23°26'N,90°E)"
  - 说明：太阳光线垂直照射赤道与 90°E 经线交点，说明太阳直射赤道（二分日）
  - 状态指示："步骤 3/5"

- 步骤 3：显示经度与时间
  - 新增：昼半球标签"昼半球"、夜半球标签"夜半球"
  - 高亮：90°E 经线（加粗显示）
  - 新增：时间标注"12:00"在直射点附近
  - 说明：直射点所在经线（90°E）地方时为 12 时，可推算其他经线时间
  - 状态指示："步骤 4/5"

- 步骤 4：标注昼夜分布
  - 高亮：E、F、G 三点（放大并加粗）
  - 新增：昼夜长短说明"E 点：昼夜等长；F 点：昼夜等长；G 点：昼夜等长"
  - 说明：二分日全球昼夜等长，各纬度均为 12 小时昼、12 小时夜
  - 状态指示："步骤 5/5"

- 结论状态：综合地理现象
  - 显示：所有元素
  - 新增：结论框显示关键答案
    - 节气：春分或秋分（二分日）
    - 直射点坐标：(0°, 90°E)
    - 北京时间：14 时（90°E 为 12 时，120°E 为 14 时）
    - 正午太阳高度公式：H = 90° - |φ - δ|
    - 自转线速度：G > F > E（纬度越低线速度越大）
  - 状态指示："结论"

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮（scene2-prev-btn）：位于控件栏左侧，点击返回上一状态，步骤 0 时禁用
  - 下一步按钮（scene2-next-btn）：位于控件栏右侧，点击进入下一状态，结论状态时变为"重播"
  - 步骤指示器：位于控件栏中央，显示当前步骤/总步骤
- 教师操作流程：
  1. 初始展示基础日照图，让学生观察经纬网和昼夜分布
  2. 点击"下一步"高亮晨昏线，讲解晨昏线的识别方法
  3. 点击"下一步"显示太阳光线和直射点，讲解直射点的确定
  4. 点击"下一步"标注时间，讲解地方时计算
  5. 点击"下一步"标注昼夜分布，讲解昼夜长短分析
  6. 到达结论状态，展示所有问题的答案和计算过程
  7. 可随时点击"上一步"回退复习某个知识点

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    日照图（800×500）                      │
  │                                                         │
  │              0°经线                                      │
  │                │                                        │
  │        夜半球  │  昼半球                                 │
  │    ╭───────╮   │   ╭───────╮                            │
  │   ╱   E    ╲  │  ╱   F    ╲  G→太阳光线                  │
  │  │    ●    │  │  │    ●    │  ●                        │
  │  │   ╭─╮   │  │  │   ╭─╮   │                           │
  │  │   │●│   │  │  │   │●│   │                           │
  │  │   ╰─╯   │  │  │   ╰─╯   │                           │
  │   ╲       ╱  │  ╲       ╱                               │
  │    ╰───────╯   │   ╰───────╯                            │
  │                │                                        │
  │              180°经线                                    │
  │                                                         │
  │  ┌─────────────────────────────────────────────────┐   │
  │  │  ◀上一步    步骤 1/5    下一步▶                    │   │
  │  └─────────────────────────────────────────────────┘   │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量（0-5）跟踪当前步骤，每个步骤对应一个显示配置对象
  2. 坐标计算：所有元素坐标硬编码在配置对象中，确保精确到像素级
  3. 动画曲线：晨昏线高亮使用 CSS transition 实现加粗效果，直射点出现使用 opacity 淡入
  4. 事件绑定：按钮点击事件绑定到 scene2-prev-btn 和 scene2-next-btn，更新 currentStep 后调用 renderStep()
  5. ID 命名规范：所有元素 ID 以 scene2- 为前缀（如 scene2-circle-equator、scene2-line-terminator、scene2-point-E）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染
  7. 步骤切换：renderStep() 函数根据 currentStep 显示/隐藏对应元素，更新步骤指示器文本
  8. 禁用状态：步骤 0 时上一步按钮 disabled，结论状态时下一步按钮文本改为"重播"
