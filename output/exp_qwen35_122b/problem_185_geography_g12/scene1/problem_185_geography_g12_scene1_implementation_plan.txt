[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    [图示区 800×500]                     │
  │                                                         │
  │              30°N                                       │
  │                ↑                                        │
  │          45°E |                                         │
  │            A  ●  B                                      │
  │           ╱  ╲ ╱  ╲                                     │
  │          ╱ 昼 ╲昏 ╲                                    │
  │         ╱  弧  ╲线 ╲                                   │
  │        ╱───────────╲                                  │
  │       ╱    夜弧      ╲                                 │
  │      ╱                ╲                                │
  │     └──────────────────┘                               │
  │                45°W                                    │
  │                                                         │
  │         [◀上一步]        [下一步▶]                      │
  │              (y=455)                                   │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用 currentStep 变量跟踪当前步骤（0-4），每个步骤对应一个元素显示数组
  2. 坐标计算：A点坐标=(400-180*cos(15°), 250-180*sin(15°))≈(235,207)；B点坐标=(400+180*cos(15°), 250-180*sin(15°))≈(565,207)
  3. 动画曲线：元素出现使用 opacity 从 0 到 1 的过渡动画（duration=300ms）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateDisplay() 函数
  5. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-circle、scene1-晨线、scene1-A-point）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 昼弧/夜弧 path 计算：使用 SVG arc 命令，昼弧从A到B逆时针，夜弧从B到A逆时针
