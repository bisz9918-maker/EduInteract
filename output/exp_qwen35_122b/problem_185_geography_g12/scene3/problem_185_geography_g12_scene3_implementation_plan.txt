[分步序列]
- 步骤 0（初始状态）：显示纬线圈、北极点及标签、A 点及标签、B 点及标签、经线网格及经度标签、30°N 标签。等待教师点击"下一步"。
- 步骤 1：点击"下一步"→ 显示纬线路径（灰色虚线，沿 30°N 从 A 到 B 的劣弧）和大圆航线（蓝色粗实线，从 A 到 B 凸向北极）。新增标签"纬线路径"和"大圆航线"。教师讲解：两点间最短距离是大圆航线，不是沿纬线。
- 步骤 2：点击"下一步"→ 显示三个方向箭头，分别标注在大圆航线的起点、中点、终点位置，显示飞行方向变化。教师讲解：方向从东北逐渐转向正北，再转向东南。
- 步骤 3（最终步骤）：点击"下一步"→ 显示"先向东北"和"后向东南"文字标签，完整标注飞行方向变化规律。教师总结：从 A 到 B 的最短航线方向是先向东北，后向东南。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：位置(250,450)-(350,480)，点击回退到上一状态
  - "下一步 ▶"按钮：位置(450,450)-(550,480)，点击进入下一状态
  - 步骤指示器：位置(360,455)-(440,475)，显示"步骤 X/4"
- 教师操作流程：
  1. 初始展示 A、B 两点位置和经线网格，让学生识别两点位置
  2. 点击"下一步"展示纬线路径和大圆航线，对比两条路径
  3. 点击"下一步"展示方向箭头，观察方向变化
  4. 点击"下一步"展示方向文字说明，总结规律
  5. 可随时点击"上一步"回退复习

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需复杂动画库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────┐
  │                    [图示区 800×500]                  │
  │                                                     │
  │              45°E                                   │
  │                │                                    │
  │          ┌─────┼─────┐                              │
  │         /      │      \                             │
  │        /   大圆航线    \                             │
  │       A───────●────────B                            │
  │        \  纬线路径    /                             │
  │         \            /                              │
  │          └─────┬─────┘                              │
  │                │                                    │
  │              45°W                                   │
  │                                                     │
  │        [◀ 上一步]  [步骤 X/4]  [下一步 ▶]            │
  └─────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 currentStep 记录当前步骤（0-3），根据 currentStep 控制各元素的 display 属性
  2. 坐标计算：
     - 圆心(400,250)，半径 180
     - A 点：(400-180, 250) = (220, 250)
     - B 点：(400+180, 250) = (580, 250)
     - 大圆航线：使用 SVG path 的弧线命令，从 A 到 B，控制点设为(400, 100)使弧线凸向北极
     - 纬线路径：使用 SVG path 的弧线命令，从 A 到 B 沿上半圆
  3. 动画曲线：无复杂动画，仅元素显示/隐藏
  4. 事件绑定：按钮点击事件监听，更新 currentStep 并刷新元素显示状态
  5. ID 命名规范：所有元素 ID 以"scene3-"为前缀（如 scene3-circle、scene3-point-a、scene3-btn-next）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
- SVG path 示例：
  - 大圆航线：M 220,250 Q 400,100 580,250（二次贝塞尔曲线，控制点(400,100)）
  - 纬线路径：M 220,250 A 180,180 0 0,1 580,250（椭圆弧，半径 180，上半圆）
