[图示主题与整合说明]
- 本图示主题：四地点地理坐标计算与空间分布
- 整合内容：整合了经度计算（时差法）、纬度计算（太阳高度法）、四地在世界地图上的位置标注、相对方向判断
- 教学价值：教师可逐步展示从原始数据（热水器倾角、地方时）到地理坐标计算的完整推理过程，帮助学生理解时差与经度的关系、正午太阳高度与纬度的关系

[分步序列]
- 步骤 0（初始状态）：显示世界地图底图、0°经线、赤道、四地标记点（不显示坐标标签），计算框显示"根据热水器倾角和地方时计算地理坐标"，坐标列表框空白
- 步骤 1：计算框显示"经度计算：经度 = (当地 12 时 - 世界时) × 15°"，四地标记点旁显示经度标注（①120°E、②60°E、③0°、④180°）
- 步骤 2：计算框显示"纬度计算：正午太阳高度 = 90° - 倾角，纬度 = 23°26' + (90° - 正午太阳高度 - 23°26')"，四地标记点旁显示纬度标注（①30°N、②50°N、③52°N、④37°N）
- 步骤 3：四地完整坐标标签显示（①30°N,120°E、②50°N,60°E、③52°N,0°、④37°N,180°），坐标列表框显示四地完整坐标
- 步骤 4：显示从①地指向④地的红色方向箭头，方向标签显示"④在①东北方向"，区域地理标签显示（①附近"沪宁杭"、③附近"北海渔场"）
- 步骤 5（结论）：所有元素高亮显示，计算框显示"结论：四地坐标已确定，可用于后续分析"，坐标列表框完整显示

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：位置(280,460)，作用：返回上一步骤
  - "下一步 ▶"按钮：位置(500,460)，作用：进入下一步骤
- 教师操作流程：
  1. 从步骤 0 开始，展示基础地图和四地位置
  2. 点击"下一步"逐步展示经度计算、纬度计算过程
  3. 步骤 3 展示完整坐标，步骤 4 展示方向关系和区域地理信息
  4. 步骤 5 总结结论，教师可点击"上一步"回退复习关键步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何和文本标注，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────┐
  │                    世界地图底图                          │
  │         0°经线              四地标记点                    │
  │           │              ②  ③                           │
  │           │                    ①     ④                  │
  │  赤道 ────┼──────────────────────────────────            │
  │           │                                             │
  │  计算框(50,400)                    坐标列表(620,400)     │
  │  ┌─────────────┐              ┌─────────────┐           │
  │  │ 计算说明    │              │ 四地坐标    │           │
  │  └─────────────┘              └─────────────┘           │
  │  ◀上一步(280,460)    下一步▶(500,460)                    │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量跟踪当前步骤（0-5），每一步控制对应元素的 display 属性
  2. 坐标计算：地图投影采用简单的等距圆柱投影，经度 0°-360°映射到 x=100-700，纬度 0°-90°N 映射到 y=380-80
  3. 动画曲线：元素出现使用 opacity 渐变（0→1，duration=300ms）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateScene() 刷新显示
  5. ID 命名规范：所有元素 ID 以"scene2-"为前缀（如 scene2-point1、scene2-arrow-dir）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
- 元素显示控制：
  - 步骤 0：显示地图、经线、赤道、标记点
  - 步骤 1：+显示经度标注
  - 步骤 2：+显示纬度标注
  - 步骤 3：+显示完整坐标标签、坐标列表
  - 步骤 4：+显示方向箭头、方向标签、区域地理标签
  - 步骤 5：所有元素高亮（stroke-width 增加或 opacity 调整）
