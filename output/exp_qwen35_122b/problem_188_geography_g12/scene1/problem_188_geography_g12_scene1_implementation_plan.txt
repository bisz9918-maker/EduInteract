[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：位于(280,450)，点击返回上一步骤，步骤0时禁用
  - "下一步 ▶"按钮：位于(420,450)，点击进入下一步骤，步骤5时变为"完成"
- 教师操作流程：
  1. 初始展示完整示意图，让学生观察整体结构
  2. 点击"下一步"逐步讲解每个关键点
  3. 每步讲解对应节气的地理意义
  4. 可点击"上一步"回退复习
  5. 最终步骤展示完整循环，帮助学生建立整体概念

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（直线、圆、文本），无需复杂图表库，原生实现轻量高效
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    太阳直射点回归运动                    │
  │                                                         │
  │  北回归线 ──────────────────────────────────────── 北回归线│
  │        ╱ ②↑                                          │
  │       ╱    ╲                                         │
  │  ①↑ ╱        ╲ ③                                     │
  │────╱───────────╱──────────────────────────────── 赤道  │
  │   ╱            ╲    ╲                                │
  │  ╱              ╲    ╲ ④                             │
  │ ╱                ╲  ↓                                │
  │                   ╲                                  │
  │  南回归线 ──────────────────────────────────────── 南回归线│
  │                                                         │
  │              [◀ 上一步]    [下一步 ▶]                   │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：currentStep 变量记录当前步骤（0-5），updateScene() 函数根据 currentStep 更新显示
  2. 坐标计算：所有元素使用绝对坐标，SVG 元素通过 id 精确控制
  3. 动画曲线：使用 SVG <animate> 或 JS requestAnimationFrame 实现平滑过渡
  4. 事件绑定：按钮点击事件监听，步骤0时禁用"上一步"，步骤5时"下一步"变为"完成"
  5. 高亮效果：当前点添加绿色外圈（<circle>元素，fill="none", stroke="#2e7d32", stroke-width="3"）
  6. 信息框显示：通过 CSS display 属性控制显隐，带引线连接对应点
- ID 命名规范：所有元素 ID 以 scene1- 为前缀
  - 纬线：scene1-line-tropic-north, scene1-line-equator, scene1-line-tropic-south
  - 轨迹：scene1-path-trajectory
  - 点：scene1-point-1, scene1-point-2, scene1-point-3, scene1-point-4
  - 序号标签：scene1-label-1, scene1-label-2, scene1-label-3, scene1-label-4
  - 信息框：scene1-info-1, scene1-info-2, scene1-info-3, scene1-info-4
  - 箭头：scene1-arrow-1, scene1-arrow-2, scene1-arrow-3, scene1-arrow-4
  - 按钮：scene1-btn-prev, scene1-btn-next
- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
