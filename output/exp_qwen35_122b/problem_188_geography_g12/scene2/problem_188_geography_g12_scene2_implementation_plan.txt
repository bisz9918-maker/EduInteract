- 本图示主题：太阳直射点位置与地理现象关联分析

[分步序列]
- 步骤0（初始状态）：
  - 显示：赤道线、北回归线、南回归线、运动轨迹、四个关键点①②③④及标签
  - 信息框显示标题"地理现象分析"和提示"点击「下一步」开始讲解"
  - 无高亮，无极夜阴影

- 步骤1：聚焦②点（夏至）
  - 高亮：点②添加绿色外圈
  - 信息框内容：
    "②点：夏至（6月22日前后）
    • 北半球昼最长，日出最早
    • 北回归线及其以北地区
      正午太阳高度达一年中最大值"
  - 运动轨迹在②点处加粗显示

- 步骤2：聚焦④点（冬至）
  - 高亮：点④添加绿色外圈，移除②的高亮
  - 显示：北极圈以北区域（北回归线以上）显示红色半透明极夜阴影
  - 信息框内容：
    "④点：冬至（12月22日前后）
    • 太阳直射南回归线
    • 正午太阳高度由南回归线
      向南北两侧降低
    • 南回归线及其以南地区
      正午太阳高度达一年中最大值
    • 北极圈及其以北出现极夜"

- 步骤3：聚焦②点后的移动方向
  - 高亮：点②添加绿色外圈
  - 显示：从②点出发的运动轨迹线段加粗并显示箭头，指向③点
  - 信息框内容：
    "夏至日后太阳直射点移动
    • 该日以后，太阳直射点
      向南移动
    • 从北回归线移向赤道"

- 步骤4：聚焦①点和③点（春分、秋分）
  - 高亮：点①和点③同时添加绿色外圈
  - 信息框内容：
    "①点和③点：春分与秋分
    • ①：春分（3月21日前后）
    • ③：秋分（9月23日前后）
    • 太阳直射赤道
    • 全球昼夜平分"

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：位于底部左侧(250,445)，点击返回上一状态
  - "下一步 ▶"按钮：位于底部右侧(450,445)，点击进入下一状态
  - 步骤指示器：位于底部中间(370,450)，显示当前步骤"步骤 X/5"
- 教师操作流程：
  1. 初始展示完整示意图，让学生观察四个关键点
  2. 点击"下一步"进入步骤1，讲解夏至日的地理现象
  3. 继续点击"下一步"依次讲解冬至日、夏至日后移动方向、春分秋分
  4. 可随时点击"上一步"回退复习某个知识点
  5. 配合信息框内容，引导学生理解太阳直射点位置与各地理现象的因果关系

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：本图示以几何图形为主（线段、圆、矩形），无需复杂数据可视化或 3D 效果，原生 SVG 足以实现所有视觉元素，性能优且代码简洁

- 画布尺寸：800 × 500 px

- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │                        太阳直射点回归运动示意图                 │
  │                                                                │
  │   北回归线 ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─    │
  │              ●②                                                │
  │             /                                                  │
  │            /        信息框                                      │
  │   赤道 ─ ─●①───────●③───────┐  ┌─────────────────────┐        │
  │          /                  │  │  地理现象分析        │        │
  │         /                   │  │                      │        │
  │        ●④                   │  │  [动态内容区]        │        │
  │   南回归线 ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─    │
  │                                                                │
  │              ◀ 上一步    步骤 1/5    下一步 ▶                   │
  └────────────────────────────────────────────────────────────────┘
  ```

- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量（0-4）跟踪当前步骤，每一步对应不同的视觉状态
  2. 坐标计算：所有元素坐标按布局坐标表精确实现，使用 SVG 绝对定位
  3. 动画曲线：点高亮使用 CSS transition 实现外圈渐显效果（0.3s ease）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 并调用 updateScene() 刷新视图
  5. 信息框内容：使用数组存储各步骤的 HTML 内容，根据 currentStep 动态插入
  6. 极夜阴影：步骤 2 时显示，使用 opacity 控制透明度
  7. 高亮外圈：使用 <circle> 元素，fill="none"，stroke="#2e7d32"，stroke-width="3"

- ID 命名规范：
  - 所有交互元素 ID 以 scene2- 为前缀
  - 示例：scene2-赤道线、scene2-北回归线、scene2-南回归线、scene2-轨迹、scene2-point1、scene2-point2、scene2-point3、scene2-point4、scene2-highlight-circle1、scene2-highlight-circle2、scene2-highlight-circle3、scene2-highlight-circle4、scene2-info-box、scene2-polar-night、scene2-prev-btn、scene2-next-btn、scene2-step-indicator

- IIFE 隔离：
  所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染

- 核心函数设计：
  - initScene2(): 初始化所有 SVG 元素
  - updateScene2(step): 根据 step 参数更新高亮、阴影、信息框内容
  - prevStep(): 处理上一步按钮点击
  - nextStep(): 处理下一步按钮点击
  - updateHighlight(step): 更新高亮外圈显示
  - updateInfoBox(step): 更新信息框文本内容
  - updatePolarNight(step): 更新极夜阴影显示
