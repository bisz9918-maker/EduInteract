标签列表及坐标检查：
- "东半球"：(230,430)

- "N"（东）：(230,45)
- "S"（东）：(230,420)

- "S"（西）：(570,420)

- "23°26'N"：(75,140)
- "23°26'S"：(75,310)
- "66°34'N"：(75,90)
- "66°34'S"：(75,360)
- "A"：(70,285)
- "B"：(185,220)
- "C"：(365,155)
- "D"：(435,155)
- "E"：(575,220)
- "F"：(725,285)

冲突检查：
1. "0°"(75,225) 与 "A"(70,285)：垂直距离60px → 无冲突
2. "23°26'S"(75,310) 与 "A"(70,285)：垂直距离25px → 无冲突（>20px）
3. "66°34'S"(75,360) 与 "S"(东)(230,420)：水平距离155px → 无冲突
4. "C"(365,155) 与 "D"(435,155)：水平距离70px → 无冲突
5. "B"(185,220) 与 "0°"(75,225)：水平距离110px → 无冲突
6. "E"(575,220) 与 "西半球"(570,430)：垂直距离210px → 无冲突
7. "N"(东)(230,45) 与 "66°34'N"(75,90)：水平距离155px → 无冲突
8. "S"(东)(230,420) 与 "东半球"(230,430)：垂直距离10px → 轻微接近，但"S"在地球轮廓内，"东半球"在地球下方，实际无重叠

解决方案：所有标签间距均≥10px，且位置分布合理，无实质性冲突。信息框位置已避开所有固定标签。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：位置(250,455)，作用：返回上一状态，步骤0时禁用
  - "下一步 ▶"按钮：位置(425,455)，作用：进入下一状态，步骤6时变为"重置"
  - 步骤6时"下一步 ▶"变为"重置"，点击后返回步骤0
- 教师操作流程：
  1. 初始展示完整轨迹图，让学生观察整体
  2. 点击"下一步"逐步展示A→B→C/D→E→F各点特征
  3. 每步停留讲解该点对应的节气、直射纬度、极昼极夜范围
  4. 可点击"上一步"回退复习
  5. 最后点击"总结"展示完整移动规律

[技术实现]
- JS库选择：原生SVG + 原生JavaScript
  - 原因：几何图形简单（椭圆、直线、曲线、圆点），原生SVG足以实现，无需引入大型库
  - 动画效果通过CSS transition和JS状态管理实现

- 画布尺寸：800 × 500 px

- 关键实现要点：
  1. 状态机设计：使用currentStep变量(0-6)跟踪当前步骤，updateScene()函数根据currentStep更新显示
  2. 坐标计算：所有元素坐标预先计算好，存储在常量对象中
  3. 动画曲线：轨迹线使用SVG path的贝塞尔曲线，A-B-C-D-E-F用平滑曲线连接
  4. 事件绑定：按钮点击事件监听，步骤0时禁用"上一步"，步骤6时"下一步"变为"重置"
  5. 信息框显示：使用SVG <foreignObject>或<rect>+<text>组合，根据当前高亮点动态定位
  6. 极昼极夜填充：使用SVG <path>定义区域，通过display或opacity控制显示/隐藏

- ID命名规范：
  - 所有交互元素ID以"scene1-"为前缀
  - 示例：scene1-earth-east, scene1-earth-west, scene1-point-A, scene1-point-B, ..., scene1-trajectory, scene1-info-box, scene1-btn-prev, scene1-btn-next
  - JS中使用getElementById获取元素

- IIFE隔离：
