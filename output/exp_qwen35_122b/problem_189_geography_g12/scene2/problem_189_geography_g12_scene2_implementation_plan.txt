[图示主题与整合说明]
- 本图示主题：正午太阳高度角纬度分布规律
- 整合内容：整合了太阳直射点在不同位置（赤道、北回归线、南回归线）时，全球正午太阳高度角随纬度变化的分布规律
- 教学价值：教师可通过拖拽滑块改变直射点纬度，学生可以直观观察正午太阳高度角分布曲线的连续变化，理解"从直射点向南北两侧递减"的规律。配合左侧地球示意图，帮助学生建立直射点位置与全球高度角分布的空间对应关系。

  4. 公式显示框：位于坐标图上方 (300,20)-(740,50)，显示正午太阳高度角计算公式

- 教师操作流程：
  1. 初始展示：滑块在 0°位置，展示直射赤道时的对称分布曲线
  2. 讲解赤道直射：说明此时全球正午太阳高度角从赤道向南北两侧对称递减
  3. 拖拽滑块向北：边拖边讲解，曲线峰值随直射点北移，北半球高度角增大，南半球减小
  4. 拖至北回归线：说明夏至日情况，北极点仍有约 43°高度角
  5. 拖拽滑块向南：反向演示，曲线峰值南移
  6. 拖至南回归线：说明冬至日情况
  7. 回到中间位置：总结规律——"正午太阳高度角从直射点所在纬度向南北两侧递减"

- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：本场景主要是几何图形和曲线绘制，原生 SVG 足以实现，无需引入大型库
  - 曲线绘制：使用 SVG 的 <path> 元素，通过 JavaScript 动态计算路径数据

- 画布尺寸：800 × 500 px（固定）

- 关键实现要点：
  1. 状态机设计：
     - 使用变量 currentLatitude 存储当前直射点纬度（范围 -23.5~23.5）
     - 监听滑块拖拽事件，实时更新 currentLatitude
     - 根据 currentLatitude 重新计算并绘制分布曲线和直射点标记

  2. 坐标计算：
     - 地球示意图：直射点 y 坐标 = 220 - (currentLatitude / 23.5) * 60
     - 横轴映射：纬度 -90~90 映射到 x 坐标 320~720，公式：x = 320 + (纬度 + 90) * 400 / 180
     - 纵轴映射：高度角 0~90 映射到 y 坐标 340~80，公式：y = 340 - 高度角 * 260 / 90
     - 分布曲线：对每个纬度值 lat（-90~90），计算高度角 h = 90 - Math.abs(lat - currentLatitude)，然后映射到坐标

  3. 动画曲线：
     - 滑块拖拽时实时更新，无需缓动动画
     - 曲线重绘使用 requestAnimationFrame 保证流畅性

  4. 事件绑定：
     - 滑块手柄 mousedown/touchstart：开始拖拽
     - document mousemove/touchmove：拖拽中更新位置
     - document mouseup/touchend：结束拖拽
     - 限制拖拽范围在轨道内

  5. ID 命名规范：
     - 所有元素 ID 以 scene2- 为前缀
     - 如：scene2-earth-circle, scene2-equator-line, scene2-curve, scene2-slider-handle, scene2-formula-text 等

  6. IIFE 隔离：
     - 所有 JS 代码包裹在 (function() { ... })() 中
     - 避免全局变量污染

  7. 曲线绘制算法：
     ```javascript
     function generateCurvePath(currentLat) {
       let path = '';
       for (let lat = -90; lat <= 90; lat += 1) {
         const height = 90 - Math.abs(lat - currentLat);
         const x = 320 + (lat + 90) * 400 / 180;
         const y = 340 - height * 260 / 90;
         path += (lat === -90 ? 'M' : 'L') + x + ',' + y + ' ';
       }
       return path;
     }
     ```

  8. 滑块拖拽处理：
     ```javascript
     function handleSliderMove(clientX) {
       const rect = sliderTrack.getBoundingClientRect();
       const percent = Math.max(0, Math.min(1, (clientX - rect.left) / rect.width));
       currentLatitude = (percent * 2 - 1) * 23.5; // -23.5 ~ 23.5
       updateDisplay();
     }
     ```
