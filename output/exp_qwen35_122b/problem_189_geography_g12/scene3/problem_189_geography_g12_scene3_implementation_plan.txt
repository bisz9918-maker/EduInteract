[分步序列]
- 步骤0（初始状态）：
  - 显示地球圆、经线网格（0°、180°）
  - 显示东半球边界（20°W、160°E）
  - 信息框显示："点击'下一步'查看东半球范围详解"

- 步骤1（点击"下一步"→查看东半球范围）：
  - 高亮东半球边界（20°W和160°E加粗）
  - 东半球区域填充浅蓝色
  - 信息框显示："东半球范围：20°W → 0° → 160°E，共180°经度跨度"

- 步骤2（点击"下一步"→黑夜条件）：
  - 显示晨昏线：20°W为晨线，160°E为昏线
  - 东半球区域变为深蓝色（表示黑夜）
  - 信息框显示："东半球全部黑夜时：20°W为晨线(6:00)，160°E为昏线(18:00)"

- 步骤3（点击"下一步"→直射点位置）：
  - 在西半球中央显示太阳直射点（110°W）
  - 直射点标注"110°W 12:00"
  - 信息框显示："太阳直射点位于110°W，地方时为12:00"

- 步骤4（点击"下一步"→计算北京时间）：
  - 显示计算过程：
    - 已知：110°W = 12:00
    - 求：120°E的地方时
    - 经度差 = 110° + 120° = 230°
    - 时间差 = 230° ÷ 15°/h = 15小时20分
    - 北京时间 = 12:00 + 15:20 = 次日3:20
  - 信息框显示上述计算过程（绿色文字）

- 步骤5（点击"总结"→完整答案）：
  - 信息框显示完整答案：
    - (5) B点经度：70°E
    - 东半球黑夜时直射点：D点
    - 北京时间：3月22日 3时20分
  - 高亮图中D点位置

[交互方案]

- 控件说明：
  - "◀ 上一步"按钮：位于(200,450)，回退到上一状态
  - "下一步 ▶"按钮：位于(350,450)，进入下一状态
  - "总结"按钮：位于(500,450)，显示完整答案
- 教师操作流程：
  1. 初始展示东半球范围，引导学生理解20°W~160°E的界定
  2. 点击"下一步"展示东半球全部黑夜时的晨昏线位置
  3. 继续点击"下一步"展示太阳直射点位置（110°W）
  4. 继续点击"下一步"逐步展示北京时间计算过程
  5. 点击"总结"显示题目完整答案，配合讲解

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 理由：几何图形简单（圆形、线段、扇形），无需复杂图表库；原生实现轻量高效
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │                    东半球与地方时计算                        │  y=50
  ├─────────────────────────────────────────────────────────────┤
  │                                                             │
  │    ┌─────────────┐                                         │
  │    │   地球图    │         信息框                          │
  │    │  (150,250)  │      (400,100)                         │
  │    │             │      ┌─────────────┐                   │
  │    │  ○ 地球     │      │  步骤内容    │                   │
  │    │             │      │  显示区      │                   │
  │    └─────────────┘      └─────────────┘                   │
  │                                                             │
  ├─────────────────────────────────────────────────────────────┤
  │     [◀上一步]    [下一步▶]    [总结]                        │  y=450
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-5) 跟踪当前步骤，updateDisplay() 函数根据 currentStep 显示对应元素
  2. 坐标计算：经线用 SVG 弧线表示，根据角度计算端点坐标；东半球扇形用 SVG path 的 A 命令绘制
  3. 动画曲线：元素出现/消失用 opacity 过渡（transition: opacity 0.3s）
  4. 事件绑定：三个按钮分别绑定 click 事件，修改 currentStep 后调用 updateDisplay()
  5. ID 命名规范：所有元素 ID 以 scene3- 为前缀（如 scene3-earth, scene3-btn-next, scene3-info-box）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 信息框内容：用 innerHTML 动态更新，支持多行文本和换行
