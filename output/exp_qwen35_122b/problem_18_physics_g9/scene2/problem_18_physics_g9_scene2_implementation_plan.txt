[分步序列]
- 步骤 0（初始状态）：
  - 显示：水容器、水面线、物体 A、三个力箭头（G_A 红色向下、T 蓝色向上、F_浮 绿色向上）
  - 标签：G_A=29.4N、T=19.6N、F_浮=?
  - 公式框 1 显示："F_浮 + T = G_A"（平衡方程）
  - 公式框 2-4 隐藏
  - 体积示意和结论框隐藏

- 步骤 1：
  - 新增：公式框 2 显示"代入：F_浮 = 29.4N - 19.6N"
  - F_浮 箭头高亮（加粗）

- 步骤 2：
  - 公式框 2 更新为："F_浮 = 29.4N - 19.6N = 9.8N"
  - F_浮 标签更新为："F_浮=9.8N"
  - 公式框 3 显示："F_浮 = ρ_水 × g × V_排"

- 步骤 3：
  - 公式框 3 高亮
  - 公式框 4 显示："V_排 = 9.8N / (1000kg/m³ × 9.8N/kg)"

- 步骤 4：
  - 公式框 4 更新为："V_排 = 0.001m³ = 1000cm³"
  - 体积示意立方体显示（透视线框，内部可画网格示意）
  - 体积标签显示："V_排=1000cm³"

- 步骤 5（最终步骤）：
  - 结论框显示："选项 B 错误！正确体积为 1000cm³"
  - 结论框背景#ffcdd2（红色提示错误选项）
  - 所有公式框保持显示

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀上一步"按钮：位于 (300,450)-(400,480)，点击返回上一步骤
  - "下一步▶"按钮：位于 (420,450)-(520,480)，点击进入下一步骤
  - 步骤指示器：显示"步骤 X/5"，位于按钮上方
- 教师操作流程：
  1. 初始展示物体 A 受力情况，引导学生识别三个力
  2. 点击"下一步"展示平衡方程，讲解受力平衡概念
  3. 继续点击展示代入计算过程，强调数值来源
  4. 展示阿基米德原理公式，连接浮力与排开体积
  5. 完成体积计算，显示 1000cm³结果
  6. 最终高亮结论，指出选项 B 错误

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何和文本，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │                        图示区 800×500                          │
  │                                                                │
  │  ┌─────────────────┐                                          │
  │  │   水容器        │                                          │
  │  │   ~~~~~~~~      │                                          │
  │  │   ┌───────┐     │     公式框 1: F_浮 + T = G_A             │
  │  │   │   A   │←F_浮│                                          │
  │  │   │       │↑T   │     公式框 2: F_浮 = 29.4 - 19.6         │
  │  │   └───↓───┘     │                                          │
  │  │       G_A       │     公式框 3: F_浮 = ρgV_排              │
  │  └─────────────────┘                                          │
  │                        │     公式框 4: V_排 = 1000cm³          │
  │                        │                                      │
  │                        │     [体积示意立方体]                 │
  │                        │     结论框：选项 B 错误！             │
  │                                                                │
  │              [◀上一步]  步骤 X/5  [下一步▶]                    │
  └────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep 记录当前步骤（0-5），每一步定义要显示/隐藏/更新的元素 ID 列表
  2. 坐标计算：所有元素按布局坐标表精确绘制，箭头用 polyline 或 path 实现
  3. 动画曲线：步骤切换用简单的 opacity 淡入淡出（0.3s transition）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateScene() 函数刷新显示
  5. ID 命名规范：所有元素 ID 以"scene2-"为前缀（如 scene2-objA、scene2-arrow-GA、scene2-formula1 等）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 公式渲染：使用 MathJax 或直接用 HTML 文本（本题公式简单，可直接用 text 元素）
