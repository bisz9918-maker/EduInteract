[视觉元素清单]
- 四棱锥 P-ABCD 基础结构：5 个顶点 + 8 条棱线
  - 顶点 P(400,80)、A(150,350)、B(350,380)、C(650,360)、D(450,300)
  - 可见棱（实线 #000000）：PA、PB、PC、AB、BC
  - 被遮挡棱（虚线 #888888）：PD、AD、DC
- 平面 PAB 填充：三角形 (400,80)-(150,350)-(350,380)，#1565c0 半透明 20%
- 平面 PDC 填充：三角形 (400,80)-(450,300)-(650,360)，#c62828 半透明 20%
- DC 高亮线段：(450,300)-(650,360)，#c62828 加粗 3px，步骤 1 显示
- 平面 PAB 内示例直线：(250,220)-(300,365)，#1565c0 实线 2px，步骤 3 显示
- 平面 PDC 法向箭头：起点 (550,330)，终点 (580,300)，#2e7d32，步骤 3 显示
- 标签：P、A、B、C、D 顶点标注（黑色 14px），"平面 PAB"（蓝色 14px），"平面 PDC"（红色 14px）
- 结论标记：命题①"×"（红色 18px 加粗），命题②"√"（绿色 18px 加粗）
- 控件栏：浅灰色背景，上一步/下一步按钮，步骤指示器

[分步序列]
- 初始状态（步骤 0）：
  - 显示四棱锥 P-ABCD 基础结构（所有棱线，实线/虚线区分可见性）
  - 显示平面 PAB 和平面 PDC 的半透明填充
  - 显示标签 P、A、B、C、D、"平面 PAB"、"平面 PDC"
  - 上一步按钮禁用，下一步按钮可用

- 步骤 1：点击「下一步」→ 分析命题①
  - 新增：DC 线段红色加粗高亮（#c62828，3px）
  - 新增：标签 "DC" 显示在 DC 线段上方
  - 视觉焦点：DC 与平面 PAB 的位置关系（DC 不在平面 PAB 内，且与平面 PAB 相交）
  - 结论：平面 PAB 内不存在直线与 DC 平行（因为 DC 与平面 PAB 相交）

- 步骤 2：点击「下一步」→ 命题①结论
  - 新增：命题①结论标记 "×" 显示在左上角（红色）
  - 说明：命题①"在平面 PAB 内不存在直线与 DC 平行" 是错误的
  - 原因：DC 与平面 PAB 相交于点 D 附近区域，平面 PAB 内存在与 DC 平行的直线（过平面内一点作 DC 的平行线）

- 步骤 3：点击「下一步」→ 分析命题②
  - 新增：平面 PAB 内示例直线（蓝色 #1565c0，从 PA 上某点到 AB 上某点）
  - 新增：平面 PDC 法向箭头（绿色 #2e7d32，从平面 PDC 中心向外）
  - 视觉焦点：平面 PAB 内的直线与平面 PDC 的平行关系
  - 说明：在平面 PAB 内可以作无数条与平面 PDC 平行的直线（作与两平面交线平行的直线）

- 步骤 4：点击「下一步」→ 命题②结论
  - 新增：命题②结论标记 "√" 显示在右上角（绿色）
  - 说明：命题②"在平面 PAB 内存在无数多条直线与平面 PDC 平行" 是正确的
  - 原因：平面 PAB 与平面 PDC 相交于过 P 点的直线，平面 PAB 内所有与该交线平行的直线都与平面 PDC 平行

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮（scene2-prev-btn）：位于控件栏左侧，点击返回上一步，步骤 0 时禁用
  - 下一步按钮（scene2-next-btn）：位于控件栏右侧，点击进入下一步，步骤 4 时禁用
  - 步骤指示器（scene2-step-indicator）：位于控件栏中央，显示当前步骤 "步骤 k/4"
- 教师操作流程：
  1. 初始展示四棱锥结构，介绍两个平面 PAB 和 PDC
  2. 点击下一步，高亮 DC 线段，引导学生分析 DC 与平面 PAB 的位置关系
  3. 点击下一步，显示命题①结论（×），解释为什么命题①错误
  4. 点击下一步，显示平面 PAB 内示例直线和平面 PDC 法向，分析命题②
  5. 点击下一步，显示命题②结论（√），总结正确答案

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    四棱锥图示区                          │
  │                                                         │
  │         P(400,80)                                       │
  │        /   |   \                                        │
  │       /    |    \                                       │
  │  平面PAB  平面PDC                                       │
  │     /      |      \                                    │
  │    A-------D-------C                                   │
  │     \      |      /                                    │
  │      \     |     /                                     │
  │       B────┴────                                        │
  │                                                         │
  │  命题①×(100,120)              命题②√(650,120)           │
  │                                                         │
  │  ┌─────────────────────────────────────────────────┐   │
  │  │  [◀上一步]  步骤 0/4  [下一步▶]                  │   │
  │  └─────────────────────────────────────────────────┘   │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：currentStep 变量跟踪当前步骤（0-4），updateScene() 函数根据 currentStep 显示/隐藏对应元素
  2. 坐标计算：所有元素坐标硬编码在布局坐标表中，确保精确到像素级
  3. 动画曲线：元素出现使用 opacity 渐变（0→1，300ms ease-in-out）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateScene()
  5. ID 命名规范：所有元素 ID 以 scene2- 为前缀（如 scene2-vertex-p、scene2-edge-pa、scene2-prev-btn 等）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 元素显示控制：使用 display 或 opacity 控制元素显示/隐藏，步骤 1 显示 DC 高亮，步骤 2 显示命题①结论，步骤 3 显示示例直线和法向箭头，步骤 4 显示命题②结论
