[分步序列]
- 初始状态（步骤 0）：显示四棱锥 P-ABCD 基础结构，所有棱线（实线/虚线区分可见性），底面 ABCD 轮廓，顶点标签 P、A、B、C、D。平面 PAB 和 PDC 尚未填充。
- 步骤 1：点击「下一步」→ 平面 PAB 以#1565c0 半透明填充（opacity=0.2），平面 PDC 以#c62828 半透明填充（opacity=0.2）。点 P 高亮显示（绿色小圆点），标注"交线上的点 P"。
- 步骤 2：点击「下一步」→ 延长 AB 与 DC，显示它们的交点 Q（位于底面外侧，坐标约 (500, 400) 附近）。Q 点用绿色圆点标记，标注"Q = AB ∩ DC"。说明 Q 同时在平面 PAB 和平面 PDC 内。
- 步骤 3：点击「下一步」→ 画出完整交线 l = PQ，用#2e7d32 加粗实线连接 P(400,80) 到 Q(500,400)。交线标签"l"显示在 (460, 260) 位置。
- 步骤 4：点击「下一步」→ 显示交线 l 的延长线（#888888 虚线），延长至与底面 ABCD 所在平面相交。用箭头和文字说明"交线 l 与底面 ABCD 相交于点 Q"，标注"不平行"标记。
- 步骤 5：点击「下一步」→ 在图示右上角显示绿色"√"标记，文字说明"命题③正确：平面 PAB 与平面 PDC 的交线与底面 ABCD 不平行"。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 按钮"◀ 上一步"：位置 (280, 455)，作用：返回上一状态
  - 按钮"下一步 ▶"：位置 (480, 455)，作用：进入下一状态
  - 步骤指示器：位置 (350, 420)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始展示四棱锥结构，引导学生观察空间关系
  2. 点击"下一步"展示两个平面，说明平面 PAB 和 PDC 的位置
  3. 继续点击展示交线上的点 P，说明 P 是两平面的公共点
  4. 展示 AB 与 DC 延长线的交点 Q，说明 Q 也是两平面的公共点
  5. 画出交线 PQ，强调两平面交线由两个公共点确定
  6. 展示交线与底面相交，说明交线与底面不平行
  7. 最后显示"√"标记，确认命题③正确

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    图示区 800×500                        │
  │                                                          │
  │                    P(400,80)                             │
  │                   / |  \                                 │
  │                  /  |   \                                │
  │                 /   |    \                               │
  │                /    |     \                              │
  │           A(200,350) D(300,320)                          │
  │            \   \   /   /                                 │
  │             \   \ /   /                                  │
  │              \   B(350,380)                              │
  │               \   |   /                                  │
  │                \  |  /                                   │
  │                 \ | /                                    │
  │                  C(600,360)                              │
  │                                                          │
  │              [平面 PAB 蓝色半透明]                        │
  │              [平面 PDC 红色半透明]                        │
  │              [交线 l 绿色加粗]                            │
  │                                                          │
  │              步骤指示器：步骤 X/5                         │
  │              [◀ 上一步]  [下一步 ▶]                       │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  - 状态机设计：使用变量 currentStep (0-5) 跟踪当前步骤
  - 坐标计算：所有顶点坐标预先定义在配置对象中
  - 动画曲线：元素显示使用 opacity 渐变 (0→1)，时长 300ms
  - 事件绑定：按钮点击事件更新 currentStep，调用 renderStep() 重新渲染
  - 元素显示控制：每个元素定义 showInSteps 数组，如交线 l: [3,4,5]
- ID 命名规范：所有交互元素 ID 以 scene3- 为前缀（如 scene3-btn-next, scene3-svg-canvas）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局污染
