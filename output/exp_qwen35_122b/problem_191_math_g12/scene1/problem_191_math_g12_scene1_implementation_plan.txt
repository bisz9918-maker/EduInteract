[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（几何图形简单，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    图示区 800×500                       │
  │                                                         │
  │           P(200,100)                                    │
  │            /  \                                         │
  │           /    \  割线PBA                               │
  │      切线/      \                                       │
  │        PE        B(480,220)                             │
  │       /          /  \                                  │
  │      /    角平分线/    \  弦BE                          │
  │     E(330)------C------A(570)                          │
  │      \    弦AE   \    /                                │
  │       \    圆O    \  /                                 │
  │        \    ●(450,300)                                 │
  │         \                                                │
  │          \                                               │
  │                                                         │
  │  [◀ 上一步]        步骤 1/4        [下一步 ▶]           │
  │  (50,460)         (350,460)        (650,460)            │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量（0-3），控制各元素的 display/opacity
  2. 坐标计算：所有元素使用绝对坐标，确保精确对齐
  3. 动画曲线：步骤切换使用 opacity 过渡（0.3s ease）
  4. 事件绑定：按钮点击事件更新 currentStep，重新渲染元素可见性
  5. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-circle-O、scene1-line-PE、scene1-btn-next）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 元素分组：使用<g>标签将相关元素分组（如 scene1-group-lines、scene1-group-labels、scene1-group-highlights）
  8. 角度弧线绘制：使用 SVG path 的 arc 命令绘制角标注弧线
