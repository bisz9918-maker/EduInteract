[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "上一步"按钮：scene1-prev-btn，位于 (320,450)，回退到上一状态
  - "下一步"按钮：scene1-next-btn，位于 (480,450)，前进到下一状态
- 教师操作流程：
  1. 初始展示完整三角形，让学生观察整体结构
  2. 点击"下一步"，高亮第一个递推关系（1/1=1/2+1/2），讲解基本规则
  3. 继续点击"下一步"，展示更多递推示例，强化理解
  4. 最后一步展示递推公式总结，归纳规律
  5. 可随时点击"上一步"回退复习

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（圆形、箭头、文本），无需复杂图表库；SVG 便于精确控制坐标和样式

- 画布尺寸：800 × 500 px

- 布局草图（ASCII）：
```
┌─────────────────────────────────────────────────────────┐
│  第 1 行标签                                              │
│           ● 1/1                                         │
│          ↙     ↘                                       │
│  第 2 行标签  ● 1/2     ● 1/2                           │
│          ↙  ↘   ↙  ↘                                  │
│  第 3 行标签 ● 1/3 ● 1/6 ● 1/3                         │
│         ↙↘  ↙↘  ↙↘  ↙↘                               │
│  第 4 行标签●1/4●1/12●1/12●1/4                       │
│        ↙↘↙↘↙↘↙↘↙↘↙↘                                │
│  第 5 行标签●1/5●1/20●1/30●1/20●1/5                 │
│                                                       │
│  递推说明：每个数=下一行左右相邻两数之和                │
│                                                       │
│              [◀ 上一步] [下一步 ▶]                     │
└─────────────────────────────────────────────────────────┘
```

- 关键实现要点：
  1. 状态机设计：currentStep 变量（0-3），updateScene() 函数根据 currentStep 显示/隐藏元素
  2. 坐标计算：使用预定义的坐标常量，确保元素位置精确
  3. 动画曲线：箭头高亮使用 CSS transition（opacity、stroke 属性）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateScene()
  5. MathJax 渲染：分数使用 MathJax 公式渲染，确保显示美观

- ID 命名规范：
  - 所有元素 ID 前缀：scene1-
  - 示例：scene1-circle-1-1（第 1 行第 1 个圆）、scene1-arrow-1-1（第 1 个箭头）、scene1-prev-btn、scene1-next-btn

- IIFE 隔离：
```javascript
(function() {
    // 所有代码封装在此
    const sceneId = 1;
    let currentStep = 0;
    // ... 实现逻辑
})();
```
