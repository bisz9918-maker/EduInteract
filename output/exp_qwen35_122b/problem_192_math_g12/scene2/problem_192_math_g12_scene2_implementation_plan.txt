[图示主题与整合说明]
- 本图示主题：牛顿调和三角形第6行第2个数的推导过程

[分步序列]
- 步骤0（初始状态）：
  - 显示标题"第6行第2个数推导"
  - 显示第5行完整：1/5, 1/20, 1/30, 1/20, 1/5
  - 显示第6行两端：1/6, ?, ?, ?, ?, 1/6
  - 显示递推箭头（虚线）
  - 显示计算框和公式说明框
  - 第6行第2个数显示为红色"?"

- 步骤1：
  - 第5行第1个数(1/5)高亮为蓝色
  - 第6行第1个数(1/6)高亮为蓝色
  - 第6行第2个数(?)保持红色
  - 计算步骤1高亮："1/5 = 1/6 + x"

- 步骤2：
  - 保持步骤1的高亮
  - 计算步骤2高亮："x = 1/5 - 1/6"
  - 递推箭头2（指向第6行第2个数）加粗显示

- 步骤3：
  - 保持之前高亮
  - 计算步骤3高亮："x = 1/30"
  - 第6行第2个数的"?"变为"1/30"（红色）

- 步骤4（最终状态）：
  - 第6行第2个数(1/30)高亮为绿色
  - 计算框整体边框变为绿色
  - 显示验证文字："验证：1/5 = 1/6 + 1/30 ✓"

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮：位于(300,450)，点击返回前一步骤，步骤0时禁用
  - 下一步按钮：位于(500,450)，点击进入下一步骤，步骤4时禁用
- 教师操作流程：
  1. 初始展示第5行和第6行框架，让学生观察结构
  2. 点击下一步，高亮第5行第1个数和第6行相关位置，引出计算关系
  3. 点击下一步，展示递推公式应用过程
  4. 点击下一步，显示计算结果
  5. 点击下一步，验证答案并强调绿色确认状态

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何和文本，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────┐
  │                    第6行第2个数推导                      │  y=20
  │                                                         │
  │     1/5     1/20    1/30    1/20    1/5                │  y=80 (第5行)
  │      ↓↘                                                  │
  │     1/6     ?       ?       ?       ?       1/6        │  y=200 (第6行)
  │                                                         │
  │  ┌──────────────┐                    ┌─────────────────┐│
  │  │ 递推计算：    │                    │  递推规则：      ││
  │  │ 1/5 = 1/6+x  │                    │  第n行第k个数=   ││
  │  │ x = 1/5-1/6  │                    │  第(n+1)行第k+   ││
  │  │ x = 1/30     │                    │  第(n+1)行第k+1  ││
  │  └──────────────┘                    └─────────────────┘│
  │                                                         │
  │              [◀ 上一步]      [下一步 ▶]                 │  y=450
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep 记录当前步骤（0-4），根据步骤控制元素显示/高亮
  2. 坐标计算：所有元素位置按布局坐标表精确实现
  3. 高亮效果：通过修改 fill/stroke 属性实现蓝/红/绿高亮切换
  4. 动画曲线：步骤切换时使用 opacity 渐变（0.3s ease-in-out）
  5. 事件绑定：按钮点击事件更新 currentStep 并调用 updateScene() 刷新显示
  6. ID 命名规范：所有交互元素 ID 以 scene2- 为前缀（如 scene2-step0-text, scene2-next-btn）
  7. JS 隔离：所有代码包在 (function() { ... })() IIFE 中，避免全局污染
  8. 按钮状态：步骤0时上一步按钮 disabled，步骤4时下一步按钮 disabled
