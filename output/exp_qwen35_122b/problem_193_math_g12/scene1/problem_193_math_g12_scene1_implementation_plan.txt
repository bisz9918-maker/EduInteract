[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮（scene1-prev）：位于 (250,455)-(330,485)，点击返回前一步骤，初始步骤时禁用
  - 下一步按钮（scene1-next）：位于 (470,455)-(550,485)，点击进入下一步骤，最终步骤时禁用
  - 步骤指示器：位于 (350,460)-(450,480)，显示当前步骤"步骤 X/5"
- 教师操作流程：
  1. 初始展示三视图，引导学生观察各视图特征
  2. 点击"下一步"，高亮俯视图半圆部分，讲解半圆锥的识别
  3. 点击"下一步"，高亮俯视图三角形部分，讲解三棱锥的识别
  4. 点击"下一步"，展示立体透视图，讲解两部分拼接关系
  5. 点击"下一步"，标注关键尺寸，引导学生进行体积计算

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │                        800 × 500 画布                          │
  │                                                                │
  │  ┌─────────────┐  ┌─────────────┐                              │
  │  │  正视图     │  │  侧视图     │                              │
  │  │  (三角形)   │  │  (三角形)   │                              │
  │  └─────────────┘  └─────────────┘                              │
  │                                                                │
  │  ┌─────────────────────┐                                       │
  │  │      俯视图         │                                       │
  │  │  (半圆+三角形)      │                                       │
  │  └─────────────────────┘                                       │
  │                                                                │
  │              立体透视图区域                                     │
  │         (半圆锥 + 三棱锥拼接)                                   │
  │                                                                │
  │          ┌─────────────────────────┐                           │
  │          │  ◀上一步  步骤 1/5  下一步▶ │                           │
  │          └─────────────────────────┘                           │
  └────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  - 状态机设计：使用变量 currentStep (0-4) 跟踪当前步骤
  - 坐标计算：所有元素使用绝对定位，基于布局坐标表
  - 动画曲线：元素显示/隐藏使用 opacity 过渡（0.3s ease）
  - 事件绑定：按钮点击事件更新 currentStep，调用 updateScene() 刷新显示
  - ID 命名规范：所有交互元素 ID 以 scene1- 为前缀（如 scene1-tri-front, scene1-prev, scene1-next）
  - JS 使用 getElementById 获取元素，避免全局 class 污染
  - IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中
- 元素显示控制：
  - 每个步骤定义 showElements 和 hideElements 数组
  - updateScene() 函数根据 currentStep 切换元素 visibility/opacity
  - 高亮元素使用 class "highlight-blue" 或 "highlight-green" 控制填充色
  - 标签元素根据步骤动态创建/销毁或切换 visibility
