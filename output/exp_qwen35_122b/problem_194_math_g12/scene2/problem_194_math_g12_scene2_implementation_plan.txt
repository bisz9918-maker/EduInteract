[分步序列]
本场景为连续拖拽交互，无分步导航，状态随滑块拖动实时更新：

- 初始状态（滑块在中间位置）：
  - 显示椭圆、坐标轴、焦点 A 和 D
  - 点 B 位于椭圆右侧（角度 0°），点 C 位于椭圆上对应位置使 BC=2
  - 显示线段 BC、距离 d、短半轴 b、长半轴 a、焦距 c
  - 显示所有标签和实时数值

- 拖动过程中：
  - B 点沿椭圆移动（由滑块控制角度）
  - C 点自动调整位置，保持 BC=2 且 BC⊥AD
  - 距离 d 实时更新（BC 中点到椭圆中心的距离）
  - 数值显示实时更新 d 的当前值

- 最大值状态（滑块拖动到使 B 位于短轴端点）：
  - B 点位于椭圆短轴上端点 (400, 339) 或下端点 (400, 161)
  - C 点对称位置，BC 平行于短轴
  - 距离 d 达到最大值 b = √(a²-c²)
  - 高亮显示最大值区域（红色填充，透明度 20%）
  - 显示结论：d_max = b

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：
  - 滑块：input[type=range]，id=scene2-slider，位置 (250,450)-(550,470)，范围 0-360（角度）
  - 作用：控制 B 点在椭圆上的位置（角度）
  - 数值显示：text，id=scene2-value，位置 (620,60)，实时显示 d 的当前值
  - 最大值提示：text，id=scene2-max，位置 (620,90)，显示 d_max = b = √(a²-c²)

- 教师操作流程：
  1. 初始展示：向學生說明圖示各元素含義（椭圆、焦点、动点、距离 d）
  2. 拖动滑块：缓慢拖动滑块，让学生观察 B、C 点沿椭圆移动
  3. 观察变化：引导学生注意距离 d 的数值变化
  4. 发现规律：当 B 点移动到短轴端点时，d 达到最大值
  5. 总结结论：d_max = b = √(a²-c²)，此时四面体体积最大

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    [数值显示 d=X.XX]                     │
  │                    [最大值提示 d_max=b]                  │
  │                                                         │
  │              ┌─────────────────────────────┐            │
  │              │         椭圆区域             │            │
  │              │      (中心 400,250)          │            │
  │              │                             │            │
  │         A●───┼────────────────────●D       │            │
  │              │      B●──────●C            │            │
  │              │         │ d                 │            │
  │              │         │                   │            │
  │              │         ● (中心)            │            │
  │              │         │ b                 │            │
  │              └─────────────────────────────┘            │
  │                                                         │
  │              [滑块：拖动控制 B 点位置]                    │
  └─────────────────────────────────────────────────────────┘
  ```

- 关键实现要点：
  1. 椭圆参数方程：x = 400 + 120*cos(θ), y = 250 + 89*sin(θ)
  2. B 点位置由滑块角度 θ 决定
  3. C 点位置：保持 BC=2，且 BC⊥AD（即 BC 垂直于 x 轴）
  4. 距离 d = |BC 中点 y 坐标 - 250|
  5. 最大值 b = √(a²-c²) = √(120²-80²) = √8000 ≈ 89.4
  6. 状态机：单一状态（滑块角度），实时更新所有相关元素
  7. 事件绑定：slider 的 input 事件触发重绘
  8. ID 命名规范：所有元素 ID 以 scene2- 为前缀（如 scene2-ellipse, scene2-pointB, scene2-slider）
  9. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中

- 坐标计算：
  - 椭圆：centerX=400, centerY=250, rx=120, ry=89
  - 焦点 A：(400-80, 250) = (320, 250)
  - 焦点 D：(400+80, 250) = (480, 250)
  - B 点：(400+120*cos(θ), 250+89*sin(θ))
  - C 点：根据 BC=2 和 BC⊥AD 计算
  - d = |((By+Cy)/2) - 250|

- 动画曲线：无动画，实时更新

- 事件绑定：
  - scene2-slider 的 'input' 事件 → 更新 B、C 位置，重绘所有相关元素
