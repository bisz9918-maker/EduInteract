[分步序列]
- 步骤 0（初始状态）：
  - 显示：圆 O、点 A/B/C/M/O/P、切线 AP、割线 AC、弦 BC
  - 隐藏：辅助线 OP、辅助线 OM、直角标记、角度弧、角度标签
  - 目的：展示题目基础图形，让学生观察已知条件

- 步骤 1：点击「下一步」→
  - 新增：辅助线 OP（蓝色）、直角标记1（OP⊥AP）
  - 高亮：OP 线段和直角符号
  - 目的：揭示切线性质——切线垂直于过切点的半径

- 步骤 2：点击「下一步」→
  - 新增：辅助线 OM（蓝色）、直角标记2（OM⊥BC）
  - 高亮：OM 线段和直角符号
  - 目的：揭示弦中点性质——圆心到弦中点的连线垂直于弦

- 步骤 3：点击「下一步」→
  - 新增：角度弧 OAM（红色）、角度弧 APM（红色）、标签"∠OAM"、标签"∠APM"
  - 显示结论：在图示旁或角度附近标注"∠OAM + ∠APM = 90°"
  - 目的：展示目标角度，引导学生完成角度和的计算

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：ID=scene1-prev-btn，位置(250,460)，步骤0时禁用，步骤1-3时启用
  - 「下一步 ▶」按钮：ID=scene1-next-btn，位置(450,460)，步骤3时禁用，步骤0-2时启用
- 教师操作流程：
  1. 初始展示基础图形，让学生观察已知条件
  2. 点击「下一步」揭示辅助线 OP，讲解切线性质
  3. 再次点击「下一步」揭示辅助线 OM，讲解弦中点性质
  4. 最后点击「下一步」高亮目标角度，引导学生完成证明
  5. 可随时点击「上一步」回退复习某个步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形（圆、线段、点、角度弧）用 SVG 绘制最清晰，无需复杂动画库
  - 角度弧用 SVG path 的 arc 命令绘制
  - 直角标记用 SVG path 绘制 L 形

- 关键实现要点：
  1. 状态机设计：用变量 currentStep 记录当前步骤（0-3），根据 currentStep 控制各元素的 display 属性
  2. 坐标计算：所有坐标已在布局坐标表中精确给出，直接硬编码
  3. 角度弧绘制：用 SVG path 的 arc 命令，计算起点和终点的角度
     - ∠OAM：以 A(100,250) 为圆心，从 AO 方向到 AM 方向
     - ∠APM：以 P(520,160) 为圆心，从 PA 方向到 PM 方向
  4. 直角标记绘制：用 SVG path 绘制 L 形，如 M160,160 L160,172 L172,172
  5. 事件绑定：按钮点击事件更新 currentStep，然后调用 updateDisplay() 函数刷新显示
  6. 按钮状态：步骤0时禁用上一步，步骤3时禁用下一步

- ID 命名规范：
  - 所有交互元素 ID 以 scene1- 为前缀
  - 示例：scene1-circle-o, scene1-point-a, scene1-line-ap, scene1-line-op, scene1-line-om, scene1-right-angle-1, scene1-right-angle-2, scene1-arc-oam, scene1-arc-apm, scene1-prev-btn, scene1-next-btn

- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
