[分步序列]
- 初始状态（步骤 0）：
  - 显示△ABC 完整三角形（边 AB、BC、AC）
  - 显示顶点 A、B、C 及标签
  - 显示∠A=26°、∠C=120°、∠B=34°标注
  - 显示中位线 DE（虚线）及 D、E 点标签
  - A'点不显示
  - 提示文字："原三角形及中位线"

- 步骤 1：点击「下一步」→
  - A 点沿 DE 折叠到 A'位置（动画：A 点淡出，A'点淡入，位置从 (280,120) 移动到 (280,380)）
  - 显示△A'DE（边 A'D、A'E、DE）
  - 显示标签"A'"
  - 显示标签"DE 中位线"、"折叠"
  - 提示文字："沿中位线 DE 折叠，A 点落到 A'"

- 步骤 2：点击「下一步」→
  - 标注∠A'=26°（蓝色弧线 + 标签，蓝高亮 #1565c0）
  - 标注∠ADE（蓝色弧线 + 标签，蓝高亮 #1565c0）
  - 标注∠A'DE（绿色弧线 + 标签，绿高亮 #2e7d32）
  - 显示文字"∠A'DE = ∠ADE（折叠性质）"
  - 显示文字"DE∥AB ⇒ ∠ADE = ∠B = 34°（同位角）"
  - 提示文字："折叠后角度关系"

- 步骤 3：点击「下一步」→
  - 高亮∠A'DB（红色弧线 + 标签，红高亮 #c62828）
  - 显示计算过程："∠A'DB = 180° - ∠ADE - ∠A'DE = 180° - 34° - 34° = 112°"
  - 显示最终答案框："答案：112°"
  - 提示文字："待求角∠A'DB = 112°"

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮（scene2-prev-btn）：位于控件栏左侧，点击返回前一步骤
  - 下一步按钮（scene2-next-btn）：位于控件栏右侧，点击进入下一步骤
  - 步骤指示器：控件栏中间显示"步骤 X/4"
- 教师操作流程：
  1. 初始展示原三角形及已知条件
  2. 点击"下一步"展示折叠动画，引导学生观察 A 点移动轨迹
  3. 点击"下一步"标注折叠后角度关系，强调折叠性质（对应角相等）
  4. 点击"下一步"高亮待求角并展示计算过程，完成推导

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    图示区 800×500                       │
  │                                                         │
  │           A(280,120)                                    │
  │          /    \                                         │
  │         /      \                                        │
  │        /   △    \                                       │
  │   B(100,380)----C(400,380)                              │
  │        \   D(240,250)----E(340,250) /                   │
  │         \         虚线 DE         /                     │
  │          \                       /                      │
  │           A'(280,380)            /                      │
  │            \   △A'DE            /                      │
  │                                                         │
  │         [上一步]  步骤 X/4  [下一步]                    │
  │         (260,455)          (440,455)                   │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep 记录当前步骤（0-3），根据步骤控制元素显示/隐藏
  2. 坐标计算：所有元素坐标已在布局坐标表中精确定义，直接硬编码
  3. 动画曲线：A 点折叠动画使用 CSS transition，duration=0.8s，ease-in-out
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 renderStep() 重绘
  5. 角度弧线绘制：使用 SVG path 的 arc 命令，计算起点终点坐标
  6. 颜色管理：定义颜色常量对象，便于统一修改
- ID 命名规范：所有交互元素 ID 以 scene2- 为前缀（如 scene2-tri-abc、scene2-arc-ade、scene2-prev-btn）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局污染
