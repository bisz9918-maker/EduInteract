冲突检查（任意两标签间距 ≥ 20px）：
- C(635,250) 与 x(690,240)：√[(690-635)²+(240-250)²] = √[3025+100] ≈ 56px ✓
- D(485,105) 与 y(405,70)：√[(405-485)²+(70-105)²] = √[6400+1225] ≈ 87px ✓
- E(315,105) 与 y(405,70)：√[(405-315)²+(70-105)²] = √[8100+1225] ≈ 96px ✓
- F(165,250) 与 O(410,260)：√[(410-165)²+(260-250)²] = √[60025+100] ≈ 245px ✓
- A(315,395) 与 a(400,400)：√[(400-315)²+(400-395)²] = √[7225+25] ≈ 85px ✓
- B(485,395) 与 a(400,400)：√[(485-400)²+(400-395)²] = √[7225+25] ≈ 85px ✓
- a(400,400) 与 AB∥Ox(400,425)：|425-400| = 25px ✓（刚好满足）
- O(410,260) 与 A(315,395)：√[(410-315)²+(260-395)²] = √[9025+18225] ≈ 165px ✓
- O(410,260) 与 B(485,395)：√[(485-410)²+(395-260)²] = √[5625+18225] ≈ 154px ✓

结论：所有标签间距均 ≥ 20px，无冲突。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 按钮"◀ 上一步"：位于控件栏左侧 (50, 455)，返回上一状态
  - 按钮"下一步 ▶"：位于控件栏右侧 (650, 455)，进入下一状态
  - 步骤指示器：位于控件栏中央 (350-450, 455)，显示"步骤 1/4"
- 教师操作流程：
  1. 初始展示正六边形轮廓，引导学生观察整体形状
  2. 点击"下一步"，标注顶点 A-F 和边长 a，讲解顶点命名规则
  3. 点击"下一步"，显示坐标轴，讲解对称性
  4. 点击"下一步"，高亮 AB 边并标注平行条件，强调 AB∥Ox 的几何意义

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需复杂计算）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  ┌─────────────────────────────────────────────────────┐
  │                    SVG 画布 800×500                  │
  │                                                     │
  │              y                                      │
  │              ↑                                      │
  │         E ──── D                                    │
  │        /        \                                   │
  │       F          C      x →                         │
  │        \        /                                   │
  │         A ──── B                                    │
  │              ↓                                      │
  │                                                     │
  │        a                                            │
  │      AB∥Ox                                          │
  │  ┌─────────────────────────────────────────────┐   │
  │  │ ◀ 上一步      步骤 1/4        下一步 ▶      │   │
  │  └─────────────────────────────────────────────┘   │
  └─────────────────────────────────────────────────────┘
  ```

- 关键实现要点：
  1. 状态机设计：currentStep 变量 (0-3)，控制各元素的 display 属性
  2. 坐标计算：正六边形顶点按 60° 间隔分布，边长 a=150px
  3. 元素分组：使用 SVG <g> 标签按步骤分组，便于批量控制显示/隐藏
  4. 事件绑定：按钮点击事件更新 currentStep，遍历所有步骤组更新 display
  5. 按钮状态：步骤 0 时禁用"上一步"，步骤 3 时禁用"下一步"

- ID 命名规范：
  - 六边形轮廓：scene1-hexagon-outline
  - 顶点标签组：scene1-vertex-labels
  - 坐标轴组：scene1-coordinate-axes
  - 高亮元素组：scene1-highlight-elements
  - 边长标注：scene1-side-label
  - 平行条件标注：scene1-parallel-annotation
  - 上一步按钮：scene1-btn-prev
  - 下一步按钮：scene1-btn-next
  - 步骤指示器：scene1-step-indicator

- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
