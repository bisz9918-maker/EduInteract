[图示主题与整合说明]
- 本图示主题：函数S=f(t)奇偶性的验证对比
- 整合内容：t与-t两种情况的直线对比、交点对称关系展示、面积相等验证、结论呈现
- 教学价值：教师可通过切换三种状态（t=0、t>0、t<0），直观展示正六边形对称性如何导致△OMN面积关于t为偶函数，帮助学生理解函数奇偶性的几何意义

[分步序列]
多状态切换交互（非分步导航，三个状态按钮并列）：

- 状态0（t=0，初始状态）：
  - 显示：正六边形ABCDEF（半透明）、坐标轴、直线t=0（黑色，与x轴重合）、原点O
  - 隐藏：直线t>0、直线t<0、交点M₁/N₁/M₂/N₂、两个三角形填充、面积标签、结论标签

- 状态1（t>0，点击"t>0"按钮）：
  - 显示：状态0所有元素 + 直线t>0（蓝色）、交点M₁（蓝色圆点）、交点N₁（蓝色圆点）、△OM₁N₁（蓝色填充）、标签M₁、N₁、标签S₁="S₁=1200"
  - 高亮：蓝色元素（直线、交点、三角形）
  - 说明：直线向上平移，与六边形交于M₁、N₁，形成蓝色三角形，面积S₁

- 状态2（t<0，点击"t<0"按钮）：
  - 显示：状态0所有元素 + 直线t<0（红色）、交点M₂（红色圆点）、交点N₂（红色圆点）、△OM₂N₂（红色填充）、标签M₂、N₂、标签S₂="S₂=1200"、标签结论"f(t)=f(-t)，偶函数"
  - 高亮：红色元素（直线、交点、三角形）
  - 说明：直线向下平移，与六边形交于M₂、N₂，形成红色三角形。由于六边形关于x轴对称，S₂=S₁，验证f(t)=f(-t)

[交互方案]
- 交互类型：多状态切换（3个状态按钮）
- 控件说明：
  - 按钮"t=0"：位置(300,450)-(360,480)，切换到状态0，显示直线过原点情况
  - 按钮"t>0"：位置(370,450)-(430,480)，切换到状态1，显示直线向上平移情况
  - 按钮"t<0"：位置(440,450)-(500,480)，切换到状态2，显示直线向下平移情况
- 教师操作流程：
  1. 初始展示t=0状态，说明直线过原点时面积为0
  2. 点击"t>0"，展示直线向上平移，讲解交点M₁、N₁位置及三角形形成
  3. 点击"t<0"，展示直线向下平移，对比说明S₂=S₁，引出对称性
  4. 强调结论"f(t)=f(-t)，偶函数"，完成奇偶性验证

[技术实现]
- JS库选择：原生SVG + 原生JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │                        图示区 800×500                       │
  │                                                             │
  │         y                                                   │
  │         ↑                                                   │
  │    E ────┐      t>0(蓝)                                     │
  │   /      \     /                                            │
  │  F───────────M₁───────O──────────────────→ x                │
  │   \      /     \     /                                      │
  │    A ────┘      t<0(红)                                     │
  │         ↓                                                   │
  │                                                             │
  │   △OM₁N₁(蓝填充)        △OM₂N₂(红填充)                      │
  │                                                             │
  │   S₁=1200              S₂=1200                              │
  │   f(t)=f(-t)，偶函数                                        │
  │                                                             │
  │   [t=0]  [t>0]  [t<0]          ← 控件栏 y=450~480          │
  └─────────────────────────────────────────────────────────────┘
  ```

- 关键实现要点：
  1. 状态机设计：使用变量currentState（0/1/2）跟踪当前状态，setState(n)函数切换状态
  2. 坐标计算：正六边形顶点按边长a=120、中心(400,250)计算，直线方程y=kx+t，k=0.23
  3. 交点计算：直线与六边形边求交，t>0时交于左边EF和上边DE，t<0时交于左边EF和下边AB
  4. 动画曲线：状态切换使用opacity过渡（0.3s ease-in-out），元素淡入淡出
  5. 事件绑定：三个按钮分别绑定click事件，调用setState(0/1/2)
  6. ID命名规范：所有元素ID以"scene3-"为前缀，如scene3-hexagon、scene3-line-t0、scene3-btn-state0等
  7. IIFE隔离：所有JS代码包裹在(function() { ... })()中，避免全局污染
