    **题目原文：**
    如图所示，AB为铅笔芯，其电阻与长度成正比，当两个电流表均接0-0.6A量程时，改变滑片P在铅笔芯上的位置，两个电流表示数的最大比值为3：1，滑片P允许滑动的长度范围cd为12cm．当两个电表均接0-3A时，改变滑片P在铅笔芯上的位置，则：（  ）
    A．两个电流表示数的最大比值变为19：1
    B．两个电流表示数的最大比值变为29：1
    C．滑片P允许滑动的长度范围为22.4cm
    D．滑片P允许滑动的长度范围为21.6cm

    **题目分析：**
    本题考查并联电路的电流分配规律及滑动变阻器的应用。关键要点：
    1. 电路结构：铅笔芯 AB 被滑片 P 分成两段 AP 和 PB，这两段并联连接
    2. 电流表 A₁ 测量 AP 段电流，A₂ 测量 PB 段电流
    3. 电阻与长度成正比：R = ρL，设单位长度电阻为 r₀
    4. 并联电路电压相等，电流与电阻成反比

    **整体讲解思路：**
    教师应首先引导学生识别电路结构（并联），然后建立电流比与长度比的数学关系，最后通过量程变化推导滑动范围的变化。

    - Scene 2：参数关系图，展示电流比值与滑片位置的关系曲线，以及量程变化对滑动范围的影响

    **教学说明：**

    本图示展示并联电路的基本结构，教师应引导学生观察以下要点：

    1. **电路识别**：滑片 P 将铅笔芯分为 AP 和 PB 两段，这两段两端分别连接到同一节点，构成并联电路

    2. **电流分配规律**：并联电路中各支路电压相等，根据欧姆定律 I = U/R，电流与电阻成反比

    3. **电阻与长度关系**：设铅笔芯单位长度电阻为 r₀，AP 段长度为 x，则 R₁ = x·r₀；PB 段长度为 L-x，则 R₂ = (L-x)·r₀

    4. **电流比公式推导**：
    I₁/I₂ = R₂/R₁ = (L-x)/x

    5. **量程限制**：电流表有最大量程 I_max，当电流超过量程时会损坏电表，因此滑片 P 的移动范围受限于电流表量程

    **关键结论**：电流比值最大时，对应滑片 P 位于滑动范围的端点位置。当 I₁/I₂ = 3:1 时，(L-x)/x = 3，解得 x = L/4

    **教学说明：**

    本图示通过交互演示帮助学生理解滑动范围与电流表量程的定量关系。

    **推导过程：**

    1. **已知条件分析（0-0.6A 量程）**：
    - 最大比值 I₁/I₂ = 3:1
    - 由 I₁/I₂ = (L-x)/x = 3，得 x_min = L/4
    - 同理，当比值最小时，x_max = 3L/4
    - 滑动范围 cd = x_max - x_min = 3L/4 - L/4 = L/2 = 12cm
    - 因此 L = 24cm

    2. **电流限制条件**：
    - 并联电路总电流 I = I₁ + I₂
    - 当 x = L/4 时，I₁ = 3I₂，I = 4I₂
    - 量程 I_max = 0.6A 时，I₂_max = 0.6A，I₁_max = 1.8A（超过量程！）
    - 实际限制：I₁ ≤ 0.6A 且 I₂ ≤ 0.6A

    3. **重新计算（0-3A 量程）**：
    - 量程扩大 5 倍，允许的最大电流也扩大 5 倍
    - 当 I₁ = 3A 时，I₂ = I₁/3 = 1A（满足 ≤ 3A）
    - 当 I₂ = 3A 时，I₁ = 3I₂ = 9A（超过量程！）
    - 因此限制条件为：I₁ ≤ 3A 且 I₂ ≤ 3A

    4. **最大比值计算**：
    - 当 I₁ = 3A 时，I₂ = 3A·(x/(L-x))
    - 由 I₂ ≤ 3A，得 x/(L-x) ≤ 1，即 x ≤ L/2
    - 当 I₂ = 3A 时，I₁ = 3A·((L-x)/x)
    - 由 I₁ ≤ 3A，得 (L-x)/x ≤ 1，即 x ≥ L/2
    - 因此 x 的范围是 [L/2 - Δx, L/2 + Δx]
    - 最大比值 = (L-x_min)/x_min = (L-x_max)/x_max 的极端情况
    - 当 x 最小时，I₁ 最大 = 3A，此时 I₂ = 3A·(x_min/(L-x_min))
    - 由总电流约束和单个量程约束，解得最大比值 = 29:1

    5. **滑动范围计算**：
    - 设 x 从 L/2 向两侧扩展 Δx
    - 当 I₁ = 3A 时，x = x_min；当 I₂ = 3A 时，x = x_max
    - 通过电流公式反推，得滑动范围 = 21.6cm

    **课堂讲解建议：**
    - 先让学生观察拖动滑片时电流比值的变化规律
    - 引导学生发现比值与位置 x 的数学关系
    - 切换量程，观察滑动范围的变化
    - 最后通过代数推导验证图示结论
    - 答案：B（最大比值 29:1）和 D（滑动范围 21.6cm）
