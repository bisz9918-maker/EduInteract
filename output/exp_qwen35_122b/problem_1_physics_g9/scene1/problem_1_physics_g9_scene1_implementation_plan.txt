[分步序列]
- 步骤 0（初始状态）：
  - 显示：杠杆 OAB（黑线）、支点三角形、重物 G（矩形 + 红箭头）、四个力 F₁/F₂/F₃/F₄（蓝色箭头）
  - 标签：O、A、B、G、F₁、F₂、F₃、F₄
  - 不显示：任何力臂虚线
  - 目的：展示题目基础条件，让学生识别杠杆各要素

- 步骤 1：
  - 视觉变化：支点三角形高亮（填充 #fff9c4 浅黄色），显示提示文字"支点是杠杆绕着转动的固定点"
  - 提示文字位置：(350,400)，字号 16px，黑色
  - 目的：强调支点概念

- 步骤 2：
  - 视觉变化：高亮重物 G 箭头（加粗至 3px），显示阻力臂 L_G 虚线（与杠杆 OA 重合，灰色虚线），标注"L_G"
  - 提示文字："阻力臂是从支点到阻力作用线的垂直距离"
  - 目的：引入阻力臂概念

- 步骤 3：
  - 视觉变化：依次演示四个力的力臂（每点击一次下一步演示一个力）
  - 子步骤 3a：显示 L₁虚线（灰色），高亮 F₁箭头，标注"L₁"
  - 子步骤 3b：显示 L₂虚线（灰色），高亮 F₂箭头，标注"L₂"
  - 子步骤 3c：显示 L₃虚线（灰色），高亮 F₃箭头，标注"L₃"，同时显示文字提示"F₃垂直向上，力臂 L₃=OB"
  - 子步骤 3d：显示 L₄虚线（灰色），高亮 F₄箭头，标注"L₄"
  - 目的：演示力臂画法——从支点向力的作用线作垂线

- 步骤 4：
  - 视觉变化：同时显示所有四个力臂（L₁/L₂/L₃/L₄均为灰色虚线），L₃用绿色加粗高亮
  - 显示文字："比较力臂长度：L₃最长（等于 OB）"
  - 目的：直观对比四个力臂长度

- 步骤 5（最终步骤）：
  - 视觉变化：L₃保持绿色加粗，其他力臂变淡（透明度 50%）
  - 显示结论文字："根据杠杆平衡条件 F×L = G×L_G，力臂最长则力最小，所以 F₃最小"
  - 目的：得出结论，回答问题

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：ID=scene1-prev-btn，位置 (250,455)，步骤 0 时禁用（灰色），其他步骤可点击
  - "下一步 ▶"按钮：ID=scene1-next-btn，位置 (550,455)，始终可点击，步骤 5 时变为"完成"
  - 步骤指示器：ID=scene1-step-indicator，位置 (370,465)，显示"步骤 X/6"
- 教师操作流程：
  1. 初始展示杠杆结构，让学生识别支点、阻力、动力
  2. 点击"下一步"逐步讲解支点概念
  3. 继续点击讲解阻力臂
  4. 逐步演示四个力的力臂画法
  5. 对比力臂长度
  6. 得出结论
  教师可随时点击"上一步"回退复习，或根据学生反应调整讲解节奏

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（线段、箭头、矩形、三角形），原生 SVG 足够且性能好，无需引入大型库
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    图示区 800×500                       │
  │                                                         │
  │     O          A                    B                   │
  │     △──────────┼────────────────────●──→F₂             │
  │                │                    │  ╲               │
  │                ▼ G                   │   ↗ F₃          │
  │               ┌──┐                   │  ╱               │
  │               │  │                   ↖ F₄              │
  │               └──┘                   ╲                 │
  │                                      ↓ F₁              │
  │                                                         │
  │            [力臂虚线根据步骤显示]                       │
  │                                                         │
  │  ┌─────────────────────────────────────────────────┐   │
  │  │        ◀ 上一步    步骤 1/6     下一步 ▶         │   │
  │  └─────────────────────────────────────────────────┘   │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-5) 跟踪当前步骤，updateScene() 函数根据 currentStep 显示/隐藏对应元素
  2. 坐标计算：所有元素坐标按布局坐标表硬编码，力臂虚线终点通过几何计算（从 O 点到各力作用线的垂足）
  3. 动画曲线：力臂显示使用 opacity 渐变（0→1，时长 300ms），高亮使用 stroke-width 变化
  4. 事件绑定：按钮点击事件调用 prevStep()/nextStep()，更新 currentStep 后调用 updateScene()
  5. 力臂几何计算：
     - L₁：O 到 F₁作用线（过 B 点，方向 45°右下）的垂线
     - L₂：O 到 F₂作用线（过 B 点，方向 45°右上）的垂线
     - L₃：O 到 F₃作用线（过 B 点，垂直向上）的垂线 = OB 线段
     - L₄：O 到 F₄作用线（过 B 点，方向 45°左上）的垂线
  6. 提示文字：步骤 1/2/3c/4/5 显示不同提示，用 <text> 元素，根据 currentStep 控制显示
- ID 命名规范：所有交互元素 ID 以 scene1- 为前缀
  - scene1-lever（杠杆）
  - scene1-fulcrum（支点）
  - scene1-weight（重物）
  - scene1-force1/2/3/4（四个力）
  - scene1-arm1/2/3/4（四个力臂）
  - scene1-prev-btn、scene1-next-btn、scene1-step-indicator（控件）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局污染
