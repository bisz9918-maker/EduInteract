[分步序列]
- 步骤 0（初始状态全览）：
  - 显示：A 管、B 管轮廓，活塞，水银区域（A 管和 B 管），封闭气柱
  - 显示：所有尺寸标注（h₁=5cm, h₂=10cm, L=112cm）
  - 显示：S_A=4S_B 标注
  - 不显示：压强箭头和压强标签
  - 结果框文本："初始状态"

- 步骤 1（高亮大气压作用）：
  - 新增：p₀=75cmHg 标签和向下红色箭头
  - 高亮：活塞上表面（加粗边框或闪烁效果）
  - 结果框文本："p₀ 作用于活塞上方"

- 步骤 2（高亮水银柱压强）：
  - 新增：p_气标签指向封闭气体
  - 高亮：A 管水银和 B 管水银区域（加深蓝色或加粗边框）
  - 显示：水银柱总高度 h₁+h₂=15cm 的标注
  - 结果框文本："水银柱压强 = h₁ + h₂ = 15cmHg"

- 步骤 3（显示封闭气体压强公式）：
  - 高亮：封闭气柱区域（加深浅蓝色）
  - 显示：压强平衡公式 p_气 = p₀ + h₁ + h₂
  - 结果框文本："p_气 = p₀ + h₁ + h₂"

- 步骤 4（显示计算结果）：
  - 所有元素正常显示
  - 结果框文本："p_气 = 75 + 5 + 10 = 90cmHg"
  - 封闭气体压强标签显示完整："p_气 = 90cmHg"

- 画布尺寸：800 × 500 px

- 关键实现要点：
  1. 状态机设计：用 currentStep 变量（0-4）跟踪当前步骤，每个步骤定义显示/隐藏的元素 ID 列表
  2. 坐标计算：所有元素使用绝对坐标，管壁用 line 元素，填充区域用 rect 元素
  3. 动画曲线：步骤切换使用 opacity 过渡（0.3s ease），高亮效果使用 stroke-width 变化
  4. 事件绑定：按钮点击事件更新 currentStep，调用 updateScene() 刷新显示
  5. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-tube-A, scene1-piston, scene1-mercury-A 等）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 水银斜线纹理：使用 SVG pattern 定义斜线填充模式
  8. 压强箭头：用 line + polygon 组合绘制带箭头的线段
