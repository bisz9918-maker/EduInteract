[分步序列]
本场景采用连续拖拽交互，无分步按钮，状态随滑块连续变化：

- 初始状态（x=0）：
  - 活塞位置：y=120（相对位移 0）
  - A 管水银面：y=140（未下降，Δh₁=0）
  - B 管水银面：y=280（未上升，Δh₂=0）
  - 气柱长度：L'=112cm（原始长度）
  - 气体压强：p'=90cmHg（初始压强 = p₀ + h₁ + h₂ = 75+5+10=90）
  - 拉力 F=0
  - 数据显示：x=0, Δh₁=0, Δh₂=0, L'=112, p'=90, F=0

- 拖拽过程（x 从 0 到 20cm 连续变化）：
  - 活塞向上移动 x cm
  - A 管水银面下降 Δh₁ = x/5 cm（体积守恒：Δh₁·S_A = x·S_A - Δh₂·S_B，推导得Δh₁=x/5）
  - B 管水银面上升 Δh₂ = 4Δh₁ = 4x/5 cm
  - 气柱长度 L' = 112 - Δh₂ = 112 - 4x/5 cm
  - 气体压强 p' = p₀·L/L' = 75×112/L' cmHg（玻意耳定律）
  - 拉力 F = (p' - p₀)·S_B - ρg·(Δh₁·S_A + Δh₂·S_B) 简化计算
  - 实时更新所有标注和数据显示

- 最大位移状态（x=20cm）：
  - 活塞位置：y=100（向上移动 20cm）
  - Δh₁ = 4cm, Δh₂ = 16cm
  - L' = 112 - 16 = 96cm
  - p' = 75×112/96 = 87.5cmHg
  - 显示最终数据

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：
  1. 底部滑块控件（scene2-slider）：range 类型，min=0, max=20, step=0.1，控制活塞位移 x
  2. 活塞手柄（scene2-piston-handle）：可拖拽区域，与滑块联动
- 教师操作流程：
  1. 初始展示系统平衡状态（x=0, F=0）
  2. 拖动滑块或活塞手柄，缓慢向上拉活塞
  3. 观察水银面联动变化（A 管下降、B 管上升）
  4. 实时读取数据面板中的 x、Δh₁、Δh₂、L'、p'、F 值
  5. 讲解体积守恒关系Δh₂ = 4Δh₁
  6. 讲解玻意耳定律 p' = p₀·L/L'
  7. 分析拉力 F 的变化规律（何时 F=0，何时 F 最大）

  │  └──────────────────────────────────────────────────────────┘  │
  └────────────────────────────────────────────────────────────────┘

- 关键实现要点：
  1. 状态机设计：单一状态变量 x（活塞位移），其他所有变量由 x 计算得出
  2. 坐标计算：
     - 活塞 y 坐标 = 120 - x（向上为正）
     - A 管水银面 y = 140 + Δh₁ = 140 + x/5
     - B 管水银面 y = 280 - Δh₂ = 280 - 4x/5
     - 气柱底部 y = 420（固定），顶部 y = 280 - Δh₂ + h₂ = 340 - 4x/5
  3. 物理公式：
     - Δh₁ = x/5（体积守恒推导）
     - Δh₂ = 4Δh₁ = 4x/5
     - L' = 112 - Δh₂
     - p' = 75 × 112 / L'（玻意耳定律，等温过程）
     - F = (p' - 75) × S_B - ρg × (Δh₁×S_A + Δh₂×S_B) 简化为 F = (p' - 75 - Δh₁ - Δh₂) × S_B
  4. 动画曲线：滑块拖拽实时更新，无缓动
  5. 事件绑定：slider input 事件、piston handle mousedown/mousemove/mouseup 事件
  6. ID 命名规范：所有元素 ID 以 scene2- 为前缀（如 scene2-slider, scene2-piston, scene2-mercury-a, scene2-mercury-b, scene2-gas, scene2-data-x 等）
  7. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
