[分步序列]
- 初始状态（步骤 0）：显示完整 F-x 函数图像，包括坐标系、网格线、完整曲线、所有关键点标记、坐标轴标签。状态说明文本显示"拉力 F 随活塞位移 x 的变化规律"
- 状态 1（点击"全览"）：显示 F-x 曲线全览，标注起点 (x=0, F<0) 和零点 (x≈28cm, F=0)，状态说明显示"完整曲线：F 从负值开始，先增大后减小至零"
- 状态 2（点击"临界点"）：高亮零点标记 (x≈28cm, F=0)，该点红色圆点放大至 10px 并闪烁，状态说明显示"临界点：x≈28cm 时 F=0，此时无需外力即可保持平衡"
- 状态 3（点击"趋势分析"）：显示绿色趋势箭头和文字标注，在曲线上升段标注"增大"，下降段标注"减小"，状态说明显示"变化趋势：F 先增大（0<x<12cm）后减小（12cm<x<28cm）"

[交互方案]
- 交互类型：多状态切换（3 个按钮）
- 控件说明：
  - 按钮 1 "全览"：位置 (200,450)，显示完整 F-x 曲线及关键点
  - 按钮 2 "临界点"：位置 (350,450)，高亮 F=0 的临界位置
  - 按钮 3 "趋势分析"：位置 (450,450)，显示变化趋势箭头和文字
- 教师操作流程：
  1. 点击"全览"展示完整曲线，讲解 F 随 x 变化的整体规律
  2. 点击"临界点"高亮 F=0 位置，强调 x≈28cm 时的平衡状态
  3. 点击"趋势分析"显示增减区域，分析 F 变化的物理原因（气体压强变化导致）

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单函数图像无需引入大型库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    F-x 函数图像区                        │
  │  (120,80) ┌───────────────────────────────────────┐     │
  │           │    F                                  │     │
  │           │    ↑                                  │     │
  │           │    │     ● 极值点                     │     │
  │           │    │    /   \                         │     │
  │           │    │   /     \                        │     │
  │           │    │  /       \                       │     │
  │           │    │ /         \                      │     │
  │           │    ●             ● 零点               │     │
  │           │ 起点              \                   │     │
  │           │                    \                  │     │
  │           └───────────────────────────────────────┘     │
  │           0    5   10   15   20   25   30  x (cm)       │
  │                                                         │
  │  状态说明：拉力 F 随活塞位移 x 的变化规律                  │
  │                                                         │
  │  [ 全览 ]  [ 临界点 ]  [ 趋势分析 ]                      │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 currentStatus 记录当前状态 (1/2/3)，切换时更新 DOM 元素可见性
  2. 坐标计算：F-x 曲线使用二次贝塞尔曲线模拟，起点 (140,280)，极值点 (350,180)，终点 (660,380)
  3. 动画曲线：状态切换使用 CSS transition 实现淡入淡出效果 (opacity: 0→1, 300ms)
  4. 事件绑定：三个按钮分别绑定 click 事件，调用 updateStatus(n) 函数切换状态
  5. 高亮效果：临界点高亮使用 CSS animation 实现脉冲效果 (scale: 1→1.5→1, 1s 循环)
- ID 命名规范：所有元素 ID 以 scene3- 为前缀，如 scene3-axis-x、scene3-curve、scene3-btn-1、scene3-point-zero 等
- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染
