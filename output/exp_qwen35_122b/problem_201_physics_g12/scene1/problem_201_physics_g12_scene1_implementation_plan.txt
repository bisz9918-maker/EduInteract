[图示主题与整合说明]
- 本图示主题：带电粒子在复合场中的运动分解
- 整合内容：
  - 粒子从 A 到 B 的抛物线运动轨迹
  - 水平方向：初速为 0 的匀加速直线运动（电场力 qE 作用）
  - 竖直方向：竖直上抛运动（重力 mg 作用）
  - A 点和 B 点的速度矢量对比（v₀ 竖直向上 → v_B=2v₀ 水平向右）
- 教学价值：教师可逐步引导学生理解：
  1. 初始状态：粒子以 v₀ 竖直向上射入水平电场
  2. 受力分析：重力向下、电场力向右，两方向运动独立
  3. 轨迹形成：抛物线运动是两方向运动的合成
  4. 末状态：竖直速度减为 0，水平速度增至 2v₀
  5. 速度分解对比：清晰展示两方向速度变化规律

[分步序列]
步骤 0（初始状态）：
- 显示：5 条电场线（黑色水平箭头）、E 标签
- 显示：A 点（黑色圆点）、A 标签
- 显示：v₀矢量（蓝色竖直向上箭头）、v₀标签
- 隐藏：B 点、轨迹、受力矢量、位移标注、v_B 矢量
- 教师讲解：粒子以 v₀竖直向上射入水平匀强电场

步骤 1（运动分解）：
- 新增：mg 矢量（红色虚线向下）、mg 标签
- 新增：qE 矢量（绿色虚线向右）、qE 标签
- 显示：B 点（黑色圆点）、B 标签
- 隐藏：无
- 教师讲解：粒子受重力 mg 向下、电场力 qE 向右，两方向运动独立

步骤 2（轨迹形成）：
- 新增：轨迹曲线（蓝色抛物线，从 A 到 B）
- 新增：水平位移线（灰色虚线）、竖直位移线（灰色虚线）
- 新增：x 标签、h 标签、直角符号
- 教师讲解：粒子做抛物线运动，水平匀加速、竖直上抛

步骤 3（B 点状态）：
- 新增：v_B矢量（红色水平向右箭头）、v_B标签
- 教师讲解：到达 B 点时竖直速度减为 0，水平速度增至 2v₀

步骤 4（速度分解对比）：
- 高亮：v₀矢量（加粗或闪烁）、v_B矢量（加粗或闪烁）
- 在 A 点附近添加文字标注：v_x=0, v_y=v₀
- 在 B 点附近添加文字标注：v_x=2v₀, v_y=0
- 教师讲解：对比初末状态速度分量，总结运动规律

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（线段、圆、箭头、曲线），原生 SVG 足够且性能好，无需引入重型库
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │ 800×500 SVG 画布                                         │
  │                                                         │

  │                                                         │
  │                    ● B                                  │ 电场线 y=180
  │                   → v_B                                 │
  │                                                         │
  │  ←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←  │ 电场线 y=260
  │                                                         │
  │  ● A                                                    │ 电场线 y=340
  │  ↑ v₀  → qE                                             │
  │  ↓ mg                                                   │
  │                                                         │

  │                                                         │

  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep 记录当前步骤（0-4），根据 currentStep 控制元素显示/隐藏
  2. 坐标计算：所有元素坐标按布局坐标表精确实现，使用 SVG 绝对坐标
  3. 动画曲线：轨迹用贝塞尔曲线<path d="M 150,340 Q 350,340 550,180">实现抛物线
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateDisplay() 刷新显示
  5. 渐变透明度：轨迹用<linearGradient>定义，从 A 点 30% 到 B 点 10%
  6. 箭头绘制：用 SVG marker 定义箭头头，复用於所有箭头元素
- ID 命名规范：所有交互元素 ID 以"scene1-"为前缀
  - 元素 ID 示例：scene1-field-line-1, scene1-point-a, scene1-vec-v0, scene1-traj, scene1-prev-btn, scene1-next-btn, scene1-step-indicator
  - JS 中使用 getElementById('scene1-xxx') 获取元素
- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
