题目原文：
如图所示的直角坐标系中，第Ⅰ、Ⅳ象限内存在着垂直纸面向里的匀强磁场，在$x=-2L$与$y$轴之间第Ⅱ、Ⅲ象限内存在大小相等，方向相反的匀强电场，场强方向如图所示。在$A(-2L,L)$到$C(-2L,0)$的连线上连续分布着电荷量为＋$q$、质量为$m$的粒子。从$t=0$时刻起，这些带电粒子依次以相同的速度$v_{0}$沿$x$轴正方向射出。从$A$点射出的粒子刚好沿如图所示的运动轨迹（轨迹与$x$轴的交点为$OC$的中点）从$y$轴上沿$x$轴正方向进入磁场。不计粒子的重力及它们间的相互作用，不考虑粒子间的碰撞。

（1）求电场强度$E$的大小；
（2）若匀强磁场的磁感应强度$B=\frac{8mv_{0}}{5qL}$，求从$A'$点进入磁场的粒子返回到直线$x=-2L$时的位置坐标；
（3）在$AC$间还有哪些位置的粒子，经过电场后也能沿$x$轴正方向进入磁场。

题目分析：
本题是带电粒子在组合场（电场+磁场）中运动的综合问题，涉及以下核心知识点：

  1. 电场中的类平抛运动：粒子在第Ⅱ、Ⅲ象限的电场中做类平抛运动，水平方向匀速直线运动，竖直方向匀加速直线运动
  2. 磁场中的匀速圆周运动：粒子进入磁场后做匀速圆周运动，洛伦兹力提供向心力
  3. 对称性分析：电场区域上下对称，粒子轨迹具有对称特征
  4. 临界条件分析：第（3）问需要找出满足特定条件的粒子初始位置

整体讲解思路：

  • 首先通过图示1展示完整的物理场景，帮助学生建立空间认知
  • 通过图示2详细分析电场中的运动分解，推导电场强度E
  • 通过图示3展示磁场中的圆周运动轨迹，结合几何关系求解位置坐标
  • 最后总结第（3）问的对称性条件

步骤 0/5

图示2教学说明：电场中运动分解与电场强度求解

教学目标：
引导学生理解粒子在电场中的类平抛运动，通过运动分解推导电场强度E的表达式。

讲解要点：

  1. 运动分解思路

粒子在电场中受到恒定的电场力F=qE，加速度a=qE/m恒定。由于初速度v₀沿x轴方向，而电场力沿y轴方向，因此：

  • 水平方向：匀速直线运动，v_x = v₀
  • 竖直方向：匀加速直线运动，初速度为0
  1. 关键条件分析

从A点(-2L,L)出发的粒子，运动到y轴时沿x轴正方向进入磁场，说明此时竖直速度v_y=0。

  1. 对称性应用

粒子在第Ⅱ象限（y>0）电场向下，做类平抛运动；进入第Ⅲ象限（y<0）后电场向上，加速度反向。轨迹与x轴交点为OC中点，即(-L,0)。

推导步骤：

  1. 粒子从A(-2L,L)运动到x轴交点(-L,0)：
  • 水平位移：Δx = L
  • 竖直位移：Δy = -L
  • 水平时间：t₁ = L/v₀
  1. 竖直方向运动分析（第Ⅱ象限）：
  • 加速度：a = qE/m（向下）
  • 到达x轴时竖直速度：v_y1 = a·t₁ = (qE/m)·(L/v₀)
  1. 粒子从x轴交点(-L,0)运动到A'点（y轴）：
  • 水平位移：Δx = L
  • 水平时间：t₂ = L/v₀ = t₁
  • 第Ⅲ象限加速度：a' = -qE/m（向上，与第Ⅱ象限相反）
  1. 竖直方向速度变化：
  • 从x轴到y轴，竖直速度：vy2 = vy1 + a'·t₂ = v_y1 - (qE/m)·(L/v₀) = 0
  • 这解释了为什么粒子沿x轴方向进入磁场
  1. 求解E：
  • 从A到x轴，竖直位移：-L = 0·t₁ - (1/2)·(qE/m)·t₁²
  • 代入t₁ = L/v₀：-L = -(1/2)·(qE/m)·(L²/v₀²)
  • 解得：E = 2mv₀²/(qL)

引导学生观察：

  • 注意轨迹在x轴两侧的对称性
  • 理解为什么粒子到达y轴时竖直速度为零
  • 体会运动分解法在复杂运动分析中的优势
步骤 0/5

图示3教学说明：磁场中圆周运动与返回位置计算

教学目标：
引导学生分析粒子在磁场中的匀速圆周运动，利用几何关系求解粒子返回x=-2L直线时的位置坐标。

讲解要点：

  1. 磁场中运动特征

粒子以速度v₀沿x轴正方向进入磁场，洛伦兹力提供向心力，做匀速圆周运动。

  1. 半径计算

由qv₀B = mv₀²/R，得R = mv₀/(qB)
代入B = 8mv₀/(5qL)，得R = 5L/8

  1. 几何关系分析
  • 粒子从A'点进入磁场，速度沿x轴正方向
  • 圆心在A'点正上方（或正下方），距离为R
  • 粒子在磁场中运动半周后，速度反向，沿x轴负方向离开磁场
  • 离开磁场后，粒子再次进入电场区域，运动轨迹与进入时对称
  1. 返回位置计算
  • 粒子在磁场中偏转180°后，从磁场左边界（y轴）离开
  • 离开磁场时速度沿x轴负方向，大小仍为v₀
  • 粒子再次穿过电场区域，由于电场对称性，返回x=-2L时的竖直位置与A'点对称

推导步骤：

  1. 先求A'点坐标：
  • 从A到A'，竖直方向总位移：Δy_total = -2L（从y=L到y=-L）
  • 所以A'点坐标为(0, -L)
  1. 磁场中圆周运动半径：
  • R = mv₀/(qB) = mv₀/(q·8mv₀/5qL) = 5L/8
  1. 圆心位置：
  • 粒子从A'(0,-L)沿x轴正方向进入磁场
  • 洛伦兹力方向：由左手定则，F沿y轴负方向
  • 圆心在A'点下方，坐标为(0, -L-R) = (0, -L-5L/8) = (0, -13L/8)
  1. 粒子在磁场中的轨迹：
  • 做半圆周运动，从A'(0,-L)到B(0,-L-2R) = (0,-L-5L/4) = (0,-9L/4)
  • 离开磁场时速度沿x轴负方向
  1. 返回x=-2L的位置：
  • 粒子从磁场离开后，以v₀沿x轴负方向进入电场
  • 由于电场对称性和时间反演对称性，粒子将沿原轨迹返回
  • 最终返回x=-2L时的位置：(-2L, -3L)

引导学生观察：

  • 注意磁场中圆周运动的圆心确定方法
  • 理解对称性在简化计算中的作用
  • 体会洛伦兹力不做功，粒子速率保持不变
步骤 1/6

总结与第（3）问讲解

完整解答汇总：

（1）电场强度大小：E = 2mv₀²/(qL)

（2）返回位置坐标：(-2L, -3L)

（3）AC间满足条件的粒子位置：

第（3）问分析：
要使粒子经过电场后沿x轴正方向进入磁场，需要满足：

  • 粒子到达y轴时，竖直速度v_y = 0
  • 这要求粒子在电场中运动的时间是电场方向改变周期的整数倍

对称性条件：
设粒子从y=y₀处发射（y₀∈[0,L]）：

  • 到达x轴的时间：t₁ = 2L/v₀（水平位移2L）
  • 竖直方向：先加速后减速，总时间需满足对称条件
  • 粒子在电场中运动的总时间：t_total = 2L/v₀

满足条件的位置：
粒子要沿x轴方向进入磁场，需要竖直速度为零。由运动对称性：

  • 从y₀发射的粒子，到达y轴时竖直位移为-y₀
  • 要满足v_y=0，需要粒子在电场中经历完整的加速-减速周期
  • 因此，y₀ = L/n（n=1,2,3,...），即y₀ = L, L/2, L/3, ...

但在AC范围内（y₀∈[0,L]），满足条件的位置为：
y₀ = L/n，其中n为正整数，且y₀≥0

即：(-2L, L/n)，n=1,2,3,...

  1. 先用图示1建立整体认知，让学生理解题目的物理场景
  2. 通过图示2详细推导电场强度，强调运动分解法的应用
  3. 通过图示3展示磁场中的圆周运动，重点讲解圆心确定和几何关系
  4. 第（3）问强调对称性思维，引导学生发现位置分布的规律
  5. 总结时回顾三个图示的逻辑关系：场景→电场分析→磁场分析→综合应用
