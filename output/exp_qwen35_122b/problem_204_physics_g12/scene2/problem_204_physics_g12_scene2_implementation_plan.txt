[图示主题与整合说明]
- 本图示主题：三临界状态受力对比分析（圆盘转动系统）
- 整合内容：ω₀（AB 绳开始有张力）、ω₁（OB 绳开始有张力）、ω₂（A 开始滑动）三个临界状态的受力分析
- 教学价值：教师可通过分步导航展示物理过程的连续性，帮助学生理解：
  1. 静摩擦力如何随角速度增加而增大
  2. 绳子张力何时开始产生
  3. 临界状态的判断条件

[分步序列]
步骤 0（ω < ω₀）：
- 显示：圆盘、转轴、物体 A、B、半径辅助线、距离标注
- 力矢量：f_A（橙色，细箭头，长度 30px）、f_B（橙色，细箭头，长度 15px）
- 无绳子张力
- 状态显示：ω < ω₀，f_A = mω²r_A，f_B = mω²r_B，T_AB = 0，T_OB = 0

步骤 1（ω = ω₀）：
- 显示：同上
- 力矢量：f_A（红色，粗箭头，长度 60px，标注 f_max）、f_B（橙色，细箭头，长度 30px）
- T_AB 开始出现（绿色，极短箭头，长度 5px，标注 T_AB=0⁺）
- 状态显示：ω = ω₀，f_A = f_max = 0.5mg，f_B = mω₀²r_B，T_AB = 0⁺，T_OB = 0
- 临界标识：在 A 旁标注"临界：AB 绳开始有张力"

步骤 2（ω₀ < ω < ω₁）：
- 显示：同上
- 力矢量：f_A（红色，粗箭头，长度 60px）、f_B（橙色，细箭头，长度 40px）
- T_AB（绿色，中等箭头，长度 20px）
- 状态显示：ω₀ < ω < ω₁，f_A = f_max，f_B < f_max，T_AB > 0，T_OB = 0

步骤 3（ω = ω₁）：
- 显示：同上
- 力矢量：f_A（红色，粗箭头，长度 60px）、f_B（红色，粗箭头，长度 60px，标注 f_max）
- T_AB（绿色，较长箭头，长度 35px）
- T_OB 开始出现（绿色，极短箭头，长度 5px，标注 T_OB=0⁺）
- 状态显示：ω = ω₁，f_A = f_max，f_B = f_max，T_AB > 0，T_OB = 0⁺
- 临界标识：在 B 旁标注"临界：OB 绳开始有张力"

步骤 4（ω₁ < ω < ω₂）：
- 显示：同上
- 力矢量：f_A（红色，粗箭头，长度 60px）、f_B（红色，粗箭头，长度 60px）
- T_AB（绿色，长箭头，长度 50px）
- T_OB（绿色，中等箭头，长度 25px）
- 状态显示：ω₁ < ω < ω₂，f_A = f_max，f_B = f_max，T_AB 增大，T_OB > 0

步骤 5（ω = ω₂）：
- 显示：同上
- 力矢量：f_A（红色，粗箭头，长度 60px）、f_B（红色，粗箭头，长度 60px）
- T_AB（绿色，最长箭头，长度 70px，接近 2mg）
- T_OB（绿色，较长箭头，长度 45px）
- 状态显示：ω = ω₂，f_A + T_AB = mω₂²r_A（即将滑动），f_B = f_max，T_AB < 2mg
- 临界标识：在 A 旁标注"临界：A 即将滑动"

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮（scene2-btn-prev）：位于底部左侧，点击返回上一状态
  - 下一步按钮（scene2-btn-next）：位于底部右侧，点击进入下一状态
  - 步骤指示器：显示当前步骤（如"步骤 1/5"）
- 教师操作流程：
  1. 从步骤 0 开始，展示基础系统布局
  2. 点击"下一步"逐步展示三个临界状态
  3. 在步骤 1、3、5 重点讲解临界条件
  4. 可随时点击"上一步"回退复习
  5. 配合右侧力状态显示，对比各状态下力的变化

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何和动画，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │                        图示区 800×500                          │
  │                                                                │
  │     ┌────────────────────────────────────────────────────┐    │
  │     │                    圆盘俯视图                       │    │
  │     │                                                     │    │
  │     │        旋转箭头                                      │    │
  │     │           ↑                                         │    │
  │     │           │                                         │    │
  │     │      O─────B────────────A                           │    │
  │     │      │     │←f_B→│←f_A→│                           │    │
  │     │      │     │     │     │                           │    │
  │     │      │←r_B→│←────r_A──→│                           │    │
  │     │                                                     │    │
  │     │     右侧力状态显示区                                 │    │
  │     │     ω = ...                                         │    │
  │     │     f_A = ...                                       │    │
  │     │     f_B = ...                                       │    │
  │     │     T_AB = ...                                      │    │
  │     │     T_OB = ...                                      │    │
  │     └────────────────────────────────────────────────────┘    │
  │                                                                │
  │     ┌────────────────────────────────────────────────────┐    │
  │     │  ◀上一步        步骤 1/5         下一步▶            │    │
  │     └────────────────────────────────────────────────────┘    │
  └────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep（0-5）跟踪当前步骤
  2. 力矢量长度计算：根据当前步骤动态计算箭头长度（f_max 固定 60px，其他按比例）
  3. 颜色切换：根据步骤动态切换力矢量颜色（橙色→红色，绿色箭头出现/消失）
  4. 文本更新：右侧状态显示区根据当前步骤更新力的大小描述
  5. 临界标识：在步骤 1、3、5 显示对应的临界条件文本
  6. 按钮状态：步骤 0 禁用"上一步"，步骤 5 禁用"下一步"
- ID 命名规范：所有交互元素 ID 以 scene2- 为前缀（如 scene2-obj-A、scene2-arrow-fA、scene2-btn-prev）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局污染
