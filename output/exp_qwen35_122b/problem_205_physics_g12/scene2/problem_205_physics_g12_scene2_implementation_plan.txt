[分步序列]
- 步骤0（初始状态）：显示半圆轨道、圆心O、N点标注、L点物块、半径R虚线、标签L/O/N/R。受力箭头和速度箭头隐藏。
- 步骤1（受力分析）：显示重力G箭头（红色，向下）、支持力N箭头（绿色，向下）。标签"G=mg"和"N"出现。
- 步骤2（向心力公式）：显示向心力Fn箭头（蓝色虚线，向下）。标签"F_n"出现。同时高亮重力G和支持力N箭头，显示公式文本"mg + N = F_n"在图示右侧(500,200)位置。
- 步骤3（临界速度）：支持力N箭头消失（临界时N=0）。向心力Fn箭头变为实线并加粗。显示公式文本"mg = m·v_L²/R"在(500,200)。显示临界速度推导"v_L ≥ √(gR)"在(500,250)。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 按钮"◀ 上一步"：位置(280,460)，作用：返回上一状态
  - 按钮"下一步 ▶"：位置(500,460)，作用：进入下一状态
  - 步骤指示器：位置(380,460)，显示"步骤 X/3"
- 教师操作流程：
  1. 初始展示L点位置，提问"物块在最高点需要满足什么条件才能不脱离轨道？"
  2. 点击下一步，展示受力分析，引导学生识别重力和支持力
  3. 点击下一步，展示向心力公式，讲解合力提供向心力
  4. 点击下一步，展示临界条件（N=0），推导最小速度v_L=√(gR)

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何和动画，无需重型库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    图示区 800×500                       │
  │                                                         │
  │           v_L ← ┌─────┐                                 │
  │                 │  L  │  G↓  N↓  Fn↓                    │
  │           ┌─────┴─────┴─────┴─────┐                     │
  │           │                       │                     │
  │      P    │         半圆           │                    │
  │           │         轨道            │                   │
  │           │                       │                     │
  │           └───────────┬───────────┘                     │
  │                       O                                 │
  │                       N                                 │
  │                                                         │
  │  ┌─────────────────────────────────────────────────┐   │
  │  │    ◀ 上一步      步骤 2/3       下一步 ▶        │   │
  │  └─────────────────────────────────────────────────┘   │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量currentStep(0-3)跟踪当前步骤，updateScene()函数根据currentStep显示/隐藏对应元素
  2. 坐标计算：所有元素使用绝对坐标，箭头起点从物块中心(395,175)出发
  3. 动画曲线：元素显示使用opacity过渡(0.3s ease-in-out)
  4. 事件绑定：按钮点击事件调用prevStep()/nextStep()，更新currentStep后调用updateScene()
  5. 公式文本：步骤2和3在(500,200)和(500,250)位置动态显示公式SVG text元素
- ID 命名规范：所有交互元素ID以"scene2-"为前缀（如scene2-arc轨道、scene2-block物块、scene2-btn-prev按钮）
- IIFE 隔离：所有 JS 包在(function() { ... })()中，避免全局变量污染
