  - 物块显示在 S=1.0m 对应位置（x≈250）
  - 4 个能量条显示对应能量值（按比例填充）

  - 物块位置实时移动（x=150+(S-0.5)/1.5×400）
  - 4 个能量条长度实时更新（宽度=能量值/最大能量×180px）
  - 4 个速度数值实时更新
  - S 数值实时更新

- 临界状态（S≈1.32m，物块刚好到达 L 点）：
  - vL≈0（临界速度）
  - 所有能量条显示对应比例
  - 可高亮显示临界状态（物块边框变红）

[交互方案]
- 交互类型：连续拖拽滑块 — 选择理由：通过调节 S 值可以直观观察能量变化关系，帮助学生理解 S 与最终速度的函数关系
- 控件说明：
  - S 值滑块：位于底部 (150,450)-(750,450)，拖动范围对应 S=0.5m~2.0m
  - S 数值显示：滑块上方居中 (450,430)，实时显示当前 S 值
  - 能量条：右侧 4 个垂直排列的能量条，实时显示各能量值
  - 速度数值：4 个位置的速度值实时显示
- 教师操作流程：
  1. 初始展示 S=1.0m 时的能量状态
  2. 拖动滑块增大 S 值，观察物块起始位置右移，各能量值变化
  3. 继续拖动找到临界 S 值（约 1.32m），此时 vL≈0
  4. 继续增大 S 值，观察 vL>0，物块可越过 L 点
  5. 对比不同 S 值下的能量分配，讲解动能定理应用

- 关键实现要点：
  1. 状态机设计：单一状态变量 S（0.5~2.0），所有显示值由 S 计算得出
  2. 坐标计算：
     - 物块 x 坐标：x = 150 + (S - 0.5) / 1.5 × 400
     - 能量条宽度：width = energy / maxEnergy × 180
     - 速度计算：根据动能定理 W 电 - W 摩擦 - W 重力 = ΔEk
  3. 物理公式：
     - 电场力 F 电 = qE = 2×10^-4 × 10^3 = 0.2N
     - 摩擦力 f = μmg = 0.2 × 0.08 × 10 = 0.16N
     - 从 M 到 N：W 电 = F 电×S，W 摩擦 = f×S
     - 从 N 到 L：W 重力 = mg×2R，电场力不做功（垂直位移）
     - 临界条件：vL=0 时，Ek_N = mg×2R
  4. 动画曲线：滑块拖拽使用 requestAnimationFrame 平滑更新
  5. 事件绑定：mousedown/mousemove/mouseup 处理滑块拖拽
  6. ID 命名规范：所有元素 ID 以"scene3-"为前缀（如 scene3-block、scene3-slider、scene3-ek-bar）
  7. IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局污染

- 能量计算公式（用于实时更新）：
  - Ek_M = 0（从静止释放）
  - Ek_N = (F 电 - f) × S = (0.2 - 0.16) × S × 100 = 4S (J，S 单位 m)
  - Ep 电 (M) = 0（参考点），Ep 电 (N) = -F 电×S = -20S (J)
  - Ep 重 (N) = 0（参考点），Ep 重 (L) = mg×2R = 0.08×10×0.8 = 0.64J
  - Wf = f×S = 0.16×S×100 = 16S (J)
  - vN = sqrt(2×Ek_N / m)
  - vP = sqrt(2×(Ek_N - mgR) / m)
  - vL = sqrt(2×(Ek_N - mg×2R) / m)（若 Ek_N > mg×2R，否则 vL=0）

- 临界 S 值计算：
  - 临界条件：Ek_N = mg×2R = 0.64J
  - 4S = 0.64 → S = 0.16m（但需克服摩擦力，实际 S 需更大）
  - 重新计算：(F 电 - f)×S = mg×2R → 0.04×S×100 = 0.64 → S = 1.6m
  - 考虑电场力做功：F 电×S - f×S = mg×2R → 0.04×S×100 = 0.64 → S = 1.6m
