problem_206_physics_g12

场景导航：Scene 1

题目原文：

在光滑绝缘的水平面上，存在平行于水平面向右的匀强电场，电场强度为E．水平面上放置两个静止的小球A和B（均可看作质点），两小球质量均为m，A球带电荷量为+q，B球不带电，A、B连线与电场线平行．开始时两球相距L，在电场力作用下，A球开始运动（此时为计时零点，即t=0），后与B球发生对心碰撞，碰撞过程中A、B两球总动能无损失．设在各次碰撞过程中，A、B两球间无电量转移，且不考虑两球碰撞时间及两球间的万有引力．求：

（1）第一次碰撞结束瞬间A、B两球的速度各为多大？

（2）从计时零点到即将发生第三次碰撞这段过程中，共经过多长时间？

（3）从计时零点到即将发生第n次碰撞这段过程中，小球A经过的位移大小为多少？

题目分析：

本题是电场与力学综合题，核心知识点包括：

  1. 匀强电场中带电粒子的匀加速运动（a = qE/m）
  2. 弹性碰撞的速度交换规律（质量相等时）
  3. 多次碰撞过程的递推分析

整体讲解思路：

本题的关键在于理解每次碰撞后两球的运动状态变化，以及A球在电场力作用下的持续加速特性。由于两球质量相等且碰撞为弹性碰撞，每次碰撞都会发生速度交换。

图示规划说明：

规划一个综合图示，展示从初始状态到多次碰撞的完整过程。通过分步按钮导航，逐步展示：

  • 初始状态：A、B静止，相距L
  • 第一次碰撞前：A匀加速运动
  • 第一次碰撞后：速度交换，A静止，B匀速
  • 第二次碰撞：A再次追上B
  • 第n次碰撞的规律总结

图示将包含电场线、两球位置、速度矢量、位移标注等元素，帮助教师直观呈现物理过程。

教学说明：

本图示用于展示匀强电场中两球多次碰撞的完整物理过程。教师应按以下步骤引导学生观察：

第一步：初始状态分析
引导学生观察初始条件：A球带电+q，在电场力F=qE作用下将做匀加速运动；B球不带电，保持静止。两球相距L。

第二步：第一次碰撞前
讲解A球的运动学：

  • 加速度 a = qE/m
  • 运动距离 L 后碰撞
  • 碰撞前速度 v₁ = √(2aL) = √(2qEL/m)

第三步：第一次碰撞后
强调弹性碰撞的速度交换规律：

  • 两球质量相等
  • 碰撞后A静止，B以v₁匀速向右

第四步：第二次碰撞
关键分析点：

  • A从静止再次加速，B匀速
  • 设经过时间t₂相遇：½at₂² = v₁t₂
  • 解得 t₂ = 2v₁/a = 2√(2mL/qE)
  • 第二次碰撞前A的速度 v₂ = at₂ = 2v₁

第五步：规律总结
引导学生发现递推规律：

  • 第k次碰撞前，A的速度 vₖ = k·v₁
  • 第k次碰撞后，A静止，B以vₖ匀速
  • 第k+1次碰撞前，A再次加速追上B
  • 总位移 Sₙ = n²L

关键公式推导：

  1. 第一次碰撞前A的速度：

$$v_1 = \sqrt{2aL} = \sqrt{\frac{2qEL}{m}}$$

  1. 第一次碰撞后：
  • A的速度 v_A = 0
  • B的速度 v_B = v₁
  1. 第二次碰撞时间间隔：

$$\frac{1}{2}at_2^2 = v_1t_2 \Rightarrow t_2 = \frac{2v_1}{a} = 2\sqrt{\frac{2mL}{qE}}$$

  1. 第n次碰撞前A的总位移：

$$S_n = n^2L$$

讲解建议：

  • 每点击"下一步"，引导学生观察状态变化
  • 重点强调"速度交换"这一核心规律
  • 鼓励学生预测下一次碰撞的状态
  • 最后总结递推公式的物理意义

完整解答：

（1）第一次碰撞结束瞬间A、B两球的速度

A球在电场力作用下匀加速运动距离L：
$$a = \frac{qE}{m}$$
$$v_1 = \sqrt{2aL} = \sqrt{\frac{2qEL}{m}}$$

弹性碰撞，质量相等，速度交换：

  • 碰撞后A的速度：v_A = 0
  • 碰撞后B的速度：v_B = √(2qEL/m)

（2）从计时零点到即将发生第三次碰撞的时间

  • 第一次碰撞前时间：t₁ = √(2L/a) = √(2mL/qE)
  • 第一次碰撞后到第二次碰撞：t₂ = 2v₁/a = 2√(2mL/qE)
  • 第二次碰撞后到第三次碰撞：t₃ = 2v₂/a = 4√(2mL/qE)

总时间：
$$T = t_1 + t_2 + t_3 = \sqrt{\frac{2mL}{qE}} + 2\sqrt{\frac{2mL}{qE}} + 4\sqrt{\frac{2mL}{qE}} = 7\sqrt{\frac{2mL}{qE}}$$

（3）从计时零点到即将发生第n次碰撞，小球A的总位移

每次碰撞后A从静止开始加速，第k次碰撞前A的位移为：
$$s_k = (2k-1)L$$

总位移：
$$S_n = L + 3L + 5L + \cdots + (2n-1)L = n^2L$$

答案：

  • （1）vA = 0，vB = √(2qEL/m)
  • （2）T = 7√(2mL/qE)
  • （3）Sₙ = n²L

课堂讲解建议：

  1. 先让学生独立思考每次碰撞后的运动状态
  2. 通过图示逐步验证学生的猜想
  3. 强调"速度交换"是解题关键
  4. 引导学生发现位移的等差数列规律
  5. 最后总结递推公式，强化物理直觉
