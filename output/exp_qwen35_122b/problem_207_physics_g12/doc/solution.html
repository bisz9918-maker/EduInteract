场景导航：Scene 1 | Scene 2

题目原文：
如图所示，一倾角α=37°、长度为 9m 的固定斜面，其底端与长木板 B 上表面等高，原来 B 静止在粗糙水平地面上，左端与斜面接触但不粘连，斜面底端与木板 B 的上表面接触处圆滑，一可视为质点的小滑块 A 从斜面顶端处由静止开始下滑，最终 A 刚好未从木板 B 上滑下。已知 A、B 的质量相等，木板 B 的长度 L=3m，A 与斜面、B 上表面间的动摩擦因数均为μ₁=0.5，B 与地面的动摩擦因数为μ₂，重力加速度 g 取 10m/s²。
（1）通过计算分析当 A 滑上 B 的上表面后，B 是否仍保持静止；
（2）若 B 仍然静止，求出μ₂的最小值；若 B 滑动，求出μ₂的值。

题目分析：
本题是力学综合题，涉及斜面运动、水平面运动、摩擦力分析和牛顿运动定律。题目分为两个阶段：

  1. 滑块 A 沿斜面下滑阶段
  2. 滑块 A 在木板 B 上滑动阶段

整体讲解思路：
第一阶段需分析 A 在斜面上的受力，计算滑到底端时的速度；第二阶段需分析 A 滑上 B 后 A 和 B 的受力情况，判断 B 是否静止，进而求解μ₂。

图示规划说明：

  • Scene 1：斜面下滑过程，展示受力分析，计算末速度
  • Scene 2：水平面上 A 与 B 的相互作用，判断 B 的运动状态并求解μ₂
步骤 1/5

Scene 1 教学说明：

本图示用于讲解滑块 A 沿斜面下滑的物理过程。教师应引导学生按以下步骤理解：

  1. 受力分析：滑块 A 受三个力作用——重力 mg（竖直向下）、支持力 N₁（垂直斜面向上）、滑动摩擦力 f₁（沿斜面向上，与运动方向相反）
  1. 重力分解：将重力分解为平行斜面分量 mgsinα 和垂直斜面分量 mgcosα
  1. 支持力计算：垂直斜面方向受力平衡，N₁ = mgcosα
  1. 摩擦力计算：f₁ = μ₁N₁ = μ₁mgcosα
  1. 加速度计算：沿斜面方向应用牛顿第二定律
  • mgsinα - f₁ = ma₁
  • a₁ = g(sinα - μ₁cosα)
  • 代入数据：a₁ = 10×(sin37° - 0.5×cos37°) = 10×(0.6 - 0.5×0.8) = 10×0.2 = 2m/s²
  1. 底端速度计算：由运动学公式 v₁² = 2a₁s
  • v₁ = √(2×2×9) = √36 = 6m/s

关键要点：强调摩擦力方向与运动方向相反，加速度计算需考虑重力分量与摩擦力的合力。

步骤 1/5

Scene 2 教学说明：

本图示用于讲解滑块 A 滑上木板 B 后的相互作用，核心是判断 B 是否静止并求解μ₂。教师应引导学生按以下步骤推理：

  1. A 对 B 的摩擦力分析：
  • A 在 B 上向右滑动，B 对 A 的摩擦力 f_BA = μ₁mg（向左）
  • 根据牛顿第三定律，A 对 B 的摩擦力 f_AB = μ₁mg（向右）
  • f_AB = 0.5×m×10 = 5m（N）
  1. B 的受力分析：
  • 竖直方向：N₂ = mg（B 的重力）+ mg（A 的压力）= 2mg
  • 水平方向：f_AB（向右）与 f₂（地面对 B 的摩擦力，向左）
  1. 判断 B 是否静止：
  • 地面对 B 的最大静摩擦力 f_max = μ₂N₂ = μ₂×2mg
  • 若 fAB ≤ fmax，则 B 静止；若 fAB > fmax，则 B 滑动
  • 即：5m ≤ μ₂×2m×10 = 20μ₂m
  • 解得：μ₂ ≥ 0.25 时 B 静止
  1. 求解μ₂：
  • 题目条件"最终 A 刚好未从木板 B 上滑下"意味着 A 在 B 上滑行了 L=3m 后与 B 相对静止
  • 若 B 静止（μ₂ ≥ 0.25）：A 在 B 上做匀减速运动，a_A = -μ₁g = -5m/s²
  • 由 v² - v₁² = 2a_A L，得 0 - 36 = 2×(-5)×3 = -30，矛盾！
  • 因此 B 必须滑动，即μ₂ < 0.25
  1. B 滑动时的求解：
  • A 的加速度：a_A = -μ₁g = -5m/s²（向左）
  • B 的加速度：aB = (fAB - f₂)/m = (μ₁mg - μ₂×2mg)/m = 5 - 20μ₂（向右）
  • 相对加速度：a相对 = aA - a_B = -5 - (5 - 20μ₂) = -10 + 20μ₂
  • 相对位移 L = 3m，由 v相对² - v₁² = 2a相对 L
  • 0 - 36 = 2×(-10 + 20μ₂)×3
  • -36 = -60 + 120μ₂
  • μ₂ = 24/120 = 0.2

关键要点：

  • 强调牛顿第三定律在摩擦力分析中的应用
  • 判断 B 是否静止需比较驱动力与最大静摩擦力
  • "刚好未滑下"意味着相对位移等于木板长度，相对末速度为 0
  • 通过反证法判断 B 必须滑动，再求解μ₂
