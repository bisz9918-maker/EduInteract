[图示主题与整合说明]
- 本图示主题：离子在电场中的偏转——撤去磁场后的类平抛运动
- 整合内容：仅存在电场时的离子运动轨迹、偏转过程中的速度分解、射出电场时的速度方向（30°角）、偏转位移与板长的关系
- 教学价值：教师可逐步展示离子在电场中的偏转过程，帮助学生理解类平抛运动的轨迹特征、速度分解原理以及偏转角与速度分量的几何关系

[标签冲突检查]
- 标签"+"：坐标 (400,65)
- 标签"-"：坐标 (400,155)
- 标签"v"：坐标 (140,95)
- 标签"E"：坐标 (230,110)
- 标签"v_x=v"：坐标 (690,145)
- 标签"v_y"：坐标 (745,150)
- 标签"v'"：坐标 (740,165)
- 标签"θ=30°"：坐标 (680,145)

冲突检查：
- "+"与"-"：垂直距离 90px → 无冲突
- "v"与"E"：水平距离 90px，垂直距离 15px → 无冲突
- "v_x=v"与"θ=30°"：水平距离 10px，垂直距离 0px → 潜在冲突！解决方案：将"θ=30°"上移至 (680,135)
- "v_y"与"v'"：水平距离 5px，垂直距离 15px → 无冲突
- "θ=30°"调整后 (680,135) 与"v_x=v"(690,145)：水平距离 10px，垂直距离 10px，间距约 14px → 仍偏近，将"v_x=v"下移至 (690,150)

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形和动画，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    图示区 800×500                       │
  │                                                         │
  │    +                                                  │
  │  ┌──────────────────────────────────────────┐         │
  │  │              上金属板                     │         │
  │  └──────────────────────────────────────────┘         │
  │         ~ 电场 E ↓ ~                                  │
  │    v → ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~     │
  │         ~ 电场 E ↓ ~        偏转轨迹（抛物线）         │
  │  ┌──────────────────────────────────────────┐         │
  │  │              下金属板                     │         │
  │  └──────────────────────────────────────────┘         │
  │                              ● → v' (30°)              │
  │                              │                         │
  │                              ↓ v_y                     │
  │                        v_x ←─┘                         │
  │                                                         │
  │  ┌─────────────────────────────────────────────────┐   │
  │  │        ◀上一步    步骤 1/5    下一步▶            │   │
  │  └─────────────────────────────────────────────────┘   │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-4) 跟踪当前步骤，每一步定义需要显示/隐藏的元素 ID 列表
  2. 坐标计算：抛物线轨迹使用二次贝塞尔曲线，起点 (150,105)，控制点 (400,105)，终点 (650,130)
  3. 速度矢量角度：射出速度与水平成 30°，矢量终点计算：x = 650 + 80×cos(30°), y = 130 + 80×sin(30°)
  4. 事件绑定：按钮点击事件更新 currentStep，调用 updateScene() 函数刷新显示
  5. ID 命名规范：所有元素 ID 以 scene2- 为前缀（如 scene2-plate-top、scene2-trajectory、scene2-btn-next 等）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染
  7. 元素显示控制：使用 style.display = 'none' / 'block' 或 opacity 控制元素可见性
