[图示主题与整合说明]
- 本图示主题：正三角形匀速穿过正方形过程中重叠面积S随时间t的变化规律

[分步序列]
步骤0（初始状态）：
- 三角形位置：右顶点在x=150（正方形左边界x=180左侧30px）
- 重叠面积：S=0
- S-t图像：仅显示原点(0,0)
- 阶段指示器显示："阶段0：初始位置"

步骤1（开始进入）：
- 三角形位置：右顶点接触正方形左边界x=180
- 重叠面积：S=0（刚接触）
- S-t图像：显示点(1,0)，t=1单位
- 阶段指示器显示："阶段1：开始进入"

步骤2（部分进入）：
- 三角形位置：右顶点在x=240（正方形中心）
- 重叠面积：S=√3/8≈0.22（小三角形面积）
- S-t图像：曲线从(1,0)上升到(3,0.22)，抛物线上升段
- 阶段指示器显示："阶段2：部分进入"

步骤3（完全重叠）：
- 三角形位置：完全在正方形内部，中心对齐
- 重叠面积：S=√3/4≈0.43（三角形最大面积）
- S-t图像：曲线从(3,0.22)上升到(5,0.43)，然后水平到(7,0.43)
- 阶段指示器显示："阶段3：完全重叠"

步骤4（开始离开）：
- 三角形位置：左顶点到达正方形右边界x=300
- 重叠面积：S=√3/4≈0.43（保持最大）
- S-t图像：曲线水平段结束，开始下降
- 阶段指示器显示："阶段4：开始离开"

步骤5（部分离开）：
- 三角形位置：左顶点在x=360（正方形右边界右侧60px）
- 重叠面积：S=√3/8≈0.22（对称于进入阶段）
- S-t图像：曲线从(7,0.43)下降到(9,0.22)，抛物线下降段
- 阶段指示器显示："阶段5：部分离开"

步骤6（完全离开）：
- 三角形位置：左顶点在x=420（正方形右边界右侧120px）
- 重叠面积：S=0
- S-t图像：曲线从(9,0.22)下降到(11,0)
- 阶段指示器显示："阶段6：完全离开"

[交互方案]

  - 上一步按钮：id="scene1-prev-btn"，位置(220,450)，点击后阶段减1（阶段0时禁用）

  4. 可点击"上一步"回退复习某个阶段

- 关键实现要点：
  1. 状态机设计：用变量currentStage(0-6)跟踪当前阶段，每个阶段对应三角形x坐标和重叠面积S
  2. 坐标计算：
     - 三角形底边长120px，高=120×√3/2≈104px
     - 阶段0-6的三角形右顶点x坐标：[150, 180, 240, 300, 360, 420, 480]
     - 重叠面积S计算：根据三角形与正方形交集的几何形状分段计算
  3. S-t曲线绘制：用polyline元素，根据当前阶段动态更新points属性
  4. 动画曲线：阶段2和阶段5的S-t曲线为抛物线段（二次函数），阶段3-4为水平线段
  5. 事件绑定：按钮点击事件更新currentStage，触发重绘
  6. ID命名规范：所有元素ID以"scene1-"为前缀（如scene1-triangle, scene1-square, scene1-curve等）
  7. IIFE隔离：所有JS代码包裹在(function() { ... })()中，避免全局污染

- 重叠面积计算公式：
  - 阶段0-1：S=0（无重叠）
  - 阶段2：S = (x-180)² × √3 / 144，其中x为三角形右顶点坐标，180≤x≤240
  - 阶段3：S = √3/4 ≈ 0.43（完全重叠）
  - 阶段4：S = √3/4 ≈ 0.43（保持最大）
  - 阶段5：S = (420-x)² × √3 / 144，其中x为三角形右顶点坐标，360≤x≤420
  - 阶段6：S=0（完全离开）

- 初始状态：图示加载后显示阶段0（三角形在正方形左侧，无重叠），等待教师点击"下一步"触发交互
