[分步序列]
- 步骤0（初始状态）：显示所有线段（AB/AC/BC/DE/DF/EF）和所有顶点标签（A/B/C/D/E/F），无高亮
- 步骤1：高亮△ABC（大三角形），蓝色边框加粗，内部填充20%透明度，其他元素保持原样
- 步骤2：取消△ABC高亮，高亮△ADE（顶部小三角形），蓝色边框加粗，内部填充20%透明度
- 步骤3：取消△ADE高亮，高亮△BDF（左下角小三角形），蓝色边框加粗，内部填充20%透明度
- 步骤4：取消△BDF高亮，高亮△CEF（右下角小三角形），蓝色边框加粗，内部填充20%透明度
- 步骤5：取消△CEF高亮，高亮△DEF（中间小三角形），蓝色边框加粗，内部填充20%透明度
- 步骤6（结论）：所有5个三角形同时高亮（使用红高亮#c62828），显示计数结果文字"共5个三角形"（绿色#2e7d32）

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 按钮"scene1-btn-prev"：位置(280,450)，作用：返回上一步，步骤0时禁用
  - 按钮"scene1-btn-next"：位置(420,450)，作用：进入下一步，步骤6时改为"完成"并禁用
- 教师操作流程：
  1. 初始展示完整图形，让学生观察整体结构
  2. 点击"下一步"逐一高亮每个三角形，引导学生跟随计数
  3. 可点击"上一步"回退复习某个三角形
  4. 最终步骤展示所有三角形同时高亮并显示总数，强化记忆

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    [图示区 800×500]                     │
  │                                                         │
  │                    A(400,80)                            │
  │                   /   \                                 │
  │                  /     \                                │
  │             D(300,230) E(500,230)                       │
  │              /    △     \                               │
  │             /    /   \   \                              │
  │            /    /       \  \                            │
  │      B(200,380)---F(400,380)---C(600,380)              │
  │                                                         │
  │           [◀ 上一步]      [下一步 ▶]                    │
  │              (280,450)      (420,450)                   │
  │                                                         │
  │              共5个三角形 (步骤6显示)                     │
  │                    (350,450)                            │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-6) 跟踪当前步骤
  2. 坐标计算：所有顶点坐标预先计算并存储为常量
  3. 高亮实现：每个三角形对应一个 SVG path 元素，通过 class 切换高亮样式
  4. 动画曲线：高亮切换使用 CSS transition (0.3s ease)
  5. 事件绑定：按钮点击事件更新 currentStep 并调用 updateDisplay() 刷新视图
  6. 按钮状态：步骤0时禁用"上一步"，步骤6时禁用"下一步"
- ID 命名规范：所有交互元素 ID 以 scene1- 为前缀（如 scene1-tri-abc, scene1-btn-prev, scene1-btn-next）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局污染
