[图示主题与整合说明]
- 本图示主题：自行车链条长度规律探究
- 整合内容：整合了 1 节→2 节→3 节→n 节→100 节的完整推导过程，通过递进式展示帮助学生理解重叠规律并推导通用公式
- 教学价值：教师可通过分步演示，引导学生从具体案例（1 节、2 节、3 节）观察规律，逐步抽象出通用公式，最后代入 n=100 得出答案。适合用于"找规律"类数学问题的教学，培养学生从特殊到一般的归纳思维能力。

[视觉元素清单]

[分步序列]
步骤 0（初始状态）：
- 显示：1 节链条轮廓（280,150)-(380,220)，两端半圆圆心 (280,185) 和 (380,185)
- 标注：上方尺寸线 (280,120)-(380,120)，标签"2.5cm"在 (330,110)
- 下方标签："1 节"在 (330,250)
- 公式区：显示"1 节链条长度 = 2.5cm"
- 按钮：「下一步 ▶」可用，「◀ 上一步」禁用（灰色）

步骤 1：
- 显示：2 节链条轮廓（200,150)-(460,220)，新增第 2 节链节
- 高亮：连接圆 (360,185) 用#1565c0 蓝色半透明填充，标注"0.8cm"在 (352,110)
- 下方标签："2 节"在 (330,250)
- 公式区：显示"2 节链条长度 = 2.5 + 2.5 - 0.8 = 4.2cm"
- 按钮：「◀ 上一步」和「下一步 ▶」均可用

步骤 2：
- 显示：3 节链条轮廓（150,150)-(510,220)，新增第 3 节链节
- 高亮：新增连接圆 (420,185) 用#1565c0 蓝色半透明填充
- 下方标签："3 节"在 (330,250)
- 公式区：显示"3 节链条长度 = 2.5×3 - 0.8×2 = 5.9cm"
- 按钮：「◀ 上一步」和「下一步 ▶」均可用

步骤 3：
- 显示：n 节链条轮廓（100,150)-(560,220)，中间用省略号"..."表示

- 按钮：「◀ 上一步」可用，「下一步 ▶」禁用（灰色）

[标签冲突检查]

- 公式文本区：(100,300)-(700,400)
- 与链条底部间距：300-220=80px → 无冲突

- 按钮区域：(150,440)-(320,480) 和 (480,440)-(650,480)
- 与公式区底部间距：440-400=40px → 无冲突

- 尺寸标注线与链条顶部间距：120-150=-30px（标注线在链条上方 30px）→ 无冲突

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位置 (150,440)-(320,480)，点击返回上一状态，第一步时禁用
  - 「下一步 ▶」按钮：位置 (480,440)-(650,480)，点击进入下一状态，最后一步时禁用
- 教师操作流程：
  1. 初始展示 1 节链条，讲解单节长度 2.5cm
  2. 点击「下一步」，展示 2 节链条，高亮重叠区域 0.8cm，讲解"为什么不是 2.5×2"
  3. 点击「下一步」，展示 3 节链条，引导学生观察规律（每增加 1 节，增加 2.5-0.8=1.7cm）
  4. 点击「下一步」，抽象为 n 节，推导通用公式 1.7n+0.8
  5. 点击「下一步」，代入 n=100，得出答案 170.8cm，选择 C
  6. 可随时点击「上一步」回退复习关键步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    800×500 画布                         │
  │                                                         │
  │   尺寸标注线（2.5cm、0.8cm）                            │
  │         ↑          ↑                                    │
  │   ┌─────────────────────────────────────────────┐       │
  │   │         链条图形展示区（y=120~250）          │       │
  │   │         1 节 / 2 节 / 3 节 / n 节 / 100 节      │       │
  │   └─────────────────────────────────────────────┘       │
  │                                                         │
  │         公式/计算展示区（y=300~400）                    │
  │         "2.5n - 0.8(n-1) = 1.7n + 0.8"                 │
  │                                                         │
  │   ┌───────────────┐               ┌───────────────┐    │
  │   │ ◀ 上一步      │               │    下一步 ▶   │    │
  │   │ (y=440~480)   │               │ (y=440~480)   │    │
  │   └───────────────┘               └───────────────┘    │
  └─────────────────────────────────────────────────────────┘
  ```

- 关键实现要点：
  1. 状态机设计：用变量 currentStep（0-4）记录当前步骤，updateScene() 函数根据 currentStep 更新显示内容
  2. 坐标计算：链条水平居中，根据节数动态计算总宽度。单节宽度 100px，每增加一节增加 80px（2.5-0.8=1.7cm 对应 80px 缩放）
  3. 动画曲线：元素出现/消失使用 opacity 过渡（0.3s ease）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateScene()
  5. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-chain-1、scene1-btn-prev、scene1-formula）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染

- SVG 元素 ID 命名示例：
  - scene1-chain-1：1 节链条路径
  - scene1-chain-2：2 节链条路径
  - scene1-chain-3：3 节链条路径
  - scene1-chain-n：n 节链条路径
  - scene1-chain-100：100 节链条路径
  - scene1-connector-1：第 1 个连接圆
  - scene1-connector-2：第 2 个连接圆
  - scene1-connector-3：第 3 个连接圆
  - scene1-label-count：节数标签
  - scene1-formula-text：公式文本
  - scene1-btn-prev：上一步按钮
  - scene1-btn-next：下一步按钮
  - scene1-dimension-2.5：2.5cm 尺寸标注
  - scene1-dimension-0.8：0.8cm 尺寸标注

- 公式文本动态更新逻辑：
  ```javascript
  const formulas = [
    "1 节链条长度 = 2.5cm",
    "2 节链条长度 = 2.5 + 2.5 - 0.8 = 4.2cm",
    "3 节链条长度 = 2.5×3 - 0.8×2 = 5.9cm",
    "n 节链条长度 = 2.5n - 0.8(n-1) = 1.7n + 0.8",
    "当 n=100 时，总长度 = 1.7×100 + 0.8 = 170.8cm\n故选 C"
  ];
  ```
