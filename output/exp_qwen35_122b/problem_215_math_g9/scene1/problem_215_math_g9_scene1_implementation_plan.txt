- 画布尺寸：800 × 500 px

- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-4) 跟踪当前步骤，updateScene() 函数根据 currentStep 显示/隐藏对应元素
  2. 坐标计算：所有元素坐标硬编码在配置对象中，便于维护和修改
  3. 动画曲线：使用 CSS transition 实现淡入淡出效果（opacity: 0→1，duration: 0.3s）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateScene()
  5. 直角符号绘制：用 SVG 路径绘制 L 形，根据垂线段方向调整旋转角度
  6. 角度弧线：用 SVG path 绘制圆弧，计算起始角和结束角
  7. 三角形填充：用 SVG polygon 元素，设置 fill-opacity

- ID 命名规范：
  - 所有交互元素 ID 以 scene1- 为前缀
  - 示例：scene1-square、scene1-line-a、scene1-de-seg、scene1-bf-seg、scene1-vert-e、scene1-vert-f、scene1-label-de、scene1-label-bf、scene1-arc-dae、scene1-arc-baf、scene1-tri-ade、scene1-tri-baf、scene1-label-ae、scene1-label-af、scene1-seg-ef、scene1-label-ef、scene1-prev-btn、scene1-next-btn

- IIFE 隔离：
  ```javascript
  (function() {
      // 所有代码包在此 IIFE 中
      const currentStep = 0;
      const maxStep = 4;
      
      function updateScene() {
          // 根据 currentStep 显示/隐藏元素
      }
      
      document.getElementById('scene1-prev-btn').addEventListener('click', () => {
          if (currentStep > 0) {
              currentStep--;
              updateScene();
          }
      });
      
      document.getElementById('scene1-next-btn').addEventListener('click', () => {
          if (currentStep < maxStep) {
              currentStep++;
              updateScene();
          }
      });
  })();
  ```
