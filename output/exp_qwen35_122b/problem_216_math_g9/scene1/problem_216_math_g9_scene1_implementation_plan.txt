[分步序列]
步骤0（初始状态）：
- 显示：x轴、y轴、抛物线、原点O、刻度-1、刻度1、刻度3、x轴标签、y轴标签
- 隐藏：对称轴、所有交点标记、所有交点坐标标签、方程标签
- 目的：展示基础抛物线图像，让学生观察整体形态

步骤1（标注对称轴）：
- 新增：对称轴虚线(400,80)-(400,400)、对称轴标签"x=1"(410,100)
- 显示：对称轴为灰色虚线，强调其辅助线性质
- 目的：引导学生关注对称轴位置，理解对称轴x=1的含义

步骤2（标注已知交点）：
- 新增：点(-1,0)蓝色圆点、点(0,3)蓝色圆点
- 新增标签："(-1, 0)"在(200,335)、"(0, 3)"在(280,145)
- 新增：方程标签"y=ax²+bx+c"(520,120)
- 目的：明确已知条件，标注与x轴、y轴的交点坐标

步骤3（利用对称性求另一交点）：
- 新增：点(3,0)红色圆点（区别于已知点，表示推导得出）
- 新增标签："(3, 0)"在(550,335)
- 动画效果：可从对称轴虚线向两侧延伸示意对称关系
- 目的：展示利用对称性x=1，由(-1,0)推导(3,0)的过程

步骤4（完整标注）：
- 显示：所有元素（对称轴、三个交点、所有标签、方程）
- 高亮：对称轴与x轴交点(400,320)可短暂闪烁强调
- 目的：完整呈现抛物线关键特征，为后续分析结论做准备

[标签冲突检查]
逐一检查所有标签坐标间距：

- 标签"O"：坐标(305,340)
- 标签"(-1, 0)"：坐标(200,335)
- 标签"(0, 3)"：坐标(280,145)
- 标签"(3, 0)"：坐标(550,335)
- 标签"x=1"：坐标(410,100)
- 标签"x"：坐标(680,305)
- 标签"y"：坐标(305,95)
- 标签"-1"：坐标(230,340)
- 标签"1"：坐标(390,340)
- 标签"3"：坐标(295,155)
- 标签"y=ax²+bx+c"：坐标(520,120)

冲突检查：
1. "O"(305,340)与"-1"(230,340)：水平距离75px → 无冲突
2. "O"(305,340)与"(-1, 0)"(200,335)：距离约105px → 无冲突
3. "(-1, 0)"(200,335)与"-1"(230,340)：距离约30px → 无冲突（标签与刻度可接受）
4. "(0, 3)"(280,145)与"3"(295,155)：距离约18px → 接近但可接受（坐标标签与刻度紧邻）
5. "(0, 3)"(280,145)与"y"(305,95)：距离约55px → 无冲突
6. "x=1"(410,100)与"y"(305,95)：距离约105px → 无冲突
7. "x=1"(410,100)与"y=ax²+bx+c"(520,120)：距离约115px → 无冲突
8. "1"(390,340)与"O"(305,340)：距离85px → 无冲突
9. "(3, 0)"(550,335)与"1"(390,340)：距离160px → 无冲突
10. "x"(680,305)与"(3, 0)"(550,335)：距离约135px → 无冲突

结论：所有标签间距均≥18px，无重叠冲突。"(0, 3)"与刻度"3"距离较近但属于合理标注关系。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮：id="scene1-prev-btn"，位置(280,455)，作用：返回上一状态，步骤0时禁用
  - 下一步按钮：id="scene1-next-btn"，位置(460,455)，作用：进入下一状态，步骤4时禁用
- 教师操作流程：
  1. 初始展示抛物线图像，让学生观察整体形态
  2. 点击"下一步"，标注对称轴x=1，讲解对称轴概念
  3. 点击"下一步"，标注已知交点(-1,0)和(0,3)，明确题目条件
  4. 点击"下一步"，展示利用对称性推导(3,0)的过程，强调对称性应用
  5. 点击"下一步"，完整呈现所有标注，引导学生总结抛物线特征
  6. 可随时点击"上一步"回退复习关键步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（线段、曲线、圆点），原生SVG足以实现，无需引入大型库
  - 抛物线用<path>的二次贝塞尔曲线或分段line近似

- 画布尺寸：800 × 500 px

- 关键实现要点：
  1. 状态机设计：用变量currentStep(0-4)跟踪当前步骤，updateScene()函数根据currentStep显示/隐藏对应元素
  2. 坐标计算：建立单位坐标到像素坐标的映射函数：
     - pixelX = 320 + unitX * 80
     - pixelY = 320 - unitY * 80
  3. 抛物线绘制：用<path>的二次贝塞尔曲线，或分段line近似，顶点(1,4)→(400,80)
  4. 元素显示/隐藏：用CSS display或opacity控制，避免重新渲染
  5. 按钮状态：步骤0时prev-btn disabled，步骤4时next-btn disabled
  6. 事件绑定：按钮click事件触发updateScene()，更新currentStep后重绘

- ID 命名规范：
  - 所有交互元素ID以"scene1-"为前缀
  - 示例：scene1-axis-x、scene1-axis-y、scene1-parabola、scene1-sym-line、scene1-point-a、scene1-point-b、scene1-point-c、scene1-label-sym、scene1-label-a、scene1-label-b、scene1-label-c、scene1-prev-btn、scene1-next-btn
  - JS中使用getElementById获取元素，避免querySelectorAll配合全局class导致多场景污染

- IIFE 隔离：
  所有JS代码包裹在(function() { ... })()中，避免全局变量污染
  示例：
  ```javascript
  (function() {
      const currentStep = 0;
      function updateScene() { ... }
      document.getElementById('scene1-prev-btn').addEventListener('click', ...);
  })();
  ```
