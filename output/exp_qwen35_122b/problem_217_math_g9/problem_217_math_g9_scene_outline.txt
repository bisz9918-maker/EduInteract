    **题目原文：**
    如图，二次函数$y=x^2-2x-3$的图像与$x$轴交于$A,B$两点，与$y$轴交于点$C$，下列说法：① $AB=4$；② $\angle ABC=45^\circ$；③ 当$0<x<2$时，$-4\le y<-3$；④ 当$x>1$时，$y$随$x$的增大而增大，其中结论正确的个数有（ ）

    A．1个  B．2个  C．3个  D．4个

    **题目分析：**
    本题考察二次函数图像的基本性质，包括：
    1. 求抛物线与坐标轴的交点坐标
    2. 计算线段长度
    3. 判断角度大小
    4. 分析函数值在给定区间内的取值范围
    5. 判断函数的单调性

    **整体讲解思路：**
    首先引导学生从函数解析式出发，求出 A、B、C 三点的坐标，这是解题的基础。然后逐一验证四个结论：
    - 结论①：通过求根公式得到 A、B 坐标，计算距离
    - 结论②：利用坐标计算三角形边长，判断角度
    - 结论③：找到顶点坐标，分析区间内的函数值范围
    - 结论④：确定对称轴，判断单调性

    **图示规划说明：**
    本教案规划 2 个图示：
    - Scene 1：抛物线与坐标轴交点及结论①④验证（整合交点求解与单调性判断）
    - Scene 2：角度验证与函数值范围分析（整合结论②③验证）

    **教学说明：**

    本图示用于讲解结论①和④的验证过程。

    **步骤 0：基础抛物线**
    教师首先展示抛物线 y = x² - 2x - 3 的基本图像，引导学生观察开口方向（向上）和大致位置。

    **步骤 1：标注交点坐标**
    1. 求与 x 轴交点：令 y = 0，解方程 x² - 2x - 3 = 0
    2. 因式分解：(x - 3)(x + 1) = 0
    3. 得到 x₁ = -1，x₂ = 3，故 A(-1, 0)，B(3, 0)
    4. 求与 y 轴交点：令 x = 0，得 y = -3，故 C(0, -3)

    **步骤 2：验证结论① AB = 4**
    AB = |x_B - x_A| = |3 - (-1)| = 4，结论①正确。

    **步骤 3：验证结论④单调性**
    1. 对称轴公式：x = -b/(2a) = 2/(2×1) = 1
    2. 抛物线开口向上，对称轴右侧（x > 1）函数单调递增
    3. 结论④正确。

    **引导学生观察：**
    - 对称轴恰好是 A、B 两点横坐标的中点
    - x > 1 区域图像呈上升趋势

    **教学说明：**

    本图示用于讲解结论②和③的验证过程。

    **步骤 0-1：验证结论② ∠ABC = 45°**
    1. 连接 BC，观察△OBC
    2. OB = 3（B 点横坐标绝对值）
    3. OC = 3（C 点纵坐标绝对值）
    4. △OBC 为等腰直角三角形，∠OBC = 45°
    5. 由于 A、O、B 共线，∠ABC = ∠OBC = 45°
    6. 结论②正确。

    **步骤 2-4：验证结论③ 函数值范围**
    1. 顶点坐标：x = 1 时，y = 1² - 2×1 - 3 = -4，顶点 V(1, -4)
    2. 区间 0 < x < 2 包含顶点 x = 1
    3. 当 x = 0 时，y = -3；当 x = 2 时，y = 2² - 2×2 - 3 = -3
    4. 在区间 (0, 2) 内，函数最小值为 -4（顶点处），最大值趋近于 -3（端点处）
    5. 故 -4 ≤ y < -3，结论③正确。

    **完整解答：**
    四个结论全部正确，答案选 D（4 个）。

    **课堂讲解建议：**
    1. 强调数形结合思想：从图像直观判断，再用代数方法验证
    2. 提醒学生注意等腰直角三角形的判定条件（两直角边相等）
    3. 对于函数值范围问题，要特别关注区间是否包含顶点
    4. 总结二次函数图像分析的常见考点：交点、对称轴、单调性、最值
