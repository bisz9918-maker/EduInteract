[图示主题与整合说明]
- 本图示主题：二次函数 y = x² - 2x - 3 的图像与坐标轴交点及单调性分析
- 整合内容：抛物线绘制、A/B/C 三点坐标标注、AB 距离计算、对称轴与单调性展示
- 教学价值：教师可逐步引导学生理解二次函数图像特征，包括与坐标轴交点求法、对称轴位置、单调区间判断，帮助学生验证四个结论的正确性

[分步序列]
步骤 0（初始状态）：
- 显示：坐标系（x 轴、y 轴）、完整抛物线 y=x²-2x-3
- 不显示：点 A/B/C、对称轴、AB 线段、区域填充、所有坐标标签
- 目的：展示基础函数图像

步骤 1：
- 新增：点 A、B、C（红色圆点）、原点 O
- 新增标签：A(-1,0)、B(3,0)、C(0,-3)、O
- 目的：标注与坐标轴的交点

步骤 2：
- 新增：AB 线段（蓝色粗线）、标签"AB=4"
- 显示计算过程：AB = |3 - (-1)| = 4
- 目的：验证结论① AB=4 正确

步骤 3：
- 新增：对称轴 x=1（灰色虚线）、标签"x=1"
- 新增：x>1 区域绿色半透明填充
- 目的：展示对称轴位置及单调递增区间

步骤 4（结论）：
- 高亮显示：结论①正确（绿色）、结论④正确（绿色）
- 显示总结："正确结论：① AB=4；④ x>1 时 y 随 x 增大而增大"
- 显示答案："答案：D（4 个结论中有 2 个正确）"
- 目的：总结验证结果

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件位置：SVG 内底部 y=440~490 区域，居中放置
- 控件说明：
  - 按钮"◀上一步"：位置 (280,460)，返回上一步骤
  - 按钮"下一步▶"：位置 (500,460)，进入下一步骤
  - 步骤指示器：位置 (380,430)，显示"步骤 1/5"
- 教师操作流程：
  1. 初始展示抛物线图像，引导学生观察函数特征
  2. 点击"下一步"标注交点 A、B、C，讲解交点求法
  3. 点击"下一步"显示 AB 长度，验证结论①
  4. 点击"下一步"显示对称轴和单调区间，验证结论④
  5. 点击"下一步"展示最终结论，总结答案

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何绘图，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    800px 宽度                          │
  │  ┌───────────────────────────────────────────────────┐  │
  │  │                                                   │  │
  │  │              抛物线图像区                         │  │
  │  │              (坐标系 + 曲线)                      │  │
  │  │              500px 高度                          │  │
  │  │                                                   │  │
  │  │              [点 A]    [对称轴]    [点 B]         │  │
  │  │                  \        |        /             │  │
  │  │                   \       |       /              │  │
  │  │                    \      |      /               │  │
  │  │                     [C]   |                    │  │
  │  │                                                   │  │
  │  │              [步骤指示器：步骤 1/5]               │  │
  │  │              [◀上一步]  [下一步▶]                │  │
  │  └───────────────────────────────────────────────────┘  │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：currentStep 变量 (0-4)，控制各元素显示/隐藏
  2. 坐标计算：使用映射函数 coordX(x) = 170 + x*85，coordY(y) = 250 - y*50
  3. 抛物线绘制：生成 x∈[-1.5,5] 的点序列，计算 y=x²-2x-3，用 polyline 连接
  4. 动画曲线：元素出现使用 opacity 过渡 (0→1，duration 300ms)
  5. 事件绑定：按钮点击更新 currentStep，重新渲染可见元素
  6. ID 命名规范：所有元素 ID 以"scene1-"为前缀（如 scene1-para、scene1-pointA、scene1-btnNext）
  7. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  8. 步骤控制：使用 display 或 opacity 控制元素可见性，步骤 0-4 共 5 个状态
