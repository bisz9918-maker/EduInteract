[图示主题与整合说明]
- 本图示主题：两个直角三角板（等腰直角三角形ABC与含30°角直角三角形DEF）的摆放关系
- 整合内容：等腰直角三角形ABC的结构（∠A=90°，AB=AC）、含30°角直角三角形DEF的结构（∠EDF=90°，∠E=30°）、两三角板的位置关系（点C在EF上、A-D-C共线、∠BCE=40°）
- 教学价值：教师可逐步展示两个三角板的独立属性及组合关系，引导学生理解角度计算逻辑，最终求解∠CDF

[分步序列]
步骤0（初始状态）：
- 显示：△ABC轮廓（黑线）、△DEF轮廓（黑线）、所有顶点字母A/B/C/D/E/F
- 不显示：所有角度标记、所有数值标签、所有高亮颜色
- 目的：展示两个三角板的基本结构和位置关系

步骤1（标注△ABC条件）：
- 新增：∠A=90°直角标记（蓝高亮）、90°数值标签（A点左下方）、AB=AC等长标记（蓝高亮）
- 高亮：△ABC边框变为蓝高亮 #1565c0
- 目的：明确等腰直角三角形ABC的已知条件

步骤2（标注△DEF条件）：
- 新增：∠EDF=90°直角标记（红高亮）、90°数值标签（D点左下方）、∠E=30°弧线（红高亮）、30°数值标签
- 高亮：△DEF边框变为红高亮 #c62828
- 目的：明确含30°角直角三角形DEF的已知条件

步骤3（标注位置关系）：
- 新增：∠BCE=40°弧线（绿高亮）、40°数值标签（C点左上方）
- 高亮：点C和线段BC、CE变为绿高亮 #2e7d32
- 目的：明确两三角板的位置关系和已知角度

步骤4（高亮待求角）：
- 新增：∠CDF待求弧线（绿高亮）、"?"标签（D点右侧）
- 高亮：线段CD、DF变为绿高亮 #2e7d32
- 目的：明确待求目标，引导学生进行角度计算

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：位置(280,455)，作用：返回上一状态，若无上一步则禁用
  - "下一步 ▶"按钮：位置(500,455)，作用：进入下一状态，若无下一步则禁用
  - 步骤指示器：位置(380,455)，显示"步骤 k/4"
- 教师操作流程：
  1. 初始展示两个三角板轮廓，让学生观察基本结构
  2. 点击"下一步"逐步标注△ABC的等腰直角条件
  3. 继续点击"下一步"标注△DEF的30°直角条件
  4. 继续点击"下一步"标注两三角板位置关系和∠BCE=40°
  5. 最后点击"下一步"高亮待求角∠CDF，引导学生计算
  6. 可随时点击"上一步"回退复习已讲解内容

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    图示区 800×500                       │
  │                                                         │
  │           A                                            │
  │          /│\                                           │
  │         / │ \              D                           │
  │        B  │  \            /│\                          │
  │           │   \          / │ \                         │
  │           │    \        /  │  \                        │
  │           │     \      /   │   \                       │
  │           │      \    /    │    \                      │
  │           │       \  /     │     \                     │
  │           │        \/      C──────F                    │
  │           │        /\             │                    │
  │           │       /  \            │                    │
  │          E───────/────\───────────┘                     │
  │                                                         │
  │  ┌─────────────────────────────────────────────────┐   │
  │  │  ◀ 上一步    步骤 k/4    下一步 ▶               │   │
  │  └─────────────────────────────────────────────────┘   │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：currentStep 变量（0-4），每一步对应一个状态对象，存储该步骤应显示的元素ID列表
  2. 坐标计算：所有元素使用绝对坐标，通过 SVG 的 x/y/cx/cy 属性精确控制
  3. 动画曲线：使用 CSS transition 实现淡入淡出效果（opacity: 0→1）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 renderStep() 刷新显示
  5. ID 命名规范：所有元素 ID 以 "scene1-" 为前缀（如 scene1-tri-abc、scene1-ang-a、scene1-btn-prev）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 角度弧线绘制：使用 SVG path 的 arc 命令，根据圆心和半径计算起点终点坐标
  8. 直角标记绘制：使用 SVG path 绘制小正方形角标（如 M 460,150 L 472,150 L 472,162）
