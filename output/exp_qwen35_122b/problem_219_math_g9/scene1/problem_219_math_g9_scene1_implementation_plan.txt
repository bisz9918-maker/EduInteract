[图示主题与整合说明]
- 本图示主题：反比例函数图像上两点构成的梯形与三角形面积关系
- 整合内容：①反比例函数曲线与点 A、B 的位置关系；②垂线构造梯形 ABCD；③连接 OA、OB 形成△OAB；④面积公式推导与比值结论
- 教学价值：教师可通过分步演示，引导学生理解反比例函数图像上任意两点与原点构成的三角形面积，与这两点到 y 轴垂线构成的梯形面积之间的等量关系（S₁:S₂ = 1:1），帮助学生掌握反比例函数几何性质的证明方法

[分步序列]
- 步骤 0（初始状态）：
  - 显示：x 轴、y 轴、原点 O、函数曲线、曲线标签 y=k/x
  - 显示：点 A、点 B（曲线上）
  - 显示：标签 x、y、O、A、B
  - 隐藏：垂线 AD、BC，垂足 C、D，线段 OA、OB、AB，梯形区域，三角形区域，面积标签 S₁、S₂，坐标标签

- 步骤 1（添加垂线，高亮梯形）：
  - 新增：垂线 AD（A 到 y 轴水平线）、垂足 D（y 轴上）
  - 新增：垂线 BC（B 到 y 轴水平线）、垂足 C（y 轴上）
  - 新增：标签 C、D
  - 新增：梯形 ABCD 区域（半透明蓝色填充）
  - 新增：面积标签 S₁（梯形内部中央位置 (300,200)）
  - 梯形区域高亮（蓝色边框闪烁效果）

- 步骤 2（连接 OA、OB，高亮三角形）：
  - 新增：线段 OA（原点 O 到 A）
  - 新增：线段 OB（原点 O 到 B）
  - 新增：线段 AB（A 到 B，与梯形上边重合）
  - 新增：△OAB 区域（半透明红色填充）
  - 新增：面积标签 S₂（三角形内部位置 (350,300)）
  - 三角形区域高亮（红色边框闪烁效果）

- 步骤 3（显示坐标标注）：
  - 新增：坐标标签 A(x₁, y₁) 在点 A 右下方 (270,160)
  - 新增：坐标标签 B(x₂, y₂) 在点 B 右下方 (520,260)
  - 点 A、B 高亮（放大至 8px，加粗边框）

- 步骤 4（面积公式与结论）：
  - 梯形面积公式显示：S₁ = ½(x₁+x₂)(y₁-y₂) = k（利用 y₁=k/x₁, y₂=k/x₂）
  - 三角形面积公式显示：S₂ = ½|x₁y₂ - x₂y₁| = k
  - 结论高亮：S₁ : S₂ = 1 : 1
  - 梯形和三角形区域同时高亮（交替闪烁）
  - 下一步按钮禁用

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮：ID=scene1-prev-btn，位置 (280,455)-(380,475)，作用：返回上一步骤，步骤 0 时禁用
  - 下一步按钮：ID=scene1-next-btn，位置 (420,455)-(520,475)，作用：进入下一步骤，步骤 4 时禁用
- 教师操作流程：
  1. 初始显示坐标系和函数曲线，讲解反比例函数图像特征
  2. 点击"下一步"，添加垂线构造梯形，讲解梯形 ABCD 的构成
  3. 点击"下一步"，连接 OA、OB 形成三角形，讲解△OAB 的构成
  4. 点击"下一步"，显示坐标标注，引导学生用坐标表示面积
  5. 点击"下一步"，显示面积公式推导和结论 S₁:S₂=1:1
  6. 可随时点击"上一步"回退复习某个步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形绘制简单，SVG 适合精确坐标定位和样式控制，无需额外依赖
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │                        图示区 800×500                        │
  │                                                              │
  │   y↑                                                        │
  │    │  y=k/x                                                 │
  │    │    ╱                                                   │
  │    │   ╱  A●───────────────●D                               │
  │    │  ╱   │  S₁ 梯形      │                                │
  │    │ ╱    │  (蓝色)       │                                │
  │    │╱     │               │                                │
  │    ●B─────┼───────────────●C                                │
  │   ╱│      │               │                                │
  │  ╱ │      │   S₂△OAB      │                                │
  │ ╱  │      │   (红色)      │                                │
  │╱   │      │               │                                │
  │O───┼──────┴───────────────┴──────────────────→ x            │
  │    │                                                        │
  │    │                    [◀上一步] [下一步▶]                 │
  │    └──────────────────────────────────────────────────────  │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-4) 跟踪当前步骤，updateScene() 函数根据 currentStep 显示/隐藏对应元素
  2. 坐标计算：所有元素坐标按上述布局表硬编码，确保精确位置
  3. 动画曲线：梯形和三角形高亮使用 CSS 动画（边框颜色闪烁，2 次循环）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateScene()
  5. 元素显示控制：用 CSS display 或 opacity 控制元素可见性
  6. 面积公式显示：步骤 4 时在 S₁、S₂ 标签下方动态插入公式文本元素
- ID 命名规范：所有交互元素 ID 以 scene1- 为前缀（如 scene1-tri-abcd, scene1-tri-oab, scene1-prev-btn, scene1-next-btn）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
