[图示主题与整合说明]
- 本图示主题：热力环流模式下的气压与温度分布分析
- 整合的步骤/概念：热力环流形成机制（受热上升/冷却下沉）、近地面与高空气压对比、温度垂直分布规律、选项 A 和 B 的判断依据
- 教学价值：教师可通过分步演示，引导学生理解热力环流的形成过程——从受热/冷却条件出发，推导空气垂直运动，进而分析水平气压梯度，最终形成环流圈。此图示帮助学生掌握"热低压、冷高压"的近地面规律，以及高空气压分布与近地面相反的特点。

[分步序列]
- 步骤 0（初始状态）：显示基础环流图
  - 显示：地面平面、四个点 a/b/c/d、四个箭头①②③④、点标签 a/b/c/d、箭头标签①②③④、"地面"和"高空"标注
  - 隐藏：所有解释性标注（冷却/受热、高压/低压、温度、选项判断）

- 步骤 1：标注受热/冷却区域
  - 新增：标签"冷却下沉"（红色，位置 (140,330)，a 处左上）、标签"受热上升"（蓝色，位置 (660,330)，b 处右上）
  - 高亮：点 a 及其附近区域用红色 #c62828 高亮，点 b 及其附近区域用蓝色 #1565c0 高亮
  - 教学要点：a 处空气冷却收缩下沉，b 处空气受热膨胀上升

- 步骤 2：标注近地面气压高低
  - 新增：标签"a:高压"（绿色，位置 (140,380)）、标签"b:低压"（红色，位置 (660,380)）
  - 教学要点：冷却处（a）空气下沉堆积形成高压，受热处（b）空气上升流失形成低压

- 步骤 3：标注高空气压高低
  - 新增：标签"c:高压"（绿色，位置 (660,110)）、标签"d:低压"（红色，位置 (140,110)）
  - 教学要点：高空气压分布与近地面相反，b 处上升气流在 c 处堆积形成高压，a 处下沉气流导致 d 处空气减少形成低压

- 步骤 4：标注温度分布
  - 新增：标签"T_b>T_a"（蓝色，位置 (400,330)，近地面温度对比）、标签"T_a>T_c>T_d"（蓝色，位置 (400,200)，垂直温度递减）
  - 教学要点：近地面受热处温度高于冷却处；同一地点海拔越高温度越低

- 步骤 5（结论）：判断选项 A、B 正误
  - 新增：标签"选项 A:错误"（位置 (400,430)）、标签"选项 B:错误"（位置 (400,455)）
  - 高亮：显示判断依据
    - A 错误原因：温度应为 T_b > T_a > T_c > T_d（近地面 b 受热温度最高，而非 a）
    - B 错误原因：气压应为 a > b > c > d（近地面气压高于高空，且 a 为高压、b 为低压）
  - 教学要点：总结热力环流中温度和气压的分布规律

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 按钮"◀ 上一步"：位置 (280,460)，作用：返回上一状态，教师可回退复习
  - 按钮"下一步 ▶"：位置 (520,460)，作用：进入下一状态，逐步展示分析过程
- 教师操作流程：
  1. 初始展示基础环流图，让学生观察四点位置和气流方向
  2. 点击"下一步"展示受热/冷却区域，讲解空气垂直运动原因
  3. 点击"下一步"展示近地面气压分布，讲解"热低压、冷高压"规律
  4. 点击"下一步"展示高空气压分布，讲解高空气压与近地面相反的特点
  5. 点击"下一步"展示温度分布，讲解垂直温度递减规律
  6. 点击"下一步"展示选项判断结论，总结热力环流中温度和气压的分布规律
  7. 如需复习某一步骤，可点击"上一步"回退

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（矩形、线段、箭头、圆点、文本），无需复杂绘图库；原生 SVG 可直接操作 DOM，便于分步显示/隐藏元素
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────┐
  │                    高空 (400,105)                       │
  │                                                         │
  │    d●─────────────────────●c                            │
  │    │ ④                    │ ②                           │
  │    │                      │                             │
  │    │                      │                             │
  │    │                      │                             │
  │    ●─────────────────────●                              │
  │    a         ③            b                             │
  │                                                         │
  │              地面 (400,405)                             │
  │                                                         │
  │      ◀ 上一步              下一步 ▶                     │
  │      (280,460)            (520,460)                     │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep 记录当前步骤（0-5），每一步对应一个元素显示集合
  2. 坐标计算：所有元素坐标按布局坐标表精确实现，使用 SVG 的 x/y 属性
  3. 动画曲线：元素出现使用 opacity 过渡（0→1），时长 300ms，ease-in-out
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateDisplay() 刷新显示
  5. ID 命名规范：所有交互元素 ID 以 scene1- 为前缀，如 scene1-point-a、scene1-arrow-1、scene1-btn-prev、scene1-btn-next
  6. IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
  7. 元素分组：用 SVG <g> 元素将每步需要同时显示的元素分组，通过控制组的 display 或 opacity 实现分步显示
  8. 箭头绘制：使用 SVG <line> + <polygon> 组合绘制带箭头的线段，箭头指向终点
