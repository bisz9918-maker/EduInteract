    本图示是讲解经纬网方向判断的核心图示，教师应按以下步骤引导学生：

    **步骤0讲解要点：**
    1. 首先介绍经纬网的基本结构：横向线是纬线，指示东西方向；纵向线是经线，指示南北方向
    2. 说明坐标读取规则：先看纬度（横线数值），再看经度（竖线数值）
    3. 引导学生读出四个点的坐标：
       - ①：(0°, 120°W)
       - ②：(0°, 90°E)
       - ③：(35°N, 120°E)
       - ④：(35°N, 120°W)

    **步骤1讲解要点：**
    1. 高亮①和③点，提问："①点在③点的什么方向？"
    2. 引导学生分两步判断：
       - 南北方向：①在0°纬线，③在35°N，①在③的南方
       - 东西方向：①在120°W，③在120°E，①在③的西方
    3. 综合结论：①在③的西南方向
    4. 强调：方向判断要分别考虑南北和东西两个维度

    **步骤2讲解要点：**
    1. 介绍新加坡坐标：(1°N, 104°E)
    2. 引导学生比较：
       - 纬度：1°N接近0°纬线（赤道）
       - 经度：104°E接近90°E和120°E之间
    3. 结论：②点(0°, 90°E)与新加坡坐标最接近

    **步骤3讲解要点：**

    2. 强调解题方法：先读坐标，再比较分析

    **常见错误提醒：**
    - 混淆经线和纬线的方向指示作用
    - 东西方向判断时未考虑经度数值大小关系
    - 坐标书写顺序错误（应为纬度在前，经度在后）

    **完整解答：**

    （1）图中①点在③点的**西南**方向．

    **解析：**
    - ①点坐标：(0°, 120°W)
    - ③点坐标：(35°N, 120°E)
    - 南北方向：0° < 35°N，①在③的南方
    - 东西方向：120°W 与 120°E 相比，①在③的西方
    - 综合：西南方向

    （2）首届青年奥运会举办城市新加坡的经纬度位置与图中比较接近的是**②**，①的经纬度是**(0°, 120°W)**．

    **解析：**
    - 新加坡坐标：(1°N, 104°E)
    - ②点坐标：(0°, 90°E)
    - 纬度差：|1°N - 0°| = 1°
    - 经度差：|104°E - 90°E| = 14°
    - ②点是图中与新加坡坐标最接近的点

    **课堂讲解建议：**
    1. 先让学生独立读图，尝试回答两个问题
    2. 使用图示分步讲解，引导学生说出判断依据
    3. 强调经纬网方向判断的"分步法"：先南北，后东西
    4. 可拓展练习：让学生判断其他点之间的方向关系
