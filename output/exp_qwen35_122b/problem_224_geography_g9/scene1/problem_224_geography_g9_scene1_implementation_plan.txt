[视觉元素清单]
- 经纬网：黑色线条（线宽 2px），构成 3×6 网格

- 夜半球：EDF 线左侧三角形区域，蓝色斜线填充（透明度 20%，斜线 45°，间距 5px）

- 太阳直射点：红色星号（尺寸 12px），位于北回归线与 45°E 交点

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：位于控件栏左侧，点击返回上一状态，第一步时禁用
  - "下一步 ▶"按钮：位于控件栏右侧，点击进入下一状态，最后一步时禁用
  - 步骤指示器：位于控件栏中央，显示"步骤 X/4"
- 教师操作流程：
  1. 初始展示光照图，引导学生观察晨昏线位置
  2. 点击"下一步"→显示夜半球，提问"如何判断昼夜半球？"
  3. 点击"下一步"→显示太阳直射点，讲解"如何确定直射点坐标？"
  4. 点击"下一步"→显示完整标注和对比表，引导学生分析各点地理关系
  5. 可随时点击"上一步"回退，针对关键节点深入讲解

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    图示区 800×500                       │
  │  ┌───────────────────────────────────────────────────┐  │
  │  │  135°W        45°E        135°E                   │  │
  │  │    │            │            │                    │  │
  │  │  90°N ─────────┼────────────┼────────── 90°N      │  │
  │  │    │            │            │                    │  │
  │  │  66.5°N ───────D────────────┼────────── 66.5°N    │  │
  │  │    │            │            │                    │  │
  │  │  23.5°N ───────┼────────────C────────── 23.5°N    │  │
  │  │    │            │            │                    │  │
  │  │  赤道 ─────────B────────────┼────────── 赤道      │  │
  │  │    │            │            │                    │  │
  │  │  23.5°S ───────┼────────────┼────────── 23.5°S    │  │
  │  │    │            │            │                    │  │
  │  │  66.5°S ───A───┼────────────┼────────── 66.5°S    │  │
  │  │   E│            │            │F                   │  │
  │  └────┴────────────┴────────────┴────────────────────┘  │
  │                                                          │
  │  [◀ 上一步]  步骤 1/4  [下一步 ▶]                        │
  └─────────────────────────────────────────────────────────┘
  ```

- 关键实现要点：
  1. 状态机设计：用 currentStep 变量（0-3）跟踪当前步骤，updateScene() 函数根据 currentStep 显示/隐藏对应元素
  2. 坐标计算：所有元素坐标按上述布局表硬编码，确保精确对齐
  3. 动画曲线：元素出现使用 opacity 渐变（0→1，duration 300ms）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateScene()
  5. 夜半球斜线填充：使用 SVG pattern 定义斜线图案，应用到多边形 fill
  6. 对比表格：步骤 3 时动态创建 SVG 文本元素，定位在右下角 (550,280) 区域

- ID 命名规范：所有交互元素 ID 以 scene1- 为前缀
  - 晨昏线：scene1-晨昏线-ED, scene1-晨昏线-DF
  - 点元素：scene1-点-A, scene1-点-B, scene1-点-C, scene1-点-D
  - 夜半球：scene1-夜半球区域
  - 太阳直射点：scene1-直射点
  - 标签：scene1-标签-A, scene1-标签-B, ...
  - 按钮：scene1-按钮 - 上一步, scene1-按钮 - 下一步
  - 表格：scene1-对比表格

- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
