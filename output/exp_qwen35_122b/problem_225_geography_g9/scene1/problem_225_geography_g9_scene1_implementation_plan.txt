[分步序列]
- 步骤0（初始状态）：显示完整经纬网框架（6条经线+6条纬线），标注经度轴（120°-140°-160°-180°-160°-140°）和纬度轴（80°-60°-40°-20°-0°-20°S），显示A、B、C、D四个点但不标注坐标
- 步骤1：高亮显示A、B、C、D四点（绿色圆点加粗），并在各点旁边标注地理坐标：A(140°E, 80°N)、B(140°W, 40°N)、C(140°E, 20°N)、D(140°W, 20°S)
- 步骤2：高亮A点和C点（加粗绿色圆点），用红色垂直箭头从A指向C，标注"A在C的正北方"；高亮B点和C点，用红色斜箭头从B指向C，标注"B在C的东北方"
- 步骤3：用蓝色半透明色带高亮赤道以北区域（北半球），用红色半透明色带高亮赤道以南区域（南半球）；用虚线标注20°W和160°E经线，用不同颜色填充东西半球区域
- 步骤4：用绿色半透明色带标注低纬度区域（0°-30°），用橙色标注中纬度区域（30°-60°），用紫色标注高纬度区域（60°-90°）；在各点旁标注所属纬度带
- 步骤5（结论）：汇总所有答案，在左侧显示完整解答：
  （1）A(140°E, 80°N)、B(140°W, 40°N)、C(140°E, 20°N)、D(140°W, 20°S)
  （2）A在C的正北方
  （3）B在C的东北方
  （4）北半球：A、B、C；南半球：D；东半球：A、C；西半球：B、D
  （5）低纬度：C、D；中纬度：B；高纬度：A

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮（scene1-prev-btn）：位于(280, 455)，点击返回上一步骤，步骤0时禁用
  - 下一步按钮（scene1-next-btn）：位于(500, 455)，点击进入下一步骤，步骤5时禁用
  - 步骤指示器：位于(370, 460)，显示当前步骤"步骤 X/6"
  - 答案显示区：位于(100, 450)，步骤5时显示完整解答
- 教师操作流程：
  1. 初始展示经纬网框架，让学生观察网格结构
  2. 点击"下一步"，显示四点坐标，引导学生读取坐标
  3. 点击"下一步"，显示方向关系，讲解方向判断方法
  4. 点击"下一步"，显示半球划分，讲解半球概念
  5. 点击"下一步"，显示纬度带划分，讲解纬度带概念
  6. 点击"下一步"，显示完整答案，进行总结

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │  120°E  140°E  160°E   180°   160°W  140°W            │ ← 经度标注 (y=65)
  │    │      │      │      │      │      │               │
  │ 80°├──A───┼──────┼──────┼──────┼──────┤               │
  │    │      │      │      │      │      │               │
  │ 60°├──────┼──────┼──────┼──────┼──────┤               │

  │ 40°├──────┼──────┼──────┼──────B──────┤               │ ← 纬度标注 (x=60)
  │    │      │      │      │      │      │               │
  │ 20°├──C───┼──────┼──────┼──────┼──────┤               │
  │    │      │      │      │      │      │               │
  │  0°├──────┼──────┼──────┼──────┼──────┤ 赤道          │

  └─────────────────────────────────────────────────────────┘
  ```

- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量（0-5）跟踪当前步骤，updateScene() 函数根据 currentStep 显示/隐藏对应元素
  2. 坐标计算：经线 x = 100 + i*100 (i=0~5)，纬线 y = 80 + i*60 (i=0~5)
  3. 元素显示控制：使用 display: none/block 或 opacity 控制各步骤元素的可见性
  4. 按钮状态：步骤0时禁用上一步按钮，步骤5时禁用下一步按钮
  5. 箭头绘制：使用 SVG polyline 或 path 元素，步骤2时动态创建
  6. 区域填充：使用 SVG rect 元素，设置 fill-opacity="0.2"
  7. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-grid-line-1、scene1-point-A、scene1-prev-btn）
  8. JS 隔离：所有代码包裹在 (function() { ... })() IIFE 中，避免全局污染

- 元素 ID 命名示例：
  - 经线：scene1-meridian-1 至 scene1-meridian-6
  - 纬线：scene1-latitude-1 至 scene1-latitude-6
  - 点：scene1-point-A、scene1-point-B、scene1-point-C、scene1-point-D
  - 点标签：scene1-label-A、scene1-label-B、scene1-label-C、scene1-label-D
  - 坐标标签：scene1-coord-A、scene1-coord-B、scene1-coord-C、scene1-coord-D
  - 按钮：scene1-prev-btn、scene1-next-btn
  - 步骤指示器：scene1-step-indicator
  - 答案区：scene1-answer-area
  - 箭头：scene1-arrow-AC、scene1-arrow-BC
  - 区域：scene1-hemisphere-north、scene1-hemisphere-south、scene1-latitude-zone-low 等
