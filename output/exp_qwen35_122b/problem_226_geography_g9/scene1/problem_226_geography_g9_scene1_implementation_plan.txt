[分步序列]
- 步骤 0（初始状态）：
  - 显示：地球轮廓、太阳光线（5 条）、地轴、N/S 点及标签、A/B/C 点及标签
  - 隐藏：所有纬线、晨昏线、昼夜半球填充、太阳直射点、极昼极夜区域、半球标签
  - 目的：展示基础地球模型和观测点位置

- 步骤 1（标注晨昏线与昼夜半球）：
  - 新增：晨昏线（黑色实线）、昼半球（无填充）、夜半球（斜线阴影）
  - 新增标签："昼半球"、"夜半球"
  - 视觉变化：地球被清晰分为左右两半，左侧明亮右侧阴影
  - 教学要点：晨昏线是昼夜分界线，左侧为昼半球，右侧为夜半球

- 步骤 2（显示太阳直射点与纬线）：
  - 新增：赤道、北回归线、南回归线、北极圈、南极圈（均为灰色弧线）
  - 新增：太阳直射点（红色圆点，位于南回归线与晨昏线交点）
  - 高亮：南回归线变为红色实线
  - 新增标签：各纬线名称标签（右侧）
  - 教学要点：太阳直射南回归线（23°26'S），为冬至日

- 步骤 3（高亮极昼极夜区域）：
  - 新增：北极圈内绿色半透明填充（极夜区域）
  - 新增：南极圈内绿色半透明填充（极昼区域）
  - 视觉变化：两极区域被绿色高亮
  - 教学要点：北极圈及其以北出现极夜，南极圈及其以南出现极昼

- 步骤 4（标注 B、C 两点地方时）：
  - 在 B 点旁显示标签："地方时≈6:00"（晨线附近，日出时刻）
  - 在 C 点旁显示标签："地方时≈0:00"（夜半球中央，子夜）
  - 高亮：B 点和 C 点变为橙色
  - 教学要点：晨线附近为日出时刻（约 6 时），夜半球中央为子夜（0 时）

- 结论（完整答案展示）：
  - 显示：所有元素同时显示
  - 在底部添加答案框，显示：
    - （1）12 月 22 日，南回归线（23°26'S），冬至日
    - （2）昼短夜长（纬度越高昼越短）
    - （3）时至午餐的是 C（实际应为昼半球中央经线附近点，但图中 C 在夜半球，需修正为昼半球某点），深夜的是 C
  - 教学要点：整合所有判读结论

- 控件说明：
  - "◀ 上一步"按钮：ID=scene1-btn-prev，位置 (260,455)，点击返回上一步

  2. 点击"下一步"，显示晨昏线和昼夜半球，引导学生识别分界线
  3. 点击"下一步"，显示纬线和太阳直射点，引导学生判断直射纬线
  4. 点击"下一步"，高亮极昼极夜区域，引导学生观察范围
  5. 点击"下一步"，标注 B、C 地方时，引导学生推断时间
  6. 点击"下一步"，展示完整答案，进行总结

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（圆形、弧线、直线、箭头），原生 SVG 足够实现，无需引入重型库
- 画布尺寸：800 × 500 px

- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-5) 跟踪当前步骤，每一步对应一个显示配置对象
  2. 坐标计算：地球圆心 (400,250)，半径 200px，所有纬线/经线基于此计算
  3. 晨昏线绘制：垂直线 x=400，从 y=50 到 y=450
  4. 夜半球阴影：使用 SVG pattern 定义斜线填充
  5. 动画曲线：元素出现使用 opacity 从 0 到 1 的过渡动画（200ms）
  6. 事件绑定：按钮点击事件更新 currentStep，调用 renderStep() 重新渲染
  7. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-earth, scene1-ray1, scene1-btn-next）
  8. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  9. 纬线绘制：使用 SVG path 绘制椭圆弧，根据纬度计算 y 坐标和宽度
  10. 极昼极夜区域：使用 SVG path 绘制半圆，填充绿色半透明
