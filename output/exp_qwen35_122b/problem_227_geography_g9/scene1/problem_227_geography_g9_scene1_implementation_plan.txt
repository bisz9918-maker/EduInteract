[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮：scene1-btn-prev，位置 (280,455)，作用：返回上一步骤
  - 下一步按钮：scene1-btn-next，位置 (520,455)，作用：进入下一步骤
  - 步骤指示器：scene1-step-indicator，位置 (350,420)，显示"步骤 X/4"
- 教师操作流程：
  1. 初始展示经纬网和四点位置，让学生观察经纬度分布
  2. 点击"下一步"，展示赤道和南北半球划分，引导学生判断四点所在半球
  3. 点击"下一步"，展示东西半球分界线和区域，让学生判断各点东西半球归属
  4. 点击"下一步"，展示 B-D 虚线路径和方向箭头，引导学生分析方向变化
  5. 最后展示答案总结，核对判断结果

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    北半球标注                            │
  │                                                         │
  │         40°N ────●A────────────●C──── 40°               │
  │             ╲    │            │    ╲                    │
  │         30°N ────┼────────────┼──── 30°                 │
  │             ╲    │            │    ╲                    │
  │         20°N ────●B══════════●D──── 20°                 │
  │             ╱    │            │    ╱                    │
  │          170°    180°        170°                       │
  │                 (经度标注)                               │
  │                                                         │
  │  ════════════════════════════════════════════════════   │
  │                    赤道 0°                               │
  │                                                         │
  │  步骤指示器：[步骤 0/4]                                  │
  │              [◀上一步]  [下一步▶]                        │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：currentStep 变量（0-4），控制各元素显示/隐藏
  2. 坐标计算：经线用 SVG path 绘制弧线（贝塞尔曲线），纬线同理
  3. 动画曲线：元素出现使用 opacity 渐变（0→1，300ms）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 并刷新显示
  5. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-meridian-170e、scene1-point-a、scene1-btn-next）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 元素显示控制：通过 class "hidden" 控制显示/隐藏，CSS 定义 .hidden { display: none; }
