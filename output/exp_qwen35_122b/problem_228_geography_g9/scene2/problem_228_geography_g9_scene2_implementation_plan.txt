[图示主题与整合说明]
- 本图示主题：地方时计算与日期分界线
- 整合的步骤/概念：B点地方时推算（晨线与赤道交点为6时）→ O点地方时确认（晨昏线交点为0时）→ A点经度确定（180°经线为日期分界线）→ 阴影区域日期分析 → A点夜长计算
- 教学价值：教师可通过分步演示，引导学生理解晨昏线与地方时的关系、日期分界线的判断方法、以及夜长的计算原理

[分步序列]
- 步骤0（初始状态）：显示完整经纬网、晨昏线AO和BO、阴影区域、O/A/B三点及纬度标签。无时间标注，无经度标注，无时间差箭头。等待教师点击"下一步"。

- 步骤1：在B点右侧显示蓝色时间标签"6:00"，在B点上方显示文字"晨线与赤道交点，地方时6:00"。其他元素不变。

- 步骤2：在经线下方显示经度标注（从左到右：180°、150°E、120°E、90°E、60°E、30°E），在O点右侧显示红色时间标签"0:00"，在O点上方显示文字"晨昏线交点，地方时0:00"。

- 步骤3：显示橙色时间差箭头连接O点经线(464)与B点经线(720)，在箭头上方显示"经度差45°，时间差3h"。同时显示文字"O点经度90°E，B点经度30°E，B点在O点西侧"。

- 步骤4：显示文字"矛盾分析：若B点6:00，O点0:00，则B点应在O点东侧90°。但图中B点在O点东侧45°。重新分析：O点为0时经线，阴影左边界为180°经线"。

- 步骤5：在A点左侧显示绿色经度标签"120°E"，在阴影区域左侧边界显示"180°经线（日期分界线）"。显示文字"A点经度=180°-60°=120°E"。

- 步骤6：在A点下方显示"夜长计算：A点位于昏线，日落时间=18:00，昼长=12h，夜长=12h"。同时显示A点夜长弧线示意（从A点沿纬线向左的半圆弧）。

[交互方案]

- 控件说明：
  - "◀上一步"按钮：位于(280,440)，宽100px，高36px，灰色背景，点击返回上一步
  - "下一步▶"按钮：位于(500,440)，宽100px，高36px，蓝色背景，点击进入下一步
  - 步骤指示器：位于(360,445)，显示"步骤 X/6"，黑色14px
- 教师操作流程：
  1. 展示初始图，让学生观察晨昏线位置和阴影区域
  2. 点击"下一步"，揭示B点地方时（晨线与赤道交点为6时）
  3. 点击"下一步"，揭示O点地方时和经度标注
  4. 点击"下一步"，显示时间差计算，引导学生发现矛盾
  5. 点击"下一步"，重新分析日期分界线
  6. 点击"下一步"，得出A点经度
  7. 点击"下一步"，计算A点夜长

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    图示区 800×420                       │
  │  ┌──────────────────────────────────────────────────┐   │
  │  │  纬度标签  │  经纬网+晨昏线+阴影+点标注          │   │
  │  │  0°        │                                      │   │
  │  │  23.5°     │         AO(昏线)    BO(晨线)        │   │
  │  │  70°       │              O●                     │   │
  │  │            │    A●           阴影                │   │
  │  │            │                        ●B           │   │
  │  └──────────────────────────────────────────────────┘   │
  │                                                          │
  │  经度标签：180°  150°E  120°E  90°E  60°E  30°E         │
  └─────────────────────────────────────────────────────────┘
  ┌─────────────────────────────────────────────────────────┐
  │  控件栏 y=420-490                                        │
  │  [◀上一步]  步骤 X/6  [下一步▶]                          │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 currentStep 记录当前步骤（0-6），每一步定义需要显示/隐藏的元素ID列表
  2. 坐标计算：所有元素使用绝对坐标，经线间距128px（640/5），纬线间距106.7px（320/3）
  3. 动画曲线：元素出现使用 opacity 从0到1的过渡动画（0.3s ease-in-out）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateScene() 函数刷新显示
  5. ID 命名规范：所有元素ID以"scene2-"为前缀，如"scene2-point-O"、"scene2-line-AO"、"scene2-btn-next"
  6. IIFE 隔离：所有JS代码包裹在(function() { ... })()中，避免全局变量污染
  7. 元素显示控制：使用 setAttribute('display', 'none') 和 setAttribute('display', 'block') 控制元素可见性
