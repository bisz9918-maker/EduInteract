[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：位于底部左侧(280,455)，返回上一状态
  - "下一步 ▶"按钮：位于底部右侧(500,455)，进入下一状态
  - 步骤指示器：底部中央显示"步骤 X/5"
- 教师操作流程：
  1. 初始展示空白经纬网，让学生观察网格结构
  2. 点击"下一步"添加经纬度数值，引导学生读坐标
  3. 点击"下一步"标注点位，让学生练习定位
  4. 点击"下一步"添加方向箭头，讲解方向判断
  5. 点击"下一步"展示经线圈，理解经线配对
  6. 点击"下一步"展示半球划分，理解半球概念
  7. 可随时点击"上一步"回退复习

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（经纬网为几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  ┌─────────────────────────────────────────────────────┐
  │                    经纬网图示区                      │
  │  140°E  160°E   180°   160°W  140°W                │
  │     │      │      │      │      │                  │
  │  60°N─┼──D───┼───A──┼──────┼──────┼──              │
  │     │      │      │      │      │                  │
  │  50°N─┼──────┼──────┼──────F─────┼──              │
  │     │      │      │      │      │                  │
  │  40°N─┼──────E─────┼──────┼──────┼──              │
  │     │      │      │      │      │                  │
  │                                    40°N            │
  │                                                     │
  │         [◀ 上一步]  步骤 X/5  [下一步 ▶]            │
  └─────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：currentStep 变量(0-5)，控制各元素显示/隐藏
  2. 坐标计算：经线x坐标等距分布(120,280,440,600,760)，纬线y坐标等距分布(120,250,380)
  3. 弧线绘制：经线用<path>绘制轻微弯曲的弧线模拟地球曲面，纬线同理
  4. 动画曲线：元素出现使用 opacity 渐变(0→1)，时长300ms
  5. 事件绑定：按钮点击事件更新 currentStep，调用 updateDisplay() 刷新视图
  6. ID 命名规范：所有元素 ID 以"scene1-"为前缀（如 scene1-meridian-140e、scene1-point-d）
  7. IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局污染
  8. 方向箭头：使用<path>绘制带箭头的线，marker-end 定义箭头样式
  9. 半球填充：使用<path>绘制多边形区域，fill-opacity 设置透明度
