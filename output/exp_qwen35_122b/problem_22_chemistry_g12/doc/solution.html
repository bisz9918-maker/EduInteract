problem_22_chemistry_g12

场景导航：Scene 1 | Scene 2

题目原文：
下列有关右图装置的叙述不正确的是（ ）
A．a和b用导线连接时，铜片上析出金属铜
B．b和a分别连接直流电源正、负极时，SO₄²⁻向铁电极移动
C．a和b分别连接直流电源正、负极时，铁片上发生的反应为Cu²⁺+2e⁻═Cu
D．无论a和b怎样连接，铁片均会溶解，溶液从蓝色逐渐变成浅绿色

题目分析：
本题考查电化学装置的工作原理，涉及原电池和电解池两种工作模式的对比。装置核心要素：

  • 两个电极：铜电极（Cu）和铁电极（Fe）
  • 电解质溶液：含 Cu²⁺ 和 SO₄²⁻ 的硫酸铜溶液（蓝色）
  • 两个接线柱 a 和 b，可连接导线或直流电源

整体讲解思路：

  1. 首先明确装置的基本结构，识别电极材料和溶液成分
  2. 分情况讨论三种连接方式：
  • 原电池模式：a和b用导线直接连接
  • 电解池模式1：a接电源正极，b接电源负极
  • 电解池模式2：b接电源正极，a接电源负极
  1. 对每种模式，分析电极反应、离子移动方向、电子流向
  2. 逐项判断选项正误

图示规划说明：

  • Scene_1：展示装置基础结构 + 原电池模式工作原理（导线连接时）
  • Scene_2：展示两种电解池连接方式的对比（电源正负极互换）
步骤 1/6

Scene_1 教学说明：

引导学生观察要点：

  1. 首先识别装置基本结构：两个不同金属电极（Cu 和 Fe）插入同一电解质溶液（CuSO₄）
  2. 当 a 和 b 用导线连接时，构成原电池

原电池工作原理讲解：

  1. 电极判断：Fe 比 Cu 活泼，Fe 作负极，Cu 作正极
  2. 负极反应（Fe 电极）：Fe - 2e⁻ → Fe²⁺（铁溶解）
  3. 正极反应（Cu 电极）：Cu²⁺ + 2e⁻ → Cu（铜析出）
  4. 电子流向：从负极（Fe）经导线流向正极（Cu）
  5. 离子移动：阳离子（Cu²⁺）向正极移动，阴离子（SO₄²⁻）向负极移动

选项判断：

  • 选项 A：正确。铜片（正极）上发生 Cu²⁺ + 2e⁻ → Cu，析出金属铜
  • 选项 D：前半句"无论怎样连接，铁片均会溶解"需要进一步分析（见 Scene_2）

溶液颜色变化：

  • 初始：Cu²⁺ 使溶液呈蓝色
  • 反应后：Fe²⁺ 使溶液呈浅绿色，Cu²⁺ 浓度降低
  • 因此溶液从蓝色逐渐变成浅绿色

Scene_2 教学说明：

电解池工作原理讲解：

状态 1：a 接电源正极，b 接电源负极

  1. 电极极性：Cu 电极（a）为阳极，Fe 电极（b）为阴极
  2. 阳极反应（Cu 电极）：Cu - 2e⁻ → Cu²⁺（铜溶解）
  3. 阴极反应（Fe 电极）：Cu²⁺ + 2e⁻ → Cu（铜析出）
  4. 离子移动：SO₄²⁻ 向阳极（Cu 电极）移动，Cu²⁺ 向阴极（Fe 电极）移动

状态 2：b 接电源正极，a 接电源负极

  1. 电极极性：Fe 电极（b）为阳极，Cu 电极（a）为阴极
  2. 阳极反应（Fe 电极）：Fe - 2e⁻ → Fe²⁺（铁溶解）
  3. 阴极反应（Cu 电极）：Cu²⁺ + 2e⁻ → Cu（铜析出）
  4. 离子移动：SO₄²⁻ 向阳极（Fe 电极）移动，Cu²⁺ 向阴极（Cu 电极）移动

选项判断：

  • 选项 B：正确。b 接正极（阳极），a 接负极（阴极），SO₄²⁻ 向阳极（Fe 电极）移动
  • 选项 C：错误。a 接正极时，Fe 电极（b）为阴极，发生 Cu²⁺ + 2e⁻ → Cu；但选项说"铁片上发生 Cu²⁺ + 2e⁻ → Cu"，此时铁片是阴极，确实发生该反应。但仔细分析：a 接正极时，Cu 是阳极（Cu - 2e⁻ → Cu²⁺），Fe 是阴极（Cu²⁺ + 2e⁻ → Cu）。选项 C 描述正确？需要再确认——实际上选项 C 说"a 和 b 分别连接直流电源正、负极时，铁片上发生的反应为 Cu²⁺ + 2e⁻ → Cu"，此时铁片是阴极，确实发生该反应，所以选项 C 是正确的。

重新分析选项 D：

  • "无论 a 和 b 怎样连接，铁片均会溶解"
  • 原电池模式：Fe 作负极，Fe - 2e⁻ → Fe²⁺，铁溶解 ✓
  • 电解池模式 1（a 正 b 负）：Fe 作阴极，Cu²⁺ + 2e⁻ → Cu，铁不溶解 ✗
  • 电解池模式 2（b 正 a 负）：Fe 作阳极，Fe - 2e⁻ → Fe²⁺，铁溶解 ✓
  • 因此选项 D 错误，因为电解池模式 1 中铁片不溶解

最终答案：选项 D 不正确

课堂讲解建议：

  1. 先用 Scene_1 讲解原电池模式，让学生理解自发氧化还原反应
  2. 再用 Scene_2 对比两种电解池模式，强调外接电源决定电极极性
  3. 引导学生总结规律：
  • 原电池：活泼金属作负极（被氧化）
  • 电解池：阳极发生氧化反应，阴极发生还原反应
  1. 强调选项 D 的错误原因：电解池模式下，铁片可能作阴极而不溶解
