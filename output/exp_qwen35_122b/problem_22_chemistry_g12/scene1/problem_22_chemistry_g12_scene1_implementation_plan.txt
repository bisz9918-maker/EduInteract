[分步序列]
步骤 0（初始状态）：
- 显示：烧杯轮廓、溶液区域、铜电极、铁电极、接线柱 a 和 b、电极引线
- 显示标签：Cu、Fe、a、b、Cu²⁺、SO₄²⁻
- 隐藏：导线连接、电子流向、离子移动箭头、电极反应框
- 目的：展示装置基础结构，让学生识别各组成部分

步骤 1（原电池连接）：
- 新增：导线连接 a 和 b（黑色折线）
- 显示：步骤 0 所有元素 + 导线连接
- 目的：展示 a 和 b 用导线连接时的原电池模式

步骤 2（电子流向）：
- 新增：电子流向箭头（红色，从 Fe 经导线指向 Cu）
- 新增：e⁻标签
- 显示：步骤 1 所有元素 + 电子流向
- 目的：展示电子从负极（Fe）流向正极（Cu）

步骤 3（离子移动）：
- 新增：Cu²⁺移动箭头（蓝色，向 Cu 电极移动）
- 新增：SO₄²⁻移动箭头（灰色虚线，向 Fe 电极移动）
- 显示：步骤 2 所有元素 + 离子移动箭头
- 目的：展示溶液中离子的定向移动

步骤 4（电极反应）：
- 新增：负极反应框（左侧，显示"Fe - 2e⁻ → Fe²⁺"）
- 新增：正极反应框（右侧，显示"Cu²⁺ + 2e⁻ → Cu"）
- 新增：负极标注、正极标注
- 显示：步骤 3 所有元素 + 电极反应框
- 目的：展示两极的电极反应方程式

步骤 5（结论）：
- 高亮：负极反应框、正极反应框（加粗边框或闪烁效果）
- 新增：结论文字框（底部，显示"选项 A 正确：铜片上析出金属铜"、"选项 D 正确：铁片溶解，溶液变浅绿色"）
- 显示：步骤 4 所有元素 + 结论
- 目的：总结原电池工作原理，判断选项 A、D 正确

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮（scene1-prev-btn）：位于控件栏左侧，点击返回上一步，步骤 0 时禁用
  - 下一步按钮（scene1-next-btn）：位于控件栏右侧，点击进入下一步
  - 步骤指示器（scene1-step-indicator）：位于控件栏中央，显示当前步骤/总步骤
- 教师操作流程：
  1. 初始展示装置结构，引导学生识别电极、溶液、接线柱
  2. 点击"下一步"展示导线连接，说明原电池模式
  3. 点击"下一步"展示电子流向，强调电子从负极流向正极
  4. 点击"下一步"展示离子移动，说明溶液中离子定向移动
  5. 点击"下一步"展示电极反应，讲解氧化还原反应
  6. 点击"下一步"展示结论，判断选项 A、D 正确
  7. 可随时点击"上一步"回退复习

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何和动画，无需重型库）
- MathJax：用于渲染化学式（Cu²⁺、SO₄²⁻、电极反应方程式）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：

  │                    控件栏（y=450~485）                   │
  └─────────────────────────────────────────────────────────┘

- 关键实现要点：
  1. 状态机设计：用 currentStep 变量（0-5）跟踪当前步骤，每个步骤对应一个显示元素集合
  2. 坐标计算：所有元素使用绝对坐标，通过 SVG 的 x、y、x1、y1 等属性精确控制
  3. 动画曲线：元素出现使用 opacity 从 0 到 1 的过渡动画（CSS transition，duration 300ms）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 并调用 updateDisplay() 刷新显示
  5. MathJax 渲染：化学式使用 MathJax 的 typeset() 方法动态渲染
  6. 禁用状态：步骤 0 时上一步按钮添加 disabled 属性和灰色样式

- ID 命名规范：所有交互元素 ID 以 scene1- 为前缀
  - 烧杯：scene1-beaker
  - 溶液：scene1-solution
  - 铜电极：scene1-cu-electrode
  - 铁电极：scene1-fe-electrode
  - 接线柱 a：scene1-terminal-a
  - 接线柱 b：scene1-terminal-b
  - 导线连接：scene1-wire-ab
  - 电子流向箭头：scene1-electron-arrow
  - Cu²⁺移动箭头：scene1-cu2plus-arrow
  - SO₄²⁻移动箭头：scene1-so4-arrow
  - 负极反应框：scene1-anode-box
  - 正极反应框：scene1-cathode-box
  - 上一步按钮：scene1-prev-btn
  - 下一步按钮：scene1-next-btn
  - 步骤指示器：scene1-step-indicator

- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染
