[图示主题与整合说明]
- 本图示主题：甲与丙的等效平衡分析
- 整合的内容：展示甲（从 0.2 mol NO₂出发）和丙（从 0.1 mol N₂O₄出发）如何达到相同的平衡状态
- 教学价值：教师可逐步演示等效平衡的建立过程，帮助学生理解"从正逆两个方向出发，在相同条件下可达到同一平衡状态"的核心概念

[分步序列]
- 步骤 0（初始状态）：
  - 显示甲容器（矩形边框 #000000）
  - 显示丙容器（矩形边框 #000000）
  - 甲容器内显示"0.2 mol NO₂"（蓝色 #1565c0）
  - 丙容器内显示"0.1 mol N₂O₄"（绿色 #2e7d32）
  - 显示等效双向箭头（灰色虚线）
  - 显示"等效平衡"标注
  - 隐藏反应箭头、平衡后内容、结论

- 步骤 1（甲中反应开始）：
  - 保留步骤 0 所有元素
  - 显示甲容器内反应箭头（红色 #c62828，向右）
  - 甲容器边框变为蓝色 #1565c0 加粗（表示正在反应）
  - 丙容器保持原样

- 步骤 2（丙中反应开始）：
  - 保留步骤 1 所有元素
  - 显示丙容器内反应箭头（红色 #c62828，向右）
  - 丙容器边框变为绿色 #2e7d32 加粗（表示正在反应）

- 步骤 3（达到平衡）：
  - 保留步骤 2 所有元素
  - 甲容器内新增显示平衡组成：
    - "NO₂: x mol"（蓝色 #1565c0）在 (130,290)
    - "N₂O₄: y mol"（绿色 #2e7d32）在 (130,315)
  - 丙容器内新增显示平衡组成：
    - "N₂O₄: y mol"（绿色 #2e7d32）在 (530,290)
    - "NO₂: x mol"（蓝色 #1565c0）在 (530,315)
  - 甲、丙容器边框均变为蓝色 #1565c0 加粗（表示平衡状态）
  - 反应箭头变为灰色虚线（表示反应停止）

- 步骤 4（结论）：
  - 保留步骤 3 所有元素
  - 底部显示结论文字"平衡时 c(NO₂)甲 = c(NO₂)丙，c(N₂O₄)甲 = c(N₂O₄)丙"（蓝色 #1565c0）
  - 等效双向箭头变为蓝色加粗（强调等效关系）

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "上一步"按钮：id="scene2-prev"，位置 (260,450)-(350,480)，点击返回上一状态
  - "下一步"按钮：id="scene2-next"，位置 (460,450)-(550,480)，点击进入下一状态
  - 步骤 0 时"上一步"按钮禁用，最终步骤时"下一步"按钮禁用
- 教师操作流程：
  1. 初始展示甲、丙容器的初始物质
  2. 点击"下一步"，展示甲中 NO₂开始转化为 N₂O₄
  3. 点击"下一步"，展示丙中 N₂O₄开始分解为 NO₂
  4. 点击"下一步"，展示两容器达到相同平衡状态
  5. 点击"下一步"，显示等效平衡结论
  6. 可随时点击"上一步"回退复习

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何和文本，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │                        等效平衡图示                          │
  │                                                             │
  │     甲                              丙                      │
  │   ┌─────────┐        等效        ┌─────────┐               │
  │   │         │  ←────────────→   │         │               │
  │   │0.2mol   │                   │0.1mol   │               │
  │   │ NO₂     │                   │N₂O₄     │               │
  │   │         │                   │         │               │
  │   │  →      │                   │  →      │               │
  │   │         │                   │         │               │
  │   │NO₂ x    │                   │N₂O₄ y   │               │
  │   │N₂O₄ y   │                   │NO₂ x    │               │
  │   └─────────┘                   └─────────┘               │
  │                                                             │
  │    平衡时 c(NO₂)甲 = c(NO₂)丙，c(N₂O₄)甲 = c(N₂O₄)丙        │
  │                                                             │
  │              [◀ 上一步]        [下一步 ▶]                   │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-4) 跟踪当前步骤
  2. 元素 ID 命名：所有元素 ID 以 scene2- 为前缀（如 scene2-container-a、scene2-arrow-a）
  3. 状态切换函数：updateScene(step) 根据当前步骤显示/隐藏对应元素
  4. 按钮禁用逻辑：step=0 时禁用 prev，step=4 时禁用 next
  5. 容器边框动画：使用 setAttribute 动态修改 stroke 和 stroke-width
  6. 箭头显示控制：初始 opacity=0，需要时设为 1
  7. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中
  8. 使用 getElementById 获取元素，避免 querySelectorAll 全局污染
