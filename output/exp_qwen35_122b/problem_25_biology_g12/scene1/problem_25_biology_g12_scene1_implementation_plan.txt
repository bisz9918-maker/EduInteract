[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮（scene1-prev-btn）：位于控件栏左侧，点击返回上一状态，第一步时禁用
  - 下一步按钮（scene1-next-btn）：位于控件栏右侧，点击进入下一状态，最后一步时显示"完成"
- 教师操作流程：
  1. 初始展示亲本基因型，讲解F1雌果蝇为杂合子(X^A X^a)，F2雄果蝇为隐性纯合(X^a Y)
  2. 点击"下一步"展示配子形成，讲解减数分裂产生四种配子
  3. 点击"下一步"展示受精箭头，讲解随机受精过程
  4. 点击"下一步"展示后代结果，讲解表现型比例1:1:1:1的遗传学意义
  5. 可随时点击"上一步"回退复习关键概念

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（遗传图解为静态几何图形，无需复杂动画库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │                      亲本层标题                              │
  │  F1直刚毛雌果蝇        ×        F2卷刚毛雄果蝇              │
  │  ┌──────────┐                  ┌──────────┐                 │
  │  │ X^A X^a  │                  │ X^a Y    │                 │
  │  └──────────┘                  └──────────┘                 │
  │                              配子层标题                       │
  │  雌配子：  (X^A)  (X^a)      雄配子：  (X^a)  (Y)           │
  │        ╲    ╱  ╲    ╱  ╲    ╱  ╲    ╱                       │
  │         ╲  ╱    ╲  ╱    ╲  ╱    ╲  ╱                        │
  │          ╲      ╲        ╲      ╲                            │
  │                        后代层标题                              │
  │  X^A X^a   X^A Y    X^a X^a   X^a Y                          │
  │  直刚毛雌  直刚毛雄   卷刚毛雌   卷刚毛雄                      │
  │     1   :    1   :    1   :    1                             │
  │                                                               │
  │              [◀ 上一步]              [下一步 ▶]               │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-3) 跟踪当前步骤，updateScene() 函数根据 currentStep 控制元素显示/隐藏
  2. 坐标计算：所有元素使用绝对坐标，通过 SVG 的 x/y 属性精确控制位置
  3. 动画曲线：使用 CSS transition 实现淡入效果（opacity: 0→1，duration 0.3s）
  4. 事件绑定：按钮点击事件监听器，更新 currentStep 后调用 updateScene()
  5. 元素显示控制：通过设置 display="none" 或 display="block" 控制各层元素可见性
  6. ID 命名规范：所有交互元素 ID 以 scene1- 为前缀（如 scene1-prev-btn, scene1-next-btn, scene1-parents-group, scene1-gametes-group, scene1-arrows-group, scene1-offspring-group）
  7. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染
  8. 箭头绘制：使用 SVG <line> 元素配合 <marker> 定义箭头头部，stroke-dasharray 实现虚线效果
  9. 文字渲染：基因型文字使用 tspan 实现上标效果（X<tspan baseline-shift="super">A</tspan>）
