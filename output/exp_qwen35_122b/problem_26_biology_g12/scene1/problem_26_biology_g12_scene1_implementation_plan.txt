[视觉元素清单]
- 果蝇性别符号：♀用圆形(○)，♂用箭头(♂)，直径/边长 35-40px
- 翅型图标：
  - 长翅：完整翅膀轮廓（椭圆形，填充蓝色 #1565c0）
  - 小翅：小翅膀轮廓（半椭圆形，填充红色 #c62828）
  - 残翅：退化翅膀轮廓（小点状，填充绿色 #2e7d32）

  - 红色 #c62828：小翅表型（伴性隐性）
  - 绿色 #2e7d32：残翅表型（常染色体隐性）

[分步序列]
- 步骤0（初始状态）：
  - 显示标题"正交实验：残翅♀×小翅♂"
  - 显示 P 代容器，内含残翅♀和小翅♂图标
  - 标注"纯合子"在 P 代上方
  - 显示 P 代→F₁的箭头（灰色虚线，表示待展示）
  - F₁和 F₂区域隐藏

- 步骤1：
  - F₁容器出现
  - F₁长翅♀和长翅♂图标显示（蓝色填充）
  - 标注"F₁全为长翅，♀♂=1:1"
  - P→F₁箭头变为实线黑色
  - F₁→F₂箭头仍为虚线

- 步骤2：
  - F₂容器出现
  - F₁互交箭头变为实线黑色
  - F₂长翅组显示（长翅♀和长翅♂，蓝色填充）
  - 标注"长翅♀+♂"

- 步骤3：
  - F₂小翅组显示（仅小翅♂，红色填充）
  - F₂残翅组显示（残翅♀和残翅♂，绿色填充）
  - 标注"小翅♂"和"残翅♀+♂"

- 步骤4（最终步骤）：
  - 比例统计区显示，柱状图展示 9:3:4 比例
  - 关键观察框显示，高亮"小翅性状仅出现在雄性"
  - F₂各表型数量标注：长翅 804、小翅 239、残翅 321
  - 所有箭头变为实线，完整遗传路径展示

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "上一步"按钮（id="scene1-btn-prev"）：位于控件栏左侧，点击返回上一状态
  - "下一步"按钮（id="scene1-btn-next"）：位于控件栏右侧，点击进入下一状态
  - 步骤指示器：显示当前步骤"步骤 X/5"
- 教师操作流程：
  1. 初始展示亲本杂交 setup，讲解纯合子概念
  2. 点击"下一步"展示 F₁全为长翅，引导学生思考显隐性关系
  3. 点击"下一步"展示 F₁互交，引出 F₂分离
  4. 点击"下一步"展示 F₂完整表型分布
  5. 点击"下一步"展示比例统计和关键观察，引导学生发现伴性遗传特征

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何和动画，无需重型库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │                    正交实验：残翅♀×小翅♂                       │  y=15
  ├────────────────────────────────────────────────────────────────┤
  │  [P代]        →        [F₁]        →        [F₂]              │  y=80-300
  │  残翅♀小翅♂           长翅♀♂           长翅/小翅/残翅        │
  │                                                                │
  ├────────────────────────────────────────────────────────────────┤
  │  [比例统计 9:3:4]        [关键观察：小翅仅雄性]                 │  y=320-420
  ├────────────────────────────────────────────────────────────────┤
  │              [步骤 1/5]  ◀上一步  下一步▶                       │  y=425-480
  └────────────────────────────────────────────────────────────────┘
  ```

- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-4) 跟踪当前步骤
  2. 元素显示控制：每个步骤对应的元素用 data-step 属性标记，通过 class 控制显示/隐藏
  3. 箭头动画：用 stroke-dasharray 和 stroke-dashoffset 实现虚线到实线的过渡
  4. 按钮状态：步骤 0 时禁用"上一步"，步骤 4 时禁用"下一步"
  5. ID 命名规范：所有元素 ID 以 "scene1-" 为前缀（如 scene1-p-female, scene1-f1-male 等）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染

- 核心代码结构：
  ```javascript
  (function() {
    const state = { currentStep: 0, totalSteps: 4 };
    
    function updateDisplay() {
      // 根据 currentStep 显示/隐藏对应元素
      // 更新步骤指示器
      // 更新按钮状态
    }
    
    function prevStep() {
      if (state.currentStep > 0) {
        state.currentStep--;
        updateDisplay();
      }
    }
    
    function nextStep() {
      if (state.currentStep < state.totalSteps) {
        state.currentStep++;
        updateDisplay();
      }
    }
    
    // 绑定事件
    document.getElementById('scene1-btn-prev').addEventListener('click', prevStep);
    document.getElementById('scene1-btn-next').addEventListener('click', nextStep);
    
    // 初始化
    updateDisplay();
  })();
  ```
