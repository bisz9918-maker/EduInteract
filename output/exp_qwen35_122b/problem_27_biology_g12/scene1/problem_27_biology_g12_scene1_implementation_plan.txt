[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "上一步"按钮（scene1-prev-btn）：位于底部左侧，点击返回上一状态
  - "下一步"按钮（scene1-next-btn）：位于底部右侧，点击进入下一状态
  - 步骤指示器：显示当前步骤/总步骤数（如"步骤 2/6"）
- 教师操作流程：
  1. 初始展示完整系谱图，让学生观察整体结构
  2. 点击"下一步"，高亮甲病患者，引导学生分析甲病特征
  3. 继续点击"下一步"，高亮乙病患者，分析乙病特征
  4. 逐步展示遗传方式结论，讲解推理过程
  5. 最后展示基因型，为后续概率计算做准备
  6. 可随时点击"上一步"回退复习关键步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（遗传系谱图为几何图形，无需复杂图表库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────────────┐
  │                    遗传系谱图分析图示 (800×500)                  │
  │                                                                 │
  │  Ⅰ代  ○──□                    ■──●    图例区                    │
  │       Ⅰ1 Ⅰ2                    Ⅰ3 Ⅰ4   ┌──────────┐            │
  │                                    │  □○正常    │            │
  │  Ⅱ代 ○ ○ ■ ⊞ ○ ○  ○ ○ ○ ■ ○    │  ■●甲病    │            │
  │       Ⅱ1Ⅱ2Ⅱ3Ⅱ4Ⅱ5Ⅱ6 Ⅱ7Ⅱ8Ⅱ9Ⅱ10Ⅱ11  │  ▦乙病    │            │
  │                                    │  ⊞XX男    │            │
  │  Ⅲ代  ○      ■ ●          ■ □    └──────────┘            │
  │       Ⅲ1    Ⅲ2Ⅲ3        Ⅲ4Ⅲ5                              │
  │                                                                 │
  │              [提示框：动态显示步骤说明]                          │
  │                                                                 │
  │              [◀上一步] (2/6) [下一步▶]                          │
  └─────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量（0-5）跟踪当前步骤，每一步定义需要显示/高亮的元素集合
  2. 坐标计算：所有个体位置预先计算并硬编码，确保布局精确
  3. 高亮框动态更新：每一步清除旧高亮框，根据当前步骤添加新高亮框
  4. 斜线填充实现：使用 SVG pattern 定义 45 度斜线，应用于乙病患者
  5. 事件绑定：按钮点击事件调用 updateStep() 函数，根据 currentStep 更新视图
  6. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-circle-i1、scene1-line-marriage-1-2）
  7. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  8. 基因型标注：步骤 5 动态创建 text 元素，插入到 DOM 中对应位置
