[图示主题与整合说明]

[分步序列]
- 步骤0（初始状态）：
  - 显示：完整表格（所有6组数据）、标题
  - 隐藏：推导说明框、结论框、所有高亮框
  - 按钮状态：上一步禁用（灰色），下一步启用（蓝色）
  - 教师操作：让学生先观察完整表格数据，熟悉各组交配组合及结果

- 步骤1（点击下一步）：
  - 显示：完整表格、标题、推导说明框
  - 高亮：组合3用蓝高亮框#1565c0
  - 推导说明框文字："关键发现：组合3（有毛♀×有毛♂）→ 子代出现无毛个体"
  - 隐藏：结论框、其他高亮框
  - 按钮状态：上一步启用，下一步启用
  - 教师操作：引导学生观察组合3，理解"有毛×有毛→出现无毛"说明无毛为隐性性状

- 步骤2（点击下一步）：
  - 显示：完整表格、标题、推导说明框
  - 高亮：组合4用红高亮框#c62828
  - 推导说明框文字："验证：组合4（无毛♀×无毛♂）→ 子代全无毛，符合隐性纯合特征"
  - 隐藏：结论框、其他高亮框
  - 按钮状态：上一步启用，下一步启用
  - 教师操作：引导学生观察组合4，理解"无毛×无毛→全无毛"验证无毛为隐性

- 步骤3（点击下一步）：
  - 显示：完整表格、标题、推导说明框
  - 高亮：组合1、组合2用绿高亮框#2e7d32
  - 推导说明框文字："性别关联：组合1（无毛♀×有毛♂）子代无毛均为雄性；组合2（有毛♀×无毛♂）子代无毛雌雄均有"
  - 隐藏：结论框、其他高亮框
  - 按钮状态：上一步启用，下一步启用
  - 教师操作：引导学生观察组合1、2子代性别分布差异，理解伴X染色体遗传特征

- 步骤4（点击下一步，最终步骤）：
  - 显示：完整表格、标题、结论框
  - 隐藏：推导说明框、所有高亮框
  - 结论框文字："遗传方式判断结论：\n无毛基因为隐性基因，位于X染色体上（伴X隐性遗传）"
  - 按钮状态：上一步启用，下一步禁用（灰色）
  - 教师操作：总结全部推导过程，确认遗传方式判断

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮：位于底部左侧(300,440)，步骤0时禁用，其他步骤启用，点击返回上一状态
  - 下一步按钮：位于底部右侧(400,440)，步骤4时禁用，其他步骤启用，点击进入下一状态
- 教师操作流程：
  1. 图示加载后显示完整表格（步骤0），教师让学生先观察数据
  2. 点击下一步进入步骤1，高亮组合3，教师讲解显隐性判断
  3. 点击下一步进入步骤2，高亮组合4，教师讲解隐性验证
  4. 点击下一步进入步骤3，高亮组合1、2，教师讲解伴性遗传判断
  5. 点击下一步进入步骤4，显示结论，教师总结全部推导过程
  6. 如需复习某一步骤，可点击上一步返回

- 关键实现要点：
  1. 状态机设计：用变量 currentStep 记录当前步骤（0-4），根据 currentStep 控制显示/隐藏元素
  2. 坐标计算：所有元素坐标按布局坐标表精确实现，表格单元格宽度按比例分配
  3. 高亮框实现：用 SVG rect 元素，设置 stroke 颜色和 stroke-width，通过 display 控制显示/隐藏
  4. 按钮事件：绑定 click 事件，点击时更新 currentStep，重新渲染显示状态
  5. 按钮禁用状态：步骤0时上一步按钮 disabled，步骤4时下一步按钮 disabled
  6. 推导说明文字：根据 currentStep 动态更新文本内容

- ID 命名规范：所有交互元素 ID 以 scene1- 为前缀
  - scene1-table-frame：表格框架
  - scene1-header-row：表头行
  - scene1-data-row-1 至 scene1-data-row-6：数据行
  - scene1-highlight-3：组合3高亮框
  - scene1-highlight-4：组合4高亮框
  - scene1-highlight-1-2：组合1、2高亮框
  - scene1-reasoning-box：推导说明框
  - scene1-conclusion-box：结论框
  - scene1-btn-prev：上一步按钮
  - scene1-btn-next：下一步按钮

- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
