[图示主题与整合说明]
- 本图示主题：PCR 放射性标记分布规律（半保留复制特点）
- 整合内容：整合了题目第 (3) 问，展示循环一次和循环 n 次后放射性标记在 DNA 单链中的分布比例
- 教学价值：教师可通过分步动画展示 PCR 半保留复制过程中放射性标记的传递规律，帮助学生理解：
  1. 原始母链始终保持无放射性（黑色）
  2. 新合成的链都含放射性标记（绿色）
  3. 循环 n 次后不含放射性单链的比例为 1/2^n

[分步序列]
- 步骤 0（初始状态）：
  - 显示标题"循环 0 次：原始 DNA"
  - 显示 1 个 DNA 双链分子（2 条黑色母链）
  - 统计区显示："链数：2 条 | 无放射性链：2 条 | 比例：2/2 = 1"
  - 按钮状态：上一步禁用，下一步启用

- 步骤 1（循环 1 次）：
  - 标题变为"循环 1 次后"
  - 原始 DNA 缩小移至左侧，显示 2 个子代 DNA 分子
  - DNA1：上链黑色（母链）+ 下链绿色（新链，含³²P）
  - DNA2：上链绿色（新链，含³²P）+ 下链黑色（母链）
  - 新增³²P 红色标记在新链旁
  - 统计区显示："链数：4 条 | 无放射性链：2 条 | 比例：2/4 = 1/2"
  - 按钮状态：上一步启用，下一步启用

- 步骤 2（循环 2 次）：
  - 标题变为"循环 2 次后"
  - 显示 4 个 DNA 分子，垂直排列
  - 每个分子仍保持 1 黑 1 绿结构
  - 统计区显示："链数：8 条 | 无放射性链：2 条 | 比例：2/8 = 1/4"
  - 按钮状态：上一步启用，下一步启用

- 步骤 3（循环 n 次 - 总结）：
  - 标题变为"循环 n 次后（规律总结）"
  - 显示示意性布局：左侧 2 条黑色母链，右侧多个绿色新链 + "..."
  - 统计区显示："链数：2^(n+1) 条 | 无放射性链：2 条 | 比例：2/2^(n+1) = 1/2^n"
  - 公式区显示："不含放射性单链比例 = 1/2^n"
  - 按钮状态：上一步启用，下一步禁用（或循环回步骤 0）

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶/总结）
- 控件说明：
  - "◀ 上一步"按钮：scene2-btn-prev，位于 (220,450)，回退到上一状态
  - "下一步 ▶"按钮：scene2-btn-next，位于 (350,450)，进入下一状态
  - "总结"按钮：scene2-btn-summary，位于 (480,450)，直接跳到 n 次规律
- 教师操作流程：
  1. 初始展示原始 DNA，讲解母链无放射性
  2. 点击"下一步"，展示循环 1 次，强调半保留复制（每条母链保留，新链合成）
  3. 点击"下一步"，展示循环 2 次，观察无放射性链数量不变
  4. 点击"总结"，引出 n 次规律，推导 1/2^n 公式
  5. 可点击"上一步"回退复习关键概念

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何线条，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    标题区 (300,20)                      │
  │              "循环 X 次后"                              │
  ├─────────────────────────────────────────────────────────┤
  │                                                         │
  │           DNA 分子显示区 (150,80)-(500,320)             │
  │           ┌─────────────────────────────────┐          │
  │           │  黑色母链  ────────  绿色新链   │          │
  │           │  灰色氢键  |||||||||||||||||    │          │
  │           └─────────────────────────────────┘          │
  │                                                         │
  ├─────────────────────────────────────────────────────────┤
  │           统计区 (250,350)  比例公式 (280,380)          │
  │           "链数：X 条 | 比例：Y"                        │
  ├─────────────────────────────────────────────────────────┤
  │           控件栏 (200,440)-(600,490)                    │
  │           [◀上一步]  [下一步▶]  [总结]                  │
  └─────────────────────────────────────────────────────────┘
  ```

- 关键实现要点：
  1. 状态机设计：currentStep 变量 (0-3)，控制显示内容
  2. 坐标计算：DNA 分子位置根据 step 动态计算，使用数组存储各状态数据
  3. 动画曲线：使用 CSS transition 实现淡入淡出效果 (opacity: 0→1)
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后重绘
  5. ID 命名规范：所有元素 ID 以 scene2- 为前缀（如 scene2-dna-chain1, scene2-btn-prev）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 数据驱动：使用状态数组存储各步骤的 DNA 链配置，便于扩展

- 状态数据结构示例：
  ```javascript
  const states = [
    { title: "循环 0 次：原始 DNA", chains: [{color: "black", y: 120}, {color: "black", y: 140}], stats: "2 条 | 2/2 = 1" },
    { title: "循环 1 次后", chains: [...], stats: "4 条 | 2/4 = 1/2" },
    { title: "循环 2 次后", chains: [...], stats: "8 条 | 2/8 = 1/4" },
    { title: "循环 n 次后（规律总结）", chains: [...], stats: "2^(n+1) 条 | 2/2^(n+1) = 1/2^n" }
  ];
  ```

- MathJax 集成：用于渲染³²P 和 1/2^n 等数学公式
  - CDN: https://cdn.jsdelivr.net/npm/mathjax@3/es5/tex-mml-chtml.js
  - 配置：MathJax.typeset() 在每次状态更新后调用
