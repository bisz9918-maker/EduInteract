[分步序列]
步骤 0（初始状态）：
- 显示：5 个空白圆形节点（X、Y、M、N、铁），仅显示节点字母标签
- 隐藏：所有连接线、物质名称标签
- 目的：展示网络框架结构，让学生观察节点布局

步骤 1：
- 新增：显示所有反应连接线（"—"）
  - X-Y、Y-铁（水平线）
  - X-M、Y-M、Y-N（斜线）
- 箭头 N→铁 仍隐藏
- 目的：展示物质间的反应关系网络

步骤 2：
- 新增：显示已知物质"铁"的完整标签
- 目的：明确已知条件，铁是已知物质

步骤 3：
- 高亮：节点 Y 边框变为绿色（#2e7d32），线宽 3px
- 显示：Y 节点的所有连接线（X-Y、Y-铁、Y-M、Y-N）加粗或高亮
- 目的：引导学生分析 Y 节点的反应特性（Y 能与 4 种物质反应）

步骤 4：
- 显示：Y=稀盐酸（在 Y 节点上方显示"稀盐酸"标签）
- 保持：Y 节点绿色高亮
- 目的：根据 Y 能与多种物质反应的特性，推断 Y 为稀盐酸

步骤 5：
- 取消：Y 节点高亮
- 高亮：节点 N 边框变为绿色
- 显示：N→铁 的红色箭头
- 目的：引导学生分析 N 能转化为铁的特性

步骤 6：
- 显示：N=氧化铁（在 N 节点下方显示"氧化铁"标签）
- 保持：N 节点绿色高亮、N→铁箭头
- 目的：根据 N 能转化为铁，推断 N 为氧化铁

步骤 7（结论）：
- 取消：N 节点高亮
- 显示：X=氢氧化钙溶液、M=碳酸钠溶液（或反之，说明两者可互换）
- 显示：完整标注的反应网络，所有物质名称清晰可见
- 目的：展示完整推断结果，X 和 M 为氢氧化钙和碳酸钠（两者位置可互换，均满足反应关系）

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮：ID=scene1-btn-prev，位置 (260,450)，灰色，点击返回上一步
  - 下一步按钮：ID=scene1-btn-next，位置 (440,450)，蓝色，点击进入下一步
  - 步骤指示器：ID=scene1-step-indicator，位置 (350,455)，显示"步骤 1/8"
- 教师操作流程：
  1. 初始展示空白网络框架，让学生观察节点布局
  2. 点击"下一步"显示反应连接线，引导学生分析反应关系
  3. 继续点击逐步揭示已知物质和推断过程
  4. 关键步骤（步骤 3、5）可暂停，让学生先思考再揭示答案
  5. 最终展示完整推断结果，总结复分解反应条件

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（圆形、线段、箭头），原生 SVG 足以实现，无需引入大型库
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
```
┌─────────────────────────────────────────────────────────┐
│                    化学反应关系网络图                    │
│                                                         │
│    X ─────── Y ─────── 铁                               │
│    ╲        ╱ ╲        ╱                                │
│     ╲      ╱   ╲      ╱                                 │
│      M ──────── N → 铁                                  │
│                                                         │
│              [◀上一步]  [下一步▶]                        │
└─────────────────────────────────────────────────────────┘
```

- 关键实现要点：
  1. 状态机设计：使用变量 currentStep 记录当前步骤（0-7），根据 currentStep 控制元素显示/隐藏
  2. 坐标计算：所有元素坐标已在布局坐标表中精确定义，直接硬编码
  3. 动画曲线：元素出现使用 opacity 渐变（0→1，时长 300ms），高亮使用 stroke-width 渐变
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 renderStep() 重绘
  5. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-node-x、scene1-line-xy、scene1-label-y）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染

- SVG 元素 ID 命名示例：
  - 节点：scene1-node-x, scene1-node-y, scene1-node-iron, scene1-node-m, scene1-node-n
  - 连接线：scene1-line-xy, scene1-line-yiron, scene1-line-xm, scene1-line-ym, scene1-line-yn, scene1-line-niron
  - 箭头：scene1-arrow-niron
  - 标签：scene1-label-x, scene1-label-y, scene1-label-iron, scene1-label-m, scene1-label-n
  - 物质名称标签：scene1-label-hcl, scene1-label-oxide, scene1-label-caoh, scene1-label-na2co3
  - 控件：scene1-btn-prev, scene1-btn-next, scene1-step-indicator

- 初始状态渲染：
  - 页面加载后调用 renderStep(0) 渲染步骤 0
  - 仅显示 5 个节点圆形和字母标签
  - 连接线、物质名称标签、高亮效果均隐藏

- 步骤切换逻辑：
  - 下一步：currentStep < 7 时 currentStep++，调用 renderStep(currentStep)
  - 上一步：currentStep > 0 时 currentStep--，调用 renderStep(currentStep)
  - renderStep(n) 根据 n 值控制各元素的 display 或 opacity 属性
