[图示主题与整合说明]
- 本图示主题：体心立方（BCC）与面心立方（FCC）晶胞的边长与密度关系对比

[分步序列]
- 步骤 0（初始状态）：
  - 显示：BCC 晶胞（左侧蓝色线框立方体）、FCC 晶胞（右侧绿色线框立方体）
  - 标签："BCC"在左侧上方，"FCC"在右侧上方
  - 等待教师点击"下一步"

- 步骤 1：
  - 新增：BCC 体对角线（红色虚线，从(150,125)到(300,275)）、FCC 面对角线（红色虚线，从(500,125)到(650,275)）
  - 新增：原子半径标注"r"在 BCC 体对角线旁(200,180)和 FCC 面对角线旁(550,180)
  - 新增：中间标注"r 相同"(380,200)
  - 视觉变化：两条对角线高亮显示，强调原子半径相同

- 步骤 2：
  - 新增：BCC 边长公式"$\\sqrt{3}a_1 = 4r$"在 BCC 下方(225,300)
  - 新增：FCC 边长公式"$2\\sqrt{2}a_2 = 4r$"在 FCC 下方(575,300)
  - 视觉变化：边长公式出现，展示边长与半径的关系

- 步骤 3：
  - 新增：边长比标注"$a_1 : a_2 = \\sqrt{3} : 2\\sqrt{2}$"在底部(225,420)
  - 视觉变化：边长比公式出现，展示两种晶胞边长的比例关系

- 步骤 4：
  - 新增：BCC 原子数标注"n₁ = 2"在 BCC 下方(225,370)
  - 新增：FCC 原子数标注"n₂ = 4"在 FCC 下方(575,370)
  - 视觉变化：原子数标注出现，展示两种晶胞的原子数

- 步骤 5（最终状态）：
  - 新增：密度比标注"$\\rho_1 : \\rho_2 = \\sqrt{3} : \\sqrt{2}$"在底部(575,420)
  - 视觉变化：密度比公式出现，展示最终结论
  - 所有元素完整显示，教师可回顾整个推导过程

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：位置(280,455)，作用：回退到上一个步骤
  - "下一步 ▶"按钮：位置(500,455)，作用：进入下一个步骤
  - 步骤指示器：位置(380,425)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始展示两种晶胞结构
  2. 点击"下一步"逐步展示原子半径关系、边长公式、边长比、原子数、密度比
  3. 可随时点击"上一步"回退复习
  4. 最终展示完整推导过程和结论

- JS 库选择：原生 SVG + MathJax（用于数学公式渲染）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────┐
  │  BCC(180,80)                    FCC(530,80)            │
  │     ●────────────●                  ●────────────●      │
  │    /│           /│                 /│           /│      │
  │   ●────────────●  │                ●────────────●  │     │
  │   │ ●──────────│─●       r 相同    │ ●──────────│─●     │
  │   │ │          │ │   (380,200)    │ │          │ │     │
  │   │ ●──────────│─●                │ ●──────────│─●     │
  │   │/           │/                 │/           │/      │
  │   ●────────────●                  ●────────────●      │
  │   a₁(225,340)                     a₂(575,340)         │
  │   n₁=2(225,370)                   n₂=4(575,370)       │
  │                                                       │
  │   边长比(225,420)              密度比(575,420)        │
  │                                                       │
  │   [◀ 上一步]  步骤 X/5  [下一步 ▶]  (y=455)           │
  └─────────────────────────────────────────────────────────┘
  ```

- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量跟踪当前步骤（0-5），每一步控制元素的显示/隐藏
  2. 坐标计算：BCC 和 FCC 晶胞使用透视投影绘制 3D 立方体效果
  3. 动画曲线：元素出现使用 fade-in 动画（opacity 从 0 到 1，持续时间 300ms）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 并重新渲染
  5. MathJax 集成：使用 MathJax.typeset() 更新数学公式渲染

- ID 命名规范：所有交互元素 ID 必须以 scene3- 为前缀
  - scene3-bcc-cube（BCC 晶胞）
  - scene3-fcc-cube（FCC 晶胞）
  - scene3-bcc-diagonal（BCC 体对角线）
  - scene3-fcc-diagonal（FCC 面对角线）
  - scene3-step-btn-prev（上一步按钮）
  - scene3-step-btn-next（下一步按钮）
  - scene3-step-indicator（步骤指示器）

- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
