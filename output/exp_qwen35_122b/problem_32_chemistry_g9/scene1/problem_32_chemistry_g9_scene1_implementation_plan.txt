[分步序列]
步骤 0（初始状态）：
- 显示完整装置结构（A 瓶、B 瓶、导管、烧杯、胶头滴管）
- A 瓶内显示"HCl"标签和 3 个红色 HCl 分子
- B 瓶内显示"NH₃"标签和 3 个蓝色 NH₃分子
- 三个活塞 a、b、c 显示为红色（关闭状态）
- 无分子运动箭头，无白烟
- 显示瓶标识"A"、"B"，活塞标识"a"、"b"、"c"，水标签

步骤 1（操作提示）：
- 保持步骤 0 所有元素
- 三个活塞 a、b、c 变为绿色（打开状态）
- 在活塞上方显示提示文字"打开活塞 a、b、c"
- 水平导管和垂直导管高亮显示（加粗或变色）

步骤 2（分子运动）：
- 保持步骤 1 所有元素
- 从 A 瓶向中间显示 HCl 运动箭头（灰色虚线，长度 95px，终点约 x=300）
- 从 B 瓶向中间显示 NH₃运动箭头（灰色虚线，长度 115px，终点约 x=480）
- NH₃箭头明显长于 HCl 箭头，表示速率更快
- 在箭头末端显示小圆点表示分子位置

步骤 3（相遇反应）：
- 保持步骤 2 所有元素
- 在靠近 A 瓶的导管位置 (320-360, 235-245) 显示白烟（6-8 个白色小圆点集群）
- 白烟上方显示标签"NH₄Cl"
- 白烟位置明显偏向 A 瓶一侧（约距 A 瓶 120px，距 B 瓶 240px）

步骤 4（结论）：
- 保持步骤 3 所有元素
- 底部显示分子量对比说明：
  - 左侧 (220,450)："HCl 分子量：36.5"
  - 右侧 (580,450)："NH₃分子量：17"
- 白烟位置下方显示距离标注：
  - 距 A 瓶："距 A 瓶近"
  - 距 B 瓶："距 B 瓶远"
- 用测量线连接白烟位置到两瓶，显示距离差异

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    800 × 500 画布                        │
  │                                                         │
  │     A 瓶 (150,80)                    B 瓶 (550,80)        │
  │       ○──────────────────────────────────○              │
  │       │           水平导管               │              │
  │       │                                  │              │
  │       └────c────┐                  ┌────a────┘          │
  │                 │                  │                    │
  │                 └───────b──────────┘                    │
  │                            │                            │
  │                            ▼                            │
  │                       ┌───────┐                         │
  │                       │  烧杯  │                         │
  │                       │  水   │                         │
  │                       └───────┘                         │
  │                                                         │
  │  [◀ 上一步]  [步骤 1/5]  [下一步 ▶]  (y=460 控件栏)        │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-4) 跟踪当前步骤
  2. 元素分组：每个步骤的元素用 group ID 分组，如 scene1-step2-arrows
  3. 坐标计算：所有元素使用绝对坐标，确保精确定位
  4. 动画曲线：分子运动箭头用渐显效果（opacity 0→1，duration 0.5s）
  5. 事件绑定：按钮点击事件监听，更新 currentStep 并刷新显示
  6. ID 命名规范：所有元素 ID 以 scene1- 为前缀，如 scene1-bottle-a、scene1-valve-c
  7. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  8. 活塞状态切换：用 CSS class 控制颜色（valve-closed 红色，valve-open 绿色）
  9. 白烟显示：用多个小圆点组成集群，随机分布在小区域内
  10. 文字标签：使用 SVG text 元素，确保清晰可读
