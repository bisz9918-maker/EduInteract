[图示主题与整合说明]
- 本图示主题：凹凸图形周长比较——平移法演示
- 整合的步骤/概念：整合了甲乙图形展示、平移辅助线演示、补全矩形演示、边长对比演示、周长相等结论展示五个步骤
- 教学价值：教师可通过分步导航引导学生逐步观察图形特征，理解平移法原理，最终得出甲乙周长相等的结论。学生可反复回看关键步骤，巩固平移法比较周长的解题技巧。

[分步序列]
步骤0（初始状态）：
- 显示甲图形轮廓和填充（凹字形）
- 显示乙图形轮廓和填充（凸字形）
- 显示"甲"、"乙"标签
- 等待教师点击"下一步"

步骤1（平移辅助线）：
- 在甲图形凹陷处添加灰色虚线：水平线(180,140)-(220,140)，竖直线(180,140)-(180,100)和(220,140)-(220,100)
- 在乙图形凸起处添加灰色虚线：水平线(540,220)-(580,220)，竖直线(540,220)-(540,260)和(580,220)-(580,260)
- 显示"平移后"标签在甲辅助线旁(230,120)和乙辅助线旁(590,200)
- 说明：虚线表示线段平移轨迹，将凹/凸部分平移至外轮廓

步骤2（补全矩形）：
- 在甲图形外添加虚线矩形框(100,100)-(340,260)
- 在乙图形外添加虚线矩形框(460,100)-(700,260)
- 显示"外轮廓相同"标签在两图形之间(350,180)和(430,180)
- 说明：补全后两个图形外轮廓矩形尺寸相同（6格×4格）

步骤3（边长对比）：
- 隐藏灰色辅助线，显示红色实线高亮甲增加的两条竖边(180,140)-(180,100)和(220,140)-(220,100)
- 显示红色实线高亮乙增加的两条竖边(540,220)-(540,260)和(580,220)-(580,260)
- 显示"+2竖边"标签在甲左侧(160,120)和乙右侧(600,240)
- 说明：甲凹进去增加2条竖边，乙凸出来也增加2条竖边，增加量相同

步骤4（结论）：
- 显示绿色结论文字"甲周长 = 乙周长"(320,380)
- 用绿色等号"="高亮显示
- 说明：通过平移法可知，甲乙周长相等，选C

- 控件说明：
  - 上一步按钮：ID=scene1-prev-btn，位置(280,450)，作用：返回上一步骤
  - 下一步按钮：ID=scene1-next-btn，位置(440,450)，作用：进入下一步骤
  - 步骤指示器：ID=scene1-step-indicator，位置(380,410)，显示"步骤 1/5"
- 教师操作流程：
  1. 初始展示甲乙图形，让学生观察形状差异
  2. 点击"下一步"展示平移辅助线，讲解平移法原理
  3. 点击"下一步"展示补全矩形，说明外轮廓相同
  4. 点击"下一步"高亮增加边长，对比两者增加量
  5. 点击"下一步"展示结论，强调周长相等
  6. 可随时点击"上一步"回退复习关键步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形绘制简单，SVG 适合精确坐标定位和样式控制，无需额外库依赖
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    图示区 800×500                       │
  │                                                         │
  │    ┌─────────────┐              ┌─────────────┐        │
  │    │   甲图形    │              │   乙图形    │        │
  │    │  (凹字形)   │              │  (凸字形)   │        │
  │    │             │              │             │        │
  │    └─────────────┘              └─────────────┘        │
  │                                                         │
  │         [平移辅助线/外轮廓/高亮边长]                     │
  │                                                         │
  │              甲周长 = 乙周长                            │
  │                                                         │
  │    ┌─────────┐  步骤 1/5  ┌─────────┐                   │
  │    │ 上一步  │           │ 下一步  │                   │
  │    └─────────┘           └─────────┘                   │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用 currentStep 变量记录当前步骤(0-4)，每个步骤对应一个显示函数
  2. 坐标计算：基于网格单元 40px，甲图形起点(100,100)，乙图形起点(460,100)
  3. 动画曲线：元素出现使用 opacity 渐变(0→1)，持续时间 300ms
  4. 事件绑定：按钮点击事件触发 stepChange 函数，更新 currentStep 并重新渲染
  5. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-tri-abc、scene1-prev-btn）
  6. IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
  7. 元素显示控制：用 display 属性或 opacity 控制各步骤元素的显示/隐藏
  8. SVG 结构：使用<g>分组管理各步骤元素，便于批量控制显示状态
