[图示主题与整合说明]
- 本图示主题：圆剪拼成近似长方形的动态变换过程
- 整合内容：圆的原始状态 → 分割成扇形 → 重新排列成长方形 → 最终近似长方形形态
- 教学价值：帮助学生直观理解圆周长与长方形周长的关系，掌握"圆剪拼成长方形"的几何变换原理，理解长方形长≈πr、宽=r的推导过程

[分步序列]
步骤 0（初始状态）：
- 显示：完整圆形（左侧），无分割线
- 标注：圆心"O"，半径"r=10cm"
- 右侧：空白或显示"→"提示
- 步骤编号："步骤 0/4"

步骤 1：
- 显示：圆被等分成 16 个扇形
- 扇形填充：交替颜色（蓝色 20% 透明度 + 白色）
- 扇形分割线：灰色虚线从圆心辐射
- 右侧：显示 16 个扇形开始分离的动画
- 步骤编号："步骤 1/4"

步骤 2：
- 显示：16 个扇形完全分离
- 动画：上半圆 8 个扇形向上移动，下半圆 8 个扇形向下移动
- 右侧：扇形开始交错排列，一半尖朝上、一半尖朝下
- 步骤编号："步骤 2/4"

步骤 3：
- 显示：左侧圆保持 16 分割状态
- 右侧：形成近似长方形，上下边呈锯齿状
- 标注：长方形"长≈πr"，"宽=r"
- 步骤编号："步骤 3/4"

步骤 4：
- 显示：左侧圆增加分割份数至 32 份
- 右侧：32 个扇形排列成长方形，锯齿更平滑
- 最终标注：显示周长计算公式 C = 2×(πr + r) = 2×(31.4 + 10) = 82.8cm
- 步骤编号："步骤 4/4"

[交互方案]

- 控件说明：
  - 上一步按钮：ID=scene1-prev-btn，位置(220,455)，点击返回上一状态

- 教师操作流程：

  2. 点击"下一步"，展示扇形分割，讲解等分概念
  3. 点击"下一步"，展示扇形分离移动，讲解变换过程
  4. 点击"下一步"，展示近似长方形，讲解长≈πr、宽=r
  5. 点击"下一步"，展示 32 分割更精确的长方形，推导周长公式
  6. 可随时点击"上一步"回退复习关键步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何动画无需重型库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    步骤 X/4 (400,80)                    │
  │                                                         │
  │   ┌─────────────────┐     →      ┌─────────────────┐   │
  │   │     圆形        │ 剪拼变换   │   近似长方形     │   │
  │   │   (160,205)     │          │    (560,205)     │   │
  │   │    r=10cm       │          │   长≈πr 宽=r     │   │
  │   └─────────────────┘          └─────────────────┘   │
  │                                                         │
  │   ┌─────────────────────────────────────────────────┐   │
  │   │  ◀上一步    步骤 X/4    下一步▶                 │   │
  │   └─────────────────────────────────────────────────┘   │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：currentStep 变量 0-4，updateScene() 函数根据 currentStep 渲染对应状态
  2. 扇形生成：使用 Math.sin/cos 计算扇形顶点坐标，16 份时每份 22.5°，32 份时每份 11.25°
  3. 动画过渡：使用 requestAnimationFrame 实现扇形移动的平滑过渡
  4. 事件绑定：prevBtn 和 nextBtn 点击事件，边界检查（步骤 0 禁用 prev，步骤 4 禁用 next）
  5. ID 命名规范：所有元素 ID 以"scene1-"为前缀（如 scene1-circle, scene1-prev-btn）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 坐标计算：扇形顶点用极坐标转直角坐标公式：x = cx + r×cos(θ), y = cy + r×sin(θ)
  8. 长方形扇形排列：奇数扇形尖朝上，偶数扇形尖朝下，交错排列
