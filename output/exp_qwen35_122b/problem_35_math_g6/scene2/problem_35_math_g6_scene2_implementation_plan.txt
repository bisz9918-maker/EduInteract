[图示主题与整合说明]
- 本图示主题：圆剪拼成长方形的几何关系推导
- 整合的步骤/概念：
  1. 圆的剪拼过程可视化（扇形交错排列）
  2. 长方形长与圆周长一半的对应关系
  3. 长方形宽与圆半径的对应关系
  4. 从几何关系到代数公式的推导
  5. 代入数值计算最终结果
- 教学价值：教师可通过分步演示，让学生直观理解"圆剪拼成长方形"这一经典几何变换，建立图形变换与代数计算的联系，帮助学生记忆周长公式 P = 2r(π + 1)

[交互方案]

  1. 按钮"◀ 上一步"：位于 (280,460)，80×30px，点击返回上一状态，步骤 0 时禁用

  3. 按钮"下一步 ▶"：位于 (520,460)，80×30px，点击进入下一状态，步骤 5 时禁用
- 教师操作流程：
  1. 初始展示圆和长方形，让学生观察图形变换
  2. 点击"下一步"，标注长方形的长和宽，引导学生思考与圆的关系
  3. 点击"下一步"，显示关系弧线，直观展示对应关系

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形（圆、矩形、线段、弧线）用 SVG 绘制最清晰，动画用 CSS transition 和 requestAnimationFrame 即可实现，无需重型库
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    图示区 800×500                       │
  │                                                         │
  │   上半部分（y=0~250）：                                  │
  │   ┌─────────────┐              ┌───────────────────┐    │
  │   │   圆示意图   │   关系弧线   │     长方形        │    │
  │   │   (80,150)  │  ~~~~~~~~~~> │   (350,80)        │    │
  │   │   r=60px    │              │   330×140         │    │
  │   └─────────────┘              └───────────────────┘    │
  │                                                         │
  │   下半部分（y=250~440）：                                │
  │   ┌─────────────────────────────────────────────────┐   │
  │   │  公式推导区                                      │   │
  │   │  公式 1-4（左侧）    计算过程（右侧）             │   │
  │   └─────────────────────────────────────────────────┘   │
  │                                                         │
  │   控件栏（y=440~490，SVG 内 absolute）：                  │
  │   ┌────────┐  ┌────────┐  ┌────────┐                   │
  │   │◀上一步 │  │步骤 1/6 │  │下一步▶ │                   │
  │   └────────┘  └────────┘  └────────┘                   │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-5) 记录当前步骤，updateScene() 函数根据 currentStep 控制元素显示/隐藏
  2. 坐标计算：所有元素坐标硬编码在配置对象中，便于调整
  3. 动画曲线：使用 CSS transition 实现淡入淡出（opacity），使用 requestAnimationFrame 实现弧线绘制（stroke-dasharray 动画）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateScene()
  5. 元素 ID 命名：所有元素 ID 以 scene2- 为前缀，如 scene2-circle、scene2-rect、scene2-btn-prev、scene2-btn-next
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 公式渲染：使用普通 text 元素，无需 MathJax（公式简单，无复杂排版需求）
  8. 响应式：固定 800×500 画布，容器用 overflow: hidden 防止溢出

- 元素 ID 命名规范示例：
  - scene2-circle：圆示意图
  - scene2-rect：长方形
  - scene2-line-length：长标注线
  - scene2-line-width：宽标注线
  - scene2-curve-1：关系弧线 1
  - scene2-curve-2：关系弧线 2
  - scene2-formula-1~4：公式 1-4
  - scene2-calc-text：计算式
  - scene2-calc-process：计算过程
  - scene2-calc-result：计算结果
  - scene2-btn-prev：上一步按钮
  - scene2-btn-next：下一步按钮
  - scene2-step-indicator：步骤指示文本
