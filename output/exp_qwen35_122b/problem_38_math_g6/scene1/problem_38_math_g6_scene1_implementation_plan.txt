[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：位置(320,460)，点击返回上一状态，步骤0时禁用
  - "下一步 ▶"按钮：位置(440,460)，点击进入下一状态，步骤2时禁用
  - 步骤指示器：位置(380,420)，显示当前步骤"步骤 X/3"
- 教师操作流程：
  1. 初始展示左图阶梯状立体图形，讲解其结构（底层3个、中层2个、顶层1个）
  2. 点击"下一步"展示右图U型立体图形，讲解其结构（底层3个、中层左右各1个、顶层右边1个）
  3. 点击"下一步"同时显示两个图，引导学生对比两个图形的异同
  4. 可随时点击"上一步"回退复习某个图形的结构

- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0,1,2) 跟踪当前步骤
  2. 等轴测立方体绘制：每个正方体绘制3个可见面（顶面、正面、右侧面），使用 SVG polygon 元素
  3. 坐标计算：等轴测投影中，正方体边长 s=40，顶面为菱形，正面和右侧面为平行四边形
  4. 动画曲线：步骤切换使用淡入淡出效果（opacity 0→1 或 1→0），过渡时间 300ms
  5. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 render() 函数刷新显示
  6. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-cube-left-1, scene1-btn-prev）
  7. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染

- 等轴测立方体绘制公式：
  - 给定正方体左下角坐标 (x, y, z)，等轴测投影：
    - 顶面四个顶点：(x, y-20), (x+20, y-40), (x+40, y-20), (x+20, y)
    - 正面四个顶点：(x, y), (x+40, y), (x+40, y+40), (x, y+40)
    - 右侧面四个顶点：(x+40, y), (x+60, y-20), (x+60, y+20), (x+40, y+40)
  - 实际绘制时根据层级叠加，z 值越大越靠上
