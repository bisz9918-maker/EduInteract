[图示主题与整合说明]
- 本图示主题：从三个方向观察两个立体图形的视图对比
- 整合的步骤/概念：整合了从上面、前面、左面三个方向观察两个立体图形的视图对比，帮助学生理解三视图概念
- 教学价值：教师可以通过切换不同视角，直观展示两个立体图形从各个方向观察时的形状差异，引导学生发现"从上面看两个图形的形状相同"这一关键结论，培养空间想象能力

[分步序列]
本场景采用多状态切换交互，共3个状态：

状态0（初始状态 - 从上面看）：
- 视角标签显示"从上面看"
- 左图视图：3个小正方形水平排列，中心坐标分别为(140,200)、(180,200)、(220,200)，每个正方形40×40
- 右图视图：3个小正方形水平排列，中心坐标分别为(540,200)、(580,200)、(620,200)，每个正方形40×40
- 按钮"从上面看"处于激活状态（#1565c0），其他按钮默认状态（#888888）
- 视觉结论：两个图形从上面看形状相同（都是3个正方形排成一行）

状态1（点击"从前面看"）：
- 视角标签显示"从前面看"
- 左图视图：3列正方形，从左到右高度分别为3、2、1
  - 第1列：3个正方形垂直堆叠，y坐标分别为140、180、220
  - 第2列：2个正方形垂直堆叠，y坐标分别为180、220
  - 第3列：1个正方形，y坐标为220
  - x坐标分别为140、180、220
- 右图视图：3列正方形，从左到右高度分别为2、1、2
  - 第1列：2个正方形垂直堆叠，y坐标分别为180、220
  - 第2列：1个正方形，y坐标为220
  - 第3列：2个正方形垂直堆叠，y坐标分别为180、220
  - x坐标分别为540、580、620
- 按钮"从前面看"处于激活状态，其他按钮默认状态
- 视觉结论：两个图形从前面看形状不同

状态2（点击"从左面看"）：
- 视角标签显示"从左面看"
- 左图视图：1列3个正方形垂直堆叠（从左面看只能看到最左边一列，高度为3）
  - 正方形y坐标分别为140、180、220，x坐标为140
- 右图视图：1列2个正方形垂直堆叠（从左面看能看到高度为2）
  - 正方形y坐标分别为180、220，x坐标为540
- 按钮"从左面看"处于激活状态，其他按钮默认状态
- 视觉结论：两个图形从左面看形状不同（左图3层，右图2层）

[交互方案]
- 交互类型：多状态切换（3个按钮）
- 控件说明：
  - 按钮1"从上面看"：位置(150,430)，点击后切换到状态0，显示从上面观察的视图
  - 按钮2"从前面看"：位置(340,430)，点击后切换到状态1，显示从前面观察的视图
  - 按钮3"从左面看"：位置(530,430)，点击后切换到状态2，显示从左面观察的视图
- 教师操作流程：
  1. 图示加载后默认显示"从上面看"的状态
  2. 教师引导学生观察两个图形从上面看的形状，发现都是3个正方形排成一行，形状相同
  3. 点击"从前面看"按钮，展示两个图形从前面看的不同形状（左图阶梯状，右图U形）
  4. 点击"从左面看"按钮，展示两个图形从左面看的不同层数（左图3层，右图2层）
  5. 总结：只有从上面看两个图形的形状相同，答案为C

[技术实现]
- JS 库选择：原生 HTML/CSS/JavaScript + SVG（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
```
┌────────────────────────────────────────────────────────────────┐
│                        视角标签 (320,20)                        │
│                                                                │
│   左图标签(150,85)                    右图标签(500,85)          │
│      ↓                                    ↓                   │
│  ┌───────────────┐                  ┌───────────────┐          │
│  │               │                  │               │          │
│  │   左图视图    │                  │   右图视图    │          │
│  │  (100,100)    │                  │  (450,100)    │          │
│  │   250×250     │                  │   250×250     │          │
│  │               │                  │               │          │
│  └───────────────┘                  └───────────────┘          │
│                                                                │
│  [从上面看]        [从前面看]        [从左面看]                │
│   (150,430)        (340,430)        (530,430)                 │
└────────────────────────────────────────────────────────────────┘
```

- 关键实现要点：
  1. 状态机设计：使用变量 currentView 记录当前视角（0=上面，1=前面，2=左面）
  2. 坐标计算：小正方形边长40px，间距0px（紧密排列），视图区中心对齐
  3. 动画曲线：状态切换时使用淡入淡出效果（opacity 0→1，200ms过渡）
  4. 事件绑定：三个按钮分别绑定 click 事件，切换状态并更新视图
  5. ID 命名规范：所有元素 ID 以 scene2- 为前缀（如 scene2-view-label、scene2-btn-top、scene2-left-view 等）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染

- SVG 结构：
  - 主 SVG 元素：width="800" height="500"
  - 视图背景矩形：scene2-left-bg、scene2-right-bg
  - 小正方形组：scene2-left-squares、scene2-right-squares（动态清空重绘）
  - 标签文本：scene2-view-label、scene2-left-label、scene2-right-label
  - 按钮组：使用 HTML button 元素，position:absolute 定位在 SVG 容器内

- 视图绘制逻辑：
  - 从上面看：左右各绘制3个水平排列的正方形
  - 从前面看：左图绘制高度3、2、1的阶梯，右图绘制高度2、1、2的U形
  - 从左面看：左图绘制1列3个正方形，右图绘制1列2个正方形
