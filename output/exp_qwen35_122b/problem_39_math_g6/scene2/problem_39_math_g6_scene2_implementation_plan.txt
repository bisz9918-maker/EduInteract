[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于底部左侧，点击返回上一状态，第一步时禁用
  - 「下一步 ▶」按钮：位于底部右侧，点击进入下一状态，最后一步时变为「完成」
- 教师操作流程：
  1. 初始展示通用公式，讲解旋转坐标变换的基本原理
  2. 点击「下一步」，展示三步变换流程，配合讲解平移-旋转-平移的完整过程
  3. 点击「下一步」，代入本题数据，展示计算过程，同时呈现四个选项
  4. 点击「下一步」，显示最终答案并高亮正确选项 C，引导学生理解为什么其他选项错误

[技术实现]
- JS 库选择：原生 JavaScript + SVG（无需额外库，简单 DOM 操作即可）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │  通用公式推导                    │         本题应用              │
  │  ┌────────────────────────────┐ │  ┌─────────────────────────┐ │
  │  │ x' = a + (y - b)           │ │  │ 已知条件                │ │
  │  │ y' = b - (x - a)           │ │  │ O(5,1), A(5,7)          │ │
  │  │ a,b 为旋转中心坐标         │ │  │ 顺时针 90°              │ │
  │  └────────────────────────────┘ │  └─────────────────────────┘ │
  │  ┌────────────────────────────┐ │  ┌─────────────────────────┐ │
  │  │ 平移 → 旋转 → 平移         │ │  │ 计算过程                │ │
  │  └────────────────────────────┘ │  │ x' = 5 + (7-1) = 11     │ │
  │                                 │ │ y' = 1 - (5-5) = 1      │ │
  │                                 │ │ A'(11,1) [红色高亮]      │ │
  │                                 │  └─────────────────────────┘ │
  │                                 │  选项对比                    │
  │                                 │  A(7,5) B(10,3) C(9,3) D(1,3)│
  │                                 │  [C 绿色高亮]                │
  ├────────────────────────────────────────────────────────────────┤
  │                    [◀ 上一步]      [下一步 ▶]                  │
  └────────────────────────────────────────────────────────────────┘
  ```

- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-3) 跟踪当前步骤
  2. 元素显示控制：每个步骤对应一组元素的 display 属性切换
  3. 坐标计算：所有元素使用绝对定位，坐标已在布局坐标表中定义
  4. 按钮状态：第一步时禁用「上一步」，最后一步时「下一步」变为「完成」
  5. 高亮效果：步骤 3 时选项 C 框的填充色和边框样式动态变化

- ID 命名规范：所有交互元素 ID 以 scene2- 为前缀
  - scene2-formula-box, scene2-step-flow, scene2-conditions-box
  - scene2-calc-box, scene2-option-a, scene2-option-b, scene2-option-c, scene2-option-d
  - scene2-prev-btn, scene2-next-btn

- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
