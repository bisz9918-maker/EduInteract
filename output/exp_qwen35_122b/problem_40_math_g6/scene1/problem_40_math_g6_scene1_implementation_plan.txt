[分步序列]

- 步骤1：
  - 视觉变化：高亮框1显示（#2e7d32 实线2px），爱心图案和爱心标签同时高亮（加粗边框#2e7d32）
  - 说明框1内文字："爱心 ↔ 爱心（正面与背面）"
  - 按钮：上一步（启用）、下一步（启用）

- 步骤2：
  - 视觉变化：高亮框2显示，太阳图案和太阳标签同时高亮
  - 说明框2内文字："太阳 ↔ 太阳（顶面与底面）"
  - 高亮框1恢复透明
  - 按钮：上一步（启用）、下一步（启用）

- 步骤3：
  - 视觉变化：高亮框3显示，笑脸图案和笑脸标签同时高亮
  - 说明框3内文字："笑脸 ↔ 笑脸（右侧面与左侧面）"
  - 高亮框2恢复透明
  - 按钮：上一步（启用）、下一步（启用）

- 步骤4（最终状态）：
  - 视觉变化：三个高亮框同时显示（或循环闪烁），三个图案标签同时高亮
  - 说明框内文字统一为："三组对面图案分别相同"
  - 按钮：上一步（启用）、下一步（禁用）

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - scene1-btn-prev：位于(300,440)-(400,480)，点击返回上一步，步骤0时禁用
  - scene1-btn-next：位于(400,440)-(500,480)，点击进入下一步，步骤4时禁用
- 教师操作流程：
  1. 初始展示正方体立体图，引导学生观察可见的三个面
  2. 点击"下一步"，逐步高亮每组对面，讲解"对面图案相同"的空间关系
  3. 最终步骤展示三组对面关系总结，为后续展开图判断做铺垫

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │                        800px 宽度                              │
  │  ┌────────────────────┬─────────────────────────────────────┐  │
  │  │                    │  对面关系                           │  │
  │  │    正方体立体图     │  ┌─────────────────────────────┐   │  │
  │  │   (正面/顶面/右侧面) │  │ 爱心 ↔ 爱心（正面与背面）   │   │  │
  │  │                    │  ├─────────────────────────────┤   │  │
  │  │   [爱心][太阳]      │  │ 太阳 ↔ 太阳（顶面与底面）   │   │  │
  │  │       [笑脸]        │  ├─────────────────────────────┤   │  │
  │  │                    │  │ 笑脸 ↔ 笑脸（右侧面与左侧面）│   │  │
  │  │                    │  └─────────────────────────────┘   │  │
  │  │                    │                                     │  │
  │  └────────────────────┴─────────────────────────────────────┘  │
  │  ┌─────────────────────────────────────────────────────────────┐│
  │  │              [◀ 上一步]  [下一步 ▶]                         ││
  │  └─────────────────────────────────────────────────────────────┘│
  └────────────────────────────────────────────────────────────────┘
                              500px 高度
  ```

- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-4) 跟踪当前步骤
  2. 坐标计算：正方体采用斜二测投影，正面为平行四边形，顶面和右侧面按透视偏移
  3. 高亮动画：使用 CSS transition 实现高亮框淡入淡出（opacity 0→1）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 renderStep() 刷新显示
  5. ID 命名规范：所有交互元素 ID 以 scene1- 为前缀（如 scene1-cube-front, scene1-btn-prev）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
