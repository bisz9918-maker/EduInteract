[分步序列]
- 初始状态（步骤0）：
  - 显示3D立体图基础框架（所有立方体线框，无填充）
  - 显示标题"立体图"
  - 不显示层数标签和总数
  - 控件：下一步▶可用，◀上一步禁用

- 步骤1：
  - 高亮左上角2层位置：该柱体填充红色（透明度20%），轮廓变蓝色#1565c0
  - 显示左上柱标签"2层"（蓝色）
  - 控件：◀上一步/下一步▶均可用

- 步骤2：
  - 所有柱体显示层数标签：
    - 左下柱标签"1层"（黑色）
    - 中上柱标签"1层"（黑色）
    - 右上柱标签"1层"（黑色）
  - 其他柱体填充浅灰色（透明度20%）
  - 控件：◀上一步/下一步▶均可用

- 步骤3（最终步骤）：
  - 显示总数框：绿色文字"共5个正方体"
  - 所有标签和柱体保持显示
  - 控件：◀上一步可用，下一步▶禁用

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：位于(280,460)，点击返回上一状态，步骤0时禁用
  - "下一步 ▶"按钮：位于(420,460)，点击进入下一状态，步骤3时禁用
- 教师操作流程：
  1. 初始展示立体图框架，让学生根据三视图猜测结构
  2. 点击"下一步"高亮2层位置，引导学生注意关键差异
  3. 点击"下一步"显示所有层数，验证推理
  4. 点击"下一步"显示总数，确认答案（选项B：5个）

[技术实现]
- JS库选择：原生SVG（简单几何首选），无需额外库
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │ 立体图                                                         │
  │                                                                │
  │           [2层]  [1层]  [1层]                                  │
  │             ████  ████  ████                                   │
  │             ████  ████  ████                                   │
  │       [1层] ████                                               │
  │         ████                                                   │
  │                                                                │
  │                                                                │
  │                  共5个正方体                                   │
  │                                                                │
  │              [◀ 上一步]  [下一步 ▶]                            │
  └────────────────────────────────────────────────────────────────┘
  ```

- 关键实现要点：
  1. 状态机设计：currentStep变量(0-3)，updateScene()函数根据currentStep更新DOM
  2. 坐标计算：等轴测视角，立方体边长60px，使用SVG transform进行3D投影
  3. 动画曲线：元素出现使用opacity过渡(0.3s ease-in-out)
  4. 事件绑定：按钮click事件，步骤0禁用上一步，步骤3禁用下一步
  5. ID命名规范：所有元素ID以"scene2-"为前缀（如scene2-cube-bl, scene2-label-tl, scene2-btn-prev）
  6. IIFE隔离：所有JS包在(function() { ... })()中，避免全局污染

- SVG结构：
  - 使用<g id="scene2-cubes">包裹所有立方体
  - 每个立方体用<g id="scene2-cube-XX">包裹，包含3个面(polygon)
  - 标签用<text id="scene2-label-XX">
  - 总数框用<g id="scene2-total-box">包含rect和text
  - 控件用<div id="scene2-controls">绝对定位在SVG底部
