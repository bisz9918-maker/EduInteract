[分步序列]
- 步骤 0（初始状态）：显示菱形循环结构（A→B→D→C→A 四条箭头线段），显示 A、B、C、D 四个顶点圆点及点标签，阶段说明标签全部隐藏
- 步骤 1：高亮 A 顶点（蓝高亮填充），显示 A 阶段标签"卵"（在 A 点下方(400,110)）
- 步骤 2：高亮 B 顶点（蓝高亮填充），显示 B 阶段标签"幼虫/若虫"（在 B 点左下方(150,280)），A 高亮恢复
- 步骤 3：高亮 D 顶点（蓝高亮填充），显示 D 阶段标签"蛹/成虫"（在 D 点左上方(360,390)），B 高亮恢复
- 步骤 4：高亮 C 顶点（蓝高亮填充），显示 C 阶段标签"成虫"（在 C 点右下方(630,280)），D 高亮恢复
- 步骤 5（最终状态）：所有顶点恢复默认，所有阶段说明标签显示（"卵"、"幼虫/若虫"、"蛹/成虫"、"成虫"），完整展示发育周期

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮（scene1-prev-btn）：位于 (250,455)，点击返回上一状态，步骤 0 时禁用
  - 下一步按钮（scene1-next-btn）：位于 (470,455)，点击进入下一状态，步骤 5 时禁用
- 教师操作流程：
  1. 初始展示循环结构，引导学生观察箭头方向
  2. 点击"下一步"逐步揭示各阶段含义（卵→幼虫/若虫→蛹/成虫→成虫）
  3. 最后展示完整标注，总结发育周期
  4. 可随时点击"上一步"回退复习特定阶段

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  
                    A(400,80)
                   /         \
                  /           \
                 /             \
                /               \
          B(200,250)───────────C(600,250)
                \               /
                 \             /
                  \           /
                   \         /
                    D(400,420)
  
  [控件栏（SVG 内底部 y=450~480）]
  ┌─────────────────────────────────────┐
  │      ◀上一步          下一步▶       │
  └─────────────────────────────────────┘
  ```

- 关键实现要点：
  1. 状态机设计：currentStep 变量（0-5），updateScene() 函数根据 currentStep 显示/隐藏元素
  2. 坐标计算：菱形顶点坐标预先计算好，箭头使用 SVG line 元素 + marker-end 箭头标记
  3. 动画曲线：高亮效果使用 CSS transition（opacity 0.3s ease）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateScene()
  5. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-vertex-a、scene1-arrow-ab、scene1-label-stage-a、scene1-prev-btn、scene1-next-btn）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
