[图示主题与整合说明]
- 本图示主题：完全变态与不完全变态发育对比
- 整合内容：左侧展示完全变态发育（蚊、家蚕）的四阶段循环，右侧展示不完全变态发育（蝗虫、蟋蟀）的三阶段循环，中间用虚线分隔对比

[交互方案]
- 交互类型：多状态切换（3 个状态按钮）
- 控件说明：
  - 按钮 1「完全变态发育」：位置 (260,450)-(350,480)，点击显示左侧四阶段循环
  - 按钮 2「不完全变态发育」：位置 (360,450)-(450,480)，点击显示右侧三阶段循环
  - 按钮 3「对比模式」：位置 (460,450)-(540,480)，点击同时显示左右两侧并高亮关键差异
- 教师操作流程：
  1. 先点击「完全变态发育」，讲解蚊、家蚕的四阶段发育过程，强调有蛹期
  2. 再点击「不完全变态发育」，讲解蝗虫、蟋蟀的三阶段发育，强调无蛹期
  3. 最后点击「对比模式」，对比两种类型，引导学生观察阶段数量差异
  4. 结合题目选项，引导学生判断：A 选项（蚊→蛹期 D）正确；B 选项（蝗虫→成虫 C）正确；C 选项（家蚕延长 B 幼虫期）正确；D 选项（蟋蟀 C 期蜕皮）错误，因为蟋蟀若虫期（B）才蜕皮

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形和状态切换，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │                    完全变态发育        |      不完全变态发育  │
  │                                                             │
  │           A(卵)                    A(卵)                   │
  │          /   \                      |                       │
  │     B(幼虫)  C(成虫)          B(若虫)───C/D(成虫)          │
  │          \   /                      ↑                       │
  │           D(蛹)                     │                       │
  │                                                             │
  │        例：蚊、家蚕              例：蝗虫、蟋蟀              │
  │        家蚕吐丝在幼虫期(B)                                 │
  │                                                             │
  │              [完全变态] [不完全变态] [对比模式]              │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentState = 0/1/2 跟踪当前状态，updateDisplay() 函数根据状态显示/隐藏元素
  2. 坐标计算：所有元素使用绝对坐标，椭圆用 cx/cy/rx/ry，箭头用 path 绘制带箭头标记
  3. 动画曲线：状态切换使用 opacity 渐变（0.3s ease），元素淡入淡出
  4. 事件绑定：三个按钮分别绑定 click 事件，调用 setState(n) 切换状态
  5. ID 命名规范：所有元素 ID 以 scene2- 为前缀，如 scene2-ellipse-left-A、scene2-arrow-left-AB、scene2-btn-1 等
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 箭头绘制：使用 SVG marker 定义箭头头部，path 的 marker-end 属性引用
  8. 高亮效果：对比模式下，给 scene2-ellipse-left-D 添加绿色边框和阴影
