[图示主题与整合说明]
- 本图示主题：胰岛调节血糖的生理机制（场景 2）
- 整合内容：血糖浓度变化 → 胰岛感知 → 胰岛素分泌 → 丙血管中胰岛素含量变化
- 教学价值：教师可通过拖动血糖滑块，动态演示负反馈调节机制，帮助学生理解"血糖升高→胰岛素分泌增加→血糖降低"的闭环调节过程

[分步序列]
本场景为连续拖拽交互，无分步导航，状态随滑块位置实时变化：

- 初始状态（滑块最左 x=80，血糖=3.0 mmol/L）：
  - 滑块手柄位于最左侧
  - 胰岛素柱状图高度=10px（最低）
  - 丙血管内显示 2 个胰岛素分子
  - 状态指示显示"低血糖"（蓝色）

- 中间状态（滑块中左 x=113，血糖=5.5 mmol/L）：
  - 滑块手柄向左移动 1/3
  - 胰岛素柱状图高度=40px
  - 丙血管内显示 5 个胰岛素分子
  - 状态指示显示"正常血糖"（绿色）

- 中间状态（滑块中右 x=147，血糖=8.0 mmol/L）：
  - 滑块手柄向右移动 2/3
  - 胰岛素柱状图高度=70px
  - 丙血管内显示 10 个胰岛素分子
  - 状态指示显示"血糖偏高"（橙色）

- 最终状态（滑块最右 x=180，血糖=12.0 mmol/L）：
  - 滑块手柄位于最右侧
  - 胰岛素柱状图高度=100px（最高）
  - 丙血管内显示 15 个胰岛素分子
  - 状态指示显示"高血糖"（红色警示）

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：
  1. 血糖浓度滑块（scene2-glucose-slider）：位于左侧 (80,370)-(180,390)，拖动手柄改变血糖值
  2. 数值显示（scene2-glucose-value）：实时显示当前血糖浓度（mmol/L）
  3. 状态指示（scene2-status-text）：右侧显示当前血糖状态（低/正常/高）

- 教师操作流程：
  1. 初始展示低血糖状态，说明此时胰岛素分泌最少
  2. 缓慢拖动滑块向右，边拖边讲解："当血糖升高时，胰岛β细胞感知到变化"
  3. 继续拖动至正常范围，说明："胰岛素分泌逐渐增加，促进血糖进入细胞"
  4. 拖动至高血糖区域，强调："血糖越高，胰岛素分泌越多，这是负反馈调节"
  5. 可来回拖动，让学生观察胰岛素分子数量的动态变化

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何和交互，无需重型库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │                        图示区 800×500                          │
  │                                                                │
  │  甲→ [乙] →丙                                                  │
  │  (50,200) (220,150) (480,200)                                  │
  │                                                                │
  │        [胰岛素分泌量柱状图]                                     │
  │              (300,280)                                         │
  │                                                                │
  │  [血糖滑块]                    [丙血管内胰岛素分子]              │
  │  (80,370)                      (520,180)                       │
  │                                                                │
  │  ───────────────────────────────────────────────────────────── │
  │  控件栏：无独立控件栏，滑块已嵌入 SVG 内                         │
  └────────────────────────────────────────────────────────────────┘
  ```

- 关键实现要点：
  1. 状态机设计：
     - 状态变量：glucoseLevel (3.0-12.0 mmol/L)
     - 映射关系：glucoseLevel → insulinHeight (10-100px) → moleculeCount (2-15)
     - 公式：insulinHeight = (glucoseLevel - 3) / 9 * 90 + 10
     - 公式：moleculeCount = Math.floor((glucoseLevel - 3) / 9 * 13) + 2

  2. 坐标计算：
     - 滑块手柄 x = 80 + (glucoseLevel - 3) / 9 * 100
     - 柱状图高度 = insulinHeight
     - 分子位置：在 (520-620, 180-220) 区域内随机分布，数量=moleculeCount

  3. 动画曲线：使用 requestAnimationFrame 实现平滑过渡，拖拽时实时更新

  4. 事件绑定：
     - mousedown/mousemove/mouseup 实现拖拽
     - touchstart/touchmove/touchend 支持移动端

  5. ID 命名规范：所有元素 ID 以 scene2- 为前缀
     - scene2-slider-track, scene2-slider-handle, scene2-glucose-value
     - scene2-rect-yi, scene2-line-jia, scene2-line-bing
     - scene2-bar-insulin, scene2-molecules-group, scene2-status-text

  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染

  7. 颜色应用：
     - 血糖/滑块：#1565c0（蓝色）
     - 胰岛素/柱状图/分子：#2e7d32（绿色）
     - 高血糖状态：#c62828（红色）
     - 正常状态：#2e7d32（绿色）
     - 低血糖状态：#1565c0（蓝色）
