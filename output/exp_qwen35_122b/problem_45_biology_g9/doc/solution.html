problem_45_biology_g9

场景导航：Scene 1

题目原文：
下图是血液流经某器官的示意图，下列表述正确的是（ ）

A．b表示心脏，则C血管里流的是静脉血
B．b表示肺，则C血管里流的是静脉血
C．b表示小肠，则C血管里流的是动脉血
D．b表示组织细胞，则C血管里流的是静脉血

题目分析：
本题考察血液循环系统中血液成分的变化规律。图示展示了血液流动的基本模式：血管 a（流入）→ 器官 b → 血管 c（流出）。

核心知识点：

  1. 动脉血与静脉血的定义：动脉血含氧量高（鲜红色），静脉血含氧量低（暗红色）
  2. 肺循环：肺动脉（静脉血）→ 肺毛细血管（气体交换）→ 肺静脉（动脉血）
  3. 体循环：动脉（动脉血）→ 组织毛细血管（气体交换）→ 静脉（静脉血）
  4. 心脏的血液流动：上下腔静脉→右心房→右心室→肺动脉（静脉血）；肺静脉→左心房→左心室→主动脉（动脉血）

讲解思路：
教师应引导学生理解：血液流经器官时是否发生气体交换，决定了流出血管的血液类型。肺部进行氧气摄取（静脉血→动脉血），组织器官进行氧气消耗（动脉血→静脉血）。

图示规划：
设计一个多状态切换图示，展示血液流经四种不同器官（心脏、肺、小肠、组织细胞）时的血液类型变化，帮助学生对比理解。

教学说明：

本图示通过多状态切换，帮助学生直观理解血液流经不同器官时的变化规律。

讲解步骤：

  1. 初始状态讲解：首先展示基础结构，让学生理解图示含义——血液从血管 a 流入器官 b，经过器官后从血管 c 流出。
  1. 肺循环讲解（状态 1）：
  • 切换至"肺"状态
  • 强调：血液流经肺部时进行气体交换，从肺动脉（静脉血）流入，从肺静脉（动脉血）流出
  • 学生观察：血管 a 为蓝色（静脉血），血管 c 为红色（动脉血）
  • 结论：选项 B 错误（c 血管流动脉血，不是静脉血）
  1. 组织细胞讲解（状态 2）：
  • 切换至"组织细胞"状态
  • 强调：血液流经组织时，氧气被组织细胞利用，从动脉（动脉血）流入，从静脉（静脉血）流出
  • 学生观察：血管 a 为红色（动脉血），血管 c 为蓝色（静脉血）
  • 结论：选项 D 正确
  1. 小肠讲解（状态 3）：
  • 切换至"小肠"状态
  • 强调：小肠属于组织器官，血液变化规律与组织细胞相同
  • 学生观察：血管 a 为红色（动脉血），血管 c 为蓝色（静脉血）
  • 结论：选项 C 错误（c 血管流静脉血，不是动脉血）
  1. 心脏讲解（状态 4）：
  • 切换至"心脏"状态
  • 强调：心脏作为血液循环的泵，需要区分体循环和肺循环
  • 体循环：上下腔静脉（静脉血）→ 心脏 → 主动脉（动脉血）
  • 肺循环：肺静脉（动脉血）→ 心脏 → 肺动脉（静脉血）
  • 结论：选项 A 表述不准确，因为心脏有多个出入口，血液类型取决于具体路径

关键公式/结论：

  • 肺循环：静脉血 → 肺 → 动脉血
  • 体循环：动脉血 → 组织 → 静脉血
  • 正确答案：D

课堂建议：
教师可先让学生预测各选项的正误，然后通过切换图示验证。重点强调气体交换的方向和血液颜色变化的对应关系。
