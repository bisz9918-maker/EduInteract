[图示主题与整合说明]
- 本图示主题：血液流经不同器官时的血液类型变化对比
- 整合内容：整合四种器官情况（肺、组织细胞、小肠、心脏）的血液流动与气体交换对比
- 教学价值：教师可通过切换不同器官状态，让学生直观观察血液颜色变化和气体交换情况，快速理解各选项的正误。重点对比肺循环（静脉血→动脉血）与体循环（动脉血→静脉血）的差异

[分步序列]
本场景采用多状态切换交互，非分步导航：

状态 0（初始）：
- 显示基础结构：血管 a → 器官 b → 血管 c
- 器官 b 显示"？"（待选择）
- 血管 a 和 c 为灰色填充（未确定）
- 无气体交换箭头
- 四个状态按钮均无高亮

状态 1（点击"肺"按钮）：
- 器官 b 显示"肺"
- 血管 a 填充蓝色（静脉血），标签"肺动脉（静脉血）"
- 血管 c 填充红色（动脉血），标签"肺静脉（动脉血）"
- 显示 O₂箭头（从肺泡进入血液）和 CO₂箭头（从血液排出到肺泡）
- 器官内部显示肺泡结构（小圆圈群）
- 结论文本："选项 B 错误：肺循环中，C 血管（肺静脉）流的是动脉血"
- "肺"按钮蓝色边框高亮

状态 2（点击"组织细胞"按钮）：
- 器官 b 显示"组织细胞"
- 血管 a 填充红色（动脉血），标签"动脉（动脉血）"
- 血管 c 填充蓝色（静脉血），标签"静脉（静脉血）"
- 显示 O₂箭头（从血液进入组织）和 CO₂箭头（从组织进入血液）
- 器官内部显示毛细血管网（灰色虚线）
- 结论文本："选项 D 正确：组织细胞处，C 血管（静脉）流的是静脉血"
- "组织细胞"按钮蓝色边框高亮

状态 3（点击"小肠"按钮）：
- 器官 b 显示"小肠"
- 血管 a 填充红色（动脉血），标签"肠动脉（动脉血）"
- 血管 c 填充蓝色（静脉血），标签"肠静脉（静脉血）"
- 显示 O₂箭头和 CO₂箭头（同组织细胞）
- 器官内部显示毛细血管网和绒毛结构
- 结论文本："选项 C 错误：小肠处，C 血管（肠静脉）流的是静脉血"
- "小肠"按钮蓝色边框高亮

状态 4（点击"心脏"按钮）：
- 器官 b 显示"心脏"
- 血管 a 和 c 根据循环类型区分：
  - 若 a 为肺静脉→左心房：a 红色，c（主动脉）红色
  - 若 a 为上下腔静脉→右心房：a 蓝色，c（肺动脉）蓝色
- 器官内部显示心腔结构（四腔示意）
- 结论文本："选项 A 错误：心脏作为泵，C 血管血液类型取决于具体循环路径"
- "心脏"按钮蓝色边框高亮

[交互方案]
- 交互类型：多状态切换（4 个状态按钮）
- 控件说明：
  - 按钮 1"肺"：位置(150,430)-(250,470)，切换到肺循环状态
  - 按钮 2"组织细胞"：位置(270,430)-(370,470)，切换到组织气体交换状态
  - 按钮 3"小肠"：位置(390,430)-(490,470)，切换到小肠气体交换状态
  - 按钮 4"心脏"：位置(510,430)-(610,470)，切换到心脏循环状态
- 教师操作流程：
  1. 初始状态展示基础结构，引导学生观察血流方向（a→b→c）
  2. 点击"肺"按钮，讲解肺循环：静脉血→肺→动脉血，指出选项 B 错误
  3. 点击"组织细胞"按钮，讲解体循环：动脉血→组织→静脉血，指出选项 D 正确
  4. 点击"小肠"按钮，对比小肠与组织细胞的气体交换相同，指出选项 C 错误
  5. 点击"心脏"按钮，说明心脏作为泵的特殊性，指出选项 A 错误
  6. 总结：正确答案为 D

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何和状态切换，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    图示区 800×500                       │
  │                                                         │
  │   a                    b                    c          │
  │  ┌──┐              ┌───────┐              ┌──┐         │
  │  │  │══════════════│  肺   │══════════════│  │         │
  │  │  │   静脉血      │       │   动脉血      │  │         │
  │  └──┘              └───────┘              └──┘         │
  │   ↑                  O₂↑↓CO₂              ↑            │
  │                                                         │
  │  结论：选项 B 错误：肺循环中，C 血管流的是动脉血            │
  │                                                         │
  │  [  肺  ] [组织细胞] [  小肠  ] [  心脏  ]              │
  │                                                         │
  └─────────────────────────────────────────────────────────┘
  ```

- 关键实现要点：
  1. 状态机设计：使用变量 currentStatus（0-4）跟踪当前状态
  2. 坐标计算：所有元素使用固定像素坐标，确保布局一致
  3. 颜色切换：通过修改 SVG fill 属性实现血液颜色变化
  4. 元素显示/隐藏：通过 setAttribute('display', 'none'|'block') 控制气体箭头和内部结构
  5. 按钮高亮：通过添加/移除 class 'active'实现蓝色边框
  6. 结论文本更新：根据状态动态更新结论内容

- ID 命名规范：所有交互元素 ID 以"scene1-"为前缀
  - 血管：scene1-vessel-a, scene1-vessel-c
  - 器官：scene1-organ-b
  - 填充：scene1-fill-a, scene1-fill-c, scene1-fill-organ
  - 箭头：scene1-arrow-o2, scene1-arrow-co2
  - 标签：scene1-label-a, scene1-label-c, scene1-label-o2, scene1-label-co2
  - 器官名：scene1-organ-name
  - 血管类型标签：scene1-vessel-type-a, scene1-vessel-type-c
  - 结论文本：scene1-conclusion
  - 按钮：scene1-btn-lung, scene1-btn-tissue, scene1-btn-intestine, scene1-btn-heart

- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
