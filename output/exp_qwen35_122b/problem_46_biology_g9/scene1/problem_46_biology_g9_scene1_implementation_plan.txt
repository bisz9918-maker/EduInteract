[交互方案]

- 控件说明：
  - 上一步按钮（scene1-prev-btn）：位于控件栏左侧，点击返回上一状态，步骤 0 时禁用
  - 下一步按钮（scene1-next-btn）：位于控件栏右侧，点击进入下一状态，步骤 4 时禁用
- 教师操作流程：

  2. 点击"下一步"→ 高亮磷酸二酯键，讲解限制酶和 DNA 连接酶的作用位点
  3. 点击"下一步"→ 高亮氢键，讲解解旋酶的作用位点
  4. 点击"下一步"→ 显示碱基配对规则，强调 A-T 双氢键、G-C 三氢键
  5. 点击"下一步"→ 显示碱基比例计算推导，结合题目条件 C=30% 进行计算
  6. 可随时点击"上一步"回退复习任一知识点

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无需额外库，SVG 原生支持足够实现所有图形和动画）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    DNA 分子结构示意图                    │
  │                                                         │
  │    ①磷酸二酯键                                          │
  │       ↓                                                 │
  │    C──T──G──C───────────────C──T──T──A    上链 (y=200)  │
  │    │  │  │  │               │  │  │  │                 │
  │    │  │  │  │   ─ ─ ─ ─     │  │  │  │   氢键②         │
  │    │  │  │  │               │  │  │  │                 │
  │    G──A──C──G───────────────G──A──A──T    下链 (y=280)  │
  │                                                         │
  │  ┌─────────────────────────────────────────────────┐   │
  │  │ 已知：C = 30%                                   │   │
  │  │ 根据碱基互补配对：                              │   │
  │  │ G = C = 30% → C+G = 60%                         │   │
  │  └─────────────────────────────────────────────────┘   │
  │                                                         │
  │  ┌────────┐  ┌────────┐                                │
  │  │ 上一步 │  │ 下一步 │                                │
  │  └────────┘  └────────┘                                │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-4) 跟踪当前步骤，每一步对应一个状态配置对象
  2. 坐标计算：所有元素坐标按布局坐标表精确实现，使用 SVG 绝对坐标
  3. 高亮动画：使用 CSS transition 实现颜色渐变（0.3s ease），高亮元素添加 class "highlight-blue"、"highlight-red"、"highlight-green"
  4. 元素显示/隐藏：使用 CSS display 或 opacity 控制计算框和新增文字的显示
  5. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 renderStep() 重绘
  6. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-dna-top、scene1-annotation-1、scene1-prev-btn）
  7. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  8. 氢键线绘制：C-G 对绘制 3 条平行线（y 偏移 2px），A-T 对绘制 2 条平行线
  9. 省略区处理：用虚线矩形表示中间省略的碱基对，避免画布过长
