[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - scene2-prev-btn：位于(300,455)，100×30px，点击返回上一步，步骤0时禁用
  - scene2-next-btn：位于(400,455)，100×30px，点击进入下一步，步骤5时禁用
- 教师操作流程：
  1. 初始展示亲代DNA（$^{15}$N标记），讲解亲代DNA结构
  2. 点击"下一步"展示解旋过程，讲解解旋酶作用于氢键
  3. 点击"下一步"展示新链合成，讲解以$^{14}$N为原料
  4. 点击"下一步"展示第一代，讲解半保留复制（每个DNA含1条旧链+1条新链）
  5. 点击"下一步"展示第二代，讲解杂合DNA与全新DNA的比例
  6. 点击"下一步"展示第n代，讲解2^n总数与2个含$^{15}$N的规律
  7. 可随时点击"上一步"回退复习关键步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │                    DNA半保留复制过程                           │  y=15
  │                                                                │
  │  亲代DNA    [解旋]    [新链合成]    子一代    子二代    子n代   │  y=50-400
  │  ══════     ══╦══     ══╦══      ══════    ══════    ══════   │
  │  ══════     ══╩══     ══╩══      ══════    ══════    ══════   │
  │                                                                │
  │  ┌────────────────────────────────────────────────────────┐   │
  │  │                    数量统计                            │   │  y=30-400
  │  │  DNA总数：X                                            │   │
  │  │  含¹⁵N数量：Y                                          │   │
  │  │  含¹⁴N数量：Z                                          │   │
  │  │  含¹⁴N比例：P%                                         │   │
  │  └────────────────────────────────────────────────────────┘   │
  │                                                                │
  │              [◀ 上一步]    [下一步 ▶]                          │  y=440-490
  └────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：currentStep变量(0-5)，updateScene()函数根据currentStep显示/隐藏对应元素
  2. 坐标计算：所有元素使用绝对定位，通过CSS transform或直接设置x/y属性
  3. 动画曲线：使用CSS transition实现平滑过渡（opacity, transform）
  4. 事件绑定：按钮点击事件监听，更新currentStep后调用updateScene()
  5. 统计框动态更新：根据currentStep计算DNA总数、含$^{15}$N数量、含$^{14}$N数量、比例
  6. 颜色编码：蓝色#1565c0表示$^{15}$N旧链，绿色#2e7d32表示$^{14}$N新链，红色#c62828表示解旋酶作用位置
  7. MathJax集成：用于渲染$^{15}$N、$^{14}$N等上标符号
- ID 命名规范：所有交互元素ID以"scene2-"为前缀（如scene2-dna-parent, scene2-prev-btn, scene2-next-btn）
- IIFE 隔离：所有JS代码包裹在(function() { ... })()中，避免全局污染
