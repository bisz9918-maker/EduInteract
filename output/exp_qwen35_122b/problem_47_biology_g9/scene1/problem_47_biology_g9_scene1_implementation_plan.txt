[图示主题与整合说明]
- 本图示主题：肾单位结构与尿液形成过程
- 整合内容：整合了肾小球、肾小囊（甲）、肾小管（乙）三个结构，以及原尿（a）、尿液（b）两种液体的形成过程，涵盖过滤作用和重吸收作用两个核心生理过程

[分步序列]
- 步骤 0（初始状态）：显示肾单位整体结构（肾小球、肾小囊、肾小管、入球/出球小动脉、肾小管周围毛细血管），显示左右标题，显示流程框（血液、甲、a、乙、b）但无箭头和高亮。所有结构标签可见。
- 步骤 1：高亮入球小动脉和出球小动脉（红色加粗），显示血液流动箭头，在肾小球处显示"血液进入"提示文字。流程区"血液"框高亮红色。
- 步骤 2：显示过滤作用箭头（蓝色，从肾小球指向肾小囊内部），肾小球和肾小囊高亮蓝色，显示"过滤作用"标签。流程区"甲"框高亮蓝色，箭头 1 显示。
- 步骤 3：原尿 a 高亮蓝色，在肾小囊与肾小管连接处显示"原尿形成"提示，肾小囊内显示小水滴图标表示原尿。流程区箭头 2 显示，"a"标签高亮。
- 步骤 4：显示重吸收箭头（绿色，从肾小管指向周围毛细血管），肾小管高亮绿色，显示"重吸收作用"标签。流程区"乙"框高亮绿色，箭头 3 显示。
- 步骤 5：尿液 b 高亮绿色，在肾小管末端显示"尿液形成"提示，肾小管末端显示小水滴图标表示尿液。流程区箭头 4 显示，"b"标签高亮。
- 步骤 6（结论）：所有箭头和标签同时显示，左右视图完整呈现，在底部显示总结文字"尿液形成：血液→过滤→原尿→重吸收→尿液"。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "上一步"按钮：ID scene1-prev-btn，位置 (280,450)，点击返回上一状态，步骤 0 时禁用
  - "下一步"按钮：ID scene1-next-btn，位置 (620,450)，点击进入下一状态，步骤 6 时禁用
  - 步骤指示器：ID scene1-step-indicator，位置 (400,420)，显示"步骤 X/6"
- 教师操作流程：
  1. 初始展示肾单位完整结构，教师介绍各部分名称
  2. 点击"下一步"，展示血液流动，讲解入球/出球小动脉
  3. 点击"下一步"，展示过滤作用，讲解肾小球过滤功能
  4. 点击"下一步"，展示原尿形成，讲解原尿成分
  5. 点击"下一步"，展示重吸收作用，讲解肾小管重吸收功能
  6. 点击"下一步"，展示尿液形成，讲解最终尿液成分
  7. 结论状态展示完整流程，教师总结尿液形成全过程
  8. 可随时点击"上一步"回退复习特定步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何和动画首选，无需额外依赖）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │  肾单位结构                    尿液形成流程                     │
  │  (120,30)                    (500,30)                          │
  │                                                                  │
  │     入球小动脉                                                      │
  │        ↓                                                          │
  │    ┌─────────┐  肾小球  ┌─────────┐  出球小动脉                   │
  │    │  肾小囊  │ ─────→ │         │ ─────→                        │
  │    │   (甲)  │          └─────────┘                               │
  │    └────┬────┘                                                    │
  │         ↓ 过滤作用                                                 │
  │    ┌────┴────┐                                                    │
  │    │ 肾小管  │                                                   │
  │    │  (乙)  │ ───→ 重吸收 → 毛细血管网                             │
  │    └────┬────┘                                                    │
  │         ↓ 尿液形成                                                 │
  │                                                                  │
  │  血液 ─→ 甲 ─→ a ─→ 乙 ─→ b                                       │
  │  (460)   (560)  (650) (680) (770)                                 │
  │                                                                  │
  │              步骤 X/6                                             │
  │         [◀ 上一步]    [下一步 ▶]                                  │
  │        (280,450)      (620,450)                                  │
  └────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-6) 跟踪当前步骤，每个步骤定义需要显示/高亮的元素 ID 列表
  2. 坐标计算：所有元素使用绝对坐标，SVG 元素通过 x/y/cx/cy 属性精确控制位置
  3. 动画曲线：使用 CSS transition 实现高亮效果（0.3s ease），箭头使用 stroke-dasharray 动画实现流动效果
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateScene() 函数刷新显示
  5. 禁用状态：步骤 0 时上一步按钮 disabled，步骤 6 时下一步按钮 disabled
  6. 高亮效果：通过添加/移除 CSS 类（如 .highlight-blue, .highlight-green）实现颜色变化
  7. 箭头动画：使用 requestAnimationFrame 更新 stroke-dashoffset 实现流动动画
- ID 命名规范：所有交互元素 ID 以 scene1- 为前缀，如 scene1-kidney-glomerulus、scene1-prev-btn、scene1-next-btn、scene1-step-indicator
- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染
