[分步序列]
- 步骤0（初始状态）：
  - 显示：所有经纬线（4条经线、3条纬线）
  - 不显示：M点、N点、点标签、问题提示
  - 目的：让学生先观察经纬网结构

- 步骤1：
  - 新增显示：M点（实心圆）及标签"M"
  - 显示：经度标注"80°"、纬度标注"60°"
  - 目的：标注M点位置（80°E, 60°N）

- 步骤2：
  - 新增显示：N点（实心圆）及标签"N"
  - 显示：经度标注"120°"、纬度标注"40°"
  - 目的：标注N点位置（120°E, 60°N），完成两点定位

- 步骤3（最终步骤）：
  - 新增显示：问题提示框及文字"最短航线：大圆劣弧方向？"
  - 目的：引导学生思考最短航线问题，为后续分析做铺垫

[标签冲突检查]
- 标签"80°"：坐标(190,70)
- 标签"120°"：坐标(585,70)
- 标签"60°"：坐标(720,145)
- 标签"40°"：坐标(720,295)
- 标签"M"：坐标(210,170)
- 标签"N"：坐标(610,170)

逐对检查：
- "80°"与"120°"：水平间距 395px → 无冲突
- "80°"与"M"：距离约 sqrt(20²+100²)≈102px → 无冲突
- "80°"与"60°"：距离约 sqrt(530²+75²)≈535px → 无冲突
- "120°"与"N"：距离约 sqrt(25²+80²)≈84px → 无冲突
- "120°"与"60°"：距离约 sqrt(135²+75²)≈154px → 无冲突
- "60°"与"40°"：垂直间距 150px → 无冲突
- "M"与"N"：水平间距 400px → 无冲突
- "M"与"60°"：距离约 sqrt(510²+25²)≈511px → 无冲突
- "N"与"60°"：距离约 sqrt(110²+25²)≈113px → 无冲突

结论：所有标签间距均≥80px，无冲突。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 按钮"◀ 上一步"：位于控件栏左侧，ID=scene1-btn-prev，作用：返回上一状态
  - 按钮"下一步 ▶"：位于控件栏右侧，ID=scene1-btn-next，作用：进入下一状态
  - 状态指示器：位于控件栏中央，显示"步骤 X/3"，ID=scene1-step-indicator
- 教师操作流程：
  1. 初始展示经纬网，让学生观察网格结构
  2. 点击"下一步"，标注M点坐标，讲解M点位置
  3. 点击"下一步"，标注N点坐标，对比两点位置关系
  4. 点击"下一步"，显示问题提示，引导学生思考最短航线方向
  5. 可随时点击"上一步"回退复习，巩固坐标识别

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    经纬网示意图                          │
  │                                                         │
  │     80°                    120°                         │
  │      │                      │                           │
  │  ────┼──────────────────────┼────────────────────── 60° │
  │      ● M                   ● N                          │
  │      │                      │                           │
  │  ────┼──────────────────────┼────────────────────── 40° │
  │      │                      │                           │
  │                                                         │
  │  ┌─────────────────────────────────────────────────┐   │
  │  │  最短航线：大圆劣弧方向？                        │   │
  │  └─────────────────────────────────────────────────┘   │
  │                                                         │
  │           [◀ 上一步]    步骤 X/3    [下一步 ▶]          │
  └─────────────────────────────────────────────────────────┘
  ```

- 关键实现要点：
  1. 状态机设计：使用变量 currentStep（0-3）跟踪当前步骤
  2. 元素分组：将M点、N点、标签、提示框分别分组，按步骤控制显示/隐藏
  3. 坐标计算：经线间距 200px（80°E→200px, 120°E→600px），纬线间距 150px（60°N→150px, 40°N→300px）
  4. 动画曲线：元素出现使用淡入动画（opacity: 0→1，duration 300ms）
  5. 事件绑定：按钮点击事件监听，更新 currentStep 并刷新显示
  6. ID 命名规范：所有交互元素 ID 以 scene1- 为前缀（如 scene1-m-point, scene1-n-point, scene1-btn-prev, scene1-btn-next, scene1-step-indicator）
  7. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
