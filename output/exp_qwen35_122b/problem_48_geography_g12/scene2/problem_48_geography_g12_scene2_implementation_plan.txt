[分步序列]
- 步骤 0（初始状态）：
  - 显示：主视图经纬网（所有经线、纬线、标签）
  - 显示：M 点、N 点及其标签
  - 显示：纬线航线（灰色虚线，表示沿 60°N 纬线飞行）
  - 隐藏：大圆航线、方向箭头、副视图、M' 点、地心连线
  - 目的：展示题目基础条件，M 与 N 在同一纬线上

- 步骤 1：
  - 新增：大圆航线（绿色实线弧线，从 M 到 N，向北弯曲）
  - 高亮：大圆航线比纬线航线更短（视觉上弧线长度更短）
  - 目的：展示最短航线是大圆航线，而非纬线

- 步骤 2：
  - 新增：三个方向箭头及标签（东北、正东、东南）
  - 高亮：箭头沿大圆航线依次显示，展示飞行方向变化
  - 目的：解释为何方向是"先东北→正东→东南"

- 步骤 3：
  - 新增：副视图（地球轮廓）
  - 新增：M' 点（#c62828 圆点）
  - 新增：地心连线（M 到 M' 的虚线）
  - 目的：展示地心对称点的空间位置关系

- 步骤 4（最终步骤）：
  - 新增：M' 坐标标注"(60°S, 100°W)"
  - 高亮：M 点 (60°N, 80°E) 与 M' 点 (60°S, 100°W) 的坐标对比
  - 目的：总结地心对称点规律：纬度相反（60°N→60°S），经度相差 180°（80°E→100°W）

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮（scene2-prev）：位于 (250,455)，点击返回上一步，步骤 0 时禁用
  - 下一步按钮（scene2-next）：位于 (470,455)，点击进入下一步，步骤 4 时禁用
- 教师操作流程：
  1. 初始展示 M、N 点及纬线航线，提问"飞机沿纬线飞行是否最短？"
  2. 点击下一步，展示大圆航线，引导学生观察弧线更短
  3. 点击下一步，展示方向箭头，讲解"先东北→正东→东南"的方向变化原因
  4. 点击下一步，展示副视图和 M' 点，引入地心对称点概念
  5. 点击下一步，展示 M' 坐标，总结对称点规律

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（直线、弧线、圆点），原生 SVG 足够且性能最佳，无需引入重型库

- 画布尺寸：800 × 500 px（固定）

- 布局草图（ASCII）：
```
┌────────────────────────────────────────────────────────────────┐
│  80°    100°   120°   140°                                     │
│   │      │      │      │                                       │
│   ● M    │      ● N    │         ┌──────────────────┐          │
│   │      │      │      │         │   副视图区域     │          │
│   │  大圆航线(弧线)    │         │      (60°S,      │          │
│   │  ↗→→→→→→→↘         │         │     100°W)       │          │
│   │  东北 正东 东南     │         │        ● M'      │          │
│   │──────────────────  │         │                  │          │
│   │  纬线航线(虚线)    │         └──────────────────┘          │
│   40°                                                        │
├────────────────────────────────────────────────────────────────┤
│                    [◀上一步]        [下一步▶]                   │
└────────────────────────────────────────────────────────────────┘
```

- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-4) 跟踪当前步骤，updateScene() 函数根据 currentStep 显示/隐藏对应元素
  2. 坐标计算：所有元素坐标已在布局坐标表中精确定义，直接硬编码
  3. 动画曲线：大圆航线用 SVG 贝塞尔曲线<path d="M100,140 C150,70 250,70 300,140"/>实现
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateScene()
  5. 元素显示控制：用 CSS class "hidden" (display: none) 控制元素显隐

- ID 命名规范：
  - 所有交互元素 ID 以 scene2- 为前缀
  - 示例：scene2-m-point, scene2-n-point, scene2-great-circle, scene2-arrow1, scene2-m-prime, scene2-prev, scene2-next

- IIFE 隔离：
  ```javascript

  ```
