[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────┐
  │                                                     │
  │         左侧纬度推导区        右侧经度推导区         │
  │         (150-250,250-350)    (550-650,250-350)     │
  │                                                     │
  │              ┌───────── 南极俯视图 ─────────┐       │
  │              │         (300-500,120-480)    │       │
  │              │                              │       │
  │              │      O(南极点)               │       │
  │              │     /    |    \              │       │
  │              │    /     |M    \             │       │
  │              │   /  70°S纬线  \            │       │
  │              │  /______________\           │       │
  │              └──────────────────────────────┘       │
  │                                                     │
  │        最终坐标框 (320-480,450-480)                 │
  │                                                     │
  │  [◀ 上一步]  [步骤 1/5]  [下一步 ▶]  (y=460)        │
  └─────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量 (0-4) 跟踪当前步骤，每个步骤定义要显示/高亮的元素 ID 列表
  2. 坐标计算：所有元素使用绝对坐标，SVG 元素通过 setAttribute 动态控制显示/隐藏
  3. 动画曲线：使用 CSS transition 实现元素淡入淡出（opacity: 0→1，duration: 0.3s）
  4. 事件绑定：按钮点击事件更新 currentStep，调用 updateScene() 刷新显示
  5. ID 命名规范：所有元素 ID 以"scene2-"为前缀（如 scene2-point-O、scene2-arc-70s、scene2-line-ob 等）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染
  7. 步骤切换逻辑：updateScene() 函数根据 currentStep 显示对应元素，隐藏其他元素
