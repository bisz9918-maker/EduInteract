[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮（scene3-btn-prev）：位于底部左侧，点击返回上一状态，初始步骤0时禁用
  - 下一步按钮（scene3-btn-next）：位于底部右侧，点击进入下一状态，最终步骤4时变为"完成"
- 教师操作流程：
  1. 初始展示公式，教师讲解正午太阳高度角的基本概念
  2. 点击"下一步"，展示太阳直射点和观测点，教师解释φ和δ的含义
  3. 点击"下一步"，展示纬度差计算，教师引导学生理解绝对值的意义
  4. 点击"下一步"，展示最终计算结果，教师强调结果的实际意义
  5. 点击"下一步"，补充地方时计算说明，完成完整讲解
  6. 可随时点击"上一步"回退复习关键步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何和文本展示，无需复杂库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │                        正午太阳高度角计算                       │  y=30
  │                    H = 90° - |φ - δ|                           │  y=70
  │                                                                │
  │   ┌─────────────┐                                              │
  │   │   地球侧视   │         计算步骤区                          │
  │   │    示意图    │         步骤0: 公式                         │
  │   │             │         步骤1: 已知条件                      │
  │   │  ●观测点    │         步骤2: 代入计算                      │
  │   │   ●直射点   │         步骤3: 结果                         │
  │   │             │         步骤4: 地方时说明                    │
  │   └─────────────┘         ┌──────────────┐                    │
  │                           │ H = 39.5°    │                    │
  │                           └──────────────┘                    │
  │                                                                │
  │              [◀ 上一步]        [下一步 ▶]                      │  y=465
  └────────────────────────────────────────────────────────────────┘
  ```

- 关键实现要点：
  1. 状态机设计：使用变量 currentStep（0-4）跟踪当前步骤，每一步对应一个状态对象，包含该步骤应显示/隐藏的元素的ID列表
  2. 坐标计算：所有元素使用绝对定位，SVG 内元素使用 x/y 属性精确控制
  3. 动画曲线：使用 CSS transition 实现淡入效果（opacity: 0→1，duration: 0.3s）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 renderStep() 函数刷新显示
  5. ID 命名规范：所有交互元素 ID 以 scene3- 为前缀（如 scene3-earth, scene3-sun-point, scene3-obs-point, scene3-btn-prev, scene3-btn-next）
  6. JS 隔离：所有代码包裹在 (function() { ... })() IIFE 中，避免全局污染
  7. 按钮状态管理：步骤0时禁用上一步按钮，步骤4时下一步按钮变为"完成"并禁用

- 元素 ID 列表（scene3- 前缀）：

  - scene3-formula: 公式主体

  - scene3-obs-point: 观测点
  - scene3-latitude-sun: 直射点纬度线
  - scene3-latitude-obs: 观测点纬度线
  - scene3-latitude-diff: 纬度差弧线
  - scene3-latitude-diff-label: 纬度差标签
  - scene3-step-texts: 步骤文本组（4个文本元素）
  - scene3-result-box: 结果框
  - scene3-result-text: 结果文本
  - scene3-btn-prev: 上一步按钮
