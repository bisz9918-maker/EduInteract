[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "上一步"按钮：scene1-prev-btn，位于(250,465)，点击返回上一状态
  - "下一步"按钮：scene1-next-btn，位于(470,465)，点击进入下一状态
  - 步骤指示器：scene1-step-text，位于(365,468)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始展示完整电路图，讲解电路元件布局
  2. 点击"下一步"，开关S闭合，高亮正极→D路径，讲解电流从正极出发
  3. 点击"下一步"，高亮导线b（D→B），强调这是短路关键路径
  4. 点击"下一步"，高亮导线M（B→开关→负极），完成短路回路
  5. 点击"下一步"，灯泡变灰，显示短路警告，讲解灯泡被短路不发光
  6. 点击"下一步"，显示结论，指出选项B错误
  7. 可随时点击"上一步"回退复习某一步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（电路图为几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    [图示区 800×500]                     │
  │                                                         │
  │              ┌─────────────────────────┐               │
  │              │      电池组 (+/-)       │               │
  │              └─────────────────────────┘               │
  │                    │        │                          │
  │                    │        │导线1                     │
  │                    │        ↓                          │
  │              ┌─────────────────────────┐               │
  │              │   L₂ (C)───a───(A) L₁   │               │
  │              │      │         │        │               │
  │              │      b         │        │               │
  │              │      ↓         │        │               │
  │              │    (D)       (B)───M────┘               │
  │              └─────────────────────────┘               │
  │                    │                                    │
  │              ┌─────────────────────────┐               │
  │              │      开关 S             │               │
  │              └─────────────────────────┘               │
  │                                                         │
  │        [上一步]  步骤 X/5  [下一步]  ← 控件栏           │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：currentStep变量(0-5)，updateScene()函数根据currentStep更新元素样式
  2. 坐标计算：所有元素使用绝对坐标，导线用<path>元素绘制贝塞尔曲线
  3. 动画曲线：导线高亮使用transition(0.3s ease)实现平滑颜色变化
  4. 事件绑定：按钮click事件调用prevScene()/nextScene()，更新currentStep后调用updateScene()
  5. ID命名规范：所有元素ID以"scene1-"为前缀（如scene1-battery、scene1-switch、scene1-lamp1等）
  6. IIFE隔离：所有JS代码包裹在(function() { ... })()中，避免全局污染
  7. 导线绘制：使用<path>元素，d属性为贝塞尔曲线路径，确保导线走向自然
  8. 电流箭头：使用<marker>定义箭头标记，配合<path>虚线显示电流方向
  9. 灯泡状态：通过切换灯丝stroke颜色实现发光/熄灭效果
  10. 开关状态：通过旋转闸刀<path>实现开/关视觉效果
