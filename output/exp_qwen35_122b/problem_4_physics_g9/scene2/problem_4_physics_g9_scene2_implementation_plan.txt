[图示主题与整合说明]
- 本图示主题：电路改造对比（串联与并联）
- 整合的步骤/概念：整合了两种电路改造方案——去掉导线 b 实现串联、导线 M 改接实现并联

[分步序列]
- 初始状态（状态 0）：显示原电路图
  - 所有导线为黑色实线
  - 导线 b 为实线（连接 D-B）
  - 导线 M 连接 B-开关
  - 无电流箭头（或显示红色短路警告）
  - 状态标签显示"原电路"
  - 灯泡不发光（短路状态）

- 状态 1（串联改造）：去掉导线 b
  - 导线 b 变为灰色虚线（表示已移除）
  - 导线 M 保持连接 B-开关
  - 显示蓝色电流路径：正极→D→C→A→B→M→开关→负极
  - 电流箭头沿路径分布：(550,120)→(450,120)→(450,300)→(550,300)→(220,350)→(80,350)→(80,100)
  - L1 和 L2 显示绿色发光效果
  - 状态标签显示"串联改造"

- 状态 2（并联改造）：导线 M 从 B 改接到 A
  - 导线 b 恢复为黑色实线（D-B）
  - 导线 M 原位置 (B-开关) 变为灰色虚线
  - 新增导线 M 新位置 (A-开关) 为黑色实线
  - 显示蓝色电流路径：正极→D 后分两路
    - 支路 1：D→B→M(原)→但 M 已改接，所以 D→B 无电流
    - 实际路径：正极→D→B（无，因为 M 改接）→重新分析
    - 正确路径：正极→D，D 分两路：D→C→A→M→开关 和 D→B（但 B 无连接）
    - 修正：正极→D→C→A→M→开关（L2 通路），同时正极→D→B（L1 右端，但 L1 左端 A 已接 M）
    - 实际并联：L2 路径 D→C→A→M，L1 路径 D→B→A→M（通过导线 a）
  - 显示两条蓝色支路电流箭头
  - L1 和 L2 显示绿色发光效果
  - 状态标签显示"并联改造"

[交互方案]
- 交互类型：多状态切换（3 个按钮）
- 控件说明：
  - 按钮"原电路"：位置 (200,460)，切换到状态 0，显示原始电路（短路状态）
  - 按钮"串联改造"：位置 (360,460)，切换到状态 1，显示去掉导线 b 后的串联电路
  - 按钮"并联改造"：位置 (530,460)，切换到状态 2，显示导线 M 改接后的并联电路
- 教师操作流程：
  1. 点击"原电路"展示题目原始电路图，引导学生分析短路原因
  2. 点击"串联改造"展示去掉导线 b 后的电路，讲解串联连接特点及电流路径
  3. 点击"并联改造"展示导线 M 改接后的电路，讲解并联连接特点及支路电流
  4. 可反复切换对比三种状态，强化串并联概念理解

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（电路图为几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │                        图示区 800×500                        │
  │                                                             │
  │   电池组                                                    │
  │   (80,60)-(280,140)                                         │
  │      │                                                      │
  │      │ 导线                                                 │
  │      ▼                                                      │
  │   ┌─────────┐                    ┌─────────┐               │
  │   │ 开关 S  │                    │  灯泡 L2 │               │
  │   │(80,320) │                    │(450,80) │               │
  │   └─────────┘                    └─────────┘               │
  │      │                              │  │                    │
  │      │ 导线 M                        │  │ 导线 a  b          │
  │      ▼                              ▼  ▼                    │
  │                              ┌─────────┐                    │
  │                              │  灯泡 L1 │                    │
  │                              │(450,260)│                    │
  │                              └─────────┘                    │
  │                                                             │
  │   ┌─────────────────────────────────────────────────────┐  │
  │   │  状态标签：[原电路] [串联改造] [并联改造]            │  │
  │   │  按钮：[原电路]  [串联改造]  [并联改造]             │  │
  │   └─────────────────────────────────────────────────────┘  │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 currentState (0/1/2) 跟踪当前状态
  2. 坐标计算：所有元素使用固定坐标，导线用 SVG <line> 元素
  3. 动画曲线：电流箭头使用 CSS transition 实现淡入淡出
  4. 事件绑定：三个按钮分别绑定 click 事件，切换 currentState 并更新视图
  5. ID 命名规范：所有元素 ID 以 scene2- 为前缀（如 scene2-battery、scene2-switch、scene2-lamp1、scene2-lamp2、scene2-wire-b、scene2-wire-m 等）
  6. 状态更新函数：updateScene(state) 根据状态显示/隐藏相应元素、改变导线样式、显示/隐藏电流箭头
  7. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  8. 电流箭头实现：使用 SVG <polygon> 绘制三角形，沿导线分布，通过 opacity 控制显示/隐藏
  9. 灯泡发光效果：使用 SVG <circle> 外圈，fill-opacity 控制发光强度
