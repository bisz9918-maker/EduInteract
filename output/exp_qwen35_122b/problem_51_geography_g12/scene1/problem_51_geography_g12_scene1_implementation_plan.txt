[图示主题与整合说明]
- 本图示主题：地球光照图基础认知——晨昏线、昼夜半球与自转方向

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 按钮"◀ 上一步"：位置(250,460)，作用：返回上一状态
  - 按钮"下一步 ▶"：位置(500,460)，作用：进入下一状态
  - 状态指示器：位置(370,465)，显示"步骤 X/4"
- 教师操作流程：
  1. 从步骤0开始，先让学生观察地球轮廓和 0°经线位置
  2. 点击"下一步"展示晨昏线和昼夜半球，引导学生识别分界线
  3. 点击"下一步"展示自转方向，讲解地球自转与光照关系
  4. 点击"下一步"标注 A/B/C 三点，准备进行后续分析
  5. 点击"下一步"进入结论，总结晨昏线特征
  6. 可随时点击"上一步"回退复习关键概念

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（椭圆、直线、弧线），SVG 矢量绘图清晰，无需复杂动画库
  - 状态切换通过 CSS display/opacity 控制，性能高效

- 画布尺寸：800 × 500 px

- 布局草图（ASCII）：

- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-4) 跟踪当前步骤
  2. 元素 ID 命名：所有元素以 scene1- 为前缀（如 scene1-ellipse, scene1-terminator, scene1-point-a）
  3. 显示控制：每个步骤对应一组元素的 display 属性切换
  4. 晨昏线绘制：使用 SVG path 绘制贝塞尔曲线 M200,150 Q180,250 200,350
  5. 昼夜半球：使用 clipPath 将椭圆分为左右两半分别填充
  6. 自转箭头：使用 SVG path 绘制弧线 + 箭头标记
  7. 按钮事件：绑定 click 事件，更新 currentStep 后重新渲染元素可见性
  8. 状态指示器：动态更新文本显示当前步骤
  9. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
