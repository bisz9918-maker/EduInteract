[图示主题与整合说明]
- 本图示主题：地转偏向力与自转线速度比较
- 整合内容：纬度与地转偏向力关系（f = 2ωv sinφ，随纬度增加而增大）、纬度与自转线速度关系（v = ωR cosφ，随纬度增加而减小）、A、B、C 三点对比
- 教学价值：教师可通过状态切换，直观展示同一地点在不同物理量下的规律差异，帮助学生理解地转偏向力和自转线速度随纬度变化的相反趋势

[分步序列]
- 初始状态（步骤 0）：显示地球椭圆、赤道线、北纬 30°线、北纬 60°线（灰色虚线）、A/B/C 三点（蓝色）、各点纬度标注。无箭头显示。结论区显示"请选择模式查看"。
- 状态 1（地转偏向力模式）：点击"地转偏向力"按钮 → 显示红色地转偏向力箭头（A 点最长 40px、B 点中等 25px、C 点最短 5px），箭头方向垂直于自转方向向外。结论区显示"f = 2ωv sinφ，纬度越高偏向力越大：A > B > C"。
- 状态 2（自转线速度模式）：点击"自转线速度"按钮 → 显示绿色自转线速度箭头（A 点最短 20px、B 点中等 35px、C 点最长 50px），箭头方向沿纬线切线方向。结论区显示"v = ωR cosφ，纬度越高线速度越小：C > B > A"。

[交互方案]
- 交互类型：多状态切换（2 个按钮 + 初始状态）
- 控件说明：
  - 按钮 1："地转偏向力" | 位置 (250,450)-(380,480) | 切换到状态 1，显示红色偏向力箭头
  - 按钮 2："自转线速度" | 位置 (420,450)-(550,480) | 切换到状态 2，显示绿色线速度箭头
- 教师操作流程：
  1. 初始展示地球和 A/B/C 三点位置，说明三点纬度不同
  2. 点击"地转偏向力"按钮，展示红色箭头，讲解 f = 2ωv sinφ，纬度越高偏向力越大
  3. 点击"自转线速度"按钮，展示绿色箭头，讲解 v = ωR cosφ，纬度越高线速度越小
  4. 对比两种规律，强调它们随纬度变化的相反趋势

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形和状态切换，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────┐
  │                                                         │
  │              地球椭圆 (400,250) rx=180 ry=100           │
  │                    ╭───────────╮                        │
  │                   ╱   A●       ╲                       │
  │                  ╱   ╱ 北纬 60°  ╲                      │
  │                 ╱   ╱   ●B       ╲                     │
  │                ╱   ╱   ╱ 北纬 30°  ╲                    │
  │               ╱   ╱   ╱   ●C       ╲                   │
  │              ╱   ╱   ╱   ╱ 赤道      ╲                  │
  │             ╰───────────────────────╯                   │
  │                                                         │
  │        右侧：模式标题 + 结论区 (650,100)-(770,300)      │
  │                                                         │
  │  底部控件栏 (y=450~480)：                               │
  │  [地转偏向力]        [自转线速度]                       │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  - 状态机：currentMode ∈ {0: 初始，1: 地转偏向力，2: 自转线速度}
  - 箭头绘制：使用 SVG <line> + <polygon> 组合，根据状态显示/隐藏对应箭头组
  - 箭头长度：地转偏向力 A=40, B=25, C=5；自转线速度 A=20, B=35, C=50
  - 事件绑定：按钮点击 → 更新 currentMode → 调用 render() 刷新显示
  - ID 命名规范：所有元素 ID 以 scene3- 为前缀（如 scene3-ellipse-earth, scene3-btn-coriolis, scene3-btn-velocity）
  - IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局污染
- 公式渲染：使用 MathJax CDN 渲染 f = 2ωv sinφ 和 v = ωR cosφ
