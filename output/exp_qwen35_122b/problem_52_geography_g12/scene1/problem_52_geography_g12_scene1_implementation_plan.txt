[分步序列]
- 步骤 0（初始状态）：显示基础半球图
  - 显示：左右半圆轮廓、赤道线、所有经线（灰色虚线）、所有纬线（灰色虚线）、N/S 极点、北半球/南半球文字标注
  - 隐藏：点 A/B/甲/乙/C、20°W/160°E 高亮线、阴影区域、所有点标签

- 步骤 1：标注 20°W 经线
  - 新增：20°W 经线高亮（蓝色实线 3px），显示 20°W 标签（上方和下方各一个）
  - 说明：20°W 是东西半球的分界线之一

- 步骤 2：标注 160°E 经线
  - 新增：160°E 经线高亮（蓝色实线 3px），显示 160°E 标签
  - 说明：160°E 是东西半球的另一条分界线

- 步骤 3：高亮 A 点经度
  - 新增：点 A 显示（红色实心圆点），A 标签显示
  - 高亮：160°E 经线再次闪烁
  - 说明：A 点位于 160°E 经线与赤道交点

- 步骤 4：高亮 B 点经度
  - 新增：点 B 显示（红色实心圆点），B 标签显示
  - 高亮：20°W 经线再次闪烁
  - 说明：B 点位于 20°W 经线与赤道交点

- 结论步骤：显示最终答案
  - 显示：所有点 A/B/甲/乙/C 及其标签
  - 显示：阴影区域（左半圆黑夜部分）
  - 结论文字：A = 160°E，B = 20°W

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮：scene1-btn-prev，位置 (280,455)，作用：返回上一步骤
  - 下一步按钮：scene1-btn-next，位置 (500,455)，作用：进入下一步骤
  - 步骤指示器：scene1-step-indicator，位置 (350,420)，显示"步骤 X/6"
- 教师操作流程：
  1. 从步骤 0 开始，展示基础半球图，让学生观察整体结构
  2. 点击"下一步"到步骤 1，讲解 20°W 经线的位置和意义
  3. 点击"下一步"到步骤 2，讲解 160°E 经线的位置和意义
  4. 点击"下一步"到步骤 3，引导学生判断 A 点经度
  5. 点击"下一步"到步骤 4，引导学生判断 B 点经度
  6. 点击"下一步"到结论，展示最终答案 A=160°E，B=20°W
  7. 可随时点击"上一步"回退复习

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    图示区 800×500                       │
  │                                                         │
  │     南半球                  北半球                      │
  │    (西半球)               (东半球)                      │
  │       S                         N                       │
  │      / \                       / \                      │
  │     /   \                     /   \                     │
  │    / 阴影 \                   /     \                   │
  │   /_______\_________________/_______\                  │
  │  甲 B      20°W    C      160°E      A                 │
  │                                                         │
  │           步骤指示器：步骤 0/6                          │
  │           [◀上一步]       [下一步▶]                     │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用 currentStep 变量跟踪当前步骤（0-6），每一步对应一个显示配置对象
  2. 坐标计算：所有元素坐标已在布局坐标表中精确定义，直接硬编码
  3. 动画曲线：经线高亮使用 CSS transition，opacity 从 0 到 1，duration 0.3s
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 renderStep() 重新渲染
  5. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-circle-right、scene1-line-20w、scene1-point-a）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 步骤配置：用数组存储每一步的显示配置，包含可见元素列表和标签显示状态
