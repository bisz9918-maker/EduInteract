[图示主题与整合说明]
- 本图示主题：长方体表面展开方式对比
- 整合内容：三种典型展开方式及其对应的A到F直线距离计算
- 教学价值：教师可通过按钮切换三种展开方式，直观展示长方体表面最短路径问题的多种解法，帮助学生理解"展开图法"求立体表面最短距离的核心思想，并通过比较三种结果找出最短路径

[分步序列]
本场景采用多状态切换交互（非分步导航），通过三个按钮切换三种展开方式：

- 初始状态（状态0）：显示标题和空白展开图容器，等待教师选择展开方式
- 状态1：点击"展开方式1：前面+右面"按钮
  - 显示前面(5×h)与右面(3×h)并排展开图
  - A点在前面左下角(200,320)，F点在右面右侧棱中点(440,200)
  - 绿色路径线连接A到F
  - 标注水平距离8cm、垂直距离6cm
  - 结果文本显示："√(8²+6²) = √100 = 10cm"
  - 显示绿色"✓ 最短路径：10cm"标记
- 状态2：点击"展开方式2：底面+右面"按钮
  - 显示底面(5×3)与右面(3×h)展开图
  - A点在底面左下角(200,250)，F点在右面右上角(290,160)
  - 黑色路径线连接A到F
  - 标注水平距离5cm、垂直距离9cm
  - 结果文本显示："√(5²+9²) = √106 ≈ 10.3cm"
  - 隐藏最短路径标记
- 状态3：点击"展开方式3：前面+顶面+右面"按钮
  - 显示前面(5×h)、顶面(5×3)、右面(3×h)展开图
  - A点在前面左下角(200,320)，F点在右面右侧棱中点(440,200)
  - 黑色路径线连接A到F
  - 标注水平距离11cm、垂直距离3cm
  - 结果文本显示："√(11²+3²) = √130 ≈ 11.4cm"
  - 隐藏最短路径标记

[交互方案]
- 交互类型：多状态切换（3个按钮）
- 控件说明：
  - 按钮1（scene2-btn-mode1）：位置(180,440)，作用"切换至展开方式1（前面+右面）"
  - 按钮2（scene2-btn-mode2）：位置(330,440)，作用"切换至展开方式2（底面+右面）"
  - 按钮3（scene2-btn-mode3）：位置(480,440)，作用"切换至展开方式3（前面+顶面+右面）"
- 教师操作流程：
  1. 点击按钮1，展示第一种展开方式，讲解"前面+右面"展开后A到F的直线距离计算
  2. 点击按钮2，切换至第二种展开方式，对比讲解不同展开路径的计算差异
  3. 点击按钮3，切换至第三种展开方式，完成三种方式的对比
  4. 引导学生观察三种结果（10cm、10.3cm、11.4cm），得出最短路径为10cm的结论

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │                    长方体表面展开方式对比                     │  y=20
  ├─────────────────────────────────────────────────────────────┤
  │                                                             │
  │              [展开图绘制区域 500×280]                        │  y=80~360
  │              (动态显示三种展开方式之一)                       │
  │                                                             │
  ├─────────────────────────────────────────────────────────────┤
  │              计算结果：√(8²+6²) = √100 = 10cm               │  y=380
  │                    ✓ 最短路径：10cm                         │  y=405
  ├─────────────────────────────────────────────────────────────┤
  │  [展开方式1]  [展开方式2]  [展开方式3]                       │  y=440
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentMode 记录当前状态（0=初始，1/2/3=三种展开方式）
  2. 坐标计算：三种展开方式的矩形位置、A/F点位置、路径线坐标需精确计算
  3. 动画曲线：状态切换时使用 opacity 过渡（0.3s ease）实现淡入淡出效果
  4. 事件绑定：三个按钮分别绑定 click 事件，切换状态并更新显示
  5. ID 命名规范：所有元素 ID 以 scene2- 为前缀（如 scene2-mode1-group、scene2-btn-mode1）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 元素分组：每种展开方式的所有元素放入一个 <g> 组，通过 display 控制显示/隐藏
  8. 按钮高亮：当前选中按钮添加 class "active"，样式为#1565c0背景色
