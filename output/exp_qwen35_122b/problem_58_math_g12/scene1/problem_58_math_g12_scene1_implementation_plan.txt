[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 理由：几何图形简单（圆、线段、弧线、文本），原生 SVG 足以胜任，无需引入重型库
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────┐
  │                    [图示区 800×440]                  │
  │                                                     │
  │              ┌─────────────────────────┐            │
  │              │         圆 O            │            │
  │              │    (400,250,r=150)      │            │
  │              │                         │            │
  │         C●   │           ●O            │   ●A       │
  │           \  │        /     \          │  /         │
  │            \ │   ●B  /       \         │ /          │
  │             \|/   /         \         |/           │
  │              └───┴───────────┴─────────┘            │
  │                   △ABC 及辅助线                     │
  │                                                     │
  │              [标签分布在外侧空白处]                  │
  │                                                     │
  └─────────────────────────────────────────────────────┘
  ┌─────────────────────────────────────────────────────┐
  │  [控件栏 y=440~490]                                  │
  │  ◀上一步  [步骤指示器]  下一步▶                       │
  └─────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-4) 跟踪当前步骤，updateScene() 函数根据 currentStep 显示/隐藏对应元素
  2. 坐标计算：预先计算所有点坐标，存储在常量对象中，避免重复计算
  3. 动画曲线：元素出现使用 opacity 过渡 (0→1)，时长 300ms，ease-in-out
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateScene()
  5. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-circle、scene1-line-ab、scene1-label-o）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 元素显示控制：用 display="none" 或 opacity 控制步骤元素的显示/隐藏
  8. 公式渲染：使用 MathJax 渲染数学公式（如 S=πR²），确保数学符号正确显示
