场景导航：Scene 1

(2010•肥城市模拟) 如图，为了测量河的宽度，在河的一岸边选取两点 A，B，观察对岸的点 C，测得∠CAB=75°，∠CBA=45°，且 AB=96 米，则河的宽度为 ．

$(\sqrt{2}=1.4，\sqrt{3}=1.7，精确到米)$．

题目分析：

本题是解三角形在实际测量中的应用。核心是求点 C 到直线 AB 的垂直距离（河宽）。

整体讲解思路：

  1. 首先明确题意：河宽即点 C 到 AB 所在直线的垂线段长度
  2. 在△ABC 中，已知两角一边，可先求第三角
  3. 用正弦定理求出 AC 或 BC 的长度
  4. 作高线，利用三角函数求河宽

图示规划说明：

设计一个分步导航图示，从原始条件逐步添加辅助线和标注，最终展示完整解题过程。

教学说明：

本图示用于引导学生理解解三角形在实际测量中的应用。教师应按以下步骤讲解：

步骤 0-1：理解题意与角度计算

首先明确河宽的定义：点 C 到直线 AB 的垂直距离。

在△ABC 中，已知：

  • ∠CAB = 75°
  • ∠CBA = 45°
  • AB = 96 米

根据三角形内角和定理：
∠ACB = 180° - 75° - 45° = 60°

步骤 2：添加辅助线

作 CD⊥AB 于 D，则 CD 即为所求河宽 h。

步骤 3-4：正弦定理求解

在△ABC 中，由正弦定理：
AC/sin(∠CBA) = AB/sin(∠ACB)

AC = AB·sin(45°)/sin(60°) = 96·(√2/2)/(√3/2) = 96·√2/√3 = 96·√6/3 = 32√6

在 Rt△ACD 中：
h = CD = AC·sin(∠CAD) = AC·sin(75°)

sin(75°) = sin(45°+30°) = sin(45°)cos(30°) + cos(45°)sin(30°)
= (√2/2)(√3/2) + (√2/2)(1/2) = √2(√3+1)/4

h = 32√6 × √2(√3+1)/4 = 8√12(√3+1) = 16√3(√3+1) = 16(3+√3) = 48 + 16√3

代入 √3 ≈ 1.7：
h ≈ 48 + 16×1.7 = 48 + 27.2 = 75.2 ≈ 75 米

讲解要点：

  1. 强调河宽的几何定义（点到直线的距离）
  2. 引导学生识别已知条件与待求量的关系
  3. 说明正弦定理的使用条件（已知两角一边或两边一对角）
  4. 提醒学生注意特殊角的三角函数值
  5. 强调近似计算的精度要求（精确到米）

课堂建议：

  • 可先让学生独立思考解题思路，再逐步展示图示
  • 引导学生讨论是否有其他解法（如先求 BC 再求 h）
  • 强调实际应用题中单位的重要性
