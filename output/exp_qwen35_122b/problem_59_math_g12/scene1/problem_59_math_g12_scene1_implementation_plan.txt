步骤 1（计算∠ACB）：

步骤 2（添加高线 CD）：
- 新增：D 点（220,360）及 D 标签（下方 (215,380)）
- 新增：CD 高线（灰色虚线，从 C(220,240) 到 D(220,360)）

- 计算结果框显示："作 CD⊥AB 于 D，CD 即为河宽 h"
- 上一步按钮：启用
- 下一步按钮：启用

步骤 3（正弦定理求 AC）：
- 高亮：AC 边（加粗或变色）
- 计算结果框显示："由正弦定理：AC/sin(45°) = AB/sin(60°)"
- 计算结果框第二行："AC = 96 × sin(45°)/sin(60°) = 96 × (√2/2)/(√3/2) = 96√2/√3 ≈ 78.4 米"
- 上一步按钮：启用
- 下一步按钮：启用

步骤 4（计算河宽 h）：
- 高亮：CD 高线（红色加粗）
- 计算结果框显示："在 Rt△ACD 中，h = CD = AC × sin(75°)"
- 计算结果框第二行："h = 78.4 × sin(75°) = 78.4 × (√6+√2)/4 ≈ 78.4 × 0.966 ≈ 76 米"
- 计算结果框第三行（最终结果）："河宽约为 76 米"
- 上一步按钮：启用
- 下一步按钮：禁用（或循环回步骤 0）

- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-4) 跟踪当前步骤
  2. 元素显示控制：每个可动态显示的元素赋予 data-step 属性，根据 currentStep 控制 display 属性
  3. 按钮状态：根据 currentStep 启用/禁用按钮（currentStep=0 时上一步禁用，currentStep=4 时下一步禁用）
  4. 计算结果框内容：根据 currentStep 动态更新 innerText
  5. 坐标计算：所有元素坐标硬编码，确保精确到像素
  6. 事件绑定：按钮点击事件更新 currentStep，调用 updateDisplay() 刷新界面
  7. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-triangle, scene1-cd-line, scene1-step-btn-prev）
  8. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染

- JS 核心逻辑：
  ```javascript
  (function() {
    var currentStep = 0;
    var maxStep = 4;
    
    // 元素 ID 映射
    var elements = {
      pointD: 'scene1-point-d',
      cdLine: 'scene1-cd-line',
      perpSymbol: 'scene1-perp-symbol',
      labelD: 'scene1-label-d',
      labelCd: 'scene1-label-cd',
      angleC: 'scene1-angle-c',
      labelAngleC: 'scene1-label-angle-c',
      result: 'scene1-result',
      btnPrev: 'scene1-btn-prev-bg',
      btnNext: 'scene1-btn-next-bg'
    };
    
    // 每步显示的元素和结果文本
    var stepConfig = [
      { show: [], result: '已知：AB=96 米，∠CAB=75°，∠CBA=45°' },
      { show: ['angleC', 'labelAngleC'], result: '∠ACB = 180° - 75° - 45° = 60°' },
      { show: ['pointD', 'cdLine', 'perpSymbol', 'labelD', 'labelCd'], result: '作 CD⊥AB 于 D，CD 即为河宽 h' },
      { show: [], result: '由正弦定理：AC/sin(45°) = AB/sin(60°)\nAC = 96 × sin(45°)/sin(60°) ≈ 78.4 米' },
      { show: [], result: 'h = AC × sin(75°) ≈ 78.4 × 0.966 ≈ 76 米\n河宽约为 76 米' }
    ];
    
    function updateDisplay() {
      // 更新各元素显示状态
      // 更新结果文本
      // 更新按钮状态
    }
    
    function prevStep() {
      if (currentStep > 0) {
        currentStep--;
        updateDisplay();
      }
    }
    
    function nextStep() {
      if (currentStep < maxStep) {
        currentStep++;
        updateDisplay();
      }
    }
    
    // 初始化
    document.getElementById('scene1-btn-prev-text').parentElement.addEventListener('click', prevStep);
    document.getElementById('scene1-btn-next-text').parentElement.addEventListener('click', nextStep);
    updateDisplay();
  })();
  ```
