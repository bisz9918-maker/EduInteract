[分步序列]
- 步骤 0（初始状态）：显示完整电路图，所有元件可见但无高亮，导线为黑色 2px，电流箭头为灰色虚线
- 步骤 1：点击「下一步」→ 高亮电源和干路（从正极到电流表再到分支点），路径变蓝色 3px 带发光，其他导线保持黑色
- 步骤 2：点击「下一步」→ 高亮 L₁ 支路电流路径（从分支点到 L₁ 再到汇合点），该支路变蓝色 3px 带发光，显示电流箭头
- 步骤 3：点击「下一步」→ 高亮 L₂ 支路电流路径（从分支点到电流表到 L₂ 再到汇合点），该支路变蓝色 3px 带发光，显示电流箭头
- 步骤 4：点击「下一步」→ 电流表特殊高亮（红色 #c62828 3px 带发光），在电流表旁显示标注"A 测量 L₂ 电流"
- 步骤 5：点击「下一步」→ 显示结论文字"电流表与 L₂ 串联，测量通过 L₂ 的电流"（绿色 18px 加粗），在结论前显示绿色对勾标记

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "上一步"按钮：位于 SVG 底部左侧 (50,450)，灰色背景，点击返回上一步
  - "下一步"按钮：位于 SVG 底部右侧 (700,450)，蓝色背景，点击进入下一步
  - 步骤指示器：位于 SVG 底部中央 (350,450)，显示"步骤 1/6"
- 教师操作流程：
  1. 初始展示完整电路图，让学生观察电路结构
  2. 点击"下一步"高亮干路，讲解电流从电源正极流出的路径
  3. 点击"下一步"高亮 L₁ 支路，讲解并联电路的分支特点
  4. 点击"下一步"高亮 L₂ 支路，对比两条支路的差异
  5. 点击"下一步"高亮电流表，强调电流表与 L₂ 串联
  6. 点击"下一步"显示结论，总结电流表测量对象
  7. 可随时点击"上一步"回退复习关键步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（电路图为几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    800 × 500 画布                       │
  │                                                         │
  │     电源          电流表              开关              │
  │    (+ -)           (A)                /                 │
  │      │              │                 │                 │
  │      │              │                 │                 │
  │      │              └─────┬───────────┘                 │
  │      │                    │                             │
  │      │              ┌─────┴─────┐                       │
  │      │              │           │                       │
  │     L₁              │           │              L₂       │
  │    (灯泡)           │  分支点   │            (灯泡)     │
  │      │              │           │                       │
  │      └──────┬───────┴───────────┘                       │
  │             │                                           │
  │             └───────────────────────────────────────────┘
  │                                                         │
  │         [上一步]      步骤 1/6      [下一步]             │
  │                                                         │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用 currentStep 变量记录当前步骤 (0-5)，每一步对应不同的 CSS class 状态
  2. 坐标计算：所有导线端点坐标需精确计算，确保元件连接处无缝对接
  3. 动画曲线：高亮效果使用 CSS transition (0.3s ease-in-out) 实现平滑过渡
  4. 事件绑定：按钮点击事件监听，更新 currentStep 并调用 updateStep() 函数刷新显示
  5. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-battery、scene1-ammeter、scene1-lamp1、scene1-lamp2、scene1-switch、scene1-wire-*、scene1-arrow-*）
  6. IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
  7. 高亮实现：通过切换 SVG 元素的 stroke 和 stroke-width 属性，配合 filter 实现发光效果
  8. 电流箭头：使用 SVG marker 定义箭头头部，沿导线 path 的 marker-end 属性显示方向
