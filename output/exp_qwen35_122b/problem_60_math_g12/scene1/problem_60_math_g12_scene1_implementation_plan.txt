[图示主题与整合说明]
- 本图示主题：圆与椭圆的切线性质类比
- 整合的步骤/概念：
  1. 展示圆的经典结论：PC·PD = PO²
  2. 展示椭圆的类比问题：PC·PD = ?
  3. 揭示类比对应关系：圆的半径 PO 对应椭圆的半短轴 b
  4. 给出椭圆结论：PC·PD = b²
- 教学价值：教师可通过分步演示，引导学生从熟悉的圆的性质出发，通过类比推理理解椭圆的相应性质，培养类比思维能力

  1. 初始展示左右两个图形的基本结构

  3. 点击"下一步"，展示椭圆的完整结构（含焦点、短轴）
  4. 点击"下一步"，高亮类比对应关系 PO ↔ b
  5. 点击"下一步"，揭示椭圆结论 PC·PD = b²
  6. 可随时点击"上一步"回退复习

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（圆、椭圆、线段），原生 SVG 足够且性能好，无需引入重型库
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │                    圆与椭圆的切线性质类比                       │  y=0~20
  ├────────────────────────────────────────────────────────────────┤
  │  圆的情况                        椭圆的情况                     │  y=20~40
  │                                                                │
  │     C────P────D                    C────P────D                 │
  │     │    ●    │                    │    ●    │                 │
  │     │   ╱ ╲   │                    │   ╱ ╲   │                 │
  │  A──┼──●───●──B                A──┼──●───●──B                 │
  │     │ O   │   │                    │ O F₁F₂│                 │
  │     │     │   │                    │   ╲ ╱   │                 │
  │     └─────┘   │                    └─────┘   │                 │
  │    (圆)       │                   (椭圆)      │                 │
  │                                                                │
  │                   [结论框]                                      │  y=360~420
  │                   PC·PD = ?                                    │
  ├────────────────────────────────────────────────────────────────┤
  │         ◀ 上一步              下一步 ▶                          │  y=450~485
  └────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-4) 跟踪当前步骤
  2. 坐标计算：所有元素使用绝对坐标，按布局表精确实现
  3. 元素分组：左侧图形元素用 group id="scene1-left"，右侧用 id="scene1-right"，便于批量控制显示/隐藏
  4. 动画曲线：步骤切换使用 CSS transition (opacity 0.3s ease) 实现淡入淡出
  5. 事件绑定：按钮点击事件更新 currentStep，调用 updateDisplay() 刷新视图
  6. ID 命名规范：所有元素 ID 以 "scene1-" 为前缀（如 scene1-circle, scene1-ellipse, scene1-btn-prev）
  7. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  8. 显示控制：使用 CSS class "hidden" { display: none; } 控制元素显示/隐藏
  9. 高亮切换：使用 CSS class "highlight-red" 实现红色高亮，通过 toggleClass 控制
