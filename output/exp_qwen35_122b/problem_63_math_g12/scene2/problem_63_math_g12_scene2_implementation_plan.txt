[分步序列]
步骤 0（初始状态）：
- 显示：x 轴、y 轴、点 O、点 F、点 M、线段 OM、线段 MF、线段 OF、直角标记
- 隐藏：点 P、线段 PM、线段 OP、所有长度标注、等长标记
- 目的：建立△OMF 直角三角形基础

步骤 1：
- 新增：标注"b"在 OM 左侧、标注"c"在 OF 下方
- 视觉变化：OM 和 OF 边高亮（加粗）
- 目的：标注已知边长

步骤 2：
- 新增：标注"a"在 MF 右侧
- 视觉变化：MF 边高亮，显示勾股定理推导提示（可选小字"c²-b²=a²"）
- 目的：由勾股定理得 MF=a

步骤 3：
- 新增：点 P、线段 PM、线段 OP、等长标记（PM=MF 单横线）
- 视觉变化：PM 与 MF 同时闪烁高亮，显示"PF=2MF=2a"
- 目的：利用中点性质

步骤 4：
- 新增：等长标记（OP=OF 双横线）
- 视觉变化：OP 与 OF 同时闪烁高亮，显示"OP=OF=c"
- 目的：推导 OP=OF

结论步骤：
- 新增：渐近线方程文本框（右下角）
- 显示：渐近线方程"y=±(b/a)x"及推导结果
- 目的：总结结论

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：位置 (550,450)，作用：返回前一步骤
  - "下一步 ▶"按钮：位置 (650,450)，作用：进入下一步骤
  - 步骤指示器：位置 (350,455)，显示"步骤 k/5"
- 教师操作流程：
  1. 初始展示△OMF 直角三角形，讲解切线性质
  2. 点击"下一步"标注边长 b、c，引导学生识别已知条件
  3. 点击"下一步"标注 a，讲解勾股定理推导
  4. 点击"下一步"展示中点关系，推导 PF=2a
  5. 点击"下一步"推导 OP=OF=c
  6. 点击"下一步"展示渐近线方程结论
  教师可随时点击"上一步"回退复习关键步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（几何图形简单，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    图示区 800×500                        │
  │                                                         │
  │         y                                               │
  │         ↑                                               │
  │         │      P                                        │
  │         │     ●  (绿色)                                 │
  │         │    /                                          │
  │         │   /  (蓝色△OMP)                              │
  │         │  M● (蓝色)                                    │
  │         │ /  \                                          │
  │         │/____\                                         │
  │   O●────●────●F                                         │
  │ (黑)  (黑)  (红)                                        │
  │         └──────────────────────────────────→ x          │
  │                                                         │
  │  控件栏（SVG 内底部 y=440~490）                          │
  │  [步骤指示器]  [◀上一步]  [下一步▶]                      │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep 跟踪当前步骤（0-5），每一步定义 showElements 和 hideElements 数组
  2. 坐标计算：建立坐标映射函数 mapCoord(x, y) 将数学坐标转换为画布坐标
  3. 动画曲线：元素出现使用 opacity 从 0 到 1 的过渡动画（duration=300ms）
  4. 事件绑定：按钮点击事件调用 updateStep() 函数，根据 currentStep 更新 DOM 元素显示状态
  5. ID 命名规范：所有元素 ID 以"scene2-"为前缀，如 scene2-point-O、scene2-line-OM、scene2-btn-next
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 高亮效果：使用 CSS class "highlight" 实现边加粗（stroke-width 从 2 到 4）
