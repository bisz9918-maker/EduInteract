[分步序列]
- 步骤 0（初始状态）：
  - 显示：四棱柱完整轮廓（底面 ABCD、上底面 A₁B₁C₁D₁、四条侧棱）
  - 显示：所有顶点标签 A/B/C/D/A₁/B₁/C₁/D₁
  - 显示：标签"侧棱⊥底面"
  - 隐藏：对角线 AC、BD、B₁D₁，投影辅助线，对角线标签
  - 状态：展示基础结构，等待教师点击"下一步"

- 步骤 1：
  - 新增：高亮显示对角线 AC（蓝色 #1565c0）
  - 新增：高亮显示对角线 B₁D₁（红色 #c62828）
  - 新增：标签"AC"（右侧）、标签"B₁D₁"（上方）
  - 视觉变化：两条对角线同时高亮，形成对比
  - 教学提示：提出问题"AC 与 B₁D₁ 是否垂直？需要什么条件？"

- 步骤 2：
  - 新增：高亮显示对角线 BD（绿色 #2e7d32）
  - 新增：标签"BD"（下方）
  - 新增：投影辅助线 B₁-B 和 D₁-D（灰色虚线）
  - 视觉变化：BD 出现，与 B₁D₁ 形成平行对应关系
  - 教学提示：说明"B₁D₁∥BD（因为侧棱垂直底面，上底面平行下底面）"

- 步骤 3：
  - 视觉变化：B₁D₁ 逐渐"投影"到底面，与 BD 重合（可用动画效果）
  - 高亮：AC 与 BD 的交点处显示直角符号（步骤 3 后）
  - 新增：文字说明"AC⊥B₁D₁ ⇔ AC⊥BD"
  - 教学提示：说明"空间垂直转化为平面垂直"

- 结论（步骤 4）：
  - 显示：底面需满足的条件"AC⊥BD"（即底面 ABCD 的对角线互相垂直）
  - 高亮：底面四边形 ABCD，强调这是关键条件
  - 最终状态：完整展示推理链条，教师可回退复习各步骤

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 按钮"◀ 上一步"：位置 (280,460)，作用：返回上一状态，第一步时禁用
  - 按钮"下一步 ▶"：位置 (500,460)，作用：进入下一状态，最后一步时变为"完成"
  - 按钮状态：初始时"上一步"禁用（灰色），"下一步"启用（蓝色）
- 教师操作流程：
  1. 展示步骤 0，介绍四棱柱基本结构
  2. 点击"下一步"进入步骤 1，提出问题"AC 与 B₁D₁ 垂直需要什么条件？"
  3. 点击"下一步"进入步骤 2，引导学生发现 B₁D₁∥BD
  4. 点击"下一步"进入步骤 3，说明空间垂直转化为平面垂直
  5. 点击"下一步"进入结论，得出底面需满足 AC⊥BD
  6. 可随时点击"上一步"回退复习关键推理环节

- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-4) 跟踪当前步骤，updateScene() 函数根据 currentStep 显示/隐藏对应元素
  2. 坐标计算：所有元素坐标硬编码在 SVG 中，确保精确位置
  3. 动画曲线：步骤 3 的投影效果使用 SVG SMIL 动画或 requestAnimationFrame 实现 B₁D₁ 到 BD 的渐变
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateScene()
  5. 元素显示控制：通过 CSS class "hidden" 控制元素显示/隐藏，避免删除 DOM 节点
  6. ID 命名规范：所有元素 ID 以 scene1- 为前缀，如 scene1-line-ac、scene1-line-bd1、scene1-btn-prev
  7. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
