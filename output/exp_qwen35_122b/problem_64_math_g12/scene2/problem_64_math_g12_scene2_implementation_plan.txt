[图示主题与整合说明]
- 本图示主题：四棱柱底面四边形对角线垂直条件

[分步序列]
多状态切换交互（非分步导航，4 个状态按钮并列）：

状态 0（初始状态）：
- 显示：一般四边形 ABCD（顶点坐标见上表），对角线 AC（蓝）、BD（绿），交点 O 处直角符号（红），"AC⊥BD"标注
- 类型标签："一般对角线垂直四边形"
- 教学要点：展示题目核心条件——底面对角线垂直

状态 1（点击"菱形"按钮）：
- 显示：菱形 ABCD（四边相等，对角线垂直且互相平分），对角线 AC、BD，直角符号
- 类型标签："菱形（对角线垂直且平分）"
- 教学要点：菱形是满足条件的典型例子

状态 2（点击"正方形"按钮）：
- 显示：正方形 ABCD（四边相等且四角为直角，对角线垂直且相等），对角线 AC、BD，直角符号
- 类型标签："正方形（对角线垂直且相等）"
- 教学要点：正方形是菱形的特例，也满足条件

状态 3（点击"任意四边形"按钮）：
- 显示：一般对角线垂直四边形（非对称，仅满足对角线垂直），对角线 AC、BD，直角符号
- 类型标签："任意对角线垂直四边形"
- 教学要点：强调答案的开放性——只要对角线垂直即可

[交互方案]
- 交互类型：多状态切换（4 个状态按钮）
- 控件说明：
  - 按钮 1："初始条件"，位置 (200,450)，作用：切换到状态 0，显示一般对角线垂直四边形
  - 按钮 2："菱形"，位置 (300,450)，作用：切换到状态 1，显示菱形
  - 按钮 3："正方形"，位置 (400,450)，作用：切换到状态 2，显示正方形
  - 按钮 4："任意四边形"，位置 (500,450)，作用：切换到状态 3，显示一般对角线垂直四边形
- 教师操作流程：
  1. 初始展示状态 0，讲解题目条件 AC⊥B₁D₁ 等价于 AC⊥BD
  2. 点击"菱形"按钮，展示菱形作为满足条件的例子
  3. 点击"正方形"按钮，展示正方形作为菱形的特例
  4. 点击"任意四边形"按钮，强调答案的开放性——只要对角线垂直即可

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    图示区 800×500                        │
  │                                                          │
  │         A                                                │
  │         ●                                                │
  │        / \                                               │
  │       /   \                                              │
  │   B  ●-----● D                                           │
  │      \   /                                               │
  │       \ /                                                │
  │         ●                                                │
  │         C                                                │
  │                                                          │
  │    [AC⊥BD]  (对角线交点处直角符号)                        │
  │                                                          │
  │                              类型标签                     │
  │                              (右侧)                       │
  │                                                          │
  │  ┌─────────────────────────────────────────────────┐    │
  │  │ [初始条件] [菱形] [正方形] [任意四边形]          │    │
  │  └─────────────────────────────────────────────────┘    │
  │  (控件栏 y=440~490)                                      │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentScene 记录当前状态 (0-3)，点击按钮时更新状态并重绘
  2. 坐标计算：预定义 4 种状态的顶点坐标数组，切换时直接读取对应坐标
  3. 动态绘制：用 SVG 的 <polygon>、<line>、<text> 元素，通过 JS 动态更新坐标和文本
  4. 直角符号绘制：在交点处绘制两条垂直短线段组成的直角符号
  5. 事件绑定：4 个按钮分别绑定 click 事件，更新 currentScene 后调用重绘函数
  6. 高亮切换：对角线 AC 始终蓝色，BD 始终绿色，状态切换时坐标变化但颜色不变
- ID 命名规范：所有交互元素 ID 以 scene2- 为前缀，如 scene2-poly-quad、scene2-line-ac、scene2-btn-0 等
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
