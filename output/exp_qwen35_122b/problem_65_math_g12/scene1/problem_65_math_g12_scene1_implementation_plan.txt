[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：位于 SVG 底部左侧 (280,455)，点击返回上一状态，第一步时禁用
  - "下一步 ▶"按钮：位于 SVG 底部右侧 (440,455)，点击进入下一状态，最后一步时禁用
- 教师操作流程：
  1. 初始展示题目已知条件（Rt△ABC，AC=6cm，BC=8cm，∠C=90°）
  2. 点击"下一步"添加圆，讲解"以 AC 为直径作圆"
  3. 点击"下一步"显示交点 D 和辅助线 CD，讲解圆的交点性质
  4. 点击"下一步"高亮垂直关系，讲解"直径所对圆周角为直角"定理
  5. 点击"下一步"高亮相似三角形，讲解相似三角形判定
  6. 点击"下一步"展示计算过程和结果，完成解题

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（三角形、圆、线段），原生 SVG 足以胜任，无需引入重型库
  - 状态管理：使用变量 currentStep 记录当前步骤（0-5）
  - 元素显示控制：通过 setAttribute('display', 'none'/'block') 控制各步骤元素的可见性

- 画布尺寸：800 × 500 px

- 布局草图（ASCII）：

- 关键实现要点：
  1. 状态机设计：currentStep 变量（0-5），每一步对应一组元素的 display 属性
  2. 坐标计算：基于几何关系精确计算各点坐标，D 点通过圆与直线交点公式计算
  3. 动画曲线：元素显示使用 opacity 渐变（0→1，300ms），增强视觉流畅性
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后刷新元素显示状态
  5. 禁用状态：第一步时"上一步"按钮禁用，最后一步时"下一步"按钮禁用

- ID 命名规范：
  - 所有交互元素 ID 以 scene1- 为前缀
  - 示例：scene1-tri-abc（三角形）、scene1-circle（圆）、scene1-point-a（A 点）、scene1-prev-btn（上一步按钮）、scene1-next-btn（下一步按钮）
  - JS 中使用 getElementById('scene1-xxx') 获取元素

- IIFE 隔离：
  所有 JavaScript 代码包裹在 (function() { ... })() 中，避免全局变量污染
