    **题目原文：**
    如图，边长为 a 的正△ABC 的中线 AF 与中位线 DE 相交于 G，已知△A'ED 是△AED 绕 DE 旋转过程中的一个图形，现给出下列命题，其中正确的命题有______．(填上所有正确命题的序号)
    (1) 动点 A' 在平面 ABC 上的射影在线段 AF 上；
    (2) 三棱锥 A'-FED 的体积有最大值；
    (3) 恒有平面 A'GF⊥平面 BCED；
    (4) 异面直线 A'E 与 BD 不可能互相垂直．

    **题目分析：**
    本题是立体几何综合题，考查旋转体、射影、体积、平面垂直、异面直线等核心概念。

    **关键几何关系：**
    1. 正△ABC 边长为 a，AF 是中线（也是高线、角平分线）
    2. DE 是中位线，D、E 分别是 AB、AC 中点，DE∥BC 且 DE = a/2
    3. G 是 AF 与 DE 的交点，由于 DE 是中位线，G 是 AF 中点
    4. △AED 绕 DE 旋转，A' 是 A 的旋转位置，A' 的轨迹是以 DE 为轴的圆弧

    **解题思路：**
    - 命题 (1)：A' 绕 DE 旋转，其射影应在过 A 且垂直于 DE 的直线上，即 AF 上 ✓
    - 命题 (2)：体积 V = (1/3)×底面积×高，高最大时体积最大 ✓
    - 命题 (3)：需分析平面 A'GF 与平面 BCED 的法向量关系 ✓
    - 命题 (4)：需判断是否存在旋转角度使 A'E⊥BD ✗

    **图示规划：**
    共规划 3 个场景：
    - Scene 1：基础图形 + 旋转过程（整合初始状态与旋转动画）
    - Scene 2：射影关系与平面垂直（整合命题 1 和 3 的验证）
    - Scene 3：体积变化与异面直线（整合命题 2 和 4 的验证）

    **Scene 1 教学说明：**

    本图示用于帮助学生理解题目的几何背景和旋转过程。

    **讲解要点：**

    1. 首先展示正三角形 ABC，强调其性质：三边相等（均为 a），三角均为 60°

    2. 逐步添加中线 AF：
    - F 是 BC 中点，BF = FC = a/2
    - 在正三角形中，中线也是高线和角平分线
    - AF 的长度 = (√3/2)a

    3. 添加中位线 DE：
    - D 是 AB 中点，E 是 AC 中点
    - DE∥BC 且 DE = BC/2 = a/2
    - 这是三角形中位线定理

    4. 标出交点 G：
    - 由于 DE 是中位线，G 是 AF 的中点
    - AG = GF = AF/2 = (√3/4)a

    5. 展示旋转过程：
    - △AED 绕 DE 旋转，DE 是旋转轴
    - A' 是 A 的旋转位置，A'D = AD，A'E = AE
    - A' 的轨迹是以 DE 为轴的圆弧，圆心在 DE 上

    **引导学生观察：**
    - 旋转过程中，哪些量保持不变？（A'D = AD，A'E = AE，DE 长度不变）
    - A' 的位置如何变化？（在垂直于 DE 的平面内做圆周运动）
    - 旋转角度范围是多少？（0°到 180°）

    **Scene 3 教学说明：**

    本图示用于验证命题 (2) 和命题 (4)，通过动态拖拽展示体积变化和异面直线夹角。

    **命题 (2) 验证：**
    - 三棱锥 A'-FED 的体积 V = (1/3)×S_FED×h
    - S_FED 是底面面积，固定不变（F、E、D 位置固定）
    - h 是 A' 到平面 FED 的距离（高）
    - 当 A' 绕 DE 旋转时，h 随旋转角度变化
    - h 最大时，V 最大
    - h 的最大值出现在 A' 到平面 FED 的距离最大时，即 A' 在垂直于 FED 的方向上最远
    - 因此体积有最大值 ✓

    **计算验证：**
    - S_FED = (1/2)×DE×(F 到 DE 的距离)
    - DE = a/2，F 到 DE 的距离 = AF/2 = (√3/4)a
    - S_FED = (1/2)×(a/2)×(√3/4)a = (√3/16)a²
    - h_max = A 到 DE 的距离 = AG = (√3/4)a
    - V_max = (1/3)×(√3/16)a²×(√3/4)a = (3/192)a³ = (1/64)a³

    **命题 (4) 验证：**
    - 需要判断是否存在旋转角度使 A'E⊥BD
    - A'E 是旋转后的线段，BD 是固定线段
    - 通过滑块观察夹角 φ 的变化
    - 当 φ = 90°时，A'E⊥BD
    - 通过计算或观察，发现存在某个 θ 使 φ = 90°
    - 因此命题 (4) 错误 ✗

    **关键分析：**
    - A'E 的长度固定（A'E = AE = a/2）
    - BD 的长度固定（BD = a/2）
    - 两线段的方向随 A' 的旋转而变化
    - 通过向量点积判断垂直：A'E·BD = 0 时垂直
    - 存在解，因此可能垂直

    **课堂讲解建议：**
    1. 先通过 Scene 1 建立几何直观
    2. 用 Scene 2 验证命题 (1) 和 (3)，强调射影和平面垂直的几何本质
    3. 用 Scene 3 验证命题 (2) 和 (4)，重点讲解体积最大值和异面直线垂直的判断
    4. 总结：正确命题为 (1)、(2)、(3)

    **完整解答：**
    正确命题序号：(1)、(2)、(3)
