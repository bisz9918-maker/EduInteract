[分步序列]
本场景采用连续滑块交互，无分步按钮，但有以下关键状态节点：

- 初始状态（θ = 0°）：
  - A' 与 A 重合（右侧视图中 A' 在圆弧起点）
  - H 与 G 重合（俯视图中 H 在 G 点位置）
  - 平面 A'GF 与平面 AGF 重合
  - 平面夹角显示 90°（验证垂直关系）

- θ = 45°：
  - A' 沿圆弧运动到 45°位置
  - H 沿 AF 向下移动
  - 实时显示 A'H 垂线
  - 平面夹角仍为 90°（验证命题 3）

- θ = 90°：
  - A' 运动到圆弧最高点
  - H 移动到 AF 中点附近
  - 平面 A'GF 垂直于底面最明显

- θ = 135°：
  - A' 继续运动
  - H 继续沿 AF 向下
  - 平面夹角保持 90°

- 最终状态（θ = 180°）：
  - A' 运动到圆弧终点（与初始位置对称）
  - H 移动到接近 F 点
  - 验证完成：H 始终在 AF 上（命题 1 成立），平面夹角始终 90°（命题 3 成立）

冲突检查：
- "G" (200,205) 与 "H" (215, H_y)：当 H 接近 G 时（θ 接近 0°），H_y 接近 190，间距约 15px → 解决方案：H 标签固定右偏，G 标签固定下偏，避免重叠
- "θ = XX°" (600,420) 与 "平面夹角 = XX°" (600,445)：垂直间距 25px → 无冲突
- "n2" (605,235) 与 "A'" (615, A'_y)：当 A' 在高位时可能接近 → 解决方案：n2 标签固定上方，A' 标签固定右上方，根据 A' 位置动态调整

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：
  - 滑块：id="scene2-slider"，位置 (500,460)-(700,480)，范围 0~180，步长 1
  - 角度显示：id="scene2-angle-display"，实时显示当前 θ 值
  - 平面夹角显示：id="scene2-plane-angle-display"，实时显示两平面夹角（应恒为 90°）
- 教师操作流程：
  1. 初始状态展示 θ=0°，A' 与 A 重合，说明这是旋转起始位置
  2. 缓慢拖动滑块，让学生观察 A' 的运动轨迹（圆弧）
  3. 同时观察俯视图中 H 点始终在 AF 线段上移动（验证命题 1）
  4. 观察侧视图中平面夹角始终显示 90°（验证命题 3）
  5. 拖动到 θ=90° 时暂停，强调此时 A' 到平面距离最大
  6. 继续拖动到 θ=180°，完成整个旋转过程的观察

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形绘制用 SVG 最清晰，滑块交互用原生 JS 即可实现，无需重型库
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    俯视图          侧视图               │
  │                   (左)            (右)                  │
  │  ┌─────────────────────┐  ┌─────────────────────┐      │
  │  │      △ABC           │  │        A'           │      │
  │  │       A             │  │        *            │      │
  │  │      / \            │  │       / \           │      │
  │  │     D---E           │  │      G-----F        │      │
  │  │      \ /            │  │                     │      │
  │  │       F             │  │    圆弧轨迹         │      │
  │  │      B---C          │  │                     │      │
  │  └─────────────────────┘  └─────────────────────┘      │
  │                                                         │
  │              θ = XX°    平面夹角 = 90°                  │
  │         ┌──────────────────────────────────┐           │
  │         │ 旋转角度 θ：0° ─────●───── 180°  │           │
  │         └──────────────────────────────────┘           │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：单一状态变量 theta（0~180），所有动态元素位置由 theta 计算得出
  2. 坐标计算：
     - 俯视图 H 点：沿 AF 线段，位置 = G + (F-G) * (1-cosθ)/2
     - 侧视图 A' 点：圆弧参数方程 (600 + 90*sinθ, 190 - 90*cosθ)
     - 侧视图 H 点：(600, 190 + 90*(1-cosθ))
  3. 动画曲线：滑块拖动时实时更新，无需缓动
  4. 事件绑定：slider 的 'input' 事件触发重绘
  5. ID 命名规范：所有元素 ID 以 "scene2-" 为前缀（如 scene2-slider, scene2-a-prime, scene2-h-point）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 平面夹角计算：平面 A'GF 的法向量与平面 BCED 的法向量（垂直向上）的夹角，应恒为 90°
