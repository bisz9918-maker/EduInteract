[分步序列]
本场景采用连续拖拽交互，无分步导航，状态随滑块实时变化：

- 初始状态（滑块位置 50%，点 P 在椭圆上半部分约 30°位置）：
  - 显示完整椭圆框架（椭圆、坐标轴、点 A、B、O、F、直线 l）
  - 显示点 P、线段 AP、点 D、线段 BD、点 M
  - 显示线段 FM、PM、PF
  - 所有标签正常显示
  - 滑块位于中间位置，教师可拖动观察变化

- 交互过程：
  - 拖动滑块 → 点 P 沿椭圆移动（上半部分，避免与 A、B 重合）
  - 点 P 移动时，线段 AP 实时更新
  - 点 D 随 AP 与 l 的交点实时更新
  - 点 M 随 BD 中点实时更新
  - 线段 FM、PM、PF 实时更新
  - 所有标签位置随对应点实时更新

- 观察重点（教师可引导）：
  1. 观察 FM 是否始终平分∠PFB（结论①）
  2. 观察 PM 是否始终与椭圆相切（结论②）
  3. 观察 PM 是否始终平分∠FPD（结论③）
  4. 观察 PM 与 BM 长度是否可能相等（结论④）

[交互方案]
- 交互类型：连续拖拽滑块 — 选择理由：点 P 在椭圆上连续移动时，相关点 D 和 M 随之联动变化，通过拖拽可直观观察各几何元素的变化规律和不变量
- 控件说明：
  - 滑块：id="scene1-slider"，位置 (250,450)-(550,470)，范围 0-100，控制点 P 在椭圆上半部分的位置参数（角度从 10°到 170°，避免与 A、B 重合）
  - 滑块标签：text "点 P 位置"，位置 (250,430)
- 教师操作流程：
  1. 图示加载后显示完整椭圆框架和初始点 P 位置
  2. 教师拖动滑块，点 P 沿椭圆上半部分移动
  3. 观察点 D、M 的联动变化
  4. 观察线段 FM、PM 的变化，验证四个几何结论
  5. 可反复拖动，观察不同位置时的几何关系

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形绘制简单，SVG 适合精确坐标定位和动态更新，无需引入大型库
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    [图示区 800×500]                     │
  │                                                         │
  │           y                                             │
  │           ↑                                             │
  │      P●                                                 │
  │     /  \                   D●                           │
  │    /    \                 /                             │
  │   /      \               /                              │
  │  A●------●O------●F----●B                              │
  │   \      /      /      │                                │
  │    \    /      /       │ l                              │
  │     \  /      /        │                                │
  │      ●M      /         │                                │
  │       \     /          │                                │
  │        \   /           │                                │
  │         \ /            │                                │
  │          ●             │                                │
  │          ↓            ↓                                 │
  │                                                         │
  │              点 P 位置 [━━━━━●━━━━━]                    │
  │              (250,450)        (550,470)                │
  └─────────────────────────────────────────────────────────┘
  ```

- 关键实现要点：
  1. 坐标系转换：SVG 内部使用数学坐标系，原点在 (400,250)，x 轴向右，y 轴向上。绘制时需将数学坐标转换为 SVG 坐标（y 轴翻转）
  2. 椭圆参数方程：x = a·cos(θ), y = b·sin(θ)，其中 a=200, b=120，θ 由滑块值映射到 [10°, 170°]
  3. 点 D 计算：直线 AP 的方程为 y = k(x - x_A)，与 x = a 的交点即为 D，k = (y_P - y_A)/(x_P - x_A)
  4. 点 M 计算：M 为 BD 中点，M_x = B_x = a, M_y = (B_y + D_y)/2
  5. 实时更新：滑块 input 事件触发，重新计算 P、D、M 坐标，更新所有相关线段和标签位置
  6. 避免 P 与 A、B 重合：滑块范围映射到 θ ∈ [10°, 170°]，确保 P 不在顶点
