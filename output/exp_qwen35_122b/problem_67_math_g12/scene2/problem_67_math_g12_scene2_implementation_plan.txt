[分步序列]
- 步骤 0（初始状态）：显示椭圆框架、坐标轴、点 A/B/O/F/P/D/M、切线 l、线段 AP/PF/FM/PM/BD。所有元素正常显示，等待教师点击「下一步」开始验证。
- 步骤 1（验证结论①）：高亮线段 FM（#1565c0 加粗），显示角度弧∠PFM 和∠MFB（#1565c0），在弧线旁标注"∠1"和"∠2"，显示相等标记（双弧线）。非相关元素透明度降至 50%。结论：FM 平分∠PFB ✓
- 步骤 2（验证结论②）：高亮线段 PM（#2e7d32 加粗），在点 P 处绘制椭圆切线（与 PM 重合），显示相切标记（直角符号⊥连接 PM 与 OP 半径）。非相关元素透明度降至 50%。结论：PM 与椭圆 Γ 相切 ✓
- 步骤 3（验证结论③）：高亮线段 PM 和 PF（#1565c0 加粗），显示角度弧∠FPM 和∠MPD（#1565c0），在弧线旁标注"∠3"和"∠4"，显示相等标记（双弧线）。非相关元素透明度降至 50%。结论：PM 平分∠FPD ✓
- 步骤 4（验证结论④）：高亮线段 PM 和 BM，显示长度标注"PM"和"BM"，用不同颜色标注长度数值（PM 用红色，BM 用绿色），显示 PM > BM 的比较结果。非相关元素透明度降至 50%。结论：PM=BM 的点 P 不存在 ✓
- 结论状态：汇总显示正确结论序号"①②③"，用绿色高亮显示，错误结论④用红色标注。所有元素恢复正常透明度。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于控件栏左侧，步骤 1-4 时可用，点击返回前一步骤
  - 「下一步」按钮：位于控件栏中间，步骤 0-3 时可用，点击进入下一步验证
  - 「结论」按钮：位于控件栏右侧，步骤 4 时显示，点击汇总正确结论
- 教师操作流程：
  1. 初始展示椭圆框架和所有关键点，让学生观察图形结构
  2. 点击「下一步」→ 验证结论①，讲解角平分线的几何意义
  3. 点击「下一步」→ 验证结论②，讲解椭圆切线性质
  4. 点击「下一步」→ 验证结论③，讲解角平分线定理
  5. 点击「下一步」→ 验证结论④，讲解长度比较
  6. 点击「结论」→ 汇总正确结论①②③，强调错误结论④

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │                         Y                                   │
  │                          ↑                                  │
  │                    ┌─────┼─────┐                           │
  │                   /      O      \                          │
  │                  |   A    F    B |  l                      │
  │                  |      ●───●───●  │                       │
  │                   \      │   │  /   │                      │
  │                    └─────┼───┼─┘    │                      │
  │                          │   P      │                      │
  │                          │  / \     │                      │
  │                          │ /   \    │                      │
  │                          |/  M  \   │                      │
  │                          ●───────●  │                      │
  │                          D        \ │                      │
  │                                   \|                      │
  │  ──────────────────────────────────→────────────────────── X
  │                         控件栏 [上一步][下一步][结论]       │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：currentStep 变量跟踪当前步骤（0-4），updateScene() 函数根据 currentStep 更新显示
  2. 坐标计算：椭圆参数方程 x = 400 + 200*cos(θ), y = 250 + 100*sin(θ)，P 点取 θ=120°
  3. 动画曲线：使用 CSS transition 实现元素透明度渐变（opacity: 1 → 0.5）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateScene()
  5. 角度弧绘制：使用 SVG path 的 arc 命令，计算起点终点坐标
  6. 切线绘制：椭圆在 P 点的切线斜率 = -(b²x₀)/(a²y₀)，绘制过 P 点的直线
- ID 命名规范：所有交互元素 ID 以 scene2- 为前缀（如 scene2-ellipse, scene2-step-btn-next, scene2-arc-angle1）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
