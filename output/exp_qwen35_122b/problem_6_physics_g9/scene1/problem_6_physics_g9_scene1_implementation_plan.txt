[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：电路图元素为简单几何形状（线段、矩形、圆形、文字），原生 SVG 足以实现，无需引入重型库
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │                        800 × 500 画布                          │
  │  ┌──────────────────────┐  ┌──────────────────────────────┐   │
  │  │    电路图区域        │  │      电磁装置区域            │   │
  │  │   (20,30)-(450,420)  │  │    (480,30)-(780,420)        │   │
  │  │                      │  │                              │   │
  │  │  定值电阻 [====]     │  │   弹簧测力计                 │   │
  │  │      │               │  │      │                       │   │
  │  │  电流表 (A)          │  │      ▼ 铁球 ●               │   │
  │  │      │               │  │                              │   │
  │  │  滑动变阻器 [←→]     │  │   电磁铁 (线圈)              │   │

  └────────────────────────────────────────────────────────────────┘
  ```

- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-5) 跟踪当前步骤，步骤变化时调用 updateScene() 函数
  2. 坐标计算：所有元素坐标按布局坐标表精确实现，使用 SVG 元素属性直接设置
  3. 动画曲线：元素出现使用 opacity 从 0 到 1 的过渡动画（duration=300ms）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后触发重绘
  5. 高亮逻辑：已激活元件用蓝高亮，当前步骤新增用红高亮，电流方向用绿高亮
  6. 电流箭头实现：用 SVG <marker> 定义箭头，配合 <path> 绘制电流路径

- ID 命名规范：
  - 所有交互元素 ID 以 scene1- 为前缀
  - 元件 ID 示例：scene1-source（电源）、scene1-switch（开关）、scene1-ammeter（电流表）、scene1-rheostat（变阻器）、scene1-resistor（定值电阻）、scene1-electromagnet（电磁铁）、scene1-spring（弹簧测力计）、scene1-ball（铁球）
  - 导线 ID 示例：scene1-wire1、scene1-wire2...scene1-wire9
  - 标签 ID 示例：scene1-label-source、scene1-label-switch...
  - 控件 ID：scene1-btn-prev、scene1-btn-next、scene1-step-indicator

- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染

- 状态更新函数逻辑：
  ```javascript
  function updateScene() {
    // 重置所有元素透明度
    document.querySelectorAll('.scene1-element, .scene1-wire, .scene1-label, .scene1-current')
            .forEach(el => el.style.opacity = '0');
    
    // 根据 currentStep 显示对应元素
    const stepElements = {
      1: ['source', 'switch', 'ammeter', 'wire1', 'wire3', 'wire4', 'wire5'],
      2: ['rheostat', 'resistor', 'wire2', 'wire6'],
      3: ['electromagnet', 'wire7', 'wire8', 'wire9'],
      4: ['spring', 'ball'],
      5: ['current-arrow1', 'current-arrow2', ...] // 所有电流箭头
    };
    
    // 显示当前步骤及之前步骤的元素
    for (let s = 1; s <= currentStep; s++) {
      if (stepElements[s]) {
        stepElements[s].forEach(id => {
          const el = document.getElementById('scene1-' + id);
          if (el) el.style.opacity = '1';
        });
      }
    }
    
    // 步骤5显示所有电流箭头
    if (currentStep === 5) {
      // 显示所有电流箭头
    }
    
    // 更新按钮状态
    document.getElementById('scene1-btn-prev').disabled = (currentStep === 0);
    document.getElementById('scene1-btn-next').disabled = (currentStep === 5);
    
    // 更新步骤指示器
    document.getElementById('scene1-step-indicator').textContent = '步骤 ' + currentStep + '/5';
  }
  ```
