[分步序列]
- 步骤 0（初始状态）：
  - 开关：断开状态（斜线）
  - 电流表：显示 "I = 0.0 A"
  - 弹簧：自然长度（指针在中间刻度）
  - 测力计示数：显示 "F = 2.0 N"（仅铁球重力）
  - 磁力线：无（不显示）
  - 电磁铁：无磁性（线圈无高亮）
  - 铁球位置：正常悬挂位置

- 步骤 1（闭合开关，电流产生）：
  - 开关：闭合状态（直线连接）
  - 电流表：显示 "I = 0.5 A"（初始电流）
  - 导线：通电部分用蓝色高亮
  - 其他：弹簧、测力计示数不变（步骤 0 状态）
  - 磁力线：无（磁性尚未显现）

- 步骤 2（电磁铁产生磁性，吸引铁球）：
  - 电磁铁线圈：蓝色高亮 #1565c0
  - 磁力线：出现 3 条红色曲线 #c62828，从电磁铁指向铁球
  - 铁球：轻微上移（弹簧伸长）
  - 弹簧：长度增加（指针下移）
  - 测力计示数：显示 "F = 2.5 N"（重力+磁力）
  - 电流表：保持 "I = 0.5 A"

- 步骤 3（滑片右移，电流减小）：
  - 滑动变阻器：滑片向右移动（箭头位置右移）
  - 电流表：显示 "I = 0.3 A"（电流减小）
  - 导线：蓝色高亮变淡
  - 其他：磁力线、弹簧、测力计示数保持步骤 2 状态

- 步骤 4（磁性减弱，吸引力减小）：
  - 电磁铁线圈：蓝色高亮变淡
  - 磁力线：减少为 2 条，长度缩短
  - 铁球：轻微下移（弹簧收缩）
  - 弹簧：长度减小（指针上移）
  - 测力计示数：显示 "F = 2.2 N"（磁力减小）
  - 电流表：保持 "I = 0.3 A"

- 步骤 5（弹簧测力计示数变小 - 结论）：
  - 弹簧：进一步收缩（指针继续上移）
  - 测力计示数：显示 "F = 2.0 N"（回到初始值，磁力几乎消失）
  - 磁力线：仅 1 条或消失
  - 电磁铁线圈：无高亮（磁性很弱）
  - 电流表：保持 "I = 0.3 A"
  - 结论标注：在测力计旁显示绿色文字"示数变小" #2e7d32

- 控件说明：
  - 按钮"上一步"：ID=scene3-prev，位置 (250,440)-(330,470)，回退到上一状态

  - 步骤指示：ID=scene3-step-display，位置 (470,445)-(540,465)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始展示开关断开状态，讲解电路组成
  2. 点击"下一步"闭合开关，讲解电流产生
  3. 点击"下一步"展示电磁铁磁性及铁球受力变化
  4. 点击"下一步"移动滑片，讲解电阻变化导致电流变化
  5. 点击"下一步"展示磁性减弱
  6. 点击"下一步"展示最终结论（测力计示数变小）
  7. 可随时点击"上一步"回退复习某个环节

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何和状态切换，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │  电磁铁磁性变化与弹簧测力计示数关系（标题，可选）              │
  ├────────────────────────────────────────────────────────────────┤
  │                                                                │
  │  ┌──────────────────┐              ┌──────────────────┐       │
  │  │   电路图区域     │              │   右侧装置区域   │       │
  │  │                  │              │                  │       │
  │  │   电源 开关      │              │   弹簧测力计     │       │
  │  │   变阻器 电阻    │              │   铁球           │       │
  │  │   电流表         │              │   电磁铁         │       │
  │  │                  │              │                  │       │
  │  └──────────────────┘              └──────────────────┘       │
  │                                                                │
  │         [◀上一步]  [步骤 X/5]  [下一步▶]                       │
  └────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-5) 跟踪当前步骤，每个步骤对应一个状态对象，包含各元素的显示属性
  2. 坐标计算：所有元素使用绝对坐标，通过 SVG transform 或 CSS position 定位
  3. 动画曲线：弹簧伸缩用 CSS transition (ease-in-out, 0.3s)，磁力线数量变化用 opacity 渐变
  4. 事件绑定：按钮点击事件 → 更新 currentStep → 调用 renderStep() 重绘所有元素
  5. ID 命名规范：所有交互元素 ID 以 scene3- 为前缀（如 scene3-prev, scene3-next, scene3-step-display, scene3-switch, scene3-spring, scene3-magnet-lines 等）
  6. IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
  7. 状态数据：用数组存储 6 个步骤的状态数据，每个状态包含：开关状态、电流值、磁力线数量/长度、弹簧长度、指针位置、示数值
  8. 磁力线绘制：用 SVG path 绘制贝塞尔曲线，根据步骤动态调整路径点和数量
  9. 弹簧绘制：用 SVG polyline 绘制锯齿线，根据步骤动态调整 y 坐标范围
  10. 指针移动：用 CSS transform: translateY() 实现平滑移动
