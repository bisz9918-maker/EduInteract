[图示主题与整合说明]
- 本图示主题：四棱锥 P-ABCD 的几何结构与平面垂直条件分析
- 整合的步骤/概念：
  1. 四棱锥基本结构展示（PA⊥底面，底面为菱形）
  2. 底面菱形性质：对角线 AC⊥BD
  3. PA⊥底面推出 PA⊥BD
  4. BD⊥平面 PAC 的推导
  5. M 点在 PC 上的位置及 DM 连线
  6. DM⊥PC 条件的几何意义
  7. 平面 MBD⊥平面 PCD 的结论
- 教学价值：教师可通过分步演示，引导学生从已知条件逐步推导，理解空间几何中线面垂直、面面垂直的判定定理，培养空间想象能力和逻辑推理能力

[分步序列]
- 初始状态（步骤 0）：
  显示：四棱锥基本结构（所有棱线、顶点）
  高亮：无
  标签：显示 P、A、B、C、D 五个顶点标签
  标注：显示"PA⊥底面"标注在棱 PA 右侧
  隐藏：对角线 AC、BD，线段 DM、BM，动点 M，所有直角标记，平面填充

- 步骤 1：
  视觉变化：显示底面对角线 AC、BD（虚线），在对角线交点(380,330)处显示直角标记，显示标注"AC⊥BD"在对角线交点下方
  高亮：底面四边形 ABCD 的边 AB、BC、CD、DA 加粗显示
  新增元素坐标：对角线 AC(150,380)-(620,280)、BD(420,380)-(280,280)、直角标记(380,330)、标注文字(395,345)

- 步骤 2：
  视觉变化：棱 PA 加粗高亮（3px→5px），在 A 点(165,365)处显示直角标记
  高亮：棱 PA 变为蓝色#1565c0
  说明：PA⊥底面 ABCD ⇒ PA⊥BD

- 步骤 3：
  视觉变化：对角线 BD 加粗高亮（2px→4px），显示文字说明"BD⊥平面 PAC"
  高亮：BD 变为绿色#2e7d32，同时高亮 PA（蓝色）和 AC（蓝色）
  说明：BD⊥PA 且 BD⊥AC ⇒ BD⊥平面 PAC

- 步骤 4：
  视觉变化：在 PC 棱上显示动点 M(420,180)，显示线段 DM、BM（虚线）
  新增元素：点 M 圆圈、线段 DM(280,280)-(420,180)、线段 BM(420,380)-(420,180)
  标签：显示标签"M"在点 M 右上方(435,170)

- 步骤 5：
  视觉变化：在 M 点(410,190)处显示直角标记，显示标注"DM⊥PC"在 M 点右上方(440,200)
  高亮：线段 DM 变为绿色#2e7d32，线段 PC 变为绿色#2e7d32
  说明：当 DM⊥PC 时，PC⊥平面 MBD

- 步骤 6（最终步骤）：
  视觉变化：平面 MBD 显示蓝色半透明填充，平面 PCD 显示红色半透明填充
  高亮：平面 MBD 填充#1565c0 opacity=0.2，平面 PCD 填充#c62828 opacity=0.2
  标注：显示结论"平面 MBD⊥平面 PCD"在图示上方中央
  说明：PC⊂平面 PCD 且 PC⊥平面 MBD ⇒ 平面 MBD⊥平面 PCD

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮：ID=scene1-prev，位置(250,455)，作用：返回上一步骤，可回退复习
  - 下一步按钮：ID=scene1-next，位置(520,455)，作用：进入下一步骤，展示新的几何关系
  - 步骤指示器：ID=scene1-step-indicator，位置(370,460)，作用：显示当前步骤"步骤 X/7"
- 教师操作流程：
  1. 初始展示四棱锥结构，讲解已知条件（PA⊥底面，底面为菱形）
  2. 点击"下一步"，展示底面对角线垂直关系
  3. 点击"下一步"，强调 PA⊥底面的推论
  4. 点击"下一步"，推导 BD⊥平面 PAC
  5. 点击"下一步"，引入动点 M 和线段 DM
  6. 点击"下一步"，展示关键条件 DM⊥PC
  7. 点击"下一步"，展示最终结论平面 MBD⊥平面 PCD
  8. 可随时点击"上一步"回退，帮助学生理解推导逻辑

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  原因：几何图形绘制用 SVG 最精确，动画和状态切换用原生 JS 即可，无需额外库
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    四棱锥 P-ABCD                        │
  │                                                         │
  │                    P(150,80)                            │
  │                   /│\\                                  │
  │                  / │ \\                                 │
  │                 /  │  \\                                │
  │                /   │   \\                               │
  │               /    │    \\                              │
  │              /     M     \\                             │
  │             /    (420,180) \\                           │
  │            /         │      \\                          │
  │           /          │       \\                         │
  │    D(280,280)--------│--------C(620,280)               │
  │          \\          │      //                          │
  │           \\         │     //                           │
  │            \\        │    //                            │
  │             \\       │   //                             │
  │              \\      │  //                              │
  │               \\     │ //                               │
  │                \\    |/                                 │
  │                 \\   /                                  │
  │                  \\ /                                   │
  │               A(150,380)-------B(420,380)               │
  │                                                         │
  │  ┌─────────────────────────────────────────────────┐   │
  │  │        [上一步]    步骤 0/7    [下一步]          │   │
  │  └─────────────────────────────────────────────────┘   │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep 记录当前步骤（0-6），每个步骤对应一个状态对象，包含该步骤应显示/高亮的元素 ID 列表
  2. 坐标计算：所有元素坐标已在布局坐标表中精确定义，SVG 元素直接用这些坐标
  3. 动画曲线：元素显示/隐藏用 opacity 过渡（transition: opacity 0.3s ease），高亮用 stroke-width 和 stroke 颜色过渡
  4. 事件绑定：上一步/下一步按钮点击事件，更新 currentStep，调用 updateScene() 函数刷新显示
  5. updateScene() 函数：根据 currentStep，遍历状态对象，设置对应元素的 display/opacity/stroke/fill 属性
  6. ID 命名规范：所有交互元素 ID 以 scene1- 为前缀（如 scene1-prev、scene1-next、scene1-step-indicator、scene1-vertex-p、scene1-edge-pa 等）
  7. IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
  8. 直角标记绘制：用 SVG path 绘制 L 形，如 d="M 165 380 L 165 365 L 180 365"
  9. 平面填充：用 SVG polygon 元素，设置 fill 颜色和 opacity 属性
  10. 初始状态：页面加载后自动显示步骤 0，按钮根据当前步骤启用/禁用（步骤 0 时上一步禁用，步骤 6 时下一步禁用）
