[图示主题与整合说明]
- 本图示主题：四棱锥侧面斜高计算与侧面积求解
- 整合内容：前后侧面斜高计算、左右侧面斜高计算、侧面积汇总、总表面积计算

[分步序列]
- 步骤0（初始状态）：
  - 显示：四棱锥立体图（所有侧棱、底面边、高PO虚线）、顶点P和底面顶点A/B/C/D/O标签
  - 隐藏：斜高辅助线、侧面填充、计算图示区
  - 右侧显示标题"四棱锥斜高与侧面积计算"

- 步骤1：点击「下一步」
  - 新增：前后侧面△PAB和△PCD填充蓝色高亮（透明度20%）
  - 新增：斜高l1辅助线（红色虚线，从P到底边AB/CD中点）
  - 右侧新增：勾股定理△1图示（绿色直角三角形）
  - 右侧新增文本："前后侧面斜高 l₁ = √(h² + (b/2)²) = √(4² + 1²) = √17"

- 步骤2：点击「下一步」
  - 保持：步骤1所有元素
  - 新增文本："前后侧面积 = 2 × (1/2 × 6 × √17) = 6√17"
  - 勾股定理△1标注：竖直边"4"，水平边"1"，斜边"l₁=√17"

- 步骤3：点击「下一步」
  - 变化：前后侧面填充变淡（透明度10%），左右侧面△PBC和△PDA填充蓝色高亮（透明度20%）
  - 新增：斜高l2辅助线（红色虚线，从P到底边BC/DA中点）
  - 右侧新增：勾股定理△2图示（绿色直角三角形）
  - 右侧新增文本："左右侧面斜高 l₂ = √(h² + (a/2)²) = √(4² + 3²) = 5"

- 步骤4：点击「下一步」
  - 保持：步骤3所有元素
  - 新增文本："左右侧面积 = 2 × (1/2 × 2 × 5) = 10"
  - 勾股定理△2标注：竖直边"4"，水平边"3"，斜边"l₂=5"

- 步骤5：点击「下一步」
  - 变化：所有侧面填充恢复透明度20%，高亮边框加粗
  - 右侧新增文本："侧面积总和 = 6√17 + 10"
  - 右侧新增：底面积 = 6 × 2 = 12

- 步骤6（最终步骤）：点击「下一步」
  - 变化：四棱锥整体加粗边框，所有侧棱高亮
  - 右侧新增："表面积 = 侧面积 + 底面积 = 6√17 + 10 + 12 = 6√17 + 22"
  - 右侧最终答案框："答案：6√17 + 22"（绿色边框高亮）

  - 按钮"◀ 上一步"：ID=scene2-btn-prev，位置(250,430)，作用：返回上一步骤，步骤0时禁用

- 教师操作流程：

  3. 继续下一步，展示前后侧面积计算
  4. 继续下一步，高亮左右侧面，展示斜高l2的勾股定理计算
  5. 继续下一步，展示左右侧面积计算
  6. 继续下一步，汇总所有侧面积和底面积

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（几何图形简单，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │  四棱锥斜高与侧面积计算                                         │
  │                                                                │
  │  ┌──────────────────────┐  ┌─────────────────────────────────┐ │
  │  │                      │  │  勾股定理计算区                  │ │
  │  │    四棱锥立体图       │  │  △1: l₁=√(4²+1²)=√17           │ │
  │  │    (带辅助线)         │  │  △2: l₂=√(4²+3²)=5             │ │
  │  │                      │  │  侧面积 = 6√17 + 10             │ │
  │  │    P                 │  │  底面积 = 12                    │ │
  │  │   /│\                │  │  表面积 = 6√17 + 22             │ │
  │  │  / │ \               │  │                                 │ │
  │  │ A──┼──B              │  │                                 │ │
  │  │ │  O  │              │  │                                 │ │
  │  │ D─────C              │  │                                 │ │
  │  └──────────────────────┘  └─────────────────────────────────┘ │
  │                                                                │
  │              [◀ 上一步]          [下一步 ▶]                    │
  └────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：currentStep变量(0-6)，updateScene()函数根据currentStep显示/隐藏元素
  2. 坐标计算：四棱锥透视使用简单斜投影，顶点P(230,100)，底面中心O(230,340)
  3. 动画曲线：元素出现使用 opacity 渐变 (0→1，duration 300ms)
  4. 事件绑定：按钮点击事件监听，边界检查（步骤0禁用prev，步骤6禁用next）
  5. ID 命名规范：所有元素 ID 以 scene2- 为前缀（如 scene2-vertex-p, scene2-edge-pa, scene2-face-front）
  6. IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局污染
  7. 侧面填充：使用 polygon 元素，fill="#1565c0" fill-opacity="0.2"
  8. 辅助线样式：stroke="#c62828" stroke-dasharray="5,5"（斜高），stroke="#888888" stroke-dasharray="3,3"（高）
  9. 勾股定理直角符号：在直角顶点处绘制小正方形（边长8px）
