[图示主题与整合说明]
- 本图示主题：导体棒在倾斜 U 形框架上下滑的电磁感应过程与受力分析
- 整合内容：整合了装置结构展示、磁场方向标注、导体棒运动、感应电动势产生、感应电流方向、安培力方向、受力分析、最大速度条件等全部核心概念
- 教学价值：教师可逐步引导学生理解电磁感应的因果关系——从装置→磁场→运动→感应→受力→平衡，每一步都有明确的视觉提示，便于课堂讲解和学生理解物理过程

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：位置 (280,450)，作用：返回上一步骤
  - "下一步 ▶"按钮：位置 (520,450)，作用：进入下一步骤
  - 步骤指示器：位置 (380,420)，显示"步骤 X/6"
- 教师操作流程：
  1. 从步骤 0 开始，先讲解装置结构（U 形框架、导体棒、倾斜角度）
  2. 点击"下一步"至步骤 1，讲解磁场方向（垂直框架平面向上）
  3. 点击"下一步"至步骤 2，讲解导体棒下滑运动
  4. 点击"下一步"至步骤 3，讲解感应电流产生及方向（右手定则）
  5. 点击"下一步"至步骤 4，讲解安培力产生及方向（左手定则）
  6. 点击"下一步"至步骤 5，进行受力分析对比
  7. 点击"下一步"至步骤 6，讲解平衡条件及最大速度概念
  8. 可随时点击"上一步"回退复习

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    图示区 800×500                       │
  │                                                         │
  │         B↑                                              │
  │          │                                              │
  │    M─────┼─────N    F_安←→mg sinθ                       │
  │   ╱      │      ╲                                       │
  │  ╱       ↓v      ╲                                      │
  │ ╱─────────────────╲                                     │
  │ ╲                 ╱                                     │
  │  ╲               ╱                                      │
  │   ╲             ╱                                       │
  │    ╲───────────╱                                        │
  │      θ=30°                                              │
  │  ───────────────────────────────── 水平参考线            │
  │                                                         │
  │          步骤指示器：步骤 0/6                            │
  │      [◀ 上一步]              [下一步 ▶]                 │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep 记录当前步骤（0-6），每一步对应一个元素显示数组
  2. 坐标计算：使用 SVG 绝对坐标，所有元素位置预先计算好
  3. 动画曲线：步骤 6 的平衡状态高亮使用 CSS 动画（opacity 0.5-1 循环）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后重新渲染对应元素
  5. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-frame-left、scene1-rod、scene1-field-B 等）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 元素显示控制：用 display: none/block 控制各步骤元素的显示/隐藏
  8. 平衡状态高亮：步骤 6 时，F_安和 mg sinθ 箭头添加 class "highlight"，CSS 定义闪烁动画
