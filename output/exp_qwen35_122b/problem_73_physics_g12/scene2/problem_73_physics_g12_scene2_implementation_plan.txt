[图示主题与整合说明]
- 本图示主题：电磁感应过程中的能量转化与电量计算
- 整合内容：整合了能量转化关系（重力势能→动能+电能）、电功率计算、电量计算等核心概念
- 教学价值：教师可通过分步展示，引导学生理解导体棒下滑过程中的能量守恒关系，以及电功率和电量的物理意义。逐步揭示公式推导过程，帮助学生建立完整的物理图像。

[分步序列]
- 步骤 0（初始状态）：
  - 显示标题"能量转化与电量计算"
  - 显示三个能量框（重力势能、动能、电能）的框架（仅边框，无内容）
  - 显示电功率框和电量框的框架（仅边框，无内容）
  - 转化箭头不显示
  - 下滑示意区不显示
  - 按钮状态：上一步禁用，下一步启用

- 步骤 1（点击下一步）：
  - 重力势能框内显示"重力势能"和"ΔE_p = mgh"
  - 显示从重力势能框出发的箭头（箭头 1）
  - 其他框仍为空框架

- 步骤 2（点击下一步）：
  - 动能框内显示"动能"和"ΔE_k = ½mv_m²"
  - 显示箭头 2（重力势能→动能）
  - 重力势能框高亮（加深边框）

- 步骤 3（点击下一步）：
  - 电能框内显示"电能"和"Q_电 = 1.5J"（Q_电=1.5J 用红高亮 #c62828）
  - 显示箭头 3（重力势能→电能）
  - 显示能量守恒关系文字（可选）："ΔE_p = ΔE_k + Q_电"

- 步骤 4（点击下一步）：
  - 电功率框内显示"P = I²R"和"= B²L²v_m²/R"
  - 电功率框高亮（加深边框）
  - 显示推导提示："当 v = v_m 时，P 最大"

- 步骤 5（点击下一步）：
  - 电量框内显示"q = It = ΔΦ/R"和"= BLx/R"
  - 电量框高亮（加深边框）
  - 显示下滑示意区（斜面线、x 标注线、x 标签、ΔΦ 标注）
  - 显示最终结论："q = ΔΦ/R = BLx/R"

- 教师操作流程：
  1. 初始展示能量框框架，引导学生思考能量转化关系

  4. 推导电功率公式 P = B²L²v_m²/R
  5. 推导电量公式 q = BLx/R，结合下滑距离 x 和磁通量变化 ΔΦ

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何和文本，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │                    能量转化与电量计算                           │  y=20
  │                                                                │
  │  ┌──────────────┐                    ┌──────────────────────┐  │
  │  │ 重力势能     │                    │    电功率 P          │  │
  │  │ ΔE_p=mgh     │                    │ P=I²R=B²L²v_m²/R     │  │
  │  └──────┬───────┘                    └──────────────────────┘  │
  │         │                                                      │
  │  ┌──────┴───────┐         ┌──────────────┐                    │
  │  │ 动能         │         │    电量 q    │                    │
  │  │ ΔE_k=½mv_m²  │         │ q=It=ΔΦ/R    │                    │
  │  └──────────────┘         │ =BLx/R       │                    │
  │                           └──────────────┘                    │
  │                                                                │
  │                    ──────╱  x  ──────                          │
  │                          ΔΦ=BLx                                │
  │                                                                │
  │              [◀ 上一步]              [下一步 ▶]                │  y=450
  └────────────────────────────────────────────────────────────────┘
  ```

- 关键实现要点：
  1. 状态机设计：用变量 currentStep 记录当前步骤（0-5），根据步骤控制元素显示/隐藏
  2. 坐标计算：所有元素使用绝对定位，SVG 内使用 viewBox="0 0 800 500"
  3. 动画曲线：元素出现使用 opacity 淡入动画（0→1，duration=300ms）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 renderStep() 重绘
  5. ID 命名规范：所有元素 ID 以 scene2- 为前缀（如 scene2-rect-gpe、scene2-text-deltaEp）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染

- 元素显示控制：
  - 步骤 0：显示标题、所有框边框
  - 步骤 1：+ 重力势能框内容、箭头 1
  - 步骤 2：+ 动能框内容、箭头 2
  - 步骤 3：+ 电能框内容、箭头 3
  - 步骤 4：+ 电功率框内容
  - 步骤 5：+ 电量框内容、下滑示意区

- MathJax 公式渲染（可选）：如需更美观的数学公式，可引入 MathJax CDN，用 $$...$$ 包裹公式
