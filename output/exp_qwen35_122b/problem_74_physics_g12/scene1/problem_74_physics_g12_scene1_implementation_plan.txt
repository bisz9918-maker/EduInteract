[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "上一步"按钮：scene1-btn-prev，位置 (250,460)，作用：返回上一状态
  - "下一步"按钮：scene1-btn-next，位置 (550,460)，作用：进入下一状态
  - 步骤指示器：scene1-step-indicator，位置 (380,460)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始展示完整装置，让学生观察整体结构
  2. 点击"下一步"，逐步高亮线圈并标注其参数
  3. 继续点击，依次展示砝码、磁场区域
  4. 最后展示物理过程标注，引导学生理解电磁感应原理
  5. 可随时点击"上一步"回退复习

- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量跟踪当前步骤 (0-4)
  2. 坐标计算：所有元素使用绝对坐标，确保精确位置
  3. 动画曲线：元素出现使用 opacity 渐变 (0→1)，持续时间 300ms
  4. 事件绑定：按钮点击事件监听，更新状态并重绘
  5. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-coil-rect、scene1-magnet-rect）
  6. JS 使用 getElementById 获取元素，避免 querySelectorAll 全局污染
  7. 所有 JS 代码包在 IIFE (function() { ... })() 中隔离作用域
  8. 磁场×符号使用循环生成，均匀分布在磁场区域内
  9. 步骤 4 的物理过程标注使用箭头和文字组合显示
