problem_75_physics_g12

场景导航：Scene 1 | Scene 2

题目原文：
如图所示，一平行板电容器水平放置，板间距离为d，上极板开有一小孔，三个质量均为m、带电荷量均为+q的带电小球，其间用长为L的绝缘轻杆相连，处于竖直状态，已知 d=3L。今使下端小球恰好位于小孔中，且由静止释放，让三球竖直下落．当下端小球到达下极板时，速度恰好为零． 试求：
（1）两极板间的电压 U
（2）小球运动的最大速度．

题目分析：
本题是带电小球在重力场和电场复合场中的运动问题，核心在于能量守恒和受力分析。

关键物理过程：

  1. 初始状态：三球竖直排列，下端小球恰在上极板小孔处
  2. 释放后：三球在重力作用下竖直下落
  3. 进入电场：小球依次进入电场，受到向上的电场力
  4. 速度变化：先加速后减速，当下端小球到达下极板时速度为零

解题思路：

  1. 用能量守恒求电压：重力做功 = 电场力做功
  2. 求最大速度：合力为零时速度最大，再用动能定理

图示规划：

  • Scene 1：初始状态与运动过程概览（分步导航展示三球进入电场的不同阶段）
  • Scene 2：能量转化分析（展示重力做功与电场力做功的关系）
步骤 0/4

Scene 1 教学说明：

本图示用于展示三球系统从释放到下端小球到达下极板的完整运动过程。教师应按以下步骤引导学生观察：

  1. 初始状态（步骤0）：强调三球竖直排列，下端小球恰在上极板小孔处，系统静止。此时只有重力势能，动能为0。
  1. 进入电场过程（步骤1-3）：
  • 步骤1：第一球进入电场，开始受到向上的电场力 F = qE
  • 步骤2：前两球在电场中，电场力 F = 2qE
  • 步骤3：三球都在电场中，电场力 F = 3qE
  • 引导学生观察：随着进入电场的球数增加，电场力逐渐增大
  1. 速度变化规律：
  • 初始阶段：重力 > 电场力，加速下落
  • 中间阶段：重力 = 电场力，速度最大
  • 后期阶段：重力 < 电场力，减速下落
  • 末状态：下端小球到达下极板，速度恰好为0
  1. 最大速度位置（步骤4）：
  • 当合力为零时速度最大
  • 此时重力 3mg = 电场力（与进入电场的球数有关）
  • 用绿色标记该位置，便于后续计算

关键问题引导：

  • 为什么速度会先增大后减小？
  • 电场力是如何变化的？
  • 最大速度出现在什么位置？
步骤 1/5

Scene 2 教学说明：

本图示用于能量守恒分析，帮助学生理解重力做功与电场力做功的关系。

讲解要点：

  1. 重力做功计算（步骤1）：
  • 三球总质量 3m，下落距离 d
  • W_G = 3mgd（正功，重力势能转化为动能）
  1. 电场力做功计算（步骤2）：
  • 第一球：进入电场距离 d，做功 -qEd
  • 第二球：进入电场距离 d-L，做功 -qE(d-L)
  • 第三球：进入电场距离 d-2L，做功 -qE(d-2L)
  • 总电场力做功：W_E = -qE[d + (d-L) + (d-2L)] = -qE(3d - 3L)
  • 已知 d = 3L，代入得：W_E = -qE(9L - 3L) = -6qEL
  1. 能量守恒（步骤3）：
  • 初动能 Ek1 = 0，末动能 Ek2 = 0
  • ΔEk = WG + W_E = 0
  • 3mgd - 6qEL = 0
  • 代入 d = 3L：9mgL - 6qEL = 0
  • 解得：E = 3mg/(2q)
  1. 电压计算（步骤4）：
  • U = Ed = 3mg/(2q) × 3L = 9mgL/(2q)

最大速度求解：

  • 最大速度出现在合力为零时
  • 设第一球进入电场距离为 x 时合力为零
  • 3mg = qE（仅第一球在电场中）
  • 或 3mg = 2qE（前两球在电场中）
  • 或 3mg = 3qE（三球都在电场中）
  • 判断哪个阶段合力为零，再用动能定理求 v_max

课堂建议：

  • 先让学生独立计算重力做功和电场力做功
  • 再引导学生建立能量守恒方程
  • 最后讨论最大速度的求解方法
