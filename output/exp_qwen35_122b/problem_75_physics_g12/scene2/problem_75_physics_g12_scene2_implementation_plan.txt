[分步序列]
步骤 0（初始状态）：
- 显示：上极板、下极板、板间距离标注 d、三球系统（球 1/2/3 及连接杆）、杆长标签 L
- 右侧区域：显示标题"能量转化与做功分析"
- 能量守恒框：显示"初始状态：系统静止，动能为 0"
- 公式区域：空白
- 步骤指示器：显示"步骤 1/5"

步骤 1：
- 新增：重力做功箭头（绿色向下）及标签 W_G = 3mgd
- 能量守恒框：更新为"重力做功：W_G = 3mgd（三球总重力做功）"
- 公式区域：显示"W_G = mg·d + mg·d + mg·d = 3mgd"
- 步骤指示器：显示"步骤 2/5"

步骤 2：
- 新增：电场力做功箭头（红色向上）及标签 W_E = -qE[d + (d-L) + (d-2L)]
- 能量守恒框：更新为"电场力做功：W_E = -qE[d + (d-L) + (d-2L)]"
- 公式区域：显示"W_E = -qE·d - qE·(d-L) - qE·(d-2L)"
- 步骤指示器：显示"步骤 3/5"

步骤 3：
- 能量守恒框：更新为"能量守恒：ΔE_k = W_G + W_E = 0"
- 公式区域：显示"初末动能均为 0，故 W_G + W_E = 0"
- 步骤指示器：显示"步骤 4/5"

步骤 4（最终结论）：
- 电场强度公式：显示"E = U/d"
- 电压公式区域：显示"U = 3mgd/q - 3mgL/q"（或化简后的表达式）
- 能量守恒框：高亮显示最终能量关系
- 步骤指示器：显示"步骤 5/5"

- 关键实现要点：
  1. 状态机设计：使用变量 currentStep（0-4）跟踪当前步骤
  2. 坐标计算：所有元素使用绝对坐标，通过 SVG 元素 id 精确控制
  3. 动画曲线：使用 CSS transition 实现元素淡入效果（opacity: 0→1）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 并刷新显示
  5. 元素显示控制：通过 setAttribute('display', 'none/block') 控制元素可见性
  6. 文本更新：通过 textContent 动态更新公式内容

- ID 命名规范：
  - 所有交互元素 ID 以 scene2- 为前缀
  - 示例：scene2-ball1, scene2-ball2, scene2-ball3, scene2-plate-top, scene2-plate-bottom, scene2-arrow-gravity, scene2-arrow-electric, scene2-box-energy, scene2-formula-wg, scene2-formula-we, scene2-formula-conservation, scene2-formula-e, scene2-formula-u, scene2-prev-btn, scene2-next-btn, scene2-step-indicator

- IIFE 隔离：
  ```javascript
  (function() {
    // 所有 scene2 的 JS 代码封装在此
    const currentStep = 0;
    // ... 状态管理和事件处理
  })();
  ```

- 公式渲染：使用 MathJax 渲染复杂数学公式（可选，若公式简单可直接用 text 元素）
- 响应式：固定 800×500 画布，无需响应式适配
