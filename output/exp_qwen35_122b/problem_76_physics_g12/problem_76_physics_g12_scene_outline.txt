    **题目原文：**

    如图所示，在光滑水平面上有两个并排放置的木块A、B，已知m_A=0.5kg，m_B=0.3kg。现有质量m_0=0.08kg的小物块C以初速v_0=25m/s在A表面沿水平方向向右滑动，由于C与A、B间均有摩擦，C最终停在B上，B、C最后的共同速度v=2.5m/s。求：

    （1）A木块的最终速度的大小；
    （2）C物块滑离A木块的瞬时速度大小。

    **题目分析：**

    这是一道动量守恒定律的综合应用题，涉及多体系统的分阶段动量守恒分析。

    **关键物理过程：**

    1. **第一阶段**：C在A上滑动，A和B紧靠在一起共同运动
       - 系统：C + A + B
       - 动量守恒：m_C·v_0 = m_C·v_C1 + (m_A + m_B)·v_A1
       - 此阶段结束时，C滑离A，A获得速度v_A1

    2. **第二阶段**：C滑上B，A以v_A1匀速运动，B和C相互作用
       - 系统：C + B（A已分离）
       - 动量守恒：m_C·v_C1 + m_B·v_A1 = (m_C + m_B)·v_final
       - 最终状态：B和C共速v_final = 2.5m/s

    **解题思路：**

    1. 先分析第一阶段，建立C、A、B的动量守恒方程
    2. 再分析第二阶段，建立C、B的动量守恒方程
    3. 联立求解两个方程，得到v_A1和v_C1

    **图示规划说明：**

    本图示集合将展示：
    - Scene 1：初始状态与物理过程全景图，帮助学生理解整个物理过程的三个阶段
    - Scene 2：分阶段动量守恒分析图，通过分步导航展示两个阶段的动量守恒关系及求解过程

    **完整解答：**

    **第一阶段：C在A上滑动（C、A、B系统动量守恒）**

    设C滑离A时的速度为v_C1，此时A、B的共同速度为v_A（即A的最终速度）

    动量守恒方程：
    m_C·v_0 = m_C·v_C1 + (m_A + m_B)·v_A  ……①

    **第二阶段：C在B上滑动（C、B系统动量守恒）**

    C滑上B时，B的初速度为v_A，C的初速度为v_C1
    最终B、C共速v = 2.5m/s

    动量守恒方程：
    m_C·v_C1 + m_B·v_A = (m_C + m_B)·v  ……②

    **联立求解：**

    将已知数据代入方程②：
    0.08·v_C1 + 0.3·v_A = (0.08 + 0.3)×2.5
    0.08·v_C1 + 0.3·v_A = 0.95  ……③

    将已知数据代入方程①：
    0.08×25 = 0.08·v_C1 + (0.5 + 0.3)·v_A
    2 = 0.08·v_C1 + 0.8·v_A  ……④

    由③得：0.08·v_C1 = 0.95 - 0.3·v_A
    代入④：2 = (0.95 - 0.3·v_A) + 0.8·v_A
    2 = 0.95 + 0.5·v_A
    v_A = (2 - 0.95) / 0.5 = 2.1m/s

    将v_A = 2.1m/s代入③：
    0.08·v_C1 + 0.3×2.1 = 0.95
    0.08·v_C1 = 0.95 - 0.63 = 0.32
    v_C1 = 4m/s

    **答案：**
    （1）A木块的最终速度大小：v_A = 2.1m/s
    （2）C物块滑离A木块的瞬时速度大小：v_C1 = 4m/s

    **课堂讲解建议：**

    1. 强调动量守恒的条件：系统不受外力或合外力为零
    2. 引导学生识别每个阶段的系统边界（哪些物体参与动量守恒）
    3. 提醒学生注意速度的方向性（本题均为同向，取正值）
    4. 验证答案合理性：v_C1 > v_A > v，符合物理直觉（C减速，A、B加速）
