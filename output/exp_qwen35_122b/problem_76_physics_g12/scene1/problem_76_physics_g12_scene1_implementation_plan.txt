[图示主题与整合说明]
- 本图示主题：三物体系统动量守恒过程全景展示
- 整合的内容：初始状态 → C在A上滑动 → C滑离A → C在B上滑动 → 最终状态（五个关键时刻整合为分步动态图示）
- 教学价值：教师可通过分步演示，帮助学生理解多物体系统中动量守恒的分阶段应用，清晰展示每个阶段哪些物体参与相互作用、哪些物体独立运动

[分步序列]
- 步骤0（初始状态）：
  - 显示：地面、木块A、木块B、物块C（在A左端上方）
  - 显示：标签 m_A=0.5kg、m_B=0.3kg、m_C=0.08kg
  - 显示：速度矢量 v_0=25m/s（黑色实线箭头，从C上方指向右）
  - 隐藏：v_A、v_B、v_final 相关元素
  - 状态：C即将滑上A，A、B静止

- 步骤1（C在A上滑动）：
  - 显示：同步骤0，物块C位置移动到A中部上方 (200,220)-(250,270)
  - 显示：A、B共同向右运动的示意（可在A、B下方添加小箭头表示共同速度）
  - 状态：C在A上滑动，A、B作为一个整体共同运动

- 步骤2（C刚滑离A）：
  - 显示：物块C位置移动到B左端上方 (300,220)-(350,270)
  - 显示：速度矢量 v_A（灰色虚线箭头，从A右侧指向右，标注"v_A"待求）
  - 显示：速度矢量 v_B（黑色实线箭头，从B右侧指向右）
  - 隐藏：v_0 矢量
  - 状态：C刚离开A，A以v_A匀速运动，C滑上B

- 步骤3（C在B上滑动）：
  - 显示：物块C位置移动到B中部上方 (325,220)-(375,270)
  - 显示：v_A、v_B 矢量（v_B 长度逐渐变化示意）
  - 状态：C在B上滑动，B、C相互作用，B加速、C减速

- 步骤4（最终状态）：
  - 显示：物块C停在B上 (325,220)-(375,270)
  - 显示：速度矢量 v_final=2.5m/s（黑色实线箭头，从B、C上方指向右）
  - 显示：标签 v=2.5m/s（B、C最终共同速度）
  - 显示：v_A 矢量（灰色虚线，保持步骤2的速度）
  - 隐藏：v_B 单独矢量（被v_final替代）
  - 状态：B、C共速，A以v_A匀速远离

[标签冲突检查]

- 标签"m_B=0.3kg"：坐标 (370,255)
- 标签"m_C=0.08kg"：坐标 (170,205)
- 标签"v_0=25m/s"：坐标 (175,190)
- 标签"v_A"：坐标 (310,255)
- 标签"v=2.5m/s"：坐标 (350,205)
- 标签"A"：坐标 (220,310)
- 标签"B"：坐标 (370,310)
- 标签"C"：坐标 (170,245)

冲突检查：
- "m_A=0.5kg"(220,255) 与 "A"(220,310)：垂直间距 55px → 无冲突
- "m_B=0.3kg"(370,255) 与 "B"(370,310)：垂直间距 55px → 无冲突
- "m_C=0.08kg"(170,205) 与 "v_0=25m/s"(175,190)：水平间距 5px，垂直间距 15px → 对角距离约 16px，接近临界值
  - 解决方案：将 "v_0=25m/s" 上移至 (175,180)，垂直间距增至 25px → 无冲突
- "v_A"(310,255) 与 "m_B=0.3kg"(370,255)：水平间距 60px → 无冲突
- "v=2.5m/s"(350,205) 与 "m_C=0.08kg"(170,205)：水平间距 180px → 无冲突
- "C"(170,245) 与 "m_C=0.08kg"(170,205)：垂直间距 40px → 无冲突

调整后 "v_0=25m/s" 坐标为 (175,180)

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "上一步"按钮：scene1-btn-prev，位置 (250,455)，点击后步骤减1（步骤0时禁用）
  - "下一步"按钮：scene1-btn-next，位置 (450,455)，点击后步骤加1（步骤4时禁用）
  - 步骤指示器：scene1-step-indicator，位置 (350,420)，显示"步骤 X/4"
- 教师操作流程：
  1. 从步骤0开始讲解初始条件（C的初速度、三物体质量）
  2. 点击"下一步"到步骤1，讲解C在A上滑动时A、B共同运动的物理过程
  3. 点击"下一步"到步骤2，讲解C滑离A瞬间A获得最终速度v_A，引入第一问求解
  4. 点击"下一步"到步骤3，讲解C在B上滑动时B、C的相互作用
  5. 点击"下一步"到步骤4，展示最终状态B、C共速v=2.5m/s，引入动量守恒求解第二问
  6. 可随时点击"上一步"回退复习某个阶段

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形和状态切换，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：

- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-4) 跟踪当前步骤
  2. 坐标计算：所有元素使用绝对定位，通过 CSS transform 或 SVG 属性控制位置
  3. 动画曲线：元素位置变化使用 CSS transition (ease-in-out, 0.3s)
  4. 事件绑定：按钮点击事件更新 currentStep，调用 renderStep() 重绘
  5. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-block-A、scene1-block-C、scene1-arrow-v0）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 步骤渲染函数 renderStep(step)：根据 step 参数显示/隐藏对应元素，更新物块C位置
  8. 按钮状态管理：步骤0时禁用"上一步"，步骤4时禁用"下一步"
