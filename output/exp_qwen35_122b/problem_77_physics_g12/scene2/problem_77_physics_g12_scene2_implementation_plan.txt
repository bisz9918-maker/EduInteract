[分步序列]
本场景为连续拖拽交互，无分步导航，状态随滑块实时变化：

- 初始状态（t₀=0）：
  - 电压波形图显示完整方波（0~2T）
  - 入射时刻竖线位于t=0处
  - 高亮区间为[0,T]，显示该区间内电压分段
  - 加速度图显示t∈[0,T]内的加速度变化：0~2T/3段a向下（正值），2T/3~T段a向上（负值）

- 拖动过程中（t₀从0到T）：
  - 入射时刻竖线实时跟随滑块位置
  - 高亮区间[t₀,t₀+T]实时移动并更新
  - 加速度图根据t₀重新计算分段：
    * 若t₀∈[0,2T/3]：粒子在[t₀,2T/3]段a向下，[2T/3,T]段a向上，[T,t₀+T]段根据电压波形继续分段
    * 若t₀∈[2T/3,T]：粒子在[t₀,T]段a向上，[T,t₀+T]段根据电压波形继续分段
  - 实时显示当前t₀数值

- 最终状态（t₀接近T）：
  - 展示粒子在T时刻入射后的完整受力时序
  - 加速度图完整显示一个周期内的加速度变化

[交互方案]
- 交互类型：连续拖拽滑块 — 选择粒子入射时刻t₀（0 ≤ t₀ < T）
- 控件说明：
  - 滑块手柄：圆形，位于(250~550,465)，拖动控制t₀从0到T
  - 实时数值显示：在滑块上方显示"t₀ = X"（X为当前值，格式如"0.3T"）
- 教师操作流程：
  1. 初始展示t₀=0时粒子受力情况
  2. 教师拖动滑块，边拖边讲解："当粒子在t₀时刻入射，它在电场中飞行时间T，经历的时间段是[t₀,t₀+T]"
  3. 拖动到高亮区间跨越电压跳变点时强调："注意，粒子在飞行过程中电场方向会改变，加速度也随之改变"
  4. 对比不同t₀的加速度图："入射时刻不同，粒子经历的加速度分段就不同，这导致最终偏转位移不同"

- 关键实现要点：
  1. 坐标映射：时间t∈[0,2T]映射到x∈[80,720]，比例因子px_per_T = 320（因为T对应320px）
  2. 电压跳变点：2T/3对应x=80+320×(2/3)≈293，T对应x=80+320=400，5T/3对应x=80+320×(5/3)≈613
  3. 滑块拖动：监听mousedown/mousemove/mouseup事件，更新t₀值并重绘高亮区间和加速度图
  4. 加速度分段计算：根据t₀和电压波形，计算[t₀,t₀+T]内每个时间段的加速度方向
  5. 状态机：单一状态t₀，拖动时实时更新，无复杂状态转换
  6. 重绘优化：使用requestAnimationFrame平滑更新，避免频繁DOM操作

- ID 命名规范：所有交互元素 ID 以 scene2- 为前缀
  - scene2-voltage-axis-h（电压横轴）
  - scene2-voltage-axis-v（电压纵轴）
  - scene2-waveform（方波折线）
  - scene2-highlight-rect（高亮区间矩形）
  - scene2-t0-line（入射时刻竖线）
  - scene2-accel-axis-h（加速度横轴）
  - scene2-accel-axis-v（加速度纵轴）
  - scene2-accel-graph（加速度折线）
  - scene2-slider-track（滑块轨道）
  - scene2-slider-handle（滑块手柄）
  - scene2-t0-label（t₀数值显示）

- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
