场景导航：Scene 1 | Scene 2

题目原文：

如图所示，电阻忽略不计的、两根平行的光滑金属导轨竖直放置，其上端接一阻值为 3Ω 的定值电阻 R。在水平虚线 L₁、L₂ 间有一与导轨所在平面垂直的匀强磁场 B，磁场区域的高度为 d=0.5m。导体棒 a 的质量 mₐ=0.2kg、电阻 Rₐ=3Ω；导体棒 b 的质量 mᵦ=0.1kg、电阻 Rᵦ=6Ω，它们分别从图中 M、N 处同时由静止开始在导轨上无摩擦向下滑动，且都能匀速穿过磁场区域，当 b 刚穿出磁场时 a 正好进入磁场。已知金属棒始终与导轨接触良好且导轨足够长，设重力加速度为 g=10m/s²。（不计 a、b 之间的作用）求：

（1）a、b 两棒在磁场中运动的速度大小之比；
（2）b 棒穿过磁场过程，电阻 R 上产生的焦耳热。

题目分析：

本题是电磁感应与力学综合题，核心物理过程包括：

  1. 两棒从静止开始自由下落（无磁场区域）
  2. 进入磁场后匀速运动（重力与安培力平衡）
  3. b 穿出磁场时 a 正好进入磁场（时间关系）

关键物理关系：

  • 匀速运动条件：重力 = 安培力，即 mg = BIL = B²L²v/R_总
  • 由此可得 v = mgR_总/(B²L²)，速度与质量及总电阻有关
  • 能量守恒：匀速运动时重力做功全部转化为焦耳热

整体讲解思路：

  1. 首先展示装置结构，明确导轨、磁场区域、两棒初始位置
  2. 分析匀速运动时的受力平衡，推导速度表达式
  3. 利用时间关系求解速度比
  4. 计算焦耳热分配

图示规划说明：

  • Scene 1：装置结构与运动过程总览（分步展示两棒运动轨迹）
  • Scene 2：匀速运动受力分析与速度推导（分步展示受力平衡推导）
步骤 1/7

图示 1 教学说明：

本图示展示电磁感应装置的完整结构和两棒的运动过程。教师应引导学生按以下步骤观察：

  1. 首先观察装置结构：竖直平行导轨、顶部电阻、磁场区域位置
  2. 理解两棒初始位置关系：a 在 M 处，b 在 N 处，b 在 a 下方
  3. 观察关键时间关系：当 b 刚穿出磁场（到达 L₂）时，a 正好进入磁场（到达 L₁）

讲解要点：

  • 两棒同时由静止开始下滑，初始速度均为 0
  • 在无磁场区域，两棒均做自由落体运动
  • 进入磁场后，由于切割磁感线产生感应电流，受到安培力作用
  • 题目给出"都能匀速穿过磁场"，说明重力与安培力平衡

关键推导：
匀速运动时，受力平衡：
mg = F_安 = BIL

感应电动势：ε = BLv

回路总电阻：对于棒 a，R_总ₐ = R + Rₐ = 3Ω + 3Ω = 6Ω
对于棒 b，R_总ᵦ = R + Rᵦ = 3Ω + 6Ω = 9Ω

感应电流：I = ε/R总 = BLv/R总

安培力：F安 = BIL = B²L²v/R总

由 mg = B²L²v/R总 得：v = mgR总/(B²L²)

步骤 0/8

图示 2 教学说明：

本图示展示匀速运动的受力平衡分析和完整推导过程。教师应引导学生理解从受力平衡到速度表达式的推导逻辑。

讲解步骤：

  1. 受力分析：导体棒在磁场中匀速运动时，受重力 mg 向下，安培力 F_安向上，二力平衡
  1. 推导速度公式：
  • 感应电动势：ε = BLv
  • 感应电流：I = ε/R总 = BLv/R总
  • 安培力：F安 = BIL = B²L²v/R总
  • 由 mg = F安 得：v = mgR总/(B²L²)
  1. 计算两棒速度比：
  • 对棒 a：R_总ₐ = R + Rₐ = 3Ω + 3Ω = 6Ω
  • 对棒 b：R_总ᵦ = R + Rᵦ = 3Ω + 6Ω = 9Ω
  • vₐ = mₐgR总ₐ/(B²L²)，vᵦ = mᵦgR总ᵦ/(B²L²)
  • vₐ/vᵦ = (mₐR总ₐ)/(mᵦR总ᵦ) = (0.2×6)/(0.1×9) = 12/9 = 4/3
  1. 利用时间关系验证：
  • b 从 N 到 L₁ 自由下落，a 从 M 到 L₁ 自由下落
  • b 穿过磁场时间 tᵦ = d/vᵦ
  • a 从 M 到 L₁ 的时间 = b 从 N 到 L₁ 的时间 + tᵦ
  • 由此可验证速度比的正确性
  1. 计算焦耳热：
  • b 棒匀速穿过磁场，重力做功 W = mᵦgd
  • 全部转化为焦耳热：Q_总 = mᵦgd = 0.1×10×0.5 = 0.5J
  • 热量分配与电阻成正比：QR/Q总 = R/(R + Rᵦ) = 3/(3+6) = 1/3
  • QR = Q总/3 = 0.5/3 ≈ 0.167J

课堂讲解建议：

  • 强调"匀速运动"意味着受力平衡，这是解题的关键条件
  • 引导学生注意两棒总电阻不同，导致速度不同
  • 焦耳热分配要说明是按电阻比例分配（串联电路）
