[图示主题与整合说明]
- 本图示主题：匀速运动受力平衡分析与速度比推导
- 整合内容：受力分析图 + 速度表达式推导 + 速度比计算 + 焦耳热计算
- 教学价值：教师可通过分步演示，引导学生理解导体棒匀速穿过磁场的受力平衡条件，逐步推导速度公式，最终计算速度比和焦耳热。图示将抽象的电磁感应问题可视化，帮助学生建立物理直觉。

[分步序列]
步骤 0（初始状态）：
- 显示：导轨、电阻 R、导体棒 a（M 处）、导体棒 b（N 处）、磁场区域（L1-L2 间）、d 标注、B 标签、×符号组
- 隐藏：所有力矢量、所有公式、参数表格
- 目的：展示题目基础条件

步骤 1：
- 新增：重力 mg 箭头（从 a 棒中心向下）、mg 标签
- 公式区显示：步骤 1 公式 "匀速运动：mg = F_安"
- 目的：引入受力分析，标注重力

步骤 2：
- 新增：安培力 F_安箭头（从 a 棒中心向上，与 mg 等长）、F_安标签
- 公式区显示：步骤 2 公式 "感应电动势：ε = BLv"
- 目的：展示受力平衡条件

步骤 3：
- 新增：速度 v 箭头（向下，较小）
- 公式区显示：步骤 3 公式 "感应电流：I = ε/R_总 = BLv/R_总"
- 目的：引入速度概念和电流公式

步骤 4：
- 公式区显示：步骤 4 公式 "安培力：F_安 = BIL = B²L²v/R_总"
- 目的：推导安培力表达式

步骤 5：
- 公式区显示：步骤 5 公式 "速度公式：v = mgR_总/(B²L²)"
- 高亮：速度公式为粗体
- 目的：得到速度表达式

步骤 6：
- 新增：参数表格（显示 a、b 两棒的 m、R、R_总）
- 公式区显示：步骤 6 公式 "R_总a = R∥Ra = 1.5Ω, R_总b = R∥Rb + R = 5Ω"
- 目的：计算两棒的总电阻

步骤 7：
- 公式区显示：步骤 7 公式 "vₐ/vᵦ = (mₐR_总a)/(mᵦR_总b) = (0.2×1.5)/(0.1×5) = 0.6"
- 高亮：速度比结果为绿色粗体
- 目的：计算速度比

步骤 8（最终步骤）：
- 公式区显示：步骤 8 公式 "Q_R = (R/(R+R_b))×mᵦgd = (3/9)×0.1×10×0.5 = 0.167J"
- 高亮：最终结果为绿色粗体 20px
- 目的：计算焦耳热，完成解答

- "B"与"d"：(200,300) 与 (15,300) → 间距 185px → 无冲突

- 参数表格与公式：表格从 y=280 开始，公式到 y=380 → 重叠 → 解决方案：步骤 6 才显示表格，步骤 6-8 公式在表格上方或表格内显示

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮：scene2-prev-btn，位置 (450,450)，作用：返回上一步，初始步骤 0 时禁用
  - 下一步按钮：scene2-next-btn，位置 (580,450)，作用：进入下一步，最终步骤 8 时禁用
  - 步骤指示器：scene2-step-indicator，位置 (680,455)，作用：显示当前步骤"步骤 k/8"
- 教师操作流程：
  1. 初始展示题目图形，让学生理解物理情境
  2. 点击"下一步"逐步引入受力分析，引导学生思考匀速运动的条件
  3. 继续点击"下一步"推导公式，每步停顿让学生理解
  4. 展示参数表格，对比两棒差异
  5. 最后展示计算结果，总结解题思路

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（线段、矩形、箭头、文本），无需复杂库；原生实现性能最佳，代码轻量
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：

- 关键实现要点：
  1. 状态机设计：用 currentStep 变量跟踪当前步骤（0-8），每一步定义要显示/隐藏/高亮的元素 ID 列表
  2. 坐标计算：所有元素使用绝对坐标，通过 SVG 的 x/y 属性精确控制位置
  3. 动画曲线：力矢量出现使用 opacity 渐变（0→1，300ms），公式显示使用淡入效果
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateScene() 刷新显示
  5. ID 命名规范：所有元素 ID 以 scene2- 为前缀，如 scene2-rail-left、scene2-rod-a、scene2-mg-arrow、scene2-formula-1 等
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 箭头绘制：使用 SVG 的 polyline 或 polygon 元素绘制箭头头部，line 元素绘制箭身
  8. 公式渲染：使用普通 text 元素，关键公式用 tspan 设置 font-weight="bold"
  9. 表格绘制：使用 SVG 的 rect 绘制单元格边框，text 放置内容
