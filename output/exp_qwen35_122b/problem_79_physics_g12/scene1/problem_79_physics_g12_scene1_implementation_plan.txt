- 步骤 1（标注已知条件）：新增标签"M=3kg"、"m=1kg"、"L=1.6m"（带尺寸虚线）、"μ=0.1"，展示题目给定参数
- 步骤 2（显示受力分析）：新增拉力 F 箭头（蓝色）、重力 G_m 和 G_M（绿色）、支持力 N_m 和 N_M（绿色），展示外力与竖直方向力

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "上一步"按钮：位于 SVG 底部左侧 (100,450)，点击返回前一状态
  - "下一步"按钮：位于 SVG 底部右侧 (650,450)，点击进入下一状态
  - 步骤指示器：位于底部中央 (350,455)，显示"步骤 1/4"
- 教师操作流程：
  1. 初始展示几何布局，让学生观察木板与物块的相对位置
  2. 点击"下一步"展示已知条件，引导学生识别题目参数
  3. 点击"下一步"展示外力与竖直方向力，讲解受力分析基础
  4. 点击"下一步"展示摩擦力，强调摩擦力方向判断和牛顿第三定律
  5. 可随时点击"上一步"回退复习，巩固关键概念

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────┐
  │                                                         │
  │                    μ=0.1                                │
  │                      ▲                                  │
  │                      │                                  │
  │              ┌──────────────┐                           │
  │              │   m=1kg      │                           │
  │              │              │                           │
  │              └──────────────┘                           │
  │                    │  ▲  │                              │
  │                    │  │  │                              │
  │  ┌─────────────────┴──┴──┴─────────────────┐            │
  │  │              M=3kg                      │───→ F      │
  │  └─────────────────────────────────────────┘            │
  │      ▲              │              ▲                    │
  │      │              │              │                    │
  │  ────┴──────────────┴──────────────┴────────────────    │
  │  地面（斜线填充）                                        │
  │           L=1.6m                                        │
  │                                                         │
  │  [◀ 上一步]                    步骤 1/4              下一步 ▶]  │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  - 状态机设计：用变量 currentStep (0-3) 跟踪当前步骤，每一步控制特定元素的 display 属性
  - 坐标计算：所有元素使用绝对坐标，通过 SVG 的 x/y 属性精确控制位置
  - 动画曲线：元素出现使用 opacity 从 0 到 1 的过渡动画，duration 300ms
  - 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateDisplay() 函数
  - ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-rect-board、scene1-arrow-F）
  - IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  - 元素分组：用 SVG <g> 标签将相关元素分组（如 scene1-group-forces），便于批量控制显示/隐藏
