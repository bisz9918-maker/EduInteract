  - "◀ 上一步" 按钮：位置 (250,460)，作用：回退到上一状态

- 教师操作流程：

  2. 点击"下一步"，展示力和加速度矢量，讲解力的作用
  3. 点击"下一步"，推导物块加速度，强调摩擦力决定最大加速度
  4. 点击"下一步"，用整体法计算最小拉力
  5. 点击"下一步"，展示最终结论，强调 F > 4N 的条件
  6. 可随时点击"上一步"回退复习关键步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（矩形、线段、箭头），原生 SVG 足够且性能好，无需引入重型库
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    图示区 800×500                       │
  │                                                         │
  │         物块 m                                          │
  │        ┌──────┐                                         │
  │        │      │  ←f    →F                               │
  │        └──────┘                                         │
  │  ┌──────────────────────────────────────────────┐       │
  │  │              木板 M                          │       │
  │  │                                              │  →a_M │
  │  └──────────────────────────────────────────────┘       │
  │  ←─────────────── L ────────────────────────────→       │
  │  ───────────────────────────────────────────────────    │ 地面
  │                                                         │
  │  ┌──────────────────────────────────────────────────┐   │
  │  │  步骤 0：初始状态                                 │   │
  │  │  步骤 1：临界条件：a_M = a_m                     │   │
  │  │  步骤 2：a_m = μg = 1m/s²                        │   │
  │  │  步骤 3：F_min = (M+m)a_m = 4N                   │   │
  │  │  结论：F > 4N 才能抽离                           │   │
  │  └──────────────────────────────────────────────────┘   │
  │                                                         │
  │         [◀ 上一步]        步骤 X / 5        [下一步 ▶]  │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep 记录当前步骤 (0-4)，每一步定义要显示/隐藏的元素 ID 列表
  2. 坐标计算：所有元素使用绝对坐标，箭头用 polyline 或 path 绘制，带箭头标记 marker
  3. 动画曲线：元素出现使用 opacity 从 0 到 1 的过渡动画，duration=300ms
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateScene() 刷新显示
  5. ID 命名规范：所有元素 ID 以 "scene2-" 为前缀，如 scene2-rect-M、scene2-arrow-F、scene2-text-step1
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 公式渲染：简单文本即可，无需 MathJax，数值计算在 JS 中完成
