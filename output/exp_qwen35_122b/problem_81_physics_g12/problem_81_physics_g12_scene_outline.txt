    **题目原文：**
    如图所示，A、B两物体的质量都为m，拉A物体的细线与水平方向的夹角为30°时处于静止状态，不考虑摩擦力，设弹簧的劲度系数为k．若悬线突然断开后，A在水平面上做周期为T的简谐运动，当B落地时，A恰好将弹簧压缩到最短，求：
    （1）A振动时的振幅；
    （2）B落地时的速度．

    **题目分析：**
    本题是简谐运动与自由落体运动的综合问题，涉及以下核心知识点：
    1. 初始平衡状态下的受力分析
    2. 简谐运动的振幅定义与运动规律
    3. 自由落体运动的时间计算
    4. 两个运动过程的时间关联

    **整体讲解思路：**
    首先分析初始平衡状态，确定弹簧的初始伸长量；然后分析悬线断开后的运动过程，建立A的简谐运动与B的自由落体运动之间的时间关系；最后利用时间关系求解振幅和落地速度。

    **图示规划说明：**
    - Scene 1：展示初始平衡状态，进行受力分析，计算初始弹簧伸长量
    - Scene 2：展示悬线断开后的运动过程，同步呈现A的简谐运动与B的自由落体运动，突出时间关联
    </TEXT_1>

    **图示1教学说明：**

    本图示展示系统初始平衡状态，教师应引导学生按以下步骤分析：

    1. **步骤0：系统初始配置**
    - 展示完整的物理系统：弹簧-A-细线-滑轮-B
    - 强调已知条件：m_A = m_B = m，θ = 30°，系统静止

    2. **步骤1：物体B的受力分析**
    - B受重力mg向下，细线拉力T向上
    - 平衡条件：T = mg

    3. **步骤2：物体A的受力分析**
    - A受四个力：
      - 重力mg向下
      - 支持力N向上
      - 细线拉力T，方向与水平成30°斜向上
      - 弹簧弹力F_弹，水平向左
    - 水平方向平衡：Tcos30° = F_弹
    - 竖直方向平衡：N + Tsin30° = mg

    4. **步骤3：计算初始弹簧伸长量**
    - 由胡克定律：F_弹 = kx₀
    - 代入平衡方程：mg·cos30° = kx₀
    - 解得：x₀ = (mg·cos30°)/k = (√3 mg)/(2k)

    **关键引导点：**
    - 强调平衡条件的应用：合力为零
    - 提醒学生注意力的分解：T的水平分量和竖直分量
    - 明确x₀是弹簧的初始伸长量，这是后续简谐运动的初始位置

    **图示2教学说明：**

    本图示展示悬线断开后的运动过程，重点突出两个运动的时间关联，教师应引导学生按以下步骤理解：

    1. **步骤0：悬线断开瞬间**
    - A位于初始位置（弹簧伸长x₀处）
    - B位于初始高度h处
    - t = 0时刻，两物体同时开始运动

    2. **步骤1：A运动至平衡位置，B下落一段距离**
    - A从初始位置向平衡位置运动
    - 这是简谐运动的1/4周期：t₁ = T/4
    - B自由下落距离：h₁ = (1/2)gt₁²

    3. **步骤2：A运动至压缩最短，B落地**
    - A从初始位置运动到压缩最短位置
    - 这是简谐运动的1/2周期：t₂ = T/2
    - B自由下落高度h，落地时间：t = √(2h/g)
    - **关键条件**：B落地时A恰好压缩到最短，故 t = T/2

    4. **步骤3：时间关系总结与求解**
    - 由时间关系：T/2 = √(2h/g)
    - 解得：h = gT²/8

    **求解（1）A振动时的振幅：**
    - 简谐运动的平衡位置：弹簧原长位置（此时弹力为零）
    - 初始位置：弹簧伸长x₀ = (√3 mg)/(2k)
    - 压缩最短位置：弹簧压缩x₀（对称性）
    - 振幅A = x₀ = (√3 mg)/(2k)

    **求解（2）B落地时的速度：**
    - 自由落体速度公式：v = gt
    - 落地时间：t = T/2
    - 故：v = gT/2

    **关键引导点：**
    - 强调"时间关联"是解题核心：B落地时间 = A运动到压缩最短的时间
    - 明确简谐运动的对称性：从最大伸长的初始位置到最大压缩位置，恰好是半个周期
    - 提醒学生注意振幅的定义：从平衡位置到最大位移的距离
    - 平衡位置是弹簧原长位置（弹力为零处），不是初始位置
