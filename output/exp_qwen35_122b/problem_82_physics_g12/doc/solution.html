problem_82_physics_g12

场景导航：Scene 1 | Scene 2 | Scene 3

题目原文：

如图所示，质量分别为 3m、2m、m 的三个小球 A、B、C 用两根长为 L 的轻绳相连，置于倾角为 30°、高为 L 的固定光滑斜面上，A 球恰能从斜面顶端外竖直落下，弧形挡板使小球只能竖直向下运动，碰撞过程中没有动能损失，小球落地后均不再反弹．由静止开始释放它们，不计所有摩擦，求：

（1）A 球刚要落地时的速度大小

（2）C 球刚要落地时的速度大小．

（3）在 B 球运动过程中，两绳对 B 球做的总功为多少．

题目分析：

本题是连接体系统的机械能守恒问题，涉及多阶段运动过程分析。

系统特点：

  • 三球通过轻绳连接，运动过程中绳长不变，速度大小相等（同一时刻）
  • 斜面光滑，无摩擦损耗，系统机械能守恒
  • 弧形挡板约束 A 球只能竖直下落

运动阶段划分：

  1. 第一阶段：A 球从斜面顶端竖直下落 L 距离至落地，此过程中 B、C 沿斜面向上运动 L 距离
  2. 第二阶段：A 落地后静止，B 继续沿斜面向上运动，带动 C 继续上升，直到 B 到达斜面顶端
  3. 第三阶段：B 从斜面顶端竖直下落，带动 C 继续运动

解题思路：

  • 第 (1) 问：对第一阶段用系统机械能守恒，A 重力势能减少量 = B、C 重力势能增加量 + 三球动能增加量
  • 第 (2) 问：需分段分析，先求 A 落地时速度，再分析 B 从斜面顶端下落过程
  • 第 (3) 问：对 B 球用动能定理，两绳拉力做功 = B 球动能变化量 + B 球重力做功

图示规划：

  • Scene 1：系统初始状态与三阶段运动过程概览（分步导航）
  • Scene 2：第一阶段能量转化分析（A 下落过程）
  • Scene 3：B 球受力分析与做功计算
初始状态

图示 1 教学说明：

本图示用于展示系统的初始状态和三个运动阶段的整体过程，帮助学生建立对题目物理情景的直观认识。

讲解要点：

  1. 初始状态分析
  • 三球静止释放，系统初动能为 0
  • A 球位于斜面顶端，即将竖直下落
  • B、C 球位于斜面上，绳长为 L，间距固定
  1. 第一阶段（A 下落过程）
  • A 球竖直下落距离 L，重力势能减少：ΔE_pA = 3mgL
  • B、C 球沿斜面上升距离 L，重力势能增加：ΔEpB = 2mg·L·sin30° = mgL，ΔEpC = mg·L·sin30° = 0.5mgL
  • 三球速度大小相等（绳不可伸长），设为 v₁
  • 系统机械能守恒：3mgL = mgL + 0.5mgL + ½(3m+2m+m)v₁²
  1. 第二阶段（B 继续上升）
  • A 落地后静止，不再参与运动
  • B 从斜面中点继续上升至顶端，上升距离 L
  • C 随之沿斜面上升距离 L
  • 此阶段 B、C 速度仍相等
  1. 第三阶段（B 下落带动 C）
  • B 从斜面顶端竖直下落
  • C 继续沿斜面向上运动
  • 需分析 B 下落过程中 C 的运动状态

引导学生观察：

  • 注意三球通过绳连接，速度大小始终相等（同一阶段内）
  • 注意重力势能变化与高度变化的关系（竖直高度 vs 斜面距离）
  • 注意各阶段能量转化的不同特点

图示 2 教学说明：

本图示专门用于讲解第一问：A 球刚要落地时的速度大小。

推导步骤：

  1. 确定初末状态
  • 初态：三球静止，v₀ = 0
  • 末态：A 下落 L，B、C 沿斜面上升 L，三球速度均为 v₁
  1. 计算重力势能变化
  • A 球：ΔE_pA = 3mg·L（减少，取正值）
  • B 球：ΔE_pB = 2mg·L·sin30° = mgL（增加）
  • C 球：ΔE_pC = mg·L·sin30° = 0.5mgL（增加）
  1. 应用机械能守恒

系统重力势能减少量 = 系统动能增加量

3mgL = mgL + 0.5mgL + ½(3m + 2m + m)v₁²

3mgL = 1.5mgL + 3mv₁²

1.5mgL = 3mv₁²

v₁² = 0.5gL

v₁ = √(gL/2)

关键提醒：

  • 注意斜面倾角 30°，沿斜面移动距离 L 对应的竖直高度变化是 L·sin30° = 0.5L
  • 三球速度大小相等，因为绳不可伸长
  • 系统总质量为 6m
步骤 1/4

图示 3 教学说明：

本图示用于讲解第三问：B 球运动过程中两绳对 B 球做的总功。

完整解答：

第 (1) 问答案：
v₁ = √(gL/2)

第 (2) 问分析：
A 落地后，B 继续从斜面中点上升至顶端（上升距离 L），此过程中 B、C 速度从 v₁变化到 v₂。

对 B、C 系统用机械能守恒（A 已静止）：

  • B 上升 L，势能增加：2mg·L·sin30° = mgL
  • C 上升 L，势能增加：mg·L·sin30° = 0.5mgL
  • 动能变化：½(2m+m)(v₂² - v₁²) = 1.5m(v₂² - v₁²)

但需注意：B 到达斜面顶端后将竖直下落，此时 C 的运动状态需要重新分析。

实际上，第 (2) 问"C 球刚要落地时的速度"需要分析 B 从斜面顶端下落的过程。

第 (3) 问解答（对 B 用动能定理）：

B 球从初始位置到最终落地的全过程：

  • 初动能：E_k0 = 0
  • 末动能：Ekf = ½(2m)vBf²

对 B 应用动能定理：
W总 = ΔEkB = Ekf - Ek0

WG + WT1 + WT2 = ½(2m)vBf² - 0

其中 WG 是重力做功，WT1 + W_T2 是两绳拉力总功（待求）。

B 球运动过程：

  1. 第一阶段：沿斜面上升 L，重力做功 W_G1 = -2mg·L·sin30° = -mgL
  2. 第二阶段：从斜面顶端竖直下落 L，重力做功 W_G2 = 2mgL

总重力做功：W_G = -mgL + 2mgL = mgL

两绳总功：
WT1 + WT2 = ½(2m)vBf² - mgL = mvBf² - mgL

需要求出 B 落地时的速度 v_Bf 才能得到具体数值。

课堂讲解建议：

  • 强调动能定理的应用：合外力做功 = 动能变化
  • 区分重力做功和绳子拉力做功
  • 注意 B 球运动分为两个阶段，重力做功需分段计算
  • 绳子拉力是变力，不能直接用 W = Fs 计算，必须用动能定理间接求解
