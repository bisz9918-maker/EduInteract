  - 上一步按钮：ID=scene2-prev-btn，位置 (280,455)，点击返回上一状态

- 教师操作流程：
  1. 初始展示系统配置，讲解各球初始高度
  2. 点击"下一步"，展示 A 下落、B/C 上升后的位置，讲解位移关系
  3. 点击"下一步"，展示能量转化箭头和守恒方程，讲解能量分配
  4. 点击"下一步"，展示速度计算结果，总结第一阶段分析
  5. 可随时点击"上一步"回退复习关键步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何和状态切换，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │                        图示区 800×500                          │
  │                                                                │
  │   斜面区                    高度标注区        能量分析区       │
  │   (100-300,280-420)        (65-330,260-440)  (550-780,100-470)│
  │                                                                │
  │     ▲                           │              势能减少(红)    │
  │    /│\                          │                ↓           │
  │   / │ \  A(3m)初始              │              势能增加(绿)   │
  │  /  │  \  ●虚线                 │                ↑           │
  │ /   │   \                      │              动能增加(蓝)   │
  │/ B(2m)初始                      │                →           │
  │●虚线                           │              [能量方程框]   │
  │ \  │                           │                              │
  │  \ │ C(m)初始                  │              [v1 结果框]     │
  │   \│●虚线                      │                              │
  │────┼───────────────────────────│────────────────────────────  │
  │ 斜面底边                       │                              │
  │                                │                              │
  │────────────────────────────────│────────────────────────────  │
  │              [◀上一步] [下一步▶] 控件栏 y=455                  │
  └────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-3) 跟踪当前步骤
  2. 元素分组：用 SVG <g> 标签按步骤分组元素，通过 display 属性控制显示/隐藏
  3. 坐标计算：所有坐标硬编码，确保精确到像素级
  4. 事件绑定：按钮点击事件监听，更新 currentStep 并刷新显示
  5. 初始状态：页面加载时显示步骤 0 元素
  6. ID 命名规范：所有交互元素 ID 以 scene2- 为前缀（如 scene2-tri-slope, scene2-ball-a-init, scene2-prev-btn 等）
  7. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  8. 元素显示控制：用 getElementById 获取元素，通过 style.display = 'block'/'none' 控制
