[分步序列]
- 初始状态（步骤0）：
  - 显示左侧斜面示意图（斜面轮廓、A/B/C三球位置、两根绳子、质量标签、长度标签、30°倾角）
  - 显示中间B球受力分析图（B球、T₁/T₂/G_B/N四个力箭头及标签）
  - 显示右侧公式框标题"两绳对B做功"
  - 步骤指示器显示"步骤 1/4"
  - 公式框内仅显示标题，其他内容隐藏

- 步骤1：点击「下一步」→
  - 在受力分析图中，T₁和T₂箭头高亮（加粗至4px）
  - 显示位移s₁箭头（沿斜面向上，虚线）和s₁=L标签
  - 公式框内显示：
    - W_T1 = T₁·s₁·cos180° = -T₁L
    - W_T2 = T₂·s₁·cos0° = T₂L
  - 步骤指示器显示"步骤 2/4"

- 步骤2：点击「下一步」→
  - 在受力分析图中，显示位移s₂箭头（竖直向下，虚线）和s₂=L标签
  - 公式框内显示：
    - W_total = W_T1 + W_T2
    - W_total = -T₁L + T₂L = (T₂ - T₁)L
  - 动能定理框显示：
    - 动能定理
    - ΔE_kB = W_total
  - 步骤指示器显示"步骤 3/4"

- 步骤3（最终步骤）：点击「下一步」→
  - 公式框内显示计算结果：
    - 由系统方程解得：T₁ = 2mg, T₂ = mg/2
    - W_total = (mg/2 - 2mg)L = -1.5mgL
  - 结果框高亮显示：W_total = -1.5mgL
  - 步骤指示器显示"步骤 4/4"
  - 下一步按钮变灰不可点击

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何和动画，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │                        图示区 800×500                          │
  │                                                                │
  │  [斜面示意]        [受力分析]        [公式/结果框]             │
  │  (50,200)          (400,180)         (620,80)                  │
  │  ┌─────┐           ○ B球              ┌──────────────┐         │
  │  │  /  │          ↗↑←↓力矢量          │ 两绳对B做功  │         │
  │  │ /30°│           │                  │ W_T1=...     │         │
  │  │/    │           │                  │ W_T2=...     │         │
  │  └─────┘           │                  │ W_total=...  │         │
  │  A B C球           │                  └──────────────┘         │
  │                    │                  ┌──────────────┐         │
  │                    │                  │ 动能定理     │         │
  │                    │                  │ ΔE_k=W_total │         │
  │                    │                  └──────────────┘         │
  │                    │                  ┌──────────────┐         │
  │                    │                  │ W_total=     │         │
  │                    │                  │ -1.5mgL      │         │
  │                    │                  └──────────────┘         │
  │                                                                │
  │                   步骤指示器 (370,410)                         │
  │                   [◀上一步] [下一步▶]                          │
  │                   (250,450)  (350,450)                         │
  └────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-3) 跟踪当前步骤，updateScene() 函数根据 currentStep 显示/隐藏对应元素
  2. 坐标计算：所有元素使用绝对坐标，力矢量箭头终点 = 起点 + 方向向量×长度
  3. 动画曲线：元素显示使用 opacity 渐变 (0→1)，时长 300ms
  4. 事件绑定：按钮点击事件调用 prevStep()/nextStep()，更新 currentStep 后调用 updateScene()
  5. ID 命名规范：所有元素 ID 以 scene3- 为前缀（如 scene3-tri-slope, scene3-ball-b, scene3-force-t1, scene3-btn-prev 等）
  6. JS 隔离：所有代码包在 (function() { ... })() IIFE 中，避免全局污染
  7. 元素分组：用<g>标签将相关元素分组（如斜面组、受力分析组、公式组），便于批量显示/隐藏
  8. 公式渲染：使用 MathJax 渲染复杂公式（如 W_T1 = T₁·s₁·cos180°）
