[图示主题与整合说明]
- 本图示主题：子弹射入滑块瞬间的动量守恒（场景 1）
- 整合内容：初始状态（小车+滑块向右运动，子弹向左运动）→ 子弹射入滑块 → 子弹与滑块获得共同速度
- 教学价值：教师可通过分步动画展示"时间极短"的物理含义，帮助学生理解动量守恒的适用条件（子弹射入瞬间，弹簧尚未压缩，小车速度未变）

[分步序列]
- 步骤 0（初始状态）：
  - 显示：地面、小车（含轮子）、弹簧（原长）、滑块、子弹
  - 显示：M 标签、m 标签、m₀标签
  - 显示：v₁箭头（蓝，向右）在滑块上方，v₁=10m/s 标签
  - 显示：v₀箭头（红，向左）在子弹上方，v₀=50m/s 标签
  - 显示：弹簧原长标注
  - 子弹位置：x=620（右侧远处）

- 步骤 1（子弹接触滑块）：
  - 子弹移动至 x=480（紧贴滑块右侧）
  - v₀箭头跟随子弹移动
  - 其他元素保持不变
  - 新增：子弹与滑块接触点高亮（红色闪烁效果）

- 步骤 2（子弹嵌入滑块，获得共同速度）：
  - 子弹与滑块合并为一个整体（视觉上子弹"嵌入"滑块内部）
  - 滑块+子弹整体向右移动一小段距离（x=400→420）
  - v₀箭头消失
  - 新增：v₂箭头（绿，向右）在滑块上方，v₂=? 标签
  - 滑块填充色变为 #e8f5e9（20% 透明度，绿色调）
  - 小车和弹簧保持不变（说明"时间极短"，小车速度未变）

- 步骤 3（标注动量守恒方程）：
  - 在图示下方显示动量守恒方程（控件栏上方区域）
  - 方程：m₀v₀（向左）+ mv₁（向右）= (m₀+m)v₂（向右）
  - 代入数值：0.2×50（←）+ 1.8×10（→）= (0.2+1.8)v₂
  - 箭头方向用颜色区分：红色←，蓝色→，绿色→
  - v₂标签更新为计算结果：v₂ = 4m/s（向右）

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 按钮"◀ 上一步"：位置 (280, 450)，作用：返回上一状态
  - 按钮"下一步 ▶"：位置 (520, 450)，作用：进入下一状态
  - 状态指示器：位置 (380, 450)，显示"步骤 k/3"
- 教师操作流程：
  1. 初始展示系统状态，讲解各物体质量和初速度
  2. 点击"下一步"展示子弹接触滑块瞬间
  3. 再次点击展示子弹嵌入后获得共同速度，强调"时间极短"含义
  4. 最后点击展示动量守恒方程，引导学生列式计算

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────┐
  │                                                         │
  │   v₁→        v₀←        v₂→                           │
  │  ┌─────┐    ┌───┐      ┌───┐                          │
  │   │ M   │←→ │ m │      │m₀ │                          │
  │  └──┬──┘    └───┘      └───┘                          │
  │     │ 弹簧                                            │
  │  ┌──┴──────────────────────────────────────┐          │
  │  │              小车底板                    │          │
  │  └─────────────────────────────────────────┘          │
  │     ○                              ○                  │
  │  左轮                            右轮                  │
  │  ─────────────────────────────────────────────────    │
  │  地面阴影（斜线）                                      │
  │                                                         │
  │  [◀ 上一步]  [步骤 k/3]  [下一步 ▶]                    │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：currentStep 变量 (0-3)，updateScene() 函数根据 currentStep 更新元素显示/隐藏和位置
  2. 坐标计算：所有元素使用绝对坐标，子弹移动通过改变 x 坐标实现
  3. 动画曲线：子弹移动使用 requestAnimationFrame 实现平滑过渡（可选）
  4. 事件绑定：按钮点击事件监听，边界检查（第一步禁用"上一步"，最后一步禁用"下一步"）
  5. 方程显示：步骤 3 动态生成 SVG text 元素显示动量守恒方程
- ID 命名规范：所有交互元素 ID 以 scene1- 为前缀（如 scene1-cart, scene1-block, scene1-bullet, scene1-v1-arrow, scene1-btn-prev, scene1-btn-next）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
