[图示主题与整合说明]
- 本图示主题：弹簧压缩到最短时的能量转化（场景 2）

[分步序列]
- 初始状态（步骤 0）：
  - 显示：地面、小车（蓝色）、滑块（绿色，含子弹标记）、弹簧（原长，黑色）
  - 显示：v₁箭头（蓝色，小车上方，v₁=10m/s 向右）
  - 显示：v₂箭头（绿色，滑块上方，v₂=4m/s 向右）
  - 显示：M 标签（左侧）、m+m₀标签（右侧）
  - 隐藏：v₃箭头、d 标注、能量框、能量守恒式
  - 说明：子弹射入瞬间后，滑块 + 子弹速度 v₂=4m/s，小车仍为 v₁=10m/s，弹簧原长

- 步骤 1：
  - 新增：v₃箭头（紫色，显示"v₃=?"，表示待求共速）
  - 弹簧保持原长，但用虚线框标注"开始压缩"
  - 滑块位置不变，但用箭头表示相对小车向左运动趋势
  - 说明：弹簧开始压缩，滑块相对小车向左运动

- 步骤 2：
  - 弹簧变为压缩状态（红色，长度缩短至 180px）
  - 滑块位置左移至 (300,220)-(420,280)
  - 显示：d 标注线（虚线双向箭头，标注压缩量 d=0.50m）
  - 显示：d 标签
  - v₁、v₂箭头消失，v₃箭头变为实线（标注"v₃=共速"）
  - 说明：弹簧压缩到最短时，三者共速

- 步骤 3：
  - 新增：能量框图（右侧，4 个能量框）
  - 新增：能量守恒公式
  - 弹簧保持压缩状态，用红色高亮
  - E_p弹框用红色高亮边框
  - Q_摩擦框用橙黄色高亮
  - 说明：能量转化关系 E_k初=E_k末+Q_摩擦+E_p弹

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 按钮"◀ 上一步"：位置 (280,450)，作用：返回上一状态
  - 按钮"下一步 ▶"：位置 (500,450)，作用：进入下一状态
  - 步骤指示器：位置 (380,420)，显示"步骤 X/4"
- 教师操作流程：
  1. 初始展示子弹射入后的状态（步骤 0）
  2. 点击"下一步"展示弹簧开始压缩（步骤 1）
  3. 点击"下一步"展示弹簧压缩到最短，三者共速（步骤 2）
  4. 点击"下一步"展示能量转化关系（步骤 3）
  5. 可随时点击"上一步"回退复习关键状态

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何动画，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────┐
  │  v₃=?  v₁=10m/s  v₂=4m/s                               │
  │    ↑      ↑        ↑                                   │
  │  ┌──────┐      ┌──────────┐                            │
  │  │挡板  │━━━━━━│ 滑块+子弹│  能量框图区                 │
  │  └──┬───┘弹簧  └──────────┘  ┌─────────────────────┐   │
  │     │                        │ E_k初               │   │
  │  ┌──┴────────────────────┐  │ E_k末               │   │
  │  │      小车 (M)         │  │ Q_摩擦              │   │
  │  └──○──────────────────○─┘  │ E_p弹               │   │
  │     轮              轮      └─────────────────────┘   │
  │  ━━━━━━━━━━━━━━━━━━━━━━━━━━  E_k初=E_k末+Q+E_p       │
  │  地面（斜线阴影）                                      │
  │                                                       │
  │         步骤指示器：步骤 0/4                           │
  │         [◀ 上一步]  [下一步 ▶]                        │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-3) 跟踪当前步骤
  2. 坐标计算：所有元素用绝对坐标，弹簧压缩时用 transform 或重新绘制
  3. 动画曲线：弹簧压缩用 CSS transition 或 requestAnimationFrame 平滑过渡
  4. 事件绑定：按钮点击事件更新 currentStep，调用 renderStep() 重绘
  5. 弹簧绘制：用 polyline 绘制螺旋线，压缩状态减少 x 范围
  6. 元素显示/隐藏：用 display 或 opacity 控制
- ID 命名规范：所有交互元素 ID 以 scene2- 为前缀（如 scene2-btn-next、scene2-spring、scene2-block）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局污染
