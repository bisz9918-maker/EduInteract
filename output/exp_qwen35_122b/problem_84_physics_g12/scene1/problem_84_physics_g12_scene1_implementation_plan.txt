[分步序列]
- 步骤 0（初始状态）：
  - 显示：上导轨、下导轨、电阻 R、金属棒 ab、点 a、点 b
  - 标签：L=1m、R=0.8Ω、r=0.2Ω、a、b、m=0.2kg、μ=0.5
  - 隐藏：磁场箭头、所有力箭头、平衡条件文字
  - 目的：展示装置基本结构

- 步骤 1：
  - 新增：5 个磁场箭头（竖直向上）
  - 新增标签：B=1T
  - 显示：步骤 0 所有元素 + 磁场箭头 + B=1T 标签
  - 目的：展示磁场环境

- 步骤 2：
  - 新增：外力 F 箭头（蓝色，向左）
  - 新增标签：F=3N
  - 显示：步骤 1 所有元素 + F 箭头 + F=3N 标签
  - 目的：展示主动力

- 步骤 3：
  - 新增：摩擦力 f 箭头（红色，向右）
  - 新增标签：f=μmg
  - 显示：步骤 2 所有元素 + f 箭头 + f=μmg 标签
  - 目的：展示摩擦阻力

- 步骤 4：
  - 新增：安培力 FA 箭头（红色，向右，与 f 平行但 y 坐标错开 10px）
  - 新增标签：FA
  - 显示：步骤 3 所有元素 + FA 箭头 + FA 标签
  - 目的：展示电磁感应产生的安培力

- 步骤 5（最终状态）：
  - 新增：平衡条件文字"F = FA + f（稳定状态）"
  - 高亮：三个力箭头同时加粗闪烁 2 次
  - 显示：步骤 4 所有元素 + 平衡条件文字
  - 目的：展示稳定状态的力平衡条件

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 按钮"◀ 上一步"：位置 (260,455)，作用：返回上一状态，若已在步骤 0 则禁用
  - 按钮"下一步 ▶"：位置 (440,455)，作用：进入下一状态，若已在步骤 5 则禁用
  - 按钮"重置"：位置 (350,455)，作用：返回步骤 0 初始状态
- 教师操作流程：
  1. 初始展示装置结构，讲解 U 形框架和金属棒的基本构造
  2. 点击"下一步"添加磁场，讲解匀强磁场方向
  3. 点击"下一步"添加外力 F，讲解主动力的作用
  4. 点击"下一步"添加摩擦力 f，讲解摩擦阻力
  5. 点击"下一步"添加安培力 FA，讲解电磁感应产生的力
  6. 点击"下一步"展示平衡条件，讲解稳定状态的物理意义
  7. 可随时点击"上一步"回退复习，或点击"重置"重新开始

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │                         图示区 800×500                       │
  │                                                             │
  │    B↑   B↑   B↑   B↑   B↑                                   │
  │    │    │    │    │    │                                   │
  │  ─┼────┼────┼────┼────┼───────────────────────────┐        │
  │  a│    │    │    │    │                           │ R      │
  │  /│    │    │    │    │                           │        │
  │ / │ F←─┼────┼────┼────┼───────────────────────────┘        │
  │b  │    │    │    │    │                                    │
  │  ─┼────┼────┼────┼────┼───────────────────────────┐        │
  │    │    │    │    │    │                           │        │
  │    L=1m  m=0.2kg  μ=0.5                            │        │
  │                                                   电阻 R    │
  │                                                             │
  │              F = FA + f（稳定状态）                          │
  │                                                             │
  │         [◀ 上一步]  [重置]  [下一步 ▶]                       │
  │                                                             │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-5) 跟踪当前步骤
  2. 元素分组：每个步骤新增的元素用 data-step 属性标记，如 data-step="1" 表示步骤 1 新增
  3. 坐标计算：所有元素使用绝对坐标，力箭头从金属棒中心 (300,250) 辐射
  4. 动画曲线：力箭头出现使用 opacity 渐变 (0→1，时长 300ms)
  5. 事件绑定：按钮点击事件监听，更新 currentStep 后重新渲染可见元素
  6. 平衡条件高亮：步骤 5 时，三个力箭头使用 CSS animation 闪烁 2 次
- ID 命名规范：所有交互元素 ID 以 scene1- 为前缀，如 scene1-step-btn-prev、scene1-step-btn-next、scene1-step-btn-reset、scene1-rod-ab、scene1-force-F、scene1-force-f、scene1-force-FA 等
- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
