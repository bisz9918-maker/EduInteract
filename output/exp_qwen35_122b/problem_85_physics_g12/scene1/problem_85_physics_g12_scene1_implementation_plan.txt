[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮：scene1-btn-prev，位置 (280,450)，作用：返回上一状态
  - 下一步按钮：scene1-btn-next，位置 (520,450)，作用：进入下一状态

  2. 点击"下一步"添加活塞，讲解活塞位置关系
  3. 点击"下一步"显示气体区域，区分氧气和氮气
  4. 点击"下一步"添加条件标注，讲解已知参数
  5. 点击"下一步"完成图示，总结初始状态所有信息
  6. 可随时点击"上一步"回退复习

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
```
┌─────────────────────────────────────────────────────────────┐
│                    图示区 800×500                           │
│                                                             │
│     导热符号 ~~~~~~~~           大气                        │
│        ┌──────────┐              ┌──┐                       │
│        │  氧气    │              │  │                       │
│        │   a      │              │  b│                      │
│        │──────────│              │──│                      │
│        │          │              │  │                       │
│        │   氮气   │══════════════│  │                       │
│        │          │              │  │                       │
│        └──────────┘              └──┘                       │
│           电阻丝 ~~~~                                       │
│                                                             │
│   H←→  S_A=4S_B         P₀  T₀=280K                        │
│                                                             │
│              [◀上一步]  步骤 k/4  [下一步▶]                 │
│                     y=450 控件栏                            │
└─────────────────────────────────────────────────────────────┘
```

- 关键实现要点：
  1. 状态机设计：当前步骤变量 currentStep (0-4)，用数组存储每步应显示的元素 ID 列表
  2. 坐标计算：所有元素使用绝对坐标，通过 SVG 的 x/y 属性精确控制
  3. 动画曲线：使用 CSS transition 实现淡入效果（opacity: 0→1，duration 0.3s）
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateDisplay() 刷新视图
  5. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-cyl-a、scene1-piston-a、scene1-btn-next）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 元素显示控制：通过 setAttribute('display', 'none/block') 或修改 opacity 控制可见性
