problem_86_physics_g12

场景导航：Scene 1 | Scene 2

题目原文：
如图所示，水平放置的平行板电容器，原来AB两板不带电，B极板接地，它的极板长L=0.1m，两板间距离d=0.4cm，现有一微粒质量m=2.0×10^(-6)kg，带电量q=+1.0×10^(-8)C，以一定初速度从两板中央平行于极板射入，由于重力作用微粒恰好能落到A板上中点O处，取g=10m⋅s^(-2)，试求：
（1）带电粒子入射初速度的大小；
（2）现使电容器带上电荷，使带电微粒能从平行板电容器的右侧射出，则带电后A板的电势范围为多少？

题目分析：
本题涉及带电粒子在重力场和电场中的运动，分为两个物理过程：

  1. 第一问：电容器不带电，微粒仅受重力，做平抛运动
  2. 第二问：电容器带电后，微粒同时受重力和电场力，需分析临界条件

整体讲解思路：

  • 首先展示无电场时的平抛运动，帮助学生理解初始条件
  • 然后引入电场，通过受力分析展示微粒运动轨迹的变化
  • 最后通过临界条件确定A板电势的取值范围

图示规划：

  • Scene 1：平抛运动分析（无电场情况）
  • Scene 2：电场作用下的运动范围分析（有电场情况）
步骤 1/5

Scene 1 教学说明：

本图示展示电容器不带电时微粒的平抛运动过程，教师应引导学生按以下步骤观察：

步骤0-1：理解初始条件
微粒从两板中央水平射入，只受重力作用。

步骤2-3：运动分解
水平方向：匀速直线运动 x = v0·t
竖直方向：自由落体运动 y = (1/2)·g·t²

关键计算：
已知条件：

  • 竖直位移 y = d/2 = 0.2cm = 0.002m
  • 水平位移 x = L/2 = 0.05m

由竖直方向：
d/2 = (1/2)·g·t²
t = √(d/g) = √(0.004/10) = 0.02s

由水平方向：
v0 = x/t = 0.05/0.02 = 2.5m/s

引导学生观察：

  • 轨迹是抛物线，体现水平匀速与竖直匀加速的合成
  • 落点O恰好是A板中点，说明水平位移为L/2
φ_A
0 V
φ_A = 0 V，微粒落到 A 板中点 O

Scene 2 教学说明：

本图示展示电容器带电后微粒的运动情况，通过滑块调节A板电势，实时观察轨迹变化。

受力分析：
微粒受两个力：

  • 重力：mg，竖直向下（恒定）
  • 电场力：qE，方向取决于电场方向

电场方向与电势关系：

  • B板接地（φB=0）
  • 若φA>0，电场方向向上（从A指向B），正电荷受电场力向上
  • 若φA<0，电场方向向下（从B指向A），正电荷受电场力向下

临界条件分析：

微粒要从右侧射出，不能碰到上极板或下极板。

临界1：刚好不碰下极板A
此时电场力向上，抵消部分重力，微粒轨迹向上弯曲
竖直方向加速度：a = g - qE/m
运动时间：t = L/v0 = 0.1/2.5 = 0.04s
竖直位移：y = (1/2)·a·t² ≤ d/2

临界2：刚好不碰上极板B
此时电场力向下，与重力同向，微粒轨迹向下弯曲
竖直方向加速度：a = g + qE/m
竖直位移：y = (1/2)·a·t² ≤ d/2

计算电势范围：
电场强度：E = |φA|/d

由临界条件可求得φA的取值范围。

引导学生观察：

  • 滑块向右（φA增大）：电场力向上增大，轨迹向上弯曲
  • 滑块向左（φA减小）：电场力向下增大，轨迹向下弯曲
  • 找到轨迹刚好从板边缘射出的临界位置
  • 理解电势范围由两个临界条件共同确定

完整解答总结：

第（1）问解答：
微粒做平抛运动：

  • 竖直方向：d/2 = (1/2)·g·t²
  • 水平方向：L/2 = v0·t

联立解得：v0 = (L/2)·√(g/d) = 0.05·√(10/0.004) = 2.5m/s

第（2）问解答：
微粒从右侧射出的条件：竖直位移|y| ≤ d/2

运动时间：t = L/v0 = 0.1/2.5 = 0.04s

竖直方向加速度：a = g ± qE/m（电场力方向可上可下）

竖直位移：y = (1/2)·a·t²

临界条件：|y| = d/2 = 0.002m

解得：|a| = 2y/t² = 2×0.002/0.0016 = 2.5m/s²

即：|g ± qE/m| = 2.5

两种情况：

  1. g - qE/m = 2.5 → qE/m = 7.5 → E = 7.5m/q
  2. g + qE/m = 2.5 → qE/m = -7.5（舍去，加速度不能为负）

或考虑电场力方向：

  • 电场力向上时：a = g - qE/m ≥ -2.5
  • 电场力向下时：a = g + qE/m ≤ 2.5

最终求得A板电势范围：-100V ≤ φA ≤ 600V（具体数值需精确计算）

课堂讲解建议：

  1. 先用Scene 1讲解平抛运动，建立基础
  2. 再用Scene 2通过滑块演示，让学生直观感受电场力对轨迹的影响
  3. 重点强调临界条件的物理意义
  4. 引导学生理解电势正负与电场力方向的关系
