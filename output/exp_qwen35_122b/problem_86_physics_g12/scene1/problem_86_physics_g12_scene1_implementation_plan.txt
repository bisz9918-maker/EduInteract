  3. 点击"下一步"显示运动轨迹，讲解平抛运动合成

  6. 可随时点击"上一步"回退复习

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（线段、圆、箭头、抛物线），原生 SVG 足以实现，无需引入重型库
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    800px 宽                             │
  │  ┌───────────────────────────────────────────────────┐  │
  │  │                                                   │  │
  │  │     B极板 ───────────────────────────────         │  │
  │  │     │                                           │  │
  │  │     │ d=0.4cm                                   │  │
  │  │     │                                           │  │
  │  │   ⊕ ──→ v0                                      │  │
  │  │   │                                             │  │
  │  │   ↓ mg              轨迹 (虚线)                  │  │
  │  │           ╲                                     │  │
  │  │            ╲                                    │  │
  │  │             ╲                                   │  │
  │  │              O                                  │  │
  │  │     A极板 ───────────────────────────────         │  │
  │  │                                                   │  │
  │  │      ← L/2 →         ← L/2 →                     │  │
  │  │                                                   │  │
  │  │  [步骤 X/4]  ◀上一步  下一步▶                     │  │
  │  │     440px                                         │  │
  │  └───────────────────────────────────────────────────┘  │
  │                    500px 高                             │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量 (0-4) 跟踪当前步骤，每一步定义需要显示/隐藏的 element ID 列表
  2. 坐标计算：所有坐标已在布局坐标表中精确定义，直接硬编码
  3. 抛物线绘制：使用 SVG 路径命令 `M 180,250 Q 290,315 400,380`（二次贝塞尔曲线近似抛物线）
  4. 箭头绘制：使用 SVG `<line>` + `<polygon>` 组合，或 `<marker>` 定义箭头标记
  5. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateDisplay() 刷新显示
  6. ID 命名规范：所有元素 ID 以 `scene1-` 为前缀（如 scene1-plate-top、scene1-particle、scene1-vec-v0 等）
  7. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  8. 步骤控制：步骤 0 为初始状态，步骤 4 为最终状态，按钮根据 currentStep 启用/禁用
