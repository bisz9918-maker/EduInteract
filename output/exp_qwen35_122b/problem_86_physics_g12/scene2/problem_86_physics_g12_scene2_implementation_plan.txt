[图示主题与整合说明]
- 本图示主题：电容器带电后微粒的运动范围与临界条件
- 整合内容：电场力分析 + 运动轨迹变化 + 临界条件展示 + 电势范围确定
- 教学价值：教师可通过拖拽滑块实时调节 A 板电势，观察微粒轨迹如何随电场力变化而改变，帮助学生直观理解电场力对带电粒子运动的影响，以及找到微粒从右侧射出的临界条件

[分步序列]
本场景采用连续拖拽交互，无分步导航，实时响应：

- 初始状态（φA = 0）：
  - 显示上极板 B（接地）、下极板 A
  - 微粒位于 (80,250)，显示 v0、mg 矢量
  - qE 矢量为 0（不显示）
  - F 合矢量 = mg（向下）
  - 显示默认轨迹（落到 A 板中点）
  - 显示两条灰色虚线临界轨迹
  - 滑块位于中间位置
  - 结果提示框显示："φA = 0V，微粒落到 A 板"

- 拖拽过程（φA 变化）：
  - φA > 0（A 板电势为正）：
    - qE 矢量向上显示（绿色）
    - F 合矢量减小（mg - qE）
    - 轨迹向上弯曲程度减小
    - 当 φA 达到临界值，轨迹刚好从下边缘射出
  - φA < 0（A 板电势为负）：
    - qE 矢量向下显示（橙色）
    - F 合矢量增大（mg + |qE|）
    - 轨迹向下弯曲程度增大
    - 当 φA 达到临界值，轨迹刚好从上边缘射出
  - 实时显示当前电势值和运动状态

- 临界条件展示：
  - 当轨迹刚好擦过上极板边缘：φA 最小值
  - 当轨迹刚好擦过下极板边缘：φA 最大值
  - 结果提示框显示："临界范围：φA ∈ [φmin, φmax]"

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：
  1. 垂直滑块（scene2-slider）：
     - 位置：(720,150)-(740,350)
     - 作用：调节 A 板电势φA，范围从 -500V 到 +500V
     - 手柄：圆形，直径 20px，可上下拖拽
  2. 电势值显示（scene2-phia-display）：
     - 位置：(750,250)
     - 作用：实时显示当前φA 数值
  3. 结果提示框（scene2-result-box）：
     - 位置：(50,420)-(400,470)
     - 作用：显示当前运动状态和临界条件

- 教师操作流程：
  1. 初始状态：φA = 0，微粒受重力作用落到 A 板
  2. 向上拖拽滑块（φA > 0）：
     - 观察 qE 矢量向上出现（绿色）
     - 轨迹向上弯曲程度减小
     - 继续拖拽直到轨迹刚好从下边缘射出，记录φA 最大值
  3. 向下拖拽滑块（φA < 0）：
     - 观察 qE 矢量向下出现（橙色）
     - 轨迹向下弯曲程度增大
     - 继续拖拽直到轨迹刚好从上边缘射出，记录φA 最小值
  4. 总结：φA 在 [φmin, φmax] 范围内，微粒可从右侧射出

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（线段、圆形、箭头、曲线），原生 SVG 足以实现，无需引入重型库
  - 动画：使用 requestAnimationFrame 实现平滑轨迹更新

- 画布尺寸：800 × 500 px

- 关键实现要点：
  1. 状态机设计：
     - 单一状态变量：phia（A 板电势，范围 -500V ~ +500V）
     - 派生状态：qE 大小和方向、F 合大小和方向、轨迹终点
  2. 坐标计算：
     - 物理公式：y = (1/2) * a * t², x = v0 * t
     - 加速度 a = (mg - qE) / m（向上为正）
     - 轨迹方程：y(x) = y0 + (a / (2*v0²)) * x²
  3. 动画曲线：
     - 使用 SVG 路径的 quadraticCurveTo 或 bezierCurveTo 绘制抛物线
     - 轨迹更新使用 requestAnimationFrame 实现平滑过渡
  4. 事件绑定：
     - 滑块 mousedown/mousemove/mouseup 事件
     - 触摸设备支持 touchstart/touchmove/touchend
  5. ID 命名规范：
     - 所有元素 ID 以"scene2-"为前缀
     - 如：scene2-plate-top, scene2-plate-bottom, scene2-particle, scene2-slider, scene2-trajectory, scene2-qe-vector 等
  6. IIFE 隔离：
     - 所有 JS 代码包裹在 (function() { ... })() 中
     - 避免全局变量污染

- 物理计算逻辑：
  ```
  已知：m = 2.0×10^-6 kg, q = +1.0×10^-8 C, L = 0.1m, d = 0.4cm, g = 10 m/s²
  
  初始状态（φA = 0）：
  - 微粒落到 A 板中点 O，x = L/2 = 0.05m
  - 竖直位移 y = d/2 = 0.002m
  - 由 y = (1/2)gt² 得 t = √(2y/g) = √(0.004/10) = 0.02s
  - v0 = x/t = 0.05/0.02 = 2.5 m/s
  
  带电后：
  - 电场强度 E = φA / d
  - 电场力 qE = q * φA / d
  - 加速度 a = (mg - qE) / m = g - q*φA/(m*d)
  - 飞行时间 t = L / v0 = 0.1 / 2.5 = 0.04s
  - 竖直位移 Δy = (1/2) * a * t²
  
  临界条件：
  - 从上边缘射出：Δy = -d/2 = -0.002m（向上）
  - 从下边缘射出：Δy = +d/2 = +0.002m（向下）
  ```
