[分步序列]
- 步骤 0（初始状态）：
  - 显示：斜面（三条线段）、6 条电场线、E 标签、37°弧线及标签、A 球及 A 标签、B 球及 B 标签、L 虚线及 L 标签
  - 隐藏：所有力矢量、所有方程框
  - 目的：展示题目基础条件，等待教师开始讲解

- 步骤 1：
  - 新增：A 球高亮（填充变为 rgba(21,101,192,0.4)）、mg 箭头（竖直向下）、mg 标签、N 箭头（垂直斜面向上）、N 标签、F_E 箭头（水平向左，蓝色）、F_E 标签、F_C 箭头（沿斜面向上，红色）、F_C 标签
  - 目的：展示 A 球静止时的完整受力分析

- 步骤 2：
  - 新增：方程框 1，显示平衡方程 "沿斜面方向：mg·sin37° = qE·cos37° + kq²/L²"
  - 高亮：方程中各力分量对应颜色（mg 黑色、qE 蓝色、kq²/L²红色）
  - 目的：展示 A 球沿斜面方向的平衡方程

- 步骤 3：
  - 隐藏：A 球受力矢量（mg、N、F_E、F_C 箭头及标签）、方程框 1
  - 恢复：A 球填充为 rgba(0,0,0,0.2)
  - 新增：B 球高亮（填充变为 rgba(21,101,192,0.4)）、mg 箭头（B 球，竖直向下）、mg 标签（B）、N'箭头（垂直斜面向上）、N'标签、F_E'箭头（水平向左，蓝色）、F_E'标签、F_C'箭头（沿斜面向下，红色）、F_C'标签
  - 目的：切换至 B 球受力分析

- 步骤 4（最终步骤）：
  - 新增：方程框 2，显示牛顿第二定律方程 "沿斜面方向：mg·sin37° + kq²/L² - qE·cos37° = ma"
  - 新增：a 箭头（沿斜面向下，绿色）、a 标签
  - 高亮：方程中各力分量对应颜色，加速度 a 绿色
  - 目的：展示 B 球释放瞬间的加速度分析，完成完整逻辑链条

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "上一步"按钮：ID scene1-btn-prev，位置 (320,460)，作用：返回上一状态
  - "下一步"按钮：ID scene1-btn-next，位置 (480,460)，作用：进入下一状态
  - 步骤指示器：text，ID scene1-step-indicator，位置 (380,435)，显示当前步骤 "步骤 1/5"
- 教师操作流程：
  1. 初始展示斜面系统基础图，教师介绍题目背景
  2. 点击"下一步"展示 A 球受力矢量，教师讲解受力分析
  3. 点击"下一步"展示平衡方程，教师列方程求解
  4. 点击"下一步"切换至 B 球受力分析，教师对比两球受力差异
  5. 点击"下一步"展示加速度方程，教师完成完整分析
  6. 可随时点击"上一步"回退复习关键步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何和动画，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │ 800×500 SVG 画布                                         │
  │                                                          │
  │  ←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←    │ 电场线 (6 条)
  │                                                          │
  │              A●                                          │
  │             /│\ 受力矢量                                 │
  │            / │ \                                         │
  │           /  │  \                                        │
  │    B●───L───●                                           │
  │     /│\                                                 │
  │    / │ \ 受力矢量                                       │
  │   /  │  \                                               │
  │  /37°│                                                   │
  │ ──────────────────────────────────────────────────────  │ 斜面底边
  │                                                          │
  │  步骤指示器：步骤 1/5                                    │
  │  [◀上一步]                    [下一步▶]                  │ 控件栏
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-4) 跟踪当前步骤，updateScene() 函数根据 currentStep 显示/隐藏对应元素
  2. 坐标计算：所有元素使用绝对坐标，力矢量从球心 (cx,cy) 出发，按指定方向计算终点
  3. 动画曲线：力矢量使用 opacity 渐变 (0→1) 实现淡入效果，过渡时间 300ms
  4. 事件绑定：按钮点击事件调用 changeStep(delta) 函数，更新 currentStep 后调用 updateScene()
  5. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-ball-a、scene1-force-mg-a、scene1-btn-next）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  7. 方程渲染：使用 MathJax 或简单 HTML 实体渲染数学公式（sin37°、kq²/L²等）
