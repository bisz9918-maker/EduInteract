[图示主题与整合说明]
- 本图示主题：圆弧轨道电磁感应装置结构与金属棒运动过程
- 整合内容：装置三维结构、磁场方向、金属棒运动轨迹、电路连接关系

[分步序列]
- 步骤0（初始状态）：
  - 显示：左圆弧轨道、右圆弧轨道、圆心O、半径r、金属棒cd（实线）、磁场线B×3、电阻R及连接线
  - 隐藏：金属棒ab、运动轨迹、速度矢量v₀
  - 标签显示：O、r、c、d、B、R、L

- 步骤1（中间位置θ角）：
  - 显示：步骤0所有元素 + 金属棒ab（虚线，位置在顶部）+ 运动轨迹（虚线弧）
  - 新增：在金属棒cd上显示角度θ标注（从水平方向逆时针旋转）
  - 标签新增：a、b、θ

- 步骤2（最终位置）：
  - 显示：步骤1所有元素 + 速度矢量v₀（在cd位置，切线方向）
  - 金属棒cd变为半透明（opacity=0.5），金属棒ab变为实线（opacity=1.0）
  - 标签新增：v₀

- 步骤3（完整轨迹）：
  - 显示：所有元素完整展示
  - 运动轨迹高亮（stroke-width=3）
  - 添加动画效果：金属棒沿轨迹从cd移动到ab的连续运动演示（可选）
  - 所有标签完整显示：O、r、L、R、B、v₀、a、b、c、d

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 按钮"◀上一步"：位置(250,460)，作用：返回上一状态，若已在步骤0则禁用
  - 按钮"下一步▶"：位置(550,460)，作用：进入下一状态，若已在步骤3则禁用
- 教师操作流程：
  1. 初始展示装置结构（步骤0），讲解初始条件
  2. 点击"下一步"展示中间位置和运动轨迹（步骤1），讲解运动过程
  3. 点击"下一步"展示最终位置和速度方向（步骤2），讲解末状态
  4. 点击"下一步"展示完整轨迹和动态演示（步骤3），总结全过程
  5. 可随时点击"上一步"回退复习关键节点

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何和动画，无需重型库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │                        图示区 800×500                        │
  │                                                             │
  │    B↑                    磁场线贯穿                          │
  │    ↑                                                          │
  │    ↑        a─────b        电阻R                             │
  │    ↑        │     │          ┌───┐                          │
  │    ↑        │ 轨迹 │          │ R │                          │
  │    ↑        │ ╲   │          └───┘                          │
  │    ↑        │  ╲  │           │                              │
  │    ↑    O───┼──╲──┼───────────┘                              │
  │    ↑   /    │   ╲ │                                          │
  │    ↑  /     │    ╲│                                          │
  │    ↑ /      │     │                                          │
  │    ↑/       │     │                                          │
  │    c────────d                                              │
  │    ↑                                                          │
  │    └───左轨道    右轨道                                        │
  │                                                             │
  │              ◀上一步              下一步▶                     │
  │              (250,460)          (550,460)                    │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-3) 跟踪当前步骤
  2. 坐标计算：圆弧用 SVG path 的 A 命令，角度转弧度计算
  3. 元素显示/隐藏：用 CSS display 或 opacity 控制
  4. 按钮状态：根据 currentStep 启用/禁用按钮
  5. 箭头绘制：用 SVG polygon 绘制箭头头部
  6. 动画效果：步骤3可用 requestAnimationFrame 实现金属棒沿轨迹移动
- ID 命名规范：所有交互元素 ID 以 scene1- 为前缀（如 scene1-tri-abc、scene1-btn-next）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局污染
