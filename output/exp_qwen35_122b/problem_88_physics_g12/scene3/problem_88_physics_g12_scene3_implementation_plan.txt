[分步序列]
- 步骤0（初始状态）：
  - 显示：能量转化流程图背景、W_F框、ΔE_p框、Q框、W_F→ΔE_p箭头、金属棒位置示意图（仅cd位置）、B磁场箭头
  - 隐藏：ab金属棒、公式框、能量柱状图、W_F→Q箭头
  - 说明：展示基础能量转化路径，金属棒在初始位置cd

- 步骤1（焦耳热计算）：
  - 新增显示：ab金属棒（虚线表示末位置）、W_F→Q箭头
  - 公式框显示：Q = I²(R+r/3)t，E = BLv₀sinθ
  - 说明：展示金属棒运动至ab位置，焦耳热产生过程

- 步骤2（功能关系）：
  - 公式框更新：W_F = ΔE_p + Q
  - 能量柱状图显示：三根柱体全部显示
  - 说明：建立功能关系方程，展示能量分配

- 步骤3（拉力做功）：
  - 公式框更新：W_F = mgr + Q
  - ΔE_p柱体高亮（边框加粗）
  - 说明：明确拉力做功的具体表达式

- 步骤4（能量守恒验证）：
  - 公式框更新：W_F = ΔE_p + Q_R + Q_r
  - Q框内显示Q_R和Q_r子标签
  - 所有柱体边框加粗高亮
  - 说明：展示能量守恒的完整形式，电阻R和内阻r的热量分配

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何和动画，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │ 800×500 画布                                                    │
  │                                                                 │
  │ ┌─────────────┐    ┌─────────────────────────────────────┐     │
  │ │ 能量流程图  │    │         金属棒位置示意图             │     │
  │ │ (30,50)     │    │         (350,30)-(750,200)          │     │
  │ │  W_F        │    │         圆弧轨道+cd/ab位置           │     │
  │ │  ↓          │    │         B磁场箭头                    │     │
  │ │  ΔE_p       │    │                                     │     │
  │ │  ↓          │    │         ┌─────────────────────┐     │     │
  │ │  Q          │    │         │    公式框           │     │     │
  │ │             │    │         │  (350,220)-(750,310)│     │     │
  │ │             │    │         └─────────────────────┘     │     │
  │ │             │    │                                     │     │

  │         │      控件栏 (y=440-490)             │                 │
  │         │   [◀上一步]  [下一步▶]  步骤X/5     │                 │
  │         └─────────────────────────────────────┘                 │
  └────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用currentStep变量(0-4)跟踪当前步骤，每个步骤定义显示/隐藏元素列表
  2. 坐标计算：所有元素使用绝对定位，通过setAttribute精确控制位置
  3. 动画曲线：元素显示使用opacity从0到1的过渡动画（0.3s ease）
  4. 事件绑定：按钮点击事件更新currentStep，调用updateScene()刷新显示
  5. ID命名规范：所有元素ID以scene3-为前缀（如scene3-wf-box、scene3-cd-rod、scene3-btn-next等）
  6. IIFE隔离：所有JS代码包裹在(function() { ... })()中，避免全局污染
  7. 高亮效果：使用stroke-width和stroke属性动态改变元素边框实现高亮
