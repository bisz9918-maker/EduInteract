[分步序列]
- 步骤 0（初始状态）：显示完整电路连接图（电源、开关、L₁、L₂、电压表及所有导线），所有元件为黑色，无高亮，无电流箭头，无测量范围框
- 步骤 1：点击「下一步」→ 高亮电源和开关（蓝色填充），显示标签"电源+/-"和"开关 S"，其他元件保持黑色
- 步骤 2：点击「下一步」→ 高亮灯泡 L₁和 L₂（蓝色填充），显示标签"L₁"和"L₂"，电源和开关恢复黑色
- 步骤 3：点击「下一步」→ 显示绿色电流方向箭头（顺时针：电源+ → L₁ → 开关 → L₂ → 电源-），高亮整条电流路径（绿色导线加粗），其他元件恢复黑色
- 步骤 4：点击「下一步」→ 高亮电压表 V（蓝色填充），显示红色虚线框包围 L₂（表示电压表测量 L₂两端电压），显示标签"V"，其他元件恢复黑色，电流箭头保持显示

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位置 (280,450)，作用：返回前一个步骤，可复习之前内容
  - 「下一步」按钮：位置 (520,450)，作用：进入下一个步骤，展示新的分析内容
- 教师操作流程：
  1. 初始展示完整电路，让学生观察整体结构
  2. 点击「下一步」，高亮电源和开关，讲解电路的起始部分
  3. 点击「下一步」，高亮两个灯泡，讲解串联负载
  4. 点击「下一步」，显示电流路径，讲解电流流向和串联特性
  5. 点击「下一步」，高亮电压表并显示测量范围，讲解电压表并联测量原理
  6. 可随时点击「上一步」回退复习，巩固理解

- 画布尺寸：800 × 500 px

- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-4) 跟踪当前步骤
  2. 坐标计算：所有元素按布局坐标表精确定位
  3. 动画曲线：元素高亮使用 CSS transition (0.3s ease) 实现平滑过渡
  4. 事件绑定：按钮点击事件更新 currentStep，触发对应元素的显示/隐藏/高亮
  5. 电压表测量范围：使用红色虚线矩形框，包围 L₂灯泡，填充透明度 20%
  6. 电流路径：绿色箭头沿导线顺时针方向，步骤 3 后持续显示

- ID 命名规范：所有交互元素 ID 以 scene1- 为前缀
  - scene1-battery（电源）
  - scene1-switch（开关）
  - scene1-lamp1（L₁）
  - scene1-lamp2（L₂）
  - scene1-voltmeter（电压表）
  - scene1-current-arrow（电流箭头）
  - scene1-measure-box（测量范围框）
  - scene1-btn-prev（上一步按钮）
  - scene1-btn-next（下一步按钮）
  - scene1-label-battery-plus（电源+ 标签）
  - scene1-label-battery-minus（电源- 标签）
  - scene1-label-switch（开关标签）
  - scene1-label-lamp1（L₁标签）
  - scene1-label-lamp2（L₂标签）
  - scene1-label-voltmeter（电压表标签）

- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染
