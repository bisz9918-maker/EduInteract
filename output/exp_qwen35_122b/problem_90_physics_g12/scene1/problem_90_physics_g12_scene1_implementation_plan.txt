[图示主题与整合说明]
- 本图示主题：玻璃管内气体三种状态的对比展示（玻意耳定律应用）
- 整合的步骤/概念：整合图甲（开口向上）、图乙（开口向下）、图丙（开口向下 + 活塞）三种状态，展示气体等温变化过程中水银柱位置、空气柱长度、压强的变化关系
- 教学价值：教师可逐步展示三种状态，帮助学生理解玻意耳定律 P₁V₁=P₂V₂ 的应用，以及压强与液柱高度的关系 P=P₀±ρgh

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于底部中央偏左 (320, 470)，点击返回上一状态
  - 「下一步 ▶」按钮：位于底部中央偏右 (500, 470)，点击进入下一状态
- 教师操作流程：
  1. 初始展示图甲（开口向上），讲解 P₁=P₀+h 的压强关系
  2. 点击「下一步」展示图乙（开口向下），对比讲解 P₂=P₀-h 的压强关系
  3. 再次点击「下一步」展示图丙（加入活塞），引出待求量 d
  4. 可随时点击「上一步」回顾前面状态，帮助学生理解状态变化的因果关系

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │                        800px                                │
  │  ┌─────────┐  ┌─────────┐  ┌─────────┐                     │
  │  │   图甲   │  │   图乙   │  │   图丙   │   500px           │
  │  │ (开口上) │  │ (开口下) │  │ (活塞)  │                     │
  │  │  P₁=P₀+h │  │  P₂=P₀-h │  │   d=?   │                     │
  │  └─────────┘  └─────────┘  └─────────┘                     │
  │                                                             │
  │              [◀ 上一步]  [下一步 ▶]                         │
  │                     470px                                   │
  └─────────────────────────────────────────────────────────────┘
  ```

- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0/1/2) 跟踪当前步骤
  2. 高亮框动态移动：根据 currentStep 更新绿色边框的 x 坐标
  3. 坐标计算：按 5.65 px/cm 比例将物理长度转换为像素
  4. 事件绑定：按钮点击事件更新 currentStep 并刷新高亮框位置
  5. 边界处理：步骤 0 时禁用「上一步」，步骤 2 时禁用「下一步」

- ID 命名规范：所有交互元素 ID 以 scene1- 为前缀
  - scene1-tube-a: 图甲玻璃管
  - scene1-tube-b: 图乙玻璃管
  - scene1-tube-c: 图丙玻璃管
  - scene1-highlight: 高亮框
  - scene1-prev-btn: 上一步按钮
  - scene1-next-btn: 下一步按钮
  - scene1-step-label: 步骤状态标签

- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
