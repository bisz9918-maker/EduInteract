[图示主题与整合说明]
- 本图示主题：三带电小球系统的库仑力分析与运动状态
- 整合内容：等边三角形几何结构、电荷分布、各球间库仑力方向、外力 F 与加速度 a 的关系
- 教学价值：教师可逐步引导学生从几何结构→电荷相互作用→受力分析→运动状态，理解"保持间距不变"意味着整体匀加速运动，C 必须带负电才能提供向右的合力

[分步序列]
- 步骤 0（初始）：
  - 显示：小球 A、B、C（A、B 浅蓝填充，C 浅红填充）
  - 显示：三条虚线边 AB、BC、CA
  - 显示：标签 A、B、C 和边长 r（三处）
  - 显示：电荷标签 q（A、B 上方/下方）、Q（C 上方）
  - C 球内显示"?"符号（步骤 5 后改为"-"）
  - 隐藏：所有力矢量箭头、外力 F、加速度 a

- 步骤 1：
  - 新增：力矢量 F_AC（C→A 方向，蓝色）、F_BC（C→B 方向，蓝色）
  - 新增：标签 F_AC、F_BC
  - 说明：A、B 对 C 的库仑引力方向（假设 C 带负电）

- 步骤 2：
  - 新增：力矢量 F_CA（A→C 方向，蓝色）、F_CB（B→C 方向，蓝色）
  - 新增：标签 F_CA、F_CB
  - 说明：C 对 A、C 对 B 的库仑引力方向（牛顿第三定律）

- 步骤 3：
  - 新增：力矢量 F_AB（A 竖直向上，红色）、F_BA（B 竖直向下，红色）
  - 新增：标签 F_AB、F_BA
  - 说明：A、B 间的库仑斥力方向（同种电荷相斥）

- 步骤 4：
  - 新增：外力 F 箭头（从 C 右侧水平向右，绿色）
  - 新增：标签 F
  - 新增：加速度 a 箭头（右上独立位置，绿色）
  - 新增：标签 a
  - 说明：外力 F 作用于 C，系统整体以加速度 a 向右运动

- 步骤 5（最终）：
  - 变化：C 球内"?"改为"-"符号
  - 高亮：C 球轮廓加粗（3px）并闪烁效果（可选）
  - 说明：C 必须带负电，A、B 对 C 的引力合力向右，才能提供系统加速度

冲突检查：
- "A"(175,180) 与 "r"(AB)(175,240)：间距 60px → 无冲突
- "A"(175,180) 与 "q"(A)(200,155)：间距约 32px → 无冲突
- "B"(175,300) 与 "r"(AB)(175,240)：间距 60px → 无冲突
- "B"(175,300) 与 "q"(B)(200,325)：间距约 32px → 无冲突
- "C"(329,240) 与 "Q"(C)(304,215)：间距约 36px → 无冲突
- "r"(CA)(252,200) 与 "F_CA"(240,190)：间距约 16px → 接近但可接受（不同步显示）
- "r"(BC)(252,280) 与 "F_CB"(240,290)：间距约 16px → 接近但可接受（不同步显示）
- "F_AB"(175,160) 与 "q"(A)(200,155)：间距约 25px → 无冲突
- "F_BA"(175,320) 与 "q"(B)(200,325)：间距约 25px → 无冲突
- "F"(374,225) 与 "C"(329,240)：间距约 48px → 无冲突
- "a"(490,135) 与其他标签间距均>50px → 无冲突

结论：所有标签间距≥16px，无严重冲突。步骤 1-3 的力标签与边长标签在不同步骤显示，不会同时出现造成视觉拥挤。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 按钮"◀ 上一步"：位置 (50,460)，作用：返回上一状态，步骤 0 时禁用
  - 按钮"下一步 ▶"：位置 (700,460)，作用：进入下一状态，步骤 5 时改为"完成"
- 教师操作流程：
  1. 初始展示三角形结构和电荷分布，引导学生观察几何关系
  2. 逐步添加 A、B 对 C 的引力，讨论 C 的电性
  3. 添加 C 对 A、B 的引力，强调牛顿第三定律
  4. 添加 A、B 间斥力，分析竖直方向受力平衡
  5. 添加外力 F 和加速度 a，引出整体运动分析
  6. 最终高亮 C 球，确认 C 带负电的必要性

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │                           图示区 800×500                        │
  │                                                                 │
  │     A○─────────────○C                                          │
  │      │  r         /  \                                         │
  │      │ r        /      \  r                                    │
  │      │        /          \                                     │
  │     B○────────────────────                                      │
  │                                                                 │
  │              [力矢量箭头按需显示]                                │
  │                                                                 │
  │  ┌─────────────────────────────────────────────────────────┐   │
  │  │  ◀ 上一步                                    下一步 ▶   │   │
  │  └─────────────────────────────────────────────────────────┘   │
  │                        控件栏 y=440~490                         │
  └────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：currentStep 变量 (0-5)，每一步定义显示/隐藏的元素 ID 列表
  2. 坐标计算：等边三角形顶点坐标精确计算（AB 竖直，C 在右侧）
  3. 箭头绘制：使用 SVG <line> + <polygon> 组合，箭头头部指向正确方向
  4. 事件绑定：按钮点击事件更新 currentStep，调用 renderStep() 刷新显示
  5. C 球电荷符号：步骤 0 显示"?"，步骤 5 改为"-"，使用 SVG <text> 元素
  6. 高亮效果：步骤 5 时 C 球轮廓 stroke-width 从 2px 改为 3px，可添加 CSS 动画
- ID 命名规范：所有元素 ID 以"scene1-"为前缀，如 scene1-ball-A、scene1-line-AB、scene1-force-AC 等
- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
