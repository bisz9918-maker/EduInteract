[分步序列]
- 步骤 0（初始）：显示 C 球受力图，展示 F_AC、F_BC 两个蓝色引力矢量（C 已确定为负电），显示 A、B、C 三球位置及 60°角度标注
- 步骤 1：在 C 球处显示 F_AC、F_BC 的合力 F_合C（橙色箭头，水平向左），用平行四边形法则示意合力方向
- 步骤 2：在 C 球处显示外力 F（绿色箭头，水平向右），底部方程框显示 C 球牛顿第二定律方程：F - F_合C = ma
- 步骤 3：切换至 A 球受力图，显示 F_BA（红色斥力，水平向右）、F_CA（蓝色引力，沿 AC 方向指向 C），显示 30°角度标注
- 步骤 4：分解 F_CA，显示灰色虚线分力 F_CA_x（水平向右）和 F_CA_y（竖直向下），显示水平分量与 F_BA 的合力方向
- 步骤 5：底部方程框显示 A 球牛顿第二定律方程：F_BA + F_CA_x = ma，即 kq²/r² + kqQ/r²·cos30° = ma
- 步骤 6：方程框显示联立求解过程，结果框高亮显示最终答案：Q = 2q（C 带负电），F = 3kq²/r²

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何矢量图，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：

  ```
  │                    800 × 500 画布                        │

  │       A ○                    │       ○ A                 │

  │  └───────────────────────────────────────────────┘      │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：currentStep 变量 (0-6)，控制各元素显示/隐藏
  2. 坐标计算：使用 SVG 绝对坐标，力矢量长度与力大小成比例（F_合C、F 长度设为 80px，库仑力 60px）
  3. 动画曲线：元素出现使用 opacity 淡入动画 (0.3s ease-in)
  4. 事件绑定：按钮点击事件更新 currentStep，调用 updateScene() 刷新显示
  5. 方程显示：使用 MathJax 渲染 LaTeX 公式，或直接用 SVG text 显示简化公式
  6. ID 命名规范：所有元素 ID 以 scene2- 为前缀（如 scene2-ball-c、scene2-arrow-fac、scene2-btn-prev）
  7. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
