场景导航：Scene 1 | Scene 2 | Scene 3

题目原文：
如图 1，已知线段 AB=8，点 C 是 AB 上的一动点（不包括 A、B），在 AB 同侧作两个等边三角形 ACD 和 BCE，连 DE，点 P、F 分别是 DE 和 BE 的中点，连接 AF，分别交 DC、CE 于 G、H．
（1）写出图中所有的相似三角形（除等边三角形 ACD 和 BCE 外）；
（2）当点 C 在 AB 中点时，如图 2，求 CP 的长及 AG：GH：HF；
（3）点 M、N 是线段 AB 上两点，且 AM=BN=2，当点 C 从点 M 向点 N 运动时，求点 P 所经过的路径长．

题目分析：
本题综合考查等边三角形性质、相似三角形判定、中点性质及动点轨迹问题。核心在于理解两个等边三角形的结构关系，以及中点 P 随 C 点运动的轨迹特征。

整体讲解思路：

  1. 首先通过基础图形展示，帮助学生建立完整的几何结构认知
  2. 然后分析特殊情况（C 为中点），计算具体数值和比例
  3. 最后通过动点轨迹演示，直观呈现 P 点的运动路径

图示规划说明：

  • Scene 1：基础图形结构展示，分步呈现各几何元素和相似三角形
  • Scene 2：特殊情况分析（C 为中点），展示 CP 长度和比例关系
  • Scene 3：动点轨迹演示，展示 C 点运动时 P 点的轨迹路径
步骤 1/5

教学说明：

本图示用于讲解第（1）问，引导学生识别图中的相似三角形。

讲解要点：

  1. 首先让学生观察两个等边三角形的结构特征
  2. 引导学生寻找平行线关系（如 DC∥BE、CE∥AD）
  3. 利用平行线截比例线段定理或 AA 相似判定相似三角形

关键相似三角形：

  • △ACG∽△ABF（∠CAG=∠BAF 公共角，∠ACG=∠ABF=60°）
  • △BHF∽△BCA（∠HBF=∠CBA 公共角，∠BHF=∠BCA）
  • △DGP∽△EFP（对顶角相等，DP=PE）

引导学生观察：

  • 点击步骤按钮，逐步添加图形元素

步骤 1/6

教学说明：

本图示用于讲解第（2）问，展示特殊情形下的计算过程。

讲解要点：

  1. 当 C 为中点时，两个等边三角形全等且对称
  2. DE 水平，P 为 DE 中点，CP 垂直 AB
  3. 利用坐标法或几何法计算 CP 长度
  4. 利用相似三角形比例关系求 AG:GH:HF

CP 长度计算：

  • 等边三角形高 = 4×√3/2 = 2√3
  • D、E 纵坐标均为 2√3
  • P 为 DE 中点，纵坐标 2√3
  • C 在 AB 上，纵坐标 0
  • CP = 2√3

比例计算：

  • 利用△ACG∽△ABF，得 AG:AF = AC:AB = 4:8 = 1:2
  • 利用△BHF∽△BCA，得 BH:BC = BF:BA = 2:8 = 1:4
  • 综合得 AG:GH:HF = 3:2:1

引导学生观察：

  • 逐步展示计算过程
  • 高亮关键线段，帮助学生理解比例关系
  • 总结特殊情形的结论
拖动滑块观察 P 点轨迹

教学说明：

本图示用于讲解第（3）问，展示动点轨迹问题。

讲解要点：

  1. C 点运动范围：从 M(2) 到 N(6)，运动距离为 4
  2. P 点轨迹分析：由于两个等边三角形始终在 AB 同侧，DE 始终水平，P 点始终在固定高度
  3. P 点水平位移与 C 点水平位移的关系

路径长度计算：

  • 当 C 从 M(2) 运动到 N(6) 时，AC 从 2 变到 6，BC 从 6 变到 2
  • D 点横坐标 = AC/2 = C/2，E 点横坐标 = C + BC/2 = C + (8-C)/2 = C/2 + 4
  • P 点横坐标 = (D 横坐标 + E 横坐标)/2 = (C/2 + C/2 + 4)/2 = C/2 + 2
  • 当 C 从 2 变到 6 时，P 横坐标从 3 变到 5
  • P 点轨迹长度 = 5 - 3 = 2

课堂讲解建议：

  1. 先用 Scene 1 建立整体结构认知
  2. 再用 Scene 2 分析特殊情况，建立具体数值概念
  3. 最后用 Scene 3 演示动点轨迹，让学生直观理解轨迹形成
  4. 拖动滑块时，引导学生观察 P 点运动规律，发现轨迹为线段
  5. 总结：动点轨迹问题的关键是找到动点坐标与参数之间的关系

完整解答总结：
（1）相似三角形：△ACG∽△ABF，△BHF∽△BCA，△DGP∽△EFP 等
（2）CP=2√3，AG:GH:HF=3:2:1
（3）P 点路径长=2
