[分步序列]
- 步骤 0（初始状态）：
  - 显示：四个选项图形 A、B、C、D 并列展示，标签 A/B/C/D 显示
  - 隐藏：所有判断标记、步骤说明文本
  - 按钮状态：上一步禁用，下一步启用

- 步骤 1（分析选项 A）：
  - 视觉变化：选项 A 图形边框高亮为蓝色 (#1565c0)，fill-opacity=0.2
  - 新增：选项 A 判断标记显示"✓"（绿色），步骤说明文本显示"选项 A：3 个矩形侧面 + 2 个三角形底面，位置正确，可折叠成三棱柱"
  - 按钮状态：上一步启用，下一步启用

- 步骤 2（分析选项 B）：
  - 视觉变化：选项 A 高亮取消，选项 B 图形边框高亮为蓝色
  - 新增：选项 B 判断标记显示"✗"（红色），步骤说明文本显示"选项 B：2 个三角形都在同一侧，无法折叠成三棱柱"
  - 按钮状态：上一步启用，下一步启用

- 步骤 3（分析选项 C）：
  - 视觉变化：选项 B 高亮取消，选项 C 图形边框高亮为蓝色
  - 新增：选项 C 判断标记显示"✗"（红色），步骤说明文本显示"选项 C：只有 1 个三角形底面，缺少一个底面"
  - 按钮状态：上一步启用，下一步启用

- 步骤 4（分析选项 D）：
  - 视觉变化：选项 C 高亮取消，选项 D 图形边框高亮为蓝色
  - 新增：选项 D 判断标记显示"✗"（红色），步骤说明文本显示"选项 D：没有三角形底面，只有 3 个矩形"
  - 按钮状态：上一步启用，下一步启用

- 步骤 5（总结正确答案）：
  - 视觉变化：选项 D 高亮取消，选项 A 图形边框高亮为绿色 (#2e7d32)，其他选项恢复黑色
  - 新增：步骤说明文本显示"正确答案：A（三棱柱展开图需 3 个矩形侧面 + 2 个三角形底面，且底面位于两侧）"
  - 按钮状态：上一步启用，下一步禁用

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮：位于 (300,450)，点击返回上一分析步骤，步骤 0 时禁用
  - 下一步按钮：位于 (500,450)，点击进入下一分析步骤，步骤 5 时禁用
- 教师操作流程：
  1. 初始展示四个选项，让学生观察
  2. 点击"下一步"，逐步分析每个选项，高亮当前选项并显示判断结果
  3. 分析完所有选项后，点击"下一步"进入总结，绿色高亮正确答案 A
  4. 可随时点击"上一步"回退复习某个选项的分析

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────┐
  │                        800px 宽度                               │
  │  ┌─────────┐  ┌─────────┐  ┌─────────┐  ┌─────────┐            │
  │  │  选项 A  │  │  选项 B  │  │  选项 C  │  │  选项 D  │  y=80~320 │
  │  │ (50-220)│  │(240-410)│  │(430-600)│  │(620-790)│            │
  │  └────┬────┘  └────┬────┘  └────┬────┘  └────┬────┘            │
  │       A✓          B✗          C✗          D✗     y=345        │
  │                                                               │
  │              步骤说明文本 (400, 400) 居中                      │
  │                                                               │
  │            [◀ 上一步]              [下一步 ▶]  y=450          │
  └────────────────────────────────────────────────────────────────┘
                              500px 高度
  ```

- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量（0-5）跟踪当前步骤
  2. 坐标计算：所有图形元素使用绝对坐标，通过 data-option 属性关联选项
  3. 高亮切换：通过修改 stroke 颜色和 fill-opacity 实现高亮效果
  4. 事件绑定：按钮点击事件更新 currentStep，调用 updateDisplay() 刷新界面
  5. ID 命名规范：所有元素 ID 以 scene2- 为前缀（如 scene2-optionA, scene2-btn-prev）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染

- 元素 ID 命名：
  - scene2-optionA, scene2-optionB, scene2-optionC, scene2-optionD（选项图形组）
  - scene2-label-A, scene2-label-B, scene2-label-C, scene2-label-D（选项标签）
  - scene2-mark-A, scene2-mark-B, scene2-mark-C, scene2-mark-D（判断标记）
  - scene2-step-text（步骤说明文本）
  - scene2-btn-prev, scene2-btn-next（导航按钮）

- updateDisplay() 函数逻辑：
  1. 根据 currentStep 更新所有选项的高亮状态
  2. 显示/隐藏对应的判断标记
  3. 更新步骤说明文本内容
  4. 更新按钮启用/禁用状态
