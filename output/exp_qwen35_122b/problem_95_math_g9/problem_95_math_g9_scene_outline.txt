    **题目原文：**

    笔直的海岸线上依次有 A、B、C 三个港口，甲船从 A 港口出发，沿海岸线匀速驶向 C 港，1 小时后乙船从 B 港口出发，沿海岸线匀速驶向 A 港，两船同时到达目的地。甲船的速度是乙船的 1.25 倍，甲、乙两船与 B 港的距离 y（km）与甲船行驶时间 x（h）之间的函数关系如图所示，下列说法：①A、B 港口相距 400km；②甲船的速度为 100km/h；③B、C 港口相距 200km；④乙出发 4h 时两船相距 220km，其中正确的个数是（）

    A.4 个  B.3 个  C.2 个  D.1 个

    ---

    **题目分析：**

    本题是一道函数图像应用题，核心在于理解图像中两条折线的含义，并从中提取关键信息来判断四个说法的正确性。

    **关键信息提取：**
    - y 轴表示"与 B 港的距离"，x 轴表示"甲船行驶时间"
    - 从 (0, 400) 到 (4, 0) 的线段：甲船从 A 到 B 的过程（初始距离 B 港 400km，4 小时后到达 B 港）
    - 从 (1, 0) 开始的线段：乙船从 B 出发的过程（1 小时后出发，初始距离 B 港 0km）
    - 甲船最终到达 C 港，乙船最终到达 A 港，且同时到达

    **整体讲解思路：**
    1. 首先通过场景示意图帮助学生建立空间认知：A、B、C 三个港口的相对位置
    2. 然后分析函数图像，逐条提取信息，验证四个说法
    3. 重点讲解如何从图像中读出速度、距离、时间等关键信息

    **图示规划说明：**
    - Scene 1：港口空间布局示意图，帮助学生理解题意中的位置关系
    - Scene 2：函数图像分析图，分步展示如何从图像提取信息并验证各说法
    </TEXT_1>

    **图示 1 教学说明：**

    本图示帮助学生建立空间认知模型，理解题目中的位置关系和运动方向。

    **引导学生观察要点：**
    1. 首先让学生观察海岸线上三个港口的排列顺序：A、B、C 从左到右依次排列
    2. 明确甲船的运动路径：从 A 出发，经过 B，最终到达 C
    3. 明确乙船的运动路径：从 B 出发，最终到达 A（与甲船方向相反）
    4. 注意两船是"同时到达目的地"，这是解题的关键条件

    **讲解要点：**
    - 通过步骤 0→1→2→3 的递进展示，让学生逐步理解题意
    - 强调"与 B 港的距离"这个概念：y 值表示船当前位置到 B 港的直线距离
    - 甲船从 A 到 B 时，与 B 港距离逐渐减小；从 B 到 C 时，与 B 港距离逐渐增大
    - 乙船从 B 到 A 时，与 B 港距离逐渐增大

    **关键公式：**
    - 速度 = 距离 ÷ 时间
    - 甲船速度 v_甲 = 100 km/h
    - 乙船速度 v_乙 = v_甲 ÷ 1.25 = 80 km/h

    **图示 2 教学说明：**

    本图示是解题的核心，通过分步验证四个说法，帮助学生掌握从函数图像提取信息的方法。

    **分步讲解要点：**

    **步骤 1（验证说法①）：**
    - 观察甲船图像的起点 (0, 400)
    - 解释：x=0 时甲船刚出发，y=400 表示此时甲船与 B 港距离 400km
    - 结论：A、B 港口相距 400km，说法①正确 ✓

    **步骤 2（验证说法②）：**
    - 观察甲船从 A 到 B 的过程：从 (0, 400) 到 (4, 0)
    - 计算：甲船 4 小时行驶 400km，速度 = 400÷4 = 100km/h
    - 结论：说法②正确 ✓

    **步骤 3（验证说法③）：**
    - 已知甲船速度 100km/h，乙船速度 = 100÷1.25 = 80km/h
    - 乙船从 B 到 A 需要时间：400÷80 = 5 小时
    - 乙船出发时 x=1，到达时 x=1+5=6
    - 甲船也同时到达 C，甲船从 x=4 到 x=6 行驶 2 小时
    - BC 距离 = 100×2 = 200km
    - 结论：说法③正确 ✓

    **步骤 4（验证说法④）：**
    - 乙出发 4h 时，x = 1+4 = 5
    - 此时甲船位置：从 B 向 C 行驶了 1 小时，与 B 港距离 = 100×1 = 100km
    - 此时乙船位置：从 B 向 A 行驶了 4 小时，与 B 港距离 = 80×4 = 320km
    - 两船相距 = 100 + 320 = 420km（不是 220km）
    - 结论：说法④错误 ✗

    **完整解答：**
    正确的说法有①、②、③，共 3 个，故选 B。

    **课堂讲解建议：**
    1. 强调"与 B 港的距离"这个概念的理解是解题关键
    2. 引导学生学会从图像中读取关键点坐标
    3. 注意两船"同时到达"这个条件的使用
    4. 验证说法④时，提醒学生两船在 B 港两侧，距离需要相加
