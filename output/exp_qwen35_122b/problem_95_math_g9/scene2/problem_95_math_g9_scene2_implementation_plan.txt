[分步序列]
步骤0（初始状态）：
- 显示完整函数图像（甲船蓝色折线、乙船红色直线）
- 显示所有关键点及坐标标注
- 显示4个说法标签（①②③④）
- 验证信息框显示："点击'下一步'开始验证"
- 所有说法结果标记隐藏

步骤1（验证说法①）：
- 高亮甲船图像第一段(0,400)点，用绿色粗圈标记
- 从(0,400)点画水平虚线到y轴
- 验证信息框显示："说法①：x=0时，甲与B港距离=400km → A、B相距400km"
- 说法①结果标记显示"✓"（绿色）
- 其他说法结果仍隐藏

步骤2（验证说法②）：
- 高亮甲船图像第一段(0,400)到(4,0)线段，用绿色加粗显示
- 显示计算过程：400÷4=100km/h
- 验证信息框显示："说法②：甲速=400km÷4h=100km/h"
- 说法②结果标记显示"✓"（绿色）

步骤3（验证说法③）：
- 高亮甲船图像第二段(4,0)到(6,200)线段，用绿色加粗显示
- 显示计算过程：100km/h×2h=200km
- 验证信息框显示："说法③：甲从B到C用时2h，BC=100×2=200km"
- 说法③结果标记显示"✓"（绿色）

步骤4（验证说法④）：
- 在x=5处画垂直虚线（从x轴向上）
- 显示甲船位置：x=5时，甲在BC段，y=100km（与B港距离）
- 显示乙船位置：x=5时，乙在BA段，y=320km（与B港距离）
- 计算两船距离：|320-100|=220km
- 验证信息框显示："说法④：x=5时，甲距B=100km，乙距B=320km，相距220km"
- 说法④结果标记显示"✓"（绿色）

步骤5（总结）：
- 所有4个说法结果标记均显示"✓"
- 验证信息框显示："正确说法个数：4个 → 答案：A"
- 在说法区域下方显示总结框："4个说法全部正确"

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮（scene2-btn-prev）：位于底部左侧，点击返回上一验证步骤
  - 下一步按钮（scene2-btn-next）：位于底部右侧，点击进入下一验证步骤
  - 步骤指示器：显示当前步骤编号（0/5）
- 教师操作流程：
  1. 初始展示完整图像，让学生观察两船运动轨迹
  2. 点击"下一步"逐步验证每个说法
  3. 每步高亮相关图像部分，引导学生从图像提取信息
  4. 最后总结正确说法个数，得出答案

- JS库选择：原生SVG + 原生JavaScript
  - 理由：几何图形简单（线段、圆、文本），无需复杂绘图库；原生SVG便于精确控制坐标和样式；性能好，代码轻量

- 关键实现要点：
  1. 状态机设计：使用currentStep变量（0-5）跟踪当前步骤，每个步骤对应一个状态对象，包含该步骤需要显示/高亮的元素ID列表
  2. 坐标计算：定义坐标转换函数coordToPixel(x, y)，将数据坐标转换为SVG像素坐标
  3. 高亮机制：通过修改stroke-width和stroke属性实现线段高亮，通过添加/移除class实现元素显示/隐藏
  4. 事件绑定：上一步/下一步按钮点击事件，更新currentStep后调用renderStep()重新渲染
  5. 边界处理：第一步禁用上一步按钮，最后一步下一步按钮变为"完成"或禁用

- ID命名规范：
  - 所有交互元素ID以"scene2-"为前缀
  - 示例：scene2-axis-x, scene2-axis-y, scene2-line-jia, scene2-line-yi, scene2-point-0-400, scene2-btn-prev, scene2-btn-next, scene2-statement-1, scene2-statement-1-result等

- IIFE隔离：所有JS代码包裹在(function() { ... })()中，避免全局变量污染
