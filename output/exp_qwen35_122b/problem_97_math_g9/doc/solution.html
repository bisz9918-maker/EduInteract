场景导航：Scene 1 | Scene 2

题目原文：

已知二次函数 y=ax²+bx+1 的大致图象如图所示，那么一次函数 y=ax+b 的图象不经过（ ）

A. 第一象限 B. 第二象限 C. 第三象限 D. 第四象限

题目分析：

本题考察二次函数与一次函数图像性质的关联。解题关键在于：

  1. 从二次函数图像提取参数 a、b 的符号信息
  2. 根据 a、b 符号判断一次函数图像的位置特征

整体讲解思路：

第一步：观察二次函数图像，分析开口方向→确定 a 的符号；分析对称轴位置→确定 b 的符号

第二步：根据 a<0、b<0，画出一次函数 y=ax+b 的示意图，判断其经过的象限

图示规划说明：

规划 2 个图示：

  • Scene 1：二次函数图像分析，通过分步导航展示如何从图像提取 a、b 符号
  • Scene 2：一次函数图像判断，展示根据 a、b 符号确定直线位置的过程
步骤 1/4

教学说明：

本图示用于引导学生从二次函数图像中提取参数信息。教师应按以下步骤讲解：

  1. 步骤 0：展示完整图像，让学生观察整体特征
  1. 步骤 1：高亮抛物线开口方向
  • 提问：「抛物线开口向上还是向下？」
  • 结论：开口向下 → a < 0
  • 强调：二次项系数 a 决定开口方向
  1. 步骤 2：高亮对称轴位置
  • 提问：「对称轴在 y 轴左侧还是右侧？」
  • 公式：对称轴 x = -b/(2a)
  • 推理：对称轴在左侧 → -b/(2a) < 0
  • 由于 a < 0，故 b < 0
  • 强调：对称轴位置与 a、b 符号的关系
  1. 步骤 3：总结 a、b 符号
  • a < 0（开口向下）
  • b < 0（对称轴在左侧）

关键公式：

二次函数 y = ax² + bx + c

  • 开口方向由 a 决定：a > 0 开口向上，a < 0 开口向下
  • 对称轴：x = -b/(2a)

教学说明：

本图示用于展示如何根据 a、b 符号判断一次函数图像经过的象限。教师应按以下步骤讲解：

  1. 步骤 0：展示坐标系和已知条件（a<0，b<0）
  1. 步骤 1：分析斜率
  • 斜率 a < 0 → 直线从左上向右下倾斜
  • 高亮显示直线的倾斜方向
  1. 步骤 2：分析截距
  • 截距 b < 0 → 直线与 y 轴交于负半轴
  • 高亮显示交点位置 (0, b)
  1. 步骤 3：综合判断
  • 斜率负 + 截距负 → 直线经过第二、三、四象限
  • 不经过第一象限
  • 用绿色填充经过的象限，红色标注不经过的象限

完整解答：

由二次函数图像可知：

  • a < 0（开口向下）
  • b < 0（对称轴在 y 轴左侧）

对于一次函数 y = ax + b：

  • 斜率 a < 0 → 直线从左上向右下
  • 截距 b < 0 → 与 y 轴交于负半轴

因此直线经过第二、三、四象限，不经过第一象限。

答案：A

课堂讲解建议：

  1. 强调两个函数图像之间的联系：二次函数图像提供参数信息，一次函数图像应用参数信息
  1. 提醒学生注意对称轴公式 x = -b/(2a) 的符号判断技巧
  1. 可让学生先独立思考，再对照图示验证思路
