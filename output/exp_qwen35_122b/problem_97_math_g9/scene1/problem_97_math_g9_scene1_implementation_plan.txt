[分步序列]
- 步骤 0（初始状态）：
  - 显示：x 轴、y 轴、原点 O、抛物线、y 轴截距点及标签"1"
  - 隐藏：对称轴、对称轴标签、开口箭头、a<0 标注、b<0 标注
  - 目的：展示题目原始图像，等待学生观察

- 步骤 1：
  - 新增显示：对称轴（虚线）、对称轴标签
  - 新增显示：开口箭头（红色，向下）
  - 新增显示：a<0 标注（红高亮，位于开口上方）
  - 高亮：抛物线填充色加深至 25% 蓝色
  - 目的：引导学生观察开口方向，得出 a<0

- 步骤 2：
  - 新增显示：b<0 标注（蓝高亮，位于对称轴左侧）
  - 高亮：对称轴虚线加粗至 3px
  - 目的：引导学生观察对称轴位置，结合 a<0 推导 b<0

- 步骤 3（最终状态）：
  - 所有元素显示
  - 在右下角添加总结框："结论：a<0，b<0"（绿高亮 #2e7d32）
  - 总结框位置：(550,150)，大小约 120×40
  - 目的：总结参数符号，为判断一次函数图像位置做准备

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（线段、曲线、文本），无需复杂计算，原生 SVG 足够且性能最佳
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │                        y                                    │
  │                        ↑                                    │
  │           ╱‾‾‾╲        │        对称轴                      │
  │         ╱       ╲      │        │                           │
  │        │  a<0    │     │        │ b<0                       │
  │       ╱           ╲    │        │                           │
  │      ╱    顶点      ╲   │        │                           │
  │     ╱               ╲  │        │                           │
  │    ╱                 ╲ │        │                           │
  │───╱───────────────────╲┼────────┼──────────────────────────→ x
  │  ╱          O          │        │              1            │
  │ ╱                      │        │                           │
  │╱                       │        │                           │
  │                        │        │                           │
  │                        │        │                           │
  │     步骤指示器         │        │                           │
  │    [◀上一步][下一步▶]  │        │                           │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-3) 记录当前步骤，updateScene() 函数根据 currentStep 控制元素显示/隐藏
  2. 抛物线绘制：用 SVG path 的 quadratic bezier 曲线或精确的二次函数点集，顶点 (280,120)，过 (400,280)
  3. 坐标计算：y 轴截距 (0,1) 对应图像坐标 (400,280)，顶点 (-120, 160) 对应 (280,120)
  4. 动画曲线：元素出现用 opacity 从 0 到 1 的过渡动画，duration 300ms
  5. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateScene()
  6. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-parabola、scene1-axis-x、scene1-label-a）
  7. IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
  8. 总结框：步骤 3 才显示的 rect + text 组合，位置 (550,150)，绿边框 #2e7d32
