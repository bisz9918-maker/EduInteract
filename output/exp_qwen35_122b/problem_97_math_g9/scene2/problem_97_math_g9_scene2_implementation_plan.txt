[分步序列]
- 步骤 0（初始状态）：
  - 显示：x 轴、y 轴、原点 O、四个象限标注（Ⅰ、Ⅱ、Ⅲ、Ⅳ）
  - 显示：参数条件区（a<0、b<0、y=ax+b）
  - 隐藏：一次函数直线、象限填充、不经过标注、斜率箭头、截距点
  - 目的：展示已知参数条件，等待推理

- 步骤 1：
  - 新增：一次函数直线（蓝高亮#1565c0，从 (150,150) 到 (650,350)）
  - 新增：斜率箭头（红高亮#c62828，从 (250,200) 到 (300,220)，标注"a<0"）
  - 高亮：a<0 标注文字加粗
  - 目的：展示斜率为负时直线的倾斜方向（从左上到右下）

- 步骤 2：
  - 新增：截距标注点（蓝高亮#1565c0，在 (400,300)）
  - 新增：截距标注文字"b<0"在点右侧 (415,295)
  - 高亮：b<0 标注文字加粗
  - 目的：展示截距为负时直线与 y 轴交于负半轴

- 步骤 3（最终步骤）：
  - 新增：象限Ⅱ、Ⅲ、Ⅳ填充（绿高亮#2e7d32，透明度 20%）
  - 新增：不经过标注（红高亮#c62828，在象限Ⅰ区域 (550,200) 显示"不经过"）
  - 高亮：象限Ⅰ文字变红
  - 目的：完整展示一次函数 y=ax+b 经过Ⅱ、Ⅲ、Ⅳ象限，不经过Ⅰ象限

冲突检查：
- "O"(385,265) 与 "Ⅲ"(250,320)：距离约 147px → 无冲突
- "O"(385,265) 与 "Ⅳ"(550,320)：距离约 173px → 无冲突
- "Ⅰ"(550,180) 与 "不经过"(550,200)：距离 20px → 临界，将"不经过"下移至 (550,210)
- "a<0"(130,140) 与 "b<0"(130,170)：距离 30px → 无冲突
- "b<0"(130,170) 与 "y=ax+b"(130,195)：距离 25px → 无冲突
- "截距 b<0"(415,295) 与 "O"(385,265)：距离约 43px → 无冲突
- "截距 b<0"(415,295) 与 "Ⅳ"(550,320)：距离约 138px → 无冲突

解决方案：将"不经过"标注从 (550,200) 下移至 (550,210)，确保与象限Ⅰ标签间距≥25px

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮：ID scene2-prev-btn，位置 (280,455)，作用：返回上一状态
  - 下一步按钮：ID scene2-next-btn，位置 (460,455)，作用：进入下一状态
- 教师操作流程：
  1. 初始展示参数条件，引导学生从二次函数图像推导 a<0、b<0
  2. 点击"下一步"，展示斜率 a<0 对应的直线倾斜方向
  3. 点击"下一步"，展示截距 b<0 对应的 y 轴交点位置
  4. 点击"下一步"，完整展示直线经过的象限，得出"不经过第一象限"的结论
  5. 可随时点击"上一步"回退复习关键推理环节

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    800px                                │

  │  │                                                   │  │
  │  │     Ⅱ              │              Ⅰ              │  │
  │  │    ┌──────┐        │        ┌──────┐              │  │
  │  │    │      │        │        │不经过│              │  │

  │  │    │ ╱    │        │        │      │              │  │

  │  └───────────────────────────────────────────────────┘  │
  │                         500px                           │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-3) 跟踪当前步骤
  2. 元素分组：每个步骤新增的元素用 <g> 标签分组，通过 display 属性控制显示/隐藏
  3. 坐标计算：所有坐标按布局坐标表精确实现
  4. 动画曲线：直线绘制使用 stroke-dasharray + stroke-dashoffset 实现绘制动画
  5. 事件绑定：按钮点击事件更新 currentStep，刷新对应元素显示状态
  6. ID 命名规范：所有元素 ID 以 scene2- 为前缀（如 scene2-axis-x、scene2-line、scene2-quadrant-Ⅰ等）
  7. IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
  8. 控件栏位置：固定在 SVG 底部 y=440~490 区域，使用 absolute 定位
