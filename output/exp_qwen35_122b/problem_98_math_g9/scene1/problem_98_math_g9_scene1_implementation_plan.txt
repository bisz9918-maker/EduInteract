[图示主题与整合说明]
- 本图示主题：圆内接等腰三角形与直径的几何关系分析
- 整合的步骤/概念：
  1. 题目原图的完整呈现（圆⊙O、内接△ABC、直径 AD）
  2. 等腰三角形角度推导（∠ABC=120° ⇒ ∠BAC=30°）
  3. 直径所对圆周角为直角的识别（∠ABD=90°）
  4. 直角三角形中的三角函数计算（AB=AD·cos30°）
- 教学价值：教师可通过分步导航逐步揭示图形中的隐含条件，学生跟随每一步的视觉变化理解推导逻辑，特别适合讲解圆内接三角形性质和直径所对圆周角定理

[分步序列]
- 步骤 0（初始状态）：
  - 显示：圆⊙O、点 A/B/C/D/O、线段 AB/BC/AC/AD、等长标记 AB/BC
  - 标注：∠ABC=120°、AD=6
  - 隐藏：辅助线 BD、∠BAC 标注、∠ABD 标注、计算式、高亮填充
  - 按钮：上一步禁用，下一步启用

- 步骤 1：
  - 新增：△ABC 高亮填充、∠BAC 弧线、∠BAC=30°标注
  - 视觉变化：△ABC 区域淡入蓝色填充，A 点内侧出现蓝色弧线及"30°"标注
  - 推导：等腰三角形底角相等，∠BAC=∠BCA=(180°-120°)/2=30°
  - 按钮：上一步启用，下一步启用

- 步骤 2：
  - 新增：辅助线 BD（虚线）、∠ABD 直角标记、∠ABD=90°标注
  - 视觉变化：BD 虚线淡入，B 点内侧出现红色直角符号及"90°"标注
  - 推导：直径所对圆周角为直角，∠ABD=90°
  - 按钮：上一步启用，下一步启用

- 步骤 3：
  - 新增：Rt△ABD 高亮填充、计算式"AB=AD·cos30°=6×(√3/2)=3√3"
  - 视觉变化：△ABD 区域淡入蓝色填充，右下角出现蓝色计算式
  - 推导：在 Rt△ABD 中，∠BAD=30°，AB=AD·cos30°=6×(√3/2)=3√3
  - 按钮：上一步启用，下一步启用

- 步骤 4（结论）：
  - 新增：最终答案"AB=3√3"、选项"C"标记
  - 视觉变化：右下角出现绿色粗体答案，旁边标注"选项 C"
  - 结论：AB=3√3，选择选项 C
  - 按钮：上一步启用，下一步禁用

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形绘制简单，SVG 适合精确坐标定位，原生 JS 无需额外依赖，性能好
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │                         图示区 800×500                       │
  │                                                              │
  │              D(570,240)                                     │
  │                ●                                             │
  │               /  ╲                                           │
  │              /    ╲                                          │
  │     O(410,235)      ╲                                        │
  │       ●──────────────●───────────────── 直径 AD=6            │
  │      /  ╲            A(250,250)                              │
  │     /    ╲                                                   │
  │    /      ╲                                                  │
  │   ●────────● C(550,320)                                      │
  │  A(230,270)  ╲                                               │
  │               ╲                                              │
  │                ● B(400,405)                                  │
  │                                                              │
  │              计算式区域 (620,380)                            │
  │              答案区域 (620,420)                              │
  │                                                              │
  │  ┌──────────────┐                              ┌──────────────┐
  │  │ ◀ 上一步     │                              │     下一步 ▶ │
  │  └──────────────┘                              └──────────────┘
  │                    控件栏 y=450~490                            │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 currentStep 记录当前步骤 (0-4)，updateScene() 函数根据 currentStep 显示/隐藏对应元素
  2. 坐标计算：所有元素坐标硬编码在配置对象中，便于维护和调整
  3. 动画曲线：使用 CSS transition 实现淡入淡出效果 (opacity: 0→1，duration: 0.3s)
  4. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 updateScene()
  5. 元素显示控制：通过修改 SVG 元素的 display 或 opacity 属性控制显示/隐藏
  6. 高亮填充：使用 <path> 元素配合 fill-opacity 实现半透明填充
- ID 命名规范：所有交互元素 ID 以 scene1- 为前缀（如 scene1-circle-o、scene1-line-ab、scene1-prev-btn、scene1-next-btn）
- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染
