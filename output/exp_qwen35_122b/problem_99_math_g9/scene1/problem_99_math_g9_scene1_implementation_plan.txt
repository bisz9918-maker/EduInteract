[分步序列]
- 步骤 0（初始状态）：显示等边三角形 ABC（实线），点 D 在 AB 上，标注 A、B、C、D 顶点标签，标注 AD=1、BD=2、BF=1.25。等待教师点击「下一步」
- 步骤 1：显示折痕 EF（虚线），显示虚线三角形 CEF（表示折叠前的 C 点位置），显示点 E、F 顶点标签，显示数值 CF=1.75。C 点位置用虚线表示，准备折叠。新增标签 E、F、CF=1.75
- 步骤 2：显示线段 DE（蓝色高亮）和 DF（红色高亮），显示点 E、F 的实心圆点，显示等长标记（CE=DE 用蓝色双短线，CF=DF 用红色双短线），显示等长说明文字。折叠动画：虚线 C 点移动到 D 点位置
- 步骤 3：高亮显示待求量 CE=?（红色加粗），显示所有已知长度标注，显示最终结论区域（显示 CE=7/5，对应选项 A）。所有元素完整显示

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 按钮「上一步」：scene1-btn-prev，位置 (300,460)，作用：返回上一步骤
  - 按钮「下一步」：scene1-btn-next，位置 (500,460)，作用：进入下一步骤
  - 步骤指示器：scene1-step-indicator，位置 (380,460)，显示「步骤 1/4」
- 教师操作流程：
  1. 初始展示三角形 ABC 和已知条件（AD=1, BD=2, BF=1.25）
  2. 点击「下一步」展示折痕 EF 和折叠前的虚线三角形
  3. 点击「下一步」展示折叠后的线段关系（DE, DF）和等长标记
  4. 点击「下一步」高亮待求量 CE=? 并显示答案
  5. 可随时点击「上一步」回退复习关键步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────┐
  │                    800px                                │
  │  ┌───────────────────────────────────────────────────┐  │
  │  │                                                   │  │
  │  │              C(400,68)                            │  │
  │  │               /   \                               │  │
  │  │              /     \                              │  │
  │  │         E   /       \   F                         │  │
  │  │        ●───●---------●───●                        │  │
  │  │       /     \       /     \                       │  │
  │  │      /       \     /       \                      │  │
  │  │     /    D    \   /         \                     │  │
  │  │    ●───────────●─────────────●                    │  │
  │  │   A(220,380)  (340,380)    B(580,380)             │  │
  │  │                                                   │  │
  │  │  [上一步]  步骤 1/4  [下一步]  ← 控件栏 y=460      │  │
  │  └───────────────────────────────────────────────────┘  │
  │                     500px                               │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：currentStep 变量 (0-3)，updateScene() 函数根据 currentStep 显示/隐藏对应元素
  2. 坐标计算：使用 spec 中给出的精确像素坐标，三角形顶点通过等边三角形几何关系计算
  3. 动画曲线：折叠动画使用 requestAnimationFrame，C 点从 (400,68) 线性移动到 (340,380)，时长 500ms
  4. 事件绑定：按钮点击事件绑定到 scene1-btn-prev 和 scene1-btn-next，边界检查防止越界
  5. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-tri-abc, scene1-point-d, scene1-line-de）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染
  7. 元素显示控制：使用 style.display = 'none'/'block' 或 opacity 控制各步骤元素的显示/隐藏
  8. 等长标记实现：在 CE 和 DE 线段中点附近绘制两条短垂线，颜色 #2e7d32
