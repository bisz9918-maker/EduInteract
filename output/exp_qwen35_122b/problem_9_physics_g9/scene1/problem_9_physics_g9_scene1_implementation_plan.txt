[视觉元素清单]
- 电源：电池符号（长竖线表示正极在左，短竖线表示负极在右），位置 (200,420)-(600,420)，标签"3V"在下方 (400,445)
- 灯泡 L₁：圆圈（直径 50px）内加叉号，圆心 (275,200)，标签"L₁"在上方 (275,165)，绿色填充透明度 20%
- 灯泡 L₂：圆圈（直径 50px）内加叉号，圆心 (425,200)，标签"L₂"在上方 (425,165)，绿色填充透明度 20%
- 开关 S₁：单刀双掷开关，公共端 (550,380)，触点 a(600,380)、b(450,280)，开关臂从公共端指向 b 触点（初始状态），标签"S₁"在右下方 (570,395)，触点用红色标注
- 开关 S₂：单刀单掷开关，位置 (300,120)-(380,120)，断开状态，标签"S₂"在上方 (340,100)

- 节点：实心圆点，直径 6px，黑色
- 高亮层：蓝色 (#1565c0) 用于当前步骤高亮，红色 (#c62828) 用于开关触点，绿色 (#2e7d32) 用于灯泡

[分步序列]
步骤 0（初始状态）：
- 显示完整电路图的灰色轮廓（所有导线、元件用 #888888 虚线或浅灰色显示）
- 显示所有标签（L₁、L₂、S₁、S₂、a、b、3V）
- 等待教师点击"下一步"

步骤 1：高亮电源和主回路
- 电源变为黑色实线，标注"3V"加粗
- 左侧竖线 (200,150)-(200,420) 和底部电源 (200,420)-(600,420) 变为蓝色高亮
- 右侧竖线 (600,200)-(600,380) 变为蓝色高亮
- 其他元件保持灰色
- 视觉变化：主回路路径清晰可见

步骤 2：高亮 S₁及 a、b 触点
- S₁开关（公共端、开关臂、触点 a 和 b）变为蓝色高亮
- 触点 a、b 用红色圆圈特别标注
- 连接线 (600,200)-(600,380) 和 (450,200)-(450,280) 变为蓝色高亮
- 其他保持步骤 1 状态或灰色
- 视觉变化：S₁的两种连接路径清晰

步骤 3：高亮 S₂支路
- S₂开关及其连接线 (200,120)-(200,150) 和 (500,120)-(500,200) 变为蓝色高亮
- S₂开关本身用蓝色加粗显示
- 视觉变化：顶部并联支路清晰

步骤 4：标注 L₁、L₂参数
- L₁灯泡变为绿色高亮，显示参数"6V 6W"在标签旁
- L₂灯泡变为绿色高亮，显示参数"3V 3W"在标签旁
- 所有元件高亮完成，电路全貌清晰
- 视觉变化：灯泡参数标注完成，准备进行电路分析

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "上一步"按钮：位置 (250,460)，作用：返回前一个步骤
  - "下一步"按钮：位置 (550,460)，作用：进入下一个步骤
  - 步骤指示器：位置 (380,460)，显示"步骤 1/5"
- 教师操作流程：
  1. 初始展示灰色电路轮廓，让学生先观察整体结构
  2. 点击"下一步"，逐步高亮各部分，引导学生识别电源、开关、灯泡的位置
  3. 每一步暂停，讲解该部分的功能和连接关系
  4. 最后一步展示完整参数，为分析各选项做准备
  5. 可随时点击"上一步"回退复习

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（电路图适合用 SVG 绘制，线条清晰，易于高亮控制）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
```
┌─────────────────────────────────────────────────────────┐
│                    图示区 800×500                        │
│                                                         │
│   S₂ ────────────────────────────────                   │
│   │                                    │                │
│   ●──── L₁ ─────●──── L₂ ─────●        │                │
│   │             │             │        │                │
│   │             │             ● a      │                │
│   │             ● b           │        │                │
│   │                           │        │                │
│   │                           ● S₁     │                │
│   │                                    │                │
│   └──────────── 电源 3V ───────────────┘                │
│                                                         │
│   [◀ 上一步]  步骤 1/5  [下一步 ▶]  (y=460 控件栏)       │
└─────────────────────────────────────────────────────────┘
```

- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-4) 跟踪当前步骤，updateHighlight() 函数根据 currentStep 更新各元素样式
  2. 坐标计算：所有元素坐标按上述布局表精确实现
  3. 高亮动画：使用 CSS transition 实现颜色渐变效果（0.3s ease）
  4. 事件绑定：按钮点击事件更新 currentStep 并调用 updateHighlight()
  5. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-battery、scene1-lamp1、scene1-switch1 等）
  6. IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染

- SVG 元素 ID 命名：
  - scene1-battery：电源
  - scene1-lamp1：灯泡 L₁
  - scene1-lamp2：灯泡 L₂
  - scene1-switch1：开关 S₁
  - scene1-switch2：开关 S₂
  - scene1-wire-*：各段导线
  - scene1-label-*：各标签文本
  - scene1-btn-prev：上一步按钮
  - scene1-btn-next：下一步按钮
  - scene1-step-indicator：步骤指示器
