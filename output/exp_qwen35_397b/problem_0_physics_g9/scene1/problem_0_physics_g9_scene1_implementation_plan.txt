[图示主题与整合说明]
- 本图示主题：杠杆平衡条件及动态变化分析
- 整合的内容：初始平衡状态展示、两人向支点移动过程、力臂变化标注、移动后力矩对比、最终结论呈现
- 教学价值：教师可通过分步演示，引导学生从初始平衡条件出发，理解力矩平衡公式 G×L，再通过动态移动过程直观感受力臂变化对力矩的影响，最终推导出"小孩那端下沉"的结论。分步节奏可控，便于课堂互动和难点突破。

[分步序列]
- 步骤 0（初始状态）：显示杠杆、支点、大人简笔画、小孩简笔画、G_大人 标签、G_小孩 标签。杠杆水平，呈现题目原图基础状态。
- 步骤 1：新增显示 L_大人 标注线、L_小孩 标注线、L_大人 标签、L_小孩 标签。高亮支点（加粗轮廓）。显示 G_大人 > G_小孩 提示文字在顶部(400,50)。
- 步骤 2：新增显示大人移动箭头、小孩移动箭头、ΔL 标签（两侧）。箭头从透明到可见的淡入动画（300ms）。
- 步骤 3：新增显示力矩变化框（大人，红色半透明）、力矩变化框（小孩，绿色半透明）、G_大人×ΔL 标签、G_小孩×ΔL 标签。大人侧红色框先从左到右展开动画，小孩侧绿色框从右到左展开动画（各 400ms）。
- 步骤 4（最终结论）：杠杆绕支点顺时针旋转 5 度（小孩端下沉动画，500ms）。显示结论文本"小孩那端下沉"在(400,420)，红色加粗淡入。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于(280,455)，100×35px，点击后返回上一状态，若已在步骤 0 则禁用
  - 「下一步」按钮：位于(420,455)，100×35px，点击后进入下一状态，若已在步骤 4 则禁用
- 教师操作流程：
  1. 初始加载后，教师先展示步骤 0，让学生观察题目原图
  2. 点击「下一步」到步骤 1，讲解力臂概念和初始平衡条件 G_大人×L_大人 = G_小孩×L_小孩
  3. 点击「下一步」到步骤 2，说明两人同时向支点移动，移动距离相等ΔL
  4. 点击「下一步」到步骤 3，对比两侧力矩减少量：G_大人×ΔL > G_小孩×ΔL，大人侧力矩减少更多
  5. 点击「下一步」到步骤 4，展示结论：小孩那端下沉，杠杆顺时针转动
  6. 教师可随时点击「上一步」回退复习关键步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript。原因：本题为 2D 几何图示，无需复杂库，原生 SVG 可精确控制坐标和样式，代码轻量易维护。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                    ΔL    ΔL                      |
  |              →  [大人]      [小孩]  ←            |
  |                   G_大人    G_小孩               |
  |                                                  |
  |  ====================杠杆====================    |
  |                        △ 支点                    |
  |              <---L_大人---><---L_小孩--->        |
  |                                                  |
  |         [G_大人×ΔL]            [G_小孩×ΔL]       |
  |                                                  |
  |              小孩那端下沉                        |
  |                                                  |
  |            [◀上一步]    [下一步▶]               |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-4)，每个步骤对应一组可见元素 ID 列表
  2. 坐标计算：所有元素坐标硬编码，确保与布局坐标表一致
  3. 动画曲线：使用 CSS transition 实现淡入和位移动画，easing 为 ease-out
  4. 事件绑定：按钮点击事件绑定到 step 切换函数，切换时更新元素 display/opacity 属性
  5. 杠杆旋转动画：步骤 4 使用 transform: rotate(5deg) 并设置 transform-origin 为支点位置
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀，例如：
  - scene1-lever（杠杆）
  - scene1-fulcrum（支点）
  - scene1-adult（大人）
  - scene1-child（小孩）
  - scene1-label-G-adult（G_大人 标签）
  - scene1-label-G-child（G_小孩 标签）
  - scene1-arm-L-adult（L_大人 标注线）
  - scene1-arm-L-child（L_小孩 标注线）
  - scene1-arrow-adult（大人移动箭头）
  - scene1-arrow-child（小孩移动箭头）
  - scene1-box-moment-adult（大人侧力矩变化框）
  - scene1-box-moment-child（小孩侧力矩变化框）
  - scene1-btn-prev（上一步按钮）
  - scene1-btn-next（下一步按钮）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
