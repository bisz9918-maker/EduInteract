[分步序列]
- 初始状态（步骤 0）：显示折叠前正方形、折叠箭头、折叠后三角形、三个洞（洞 1/2/3 均为 #000000 轮廓）、对称轴虚线。展开后正方形和对角线显示但洞不显示。选项区显示四个选项但无高亮。
- 步骤 1：点击「下一步」→ 洞 1 高亮为 #1565c0，展开后正方形中显示洞 1 的两个对称位置（展开洞 1a 和 1b），用 #1565c0 绘制，并显示从洞 1 到对称位置的虚线箭头。洞 1 标签显示在右下方 (250, 145)。
- 步骤 2：点击「下一步」→ 洞 1 变为 #2e7d32（已分析），洞 2 高亮为 #1565c0，展开后正方形中显示洞 2 的两个对称位置（展开洞 2a 和 2b），用 #1565c0 绘制。洞 2 标签显示在左上方 (230, 80)。
- 步骤 3：点击「下一步」→ 洞 2 变为 #2e7d32，洞 3 高亮为 #1565c0，展开后正方形中显示洞 3 的两个对称位置（与洞 2 的对称位置重合，用 #1565c0 叠加显示）。洞 3 标签显示在右下方 (295, 145)。
- 步骤 4：点击「下一步」→ 所有洞变为 #2e7d32，展开后正方形中显示全部 6 个洞（实际可见 4 个位置，其中两个位置各有 2 个洞重叠），用 #2e7d32 绘制完整图案。显示"完整图案"标签。
- 步骤 5：点击「下一步」→ 选项 C 的边框加粗为 #2e7d32 3px，其他选项边框变淡为 #cccccc，显示"正确答案"标签指向选项 C。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 (280, 455)，80×30px，蓝色圆角矩形，点击返回上一状态
  - 「下一步」按钮：位于 (440, 455)，80×30px，蓝色圆角矩形，点击进入下一状态
  - 步骤指示器：位于 (400, 465)，显示当前步骤编号 "步骤 X/5"
- 教师操作流程：
  1. 初始状态展示折叠过程和三个洞的位置
  2. 点击「下一步」逐步展示每个洞的对称展开效果
  3. 步骤 4 展示完整图案后，可暂停讲解对称原理
  4. 步骤 5 展示正确答案，与选项 C 对比
  5. 可随时点击「上一步」回退复习关键步骤

[技术实现]
- JS 库选择及原因：原生 SVG（简单几何图形，无需复杂库，轻量且易于控制坐标）
- 画布尺寸：800 × 500 px（固定画布）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +----------------------------------------------------------+
  |                    挖洞与对称展开                         |  y=30 标题
  |                                                          |
  |  [正方形] → [三角形]                                      |  y=70-150 折叠过程
  |     洞 1 洞 2 洞 3                                         |
  |                    ↓                                      |
  |           [展开正方形 + 对角线]                            |  y=250-390 展开图
  |              显示对称洞位                                  |
  |                                                          |
  |    选项对比：[A] [B] [C] [D]                              |  y=280-350 选项区
  |                                                          |
  +----------------------------------------------------------+
  |  [◀上一步]    步骤 X/5    [下一步▶]                       |  y=440-490 控件栏
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-5），每个状态对应一组可见元素
  2. 坐标计算：所有元素坐标预先定义在配置对象中，避免运行时计算
  3. 动画曲线：使用 CSS transition 实现洞的高亮颜色变化（0.3s ease）
  4. 事件绑定：按钮点击事件绑定到状态切换函数，更新可见性
  5. 元素可见性控制：通过 display 属性或 opacity 控制各步骤元素的显示/隐藏
- ID 命名规范：所有交互元素 ID 必须以 scene2- 为前缀（如 scene2-square-fold, scene2-hole-1, scene2-btn-prev, scene2-btn-next）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
