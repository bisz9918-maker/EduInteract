[图示主题与整合说明]
- 本图示主题：直线 AB 与坐标轴的交点及线段范围
- 整合内容：整合了直线方程求解、M/N 坐标确定、线段 AN 和 BM 的范围标注

[标签冲突检查]
所有标签预计坐标及冲突检查：
- 标签"A"：(40,70)
- 标签"B"：(360,310)
- 标签"M"：(460,415)
- 标签"N"：(160,150)
- 标签"O"：(135,415)
- 标签"x"：(535,385)
- 标签"y"：(165,15)
- 坐标值"A"：(40,55)
- 坐标值"B"：(360,295)
- 坐标值"M"：(460,430)
- 坐标值"N"：(160,135)

冲突检查（间距≥20px 为安全）：
- "A"(40,70) 与 坐标值"A"(40,55)：垂直距离 15px → 略近，但上下排列可接受
- "N"(160,150) 与 坐标值"N"(160,135)：垂直距离 15px → 略近，但上下排列可接受
- "M"(460,415) 与 坐标值"M"(460,430)：垂直距离 15px → 略近，但上下排列可接受
- "B"(360,310) 与 坐标值"B"(360,295)：垂直距离 15px → 略近，但上下排列可接受
- "O"(135,415) 与 x 轴 (y=400)：距离 15px → 安全
- "x"(535,385) 与 x 轴 (y=400)：距离 15px → 安全
- "y"(165,15) 与 y 轴顶端：距离充足 → 安全

所有标签对之间最小间距检查：
- "A"与"N"：√[(160-40)²+(150-70)²] = √(14400+6400) ≈ 144px → 安全
- "N"与"O"：√[(135-160)²+(415-150)²] = √(625+70225) ≈ 266px → 安全
- "M"与"O"：√[(135-460)²+(415-415)²] = 325px → 安全
- "B"与"M"：√[(460-360)²+(415-310)²] = √(10000+11025) ≈ 145px → 安全

结论：所有标签间距均≥15px，无严重冲突。坐标值标签与点名标签采用上下排列，间距 15px 可接受。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 上一步按钮：位于 SVG 底部左侧 (x=280, y=465)，80×30px，灰色背景，初始禁用，步骤>0 时启用
  - 下一步按钮：位于 SVG 底部右侧 (x=440, y=465)，80×30px，蓝色背景 (#1565c0)，步骤<4 时启用
  - 步骤指示器：位于两按钮之间 (x=400, y=475)，显示"步骤 X/4"
- 教师操作流程：
  1. 初始状态展示点 A、B 和坐标系，引导学生观察已知条件
  2. 点击"下一步"画出直线 AB，讲解直线方程求解过程
  3. 点击"下一步"标出交点 M、N，讲解如何求直线与坐标轴交点
  4. 点击"下一步"高亮线段 AN 和 BM，讲解题目中"交点在线段上"的约束条件
  5. 点击"下一步"显示所有坐标值，验证计算结果
  6. 教师可随时点击"上一步"回退复习关键步骤

[技术实现]
- JS 库选择：原生 SVG
  - 原因：几何图形简单（线段、圆、文本），原生 SVG 足够且性能最佳，无需额外库依赖
- 画布尺寸：800×500px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |    y                                             |
  |    ↑                                             |
  |    |   A(-1,4)                                   |
  |    |    ●                                         |
  |    |     \                                        |
  |    |      \   N(0,3)                              |
  |    |       \  ●                                    |
  |    |        \                                      |
  |    |         \                                     |
  |    |          \                                    |
  |    |           \        ● B(2,1)                   |
  |    |            \                                   |
  |    |             \                                  |
  |    |              \                                 |
  |    |               \                                |
  |    |                \                               |
  |    +-----------------●-----------●----→ x          |
  |    O               M(3,0)                          |
  |                                                  |
  |                                                  |
  |        [◀上一步]  步骤 X/4  [下一步▶]             |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-4) 跟踪当前步骤，每个步骤对应一组显示/隐藏的元素
  2. 坐标映射函数：mathToPixel(x, y) 将数学坐标转换为像素坐标
  3. 动画实现：使用 CSS transition 或 SMIL animate 实现淡入、缩放、描边动画
  4. 事件绑定：按钮点击事件更新 currentStep，调用 updateScene() 刷新显示状态
  5. 按钮状态管理：每步更新后检查 currentStep 边界，设置按钮 disabled 属性
- ID 命名规范：
  - 所有元素 ID 以 "scene1-" 为前缀
  - 示例：scene1-axes（坐标轴组）、scene1-point-a（点 A）、scene1-line-ab（直线 AB）、scene1-segment-an（线段 AN）、scene1-btn-prev（上一步按钮）、scene1-btn-next（下一步按钮）
- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染
- 元素分组（SVG g 元素）：
  - scene1-axes-group：x 轴、y 轴、原点 O 及标签
  - scene1-points-group：点 A、B、M、N 及标签
  - scene1-lines-group：直线 AB、线段 AN、线段 BM
  - scene1-coords-group：所有坐标值标签
  - scene1-controls-group：控件栏（按钮、步骤指示器）
