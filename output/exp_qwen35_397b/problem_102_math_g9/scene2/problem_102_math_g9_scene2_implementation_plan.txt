[图示主题与整合说明]
- 本图示主题：抛物线与直线交点随参数 b 变化的动态演示
- 整合内容：整合了抛物线方程 y = x² - bx + 2、直线 AB 方程 y = -x + 3、交点位置、参数 b 变化对交点的影响
- 教学价值：教师可通过拖动滑块实时观察 b 值变化时抛物线形状的改变及两个交点的移动轨迹，帮助学生发现临界状态 b = 5/2 和 b = 11/3，理解为何 b 的取值范围是 5/2 ≤ b ≤ 11/3

[分步序列]
本场景为连续交互模式，无分步导航，通过滑块控制：
- 初始状态（b=2.5）：抛物线经过临界位置，P₁在 A 点附近，P₂在 BM 段上
- 拖拽滑块 b 从 0→4：抛物线顶点从右向左移动，两个交点沿直线 AB 滑动
- b < 5/2 时：P₁在 AN 延长线上（不满足条件），P₂在 BM 上
- b = 5/2 时：P₁恰好在 A 点（临界）
- 5/2 < b < 11/3 时：P₁在 AN 上，P₂在 BM 上（满足条件）
- b = 11/3 时：P₂恰好在 B 点（临界）
- b > 11/3 时：P₂在 BM 延长线上（不满足条件）

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：
  - 滑块轨道：位于 SVG 底部 y=465~485，x=150~650，对应 b 值范围 0~4
  - 滑块手柄：圆形 r=12，可左右拖拽，x 位置 = 150 + (b/4)×500
  - b 值显示：右上角 (680,470) 显示当前 b 值（保留 2 位小数）
  - 交点坐标显示：(680,440) 显示 P₁(x₁,y₁) 和 P₂(x₂,y₂)
- 教师操作流程：
  1. 初始状态 b=2.5，展示临界情况
  2. 向左拖动滑块减小 b，观察 P₁向 A 点左侧移动（离开 AN 段）
  3. 向右拖动滑块增大 b，观察 P₁沿 AN 向 N 移动，P₂沿 BM 向 M 移动
  4. 拖到 b≈3.67 时，P₂到达 B 点（另一临界）
  5. 继续向右，P₂离开 BM 段
  6. 引导学生总结：只有当 5/2 ≤ b ≤ 11/3 时，两交点才分别落在 AN 和 BM 上

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单，无需复杂库；SVG 便于精确坐标控制和交互事件绑定
- 画布尺寸：800×500 px
- 布局草图：
  ```
  [图示区 800×440]
  +------------------------------------------+
  | y=x²-bx+2                    y=-x+3      |
  |                                          |
  |     A    N                               |
  |        /                                 |
  |       /      P₁  P₂                      |
  |      /         ●   ●                     |
  |     /              B                     |
  |    /               ●                     |
  |   O----------------M---- x               |
  |                                          |
  |  [====|====|====|====|====]  b=2.50      |
  +------------------------------------------+
  [控件栏 y=440~500]
  滑块轨道 + 手柄 + b 值显示 + 交点坐标
  ```
- 关键实现要点：
  1. 坐标映射函数：mathToPixel(x, y) → (px, py)，pixelToMath(px, py) → (x, y)
  2. 抛物线绘制：对 x ∈ [-2, 4] 采样 200 点，计算 y = x² - bx + 2，转换为像素坐标生成 path
  3. 交点计算：解方程 x² - bx + 2 = -x + 3 → x² - (b-1)x - 1 = 0，用求根公式得 x₁, x₂
  4. 滑块拖拽：mousedown/mousemove/mouseup 事件，更新 b 值并重绘抛物线和交点
  5. 临界线：固定位置虚线，b=5/2 对应像素 x=430，b=11/3 对应 x=547
- ID 命名规范：所有元素 ID 以 scene2- 为前缀
  - scene2-axes, scene2-line-ab, scene2-parabola, scene2-point-a, scene2-point-b
  - scene2-intersect-p1, scene2-intersect-p2, scene2-critical-1, scene2-critical-2
  - scene2-slider-track, scene2-slider-handle, scene2-b-value, scene2-coords-display
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
