[视觉元素清单]
- 坐标系：x 轴范围[-2,4]，y 轴范围[-2,6]，原点位于(400,250)

- 辅助虚线：从 x 轴关键点垂直延伸到函数曲线，灰色 #888888 虚线
- 推导区：浅灰色背景矩形，显示推导步骤文本
- 答案框：蓝色 #1565c0 边框，线宽 2px，内部显示最终答案

  - 负函数值区域/标签：#c62828
  - 答案框：#1565c0 边框加粗
  - 辅助线：#888888 虚线

[分步序列]
- 初始状态（步骤 0）：显示坐标系、函数曲线 f(x)=x²-(b-1)x-1（取 b=2 为例）、x 轴上 4 个关键点(-1,0,2,3) 及其标签
- 步骤 1：点击「下一步」→ 显示 4 条灰色虚线从 x 轴关键点延伸到曲线，标注 f(-1)、f(0)、f(2)、f(3) 的位置
- 步骤 2：点击「下一步」→ 高亮显示各函数值标签，f(-1)=b-1(绿色，正)、f(0)=-1(红色，负)、f(2)=5-2b(绿色，正)、f(3)=11-3b(绿色，正)
- 步骤 3：点击「下一步」→ 推导区显示根的分布条件：f(-1)·f(0)≤0 且 f(2)·f(3)≤0
- 步骤 4：点击「下一步」→ 推导区显示代入计算过程：(b-1)·(-1)≤0 → b≥1；(5-2b)·(11-3b)≤0 → 5/2≤b≤11/3
- 步骤 5：点击「下一步」→ 答案框显示最终答案：5/2≤b≤11/3，蓝色边框高亮

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 底部左侧(280,455)，灰色背景，点击返回上一状态
  - 「下一步」按钮：位于 SVG 底部右侧(440,455)，蓝色背景，点击进入下一状态
  - 步骤指示器：位于两按钮之间(400,460)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始状态展示函数图像和关键点，让学生观察
  2. 点击「下一步」逐步展示辅助线和函数值位置
  3. 继续点击展示函数值符号和表达式
  4. 展示根的分布条件的数学表达
  5. 展示代入计算过程
  6. 最终展示答案，强调取值范围

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript
  - 原因：几何图形和函数曲线用 SVG 路径绘制简单高效，无需额外库；状态切换用原生 JS 控制即可
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |              标题：根的分布条件分析               | y=25
  +--------------------------------------------------+
  |                                                  |
  |                    函数曲线                       |
  |         f(-1)●           ●f(2) ●f(3)            |
  |              \           /     /                 |
  |               \         /     /                  |
  |                \       /     /                   |
  |  x=-1●---------●-----●-----●------● x=3         | y=250 (x 轴)
  |        \       |     |     |      |              |
  |         \      |     |     |      |              |
  |          \     |    f(0)  |      |              |
  |           \    |         |      |              |
  |                                                  |
  +--------------------------------------------------+
  | [推导区 y=340-430]                               |
  | 步骤文本：根的分布条件...                         |
  | [答案框 y=400-430] 5/2 ≤ b ≤ 11/3               |
  +--------------------------------------------------+
  | [控件栏 y=450-480]                               |
  |      [◀上一步]  步骤 X/5  [下一步▶]              |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量(0-5)，数组存储各状态配置
  2. 坐标计算：建立 x 值到 SVG 坐标的映射函数：svgX = 400 + x * 87.5（比例尺 87.5px/单位）
  3. 函数曲线绘制：根据当前 b 值计算路径点，使用 SVG path 元素
  4. 动画曲线：使用 CSS transition 实现平滑过渡，duration 300ms
  5. 事件绑定：按钮点击事件绑定到状态切换函数，更新 DOM 元素可见性
  6. 边界处理：第一步禁用「上一步」，最后一步禁用「下一步」
- ID 命名规范：所有交互元素 ID 必须以 scene3- 为前缀
  - scene3-coord-system, scene3-func-curve, scene3-point-x1, scene3-point-x0, scene3-point-x2, scene3-point-x3
  - scene3-label-x1, scene3-label-x0, scene3-label-x2, scene3-label-x3
  - scene3-label-f1, scene3-label-f0, scene3-label-f2, scene3-label-f3
  - scene3-dash-1, scene3-dash-2, scene3-dash-3, scene3-dash-4
  - scene3-derive-box, scene3-answer-box, scene3-btn-prev, scene3-btn-next, scene3-step-indicator
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中
