[分步序列]
- 初始状态（步骤 0）：显示正方形 ABCD 和菱形 PQCB 的基础轮廓（黑色实线），不显示阴影、辅助线、数值标注。显示所有点标签 A/B/C/D/P/Q/E/H。
- 步骤 1：点击「下一步」→ 在 BC 边下方显示蓝色标注"5"（正方形边长，由面积 25 推导），同时在 AB 边左侧也显示"5"。
- 步骤 2：点击「下一步」→ 画出辅助线 PH（P 到 BC 的垂线，灰色虚线），在 H 点添加直角符号，在 PH 右侧显示蓝色标注"4"（菱形的高，由面积 20÷5=4 推导）。显示 E 点标签。
- 步骤 3：点击「下一步」→ 阴影区域（五边形 ADEPB）以灰色 30% 透明度填充高亮，阴影边界用蓝色 #1565c0 加粗显示。
- 步骤 4：点击「下一步」→ 在画布左侧 (120,280) 显示红色文字"阴影面积=7.5"，同时可显示计算过程提示（正方形面积 25 - 重叠梯形面积 17.5 = 7.5）。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于 SVG 底部左侧 (x=350, y=455)，返回上一状态
  - 「下一步 ▶」按钮：位于 SVG 底部右侧 (x=450, y=455)，进入下一状态
  - 步骤指示器：位于两按钮之间 (x=400, y=455)，显示"步骤 X/4"
- 教师操作流程：
  1. 初始展示基础图形，让学生观察正方形与菱形的位置关系
  2. 点击「下一步」显示边长 5，引导学生由面积 25 推导边长
  3. 点击「下一步」显示辅助线和高 4，讲解菱形面积公式（底×高）
  4. 点击「下一步」高亮阴影，明确所求区域
  5. 点击「下一步」显示最终答案 7.5，完成讲解

[技术实现]
- JS 库选择及原因：原生 SVG。理由：本题为静态几何图形，无需复杂动画或交互，原生 SVG 轻量且精确控制坐标，适合几何教学图示。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |   阴影面积=7.5    A__________D                   |
  |                   |          |                   |
  |                   |  阴影    |E                  |
  |                   |    _P____|_______Q           |
  |                   |   /      |                   |
  |                   |  /       |                   |
  |                   | /        |                   |
  |                   B__________C                   |
  |                          H   (辅助线 PH 虚线)      |
  |                                                  |
  |         [边长 5]    [高 4]                        |
  |                                                  |
  |              [◀ 上一步]  步骤 X/4  [下一步 ▶]     |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-4)，每步对应不同的显示元素集合
  2. 元素分组：将 SVG 元素按步骤分组（如 step0-group, step1-group 等），通过 display 属性控制显示/隐藏
  3. 坐标计算：所有坐标预先计算好，硬编码在 SVG 中，确保精确
  4. 事件绑定：按钮点击事件切换 currentStep，调用 updateDisplay() 函数更新各元素可见性
  5. 边界处理：第一步禁用「上一步」，最后一步禁用「下一步」
- ID 命名规范：所有元素 ID 以 scene1- 为前缀，如 scene1-square、scene1-rhombus、scene1-shadow、scene1-label-A、scene1-btn-prev、scene1-btn-next
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
