场景导航：Scene 1 | Scene 2 | Scene 3

题目原文：

如图，∠BAC=∠DAF=90°，AB=AC，AD=AF，点 D、E 为 BC 边上的两点，且∠DAE=45°，连接 EF、BF，则下列结论：
①△AED≌△AEF；②△ABE∽△ACD；③BE+DC＞DE；④BE²+DC²=DE²，其中正确的有（）
A.1个 B.2个 C.3个 D.4个

题目分析：

本题是一道综合性几何证明题，核心考查：

  1. 全等三角形的判定（SAS）
  2. 旋转变换的性质
  3. 三角形不等式
  4. 勾股定理

关键解题思路是利用旋转变换：将△ACD 绕点 A 逆时针旋转 90°，由于 AB=AC、AD=AF 且∠BAC=∠DAF=90°，旋转后 C 与 B 重合、D 与 F 重合，从而得到 BF=DC 这一关键等量关系。

整体讲解思路：

  1. 首先让学生识别图中的两个等腰直角结构（△ABC 和∠DAF）
  2. 通过角度计算证明∠FAE=∠DAE=45°，进而用 SAS 证明结论①
  3. 引入旋转变换，说明 BF=DC 的来源
  4. 在△BEF 中应用三角形不等式和勾股定理，验证结论③④
  5. 结论②无法证明，举反例或说明条件不足

教学说明：

引导步骤：

  1. 先展示基础图形（步骤 0），让学生识别图中有哪些三角形
  2. 逐步高亮已知条件，每步停顿让学生思考该条件的几何含义
  3. 特别强调两个 90°角的位置关系：∠BAC 是大三角形的顶角，∠DAF 是跨越的角
  4. 最后引导学生计算∠FAE = ∠DAF - ∠DAE = 90° - 45° = 45°，为结论①的证明做铺垫

关键提问：

  • "图中哪些线段长度相等？"（AB=AC，AD=AF）
  • "∠FAE 等于多少度？为什么？"
  • "观察△AED 和△AEF，它们有什么关系？"

教学说明：

本图示用于证明结论①，是解题的第一个关键突破点。

证明过程：

  1. AD = AF（已知）
  2. AE = AE（公共边）
  3. ∠DAE = 45°（已知）
  4. ∠FAE = ∠DAF - ∠DAE = 90° - 45° = 45°
  5. ∴ ∠DAE = ∠FAE
  6. 由 SAS 判定：△AED ≌ △AEF
  7. ∴ DE = EF（全等三角形对应边相等）

引导要点：

  • 强调"公共边"是全等证明中常用的隐含条件
  • 角度计算∠FAE=45°是关键过渡步骤
  • 全等结论 DE=EF 将在后续结论③④的证明中直接使用

易错提醒：

学生可能忽略角度计算步骤，直接认为∠DAE=∠FAE，需强调推导过程。

步骤 0/6

教学说明：

本图示是本题的核心，展示旋转变换这一关键解题思想，并整合结论③④的证明。

旋转变换分析：

由于 AB=AC，AD=AF，∠BAC=∠DAF=90°，可将△ACD 绕点 A 逆时针旋转 90°：

  • 点 C 旋转至点 B（因为 AC=AB，旋转 90°）
  • 点 D 旋转至点 F（因为 AD=AF，旋转 90°）
  • ∴ △ACD ≌ △ABF（旋转不改变形状大小）
  • ∴ BF = DC（对应边相等）

∠EBF=90°的证明：

  1. 在等腰直角△ABC 中，∠ABC = ∠ACB = 45°
  2. 由旋转知∠ABF = ∠ACD = 45°
  3. ∴ ∠EBF = ∠ABF + ∠ABC = 45° + 45° = 90°

结论③的证明：

在△BEF 中，由三角形不等式：BE + BF > EF
又 BF = DC，EF = DE（由结论①）
∴ BE + DC > DE ✓

结论④的证明：

在 Rt△BEF 中，由勾股定理：BE² + BF² = EF²
又 BF = DC，EF = DE
∴ BE² + DC² = DE² ✓

结论②的分析：

△ABE ∽ △ACD 需要对应角相等或对应边成比例，但题目条件不足以证明这一点，故结论②不成立。

正确答案：C（①③④正确，共 3 个）

  3. 结论③④的证明依赖结论①和旋转变换，体现知识的串联
  4. 可让学生尝试用其他方法证明，培养发散思维
