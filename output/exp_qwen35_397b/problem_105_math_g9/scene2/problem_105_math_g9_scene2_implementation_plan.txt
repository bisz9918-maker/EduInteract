[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单，无需复杂库；SVG 缩放不失真，适合几何图示；原生 JS 足够实现状态切换
- 画布尺寸：800×500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +------------------------------------------+
  |  △AED≌△AEF  (顶部中央 y=30)              |
  |     SAS      (y=50)                      |
  |                                          |
  |         A(400,80)                        |
  |        / | \  \                          |
  |       /  |  \   \                        |
  |   F  /   |   \   \  D                    |
  |     /    |    \   \                      |
  |    /  ∠  |     \   \                     |
  |   /______|______\___\____                |
  |  B       E       D    C   (底边 y=380)   |
  |                                          |
  |  [标注区：AD=AF, AE=AE, 角度等动态显示]    |
  |                                          |
  |  [说明文字区 y=465]                       |
  |  [◀上一步]        [下一步▶]               |
  +------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-5），steps 数组存储每步的配置对象
  2. 每步配置包含：要显示的元素 ID 列表、要高亮的元素 ID 列表、说明文字
  3. 坐标计算：所有点坐标硬编码，确保与布局表一致
  4. 动画曲线：元素显示使用 CSS transition opacity 0.3s ease，高亮使用 stroke-width 和 stroke 颜色过渡
  5. 事件绑定：按钮点击事件切换 currentState，调用 renderStep() 更新视图
  6. 边界处理：第一步禁用"上一步"，最后一步禁用"下一步"
- ID 命名规范：
  - 所有元素 ID 以 scene2- 为前缀
  - 点：scene2-point-a, scene2-point-b, scene2-point-c, scene2-point-d, scene2-point-e, scene2-point-f
  - 线段：scene2-line-ab, scene2-line-ac, scene2-line-af, scene2-line-ad, scene2-line-ae, scene2-line-fb, scene2-line-fe, scene2-line-bc
  - 三角形填充：scene2-tri-aed, scene2-tri-aef
  - 高亮边（覆盖层）：scene2-highlight-ad, scene2-highlight-af, scene2-highlight-ae, scene2-highlight-de, scene2-highlight-ef
  - 角度弧：scene2-arc-dae, scene2-arc-fae
  - 标签：scene2-label-a, scene2-label-b, ..., scene2-label-f
  - 标注文本：scene2-anno-adaf, scene2-anno-aeae, scene2-anno-angle, scene2-anno-sas, scene2-anno-congruent, scene2-anno-deef
  - 控件：scene2-btn-prev, scene2-btn-next, scene2-status-text
- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染
- CDN：无需外部库，纯原生实现
