[技术实现]
- JS 库选择及原因：原生SVG + 原生JavaScript
  - 原因：几何图形简单，SVG原生支持路径、圆弧、变换动画；无需额外库依赖；代码轻量易维护
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |                    A                             |
  |                   /|\                            |
  |                  / | \                           |
  |                 /  |  \                          |
  |                F   |   \                         |
  |               /    |    \                        |
  |              /     |     \                       |
  |             /      |      \                      |
  |            B-------E-------D-------C             |
  |                                                  |
  |         [BF=DC]          [DE=EF]                 |
  |                                                  |
  |              [∠EBF=90°]                          |
  |                                                  |
  |    [BE+DC>DE]            [BE²+DC²=DE²]           |
  |                                                  |
  +--------------------------------------------------+
  |        [◀上一步]  步骤X/6  [下一步▶]             |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量currentState(0-6)跟踪当前步骤，数组states存储每步的可见元素ID列表
  2. 旋转动画：使用SVG transform="rotate()"配合SMIL animateTransform或JS requestAnimationFrame实现△ACD绕A点逆时针旋转90°
  3. 坐标计算：旋转后点坐标公式：x' = Ax + (x-Ax)*cosθ - (y-Ay)*sinθ, y' = Ay + (x-Ax)*sinθ + (y-Ay)*cosθ，其中θ=90°
  4. 事件绑定：按钮点击事件绑定到stepForward()/stepBackward()函数，更新currentState并调用renderState()
  5. 元素可见性：每步通过display属性控制元素显示/隐藏
- ID 命名规范：所有交互元素 ID 必须以 scene3- 为前缀
  - scene3-tri-abc（△ABC）
  - scene3-tri-acd（△ACD）
  - scene3-tri-abf（△ABF）
  - scene3-tri-adf（△ADF）
  - scene3-tri-bef（△BEF）
  - scene3-point-a/b/c/d/e/f（各点）
  - scene3-label-a/b/c/d/e/f（各标签）
  - scene3-rot-arrow（旋转箭头）
  - scene3-label-bfdc（BF=DC标注）
  - scene3-label-deef（DE=EF标注）
  - scene3-label-ebf90（∠EBF=90°标注）
  - scene3-formula-3（结论③）
  - scene3-formula-4（结论④）
  - scene3-btn-prev（上一步按钮）
  - scene3-btn-next（下一步按钮）
  - scene3-step-indicator（步骤指示器）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
