[分步序列]
- 初始状态（步骤 0）：
  - 显示△ADE（左侧）和△BCE（右侧）分离展示
  - AD 边和 BC 边用蓝色#1565c0 高亮
  - 显示标签"AD=4/5"和"BC=4"
  - 其他边为默认黑色 2px

- 步骤 1：点击「下一步」→
  - AE 边和 BE 边变为红色#c62828 高亮
  - DE 边和 CE 边变为绿色#2e7d32 高亮
  - 显示标签"AE=x"和"BE=5x"
  - 比例式框显示：AD/BC = AE/BE → (4/5)/4 = x/BE

- 步骤 2：点击「下一步」→
  - 比例式框更新为：AD/BC = AE/BE = DE/CE
  - 代入数值：(4/5)/4 = 1/5，故 AE/BE = 1/5，得 BE=5AE=5x
  - 推导框显示：∵△ADE∽△BCE（∠DAE=∠CBE，∠ADE=∠BCE）

- 步骤 3：点击「下一步」→
  - 推导框更新：∵AC=BC=4（等腰 Rt△），AE+CE=AC=4
  - 又∵CE=5DE（相似比 1:5），需建立方程
  - 关键：在△ABE 中，利用勾股定理或相似关系

- 步骤 4：点击「下一步」→
  - 推导框显示最终方程：x + CE = 4，结合比例关系解得 x=1
  - 答案框高亮显示："AE=1"，红色边框
  - 选项 C 高亮标记

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 (280,465)，80×30px，灰色背景，点击返回上一状态
  - 「下一步」按钮：位于 (440,465)，80×30px，蓝色背景，点击进入下一状态
  - 步骤指示器：显示"步骤 X/4"，位于两按钮之间
- 教师操作流程：
  1. 初始展示两个分离三角形，讲解为何△ADE∽△BCE（圆周角定理）
  2. 点击「下一步」高亮对应边，引导学生识别对应关系
  3. 继续点击展示比例式推导，强调代数代入过程
  4. 最终显示答案，验证选项 C 正确

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单，无需复杂库；SVG 便于精确控制坐标和样式；原生 JS 足够实现状态切换
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────┐
  │                                                         │
  │    △ADE                    △BCE                         │
  │     D                        C                          │
  │    / \                      / \                         │
  │   /   \                    /   \                        │
  │  A-----E                  B-----E                       │
  │  AD=4/5 BC=4              AE=x  BE=5x                   │
  │                                                         │
  │  ┌─────────────────────────────────────────────────┐   │
  │  │  比例式：AD/BC = AE/BE = DE/CE                  │   │
  │  └─────────────────────────────────────────────────┘   │
  │  ┌─────────────────────────────────────────────────┐   │
  │  │  推导步骤文本区域                               │   │
  │  └─────────────────────────────────────────────────┘   │
  │              ┌──────────┐                              │
  │              │  AE=1    │ (步骤 4 显示)                │
  │              └──────────┘                              │
  │         [◀上一步]  [下一步▶]                           │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用 currentState 变量跟踪当前步骤（0-4），数组存储每步的显示配置
  2. 坐标计算：三角形顶点坐标硬编码，确保两个三角形大小比例一致（相似比 1:5 的视觉效果）
  3. 动画曲线：边的高亮用 CSS transition，0.3s ease-in-out
  4. 事件绑定：按钮点击事件切换状态，更新 DOM 元素的 display 和 class
  5. 边界检查：第一步禁用「上一步」，最后一步禁用「下一步」
- ID 命名规范：
  - 所有元素 ID 以 scene2- 为前缀
  - 示例：scene2-tri-ade, scene2-tri-bce, scene2-line-ad, scene2-line-bc, scene2-label-ad, scene2-btn-prev, scene2-btn-next
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
