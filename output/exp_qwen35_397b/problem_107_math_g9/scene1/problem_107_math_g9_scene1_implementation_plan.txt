[图示主题与整合说明]
- 本图示主题：屋架结构中的直角三角形与中位线关系
- 整合的步骤/概念：原题图标注已知条件 → Rt△ABC中求BC → 中位线DE与BC比例关系 → 最终结论DE=2m

[分步序列]
- 初始状态（步骤0）：显示屋架完整轮廓（横梁、斜梁、所有立柱和支撑）、点标签A/B/C/D/E、直角符号（C和E处）、中点标记（D处）、屋架淡黄色填充。不显示任何数值标注和计算过程。
- 步骤1：点击「下一步」→ 显示∠A角度弧线（蓝色）和角度值"30°"（蓝色）、显示"AB=8m"标注（AB中点右上方）。计算过程区显示第一行："已知：AB=8m, ∠A=30°"。
- 步骤2：点击「下一步」→ BC立柱变为红色高亮（#c62828，线宽3px）、显示"BC=4m"标注（BC右侧红色）。计算过程区新增："在Rt△ABC中，BC = AB × sin30° = 8 × 0.5 = 4m"。
- 步骤3：点击「下一步」→ DE立柱变为蓝色高亮（#1565c0，线宽3px）、显示DE∥BC提示（虚线箭头从DE指向BC，灰色）。计算过程区新增："∵ D是AB中点，DE⊥AC，BC⊥AC ∴ DE∥BC"。
- 步骤4：点击「下一步」→ 显示"DE=2m"标注（DE左侧蓝色）、计算过程区新增："∴ DE是△ABC的中位线，DE = BC/2 = 4/2 = 2m"。答案框显示："答案：B. 2m"（蓝色文字，淡蓝色背景）。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于(320,455)，尺寸80×30px，点击后返回上一状态，步骤0时禁用
  - 「下一步 ▶」按钮：位于(420,455)，尺寸80×30px，点击后进入下一状态，步骤4时禁用
  - 步骤指示器：位于两按钮之间(410,465)，显示"步骤 X/4"
- 教师操作流程：
  1. 初始展示屋架结构，让学生观察图形特征
  2. 点击「下一步」显示已知条件∠A=30°和AB=8m
  3. 点击「下一步」高亮BC并显示计算过程，讲解30°直角三角形性质
  4. 点击「下一步」高亮DE并显示平行关系，引导学生发现中位线
  5. 点击「下一步」显示最终结论DE=2m和答案
  6. 可随时点击「上一步」回退复习关键步骤

[技术实现]
- JS 库选择及原因：原生SVG + 原生JavaScript。原因：本题为静态几何图形加简单状态切换，无需复杂动画或数据可视化，原生SVG足够且性能最优，代码简洁易维护。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |                    B(400,120)                    |
  |                     /\                           |
  |                    /  \                          |
  |              D    /    \                         |
  |           (275,235)/      \                      |
  |                  /        \                      |
  |                 /          \                     |
  |    A(150,350)--E(275,350)--C(400,350)---------   |
  |                                                  |
  |                              [计算过程区]        |
  |                              已知：AB=8m...      |
  |                                                  |
  |                              [答案框]            |
  |                                                  |
  |          [◀上一步] [步骤X/4] [下一步▶]           |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量currentStep(0-4)跟踪当前步骤，数组steps存储每步的显示配置
  2. 坐标计算：所有元素坐标硬编码，确保精确控制；D点为AB中点，E点为D在AC上的垂足
  3. 动画曲线：元素显示/高亮使用CSS transition，duration 300ms，ease-in-out
  4. 事件绑定：按钮点击事件绑定到updateStep()函数，更新currentStep并重新渲染
  5. 元素ID规范：所有交互元素ID以scene1-为前缀，如scene1-bc、scene1-de、scene1-btn-prev、scene1-btn-next
  6. IIFE隔离：所有JS代码包在(function() { ... })()中，避免全局变量污染
  7. 响应式：画布固定800×500，容器使用overflow:hidden确保不溢出
- ID 命名规范：
  - 线段：scene1-ab, scene1-bc, scene1-de, scene1-ac
  - 标签：scene1-label-a, scene1-label-b, scene1-label-c, scene1-label-d, scene1-label-e
  - 数值标注：scene1-ab-len, scene1-bc-len, scene1-de-len
  - 角度：scene1-angle-arc, scene1-angle-text
  - 直角符号：scene1-rt-c, scene1-rt-e
  - 计算区：scene1-calc-area
  - 答案框：scene1-answer-box
  - 按钮：scene1-btn-prev, scene1-btn-next, scene1-step-indicator
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中
