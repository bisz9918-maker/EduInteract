[分步序列]
- 初始状态（步骤 0）：显示基础图形——△AMN 和△BMN（所有边黑色 2px），标注点 A、B、M、N、C（C 点暂不显示标签），无角度标记，公式框显示"已知：BM 平分∠AMN，AN 平分∠BNM"
- 步骤 1：点击「下一步」→ BM 线段变为蓝色加粗 3px，在 M 点绘制∠AMB 和∠NMB 的绿色弧线标记（相同半径表示相等），公式框显示"∵ BM 平分∠AMN ∴ ∠AMB = ∠NMB"
- 步骤 2：点击「下一步」→ AN 线段变为蓝色加粗 3px，在 N 点绘制∠MNC 和∠BNC 的绿色弧线标记，公式框显示"∵ AN 平分∠BNM ∴ ∠MNC = ∠BNC"
- 步骤 3：点击「下一步」→ 在 A 点角内显示"α°"标签，公式框显示"在△AMN 中：∠A + ∠AMN + ∠ANM = 180° ⇒ ∠AMN + ∠ANM = 180° - α°"
- 步骤 4：点击「下一步」→ 在 B 点角内显示"β°"标签，公式框显示"在△BMN 中：∠B + ∠BMN + ∠BNM = 180° ⇒ ∠BMN + ∠BNM = 180° - β°"
- 步骤 5：点击「下一步」→ 高亮△MCN（MC、NC、MN 边用红色 #c62828 虚线闪烁 2 秒），公式框显示"在△MCN 中：∠MCN = 180° - (∠CMN + ∠CNM) = 180° - (∠NMB + ∠MNC)"
- 步骤 6：点击「下一步」→ 显示最终结论，公式框显示"∠MCN = 180° - ½(∠AMN + ∠BNM) = 90° + ½(∠A + ∠B)/2 = 90° + (α+β)/4"，并在下方显示"选项 C：∠MCN = (α+β)/3 + 60° ❌ 不正确"

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于 (280,450)，100×35px，点击后返回上一状态，步骤 0 时禁用
  - 「下一步 ▶」按钮：位于 (420,450)，100×35px，点击后进入下一状态，步骤 6 时禁用
  - 步骤指示器：位于两按钮之间 (390,460)，显示"步骤 X/6"
- 教师操作流程：
  1. 初始状态展示基础图形，教师介绍题目条件
  2. 点击「下一步」逐步展示角平分线性质
  3. 在步骤 3-4 讲解三角形内角和定理的应用
  4. 在步骤 5-6 引导学生推导∠MCN 表达式
  5. 可随时点击「上一步」回退复习关键步骤

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript。原因：本场景为静态几何图形分步展示，无需复杂动画或数据可视化，原生 SVG 足够且性能最优
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |           A(300,100)        B(560,120)          |
  |            /  \              /  |                |
  |           /    \            /   |                |
  |          /      \          /    |                |
  |         /   C    \        /     |                |
  |        /  (430,174)\    /      |                |
  |       /            \  /       |                |
  |      M(150,300)----N(650,300)                 |
  |                                                  |
  |  +------------------------------------------+    |
  |  | 公式推导区 (50,360)-(400,420)            |    |
  |  | 动态显示当前步骤的推导公式               |    |
  |  +------------------------------------------+    |
  |                                                  |
  |        [◀ 上一步]  步骤 X/6  [下一步 ▶]          |
  |         (280,450)          (420,450)            |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量（0-6），每个步骤对应一个状态对象，包含要显示/隐藏的元素 ID 列表
  2. 坐标计算：C 点坐标预计算为 (430,174)，角度弧线使用 SVG <path> 的 arc 命令绘制
  3. 动画曲线：步骤切换使用 CSS transition，opacity 从 0 到 1 耗时 300ms
  4. 事件绑定：按钮点击事件绑定到 stepForward() 和 stepBack() 函数
  5. 元素显隐：使用 display="none" 控制 SVG 元素显隐，按钮状态用 disabled 属性
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀
  - scene1-tri-amn（△AMN 相关元素组）
  - scene1-tri-bmn（△BMN 相关元素组）
  - scene1-line-mn（底边 MN）
  - scene1-line-bm（BM 线段）
  - scene1-line-an（AN 线段）
  - scene1-point-c（C 点）
  - scene1-label-a/b/c/m/n（点标签）
  - scene1-angle-amb/angle-nmb/angle-mnc/angle-bnc（角度弧线）
  - scene1-angle-alpha/angle-beta（α°、β°标签）
  - scene1-formula-box（公式框）
  - scene1-formula-text（公式文本）
  - scene1-btn-prev（上一步按钮）
  - scene1-btn-next（下一步按钮）
  - scene1-step-indicator（步骤指示器）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
