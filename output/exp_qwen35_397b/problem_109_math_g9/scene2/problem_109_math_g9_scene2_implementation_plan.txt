[图示主题与整合说明]
- 本图示主题：阴影部分面积等于扇形 ABA' 面积的割补法演示
- 整合内容：面积关系分析、割补转化、扇形面积计算
- 教学价值：教师通过分步演示，展示阴影面积如何通过等量代换转化为扇形面积，帮助学生理解"旋转不改变面积"和"割补法"的核心思想。步骤 0-4 逐步揭示 S_阴影 = S_扇形 ABA' 的推导过程，最终单独展示扇形便于计算。

- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-4），steps 数组存储每步的配置对象
  2. 坐标计算：A' 坐标通过旋转矩阵计算：x' = x·cosθ - y·sinθ, y' = x·sinθ + y·cosθ
  3. 扇形路径：使用 SVG path 的 A 命令绘制圆弧，M 命令移动到圆心，L 命令画半径
  4. 动画曲线：使用 CSS transition 实现淡入淡出（opacity 0→1，duration 300ms）
  5. 事件绑定：按钮点击事件切换 currentState，调用 renderStep() 更新 DOM
  6. 元素显隐：通过 display:none 或 opacity:0 控制，避免重绘闪烁

- ID 命名规范：
  - 所有元素 ID 必须以 scene2- 为前缀
  - 示例：scene2-semicircle-original, scene2-semicircle-rotated, scene2-sector-aba, scene2-label-a, scene2-label-b, scene2-label-aprime, scene2-formula-box, scene2-btn-prev, scene2-btn-next, scene2-extracted-sector
