[图示主题与整合说明]
- 本图示主题：圆台容器形状对比与液体密度分析
- 整合内容：容器正反之分、液体体积差异可视化、密度推导（ρ=m/V）
- 教学价值：教师可逐步引导学生观察两个相同圆台容器正反之放的形状差异，通过可视化液体体积对比，理解"质量相同、体积不同→密度不同"的推导过程。分步展示帮助学生建立从几何直观到物理公式的认知桥梁。

[分步序列]
- 初始状态（步骤 0）：显示两个容器轮廓、液体填充区域（蓝色半透明）、深度标注线 h、桌面、速度箭头（v 和 2v）、拉力箭头（F₁ 和 F₂）、标签 m₁=m₂、标签 ρ₁ 和 ρ₂（容器下方）、标签 V₁ 和 V₂（液面上方）
- 步骤 1：点击「下一步」→ 液体区域叠加绿色虚线网格高亮，强调体积对比；网格从透明度 0 渐变到 100%（500ms 动画）
- 步骤 2：点击「下一步」→ 在画布中上部显示体积公式框（浅绿背景），内容 "V₁ < V₂"，从透明度 0 渐变到 100%（500ms 动画）
- 步骤 3：点击「下一步」→ 在体积公式框下方显示密度结论框（浅蓝背景），内容 "ρ₁ > ρ₂"（因 m 相同，V 越小则 ρ 越大），从透明度 0 渐变到 100%（500ms 动画）
- 教师可随时点击「上一步」回退复习

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 内底部左侧 (x=300, y=455)，点击回退到前一状态
  - 「下一步」按钮：位于 SVG 内底部右侧 (x=450, y=455)，点击进入下一状态
  - 步骤指示器：位于两按钮之间 (x=380, y=460)，显示 "步骤 X/3"
- 教师操作流程：
  1. 初始状态展示题目基础条件，引导学生观察两容器形状差异
  2. 点击「下一步」高亮液体体积，提问"哪个容器液体体积更大？"
  3. 点击「下一步」显示体积公式对比，引导学生理解 V₁<V₂
  4. 点击「下一步」显示密度结论，推导 ρ₁>ρ₂（质量相同，体积越小密度越大）
  5. 可随时点击「上一步」回退复习关键步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单，无需复杂库；SVG 缩放不失真，适合几何图示；原生 JS 足够处理分步状态切换
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +----------------------------------------------------------+
  |  v→                          2v→                         |
  |  +--------+                  +--------+                  |
  |  |        |                  |  ____  |                  |
  |  |  V₁    |                  | /    \ |  V₂              |
  |  | ~~~~~~ |                  | |~~~~| |                  |
  |  | |####| |                  | |####| |                  |
  |  | |####| | h                | |####| |                  |
  |  | |####| |                  | |####| |                  |
  |  +--|##|--+                  +--|##|--+                  |
  |     |##|  F₁→                   |##|  F₂→                |
  |     |##|                        |##|                     |
  |     ρ₁                         ρ₂                       |
  |                                                          |
  |              [V₁ < V₂]  ← 步骤 2 显示                    |
  |              [ρ₁ > ρ₂]  ← 步骤 3 显示                    |
  |                                                          |
  |                    m₁ = m₂                               |
  |                                                          |
  |              [◀上一步]  步骤 X/3  [下一步▶]              |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用 currentState 变量 (0-3) 跟踪当前步骤，steps 数组存储每步的可见元素 ID 列表
  2. 坐标计算：圆台轮廓用 path 的 L 和 Q 命令绘制梯形；液体区域为容器路径的下半部分裁剪
  3. 动画曲线：CSS transition opacity 0.5s ease-in-out 实现淡入淡出
  4. 事件绑定：按钮点击事件切换状态，更新可见元素 opacity 和 display 属性
  5. 网格填充：SVG pattern 定义绿色虚线网格，步骤 1 时应用到液体区域
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀
  - scene1-container-left, scene1-container-right
  - scene1-liquid-left, scene1-liquid-right
  - scene1-grid-left, scene1-grid-right
  - scene1-depth-line, scene1-label-h
  - scene1-label-v1, scene1-label-v2
  - scene1-label-rho1, scene1-label-rho2
  - scene1-formula-box, scene1-conclusion-box
  - scene1-btn-prev, scene1-btn-next, scene1-step-indicator
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
