problem_111_math_g9

场景导航：Scene 1

题目原文：

如图，△ABC 中，AB=AC=4，∠C=72°，D 是 AB 中点，点 E 在 AC 上，DE⊥AB，则 cosA 的值为（ ）

A. (√5−1)/2 B. (√5−1)/4 C. (√5+1)/4 D. (√5+1)/2

题目分析：

本题是等腰三角形与垂直平分线综合的几何题，核心知识点包括：

  1. 等腰三角形性质：等边对等角
  2. 垂直平分线性质：垂直平分线上的点到线段两端距离相等
  3. 黄金三角形（顶角 36° 的等腰三角形）的边角关系
  4. 余弦的定义与特殊角计算

整体讲解思路：

首先引导学生从已知条件出发，利用等腰三角形性质求出∠A=36°。然后通过垂直平分线性质发现 EA=EB，进而推导出△BCE 也是等腰三角形。最终利用黄金三角形的性质或余弦定理求得 cos36°=(√5+1)/4。

图示规划说明：

设计一个整合式交互图示，通过分步导航完整展示从已知条件到最终结论的推导过程。所有几何元素在同一图中呈现，避免拆分多个相似三角形图。

本图示教学说明：

步骤 0 引导：
请学生观察图形，识别已知条件：△ABC 是等腰三角形（AB=AC），∠C=72°，DE 是 AB 的垂直平分线。

步骤 1 引导：
提问：等腰三角形的底角有什么关系？引导学生得出∠B=∠C=72°。再提问：三角形内角和是多少？如何求∠A？

推导：∠A = 180° − ∠B − ∠C = 180° − 72° − 72° = 36°

步骤 2 引导：
提问：DE 是 AB 的垂直平分线，垂直平分线上的点有什么性质？

关键点：垂直平分线上的任意一点到线段两端的距离相等，因此 EA = EB。

步骤 3 引导：
提问：△ABE 是什么三角形？（等腰三角形，因为 EA=EB）

推导：

  1. ∠ABE = ∠A = 36°（等腰三角形底角相等）
  2. ∠CBE = ∠ABC − ∠ABE = 72° − 36° = 36°
  3. ∠BEC = 180° − ∠C − ∠CBE = 180° − 72° − 36° = 72°

步骤 4 引导：
提问：△BCE 中，∠BEC = ∠C = 72°，这说明什么？

关键点：△BCE 也是等腰三角形，BE = BC。

设 AE = x，则：

  • EB = x（因为 EA = EB）
  • BC = x（因为 BE = BC）
  • EC = AC − AE = 4 − x

步骤 5 引导：
本题最终求 cosA = cos36°。36° 是黄金三角形的特征角，其余弦值为：

cos36° = (√5 + 1) / 4

因此答案为选项 C。

总结与课堂讲解建议：

完整解答：

  1. 由 AB = AC，得 ∠B = ∠C = 72°
  2. ∠A = 180° − 72° − 72° = 36°
  3. DE 是 AB 的垂直平分线 ⇒ EA = EB
  4. △ABE 中，∠ABE = ∠A = 36°
  5. ∠CBE = 72° − 36° = 36°，∠BEC = 180° − 72° − 36° = 72°
  6. △BCE 中，∠BEC = ∠C ⇒ BE = BC
  7. cosA = cos36° = (√5 + 1) / 4

答案：C

课堂讲解建议：

  1. 先让学生自主观察：给 30 秒时间让学生看图，尝试找出所有已知条件和隐含条件
  2. 分步提问引导：不要直接给出答案，通过提问让学生自己发现 EA=EB、BE=BC 等等量关系
  3. 强调垂直平分线性质的应用：这是本题的关键突破口，很多学生容易忽略
  4. 黄金三角形拓展：可以简要介绍顶角 36° 的等腰三角形是黄金三角形，其底边与腰的比为黄金分割比 (√5−1)/2
  5. 变式训练：可让学生思考如果∠C 改为其他角度，解题方法是否依然适用

易错点提醒：

  • 学生可能忘记垂直平分线的性质
  • 角度计算时容易出错，建议板书详细步骤
  • cos36° 的值需要记忆或会推导
