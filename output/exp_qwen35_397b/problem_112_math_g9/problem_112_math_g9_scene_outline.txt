    **题目原文：**

    如图，△OAB 绕点 O 逆时针旋转 70° 到△OCD，如果∠A=100°，则∠D=50°，那么∠AOD 的度数是（）
    A.20°
    B.30°
    C.40°
    D.50°

    **题目分析：**

    本题考察图形旋转的性质及三角形内角和定理。关键信息：
    1. △OAB 绕点 O 逆时针旋转 70° 得到△OCD → 旋转角为 70°
    2. 旋转前后图形全等 → △OAB ≅ △OCD
    3. 对应角相等：∠A = ∠C = 100°，∠B = ∠D = 50°

    **整体讲解思路：**

    1. 首先理解旋转的定义和性质（对应点到旋转中心的距离相等，对应角相等）
    2. 识别旋转角：点 A 旋转到点 C，点 B 旋转到点 D，故∠AOC = ∠BOD = 70°
    3. 利用三角形内角和求出∠AOB 或∠COD
    4. 通过角度差求出∠AOD

    **本图示教学说明：**

    **引导学生观察要点：**

    1. **步骤 0→1（认识旋转）：**
       - 提问：△OCD 是如何由△OAB 得到的？
       - 引导学生识别旋转中心 O、旋转方向（逆时针）、旋转角度 70°
       - 强调：旋转角是对应点与旋转中心连线的夹角，即∠AOC = ∠BOD = 70°

    2. **步骤 1→2（利用全等）：**
       - 提问：旋转前后图形有什么关系？
       - 学生回答：全等（形状大小不变）
       - 推导：△OAB ≅ △OCD → 对应角相等
       - 标注：∠A = ∠C = 100°，∠B = ∠D = 50°

    3. **步骤 2→3（角度计算）：**
       - 在△OAB 中，利用内角和：∠AOB = 180° - ∠A - ∠B = 180° - 100° - 50° = 30°
       - 观察角度关系：∠AOD = ∠BOD - ∠AOB
       - 代入计算：∠AOD = 70° - 30° = 40°

    **关键公式：**

    1. 三角形内角和：∠AOB + ∠A + ∠B = 180°
    2. 角度差关系：∠AOD = ∠BOD - ∠AOB

    **总结：**

    **完整解答：**

    1. 由旋转性质得：△OAB ≅ △OCD，旋转角∠BOD = 70°
    2. 对应角相等：∠B = ∠D = 50°
    3. 在△OAB 中：∠AOB = 180° - 100° - 50° = 30°
    4. ∠AOD = ∠BOD - ∠AOB = 70° - 30° = 40°
    5. 答案：**C. 40°**

    **课堂讲解建议：**

    - 使用分步导航时，每步停留让学生先观察思考，再揭示下一步
