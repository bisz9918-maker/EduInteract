[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于 SVG 内底部左侧 (280,455)，100×35px，灰色圆角矩形，初始禁用，步骤>0 时启用
  - 「下一步▶」按钮：位于 SVG 内底部中央 (420,455)，100×35px，蓝色圆角矩形，步骤<3 时启用，步骤=3 时禁用
  - 步骤指示器：位于右侧 (550,465)，显示"步骤 X/4"，灰色 14px 字体
- 教师操作流程：
  1. 加载图示，展示基础图形（步骤 0），教师介绍题目条件
  2. 点击「下一步」，显示旋转角 70°（步骤 1），讲解旋转变换
  3. 点击「下一步」，显示已知角度和全等推导（步骤 2），讲解△OAB≌△OCD，对应角相等
  4. 点击「下一步」，显示计算过程和结论（步骤 3），讲解∠AOD = ∠BOD - ∠AOB = 70° - 30° = 40°
  5. 可随时点击「上一步」回退复习关键步骤

[技术实现]
- JS 库选择：原生 SVG
  - 原因：几何图形（三角形、弧线、圆点）用 SVG 原生元素实现最简洁，无需额外库；弧线用<path>的 arc 命令，箭头用 marker；交互用简单状态机
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |         C●    D●                                 |
  |          \   /                                   |
  |           \ /                                    |
  |            O●─────────────●A                     |
  |             \            /                       |
  |              \          /                        |
  |               \        /                         |
  |                \      /                          |
  |                 \    /                           |
  |                  \  /                            |
  |                   ●B                             |
  |                                                  |
  |                                                  |
  |          [◀ 上一步] [下一步▶]  步骤 1/4          |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-3) 跟踪当前步骤，数组 steps[] 存储每步需显示的元素 ID 列表
  2. 坐标计算：顶点坐标硬编码（见坐标表），弧线用 SVG path 的 A 命令，箭头用<marker>
  3. 动画曲线：元素淡入用 CSS transition opacity 0.3s ease，无需复杂动画库
  4. 事件绑定：按钮 click 事件更新 currentStep，调用 updateDisplay() 刷新可见性
  5. 元素分组：用<g>按步骤分组，初始 display:none，按需切换
- ID 命名规范：所有元素 ID 以 scene1- 为前缀
  - 顶点：scene1-point-o, scene1-point-a, scene1-point-b, scene1-point-c, scene1-point-d
  - 三角形：scene1-tri-oab, scene1-tri-ocd
  - 角度弧：scene1-arc-aoc, scene1-arc-bod, scene1-arc-angle-a, scene1-arc-angle-d, scene1-arc-angle-b, scene1-arc-aob, scene1-arc-aod
  - 角度标签：scene1-label-70, scene1-label-100, scene1-label-50d, scene1-label-50b, scene1-label-30, scene1-label-40
  - 按钮：scene1-btn-prev, scene1-btn-next, scene1-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
