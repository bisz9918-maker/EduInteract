[图示主题与整合说明]
- 本图示主题：极地俯视图结构与经度差两种情况的对比
- 整合的内容：图中基本元素识别（极点 O、纬线 L、经线 OP/OQ、交点 P/Q）、经度差 30°和 60°两种情况的对比展示

[分步序列]
多状态切换模式（3 个状态）：

- 状态 0（原图）：
  - 显示：极点 O、纬线 L、经线 OP/OQ、P 点、Q 点、O/L/P/Q 标签
  - 15°E 标注显示在 Q 点下方
  - 45°标注显示在 P 点下方（黑色，不标 E/W）
  - 不显示经度差弧线和经度差数值

- 状态 1（情况 1：经度差 30°）：
  - 显示状态 0 所有元素
  - P 点经度标注变为"45°E"（红色 #c62828）
  - 新增经度差弧线：蓝色圆弧，圆心(400,80), 半径 260, 从 P 到 Q
  - 新增经度差数值"30°"：蓝色文字，位于(400, 380)

- 状态 2（情况 2：经度差 60°）：
  - 显示状态 0 所有元素
  - P 点经度标注变为"45°W"（红色 #c62828）
  - 新增经度差弧线：蓝色圆弧，圆心(400,80), 半径 260, 从 P 到 Q（跨度更大）
  - 新增经度差数值"60°"：蓝色文字，位于(400, 380)

[交互方案]
- 交互类型：多状态切换（3 个按钮）
- 控件说明：
  - 按钮 1「原图」：位置 (220, 455)，显示题目原始图形，无经度差标注
  - 按钮 2「情况 1：经度差 30°」：位置 (340, 455)，P 为 45°E，显示 30°弧线标注
  - 按钮 3「情况 2：经度差 60°」：位置 (480, 455)，P 为 45°W，显示 60°弧线标注
- 教师操作流程：
  1. 初始加载显示原图，教师讲解极地俯视图基本结构（极点、纬线、经线）
  2. 点击「情况 1：经度差 30°」，展示 P 为 45°E 时的情形，讲解同在东半球、经度差计算
  3. 点击「情况 2：经度差 60°」，展示 P 为 45°W 时的情形，讲解东西半球判断
  4. 可随时点击任一按钮回退或对比两种情况

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +------------------------------------------+
  |                  O                       |  y=80
  |                 / \                      |
  |                /   \                     |
  |           P   /     \   Q               |  y=320
  |          45°  ~~~~~~~  15°E             |  y=355
  |              L   30°/60°                |  y=380
  |                                          |
  |                                          |
  |    [原图]  [情况 1]  [情况 2]            |  y=455
  +------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0/1/2），点击按钮时更新状态并重绘
  2. 坐标计算：经线端点 P/Q 使用极坐标转换（角度 120°/240°，半径 220）
  3. 圆弧绘制：使用 SVG path 的 A 命令绘制纬线和经度差弧线
  4. 事件绑定：三个按钮分别绑定 click 事件，调用 setState() 函数
  5. 元素显示/隐藏：使用 display 属性或 opacity 控制不同状态下的元素可见性
- ID 命名规范：所有元素 ID 以 scene1- 为前缀
  - scene1-pole-o, scene1-label-o, scene1-arc-l, scene1-label-l
  - scene1-line-op, scene1-line-oq, scene1-point-p, scene1-point-q
  - scene1-label-p, scene1-label-q, scene1-lon-q, scene1-lon-p
  - scene1-arc-diff, scene1-label-diff
  - scene1-btn-state0, scene1-btn-state1, scene1-btn-state2
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
