[图示主题与整合说明]
- 本图示主题：东西半球划分与 P、Q 位置关系判断
- 整合的内容：东西半球分界线（20°W、160°E）的展示、两种经度差情况下 P、Q 所在半球的判断、推理链条的逐步呈现

[视觉元素清单]
- 极点 O：黑色实心圆 r=5，位于 (400,80)，标签"O"位于 (400,65) 上方
- 纬线 L：黑色弧线，线宽 2，从角度 120° 到 240°，半径 170，标签"L"位于 (280,260) 左侧
- 经线 OP、OQ：黑色实线，线宽 1.5，从极点 O 辐射到 P、Q
- P 点：蓝色 #1565c0 实心圆 r=6，位置随步骤变化

- 东半球填充：#2e7d32 透明度 20%
- 西半球填充：#c62828 透明度 20%
- 结论文字框：白色背景，黑色边框，黑色文字
- 颜色规格沿用 scene_outline 中的配色规则

[分步序列]
步骤 0（初始状态）：显示东西半球分界线示意
- 显示：极点 O、纬线 L、两条经线（灰色淡化）
- 显示：20°W 和 160°E 分界线（绿色虚线）
- 显示：东半球区域（浅绿色填充）、西半球区域（浅红色填充）
- 显示：东半球、西半球标签
- 隐藏：P 点、Q 点、经度数值标签
- 结论文字框：显示"东西半球划分：20°W 向东到 160°E 为东半球"

步骤 1：情况 1（经度差 30°）— P、Q 位置
- 高亮：经线 OP、OQ（黑色加粗）
- 显示：P 点 (320,280)、Q 点 (480,280)
- 显示：P 点经度标签"45°E"（左侧）、Q 点经度标签"15°E"（右侧）
- 结论文字框：显示"情况 1：经度差 30°，P 为 45°E，Q 为 15°E"

步骤 2：情况 1 结论
- 保持步骤 1 所有元素
- 高亮：P、Q 所在区域（东半球区域边框加粗）
- 结论文字框：显示"结论：P、Q 都位于东半球（15°E 和 45°E 都在 20°W~160°E 范围内）"

步骤 3：情况 2（经度差 60°）— P、Q 位置
- 更新：P 点位置移动到 (280,290)，经度标签改为"45°W"
- Q 点保持不变 (480,280)，标签"15°E"
- 结论文字框：显示"情况 2：经度差 60°，P 为 45°W，Q 为 15°E"

步骤 4：情况 2 结论
- 保持步骤 3 所有元素
- 高亮：P 点所在西半球区域（红色边框）、Q 点所在东半球区域（绿色边框）
- 结论文字框：显示"结论：P 位于西半球（45°W），Q 位于东半球（15°E），P 在 Q 的正西方"

[交互方案]
- 交互类型：分步按钮导航
- 控件说明：
  - 「◀ 上一步」按钮：位于 (280,455)，点击后切换到前一步骤（步骤 0 时禁用）
  - 「下一步 ▶」按钮：位于 (440,455)，点击后切换到下一步骤（步骤 4 时禁用）
  - 步骤指示器：位于 (400,455)，显示当前步骤编号"步骤 X/4"
- 教师操作流程：
  1. 初始展示东西半球划分规则（步骤 0）
  2. 点击「下一步」展示情况 1 的 P、Q 位置（步骤 1）
  3. 点击「下一步」展示情况 1 结论（步骤 2）
  4. 点击「下一步」展示情况 2 的 P、Q 位置（步骤 3）
  5. 点击「下一步」展示情况 2 结论（步骤 4）
  6. 可随时点击「上一步」回退复习

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单，无需复杂库；原生 SVG 便于精确控制坐标和样式
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +------------------------------------------+
  |              O (极点)                    |
  |           /     \                        |
  |      P  /         \  Q                   |
  |        /    纬线 L  \                    |
  |       /_____________\                    |
  |                                          |
  |   [西半球]          [东半球]             |
  |                                          |
  |   [结论文字框]                           |
  |                                          |
  |      [◀上一步] [步骤 X/4] [下一步▶]      |
  +------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-4) 跟踪当前步骤
  2. 所有元素用 scene2- 前缀命名（如 scene2-pole、scene2-point-p）
  3. 每个步骤对应一个 updateScene() 函数，根据 currentStep 显示/隐藏元素
  4. 按钮点击事件绑定，更新 currentStep 后调用 updateScene()
  5. 步骤 0 时禁用「上一步」，步骤 4 时禁用「下一步」
  6. P 点位置在步骤 3 需要动画过渡（从 45°E 移动到 45°W 位置）
  7. 所有 JS 代码包在 IIFE 中：(function() { ... })()
- ID 命名规范：
  - scene2-pole（极点 O）
  - scene2-arc-l（纬线 L）
  - scene2-line-op（经线 OP）
  - scene2-line-oq（经线 OQ）
  - scene2-point-p（P 点）
  - scene2-point-q（Q 点）
  - scene2-div-20w（20°W 分界线）
  - scene2-div-160e（160°E 分界线）
  - scene2-zone-east（东半球区域）
  - scene2-zone-west（西半球区域）
  - scene2-label-p-lon（P 点经度标签）
  - scene2-label-q-lon（Q 点经度标签）
  - scene2-conclusion-box（结论文字框）
  - scene2-btn-prev（上一步按钮）
  - scene2-btn-next（下一步按钮）
  - scene2-step-indicator（步骤指示器）
