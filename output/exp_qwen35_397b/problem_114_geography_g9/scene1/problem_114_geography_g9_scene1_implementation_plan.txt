[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript。理由：几何图形简单（圆、线段、弧线），无需复杂库；原生实现轻量、加载快、易于多场景合并
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  [北半球俯视图]           [南半球俯视图]         |
  |       左图(240,220)         右图(560,220)        |
  |    ↺逆时针    A●         B●    顺时针↻          |
  |      北逆                      南顺              |
  |        180°                    180°              |
  |         |                       |                |
  |    -----+-----             -----+-----           |
  |         |                       |                |
  |         0°                      0°               |
  |                                                  |
  |  [上一步]   步骤 X/4   [下一步]                  |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-4) 跟踪当前步骤，steps 数组存储每步的显示配置
  2. 坐标计算：左图中心(240,220)，右图中心(560,220)，经线角度用 Math.cos/sin 计算
  3. 动画曲线：元素显示用 opacity 过渡 0.3s ease-out，高亮用 stroke-width 过渡
  4. 事件绑定：按钮点击事件绑定到 stepForward/stepBackward 函数
  5. 元素显隐：用 display:none 或 opacity:0 控制，高亮用 class 切换
- ID 命名规范：所有元素 ID 以 scene1- 为前缀，如 scene1-left-circle、scene1-right-circle、scene1-point-a、scene1-point-b、scene1-arrow-left、scene1-arrow-right、scene1-btn-prev、scene1-btn-next、scene1-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
