[图示主题与整合说明]
- 本图示主题：太阳直射点移动规律与 A、B 点直射次数判断
- 整合的内容：太阳直射点周年移动轨迹、回归线位置、A 点直射次数、B 点直射次数
- 教学价值：教师通过拖动日期滑块，让学生直观观察太阳直射点在南北回归线之间的周年移动，理解为什么赤道与回归线之间的地区一年有两次直射，回归线上一年只有一次直射，回归线以外无直射。配合 A、B 两点的纬度位置，学生可以判断各点的直射次数。

[分步序列]
本场景采用连续拖拽滑块交互，无固定步骤，但有以下关键状态：
- 初始状态（滑块在春分位置）：直射点位于赤道(y=225)，计数器均为 0
- 状态 1（拖到夏至）：直射点移动到北回归线(y=165)，若经过 A 点纬度则 A 计数器+1
- 状态 2（拖到秋分）：直射点回到赤道(y=225)
- 状态 3（拖到冬至）：直射点移动到南回归线(y=285)，若经过 B 点纬度则 B 计数器+1
- 状态 4（拖回春分）：直射点回到赤道(y=225)，完成一个周年循环

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：
  - 日期滑块轨道：位于 y=400~420，x=150~650，表示一年 365 天
  - 滑块手柄：可左右拖拽，x 范围 150~650，对应春分→夏至→秋分→冬至→春分
  - 当前日期显示：位于(400,370)，实时显示滑块对应的日期和节气
  - 直射次数计数器：位于右侧统计区，实时累加直射次数
- 教师操作流程：
  1. 初始状态展示地球侧视图和 A、B 两点位置
  2. 拖动滑块从春分开始，观察直射点向北移动
  3. 当直射点经过 A 点纬度时，高亮 A 点，计数器+1
  4. 继续拖到夏至，直射点到达北回归线
  5. 拖动滑块向南，直射点再次经过 A 点，计数器再+1
  6. 经过赤道到南半球，当经过 B 点纬度时高亮 B 点，计数器+1
  7. 到冬至后返回，再次经过 B 点，计数器再+1
  8. 总结：A、B 两点都在回归线与赤道之间，一年各有两次直射

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单，无需复杂库；拖拽交互用原生事件即可实现
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  [地球侧视图]           [直射次数统计]           |
  |     北回归线 23.5°N  ┌─────────────────┐         |
  |     赤道 0°   ------│ A 点已直射：X 次 │         |
  |     南回归线 23.5°S │ B 点已直射：X 次 │         |
  |                        └─────────────────┘         |
  |                                                    |
  |           当前日期：X 月 X 日 节气                  |
  |  [══════════════════════════════════════]          |
  |  春分    夏至        秋分        冬至    春分       |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用单个变量 sliderPosition (0~1) 表示滑块位置，0=春分，0.25=夏至，0.5=秋分，0.75=冬至，1=春分
  2. 坐标计算：直射点 y 坐标 = 225 + 60 * sin(sliderPosition * 2 * π - π/2)，实现正弦运动
  3. 直射次数累加：记录上次直射点位置，当穿越 A/B 点纬度时计数器+1
  4. 事件绑定：mousedown/mousemove/mouseup 实现拖拽，touch 事件支持移动端
  5. 高亮效果：当直射点与 A/B 点纬度差<5px 时，对应点放大并改变颜色
- ID 命名规范：所有交互元素 ID 以 scene2- 为前缀
  - scene2-earth-ellipse
  - scene2-equator-line
  - scene2-tropic-north
  - scene2-tropic-south
  - scene2-point-a
  - scene2-point-b
  - scene2-sun-point
  - scene2-sun-ray
  - scene2-label-0
  - scene2-label-23n
  - scene2-label-23s
  - scene2-label-a-lat
  - scene2-label-b-lat
  - scene2-slider-track
  - scene2-slider-handle

  - scene2-counter-a

- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
