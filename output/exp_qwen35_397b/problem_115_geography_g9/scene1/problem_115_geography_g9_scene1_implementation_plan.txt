[图示主题与整合说明]
- 本图示主题：经纬网坐标读取与点位识别
- 整合的内容：图中 6 个点的坐标标注、经纬线度数标识、方向指示
- 教学价值：教师可使用此图示逐步展示经纬网结构，引导学生依次读取各点坐标，理解经纬度定位原理，掌握东西半球、南北半球的判断方法。通过分步高亮，学生可聚焦单个点位，避免信息过载。

[视觉元素清单]
- 经线：4 条黑色实线，线宽 4px，位置见坐标表
- 纬线：4 条线，赤道为实线 4px，其余为虚线 2px，颜色#000000
- 标注点：6 个黑色实心圆，半径 6px，初始显示
- 点标签：6 个汉字/字母标签，黑色#000000，14px 字体
- 经度标注：4 个，位于对应经线正下方 y=385
- 纬度标注：4 个，位于对应纬线右侧 x=570，带 N/S 标识
- 高亮效果：选中点变为蓝色#1565c0，半径扩大至 10px，带半透明蓝色填充圆（r=15，透明度 20%）
- 方向箭头：4 个绿色#2e7d32 箭头，步骤 6 显示
- 坐标显示区：显示当前步骤高亮的点及其经纬度坐标

[分步序列]
- 步骤 0（初始状态）：显示基础经纬网（4 条经线、4 条纬线）、6 个标注点（黑色）、所有点标签（甲乙丙丁 EF）、经度标注（底部）、纬度标注（右侧）。坐标显示区显示"请选择下一步查看点位坐标"
- 步骤 1：高亮甲点（蓝色填充圆 + 蓝色边框），坐标显示区更新为"甲：(0°, 66.5°N)"
- 步骤 2：取消甲高亮，高亮乙点，坐标显示区更新为"乙：(20°W, 23.5°N)"
- 步骤 3：取消乙高亮，高亮丙点，坐标显示区更新为"丙：(0°, 0°)"
- 步骤 4：取消丙高亮，高亮丁点，坐标显示区更新为"丁：(20°E, 23.5°S)"
- 步骤 5：取消丁高亮，高亮 E 点和 F 点，坐标显示区更新为"E：(20°E, 0°)  F：(40°E, 66.5°N)"
- 步骤 6：保持 E、F 高亮，显示 4 个方向箭头（北南东西）及对应文字标签，坐标显示区更新为"方向指示：上北下南，左西右东"

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - "上一步"按钮：位于 (280,455)，返回上一状态
  - "下一步"按钮：位于 (450,455)，进入下一状态
  - 步骤指示器：位于 (380,455)，显示"步骤 X/6"
- 教师操作流程：
  1. 初始展示完整经纬网，让学生观察整体结构
  2. 点击"下一步"，依次高亮各点，引导学生读取坐标
  3. 每高亮一个点，提问学生该点的经纬度
  4. 最后展示方向指示，讲解方向判断规则
  5. 可随时点击"上一步"回退复习

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（直线、圆点、文字），无需复杂库；原生实现轻量、加载快
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                    纬线标注区                      |
  |   西←    经纬网主图区 (150,50)-(550,350)    →东   |
  |                    纬线标注区                      |
  |                    经度标注区                      |
  |              [坐标显示区]                          |
  |         [◀上一步] [步骤 X/6] [下一步▶]             |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-6) 跟踪当前步骤
  2. 高亮实现：每个点有基础圆（黑色）和高亮圆（蓝色，初始 display:none），切换时控制显示
  3. 坐标显示：用 textContent 动态更新坐标显示区文本
  4. 方向箭头：步骤 6 时才显示，初始 display:none
  5. 按钮边界处理：步骤 0 时禁用"上一步"，步骤 6 时禁用"下一步"
- ID 命名规范：
  - 所有元素 ID 以 scene1- 为前缀
  - 经线：scene1-meridian-20W, scene1-meridian-0, scene1-meridian-20E, scene1-meridian-40E
  - 纬线：scene1-parallel-665N, scene1-parallel-235N, scene1-parallel-0, scene1-parallel-235S
  - 点：scene1-point-jia, scene1-point-yi, scene1-point-bing, scene1-point-ding, scene1-point-E, scene1-point-F
  - 点标签：scene1-label-jia, scene1-label-yi, ...
  - 高亮圆：scene1-highlight-jia, scene1-highlight-yi, ...
  - 经度标注：scene1-lon-20W, scene1-lon-0, ...
  - 纬度标注：scene1-lat-665N, scene1-lat-235N, ...
  - 方向箭头：scene1-arrow-N, scene1-arrow-S, scene1-arrow-E, scene1-arrow-W
  - 坐标显示区：scene1-coord-display
  - 按钮：scene1-btn-prev, scene1-btn-next
  - 步骤指示器：scene1-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
