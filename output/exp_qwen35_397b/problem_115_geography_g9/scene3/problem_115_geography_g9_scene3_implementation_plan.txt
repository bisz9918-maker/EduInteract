[图示主题与整合说明]
- 本图示主题：东西半球划分与五带范围
- 整合的步骤/概念：东西半球分界线（20°W 和 160°E）、五带划分（热带、南北温带、南北寒带）、图中各点的位置判断
- 教学价值：教师可逐步展示半球分界线和五带范围，引导学生理解"东部是东半球、西部是西半球、北部四季变化明显、南部有太阳直射现象"这一综合条件，最终定位到乙点。通过颜色填充和分步高亮，帮助学生建立空间概念和条件推理能力。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮：位于 (60,450)，灰色背景，点击返回上一状态
  - 下一步按钮：位于 (180,450)，蓝色背景，点击进入下一状态
  - 步骤指示器：位于 (280,460)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始状态展示基础经纬网和 6 个点，让学生观察各点位置
  2. 点击「下一步」展示东西半球分界线，讲解 20°W 和 160°E 的意义
  3. 点击「下一步」展示热带范围，讲解太阳直射现象
  4. 点击「下一步」展示北温带范围，讲解四季变化
  5. 点击「下一步」展示综合判断条件，引导学生推理
  6. 点击「下一步」显示答案，验证学生判断

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  纬度标签                                        |
  |  66.5° ─────────────────────────────────────     |
  |        │    甲           F   │                   |
  |  23.5° ─┼─乙─────────────────┼──────  热带 (黄)   |
  |    0° ──┼────丙──────E───────┼──────  赤道       |
  |  23.5° ─┼───────────丁───────┼──────  热带 (黄)   |
  |        │                     │                   |
  |       20°  0°   20°   40°    │                   |
  |                                                  |
  |  [条件说明框]  [答案框]                          |
  |                                                  |
  |  [◀上一步] [下一步▶]  步骤 X/5                   |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用 currentState 变量跟踪当前步骤（0-5），数组存储各状态配置
  2. 坐标计算：经纬线位置固定，填充区域根据步骤动态显示/隐藏
  3. 动画曲线：填充区域使用 fade-in 效果（opacity 0→1，300ms）
  4. 事件绑定：按钮点击事件绑定到 stateTransition 函数
  5. 元素显隐：各步骤元素用 display/opacity 控制，避免重绘
- ID 命名规范：所有元素 ID 以 scene3- 为前缀（如 scene3-point-yi, scene3-tropic-zone）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
