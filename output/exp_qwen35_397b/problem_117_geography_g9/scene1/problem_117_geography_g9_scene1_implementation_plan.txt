[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 (280,455)，宽 100px，高 35px，浅灰色背景 #e0e0e0
  - 「下一步」按钮：位于 (420,455)，宽 100px，高 35px，蓝色背景 #1565c0，白色文字
  - 步骤指示器：位于 (380,465)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始展示网格框架，让学生观察甲乙两点位置
  2. 点击「下一步」逐步显示经度标注，引导学生发现左图经度递减（西经）、右图经度递增（东经）
  3. 继续点击显示纬度标注，引导学生发现左图纬度向下递增（南纬）、右图纬度向下递减（北纬）
  4. 最后显示完整坐标，让学生总结甲乙两地的经纬度

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何网格和标注简单，无需复杂库；原生 SVG 便于精确控制坐标和样式
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  甲地 (55)                    乙地 (55)          |
  |  +----------------+    +----------------+        |
  |  |  50°  40°  30° |    |  30°  40°  50° |        |
  |  |  W    W    W   |    |  E    E    E   |        |
  |20°|  ┌──┬──┬──┐  |    |  ┌──┬──┬──┐  | 40°     |
  |S  |  │  │  │  │  |    |  │  │  │  │  | N       |
  |30°|──┼──●──┼──│  |    |──┼──●──┼──│  | 30°     |
  |S  |  │甲 │  │  |    |  │乙 │  │  | N       |
  |40°|  └──┴──┴──┘  |    |  └──┴──┴──┘  | 20°     |
  |S  |              |    |              | N       |
  |  +----------------+    +----------------+        |
  |     西经 W 递减→        东经 E 递增→             |
  |                                                  |
  |              [◀上一步]  [下一步▶]                |
  |                   步骤 1/5                       |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-5) 跟踪当前步骤，数组 steps 存储每步需显示的元素 ID 列表
  2. 坐标计算：网格线位置通过基础坐标 + 偏移量计算，确保左右图对称
  3. 动画曲线：元素显示使用 CSS transition opacity 0.3s ease-in-out
  4. 事件绑定：按钮点击事件绑定到 stepChange 函数，更新 currentStep 并刷新显示状态
  5. 边界处理：步骤 0 时禁用「上一步」，步骤 5 时禁用「下一步」
- ID 命名规范：所有元素 ID 以 scene1- 为前缀
  - 例如：scene1-left-grid, scene1-right-grid, scene1-point-jia, scene1-point-yi
  - 经度标注：scene1-left-lon-50w, scene1-right-lon-40e 等
  - 纬度标注：scene1-left-lat-30s, scene1-right-lat-30n 等
  - 坐标标签：scene1-jia-coord, scene1-yi-coord
  - 按钮：scene1-btn-prev, scene1-btn-next, scene1-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
