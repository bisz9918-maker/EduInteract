[分步序列]
- 初始状态（步骤 0）：显示基础电路
  - 显示所有元件：电源、开关 S、R₁、R₂、电流表 A、电压表 V₁、电压表 V₂
  - 显示所有标签：R₁、R₂、P、S、A、V₁、V₂
  - 导线为黑色实线 2px
  - 等待教师点击「下一步」

- 步骤 1：高亮 R₁与 R₂串联关系
  - 在步骤 0 基础上，用蓝色 (#1565c0) 加粗 3px 高亮显示 R₁和 R₂所在的串联路径
  - 高亮段：左竖导线 (100,100)-(100,350)、R₁电阻、顶横导线左段 (100,100)-(250,100)、R₂变阻器
  - 新增标签"串联"在 (150,200)，蓝色

- 步骤 2：高亮电流表 A 测量总电流
  - 保持步骤 1 的串联高亮
  - 用蓝色 (#1565c0) 加粗 3px 高亮整个电流回路路径
  - 在电流表 A 右侧显示标签"I"表示电流
  - 新增标签"总电流"在 (650,120)，蓝色

- 步骤 3：高亮 V₁测量 R₂电压
  - 保持步骤 2 的电流路径高亮
  - 用蓝色虚线框 (#1565c0, 虚线 2px) 框出 V₁与 R₂的并联关系
  - 虚线框范围：(240,70)-(560,130)
  - 在 V₁附近显示标签"U₁"表示测量电压
  - 新增标签"测 R₂电压"在 (400,150)，蓝色

- 步骤 4：高亮 V₂测量电源电压
  - 保持步骤 3 的 V₁高亮框
  - 用绿色虚线框 (#2e7d32, 虚线 2px) 框出 V₂与电源的并联关系
  - 虚线框范围：(90,370)-(630,430)
  - 在 V₂附近显示标签"U₂"表示测量电压
  - 新增标签"测电源电压"在 (400,440)，绿色

- 步骤 5：标注滑片 P 左移方向
  - 保持步骤 4 的所有高亮
  - 在滑片 P 上方显示红色向左箭头 (350,60)-(380,60)
  - 箭头颜色 #c62828，线宽 3px
  - 新增标签"左移"在 (365,45)，红色
  - 展示所有结论，完成电路分析

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 内底部左侧 (50,450)，点击回退到上一状态
  - 「下一步」按钮：位于 SVG 内底部右侧 (700,450)，点击进入下一状态
  - 步骤指示器：位于底部中央 (400,450)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始状态展示基础电路，让学生识别各元件
  2. 点击「下一步」高亮串联路径，讲解 R₁与 R₂的串联关系
  3. 点击「下一步」高亮电流路径，讲解电流表测量总电流
  4. 点击「下一步」高亮 V₁并联范围，讲解 V₁测量 R₂电压
  5. 点击「下一步」高亮 V₂并联范围，讲解 V₂测量电源电压
  6. 点击「下一步」显示滑片移动方向，分析动态电路变化

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript
  - 电路图是静态几何图形，原生 SVG 足够实现
  - 无需复杂动画库，分步状态切换用 CSS class 控制即可
  - 轻量级，加载快，兼容性好

- 画布尺寸：800 × 500 px（固定）

- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                    V₁                            |
  |                   (V₁)                           |
  |                    |                             |
  |     +--------------+--------------+              |
  |     |                             |              |
  |     |    P ← 左移                 |     A        |
  |     |    ↓                        |    (A)       |
  |     +----[====R₂====]-------------+              |
  |     |                             |              |
  |  R₁ |                             |              |
  |  [  ]                             |              |
  |  [  ]                             |              |
  |     |                             |              |
  |     |         + -                 |              |
  |     |        [电源]----S          |              |
  |     |                             |              |
  |     +-----------------------------+              |
  |                    |                             |
  |                   (V₂)                           |
  |                    V₂                            |
  |                                                  |
  |     [◀上一步]    步骤 1/5    [下一步▶]           |
  +--------------------------------------------------+
  [控件栏在 SVG 内底部 y=440~490 区域]
  ```

- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-5) 跟踪当前步骤，数组 steps 存储每步的显示配置
  2. 坐标计算：所有元件位置硬编码，确保精确对齐
  3. 动画曲线：步骤切换用 CSS transition，duration 300ms，ease-in-out
  4. 事件绑定：按钮点击事件绑定到 stepChange 函数，更新 currentStep 并重新渲染
  5. 高亮实现：用 CSS class 控制 stroke-width 和 stroke 颜色，虚线框用 stroke-dasharray

- ID 命名规范：
  - 所有交互元素 ID 必须以 scene1- 为前缀
  - 示例：scene1-power、scene1-switch、scene1-r1、scene1-r2、scene1-slider-p、scene1-ammeter-a、scene1-voltmeter-v1、scene1-voltmeter-v2、scene1-wire-left、scene1-wire-top、scene1-wire-right、scene1-wire-bottom、scene1-highlight-series、scene1-highlight-current、scene1-highlight-v1、scene1-highlight-v2、scene1-arrow-left、scene1-btn-prev、scene1-btn-next、scene1-step-indicator

- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
