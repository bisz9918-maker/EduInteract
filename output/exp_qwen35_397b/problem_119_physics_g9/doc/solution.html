problem_119_physics_g9

场景导航：Scene 1 | Scene 2

题目原文：

如图所示的电路中，闭合开关 S，当滑动变阻器的滑片 P 向右滑动时（ ）

A、灯 L₁ 变亮，灯 L₂ 变暗
B、灯 L₂ 变亮，灯 L₁ 亮度不变
C、灯 L₁ 和 L₂ 均变暗
D、灯 L₁ 亮度变化，灯 L₂ 亮度不变

题目分析：

本题考查并联电路的特点及滑动变阻器对支路电流的影响。

电路结构：

  1. 灯 L₁ 单独构成一条支路，直接并联在电源两端
  2. 滑动变阻器与灯 L₂ 串联后构成另一条支路
  3. 两条支路并联，开关 S 在干路控制整个电路

解题思路：

  1. 分析 L₁ 支路：L₁ 两端电压始终等于电源电压，与滑动变阻器无关，故 L₁ 亮度不变
  2. 分析 L₂ 支路：滑片 P 向右滑动时，滑动变阻器接入电阻减小，该支路总电阻减小，电流增大，故 L₂ 变亮
  3. 结论：选 B

图示规划说明：
本规划包含 2 个图示场景：

  • SCENE_1：完整电路图，展示电路结构和电流路径，通过分步高亮帮助学生理解并联关系
  • SCENE_2：滑动变阻器细节图，展示滑片移动时电阻变化及对支路电流的影响

SCENE_1 教学说明：

本图示用于帮助学生建立电路的整体认知框架。

引导步骤：

  1. 首先让学生观察原始电路图，识别各元件及其连接方式
  2. 点击「下一步」高亮 L₁ 支路，引导学生发现 L₁ 直接接在电源两端，电压恒等于电源电压 U
  3. 继续点击高亮 L₂ 支路，说明滑动变阻器与 L₂ 串联，滑片移动会改变该支路电阻
  4. 最后展示结论，用视觉亮度变化强化理解

关键公式：

  • L₁ 支路：$U_1 = U$（电源电压），$P_1 = \frac{U_1^2}{R_1}$，故亮度不变
  • L₂ 支路：$R_{总} = R_{变} + R_{L2}$，滑片右移 $R_{变} \downarrow$，故 $I_2 = \frac{U}{R_{总}} \uparrow$，$P_2 = I_2^2 R_{L2} \uparrow$，亮度变亮

SCENE_2 教学说明：

本图示用于深化学生对滑动变阻器工作原理的理解，建立「滑片位置→接入电阻→支路电流→灯泡亮度」的完整因果链。

引导要点：

  1. 让学生拖动滑块，观察接入电阻丝长度的变化
  2. 引导学生发现：滑片右移→接入长度变短→电阻变小
  3. 结合欧姆定律 $I = \frac{U}{R}$，说明电压不变时电阻减小则电流增大
  4. 观察 L₂ 亮度变化，建立电流与功率的关系 $P = I^2 R$

易错点提醒：

  • 滑动变阻器只有接入电路的部分才起作用
  • 并联电路各支路互不影响（L₁ 支路不受滑动变阻器影响）
  • 灯泡亮度由实际功率决定，不是由电压或电流单独决定

总结与课堂讲解建议：

完整解答：

当滑片 P 向右滑动时：

  • L₁ 支路：两端电压始终等于电源电压，电阻不变，故电流不变，亮度不变
  • L₂ 支路：滑动变阻器接入电阻减小，支路总电阻减小，电流增大，故 L₂ 变亮

答案：B

课堂讲解建议：

  1. 先用 SCENE_1 建立电路整体认知，强调并联电路「各支路独立工作」的特点
  2. 再用 SCENE_2 深入分析滑动变阻器的作用机制，让学生动手拖动滑块观察变化
  3. 最后引导学生用公式推导验证直观观察的结论，培养「定性分析 + 定量计算」的双重能力
  4. 可拓展提问：若滑片向左滑动会怎样？若 L₁ 支路也串联一个电阻会怎样？
