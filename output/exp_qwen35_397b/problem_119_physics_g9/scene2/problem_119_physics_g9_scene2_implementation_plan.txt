[图示主题与整合说明]
- 本图示主题：滑动变阻器电阻变化与支路电流关系
- 整合内容：滑动变阻器结构细节、滑片位置与接入电阻的对应关系、电阻变化引起电流变化的动态演示
- 教学价值：教师可通过拖动滑片 P，让学生直观观察滑动变阻器接入电路的电阻丝长度变化，理解电阻与长度的正比关系，同时观察 L₂ 支路电流变化和灯泡亮度变化，建立"滑片位置→接入电阻→支路电流→灯泡亮度"的完整因果链。L₁ 支路不受影响（并联电路各支路独立），可对比理解。

[分步序列]
本场景为连续拖拽交互，无分步导航，定义以下关键状态：

- 初始状态（滑片 P 在最左端，x=100）：
  - 接入电阻最大：R = 20Ω（全长度接入）
  - L₂ 支路电流最小：I₂ = 0.15A
  - L₂ 灯泡较暗（发光强度 30%）
  - 接入部分高亮线段最长（从 x=100 到 x=380）
  - 未接入部分为虚线（长度≈0）

- 中间状态（滑片 P 在中点，x=240）：
  - 接入电阻中等：R = 10Ω
  - L₂ 支路电流中等：I₂ = 0.30A
  - L₂ 灯泡中等亮度（发光强度 60%）
  - 接入部分高亮线段中等长度（从 x=240 到 x=380）

- 最终状态（滑片 P 在最右端，x=370）：
  - 接入电阻最小：R = 0Ω（近似）
  - L₂ 支路电流最大：I₂ = 0.60A
  - L₂ 灯泡最亮（发光强度 100%）
  - 接入部分高亮线段最短（从 x=370 到 x=380）
  - 未接入部分虚线最长

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：
  - 底部水平滑块轨道：x=100 到 x=700，y=460
  - 滑块手柄：圆形，可左右拖拽，x 范围 100-370（与变阻器滑片同步）
  - 滑片 P：与滑块手柄联动，同步移动
- 教师操作流程：
  1. 初始状态展示电路，讲解并联电路特点（L₁、L₂ 独立支路）
  2. 拖动滑片 P 向右，引导学生观察：
     - 接入电阻丝长度变短 → R 减小
     - L₂ 支路电流 I₂ 增大（电流表读数变化）
     - L₂ 灯泡变亮（发光效果增强）
  3. 强调 L₁ 亮度不变（并联电路各支路电压相等，L₁ 支路电阻不变）
  4. 拖动滑片 P 向左，反向验证
  5. 总结：滑片右移→R 减小→I₂ 增大→L₂ 变亮，答案选 A（L₁ 不变，L₂ 变亮）

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单，无需复杂库；拖拽交互用原生事件即可实现；SVG 便于动态更新线段长度和发光效果
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |   [滑动变阻器]              [L₂] [A]             |
  |   ==========P============>   ( )  (A)            |
  |      R=20Ω                   L₂   I₂=0.15A       |
  |                                                  |
  |                                                  |
  |              拖动滑片 P                          |
  |   O========================================O     |
  |  100                                      700    |
  +--------------------------------------------------+
  [控件栏在 SVG 内底部 y=430-490 区域]
  ```
- 关键实现要点：
  1. 状态机设计：单状态连续变量（滑片 x 坐标），无离散步骤
  2. 坐标计算：
     - 滑片 x 范围：100-370（变阻器区域）
     - 接入电阻 R = 20 × (370 - Px) / 270（线性映射）
     - 电流 I₂ = 0.15 + (0.60 - 0.15) × (370 - Px) / 270
     - 亮度强度 = 30% + 70% × (370 - Px) / 270
  3. 动画曲线：拖拽实时响应，无过渡动画（即时反馈）
  4. 事件绑定：
     - mousedown/touchstart：开始拖拽
     - mousemove/touchmove：更新滑片位置
     - mouseup/touchend：结束拖拽
  5. 发光效果：用 SVG radialGradient，通过 JS 动态调整 stop-color 的透明度或颜色饱和度
- ID 命名规范：
  - scene2-slider-track：滑块轨道
  - scene2-slider-handle：滑块手柄
  - scene2-rheostat-base：变阻器基座
  - scene2-rheostat-wire-active：接入电阻丝（高亮）
  - scene2-rheostat-wire-inactive：未接入电阻丝（虚线）
  - scene2-slider-p：滑片 P 三角形
  - scene2-bulb-l2：L₂ 灯泡圆形
  - scene2-bulb-l2-glow：L₂ 发光效果 gradient
  - scene2-ammeter-a：电流表圆形
  - scene2-label-r：R 数值显示
  - scene2-label-i2：I₂ 数值显示
  - scene2-label-p：P 标签
  - scene2-label-l2：L₂ 标签
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
