    **题目原文：**

    如图所示，A 是悬挂在弹簧测力计下的条形磁铁，B 是螺线管。闭合开关，待弹簧测力计示数稳定后，将滑动变阻器的滑片缓慢向右移动的过程中，下列说法正确的是（）

    A. 电压表示数变大，电流表示数也变大
    B. 电压表示数变小，电流表示数也变小
    C. 螺线管上端是 N 极，弹簧测力计示数变小
    D. 螺线管上端是 S 极，弹簧测力计示数变大

    **题目分析：**

    本题是电磁学综合题，涉及三个核心知识点：
    1. 动态电路分析：滑动变阻器滑片移动→电阻变化→电流/电压变化
    2. 安培定则：判断通电螺线管的磁极极性
    3. 磁极相互作用：同名磁极相斥、异名磁极相吸，结合受力分析判断弹簧测力计示数变化

    **整体讲解思路：**

    1. 先分析电路结构：R₀与滑动变阻器 R 串联，电压表测 R 两端电压，电流表测总电流
    2. 滑片右移→R 接入电阻变小→总电阻变小→总电流变大
    3. 根据串联分压，R 变小→R 两端电压变小（电压表示数变小）
    4. 用安培定则判断螺线管上端极性
    5. 根据磁极相互作用判断弹簧测力计示数变化

    **图示规划说明：**

    - SCENE_1：电路动态分析图示，整合滑片移动、电阻变化、电表示数变化
    - SCENE_2：螺线管极性判断图示，整合电流方向、安培定则、磁极标注
    - SCENE_3：受力分析图示，整合磁极相互作用、力的矢量、测力计示数变化

    **教学说明：**

    本图示用于讲解动态电路分析方法。教师应引导学生按以下步骤观察：

    1. **识别电路结构**：R₀与滑动变阻器 R 串联，电压表测 R 两端电压，电流表测串联电路总电流

    2. **分析滑片移动的影响**：
       - 滑片向右移动→接入电路的电阻丝长度变短→R 的阻值变小

    3. **应用欧姆定律**：
       - 总电阻 R_total = R₀ + R 变小
       - 总电流 I = U/R_total 变大（电流表示数变大）

    4. **分析电压表示数**：
       - 方法一：U_R = I × R，I 变大但 R 变小，需进一步分析
       - 方法二：U_R = U_电源 - I × R₀，I 变大→I × R₀变大→U_R 变小
       - 结论：电压表示数变小

    **关键公式：**
    - 串联电路总电阻：R_total = R₀ + R
    - 欧姆定律：I = U / R_total
    - 串联分压：U_R = U_电源 - I × R₀

    **讲解要点：**
    - 强调电压表测量对象是滑动变阻器 R，不是电源或 R₀
    - 引导学生理解"串联分压"原理：R 变小，分得的电压比例也变小

    **教学说明：**

    本图示用于讲解磁极相互作用及受力分析。教师应引导学生按以下步骤观察：

    1. **判断磁极相对关系**：
       - 条形磁铁 A：上端 S 极，下端 N 极（题目图中标注）
       - 螺线管 B：上端 N 极，下端 S 极（由安培定则判断）
       - 相对的两个磁极：A 的下端 N 与 B 的上端 N

    2. **判断相互作用力**：
       - 同名磁极相斥→A 受到向上的斥力 F_斥

    3. **受力分析**：
       - 条形磁铁受三个力：
         - 重力 G（向下）
         - 弹簧拉力 F_弹（向上）
         - 磁场斥力 F_斥（向上）
       - 平衡状态：F_弹 + F_斥 = G
       - 弹簧测力计示数：F_弹 = G - F_斥

    4. **分析示数变化**：
       - 滑片右移→电流变大→螺线管磁性增强
       - 斥力 F_斥变大
       - F_弹 = G - F_斥，G 不变，F_斥变大→F_弹变小
       - 结论：弹簧测力计示数变小

    **关键公式：**
    - 平衡方程：F_弹 + F_斥 = G
    - 测力计示数：F_弹 = G - F_斥

    **讲解要点：**
    - 强调弹簧测力计测量的是弹簧对磁铁的拉力
    - 斥力向上，与重力方向相反，会"抵消"部分重力
    - 电流越大，电磁铁磁性越强，斥力越大

    **总结与完整解答：**

    **综合分析：**

    1. 电路分析：滑片右移→R 变小→总电流 I 变大→电压表示数 U_R 变小
       - 排除选项 A（电压表示数变大）
       - 排除选项 B（电流表示数变小）

    2. 螺线管极性：由安培定则判断，上端为 N 极
       - 排除选项 D（上端是 S 极）

    3. 测力计示数：同名磁极相斥，斥力向上，电流变大→斥力变大→示数变小
       - 选项 C 正确

    **正确答案：C**

    **课堂讲解建议：**

    1. 先让学生独立分析电路，判断电表示数变化
    2. 用 SCENE_1 验证学生的电路分析
    3. 引导学生回忆安培定则，用 SCENE_2 演示判断过程
    4. 重点讲解受力分析，用 SCENE_3 展示斥力与示数的关系
    5. 最后综合三个图示的结论，得出正确答案

    **易错点提醒：**
    - 电压表测量对象易错：测的是滑动变阻器 R，不是电源
    - 安培定则应用易错：要注意线圈绕向和电流方向
    - 受力分析易错：斥力向上，会减小测力计示数，不是增大
