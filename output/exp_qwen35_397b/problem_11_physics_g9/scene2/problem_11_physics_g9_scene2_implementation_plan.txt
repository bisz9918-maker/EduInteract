[图示主题与整合说明]
- 本图示主题：安培定则判断螺线管磁极极性
- 整合的步骤/概念：电流方向标注、右手螺旋定则演示、螺线管 N/S 极判断

[视觉元素清单]
- 螺线管铁芯：矩形填充 #f5f5f5，边框 #000000 线宽 2px，位置 (460,150)-(540,350)
- 线圈绕线：黑色 #000000 路径，线宽 3px，6 匝环绕铁芯，从下端开始向上绕
- 电流方向箭头：蓝色 #1565c0，沿线圈正面分布 3 个箭头，指向右方（表示电流环绕方向）
- 右手示意图：绿色 #2e7d32 半透明手掌轮廓，透明度 30%，位置 (560,160)-(720,340)
- 大拇指：绿色 #2e7d32 粗线段，从手掌向上延伸指向 N 极
- 磁感线：灰色 #888888 虚线，从 N 极发出呈弧形回到 S 极，左右各一条
- N 极标注：红色 #c62828 文本"N"，位置 (500,110)，螺线管上端外侧
- S 极标注：红色 #c62828 文本"S"，位置 (500,375)，螺线管下端外侧
- 颜色规格沿用 scene_outline 中的配色规则

[分步序列]
- 初始状态（步骤 0）：显示螺线管铁芯和线圈绕线（黑色），显示"电流流入"标注和箭头指向螺线管下端
- 步骤 1：点击「下一步」→ 显示 3 个蓝色电流方向箭头沿线圈正面分布，箭头指向右方表示电流环绕方向
- 步骤 2：点击「下一步」→ 显示绿色半透明右手示意图（透明度 30%），四指弯曲方向与电流方向一致
- 步骤 3：点击「下一步」→ 大拇指高亮显示（绿色加粗），指向上方，同时显示 N 极标注（红色）在螺线管上端
- 步骤 4：点击「下一步」→ 显示 S 极标注（红色）在螺线管下端，显示两条灰色虚线磁感线从 N 极到 S 极
- 最终状态：展示完整的安培定则应用过程，包含电流方向、右手握法、N/S 极判断、磁感线

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 (320,455)，90×35px，点击返回上一状态
  - 「下一步」按钮：位于 (430,455)，90×35px，点击进入下一状态
  - 步骤指示：位于 (540,465)，显示当前步骤编号"步骤 X/5"
- 教师操作流程：
  1. 初始状态展示螺线管结构，讲解题目背景
  2. 点击「下一步」展示电流方向，提问学生电流如何流动
  3. 点击「下一步」展示右手握法，演示如何握持螺线管
  4. 点击「下一步」展示大拇指指向和 N 极，引导学生理解大拇指指向即为 N 极
  5. 点击「下一步」展示完整磁极和磁感线，总结安培定则的应用

[技术实现]
- JS 库选择：原生 SVG（简单几何图形首选，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |                    右手示意                       |
  |                      (绿)                        |
  |         磁感线      螺线管      磁感线            |
  |          (灰)      (黑+蓝)      (灰)             |
  |            \         |         /                 |
  |             \        N        /                  |
  |              \       |       /                   |
  |               \      |      /                    |
  |                \     |     /                     |
  |                 \    S    /                      |
  |                  \   |   /                       |
  |                   \  |  /                        |
  |                                                  |
  |              [上一步] [下一步] 步骤 X/5           |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量 (0-4) 跟踪当前步骤
  2. 元素分组：将不同步骤的元素放入不同的<g>组，通过 display 属性控制显示/隐藏
  3. 线圈绕线路径：使用 SVG path 绘制螺旋线，6 匝均匀分布
  4. 右手示意图：使用 SVG path 绘制简化的手掌轮廓，fill-opacity="0.3"
  5. 事件绑定：按钮点击事件切换 currentState，调用 updateDisplay() 函数
  6. IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中
- ID 命名规范：
  - scene2-solenoid-core（螺线管铁芯）
  - scene2-coil-path（线圈绕线）
  - scene2-current-arrow-1/2/3（电流箭头）
  - scene2-right-hand（右手示意）
  - scene2-thumb（大拇指）
  - scene2-magnetic-line-1/2（磁感线）
  - scene2-label-n（N 极标注）
  - scene2-label-s（S 极标注）
  - scene2-btn-prev（上一步按钮）
  - scene2-btn-next（下一步按钮）
  - scene2-step-indicator（步骤指示）
