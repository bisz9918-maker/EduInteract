[分步序列]
- 初始状态（步骤0）：显示弹簧测力计、条形磁铁A（标注上S下N）、螺线管B（标注上N下S），所有箭头和结论隐藏
- 步骤1：点击「下一步」→ 高亮相对的两个磁极（磁铁下端N极区、螺线管上端N极区，红色填充透明度20%）
- 步骤2：点击「下一步」→ 显示同名磁极相斥，从磁铁重心向上绘制红色斥力箭头F_斥，标注"F_斥"
- 步骤3：点击「下一步」→ 展示条形磁铁受力分析：重力G向下（黑色箭头）、弹簧拉力F_弹向上（蓝色箭头），标注"G"和"F_弹"
- 步骤4：点击「下一步」→ 显示滑片右移效果（滑动变阻器示意），电流变大→磁性增强→斥力箭头变长变粗（红色加深）
- 步骤5：点击「下一步」→ 显示受力平衡公式"F_弹 = G - F_斥"，斥力变大→示数变小，测力计指针向上偏转，右侧显示绿色结论"示数变小"

- "A"(440,200)与"F_斥"(415,210)：间距≈26px → 无冲突
- "G"(415,245)与"N(磁铁)"(400,250)：间距≈16px → 接近，G向右微调至(425,245)
- "F_斥"(415,210)与"F_弹"(375,175)：分别在磁铁右侧和左侧 → 无冲突
- "N(螺线管)"(400,320)与"B"(460,350)：间距≈42px → 无冲突

解决方案：将标签"G"从(415,245)调整至(425,245)，确保与"N(磁铁)"间距≥20px

[技术实现]
- JS 库选择：原生 SVG（简单几何图形和箭头绘制，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────┐
  │                                             │
  │           [弹簧测力计]                       │
  │               │                             │
  │           [条形磁铁A]      [刻度盘放大]      │
  │               │                             │
  │           [斥力/重力/拉力箭头]               │
  │               │                             │
  │           [螺线管B]                          │
  │                                             │
  │                    [结论文本]                │
  │                                             │
  │         [◀上一步]  步骤指示  [下一步▶]       │
  └─────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用currentState变量(0-5)跟踪当前步骤，steps数组存储每步的显示配置
  2. 元素ID规范：所有元素ID以"scene3-"为前缀，如scene3-magnet-a、scene3-solenoid-b、scene3-arrow-repulsion
  3. 显隐控制：每步调用updateDisplay()函数，根据currentState设置各元素的display属性
  4. 箭头绘制：用SVG marker-end定义箭头，动态调整path的d属性实现箭头长度变化
  5. 高亮效果：用opacity和fill属性控制磁极区的红色高亮透明度
  6. 指针动画：用transform rotate实现指针偏转，transition实现平滑过渡
  7. IIFE隔离：所有JS代码包在(function() { ... })()中，避免全局污染
- 颜色规格：
  - 背景：#ffffff
  - 主线：#000000（线宽2px）
  - 蓝高亮：#1565c0（F_弹及测力计）
  - 红高亮：#c62828（F_斥及同名磁极）
  - 绿高亮：#2e7d32（结论标注）
  - 辅助线：#888888虚线
