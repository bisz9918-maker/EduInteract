[图示主题与整合说明]
- 本图示主题：串联电路结构分析（九年级物理）
- 整合内容：电路元件连接关系、电流表/电压表测量对象、滑片位置示意

[视觉元素清单]
- 电源：电池符号（长短线），位置(120,250)，标签"U"在上方(150,220)
- 电流表 A：圆圈内含字母 A，位置(220,250)，半径 20px，标签在右侧
- 开关 S：断开/闭合符号，位置(400,150)，标签在上方
- 灯泡 L：圆圈内含×，位置(620,250)，半径 20px，标签在右侧
- 滑动变阻器：长方形电阻丝 + 滑片箭头，位置(280,350)-(520,370)，标签"R"在下方
- 滑片 P：向下箭头指向变阻器，位置(400,330)，标签"P"在上方
- 电压表 V：圆圈内含字母 V，位置(400,290)，半径 20px，标签在下方
- 导线：黑色实线 2px，连接各元件形成闭合回路
- 颜色/样式沿用 spec 中声明：
  - 主线 #000000 实线 2px
  - 电流表路径 #1565c0 高亮（步骤 1）
  - 电压表路径 #2e7d32 高亮（步骤 2）
  - 滑片移动方向 #c62828 箭头（步骤 3）
  - 元件标签 #000000 14px
  - 填充透明度 20%

[分步序列]
- 初始状态（步骤 0）：显示完整基础电路图，所有元件和导线以默认黑色显示，无高亮
  - 显示：电源、开关 S、灯泡 L、电流表 A、滑动变阻器、电压表 V、所有导线
  - 标签：U、S、L、A、V、P、R 全部显示

- 步骤 1：高亮电流表测量路径（蓝色 #1565c0）
  - 视觉变化：电流表 A 圆圈变为蓝色描边，电流流经的导线路径（电源→A→变阻器→L→S→电源）变为蓝色虚线或加粗
  - 新增：电流方向箭头（蓝色小箭头沿路径分布）
  - 说明：电流表串联在干路中，测量整个电路的电流

- 步骤 2：高亮电压表并联位置（绿色 #2e7d32）
  - 视觉变化：电压表 V 圆圈变为绿色描边，电压表并联的两条引线变为绿色
  - 恢复：步骤 1 的蓝色高亮恢复为黑色
  - 新增：电压表两端连接点高亮显示（变阻器左端和滑片 P 处）
  - 说明：电压表并联在滑动变阻器两端，测量变阻器两端电压

- 步骤 3：标注滑片移动方向及阻值变化（红色 #c62828）
  - 恢复：步骤 2 的绿色高亮恢复为黑色
  - 新增：底部双向箭头 (300,400)-(500,400)，红色
  - 新增：左移标签"R 增大"在 (285,415)，右移标签"R 减小"在 (505,415)
  - 新增：滑片 P 左右移动的动画示意（小幅度往复移动）
  - 说明：滑片左移时接入电阻增大，右移时接入电阻减小

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 按钮"◀ 上一步"：位置 (320,460)，尺寸 80×30px，点击返回上一状态
  - 按钮"下一步 ▶"：位置 (400,460)，尺寸 80×30px，点击进入下一状态
  - 步骤指示器：位置 (500,465)，显示"步骤 X/4"
- 教师操作流程：
  1. 初始展示完整电路图，让学生识别各元件
  2. 点击"下一步"高亮电流路径，讲解电流表串联测量原理
  3. 点击"下一步"高亮电压表，讲解电压表并联测量对象
  4. 点击"下一步"展示滑片移动，讲解变阻器阻值变化规律
  5. 可随时点击"上一步"回退复习

[技术实现]
- JS 库选择：原生 SVG（电路图符号简单，SVG 缩放不失真，适合几何图形）
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +------------------------------------------+
  |           S(开关)                        |
  |     ┌───────────┐                        |
  |     │           │                        |
  |  U  │           L(灯泡)                  |
  | (电源)──A──┐    │                        |
  |     │      │    │                        |
  |     │   V(电压表) │                        |
  |     │      │    │                        |
  |     └──────┴────┘                        |
  |        R(滑动变阻器)←P→                    |
  |     ←───────┴────────→                    |
  |      R 增大        R 减小                  |
  |                                          |
  |     [◀上一步] [下一步▶]  步骤 1/4          |
  +------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep(0-3) 跟踪当前步骤，数组存储各步骤的显示配置
  2. 坐标计算：所有元件位置预先计算好，用常量对象存储
  3. 动画曲线：滑片移动用 CSS transition ease-in-out 0.5s
  4. 事件绑定：按钮点击事件切换状态，更新 SVG 元素样式
  5. 高亮实现：通过修改 stroke/fill 属性和 stroke-width 实现
- ID 命名规范：所有元素 ID 以 scene1- 为前缀
  - scene1-power, scene1-ammeter, scene1-switch, scene1-bulb
  - scene1-rheostat, scene1-slider, scene1-voltmeter
  - scene1-wire-1~8, scene1-label-u, scene1-label-a 等
  - scene1-btn-prev, scene1-btn-next, scene1-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
