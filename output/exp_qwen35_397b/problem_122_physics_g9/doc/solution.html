problem_122_physics_g9

场景导航：Scene 1 | Scene 2

题目原文：

图为某均匀金属薄板，现测得接线柱A、B之间的电阻为R．如果将该电阻板均匀分成9块，并挖去其中一小块，则此时A、B之间的电阻变为（ ）
A、8R/9 B、7R/6 C、9R/8 D、6R/7

题目分析：

本题考察电阻网络的等效变换。原金属板可视为3×3=9个相同的小电阻块组成的网络，电流从A流向B。

整体讲解思路：

  1. 首先将金属板建模为电阻网络——每个小方块视为一个电阻单元
  2. 分析原9块完整时的等效电阻R与各小电阻的关系
  3. 挖去右下角一块后，重新分析8块组成的新网络
  4. 计算新的等效电阻并与R比较

图示规划说明：

  • SCENE_1：展示原金属板的电阻网络模型（3×3网格，9个电阻单元）
  • SCENE_2：展示挖去一块后的电阻网络及等效电路简化过程
步骤 1/4

教学说明：

本图示帮助学生建立从物理实体到电路模型的映射关系。

讲解要点：

  1. 均匀金属板可视为由9个相同的小电阻块组成
  2. 每个小块的电阻值相同，记为r
  3. 电流从A端流入，经过3列电阻块，从B端流出
  4. 每一列的3个小块是并联关系，3列之间是串联关系

关键公式：

原9块完整时：

  • 每列3块并联：R_列 = r/3
  • 3列串联：R_AB = 3 × (r/3) = r
  • 因此 R = r（每个小块的电阻等于总电阻）
步骤 1/4

教学说明：

本图示展示挖去一块后的网络重构与等效计算。

讲解要点：

  1. 挖去右下角一块后，第3列只剩2个电阻并联
  2. 第1列和第2列仍保持3个电阻并联
  3. 三列之间仍为串联关系

推导步骤：

  1. 第1列等效电阻：R₁ = r/3
  2. 第2列等效电阻：R₂ = r/3
  3. 第3列等效电阻：R₃ = r/2（只有2块并联）
  4. 总电阻：R'_AB = R₁ + R₂ + R₃ = r/3 + r/3 + r/2 = 7r/6
  1. 由原电阻 R = r，得：R'_AB = 7R/6

答案：B

课堂讲解建议：

  • 引导学生先识别原网络的串并联结构
  • 强调"挖去一块"只影响所在列的并联数量
  • 对比挖去前后的变化，理解局部变化对整体的影响
