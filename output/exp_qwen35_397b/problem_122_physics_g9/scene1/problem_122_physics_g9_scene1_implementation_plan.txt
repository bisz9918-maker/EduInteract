[分步序列]
- 初始状态（步骤0）：显示金属板轮廓（实线黑色）、接线柱A和B（蓝色圆点+黑色引线）、总电阻标注 R_AB=R（红色，金属板上方）
- 步骤1：点击「下一步」→ 显示3×3网格虚线（灰色），将金属板划分为9个小方块
- 步骤2：点击「下一步」→ 在每个小方块中心显示电阻标注"r"（共9个，黑色14px）
- 步骤3：点击「下一步」→ 显示电流方向箭头（绿色，从A指向B，位于金属板上方y=230处），箭头从x=170延伸到x=630，带箭头头部
- 教师可随时点击「上一步」回退复习

[标签冲突检查]
- 标签"A"：坐标(130,245)
- 标签"B"：坐标(660,245)
- 标签"R_AB=R"：坐标(400,85)
- 标签"r11"~"r33"：9个r分别位于各小方块中心，坐标见坐标表

冲突检查：
- "A"与金属板左边缘(200,250)：水平距离70px → 无冲突
- "B"与金属板右边缘(600,250)：水平距离60px → 无冲突
- "R_AB=R"与金属板上边缘(y=115)：垂直距离30px → 无冲突
- 各"r"标签之间：相邻r水平间距约133px，垂直间距约90px → 无冲突
- 电流箭头(y=230)与第2行r标签(y=250)：垂直距离20px → 无冲突（箭头在上方）
- 所有标签均位于图形元素外侧或中心空白处，无重叠

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于SVG底部左侧(x=300, y=455)，点击后回退到前一状态
  - 「下一步」按钮：位于SVG底部右侧(x=500, y=455)，点击后进入下一状态
  - 状态指示器：显示当前步骤序号（如"步骤 1/4"），位于两按钮之间(x=400, y=460)
- 教师操作流程：
  1. 初始展示金属板实物，讲解题目背景
  2. 点击「下一步」显示网格，说明将金属板划分为9个等效单元
  3. 点击「下一步」显示各单元电阻r，建立电阻网络模型
  4. 点击「下一步」显示电流方向，讲解电流从A到B的分布规律
  5. 可随时回退复习关键概念

[技术实现]
- JS库选择：原生SVG（简单几何图形首选，无需额外库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |              R_AB=R (步骤0显示)                   |
  |                                                  |
  |    A o====[金属板 3×3 网格]====o B               |
  |         | r11 | r12 | r13 |                      |
  |         | r21 | r22 | r23 |  (步骤2显示r)        |
  |         | r31 | r32 | r33 |                      |
  |                                                  |
  |    ←──────── 电流箭头 ────────→  (步骤3显示)      |
  |                                                  |
  |         [◀上一步]  步骤X/4  [下一步▶]            |
  +--------------------------------------------------+
  [控件栏在SVG内底部 y=440~490]
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-3) 跟踪当前步骤，数组存储各步骤应显示的元素ID列表
  2. 坐标计算：金属板居中，网格线位置通过等分计算（宽400/3≈133.33，高270/3=90）
  3. 动画曲线：元素淡入效果用 CSS transition opacity 0.3s ease
  4. 事件绑定：按钮点击事件绑定到 stepForward/stepBackward 函数
  5. 元素显隐：通过 display:none 或 opacity:0 控制，步骤切换时更新
- ID命名规范：所有交互元素ID必须以 scene1- 为前缀
  - scene1-metal-plate（金属板）
  - scene1-grid-v1, scene1-grid-v2（垂直网格线）
  - scene1-grid-h1, scene1-grid-h2（水平网格线）
  - scene1-terminal-a, scene1-terminal-b（接线柱）
  - scene1-lead-a, scene1-lead-b（引线）
  - scene1-label-a, scene1-label-b（A/B标签）
  - scene1-label-r11 ~ scene1-label-r33（9个r标签）
  - scene1-label-total（总电阻标注）
  - scene1-current-arrow（电流箭头）
  - scene1-btn-prev, scene1-btn-next（按钮）
  - scene1-step-indicator（步骤指示器）
- IIFE隔离：所有JS代码包在 (function() { ... })() 中，避免全局污染
