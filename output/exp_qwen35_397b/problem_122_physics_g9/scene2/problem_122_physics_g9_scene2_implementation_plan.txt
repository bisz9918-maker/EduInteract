[图示主题与整合说明]
- 本图示主题：挖去一块后的电阻网络及等效电路
- 整合的步骤/概念：
  1. 挖去右下角一块的金属板示意图（8 块剩余）
  2. 转换为 8 个电阻单元的网络图
  3. 重画为标准等效电路图（三列并联组串联）
  4. 标注各列等效电阻并计算最终总电阻
- 教学价值：教师可逐步展示从物理模型到电路模型的抽象过程，帮助学生理解电阻网络的等效简化方法。通过分步导航，教师可控制节奏，在每一步引导学生思考：为什么可以这样等效？每列的并联关系如何确定？

[分步序列]
- 初始状态（步骤 0）：
  - 显示：金属板外框、挖去区域（右下角斜线填充）、网格虚线、接线柱 A/B 及引线、标签 A/B
  - 隐藏：所有电阻单元、等效电路图、公式
  - 视觉：完整的 3×3 网格，右下角空缺，直观展示"挖去一块"

- 步骤 1（点击「下一步」）：
  - 显示：8 个电阻单元矩形框（#1565c0 蓝色），每个内部标注小写 r
  - 隐藏：网格虚线（避免视觉干扰）
  - 新增标签：「r(×8)」位于金属板上方
  - 视觉：金属板转换为 8 个独立电阻单元的阵列

- 步骤 2（点击「下一步」）：
  - 显示：等效电路图（右侧区域）
    - 第 1 列：3 个电阻并联（垂直排列）
    - 第 2 列：3 个电阻并联（垂直排列）
    - 第 3 列：2 个电阻并联（垂直排列，因为右下角缺失）
    - 三列之间用水平线串联连接
  - 隐藏：左侧金属板示意图（或淡出）
  - 新增标签：「r/3」「r/3」「r/2」分别位于三列上方（#2e7d32 绿色）
  - 视觉：清晰的电路图结构，展示列间串联、列内并联关系

- 步骤 3（点击「下一步」）：
  - 显示：计算公式（底部居中）
    - 第 1 行：R'_AB = r/3 + r/3 + r/2 = 7r/6
    - 第 2 行：∵ R = r/3 + r/3 + r/3 = r  ∴ r = 3R/2（原 9 块时 R = r）
    - 第 3 行：R'_AB = 7R/6（#c62828 红色加粗）
  - 高亮：最终结果
  - 视觉：完整推导过程，答案突出显示

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 内底部左侧 (280,455)，80×30px，点击后返回前一状态
  - 「下一步」按钮：位于 SVG 内底部右侧 (440,455)，80×30px，点击后进入下一状态
  - 步骤指示器：显示「步骤 X/4」，位于两按钮之间
- 教师操作流程：
  1. 初始状态展示挖去一块的金属板，提问学生"如何建模这个电阻网络？"
  2. 点击「下一步」展示 8 个电阻单元，引导学生识别每个小块的电阻为 r
  3. 点击「下一步」展示等效电路，讲解列内并联、列间串联的关系
  4. 点击「下一步」展示计算过程，推导最终答案 7R/6

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形和电路图均为 2D 静态/简单动画，无需复杂库；原生 SVG 轻量且易于精确控制坐标
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [800 × 500 画布]
  +--------------------------------------------------+
  |  y=20                                            |
  |  [左侧：金属板示意图]  [右侧：等效电路图]        |
  |  y=100                                           |
  |  +------------+      +------------------------+  |
  |  | 3x3 网格   |      | 第 1 列 | 第 2 列 | 第 3 列 |  |
  |  | 右下角空缺 |      | 3 并联 | 3 并联 | 2 并联 |  |
  |  | A o----o B |      | r/3   | r/3   | r/2   |  |
  |  +------------+      +------------------------+  |
  |  y=280                                           |
  |                                                  |
  |  [计算公式区 y=390~430]                          |
  |  R'_AB = r/3 + r/3 + r/2 = 7r/6 = 7R/6          |
  |                                                  |
  |  [控件栏 y=440~490]                              |
  |        [◀上一步]  步骤 2/4  [下一步▶]            |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0~3），数组存储每步的可见元素 ID 列表
  2. 坐标计算：所有元素使用绝对坐标（非相对定位），确保精确对齐
  3. 动画曲线：步骤切换使用 CSS transition（opacity: 0→1，duration: 300ms）
  4. 事件绑定：按钮点击事件绑定到 updateState() 函数，更新可见性并刷新步骤指示器
  5. 电阻符号：使用 SVG path 绘制标准锯齿形电阻符号，或简化为矩形框
- ID 命名规范：
  - 所有元素 ID 以 scene2- 为前缀
  - 示例：scene2-metal-plate, scene2-resistor-1-1, scene2-equiv-col1, scene2-label-r3-1, scene2-btn-prev, scene2-btn-next
- IIFE 隔离：
  ```javascript
  (function() {
    // 所有 JS 代码包在此闭包内
    let currentState = 0;
    const states = [...];
    function updateState() { ... }
    document.getElementById('scene2-btn-prev').addEventListener('click', ...);
    document.getElementById('scene2-btn-next').addEventListener('click', ...);
  })();
  ```
