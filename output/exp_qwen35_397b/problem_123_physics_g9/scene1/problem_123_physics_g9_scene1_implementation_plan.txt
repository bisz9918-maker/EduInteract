[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于SVG内底部左侧(x=350,y=455)，点击返回上一状态
  - 「下一步」按钮：位于SVG内底部右侧(x=430,y=455)，点击进入下一状态
  - 步骤指示器：位于两按钮中间(x=395,y=460)，显示当前步骤编号（如"步骤 1/4"）
- 教师操作流程：
  1. 初始状态展示题目条件，引导学生观察三个容器的初始水面位置和气体分布
  2. 点击「下一步」步骤1，高亮开关M并显示水流方向，提问学生"水会往哪个方向流？"
  3. 点击「下一步」步骤2，显示水面变化箭头，引导学生分析各容器水面上升/下降趋势
  4. 点击「下一步」步骤3，显示气体体积变化和△V标注，引导学生比较△V_乙和△V_丙的大小关系
  5. 可随时点击「上一步」回退复习关键步骤

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript。理由：本图示为静态几何图形+简单箭头动画，无需复杂库；SVG 便于精确控制坐标和样式，适合教育图示
- 画布尺寸：800 × 500 px（固定画布）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                    P₀                            |
  |        甲容器                                    |
  |        +--------+                                |
  |   甲   | ~~~~~~ |  右侧水连通管                  |
  |        |  水    |====                            |
  |        +--------+    |                           |
  |           |          |                           |
  |        中间管(M)     |                           |
  |           ↓          |                           |
  |        +--------+    |      P_乙  △V_乙          |
  |   乙   | ~~~~~~ |====|      (气体)               |
  |        |  水    |    |                           |
  |        +--------+    |                           |
  |           |          |                           |
  |        左侧气体连通管|                           |
  |           |          |                           |
  |        +--------+    |      P_丙  △V_丙          |
  |   丙   | ~~~~~~ |====|      (气体)               |
  |        |  水    |                                |
  |        +--------+                                |
  |                                                  |
  |              [◀上一步] 步骤1/4 [下一步▶]         |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用currentState变量(0-3)跟踪当前步骤，steps数组存储各步骤的可见元素ID列表
  2. 坐标计算：所有元素坐标预先计算好，步骤切换时通过display属性控制可见性
  3. 动画曲线：水流箭头使用CSS transition实现淡入效果（0.3s ease-in-out）
  4. 事件绑定：按钮点击事件绑定到updateStep()函数，更新currentState并刷新DOM可见性
  5. 元素初始化：所有步骤元素在SVG中预先创建，步骤0时仅显示基础元素
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀（如 scene1-container-a、scene1-water-arrow）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
