[图示主题与整合说明]
- 本图示主题：压强关系分析图（初始状态与最终状态的压强对比）
- 整合的步骤/概念：整合了初始压强平衡方程、打开 M 后的压强变化、体积变化量比较三个分析维度
- 教学价值：教师如何使用此图示进行课堂讲解
  1. 初始状态展示：让学生理解三个容器初始压强关系 P_乙 = P_丙 = P > P₀
  2. 打开 M 后的变化：通过高亮中间管，展示水流动的压强差原因
  3. 新平衡状态：直观显示乙水面上升、丙水面下降的高度变化
  4. 体积变化对比：通过条形图比较△V_乙与△V_丙的大小关系
  5. 结论归纳：高亮正确选项 B，强化理解

[分步序列]
- 初始状态（步骤 0）：
  - 显示：三个容器轮廓、水面线、连通管、中间管（灰色）、开关 M
  - 显示：标签"甲"、"乙"、"丙"、"M"
  - 显示：P₀标注（大气压）
  - 显示：压强标注框，文字"P_乙 = P_丙 = P > P₀"
  - 显示：压强公式框，文字"P = P₀ + ρgh"
  - 隐藏：△h 标注、条形图
  - 选项区域：四个选项均显示，无高亮

- 步骤 1（打开 M 后）：
  - 中间管高亮：颜色从灰色变为 #c62828，线宽加粗
  - 开关 M 高亮：填充变为 #c62828
  - 新增标注：在中间管旁显示"M 处压强 P_M = P₀ + ρgh_甲 > P_乙"
  - 箭头动画：从中间管指向乙容器，表示水流动方向
  - 其他元素保持步骤 0 状态

- 步骤 2（新平衡）：
  - 乙水面变化：水面上升，显示△h_乙双向箭头和文字标注
  - 丙水面变化：水面下降，显示△h_丙双向箭头和文字标注
  - 新增压强标注：显示"P' = P₀ + ρg(h_甲 - △h)"
  - 中间管恢复普通状态
  - 保留步骤 1 的压强关系标注

- 步骤 3（结论）：
  - 显示体积对比条形图：△V_乙条形（较长，红色），△V_丙条形（较短，绿色）
  - 显示结论文字："△V_乙 > △V_丙"
  - 选项 B 高亮：背景变为 #e8f5e9，文字变为 #2e7d32 加粗
  - 其他选项变为灰色 #888888
  - 显示完整推导链

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "上一步"按钮：位于 (620,460)，80×30px，点击后退到前一步状态
  - "下一步"按钮：位于 (710,460)，80×30px，点击前进到下一步状态
  - 步骤指示器：位于 (700,420)，显示当前步骤 X/4
- 教师操作流程：
  1. 加载图示，显示初始状态（步骤 0），讲解初始压强平衡关系
  2. 点击"下一步"，进入步骤 1，高亮中间管和开关 M，讲解打开 M 后的压强差
  3. 点击"下一步"，进入步骤 2，显示水面高度变化，讲解新平衡状态
  4. 点击"下一步"，进入步骤 3，显示体积对比条形图和高亮选项 B，总结结论
  5. 可随时点击"上一步"回退复习关键步骤

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（矩形、线段、文字），无需复杂库；原生 SVG 交互性能好，代码简洁
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +----------------------------------------------------------+
  |  [容器甲]  [容器乙]  [容器丙]        |  P₀标注            |
  |     |        |        |              |                    |
  |  连通管（右）连通管（左）中间管      |  P 标注框          |
  |                                     |  压强公式框        |
  |                                     |  △h 标注           |
  |                                     |                    |
  |                                     |  [条形图区域]      |
  |                                     |  △V_乙  △V_丙      |
  |                                     |                    |
  |  [选项 A] [选项 B] [选项 C] [选项 D] |  步骤 X/4          |
  |                                     |                    |
  |                    [◀上一步][下一步▶]|                    |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 state 变量（0-3）跟踪当前步骤，steps 数组存储每步的显示配置
  2. 坐标计算：所有元素坐标硬编码，确保与布局坐标表一致
  3. 动画曲线：水面变化使用 CSS transition，duration 500ms，ease-out
  4. 事件绑定：按钮点击事件绑定到 updateState() 函数，更新 DOM 元素显示状态
  5. 元素显隐：使用 display:none / display:block 或 opacity 控制
  6. 高亮效果：通过添加/移除 CSS class 实现（如 .highlight）
- ID 命名规范：所有交互元素 ID 必须以 scene2- 为前缀
  - scene2-container-a, scene2-container-b, scene2-container-c
  - scene2-water-a, scene2-water-b, scene2-water-c
  - scene2-tube-right, scene2-tube-left, scene2-tube-middle
  - scene2-valve-m, scene2-label-a, scene2-label-b, scene2-label-c, scene2-label-m
  - scene2-pressure-box, scene2-formula-box
  - scene2-delta-h-b, scene2-delta-h-c
  - scene2-bar-vb, scene2-bar-vc
  - scene2-option-a, scene2-option-b, scene2-option-c, scene2-option-d
  - scene2-step-indicator, scene2-btn-prev, scene2-btn-next
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
