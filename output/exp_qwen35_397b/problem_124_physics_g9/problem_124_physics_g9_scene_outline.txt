    **题目原文：**

    电磁铁甲和永磁体乙如图放置，开关 S 闭合后，b、c 两端形成的磁感线如图中实线所示，由此可知（  ）

    A、a、c 两端都是 N 极

    B、a、d 两端都是 N 极

    C、b、c 两端都是 N 极

    D、b、d 两端都是 N 极

    **题目分析：**

    本题考查电磁铁磁极判断和磁感线特征两个核心知识点：

    1. 电磁铁甲的磁极需要用安培定则（右手螺旋定则）判断：根据电源正负极确定电流方向，再用右手握住螺线管，四指指向电流方向，大拇指指向 N 极
    2. 磁感线的特征：磁感线从 N 极出发，回到 S 极；同名磁极之间的磁感线相互排斥（向外弯曲），异名磁极之间的磁感线相互吸引（向内连接）

    **整体讲解思路：**

    1. 先分析电磁铁甲：从电源正极出发，确定线圈中电流方向，应用安培定则判断 b 端为 N 极，a 端为 S 极
    2. 再分析磁感线：观察 b、c 之间的磁感线形状，发现磁感线从两端都向外发散，说明 b、c 是同名磁极且都是 N 极
    3. 最后得出永磁体乙的磁极：c 端为 N 极，则 d 端为 S 极
    4. 对照选项，正确答案为 C（b、c 两端都是 N 极）

    **本图示教学说明：**

    **引导学生观察的要点：**

    1. **电流方向判断**：首先让学生识别电源符号，长竖线为正极，短竖线为负极。开关闭合后，电流从正极流出，经线圈回到负极。

    2. **安培定则应用**：
       - 用右手握住螺线管
       - 四指弯曲方向与电流方向一致
       - 大拇指所指的一端为 N 极
       - 本题中，大拇指指向 b 端，故 b 为 N 极，a 为 S 极

    3. **磁感线特征分析**：
       - 磁感线从 N 极出发，回到 S 极
       - 观察 b、c 之间的磁感线形状：向两侧弯曲，互不连接
       - 这说明 b、c 是同名磁极，且磁感线从两端出发向外，故都是 N 极

    4. **永磁体磁极推断**：
       - 已知 c 端为 N 极
       - 永磁体两端磁极相反，故 d 端为 S 极

    **关键公式/定则：**

    安培定则（右手螺旋定则）：用右手握住通电螺线管，使四指弯曲方向与电流方向一致，则大拇指所指的那一端就是通电螺线管的 N 极。

    **讲解建议：**

    - 步骤 0-1：让学生先独立思考电流方向，再点击显示答案
    - 步骤 2：可请学生用手比划安培定则，增强记忆
    - 步骤 3：对比异名磁极的磁感线形状（相互连接），加深理解
    - 步骤 4：引导学生对照四个选项，排除错误答案

    **完整解答：**

    1. 根据电源正负极，电流从右侧流入线圈，从左侧流出
    2. 应用安培定则，右手握住螺线管，四指指向电流方向，大拇指指向 b 端，故 b 端为 N 极，a 端为 S 极
    3. 观察 b、c 之间的磁感线，从两端向外发散，说明 b、c 为同名磁极且都是 N 极
    4. 永磁体乙的 c 端为 N 极，则 d 端为 S 极
    5. 综上：a(S 极)、b(N 极)、c(N 极)、d(S 极)
    6. 对照选项，正确答案为 **C**（b、c 两端都是 N 极）

    **课堂讲解建议：**

    - 先让学生独立观察磁感线形状，猜测 b、c 的磁极关系
