    **题目原文：**

    小红同学在做"探究凸透镜成像规律"实验时，烛焰在光屏上成了一个清晰的像 (如图)，下列说法正确的是 (   )

    A.实验中蜡烛越烧越短，光屏上烛焰的像向上移动
    B.要使光屏上烛焰的像变小，只需将蜡烛靠近凸透镜
    C.利用这一成像规律可制成投影仪
    D.为了便于从不同方向观察光屏上的像，光屏应选用较光滑的玻璃板

    **题目分析：**

    从题图可知：蜡烛位于 2F 之外（物距 u > 2f），光屏位于 F 与 2F 之间（像距 f < v < 2f），此时成倒立、缩小的实像。这是照相机的成像原理。

    **整体讲解思路：**

    1. 首先通过光路图展示成像原理，理解为什么成倒立缩小的实像
    2. 分析蜡烛燃烧变短时像的移动方向（倒立像的特性）
    3. 讲解物距与像大小的关系
    4. 对比照相机与投影仪的成像条件差异
    5. 说明光屏材质选择的原因（漫反射）

    **图示规划说明：**

    - SCENE_1：完整光路图，展示三条特殊光线的传播路径，整合成像原理与倒立特性
    - SCENE_2：物距变化对像的影响，用滑块动态演示蜡烛移动时像距和像大小的变化规律
    - SCENE_3：三种成像情况对比（照相机/投影仪/放大镜），帮助区分不同应用对应的成像条件

    **教学说明：**

    本图示用于讲解凸透镜成像的基本原理。教师应引导学生按步骤观察：

    1. **光线 1**：从烛焰顶端发出平行于主光轴的光线，经凸透镜折射后通过右侧焦点 F
    2. **光线 2**：从烛焰顶端发出通过光心 O 的光线，传播方向不改变
    3. **光线 3**：从烛焰顶端发出通过左侧焦点 F 的光线，经凸透镜折射后平行于主光轴

    三条光线在透镜右侧会聚于一点，该点即为烛焰顶端的像点。由于光线实际会聚，形成的是**实像**。

    **关键观察点：**

    - 烛焰顶端发出的光线会聚后位于主光轴下方，说明成**倒立**的像
    - 像的高度小于物体高度，说明成**缩小**的像
    - 当蜡烛燃烧变短时，烛焰顶端向下移动，根据光路可逆性，像的顶端会向上移动

    **公式推导：**

    凸透镜成像公式：

    $$\frac{1}{u} + \frac{1}{v} = \frac{1}{f}$$

    放大率公式：

    $$m = \frac{h'}{h} = \frac{v}{u}$$

    当 u > 2f 时，f < v < 2f，m < 1，成倒立缩小的实像。

    **教学说明：**

    本图示用于探究物距变化时像的变化规律。教师可拖动滑块演示以下关键位置：

    1. **u > 2f**（题图情况）：f < v < 2f，成倒立缩小的实像 — 照相机原理
    2. **u = 2f**：v = 2f，成倒立等大的实像 — 测焦距方法
    3. **f < u < 2f**：v > 2f，成倒立放大的实像 — 投影仪/幻灯机原理
    4. **u = f**：不成像（光线平行射出）
    5. **u < f**：成正立放大的虚像 — 放大镜原理

    **引导学生观察：**

    - 当蜡烛从远处向透镜靠近时（u 减小），像距 v 如何变化？（增大）
    - 像的大小如何变化？（变大）
    - 实像和虚像的分界点在哪里？（u = f）

    **选项 B 分析：**

    要使光屏上烛焰的像变小，应**增大**物距（蜡烛远离凸透镜），同时**减小**像距（光屏靠近凸透镜）。选项 B 说"将蜡烛靠近凸透镜"会使像变大，因此错误。

    **教学说明：**

    本图示用于对比三种常见光学仪器的成像原理，帮助学生区分记忆。

    **照相机（对应本题）：**

    - 物距：u > 2f
    - 像距：f < v < 2f
    - 像的性质：倒立、缩小、实像
    - 题图中蜡烛在 2F 外，光屏在 F 与 2F 之间，正是照相机的成像条件

    **投影仪：**

    - 物距：f < u < 2f
    - 像距：v > 2f
    - 像的性质：倒立、放大、实像
    - 与题图条件不符，选项 C 错误

    **放大镜：**

    - 物距：u < f
    - 像距：v > u（虚像，与物同侧）
    - 像的性质：正立、放大、虚像

    **选项分析总结：**

    - **A 正确**：蜡烛燃烧变短，烛焰向下移动，由于成倒立像，像向上移动
    - **B 错误**：要使像变小，应增大物距（蜡烛远离透镜）
    - **C 错误**：题图是照相机原理，投影仪需要 f < u < 2f
    - **D 错误**：光屏应选用粗糙表面，利用漫反射才能从不同方向观察到像

    **正确答案：A**
