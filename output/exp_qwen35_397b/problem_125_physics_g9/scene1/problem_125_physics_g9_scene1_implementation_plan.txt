[图示主题与整合说明]
- 本图示主题：凸透镜成像光路图与倒立像特性
- 整合的内容：三条特殊光线作图、实像形成过程、倒立像的上下关系、蜡烛变短导致像上移的现象
- 教学价值：教师可逐步展示光线传播路径，从单一光线到完整光路，帮助学生理解实像的形成机制；最后通过蜡烛变短动画直观展示"倒立像"特性——物下移则像上移，突破学生认知难点

[视觉元素清单]
- 主光轴：水平直线，y=250，x 从 50 到 750，#000000 实线，线宽 3px
- 凸透镜：竖直椭圆，中心 (400,250)，宽 40px 高 120px，#000000 轮廓，无填充
- 光心 O：黑色实心点 (400,250)，直径 4px，标签"O"在 (400,265)
- 焦点 F：左右各一个，(300,250) 和 (500,250)，黑色实心点直径 6px，标签"F"在点下方 15px
- 2F 点：左右各一个，(200,250) 和 (600,250)，黑色实心点直径 6px，标签"2F"在点下方 15px
- 蜡烛：主体矩形 (115,220) 15×30px #8d6e63，火焰椭圆 (122,200) 12×20px #ff9800
- 光屏：支架线段 (550,210)-(550,250)，屏面矩形 (520,170)-(580,210) #bdbdbd 30% 透明
- 光线 1（蓝色 #1565c0）：从烛焰顶端 (122,200) 水平向右到透镜 (400,200)，折射后过右焦点 (500,250) 到光屏 (550,250)
- 光线 2（绿色 #2e7d32）：从烛焰顶端 (122,200) 过光心 (400,250) 直线传播到光屏
- 光线 3（红色 #c62828）：从烛焰顶端 (122,200) 过左焦点 (300,250) 到透镜，折射后平行主光轴
- 实像：倒立火焰椭圆 (550,270) 12×20px #ff5722
- 标签：所有标签均为黑色 #000000，字体 14px sans-serif

[分步序列]
- 步骤 0（初始状态）：显示基础元件
  - 主光轴、凸透镜、光心 O、左右焦点 F 和 2F 点及标签

  - 蜡烛标签、凸透镜标签、光屏标签
  - 物距 u 标注（从蜡烛到透镜的双向箭头）、像距 v 标注（从透镜到光屏的双向箭头）
  - 不显示任何光线和实像

- 步骤 1：显示光线 1
  - 在步骤 0 基础上，显示蓝色光线 1
  - 段 1：(122,200) 到 (400,200) 水平线
  - 段 2：(400,200) 到 (550,250) 斜线（过右焦点）
  - 箭头：在段 2 中点附近 (475,225) 添加指向传播方向的箭头
  - 高亮：光线 1 路径加粗显示

- 步骤 2：显示光线 2
  - 在步骤 1 基础上，显示绿色光线 2
  - 从 (122,200) 过光心 (400,250) 到 (550,250) 的直线
  - 箭头：在 (350,225) 添加指向传播方向的箭头
  - 高亮：光线 2 路径加粗显示

- 步骤 3：显示光线 3
  - 在步骤 2 基础上，显示红色光线 3
  - 段 1：(122,200) 到 (300,250) 过左焦点
  - 段 2：(400,250) 到 (550,250) 平行主光轴（用虚线表示与主光轴重合部分）
  - 箭头：在 (350,240) 添加指向传播方向的箭头
  - 高亮：光线 3 路径加粗显示

  - 显示"倒立缩小"标签于 (550,310)
  - 三条光线变为半透明（opacity 0.5），突出实像

- 步骤 5：蜡烛变短效果演示
  - 蜡烛火焰从 (122,200) 下移到 (122,215)（向下 15px 动画）
  - 对应实像火焰从 (550,270) 上移到 (550,255)（向上 15px 动画）
  - 显示向下箭头 (122,210) 8×15px 表示蜡烛变短
  - 显示向上箭头 (550,280) 8×15px 表示像上移
  - 三条光线重新计算路径（起点随烛焰下移）

[交互方案]

- 控件说明：
  - 按钮组位于 SVG 内底部 y=450 区域，水平居中排列
  - 按钮 1：「步骤 0：基础元件」— 显示蜡烛、透镜、光屏、焦点
  - 按钮 2：「步骤 1：光线 1」— 显示平行光线折射路径
  - 按钮 3：「步骤 2：光线 2」— 显示过光心光线
  - 按钮 4：「步骤 3：光线 3」— 显示过焦点光线
  - 按钮 5：「步骤 4：实像形成」— 显示三条光线会聚与倒立实像
  - 按钮 6：「步骤 5：蜡烛变短」— 演示物下移像上移
  - 导航按钮：「◀上一步」「下一步▶」位于步骤按钮下方或两侧
- 教师操作流程：
  1. 点击「步骤 0」介绍实验装置，讲解物距 u>2f 的条件
  2. 点击「步骤 1」展示第一条特殊光线，讲解"平行于主光轴的光线经凸透镜折射后过焦点"
  3. 点击「步骤 2」展示第二条光线，讲解"过光心的光线传播方向不变"
  4. 点击「步骤 3」展示第三条光线，讲解"过焦点的光线经凸透镜折射后平行于主光轴"
  5. 点击「步骤 4」展示三条光线会聚点即像的位置，强调"倒立缩小实像"
  6. 点击「步骤 5」动态演示蜡烛燃烧变短，引导学生观察像的移动方向，验证"倒立"特性

[技术实现]
- JS 库选择：原生 SVG
  - 原因：几何光路图由直线、椭圆、箭头等基本形状构成，原生 SVG 足够胜任；无需额外库依赖，加载快；SVG 元素可通过 CSS 控制显隐和动画，适合分步展示
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +----------------------------------------------------------+
  |  蜡烛        凸透镜                    光屏              |
  |   🔥         ||                       ┌──┐              |
  |   ||         ||                       │  │              |
  |   ||         ||                       └──┘              |
  |---●----●----O----●----●----------------------------------| 主光轴 y=250
  |  2F   F         F   2F                                   |
  |          u              v                                |
  |                    倒立缩小                              |
  |                                                          |
  |  [步骤 0][步骤 1][步骤 2][步骤 3][步骤 4][步骤 5]        |  y=430
  |         [◀上一步]          [下一步▶]                     |  y=460
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-5) 跟踪当前步骤，每次切换调用 updateScene() 函数
  2. 元素显隐：所有光线、实像、箭头元素设置 id，通过 display:none / display:block 控制显隐
  3. 动画实现：蜡烛变短和像上移使用 CSS transition 或 requestAnimationFrame 实现平滑过渡（300ms）
  4. 事件绑定：按钮点击事件绑定到 stepChange(step) 函数，更新 currentStep 并刷新视图
  5. 光线路径：使用 SVG <polyline> 或 <path> 绘制折线，箭头用 <marker> 定义复用
  6. 坐标计算：所有坐标硬编码（基于布局坐标表），确保精确对齐
- ID 命名规范：
  - 所有元素 ID 以 scene1- 为前缀
  - 示例：scene1-optical-axis, scene1-lens, scene1-candle, scene1-flame, scene1-screen
  - 光线：scene1-ray1-seg1, scene1-ray1-seg2, scene1-ray2, scene1-ray3-seg1, scene1-ray3-seg2
  - 箭头：scene1-ray1-arrow, scene1-ray2-arrow, scene1-ray3-arrow
  - 标签：scene1-label-candle, scene1-label-lens, scene1-label-screen, scene1-label-o, scene1-label-f-left 等
  - 按钮：scene1-btn-step0 至 scene1-btn-step5, scene1-btn-prev, scene1-btn-next
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
- 响应式：固定画布 800×500，不随窗口缩放（教学图示通常全屏或固定尺寸展示）
