[图示主题与整合说明]
- 本图示主题：正三棱柱晶胞堆积方式与分摊系数几何解释
- 整合的内容：顶点共享示意（12 个晶胞共享 1 个顶点）+ 棱上共享示意（6 个晶胞共享 1 条棱）+ 体心独占示意
- 教学价值：教师可通过切换三种状态，直观展示晶体中不同位置粒子的共享情况，帮助学生理解分摊系数的几何来源。状态 1 解释顶点 A 粒子为何分摊 1/12，状态 2 解释棱上 B 粒子为何分摊 1/6，状态 3 解释体心 C 粒子为何独占（分摊系数为 1）。

[分步序列]
多状态切换交互（3 个状态）：

- 初始状态（默认显示状态 1）：
  - 显示中心正三棱柱线框
  - 显示 6 个顶点 A 粒子、9 个棱上 B 粒子、1 个体心 C 粒子
  - 显示 11 个相邻晶胞（半透明灰色虚线），围绕上底面某一顶点分布
  - 该共享顶点用红色高亮（r=8px 填充圆）
  - 底部显示分摊系数「1/12」
  - 「顶点共享」按钮高亮（表示当前状态）

- 状态 2（点击「棱共享」按钮）：
  - 隐藏状态 1 的相邻晶胞和红色高亮顶点
  - 显示 5 个相邻晶胞（半透明灰色虚线），围绕某条侧棱分布
  - 该共享棱用绿色高亮（线宽 4px）
  - 底部显示分摊系数「1/6」
  - 「棱共享」按钮高亮

- 状态 3（点击「体心独占」按钮）：
  - 隐藏所有相邻晶胞和高亮元素
  - 仅显示单个中心正三棱柱
  - 体心 C 粒子用蓝色高亮（r=10px 填充圆）
  - 底部显示分摊系数「1」
  - 「体心独占」按钮高亮

[交互方案]
- 交互类型：多状态切换（3 个按钮）
- 控件说明：
  - 按钮 1「顶点共享」：位于 (180,460)，点击后显示 12 个晶胞共享一个顶点的堆积方式，高亮共享顶点，显示分摊系数 1/12
  - 按钮 2「棱共享」：位于 (340,460)，点击后显示 6 个晶胞共享一条棱的堆积方式，高亮共享棱，显示分摊系数 1/6
  - 按钮 3「体心独占」：位于 (500,460)，点击后仅显示单个晶胞，高亮体心粒子，显示分摊系数 1
- 教师操作流程：
  1. 初始展示状态 1，讲解顶点 A 粒子被 12 个晶胞共享，每个晶胞分摊 1/12
  2. 点击「棱共享」，讲解棱上 B 粒子被 6 个晶胞共享，每个晶胞分摊 1/6
  3. 点击「体心独占」，讲解体心 C 粒子完全属于该晶胞，分摊系数为 1
  4. 可反复切换对比三种情况

[技术实现]
- JS 库选择：原生 SVG（适合绘制几何线框结构，无需额外库）
- 画布尺寸：800×500px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +------------------------------------------+
  |                                          |
  |           正三棱柱堆积示意图              |
  |         (中心晶胞 + 相邻晶胞)             |
  |                                          |
  |              [三棱柱图形]                 |
  |           (根据状态显示不同内容)           |
  |                                          |
  |                                          |
  |              分摊系数：1/12              |
  |                                          |
  |   [A] [B] [C]  图例                       |
  |                                          |
  |   +----------+----------+----------+      |
  |   |顶点共享  |棱共享    |体心独占  |      |
  |   +----------+----------+----------+      |
  +------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用 currentState 变量跟踪当前状态（1/2/3），点击按钮时更新状态并重绘
  2. 三棱柱绘制：上底面三角形 + 下底面三角形 + 3 条侧棱；下底面后边用虚线表示被遮挡
  3. 相邻晶胞绘制：状态 1 需绘制 11 个围绕顶点的晶胞（可用旋转变换生成）；状态 2 需绘制 5 个围绕棱的晶胞
  4. 粒子位置计算：顶点坐标已知，棱中点 = (顶点 1+ 顶点 2)/2，体心 = 上下底面中心连线的中点
  5. 事件绑定：三个按钮分别绑定 click 事件，切换状态后调用 render() 函数重绘
  6. 按钮高亮：当前状态对应按钮添加 active 类（背景色加深）
- ID 命名规范：所有元素 ID 以 scene2- 为前缀，如 scene2-prism-center, scene2-particle-a1, scene2-btn-vertex 等
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
