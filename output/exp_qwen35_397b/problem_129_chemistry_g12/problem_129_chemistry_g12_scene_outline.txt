    **题目原文：**

    "长征"火箭发射使用的燃料是偏二甲肼(C₂H₈N₂)，并使用四氧化二氮作为氧化剂，这种组合的两大优点是既能在短时间内产生巨大能量将火箭送上太空，产物又不污染空气(产物都是空气成分)。某校外研究性学习小组拟将此原理设计为原电池，如图所示，结合学习过的电化学原理分析其设计方案，下列说法正确的是( )

    A. B为正极
    B. 从a口通入四氧化二氮气体
    C. 从d口排出的是NO气体
    D. A极发生的电极反应式：C₂H₈N₂－16e⁻＋8H₂O===CO₂＋N₂＋16H⁺

    **题目分析：**

    本题考查原电池原理的应用，核心是根据电子流向判断正负极，进而确定燃料和氧化剂的通入位置，写出正确的电极反应式。

    **关键信息提取：**
    1. 燃料：偏二甲肼(C₂H₈N₂) —— 在负极被氧化
    2. 氧化剂：四氧化二氮(N₂O₄) —— 在正极被还原
    3. 电解质：H₂SO₄（酸性环境）
    4. 电子流向：从B极经外电路流向A极 → B为负极，A为正极
    5. 产物为空气成分：CO₂、N₂、H₂O

    **整体讲解思路：**
    1. 首先根据电子流向判断正负极
    2. 确定燃料和氧化剂分别从哪个口通入
    3. 分析正负极的电极反应式
    4. 验证各选项的正确性

    **图示规划说明：**

    - SCENE_2：电极反应式推导，展示正负极半反应及总反应式

    **本图示教学说明：**

    **引导学生观察顺序：**

    1. **第一步：判断正负极**
       - 提问：电子从哪个电极流出？
       - 观察：外电路中e⁻箭头从B指向A
       - 结论：电子从负极流出，故B为负极，A为正极

    2. **第二步：确定物质通入位置**
       - 原理：燃料在负极被氧化，氧化剂在正极被还原
       - 结论：偏二甲肼(C₂H₈N₂)从b口通入B极，四氧化二氮(N₂O₄)从a口通入A极

    3. **第三步：分析离子移动**
       - 原理：原电池中阳离子向正极移动
       - 观察：H⁺从B侧向A侧移动

    4. **第四步：确定产物排出**
       - 负极产物：C₂H₈N₂被氧化生成CO₂、N₂，从c口排出
       - 正极产物：N₂O₄被还原生成H₂O，从d口排出

    **选项分析要点：**
    - A选项：B为正极 → 错误（B为负极）
    - B选项：从a口通入四氧化二氮 → 正确（A为正极，氧化剂在正极反应）
    - C选项：从d口排出NO → 错误（题目明确产物不污染空气，NO有毒）
    - D选项：电极反应式 → 需进一步验证配平

    **本图示教学说明：**

    **负极反应式推导（重点验证选项D）：**

    1. **确定反应物和产物**
       - 反应物：C₂H₈N₂（燃料在负极被氧化）
       - 产物：CO₂、N₂、H⁺（酸性环境）

    2. **配平步骤**
       - C原子：C₂H₈N₂ → 2CO₂（2个C）
       - N原子：C₂H₈N₂ → N₂（2个N）
       - O原子：2CO₂需4个O，需4H₂O提供 → 但实际需8H₂O（考虑H平衡）
       - H原子：C₂H₈N₂有8个H，8H₂O有16个H，共24个H → 生成16H⁺（剩余8个H与O结合成8H₂O中的8个H...）

    3. **正确配平**
       - C₂H₈N₂ + 8H₂O → 2CO₂ + N₂ + 16H⁺ + 16e⁻
       - 检查：C(2=2)、N(2=2)、H(8+16=24，16H⁺中16+8H₂O中8=24)、O(8=4+4)、电荷(0=16-16)✓

    4. **选项D分析**
       - 选项D写的是：C₂H₈N₂－16e⁻＋8H₂O===CO₂＋N₂＋16H⁺
       - 错误：CO₂系数应为2，不是1
       - 故D选项错误

    **正极反应式：**
    N₂O₄ + 8H⁺ + 8e⁻ → N₂ + 4H₂O

    **总反应式：**
    C₂H₈N₂ + 2N₂O₄ → 3N₂ + 2CO₂ + 4H₂O

    **正确答案：B**

    **课堂讲解建议：**
    - 强调电子流向是判断正负极的关键依据
    - 提醒学生注意题目条件"产物不污染空气"，排除NO等有毒气体
    - 电极反应式配平时要同时检查原子守恒和电荷守恒
    - 选项D的陷阱在于CO₂系数错误，需仔细核对
