[图示主题与整合说明]
- 本图示主题：两个弹簧测力计连接的整体受力分析
- 整合的内容：测力计连接方式展示、A 的读数标注、中间相互作用力分析、B 的读数推导、两端手的拉力分析
- 教学价值：教师可使用此图示逐步展示牛顿第三定律在弹簧测力计中的应用，通过分步动画让学生理解力的传递原理——当两个测力计串联时，相互作用力大小相等，因此两测力计读数相同，且两端拉力也等于该读数

[分步序列]
- 初始状态（步骤 0）：显示两个测力计轮廓（A 和 B 外框、弹簧、圆环、挂钩），显示标签"A"、"B"、"甲"、"乙"，显示左右拉力箭头（灰色，透明度 50%）
- 步骤 1：点击「下一步」→ 在测力计 A 上方显示绿色读数框"8N"，A 外框高亮（边框加粗）
- 步骤 2：点击「下一步」→ 中间挂钩处高亮显示（红色圆圈），显示两个红色相互作用力箭头（A 对 B 向右、B 对 A 向左），显示"相互作用力"标注
- 步骤 3：点击「下一步」→ 在测力计 B 上方显示绿色读数框"8N"，B 外框高亮
- 步骤 4：点击「下一步」→ 左右拉力箭头变为蓝色实线，显示"F_左=8N"和"F_右=8N"标注
- 步骤 5（结论）：点击「下一步」→ 显示答案框"答案：A (8N, 8N)"，所有元素完整显示

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于控件栏左侧，点击返回上一状态
  - 「下一步」按钮：位于控件栏右侧，点击进入下一状态
  - 步骤指示器：显示当前步骤/总步骤数（如"步骤 2/5"）
- 教师操作流程：
  1. 初始状态展示两个测力计连接的基本结构
  2. 点击「下一步」标注 A 的读数 8N，引导学生思考 B 的读数
  3. 点击「下一步」高亮中间挂钩，讲解牛顿第三定律——相互作用力大小相等
  4. 点击「下一步」显示 B 的读数，验证学生猜想
  5. 点击「下一步」标注两端拉力，说明整体受力平衡
  6. 点击「下一步」显示答案，完成讲解

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（矩形、圆形、折线、箭头），无需复杂库；原生 SVG 便于精确控制每个元素的状态和动画
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +----------------------------------------------------------+
  |                    [读数框 A]    [读数框 B]               |
  |                      8N          8N                      |
  |                        A           B                      |
  |   ←F_左  [====测力计 A====]--[测力计 B====]  F_右→        |
  |                        甲           乙                     |
  |                        [相互作用力 F=8N]                  |
  |                                                           |
  |                    [答案框：A (8N, 8N)]                   |
  |                                                           |
  |              [◀上一步]    步骤 2/5    [下一步▶]           |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-5），每个状态对应一组可见元素
  2. 元素分组：将相关元素放入<g>组，通过 display/opacity 控制显示隐藏
  3. 动画效果：使用 CSS transition 实现淡入淡出（opacity 0→1，duration 300ms）
  4. 按钮事件：绑定 click 事件，更新 currentState，调用 updateScene() 刷新显示
  5. 边界处理：步骤 0 时禁用「上一步」，步骤 5 时禁用「下一步」
- ID 命名规范：所有元素 ID 以 scene1- 为前缀
  - scene1-springA、scene1-springB（测力计外框）
  - scene1-labelA、scene1-labelB、scene1-labelJia、scene1-labelYi
  - scene1-readoutA、scene1-readoutB（读数框）
  - scene1-arrowLeft、scene1-arrowRight（拉力箭头）
  - scene1-interactionForce（相互作用力箭头组）
  - scene1-answerBox（答案框）
  - scene1-btnPrev、scene1-btnNext、scene1-stepIndicator（控件）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
