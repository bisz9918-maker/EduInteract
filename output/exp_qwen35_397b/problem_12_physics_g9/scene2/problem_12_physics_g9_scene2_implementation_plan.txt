[图示主题与整合说明]
- 本图示主题：隔离法受力分析——分别展示弹簧测力计 A 和 B 的受力情况
- 整合的步骤/概念：
  1. 隔离法基本原理（将系统拆分为独立研究对象）
  2. 测力计 A 的受力平衡分析
  3. 测力计 B 的受力平衡分析
  4. 作用力与反作用力对的识别（牛顿第三定律）
  5. 平衡方程与结论推导
- 教学价值：教师可通过分步展示，引导学生理解隔离法的核心思想——分别对每个物体进行受力分析，再结合牛顿第三定律得出整体结论。学生能直观看到"为什么两个测力计读数都是 8N"。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript
  - 原因：几何形状简单（矩形、箭头、文本），无需复杂库；原生实现轻量、加载快
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +----------------------------------------------------------+
  |                    A              B                      |
  |                  [====]         [====]                   |
  |   ←8N  [====]  →8N    ←8N  [====]  →8N                  |
  |     F_手对 A  F_B 对 A    F_A 对 B  F_手对 B              |
  |              <---作用力与反作用力--->                    |
  |                                                          |
  |        +----------------------------------+              |
  |        | 对 A: F_手对 A = F_B 对 A = 8N   |              |
  |        | 对 B: F_A 对 B = F_手对 B = 8N   |              |
  |        | ∴ B 读数 = 8N, 手拉力 = 8N       |              |
  |        +----------------------------------+              |
  |                                                          |
  |              [◀上一步]  2/5  [下一步▶]                   |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-4) 跟踪当前步骤，steps 数组存储每步应显示的元素 ID 列表
  2. 坐标计算：所有元素坐标硬编码于布局坐标表，箭头终点 = 起点 + 方向向量 × 长度
  3. 动画曲线：元素显示使用 CSS transition opacity 0.3s ease-in-out
  4. 事件绑定：按钮点击事件绑定到 stepChange 函数，更新 currentStep 并调用 renderStep()
  5. 元素显隐：每步 renderStep() 遍历所有元素，根据 steps[currentStep] 决定 display 属性
- ID 命名规范：所有交互元素 ID 必须以 scene2- 为前缀
  - scene2-box-a, scene2-box-b（隔离框）
  - scene2-arrow-hand-a, scene2-arrow-b-on-a（A 的受力箭头）
  - scene2-arrow-a-on-b, scene2-arrow-hand-b（B 的受力箭头）
  - scene2-label-8n-hand-a, scene2-label-8n-b-on-a 等（数值标注）
  - scene2-label-f-hand-a, scene2-label-f-b-on-a 等（力名称标签）
  - scene2-action-pair-line, scene2-action-pair-label（作用力对）
  - scene2-equation-box, scene2-equation-text-1/2/3（平衡方程）
  - scene2-btn-prev, scene2-btn-next, scene2-step-indicator（控件）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
