- 步骤2：点击「下一步」→ 新增显示2个CH₂基团框及其内部文字"—CH₂—"，每个CH₂显示2条价键线（左右各1条），显示价数标签"2价"，显示数量标签"×2"

- 步骤5：点击「下一步」→ 所有元素完整显示，各基团框轻微高亮（边框加粗或添加阴影效果），表示汇总完成

[标签冲突检查]
- 标签"×2"(CH₃)：坐标(140,160)
- 标签"×2"(CH₂)：坐标(400,160)
- 标签"×1"(CH)：坐标(620,160)
- 标签"×1"(Cl)：坐标(730,160)
- 标签"1价"(CH₃)：坐标(120,275)
- 标签"2价"(CH₂)：坐标(380,275)
- 标签"3价"(CH)：坐标(620,275)
- 标签"1价"(Cl)：坐标(730,275)
- 标题：坐标(400,40)

冲突检查：
- "×2"(CH₃)与"×2"(CH₂)：水平距离260px → 无冲突
- "×2"(CH₂)与"×1"(CH)：水平距离220px → 无冲突
- "×1"(CH)与"×1"(Cl)：水平距离110px → 无冲突
- "1价"(CH₃)与"2价"(CH₂)：水平距离260px → 无冲突
- "2价"(CH₂)与"3价"(CH)：水平距离240px → 无冲突
- "3价"(CH)与"1价"(Cl)：水平距离110px → 无冲突
- 上方数量标签行(y=160)与下方价数标签行(y=275)：垂直距离115px → 无冲突
- 所有标签与基团框(y=180-230)：最近距离20px（数量标签）和45px（价数标签）→ 无冲突

结论：所有标签间距均≥20px，无重叠冲突。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于(250,460)，点击后回退到前一状态，步骤0时禁用
  - 「下一步」按钮：位于(450,460)，点击后进入下一状态，步骤5时禁用
  - 步骤指示器：位于(380,465)，显示当前步骤"步骤 X/5"
- 教师操作流程：
  1. 初始状态仅显示标题，教师可介绍本节课要分析的基团组成
  2. 点击「下一步」展示CH₃基团，讲解甲基是1价基团，只能连接1个其他原子/基团
  3. 继续点击展示CH₂，讲解亚甲基是2价基团，可连接2个其他原子/基团
  4. 展示CH，讲解次甲基是3价基团，可连接3个其他原子/基团
  5. 展示Cl，讲解氯原子是1价
  6. 最后汇总所有基团，为后续分析同分异构体做铺垫
  7. 教师可随时点击「上一步」回退复习某个基团

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：本场景为简单几何图形（矩形、线段、文本），无需复杂库；原生 SVG 可精确控制坐标，便于分步显示/隐藏
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [800 × 500 画布]
  +--------------------------------------------------+
  |              基团组成及价键规则                   | y=40
  |                                                  |
  |  [CH₃] [CH₃]  [CH₂] [CH₂]  [CH]     [Cl]         | y=180-230
  |    ×2           ×2        ×1       ×1            | y=160
  |     |     |      ||  ||     |||       |          | y=230-255
  |    1价         2价       3价      1价            | y=275
  |                                                  |
  |                                                  |
  |                                                  |
  |                                                  |
  |                                                  |
  |                                                  |
  |                                                  |
  |                                                  |
  |              [◀上一步] 步骤X/5 [下一步▶]          | y=460-485
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-5) 跟踪当前步骤
  2. 元素分组：将同一步骤显示的元素放入同一 SVG <g> 组，用 display 属性控制显示/隐藏
  3. 按钮状态：步骤0时禁用「上一步」，步骤5时禁用「下一步」
  4. 动画效果：元素出现时使用淡入效果（opacity 0→1，transition 300ms）
  5. 事件绑定：按钮点击事件绑定到 stepChange 函数，更新 currentStep 并刷新显示
- ID 命名规范：
  - 所有交互元素 ID 以 scene1- 为前缀
  - 示例：scene1-ch3-group1, scene1-ch3-group2, scene1-ch2-group1, scene1-ch2-group2, scene1-ch-group, scene1-cl-group
  - 按钮：scene1-btn-prev, scene1-btn-next, scene1-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
