[图示主题与整合说明]
- 本图示主题：异戊烷碳骨架及氯原子可能取代位置
- 整合内容：展示异戊烷（2-甲基丁烷）碳骨架结构，分步高亮标注 4 个可能的氯取代位置

[分步序列]
- 初始状态（步骤 0）：显示完整碳骨架结构（CH₃-CH(CH₃)-CH₂-CH₃），4 个碳原子编号 C₁-C₄，分支甲基用绿色#2e7d32 标注
- 步骤 1：显示取代位置①圆圈（左端 CH₃），在圆圈左侧显示 Cl 虚线框，表示该位置 H 可被 Cl 取代
- 步骤 2：隐藏步骤 1 的 Cl 框，显示取代位置②圆圈（分支 CH），在圆圈上方显示 Cl 虚线框
- 步骤 3：隐藏步骤 2 的 Cl 框，显示取代位置③圆圈（中间 CH₂），在圆圈下方显示 Cl 虚线框
- 步骤 4：隐藏步骤 3 的 Cl 框，显示取代位置④圆圈（右端 CH₃），在圆圈右侧显示 Cl 虚线框
- 步骤 5（汇总）：同时显示 4 个取代位置圆圈（①②③④），Cl 虚线框隐藏，底部显示文字"共 4 种位置异构"

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 内底部左侧 (x=350, y=455)，宽 100px，高 30px
  - 「下一步」按钮：位于 SVG 内底部右侧 (x=450, y=455)，宽 100px，高 30px
  - 步骤指示器：位于两按钮之间，显示"步骤 X/5"
- 教师操作流程：
  1. 初始展示碳骨架，讲解异戊烷结构特点
  2. 点击「下一步」逐步高亮每个取代位置，讲解该位置氢原子被氯取代后的产物
  3. 可随时点击「上一步」回退复习
  4. 最后汇总 4 种位置异构体，得出答案

[技术实现]
- JS 库选择：原生 SVG（简单几何图形和文本，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +------------------------------------------+
  |                                          |
  |              分支 CH₃ (绿色)              |
  |                 |                        |
  |    ①    ②    ③    ④                     |
  |   (○)   (○)   (○)   (○)                  |
  |    |     |     |     |                   |
  |   CH₃—CH—CH₂—CH₃   (碳骨架主链)          |
  |    |     |     |     |                   |
  |    C₁    C₂    C₃    C₄   (碳编号)        |
  |                                          |
  |                                          |
  |         [◀上一步] 步骤 X/5 [下一步▶]      |
  +------------------------------------------+
  ```
- 关键实现要点：
  - 状态机设计：用变量 currentStep (0-5) 跟踪当前步骤
  - 每个步骤对应一组元素的显示/隐藏状态
  - 取代位置圆圈用<circle>元素，Cl 示意框用<rect>元素（stroke-dasharray 实现虚线）
  - 按钮点击事件更新 currentStep，调用 renderStep() 重绘对应元素
  - 步骤 5 汇总时显示所有圆圈，隐藏 Cl 框
- ID 命名规范：
  - 碳骨架：scene2-skeleton-main, scene2-skeleton-branch
  - 碳原子标签：scene2-c1-label, scene2-c2-label, scene2-c3-label, scene2-c4-label
  - 碳编号：scene2-c1-num, scene2-c2-num, scene2-c3-num, scene2-c4-num
  - 取代位置圆圈：scene2-pos1-circle, scene2-pos2-circle, scene2-pos3-circle, scene2-pos4-circle
  - 取代位置编号：scene2-pos1-num, scene2-pos2-num, scene2-pos3-num, scene2-pos4-num
  - Cl 示意框：scene2-cl-box（动态更新位置）
  - 按钮：scene2-btn-prev, scene2-btn-next, scene2-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
