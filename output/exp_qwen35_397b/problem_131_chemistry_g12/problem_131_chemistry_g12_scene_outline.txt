    **题目原文：**

    如图所示，将两烧杯用导线如图相连，Pt、Cu、Zn、C 分别为四个电极，当闭合开关后，则以下叙述正确的是 (  )

    A. C 电极为电解池的阳极
    B. Cu 电极附近 OH⁻ 浓度增大
    C. Na⁺ 移向 Pt 电极
    D. Pt 电极上有 O₂ 生成

    **题目分析：**

    本题考察原电池与电解池的组合装置判断。关键步骤：
    1. 判断哪个烧杯是原电池，哪个是电解池
    2. 确定各电极的极性（正/负极或阳/阴极）
    3. 分析电极反应和离子移动方向

    **整体讲解思路：**

    右侧烧杯（Zn-C-稀 H₂SO₄）中，Zn 是活泼金属，能自发与稀硫酸反应，构成**原电池**；左侧烧杯（Pt-Cu-NaCl 溶液）需要外接电源才能工作，构成**电解池**。

    原电池中：Zn 为负极（失电子），C 为正极（H⁺得电子）
    电解池中：Pt 连接原电池正极→阳极，Cu 连接原电池负极→阴极

    **图示规划说明：**

    共设计 2 个图示：
    - Scene 1：装置整体结构，展示原电池/电解池判断、电子流向、离子移动
    - Scene 2：四电极反应详解，分步展示各电极的电极反应式及产物
    </TEXT_1>

    **Scene 1 教学说明：**

    本图示帮助学生建立对组合装置的整体认识。教师应引导学生按以下顺序观察：

    1. **识别装置类型**：右侧 Zn 能与稀 H₂SO₄ 自发反应（Zn + 2H⁺ → Zn²⁺ + H₂↑），故为原电池；左侧 NaCl 溶液与 Pt、Cu 不发生自发反应，需外接电源，故为电解池。

    2. **判断电极极性**：
       - 原电池：Zn（负极，失电子），C（正极，H⁺得电子）
       - 电解池：Pt 连接原电池正极→阳极，Cu 连接原电池负极→阴极

    3. **电子流向**：外电路中电子从负极（Zn）流出，经导线流向阳极（Pt）；从阴极（Cu）流回正极（C）。

    4. **离子移动**：电解池中阳离子（Na⁺）移向阴极（Cu），阴离子（Cl⁻）移向阳极（Pt）。

    **关键公式：**

    原电池负极反应：Zn - 2e⁻ → Zn²⁺

    原电池正极反应：2H⁺ + 2e⁻ → H₂↑

    <TEXT_3>
    **Scene 2 教学说明：**

    本图示详细展示四个电极的反应，教师应逐一讲解：

    **1. Zn 电极（原电池负极）：**

    反应式：Zn - 2e⁻ → Zn²⁺

    现象：Zn 电极逐渐溶解

    **2. C 电极（原电池正极）：**

    反应式：2H⁺ + 2e⁻ → H₂↑

    现象：C 电极表面有气泡产生（H₂）

    **3. Pt 电极（电解池阳极）：**

    反应式：2Cl⁻ - 2e⁻ → Cl₂↑

    现象：Pt 电极表面有气泡产生（Cl₂），不是 O₂

    **4. Cu 电极（电解池阴极）：**

    反应式：2H₂O + 2e⁻ → H₂↑ + 2OH⁻

    现象：Cu 电极表面有气泡产生（H₂），同时电极附近 OH⁻ 浓度增大

    **选项判断：**

    - A. C 电极为电解池的阳极 → **错误**，C 是原电池的正极
    - B. Cu 电极附近 OH⁻ 浓度增大 → **正确**，阴极 H⁺放电，水的电离平衡右移
    - C. Na⁺ 移向 Pt 电极 → **错误**，阳离子移向阴极（Cu 电极）
    - D. Pt 电极上有 O₂ 生成 → **错误**，Cl⁻ 优先放电生成 Cl₂

    **答案：B**
