    **题目原文：**

    鸦片具有复杂的组成，其中的罂粟碱的分子结构如下：鸦片最早用于药物（有止痛、止泻、止咳作用），长期服用会成瘾，使人体质衰弱，精神颓废．已知该物质的燃烧产物为 CO₂、H₂O 和 N₂，1mol 该化合物完全燃烧消耗 O₂ 的物质的量及在一定条件下与 Br₂ 发生苯环取代反应生成的一溴代物同分异构体的种数分别是（  ）

    A．23.25 mol；5    B．24.5mol；7    C．24.5mol；8    D．26.5mol；6

    **题目分析：**

    本题考查有机化学中的两个核心知识点：
    1. 有机物燃烧耗氧量的计算——需要根据分子结构确定分子式，然后配平燃烧反应方程式
    2. 苯环上取代反应的同分异构体数目——需要识别分子中有几个苯环，每个苯环上有几个可被取代的氢原子

    **整体讲解思路：**

    第一步：从分子结构图出发，引导学生识别分子中的各个结构单元（异喹啉环系统、苯环、甲氧基、亚甲基桥）

    第二步：通过分步计数确定分子式 C₂₀H₂₁NO₄

    第三步：配平燃烧反应方程式，计算耗氧量

    第四步：分析苯环上可取代的氢原子位置，确定一溴代物同分异构体种数

    **原子计数引导：**

    异喹啉环部分（含左侧苯环上的 2 个甲氧基）：
    - 碳原子：9C（稠环）+ 2C（甲氧基）= 11C
    - 氢原子：苯环剩余 2H + 杂环 3H + 甲氧基 6H = 11H
    - 氮原子：1N
    - 氧原子：2O

    右侧部分（苯环 + 亚甲基 + 2 个甲氧基）：
    - 碳原子：6C（苯环）+ 1C（亚甲基）+ 2C（甲氧基）= 9C
    - 氢原子：苯环剩余 3H + 亚甲基 2H + 甲氧基 6H = 11H
    - 氧原子：2O

    总计：C₂₀H₂₁NO₄

    **教学说明：燃烧耗氧量计算**

    本图示展示有机物燃烧反应方程式的配平过程和耗氧量计算。

    **燃烧反应通式：**

    有机物 CₓHᵧNₘOₙ 完全燃烧的通式为：

    CₓHᵧNₘOₙ + (x + y/4 - n/2)O₂ → xCO₂ + (y/2)H₂O + (m/2)N₂

    **本题具体推导：**

    1. 写出反应框架：C₂₀H₂₁NO₄ + xO₂ → aCO₂ + bH₂O + cN₂

    2. 根据 C 原子守恒：a = 20

    3. 根据 H 原子守恒：2b = 21，得 b = 10.5

    4. 根据 N 原子守恒：2c = 1，得 c = 0.5

    5. 根据 O 原子守恒：左侧 O 原子数 = 4 + 2x，右侧 O 原子数 = 20×2 + 10.5×1 = 50.5

    6. 列方程：4 + 2x = 50.5，解得 x = 23.25

    **结论：** 1mol 罂粟碱完全燃烧消耗 23.25 mol O₂

    **教学说明：苯环取代位点分析**

    本图示用于分析罂粟碱分子中苯环上可发生溴代反应的氢原子位置。

    **关键概念：**

    苯环上的氢原子可以被溴原子取代，但已被其他基团（如甲氧基、亚甲基）占据的位置不能发生取代。

    **左侧异喹啉的苯环部分：**

    - 该苯环有 6 个碳原子位置
    - 其中 2 个碳与杂环稠合（无氢原子）
    - 2 个碳被甲氧基（-OCH₃）占据
    - 剩余 2 个碳上有氢原子，可被溴取代 → 2 种位置

    **右侧苯环部分：**

    - 该苯环有 6 个碳原子位置
    - 1 个碳连接亚甲基桥
    - 2 个碳被甲氧基（-OCH₃）占据
    - 剩余 3 个碳上有氢原子，可被溴取代 → 3 种位置

    **总计：** 2 + 3 = 5 种一溴代物同分异构体

    **最终答案：** A．23.25 mol；5
