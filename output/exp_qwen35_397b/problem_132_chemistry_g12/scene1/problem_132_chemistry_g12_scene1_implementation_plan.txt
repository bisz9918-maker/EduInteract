[图示主题与整合说明]
- 本图示主题：罂粟碱分子结构拆解与官能团识别
- 整合的内容：分子整体结构展示、各结构单元标注、原子计数引导三个认知阶段
- 教学价值：教师可使用此图示引导学生从整体到局部逐步识别罂粟碱分子结构，通过分步高亮不同区域帮助学生理解分子组成，最终推导分子式。适合课堂讲解有机化合物结构分析，教师可控制讲解节奏，随时回退复习。

[视觉元素清单]
- 分子骨架主线：黑色实线 2px，绘制所有化学键
- 异喹啉环系统：由两个稠合六元环组成，左侧苯环+右侧含氮杂环
- 右侧苯环：独立六元环，通过亚甲基桥连接
- 亚甲基桥：单键线段连接左右两部分
- 4 个甲氧基：-OCH₃ 基团，用短线表示 C-O 键，标签标注 OCH₃
- 氮原子：用字母 N 标注在异喹啉环的杂环位置
- 高亮区域：半透明色块覆盖对应结构区域
- 原子计数标签：步骤 4 显示各部分 C、H、N、O 原子数
- 最终分子式：C₂₀H₂₁NO₄，步骤 5 显示
- 颜色规格：
  - 分子骨架主线：#000000 实线 2px
  - 异喹啉环高亮：#1565c0 填充透明度 20%
  - 右侧苯环高亮：#2e7d32 填充透明度 20%
  - 甲氧基高亮：#c62828 红色圆圈
  - 亚甲基桥高亮：#888888 灰色虚线边框
  - 原子计数标签：使用对应区域颜色
  - 最终分子式：#000000 粗体
  - 背景：#ffffff

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 内底部左侧 (450,460)，点击回退到上一状态
  - 「下一步」按钮：位于 SVG 内底部右侧 (550,460)，点击进入下一状态
  - 步骤指示器：位于底部中央 (400,465)，显示「步骤 X/5」
- 教师操作流程：
  1. 初始展示完整分子结构，让学生观察整体
  2. 点击「下一步」高亮异喹啉环，讲解左侧稠环系统
  3. 点击「下一步」高亮右侧苯环和亚甲基桥，讲解连接方式
  4. 点击「下一步」标注 4 个甲氧基，讲解官能团分布
  5. 点击「下一步」显示原子计数，引导学生计算各部分原子数
  6. 点击「下一步」显示最终分子式，验证计算结果
  7. 可随时点击「上一步」回退复习特定结构

[技术实现]
- JS 库选择：原生 SVG（分子结构为静态几何图形，SVG 最适合绘制化学键线式，支持路径、多边形、文本等元素）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |         分子结构（居中，y=150-350）              |
  |    [异喹啉环]=====[CH₂]=====[苯环]              |
  |       (左)            (中)        (右)           |
  |                                                  |
  |   [甲氧基标签]                      [甲氧基标签] |
  |                                                  |
  |              [原子计数汇总区 y=380-430]          |
  |                                                  |
  |         [分子式 C₂₀H₂₁NO₄ y=450]                 |
  |                                                  |
  |   [◀上一步]  [步骤 X/5]  [下一步▶]  y=460       |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-5），数组存储各状态配置
  2. 分子骨架路径：使用 SVG <path> 绘制化学键，精确计算各顶点坐标
  3. 高亮区域：使用 <rect> 或 <polygon> 配合 fill-opacity="0.2" 实现半透明效果
  4. 甲氧基圆圈：使用 <circle> 元素，步骤 3 时显示
  5. 原子计数文本：步骤 4 时动态生成 <text> 元素，按区域着色
  6. 分子式：步骤 5 时显示，使用 <tspan> 实现下标效果
  7. 按钮事件：绑定 click 事件，更新 currentState，调用 render() 重绘
  8. 按钮禁用状态：步骤 0 时禁用「上一步」，步骤 5 时禁用「下一步」
- ID 命名规范：所有元素 ID 以 scene1- 为前缀
  - scene1-molecule-skeleton（分子骨架）
  - scene1-isoquinoline-highlight（异喹啉高亮区）
  - scene1-benzene-highlight（苯环高亮区）
  - scene1-methylene-highlight（亚甲基高亮区）
  - scene1-methoxy-circle-1~4（4 个甲氧基圆圈）
  - scene1-label-isoquinoline（异喹啉标签）
  - scene1-label-benzene（苯环标签）
  - scene1-label-methylene（亚甲基标签）
  - scene1-label-methoxy-1~4（4 个甲氧基标签）
  - scene1-atom-count（原子计数区）
  - scene1-molecular-formula（分子式）
  - scene1-btn-prev（上一步按钮）
  - scene1-btn-next（下一步按钮）
  - scene1-step-indicator（步骤指示器）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
