[技术实现]
- JS 库选择：原生 SVG（简单几何和文字渲染足够，无需额外库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |           燃烧反应方程式配平 (标题 y=35)          |
  +--------------------------------------------------+
  |                                                  |
  |   C₂₀H₂₁NO₄ + xO₂ → aCO₂ + bH₂O + cN₂ (y=130)   |
  |                                                  |
  +--------------------------------------------------+
  |  步骤1:配平C  |  步骤3:配平N                      |
  |  a=20         |  c=0.5                            |
  |  步骤2:配平H  |  步骤4:计算O                      |
  |  b=10.5       |  O总数=50.5                       |
  +--------------------------------------------------+
  |        氧原子守恒方程：4 + 2x = 50.5             |
  |        2x = 46.5 → x = 23.25                     |
  |                    [耗氧量=23.25 mol]            |
  +--------------------------------------------------+
  |              [◀上一步]  4/7  [下一步▶]           |
  |              (控件栏 y=440~490)                  |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量（0-6），steps 数组存储每步的显示配置
  2. 坐标计算：所有元素使用绝对坐标，方程式元素横向排列间距约 80-100px
  3. 动画曲线：系数变化使用简单的 opacity 淡入效果（200ms）
  4. 事件绑定：按钮点击事件切换 currentStep，调用 render() 重绘
  5. 高亮逻辑：每步激活时，对应系数元素添加 highlight 类（蓝色粗体）
- ID 命名规范：所有交互元素 ID 必须以 scene2- 为前缀
  - scene2-title, scene2-equation, scene2-reactant, scene2-product-co2, scene2-product-h2o, scene2-product-n2
  - scene2-step1-label, scene2-step1-content, scene2-step2-label, scene2-step2-content
  - scene2-step3-label, scene2-step3-content, scene2-step4-label, scene2-step4-content
  - scene2-oxygen-equation, scene2-solution, scene2-result-box, scene2-result-text
  - scene2-btn-prev, scene2-btn-next, scene2-step-indicator
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
