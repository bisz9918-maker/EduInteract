    **题目原文：**

    标准状况下，密闭容器内分别充入空气和 H₂、O₂的混合气体在可移动的活塞两边，充入时体积如图所示，若将装置右边 H₂、O₂的混合气体点燃引爆，活塞先左弹，恢复至原温度后，活塞右滑最终停在容器的正中央，则原来 H₂、O₂的体积比最接近于（  ）

    ①2：7          ②5：4           ③4：5         ④7：2．

    A．①②    B．②④    C．③④    D．①③

    **题目分析：**

    本题是气体反应与压强平衡的综合问题。关键信息：
    - 初始状态：左边空气体积为 1 份，右边 H₂+O₂混合气体体积为 3 份
    - 反应：2H₂ + O₂ → 2H₂O（液态，标准状况下不占气体体积）
    - 最终状态：活塞停在中央，说明两边气体体积相等

    **整体讲解思路：**

    1. 首先分析初始状态的体积比例关系
    2. 理解活塞移动的物理意义（两边压强相等时平衡）
    3. 分析反应后气体体积的变化
    4. 分两种情况讨论：H₂过量或 O₂过量
    5. 列方程求解体积比

    **图示规划说明：**

    - Scene 1：初始状态与最终状态对比图，展示活塞位置变化和体积关系
    - Scene 2：两种过量情况的计算分析图，用条形图展示反应前后气体体积变化

    **教学说明：**

    本图示用于帮助学生建立直观的物理图像，理解活塞移动的本质是两边气体压强趋于平衡。

    **引导学生观察要点：**

    1. 初始状态：左右体积比为 1:3，此时两边压强相等（活塞静止）
    2. 点燃瞬间：反应放热使右边气体温度升高、体积膨胀，活塞向左移动
    3. 恢复温度后：由于 H₂和 O₂反应生成液态水，右边气体物质的量减少，压强降低，活塞向右滑动
    4. 最终平衡：活塞停在中央，说明两边气体体积相等，压强再次平衡

    **关键公式：**

    - 反应方程式：2H₂ + O₂ → 2H₂O(l)
    - 阿伏伽德罗定律：同温同压下，气体体积比等于物质的量之比
    - 设空气物质的量为 n，则初始右边混合气体物质的量为 3n

    <TEXT_3>
    **教学说明：**

    本图示用于详细展示两种情况的计算过程，帮助学生理解分类讨论的思路。

    **讲解要点：**

    **情况一：H₂过量（O₂完全反应）**

    1. 设 O₂体积为 x，则 H₂体积为 3-x
    2. 根据反应 2H₂ + O₂ → 2H₂O，消耗 H₂体积为 2x
    3. 剩余 H₂体积 = (3-x) - 2x = 3-3x
    4. 最终活塞居中，右边剩余气体体积 = 2（因为左边空气体积从 1 变为 2）
    5. 列方程：3-3x = 2，解得 x = 1/3
    6. H₂体积 = 3 - 1/3 = 8/3
    7. H₂:O₂ = (8/3):(1/3) = 8:1 ≈ 7:2（对应选项④）

    **情况二：O₂过量（H₂完全反应）**

    1. 设 H₂体积为 y，则 O₂体积为 3-y
    2. 根据反应 2H₂ + O₂ → 2H₂O，消耗 O₂体积为 y/2
    3. 剩余 O₂体积 = (3-y) - y/2 = 3-3y/2
    4. 最终活塞居中，右边剩余气体体积 = 2
    5. 列方程：3-3y/2 = 2，解得 y = 2/3
    6. O₂体积 = 3 - 2/3 = 7/3
    7. H₂:O₂ = (2/3):(7/3) = 2:7（对应选项①）

    **完整解答：**

    两种情况分别得到体积比 7:2 和 2:7，对应选项①和④，故答案为 D．①③

    - 强调反应后生成的是液态水，不占气体体积
    - 最后总结：本题综合考查气体反应、压强平衡和分类讨论思想
