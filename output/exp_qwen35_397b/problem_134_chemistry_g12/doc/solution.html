problem_134_chemistry_g12

场景导航：Scene 1 | Scene 2 | Scene 3

题目原文：

有机物烃 A、B 和 C 的结构如下图，下列有关说法正确的是

A．A 的二氯代物结构有两种

B．B 的分子式为 C₆H₁₂

C．与 C 互为同分异构体且属于芳香烃的有机物可能使酸性高锰酸钾溶液褪色

D．A、B、C 中只有 C 的最简式为 CH

题目分析：

本题考查烃的立体结构、分子式、最简式、二氯代物同分异构体、芳香烃性质等核心概念。

  • 物质 A：正四面体结构（四面体烷），4 个碳原子位于四面体顶点，每个碳连 1 个氢，分子式 C₄H₄
  • 物质 B：三棱柱结构（棱柱烷），6 个碳原子位于三棱柱顶点，每个碳连 1 个氢，分子式 C₆H₆
  • 物质 C：立方体结构（立方烷），8 个碳原子位于立方体顶点，每个碳连 1 个氢，分子式 C₈H₈

整体讲解思路：

  1. 首先展示三种烃的立体结构，帮助学生建立空间想象
  2. 分析每个分子的碳原子数、氢原子数，推导分子式和最简式
  3. 利用对称性分析 A 的二氯代物种类
  4. 找出 C 的芳香烃同分异构体，分析其化学性质

图示规划说明：

  • Scene 1：三种烃的立体结构对比（整合 A、B、C 的碳架结构、分子式、最简式）
  • Scene 2：四面体对称性与二氯代物分析（展示 A 的对称性，说明二氯代物只有一种）
  • Scene 3：C 的芳香烃同分异构体结构（苯乙烯结构及性质）
步骤 1/5

教学说明：

本图示用于帮助学生建立三种烃的空间结构认知，理解分子式与最简式的关系。

讲解要点：

  1. 引导学生观察三种结构的几何特征：A 是正四面体（4 顶点），B 是三棱柱（6 顶点），C 是立方体（8 顶点）
  2. 强调每个顶点代表一个碳原子，每个碳原子形成 4 个共价键（3 个 C-C 键 + 1 个 C-H 键）
  3. 推导分子式：数碳原子数 n，氢原子数也为 n（因为每个碳只连 1 个氢）
  4. 计算最简式：C₄H₄、C₆H₆、C₈H₈ 的最简式均为 CH，因此选项 D 错误

关键公式：

  • 最简式 = 分子式中各元素原子数的最简整数比
  • C₄H₄ → 4:4 = 1:1 → CH
  • C₆H₆ → 6:6 = 1:1 → CH
  • C₈H₈ → 8:8 = 1:1 → CH
1/5

教学说明：

本图示用于分析选项 A，帮助学生理解高度对称分子的二氯代物种类判断方法。

讲解要点：

  1. 正四面体具有高度对称性：4 个顶点完全等价，6 条棱也完全等价
  2. 一氯代物：由于 4 个氢原子位置等价，一氯代物只有 1 种
  3. 二氯代物：任选两个氢原子被氯取代，由于所有棱等价，任意两个顶点之间的距离相同，因此二氯代物也只有 1 种
  4. 结论：选项 A 说"有两种"是错误的

关键概念：

  • 对称性：分子中可通过旋转、反射等操作重合的原子位置称为等价位置
  • 等价位置上的取代产物相同
  • 正四面体：4 个顶点等价，6 条棱等价

教学说明：

本图示用于分析选项 C，帮助学生理解同分异构体概念和芳香烃的化学性质。

讲解要点：

  1. 同分异构体定义：分子式相同但结构不同的化合物
  2. 立方烷分子式 C₈H₈，寻找其芳香烃同分异构体
  3. 苯乙烯（C₆H₅-CH=CH₂）分子式也是 C₈H₈，含有苯环，属于芳香烃
  4. 苯乙烯含有碳碳双键，能被酸性高锰酸钾氧化，使溶液褪色
  5. 结论：选项 C 正确

关键公式：

  • 苯乙烯分子式验证：苯环 C₆H₅ + 乙烯基 C₂H₃ = C₈H₈ ✓
  • 碳碳双键氧化反应：C=C + KMnO₄（酸性）→ 氧化产物 + Mn²⁺（无色）

完整解答：

  • 选项 A：错误，A 的二氯代物只有 1 种（四面体高度对称）
  • 选项 B：错误，B 的分子式为 C₆H₆（6 个碳各连 1 个氢）
  • 选项 C：正确，苯乙烯是 C 的同分异构体且为芳香烃，含碳碳双键能使酸性高锰酸钾褪色
  • 选项 D：错误，A、B、C 的最简式均为 CH

答案：C
