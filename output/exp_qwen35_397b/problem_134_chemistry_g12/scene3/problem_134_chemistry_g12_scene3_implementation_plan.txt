[图示主题与整合说明]
- 本图示主题：立方烷（C）的芳香烃同分异构体——苯乙烯
- 整合的步骤/概念：整合了立方烷结构、苯乙烯结构、酸性高锰酸钾褪色反应示意
- 教学价值：教师可通过此图示对比展示立方烷与苯乙烯两种同分异构体（分子式均为 C₈H₈）的结构差异，并直观演示苯乙烯因含碳碳双键而能使酸性高锰酸钾溶液褪色的化学性质，帮助学生理解同分异构体概念及不饱和烃的氧化反应特性

[分步序列]
- 初始状态（步骤 0）：显示立方烷结构及其标签、分子式 C₈H₈
- 步骤 1（点击「苯乙烯」按钮）：隐藏立方烷，显示苯乙烯结构，苯环用蓝色加粗高亮，乙烯基碳碳双键用红色加粗高亮，显示标签"苯乙烯"和分子式 C₈H₈
- 步骤 2（点击「褪色反应」按钮）：保持苯乙烯结构显示，下方新增高锰酸钾褪色反应示意（左侧紫色溶液瓶→箭头→右侧无色溶液瓶），标注 KMnO₄(紫色) 和 Mn²⁺(无色)
- 教师可随时点击「立方烷」按钮返回步骤 0，或点击「苯乙烯」返回步骤 1

[交互方案]
- 交互类型：多状态切换（3 个状态按钮）
- 控件说明：
  - 按钮 1「立方烷」：显示立方烷 C₈H₈ 结构
  - 按钮 2「苯乙烯」：显示苯乙烯 C₈H₈ 结构，高亮苯环和碳碳双键
  - 按钮 3「褪色反应」：在苯乙烯基础上，下方显示高锰酸钾褪色反应示意
- 教师操作流程：
  1. 初始展示立方烷结构，讲解其立体碳架特点
  2. 点击「苯乙烯」，对比展示同分异构体结构差异，强调苯环和碳碳双键
  3. 点击「褪色反应」，演示苯乙烯因含碳碳双键可被酸性高锰酸钾氧化，溶液由紫色变为无色

[技术实现]
- JS 库选择：原生 SVG（适合绘制分子结构线框和简单几何图形，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |   [立方烷]              [苯乙烯]                 |
  |   (120,80)-(280,240)    (420,80)-(680,240)       |
  |                                                  |
  |   立方烷                苯乙烯                   |
  |   C₈H₈                  C₈H₈                     |
  |                                                  |
  |                    [状态 3 时显示]               |
  |   KMnO₄(紫色)  →→→→→→→→→  Mn²⁺(无色)            |
  |   [紫色溶液瓶]          [无色溶液瓶]             |
  |                                                  |
  |   [立方烷] [苯乙烯] [褪色反应]  ← 控件栏         |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  - 状态机设计：使用 currentState 变量 (0/1/2) 跟踪当前状态，每次切换时隐藏所有元素组后显示对应状态元素
  - 立方烷 3D 效果：前方面 4 条边用实线，后方面 4 条边中 2 条可见用实线、2 条被遮挡用虚线，连接前后面的 4 条边中 2 条可见用实线、2 条被遮挡用虚线
  - 苯乙烯结构：苯环为正六边形，乙烯基从苯环一个顶点延伸，碳碳双键用两条平行线表示
  - 动画过渡：状态切换时使用 opacity 淡入淡出（300ms）
  - 事件绑定：三个按钮分别绑定 click 事件，调用 updateState(n) 函数
- ID 命名规范：所有交互元素 ID 以 scene3- 为前缀（如 scene3-cubane、scene3-styrene、scene3-btn1 等）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
