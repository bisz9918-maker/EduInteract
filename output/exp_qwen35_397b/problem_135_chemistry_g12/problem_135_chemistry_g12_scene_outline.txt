    **题目原文：**

    用如图所示装置分别进行如下实验，测定溶液导电性变化．以下哪个选项为导电性先增大后减弱的为（  ）

    A．向醋酸溶液中加入氨水
    B．向 AgNO₃ 溶液中加入 HCl
    C．向盐酸溶液中加入 NaCl 溶液
    D．向 H₂SO₄ 溶液中加入 BaCl₂ 溶液

    **题目分析：**

    本题考查电解质溶液导电性与离子浓度的关系。溶液导电性取决于自由移动离子的浓度和离子所带电荷数。

    **解题思路：**

    1. 弱电解质 + 弱电解质 → 强电解质：离子浓度增大，导电性增强
    2. 继续加入过量试剂：溶液稀释或加入弱电解质，导电性可能减弱
    3. 强电解质 + 强电解质 → 沉淀 + 强电解质：离子浓度变化不大

    **图示规划说明：**

    - SCENE_1：溶液导电性原理示意，展示离子移动形成电流的微观机制
    - SCENE_2：四个选项反应前后离子变化对比，用柱状图展示离子浓度变化
    - SCENE_3：导电性变化曲线图，展示各选项导电性随加入量的变化趋势

    **正确答案：A**

    **教学要点：**

    1. 溶液导电的本质是自由移动离子的定向移动
    2. 阳离子向阴极移动，阴离子向阳极移动
    3. 离子浓度越大，导电性越强，灯泡越亮
    4. 弱电解质部分电离，离子浓度低；强电解质完全电离，离子浓度高

    **引导学生观察：**

    - 注意离子移动方向与电极极性的关系
    - 理解灯泡亮度反映离子浓度大小
    - 建立宏观现象（灯泡亮度）与微观本质（离子浓度）的联系

    **各选项分析：**

    **A. 醋酸 + 氨水（正确答案）**

    反应方程式：CH₃COOH + NH₃·H₂O → CH₃COONH₄ + H₂O

    1. 反应前：醋酸是弱电解质，部分电离，离子浓度低，导电性弱
    2. 反应中：生成醋酸铵是强电解质，完全电离，离子浓度显著增大，导电性增强
    3. 反应后继续加氨水：氨水是弱电解质，且溶液被稀释，导电性减弱
    4. 结论：导电性先增大后减弱 ✓

    **B. AgNO₃ + HCl**

    反应方程式：AgNO₃ + HCl → AgCl↓ + HNO₃

    1. 反应前后都是强电解质
    2. Ag⁺和 Cl⁻生成沉淀，但 H⁺和 NO₃⁻仍在溶液中
    3. 离子浓度变化不大，导电性基本不变

    **C. 盐酸 + NaCl**

    1. 两者都是强电解质
    2. 混合后离子浓度略有增加
    3. 导电性略有增强，但无"先增大后减弱"特征

    **D. H₂SO₄ + BaCl₂**

    反应方程式：H₂SO₄ + BaCl₂ → BaSO₄↓ + 2HCl

    1. 反应前后都是强电解质
    2. Ba²⁺和 SO₄²⁻生成沉淀，但生成 HCl
    3. 离子浓度变化不大，导电性基本不变
    </TEXT_3>

    **总结与课堂讲解建议：**

    **核心知识点：**

    1. 溶液导电性取决于自由移动离子的浓度
    2. 弱电解质→强电解质：导电性增强
    3. 强电解质→弱电解质或稀释：导电性减弱
    4. 沉淀反应不一定导致导电性显著变化（需看是否生成新的强电解质）

    **讲解流程建议：**

    1. 先用 SCENE_1 建立导电机理的微观认识
    2. 用 SCENE_2 逐一分析四个选项的离子变化
    3. 用 SCENE_3 直观展示导电性变化趋势，强化"先增大后减弱"的图像特征
    4. 引导学生归纳：弱 + 弱→强，过量稀释→弱的规律

    **易错点提醒：**

    - 不要只看是否有沉淀生成，要看反应前后离子总浓度变化
    - 注意区分"导电性不变"和"导电性先增大后减弱"
    - 氨水是弱电解质，过量加入会稀释溶液
