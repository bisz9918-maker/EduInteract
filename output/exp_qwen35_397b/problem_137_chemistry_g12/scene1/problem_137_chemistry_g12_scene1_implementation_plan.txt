[图示主题与整合说明]
- 本图示主题：有机化合物 A 的分子结构与官能团分析
- 整合的步骤/概念：分子结构展示、酯基识别、碳碳双键识别、手性碳定位、反应计量分析、选项判断
- 教学价值：教师可使用此图示逐步揭示有机分子的结构特征，从整体骨架到局部官能团，再到反应性质分析。分步导航允许教师灵活控制讲解节奏，随时回退复习关键概念，帮助学生建立"结构决定性质"的化学思维。

[分步序列]
- 初始状态（步骤0）：显示完整分子骨架结构（黑色线条），右侧信息框显示"步骤0：分子结构"，其他高亮元素隐藏
- 步骤1：点击「下一步」→ 显示3个红色高亮框标注酯基位置，右侧信息区显示"酯基×3"，其他高亮隐藏
- 步骤2：点击「下一步」→ 隐藏酯基高亮，显示4个蓝色高亮框标注碳碳双键位置，右侧信息区显示"双键×4"
- 步骤3：点击「下一步」→ 隐藏双键高亮，显示2个绿色圆点标记手性碳原子，右侧信息区显示"手性碳×2"
- 步骤4：点击「下一步」→ 隐藏手性碳标记，右侧信息区显示"H₂加成：4 mol（4个双键）"和"NaOH水解：3 mol（3个酯基）"
- 步骤5（结论）：点击「下一步」→ 显示分子式"C₂₁H₂₆O₆"，并汇总选项判断："A正确 B正确 C错误 D正确 → 答案：C"

  2. 点击下一步，引导学生识别酯基官能团（3个）

  5. 点击下一步，分析反应计量关系（H₂加成、NaOH水解）
  6. 点击下一步，汇总分子式和选项判断，得出答案C错误

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：分子结构为静态2D图形，无需复杂动画库；原生SVG可精确控制路径和形状；轻量无依赖
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +----------------------------------------------------------+
  |  [分子结构区 500×350]        |  [信息区 220×320]        |
  |                              |  分子式 C₂₁H₂₆O₆          |
  |     有机分子骨架              |  酯基×3                  |
  |     (黑色线条)               |  双键×4                  |
  |                              |  手性碳×2                |
  |                              |  H₂:4 mol                |
  |                              |  NaOH:3 mol              |
  |                              |  选项判断                |
  |                              |                          |
  +----------------------------------------------------------+
  |           [◀ 上一步]              [下一步 ▶]             |
  |              (y=450~485)                                  |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量 (0-5)，每个步骤对应一组显示/隐藏的元素
  2. 分子骨架路径：根据原图比例，将分子结构转换为 SVG path 的 M/L/C 命令序列
  3. 高亮区域：使用 <rect> 元素，通过 class 控制显示/隐藏和颜色
  4. 手性碳标记：使用 <circle> 元素，绿色填充
  5. 信息文本：使用 <text> 元素，动态更新内容
  6. 按钮事件：绑定 click 事件，更新 currentStep，调用 updateDisplay() 刷新视图
  7. 按钮状态：步骤0禁用上一步，步骤5禁用下一步（opacity:0.5, pointer-events:none）
- ID 命名规范：所有元素 ID 以 scene1- 为前缀
  - scene1-molecule-skeleton（分子骨架路径）
  - scene1-ester-highlight-1/2/3（酯基高亮框）
  - scene1-doublebond-highlight-1/2/3/4（双键高亮框）
  - scene1-chiral-mark-1/2（手性碳标记）
  - scene1-info-box（信息框）
  - scene1-info-text（信息文本）
  - scene1-btn-prev（上一步按钮）
  - scene1-btn-next（下一步按钮）
- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
