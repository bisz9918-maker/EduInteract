[交互方案]

  - 按钮 1「单倍体育种」：位于顶部左侧 (80,20)，激活时显示花药离体培养流程
  - 按钮 2「染色体加倍」：位于顶部中间 (290,20)，激活时显示秋水仙素加倍过程
  - 按钮 3「基因工程」：位于顶部右侧 (500,20)，激活时显示基因工程流程
- 教师操作流程：
  1. 默认展示状态 1，讲解花药离体培养获得单倍体的过程
  2. 点击按钮 2，对比展示染色体加倍原理，强调秋水仙素的作用机制
  3. 点击按钮 3，切换到基因工程，说明运载体（质粒）的作用
  4. 可反复切换对比，帮助学生区分染色体变异与基因重组

[技术实现]
- JS 库选择：原生 SVG（流程图简单，无需复杂库）
- 画布尺寸：800×500 px（固定）
- 布局草图：
  ```
  [800×500 画布]
  ┌────────────────────────────────────────────────────┐
  │  [按钮 1]    [按钮 2]    [按钮 3]                  │ y=20~50
  │                                                    │
  │           主图区（当前状态流程图）                   │ y=80~380
  │                                                    │
  │                                                    │
  │        ┌──────────────────────────────┐            │ y=420~470
  │        │      原理说明文字框            │            │
  │        └──────────────────────────────┘            │
  └────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentState(1/2/3) 跟踪当前激活状态
  2. 所有元素按状态分组，用 display:none 控制显示/隐藏
  3. 按钮点击事件切换 currentState，更新按钮高亮状态，更新原理框文字
  4. 动画：状态切换时可用淡入淡出（opacity 过渡 0.3s）
  5. ID 命名规范：所有元素 ID 以 scene3- 为前缀
     - 按钮：scene3-btn1, scene3-btn2, scene3-btn3
     - 状态 1 元素：scene3-s1-anther, scene3-s1-callus, scene3-s1-plant 等
     - 状态 2 元素：scene3-s2-cell1, scene3-s2-chromo1, scene3-s2-cell2 等
     - 状态 3 元素：scene3-s3-gene, scene3-s3-plasmid, scene3-s3-recombinant, scene3-s3-cabbage
     - 原理框：scene3-principle-box
  6. IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
  7. 按钮高亮：激活按钮添加 class="active"，CSS 设置蓝色边框#1565c0、背景#E3F2FD
  8. 原理框文字：用 scene3-principle-text 的 textContent 动态更新
