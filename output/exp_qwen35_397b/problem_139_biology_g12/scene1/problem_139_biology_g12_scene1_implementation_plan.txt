[图示主题与整合说明]

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于(250,455)，100×35px，点击返回上一状态
  - 「下一步」按钮：位于(450,455)，100×35px，点击进入下一状态
  - 状态指示器：显示当前步骤/总步骤（如"步骤 1/4"）
- 教师操作流程：
  1. 初始加载显示步骤0（仅基因A路径），教师讲解基因A如何控制紫色素合成
  2. 点击「下一步」显示步骤1，添加基因B路径，讲解基因B控制蓝色素合成
  3. 点击「下一步」显示步骤2，展示互作抑制机制，讲解A、B共存时mRNA结合导致酶无法合成
  4. 点击「下一步」显示步骤3，完整机制图，教师可回顾整体流程
  5. 教师可随时点击「上一步」回退复习特定环节

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript
  - 原因：本图示为流程图/示意图类型，元素数量适中（约20个），无需复杂坐标系或动画库
  - 原生 SVG 可精确控制每个元素的位置和样式，便于分步显示/隐藏
  - 无需引入外部库，加载速度快，代码简洁

- 画布尺寸：800 × 500 px（固定）

- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────┐
  │  [基因B]                    [基因A]                     │ y=50-90
  │     ↓①                        ↓①                        │ y=90-120
  │  [mRNA-B]    ×互作    [mRNA-A]                          │ y=130-160
  │     ↓②                        ↓②                        │ y=160-190
  │  [酶B]                      [酶A]                       │ y=200-240
  │     ↓                          ↓                         │ y=240-280
  │  酶B标注                    酶A标注                      │ y=285
  │     ↓                          ↓                         │
  │  ●蓝色  ←────  ●白色  ────→  ●紫色                      │ y=300
  │   色素        前体物质       色素                        │ y=335
  │                                                         │
  │                                                         │
  │              [◀上一步]          [下一步▶]                │ y=440-490
  └─────────────────────────────────────────────────────────┘
  ```

- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-3），数组存储每步应显示的元素ID列表
  2. 元素分组：按路径分组（geneA-path、geneB-path、interaction），便于批量显示/隐藏
  3. 动画效果：使用 CSS transition 实现淡入淡出，互作符号使用 keyframe 闪烁动画
  4. 事件绑定：按钮点击事件切换状态，更新按钮禁用状态（第一步禁用上一步，最后一步禁用下一步）
  5. ID 命名规范：所有元素 ID 以 scene1- 为前缀，如 scene1-geneA-box、scene1-mRNA-B、scene1-enzyme-A 等

- ID 命名规范示例：
  - scene1-geneA-box, scene1-geneB-box
  - scene1-arrow-1-A, scene1-arrow-1-B
  - scene1-label-1-A, scene1-label-1-B
