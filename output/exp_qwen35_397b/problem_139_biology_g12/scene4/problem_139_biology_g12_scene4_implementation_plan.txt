[图示主题与整合说明]

[分步序列]
- 初始状态（步骤 0）：显示标题和三个状态面板的框架，所有面板半透明显示，底部三个控件按钮可见但未激活
- 状态 1（点击"基因型 A_B_"按钮）：
  - 状态 1 面板高亮（不透明度 100%），状态 2、3 面板半透明（不透明度 40%）
  - 显示 A_B_ 基因型说明：白花植株基因型为 A_B_，B 基因原本被抑制
  - 花瓣示意图显示白色背景上的蓝色斑点
  - 突变箭头显示"B 基因获得功能"，指向花瓣
  - 说明文字：体细胞中 B 基因突变激活，局部合成酶 B，产生蓝色色素
- 状态 2（点击"基因型 aabb"按钮）：
  - 状态 2 面板高亮，状态 1、3 面板半透明
  - 显示 aabb 基因型说明：白花植株基因型为 aabb，无 A、B 基因功能
  - 花瓣示意图显示纯白色（无蓝色斑点可能）
  - 突变箭头显示"无突变可能"，灰色虚线
  - 说明文字：aabb 基因型无法通过单次突变产生蓝色斑点，需同时获得 A 和 B 功能
- 状态 3（点击"基因型 A_bb/aaB_"按钮）：
  - 状态 3 面板高亮，状态 1、2 面板半透明
  - 显示 A_bb 或 aaB_基因型说明：白花植株含单一功能基因
  - 花瓣示意图显示白色背景上的蓝色斑点
  - 突变箭头显示"A 基因失活或 B 基因激活"
  - 说明文字：A_bb 中 A 基因体细胞失活，或 aaB_中 B 基因激活，均可产生蓝色斑点

[交互方案]
- 交互类型：多状态切换（3 个按钮）
- 控件说明：
  - 按钮 1"基因型 A_B_"：位于 (120,450)，点击显示 A_B_基因型白花产生蓝色斑点的机制
  - 按钮 2"基因型 aabb"：位于 (310,450)，点击显示 aabb 基因型白花无法产生蓝色斑点的原因
  - 按钮 3"基因型 A_bb/aaB_"：位于 (500,450)，点击显示 A_bb 或 aaB_基因型白花产生蓝色斑点的机制
- 教师操作流程：
  1. 首先展示初始状态，介绍白花植株的三种可能基因型
  2. 点击按钮 1，讲解 A_B_基因型中 B 基因被抑制，体细胞突变可使 B 基因激活产生蓝色斑点
  3. 点击按钮 2，讲解 aabb 基因型缺乏 A、B 基因功能，单次突变无法产生蓝色斑点
  4. 点击按钮 3，讲解 A_bb 或 aaB_基因型中单一基因功能缺失/存在，突变可改变表型
  5. 可反复切换对比三种情况，强化学生对基因型与表型关系的理解

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript
  - 原因：本场景为静态图示切换，无需复杂动画或数据可视化，原生 SVG 足够实现且性能好
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |           基因突变导致花色斑点分析                | y=35
  +--------------------------------------------------+
  |  [状态 1: A_B_]           [状态 2: aabb]          | y=70-280
  |   基因型标签               基因型标签              |
  |   花瓣 (白底蓝斑)          花瓣 (纯白)             |
  |   突变说明                 突变说明                |
  +--------------------------------------------------+
  |  [状态 3: A_bb/aaB_]                              | y=290-400
  |   基因型标签  花瓣 (白底蓝斑)  突变说明            |
  +--------------------------------------------------+
  |  [基因型 A_B_] [基因型 aabb] [基因型 A_bb/aaB_]   | y=450
  |     按钮 1         按钮 2         按钮 3          |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量 (0/1/2/3) 跟踪当前激活状态
  2. 三个状态面板使用<g>分组，通过 opacity 控制显示/隐藏
  3. 按钮点击事件绑定：每个按钮点击时更新 currentState，调用 updateDisplay() 函数
  4. updateDisplay() 函数：根据 currentState 设置各面板 opacity，高亮当前按钮
  5. 花瓣斑点使用<clipPath>或<mask>实现局部蓝色区域
  6. 突变箭头使用<path>绘制，带箭头标记 (marker-end)
- ID 命名规范：
  - 所有元素 ID 以 scene4- 为前缀
  - 示例：scene4-panel1, scene4-panel2, scene4-panel3, scene4-petal1, scene4-spot1, scene4-btn1, scene4-btn2, scene4-btn3
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
