[图示主题与整合说明]
- 本图示主题：整体 (A+B) 水平受力分析——实验台与 B 之间静摩擦力的变化
- 整合的步骤/概念：初始状态受力分析 + 变化后受力分析 + 摩擦力大小比较
- 教学价值：教师可使用此图示逐步展示物理受力分析过程，通过分步导航控制讲解节奏，帮助学生理解整体法分析静摩擦力的方法。步骤 0 展示原装置，步骤 1 分析初始状态（左侧 2 钩码、右侧 3 钩码），步骤 2 分析变化后状态（左侧 1 钩码、右侧 3 钩码），步骤 3 对比得出结论（摩擦力增大）。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 (300,455)-(380,485)，点击后退到前一状态
  - 「下一步」按钮：位于 (420,455)-(500,485)，点击前进到下一状态
  - 步骤指示文本：位于 (400,440)，显示当前步骤"步骤 X/3"
- 教师操作流程：
  1. 加载后显示步骤 0（原装置图），教师介绍题目背景
  2. 点击「下一步」到步骤 1，讲解初始状态整体受力：左侧 2 钩码拉力 2G，右侧 3 钩码拉力 3G，净拉力向右 G，故静摩擦力 f₁向左大小 G
  3. 点击「下一步」到步骤 2，讲解变化后状态：左侧 1 钩码拉力 G，右侧仍 3G，净拉力向右 2G，故静摩擦力 f₂向左大小 2G
  4. 点击「下一步」到步骤 3，对比 f₁和 f₂，得出结论：f₂>f₁，摩擦力增大

[技术实现]
- JS 库选择：原生 SVG（简单几何图形和箭头，无需额外库）
- 画布尺寸：800×500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |              整体 (A+B) 水平受力分析              | y=35
  |                                                  |
  |    [左滑轮]====[A+B]====[右滑轮]                 | y=130-180
  |      ||                     ||                   |
  |     [钩码]                 [钩码]                | y=200-260
  |                                                  |
  |              初始状态          变化后            | y=260
  |                                                  |
  |           ←T 左  [A+B]  T 右→                    | y=280-330
  |              ←f₁/f₂                              | y=320-340
  |                                                  |
  |                    步骤 X/3                      | y=440
  |              [◀上一步] [下一步▶]                 | y=455-485
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-3) 跟踪当前步骤，steps 数组存储每步的显示配置
  2. 坐标计算：箭头终点 = 起点 + (方向单位向量 × 长度)，箭头头部用 polygon 绘制
  3. 动画曲线：使用 CSS transition 实现箭头淡入淡出（opacity 0→1，duration 300ms）
  4. 事件绑定：按钮 click 事件调用 stepForward()/stepBackward()，更新 DOM 元素 display 属性
  5. 钩码数量切换：步骤 2 时隐藏左侧下方钩码（id: scene1-hook-left-2）
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀
  - scene1-device-rect（装置图 A+B 矩形）
  - scene1-pulley-left/right（左右滑轮）
  - scene1-hook-left-1/2（左侧钩码）
  - scene1-hook-right-1/2/3（右侧钩码）
  - scene1-force-rect（受力分析矩形）
  - scene1-arrow-t-left/t-right/f1（步骤 1 箭头）
  - scene1-arrow-t-left-prime/t-right-prime/f2（步骤 2 箭头）
  - scene1-label-*（所有标签）
  - scene1-btn-prev/next（按钮）
  - scene1-step-indicator（步骤指示）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
