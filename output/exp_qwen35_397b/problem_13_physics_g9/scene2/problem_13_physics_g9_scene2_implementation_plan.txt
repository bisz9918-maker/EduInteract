[图示主题与整合说明]
- 本图示主题：木块 A 水平受力分析——A、B 之间静摩擦力的变化
- 整合的内容：初始状态 A 受力分析 + 变化后 A 受力分析 + 摩擦力大小比较
- 教学价值：教师可通过分步展示，让学生理解木块 A 在水平方向的受力平衡关系。初始状态左侧拉力为 2G，B 对 A 的静摩擦力向右也为 2G；取下 1 个钩码后拉力变为 1G，静摩擦力也变为 1G。通过对比条形图直观展示摩擦力减小的结论，帮助学生建立受力分析与平衡条件的联系。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 (280,455)，宽 80px，高 30px，点击后退到前一状态
  - 「下一步」按钮：位于 (440,455)，宽 80px，高 30px，点击前进到下一状态
  - 状态指示文本：位于 (400,460)，显示当前步骤说明
- 教师操作流程：
  1. 初始加载显示木块 A 隔离体，教师介绍研究对象
  2. 点击「下一步」展示初始受力，讲解左侧 2 个钩码产生 2G 拉力，A 静止故 f_AB=2G 向右
  3. 点击「下一步」展示变化后受力，讲解取下 1 个钩码后拉力变为 G，f_AB'=G
  4. 点击「下一步」展示条形图对比，直观得出摩擦力减小的结论
  5. 可随时点击「上一步」回退复习关键步骤

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript。理由：本场景为简单几何图形（矩形、箭头、文本），无需复杂库，原生 SVG 可精确控制坐标和样式，代码轻量易维护
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |              初始状态/变化后 标题                 | y=50
  |                                                  |
  |         ←T 左     [木块 A]     f_AB→             | y=80-160
  |         2G                    2G                 | y=100
  |                                                  |
  |         ←T 左'    [木块 A]     f_AB'→            | y=190-220
  |          G                     G                 | y=200
  |                                                  |
  |         摩擦力大小对比                           | y=290
  |         ┌────┐              ┌──┐                | y=320-400
  |         │    │              │  │                |
  |         │ 2G │              │G │                |
  |         └────┘              └──┘                |
  |                                                  |
  |         [◀上一步]    状态文本    [下一步▶]       | y=455
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-3) 跟踪当前步骤，数组 steps 定义每步显示的元素 ID 列表
  2. 坐标计算：所有元素坐标硬编码，确保精确对齐
  3. 动画曲线：箭头出现使用简单 fade-in（opacity 0→1，300ms），无需复杂动画
  4. 事件绑定：按钮点击事件绑定到 stepChange 函数，更新 currentStep 并调用 renderStep()
  5. 元素显隐：每步调用 renderStep() 时，遍历所有元素，根据 steps[currentStep] 决定 display 属性
- ID 命名规范：所有交互元素 ID 必须以 scene2- 为前缀（如 scene2-block-a、scene2-arrow-t-left、scene2-btn-next）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
