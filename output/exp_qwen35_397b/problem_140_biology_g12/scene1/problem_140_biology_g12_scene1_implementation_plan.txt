[图示主题与整合说明]
- 本图示主题：雄果蝇 M 的染色体与基因位置关系
- 整合的内容：染色体形态识别、基因位置标注、同源染色体判断、性染色体与常染色体区分
- 教学价值：教师可逐步展示果蝇四对染色体上的基因分布，从整体染色体组到局部基因定位，帮助学生理解伴性遗传、基因连锁等概念。通过高亮不同染色体对，学生可清晰区分性染色体与常染色体，观察基因在染色体上的具体位置。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 上一步按钮：位于 (320, 460)，点击后返回上一状态（步骤 0 时禁用）
  - 下一步按钮：位于 (420, 460)，点击后进入下一状态（步骤 5 时禁用）
  - 步骤指示器：位于 (520, 465)，显示当前步骤编号
- 教师操作流程：
  1. 初始展示完整染色体组，让学生观察整体结构
  2. 点击「下一步」高亮性染色体，讲解伴性遗传（E 基因在 X 染色体上）
  3. 点击「下一步」高亮 3-4 号染色体，讲解基因连锁（B/b 与 V/v 在同一对染色体上）
  4. 点击「下一步」高亮 5-6 号染色体，讲解 R/r 基因位置
  5. 点击「下一步」高亮点状染色体，说明 7-8 号无图示基因
  6. 点击「下一步」显示结论图例，总结四对染色体分布
  7. 可随时点击「上一步」回退复习

[技术实现]
- JS 库选择：原生 SVG
  - 原因：染色体为静态几何图形，无需复杂动画；SVG 路径可精确模拟染色体弯曲形态；标签定位精确；代码轻量
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×450]
  +--------------------------------------------------+
  |                    3       5                     |
  |                   / \     / \                    |
  |                  4   \   /   6                   |
  |                       \ /                        |
  |                    7   8                         |
  |                                                  |
  |                   /     \                        |
  |                  1       2                       |
  |                                                  |
  |          [基因标签分散在各染色体旁]               |
  +--------------------------------------------------+
  [控件栏 y=450~490]
  |  [◀上一步]  [下一步▶]  步骤 X/5                   |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量 (0-5)，每个步骤对应一组显示/隐藏的元素
  2. 染色体路径：使用 SVG <path> 元素，d 属性定义弯曲形态，通过改变 fill/stroke 颜色实现高亮
  3. 基因标记：使用 SVG <circle> 元素，初始 display="none"，按步骤显示
  4. 基因标签：使用 SVG <text> 元素，与标记点同步显示/隐藏
  5. 按钮事件：点击时更新 currentStep，调用 updateDisplay() 函数刷新视图
  6. 按钮状态：步骤 0 时禁用上一步，步骤 5 时禁用下一步（opacity=0.5, pointer-events=none）
- ID 命名规范：
  - 染色体：scene1-chrom-1, scene1-chrom-2, ..., scene1-chrom-8
  - 基因标记：scene1-gene-E, scene1-gene-B, scene1-gene-v, scene1-gene-b, scene1-gene-V, scene1-gene-R, scene1-gene-r
  - 基因标签：scene1-label-E, scene1-label-B, ...
  - 染色体编号：scene1-num-1, scene1-num-2, ...
  - 同源连线：scene1-homolog-34, scene1-homolog-56, scene1-homolog-78
  - 按钮：scene1-btn-prev, scene1-btn-next
  - 步骤指示器：scene1-step-indicator
- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染
- 颜色配置（CSS 变量或常量）：
  - COLOR_BASE = "#5d4037"
  - COLOR_SEX_HIGHLIGHT = "#1565c0"
  - COLOR_CHROM34_HIGHLIGHT = "#2e7d32"
  - COLOR_CHROM56_HIGHLIGHT = "#c62828"
  - COLOR_DOT_HIGHLIGHT = "#ff9800"
  - COLOR_GENE_DOT = "#ff9800"
  - COLOR_HOMOLOG_LINE = "#888888"
