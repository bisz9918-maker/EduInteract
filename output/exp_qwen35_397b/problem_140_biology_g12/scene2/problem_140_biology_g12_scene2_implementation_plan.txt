[图示主题与整合说明]
- 本图示主题：减数分裂异常导致 X^E X^e Y 个体形成的机制
- 整合的步骤/概念：亲本基因型 → 正常减数分裂过程 → 减数分裂 I 异常（同源染色体未分离）→ 减数分裂 II 异常（姐妹染色单体未分离）→ 异常配子形成 → 受精产生 X^E X^e Y 个体
- 教学价值：教师可通过分步演示，对比正常与异常减数分裂过程，帮助学生理解染色体数目变异的来源，解释子代中出现 X^E X^e Y 异常个体的两种可能原因（母本减 I 异常或父本减 I 异常）

[分步序列]
- 步骤 0（初始状态）：显示亲本信息
  - 显示：父本果蝇图标 (40,80)、母本果蝇图标 (40,200)
  - 显示：父本基因型 X^E Y (100,95)、母本基因型 X^e X^e (100,215)
  - 显示：P 标签 (25,70)
  - 显示：父本性染色体图示 (110-150,110-145)，标注 E 基因橙色点
  - 显示：母本性染色体图示 (110-150,230-265)，标注 e 基因绿色点
  - 步骤标题：「亲本基因型：父本 X^E Y × 母本 X^e X^e」

- 步骤 1：展示正常减数分裂过程
  - 新增：分裂箭头 (220,150)-(280,150)
  - 新增：正常减 I 细胞 (320,120)，内含复制后的 X 和 Y 染色体（各含两条姐妹染色单体）
  - 新增：正常减 II 细胞两个 (420,80) 含 X、(420,160) 含 Y
  - 新增：正常配子两个 (520,80) 含 X^E、(520,160) 含 Y
  - 步骤标题：「正常减数分裂：产生 X^E 和 Y 两种配子」

- 步骤 2：展示母本减数分裂 I 异常（同源染色体未分离）
  - 高亮：母本区域，红色边框#c62828
  - 新增：异常减 I 细胞 (320,280)，红色边框，内含两条 X 染色体未分离
  - 新增：异常减 II 细胞 (420,280)，红色边框
  - 新增：异常配子 (520,280)，红色边框，内含 X^e X^e
  - 标签：「同源染色体未分离」(320,320)
  - 步骤标题：「异常情况 1：母本减数分裂 I 同源染色体未分离」

- 步骤 3：展示异常配子与父本配子结合
  - 新增：受精箭头 (560,280)-(620,220) 从异常配子指向子代
  - 新增：子代细胞 (680,200)，内含 X^e X^e（来自母本异常配子）+ Y（来自父本）
  - 新增：子代基因型标签 X^e X^e Y (650,260)
  - 步骤标题：「异常配子 X^e X^e + 父本配子 Y → X^e X^e Y」

- 步骤 4：展示父本减数分裂 I 异常（另一种可能）
  - 隐藏步骤 2-3 的异常路径，显示父本异常路径
  - 高亮：父本区域，红色边框#c62828
  - 新增：异常减 I 细胞 (320,280)，红色边框，内含 X 和 Y 未分离
  - 新增：异常配子 (520,280)，红色边框，内含 X^E Y
  - 标签：「同源染色体未分离」(320,320)
  - 步骤标题：「异常情况 2：父本减数分裂 I 同源染色体未分离」

- 步骤 5：展示两种异常途径产生 X^E X^e Y
  - 同时显示两种异常途径
  - 途径 1：母本异常配子 X^e X^e + 父本 Y → X^e X^e Y（实际题目为 X^E X^e Y，需修正）
  - 途径 2：母本异常配子 X^e + 父本异常配子 X^E Y → X^E X^e Y
  - 子代细胞显示 X^E X^e Y，三条染色体分别标注 E(橙色)、e(绿色)、Y(红色)
  - 步骤标题：「结论：X^E X^e Y 个体形成的两种可能原因」

- 最终步骤：总结
  - 显示完整流程图
  - 高亮两条异常路径
  - 结论文本：「原因 1：母本减 I 异常产生 X^e X^e 配子；原因 2：父本减 I 异常产生 X^E Y 配子」

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位置 (280,455)，尺寸 80×35，灰色背景#9e9e9e，白色文字
  - 「下一步」按钮：位置 (440,455)，尺寸 80×35，蓝色背景#1565c0，白色文字
  - 步骤指示器：位置 (380,465)，显示「步骤 X/6」，灰色文字#666666
- 教师操作流程：
  1. 初始加载显示步骤 0（亲本基因型），教师讲解亲本杂交组合
  2. 点击「下一步」至步骤 1，展示正常减数分裂过程，对比异常路径
  3. 点击「下一步」至步骤 2，高亮母本减 I 异常，讲解同源染色体未分离
  4. 点击「下一步」至步骤 3，展示异常配子受精结果
  5. 点击「下一步」至步骤 4，切换到父本异常路径，讲解另一种可能
  6. 点击「下一步」至步骤 5，同时显示两种途径，总结 X^E X^e Y 形成原因
  7. 教师可随时点击「上一步」回退复习关键步骤

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript
  - 原因：本场景以几何图形（圆形、椭圆、箭头）和文本标签为主，无需复杂图表库；原生 SVG 可精确控制每个元素坐标和样式，便于分步显示/隐藏
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +----------------------------------------------------------+
  |  [步骤标题：居上 (350,30)]                                |
  |                                                          |
  |  [亲本区]        [减数分裂区]           [子代区]          |
  |  x=20-180        x=200-580              x=600-780        |
  |  +--------+      正常路径 (y=80-160)    +--------+       |
  |  | 父本   |----->(减 I)→(减 II)→配子--->|        |       |
  |  | X^E Y  |      异常路径 (y=280)       | 子代   |       |
  |  +--------+      [红色边框标识异常]     |X^E X^e Y|       |
  |  +--------+                           +--------+       |
  |  | 母本   |                                              |
  |  | X^e X^e|                                              |
  |  +--------+                                              |
  |                                                          |
  |  [控件栏 y=440-490]                                      |
  |  +------------------+------------------+                 |
  |  |    ◀ 上一步      |     下一步 ▶     |  步骤 X/6       |
  |  +------------------+------------------+                 |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-5) 跟踪当前步骤，每个步骤对应一个状态对象，包含需显示/隐藏的元素 ID 列表
  2. 坐标计算：所有元素坐标硬编码在 SVG 中，确保与布局表一致
  3. 动画曲线：步骤切换使用 CSS transition，opacity 从 0→1 用时 300ms，transform 位移使用 ease-out
  4. 事件绑定：按钮点击事件绑定到 stepChange 函数，更新 currentStep 并调用 renderStep()
  5. 元素分组：用<g>标签将相关元素分组（如亲本组、正常分裂组、异常分裂组、子代组），便于批量显示/隐藏
- ID 命名规范：所有交互元素 ID 必须以 scene2- 为前缀
  - 示例：scene2-parent-male（父本）、scene2-parent-female（母本）、scene2-meiosis-normal-meiosis1（正常减 I）、scene2-meiosis-abnormal-meiosis1（异常减 I）、scene2-gamete-normal-1（正常配子 1）、scene2-gamete-abnormal（异常配子）、scene2-offspring（子代）、scene2-btn-prev（上一步按钮）、scene2-btn-next（下一步按钮）、scene2-step-indicator（步骤指示器）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
- MathJax 配置：如需显示上标（X^E），使用 SVG <text> 的<tspan>元素实现上标效果，dy="-5" font-size="0.7em"
