[技术实现]
- JS库选择及原因：原生SVG + 原生JavaScript
  - 原因：几何图形简单（矩形、文本、线条），无需复杂库；原生SVG便于精确控制每个元素的显示/隐藏和动画
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [800×500 画布]
  ┌─────────────────────────────────────────────────────────────┐
  │                    F₂代比例异常：配子致死机制                │ y=35
  ├─────────────────────────────────────────────────────────────┤
  │  P: [果蝇] VVRR    ×    [果蝇] vvrr                         │ y=70-160
  │        长翅细眼              残翅粗眼                         │
  ├─────────────────────────────────────────────────────────────┤
  │                      F₁: [果蝇] VvRr                        │ y=190-265
  │                          长翅细眼                            │
  ├─────────────────────────────────────────────────────────────┤
  │  配子: [VR][Vr][vR][vr]    ┌───────棋盘格───────┐           │ y=295-420
  ├─────────────────────────────────────────────────────────────┤
  │  比例对比: [理论9:3:3:1] [实际7:3:1:1]  [致死提示框]        │ y=445-480
  ├─────────────────────────────────────────────────────────────┤
  │                              [◀上一步][下一步▶]             │ y=475-490
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用currentStep变量(0-6)跟踪当前步骤，steps数组存储每步的可见元素ID列表
  2. 坐标计算：所有元素使用绝对坐标，棋盘格16个单元格用循环生成
  3. 动画曲线：使用CSS transition实现淡入效果（opacity: 0→1, duration: 0.5s）
  4. 事件绑定：按钮点击事件绑定到stepForward()和stepBack()函数
  5. 元素显隐：通过display属性或opacity控制，每步更新后重新渲染相关元素
- ID命名规范：
  - 所有元素ID以"scene3-"为前缀
  - 示例：scene3-parent1、scene3-parent2、scene3-f1、scene3-gamete-vr、scene3-punnett、scene3-bar-theory、scene3-bar-actual、scene3-lethal-box、scene3-btn-prev、scene3-btn-next
- IIFE隔离：
  ```javascript
  (function() {
    // 所有场景3的JS代码包裹在此
    let currentStep = 0;
    const totalSteps = 6;
    // ... 状态机和事件处理
  })();
  ```
