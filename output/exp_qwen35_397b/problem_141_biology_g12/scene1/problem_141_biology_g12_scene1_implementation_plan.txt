[图示主题与整合说明]
- 本图示主题：6 种幼苗类型的基因整合情况对比
- 整合的内容：题目原图中 a-f 六种类型的染色体和线粒体基因整合状态，用颜色标注区分

[视觉元素清单]
- 6 个细胞外框：圆形，stroke=#333333，stroke-width=2，fill=none；类型 d 初始状态用#2e7d32 绿色外框高亮（stroke-width=3）
- 染色体：竖直线段，stroke=#000000 或#888888（未整合），stroke-width=3
- 染色体 S 基因整合标记：蓝色实心箭头#1565c0，位于染色体顶端上方约 5px
- 线粒体：小圆形，stroke=#333333，stroke-width=1，fill=none 或#f0f0f0
- 线粒体 S 基因整合标记：红色实心圆点#c62828，r=5，位于线粒体中心
- 类型标签：a-f，字体 14px 粗体，黑色，位于各细胞正上方 15px 处
- 图例文字：底部说明"↑表示已整合基因 S 的 2 号染色体 DNA；○表示未整合基因 S 的线粒体环状 DNA"等
- 颜色规格：
  - 背景：#ffffff
  - 染色体主线（无 S）：#888888 灰色
  - 染色体 S 基因整合：#1565c0 蓝色实心箭头
  - 线粒体 S 基因整合：#c62828 红色实心圆点
  - 线粒体无 S：#888888 灰色空心圆
  - 类型 d 外框高亮：#2e7d32 绿色

[分步序列]
分步按钮导航，共 5 步（步骤 0-4）：

- 步骤 0（初始状态）：显示 6 种类型基础图
  - 显示所有 6 个细胞外框（d 用绿色框，其余灰色框）
  - 显示所有染色体（根据类型显示黑色或灰色）
  - 显示所有线粒体（根据类型显示空心或带红点）
  - 显示类型标签 a-f
  - 染色体和线粒体的 S 基因标记暂不显示（或半透明）

- 步骤 1：点击「下一步」→ 高亮染色体 S 基因
  - 类型 a、b、d、e 的染色体上出现蓝色箭头标记
  - a、d：两条染色体都有蓝色箭头
  - b、e：仅左侧染色体有蓝色箭头
  - c、f：无箭头（染色体灰色）
  - 添加标注文字"染色体 S 基因整合"（位于顶部 y=50 处）

- 步骤 2：点击「下一步」→ 高亮线粒体 S 基因
  - 类型 a、b、c 的线粒体中心出现红色圆点
  - d、e、f：线粒体无红点（灰色空心）
  - 添加标注文字"线粒体 S 基因整合"（位于顶部 y=70 处）

- 步骤 3：点击「下一步」→ 标注每种类型的遗传特性
  - 在每个细胞下方添加特性标签：
    - a：下方 (200,220) "杂合 + 母系"
    - b：下方 (400,220) "杂合 + 母系"
    - c：下方 (600,220) "仅母系"
    - d：下方 (200,420) "纯合✓"（绿色）
    - e：下方 (400,420) "杂合"
    - f：下方 (600,420) "无抗性"
  - 特性标签字体 12px，d 的标签用绿色#2e7d32

- 步骤 4：点击「下一步」→ 标出符合长期种植要求的类型 d
  - 类型 d 的细胞外框加粗绿色高亮（stroke-width=4）
  - 在 d 细胞右侧添加说明文字"符合长期种植要求"（位于 (270,350)）
  - 其他细胞外框变淡（opacity=0.6）
  - 顶部添加结论文字"答案：d"（位于 (400,30)，字体 18px 粗体绿色）

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 内底部左侧 (350,460)，点击返回上一状态
  - 「下一步」按钮：位于 SVG 内底部右侧 (450,460)，点击进入下一状态
  - 步骤指示器：位于两按钮之间 (410,465)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始展示 6 种类型基础结构，让学生观察差异
  2. 点击「下一步」高亮染色体 S 基因，讲解染色体整合的遗传规律
  3. 点击「下一步」高亮线粒体 S 基因，讲解母系遗传特点
  4. 点击「下一步」显示各类型遗传特性，引导学生分析稳定性
  5. 点击「下一步」突出类型 d，得出符合长期种植要求的结论

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库）
- 画布尺寸：800×500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                    顶部标注区                     |
  |          (染色体/线粒体 S 基因整合说明)            |
  |                                                  |
  |    a          b          c                       |
  |   (○)        (○)        (○)                      |
  |   || ||      |  ||      || ||                    |
  |                                                  |
  |    d          e          f                       |
  |   (○)        (○)        (○)                      |
  |   || ||      |  ||      || ||                    |
  |                                                  |
  |         [特性标签区：各细胞下方]                  |
  |                                                  |
  |    [◀上一步]  步骤 X/5  [下一步▶]               |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-4) 跟踪当前步骤，steps 数组存储每步的显示配置
  2. 坐标计算：6 个细胞中心坐标预定义为数组 cells = [{x:200,y:150}, {x:400,y:150}, ...]
  3. 基因整合配置：用对象存储每种类型的基因状态，如 typeConfig = {a:{chr:[1,1], mito:1}, b:{chr:[1,0], mito:1}, ...}
  4. 动画曲线：使用 CSS transition 实现平滑显示/隐藏（opacity 和 stroke-width 变化）
  5. 事件绑定：按钮点击事件调用 updateStep() 函数，根据 currentStep 更新各元素 visibility/class
- ID 命名规范：
  - 细胞外框：scene1-cell-a, scene1-cell-b, ..., scene1-cell-f
  - 染色体：scene1-chr-a-l, scene1-chr-a-r（左/右）
  - 线粒体：scene1-mito-a, scene1-mito-b, ...
  - S 基因标记：scene1-s-chr-a-l, scene1-s-mito-a
  - 类型标签：scene1-label-a, scene1-label-b, ...
  - 特性标签：scene1-trait-a, scene1-trait-b, ...
  - 按钮：scene1-btn-prev, scene1-btn-next
  - 步骤指示器：scene1-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
- 多场景合并兼容：所有选择器使用 getElementById，不使用全局 class 查询
