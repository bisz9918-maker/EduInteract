[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "上一步"按钮：位于(280,460)，80×30px，灰色背景，点击返回上一状态
  - "下一步"按钮：位于(440,460)，80×30px，蓝色背景，点击进入下一状态
  - 步骤指示器：显示"步骤 X/4"，位于两按钮之间
- 教师操作流程：
  1. 初始展示5种亲本类型，讲解基因整合位置的差异
  2. 点击"下一步"展示自交结果，讲解孟德尔遗传比例
  3. 点击"下一步"展示杂交结果，强调父本线粒体不传递
  4. 点击"下一步"高亮e的特殊情况，对比a/b/e的差异
  5. 点击"下一步"总结筛选条件，指出类型d为符合要求的答案

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript
  - 原因：流程图结构简单，无需复杂库；SVG 便于精确控制坐标和样式
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  亲本类型    自交系一代    杂交系一代            |
  |  +---+      +-------+    +-------+               |
  |  | a |  →   | 3:1   | →  | 3:1   |  第1行       |
  |  +---+      +-------+    +-------+               |
  |  +---+      +-------+    +-------+               |
  |  | b |  →   | 3:1   | →  | 3:1   |  第2行       |
  |  +---+      +-------+    +-------+               |
  |  +---+      +-------+    +-------+               |
  |  | c |  →   | 100%  | →  | 100%  |  第3行       |
  |  +---+      +-------+    +-------+               |
  |  +---+      +-------+    +-------+               |
  |  | d |  →   | 100%  | →  | 100%  |  第4行(答案) |
  |  +---+      +-------+    +-------+               |
  |  +---+      +-------+    +-------+               |
  |  | e |  →   | 全感病| →  | 全感病|  第5行       |
  |  +---+      +-------+    +-------+               |
  |                                                  |
  |  [筛选条件框：自交100%且杂交100% → 类型d]        |
  |                                                  |
  |        [◀上一步]  步骤X/4  [下一步▶]            |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-4) 跟踪当前步骤
  2. 每步显示/隐藏对应元素组（用 display 或 opacity 控制）
  3. 高亮效果：用 CSS class 切换边框粗细和颜色
  4. 箭头动画：用 stroke-dasharray 实现绘制动画效果
  5. 按钮状态：第一步禁用"上一步"，最后一步禁用"下一步"或改为"完成"
- ID 命名规范：所有元素 ID 以 scene2- 为前缀
  - 亲本框：scene2-parent-a, scene2-parent-b, ..., scene2-parent-e
  - 自交结果：scene2-self-a, scene2-self-b, ..., scene2-self-e
  - 杂交结果：scene2-cross-a, scene2-cross-b, ..., scene2-cross-e
  - 箭头：scene2-arrow-self-a, scene2-arrow-cross-a, ...
  - 筛选框：scene2-filter-box
  - 按钮：scene2-btn-prev, scene2-btn-next
  - 步骤指示：scene2-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
