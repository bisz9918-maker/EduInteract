[分步序列]
- 初始状态（步骤0）：仅显示白色物质框及其标签，其他元素隐藏
- 步骤1：点击「下一步」→ 显示基因A的抑制符号（T型线）及"基因A"、"抑制"标签，T型线从上方指向箭头1位置
- 步骤2：点击「下一步」→ 显示反应箭头1（白色→棕色）、棕色物质框及标签、"酶B"标签，箭头1高亮闪烁
- 步骤3：点击「下一步」→ 显示反应箭头2（棕色→黑色）、黑色物质框及标签、"酶C"标签，箭头2高亮闪烁
- 步骤4（结论）：点击「下一步」→ 所有元素完整显示，在底部显示表型判定条件文本框（白色背景，边框#1565c0）

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于(280,460)，返回上一状态
  - 「下一步」按钮：位于(420,460)，进入下一状态
  - 步骤指示器：位于(360,460)，显示"步骤X/5"
- 教师操作流程：
  1. 初始状态展示白色物质，引入代谢底物概念
  2. 点击「下一步」展示基因A的抑制作用，讲解负调控机制
  3. 点击「下一步」展示B基因催化白色→棕色，讲解酶促反应
  4. 点击「下一步」展示C基因催化棕色→黑色，完成代谢途径
  5. 最终状态总结表型判定条件，可点击「上一步」回退复习

[技术实现]
- JS 库选择及原因：原生 SVG（简单几何图形和箭头，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +----------------------------------------------------------+
  |                                                          |
  |                    基因A  抑制                           |
  |                      |                                   |
  |                      T                                   |
  |                                                          |
  |   白色物质          酶B         棕色物质    酶C   黑色物质 |
  |   +------+        -------->    +------+  --------> +------+
  |   |      |                     |      |              |      |
  |   +------+                     +------+              +------+
  |                                                          |
  |                                                          |
  |                                                          |
  |              [◀上一步]  步骤X/5  [下一步▶]               |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-4) 跟踪当前步骤
  2. 元素分组：将相关元素放入<g>组，用 display 控制显隐
     - group-step0: 白色物质框及标签
     - group-step1: 基因A抑制符号及标签
     - group-step2: 反应箭头1、棕色物质框及标签、酶B标签
     - group-step3: 反应箭头2、黑色物质框及标签、酶C标签
     - group-step4: 结论文本框
  3. 动画效果：箭头出现时用 stroke-dasharray 实现绘制动画（500ms）
  4. 事件绑定：按钮点击事件切换 currentStep，调用 updateDisplay() 更新显隐
  5. 边界处理：步骤0时禁用「上一步」，步骤4时禁用「下一步」
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀（如 scene1-white-box, scene1-arrow-1, scene1-btn-next）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中
