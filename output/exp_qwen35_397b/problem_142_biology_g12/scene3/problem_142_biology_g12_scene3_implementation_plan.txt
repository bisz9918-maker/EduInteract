[分步序列]
步骤 0（初始状态）：
- 显示标题"测交实验：突变体类型判定"
- 显示两个亲本框：左侧"突变体：aaBbCcc"，右侧"隐性纯合子：aabbcc"
- 显示×符号表示杂交
- 配子区、后代区、表型区、结论区均隐藏
- 步骤指示器显示"步骤 1/5"

步骤 1（点击"下一步"）：
- 显示两个向下箭头（亲本→配子）
- 显示配子标题"配子类型"
- 左侧显示突变体产生的配子：3 个圆形节点
  - 根据突变体类型（甲/乙/丙）动态显示不同配子组合
  - 突变体甲：aaBbCc (1/4), aaBbc (1/4), aabbc (1/4), aabbc (1/4) → 实际为 aaBbCc:aaBbc:aabbc = 1:1:2
  - 突变体乙：配子类型不同
  - 突变体丙：配子类型不同
- 右侧显示隐性纯合子产生的配子：1 种 aabc（所有配子相同）
- 步骤指示器显示"步骤 2/5"

步骤 2（点击"下一步"）：
- 显示后代标题"后代基因型"
- 显示 3×3 表格框架
- 填充表格单元格，显示各配子组合产生的后代基因型
- 步骤指示器显示"步骤 3/5"

步骤 3（点击"下一步"）：
- 显示表型标题"表型比例"
- 显示柱状图背景和三个柱子
- 根据后代基因型计算并显示表型比例
  - 黑色：含 C 基因且 C≥c
  - 棕色：不含 C 基因或 C<c
  - 黑青色：C 基因数少于 c 基因数
- 在柱子上方显示比例数值（如 3/8, 3/8, 2/8）
- 步骤指示器显示"步骤 4/5"

步骤 4（点击"下一步"）：
- 隐藏表格和柱状图（或保留）
- 显示结论框
- 根据表型比例显示突变体判定结论：
  - 若黑色:棕色:黑青色 = 3:3:2 → 突变体甲
  - 若比例不同 → 突变体乙或丙
- 步骤指示器显示"步骤 5/5"
- "下一步"按钮变为"重新开始"

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：位于 (220,450)，点击后回退到上一状态
  - "下一步 ▶"按钮：位于 (480,450)，点击后进入下一状态
  - 步骤指示器：位于 (400,465)，显示当前步骤/总步骤数
- 教师操作流程：
  1. 初始状态展示测交实验的亲本选择
  2. 点击"下一步"展示配子形成过程，讲解减数分裂中染色体分离
  3. 点击"下一步"展示后代基因型组合，讲解受精过程中配子随机结合
  4. 点击"下一步"展示表型比例，讲解基因型与表型的对应关系
  5. 点击"下一步"展示结论，讲解如何根据表型比例判定突变体类型
  6. 可随时点击"上一步"回退复习关键概念

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript
  - 原因：本场景为 2D 静态图示 + 简单状态切换，无需复杂动画库；原生 SVG 可精确控制元素位置和样式；代码轻量，易于多场景合并
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────┐
  │              测交实验：突变体类型判定                    │ y=20-50
  ├─────────────────────────────────────────────────────────┤
  │  [突变体：aaBbCcc]    ×    [隐性纯合子：aabbcc]         │ y=60-110
  │         ↓                        ↓                      │ y=115-135
  │    ○ ○ ○ 配子              ○ ○ ○ 配子                   │ y=140-200
  ├─────────────────────────────────────────────────────────┤
  │                  后代基因型                              │ y=215
  │  ┌─────────────────────────────────────────────────┐    │ y=230-325
  │  │  单元格  │  单元格  │  单元格  │                 │    │
  │  │  单元格  │  单元格  │  单元格  │                 │    │
  │  └─────────────────────────────────────────────────┘    │    │
  ├─────────────────────────────────────────────────────────┤
  │                  表型比例                                │ y=340
  │     ┌─────┐  ┌─────┐  ┌─────┐                          │ y=355-420
  │     │黑色 │  │棕色 │  │黑青 │                          │    │
  │     └─────┘  └─────┘  └─────┘                          │    │
  ├─────────────────────────────────────────────────────────┤
  │         [◀ 上一步]    步骤 1/5    [下一步 ▶]             │ y=445-485
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-4）跟踪当前步骤，states 数组存储各状态的显示配置
  2. 坐标计算：所有元素使用绝对坐标（x,y），确保布局精确
  3. 动画曲线：元素显示使用淡入效果（opacity 0→1，duration 300ms）
  4. 事件绑定：按钮点击事件绑定到 updateState() 函数，根据 currentState 更新显示
  5. 突变体类型选择：可在步骤 0 添加下拉菜单选择突变体甲/乙/丙，动态更新后续步骤
- ID 命名规范：所有交互元素 ID 必须以 scene3- 为前缀
  - scene3-title, scene3-parent-left, scene3-parent-right
  - scene3-gamete-left-1, scene3-gamete-left-2, scene3-gamete-left-3
  - scene3-gamete-right-1
  - scene3-offspring-table, scene3-cell-1-1, scene3-cell-1-2, ...
  - scene3-phenotype-bar-black, scene3-phenotype-bar-brown, scene3-phenotype-bar-cyan
  - scene3-conclusion-box, scene3-conclusion-text
  - scene3-btn-prev, scene3-btn-next, scene3-step-indicator
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
