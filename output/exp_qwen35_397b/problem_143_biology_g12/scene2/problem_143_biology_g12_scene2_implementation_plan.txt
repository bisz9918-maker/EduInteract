[分步序列]
- 初始状态（步骤 0）：显示草能量框（300 万千焦），所有箭头灰色虚线，其他能量框隐藏
- 步骤 1：点击「下一步」→ 显示第二营养级三个能量框（羚羊、斑马、鼠各 100 万千焦），草→各生物箭头变实线，显示 10% 标签，显示计算标注"300×10%÷3=10"
- 步骤 2：点击「下一步」→ 显示第三营养级（野狗、蛇能量框），羚羊/斑马→野狗、鼠→蛇箭头变实线，野狗能量=100×10%÷2=5，蛇能量=100×10%=10
- 步骤 3：点击「下一步」→ 显示第四营养级（食蛇动物能量框），蛇→食蛇动物箭头变实线，食蛇动物能量=10×10%=1
- 步骤 4：点击「下一步」→ 显示所有指向狮子的箭头（羚羊→狮子、斑马→狮子、食蛇动物→狮子、野狗→狮子），各路径能量标注显示
- 步骤 5：点击「下一步」→ 狮子能量框高亮显示，汇总框显示"11.1 万千焦"红色加粗，所有能量路径完整展示

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于(280,455)，返回前一状态
  - 「下一步」按钮：位于(420,455)，进入下一状态
  - 步骤指示器：位于(600,460)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始展示草的 300 万千焦能量
  2. 点击「下一步」展示第二营养级分配（100 万千焦各）
  3. 继续点击展示第三、四营养级能量传递
  4. 最后展示狮群总能量汇总
  5. 可随时点击「上一步」回退复习关键计算步骤

[技术实现]
- JS 库选择：原生 SVG（几何形状和箭头绘制简单，无需额外库）
- 画布尺寸：800×500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +----------------------------------------------------------+
  |  草    羚羊                                              |
  | 300   100     野狗          食蛇动物    狮子              |
  |        |      5              1        11.1               |
  |       斑马    |                                          |
  |       100    ↓                                          |
  |        |     蛇                                          |
  |        ↓     10                                          |
  |        鼠                                                 |
  |       100                                                 |
  |                                                           |
  |  [10% 标注沿箭头分布]                                      |
  |                                                           |
  |              [步骤 0 → 1 → 2 → 3 → 4 → 5]                 |
  |              [◀上一步]    [下一步▶]   步骤 X/5            |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用 currentState 变量（0-5）跟踪当前步骤
  2. 元素分组：每个营养级的能量框、箭头、标签分别放入<g>组，用 display 控制显隐
  3. 箭头绘制：使用 SVG <marker> 定义箭头头部，<path> 绘制曲线
  4. 动画过渡：能量框出现时用 opacity 淡入（300ms），箭头用 stroke-dasharray 动画
  5. 事件绑定：按钮点击事件切换状态，更新所有元素显隐
- ID 命名规范：所有元素 ID 以 scene2- 为前缀
  - scene2-grass-box, scene2-antelope-box, scene2-zebra-box, scene2-mouse-box
  - scene2-wilddog-box, scene2-snake-box, scene2-snakeater-box, scene2-lion-box
  - scene2-arrow-grass-antelope, scene2-arrow-antelope-lion 等
  - scene2-btn-prev, scene2-btn-next, scene2-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
