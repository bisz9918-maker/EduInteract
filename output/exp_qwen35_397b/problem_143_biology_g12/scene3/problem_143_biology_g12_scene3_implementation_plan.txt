[图示主题与整合说明]
- 本图示主题：人类干预前后能量分配对比
- 整合内容：干预前鼠类能量占比1/3、干预后鼠类占2/3、狮群能量从21.1降至5.57万千焦、捕食区域需扩大约3.8倍

[交互方案]
- 交互类型：多状态切换（3个按钮）
- 控件说明：
  - 按钮1"干预前"：位置(150,450)，显示干预前能量分配状态
  - 按钮2"干预后"：位置(340,450)，显示干预后能量分配状态
  - 按钮3"对比总结"：位置(530,450)，同时显示干预前后对比及变化标注
- 教师操作流程：
  1. 点击"干预前"，讲解干预前第二营养级能量均匀分配（鼠类、羚羊、斑马各1/3），狮群获得21.1万千焦
  2. 点击"干预后"，讲解人类干扰导致鼠类占比增至2/3，狮群能量降至5.57万千焦
  3. 点击"对比总结"，展示能量下降幅度（3.8倍），引导学生理解种群密度与捕食区域的关系

[技术实现]
- JS库选择及原因：原生SVG（饼图绘制简单，状态切换清晰，无需额外库）
- 画布尺寸：800×500 px
- 布局草图：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────┐
  │           人类干预前后能量对比 (y=35)               │
  │                                                     │
  │    干预前 (y=70)              干预后 (y=70)         │
  │      ○饼图 (y=220)            ○饼图 (y=220)        │
  │    [21.1万千焦]              [5.57万千焦]          │
  │                    ↓ 3.8倍                          │
  │              种群密度下降                           │
  │                                                     │
  │  [干预前]  [干预后]  [对比总结]  (y=450~485)        │
  └─────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用currentState变量(0/1/2)跟踪当前状态，点击按钮时更新状态并重新渲染
  2. 饼图绘制：使用SVG path的A命令绘制扇形，干预前鼠类扇形角度120°(1/3)，干预后240°(2/3)
  3. 状态切换：每个状态对应一组元素的display属性切换，使用classList.add/remove('active')
  4. 动画过渡：饼图和数值框使用CSS transition实现淡入淡出效果(0.3s)
  5. 事件绑定：三个按钮分别绑定click事件，调用updateState(0/1/2)函数
- ID命名规范：
  - 场景前缀：scene3-
  - 饼图：scene3-pie-before, scene3-pie-after
  - 数值框：scene3-energy-before, scene3-energy-after
  - 箭头：scene3-arrow-down
  - 倍数标注：scene3-multiplier
  - 按钮：scene3-btn-before, scene3-btn-after, scene3-btn-compare
- IIFE隔离：所有JS代码包裹在(function() { ... })()中，避免全局变量污染
