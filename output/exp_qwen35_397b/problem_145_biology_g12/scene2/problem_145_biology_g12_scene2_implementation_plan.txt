[图示主题与整合说明]
- 本图示主题：Ⅱ-5 性染色体异常（XO）的成因分析
- 整合的步骤/概念：父方减数分裂异常过程展示、O 型配子形成机制、另一种异常配子（XY）结合的可能结果
- 教学价值：教师可通过分步动画展示减数分裂过程中染色体的正常分离与异常不分离现象，帮助学生直观理解Ⅱ-5 性染色体异常（XO）的成因，以及异常配子结合后可能产生的其他性染色体组成（XXY、XYY 等）

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位置(280,460)，80×30px，点击后退到前一状态
  - 「下一步」按钮：位置(440,460)，80×30px，点击前进到下一状态
  - 步骤指示器：位置(400,465)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始加载显示步骤 0（父母性染色体组成）
  2. 点击「下一步」逐步展示减数分裂正常过程（步骤 1）
  3. 继续点击展示异常不分离现象（步骤 2）
  4. 展示 O 配子结合形成Ⅱ-5（步骤 3）
  5. 展示 XY 配子结合的其他可能（步骤 4）
  6. 最终总结所有异常类型（步骤 5）
  7. 教师可随时点击「上一步」回退复习关键步骤

[技术实现]
- JS 库选择：原生 SVG（适合绘制染色体、细胞、箭头等几何图形，无需额外库）
- 画布尺寸：800×500px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────┐
  │  [父方细胞]          [母方细胞]                     │ y=45-120
  │     X^B Y              X^B X^b                      │
  │                                                     │
  │  ┌───────────┐      ┌───────────────┐              │ y=140-230
  │  │ 减数第一次 │      │ 减数第二次    │              │
  │  │  分裂     │      │  分裂(异常)   │              │
  │  └───────────┘      └───────────────┘              │
  │                                                     │
  │  [正常配子]          [异常配子]                     │ y=280-320
  │    X    Y              XY    O                      │
  │                                                     │
  │         [卵细胞]  →  [合子]  [合子]  [合子]        │ y=360-440
  │                    Ⅱ-5    XXY    XYY               │
  │                                                     │
  │  [◀上一步]  [步骤 X/5]  [下一步▶]                  │ y=450-490
  └─────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用 currentStep 变量(0-5)跟踪当前步骤，steps 数组存储每步的可见元素 ID 列表
  2. 坐标计算：所有元素位置预先计算好，用 transform 或直接设置 cx/cy/x/y 属性
  3. 动画曲线：染色体移动用 CSS transition，ease-in-out 曲线，duration 500ms
  4. 事件绑定：按钮点击事件切换步骤，更新可见性
  5. 元素显隐：用 display:none 或 opacity:0 控制，保留 DOM 以便回退

- ID 命名规范（严格遵循）：
  - 所有交互元素 ID 必须以 scene2- 为前缀
  - 示例：scene2-father-cell, scene2-mother-cell, scene2-xb-chrom, scene2-y-chrom
  - 示例：scene2-meiosis1-box, scene2-meiosis2-box, scene2-normal-gamete-x
  - 示例：scene2-abnormal-gamete-xy, scene2-abnormal-gamete-o
  - 示例：scene2-zygote-1, scene2-zygote-2, scene2-zygote-3
  - 示例：scene2-btn-prev, scene2-btn-next, scene2-step-indicator

- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染

- 染色体绘制方法：
  - 用<rect>或<path>绘制棒状染色体
  - X 染色体：较长（8×20），蓝色或红色
  - Y 染色体：较短（6×15），黄色
  - 填充透明度 20%：fill-opacity="0.2"

- 箭头绘制方法：
  - 用<line>加 marker-end 定义箭头
  - 或直接用<path d="M x1 y1 L x2 y2 L x3 y3 Z"/>绘制三角形箭头

- 细胞绘制方法：
  - 用<circle>绘制细胞轮廓
  - 填充白色，轮廓黑色 2px 实线
