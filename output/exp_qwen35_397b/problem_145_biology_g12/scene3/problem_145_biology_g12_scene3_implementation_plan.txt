[分步序列]
- 初始状态（步骤 0）：显示亲本基因型框
  - 显示Ⅱ-3 基因型框 (150,60) 内容"AaX^B Y"
  - 显示Ⅱ-4 基因型框 (470,60) 内容"aaX^B X^b"
  - 分支图区域空白，等待下一步展开

- 步骤 1：分析甲病遗传
  - 显示分支树根节点 (400,160)
  - 显示第一层分支：两条蓝色线到 (300,210) 和 (500,210)
  - 显示甲病基因型标签"Aa"和"aa"
  - 显示甲病概率"1/2"和"1/2"
  - 高亮甲病分支线 #1565c0

- 步骤 2：分析乙病遗传
  - 在步骤 1 基础上，显示第二层分支
  - 显示四条红色分支线从甲病节点向下延伸
  - 显示乙病基因型标签"X^B Y"、"X^b Y"、"X^B X^B"、"X^B X^b"
  - 显示乙病概率标注（各 1/2）
  - 高亮乙病分支线 #c62828

- 步骤 3：展示完整分支图与单病概率
  - 显示完整的两层分支树
  - 显示甲病患病框 (280,320) 内容"甲病：1/2"
  - 显示乙病患病框 (420,320) 内容"乙病：1/4"
  - 乙病患病概率解释：X^b Y 为患乙病男性，概率 = 1/2(来自 Aa 分支) × 1/2(来自乙病分支) = 1/4

- 步骤 4：展示联合概率计算
  - 显示计算过程框 (200,370)
  - 显示公式"两病兼患 = 1/2 × 1/4 = 1/8"
  - 用箭头或连线将甲病概率、乙病概率与计算过程关联

- 步骤 5：高亮两病兼患后代类型
  - 在分支图中，高亮显示两病兼患的后代路径
  - 两病兼患基因型：AaX^b Y（患甲病且患乙病的男性）
  - 对应路径：根→Aa(1/2)→X^b Y(1/2)，联合概率 1/4，但需考虑这是在所有后代中的比例
  - 实际两病兼患概率 = P(甲病) × P(乙病) = 1/2 × 1/4 = 1/8
  - 用绿色 #2e7d32 填充 30% 透明度高亮相关节点和路径
  - 显示结论框 (320,430) 内容"概率 = 1/8"

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 内底部左侧 (280,455)，80×30px，点击返回上一状态
  - 「下一步」按钮：位于 SVG 内底部右侧 (440,455)，80×30px，点击进入下一状态
  - 步骤指示器：显示当前步骤/总步骤数，位于两按钮之间
- 教师操作流程：
  1. 初始状态展示亲本基因型，教师介绍Ⅱ-3 和Ⅱ-4 的基因型
  2. 点击「下一步」展开甲病分支，讲解显性遗传 Aa×aa→1/2 患病
  3. 点击「下一步」展开乙病分支，讲解伴性遗传 X^B Y×X^B X^b→1/4 患病
  4. 点击「下一步」展示单病概率结果框
  5. 点击「下一步」展示联合概率计算公式
  6. 点击「下一步」高亮两病兼患路径，展示最终结论 1/8
  7. 可随时点击「上一步」回退复习

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：分支树结构简单，原生 SVG 足够实现；无需复杂动画库；轻量级加载快
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────┐
  │              亲本基因型 (y=30-110)                   │
  │   [Ⅱ-3: AaX^B Y]           [Ⅱ-4: aaX^B X^b]         │
  │                                                     │
  │              后代基因型分支图 (y=120-310)            │
  │                    ● (根节点)                        │
  │                   / \                               │
  │              (Aa)   (aa)                            │
  │               / \   / \                             │
  │           X^B Y X^b Y X^B X^B X^B X^b               │
  │                                                     │
  │   [甲病：1/2]           [乙病：1/4]                 │
  │                                                     │
  │   [两病兼患 = 1/2 × 1/4 = 1/8]                      │
  │                                                     │
  │              [概率 = 1/8]                           │
  │                                                     │
  │   [◀上一步]          [下一步▶]                      │
  └─────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-5），steps 数组存储每步的显示配置
  2. 元素分组：按步骤将 SVG 元素分组（g 标签），通过 display 属性控制显示/隐藏
  3. 高亮效果：通过添加/移除 CSS class 实现颜色变化和高亮填充
  4. 事件绑定：按钮点击事件切换 currentState，调用 renderStep() 更新视图
  5. 边界处理：第一步禁用「上一步」，最后一步禁用「下一步」或显示「完成」
- ID 命名规范：
  - 所有交互元素 ID 以 scene3- 为前缀
  - 示例：scene3-parent-ii3、scene3-parent-ii4、scene3-branch-root、scene3-branch-aa、scene3-branch-ab、scene3-result-aa、scene3-result-ab、scene3-calc-box、scene3-conclusion、scene3-btn-prev、scene3-btn-next
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
