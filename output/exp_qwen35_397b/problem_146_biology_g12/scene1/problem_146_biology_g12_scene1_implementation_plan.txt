[图示主题与整合说明]
- 本图示主题：果蝇性染色体异常类型与染色体组成
- 整合的内容：题目原图的四种异常情况（XXY、XO、XXX、OY）+ 正常果蝇染色体组成对比（共 5 种类型）
- 教学价值：教师可通过分步展示，依次讲解每种染色体异常类型的组成、性别表现和育性状态，帮助学生理解性染色体数目变异对生物性状的影响。分步导航便于课堂节奏控制，学生可清晰对比正常与异常情况的差异。

[视觉元素清单]
- 细胞轮廓：5 个圆形，描边#888888，线宽 1.5px，无填充
- 常染色体：每组 6 条（3 对），V 形或棒状，#000000 实线，线宽 2px，着丝点用小圆圈表示
- X 染色体：棒状，#1565c0 蓝色，线宽 3px，长度约 20px
- Y 染色体：J 形钩状，#c62828 红色，线宽 3px，长度约 18px
- 状态标签：可育用绿色#2e7d32，不育用橙色#f57c00，死亡用红色#c62828
- 细胞内染色体布局：常染色体位于细胞上半区（y 偏移 -25 到 -10），性染色体位于下半区（y 偏移 5 到 25）

[分步序列]
步骤 0（初始状态）：显示正常果蝇细胞
- 显示：细胞轮廓 1（正常 XY）、常染色体组 1、2 条 X 染色体（实际正常雄性为 XY，1X1Y）、标签"正常 XY"、标签"雄性可育"（绿色）
- 隐藏：其他 4 个细胞及标签
- 步骤指示器：显示"步骤 1/5"

步骤 1：点击「下一步」→ 显示 XXY 类型
- 保持显示：步骤 0 的所有元素
- 新增显示：细胞轮廓 2（XXY）、常染色体组 2、2 条 X 染色体 +1 条 Y 染色体、标签"XXY"、标签"雌性可育"（绿色）
- 步骤指示器：显示"步骤 2/5"

步骤 2：点击「下一步」→ 显示 XO 类型
- 保持显示：步骤 1 的所有元素
- 新增显示：细胞轮廓 3（XO）、常染色体组 3、1 条 X 染色体（无 Y）、标签"XO"、标签"雄性不育"（橙色）
- 步骤指示器：显示"步骤 3/5"

步骤 3：点击「下一步」→ 显示 XXX 类型
- 保持显示：步骤 2 的所有元素
- 新增显示：细胞轮廓 4（XXX）、常染色体组 4、3 条 X 染色体、标签"XXX"、标签"死亡"（红色）
- 步骤指示器：显示"步骤 4/5"

步骤 4：点击「下一步」→ 显示 OY 类型（最终步骤）
- 保持显示：步骤 3 的所有元素
- 新增显示：细胞轮廓 5（OY）、常染色体组 5、1 条 Y 染色体（无 X）、标签"OY"、标签"死亡"（红色）
- 步骤指示器：显示"步骤 5/5"

教师可随时点击「上一步」回退复习，已显示的元素保持显示，仅隐藏当前步骤及之后的元素。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 (280, 460)，80×30px，点击后隐藏当前步骤元素，步骤指示器减 1
  - 「下一步」按钮：位于 (440, 460)，80×30px，点击后显示下一步元素，步骤指示器加 1
  - 步骤指示器：位于 (400, 465)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始加载显示正常果蝇染色体组成，教师讲解正常情况
  2. 点击「下一步」依次展示 XXY、XO、XXX、OY 四种异常类型
  3. 每展示一种类型，教师讲解其染色体组成、性别表现、育性状态
  4. 可随时点击「上一步」回退复习已讲内容
  5. 最终步骤展示全部 5 种类型，进行对比总结

[技术实现]
- JS 库选择：原生 SVG（简单几何图形首选，无需额外库）
- 画布尺寸：800×500px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────────┐
  │                                                             │
  │    [正常 XY]        [XXY]           [XO]                   │
  │      ○○○             ○○○            ○○○                   │
  │   雄性可育         雌性可育       雄性不育                  │
  │                                                             │
  │                                                             │
  │         [XXX]                    [OY]                       │
  │           ○○○                     ○○○                      │
  │         死亡                     死亡                       │
  │                                                             │
  │                                                             │
  │              [◀上一步]  步骤 X/5  [下一步▶]                 │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep（0-4）跟踪当前步骤，数组 steps[] 存储每步需显示的元素 ID 列表
  2. 坐标计算：5 个细胞圆心坐标预定义，染色体相对圆心偏移量固定
  3. 动画曲线：元素显示使用淡入效果（opacity 0→1，duration 300ms）
  4. 事件绑定：按钮点击事件绑定 stepForward() 和 stepBack() 函数
  5. 边界处理：步骤 0 时禁用「上一步」，步骤 4 时禁用「下一步」
- ID 命名规范：所有元素 ID 以 scene1- 为前缀
  - 细胞轮廓：scene1-cell-normal, scene1-cell-xxy, scene1-cell-xo, scene1-cell-xxx, scene1-cell-oy
  - 染色体组：scene1-autosome-1~5, scene1-chrom-x-*, scene1-chrom-y-*
  - 标签：scene1-label-normal, scene1-label-xxy, scene1-label-xo, scene1-label-xxx, scene1-label-oy
  - 状态标签：scene1-status-normal, scene1-status-xxy, scene1-status-xo, scene1-status-xxx, scene1-status-oy
  - 控件：scene1-btn-prev, scene1-btn-next, scene1-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
- 配色规格：
  - 背景：#ffffff
  - 常染色体：#000000 实线
  - X 染色体：#1565c0 蓝色加粗
  - Y 染色体：#c62828 红色加粗
  - 细胞轮廓：#888888 细线
  - 可育状态文字：#2e7d32 绿色
  - 不育状态文字：#f57c00 橙色
  - 死亡状态文字：#c62828 红色
