[图示主题与整合说明]
- 本图示主题：果蝇减数分裂过程中染色体数目变化
- 整合的步骤/概念：减数第一次分裂中期染色体组数 + 减数第二次分裂后期染色体数
- 教学价值：教师可通过分步动画展示减数分裂连续过程中染色体行为和数目的动态变化，帮助学生理解同源染色体分离、姐妹染色单体分离的关键区别，掌握染色体组数和染色体数的变化规律

[视觉元素清单]
- 细胞轮廓：5个圆形，黑色细线描边#000000，无填充，半径55px，横向排列间距140px
- 染色体：棒状结构，黑色实线#000000，线宽2px，每条含2个染色单体（减Ⅰ）或1个（减Ⅱ后期）
- 着丝点：蓝色实心圆#1565c0，直径4px，位于染色体中心
- 纺锤丝：灰色虚线#888888，线宽1px，从细胞两极（上下）延伸到着丝点
- 时期标签：黑色文字，位于各细胞正下方y=200处
- 数值标签：红色加粗#c62828，位于信息面板内
- 信息面板：浅灰色背景#f5f5f5，圆角矩形，显示当前步骤的染色体组数和染色体数
- 导航按钮：蓝色背景#1976d2，白色文字，圆角矩形

[分步序列]
步骤0（初始状态 - 间期）：
- 显示细胞1（间期）：圆形轮廓内散布细丝状染色质（8条曲线表示复制前染色体）
- 细胞2-5轮廓显示但内部染色体半透明（透明度0.3）
- 信息面板显示：当前时期：间期 | 染色体组数=2 | 染色体数=8
- 步骤指示器：步骤 1/5

步骤1（减Ⅰ中期）：
- 细胞1保持原状
- 细胞2高亮（轮廓加粗，内部染色体不透明）
- 显示4对同源染色体（共8条染色单体）排列在赤道板上
- 纺锤丝从两极连接到着丝点
- 信息面板更新：当前时期：减数第一次分裂中期 | 染色体组数=2 | 染色体数=8
- 步骤指示器：步骤 2/5

步骤2（减Ⅰ后期）：
- 细胞2恢复半透明
- 细胞3高亮
- 显示同源染色体分离，4条染色体移向一极，4条移向另一极
- 信息面板更新：当前时期：减数第一次分裂后期 | 染色体组数=2→1 | 染色体数=8→4（每极）
- 步骤指示器：步骤 3/5

步骤3（减Ⅱ中期）：
- 细胞3恢复半透明
- 细胞4高亮
- 显示2个次级细胞（简化为1个示意），每个细胞内4条染色体排列在赤道板
- 信息面板更新：当前时期：减数第二次分裂中期 | 染色体组数=1 | 染色体数=4
- 步骤指示器：步骤 4/5

步骤4（减Ⅱ后期）：
- 细胞4恢复半透明
- 细胞5高亮
- 显示姐妹染色单体分离，4条染色单体移向每极
- 信息面板更新：当前时期：减数第二次分裂后期 | 染色体组数=1 | 染色体数=4→8（分离后）
- 步骤指示器：步骤 5/5

- 信息面板位于y=280~400区域，与细胞区(y=65~175)分离 → 无冲突
- 按钮区位于y=420~485，与信息面板(y=280~400)间距35px → 无冲突
- 所有标签均位于图形元素外侧，无重叠 → 通过

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于(280,450)，点击后退到前一阶段，步骤0时禁用
  - 「下一步」按钮：位于(440,450)，点击前进到下一阶段，步骤4时禁用
  - 步骤指示器：位于(400,420)，显示当前步骤序号
- 教师操作流程：
  1. 初始展示间期状态，讲解染色体复制
  2. 点击「下一步」展示减Ⅰ中期，讲解同源染色体配对和赤道板排列
  3. 点击「下一步」展示减Ⅰ后期，讲解同源染色体分离
  4. 点击「下一步」展示减Ⅱ中期，讲解次级细胞形成
  5. 点击「下一步」展示减Ⅱ后期，讲解姐妹染色单体分离
  6. 可随时点击「上一步」回退复习关键概念

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库）
- 画布尺寸：800×500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  ┌────────────────────────────────────────────────────────────┐
  │  ○     ○     ○     ○     ○     (5个细胞横向排列 y=120)    │
  │ 间期  减Ⅰ中  减Ⅰ后  减Ⅱ中  减Ⅱ后   (时期标签 y=200)       │
  │                                                            │
  │  ┌──────────────────────────────────────────────────┐     │
  │  │ 当前时期：减数第一次分裂中期                     │     │
  │  │ 染色体组数：2   染色体数：8                      │     │
  │  └──────────────────────────────────────────────────┘     │
  │                                                            │
  │                    步骤 2/5                                │
  │         [◀上一步]          [下一步▶]                       │
  └────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用 currentStep 变量(0-4)跟踪当前步骤
  2. 坐标计算：5个细胞中心x坐标分别为80,220,360,500,640，间距140px
  3. 动画曲线：染色体移动使用 ease-in-out 缓动，持续时间500ms
  4. 事件绑定：按钮点击事件触发 stepChange 函数，更新 DOM 和 SVG 元素
  5. 元素显隐：用 CSS opacity 和 display 控制各步骤元素显示
- ID 命名规范：所有元素 ID 以 scene2- 为前缀
  - scene2-cell-1, scene2-cell-2, ..., scene2-cell-5
  - scene2-chromo-1-1, scene2-chromo-1-2, ... (细胞1的染色体)
  - scene2-btn-prev, scene2-btn-next, scene2-step-indicator
  - scene2-info-panel, scene2-info-title, scene2-info-content
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
