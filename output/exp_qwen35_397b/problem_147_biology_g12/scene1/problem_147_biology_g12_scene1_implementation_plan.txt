[分步序列]
- 步骤 0（初始状态）：显示完整 DNA 双链（a 链和 b 链），标注 5'/3'端，显示引物Ⅰ位置，引物Ⅱ位置显示"待填"提示
- 步骤 1（95°C 变性）：DNA 双链解开成两条单链，上下分离约 30px，右侧显示"95°C"温度标签，氢键断裂用淡出动画表示
- 步骤 2（55°C 复性）：两条单链回到原位，引物Ⅰ（蓝色）结合到 a 链 3'端，引物Ⅱ（红色）结合到 b 链 3'端，右侧显示"55°C"
- 步骤 3（72°C 延伸）：从引物 3'端开始合成新链（绿色），新链长度逐渐增长至完整，右侧显示"72°C"
- 步骤 4（循环产物）：显示两个完整的 DNA 双链分子，每个分子含一条原始链和一条新合成链，标注"DNA 分子 1"和"DNA 分子 2"

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 上一步按钮：位于 SVG 底部左侧 (280,455)，点击返回上一状态
  - 下一步按钮：位于 SVG 底部右侧 (420,455)，点击进入下一状态
  - 步骤指示器：位于两按钮之间，显示当前步骤序号
- 教师操作流程：
  1. 初始加载显示步骤 0，教师讲解 DNA 双链结构和引物位置
  2. 点击"下一步"进入步骤 1，讲解 95°C 高温使氢键断裂、双链解开
  3. 点击"下一步"进入步骤 2，讲解 55°C 时引物与模板链特异性结合
  4. 点击"下一步"进入步骤 3，讲解 72°C 时 Taq 酶催化新链延伸
  5. 点击"下一步"进入步骤 4，展示循环一次后得到两个 DNA 分子
  6. 可随时点击"上一步"回退复习关键步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何元素简单（线段、曲线、文本），无需复杂库；原生实现轻量、加载快
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │                    PCR 循环过程 (标题 y=30)                  │
  ├─────────────────────────────────────────────────────────────┤
  │ [初始状态]  DNA 双链 + 引物Ⅰ位置 (y=55-125)                  │
  ├─────────────────────────────────────────────────────────────┤
  │ [95°C 变性]  两条分离单链 (y=135-205)                        │
  ├─────────────────────────────────────────────────────────────┤
  │ [55°C 复性]  引物结合到模板链 (y=215-285)                    │
  ├─────────────────────────────────────────────────────────────┤
  │ [72°C 延伸]  新链合成中 (y=295-365)                          │
  ├─────────────────────────────────────────────────────────────┤
  │ [循环产物]  两个 DNA 分子 (y=375-435)                        │
  ├─────────────────────────────────────────────────────────────┤
  │           [◀上一步]  步骤 X/4  [下一步▶]   (y=445-490)       │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用 currentStep 变量 (0-4) 跟踪当前步骤，steps 数组存储每步的可见元素配置
  2. 元素分组：每个步骤的元素用<g>分组，通过 display 属性控制显示/隐藏
  3. 动画效果：使用 CSS transition 实现淡入淡出，新链延伸用 stroke-dasharray 动画
  4. 事件绑定：按钮点击事件切换 currentStep，调用 updateDisplay() 刷新视图
  5. 边界处理：步骤 0 时禁用"上一步"，步骤 4 时禁用"下一步"
- ID 命名规范：
  - 所有元素 ID 以 scene1- 为前缀
  - 示例：scene1-dna-a-chain, scene1-dna-b-chain, scene1-primer-1, scene1-primer-2
  - 按钮 ID：scene1-btn-prev, scene1-btn-next, scene1-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
- 状态配置示例：
  ```javascript
  const stepConfig = {
    0: ['dna-a-chain', 'dna-b-chain', 'primer-1-placeholder', 'label-a', 'label-b'],
    1: ['dna-single-1', 'dna-single-2', 'temp-95'],
    2: ['dna-a-chain', 'dna-b-chain', 'primer-1', 'primer-2', 'temp-55'],
    3: ['dna-extending-1', 'dna-extending-2', 'new-chain-1', 'new-chain-2', 'temp-72'],
    4: ['product-dna-1', 'product-dna-2', 'product-label-1', 'product-label-2']
  };
  ```
