[分步序列]
步骤 0（初始状态）：
- 显示：标题、a 链和 b 链模板（完整线段+5'/3'标识+序列文本"G-G······T-C"和"C-C······A-G"）
- 隐藏：引物序列框内容、结合位置高亮、方向箭头、碱基配对线
- 目的：展示题目基础条件，让学生观察模板链结构

步骤 1（推导引物Ⅰ序列）：
- 显示：引物Ⅰ序列框内填写"5'-G-G-OH"（蓝色文字#1565c0）
- 高亮：a 链左端区域（引物Ⅰ结合位点）
- 新增：从引物Ⅰ框到 a 链左端的引导虚线（灰色）
- 目的：展示引物Ⅰ与 a 链 5'端的对应关系

步骤 2（推导引物Ⅱ序列）：
- 显示：引物Ⅱ序列框内填写"5'-C-C······A-G-3'"（红色文字#c62828）
- 高亮：b 链右端区域（引物Ⅱ结合位点）
- 新增：从引物Ⅱ框到 b 链右端的引导虚线（灰色）
- 目的：展示引物Ⅱ与 b 链 3'端的对应关系（碱基互补）

步骤 3（展示引物结合位置）：
- 显示：结合位置示意图完整呈现
- 高亮：引物Ⅰ结合区（蓝色半透明块，x=140-240，y=340-350）
- 高亮：引物Ⅱ结合区（红色半透明块，x=560-660，y=380-390）
- 新增：碱基配对虚线（引物Ⅰ与 a 链左端、引物Ⅱ与 b 链右端）
- 目的：直观展示引物在模板链上的实际结合位置

步骤 4（标注延伸方向）：
- 显示：方向箭头（绿色#2e7d32）
- 引物Ⅰ方向箭头：从 x=245 指向 x=285（向右，表示 5'→3'延伸）
- 引物Ⅱ方向箭头：从 x=515 指向 x=555（向右，表示 5'→3'延伸）

- 目的：验证 DNA 聚合酶只能从 5'向 3'方向合成新链

[交互方案]

  - 「上一步」按钮：位于 SVG 内底部左侧 (220,455)-(380,485)，灰色背景，点击返回上一状态
  - 「下一步」按钮：位于 SVG 内底部右侧 (420,455)-(580,485)，蓝色背景，点击进入下一状态

  3. 点击「下一步」，展示引物Ⅱ序列推导（步骤 2），讲解碱基互补配对原则
  4. 点击「下一步」，展示结合位置示意图（步骤 3），直观呈现引物在模板上的实际结合位点

  6. 教师可随时点击「上一步」回退复习关键概念

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：本场景为 2D 几何图形和文本标注，无需复杂图表库；原生 SVG 轻量且易于精确控制坐标；状态切换简单，无需动画库
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌────────────────────────────────────────────────────┐
  │              引物结合位置与方向 (标题 y=35)         │
  │                                                    │
  │  a 链  5'────G-G······T-C────3'  (y=85)            │
  │  b 链  3'────C-C······A-G────5'  (y=125)           │
  │                                                    │
  │  引物Ⅰ [5'-G-G-OH            ]  (y=205-235) 蓝色   │
  │  引物Ⅱ [5'-C-C······A-G-3'   ]  (y=255-285) 红色   │
  │                                                    │
  │            引物结合位置 (y=315)                    │
  │  a 链 ────████████────  (y=345) 蓝色高亮区         │
  │  b 链 ────████████────  (y=385) 红色高亮区         │
  │         →5'→3'            →5'→3'  绿色箭头         │
  │                                                    │
  │     [◀上一步]  步骤 X/5  [下一步▶]  (y=445-485)    │
  └────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量 (0-4) 跟踪当前步骤，steps 数组存储每步的可见元素 ID 列表
  2. 坐标计算：所有元素使用绝对坐标（非相对定位），确保多场景合并时不偏移
  3. 动画曲线：步骤切换使用 CSS transition: opacity 0.3s ease-in-out 实现淡入淡出
  4. 事件绑定：按钮点击事件绑定到 updateStep() 函数，更新 currentState 并调用 renderStep()
  5. 元素显隐：每步通过 display: none/block 控制元素可见性，而非删除 DOM 节点
- ID 命名规范：所有交互元素 ID 必须以 scene2- 为前缀
  - 示例：scene2-title, scene2-chain-a, scene2-chain-b, scene2-primer1-box, scene2-primer2-box, scene2-binding-area-1, scene2-binding-area-2, scene2-arrow-1, scene2-arrow-2, scene2-btn-prev, scene2-btn-next, scene2-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
- CDN 引入：无需外部库，纯原生实现
