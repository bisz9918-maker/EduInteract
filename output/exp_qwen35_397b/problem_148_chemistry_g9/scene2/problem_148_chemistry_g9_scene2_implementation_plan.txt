[分步序列]
- 初始状态（步骤 0）：显示配平方程式 CH₄ + H₂O → CO + 3H₂，四个系数（1,1,1,3）用蓝色圆圈高亮显示，其他区域空白
- 步骤 1：点击「下一步」→ 显示左侧分子个数比柱状图，丙柱（80px 高）和丁柱（240px 高）出现，上方标注"1"和"3"，中间显示"1 : 3"，右侧仍空白
- 步骤 2：点击「下一步」→ 显示右侧质量比计算区，三行计算式依次出现：乙(H₂O)=18、丁(3×H₂)=6、乙:丁=18:6=3:1（绿色）
- 步骤 3：点击「下一步」→ 显示结论区，两行文本："✓ 选项 D 正确：丙和丁的分子个数比为 1:3"、"✓ 选项 C 正确：乙和丁的质量比为 3:1"
- 最终状态：所有元素完整显示，教师可点击「上一步」回退复习任一步骤

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于(250,455)，灰色背景，点击后退到前一状态
  - 「下一步」按钮：位于(450,455)，蓝色背景#1565c0，点击前进到下一状态
  - 步骤指示器：位于两按钮之间，显示"步骤 X/4"
- 教师操作流程：
  1. 初始展示配平方程式，讲解反应物与生成物
  2. 点击「下一步」展示分子个数比柱状图，直观对比丙:丁=1:3
  3. 点击「下一步」展示质量比计算过程，推导乙:丁=3:1
  4. 点击「下一步」展示结论，确认选项 C、D 的正确性
  5. 可随时点击「上一步」回退复习关键步骤

[技术实现]
- JS 库选择：原生 SVG（简单几何图形和文本，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +------------------------------------------+
  |         标题：反应方程式与定量分析        | y=35
  +------------------------------------------+
  |  方程式：CH₄ + H₂O → CO + 3H₂            | y=70-130
  |  （系数高亮显示）                         |
  +------------------------------------------+
  |  分隔线                                   | y=150
  +------------------------------------------+
  |  [分子个数比]        [质量比计算]        | y=180-320
  |   丙□  丁□□□        乙=18               |
  |   1 : 3              丁=6                |
  |                      乙:丁=3:1           |
  +------------------------------------------+
  |         结论区（选项 C、D 判断）          | y=350
  +------------------------------------------+
  |                                          |
  |        [◀上一步]  步骤 X/4  [下一步▶]    | y=440-490
  +------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用 currentState 变量（0-4）跟踪当前步骤，steps 数组存储每步显示的元素 ID 列表
  2. 坐标计算：所有元素使用绝对坐标，柱状图高度按比例缩放（1 单位=80px）
  3. 动画曲线：元素出现使用淡入效果（opacity 0→1，duration 300ms）
  4. 事件绑定：按钮点击事件切换状态，更新显示元素集合
  5. ID 命名规范：所有元素 ID 以 scene2- 为前缀（如 scene2-equation、scene2-bar-bing、scene2-btn-next）
  6. IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
- 元素 ID 列表：
  - scene2-title（标题）
  - scene2-equation（方程式组）
  - scene2-coeff-1~4（四个系数标签）
  - scene2-divider（分隔线）
  - scene2-left-title（左侧标题）
  - scene2-bar-bing（丙柱状图）
  - scene2-bar-ding（丁柱状图）
  - scene2-ratio-text（比例文本）
  - scene2-right-title（右侧标题）
  - scene2-calc-1~3（三行计算式）
  - scene2-conclusion（结论区）
  - scene2-btn-prev（上一步按钮）
  - scene2-btn-next（下一步按钮）
  - scene2-step-indicator（步骤指示器）
