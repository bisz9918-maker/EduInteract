[图示主题与整合说明]
- 本图示主题：化学反应前后微观粒子对比与识别
- 整合的内容：图例说明、反应前粒子组成（甲框）、反应后粒子组成（乙框）、生成物粒子识别
- 教学价值：教师可使用此图示逐步引导学生从识别原子图例→分析反应前物质组成→分析反应后物质组成→区分哪些是生成物，形成完整的认知链条，帮助学生理解化学反应的本质是原子重新组合

[分步序列]
- 初始状态（步骤 0）：显示图例区（三个原子模型及标签 a/b/c）、甲框（含 4 个 a₂分子和 2 个 cb₂c 分子）、乙框（含反应后所有粒子）、反应箭头、甲/乙标签。无高亮。
- 步骤 1：点击「下一步」→ 高亮甲框中的 4 个 a₂分子（蓝色虚线框包围），在甲框上方显示数量标注"4 个 a₂"（坐标 300,60）
- 步骤 2：点击「下一步」→ 保持步骤 1 的高亮，新增高亮甲框中的 2 个 cb₂c 分子（蓝色虚线框），在甲框下方显示数量标注"2 个 cb₂c"（坐标 300,230）
- 步骤 3：点击「下一步」→ 清除甲框高亮，高亮乙框中的 2 个 c 原子（红色单独大圆），在乙框右侧显示标注"c 原子"（坐标 730,140）
- 步骤 4：点击「下一步」→ 保持步骤 3 高亮，新增高亮乙框中的 2 个 b₂分子（绿色双原子），在乙框右侧显示标注"b₂分子"（坐标 730,120）
- 步骤 5：点击「下一步」→ 清除 c 原子和 b₂分子高亮，高亮乙框中的 4 个 a₂b 分子，在乙框上方显示红色加粗标注"生成物"（坐标 600,60）
- 步骤 6：点击「下一步」→ 保持步骤 5 高亮，在画布底部中央显示结论文本"乙框中属于生成物的粒子有 1 种：a₂b"（坐标 400,280，红色# c62828）

  - 上一步按钮：位于 (280,460)，点击后返回上一状态，第一步时禁用

- 教师操作流程：

  4. 可随时点击「上一步」回退复习关键概念

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：本图示为 2D 静态图形 + 简单高亮动画，无需复杂库；原生 SVG 可精确控制每个原子和分子的位置，便于高亮和状态切换
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +----------------------------------------------------------+
  | [图例]    [甲框：反应前]  →  [乙框：反应后]              |
  |  a ●     +------------+     +------------+               |
  |  b ●     | a₂ a₂      |     | c   b₂     |               |
  |  c ●     | cb₂c       |     | a₂b  a₂b   |               |
  |          | a₂ a₂      |     | b₂   a₂b   |               |
  |          | cb₂c       |     |      a₂b   |               |
  |          +------------+     +------------+               |
  |             甲                    乙                     |
  |                                                          |
  |              [结论文本区 - 步骤 6 显示]                  |
  +----------------------------------------------------------+
  |              [◀上一步] 步骤 X/6 [下一步▶]                |
  |                   (控件栏 y=440-490)                     |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量 (0-6)，steps 数组存储每个状态的配置
  2. 每个状态配置包含：highlightElements 数组（要高亮的元素 ID 列表）、labels 数组（要显示的标签及其坐标）
  3. 高亮实现：对目标元素添加 CSS class "highlight"（蓝色虚线边框）或绘制高亮矩形覆盖
  4. 动画曲线：高亮框出现使用 ease-out 过渡，duration 300ms
  5. 事件绑定：按钮点击事件绑定到 updateState() 函数，更新当前状态并重新渲染
  6. 按钮禁用逻辑：currentState===0 时禁用上一步，currentState===6 时禁用下一步
- ID 命名规范：所有元素 ID 以 scene1- 为前缀
  - 图例：scene1-legend-a, scene1-legend-b, scene1-legend-c
  - 甲框分子：scene1-jia-a2-1~4, scene1-jia-cb2c-1~2
  - 乙框粒子：scene1-yi-c-1~2, scene1-yi-b2-1~2, scene1-yi-a2b-1~4
  - 高亮框：scene1-highlight-box
  - 标签：scene1-label-xxx
  - 按钮：scene1-btn-prev, scene1-btn-next, scene1-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
