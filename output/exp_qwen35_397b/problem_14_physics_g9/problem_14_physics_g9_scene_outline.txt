    **题目原文：**

    如图所示，重为50N的物体A在拉力F作用下沿水平面做匀速直线运动．已知滑轮组机械效率为80%，物体运动的速度为1m/s，下列分析计算正确的是（  ）

    A．物体所受合力为5N

    B．物体受到的摩擦力为12N

    C．拉力F做功的功率为5W

    D．在10s内机械所做的有用功为500J

    **题目分析：**

    本题是滑轮组与机械效率的综合计算题。关键信息：
    - 物体A重50N，在水平面上运动（重力不做功，摩擦力是有用阻力）
    - 匀速直线运动→合力为0
    - 滑轮组机械效率η=80%
    - 物体速度v=1m/s
    - 从图中可知：n=3段绳子承担动滑轮，拉力F=5N

    **整体讲解思路：**

    1. 先分析滑轮组结构，确定绳子段数n
    2. 理解水平滑轮组的有用功是克服摩擦力做功
    3. 利用机械效率公式求摩擦力
    4. 计算拉力的功率
    5. 逐项判断选项

    **图示规划说明：**

    本图示帮助学生理解滑轮组的结构特点和力的传递关系。

    **引导学生观察：**

    1. 数一数有几段绳子承担动滑轮（答案：n=3）
    2. 拉力F作用在绳子自由端，方向向左
    3. 物体A匀速运动，水平方向受力平衡

    **关键公式推导：**

    1. 绳子自由端移动距离与物体移动距离关系：s_绳 = n × s_物 = 3s_物

    2. 绳子自由端速度与物体速度关系：v_绳 = n × v_物 = 3 × 1m/s = 3m/s

    3. 匀速运动时物体A受力平衡：滑轮组对物体的拉力 T = 摩擦力 f

    4. 理想情况下（不计滑轮重和摩擦）：T = nF = 3 × 5N = 15N

    5. 但实际存在机械效率，需结合η=80%计算实际摩擦力

    <TEXT_3>
    **教学说明：**

    本图示重点讲解机械效率在水平滑轮组中的应用，这是学生的易错点。

    **关键概念澄清：**

    1. **水平滑轮组的有用功**：不是克服重力做功，而是克服摩擦力做功
       - W_有用 = f × s_物（f是摩擦力，不是重力）

    2. **机械效率的物理意义**：有用功占总功的比例
       - η = W_有用 / W_总 = (f × s_物) / (F × s_绳) = (f × s_物) / (F × 3s_物) = f / (3F)

    3. **摩擦力的计算**：
       - 由η = f / (nF) 得：f = η × n × F = 0.8 × 3 × 5N = 12N

    4. **功率的计算**：
       - P = W_总 / t = F × s_绳 / t = F × v_绳 = F × n × v_物
       - P = 5N × 3 × 1m/s = 15W

    5. **10s内的有用功**：
       - s_物 = v × t = 1m/s × 10s = 10m
       - W_有用 = f × s_物 = 12N × 10m = 120J
    </TEXT_3>

    **总结与课堂讲解建议：**

    **完整解答：**

    | 选项 | 分析 | 判断 |
    |------|------|------|
    | A | 物体匀速直线运动，处于平衡状态，合力为0 | 错误 |
    | B | f = η×n×F = 0.8×3×5N = 12N | 正确 |
    | C | P = F×v_绳 = F×n×v = 5N×3×1m/s = 15W | 错误 |
    | D | W_有用(10s) = f×s = 12N×10m = 120J | 错误 |

    **答案：B**

    **课堂讲解建议：**

    1. **先让学生观察滑轮组结构**，数出绳子段数n=3，这是解题的基础

    2. **强调水平滑轮组的特殊性**：有用功是克服摩擦力，不是克服重力

    3. **机械效率公式的变形应用**：η = f/(nF) → f = η×n×F，这是求摩擦力的关键

    4. **功率计算的两种方法**：P = W/t 或 P = Fv，本题用P = F×v_绳更简便

    5. **易错点提醒**：
       - 匀速运动合力为0（不是5N）
       - 功率计算要用绳子自由端的速度（3m/s），不是物体速度（1m/s）
       - 10s有用功是120J，不是500J（500J是用重力50N×10m算的，完全错误）

    **拓展思考：**

    - 如果物体加速运动，合力不为0，如何分析？
    - 如果滑轮组竖直提升物体，有用功如何计算？
    - 机械效率小于100%的原因是什么？（滑轮重、绳与滑轮摩擦）
