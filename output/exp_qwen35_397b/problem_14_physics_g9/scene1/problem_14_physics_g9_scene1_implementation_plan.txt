[图示主题与整合说明]
- 本图示主题：滑轮组结构分析与受力关系
- 整合内容：滑轮组绳子段数识别、拉力与摩擦力的关系、匀速运动受力平衡

  - 视觉变化：显示右侧受力分析图框及内容
  - 新增元素：

  - 教师讲解点：匀速直线运动时物体受力平衡，拉力T等于摩擦力f

  2. 点击「下一步」高亮3段承重绳，引导学生数绳子段数n=3

[技术实现]
- JS库选择：原生SVG + 原生JavaScript
  - 原因：几何图形简单，无需复杂库；SVG便于精确控制坐标和样式；原生JS足够实现分步状态切换
- 画布尺寸：800×500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +----------------------------------------------------------+
  |  [滑轮组主图区 x=20-480]    |  [受力分析区 x=520-760]    |
  |                              |                            |
  |   墙面  定滑轮  动滑轮  物体A  |  +--------------------+  |
  |   ||    (O)-----(O)----[A]   |  | 物体A受力分析      |  |
  |   ||     |       |           |  |                    |  |
  |   ||_____│_______│___________|  |   ←f  [物体]  T→   |  |
  |   地面~~~~~~~~~~~~~~~~~~~~~~~  |  |                    |  |
  |         F=5N←                  |  |  f = 3F×η = 12N   |  |
  |                              |  |  合力 = 0           |  |
  |                              |  +--------------------+  |
  |                              |                            |
  |         [上一步] [步骤1/3] [下一步]                       |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用currentIndex变量(0-3)跟踪当前步骤，steps数组存储每步的可见元素ID列表
  2. 坐标计算：所有元素使用绝对坐标（SVG viewBox="0 0 800 500"），确保缩放一致性
  3. 动画曲线：绳子高亮使用CSS transition: stroke 0.3s ease, stroke-width 0.3s ease
  4. 事件绑定：按钮点击事件绑定到updateStep()函数，更新可见性并刷新步骤指示器
  5. 元素可见性：使用display属性或opacity控制，初始隐藏元素设置opacity=0
- ID命名规范：所有元素ID以scene1-为前缀
  - scene1-wall, scene1-ground, scene1-fixed-pulley, scene1-movable-pulley
  - scene1-object-a, scene1-rope-seg1, scene1-rope-seg2, scene1-rope-seg3
  - scene1-arrow-f, scene1-label-f, scene1-label-n3, scene1-label-f5n
  - scene1-analysis-box, scene1-analysis-object, scene1-analysis-arrow-t
  - scene1-analysis-arrow-f, scene1-formula-text, scene1-net-force-text
  - scene1-btn-prev, scene1-btn-next, scene1-step-indicator
- IIFE隔离：所有JS代码包裹在(function() { ... })()中，避免全局变量污染
- CDN引入：无需额外库，使用原生SVG和JavaScript
