[图示主题与整合说明]
- 本图示主题：机械效率与功的计算关系
- 整合的内容：有用功定义、总功计算、机械效率公式应用、功率计算
- 教学价值：教师可通过分步展示，帮助学生理解水平滑轮组中机械效率的物理意义，掌握有用功（克服摩擦力做功）与总功（拉力做功）的区别，学会运用η=W_有用/W_总进行推导计算。分步导航让教师可控制节奏，逐步揭示计算链条。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 上一步按钮：位于(200,450)-(320,480)，点击返回上一状态，步骤0时禁用
  - 下一步按钮：位于(480,450)-(600,480)，点击进入下一状态，步骤4时显示"完成"
  - 步骤指示：位于(400,465)，显示当前步骤"步骤 X/4"
- 教师操作流程：
  1. 初始展示效率公式，讲解机械效率定义
  2. 点击"下一步"展示有用功定义，强调水平滑轮组中有用功是克服摩擦力
  3. 点击"下一步"展示总功定义，对比有用功与总功的关系
  4. 点击"下一步"展示摩擦力和功率计算，推导 f=η×n×F
  5. 点击"下一步"展示10s内有用功计算，完成完整计算链条
  6. 可随时点击"上一步"回退复习关键概念

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：本场景以公式文本和简单几何图形为主，无需复杂图表库；原生实现轻量且易于多场景合并
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │  [公式标题区 η = W_有用/W_总 = 80%]                         │ y=30-90
  ├─────────────────────────────────────────────────────────────┤
  │  [有用功框]           [连接]           [总功框]             │ y=110-170
  │  W_有用=f×s_物         →→→→           W_总=F×s_绳           │
  │       ↓                                  ↓                  │ y=170-200
  ├─────────────────────────────────────────────────────────────┤
  │  [计算行1] f = η×n×F = 0.8×3×5N = 12N ■                    │ y=210-260
  │  [计算行2] P = F×v_绳 = 5N×3m/s = 15W ■                    │ y=270-320
  │  [计算行3] W_有用 = f×s = 12N×10m = 120J ■                 │ y=330-380
  ├─────────────────────────────────────────────────────────────┤
  │                                                             │
  │         [◀ 上一步]    步骤 X/4    [下一步 ▶]                │ y=440-490
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用 currentStep 变量(0-4)跟踪当前步骤，steps 数组存储每步的可见元素ID列表
  2. 元素显示/隐藏：通过 CSS class "visible" 控制 opacity 和 display
  3. 动画效果：使用 CSS transition 实现淡入（opacity）、滑入（transform）
  4. 按钮状态：步骤0禁用上一步，步骤4将下一步文字改为"完成"并禁用
  5. 事件绑定：按钮点击事件调用 updateStep(direction) 函数
- ID 命名规范：
  - 所有元素 ID 以 "scene2-" 为前缀
  - 示例：scene2-title-box, scene2-efficiency-formula, scene2-useful-work-box, scene2-total-work-box, scene2-calc-row1, scene2-calc-row2, scene2-calc-row3, scene2-result-12n, scene2-result-15w, scene2-result-120j, scene2-btn-prev, scene2-btn-next, scene2-step-indicator
- IIFE 隔离：
  ```javascript
  (function() {
      // 所有 scene2 相关代码包裹在此
      const currentStep = 0;
      // ...
  })();
  ```
