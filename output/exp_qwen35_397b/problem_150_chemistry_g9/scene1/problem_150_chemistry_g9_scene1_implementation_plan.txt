[图示主题与整合说明]
- 本图示主题：图甲反应装置及一氧化碳、氢气还原氧化铁的产物生成
- 整合的内容：整合了图甲装置结构、CO 还原反应方程式、H₂还原反应方程式、两种产物的标识
- 教学价值：教师可使用此图示逐步讲解一氧化碳和氢气还原氧化铁的实验原理，从装置认知到反应过程再到产物分析，形成完整的认知递进。分步导航让教师可以控制讲解节奏，配合课堂提问和讨论。

[分步序列]
- 初始状态（步骤 0）：显示图甲装置完整结构（铁架台、硬质玻璃管、氧化铁粉末、酒精喷灯），显示标题"图甲：一氧化碳/氢气还原氧化铁"，右侧方程式区域空白，出口箭头隐藏
- 步骤 1：高亮氧化铁粉末（添加发光效果），在氧化铁上方显示标签"氧化铁"，左侧显示 CO 和 H₂入口箭头及标签
- 步骤 2：在右侧上方显示 CO 还原反应方程式"3CO + Fe₂O₃ → 2Fe + 3CO₂"，显示 CO₂分子示意图，显示 CO₂出口箭头及标签
- 步骤 3：在右侧下方显示 H₂还原反应方程式"3H₂ + Fe₂O₃ → 2Fe + 3H₂O"，显示 H₂O 分子示意图，显示 H₂O 出口箭头及标签
- 步骤 4：同时高亮两个方程式，CO₂和 H₂O 出口箭头同时闪烁动画，步骤指示器显示"完成"

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮：位置 (650,450)-(730,480)，点击后返回上一状态，步骤 0 时禁用
  - 下一步按钮：位置 (740,450)-(820,480)，点击后进入下一状态，步骤 4 时变为"完成"
  - 步骤指示器：位置 (20,460)，显示当前步骤编号"步骤 X/5"
- 教师操作流程：
  1. 初始展示装置结构，让学生识别各部件名称
  2. 点击"下一步"，高亮氧化铁，引入反应物 CO 和 H₂
  3. 点击"下一步"，展示 CO 还原反应，讲解产物 CO₂
  4. 点击"下一步"，展示 H₂还原反应，讲解产物 H₂O
  5. 点击"下一步"，总结两种反应的共同点和差异

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript。原因：本场景以静态图示和简单动画为主，无需复杂数据可视化或 3D 效果，原生方案轻量且易于控制。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │ [标题：图甲：一氧化碳/氢气还原氧化铁]                        │
  │                                                             │
  │  ┌──────────────┐                                          │
  │  │   图甲装置    │     ┌─────────────────────────┐          │
  │  │  (60% 宽度)   │     │   方程式区域 (40% 宽度)    │          │
  │  │              │     │                         │          │
  │  │  铁架台+玻璃管│     │  [CO 还原方程式]          │          │
  │  │  氧化铁+酒精灯│     │  [H₂还原方程式]           │          │
  │  │              │     │                         │          │
  │  │  ←CO/H₂入口  │     │  分子示意图              │          │
  │  │  CO₂/H₂O 出口→│     │                         │          │
  │  └──────────────┘     └─────────────────────────┘          │
  │                                                             │
  │  [步骤指示器]                    [◀上一步] [下一步▶]        │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-4），每个状态对应一组可见元素
  2. 元素分组：将相关元素按状态分组，使用 CSS class 控制显示/隐藏
  3. 动画效果：使用 CSS transition 实现箭头出现/高亮闪烁效果
  4. 事件绑定：按钮点击事件切换状态，更新可见元素和步骤指示器
  5. 边界处理：步骤 0 禁用上一步，步骤 4 下一步显示"完成"
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀
  - scene1-device-group（装置组）
  - scene1-oxide-label（氧化铁标签）
  - scene1-co-arrow（CO 入口箭头）
  - scene1-h2-arrow（H₂入口箭头）
  - scene1-co2-arrow（CO₂出口箭头）
  - scene1-h2o-arrow（H₂O 出口箭头）
  - scene1-equation-co（CO 方程式）
  - scene1-equation-h2（H₂方程式）
  - scene1-btn-prev（上一步按钮）
  - scene1-btn-next（下一步按钮）
  - scene1-step-indicator（步骤指示器）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
