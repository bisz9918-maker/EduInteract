    我国是世界上第一个在海域成功试采可燃冰的国家，可燃冰主要含有甲烷水合物，用作燃料时反应的微观示意图如图，下列说法正确的是（  ）

    C．反应的化学方程式为 CH₄ + O₂ $\xrightarrow{点燃}$ CO₂ + H₂O

    D．该反应属于置换反应

    **题目分析：**

    本题通过微观示意图考查化学反应的本质理解。图中展示了甲烷（CH₄）与氧气（O₂）在点燃条件下反应生成二氧化碳（CO₂）和水（H₂O）的过程。

    1. 首先识别各分子的化学式（根据原子图例）
    2. 写出配平的化学方程式
    3. 逐一分析四个选项
    4. 重点讲解质量守恒定律（原子数目不变）和质量比计算

    **教学说明：**

    本图示用于帮助学生从微观角度理解化学反应的本质。

    **讲解要点：**

    1. **分子识别**：引导学生根据图例识别各分子
       - A 分子：1 个碳原子 + 4 个氢原子 → CH₄（甲烷）
       - B 分子：2 个氧原子 → O₂（氧气）
       - C 分子：1 个碳原子 + 2 个氧原子 → CO₂（二氧化碳）
       - D 分子：2 个氢原子 + 1 个氧原子 → H₂O（水）

    2. **方程式配平**：
       - 未配平：CH₄ + O₂ → CO₂ + H₂O
       - 配平后：**CH₄ + 2O₂ $\xrightarrow{点燃}$ CO₂ + 2H₂O**

    3. **反应类型判断**：
       - 置换反应定义：单质 + 化合物 → 新单质 + 新化合物
       - 本反应：化合物 (CH₄) + 单质 (O₂) → 化合物 (CO₂) + 化合物 (H₂O)
       - 结论：**不属于置换反应**（生成物无单质），属于氧化反应/燃烧反应

    **引导学生观察：** 点击"下一步"逐步展示，让学生先尝试自己写出方程式，再对比正确答案。

    **教学说明：**

    本图示用于验证质量守恒定律的微观本质——化学反应前后原子的种类和数目不变。

    **讲解要点：**

    1. **碳原子计数**：
       - 反应前：CH₄ 中含 1 个 C 原子
       - 反应后：CO₂ 中含 1 个 C 原子
       - 结论：1 = 1 ✓

    2. **氢原子计数**：
       - 反应前：CH₄ 中含 4 个 H 原子
       - 反应后：2H₂O 中含 2×2 = 4 个 H 原子
       - 结论：4 = 4 ✓

    3. **氧原子计数**：
       - 反应前：2O₂ 中含 2×2 = 4 个 O 原子
       - 反应后：CO₂ 中含 2 个 + 2H₂O 中含 2 个 = 4 个 O 原子
       - 结论：4 = 4 ✓

    4. **选项 A 判断**：**正确** ✓

    **核心概念强调：** 化学反应的本质是原子的重新组合，原子本身不会凭空产生或消失，这就是质量守恒定律的微观解释。

    **教学说明：**

    本图示用于讲解如何根据化学方程式计算反应物的质量比。

    **讲解要点：**

    1. **相对分子质量计算**：
       - CH₄：12 + 4×1 = **16**
       - O₂：2×16 = **32**

    2. **质量比计算**（注意化学计量数）：
       - 根据方程式 CH₄ + 2O₂ → CO₂ + 2H₂O
       - m(CH₄) : m(O₂) = (1×16) : (2×32) = 16 : 64 = **1 : 4**

    3. **选项 B 判断**：
       - 选项 B 声称质量比为 8:1
       - 实际计算结果为 1:4
       - 结论：**选项 B 错误** ✗

    **易错点提醒：** 学生容易忽略化学计量数，直接计算 16:32=1:2，或者将比例颠倒。强调必须用"相对分子质量 × 化学计量数"来计算参加反应的质量比。

    **完整解答总结：**
    - A ✓ 正确（原子数目不变）
    - B ✗ 错误（质量比应为 1:4，非 8:1）
    - C ✗ 错误（方程式未配平）
    - D ✗ 错误（不属于置换反应）

    **正确答案：A**
