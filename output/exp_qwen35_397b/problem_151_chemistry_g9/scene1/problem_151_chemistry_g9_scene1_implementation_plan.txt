[分步序列]
- 步骤 0（初始状态）：显示反应前区域（甲烷分子 A 和氧气分子 B），显示图例框，显示"反应前"文字，显示反应箭头和"点燃"文字。反应后区域空白。
- 步骤 1：在步骤 0 基础上，在甲烷分子下方显示"CH₄"，在氧气分子下方显示"O₂"，标签"A"和"B"高亮显示。
- 步骤 2：显示反应后区域（二氧化碳分子 C 和水分子 D），显示"反应后"文字，在二氧化碳下方显示"CO₂"，在水分子下方显示"H₂O"，标签"C"和"D"高亮显示。
- 步骤 3：在底部方程式区显示配平的化学方程式：CH₄ + 2O₂ → CO₂ + 2H₂O（使用 MathJax 渲染），方程式中的系数"2"用红色高亮。
- 步骤 4（最终步骤）：在方程式下方显示反应类型说明："该反应不属于置换反应（生成物有两种化合物）"，同时高亮显示正确选项 A"反应前后原子数目不变"。

[标签冲突检查]
- 标签"A"：坐标 (150, 265)
- 标签"B"：坐标 (280, 265)
- 标签"C"：坐标 (520, 265)
- 标签"D"：坐标 (650, 265)
- "反应前"：坐标 (180, 300)
- "反应后"：坐标 (580, 300)
- "点燃"：坐标 (415, 175)
- 图例文字"氢原子"：坐标 (670, 60)
- 图例文字"氧原子"：坐标 (670, 90)
- 图例文字"碳原子"：坐标 (670, 120)

冲突检查结果：
- "A"与"B"间距：130px → 无冲突
- "B"与"反应前"间距：√[(280-180)²+(265-300)²] ≈ 106px → 无冲突
- "C"与"D"间距：130px → 无冲突
- "D"与"反应后"间距：√[(650-580)²+(265-300)²] ≈ 78px → 无冲突
- 图例文字之间垂直间距：30px → 无冲突
- 所有标签与分子圆心的最小距离：氢原子标签距最近氢原子约 45px → 无冲突
- 方程式区 y=360 与反应后区域 y=300 间距 60px → 无冲突

结论：所有标签间距均≥20px，无重叠冲突。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - "上一步"按钮：位于 (250, 455)，初始状态禁用（灰色），步骤 1 起可用
  - "下一步"按钮：位于 (450, 455)，步骤 4 时禁用（灰色）
  - 步骤指示器：位于两按钮之间 (400, 465)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始状态展示反应物分子，引导学生识别 A 和 B 分别代表什么物质
  2. 点击"下一步"显示化学式，确认学生理解
  3. 点击"下一步"展示生成物，引导学生观察原子如何重新组合
  4. 点击"下一步"显示配平方程式，讲解配平方法（观察法：先配 C，再配 H，最后配 O）
  5. 点击"下一步"显示反应类型分析，引导学生判断各选项正误

[技术实现]
- JS 库选择及原因：
  - 原生 SVG：用于绘制分子结构、箭头、图例等几何元素，轻量且易于控制
  - MathJax（CDN）：用于渲染化学方程式，确保下标和箭头符号正确显示
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +----------------------------------------------------------+
  | [图例框]                                                 |
  |  ○氢原子                                                 |
  |  ●氧原子                                                 |
  |  ⊚碳原子                                                 |
  |                                                          |
  |   [A:CH₄]    [B:O₂]      点燃      [C:CO₂]   [D:H₂O]     |
  |    ⊚          ●●         →          ●⚫●      ●           |
  |   ○○○○       ●●                              ○○          |
  |                                                          |
  |   反应前                              反应后              |
  |                                                          |
  |        CH₄ + 2O₂ → CO₂ + 2H₂O (步骤 3 显示)              |
  |        反应类型说明 (步骤 4 显示)                         |
  |                                                          |
  |  [上一步]  步骤 X/5  [下一步]                             |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量 (0-4) 跟踪当前步骤，steps 数组存储每步的显示配置
  2. 坐标计算：所有分子原子坐标硬编码，确保布局精确
  3. 动画曲线：元素淡入使用 CSS transition opacity 0.3s ease
  4. 事件绑定：按钮点击事件绑定到 stepForward() 和 stepBack() 函数
  5. 按钮状态：每步更新时检查边界，步骤 0 禁用上一步，步骤 4 禁用下一步
- ID 命名规范：
  - 所有交互元素 ID 以 scene1- 为前缀
  - 示例：scene1-molecule-a, scene1-molecule-b, scene1-btn-prev, scene1-btn-next
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
- 碳原子斜线填充实现：使用 SVG pattern 定义斜线，应用到碳原子圆
