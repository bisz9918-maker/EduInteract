- 控件说明：

  - 「重置」按钮：位于底部右侧 (560,455)，点击回到初始状态
- 教师操作流程：
  1. 初始展示配平的化学方程式，引导学生观察反应物与生成物
  2. 点击「下一步」展示相对分子质量，复习计算方法
  3. 点击「下一步」展示计量数，强调配平后的系数
  4. 点击「下一步」展示质量比计算过程，逐步推导
  5. 点击「下一步」展示最终结果并与选项 B 对比，得出结论

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript。本场景为静态文本标注 + 分步显示，无需复杂动画或绘图库，原生实现最轻量
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────┐
  │              反应物质量比计算 (标题 y=35)                │
  │                                                         │
  │         CH₄ + 2O₂ → CO₂ + 2H₂O (方程式 y=100)           │
  │                                                         │
  │    [16]    [32]    [44]    [18]  (相对分子质量 y=150)   │
  │     ↓       ↓       ↓       ↓                           │
  │    [×1]   [×2]    [×1]    [×2]  (计量数 y=202)          │
  │                                                         │
  │         m(CH₄) : m(O₂) (计算式 y=260)                   │
  │         = (1×16) : (2×32) (y=295)                       │
  │         = 16 : 64 (y=330)                               │
  │         = 1 : 4 (y=365, 绿色)                           │
  │                                                         │
  │    选项 B: 8:1 ✗ (红)    正确答案: 1:4 (绿) (y=410)     │
  │                                                         │
  │    [◀上一步]  [下一步▶]  [重置] (控件 y=455)            │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量（0-4）跟踪当前步骤，steps 数组存储每步需显示的元素 ID 列表
  2. 元素显示/隐藏：每步调用 updateDisplay() 函数，根据 currentStep 设置各元素 display 属性
  3. 按钮状态：步骤 0 时禁用「上一步」，步骤 4 时禁用「下一步」
  4. 动画效果：元素出现时使用淡入效果（opacity 0→1，transition 0.3s）
  5. 事件绑定：三个按钮分别绑定 click 事件，调用 handleStep() 函数
- ID 命名规范：所有元素 ID 以 scene3- 为前缀，如 scene3-title、scene3-equation、scene3-mass-ch4、scene3-step1-labels 等
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
