[图示主题与整合说明]
- 本图示主题：测定空气中氧气含量实验装置图
- 整合内容：整合实验装置整体结构、各部件名称标注、初始状态展示

[视觉元素清单]
- 集气瓶：带橡皮塞的广口瓶，瓶身有4条刻度线，底部有少量水
  - 瓶身轮廓：#000000 实线 2px
  - 橡皮塞：#555555 填充
  - 瓶内水：#1565c0 填充 透明度30%
- 燃烧匙：悬挂于集气瓶内，匙斗盛红磷
  - 匙柄：#000000 实线 2px
  - 匙斗：#000000 实线 2px 填充#888888
  - 红磷：#c62828 填充
- 导管：从橡皮塞穿出，经止水夹连接至烧杯
  - 导管：#000000 实线 3px
- 止水夹：夹在导管水平段上
  - 止水夹：#333333 填充
- 烧杯：盛有水，导管末端浸入水中
  - 杯身：#000000 实线 2px
  - 杯内水：#1565c0 填充 透明度30%，加水平虚线表示液面
- 刻度：1-4 等分标记，位于集气瓶左侧
  - 刻度线：#000000 实线 2px
  - 刻度数字：#000000 text
- 标注引线：#888888 虚线 1px
- 标注文字：#000000 text 14px

[分步序列]
步骤0（初始状态）：显示基础装置轮廓
- 显示：集气瓶瓶身、瓶口、橡皮塞、烧杯杯身、导管路径、止水夹轮廓
- 不显示：任何标注文字、刻度、瓶内水、红磷
- 高亮：无

步骤1：标注集气瓶和刻度
- 新增显示：刻度线1-4、刻度数字1-4、瓶内水填充
- 新增标注：「集气瓶」标签及引线（指向瓶身）
- 高亮：集气瓶瓶身轮廓加粗为3px，#2196f3 蓝色高亮

步骤2：标注燃烧匙和红磷
- 新增显示：燃烧匙柄、燃烧匙斗、红磷填充
- 新增标注：「燃烧匙」标签及引线、「红磷」标签及引线
- 高亮：燃烧匙和红磷区域 #ff9800 橙色高亮

步骤3：标注导管和止水夹
- 新增显示：导管完整路径（若步骤0未完全显示）
- 新增标注：「导管」标签及引线、「止水夹」标签及引线
- 高亮：导管路径 #4caf50 绿色高亮，止水夹 #795548 棕色高亮

步骤4：标注烧杯和水
- 新增显示：烧杯内水填充（水平虚线表示液面）
- 新增标注：「烧杯」标签及引线、「水」标签及引线（指向烧杯内水）
- 高亮：烧杯区域 #9c27b0 紫色高亮

步骤5（最终状态）：完整标注图
- 显示：所有元素和标注
- 高亮：取消所有高亮，恢复默认样式
- 教师可在此步骤进行整体讲解

[标签冲突检查]
所有标签坐标及冲突检查：
- 标签「集气瓶」：(180,120) — 位于集气瓶正上方，与橡皮塞距离约25px，无冲突
- 标签「燃烧匙」：(220,290) — 位于集气瓶右侧，与红磷标签水平错开
- 标签「红磷」：(300,295) — 位于燃烧匙右侧，与燃烧匙标签间距约80px，无冲突
- 标签「导管」：(420,105) — 位于导管水平段上方，与止水夹标签垂直错开
- 标签「止水夹」：(460,95) — 位于止水夹正上方，与导管标签间距约40px，无冲突
- 标签「烧杯」：(640,200) — 位于烧杯正上方，无冲突
- 标签「水」：(560,380) — 位于烧杯左侧，指向杯内水，与烧杯标签垂直错开约180px，无冲突
- 刻度数字1-4：(55,395/335/275/215) — 位于集气瓶左侧，彼此垂直间距60px，无冲突

冲突检查结论：所有标签间距均≥20px，无重叠冲突。标签均采用外侧偏移策略，避免压在图形元素上。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于控件栏左侧 (280,455)，点击返回上一状态，步骤0时禁用
  - 「下一步」按钮：位于控件栏右侧 (420,455)，点击进入下一状态，步骤5时禁用
  - 步骤指示器：位于两按钮之间，显示「步骤 X/5」
- 教师操作流程：
  1. 初始加载显示步骤0（基础装置），教师介绍实验目的
  2. 点击「下一步」→步骤1，教师讲解集气瓶结构和刻度作用
  3. 点击「下一步」→步骤2，教师讲解燃烧匙和红磷的作用
  4. 点击「下一步」→步骤3，教师讲解导管和止水夹的作用
  5. 点击「下一步」→步骤4，教师讲解烧杯和水的作用
  6. 点击「下一步」→步骤5，教师进行整体回顾，可点击「上一步」回退复习

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：本场景为静态实验装置图，无需复杂动画或交互，原生 SVG 足够实现且性能好
- 画布尺寸：800×500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +----------------------------------------------------------+
  |                                                          |
  |   集气瓶(左)                    导管         烧杯(右)    |
  |   +-------+                    ======       +-------+    |
  |   | 4     |                  ||    ||       | ~~~~~ |    |
  |   | 3  🔴 |==================||夹  ||=======| |水|  |    |
  |   | 2     |                  ||    ||       | ~~~~~ |    |
  |   | 1 ~~~ |                  ||    ||       |       |    |
  |   +-------+                    ======       +-------+    |
  |                                                          |
  |   [标注文字分布于装置周围上方和两侧]                      |
  |                                                          |
  +----------------------------------------------------------+
  |  [上一步]  步骤 X/5  [下一步]  (控件栏 y=440-490)         |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-5），每个状态对应一组显示/隐藏的元素
  2. 元素分组：将相关元素按功能分组（如集气瓶组、燃烧匙组、导管组等），每组有独立 ID
  3. 高亮效果：通过修改 stroke-width 和 stroke 属性实现高亮
  4. 事件绑定：按钮点击事件切换状态，更新显示/隐藏和高亮
  5. 步骤指示器：动态更新显示当前步骤编号
- ID 命名规范：所有元素 ID 以 scene1- 为前缀
  - scene1-bottle（集气瓶）
  - scene1-stopper（橡皮塞）
  - scene1-scale-1/2/3/4（刻度线）
  - scene1-scale-num-1/2/3/4（刻度数字）
  - scene1-water-bottle（瓶内水）
  - scene1-spoon（燃烧匙）
  - scene1-phosphorus（红磷）
  - scene1-tube（导管）
  - scene1-clamp（止水夹）
  - scene1-beaker（烧杯）
  - scene1-water-beaker（烧杯内水）
  - scene1-label-bottle（集气瓶标签）
  - scene1-label-spoon（燃烧匙标签）
  - scene1-label-phosphorus（红磷标签）
  - scene1-label-tube（导管标签）
  - scene1-label-clamp（止水夹标签）
  - scene1-label-beaker（烧杯标签）
  - scene1-label-water（水标签）
  - scene1-btn-prev（上一步按钮）
  - scene1-btn-next（下一步按钮）
  - scene1-step-indicator（步骤指示器）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
- 颜色规格：
  - 背景：#ffffff
  - 装置轮廓：#000000 实线 2px
  - 水：#1565c0 填充 透明度30%
  - 红磷：#c62828 填充
  - 标注文字：#000000
  - 标注引线：#888888 虚线 1px
  - 刻度线：#000000
  - 高亮色：步骤1 #2196f3 / 步骤2 #ff9800 / 步骤3 #4caf50 / 步骤4 #9c27b0
