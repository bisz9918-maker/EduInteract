[图示主题与整合说明]
- 本图示主题：测定空气中氧气含量实验——气压变化原理示意图
- 整合的步骤/概念：整合燃烧前后气压对比、水进入原因解释、氧气体积分数结论
- 教学价值：教师可通过状态切换逐步讲解实验原理——从初始状态（气压平衡）到燃烧后（氧气消耗、气压降低）再到打开止水夹（大气压将水压入），最后得出氧气约占空气体积 1/5 的结论。这种对比展示帮助学生理解"气压差"是水进入的根本原因，而非单纯记忆现象。

[交互方案]
- 交互类型：多状态切换（4 个状态按钮）
- 控件说明：
  - 按钮 1"燃烧前"：位置 (480,450)，切换到状态 0，展示初始气压平衡
  - 按钮 2"燃烧后"：位置 (580,450)，切换到状态 1，展示气压降低
  - 按钮 3"打开止水夹"：位置 (680,450)，切换到状态 2，展示水被压入
  - 按钮 4"结论"：位置 (480,480)，切换到状态 3，展示最终结论
- 教师操作流程：
  1. 点击"燃烧前"，讲解初始状态瓶内外气压相等，分子分布情况
  2. 点击"燃烧后"，讲解红磷燃烧消耗氧气，瓶内气压降低形成气压差
  3. 点击"打开止水夹"，讲解大气压将水压入瓶内，水占据约 1/5 体积
  4. 点击"结论"，总结氧气约占空气体积的 1/5

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript
  - 原因：本场景为 2D 示意图，元素数量适中（约 20-30 个 SVG 元素），无需复杂动画库；状态切换只需显示/隐藏元素，原生 JS 足够
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +----------------------------------------------------------+
  |  [集气瓶]    [导管]    [烧杯]        |  实验原理         |
  |     |         |         |            |  (标题)           |
  |  气压箭头   止水夹     水           |                   |
  |  分子示意                            |  [说明文字区]     |
  |                                      |                   |
  |                                      |  [结论框]         |
  |                                      |                   |
  |  [燃烧前] [燃烧后] [打开止水夹]      |                   |
  |  [结论]                              |                   |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-3），每个状态对应一组显示/隐藏规则
  2. 坐标计算：所有元素使用绝对坐标（SVG viewBox="0 0 800 500"）
  3. 动画曲线：状态切换使用 CSS transition（opacity 0.3s ease）实现平滑过渡
  4. 事件绑定：4 个按钮分别绑定 click 事件，调用 switchState(n) 函数
  5. 分子随机分布：预计算 50 个分子的随机坐标（种子固定以保证可重现），状态切换时调整 opacity
- ID 命名规范：所有交互元素 ID 必须以 scene3- 为前缀
  - 示例：scene3-bottle（集气瓶）、scene3-pressure-arrow-inner（瓶内气压箭头）、scene3-o2-molecule-1（氧气分子 1）、scene3-btn-state0（状态 0 按钮）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
