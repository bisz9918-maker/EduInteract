problem_153_chemistry_g9

场景导航：Scene 1 | Scene 2

题目原文：
现有氢气、氮气、氯化氢、水蒸汽、一氧化碳和二氧化碳混合气体，依次通过下图 A、B、C、D 装置（假设每步都充分反应），各装置依次除去的气体和最后得到的气体分别是（ ）

$\\begin{description}
\\item A．HCl、CO、H{2}、CO{2}、H{2}O、N{2}
\\item B．CO{2}、CO、H{2}、HCl、H{2}O、N{2}
\\item C．HCl、CO、H{2}、H{2}O、CO{2}、N{2}
\\item D．H{2}、CO、CO{2}、HCl、N{2}、H{2}O
\\end{description}$

题目分析：
本题考查混合气体通过不同化学装置时的成分变化，需分析每个装置的作用及反应后气体成分。关键点包括：

  1. 装置 A（碳酸氢钠溶液）：除去 HCl，生成 CO₂
  2. 装置 B（加热氧化铜）：除去 H₂和 CO，生成 CO₂和 H₂O
  3. 装置 C（澄清石灰水）：除去 CO₂
  4. 装置 D（浓硫酸）：除去 H₂O

最终剩余气体为 N₂。

整体讲解思路：

  1. 通过流程图展示气体通过各装置的顺序及成分变化
  2. 分步解析每个装置的化学反应及气体成分变化
  3. 对比选项，验证正确答案（选项 A）

图示规划说明：

  • Scene 1：四装置流程图，动态展示气体成分变化（分步导航）
  • Scene 2：各装置反应方程式及气体成分表格（分步导航）

教学说明：

  1. 引导学生观察初始混合气体成分（6 种气体）
  2. 点击「下一步」展示通过 A 装置后 HCl 被除去，生成 CO₂
  3. 继续点击展示 B 装置除去 H₂和 CO，生成 CO₂和 H₂O
  4. C 装置除去所有 CO₂，D 装置除去 H₂O
  5. 最终剩余 N₂，对应选项 A

关键公式：

  • A 装置：NaHCO₃ + HCl → NaCl + CO₂↑ + H₂O
  • B 装置：H₂ + CuO → Cu + H₂O；CO + CuO → Cu + CO₂
  • C 装置：Ca(OH)₂ + CO₂ → CaCO₃↓ + H₂O
  • D 装置：浓硫酸吸水（物理变化）

总结：

  1. 正确答案为选项 A：各装置依次除去 HCl、CO、H₂、CO₂、H₂O，最后剩余 N₂
  2. 课堂讲解建议：
  • 强调装置顺序不可颠倒（如先除 HCl 再除 CO₂）
  • 提醒学生注意 B 装置同时除去两种气体（H₂和 CO）
  • 通过图示动态演示帮助学生建立流程化思维
