[视觉元素清单]
- 装置 A（碳酸氢钠洗气瓶）：矩形瓶身 (60,180)-(140,320)，内含液体（浅蓝色 #e3f2fd），双导管（左进右出）
- 装置 B（加热氧化铜管）：水平玻璃管 (220,200)-(380,260)，内有氧化铜粉末（黑色 #424242），下方酒精灯（橙色火焰 #ff9800）
- 装置 C（澄清石灰水洗气瓶）：矩形瓶身 (460,180)-(540,320)，内含液体（透明浅蓝 #e3f2fd）
- 装置 D（浓硫酸洗气瓶）：矩形瓶身 (640,180)-(720,320)，内含液体（浅黄色 #fff9c4）
- 连接管道：黑色实线 #000000，线宽 4px
- 气体流向箭头：黑色实心箭头，指向右方
- 气体成分标签：使用指定颜色
  - HCl：红色 #c62828
  - CO：蓝色 #1565c0
  - H₂：绿色 #2e7d32
  - CO₂：橙色 #ff9800
  - H₂O：青色 #00bcd4
  - N₂：灰色 #888888
- 除去气体标注框：红色虚线框 #c62828，虚线样式
- 装置名称标签：黑色粗体，位于各装置正下方
- 试剂名称标签：黑色常规字体，位于装置下方或上方

[分步序列]
- 初始状态（步骤 0）：显示四个装置、连接管道、进气出气箭头；左侧显示"混合气体：H₂、N₂、HCl、H₂O、CO、CO₂"（各气体用对应颜色标签）；所有除去气体框隐藏
- 步骤 1（通过 A 后）：装置 A 上方红色虚线框出现，显示"除去 HCl"（红色#c62828）；气体成分区更新为"H₂、N₂、H₂O、CO、CO₂"（HCl 标签消失）
- 步骤 2（通过 B 后）：装置 B 上方红色虚线框出现，显示"除去 H₂、CO"（红色#c62828）；气体成分区更新为"N₂、H₂O、CO₂"（H₂和 CO 标签消失，注意 B 中生成 H₂O 和 CO₂但已被后续装置处理）
- 步骤 3（通过 C 后）：装置 C 上方红色虚线框出现，显示"除去 CO₂"（红色#c62828）；气体成分区更新为"N₂、H₂O"（CO₂标签消失）
- 步骤 4（通过 D 后）：装置 D 上方红色虚线框出现，显示"除去 H₂O"（红色#c62828）；气体成分区更新为"N₂"（H₂O 标签消失，仅剩灰色 N₂）
- 最终状态：所有装置上方均显示除去的气体，气体成分区仅显示"N₂"，可添加"最终得到：N₂"结论标注

[标签冲突检查]
- 标签"A"：坐标(100,340)
- 标签"B"：坐标(300,340)
- 标签"C"：坐标(500,340)
- 标签"D"：坐标(680,340)
- "A"与"B"间距：200px → 无冲突
- "B"与"C"间距：200px → 无冲突
- "C"与"D"间距：180px → 无冲突
- 试剂标签与装置标签垂直间距 20px → 无冲突
- 除去气体框 y=120~150，装置顶部 y=180，间距 30px → 无冲突
- 气体成分区 y=380~430，装置标签 y=340~370，间距 10px → 需确保气体标签不超出区域
- 控件栏 y=450~490，气体成分区 y=430，间距 20px → 无冲突

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 内底部左侧 (530,450)，点击回退到前一状态
  - 「下一步」按钮：位于 SVG 内底部右侧 (650,450)，点击进入下一状态
  - 步骤指示器：显示"步骤 X/5"，位于两按钮之间
- 教师操作流程：
  1. 初始状态展示混合气体成分和四个装置
  2. 点击「下一步」，装置 A 上方出现"除去 HCl"，气体成分更新
  3. 继续点击，依次展示 B、C、D 装置的除杂效果
  4. 可随时点击「上一步」回顾前一状态
  5. 最终状态展示仅剩 N₂，配合讲解得出答案

[技术实现]
- JS 库选择：原生 SVG（适合绘制装置、管道、箭头等几何图形，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────┐
  │  [除去 HCl]  [除去 H₂,CO]  [除去 CO₂]  [除去 H₂O]      │ y=120~150
  │                                                       │
  │     A         B           C           D               │ y=180~320
  │   [瓶]      [管]        [瓶]        [瓶]              │
  │    │         │           │           │                │
  │    A         B           C           D               │ y=340 装置名
  │  碳酸氢钠   氧化铜      石灰水      浓硫酸            │ y=360 试剂名
  │                                                       │
  │  [气体成分显示区：H₂ N₂ HCl H₂O CO CO₂]              │ y=380~430
  │                                                       │
  │         [◀上一步]  [步骤 2/5]  [下一步▶]             │ y=450~490
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用 currentState 变量（0~5）跟踪当前步骤
  2. 气体成分数组：初始 ['H₂','N₂','HCl','H₂O','CO','CO₂']，每步过滤
  3. 除去气体映射：{1:'HCl', 2:'H₂、CO', 3:'CO₂', 4:'H₂O'}
  4. 动画效果：除去气体框用淡入动画（opacity 0→1），气体标签用淡出动画
  5. 事件绑定：按钮点击事件切换状态，更新 DOM 元素可见性
- ID 命名规范：所有元素 ID 以 scene1- 为前缀，如 scene1-device-a、scene1-gas-h2、scene1-btn-next
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
