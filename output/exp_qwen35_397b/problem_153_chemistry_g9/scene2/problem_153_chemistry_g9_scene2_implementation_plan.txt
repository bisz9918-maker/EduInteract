[分步序列]
- 初始状态（步骤 0）：显示标题、装置 A 方程式（高亮#1565c0）、表格仅显示"初始"行（全部 6 种气体都存在，全✓）
- 步骤 1：点击「下一步」→ 装置 B 方程式出现（高亮），表格新增"装置 A"行（HCl 变为✗，CO₂新增✓，其他不变）
- 步骤 2：点击「下一步」→ 装置 C 方程式出现（高亮），表格新增"装置 B"行（H₂✗、CO✗，H₂O✓、CO₂✓）
- 步骤 3：点击「下一步」→ 装置 D 方程式出现（高亮），表格新增"装置 C"行（CO₂✗，其他不变）
- 步骤 4：点击「下一步」→ 表格新增"装置 D"行（H₂O✗），最终行显示（仅 N₂✓，其余全✗）
- 步骤 5（结论）：所有方程式和表格完整显示，最终气体 N₂高亮#2e7d32

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 (280,455)，点击回退到前一状态
  - 「下一步」按钮：位于 (420,455)，点击进入下一状态
  - 步骤指示：位于 (400,490)，显示当前步骤编号
- 教师操作流程：
  1. 初始状态展示装置 A 反应，讲解碳酸氢钠除去 HCl
  2. 点击「下一步」展示装置 B，讲解 H₂和 CO 还原氧化铜
  3. 点击「下一步」展示装置 C，讲解石灰水除去 CO₂
  4. 点击「下一步」展示装置 D，讲解浓硫酸干燥
  5. 点击「下一步」展示最终结果，强调仅剩 N₂
  6. 可随时点击「上一步」回退复习

[技术实现]
- JS 库选择：原生 SVG（简单几何和文本）+ 原生 JavaScript（状态管理）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |           各装置反应及气体成分变化 (标题)         | y=25
  |                                                  |
  |  A: NaHCO₃ + HCl → ... (方程式区 y=70~270)       |
  |  B: H₂ + CuO → ...                               |
  |  C: Ca(OH)₂ + CO₂ → ...                          |
  |  D: 浓 H₂SO₄ 吸收 H₂O                            |
  |                                                  |
  |  +------------------------------------------+    | y=290~420
  |  | 表格：气体成分变化 (6 列×5 行)              |    |
  |  +------------------------------------------+    |
  |                                                  |
  |     [◀上一步]  步骤 X/5  [下一步▶]               | y=455~490
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用 currentState 变量 (0-5) 跟踪当前步骤
  2. 方程式按步骤逐步显示（opacity 或 display 控制）
  3. 表格行按步骤逐步添加，单元格内填✓或✗
  4. 按钮事件绑定：点击更新 currentState，调用 render() 重绘
  5. 边界处理：步骤 0 时禁用「上一步」，步骤 5 时禁用「下一步」
- ID 命名规范：所有元素 ID 以 scene2- 为前缀
  - scene2-title, scene2-eq-a, scene2-eq-b, scene2-eq-c, scene2-eq-d
  - scene2-table, scene2-table-row-0~4
  - scene2-btn-prev, scene2-btn-next, scene2-step-indicator
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中
