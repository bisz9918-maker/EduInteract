[图示主题与整合说明]
- 本图示主题：物质转化关系整体框架与已知条件定位
- 整合的步骤/概念：整合了完整的七物质转化网络（A-G）、三个已知条件的标注（B-最常见酸、D-人体含量最多物质、G-蓝色不溶物）、三个反应编号标识（①②③）
- 教学价值：教师可使用此图示引导学生从整体到局部逐步理解转化关系，先展示完整框架建立全局认知，再依次高亮三个已知条件作为解题突破口，最后同时高亮建立解题起点，帮助学生形成系统化的推断思路

[分步序列]
- 初始状态（步骤 0）：显示完整转化关系图，所有 7 个物质框为灰色边框#888888，填充#f5f5f5，三个反应圆圈显示，所有连接线显示，三个已知条件标注框隐藏
- 步骤 1：点击「下一步」→ B 物质框高亮（边框#2e7d32 绿色，填充#c8e6c9），B 框下方显示标注框"最常见的酸"，其他元素保持步骤 0 状态
- 步骤 2：点击「下一步」→ B 保持高亮，D 物质框高亮（边框#2e7d32 绿色，填充#c8e6c9），D 框下方显示标注框"人体中含量最多的物质→H₂O"
- 步骤 3：点击「下一步」→ B、D 保持高亮，G 物质框高亮（边框#2e7d32 绿色，填充#c8e6c9），G 框下方显示标注框"蓝色不溶物→Cu(OH)₂"
- 步骤 4：点击「下一步」→ 三个已知物质 B、D、G 同时高亮显示，三个标注框全部可见，建立解题起点（最终状态）
- 教师可随时点击「上一步」回退复习

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 底部左侧 (280,460)，点击回退到上一状态
  - 「下一步」按钮：位于 SVG 底部右侧 (480,460)，点击前进到下一状态
  - 步骤指示器：位于中间 (400,460)，显示"步骤 X/4"
- 教师操作流程：
  1. 初始展示完整框架，让学生观察物质转化网络结构
  2. 点击「下一步」高亮 B，提问"最常见的酸是什么？"引导学生思考
  3. 点击「下一步」高亮 D，提问"人体中含量最多的物质是什么？"引出 H₂O
  4. 点击「下一步」高亮 G，提问"蓝色不溶物常见的是什么？"引出 Cu(OH)₂
  5. 点击「下一步」同时高亮三个已知物质，总结解题突破口
  6. 可随时点击「上一步」回退复习某个已知条件

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript，简单几何图形和状态切换无需额外库，轻量且兼容性好
- 画布尺寸：800 × 500 px（固定画布）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  A    →→→  ①  →→→  E(中)                         |
  |        ↘        ↙                                |
  |  B    →→→  ②  →→→  D            E(右)            |
  |        ↙        ↘              ↗                 |
  |  C    →→→  ②  →→→  F    →→→  ③  →→→  G          |
  |                                                   |
  |  [标注框：最常见的酸] [H₂O]      [Cu(OH)₂]        |
  |                                                   |
  |              [◀上一步] 步骤 X/4 [下一步▶]         |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量 (0-4) 跟踪当前步骤，steps 数组存储每个状态的配置
  2. 高亮逻辑：每个物质框有 data-id 属性，通过 getElementById 获取并切换 class（.highlighted）
  3. 标注框显示/隐藏：每个标注框有 data-step 属性，根据 currentState 控制 display 样式
  4. 按钮事件绑定：上一步/下一步按钮绑定 click 事件，更新 currentState 并调用 renderState()
  5. 边界处理：步骤 0 时禁用「上一步」，步骤 4 时禁用「下一步」
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀
  - scene1-box-a, scene1-box-b, scene1-box-c, scene1-box-d, scene1-box-e1, scene1-box-e2, scene1-box-f, scene1-box-g
  - scene1-reaction-1, scene1-reaction-2, scene1-reaction-3
  - scene1-label-b, scene1-label-d, scene1-label-g（已知条件标注框）
  - scene1-btn-prev, scene1-btn-next, scene1-step-indicator
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
