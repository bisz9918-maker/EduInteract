[分步序列]
- 初始状态（步骤 0）：显示转化关系图框架，8 个空物质框，3 个反应标号；已知条件标注：B 框内显示"H₂SO₄"（绿色背景），D 框内显示"H₂O"（绿色背景），G 框内显示"Cu(OH)₂↓"（绿色背景）
- 步骤 1：高亮反应③区域（E+F→G），右侧推理区显示"分析反应③：E + F → G(↓) + ...，G 为蓝色沉淀 Cu(OH)₂，说明反应物中一个含 Cu²⁺，另一个含 OH⁻"
- 步骤 2：E 框填充"CuSO₄"（蓝色背景），推理区显示"由反应①：A + 酸 B → E + H₂O，E 是铜盐，推测 E = CuSO₄"
- 步骤 3：F 框填充"NaOH"（蓝色背景），推理区显示"由反应③：CuSO₄ + F → Cu(OH)₂↓ + ...，F 必须是碱，推测 F = NaOH"
- 步骤 4：高亮反应①，A 框填充"CuO"（蓝色背景），推理区显示"由反应①：A + H₂SO₄ → CuSO₄ + H₂O，A 可能是 CuO（氧化物）或 Cu(OH)₂（碱）"
- 步骤 5：高亮反应②，C 框填充"Na₂CO₃"（蓝色背景），推理区显示"由反应②：C + H₂SO₄ → Na₂SO₄ + H₂O + CO₂↑，C 是碳酸盐，推测 C = Na₂CO₃"
- 步骤 6（最终）：底部答案框显示完整答案：(1) C=Na₂CO₃ (2) 复分解反应 (3) 氧化物或碱；推理区显示"推断完成！"

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 (280,450)，点击回退到前一推理步骤
  - 「下一步」按钮：位于 (420,450)，点击进入下一推理步骤
  - 步骤指示器：位于 (400,470)，显示当前步骤编号"步骤 X/6"
- 教师操作流程：
  1. 初始状态展示转化关系图和已知条件（B、D、G）
  2. 点击「下一步」逐步展示推理逻辑，每步高亮相关反应和物质
  3. 可随时点击「上一步」回退复习关键推理点
  4. 最终步骤显示完整答案，供学生核对

[技术实现]
- JS 库选择：原生 SVG（简单几何图形和箭头）+ 原生 JavaScript（状态管理）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  [转化关系图]           |  [推理过程区]          |
  |   A → E                 |  步骤文本显示区        |
  |   ↓   ↓                 |  (460,90)-(770,360)   |
  |   B → D                 |                        |
  |   ↓   ↓                 |                        |
  |   C → F → G             |                        |
  |                         |                        |
  |  [答案框 1][答案框 2][答案框 3] (y=380)          |
  +--------------------------------------------------+
  |     [◀上一步]  步骤 X/6  [下一步▶]  (y=450)      |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量（0-6），steps 数组存储每步的视觉状态配置
  2. 每步配置包含：需要高亮的元素 ID、需要显示的文本、需要填充化学式的物质框
  3. 动画效果：物质框填充使用 CSS transition，透明度从 0 到 1，时长 300ms
  4. 事件绑定：按钮点击事件绑定到 stepForward() 和 stepBackward() 函数
  5. 边界处理：步骤 0 时禁用「上一步」，步骤 6 时禁用「下一步」
- ID 命名规范：所有元素 ID 以 scene2- 为前缀
  - 物质框：scene2-box-a, scene2-box-b, scene2-box-c, scene2-box-e1, scene2-box-d1, scene2-box-f, scene2-box-e2, scene2-box-g
  - 反应标号：scene2-reaction-1, scene2-reaction-2, scene2-reaction-3
  - 箭头：scene2-arrow-1a, scene2-arrow-1b, scene2-arrow-2a, scene2-arrow-2b, scene2-arrow-3a, scene2-arrow-3b
  - 推理文本区：scene2-reasoning-text
  - 答案框：scene2-answer-1, scene2-answer-2, scene2-answer-3
  - 按钮：scene2-btn-prev, scene2-btn-next
  - 步骤指示器：scene2-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
