[图示主题与整合说明]
- 本图示主题：反应③复分解反应的微观本质（CuSO₄ + 2NaOH → Cu(OH)₂↓ + Na₂SO₄）
- 整合的内容：反应③的化学方程式、离子交换过程示意、沉淀生成动画
- 教学价值：教师可通过拖拽滑块演示两种溶液混合过程，学生直观观察 Cu²⁺与 OH⁻结合形成 Cu(OH)₂蓝色沉淀的微观过程，理解复分解反应"离子交换"的本质，区分沉淀物与溶液中剩余离子

[分步序列]
本场景采用「连续拖拽滑块」交互，配合滑块位置触发视觉状态变化：

状态 0（初始状态，滑块在最左端 0%）：
- 显示左侧两个烧杯：烧杯1 含 Cu²⁺(蓝色) 和 SO₄²⁻(灰色) 离子，烧杯2 含 Na⁺(灰色) 和 OH⁻(灰色) 离子
- 右侧烧杯3 为空或半透明
- 底部方程式框显示完整方程式但半透明（opacity=0.5）
- 滑块手柄位于最左端

状态 1（滑块拖拽至 50%，溶液开始混合）：
- 左侧离子开始向右侧烧杯3 移动（动画过渡）
- 烧杯3 中出现部分离子
- 方程式框 opacity=0.8

状态 2（滑块拖拽至 100%，反应完成）：
- 左侧烧杯离子全部消失
- 烧杯3 中显示：Cu²⁺与 OH⁻结合形成红色 Cu(OH)₂沉淀颗粒簇（底部），Na⁺和 SO₄²⁻游离在溶液中
- 沉淀标签"Cu(OH)₂↓" 高亮显示
- 方程式框 opacity=1.0，完全显示
- 反应类型标签"复分解反应" 加粗高亮

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：
  - 拖拽滑块轨道：位于 SVG 底部 y=460~485，x=200~600，长度 400px
  - 滑块手柄：圆形 r=15，可左右拖拽，范围 0%~100%
  - 滑块位置映射：0%=初始分离状态，50%=混合中，100%=反应完成
- 教师操作流程：
  1. 初始状态展示两种溶液分离时的离子组成
  2. 拖动滑块向右，演示溶液混合过程，离子开始移动
  3. 滑块拖至最右端，展示 Cu²⁺与 OH⁻结合形成沉淀，Na⁺与 SO₄²⁻留在溶液中
  4. 配合讲解复分解反应的离子交换本质：Cu²⁺ + 2OH⁻ → Cu(OH)₂↓

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无需额外库，简单几何图形和动画足够）
- 画布尺寸：800×500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  [CuSO₄]    [NaOH]          [混合后溶液]         |
  |   +---+      +---+      +-------+                |
  |   |Cu²⁺|     |Na⁺ |      |       |               |
  |   |SO₄²⁻|    |OH⁻ |  →  |沉淀↓  |               |
  |   +---+      +---+      |Na⁺SO₄²⁻|              |
  |                    →    +-------+                |
  |              复分解反应                          |
  |                                                  |
  |  [方程式框：CuSO₄ + 2NaOH → Cu(OH)₂↓ + Na₂SO₄]  |
  |                                                  |
  |  [====拖拽滑块====]                              |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 sliderPosition (0-100) 作为唯一状态变量，根据位置计算离子位置和透明度
  2. 坐标计算：离子从初始烧杯位置线性插值到目标位置（烧杯3 内）
  3. 动画曲线：使用 requestAnimationFrame 实现平滑过渡，离子移动使用 ease-out 曲线
  4. 事件绑定：滑块使用 mousedown/mousemove/mouseup 实现拖拽，touch 事件支持移动端
  5. 沉淀生成：当 sliderPosition > 70 时，Cu²⁺和 OH⁻离子逐渐消失，沉淀颗粒逐渐出现（opacity 过渡）
- ID 命名规范：所有元素 ID 以 scene3- 为前缀
  - scene3-beaker-1, scene3-beaker-2, scene3-beaker-3
  - scene3-ion-cu2-1, scene3-ion-so4-1, scene3-ion-na-1, scene3-ion-oh-1
  - scene3-precipitate, scene3-equation-box, scene3-slider-track, scene3-slider-handle
  - scene3-label-cuso4, scene3-label-naoh, scene3-label-precipitate
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
