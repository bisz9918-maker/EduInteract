[图示主题与整合说明]
- 本图示主题：可逆反应的温度依赖性与平衡移动——Co 与 HCl 反应提纯工艺
- 整合内容：反应方程式 Co(s)+2HCl(g)⇌CoCl₂(g)+H₂(g)、900℃/600℃温度条件对比、正逆向反应方向、物质状态标注、四个选项的判断依据

[交互方案]
- 交互类型：多状态切换（3 个按钮）
- 控件说明：
  - 按钮 1"900℃正向"：位于(200,485)，点击切换到状态 0，展示 900℃下正向反应
  - 按钮 2"600℃逆向"：位于(360,485)，点击切换到状态 1，展示 600℃下逆向反应
  - 按钮 3"选项分析"：位于(520,485)，点击切换到状态 2，展示四个选项判断
- 教师操作流程：
  1. 初始加载默认状态 0，教师讲解 900℃时 Co 与 HCl 反应生成 CoCl₂和 H₂
  2. 点击"600℃逆向"，展示温度降低时反应逆向进行，CoCl₂分解重新生成 Co
  3. 点击"选项分析"，逐一讲解四个选项，D 选项高亮显示为正确答案
  4. 可随时切换回状态 0/1 复习反应原理

[技术实现]
- JS 库选择：原生 SVG（几何形状简单，无需复杂库）+ 原生 JS 状态管理
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌────────────────────────────────────────────────────────────┐
  │              可逆反应的温度依赖性 (y=35)                    │
  │                                                            │
  │                    900℃ (y=85)                             │
  │         Co(s) + 2HCl(g) ⇌ CoCl₂(g) + H₂(g) (y=110)        │
  │                    600℃ (y=140)                            │
  │                                                            │
  │   HCl→[容器 1 900℃]====[容器 2 600℃]→产物 (y=240-290)      │
  │                                                            │
  │  ┌───────────┐  ┌───────────┐                              │
  │  │ 选项 A ✗  │  │ 选项 B ✗  │  (y=350-425)                 │
  │  └───────────┘  └───────────┘                              │
  │  ┌───────────┐  ┌───────────┐                              │
  │  │ 选项 C ✗  │  │ 选项 D ✓  │  (y=440-515)                 │
  │  └───────────┘  └───────────┘                              │
  │  [900℃正向]  [600℃逆向]  [选项分析]   (y=485 控件栏)        │
  └────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0/1/2），switch 语句控制各状态显示
  2. 坐标计算：所有元素使用绝对坐标，避免相对定位导致偏移
  3. 动画曲线：箭头流动使用 CSS transition，duration 800ms，ease-in-out
  4. 事件绑定：三个按钮分别绑定 click 事件，调用 updateState(newState)
  5. 元素显隐：使用 display:none / display:block 或 opacity:0 / opacity:1 控制
  6. 高亮实现：通过添加/移除 CSS class（.highlight-forward / .highlight-reverse / .highlight-option）
- ID 命名规范：所有元素 ID 以 scene2- 为前缀
  - scene2-title, scene2-equation, scene2-temp-900, scene2-temp-600
  - scene2-arrow-forward, scene2-arrow-reverse
  - scene2-container1, scene2-container2, scene2-pipe-connect
  - scene2-label-container1, scene2-label-container2
  - scene2-label-solid1, scene2-label-solid2
  - scene2-option-a, scene2-option-b, scene2-option-c, scene2-option-d
  - scene2-mark-a, scene2-mark-b, scene2-mark-c, scene2-mark-d
  - scene2-btn-state0, scene2-btn-state1, scene2-btn-state2
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
- 状态切换函数伪代码：
  ```javascript
  (function() {
    let currentState = 0;
    function updateState(state) {
      currentState = state;
      // 隐藏所有状态相关元素
      // 根据 state 显示对应元素
      // 更新按钮高亮状态
    }
    // 绑定按钮事件
    document.getElementById('scene2-btn-state0').onclick = () => updateState(0);
    document.getElementById('scene2-btn-state1').onclick = () => updateState(1);
    document.getElementById('scene2-btn-state2').onclick = () => updateState(2);
    // 初始化
    updateState(0);
  })();
  ```
