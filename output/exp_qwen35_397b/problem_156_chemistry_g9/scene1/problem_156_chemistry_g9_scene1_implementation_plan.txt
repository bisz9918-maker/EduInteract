[图示主题与整合说明]
- 本图示主题：化学反应微观示意图——反应前后分子种类与数量对比
- 整合内容：反应前分子分布、参与反应的分子高亮、反应后分子分布、剩余分子标识

[分步序列]
- 初始状态（步骤0）：显示反应前区域全部5个分子（4个白色双原子分子+1个黑色双原子分子），反应后区域显示2个化合物分子+2个白色双原子分子，反应箭头，"反应前""反应后"标签
- 步骤1：点击「下一步」→ 显示蓝色高亮框框选参与反应的3个分子（2个白色双原子分子+1个黑色双原子分子），步骤标签区显示"参与反应的分子：2个○○ + 1个●●"
- 步骤2：点击「下一步」→ 高亮框保持，反应后区域的2个化合物分子高亮显示（描边加粗或轻微放大），步骤标签区显示"生成物：2个○○●"
- 步骤3：点击「下一步」→ 显示灰色虚线框框选反应前剩余的2个白色双原子分子，同时反应后区域对应的2个剩余分子也显示灰色虚线框，步骤标签区显示"剩余分子：2个○○ 未参与反应"
- 最终步骤（步骤4）：点击「下一步」→ 所有高亮和框选保持，步骤标签区显示"结论：实际反应比例 2:1，属于化合反应"，化合物分子用#1565c0蓝色描边强调

[标签冲突检查]
- 标签"反应前"：坐标(200,300)
- 标签"反应后"：坐标(600,300)
- 标签"参与反应的分子"：坐标(200,340)
- 标签"生成物"：坐标(200,340)（步骤2替换）
- 标签"剩余分子"：坐标(200,340)（步骤3替换）
- 标签"结论"：坐标(200,340)（步骤4替换）
- 所有标签间距检查：
  - "反应前"与"反应后"：水平距离400px → 无冲突
  - "反应前"与步骤标签区：垂直距离40px → 无冲突
  - 步骤标签区内部：同一位置动态替换 → 无冲突
- 分子标签：本场景不直接在分子旁标注文字，避免拥挤，通过高亮框和步骤说明区分

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于(280,450)，80×30px，灰色背景，点击返回上一状态
  - 「下一步」按钮：位于(440,450)，80×30px，蓝色背景#1565c0，点击进入下一状态
  - 步骤指示器：位于两按钮之间(380,455)，显示"步骤 X/4"
- 教师操作流程：
  1. 初始状态展示完整反应前后对比，让学生观察差异
  2. 点击「下一步」高亮参与反应的分子，提问"哪些分子参与了反应？"
  3. 点击「下一步」高亮生成物，提问"生成了什么新分子？"
  4. 点击「下一步」标注剩余分子，强调"并非所有反应物都消耗完"
  5. 点击「下一步」展示结论，总结化合反应特征和反应比例

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  [反应前方框]     →箭头→    [反应后方框]         |
  |   80,80-320,280              480,80-720,280      |
  |                                                  |
  |     反应前                    反应后             |
  |        (200,300)              (600,300)          |
  |                                                  |
  |           步骤标签区 (200,340)                   |
  |                                                  |
  |        [◀上一步] 步骤X/4 [下一步▶]               |
  |         (280,450)          (440,450)             |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量(0-4)，数组存储每步的可见元素ID列表
  2. 分子绘制：每个分子用<group>包裹多个<circle>，白色分子2个空心圆，黑色分子2个实心圆，化合物分子3个圆(2白1黑呈V型)
  3. 高亮框：使用<rect>元素，通过display属性控制显示/隐藏
  4. 按钮事件：绑定click事件，更新currentState，调用renderState()函数刷新可见性
  5. 按钮禁用：步骤0时禁用"上一步"，步骤4时禁用"下一步"（opacity置0.5，pointer-events:none）
- ID 命名规范：所有元素ID以 scene1- 为前缀
  - scene1-box-before, scene1-box-after
  - scene1-arrow
  - scene1-mol-w1-before, scene1-mol-w2-before, scene1-mol-w3-before, scene1-mol-w4-before
  - scene1-mol-b1-before
  - scene1-mol-c1-after, scene1-mol-c2-after
  - scene1-mol-w1-after, scene1-mol-w2-after
  - scene1-highlight-react, scene1-highlight-remain-before, scene1-highlight-remain-after
  - scene1-label-before, scene1-label-after, scene1-label-step
  - scene1-btn-prev, scene1-btn-next, scene1-label-step-indicator
- IIFE 隔离：所有JS代码包裹在 (function() { ... })() 中，避免全局变量污染
