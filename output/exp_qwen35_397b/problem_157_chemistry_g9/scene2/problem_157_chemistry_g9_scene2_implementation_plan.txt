[图示主题与整合说明]
- 本图示主题：温度变化对A点饱和溶液的影响——降温过程中溶质析出
- 整合的步骤/概念：
  1. A点初始状态（t₂℃时的饱和溶液，溶解度S₂）
  2. 降温轨迹（沿溶解度曲线向左下方移动）
  3. 溶解度随温度降低而减小
  4. 溶质析出过程（温度低于t₂时晶体开始析出）
  5. 溶质质量分数随温度变化的关系
- 教学价值：教师可通过拖动滑块直观展示降温过程中溶液状态的连续变化，帮助学生理解：
  - 饱和溶液降温时溶解度减小
  - 多余溶质以晶体形式析出
  - 溶质质量分数随温度降低而减小
  - 建立温度-溶解度-质量分数的因果关系

[分步序列]
本场景采用连续拖拽滑块交互，无固定步骤，但定义以下关键状态供参考：

- 初始状态（滑块在t₂位置）：
  - 动点P位于A点(400,200)，对应温度t₂、溶解度S₂
  - 显示A点的投影虚线到坐标轴
  - 数值显示：温度=t₂，溶解度=S₂，质量分数=S₂/(100+S₂)×100%
  - 无晶体析出
  - 轨迹线为空

- 状态1（滑块拖至t₁和t₂之间，如t=1.5t₁）：
  - 动点P沿曲线移动到新位置
  - 显示新的投影虚线
  - 数值实时更新
  - 开始显示少量晶体（灰色小三角形堆积）
  - 轨迹线显示从A点到当前位置的蓝色虚线路径

- 状态2（滑块拖至t₁位置）：
  - 动点P位于(200,320)，对应温度t₁、溶解度S₁
  - 晶体堆积高度增加
  - 显示"晶体析出"标注
  - 数值：温度=t₁，溶解度=S₁，质量分数=S₁/(100+S₁)×100%
  - 轨迹线完整显示从A到当前位置的路径

- 状态3（滑块拖至t₁左侧，如t=0.5t₁）：
  - 动点P继续左移，溶解度进一步减小
  - 晶体堆积高度达到最大
  - 质量分数继续减小
  - 轨迹线延伸至最左端

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：
  1. 温度滑块：水平滑块，范围0~t₃（对应x坐标100~600），手柄可左右拖拽
  2. 温度显示：滑块右侧实时显示当前温度值
  3. 溶解度显示：右上角显示当前溶解度
  4. 质量分数显示：右上角显示当前溶质质量分数百分比
- 教师操作流程：
  1. 初始状态展示A点（t₂℃饱和溶液）
  2. 拖动滑块向左，观察动点P沿曲线移动
  3. 当温度低于t₂时，晶体开始析出，晶体堆积高度随温度降低而增加
  4. 引导学生观察数值变化：温度↓→溶解度↓→质量分数↓
  5. 可来回拖动滑块，对比不同温度下的溶液状态

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单，无需复杂库；原生SVG便于精确控制坐标和动画
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  Y轴标题              [温度显示]  t=xx℃          |
  |  溶                    [溶解度]   S=xx g         |
  |  解                    [质量分数] w=xx%          |
  |  度  |                                          |
  |      |         曲线      A/P●                    |
  |      |              /                            |
  |      |            /                              |
  |      |          /                                |
  |      |        /                                  |
  |      |      /                                    |
  |      |____/______________________________________|
  |      t₁   t₂   t₃                    温度(℃)      |
  |                                                   |
  |              [晶体析出]                           |
  |              ▄▄▄▄▄▄▄                              |
  |                                                   |
  |         温度滑块：[====●====]  t=xx℃              |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：单状态连续变量（温度值），无需离散状态
  2. 坐标计算：建立温度t到x坐标的映射函数 x = mapTtoX(t)，溶解度S到y坐标的映射 y = mapStoY(S)
  3. 溶解度曲线函数：使用三次样条或贝塞尔曲线拟合，支持根据温度查询溶解度
  4. 晶体高度计算：crystalHeight = k × (S_initial - S_current)，k为比例系数
  5. 质量分数计算：w = S/(100+S) × 100%，实时更新
  6. 事件绑定：slider.addEventListener('input', updateScene)
  7. 拖拽实现：mousedown/mousemove/mouseup 或 touch 事件处理

- ID 命名规范：
  - 所有交互元素ID必须以 scene2- 为前缀
  - 示例：scene2-curve（溶解度曲线）、scene2-point-p（动点P）、scene2-slider（温度滑块）、scene2-crystal（晶体）、scene2-temp-display（温度显示）等

- IIFE 隔离：
  ```javascript
  (function() {
    // 所有场景2的JS代码包在此IIFE中
    // 避免与场景1或其他场景变量冲突
  })();
  ```

- 颜色规范（沿用场景大纲）：
  - 背景：#ffffff
  - 坐标轴及曲线：#000000
  - 动点及轨迹：#1565c0（蓝色）
  - 晶体：#888888（灰色）
  - 滑块轨道：#000000
  - 滑块手柄：#1565c0
