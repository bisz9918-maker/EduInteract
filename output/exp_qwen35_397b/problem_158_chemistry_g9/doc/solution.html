problem_158_chemistry_g9

场景导航：Scene 1 | Scene 2

题目原文：

下列各组变化中，每一步转化在一定条件下均能一步实现的是

$\begin{description}
\item A．①②\item B．①③\item C．②③\item D．①②③
\end{description}$

题目分析：

本题考察常见物质的化学转化关系，要求判断三个三角转化图中，哪些组的每一步转化都能通过一个化学反应直接实现。

整体讲解思路：

  1. 首先展示三个转化图的整体结构，让学生观察物质间的转化关系
  2. 逐一分析每个转化图中的三步反应，写出反应方程式
  3. 判断每步反应是否能"一步实现"（即是否只需一个化学反应）
  4. 综合判断哪个选项正确

图示规划说明：

  • SCENE_1：主图示，展示三个转化循环图，用颜色编码标注每步转化的可行性
  • 采用分步按钮导航，逐步揭示每个转化的反应方程式和判断结果

图①（钙化合物转化）分析：

  1. CaCO₃ → CaO：高温分解反应

$$CaCO_3 \xrightarrow{高温} CaO + CO_2↑$$
可一步实现 ✓

  1. CaO → Ca(OH)₂：化合反应

$$CaO + H_2O \rightarrow Ca(OH)_2$$
可一步实现 ✓

  1. Ca(OH)₂ → CaCO₃：与二氧化碳反应

$$Ca(OH)_2 + CO_2 \rightarrow CaCO_3↓ + H_2O$$
可一步实现 ✓

结论：图①全部转化均可一步实现

图②（铁化合物转化）分析：

  1. Fe → Fe₂O₃：铁缓慢氧化（生锈）

$$4Fe + 3O_2 \rightarrow 2Fe_2O_3$$
可一步实现 ✓

  1. Fe₂O₃ → FeSO₄：氧化铁与硫酸反应

$$Fe_2O_3 + 3H_2SO_4 \rightarrow Fe_2(SO_4)_3 + 3H_2O$$
生成的是硫酸铁 Fe₂(SO₄)₃，不是硫酸亚铁 FeSO₄
不能一步实现 ✗

  1. FeSO₄ → Fe：置换反应

$$Zn + FeSO_4 \rightarrow ZnSO_4 + Fe$$
可一步实现 ✓

结论：图②中 Fe₂O₃ → FeSO₄ 不能一步实现

图③（水/氧/氧化镁转化）分析：

  1. H₂O → O₂：电解水

$$2H_2O \xrightarrow{通电} 2H_2↑ + O_2↑$$
可一步实现 ✓

  1. O₂ → MgO：镁燃烧

$$2Mg + O_2 \xrightarrow{点燃} 2MgO$$
可一步实现 ✓

  1. MgO → H₂O：氧化镁与酸反应

$$MgO + H_2SO_4 \rightarrow MgSO_4 + H_2O$$
可一步实现 ✓

结论：图③全部转化均可一步实现

教学要点总结：

  1. 审题关键："每一步转化"和"一步实现"是核心要求，必须检查三角图中的所有三条边
  1. 常见陷阱：
  • Fe₂O₃（+3 价铁）与酸反应生成 Fe³⁺盐，不是 Fe²⁺盐
  • 要生成 FeSO₄（+2 价），需要用 Fe 单质与酸反应，或用还原剂还原 Fe³⁺
  1. 知识网络：
  • 钙的化合物转化是经典的可逆循环
  • 铁的转化涉及变价问题，需特别注意
  • 水的电解和金属氧化是基础反应

完整解答：

  • 图①：3 步均可一步实现 ✓
  • 图②：Fe₂O₃ → FeSO₄ 不能一步实现 ✗
  • 图③：3 步均可一步实现 ✓

正确答案：B．①③

课堂讲解建议：

  1. 先让学生独立判断，暴露常见错误（如忽略 Fe 的价态）
  2. 使用 SCENE_1 分步展示，让学生跟随分析每个转化
  3. 使用 SCENE_2 重点突破 Fe₂O₃→FeSO₄ 的难点
  4. 引导学生总结：判断"一步实现"时，要写出具体反应方程式验证
