problem_159_chemistry_g9

场景导航：Scene 1 | Scene 2

题目原文：

下列图像能正确反映对应的实验操作的是

A．向一定量的饱和石灰水中加入氧化钙
B．加热一定量高锰酸钾固体产生氧气
C．高温煅烧 CaCO₃
D．O₂在水中的溶解性

题目分析：

本题为化学图像分析选择题，考查学生对四个不同化学实验过程中物理量变化规律的理解。需要判断每个选项对应的图像是否正确反映了实验过程中相关量的变化趋势。

整体讲解思路：

  1. 首先展示原题四个图像，让学生观察每个图像的横纵坐标含义及曲线趋势
  2. 逐一分析每个选项对应的化学反应过程
  3. 对比题目图像与正确图像，指出错误所在
  4. 得出正确答案

图示规划说明：

设计一个综合图示场景，用分步按钮导航逐一分析四个选项。每个步骤高亮对应图像，叠加显示该实验过程的正确变化曲线（用不同颜色区分），帮助学生直观对比题目图像与正确图像的差异。

本图示教学说明：

教师应引导学生按以下步骤观察和分析：

步骤 1：分析选项 A

向饱和石灰水中加入氧化钙：

  • 氧化钙与水反应：CaO + H₂O → Ca(OH)₂
  • 反应消耗溶剂水，溶质会析出
  • 反应放热，氢氧化钙溶解度随温度升高而降低
  • 因此溶质质量应减少，而非保持不变
  • 题目图像错误

步骤 2：分析选项 B

加热高锰酸钾固体：

  • 反应方程式：2KMnO₄ → K₂MnO₄ + MnO₂ + O₂↑
  • 氧气逸出，固体总质量减少
  • 但剩余固体 K₂MnO₄ 和 MnO₂ 仍有质量
  • 固体质量应降至非零值，而非 0
  • 题目图像错误

步骤 3：分析选项 C

高温煅烧碳酸钙：

  • 反应方程式：CaCO₃ → CaO + CO₂↑
  • 反应需要达到一定温度才开始，初期固体质量不变
  • 分解过程中 CO₂ 逸出，固体质量减少
  • 完全分解后剩余 CaO，质量保持非零常数
  • 图像趋势：先平→下降→再平（非零）
  • 题目图像正确

步骤 4：分析选项 D

氧气在水中的溶解度：

  • 气体溶解度随温度升高而降低
  • 题目图像显示溶解度随温度升高而增加
  • 题目图像错误

关键公式：

  • CaO + H₂O → Ca(OH)₂（放热反应）
  • 2KMnO₄ → K₂MnO₄ + MnO₂ + O₂↑
  • CaCO₃ → CaO + CO₂↑

本图示教学说明：

此图示用于深入讲解正确答案选项 C 的反应过程，帮助学生建立"宏观图像—微观反应—化学方程式"之间的联系。

讲解要点：

  1. 阶段一（加热初期）：
  • 酒精灯加热，但温度尚未达到碳酸钙分解温度（约 825°C）
  • 固体仍为 CaCO₃，质量保持不变
  • 对应图像中的水平线段
  1. 阶段二（分解过程）：
  • 达到分解温度，CaCO₃ 开始分解
  • CO₂ 气体不断逸出，固体质量持续减少
  • 对应图像中的下降线段
  • 反应方程式：CaCO₃ → CaO + CO₂↑
  1. 阶段三（完全分解）：
  • CaCO₃ 完全分解为 CaO
  • 剩余固体为 CaO，质量不再变化
  • 对应图像中的水平线段（非零）
  • 质量关系：100g CaCO₃ → 56g CaO + 44g CO₂↑

引导学生思考：

  • 为什么图像开始有一段水平线？（需要达到分解温度）
  • 为什么最后不是降到 0？（有固体产物 CaO 剩余）
  • 如果继续加热，质量会变化吗？（不会，已完全分解）

总结：完整解答与课堂讲解建议

正确答案：C

各选项判断依据：

| 选项 | 实验操作 | 题目图像 | 正确图像 | 判断 |
|------|----------|----------|----------|------|
| A | 饱和石灰水加 CaO | 水平直线 | 下降曲线 | ✗ 错误 |
| B | 加热 KMnO₄ | 降至 0 | 降至非零值 | ✗ 错误 |
| C | 高温煅烧 CaCO₃ | 先平后降再平 | 先平后降再平 | ✓ 正确 |
| D | O₂ 溶解度 | 上升 | 下降 | ✗ 错误 |

课堂讲解建议：

  1. 先让学生独立观察四个图像，猜测哪个正确
  2. 使用 Scene 1 逐一分析每个选项，让学生说出判断理由
  3. 对正确答案 C，使用 Scene 2 深入讲解反应过程
  4. 引导学生总结图像分析题的解题方法：
  • 明确横纵坐标含义
  • 分析化学反应过程
  • 判断物理量变化趋势
  • 注意起点、终点、转折点的意义

易错点提醒：

  • 选项 A：忽略 CaO 与水反应消耗溶剂，且放热影响溶解度
  • 选项 B：忽略反应后有固体剩余
  • 选项 D：混淆气体与固体溶解度随温度变化的规律（气体溶解度随温度升高而降低）
