[图示主题与整合说明]
- 本图示主题：图甲（叠放）整体受力分析
- 整合内容：叠放状态展示、整体受力分析、摩擦力与推力平衡关系
- 教学价值：教师可逐步展示叠放木块的整体受力情况，帮助学生理解匀速直线运动时推力与摩擦力的平衡关系，以及正压力与重力的关系。通过分步动画，学生能清晰看到每个力的作用位置和方向。

[分步序列]
- 初始状态（步骤0）：显示桌面、木块A、木块B、标签"A"、"B"、"图甲"、速度箭头v₁及标签"v₁=1m/s"
- 步骤1：点击「下一步」→ 显示重力G箭头（虚线灰色）及标签"G=2mg"，显示支持力N箭头（虚线灰色）及标签"N=2mg"
- 步骤2：点击「下一步」→ 显示摩擦力f₁箭头（红色）及标签"f₁"，箭头从A底部向左
- 步骤3：点击「下一步」→ 显示推力F₁箭头（蓝色）及标签"F₁=100N"，箭头从左侧指向A；同时高亮F₁和f₁，显示平衡关系提示"F₁=f₁"（小字，灰色，位于两箭头之间下方）
（教师可随时点击「上一步」回退复习）

冲突检查：
- "A"与"B"：垂直距离80px → 无冲突
- "A"与"N=2mg"：水平距离60px，垂直距离5px → 需调整，将"N=2mg"移至(300,390)
- "B"与"v₁=1m/s"：垂直距离100px → 无冲突
- "F₁=100N"与"f₁"：垂直距离80px → 无冲突
- "N=2mg"与"G=2mg"：垂直距离75px → 无冲突
- "G=2mg"与"图甲"：垂直距离10px → 需调整，将"图甲"移至(280,485)
- 所有标签与图形元素：均保持≥15px间距 → 无冲突

解决方案：
- "N=2mg"调整至(300,390)
- "图甲"调整至(280,485)

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于SVG内左下角(60,455)，灰色背景，点击回退到前一状态
  - 「下一步」按钮：位于SVG内右下角(150,455)，蓝色背景，点击进入下一状态
  - 步骤指示器：位于两按钮之间，显示"步骤X/4"
- 教师操作流程：
  1. 初始状态展示叠放木块和运动方向
  2. 点击「下一步」展示竖直方向受力（重力和支持力）
  3. 点击「下一步」展示摩擦力方向
  4. 点击「下一步」展示推力并强调平衡关系
  5. 可随时点击「上一步」回顾之前的受力分析

[技术实现]
- JS库选择：原生SVG（简单几何图形，无需额外库）
- 画布尺寸：800×500px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |                    v₁=1m/s                       |
  |                      →                           |
  |                    ┌─────┐ B                     |
  |                    │  B  │                        |
  |              F₁→   ┌─────┐                        |
  |                    │  A  │ A                      |
  |                    └─────┘                        |
  |  ═══════════════════════════════════ 桌面         |
  |                      ↓ N=2mg                     |
  |                      ↑ G=2mg                     |
  |                                                  |
  |  [◀上一步]  步骤X/4  [下一步▶]                   |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用currentState变量(0-3)跟踪当前步骤
  2. 元素分组：将每步新增元素放入独立<g>组，通过display控制显示/隐藏
  3. 箭头绘制：使用SVG marker定义箭头头部，统一样式
  4. 事件绑定：按钮点击事件绑定到stepForward/stepBack函数
  5. 动画效果：新增元素使用fade-in动画（opacity 0→1，300ms）
- ID命名规范：所有元素ID以scene1-为前缀
  - scene1-desktop, scene1-block-a, scene1-block-b
  - scene1-arrow-f1, scene1-arrow-f1-label
  - scene1-arrow-friction, scene1-arrow-friction-label
  - scene1-arrow-gravity, scene1-arrow-gravity-label
  - scene1-arrow-normal, scene1-arrow-normal-label
  - scene1-arrow-velocity, scene1-arrow-velocity-label
  - scene1-btn-prev, scene1-btn-next, scene1-step-indicator
- IIFE隔离：所有JS代码包在(function() { ... })()中，避免全局污染
