[图示主题与整合说明]
- 本图示主题：两种情况对比——摩擦力与接触面积、速度无关
- 整合的内容：图甲图乙并列对比、关键物理量对比表、结论展示
- 教学价值：教师可通过切换按钮逐一高亮对比接触面积、速度、正压力和摩擦力，帮助学生理解滑动摩擦力只与正压力和接触面粗糙程度有关，与接触面积和运动速度无关。通过视觉对比强化"控制变量法"的物理思想。

[交互方案]
- 交互类型：多状态切换（3 个按钮）
- 控件说明：
  - 按钮 1「对比接触面积」：位于 (100,480)，点击后高亮两图中木块接触区域，表格第 1 行高亮
  - 按钮 2「对比速度」：位于 (220,480)，点击后高亮两图中速度箭头，表格第 2 行高亮
  - 按钮 3「对比正压力和摩擦力」：位于 (340,480)，点击后高亮地面接触面，表格第 3、4 行高亮，结论框突出显示
- 教师操作流程：
  1. 初始状态展示两图对比，让学生观察差异
  2. 点击按钮 1，引导学生注意接触面积不同（叠放 vs 并排）
  3. 点击按钮 2，引导学生注意速度不同（1m/s vs 2m/s）
  4. 点击按钮 3，强调正压力和摩擦力相同，得出 F₂=F₁=100N 结论
  5. 可反复切换按钮，强化"摩擦力与接触面积、速度无关"的核心概念

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（矩形、线段、箭头），无需复杂库；原生实现轻量、加载快
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```

  │   └───┘                                                     │
  │   ─────────                                                  │
  ```

- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-3），每个按钮点击时更新状态并调用 renderState() 函数
  2. 坐标计算：所有元素使用绝对坐标（SVG 坐标系），确保布局精确
  3. 动画曲线：状态切换使用 CSS transition（0.3s ease-out），高亮效果使用 opacity 和 stroke-width 变化
  4. 事件绑定：3 个按钮分别绑定 onclick 事件，调用 setState(1/2/3)
  5. 高亮逻辑：每个状态对应一组元素的 class 切换（如 .highlight-contact、.highlight-velocity、.highlight-force）
- ID 命名规范：
  - 所有元素 ID 以 scene3- 为前缀
  - 示例：scene3-figureA、scene3-figureB、scene3-table-row1、scene3-btn1、scene3-conclusion
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
- CSS 类定义：
  - .highlight-contact：红色边框 #c62828，线宽 4px
  - .highlight-velocity：红色箭头 #c62828，线宽 5px
  - .highlight-force：绿色地面 #2e7d32，线宽 5px
  - .row-highlight-1/2/3：对应表格行背景色
  - .btn-active：蓝色背景 #1565c0，白色文字
  - .conclusion-active：蓝色边框 #1565c0，背景#e3f2fd
