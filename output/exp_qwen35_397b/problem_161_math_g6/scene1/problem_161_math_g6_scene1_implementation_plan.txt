[图示主题与整合说明]
- 本图示主题：长方形分类计数演示
- 整合的内容：原图结构展示 + 单个长方形计数 + 组合长方形计数 + 总数统计
- 教学价值：教师可使用此图示按类别逐步展示不同大小的长方形，从单个基本单元到多个组合，帮助学生理解系统计数方法（分类枚举法），避免重复或遗漏。分步导航让教师可控制节奏，引导学生观察规律（4+3+2+1=10）。

[分步序列]
- 初始状态（步骤0）：显示原图基础结构（大长方形外框+3条竖直线，黑色边框），无高亮，计数标签显示"请点击下一步开始"
- 步骤1：点击「下一步」→ 依次高亮显示4个单个小长方形（蓝色填充#1565c0，透明度20%），计数标签显示"单个：4个"
- 步骤2：点击「下一步」→ 清除步骤1高亮，高亮显示3个由2个相邻小长方形组成的长方形（绿色填充#2e7d32，透明度20%），计数标签显示"两个组合：3个"
- 步骤3：点击「下一步」→ 清除步骤2高亮，高亮显示2个由3个相邻小长方形组成的长方形（橙色填充#f57c00，透明度20%），计数标签显示"三个组合：2个"
- 步骤4：点击「下一步」→ 清除步骤3高亮，高亮显示1个由4个小长方形组成的大长方形（红色填充#c62828，透明度20%），计数标签显示"四个组合：1个"
- 步骤5：点击「下一步」→ 清除步骤4高亮，显示所有长方形轮廓（可选虚线辅助），计数标签显示"总数：4+3+2+1=10个"

- 上一步按钮文字：坐标(330,468) 居中
- 下一步按钮文字：坐标(470,468) 居中

冲突检查：
- 计数标签(400,380) 与 步骤指示器(400,420)：垂直间距40px → 无冲突（≥20px要求）
- 步骤指示器(400,420) 与 按钮区(450)：垂直间距30px → 无冲突
- 所有标签均位于主图区(y=150-350)下方，与图形元素无重叠 → 无冲突

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于(280,450)，点击后退到前一状态，步骤0时禁用
  - 「下一步 ▶」按钮：位于(420,450)，点击前进到下一状态，步骤5时禁用
  - 步骤指示器：位于(400,420)，显示当前步骤"步骤X/5"
  - 计数标签：位于(400,380)，显示当前类别的计数信息
- 教师操作流程：
  1. 初始状态展示原图，让学生观察图形结构
  2. 点击「下一步」展示4个单个长方形，提问"有多少个基本小长方形？"
  3. 点击「下一步」展示3个两两组合的长方形，引导学生发现相邻组合规律
  4. 点击「下一步」展示2个三个组合的长方形
  5. 点击「下一步」展示1个整体大长方形
  6. 点击「下一步」显示总计公式，总结分类计数方法

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript
  - 原因：本图为简单几何图形（矩形和线段），无需复杂库；SVG 便于精确控制坐标和样式；原生 JS 足够实现分步状态切换
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |              [大长方形 600×200]                  |
  |         +---+---+-----------+---+                |
  |         | 1 | 2 |     3     | 4 |  y=150-350    |
  |         +---+---+-----------+---+                |
  |                                                  |
  |              计数标签 (400,380)                  |
  |              步骤指示 (400,420)                  |
  |         [◀上一步]      [下一步▶]                 |
  |          (280,450)      (420,450)                |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量(0-5)跟踪当前步骤，steps 数组存储每步的配置（高亮区域数组、颜色、标签文本）
  2. 坐标计算：4个小长方形宽度分别为75/75/300/150，基于左边界x=100计算各分割线位置
  3. 高亮区域渲染：每步清除上一高亮，根据当前步骤配置创建新的 rect 元素，设置 fill 和 fill-opacity
  4. 事件绑定：按钮点击事件切换 currentStep，调用 renderStep() 更新视图，更新按钮禁用状态
  5. 边界处理：步骤0时禁用「上一步」，步骤5时禁用「下一步」
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀
  - scene1-main-rect（大长方形外框）
  - scene1-line-1/2/3（三条竖直线）
  - scene1-highlight-group（高亮区域组）
  - scene1-count-label（计数标签）
  - scene1-step-indicator（步骤指示器）
  - scene1-btn-prev（上一步按钮）
  - scene1-btn-next（下一步按钮）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
