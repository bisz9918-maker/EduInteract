    <TEXT_1>
    **题目原文：**

    下面图形中，周长最长的是（）

    图形 A：长方形，长 10，宽 6

    图形 B：阶梯状图形，底边 10，左边 6，右上角呈阶梯状

    图形 C：长方形顶部中间有凹槽，底边 10，右边 6

    **题目分析：**

    本题考察周长的概念及"平移法"求不规则图形周长的技巧。三个图形的外轮廓尺寸相同（均为 10×6 的矩形范围），但内部线条不同。

    **整体讲解思路：**

    1. 首先明确周长的定义：封闭图形一周的长度
    2. 分别计算三个图形的周长
    3. 图形 A 是标准长方形，直接套用公式
    4. 图形 B 用平移法，将阶梯的水平线段向上平移、竖直线段向右平移，可拼成完整长方形
    5. 图形 C 的凹槽两条竖边无法通过平移消除，是额外增加的长度
    6. 比较得出结论

    **图示规划说明：**

    - SCENE_1：展示三个图形的原始状态，建立直观印象
    - SCENE_2：用平移法演示图形 B 的周长计算（核心难点）
    - SCENE_3：用平移法演示图形 C 的周长计算，突出凹槽的额外边长

    </TEXT_1>

    1. 先将滑块置于 0%，让学生观察图形 B 的阶梯状边界

    4. 滑块到 100% 时，强调：图形 B 的周长 = 长方形周长 = (10+6)×2 = 32
    5. 总结平移法的核心：**线段平移不改变长度**

    关键公式：

    图形 B 周长 = (10 + 6) × 2 = 32

    **教学说明：**

    本图示展示图形 C 的特殊性。教师讲解要点：

    1. 步骤 1：将凹槽底部的水平线段向上平移，可与顶部两侧线段拼成完整顶边（长度=10）
    2. 步骤 2：**关键观察**——凹槽的两条竖直边无法通过平移消除！
    3. 这两条竖边是"额外"的周长，使图形 C 的周长大于标准长方形
    4. 设凹槽深度为 h，则图形 C 周长 = 32 + 2h

    关键公式：

    图形 C 周长 = (10 + 6) × 2 + 2h = 32 + 2h

    由于 h > 0，所以 图形 C 周长 > 32

    <TEXT_5>
    **总结与完整解答：**

    **三个图形周长对比：**

    | 图形 | 周长计算 | 结果 |
    |------|----------|------|
    | A | (10 + 6) × 2 | 32 |
    | B | (10 + 6) × 2（平移法） | 32 |
    | C | (10 + 6) × 2 + 2h | 32 + 2h > 32 |

    **结论：图形 C 的周长最长**

    **课堂讲解建议：**

    1. 先让学生直观猜想，再验证
    2. 重点讲解平移法的思想：线段平移不改变长度
    3. 强调图形 C 的特殊性：凹槽的竖直边是"额外"的
    4. 可延伸提问：如果图形 C 是向外凸起而非凹陷，周长会如何变化？（答案：同样是 32 + 2h）

    **核心知识点：**

    - 周长的定义：封闭图形一周的长度
    - 平移法：通过平移线段，将不规则图形转化为规则图形计算周长
    - 平移不改变线段长度，但要注意是否有无法平移消除的"额外"线段
