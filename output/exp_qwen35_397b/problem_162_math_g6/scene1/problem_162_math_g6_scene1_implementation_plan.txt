[图示主题与整合说明]
- 本图示主题：三个待比较图形的原始展示——周长比较问题
- 整合内容：图形 A（标准长方形）、图形 B（阶梯状多边形）、图形 C（带凹槽长方形）的原始形态及已知尺寸标注

[分步序列]
分步按钮导航，共 4 个状态（步骤 0-3）：

- 初始状态（步骤 0）：仅显示图形 A
  - 显示：图形 A 轮廓、标签"A."、尺寸"10"、尺寸"6"
  - 隐藏：图形 B、图形 C 及其所有标签
  - 按钮状态："上一步"禁用，"下一步"启用

- 步骤 1：点击「下一步」→ 显示图形 B
  - 显示：图形 A（保持）、图形 B 轮廓、标签"B."、尺寸"10"、尺寸"6"
  - 隐藏：图形 C 及其所有标签
  - 按钮状态："上一步"启用，"下一步"启用

- 步骤 2：点击「下一步」→ 显示图形 C
  - 显示：图形 A、图形 B（保持）、图形 C 轮廓、标签"C."、尺寸"10"、尺寸"6"
  - 隐藏：无
  - 按钮状态："上一步"启用，"下一步"启用

- 步骤 3（最终步骤）：三个图形并列对比
  - 显示：全部三个图形及所有标签
  - 视觉强调：三个图形同时高亮显示（可轻微加粗描边至 3px）
  - 按钮状态："上一步"启用，"下一步"禁用（或循环回到步骤 0）

冲突检查：
- "A."(70,235) 与 "A-10"(200,325)：水平距离 130px，垂直距离 90px → 无冲突
- "A."(70,235) 与 "A-6"(315,235)：水平距离 245px → 无冲突
- "A-6"(315,235) 与 "B."(310,235)：水平距离 5px → **潜在冲突！** 解决方案：将"B."左移至 (295,235)，间距 20px
- "B-6"(325,235) 与 "B."(295,235)：水平距离 30px → 无冲突
- "B-6"(325,235) 与 "A-6"(315,235)：水平距离 10px → **潜在冲突！** 解决方案：将"B-6"左移至 (305,235)，但会与"B."冲突。调整方案：将"B-6"放在图形 B 左侧更远处 (300,235)，"B."放在 (285,235)
- "B."(285,235) 与 "A-6"(315,235)：水平距离 30px → 无冲突
- "C."(550,235) 与 "C-6"(795,235)：水平距离 245px → 无冲突

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - "上一步"按钮：位于 (320,460)，宽 80px，高 30px，点击后切换到前一个步骤
  - "下一步"按钮：位于 (420,460)，宽 80px，高 30px，点击后切换到下一个步骤
- 教师操作流程：
  1. 初始展示图形 A，提问："这个长方形的长和宽分别是多少？周长如何计算？"
  2. 点击「下一步」展示图形 B，提问："这个阶梯图形的周长与长方形 A 相比，是更长、更短还是相等？"
  3. 点击「下一步」展示图形 C，提问："这个带凹槽的图形周长又是多少？"
  4. 三个图形全部展示后，引导学生比较三个图形的周长，得出结论

[技术实现]
- JS 库选择：原生 SVG（简单几何图形首选，无需额外库）
- 画布尺寸：800×500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |   A.  [图形 A]    B.  [图形 B]    C.  [图形 C]   |
  |       10  6           10  6           10  6      |
  |                                                  |
  |                                                  |
  |                                                  |
  |                                                  |
  |                                                  |
  |                                                  |
  |                                                  |
  |              [上一步]  [下一步]                  |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-3) 跟踪当前步骤
  2. 每个图形及其标签分组（<g>元素），通过 display 属性控制显示/隐藏
  3. 按钮点击事件绑定，更新 currentStep 并刷新显示状态
  4. 步骤 0 和步骤 3 时分别禁用"上一步"和"下一步"按钮
  5. 图形 B 阶梯绘制：使用 polyline 或 path，5 级台阶，每级水平 40px，垂直 24px
  6. 图形 C 凹槽绘制：使用 path，从左下角开始顺时针绘制，顶部中间凹陷
- ID 命名规范：所有元素 ID 以 scene1- 为前缀
  - scene1-group-a, scene1-group-b, scene1-group-c（图形分组）
  - scene1-label-a, scene1-label-b, scene1-label-c（选项标识）
  - scene1-dim-a-10, scene1-dim-a-6 等（尺寸标注）
  - scene1-btn-prev, scene1-btn-next（按钮）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
