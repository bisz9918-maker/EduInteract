[图示主题与整合说明]
- 本图示主题：图形 B 的平移法周长计算
- 整合的步骤/概念：图形 B 原始形态、平移动画演示、等效长方形转换

[分步序列]
本场景采用连续拖拽滑块交互，无固定步骤，但定义以下关键状态：

- 状态 0（滑块 0%）：显示原始阶梯图形（黑色实线），无平移效果
  - 显示：底边、左边、8 段水平阶梯、7 段竖直阶梯（均为黑色）
  - 隐藏：等效长方形、平移轨迹
  - 公式区：空白

- 状态 1（滑块 1%~49%）：平移开始，线段开始移动
  - 水平线段：向上平移，透明度渐变至 70%，颜色变为蓝色
  - 竖直线段：向右平移，透明度渐变至 70%，颜色变为蓝色
  - 显示灰色虚线轨迹
  - 公式区：空白

- 状态 2（滑块 50%~99%）：平移进行中，接近完成
  - 水平线段：继续向上平移至目标位置（y=170）
  - 竖直线段：继续向右平移至目标位置（x=700）
  - 等效长方形：逐渐显现（绿色边框透明度从 0% 到 100%）
  - 公式区：空白

- 状态 3（滑块 100%）：平移完成，形成完整长方形
  - 所有阶梯线段已平移至长方形边界
  - 等效长方形：完全显示（绿色 #2e7d32，3px）
  - 公式区：显示 "(10+6)×2 = 32"（绿色）
  - 平移箭头：高亮显示

[交互方案]
- 交互类型：连续拖拽滑块（0%~100%）
- 控件说明：
  - 滑块：位于 SVG 底部 y=450~480 区域，x=200~600，拖动范围 400px
  - 滑块标签："平移进度"，位于滑块左侧
- 教师操作流程：
  1. 初始状态展示原始阶梯图形，提问学生"这个图形的周长如何计算？"
  2. 缓慢拖动滑块，展示水平线段向上平移、竖直线段向右平移的过程
  3. 在滑块 50% 处暂停，引导学生观察平移规律
  4. 拖动至 100%，展示等效长方形，引出周长公式 (10+6)×2 = 32
  5. 可来回拖动滑块，反复演示平移过程

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单，无需复杂库；SVG 便于精确控制线段位置和透明度动画
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  +----------------------------------------------------------+
  |  [周长公式：(10+6)×2 = 32]                    [平移箭头]  |
  |                                                          |
  |           ↑                                              |
  |        平移箭头                                          |
  |                                                          |
  |    +------------------------阶梯图形------------------+  |
  |    |  ┌──┐                                             |  |
  |  6 |  │  ├──┐                                          |  |
  |    |  │  │  ├──┐                                       |  |
  |    |  │  │  │  ├──┐                                    |  |
  |    |  └──┴──┴──┴──┴──┴──┴──┴──┘                       |  |
  |    +--------------------------------------------------+  |
  |                        10                                |
  |                                                          |
  |  平移进度 [━━━━━━━━━━━━━━━━━━━━━━━━●━━━━━━━━━━]          |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：监听 slider input 事件，根据 sliderValue (0~1) 计算各线段位置
  2. 坐标计算：
     - 水平线段目标 y 坐标：170（长方形顶边）
     - 竖直线段目标 x 坐标：700（长方形右边）
     - 当前 y = 原始 y + (目标 y - 原始 y) × sliderValue
     - 当前 x = 原始 x + (目标 x - 原始 x) × sliderValue
  3. 透明度渐变：opacity = 0.7 + 0.3 × (1 - sliderValue)，滑块 100% 时恢复不透明
  4. 等效长方形：opacity = sliderValue > 0.9 ? (sliderValue - 0.9) × 10 : 0
  5. 公式显示：sliderValue === 1 时显示
- ID 命名规范：所有元素 ID 以 scene2- 为前缀
  - scene2-base-bottom, scene2-base-left
  - scene2-hseg-1 ~ scene2-hseg-8（水平阶梯段）
  - scene2-vseg-1 ~ scene2-vseg-7（竖直阶梯段）
  - scene2-label-10, scene2-label-6
  - scene2-arrow-h, scene2-arrow-v
  - scene2-equiv-rect（等效长方形）
  - scene2-formula（周长公式）
  - scene2-slider, scene2-slider-label
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中
