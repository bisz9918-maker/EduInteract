[图示主题与整合说明]
- 本图示主题：图形 C 的周长计算与凹槽分析
- 整合的步骤/概念：图形 C 原始形态、平移演示、凹槽额外边长高亮
- 教学价值：教师可通过分步演示，让学生理解凹槽图形的周长计算方法——通过平移将不规则图形转化为规则长方形，再分析凹槽带来的额外边长。逐步展示平移过程和凹槽的额外边长，逻辑递进清晰，帮助学生建立"平移等效"的几何思维。

[分步序列]
- 初始状态（步骤 0）：显示图形 C 原始轮廓（黑色实线），底边标注"10"，右侧边标注"6"，凹槽深度箭头和标签"h"。右侧公式区显示"图形 C 周长 = ?"
- 步骤 1：点击「下一步」→ 顶部可平移线段变为蓝色 #1565c0 高亮，同时出现灰色虚线等效长方形轮廓 (150,150)-(550,300)。右侧公式区显示"平移后等效长方形周长 = (10+6)×2 = 32"
- 步骤 2：点击「下一步」→ 凹槽的两条竖直边（左竖边和右竖边）变为红色 #c62828 加粗高亮。右侧公式区追加显示"凹槽额外边长 = 2×h"
- 步骤 3：点击「下一步」→ 右侧公式区显示完整公式"周长 = 32 + 2h > 32"，并在公式下方显示结论"图形 C 周长最长"。所有高亮元素保持显示。

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript。原因：本场景为简单 2D 几何图形演示，无需复杂库，原生 SVG 可精确控制坐标和样式，代码轻量易维护。
- 画布尺寸：800 × 500 px（固定画布）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |    [图形 C]                    [公式区]          |
  |    带凹槽的多边形               周长计算          |
  |    (150,180)-(550,300)         (620,200) 起      |
  |                                                  |
  |                                                  |
  |                                                  |
  |                                                  |
  |                                                  |
  |              [上一步] [下一步]                   |
  |              (320,455) (420,455)                 |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-3），每个状态对应一组显示/隐藏的元素
  2. 坐标计算：图形 C 的凹槽位置按比例计算，凹槽深度 h = 30px（视觉比例）
  3. 动画曲线：平移线段使用 CSS transition，duration 500ms，ease-in-out
  4. 事件绑定：按钮点击事件绑定到状态切换函数，更新 DOM 元素显示状态
  5. 元素 ID 命名：所有元素 ID 以 scene3- 为前缀，如 scene3-graph-c、scene3-top-segment、scene3-groove-left 等
  6. IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
- ID 命名规范示例：
  - scene3-graph-c（图形 C 轮廓）
  - scene3-top-segment（顶部可平移线段）
  - scene3-groove-left（凹槽左竖边）
  - scene3-groove-right（凹槽右竖边）
  - scene3-equiv-rect（等效长方形轮廓）
  - scene3-label-10（底边标注）
  - scene3-label-6（右侧边标注）
  - scene3-label-h（凹槽深度标签）
  - scene3-formula-text（公式文本区）
  - scene3-btn-prev（上一步按钮）
  - scene3-btn-next（下一步按钮）
  - scene3-step-indicator（步骤指示器）
