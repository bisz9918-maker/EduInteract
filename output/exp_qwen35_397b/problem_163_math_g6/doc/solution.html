场景导航：Scene 1

题目原文：

如下图，在三角形 ABC 中，边 AB 上的高是（ ）。

A．CB B．CD C．EB

题目分析：

本题考查三角形高的定义：从三角形的一个顶点向对边（或对边的延长线）作垂线，顶点与垂足之间的线段叫做三角形的高。

在三角形 ABC 中：

  • 三个顶点：A、B、C
  • 边 AB 是底边
  • 需要找到从顶点 C 向直线 AB 所作的垂线段

整体讲解思路：

  1. 首先明确三角形高的定义
  2. 确定三角形 ABC 的三个顶点和底边 AB
  3. 从顶点 C 向直线 AB 作垂线，观察垂足位置
  4. 对比三个选项，判断哪条线段符合高的定义

图示规划说明：

设计一个分步导航图示，逐步展示：原图→高亮三角形 ABC→标注底边 AB→显示从 C 到 AB 的垂线 CD→对比三个选项→得出结论。

步骤 1/6

教学说明：

如何引导学生：

  1. 先让学生观察原图，找出三角形 ABC 的三个顶点
  2. 提问："什么是三角形的高？"引导学生回忆定义
  3. 强调：高必须满足两个条件——(1) 从顶点出发；(2) 垂直于对边

讲解要点：

  • 选项 A（CB）：从 C 出发，但 CB 与 AB 不垂直（∠CBA 不是直角）
  • 选项 B（CD）：从 C 出发，且 CD⊥AD（即 CD⊥AB），符合高的定义
  • 选项 C（EB）：虽然 EB⊥AB，但 E 不是三角形 ABC 的顶点，不符合"从顶点出发"的条件

关键公式/结论：

三角形的高 = 从顶点向对边所作的垂线段

在本题中：顶点 C → 垂足 D → 高为 CD

总结：

完整解答：

根据三角形高的定义，从顶点 C 向边 AB（或其延长线）作垂线，垂足为 D，因此边 AB 上的高是线段 CD。

答案：B

课堂讲解建议：

  1. 使用图示的分步导航功能，逐步展示分析过程
  2. 在步骤 4 停留，让学生自己判断三个选项的对错
  3. 强调易错点：EB 虽然垂直于 AB，但不是从三角形顶点出发
  4. 可延伸提问：如果问"边 BC 上的高"，应该是哪条线段？（从 A 向 BC 作垂线）
