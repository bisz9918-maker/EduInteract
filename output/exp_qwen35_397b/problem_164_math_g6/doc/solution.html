题目原文：

桌面上放着三个不同的物体，小明从不同的角度看其中的一个物体，看到的图形如图．那么，他看到的物体是图 2 中的（ ）

A．① B．② C．③

题目分析：

本题是空间几何中的三视图问题，考查学生从不同视角观察立体图形的能力。

已知条件（图 1）：

  • 正面视图：矩形
  • 侧面视图：矩形（中间有一条竖线，表示可见的棱）
  • 上面视图：梯形（上底短、下底长的四边形）

候选物体（图 2）：

  • ① 长方体（四棱柱，底面为矩形）
  • ② 五棱柱（底面为五边形，类似房子形状）
  • ③ 四棱柱（底面为梯形）

整体讲解思路：

  1. 首先引导学生观察图 1 的三个视图，理解"正面""侧面""上面"的含义
  2. 分析每个视图的特征：上面看是梯形是关键线索
  3. 逐一检验三个候选物体的三视图，排除不符合的选项
  4. 确认物体③的三视图与图 1 完全匹配

  • SCENE_2：对比三个候选物体的俯视图，直观说明为什么只有③符合题目条件

SCENE_1 教学说明：

本图示用于展示正确答案③的三视图形成过程，帮助学生建立立体图形与平面视图之间的对应关系。

引导步骤：

  1. 先让学生观察立体图形，识别这是一个底面为梯形的四棱柱
  2. 点击"下一步"展示正面视图：从正面看，只能看到一个矩形面（梯形的一个腰与视线垂直）
  3. 点击"下一步"展示侧面视图：从侧面看，看到矩形轮廓，中间的竖线是梯形另一腰形成的棱
  4. 点击"下一步"展示上面视图：从上面看，直接看到梯形的顶面
  5. 最后一步用颜色连线强化对应关系，帮助学生理解投影原理

关键公式/概念：

三视图投影规则：

  • 主视图（正面）：从前向后投影
  • 左视图（侧面）：从左向右投影
  • 俯视图（上面）：从上向下投影
  • 三视图满足"长对正、高平齐、宽相等"

SCENE_2 教学说明：

本图示用于对比三个候选物体的俯视图，通过排除法确定正确答案。

讲解要点：

  1. 题目给出的关键线索是"上面看是梯形"
  2. 逐一检查每个物体的俯视图：
  • 物体①（长方体）：俯视图是矩形，不符合
  • 物体②（五棱柱）：俯视图是五边形，不符合
  • 物体③（梯形四棱柱）：俯视图是梯形，符合！
  1. 再验证物体③的正面和侧面视图也与题目一致，确认答案

完整解答：

根据图 1 的三视图特征：

  • 上面看是梯形 → 物体顶面/底面必须是梯形
  • 正面看是矩形 → 侧面为矩形
  • 侧面看是带棱的矩形 → 侧面有可见棱

只有物体③（梯形四棱柱）同时满足以上三个条件。

答案：C．③

  2. 使用 SCENE_1 演示正确答案的三视图形成过程
  3. 使用 SCENE_2 进行对比分析，强化排除法的解题策略
  4. 总结：解决三视图问题的关键是抓住最特征的视图（本题中是梯形俯视图）作为突破口
