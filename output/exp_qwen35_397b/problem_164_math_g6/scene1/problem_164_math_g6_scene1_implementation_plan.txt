[图示主题与整合说明]
- 本图示主题：正确答案③（梯形四棱柱）的三视图形成过程
- 整合的内容：立体图形展示 + 三个视角的投影演示 + 三视图结果呈现
- 教学价值：教师可通过分步演示，引导学生理解从不同方向观察立体图形得到不同视图的概念。逐步展示正面、侧面、上面的观察过程和投影结果，帮助学生建立空间想象能力，理解三视图与立体图形的对应关系。

[视觉元素清单]
- 梯形四棱柱立体图：位于画布中心 (400,200)，用 SVG polygon 绘制透视效果。顶面为梯形，底面为梯形，四个侧面为矩形。可见棱用黑色实线 (#000000, 2px)，隐藏棱用黑色虚线 (#000000, 1px, stroke-dasharray="5,5")。填充透明度 20% (#f5f5f5)。
- 正面观察箭头：蓝色 (#1565c0)，从左侧指向立体图正面，箭头头部为三角形。
- 侧面观察箭头：绿色 (#2e7d32)，从右侧指向立体图侧面，箭头头部为三角形。
- 上面观察箭头：红色 (#c62828)，从上方指向立体图顶面，箭头头部为三角形。
- 正面视图矩形：蓝色轮廓 (#1565c0, 2px)，位于左侧 (80,280)，尺寸 60×80，表示从正面看到的矩形。
- 侧面视图矩形：绿色轮廓 (#2e7d32, 2px)，位于右侧 (640,280)，尺寸 60×80，中间有一条竖线表示棱。
- 上面视图梯形：红色轮廓 (#c62828, 2px)，位于下方 (370,400)，上底 40px，下底 80px，高 50px，表示从上面看到的梯形。
- 投影线：灰色虚线 (#888888, 1px)，连接立体图与各视图，表示投影关系。
- 标签：仅使用短标签"正面"、"侧面"、"上面"，分别用对应视图的颜色。

[分步序列]
- 初始状态（步骤 0）：仅显示梯形四棱柱立体图（中心位置）和标题。所有箭头、视图、投影线均隐藏。
- 步骤 1：显示正面观察箭头（蓝色）和投影线 1，正面视图矩形（蓝色）渐显。立体图正面轮廓高亮（蓝色描边）。
- 步骤 2：在步骤 1 基础上，显示侧面观察箭头（绿色）和投影线 2，侧面视图矩形（绿色）渐显。立体图侧面轮廓高亮（绿色描边）。
- 步骤 3：在步骤 2 基础上，显示上面观察箭头（红色）和投影线 3，上面视图梯形（红色）渐显。立体图顶面轮廓高亮（红色描边）。
- 步骤 4：完整展示所有元素，用颜色连线标注对应棱（正面视图对应棱用蓝色虚线连接，侧面视图对应棱用绿色虚线连接，上面视图对应棱用红色虚线连接）。

[交互方案]
- 交互类型：分步按钮导航（◀ 上一步 / 下一步 ▶）
- 控件说明：
  - "上一步"按钮：位于底部左侧 (280,455)，尺寸 100×30，点击后退到前一状态
  - "下一步"按钮：位于底部右侧 (420,455)，尺寸 100×30，点击前进到下一状态
  - 步骤指示器：位于两按钮之间 (390,460)，显示"步骤 X/4"
- 教师操作流程：
  1. 初始状态展示立体图形，让学生观察物体形状
  2. 点击"下一步"展示正面观察过程和结果，引导学生理解正面视图
  3. 点击"下一步"展示侧面观察过程和结果，对比正面视图的差异
  4. 点击"下一步"展示上面观察过程和结果，完整呈现三视图
  5. 点击"下一步"展示完整对应关系，用颜色连线强化理解
  6. 可随时点击"上一步"回退复习

[技术实现]
- JS 库选择及原因：原生 SVG。原因：本场景为 2D 几何图形展示，SVG 原生支持多边形、箭头、虚线等元素，无需额外库即可实现清晰的矢量图形。
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |              梯形四棱柱的三视图                   |  y=30 标题
  |                                                  |
  |                    ↑ (上面箭头)                   |
  |                    |                             |
  |     (正面箭头)→  [立体图]  ←(侧面箭头)            |  y=200 立体图
  |                   / | \                          |
  |                  /  |  \ 投影线                   |
  |                 /   |   \                        |
  |    +-------+   /    |    \   +-------+           |  y=280 视图
  |    | 正面  |  /     |     \  | 侧面  |           |
  |    | 视图  | /      |      \ | 视图  |           |
  |    +-------+/       |       \+-------+           |
  |                 +-------+                        |
  |                 | 上面  |                        |  y=400 上面视图
  |                 | 视图  |                        |
  |                                                  |
  |     [◀ 上一步]  步骤 X/4  [下一步 ▶]              |  y=455 控件栏
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量 (0-4) 跟踪当前步骤，steps 数组存储每步应显示的元素 ID 列表
  2. 坐标计算：立体图使用透视投影简化计算，顶面梯形四个顶点坐标预先计算好
  3. 动画曲线：使用 CSS transition 实现渐显效果 (opacity: 0→1, duration: 0.5s)
  4. 事件绑定：按钮点击事件绑定到 updateStep() 函数，更新显示状态
  5. 元素显隐：通过 display="none"/"inline" 或 opacity 控制元素可见性
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀（如 scene1-prism, scene1-front-view, scene1-arrow-front 等）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
