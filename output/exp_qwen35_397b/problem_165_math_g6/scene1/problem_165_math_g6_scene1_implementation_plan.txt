[图示主题与整合说明]
- 本图示主题：两种正方形地砖的面积对比
- 整合内容：展示边长 2dm 和 3dm 的正方形，标注边长和面积，直观对比面积大小关系，推导地砖数量与面积的反比关系
- 教学价值：教师可使用此图示逐步展示从边长到面积的推导过程，帮助学生理解正方形面积与边长的平方关系，进而理解地砖数量与单块面积成反比的数学原理。通过视觉对比，学生能直观看到 3dm 地砖面积是 2dm 地砖的 2.25 倍（9:4），因此所需数量是 400×(4/9)≈900 块。

- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 内底部左侧 (x=350, y=455)，宽 80px，高 30px，灰色背景
  - 「下一步」按钮：位于 SVG 内底部右侧 (x=450, y=455)，宽 80px，高 30px，蓝色背景

- 教师操作流程：
  1. 初始状态展示两个正方形轮廓，提问学生"这两个正方形有什么关系？"
  2. 点击「下一步」显示边长标注，引导学生注意边长比例 2:3
  3. 点击「下一步」显示面积计算，推导面积公式和数值
  4. 点击「下一步」高亮面积比，总结地砖数量与面积的反比关系

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript。理由：本场景为简单几何图形展示，无需复杂库，原生 SVG 可精确控制坐标和样式，代码轻量易维护。
- 画布尺寸：800 × 500 px（固定画布）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |     面积=4dm²           面积=9dm²               |
  |        ↓                   ↓                     |
  |   +--------+          +--------------+           |
  |   |        |          |              |           |
  | ← |  2dm   | →     ←  |     3dm      | →        |
  |   | 正方形 |          |    正方形    |           |
  |   |        |          |              |           |
  |   +--------+          +--------------+           |
  |        ↓                   ↓                     |
  |     2×2=4               3×3=9                    |
  |                                                  |
  |              面积比 4:9                          |
  |                                                  |
  |         [◀上一步]  步骤 X/4  [下一步▶]           |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量 (0-3) 跟踪当前步骤，steps 数组存储每步需显示的元素 ID 列表
  2. 坐标计算：正方形按 2:3 比例精确计算，左侧 120px，右侧 180px，垂直居中对齐
  3. 动画曲线：元素显示使用淡入效果 (opacity 0→1，过渡 300ms)
  4. 事件绑定：按钮点击事件绑定到 updateStep() 函数，更新显示状态
  5. 元素显隐：使用 CSS class "hidden" 控制元素显示/隐藏，避免重复创建 DOM
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀（如 scene1-square-left、scene1-label-2dm、scene1-btn-next）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
