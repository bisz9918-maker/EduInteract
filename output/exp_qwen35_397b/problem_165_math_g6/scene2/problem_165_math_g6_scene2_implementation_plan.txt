[图示主题与整合说明]
- 本图示主题：总面积不变与地砖数量转换
- 整合内容：展示健身房总面积概念，演示400块3dm大地砖如何等价于900块2dm小地砖，整合面积计算和数量转换

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript
  - SVG 适合绘制精确的几何网格和矩形
  - 无需外部库，加载快，兼容性好
  - 网格线可用 SVG pattern 或动态生成 path 元素
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                    "400块"                        | y=40
  |                                                   |
  |  +----+ 3dm          [健身房矩形 500×250]         | y=60-310
  |  |    |               大地砖/小地砖网格            |
  |  +----+                                           |
  |                                                   |
  |  +----+ 2dm                                       | y=200
  |  |    |                                           |
  |  +----+                                           |
  |                                                   |
  |  [公式框1] 400块 × 9dm² = 3600dm²                | y=370
  |  [公式框2] 总面积 = 3600dm²                      | y=400
  |  [公式框3] 3600dm² ÷ 4dm² = 900块               | y=430
  |                    [答案框] 答案：900块          | y=380-440
  |                                                   |
  |         [◀上一步]          [下一步▶]             | y=465-490
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 step 变量(0-3)跟踪当前步骤，steps 数组存储每步的可见元素配置
  2. 网格生成：大地砖网格 20×20（每格25px），小地砖网格 30×30（每格约16.67px）
  3. 动画曲线：使用 CSS transition 实现淡入淡出，duration 300ms，ease-in-out
  4. 事件绑定：按钮点击事件绑定到 updateStep() 函数，更新 DOM 元素 display/opacity
  5. 网格切换：大地砖网格和小地砖网格使用两个独立的 SVG g 元素，通过 opacity 控制显隐
- ID 命名规范：所有交互元素 ID 必须以 scene2- 为前缀
  - scene2-gym-rect, scene2-large-grid, scene2-small-grid
  - scene2-tile-large-sample, scene2-tile-small-sample
  - scene2-label-400, scene2-label-900
  - scene2-formula1, scene2-formula2, scene2-formula3
  - scene2-answer-box, scene2-btn-prev, scene2-btn-next
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
