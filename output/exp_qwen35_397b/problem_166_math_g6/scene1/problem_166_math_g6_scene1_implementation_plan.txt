[图示主题与整合说明]
- 本图示主题：平行线间三个图形的面积比较
- 整合的内容：三个图形的形状展示、底边标注、高线标注、面积公式应用及最终比较
- 教学价值：教师可使用此图示逐步引导学生观察平行线间等高条件下，不同图形的面积计算方式。通过分步高亮，学生能清晰看到每个图形的底和高，理解面积公式的应用，最后通过条形图直观比较面积大小，得出图形3面积最小的结论。

[分步序列]
- 初始状态（步骤0）：显示两条平行线、所有刻度及数字、三个图形的灰色轮廓（透明度10%）、图形标签"1""2""3"、右侧高线及"h"标签。不显示底边标注和面积公式。
- 步骤1：高亮图形1（三角形），填充色变为 #1565c0 透明度20%，显示底边标注"2"在 (220,330)，显示面积公式"S₁ = ½×2×h = h"在 (150,400)。图形2和3保持灰色。
- 步骤2：高亮图形2（平行四边形），填充色变为 #2e7d32 透明度20%，显示底边标注"1"在 (400,330)，显示面积公式"S₂ = 1×h = h"在 (350,400)。图形1和3恢复灰色。
- 步骤3：高亮图形3（三角形），填充色变为 #c62828 透明度20%，显示底边标注"1"在 (640,330)，显示面积公式"S₃ = ½×1×h = h/2"在 (550,400)。图形1和2恢复灰色。
- 步骤4：三个图形均恢复灰色轮廓，底部显示面积对比条形图。条形图1高度40px（蓝色#1565c0），条形图2高度40px（绿色#2e7d32），条形图3高度20px（红色#c62828）。每个条形图上方显示对应面积公式。突出显示图形3面积最小。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于 SVG 底部左侧 (320,460)，点击后退到前一个步骤
  - 「下一步 ▶」按钮：位于 SVG 底部右侧 (420,460)，点击前进到下一个步骤
  - 步骤指示器：显示当前步骤序号（如"步骤 1/5"）
- 教师操作流程：
  1. 初始状态展示题目图形，引导学生观察三条平行线间的三个图形
  2. 点击「下一步」高亮图形1，讲解三角形面积公式 S=½×底×高，底为2，高为h
  3. 点击「下一步」高亮图形2，讲解平行四边形面积公式 S=底×高，底为1，高为h
  4. 点击「下一步」高亮图形3，讲解三角形面积公式，底为1，高为h
  5. 点击「下一步」显示面积对比条形图，直观比较三个面积大小，得出图形3面积最小的结论
  6. 可随时点击「上一步」回退复习

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单，SVG 原生支持多边形、线段、文字等元素，无需额外库
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  y=75   0   1   2   3   4   5    (上刻度数字)     |
  |  y=90   |---|---|---|---|---|---|  (上平行线y=100)|
  |         \ 1 /   | 2 |    \ 3 /                   |
  |  y=240   图形1    图形2     图形3    h(740,225)   |
  |         /   \   |   |    /   \                   |
  |  y=350  |---|---|---|---|---|---|  (下平行线)     |
  |  y=375   0   1   2   3   4   5    (下刻度数字)     |
  |  y=400  S₁=h   S₂=h   S₃=h/2   (面积公式)         |
  |  y=440  [条形图1][条形图2][条形图3] (步骤4显示)   |
  |  y=460        [◀上一步][下一步▶]  (控件栏)        |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量（0-4）跟踪当前步骤，steps 数组存储每步的状态配置
  2. 每步状态包含：高亮图形索引、显示的底边标注、显示的面积公式、是否显示条形图
  3. 更新函数 updateStep() 根据 currentStep 设置各元素的 display 属性和填充颜色
  4. 按钮事件绑定：上一步按钮 currentStep--（最小0），下一步按钮 currentStep++（最大4）
  5. 按钮状态：步骤0时禁用上一步，步骤4时禁用下一步
- ID 命名规范：所有元素 ID 以 scene1- 为前缀
  - scene1-top-line, scene1-bottom-line
  - scene1-tick-top-0 到 scene1-tick-top-5
  - scene1-tick-bottom-0 到 scene1-tick-bottom-5
  - scene1-num-top-0 到 scene1-num-top-5
  - scene1-num-bottom-0 到 scene1-num-bottom-5
  - scene1-shape-1, scene1-shape-2, scene1-shape-3
  - scene1-label-1, scene1-label-2, scene1-label-3
  - scene1-height-line, scene1-height-label
  - scene1-base-label-1, scene1-base-label-2, scene1-base-label-3
  - scene1-formula-1, scene1-formula-2, scene1-formula-3
  - scene1-bar-1, scene1-bar-2, scene1-bar-3
  - scene1-bar-label-1, scene1-bar-label-2, scene1-bar-label-3
  - scene1-btn-prev, scene1-btn-next, scene1-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
