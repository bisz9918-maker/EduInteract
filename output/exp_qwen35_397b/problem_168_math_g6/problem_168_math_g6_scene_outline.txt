    **教学说明：**

    本图示用于直观验证代数推导的结论，将抽象的公式转化为可视化的长度对比。

    **讲解要点：**

    1. 回顾圆周长公式 C = πd
    2. 分别计算：大圆周长 = πD，两个小圆周长之和 = πd1 + πd2
    3. 利用分配律：πd1 + πd2 = π(d1 + d2)
    4. 结合直径关系 d1 + d2 = D，得出 π(d1 + d2) = πD
    5. 结论：两个小圆周长之和等于大圆周长

    **完整解答：**

    设大圆直径为 D，两个小圆直径分别为 d₁ 和 d₂。

    由图可知：d₁ + d₂ = D

    大圆周长：C = πD

    两个小圆周长之和：C₁ + C₂ = πd₁ + πd₂ = π(d₁ + d₂) = πD

    因此，两个小圆的周长之和与大圆的周长**一样长**。

    **答案：A**

    **课堂讲解建议：**

    - 可让学生先猜测答案，再用图示验证，增强参与感
    - 强调这是"一般性结论"：无论两个小圆大小如何分配，只要它们的直径之和等于大圆直径，周长之和就一定等于大圆周长
    - 可延伸思考：如果是三个、四个小圆呢？结论是否依然成立？
