[图示主题与整合说明]
- 本图示主题：三个圆的直径关系展示——验证"两个小圆周长之和等于大圆周长"
- 整合的内容：图形结构观察 → 直径标注 → 直径数量关系推导 → 周长公式应用
- 教学价值：教师可通过分步导航控制讲解节奏，从直观图形观察过渡到代数推导，帮助学生理解为什么两个小圆周长之和等于大圆周长（因为 d1 + d2 = D，所以 πd1 + πd2 = πD）

[分步序列]
- 步骤 0（初始状态）：显示三个圆的黑色轮廓（大圆 + 两个小圆），无直径线和标签，呈现题目原始图形
- 步骤 1：点击「下一步」→ 显示大圆直径（蓝色水平线段从(220,250)到(580,250)），在(400,225)显示标签"D"
- 步骤 2：点击「下一步」→ 显示两个小圆直径（绿色线段），左小圆直径(200,250)-(320,250)上方显示"d₁"，右小圆直径(400,250)-(600,250)上方显示"d₂"
- 步骤 3：点击「下一步」→ 在图形下方显示关系式"d₁ + d₂ = D"（红色加粗），同时显示拼接示意图：两条绿色线段首尾相接（长度分别对应 d1、d2），下方一条蓝色线段（长度对应 D），直观展示 d1+d2=D
- 步骤 4：点击「下一步」→ 在关系式下方显示周长公式"C = πd"（蓝色），暗示 C大=πD=π(d1+d2)=πd1+πd2=C小1+C小2

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 按钮「◀ 上一步」：位于 SVG 内底部左侧 (x=320, y=460)，宽 100px，灰色背景，点击后退到前一状态
  - 按钮「下一步 ▶」：位于 SVG 内底部右侧 (x=480, y=460)，宽 100px，蓝色背景，点击前进到下一状态
  - 步骤指示器：位于两按钮之间 (x=400, y=460)，显示"步骤 X/4"
- 教师操作流程：
  1. 初始展示原始图形，让学生观察三个圆的位置关系
  2. 点击「下一步」展示大圆直径，提问"大圆直径用什么表示？"
  3. 点击「下一步」展示两个小圆直径，提问"两个小圆直径与大圆直径有什么关系？"
  4. 点击「下一步」展示关系式和拼接示意，验证 d1+d2=D
  5. 点击「下一步」展示周长公式，引导学生推导周长关系

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |              大圆 (r=180)                        |
  |         +----左小圆----+                          |
  |         |             |    +----右小圆----+      |
  |    d₁   |             | d₂ |              |      |
  |   ←─────┼─────────────┼────┼──────────────┼→    |
  |         (260,250)     |    (500,250)            |
  |              大圆直径 D (蓝色)                   |
  |                                                  |
  |         d₁ + d₂ = D  (红色关系式)                |
  |              C = πd   (蓝色公式)                 |
  |                                                  |
  |    [拼接示意：绿色 d1][绿色 d2]                  |
  |    [========蓝色 D========]                      |
  |                                                  |
  |         [◀上一步]  步骤 X/4  [下一步▶]           |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-4) 跟踪当前步骤，数组 steps 存储每步应显示的元素 ID 列表
  2. 坐标计算：所有元素使用绝对坐标（非相对定位），确保精确控制
  3. 动画曲线：直径线使用 CSS transition: opacity 0.3s ease-in-out 实现淡入效果
  4. 事件绑定：按钮点击事件绑定到 updateStep() 函数，更新 currentStep 并刷新显示状态
  5. 元素显隐：用 display:none / display:block 或 opacity:0 / opacity:1 控制
- ID 命名规范：所有元素 ID 以 scene1- 为前缀
  - scene1-circle-large（大圆）
  - scene1-circle-small-left（左小圆）
  - scene1-circle-small-right（右小圆）
  - scene1-diameter-D（大圆直径）
  - scene1-diameter-d1（左小圆直径）
  - scene1-diameter-d2（右小圆直径）
  - scene1-label-D、scene1-label-d1、scene1-label-d2（直径标签）
  - scene1-relation-text（关系式）
  - scene1-formula-text（周长公式）
  - scene1-combine-d1、scene1-combine-d2、scene1-combine-D（拼接示意线段）
  - scene1-btn-prev、scene1-btn-next、scene1-step-indicator（控件）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
