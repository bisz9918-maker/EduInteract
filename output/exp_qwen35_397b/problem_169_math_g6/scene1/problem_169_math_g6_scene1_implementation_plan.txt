[图示主题与整合说明]
- 本图示主题：方位角与距离的综合判断
- 整合内容：方位坐标系认知 + 角度读取（北偏东40°）+ 比例尺距离计算（50km）+ 答案验证
- 教学价值：教师可使用此图示逐步讲解方位角概念，先展示坐标系建立方向感，再高亮角度帮助学生理解"北偏东"的含义，最后通过比例尺对比让学生掌握距离计算，最终综合得出结论。分步导航让教师可根据学生理解程度灵活控制节奏。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于SVG底部左侧(250,485)，点击后退到前一状态
  - 「下一步 ▶」按钮：位于SVG底部右侧(460,485)，点击前进到下一状态
  - 步骤指示器：显示当前步骤（如"步骤 2/5"），位于两按钮之间
- 教师操作流程：
  1. 初始加载后，教师先讲解方位坐标系的基本概念（步骤0）
  2. 点击「下一步」显示巡洋舰位置，引导学生观察目标点（步骤1）
  3. 再次点击「下一步」高亮角度，讲解"北偏东40°"的含义（步骤2）
  4. 继续点击「下一步」显示比例尺，对比距离（步骤3）
  5. 最后点击「下一步」显示选项，验证答案A正确（步骤4）
  6. 如需复习，可点击「上一步」回退到任意步骤

[技术实现]
- JS库选择：原生SVG + 原生JavaScript
  - 原因：本场景为2D几何图示，元素数量适中（约20个），原生SVG足够胜任，无需引入重型库
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                    北                            |
  |                     |                            |
  |                     |                            |
  |        西 ----------+---------- 东                |
  |                     |     巡洋舰●                |
  |                     |    /                       |
  |                     |  / 40°                     |
  |                     |/                           |
  |                  雷达站●                         |
  |                     |                            |
  |                     |           [50km]比例尺     |
  |                    南                            |
  |                                                  |
  |  [A]北偏东40°  [B]北偏西40°  [C]北偏东40°        |
  |     方向50km      方向50km      方向100km        |
  |                                                  |
  |         [◀ 上一步]    步骤3/5    [下一步 ▶]      |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用数组存储5个状态的配置对象，每个状态包含{visibleElements: [], highlightedElements: []}
  2. 坐标计算：巡洋舰坐标通过极坐标转换计算：x=400+160*sin(40°), y=250-160*cos(40°)
  3. 角度弧绘制：使用SVG path的arc命令，从90°（正北）到50°（北偏东40°）
  4. 事件绑定：按钮点击事件绑定到状态切换函数，更新DOM元素的display属性
  5. 动画过渡：使用CSS transition实现元素淡入淡出效果（opacity从0到1，duration 300ms）
- ID命名规范：
  - 所有元素ID以scene1-为前缀
  - 示例：scene1-axis-north, scene1-radar-station, scene1-cruiser, scene1-angle-arc, scene1-scale-bar, scene1-option-a
- IIFE隔离：所有JS代码包在(function() { ... })()中，避免全局变量污染
- 响应式考虑：SVG使用viewBox="0 0 800 500"确保缩放一致性
