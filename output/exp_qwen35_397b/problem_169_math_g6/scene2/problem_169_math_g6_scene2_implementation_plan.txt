[图示主题与整合说明]
- 本图示主题：方位角概念辨析对比（北偏东 vs 北偏西 vs 东偏北）
- 整合的步骤/概念：
  1. 北偏东40°：从正北方向向东（顺时针）偏转40°的射线方向
  2. 北偏西40°：从正北方向向西（逆时针）偏转40°的射线方向
  3. 东偏北50°：从正东方向向北（逆时针）偏转50°的射线方向（与北偏东40°重合）
- 教学价值：教师可通过切换三种方位角表述，直观展示：
  - 正确方向（北偏东40°）与巡洋舰实际位置的关系
  - 错误方向（北偏西40°）为何不匹配
  - 等价表述（东偏北50° = 北偏东40°）的几何原理
  - 帮助学生理解方位角的基准方向和偏转方向

[视觉元素清单]
- 坐标轴：4条黑色实线（#000000，线宽2px），从中心(400,250)向四方向延伸180px
- 雷达站：中心圆点（#000000填充，r=6）
- 巡洋舰：目标圆点（#c62828填充，r=5，始终显示）
- 北偏东射线：状态1/3激活时显示（#c62828红色实线，线宽2.5px）
- 北偏西射线：状态2激活时显示（#1565c0蓝色实线，线宽2.5px）

- 角度弧线：对应状态的角弧（高亮色，线宽1.5px）

- 比例尺：右下角黑色线段+刻度+文字
- 所有标签：黑色文字（#000000），字体14-16px
- 按钮：白色背景，黑色边框，选中状态用对应高亮色背景

[分步序列]
多状态切换交互（3个状态，通过按钮切换）：

状态0（初始/默认）：
- 显示：十字坐标轴、雷达站、巡洋舰实点、比例尺
- 所有方向标签（北南西东）、"雷达站"、"巡洋舰"、"50km"
- 不显示任何射线和角度标注，等待教师选择

状态1（点击"北偏东40°"按钮）：
- 高亮：北偏东射线（#c62828红色实线）
- 显示：40°角度弧（从北轴顺时针到射线）、"40°"标签
- 扇形填充：北偏东区域20%透明度红色
- 巡洋舰：红色实心点（表示匹配）
- 按钮1：红色背景高亮，按钮2/3：灰色

状态2（点击"北偏西40°"按钮）：
- 高亮：北偏西射线（#1565c0蓝色实线）
- 显示：40°角度弧（从北轴逆时针到射线）、"40°"标签（左侧）
- 扇形填充：北偏西区域20%透明度蓝色
- 巡洋舰：灰色虚影点（表示不匹配，opacity=0.4）
- 按钮2：蓝色背景高亮，按钮1/3：灰色

状态3（点击"东偏北50°"按钮）：
- 高亮：北偏东射线（#1565c0蓝色实线，说明等价）
- 显示：50°角度弧（从东轴逆时针到射线）、"50°"标签
- 扇形填充：东偏北区域20%透明度蓝色
- 巡洋舰：蓝色实心点（表示匹配）
- 按钮3：蓝色背景高亮，按钮1/2：灰色
- 附加说明：显示"与北偏东40°方向相同"文字提示

[交互方案]
- 交互类型：多状态切换（3个按钮）
- 控件说明：
  - 按钮1「北偏东40°」：位于(180,450)-(300,485)，点击后显示北偏东射线和40°角
  - 按钮2「北偏西40°」：位于(340,450)-(460,485)，点击后显示北偏西射线和40°角
  - 按钮3「东偏北50°」：位于(500,450)-(620,485)，点击后显示东偏北射线和50°角
- 教师操作流程：
  1. 初始状态展示基础坐标系和巡洋舰位置
  2. 点击「北偏东40°」，讲解这是正确答案，射线指向巡洋舰
  3. 点击「北偏西40°」，对比说明这是错误方向，巡洋舰不在该射线上
  4. 点击「东偏北50°」，说明这与北偏东40°指向相同，只是表述基准不同
  5. 可反复切换对比，强化学生对方位角概念的理解

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                    北                            |
  |                    |                             |
  |              西----+----东                       |
  |                    |                             |
  |                    南                            |
  |                                                  |
  |         [巡洋舰]  ●                               |
  |                                                  |
  |                                      [50km比例尺]|
  |                                                  |
  |  [北偏东40°]  [北偏西40°]  [东偏北50°]           |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentState (0-3) 跟踪当前状态
  2. 所有交互元素 ID 以 scene2- 为前缀（如 scene2-ray-ne, scene2-ship）
  3. JS 包在 IIFE 中：(function() { ... })() 避免全局污染
  4. 射线显示/隐藏：通过 display 属性或 opacity 控制
  5. 巡洋舰状态：实心点（匹配）vs 虚影点（不匹配，opacity=0.4）
  6. 按钮高亮：选中状态用对应颜色背景，未选中灰色
  7. 角度弧绘制：使用 SVG path 的 arc 命令
  8. 扇形填充：使用 SVG path 绘制扇形，fill-opacity=0.2
- ID 命名规范：
  - scene2-axis-n, scene2-axis-s, scene2-axis-w, scene2-axis-e（坐标轴）
  - scene2-center（雷达站中心点）
  - scene2-ship（巡洋舰点）
  - scene2-ray-ne（北偏东射线）
  - scene2-ray-nw（北偏西射线）
  - scene2-arc-40, scene2-arc-50（角度弧）
  - scene2-label-ne, scene2-label-nw, scene2-label-en（方向标签）
  - scene2-btn-1, scene2-btn-2, scene2-btn-3（三个状态按钮）
  - scene2-scale（比例尺组）
