[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位置(280,460)，尺寸80×35px，灰色背景，点击返回上一状态
  - 「下一步」按钮：位置(440,460)，尺寸80×35px，蓝色背景，点击进入下一状态
  - 步骤指示器：位置(380,465)，显示"步骤 X/4"
- 教师操作流程：
  1. 初始展示实物图，让学生观察元件连接
  2. 点击「下一步」高亮电流路径，讲解电流走向
  3. 点击「下一步」显示等效电路图，对比实物与符号
  4. 点击「下一步」显示电表测量范围，明确V₁测变阻器、V₂测灯泡
  5. 可随时点击「上一步」回退复习

[技术实现]
- JS库选择：原生SVG（电路图为几何图形，无需复杂库）
- 画布尺寸：800×500px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +------------------------------------------+
  |  [左侧实物图区]  →  [右侧等效电路图区]   |
  |     (340×350)         (340×350)         |
  |                                          |
  |                                          |
  |              [控件栏]                    |
  |         [◀上一步][步骤][下一步▶]         |
  +------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量currentStep(0-3)跟踪当前步骤，steps数组存储各步骤配置
  2. 坐标计算：所有元件位置预先计算好，步骤切换时通过display/opacity控制显示
  3. 动画曲线：步骤切换使用CSS transition，duration=500ms，ease-in-out
  4. 事件绑定：按钮点击事件绑定到stepChange函数，更新currentStep并重绘
  5. 电流路径：用<polyline>绘制，带<marker>箭头，步骤1时添加class="highlight"
  6. 虚线框：用<rect>设置stroke-dasharray="5,5"实现虚线效果
- ID命名规范：所有元素ID以scene1-为前缀，如scene1-power-real、scene1-bulb-real、scene1-path-highlight、scene1-v1-box等
- IIFE隔离：所有JS代码包在(function() { ... })()中，避免全局变量污染
- 配色规格：
  - 背景：#ffffff
  - 主线：#000000实线2px
  - 电流路径：#1565c0箭头
  - 电压表测量范围：#888888虚线
  - 元件符号：#000000
  - 高亮标注：#2e7d32加粗
  - 电表填充：#e3f2fd
