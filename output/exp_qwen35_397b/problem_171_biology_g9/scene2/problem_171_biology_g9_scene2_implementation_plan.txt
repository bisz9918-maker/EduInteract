[分步序列]
- 状态 0（初始）：显示 DNA 与 RNA 对比表、概念图（A+B+C→D→E）、5 种碱基圆形图标。选项区显示四个选项文本但不显示判断标记。分析说明区显示"请点击下方按钮分析各选项"。
- 状态 1（选项 A）：高亮对比表中"DNA 碱基=A,T,C,G"单元格（蓝色边框），在碱基展示区用红色叉号覆盖显示"✗ 5 种"，选项 A 旁显示红色"✗ 错误"标记。分析说明区显示："错误。A 代表含氮碱基，DNA 中只有 4 种碱基 (A,T,C,G)。5 种是 DNA+RNA 的总碱基数 (A,T,C,G,U)。"
- 状态 2（选项 B）：高亮概念图中的 D 方框（蓝色粗边框），在 D 方框内显示"脱氧核苷酸"文字，选项 B 旁显示绿色"✓ 正确"标记。分析说明区显示："正确。D 是由一分子含氮碱基 (A)、一分子脱氧核糖 (B) 和一分子磷酸 (C) 组成的脱氧核苷酸，是 DNA 的基本组成单位。"
- 状态 3（选项 C）：高亮对比表中"DNA 核苷酸=4 种"单元格（蓝色边框），在核苷酸展示区显示"4 种"并用红色叉号覆盖"8 种"，选项 C 旁显示红色"✗ 错误"标记。分析说明区显示："错误。D 表示脱氧核苷酸，根据碱基种类 (A,T,C,G) 不同，脱氧核苷酸只有 4 种。8 种是 DNA(4 种)+RNA(4 种) 的核苷酸总数。"
- 状态 4（选项 D）：高亮概念图中的 B 方框（蓝色粗边框），在 B 方框内显示"脱氧核糖"文字，同时高亮对比表中 DNA 的"脱氧核糖"和 RNA 的"核糖"，选项 D 旁显示红色"✗ 错误"标记。分析说明区显示："错误。B 表示五碳糖，在 DNA 中 B 是脱氧核糖，不是核糖。核糖存在于 RNA 中。"

[交互方案]
- 交互类型：多状态切换（5 个状态按钮）
- 控件说明：
  - 按钮"初始"：返回初始状态，显示基础对比表和概念图
  - 按钮"选项 A"：分析选项 A 的正误及原因
  - 按钮"选项 B"：分析选项 B 的正误及原因
  - 按钮"选项 C"：分析选项 C 的正误及原因
  - 按钮"选项 D"：分析选项 D 的正误及原因
- 教师操作流程：
  1. 初始状态展示 DNA/RNA 对比表和概念图，让学生回顾基础知识
  2. 点击"选项 A"，高亮相关区域，解释为什么 A 错误（混淆了 DNA 碱基数和总碱基数）
  3. 点击"选项 B"，高亮 D 方框，确认 B 正确（D 确实是脱氧核苷酸）
  4. 点击"选项 C"，解释为什么 C 错误（混淆了脱氧核苷酸种类和总核苷酸种类）
  5. 点击"选项 D"，高亮 B 方糖，解释为什么 D 错误（DNA 中是脱氧核糖不是核糖）

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：本场景以静态图示和状态切换为主，无需复杂动画或图表库，原生 SVG 足够实现且性能好
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [800×500 画布]
  +--------------------------------------------------+
  | [对比表]      [概念图 A+B+C→D→E]                 |
  | DNA vs RNA    A + B + C → D → E                  |
  |               (糖)(磷酸)                         |
  |               [碱基展示 A T C G U]               |
  +--------------------------------------------------+
  | [选项区]                                         |
  | A. ... ✗错误                                     |
  | B. ... ✓正确              [分析说明区]           |
  | C. ... ✗错误                                     |
  | D. ... ✗错误                                     |
  +--------------------------------------------------+
  | [初始] [选项 A] [选项 B] [选项 C] [选项 D]       |
  | (状态切换按钮栏，y=445~480)                       |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用 currentState 变量 (0-4) 跟踪当前状态，每个状态对应一组显示/隐藏逻辑
  2. 高亮实现：通过改变元素的 stroke-width、stroke 颜色、fill 透明度来实现高亮效果
  3. 动态文本：分析说明区的文本内容根据 currentState 动态更新
  4. 判断标记：选项旁的✓/✗标记根据状态显示/隐藏，颜色对应红/绿
  5. 事件绑定：5 个按钮分别绑定点击事件，调用 updateState(newState) 函数
- ID 命名规范：所有元素 ID 以 scene2- 为前缀
  - 对比表：scene2-table-dna、scene2-table-rna、scene2-table-row-sugar 等
  - 概念图：scene2-box-a、scene2-box-b、scene2-box-c、scene2-box-d、scene2-box-e
  - 碱基：scene2-base-a、scene2-base-t、scene2-base-c、scene2-base-g、scene2-base-u
  - 选项：scene2-opt-a、scene2-opt-b、scene2-opt-c、scene2-opt-d
  - 判断标记：scene2-mark-a、scene2-mark-b、scene2-mark-c、scene2-mark-d
  - 分析说明：scene2-analysis-text
  - 按钮：scene2-btn-init、scene2-btn-a、scene2-btn-b、scene2-btn-c、scene2-btn-d
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
