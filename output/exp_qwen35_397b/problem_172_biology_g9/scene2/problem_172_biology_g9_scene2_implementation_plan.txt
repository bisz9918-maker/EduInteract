[图示主题与整合说明]
- 本图示主题：三种小分子跨膜运输方式特点对比
- 整合的步骤/概念：整合了自由扩散、协助扩散（图中②）、主动运输（图中①）三种运输方式在浓度梯度、载体蛋白、能量消耗三个维度的特点对比，以及各自的实例（图中③④对应协助扩散和主动运输的实例）
- 教学价值：教师可通过分步展示的方式，逐项对比三种运输方式的异同，帮助学生建立系统性认知。先展示运输方式名称，再依次揭示各维度特点，最后呈现实例对应，符合从抽象到具体的认知规律。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮：位于(280,455)，尺寸80×30px，点击后回退到前一状态
  - 下一步按钮：位于(440,455)，尺寸80×30px，点击后进入下一状态
  - 步骤指示：位于(400,480)，显示当前步骤/总步骤数
- 教师操作流程：
  1. 初始展示三种运输方式名称，让学生回忆已有知识
  2. 点击「下一步」展示浓度梯度对比，提问"哪种运输可以逆浓度进行？"
  3. 点击「下一步」展示载体蛋白需求，强调协助扩散和主动运输的共同点
  4. 点击「下一步」展示能量消耗，突出主动运输的独特性
  5. 点击「下一步」展示实例，联系图中③④序号
  6. 最后完整呈现，引导学生总结三种运输方式的核心差异
  7. 可随时点击「上一步」回退复习特定维度

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript。理由：本场景为静态对比表格，无需复杂动画或交互，原生 SVG 足够实现，且代码轻量、易于维护。
- 画布尺寸：800 × 500 px（固定画布）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +----------------------------------------------------------+
  |              三种跨膜运输方式对比 (y=40)                  |
  +----------------------------------------------------------+
  |  维度    |  自由扩散  |  协助扩散②  |  主动运输①  |
  |----------|------------|------------|------------|
  | 浓度梯度 |  顺浓度    |  顺浓度    |  逆浓度    |
  |----------|------------|------------|------------|
  | 载体蛋白 |  不需要    |  需要      |  需要      |
  |----------|------------|------------|------------|
  | 能量消耗 |  不消耗    |  不消耗    |  消耗ATP   |
  |----------|------------|------------|------------|
  | 实例     |  O₂、CO₂   |  葡萄糖③  |  离子④    |
  |          |  甘油乙醇  |  红细胞    |  Na⁺K⁺    |
  +----------------------------------------------------------+
  |         [◀上一步]          步骤 X/5        [下一步▶]      |
  |                    (控件栏 y=440~490)                     |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量(0-5)跟踪当前步骤，steps 数组存储每步应显示的元素ID列表
  2. 坐标计算：所有元素使用绝对坐标，三列等宽200px，列间距20px
  3. 动画曲线：元素显示使用淡入效果（opacity 0→1，过渡300ms）
  4. 事件绑定：按钮点击事件绑定到 updateState() 函数，更新显示元素并刷新步骤指示
  5. 高亮实现：通过添加/移除 CSS class 实现列高亮（.highlight-green/.highlight-blue/.highlight-red）
- ID 命名规范：所有交互元素 ID 必须以 scene2- 为前缀
  - scene2-col-passive（自由扩散列）
  - scene2-col-facilitated（协助扩散列）
  - scene2-col-active（主动运输列）
  - scene2-row-gradient（浓度梯度行内容组）
  - scene2-row-carrier（载体蛋白行内容组）
  - scene2-row-energy（能量消耗行内容组）
  - scene2-row-example（实例行内容组）
  - scene2-btn-prev（上一步按钮）
  - scene2-btn-next（下一步按钮）
  - scene2-step-indicator（步骤指示文本）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
