[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  · "上一步"按钮：位置 (280,460)，尺寸 80×30，点击后退到前一状态
  · "下一步"按钮：位置 (440,460)，尺寸 80×30，点击前进到下一状态
  · 步骤指示器：位置 (380,465)，显示"步骤 X/3"
- 教师操作流程：
  1. 初始状态展示原始图，让学生观察整体结构
  2. 点击"下一步"高亮三个神经元，讲解神经元识别方法
  3. 点击"下一步"高亮突触位置，讲解突触数量统计（强调是 2 个而非 3 个）
  4. 点击"下一步"展示放大突触结构，讲解突触各部分名称和功能
  5. 可随时点击"上一步"回退复习

[技术实现]
- JS 库选择：原生 SVG（适合绘制神经元轮廓、导线、标注等几何元素，无需额外库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +----------------------------------------------------------+
  |                    电流计 (320,60)                        |
  |         导线 a←───────────┬───────────→导线 d             |
  |                           ↓                                |
  |  [神经元 A]    [神经元 B]    [神经元 C]   |  [步骤 3 放大图]  |
  |     (绿)        (蓝)        (红)        |  突触前膜       |
  |      ●b          ●c                    |  突触间隙       |
  |                                        |  突触后膜       |
  |                                        |  突触小泡       |
  |                                        |  受体           |
  |                                        |                 |
  |  [突触 1 高亮]  [突触 2 高亮]            |                 |
  |                                                  |
  |              [上一步]  步骤 X/3  [下一步]         |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-3) 跟踪当前步骤，steps 数组存储每步的可见元素 ID 列表
  2. 坐标计算：神经元轮廓用 SVG path 绘制近似椭圆，突触小泡用 circle 元素
  3. 动画曲线：元素显示/隐藏用 opacity 过渡 0.3s，高亮用 fill-opacity 过渡
  4. 事件绑定：按钮点击事件调用 stepForward()/stepBackward() 函数更新状态
  5. 元素分组：用<g>元素将相关元素分组（如 neuron-A-group、synapse-1-group），便于整体显示/隐藏
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀
  · scene1-neuron-a、scene1-neuron-b、scene1-neuron-c
  · scene1-synapse-1、scene1-synapse-2
  · scene1-synapse-detail（放大图组）
  · scene1-btn-prev、scene1-btn-next、scene1-step-indicator
  · scene1-label-neuron-a、scene1-label-synapse-1 等
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
