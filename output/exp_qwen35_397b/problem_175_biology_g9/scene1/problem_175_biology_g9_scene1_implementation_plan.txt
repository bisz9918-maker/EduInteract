[视觉元素清单]
- 树状连线：line 类型，黑色实线 2px，连接各层级节点
- 节点文字：text 类型，黑色 #000000，14px 字体
- 编号圆圈：circle 类型，#1565c0 填充，白色文字，r=12
- 特征文本框：rect 类型，#e3f2fd 浅蓝背景，圆角 5px，内含特征描述文字
- 高亮边框：rect 类型，#2e7d32 绿色，3px 描边，步骤展开时显示
- 选项判断标记：text 类型，✓用#2e7d32 绿色，✗用#c62828 红色
- 辅助虚线：line 类型，#888888 灰色虚线，用于引导视线

[分步序列]
- 初始状态（步骤0）：显示完整分类树框架（所有节点文字、树状连线、编号圆圈①②③④），特征框和选项判断隐藏
- 步骤1：高亮①裸子植物节点（绿色粗边框），显示特征框①"种子裸露，无果皮包被，如松、柏、银杏"
- 步骤2：高亮②藻类植物节点（绿色粗边框），显示特征框②"无根茎叶分化，大多生活在水中，如海带、紫菜"
- 步骤3：高亮③蕨类植物节点（绿色粗边框），显示特征框③"有根茎叶分化，有输导组织，孢子繁殖，如肾蕨"
- 步骤4：高亮④苔藓植物节点（绿色粗边框），显示特征框④"有茎叶但无输导组织，无真正根，如葫芦藓"
- 步骤5：显示选项判断结果：A✗（①是裸子植物非种子植物统称）、B✗（②藻类不一定只能生活在水中）、C✗（③蕨类有真正根但不一定矮小）、D✓（④苔藓无真正根，叶简单易受气体伤害）

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - "上一步"按钮：位于 SVG 内底部左侧 (x=350, y=450)，点击回退到上一状态
  - "下一步"按钮：位于 SVG 内底部右侧 (x=450, y=450)，点击进入下一状态
  - 状态指示器：位于底部中央 (x=400, y=470)，显示"步骤 X/6"
- 教师操作流程：
  1. 初始展示完整分类树框架，让学生观察结构
  2. 点击"下一步"高亮①，讲解裸子植物特征
  3. 点击"下一步"高亮②，讲解藻类植物特征
  4. 点击"下一步"高亮③，讲解蕨类植物特征
  5. 点击"下一步"高亮④，讲解苔藓植物特征
  6. 点击"下一步"显示选项判断，引导学生分析各选项正误
  7. 可随时点击"上一步"回退复习

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript，无需额外库，轻量且适合树状图绘制
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────┐
  │                    无果实植物                        │ y=50
  │                        │                             │
  │              ┌─────────┴─────────┐                   │
  │           无种子              有种子①                 │ y=120-145
  │             │                    │                    │
  │      ┌──────┴──────┐             │                    │
  │   无茎叶②       有茎叶           │                    │ y=200-225
  │      │             │                                  │
  │      │      ┌──────┴──────┐                          │
  │      │   有输导组织③  无输导组织④                     │ y=280-305
  │                                                     │
  │  [特征框动态显示在对应节点右侧]                        │
  │                                                     │
  │  A✗    B✗    C✗    D✓                               │ y=400
  │                                                     │
  │         [◀上一步]  步骤X/6  [下一步▶]                │ y=450-470
  └─────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用 currentState 变量跟踪当前步骤（0-5），数组存储各状态配置
  2. 坐标计算：树状图采用层级布局算法，每层 y 坐标固定，x 坐标根据子节点数量均分
  3. 动画曲线：使用 CSS transition 实现淡入淡出效果（opacity 0→1，duration 300ms）
  4. 事件绑定：按钮点击事件绑定到 updateState() 函数，更新 DOM 元素显示状态
  5. 高亮实现：通过添加/移除 CSS class 实现绿色粗边框高亮
- ID 命名规范：所有交互元素 ID 以 scene1- 为前缀，如 scene1-node-seedless、scene1-circle-1、scene1-feature-box-1、scene1-btn-prev、scene1-btn-next
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
