[图示主题与整合说明]
- 本图示主题：正常状态下上臂动脉和静脉的血流方向
- 整合的步骤/概念：动脉与静脉的定义、血流方向、在上臂中的位置关系、丝带扎紧后血管膨胀/变扁的原理
- 教学价值：教师可逐步展示动脉静脉的血流方向差异，帮助学生理解为什么丝带扎紧后不同位置的血管会有不同的膨胀/变扁现象，为解答题目中的选择题奠定直观认知基础

[分步序列]
- 初始状态（步骤0）：显示上臂轮廓（浅灰色圆角矩形）、心脏方向指示（顶部"心脏"文字+向上箭头）、手指方向指示（底部"手指"文字+向下箭头）。此时血管、丝带、区域标注均隐藏。
- 步骤1：点击「下一步」→ 显示动脉血管（红色矩形管道，右侧）和动脉血流箭头（红色向下箭头）。标签"动脉"出现在动脉上方。
- 步骤2：点击「下一步」→ 显示静脉血管（蓝色矩形管道，左侧）和静脉血流箭头（蓝色向上箭头）。标签"静脉"出现在静脉上方。
- 步骤3：点击「下一步」→ 显示丝带（灰色水平虚线，中间位置）和"丝带"标签，同时显示四个区域标注①②③④（分别位于左下、右下、右上、左上四个象限）。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 按钮"上一步"：位置(320,470)，宽80px，高36px，灰色背景
  - 按钮"下一步"：位置(400,470)，宽80px，高36px，蓝色背景
  - 步骤指示器：位置(500,475)，显示"步骤 X/3"
- 教师操作流程：
  1. 初始状态展示上臂轮廓和方向指示，教师讲解上臂的解剖位置关系
  2. 点击"下一步"展示动脉，教师讲解动脉血流方向（从心脏流向手指）
  3. 点击"下一步"展示静脉，教师讲解静脉血流方向（从手指流回心脏）
  4. 点击"下一步"展示丝带和四个区域，教师讲解丝带扎紧后为什么①③膨胀、②④变扁

[技术实现]
- JS 库选择及原因：原生 SVG。理由：本场景为简单几何图形（矩形、线条、箭头、文字），无需复杂库，原生 SVG 轻量且易于控制各元素的显示/隐藏状态。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                    心脏 ↑                        |
  |                                                  |
  |   静脉        [上臂轮廓]         动脉            |
  |     ↑        +----------+          ↓            |
  |     |        |          |          |            |
  |  ④  |        |          |          |  ③         |
  |-----+--------+----------+----------+------------| 丝带
  |  ①  |        |          |          |  ②         |
  |     |        |          |          |            |
  |     ↓        +----------+          ↑            |
  |                                                  |
  |                    手指 ↓                        |
  |                                                  |
  |         [◀上一步] [下一步▶]  步骤 X/3            |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-3) 跟踪当前步骤
  2. 各元素分组：使用 SVG <g> 元素将相关元素分组（如动脉组、静脉组、丝带组、区域标注组）
  3. 显示/隐藏控制：通过设置 display="none" 或 display="block" 控制各组的可见性
  4. 按钮事件绑定：为"上一步"和"下一步"按钮添加 click 事件监听器
  5. 边界处理：步骤0时禁用"上一步"，步骤3时禁用"下一步"
  6. 动画效果（可选）：元素出现时添加简单的淡入效果（opacity 从 0 到 1）
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀
  - scene1-arm-outline（上臂轮廓）
  - scene1-vein-group（静脉组）
  - scene1-artery-group（动脉组）
  - scene1-band-group（丝带组）
  - scene1-region-1/2/3/4（区域标注①②③④）
  - scene1-btn-prev（上一步按钮）
  - scene1-btn-next（下一步按钮）
  - scene1-step-indicator（步骤指示器）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
