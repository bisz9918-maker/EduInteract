[图示主题与整合说明]
- 本图示主题：动脉血与静脉血的含氧量对比
- 整合内容：基于题目图片中的丝带扎紧上臂示意图，展示血管①②③④的血流方向、血管类型（动脉/静脉）及含氧量对比

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（线段、矩形、圆形、文字），无需复杂库；原生实现轻量、加载快
- 画布尺寸：800×500 px（固定）
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │                    ①与③含氧量对比                          │ 标题区 y=40
  │                                                             │
  │    含氧条                          含氧条                   │
  │    ③████████ 80%                  ④███ 30%                │ y=180-200
  │         ↑                              ↓                   │
  │    ┌────┴────┐                    ┌────┴────┐              │
  │  ④│         │③                  ④│         │③            │ y=150-250
  │    │  丝带   ├────────────────────┤  丝带   │              │ y=250 丝带线
  │  ①│         │②                  ①│         │②            │ y=250-350
  │    └────┬────┘                    └────┬────┘              │
  │         ↓                              ↑                   │
  │    ①███ 30%                   ②████████ 80%                │ y=300-320
  │    含氧条                          含氧条                   │
  │                                                             │
  │              ┌──────────────────────────────┐               │ 总结框 y=380
  │              │  动脉血 vs 静脉血 总结文字    │               │
  │              └──────────────────────────────┘               │
  │                                                             │
  │         [①vs③]    [②vs④]    [总结]                        │ 控件栏 y=460
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-3），每个状态对应一组显示/隐藏元素
  2. 元素 ID 命名：所有元素以 scene3- 为前缀，如 scene3-vein-left、scene3-artery-right、scene3-o2-bar-1 等
  3. 状态切换函数：updateState(newState) 统一控制所有元素的 display 属性
  4. 按钮高亮：当前激活状态按钮添加 active 类（背景色加深）
  5. 动画效果：状态切换时含氧条使用 CSS transition 实现填充宽度渐变（0.3s ease）
  6. 事件绑定：三个按钮分别绑定 onclick 调用 updateState(1/2/3)
- ID 命名规范：
  - 血管：scene3-vein-left（左静脉）、scene3-artery-right（右动脉）
  - 编号标签：scene3-label-1/2/3/4
  - 含氧条：scene3-o2-bar-1/2/3/4
  - 氧分子：scene3-o2-molecule-1a/1b...（每个血管多个分子）
  - 按钮：scene3-btn-state1/2/3
  - 标题：scene3-title
  - 总结框：scene3-summary-box
- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染
