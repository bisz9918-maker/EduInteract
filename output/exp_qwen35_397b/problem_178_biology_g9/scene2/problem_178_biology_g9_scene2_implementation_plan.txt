[图示主题与整合说明]
- 本图示主题：过程③的分离定律验证（F₁白花自交）
- 整合的步骤/概念：整合了配子形成、Punnett 方格、后代基因型比例、表现型比例四个环节
- 教学价值：教师可通过分步演示，让学生清晰理解从 F₁白花亲本（Aa）经减数分裂产生配子，再到受精形成 F₂后代的完整过程，验证基因分离定律。分步呈现有助于学生建立因果关系链，理解为什么会出现 3:1 的表现型比例。

[分步序列]
- 初始状态（步骤 0）：显示标题、亲本 Aa⊗符号、Punnett 方格框架（外框 + 内线，空白）、配子形成标题、比例标题（空白值）。等待教师触发。
- 步骤 1：点击「下一步」→ 显示配子形成箭头（Aa→A 和 a）、配子 A（绿色）和 a（红色）、分离定律示意简图（同源染色体分离）。Punnett 方格仍空白。
- 步骤 2：点击「下一步」→ 显示 Punnett 方格的顶部配子标签（A、a）和左侧配子标签（A、a），表示父本和母本配子准备结合。
- 步骤 3：点击「下一步」→ 填充 Punnett 方格：左上 AA（蓝色背景）、右上 Aa（蓝色背景）、左下 Aa（蓝色背景）、右下 aa（黄色背景）。四个基因型同时出现。
- 步骤 4：点击「下一步」→ 显示比例标注：基因型比例"1:2:1"（加粗）、表现型比例"3 白:1 黄"（加粗）。完成整个分离定律验证过程。
- 教师可随时点击「上一步」回退复习任一环节。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于 (250,455)，80×30px，点击后返回上一状态（步骤 0 时禁用）
  - 「下一步 ▶」按钮：位于 (470,455)，80×30px，点击后进入下一状态（步骤 4 时禁用）
  - 步骤指示文本：位于 (400,465)，显示当前步骤"步骤 X/5"
- 教师操作流程：
  1. 初始状态展示 F₁白花亲本（Aa）和空白 Punnett 方格框架，教师介绍背景
  2. 点击「下一步」展示配子形成，教师讲解减数分裂中等位基因分离
  3. 点击「下一步」展示 Punnett 方格的配子标签，教师说明雌雄配子结合
  4. 点击「下一步」填充方格，教师引导学生观察基因型组合
  5. 点击「下一步」显示比例，教师总结分离定律的 3:1 表现型比例
  6. 可随时点击「上一步」回退复习任一环节

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript。本场景为静态几何图形（方格、箭头、文本）和简单状态切换，无需复杂动画或 3D，原生 SVG 足够且性能最优。
- 画布尺寸：800 × 500 px（固定画布）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────────┐
  │  过程③：F₁白花自交验证分离定律                    (y=35)   │
  │                                                             │
  │  亲本：Aa ⊗                                   (y=80)       │
  │                                                             │
  │  配子形成          Punnett 方格                             │
  │  Aa→A              ┌─────┬─────┐  顶标 A  a                │
  │    →a              │ AA  │ Aa  │                           │
  │                    ├─────┼─────┤  左标 A/a                 │
  │  [染色体示意]      │ Aa  │ aa  │                           │
  │                    └─────┴─────┘                           │
  │                                                             │
  │  基因型比例：1:2:1    表现型比例：3 白:1 黄    (y=400)      │
  │                                                             │
  │  ┌─────────────────────────────────────────────────────┐   │
  │  │   [◀ 上一步]      步骤 X/5      [下一步 ▶]          │   │
  │  └─────────────────────────────────────────────────────┘   │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量（0-4），每个步骤对应一组元素的显示/隐藏状态
  2. 元素分组：将相关元素放入 <g> 组，如 step1-group、step2-group 等，通过 display 属性控制显示
  3. 按钮状态：步骤 0 时禁用「上一步」，步骤 4 时禁用「下一步」，使用 opacity 和 pointer-events 控制
  4. 坐标计算：所有坐标硬编码，确保与布局表一致
  5. 事件绑定：按钮点击事件绑定到 stepChange 函数，更新 currentStep 并刷新显示
- ID 命名规范：所有交互元素 ID 必须以 scene2- 为前缀
  - scene2-title, scene2-parent-label, scene2-parent-genotype, scene2-self-cross-symbol
  - scene2-gamete-title, scene2-gamete-arrow-1, scene2-gamete-arrow-2, scene2-gamete-A, scene2-gamete-a
  - scene2-punnett-title, scene2-punnett-frame, scene2-punnett-hline, scene2-punnett-vline
  - scene2-punnett-top-A, scene2-punnett-top-a, scene2-punnett-left-A, scene2-punnett-left-a
  - scene2-punnett-cell-AA, scene2-punnett-cell-Aa1, scene2-punnett-cell-Aa2, scene2-punnett-cell-aa
  - scene2-ratio-genotype-label, scene2-ratio-genotype-value, scene2-ratio-phenotype-label, scene2-ratio-phenotype-value
  - scene2-separation-diagram
  - scene2-btn-prev, scene2-btn-next, scene2-step-indicator, scene2-control-bar
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
