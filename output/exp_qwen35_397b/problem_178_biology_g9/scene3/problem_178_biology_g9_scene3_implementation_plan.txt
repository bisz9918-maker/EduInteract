[图示主题与整合说明]
- 本图示主题：F₂代黄花与白花比例计算可视化
- 整合的步骤/概念：整合了F₁比例分析、两支系分别计算、最终比例汇总三个环节
- 教学价值：教师可使用此图示逐步演示遗传比例的计算过程，从F₁构成出发，分别追踪黄花支系和白花支系的遗传贡献，最后汇总得出F₂代5:3的比例。分步导航让教师可以控制讲解节奏，学生能清晰看到每一步的计算逻辑。

[视觉元素清单]
- F₁构成区：两个并排矩形框，左侧红色边框(#c62828)表示黄花，右侧蓝色边框(#1565c0)表示白花
- 支系计算区：左侧黄花支系用红色路径(#c62828)，右侧白花支系用蓝色路径(#1565c0)
- 数值标注：黄花数值用黄色(#f9a825)加粗，白花数值用蓝色(#1565c0)加粗
- 汇总框：绿色边框(#2e7d32)，白色填充，突出显示最终比例
- 箭头：黑色实线(#000000) 2px，带箭头标记
- 背景：#ffffff

[分步序列]
- 初始状态（步骤0）：显示F₁构成区（黄花1/2框+白花1/2框），显示标题"F₁ 构成"，两支系区域和汇总区隐藏
- 步骤1：显示黄花支系计算区（标题+计算式"1/2 × 1 = 1/2" + 结果"→ 1/2 黄花"），黄花贡献箭头出现，黄花数值用黄色高亮
- 步骤2：显示白花支系计算区上半部分（标题+计算式1"1/2 × 1/4 = 1/8" + 结果"→ 1/8 黄花"），白花黄花贡献箭头出现，1/8用黄色高亮
- 步骤3：显示白花支系计算区下半部分（计算式2"1/2 × 3/4 = 3/8" + 结果"→ 3/8 白花"），白花花贡献箭头出现，3/8用蓝色高亮
- 步骤4：显示汇总框，汇总计算式"黄花=1/2+1/8=5/8，白花=3/8"，最终比例"5:3"用大字号绿色显示，标注"选项C正确"

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "上一步"按钮：位于(320, 450)，点击后回退到前一状态
  - "下一步"按钮：位于(480, 450)，点击后进入下一状态
  - 步骤指示器：位于(400, 490)，显示当前步骤"步骤 X/4"
- 教师操作流程：
  1. 初始状态展示F₁构成，教师讲解亲本杂交结果
  2. 点击"下一步"，展示黄花支系计算，教师讲解黄花纯合子自交后代全为黄花
  3. 点击"下一步"，展示白花支系的黄花贡献，教师讲解杂合子分离定律
  4. 点击"下一步"，展示白花支系的白花贡献，完善分离比例
  5. 点击"下一步"，展示汇总结果，教师讲解5:3比例的由来并验证选项C

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript。原因：本场景为流程图+文本标注，无需复杂图表库，原生 SVG 足够实现且性能好
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────┐
  │                    F₁ 构成                               │ y=20-40
  │  ┌─────────────┐           ┌─────────────┐             │ y=55-95
  │  │  黄花 1/2   │           │   白花 1/2  │             │
  │  └──────┬──────┘           └──────┬──────┘             │
  │         ↓                         ↓                     │ y=95-125
  │  ┌─────────────┐           ┌─────────────┐             │ y=130-160
  │  │黄花支系(aa) │           │白花支系(Aa) │             │
  │  │ 1/2×1=1/2   │           │1/2×1/4=1/8  │             │ y=160-200
  │  │ →1/2黄花    │           │→1/8黄花     │             │ y=200-235
  │  │             │           │1/2×3/4=3/8  │             │ y=235-270
  │  │             │           │→3/8白花     │             │ y=270-305
  │         ↘                 ↙     ↘                         │ y=305-350
  │  ┌─────────────────────────────────────┐                │ y=370-430
  │  │        F₂ 比例 黄花:白花 = 5:3      │                │
  │  └─────────────────────────────────────┘                │
  │                                                         │
  │         [◀上一步]          [下一步▶]                    │ y=450-480
  │                    步骤 X/4                             │ y=490
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量(0-4)跟踪当前步骤，steps 数组存储每步的可见元素ID列表
  2. 坐标计算：所有元素使用绝对坐标，箭头路径使用 SVG path 元素
  3. 动画曲线：元素出现使用淡入效果（opacity 0→1，duration 300ms）
  4. 事件绑定：按钮点击事件绑定到 updateStep() 函数，更新可见元素和步骤指示器
  5. 高亮逻辑：每步新增元素添加高亮类（黄色或蓝色），旧元素保持普通样式
- ID 命名规范：所有交互元素 ID 必须以 scene3- 为前缀（如 scene3-f1-yellow-box、scene3-yellow-branch-title、scene3-summary-box）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
