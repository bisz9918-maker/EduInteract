[分步序列]
步骤0（初始状态）：显示基础装置
- 显示：两个试管轮廓、石灰水（透明浅蓝色#e3f2fd 30%）、导管系统（灰色）、M口
- 夹子X/Y显示为灰色中性状态（未明确开/关）
- 显示所有静态标签：M、夹子X、夹子Y、试管1、试管2、石灰水
- 无气流、无气泡、无浑浊效果

步骤1：点击「下一步」→ 高亮夹子状态
- 夹子X变为红色×图标（#c62828），表示关闭
- 夹子Y变为绿色√图标（#2e7d32），表示开启
- 其他元素保持不变

步骤2：点击「下一步」→ 动态气流箭头
- 保持步骤1的夹子状态
- 蓝色箭头#1565c0从M口(400,100)沿水平管道向右侧移动至(600,100)
- 箭头动画：分段移动效果，模拟气体流动
- 试管1侧无气流（因夹子X关闭）

步骤3：点击「下一步」→ 试管2产生气泡
- 保持步骤2的气流箭头（半透明）
- 气泡从试管2长导管末端(600,300)产生，向上冒泡至液面(600,280)
- 气泡动画：3-5个小圆圈#90caf9依次上升，大小渐变

步骤4：点击「下一步」→ 试管2石灰水变浑浊
- 保持步骤3的气泡效果（间歇显示）
- 试管2石灰水逐渐变为浑浊状态：#ffffff透明度80% + 白色颗粒#eeeeee随机悬浮
- 试管1保持澄清状态（#e3f2fd 30%透明度）
- 显示最终结论视觉提示：试管2明显浑浊 vs 试管1澄清

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于(320,455)，点击后退到前一状态（步骤0时禁用）
  - 「下一步 ▶」按钮：位于(460,455)，点击前进到下一状态（步骤4时禁用）
- 教师操作流程：
  1. 初始展示装置结构，讲解各部分名称和功能
  2. 点击「下一步」展示夹子状态，解释为什么X关闭Y开启（呼气时气体只能走右侧）
  3. 点击「下一步」展示气流路径，追踪气体从M口到试管2的流动
  4. 点击「下一步」展示气泡现象，说明气体通入石灰水
  5. 点击「下一步」展示浑浊结果，解释CO₂使石灰水变浑浊的化学原理
  6. 可随时点击「上一步」回退复习关键步骤

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript
  - 理由：几何形状简单（试管、管道、箭头），无需复杂库；SVG 便于精确控制坐标和动画；原生JS足够实现状态切换和简单动画
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │                        M                                    │
  │                        │                                    │
  │         夹子X          │          夹子Y                     │
  │     [×]────────────────┼───────────────[√]                  │
  │      │  │             │               │  │                  │
  │   ┌──┴──┴──┐                      ┌───┴──┴───┐             │
  │   │ 试管1  │                      │  试管2   │             │
  │   │ ~~~~~  │    ←── 石灰水 ──→    │ ~~~~~~~~ │  ← 浑浊    │
  │   │        │                      │          │             │
  │   └────────┘                      └──────────┘             │
  │     试管1                            试管2                  │
  │                                                             │
  │              [◀ 上一步]      [下一步 ▶]                     │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用currentState变量(0-4)跟踪当前步骤，steps数组存储每步的显示配置
  2. 坐标计算：所有元素使用绝对坐标（SVG viewBox="0 0 800 500"）
  3. 动画曲线：气流箭头使用CSS transition + transform translateX；气泡使用requestAnimationFrame逐帧上升
  4. 事件绑定：按钮点击事件绑定到stepForward()/stepBackward()函数
  5. 元素显隐：通过display属性或opacity控制各步骤元素的显示/隐藏
  6. 浑浊效果：使用<circle>元素生成20-30个随机位置的白色小圆，opacity动画模拟悬浮
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀
  - scene1-tube1, scene1-tube2（试管轮廓）
  - scene1-lime1, scene1-lime2（石灰水填充）
  - scene1-pipe-horizontal, scene1-pipe-m, scene1-pipe1-long, scene1-pipe1-short, scene1-pipe2-long, scene1-pipe2-short（导管）
  - scene1-clipper-x, scene1-clipper-y（夹子图标）
  - scene1-label-m, scene1-label-clipper-x, scene1-label-clipper-y, scene1-label-tube1, scene1-label-tube2, scene1-label-lime（标签）
  - scene1-arrow-flow（气流箭头）
  - scene1-bubble-group（气泡组）
  - scene1-turbid-particles（浑浊颗粒组）
  - scene1-btn-prev, scene1-btn-next（按钮）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
