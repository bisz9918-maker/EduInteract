[分步序列]
- 初始状态（步骤 0）：显示完整实物电路图，所有元件和导线可见，无高亮，无电流箭头
- 步骤 1：高亮干路电流路径（电源正极→开关 S），蓝色箭头从(450,65)沿导线指向(680,120)，开关 S 轮廓加粗
- 步骤 2：高亮分支点，红色圆点出现在(560,320)，标注"分支点"文字，显示电流分为两路的示意箭头
- 步骤 3：高亮 L₁ 支路，蓝色箭头从分支点经 L₁ 右侧→L₁→L₁ 左侧→电流表→汇合点，电流表 A 和 L₁ 轮廓加粗为蓝色
- 步骤 4：高亮 L₂ 支路，蓝色箭头从分支点经 L₂ 右侧→L₂→L₂ 左侧→汇合点，L₂ 轮廓加粗为蓝色
- 步骤 5：显示汇合点红色圆点(200,230)，标注"汇合点"，电流汇合后回到电源负极，底部结论文本框显示"并联电路：L₁ 与 L₂ 并联，电流表测 L₁ 支路电流"

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于(320,475)，返回上一状态
  - 「下一步」按钮：位于(420,475)，进入下一状态
  - 步骤指示器：位于(380,475)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始状态展示完整电路，让学生观察元件连接
  2. 点击「下一步」逐步追踪电流路径
  3. 在步骤 2 强调分支概念
  4. 在步骤 3-4 对比两条支路，说明电流表与 L₁ 串联
  5. 步骤 5 总结并联结构结论

[技术实现]
- JS 库选择：原生 SVG（电路图为静态几何图形，无需复杂动画库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +------------------------------------------+
  |              电源 (+ -)                  |
  |                    开关 S                |
  |                                          |
  |     电流表 A                    分支点   |
  |                              L₁   L₂     |
  |                    汇合点                |
  |                                          |
  |              [结论文本框]                |
  |         [◀上一步] 步骤 X/5 [下一步▶]     |
  +------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用 currentState 变量(0-5)跟踪当前步骤，steps 数组存储每步的显示配置
  2. 电流箭头动画：使用 SVG <path> 配合 stroke-dasharray/stroke-dashoffset 实现流动效果
  3. 高亮效果：通过改变 stroke-width 和 stroke 颜色实现元件高亮
  4. 事件绑定：按钮点击事件切换状态，更新 SVG 元素可见性和样式
  5. ID 命名规范：所有元素 ID 以 scene1-为前缀（如 scene1-battery、scene1-switch、scene1-ammeter、scene1-lamp1、scene1-lamp2、scene1-branch-point、scene1-junction-point、scene1-arrow-1 等）
  6. IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
- 配色规格：
  - 背景：#ffffff
  - 导线及元件轮廓：#000000 实线
  - 电流路径箭头：#1565c0 蓝色
  - 分支点/汇合点：#c62828 红色
  - 结论文本框边框：#2e7d32 绿色
  - 辅助说明线：#888888 虚线
