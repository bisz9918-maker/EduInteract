[分步序列]
- 初始状态（步骤 0）：显示空白绘图区框架，右侧显示四个选项框（灰色背景，无验证结果）
- 步骤 1：绘制电源符号和开关 S，显示干路导线，标签"电源"和"S"出现
- 步骤 2：绘制 L₁ 支路（从分支点向下→向左），绘制电流表 A 和灯泡 L₁，蓝色电流箭头显示 L₁ 支路电流方向
- 步骤 3：绘制 L₂ 支路（从分支点向下→向右），绘制灯泡 L₂，蓝色电流箭头显示 L₂ 支路电流方向
- 步骤 4：完成并联结构，显示汇合点和回电源导线，两个分支点用实心圆点标记
- 步骤 5：逐项验证选项：
  · 选项 A（串联）→ 显示红色×（两灯并联非串联）
  · 选项 B（电流表测 L₁ 电流）→ 显示绿色√背景高亮（电流表与 L₁ 串联）
  · 选项 C（电流表测 L₂ 电流）→ 显示红色×（电流表不在 L₂ 支路）
  · 选项 D（开关只控 L₂）→ 显示红色×（开关在干路控制全电路）

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  · 「上一步」按钮：位于 (280,460)，返回上一状态
  · 「下一步」按钮：位于 (420,460)，进入下一状态
  · 步骤指示器：位于 (380,455)，显示"步骤 X/6"
- 教师操作流程：
  1. 初始展示空白框架和选项
  2. 点击「下一步」逐步绘制电路图，讲解实物图与标准图的对应关系
  3. 步骤 4 完成后强调并联结构特征
  4. 步骤 5 逐项验证，引导学生判断各选项正误
  5. 可点击「上一步」回顾关键步骤

[技术实现]
- JS 库选择：原生 SVG（电路符号为简单几何图形，SVG 缩放不失真）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |   [电源]──[开关 S]──●分支点                      |
  |              │       │                           |
  |              │    [L₂支路]                       |
  |           [L₁支路]   │                           |
  |        [电流表]──[L₁] │                          |
  |              │       │                           |
  |              └───●───┘ 汇合点                    |
  |                  │                                |
  |              (回电源)                             |
  |                                                  |
  |   [选项区]                                       |
  |   A. 电灯 L₁、L₂ 是串联      [×]                 |
  |   B. 电流表测 L₁ 的电流     [√] 绿色高亮         |
  |   C. 电流表测 L₂ 的电流      [×]                 |
  |   D. 开关只控制 L₂          [×]                 |
  |                                                  |
  |        [◀上一步]  步骤 X/6  [下一步▶]            |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  · 状态机设计：用 currentState 变量 (0-5) 跟踪步骤，数组存储每步需显示的元素 ID 列表
  · 电路符号绘制：用 SVG <path> 绘制电池组（长短线）、开关（折线）、灯泡（圆+×）、电流表（圆+A）
  · 动画效果：元素用 opacity 和 stroke-dasharray 实现渐显/绘制动画
  · 事件绑定：按钮点击事件切换状态，更新显示元素集合
  · ID 命名规范：所有元素 ID 以 scene2- 为前缀（如 scene2-power、scene2-switch、scene2-lamp1、scene2-ampere、scene2-option-a 等）
  · IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
- 配色规格：
  · 背景：#ffffff
  · 电路符号及导线：#000000 实线
  · 电流方向箭头：#1565c0 蓝色
  · 正确选项 B 高亮：#2e7d32 绿色背景
  · 错误选项 A/C/D：#c62828 红色叉号
  · 辅助线：#888888 虚线
