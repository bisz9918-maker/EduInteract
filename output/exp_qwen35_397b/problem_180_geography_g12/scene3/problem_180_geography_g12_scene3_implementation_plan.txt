[图示主题与整合说明]
- 本图示主题：昼长计算原理——纬线圈被晨昏线分割的昼弧与夜弧
- 整合内容：B 点所在纬线的昼弧夜弧比例、昼长计算公式、A 点赤道的昼夜等长特性
- 教学价值：教师通过拖动滑块选择不同纬线，直观展示该纬线被晨昏线分割的昼弧和夜弧长度比例，学生可观察纬度变化与昼长变化的关系，理解"昼长=昼弧/360°×24 小时"的计算原理。赤道全年昼夜等长（12 小时）作为参照基准。

[分步序列]
本场景为连续拖拽滑块交互，无分步导航，状态随滑块位置连续变化：

- 初始状态（滑块在 B 点纬线 y=160）：
  - 显示地球侧视图、晨昏线、昼夜半球填充
  - 高亮显示 B 点纬线的昼弧段（绿色）和夜弧段（灰色）
  - 显示昼弧、夜弧标注
  - 滑块手柄位于 y=160
  - 昼长数值显示："B 点昼长≈16 小时"（根据昼弧比例计算）
  - A 点夜长固定显示："A 点（赤道）夜长=12 小时"
  - 公式标签显示："昼长=昼弧/360°×24 小时"

- 拖动滑块向上（更高纬度）：
  - 滑块手柄 y 坐标减小
  - 高亮显示新纬线的昼弧和夜弧
  - 昼长数值实时更新（北半球夏季纬度越高昼越长）
  - 当滑块接近北极圈时，昼长接近 24 小时

- 拖动滑块向下（赤道方向）：
  - 滑块手柄 y 坐标增大
  - 昼弧夜弧比例趋近 1:1
  - 昼长数值趋近 12 小时
  - 到达赤道(y=250)时，昼长=12 小时

- 拖动滑块到南半球（y>250）：
  - 高亮显示南半球对应纬线
  - 昼长数值小于 12 小时（南半球此时为冬季）
  - 当滑块接近南极圈时，昼长接近 0 小时（极夜）

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：
  - 纬度滑块轨道：位于 x=680，y 从 120 到 380，表示从北极到南极的纬度范围
  - 滑块手柄：圆形可拖动，跟随鼠标/触摸移动，限制在轨道范围内
  - 昼长数值显示区：位于底部(600,450)，实时显示当前纬线的昼长
  - A 点夜长固定显示：位于(600,475)，始终显示"赤道夜长=12 小时"作为参照

- 教师操作流程：
  1. 初始状态展示 B 点纬线的昼弧夜弧分割情况
  2. 讲解"昼长=昼弧/360°×24 小时"公式
  3. 拖动滑块向上，展示高纬度地区昼弧变长，昼长增加
  4. 拖动滑块到赤道，展示昼夜等长（12 小时）
  5. 拖动滑块到南半球，展示南半球昼弧变短，昼长减少
  6. 引导学生总结纬度与昼长的关系规律

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（圆形、椭圆弧、线段），无需复杂库；拖拽交互用原生事件即可实现

- 画布尺寸：800 × 500 px（固定）

- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +----------------------------------------------------------+
  |  N                          公式标签      [滑块轨道]     |
  |     [地球侧视图]                                          |
  |    / 昼弧 夜弧 \                           |             |
  |   |   (B 纬线)   |                          |  ●手柄     |
  |   |  晨昏线 A●C  |                          |             |
  |    \           /                            |             |
  |     [S]                                      |             |
  |                                              |             |
  |                    昼长数值：___小时         |             |
  |                    A 点夜长=12 小时          |             |
  +----------------------------------------------------------+
  ```

- 关键实现要点：
  1. 状态机设计：无需离散状态，滑块位置(y 坐标)作为连续状态变量
  2. 坐标计算：
     - 纬线椭圆弧：根据 y 坐标计算椭圆在地球圆内的截线
     - 昼弧角度：根据晨昏线方程与纬线交点计算昼弧所对圆心角
     - 昼长 = (昼弧角度/360) × 24
  3. 动画曲线：拖拽为实时响应，无需动画曲线
  4. 事件绑定：
     - mousedown/touchstart：开始拖动
     - mousemove/touchmove：更新滑块位置和高亮区域
     - mouseup/touchend：结束拖动
  5. 边界限制：滑块 y 坐标限制在[120, 380]范围内

- ID 命名规范：
  - 地球轮廓：scene3-earth-circle
  - 晨昏线：scene3-terminator-line
  - 夜半球：scene3-night-region
  - 昼半球：scene3-day-region
  - 赤道：scene3-equator-line
  - B 点纬线：scene3-lat-b
  - 南半球纬线：scene3-lat-south
  - A 点：scene3-point-a
  - B 点：scene3-point-b
  - C 点：scene3-point-c
  - 滑块轨道：scene3-slider-track
  - 滑块手柄：scene3-slider-handle
  - 昼弧高亮：scene3-day-arc-highlight
  - 夜弧高亮：scene3-night-arc-highlight
  - 昼长数值：scene3-daylength-value
  - 公式标签：scene3-formula-label

- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
