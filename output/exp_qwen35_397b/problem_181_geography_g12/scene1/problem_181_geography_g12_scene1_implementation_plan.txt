[图示主题与整合说明]
- 本图示主题：三圈环流剖面结构与气压带风带分布
- 整合的步骤/概念：整合图甲的完整三圈环流系统，包括低纬环流圈、中纬环流圈、高纬环流圈，以及 A-F 各位置的气压带和风带标注、纬度对应关系
- 教学价值：教师可使用此图示从赤道到极地依次讲解三圈环流的形成机制，帮助学生建立系统认知。通过分步呈现，学生可先理解环流圈结构，再认识气压带分布，最后掌握风带特征，符合认知规律。

[分步序列]
- 初始状态（步骤 0）：显示剖面弧线、N 极点标注、4 条纬度标注线及数值（0°、30°、60°、90°）。仅显示基础框架，等待教师讲解。
- 步骤 1：点击「下一步」→ 显示三个环流圈的闭合环流箭头（低纬、中纬、高纬），箭头为蓝色 #1565c0。教师可讲解环流圈的形成和方向。
- 步骤 2：点击「下一步」→ 高亮 A、C、E、N 四个气压带位置，用红色半透明区域 #c62828(20%) 填充，同时显示字母标签 A、C、E、N。教师讲解气压带的纬度分布。
- 步骤 3：点击「下一步」→ 高亮 B、D、F 三个风带位置，用绿色半透明区域 #2e7d32(20%) 填充，同时显示字母标签 B、D、F。教师讲解风带的位置。
- 步骤 4：点击「下一步」→ 显示完整文字标注：赤道低压带、副热带高压带、副极地低压带、极地高压带（气压带名称）；东北信风带、盛行西风带、极地东风带（风带名称）。教师总结三圈环流系统。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 (280,460)，点击后返回上一状态
  - 「下一步」按钮：位于 (420,460)，点击后进入下一状态
  - 状态指示器：位于 (360,460)，显示"步骤 X/4"
- 教师操作流程：
  1. 初始状态展示基础框架，教师介绍剖面图结构
  2. 点击「下一步」显示环流圈，讲解三圈环流形成
  3. 点击「下一步」高亮气压带，讲解气压带分布规律
  4. 点击「下一步」高亮风带，讲解风带位置
  5. 点击「下一步」显示完整标注，总结三圈环流系统
  6. 可随时点击「上一步」回退复习

[技术实现]
- JS 库选择及原因：原生 SVG。理由：本场景为 2D 几何图形和箭头，无需复杂动画库，原生 SVG 轻量且易于控制元素显隐。
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |   [剖面图主体]              [图例框]             |
  |   弧线 + 环流圈              600,80-780,200      |
  |   120,420 - 520,100                              |
  |                                                  |
  |   [纬度标注]                                     |
  |   右侧 520-580 区域                              |
  |                                                  |
  |                                                  |
  |                                                  |
  |              [控件栏]                            |
  |         280,460 - 520,490                        |
  |      [◀上一步] [步骤 X/4] [下一步▶]              |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量 (0-4)，每个状态对应一组可见元素
  2. 元素分组：将元素按步骤分组，每组用 g 元素包裹，通过 display 属性控制显隐
  3. 坐标计算：剖面弧线使用 SVG path 的 A 命令绘制圆弧；环流圈使用 path 绘制带箭头的闭合路径
  4. 事件绑定：按钮点击事件切换 currentState，调用 updateDisplay() 函数更新各元素可见性
  5. 箭头标记：使用 SVG marker 定义箭头样式，应用于环流圈 path
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀（如 scene1-arc-profile、scene1-circulation-low、scene1-pressure-A、scene1-wind-B、scene1-btn-prev、scene1-btn-next）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中
