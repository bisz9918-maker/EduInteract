[分步序列]
- 初始状态（步骤0）：显示完整经纬网框架（7经线+7纬线+4条特殊纬线虚线）+ 经度/纬度标注 + 五个点（A/B/C/D/E）以默认蓝色小圆显示，不显示坐标标签
- 步骤1：点击「下一步」→ A点高亮（圆放大至10px，颜色加深），显示A点坐标标签"A (30°N, 60°W)"于(320,145)
- 步骤2：点击「下一步」→ A点恢复默认，B点高亮（圆放大至10px），显示B点坐标标签"B (60°S, 0°)"于(435,325)
- 步骤3：点击「下一步」→ B点恢复默认，C/D/E三点同时高亮（圆放大至10px），显示C/D/E坐标标签于各自位置
- 步骤4：点击「下一步」→ 所有点恢复默认，显示从B指向A的红色方向箭头，箭头中点附近显示"西北"文字，表示A相对B的方向

- B点坐标标签(435,325)：与B点(420,340)距离约18px，与附近纬线60°S(y=340)垂直距离15px，无冲突
- C点坐标标签(435,205)：与C点(420,220)距离约18px，与附近纬线0°(y=220)垂直距离15px，无冲突

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于(280,455)，80×30px，灰色背景，点击后回退到前一状态
  - 「下一步」按钮：位于(440,455)，80×30px，蓝色背景，点击后进入下一状态
  - 步骤指示器：位于(400,475)，显示当前步骤"步骤 X/4"
- 教师操作流程：
  1. 初始展示完整经纬网，讲解经纬线分布规律
  2. 点击「下一步」高亮A点，讲解如何读取A点坐标（先纬后经）
  3. 点击「下一步」高亮B点，对比A/B两点纬度差异
  4. 点击「下一步」高亮C/D/E，快速回顾剩余点位
  5. 点击「下一步」显示方向箭头，讲解如何判断两点相对方向（A在B的西北方）
  6. 可随时点击「上一步」回退复习

[技术实现]
- JS 库选择：原生 SVG（简单几何图形首选，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  纬度标注  |           经纬网格区域              |
  |   (x=60)   |        (x=80~760, y=40~400)         |
  |            |                                     |
  |  90°N      |-------------------------------------|
  |  60°N      |  D●         ●E                      |
  |  30°N      |     A●                              |
  |   0°       |        C●                           |
  |  30°S      |                                     |
  |  60°S      |           B●                        |
  |  90°S      |-------------------------------------|
  |            |  180° 120° 60°  0°  60° 120° 180°   |
  |            |   W    W   W       E    E    E      |
  +--------------------------------------------------+
  |  [◀上一步]      步骤 X/4      [下一步▶]          |
  |              (y=440~490 控件栏)                  |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-4），数组存储各状态配置
  2. 坐标计算：经线 x = 80 + i * 113.33，纬线 y = 40 + j * 60
  3. 动画曲线：使用 CSS transition 实现平滑高亮过渡（0.3s ease）
  4. 事件绑定：按钮点击事件切换状态，更新 DOM 元素显示/隐藏
  5. 边界处理：步骤0禁用「上一步」，步骤4禁用「下一步」
- ID 命名规范：所有交互元素 ID 以 scene1- 为前缀
  - scene1-grid-group（经纬网组）
  - scene1-point-a/b/c/d/e（五个点）
  - scene1-label-a/b/c/d/e（五个坐标标签）
  - scene1-arrow-ba（方向箭头）
  - scene1-btn-prev/next（上下步按钮）
  - scene1-step-indicator（步骤指示器）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局污染
