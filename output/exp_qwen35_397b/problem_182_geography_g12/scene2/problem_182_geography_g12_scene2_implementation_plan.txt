[图示主题与整合说明]
- 本图示主题：经线上球面距离计算（B→C 飞行路径）
- 整合的步骤/概念：整合了 B 到 C 的经线路径高亮、纬度差标注、距离计算公式展示三个环节

[标签冲突检查]
- 标签"B (60°S, 0°)"：坐标 (395,350)，预计占用 (395,350)-(465,366)
- 标签"C (0°, 0°)"：坐标 (395,210)，预计占用 (395,210)-(455,226)
- 标签"60°"（纬度差）：坐标 (335,285)，预计占用 (335,285)-(365,301)
- 经度标签"0°"：坐标 (375,35)，预计占用 (375,35)-(395,51)
- 纬度标签"0°"：坐标 (35,218)，预计占用 (35,218)-(60,234)
- 纬度标签"60°S"：坐标 (30,338)，预计占用 (30,338)-(65,354)

冲突检查：
- "B (60°S, 0°)"与"60°S"纬度标签：B 标签 x=395，纬度标签 x=30~65，水平距离>300px → 无冲突
- "C (0°, 0°)"与"0°"纬度标签：C 标签 x=395，纬度标签 x=35~60，水平距离>300px → 无冲突
- "60°"纬度差标签与 B→C 路径：标签 x=335~365，路径 x=380，水平距离 15px → 安全（标签在路径左侧）
- "B (60°S, 0°)"与 B→C 路径：标签 x=395，路径 x=380，水平距离 15px → 安全（标签在路径右侧）
- "C (0°, 0°)"与 B→C 路径：标签 x=395，路径 x=380，水平距离 15px → 安全（标签在路径右侧）
- 所有标签与网格线：标签均放置在网格线间隙或外侧 → 无冲突

结论：所有标签间距≥15px，无重叠冲突

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 内底部左侧 (250,455)，点击后回退到上一状态
  - 「下一步」按钮：位于 SVG 内底部右侧 (470,455)，点击后进入下一状态
  - 步骤指示器：显示当前步骤（如「步骤 2/4」），位于两按钮之间
- 教师操作流程：
  1. 初始状态展示经纬网和 B、C 两点位置，让学生识别两点坐标
  2. 点击「下一步」高亮 B→C 路径，强调这是经线上的飞行路线
  3. 点击「下一步」显示纬度差 60°，引导学生读取纬度差
  4. 点击「下一步」显示计算公式，讲解"每度纬度≈111km"的原理
  5. 点击「下一步」显示最终答案，验证计算结果

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库）
- 画布尺寸：800 × 500 px（固定画布）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  经度标签 (180° 120° 60° 0° 60° 120° 180°)       |
  |  +--------------------------------------------+  |
  |  |                                            |  |
  |  |           经纬网 (600×360)                 |  | 计算框
  |  |     B●───────────────●C (路径高亮)         |  | (右侧)
  |  |     |                |                     |  |
  |  |     |    60° 纬度差   |                     |  |
  |  |                                            |  |
  |  +--------------------------------------------+  |
  |                                                  |
  |        [◀上一步]  步骤 2/4  [下一步▶]            |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量 (0-4) 跟踪当前步骤
  2. 元素 ID 命名：所有元素以 scene2- 为前缀（如 scene2-point-b、scene2-path-bc、scene2-calc-box）
  3. 显隐控制：使用 display:none / display:block 或 opacity 切换元素可见性
  4. 按钮状态：第一步禁用「上一步」，最后一步禁用「下一步」或改为「重播」
  5. IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中避免全局污染
- ID 命名规范：
  - scene2-grid：经纬网组
  - scene2-point-b：B 点标记
  - scene2-point-c：C 点标记
  - scene2-label-b：B 点标签
  - scene2-label-c：C 点标签
  - scene2-path-bc：B→C 路径线段
  - scene2-arc-lat：纬度差标注弧
  - scene2-label-lat：纬度差标签
  - scene2-calc-box：计算框
  - scene2-btn-prev：上一步按钮
  - scene2-btn-next：下一步按钮
  - scene2-step-indicator：步骤指示器
