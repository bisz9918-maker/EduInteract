[图示主题与整合说明]
- 本图示主题：昼夜半球划分（A 点 14:00 时的夜半球范围）
- 整合的步骤/概念：整合了晨昏线绘制、夜半球阴影填充、A 点位置标注三个环节

[分步序列]
- 初始状态（步骤 0）：显示完整经纬网（7 条经线 +7 条纬线）、经度纬度标注、A 点标记（蓝色圆点）
- 步骤 1：点击「下一步」→ 显示 A 点标签"A (14:00)"，强调 A 点当前时刻
- 步骤 2：点击「下一步」→ 显示 12:00 经线（30°W，绿色虚线）及标签"12:00 经线 (30°W)"，说明 A 点 14:00 则正午经线在其东侧 30°
- 步骤 3：点击「下一步」→ 绘制晨昏线（红色大圆弧，经过 60°E 和 120°W），显示标签"晨昏线"
- 步骤 4：点击「下一步」→ 填充夜半球阴影（晨昏线西侧区域，灰色 30% 透明），显示标签"夜半球"，完成昼夜半球划分

[标签冲突检查]
- 标签"A (14:00)"：坐标 (295,175)
- 标签"12:00 经线 (30°W)"：坐标 (340,475)
- 标签"晨昏线"：坐标 (580,200)
- 标签"夜半球"：坐标 (150,250)
- 经度标注：y=25，x 分别为 40,160,280,400,520,640,760
- 纬度标注：x=25，y 分别为 40,110,180,250,320,390,460

冲突检查：
- "A (14:00)"与 60°W 经度标注 (x=280,y=25)：垂直距离 150px → 无冲突
- "A (14:00)"与 30°N 纬度标注 (x=25,y=180)：水平距离 270px → 无冲突
- "晨昏线"与 60°E 经线 (x=520)：水平距离 60px → 无冲突
- "夜半球"与 120°W 经线 (x=160)：水平距离 10px → 需调整，将"夜半球"移至 (140,250)
- 所有经度标注间距 120px → 无冲突
- 所有纬度标注间距 70px → 无冲突

解决方案：将"夜半球"标签从 (150,250) 调整为 (140,250)，确保与 120°W 经线有 20px 间距

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 底部左侧 (x=320, y=485)，点击返回上一状态
  - 「下一步」按钮：位于 SVG 底部右侧 (x=460, y=485)，点击进入下一状态
  - 状态指示器：位于两按钮之间 (x=400, y=485)，显示"步骤 X/4"
- 教师操作流程：
  1. 初始展示经纬网和 A 点，让学生定位 A 点坐标
  2. 点击「下一步」显示 A 点时刻 14:00，提问学生此时太阳直射点位置
  3. 点击「下一步」显示 12:00 经线，讲解地方时与经度关系（每 15°差 1 小时）
  4. 点击「下一步」显示晨昏线，说明晨昏线与 12:00 经线垂直
  5. 点击「下一步」显示夜半球，总结昼夜半球范围

[技术实现]
- JS 库选择：原生 SVG（适合绘制经纬网、弧线、多边形等几何元素，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  经度标注 (y=25)                                  |
  |  纬度标注 (x=25)                                   |
  |  +--------------------------------------------+   |
  |  |                                            |   |
  |  |           经纬网 + A 点标记                  |   |
  |  |           12:00 经线（步骤 2 显示）            |   |
  |  |           晨昏线（步骤 3 显示）                |   |
  |  |           夜半球阴影（步骤 4 显示）            |   |
  |  |                                            |   |
  |  +--------------------------------------------+   |
  |                                                    |
  |         [◀上一步]  步骤 X/4  [下一步▶]             |
  |              (y=480~495 控件栏)                    |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用 currentState 变量 (0-4) 跟踪当前步骤，steps 数组存储各步骤应显示的元素 ID 列表
  2. 坐标计算：经度映射 x = 40 + (lon + 180) * (720/360)，纬度映射 y = 40 + (90 - lat) * (420/180)
  3. 晨昏线绘制：使用 SVG <path> 绘制大圆弧，路径为从 (60°E,90°N) 经 (0°,0°) 到 (120°W,90°S) 的弧线
  4. 夜半球填充：使用 SVG <path> 绘制多边形，边界为晨昏线 + 150°E 经线围成的区域
  5. 事件绑定：按钮点击事件更新 currentState，调用 render() 函数显示/隐藏对应元素
  6. 动画过渡：使用 CSS transition 实现阴影淡入效果（opacity 0→1，duration 0.5s）
- ID 命名规范：所有元素 ID 以 scene4- 为前缀，如 scene4-grid、scene4-point-a、scene4-meridian-12、scene4-terminator、scene4-night-shadow
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
