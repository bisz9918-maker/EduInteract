[图示主题与整合说明]
- 本图示主题：地球公转轨道与两分两至节气判断
- 整合的步骤/概念：公转椭圆轨道、四个位置（A/B/C/D）的节气判断、地轴倾斜方向、太阳直射点变化

[分步序列]
- 初始状态（步骤0）：显示椭圆轨道、太阳（带光线）、四个地球轮廓（灰色#9e9e9e透明度50%）、地轴虚线（灰色）、位置标签A/B/C/D。不显示节气标签和直射点。
- 步骤1（点击「下一步」或「春分」）：地球A高亮（#2e7d32填充透明度20%），显示直射点A（赤道位置），显示节气标签"春分"（绿色#2e7d32），其他地球恢复灰色半透明。底部步骤指示显示"步骤1/5"。
- 步骤2（点击「下一步」或「夏至」）：地球B高亮，显示直射点B（北回归线位置），显示节气标签"夏至"，其他地球恢复灰色半透明。步骤指示"步骤2/5"。
- 步骤3（点击「下一步」或「秋分」）：地球C高亮，显示直射点C（赤道位置），显示节气标签"秋分"，其他地球恢复灰色半透明。步骤指示"步骤3/5"。
- 步骤4（点击「下一步」或「冬至」）：地球D高亮，显示直射点D（南回归线位置），显示节气标签"冬至"，其他地球恢复灰色半透明。步骤指示"步骤4/5"。
- 步骤5（点击「下一步」或「总结」）：四个地球同时显示（正常颜色#1565c0），所有直射点可见，所有节气标签可见。添加总结文本框（可选）："地轴倾斜方向保持不变，直射点在南北回归线间移动"。步骤指示"步骤5/5"。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶ + 步骤快捷按钮1-5）
- 控件说明：
  - 「上一步」按钮：位于(50,460)，返回上一状态，步骤0时禁用
  - 「下一步」按钮：位于(150,460)，进入下一状态，步骤5时禁用
  - 「春分/1」按钮：位于(300,460)，直接跳转步骤1
  - 「夏至/2」按钮：位于(380,460)，直接跳转步骤2
  - 「秋分/3」按钮：位于(460,460)，直接跳转步骤3
  - 「冬至/4」按钮：位于(540,460)，直接跳转步骤4
  - 「总结/5」按钮：位于(620,460)，跳转步骤5
  - 步骤指示文本：位于(400,430)，显示当前步骤进度
- 教师操作流程：
  1. 初始展示基础轨道和四个位置，介绍公转轨道概念
  2. 点击「下一步」或「春分」，讲解A位置春分特征（直射赤道）
  3. 点击「下一步」或「夏至」，讲解B位置夏至特征（直射北回归线）
  4. 点击「下一步」或「秋分」，讲解C位置秋分特征（直射赤道）
  5. 点击「下一步」或「冬至」，讲解D位置冬至特征（直射南回归线）
  6. 点击「总结」，综合回顾地轴倾斜方向不变、直射点移动规律
  7. 可随时点击「上一步」回退复习，或点击步骤按钮直接跳转

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript。理由：几何图形简单（椭圆、圆形、线段），无需复杂库；原生实现轻量、加载快、易于多场景合并。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                    春分                           |
  |                      A                            |
  |                    (地球)                         |
  |                                                   |
  |     夏至              太阳              冬至      |
  |       B            (右侧)              D          |
  |     (地球)          ☀️                (地球)      |
  |                                                   |
  |                      C                            |
  |                    秋分                           |
  |                  (地球)                           |
  |                                                   |
  |              步骤指示：步骤X/5                    |
  +--------------------------------------------------+
  | [上一步][下一步] [1][2][3][4][5]  <- 控件栏 y=445~490 |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-5) 跟踪当前状态，steps 数组定义每步显示的元素ID列表
  2. 坐标计算：椭圆轨道参数方程 x=380+280*cos(θ), y=250+120*sin(θ)，四个位置θ分别为-90°(A)、180°(B)、90°(C)、0°(D)
  3. 地轴倾斜：所有地轴保持相同倾斜角度（与垂直方向夹角23.5°，即与水平方向夹角66.5°），使用 transform="rotate(23.5, cx, cy)"
  4. 直射点位置：根据节气计算纬度偏移，春分/秋分在赤道(y=地球cy)，夏至在北回归线(y=地球cy-8)，冬至在南回归线(y=地球cy+8)
  5. 事件绑定：每个按钮绑定 click 事件，调用 updateStep() 函数更新显示状态
  6. 高亮效果：通过切换 circle 的 fill-opacity 和 fill 属性实现
  7. 按钮禁用状态：步骤0时禁用「上一步」，步骤5时禁用「下一步」，使用 opacity=0.5 视觉提示
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀
  - scene1-orbit-ellipse（椭圆轨道）
  - scene1-sun-circle（太阳）
  - scene1-sun-rays（太阳光线组）
  - scene1-earth-a/b/c/d（四个地球）
  - scene1-axis-a/b/c/d（四个地轴）
  - scene1-direct-a/b/c/d（四个直射点）
  - scene1-label-a/b/c/d（位置标签）
  - scene1-season-a/b/c/d（节气标签）
  - scene1-highlight-a/b/c/d（高亮区域）
  - scene1-btn-prev/next（上一步/下一步按钮）
  - scene1-btn-step1/2/3/4/5（步骤快捷按钮）
  - scene1-step-indicator（步骤指示文本）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
- 状态数据结构示例：
  ```javascript
  const stepConfig = {
    0: { show: ['orbit', 'sun', 'earth-a','earth-b','earth-c','earth-d'], highlight: null },
    1: { show: ['orbit','sun','earth-a','axis-a','direct-a','label-a','season-a'], highlight: 'a' },
    2: { show: ['orbit','sun','earth-b','axis-b','direct-b','label-b','season-b'], highlight: 'b' },
    3: { show: ['orbit','sun','earth-c','axis-c','direct-c','label-c','season-c'], highlight: 'c' },
    4: { show: ['orbit','sun','earth-d','axis-d','direct-d','label-d','season-d'], highlight: 'd' },
    5: { show: 'all', highlight: null }
  };
  ```
