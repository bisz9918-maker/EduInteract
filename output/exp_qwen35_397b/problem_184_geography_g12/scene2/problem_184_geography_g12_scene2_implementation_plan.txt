[图示主题与整合说明]
- 本图示主题：日照图综合分析（晨昏线、直射点、时间计算、线速度比较）
- 整合的步骤/概念：
  1. 极地俯视图判读（北极为中心，逆时针自转）
  2. 晨昏线识别（昼夜分界线）
  3. 极昼现象与日期判断
  4. 太阳直射点坐标确定
  5. 地方时/北京时间计算
  6. 昼夜长短与正午太阳高度
  7. 自转线速度纬度分布规律
- 教学价值：教师可逐步引导学生从图形判读到定量计算，层层递进理解日照图的综合应用，适合课堂讲解地球运动相关知识点

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（圆、线段、箭头），无需复杂库；原生实现轻量、加载快
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │  [日照图主体]                    │  [信息面板]              │
  │       北极点                      │  综合分析                │
  │         ╭───╮                    │  ┌──────────────────┐   │
  │      ╭──┤ E ├──╮                 │  │ 步骤X：标题       │   │
  │    ╭─┤  F   │  ├─╮ 太阳光线→→→   │  │ 详细内容...       │   │
  │   │  │   ○  │  │                 │  │                   │   │
  │   │  │  G●  │  │                 │  │                   │   │
  │    ╰─┤      │  ├─╯               │  │                   │   │
  │      ╰───┬───╯                   │  │ [线速度比较条]    │   │
  │          │ 晨昏线                 │  │ G ████████        │   │
  │         夜│昼                     │  │ F ██████░░        │   │
  │          │                       │  │ E ████░░░░        │   │
  │         ╰─╯自转                  │  └──────────────────┘   │
  │                                  │                         │
  │  ┌─────────────────────────┐     │                         │
  │  │  ◀上一步  步骤X/6  下一步▶  │     │                         │
  │  └─────────────────────────┘     │                         │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量（0-6），steps 数组存储每步配置
  2. 坐标计算：所有元素使用绝对坐标，圆心(260,250)为基准
  3. 动画曲线：使用 CSS transition 实现平滑过渡（opacity、stroke-width）
  4. 事件绑定：按钮点击事件绑定到 updateStep() 函数
  5. 高亮效果：通过修改 stroke-width 和 stroke 颜色实现
  6. 闪烁动画：使用 CSS @keyframes 实现 pulsing 效果
- ID 命名规范：所有交互元素 ID 以 scene2- 为前缀
  - scene2-circle-equator（赤道圆）
  - scene2-circle-tropic（北回归线）
  - scene2-circle-arctic（北极圈）
  - scene2-line-terminator（晨昏线）
  - scene2-point-e / scene2-point-f / scene2-point-g
  - scene2-point-subsolar（直射点）
  - scene2-label-*（所有标签）
  - scene2-info-panel（信息面板）
  - scene2-btn-prev / scene2-btn-next（按钮）
  - scene2-step-indicator（步骤指示器）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
- 多场景合并兼容：使用 getElementById 精确选择，不使用全局 class 选择器
