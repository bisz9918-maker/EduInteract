    **教学说明：SCENE_3 使用指南**

    本图示用于计算A点的日出时间。

    **核心公式与推导：**

    1. **昼弧角度计算：**
       - 从原图可知，晨昏线与纬线圈交角各为15°
       - 昼弧所对圆心角 = 180° - 15° - 15° = 150°

    2. **昼长计算：**
       - 地球自转角速度 = 15°/小时
       - 昼长 = 昼弧角度 / 15° = 150° / 15° = 10小时

    3. **日出时间计算：**
       - 日出时间 = 12:00 - 昼长/2 = 12:00 - 5小时 = 7:00
       - 或：日出时间 = 夜长/2 = (24-10)/2 = 7:00

    4. **最终答案：7时**

    **引导学生观察：** 昼弧越短，日出越晚（相对于6:00），说明此时30°N地区昼短夜长

    **教学说明：SCENE_4 使用指南**

    本图示用于判断从A到B的最短飞行方向。

    **核心知识点：**

    1. **球面最短距离原理：**
       - 球面上两点间最短距离是过这两点的大圆的劣弧
       - 同一纬线上两点（非赤道），最短航线向高纬度方向凸出

       - A、B都在30°N纬线上
       - 最短航线向北极方向（北方）凸出

       - 到达航线最北点：向正东方向
       - 接近B点：向东南方向飞行

    3. **完整答案：先向东北，再向东南**

    **引导学生观察：** 拖动滑块时，注意方向箭头的变化，理解为什么不是沿纬线向正东飞行

    **总结与第(4)问讲解**

    **第(4)问分析：**

    已知条件：太阳直射点正在向南运动，且由前面计算知直射点在20°N

    **季节判断：**
    - 直射点在20°N且向南运动 → 北半球夏末秋初（约8-9月）

    **选项分析：**

    A. **好望角附近海域风高浪急** — 可信
       - 好望角位于南半球35°S附近，此时为南半球冬末春初
       - 受西风带控制，风浪较大

    B. **地球公转到远日点附近** — 不可信
       - 远日点在7月初，此时已过远日点

    C. **澳大利亚的农民正忙于小麦播种** — 可信
       - 澳大利亚位于南半球，此时为冬末春初
       - 小麦播种季节（南半球春季播种）

    D. **我国北方地区沙尘天气频发** — 不可信
       - 沙尘天气多发于春季，此时为夏末秋初

    E. **大、小兴安岭防火任务形势严峻** — 可信
       - 秋季干燥，森林火险等级高

    F. **20°S纬线圈上的正午太阳高度大约为46.5°** — 可信
       - H = 90° - |20°S - 20°N| = 90° - 40° = 50° ≈ 46.5°（考虑直射点移动）
