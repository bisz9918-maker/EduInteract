[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 内底部左侧 (x=320, y=460)，点击后返回上一状态
  - 「下一步」按钮：位于 SVG 内底部右侧 (x=460, y=460)，点击后进入下一状态
  - 状态指示器：位于两按钮之间 (x=400, y=460)，显示"步骤 X/4"
- 教师操作流程：
  1. 初始状态仅显示纬线圈和经线，教师介绍基础坐标系
  2. 点击「下一步」添加晨昏线，讲解晨昏线概念
  3. 点击「下一步」标注 A、B 交点及 15°夹角，讲解交点确定方法
  4. 点击「下一步」显示经度标注，完成完整图示讲解
  5. 可随时点击「上一步」回退复习关键概念

[技术实现]
- JS 库选择及原因：原生 SVG
  - 原因：本图示为简单几何图形（圆形、线段、弧线、点），原生 SVG 足够胜任，无需引入额外库
  - 优势：代码轻量、易于控制每个元素的显示/隐藏、支持精确坐标定位
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：

- 关键实现要点：
  1. 状态机设计：使用 currentState 变量 (0-3) 跟踪当前步骤，steps 数组存储每步应显示的元素 ID 列表
  2. 坐标计算：晨昏线端点通过三角函数计算，角度 15° 转换为弧度 Math.PI/12
  3. 动画曲线：元素出现使用淡入效果 (opacity 0→1, 300ms ease-out)
  4. 事件绑定：按钮点击事件绑定到 updateDisplay() 函数，根据 currentState 更新元素可见性
  5. 边界处理：第一步禁用「上一步」，最后一步禁用「下一步」
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀
  - scene1-circle-30n（纬线圈）
  - scene1-meridian-vertical（垂直经线）
  - scene1-meridian-horizontal（水平经线）
  - scene1-terminator（晨昏线）
  - scene1-point-a（A 点）
  - scene1-point-b（B 点）
  - scene1-arc-15-left（左侧 15°角弧）
  - scene1-arc-15-right（右侧 15°角弧）
  - scene1-label-45e、scene1-label-45w、scene1-label-a、scene1-label-b
  - scene1-label-15-left、scene1-label-15-right、scene1-label-30n
  - scene1-btn-prev、scene1-btn-next、scene1-step-indicator
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
