- 步骤 3：点击「下一步」→ 直射点红色实心圆出现在 (80,250)，"太阳直射点"标签出现在 (70,230)，右侧显示"由原图可知：直射点经度 = 45°E"
- 步骤 4：点击「下一步」→ 右侧底部显示最终结论"(20°N, 45°E)"，加粗红色显示，所有元素完整呈现

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - scene2-btn-prev：上一步按钮，位于 (280,455)，宽 100px，初始禁用（步骤 0 时）
  - scene2-btn-next：下一步按钮，位于 (420,455)，宽 100px
  - scene2-step-indicator：步骤指示器，位于 (380,485)，显示"步骤 X/4"
- 教师操作流程：
  1. 初始展示侧视地球与晨昏线相切状态，讲解题目条件
  2. 点击「下一步」展示切点与 20°夹角，讲解"切点纬度与直射点纬度互余"
  3. 点击「下一步」展示纬度推导公式和太阳光线，强化理解
  4. 点击「下一步」展示直射点位置和经度来源（结合原图 45°E）
  5. 点击「下一步」展示最终坐标结论，完成推导

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript。原因：几何图形简单（圆形、线段、箭头），无需复杂库；原生实现轻量且易于多场景合并
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |   [侧视地球]              [推导公式与结论]        |
  |      地球                  90°-70°=20°           |
  |    晨昏线\                 20°N                  |
  |           \                45°E                  |
  |            \               (20°N, 45°E)          |
  |                                                  |
  |                                                  |
  |                                                  |
  |              [控件栏 y=440-490]                  |
  |           [◀上一步]  步骤 X/4  [下一步▶]         |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用 scene2CurrentStep 变量（0-4）跟踪当前步骤，每个步骤对应一组可见元素
  2. 元素可见性：所有元素预先创建，用 display/opacity 控制显示，步骤切换时更新
  3. 动画效果：步骤切换时新增元素用 fade-in 动画（CSS transition: opacity 0.3s）
  4. 按钮状态：步骤 0 时禁用"上一步"，步骤 4 时"下一步"文字改为"完成"并禁用
  5. 事件绑定：按钮点击事件绑定到 scene2-btn-prev 和 scene2-btn-next
- ID 命名规范：所有元素 ID 以 scene2- 为前缀，如 scene2-earth、scene2-morning-line、scene2-sun-ray-1、scene2-label-70deg 等
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
