- 步骤 2：点击「下一步」→ 在计算区显示第一行："昼弧角度 = 180° - 15° - 15° = 150°"，同时 180°、15°、15° 数字高亮（对应图中平角和两个夹角）。
- 步骤 3：点击「下一步」→ 在计算区追加第二行："昼长 = 150° ÷ 15°/小时 = 10 小时"，150°和 10 高亮。
- 步骤 4：点击「下一步」→ 在计算区追加第三行："日出时间 = 12 - 10/2 = 7 时"，最终结果"7 时"用红色加粗显示。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于(280,460)，宽 100px，点击回退到前一状态
  - 「下一步」按钮：位于(420,460)，宽 100px，点击进入下一状态
  - 状态指示器：位于(520,465)，显示"步骤 X/4"
- 教师操作流程：
  1. 初始展示纬线圈和 A、B 点位置，让学生识别晨昏线交点
  2. 点击「下一步」高亮昼弧，引导学生观察昼弧对应的圆心角
  3. 点击「下一步」显示角度计算，讲解 180°-15°-15°的推导
  4. 点击「下一步」显示昼长计算，强调 15°/小时的换算关系
  5. 点击「下一步」显示日出时间公式，完成完整推导链

[技术实现]
- JS 库选择：原生 SVG（几何图形简单，无需额外库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +------------------------------------------+
  |              45°E                        |
  |               |                          |
  |          A ___|___ B    150°            |
  |           /   |   \                      |
  |      15° /    |    \ 15°                 |
  |---------O----45°W------------------------|
  |           \   |   /                      |
  |            \  |  /                       |
  |             \ | /                        |
  |              \|/                         |
  |                                        |
  |     昼弧角度 = 180° - 15° - 15° = 150°  |
  |     昼长 = 150° ÷ 15°/小时 = 10 小时    |
  |     日出时间 = 12 - 10/2 = 7 时         |
  |                                        |
  |      [◀上一步]  [下一步▶]  步骤 X/4     |
  +------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用 currentState 变量(0-4)跟踪步骤，steps 数组存储每步的可见元素配置
  2. 圆弧绘制：使用 SVG path 的 A 命令绘制昼弧和夜弧，昼弧用绿色 stroke-width=4，夜弧用灰色虚线
  3. 坐标计算：A 点角度 195°(180°+15°)，B 点角度 345°(360°-15°)，用 cos/sin 计算像素坐标
  4. 动画过渡：元素显示/隐藏使用 opacity 过渡(0.3s)，高亮使用 stroke-width 变化
  5. 事件绑定：按钮点击事件更新 currentState，调用 renderStep() 刷新视图
- ID 命名规范：所有元素 ID 以 scene3- 为前缀
  - scene3-circle, scene3-meridian-v, scene3-meridian-h
  - scene3-point-a, scene3-point-b
  - scene3-line-oa, scene3-line-ob
  - scene3-arc-day, scene3-arc-night
  - scene3-label-a, scene3-label-b, scene3-label-150
  - scene3-angle-15-left, scene3-angle-15-right
  - scene3-calc-text1, scene3-calc-text2, scene3-calc-text3
  - scene3-btn-prev, scene3-btn-next, scene3-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
