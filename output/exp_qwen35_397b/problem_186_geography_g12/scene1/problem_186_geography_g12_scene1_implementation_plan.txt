[图示主题与整合说明]
- 本图示主题：地球赤道面与黄道面的空间关系及黄赤交角
- 整合的内容：地球自转轴、赤道平面、公转轨道平面（黄道面）、黄赤交角（23°26'）
- 教学价值：教师可通过分步展示，帮助学生理解地球自转产生赤道面、公转产生黄道面，两平面不重合形成黄赤交角这一核心概念。逐步揭示空间关系，符合从具体到抽象的认知规律。

[分步序列]
- 初始状态（步骤0）：显示地球球体（圆心350,280 r=70）和自转轴（线段290,160-410,400），标题显示。等待教师触发下一步。
- 步骤1：点击「下一步」→ 淡入显示赤道平面（半透明蓝色平行四边形），同时显示标签"赤道平面"(180,240)。自转轴高亮（线宽从3px变为5px）。
- 步骤2：点击「下一步」→ 淡入显示黄道面（半透明橙色平行四边形），同时显示标签"黄道面"(520,320)。赤道平面边框高亮。
- 步骤3：点击「下一步」→ 显示黄赤交角弧线（红色圆弧，圆心350,280 r=90，角度0°到23.5°），显示数值标签"23°26'"(450,260)，显示标签"自转轴"(420,170)。两平面交角区域轻微脉冲动画强调。

[标签冲突检查]
- 标签"自转轴"：坐标(420,170)
- 标签"赤道平面"：坐标(180,240)
- 标签"黄道面"：坐标(520,320)
- 标签"23°26'"：坐标(450,260)
- 标题：坐标(400,40)

冲突检查：
- "自转轴"(420,170) 与 "23°26'"(450,260)：水平距离30px，垂直距离90px，斜距≈95px → 无冲突
- "赤道平面"(180,240) 与 "黄道面"(520,320)：水平距离340px → 无冲突
- "23°26'"(450,260) 与 地球球体边缘(350+70=420,280)：距离约50px → 无冲突
- 所有标签均位于图形元素外侧空白区域 → 无重叠风险

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 底部左侧 (x=350, y=460)，点击回退到前一状态
  - 「下一步」按钮：位于 SVG 底部右侧 (x=450, y=460)，点击进入下一状态
  - 步骤指示器：位于两按钮之间 (x=400, y=460)，显示"步骤 X/4"
- 教师操作流程：
  1. 初始状态展示地球和自转轴，讲解地球自转概念
  2. 点击「下一步」显示赤道平面，讲解赤道面定义（垂直于自转轴）
  3. 点击「下一步」显示黄道面，讲解地球公转轨道平面
  4. 点击「下一步」显示黄赤交角，强调23°26'这一关键数值及其地理意义

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（圆形、线段、平行四边形、圆弧），原生 SVG 足够胜任，无需引入重型库
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [800×500 画布]
  +--------------------------------------------------+
  |            标题：地球赤道面与黄道面关系           | y=40
  |                                                  |
  |                    自转轴标签                     | y=170
  |              /                                   |
  |             /   地球●                            | y=280
  |            /   赤道平面═══黄道面                 |
  |           /         \  23°26'                    |
  |                                                  |
  |                                                  |
  |                                                  |
  |                                                  |
  |              [◀上一步] 步骤X/4 [下一步▶]          | y=460
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentState (0-3) 跟踪当前步骤，数组存储每步需显示的元素 ID 列表
  2. 坐标计算：赤道平面需旋转使法线与自转轴平行；黄道面保持水平；交角弧线起点沿黄道面方向，终点沿赤道面方向
  3. 动画曲线：元素淡入使用 CSS transition opacity 0.5s ease-out
  4. 事件绑定：按钮点击事件绑定到 updateState() 函数，更新显示元素并刷新步骤指示器
  5. 自转轴倾斜角计算：atan2(400-160, 410-290) ≈ 63.4°（与水平夹角），赤道面需垂直于此角度
- ID 命名规范：所有元素 ID 以 scene1- 为前缀
  - scene1-earth（地球球体）
  - scene1-axis（自转轴）
  - scene1-equator-plane（赤道平面）
  - scene1-ecliptic-plane（黄道面）
  - scene1-angle-arc（黄赤交角弧线）
  - scene1-label-axis（自转轴标签）
  - scene1-label-equator（赤道平面标签）
  - scene1-label-ecliptic（黄道面标签）
  - scene1-label-angle（黄赤交角数值）
  - scene1-title（标题）
  - scene1-btn-prev（上一步按钮）
  - scene1-btn-next（下一步按钮）
  - scene1-step-indicator（步骤指示器）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
