[分步序列]
- 步骤 0（初始状态）：显示完整流程图框架，所有 10 个流程框和 10 个箭头，填空位置显示灰色下划线"____"，无答案文字
- 步骤 1：显示"赤道"（填空 1）和"黄道"（填空 2）答案文字，蓝色#1565c0 加粗；同时"赤道平面框"和"黄道平面框"边框变为#2e7d32 加粗高亮
- 步骤 2：显示"黄赤"（填空 3）答案文字；"黄赤交角框"边框#2e7d32 加粗高亮；步骤 1 的答案保持显示但边框恢复黑色
- 步骤 3：显示"正午太阳高度"（填空 4）和"昼夜长短"（填空 5）答案文字；"正午太阳高度框"和"昼夜长短框"边框#2e7d32 加粗高亮
- 步骤 4：显示"季节"（填空 6）答案文字；"季节变化框"边框#2e7d32 加粗高亮
- 步骤 5（最终状态）：所有答案保持显示，所有流程框边框恢复黑色，所有答案文字统一高亮显示（#1565c0 加粗），表示完整流程图完成

[标签冲突检查]
所有文字标签均位于矩形框内部居中，框与框之间垂直间距 15px，水平间距充足：
- 第 1 层：自转 (260,20) 与公转 (460,20) 水平间距 120px → 无冲突
- 第 2 层：赤道平面 (210,70) 与黄道平面 (450,70) 水平间距 100px → 无冲突
- 第 3-8 层：均为单框居中，垂直间距 50px → 无冲突
- 框内文字居中，与边框距离≥15px → 无冲突
- 箭头位于框间空白区域，不与文字重叠 → 无冲突

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - "上一步"按钮：位于 (280,460)，宽 80px，高 35px，点击回退到前一状态
  - "下一步"按钮：位于 (440,460)，宽 80px，高 35px，点击进入下一状态
  - 步骤指示器：位于 (380,465)，显示"步骤 X/5"
- 教师操作流程：
  1. 加载后显示步骤 0（空白流程图），提问学生"自转产生什么平面？"
  2. 点击"下一步"显示步骤 1（赤道、黄道），讲解两个平面概念
  3. 点击"下一步"显示步骤 2（黄赤交角），讲解交角形成
  4. 点击"下一步"显示步骤 3（正午太阳高度、昼夜长短），讲解地理效应
  5. 点击"下一步"显示步骤 4（季节变化），讲解季节形成
  6. 点击"下一步"显示步骤 5（完整图），总结四季形成完整因果链
  7. 可随时点击"上一步"回退复习关键节点

[技术实现]
- JS 库选择：原生 SVG（流程图结构简单，无需额外库）
- 画布尺寸：800×500 px
- 布局草图：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────┐
  │   [自转]           [公转]          │ y=20
  │     ↓                ↓             │
  │  [赤道平面]      [黄道平面]        │ y=70
  │       ↘            ↙               │
  │        [黄赤交角]                  │ y=120
  │            ↓                       │
  │      [直射点回归]                  │ y=170
  │            ↓                       │
  │   [正午太阳高度] [昼夜长短]        │ y=220
  │            ↘     ↙                 │
  │      [地面受热多少变化]            │ y=270
  │            ↓                       │
  │        [季节变化]                  │ y=320
  │            ↓                       │
  │        [四季交替]                  │ y=370
  │                                    │
  │     [◀上一步]  步骤 X/5  [下一步▶] │ y=450-490
  └─────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-5) 跟踪当前步骤
  2. 每个填空答案元素用独立 ID：scene3-answer1 至 scene3-answer6
  3. 每个流程框用独立 ID：scene3-box1 至 scene3-box10
  4. 步骤切换函数 updateStep() 根据 currentStep 显示/隐藏对应答案，更新高亮框
  5. 按钮事件绑定：上一步（currentStep--，最小 0），下一步（currentStep++，最大 5）
  6. 步骤指示器同步更新文本
  7. 所有 JS 包在 IIFE 中：(function() { ... })()
- ID 命名规范：
  - 流程框：scene3-box1（自转）, scene3-box2（公转）, scene3-box3（赤道平面）, scene3-box4（黄道平面）, scene3-box5（黄赤交角）, scene3-box6（直射点回归）, scene3-box7（正午太阳高度）, scene3-box8（昼夜长短）, scene3-box9（地面受热）, scene3-box10（季节变化）, scene3-box11（四季交替）
  - 答案：scene3-answer1（赤道）, scene3-answer2（黄道）, scene3-answer3（黄赤）, scene3-answer4（正午太阳高度）, scene3-answer5（昼夜长短）, scene3-answer6（季节）
  - 按钮：scene3-prev-btn, scene3-next-btn, scene3-step-indicator
  - 箭头：scene3-arrow1 至 scene3-arrow10
