    **题目原文：**

    下图为北半球四地点在6月22日不同时刻测到的当地太阳位于正南方时的太阳能热水器倾角示意图。

    （1）该日四地点中正午太阳高度由大到小的排序是________，该日四地点中昼长时间由长到短的排序是________。

    （2）②地的地理坐标是________，④地在①地________方向。

    （3）若①地在大陆上，其附近的著名工业基地是________工业基地，若④地为陆地，其附近的著名工业基地是________。

    （4）③国附近的著名渔场是________渔场，该国的气候深受________洋流影响。

    **题目分析：**

    本题综合考查正午太阳高度角、地方时计算、昼夜长短、地理坐标定位等知识点。核心关系：太阳能热水器倾角α = 90° - 正午太阳高度角H。

    6月22日为夏至日，太阳直射北回归线（23°26'N）。北半球纬度越高，正午太阳高度角越小（直射点以北地区），昼长越长。

    **整体讲解思路：**

    1. 首先理解太阳能热水器倾角与正午太阳高度角的互余关系
    2. 根据倾角计算四地正午太阳高度角，进而推算纬度
    3. 根据地方时与世界时的时差计算经度
    4. 综合经纬度定位四地位置，判断相对方位和附近地理事物

    **图示规划说明：**

    **教学说明：**

    本图示用于建立核心概念：太阳能热水器为了获得最大太阳辐射，其集热板应与太阳光线垂直。因此热水器倾角α与正午太阳高度角H互余。

    **讲解要点：**

    1. 太阳能热水器工作原理：集热板与太阳光线垂直时，单位面积接收的太阳辐射最多
    2. 正午太阳高度角H：正午时太阳光线与地平面的夹角
    3. 几何关系：热水器倾角α + 正午太阳高度角H = 90°（因为集热板与太阳光线垂直）
    4. 计算公式：α = 90° - H 或 H = 90° - α

    **引导学生观察：**

    - 注意图中直角符号的位置，理解为什么α+H=90°
    - 倾角越大，说明正午太阳高度角越小，该地纬度越高（直射点以北地区）

    **教学说明：**

    本图示用于推导四地纬度和昼夜长短排序，是解题的核心计算环节。

    **计算过程：**

    1. 正午太阳高度角计算（H = 90° - α）：
       - H_A = 90° - 6°34' = 83°26'
       - H_B = 90° - 26°34' = 63°26'
       - H_C = 90° - 28°34' = 61°26'
       - H_D = 90° - 13°34' = 76°26'

    2. 正午太阳高度由大到小排序：A > D > B > C

    3. 纬度推算（夏至日太阳直射23°26'N，H = 90° - |φ - 23°26'|）：
       - φ_A = 23°26' - (90° - 83°26') = 13°N（直射点以南）
       - φ_B = 23°26' + (90° - 63°26') = 37°N
       - φ_C = 23°26' + (90° - 61°26') = 39°N
       - φ_D = 23°26' + (90° - 76°26') = 37°N

    4. 夏至日北半球昼夜长短规律：纬度越高，昼越长
       - 昼长排序（由长到短）：C > B≈D > A

    **关键公式：**

    正午太阳高度角公式：H = 90° - |φ - δ|

    其中φ为当地纬度，δ为太阳直射点纬度（夏至日δ = 23°26'N）

    **教学说明：**

    本图示用于计算四地经度，完成地理坐标定位。

    **核心概念：**

    1. 地方时：当地太阳位于正南方时的时刻为地方时12时
    2. 世界时：0°经线（本初子午线）的地方时
    3. 时差与经度关系：经度每差15°，地方时相差1小时

    **计算过程：**

    | 地点 | 世界时 | 地方时 | 时差 | 经度 |
    |------|--------|--------|------|------|
    | A | 4时 | 12时 | +8h | 120°E |
    | B | 8时 | 12时 | +4h | 60°E |
    | C | 12时 | 12时 | 0h | 0° |
    | D | 24时(0时) | 12时 | -12h | 180° |

    **时差计算：** 时差 = 地方时12时 - 世界时

    **经度换算：** 经度 = 时差 × 15°/小时（东正西负）

    **四地完整坐标：**
    - A(①)：13°N, 120°E — 中国东南沿海（珠三角附近）
    - B(②)：37°N, 60°E — 中亚地区
    - C(③)：39°N, 0° — 欧洲西部（西班牙/法国附近）
    - D(④)：37°N, 180° — 太平洋/美国西海岸附近

    **相对方位判断：** ④在①的东北方向（纬度更高，经度更东）
    </TEXT_4>

    **（1）正午太阳高度由大到小排序：** A > D > B > C

    **（2）②地（B地）地理坐标：** 37°N, 60°E

    **④地在①地方向：** 东北方向

    **（3）①地附近工业基地：** 珠江三角洲工业基地
