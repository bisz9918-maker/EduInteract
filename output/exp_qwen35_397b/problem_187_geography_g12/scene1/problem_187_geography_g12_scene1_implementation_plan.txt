[图示主题与整合说明]
- 本图示主题：太阳能热水器倾角与正午太阳高度角的互余关系

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 上一步按钮：位于(250,460)，点击后返回上一状态，步骤0时禁用
  - 下一步按钮：位于(400,460)，点击后进入下一状态，步骤3时禁用
  - 步骤指示器：位于(520,465)，显示当前步骤"步骤X/4"
- 教师操作流程：
  1. 初始展示热水器基本结构，讲解倾角α定义
  2. 点击下一步，展示太阳光线，讲解正午太阳高度角H定义
  3. 点击下一步，展示直角关系，引导学生发现α+H=90°
  4. 点击下一步，展示公式，总结互余关系

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript。理由：几何图形简单，无需复杂库；SVG 便于精确控制坐标和动画；原生 JS 足够实现分步状态切换
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |   [热水器示意图]           [公式框]              |
  |   地面线 y=350            α+H=90°               |
  |   热水器倾斜-25°          α=90°-H               |
  |                                                  |
  |                                                  |
  |                                                  |
  |              [控件栏 y=460-490]                  |
  |           [◀上一步] [下一步▶]  步骤X/4           |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-3) 跟踪当前步骤
  2. 元素分组：将各步骤元素放入不同<g>组，用 display 控制显示/隐藏
  3. 按钮状态：步骤0时禁用上一步，步骤3时禁用下一步（opacity+pointer-events）
  4. 动画效果：元素出现时使用淡入动画（opacity 0→1，duration 300ms）
  5. 坐标计算：热水器面板旋转中心为(140,340)，旋转角度-25°模拟典型倾角
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀
  - scene1-ground-line（地面线）
  - scene1-solar-panel（热水器面板）
  - scene1-solar-rays（太阳光线组）
  - scene1-angle-alpha（α角度弧线）
  - scene1-angle-h（H角度弧线）
  - scene1-right-angle（直角标记）
  - scene1-formula-box（公式框）
  - scene1-btn-prev（上一步按钮）
  - scene1-btn-next（下一步按钮）
  - scene1-step-indicator（步骤指示器）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
