[图示主题与整合说明]
- 本图示主题：四地纬度计算与昼夜长短排序
- 整合的步骤/概念：四地倾角数据→正午太阳高度角计算(H=90°-α)→纬度推算(H=90°-|φ-23°26'|)→夏至日昼夜长短规律→昼长排序结论

[技术实现]
- JS 库选择：原生 SVG（几何图形简单，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  ┌────────────────────────────────────────┐
  │  标题：四地纬度计算与昼夜长短          │ y=20-40
  ├────────────────────────────────────────┤
  │  ┌─────┬─────┬─────┬─────┐            │ y=50-140
  │  │  A  │  B  │  C  │  D  │  数据表格  │
  │  │α=6° │α=26°│α=28°│α=13°│            │
  │  │H=83°│H=63°│H=61°│H=76°│            │
  │  └─────┴─────┴─────┴─────┘            │
  ├────────────────────────────────────────┤
  │  纬度示意图（赤道、回归线、四地位置点） │ y=180-320
  │  0° ─────────────────────────────      │
  │  23°26'N ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─      │
  │  ·A(13°N)  ·B(37°N)  ·C(39°N)  ·D(37°N)│
  ├────────────────────────────────────────┤
  │  昼弧示意：[A][B ][C  ][D ]            │ y=360-380
  │  结论框：昼长排序 C>B=D>A              │ y=400-430
  ├────────────────────────────────────────┤
  │        [◀上一步]    [下一步▶]          │ y=440-490
  └────────────────────────────────────────┘
  ```
- 关键实现要点：
  - 状态机：currentState (0-4)，数组存储每步可见元素ID列表
  - 坐标计算：纬度位置y坐标 = 200 + (纬度值/45)×110（线性映射）
  - 动画曲线：元素淡入使用opacity过渡，duration 300ms
  - 事件绑定：按钮点击事件切换状态，更新可见性
- ID 命名规范：所有元素ID以 scene2- 为前缀（如 scene2-table-A、scene2-point-A、scene2-label-phi-A）
- IIFE 隔离：所有JS代码包在 (function() { ... })() 中，避免全局污染
