[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript。原因：本图示为静态几何图形+简单高亮动画，无需复杂库；SVG 便于精确控制坐标和样式，适合地理图示
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +----------------------------------------------------------+
  | [移动方向标题：太阳直射点移动方向：F→E→D→C→B→A] (y=30)   |
  |                                                          |
  |    [东半球]              [西半球]                        |
  |     圆形r=140            圆形r=140                       |
  |    中心(200,250)        中心(600,250)                    |
  |     A·B·C·              ·D·E·F·                          |
  |                                                          |
  |   [东半球标签]          [西半球标签]                     |
  |     (200,400)            (600,400)                       |
  |                                                          |
  |              [北回归线][赤道][南回归线] ←右侧标签区      |
  |                                                          |
  |         [◀上一步] [步骤X/5] [下一步▶] (y=460)            |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量(0-5)跟踪当前步骤，steps 数组存储每步的显示配置
  2. 坐标计算：所有点坐标预先计算好，轨迹曲线使用 SVG path 的二次贝塞尔曲线
  3. 动画曲线：高亮时使用 CSS transition 实现半径和颜色渐变(0.3s ease-out)
  4. 事件绑定：按钮点击事件绑定到 updateStep() 函数，更新当前状态并重绘
  5. 元素显示控制：每步通过 display 属性或 opacity 控制元素可见性
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀（如 scene1-point-a、scene1-label-a、scene1-btn-next）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
