[分步序列]
本场景为连续拖拽滑块交互，无分步导航，状态连续变化：

- 初始状态（滑块在A点）：
  - 直射点位于南回归线（A点，冬至位置）
  - 北极圈内全部为极夜区（红色填充）
  - 南极圈内全部为极昼区（绿色填充）
  - 节气显示："冬至"
  - 直射点纬度显示："23°26′S"

- 拖动过程中（滑块从A→F连续移动）：
  - 直射点沿轨迹曲线移动
  - 极昼极夜范围连续变化：
    - A→B：北极极夜范围缩小，南极极昼范围缩小
    - B点（春分）：无极昼极夜
    - B→D：北极极昼范围扩大，南极极夜范围扩大
    - D点（夏至）：北极圈内全部极昼，南极圈内全部极夜
    - D→E：北极极昼范围缩小，南极极夜范围缩小
    - E点（秋分）：无极昼极夜
    - E→F：北极极夜范围扩大，南极极昼范围扩大
  - 节气和纬度标签实时更新

- 关键位置状态：
  - A点：冬至，直射23°26′S，北极全极夜，南极全极昼
  - B点：春分，直射0°，无极昼极夜
  - D点：夏至，直射23°26′N，北极全极昼，南极全极夜
  - E点：秋分，直射0°，无极昼极夜
  - F点：冬至，直射23°26′S，北极全极夜，南极全极昼

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：
  - 水平滑块轨道：位于y=380，x从100到700，长度600px
  - 滑块手柄：圆形r=12，可沿轨道左右拖动
  - 刻度标记：A、B、C、D、E、F六个关键位置标注在轨道下方
  - 信息面板：显示当前节气名称和直射点纬度
- 教师操作流程：
  1. 初始状态展示冬至时极昼极夜分布
  2. 拖动滑块从A向D移动，讲解直射点北移过程中极昼极夜范围变化
  3. 在B点（春分）暂停，说明此时全球昼夜平分
  4. 继续拖至D点（夏至），展示北极全极昼、南极全极夜
  5. 反向拖动复习，强化"直射点位置→极昼极夜范围→节气"的对应关系

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单，无需复杂库；拖拽交互用原生事件即可实现
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                    节气标签                       | y=35
  |                                                  |
  |              地球侧视图 (r=120)                   | y=60-300
  |         纬线标签 →  0°, 23°26′N/S, 66°34′N/S    |
  |                                                  |
  |              直射点纬度标签                       | y=330
  |        极昼区图例  极夜区图例                      | y=350
  |                                                  |
  |  A    B    C  D   E              F              | y=380 滑块轨道
  |  |    |    |  |   |              |              |
  |  o----o----o--o---o--------------o  (手柄可拖动)  |
  |                                                  |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用单个变量 sliderPosition (0-1) 表示滑块位置，0对应A点，1对应F点
  2. 直射点轨迹计算：根据 sliderPosition 计算直射点纬度（正弦曲线模拟）
     - 纬度 = 23.43 × sin(2π × sliderPosition - π/2)
  3. 极昼极夜范围计算：
     - 极昼边界纬度 = 90 - |直射点纬度|
     - 北极：直射点在北半球时，北极圈内有极昼；直射点在南半球时，北极圈内有极夜
     - 南极：与北极相反
  4. 节气判断：根据直射点纬度和移动方向判断
     - 23.43°N → 夏至；0°且北移 → 春分；0°且南移 → 秋分；23.43°S → 冬至
  5. 拖拽事件绑定：mousedown/mousemove/mouseup 实现手柄拖动
  6. 实时更新：drag 事件中重绘直射点、极昼极夜区域、更新标签
