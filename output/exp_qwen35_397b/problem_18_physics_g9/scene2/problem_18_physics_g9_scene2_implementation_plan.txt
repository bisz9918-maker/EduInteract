[图示主题与整合说明]
- 本图示主题：物体 A 的浮力与排水体积关系
- 整合内容：浮力大小展示、阿基米德原理应用、排水体积计算
- 教学价值：教师可通过分步动画展示浮力计算过程，从已知浮力 F_浮=9.8N 出发，应用阿基米德原理 F_浮=ρ_水×g×V_排，逐步推导排水体积 V_排=1000cm³，并与选项 B 的 500cm³ 对比，帮助学生理解浮力计算的完整逻辑链

[分步序列]
- 初始状态（步骤 0）：显示物体 A 放大图（长方体轮廓+浅蓝填充）、水面线穿过物体、水下区域填充、排水体积虚线框。右侧公式区仅显示标题"阿基米德原理"。浮力箭头和所有公式/数值隐藏。
- 步骤 1：点击「下一步」→ 浮力箭头从物体底部向上绘制（动画），同时显示标签"F_浮=9.8N"在箭头上方。右侧仍隐藏公式。
- 步骤 2：点击「下一步」→ 右侧显示公式"F_浮 = ρ_水 × g × V_排"，其中 F_浮 和 9.8N 高亮绿色。同时显示"ρ_水 = 1000kg/m³"。
- 步骤 3：点击「下一步」→ 显示计算过程第 1-3 行：V_排 = F_浮 / (ρ_水 × g) = 9.8 / (1000 × 9.8) = 0.001m³。每行依次淡入。
- 步骤 4：点击「下一步」→ 显示最终结果"V_排 = 1000cm³"（绿色大号字体），下方显示"选项 B: 500cm³"（红色）并绘制红色×标记。对比结论：选项 B 错误。

  5. 点击下一步，展示最终结果并与选项 B 对比，得出结论

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript。原因：几何图形简单（矩形、线段、箭头、文字），无需复杂库；原生实现轻量且易于状态控制
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |  [物体 A 放大图]           [公式推导区]          |
  |     ┌────────┐                                    |
  |     │   A    │ 水面~~~          F_浮=ρ�gV        |
  |     │~~~~~~~│                  V=F/ρg            |
  |     │ 浸没  │                  =0.001m³          |
  |     └───↑───┘                  V=1000cm³ ✓       |
  |       F_浮                     选项 B:500cm³ ×   |
  |                                                  |
  |                                                  |
  |              [步骤指示器：步骤 X/4]              |
  |     [◀上一步]                    [下一步▶]       |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量 (0-4)，steps 数组存储每步的可见元素 ID 列表
  2. 坐标计算：所有元素使用绝对坐标（spec 中已精确规划），箭头路径用 SVG path 绘制
  3. 动画曲线：浮力箭头使用 CSS transition + transform: scaleY(0→1) 实现从下向上绘制效果
  4. 事件绑定：按钮点击事件绑定到 updateState() 函数，更新可见性并刷新步骤指示器
  5. 元素可见性：使用 display:none/block 或 opacity:0/1 控制，避免重绘闪烁
- ID 命名规范：所有交互元素 ID 必须以 scene2- 为前缀
  - scene2-objectA, scene2-waterLine, scene2-waterArea, scene2-buoyancyArrow, scene2-buoyancyLabel
  - scene2-formulaTitle, scene2-formula, scene2-calcStep1, scene2-calcStep2, scene2-calcStep3
  - scene2-result, scene2-optionB, scene2-wrongMark
  - scene2-prevBtn, scene2-nextBtn, scene2-stepIndicator
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
