[图示主题与整合说明]
- 本图示主题：平面 PAB 与平面 PDC 的交线及命题②③的分析
- 整合的步骤/概念：
  1. 两平面交线的确定（过公共点 P 的直线 l）
  2. 平面 PAB 内平行于交线 l 的直线族（无数多条）
  3. 交线 l 与底面 ABCD 的位置关系分析
- 教学价值：教师可通过分步展示，帮助学生理解空间几何中两平面交线的概念，直观看到平面 PAB 内存在无数条与交线 l 平行的直线（从而与平面 PDC 平行），同时观察交线 l 与底面 ABCD 相交而非平行，从而判断命题②正确、命题③错误

[视觉元素清单]
- 四棱锥框架：6 条棱线（PA、PB、PC 实线黑色，PD、CD、DA 虚线黑色，AB、BC 实线黑色）
- 顶点标签：P、A、B、C、D 共 5 个，黑色字体 14px
- 平面 PAB：三角形 P-A-B 区域，蓝色 #1565c0 填充，透明度 20%
- 平面 PDC：三角形 P-D-C 区域，绿色 #2e7d32 填充，透明度 20%
- 交线 l：过 P 点的红色 #c62828 加粗直线（4px），从 P 点向左下和右上延伸
- 平行直线族：4 条蓝色 #1565c0 直线（1.5px），在平面 PAB 内均匀分布，均平行于交线 l
- 底面 ABCD：四边形 A-B-C-D 区域，灰色 #888888 填充，透明度 15%
- 颜色/样式沿用 spec 中声明的配色规则

[分步序列]
- 初始状态（步骤 0）：显示基础四棱锥 P-ABCD
  - 显示：6 条棱线（实线/虚线区分可见性）、5 个顶点标签 P/A/B/C/D
  - 隐藏：平面填充、交线 l、平行直线族、底面填充

- 步骤 1：高亮平面 PAB 和平面 PDC，显示交线 l
  - 新增显示：平面 PAB（蓝色半透明填充）、平面 PDC（绿色半透明填充）
  - 新增显示：交线 l（红色加粗直线，过 P 点，两端延伸出平面）
  - 新增标签：交线 l 的标签（红色，位于交线右上端）
  - 视觉变化：两平面以不同颜色半透明显示，交线 l 用红色加粗突出

- 步骤 2：在平面 PAB 内展示多条平行于交线 l 的直线
  - 新增显示：4 条蓝色平行直线（均匀分布在平面 PAB 内）
  - 视觉变化：平面 PAB 内出现一组平行于交线 l 的直线族，直观展示"无数多条"的概念
  - 保持：步骤 1 的所有元素

- 步骤 3：高亮底面 ABCD，分析交线 l 与底面的位置关系
  - 新增显示：底面 ABCD（灰色半透明填充）
  - 视觉变化：底面以灰色半透明显示，可观察到交线 l 向下延伸会与底面相交（不平行）
  - 保持：步骤 2 的所有元素

- 步骤 4：得出结论
  - 显示结论文本框（位于图示上方空白区域）：
    - "命题②：正确 ✓"（绿色文字）
    - "命题③：错误 ✗"（红色文字）
  - 视觉变化：结论以醒目方式呈现，配合图示验证
  - 保持：步骤 3 的所有元素

[标签冲突检查]
- 标签"P"：坐标(400, 65)
- 标签"A"：坐标(205, 372)
- 标签"B"：坐标(360, 428)
- 标签"C"：坐标(592, 402)
- 标签"D"：坐标(472, 322)
- 标签"l"：坐标(490, 275)

冲突检查：
- "P"与"l"：距离约 sqrt((490-400)²+(275-65)²) ≈ 230px → 无冲突
- "A"与"B"：距离约 sqrt((360-205)²+(428-372)²) ≈ 165px → 无冲突
- "B"与"C"：距离约 sqrt((592-360)²+(402-428)²) ≈ 233px → 无冲突
- "C"与"D"：距离约 sqrt((472-592)²+(322-402)²) ≈ 144px → 无冲突
- "D"与"A"：距离约 sqrt((205-472)²+(372-322)²) ≈ 272px → 无冲突
- "l"与各顶点标签：最小距离为"l"与"D"约 sqrt((490-472)²+(275-322)²) ≈ 50px → 无冲突

所有标签间距均 ≥ 20px，无冲突。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 按钮"◀ 上一步"：位于 SVG 内底部左侧 (x=320, y=455)，点击回退到上一状态
  - 按钮"下一步 ▶"：位于 SVG 内底部右侧 (x=460, y=455)，点击前进到下一状态
  - 步骤指示器：位于两按钮之间 (x=400, y=455)，显示当前步骤编号（如"步骤 2/4"）
- 教师操作流程：
  1. 初始展示基础四棱锥，让学生回顾题目条件
  2. 点击"下一步"显示两平面及交线，讲解两平面交线的概念
  3. 点击"下一步"显示平行直线族，说明平面 PAB 内存在无数条与交线 l 平行的直线
  4. 点击"下一步"高亮底面，引导学生观察交线 l 与底面的位置关系
  5. 点击"下一步"显示结论，总结命题②正确、命题③错误的原因

[技术实现]
- JS 库选择：原生 SVG（适合绘制几何图形、半透明填充、线段），无需额外库
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +------------------------------------------+
  |                                          |
  |              P(顶点)                     |
  |             /|\                          |
  |            / | \                         |
  |           /  |  \                        |
  |      平面 PAB |   平面 PDC                |
  |         /    |l   \                      |
  |        A-----+-----C                     |
  |         \    |    /                      |
  |          \   |   /                       |
  |           \  |  /                        |
  |            \ | /                         |
  |             \|/                          |
  |              D                           |
  |                                          |
  |    [◀ 上一步]  步骤 2/4  [下一步 ▶]       |
  +------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 stateIndex 变量（0-4）跟踪当前步骤，steps 数组存储每步需显示的元素 ID 列表
  2. 坐标计算：四棱锥顶点坐标预先计算好，平面填充使用 SVG <polygon> 元素
  3. 动画曲线：元素显示/隐藏使用 CSS transition（opacity 0.3s ease）
  4. 事件绑定：按钮点击事件调用 updateStep() 函数，根据 stateIndex 更新显示状态
  5. 虚线实现：使用 SVG stroke-dasharray="5,5" 属性
  6. 半透明填充：使用 fill-opacity 属性（0.2 表示 20% 透明度）
- ID 命名规范：所有交互元素 ID 必须以 scene2- 为前缀
  - scene2-pyramid-frame（四棱锥框架组）
  - scene2-plane-pab（平面 PAB 填充）
  - scene2-plane-pdc（平面 PDC 填充）
  - scene2-line-l（交线 l）
  - scene2-parallel-lines（平行直线族组）
  - scene2-base-abcd（底面填充）
  - scene2-btn-prev（上一步按钮）
  - scene2-btn-next（下一步按钮）
  - scene2-step-indicator（步骤指示器）
  - scene2-conclusion-box（结论文本框）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
