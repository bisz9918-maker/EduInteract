[图示主题与整合说明]
- 本图示主题：角度关系代数推导可视化

[分步序列]
- 初始状态（步骤 0）：显示完整几何图形（圆、切线 PE、割线 PBA、弦 AE、弦 BE、角平分线 PC），标注点 P、A、B、E、C、D，标注角度变量α（E 点和 B 点处）、β（P 点处两侧），标注已知角 40°（∠AEB 处，红色）
- 步骤 1：点击「下一步」→ 右侧显示公式框 1「∠PCE = ∠EPC + ∠PEC」（外角定理），公式框淡入动画
- 步骤 2：点击「下一步」→ 公式框 2 显示推导链：
  · 弦切角定理：∠PEA = ∠PBE = α
  · 角平分线：∠EPC = ∠CPA = β
  · 已知：∠AEB = 40°
  · ∴ ∠PEC = α + 40°
  公式框淡入，同时几何图中∠AEB 的 40°标签闪烁高亮
- 步骤 3：点击「下一步」→ 公式框 3 显示最终答案「∠PCE = 70°」（绿色背景#2e7d32，白色粗体字），同时几何图中∠PCE 位置用绿色弧度高亮显示
- 教师可随时点击「上一步」回退复习，已显示的公式框淡出

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  · 「上一步」按钮：位于 SVG 底部左侧(260,455)，点击后隐藏当前步骤新增元素，返回上一步状态
  · 「下一步」按钮：位于 SVG 底部右侧(440,455)，点击后显示下一步新增元素
  · 步骤指示器：显示「步骤 X/4」，位于两按钮之间
- 教师操作流程：
  1. 初始状态展示几何图形和角度变量标注，讲解题目条件
  2. 点击「下一步」展示外角定理公式，讲解∠PCE 与△PCE 内角的关系
  3. 点击「下一步」展示完整推导链，讲解弦切角定理和角平分线性质的应用
  4. 点击「下一步」展示最终答案，用绿色高亮强调结论

[技术实现]
- JS 库选择：原生 SVG（几何图形精确绘制）+ 原生 JS（状态管理）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  [几何图形区]           |  [公式推导区]          |
  |  (0-400, 50-400)        |  (450-770, 80-350)     |
  |       P                  |  标题：角度推导过程    |
  |      / \                 |  +------------------+  |
  |     /   \                |  | ∠PCE = ∠EPC +   |  |
  |    E-----A               |  |       ∠PEC      |  |
  |   / \   /                |  +------------------+  |
  |  /   \ /                 |  | 弦切角：∠PEA =  |  |
  | B-----C--D               |  | ∠PBE = α        |  |
  |  (圆 O)                  |  | ...             |  |
  |                          |  +------------------+  |
  |                          |  | ∠PCE = 70°     |  |
  |                          |  | (绿色高亮)     |  |
  |                          |  +------------------+  |
  +--------------------------------------------------+
  |        [◀ 上一步]  步骤 2/4  [下一步 ▶]          |
  |              (y=450-490 控件栏)                  |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用 step 变量(0-3)跟踪当前步骤，steps 数组存储每步显示的元素 ID 列表
  2. 坐标计算：所有几何点坐标硬编码，确保图形比例正确
  3. 动画曲线：公式框使用 CSS transition opacity 0.3s ease-in-out 淡入淡出
  4. 事件绑定：按钮点击事件切换步骤，更新 DOM 元素 display 属性
  5. 角度弧绘制：使用 SVG path 的 arc 命令绘制圆弧
- ID 命名规范：所有交互元素 ID 以 scene2- 为前缀（如 scene2-circle-o, scene2-formula-box-1, scene2-btn-next）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
