[图示主题与整合说明]
- 本图示主题：牛顿调和三角形——第 n 行第 2 个数与第 3 个数的规律探究
- 整合的步骤/概念：
  1. 第 2 个数规律表（行号 n、数值、分母分解、规律）
  2. 第 3 个数规律表（行号 n、数值、分母分解、规律）
  3. 通项公式推导展示（从具体数值归纳到一般公式）
- 教学价值：教师可逐步展示从具体数值到通项公式的归纳过程，引导学生观察分母规律，理解数列递推关系。通过分步填充表格，学生能清晰看到模式形成过程，最后得出通项公式。

[分步序列]
步骤 0（初始状态）：
- 显示左右两表的表头和空数据行框架
- 显示两个通项公式框（空或显示问号）
- 不显示具体数据，等待教师触发

步骤 1（点击「下一步」）：
- 填充左表（第 2 个数）前 5 行数据：
  - n=2: 数值 1/2, 分母 2=2×1, 规律 —
  - n=3: 数值 1/6, 分母 6=3×2, 规律 —
  - n=4: 数值 1/12, 分母 12=4×3, 规律 —
  - n=5: 数值 1/20, 分母 20=5×4, 规律 —
  - n=6: 数值 1/30, 分母 30=6×5, 规律 —
- 右表保持为空

步骤 2（点击「下一步」）：
- 高亮显示左表分母列的 n(n-1) 模式（绿色框）
- 左表公式框显示：a(n,2) = 1/[n(n-1)]
- 引导学生观察分母规律

步骤 3（点击「下一步」）：
- 填充右表（第 3 个数）前 5 行数据：
  - n=3: 数值 1/3, 分母 3=3×2×1/2, 规律 —
  - n=4: 数值 1/12, 分母 12=4×3×2/2, 规律 —
  - n=5: 数值 1/30, 分母 30=5×4×3/2, 规律 —
  - n=6: 数值 1/60, 分母 60=6×5×4/2, 规律 —
  - n=7: 数值 1/105, 分母 105=7×6×5/2, 规律 —
- 左表保持步骤 2 状态

步骤 4（点击「下一步」）：
- 显示推导箭头（从左表指向右表，灰色虚线）
- 高亮显示右表分母列的 n(n-1)(n-2)/2 模式（绿色框）
- 显示推导过程文字："分母 = n(n-1)(n-2)/2"

步骤 5（点击「下一步」）：
- 右表公式框显示：a(n,3) = 2/[n(n-1)(n-2)]
- 右表规律列显示绿色文字 "✓"
- 所有元素完整显示，展示最终结论

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 上一步按钮：位于 (250, 455)，点击后回退到前一状态
  - 下一步按钮：位于 (460, 455)，点击后进入下一状态
  - 步骤指示器：位于 (400, 470)，显示当前步骤 "步骤 X/5"
- 教师操作流程：
  1. 初始状态展示空表格框架，介绍探究目标
  2. 点击「下一步」填充第 2 个数表格，引导学生观察分母规律
  3. 点击「下一步」高亮分母模式，得出第 2 个数通项
  4. 点击「下一步」填充第 3 个数表格，继续探究
  5. 点击「下一步」显示推导箭头和过程
  6. 点击「下一步」展示最终通项公式
  7. 可随时点击「上一步」回退复习关键步骤

[技术实现]
- JS 库选择：原生 SVG（表格和文本渲染简单，无需额外库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  [左表标题]              [右表标题]              |
  |  +----------+            +----------+            |
  |  | 左表表头 |            | 右表表头 |            |
  |  | 数据行 1 |            | 数据行 1 |            |
  |  | 数据行 2 |            | 数据行 2 |            |
  |  | 数据行 3 |            | 数据行 3 |            |
  |  | 数据行 4 |            | 数据行 4 |            |
  |  | 数据行 5 |            | 数据行 5 |            |
  |  +----------+            +----------+            |
  |                                                  |
  |  [公式框 1]              [公式框 2]              |
  |                                                  |
  |  [上一步] [步骤指示器] [下一步]                  |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-5），存储每个状态的显示配置
  2. 表格数据预定义：将每行数据存储在数组中，按步骤动态填充
  3. 高亮效果：使用绿色矩形框覆盖分母单元格，opacity=0.3
  4. 动画过渡：使用 CSS transition 实现淡入效果（opacity 0→1，duration 300ms）
  5. 按钮状态：第一步禁用「上一步」，最后一步禁用「下一步」
  6. 步骤指示器：实时更新显示 "步骤 X/5"
- ID 命名规范：
  - 所有元素 ID 以 scene2- 为前缀
  - 左表：scene2-left-table, scene2-left-header, scene2-left-row-1~5
  - 右表：scene2-right-table, scene2-right-header, scene2-right-row-1~5
  - 公式框：scene2-formula-box-1, scene2-formula-box-2
  - 按钮：scene2-btn-prev, scene2-btn-next
  - 步骤指示器：scene2-step-indicator
  - 高亮框：scene2-highlight-left, scene2-highlight-right
  - 箭头：scene2-arrow-1, scene2-arrow-2
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
- CDN 引入：无需额外库，使用原生 SVG 和 JavaScript
