[图示主题与整合说明]
- 本图示主题：B、C 两点的椭圆轨迹及参数 a、c 的关系
- 整合内容：椭圆定义（到两定点距离和为常数）、B 与 C 的对称性、参数 a 和 c 的几何意义

[分步序列]
- 初始状态（步骤 0）：显示椭圆轨迹、焦点 A 和 D、点 B 和 C 在椭圆上对称位置、线段 AB/BD/AC/CD/AD、距离标注 AB+BD=2a 和 AC+CD=2a、滑块控件（a 初始值设为 1.5c）
- 步骤 1：拖动滑块增大 a 值 → 椭圆扩大，B 点沿椭圆移动，实时更新 AB+BD=2a 的数值标注
- 步骤 2：拖动滑块减小 a 值 → 椭圆缩小，B 点沿椭圆移动，实时更新距离标注
- 步骤 3：点击切换 B/C 点高亮 → 显示对应点的距离计算过程
- 最终状态：展示 a 与 c 的关系（a>c 时椭圆存在），以及 B、C 对称性对四面体体积的影响

[交互方案]
- 交互类型：连续拖拽滑块 + 点拖动
- 控件说明：
  - 滑块轨道：底部 y=465，x 范围 170~630
  - 滑块手柄：可左右拖动，改变 a 值（范围：c+0.1 到 3c）
  - 滑块标签：实时显示当前 a 值
  - 点 B/C：可沿椭圆轨迹拖动，实时显示距离和
- 教师操作流程：
  1. 初始展示椭圆和焦点，讲解椭圆定义
  2. 拖动滑块改变 a 值，观察椭圆大小变化
  3. 拖动 B 点沿椭圆移动，验证 AB+BD=2a 恒成立
  4. 切换显示 C 点，说明 B、C 对称性
  5. 引导学生理解 a、c 参数对四面体体积的影响

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript
  - 椭圆和点线面用 SVG 原生元素绘制，性能好
  - 拖拽交互用原生事件处理，无需额外库
  - 数学计算简单，无需 D3 或 MathJax
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +------------------------------------------+
  |           标题：椭圆轨迹演示              | y=30
  |                                          |
  |        AB+BD=2a                          | y=60
  |              B●                          | y=100
  |            /   \                         |
  |      A●---/-----\---●D    椭圆虚线轨迹   | y=220
  |            \     /                       |
  |              C●                          | y=340
  |        AC+CD=2a                          | y=380
  |                                          |
  |        a = [滑块值]                      | y=430
  |  [══════════●══════════]  滑块控件        | y=465
  +------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：维护当前 a 值、B 点角度、C 点角度（C 与 B 对称）
  2. 椭圆参数方程：x = cx + rx*cos(θ), y = cy + ry*sin(θ)
  3. 滑块拖拽：监听 mousedown/mousemove/mouseup 事件，计算 a 值
  4. 点 B/C 拖拽：监听椭圆上的拖拽，更新角度 θ，实时重绘
  5. 距离计算：AB+BD = 2a 实时验证显示
  6. 动画平滑：使用 requestAnimationFrame 更新位置
- ID 命名规范：所有交互元素 ID 必须以 scene2- 为前缀
  - scene2-ellipse（椭圆轨迹）
  - scene2-focus-a（焦点 A）
  - scene2-focus-d（焦点 D）
  - scene2-point-b（点 B）
  - scene2-point-c（点 C）
  - scene2-line-ab（线段 AB）
  - scene2-line-bd（线段 BD）
  - scene2-line-ac（线段 AC）
  - scene2-line-cd（线段 CD）
  - scene2-line-ad（线段 AD）
  - scene2-label-a（标签 A）
  - scene2-label-d（标签 D）
  - scene2-label-b（标签 B）
  - scene2-label-c（标签 C）
  - scene2-dist-b（距离标注 AB+BD）
  - scene2-dist-c（距离标注 AC+CD）
  - scene2-slider-track（滑块轨道）
  - scene2-slider-handle（滑块手柄）
  - scene2-slider-label（滑块标签）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局污染
