[图示主题与整合说明]
- 本图示主题：圆的切线与割线关系及切割线定理应用
- 整合的内容：基础图形展示、切线割线高亮、切割线定理公式推导、PC 长度计算
- 教学价值：教师可通过分步演示，引导学生理解切割线定理 PA²=PB×PC 的几何意义，从已知条件 PA=2、PB=1 逐步推导出 PC=4，进而求得 BC=3 和半径 R。分步导航便于控制课堂节奏，高亮显示帮助学生聚焦关键线段。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 按钮「◀上一步」：位于 SVG 底部左侧 (x=350, y=460)，点击后退到前一状态
  - 按钮「下一步▶」：位于 SVG 底部右侧 (x=450, y=460)，点击前进到下一状态
  - 步骤指示器：位于两按钮之间 (x=400, y=465)，显示「步骤 X/4」
- 教师操作流程：
  1. 初始展示基础图形，让学生识别切线、割线、直径
  2. 点击「下一步」高亮 PA 和 PCB，强调关键线段
  3. 点击「下一步」显示切割线定理公式，讲解定理内容
  4. 点击「下一步」代入数值计算，展示 PC=4 和 BC=3
  5. 点击「下一步」显示结论，引导学生进一步求半径 R

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：本题为平面几何图形，SVG 原生支持圆、线段、点、文本等元素，无需额外库
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  | [公式框]                                         |
  |                                                  |
  |                    C                             |
  |                    |                             |
  |              B     |                             |
  |             /      |                             |
  |            /       |                             |
  |           /        |                             |
  |          /         |                             |
  |         /          |                             |
  |        P-----------A                             |
  |                                                  |
  |                                                  |
  |              [控件栏 y=450~490]                  |
  |         [◀上一步] [步骤 X/4] [下一步▶]           |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-4) 跟踪当前步骤，数组 steps 定义每步的显示/隐藏规则
  2. 坐标计算：所有元素坐标硬编码，确保与布局表一致
  3. 动画曲线：线段颜色变化用 CSS transition，duration 300ms
  4. 事件绑定：按钮点击事件绑定到 stepForward() 和 stepBack() 函数
  5. 元素 ID 命名：所有元素 ID 以 scene1- 为前缀，如 scene1-circle-o、scene1-line-pa、scene1-label-pa-2
  6. IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
- ID 命名规范示例：
  - 圆：scene1-circle-o
  - 点：scene1-point-p, scene1-point-a, scene1-point-b, scene1-point-c, scene1-point-o
  - 线段：scene1-line-pa, scene1-line-pcb, scene1-line-ac
  - 标签：scene1-label-p, scene1-label-a, scene1-label-b, scene1-label-c, scene1-label-o
  - 长度标签：scene1-label-pa-2, scene1-label-pb-1, scene1-label-pc-4, scene1-label-bc-3
  - 公式框：scene1-formula-box, scene1-formula-text
  - 控件：scene1-btn-prev, scene1-btn-next, scene1-step-indicator
