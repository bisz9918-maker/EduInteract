[图示主题与整合说明]
- 本图示主题：直径构造直角三角形及勾股定理求解半径
- 整合的步骤/概念：连接辅助线 AB→发现直径所对圆周角为直角→标注三角形边长→建立勾股定理方程→求解半径 R
- 教学价值：教师可逐步展示如何通过添加辅助线构造直角三角形，利用直径所对圆周角为 90°的性质，结合勾股定理求解圆的半径。分步演示帮助学生理解几何证明的逻辑链条。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 上一步按钮：位于 SVG 底部左侧 (x=350, y=455)，点击后返回上一状态
  - 下一步按钮：位于 SVG 底部右侧 (x=450, y=455)，点击后进入下一状态
  - 步骤指示器：位于两按钮之间，显示「步骤 X/5」
- 教师操作流程：
  1. 初始状态展示题目基础图形，引导学生观察已知条件
  2. 点击「下一步」添加辅助线 AB，提问学生为什么要连接 AB
  3. 点击「下一步」显示直角，引导学生回忆「直径所对圆周角为 90°」
  4. 点击「下一步」标注边长，引导学生计算 AB=√(PA²-PB²)=√3
  5. 点击「下一步」显示方程，引导学生建立勾股定理关系
  6. 点击「下一步」显示结果，完成求解

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript。原因：几何图形简单，无需复杂库；原生 SVG 精确控制坐标，便于标签定位。
- 画布尺寸：800×500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |         C(520,150)                               |
  |          *                                       |
  |         / \                                      |
  |        /   \  圆 O                               |
  |   B(385,245) \                                   |
  |      *-------\------* O(520,260)                 |
  |     /         \     |                            |
  |    /           \    |                            |
  |   /             \   |                            |
  |  /               \  |                            |
  | P(220,370)--------* A(520,370)                   |
  |                                                  |
  |                                                  |
  |  [方程区 y=440] AB²+BC²=AC²                      |
  |  [结果区 y=470] R=√3                             |
  |                                                  |
  |  [控件栏 y=450]  ◀ 上一步  步骤 X/5  下一步 ▶    |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-5) 跟踪当前步骤，数组 stepElements 存储每步需显示的元素 ID
  2. 坐标计算：B 点坐标通过直线 PC 与圆的交点公式计算，预计算为 (385,245)
  3. 动画曲线：元素显示使用淡入效果 (opacity 0→1，300ms)
  4. 事件绑定：按钮点击事件绑定到 updateStep() 函数，更新显示状态
  5. 边界处理：步骤 0 时禁用「上一步」，步骤 5 时禁用「下一步」
- ID 命名规范：所有元素 ID 以 scene2- 为前缀，如 scene2-circle-o、scene2-line-ab、scene2-label-b 等
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
