[图示主题与整合说明]
- 本图示主题：四边形 PADB 面积分解与计算
- 整合的步骤/概念：四边形区域高亮、三角形分解、关键长度标注、面积公式展示
- 教学价值：教师通过分步演示，帮助学生理解从几何图形到代数计算的转化过程。先展示完整四边形，再用对称轴分解，最后通过三角形面积计算推导最终答案。学生可直观看到四边形 PADB 由两个全等三角形组成，理解 S_PADB = 2 × S_△PAD 的几何意义。

[分步序列]
- 初始状态（步骤 0）：显示完整四边形 PADB（浅蓝色半透明填充），圆 O，所有点标签 P/O/C/D/A/B，标注 PC=1、CD=1。右侧公式框显示标题「四边形 PADB 面积计算」
- 步骤 1：点击「下一步」→ 对称轴 PO 以红色虚线高亮出现，将四边形分为左右两部分。公式框更新显示「S_PADB = 2 × S_△PAD」
- 步骤 2：点击「下一步」→ △PAD 区域以浅绿色半透明填充高亮（覆盖原蓝色），标注「△PAD」文本出现在三角形内部。公式框显示「思路：先求 S_△PAD」
- 步骤 3：点击「下一步」→ 标注 PA=√2 出现在 PA 线段外侧，标注 PD=2 出现在 PD 线段上方，标注 OA=0.5 出现在 OA 线段外侧，标注 PO=1.5 出现在 PO 线段上方。公式框显示「已知：PC=CD=1 → 半径 r=0.5, PO=1.5」
- 步骤 4：点击「下一步」→ 半径 OA 以灰色虚线出现（辅助线），标注直角符号∠OAP。公式框显示「△POA 为直角三角形，PA² = PO² - OA² = 1.5² - 0.5² = 2 → PA=√2」
- 步骤 5：点击「下一步」→ 公式框更新显示面积计算过程：「S_△PAD = ½ × PA × AD × sin(∠PAD)」换行「或用坐标法/三角函数法」换行「S_△PAD = √3/4」
- 步骤 6：点击「下一步」→ 答案框高亮显示最终答案「S = 2 × S_△PAD = √3/2」，绿色边框闪烁提示。所有元素完整显示

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 内底部左侧 (280,455)，点击返回上一状态
  - 「下一步」按钮：位于 SVG 内底部右侧 (440,455)，点击进入下一状态
  - 步骤指示器：显示「步骤 X/6」位于两按钮中间 (380,460)
- 教师操作流程：
  1. 初始状态展示完整四边形，让学生观察图形结构
  2. 点击「下一步」展示对称轴，讲解四边形的对称性
  3. 点击「下一步」高亮△PAD，说明面积分解思路
  4. 点击「下一步」显示各边长度，引导学生推导切线长
  5. 点击「下一步」展示辅助线和直角关系，讲解勾股定理应用
  6. 点击「下一步」展示面积计算过程
  7. 点击「下一步」显示最终答案，完成讲解
  8. 可随时点击「上一步」回退复习关键步骤

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript。理由：本场景为静态几何图形分步展示，无需复杂动画或坐标系变换，原生 SVG 足够且性能最优
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |   [几何图形区 500×350]    [公式框 260×200]       |
  |   圆 O + 四边形 PADB      S_PADB = 2×S_△PAD     |
  |   左侧 2/3                右侧 1/3               |
  |                                                  |
  |                                                  |
  |   [控件栏 y=440~490]                             |
  |   [◀上一步]  步骤 X/6  [下一步▶]                 |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-6) 跟踪当前步骤，数组 steps 存储每步的显示配置
  2. 每步更新函数 updateStep() 根据 currentStep 显示/隐藏对应元素
  3. 元素 ID 命名：所有元素以 scene2- 为前缀，如 scene2-quad-padb、scene2-tri-pad、scene2-axis-po
  4. 按钮事件：绑定 click 事件，currentStep 增减后调用 updateStep()
  5. 边界检查：currentStep < 0 时设为 0，> 6 时设为 6
  6. 公式框内容：用 <text> 元素多行显示，每行 y 坐标递增 25px
  7. IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局污染
- ID 命名规范：
  - scene2-circle-o（圆）
  - scene2-quad-padb（四边形）
  - scene2-tri-pad（三角形）
  - scene2-line-pa, scene2-line-pb, scene2-line-ad, scene2-line-bd, scene2-line-po, scene2-line-oa
  - scene2-point-p, scene2-point-o, scene2-point-c, scene2-point-d, scene2-point-a, scene2-point-b
  - scene2-label-p, scene2-label-o, scene2-label-c, scene2-label-d, scene2-label-a, scene2-label-b
  - scene2-anno-pc1, scene2-anno-cd1, scene2-anno-pa-root2, scene2-anno-pd2, scene2-anno-oa05, scene2-anno-po15
  - scene2-formula-box, scene2-formula-text, scene2-answer-box
  - scene2-btn-prev, scene2-btn-next, scene2-step-indicator
