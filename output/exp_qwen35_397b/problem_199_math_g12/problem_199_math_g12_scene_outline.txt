    **题目原文：**

    如图，在直角坐标平面内有一个边长为 a，中心在原点 O 的正六边形 ABCDEF，AB∥Ox．直线 L：y=kx+t(k 为常数) 与正六边形交于 M、N 两点，记△OMN 的面积为 S，则函数 S=f(t) 的奇偶性为 ______．

    **题目分析：**

    本题核心是判断面积函数 S=f(t) 的奇偶性，其中 t 是直线 L 的截距参数。

    关键观察点：
    1. 正六边形是中心对称图形，关于原点 O 对称
    2. 直线 y=kx+t 与 y=kx-t 关于原点对称
    3. 当 t 变为 -t 时，交点 M、N 关于原点对称变换
    4. 对称变换下，△OMN 的面积保持不变

    **整体讲解思路：**

    1. 首先展示正六边形的中心对称性质
    2. 演示直线 L 随 t 变化时，交点 M、N 的移动轨迹
    3. 对比 t 和 -t 两种情况，验证面积相等
    4. 得出 S(t)=S(-t)，函数为偶函数

    **图示规划说明：**

    - SCENE_1：正六边形与直线 L 的动态交互，展示 t 变化时 M、N 及△OMN 的变化
    - SCENE_2：奇偶性对比验证，同时展示 t 和 -t 两种情况下的三角形面积
    </TEXT_1>

    **教学说明：**

    本图示用于严格验证函数的奇偶性，通过并置对比强化学生的理解。

    **讲解要点：**

    1. 几何对称性分析：
       - 正六边形关于原点中心对称
       - 直线 y=kx+t 与 y=kx-t 关于原点对称
       - 因此交点满足：M₂ = -M₁，N₂ = -N₁（向量关系）

    2. 面积公式推导：

       设 M₁(x₁, y₁)，N₁(x₂, y₂)，则：

       S(t) = ½|x₁y₂ - x₂y₁|

       对于 -t 情况，M₂(-x₁, -y₁)，N₂(-x₂, -y₂)：

       S(-t) = ½|(-x₁)(-y₂) - (-x₂)(-y₁)| = ½|x₁y₂ - x₂y₁| = S(t)

    3. 结论：S(t) = S(-t)，函数 f(t) 是**偶函数**

    **课堂讲解建议：**

    - 先让学生通过 SCENE_1 自主探索，发现面积对称现象
    - 再用 SCENE_2 进行严格验证，从几何直观过渡到代数证明
    - 强调"中心对称图形 + 对称直线 → 对称交点 → 等面积"的逻辑链
    </TEXT_3>
