[图示主题与整合说明]
- 本图示主题：正六边形中直线平移与△OMN 面积的动态关系
- 整合内容：正六边形基本结构、直线 L 随参数 t 平移、交点 M/N 动态追踪、△OMN 面积实时计算与奇偶性验证
- 教学价值：教师可通过拖动滑块直观展示当 t 变化时，直线 L 上下平移，交点 M、N 随之移动，△OMN 面积 S 的变化规律。学生可观察到 S(t) = S(-t) 的对称性，从而理解函数 S=f(t) 为偶函数的几何本质。

[分步序列]
本场景为连续交互（滑块拖拽），无分步导航。状态定义如下：
- 初始状态（t=0）：直线 L 过原点 y=0.5x，M、N 为直线与六边形交点，△OMN 面积 S≈0（直线过原点时面积为 0）
- 状态 1（t>0）：直线向上平移，M 向左下移动，N 向右上移动，△OMN 面积增大
- 状态 2（t<0）：直线向下平移，M、N 位置对称变化，面积 S 与 |t| 相同的情况相等
- 对称验证：当 t=50 和 t=-50 时，面积 S 相等，验证偶函数性质

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：
  - t 值滑块：位于画布底部 (200,460)-(600,480)，范围 [-100, 100]，初始值 0
  - t 值标签：显示当前 t 值，位于滑块左侧上方 (200,440)
  - 面积显示框：位于右上角 (620,120)-(780,160)，实时显示 S 值
- 教师操作流程：
  1. 初始状态 t=0，直线过原点，面积 S=0
  2. 向右拖动滑块（t>0），观察直线向上平移，M、N 移动，面积 S 增大
  3. 记录某 t 值（如 t=50）时的面积 S
  4. 向左拖动至对称位置（t=-50），观察面积 S 相等
  5. 引导学生发现 S(t)=S(-t)，得出 S=f(t) 为偶函数

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单，无需复杂库；SVG 便于动态更新坐标和样式
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +------------------------------------------+
  |  y↑                                      |
  |   E──────D              [S=xxx]          |
  |  /        \                              |
  | F          C                             |
  | |    O     |      L                      |
  | |   / \    |                            x→
  |  \ /   \  /                              |
  |   A──────B                               |
  |                                          |
  |                                          |
  |  t = [0]  [====●====]                    |
  +------------------------------------------+
  ```
- 关键实现要点：
  1. 正六边形顶点预计算（边长 a=100，中心 (400,250)）
  2. 直线方程 y = 0.5x + t，t 由滑块控制
  3. 交点计算：遍历六边形 6 条边，求直线与每条线段的交点，取有效交点（在线段上）
  4. 面积计算：S = 0.5 * |x_M*y_N - x_N*y_M|（O 为原点，叉积公式）
  5. 滑块事件：input 事件监听，实时更新直线、交点、三角形、面积显示
  6. t 范围：[-100, 100] 覆盖直线与六边形有交点的区间
- ID 命名规范：
  - scene1-hexagon（正六边形）
  - scene1-line-l（直线 L）
  - scene1-point-m（交点 M）
  - scene1-point-n（交点 N）
  - scene1-tri-omn（△OMN）
  - scene1-label-o/a/b/c/d/e/f（顶点标签）
  - scene1-label-m/n（交点标签）
  - scene1-label-x/y（轴标签）
  - scene1-label-l（直线标签）
  - scene1-area-box（面积显示框）
