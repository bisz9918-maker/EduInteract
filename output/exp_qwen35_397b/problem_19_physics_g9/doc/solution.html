problem_19_physics_g9

场景导航：Scene 1 | Scene 2 | Scene 3

题目原文：

如图所示，AB 为铅笔芯，其电阻与长度成正比，当两个电流表均接 0-0.6A 量程时，改变滑片 P 在铅笔芯上的位置，两个电流表示数的最大比值为 3:1，滑片 P 允许滑动的长度范围 cd 为 12cm。当两个电表均接 0-3A 时，改变滑片 P 在铅笔芯上的位置，则：（ ）

A. 两个电流表示数的最大比值变为 19:1

B. 两个电流表示数的最大比值变为 29:1

C. 滑片 P 允许滑动的长度范围为 22.4cm

D. 滑片 P 允许滑动的长度范围为 21.6cm

题目分析：

本题是并联电路动态分析问题。电路结构为：电源、开关、滑片 P 构成干路，铅笔芯 AB 被滑片 P 分成 AP 和 PB 两段，这两段电阻并联，电流表 A1 测 AP 段电流，A2 测 PB 段电流。

关键物理关系：

  1. 铅笔芯电阻与长度成正比：R = ρL/S
  2. 并联电路电压相等：UAP = UPB
  3. 电流与电阻成反比：I1/I2 = R2/R1 = LPB/LAP

整体讲解思路：

  1. 首先分析电路结构，明确并联关系
  2. 推导电流比值与滑片位置的关系
  3. 根据 0-0.6A 量程条件求出铅笔芯总长度
  4. 分析 0-3A 量程时的新约束条件
  5. 计算新的最大比值和滑动范围

图示规划说明：

共设计 3 个图示：

  • SCENE_1：电路结构与电流分布（分步展示电路分解）
  • SCENE_2：电流比值随滑片位置变化规律（滑块拖动观察）
  • SCENE_3：两种量程下滑动范围对比（多状态切换）

教学说明：

本图示帮助学生理解电路的并联本质。教师应引导学生：

  1. 观察原图，识别电流从电源正极出发后的分流点
  2. 理解滑片 P 将铅笔芯分成两段，这两段是并联关系
  3. 明确 A1 测量左段电流 I1，A2 测量右段电流 I2

关键公式推导：

设铅笔芯总长度为 L，滑片 P 距 A 端距离为 x，则：

  • AP 段长度：x
  • PB 段长度：L - x

因电阻与长度成正比，设单位长度电阻为 r：

  • R_AP = r·x
  • R_PB = r·(L - x)

并联电路电压相等，电流与电阻成反比：

I1/I2 = RPB/RAP = (L - x)/x

此式是解题的核心关系。

教学说明：

本图示让学生通过拖动滑片直观感受电流比值的变化规律。教师应引导学生：

  1. 观察当 P 靠近 A 端时，x 很小，I1/I2 = (L-x)/x 很大
  2. 观察当 P 靠近 B 端时，x 接近 L，I1/I2 接近 0
  3. 理解电流表量程限制了滑片的活动范围

0-0.6A 量程条件分析：

当滑片在 c 点时，I1 达到最大值 0.6A，此时 I1/I2 = 3:1

由 I1/I2 = (L-xc)/xc = 3，得：L - xc = 3xc → L = 4xc → xc = L/4

当滑片在 d 点时，I2 达到最大值 0.6A，此时 I2/I1 = 3:1

由 I2/I1 = xd/(L-xd) = 3，得：xd = 3(L-xd) → x_d = 3L/4

cd 长度 = xd - xc = 3L/4 - L/4 = L/2 = 12cm

因此铅笔芯总长度 L = 24cm

验证：xc = 6cm，xd = 18cm

教学说明：

本图示对比两种量程下的滑动范围变化。教师应引导学生理解：量程扩大 5 倍（0.6A→3A），滑动范围也会相应扩大，但不是简单的 5 倍关系。

0-3A 量程计算：

电源电压 U 可由 0-0.6A 条件求出：

当 P 在 c 点时，I1 = 0.6A，R_AP = r·6cm

U = I1·R_AP = 0.6·r·6 = 3.6r（单位：V，r 单位：Ω/cm）

当量程改为 0-3A 时：

新 c'点：I1 = 3A，RAP' = U/3 = 3.6r/3 = 1.2r → xc' = 1.2cm

新 d'点：I2 = 3A，RPB' = U/3 = 1.2r → L - xd' = 1.2cm → x_d' = 22.8cm

新滑动范围 = xd' - xc' = 22.8 - 1.2 = 21.6cm

新最大比值：

当 P 在 c'点时，I1/I2 = (L-xc')/xc' = (24-1.2)/1.2 = 22.8/1.2 = 19

因此最大比值为 19:1

答案：A 和 D 正确
