[图示主题与整合说明]
- 本图示主题：两种量程下滑动范围对比
- 整合的内容：0-0.6A 量程范围 vs 0-3A 量程范围、最大比值对比
- 教学价值：教师可通过切换按钮清晰展示两种量程下约束条件的变化，帮助学生理解电流表量程如何影响滑片允许滑动范围和电流比值，直观对比两种情况的差异

[视觉元素清单]
- 铅笔芯 AB：黑色粗线段，位置 (150,250)-(650,250)，线宽 4px
- 刻度线：13 条黑色短线，间隔约 41.67px（500px/12），从 x=150 到 x=650
- A/B 标签：黑色文字，A 在 (145,270)，B 在 (655,270)
- 0-0.6A 范围：蓝色矩形填充 #1565c0，透明度 30%，位置 (275,230)-(525,245)，边界标记 c(6cm)、d(18cm)
- 0-3A 范围：绿色矩形填充 #2e7d32，透明度 30%，位置 (225,255)-(575,270)，边界标记 c'、d'
- 比值面板：右侧 (680,100)-(780,200)，显示两种量程下的最大比值
- 边界标记：红色竖线 #c62828，线宽 2px，高度 12px
- 按钮：蓝色背景 #1565c0，白色文字，圆角矩形

[分步序列]
- 初始状态（步骤 0）：显示铅笔芯 AB、刻度、A/B 标签，不显示任何范围
- 状态 1（点击「0-0.6A 量程」）：
  - 显示蓝色范围 c-d（6cm-18cm），上方位置
  - 显示 c、d 标签
  - 右侧面板显示「最大比值：3:1」
  - 隐藏绿色范围
- 状态 2（点击「0-3A 量程」）：
  - 显示绿色范围 c'-d'（计算后位置），下方位置
  - 显示 c'、d'标签
  - 右侧面板显示「最大比值：19:1」（根据题目选项 A）
  - 隐藏蓝色范围
- 状态 3（点击「对比」）：
  - 同时显示蓝色范围（上方）和绿色范围（下方）
  - 同时显示 c、d、c'、d'标签
  - 右侧面板同时显示两个比值
  - 用不同颜色区分两种范围

[标签冲突检查]
- 标签"A"：坐标 (145,270)
- 标签"B"：坐标 (655,270)
- 标签"c"：坐标 (270,220)
- 标签"d"：坐标 (520,220)
- 标签"c'"：坐标 (220,280)
- 标签"d'"：坐标 (570,280)
- 比值 3:1：坐标 (690,130)
- 比值新值：坐标 (690,170)

冲突检查：
- "A"与"c'"：距离 ≈ sqrt((145-220)²+(270-280)²) ≈ 76px → 无冲突
- "B"与"d'"：距离 ≈ sqrt((655-570)²+(270-280)²) ≈ 86px → 无冲突
- "c"与"d"：距离 ≈ 250px → 无冲突
- "c'"与"d'"：距离 ≈ 350px → 无冲突
- "c"与"c'"：距离 ≈ sqrt((270-220)²+(220-280)²) ≈ 78px → 无冲突
- "d"与"d'"：距离 ≈ sqrt((520-570)²+(220-280)²) ≈ 78px → 无冲突
- 所有标签间距均 ≥ 20px，无冲突

[交互方案]
- 交互类型：多状态切换（3 个按钮）
- 控件说明：
  - 按钮 1「0-0.6A 量程」：显示蓝色范围 c-d 及比值 3:1
  - 按钮 2「0-3A 量程」：显示绿色范围 c'-d'及新比值
  - 按钮 3「对比」：同时显示两种范围进行对比
- 教师操作流程：
  1. 先点击「0-0.6A 量程」，讲解已知条件（cd=12cm，比值 3:1）
  2. 再点击「0-3A 量程」，展示新量程下的变化
  3. 最后点击「对比」，直观比较两种情况的差异，引导学生分析原因

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                    比值面板                       |
  |                   (680,100)                      |
  |                                                  |
  |         [0-0.6A 范围 蓝色]                        |
  |         c(6cm)----------d(18cm)                  |
  |                                                  |
  |    A ===================================== B     |
  |       | | | | | | | | | | | | |  (铅笔芯)        |
  |                                                  |
  |         [0-3A 范围 绿色]                          |
  |       c'------------------------d'               |
  |                                                  |
  |                                                  |
  |    [0-0.6A]  [0-3A]   [对比]    (按钮区 y=450)   |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用 currentState 变量跟踪当前状态（0=初始，1=0.6A，2=3A，3=对比）
  2. 坐标计算：铅笔芯 500px 代表 24cm，比例尺 = 500/24 ≈ 20.83px/cm
     - c 点 (6cm)：x = 150 + 6×20.83 ≈ 275
     - d 点 (18cm)：x = 150 + 18×20.83 ≈ 525
     - c'点：根据题目计算（选项 C/D 给出 22.4cm 或 21.6cm 范围）
     - d'点：根据题目计算
  3. 事件绑定：三个按钮分别绑定 click 事件，切换显示状态
  4. 动画：范围显示/隐藏使用 opacity 过渡（0.3s）
- ID 命名规范：所有元素 ID 以 scene3- 为前缀
  - scene3-pencil-ab, scene3-range-06a, scene3-range-3a
  - scene3-label-c, scene3-label-d, scene3-label-cp, scene3-label-dp
  - scene3-btn-06a, scene3-btn-3a, scene3-btn-compare
  - scene3-ratio-panel, scene3-ratio-06a, scene3-ratio-3a
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中
