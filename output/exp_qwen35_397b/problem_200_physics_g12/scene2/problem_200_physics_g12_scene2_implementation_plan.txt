[分步序列]
本场景为连续拖拽滑块交互，无分步导航。状态定义如下：

- 初始状态（x=0）：
  - 活塞位置：y_p=52（距 A 管顶部 10px）
  - A 管水银高：h₁'=5cm（12.5px）
  - B 管水银高：h₂'=10cm（25px）
  - 气体长度：L'=112cm（280px）
  - 气体压强：p₂=75+5+10=90cmHg
  - 显示：初始状态，滑块在最左端

- 中间状态（x=10cm，滑块中点）：
  - 活塞上移 10cm，y_p=42
  - 体积守恒：A 管截面积 S_A=4S_B，活塞上移 x，A 管水银下降Δh₁
  - 4S_B·x = 4S_B·Δh₁ + S_B·Δh₂（水银体积守恒）
  - 简化：4x = 4Δh₁ + Δh₂
  - 同时：Δh₁ = x - (水银从 A 流向 B 的部分)
  - 实际计算：A 管水银减少体积 = B 管水银增加体积
  - 4S·Δh_A = S·Δh_B → Δh_B = 4Δh_A
  - 活塞上移 x，若水银不流出 A 管：h₁' = h₁ - (x 中用于填补活塞上升的部分)
  - 需要仔细计算水银重新分布

- 最终状态（x=20cm，滑块最右端）：
  - 活塞上移 20cm
  - 显示最大位移时的各参数值
  - 计算此时拉力 F 是否为零

- 画布尺寸：800×500px（固定）
- 布局草图：

  +--------------------------------------------------+

- 关键实现要点：
  1. 状态变量：x（活塞位移，0~20cm）
  2. 物理计算：
     - 初始：h₁=5cm, h₂=10cm, L=112cm, p₀=75+5+10=90cmHg
     - 活塞上移 x 时：
       - 设 A 管水银下降Δh₁，B 管水银上升Δh₂
       - 体积守恒：S_A·Δh₁ = S_B·Δh₂，且 S_A=4S_B → Δh₂=4Δh₁
       - 活塞上移 x，若水银始终接触活塞：h₁' = h₁ - Δh₁
       - 但实际：活塞上移 x，水银面相对活塞下降，所以 h₁' = h₁ - (x - 活塞与水银分离的部分)
       - 简化模型：假设水银始终接触活塞，则 h₁' = h₁ - x + (流向 B 管的部分)
       - 更准确：设水银总体积不变，4S·h₁ + S·h₂ = 4S·h₁' + S·h₂'
       - 且活塞位置决定：h₁' + (活塞上移量中水银填充部分) = h₁
     - 气体压强：p₂ = p₀ + h₁' + h₂'（大气压 + 水银柱压强）
     - 玻意耳定律：p₀·L = p₂·L' → L' = p₀·L/p₂
  3. 拖拽事件：mousedown/mousemove/mouseup 或 touch 事件
  4. 实时更新：拖拽时重绘水银区域、气体区域、数值显示
  5. 边界处理：x∈[0,20]，水银不溢出 A 管顶部，气体不溢出 B 管底部
- ID 命名规范：
  - 所有元素 ID 以 scene2- 为前缀
  - 如：scene2-piston, scene2-mercury-a, scene2-gas, scene2-slider, scene2-val-x 等
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
