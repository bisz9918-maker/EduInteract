冲突检查：
- "O"与"F"：垂直距离 355px → 无冲突
- "O"与"x/cm"：水平距离 630px → 无冲突
- "(0, 15)"与"F"：垂直距离 135px → 无冲突
- "x₀≈12"与"F=0"：垂直距离 15px → 接近但可接受（F=0 在 x₀上方）
- "F_min"与 x 轴刻度：垂直距离 30px → 无冲突
- 所有关键点标签均位于曲线外侧，不压在线段上

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于控件栏左侧，点击返回上一状态
  - 「下一步」按钮：位于控件栏右侧，点击进入下一状态
  - 状态指示器：显示当前步骤（如「步骤 2/4」）
- 教师操作流程：
  1. 初始展示坐标系和曲线，让学生观察整体趋势
  2. 点击「下一步」标注初始状态，讲解初始拉力 F=15 cmHg 的计算
  3. 点击「下一步」标注 F=0 临界点，讨论此时活塞受力平衡
  4. 点击「下一步」标注极值点，分析拉力最小值
  5. 点击「下一步」展示完整变化规律，总结 F 先减小后增大的物理原因

[技术实现]
- JS 库选择：原生 SVG（适合绘制坐标系、曲线、标注，无需额外库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  F                                               |
  |  ↑                                    [图例]     |
  |  |    P0(0,15)●                                   |
  |  |       \                                        |
  |  |        \                                       |
  |  |         \                                      |
  |  |          \    P2●                               |
  |  |           \   /                                 |
  |  |            \ /                                  |
  |  |             ●P1(x₀,0)                           |
  |  +-------------+------------------+                |
  |  O             x₀                x/cm              |
  |                                                      |
  |           [◀上一步]  步骤 2/4  [下一步▶]            |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用 currentState 变量跟踪当前步骤（0-4），数组存储每步需显示的元素 ID
  2. 曲线绘制：使用 SVG <path> 的 bezier 曲线命令，根据 F-x 函数计算关键点坐标
  3. 坐标映射：物理坐标 (x,F) 到 SVG 坐标 (svgX, svgY) 的线性变换函数
  4. 事件绑定：按钮点击事件切换状态，更新元素 display 属性
  5. ID 命名规范：所有元素 ID 以 scene3- 为前缀（如 scene3-axis-x, scene3-curve-fx, scene3-point-p0）
  6. IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
- 坐标变换公式：
  - svgX = 120 + x * 30（x 范围 0~20，映射到 120~720）
  - svgY = 400 - F * 20（F 范围 -5~15，映射到 400~80，注意 SVG y 轴向下）
