[图示主题与整合说明]
- 本图示主题：带电粒子在复合场中的受力分析与运动分解
- 整合内容：粒子受力（重力 + 电场力）、水平与竖直分运动独立展示、速度分量变化
- 教学价值：教师可通过分步演示，帮助学生理解运动的独立性原理——竖直方向受重力做竖直上抛运动，水平方向受电场力做匀加速直线运动。分步展示力→加速度→速度变化的因果关系，突破学生"曲线运动难以分解"的认知障碍。

[技术实现]
- JS库选择：原生SVG（简单几何图形+箭头，无需额外库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │  [电场线区域]           │  [竖直分运动]  [水平分运动]      │
  │      ←←←←←←←           │   v₀↑  g↓      Fe→  ax→         │
  │      粒子P●→Fe         │                                     │
  │        ↓G              │  ─────────────────────────────    │
  │      ←←←←←←←           │  [vy-t图]      [vx-t图]          │
  │                         │   vy↘          vx↗              │
  │                         │   ────          ────             │
  ├─────────────────────────────────────────────────────────────┤
  │         [◀上一步]  步骤 X/4  [下一步▶]                      │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-4) 跟踪当前步骤，数组存储每步可见元素ID列表
  2. 箭头绘制：用SVG <marker> 定义箭头样式，<line> + marker-end 实现
  3. 淡入动画：CSS transition opacity 0.5s，步骤切换时添加/移除 .visible 类
  4. 事件绑定：按钮点击事件调用 stepForward()/stepBackward() 函数
  5. 脉冲动画：CSS @keyframes pulse { 0%,100% { r:6 } 50% { r:8 } }
  6. 坐标计算：所有坐标硬编码，确保与布局表一致
- ID命名规范：
  - 所有元素ID以 scene2- 为前缀
  - 示例：scene2-particle, scene2-arrow-G, scene2-arrow-Fe, scene2-vy-arrow, scene2-g-arrow
  - 按钮：scene2-btn-prev, scene2-btn-next, scene2-step-indicator
- IIFE隔离：所有JS代码包裹在 (function() { ... })() 中，避免全局污染
- 状态切换逻辑：
  ```javascript
  const stepElements = {
    0: ['scene2-field-lines', 'scene2-particle', 'scene2-arrow-G', 'scene2-arrow-Fe', 'scene2-label-G', 'scene2-label-Fe'],
    1: [...stepElements[0], 'scene2-vertical-group'],
    2: [...stepElements[1], 'scene2-horizontal-group'],
    3: [...stepElements[2], 'scene2-vt-charts'],
    4: [...stepElements[3], 'scene2-conclusion-box']
  };
  ```
