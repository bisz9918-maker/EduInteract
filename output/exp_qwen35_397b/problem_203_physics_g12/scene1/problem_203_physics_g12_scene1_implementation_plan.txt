[分步序列]
- 初始状态（步骤 0）：显示基础装置
  - 金属板 A、B（黑色粗线）
  - 中心线 RD（灰色虚线）
  - 界面 MN、PS（灰色虚线）
  - 所有固定标签：A、B、R、M、N、D、P、S、L=8cm、d=8cm、12cm
  - 初速度箭头 v₀ 及标签

- 步骤 1：高亮电场区域，显示电场线方向
  - 在板 A、B 之间添加浅蓝色半透明填充 (#1565c0, opacity=0.15)
  - 显示 4 条电场线（蓝色向下箭头）
  - 电场线从 A 板附近指向 B 板附近

- 步骤 2：绘制电场中轨迹（红色抛物线从 R 到 MN）
  - 绘制红色抛物线轨迹：从 R(100,250) 到 MN 界面 (420,280)
  - 抛物线方程：y = 250 + k*(x-100)²，k 使 x=420 时 y=280
  - 轨迹起点 R 处添加小圆点标记

- 步骤 3：绘制无电场区轨迹（红色直线从 MN 到 PS）
  - 绘制红色直线轨迹：从 MN(420,280) 到 PS(760,340)
  - 直线斜率与抛物线在 MN 处的切线斜率相同
  - 轨迹终点添加小圆点标记

- 步骤 4：标注偏移量 y₁ 和 y₂
  - 显示 y₁ 双箭头标注（MN 处，从中心线到轨迹）
  - 显示 y₂ 双箭头标注（PS 处，从中心线到轨迹）
  - 显示 y₁、y₂ 标签

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 底部左侧 (x=320, y=455)，返回上一状态
  - 「下一步」按钮：位于 SVG 底部右侧 (x=480, y=455)，进入下一状态
  - 步骤指示器：位于底部中央 (x=400, y=455)，显示「步骤 X/4」
- 教师操作流程：
  1. 初始状态展示装置结构，讲解平行板电容器 setup
  2. 点击「下一步」显示电场线，讲解电场方向（A→B，向下）
  3. 点击「下一步」显示电场中轨迹，讲解类平抛运动（水平匀速 + 竖直匀加速）
  4. 点击「下一步」显示无电场区轨迹，讲解离开电场后匀速直线运动
  5. 点击「下一步」显示偏移量标注，讲解 y₁ 和 y₂ 的物理意义

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  P                                               |
  |  |                                               |
  |  |              12cm                             |
  |  M-----------------------------------------------|
  |  |                                               |
  |  |====A 板====================|                  |
  |  |                            |                  |
  |  R→v₀  ........RD.............|.........D........|
  |  |                            |                  |
  |  |====B 板====================|                  |
  |  |                                               |
  |  N-----------------------------------------------|
  |  |                                               |
  |  S                                               |
  |                                                  |
  |     [◀上一步]   步骤 X/4   [下一步▶]            |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-4) 跟踪当前步骤
  2. 所有元素按步骤分组，用 display 属性控制显示/隐藏
  3. 抛物线用 SVG path 的二次贝塞尔曲线或逐点绘制
  4. 电场线箭头用 SVG marker-end 定义箭头样式
  5. 双箭头标注用两条带箭头的线段组合
  6. 按钮事件绑定：onclick 切换 currentStep 并更新显示
  7. 步骤指示器同步更新文本

- ID 命名规范：
  - 所有元素 ID 以 scene1- 为前缀
  - 示例：scene1-plate-a, scene1-plate-b, scene1-center-line, scene1-mn-line, scene1-ps-line
  - 轨迹：scene1-trajectory-field, scene1-trajectory-free
  - 电场线：scene1-efield-1, scene1-efield-2, scene1-efield-3, scene1-efield-4
  - 标注：scene1-y1-arrow, scene1-y2-arrow
  - 标签：scene1-label-a, scene1-label-b, scene1-label-r, 等
  - 控件：scene1-btn-prev, scene1-btn-next, scene1-step-indicator

- IIFE 隔离：
  ```javascript
  (function() {
      // 所有 JS 代码包裹在此
      let currentStep = 0;
      // ...
  })();
  ```
