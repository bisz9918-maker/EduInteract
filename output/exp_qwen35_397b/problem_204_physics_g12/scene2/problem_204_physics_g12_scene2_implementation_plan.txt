[图示主题与整合说明]
- 本图示主题：三阶段临界状态受力分析
- 整合的步骤/概念：整合三个临界状态（ω₀、ω₁、ω₂）的受力分析，展示静摩擦力和绳子张力随角速度增大的变化过程

[分步序列]
- 步骤 0（初始状态，ω 较小）：
  - 显示：圆盘、O、A、B、半径线
  - 受力：f_A、f_B 静摩擦力箭头（#1565c0，正常线宽）
  - 公式区显示：f_A = mω²r_A，f_B = mω²r_B
  - 步骤指示：步骤 0：静摩擦力提供向心力

- 步骤 1（临界状态 1，ω = ω₀）：
  - 变化：f_A 变为红色加粗（#c62828，线宽3），出现 T_AB_A 箭头（A受拉力向左）
  - 高亮：f_A 箭头和 T_AB_A 箭头用黄色半透明框包围
  - 公式区显示：f_A = f_m = 0.5mg，ω₀ = √(0.5g/r_A) = 5 rad/s
  - 步骤指示：步骤 1：AB 绳开始有张力（ω₀ = 5 rad/s）

- 步骤 2（临界状态 2，ω = ω₁）：
  - 变化：f_B 也变为红色加粗，出现 T_AB_B 箭头（B受拉力向右），出现 T_OB_B 箭头（B受拉力向左）
  - 高亮：f_B、T_AB_B、T_OB_B 用黄色半透明框包围
  - 公式区显示：f_B = f_m = 0.5mg，T_AB = f_m - mω²r_B，ω₁ = √(0.5g/r_B) ≈ 7.07 rad/s
  - 步骤指示：步骤 2：OB 绳开始有张力（ω₁ ≈ 7.07 rad/s）

- 步骤 3（临界状态 3，ω = ω₂）：
  - 变化：所有力显示，T_AB_A 和 T_AB_B 加粗，T_OB_B 加粗
  - 高亮：所有张力箭头用黄色半透明框包围
  - 公式区显示：对 A：T_AB + f_m = mω₂²r_A；对 B：T_OB - T_AB + f_m = mω₂²r_B；解得 ω₂ ≈ 7.9 rad/s
  - 步骤指示：步骤 3：A 即将滑动（ω₂ ≈ 7.9 rad/s）

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于(280,470)，尺寸80×28，点击返回上一状态
  - 「下一步」按钮：位于(440,470)，尺寸80×28，点击进入下一状态
  - 步骤指示文本：位于(400,455)，显示当前步骤名称
  - 公式区：位于(50,380)-(750,430)，显示当前步骤的受力方程和计算结果
- 教师操作流程：
  1. 初始加载显示步骤0，讲解静摩擦力提供向心力的基本概念
  2. 点击「下一步」进入步骤1，讲解A先达到最大静摩擦力的原因（r_A较大）
  3. 点击「下一步」进入步骤2，讲解B也达到最大静摩擦力时OB绳开始受力
  4. 点击「下一步」进入步骤3，讲解A即将滑动时的临界条件，联立方程求解

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（圆形、矩形、箭头），无需复杂库；原生实现轻量且易于控制状态
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |              圆盘俯视图 (居中)                    |
  |         O────B────────A                          |
  |         受力箭头从物体出发                        |
  |                                                  |
  |  [公式显示区域 y=380~430]                        |
  |  f_A = mω²r_A, f_B = mω²r_B                     |
  |                                                  |
  |  [步骤指示 y=455]  步骤 0：静摩擦力提供向心力     |
  |                                                  |
  |     [◀上一步]      [下一步▶]                     |
  |     (280,470)      (440,470)                     |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-3) 跟踪当前步骤，数组存储每步的配置
  2. 箭头绘制函数：createArrow(fromX, fromY, toX, toY, color, width) 统一生成箭头 SVG 元素
  3. 高亮框：用<rect>元素，fill="#ffd54f"，opacity="0.3"，根据当前步骤动态更新位置和显示
  4. 公式更新：每步更新公式区textContent
  5. 按钮状态：步骤0时禁用「上一步」，步骤3时禁用「下一步」
  6. 事件绑定：按钮点击事件监听，更新 currentStep 后调用 renderStep()
- ID 命名规范：
  - 所有元素 ID 以 scene2- 为前缀
  - 示例：scene2-disc（圆盘）、scene2-obj-a（物体A）、scene2-obj-b（物体B）
  - 箭头：scene2-arrow-fa、scene2-arrow-fb、scene2-arrow-tab-a、scene2-arrow-tab-b、scene2-arrow-tob-b
  - 标签：scene2-label-o、scene2-label-a、scene2-label-b、scene2-label-ra、scene2-label-rb
  - 控件：scene2-btn-prev、scene2-btn-next、scene2-step-indicator、scene2-formula-box
  - 高亮框：scene2-highlight-box
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
