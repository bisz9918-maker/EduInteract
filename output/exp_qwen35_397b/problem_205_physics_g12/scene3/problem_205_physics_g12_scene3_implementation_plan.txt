[图示主题与整合说明]

[分步序列]
- 步骤 0（初始状态）：显示半圆轨道 NL、圆心 O、P 点高亮标记（蓝色实心圆）、标签"P"、"O"、"R"。右侧方程框隐藏。
- 步骤 1：在步骤 0 基础上，显示 P 点三个受力向量——重力 mg（红色向下箭头）、电场力 qE（蓝色向左箭头）、支持力 N_P（绿色向右箭头），并显示对应标签。
- 步骤 2：在步骤 1 基础上，显示向心力方向（灰色虚线箭头从 P 指向圆心 O），强调向心力由支持力与电场力的合力提供。
- 步骤 3：在步骤 2 基础上，右侧显示方程框 1，内容为向心力方程"N_P - qE = mv_P²/R"，方程中 N_P 高亮显示。
- 步骤 4：在步骤 3 基础上，右侧显示方程框 2，内容为动能定理方程"qE·(S+R) - μmgS - mgR = ½mv_P²"，说明从 M 到 P 过程的能量关系。
- 步骤 5（最终步骤）：在步骤 4 基础上，右侧显示结果框，内容为最终压力值"N_P = 3.0 N"（根据计算结果），所有元素完整展示。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 按钮"◀ 上一步"：位置(280, 455)，返回上一状态
  - 按钮"下一步 ▶"：位置(420, 455)，进入下一状态
  - 状态指示器：位置(380, 455)，显示"步骤 X/6"
- 教师操作流程：
  1. 初始展示 P 点位置，让学生识别 P 点在半圆轨道上的位置
  2. 点击"下一步"展示受力图，引导学生分析 P 点受哪些力
  3. 点击"下一步"展示向心力方向，说明向心力指向圆心
  4. 点击"下一步"展示向心力方程，建立牛顿第二定律方程
  5. 点击"下一步"展示动能定理，说明如何求 v_P
  6. 点击"下一步"展示最终结果，完成压力计算

[技术实现]
- JS 库选择：原生 SVG（简单几何图形和箭头，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |   [半圆轨道]          [方程框 1]                 |
  |      L                N_P - qE = mv_P²/R         |
  |      |                                           |
  |   P--O--R            [方程框 2]                 |
  |      |                qE·(S+R) - μmgS - mgR      |
  |      N                = ½mv_P²                   |
  |                                                  |
  |                      [结果框]                    |
  |                      N_P = 3.0 N                 |
  |                                                  |
  |         [◀ 上一步]  步骤 X/6  [下一步 ▶]         |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0~5) 跟踪当前步骤，数组 steps[] 存储每步显示的元素 ID 列表
  2. 坐标计算：半圆轨道用 SVG path 的 arc 命令，圆心(200,250)，半径120px
  3. 箭头绘制：用 SVG marker-end 定义箭头样式，线段 + 箭头组合
  4. 事件绑定：按钮点击事件切换 currentStep，调用 updateDisplay() 函数更新可见性
  5. 动画效果：元素出现时用 CSS transition 实现淡入效果（opacity 0→1，0.3s）
- ID 命名规范：所有元素 ID 以 scene3- 为前缀，如 scene3-semicircle、scene3-point-p、scene3-arrow-mg、scene3-box-equation1 等
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
