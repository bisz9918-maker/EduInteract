problem_206_physics_g12

场景导航：Scene 1 | Scene 2 | Scene 3

题目原文：

在光滑绝缘的水平面上，存在平行于水平面向右的匀强电场，电场强度为 E。水平面上放置两个静止的小球 A 和 B（均可看作质点），两小球质量均为 m，A 球带电荷量为 +q，B 球不带电，A、B 连线与电场线平行。开始时两球相距 L，在电场力作用下，A 球开始运动（此时为计时零点，即 t=0），后与 B 球发生对心碰撞，碰撞过程中 A、B 两球总动能无损失。设在各次碰撞过程中，A、B 两球间无电量转移，且不考虑两球碰撞时间及两球间的万有引力。求：
（1）第一次碰撞结束瞬间 A、B 两球的速度各为多大？
（2）从计时零点到即将发生第三次碰撞这段过程中，共经过多长时间？
（3）从计时零点到即将发生第 n 次碰撞这段过程中，小球 A 经过的位移大小为多少？

题目分析：

本题是典型的"电场中带电粒子运动 + 弹性碰撞"综合题，核心物理过程包括：

  1. A 球在电场力作用下做匀加速直线运动
  2. A、B 两球发生弹性碰撞（质量相等，速度交换）
  3. 碰撞后 B 球匀速运动，A 球继续加速追赶
  4. 多次碰撞形成周期性规律

整体讲解思路：

  1. 首先明确物理模型：电场加速 + 弹性碰撞
  2. 分析第一次碰撞前：A 球匀加速，B 球静止
  3. 分析碰撞过程：质量相等的弹性碰撞，速度交换
  4. 分析碰撞后：B 球匀速，A 球从静止重新加速
  5. 寻找多次碰撞的时间规律和位移规律

教学说明：

本图示用于帮助学生建立物理情景的直观认识。教师应引导学生按以下步骤观察：

  1. 初始状态：明确电场方向向右，A 球带正电受电场力向右，B 球不带电不受电场力
  1. 受力分析：A 球受电场力 F = qE，加速度 a = F/m = qE/m
  1. 第一次碰撞前：A 球从静止开始匀加速，位移 L 时与 B 碰撞
  • 由运动学公式：v₀² = 2aL，得 v₀ = √(2qEL/m)
  1. 碰撞过程：质量相等的弹性碰撞，速度交换
  • 碰撞前：vA = v₀，vB = 0
  • 碰撞后：vA' = 0，vB' = v₀
  1. 关键结论：第一次碰撞结束瞬间，A 球速度为 0，B 球速度为 v₀ = √(2qEL/m)

教学说明：

本 v-t 图像是理解本题碰撞规律的核心工具。教师应重点引导学生观察：

  1. 第一次碰撞前（0 到 t₁）：
  • A 球：v = at，匀加速直线
  • B 球：v = 0，静止
  • t₁ 时刻：A 球速度达到 v₀
  1. 第一次碰撞后（t₁ 到 t₂）：
  • A 球：从 0 重新加速，v = a(t - t₁)
  • B 球：以 v₀ 匀速运动
  • t₂ 时刻：两球速度相等，发生第二次碰撞
  1. 速度交换规律：
  • 每次碰撞，A、B 速度交换
  • 碰撞时刻：t₁、t₂、t₃...
  • 从 v-t 图可看出时间间隔规律
  1. 时间计算：
  • 第一次碰撞前：L = ½at₁²，得 t₁ = √(2L/a)
  • 第一次到第二次：A 从 0 加速追 B（速度 v₀）
  • 由位移相等：½aΔt² = v₀Δt，得 Δt = 2v₀/a = 2t₁
  • 故 t₂ = t₁ + 2t₁ = 3t₁，t₃ = t₂ + 2t₁ = 5t₁
  1. 第（2）问答案：从 0 到即将第三次碰撞，时间为 t₃ = 5t₁ = 5√(2mL/qE)

教学说明：

本图示用于解决第（3）问，推导第 n 次碰撞时 A 球的位移。教师讲解要点：

  1. 观察碰撞位置规律：
  • 第一次碰撞：x₁ = L = 1²·L
  • 第二次碰撞：x₂ = 4L = 2²·L
  • 第三次碰撞：x₃ = 9L = 3²·L
  1. 归纳通项：
  • 第 n 次碰撞位置：x_n = n²L
  1. 物理推导验证：
  • 时间规律：t₁、t₂ = 3t₁、t₃ = 5t₁、...、t_n = (2n-1)t₁
  • A 球位移：每次碰撞后从静止重新加速
  • 第 n 次碰撞时，A 球总位移等于各段位移之和
  1. 第（3）问答案：

从计时零点到即将发生第 n 次碰撞，小球 A 经过的位移大小为：
x_n = n²L

  1. 完整解答总结：
  • （1）第一次碰撞后：vA = 0，vB = √(2qEL/m)
  • （2）到第三次碰撞前：t = 5√(2mL/qE)
  • （3）到第 n 次碰撞前：x = n²L
