[图示主题与整合说明]

[分步序列]
共 5 个步骤（步骤 0~4），教师可通过「上一步」「下一步」按钮切换：

- 步骤 0（初始状态）：
  显示：上电场线、下电场线、E 标签、轨迹虚线、A 球、B 球、A 球标签、B 球标签、A 球质量"m"、A 球电荷"+q"、B 球质量"m"、距离 L 双向箭头、L 标签
  隐藏：电场力 qE 箭头、qE 标签、速度 v₀ 箭头、v₀ 标签、碰撞后 B 速度箭头、碰撞后 A 速度标签"0"
  说明：展示题目初始条件——匀强电场中两球静止，相距 L

- 步骤 1（A 球受力分析）：
  显示：步骤 0 所有元素 + 电场力 qE 箭头、qE 标签
  隐藏：速度 v₀ 箭头、v₀ 标签、碰撞后 B 速度箭头、碰撞后 A 速度标签"0"
  说明：A 球受电场力 F=qE 作用，方向向右（与电场方向相同）

- 步骤 2（A 球加速运动轨迹）：
  显示：步骤 1 所有元素，电场力 qE 箭头做脉冲动画（透明度 0.3~1 循环）
  隐藏：速度 v₀ 箭头、v₀ 标签、碰撞后 B 速度箭头、碰撞后 A 速度标签"0"
  说明：A 球在电场力作用下向右做匀加速直线运动，轨迹沿虚线

- 步骤 3（第一次碰撞瞬间）：
  显示：上电场线、下电场线、E 标签、轨迹虚线、A 球（移至 x=500 与 B 重合）、B 球、速度 v₀ 箭头（从 A 球心向右）、v₀ 标签、A 球标签、B 球标签、A 球质量"m"、A 球电荷"+q"、B 球质量"m"

  说明：A 球加速至 B 球位置，碰撞前瞬间速度为 v₀

- 步骤 4（碰撞后速度交换）：
  显示：上电场线、下电场线、E 标签、轨迹虚线、A 球（x=500）、B 球（x=500）、碰撞后 B 速度箭头（从 B 球心向右）、v₀ 标签（移至 B 速度箭头上方）、碰撞后 A 速度标签"0"（A 球上方）、A 球标签、B 球标签、A 球质量"m"、A 球电荷"+q"、B 球质量"m"

[标签冲突检查]
列出所有标签及其预计坐标，逐对检查间距：

| 标签名 | 坐标 (x,y) | 备注 |
|--------|-----------|------|
| E | (760,95) | 上电场线右端 |
| A | (200,255) | A 球下方 |
| B | (500,255) | B 球下方 |
| m(A 球) | (185,205) | A 球左上方 |
| +q | (215,205) | A 球右上方 |
| m(B 球) | (485,205) | B 球左上方 |
| L | (350,295) | 距离标注下方 |
| qE | (240,205) | 电场力箭头上方 |
| v₀ | (250,205) | 速度箭头上方 |
| 0 | (200,195) | 碰撞后 A 球上方 |

冲突检查：
- "m(A 球)" (185,205) 与 "+q" (215,205)：水平间距 30px → 无冲突（≥20px）
- "+q" (215,205) 与 "qE" (240,205)：水平间距 25px → 无冲突
- "qE" (240,205) 与 "v₀" (250,205)：水平间距 10px → 潜在冲突！解决方案：步骤 1 显示 qE 时 v₀ 不显示，步骤 3 显示 v₀ 时 qE 不显示，两者不会同时出现
- "A" (200,255) 与 "L" (350,295)：距离 √[(150)²+(40)²]≈155px → 无冲突
- "B" (500,255) 与 "m(B 球)" (485,205)：距离 √[(15)²+(50)²]≈52px → 无冲突
- "E" (760,95) 与其他标签：距离均>200px → 无冲突

结论：通过分步显示策略，所有同时出现的标签间距均≥20px，无重叠冲突。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 内底部左侧 (250,455)，点击后切换到前一个步骤
  - 「下一步」按钮：位于 SVG 内底部右侧 (450,455)，点击后切换到下一个步骤
  - 步骤指示文本：位于 SVG 内底部中央 (400,470)，显示当前步骤说明（如"步骤 1/4：受力分析"）
- 教师操作流程：
  1. 初始加载显示步骤 0，教师讲解题目初始条件（电场、两球位置、电荷分布）
  2. 点击「下一步」到步骤 1，讲解 A 球受电场力 F=qE 作用
  3. 点击「下一步」到步骤 2，讲解 A 球在电场力作用下匀加速运动
  4. 点击「下一步」到步骤 3，讲解碰撞前瞬间 A 球速度 v₀
  5. 点击「下一步」到步骤 4，讲解弹性碰撞后速度交换（A 静止，B 以 v₀ 运动）
  6. 可随时点击「上一步」回退复习关键概念

[技术实现]
- JS 库选择：原生 SVG（简单几何图形首选，无需额外库）
- 画布尺寸：800×500 px（固定）
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │  [上电场线 ===============================► E]  y=100       │
  │                                                             │
  │         m +q                    m                           │
  │     ●───────►qE/v₀            ●───────►v₀                   │
  │   A│←────── L ──────→│B                                      │
  │     └───────────────┘                                       │
  │                                                             │
  │  [下电场线 ===============================►]  y=350         │
  │                                                             │
  │  [轨迹虚线 - - - - - - - - - - - - - - - - - - -]  y=225   │
  │                                                             │
  │  ┌─────────────────────────────────────────────────────┐    │
  │  │  [◀上一步]      步骤 1/4：受力分析      [下一步▶]   │    │
  │  │              (控件栏 y=440~500)                     │    │
  │  └─────────────────────────────────────────────────────┘    │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量（0~4），每个步骤对应一组元素的显示/隐藏状态
  2. 元素分组：将相关元素放入 <g> 组，通过组的 display 属性控制显隐
     - scene1-initial：初始元素（电场线、两球、标签、距离 L）
     - scene1-force：电场力 qE 箭头及标签
     - scene1-velocity：速度 v₀ 箭头及标签
     - scene1-collision：碰撞后状态元素
  3. 动画实现：步骤 2 中电场力箭头使用 CSS animation 或 requestAnimationFrame 实现脉冲效果
  4. 事件绑定：按钮点击事件切换 currentStep，调用 updateDisplay() 函数更新各元素显隐
  5. 按钮禁用逻辑：步骤 0 时禁用「上一步」，步骤 4 时禁用「下一步」
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀
  - scene1-field-line-top：上电场线
  - scene1-field-line-bottom：下电场线
  - scene1-field-label-E：E 标签
  - scene1-trajectory：轨迹虚线
  - scene1-ball-a：A 球
  - scene1-ball-b：B 球
  - scene1-label-a：A 球标签
  - scene1-label-b：B 球标签
  - scene1-label-ma：A 球质量
  - scene1-label-qa：A 球电荷
  - scene1-label-mb：B 球质量
  - scene1-distance-L：距离 L 双向箭头
  - scene1-label-L：L 标签
  - scene1-force-arrow：电场力箭头
  - scene1-force-label：qE 标签
  - scene1-velocity-arrow：速度箭头
  - scene1-velocity-label：v₀ 标签
  - scene1-group-initial：初始状态元素组
  - scene1-group-force：受力分析元素组
  - scene1-group-velocity：速度元素组
  - scene1-btn-prev：上一步按钮
  - scene1-btn-next：下一步按钮
  - scene1-step-indicator：步骤指示文本
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
