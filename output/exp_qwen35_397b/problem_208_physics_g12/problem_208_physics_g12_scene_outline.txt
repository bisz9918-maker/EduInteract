    **题目原文：**

    如图所示，两平行金属板水平放置，板间存在垂直纸面的匀强磁场和电场强度为 E 的匀强电场。金属板右下方以 MN 为上边界，PQ 为下边界，MP 为左边界的区域内，存在垂直纸面向外的匀强磁场，磁场宽度为 d，MN 与下极板等高，MP 与金属板右端在同一竖直线。一个电荷量为 q、质量为 m 的正离子以初速度在两板间沿平行于金属板的虚线射入金属板间。不计粒子重力。

    (1) 已知离子恰好做匀速直线运动，求金属板间的磁感应强度 B₀；

    (2) 若撤去板间磁场 B₀，离子恰好从下极板的右侧边缘射出电场，方向与水平方向成 30°角，离子进入磁场运动后从磁场边界点射出，求该磁场的磁感应强度 B 的大小。

    **题目分析：**

    本题是带电粒子在复合场中运动的综合问题，分为两个物理过程：

    1. **平行板区域**：粒子先在电场 + 磁场的复合场中匀速直线运动（受力平衡），后在纯电场中做类平抛运动
    2. **矩形磁场区域**：粒子以 30°角进入匀强磁场，做匀速圆周运动

    **整体讲解思路：**

    - 第 (1) 问核心：速度选择器原理，电场力与洛伦兹力平衡
    - 第 (2) 问核心：类平抛运动的速度分解 + 磁场中圆周运动的几何关系

    **图示规划说明：**

    共设计 2 个交互式图示：
    - SCENE_1：平行板区域的两种运动状态（复合场平衡 → 纯电场偏转）
    - SCENE_2：矩形磁场中的圆周运动轨迹与几何关系
    </TEXT_1>

    **SCENE_1 教学说明：**

    **状态 0（复合场平衡）讲解要点：**

    1. 引导学生观察粒子做匀速直线运动的条件：合力为零
    2. 受力分析：正离子受电场力 F_E = qE（方向与电场同向，竖直向下）
    3. 洛伦兹力 F_B = qv₀B₀（方向由左手定则判断，竖直向上）
    4. 平衡方程：qE = qv₀B₀，解得 B₀ = E/v₀

    **状态 1（纯电场偏转）讲解要点：**

    1. 撤去磁场后，粒子只受电场力，做类平抛运动
    2. 水平方向：匀速直线运动，v_x = v₀
    3. 竖直方向：匀加速直线运动，a = qE/m

    **状态 2（速度分解）讲解要点：**

    1. 出射时速度方向与水平成 30°角
    2. 速度分解：tan30° = v_y/v₀
    3. 由此可求出射时竖直分速度 v_y = v₀·tan30° = v₀/√3

    **关键公式：**
    - 平衡条件：qE = qv₀B₀
    - 类平抛：v_y = at，y = ½at²
    - 速度偏转：tanθ = v_y/v₀

    **SCENE_2 教学说明：**

    **步骤 0-1（入射与轨迹）讲解要点：**

    1. 粒子进入磁场后，洛伦兹力提供向心力：qvB = mv²/R
    2. 轨迹为圆弧，圆心在速度的垂线上

    **步骤 2（圆心确定）讲解要点：**

    1. 过入射点 M 作速度 v 的垂线（即半径方向）
    2. 由于粒子带正电，磁场向外，由左手定则知洛伦兹力指向右下方
    3. 圆心 O 在 M 点右下方，在 MN 边界上

    **步骤 3（几何关系与出射点）讲解要点：**

    1. 关键几何关系：从圆心 O 向 PQ 作垂线，构成直角三角形
    2. 由几何关系：R·sin30° = d
    3. 解得：R = d/sin30° = 2d

    **完整解答：**

    **第 (1) 问：**
    粒子匀速直线运动，电场力与洛伦兹力平衡：
    - qE = qv₀B₀
    - 解得：B₀ = E/v₀

    **第 (2) 问：**
    1. 类平抛出射时：tan30° = v_y/v₀，得 v_y = v₀/√3
    2. 合速度：v = √(v₀² + v_y²) = v₀/ cos30° = 2v₀/√3
    3. 磁场中圆周运动：qvB = mv²/R
    4. 几何关系：R·sin30° = d，得 R = 2d
    5. 联立解得：B = mv/(qR) = m·(2v₀/√3)/(q·2d) = mv₀/(√3·qd)

    **课堂讲解建议：**
    - 先让学生回顾速度选择器原理（第 1 问）
    - 第 2 问分两阶段：电场偏转求速度 → 磁场偏转找几何关系
    - 强调圆周运动问题中"找圆心、画轨迹、用几何"的三步法
