[图示主题与整合说明]
- 本图示主题：平行金属板间带电粒子的受力与运动分析
- 整合的步骤/概念：第(1)问复合场匀速直线运动（受力平衡）+ 第(2)问纯电场类平抛运动（速度偏转30°）
- 教学价值：教师可通过三状态切换对比展示：①复合场中电场力与洛伦兹力平衡使粒子匀速直线运动；②撤去磁场后粒子在纯电场中做类平抛运动；③出射时速度的矢量分解关系。帮助学生直观理解两种运动模式的受力差异和运动轨迹变化。

[交互方案]
- 交互类型：多状态切换（3个按钮）
- 控件说明：
  - 按钮0"复合场平衡"：位于(150,450)，120×35px，点击显示状态0（受力平衡）
  - 按钮1"纯电场偏转"：位于(340,450)，120×35px，点击显示状态1（抛物线轨迹）
  - 按钮2"速度分解"：位于(530,450)，120×35px，点击显示状态2（速度矢量分解）
- 教师操作流程：
  1. 默认显示状态0，讲解复合场中粒子受力平衡条件：qE=qv₀B₀，推导B₀=E/v₀
  2. 点击"纯电场偏转"，撤去磁场后粒子仅受电场力，做类平抛运动，轨迹为抛物线
  3. 点击"速度分解"，展示出射点速度分解：v_x=v₀，v_y=at，tan30°=v_y/v₀
  4. 教师可反复切换对比两种运动模式，强化学生对复合场与单一场运动差异的理解

[技术实现]
- JS库选择及原因：原生SVG。理由：本场景为2D静态图示+状态切换，无需复杂动画库；SVG便于精确控制坐标、矢量图形清晰、标签文字渲染质量好。
- 画布尺寸：800×500px（固定画布）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +----------------------------------------------------------+
  |                    上金属板(+)                            |
  |   +  +  +  +  +  +  +  电场线向下                         |
  |   v₀→  ──────────────── 轨迹(状态0虚线/状态1红色抛物线)    |
  |                    下金属板(-)                            |
  |                                         右侧磁场区        |
  |                                    MN  ··········        |
  |                                    ·  ·  ·  ·  ·  ·      |
  |                                    ·  ·  ·  ·  ·  · d    |
  |                                    ·  ·  ·  ·  ·  ·      |
  |                                    PQ  ··········        |
  |                                                          |
  |         [复合场平衡]  [纯电场偏转]  [速度分解]            |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量currentState(0/1/2)记录当前状态，点击按钮时更新状态并重绘
  2. 坐标计算：抛物线轨迹用二次贝塞尔曲线或参数方程y=110+k(x-60)²，代入终点(400,140)求k
  3. 速度分解：v箭头长度50px，角度-30°；v₀分量长度=50×cos(30°)≈43.3px
  4. 事件绑定：三个按钮分别绑定onclick事件，调用updateState(0/1/2)函数
  5. 元素显隐：用SVG元素的display属性控制显隐，或动态添加/移除DOM元素
- ID命名规范：所有交互元素ID必须以scene1-为前缀
  - scene1-plate-top, scene1-plate-bottom
  - scene1-label-plus, scene1-label-minus
  - scene1-e-field-1~7, scene1-label-E
  - scene1-velocity-v0, scene1-label-v0
  - scene1-trajectory-0, scene1-particle, scene1-force-Fe, scene1-label-Fe, scene1-force-Fb, scene1-label-Fb
  - scene1-trajectory-1, scene1-exit-point
  - scene1-velocity-v, scene1-label-v, scene1-velocity-v0-comp, scene1-label-v0-comp
  - scene1-angle-arc, scene1-label-angle
  - scene1-mag-boundary-mp, scene1-mag-boundary-mn, scene1-mag-boundary-pq, scene1-mag-boundary-right
  - scene1-mag-dots (组), scene1-label-MN, scene1-label-d
  - scene1-btn-state0, scene1-btn-state1, scene1-btn-state2
- IIFE隔离：所有JS代码包在(function() { ... })()中，避免全局变量污染
