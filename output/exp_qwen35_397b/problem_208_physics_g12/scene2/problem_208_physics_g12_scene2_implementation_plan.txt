[图示主题与整合说明]
- 本图示主题：带电粒子在矩形匀强磁场中的圆周运动轨迹
- 整合的步骤/概念：粒子以 30°角进入磁场 → 圆周运动轨迹 → 圆心与半径确定 → 出射点位置 → 几何关系 R·sin30° = d
- 教学价值：教师可通过分步演示，引导学生理解带电粒子在匀强磁场中做圆周运动的几何分析方法。从入射条件出发，逐步构建轨迹、确定圆心位置、推导半径与磁场宽度的关系，帮助学生建立"速度垂线找圆心"的解题思路，强化几何关系在物理问题中的应用。

[技术实现]
- JS 库选择及原因：原生 SVG
  - 理由：几何图形（线段、圆弧、圆点、箭头）用 SVG 原生元素实现最简洁；无需复杂动画库；CDN 无需引入额外依赖
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |  [+]                                              |
  |  ==== 金属板 ====================================  |
  |  [-]           M____30°____N                      |
  |                  |    · ·    |                     |
  |                  |  ·     ·  |  d                  |
  |                  | ·   O   · |  ↑                  |
  |                  | ·  / | \ · |  |                  |
  |                  | · /   |  \· |  |                  |
  |                  | ·     |   S|  |                  |
  |                  | ·     |    |  |                  |
  |                  | ·     |    |  ↓                  |
  |                  P · · · · · · Q                    |
  |                                                      |
  |              [◀ 上一步] [下一步 ▶]  步骤 X/4         |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-3），每个状态对应一组可见元素 ID 列表
  2. 坐标计算：
     - 圆心 O 坐标：过 M 点作速度垂线，与 MN 延长线交点
     - 速度方向：与水平成 30°向下，单位向量 (cos30°, sin30°) = (√3/2, 1/2)
     - 垂线方向：与速度垂直，方向 (-sin30°, cos30°) = (-1/2, √3/2)
     - 半径 R = d / sin30° = 2d（根据几何关系）
  3. 圆弧绘制：使用 SVG <path> 元素，A 命令绘制圆弧
  4. 事件绑定：按钮点击事件切换状态，更新可见元素 display 属性
  5. 禁用状态：步骤 0 时上一步按钮 disabled，步骤 3 时下一步按钮 disabled
- ID 命名规范：所有交互元素 ID 必须以 scene2- 为前缀
  - scene2-plate-top, scene2-plate-bottom（金属板）
  - scene2-field-rect（磁场区域）
  - scene2-field-dots（磁场点阵）
  - scene2-label-M, scene2-label-N, scene2-label-P, scene2-label-Q
  - scene2-label-d, scene2-label-angle30, scene2-label-v
  - scene2-velocity（速度矢量）
  - scene2-angle-arc（30°角弧）
  - scene2-trajectory（圆周轨迹）
  - scene2-label-S（出射点）
  - scene2-center-O（圆心）
  - scene2-label-O, scene2-label-R
  - scene2-radius-OM, scene2-radius-OS（半径线）
  - scene2-aux-line（辅助线）
  - scene2-formula（公式文本）
  - scene2-btn-prev, scene2-btn-next, scene2-step-indicator（控件）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
