    **题目原文：**

    如图（a），一物块在 t=0 时刻滑上一固定斜面，其运动的 v-t 图线如图（b）所示．若重力加速度 g、斜面的倾角θ及图中的 v₀、v₁、t₁ 均为已知量，求物块与斜面间的动摩擦因数．

    **题目分析：**

    本题是典型的斜面动力学问题，结合运动图像（v-t 图）考查牛顿第二定律的应用。核心在于：
    1. 从 v-t 图像提取上滑和下滑两个阶段的加速度
    2. 对两个阶段分别进行受力分析
    3. 联立方程求解动摩擦因数 μ

    **整体讲解思路：**

    1. 先引导学生观察 v-t 图，识别两个运动阶段：上滑减速（0→t₁）和下滑加速（t₁→3t₁）
    2. 从图像斜率求出两个阶段的加速度大小
    3. 分别画出上滑和下滑时的受力分析图，注意摩擦力方向始终与相对运动方向相反
    4. 列牛顿第二定律方程，联立消去 mgsinθ，解出 μ

    **图示规划说明：**

    - SCENE_1：斜面受力分析对比图，整合上滑和下滑两个状态的受力情况，用分步按钮切换展示
    - SCENE_2：v-t 图像分析，标注两段斜率对应的加速度，用拖拽滑块观察斜率与加速度的关系
    </TEXT_1>

    **教学说明：**

    本图示用于讲解受力分析的核心环节。教师应引导学生注意：

    1. **摩擦力方向的判断**：摩擦力始终与相对运动方向相反
       - 上滑时：物块相对斜面向上运动 → 摩擦力沿斜面向下
       - 下滑时：物块相对斜面向下运动 → 摩擦力沿斜面向上

    2. **力的分解**：重力沿斜面方向和垂直斜面方向分解
       - 沿斜面分力：mgsinθ（始终沿斜面向下）
       - 垂直斜面分力：mgcosθ（与支持力 N 平衡）

    3. **牛顿第二定律方程**：
       - 上滑阶段：mgsinθ + μmgcosθ = ma₁
       - 下滑阶段：mgsinθ - μmgcosθ = ma₂

    4. **关键观察**：两方程中 mgsinθ 符号相同（重力分力方向不变），μmgcosθ 符号相反（摩擦力方向改变）

    <TEXT_3>
    **教学说明：**

    本图示用于从运动图像提取加速度信息。教师应引导学生：

    1. **识别运动阶段**：
       - 0 → t₁：速度从 v₀ 减到 0，上滑减速
       - t₁ → 3t₁：速度从 0 变到 -v₁，下滑加速

    2. **从斜率求加速度**：
       - 上滑加速度大小：a₁ = |Δv/Δt| = v₀/t₁
       - 下滑加速度大小：a₂ = |Δv/Δt| = v₁/(3t₁ - t₁) = v₁/(2t₁)

    3. **联立求解**：
       由牛顿第二定律：
       - 上滑：mgsinθ + μmgcosθ = m·(v₀/t₁)
       - 下滑：mgsinθ - μmgcosθ = m·(v₁/(2t₁))

       两式相减消去 mgsinθ：
       2μmgcosθ = m(v₀/t₁ - v₁/(2t₁))

       解得：
       $$\mu = \frac{v_0/t_1 - v_1/(2t_1)}{2g\cos\theta} = \frac{2v_0 - v_1}{4gt_1\cos\theta}$$

    **完整解答：**

    $$a_1 = \frac{v_0}{t_1}, \quad a_2 = \frac{v_1}{2t_1}$$

    $$mgsin\theta + \mu mgcos\theta = ma_1$$
    $$mgsin\theta - \mu mgcos\theta = ma_2$$

    $$\mu = \frac{2v_0 - v_1}{4gt_1\cos\theta}$$
    </TEXT_3>
