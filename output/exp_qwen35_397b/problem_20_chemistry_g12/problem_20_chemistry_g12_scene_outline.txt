    **题目原文：**
    将 C 棒、Fe 棒平行插人饱和 NaCl 溶液中（如图所示）．下列叙述符合事实的是（  ）

    A．断开 K₂，闭合 K₁时，Fe 电极反应为：2 H⁺+2e⁻=H₂↑
    B．断开 K₂，闭合 K₁时，C 电极反应为：2Cl⁻-2e⁻=Cl₂↑
    C．断开 K₁，闭合 K₂时，Fe 电极反应为：Fe-2e⁻=Fe²⁺
    D．断开 K₁，闭合 K₂时，C 电极反应为：2Cl⁻-2e⁻=Cl₂↑

    **题目分析：**
    本题考查原电池与电解池的工作原理及电极反应式的书写。关键在于判断不同开关状态下装置的类型（原电池或电解池），并确定电极的极性（正负极或阴阳极）。

    **整体讲解思路：**
    1. 首先分析断开 K₂、闭合 K₁时的原电池工作状态
    2. 然后分析断开 K₁、闭合 K₂时的电解池工作状态
    3. 对比两种状态下电极反应的本质区别
    4. 引导学生理解电极材料活性与反应类型的关系

    - SCENE_1：原电池工作状态（K₁闭合、K₂断开）

    **教学说明：**
    本图示展示原电池工作状态，教师应引导学生按以下步骤观察：

    1. **电极极性判断**：Fe 比 C 活泼，Fe 为负极（失电子），C 为正极（得电子）
    2. **电子流向**：电子从负极（Fe）经导线流向正极（C）
    3. **离子迁移**：阳离子（Na⁺）向正极移动，阴离子（Cl⁻）向负极移动
    4. **电极反应式**：
       - 负极（Fe）：Fe - 2e⁻ → Fe²⁺（氧化反应）
       - 正极（C）：2H₂O + O₂ + 4e⁻ → 4OH⁻（还原反应，中性环境）

    **关键公式：**
    - 负极反应：Fe → Fe²⁺ + 2e⁻
    - 正极反应：O₂ + 2H₂O + 4e⁻ → 4OH⁻
    - 总反应：2Fe + O₂ + 2H₂O → 2Fe(OH)₂

    **讲解要点：**
    - 强调原电池自发进行的氧化还原反应
    - 解释为何正极不是 H⁺得电子（中性溶液 H⁺浓度低）
    - 对比选项 A、B 的错误原因

    **教学说明：**
    本图示展示电解池工作状态，教师应引导学生按以下步骤观察：

    1. **电极极性判断**：与电源正极相连的 C 为阳极（失电子），与负极相连的 Fe 为阴极（得电子）
    2. **电子流向**：电子从电源负极流向阴极（Fe），从阳极（C）流回电源正极
    3. **离子迁移**：阳离子（Na⁺）向阴极移动，阴离子（Cl⁻）向阳极移动
    4. **电极反应式**：
       - 阳极（C）：2Cl⁻ - 2e⁻ → Cl₂↑（氧化反应）
       - 阴极（Fe）：2H₂O + 2e⁻ → H₂↑ + 2OH⁻（还原反应）

    **关键公式：**
    - 阳极反应：2Cl⁻ → Cl₂↑ + 2e⁻
    - 阴极反应：2H₂O + 2e⁻ → H₂↑ + 2OH⁻
    - 总反应：2NaCl + 2H₂O → Cl₂↑ + H₂↑ + 2NaOH

    **讲解要点：**
    - 强调电解池需要外加电源驱动非自发反应
    - 解释为何阳极是 Cl⁻放电而非 OH⁻（Cl⁻浓度高）
    - 对比选项 C、D 的正误（D 正确）

    <TEXT_4>
    **总结：**
    **完整解答：**
    - 选项 A 错误：原电池 Fe 为负极，反应为 Fe→Fe²⁺+2e⁻
    - 选项 B 错误：原电池 C 为正极，发生还原反应而非氧化
    - 选项 C 错误：电解池 Fe 为阴极，发生还原反应
    - 选项 D 正确：电解池 C 为阳极，Cl⁻放电生成 Cl₂

    **课堂讲解建议：**
    1. 先让学生独立判断两种状态的装置类型
    2. 通过图示动态展示粒子运动，强化微观理解
    3. 对比原电池与电解池的电极命名规则（正负极 vs 阴阳极）
    4. 强调溶液酸碱性对电极反应的影响（中性环境 H⁺浓度低）
    5. 引导学生总结判断电极反应的一般步骤
