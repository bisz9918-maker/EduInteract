[图示主题与整合说明]
- 本图示主题：原电池工作状态下的电极反应与粒子运动
- 整合的内容：电极极性判断、电子流向、离子迁移方向、电极反应式

[分步序列]
- 初始状态（步骤 0）：显示基础装置
  - 烧杯容器、饱和 NaCl 溶液（虚线液面）
  - C 棒电极（左）、Fe 棒电极（右）
  - 导线系统（顶部横线、左右竖线）
  - 开关 K₁（闭合，绿色）、开关 K₂（断开，红色）
  - 电源符号（与 K₂ 串联）
  - 基础标签："C"、"Fe"、"K₁"、"K₂"

- 步骤 1：标注电极极性
  - 新增：C 电极右侧显示"正极"标签（#c62828 红色高亮）
  - 新增：Fe 电极左侧显示"负极"标签（#c62828 红色高亮）
  - 视觉变化：电极极性文字淡入

- 步骤 2：显示电子流向
  - 新增：顶部导线路径上显示蓝色箭头#1565c0，从 Fe 指向 C
  - 新增：箭头上方标注"e⁻"标签
  - 视觉变化：箭头从左到右动画绘制

- 步骤 3：显示离子迁移
  - 新增：溶液内显示 3 个 Na⁺ 离子（红色圆点#c62828），带箭头指向 C 极
  - 新增：溶液内显示 3 个 Cl⁻ 离子（绿色圆点#2e7d32），带箭头指向 Fe 极
  - 新增："Na⁺"和"Cl⁻"标签
  - 视觉变化：离子圆点脉冲动画，迁移箭头渐变显示

- 步骤 4：显示电极反应式
  - 新增：Fe 电极下方显示反应式"Fe-2e⁻=Fe²⁺"（#757575 灰色）
  - 新增：C 电极下方显示反应式"2H⁺+2e⁻=H₂↑"（#000000 黑色）
  - 视觉变化：反应式从下向上滑入
  - 最终状态：展示完整的原电池工作原理

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：位于 (280,455)，点击回退到前一状态
  - "下一步 ▶"按钮：位于 (440,455)，点击进入下一状态
  - 步骤指示器：位于 (400,470)，显示当前步骤"步骤 X/5"
- 教师操作流程：
  1. 初始状态展示装置结构，讲解电解池基本组成
  2. 点击"下一步"显示电极极性，讲解原电池正负极判断依据
  3. 点击"下一步"显示电子流向，讲解外电路电子移动方向
  4. 点击"下一步"显示离子迁移，讲解内电路离子移动规律（阳离子向正极，阴离子向负极）
  5. 点击"下一步"显示电极反应式，讲解两极的氧化还原反应
  6. 可随时点击"上一步"回退复习关键概念

[技术实现]
- JS 库选择：原生 SVG（适合绘制电化学装置图，几何形状简单，无需复杂动画库）
- 画布尺寸：800 × 500 px（固定画布）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                    K₁  K₂ [电源]                 |  y=40-120 开关区
  |         |==============================|         |  y=80 顶部导线
  |         |                              |         |
  |      [C 棒]                      [Fe 棒]         |  y=160-380 电极区
  |      正极                        负极            |  y=240 极性标签
  |    +-------------------------------+            |
  |    |  ~~~~~ 饱和 NaCl 溶液 ~~~~~   |            |  y=240-390 溶液区
  |    |   ●Na⁺  →        ←  ●Cl⁻     |            |  y=300-370 离子区
  |    +-------------------------------+            |
  |    Fe-2e⁻=Fe²⁺          2H⁺+2e⁻=H₂↑            |  y=400 反应式
  |                                                  |
  |         [◀ 上一步]  步骤 X/5  [下一步 ▶]         |  y=440-490 控件栏
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-4），数组存储每步可见元素 ID 列表
  2. 坐标计算：所有元素使用绝对坐标，SVG viewBox="0 0 800 500"
  3. 动画曲线：使用 CSS transition 实现淡入/滑入效果，duration 300ms
  4. 事件绑定：按钮点击事件切换状态，更新可见元素 display 属性
  5. 离子动画：使用 CSS @keyframes 实现脉冲效果（opacity 0.6→1→0.6）
- ID 命名规范：所有交互元素 ID 以 scene1- 为前缀
  - scene1-beaker（烧杯）
  - scene1-solution（溶液）
  - scene1-electrode-c（C 电极）
  - scene1-electrode-fe（Fe 电极）
  - scene1-wire-top（顶部导线）
  - scene1-switch-k1（开关 K₁）
  - scene1-switch-k2（开关 K₂）
  - scene1-power（电源）
  - scene1-label-c、scene1-label-fe（电极标签）
  - scene1-label-positive、scene1-label-negative（极性标签，步骤 1）
  - scene1-electron-arrow（电子流向箭头，步骤 2）
  - scene1-label-e（电子标签，步骤 2）
  - scene1-ion-na-1/2/3（Na⁺ 离子，步骤 3）
  - scene1-ion-cl-1/2/3（Cl⁻ 离子，步骤 3）
  - scene1-arrow-na、scene1-arrow-cl（离子迁移箭头，步骤 3）
  - scene1-label-na、scene1-label-cl（离子标签，步骤 3）
  - scene1-reaction-fe、scene1-reaction-c（电极反应式，步骤 4）
  - scene1-btn-prev、scene1-btn-next（控件按钮）
  - scene1-step-indicator（步骤指示器）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
