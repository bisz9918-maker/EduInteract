[图示主题与整合说明]
- 本图示主题：三角形穿过正方形的运动过程演示
- 整合内容：整合了题目原图展示的 5 个阶段（左侧→进入→完全进入→离开→右侧），以及重合部分的面积高亮显示
- 教学价值：教师可通过分步控制，逐步讲解三角形穿过正方形过程中重合面积 S 的变化规律，帮助学生理解分段函数图象的形成原因。每个阶段的重合区域用蓝色高亮，直观展示面积变化趋势。

[分步序列]
- 初始状态（步骤0）：三角形在正方形左侧，底边与基线对齐，三角形右顶点接触正方形左边界。无重合区域高亮。显示阶段标签"初始"。
- 步骤1：点击「下一步」→ 三角形向右移动至部分进入正方形。重合部分为小三角形（蓝色高亮）。显示阶段标签"进入"。重合区域顶点：(350,300)、(350, 300-三角形进入宽度×tan60°)、(350+进入宽度, 300)。
- 步骤2：点击「下一步」→ 三角形完全进入正方形内部，底边与正方形底边重合。重合部分为整个三角形（蓝色高亮）。显示阶段标签"完全进入"。显示面积标注"S = √3/4（最大值）"于三角形顶点上方。
- 步骤3：点击「下一步」→ 三角形开始离开正方形，部分仍在内部。重合部分为剩余三角形（蓝色高亮）。显示阶段标签"离开"。
- 步骤4：点击「下一步」→ 三角形完全离开正方形，位于右侧。无重合区域高亮。显示阶段标签"离开完成"。面积标注隐藏。

[标签冲突检查]
- 标签"初始"：坐标(255,330)
- 标签"进入"：坐标(350,330)
- 标签"完全进入"：坐标(425,330)
- 标签"离开"：坐标(500,330)
- 标签"离开完成"：坐标(575,330)
- 标签"S = √3/4（最大值）"：坐标(425,140)

冲突检查：
- "初始"与"进入"间距：95px → 无冲突
- "进入"与"完全进入"间距：75px → 无冲突
- "完全进入"与"离开"间距：75px → 无冲突
- "离开"与"离开完成"间距：75px → 无冲突
- 面积标注(425,140)与三角形顶点(425,170)间距：30px → 无冲突
- 面积标注与正方形上边界(y=150)间距：10px → 需调整至 y=130

解决方案：面积标注调整至 y=130，确保与正方形上边界有 20px 间距。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于 (320,450)，点击后退到前一阶段
  - 「下一步 ▶」按钮：位于 (410,450)，点击前进到下一阶段
  - 步骤指示器：位于 (400,420)，显示当前步骤编号
- 教师操作流程：
  1. 初始状态展示题目情境
  2. 点击「下一步」讲解进入阶段，重合面积从 0 开始增加
  3. 点击「下一步」讲解完全进入阶段，面积达到最大值 √3/4
  4. 点击「下一步」讲解离开阶段，面积开始减小
  5. 点击「下一步」讲解离开完成，面积归零
  6. 可随时点击「上一步」回退复习

[技术实现]
- JS 库选择及原因：原生 SVG。理由：几何图形简单，SVG 便于精确控制坐标和透明度，无需额外库依赖。
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |                    S = √3/4                      |
  |         ▲           ┌────────┐                   |
  |        / \          │        │                   |
  |       /   \         │        │                   |
  |      /     \        │        │                   |
  |     /       \       │        │                   |
  |    /_________\______│________│_______            |
  |   ← 初始  进入 完全进入  离开  离开完成 →        |
  |                                                  |
  |              [◀ 上一步] [下一步 ▶]               |
  |                  步骤 1/5                        |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量（0-4），每次点击按钮更新状态并重绘
  2. 坐标计算：三角形顶点坐标根据步骤动态计算，重合区域使用多边形裁剪或手动计算交点
  3. 动画曲线：使用 CSS transition 实现平滑移动（可选）
  4. 事件绑定：按钮点击事件绑定到状态更新函数
  5. 重合区域计算：
     - 步骤1：进入宽度 = 三角形右边界 - 正方形左边界，重合为小三角形
     - 步骤2：重合为整个三角形
     - 步骤3：剩余宽度 = 正方形右边界 - 三角形左边界，重合为小三角形
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀（如 scene1-square、scene1-triangle、scene1-overlay、scene1-btn-prev、scene1-btn-next）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
