[图示主题与整合说明]
- 本图示主题：三角形分类对比展示
- 整合的内容：按大小分类的两种三角形类型对比——4 个小三角形（△ADE、△BDF、△CEF、△DEF）与 1 个大三角形（△ABC）
- 教学价值：教师可通过状态切换引导学生理解分类计数逻辑——先数最小单元三角形（4 个），再识别整体大三角形（1 个），最后汇总（5 个），帮助学生建立系统计数思维，避免遗漏或重复

[视觉元素清单]
- 左侧小三角形组：4 个独立 path 元素，分别填充不同颜色（透明度 25%），位置精确对应原图结构
  - △ADE：顶点 (180,80), (140,180), (220,180)，填充 #1565c0，opacity 0.25
  - △BDF：顶点 (100,220), (60,360), (180,360)，填充 #2e7d32，opacity 0.25
  - △CEF：顶点 (260,220), (200,360), (320,360)，填充 #c62828，opacity 0.25
  - △DEF：顶点 (140,180), (220,180), (180,280)，填充 #f9a825，opacity 0.25
- 右侧大三角形：1 个 path 元素，仅描边无填充，顶点 (620,80), (480,360), (740,360)，描边 #1565c0 3px
- 标题文本：左右各一个，黑色 18px 加粗
- 计数标签：左右各一个，黑色 16px；汇总标签仅在状态 3 显示，黑色 20px 加粗
- 颜色/样式沿用 spec 中声明：小三角 1 #1565c0 / 小三角 2 #2e7d32 / 小三角 3 #c62828 / 小三角 4 #f9a825 / 大三角轮廓 #1565c0

[分步序列]
- 初始状态（步骤 0）：显示左右分栏框架、标题，左侧 4 个小三角形半透明填充，右侧空白
- 状态 1（点击按钮 1）：仅左侧 4 个小三角形可见（半透明填充），右侧隐藏；显示标签「最小三角形：4 个」
- 状态 2（点击按钮 2）：左侧隐藏，仅右侧大三角形轮廓可见（#1565c0 3px 描边）；显示标签「最大三角形：1 个」
- 状态 3（点击按钮 3）：左右同时显示，左侧 4 个小三角 + 右侧大三角轮廓；显示汇总标签「共 5 个三角形，答案选 A」

[标签冲突检查]
- 标签「小三角形」：坐标 (180, 40)
- 标签「大三角形」：坐标 (620, 40)
- 标签「最小三角形：4 个」：坐标 (180, 400)
- 标签「最大三角形：1 个」：坐标 (620, 400)
- 标签「共 5 个，选 A」：坐标 (400, 460)
- 按钮文本「状态 1/2/3」：坐标 (320, 468), (420, 468), (520, 468)

冲突检查：
- 「小三角形」与「大三角形」：水平间距 440px → 无冲突
- 「最小三角形：4 个」与「最大三角形：1 个」：水平间距 440px → 无冲突
- 汇总标签与按钮：垂直间距 20px（460 vs 450+18）→ 需调整汇总标签 y=425，按钮 y=450
- 修正后：汇总标签 (400, 425)，按钮 (280/380/480, 450)，垂直间距 25px → 无冲突

[交互方案]
- 交互类型：多状态切换（3 个按钮）
- 控件说明：
  - 按钮 1「小三角」：位于 (280, 450)，点击显示状态 1
  - 按钮 2「大三角」：位于 (380, 450)，点击显示状态 2
  - 按钮 3「总计」：位于 (480, 450)，点击显示状态 3
- 教师操作流程：
  1. 初始展示左右分栏框架
  2. 点击「小三角」引导学生数出 4 个最小单元三角形
  3. 点击「大三角」引导学生识别整体大三角形
  4. 点击「总计」汇总答案，强化分类计数思维

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  [小三角形标题]              [大三角形标题]       |
  |                                                  |
  |  [4 个小三角半透明填充]      [大三角轮廓]         |
  |                                                  |
  |  [最小三角形：4 个]          [最大三角形：1 个]   |
  |                                                  |
  |              [共 5 个，选 A]（状态 3 显示）        |
  |                                                  |
  |        [状态 1]  [状态 2]  [状态 3]（底部按钮）   |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  - 状态机设计：用 currentState 变量（1/2/3）跟踪当前状态
  - 元素分组：左侧小三角组用 g 元素包裹，右侧大三角单独 path，便于整体显示/隐藏
  - 事件绑定：三个按钮分别绑定 click 事件，调用 setState(n) 函数
  - 状态切换逻辑：setState 函数根据状态值设置各组的 display 属性
  - 标签动态更新：根据状态显示对应计数标签
- ID 命名规范：
  - scene2-group-small（左侧小三角组）
  - scene2-path-large（右侧大三角）
  - scene2-label-small-count（左侧计数标签）
  - scene2-label-large-count（右侧计数标签）
  - scene2-label-total（汇总标签）
  - scene2-btn-state1/2/3（三个按钮）
  - scene2-title-left/right（左右标题）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局污染
