[图示主题与整合说明]
- 本图示主题：节数与总长度的函数关系验证
- 整合的内容：整合了特殊值验证（n=1,2,3,100）和线性函数图像，展示公式 L=1.7n+0.8 的正确性
- 教学价值：教师可通过此图示逐步展示链条节数与总长度的线性关系，通过描点、连线、验证的过程，帮助学生理解从特殊到一般的数学归纳思想，最终确认 100 节链条长度为 170.8cm（答案 C）

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - "上一步"按钮：位于 SVG 内底部 (320, 455)，80×30px，步骤 0 时禁用，步骤>0 时可点击回退
  - "下一步"按钮：位于 SVG 内底部 (400, 455)，80×30px，步骤<4 时可点击前进，步骤 4 时禁用
- 教师操作流程：
  1. 初始展示坐标系，介绍横纵轴含义
  2. 点击"下一步"展示 n=1,2,3 的实测数据点，讲解特殊值
  3. 点击"下一步"绘制函数直线，说明三点共线验证线性关系
  4. 点击"下一步"标记 n=100 的预测点，展示辅助线读取纵坐标
  5. 点击"下一步"显示结论，确认答案 C

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（坐标系、点、直线、虚线），无需复杂库；原生 SVG 轻量且易于精确控制坐标
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [800×500 画布]
  +--------------------------------------------------+
  |  [标题] 节数与总长度关系          [结论框]        | y=0-50
  |                                                  |
  |  L(cm)    +------------------+  L=1.7n+0.8      | y=50-100
  |    200 -  |                  |  * (100,170.8)   |
  |    150 -  |------------------|----·-------------| y=150
  |           |               ·  |   /              |
  |    100 -  |------------·-----|--/---------------| y=255
  |     50 -  |------·-----·--·--|-/----------------| y=343
  |      0 -  +------|-----|-----|/--------------> n | y=430
  |           0     50    100                        |
  |                                                  |
  |              [◀上一步] [下一步▶]                 | y=450-490
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 step 变量 (0-4) 跟踪当前步骤，每个步骤对应一组可见元素
  2. 坐标映射函数：
     - x(n) = 90 + n * (650/110) = 90 + n * 5.91
     - y(L) = 430 - L * (350/200) = 430 - L * 1.75
  3. 元素可见性控制：每个元素设置 id，通过 display 属性控制显示/隐藏
  4. 按钮状态：步骤 0 禁用"上一步"，步骤 4 禁用"下一步"
  5. 动画效果：点和直线出现时使用淡入动画（opacity 0→1，300ms）
- ID 命名规范：所有元素 ID 以 scene2- 为前缀
  - scene2-axis-x, scene2-axis-y
  - scene2-grid-50, scene2-grid-100, scene2-grid-150
  - scene2-point-1, scene2-point-2, scene2-point-3, scene2-point-100
  - scene2-label-1, scene2-label-2, scene2-label-3, scene2-label-100
  - scene2-line-func, scene2-label-formula
  - scene2-dash-v, scene2-dash-h
  - scene2-conclusion-box
  - scene2-btn-prev, scene2-btn-next
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
