[图示主题与整合说明]
- 本图示主题：正方形与垂线构造的全等三角形证明
- 整合内容：基础图形展示、已知条件标注、角度关系分析、全等证明、对应边相等结论、EF 长度计算
- 教学价值：本题是典型的多步骤几何证明题，通过分步导航让教师可灵活控制讲解节奏。从已知条件出发，逐步展示角度关系推导、全等三角形判定（AAS）、对应边相等，最终得出 EF=7 的结论。教师可在任意步骤暂停讲解，或回退复习关键推理环节。

[分步序列]
共 7 个状态（步骤 0-6），教师可通过「上一步」「下一步」按钮切换：

步骤 0（初始状态）：
- 显示：正方形 ABCD、直线 a、垂线段 DE 和 BF、直角标记（E 和 F 处）、所有顶点标签 A,B,C,D,E,F、直线标签 a
- 隐藏：所有长度标注、角度弧线、三角形高亮、EF 线段
- 画面呈现题目基础图形，等待教师开始讲解

步骤 1（标注已知条件）：
- 新增显示：DE=4 标注在 DE 线段右侧 (470,200)，BF=3 标注在 BF 线段左侧 (270,300)
- 其他元素保持步骤 0 状态
- 教师讲解：题目给出 DE=4，BF=3，求 EF 长度

步骤 2（分析△AED）：
- 新增显示：△AED 区域蓝色半透明填充，∠AED=90° 标注在 E 点左下 (430,185)
- 高亮：∠DAE 和 ∠ADE 的角度弧线（红色）
- 显示文字：∠DAE+∠ADE=90° 在图示上方空白处 (400,80)
- 教师讲解：在 Rt△AED 中，两锐角互余

步骤 3（分析△BFA）：
- 新增显示：△BFA 区域绿色半透明填充，∠BFA=90° 标注在 F 点右下 (310,305)
- 高亮：∠BAF 和 ∠ABF 的角度弧线（红色）
- 显示文字：∠BAF+∠ABF=90° 在图示上方空白处 (400,100)
- 教师讲解：在 Rt△BFA 中，两锐角互余

步骤 4（证明角相等）：
- 保持：两个三角形高亮填充
- 新增显示：∠DAE=∠ABF 标注（用相同颜色弧线强调），∠ADE=∠BAF 标注
- 显示文字：∠DAB=90°（正方形内角）→ ∠DAE+∠BAF=90°，结合步骤 2、3 得 ∠DAE=∠ABF
- 教师讲解：利用正方形直角和互余关系，推导对应角相等

步骤 5（全等结论与对应边）：
- 保持：两个三角形高亮
- 新增显示：全等结论 "△AED≌△BFA (AAS)" 在图示顶部中央 (400,50)
- 新增显示：AE=BF=3 标注在 AE 上方 (340,200)，AF=DE=4 标注在 AF 下方 (350,280)
- 教师讲解：由 AAS 判定全等，对应边相等，得 AE=3，AF=4

步骤 6（计算 EF）：
- 新增显示：EF 线段红色加粗 3px，从 E(445,175) 到 F(295,315)
- 新增显示：EF=AE+AF=3+4=7 标注在 EF 上方 (380,180)，红色加粗字体
- 高亮：最终答案 "7" 用红色框突出
- 教师讲解：EF 由 AE 和 AF 组成，代入数值得 EF=7

[标签冲突检查]
所有标签坐标及间距检查：

| 标签名 | 坐标 (x,y) | 相邻标签 | 间距计算 | 是否冲突 |
|--------|-----------|----------|---------|---------|
| A | (370,225) | B(365,345) | √[(5)²+(120)²]≈120px | 否 |
| A | (370,225) | D(495,225) | 125px | 否 |
| B | (365,345) | F(295,330) | √[(70)²+(15)²]≈72px | 否 |
| C | (495,345) | D(495,225) | 120px | 否 |
| D | (495,225) | E(445,160) | √[(50)²+(65)²]≈82px | 否 |
| E | (445,160) | DE=4(470,200) | √[(25)²+(40)²]≈47px | 否 |
| F | (295,330) | BF=3(270,300) | √[(25)²+(30)²]≈39px | 否 |
| DE=4 | (470,200) | ∠AED=90°(430,185) | √[(40)²+(15)²]≈43px | 否 |
| BF=3 | (270,300) | ∠BFA=90°(310,305) | 40px | 否 |
| AE=3 | (340,200) | AF=4(350,280) | √[(10)²+(80)²]≈81px | 否 |
| EF=7 | (380,180) | AE=3(340,200) | √[(40)²+(20)²]≈45px | 否 |
| 全等结论 | (400,50) | 角度和文字 (400,80) | 30px | 否 |

冲突解决方案：
- 所有标签间距均≥30px，满足≥20px 的最小间距要求
- 点标签均放在顶点外侧，不进入图形内部
- 数值标注均放在线段侧面偏移位置，不压在线段上
- 步骤 2-6 新增元素按顺序显示，不会同时拥挤

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 内底部左侧 (320,460)，80×30px，点击后切换到前一状态（步骤 0 时禁用）
  - 「下一步」按钮：位于 SVG 内底部中央 (400,460)，80×30px，点击后切换到后一状态（步骤 6 时禁用）
  - 步骤指示器：位于右侧 (480,465)，显示当前步骤 "步骤 X/6"
- 教师操作流程：
  1. 图示加载后显示步骤 0（基础图形）
  2. 点击「下一步」逐步展示已知条件、角度分析、全等证明、对应边、最终计算
  3. 可随时点击「上一步」回退复习关键推理环节
  4. 在任意步骤暂停，配合口头讲解该步骤的几何关系

[技术实现]
- JS 库选择：原生 SVG
  - 原因：本题为平面几何图形，元素数量适中（约 20 个 SVG 元素），原生 SVG 足够胜任，无需引入 D3 等重型库；SVG 标签语义清晰，便于按 ID 操作各元素显示/隐藏

- 画布尺寸：800×500 px（固定）

- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |                    直线 a                         |
  |              E ●───────● A                       |
  |               ╲        │ ╲                       |
  |                ╲       │  ╲                      |
  |                 ╲ △AED │   ╲ D                   |
  |                  ╲     │    ●────────────● C     |
  |                   ╲    │    │            │       |
  |              F ●────● B │    │  正方形   │       |
  |                 ╲△BFA  │    │            │       |
  |                  ╲     │    └────────────┘       |
  |                   ╲    │                          |
  |                    ╲   │                          |
  |                     ╲  │                          |
  |                      ╲ │                          |
  |                       ╲│                          |
  |                                                  |
  |        [◀上一步]  [下一步▶]   步骤 X/6            |
  +--------------------------------------------------+
  ```

- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-6），每个状态对应一个配置对象，定义该状态下哪些元素 visible:true/false
  2. 元素 ID 命名：所有元素 ID 以 scene1- 为前缀，如 scene1-square、scene1-line-a、scene1-de、scene1-bf、scene1-label-a 等
  3. 显示控制：每个状态切换时，遍历所有元素，根据状态配置设置 display 属性（inline 或 none）
  4. 按钮状态：步骤 0 时禁用「上一步」，步骤 6 时禁用「下一步」，用 opacity:0.5 和 pointer-events:none 表示禁用
  5. 动画效果：状态切换时可用 CSS transition 实现淡入淡出（opacity 从 0 到 1，时长 300ms）
  6. IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染

- ID 命名规范（所有元素必须以 scene1- 前缀）：
  - scene1-square（正方形路径）
  - scene1-line-a（直线 a）

  - scene1-bf（垂线段 BF）
  - scene1-rect-e、scene1-rect-f（直角标记）
  - scene1-label-a/b/c/d/e/f（顶点标签）
  - scene1-label-a-line（直线 a 标签）
  - scene1-label-de4、scene1-label-bf3（已知长度）
  - scene1-label-ae90、scene1-label-bf90（直角标注）
  - scene1-arc-dae、scene1-arc-abf、scene1-arc-ade、scene1-arc-baf（角度弧线）
  - scene1-tri-aed、scene1-tri-bfa（三角形高亮填充）
  - scene1-label-ae3、scene1-label-af4（对应边标注）
  - scene1-label-congruent（全等结论文字）
  - scene1-ef-line（EF 结果线段）
  - scene1-label-ef7（EF 长度标注）
  - scene1-btn-prev、scene1-btn-next（控制按钮）

