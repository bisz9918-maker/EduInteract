[图示主题与整合说明]
- 本图示主题：二次函数 y = x² - 2x - 3 的性质综合展示
- 整合的步骤/概念：对称轴 x=1、顶点 (1,-4)、区间 [0,2] 高亮、函数值范围 [-4,-3)、x>1 单调递增趋势
- 教学价值：教师可逐步展示二次函数的核心性质，从对称性到最值再到单调性，帮助学生建立完整的函数认知框架。通过视觉高亮和动画箭头，直观呈现抽象的函数性质。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 按钮 "◀ 上一步"：位置 (320,465)，尺寸 100×40px，点击后退到前一状态
  - 按钮 "下一步 ▶"：位置 (480,465)，尺寸 100×40px，点击前进到下一状态
  - 状态指示器：位置 (400,445)，显示 "步骤 X / 4"
- 教师操作流程：
  1. 初始展示抛物线基本形态和交点
  2. 点击"下一步"展示对称轴，讲解二次函数对称性
  3. 点击"下一步"标注顶点，讲解最值
  4. 点击"下一步"高亮区间 [0,2]，讲解定义域与值域关系
  5. 点击"下一步"展示函数值范围
  6. 点击"下一步"高亮 x>1 区域和递增箭头，讲解单调性
  7. 可随时点击"上一步"回退复习

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript。原因：二次函数曲线可用 SVG path 精确绘制，无需 D3 等重型库；交互简单，原生 JS 足够；文件体积小，加载快。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                    y                             |
  |                    |                             |
  |           \        |        /                    |
  |            \       |       /                     |
  |             \      |      /                      |
  |              \     |     /                       |
  |---------------A----O----B------------------x     |
  |                \   |   /                         |
  |                 \  |  /                          |
  |                  \ | /                           |
  |                   \|/ C                          |
  |                    V 顶点                        |
  |                                                  |
  |  -4≤y<-3                    x>1 时 y 随 x 增大   |
  |                                                  |
  |              [步骤 0/4]                          |
  |         [◀ 上一步]    [下一步 ▶]                 |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentState (0-4) 跟踪当前步骤，数组 steps 存储每步需显示的元素 ID
  2. 坐标计算：数学坐标 (x,y) 到画布坐标 (canvasX, canvasY) 的映射函数：
     - canvasX = 400 + x * 80
     - canvasY = 250 - y * 40
  3. 抛物线路径：用 SVG path 的 Q 或 C 命令绘制，或分段直线逼近（每 0.1 单位一个点）
  4. 动画曲线：使用 CSS transition 实现淡入效果（opacity 0→1，duration 0.3s）
  5. 事件绑定：按钮点击事件切换状态，更新元素 display/opacity 属性
- ID 命名规范：所有元素 ID 以 scene3- 为前缀，例如：
  - scene3-parabola（抛物线）
  - scene3-axis-x（x 轴）
  - scene3-axis-y（y 轴）
  - scene3-sym-axis（对称轴）
  - scene3-vertex（顶点标记）
  - scene3-interval-rect（区间填充矩形）
  - scene3-increase-area（递增区域填充）
  - scene3-increase-arrow（递增箭头）
  - scene3-label-*（各类标签）
  - scene3-btn-prev（上一步按钮）
  - scene3-btn-next（下一步按钮）
  - scene3-step-indicator（步骤指示器）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
