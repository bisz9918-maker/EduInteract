[图示主题与整合说明]
- 本图示主题：面积割补法——揭示 S₁ 与 S₂ 的等量关系
- 整合的内容：△OAD 面积、△OBC 面积、梯形 ABCD 面积 S₁、△OAB 面积 S₂、面积等量关系推导
- 教学价值：教师通过逐步的面积割补演示，直观展示 S₁=S₂ 的推导过程。学生可以清晰看到：S₂ = S△OAD + S梯形ABCD - S△OBC，而 S△OAD = S△OBC = ½k，因此 S₂ = S梯形ABCD = S₁，得出比值为 1:1。

[分步序列]
- 步骤 0（初始状态）：显示完整基础图形
  - 坐标系、反比例曲线 y=k/x
  - 点 A、B、C、D 及所有连线（OA、OB、AB、AD、BC）
  - 梯形 ABCD 虚线边框
  - 标签 O、A、B、C、D、x、y、y=k/x
  - 不显示任何填充区域和面积标注

- 步骤 1：填充△OAD
  - 显示△OAD 区域，蓝色半透明填充 (#1565c0, 20%)
  - 在△OAD 内部 (130,300) 显示标签 "½k"
  - 其他元素保持不变

- 步骤 2：填充△OBC
  - 显示△OBC 区域，绿色半透明填充 (#2e7d32, 20%)
  - 在△OBC 内部 (220,240) 显示标签 "½k"
  - △OAD 保持显示
  - 其他元素保持不变

- 步骤 3：显示面积相等关系
  - 保持步骤 2 的所有填充
  - 在画布右侧空白区 (550,200) 显示文字："S△OAD = S△OBC = ½k"
  - 用箭头或高亮强调两个三角形面积相等

- 步骤 4：填充△OAB 并显示面积割补公式
  - 显示△OAB 区域，红色半透明填充 (#c62828, 20%)
  - 在△OAB 内部 (260,280) 显示标签 "S₂"
  - 在画布右侧 (520,280) 显示公式："S₂ = S△OAD + S₁ - S△OBC"
  - 梯形区域 (280,160) 显示标签 "S₁"

- 步骤 5：得出结论
  - 保持所有填充区域
  - 在画布中央偏下 (350,380) 显示结论："S₁ = S₂"
  - 在结论下方显示："S₁ : S₂ = 1 : 1"
  - 用醒目颜色（如深红色）突出显示最终答案

[交互方案]
- 交互类型：分步按钮导航
- 控件说明：
  - 「◀ 上一步」按钮：位于 SVG 内底部左侧 (20,460)，点击返回上一状态
  - 「下一步 ▶」按钮：位于 SVG 内底部右侧 (680,460)，点击进入下一状态
  - 步骤指示器：位于底部中央 (380,465)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始展示完整图形，让学生观察题目条件
  2. 点击「下一步」填充△OAD，讲解反比例函数上任意点与坐标轴围成三角形面积为 ½k
  3. 点击「下一步」填充△OBC，强调两个三角形面积相等
  4. 点击「下一步」显示面积相等关系文字，巩固概念
  5. 点击「下一步」填充△OAB 并显示割补公式，展示 S₂ 的构成
  6. 点击「下一步」得出 S₁=S₂ 结论，完成证明
  7. 可随时点击「上一步」回退复习关键步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单，无需复杂库；SVG 便于精确控制坐标和填充；原生 JS 足够实现分步状态切换
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  | y                                                |
  | ↑                                    y=k/x       |
  | |                              曲线               |
  | D●━━━━━━━━━━━━━━━━A●                              |
  | |               ╱  │ ╲                           |
  | |  ½k         ╱     │   ╲ B●                     |
  | C●━━━━━━━━━━●━━━━━━━│━━━━━●  ½k                 |
  | | ╲       ╱   │      │  ╱  │                     |
  | |   ╲   ╱     │      │╱ S₂ │                     |
  | |     ●───────│──────●    │  S₁                  |
  | O─────────────┴──────────────→ x                 |
  |                                                    |
  |              [步骤指示器]                          |
  |     [◀ 上一步]              [下一步 ▶]             |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-5) 跟踪当前步骤，数组存储每步的可见元素 ID 列表
  2. 坐标计算：所有坐标硬编码，确保与布局表一致
  3. 动画曲线：填充区域使用 CSS transition，opacity 从 0 到 1，duration 300ms
  4. 事件绑定：按钮点击事件绑定到 stepChange 函数，更新 currentStep 并刷新 DOM 可见性
  5. 元素显隐：每步通过 getElementById 控制 display 或 opacity 属性
- ID 命名规范：所有元素 ID 以 scene2- 为前缀
  - scene2-axis-x, scene2-axis-y
  - scene2-curve
  - scene2-point-a, scene2-point-b, scene2-point-c, scene2-point-d
  - scene2-label-o, scene2-label-a, scene2-label-b, scene2-label-c, scene2-label-d
  - scene2-tri-oad, scene2-tri-obc, scene2-tri-oab
  - scene2-label-s1, scene2-label-s2
  - scene2-label-halfk-oad, scene2-label-halfk-obc
  - scene2-formula-relation, scene2-conclusion
  - scene2-btn-prev, scene2-btn-next, scene2-step-indicator
- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染
