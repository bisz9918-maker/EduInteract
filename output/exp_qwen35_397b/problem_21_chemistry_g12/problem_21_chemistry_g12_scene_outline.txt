    **题目原文：**

    如图所示，a、b是两根石墨棒．下列叙述正确的是（  ）

    A．a为阳极，发生氧化反应：锌为负极被还原

    B．电路中电子流动方向：锌→b→a→铜

    C．电路中通过0.2mol电子，铜片上产生2.24L气体

    D．往滤纸上滴加酚酞，b极附近颜色变红

    **题目分析：**

    本题是原电池与电解池的组合装置题。左侧锌-铜-稀硫酸构成原电池，右侧石墨棒a、b与饱和食盐水构成电解池。

    **整体讲解思路：**

    1. 首先判断装置类型：左侧为原电池，右侧为电解池
    2. 确定电极极性：锌为负极，铜为正极；a为阳极，b为阴极
    3. 分析电子流动方向：外电路中从负极流向正极
    4. 分析各电极反应及现象
    5. 逐一验证选项

    - SCENE_1：装置结构与电极极性判断（整合原电池/电解池识别、电极命名）
    - SCENE_2：电子与离子流动方向（整合外电路电子流、内电路离子移动）
    - SCENE_3：电极反应与实验现象（整合各电极反应式、酚酞变色现象）

    **教学说明：**

    本图示帮助学生建立装置的整体认知框架。

    **讲解要点：**

    1. **判断装置类型**
       - 左侧：锌、铜两种活泼性不同的金属插入电解质溶液，无外接电源 → 原电池
       - 右侧：两根惰性电极（石墨）插入电解质，由原电池供电 → 电解池

    2. **原电池电极判断**
       - 锌比铜活泼 → 锌为负极（失电子，氧化反应）
       - 铜为正极（得电子，还原反应）

    3. **电解池电极判断**
       - a与原电池负极（锌）相连 → a为阳极
       - b与原电池正极（铜）相连 → b为阴极

    **关键公式：**
    - 原电池负极：$Zn - 2e^- = Zn^{2+}$（氧化反应）
    - 原电池正极：$2H^+ + 2e^- = H_2↑$（还原反应）

    <TEXT_3>
    **教学说明：**

    本图示重点突破电子流动方向这一易错点。

    **讲解要点：**

    1. **电子流动规律**
       - 电子只在外电路（导线）中流动，不能通过电解质溶液
       - 电子从原电池负极流出 → 电解池阳极 → 电解池阴极 → 原电池正极

    2. **正确方向**
       - 锌（负极）→ 导线 → a（阳极）
       - b（阴极）→ 导线 → 铜（正极）
       - **错误选项B分析**：电子不能从b→a（溶液中无电子流动）

    3. **离子移动规律**
       - 原电池：阳离子向正极移动，阴离子向负极移动
       - 电解池：阳离子向阴极移动，阴离子向阳极移动

    **关键提醒：**
    - 电子流动方向与电流方向相反
    - 溶液中靠离子移动导电，不是电子

    **教学说明：**

    本图示用于最终验证各选项，得出正确答案。

    **各电极反应：**

    1. **锌电极（原电池负极）**
       - 反应：$Zn - 2e^- = Zn^{2+}$
       - 类型：氧化反应
       - **A选项错误**：锌为负极但被氧化（不是被还原）

    2. **铜电极（原电池正极）**
       - 反应：$2H^+ + 2e^- = H_2↑$
       - 现象：产生氢气气泡
       - **C选项错误**：未说明标准状况，无法确定气体体积

    3. **a电极（电解池阳极）**
       - 反应：$2Cl^- - 2e^- = Cl_2↑$
       - 类型：氧化反应

    4. **b电极（电解池阴极）**
       - 反应：$2H_2O + 2e^- = H_2↑ + 2OH^-$
       - 现象：产生$OH^-$，溶液呈碱性
       - **D选项正确**：酚酞遇碱变红，b极附近颜色变红

    **完整解答：**

    正确答案：**D**

    **课堂讲解建议：**
    - 先让学生独立判断装置类型和电极极性
    - 用SCENE_2强调电子不能通过溶液这一关键点
    - 用SCENE_3的酚酞变色现象直观验证D选项
    - 提醒学生注意C选项的陷阱（缺少标准状况条件）
