[图示主题与整合说明]
- 本图示主题：原电池 - 电解池组合装置的电极极性判断
- 整合的内容：装置结构识别、原电池正负极判断、电解池阴阳极判断、电极材料标注
- 教学价值：教师可逐步引导学生从原电池（左侧 Zn-Cu-稀硫酸）分析到电解池（右侧 a-b 石墨棒 - 饱和食盐水），理解电子流动方向与电极极性的关系。通过分步高亮，学生能清晰看到：锌为负极→铜为正极→a 为阳极→b 为阴极的逻辑链条。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 按钮"上一步"：位置 (320,465)，宽 80px，高 30px，点击后返回前一状态
  - 按钮"下一步"：位置 (420,465)，宽 80px，高 30px，点击后进入下一状态
  - 状态指示器：位置 (520,470)，显示"步骤 X/4"
- 教师操作流程：
  1. 初始展示原始装置图，让学生观察整体结构
  2. 点击「下一步」，高亮左侧原电池区域，讲解锌为负极（失电子）、铜为正极（H+得电子）
  3. 点击「下一步」，高亮右侧电解池区域，讲解 a 为阳极（Cl-失电子）、b 为阴极（H+得电子）
  4. 点击「下一步」，移除高亮框，保留极性标注，总结完整电极极性
  5. 可随时点击「上一步」回退复习

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何形状简单（矩形、椭圆、折线），无需复杂库；原生 SVG 轻量且易于控制元素显隐
- 画布尺寸：800×500 px（固定）
- 布局草图（ASCII）：
  ```
  [800×500 画布]
  +----------------------------------------------------------+
  |              标题：原电池 - 电解池组合装置                | y=40
  |                                                          |
  |    [烧杯]                    [滤纸椭圆]                  |
  |   +------+                   /        \                 |
  |   | Zn | | Cu |             | a      b |                 | y=200~380
  |   |____| |____|             \________/                  |
  |   稀硫酸→                        ↓                       |
  |                        饱和食盐水滤纸                    |
  |                                                          |
  |  [负极] [正极]              [阳极] [阴极]                | y=350~360
  |                                                          |
  |              [◀上一步] [下一步▶]  步骤 X/4               | y=460~490
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0~3) 跟踪当前步骤，数组 steps 定义每步需显示的元素 ID 列表
  2. 元素显隐：通过 getElementById(id).style.display = 'none'/'block' 控制
  3. 高亮框：用橙色半透明矩形框覆盖目标区域，stroke=#ffa000, fill=rgba(255,160,0,0.1)
  4. 按钮事件：绑定 click 事件，更新 currentStep 后调用 renderStep() 刷新显示
  5. 边界处理：步骤 0 时禁用「上一步」，步骤 3 时禁用「下一步」
- ID 命名规范：所有元素 ID 以 scene1- 为前缀
  - scene1-beaker, scene1-solution, scene1-zn, scene1-cu
  - scene1-filter-paper, scene1-electrode-a, scene1-electrode-b
  - scene1-wire-zn-b, scene1-wire-cu-a
  - scene1-label-zn, scene1-label-cu, scene1-label-a, scene1-label-b
  - scene1-label-solution, scene1-label-paper
  - scene1-highlight-box1, scene1-highlight-box2
  - scene1-polarity-negative, scene1-polarity-positive
  - scene1-polarity-anode, scene1-polarity-cathode
  - scene1-btn-prev, scene1-btn-next, scene1-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
