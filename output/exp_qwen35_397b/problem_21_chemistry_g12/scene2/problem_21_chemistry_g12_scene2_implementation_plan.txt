[图示主题与整合说明]
- 本图示主题：电路中电子与离子的流动方向
- 整合的步骤/概念：外电路电子流动方向、原电池内电路离子移动、电解池内电路离子移动

[分步序列]
滑块5个位置，教师拖动滑块逐步展示：

- 位置0（静止/初始状态）：
  - 显示完整装置结构（烧杯、电极、滤纸、石墨棒、导线）
  - 所有电极标签显示（锌、铜、a、b）
  - 溶液/滤纸标签显示
  - 无流动箭头显示
  - 图例显示在右下角

- 位置1（外电路电子流：锌→a）：
  - 显示红色虚线箭头从锌电极顶部沿导线流向石墨棒a
  - 箭头旁标注"e⁻"（红色，坐标约(240,155)）
  - 锌电极高亮（描边加粗）

- 位置2（外电路电子流：b→铜）：
  - 保留位置1的电子流箭头
  - 新增红色虚线箭头从石墨棒b沿导线流向铜电极
  - 箭头旁标注"e⁻"（红色，坐标约(535,155)）
  - 铜电极高亮

- 位置3（原电池内离子移动）：
  - 保留位置2的所有电子流箭头
  - 新增蓝色实线箭头：Zn²⁺从锌电极向铜电极移动（烧杯内，y=300）
  - 新增蓝色实线箭头：H⁺从锌电极向铜电极移动（烧杯内，y=330）
  - 标注"Zn²⁺"（蓝色，坐标(175,290)）
  - 标注"H⁺"（蓝色，坐标(175,320)）

- 位置4（电解池内离子移动）：
  - 保留位置3的所有箭头
  - 新增蓝色实线箭头：Na⁺向石墨棒b移动（滤纸上，y=280）
  - 新增绿色实线箭头：Cl⁻向石墨棒a移动（滤纸上，y=310）
  - 标注"Na⁺"（蓝色，坐标(600,270)）
  - 标注"Cl⁻"（绿色，坐标(600,300)）
  - 完成完整电路展示

[交互方案]
- 交互类型：连续拖拽滑块（5个离散位置点）
- 控件说明：
  - 滑块轨道：位于SVG底部y=450-480区域，宽度300px
  - 滑块手柄：可拖拽，有5个吸附位置（0/1/2/3/4）
  - 位置指示器：滑块下方显示当前步骤文字说明
- 教师操作流程：
  1. 初始状态展示装置结构，讲解原电池和电解池的组成
  2. 拖动滑块至位置1，展示电子从锌（负极）流出，讲解外电路电子流向
  3. 拖动至位置2，展示电子流回铜（正极），形成完整外电路
  4. 拖动至位置3，展示原电池内部离子移动，讲解内电路电荷平衡
  5. 拖动至位置4，展示电解池内部离子移动，讲解电解原理
  6. 可来回拖动滑块，对比不同阶段的流动情况

[技术实现]
- JS库选择：原生SVG + 原生JavaScript
  - 原因：几何图形简单，无需复杂库；SVG便于箭头动画和状态切换
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |   [原电池]                    [电解池]           |
  |   锌  铜                      a    b             |
  |   |   |                       |    |             |
  |   |===|=======================|====|  导线       |
  |   e⁻→                         ←e⁻                |
  |   ~~~~~稀硫酸~~~~~           (滤纸)              |
  |   Zn²⁺→ H⁺→                  Na⁺→ Cl⁻→          |
  |                                                  |
  |                                    [图例]        |
  |                              电子流 ---→         |
  |                              阳离子 ---→         |
  |                              阴离子 ---→         |
  |                                                  |
  |         [========滑块========]                   |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量currentStep(0-4)记录滑块位置，每次change事件触发updateDisplay()
  2. 箭头动画：使用SVG <marker>定义箭头头部，<path>绘制箭身，opacity控制显示/隐藏
  3. 滑块吸附：监听input事件，将滑块值四舍五入到最近的整数位置(0/1/2/3/4)
  4. 元素分组：用<g>元素将相关箭头分组，通过display或opacity控制整组显示
  5. 高亮效果：选中电极时，临时增加stroke-width和改变stroke颜色
- ID命名规范：
  - 所有元素ID以scene2-为前缀
  - 示例：scene2-zinc-electrode, scene2-copper-electrode, scene2-graphite-a, scene2-graphite-b
  - 箭头ID：scene2-arrow-e-1, scene2-arrow-e-2, scene2-arrow-zn, scene2-arrow-h, scene2-arrow-na, scene2-arrow-cl
  - 标签ID：scene2-label-zn, scene2-label-cu, scene2-label-a, scene2-label-b
  - 滑块ID：scene2-slider
- IIFE隔离：所有JS代码包裹在(function() { ... })()中，避免全局变量污染
- CDN引入：无需额外库，使用原生SVG和JS
