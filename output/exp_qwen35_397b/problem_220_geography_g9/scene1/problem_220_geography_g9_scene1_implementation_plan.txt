[图示主题与整合说明]
- 本图示主题：热力环流侧视图的形成过程及温度气压分布规律
- 整合内容：环流形成动画、温度分布标注、气压分布标注、选项 A 和 B 的验证
- 教学价值：教师可通过分步展示热力环流的形成过程，帮助学生理解"受热不均→垂直运动→水平运动→环流建立"的因果链条，同时直观对比温度分布（b>a>d>c）和气压分布（a>b>c>d）的规律，验证题目选项正误

  - 箭头③：近地面水平气流，从 a 指向 b，位于 ab 线下方 y=370
  - 箭头④：下沉气流，从 d 指向 a，位于 da 线左侧 x=230
- 箭头标签：①②③④用圆圈包围的数字，位于对应箭头外侧

[分步序列]
- 初始状态（步骤 0）：显示环流框架（4 条线段）、四个顶点 a/b/c/d 及标签，无箭头无标注
- 步骤 1：点击「下一步」→ 显示 b 处受热标识（绿色矩形+"受热"文字）、箭头②（上升气流，红色渐变）
- 步骤 2：点击「下一步」→ 显示 a 处冷却标识（橙色矩形+"冷却"文字）、箭头④（下沉气流，蓝色渐变）
- 步骤 3：点击「下一步」→ 显示箭头①（高空水平气流，紫色）和箭头③（近地面水平气流，橙色），形成完整环流
- 步骤 4：点击「下一步」→ 左侧显示温度标注区（蓝色）："温度分布"标题+"b>a>d>c"，同时高亮 b 点（受热温度最高）和 a 点（冷却温度较低）
- 步骤 5：点击「下一步」→ 右侧显示气压标注区（红色）："气压分布"标题+"a>b>c>d"，同时用不同深浅表示气压高低
- 步骤 6（结论）：底部显示结论框，验证选项 A 错误（温度应为 b>a，而非 a>b）、选项 B 错误（气压应为 a>b>c>d，而非 d>a>b>c）

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于控件栏左侧 (x=50, y=460)，点击返回上一状态
  - 「下一步」按钮：位于控件栏右侧 (x=700, y=460)，点击进入下一状态
  - 步骤指示器：位于控件栏中央 (x=400, y=460)，显示"步骤 X/7"
- 教师操作流程：
  1. 初始状态展示基础框架，引导学生观察 a、b、c、d 四点位置
  2. 点击「下一步」展示 b 处受热和上升气流，解释受热导致空气膨胀上升
  3. 点击「下一步」展示 a 处冷却和下沉气流，解释冷却导致空气收缩下沉
  4. 点击「下一步」展示水平气流，说明垂直运动导致同一水平面气压差异，进而产生水平运动
  5. 点击「下一步」展示温度分布，引导学生总结近地面温度高于高空、受热处温度高于冷却处
  6. 点击「下一步」展示气压分布，引导学生总结近地面气压高于高空、冷却处（高压）高于受热处（低压）
  7. 点击「下一步」展示结论，验证题目选项 A 和 B 的正误

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |   温度分布          环流框架           气压分布   |
  |   b>a>d>c    d ←---①---→ c    a>b>c>d  |
  |                ↑           ↑                   |
  |              ④|           |②                   |
  |                ↓           ↓                   |
  |            a →---③---→ b                       |
  |          冷却              受热                 |
  |                                                  |
  |              [结论框]                            |
  +--------------------------------------------------+
  [控件栏（SVG 内底部 y=440~490）]
  |  ◀上一步        步骤 X/7        下一步▶  |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用 currentState 变量（0-6）跟踪当前步骤，steps 数组存储每步的可见元素配置
  2. 元素分组：将相关元素放入<g>组，如 arrows-group、labels-group、temp-group、pressure-group、conclusion-group
  3. 动画效果：箭头使用 stroke-dasharray 和 stroke-dashoffset 实现绘制动画，透明度渐变实现淡入
  4. 事件绑定：为上下一步按钮添加 click 事件监听器，更新 currentState 并调用 renderState() 函数
  5. 条件渲染：renderState() 根据 currentState 显示/隐藏对应元素组
- ID 命名规范：所有元素 ID 以 scene1- 为前缀，如 scene1-frame-ab、scene1-arrow-1、scene1-label-a、scene1-temp-group、scene1-btn-next
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
