[分步序列]
- 初始状态（步骤 0）：显示左侧地球侧视图基础框架
  - 显示地平线、赤道纬线、晨昏线、经线

- 步骤 1：点击「下一步」→ 推导太阳直射点纬度
  - 左侧图显示直射点纬线 10°N（橙色虚线）
  - 显示标签"10°N"
  - 太阳光线出现，显示平行入射
  - 右侧图区仍空白

- 步骤 2：点击「下一步」→ 计算上海正午太阳高度
  - 右侧图显示地平线、建筑物墙面
  - 显示上海纬度标签"31°N"
  - 显示太阳高度角弧线及标签"H = 69°"
  - 公式显示：H = 90° - |31° - 10°| = 69°

- 步骤 3：点击「下一步」→ 展示电池板最佳角度
  - 右侧图显示太阳能电池板（倾斜绿色线段）
  - 显示电池板与墙面夹角弧线及标签"21°"
  - 公式显示：夹角 = 90° - H = 90° - 69° = 21°
  - 或：夹角 = |31° - 10°| = 21°（纬度差）

- 最终状态：所有元素显示完整，教师可总结结论

[交互方案]

  - 「上一步」按钮：位于 (320,450)，点击回退到前一状态

- 教师操作流程：
  1. 初始状态展示晨昏线与经线夹角 10°，教师讲解晨昏线几何意义
  2. 点击「下一步」显示直射点纬度 10°N，教师推导夹角与直射点纬度关系
  3. 点击「下一步」显示上海正午太阳高度计算，教师讲解 H = 90° - |φ - δ| 公式
  4. 点击「下一步」显示电池板角度，教师总结电池板与墙面夹角 = 90° - H = 纬度差

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单，无需复杂库；SVG 便于精确坐标控制和标签定位
- 画布尺寸：800 × 500 px（固定画布）
- 布局草图：
  ```
  [标题区 y=20~60]
     太阳能电池板角度计算
  
  [左侧图区 x=50~380, y=80~380]    [右侧图区 x=420~750, y=80~380]
  ┌─────────────────────┐          ┌─────────────────────┐
  │  太阳光线 → → →     │          │                     │
  │    \ 晨昏线         │          │     | 墙面          │
  │     \ 10°           │          │     |               │
  │      \              │          │     |/电池板        │
  │  ──────── 10°N ─────│          │  ───────────────    │
  │  ──────── 0°  ──────│          │     地平线          │
  │     地平线          │          │                     │
  └─────────────────────┘          └─────────────────────┘
  
  [控件栏 y=440~490]
     [◀上一步] [步骤 X/4] [下一步▶]
  ```
- 关键实现要点：
  1. 状态机设计：使用 state 变量 (0-3) 跟踪当前步骤，steps 数组存储每步显示的元素 ID 列表
  2. 坐标计算：所有元素坐标硬编码，确保与布局表一致
  3. 动画曲线：使用 CSS transition 实现淡入效果 (opacity 0→1, 300ms)
  4. 事件绑定：按钮点击事件切换状态，更新显示元素和步骤指示器
  5. 元素显隐：通过 display:none 或 opacity 控制每步元素的显示/隐藏
- ID 命名规范：所有元素 ID 以 scene3- 为前缀
  - 示例：scene3-horizon-left, scene3-sun-ray-1, scene3-solar-panel, scene3-angle-arc 等
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
