[图示主题与整合说明]
- 本图示主题：利用经纬网判断两点相对方向（①点相对于③点的方向）
- 整合的内容：①③两点的位置展示、南北方向判断辅助线、东西方向判断辅助线、最终方向结论
- 教学价值：教师可通过分步导航清晰展示方向判断的思维过程——先判断南北（比较纬度），再判断东西（比较经度），最后综合得出结论。学生可直观理解经纬网方向判断的逻辑顺序。

- 步骤说明文字：「结论：①点在③点的东南方向」
- 高亮：方向箭头和结论文字

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 (280,455)，点击返回上一状态，第一步时禁用
  - 「下一步」按钮：位于 (440,455)，点击进入下一状态，最后一步时变为「完成」
- 教师操作流程：
  1. 初始状态让学生观察两点位置
  2. 点击「下一步」展示南北方向判断，引导学生比较纬度
  3. 点击「下一步」展示东西方向判断，引导学生比较经度
  4. 点击「下一步」展示最终结论，强化方向判断逻辑
  5. 可随时点击「上一步」回退复习

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（网格、点、线、箭头），无需复杂库；原生 SVG 便于精确控制坐标和样式
- 画布尺寸：800×500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |  西                              东              |
  |  +--------------------------------------------+  |
  |  |  40°N  [经纬网区域 640×320]      ③        |  |
  |  |         ·  ·  ·  ·  ·  ·  ·  ·            |  |
  |  |  30°N                              ·       |  |
  |  |         ·  ·  ·  ·  ·  ·  ·  ·            |  |
  |  |  20°N                              ·       |  |
  |  |         ·  ·  ·  ·  ·  ·  ·  ·            |  |
  |  |  10°N                              ·       |  |
  |  |         ·  ·  ·  ·  ·  ·  ·  ·            |  |
  |  |   0°   ①  ·  ·  ·  ·  ·  ·  ·            |  |
  |  |         ·  ·  ·  ·  ·  ·  ·  ·            |  |
  |  |  10°S                                      |  |
  |  +--------------------------------------------+  |
  |  北                              南              |
  |                                                  |
  |  [步骤说明文字区域]                              |
  |                                                  |
  |           [◀上一步]      [下一步▶]              |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-3) 跟踪当前步骤
  2. 坐标计算：经度每 30°对应 80px (640/8)，纬度每 10°对应 64px (320/5)
     - ①点 (120°W, 0°)：x = 80 + (150-120)/30*80 = 176, y = 60 + (40-0)/10*64 = 316
     - ③点 (120°E, 35°N)：x = 80 + (150+120)/30*80 = 624, y = 60 + (40-35)/10*64 = 124
  3. 动画曲线：辅助线和箭头使用 CSS transition (opacity 0.3s ease)
  4. 事件绑定：按钮点击事件切换状态，更新各元素 display/opacity
  5. 按钮状态：第一步禁用「上一步」，最后一步「下一步」文字变为「完成」
- ID 命名规范：所有元素 ID 以 scene2- 为前缀
  - scene2-grid, scene2-point1, scene2-point3, scene2-label1, scene2-label3
  - scene2-ns-line, scene2-ew-line, scene2-direction-arrow
  - scene2-step-text, scene2-prev-btn, scene2-next-btn
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
