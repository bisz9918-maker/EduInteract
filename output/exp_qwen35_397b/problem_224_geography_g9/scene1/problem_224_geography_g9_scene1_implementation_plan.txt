[图示主题与整合说明]

[分步序列]
步骤 0（初始状态）：显示题目基础条件
- 显示：外框矩形、所有经线纬线、经度纬度标签、点 A/B/C/D/E/F 及点标签
- 晨昏线 EDF：显示为细线 #cccccc（未高亮）
- 隐藏：晨线/昏线标注、夜半球填充、昼/夜半球文字标签

步骤 1：点击「下一步」→ 高亮晨昏线 EDF
- 视觉变化：晨昏线 EDF 从 #cccccc 细线变为 #1565c0 加粗实线（线宽 3）
- 新增：无
- 教师讲解：引导学生识别图中 EDF 为晨昏线

步骤 2：点击「下一步」→ 标注晨线 ED 和昏线 DF
- 视觉变化：ED 段保持 #1565c0，DF 段变为 #c62828（昏线用红色区分）
- 新增：晨线标注文字「晨线」+ 箭头指向 ED 段（位置 200,200）；昏线标注文字「昏线」+ 箭头指向 DF 段（位置 600,200）
- 教师讲解：解释 ED 为晨线（由夜入昼），DF 为昏线（由昼入夜）

步骤 3：点击「下一步」→ 用斜线填充夜半球区域
- 视觉变化：晨昏线 EDF 以北区域（即图中上方三角形区域）用斜线填充
- 新增：夜半球填充 polygon（60,40)-(400,40)-(740,40)-(740,363)-(400,40)-(60,363)，斜线 #888888，透明度 30%
- 教师讲解：说明晨昏线划分昼夜半球，EDF 以北为夜半球

步骤 4：点击「下一步」→ 标注昼半球与夜半球文字
- 视觉变化：无
- 新增：夜半球标签「夜半球」（400,120，颜色 #888888）；昼半球标签「昼半球」（400,320，颜色 #1565c0）
- 教师讲解：总结昼夜半球分布，完成本题第（1）问

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 按钮「◀上一步」：位置 (280,460)，尺寸 100×40，点击返回上一状态
  - 按钮「下一步▶」：位置 (420,460)，尺寸 100×40，点击进入下一状态
  - 状态指示器：位置 (380,445)，显示「步骤 X/4」
- 教师操作流程：
  1. 初始展示原图，让学生观察经纬网和点的位置
  2. 点击「下一步」高亮晨昏线，引导学生识别 EDF
  3. 点击「下一步」区分晨线/昏线，讲解晨昏线含义
  4. 点击「下一步」填充夜半球，说明昼夜划分
  5. 点击「下一步」标注昼/夜半球，完成第（1）问讲解
  6. 可随时点击「上一步」回退复习

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库）
- 画布尺寸：800×500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  经度标签：135°E    45°W    45°E                 |
  |  +--------------------------------------------+  |
  |  | 90°N  ──────────────────────────────────── |  |
  |  |       │           │           │            |  |
  |  | 66.5°N│─────C─────│───────────│            |  |
  |  |       │     │     │           │            |  |
  |  | 23.5°N│─────│─────│───────────│            |  |
  |  |       │     │  D  │           │            |  |
  |  | 赤道  │─────│──B──│───────────│            |  |
  |  |       │     │     │           │            |  |
  |  | 23.5°S│─────│─────│───────────│            |  |
  |  |       │     │     │           │            |  |
  |  | 66.5°S│──A──│─────│───────────│──F         |  |
  |  |       │     │     │           │            |  |
  |  | 90°S  ──────────────────────────────────── |  |
  |  +--------------------------------------------+  |
  |  纬度标签 → 90°N, 66.5°N, ..., 90°S (右侧)      |
  |                                                  |
  |  [控件栏 y=440~490]                              |
  |        [◀上一步]  步骤 X/4  [下一步▶]            |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentState (0-4) 跟踪当前步骤
  2. 元素分组：将晨昏线、晨线/昏线标注、夜半球填充、昼/夜标签分别放入 <g> 组，用 display 控制显隐
  3. 晨昏线高亮：步骤 0 用细线 #cccccc，步骤 1+ 用粗线 #1565c0
  4. 夜半球填充：用 <pattern> 定义斜线，步骤 3 显示填充 polygon
  5. 事件绑定：按钮点击事件切换 currentState，调用 updateScene() 更新显示
  6. 边界处理：步骤 0 禁用「上一步」，步骤 4 禁用「下一步」
- ID 命名规范：所有元素 ID 以 scene1- 为前缀
  - scene1-grid-outer, scene1-meridian-135E, scene1-parallel-66.5N, ...
  - scene1-晨昏线-EDF, scene1-晨线-ED, scene1-昏线-DF
  - scene1-夜半球-fill, scene1-标签-夜半球, scene1-标签-昼半球
  - scene1-btn-prev, scene1-btn-next, scene1-status
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
