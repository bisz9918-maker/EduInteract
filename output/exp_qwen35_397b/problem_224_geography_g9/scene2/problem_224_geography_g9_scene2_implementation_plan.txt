[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 (250,450)，80×36px，灰色背景，点击返回上一状态
  - 「下一步」按钮：位于 (470,450)，80×36px，蓝色背景，点击进入下一状态
  - 步骤指示器：位于 (400,455)，显示当前步骤"步骤 X/5"
- 教师操作流程：
  1. 初始展示完整经纬网和晨昏线，让学生观察夜半球分布
  2. 点击「下一步」高亮北极圈极夜，引导学生发现北极圈以北全为黑夜
  3. 点击「下一步」显示日期，确认冬至日
  4. 点击「下一步」高亮南回归线，推导太阳直射纬度
  5. 点击「下一步」显示昼半球中央经线，推导太阳直射经度
  6. 点击「下一步」显示完整直射点坐标，总结结论

[技术实现]
- JS 库选择：原生 SVG（适合绘制经纬网、晨昏线、标注等几何元素，无需额外库）
- 画布尺寸：800 × 500 px（固定画布）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  经度标签：135°    45°    45°                     | y=45
  +--------------------------------------------------+
  |  90°N  +------------------------------------+    | y=60
  |        |                                    |    |
  |  66.5°N|====北极圈高亮====极夜区域==========|    | y=107
  |        |                                    |    |
  |  23.5°N|                                    |    | y=154
  |        |                                    |    |
  |  0°赤道|------------------------------------|    | y=200
  |        |                                    |    |
  |  23.5°S|----------------直射点-------------|    | y=247
  |        |                                    |    |
  |  66.5°S|E----------------------------------F|    | y=294
  |        |                                    |    |
  |  90°S  +------------------------------------+    | y=340
  +--------------------------------------------------+
  |        日期/坐标信息区 (y=360-410)                |
  +--------------------------------------------------+
  |     [◀上一步]    步骤 X/5    [下一步▶]           | y=450
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量 (0-5)，数组存储每步需显示的元素 ID 列表
  2. 坐标计算：经纬度转像素坐标使用线性映射，经度范围 135°E 到 45°W 映射到 x=100 到 x=700
  3. 动画曲线：元素显示使用淡入效果 (opacity 0→1，300ms)
  4. 事件绑定：按钮点击事件切换状态，更新显示元素和步骤指示器
  5. 夜半球填充：使用 SVG pattern 定义斜线填充，应用于晨昏线右侧多边形
- ID 命名规范：所有元素 ID 以 scene2- 为前缀，如 scene2-grid-meridian-135E、scene2-point-A、scene2-label-date 等
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
