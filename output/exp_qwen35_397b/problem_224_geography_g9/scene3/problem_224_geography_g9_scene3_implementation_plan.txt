[图示主题与整合说明]
- 本图示主题：各点地理参数比较分析（太阳光照图 - 场景 3）
- 整合的内容：A、B、C、D 四点的正午太阳高度角比较、地方时比较、线速度比较；D 点和 C 点太阳高度计算
- 教学价值：教师可通过状态切换清晰展示三种不同地理参数的比较结果，帮助学生理解纬度、经度对太阳高度角、地方时、线速度的影响规律。绿色虚线连接相等的点，直观呈现相等关系，便于学生对比记忆。

[分步序列]
本场景采用多状态切换交互，共 3 个状态：

状态 0（初始状态）：
- 显示完整经纬网图、晨昏线 EDF
- 显示 A、B、C、D 四个点及其标签
- 显示所有经纬度标签
- 不显示任何相等关系连线
- 结论文字区显示「请选择比较类型」
- 三个状态按钮均可见，无高亮

状态 1（点击「正午太阳高度角」按钮）：
- 显示绿色虚线连接 B 点和 C 点
- 其他连线隐藏
- 结论文字区显示「正午太阳高度角相等：B 和 C（同纬度对称点）」
- 按钮 1 高亮，按钮 2、3 正常
- D 点上方标注「0°」（晨昏线上太阳高度为 0）
- C 点上方标注「0°」（极夜区正午太阳高度为 0）

状态 2（点击「地方时」按钮）：
- 显示绿色虚线连接 B 点和 D 点（同经线）
- 其他连线隐藏
- 结论文字区显示「地方时相等：B 和 D（同经度 45°W）」
- 按钮 2 高亮，按钮 1、3 正常
- 隐藏太阳高度标注

状态 3（点击「线速度」按钮）：
- 显示绿色虚线连接 C 点和 D 点（同纬度）
- 其他连线隐藏
- 结论文字区显示「线速度相等：C 和 D（同纬度 66.5°N）」
- 按钮 3 高亮，按钮 1、2 正常
- 隐藏太阳高度标注

[交互方案]
- 交互类型：多状态切换（3 个按钮）
- 控件说明：
  - 按钮 1「正午太阳高度角」：位于 (150,455)，140×35px，点击后显示 B-C 连线及结论
  - 按钮 2「地方时」：位于 (330,455)，100×35px，点击后显示 B-D 连线及结论
  - 按钮 3「线速度」：位于 (470,455)，100×35px，点击后显示 C-D 连线及结论
- 教师操作流程：
  1. 初始状态展示完整经纬网和四点位置，让学生观察各点经纬度
  2. 点击「正午太阳高度角」，引导学生发现 B、C 两点关于赤道对称，正午太阳高度角相等
  3. 点击「地方时」，引导学生发现 B、D 两点在同一条经线上，地方时相同
  4. 点击「线速度」，引导学生发现 C、D 两点在同一条纬线上，自转线速度相等
  5. 可反复切换对比，强化学生对地理参数影响因素的理解

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  经度标签  135°    45°    45°                    |
  |  +--------------------------------------------+  |
  |  | 90°N  ───────────────────────────────────  |  |
  |  | 66.5°N ──────D──────────C────────────────  |  |
  |  | 23.5°N ───────────────────────────────────  |  |
  |  | 赤道  ──────────B─────────────────────────  |  | 纬度
  |  | 23.5°S ───────────────────────────────────  |  | 标签
  |  | 66.5°S ──A────────────────────────────────  |  |
  |  | 90°S  ───────────────────────────────────  |  |
  |  +--------------------------------------------+  |
  |  结论文字区：正午太阳高度角相等：B 和 C            |
  |  [正午太阳高度角] [地方时] [线速度]               |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用 currentState 变量记录当前状态（0-3），点击按钮时更新状态并重绘
  2. 所有交互元素 ID 以 scene3- 为前缀（如 scene3-point-a、scene3-line-bc、scene3-btn-state1）
  3. 使用 IIFE 隔离：(function() { ... })() 避免全局污染
  4. 连线显示/隐藏：通过 display 属性或 opacity 控制
  5. 按钮高亮：通过 fill 颜色变化（#e0e0e0 → #bdbdbd）和文字加粗
  6. 事件绑定：每个按钮绑定 click 事件，调用 updateState(stateId) 函数
- ID 命名规范：
  - 点：scene3-point-a, scene3-point-b, scene3-point-c, scene3-point-d
  - 标签：scene3-label-a, scene3-label-b, scene3-label-c, scene3-label-d
  - 连线：scene3-line-bc, scene3-line-bd, scene3-line-cd
  - 按钮：scene3-btn-state1, scene3-btn-state2, scene3-btn-state3
  - 结论文字：scene3-conclusion
  - 太阳高度标注：scene3-sunheight-d, scene3-sunheight-c
