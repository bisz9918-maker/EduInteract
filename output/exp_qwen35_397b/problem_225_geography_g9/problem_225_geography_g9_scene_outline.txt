    **题目原文：**

    读图，回答．
    （1）写出 A、B、C、D 的地理坐标：
    A：______；B：______；
    C：______；D：______．
    （2）A 点位于 C 点的 ______ 方向；
    （3）B 点位于 C 点的 ______ 方向．
    （4）A、B、C、D 四点中，
    位于北半球的是 ______，位于南半球的是 ______，
    位于东半球的是 ______，位于西半球是 ______．（填代号）
    （5）A、B、C、D 四点中，位于低纬度地区的是 ______，位于中纬度地区的是 ______，位于高纬度地区的是 ______．（填代号）

    **题目分析：**

    本题是一道综合性经纬网读图题，考查学生对经纬度坐标系统的理解与应用。核心知识点包括：
    1. 经纬度的判读方法（东经/西经、北纬/南纬的识别）
    2. 方向的判断（基于经纬网的相对位置）
    3. 半球的划分（南北半球以赤道为界，东西半球以 20°W 和 160°E 为界）
    4. 纬度带的划分（低纬度 0°-30°，中纬度 30°-60°，高纬度 60°-90°）

    **整体讲解思路：**

    1. 首先引导学生认识经纬网的基本结构：横线为纬线，竖线为经线
    2. 讲解经纬度的判读规则：180°经线左侧为东经，右侧为西经；赤道以北为北纬，以南为南纬
    3. 依次读取 A、B、C、D 四点的坐标
    4. 讲解方向判断方法：同经度比纬度（南北方向），同纬度比经度（东西方向）
    5. 讲解半球划分和纬度带划分的标准
    6. 综合应用，完成各小题

    **图示规划说明：**

    共设计 3 个交互式图示场景：
    - SCENE_1：经纬网基础与坐标读取——展示完整经纬网，交互读取各点坐标
    - SCENE_2：半球与纬度带划分——整合展示南北半球、东西半球、纬度带三种划分方式
    - SCENE_3：方向关系判断——可视化展示点对之间的方向关系
    </TEXT_1>

    **教学说明：**

    本图示用于讲解经纬网的基本结构和坐标读取方法。

    **引导学生观察要点：**

    1. 首先让学生识别图中的横线是纬线，竖线是经线
    2. 引导学生注意 180°经线的位置——它是东经和西经的分界线
    3. 强调赤道（0°纬线）是北纬和南纬的分界线

    **坐标读取规则：**

    1. 经度判读：从 180°经线向左（西）度数减小的是东经（E），向右（东）度数减小的是西经（W）
    2. 纬度判读：从赤道向北度数增大的是北纬（N），向南度数增大的是南纬（S）

    **四点坐标答案：**

    - A 点：140°E, 80°N
    - B 点：140°W, 40°N
    - C 点：140°E, 20°N
    - D 点：140°W, 20°S

    **讲解建议：**

    教师可先让学生尝试自己读取坐标，然后点击各点验证答案。对于易错点（如 B、D 点的西经判断），可重点强调 180°经线右侧为西经的规则。

    <TEXT_4>
    **教学说明：**

    本图示用于讲解经纬网上两点之间方向的判断方法。

    **方向判断规则：**

    1. 同经度：只比较纬度，纬度高者在北，低者在南
    2. 同纬度：只比较经度，东经度大者在东，西经度大者在西（需注意跨 180°的情况）
    3. 既不同经度也不同纬度：综合判断，分为东北、东南、西北、西南四个方向

    **本题答案：**

    第（2）问：A 点位于 C 点的 **正北** 方向
    - 理由：A 和 C 同在 140°E 经线上，A 的纬度（80°N）高于 C 的纬度（20°N）

    第（3）问：B 点位于 C 点的 **东北** 方向
    - 理由：B 的纬度（40°N）高于 C 的纬度（20°N）→ B 在 C 的北方
    - B 的经度（140°W）与 C 的经度（140°E）比较，从 C 向东到 B 的经度差为 80°（140°E→180°→140°W），小于向西的 280°，故 B 在 C 的东方
    - 综合：B 在 C 的东北方向

    **讲解建议：**

    教师可先展示状态 1，让学生理解同经度时的方向判断（只有南北之分）；再展示状态 2，讲解既不同经度也不同纬度时的综合判断方法。箭头可视化能帮助学生直观理解方向的合成。
    </TEXT_4>
