[图示主题与整合说明]
- 本图示主题：经纬网坐标系统与四点坐标读取
- 整合的内容：整合了经纬网结构展示、A/B/C/D 四点位置标注、各点坐标读取三个认知阶段

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 按钮「◀ 上一步」：位于 SVG 内底部左侧 (x=320, y=455)，返回上一状态
  - 按钮「下一步 ▶」：位于 SVG 内底部右侧 (x=460, y=455)，进入下一状态
  - 步骤指示器：位于两按钮之间 (x=400, y=455)，显示 "步骤 X/5"
- 教师操作流程：
  1. 初始展示完整经纬网，让学生观察网格结构
  2. 点击「下一步」高亮 A 点，引导学生读取 A 点坐标（沿经线找 140°E，沿纬线找 80°N）
  3. 依次点击「下一步」高亮 B、C、D 点，重复坐标读取过程
  4. 最后一步同时显示四点坐标，进行总结对比
  5. 可随时点击「上一步」回退复习特定点

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（直线、圆点、文本），无需复杂库；原生 SVG 交互性能好，代码轻量
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +----------------------------------------------------------+
  | [标题：经纬网坐标读取]                    步骤 0/5       |
  |                                                          |
  |      120°  140°  160°  180°  160°  140°  120°  (经度)   |
  |    +----+----+----+----+----+----+----+                  |
  | 80° | A  |    |    |    |    |    |    |  [A坐标框]      |
  |    +----+----+----+----+----+----+----+                  |
  | 60° |    |    |    |    |    |    |    |  [B坐标框]      |
  |    +----+----+----+----+----+----+----+                  |
  | 40° |    |    |    |    |    | B  |    |  [C坐标框]      |
  |    +----+----+----+----+----+----+----+                  |
  | 20° | C  |    |    |    |    |    |    |  [D坐标框]      |
  |    +----+----+----+----+----+----+----+                  |
  |  0° +----+----+----+----+----+----+----+ (赤道)          |
  |    |    |    |    |    |    |    |    |                  |
  | 20° |    |    |    |    |    | D  |    |                  |
  |    +----+----+----+----+----+----+----+                  |
  |                                                          |
  |         [◀ 上一步]    步骤 X/5    [下一步 ▶]             |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-5），数组存储每步的配置对象
  2. 坐标计算：经线 x = 120 + (index * 80)，纬线 y = 60 + (index * 53)
  3. 高亮效果：修改圆点 fill 和 r 属性，添加 <animate> 或 CSS class 实现光晕
  4. 事件绑定：按钮点击事件更新 currentState，调用 renderState() 重绘
  5. 边界处理：步骤 0 时禁用「上一步」，步骤 5 时禁用「下一步」
- ID 命名规范：
  - 所有元素 ID 以 scene1- 为前缀
  - 示例：scene1-meridian-120E, scene1-parallel-80N, scene1-point-A, scene1-label-A, scene1-coord-box-A
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
