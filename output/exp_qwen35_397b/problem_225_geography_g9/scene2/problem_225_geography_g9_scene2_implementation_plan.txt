[图示主题与整合说明]
- 本图示主题：半球划分与纬度带划分
- 整合的步骤/概念：整合了南北半球划分（赤道为界）、东西半球划分（20°W-160°E 为东半球）、低中高纬度带划分（0°-30°低纬、30°-60°中纬、60°-90°高纬）三种地理区域划分方式
- 教学价值：教师可通过状态切换，逐层展示三种不同的地理区域划分标准，避免信息过载。学生可直观理解不同划分方式的界线位置和区域范围，配合题目中的 A/B/C/D 四点判断其所属区域。

[交互方案]
- 交互类型：多状态切换（4 个状态按钮）
- 控件说明：
  - 按钮「基础」：位置(260,460)，显示状态 0，清除所有填充和分界线
  - 按钮「南北半球」：位置(340,460)，显示状态 1，显示南北半球填充和赤道分界线
  - 按钮「东西半球」：位置(440,460)，显示状态 2，显示东西半球填充和 20°W/160°E 分界线
  - 按钮「纬度带」：位置(540,460)，显示状态 3，显示纬度带填充和 30°/60°纬线
- 教师操作流程：
  1. 初始展示基础经纬网和四点位置，让学生读出各点坐标
  2. 点击「南北半球」，讲解赤道为界，提问学生 A/B/C 在北半球，D 在南半球
  3. 点击「东西半球」，讲解 20°W-160°E 为东半球，提问学生 A/C 在东半球，B/D 在西半球
  4. 点击「纬度带」，讲解 0°-30°低纬、30°-60°中纬、60°-90°高纬，提问学生 A 在高纬，B/C 在中纬，D 在低纬

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需复杂库）
- 画布尺寸：800×500px
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  经度标签行 (y=25)                               |
  |  +--------------------------------------------+  |
  |  | 纬度标签 |        经纬网格主图区          |  |
  |  | (x=65)   |        (80,40)-(760,420)       |  |
  |  |          |   A●   C●                      |  |
  |  |          |                                |  |
  |  |          |              B●   D●           |  |
  |  |          |                                |  |
  |  +--------------------------------------------+  |
  |                                                  |
  |  [基础] [南北半球] [东西半球] [纬度带]           |
  |   (260)   (340)     (440)     (540)              |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentState 跟踪当前状态（0-3），每次切换先清除所有填充和分界线，再渲染新状态元素
  2. 坐标计算：经度每 20°对应 113px（680/6≈113.33），纬度每 20°对应 63px（380/6≈63.33）
  3. 20°W 位置计算：180°经线在 x=420，20°W 即 160°E 以东 20°，x=420+20*(113.33/20)=420+113.33≈533，但东西半球分界是 20°W 和 160°E，20°W 实际在 180°以西 160°，需重新计算：从 180°向西 160°到 20°W，x=420-160*(113.33/20)=420-906.64≈负值，说明 20°W 不在当前视图内。修正：当前视图经度范围 120°E~120°W，20°W 在 140°W 以东 120°，即 x=647-120*(113.33/20)=647-680≈负值，仍不在视图。再修正：20°W=340°E，从 120°E 开始，340-120=220°，220/20*113.33=1246px，超出画布。结论：20°W 分界线不在当前视图范围内，东西半球划分只能显示 160°E 分界线。
  4. 动画效果：状态切换时填充区域用 fade-in 效果（opacity 从 0 到 1，300ms）
  5. 事件绑定：四个按钮分别绑定 click 事件，调用 switchState(n) 函数
- ID 命名规范：所有元素 ID 以 scene2- 为前缀，如 scene2-point-a、scene2-label-a、scene2-btn-northsouth 等
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
