[图示主题与整合说明]
- 本图示主题：地方时判断原理——晨昏线与经线位置关系
- 整合的步骤/概念：晨线/昏线判定、经线与地方时对应关系、B/C 两点地方时判断

[分步序列]
- 初始状态（步骤 0）：显示地球轮廓、昼/夜半球（夜半球斜线阴影）、晨昏线（黑色实线）、太阳光线箭头、N/S 极点标注
- 步骤 1：点击「下一步」→ 晨昏线分段高亮：上半段变绿色（晨线），下半段变红色（昏线），显示"晨线"和"昏线"标签
- 步骤 2：点击「下一步」→ 显示昼半球中央经线（蓝色虚线）和夜半球中央经线（灰色虚线），沿赤道标注时间刻度：6 时（晨线）、12 时（昼中央）、18 时（昏线）、0 时（夜中央）
- 步骤 3：点击「下一步」→ B 点高亮显示（蓝色实心圆放大），显示 B 点标签"B(12 时/午餐)"，强调 B 点位于昼半球中央经线→正午 12 时
- 步骤 4：点击「下一步」→ C 点高亮显示（灰色实心圆放大），显示 C 点标签"C(0 时/深夜)"，强调 C 点位于夜半球中央经线→子夜 0 时
- 结论：所有元素显示完整，教师可总结"昼半球中央经线为正午 12 时，夜半球中央经线为子夜 0 时，据此可判断任意点的地方时"

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 底部左侧 (x=320, y=455)，返回上一状态
  - 「下一步」按钮：位于 SVG 底部右侧 (x=480, y=455)，进入下一状态
  - 步骤指示器：位于底部中央 (x=400, y=455)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始状态展示基础光照图，提问"如何判断晨昏线？"
  2. 点击下一步，晨昏线分段着色，讲解"由夜入昼为晨线，由昼入夜为昏线"
  3. 点击下一步，显示经线和时间刻度，讲解"经线等分对应时间差"
  4. 点击下一步，B 点高亮，提问"B 点是什么时间？"，引导学生观察其位于昼半球中央
  5. 点击下一步，C 点高亮，提问"C 点是什么时间？"，引导学生观察其位于夜半球中央
  6. 总结地方时判断原理

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +------------------------------------------+
  |              N(400,65)                   |
  |         B●(310,150)    晨线              |
  |      12 时    ╱│╲      (510,160)         |
  |   昼半球  ╱  │  ╲  夜半球               |
  |        ╱    │    ╲   昏线               |
  |      A      │      ╲ (510,340)          |
  |    6 时────晨昏线────18 时  0 时         |
  |            │        C●(580,250)         |
  |              S(400,435)                  |
  |                                          |
  |      [◀上一步]  步骤 X/5  [下一步▶]      |
  |         (320,455)        (480,455)       |
  +------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用 currentState 变量 (0-5) 跟踪当前步骤，steps 数组存储每步的可见元素 ID 列表
  2. 夜半球阴影：使用 SVG <pattern> 定义斜线填充，apply 到右半圆 path
  3. 经线弧线：使用 SVG <path> 的椭圆弧命令 (A) 绘制
  4. 动画效果：元素显示/隐藏使用 opacity 过渡 (0.3s ease)
  5. 事件绑定：按钮点击事件切换状态，更新可见元素
  6. ID 命名规范：所有元素 ID 以 scene3- 为前缀（如 scene3-earth、scene3-morning-line、scene3-point-b）
  7. IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
