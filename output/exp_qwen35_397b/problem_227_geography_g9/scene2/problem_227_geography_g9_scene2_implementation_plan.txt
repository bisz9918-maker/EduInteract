[图示主题与整合说明]
- 本图示主题：球面最短路径与航向变化
- 整合的内容：B 到 D 的大圆航线路径 + 航向箭头动态演示 + 沿纬线路径对比
- 教学价值：教师可通过此图示直观展示球面上两点间最短路径（大圆航线）与沿纬线路径的区别，学生拖动滑块可观察航向从东北→东→东南的连续变化过程，理解为什么高纬度地区飞行/航行常走"弯路"

[分步序列]
本场景为连续拖拽滑块交互，无分步导航，状态由滑块位置决定：

- 初始状态（滑块=0%）：
  - 显示完整经纬网
  - 显示 B 点、D 点
  - 显示沿纬线的灰色虚线路径
  - 显示大圆航线（蓝色粗弧线）
  - 当前位置点在 B 点
  - 航向箭头在 B 点，指向东北方向（约 45°）
  - 航向文字显示"东北"

- 滑块=25%：
  - 当前位置点沿大圆航线移动至 1/4 处
  - 航向箭头指向东北偏东（约 30°）
  - 航向文字显示"东北"

- 滑块=50%（中点）：
  - 当前位置点在大圆航线最高点 M(400,220)
  - 航向箭头指向正东（0°）
  - 航向文字显示"东"
  - 中点 M 高亮显示

- 滑块=75%：
  - 当前位置点沿大圆航线移动至 3/4 处
  - 航向箭头指向东南偏东（约 -30°）
  - 航向文字显示"东南"

- 滑块=100%：
  - 当前位置点在 D 点
  - 航向箭头在 D 点，指向东南方向（约 -45°）
  - 航向文字显示"东南"

[交互方案]
- 交互类型：连续拖拽滑块（垂直滑块）
- 控件说明：
  - 垂直滑块：位于右侧 (740,150)-(780,350)，范围 0-100，步长 1
  - 航向指示器：位于滑块上方 (740,40)，显示当前航向文字
  - 图例区：位于滑块下方 (740,380)，显示大圆航线和沿纬线路径的图例
- 教师操作流程：
  1. 初始状态展示 B、D 两点及两条路径，提问"哪条路径更短？"
  2. 拖动滑块从 0% 开始，让学生观察航向箭头方向
  3. 拖到中点 50% 时暂停，强调此时航向为正东
  4. 继续拖到 100%，总结航向变化：东北→东→东南
  5. 对比两条路径长度，解释大圆航线为何最短

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：经纬网和路径为 2D 几何图形，SVG 足够胜任；无需复杂动画库
- 画布尺寸：800×500 px
- 布局草图：
  ```
  +--------------------------------------------------+
  |  [航向文字：东北]                      [40°]     |
  |                                                  |
  |    经纬网主图区 (640×350)                        |
  |    经线：170°E  180°  170°W                     |
  |    纬线：40°N  30°N  20°N                       |
  |    B 点───────大圆航线───────D 点                 |
  |              沿纬线虚线                          |
  |                                                  |
  |  [170°E]  [180°]  [170°W]                       |
  |                                                  |
  |         [沿纬线路径]                    [20°]    |
  +--------------------------------------------------+
  |  [滑块]  [图例]                                  |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 大圆航线用二次贝塞尔曲线：M 160,350 Q 400,220 640,350
  2. 滑块位置映射：sliderValue (0-100) → 贝塞尔曲线上的点坐标
  3. 航向箭头角度：根据贝塞尔曲线在该点的切线方向计算
     - 切线向量 = 曲线导数，角度 = atan2(dy, dx)
  4. 航向文字切换：
     - 0-35%: "东北"
     - 35-65%: "东"
     - 65-100%: "东南"
  5. 贝塞尔曲线参数方程：
     - x(t) = (1-t)²×160 + 2(1-t)t×400 + t²×640
     - y(t) = (1-t)²×350 + 2(1-t)t×220 + t²×350
     - t = sliderValue / 100
  6. 切线角度计算：
     - dx/dt = 2(1-t)(400-160) + 2t(640-400)
     - dy/dt = 2(1-t)(220-350) + 2t(350-220)
     - angle = atan2(dy/dt, dx/dt) × 180/π
- ID 命名规范：
  - scene2-grid: 经纬网组
  - scene2-point-b: B 点
  - scene2-point-d: D 点
  - scene2-path-equator: 沿纬线路径
  - scene2-path-greatcircle: 大圆航线
  - scene2-point-mid: 中点 M
  - scene2-slider: 滑块控件
  - scene2-heading-text: 航向文字
  - scene2-current-point: 当前位置点
  - scene2-heading-arrow: 航向箭头
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
