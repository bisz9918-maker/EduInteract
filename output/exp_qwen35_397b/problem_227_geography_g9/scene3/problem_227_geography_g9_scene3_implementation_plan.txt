[分步序列]
多状态切换（3个状态，非顺序步骤）：

【状态0 - 初始/默认】
- 显示：基础经纬网、ABCD四点及标签、经纬度数值
- 隐藏：半球分区、大圆航线、判断标记、解析文字
- 按钮：无高亮

【状态1 - 小题1解析】
- 显示：
  - 东西半球分界线（160°E虚线，x=280）
  - 东半球区域（左侧半透明绿色填充）
  - 西半球区域（右侧半透明红色填充）
  - 判断标记「错误」（红色，位于解析区顶部）
  - 解析文字：「小题1：错误。东半球范围是20°W~160°E。A(170°E)、B(170°E)、C(170°W)、D(170°W)均位于西半球。」
- 高亮：分界线、半球区域
- 隐藏：大圆航线、方向箭头、小题2判断标记
- 按钮1高亮（蓝色背景）

【状态2 - 小题2解析】
- 显示：
  - B→D大圆航线路径（红色弧线，从B点向上弯曲至中点再向下到D）
  - 方向箭头1（东北方向，路径前半段）
  - 方向箭头2（东南方向，路径后半段）
  - 判断标记「正确」（绿色，位于解析区顶部）
  - 解析文字：「小题2：正确。球面上两点间最短距离是大圆劣弧。从B到D沿大圆航线，先向东北，再向东南。」
- 高亮：大圆航线、方向箭头
- 隐藏：半球分区、小题1判断标记
- 按钮2高亮（蓝色背景）

【状态3 - 完整答案】
- 显示：
  - 判断标记1「错误」（红色）
  - 判断标记2「正确」（绿色）
  - 解析文字：「【答案】小题1：错误；小题2：正确。【知识点】①东西半球分界：20°W和160°E；②球面最短路径为大圆劣弧。」
- 高亮：ABCD四点
- 隐藏：半球分区、大圆航线细节
- 按钮3高亮（蓝色背景）

[交互方案]
- 交互类型：多状态切换（3个按钮）
- 控件说明：
  - 按钮1「小题1解析」：点击显示半球划分图示和小题1判断
  - 按钮2「小题2解析」：点击显示大圆航线路径和小题2判断
  - 按钮3「完整答案」：点击显示两题结论和知识点摘要
- 教师操作流程：
  1. 初始状态展示基础经纬网，让学生观察ABCD四点位置
  2. 点击「小题1解析」，展示东西半球分界，引导学生判断半球位置，得出「错误」结论
  3. 点击「小题2解析」，展示B→D大圆航线，解释方向变化，得出「正确」结论
  4. 点击「完整答案」，汇总两题答案和核心知识点，进行课堂总结

[技术实现]
- JS库选择：原生SVG（几何图形简单，无需复杂库）
- 画布尺寸：800×500 px（固定）
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │ [小题1解析]  [小题2解析]  [完整答案]        ← 状态按钮区 y=15-45 │
  ├─────────────────────────────────────────────────────────────┤
  │                                                             │
  │         40°N ─────────────────────────────                  │
  │              A           │           C                      │
  │         30°N ─────────────────────────────                  │
  │              │           │           │                      │
  │              B ─ ─ ─ ─ ─ ┼ ─ ─ ─ ─ ─ D                      │
  │         20°N ─────────────────────────────                  │
  │            170°E       180°       170°W                    │
  │                                                             │
  ├─────────────────────────────────────────────────────────────┤
  │  解析文字区（动态内容，y=310-420）                          │
  │  判断标记（错误/正确）                                      │
  ├─────────────────────────────────────────────────────────────┤
  │  知识点摘要（小字提示，y=430-450）                          │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentState (0-3) 跟踪当前状态，点击按钮时更新
  2. 元素显隐：每个状态对应一组元素的 display 属性切换
  3. 按钮样式：激活状态添加 .active 类（蓝色背景白字）
  4. 大圆航线：用 SVG path 绘制向上凸起的弧线，d="M 180,260 Q 350,200 520,260"
  5. 半球分界：160°E 经线位置计算（170°E到180°之间，约 x=280）
- ID命名规范：所有元素ID以 scene3- 为前缀
  - scene3-btn-q1, scene3-btn-q2, scene3-btn-summary
  - scene3-lat-40, scene3-lat-30, scene3-lat-20
  - scene3-lon-170e, scene3-lon-180, scene3-lon-170w
  - scene3-point-a, scene3-point-b, scene3-point-c, scene3-point-d
  - scene3-label-a, scene3-label-b, scene3-label-c, scene3-label-d
  - scene3-hemisphere-div, scene3-hemisphere-east, scene3-hemisphere-west
  - scene3-path-bd, scene3-arrow-ne, scene3-arrow-se
  - scene3-mark-q1, scene3-mark-q2
  - scene3-explain-text, scene3-summary-text
- IIFE隔离：所有JS代码包裹在 (function() { ... })() 中
- 配色规格：

  - 正确标记：#2e7d32
  - 错误标记：#c62828
