[图示主题与整合说明]
- 本图示主题：地方时计算、夜长求解与正午太阳高度年变化
- 整合的步骤/概念：
  1. 晨昏线判读（AO 为昏线，BO 为晨线）
  2. 地方时计算（B 地 6 时、O 地 0 时）
  3. 经度与夜长计算（A 地经度 180°、夜长 8 小时）
  4. 太阳直射点坐标（20°S，60°W）
  5. 正午太阳高度年变化及差值（47°）
- 教学价值：教师可逐问讲解，通过分步动画展示计算过程，帮助学生理解晨昏线图中地方时、经度、夜长、直射点坐标的求解方法，以及正午太阳高度年变化规律

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 (250,465)，点击后回退到前一状态，隐藏当前步骤新增的元素
  - 「下一步」按钮：位于 (470,465)，点击后进入下一状态，显示该步骤新增的元素
  - 步骤指示：位于 (380,470)，显示当前步骤序号如"步骤 1/5"
- 教师操作流程：
  1. 加载后显示步骤 0（基础图），教师讲解晨昏线判读
  2. 点击「下一步」显示步骤 1，讲解 B 地 6 时、O 地 0 时的计算依据
  3. 点击「下一步」显示步骤 2，讲解 A 地经度 180°的推导和夜长 8 小时的计算
  4. 点击「下一步」显示步骤 3，讲解直射点坐标 (20°S,60°W) 的确定方法
  5. 点击「下一步」显示步骤 4，讲解 A 地正午太阳高度年变化及差值 47°
  6. 可随时点击「上一步」回退复习

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript。原因：几何图形简单，无需复杂库；SVG 便于精确控制坐标和样式；原生 JS 足够实现分步状态切换
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  [光照图区 400×200]     |  [答案区 350×200]      |
  |  y=60~260               |  y=60~260              |
  |  经纬网、晨昏线、标注    |  各问答案文本          |
  |-------------------------|------------------------|
  |  [年变化曲线图 500×130]  |                        |
  |  y=310~440              |                        |
  |  正弦曲线、差值标注      |                        |
  |-------------------------|------------------------|
  |  [控件栏 y=460~490]     |                        |
  |  [◀上一步] 步骤 1/5 [下一步▶]|                    |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用数组存储 5 个状态（steps[0]~steps[4]），每个状态包含应显示的元素 ID 列表
  2. 坐标计算：所有元素使用绝对坐标（SVG viewBox="0 0 800 500"）
  3. 动画曲线：元素出现使用淡入效果（opacity 0→1，duration 300ms）
  4. 事件绑定：按钮点击事件切换状态，更新步骤指示文本
  5. 元素显隐：通过 display 属性或 opacity 控制
- ID 命名规范：所有交互元素 ID 必须以 scene3- 为前缀
  - scene3-light-diagram（光照图组）
  - scene3-ao-line（AO 昏线）
  - scene3-bo-line（BO 晨线）
  - scene3-point-a、scene3-point-b、scene3-point-o（三点）
  - scene3-label-a、scene3-label-b、scene3-label-o（点标签）
  - scene3-time-b（B 地时间）
  - scene3-time-o（O 地时间）
  - scene3-longitude-a（A 地经度）
  - scene3-night-arc（夜弧）
  - scene3-night-length（夜长标签）
  - scene3-sun-point（直射点标记）
  - scene3-sun-coord（直射点坐标）
  - scene3-curve-chart（年变化曲线图组）
  - scene3-curve-path（曲线路径）
  - scene3-diff-rect（差值区域）
  - scene3-diff-label（差值标签）
  - scene3-btn-prev（上一步按钮）
  - scene3-btn-next（下一步按钮）
  - scene3-step-indicator（步骤指示）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
