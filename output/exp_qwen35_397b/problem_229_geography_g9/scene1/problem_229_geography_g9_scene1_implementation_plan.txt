[图示主题与整合说明]
- 本图示主题：经纬网结构与点的经纬度判读
- 整合的步骤/概念：整合了经纬网基础结构展示、经度纬度判读规则、D/E/F 三点坐标标注三个认知阶段
- 教学价值：教师可使用此图示逐步引导学生理解经纬网的结构，掌握经度向东/向西变化的规律，纬度的南北判读方法，并能准确读取任意点的经纬度坐标。分步设计让教师可以控制讲解节奏，先建立整体认知再聚焦具体点位。

[视觉元素清单]
- 经纬网网格：5条经线×3条纬线，经线为纵向弧线（向北极收敛），纬线为横向弧线（向赤道弯曲）
- 经线标注：140°E、160°E、180°、160°W、140°W，位于各经线顶部上方20px
- 纬线标注：60°N、50°N、40°N，位于各纬线右端右侧10px
- 点标记：D、E、F三点用#c62828红色实心圆(r=5)
- 坐标标签框：底部三个虚线框，显示各点完整经纬度
- 颜色/样式沿用 spec 中声明：
  - 背景 #ffffff
  - 经纬网格线 #000000 实线 1.5px
  - 经度高亮 #1565c0（蓝色）
  - 纬度高亮 #2e7d32（绿色）
  - 点标记 #c62828（红色）实心圆
  - 坐标标签框 #888888 虚线边框，填充透明度20%

[分步序列]
- 初始状态（步骤0）：显示完整经纬网网格（5经3纬），显示所有经度标签(140°E,160°E,180°,160°W,140°W)和纬度标签(60°N,50°N,40°N)，显示D/E/F三个点标记及点名标签，不显示坐标框
- 步骤1：点击「下一步」→ 经线高亮（5条经线变为#1565c0蓝色，线宽2px），在每条经线旁添加小箭头指示经度变化方向（向东增大为E，向西增大为W）
- 步骤2：点击「下一步」→ 经线恢复黑色，纬线高亮（3条纬线变为#2e7d32绿色，线宽2px），在纬线旁添加小箭头指示纬度变化方向（向北增大为N）
- 步骤3：点击「下一步」→ 纬线恢复黑色，依次出现D点坐标框（淡入动画），显示"D(140°E, 60°N)"
- 步骤4：点击「下一步」→ 出现E点坐标框（淡入动画），显示"E(160°E, 40°N)"
- 步骤5：点击「下一步」→ 出现F点坐标框（淡入动画），显示"F(160°W, 50°N)"，同时D/E/F三点标记闪烁高亮一次
- 最终状态：所有元素完整显示，教师可点击「上一步」回退复习任一阶段

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于(280,455)，尺寸80×30px，灰色背景，点击回退到前一状态
  - 「下一步」按钮：位于(440,455)，尺寸80×30px，蓝色背景，点击进入下一状态
  - 状态指示器：位于(380,460)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始展示完整经纬网，让学生观察整体结构
  2. 点击「下一步」高亮经线，讲解经度判读规则（向东增大为东经E，向西增大为西经W）
  3. 点击「下一步」高亮纬线，讲解纬度判读规则（向北增大为北纬N）
  4. 连续点击「下一步」依次展示D/E/F三点坐标，引导学生练习读取
  5. 可随时点击「上一步」回退复习任一概念

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  经度标签区 (y=60)                               |
  |  140°E  160°E  180°  160°W  140°W               |
  |                                                  |
  |  +--------------------------------------------+  |
  |  |  经纬网主图区 (600×300, y=80-380)          |  | 纬度标签区
  |  |  5条经线 × 3条纬线                         |  | (x=710)
  |  |  D·  E·  F· 点标记                         |  | 60°N
  |  +--------------------------------------------+  | 50°N
  |                                                  | 40°N
  |  [D坐标框] [E坐标框] [F坐标框] (y=400-430)      |
  |                                                  |
  |        [◀上一步]  步骤X/5  [下一步▶] (y=450)    |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用 currentState 变量(0-5)跟踪当前步骤，steps 数组存储每步的显示配置
  2. 经线/纬线用 SVG path 绘制弧线（经线向中心收敛，纬线向底部弯曲）
  3. 高亮效果：通过修改 stroke 和 stroke-width 属性实现
  4. 淡入动画：坐标框初始 opacity=0，步骤触发时 transition 到 opacity=1
  5. 事件绑定：按钮点击事件调用 updateDisplay() 函数更新状态
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀
  - scene1-grid-group（经纬网组）
  - scene1-meridian-1 至 scene1-meridian-5（5条经线）
  - scene1-parallel-1 至 scene1-parallel-3（3条纬线）
  - scene1-point-d、scene1-point-e、scene1-point-f（三点标记）
  - scene1-label-d、scene1-label-e、scene1-label-f（点名标签）
  - scene1-coord-box-d、scene1-coord-box-e、scene1-coord-box-f（坐标框）
  - scene1-btn-prev、scene1-btn-next（按钮）
  - scene1-step-indicator（状态指示器）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
