[视觉元素清单]
- 烧杯：透明矩形边框，位置 (250,150)-(550,400)，边框色#555555，线宽 2px
- 溶液：矩形填充 (255,220)-(545,395)，初始颜色#bbdefb（蓝色），最终渐变为#a5d6a7（浅绿色），透明度 30%
- 铜电极：矩形 (280,180)-(320,380)，填充色#d84315（铜色），边框#8d2b0b
- 铁电极：矩形 (460,180)-(500,380)，填充色#757575（铁灰色），边框#424242
- 接线柱 a/b：圆形，r=8，填充色#333333，位置分别为 (300,140) 和 (480,140)
- 导线：路径从 (300,140) 经 (390,110) 到 (480,140) 的弧线，线宽 3px，颜色#000000
- 电子流向箭头：弧线路径在导线上方 y=115，从 x=470 到 x=310，箭头颜色#1565c0，线宽 3px
- 离子移动箭头：Cu²⁺箭头从溶液中心指向铜电极，SO₄²⁻箭头从溶液中心指向铁电极
- 电极反应式：铁电极右侧显示"Fe-2e⁻=Fe²⁺"，铜电极左侧显示"Cu²⁺+2e⁻=Cu"，字体 14px
- 正负极标识：铁电极上方"(-)"红色#c62828，铜电极上方"(+)"绿色#2e7d32
- 颜色/样式严格沿用 spec.json 中<SCENE_2>的配色规格

[分步序列]
- 初始状态（步骤 0）：显示烧杯、溶液（蓝色#bbdefb）、铜电极、铁电极、接线柱 a 和 b；点击后导线出现连接 a-b
- 步骤 1：显示电子流向箭头（蓝色，从 Fe 经导线流向 Cu），显示 e⁻标签，显示正负极标识（Fe 为负极(-)，Cu 为正极(+)）
- 步骤 2：显示离子移动——Cu²⁺（蓝色箭头）向铜电极移动，SO₄²⁻（黄色箭头）向铁电极移动；溶液中显示离子分布
- 步骤 3：显示电极反应式——铁电极旁"Fe-2e⁻=Fe²⁺"，铜电极旁"Cu²⁺+2e⁻=Cu"；铁电极开始溶解效果（高度逐渐减少），铜电极开始析出效果（宽度逐渐增加）
- 步骤 4：溶液颜色从蓝色#bbdefb 渐变为浅绿色#a5d6a7（透明度 30%），铁电极溶解效果完成，铜电极析出效果完成；显示完整原电池工作状态

冲突检查：
- "(-)"与"(+)"：水平距离 180px → 无冲突
- "e⁻"与导线：垂直距离 15px → 无冲突（箭头上方）
- "Fe-2e⁻=Fe²⁺"与铁电极：水平距离 10px → 无冲突（右侧偏移）
- "Cu²⁺+2e⁻=Cu"与铜电极：水平距离 10px → 无冲突（左侧偏移）
- 离子标签之间：间距约 30-40px → 无冲突
- 所有标签与烧杯边框：最小距离 20px → 无冲突

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位置 (320,450)，尺寸 70×30px，点击返回上一状态
  - 「下一步」按钮：位置 (410,450)，尺寸 70×30px，点击进入下一状态
  - 步骤指示器：位置 (400,470)，显示"步骤 X/4"
- 教师操作流程：
  1. 初始展示装置结构，讲解铜电极和铁电极
  2. 点击「下一步」连接导线，讲解形成闭合回路
  3. 点击「下一步」显示电子流向，讲解电子从负极（Fe）流向正极（Cu）
  4. 点击「下一步」显示离子移动，讲解阳离子向正极移动、阴离子向负极移动
  5. 点击「下一步」显示电极反应式和溶解/析出现象，讲解氧化还原反应
  6. 点击「下一步」显示溶液颜色变化，讲解 Cu²⁺浓度降低导致蓝色变浅绿色
  7. 可随时点击「上一步」回退复习关键概念

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript
  - 原因：几何形状简单（矩形、圆形、路径），无需复杂库；SVG 便于精确控制坐标和动画；原生 JS 足够实现分步状态切换
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +----------------------------------------------------------+
  |                                                          |
  |     a o====================o b                           |
  |       |                    |                             |
  |     (+)Cu                Fe(-)                           |
  |       |                    |                             |
  |   +---|--------------------|---+                         |
  |   |   |    溶液 (Cu²⁺/SO₄²⁻) |   |                         |
  |   |   |   ←Cu²⁺    SO₄²⁻→  |   |                         |
  |   |   |                    |   |                         |
  |   +---|--------------------|---+                         |
  |       |                    |                             |
  |   Cu²⁺+2e⁻=Cu        Fe-2e⁻=Fe²⁺                        |
  |                                                          |
  |              [◀上一步]  [下一步▶]                        |
  |                   步骤 X/4                               |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-4），每个状态对应一组可见元素
  2. 坐标计算：所有元素使用绝对坐标，SVG viewBox="0 0 800 500"
  3. 动画曲线：使用 CSS transition 实现平滑渐变（溶液颜色、电极形变）
  4. 事件绑定：按钮点击事件切换状态，更新各元素 display/opacity 属性
  5. 离子动画：使用 SMIL 或 JS 定时器实现离子移动动画
- ID 命名规范：所有交互元素 ID 必须以 scene2- 为前缀
  - scene2-beaker（烧杯）
  - scene2-solution（溶液）
  - scene2-electrode-cu（铜电极）
  - scene2-electrode-fe（铁电极）
  - scene2-terminal-a（接线柱 a）
  - scene2-terminal-b（接线柱 b）
  - scene2-wire（导线）
  - scene2-electron-arrow（电子流向箭头）
  - scene2-ion-cu-arrow（Cu²⁺移动箭头）
  - scene2-ion-so4-arrow（SO₄²⁻移动箭头）
  - scene2-label-negative（负极标识）
  - scene2-label-positive（正极标识）
  - scene2-reaction-fe（铁电极反应式）
  - scene2-reaction-cu（铜电极反应式）
  - scene2-btn-prev（上一步按钮）
  - scene2-btn-next（下一步按钮）
  - scene2-step-indicator（步骤指示器）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
- 多场景合并兼容：使用 scene2- 前缀确保 ID 唯一性，CSS 类名也添加 scene2- 前缀
