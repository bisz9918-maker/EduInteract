[分步序列]
步骤 0（初始状态）：
- 显示完整晶胞框架（12 条棱线）
- 显示 4 个 A 离子（黑球）和 4 个 B 离子（白球）
- 显示图例（A 离子、B 离子）
- 均摊法面板和配位数面板显示标题，内容为空
- 步骤指示："步骤 0/4"

步骤 1（点击"下一步"）：
- 高亮所有 8 个顶点离子（A 离子变蓝色#1565c0，B 离子变绿色#2e7d32）
- 均摊法面板显示："A 离子：8×1/8=1" 和 "B 离子：8×1/8=1"
- 在晶胞旁添加"1/8"标记（蓝色，位于晶胞左侧）
- 步骤指示："步骤 1/4"

步骤 2（点击"下一步"）：
- 保持步骤 1 的高亮状态
- 均摊法面板显示化学式结果："化学式：AB"（加大加粗）
- 步骤指示："步骤 2/4"

步骤 3（点击"下一步"）：
- 取消所有离子高亮，恢复原色
- 选取前左下 A 离子 (350,350) 作为中心，高亮为蓝色#1565c0
- 绘制 6 条红色虚线从中心 A 离子指向周围 6 个最近邻 B 离子位置
- 配位数面板显示："选取中心 A 离子" 和 "最近邻 B 离子：6 个"
- 步骤指示："步骤 3/4"

步骤 4（点击"下一步"）：
- 保持步骤 3 的状态
- 高亮 6 个最近邻 B 离子为绿色#2e7d32
- 配位数面板显示结论："配位数=6"（加大加粗）
- 步骤指示："步骤 4/4"

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀上一步"按钮：位于 (280,460)，点击返回上一状态，步骤 0 时禁用
  - "下一步▶"按钮：位于 (440,460)，点击进入下一状态，步骤 4 时禁用
  - 步骤指示文本：位于 (380,470)，显示当前步骤"步骤 X/4"
- 教师操作流程：
  1. 初始展示晶胞结构，让学生观察 A/B 离子分布
  2. 点击"下一步"演示均摊法，解释 8 个顶点各贡献 1/8
  3. 再点击得出化学式 AB
  4. 继续点击进入配位数分析，选取中心离子
  5. 最后展示配位数结论，完成讲解

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库）
- 画布尺寸：800×500 px
- 布局草图：
  ```
  [图示区 800×500]
  +------------------+------------------+------------------+
  |  均摊法面板      |   晶胞立体图     |   配位数面板     |
  |  (50,80-280,200) |  (350,100-600,350)|  (520,80-750,250)|
  |                  |                  |                  |
  |  均摊法计算      |   A/B 离子分布   |   配位数分析     |
  +------------------+------------------+------------------+
  |                    控件栏 (y=450-490)                   |
  |         [◀上一步]  步骤 X/4  [下一步▶]                 |
  +---------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量 (0-4)，steps 数组存储每步的显示配置
  2. 坐标计算：晶胞采用斜二测投影，前后顶点偏移 (50,50) 营造立体感
  3. 动画曲线：离子高亮使用 CSS transition，0.3s ease
  4. 事件绑定：按钮点击事件绑定到 updateScene() 函数
  5. 禁用状态：步骤 0 时上一步按钮 disabled，步骤 4 时下一步按钮 disabled
- ID 命名规范：所有元素 ID 以 scene2- 为前缀
  - scene2-cell-front-top, scene2-cell-front-bottom, ...（棱线）
  - scene2-ion-a-0, scene2-ion-a-1, ...（A 离子）
  - scene2-ion-b-0, scene2-ion-b-1, ...（B 离子）
  - scene2-panel-tally, scene2-panel-coordination（面板）
  - scene2-btn-prev, scene2-btn-next, scene2-step-indicator（控件）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
