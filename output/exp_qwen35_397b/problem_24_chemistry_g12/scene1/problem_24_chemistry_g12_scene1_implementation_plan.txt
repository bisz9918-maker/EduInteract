[分步序列]
- 初始状态（步骤0）：显示三个空容器框架（黑色边框），乙容器顶部显示活塞轮廓（灰色），V₀标识线和标签显示，容器名称"甲、乙、丙"显示在底部
- 步骤1：点击「下一步」→ 甲容器填充淡蓝色背景，甲容器内显示"0.2 mol NO₂"标签，甲容器左侧显示蓝色"恒容"标识牌

- 步骤3：点击「下一步」→ 丙容器填充淡蓝色背景，丙容器内显示"0.1 mol N₂O₄"标签，丙容器右侧显示蓝色"恒容"标识牌
- 步骤4：点击「下一步」→ 三容器完整对比视图，所有元素显示完毕，V₀标识线两端箭头闪烁强调"初始容积相等"

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 按钮"上一步"：位置(320,455)，尺寸80×30px，灰色背景，点击后回退到前一状态
  - 按钮"下一步"：位置(400,455)，尺寸80×30px，蓝色背景，点击后进入下一状态
  - 步骤指示器：位置(500,460)，显示"步骤 X/4"
- 教师操作流程：
  1. 初始展示三个空容器框架，引导学生观察容器结构差异
  2. 点击"下一步"展示甲容器，讲解恒容容器特点及NO₂初始量
  3. 点击"下一步"展示乙容器，对比恒压容器结构（活塞），讲解压强恒定的含义
  4. 点击"下一步"展示丙容器，讲解N₂O₄作为反应物的不同初始条件
  5. 点击"下一步"完成对比，引导学生思考三容器平衡状态的差异
  6. 可随时点击"上一步"回退复习

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript。原因：本场景为简单几何图形（矩形、文字），无需复杂库，原生实现轻量且性能好
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                    V₀标识线                       | y=155-170
  |                                                  |
  |   [甲容器]      [乙容器+活塞]      [丙容器]       | y=185-380
  |   恒容←         恒压→             恒容→          |
  |                                                  |
  |    甲            乙                丙            | y=405
  |                                                  |
  |         [◀上一步] [下一步▶]  步骤X/4             | y=440-490
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用currentState变量(0-4)，数组存储每步需显示的元素ID列表
  2. 坐标计算：所有元素坐标硬编码，确保精确对齐
  3. 动画曲线：填充区域使用CSS transition opacity 0.5s ease-in-out
  4. 事件绑定：按钮点击事件绑定到stepForward/stepBack函数
  5. 活塞高亮：步骤2时添加CSS class"highlight"，实现闪烁动画
- ID 命名规范：所有交互元素ID必须以 scene1- 为前缀
  - scene1-container-jia, scene1-container-yi, scene1-container-bing
  - scene1-piston-yi
  - scene1-label-jia, scene1-label-yi, scene1-label-bing
  - scene1-substance-jia, scene1-substance-yi, scene1-substance-bing
  - scene1-tag-rong-jia, scene1-tag-ya-yi, scene1-tag-rong-bing
  - scene1-fill-jia, scene1-fill-yi, scene1-fill-bing
  - scene1-vo-line, scene1-vo-label
  - scene1-btn-prev, scene1-btn-next, scene1-step-indicator
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
