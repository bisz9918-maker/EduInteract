[分步序列]
- 初始状态（滑块0%）：
  - 甲容器：显示0.2 mol NO₂（6个红色分子），N₂O₄%=0%
  - 乙容器：显示0.2 mol NO₂（6个红色分子），活塞在顶部y=140，N₂O₄%=0%
  - 体积标注：甲显示"V₀"，乙显示"V₀"
  
- 滑块拖动至50%：
  - 甲容器：NO₂分子减少至4个，N₂O₄分子出现2个，N₂O₄%≈33%
  - 乙容器：NO₂分子减少至3个，N₂O₄分子出现3个，活塞下移至y≈180，N₂O₄%≈50%
  - 体积标注：乙显示"V_乙 < V₀"
  - 体积缩小箭头逐渐显现

- 滑块拖动至100%（平衡）：
  - 甲容器：NO₂分子约3个，N₂O₄分子约4个，N₂O₄%≈57%
  - 乙容器：NO₂分子约2个，N₂O₄分子约5个，活塞下移至y≈220，N₂O₄%≈71%
  - 体积标注：乙明确显示"V_乙 < V₀"
  - 对比结论"N₂O₄% 乙 > N₂O₄% 甲"高亮显示
  - 平衡移动标注"平衡正向移动"显示

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：
  - 反应进度滑块：位于SVG底部(150,450)-(650,450)，教师可左右拖动
  - 0%标记：滑块最左端，表示反应未开始
  - 100%标记：滑块最右端，表示达到平衡
- 教师操作流程：
  1. 初始状态展示甲、乙容器初始条件（均为0.2 mol NO₂）
  2. 缓慢拖动滑块向右，展示反应进行过程
  3. 引导学生观察：乙容器活塞下移（体积缩小），甲容器体积不变
  4. 拖动至100%时，对比两容器N₂O₄百分含量，解释恒压条件下平衡正向移动更多

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（矩形容器、圆形分子、线段滑块），无需复杂库；原生实现轻量且易于控制交互状态
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |   [甲容器]          [乙容器]      [标注区]       |
  |   恒容 0.2mol       恒压 0.2mol    压强P不变      |
  |   NO₂分子(红)       NO₂分子(红)   ↓箭头         |
  |   N₂O₄分子(蓝)      N₂O₄分子(蓝)  平衡正向移动   |
  |   N₂O₄%: xx%        N₂O₄%: xx%    N₂O₄%乙>甲    |
  |                                                  |
  |            [反应进度滑块 0%────●────100%]        |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用单个progress变量(0-1)表示反应进度，所有视觉元素状态由此派生
  2. 活塞位置计算：pistonY = 140 + progress * 80（从140下移至220）
  3. 分子数量计算：
     - NO₂数量 = Math.round(6 * (1 - progress))
     - N₂O₄数量 = Math.round(4 * progress)
  4. N₂O₄%计算：
     - 甲：progress * 57%（恒容平衡转化率约57%）
     - 乙：progress * 71%（恒压平衡转化率约71%，因体积缩小有利正向）
  5. 事件绑定：滑块使用mousedown/mousemove/mouseup实现拖拽，touch事件支持移动端
  6. 动画平滑：使用requestAnimationFrame更新滑块位置和关联元素
- ID 命名规范：所有元素ID以scene3-为前缀
  - scene3-container-a（甲容器）
  - scene3-container-b（乙容器）
  - scene3-piston（乙活塞）
  - scene3-slider-track（滑块轨道）
  - scene3-slider-handle（滑块手柄）
  - scene3-no2-a、scene3-n2o4-a（甲容器分子）
  - scene3-no2-b、scene3-n2o4-b（乙容器分子）
  - scene3-percent-a、scene3-percent-b（百分含量显示）
- IIFE 隔离：所有JS代码包裹在(function() { ... })()中，避免全局变量污染
