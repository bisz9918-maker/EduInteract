- 本图示主题：果蝇刚毛性状杂交实验完整遗传图解（P→F₁→F₂）

  - 「上一步」按钮：位于 (280,450)，80×35px，点击返回上一状态

- 教师操作流程：
  1. 初始展示 P 代亲本基因型，讲解亲本表现型与基因型
  2. 点击「下一步」展示 F₁ 代，讲解显性性状表现
  3. 点击「下一步」展示配子形成，讲解减数分裂与配子类型
  4. 点击「下一步」展示 F₂ 代棋盘格，讲解受精组合
  5. 点击「下一步」展示比例，总结 2:1:1 表现型比例的遗传规律
  6. 可随时点击「上一步」回退复习关键步骤

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript
  - 原因：遗传图解以静态图形和文字标注为主，无需复杂动画库；原生 SVG 可精确控制每个元素的位置和样式；代码轻量，便于多场景合并

- 画布尺寸：800 × 500 px（固定）

- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  | P 代：[直刚毛♀] × [卷刚毛♂]          y=30~110   |
  |                    ↓                             |
  | F₁代：[直刚毛♀] × [直刚毛♂]          y=150~230  |
  |              ↙     ↘    ↙     ↘                 |
  |            配子   配子  配子   配子   y=260      |
  | F₂代：[格 1][格 2][格 3][格 4]       y=290~360  |
  |         比例标注框：2:1:1            y=380      |
  |                                                  |
  |              [◀上一步] 步骤 X/5 [下一步▶]  y=450 |
  +--------------------------------------------------+
  ```

- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-4) 跟踪当前步骤，steps 数组存储每步应显示的元素 ID 列表
  2. 坐标计算：所有元素使用绝对坐标（SVG 原生坐标系统），避免相对定位导致的偏移
  3. 动画曲线：箭头闪烁用 CSS animation (opacity 0.3→1→0.3, 0.8s ease-in-out infinite)
  4. 事件绑定：按钮点击事件绑定到 updateStep() 函数，更新 currentStep 并调用 renderStep()
  5. 元素显隐：用 display="none"/"block" 或 opacity 控制元素显示，保持布局稳定

- ID 命名规范：
  - 所有元素 ID 以 scene2- 为前缀
  - 示例：scene2-p-female, scene2-p-male, scene2-f1-female, scene2-f2-box1, scene2-btn-prev, scene2-btn-next

- IIFE 隔离：
  ```javascript
  (function() {
    // 所有 JS 代码包裹在此
    let currentStep = 0;
    const steps = [...];
    function renderStep() {...}
    function updateStep(delta) {...}
    // 事件绑定
    document.getElementById('scene2-btn-prev').addEventListener('click', () => updateStep(-1));
    document.getElementById('scene2-btn-next').addEventListener('click', () => updateStep(1));
  })();
  ```
