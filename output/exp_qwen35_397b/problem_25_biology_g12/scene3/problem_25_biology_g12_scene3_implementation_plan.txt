[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 按钮"上一步"：position absolute, x=320, y=455, 宽 80px, 高 30px, 背景 #e0e0e0
  - 按钮"下一步"：position absolute, x=400, y=455, 宽 80px, 高 30px, 背景 #2196f3, 文字白色
  - 步骤指示器：position absolute, x=360, y=465, 文字"步骤 X/4"
- 教师操作流程：
  1. 初始展示题目测交实验，让学生观察图解
  2. 点击"下一步"显示问题标注，引导学生思考该实验的局限性
  3. 点击"下一步"展示正确方案，对比两种设计
  4. 点击"下一步"显示对比表格，总结两种方案的差异和验证效果
  5. 可随时点击"上一步"回退复习关键概念

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript。原因：本场景为遗传图解，主要是文本标签和简单箭头连线，无需复杂图表库；原生 SVG 可精确控制每个元素的位置和显隐状态
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +----------------------------------------------------------+
  |  [题目测交实验]              [正确测交方案]               |
  |  +----------------+          +----------------+          |
  |  | P 代：F1 雌×F2 雄 |          | P 代：卷雌×直雄 |          |
  |  | X^A X^a × X^a Y  |          | X^a X^a × X^A Y  |          |
  |  | 配子→后代→比例   |          | 配子→后代→比例   |          |
  |  +----------------+          +----------------+          |
  |  [问题标注框：无法区分...]    [结论标注框：可验证...]       |
  |                                                          |
  |  +----------------------------------------------------+  |
  |  | 实验方案 | 预期结果 | 能否验证 |                    |  |
  |  | 题目测交 | 1:1:1:1  |   否    |                    |  |
  |  | 正确测交 | 1:1      |   是    |                    |  |
  |  +----------------------------------------------------+  |
  |                                                          |
  |              [◀上一步]  [下一步▶]  步骤 X/4               |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-3) 跟踪当前步骤，数组 steps 定义每步应显示的元素 ID 列表
  2. 元素分组：将 SVG 元素按功能分组（left-experiment, right-experiment, problem-box, conclusion-box, comparison-table），每步控制各组的 display 属性
  3. 坐标计算：所有坐标硬编码在 SVG 中，确保与计划一致
  4. 事件绑定：按钮点击事件切换 currentStep，调用 updateDisplay() 函数更新各元素显隐
  5. 按钮状态：步骤 0 时"上一步"禁用，步骤 3 时"下一步"文字改为"完成"并禁用
- ID 命名规范：所有元素 ID 以 scene3- 为前缀，如 scene3-left-experiment, scene3-right-experiment, scene3-problem-box, scene3-conclusion-box, scene3-comparison-table, scene3-btn-prev, scene3-btn-next, scene3-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
