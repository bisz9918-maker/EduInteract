problem_26_biology_g12

场景导航：Scene 1 | Scene 2 | Scene 3

题目原文：

某研究性小组利用纯合的黑腹果蝇进行了如下实验：残翅♀×小翅♂，得到 F₁都是长翅，且长翅中♀♂比例接近 1：1；将 F₁雌雄果蝇相互交配，得到 F₂，结果如下表：

| F₂表现型 | 数量 | 小计 | 翅型比 |
|---------|------|------|--------|
| 长翅♀ | 548 | 804 | 9.43 |
| 长翅♂ | 256 | | |
| 小翅♀ | 0 | 239 | 2.81 |
| 小翅♂ | 239 | | |
| 残翅♀ | 153 | 321 | 3.76 |
| 残翅♂ | 168 | | |

题目分析：

本题涉及两对基因的遗传：一对位于常染色体，一对位于 X 染色体。F₂表型比例约为 9:3:4（长翅：小翅：残翅），且小翅性状仅出现在雄性中，表明存在基因互作（上位效应）与伴性遗传的综合效应。

整体讲解思路：

  1. 首先分析 F₂数据，发现 9:3:4 比例及性别差异
  2. 推断涉及两对基因，且一对与性别相关
  3. 确定基因位置：常染色体基因控制残翅/非残翅，X 染色体基因控制长翅/小翅
  4. 写出亲本及 F₁基因型
  5. 设计反交实验并预测结果

图示规划说明：

共设计 3 个图示：

  • SCENE_1：杂交遗传图解，展示从亲本到 F₂的完整遗传过程
  • SCENE_2：基因位置与互作机制图，解释两对基因如何控制翅型
  • SCENE_3：F₂表型比例可视化，直观呈现 9:3:4 比例及性别分布
步骤 1/5

本图示教学说明：

如何引导学生：

  1. 首先让学生观察 F₂数据表，提问：「F₂中三种翅型的比例接近多少？」（引导学生发现 9:3:4）
  1. 追问：「小翅性状在雌雄中分布有什么特点？」（引导学生发现小翅只出现在雄性）
  1. 结合图示步骤 0→1，让学生理解：残翅×小翅→全长翅，说明长翅对两者都是显性
  1. 步骤 2→3，展示 F₁产生的配子类型，解释为什么会出现 9:3:4 的比例

关键公式/推导：

设定基因：

  • 常染色体基因：A（非残翅，显性）/ a（残翅，隐性）
  • X 染色体基因：X^B（长翅，显性）/ X^b（小翅，隐性）

亲本基因型：

  • 残翅♀：aaX^BX^B
  • 小翅♂：AAX^bY

F₁基因型：

  • ♀：AaX^BX^b（长翅）
  • ♂：AaX^BY（长翅）

F₂表型条件：

  • 长翅：AX^B（需要 A 且需要 X^B）
  • 小翅：A_X^bY（需要 A 且雄性且 X^b）
  • 残翅：aa__（aa 纯合，无论 X 染色体基因如何）
步骤 1/4

本图示教学说明：

讲解要点：

  1. 基因定位依据：
  • F₂中小翅只出现在雄性→控制小翅的基因在 X 染色体上
  • F₂比例 9:3:4 是 9:3:3:1 的变式→涉及两对基因互作
  1. 上位效应解释：
  • aa 纯合时，无论 X 染色体上是什么基因，都表现为残翅
  • 这就是「残翅基因」对「长翅/小翅基因」的上位效应
  • 因此 9:3:3:1 变为 9:3:4（两个 3:1 中的隐性部分合并）
  1. 表型决定逻辑：

```
首先判断 A 基因座：
├── aa → 残翅（上位效应，直接决定）
└── A_ → 继续判断 B 基因座：
├── X^B_ → 长翅
└── X^bY（仅雄性）→ 小翅
```

关键概念：

  • 上位效应（epistasis）：一对基因掩盖另一对基因的表达
  • 伴性遗传：基因位于性染色体上，表型与性别相关

本图示教学说明：

引导学生观察：

  1. 切换到状态 0，让学生确认 F₂整体比例接近 9:3:4
  1. 切换到状态 1，提问：「为什么雌性没有小翅？」引导学生理解伴性遗传的特点
  1. 切换到状态 2，让学生比较实际值与理论值的吻合程度

反交实验预测（问题 3）：

反交：残翅♂(aaX^bY) × 小翅♀(AAX^BX^B)

F₁预期：

  • ♀：AaX^BX^b（长翅）
  • ♂：AaX^bY（小翅）

所以 F₁有两种翅型：雌性全为长翅，雄性全为小翅

F₁互交得 F₂：

  • 长翅：小翅：残翅 = 3:3:2（需要详细推导）

课堂讲解建议：

  1. 先让学生独立分析数据，发现规律
  2. 用 SCENE_1 展示完整遗传过程
  3. 用 SCENE_2 解释基因互作机制
  4. 用 SCENE_3 验证数据与理论的吻合
  5. 最后让学生独立完成反交实验的设计与预测
