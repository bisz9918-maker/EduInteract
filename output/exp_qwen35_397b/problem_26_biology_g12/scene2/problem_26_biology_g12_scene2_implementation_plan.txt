[分步序列]
- 初始状态（步骤 0）：显示两对染色体结构
  - 常染色体对（一对同源染色体，椭圆形状）
  - 性染色体 XY（X 较长，Y 较短）
  - 标签："常染色体"、"X 染色体"、"Y 染色体"
  - 互作图区域显示标题"基因互作机制"，但条件框和结果框隐藏

- 步骤 1：标注基因位置
  - 在常染色体上显示 A/a 基因座（蓝色圆点 + 标签）
  - 在 X 染色体上显示 B/b 基因座（红色圆点 + 标签）
  - 在 Y 染色体旁显示"无对应基因"标注
  - 用虚线框高亮基因所在区域

- 步骤 2：展示基因互作逻辑图
  - 显示条件框 1："A_ (有 A 基因)"
  - 显示条件框 2："B_ (有 B 基因)"
  - 显示三个结果框：长翅（绿）、小翅（橙）、残翅（灰）
  - 显示箭头连接，形成决策树：
    - 若 aa → 残翅（无论 B/b 如何）
    - 若 A_ 且 B_ → 长翅
    - 若 A_ 且 bb → 小翅

- 步骤 3（最终步骤）：总结表型决定条件公式
  - 显示完整公式框：
    - 长翅：A_ X^B_ （A 存在 且 X 染色体上有 B）
    - 小翅：A_ X^bY 或 A_ X^bX^b（A 存在 但无 B）
    - 残翅：aa_ _（aa 纯合，无论 B/b）
  - 所有元素高亮显示，形成完整认知链条

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于底部左侧，点击返回上一状态
  - 「下一步」按钮：位于底部右侧，点击进入下一状态
  - 步骤指示器：位于底部中央，显示当前步骤（如"步骤 2/4"）
- 教师操作流程：
  1. 初始展示染色体结构，讲解果蝇有 4 对染色体
  2. 点击「下一步」，揭示基因位置，强调 A/a 在常染色体、B/b 在 X 染色体
  3. 点击「下一步」，展示互作逻辑，解释为什么需要同时考虑两对基因
  4. 点击「下一步」，总结公式，联系 F2 代 9:3:4 比例的成因
  5. 可随时点击「上一步」回退复习关键概念

[技术实现]
- JS 库选择：原生 SVG（适合绘制染色体、基因位点、流程图箭头）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [800 × 500 画布]
  +----------------------------------------------------------+
  |                    两对基因的位置与互作机制               |
  |                                                          |
  |  +------------------+     +---------------------------+   |
  |  |   染色体示意图   |     |      基因互作逻辑图        |   |
  |  |                  |     |                           |   |
  |  |   ( )  ( )       |     |   [A_条件] → [B_条件]     |   |
  |  |   A    a         |     |      ↓         ↓  ↓       |   |
  |  |                  |     |   [残翅]   [长翅][小翅]   |   |
  |  |   |    |         |     |                           |   |
  |  |   X    Y         |     |   [表型决定条件公式]      |   |
  |  |   B               |     |                           |   |
  |  +------------------+     +---------------------------+   |
  |                                                          |
  |              [◀上一步]  步骤 X/4  [下一步▶]              |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用 currentStep 变量（0-3）跟踪当前步骤，steps 数组存储每步的可见元素 ID 列表
  2. 坐标计算：所有元素使用绝对坐标（SVG 坐标系），确保布局精确
  3. 动画曲线：元素出现使用淡入效果（opacity 0→1，duration 300ms）
  4. 事件绑定：按钮点击事件绑定到 updateStep() 函数，更新可见性并刷新步骤指示器
  5. 元素分组：使用<g>元素按步骤分组，便于批量显示/隐藏
- ID 命名规范：
  - 所有元素 ID 以 scene2- 为前缀
  - 示例：scene2-chromo-const（常染色体）、scene2-chromo-x（X 染色体）、scene2-gene-A（A 基因座）、scene2-flow-long（长翅结果框）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
