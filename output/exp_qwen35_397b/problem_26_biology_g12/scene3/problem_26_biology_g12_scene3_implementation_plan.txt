[分步序列]
- 初始状态（状态 0）：显示整体比例饼图
  - 可见元素：饼图三扇区、三个比例标签、图例区、状态按钮组
  - 隐藏元素：性别柱状图、对比柱状图
  - 教学点：F₂整体表型比例接近 9:3:4，验证自由组合定律

- 状态 1：点击「性别分布」按钮 → 切换为性别分组柱状图
  - 可见元素：♀柱状图（长翅、残翅有数据，小翅为 0）、♂柱状图（三种翅型均有）、性别标签、图例区、状态按钮组
  - 隐藏元素：饼图、对比柱状图
  - 教学点：雌性无小翅（0 只），雄性有三种翅型，揭示伴性遗传特征

- 状态 2：点击「理论对比」按钮 → 切换为理论值与实际值对比柱状图
  - 可见元素：三组对比柱（理论边框柱 + 实际填充柱）、理论/实际标签、图例区、状态按钮组
  - 隐藏元素：饼图、性别柱状图
  - 教学点：实际数据与理论值 9:3:4 高度吻合，验证遗传假设

[交互方案]
- 交互类型：多状态切换（3 个按钮）
- 控件说明：
  - 按钮 1「整体比例」(260,25,90×30)：切换到状态 0，显示饼图
  - 按钮 2「性别分布」(355,25,90×30)：切换到状态 1，显示性别分组柱状图
  - 按钮 3「理论对比」(450,25,90×30)：切换到状态 2，显示理论实际对比图
- 教师操作流程：
  1. 初始展示饼图，讲解 F₂整体比例 9:3:4 验证自由组合定律
  2. 点击「性别分布」，展示♀♂差异，引导学生发现雌性无小翅的伴性遗传特征
  3. 点击「理论对比」，展示实际数据与理论值的吻合度，验证遗传假设

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：图表为静态几何图形（饼图扇形、柱状图矩形），无需复杂动画库；原生 SVG 轻量且易于状态切换
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [800×500 画布]
  ┌─────────────────────────────────────────────────────────────┐
  │  [整体比例] [性别分布] [理论对比]     ← 状态切换按钮 (y=20-60)│
  ├─────────────────────────────────────────────────────────────┤
  │                                                             │
  │           ┌─────────────────────────┐                       │
  │           │     主图表区            │                       │
  │           │  (饼图/柱状图/对比图)   │  (y=80-380)           │
  │           │                         │                       │
  │           └─────────────────────────┘                       │
  │                                                             │
  ├─────────────────────────────────────────────────────────────┤
  │  ■长翅  ■小翅  ■残翅  ■雌性  ■雄性   ← 图例区 (y=390-430)   │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0/1/2），点击按钮时更新状态并重新渲染
  2. 坐标计算：饼图扇形使用 SVG path 的 A 命令绘制圆弧；柱状图高度按数据比例缩放（最大值 804 对应 140px）
  3. 事件绑定：三个按钮分别绑定 onclick 事件，调用 switchState(n) 函数
  4. 元素显隐：使用 display:none / display:block 或 SVG 的 visibility 属性控制各状态元素显隐
- ID 命名规范：所有元素 ID 以 scene3- 为前缀
  - 按钮：scene3-btn-state0、scene3-btn-state1、scene3-btn-state2
  - 饼图：scene3-pie、scene3-pie-long、scene3-pie-small、scene3-pie-vestigial
  - 柱状图：scene3-bar-female-long、scene3-bar-male-long 等
  - 图例：scene3-legend-long、scene3-legend-small 等
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
