[图示主题与整合说明]
- 本图示主题：遗传概率计算可视化——亲代基因型到子代表现型概率
- 整合的步骤/概念：整合了Ⅱ5×Ⅱ6婚配的基因型推导、配子组合（棋盘格/Punnett square）、子代概率计算；以及Ⅲ2×Ⅲ3婚配的概率计算
- 教学价值：教师可逐步展示从亲代表现型→基因型推导→配子类型→棋盘格组合→子代概率计算的完整逻辑链，帮助学生理解遗传概率计算的步骤和方法。分步导航允许教师根据学生理解程度控制节奏，随时回退复习关键步骤。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "上一步"按钮：位于(320,450)，尺寸70×30，点击后返回上一状态（步骤0时禁用）
  - "下一步"按钮：位于(410,450)，尺寸70×30，点击后进入下一状态（步骤5时变为"重新开始"）
- 教师操作流程：
  1. 初始展示亲代表现型，引导学生回忆系谱图信息
  2. 点击"下一步"推导基因型，讲解甲病遗传方式判断依据
  3. 点击"下一步"显示配子，讲解减数分裂产生配子的过程
  4. 点击"下一步"显示棋盘格，逐一讲解每个单元格的基因型和表现型
  5. 点击"下一步"显示概率计算，讲解独立事件概率乘法规则
  6. 点击"下一步"切换到Ⅲ2×Ⅲ3计算，对比两代婚配的概率差异
  7. 可随时点击"上一步"回退复习关键步骤

[技术实现]
- JS库选择：原生SVG（简单几何图形和文本，无需额外库）
- 画布尺寸：800×500px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────┐
  │              Ⅱ5×Ⅱ6 婚配概率计算 (y=35)              │
  ├─────────────────────────────────────────────────────┤
  │  [Ⅱ5框]  [Ⅱ6框]           [棋盘格]      [概率框]   │
  │  (80,70) (260,70)        (250,240)    (600,280)   │
  │     ↓       ↓              4×4网格                  │
  │   配子A   配子A          单元格填充                 │
  │   配子a   配子a          绿/红色                    │
  │                                                  │
  │  ───────────────────────────────────────────────  │
  │              Ⅲ2×Ⅲ3 概率计算（步骤5显示）            │
  │  [Ⅲ2信息]  [Ⅲ3信息]              [结果：1/9]      │
  ├─────────────────────────────────────────────────────┤
  │         [◀上一步]  [下一步▶]   (y=450)             │
  └─────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用currentState变量(0-5)跟踪当前步骤，states数组存储每步的显示配置
  2. 坐标计算：所有元素使用绝对坐标，棋盘格单元格位置通过基准坐标+偏移计算
  3. 动画曲线：元素出现使用fade-in动画（opacity 0→1，duration 300ms）
  4. 事件绑定：按钮点击事件绑定到updateState函数，根据方向更新currentState
  5. 元素显隐：每步调用renderState(currentState)根据配置显示/隐藏元素
  6. 按钮状态：步骤0禁用"上一步"，步骤5将"下一步"文本改为"重新开始"
- ID命名规范：所有元素ID以"scene2-"为前缀
  - scene2-title, scene2-ii5-box, scene2-ii6-box
  - scene2-ii5-genotype, scene2-ii6-genotype
  - scene2-gamete-ii5-A, scene2-gamete-ii5-a, scene2-gamete-ii6-A, scene2-gamete-ii6-a
  - scene2-punnett-grid, scene2-cell-1至scene2-cell-9
  - scene2-prob-normal, scene2-prob-boy, scene2-prob-final
  - scene2-separator, scene2-iii2-info, scene2-iii3-info, scene2-iii-result
  - scene2-btn-prev, scene2-btn-next
- IIFE隔离：所有JS代码包裹在(function() { ... })()中，避免全局变量污染
