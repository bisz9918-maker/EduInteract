[图示主题与整合说明]
- 本图示主题：6 组交配实验数据的可视化对比
- 整合的内容：表格中 6 组交配组合的亲本表型、产仔次数、子代有毛/无毛数量及性别分布

[分步序列]
共 5 个步骤（步骤 0-4），教师可通过「上一步」「下一步」按钮导航：

**步骤 0（初始状态）：展示完整表格原始数据**
- 显示：所有 6 组柱状图（低透明度 20%）、坐标轴、图例、所有标签
- 高亮：无
- 目的：让学生整体观察 6 组数据的分布情况

**步骤 1：高亮第 4 组（无毛×无毛→全无毛）**
- 显示：所有元素保持
- 高亮：第 4 组柱子（有毛柱=0，无毛柱=11），填充透明度 80%，边框 3px
- 亲本标签「♀无×♂无」加粗显示
- 目的：引导学生观察无毛×无毛后代全无毛（或有毛为 0），说明无毛为隐性纯合

**步骤 2：高亮第 5、6 组（有毛×无毛→全有毛）**
- 显示：所有元素保持
- 高亮：第 5 组（有毛=13，无毛=0）和第 6 组（有毛=40，无毛=0）
- 亲本标签「♀无×♂有」「♀有×♂无」加粗显示
- 目的：引导学生观察有毛×无毛后代全有毛，说明有毛为显性性状

**步骤 3：高亮第 1、2、3 组（展示比例关系）**
- 显示：所有元素保持
- 高亮：第 1 组（12:9≈1:1）、第 2 组（27:20≈1:1）、第 3 组（110:29≈3:1）
- 目的：验证遗传比例，第 3 组有毛×有毛→3:1 说明有毛为显性杂合

**步骤 4：叠加理论比例参考线，对比实际数据**
- 显示：所有元素 + 理论比例虚线（y=280 对应 100，y=180 对应 200）
- 高亮：所有组别恢复正常透明度，参考线显示
- 目的：让学生对比实际数据与理论比例的接近程度，理解统计规律

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 (320,455)，点击后返回上一状态（步骤 0 时禁用）
  - 「下一步」按钮：位于 (420,455)，点击后进入下一状态（步骤 4 时禁用）
  - 步骤指示器：位于 (400,430)，显示当前步骤「步骤 X/5」
- 教师操作流程：
  1. 加载图示后默认显示步骤 0（完整数据概览）
  2. 点击「下一步」→步骤 1，高亮第 4 组，提问学生「无毛×无毛后代有什么特点？」
  3. 点击「下一步」→步骤 2，高亮第 5、6 组，提问「有毛×无毛后代全是什么性状？说明什么？」
  4. 点击「下一步」→步骤 3，高亮第 1、2、3 组，引导学生计算比例
  5. 点击「下一步」→步骤 4，显示理论比例线，对比实际数据
  6. 可随时点击「上一步」回退复习

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：柱状图结构简单，原生 SVG 足够实现；无需额外库依赖，加载快
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────────────────┐
  │                    6 组交配实验数据对比                    [图例]   │ y=20-65
  ├─────────────────────────────────────────────────────────────────────┤
  │  250│                                                               │
  │  200│  ┌───┐                                                       │
  │  150│  │   │                                                       │
  │  100│  │   │  ┌───┐                                                │ y=80-380
  │   50│  │   │  │   │  ┌───┐                                         │
  │    0├──┴───┴──┴───┴──┴───┴──┴───┴──┴───┴──┴───┴──┴───┴──┴───┴──┤
  │       组 1   组 2   组 3   组 4   组 5   组 6                      │ y=380-395
  ├─────────────────────────────────────────────────────────────────────┤
  │                    步骤 1/5                                        │ y=430
  │              [上一步]          [下一步]                            │ y=455-485
  └─────────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-4) 跟踪当前步骤，steps 数组存储每步的高亮配置
  2. 坐标计算：柱子高度 = (数值/250) × 300，y 坐标 = 380 - 高度
  3. 高亮实现：通过修改 rect 的 fill-opacity (0.2→0.8) 和 stroke-width (1→3)
  4. 按钮禁用：步骤 0 时禁用「上一步」，步骤 4 时禁用「下一步」（opacity=0.5, pointer-events=none）
  5. 事件绑定：按钮点击事件绑定到 updateStep() 函数，更新视图
- ID 命名规范：所有元素 ID 以 scene1- 为前缀
  - scene1-bar-hairy-1 ~ scene1-bar-hairy-6（有毛柱子）
  - scene1-bar-bald-1 ~ scene1-bar-bald-6（无毛柱子）
  - scene1-label-group-1 ~ scene1-label-group-6（组别标签）
  - scene1-label-parent-1 ~ scene1-label-parent-6（亲本标签）
  - scene1-label-value-hairy-1 ~ scene1-label-value-hairy-6（有毛数值）
  - scene1-label-value-bald-1 ~ scene1-label-value-bald-6（无毛数值）
  - scene1-btn-prev（上一步按钮）
  - scene1-btn-next（下一步按钮）
  - scene1-step-indicator（步骤指示器）
  - scene1-ref-line-100 / scene1-ref-line-200（理论比例线）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
- 步骤配置对象：
  ```javascript
  const steps = [
    { highlight: [] },  // 步骤 0：无高亮
    { highlight: ['group-4'] },  // 步骤 1：高亮第 4 组
    { highlight: ['group-5', 'group-6'] },  // 步骤 2
    { highlight: ['group-1', 'group-2', 'group-3'] },  // 步骤 3
    { highlight: [], showRefLines: true }  // 步骤 4：显示参考线
  ];
  ```
