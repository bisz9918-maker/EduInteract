[图示主题与整合说明]
- 本图示主题：关键组别的遗传图解与基因型推导

- 隐藏：结论框

- 步骤指示器："步骤 4/4"

回退逻辑：
- 点击"上一步"反向执行上述步骤，隐藏对应元素

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - "上一步"按钮：位于 SVG 内底部左侧 (650,450)，80×30px，灰色背景，步骤 0 时禁用
  - "下一步"按钮：位于 SVG 内底部右侧 (750,450)，80×30px，蓝色背景 (#1565c0)，步骤 3 时禁用
  - 步骤指示器：位于两按钮之间 (550,455)，显示"步骤 X/4"
- 教师操作流程：
  1. 初始展示第 4 组（无毛×无毛），讲解纯合/杂合判断
  2. 点击"下一步"展示第 5 组（♀无毛×♂有毛），引导学生记录子代比例
  3. 点击"下一步"展示第 6 组（♀有毛×♂无毛），强调与第 5 组的正交反交关系
  4. 点击"下一步"显示结论框，总结"正交反交结果一致→常染色体遗传"
  5. 可随时点击"上一步"回退复习关键步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：遗传图解为静态文本和简单箭头，无需复杂动画库；原生实现轻量且易于多场景合并
- 画布尺寸：800×500px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────┐
  │  第 4 组 (y=40~180)                                      │
  │  ┌─────────────────────────────────┐                    │
  │  │ 亲本→配子→子代基因型→子代表型   │                    │
  │  └─────────────────────────────────┘                    │
  │                                                         │
  │  第 5 组 (y=210~350)        第 6 组 (y=210~350)          │
  │  ┌─────────────────┐       ┌─────────────────┐          │
  │  │ 亲本→配子→子代  │ ←→  │ 亲本→配子→子代  │          │
  │  └─────────────────┘       └─────────────────┘          │
  │                                                         │
  │  ┌─────────────────────────────────────────────────┐    │
  │  │    正交反交结果一致→常染色体遗传 (结论框)        │    │
  │  └─────────────────────────────────────────────────┘    │
  │                                                         │
  │  [上一步]  步骤 X/4  [下一步]  (控件栏 y=440~490)        │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 `currentStep` (0~3) 跟踪当前步骤，数组 `stepElements` 存储每步需显示的元素 ID
  2. 元素分组：每组遗传图解的 5 个元素（标题、亲本、配子、子代基因型、子代表型）用 `<g>` 分组，ID 格式 `scene2-group4`、`scene2-group5`、`scene2-group6`
  3. 动画实现：用 CSS `opacity` 过渡实现淡入淡出（`transition: opacity 0.3s ease`）
  4. 事件绑定：按钮点击事件绑定到 `scene2-btn-prev` 和 `scene2-btn-next`，在 IIFE 内闭包
  5. 按钮状态：步骤 0 时禁用"上一步"（`opacity: 0.5, pointer-events: none`），步骤 3 时禁用"下一步"
- ID 命名规范：
  - 所有元素 ID 以 `scene2-` 为前缀
  - 示例：`scene2-group4`、`scene2-group5`、`scene2-group6`、`scene2-arrow-5-6`、`scene2-conclusion-box`、`scene2-btn-prev`、`scene2-btn-next`、`scene2-step-indicator`
- IIFE 隔离：
  ```javascript
  (function() {
      // 所有 JS 代码包在此 IIFE 中
      let currentStep = 0;
      const stepElements = [...];
      function updateStep() { ... }
      document.getElementById('scene2-btn-next').addEventListener('click', ...);
      document.getElementById('scene2-btn-prev').addEventListener('click', ...);
  })();
  ```
