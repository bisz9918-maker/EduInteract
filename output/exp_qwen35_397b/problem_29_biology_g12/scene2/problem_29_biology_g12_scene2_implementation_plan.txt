[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "上一步"按钮：位于(280,455)，蓝色矩形，点击后退到前一状态
  - "下一步"按钮：位于(420,455)，蓝色矩形，点击前进到下一状态
  - 步骤指示器：可选显示当前步骤编号（如"步骤2/5"）
- 教师操作流程：
  1. 初始状态展示模板链a和b的基本结构
  2. 点击"下一步"高亮a链3'端，讲解引物识别位点
  3. 点击"下一步"展示引物Ⅰ与a链配对，讲解互补原则
  4. 点击"下一步"高亮b链3'端，引导学生思考引物Ⅱ位置
  5. 点击"下一步"展示引物Ⅱ与b链配对，总结方向性原则
  6. 可随时点击"上一步"回退复习关键概念

[技术实现]
- JS库选择及原因：原生SVG + 原生JavaScript
  - 原因：几何元素简单（线段、矩形、文字），无需复杂库；原生SVG便于精确控制坐标和样式；代码轻量，加载快
- 画布尺寸：800×500px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +----------------------------------------------------------+
  |              引物与模板链互补配对详解                     |
  +--------------------------+-------------------------------+
  | [左侧区域]               | [右侧区域]                    |
  | a链 5'-G-G-...-T-C-3'    | b链 3'-C-C-...-A-G-5'        |
  |                          |                               |
  | b链 3'-C-C-...-A-G-5'    | a链 5'-G-G-...-T-C-3'        |
  |                          |                               |
  | 引物Ⅰ 5'-G-G-OH          | 引物Ⅱ 5'-G-G-OH              |
  +--------------------------+-------------------------------+
  |         [总结区：引物方向必须5'→3']                       |
  +----------------------------------------------------------+
  |              [◀上一步]          [下一步▶]                 |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用数组存储6个状态（步骤0-5），每个状态定义显示/隐藏的元素ID列表
  2. 坐标计算：所有元素坐标硬编码，确保与布局表一致
  3. 动画曲线：元素出现使用淡入效果（opacity 0→1，300ms ease-in-out）
  4. 事件绑定：按钮点击事件绑定状态切换函数，更新当前步骤索引
  5. 按钮状态管理：步骤0禁用"上一步"，步骤5禁用"下一步"
- ID命名规范：所有交互元素ID必须以`scene2-`为前缀
  - 示例：scene2-a-chain-left, scene2-b-chain-left, scene2-primer1, scene2-primer2
  - scene2-highlight1, scene2-highlight2（高亮区）
  - scene2-dash1, scene2-dash2, scene2-dash3, scene2-dash4（配对虚线）
  - scene2-summary（总结区）
  - scene2-btn-prev, scene2-btn-next（按钮）
- IIFE隔离：所有JS包在(function() { ... })()中，避免全局变量污染
- 状态数据结构示例：
  ```javascript
  const states = [
    { show: ['scene2-a-chain-left', 'scene2-b-chain-left', 'scene2-a-chain-right', 'scene2-b-chain-right'], hide: ['scene2-primer1', 'scene2-primer2', 'scene2-highlight1', 'scene2-highlight2', 'scene2-dash1', 'scene2-dash2', 'scene2-dash3', 'scene2-dash4', 'scene2-summary'] },
    { show: [...states[0].show, 'scene2-highlight1'], hide: [...] },
    // ... 其他状态
  ];
  ```
