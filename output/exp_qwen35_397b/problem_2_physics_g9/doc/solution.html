problem_2_physics_g9

场景导航：Scene 1 | Scene 2 | Scene 3

题目原文：

如图所示的实验中，小车从斜面的某一高度由静止开始滑下，撞击静止于水平木板上的木板（不计空气阻力）。则下列说法中正确的是（）

A. 小车在斜面上下滑的过程中，小车的动能转化为重力势能
B. 小车在斜面上下滑的过程中，小车的机械能增大
C. 木块对木板的压力和木板对木块的支持力是一对平衡力
D. 若木板的表面光滑且足够长，则被撞击后的木块所获得的动能将保持不变

题目分析：

本题考查能量转化与守恒、牛顿第三定律、平衡力与作用力反作用力的区别。

  1. 小车下滑过程：重力势能转化为动能（高度降低，速度增大）
  2. 机械能变化：实际存在摩擦，机械能减小；理想无摩擦时机械能守恒
  3. 力的辨析：木块对木板的压力与木板对木块的支持力是作用力与反作用力（作用在不同物体上），不是平衡力
  4. 理想光滑情况：无摩擦力，木块被撞击后匀速运动，动能保持不变

整体讲解思路：

本套图示设计 3 个场景，分别对应：

  • Scene 1：能量转化过程（小车下滑的能量变化）
  • Scene 2：受力分析（区分平衡力与作用力反作用力）
  • Scene 3：理想光滑情况对比（有摩擦 vs 无摩擦）

每个场景采用分步按钮导航，教师可逐步引导学生观察和分析。

步骤 1/4

教学说明：

本图示用于讲解选项 A 和 B，引导学生理解能量转化过程。

讲解要点：

  1. 初始状态（步骤 0）：小车在斜面顶端，具有最大重力势能 Ep = mgh，动能为零
  2. 下滑过程（步骤 1）：高度降低，速度增大，重力势能转化为动能
  3. 能量关系（步骤 2）：通过条形图直观展示 Ep 减小、Ek 增大的过程
  4. 撞击过程（步骤 3）：小车动能传递给木块

关键公式：

  • 重力势能：Ep = mgh
  • 动能：Ek = ½mv²
  • 机械能：E = Ep + Ek

选项 A 辨析： 小车下滑是重力势能转化为动能，而非动能转化为重力势能，故 A 错误

选项 B 辨析： 实际存在摩擦，部分机械能转化为内能，机械能减小；即使理想无摩擦，机械能守恒也不会增大，故 B 错误

平衡力：作用在同一物体（木块）上
作用力与反作用力：作用在不同物体上
比较项目 平衡力 作用力与反作用力
作用物体 同一物体 不同物体
力的性质 可以不同 一定相同
依存关系 独立存在 同时产生同时消失
步骤 1/4

教学说明：

本图示用于讲解选项 C，帮助学生区分平衡力与作用力反作用力。

讲解要点：

  1. 平衡力的条件：
  • 大小相等
  • 方向相反
  • 作用在同一直线上
  • 作用在同一物体上
  1. 作用力与反作用力的条件（牛顿第三定律）：
  • 大小相等
  • 方向相反
  • 作用在同一直线上
  • 作用在不同物体上

选项 C 辨析：

木块对木板的压力（作用在木板上）与木板对木块的支持力（作用在木块上）是作用力与反作用力，不是平衡力，故 C 错误

记忆口诀：

  • 平衡力：同物、等大、反向、共线
  • 作用力反作用力：异物、等大、反向、共线

教学说明：

本图示用于讲解选项 D，帮助学生理解牛顿第一定律和动能守恒的条件。

讲解要点：

  1. 实际粗糙表面：木块受摩擦力作用，做减速运动，动能转化为内能
  2. 理想光滑表面：无摩擦力，木块不受水平方向外力，根据牛顿第一定律保持匀速直线运动
  3. 动能分析：匀速运动时速度不变，质量不变，故动能 Ek = ½mv² 保持不变

选项 D 辨析：

若木板表面光滑且足够长，木块被撞击后不受摩擦力，将做匀速直线运动，动能保持不变，故 D 正确

完整解答：

正确答案：D

  • A 错误：下滑过程是重力势能转化为动能
  • B 错误：机械能不会增大（实际减小或理想守恒）
  • C 错误：压力与支持力是作用力与反作用力，不是平衡力
  • D 正确：光滑表面无摩擦，木块匀速运动，动能不变

课堂讲解建议：

  1. 先展示 Scene 1，让学生观察能量转化过程，排除选项 A、B
  2. 再用 Scene 2 讲解力的辨析，排除选项 C
  3. 最后用 Scene 3 对比两种情况，确认选项 D 正确
  4. 可引导学生思考：若斜面也光滑，小车到达底端的速度如何计算？
