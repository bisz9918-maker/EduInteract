[图示主题与整合说明]
- 本图示主题：木块受力分析 — 平衡力与作用力反作用力的区别
- 整合的内容：木块的受力示意图、平衡力展示（重力 G 与支持力 N）、作用力反作用力展示（压力 F 压与支持力 N）

[分步序列]
步骤 0（初始状态）：
- 显示：木板、木块、三个力箭头（G、N、F 压）及对应标签
- 隐藏：高亮框、对比表格
- 状态：木块静止在木板上，三个力向量清晰可见

步骤 1（点击「下一步」）：
- 显示：平衡力高亮框（蓝色虚线框住 G 和 N 箭头）
- 高亮：重力 G 和支持力 N 箭头加粗至 3px
- 表格区显示文字：「平衡力：作用在同一物体（木块）上」
- 教师讲解：重力 G 和支持力 N 都作用在木块上，大小相等方向相反，是一对平衡力

步骤 2（点击「下一步」）：
- 隐藏：平衡力高亮框
- 显示：作用力反作用力高亮框（红色虚线框住 N 和 F 压箭头）
- 高亮：支持力 N 和压力 F 压箭头加粗至 3px
- 表格区显示文字：「作用力与反作用力：作用在不同物体上」
- 教师讲解：支持力 N 是木板对木块的力，压力 F 压是木块对木板的力，作用在不同物体上

步骤 3（点击「下一步」）：
- 显示：完整对比表格（2 列 3 行）
- 表格内容：
  | 比较项目 | 平衡力 | 作用力与反作用力 |
  |----------|--------|------------------|
  | 作用物体 | 同一物体 | 不同物体 |
  | 力的性质 | 可以不同 | 一定相同 |
  | 依存关系 | 独立存在 | 同时产生同时消失 |
- 教师讲解：总结两者的本质区别

步骤 4（点击「上一步」可回退）：
- 支持随时回退复习，高亮状态和表格内容相应隐藏

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 (280,455)，80×30px，灰色背景，点击回退到前一状态
  - 「下一步」按钮：位于 (440,455)，80×30px，蓝色背景，点击进入下一状态
  - 步骤指示器：位于两按钮之间 (400,465)，显示「步骤 X/4」
- 教师操作流程：
  1. 初始状态展示木块受力全貌
  2. 点击「下一步」高亮平衡力，讲解「作用在同一物体」
  3. 点击「下一步」高亮作用力反作用力，讲解「作用在不同物体」
  4. 点击「下一步」展示对比表格，系统总结两者区别
  5. 可随时点击「上一步」回退复习关键概念

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（矩形、线段、箭头），无需复杂库；原生实现轻量且易于多场景合并
- 画布尺寸：800×500 px（固定）
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │                    受力示意图区 (y=20~320)                   │
  │                                                             │
  │         木块                                                 │
  │        ┌──────┐                                             │
  │        │      │  N↑                                         │
  │        │  ·   │─────                                        │
  │        │      │  G↓                                         │
  │        └──────┘  F 压↓                                      │
  │  ─────────────────────────────────────── 木板                │
  │                                                             │
  ├─────────────────────────────────────────────────────────────┤
  │                    对比表格区 (y=340~430)                    │
  │  ┌─────────────────────────────────────────────────────┐    │
  │  │ 比较项目 │  平衡力  │ 作用力与反作用力 │              │    │
  │  │──────────│─────────│─────────────────│              │    │
  │  │ 作用物体 │ 同一物体 │    不同物体     │              │    │
  │  │──────────│─────────│─────────────────│              │    │
  │  │ 力的性质 │ 可以不同 │    一定相同     │              │    │
  │  └─────────────────────────────────────────────────────┘    │
  ├─────────────────────────────────────────────────────────────┤
  │                    控件区 (y=440~490)                        │
  │           [◀上一步]   步骤 2/4   [下一步▶]                   │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用 currentState 变量（0-3）跟踪当前步骤，steps 数组存储每步的显示配置
  2. 箭头绘制：用 SVG <marker> 定义箭头头部，<line> + <marker-end> 组合绘制
  3. 高亮框：用 SVG <rect> 设置 stroke-dasharray="5,5" 实现虚线效果
  4. 表格渲染：用 HTML <table> 绝对定位在 SVG 容器内，步骤 3 时显示
  5. 事件绑定：按钮点击事件切换 currentState，调用 renderStep() 更新显示
  6. 边界处理：步骤 0 时禁用「上一步」，步骤 3 时「下一步」变为「完成」或禁用
- ID 命名规范：
  - 所有元素 ID 以 scene2- 为前缀
  - 示例：scene2-wood-block（木块）、scene2-wood-board（木板）、scene2-arrow-g（重力箭头）、scene2-arrow-n（支持力箭头）、scene2-arrow-f（压力箭头）、scene2-highlight-balance（平衡力高亮框）、scene2-highlight-action-reaction（作用反作用高亮框）、scene2-table（对比表格）、scene2-btn-prev（上一步按钮）、scene2-btn-next（下一步按钮）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
- CDN 引入：无需外部库，纯原生实现
