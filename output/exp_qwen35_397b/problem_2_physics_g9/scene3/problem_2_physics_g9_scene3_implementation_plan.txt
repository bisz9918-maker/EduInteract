[图示主题与整合说明]
- 本图示主题：理想光滑表面 vs 实际粗糙表面的运动对比

[分步序列]
多状态切换交互（3 个状态，通过底部按钮切换）：

- 状态 0（初始状态 - 实际粗糙表面）：
  - 显示左侧装置完整：斜面、带斜线纹理的水平面、小车、木块
  - 木块上方显示蓝色速度箭头 v（向右）
  - 木块下方显示红色摩擦力箭头 f（向左）
  - 显示「粗糙表面」「减速运动」「动能减小」标签
  - 右侧装置灰度显示（透明度 50%）
  - v-t 图区域隐藏

- 状态 1（理想光滑表面）：
  - 显示右侧装置完整：斜面、无纹理水平面、小车、木块
  - 木块上方显示蓝色速度箭头 v（向右）
  - 无摩擦力箭头
  - 显示「光滑表面」「匀速运动」「动能不变」标签
  - 左侧装置灰度显示（透明度 50%）
  - v-t 图区域隐藏

- 状态 2（v-t 图像对比）：
  - 左右装置均灰度显示（透明度 30%）
  - 显示完整 v-t 坐标系
  - 红色斜线：从 (120,360) 到 (400,420)，标注「动能减小」
  - 蓝色水平线：从 (120,360) 到 (680,360)，标注「动能不变」
  - 显示「v」「t」轴标签

[交互方案]
- 交互类型：多状态切换（3 个按钮）
- 控件说明：
  - 按钮 1「实际粗糙」：位置 (180,465)，切换到状态 0，显示粗糙表面减速运动
  - 按钮 2「理想光滑」：位置 (360,465)，切换到状态 1，显示光滑表面匀速运动
  - 按钮 3「v-t 图像」：位置 (540,465)，切换到状态 2，显示速度 - 时间图像对比
- 教师操作流程：
  1. 初始展示状态 0，讲解实际情况下木块受摩擦力减速停止，动能转化为内能
  2. 点击「理想光滑」切换到状态 1，讲解理想条件下无摩擦，木块匀速运动，动能不变
  3. 点击「v-t 图像」切换到状态 2，用图像直观对比两种情况的速度变化规律
  4. 可反复切换对比，强化学生对摩擦力影响的理解

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +------------------------------------------+
  |  [左侧装置]              [右侧装置]      |
  |   斜面 + 水平面           斜面 + 水平面   |
  |   小车→木块 [v] [f]       小车→木块 [v]  |
  |   粗糙表面 减速运动       光滑表面 匀速  |
  |                                          |
  |  [v-t 图像区域 - 状态 2 显示]             |
  |   v ↑                                    |
  |   |  \ 动能减小                          |
  |   |___\________ 动能不变 ___→ t         |
  |                                          |
  |  [实际粗糙] [理想光滑] [v-t 图像]        |
  +------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用 currentState 变量 (0/1/2) 跟踪当前状态
  2. 所有元素按状态分组，用 display/opacity 控制显示隐藏
  3. 按钮点击事件切换状态，更新所有元素可见性
  4. 当前状态按钮高亮（背景色加深），其他按钮正常
  5. 粗糙表面纹理用 SVG pattern 实现斜线填充
  6. 箭头用 SVG marker-end 实现
- ID 命名规范：所有元素 ID 以 scene3- 为前缀
  - scene3-left-ramp, scene3-left-surface, scene3-left-cart, scene3-left-block
  - scene3-right-ramp, scene3-right-surface, scene3-right-cart, scene3-right-block
  - scene3-vel-arrow-left, scene3-fric-arrow-left, scene3-vel-arrow-right
  - scene3-vt-axis, scene3-vt-rough, scene3-vt-smooth
  - scene3-btn-rough, scene3-btn-smooth, scene3-btn-vt
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局污染
