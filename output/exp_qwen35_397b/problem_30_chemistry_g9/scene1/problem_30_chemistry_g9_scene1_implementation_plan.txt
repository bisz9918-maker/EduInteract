[交互方案]

- 控件说明：
  - 「上一步」按钮：位于 SVG 底部左侧 (x=280, y=455)，宽 80px，高 30px，浅灰色背景#f5f5f5，深灰色文字#333333

- 教师操作流程：
  1. 初始展示原题空图，让学生观察物质间关系网络
  2. 点击「下一步」高亮 Y，提问"哪个物质连接最多？说明什么？"
  3. 点击「下一步」揭示 Y=稀盐酸，解释稀盐酸能与多种物质反应
  4. 点击「下一步」标注 N=氧化铁，提问"N 如何转化为铁？"
  5. 点击「下一步」标注 X、M，引导学生分析剩余两种物质
  6. 点击「下一步」显示最终结论，总结推断过程

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（圆圈、线段、箭头），无需复杂库；原生实现轻量、无外部依赖
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  
        Y(稀盐酸)
       / | \ \
      /  |  \ \
     X---M   N→铁
  
  [控件栏（在 SVG 内底部 y=440~490）]
  [◀上一步]  步骤 X/5  [下一步▶]
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-5) 跟踪当前步骤，数组 steps 存储每步的显示配置
  2. 元素 ID 命名：所有元素以 scene1- 为前缀，如 scene1-node-y、scene1-line-x-y、scene1-label-y 等
  3. 高亮实现：通过修改 stroke、stroke-width 属性实现，不创建新元素
  4. 标签显示/隐藏：通过 display 属性或 opacity 控制，初始 display="none"
  5. 箭头绘制：使用 SVG marker 或 path 绘制三角形箭头头部
  6. 事件绑定：按钮点击事件绑定到 updateStep() 函数，更新 currentStep 并重绘
  7. IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
- ID 命名规范：
  - 节点：scene1-node-x, scene1-node-y, scene1-node-m, scene1-node-n, scene1-node-fe
  - 连线：scene1-line-x-y, scene1-line-x-m, scene1-line-y-m, scene1-line-y-fe, scene1-line-y-n
  - 箭头：scene1-arrow-n-fe
  - 标签：scene1-label-x, scene1-label-y, scene1-label-m, scene1-label-n, scene1-label-fe
  - 物质标签：scene1-material-y, scene1-material-n, scene1-material-x, scene1-material-m
  - 提示文字：scene1-hint-y
  - 按钮：scene1-btn-prev, scene1-btn-next, scene1-step-indicator
