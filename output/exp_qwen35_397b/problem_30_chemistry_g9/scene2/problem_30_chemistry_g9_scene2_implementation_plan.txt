- 步骤 1：点击「下一步」→ X-Y 连线变为蓝色 #1565c0，显示标签「复分解」在连线上方 (275,100)

- 步骤 4：点击「下一步」→ Y-N 连线变为蓝色 #1565c0，显示标签「复分解」在连线下方 (480,180)；N→铁 箭头变为红色 #c62828，显示标签「氧化还原」在箭头右下 (590,180)

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 左下角 (50,450)，点击后退到前一状态
  - 「下一步」按钮：位于 SVG 右下角 (650,450)，点击前进到下一状态
  - 步骤指示器：位于底部中央 (400,460)，显示当前步骤编号（如"步骤 3/6"）
- 教师操作流程：
  1. 初始展示物质关系网络图，让学生观察物质间的反应关系
  2. 点击「下一步」逐步揭示每条边对应的反应类型
  3. 引导学生思考为什么是这种反应类型
  4. 最后展示四个选项及判断结果，逐一讲解每个选项的正误原因

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（圆形节点、直线连接、箭头），无需复杂库；原生实现轻量且易于状态管理
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |    X -------- Y -------- 铁                      |
  |     \        / \         /                       |
  |      \      /   \       /                        |
  |       \    /     \     /                         |
  |        \  /       \   /                          |
  |         \/         \ /                           |
  |         M          N                             |
  |                                                  |
  |   [反应类型标签分布在连线周围]                    |
  |                                                  |
  |  +--------+ +--------+ +--------+ +--------+     |
  |  | 选项 A | | 选项 B | | 选项 C | | 选项 D |     |
  |  |   ✗   | |   ✗   | |   ✗   | |   ✓   |     |
  |  +--------+ +--------+ +--------+ +--------+     |
  |                                                  |
  |  [◀上一步]          步骤 X/6         [下一步▶]   |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量 (0-5) 跟踪当前步骤，steps 数组存储每步的状态配置
  2. 每步状态包含：需要高亮的连线 ID、需要显示的标签 ID、需要更新的选项框样式
  3. 使用 CSS class 控制颜色变化（.highlight-blue、.highlight-green、.highlight-red）
  4. 选项框验证时使用内联样式设置背景色和显示✓/✗标记
  5. 按钮边界检查：步骤 0 时禁用「上一步」，步骤 5 时禁用「下一步」
- ID 命名规范：所有元素 ID 以 scene2- 为前缀
  - 节点：scene2-node-x, scene2-node-y, scene2-node-m, scene2-node-n, scene2-node-fe
  - 连线：scene2-line-xy, scene2-line-xm, scene2-line-ym, scene2-line-yfe, scene2-line-yn, scene2-arrow-nfe
  - 标签：scene2-label-xy, scene2-label-xm, scene2-label-ym, scene2-label-yfe, scene2-label-yn, scene2-label-nfe
  - 选项：scene2-opt-a, scene2-opt-b, scene2-opt-c, scene2-opt-d
  - 控件：scene2-btn-prev, scene2-btn-next, scene2-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
