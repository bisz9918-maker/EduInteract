[图示主题与整合说明]
- 本图示主题：体心立方（BCC）晶体结构的配位数与几何关系
- 整合内容：晶胞结构展示、体心原子配位数（8个顶点原子）、体对角线与最近邻距离的关系
- 教学价值：教师可逐步展示BCC晶胞结构，帮助学生理解体心原子的配位数为8，以及体对角线与最近邻原子距离的几何关系 d = (√3/2)a₁，为后续计算密度比奠定基础

[分步序列]
- 步骤0（初始状态）：显示完整BCC晶胞框架
  - 显示：立方体12条棱线、8个顶点原子（#1565c0）
  - 隐藏：体心原子、体心-顶点连线、体对角线、距离标注、配位数标签
  - 显示标题和边长a₁标注

- 步骤1：高亮体心原子
  - 新增显示：体心原子（#c62828，r=10px）
  - 保持：步骤0所有元素
  - 视觉变化：体心原子淡入动画（opacity:0→1，300ms）

- 步骤2：显示配位关系
  - 新增显示：8条体心-顶点连线（#1565c0实线）
  - 新增显示：配位数标签"配位数 = 8"（位置550,280）
  - 视觉变化：8条连线依次绘制动画（每条100ms延迟）

- 步骤3：标注几何关系（最终步骤）
  - 新增显示：体对角线（#2e7d32虚线，从左下前到右上后）
  - 新增显示：最近邻距离标签"d = (√3/2)a₁"（位置480,260）
  - 视觉变化：体对角线虚线绘制动画，距离标签淡入

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位置(350,460)，返回上一状态，步骤0时禁用
  - 「下一步」按钮：位置(450,460)，进入下一状态，步骤3时禁用
  - 步骤指示器：位置(400,460)，显示"步骤 X/4"
- 教师操作流程：
  1. 初始展示完整晶胞，让学生观察BCC结构特点
  2. 点击「下一步」高亮体心原子，强调体心位置
  3. 点击「下一步」显示8条连线，引出配位数概念
  4. 点击「下一步」显示体对角线和距离公式，建立几何关系
  5. 可随时点击「上一步」回退复习关键概念

[技术实现]
- JS库选择：原生SVG（简单几何图形首选，无需额外库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |              标题：体心立方(BCC)结构              | y=40
  |                                                  |
  |         [立方体晶胞]        配位数               |
  |        250,180 ~ 500,350     = 8                 | y=280
  |                                                  |
  |              边长 a₁                             | y=395
  |                                                  |
  |  [◀上一步]  步骤1/4  [下一步▶]                   | y=460
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用currentState变量(0-3)跟踪当前步骤，steps数组存储每步显示的元素ID列表
  2. 坐标计算：立方体采用斜二测投影，后方面相对前方面偏移(50,-30)
  3. 动画曲线：使用CSS transition实现淡入效果，opacity:0→1，duration:300ms
  4. 事件绑定：按钮点击事件切换状态，更新元素display/opacity属性
  5. 体对角线端点：左下前(250,380)到右上后(500,150)，中点约(375,265)
- ID命名规范：所有元素ID以scene1-为前缀
  - scene1-cube-front, scene1-cube-back, scene1-atom-vertex-1~8
  - scene1-atom-center, scene1-connector-1~8, scene1-diagonal
  - scene1-label-a1, scene1-label-d, scene1-label-coordination
  - scene1-btn-prev, scene1-btn-next, scene1-step-indicator
- IIFE隔离：所有JS代码包裹在(function() { ... })()中，避免全局污染
