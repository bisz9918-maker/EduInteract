[图示主题与整合说明]
- 本图示主题：面心立方（FCC）晶体结构的配位数与几何关系
- 整合的步骤/概念：晶胞结构展示、面心原子配位数（12个最近邻原子）、面对角线与最近邻距离的关系
- 教学价值：教师可通过分步演示，让学生直观理解FCC晶体中面心原子的12个最近邻分布，以及面对角线与原子间距的几何关系，帮助学生掌握配位数概念和晶体密度计算的基础

  5. 可随时点击「上一步」回退复习关键概念

[技术实现]
- JS库选择及原因：原生SVG
  - 原因：几何图形简单（立方体、圆形原子），SVG矢量图清晰，易于控制每个元素的显示/隐藏和样式变化
- 画布尺寸：800 × 500 px（固定画布）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |              [FCC晶胞立方体]                      |
  |              居中显示 200×200×200                |
  |                                                  |
  |                                    配位数=12     |
  |                                    d=(√2/2)a₂   |
  |                                                  |
  |                                    [边长a₂]      |
  |                                                  |
  |                                                  |
  |        [◀上一步]  步骤X/3  [下一步▶]             |
  +--------------------------------------------------+
  [控件栏在SVG内底部 y=440~490]
  ```
- 关键实现要点：
  1. 状态机设计：使用currentState变量(0-3)，每个状态对应一组显示的元素
  2. 坐标计算：立方体透视投影，后方面相对于前方面偏移(50,-50)
  3. 原子位置：顶点8个+面心6个共14个原子，预先计算好所有坐标
  4. 12个最近邻：对于右侧面心原子，最近邻包括：
     - 同一右侧面的4个顶点原子
     - 相邻4个面（顶面、底面、前面、后面）的面心原子
     - 共12个（FCC配位数为12）
  5. 动画曲线：元素显示使用淡入效果（opacity 0→1，300ms）
  6. 事件绑定：按钮点击事件切换状态，更新所有元素的display属性
- ID命名规范：所有交互元素ID必须以 scene2- 为前缀
  - scene2-cube-front, scene2-cube-back, scene2-atom-vertex-1~8
  - scene2-atom-face-1~6, scene2-highlight-atom
  - scene2-connection-1~12, scene2-diagonal-1~2
  - scene2-label-a2, scene2-label-d, scene2-label-coordination
  - scene2-btn-prev, scene2-btn-next, scene2-step-indicator
- IIFE隔离：所有JS包在 (function() { ... })() 中，避免全局变量污染
