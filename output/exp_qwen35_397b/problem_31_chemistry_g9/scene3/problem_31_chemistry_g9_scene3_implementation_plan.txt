[图示主题与整合说明]
- 本图示主题：两种晶体结构的边长比与密度比对比推导
- 整合的步骤/概念：BCC与FCC结构并列对比、最近邻距离相等条件、边长比推导、晶胞原子数统计、密度比计算

[分步序列]
- 初始状态（步骤0）：显示两个晶胞线框、所有原子球、边长标注a₁和a₂、两个标题。公式区、统计框、密度比公式均隐藏。
- 步骤1：点击「下一步」→ 显示最近邻距离公式"d₁ = (√3/2)a₁ = d₂ = (√2/2)a₂"于(400,370)，用#c62828红色高亮"="号。同时BCC体对角线和FCC面对角线虚线加粗高亮。
- 步骤2：点击「下一步」→ 显示边长比公式"a₁/a₂ = √2/√3"于(400,395)。步骤1公式保持显示。
- 步骤3：点击「下一步」→ 显示两个原子数统计框：左侧"BCC晶胞原子数 = 8×1/8 + 1 = 2"，右侧"FCC晶胞原子数 = 8×1/8 + 6×1/2 = 4"。步骤1-2公式保持显示。
- 步骤4：点击「下一步」→ 显示密度比公式"ρ₁/ρ₂ = (2/a₁³) / (4/a₂³) = (3√3)/(4√2)"于(400,420)，用#c62828红色边框矩形包围高亮。所有元素显示完成。

- 教师操作流程：

  2. 点击「下一步」显示最近邻距离相等条件，强调这是解题关键

  4. 点击「下一步」显示晶胞原子数统计，讲解均摊法计算
  5. 点击「下一步」显示最终密度比公式，完成推导

[技术实现]
- JS库选择及原因：原生SVG + 原生JavaScript。原因：几何图形简单（立方体线框、圆、直线），无需复杂库；SVG便于精确控制每个元素的显示/隐藏和样式；代码轻量易维护
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  BCC (910℃以下)           FCC (910℃以上)         | y=60
  |                                                  |
  |    +-------+                    +-------+         | y=80
  |   /       /|                   /       /|        |
  |  +-------+ |                  +-------+ |        |
  |  |   •   | +                  | •   • | +        | y=200(体心/面心)
  |  |       |/                   | •   • |/         |
  |  +-------+                    +-------+          | y=320
  |    a₁                           a₂               | y=340
  |                                                  |
  |        [最近邻距离公式]                          | y=370
  |        [边长比公式]                              | y=395
  |  [BCC原子数]              [FCC原子数]            | y=415
  |        [密度比公式]                              | y=420
  +--------------------------------------------------+
  | [上一步]      步骤 X/5      [下一步]             | y=460
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量currentStep(0-4)跟踪当前步骤，数组stepElements存储每步需显示的元素ID
  2. 坐标计算：BCC晶胞左下(80,320)右上(320,80)，FCC晶胞左下(480,320)右上(720,80)，等距偏移
  3. 动画曲线：元素显示用淡入效果（opacity 0→1，300ms ease-out）
  4. 事件绑定：按钮点击事件绑定到stepChange函数，更新currentStep并调用renderStep()
  5. 按钮状态：每步更新后检查currentStep值，设置按钮disabled属性
- ID命名规范：所有交互元素ID必须以scene3-为前缀
  - scene3-bcc-cell, scene3-fcc-cell
  - scene3-bcc-atoms (组), scene3-fcc-atoms (组)
  - scene3-bcc-diagonals, scene3-fcc-diagonals
  - scene3-label-a1, scene3-label-a2
  - scene3-title-bcc, scene3-title-fcc
  - scene3-formula-distance, scene3-formula-ratio, scene3-formula-density
  - scene3-atomcount-bcc, scene3-atomcount-fcc
  - scene3-btn-prev, scene3-btn-next, scene3-step-indicator
- IIFE隔离：所有JS代码包在(function() { ... })()中，避免全局变量污染
