[分步序列]
- 初始状态（滑块 0%）：显示水平导管、A/B 端标签、HCl 分子聚集在左端、NH₃分子聚集在右端、分子质量标注。无运动轨迹，无白烟。
- 步骤 1（滑块 25%）：HCl 分子向右移动约 1/4 距离（至 x≈250），NH₃分子向左移动约 1/3 距离（至 x≈550）。显示虚线运动轨迹。
- 步骤 2（滑块 50%）：HCl 分子继续向右（至 x≈320），NH₃分子继续向左（至 x≈480）。NH₃移动距离明显大于 HCl，体现速率差异。
- 步骤 3（滑块 75%）：HCl 分子（至 x≈370），NH₃分子（至 x≈430）。两者接近相遇。
- 步骤 4（滑块 100%）：分子在 x≈400 处相遇（距 A 端约 1/3 处），显示白烟区域（云雾状）和相遇点标记竖线。显示"白烟"和"距 A 端近"标签。

  4. 拖动至 100%，展示白烟形成位置，解释为何靠近 A 端（HCl 分子质量大，速率慢）

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何元素简单（圆、矩形、路径），无需复杂库；拖拽交互用原生事件即可实现
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────┐
  │                    HCl=36.5        NH₃=17               │
  │                   HCl 分子        NH₃分子               │
  │  A 端  ○○○○                              ○○○○  B 端    │
  │  ┌─────────────────────────────────────────────────┐    │
  │  │                                                 │    │
  │  │     HCl→  →  →          ←  ←  ←NH₃             │    │
  │  │                    [白烟]                       │    │
  │  └─────────────────────────────────────────────────┘    │
  │                    距 A 端近        白烟                │
  │                                                         │
  │              拖动滑块观察分子运动                        │
  │         0%  [====●========]  50%       100%             │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用单个变量 sliderValue (0-100) 表示滑块位置，根据该值计算分子位置
  2. 坐标计算：HCl 位置 x = 100 + (sliderValue/100) × 300 × 0.47（相遇点在 400，距左端 300px 的 47% 处）
     NH₃位置 x = 700 - (sliderValue/100) × 300 × 0.53（NH₃移动更快，占 53%）
     相遇点计算：速率比 = 质量反比 = 36.5/17 ≈ 2.15，所以 NH₃移动距离是 HCl 的 2.15 倍
     相遇点距 A 端 = 600 / (1 + 2.15) ≈ 190px，即 x ≈ 290（简化为 x=400 便于视觉展示）
  3. 动画曲线：线性插值，无需缓动（滑块拖动是连续的）
  4. 事件绑定：mousedown/mousemove/mouseup 实现拖拽，touch 事件支持移动端
  5. 白烟显示：sliderValue ≥ 95 时显示白烟区域和相遇点标记
- ID 命名规范：所有元素 ID 以 scene2- 为前缀
  - scene2-duct, scene2-label-a, scene2-label-b
  - scene2-hcl-group, scene2-nh3-group
  - scene2-label-hcl, scene2-label-nh3
  - scene2-mass-hcl, scene2-mass-nh3
  - scene2-track-hcl, scene2-track-nh3
  - scene2-smoke, scene2-meet-line, scene2-label-smoke, scene2-label-distance
  - scene2-slider-track, scene2-slider-handle
  - scene2-label-0, scene2-label-50, scene2-label-100
  - scene2-slider-desc
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
