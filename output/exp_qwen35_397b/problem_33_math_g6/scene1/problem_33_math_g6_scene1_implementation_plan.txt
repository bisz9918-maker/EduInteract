[图示主题与整合说明]
- 本图示主题：用平移法比较甲乙两个不规则图形的周长
- 整合的步骤/概念：原始图形展示 → 甲图形凹边平移 → 甲形成长方形 → 乙图形凸边平移 → 乙形成长方形 → 周长相等结论
- 教学价值：教师可通过分步动画展示"平移法"的核心思想——将不规则图形的边平移至外围形成规则长方形，直观证明甲乙周长相等。学生能清晰看到凹边和凸边如何通过平移"补齐"成长方形，理解周长不变原理。

[视觉元素清单]

- 乙图形：多边形路径，填充 (#dddddd 斜线阴影 30% 透明度)，轮廓 (#000000 实线 2px)

[分步序列]
- 步骤 0（初始状态）：显示方格背景、甲图形、乙图形、甲标签、乙标签。等待教师点击下一步。
- 步骤 1：在步骤 0 基础上，高亮显示甲图形凹进去的两条竖直边（红色 3px），显示两个蓝色平移箭头（指向上方），提示这两条边需要向上平移。
- 步骤 2：在步骤 1 基础上，显示甲图形的外接长方形轮廓（绿色虚线），表示甲图形通过平移后形成的规则长方形。高亮边和箭头保持显示。
- 步骤 3：在步骤 2 基础上，隐藏甲相关元素（高亮边、箭头、长方形），高亮显示乙图形凸出来的两条竖直边（红色 3px），显示两个蓝色平移箭头（指向下方）。
- 步骤 4：在步骤 3 基础上，显示乙图形的外接长方形轮廓（绿色虚线），表示乙图形通过平移后形成的规则长方形。高亮边和箭头保持显示。
- 步骤 5（最终步骤）：同时显示甲和乙的外接长方形轮廓（绿色虚线），两者尺寸完全相同（200×160），中央显示结论文本"周长相等"。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于 (280,450)，点击后退到上一状态，步骤 0 时禁用
  - 「下一步 ▶」按钮：位于 (420,450)，点击前进到下一状态，步骤 5 时禁用
  - 步骤指示器：位于 (400,480)，显示当前步骤编号"步骤 X/5"
- 教师操作流程：
  1. 初始展示甲乙两个不规则图形，提问学生如何比较周长
  2. 点击「下一步」展示甲图形凹边高亮和平移箭头，讲解平移思想
  3. 点击「下一步」展示甲的外接长方形，说明平移后周长不变
  4. 点击「下一步」切换到乙图形，重复平移过程
  5. 点击「下一步」展示乙的外接长方形
  6. 点击「下一步」同时显示两个长方形，得出周长相等的结论

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |   [甲方格区]              [乙方格区]             |
  |   甲图形 (带凹陷)          乙图形 (带凸起)        |
  |                                                  |
  |                                                  |
  |              [结论文本区]                        |
  |                                                  |
  |   [◀ 上一步]    步骤 X/5    [下一步 ▶]           |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用 currentStep 变量 (0-5) 跟踪当前步骤，每个步骤对应一组元素的显示/隐藏状态
  2. 坐标计算：所有元素坐标预先计算好，用常量对象存储
  3. 动画曲线：平移箭头用 CSS transition 实现简单位移动画（可选）
  4. 事件绑定：按钮点击事件切换状态，更新 DOM 元素 display 属性
  5. 按钮状态：步骤 0 禁用上一步，步骤 5 禁用下一步（opacity:0.5, pointer-events:none）
- ID 命名规范：所有元素 ID 以 scene1- 为前缀
  - scene1-grid（方格背景）
  - scene1-jia-shape（甲图形）
  - scene1-yi-shape（乙图形）
  - scene1-jia-label（甲标签）
  - scene1-yi-label（乙标签）
  - scene1-jia-highlight-1/2（甲高亮边）
  - scene1-jia-arrow-1/2（甲平移箭头）
  - scene1-jia-rect（甲外接长方形）
  - scene1-yi-highlight-1/2（乙高亮边）
  - scene1-yi-arrow-1/2（乙平移箭头）
  - scene1-yi-rect（乙外接长方形）
  - scene1-conclusion（结论文本）
  - scene1-btn-prev（上一步按钮）
  - scene1-btn-next（下一步按钮）
  - scene1-step-indicator（步骤指示器）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
