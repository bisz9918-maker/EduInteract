[分步序列]
- 初始状态（步骤 0）：显示原长方形轮廓（黑色 2px），显示尺寸标注"6"（下方）和"4"（左侧），显示灰色虚线尺寸线
- 步骤 1：在长方形右侧叠加显示正方形剪切区域（蓝色 30% 透明填充），显示正方形边长标注"2"（内部和右侧）
- 步骤 2：正方形区域渐隐消失，原长方形轮廓变为红色最终图形轮廓（凹槽形状），展示剪切后的实际图形
- 步骤 3：用绿色加粗 3px 高亮显示凹槽的三条新增边（上横、内竖、下横），帮助学生理解周长增加的部分

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 内底部左侧 (250,455)，点击后退到前一状态
  - 「下一步」按钮：位于 SVG 内底部中间 (360,455)，点击前进到下一状态
  - 步骤指示文本：位于 SVG 内底部右侧 (480,465)，显示当前步骤序号
- 教师操作流程：
  1. 初始展示原长方形，讲解题目条件（长 6 宽 4）
  2. 点击「下一步」，高亮显示要剪去的正方形区域，讲解剪切位置
  3. 点击「下一步」，展示剪切后的凹槽图形，引导学生观察形状变化
  4. 点击「下一步」，高亮新增的三条边，讲解周长计算（原周长 20 + 新增 2 条竖边 4 = 24）

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |         [原长方形 360×240]                        |
  |         +------------------+                     |
  |    4    |                  |                     |
  |  <----->|                  +--+                  |
  |         |                  |2 |                  |
  |         |                  +--+                  |
  |         +------------------+                     |
  |                                                  |
  |              6  <----------->                    |
  |                                                  |
  |                                                  |
  |     [上一步]  [下一步]   步骤 1/4                 |
  +--------------------------------------------------+
  [控件栏在 SVG 内底部 y=440~490]
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentState(0-3) 跟踪当前步骤，数组存储各状态配置
  2. 元素显示控制：各步骤元素用 display 属性或 opacity 控制显隐
  3. 动画效果：步骤 1→2 正方形区域用 opacity 渐变实现渐隐
  4. 事件绑定：按钮点击事件绑定到状态切换函数，更新视图和步骤指示
- ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-rect-original, scene1-rect-cut, scene1-label-6）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
