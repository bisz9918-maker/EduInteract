[交互方案]
- 交互类型：连续拖拽滑块（0%~100%）
- 控件说明：
  - 滑块轨道：位于SVG底部y=450~465，x=200~600，宽400px
  - 滑块手柄：圆形直径20px，初始位置x=200，可拖拽范围200~600
  - 平移箭头：2个蓝色箭头，位于平移轨迹上方/下方，指示向右平移方向
- 教师操作流程：
  1. 初始状态展示题目图形和原长方形参考轮廓
  2. 缓慢向右拖动滑块，让学生观察凹槽上下边的平移过程
  3. 停在50%位置，提问"平移过程中什么变了？什么没变？"
  4. 拖到100%位置，展示平移后形成的完整长方形轮廓
  5. 指向绿色加粗的凹槽左边，说明"这就是多出来的2条竖直边，每条2cm"
  6. 结合右侧计算式"20+2×2=24(cm)"总结周长计算方法

[技术实现]
- JS库选择：原生SVG + 原生JavaScript
  - 原因：几何图形简单，无需复杂库；SVG便于精确坐标控制和动画
- 画布尺寸：800×500px（固定）
- 布局草图（ASCII）：
  ```
  [800×500 SVG画布]
  +--------------------------------------------------+
  |  [标题区 y=20~40]                                |
  |                                                  |
  |  [主图区 y=80~380]                               |
  |   +------------------------------------------+   |
  |   |  原长方形虚线轮廓                        |   |
  |   |  不规则图形实线                          |   |
  |   |  蓝色可平移边 → → → 平移后位置           |   |
  |   |  绿色固定竖直边                          |   |
  |   |                          [计算式区]      |   |
  |   +------------------------------------------+   |
  |                                                  |
  |  [标注区 y=420~480]                              |
  |           "6"                                    |
  |  [滑块控件 y=450~470]                            |
  |  [====○====================]  ← 拖拽滑块        |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：滑块位置percent(0~1)驱动平移距离offset = percent × 160px
  2. 坐标计算：凹槽上边终点x = 630 + offset，下边同理
  3. 动画曲线：无需缓动，直接跟随滑块位置（线性映射）
  4. 事件绑定：
     - mousedown/touchstart：开始拖拽
     - mousemove/touchmove：更新滑块位置和图形位置
     - mouseup/touchend：结束拖拽
  5. 边界限制：滑块手柄x范围[200, 600]，对应offset范围[0, 160]
- ID命名规范：
  - scene2-rect-original（原长方形参考轮廓）
  - scene2-path-irregular（不规则图形路径）
  - scene2-line-groove-top（凹槽上边）
  - scene2-line-groove-bottom（凹槽下边）
  - scene2-line-groove-left（凹槽左边）
  - scene2-line-trajectory-top（上平移轨迹）
  - scene2-line-trajectory-bottom（下平移轨迹）
  - scene2-label-4 / scene2-label-6 / scene2-label-2（尺寸标注）
  - scene2-slider-track / scene2-slider-handle（滑块控件）
  - scene2-text-original-perimeter / scene2-text-added / scene2-text-total（周长标注）
  - scene2-text-formula（计算式）
- IIFE隔离：所有JS代码包在 (function() { ... })() 中，避免全局变量污染
- 比例换算：1cm = 80px（6cm→480px, 4cm→320px, 2cm→160px）
