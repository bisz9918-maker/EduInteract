- 本图示主题：三个圆的位置关系与重叠区域

[分步序列]
- 初始状态（步骤0）：显示三个圆（黑色轮廓）和直线 a（黑色水平线），无标签无阴影
- 步骤1：显示圆心 A 点、圆心 B 点（蓝色实心点），显示标签"A"、"B"、"a"
- 步骤2：显示两个重叠区域（灰色半透明填充），高亮显示
- 步骤3：在两个重叠区域内分别显示标签"x"，表示面积相等

[标签冲突检查]
- 标签"A"：坐标(220,225)
- 标签"B"：坐标(420,225)
- 标签"a"：坐标(760,235)
- 标签"x(左)"：坐标(320,250)
- 标签"x(右)"：坐标(485,300)

冲突检查：
- "A"与"B"：x 间距 200px，y 相同 → 无冲突
- "A"与"x(左)"：x 间距 100px，y 间距 25px → 无冲突
- "B"与"x(左)"：x 间距 100px，y 间距 25px → 无冲突
- "B"与"x(右)"：x 间距 65px，y 间距 75px → 无冲突
- "x(左)"与"x(右)"：x 间距 165px，y 间距 50px → 无冲突
- "a"与其他标签：距离均>200px → 无冲突
- 所有标签与图形元素：标签均位于空白区域，无重叠

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 底部左侧 (x=350, y=455)，点击回退到前一状态
  - 「下一步」按钮：位于 SVG 底部右侧 (x=450, y=455)，点击进入下一状态
  - 步骤指示器：位于底部中央 (x=400, y=455)，显示当前步骤编号
- 教师操作流程：
  1. 初始展示三个圆和直线 a 的基础布局
  2. 点击「下一步」标注圆心 A、B 和直线 a，讲解圆心位置关系
  3. 点击「下一步」高亮两个重叠区域，讲解重合部分
  4. 点击「下一步」显示面积标签 x，讲解两重叠区面积相等
  5. 可随时点击「上一步」回退复习

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +------------------------------------------+
  |                                          |
  |     圆A        圆B                       |
  |    (A)●───────●(B)─────── 直线 a         |
  |      ╲       ╱                           |
  |       ╲     ╱         圆C                |
  |        ╲   ╱          ●                  |
  |         ╲ ╱                              |
  |                                          |
  |                                          |
  |              [◀上一步] [4] [下一步▶]     |
  +------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-3) 跟踪当前步骤
  2. 重叠区域计算：使用 SVG <clipPath> 或 path 的 arc 命令绘制两圆交集
  3. 元素显隐：每个步骤对应的元素组用 display 或 opacity 控制
  4. 事件绑定：按钮点击事件切换 currentStep 并更新视图
  5. ID 命名规范：所有元素 ID 以 scene1- 为前缀（如 scene1-circle-a, scene1-label-a）
  6. IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中避免全局污染
- 重叠区域 path 计算：
  - 圆A与圆B交集：两圆心距200px，半径80px，交集宽度约40px
  - 圆B与圆C交集：圆心B(420,250)，圆心C(520,330)，圆心距约128px，半径80px，有重叠
