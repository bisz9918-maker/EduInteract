[图示主题与整合说明]
- 本图示主题：容斥原理可视化——总覆盖面积的构成
- 整合的步骤/概念：三个圆的独立面积、重叠区域的扣除、总覆盖面积的直观展示
- 教学价值：教师可逐步演示容斥原理的计算过程，从三个独立圆面积 3S 开始，展示重叠后需要扣除的部分，最终得出覆盖面积 2S+2 的表达式。通过视觉化帮助学生理解"为什么不是 3S 而是 2S+2"

[视觉元素清单]

[分步序列]
- 初始状态（步骤 0）：显示三个独立圆（无重叠效果），每个圆上方/下方标注"S"，显示直线 a 穿过圆心 A、B，圆心标签 A、B、C 可见。此时重叠区域不显示红色高亮。
- 步骤 1：点击「下一步」→ 圆 A 与圆 B 的重叠区域显现（红色半透明填充），圆 B 与圆 C 的重叠区域显现，在两个重叠区附近分别标注"x"
- 步骤 2：点击「下一步」→ 从两个重叠区分别出现红色箭头指向右侧表达式区域，表达式框出现，显示"3S - 2x"（表示从容斥原理角度，总面积=三圆面积和-两倍重叠）
- 步骤 3：点击「下一步」→ 表达式框内容变为"2S + 2"（最终结果），同时显示推导说明：因题目给定覆盖面积为 2S+2，且两重叠区面积相等

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 按钮"◀ 上一步"：位于 SVG 底部左侧 (x=320, y=460)，点击后返回上一状态
  - 按钮"下一步 ▶"：位于 SVG 底部右侧 (x=480, y=460)，点击后进入下一状态
  - 步骤指示器：位于两按钮之间 (x=400, y=460)，显示"步骤 X/4"
- 教师操作流程：
  1. 初始状态展示三个圆和直线 a，讲解题目条件
  2. 点击"下一步"展示重叠区域，提问学生"重叠部分如何处理"
  3. 点击"下一步"展示扣除箭头和中间表达式，讲解容斥原理
  4. 点击"下一步"展示最终表达式 2S+2，完成推导

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |     S         S                                  |
  |   ┌───┐     ┌───┐                    ┌─────────┐ |
  |   │ A │─────│ B │         2x ───────→│ 2S + 2  │ |
  |   └───┘     └───┘   ╲                  └─────────┘ |
  |  (●)───────(●)──────(●) C                          |
  |     ╲       ╲       │                              |
  |       ╲       ╲     │ S                            |
  |         ╲       ╲   │                              |
  |           └───────┘ │                              |
  |                    └─┘                             |
  |                                                    |
  |              [◀上一步] 步骤 2/4 [下一步▶]          |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 currentState (0-3)，数组存储各状态应显示的元素 ID 列表
  2. 重叠区域绘制：使用 SVG <clipPath> 或手动计算两圆交点绘制 path
  3. 箭头绘制：使用 SVG <marker> 定义箭头头部，<line> 或 <path> 绘制箭身
  4. 事件绑定：按钮点击事件切换状态，更新各元素 display 属性
  5. 动画过渡：可选添加 opacity 过渡效果（0.3s ease）
- ID 命名规范：所有交互元素 ID 必须以 scene2- 为前缀（如 scene2-circle-a, scene2-overlap-ab, scene2-btn-next）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
