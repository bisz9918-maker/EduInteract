[图示主题与整合说明]
- 本图示主题：直线 a 下方覆盖面积的分解分析
- 整合的步骤/概念：
  1. 三个等圆（面积均为 S）的布局关系
  2. 直线 a 过圆心 A、B，将圆 A 和圆 B 平分
  3. 直线 a 下方区域的面积构成：圆 A 下半 + 圆 B 下半 + 第三圆下方部分 - 重叠部分
  4. 利用容斥原理建立方程求解 S
- 教学价值：教师可逐步展示直线下方面积的分解过程，帮助学生理解如何从几何图形中提取代数关系，掌握容斥原理在面积计算中的应用

[分步序列]
- 初始状态（步骤 0）：
  - 显示三个圆轮廓、直线 a
  - 显示圆心标签 A、B
  - 直线 a 下方被圆覆盖的整体区域用绿色半透明高亮（#2e7d32, 20%）
  - 右下角显示"总面积=9"

- 步骤 1：点击「下一步」
  - 绿色高亮消失
  - 圆 A 下半部分用蓝色半透明高亮（#1565c0, 25%），下方显示标签"S/2"
  - 圆 B 下半部分用蓝色半透明高亮（#1565c0, 25%），下方显示标签"S/2"
  - 圆 C 保持轮廓显示

- 步骤 2：点击「下一步」
  - 保留步骤 1 的所有元素
  - 圆 C 在直线 a 下方的部分用蓝色半透明高亮，下方显示标签"S-x"
  - 底部显示面积表达式前半部分："S/2 + S/2 + (S-x)"

- 步骤 3：点击「下一步」
  - 保留步骤 2 的所有元素
  - 两重叠区域在直线 a 下方的部分用红色半透明高亮（#c62828, 30%）
  - 重叠区 1 下方显示"x/2"，重叠区 2 下方显示"x/2"
  - 底部显示完整表达式："S/2 + S/2 + (S-x) - x/2 - x/2 = 9"
  - 化简提示："2S - x = 9"

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 底部左侧 (x=350, y=475)，点击返回上一状态
  - 「下一步」按钮：位于 SVG 底部右侧 (x=450, y=475)，点击进入下一状态
  - 步骤指示器：位于两按钮之间，显示"步骤 X/4"
- 教师操作流程：
  1. 初始展示完整图形，说明题目条件
  2. 点击「下一步」分解圆 A、B 的下半部分，讲解对称性（各为 S/2）
  3. 点击「下一步」加入圆 C 的贡献，引入未知量 x 表示重叠
  4. 点击「下一步」展示扣除项，建立完整方程，引导学生求解

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单，无需复杂库；SVG 便于精确控制路径填充和透明度
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |     圆 A        圆 B                              |
  |    (200,250)   (380,250)        圆 C             |
  |       O-----------O-------------(520,330)        |
  |       |  直线 a ————————————————> a              |
  |       |           \              O               |
  |    [S/2]        [S/2]         [S-x]              |
  |                                                  |
  |         [x/2]          [x/2]                     |
  |                                                  |
  |                    总面积 = 9                    |
  |                                                  |
  |      S/2 + S/2 + (S-x) - x/2 - x/2 = 9          |
  |                                                  |
  |           [◀上一步]  步骤 X/4  [下一步▶]         |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-3) 跟踪当前步骤
  2. 半圆路径计算：使用 SVG arc 命令绘制半圆填充区域
  3. 重叠区域路径：通过计算两圆交点，用 arc 命令绘制透镜形
  4. 透明度切换：通过 display 属性或 opacity 控制各层显示/隐藏
  5. 事件绑定：按钮点击事件更新 currentStep，调用 updateDisplay() 刷新视图
- ID 命名规范：所有交互元素 ID 必须以 scene3- 为前缀
  - scene3-circle-a, scene3-circle-b, scene3-circle-c
  - scene3-line-a
  - scene3-highlight-step0, scene3-highlight-a, scene3-highlight-b, scene3-highlight-c
  - scene3-deduct-1, scene3-deduct-2
  - scene3-label-a, scene3-label-b, scene3-label-a-line
  - scene3-label-s2-a, scene3-label-s2-b, scene3-label-sx
  - scene3-label-x2-1, scene3-label-x2-2
  - scene3-btn-prev, scene3-btn-next, scene3-step-indicator
  - scene3-formula
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中
