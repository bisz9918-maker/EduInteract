[图示主题与整合说明]
- 本图示主题：光影形成原理与相似三角形关系
- 整合内容：整合了光路展示、影子形成、相似三角形标注三个认知阶段
- 教学价值：教师可逐步展示光线传播路径、影子形成过程、相似三角形对应关系，帮助学生理解"物体离光源越近（a 越小），影子越长；离光源越远（a 越大），影子越短"的原理。通过分步动画，学生能清晰看到光线如何被物体遮挡形成影子，以及两个相似三角形的对应边比例关系。

[分步序列]
- 初始状态（步骤 0）：显示基础场景
  - 显示：地面线、地面阴影线、路灯杆、光源 S（圆形）、物体（梯形）
  - 标签：S、H（带双箭头）、h（带双箭头）、a（带双箭头）
  - 隐藏：光线、影子区域、标签 L、相似三角形

- 步骤 1：添加光线
  - 视觉变化：从光源 (100,100) 发出红色光线，经过物体顶端中点 (410,320)，延伸到地面交点 (520,400)
  - 新增元素：光线（红色实线）
  - 标签：无新增

- 步骤 2：高亮影子区域
  - 视觉变化：地面上从物体底部右侧 (440,400) 到光线与地面交点 (520,400) 的区域高亮显示
  - 新增元素：影子区域（蓝色半透明填充，加粗线段）
  - 新增标签：L（影子长度，带双箭头）

- 步骤 3：标注相似三角形及对应边
  - 视觉变化：用绿色虚线边框高亮两个相似三角形
  - 新增元素：大三角形（光源 - 路灯底 - 影子末端）、小三角形（物体顶 - 物体底 - 影子末端）
  - 强调：两个三角形共享右下角顶点 (520,400)，且都是直角三角形
  - 教学提示：此时可讲解相似三角形对应边成比例：H/h = (a+L)/L

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 内底部左侧 (x=350, y=460)，点击后返回上一状态
  - 「下一步」按钮：位于 SVG 内底部右侧 (x=450, y=460)，点击后进入下一状态
  - 步骤指示器：位于两按钮之间 (x=400, y=460)，显示当前步骤（如"步骤 1/4"）
- 教师操作流程：
  1. 初始状态：展示路灯和物体的基本布局，讲解题目条件
  2. 点击「下一步」：光线出现，讲解光沿直线传播，被物体遮挡
  3. 点击「下一步」：影子区域高亮，讲解影子形成原理
  4. 点击「下一步」：相似三角形出现，讲解对应边比例关系，推导 a 与 L 的关系
  5. 可随时点击「上一步」回退复习

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单，SVG 原生支持路径、圆形、矩形、文本等元素，无需额外库
  - 动画使用 CSS transition 或 JS 控制 opacity/display 属性
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +----------------------------------------------------------+
  |                                                          |
  |    S (光源)                                              |
  |     ●                                                    |
  |     |                                                    |
  |     | H                                                  |
  |     |                                                    |
  |     |                                                    |
  |     |                                    光线           |
  |     |                                   /               |
  |     |                                  /                |
  |     |                    h           /                  |
  |     |                   ┌─┐        /                    |
  |     |                   │ │       /                     |
  |     |                   │ │      /                      |
  |     |                   └─┘     /                       |
  |     |__________________________/________________________|
  |     |←──── a ────→|←── L ──→|                          |
  |                                                          |
  |              [◀上一步]  步骤 1/4  [下一步▶]              |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-3），数组存储各步骤应显示的元素 ID 列表
  2. 坐标计算：光线与地面交点通过相似三角形比例计算：L = h*a/(H-h)，交点 x = 物体右边缘 + L
  3. 动画曲线：元素淡入使用 CSS transition: opacity 0.3s ease
  4. 事件绑定：按钮点击事件切换状态，更新元素 display/opacity 属性
  5. 边界检查：第一步禁用「上一步」，最后一步禁用「下一步」
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀
  - scene1-ground（地面线）
  - scene1-light-pole（路灯杆）
  - scene1-light-source（光源）
  - scene1-object（物体）
  - scene1-ray（光线）
  - scene1-shadow（影子）
  - scene1-triangle-large（大三角形）
  - scene1-triangle-small（小三角形）
  - scene1-label-S、scene1-label-H、scene1-label-h、scene1-label-a、scene1-label-L
  - scene1-btn-prev、scene1-btn-next、scene1-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
