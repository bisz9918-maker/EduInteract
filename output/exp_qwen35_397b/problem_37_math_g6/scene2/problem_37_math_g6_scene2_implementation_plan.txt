[图示主题与整合说明]
- 本图示主题：距离 a 变化对影子长度的影响（动态演示）
- 整合的步骤/概念：物体位置变化 → 光线角度变化 → 影子长度实时变化 → 数据记录对比

[分步序列]
本场景为连续拖拽交互，无分步导航，状态由滑块位置决定：
- 初始状态：物体位于 x=300（a≈2.5m），显示对应影子长度，数值面板显示当前 a 和 L 值
- 拖拽状态：用户拖拽滑块手柄或物体 → 物体水平移动 → 光线重新计算 → 影子长度实时更新 → 数值面板同步更新
- 记录状态：点击"记录"按钮 → 当前 a 和 L 值添加到右侧记录列表 → 最多保留 5 条记录
- 对比状态：记录多条数据后，教师可引导学生观察记录表中的规律

[交互方案]
- 交互类型：连续拖拽滑块 + 记录按钮
- 控件说明：
  - 滑块手柄：位于底部 y=470，x 范围 150~650，拖拽时物体同步移动
  - 物体本身：也可直接拖拽（x 范围 150~550），与滑块手柄联动
  - 记录按钮：位于数值面板内 (680,215)，点击记录当前 a 和 L 值
- 教师操作流程：
  1. 初始状态展示题目条件
  2. 拖拽滑块/物体，让学生观察影子长度变化
  3. 在关键位置（a 最小、a 最大、中间位置）点击"记录"
  4. 引导学生对比记录表中的数据，总结规律
  5. 可反复拖拽验证结论

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单，无需复杂库；SVG 便于动态更新线条和填充区域；原生 JS 足够处理拖拽和计算
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [800 × 500 画布]
  +----------------------------------------------------------+
  |                    距离 a 与影长 L 的关系                  | y=35
  |                                                          |
  |    💡                                                    |
  |     |                                                    |
  |     |                                    ┌───────────┐   |
  |     |                                    │ 实时数据  │   |
  |     |         🟦 物体                     │ a = X.X m │   |
  |     |         ╱╲                          │ L = X.X m │   |
  |     |        ╱  ╲━━━━━━━🔴光线            │ [记录]    │   |
  |     |       ╱    ╲     ╲                 │ 记录列表  │   |
  |     |      ╱      ╲     ╲                │ • a=1.0   │   |
  |     |     ╱影子区域 ╲     ╲               │ • a=2.5   │   |
  |     |    ╱══════════╲     ╲              │ • a=4.0   │   |
  |-----|---╱────────────╲─────╲---------------------------| y=400 地面
  |     |  ←──── a ────→←─ L ─→                          |
  |     |                                                    |
  |     |        ═══════════════════════                    | y=470 滑块
  |     |              [●] 滑块手柄                          |
  +----------------------------------------------------------+
       60                                                  780
  ```
- 关键实现要点：
  1. 光线计算：使用相似三角形原理
     - 路灯高度 H = 300px (从 y=100 到 y=400)
     - 物体高度 h = 60px (从 y=340 到 y=400)
     - 物体到路灯水平距离 d = objectX - 90
     - 影子长度 L = d × h / (H - h) = d × 60 / 240 = d / 4
     - 光线与地面交点 x = objectX + 40 + L
  2. 拖拽联动：滑块手柄 x 与物体 x 成比例映射
     - 滑块范围 150~650 (500px)
     - 物体范围 150~550 (400px)
     - 映射公式：objectX = 150 + (sliderX - 150) × 0.8
  3. 状态更新：拖拽时实时更新
     - 物体位置
     - 光线路径（三点折线）
     - 影子区域（多边形点集）
     - 标注线和文字
     - 数值面板
  4. 记录功能：数组存储最多 5 条记录，动态更新 DOM
- ID 命名规范：所有元素 ID 以 scene2- 为前缀
  - scene2-ground, scene2-pole, scene2-light, scene2-object, scene2-ray, scene2-shadow
  - scene2-label-a, scene2-label-l, scene2-panel, scene2-btn-record, scene2-record-list
  - scene2-slider-track, scene2-slider-handle
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
