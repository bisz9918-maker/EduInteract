[图示主题与整合说明]
- 本图示主题：两个立体图形的三维结构及观察方向示意
- 整合内容：展示题目中的两个立体图形（小正方体组合），标注前/左/上三个观察方向，帮助学生理解从不同方向观察立体图形的概念
- 教学价值：教师可逐步高亮不同观察方向，引导学生想象从该方向看到的平面图形，培养空间想象能力。通过对比两个图形从同一方向观察的结果，学生可判断哪些方向看到的形状相同

[视觉元素清单]
- 左图形：等轴测立体图，由6个小正方体组成（底层3个横向排列，中层2个在左侧，顶层1个在最左侧）
  - 正方体可见面填充：#f5f5f5，透明度20%
  - 轮廓线：#000000 实线，线宽1.5px
  - 位置：中心约(220,280)，占据 x=120~320, y=180~380

- 右图形：等轴测立体图，由5个小正方体组成（左列2层，中列1层，右列2层，呈U形）
  - 正方体可见面填充：#f5f5f5，透明度20%
  - 轮廓线：#000000 实线，线宽1.5px
  - 位置：中心约(620,280)，占据 x=520~720, y=180~380

- 观察方向箭头（3组，每组2个箭头分别指向两个图形）：
  - 前面箭头：水平向右，从图形左侧指向图形，颜色 #1565c0
  - 左面箭头：水平向右，从更左侧指向图形左面，颜色 #1565c0
  - 上面箭头：垂直向下，从图形上方指向图形，颜色 #1565c0

- 标签：
  - "前面"：位于两图形之间偏下，坐标(390,275)
  - "左面"：位于画布最左侧，坐标(60,275)
  - "上面"：位于两图形上方居中，坐标(220,100) 和 (620,100) 或统一居中(400,90)

- 颜色规格：
  - 背景：#ffffff
  - 立体图形轮廓：#000000
  - 正方体可见面：#f5f5f5（透明度20%）
  - 观察方向箭头：#1565c0
  - 箭头文字标签：#1565c0

[分步序列]
- 初始状态（步骤0）：
  - 显示两个立体图形（完整绘制，无高亮）
  - 三个观察方向箭头以灰色显示（#9e9e9e，透明度50%）
  - 标签文字以灰色显示
  - 按钮状态："上一步"禁用，"下一步"启用

- 步骤1（点击"下一步"）：
  - "前面"箭头变为蓝色 #1565c0（不透明）
  - "前面"标签变为蓝色
  - 两个图形的"前面"可视面轻微高亮（填充色改为 #e3f2fd，透明度40%）
  - 其他箭头和标签保持灰色
  - 按钮状态："上一步"启用，"下一步"启用

- 步骤2（点击"下一步"）：
  - "前面"箭头和标签恢复灰色
  - "左面"箭头变为蓝色 #1565c0（不透明）
  - "左面"标签变为蓝色
  - 两个图形的"左面"可视面轻微高亮
  - 按钮状态："上一步"启用，"下一步"启用

- 步骤3（点击"下一步"）：
  - "左面"箭头和标签恢复灰色
  - "上面"箭头变为蓝色 #1565c0（不透明）
  - "上面"标签变为蓝色
  - 两个图形的"上面"可视面轻微高亮
  - 按钮状态："上一步"启用，"下一步"禁用（到达最后一步）

- 回退逻辑：
  - 点击"上一步"逆向执行上述过程

[标签冲突检查]
- 标签"前面"：坐标(390,275)
- 标签"左面"：坐标(60,275)
- 标签"上面"：坐标(400,90)（统一居中放置）

冲突检查：
- "前面"(390,275) 与 "左面"(60,275)：水平距离330px → 无冲突
- "前面"(390,275) 与 "上面"(400,90)：垂直距离185px → 无冲突
- "左面"(60,275) 与 "上面"(400,90)：距离约350px → 无冲突
- 所有标签与图形元素：标签均放置在图形外侧空白区域，最小间距>30px → 无冲突

解决方案：标签位置已合理分散，无需调整

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - "上一步"按钮：位于底部左侧 (x=320, y=455)，宽80px，高30px
  - "下一步"按钮：位于底部右侧 (x=400, y=455)，宽80px，高30px
  - 步骤指示器：位于底部中央 (x=480, y=460)，显示"步骤 X/3"
- 教师操作流程：
  1. 初始展示两个立体图形，让学生观察整体结构
  2. 点击"下一步"高亮"前面"方向，提问学生从前面看两个图形分别是什么形状
  3. 点击"下一步"高亮"左面"方向，引导学生比较左视图
  4. 点击"下一步"高亮"上面"方向，引导学生比较俯视图
  5. 可随时点击"上一步"回退复习

[技术实现]
- JS 库选择：原生 SVG
  - 原因：立体图形由简单的多边形组成，SVG 可精确控制每个面的坐标和样式；无需复杂3D引擎，等轴测投影可用2D多边形模拟

- 画布尺寸：800 × 500 px

- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +----------------------------------------------------------+
  |                    上面                                   |
  |                    ↓                                      |
  |    左面→  [左图形]           [右图形]  ←前面标签          |
  |            ↑   ↑             ↑   ↑                        |
  |            |   |             |   |                        |
  |          前面箭头           前面箭头                       |
  |                                                          |
  |                                                          |
  |                                                          |
  |              [上一步]  步骤 X/3  [下一步]                 |
  +----------------------------------------------------------+
  ```

- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-3) 跟踪当前步骤
  2. 等轴测正方体绘制：每个正方体用3个平行四边形表示可见面（顶面、左前面、右前面）
  3. 坐标计算：定义正方体边长 unitSize=30px，根据等轴测角度(30°)计算各顶点坐标
  4. 高亮逻辑：通过修改 fill 和 opacity 属性实现
  5. 事件绑定：按钮点击事件触发状态更新和重绘

- ID 命名规范：
  - 左图形组：scene1-left-figure
  - 右图形组：scene1-right-figure
  - 前面箭头：scene1-front-arrow-left, scene1-front-arrow-right
  - 左面箭头：scene1-left-arrow-left, scene1-left-arrow-right
  - 上面箭头：scene1-top-arrow-left, scene1-top-arrow-right
  - 标签：scene1-label-front, scene1-label-left, scene1-label-top
  - 按钮：scene1-btn-prev, scene1-btn-next
  - 步骤指示：scene1-step-indicator

- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染
