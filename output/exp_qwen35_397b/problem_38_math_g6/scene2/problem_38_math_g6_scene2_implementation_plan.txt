[图示主题与整合说明]
- 本图示主题：从前面观察两个立体图形的形状对比（主视图）
- 整合的步骤/概念：展示两个立体图形从前面看到的平面形状（主视图），通过分步呈现和并列对比，帮助学生理解"从前面观察"的含义，并判断两个视图是否相同
- 教学价值：教师可先分别展示两个视图让学生观察，再并列对比得出结论，形成认知递进；学生通过网格化的主视图清晰看到每列的高度差异，理解为什么答案是"不相同"

[分步序列]
- 初始状态（步骤 0）：显示左图主视图（3 列：3 格/2 格/1 格），显示"左图主视图"标签；右图和结论隐藏
- 步骤 1：点击「下一步」→ 显示右图主视图（3 列：2 格/1 格/2 格），显示"右图主视图"标签；左图保持显示
- 步骤 2：点击「下一步」→ 显示对比结论文字"不相同"（红色粗体，位于两图中间下方）；教师可引导学生观察两图差异
- （教师可随时点击「上一步」回退复习）

[标签冲突检查]
- 标签"左图主视图"：坐标 (180,140)
- 标签"右图主视图"：坐标 (540,140)
- 标签"不相同"：坐标 (360,340)
- "左图主视图"与"右图主视图"间距：360px → 无冲突
- "左图主视图"与"不相同"间距：约 215px → 无冲突
- "右图主视图"与"不相同"间距：约 215px → 无冲突
- 所有标签与图形元素间距均≥20px → 无冲突
- 解决方案：布局已合理分散，无需调整

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 内底部左侧 (280,450)，点击回退到前一状态
  - 「下一步」按钮：位于 SVG 内底部右侧 (440,450)，点击进入下一状态
- 教师操作流程：
  1. 初始状态展示左图主视图，提问"左图从前面看是什么形状？"
  2. 点击「下一步」展示右图主视图，提问"右图从前面看是什么形状？"
  3. 点击「下一步」展示结论"不相同"，引导学生观察两图每列高度的差异
  4. 可随时点击「上一步」回退复习

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript。理由：本场景为简单 2D 网格图形，无需复杂库；SVG 便于精确控制矩形位置和网格线，原生 JS 足够实现分步状态切换
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |   左图主视图              右图主视图             |
  |   [===]                   [===]                  |
  |   [===]                   [   ]                  |
  |   [===][===]              [===][===]             |
  |   [===][===][=]           [===][=  ][===]        |
  |                                                  |
  |                    不相同                        |
  |                                                  |
  |            [◀上一步]      [下一步▶]              |
  +--------------------------------------------------+
  [控件栏在 SVG 内底部 y=440~490]
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0/1/2) 跟踪当前步骤
  2. 元素分组：左图元素、右图元素、结论元素分别用 g 标签分组，通过 display 属性控制显隐
  3. 按钮事件：绑定 click 事件，更新 currentStep 并调用 render() 函数刷新显示
  4. 边界处理：步骤 0 时禁用「上一步」，步骤 2 时禁用「下一步」
- ID 命名规范：所有交互元素 ID 必须以 scene2- 为前缀
  - scene2-left-view（左图主视图组）
  - scene2-right-view（右图主视图组）
  - scene2-conclusion（结论文字）
  - scene2-btn-prev（上一步按钮）
  - scene2-btn-next（下一步按钮）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
