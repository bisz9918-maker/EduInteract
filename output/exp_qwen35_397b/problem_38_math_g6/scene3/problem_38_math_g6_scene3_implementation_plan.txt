[图示主题与整合说明]
- 本图示主题：从左面观察两个立体图形的形状对比（左视图）
- 整合的步骤/概念：
  1. 展示左图的左视图（3层高单列）
  2. 展示右图的左视图（2层高单列）
  3. 并列对比两个左视图，标注"不相同"
- 教学价值：教师可逐步展示两个图形的左视图，引导学生理解从同一方向观察不同立体图形时，看到的平面形状可能不同。通过分步对比，帮助学生建立空间想象能力，理解三视图的概念。

[分步序列]
- 初始状态（步骤0）：
  - 显示：左图标题"左图"(225,30)、左图左视图标签"左视图"(210,45)
  - 显示：左图左视图3个蓝色矩形（顶层(175,60)、中层(175,120)、底层(175,180)）及边框
  - 隐藏：右图所有元素、对比结论
  - 按钮状态："上一步"禁用，"下一步"启用

- 步骤1：点击「下一步」→
  - 新增显示：右图标题"右图"(575,30)、右图左视图标签"左视图"(560,45)
  - 新增显示：右图左视图2个红色矩形（顶层(525,120)、底层(525,180)）及边框
  - 保持：左图所有元素
  - 隐藏：对比结论
  - 按钮状态："上一步"启用，"下一步"启用

- 步骤2：点击「下一步」→
  - 新增显示：对比结论文字"不相同"(400,380)及红色虚线框(340,360)-(460,400)
  - 保持：左右图所有元素
  - 按钮状态："上一步"启用，"下一步"禁用（最后一步）

- 回退操作：点击「上一步」可逐级回退，元素按相反顺序隐藏

[标签冲突检查]
- 标签"左图"：坐标(225, 30)
- 标签"左视图(左)"：坐标(210, 45)
- 标签"右图"：坐标(575, 30)
- 标签"左视图(右)"：坐标(560, 45)
- 标签"不相同"：坐标(400, 380)

冲突检查：
- "左图"与"左视图(左)"：y间距15px，x间距15px，斜距≈21px → 不冲突（≥20px）
- "左图"与"右图"：x间距350px → 不冲突
- "左视图(左)"与"左视图(右)"：x间距350px → 不冲突
- "不相同"与所有上方标签：y间距≥335px → 不冲突
- 所有标签与图形元素：标签均在图形外侧上方或下方，间距≥15px → 不冲突

结论：所有标签位置无冲突，布局安全。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "上一步"按钮：位于(280, 450)，80×30px，点击回退到前一状态
  - "下一步"按钮：位于(440, 450)，80×30px，点击进入下一状态
- 教师操作流程：
  1. 初始状态展示左图的左视图，教师提问："从左面看左图，我们看到什么形状？"
  2. 点击"下一步"展示右图的左视图，教师提问："从左面看右图，形状是什么？"
  3. 点击"下一步"显示对比结论，教师总结："两个图形从左面看到的形状不相同，左图是3层高，右图是2层高。"
  4. 可随时点击"上一步"回退复习

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（矩形堆叠），无需复杂库；原生实现轻量、加载快
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  [左图]                    [右图]                |
  |   左视图                    左视图               |
  |   ████                      ████                |
  |   ████                      ████                |
  |   ████                                            |
  |                                                  |
  |                                                  |
  |              [不相同]                            |
  |                                                  |
  |                                                  |
  |        [◀上一步]          [下一步▶]              |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0/1/2) 跟踪当前步骤
  2. 元素分组：左图元素、右图元素、结论元素分别用 g 元素分组，通过 display 控制显隐
  3. 按钮状态：每步更新按钮的 disabled 属性
  4. 动画效果：元素出现时使用淡入动画（opacity 0→1，duration 300ms）
- ID 命名规范：
  - 左图组：scene3-left-group
  - 左图视图：scene3-left-view
  - 右图组：scene3-right-group
  - 右图视图：scene3-right-view
  - 结论组：scene3-conclusion-group
  - 上一步按钮：scene3-btn-prev
  - 下一步按钮：scene3-btn-next
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
