[图示主题与整合说明]
- 本图示主题：小旗绕点 O 顺时针旋转 90° 的完整过程
- 整合内容：原图展示、旋转中心标注、旋转轨迹动画、旋转后位置、新旧坐标对比
- 教学价值：教师可使用此图示分步演示旋转过程，帮助学生理解：(1) 旋转中心的概念；(2) 旋转前后点到旋转中心的距离不变；(3) 顺时针旋转 90° 的坐标变换规律；(4) 通过轨迹弧线直观感受旋转方向和角度

[分步序列]
共 6 步（步骤 0~5），教师点击「下一步」逐步推进，点击「上一步」回退：

- 步骤 0（初始状态）：
  - 显示：网格坐标系、原始小旗（旗杆 + 旗面）、原顶点标签 "(5, 7)"
  - 隐藏：旋转中心 O、向量线、轨迹弧、旋转后小旗、新顶点标签

- 步骤 1：
  - 新增：旋转中心 O（红色实心圆）、O 点标签 "O (5, 3)"
  - 保持：步骤 0 所有元素

- 步骤 2：
  - 新增：从 O 到原顶点的蓝色向量线（相对位置向量）
  - 保持：步骤 1 所有元素

- 步骤 3：
  - 新增：顺时针 90° 旋转轨迹弧线（红色虚线，带箭头）
  - 保持：步骤 2 所有元素

- 步骤 4：
  - 变化：原始小旗变为半透明（opacity=0.3）
  - 新增：旋转后小旗（绿色轮廓 + 半透明填充）、从 O 到新顶点的绿色向量线
  - 保持：步骤 3 其他元素

- 步骤 5（最终步骤）：
  - 新增：新顶点标签 "(9, 3)"
  - 保持：步骤 4 所有元素
  - 此时完整展示旋转前后对比

[交互方案]
- 交互类型：分步按钮导航（◀ 上一步 / 下一步 ▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于 SVG 内底部左侧 (280, 460)，点击后退到前一步
  - 「下一步 ▶」按钮：位于 SVG 内底部右侧 (440, 460)，点击前进到下一步
  - 步骤指示器：位于两按钮之间 (400, 485)，显示当前步骤如「步骤 3/6」
- 教师操作流程：
  1. 初始展示原图，提问学生「小旗顶点坐标是多少？」
  2. 点击「下一步」高亮 O 点，讲解旋转中心概念
  3. 点击「下一步」显示向量，讲解点到旋转中心的相对位置
  4. 点击「下一步」显示轨迹弧，讲解旋转方向和角度
  5. 点击「下一步」显示旋转后位置，对比新旧图形
  6. 点击「下一步」显示新坐标，总结坐标变换规律

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单，SVG 原生支持 path、polygon、line 等元素，无需额外库
- 画布尺寸：800×500px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +------------------------------------------+
  |                                          |
  |          网格坐标系 (400×400)            |
  |          小旗在右上区域                  |
  |                                          |
  |                                          |
  |                                          |
  +------------------------------------------+
  |  [◀ 上一步]  步骤 X/6  [下一步 ▶]        |  <- 控件栏 y=450~490
  +------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0~5) 跟踪当前步骤，数组 steps 定义每步显示的元素 ID 列表
  2. 坐标计算：网格每格 50px，原点 (200,450) 对应坐标 (0,0)，坐标 (x,y) 映射到像素 (200+x*50, 450-y*50)
  3. 旋转轨迹弧：SVG path 使用 A 命令绘制圆弧，从 (450,250) 到 (650,450)，半径 200px
  4. 事件绑定：按钮点击事件调用 stepForward()/stepBackward()，更新 currentStep 并刷新显示
  5. 动画过渡：使用 CSS transition 实现 opacity 和 transform 的平滑过渡（可选）
- ID 命名规范：
  - 所有元素 ID 以 scene1- 为前缀
  - 示例：scene1-grid, scene1-flag-original, scene1-flag-rotated, scene1-point-o, scene1-arc-trajectory, scene1-label-original, scene1-label-new, scene1-btn-prev, scene1-btn-next, scene1-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
