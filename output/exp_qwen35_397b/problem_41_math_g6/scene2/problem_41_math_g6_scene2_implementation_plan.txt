[图示主题与整合说明]
- 本图示主题：影子长度随位置变化的函数关系图
- 整合的内容：将小亮从 A 点走向 B 点过程中影子长度的变化规律，用函数图像直观展示"先减后增"的变化趋势
- 教学价值：教师可通过分步构建函数图像，帮助学生理解：(1) 影子长度与人和路灯距离的关系；(2) 如何将实际情境抽象为数学函数；(3) 函数图像的最低点对应路灯正下方位置。学生能直观看到"先变短后变长"的选项 C 是正确的。

[分步序列]
- 步骤 0（初始状态）：显示空坐标系
  - 显示：横轴、纵轴、箭头

  - 显示：横轴上 A、路灯、B 三个位置标记及标签
  - 隐藏：所有数据点、曲线、高亮圈

- 步骤 1：描出 A 点对应的影子长度点
  - 新增：数据点 A(120,200)，蓝色实心圆点
  - 显示：从数据点 A 到横轴的虚线辅助线（可选）
  - 其他元素保持步骤 0 状态

- 步骤 2：描出路灯正下方对应的点（最低点）
  - 新增：数据点路灯(400,360)，蓝色实心圆点

- 步骤 3：描出 B 点对应的影子长度点
  - 新增：数据点 B(680,220)，蓝色实心圆点

- 步骤 4：用平滑曲线连接三点
  - 新增：红色函数曲线，从 A 点经路灯下到 B 点的平滑 U 型曲线
  - 其他元素保持步骤 3 状态

- 步骤 5：高亮最低点并标注
  - 新增：绿色高亮圈包围最低点(400,360)
  - 新增："最短"标注文字位于高亮圈上方
  - 所有元素显示完成

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于 SVG 底部左侧(300,450)，点击后返回上一状态
  - 「下一步 ▶」按钮：位于 SVG 底部右侧(420,450)，点击后进入下一状态
  - 步骤指示器：显示"步骤 X/5"，位于两按钮之间(380,455)
- 教师操作流程：
  1. 初始展示空坐标系，讲解横纵轴含义
  2. 点击"下一步"描出 A 点影子长度，提问"为什么 A 点影子较长？"
  3. 点击"下一步"描出路灯下点，引导学生发现此处影子最短
  4. 点击"下一步"描出 B 点，对比 A、B 两点影子长度
  5. 点击"下一步"连接曲线，展示完整函数图像
  6. 点击"下一步"高亮最低点，强调"路灯正下方影子最短"
  7. 可随时点击"上一步"回退复习关键概念

[技术实现]
- JS 库选择：原生 SVG
  - 原因：函数图像为 2D 平面几何，原生 SVG 足够实现坐标轴、曲线、圆点等元素，无需引入重型库
- 画布尺寸：800 × 500 px（系统规范）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |   影子长度                                        |
  |      ↑                                           |
  |      |                              ●(B 点)      |
  |      |                           /    \          |
  |      |                        /          \        |
  |      |                     /                \     |
  |      |                  /                    \    |
  |      |               /                        \   |
  |      |            /                            \  |
  |      |         /                                \ |
  |      |      /                                    \|
  |      |   ●(A 点)                              ●(路灯下)【最短】
  |      |                                           |
  |      +-------------------------------------------→ 小亮位置
  |      A         路灯                              B
  |                                                  |
  |              [◀ 上一步]  步骤 X/5  [下一步 ▶]     |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep(0-5) 跟踪当前步骤，数组 steps 存储每步应显示的元素 ID 列表
  2. 坐标计算：数据点 y 坐标 = 380 - 影子长度比例值，A 点影子长设为 180px，路灯下为 20px，B 点为 160px
  3. 曲线绘制：使用 SVG <path> 的二次贝塞尔曲线命令 Q 或三次贝塞尔曲线 C 连接三点
  4. 事件绑定：按钮点击事件更新 currentStep，调用 renderStep() 函数显示/隐藏对应元素
  5. 动画效果：数据点和曲线出现时添加淡入动画（opacity 从 0 到 1，过渡 0.3s）
- ID 命名规范：
  - 坐标轴：scene2-axis-x, scene2-axis-y
  - 轴标签：scene2-label-x, scene2-label-y
  - 横轴标记：scene2-mark-a, scene2-mark-lamp, scene2-mark-b
  - 横轴标签：scene2-text-a, scene2-text-lamp, scene2-text-b
  - 数据点：scene2-point-a, scene2-point-lamp, scene2-point-b
  - 函数曲线：scene2-curve
  - 高亮圈：scene2-highlight
  - 最低点标注：scene2-text-min
  - 按钮：scene2-btn-prev, scene2-btn-next
  - 步骤指示器：scene2-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
