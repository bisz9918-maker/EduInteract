[图示主题与整合说明]
- 本图示主题：立体图形分步构建过程（三视图还原正方体组合体）
- 整合内容：底层布局展示、逐层添加正方体、最终立体形态呈现

[分步序列]
- 初始状态（步骤0）：显示等轴测坐标系、步骤指示器"步骤0：准备构建"、计数"当前正方体数：0个"，无正方体
- 步骤1：点击「下一步」→ 显示底层4个正方体A/B/C/D（同时出现或依次淡入），位置标签显示，步骤指示器"步骤1：底层4个正方体"，计数"当前正方体数：4个"
- 步骤2：点击「下一步」→ 在位置A上方显示第2层正方体（绿色高亮#2e7d32），步骤指示器"步骤2：添加第2层"，计数"当前正方体数：5个"，新增正方体有缩放出现动画
- 步骤3：点击「下一步」→ 所有正方体统一为蓝色#1565c0，步骤指示器"步骤3：完整立体图形"，计数"共5个正方体"，显示最终答案提示
- 步骤4：点击「下一步」→ 整体图形轻微旋转±5度展示立体效果（可选），步骤指示器"步骤4：观察立体结构"，显示结论"答案：B. 5个"

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶/重置）
- 控件说明：
  - 「上一步」按钮(250,455)：回退到前一个步骤，可循环到步骤0
  - 「下一步」按钮(450,455)：前进到下一个步骤，到步骤4后禁用
  - 「重置」按钮(650,455)：直接返回步骤0
- 教师操作流程：
  1. 初始状态展示空坐标系，引出问题"如何从三视图构建立体图形？"
  2. 点击「下一步」展示底层4个正方体，讲解"俯视图确定底层位置"
  3. 点击「下一步」展示第2层正方体，讲解"主视图和左视图确定层数"
  4. 点击「下一步」展示完整图形，引导学生计数
  5. 点击「下一步」旋转视角，强化空间认知
  6. 可随时点击「上一步」回退复习关键步骤

[技术实现]
- JS 库选择：原生SVG + 原生JavaScript
  - 原因：等轴测立方体可用SVG polygon精确绘制，无需重型3D库；分步状态切换简单，原生JS足够
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  | [步骤指示器]                          [图例区]   |
  | [计数显示]                          第1层 █     |
  |                                    第2层 █     |
  |                                                  |
  |              等轴测立体图形                       |
  |                  (中央区域)                       |
  |                                                  |
  |                                                  |
  |                                                  |
  +--------------------------------------------------+
  | [上一步]        [下一步]         [重置]          |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量currentStep(0-4)跟踪当前步骤，steps数组存储每步配置
  2. 等轴测立方体绘制：定义函数drawIsoCube(x, y, size, color, opacity)，返回SVG group元素
  3. 坐标计算：等轴测投影公式 x' = x - y, y' = (x + y) / 2 - z
  4. 动画效果：新正方体使用CSS transition实现scale(0)→scale(1)淡入
  5. 事件绑定：三个按钮分别绑定click事件，更新currentStep并重绘
  6. 按钮状态：步骤0时禁用「上一步」，步骤4时禁用「下一步」
- ID 命名规范：所有元素ID以scene2-为前缀
  - scene2-cube-a, scene2-cube-b, scene2-cube-c, scene2-cube-d（底层4个）
  - scene2-cube-a2（第2层）
  - scene2-label-a, scene2-label-b, scene2-label-c, scene2-label-d（位置标签）
  - scene2-step-indicator, scene2-count-display（信息显示）
  - scene2-btn-prev, scene2-btn-next, scene2-btn-reset（按钮）
  - scene2-svg-main（主SVG容器）
- IIFE 隔离：所有JS代码包在 (function() { ... })() 中，避免全局变量污染
