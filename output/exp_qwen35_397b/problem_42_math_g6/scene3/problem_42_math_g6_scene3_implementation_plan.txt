[分步序列]
- 初始状态（步骤0）：显示完整立体图形（5个立方体，无高亮），右侧显示标题"分层计数"，选项区显示4个选项（无高亮）
- 步骤1：点击「下一步」→ 第1层4个立方体高亮（蓝色半透明），显示标签"第1层 4个"在图形下方
- 步骤2：点击「下一步」→ 第1层高亮保持，第2层1个立方体高亮（绿色半透明），显示标签"第2层 1个"在图形上方
- 步骤3：点击「下一步」→ 保持高亮，右侧显示计算式"4 + 1 = 5"（加粗黑色）
- 步骤4：点击「下一步」→ 选项B框背景变为#2e7d32高亮，选项A/C/D框变为#888888灰色，显示"总计 5个"标签

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于(280,450)，点击返回上一状态，步骤0时禁用
  - 「下一步」按钮：位于(440,450)，点击进入下一状态，步骤4时禁用
- 教师操作流程：
  1. 初始展示完整立体图形，让学生观察
  2. 点击「下一步」高亮底层，讲解"从上面看有4个位置，所以底层4个"
  3. 点击「下一步」高亮上层，讲解"从正面和左面看，只有左边有2层"
  4. 点击「下一步」显示计算式，汇总"4+1=5"
  5. 点击「下一步」高亮正确选项B，验证答案

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript。等轴测立方体用 SVG polygon 绘制，简单高效无需额外库
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  [立体图形区]           |  [计数区]              |
  |      第2层 1个          |  分层计数              |
  |        ■                |                        |
  |      ■ ■ ■              |  4 + 1 = 5             |
  |      第1层 4个          |  ┌──────────┐          |
  |                         |  │ A. 4     │          |
  |                         |  ├──────────┤          |
  |                         |  │ B. 5     │ (高亮)   |
  |                         |  ├──────────┤          |
  |                         |  │ C. 6     │          |
  |                         |  ├──────────┤          |
  |                         |  │ D. 7     │          |
  |                         |  └──────────┘          |
  |                                                  |
  |         [◀上一步]    [下一步▶]                   |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-4) 跟踪当前步骤，数组存储每步的显示配置
  2. 等轴测立方体绘制：每个立方体用3个polygon（顶面菱形、左前面平行四边形、右前面平行四边形）
  3. 高亮效果：在半透明填充层上叠加，不改变原立方体轮廓
  4. 按钮状态：步骤0禁用「上一步」，步骤4禁用「下一步」，用 opacity 和 pointer-events 控制
  5. 动画过渡：高亮层用 CSS transition 实现淡入效果（0.3s ease）
- ID 命名规范：所有元素 ID 以 scene3- 为前缀，如 scene3-cube-1、scene3-layer1-highlight、scene3-btn-next
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
