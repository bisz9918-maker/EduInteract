[图示主题与整合说明]
- 本图示主题：昆虫生命周期循环图——完全变态与不完全变态发育对比
- 整合的步骤/概念：整合了题目原图展示、完全变态发育路径标注、不完全变态发育路径标注、选项分析验证
- 教学价值：教师可使用此图示逐步展示两种发育类型的差异，通过高亮不同路径来验证各选项的正误，分步导航便于控制讲解节奏，帮助学生理解完全变态（蚊、家蚕：卵→幼虫→蛹→成虫）与不完全变态（蝗虫、蟋蟀：卵→若虫→成虫）的本质区别

[分步序列]
步骤 0（初始状态）：
- 显示：4 个节点圆圈（A/B/D/C），5 条基础箭头（A→B, B→D, D→C, C→A, D→A）
- 标签：A/B/C/D 四个字母，A 上方标注"卵"
- 等待教师点击"下一步"

步骤 1（完全变态发育）：
- 视觉变化：A→B→D→C→A 四条路径高亮为蓝色粗线（#1565c0, stroke-width=5）
- 新增标签：B 左侧显示"幼虫"，D 下方显示"蛹"，C 右侧显示"成虫"
- 底部说明文字："完全变态发育：卵→幼虫→蛹→成虫（蚊、家蚕）"
- D→A 箭头保持基础样式（不参与完全变态循环）

步骤 2（不完全变态发育）：
- 视觉变化：蓝色高亮消失，改为绿色高亮 A→B→C→A 路径（#2e7d32, stroke-width=5）
- 新增路径：B→C 直线路径（跳过 D 节点）
- D 节点变为灰色淡化（#cccccc 填充）
- 标签更新：B 左侧改为"若虫"，D 下方改为"无此阶段"
- 底部说明文字："不完全变态发育：卵→若虫→成虫（蝗虫、蟋蟀），无蛹期"

步骤 3（选项验证）：
- 保留步骤 2 的绿色路径
- 在 D 节点位置显示红色×标记，表示"D 阶段不存在"
- 底部说明文字："选项 B 错误：蝗虫为不完全变态，无 D 蛹期，D 不是成虫"
- 可选：在画布右下角显示简要选项分析（A✓ C✓ D✓）

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 按钮"◀ 上一步"：位置 (280, 460)，点击后返回上一状态，步骤 0 时禁用
  - 按钮"下一步 ▶"：位置 (420, 460)，点击后进入下一状态，步骤 3 时禁用
  - 步骤指示器：位置 (380, 460)，显示"步骤 X/4"
- 教师操作流程：
  1. 加载后显示基础循环图（步骤 0），教师介绍图示结构
  2. 点击"下一步"进入步骤 1，高亮完全变态路径，讲解蚊、家蚕的发育过程
  3. 点击"下一步"进入步骤 2，切换为不完全变态路径，D 节点淡化，讲解蝗虫、蟋蟀无蛹期
  4. 点击"下一步"进入步骤 3，显示红色×标记，验证选项 B 错误的原因
  5. 可随时点击"上一步"回退复习关键概念

[技术实现]
- JS 库选择：原生 SVG（简单几何图形首选，无需额外库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  
         A(卵)
        /     \
       /       \
      B         C
   (幼虫/若虫) (成虫)
       \       /
        \     /
         D(蛹)
         ↑
      (D→A 箭头)
  
  [控件栏 y=450~490]
  [◀ 上一步] [步骤 1/4] [下一步 ▶]
  [步骤说明文字居中显示]
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-3) 跟踪当前步骤，steps 数组存储每步的显示配置
  2. 箭头标记：使用 SVG <marker> 定义箭头头部，复用给所有路径
  3. 路径高亮：通过切换 class 或直接修改 stroke/stroke-width 实现
  4. D 节点淡化：步骤 2 中修改 fill 属性为 #cccccc
  5. 事件绑定：按钮点击事件绑定到 updateStep() 函数，更新 DOM 元素可见性
  6. 禁用状态：步骤 0 时禁用"上一步"，步骤 3 时禁用"下一步"，用 opacity 和 pointer-events 控制
- ID 命名规范：所有元素 ID 以 scene1- 为前缀
  - 节点：scene1-node-a, scene1-node-b, scene1-node-d, scene1-node-c
  - 标签：scene1-label-a, scene1-label-b, scene1-label-d, scene1-label-c
  - 标注：scene1-anno-egg, scene1-anno-larva, scene1-anno-pupa, scene1-anno-adult
  - 箭头：scene1-arrow-ab, scene1-arrow-bd, scene1-arrow-dc, scene1-arrow-ca, scene1-arrow-da
  - 高亮路径：scene1-highlight-complete-ab, scene1-highlight-incomplete-bc 等
  - 控件：scene1-btn-prev, scene1-btn-next, scene1-step-indicator, scene1-step-desc
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
- CDN 引入：无需外部库，纯原生 SVG + JS 实现
