[图示主题与整合说明]
- 本图示主题：基础血流模型——甲→乙→丙结构示意
- 整合的内容：题目原图复现 + 血流方向标注 + 血管与结构关系说明
- 教学价值：教师可使用此图示逐步展示人体血流的基本结构模型，帮助学生理解血管（甲、丙）与器官/组织结构（乙）之间的连接关系，以及血流方向的单向性。通过分步高亮，教师可以依次讲解每个部分的功能，为后续学习毛细血管、小肠、肾小球、胰岛等具体器官的血流特点奠定基础。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 按钮"◀ 上一步"：位置 (280,460)，点击后返回上一状态
  - 按钮"下一步 ▶"：位置 (420,460)，点击后进入下一状态
  - 状态指示器：位置 (380,430)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始加载后，图示显示基础结构，教师可介绍整体模型
  2. 点击"下一步"，甲血管高亮，教师讲解"甲是流入血管，将血液输送到器官"
  3. 点击"下一步"，乙结构高亮，教师讲解"乙是器官或组织结构，如毛细血管网、小肠、肾小球、胰岛等"
  4. 点击"下一步"，丙血管高亮，教师讲解"丙是流出血管，将血液从器官输送出去"
  5. 点击"下一步"，血流方向标注出现，教师总结"血流方向始终是甲→乙→丙的单向流动"
  6. 教师可随时点击"上一步"回退复习任一环节

[技术实现]
- JS 库选择及原因：原生 SVG。理由：本图示为简单几何图形（线段、矩形、箭头、文本），无需复杂库，原生 SVG 轻量且易于控制每个元素的显示/隐藏状态。
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +----------------------------------------------------------+
  |                                                          |
  |                    甲              丙                     |
  |   ────────────→  ┌──────────┐  ────────────→            |
  |                  │    乙    │                             |
  |                  │          │                             |
  |                  └──────────┘                             |
  |                                                          |
  |                   血流方向→                               |
  |                                                          |
  |                                                          |
  |              [◀ 上一步]  步骤 X/5  [下一步 ▶]             |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-4），数组存储每个状态应显示的元素 ID 列表
  2. 坐标计算：所有元素使用绝对坐标，SVG viewBox="0 0 800 500"
  3. 动画曲线：高亮层使用 CSS transition opacity 0.3s ease-in-out 实现淡入淡出
  4. 事件绑定：按钮点击事件绑定到 updateState() 函数，更新当前状态并刷新显示
  5. 边界处理：步骤 0 时禁用"上一步"按钮，步骤 4 时禁用"下一步"按钮
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀
  - scene1-vessel-a（甲血管线段）
  - scene1-vessel-a-arrow（甲箭头）
  - scene1-label-a（甲标签）
  - scene1-structure-b（乙结构框）
  - scene1-label-b（乙标签）
  - scene1-vessel-c（丙血管线段）
  - scene1-vessel-c-arrow（丙箭头）
  - scene1-label-c（丙标签）
  - scene1-flow-label（血流方向标注）
  - scene1-highlight-a（甲高亮层）
  - scene1-highlight-b（乙高亮层）
  - scene1-highlight-c（丙高亮层）
  - scene1-btn-prev（上一步按钮）
  - scene1-btn-next（下一步按钮）
  - scene1-step-indicator（步骤指示器）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
