[图示主题与整合说明]
- 本图示主题：四种器官情况下血液性质变化对比
- 整合内容：心脏、肺、小肠、组织细胞四种情况的血液变化整合为一个多状态切换图示
- 教学价值：教师可通过切换不同器官状态，直观展示血液流经不同器官时氧气和二氧化碳的变化规律，帮助学生理解体循环与肺循环的区别，以及不同器官对血液成分的影响

[分步序列]
多状态切换交互（4 个状态按钮，教师点击切换）：

- 状态 0（初始/心脏）：
  - 器官 b 显示"心脏"文字，绿色轮廓
  - 血管 a：静脉血（蓝色#1565c0 填充），标签"静脉血"
  - 血管 c：动脉血（红色#c62828 填充），标签"动脉血"
  - 气体交换：不显示 O₂/CO₂箭头（心脏主要泵血功能）
  - 说明：静脉→心脏→动脉

- 状态 1（肺）：
  - 器官 b 显示"肺"文字，绿色轮廓，内部绘制肺泡简化图标
  - 血管 a：肺动脉，静脉血（蓝色#1565c0 填充），标签"静脉血"
  - 血管 c：肺静脉，动脉血（红色#c62828 填充），标签"动脉血"
  - 气体交换：O₂箭头（红色）指向血管 c 方向，CO₂箭头（蓝色）指向外部
  - 说明：肺动脉（静脉血）→肺→肺静脉（动脉血），氧气进入血液

- 状态 2（小肠）：
  - 器官 b 显示"小肠"文字，绿色轮廓，内部绘制绒毛简化图标
  - 血管 a：肠动脉，动脉血（红色#c62828 填充），标签"动脉血"
  - 血管 c：肠静脉，静脉血（蓝色#1565c0 填充），标签"静脉血"
  - 气体交换：O₂箭头指向器官内部（被消耗），CO₂箭头从器官指出（产生）
  - 说明：动脉（动脉血）→小肠→静脉（静脉血），吸收营养，氧气被消耗

- 状态 3（组织细胞）：
  - 器官 b 显示"组织细胞"文字，绿色轮廓，内部绘制细胞简化图标
  - 血管 a：体动脉，动脉血（红色#c62828 填充），标签"动脉血"
  - 血管 c：体静脉，静脉血（蓝色#1565c0 填充），标签"静脉血"
  - 气体交换：O₂箭头指向器官内部（被消耗），CO₂箭头从器官指出（产生）
  - 说明：动脉（动脉血）→组织细胞→静脉（静脉血），氧气被消耗，产生二氧化碳

[交互方案]
- 交互类型：多状态切换（4 个状态按钮）
- 控件说明：
  - 按钮 1「心脏」：位置 (150,450)，切换到心脏状态
  - 按钮 2「肺」：位置 (275,450)，切换到肺状态
  - 按钮 3「小肠」：位置 (400,450)，切换到小肠状态
  - 按钮 4「组织细胞」：位置 (525,450)，切换到组织细胞状态
- 教师操作流程：
  1. 初始显示心脏状态，讲解心脏的泵血功能
  2. 点击「肺」按钮，展示肺循环中血液由静脉血变动脉血的过程
  3. 点击「小肠」按钮，展示体循环中血液流经消化器官的变化
  4. 点击「组织细胞」按钮，展示体循环中血液流经一般组织的变化
  5. 可反复切换对比，强调肺循环与体循环的区别

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +------------------------------------------+
  |                                          |
  |    a(血管)      b(器官)      c(血管)     |
  |    ======>    (=======)    ======>       |
  |   静脉血       器官名      动脉血         |
  |                O₂→                        |
  |                 →CO₂                      |
  |                                          |
  |                                          |
  |  [心脏]  [肺]  [小肠]  [组织细胞]         |
  |  (状态按钮区 y=450-490)                   |
  +------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用 currentState 变量 (0-3) 跟踪当前状态，点击按钮更新状态并重绘
  2. 血管填充：使用 SVG <rect> 或 <path> 填充颜色，根据血液性质切换 fill 属性
  3. 器官图标：用 SVG 基本形状（圆形、椭圆、路径）绘制简化器官图标
  4. 气体交换箭头：用 SVG <marker> 定义箭头，根据状态显示/隐藏
  5. 事件绑定：每个按钮绑定 click 事件，调用 updateState(newState) 函数
  6. 动画过渡：血管颜色切换使用 CSS transition 实现平滑过渡（0.3s）
- ID 命名规范：所有交互元素 ID 必须以 scene2- 为前缀
  - scene2-vessel-a, scene2-vessel-c, scene2-organ-b
  - scene2-label-a, scene2-label-c, scene2-label-organ
  - scene2-blood-a, scene2-blood-c（血液性质标签）
  - scene2-arrow-o2, scene2-arrow-co2
  - scene2-btn-heart, scene2-btn-lung, scene2-btn-intestine, scene2-btn-tissue
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
