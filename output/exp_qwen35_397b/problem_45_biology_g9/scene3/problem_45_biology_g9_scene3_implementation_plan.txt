[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript
  - 理由：几何形状简单（圆形、矩形、箭头），无需复杂库；原生 SVG 便于精确控制每个元素的状态和动画
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +----------------------------------------------------------+
  |                                                          |
  |                    组织细胞区域 b                         |
  |         血管 a  ────────→  (●●●●●)  ────────→  血管 c      |
  |         动脉血            组织细胞群          静脉血        |
  |                        O₂↓  ↑CO₂                          |
  |                                                          |
  |                    组织细胞                               |
  |                                                          |
  |                    D 正确 ✓                               |
  |                                                          |
  |  [◀上一步]                          [下一步▶]             |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-4) 跟踪当前步骤，每个步骤对应一组可见元素
  2. 元素 ID 命名：所有元素以 scene3- 为前缀，如 scene3-vessel-a、scene3-tissue-b、scene3-vessel-c、scene3-o2-arrow、scene3-co2-arrow、scene3-label-arterial、scene3-label-venous、scene3-conclusion
  3. 状态切换函数：updateStep() 根据 currentStep 显示/隐藏对应元素，更新按钮状态
  4. 动画效果：血管填充颜色变化用 CSS transition 实现平滑过渡（0.3s）
  5. 事件绑定：按钮点击事件绑定到 updateStep()，键盘左右箭头也可切换步骤
  6. IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
- ID 命名规范：
  - scene3-vessel-a：血管 a
  - scene3-vessel-c：血管 c
  - scene3-tissue-region：组织细胞区域 b

  - scene3-label-a：标签"a"

  - scene3-label-arterial：标签"动脉血"
