[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 内底部左侧 (x=320, y=460)，点击回退到前一状态
  - 「下一步」按钮：位于 SVG 内底部右侧 (x=460, y=460)，点击前进到下一状态
  - 步骤指示器：位于两按钮之间 (x=400, y=460)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始展示 DNA 基础结构，讲解 DNA 双链平面展开形式
  2. 点击「下一步」高亮①，讲解磷酸二酯键连接相邻核苷酸
  3. 点击「下一步」高亮②，讲解氢键连接碱基对
  4. 点击「下一步」显示解旋酶，讲解解旋酶作用于氢键使 DNA 解旋
  5. 点击「下一步」显示计算框，讲解碱基比例计算：C=30%→G=30%→A+T=40%→(C+G)/(A+T)=3/2
  6. 可随时点击「上一步」回退复习

- JS 库选择：原生 SVG（简单几何图形首选，无需额外库）
- 画布尺寸：800×500 px（固定）
- 布局草图：

  ```
  ┌────────────────────────────────────────────────────┐

  │                    ││││     ││││                   │
  │         下链骨架 y=280  ────────────────────        │
  │         碱基标签 y=305  G A C G ... G A A T        │
  │                                                     │
  │         ①标记 (190,185)  ②标记 (500,240)           │
  │         解旋酶 (500,220) [步骤 3 显示]              │
  │                                                     │
  │    ┌──────────────────────────────────────────┐    │

  │          (320,460)  (400,460)  (460,460)          │
  └────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量 (0-4) 跟踪当前步骤
  2. 元素分组：将①标记、②标记、解旋酶、计算框分别放入独立<g>组，通过 display 属性控制显示/隐藏
  3. 坐标计算：所有坐标硬编码，确保与布局坐标表一致
  4. 事件绑定：为「上一步」「下一步」按钮绑定 click 事件，更新 currentState 并刷新显示状态
  5. 边界处理：步骤 0 时禁用「上一步」，步骤 4 时禁用「下一步」
- ID 命名规范：所有元素 ID 以 scene1- 为前缀
  - scene1-dna-backbone-top, scene1-dna-backbone-bottom
  - scene1-base-pair-1 至 scene1-base-pair-8
  - scene1-label-c1, scene1-label-t1, ...（碱基标签）
  - scene1-marker-1-circle, scene1-marker-1-arrow, scene1-label-1
  - scene1-marker-2-ellipse, scene1-marker-2-arrow, scene1-label-2
  - scene1-helicase
  - scene1-calc-box, scene1-calc-text-1 至 scene1-calc-text-4
  - scene1-btn-prev, scene1-btn-next, scene1-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
