[图示主题与整合说明]
- 本图示主题：肾单位结构与尿液形成过程
- 整合内容：肾单位三部分结构识别（肾小球、肾小囊、肾小管）+ 题目流程图映射（甲、乙、a、b 标注）+ 尿液形成两过程（过滤、重吸收）
- 教学价值：教师可使用此图示按认知顺序逐步讲解肾单位结构，通过高亮和动画展示尿液形成的过滤与重吸收过程，帮助学生理解甲=肾小囊、乙=肾小管、a=原尿、b=尿液的对应关系，同时掌握肾单位的组成及功能

[分步序列]
共 7 个步骤（0-6），教师可通过"上一步/下一步"按钮控制进度：

- 步骤 0（初始状态）：显示肾单位基础结构轮廓
  - 显示：入球小动脉、肾小球（灰色轮廓）、肾小囊（灰色轮廓）、肾小管（灰色轮廓）、出球小动脉
  - 右侧流程图：仅显示"血液流进肾小球中"框
  - 所有标签隐藏，无高亮

- 步骤 1：高亮肾小球，标注过滤作用
  - 视觉变化：肾小球填充#c62828 红色，显示标签"肾小球"在 (220,130)
  - 新增：过滤箭头从 (220,190) 指向 (220,230)
  - 右侧流程图：显示箭头 1 和甲框

- 步骤 2：高亮肾小囊，标注甲和原尿 a
  - 视觉变化：肾小囊填充#bbdefb(20% 浅蓝)，边框#1565c0 高亮
  - 新增：标签"甲"在 (280,175)，标签"a"在 (275,195)，a 原尿区域填充
  - 右侧流程图：显示"形成"文本 1、a 框及连接箭头

- 步骤 3：高亮肾小管，标注乙和尿液 b
  - 视觉变化：肾小管填充#c8e6c9(20% 浅绿)，边框#2e7d32 高亮
  - 新增：标签"乙"在 (360,300)，标签"b"在 (405,375)，b 尿液区域填充
  - 右侧流程图：显示乙框、"形成"文本 2、b 框及连接箭头

- 步骤 4：动画展示过滤过程
  - 视觉变化：肾小球保持红色高亮
  - 新增动画：蛋白质分子 (紫椭圆) 和血细胞 (红圆盘) 从入球小动脉移动到肾小球处被阻挡（虚线箭头表示无法通过）
  - 水分子、葡萄糖、无机盐小图标从肾小球过滤到肾小囊（实线箭头）
  - 标签："大分子蛋白质和血细胞被阻挡"在 (150,250)

- 步骤 5：动画展示重吸收过程
  - 视觉变化：肾小管保持绿色高亮
  - 新增动画：葡萄糖 (黄)、水 (蓝)、无机盐 (绿) 从肾小管通过重吸收箭头回到出球小动脉方向
  - 标签："全部葡萄糖、大部分水、部分无机盐被重吸收"在 (300,350)

- 步骤 6（最终步骤）：总结肾单位组成
  - 视觉变化：肾小球、肾小囊、肾小管同时高亮显示
  - 新增：总结框在 (50,400) 显示"肾单位 = 肾小球 + 肾小囊 (甲) + 肾小管 (乙)"
  - 所有标签可见，完整展示题目流程图与结构的对应关系

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：位于 (280,455)，点击后返回上一状态，步骤数减 1（最小为 0）
  - "下一步 ▶"按钮：位于 (420,455)，点击后进入下一状态，步骤数加 1（最大为 6）
  - 步骤指示器：位于 (550,465)，显示当前步骤"步骤 X/6"
- 教师操作流程：
  1. 初始加载显示步骤 0（基础结构），教师介绍肾单位整体形态
  2. 点击"下一步"进入步骤 1，高亮肾小球，讲解过滤作用发生位置
  3. 点击"下一步"进入步骤 2，高亮肾小囊，说明甲=肾小囊，a=原尿
  4. 点击"下一步"进入步骤 3，高亮肾小管，说明乙=肾小管，b=尿液
  5. 点击"下一步"进入步骤 4，播放过滤动画，讲解大分子被阻挡
  6. 点击"下一步"进入步骤 5，播放重吸收动画，讲解有用物质回收
  7. 点击"下一步"进入步骤 6，总结肾单位组成，对照题目流程图
  8. 教师可随时点击"上一步"回退复习关键概念

[技术实现]
- JS 库选择：原生 SVG（适合绘制生物结构示意图，无需额外库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  [肾单位结构区]           [流程图对照区]         |
  |   入球→肾小球→出球         框 1→甲→a              |
  |         ↓ 肾小囊            ↓                    |
  |         ↓ 肾小管            乙→b                 |
  |         ↓                                          |
  |   [分子图标区]                                      |
  +--------------------------------------------------+
  |  [◀ 上一步]  [下一步 ▶]  [步骤 X/6]               |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量 (0-6)，每个状态对应一组可见元素 ID 列表
  2. 坐标计算：肾小管使用 SVG path 绘制 S 形曲线，控制点确保平滑弯曲
  3. 动画曲线：过滤/重吸收动画使用 CSS transition 或 requestAnimationFrame，缓动函数 ease-in-out
  4. 事件绑定：按钮点击事件绑定到 stateTransition 函数，更新可见性并刷新步骤指示器
  5. 元素可见性：使用 display/opacity 或 SVG visibility 属性控制各步骤元素显示
- ID 命名规范：所有元素 ID 以 scene1- 为前缀
  - scene1-glomerulus（肾小球）
  - scene1-bowman-capsule（肾小囊）
  - scene1-renal-tubule（肾小管）
  - scene1-afferent-arteriole（入球小动脉）
  - scene1-efferent-arteriole（出球小动脉）
  - scene1-label-a（a 标签）
  - scene1-label-b（b 标签）
  - scene1-flowchart-box1（流程图框 1）
  - scene1-flowchart-jia（甲框）
  - scene1-flowchart-yi（乙框）
  - scene1-btn-prev（上一步按钮）
  - scene1-btn-next（下一步按钮）
  - scene1-step-indicator（步骤指示器）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
- CDN 引入：无需额外库，使用原生 SVG 和 JavaScript
