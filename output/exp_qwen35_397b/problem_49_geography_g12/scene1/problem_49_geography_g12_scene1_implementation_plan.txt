- 本图示主题：南极俯视图基础框架与要素标注

[分步序列]
- 初始状态（步骤 0）：显示基础框架
  - 显示：外圆（赤道虚线）、内圆（70°纬线实线）、南极点 O、6 条经线（黑色细线）
  - 标签：O、70°
  - 等待教师点击「下一步」

- 步骤 1：标注晨昏线 MA
  - 新增：晨昏线 MA（蓝色弧线，从 M 到 A）
  - 新增标签：M、A、「晨昏线」
  - 高亮：晨昏线 MA 闪烁一次

- 步骤 2：高亮切点 M 及 70°纬线
  - 变化：切点 M 变为红色实心圆点（直径 6px）
  - 高亮：70°纬线圈加粗为 2px 并变为蓝色 #1565c0
  - 新增：M 点脉冲动画（半径从 6px 扩展到 10px 再收缩，重复 2 次）

- 步骤 3：标注经线 B
  - 新增：经线 B 加粗变为绿色 #2e7d32（2px）
  - 新增标签：B（左上方）
  - 高亮：经线 B 从圆心向外绘制动画

- 步骤 4：显示阴影区域并标注「日期不同」
  - 新增：阴影区域（150°~180°扇形，灰色 20% 透明度）
  - 新增标签：「阴影区」在扇形内
  - 高亮：阴影区域淡入动画（透明度从 0% 到 20%）

- 步骤 5：添加地球自转方向箭头
  - 新增：顺时针弯曲箭头（蓝色 #1565c0）在右下方
  - 动画：箭头沿顺时针方向绘制
  - 最终状态：所有要素完整显示，教师可点击「上一步」回退复习

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 内底部左侧 (x=320, y=455)，返回上一状态
  - 「下一步」按钮：位于 SVG 内底部右侧 (x=460, y=455)，进入下一状态
  - 步骤指示器：位于两按钮之间 (x=400, y=455)，显示「步骤 X/6」
- 教师操作流程：
  1. 初始状态展示基础框架，教师讲解南极俯视图的基本结构
  2. 点击「下一步」展示晨昏线，讲解晨昏线的定义和几何特征
  3. 点击「下一步」高亮切点 M，讲解切点与纬线的关系
  4. 点击「下一步」标注经线 B，讲解经线与晨昏线的交点意义
  5. 点击「下一步」显示阴影区，讲解日期分界线的概念
  6. 点击「下一步」显示自转箭头，讲解南极俯视图中地球自转方向为顺时针
  7. 可随时点击「上一步」回退复习关键概念

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript
  - 原因：本图示为 2D 几何图形（圆、弧线、线段、扇形），原生 SVG 完全满足需求，无需引入额外库
  - 优势：文件体积小、加载快、代码简洁易维护

- 画布尺寸：800 × 500 px（固定）

- 布局草图（ASCII）：
  ```

  +--------------------------------------------------+
  |                                                  |
  ```

- 关键实现要点：
  1. 状态机设计：使用 stateIndex 变量（0~5）跟踪当前步骤，steps 数组存储每个步骤的显示配置
  2. 坐标计算：所有元素坐标预先计算好硬编码，避免运行时计算误差
  3. 动画曲线：使用 CSS transition 实现淡入/绘制动画，ease-out 曲线
  4. 事件绑定：按钮点击事件绑定到 updateScene() 函数，根据 stateIndex 更新 DOM 元素可见性
  5. 元素可见性控制：每个元素有 data-step 属性，表示从哪一步开始显示

- ID 命名规范：
  - 所有交互元素 ID 必须以 scene1- 为前缀
  - 示例：scene1-outer-circle, scene1-inner-circle, scene1-point-o, scene1-point-m, scene1-point-a, scene1-point-b, scene1-morning-line, scene1-meridian-b, scene1-shadow-area, scene1-rotation-arrow, scene1-label-o, scene1-label-m, scene1-label-a, scene1-label-b, scene1-label-70, scene1-label-morning, scene1-label-shadow
  - 控件 ID：scene1-btn-prev, scene1-btn-next, scene1-step-indicator
