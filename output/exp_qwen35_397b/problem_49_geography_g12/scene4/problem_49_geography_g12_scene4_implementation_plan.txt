[分步序列]
本场景为连续拖拽滑块交互，无分步导航，状态随滑块实时变化：

- 初始状态（滑块默认值）：
  - 纬度滑块：30.5°N（手柄位置约 67% 处）
  - 经度滑块：114.5°E（手柄位置约 64% 处）
  - 公式区显示：H = 90° - |30.5° - 20°| = 79.5°
  - 结果区显示：正午太阳高度角：79.5° | 地方时：待计算
  - 地球截面图：显示 30.5°N 点 P 和 20°N 直射点 S
  - 经度数轴：114.5°E 位置高亮标记

- 拖拽纬度滑块时：
  - 手柄跟随鼠标/触摸移动
  - 地球截面图中 P 点沿经线移动
  - φ标签数值实时更新
  - 公式区 H 计算结果实时更新
  - 太阳高度角 H 弧线角度实时变化

- 拖拽经度滑块时：
  - 手柄跟随鼠标/触摸移动
  - 经度数轴上标记点移动
  - 经度标签数值实时更新
  - 地方时计算结果实时更新（基于经度差×4 分钟/度）

- 极端值状态：
  - 纬度 -90°：P 点在南极点，H = 90° - |-90° - 20°| = -20°（极夜）
  - 纬度 90°：P 点在北极点，H = 90° - |90° - 20°| = 0°
  - 经度 -180°/180°：国际日期变更线，地方时与 0°经线差 12 小时

[交互方案]
- 交互类型：连续拖拽滑块（双滑块独立控制）
- 控件说明：
  - 纬度滑块：位于底部左侧 (100,440)-(350,455)，范围 -90° 到 90°，默认 30.5°
  - 经度滑块：位于底部右侧 (450,440)-(700,455)，范围 -180° 到 180°，默认 114.5°
  - 滑块手柄：圆形 20px，可左右拖拽，拖拽时显示当前数值提示
- 教师操作流程：
  1. 初始状态展示题目给定的 30.5°N、114.5°E 的计算结果
  2. 拖拽纬度滑块，演示不同纬度地区正午太阳高度角的变化规律
  3. 拖拽经度滑块，演示不同经度地区地方时的差异
  4. 结合公式区，讲解 H = 90° - |φ - δ| 的几何意义
  5. 结合经度数轴，讲解 15°经度差=1 小时时间差的对应关系

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单，无需复杂库；拖拽交互用原生事件即可实现；CDN 依赖少，加载快
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [800 × 500 画布]
  +--------------------------------------------------+
  | [公式区 H = 90° - |φ - δ|]    [结果显示区]       |  y=50-160
  |                                                  |
  | [地球截面图]              [经度 - 时间数轴]      |  y=100-300
  |    (左)                      (右)                |
  |                                                  |
  |                                                  |
  |                                                  |
  | [纬度滑块]              [经度滑块]               |  y=440-460
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：维护 state 对象 { latitude: 30.5, longitude: 114.5, directLatitude: 20 }
  2. 坐标计算：
     - 纬度滑块手柄 x = 100 + (latitude + 90) / 180 * 250
     - 经度滑块手柄 x = 450 + (longitude + 180) / 360 * 250
     - 地球截面 P 点 y = 200 - sin(纬度弧度) * 100
  3. 动画曲线：拖拽时实时更新，无需缓动
  4. 事件绑定：mousedown/touchstart → mousemove/touchmove → mouseup/touchend
  5. 数值格式化：保留 1 位小数，角度符号°用 HTML 实体 &deg;
- ID 命名规范：
  - scene4-earth-circle, scene4-point-p, scene4-point-s, scene4-sun-rays
  - scene4-axis-longitude, scene4-axis-time
  - scene4-slider-latitude, scene4-slider-longitude
  - scene4-formula-display, scene4-result-display
  - scene4-handle-latitude, scene4-handle-longitude
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
