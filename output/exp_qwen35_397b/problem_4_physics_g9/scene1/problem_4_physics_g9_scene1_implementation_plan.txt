[图示主题与整合说明]
- 本图示主题：原电路短路路径分析
- 整合的内容：原电路结构展示 + 开关闭合后电流路径 + 短路判断
- 教学价值：教师可使用此图示逐步展示电路从静态到动态电流走向的过程，帮助学生理解短路现象的本质——电流选择电阻最小的路径，不经过用电器直接回到负极。通过分步动画，学生能清晰看到为什么选项 B 是错误的（灯泡实际不发光）。

[分步序列]
- 初始状态（步骤 0）：显示完整原电路图
  * 所有元件：电源、开关 S（断开状态）、灯泡 L₁、灯泡 L₂
  * 所有导线：电源(+)→D、电源(-)→S、导线 a、导线 b、导线 M
  * 所有标签：电源(+)、电源(-)、S、L₁、L₂、A、B、C、D、a、b、M
  * 开关闸刀处于断开位置（向上倾斜）

- 步骤 1：闭合开关 S，展示电流路径
  * 开关闸刀移动到闭合位置（水平）
  * 显示 4 个红色电流箭头，沿路径流动动画：
    - 箭头 1：从 D 沿导线 b 向下
    - 箭头 2：从导线 b 中部继续向下到 B
    - 箭头 3：从 B 沿导线 M 向左
    - 箭头 4：从导线 M 中部继续向左到 S
  * 箭头使用 CSS 动画，从左到右依次出现，模拟电流流动

- 步骤 2：高亮短路路径
  * 保持步骤 1 的所有元素
  * 导线 b 和 M 上叠加红色加粗线段（4px），表示短路路径
  * 显示短路标注文本："短路：电流不经过用电器"（红色，位置 (400,380)）
  * 电流箭头继续动画流动

- 步骤 3：显示结论
  * 保持步骤 2 的所有元素
  * 显示结论文本框（蓝色背景，白色文字）：
    "选项 A 正确（确实短路），选项 B 错误（灯泡不发光）"
  * 电流箭头停止动画，保持显示

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  * 「上一步」按钮：位置 (320,485)，灰色背景，点击返回上一状态
  * 「下一步」按钮：位置 (420,485)，蓝色背景，点击进入下一状态
  * 步骤指示器：位置 (500,485)，显示"步骤 X/4"
- 教师操作流程：
  1. 初始加载后，教师先让学生观察原电路结构，识别各元件和导线连接
  2. 点击「下一步」闭合开关，电流箭头开始流动，教师讲解电流实际路径
  3. 点击「下一步」高亮短路路径，教师强调"电流不经过用电器"
  4. 点击「下一步」显示结论，教师总结为什么选项 B 是错误的

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  * 原因：电路图是静态几何图形 + 简单动画，原生 SVG 足够胜任，无需引入重型库
  * 电流箭头动画使用 CSS @keyframes 实现流动效果

- 画布尺寸：800 × 500 px（固定）

- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                    电源                          |
  |              (-) ======== (+)                    |
  |               /              \                   |
  |              /                \                  |
  |             S                  \                 |
  |          [开关]                 \                |
  |             |                    L₂              |
  |             |-------------------(D)              |
  |             |                    | b             |
  |             |                    |               |
  |             |                    L₁              |
  |             |-------------------(B)              |
  |                                  |               |
  |  步骤 0-3：电路元件 + 导线        |               |
  |  步骤 1：+ 电流箭头动画           |               |
  |  步骤 2：+ 短路高亮 + 标注        |               |
  |  步骤 3：+ 结论文本框             |               |
  |                                                  |
  |        [◀上一步] [下一步▶]  步骤 1/4             |
  +--------------------------------------------------+
  ```

- 关键实现要点：
  1. 状态机设计：使用 state 变量 (0-3) 跟踪当前步骤，每个步骤对应一组可见元素
  2. 开关动画：闸刀线段使用 transform: rotate() 从断开角度（约 -30°）旋转到闭合角度（0°）
  3. 电流箭头动画：使用 CSS @keyframes opacity 和 transform 实现从左到右依次出现
  4. 短路高亮：在原有黑色导线上方叠加红色加粗线段，使用 opacity 过渡
  5. 事件绑定：按钮点击事件调用 updateScene() 函数，根据 state 更新各元素 display/opacity

- ID 命名规范：
  * 所有交互元素 ID 必须以 scene1- 为前缀
  * 示例：scene1-power、scene1-switch-base、scene1-switch-blade、scene1-lamp-l1、scene1-lamp-l2
  * 接线柱：scene1-terminal-a、scene1-terminal-b、scene1-terminal-c、scene1-terminal-d
  * 导线：scene1-wire-a、scene1-wire-b、scene1-wire-m、scene1-wire-pos、scene1-wire-neg
  * 电流箭头：scene1-arrow-1、scene1-arrow-2、scene1-arrow-3、scene1-arrow-4
  * 短路高亮：scene1-short-b、scene1-short-m
  * 标注：scene1-label-short、scene1-label-conclusion
  * 控件：scene1-btn-prev、scene1-btn-next、scene1-step-indicator

- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
