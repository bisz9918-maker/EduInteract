[图示主题与整合说明]
- 本图示主题：两种电路修改方案对比（串联 vs 并联）
- 整合的步骤/概念：
  1. 原始电路状态（短路）
  2. 方案 C：去掉导线 b 后的串联电路
  3. 方案 D：M 改接 A 后的并联电路
- 教学价值：教师可通过状态切换直观对比三种电路连接方式，帮助学生理解：
  - 原电路为何短路（电流经导线 b 直接回负极，不经过灯泡）
  - 去掉导线 b 后电流如何依次经过 L₂→L₁ 形成串联
  - M 改接 A 后电流如何分两路形成并联
  便于课堂讲解电路修改对连接方式的影响

[分步序列]
状态 0（原电路 - 初始状态）：
- 显示所有导线：正→D、负→开关、a、b(实线)、M(接 B)
- 导线 b 为黑色实线
- 导线 M 连接开关右端 (180,310) 到 B(620,250)
- 灯泡无发光效果
- 状态标签显示「原电路（短路）」
- 按钮 1 高亮（背景深蓝 #0d47a1）

状态 1（方案 C - 串联）：
- 导线 b 变为灰色虚线 (#888888, dasharray="5,5")
- 导线 M 仍接 B(620,250)
- 显示绿色电流路径箭头：正极→D→L₂→C→a→A→L₁→B→M→S→负极
- 灯泡 L₁、L₂ 内部填充淡绿色 (#c8e6c9, opacity 0.3) 表示发光
- 状态标签显示「串联电路」
- 按钮 2 高亮

状态 2（方案 D - 并联）：
- 导线 b 恢复黑色实线
- 导线 M 改接 A(520,250)：从 (180,310) 到 (520,250)
- 显示两条绿色电流路径：
  - 路径 1：正极→D→L₂→C→a→A→M→S→负极
  - 路径 2：正极→D→b→B→L₁→A→M→S→负极
- 灯泡 L₁、L₂ 内部填充淡绿色表示发光
- 状态标签显示「并联电路」
- 按钮 3 高亮

[交互方案]
- 交互类型：多状态切换（3 个按钮）
- 控件说明：
  - 按钮 1「原电路」：点击恢复原始连接（导线 b 实线，M 接 B）
  - 按钮 2「方案 C（串联）」：点击去掉导线 b（变虚线），显示串联电流路径
  - 按钮 3「方案 D（并联）」：点击 M 改接 A，显示并联电流路径
- 教师操作流程：
  1. 初始展示原电路，讲解为何短路（电流经 b 直接回负极）
  2. 点击「方案 C（串联）」，观察导线 b 变虚线，电流依次经过 L₂→L₁
  3. 点击「方案 D（并联）」，观察 M 改接 A，电流分两路分别经过 L₁ 和 L₂
  4. 可反复切换对比三种状态

[技术实现]
- JS 库选择：原生 SVG（电路图结构简单，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  电源(左上)          L₂(右上)                    |
  |  (+) (-)            C  💡  D                     |
  |                    |       |                     |
  |                    | a     | b                   |
  |                    |       |                     |
  |  S(左下)           A  💡  B  L₁                  |
  |  [开关]             \     /                      |
  |                     \ M /                       |
  |                      \ /                        |
  |                                               [状态] |
  |                                                  标签 |
  +--------------------------------------------------+
  |  [原电路]  [方案 C（串联）]  [方案 D（并联）]     |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentState (0/1/2) 跟踪当前状态
  2. 导线 b 样式切换：state1 时设置 stroke="#888888" stroke-dasharray="5,5"
  3. 导线 M 路径切换：state2 时修改 path d 属性终点从 B(620,250) 改为 A(520,250)
  4. 电流箭头动画：用 SMIL <animateMotion> 或 JS requestAnimationFrame 沿路径移动
  5. 灯泡发光：state1/2 时设置 circle fill="#c8e6c9" fill-opacity="0.3"
  6. 按钮高亮：当前状态按钮背景色加深
  7. 事件绑定：三个按钮分别绑定 click 事件，调用 updateState(n)
- ID 命名规范：
  - 所有元素 ID 以 scene2- 为前缀
  - 如：scene2-wire-b, scene2-wire-M, scene2-bulb-L1, scene2-btn-original 等
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
