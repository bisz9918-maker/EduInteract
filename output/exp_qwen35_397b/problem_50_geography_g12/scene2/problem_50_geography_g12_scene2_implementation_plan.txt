[图示主题与整合说明]
- 本图示主题：太阳直射点与时间计算
- 整合内容：太阳直射点坐标、地方时计算、北京时间推导
- 教学价值：教师可通过分步动画展示从已知条件（160°E为12:00）到求解北京时间（9:20）的完整逻辑链条，帮助学生理解经度差与时间差的换算关系。步骤式设计让学生跟随教师思路逐步推导，避免一步到位造成的认知负担。

[分步序列]
- 初始状态（步骤0）：显示经度轴线、120°E刻度（绿色）、160°E刻度（蓝色）、"120°E"标签、"160°E"标签、"12:00"标签（160°E上方）、"?"标签（120°E上方，绿色）。标题显示。
- 步骤1：点击「下一步」→ 显示经度差双向箭头（从120°E到160°E，y=190），显示"经度差 40°"标签（y=180）。其他元素保持。
- 步骤2：点击「下一步」→ 显示时间差弧形箭头（中心(400,260)，顺时针），显示"时间差 2h40m"标签（y=310）。其他元素保持。
- 步骤3：点击「下一步」→ 显示结论框（浅绿背景矩形），"?"变为"9:20"（绿色），显示"北京时间 9:20"文字。完成推导。
（教师可随时点击「上一步」回退复习）

- 标签"12:00"：坐标(600, 210)
- 标签"?"：坐标(200, 210)
- 标签"经度差 40°"：坐标(400, 180)
- 标签"时间差 2h40m"：坐标(400, 310)
- 标签"北京时间 9:20"：坐标(400, 365)

冲突检查：
- "120°E"(200,280) 与 "160°E"(600,280)：间距400px → 无冲突
- "120°E"(200,280) 与 "?"(200,210)：间距70px → 无冲突
- "160°E"(600,280) 与 "12:00"(600,210)：间距70px → 无冲突
- "经度差 40°"(400,180) 与 "?"(200,210)：间距≈206px → 无冲突
- "经度差 40°"(400,180) 与 "12:00"(600,210)：间距≈206px → 无冲突
- "时间差 2h40m"(400,310) 与 轴线(250)：间距60px → 无冲突
- "北京时间 9:20"(400,365) 与 "时间差 2h40m"(400,310)：间距55px → 无冲突
- 所有标签与控件栏(y=450)最小间距：365到450=85px → 无冲突

结论：所有标签间距均≥55px，无重叠冲突。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于(280,460)，宽80px，高30px，灰色背景，点击回退到前一状态
  - 「下一步」按钮：位于(440,460)，宽80px，高30px，蓝色背景#1565c0，点击进入下一状态
  - 步骤指示器：位于(380,465)，显示"步骤 X/4"
- 教师操作流程：
  1. 初始状态展示已知条件（160°E为12:00，120°E待求）
  2. 点击「下一步」展示经度差40°，讲解经度计算
  3. 点击「下一步」展示时间差2h40m，讲解15°/h换算
  4. 点击「下一步」展示北京时间9:20，讲解西侧时间减法
  5. 可随时点击「上一步」回退复习关键步骤

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript。理由：本场景为简单几何图形（线段、箭头、文字），无需复杂库；原生实现轻量、加载快、易维护。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [800 × 500 画布]
  +--------------------------------------------------+
  |           太阳直射点与时间计算 (y=35)            |
  |                                                  |
  |                    经度差 40° (y=180)            |
  |              ←────────────────────→ (y=190)      |
  |         ? (y=210)                    12:00       |
  |         │                            │           |
  |    ─────┴────────────────────────────┴───── (y=250 轴线)
  |        120°E                      160°E          |
  |         (y=280)                    (y=280)       |
  |                                                  |
  |                   时间差 2h40m (y=310)           |
  |                                                  |
  |              ┌─────────────────┐                 |
  |              │ 北京时间 9:20   │ (y=340-380)     |
  |              └─────────────────┘                 |
  |                                                  |
  |              [◀上一步]  步骤X/4  [下一步▶]       |
  |                 (y=460)                          |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-3），数组存储每步需显示的元素ID列表
  2. 坐标计算：经度轴从150到650共500px，对应40°经度差，每度12.5px
  3. 动画曲线：元素淡入使用 CSS transition opacity 0.3s ease
  4. 事件绑定：按钮点击事件绑定到 updateScene() 函数，根据 currentState 切换显示
  5. 边界处理：步骤0时禁用「上一步」，步骤3时禁用「下一步」或改为「重播」
- ID 命名规范：所有交互元素 ID 必须以 scene2- 为前缀
  - scene2-title, scene2-axis, scene2-tick-120, scene2-tick-160
  - scene2-label-120E, scene2-label-160E, scene2-time-120, scene2-time-160
  - scene2-arc-degree, scene2-label-degree, scene2-arc-time, scene2-label-time
  - scene2-result-box, scene2-result-text
  - scene2-btn-prev, scene2-btn-next, scene2-step-indicator
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
