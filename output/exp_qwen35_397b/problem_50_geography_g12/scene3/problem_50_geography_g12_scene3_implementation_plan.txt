[图示主题与整合说明]
- 本图示主题：线速度与正午太阳高度角对比

[分步序列]
- 初始状态（状态 0）：显示地球示意图，三点 A/B/C 及纬度标签，赤道线，无柱状图
- 状态 1（点击"线速度对比"）：
  - 显示线速度柱状图（三根柱子）
  - A 柱最高（180px，代表最大线速度）
  - B 柱和 C 柱等高（60px，代表高纬度线速度小且相等）
  - 显示结论"线速度：A > B = C"
  - A 点高亮蓝色#1565c0，A 柱填充蓝色
- 状态 2（点击"正午太阳高度"）：
  - 显示正午太阳高度柱状图（三根柱子）
  - A 柱最高（210px，90°，直射点）
  - C 柱中等（120px，30°）
  - B 柱最低（30px，0°，极夜）
  - 显示结论"正午太阳高度：A(90°) > C(30°) > B(0°)"
  - 各柱按 A 蓝/B 红/C 绿高亮

[标签冲突检查]
- 标签"A"：坐标 (210,240)
- 标签"B"：坐标 (210,360)
- 标签"C"：坐标 (210,120)
- "A"与"B"间距：120px → 无冲突
- "A"与"C"间距：120px → 无冲突
- "B"与"C"间距：240px → 无冲突
- 纬度标签"15°N"(215,250) 与"A"(210,240) 间距：约 14px → 接近但可接受（不同行）
- 纬度标签"75°S"(215,370) 与"B"(210,360) 间距：约 14px → 接近但可接受
- 纬度标签"75°N"(215,130) 与"C"(210,120) 间距：约 14px → 接近但可接受
- 柱状图标签与柱顶间距：15px → 安全
- 结论标签与柱底间距：20px → 安全
- 解决方案：所有标签间距均≥12px，无重叠风险

[交互方案]
- 交互类型：多状态切换（2 个状态按钮）
- 控件说明：
  - 按钮 1"线速度对比"：位于 (320,450)，点击显示线速度柱状图及结论
  - 按钮 2"正午太阳高度"：位于 (480,450)，点击显示正午太阳高度柱状图及结论
- 教师操作流程：
  1. 初始展示地球示意图，讲解三点纬度位置
  2. 点击"线速度对比"，讲解纬度越低线速度越大，B/C 同纬度故相等
  3. 点击"正午太阳高度"，讲解直射点高度角最大，极夜地区为 0°
  4. 可反复切换对比两种规律

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |   [地球圆]              [柱状图区]               |
  |     C ● 75°N            柱 A  柱 B  柱 C         |
  |       |                                          |
  |     A ● 15°N            ███  ███  ███           |
  |       |                   |    |    |            |
  |     B ● 75°S              |    |    |            |
  |                          结论标签                |
  |                                                  |
  |          [线速度对比]  [正午太阳高度]            |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentState 跟踪当前状态（0/1/2）
  2. 柱状图动态显示/隐藏：通过 display 属性或 opacity 控制
  3. 高亮同步：状态切换时同步更新地球图上点的高亮和柱状图颜色
  4. 事件绑定：按钮点击事件切换状态，更新所有相关元素
- ID 命名规范：所有元素 ID 以 scene3- 为前缀
  - scene3-earth-circle, scene3-point-a, scene3-point-b, scene3-point-c
  - scene3-vel-bar-a, scene3-vel-bar-b, scene3-vel-bar-c
  - scene3-height-bar-a, scene3-height-bar-b, scene3-height-bar-c
  - scene3-btn-velocity, scene3-btn-height
  - scene3-conclusion-velocity, scene3-conclusion-height
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中
