[图示主题与整合说明]
- 本图示主题：时间计算与日期范围示意图
- 整合内容：地方时计算、北京时间推算、日界线位置、新一天范围占比
- 教学价值：教师可通过分步动画展示从已知条件（0°经线地方时）到北京时间推算的完整逻辑链，帮助学生理解地方时计算原理和日期范围判定方法。绿色扇形直观展示新一天占全球的 3/4，强化空间概念。

- 步骤 1：点击「下一步」→ 显示 0°经线标签"0°(0 时)"，标注 0°经线地方时为 0 时/24 时
- 步骤 2：点击「下一步」→ 显示 90°E 经线和 120°E 经线，标注"90°E(12 时)"和"120°E(20 时)"，展示地方时推算过程
- 步骤 3：点击「下一步」→ 显示 180°经线（蓝色加粗）和标签"180°(日界线)"，标注两条日界线位置
- 步骤 4：点击「下一步」→ 显示新一天扇形区域（绿色 20% 透明度），显示"新一天范围：3/4"和北京时间框"北京时间：6 月 22 日 20:00"

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 内底部左侧 (x=320, y=455)，返回上一状态
  - 「下一步」按钮：位于 SVG 内底部右侧 (x=480, y=455)，进入下一状态
  - 状态指示器：位于两按钮之间 (x=400, y=460)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始状态展示地球和 0°经线，引导学生观察已知条件
  2. 点击「下一步」标注 0 时，讲解地方时起点
  3. 点击「下一步」显示 90°E 和 120°E，演示地方时计算（每 15°差 1 小时）
  4. 点击「下一步」显示日界线，讲解日期变更规则
  5. 点击「下一步」高亮新一天范围，总结占比 3/4 和北京时间

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +------------------------------------------+
  |           新一天范围：3/4                |
  |                                          |
  |         (地球轮廓圆 r=180)               |
  |      0°←────●────→180°                  |
  |         ╱    │    ╲                     |
  |       45°   90°   135°                  |
  |         ╲    │    ╱                     |
  |          120°E                          |
  |                                          |
  |    [北京时间框]                          |
  |                                          |
  |         [◀上一步] 步骤 X/5 [下一步▶]     |
  +------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-4），数组存储每步显示的元素 ID 列表
  2. 坐标计算：经线端点用极坐标转换 (x = cx + r*cos(θ), y = cy + r*sin(θ))，θ从 0°经线（左侧）开始逆时针计算
  3. 扇形路径：使用 SVG path 的 A 命令绘制圆弧，从 0°经线端点逆时针到 180°经线端点
  4. 事件绑定：按钮点击事件切换状态，更新元素 display 属性
  5. 动画过渡：使用 CSS transition 实现淡入效果（opacity 0→1，duration 0.3s）
- ID 命名规范：所有元素 ID 以 scene2- 为前缀（如 scene2-circle-earth, scene2-line-0deg, scene2-label-beijing-time）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
