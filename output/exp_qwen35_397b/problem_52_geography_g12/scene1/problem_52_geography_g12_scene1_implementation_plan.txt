[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 按钮"◀ 上一步"：位置 (320,455)，宽 100px，高 35px，背景 #1976d2，文字白色
  - 按钮"下一步 ▶"：位置 (480,455)，宽 100px，高 35px，背景 #1976d2，文字白色
  - 步骤指示器：位置 (430,455)，显示"步骤 X/4"，文字 #666666
- 教师操作流程：
  1. 初始展示基础图，让学生观察两半球视图差异
  2. 点击"下一步"高亮 20°W，讲解经度判读方法（A 点与 20°W 相对→160°E）
  3. 点击"下一步"显示南半球阴影，引导学生分析南极圈极昼现象
  4. 点击"下一步"显示日期推导文字，建立阴影位置与日期的逻辑关系
  5. 点击"下一步"显示北半球阴影，对比南北半球昼夜差异

[技术实现]
- JS 库选择及原因：原生 SVG（适合绘制精确的几何图形、弧线、填充区域，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |              [步骤说明区 y=30-90]                |
  |                                                  |
  |    [左图：南半球]          [右图：北半球]        |
  |       圆心 (200,280)         圆心 (600,280)      |
  |       r=100 圆形             r=100 半圆          |
  |                                                  |
  |              [图 1-9 标签 y=410]                 |
  |                                                  |
  |    [◀ 上一步]  步骤 X/4  [下一步 ▶]              |
  |     (320,455)   (430,455)   (480,455)            |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-4) 跟踪当前步骤，每一步对应一组可见元素
  2. 坐标计算：经线用 SVG path 的 arc 命令绘制，南极点/北极点为辐射中心
  3. 阴影填充：用 SVG pattern 定义斜线，step2/step4 时显示对应阴影组
  4. 事件绑定：按钮点击事件切换 currentStep，调用 updateDisplay() 更新各元素 visibility
  5. 动画效果：20°W 经线高亮用 CSS transition 实现颜色渐变
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀（如 scene1-left-circle, scene1-20w-line-left, scene1-btn-next）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
