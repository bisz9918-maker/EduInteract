[分步序列]
- 初始状态（步骤 0）：显示南北半球俯视图、经线网格、20°W 经线、甲、乙、C 三点位置，甲点旁标注"22 日 16 时"
- 步骤 1：点击「下一步」→ 显示甲、乙经度标注（甲：110°W，乙：20°E），用蓝色虚线弧线连接甲乙，标注"经度差 90°"
- 步骤 2：点击「下一步」→ 计算框显示"时差 = 经度差 ÷ 15°/小时 = 90° ÷ 15° = 6 小时"，然后显示"乙地时间 = 甲地时间 + 时差 = 16 时 + 6 时 = 22 时"，结果用蓝色高亮
- 步骤 3：点击「下一步」→ C 点所在纬线的昼弧用蓝色高亮显示，夜弧用灰色填充，计算框显示"昼长 = 昼弧所跨经度 ÷ 15°/小时 = 180° ÷ 15° = 12 小时"，结果用蓝色高亮

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 内底部左侧 (500,450)，点击返回上一状态
  - 「下一步」按钮：位于 SVG 内底部右侧 (600,450)，点击进入下一状态
  - 步骤指示：位于底部中央 (400,455)，显示当前步骤"步骤 X/4"
- 教师操作流程：
  1. 初始状态展示题目基础条件（甲乙 C 三点位置）
  2. 点击「下一步」展示经度差计算，讲解经度读取方法
  3. 点击「下一步」展示时差计算和地方时推导，讲解"东加西减"原则
  4. 点击「下一步」展示昼弧和昼长计算，讲解昼弧与昼长的关系

[技术实现]
- JS 库选择：原生 SVG（几何图形简单，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |    [南半球]          [北半球]                    |
  |     圆形              圆形                       |
  |    甲●  乙●          乙●  C●                    |
  |                                                  |
  |              经度差标注                          |
  |                                                  |
  +--------------------------------------------------+
  |  [计算框 600×110]                                |
  |  计算公式/结果逐步显示                           |
  +--------------------------------------------------+
  |  [上一步] [下一步]  步骤 X/4                     |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用 currentState 变量 (0-3) 跟踪当前步骤
  2. 坐标计算：经线用 SVG path 的 arc 命令绘制，从圆心辐射
  3. 动画曲线：元素淡入用 CSS transition opacity 0.3s ease
  4. 事件绑定：按钮点击事件绑定到 stepForward/stepBackward 函数
  5. 元素显示/隐藏：用 display:none 或 opacity:0 控制各步骤元素
- ID 命名规范：所有交互元素 ID 必须以 scene2- 为前缀（如 scene2-north-circle, scene2-point-jia, scene2-btn-next）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中
