[视觉元素清单]
- 四棱锥框架：6 条棱线（PA、PB、PC 实线黑色，PD 虚线灰色；AB、BC 实线黑色，CD、DA 虚线灰色）
- 底面对角线 AC：蓝色虚线 #1565c0，1px
- 线段 MN：红色实线 #c62828，2.5px 加粗
- 点 M、N：红色实心圆 r=4
- 平面 PAD：三角形区域，填充 #1565c0 透明度 15%（步骤 2 显示）
- 平面 PAC：三角形区域，填充 #2e7d32 透明度 15%（步骤 1 显示）
- 顶点标签：P、A、B、C、D 黑色 14px
- 点标签：M、N 黑色 14px
- 比例标记："1:4" 黑色加粗 16px
- 平行符号："∥" 黑色 18px（步骤 3 显示）
- 结论文本："NC:NP = 1:4" 黑色加粗 16px（步骤 5 显示）

[分步序列]
- 初始状态（步骤 0）：显示四棱锥 P-ABCD 完整框架（所有棱线、底边），对角线 AC（蓝色虚线），点 M 在 AC 上、点 N 在 PC 上，线段 MN（红色加粗），所有顶点标签 P、A、B、C、D 和点标签 M、N
- 步骤 1：点击「下一步」→ 高亮平面 PAC（浅绿色半透明填充三角形 P-A-C），其他元素保持
- 步骤 2：点击「下一步」→ 高亮平面 PAD（浅蓝色半透明填充三角形 P-A-D），显示文字提示"MN∥平面 PAD"
- 步骤 3：点击「下一步」→ 在 PA 与 MN 之间显示平行符号"∥"，表示 MN∥PA（线面平行推出线线平行）
- 步骤 4：点击「下一步」→ 在 AC 下方显示比例标记"CM:MA = 1:4"，用分段小刻度标记 AC 被 M 分为 1:4
- 步骤 5：点击「下一步」→ 在右侧显示结论"NC:NP = 1:4"，高亮线段 PC 上 N 点分割的比例关系

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于 SVG 底部左侧 (x=280, y=455)，点击后退到前一状态
  - 「下一步 ▶」按钮：位于 SVG 底部右侧 (x=480, y=455)，点击前进到下一状态
  - 步骤指示器：位于两按钮之间 (x=380~440, y=460)，显示"步骤 X/6"
- 教师操作流程：
  1. 初始展示四棱锥结构，让学生观察点 M、N 的位置
  2. 点击「下一步」高亮平面 PAC，引导学生关注截面
  3. 点击「下一步」高亮平面 PAD，说明 MN 与该平面平行
  4. 点击「下一步」显示平行符号，推导 MN∥PA
  5. 点击「下一步」标注已知比例 CM:MA=1:4
  6. 点击「下一步」得出结论 NC:NP=1:4，完成证明

[技术实现]
- JS 库选择：原生 SVG（立体几何图形绘制简单，无需复杂 3D 库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +------------------------------------------+
  |              P(400,70)                   |
  |             / | \  \                     |
  |            /  |  \  \                    |
  |         A /___|___C_\ N                  |
  |          /    |M  /  \                   |
  |         /_____|___/____\                 |
  |        D      B                            |
  |                                          |
  |         [◀ 上一步] 步骤 1/6 [下一步 ▶]    |
  +------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-5) 跟踪当前步骤，数组 steps 存储每步需显示的元素 ID
  2. 坐标计算：M 点用定比分点公式 M = (4*C + A)/5，N 点同理 N = (4*C + P)/5
  3. 平面填充：用 <polygon> 元素，fill-opacity=0.15
  4. 虚线绘制：stroke-dasharray="5,5"
  5. 事件绑定：按钮点击事件切换 currentStep，调用 updateDisplay() 刷新可见性
- ID 命名规范：所有元素 ID 以 scene1- 为前缀，如 scene1-pyramid-pa、scene1-point-m、scene1-btn-next
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
