[视觉元素清单]
- △PAC 三角形：顶点 P(400,80)、A(180,380)、C(620,380)，边框 #000000 实线 2px，无填充
- 点 M：实心圆 #000000，直径 8px，初始位置在 AC 上距 A 点 88px 处（CM:MA=1:4 时）
- 点 N：实心圆 #000000，直径 8px，位置由 MN∥PA 条件自动计算
- 线段 MN：#c62828 红色实线 2.5px，连接 M 和 N
- 平行标记：两组双箭头 #1565c0，分别位于 PA 中点和 MN 中点附近，表示平行关系
- 顶点标签：P、A、C 使用黑色 14px 字体，放在对应顶点外侧
- 动点标签：M、N 使用黑色 14px 字体，M 在点下方，N 在点右上方
- 比例显示框：背景 #f5f5f5，边框 #888888 1px，显示"CM:MA = 1 : 4"和"NC:NP = 1 : 4"
- 结论框：背景 #f5f5f5，边框 #888888 1px，显示"NC:NP = CM:MA"
- 滑块：轨道 #cccccc，手柄 #1976d2，范围对应 CM:MA 从 1:1 到 1:9

[分步序列]
本场景采用连续拖拽滑块交互，无分步序列，状态连续变化：
- 初始状态：CM:MA = 1:4，M 在 AC 上距 A 点 1/5 处，N 在 PC 上对应位置，MN∥PA，显示比例值
- 拖动过程：用户拖动滑块或点 M，M 沿 AC 移动，N 自动沿 PC 移动保持 MN∥PA，实时显示当前 CM:MA 和 NC:NP 比值
- 任意状态：无论滑块在何位置，始终满足 NC:NP = CM:MA，结论框恒成立

[交互方案]
- 交互类型：连续拖拽滑块 + 实时反馈
- 控件说明：
  1. 水平滑块：位于 SVG 底部 y=500~515，范围对应 CM:MA 比值从 1:1 到 1:9
  2. 滑块手柄：圆形，可左右拖动，拖动时实时更新 M、N 位置
  3. 比例显示框：左侧显示当前 CM:MA 和 NC:NP 的数值比
  4. 结论框：右侧显示"NC:NP = CM:MA"恒等关系
- 教师操作流程：
  1. 初始状态展示 CM:MA=1:4 时的图形，讲解题目条件
  2. 拖动滑块改变比值，引导学生观察 N 点如何自动调整
  3. 强调无论比值如何变化，MN 始终平行于 PA，且 NC:NP 始终等于 CM:MA
  4. 可拖动到极端位置（1:1 或 1:9）验证规律的普适性

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript，无需额外库
  - 原因：几何图形简单，仅需基础 SVG 绘制和事件处理，原生实现轻量高效
- 画布尺寸：800 × 500 px（含底部滑块区域，滑块可略微超出 500 到 530）
- 布局草图：
  ```
  [图示区 800×500]
  +------------------------------------------+
  |              P(400,80)                   |
  |               /\\                        |
  |              /  \\                       |
  |             /    \\                      |
  |            /      \\                     |
  |           /   N    \\                    |
  |          /    ●     \\                   |
  |         /     |      \\                  |
  |        /      |MN     \\                 |
  |       /       |       \\                |
  |      /        ●M       \\               |
  |     A(180,380)----------C(620,380)      |
  |                                          |
  |  [比例框] CM:MA=1:4    [结论框] 结论    |
  |  NC:NP=1:4           NC:NP=CM:MA        |
  |                                          |
  |  [========●========] 滑块轨道           |
  |         CM:MA 比值                       |
  +------------------------------------------+
  ```
- 关键实现要点：
  1. 坐标计算：
     - M 点坐标：Mx = Ax + (Cx-Ax) * (MA/AC) = 180 + 440 * (ratio/(1+ratio))
       其中 ratio = MA/CM，滑块值 1~9 对应 CM:MA = 1:1 到 1:9
     - N 点坐标：由 MN∥PA，利用相似三角形，PN/PC = CM/CA
       N = P + (C-P) * (PN/PC) = P + (C-P) * (CM/CA)
     - 简化：设 t = CM/CA = 1/(1+ratio)，则 N = P + (C-P) * t
  2. 事件绑定：
     - 滑块 mousedown/touchstart：开始拖动
     - document mousemove/touchmove：更新滑块位置和 M、N 坐标
     - document mouseup/touchend：结束拖动
  3. 平行标记绘制：在 PA 和 MN 中点附近各画两条短平行线段
  4. 比例格式化：将小数比转换为整数比显示（如 0.25 显示为 1:4）
- ID 命名规范：
  - 所有元素 ID 以 scene2- 为前缀
  - 如：scene2-tri-pac、scene2-point-m、scene2-point-n、scene2-seg-mn、scene2-slider、scene2-ratio-display、scene2-conclusion-box
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
