[图示主题与整合说明]
- 本图示主题：长方体表面展开与最短路径计算
- 整合内容：原始长方体结构、3 种展开方式、路径距离计算
- 教学价值：教师可逐步展示不同展开方式，让学生直观理解"表面最短路径=展开后直线距离"的原理，通过对比三种展开方式的结果，得出最优解。分步导航便于课堂节奏控制，每步可暂停讲解。

[分步序列]
步骤0（初始状态）：
- 显示左侧原始长方体线框图
- 标注点 A、C、D、F 及边长 AC=5、CD=3、DF=6
- 右侧展开图区显示"请选择展开方式"提示文字
- 底部计算式区空白

步骤1（展开前面 + 右侧面）：
- 左侧长方体保持显示
- 右侧显示展开图：前面矩形 (200×150) + 右侧面矩形 (150×150) 水平拼接
- 点 A 在左侧矩形左下角，点 F 在右侧矩形右边缘
- 红色路径线连接 A 到 F（直线）
- 显示直角三角形辅助线（虚线）
- 底部计算式：√[(5+3)² + 6²] = √(64+36) = √100 = 10 cm

步骤2（展开底面 + 右侧面）：
- 右侧更新展开图：底面矩形 (200×150) + 右侧面矩形 (150×150) 垂直拼接
- 点 A 在底面矩形左下角，点 F 在右侧面矩形右边缘
- 红色路径线连接 A 到 F
- 底部计算式：√[5² + (3+6)²] = √(25+81) = √106 ≈ 10.30 cm

步骤3（展开前面 + 顶面）：
- 右侧更新展开图：前面矩形 (200×150) + 顶面矩形 (200×100) 垂直拼接
- 点 A 在前面矩形左下角，点 F 需通过顶面到达
- 红色路径线连接 A 到 F
- 底部计算式：√[(5+6)² + 3²] = √(121+9) = √130 ≈ 11.40 cm

步骤4（结论）：
- 三种展开方式的结果并列显示
- 最短距离"10 cm"用绿色加粗高亮
- 显示结论文本："最短距离 = 10 cm（前面 + 右侧面展开）"

[标签冲突检查]
- 标签"A"：坐标 (45,340)
- 标签"C"：坐标 (195,340)
- 标签"D"：坐标 (255,360)
- 标签"F"：坐标 (258,220)
- 标注"AC=5"：坐标 (120,335)
- 标注"CD=3"：坐标 (215,345)
- 标注"DF=6"：坐标 (250,280)

冲突检查：
- "A"(45,340) 与 "AC=5"(120,335)：水平距离 75px → 无冲突
- "C"(195,340) 与 "AC=5"(120,335)：水平距离 75px → 无冲突
- "C"(195,340) 与 "CD=3"(215,345)：距离 √(20²+5²)≈20.6px → 临界，已留足间隙
- "D"(255,360) 与 "CD=3"(215,345)：距离 √(40²+15²)≈42.7px → 无冲突
- "F"(258,220) 与 "DF=6"(250,280)：垂直距离 60px → 无冲突
- 所有标签与长方体线框：标签均在外侧偏移 ≥15px → 无冲突

解决方案：所有标签已分散在不同方向，间距均≥20px，无重叠风险。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 按钮"◀ 上一步"：位置 (280,455)，尺寸 100×35，返回上一状态
  - 按钮"下一步 ▶"：位置 (420,455)，尺寸 100×35，进入下一状态
  - 步骤指示器：位置 (550,460)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始展示长方体，讲解题目条件（AC=5, CD=3, DF=6）
  2. 点击"下一步"展示第一种展开方式，讲解勾股定理应用
  3. 依次展示第二、三种展开方式，引导学生对比计算
  4. 最后一步高亮最短距离，总结结论

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  [长方体]           [展开图动态区]               |
  |   (60,120)          (320,80)                     |
  |   180×200           440×300                      |
  |                                                  |
  |                                                  |
  |                    [路径线/辅助线]               |
  |                                                  |
  |                                                  |
  |              [计算式文本区 y=400]                |
  |                                                  |
  |         [◀上一步]  [下一步▶]  [步骤 X/5]         |
  |           y=450    y=450      y=460              |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-4) 跟踪当前步骤，数组存储每步的视觉配置
  2. 坐标计算：展开图中矩形位置根据步骤动态计算，路径线端点坐标用勾股定理
  3. 动画曲线：步骤切换用 CSS transition (0.3s ease-out) 实现平滑过渡
  4. 事件绑定：按钮点击事件调用 updateScene() 函数更新 DOM 元素
  5. 边界检查：第一步禁用"上一步"，最后一步禁用"下一步"
- ID 命名规范：所有元素 ID 以 scene1- 为前缀
  - scene1-cuboid（长方体组）
  - scene1-point-a, scene1-point-c, scene1-point-d, scene1-point-f
  - scene1-label-ac, scene1-label-cd, scene1-label-df
  - scene1-unfold-group（展开图组）
  - scene1-path-line（路径线）
  - scene1-calc-text（计算式文本）
  - scene1-btn-prev, scene1-btn-next（按钮）
  - scene1-step-indicator（步骤指示器）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
