    3. 利用抛物线定义和几何关系推导关键长度和角度

    本图示展示题目的完整几何配置。教师应引导学生按以下步骤观察：

    1. 确认抛物线的基本元素：顶点 O 在原点，焦点 F 在 x 轴正半轴，准线为 x = -p/2

    **关键公式：**

    - 抛物线定义：点 A 到焦点 F 的距离 = 点 A 到准线的距离
    - 若 A 的坐标为 (x₀, y₀)，则 AF = x₀ + p/2
    - 直线 AF 的斜率：k = tan(60°) = √3

    **推导过程：**

    1. 设抛物线 y² = 2px 的焦点 F 坐标为 (p/2, 0)

    2. 因为∠AFx = 60°，直线 AF 的斜率为 √3，设 A 坐标为 (x₀, y₀)

    3. 由斜率公式：y₀ / (x₀ - p/2) = √3

    4. 又 A 在抛物线上：y₀² = 2px₀

    5. 联立解得：x₀ = 3p/2，y₀ = √3·p

    6. 由抛物线定义：AF = x₀ + p/2 = 3p/2 + p/2 = 2p

    7. 因为 FB = p/2（圆半径），所以 AB = AF - FB = 2p - p/2 = 3p/2

    8. 点 N 是 A 在 y 轴上的射影，所以 N 坐标为 (0, y₀) = (0, √3·p)

    9. 在三角形 ONB 中：
       - ON = y₀ = √3·p
       - OB 可通过坐标计算
       - NB 可通过坐标计算

    10. 通过几何关系或向量法可得：∠ONB = 30°

    **课堂讲解建议：**

    - 先让学生观察图形，猜测∠ONB 的大小
    - 引导学生利用抛物线定义和 60° 角建立方程
    - 通过坐标计算验证猜想
    - 总结：本题关键在于利用抛物线定义将几何条件转化为代数关系
