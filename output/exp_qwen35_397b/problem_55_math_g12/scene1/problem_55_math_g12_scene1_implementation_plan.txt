[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「◀上一步」按钮：位于 SVG 内底部左侧 (x=280, y=455)，点击回退到前一状态
  - 「下一步▶」按钮：位于 SVG 内底部右侧 (x=440, y=455)，点击进入下一状态
  - 步骤指示器：位于两按钮之间 (x=360, y=460)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始展示坐标系和抛物线，介绍抛物线基本形式 y²=2px
  2. 点击「下一步」展示焦点和准线，讲解抛物线定义（点到焦点距离=到准线距离）
  3. 点击「下一步」展示点 A 和 60°角，说明已知条件∠AFx=60°
  4. 点击「下一步」展示圆 F 和点 B，解释 B 是圆与 AF 交点，FB=p/2
  5. 点击「下一步」展示点 N 和线段 ON、NB，说明 N 是 A 在 y 轴垂足
  6. 点击「下一步」高亮∠ONB，引导学生思考如何求解此角

[技术实现]
- JS 库选择：原生 SVG（适合几何图形绘制，精确控制坐标，无需额外库）
- 画布尺寸：800 × 500 px（固定画布）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                    y(255,40)                     |
  |                      |                           |
  |                      |                           |
  |         N(232,120)   A(562,110)                 |
  |            o---------o                          |
  |            |        / |                          |
  |            |      /   |                          |
  |            |    B     |                          |
  |            |  o       |                          |
  |            |/         |                          |
  |  准线      O----------F----------x(705,255)      |
  |   |      (235,270)  (400,268)                   |
  |   |                                             |
  |                                                 |
  |              [◀上一步] 步骤 X/5 [下一步▶]        |
  |               (280,455)        (440,455)        |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量 (0-5)，数组 steps 存储每步可见元素 ID 列表
  2. 坐标计算：所有坐标硬编码为像素值，确保布局精确
  3. 抛物线绘制：使用 SVG path，参数方程 x=t²/(2p), y=t，t 从 -300 到 300
  4. 角度弧绘制：使用 SVG path arc 命令，∠AFx 从 0°到 60°，∠ONB 根据向量计算起止角
  5. 事件绑定：按钮点击事件切换 currentState，调用 render() 更新可见性
  6. 动画效果：步骤 5 的∠ONB 弧使用 CSS animation 实现脉冲效果（opacity 0.5→1 循环）
- ID 命名规范：所有元素 ID 以 scene1- 为前缀，如 scene1-axis-x, scene1-parabola, scene1-point-F, scene1-angle-ONB
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
