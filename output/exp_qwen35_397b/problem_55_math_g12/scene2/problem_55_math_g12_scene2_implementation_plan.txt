[分步序列]
步骤 0（初始状态）：
- 显示：坐标轴、抛物线、圆（虚线）、点 O/F/A/B/N
- 高亮：三角形 OFA 边框（蓝色 #1565c0）
- 标注：OF = p/2（黑色）、∠AFx = 60°（蓝色）
- 隐藏：三角形 ONB、其他长度标注、结论文本框

步骤 1（点击「下一步」）：
- 新增：线段 AF 长度标注 "p"（蓝色），显示抛物线定义说明
- 视觉变化：AF 线段加粗，出现文字说明「由抛物线定义：AF = 点 A 到准线距离 = p」
- 高亮：三角形 OFA 保持蓝色

步骤 2（点击「下一步」）：
- 新增：FB = p/2 标注（黑色，已知）、AB = p/2 标注（蓝色，推导）
- 视觉变化：FB 段用不同颜色区分，出现说明「FB = 圆半径 = p/2，故 AB = AF - FB = p/2」
- 高亮：线段 FB 和 AB 分别高亮

步骤 3（点击「下一步」）：
- 新增：A 点坐标标注「A(3p/2, p√3)」，∠OFA = 120°标注（蓝色）
- 视觉变化：显示辅助线 AN（虚线），标注 ON = p√3，OF = p/2
- 说明：「由∠AFx=60°，得∠OFA=120°，利用三角函数计算 A 点坐标」

步骤 4（点击「下一步」）：
- 新增：三角形 ONB 边框（绿色 #2e7d32），线段 ON、NB、OB 高亮
- 标注：ON = p√3（黑色）、NB 长度关系
- 说明：「在△ONB 中，分析边长关系」

步骤 5（点击「下一步」）：
- 新增：∠ONB = 30°标注（绿色加粗），结论文本框显示
- 结论文本框内容：「∵ ON = p√3, OB = p, ∠NOB = 90°
∴ tan(∠ONB) = OB/ON = p/(p√3) = 1/√3
∴ ∠ONB = 30°」
- 视觉变化：∠ONB 角度弧加粗显示（绿色）

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于 SVG 内底部左侧 (60,460)，返回上一状态
  - 「下一步 ▶」按钮：位于 SVG 内底部右侧 (200,460)，进入下一状态
  - 步骤指示器：位于两按钮之间 (140,470)，显示「步骤 X/5」
- 教师操作流程：
  1. 初始展示题目基础图形（步骤 0）
  2. 点击「下一步」逐步展示推导过程
  3. 每步暂停讲解当前结论
  4. 可随时点击「上一步」回顾之前步骤
  5. 最终步骤展示完整结论

[技术实现]
- JS 库选择：原生 SVG（几何图形精确绘制）+ 原生 JavaScript（状态管理）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |         y                                        |
  |         ↑                                        |
  |    N    |    A                                   |
  |    ●----|----●                                   |
  |    | \  |  / |                                   |
  |    |  \ | /  |                                   |
  |    |   \|/   |                                   |
  | O ●----F-----● B                                 |
  |    |   / \   |                                   |
  |    |  /   \  |                                   |
  |    | /     \ |                                   |
  |    |/       \|                                   |
  |----+---------+------------------→ x              |
  |                                                  |
  |                              [结论框]            |
  |                                                  |
  |  [◀上一步]  步骤 X/5  [下一步▶]                  |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量 (0-5)，steps 数组存储每步配置
  2. 坐标计算：所有点坐标预先计算好，硬编码在配置中
  3. 动画曲线：使用 CSS transition 实现元素淡入淡出 (opacity 0→1)
  4. 事件绑定：按钮点击事件绑定到 updateScene() 函数
  5. 元素显示控制：每步通过 display:none/block 控制元素可见性
- ID 命名规范：所有元素 ID 以 scene2- 为前缀
  - scene2-axis-x, scene2-axis-y, scene2-parabola, scene2-circle
  - scene2-point-o, scene2-point-f, scene2-point-a, scene2-point-b, scene2-point-n
  - scene2-tri-ofa, scene2-tri-onb
  - scene2-label-o, scene2-label-f, scene2-label-a, scene2-label-b, scene2-label-n
  - scene2-ang-60, scene2-ang-120, scene2-ang-30
  - scene2-btn-prev, scene2-btn-next, scene2-step-indicator
  - scene2-conclusion-box
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
