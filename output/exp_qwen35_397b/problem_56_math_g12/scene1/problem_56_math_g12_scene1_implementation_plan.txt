[图示主题与整合说明]
- 本图示主题：圆与正六边形嵌套构造的几何关系及无限级数求和

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于SVG内左下角(70,460)，点击回退到前一状态
  - 「下一步」按钮：位于SVG内右下角(650,460)，点击进入下一状态
  - 步骤指示器：显示"步骤 X/5"，位于底部中央(360,460)
- 教师操作流程：
  1. 初始状态展示题目基础图形（外圆+六边形）
  2. 点击「下一步」揭示边心距与30°角，讲解正六边形可分割为6个等边三角形
  3. 点击「下一步」显示内切圆，讲解R₁ = R₀ × cos(30°) = R₀ × √3/2
  4. 点击「下一步」展示嵌套继续，说明规律无限重复
  5. 点击「下一步」显示递推公式，引导学生得出等比数列求和

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |                    圆0                           |
  |              ┌───────────┐                       |
  |           ╱│  六边形0   │╲                       |
  |         ╱  │  ┌─────┐  │  ╲                     |
  |        |   │  │圆1  │  │   |                    |
  |        |   │  │┌───┐│  │   |  R₀=1 →           |
  |        |   │  ││圆2││  │   |                    |
  |         ╲  │  └─────┘  │  ╱                     |
  |           ╲│  六边形1  │╱                       |

  |                    30°标注                       |

  |                              Rₙ₊₁ = Rₙ × √3/2   |
  |                                                  |
  |  [◀上一步]              步骤X/5            [下一步▶] |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-4) 跟踪当前步骤，数组存储每步可见元素ID列表
  2. 坐标计算：正六边形顶点用极坐标转换 (x = cx + r×cosθ, y = cy + r×sinθ)
  3. 动画曲线：元素淡入用 CSS transition opacity 0.3s ease
  4. 事件绑定：按钮点击事件切换状态，更新可见性
  5. 元素显隐：用 display:none / display:block 或 opacity 控制
- ID 命名规范：所有元素ID以 scene1- 为前缀
  - scene1-circle0, scene1-circle1, scene1-circle2
  - scene1-hex0, scene1-hex1
  - scene1-radius-r0, scene1-apothem-r1
  - scene1-angle-arc, scene1-right-angle
  - scene1-label-r0, scene1-label-r1, scene1-label-angle
  - scene1-formula, scene1-btn-prev, scene1-btn-next, scene1-step-indicator
- IIFE 隔离：所有JS代码包在 (function() { ... })() 中，避免全局污染
