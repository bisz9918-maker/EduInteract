- "P"与"β"：距离≈95px → 无冲突
- "α"与"β"：距离≈42px → 无冲突（间距>20px）

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 按钮"◀ 上一步"：位于 SVG 内底部左侧 (x=280, y=455)，宽 100px，高 30px
  - 按钮"下一步 ▶"：位于 SVG 内底部右侧 (x=420, y=455)，宽 100px，高 30px
  - 步骤指示器：位于两按钮之间 (x=390, y=460)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始加载显示平面 M 和点 O，教师介绍问题背景
  2. 点击"下一步"添加 PO，讲解垂线定义
  3. 点击"下一步"添加 PA 和α角，讲解斜线与垂线夹角
  4. 点击"下一步"添加 PB 和β角，讲解动直线概念
  5. 点击"下一步"显示圆锥面，讲解圆锥面形成
  6. 点击"下一步"高亮轨迹，讲解圆锥曲线判定
  7. 可随时点击"上一步"回退复习

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript。原因：本场景为静态几何图形分步显示，无需复杂动画或 3D 渲染，原生 SVG 足够且性能最优
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                    P(400,120)                    |
  |                     *                            |
  |                    /|\                           |
  |                   / | \                          |
  |                  /  |  \                         |
  |                 /α  |β  \                        |
  |                /    |    \                       |
  |               A-----O-----B                      |
  |              *      |      *                     |
  |             /      _|_      \                    |
  |            /______/___\______\                   |
  |           /   平面 M (平行四边形)   \            |
  |          /___________________________\           |
  |                                      M           |
  |                                                  |
  |                                                  |
  |              [◀上一步] 步骤 X/5 [下一步▶]         |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-5) 跟踪当前步骤，数组 stepElements 存储每步需显示的元素 ID
  2. 坐标计算：所有坐标预先计算好硬编码，确保布局精确
  3. 动画曲线：元素显示使用 CSS transition opacity 0.3s ease-in-out 实现淡入效果
  4. 事件绑定：按钮点击事件绑定到 updateStep() 函数，更新 currentStep 并调用 renderStep()
  5. 元素显隐：使用 SVG 元素的 display 属性控制显示/隐藏
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀
  - scene1-plane-m, scene1-point-o, scene1-point-p, scene1-point-a, scene1-point-b1
  - scene1-line-po, scene1-line-pa, scene1-line-pb1, scene1-line-pb2, scene1-line-pb3
  - scene1-cone-outline, scene1-trajectory
  - scene1-angle-alpha, scene1-angle-beta
  - scene1-label-p, scene1-label-o, scene1-label-a, scene1-label-b, scene1-label-m, scene1-label-alpha, scene1-label-beta
  - scene1-btn-prev, scene1-btn-next, scene1-step-indicator
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
