[图示主题与整合说明]
- 本图示主题：圆锥截线类型探究——不同α、β参数组合下 B 点轨迹的曲线类型变化
- 整合的内容：五种情况的轨迹展示（圆、直线、抛物线、椭圆、双曲线）、参数α和β的滑块调节、轨迹类型判断结论
- 教学价值：教师可通过拖动滑块直观展示α和β的相对大小关系如何决定轨迹类型，帮助学生发现临界条件α+β=90°。预设快捷按钮可快速切换到五种典型情况，配合讲解各选项的正确性。

[分步序列]
本场景为连续交互模式，无固定步骤，但有初始状态和交互响应：

- 初始状态（α=30°、β=45°）：
  - 显示平面 M、圆锥轮廓、点 P/O/A/B
  - 轨迹显示为椭圆（绿色#2e7d32）
  - α滑块值 30°，β滑块值 45°
  - α+β显示"75° < 90°"
  - 轨迹类型显示"椭圆"

- 交互响应 1（拖动α滑块增大）：
  - 当α增大时，PB 线绕 PA 旋转
  - B 点位置实时更新
  - α+β值更新，轨迹类型可能变化

- 交互响应 2（拖动β滑块）：
  - β变化时，圆锥张角变化
  - 轨迹曲线形状连续变化
  - 当α+β=90°时，轨迹变为抛物线（蓝色），临界线高亮

- 交互响应 3（点击快捷按钮）：
  - 按钮①：设置α=0°,β=90°→ 轨迹为圆（绿色）
  - 按钮②：设置α=30°,β=90°→ 轨迹为直线（紫色）
  - 按钮③：设置α=30°,β=60°→ 轨迹为抛物线（蓝色），α+β=90°高亮
  - 按钮④：设置α=45°,β=60°→ 轨迹为椭圆（绿色），α+β=105°>90°
  - 按钮⑤：设置α=20°,β=40°→ 轨迹为双曲线（红色），α+β=60°<90°

[交互方案]
- 交互类型：连续拖拽滑块 + 快捷按钮切换
- 控件说明：
  - α滑块：范围 0°~60°，初始 30°，步长 1°
  - β滑块：范围 30°~90°，初始 45°，步长 1°
  - 快捷按钮 5 个：分别对应题目中的五个选项条件
  - 参数显示：实时显示α、β、α+β的值
  - 类型显示：根据α+β与 90°的关系显示轨迹类型
- 教师操作流程：
  1. 初始状态展示椭圆轨迹，讲解α=30°、β=45°、α+β=75°<90°的条件
  2. 拖动α滑块逐渐增大，观察α+β接近 90°时轨迹的变化
  3. 当α+β=90°时，轨迹变为抛物线，临界线高亮，强调这是临界条件
  4. 继续增大α，α+β>90°，轨迹变为双曲线
  5. 点击快捷按钮快速切换五种情况，对比不同轨迹类型
  6. 引导学生总结：α+β=90°是抛物线的临界条件

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形相对简单，无需复杂 3D 库；原生 SVG 可精确控制坐标和样式；交互逻辑简单，原生 JS 足够
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  [左侧三维视图区 450×400]  |  [右侧控制区 300×400] |
  |                            |                      |
  |     P                      |   α滑块 [====] 30°   |
  |    / \                     |   β滑块 [====] 45°   |
  |   /   \                    |                      |
  |  A-----O-----B             |   α+β = 75° < 90°    |
  |   \   / \   /              |   轨迹类型：椭圆     |
  |    \ /   \ /               |                      |
  |     M (平面)               |  [①] [②] [③]        |
  |                            |  [④] [⑤]             |
  |                            |                      |
  +--------------------------------------------------+
  [控件栏在 SVG 内底部，本场景滑块和按钮在右侧控制区]
  ```
- 关键实现要点：
  1. 状态管理：维护当前α、β值，计算α+β并判断轨迹类型
  2. 轨迹类型判断逻辑：
     - α=0°且β=90° → 圆
     - α≠0°且β=90° → 直线
     - α+β=90° → 抛物线
     - α+β>90° → 椭圆
     - α+β<90° → 双曲线
  3. 轨迹曲线绘制：使用 SVG path，根据类型生成不同曲线
     - 圆：以 O 为圆心的圆弧
     - 椭圆：以 O 为中心的椭圆弧
     - 抛物线：开口向上的抛物线段
     - 双曲线：双曲线的一支
     - 直线：过某点的直线段
  4. 事件绑定：滑块的 input 事件实时更新，按钮的 click 事件设置参数
  5. 动画过渡：轨迹变化时使用 200ms 过渡效果
- ID 命名规范：所有交互元素 ID 必须以 scene2- 为前缀
  - scene2-plane-m, scene2-point-p, scene2-point-o, scene2-point-a, scene2-point-b
  - scene2-line-po, scene2-line-pa, scene2-line-pb
  - scene2-trace-curve, scene2-angle-alpha, scene2-angle-beta
  - scene2-slider-alpha, scene2-slider-beta
  - scene2-display-alpha, scene2-display-beta, scene2-display-sum
  - scene2-display-type, scene2-btn-1, scene2-btn-2, scene2-btn-3, scene2-btn-4, scene2-btn-5
  - scene2-critical-line
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
