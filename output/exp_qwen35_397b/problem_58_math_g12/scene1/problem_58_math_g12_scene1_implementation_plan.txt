[分步序列]
- 初始状态（步骤 0）：显示圆 O、圆心 O、点 A/B/C、弦 AB/BC/AC、标签 O/A/B/C、AB=4 标注、∠ACB=37°标注（绿色弧线 + 文字）
- 步骤 1：点击「下一步」→ 弧 AB 以蓝色#1565c0 加粗弧线（stroke-width=4）高亮显示，强调∠ACB 所对的弧
- 步骤 2：点击「下一步」→ 添加辅助线 OA、OB（红色#c62828 虚线），构造圆心角∠AOB
- 步骤 3：点击「下一步」→ 显示∠AOB 的蓝色角度弧线 + 标签"∠AOB=74°"，同时显示角度关系文字"∠AOB = 2×∠ACB = 2×37° = 74°"（位于图示右上角）
- 步骤 4：点击「下一步」→ 显示结论框（右下角），内容为"圆周角定理：同弧所对的圆心角 = 2×圆周角"

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 按钮"◀ 上一步"：位于 SVG 底部左侧 (x=280, y=455)，宽 100px，高 35px
  - 按钮"下一步 ▶"：位于 SVG 底部右侧 (x=420, y=455)，宽 100px，高 35px
  - 步骤指示器：位于两按钮之间 (x=390, y=465)，显示"步骤 X/4"
- 教师操作流程：
  1. 初始状态展示题目原图，引导学生观察已知条件
  2. 点击"下一步"高亮弧 AB，强调圆周角∠ACB 所对的弧
  3. 点击"下一步"添加辅助线 OA、OB，引导学生思考如何构造圆心角
  4. 点击"下一步"显示角度关系，直观呈现 2 倍关系
  5. 点击"下一步"显示定理结论，完成证明
  6. 可随时点击"上一步"回退复习关键步骤

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |         圆 O (圆心 350,250, r=120)               |
  |              B●                                   |
  |            /   \                                  |
  |      O●---/-----\----A●                           |
  |          /       \                                |
  |         /         \                               |
  |        C●----------                               |
  |                                                  |
  |                              [角度关系文字]       |
  |                                                  |
  |                              [结论框]             |
  |                                                  |
  |    [◀ 上一步]    步骤 X/4    [下一步 ▶]          |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-4) 跟踪当前步骤，每个步骤对应一组可见元素
  2. 所有元素预先创建但初始 display:none，根据 currentStep 控制显示/隐藏
  3. 弧 AB 高亮：使用 SVG path 绘制圆弧，通过计算 A、B 两点在圆上的角度确定弧的起点和终点
  4. 角度弧线：使用 SVG path 绘制小圆弧，圆心为角顶点，半径 25-30px
  5. 事件绑定：两个按钮绑定 click 事件，更新 currentStep 并调用 render() 函数
  6. 边界处理：步骤 0 时禁用"上一步"，步骤 4 时禁用"下一步"
- ID 命名规范：所有元素 ID 以 scene1- 为前缀
  - scene1-circle-o, scene1-point-o, scene1-point-a, scene1-point-b, scene1-point-c
  - scene1-chord-ab, scene1-chord-bc, scene1-chord-ac
  - scene1-arc-ab-highlight (步骤 1)
  - scene1-radius-oa, scene1-radius-ob (步骤 2)
  - scene1-angle-acb-arc, scene1-angle-acb-label
  - scene1-angle-aob-arc, scene1-angle-aob-label (步骤 3)
  - scene1-angle-relation-text (步骤 3)
  - scene1-conclusion-box (步骤 4)
  - scene1-btn-prev, scene1-btn-next, scene1-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
