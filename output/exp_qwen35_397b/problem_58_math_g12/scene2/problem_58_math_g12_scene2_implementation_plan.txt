[图示主题与整合说明]
- 本图示主题：正弦定理求外接圆半径——AB/sinC = 2R 的几何意义
- 整合的步骤/概念：展示△ABC 及其外接圆 → 标注边角关系 → 动态演示正弦定理公式 → 直接计算半径和面积
- 教学价值：教师可通过分步演示，帮助学生理解正弦定理中"边与对角正弦值之比等于直径"的几何本质，从图形直观过渡到代数计算

[分步序列]
- 初始状态（步骤 0）：
  · 显示圆 O（黑色实线圆）
  · 显示△ABC（黑色实线三角形）
  · 标注圆心 O、点 A、B、C
  · 标注 AB=4（在 AB 右侧）
  · 标注∠ACB=37°（C 点处角弧 + 数值）

- 步骤 1：点击「下一步」
  · 弦 AB 高亮为蓝色 (#1565c0)，线宽加粗至 3px
  · 角 ACB 的角弧高亮为蓝色
  · 公式区显示：正弦定理公式 "AB / sin∠ACB = 2R"

- 步骤 2：点击「下一步」
  · 显示直径辅助线（水平虚线，穿过圆心）
  · 直径两端标注 "2R"
  · 公式区追加：代入数值 "4 / sin37° = 2R"

- 步骤 3：点击「下一步」
  · 公式区追加：计算过程 "R = 2 / sin37°"
  · 公式区追加：面积公式 "S = πR² = π(2/sin37°)²"

- 步骤 4：点击「下一步」
  · 公式区追加：化简结果 "S = 4π / sin²37°"
  · 结论框显示（绿色边框）："圆 O 的面积 = 4π/sin²37°"
  · 可选：显示数值近似 "≈ 11.05π ≈ 34.7"（保留一位小数）

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │                    图示区 800×440                           │
  │  ┌─────────────┐  ┌─────────────────────────────────────┐   │
  │  │             │  │           公式展示区                 │   │
  │  │    圆 O     │  │  (步骤 1-4 逐步显示公式和计算过程)    │   │
  │  │   △ABC     │  │                                     │   │
  │  │             │  │                                     │   │
  │  └─────────────┘  └─────────────────────────────────────┘   │
  │                                                             │
  │                    [结论框 - 步骤 4 显示]                    │
  │                                                             │
  ├─────────────────────────────────────────────────────────────┤
  │              控件栏 (y=450~490)                             │
  │           [◀上一步]  步骤 X/4  [下一步▶]                    │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-4) 跟踪当前步骤，每步对应一组显示/隐藏逻辑
  2. 坐标计算：点 A/B/C 坐标需确保在圆上（到圆心距离=半径），可用角度参数计算
     - 设圆心 (320,240)，半径 130
     - 点 B：角度 -75° → (320+130×cos(-75°), 240+130×sin(-75°)) ≈ (410,150)
     - 点 A：角度 -35° → (320+130×cos(-35°), 240+130×sin(-35°)) ≈ (420,280)
     - 点 C：角度 -110° → (320+130×cos(-110°), 240+130×sin(-110°)) ≈ (220,350)
  3. 动画曲线：元素显示/高亮使用 CSS transition (0.3s ease)
  4. 事件绑定：按钮点击事件切换 currentStep，调用 updateDisplay() 刷新视图
  5. 元素 ID 规范：所有元素 ID 以 scene2- 为前缀（如 scene2-circle-o, scene2-tri-ab, scene2-label-ab）
  6. IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
  7. 公式渲染：简单公式用 SVG text 元素，多行公式用 <tspan> 换行

- 颜色规格（沿用大纲）：
  · 背景：#ffffff
  · 圆和三角形：#000000 实线
  · 高亮边和角：#1565c0 蓝色
  · 公式文字：#000000
  · 结论框：#2e7d32 绿色边框
  · 填充透明度：10-30%（如需填充）
