problem_59_math_g12

场景导航：Scene 1

题目原文：

(2010•肥城市模拟)如图，为了测量河的宽度，在河的一岸边选取两点A，B，观察对岸的点C，测得∠CAB=75°，∠CBA=45°，且AB=96米，则河的宽度为 ．(√2=1.4，√3=1.7，精确到米)

题目分析：

本题是解三角形的实际应用题，核心是利用正弦定理和直角三角形的边角关系求河宽。

已知条件：

  • ∠CAB = 75°
  • ∠CBA = 45°
  • AB = 96 米

求解目标：点C到直线AB的垂直距离（河宽）

整体讲解思路：

  1. 首先引导学生理解题意：两条平行线代表河岸，A、B在一侧，C在对岸
  2. 分析三角形ABC：已知两角和夹边，可求第三角∠ACB = 180° - 75° - 45° = 60°
  3. 关键辅助线：作CD⊥AB于D，CD即为所求河宽
  4. 解题策略：先用正弦定理求AC或BC，再在直角三角形中求高

图示规划说明：

设计一个核心几何图示，整合以下认知阶段：

  • 步骤0：展示题目基础图形（两岸平行线、三角形ABC）
  • 步骤1：标注已知角度和边长
  • 步骤2：作高CD（辅助线），标注垂足D
  • 步骤3：高亮两个直角三角形，展示边角关系
  • 步骤4：标注计算所需的角度和边长关系

使用分步按钮导航，教师可逐步推进讲解。

步骤 0/4

本图示教学说明：

引导学生观察：

  1. 首先让学生识别图中的几何元素：两条平行线代表河岸，△ABC是观测三角形
  2. 提问：河宽在图中对应哪条线段？引导学生意识到需要作垂线CD
  3. 强调：CD同时是两个直角三角形Rt△ACD和Rt△BCD的公共直角边

讲解要点：

  1. 求第三角：∠ACB = 180° - 75° - 45° = 60°
  2. 正弦定理求边：在△ABC中，AC/sin45° = AB/sin60°
  3. 代入数据：AC = 96 × sin45° / sin60° = 96 × (√2/2) / (√3/2) = 96√2/√3
  4. 在Rt△ACD中：CD = AC × sin75°

关键公式推导：

方法一（先求AC）：

  • AC = AB × sin45° / sin60° = 96 × (√2/2) / (√3/2) = 96√2/√3
  • CD = AC × sin75° = 96√2/√3 × sin75°

方法二（先求BC）：

  • BC = AB × sin75° / sin60°
  • CD = BC × sin45° = AB × sin75° × sin45° / sin60°

代入近似值计算：

  • sin75° = sin(45°+30°) = sin45°cos30° + cos45°sin30° = (√2/2)(√3/2) + (√2/2)(1/2) = √2(√3+1)/4
  • CD = 96 × √2(√3+1)/4 × (√2/2) / (√3/2) = 96 × (√3+1) × 2 / (4√3) = 48(√3+1)/√3

用√2=1.4，√3=1.7代入：

  • CD ≈ 48 × (1.7+1) / 1.7 = 48 × 2.7 / 1.7 ≈ 76 米

总结与课堂讲解建议：

完整解答：

  1. 作CD⊥AB于D，则CD为河宽
  2. 在△ABC中，∠ACB = 180° - 75° - 45° = 60°
  3. 由正弦定理：BC/sin75° = AB/sin60°
  4. BC = 96 × sin75° / sin60°
  5. 在Rt△BCD中，CD = BC × sin45° = 96 × sin75° × sin45° / sin60°
  6. sin75° = (√6+√2)/4 ≈ (1.7×1.4+1.4)/4 = (2.38+1.4)/4 = 0.945
  7. CD ≈ 96 × 0.945 × 0.707 / 0.866 ≈ 74 米

课堂讲解建议：

  1. 先让学生独立思考：如何把"河宽"转化为几何线段？
  2. 引导学生发现需要作辅助线（高）
  3. 讨论两种解题路径：先求AC还是先求BC？哪种更简便？
  4. 强调近似值的使用时机：应在最后一步代入，避免中间过程误差累积
  5. 拓展思考：如果∠CBA=45°改为其他角度，解题方法是否改变？

易错点提醒：

  • 学生可能忘记作辅助线，直接试图用△ABC求高
  • 正弦定理的边角对应关系容易混淆
  • 近似值代入过早会导致结果偏差
