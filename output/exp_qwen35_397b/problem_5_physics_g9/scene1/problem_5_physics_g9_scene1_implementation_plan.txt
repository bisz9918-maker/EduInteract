[分步序列]
- 步骤 0（初始状态）：显示左侧完整实物电路图，所有元件和导线可见，右侧区域空白，转换箭头灰色虚线
- 步骤 1：实物图中节点位置用红色小圆点高亮标记（分支点、汇合点），导线简化为直线路径，帮助学生识别电路拓扑
- 步骤 2：右侧出现标准等效电路图，左侧实物图变淡（透明度 50%），转换箭头变实线蓝色，展示抽象化结果
- 步骤 3：等效电路图中 L₁支路（蓝色#1565c0）和 L₂支路（红色#c62828）分别高亮显示，添加支路标签，明确并联结构

[标签冲突检查]
- 标签"-"：坐标(45,95)
- 标签"+"：坐标(135,95)
- 标签"Ⓐ"：坐标(195,155)
- 标签"L₁"（实物）：坐标(75,340)
- 标签"L₂"（实物）：坐标(325,340)
- 标签"L₁"（等效）：坐标(485,285)
- 标签"L₂"（等效）：坐标(595,285)

冲突检查：
- "-"与"+"：水平距离 90px → 无冲突
- "Ⓐ"与周围标签：最近为"+"距离约 60px → 无冲突
- 实物"L₁"与实物"L₂"：水平距离 250px → 无冲突
- 等效"L₁"与等效"L₂"：水平距离 110px → 无冲突
- 实物标签与等效标签：垂直方向错开（实物 y=340，等效 y=285）→ 无冲突
- 所有标签与图形元素：均保持≥15px 间距 → 无冲突

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于(280,455)，初始禁用（步骤 0 时），点击后返回上一状态
  - 「下一步」按钮：位于(440,455)，步骤 3 时禁用，点击后进入下一状态
  - 步骤指示器：显示「步骤 1/4」，位于两按钮之间(400,465)
- 教师操作流程：
  1. 初始展示实物图，让学生观察电路连接
  2. 点击「下一步」高亮节点，引导学生识别分支点
  3. 点击「下一步」展示等效电路图，对比实物与抽象图
  4. 点击「下一步」高亮并联支路，讲解电流表测量干路总电流
  5. 可随时点击「上一步」回退复习

[技术实现]
- JS 库选择：原生 SVG（电路图为几何图形组合，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────┐
  │  ┌─────────────┐                    ┌───────────────┐  │
  │  │  实物电路图  │     ======>       │ 等效电路图    │  │
  │  │  电池/开关   │                   │ 标准符号      │  │
  │  │  电流表/L₁L₂ │                   │ 并联结构      │  │
  │  └─────────────┘                    └───────────────┘  │
  │                                                         │
  │         [◀上一步]  步骤 1/4  [下一步▶]                │
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentState(0-3) 跟踪当前步骤，数组存储各状态配置
  2. 坐标计算：所有元件位置预定义为常量对象，避免硬编码分散
  3. 动画曲线：使用 CSS transition 实现淡入淡出（opacity 0→1，300ms ease）
  4. 事件绑定：按钮点击事件切换状态，更新 DOM 元素显示/隐藏
  5. ID 命名规范：所有元素 ID 以 scene1-为前缀，如 scene1-battery、scene1-ammeter、scene1-L1-physical、scene1-L1-schematic
  6. IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
  7. 高亮实现：通过添加/移除 CSS class "highlight-blue"或"highlight-red"控制支路颜色
  8. 按钮状态：步骤 0 时禁用「上一步」，步骤 3 时禁用「下一步」，用 CSS class "disabled"控制
