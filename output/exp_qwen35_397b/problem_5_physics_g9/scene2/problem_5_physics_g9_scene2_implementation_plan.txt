[图示主题与整合说明]
- 本图示主题：电流路径动态演示与电流表测量对象判断
- 整合内容：电流流向追踪、支路识别、电流表串联关系确认
- 教学价值：教师可通过分步动画展示电流从电源正极出发的完整路径，帮助学生直观理解并联电路中电流的分流规律，明确电流表与哪个用电器串联就测量哪个用电器的电流。学生可清晰看到电流在节点处分流、在汇合点汇合的过程，建立电流路径的空间概念。

[分步序列]
- 初始状态（步骤0）：显示完整静态电路图，所有元件和导线以黑色实线显示，标注L₁、L₂、Ⓐ、+、-，无电流箭头，无高亮
- 步骤1：点击「下一步」→ 从电源正极(140,200)出发，绿色电流箭头沿导线向电流表移动，路径：(140,200)→(350,200)→(350,140)，箭头动画速度2px/帧，显示"电流从正极出发"提示
- 步骤2：点击「下一步」→ 电流到达分流节点(650,200)，显示两个箭头分别向L₁支路和L₂支路移动，L₁支路箭头路径：(650,200)→(350,200)→(350,280)→(150,280)，L₂支路箭头路径：(650,200)→(650,280)→(610,280)，标注I₁和I₂出现
- 步骤3：点击「下一步」→ L₁支路及电流表整体高亮为蓝色#1565c0（线宽4px，透明度20%填充），L₂支路高亮为红色#c62828，电流表与L₁的串联关系用蓝色虚线框标注(140,80)-(440,350)
- 步骤4：点击「下一步」→ 结论文本框显示"电流表与L₁串联，测量通过L₁的电流"，所有电流箭头停止，高亮保持，步骤指示显示"4/4"

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于(280,455)，100×35px，蓝色背景，点击后退到前一状态
  - 「下一步」按钮：位于(420,455)，100×35px，蓝色背景，点击前进到下一状态
  - 步骤指示：位于(390,440)，显示"步骤X/4"，灰色文字14px
- 教师操作流程：
  1. 初始状态展示完整电路图，让学生观察电路结构
  2. 点击「下一步」展示电流从正极出发，讲解电流方向
  3. 点击「下一步」展示分流过程，讲解并联电路电流规律
  4. 点击「下一步」高亮电流表与L₁的串联关系，引导学生观察
  5. 点击「下一步」显示结论，总结电流表测量对象判断方法
  6. 可随时点击「上一步」回退复习关键步骤

[技术实现]
- JS库选择：原生SVG + 原生JavaScript
  - 原因：电路图以几何形状和路径为主，SVG矢量图形清晰且易于动画；无需复杂库即可实现路径动画和状态切换
- 画布尺寸：800×500px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +----------------------------------------------------------+
  |  [电源]                    [电流表]          [开关]       |
  |     |                        |                 |          |
  |     |                        |                 |          |
  |    [L₁]←───分流───→[L₂]      |                 |          |
  |     |                        |                 |          |
  |     +────────汇合────────────+                 |          |
  |                                                  [结论]   |
  |                                                           |
  |              [步骤指示]                                   |
  |         [◀上一步]    [下一步▶]                            |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用currentState变量(0-4)跟踪当前步骤，steps数组存储每步的显示配置
  2. 路径动画：使用SVG <animateMotion>或JS requestAnimationFrame沿path移动箭头元素
  3. 高亮效果：通过修改stroke-width和stroke-opacity实现，或叠加半透明path
  4. 事件绑定：按钮点击事件切换状态，更新DOM元素display/opacity属性
  5. 边界处理：步骤0时禁用「上一步」，步骤4时禁用「下一步」
- ID命名规范：所有交互元素ID必须以scene2-为前缀
  - scene2-power, scene2-switch, scene2-ammeter, scene2-lamp1, scene2-lamp2
  - scene2-wire-1至scene2-wire-11
  - scene2-node-split, scene2-node-merge
  - scene2-label-l1, scene2-label-l2, scene2-label-a, scene2-label-i1, scene2-label-i2
  - scene2-btn-prev, scene2-btn-next, scene2-step-indicator
  - scene2-arrow-1, scene2-arrow-2（电流箭头）
  - scene2-highlight-l1-branch, scene2-highlight-l2-branch（高亮层）
  - scene2-conclusion-box, scene2-conclusion-text
- IIFE隔离：所有JS代码包在(function() { ... })()中，避免全局变量污染
