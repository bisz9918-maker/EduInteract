[分步序列]
本场景为连续拖拽交互，无分步导航，状态定义如下：
- 初始状态（P点角度300°/约-60°）：
  - P位置：(450, 193)
  - C位置：(300, 110)
  - D位置：(500, 225)
  - 显示所有线段：AB, AC, BD, CD, PO, PC, PD
  - 数值框1：PC·PD ≈ 10000
  - 数值框2：PO² = 10000
  - 两者相等，高亮显示（绿色背景）

- 拖拽状态（P沿圆周移动，角度θ从0°到360°连续变化）：
  - P位置：(400 + 100*cos(θ), 280 + 100*sin(θ))
  - 实时重新计算C、D位置（切线CD与AC、BD的交点）
  - 实时更新线段PC、PD、PO
  - 实时更新数值框：PC·PD 和 PO²
  - 始终显示两者相等（允许±1浮点误差）

[交互方案]
- 交互类型：连续拖拽滑块（P点可沿圆周拖拽移动）
- 控件说明：
  - 无数值滑块控件，直接拖拽P点本身
  - 底部数值显示框2个：左侧显示"PC·PD = xxx"，右侧显示"PO² = xxx"
  - 拖拽提示文字："拖拽P点观察数值变化"
- 教师操作流程：
  1. 初始状态展示定理条件：圆O、直径AB、切线AC/BD、动点P、切线CD
  2. 引导学生观察初始位置下PC·PD与PO²的数值（两者相等）
  3. 拖拽P点沿圆周移动，让学生观察两数值如何同步变化
  4. 强调无论P在何处，PC·PD始终等于PO²
  5. 可拖动P点完整绕圆一周，验证定理的普适性

[技术实现]
- JS库选择：原生SVG + 原生JavaScript
  - 原因：几何图形简单，无需复杂库；拖拽交互用原生事件即可实现
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |         D                                        |
  |        /|                                        |
  |       / |                                        |
  |      /  |                                        |
  |     C---P-----------(圆上半部)                   |
  |     |  /|            \                          |
  |     | / |             \                         |
  |     |/  |              \                        |
  |     A---O--------------B                        |
  |                                                  |
  |                                                  |
  |  +----------------+  +----------------+          |
  |  | PC·PD = 10000  |  | PO² = 10000    |  拖拽P点 |
  |  +----------------+  +----------------+  观察    |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：单状态连续交互，无需步骤切换
  2. 坐标计算：
     - P点：(400 + 100*cos(θ), 280 + 100*sin(θ))，θ由拖拽角度决定
     - 切线CD方程：法向量为OP，过P点，求与x=300和x=500的交点得C、D
     - 切线方程推导：设OP向量为(nx, ny)，则切线方程为 nx*(x-Px) + ny*(y-Py) = 0
     - C点：x=300代入切线方程求y
     - D点：x=500代入切线方程求y
  3. 拖拽实现：
     - mousedown：检测是否在P点附近（距离<15px），设置dragging=true
     - mousemove：若dragging=true，计算鼠标相对于圆心O的角度θ，更新P位置
     - mouseup：dragging=false
     - 角度计算：θ = atan2(mouseY - 280, mouseX - 400)
  4. 数值计算：
     - PC = distance(P, C)
     - PD = distance(P, D)
     - PO = 100（半径，恒定）
     - 显示值保留整数或1位小数
  5. 事件绑定：SVG元素上绑定mousedown/mousemove/mouseup事件
- ID命名规范：
  - 圆：scene1-circle-o
  - 直径AB：scene1-line-ab
  - 切线AC：scene1-line-ac
  - 切线BD：scene1-line-bd
  - 切线CD：scene1-line-cd
  - 线段PO：scene1-line-po
  - 线段PC：scene1-line-pc
  - 线段PD：scene1-line-pd
  - 点A/B/O/P/C/D：scene1-point-a/b/o/p/c/d
  - 标签A/B/O/P/C/D：scene1-label-a/b/o/p/c/d
  - 数值框1：scene1-value-box1
  - 数值框2：scene1-value-box2
  - 数值文本1：scene1-value-text1
  - 数值文本2：scene1-value-text2
- IIFE隔离：所有JS代码包在 (function() { ... })() 中，避免全局污染
- 注意事项：
  - 当P点接近A或B正上方时，切线CD可能趋于水平，C或D可能超出画布，需限制P的拖拽角度范围（如30°到330°，避开顶部极端位置）
  - 或动态调整C、D的显示范围，确保始终在画布内
