- 本图示主题：圆与椭圆的类比对比
- 整合内容：圆和椭圆并置、对应元素高亮、结论对比

[分步序列]
- 初始状态（步骤0）：显示圆和椭圆的基本结构（轮廓、直径/长轴、中心点、焦点、切线、P点、C点、D点），所有元素以基础颜色显示，无高亮
- 步骤1：点击「下一步」→ 高亮直径AB(圆)与长轴AB(椭圆)，对应线段变为#1565c0粗线，显示高亮虚线连接左右AB，标签A、B同步高亮
- 步骤2：点击「下一步」→ 高亮圆心O(圆)与焦点F₁/F₂(椭圆)，O点、F1、F2点变为#1565c0，显示高亮虚线连接O与F1F2区域
- 步骤3：点击「下一步」→ 高亮PO连线(圆)与PF₁、PF₂连线(椭圆)，PO、PF1、PF2线段变为#1565c0粗线，显示高亮虚线连接对应关系
- 步骤4：点击「下一步」→ 显示结论对比框，圆侧结论框显示"PC·PD = PO²"，椭圆侧结论框显示"PC·PD = PF₁·PF₂"，结论框边框高亮#1565c0

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 按钮"上一步"：位置(350,455)，尺寸80×30，点击回退到前一状态
  - 按钮"下一步"：位置(450,455)，尺寸80×30，点击进入下一状态
  - 状态指示器：位置(400,455)，显示"步骤X/5"
- 教师操作流程：
  1. 初始展示圆与椭圆并置结构，让学生观察两者的相似性
  2. 点击"下一步"高亮AB对应，讲解直径与长轴的类比关系
  3. 点击"下一步"高亮O与F1/F2对应，讲解圆心与焦点的类比关系
  4. 点击"下一步"高亮PO与PF1/PF2对应，讲解半径与焦半径的类比关系
  5. 点击"下一步"展示结论，引导学生得出PC·PD = PF₁·PF₂的类比结论
  6. 可随时点击"上一步"回退复习

[技术实现]
- JS 库选择及原因：原生 SVG（简单几何图形首选，无需额外库，性能好，易于精确控制坐标）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |   [圆图]              [椭圆图]                   |
  |   圆心(200,230)        中心(600,230)             |
  |   r=70                rx=90, ry=55               |
  |                                                  |
  |   A    O    B         A  F2 O  F1  B             |
  |                                                  |
  |   [结论框:PC·PD=PO²]   [结论框:PC·PD=PF₁·PF₂]    |
  |   y=380-410           y=380-410                  |
  |                                                  |
  |        [◀上一步]  步骤X/5  [下一步▶]             |
  |        y=440-490 控件栏区域                      |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-4) 跟踪当前步骤
  2. 坐标计算：所有元素坐标预先计算好，存储为常量对象
  3. 动画曲线：使用 CSS transition 实现颜色/透明度变化，duration 300ms ease-in-out
  4. 事件绑定：按钮点击事件绑定到状态切换函数
  5. 高亮逻辑：每步切换时，移除所有元素的旧高亮类，添加当前步骤对应的高亮类
  6. 结论框显示：步骤4时显示结论框，之前步骤隐藏或透明度0
- ID 命名规范：所有交互元素 ID 必须以 scene3- 为前缀
  - scene3-circle, scene3-ellipse
  - scene3-circle-ab, scene3-ellipse-ab
  - scene3-circle-o, scene3-ellipse-o, scene3-ellipse-f1, scene3-ellipse-f2
  - scene3-circle-p, scene3-ellipse-p
  - scene3-circle-c, scene3-ellipse-c, scene3-circle-d, scene3-ellipse-d
  - scene3-circle-po, scene3-ellipse-pf1, scene3-ellipse-pf2
  - scene3-conclusion-circle, scene3-conclusion-ellipse
  - scene3-btn-prev, scene3-btn-next, scene3-step-indicator
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
