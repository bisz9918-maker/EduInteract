    **题目原文：**

    如图，在半径为 3 的球面上有 A、B、C 三点，∠ABC=90°，BA=BC，球心 O 到平面 ABC 的距离是 3√2/2，则 B、C 两点的球面距离是______．

    **题目分析：**

    本题是立体几何中球面距离的经典问题。核心考点包括：
    1. 球面距离的定义：球面上两点间的最短距离是过这两点的大圆弧长
    2. 球面距离公式：s = R·θ（R 为球半径，θ 为球心角，弧度制）
    3. 球的截面性质：球心到截面的距离 d、球半径 R、截面圆半径 r 满足 R² = d² + r²
    4. 圆周角定理：90°圆周角所对的弦是直径

    **整体讲解思路：**

    第一步：理解球面距离的概念，明确需要求的是∠BOC（球心角）

    第二步：利用球的截面性质求出小圆半径 r = √(R²-d²) = √(9-9/2) = 3/√2

    第三步：由∠ABC=90° 知 AC 是小圆直径，故 AC = 2r = 3√2

    第四步：在等腰直角△ABC 中，由 BA=BC 及勾股定理得 BC = 3

    第五步：在△OBC 中，OB=OC=BC=3，故为等边三角形，∠BOC=60°=π/3

    第六步：球面距离 = R·θ = 3·π/3 = π

    **图示规划说明：**

    设计 2 个交互式图示：
    - SCENE_1：立体空间结构图，展示球体、截面圆、关键点线关系
    - SCENE_2：平面几何推导图，聚焦△OBC 的等边三角形性质与球心角计算
    </TEXT_1>

    **SCENE_2 教学说明：**

    本图示聚焦核心计算环节，教师应强调以下关键点：

    **1. 求 BC 长度：**

    在等腰直角△ABC 中：
    - 已知 AC = 3√2（小圆直径）
    - BA = BC（等腰）
    - 由勾股定理：BA² + BC² = AC²
    - 即 2·BC² = (3√2)² = 18
    - 得 BC² = 9，故 BC = 3

    **2. 发现等边三角形：**

    在△OBC 中：
    - OB = OC = 3（球半径）
    - BC = 3（已求）
    - 三边相等，故△OBC 是等边三角形
    - 因此∠BOC = 60° = π/3（弧度）

    **3. 球面距离计算：**

    球面距离定义：球面上两点间大圆弧的长度

    公式：s = R·θ（θ 用弧度制）

    代入：s = 3 · π/3 = π

    **完整解答：**

    B、C 两点的球面距离是 **π**

    **课堂讲解建议：**

    - 先让学生回顾球面距离的定义，避免与直线距离混淆
    - 强调弧度制的使用：60° 必须转换为 π/3
    - 引导学生发现△OBC 是等边三角形这一关键洞察
    - 可提问：如果∠ABC 不是 90°，解题思路会如何变化？
