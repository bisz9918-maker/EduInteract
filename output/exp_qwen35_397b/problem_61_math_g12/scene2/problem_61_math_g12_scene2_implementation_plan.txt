[图示主题与整合说明]
- 本图示主题：球心角∠BOC 与球面距离计算——展示△OBC 的等边三角形性质及弧长公式
- 整合的内容：BC 长度计算 + △OBC 三边关系 + 球心角推导 + 球面距离公式应用
- 教学价值：教师可逐步引导学生从平面几何（△ABC）过渡到空间几何（△OBC），最终理解球面距离的本质是大圆弧长。分步展示帮助学生建立"球半径→弦长→球心角→弧长"的完整逻辑链。

[分步序列]
- 初始状态（步骤 0）：显示球体轮廓、截面圆（虚线）、点 O/A/B/C、△ABC 三边（绿色）、△OBC 三边（蓝色，透明度 50%）。所有点标签显示。等待教师触发。
- 步骤 1：高亮△ABC（绿色边加粗至 stroke-width=3），在 BC 下方显示标签"BC=3"，在 AC 旁显示"AC=3√2"。右侧显示推导文字："等腰 Rt△ABC → 2·BC²=AC² → BC=3"。
- 步骤 2：高亮△OBC（蓝色边加粗至 stroke-width=3，透明度 100%），在 OB 旁显示"OB=3（球半径）"，在 OC 旁显示"OC=3（球半径）"。展开图出现，三边标注清晰。
- 步骤 3：∠BOC 角标记弧线出现（红色），显示标签"∠BOC=60°=π/3"。展开图中强调"三边相等→等边三角形"文字高亮。
- 步骤 4：公式区显示球面距离公式"s = R·θ"，下方显示代入过程"s = 3·π/3 = π"。公式逐行淡入。
- 步骤 5：大圆弧 BC（红色粗线）沿球面从 B 到 C 绘制出现，△ABC 和△OBC 边线透明度降低至 30%，突出球面距离的实际路径。最终结论"球面距离 = π"高亮显示。

[技术实现]
- JS 库选择及原因：原生 SVG。理由：本场景以几何图形为主（圆、线段、弧线、文本），原生 SVG 足够胜任，无需引入 D3 或 Three.js，加载快、代码简洁。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |    [球体立体图]           [△OBC 展开图]          |
  |       O                     O'                   |
  |      / \                   /  \                  |
  |     /   \                 /    \                 |
  |    A-----C               B'----C'                |
  |     \   /                                        |
  |      \ /                                         |
  |       B                                          |
  |                                                  |
  |    [公式区 s=R·θ=π]                              |
  |                                                  |
  |    [◀上一步]  [步骤 X/5]  [下一步▶]              |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 scene2_currentStep（0-5）跟踪当前步骤，数组 scene2_states 存储每步的显示配置
  2. 坐标计算：球面弧线用 SVG <path> 的 arc 命令，大圆弧 BC 的路径需计算球面参数方程
  3. 动画曲线：元素淡入用 CSS transition opacity 0.4s ease，线段加粗用 stroke-width 过渡
  4. 事件绑定：按钮点击事件绑定到 updateScene2Step() 函数，更新状态后重绘对应元素
  5. 禁用状态：步骤 0 时上一步按钮 disabled=true，步骤 5 时下一步按钮 disabled=true
- ID 命名规范：所有交互元素 ID 必须以 scene2- 为前缀
  - scene2-sphere（球体轮廓）
  - scene2-section-circle（截面圆）
  - scene2-point-o, scene2-point-a, scene2-point-b, scene2-point-c
  - scene2-tri-abc-ab, scene2-tri-abc-bc, scene2-tri-abc-ac
  - scene2-tri-obc-ob, scene2-tri-obc-oc, scene2-tri-obc-bc
  - scene2-arc-bc（大圆弧）
  - scene2-angle-boc（角标记）
  - scene2-unfolded-tri（展开图）
  - scene2-formula-box, scene2-formula-text, scene2-calc-text
  - scene2-btn-prev, scene2-btn-next, scene2-step-indicator
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
