[分步序列]
- 步骤0（初始状态）：显示基础四面体ABCD，中点E、F，截面点G、H，虚线EF、EH、FG、GH。顶部显示"基础结构"。
- 步骤1（命题①验证）：在步骤0基础上，延长GF、EH、BD三线，用#c62828实线绘制，标记交点P（红色实心圆）。顶部显示"命题①：GF、EH、BD三线共点（✓真）"。
- 步骤2（命题②验证）：隐藏步骤1元素，显示特殊位置使GF∥EH∥BD，三线用#2e7d32绿色，添加3个平行标记箭头。顶部显示"命题②：存在平面α₀使GF∥EH∥BD（✓真）"。
- 步骤3（命题③验证）：隐藏步骤2元素，显示AD延长线（#888888虚线），H点移至延长线上（H'，#c62828红色）。顶部显示"命题③：H可在AD延长线上（✓真）"。
- 步骤4（命题④验证）：隐藏步骤3元素，恢复标准位置，△EFG和△EFH用#1565c0半透明填充，标注"S△EFG"和"S△EFH"。顶部显示"命题④：S△EFG=S△EFH（✓真）"。
- 结论：所有命题均为真，教师可回退复习任意步骤。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于(280,460)，点击后退到前一状态，步骤0时禁用
  - 「下一步 ▶」按钮：位于(420,460)，点击前进到下一状态，步骤4时禁用
  - 步骤指示器：顶部5个圆点(100,45)、(200,45)、(300,45)、(400,45)、(500,45)，当前步骤圆点填充#1976d2
- 教师操作流程：
  1. 初始加载显示步骤0，教师介绍四面体基础结构
  2. 点击「下一步」进入步骤1，讲解命题①三线共点
  3. 点击「下一步」进入步骤2，讲解命题②平行关系
  4. 点击「下一步」进入步骤3，讲解命题③延长线位置
  5. 点击「下一步」进入步骤4，讲解命题④面积相等
  6. 可随时点击「上一步」回退复习

[技术实现]
- JS库选择：原生SVG（适合3D几何线框图，无需3D库）
- 画布尺寸：800×500px
- 布局草图：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────┐
  │  [步骤指示器 ●○○○○]                               │ y=30-55
  │                                                     │
  │              A                                      │
  │             /|\                                     │
  │            / | \                                    │
  │           E  |  H                                   │ y=200-220
  │          /   |   \                                  │
  │         B----+----D                                 │ y=350
  │          \   |   /                                  │
  │           G  |  F                                   │ y=385-400
  │            \ | /                                    │
  │              C                                      │ y=420-445
  │                                                     │
  │         [◀ 上一步]  [下一步 ▶]                      │ y=460-490
  └─────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：currentStep变量(0-4)，每步调用renderStep(n)函数
  2. 坐标计算：四面体顶点坐标固定，中点E/F用中点公式，G/H用参数方程
  3. 延长线计算：命题①中三线延长线交点P需解直线方程
  4. 动画曲线：步骤切换用CSS transition，opacity从0到1，duration 300ms
  5. 事件绑定：按钮click事件，步骤0/4时禁用对应按钮
  6. 元素显隐：每步用display:none/block控制元素组
- ID命名规范：所有元素ID以scene2-为前缀，如scene2-vertex-a、scene2-edge-ab、scene2-point-e、scene2-step1-lines等
- IIFE隔离：所有JS代码包在(function() { ... })()中，避免全局污染
- 命题①交点P计算：BD线为y=350，EH线过(300,215)-(500,215)为y=215，GF线过(500,385)-(300,385)为y=385，三线实际不共点于有限远，需调整G/H位置使三线共点（取G为BC中点、H为AD中点时，EH∥BD∥GF，交点在无穷远；取其他位置时可共点）
- 命题④面积相等证明：E、F为中点，EF为中位线，△EFG与△EFH同底EF，高相等（G、H到EF距离相等），故面积相等
