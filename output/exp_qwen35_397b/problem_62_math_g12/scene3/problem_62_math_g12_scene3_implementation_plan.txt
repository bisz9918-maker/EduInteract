[图示主题与整合说明]
- 本图示主题：命题④面积相等的几何证明图示——证明对于任意过 EF 的平面α，都有 S△EFG = S△EFH
- 整合的内容：△EFG 和△EFH 的面积计算、中点性质应用、等高三角形面积关系、四面体截面几何
- 教学价值：教师可通过分步演示，引导学生理解：(1) 两个三角形共享底边 EF；(2) 利用中点性质证明 G、H 到 EF 的距离相等；(3) 从而得出面积相等的结论。分步推导帮助学生建立严谨的几何证明思维。

[分步序列]
共 5 步（步骤 0-4），教师可通过「上一步」「下一步」按钮控制进度：

- 步骤 0（初始状态）：
  - 显示：四面体 ABCD（灰色淡化棱线#888888）、点 E、F、G、H 及标签
  - 显示：△EFG（蓝色半透明）、△EFH（绿色半透明）轮廓
  - 右侧公式区：显示标题「命题④：S△EFG = S△EFH」
  - 右侧步骤区：显示「步骤 0：观察两个三角形」

- 步骤 1（点击「下一步」）：
  - 视觉变化：公共底边 EF 高亮（#1565c0 粗线 3px）
  - 新增：EF 中点附近标注「公共底边」
  - 右侧公式区：新增「S△EFG = ½ × EF × h₁」、「S△EFH = ½ × EF × h₂」
  - 右侧步骤区：更新为「步骤 1：两个三角形共享底边 EF」

- 步骤 2（点击「下一步」）：
  - 视觉变化：从 G 作 EF 的垂线 GM（#c62828 虚线），垂足 M 用直角标记
  - 视觉变化：从 H 作 EF 的垂线 HN（#c62828 虚线），垂足 N 用直角标记
  - 新增：h₁标注（红色，GM 中点左侧）、h₂标注（红色，HN 中点右侧）
  - 右侧公式区：高亮显示 h₁、h₂
  - 右侧步骤区：更新为「步骤 2：作 G、H 到 EF 的垂线，高分别为 h₁、h₂」

- 步骤 3（点击「下一步」）：
  - 视觉变化：显示辅助线——连接 E 到 BC 中点、F 到 AD 中点的绿色虚线
  - 视觉变化：高亮显示 h₁ = h₂（两条垂线变为相同颜色#ff6f00）
  - 右侧公式区：新增「∵ E、F 为中点，∴ h₁ = h₂（等距性质）」
  - 右侧步骤区：更新为「步骤 3：利用中点性质证明 h₁ = h₂」

- 步骤 4（最终结论）：
  - 视觉变化：两个三角形同时高亮（边框加粗至 3px）
  - 右侧公式区：显示完整推导链：
    ```
    S△EFG = ½ × EF × h₁
    S△EFH = ½ × EF × h₂
    ∵ h₁ = h₂
    ∴ S△EFG = S△EFH
    ```
  - 右侧步骤区：更新为「结论：面积相等 ✓」
  - 显示「证明完成」动画（绿色对勾闪烁）

- 控件说明：
  - 按钮「◀ 上一步」：位于 (280,465)，宽 120px，高 30px，浅灰色背景 #e0e0e0
  - 按钮「下一步 ▶」：位于 (420,465)，宽 120px，高 30px，蓝色背景 #1565c0，白色文字
  - 步骤指示器：位于 (550,470)，显示「步骤 X/4」
- 教师操作流程：
  1. 初始状态展示四面体和两个三角形，让学生观察
  2. 点击「下一步」高亮公共底边 EF，引导学生注意共享边
  3. 点击「下一步」显示垂线，解释高的概念
  4. 点击「下一步」利用中点性质证明高相等
  5. 点击「下一步」展示完整推导链，得出面积相等结论
  6. 可随时点击「上一步」回退复习关键步骤

[技术实现]
- JS 库选择：原生 SVG（适合几何图形绘制，无需额外库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │                    四面体 ABCD 立体图                       │
  │         A(280,60)                                          │
  │           /|\                                              │
  │          / | \                                             │
  │      E(200,170)  H(380,200)                                │
  │        /    |    \                                         │
  │       /     |     \                                        │
  │   B(120,280)───M─N───D(440,280)                            │
  │       \     / \   /                                        │
  │        \   /   \ /                                         │
  │      G(220,340)  F(360,340)                                │
  │           \   /                                            │
  │            \|/                                             │
  │           C(280,400)                                       │
  │                                                            │
  │  ┌─────────────────┐  ┌─────────────────────────────┐      │
  │  │   面积公式区    │  │       步骤说明区            │      │
  │  │  S=½×底×高     │  │   当前步骤文字说明          │      │
  │  └─────────────────┘  └─────────────────────────────┘      │
  │                                                            │
  │              [◀ 上一步]  [下一步 ▶]  步骤 X/4               │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-4) 跟踪当前步骤，每个步骤对应一组元素显示/隐藏状态
  2. 坐标计算：四面体顶点坐标固定，中点 E、F 用中点公式计算，垂足 M、N 用点到直线垂足公式
  3. 动画曲线：元素淡入用 CSS transition opacity 0.3s ease-in-out
  4. 事件绑定：按钮点击事件绑定到 stepForward() 和 stepBackward() 函数
  5. 元素分组：用 SVG <g> 元素按步骤分组，通过 display 属性控制显示/隐藏
- ID 命名规范：所有元素 ID 以 scene3- 为前缀，例如：
  - scene3-tetra-abcd（四面体组）
  - scene3-tri-efg（△EFG）
  - scene3-tri-efh（△EFH）
  - scene3-ef-base（公共底边 EF）
  - scene3-gm-alt（垂线 GM）
  - scene3-hn-alt（垂线 HN）
  - scene3-btn-prev（上一步按钮）
  - scene3-btn-next（下一步按钮）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
- 响应式：画布固定 800×500，容器用 viewBox 保持比例
