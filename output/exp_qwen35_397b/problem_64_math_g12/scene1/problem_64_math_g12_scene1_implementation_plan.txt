[图示主题与整合说明]
- 本图示主题：直四棱柱中空间线线垂直关系的转化
- 整合的步骤/概念：四棱柱三维结构展示、B₁D₁ 与 BD 平行关系、AC 与 BD 垂直条件、答案呈现

[分步序列]
- 初始状态（步骤 0）：显示完整四棱柱线框（3 条虚线棱+9 条实线棱），标注所有 8 个顶点 A、B、C、D、A₁、B₁、C₁、D₁，高亮显示对角线 AC（蓝色）和 B₁D₁（红色）
- 步骤 1：点击「下一步」→ 侧棱 AA₁、BB₁、CC₁、DD₁ 用淡蓝色半透明填充高亮，强调顶面与底面平行关系，显示文字提示"顶面 A₁B₁C₁D₁ ∥ 底面 ABCD"
- 步骤 2：点击「下一步」→ 将 B₁D₁ 沿侧棱方向向下平移至 BD 位置，用灰色箭头动画展示平移过程（从 y=240 到 y=380），平移完成后 B₁D₁ 保持红色实线，新增 BD 红色虚线，显示文字提示"B₁D₁ ∥ BD"
- 步骤 3：点击「下一步」→ 聚焦底面 ABCD，淡化顶面和侧棱（透明度降至 30%），高亮 AC（蓝色加粗至 3px）和 BD（红色加粗至 3px），在交点 (400,380) 处显示绿色直角符号，显示文字提示"若 AC⊥BD，则 AC⊥B₁D₁"
- 步骤 4：点击「下一步」→ 在图示下方 (400,470) 显示答案文本"AC⊥BD（或四边形 ABCD 是菱形/正方形）"，所有元素保持步骤 3 状态

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于 SVG 内底部左侧 (320,455)，点击后回退到上一状态
  - 「下一步 ▶」按钮：位于 SVG 内底部右侧 (400,455)，点击后进入下一状态
  - 步骤指示器：显示"步骤 X/5"，位于两按钮之间
- 教师操作流程：
  1. 初始展示完整四棱柱，让学生观察 AC 和 B₁D₁ 的空间位置关系
  2. 点击「下一步」强调顶面与底面平行，引导学生思考平行平面的性质
  3. 点击「下一步」展示 B₁D₁ 平移到 BD，直观展示平行关系
  4. 点击「下一步」聚焦底面，展示 AC 与 BD 垂直时的直角符号
  5. 点击「下一步」给出最终答案，完成从空间到平面的转化推理

[技术实现]
- JS 库选择：原生 SVG（适合三维线框图绘制，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +------------------------------------------+
  |                                          |
  |           四棱柱线框图                    |
  |           (居中 70% 区域)                 |
  |                                          |
  |                                          |
  |                                          |
  |                                          |
  |                                          |
  |      [◀ 上一步] [步骤 X/5] [下一步 ▶]    |
  |              (底部 y=440~490)            |
  +------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量 (0-4) 跟踪当前步骤，steps 数组存储每步的显示配置
  2. 坐标计算：所有顶点坐标硬编码，确保透视效果一致
  3. 动画曲线：平移动画使用 ease-in-out 曲线，持续时间 800ms
  4. 事件绑定：按钮点击事件绑定到 updateScene() 函数，根据 currentState 更新显示
  5. 虚线实现：使用 stroke-dasharray="5,5" 实现虚线效果
  6. 透明度控制：使用 opacity 属性控制淡化效果
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀
  - scene1-prism-AA1, scene1-prism-BB1, scene1-prism-CC1, scene1-prism-DD1（侧棱）
  - scene1-edge-AB, scene1-edge-AD, scene1-edge-BC, scene1-edge-CD（底边）
  - scene1-edge-A1B1, scene1-edge-A1D1, scene1-edge-B1C1, scene1-edge-C1D1（顶边）
  - scene1-diag-AC, scene1-diag-B1D1, scene1-diag-BD（对角线）
  - scene1-label-A, scene1-label-B, ..., scene1-label-D1（顶点标签）
  - scene1-label-AC, scene1-label-B1D1, scene1-label-BD（对角线标签）
  - scene1-arrow-translate（平移箭头）
  - scene1-rect-perp（垂直符号）
  - scene1-btn-prev, scene1-btn-next（按钮）
  - scene1-answer-text（答案文本）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
