[分步序列]
- 初始状态（步骤 0）：显示左侧平面△ABC，标注所有点 A,B,C,D,E,F,G，显示中线 AF（黑色实线）、中位线 DE（黑色实线），显示边长标签"a"在 BC 下方。右侧区域空白。
- 步骤 1：高亮△AED 区域（浅蓝色填充透明度 20%），在 G 点附近显示提示文字"绕 DE 旋转"，其他元素保持不变。
- 步骤 2：显示旋转轨迹圆弧（蓝色 #1565c0），从 A 点开始沿逆时针方向绘制圆弧，圆心为 G，半径 GA=120px，圆弧角度从 0°到 60°，在圆弧中点显示标签"θ"。
- 步骤 3：在右侧显示 A'点（红色圆点），显示线段 A'D 和 A'E（红色实线），显示线段 A'G（灰色虚线），此时形成部分立体结构。
- 步骤 4（最终步骤）：显示完整三棱锥 A'-FED，包括底面 FED（浅灰填充 15%）、棱 A'F（灰色虚线）、底面各边 FD、FE、DE（黑色实线）。所有标签 A',D,E,F,G 显示。左侧平面图形保持显示以便对比。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 底部左侧 (x=320, y=455)，灰色背景，点击返回上一状态
  - 「下一步」按钮：位于 SVG 底部右侧 (x=480, y=455)，蓝色背景，点击进入下一状态
  - 状态指示器：位于底部中央 (x=400, y=455)，显示"步骤 X/4"
- 教师操作流程：
  1. 初始加载显示步骤 0，教师介绍正△ABC 基本结构
  2. 点击「下一步」到步骤 1，高亮△AED，说明旋转对象
  3. 点击「下一步」到步骤 2，显示旋转轨迹，讲解旋转过程
  4. 点击「下一步」到步骤 3，显示 A'位置，形成部分立体
  5. 点击「下一步」到步骤 4，完整三棱锥，引导学生验证四个命题
  6. 可随时点击「上一步」回退复习关键概念

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单，无需复杂库；SVG 便于精确控制坐标和样式；动画可通过 CSS transition 或 JS 逐步修改属性实现
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [800 × 500 画布]
  +----------------------------------------------------------+
  |              正三角形绕中位线旋转 (标题 y=35)              |
  +----------------------------------------------------------+
  |                                                          |
  |   [左侧平面图形]           [右侧立体图形]                 |
  |   A(230,120)                                           A' |
  |    / \                                                  /|\
  |   /   \                                                / | \
  |  D-----E (中位线)                                     D--|--E
  |  |  G  |                                              /  |  \
  |  |     |                                             /   |   \
  |  B-----F-----C                                      F----+----E
  |   (y=360)                                            (底面 FED)
  |                                                          |
  |   [旋转轨迹圆弧：蓝色，中心 G]                            |
  |                                                          |
  +----------------------------------------------------------+
  |              [◀上一步]  步骤 1/4  [下一步▶]                |
  |              (y=440~490 控件区)                           |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量 (0-4)，每个状态对应一组可见元素
  2. 元素分组：将 SVG 元素按状态分组，使用 class="step-0"、"step-1"等标识
  3. 动画曲线：旋转轨迹使用 CSS transition，opacity 和 stroke-dashoffset 实现渐显
  4. 事件绑定：按钮点击事件切换 currentState，调用 updateDisplay() 函数更新可见性
  5. 按钮状态：第一步禁用「上一步」，最后一步禁用「下一步」
- ID 命名规范：
  - 所有元素 ID 以 scene1- 为前缀
  - 点：scene1-point-a, scene1-point-b, scene1-point-a-prime
  - 线段：scene1-line-ab, scene1-line-af, scene1-line-de
  - 标签：scene1-label-a, scene1-label-b, scene1-label-a-prime
  - 按钮：scene1-btn-prev, scene1-btn-next, scene1-step-indicator
  - 分组：scene1-group-plane, scene1-group-solid, scene1-group-trajectory
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
- CDN 引入：无需额外库，使用原生 SVG 和 JavaScript
