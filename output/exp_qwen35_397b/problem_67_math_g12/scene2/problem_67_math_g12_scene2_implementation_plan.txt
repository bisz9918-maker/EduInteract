[图示主题与整合说明]
- 本图示主题：椭圆几何性质验证——PM 与椭圆相切及 PM 平分∠FPD
- 整合的步骤/概念：
  1. 基础几何结构展示（椭圆、顶点、焦点、切线、关键点）
  2. PM 线段与椭圆的位置关系高亮
  3. P 点附近放大视图展示切点唯一性
  4. P 点处理论切线与 PM 重合验证
  5. ∠FPM 与∠MPD 角度高亮对比
  6. 拖拽 P 点动态验证角平分性质恒成立
- 教学价值：教师可通过分步演示引导学生观察 PM 与椭圆的切线关系，通过放大视图直观理解"仅有一个公共点"的切线定义，通过角度高亮和拖拽交互验证角平分性质的不变性，帮助学生建立几何直观与代数证明的联系

[分步序列]
- 初始状态（步骤 0）：显示完整基础结构
  · 椭圆曲线、坐标轴、所有点 (A,B,O,F,P,D,M)、切线 l
  · 线段 AP、PD、PF、PM（PM 为灰色，与其他辅助线相同）
  · 所有点标签 (A,B,O,F,P,D,M,l)
  · 不显示角度标记、不显示理论切线、不显示放大视图

- 步骤 1：高亮 PM 线段
  · PM 线段从灰色变为红色加粗 (#c62828, 3px)
  · P 点附近椭圆弧段高亮显示（黄色半透明填充，表示关注区域）
  · 文字提示："观察线段 PM 与椭圆的位置关系"

- 步骤 2：放大 P 点附近视图
  · 右下角显示放大视图框 (620,320)-(780,420)
  · 放大视图内显示 P 点附近椭圆弧段（放大 3 倍）
  · 放大视图内显示 PM 线段（红色加粗）
  · 文字提示："放大观察：PM 与椭圆在 P 点附近仅有一个公共点"

- 步骤 3：添加 P 点处理论切线
  · 在主视图中显示过 P 点的椭圆理论切线（绿色虚线 #2e7d32）
  · 理论切线与 PM 线段完全重合（验证 PM 即为切线）
  · 放大视图中同时显示理论切线（与 PM 重合）
  · 显示绿色对勾标记✓表示验证通过
  · 文字提示："PM 与 P 点处椭圆切线重合 → 结论②正确"

- 步骤 4：高亮角度∠FPM 和∠MPD
  · 显示∠FPM 角度弧（蓝色扇形，中心 P，从 PF 到 PM）
  · 显示∠MPD 角度弧（蓝色扇形，中心 P，从 PM 到 PD）
  · 显示角度标签∠3 和∠4
  · 两角度弧线用相同颜色和大小的弧线表示相等
  · 文字提示："观察∠FPM(∠3)与∠MPD(∠4)的大小关系"

- 步骤 5：拖拽 P 点验证
  · P 点变为可拖拽状态（光标变为 move）
  · 拖拽 P 点沿椭圆移动时，所有相关元素实时更新：
    - 线段 AP、PD、PF、PM 自动重绘
    - 点 D、M 位置自动更新
    - 角度弧∠FPM、∠MPD 实时更新
    - 放大视图内容实时更新
  · 文字提示："拖拽 P 点，观察∠3 与∠4 始终相等 → 结论③正确"
  · 显示动态角度数值（可选）

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）+ 步骤 5 拖拽交互
- 控件说明：
  · 按钮"◀ 上一步"：位置 (320,455)，尺寸 80×30px，背景#e0e0e0，点击返回上一状态
  · 按钮"下一步 ▶"：位置 (420,455)，尺寸 80×30px，背景#1565c0 白色文字，点击进入下一状态
  · 状态指示器：位置 (520,460)，显示"步骤 X/5"，文字#666666
  · 步骤 5 时 P 点启用拖拽：cursor: move，拖拽范围沿椭圆路径约束
- 教师操作流程：
  1. 初始状态展示完整几何结构，讲解题目条件
  2. 点击"下一步"高亮 PM，引导学生观察 PM 与椭圆关系
  3. 点击"下一步"显示放大视图，直观展示切点唯一性
  4. 点击"下一步"显示理论切线，验证 PM 即为切线（结论②）
  5. 点击"下一步"显示角度标记，引导学生比较两角大小
  6. 点击"下一步"启用拖拽，邀请学生上台拖动 P 点，验证角平分性质恒成立（结论③）
  7. 可随时点击"上一步"回退复习关键步骤

[技术实现]
- JS 库选择及原因：
  · 原生 SVG：几何图形绘制精确，标签定位准确，无需额外库
  · 原生 JavaScript：拖拽交互、状态切换逻辑简单，无需框架
  · 无需 MathJax：本场景无复杂公式显示
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │                    主视图区 (800×420)                        │
  │                                                             │
  │         Y                                                   │
  │         ↑                                                   │
  │         │        D                                          │
  │         │       /│                                          │
  │         │      P M│                                         │
  │         │     / │ │                                         │
  │    A────┼────O───F─B───────→ X                              │
  │         │         │                                         │
  │         │         │ l                                       │
  │         │                                                 │
  │                                    ┌──────────────┐         │
  │                                    │  放大视图    │         │
  │                                    │  (P 点附近)  │         │
  │                                    └──────────────┘         │
  │                                                             │
  ├─────────────────────────────────────────────────────────────┤
  │  控件栏 (y=440~490)                                         │
  │         [◀ 上一步]  [下一步 ▶]     步骤 1/5                  │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用 scene2-currentStep 变量跟踪当前步骤 (0-5)，每一步定义显示/隐藏的元素 ID 列表
  2. 椭圆参数方程：P 点坐标用参数θ表示 (x=350+200cosθ, y=250+120sinθ)，拖拽时根据鼠标位置反算θ
  3. 切线斜率计算：椭圆上点 (x₀,y₀) 处切线斜率 k = -(b²x₀)/(a²y₀)，用于绘制理论切线
  4. 角度弧绘制：使用 SVG path 的 A 命令绘制圆弧，扇形填充用 opacity=0.2
  5. 放大视图：使用 SVG <g> 元素配合 transform="scale(3) translate(...)"实现局部放大
  6. 拖拽约束：监听 mousedown/mousemove/mouseup 事件，P 点移动时重新计算 D、M 位置并更新所有相关线段
  7. 元素更新：使用 requestAnimationFrame 保证拖拽时动画流畅
- ID 命名规范：
  · 所有元素 ID 以 scene2- 为前缀
  · 示例：scene2-ellipse, scene2-point-p, scene2-line-pm, scene2-angle-fpm, scene2-zoom-view
  · 按钮 ID：scene2-btn-prev, scene2-btn-next, scene2-step-indicator
