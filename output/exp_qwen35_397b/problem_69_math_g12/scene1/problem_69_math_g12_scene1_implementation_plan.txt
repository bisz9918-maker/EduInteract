[分步序列]
- 初始状态（步骤 0）：显示三棱柱完整线框（6 条可见棱实线，1 条不可见棱 AC 虚线），6 个顶点标签 A, B, C, A₁, B₁, C₁，对角线 A₁B
- 步骤 1：点击「下一步」→ 显示三条已知棱长标注：AA₁=8（右侧），A₁B₁=6（上方），A₁C₁=2√34（上方）
- 步骤 2：点击「下一步」→ 上底面△A₁B₁C₁ 高亮：边框变为红色 3px，内部填充红色 15% 透明度，同时在∠A₁B₁C₁ 处显示蓝色直角符号
- 步骤 3：点击「下一步」→ 显示计算结果 B₁C₁=10（蓝色标注，位于 B₁C₁ 上方），强调底面是直角三角形，由勾股定理得 B₁C₁=√(6²+(2√34)²-2×6×2√34×cos90°)=√(36+136)=√172≠10，实际应为 B₁C₁=√(A₁C₁²-A₁B₁²)=√(136-36)=√100=10
- 步骤 4：点击「下一步」→ 在 A₁ 点处显示垂直符号（表示 AA₁⊥上底面），所有元素完整展示

- "A₁"(600,215) 与 "AA₁=8"(595,310)：y 间距 95px → 无冲突
- "B₁"(435,155) 与 "A₁B₁=6"(500,175)：距离≈68px → 无冲突
- "C₁"(205,135) 与 "B₁C₁=10"(310,135)：x 间距 105px → 无冲突
- "A₁C₁=2√34"(400,165) 与 "B₁"(435,155)：距离≈37px → 无冲突
- "A₁C₁=2√34"(400,165) 与 "A₁B₁=6"(500,175)：x 间距 100px → 无冲突

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 底部左侧 (x=320, y=460)，点击回退到前一状态
  - 「下一步」按钮：位于 SVG 底部右侧 (x=460, y=460)，点击进入下一状态
  - 步骤指示器：位于底部中央 (x=400, y=460)，显示「步骤 X/5」
- 教师操作流程：
  1. 初始展示三棱柱线框，让学生观察整体结构
  2. 点击「下一步」标注已知棱长，引导学生关注已知条件
  3. 点击「下一步」高亮上底面并显示直角符号，强调底面是直角三角形
  4. 点击「下一步」显示 B₁C₁ 计算结果，复习勾股定理应用
  5. 点击「下一步」显示垂直关系，总结直三棱柱特征

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |                    C₁                            |
  |                   /  \                           |
  |                  /    \ A₁                       |
  |                 /______\____ B₁                  |
  |                |      / |                        |
  |                |     /  |                        |
  |                |    /   |                        |
  |                |   /    |                        |
  |                |  /     |                        |
  |                | /      |                        |
  |                |/       |                        |
  |                C________B_______ A               |
  |                                                  |
  |                                                  |
  |                                                  |
  |     [◀上一步]    步骤 X/5    [下一步▶]           |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用 currentState 变量（0-4）跟踪当前步骤，steps 数组存储每步应显示的元素 ID 列表
  2. 坐标计算：采用斜二测投影，z 轴（竖直方向）保持原长，x 轴水平，y 轴与水平成 45° 缩短为一半
  3. 动画曲线：元素淡入使用 CSS transition opacity 0.3s ease
  4. 事件绑定：按钮点击事件切换状态，调用 updateDisplay() 函数更新可见性
  5. 虚线实现：SVG stroke-dasharray="5,5"
- ID 命名规范：所有元素 ID 以 scene1- 为前缀，如 scene1-edge-AA1, scene1-label-A1, scene1-btn-next
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
