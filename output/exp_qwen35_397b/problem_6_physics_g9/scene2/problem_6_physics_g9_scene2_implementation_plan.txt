[分步序列]
- 初始状态（步骤 0）：显示弹簧测力计悬挂铁球的整体图、铁球受力放大图（三个力向量 G、F 拉、F 吸 均以默认透明度显示）、平衡方程框显示"F 拉 = G - F 吸"、结论框空白
- 步骤 1：点击「下一步」→ 重力 G 向量高亮（蓝色加粗，透明度 100%），右侧出现"重力不变"标签，其他力向量透明度降至 40%
- 步骤 2：点击「下一步」→ F 吸 向量高亮（红色加粗），箭头从 (400,330) 动画缩短至 (400,310) 表示吸引力减小，左侧出现"磁性减弱→吸引力减小"标签
- 步骤 3：点击「下一步」→ F 拉 向量高亮（绿色加粗），平衡方程框中"F 拉 = G - F 吸"高亮显示，F 吸 减小则 F 拉 减小的推导文字出现
- 步骤 4：点击「下一步」→ 弹簧测力计指针从 y=130 动画上移至 y=115 表示示数变小，右侧出现"示数变小"标签，结论框显示"弹簧测力计示数变小"
- 最终步骤（步骤 5）：所有元素完整显示，结论框显示完整受力变化链："滑片右移→电阻变大→电流变小→磁性减弱→F 吸 减小→F 拉 减小→示数变小"

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 (250,470)-(350,495)，点击回退到上一状态
  - 「下一步」按钮：位于 (450,470)-(550,495)，点击进入下一状态
- 教师操作流程：
  1. 初始状态展示铁球受力全貌，教师介绍三个力的来源
  2. 点击「下一步」高亮重力，强调重力恒定不变
  3. 点击「下一步」展示吸引力变化动画，解释滑片右移导致磁性减弱
  4. 点击「下一步」推导平衡方程，引导学生理解 F 拉 随 F 吸 变化
  5. 点击「下一步」展示测力计指针上移，直观呈现示数变小
  6. 最终步骤总结完整变化链，强化因果关系

[技术实现]
- JS 库选择及原因：原生 SVG（简单几何图形和箭头绘制，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────┐
  │                    弹簧测力计                        │ y=50-180
  │                       铁球                          │ y=185-205
  │                                                     │
  │              铁球受力放大图（三力向量）              │ y=250-340
  │                    电磁铁上端                        │ y=320-380
  │                                                     │
  │              [平衡方程框 F 拉 = G - F 吸]            │ y=390-425
  │              [结论框：示数变小/变化链]               │ y=430-460
  │                                                     │
  │         [◀上一步]              [下一步▶]            │ y=470-495
  └─────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-5），steps 数组存储每步的显示配置
  2. 向量箭头：使用 SVG <marker> 定义箭头，<line> + <marker-end> 绘制
  3. 动画实现：F 吸 向量长度动画使用 requestAnimationFrame 插值，指针上移动画同理
  4. 事件绑定：按钮点击事件切换 currentState，调用 renderState() 更新显示
  5. 透明度控制：通过 opacity 属性控制非高亮元素的视觉权重
- ID 命名规范：所有交互元素 ID 必须以 scene2- 为前缀（如 scene2-ball-force、scene2-arrow-G、scene2-btn-next）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
