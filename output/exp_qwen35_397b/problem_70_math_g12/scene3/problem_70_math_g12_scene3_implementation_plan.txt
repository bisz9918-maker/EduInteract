[视觉元素清单]
- 四棱锥 P-ABCD：6 条棱线，其中 3 条可见棱（PA、AB、BC、PB、PC）用黑色/蓝色实线，3 条不可见棱（AD、CD、PD）用灰色虚线 #888888
- 点 M：PC 上的定点，位置满足 DM⊥PC
- 线段 DM：红色 #c62828 实线，连接 D 和 M
- 线段 BM：红色 #c62828 实线，连接 B 和 M
- 线段 BD：绿色 #2e7d32 实线，底面对角线
- 线段 PC：蓝色 #1565c0 实线，侧棱
- 垂直符号：红色直角标记表示 DM⊥PC，绿色直角标记表示 BD⊥PC
- 平面 MBD：蓝色 #1565c0 透明度 15% 填充三角形 MBD
- 平面 PCD：绿色 #2e7d32 透明度 15% 填充三角形 PCD
- 顶点标签：P、A、B、C、D、M 共 6 个，黑色字体，位置避开棱线
- 答案文本框：绿色边框 #2e7d32，内含"DM⊥PC"

[分步序列]
- 初始状态（步骤 0）：显示四棱锥 P-ABCD 基础框架（所有棱线），显示点 M 在 PC 上的位置，显示线段 DM（红色），显示 DM⊥PC 的垂直符号（红色直角标记）。此时其他元素隐藏。
- 步骤 1：点击「下一步」→ 高亮显示线段 BD（绿色实线），显示 BD 与 PC 的垂直关系（在交点处显示绿色直角符号）。视觉上强调 BD⊥PC。
- 步骤 2：点击「下一步」→ 显示平面 MBD 的半透明填充（蓝色 15%），同时显示线段 BM（红色）。文字提示"PC⊥平面 MBD"（因为 PC 垂直于平面 MBD 内的两条相交直线 DM 和 BD）。
- 步骤 3：点击「下一步」→ 显示平面 PCD 的半透明填充（绿色 15%），在两个平面交线 PC 附近显示平面垂直标记。文字提示"平面 MBD⊥平面 PCD"（因为 PC 在平面 PCD 内且 PC⊥平面 MBD）。
- 步骤 4：点击「下一步」→ 在右下角显示答案文本框，绿色边框，内含"DM⊥PC"。所有元素完整显示，证明链条完成。

[标签冲突检查]
- 标签"P"：坐标(210, 70)
- 标签"A"：坐标(210, 380)
- 标签"B"：坐标(595, 395)
- 标签"C"：坐标(695, 300)
- 标签"D"：坐标(305, 300)
- 标签"M"：坐标(535, 210)
- 答案文本框：(600, 420) 起始

冲突检查：
- "P"与"A"：y 方向距离 310px → 无冲突
- "P"与"D"：距离约 235px → 无冲突
- "A"与"D"：距离约 115px → 无冲突
- "B"与"C"：距离约 120px → 无冲突
- "C"与"D"：x 方向距离 390px → 无冲突
- "M"与"C"：距离约 170px → 无冲突
- "M"与"P"：距离约 150px → 无冲突
- 答案文本框与标签"B"：y 方向距离约 25px，x 方向距离约 5px → 需调整答案框位置至 (620, 430)
- 答案文本框与标签"C"：距离约 130px → 无冲突

解决方案：答案文本框调整至 (620, 430)，确保与所有顶点标签间距 ≥ 20px。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于底部左侧 (250, 455)，返回上一状态
  - 「下一步」按钮：位于底部右侧 (450, 455)，进入下一状态
  - 步骤指示器：位于两按钮之间 (380, 460)，显示"步骤 X/4"
- 教师操作流程：
  1. 初始状态展示四棱锥和 DM⊥PC 条件，提问学生"从这个条件能推出什么？"
  2. 点击「下一步」展示 BD⊥PC，引导学生发现 PC 垂直于平面 MBD 内的两条直线
  3. 点击「下一步」展示平面 MBD 填充，引出"PC⊥平面 MBD"的结论
  4. 点击「下一步」展示平面 PCD 填充和垂直标记，完成"平面 MBD⊥平面 PCD"的证明
  5. 点击「下一步」显示最终答案，总结整个逻辑链条

[技术实现]
- JS 库选择及原因：原生 SVG。理由：四棱锥为静态几何图形，只需简单的线条、多边形填充和直角符号，原生 SVG 足够且性能最优，无需额外库依赖。
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +------------------------------------------+
  |                                          |
  |           P                              |
  |          /|\                             |
  |         / | \                            |
  |        /  |  \                           |
  |       D---M---C                          |
  |        \  |  /                           |
  |         \ | /                            |
  |          \|/                             |
  |           A-----B                        |
  |                                          |
  |                              [答案框]    |
  |                                          |
  |              [◀上一步] [步骤 2/4] [下一步▶]|
  +------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-4），每个状态对应一组可见元素
  2. 坐标计算：M 点坐标需满足 DM⊥PC，通过向量点积为 0 计算得出 M(520, 220)
  3. 垂直符号绘制：使用两条短线段构成直角，长度 15px
  4. 平面填充：使用 polygon 元素，fill-opacity="0.15"
  5. 事件绑定：按钮点击事件切换 currentState，调用 updateScene() 更新可见性
  6. 元素可见性：通过 display 属性或 opacity 控制
- ID 命名规范：所有元素 ID 以 scene3- 为前缀，如 scene3-vertex-p、scene3-edge-dm、scene3-plane-mbd 等
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
