[图示主题与整合说明]
- 本图示主题：正六边形内接于圆的结构及向量夹角定义
- 整合内容：正六边形顶点标注、各顶点方向角、向量夹角 θᵢ 的定义示意、点 P 位置与夹角关系
- 教学价值：教师可逐步展示正六边形的对称性、各顶点的方向角分布、点 P 与顶点向量夹角的几何意义，帮助学生理解夹角序列成等差数列的条件，进而求解第 3 项

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript。原因：本图示为 2D 几何图形，无复杂动画或交互，原生 SVG 足够胜任，且代码简洁、性能好、无需额外依赖。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +----------------------------------------------------------+
  |                    [图示区 800×440]                       |
  |                                                          |
  |         A₃        A₂                                     |
  |           \      /                                       |
  |       A₄---O----A₁    (圆与正六边形居中)                  |
  |           /      \                                       |
  |         A₅        A₆                                     |
  |                                                          |
  |                              [右侧表达式区]               |
  |                              θ₁ = |φ - 0°|              |
  |                              θ₂ = |φ - 60°|             |
  |                              ...                         |
  |                                                          |
  +----------------------------------------------------------+
  |  [◀ 上一步]  [下一步 ▶]      当前步骤说明文字              |
  |                    [控件栏 y=440~500]                     |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-4) 跟踪当前步骤，数组 steps 存储每步的可见元素 ID 列表
  2. 坐标计算：顶点坐标预计算为常量，避免运行时重复计算三角函数
  3. 角度弧线：使用 SVG path 的 A 命令绘制圆弧，起点和终点通过极坐标转换得到
  4. 事件绑定：按钮点击事件绑定到 stepForward() 和 stepBackward() 函数，更新 visibleElements 并重绘
  5. 元素显隐：每步切换时，遍历所有元素，根据当前步骤的可见列表设置 display 属性
  6. 按钮状态：步骤 0 时禁用「上一步」，步骤 4 时禁用「下一步」
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀，例如：
  - scene1-circle-o（圆）
  - scene1-hexagon（正六边形）
  - scene1-radius-oa1 至 scene1-radius-oa6（半径）
  - scene1-vertex-a1 至 scene1-vertex-a6（顶点）
  - scene1-label-a1 至 scene1-label-a6（顶点标签）
  - scene1-label-o（圆心标签）
  - scene1-angle-0 至 scene1-angle-300（方向角数值）
  - scene1-point-p（点 P）
  - scene1-vector-op（向量 OP）
  - scene1-label-p（点 P 标签）
  - scene1-label-phi（φ 标签）
  - scene1-arc-theta1、scene1-arc-theta2（角度弧线）
  - scene1-label-theta1、scene1-label-theta2（夹角标签）
  - scene1-expr-list（夹角表达式列表）
  - scene1-btn-prev、scene1-btn-next（导航按钮）
  - scene1-step-desc（步骤说明文字）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
