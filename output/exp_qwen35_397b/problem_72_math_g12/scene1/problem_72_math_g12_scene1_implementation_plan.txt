[视觉元素清单]
- 三视图区域（左侧 x=20~340）：
  - 主视图：等腰三角形，轮廓线 #000000 实线 2px，底边 120px（代表 6 单位），高 40px（代表 4 单位）
  - 俯视图：矩形，轮廓线 #000000 实线 2px，长 120px 宽 60px
  - 侧视图：直角三角形，轮廓线 #000000 实线 2px，底 60px（代表 2 单位），高 40px
  - 尺寸标注线：#000000 细实线 1px，带箭头
  - 标签：黑体 14px，#000000

- 四棱锥立体图区域（右侧 x=400~780）：
  - 底面矩形：#1565c0 实线 2px，透视效果
  - 棱线：#1565c0 实线 2px（可见棱），#888888 虚线 1px（被遮挡棱）
  - 顶点 P：#1565c0 实心圆 r=4
  - 高线：#888888 虚线 1px
  - 标签：#1565c0 黑体 14px

- 对应关系连线：#888888 虚线 1px，连接三视图与立体图对应点
- 高亮元素：#2e7d32 用于当前步骤强调

[分步序列]
- 步骤 0（初始状态）：仅显示三视图（主视图、俯视图、侧视图）及尺寸标注，右侧立体图区域空白
- 步骤 1：高亮主视图与俯视图的"长对正"关系，显示两条垂直虚线连接主视图底边端点与俯视图对应端点
- 步骤 2：高亮侧视图与俯视图的"宽相等"关系，显示水平虚线连接侧视图与俯视图的宽度对应点
- 步骤 3：显示四棱锥高度信息，在右侧区域显示顶点 P 的投影位置和高 h=4 标注
- 步骤 4：逐步连接棱线，先显示底面矩形，再依次显示四条棱线 PA、PB、PC、PD
- 步骤 5（最终状态）：完整四棱锥立体图，所有棱线显示，标注顶点 P 和高 h=4，显示对应关系虚线

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 底部左侧 (x=350, y=455)，返回上一状态
  - 「下一步」按钮：位于 SVG 底部右侧 (x=450, y=455)，进入下一状态
  - 步骤指示器：位于底部中央 (x=400, y=455)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始展示三视图，让学生观察三个视图的形状和尺寸
  2. 点击「下一步」高亮长对正关系，讲解主视图与俯视图的长度对应
  3. 点击「下一步」高亮宽相等关系，讲解侧视图与俯视图的宽度对应
  4. 点击「下一步」显示高度信息，确定顶点位置
  5. 点击「下一步」逐步连接棱线，展示立体图构建过程
  6. 点击「下一步」完成立体图，总结四棱锥结构特征

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +------------------------------------------+
  |  三视图区 (320px)  |  立体图区 (480px)   |
  |  +------------+    |                     |
  |  |  主视图    |    |                     |
  |  |  侧视图    |    |    四棱锥立体图     |
  |  +------------+    |                     |
  |  |  俯视图    |    |                     |
  |  +------------+    |                     |
  +------------------------------------------+
  |  [◀上一步]  步骤 X/5  [下一步▶]          |
  +------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 state 变量 (0-5) 跟踪当前步骤，steps 数组存储每步显示的元素 ID 列表
  2. 坐标计算：三视图按 1 单位=20px 比例缩放，立体图采用斜二测投影
  3. 动画曲线：元素淡入使用 CSS transition opacity 0.3s ease
  4. 事件绑定：按钮点击事件切换状态，更新元素 display/opacity 属性
  5. 高亮效果：当前步骤元素添加 stroke="#2e7d32" stroke-width="3"
- ID 命名规范：所有元素 ID 以 scene1- 为前缀，如 scene1-main-view、scene1-pyramid-base、scene1-vertex-p
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
