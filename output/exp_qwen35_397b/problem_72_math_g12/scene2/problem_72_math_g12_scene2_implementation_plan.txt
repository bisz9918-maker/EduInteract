[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 (320,460)，点击后回退到前一状态
  - 「下一步」按钮：位于 (420,460)，点击后进入下一状态
  - 步骤指示器：位于 (380,440)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始状态展示底面，讲解底面积计算
  2. 点击「下一步」展开前侧面，讲解前侧面斜高计算（勾股定理：√(3²+4²)=5）和面积
  3. 点击「下一步」展开后侧面，说明与前侧面全等
  4. 点击「下一步」展开左侧面，讲解左侧面斜高计算（√(1²+4²)=√17）和面积
  5. 点击「下一步」展开右侧面，说明与左侧面全等
  6. 点击「下一步」显示总面积汇总，完成表面积计算

[技术实现]
- JS 库选择：原生 SVG（适合几何图形绘制，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |                    前侧面                         |
  |                   (三角形)                        |
  |                                                  |
  |         左侧面    底面    右侧面                  |
  |        (三角形)  (矩形)  (三角形)                 |
  |                                                  |
  |                    后侧面                         |
  |                   (三角形)                        |
  |                                                  |
  |                              [总面积汇总]         |
  |                                                  |
  |              [◀上一步]  步骤 X/5  [下一步▶]       |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量（0-5），每个步骤对应一组可见元素
  2. 展开动画：使用 SVG transform rotate 实现三角形从折叠到展开的旋转动画（从 90 度旋转到 0 度）
  3. 坐标计算：底面矩形中心 (400,250)，各三角形以底面边为轴展开
  4. 事件绑定：按钮点击事件切换 currentStep，更新各元素 display 属性
  5. 斜高计算：前/后侧斜高 = √(3²+4²) = 5；左/右侧斜高 = √(1²+4²) = √17
- ID 命名规范：所有元素 ID 以 scene2- 为前缀，如 scene2-base-rect、scene2-front-tri、scene2-btn-next 等
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
