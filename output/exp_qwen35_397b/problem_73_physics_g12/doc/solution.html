problem_73_physics_g12

场景导航：Scene 1 | Scene 2 | Scene 3

题目原文：

如图所示，U形导体框架的宽度为L=1m，其所在平面与水平面夹角θ=30°，其电阻可以忽略不计。设匀强磁场与U形框架的平面垂直，磁感强度B=0.2Wb/m²。今有一条形导体棒MN，其质量m=0.2kg，其电阻R=0.2Ω，跨放在U形框架（足够长）上，并能无摩擦地滑动，求：
（1）导体棒MN下滑过程的最大速度v_m；
（2）在最大速度v_m时，在导体棒MN上释放出来的电功率P；
（3）若导体棒从开始下滑到达到最大速度这一过程中导体棒消耗的电能为Q_电=1.5J，则此过程中通过导体棒横截面积的电量q是多少？

题目分析：

本题是电磁感应与力学综合问题。导体棒沿倾斜导轨下滑时切割磁感线产生感应电动势，形成感应电流，进而受到安培力作用。安培力方向沿斜面向上，与重力沿斜面分力方向相反。

核心物理过程：

  1. 初始阶段：重力分力大于安培力，导体棒加速下滑
  2. 随着速度增大，感应电动势E=BLv增大，感应电流I增大，安培力F=BIL增大
  3. 当安培力等于重力沿斜面分力时，加速度为零，达到最大速度（收尾速度）

整体讲解思路：

第一步：受力分析，建立动力学方程
第二步：推导最大速度表达式并计算
第三步：计算电功率
第四步：利用能量守恒和电量公式求解第三问

教学说明：

本图示帮助学生建立空间想象并理解受力关系。教师应引导学生：

  1. 观察装置的空间结构：U形框架倾斜放置，磁场垂直于框架平面
  2. 理解导体棒下滑时切割磁感线，根据右手定则判断感应电流方向（N→M）
  3. 根据左手定则判断安培力方向（沿斜面向上，阻碍导体棒运动）
  4. 重力分解：沿斜面分力mgsinθ使棒下滑，垂直斜面分力mgcosθ与支持力平衡

关键公式：

感应电动势：E = BLv

感应电流：I = E/R = BLv/R

安培力：F_安 = BIL = B²L²v/R

平衡条件（最大速度时）：mgsinθ = F安 = B²L²vm/R

解得最大速度：v_m = mgRsinθ/(B²L²)

教学说明：

本图示展示导体棒从静止到达到最大速度的动态过程。教师应强调：

  1. 初始时刻t=0：v=0，安培力为0，加速度最大（a₀=gsinθ）
  2. 随着v增大，安培力增大，加速度减小（变加速运动）
  3. 当t→∞时，v→v_m，a→0，导体棒做匀速运动

最大速度计算：

代入数据：m=0.2kg，g=10m/s²，θ=30°，B=0.2T，L=1m，R=0.2Ω

v_m = mgRsinθ/(B²L²) = 0.2×10×0.2×sin30°/(0.2²×1²) = 0.4×0.5/0.04 = 5 m/s

最大速度时的电功率：

P = I²R = (BLvm/R)²R = B²L²vm²/R

或 P = F安·vm = mgsinθ·v_m = 0.2×10×0.5×5 = 5 W

教学说明：

第三问是本题难点，涉及能量守恒和电量的综合应用。教师应引导学生：

  1. 理解能量转化：重力势能减少量 = 动能增加量 + 电能消耗量
  2. 掌握电量的两种求法：q = It（恒定电流）或 q = ∫Idt = ΔΦ/R（变化电流）
  3. 本题用 q = BLx/R 更简便，关键是通过能量守恒求出位移x

完整解答：

（1）最大速度：v_m = mgRsinθ/(B²L²) = 5 m/s

（2）最大速度时电功率：P = mgsinθ·v_m = 0.2×10×0.5×5 = 5 W

（3）电量计算：

  • 由能量守恒：mgx·sinθ = ½mvm² + Q电
  • 代入数据：0.2×10×x×0.5 = ½×0.2×25 + 1.5
  • 解得：x = 4 m
  • 电量：q = BLx/R = 0.2×1×4/0.2 = 4 C
