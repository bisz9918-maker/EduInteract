- 步骤 1：点击「下一步」→ 添加重力 mg 箭头及标签、重力分力 mgsinθ和 mgcosθ虚线箭头及标签（右侧受力分析区）
- 步骤 2：点击「下一步」→ 添加安培力 F_安箭头及标签（蓝色，沿斜面向上）
- 步骤 3：点击「下一步」→ 添加感应电流 I 箭头及标签（橙色，导体棒内从 N 到 M 方向）
- 步骤 4：点击「下一步」→ 平衡状态高亮：mgsinθ与 F_安箭头加粗显示，添加平衡标注"mgsinθ = F_安"

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 (280,450)，宽 100px，高 30px，点击返回上一状态
  - 「下一步」按钮：位于 (420,450)，宽 100px，高 30px，点击进入下一状态
  - 步骤指示器：位于 (390,455)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始展示装置结构，讲解 U 形框架和磁场配置
  2. 点击「下一步」展示重力分解，讲解斜面受力特点
  3. 点击「下一步」添加安培力，讲解电磁感应产生的阻力
  4. 点击「下一步」展示感应电流方向，讲解右手定则
  5. 点击「下一步」高亮平衡条件，讲解最大速度时的受力平衡

[技术实现]
- JS 库选择：原生 SVG（几何图形精确绘制）+ 原生 JavaScript（状态管理）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  [左侧装置区 60%]    |    [右侧受力区 40%]       |
  |  x:50-450            |    x:480-780              |
  |  y:80-380            |    y:80-380               |
  |  - U 形导轨           |    - 受力分析矢量图        |
  |  - 导体棒 MN          |    - mg/mgsinθ/mgcosθ    |
  |  - 磁场 B             |    - F_安                 |
  |  - 角度θ              |                           |
  |                        |                           |
  |  [步骤指示器/按钮区 y:440-490]                    |
  |  [◀上一步]  步骤 X/5  [下一步▶]                   |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量 (0-4) 跟踪当前步骤
  2. 元素分组：按步骤将 SVG 元素分组 (g 标签)，用 display 控制显示/隐藏
  3. 坐标计算：斜面 30°倾角，使用 Math.sin(30°)=0.5, Math.cos(30°)≈0.866
  4. 事件绑定：按钮点击事件切换状态，更新元素显示和步骤指示器
  5. 高亮效果：步骤 4 时给 mgsinθ和 F_安添加 stroke-width 加粗和 fill 高亮
- ID 命名规范：所有元素 ID 以 scene1-为前缀
  - scene1-rail-left, scene1-rail-right, scene1-rail-bottom
  - scene1-rod-mn, scene1-field-b, scene1-angle-arc
  - scene1-label-m, scene1-label-n, scene1-label-b, scene1-label-theta
  - scene1-force-mg, scene1-force-mgsin, scene1-force-mgcos
  - scene1-force-ampere, scene1-current-i
  - scene1-btn-prev, scene1-btn-next, scene1-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
