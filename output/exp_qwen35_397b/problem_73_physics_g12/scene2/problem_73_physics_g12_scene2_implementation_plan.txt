[图示主题与整合说明]
- 本图示主题：导体棒速度随时间变化图像（v-t图）
- 整合的步骤/概念：速度-时间曲线、加速度变化、收尾速度的渐近线、关键物理量标注
- 教学价值：教师通过拖动时间滑块，学生可直观观察速度从0逐渐增大到v_m的动态过程，理解"收尾速度"的渐近特性。曲线斜率（加速度）逐渐减小，最终趋近于零，帮助学生建立电磁感应中动态平衡的物理图像。

[分步序列]
本场景为连续拖拽交互，无分步导航。状态由滑块位置连续决定：
- 初始状态（t=0）：滑块在最左端，当前点在原点(80,400)，v=0，a=gsinθ=4.9m/s²，切线斜率最大
- 拖动过程：滑块右移→当前点沿曲线移动→v增大→a减小→切线斜率减小
- 中间状态示例（t=1s）：v≈3.09m/s，a≈1.80m/s²
- 最终状态（t=5s）：滑块在最右端，当前点接近(580,165)，v≈4.87m/s≈v_m，a≈0.03m/s²≈0，切线接近水平

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：
  - 时间滑块：位于SVG底部y=450~485区域，范围0-5s，对应像素x=150~550
  - 滑块手柄：圆形，可左右拖拽，限制在轨道范围内
  - 数值面板：实时显示当前t、v、a值，位于图右侧
- 教师操作流程：
  1. 初始状态展示v-t曲线全貌和渐近线
  2. 拖动滑块从0开始，讲解"初始时刻速度为0，加速度最大"
  3. 缓慢右移滑块，观察速度增长、加速度减小
  4. 停在t=1s处，讲解时间常数的物理意义
  5. 继续移至t=5s，讲解"收尾速度"的渐近特性
  6. 可来回拖动，对比不同时刻的状态

[技术实现]
- JS 库选择：原生SVG + 原生JavaScript
  - 原因：v-t曲线为2D函数图，原生SVG足够；拖拽交互简单，无需额外库
- 画布尺寸：800×500px（固定）
- 布局草图：
  ```
  +--------------------------------------------------+
  |  v/(m·s⁻¹)                                       |
  |     |                              [数值面板]    |
  |  v_m|---------------------------  | t=...      |  |
  |     |                          .  | v=...      |  |
  |     |                       .     | a=...      |  |
  |     |                    .        |            |  |
  |     |                 .           |            |  |
  |     |              .              |            |  |
  |   O +-----------.-----------------+------------+  |
  |     0           1    2    3    4    5   t/s       |
  |                                                    |
  |     时间 t [====●========]  0  1  2  3  4  5      |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 物理计算：
     - v_m = mgRsinθ/(B²L²) = 4.9 m/s
     - τ = mR/(B²L²) = 1.0 s
     - v(t) = v_m × (1 - e^(-t/τ))
     - a(t) = gsinθ × e^(-t/τ) = 4.9 × e^(-t)
  2. 坐标映射：
     - t轴：0-5s → x=80-580px（比例100px/s）
     - v轴：0-6m/s → y=400-80px（比例约53.3px/(m/s)，原点在左下）
  3. 曲线绘制：使用SVG <path>，d属性用L命令连接多个采样点（t从0到5，步长0.05）
  4. 拖拽交互：
     - mousedown：记录初始位置，设置dragging标志
     - mousemove：计算新x位置，限制在[150,550]，更新滑块和数值
     - mouseup：清除dragging标志
  5. 切线绘制：计算当前点导数dv/dt=a(t)，切线斜率=a×(像素比例)，绘制60px长线段
  6. 状态更新：每次滑块移动，更新当前点cx/cy、切线x1/y1/x2/y2、数值面板textContent
- ID 命名规范：所有元素ID以 scene2- 为前缀
  - scene2-axis-x, scene2-axis-y, scene2-grid-h-1~4, scene2-grid-v-1~5
  - scene2-curve-vt, scene2-asymptote, scene2-current-point, scene2-tangent
  - scene2-panel, scene2-val-t, scene2-val-v, scene2-val-a
  - scene2-slider-track, scene2-slider-handle, scene2-slider-label
- IIFE 隔离：所有JS代码包在 (function() { ... })() 中，避免全局污染
