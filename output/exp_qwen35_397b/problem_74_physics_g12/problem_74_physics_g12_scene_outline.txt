    **题目原文：**

    如图所示，线圈 abcd 每边长 l=0.20m，线圈质量 m₁=0.10kg、电阻 R=0.10Ω，砝码质量 m₂=0.14kg．线圈上方的匀强磁场磁感强度 B=0.5T，方向垂直线圈平面向里，磁场区域的宽度为 h=l=0.20m．砝码从某一位置下降，使 ab 边进入磁场开始做匀速运动．求：
    （1）线圈做匀速运动的速度．
    （2）从 ab 进入磁场到线圈穿出磁场过程中产生的热量．

    **题目分析：**

    本题是电磁感应与力学综合题，核心考点包括：
    1. 动生电动势：E = Blv
    2. 安培力：F = BIl
    3. 受力平衡：匀速运动时合力为零
    4. 能量守恒：重力势能转化为焦耳热

    **整体讲解思路：**

    第一阶段：分析线圈匀速运动时的受力情况，建立平衡方程求解速度
    第二阶段：分析线圈穿越磁场的完整过程，计算产生的焦耳热

    **图示规划说明：**

    - SCENE_1：展示线圈穿越磁场的完整运动过程及受力分析（整合运动过程 + 受力分析）
    - SCENE_2：展示能量转化关系（整合能量守恒分析）

    **教学要点：**

    1. 引导学生观察线圈进入磁场时的电磁感应现象：
       - ab 边切割磁感线产生动生电动势 E = Blv
       - 根据右手定则判断感应电流方向（逆时针）
       - 根据左手定则判断安培力方向（向下，阻碍运动）

    2. 受力分析关键：
       - 线圈匀速运动，合力为零
       - 线圈受力：向上拉力 T，向下重力 m₁g，向下安培力 F_A
       - 砝码受力：向下重力 m₂g，向上拉力 T

    3. 平衡方程推导：
       对线圈：T = m₁g + F_A
       对砝码：T = m₂g
       联立得：m₂g = m₁g + F_A
       即：F_A = (m₂ - m₁)g

    4. 速度求解：
       F_A = BIl = B·(Blv/R)·l = B²l²v/R
       代入得：B²l²v/R = (m₂ - m₁)g
       解得：v = (m₂ - m₁)gR / (B²l²)

    **代入数值：**
    v = (0.14 - 0.10) × 10 × 0.10 / (0.5² × 0.20²) = 0.04 / 0.01 = 4 m/s

    **第二问讲解要点：**

    1. 分析线圈穿越磁场的全过程：
       - 磁场宽度 h = l = 0.20m，线圈边长 l = 0.20m
       - 阶段Ⅰ：ab 边进入至 cd 边刚进入，位移 l，ab 边切割磁感线
       - 阶段Ⅱ：线圈完全在磁场中，位移 h-l = 0（本题此阶段不存在）
       - 阶段Ⅲ：ab 边离开至 cd 边离开，位移 l，cd 边切割磁感线

    2. 感应电流产生条件：
       - 阶段Ⅰ和Ⅲ：有磁通量变化，产生感应电流，有焦耳热
       - 阶段Ⅱ：磁通量不变，无感应电流，无焦耳热

    3. 能量守恒法求解（推荐）：
       从 ab 进入磁场到 cd 离开磁场，线圈上升总高度为 h + l = 2l
       砝码下降高度也为 2l

       能量关系：m₂g·2l = m₁g·2l + Q
       Q = (m₂ - m₁)g·2l
       Q = (0.14 - 0.10) × 10 × 0.40 = 0.16 J

    4. 或用焦耳定律验证：
       匀速运动时间 t = 2l/v = 0.40/4 = 0.1s
       感应电流 I = Blv/R = 0.5×0.20×4/0.10 = 4A
       Q = I²Rt = 4² × 0.10 × 0.1 = 0.16 J（结果一致）

    **答案：**
    （1）线圈做匀速运动的速度 v = 4 m/s
    （2）产生的热量 Q = 0.16 J

    **课堂讲解建议：**
    - 先用 SCENE_1 讲解受力平衡求速度
    - 再用 SCENE_2 讲解能量守恒求热量
    - 强调两种方法（能量法 vs 焦耳定律）的等价性
