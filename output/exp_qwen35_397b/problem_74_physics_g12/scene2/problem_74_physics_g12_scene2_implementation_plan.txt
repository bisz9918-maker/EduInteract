[图示主题与整合说明]
- 本图示主题：线圈穿越磁场全过程与能量转化
- 整合的步骤/概念：线圈三个运动阶段（进入、完全在磁场中、离开）、能量守恒关系、焦耳热计算
- 教学价值：教师可通过分步展示线圈穿越磁场的不同阶段，帮助学生理解电磁感应现象、感应电流产生条件及能量转化关系。分步导航让教师能控制讲解节奏，随时回退复习关键概念。

[分步序列]
- 初始状态（步骤0）：显示磁场区域、三个半透明线圈位置（初始位置在磁场下方y=300-380）、滑轮系统、砝码、能量转化图（灰度显示）。线圈当前位置在初始位置，实线黑色边框。
- 步骤1：点击「下一步」→ 线圈移动到进入磁场位置（y=220-300），ab边进入磁场至cd边刚进入。当前位置线圈边框变为#1565c0高亮，显示阶段标签"Ⅰ"，能量图中砝码势能框高亮，箭头1开始流动动画。
- 步骤2：点击「下一步」→ 线圈完全在磁场中位置（本题h=l，此阶段不存在，线圈直接过渡）。显示阶段标签"Ⅱ"（灰色），提示"此阶段不存在（h=l）"，能量图无变化。
- 步骤3：点击「下一步」→ 线圈移动到离开磁场位置（y=140-220），ab边离开磁场至cd边离开。当前位置线圈边框变为#1565c0高亮，显示阶段标签"Ⅲ"，能量图中焦耳热框高亮显示红色#c62828。
- 步骤4：点击「下一步」→ 能量守恒完整展示。三个能量框全部高亮，箭头流动动画完成，显示能量转化关系式：m₂gh = m₁gh + Q，Q用红色突出显示。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于(250,455)，100×35px，灰色背景，点击后回退到前一状态
  - 「下一步」按钮：位于(450,455)，100×35px，蓝色背景，点击后进入下一状态
  - 步骤指示器：位于(400,470)，显示当前步骤"步骤X/4"
- 教师操作流程：
  1. 初始状态展示题目基础条件，教师介绍线圈、磁场、滑轮系统
  2. 点击「下一步」进入步骤1，讲解ab边切割磁感线产生感应电流
  3. 点击「下一步」进入步骤2，说明本题h=l故此阶段不存在
  4. 点击「下一步」进入步骤3，讲解cd边切割磁感线产生感应电流
  5. 点击「下一步」进入步骤4，总结能量守恒关系，强调焦耳热来源
  6. 可随时点击「上一步」回退复习关键概念

[技术实现]
- JS库选择及原因：原生SVG + 原生JavaScript。原因：几何图形简单（矩形、圆形、路径），无需复杂库；原生SVG便于精确控制坐标和样式；代码轻量，加载快。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  [磁场区]                    [能量转化图]        |
  |     ×××××                    ┌─────────┐        |
  |     ×××××   [线圈三位置]     │ 砝码势能│        |
  |     ×××××    □□□             └────┬────┘        |
  |     ×××××    □□□  [滑轮]          ↓    ↓        |
  |              □□□   ○──○        ┌───┐ ┌───┐    |
  |              [砝码]  │          │线圈│ │焦耳│    |
  |                       │          │势能│ │热 Q│    |
  |                       └──────────┴───┘ ┴───┘    |
  |                                                  |
  |  Ⅰ       Ⅱ       Ⅲ                              |
  +--------------------------------------------------+
  |        [◀上一步]  步骤X/4  [下一步▶]            |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用currentStep变量(0-4)跟踪当前步骤，steps数组存储每步的视觉状态配置
  2. 坐标计算：线圈位置用baseY + stepOffset计算，三个叠加位置预定义坐标
  3. 动画曲线：线圈移动用线性过渡，duration 500ms，使用requestAnimationFrame
  4. 事件绑定：按钮点击事件绑定到updateStep()函数，检查边界条件（步骤0不能上一步，步骤4不能下一步）
  5. 高亮逻辑：根据currentStep判断是否显示#1565c0高亮边框（步骤1和3）
  6. 能量流动画：步骤4时用CSS animation实现箭头流动效果
- ID命名规范：所有交互元素ID必须以scene2-为前缀：
  - scene2-magnetic-field（磁场区域）
  - scene2-coil-pos1/2/3（三个线圈位置）
  - scene2-coil-current（当前线圈）
  - scene2-pulley-left/right（滑轮）
  - scene2-weight（砝码）
  - scene2-energy-box1/2/3（三个能量框）
  - scene2-energy-arrow1/2（能量箭头）
  - scene2-btn-prev/next（上下步按钮）
  - scene2-step-indicator（步骤指示器）
  - scene2-label-stage1/2/3（阶段标签）
- IIFE隔离：所有JS包在(function() { ... })()中，避免全局变量污染
