- 初始状态（步骤 0）：仅显示上下极板（上极板带小孔），无小球无标注
- 步骤 1：点击「下一步」→ 显示距离 d 标注线及标签"d"，上极板标签、下极板标签出现
- 步骤 2：点击「下一步」→ 添加三个小球（蓝色实心圆）和两根轻杆（黑色线段），显示三个"+q"和三个"m"标签
- 步骤 3：点击「下一步」→ 显示两个 L 标注线及标签"L"，显示关系式"d=3L"
- 最终状态：展示完整初始状态图，所有元素可见

冲突检查：
- "d"与"L（下）"：水平距离 200px → 无冲突
- "L（下）"与"L（上）"：垂直距离 60px → 无冲突
- "+q"系列与"m"系列：垂直间距 10px，但错开显示（+q 在上，m 在下）→ 紧凑但可接受
- "+q（球 1）"与"d=3L"：水平距离 235px → 无冲突
- "上极板"与"下极板"：垂直距离 200px → 无冲突
- 所有标签与图形元素：均在外侧偏移，无压线情况 → 无冲突

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：SVG 内底部左侧 (x=320, y=450)，返回上一状态
  - 「下一步」按钮：SVG 内底部右侧 (x=460, y=450)，进入下一状态
  - 状态指示器：底部中央 (x=400, y=475)，显示"步骤 X/4"
- 教师操作流程：
  1. 初始展示仅电容器，引导学生观察结构
  2. 点击「下一步」标注 d，讲解板间距离
  3. 点击「下一步」添加三球系统，讲解带电小球排列
  4. 点击「下一步」标注 L 和 d=3L 关系，完成初始状态认知

[技术实现]
- JS 库选择：原生 SVG（简单几何图形首选，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                    小球 3 (+q,m)                  |
  |                        | L                        |
  |                    小球 2 (+q,m)                  |
  |                        | L                        |
  |  d                 小球 1 (+q,m) [小孔处]         |
  |  |======================[====]===================| ← 上极板
  |  |                                               |
  |  |                                               |
  |  |                                               |
  |  |                                               |
  |  |                                               |
  |  |                                               |
  |  |                                               |
  |  |                                               |
  |  |                                               |
  |  |===============================================| ← 下极板
  |                                               d=3L|
  |                                                  |
  |              [◀上一步]  步骤 1/4  [下一步▶]       | ← 控件栏 y=440~490
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用 currentState 变量 (0-3) 跟踪当前步骤
  2. 元素分组：将不同步骤的元素放入不同<g>组，用 display 控制显隐
  3. 动画效果：新增元素使用淡入动画 (opacity 0→1, 300ms)
  4. 按钮事件：绑定 click 事件，更新 currentState 并刷新显示
  5. 边界检查：步骤 0 禁用「上一步」，步骤 3 禁用「下一步」
- ID 命名规范：所有元素 ID 以 scene1- 为前缀
  - scene1-plate-top, scene1-plate-bottom, scene1-hole
  - scene1-ball-1, scene1-ball-2, scene1-ball-3
  - scene1-rod-1, scene1-rod-2
  - scene1-label-d, scene1-label-l-1, scene1-label-l-2
  - scene1-label-q-1, scene1-label-q-2, scene1-label-q-3
  - scene1-label-m-1, scene1-label-m-2, scene1-label-m-3
  - scene1-label-relation, scene1-label-plate-top, scene1-label-plate-bottom
  - scene1-btn-prev, scene1-btn-next, scene1-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
