[视觉元素清单]
- 坐标系：双纵轴单横轴结构，左轴 v(0→v_max→0)，右轴 F(正→0→负)，横轴 s(0→3L)
- v-s 曲线：蓝色 #1565c0 实线，抛物线型，起点 (80,380)，顶点 (400,120)，终点 (720,380)
- F-s 曲线：红色 #c62828 实线，分段线性，s=0 时 F>0，s=2L 时 F=0，s=3L 时 F<0
- 最大速度点：绿色 #2e7d32 实心圆，位于 (400,120)
- 指示线：灰色 #888888 虚线，垂直于 s 轴，随滑块位置移动
- 滑块：蓝色 #1565c0 圆形手柄，在轨道上水平拖动
- 数值显示：右侧显示当前 s、v、F 的实时数值
- 坐标轴：黑色 #000000 实线，带箭头
- 刻度标记：短竖线，长度 8px

[分步序列]
本场景为连续拖拽交互，无分步导航，状态由滑块位置决定：
- 初始状态（s=0）：指示线在 s=0 处，v=0，F=3mg（最大正值），v-s 曲线和 F-s 曲线完整显示
- 拖动过程（0<s<2L）：指示线右移，v 增大，F 减小但仍为正
- 最大速度点（s=2L）：指示线在 s=2L 处，v=v_max（绿色高亮），F=0
- 减速过程（2L<s≤3L）：指示线继续右移，v 减小，F 为负值
- 终点（s=3L）：指示线在 s=3L 处，v=0，F 为最大负值

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：
  - 滑块轨道：位于 y=450~470，x=150~650，对应 s=0~3L
  - 滑块手柄：蓝色圆形，可水平拖动，限制在轨道范围内
  - 指示线：随滑块同步移动的垂直虚线
  - 数值显示区：右下角显示当前 s、v、F 的精确数值
- 教师操作流程：
  1. 初始状态展示完整图像，讲解坐标系含义
  2. 缓慢拖动滑块从 s=0 向右移动，引导学生观察 v 和 F 的变化趋势
  3. 停在 s=2L 处，强调此时 F=0、v=v_max 的物理意义
  4. 继续拖动至 s=3L，说明小球减速至零的过程
  5. 可来回拖动反复演示关键位置

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：双纵轴折线图结构简单，无需 D3 等重型库；拖拽交互用原生事件即可实现
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  v                              F                |
  |  ↑                              ↑                |
  |  |         v-s 曲线 (蓝)        |                |
  |  |        ╱────●v_max────╲      |                |
  |  |       ╱               ╲     |                |
  |  |      ╱                 ╲    |                |
  |  |─────●───────────────────●───┼────── s        |
  |  0     L        2L         3L  |                |
  |              F-s 曲线 (红)     |                |
  |                                |                |
  |                                |                |
  |                                |                |
  |                    [数值显示]  |                |
  |                                |                |
  |        [══════●══════] 滑块   |                |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：单一连续状态，s 值从 0 到 3L 连续变化
  2. 坐标映射：
     - s 轴：s∈[0,3L] → x∈[80,720]，比例 640px/3L
     - v 轴：v∈[0,v_max] → y∈[380,120]，反向映射
     - F 轴：F∈[F_min,F_max] → y∈[540,60]，反向映射
  3. v-s 曲线函数：分段抛物线，s∈[0,2L] 加速段，s∈[2L,3L] 减速段
  4. F-s 曲线函数：分段线性，s∈[0,L] 三球在电场外 F=3mg；s∈[L,2L] 两球在电场内 F=3mg-2qE；s∈[2L,3L] 一球在电场内 F=3mg-qE（需根据题意调整）
  5. 拖拽事件：mousedown/mousemove/mouseup 或 touch 事件，更新滑块位置和指示线
  6. 数值计算：根据 s 实时计算 v 和 F，保留 2 位小数显示
- ID 命名规范：所有元素 ID 以 scene4- 为前缀
  - scene4-axis-v, scene4-axis-f, scene4-axis-s
  - scene4-curve-v, scene4-curve-f
  - scene4-point-max, scene4-indicator-line
  - scene4-slider-track, scene4-slider-handle
  - scene4-label-v, scene4-label-f, scene4-label-s
  - scene4-display-s, scene4-display-v, scene4-display-f
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
