    **题目原文：**

    如图所示，在光滑水平面上有两个并排放置的木块 A、B，已知 mA=0.5kg，mB=0.3kg。现有质量 m0=0.08kg 的小物块 C 以初速 v0=25m/s 在 A 表面沿水平方向向右滑动，由于 C 与 A、B 间均有摩擦，C 最终停在 B 上，B、C 最后的共同速度 v=2.5m/s。求：

    （1）A 木块的最终速度的大小；

    （2）C 物块滑离 A 木块的瞬时速度大小。

    **题目分析：**

    本题是多物体多阶段的动量守恒问题。系统在水平方向不受外力（光滑水平面），因此整个过程动量守恒。

    物理过程分为两个阶段：
    1. C 在 A 上滑动：C 受摩擦力减速，A 和 B 一起受摩擦力加速（A、B 接触，共同运动）
    2. C 滑离 A 后在 B 上滑动：C 继续减速，B 继续加速，A 已分离以恒定速度运动，直到 C 停在 B 上

    **整体讲解思路：**

    1. 首先明确研究对象和物理过程
    2. 分析各阶段的受力情况和运动状态
    3. 应用动量守恒定律列方程
    4. 联立求解两个未知量

    **图示规划说明：**

    - Scene 1：物理过程三阶段示意图，展示初始状态、C 滑离 A 瞬间、最终状态三个关键状态
    - Scene 2：动量守恒关系图，用矢量箭头直观展示各阶段系统动量的分配关系

    **本图示教学说明：**

    本图示展示物理过程的三个关键状态，帮助学生建立清晰的过程模型。

    **引导学生观察要点：**

    1. 初始状态：C 以 v0 滑上 A，A、B 静止且接触
    2. 中间状态：C 滑到 A 右端即将离开，此时 A、B 仍有共同速度 vA
    3. 最终状态：C 停在 B 上共同运动，A 已分离独立运动

    **关键公式推导：**

    设 C 滑离 A 时速度为 vC，此时 A、B 共同速度为 vA

    阶段一（C 在 A 上）：系统 (A+B+C) 动量守恒
    - m0·v0 = m0·vC + (mA + mB)·vA

    阶段二（C 在 B 上）：系统 (B+C) 动量守恒
    - m0·vC + mB·vA = (m0 + mB)·v

    全程（A+B+C）动量守恒：
    - m0·v0 = mA·vA_final + (m0 + mB)·v

    其中 v = 2.5m/s 为已知，vA_final = vA（A 分离后速度不变）

    **本图示教学说明：**

    本图示用矢量箭头直观展示动量守恒关系，帮助学生理解抽象的动量守恒方程。

    **讲解要点：**

    1. 箭头长度代表动量大小，方向代表动量方向
    2. 各阶段总动量箭头长度相等（动量守恒）
    3. 动量在不同物体间的分配变化

    **完整解答：**

    已知：mA=0.5kg，mB=0.3kg，m0=0.08kg，v0=25m/s，v=2.5m/s

    **（1）求 A 的最终速度：**

    对全程应用动量守恒（系统 A+B+C）：
    - m0·v0 = mA·vA + (m0 + mB)·v
    - 0.08×25 = 0.5×vA + (0.08+0.3)×2.5
    - 2 = 0.5vA + 0.95
    - vA = 2.1m/s

    **（2）求 C 滑离 A 时的速度：**

    对阶段一应用动量守恒：
    - m0·v0 = m0·vC + (mA + mB)·vA
    - 0.08×25 = 0.08×vC + (0.5+0.3)×2.1
    - 2 = 0.08vC + 1.68
    - vC = 4m/s

    **答案：**
    - （1）A 木块的最终速度为 2.1m/s
    - （2）C 滑离 A 时的速度为 4m/s

    **课堂讲解建议：**

    1. 先用 Scene 1 建立物理过程模型，让学生明确三阶段状态
    2. 再用 Scene 2 展示动量关系，引导学生列出方程
    3. 最后板书计算过程，强调动量守恒的适用条件（系统不受外力）
    4. 可拓展讨论：若水平面不光滑如何处理
