[技术实现]
- JS库选择：原生SVG + 原生JavaScript
  - 原因：几何图形简单，无需复杂库；原生SVG便于精确控制坐标和样式；代码轻量易维护
- 画布尺寸：800×500px（固定）
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────────┐
  │  [左侧装置区 55%]           │  [右侧U-t图区 35%]                   │
  │  ┌─────── A板 ───────┐      │  ┌─────────────────────────────┐     │
  │  │                   │      │  │  U ↑                        │     │
  │  │    → v₀           │      │  │    │     ┌───┐              │     │
  │  │  O ──────────── O'│      │  │  U₀├─────┤   │───┐          │     │
  │  │                   │      │  │    │     │   │   │          │     │
  │  └─────── B板 ───────┘      │  │  O └─────┴───┴───┴──→ t     │     │
  │         MN ▓▓▓              │  │    0  2T/3 T  5T/3 2T        │     │
  │                             │  │         -U₀ └───┘            │     │
  │                             │  └─────────────────────────────┘     │
  │                                                                     │
  │  ┌─────────────────────────────────────────────────────────────┐   │
  │  │  步骤 0/4    [◀ 上一步]    [下一步 ▶]                       │   │
  │  └─────────────────────────────────────────────────────────────┘   │
  └────────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用currentState变量(0-4)，steps数组存储每步显示的元素ID列表
  2. 坐标计算：所有坐标硬编码在SVG中，确保精确控制
  3. 动画曲线：粒子运动使用CSS transition或requestAnimationFrame实现匀速运动
  4. 事件绑定：按钮点击事件绑定到stepForward()和stepBackward()函数
  5. 元素显隐：通过display="none"或opacity控制元素显示
- ID命名规范：所有元素ID以"scene1-"为前缀
  - 示例：scene1-plate-a、scene1-plate-b、scene1-axis-oo、scene1-target-mn、scene1-arrow-v0、scene1-ut-frame、scene1-ut-wave、scene1-particle
- IIFE隔离：所有JS代码包在(function() { ... })()中，避免全局变量污染
- 控件栏实现：使用<foreignObject>或HTML绝对定位叠在SVG底部，按钮样式统一
