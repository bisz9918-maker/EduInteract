[图示主题与整合说明]
- 本图示主题：两种极端情况下粒子的偏转轨迹对比分析
- 整合内容：t=0 时刻进入粒子的轨迹 + t=2T/3 时刻进入粒子的轨迹 + 加速度/速度/位移随时间变化
- 教学价值：教师可通过分步演示，清晰展示不同时刻进入电场的粒子因电压波形不同而产生的偏转差异。步骤化呈现帮助学生理解：(1) 电场方向如何随时间变化；(2) 粒子在不同电场阶段的加速度方向；(3) 最终偏转位移的差异及原因。对比分析两种极端情况，为后续求解最大/最小偏转位移范围奠定基础。

[分步序列]
- 初始状态（步骤 0）：显示平行板装置框架（A 板、B 板、靶 MN）、中心轴线、O 点、O'点、时间轴和电压波形。所有轨迹、箭头、标注隐藏。
- 步骤 1：点击「下一步」→ 显示轨迹 1 的第一段（红色，0~2T/3 向下加速），在轨迹中点显示向下的加速度箭头（绿色），在粒子位置显示速度矢量箭头（蓝色）。标签 "t=0 进入" 出现在轨迹 1 上方 (200,160)。
- 步骤 2：点击「下一步」→ 轨迹 1 延伸至完整路径（红色实线全程），加速度箭头变为向上（2T/3~T 阶段），速度矢量箭头更新方向。在靶右侧显示 y₁标注线和文字 "y₁"。
- 步骤 3：点击「下一步」→ 显示轨迹 2 的第一段（蓝色，0~T/3 向上加速），在轨迹中点显示向上的加速度箭头（绿色），在粒子位置显示速度矢量箭头（蓝色）。标签 "t=2T/3 进入" 出现在轨迹 2 下方 (200,240)。
- 步骤 4：点击「下一步」→ 轨迹 2 延伸至完整路径（蓝色实线全程），加速度箭头变为向下（T/3~T 阶段），速度矢量箭头更新方向。在靶右侧显示 y₂标注线和文字 "y₂"。
- 步骤 5：点击「下一步」→ 两条轨迹同时高亮显示，在靶上用不同颜色圆点标记两个终点位置。在 y₁和 y₂标注旁添加双向箭头表示位移大小。时间轴上高亮显示关键时间点 2T/3 和 T。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 (280,455)，尺寸 80×30px，灰色背景，点击返回上一状态
  - 「下一步」按钮：位于 (440,455)，尺寸 80×30px，蓝色背景，点击进入下一状态
  - 状态指示器：位于 (380,455)，显示 "步骤 X/5"，白色文字
- 教师操作流程：
  1. 初始状态展示装置框架，教师介绍平行板电容器和靶的基本结构
  2. 点击「下一步」展示 t=0 时刻进入的粒子在前 2T/3 时间内的运动，教师讲解此时 A 板电势高，电场向下，正电荷受向下的电场力
  3. 点击「下一步」展示 t=0 粒子完整轨迹，教师讲解后 T/3 时间电场反向，粒子向上加速，最终偏转位移为 y₁
  4. 点击「下一步」展示 t=2T/3 时刻进入的粒子在前 T/3 时间内的运动，教师讲解此时 B 板电势高，电场向上，正电荷受向上的电场力
  5. 点击「下一步」展示 t=2T/3 粒子完整轨迹，教师讲解后 2T/3 时间电场反向，粒子向下加速，最终偏转位移为 y₂
  6. 点击「下一步」对比两种轨迹，教师总结两种极端情况的偏转位移范围，为求解问题 (1) 做准备

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形和路径绘制简单，无需复杂库；SVG 路径动画效果好；代码轻量便于多场景合并
- 画布尺寸：800×500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  ┌────────────────────────────────────────────────────┐
  │  A 板 ────────────────────────────────────── M     │ y=140~155
  │     O → v₀  ═══════════════════════════════ O'     │ y=200 中心轴
  │  B 板 ────────────────────────────────────── N     │ y=245~260
  │                                                   │
  │         [轨迹 1: 红色曲线]  t=0 进入               │
  │         [轨迹 2: 蓝色曲线]  t=2T/3 进入            │
  │                                    y₁ y₂          │ 靶右侧标注
  ├────────────────────────────────────────────────────┤
  │  时间轴：0 ─── 2T/3 ─── T ─── 5T/3 ─── 2T         │ y=380
  │  电压波形：[方波示意]                              │ y=390~420
  ├────────────────────────────────────────────────────┤
  │           [◀上一步]  步骤 X/5  [下一步▶]           │ y=450~480
  └────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量 (0~5)，每个状态对应显示/隐藏特定元素组
  2. 轨迹路径：使用 SVG <path> 元素，d 属性定义抛物线路径。抛物线方程 y = (1/2)at²，水平位移 x = v₀t，消去 t 得 y = kx²
  3. 动画效果：轨迹分段显示使用 stroke-dasharray 和 stroke-dashoffset 实现绘制动画
  4. 箭头绘制：使用 SVG <marker> 定义箭头头部，<line> + <marker> 组合绘制矢量箭头
  5. 事件绑定：按钮点击事件绑定到 updateState() 函数，根据 currentState 更新显示
  6. 元素分组：使用 <g> 元素按状态分组，便于批量显示/隐藏
- ID 命名规范：所有元素 ID 以 "scene2-" 为前缀
  - scene2-plate-a, scene2-plate-b, scene2-target, scene2-axis
  - scene2-point-o, scene2-point-oprime
  - scene2-trail1-seg1, scene2-trail1-seg2, scene2-trail2-seg1, scene2-trail2-seg2
  - scene2-arrow-a1, scene2-arrow-v1, scene2-arrow-a2, scene2-arrow-v2
  - scene2-label-y1, scene2-label-y2, scene2-label-t0, scene2-label-t23
  - scene2-timeline, scene2-voltage-wave
  - scene2-btn-prev, scene2-btn-next, scene2-state-indicator
- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染
- 状态数据结构：
  ```javascript
  const states = {
    0: { show: ['plate-a','plate-b','target','axis','point-o','point-oprime','timeline','voltage-wave'] },
    1: { show: [...states[0].show, 'trail1-seg1','arrow-a1','label-t0'] },
    2: { show: [...states[1].show, 'trail1-seg2','arrow-a2','label-y1'] },
    3: { show: [...states[2].show, 'trail2-seg1','arrow-a3','label-t23'] },
    4: { show: [...states[3].show, 'trail2-seg2','arrow-a4','label-y2'] },
    5: { show: [...states[4].show, 'endpoint1','endpoint2','displacement-arrows'] }
  };
  ```
