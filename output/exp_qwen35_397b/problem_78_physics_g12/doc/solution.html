problem_78_physics_g12

场景导航：Scene 1 | Scene 2 | Scene 3

题目原文：

如图所示，电阻忽略不计的、两根平行的光滑金属导轨竖直放置，其上端接一阻值为 3Ω 的定值电阻 R。在水平虚线 L₁、L₂ 间有一与导轨所在平面垂直的匀强磁场 B，磁场区域的高度为 d=0.5m。导体棒 a 的质量 mₐ=0.2kg、电阻 Rₐ=3Ω；导体棒 b 的质量 mᵦ=0.1kg、电阻 Rᵦ=6Ω，它们分别从图中 M、N 处同时由静止开始在导轨上无摩擦向下滑动，且都能匀速穿过磁场区域，当 b 刚穿出磁场时 a 正好进入磁场。已知金属棒始终与导轨接触良好且导轨足够长，设重力加速度为 g=10m/s²。（不计 a、b 之间的作用）求：

（1）a、b 两棒在磁场中运动的速度大小之比；

（2）b 棒穿过磁场过程，电阻 R 上产生的焦耳热。

题目分析：

本题是电磁感应与力学、能量综合的典型问题。核心知识点包括：

  1. 导体棒切割磁感线产生感应电动势 E = BLv
  2. 闭合电路欧姆定律 I = E/R_总
  3. 安培力 F = BIL
  4. 匀速运动条件：合力为零（重力 = 安培力）
  5. 能量守恒：重力势能减少 = 电路中产生的焦耳热

整体讲解思路：

首先分析装置结构和电路连接方式，明确各电阻的串并联关系；然后对导体棒在磁场中进行受力分析，利用匀速条件推导速度表达式；最后利用能量守恒计算焦耳热及其分配。

  • SCENE_3：运动时序与能量转化——展示两棒运动时间关系，计算焦耳热

教学说明：

本图示帮助学生建立装置的整体认知。教师应引导学生：

  1. 识别导轨、电阻、磁场区域、导体棒四个核心元件
  2. 理解导体棒切割磁感线时相当于电源，电动势 E = BLv
  3. 分析电路连接：当某棒在磁场中运动时，该棒电阻与定值电阻 R 构成并联电路

等效电路分析：

当导体棒在磁场中匀速运动时：

  • 棒作为电源：E = BLv
  • 外电路：R 与棒自身电阻并联（注意：题目中 R 接在导轨上端，棒在磁场中时，电流从棒流出后经导轨分为两路）

实际电路结构需仔细分析：电流从棒流出，经导轨向上，一部分流经 R，一部分流经另一棒（若另一棒也在电路中）。但题目说明"不计 a、b 之间的作用"，且两棒不会同时在磁场中，因此每次只有一棒在磁场中切割磁感线。

教学说明：

本图示是解题的核心，教师应重点讲解：

1. 匀速运动条件：

导体棒在磁场中匀速下滑，说明合力为零：

$$mg = F_{安}$$

2. 安培力表达式：

$$F_{安} = BIL$$

其中电流 I 由欧姆定律决定：

$$I = \frac{E}{R_{总}} = \frac{BLv}{R_{总}}$$

3. 速度公式推导：

联立以上公式：

$$mg = BIL = BI \cdot L = B \cdot \frac{BLv}{R_{总}} \cdot L = \frac{B^2L^2v}{R_{总}}$$

解得：

$$v = \frac{mgR_{总}}{B^2L^2}$$

4. 电路总电阻计算：

当 a 棒在磁场中时，R 与 Rₐ 并联：

$$R_{总 a} = \frac{R \cdot R_a}{R + R_a} = \frac{3 \times 3}{3 + 3} = 1.5\Omega$$

当 b 棒在磁场中时，R 与 Rᵦ 并联：

$$R_{总 b} = \frac{R \cdot R_b}{R + R_b} = \frac{3 \times 6}{3 + 6} = 2\Omega$$

5. 速度比计算：

$$\frac{v_a}{v_b} = \frac{m_a g R_{总 a}}{B^2L^2} \div \frac{m_b g R_{总 b}}{B^2L^2} = \frac{m_a R_{总 a}}{m_b R_{总 b}} = \frac{0.2 \times 1.5}{0.1 \times 2} = \frac{0.3}{0.2} = \frac{3}{2}$$

注意： 此处需要重新核算电路结构。若 R 与棒电阻是串联关系，则结果不同。需根据题目原图仔细分析电路连接方式。

教学说明：

1. 运动时序分析：

题目关键条件："当 b 刚穿出磁场时 a 正好进入磁场"

这意味着：

  • b 棒在磁场中运动的时间 = a 棒从 M 到 L₁ 的自由落体时间 - b 棒从 N 到 L₁ 的自由落体时间
  • 两棒在磁场中都做匀速运动

2. 能量守恒应用：

b 棒匀速穿过磁场，重力势能减少全部转化为电能（焦耳热）：

$$Q_{总} = m_b g d = 0.1 \times 10 \times 0.5 = 0.5\text{J}$$

3. 热量分配：

在 b 棒穿过磁场过程中，电路为 R 与 Rᵦ 并联。根据并联电路特点，热量与电阻成反比：

$$\frac{Q_R}{Q_b} = \frac{R_b}{R} = \frac{6}{3} = 2$$

因此：

$$Q_R = Q_{总} \times \frac{R_b}{R + R_b} = 0.5 \times \frac{6}{3 + 6} = 0.5 \times \frac{2}{3} = \frac{1}{3}\text{J} \approx 0.33\text{J}$$

完整解答：

（1）速度比 vₐ/vᵦ = 3:2（需根据实际电路结构核实）

（2）b 棒穿过磁场过程，电阻 R 上产生的焦耳热 Q_R = 1/3 J ≈ 0.33 J

课堂讲解建议：

  1. 先让学生识别装置结构和电路连接
  2. 引导学生分析匀速运动的力学条件
  3. 强调能量守恒在电磁感应问题中的应用
  4. 提醒学生注意并联电路中热量分配与电阻的关系
