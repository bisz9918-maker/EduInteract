[分步序列]
步骤0（初始状态）：
- 显示：导体棒（水平线段）、重力向量（向下红色箭头，带"mg"标签）、安培力向量（向上蓝色箭头，带"F_安"标签）
- 隐藏：所有公式框、结果框
- 目的：展示单棒在磁场中匀速运动时的受力情况

步骤1（点击"下一步"）：
- 显示：匀速条件框（绿色边框），内含公式"mg = F_安"
- 高亮：重力向量和安培力向量加粗显示
- 隐藏：推导框1、推导框2、结果框
- 目的：建立匀速运动的力学平衡条件

步骤2（点击"下一步"）：
- 显示：推导框1（绿色边框），内含"F_安 = BIL, I = E/R_总, E = BLv"
- 保持：步骤0和步骤1的所有元素
- 隐藏：推导框2、结果框
- 目的：展开安培力公式，建立电磁感应关系

步骤3（点击"下一步"）：
- 显示：推导框2（绿色边框），内含"v = mgR_总/(B²L²)"
- 保持：之前所有元素
- 隐藏：结果框
- 目的：推导速度表达式

步骤4（点击"下一步"）：
- 显示：结果框（蓝色填充30%），内含"vₐ/vᵦ 计算"和"vₐ/vᵦ = 3:1"
- 保持：之前所有元素
- 目的：展示最终速度比结果

- "mg"(415,115) 与 "F_安"(415,50)：垂直距离65px → 无冲突（≥20px）
- "F_安"(415,50) 与 导体棒(250,80)-(550,80)：垂直距离30px → 无冲突
- "mg"(415,115) 与 匀速条件框(200,180)：垂直距离65px → 无冲突
- 各公式框之间垂直间距：40px（180→240→290→350）→ 无冲突
- 结果框内两标签垂直距离30px → 无冲突
- 所有标签距画布边缘≥20px → 无冲突

结论：所有标签间距均≥20px，无重叠冲突。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 上一步按钮：位于(280,460)，尺寸100×35px，点击后返回上一状态
  - 下一步按钮：位于(420,460)，尺寸100×35px，点击后进入下一状态
  - 步骤指示：位于(400,495)，显示当前步骤/总步骤数
- 教师操作流程：
  1. 初始展示受力图，讲解导体棒在磁场中受重力和安培力
  2. 点击"下一步"展示匀速条件 mg = F_安，强调平衡状态
  3. 点击"下一步"展开安培力公式，讲解电磁感应三公式关联
  4. 点击"下一步"展示速度公式，推导 v 的表达式
  5. 点击"下一步"展示速度比结果，代入 a、b 数据计算 3:1

[技术实现]
- JS 库选择：原生 SVG（简单几何图形和箭头，无需额外库）
- 画布尺寸：800×500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────┐
  │         受力分析图 (y=20~160)        │
  │    导体棒 + 重力箭头 + 安培力箭头     │
  ├─────────────────────────────────────┤
  │      匀速条件框 (y=180~220)          │
  ├─────────────────────────────────────┤
  │      推导框1 (y=240~280)             │
  ├─────────────────────────────────────┤
  │      推导框2 (y=290~330)             │
  ├─────────────────────────────────────┤
  │      结果框 (y=350~410)              │
  ├─────────────────────────────────────┤
  │  [上一步]      步骤X/4     [下一步]   │
  │  (y=460)                  (y=460)   │
  └─────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-4) 跟踪当前步骤
  2. 元素分组：将每步新增元素放入独立<g>组，用 display 控制显示/隐藏
  3. 箭头绘制：用<line>+<polygon>组合，或 SVG marker 实现
  4. 事件绑定：按钮点击事件切换 currentStep，更新各组 display 属性
  5. 边界处理：步骤0时禁用"上一步"，步骤4时禁用"下一步"
- ID 命名规范：所有元素 ID 以 scene2- 为前缀
  - scene2-rod（导体棒）
  - scene2-gravity-arrow（重力箭头）
  - scene2-gravity-label（mg 标签）
  - scene2-ampere-arrow（安培力箭头）
  - scene2-ampere-label（F_安标签）
  - scene2-step1-box（匀速条件框）
  - scene2-step2-box（推导框1）
  - scene2-step3-box（推导框2）
  - scene2-step4-box（结果框）
  - scene2-btn-prev（上一步按钮）
  - scene2-btn-next（下一步按钮）
  - scene2-step-indicator（步骤指示）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
