[图示主题与整合说明]
- 本图示主题：板块系统受力分析

  3. 摩擦力方向的判断（相对运动趋势方向）

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 (280,460)，80×30px，灰色背景，步骤 0 时禁用
  - 「下一步」按钮：位于 (440,460)，80×30px，蓝色背景 (#1565c0)，步骤 3 时禁用
  - 步骤指示器：位于 (400,465)，显示"步骤 X/4"，实时更新
- 教师操作流程：
  1. 初始展示题目原图（步骤 0），让学生观察系统配置
  2. 点击「下一步」进入步骤 1，讲解小物块 m 的受力：重力 mg 向下、支持力 N₁ 向上、摩擦力 f 向右（因为 M 向右加速，m 相对 M 有向左滑动趋势，故 f 向右）
  3. 点击「下一步」进入步骤 2，讲解木板 M 的受力：重力 Mg 向下、地面支持力 N₂ 向上、拉力 F 向右、m 对 M 的摩擦力 f' 向左（与 f 互为作用力与反作用力）
  4. 点击「下一步」进入步骤 3，高亮 f 和 f'，强调牛顿第三定律：f = f' = μmg，方向相反
  5. 教师可随时点击「上一步」回退复习

[技术实现]
- JS 库选择：原生 SVG
  - 原因：几何图形简单（矩形、线段、箭头），原生 SVG 足够胜任，无需额外库依赖，加载快，代码简洁
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +----------------------------------------------------------+
  |                                                          |
  |                    N₁↑                                   |
  |              N₂↑   │    f→                               |
  |                │   │   ┌───┐                            |
  |                │   mg↓  │ m │                            |
  |                ↓      └───┘                             |
  |   ┌──────────────────────────────────────┐  F→          |
  |   │                  M                   │────→         |
  |   └──────────────────────────────────────┘              |
  |   ═══════════════════════════════════════════════════   |
  |              ←────────── L ──────────→                   |
  |                                                          |
  |              [◀上一步] 步骤 1/4 [下一步▶]                |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-3) 跟踪当前步骤，数组 steps 定义每步显示的元素 ID 列表
  2. 坐标计算：所有元素坐标硬编码于 SVG 中，确保精确控制
  3. 动画曲线：元素显示/隐藏使用 CSS transition，opacity 从 0 到 1，duration 300ms
  4. 事件绑定：按钮点击事件绑定到 updateStep() 函数，更新 currentStep 并刷新显示状态
  5. 箭头绘制：使用 SVG <marker> 定义箭头头部，<line> 绘制箭身
  6. 斜线阴影：使用 SVG <pattern> 定义 45° 斜线填充
- ID 命名规范：
  - 所有交互元素 ID 必须以 scene1- 为前缀
  - 示例：scene1-ground, scene1-board-M, scene1-block-m, scene1-label-M, scene1-label-m, scene1-arrow-F, scene1-arrow-mg, scene1-arrow-N1, scene1-arrow-f, scene1-arrow-Mg, scene1-arrow-N2, scene1-arrow-fp, scene1-btn-prev, scene1-btn-next, scene1-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
- 多场景合并兼容：使用 getElementById('scene1-xxx') 精确选择，不使用 querySelectorAll 配合全局 class
