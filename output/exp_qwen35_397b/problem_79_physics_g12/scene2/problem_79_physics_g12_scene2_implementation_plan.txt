[图示主题与整合说明]
- 本图示主题：抽出过程的相对运动分析（高中物理·牛顿运动定律·板块模型）
- 整合的步骤/概念：
  1. 初始状态：物块 m 在木板 M 最右端
  2. 运动过程：木板和物块各自产生位移 x_M 和 x_m
  3. 临界条件：刚好抽出时，相对位移等于木板长度 L = x_M - x_m
  4. 速度对比：v-t 图像展示两者速度变化差异
- 教学价值：教师可通过分步演示，帮助学生理解"抽出"的本质是相对位移达到木板长度，同时通过 v-t 图直观展示加速度差异导致的速度分离过程

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 按钮「◀ 上一步」：位于 SVG 内底部左侧 (x=250, y=455)，宽 100px，高 30px
  - 按钮「下一步 ▶」：位于 SVG 内底部右侧 (x=450, y=455)，宽 100px，高 30px
  - 步骤指示器：位于 SVG 内底部中央 (x=400, y=420)，显示当前步骤说明
- 教师操作流程：
  1. 初始加载显示步骤 0，教师讲解题目初始条件（m 在 M 最右端，施加拉力 F）
  2. 点击「下一步」进入步骤 1，展示运动一段时间后两者的位移差异
  3. 点击「下一步」进入步骤 2，展示刚好抽出时的临界条件 L = x_M - x_m
  4. 点击「下一步」进入步骤 3，通过 v-t 图解释加速度差异导致速度分离
  5. 可随时点击「上一步」回退复习关键概念

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（矩形、箭头、线段），无需复杂库；原生 SVG 便于精确控制坐标和样式
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │                    步骤指示器 (y=20)                         │
  ├─────────────────────────────────────────────────────────────┤
  │                                                             │
  │           位置变化对比区 (y=130~240)                         │
  │    [初始虚影]        [当前实线]                              │
  │    木板 M + 物块 m     木板 M + 物块 m                        │
  │                                                             │
  │    位移箭头 x_M, x_m (y=260)                                │
  │    相对位移 L (y=290)                                       │
  ├─────────────────────────────────────────────────────────────┤
  │                    v-t 图像区 (y=340~430)                    │
  │         v ↑                                                  │
  │         │     / v_M                                         │
  │         │   /                                                │
  │         │ /   / v_m                                         │
  │         └──────────────→ t                                   │
  ├─────────────────────────────────────────────────────────────┤
  │              控件栏 (y=440~490)                              │
  │         [◀ 上一步]    步骤 X    [下一步 ▶]                   │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量（0-3），每个步骤对应一组元素的显示/隐藏状态
  2. 元素分组：将相关元素按步骤分组（如 step0-group, step1-group 等），通过 display 属性控制显隐
  3. 坐标计算：所有坐标硬编码在 SVG 中，确保与布局坐标表一致
  4. 动画过渡：步骤切换时添加 300ms 淡入淡出效果（opacity 过渡）
  5. 事件绑定：按钮点击事件绑定到 stepChange 函数，更新 currentStep 并刷新视图
  6. 边界处理：步骤 0 时禁用「上一步」，步骤 3 时禁用「下一步」
- ID 命名规范：
  - 所有元素 ID 以 scene2- 为前缀
  - 示例：scene2-board-initial, scene2-block-initial, scene2-board-current, scene2-block-current
  - 示例：scene2-arrow-xM, scene2-arrow-xm, scene2-label-L
  - 示例：scene2-vt-axis, scene2-line-vm, scene2-line-vM
  - 示例：scene2-btn-prev, scene2-btn-next, scene2-step-indicator
- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局变量污染
