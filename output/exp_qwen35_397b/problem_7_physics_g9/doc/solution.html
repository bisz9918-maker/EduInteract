problem_7_physics_g9

场景导航：Scene 1 | Scene 2

题目原文：

一个大物块甲，先后两次分别在小物块乙和小物块丙的作用下，其上表面恰好与水面相平，甲、乙之间用绳连接，如图所示。则下列说法错误的是（）

A. 两种情况下，甲物块所受浮力相等
B. 绳的拉力与丙物块的重力大小相等
C. 乙物块的密度比水小
D. 乙物块的质量比丙物块大

题目分析：

本题考察浮力与受力平衡的综合应用。关键在于理解两种情况下甲物块上表面都与水面相平，意味着甲排开水的体积相同，因此甲所受浮力相等。

整体讲解思路：

  1. 首先展示两种情况的对比，明确甲、乙、丙的位置关系
  2. 分析甲在两种情况下的受力，得出浮力相等的结论
  3. 分别对乙和丙进行受力分析，建立平衡方程
  4. 通过方程推导判断各选项正误

图示规划说明：

  • SCENE_1：两种情景对比图，展示物体位置、水面关系及甲的浸没深度
  • SCENE_2：受力分析图，分步展示各物体受力情况和平衡方程推导
步骤0：基础框架

教学说明：

本图示帮助学生直观理解两种情景的核心特征：

  1. 引导学生观察甲在两种情况下上表面都与水面相平
  2. 强调这意味着甲排开水的体积 V_排 相同
  3. 根据阿基米德原理 F浮 = ρ水·g·V_排，得出甲在两种情况下所受浮力相等

关键公式：

F浮 = ρ液·g·V_排

由于两种情况下甲的 V排 相同，因此 F浮甲(左) = F_浮甲(右)

这直接验证选项 A 正确。

教学说明：

本图示引导学生完成完整的受力分析和逻辑推导：

左侧情景（乙悬挂）：

对甲受力分析：F浮甲 = G甲 + T

对乙受力分析：F浮乙 + T = G乙 → T = G乙 - F浮乙

右侧情景（丙放置）：

对甲受力分析：F浮甲 = G甲 + N（N 为丙对甲的压力）

对丙受力分析：N = G_丙

因此：F浮甲 = G甲 + G_丙

关键推导：

由于两种情况下 F浮甲 相等（由 SCENE1 得出），因此：

G甲 + T = G甲 + G丙 → T = G丙

这验证选项 B 正确。

选项 C 分析：

乙完全浸没在水中且需要绳拉力才能平衡，说明 G乙 > F浮乙

即 ρ乙·g·V乙 > ρ水·g·V乙 → ρ乙 > ρ水

因此乙的密度比水大，选项 C 错误（本题答案）。

选项 D 分析：

由 T = G丙 和 T = G乙 - F_浮乙 得：

G丙 = G乙 - F浮乙 → G乙 = G丙 + F浮乙

因此 G乙 > G丙，即 m乙 > m丙，选项 D 正确。

课堂讲解建议：

  1. 先让学生观察图示，猜测哪个选项可能错误
  2. 引导学生对每个物体单独受力分析，写出平衡方程
  3. 利用"浮力相等"这一关键条件，建立两个情景的联系
  4. 最后汇总判断，强调 C 选项为何错误（乙下沉说明密度大于水）
