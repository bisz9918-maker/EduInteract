- 本图示主题：受力分析与平衡方程推导——展示甲、乙、丙三物体受力情况及选项判断

[标签冲突检查]
所有标签坐标及冲突检查：
- "F_浮甲"：(205,55) - 左侧甲浮力标签
- "G_甲"：(225,160) - 甲重力标签
- "T"（甲端）：(225,150) - 绳拉力标签
- "F_浮乙"：(205,155) - 乙浮力标签
- "G_乙"：(225,230) - 乙重力标签
- "T"（乙端）：(205,160) - 绳拉力标签（乙端）
- "F_浮甲-R"：(595,55) - 右侧甲浮力标签
- "G_甲-R"：(615,160) - 右侧甲重力标签
- "G_丙"：(615,20) - 丙重力标签
- "N"：(595,65) - 支持力标签

冲突检查：
- "F_浮甲"(205,55) 与 "T"(225,150)：y 差 95px → 无冲突
- "G_甲"(225,160) 与 "T"(225,150)：y 差 10px，x 相同 → 需调整 T 标签到 (235,150)
- "F_浮乙"(205,155) 与 "T"(205,160)：y 差 5px → 需调整 T 乙标签到 (195,160)
- "G_乙"(225,230) 与其他标签：y>200，无冲突
- 右侧标签 x>595，与左侧标签 x<235，无冲突

解决方案：
- T_甲标签移至 (235,150)
- T_乙标签移至 (195,160)
- 所有标签与对应箭头距离保持在 5-10px

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 (280,450)，90×30px，蓝色背景，点击返回上一状态
  - 「下一步」按钮：位于 (430,450)，90×30px，蓝色背景，点击进入下一状态
  - 步骤指示：位于 (380,460)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始展示题目情景（步骤 0）
  2. 点击「下一步」展示甲受力（步骤 1），讲解浮力、重力、拉力平衡
  3. 点击「下一步」展示乙受力（步骤 2），讲解乙的受力平衡
  4. 点击「下一步」切换右侧情景（步骤 3），对比两种情况
  5. 点击「下一步」推导方程（步骤 4），得出 T=G_丙
  6. 点击「下一步」判断选项（步骤 5），指出 C 错误
  7. 可随时点击「上一步」回退复习

[技术实现]
- JS 库选择：原生 SVG（简单几何图形和箭头，无需额外库）
- 画布尺寸：800×500px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  左侧情景          |         右侧情景            |
  |  甲+乙受力分析     |         甲+丙受力分析       | y=0~250
  +--------------------------------------------------+
  |  平衡方程推导区（灰色背景框）                     | y=260~360
  +--------------------------------------------------+
  |  选项判断区（灰色背景框）                         | y=370~430
  +--------------------------------------------------+
  |        [◀上一步]  步骤 X/5  [下一步▶]            | y=440~490
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用 currentStep 变量（0-5）跟踪当前步骤，steps 数组存储每步的可见元素 ID 列表
  2. 箭头绘制：用 SVG <line> + <polygon> 组合，箭头头部用 marker 或手动绘制三角形
  3. 元素显隐：每步调用 updateStep() 函数，根据 currentStep 设置元素 display 属性
  4. 按钮事件：绑定 click 事件，currentStep++/--，边界检查（0≤step≤5）
  5. 方程文本：用 SVG <text> 元素，多行用 <tspan> 或多个 text 元素
- ID 命名规范：所有元素 ID 以 scene2- 为前缀
  - scene2-water-line-L, scene2-water-line-R
  - scene2-block-jia-L, scene2-block-yi, scene2-block-jia-R, scene2-block-bing
  - scene2-rope
  - scene2-arrow-float-jia-L, scene2-arrow-grav-jia, scene2-arrow-tension-jia
  - scene2-arrow-float-yi, scene2-arrow-grav-yi, scene2-arrow-tension-yi
  - scene2-arrow-float-jia-R, scene2-arrow-grav-jia-R, scene2-arrow-press-bing
  - scene2-arrow-grav-bing, scene2-arrow-support
  - scene2-label-float-jia, scene2-label-grav-jia, scene2-label-tension
  - scene2-label-float-yi, scene2-label-grav-yi
  - scene2-label-float-jia-R, scene2-label-grav-jia-R, scene2-label-grav-bing, scene2-label-support
  - scene2-equation-box, scene2-option-box
  - scene2-btn-prev, scene2-btn-next, scene2-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
