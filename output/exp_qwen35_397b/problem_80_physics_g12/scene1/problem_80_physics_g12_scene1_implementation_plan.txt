[图示主题与整合说明]
- 本图示主题：单摆摆动过程与机械能守恒
- 整合的步骤/概念：初始位置标注（绳长 l、夹角α、高度 H）、摆动轨迹弧线、高度差 h 的几何推导、最低点速度 v 与机械能守恒公式
- 教学价值：教师可逐步展示选手从静止释放到最低点的完整过程，通过分步动画直观呈现高度差 h 的几何来源（h=l(1-cosα)），并建立机械能守恒 mgh=½mv² 的物理关系，帮助学生理解摆动过程中的能量转化

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 内底部左侧 (x=350, y=460)，点击后回退到前一状态
  - 「下一步」按钮：位于 SVG 内底部右侧 (x=450, y=460)，点击后进入下一状态
  - 步骤指示器：位于两按钮之间 (x=400, y=465)，显示当前步骤编号（如"步骤 1/3"）
- 教师操作流程：
  1. 初始加载显示题目基础条件（步骤 0），教师讲解题目已知量 l、α、H
  2. 点击「下一步」进入步骤 1，展示摆动轨迹和最低点位置，教师讲解运动过程
  3. 点击「下一步」进入步骤 2，展示高度差 h 的几何关系，教师推导 h=l(1-cosα)
  4. 点击「下一步」进入步骤 3，展示速度向量和机械能守恒公式，教师讲解能量转化
  5. 可随时点击「上一步」回退复习关键概念

[技术实现]
- JS 库选择：原生 SVG（简单几何图形首选，无需额外库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                    O                             |
  |                   / \                            |
  |              l   /   \  竖直参考线               |
  |                 / α   \                          |
  |                m       \                         |
  |                         \                        |
  |                          \                       |
  |                           \  h                   |
  |                            \                     |
  |                             m' → v               |
  |                                                  |
  |                              H=3.8m              |
  |                                                  |
  |  岸边 ~~~~~~~ 水面 ~~~~~~~~~~~~~~~ 浮台          |
  |                                                  |
  |                              mgh=½mv²            |
  |                                                  |
  |              [◀上一步]  步骤 1/3  [下一步▶]      |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentStep 变量（0-3），每个步骤对应一组显示/隐藏的元素 ID 列表
  2. 坐标计算：所有元素坐标预先计算好，直接写入 SVG 属性，避免运行时计算
  3. 动画曲线：轨迹高亮使用 CSS transition，opacity 从 0 到 1，duration 300ms
  4. 事件绑定：按钮点击事件绑定到 stepForward() 和 stepBackward() 函数
  5. 元素显隐：使用 display="none" 或 opacity="0" 控制元素显示
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀
  - scene1-suspend-point（悬挂点 O）
  - scene1-rope-initial（初始绳子）
  - scene1-rope-lowest（最低点绳子）
  - scene1-mass-initial（初始质点）
  - scene1-mass-lowest（最低点质点）
  - scene1-trajectory（摆动轨迹）
  - scene1-vertical-ref（竖直参考线）
  - scene1-angle-arc（角度弧线）
  - scene1-water-surface（水面线）
  - scene1-shore（岸边）
  - scene1-platform（浮台）
  - scene1-height-H（高度 H 标注）
  - scene1-height-h（高度差 h 标注）
  - scene1-velocity-v（速度向量）
  - scene1-label-O、scene1-label-l、scene1-label-alpha、scene1-label-H、scene1-label-m、scene1-label-h、scene1-label-v、scene1-label-formula
  - scene1-btn-prev、scene1-btn-next、scene1-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
