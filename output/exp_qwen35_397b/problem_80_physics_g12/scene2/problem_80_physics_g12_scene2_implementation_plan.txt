[分步序列]
- 初始状态（步骤 0）：显示悬挂点 O、绳子、质点 m（红高亮）、速度 v 箭头（水平向右）、标签 O、l=2m、m=60kg、v=4m/s
- 步骤 1：点击「下一步」→ 添加重力 mg 箭头（竖直向下，绿色）、标签"mg"
- 步骤 2：点击「下一步」→ 添加拉力 F 箭头（竖直向上，蓝色，长度大于 mg）、标签"F"
- 步骤 3：点击「下一步」→ 添加向心力 Fn 虚线箭头（竖直向上指向 O，灰色）、标签"Fn"、右侧显示公式"F - mg = mv²/l"
- 步骤 4：点击「下一步」→ 显示完整计算过程与结果"F = mg + mv²/l = 60×10 + 60×4²/2 = 600 + 480 = 1080N"，拉力 F 箭头加粗高亮

  5. 点击「下一步」显示计算过程，得出 F=1080N

[技术实现]
- JS 库选择：原生 SVG（简单几何图形与箭头，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                    O (悬挂点)                    |
  |                    |                             |
  |                    | l=2m                        |
  |                    |                             |
  |              F↑    |    ←Fn (虚线)               |
  |                    |                    [公式区] |
  |              ●←m=60kg→v                          |
  |                    |                             |
  |                   mg↓                            |
  |                                                  |
  |                                                  |
  |                                                  |
  |                                                  |
  |         [◀上一步]  步骤 X/4  [下一步▶]           |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-4) 跟踪当前步骤
  2. 元素分组：将各步骤新增元素放入独立 SVG <g> 组，用 display 控制显示/隐藏
  3. 箭头绘制：使用 SVG <marker> 定义箭头样式，<line> + marker-end 实现
  4. 虚线箭头：stroke-dasharray="5,5" 实现虚线效果
  5. 公式渲染：使用 SVG <text> 多行显示，或引入 MathJax 渲染 LaTeX 公式
  6. 事件绑定：按钮点击事件切换 currentStep，更新各组 display 属性
- ID 命名规范：所有元素 ID 以 scene2- 为前缀
  - scene2-suspend-point（悬挂点 O）
  - scene2-rope（绳子）
  - scene2-mass（质点 m）
  - scene2-arrow-gravity（重力箭头）
  - scene2-arrow-tension（拉力箭头）
  - scene2-arrow-centripetal（向心力箭头）
  - scene2-arrow-velocity（速度箭头）
  - scene2-label-O、scene2-label-l、scene2-label-F、scene2-label-Fn、scene2-label-m、scene2-label-v、scene2-label-mg
  - scene2-formula-group（公式区）
  - scene2-btn-prev、scene2-btn-next、scene2-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
