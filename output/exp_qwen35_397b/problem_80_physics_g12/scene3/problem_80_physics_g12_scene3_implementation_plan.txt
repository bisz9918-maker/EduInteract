[图示主题与整合说明]
- 本图示主题：平抛运动轨迹与水平距离计算
- 整合内容：平抛轨迹、下落高度 h'、水平位移 x、浮台位置、总距离 d 计算
- 教学价值：教师可分步展示平抛运动的独立性原理——竖直方向自由落体与水平方向匀速运动相互独立，最后整合得到总距离。通过动画轨迹帮助学生理解运动合成，通过分步标注强化公式记忆。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 按钮「◀ 上一步」：位于 SVG 内底部左侧 (350,460)，点击回退到前一状态
  - 按钮「下一步 ▶」：位于 SVG 内底部右侧 (450,460)，点击前进到下一状态
  - 状态指示器：位于两按钮之间 (400,460)，显示"步骤 X/4"
- 教师操作流程：
  1. 初始状态展示题目基础条件（悬挂点、最低点、水面、浮台）
  2. 点击「下一步」展示平抛轨迹，讲解运动路径
  3. 点击「下一步」展示竖直高度 h' 和时间计算，讲解竖直方向自由落体
  4. 点击「下一步」展示水平位移 x 和速度计算，讲解水平方向匀速运动
  5. 点击「下一步」展示总距离 d 和最终结果，讲解运动合成

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript。原因：几何图形简单（线段、圆、矩形、抛物线路径），无需复杂库；SVG 路径可精确控制抛物线形状；原生 JS 足够实现分步状态切换。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                    O(悬挂点)                     |
  |                   /|                             |
  |              l=2m/ |α                            |
  |                 /  |                             |
  |                A   |                             |
  |                    |                             |
  |                    B(最低点)                     |
  |                    |                             |
  |                    | h'                          |
  |  岸边              |                             |
  |  ┌───┐             |                             |
  |  |   |=============|========水面================|
  |  |   |             |            [浮台]          |
  |  └───┘             |                             |
  |  ←l·sinα→          |                             |
  |  ←──────x=vt──────→|                             |
  |  ←────────d───────────────────────────────────→  |
  +--------------------------------------------------+
  [控件栏]
  |        [◀ 上一步]  步骤 X/4  [下一步 ▶]          |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-4），数组 steps 存储每步可见元素 ID 列表
  2. 抛物线路径：使用 SVG <path> 的二次贝塞尔曲线 Q 命令，起点(200,300)，控制点(375,300)，终点(550,400)
  3. 双向箭头：自定义函数 drawDoubleArrow(x1,y1,x2,y2,color,label,labelOffset)，绘制线段+两端箭头+标签
  4. 事件绑定：按钮点击事件切换 currentState，调用 updateDisplay() 更新所有元素 visibility
  5. 动画曲线：轨迹显示使用 stroke-dasharray + stroke-dashoffset 实现绘制动画（可选）
- ID 命名规范：所有交互元素 ID 必须以 scene3- 为前缀
  - scene3-point-o, scene3-point-b, scene3-point-a
  - scene3-rope-ob, scene3-rope-oa
  - scene3-water-line, scene3-platform, scene3-shore
  - scene3-trajectory, scene3-arrow-h, scene3-arrow-x, scene3-arrow-d, scene3-arrow-offset
  - scene3-label-o, scene3-label-b, scene3-label-h, scene3-label-l, scene3-label-x, scene3-label-d
  - scene3-btn-prev, scene3-btn-next, scene3-step-indicator
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
