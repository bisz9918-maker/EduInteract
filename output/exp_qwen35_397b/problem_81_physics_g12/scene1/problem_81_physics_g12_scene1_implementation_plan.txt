[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 (280,460)，80×30px，步骤 0 时禁用（灰色），步骤≥1 时可用（蓝色）
  - 「下一步」按钮：位于 (440,460)，80×30px，步骤 3 时禁用（灰色），步骤<3 时可用（蓝色）
  - 步骤指示：位于 (400,495)，显示当前步骤「步骤 X/4」
- 教师操作流程：
  1. 初始展示装置原图，讲解题目条件（m、30°、静止状态）
  2. 点击「下一步」展示 A 的隔离受力，讲解 A 受四个力平衡
  3. 点击「下一步」展示 B 的隔离受力，讲解 B 受两个力平衡（T=mg）
  4. 点击「下一步」展示平衡方程，推导 T·cos30°=kx₀ 和 T=mg，得出 x₀=mg/(2k)

[技术实现]
- JS 库选择：原生 SVG（简单几何图形和箭头，无需额外库）
- 画布尺寸：800×500px（固定）
- 布局草图：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │  [左侧装置原图]           │  [A 隔离受力图]                │
  │   墙壁 弹簧  A───绳───滑轮  │    N↑                         │
  │              │           │     │  T↗                      │
  │              B↓          │  F_弹←●→Tcos30°                │
  │                           │     │  Tsin30°                 │
  │                           │    mg↓                        │
  ├───────────────────────────┼───────────────────────────────┤
  │                           │  [B 隔离受力图]                │
  │                           │    T↑                         │
  │                           │    ●                          │
  │                           │   mg↓                         │
  ├───────────────────────────────────────────────────────────┤
  │  [方程区]  T·cos30°=kx₀           T=mg                    │
  ├───────────────────────────────────────────────────────────┤
  │  [控件栏]        [◀上一步]  步骤 2/4  [下一步▶]            │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 scene1CurrentStep (0-3) 跟踪当前步骤
  2. 元素分组：将每步新增元素放入独立<g>组，用 display 控制显隐
  3. 箭头绘制：用<line>+<polygon>组合，或 SVG marker-end
  4. 弹簧绘制：用<path>绘制锯齿状折线（约 8-10 个波峰）
  5. 角度弧：用<path>绘制圆弧，d 属性用 A 命令
  6. 按钮事件：点击切换步骤，更新按钮状态（禁用/启用）和步骤指示文本
  7. 动画效果：新增元素用 opacity 从 0 到 1 的淡入过渡（0.3s）
- ID 命名规范：
  - 所有元素 ID 以 scene1- 为前缀
  - 示例：scene1-device-group（装置原图组）、scene1-a-fbd-group（A 受力图组）、scene1-b-fbd-group（B 受力图组）、scene1-equation-group（方程组）、scene1-btn-prev（上一步按钮）、scene1-btn-next（下一步按钮）、scene1-step-indicator（步骤指示）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
