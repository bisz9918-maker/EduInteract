场景导航：Scene 1 | Scene 2

题目原文：
如图所示，质量分别为 3m、2m、m 的三个小球 A、B、C 用两根长为 L 的轻绳相连，置于倾角为 30°、高为 L 的固定光滑斜面上，A 球恰能从斜面顶端外竖直落下，弧形挡板使小球只能竖直向下运动，碰撞过程中没有动能损失，小球落地后均不再反弹．由静止开始释放它们，不计所有摩擦，求：
（1）A 球刚要落地时的速度大小
（2）C 球刚要落地时的速度大小．
（3）在 B 球运动过程中，两绳对 B 球做的总功为多少．

题目分析：
本题是多体连接系统的机械能守恒问题，涉及三个运动阶段：

  • 阶段 1：A 球竖直下落 L 距离，带动 B、C 沿斜面向上运动
  • 阶段 2：A 落地后，B 球竖直下落 L 距离，带动 C 沿斜面向上运动
  • 阶段 3：B 落地后，C 球继续沿斜面运动直至落地

关键点：

  1. 系统机械能守恒（光滑斜面无摩擦）
  2. 各阶段速度关联（绳连接）
  3. 碰撞无动能损失但落地后不反弹

整体讲解思路：

  1. 首先明确系统构成和运动约束
  2. 分阶段分析能量转化
  3. 对每个阶段列机械能守恒方程
  4. 求解各问

图示规划说明：

  • SCENE_1：展示系统初始状态及三阶段运动过程（分步动画）
  • SCENE_2：各阶段能量变化对比图（能量条形图）

SCENE_1 教学说明：

本图示用于帮助学生理解系统的运动过程和阶段性特征。

引导要点：

  1. 首先观察初始状态，明确三球的位置关系和连接方式
  2. 点击「下一步」观察阶段 1：A 球竖直下落，通过绳子拉动 B、C 沿斜面向上运动
  3. 强调三球速度大小始终相等（绳不可伸长）
  4. 阶段 2：A 落地后静止，B 球开始竖直下落，拉动 C 沿斜面向上
  5. 阶段 3：B 落地后，C 球独立沿斜面运动

关键公式：
阶段 1 机械能守恒（以地面为零势能面）：

  • 初始势能：Eₚ₁ = 3mgL + 2mg(L - Lsin30°) + mg(L - 2Lsin30°)
  • 末态势能：Eₚ₂ = 0 + 2mgL + mg(L - Lsin30°)
  • 动能：Eₖ = ½(3m + 2m + m)v₁²

阶段 2 机械能守恒：

  • 初始势能：Eₚ₁' = 2mgL + mg(L - Lsin30°)
  • 末态势能：Eₚ₂' = 0 + mgL
  • 动能：Eₖ' = ½(2m + m)v₂²

SCENE_2 教学说明：

本图示用于帮助学生建立能量守恒的直观认识，理解各阶段能量的转化关系。

引导要点：

  1. 阶段 1：A 球重力势能减少是系统动能增加的来源，同时 B、C 势能增加消耗部分能量
  2. 阶段 2：B 球重力势能减少转化为系统动能和 C 的势能增加
  3. 阶段 3：C 球重力势能减少全部转化为动能

完整解答：

（1）A 球刚要落地时的速度 v₁：
阶段 1 机械能守恒：
3mgL - 2mg·Lsin30° - mg·Lsin30° = ½(6m)v₁²
3mgL - mgL - 0.5mgL = 3mv₁²
1.5mgL = 3mv₁²
v₁ = √(gL/2)

（2）C 球刚要落地时的速度 v₃：
阶段 2：2mgL - mg·Lsin30° = ½(3m)v₂² - ½(3m)v₁²
阶段 3：mg·Lsin30° = ½mv₃² - ½mv₂²
联立求解得 v₃

（3）两绳对 B 球做的总功：
对 B 球用动能定理：
W绳 + WG = ΔEₖ
W_绳 = ½(2m)v₂² - ½(2m)v₁² - 2mg·Δh
