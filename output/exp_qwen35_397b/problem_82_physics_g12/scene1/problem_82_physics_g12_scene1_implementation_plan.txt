[分步序列]
步骤 0（初始状态）：
- 显示：斜面三角形、三个小球在初始位置 A(323,200), B(236,250), C(150,300)
- 显示：两根轻绳连接 A-B, B-C
- 显示：弧形挡板、30°角标、高度 L 标注
- 显示：标签 A(3m), B(2m), C(m)
- 阶段指示器：第 1 个点高亮（#1565c0），其余灰色
- 隐藏：速度箭头、轨迹虚线

步骤 1（A 球刚要落地）：
- 球 A 移动至 (466,300) — A 下落 L 竖直距离
- 球 B 移动至 (323,200) — B 沿斜面上移 L 至顶端
- 球 C 移动至 (236,250) — C 沿斜面上移 L
- 高亮：球 A（蓝色加粗描边），显示速度箭头 v1 竖直向下
- 显示：A 的轨迹虚线（从初始到落地）
- 阶段指示器：第 2 个点高亮
- 标签：显示 v1

步骤 2（B 球刚要落地）：
- 球 A 保持落地状态（灰色半透明）
- 球 B 移动至 (466,300) — B 下落 L 竖直距离
- 球 C 移动至 (323,200) — C 沿斜面上移 L 至顶端
- 高亮：球 B（绿色加粗描边），显示速度箭头 v2 竖直向下
- 显示：B 的轨迹虚线
- 阶段指示器：第 3 个点高亮
- 标签：显示 v2

步骤 3（C 球刚要落地）：
- 球 A、B 保持落地状态（灰色半透明）
- 球 C 移动至 (466,400) — C 下落 2L 竖直距离（从斜面顶端）
- 高亮：球 C（红色加粗描边），显示速度箭头 v3 竖直向下
- 显示：C 的轨迹虚线（沿斜面 + 竖直下落）
- 阶段指示器：第 4 个点高亮
- 标签：显示 v3

[标签冲突检查]
- 标签"A"：坐标 (335,195) 初始
- 标签"B"：坐标 (248,245) 初始
- 标签"C"：坐标 (162,295) 初始
- 标签"3m"：坐标 (335,215) — 在 A 下方
- 标签"2m"：坐标 (248,265) — 在 B 下方
- 标签"m"：坐标 (162,315) — 在 C 下方
- 标签"30°"：坐标 (155,375)
- 标签"L"（高度）：坐标 (495,300)
- 标签"v1/v2/v3"：坐标 (480,300) 或 (480,400)

冲突检查：
- "A"与"3m"：垂直间距 20px → 不冲突（上下排列）
- "B"与"2m"：垂直间距 20px → 不冲突
- "C"与"m"：垂直间距 20px → 不冲突
- "30°"与"C/m"：水平间距 >50px → 不冲突
- "L"与速度标签：步骤 1/2 时 v1/v2 在 (480,300)，L 标签也在 (495,300) → 需调整
  解决方案：L 标签移至 (510,300)，速度标签保持 (480,300)，间距 30px
- 各球标签随球移动，动态位置需确保不超出画布

[交互方案]
- 交互类型：分步按钮导航
- 控件说明：
  - 「◀ 上一步」按钮：位于 (320,450)，点击返回上一状态（步骤 0 时禁用）
  - 「下一步 ▶」按钮：位于 (410,450)，点击进入下一状态（步骤 3 时禁用）
  - 阶段指示器：4 个圆点位于 (660,100), (690,100), (720,100), (750,100)，仅视觉指示不可点击
- 教师操作流程：
  1. 初始展示三球静止状态，讲解题目条件
  2. 点击「下一步」展示 A 下落过程，讲解阶段 1 能量转化
  3. 点击「下一步」展示 B 下落过程，讲解阶段 2 速度变化
  4. 点击「下一步」展示 C 下落过程，讲解阶段 3 最终状态
  5. 可随时点击「上一步」回退复习关键位置

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  原因：几何图形简单，无需复杂库；原生 SVG 便于精确控制坐标和动画
- 画布尺寸：800×500px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |  [图示区 左侧 600×400]    |  [阶段指示器 右侧]    |
  |                           |   ●  ●  ●  ●        |
  |      斜面三角形            |  初始 A  B  C        |
  |      三球位置动态变化      |                      |
  |                           |                      |
  |                           |                      |
  +--------------------------------------------------+
  |        [◀ 上一步]  [下一步 ▶]   (y=450-480)      |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-3) 跟踪当前步骤
  2. 坐标计算：预计算各步骤三球的精确坐标，存储为对象数组
  3. 动画过渡：使用 SVG SMIL 或 CSS transition 实现平滑移动（可选）
  4. 事件绑定：按钮点击事件更新 currentStep，调用 renderStep() 重绘
  5. 禁用状态：步骤 0 时禁用上一步，步骤 3 时禁用下一步（opacity+pointer-events）
- ID 命名规范：
  - 所有元素 ID 以 scene1- 为前缀
  - 示例：scene1-ball-a, scene1-ball-b, scene1-ball-c, scene1-rope-ab, scene1-rope-bc
  - 按钮：scene1-btn-prev, scene1-btn-next
  - 阶段指示器：scene1-indicator-0, scene1-indicator-1, scene1-indicator-2, scene1-indicator-3
- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
- CDN 引入：无需外部库，纯原生实现
