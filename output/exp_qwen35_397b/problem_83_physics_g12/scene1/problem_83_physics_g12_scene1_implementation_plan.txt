[图示主题与整合说明]
- 本图示主题：物理过程三状态示意图（子弹射入滑块-弹簧压缩系统）
- 整合内容：初始状态（系统匀速向右）、子弹射入后状态（滑块速度改变）、弹簧压缩最短状态（三者共速）
- 教学价值：教师可通过分步展示三个关键物理状态，帮助学生理解动量守恒定律在不同阶段的应用，以及机械能转化过程。步骤0展示初始条件，步骤1展示完全非弹性碰撞结果，步骤2展示弹簧压缩最短时的共速状态和弹性势能。

[分步序列]
- 初始状态（步骤0）：显示地面、小车 M、滑块 m（原长位置520-640）、弹簧（原长130-520）、子弹 m₀（700,365）、速度 v₁ 箭头及标签、速度 v₀ 箭头及标签、质量标签 M=2kg、m=1.8kg、m₀=0.2kg。隐藏 v₂、v₃ 箭头和 d 标注。
- 步骤1（点击「下一步」）：子弹消失（已射入滑块），滑块位置不变但颜色加深表示合并，显示 v₂ 箭头(550,280)-(620,280)及标签"v₂"，隐藏 v₀ 箭头和子弹，v₁ 箭头保持显示（小车速度未变）。
- 步骤2（点击「下一步」）：弹簧缩短至(130,365)-(480,400)表示压缩，滑块左移至(480,350)-(600,380)，显示 v₃ 箭头(350,260)-(420,260)及标签"v₃"表示三者共速，显示压缩量 d 双向箭头(130,400)-(480,400)及标签"d=0.50m"，隐藏 v₂ 箭头。
- 教师可随时点击「上一步」回退复习前一状态。

冲突检查：
- "m=1.8kg"(560,330) 与 "m₀=0.2kg"(700,320)：水平距离140px → 无冲突
- "m₀=0.2kg"(700,320) 与 "v₀=50m/s"(705,320)：距离5px → 有冲突！解决方案：将"v₀=50m/s"移至(705,300)，垂直距离20px
- "v₁=10m/s"(375,280) 与 "v₃"(375,240)：步骤2时同时显示，垂直距离40px → 无冲突
- "v₂"(575,260) 与 "m=1.8kg"(560,330)：垂直距离70px → 无冲突
- "d=0.50m"(305,420) 与地面(50,420)-(750,450)：标签在地面上方，y=420与地面顶部y=420重叠 → 解决方案：将"d=0.50m"移至(305,435)，在地面内部但用白色背景框避免遮挡

修正后标签坐标：
- "v₀=50m/s"：(705,300)

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位置(280,460)，尺寸80×30，点击后切换到前一状态（步骤0→无操作，步骤1→步骤0，步骤2→步骤1）
  - 「下一步」按钮：位置(440,460)，尺寸80×30，点击后切换到后一状态（步骤0→步骤1，步骤1→步骤2，步骤2→无操作）
  - 状态指示文本：位置(380,465)，显示"步骤 X/2"
- 教师操作流程：
  1. 加载图示，显示步骤0（初始状态），讲解题目已知条件：小车和滑块以v₁=10m/s向右匀速，子弹以v₀=50m/s向左射来
  2. 点击「下一步」，切换到步骤1，讲解子弹射入滑块的完全非弹性碰撞过程，动量守恒求v₂
  3. 点击「下一步」，切换到步骤2，讲解弹簧压缩过程中系统动量守恒，压缩最短时三者共速v₃，此时弹性势能最大

[技术实现]
- JS 库选择：原生 SVG（简单几何图形和动画，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +----------------------------------------------------------+
  |                                                          |
  |                    v₃  v₂                                |
  |                    ←   →                                 |
  |         v₁ →                              v₀ ←           |
  |    +-------+=====[弹簧]=====[滑块 m]        ●子弹        |
  |    | M     |                                 |           |
  |    |_______|____O________O___________________|           |
  |    地面============================================      |
  |                                                          |
  |              [◀上一步]  步骤X/2  [下一步▶]               |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0/1/2) 跟踪当前状态，数组存储各状态配置
  2. 坐标计算：弹簧原长390px，压缩后350px（压缩量d=0.50m按比例缩放）
  3. 动画曲线：使用 CSS transition 实现平滑过渡（弹簧缩短、滑块移动）
  4. 事件绑定：按钮点击事件切换状态，更新 SVG 元素显示/隐藏
  5. 元素分组：用<g>元素按状态分组，通过 display 属性控制显示
- ID 命名规范：所有交互元素 ID 以 scene1- 为前缀，如 scene1-cart、scene1-block、scene1-spring、scene1-bullet、scene1-arrow-v1、scene1-btn-prev、scene1-btn-next
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
