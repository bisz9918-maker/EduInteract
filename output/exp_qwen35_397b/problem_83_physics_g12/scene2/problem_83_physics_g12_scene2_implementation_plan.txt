[图示主题与整合说明]
- 本图示主题：子弹射入滑块瞬间的动量守恒分析
- 整合内容：碰撞前后动量矢量对比、动量守恒方程的可视化呈现
- 教学价值：教师可通过分步演示，让学生直观理解动量守恒定律在碰撞问题中的应用。步骤0展示碰撞前系统状态，步骤1展示碰撞后共同运动状态，步骤2验证动量守恒关系，帮助学生建立矢量合成与守恒的物理图像。

[分步序列]
- 初始状态（步骤0）：显示标题、滑块图标及标签 m、子弹图标及标签 m₀、滑块动量箭头（向右）及标签 mv₁=18、子弹动量箭头（向左）及标签 m₀v₀=10、右侧方程框显示"碰撞前"标题
- 步骤1：点击「下一步」→ 隐藏子弹动量箭头，显示碰撞后组合体（滑块+子弹合并）、共同动量箭头（向右）及标签(m+m₀)v₂=8、右侧方程框更新显示"碰撞后"
- 步骤2：点击「下一步」→ 显示等号符号连接碰撞前后、右侧方程框完整显示动量守恒方程"mv₁ - m₀v₀ = (m+m₀)v₂"及数值"18 - 10 = 8 (kg·m/s)"、高亮显示守恒等号
- 教师可随时点击「上一步」回退复习任一状态

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 上一步按钮：位于(260,455) 80×30px，灰色背景，点击返回上一状态
  - 下一步按钮：位于(460,455) 80×30px，蓝色背景，点击进入下一状态
  - 步骤指示器：位于(400,465)，显示"步骤 X/3"
- 教师操作流程：
  1. 初始状态展示碰撞前系统，讲解滑块和子弹的初始动量
  2. 点击「下一步」展示碰撞后状态，讲解完全非弹性碰撞特点
  3. 点击「下一步」展示动量守恒方程，验证碰撞前后总动量相等
  4. 可随时点击「上一步」回退复习关键概念

[技术实现]
- JS 库选择：原生 SVG（简单几何图形和箭头，无需额外库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────┐
  │              子弹射入滑块—动量守恒分析                   │ y=35
  │                                                         │
  │   [滑块 m]──→mv₁    ←m₀v₀─[子弹 m₀]      ┌───────────┐  │ y=120-165
  │                                         │  方程框   │  │
  │                                         │  碰撞前   │  │ y=100-280
  │   [滑块+子弹]──→(m+m₀)v₂                 │  碰撞后   │  │
  │                                         │  守恒式   │  │
  │                                         └───────────┘  │
  │                                                         │
  │              [◀上一步]  步骤1/3  [下一步▶]              │ y=455
  └─────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentState(0-2) 跟踪当前步骤，数组存储各状态配置
  2. 坐标计算：箭头终点 = 起点 + 方向向量 × 动量大小 × 比例系数(15px per kg·m/s)
  3. 动画曲线：使用 CSS transition 实现箭头淡入淡出（opacity 0→1，时长300ms）
  4. 事件绑定：按钮点击事件切换状态，更新 DOM 元素 display/opacity 属性
  5. 边界检查：步骤0禁用「上一步」，步骤2禁用「下一步」
- ID 命名规范：所有元素 ID 以 scene2- 为前缀
  - scene2-title, scene2-block-m, scene2-bullet-m0
  - scene2-arrow-mv1, scene2-arrow-m0v0, scene2-arrow-combined
  - scene2-label-mv1, scene2-label-m0v0, scene2-label-combined
  - scene2-equation-box, scene2-eq-before, scene2-eq-after, scene2-eq-equals
  - scene2-btn-prev, scene2-btn-next, scene2-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
