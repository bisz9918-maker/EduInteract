[图示主题与整合说明]
- 本图示主题：弹簧压缩过程的能量转化关系
- 整合内容：系统初动能、末动能、弹性势能、摩擦生热的能量分配关系
- 教学价值：教师可通过分步展示能量转化过程，帮助学生理解能量守恒定律在复杂系统中的应用。从初态动能出发，逐步展示能量如何分配到末动能、弹性势能和摩擦生热，直观呈现能量守恒方程的物理意义。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 底部左侧 (280,450)，点击返回上一状态
  - 「下一步」按钮：位于 SVG 底部右侧 (420,450)，点击进入下一状态
  - 步骤指示器：底部中央显示"步骤 X/3"
- 教师操作流程：
  1. 初始状态展示初动能，提问"子弹射入后系统总动能是多少？"
  2. 点击「下一步」，展示能量分配到三个末态形式，讲解能量去向
  3. 点击「下一步」，展示能量守恒方程，总结能量守恒关系
  4. 可随时点击「上一步」回退复习关键概念

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单，无需复杂库；原生 SVG 便于精确控制坐标和样式
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [800 × 500 画布]
  +--------------------------------------------------+
  |              能量转化关系 (标题)                  |
  |                                                  |
  |  +----+                                          |
  |  |E_k |  →→→→→→→→→→→  [弹簧压缩示意图]           |
  |  | 初 |        \                                  |
  |  +----+         \→ [末动能] [弹性势能] [摩擦生热]  |
  |                 \                                 |
  |                  \→→→→→→→→→→→→→→→→→→→→→→→→→→→→→  |
  |                                                  |
  |          [能量守恒方程文本框]                     |
  |                                                  |
  |        [◀上一步]    步骤 1/3    [下一步▶]         |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用 currentStep 变量跟踪当前步骤（0/1/2）
  2. 元素分组：将相关元素放入<group>，通过 display/opacity 控制显示
  3. 动画效果：条形图出现时用 scaleY 动画（从 0 到 1），箭头用 draw 动画
  4. 事件绑定：按钮点击事件切换状态，更新步骤指示器
  5. ID 命名规范：所有元素 ID 以 scene3- 为前缀（如 scene3-bar-ek-initial）
  6. IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
- 元素 ID 命名示例：
  - scene3-title（标题）
  - scene3-bar-ek-initial（初动能条形）
  - scene3-bar-ek-final（末动能条形）
  - scene3-bar-ep（弹性势能条形）
  - scene3-bar-q（摩擦生热条形）
  - scene3-arrow-1/2/3（能量流向箭头）
  - scene3-spring-group（弹簧示意图组）
  - scene3-equation-box（方程文本框）
  - scene3-btn-prev/next（上一步/下一步按钮）
  - scene3-step-indicator（步骤指示器）
