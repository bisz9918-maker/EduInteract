[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 上一步按钮：位于 SVG 内底部左侧 (320, 460)，点击回退到前一状态
  - 下一步按钮：位于 SVG 内底部右侧 (460, 460)，点击进入下一状态
  - 步骤指示器：位于两按钮之间 (400, 460)，显示当前步骤 "步骤 X/4"
- 教师操作流程：
  1. 初始状态展示装置结构，讲解 U 形框架、金属棒、电阻、磁场方向
  2. 点击「下一步」添加外力 F，讲解恒力拉动金属棒
  3. 点击「下一步」添加安培力 F_A，讲解电磁感应产生安培力阻碍运动（方向向右）
  4. 点击「下一步」添加摩擦力 f，讲解导轨摩擦阻力（方向向右）
  5. 点击「下一步」显示平衡公式，讲解稳定状态条件 F = F_A + f

[技术实现]
- JS 库选择：原生 SVG（简单几何图形首选，无需额外库）
- 画布尺寸：800 × 500 px（固定画布）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |     B  ↑    ↑    ↑    ↑    ↑    ↑                |
  |        |    |    |    |    |    |                |
  |  L=1m  ====|====|====|====|====|====R            |
  |        |   |    |    |    |    |    |            |
  |        |   F    |    |    |    |    |            |
  |        |  ←-----●----→F_A                        |
  |        |        |    →f                          |
  |        |        |                                |
  |  ======|========|================================|
  |        b                                        |
  |                                                  |
  |              F = F_A + f  (步骤 4 显示)          |
  |                                                  |
  |              [◀上一步]  步骤 X/4  [下一步▶]      |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量 (0-4) 跟踪当前步骤
  2. 元素分组：将各步骤元素放入独立 SVG <g> 组，通过 display 属性控制显示/隐藏
  3. 箭头绘制：使用 <marker> 定义箭头样式，<line> + marker-end 绘制带箭头线段
  4. 事件绑定：为按钮添加 click 事件监听器，更新 currentState 并刷新显示
  5. 边界处理：步骤 0 时禁用「上一步」，步骤 4 时禁用「下一步」
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀
  - scene1-rail-top, scene1-rail-bottom, scene1-rod-ab, scene1-resistor-R
  - scene1-mag-arrow-1 至 scene1-mag-arrow-6
  - scene1-force-F, scene1-force-Fa, scene1-force-f
  - scene1-label-L, scene1-label-B, scene1-label-F, scene1-label-Fa, scene1-label-f
  - scene1-label-R, scene1-label-a, scene1-label-b, scene1-label-r
  - scene1-formula-balance
  - scene1-btn-prev, scene1-btn-next, scene1-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
