[图示主题与整合说明]
- 本图示主题：运动过程与力 - 速度关系动态演示
- 整合的内容：速度随时间变化曲线、安培力随速度变化关系、合力变化趋势
- 教学价值：教师可通过拖动底部速度滑块，让学生直观观察金属棒从静止加速到稳定速度过程中，安培力、合力、加速度的动态变化关系。当滑块拖到稳定速度点时，合力归零，加速度归零，帮助学生理解电磁感应中"稳定状态"的物理意义。

[分步序列]
本场景为连续拖拽交互，无分步导航，状态由滑块位置连续决定：

- 初始状态（滑块 v=0）：
  - v-t 曲线显示完整轨迹（从 0 渐近到稳定值）
  - F_A 曲线显示完整直线（从 0 到 2.5N）
  - F_net 曲线显示完整直线（从 2N 到 0）
  - 滑块手柄位于最左端（v=0）
  - 数值显示：v=0.0m/s, F_A=0.0N, F_net=2.0N, a=10.0m/s²
  - 稳定点标记显示但无高亮

- 拖动过程中（任意 v 值）：
  - 滑块手柄跟随鼠标/触摸位置
  - v-t 曲线上对应时刻点高亮（蓝色圆点 r=5px）
  - F-v 图上对应速度点高亮（红色/绿色圆点）
  - 数值实时更新

- 稳定状态（滑块 v=2.0m/s）：
  - 滑块手柄位于 v_stable 位置
  - 稳定点标记绿色高亮（填充 30%→80% 透明度）
  - 数值显示：v=2.0m/s, F_A=2.0N, F_net=0.0N, a=0.0m/s²
  - 可添加文字提示"稳定状态"（绿色）

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：
  - 速度滑块：位于底部 y=460，范围 x=100~700，对应 v=0~2.5m/s
  - 数值显示区：位于右侧图下方，显示当前 v、F_A、F_net、a 四个物理量
- 教师操作流程：
  1. 初始状态展示完整曲线，讲解物理过程
  2. 拖动滑块从 0 开始，观察安培力从 0 逐渐增大
  3. 继续拖动，观察合力从 2N 逐渐减小
  4. 拖到 v=2m/s 时，合力归零，加速度归零，强调"稳定状态"
  5. 可来回拖动，让学生理解任意时刻的物理量关系

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：坐标系和曲线绘制简单，无需 D3 等重型库；拖拽交互用原生事件即可实现
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [800×500 画布]
  +--------------------------------------------------+
  |  [v-t 图]              [F-v 图]                  |
  |  300×300               300×300                   |
  |  蓝色曲线              红/绿直线                 |
  |                                                  |
  |                    [数值显示区]                  |
  |                    v=  F_A=                      |
  |                    F_net=  a=                    |
  |                                                  |
  |  [=============●=============]  速度滑块         |
  |   0                                    2.5 m/s  |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机：单状态连续变量（sliderValue），无离散步骤
  2. 坐标映射：滑块 x 坐标 → 速度值 v = (x-100)/600 × 2.5
  3. 物理计算：
     - F_A = v（因 B²L²/(R+r) = 1）
     - F_net = F - F_A - f = 3 - v - 1 = 2 - v
     - a = F_net / m = (2-v) / 0.2 = 10 - 5v
  4. 动画曲线：v-t 曲线用指数渐近函数 v(t) = v_stable × (1 - e^(-kt))
  5. 事件绑定：mousedown/touchstart 开始拖拽，mousemove/touchmove 更新位置，mouseup/touchend 结束
  6. 稳定点检测：当 |v - 2.0| < 0.05 时，高亮稳定点标记
- ID 命名规范：
  - 所有元素 ID 以 scene2- 为前缀
  - 例：scene2-vt-curve, scene2-fa-curve, scene2-fnet-curve, scene2-slider, scene2-slider-handle, scene2-val-v, scene2-val-fa, scene2-val-fnet, scene2-val-a, scene2-stable-point
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
