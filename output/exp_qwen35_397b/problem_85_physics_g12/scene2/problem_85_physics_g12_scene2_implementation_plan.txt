[分步序列]
- 初始状态（步骤 0）：显示双气缸结构、活塞 a 在 H/4 处、活塞 b 在 H/2 处（虚线）、氮气区域浅色填充、标签"A""B""a""b""P₀""T₁=280K"
- 步骤 1：高亮氮气区域（#c62828 20% 填充），显示体积标注"V₁"在 (240,280)
- 步骤 2：动画播放 — 活塞 b 从 y=225 缓慢上升至 y=100（顶部），位移箭头出现，氮气区域填充色加深至 30%
- 步骤 3：末状态定格 — 活塞 b 在顶部（实线），显示"V₂"在 (240,320)，显示"T₂=?"在 (550,180)
- 步骤 4：展示等压条件 — 公式框出现，显示"P₁=P₂=P₀"和"V₁/T₁=V₂/T₂"，标注"等压过程"

  - 「上一步」按钮：位置 (320,455)，点击回退到前一状态
  - 「下一步」按钮：位置 (480,455)，点击进入下一状态

- 教师操作流程：
  1. 初始状态展示题目条件，讲解气缸结构和活塞初始位置
  2. 点击「下一步」高亮氮气区域，讲解初始体积 V₁
  3. 点击「下一步」播放动画，讲解活塞 b 上升过程
  4. 点击「下一步」展示末状态，讲解体积变化 V₂
  5. 点击「下一步」展示公式，讲解等压过程和盖 - 吕萨克定律

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript — 几何图形简单，无需复杂库，SVG 便于精确控制坐标和动画
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +----------------------------------------------------------+
  |  [气缸 A]              [气缸 B]         [温度标注区]     |
  |  +----+               +--+             T₁=280K           |
  |  | a  |               |b |             T₂=?              |
  |  +----+               +--+                               |
  |  | A  |               |B |             [公式框]          |
  |  |    |~~~~~~~~~~~~~~~|  |             +-----------+     |
  |  |    |               |  |             |V₁/T₁=V₂/T₂|     |
  |  +----+               +--+             |P₁=P₂=P₀   |     |
  |                                         +-----------+     |
  |                                                            |
  |              [控件栏 y=440~490]                           |
  |           [◀上一步]  步骤 X/4  [下一步▶]                  |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用 currentState 变量 (0-4) 跟踪当前步骤，steps 数组存储每步的显示配置
  2. 坐标计算：气缸高度 H=250px，活塞 a 固定在 y=100+H/4=162.5，活塞 b 初始 y=100+H/2=225，末态 y=100
  3. 动画曲线：活塞 b 上升用 requestAnimationFrame + 线性插值，duration=1500ms
  4. 事件绑定：按钮点击事件切换状态，每步更新 SVG 元素显示/隐藏
  5. 氮气区域填充：用 <path> 定义多边形区域，通过 opacity 控制填充深浅
- ID 命名规范：所有交互元素 ID 必须以 scene2- 为前缀（如 scene2-cylinder-a, scene2-piston-b-initial, scene2-label-v1）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
