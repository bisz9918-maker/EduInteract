problem_86_physics_g12

场景导航：Scene 1 | Scene 2

题目原文：

如图所示，水平放置的平行板电容器，原来 AB 两板不带电，B 极板接地，它的极板长 L=0.1m，两板间距离 d=0.4cm，现有一微粒质量 m=2.0×10^(-6)kg，带电量 q=+1.0×10^(-8)C，以一定初速度从两板中央平行于极板射入，由于重力作用微粒恰好能落到 A 板上中点 O 处，取 g=10m/s²，试求：
（1）带电粒子入射初速度的大小；
（2）现使电容器带上电荷，使带电微粒能从平行板电容器的右侧射出，则带电后 A 板的电势范围为多少？

题目分析：

本题是带电粒子在电场与重力场复合场中的运动问题，分为两个阶段：

  1. 电容器不带电时，粒子仅受重力，做类平抛运动，恰好落到 A 板中点 O
  2. 电容器带电后，粒子受重力和电场力共同作用，需要从右侧射出

整体讲解思路：

第(1)问：利用类平抛运动规律，竖直方向自由落体，水平方向匀速直线运动

第(2)问：分析两种临界情况

  • 临界 1：粒子刚好从 A 板右端边缘射出（向下偏转最大允许值）
  • 临界 2：粒子刚好从 B 板右端边缘射出（向上偏转最大允许值）

图示规划说明：

共设计 2 个图示场景：

  • SCENE_1：不带电时的类平抛运动轨迹，展示已知条件和落点位置
  • SCENE_2：带电后的两种临界轨迹对比，展示电势范围的确定方法
步骤 0/4

SCENE_1 教学说明：

本图示用于讲解第 (1) 问，引导学生分析不带电时粒子的运动规律。

讲解要点：

  1. 粒子从两板中央射入，初始位置距 A 板距离为 d/2
  1. 水平方向：匀速直线运动，位移 x = L/2，速度 v₀
  1. 竖直方向：自由落体运动，位移 y = d/2，加速度 a = g
  1. 运动时间由竖直方向决定：d/2 = (1/2)gt²
  1. 水平方向：L/2 = v₀t

公式推导：

由竖直方向：t = √(d/g) = √(0.004/10) = 0.02s

由水平方向：v₀ = (L/2)/t = 0.05/0.02 = 2.5m/s

引导学生观察：

  • 轨迹是抛物线的一部分
  • 水平位移是板长的一半（落到中点 O）
  • 竖直位移是板间距的一半（从中央到 A 板）
步骤 0/4

SCENE_2 教学说明：

本图示用于讲解第 (2) 问，分析电容器带电后粒子的运动及电势范围。

讲解要点：

  1. B 板接地，φB = 0，A 板电势为 φA
  1. 电场强度 E = |φ_A|/d，方向由高电势指向低电势
  1. 粒子带正电，电场力 F = qE，方向与电场方向相同

两种临界情况分析：

临界 1（轨迹 1，红色）：刚好从 A 板右端射出

  • 竖直位移：y₁ = d/2（向下）
  • 水平位移：x₁ = L
  • 此时电场力向上（φ_A < 0），但重力大于电场力
  • 合力向下：mg - qE₁ = ma₁

临界 2（轨迹 2，绿色）：刚好从 B 板右端射出

  • 竖直位移：y₂ = d/2（向上）
  • 水平位移：x₂ = L
  • 此时电场力向上（φ_A < 0），且电场力大于重力
  • 合力向上：qE₂ - mg = ma₂

公式推导：

水平方向：L = v₀t，得 t = L/v₀ = 0.1/2.5 = 0.04s

临界 1（向下偏转 d/2）：d/2 = (1/2)a₁t²，a₁ = d/t² = 0.004/0.0016 = 2.5m/s²

由 mg - qE₁ = ma₁，得 E₁ = m(g-a₁)/q = 2×10^(-6)×(10-2.5)/(1×10^(-8)) = 1500V/m

φ_A₁ = -E₁d = -1500×0.004 = -6V

临界 2（向上偏转 d/2）：d/2 = (1/2)a₂t²，a₂ = d/t² = 2.5m/s²

由 qE₂ - mg = ma₂，得 E₂ = m(g+a₂)/q = 2×10^(-6)×(10+2.5)/(1×10^(-8)) = 2500V/m

φ_A₂ = -E₂d = -2500×0.004 = -10V

电势范围：-10V ≤ φ_A ≤ -6V

引导学生观察：

  • 两条临界轨迹的对称性（竖直位移大小相等，方向相反）
  • 电场力方向必须向上（A 板电势为负），才能抵消部分或全部重力
  • 电势绝对值越大，电场力越大，向上加速度越大
