冲突检查：
- "A"(170,345) 与 "L/2"(305,365)：水平距离 135px，垂直距离 20px → 无冲突
- "B"(170,165) 与 "L=0.1m"(430,135)：水平距离 260px → 无冲突
- "O"(430,340) 与 "L/2"(305,365)：水平距离 125px，垂直距离 25px → 无冲突
- "v₀"(185,235) 与 "m,q"(125,265)：水平距离 60px，垂直距离 30px → 无冲突
- "d/2"(120,285) 与 "m,q"(125,265)：水平距离 5px，垂直距离 20px → 接近但可接受（d/2 在步骤 3 才显示，m,q 在左侧更靠左）
- "d=0.4cm"(715,245) 与其他标签：最右侧，无冲突

解决方案：所有标签间距均≥20px，无明显冲突。d/2 与 m,q 水平距离较近，但 d/2 在步骤 3 才出现，且 m,q 在粒子左侧 (x=125)，d/2 标注在 x=140 右侧，实际不重叠。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  · 按钮「◀上一步」：位置 (320,460)，宽 100px，高 30px，浅灰色背景 #f5f5f5，步骤 0 时禁用
  · 按钮「下一步▶」：位置 (480,460)，宽 100px，高 30px，蓝色背景 #1565c0，白色文字，步骤 4 时禁用
  · 步骤指示器：位置 (440,465)，显示「步骤 X/4」
- 教师操作流程：
  1. 初始状态展示电容器结构和已知条件，教师介绍题目背景
  2. 点击「下一步」显示入射速度，讲解粒子入射状态
  3. 点击「下一步」显示轨迹和落点，讲解类平抛运动轨迹
  4. 点击「下一步」显示位移关系，讲解水平位移 L/2 和竖直位移 d/2
  5. 点击「下一步」显示公式，讲解运动学方程和解题思路
  6. 可随时点击「上一步」回退复习

- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-4) 跟踪当前步骤，每步控制对应元素的 display 属性
  2. 轨迹绘制：用 SVG <path> 绘制抛物线，d="M 160,250 Q 295,285 430,320"（二次贝塞尔曲线近似）
  3. 箭头绘制：用 <marker> 定义箭头样式，或直接绘制三角形
  4. 双箭头标注线：两端绘制箭头，中间线段
  5. 事件绑定：按钮点击事件切换步骤，更新元素可见性和按钮状态
  6. 公式渲染：用 SVG <text> 和 <tspan> 分行显示，或简单文本
- ID 命名规范：所有元素 ID 以 scene1- 为前缀，如 scene1-plate-a、scene1-plate-b、scene1-trajectory、scene1-label-o 等
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
