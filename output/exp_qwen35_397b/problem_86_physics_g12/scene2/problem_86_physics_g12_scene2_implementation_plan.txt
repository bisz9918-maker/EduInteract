[图示主题与整合说明]
- 本图示主题：带电后粒子的两种临界运动轨迹及电势范围分析
- 整合的内容：电场力方向分析、两种临界轨迹（从 A 板右端射出和从 B 板右端射出）、受力示意图、电势范围结论
- 教学价值：教师可逐步展示带电电容器中粒子的运动分析，通过两条临界轨迹的对比，帮助学生理解电势范围的决定因素。分步导航让教师能够控制讲解节奏，先分析受力，再分别展示两种临界情况，最后得出电势范围结论。

[分步序列]
- 初始状态（步骤 0）：显示电容器极板（A 板、B 板）、接地符号、入射点 P、板长 L 标注、板间距 d 标注、A 板电势φ_A 标注。粒子在入射点静止，无轨迹。
- 步骤 1：点击「下一步」→ 显示电场线（3 条蓝色虚线箭头，竖直向下，表示电场方向从 B 到 A）、显示重力 mg 箭头（黑色向下）、显示电场力 qE 箭头（蓝色，方向取决于电势正负，此处先显示向上表示 qE 与 mg 反向的可能情况）、显示初速度 v₀ 箭头（水平向右）。
- 步骤 2：点击「下一步」→ 显示轨迹 1（红色抛物线#c62828，从入射点 (180,250) 向下偏转至 A 板右端 (680,340)），标注「轨迹 1（A 端射出）」在轨迹末端下方 (600,355)。此轨迹对应电势较低情况，电场力向上但不足以抵消重力。
- 步骤 3：点击「下一步」→ 隐藏轨迹 1，显示轨迹 2（绿色抛物线#2e7d32，从入射点 (180,250) 向上偏转至 B 板右端 (680,160)），标注「轨迹 2（B 端射出）」在轨迹末端上方 (600,145)。此轨迹对应电势较高情况，电场力向上且大于重力。
- 步骤 4：点击「下一步」→ 同时显示两条轨迹（红色和绿色），在底部中央 (300,400) 显示电势范围结论文本框：「电势范围：φ_min ≤ φ_A ≤ φ_max」（具体数值可根据计算填入）。两条轨迹形成包络区域，用浅红色和浅绿色半透明填充（透明度 10%）表示可行区域。

- "A"(170,355) 与 "轨迹 1"(600,355)：水平距离 430px → 无冲突
- "v₀"(210,235) 与 "qE"(225,220)：距离约 21px → 边界，调整 qE 标签至 (225,210) 确保间距≥25px
- "mg"(205,295) 与 A 板 (y=340)：垂直距离 45px → 无冲突
- "d"(695,250) 与轨迹末端 (680,160/340)：水平距离 15px → 调整 d 至 (710,250) 确保间距≥20px
- "轨迹 1"(600,355) 与 "轨迹 2"(600,145)：垂直距离 210px → 无冲突

解决方案：
- qE 标签调整至 (225,210)
- d 标签调整至 (710,250)
- 所有标签与图形元素间距≥15px

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位置 (280,460)，尺寸 80×35px，点击返回上一状态
  - 「下一步」按钮：位置 (440,460)，尺寸 80×35px，点击进入下一状态
  - 步骤指示器：位置 (380,465)，显示「步骤 X/4」
- 教师操作流程：
  1. 初始状态展示电容器基本结构，讲解题目条件
  2. 点击「下一步」显示电场和受力，分析粒子受力情况
  3. 点击「下一步」显示轨迹 1，讲解从 A 板右端射出的临界条件
  4. 点击「下一步」显示轨迹 2，讲解从 B 板右端射出的临界条件
  5. 点击「下一步」同时显示两条轨迹，得出电势范围结论
  6. 可随时点击「上一步」回退复习

[技术实现]
- JS 库选择：原生 SVG（简单几何图形和曲线，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                    L 标注                         |
  |  B 板 =========================================   |
  |     接地符号                                      |
  |                    轨迹 2（绿色）→→→→→→→→→→→→    |
  |                    · · · · · · · · · · · · · ·   |
  |  入射点·→v₀       ·                     ·        |
  |           ·     ·                       ·        |
  |            ·   ·  电场线 || || ||        · d 标注 |
  |             · · · · · · · · · · · · · · ·        |
  |              · · · · · · · · · · · · · · ·       |
  |  A 板 =========================================   |
  |     φ_A              轨迹 1（红色）→→→→→→→→→→    |
  |                                                  |
  |              [电势范围结论文本框]                 |
  |                                                  |
  |           [◀上一步]  步骤 X/4  [下一步▶]          |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-4），每个状态对应显示/隐藏特定元素组
  2. 轨迹曲线：使用 SVG <path> 元素，d 属性为二次贝塞尔曲线 M180,250 Q430,250 680,340（轨迹 1）和 M180,250 Q430,250 680,160（轨迹 2）
  3. 电场线：使用 <line> 元素配合 marker-end 箭头，stroke-dasharray="5,5" 实现虚线
  4. 事件绑定：按钮点击事件切换状态，更新元素 display 属性
  5. 动画效果：轨迹使用 stroke-dasharray 和 stroke-dashoffset 实现绘制动画（可选）
- ID 命名规范：所有元素 ID 以 scene2- 为前缀
  - scene2-plate-a, scene2-plate-b, scene2-ground, scene2-entry-point
  - scene2-traj1, scene2-traj2, scene2-e-field-1, scene2-e-field-2, scene2-e-field-3
  - scene2-arrow-mg, scene2-arrow-qe, scene2-arrow-v0
  - scene2-label-a, scene2-label-b, scene2-label-l, scene2-label-d
  - scene2-label-v0, scene2-label-mg, scene2-label-qe, scene2-label-phi-a
  - scene2-label-traj1, scene2-label-traj2, scene2-conclusion-box
  - scene2-btn-prev, scene2-btn-next, scene2-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
