[图示主题与整合说明]
- 本图示主题：沿斜面方向的力分解与平衡方程可视化
- 整合内容：整合了重力分解、电场力分解、库仑力，展示沿斜面方向的平衡条件
- 教学价值：教师可逐步展示A球受力分析过程，从原始受力到力的分解，最终导出平衡方程。学生能直观理解为何要将力沿斜面和垂直斜面方向分解，以及各分力如何参与平衡。分步动画帮助学生建立"力的分解→分量合成→平衡方程"的完整思维链条。

[分步序列]
- 初始状态（步骤0）：显示斜面、A球、B球、电场线背景；显示原始力矢量：重力mg（竖直向下浅色）、电场力qE（水平向左浅色）；方程框显示"受力分析中..."
- 步骤1：点击「下一步」→ 重力分解：mg变为浅色#cccccc，出现红色分力mg sin37°（沿斜面向下）和mg cos37°（垂直斜面向下），显示灰色虚线辅助矩形；方程框显示"重力分解完成"
- 步骤2：点击「下一步」→ 电场力分解：qE变为浅色#cccccc，出现绿色分力qE cos37°（沿斜面向上）和qE sin37°（垂直斜面向上），显示灰色虚线辅助矩形；方程框显示"电场力分解完成"
- 步骤3：点击「下一步」→ 库仑力出现：绿色箭头F_C沿斜面向上（从A指向远离B方向）；方程框显示"库仑力 F_C = kq²/L²（沿斜面向上）"
- 步骤4：点击「下一步」→ 沿斜面方向高亮：mg sin37°、qE cos37°、F_C三个沿斜面方向的力加粗闪烁一次，方程框显示完整平衡方程"mg sin37° = qE cos37° + F_C"
- 步骤5：点击「下一步」→ 最终结果：方程框显示完整推导过程和E的表达式"E = (mg sin37° - kq²/L²) / (q cos37°)"；所有分力保持显示

  - 「上一步」按钮：位于(250,455)，点击后退到前一状态，步骤0时禁用
  - 「下一步」按钮：位于(450,455)，点击前进到下一状态，步骤5时禁用

- 教师操作流程：
  1. 初始状态展示题目情境（斜面、电场、A球位置）
  2. 点击「下一步」讲解重力如何分解为沿斜面和垂直斜面两个分力
  3. 点击「下一步」讲解电场力（因A带负电，方向与电场相反）的分解
  4. 点击「下一步」引入库仑力（B对A的斥力，沿斜面向上）
  5. 点击「下一步」引导学生观察沿斜面方向三力平衡关系
  6. 点击「下一步」展示最终E的表达式推导结果
  7. 可随时点击「上一步」回退复习关键步骤

[技术实现]
- JS 库选择及原因：原生SVG + 原生JavaScript。原因：本场景主要是静态几何图形和箭头，分步显示/隐藏，无需复杂动画库；SVG便于精确控制坐标和样式，代码简洁易维护。
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +----------------------------------------------------------+
  |  E→ 电场线背景（5条水平箭头）                            |
  |                                                          |
  |     /|                                                   |
  |    / |  斜面(左侧)           [方程框]                    |
  |   /  |  A球● 受力分解         沿斜面方向平衡：            |
  |  /37°|    ↘ mg sin37°        mg sin37° = qE cos37° + F_C |
  | /___ |    ↙ mg cos37°        F_C = kq²/L²                |
  | B●   |    ↖ qE cos37°        E = ...                     |
  |      |    ↖ qE sin37°                                     |
  |      |    ↖ F_C                                           |
  |                                                          |
  |                                                          |
  |              [◀上一步]  步骤X/5  [下一步▶]               |
  +----------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量currentStep(0-5)跟踪当前步骤，steps数组存储每步的显示配置
  2. 坐标计算：斜面角度37°，sin37°=0.6, cos37°=0.8，分力箭头方向用三角函数计算
  3. 动画曲线：分力出现用opacity从0到1的过渡（300ms ease-out）
  4. 事件绑定：按钮点击事件调用updateStep()函数，根据currentStep更新各元素display/opacity
  5. 禁用状态：步骤0时上一步按钮disabled=true，步骤5时下一步按钮disabled=true
- ID 命名规范：所有交互元素 ID 必须以 scene2- 为前缀
  - scene2-incline（斜面）
  - scene2-ball-a（A球）
  - scene2-ball-b（B球）
  - scene2-e-field-1~5（5条电场线）
  - scene2-force-mg（重力箭头）
  - scene2-force-mg-sin（重力沿斜面分力）
  - scene2-force-mg-cos（重力垂直斜面分力）
  - scene2-force-qe（电场力箭头）
  - scene2-force-qe-cos（电场力沿斜面分力）
  - scene2-force-qe-sin（电场力垂直斜面分力）
  - scene2-force-fc（库仑力箭头）
  - scene2-dash-1~4（4条分解辅助虚线）
  - scene2-label-*（所有文本标签）
  - scene2-equation-box（方程框）
  - scene2-btn-prev（上一步按钮）
  - scene2-btn-next（下一步按钮）
  - scene2-step-indicator（步骤指示）
- IIFE 隔离：所有JS包在 (function() { ... })() 中，避免全局变量污染
