[图示主题与整合说明]
- 本图示主题：B 球释放瞬间的受力分析与加速度
- 整合内容：整合了 B 球释放后受到的重力、支持力、电场力、A 球库仑力，展示合力方向和加速度
- 教学价值：教师如何使用此图示进行课堂讲解
  教师可逐步展示 B 球受力情况，从单一力到多个力的叠加，最后展示合力与加速度的关系。
  分步演示帮助学生理解牛顿第二定律在复合场中的应用，特别是如何分解力到沿斜面和垂直斜面方向。

[分步序列]
- 初始状态（步骤 0）：显示斜面、B 球、A 球（半透明参考）、5 条电场线、E 标签、37°倾角标注、"释放瞬间"文字标签（位于 B 球上方）
- 步骤 1：点击「下一步」→ 显示重力 mg 箭头（从 B 球中心竖直向下），显示"mg"标签
- 步骤 2：点击「下一步」→ 显示支持力 N 箭头（从 B 球中心垂直斜面向上），显示"N"标签
- 步骤 3：点击「下一步」→ 显示电场力 F_E 箭头（从 B 球中心水平向右），显示"F_E=qE"标签
- 步骤 4：点击「下一步」→ 显示库仑力 F_C 箭头（从 B 球中心沿斜面向下指向 A），显示"F_C=kq²/L²"标签
- 步骤 5：点击「下一步」→ 显示合力 F_合粗箭头（沿斜面向下），显示"F_合"标签；显示加速度 a 虚线箭头，显示"a"标签
- 步骤 6：点击「下一步」→ 在右侧计算式区域显示加速度计算式：
  "沿斜面方向：F_合 = mgsin37° + qEcos37° + kq²/L²"
  "a = F_合/m = gsin37° + qEcos37°/m + kq²/(mL²)"
  "a = 0.6g + 0.8qE/m + kq²/(mL²)"

  5. 可随时点击「上一步」回顾之前的受力情况

[技术实现]
- JS 库选择及原因：原生 SVG
  - 理由：几何图形（斜面、圆形小球、箭头）用 SVG 绘制最精确；力矢量箭头可用 SVG marker 实现；分步显示/隐藏用 CSS class 控制
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  E→ 电场线区域 (y=100~420)                       |
  |                                                  |
  |     A(参考)                                      |
  |        \                                         |
  |         \  斜面 37°                               |
  |      B ● \                                       |
  |       /|\ \                                      |
  |      / | \ \  力矢量从 B 出发                      |
  |     /  |  \ \                                     |
  |    /   |   \ \                                    |
  |   /____|____\_\___________________________________|
  |                                                  |
  |              [◀上一步] 步骤X/6 [下一步▶]          |
  +--------------------------------------------------+
  [控件栏在 SVG 内底部 y=460~490]
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-6) 跟踪当前步骤，数组 stepElements[step] 存储每步需显示的元素 ID
  2. 坐标计算：斜面倾角 37°，sin37°=0.6，cos37°=0.8；垂直斜面方向的角度为 37°+90°=127°
  3. 箭头绘制：使用 SVG <marker> 定义箭头，<line marker-end="url(#arrow)"> 绘制带箭头的线段
  4. 事件绑定：按钮点击事件切换 currentStep，调用 updateDisplay() 函数更新各元素 visibility
  5. 动画效果：力矢量出现时可用 CSS transition 实现淡入效果（opacity: 0→1，duration 300ms）
- ID 命名规范：所有交互元素 ID 必须以 scene3- 为前缀
  - scene3-incline（斜面）
  - scene3-ball-b（B 球）
  - scene3-ball-a（A 球参考）
  - scene3-e-field-1~5（5 条电场线）
  - scene3-force-mg（重力）
  - scene3-force-n（支持力）
  - scene3-force-fe（电场力）
  - scene3-force-fc（库仑力）
  - scene3-force-net（合力）
  - scene3-accel-a（加速度）
  - scene3-label-*（各标签）
  - scene3-btn-prev（上一步按钮）
  - scene3-btn-next（下一步按钮）
  - scene3-step-indicator（步骤指示器）
  - scene3-formula-box（计算式区域）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
