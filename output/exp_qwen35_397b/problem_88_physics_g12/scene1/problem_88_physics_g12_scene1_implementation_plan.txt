[图示主题与整合说明]
- 本图示主题：圆弧轨道电磁感应装置结构与金属棒运动轨迹
- 整合内容：轨道几何结构（四分之一圆弧）、磁场方向（竖直向上）、金属棒初始位置 cd 和末位置 ab、运动轨迹路径、电阻 R 连接
- 教学价值：教师可逐步展示装置各组成部分，帮助学生建立空间认知，理解金属棒在磁场中运动产生感应电动势的物理情景。分步展示便于讲解轨道几何关系、磁场分布、金属棒位置变化等关键概念。

[分步序列]
共 6 个状态（步骤 0-5），教师通过「上一步/下一步」按钮切换：

- 步骤 0（初始状态）：显示基础轨道框架
  - 显示：左侧轨道弧线、右侧轨道弧线、顶端连线 ab、底端连线 cd、圆心 O 点
  - 标签：O、a、b、c、d
  - 隐藏：磁场箭头、金属棒、电阻 R、尺寸标注、运动轨迹

- 步骤 1：添加磁场方向箭头
  - 显示：步骤 0 所有元素 + 5 条磁场箭头（竖直向上）
  - 新增标签：B（磁场符号，位于最右侧箭头旁）
  - 高亮：磁场箭头淡入动画

- 步骤 2：标注尺寸 r 和 L
  - 显示：步骤 1 所有元素 + 半径标注线（水平+垂直）、间距 L 标注线
  - 新增标签：r（水平）、r（垂直）、L
  - 高亮：尺寸标注线淡入动画

- 步骤 3：显示金属棒在 cd 位置
  - 显示：步骤 2 所有元素 + 金属棒 cd（蓝色粗线）
  - 新增标签：无（c、d 已存在）
  - 高亮：金属棒 cd 加粗显示，轻微脉冲动画

- 步骤 4：显示金属棒在 ab 位置
  - 显示：步骤 3 所有元素 + 金属棒 ab（绿色粗线）+ 电阻 R 符号
  - 新增标签：R（电阻符号上方）
  - 高亮：金属棒 ab 加粗显示，电阻 R 符号淡入

- 步骤 5（最终步骤）：高亮运动轨迹弧线
  - 显示：步骤 4 所有元素 + 运动轨迹弧线（红色虚线）
  - 高亮：运动轨迹弧线从 cd 中点到 ab 中点，虚线闪烁动画
  - 所有元素完整展示

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 按钮「◀上一步」：位置 (320,460)，尺寸 80×30px，点击返回上一状态
  - 按钮「下一步▶」：位置 (400,460)，尺寸 80×30px，点击进入下一状态
  - 状态指示器：位置 (500,465)，显示"步骤 X/5"，尺寸 60×20px
- 教师操作流程：
  1. 初始加载显示步骤 0（基础轨道），教师介绍装置基本结构
  2. 点击「下一步」显示磁场，讲解磁场方向与轨道的关系
  3. 点击「下一步」显示尺寸标注，讲解半径 r 和间距 L 的几何意义
  4. 点击「下一步」显示金属棒 cd 位置，讲解初始状态
  5. 点击「下一步」显示金属棒 ab 位置和电阻 R，讲解末状态和电路连接
  6. 点击「下一步」高亮运动轨迹，讲解金属棒运动路径
  7. 可随时点击「上一步」回退复习

[技术实现]
- JS 库选择：原生 SVG（适合几何图形、箭头、弧线绘制，无需额外库）
- 画布尺寸：800×500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  标题：圆弧轨道电磁感应装置 (y=25)               |
  |                                                  |
  |     O  r→                    a──────b  R         |
  |     │                        /      /            |
  |     │                       /      /             |
  |     │←─圆弧轨道─→          /      /              |
  |     │                     /      /               |
  |     │    ↑B ↑B ↑B       /      /                |
  |     │    ↑  ↑  ↑       /      /                 |
  |     c─────────────────d  (金属棒 cd)             |
  |                                                  |
  |  尺寸标注：r（垂直）、L（底部）                   |
  |                                                  |
  |              [◀上一步] [下一步▶] 步骤 X/5        |
  |                    (控件栏 y=450~490)            |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量 (0-5)，每个状态对应一组显示/隐藏的元素
  2. 坐标计算：圆弧使用 SVG <path> 的 A 命令，圆心 (120,80)，半径 250px，起始角 270°，终止角 0°
  3. 动画曲线：淡入使用 CSS transition opacity 0.5s ease-in-out
  4. 事件绑定：按钮点击事件切换状态，更新元素 display 属性
  5. 箭头绘制：使用 SVG <marker> 定义箭头头部，复用于磁场箭头和尺寸标注
- ID 命名规范：所有元素 ID 以 scene1- 为前缀
  - scene1-orbit-left（左侧轨道）
  - scene1-orbit-right（右侧轨道）
  - scene1-field-arrow-1~5（磁场箭头）
  - scene1-rod-cd（金属棒 cd）
  - scene1-rod-ab（金属棒 ab）
  - scene1-trajectory（运动轨迹）
  - scene1-resistor（电阻 R）
  - scene1-dim-r-h（半径 r 水平标注）
  - scene1-dim-r-v（半径 r 垂直标注）
  - scene1-dim-l（间距 L 标注）
  - scene1-label-o/a/b/c/d/r/L/R/B（各标签）
  - scene1-btn-prev/next（按钮）
  - scene1-status（状态指示器）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
- 响应式：固定画布 800×500，不随窗口缩放（教学投影场景）
