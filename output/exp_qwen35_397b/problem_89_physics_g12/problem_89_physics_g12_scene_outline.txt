    **题目原文：**

    如图所示，在直角坐标系 xoy 中，虚线 ab 将第一象限分成两块区域，左边区域匀强电场沿 x 轴正方向，电场强度 E₁，右边区域匀强电场方向沿 y 轴负方向，电场强度 E₂。现一个质量为 m（重力忽略不计），电荷量为 q 的正粒子静止放在 y 轴上的 P（0，h）点，粒子在电场力的作用下运动，最后从 x 轴上的 Q 点离开电场区域，已知虚线 ab 距 y 轴的距离 L，求：

    （1）粒子穿过 E₁ 电场区域的速度；
    （2）粒子经过 Q 点的速度大小；
    （3）Q 点的坐标。

    **题目分析：**

    本题是带电粒子在分段匀强电场中的运动问题，涉及两个物理过程：

    1. **E₁ 区域（0 < x < L）**：粒子从静止开始，受水平向右的电场力 F = qE₁，做初速度为零的匀加速直线运动
    2. **E₂ 区域（x > L）**：粒子具有水平速度 v₁，同时受竖直向下的电场力 F = qE₂，做类平抛运动

    **整体讲解思路：**

    - 先展示电场分布和粒子完整运动轨迹，建立整体认知
    - 再分析两个区域的运动学关系，推导速度和坐标
    - 最后总结类平抛运动的处理方法

    **图示规划说明：**

    共设计 3 个图示场景：
    - SCENE_1：电场分布与粒子运动轨迹总览（分步动画展示完整运动过程）
    - SCENE_2：速度矢量分析（展示关键位置的速度分解）
    - SCENE_3：运动参数关系探究（滑块调节参数观察轨迹变化）
    </TEXT_1>

    **教学说明：**

    本图示用于建立学生对物理情景的整体认知。教师应按以下步骤引导：

    1. **步骤 0-1**：先让学生识别坐标系、电场分布特点，确认已知条件（P 点坐标、边界位置 L）
    2. **步骤 2**：重点讲解 E₁ 区域的运动性质——从静止开始的匀加速直线运动，电场力做正功
    3. **步骤 3**：强调进入 E₂ 区域时粒子已有水平速度，电场力方向改变，运动性质变为类平抛
    4. **步骤 4-5**：总结完整轨迹特点，为后续计算做铺垫

    **关键公式推导：**

    E₁ 区域（匀加速直线运动）：
    - 加速度：a₁ = qE₁/m
    - 位移：L = ½a₁t₁²
    - 穿出速度：v₁ = a₁t₁ = √(2qE₁L/m)

    E₂ 区域（类平抛运动）：
    - 水平方向：匀速运动，vₓ = v₁
    - 竖直方向：初速度为 0 的匀加速，a₂ = qE₂/m
    - 竖直位移：h = ½a₂t₂²

    <TEXT_3>
    **教学说明：**

    本图示聚焦速度分析，是解题的核心环节。教师讲解要点：

    1. **P 点速度**：粒子从静止释放，v₀ = 0
    2. **ab 边界速度 v₁**：仅由 E₁ 区域电场力做功获得，方向水平向右
    3. **Q 点速度分解**：
       - 水平分量 vₓ = v₁（E₂ 区域水平方向不受力，匀速）
       - 竖直分量 vᵧ = a₂t₂ = (qE₂/m)·t₂
    4. **合速度计算**：v = √(vₓ² + vᵧ²)

    **完整解答：**

    （1）粒子穿过 E₁ 电场区域的速度：
    $$v_1 = \sqrt{\frac{2qE_1L}{m}}$$

    （2）粒子经过 Q 点的速度大小：
    $$v = \sqrt{v_1^2 + v_y^2} = \sqrt{\frac{2qE_1L}{m} + \frac{2qE_2h}{m}} = \sqrt{\frac{2q(E_1L + E_2h)}{m}}$$

    （3）Q 点坐标：
    - 竖直方向：h = ½(qE₂/m)t₂² → t₂ = √(2mh/qE₂)
    - 水平位移：x = L + v₁t₂ = L + √(2qE₁L/m)·√(2mh/qE₂) = L + 2√(E₁Lh/E₂)
    - Q 点坐标：(L + 2√(E₁Lh/E₂), 0)
    </TEXT_3>

    **总结与课堂讲解建议：**

    **核心知识点：**
    1. 带电粒子在匀强电场中的受力分析（F = qE）
    2. 匀加速直线运动的处理方法
    3. 类平抛运动的分解思想（水平匀速 + 竖直匀加速）
    4. 分段运动的速度和位移关系

    **课堂讲解建议：**
    1. 先用 SCENE_1 建立整体认知，让学生描述运动过程
    2. 用 SCENE_2 深入分析速度变化，推导关键公式
    3. 用 SCENE_3 让学生动手调节参数，观察规律，验证公式
    4. 最后总结类平抛运动的处理方法：分解为两个独立的直线运动

    **易错点提醒：**
    - E₂ 区域水平方向不受力，速度保持不变
    - 竖直方向初速度为 0（不是 v₁ 的竖直分量）
    - Q 点坐标是总水平位移，不是 E₂ 区域的水平位移
