[分步序列]
- 初始状态（步骤 0）：显示三个玻璃管基础结构（轮廓、水银柱、气体区），显示所有尺寸标注（L=62cm, h=5cm, l₁=35cm, l₂=40cm, d），不显示压强关系和方程
- 步骤 1：高亮甲管（红色边框），显示压强框 P₁="P₁=P₀+h"，其他管正常显示
- 步骤 2：高亮乙管（红色边框），显示压强框 P₂="P₂=P₀-h"，显示玻意耳定律方程"P₁l₁=P₂l₂"，甲管恢复正常
- 步骤 3：高亮丙管（红色边框），显示丙管上下两部分气体标注，显示方程"(P₀+h)×35=P₀×40"，乙管恢复正常
- 步骤 4：显示完整解题过程："由(P₀+h)×35=P₀×40 得 P₀=35h/5=7h=35cmHg"，"丙状态：上气柱恢复 35cm，活塞距离 d=62-35-5-下气柱长度"

- "L=62cm"与"h=5cm"：水平距离 115px，垂直距离 25px → 无冲突
- "h=5cm"与"l₁=35cm"(甲)：水平距离 0px，垂直距离 100px → 无冲突（同侧但间距足够）
- "l₂=40cm"与"l₁=35cm"(丙)：水平距离 200px，垂直距离 0px → 无冲突
- 所有管名标签"甲/乙/丙"间距 200px → 无冲突
- 压强框与方程区 y=420~480，与管名标签 y=400 间距 20px → 无冲突

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位置 (320,460)，点击回退到前一状态
  - 「下一步」按钮：位置 (420,460)，点击进入下一状态
  - 状态指示器：位置 (380,460)，显示"步骤 X/4"
- 教师操作流程：
  1. 初始展示三状态全貌，让学生观察差异
  2. 点击「下一步」高亮甲管，讲解开口向上时压强 P₁=P₀+h
  3. 点击「下一步」高亮乙管，讲解开口向下时压强 P₂=P₀-h，引入玻意耳定律
  4. 点击「下一步」高亮丙管，讲解活塞推动后上下两部分气体状态
  5. 点击「下一步」展示完整方程和解题过程
  6. 可随时点击「上一步」回退复习

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |   [甲管]        [乙管]        [丙管]             |
  |   100-140      300-340      500-540             |
  |   y:80-380     y:80-380     y:80-380            |
  |                                                  |
  |   甲          乙          丙                     |
  |  (120,400)  (320,400)  (520,400)                |
  |                                                  |
  |  [P₁框]    [P₂框]      [方程展示区]              |
  |  (50,420) (200,420)   (350,420)                 |
  |                                                  |
  |        [◀上一步] [步骤 X/4] [下一步▶]            |
  |         (320,460) (380,460) (420,460)           |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentState 跟踪当前步骤（0-4），数组存储每步的可见元素 ID 列表
  2. 高亮效果：通过切换高亮框的 display 属性实现，红色边框 #c62828 stroke-width=3
  3. 坐标计算：所有元素使用绝对坐标，比例换算：1cm ≈ 4.84px（300px/62cm）
  4. 事件绑定：按钮点击事件切换状态，更新可见元素和状态指示器文本
  5. 初始状态：页面加载时显示步骤 0 的所有元素
- ID 命名规范：所有交互元素 ID 以 scene1- 为前缀，如 scene1-tube-a、scene1-mercury-a、scene1-highlight-a、scene1-btn-prev、scene1-btn-next
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
