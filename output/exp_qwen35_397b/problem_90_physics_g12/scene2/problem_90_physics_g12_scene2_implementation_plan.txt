[分步序列]
共6步（步骤0~5），教师可通过「上一步/下一步」按钮控制进度：

- 步骤0（初始状态）：显示状态丙原图
  - 显示：玻璃管轮廓、管顶封闭端、管口开口端
  - 显示：上端气体区域（浅蓝）、水银柱区域（深色）、下端气体区域（浅绿）、活塞（红色粗线）
  - 隐藏：所有尺寸标注线、压强标注、方程
  - 视觉：仅展示基础图形，等待教师讲解

- 步骤1：标注上端气体
  - 新增：尺寸标注线 l₁（右侧双箭头线，y=80~280）
  - 新增：标签"l₁=35cm"（右侧x=460, y=180）
  - 新增：压强标注"P₃"（左侧x=340, y=180，绿色）
  - 高亮：上端气体区域边框加粗
  - 方程区：显示"上端气体：l₁ = 35cm, 压强 P₃"

- 步骤2：标注水银柱压强关系
  - 新增：尺寸标注线 h（右侧双箭头线，y=280~308）
  - 新增：标签"h=5cm"（右侧x=460, y=294）
  - 新增：压强平衡方程"P₃ = P₄ + h"（方程区中央，绿色）
  - 高亮：水银柱区域边框加粗
  - 方程区：显示"P₃ = P₄ + 5cmHg"

- 步骤3：标注下端气体
  - 新增：尺寸标注线 l₄（右侧双箭头线，y=308~422）
  - 新增：标签"l₄"（右侧x=460, y=365）
  - 新增：压强标注"P₄"（左侧x=340, y=365，绿色）
  - 高亮：下端气体区域边框加粗
  - 方程区：显示"下端气体：压强 P₄, 长度 l₄ = ?"

- 步骤4：标注活塞位置与几何约束
  - 新增：尺寸标注线 d（右侧双箭头线，y=422~430）
  - 新增：标签"d"（右侧x=460, y=426）
  - 新增：压强标注"P₀"（左侧x=340, y=445，绿色，管口外）
  - 新增：几何约束方程"L = l₁ + h + l₄ + d"（方程区）
  - 方程区：显示"62 = 35 + 5 + l₄ + d"

- 步骤5（最终步骤）：展示完整方程组和解
  - 显示所有标注元素
  - 方程区显示完整求解过程：
    ```
    由(1)等温过程：P₃ × 35 = 80 × 35 → P₃ = 80cmHg
    由(2)压强平衡：P₄ = P₃ - h = 80 - 5 = 75cmHg
    由(3)等温过程：P₄ × l₄ = 70 × 22 → l₄ = 20.53cm
    由(4)几何约束：d = 62 - 35 - 5 - 20.53 = 1.47cm
    ```
  - 高亮：最终答案"d = 1.47cm"用红色框标注

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于SVG底部左侧(320,465)，点击回退到前一步状态
  - 「下一步」按钮：位于SVG底部右侧(420,465)，点击前进到下一步状态
  - 步骤指示器：位于两按钮之间(380,470)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始加载显示步骤0（状态丙原图），教师介绍图示结构
  2. 点击「下一步」到步骤1，讲解上端气体状态
  3. 点击「下一步」到步骤2，讲解水银柱压强传递关系
  4. 点击「下一步」到步骤3，讲解下端气体状态
  5. 点击「下一步」到步骤4，讲解几何约束条件
  6. 点击「下一步」到步骤5，展示完整方程组和解
  7. 可随时点击「上一步」回退复习关键步骤

[技术实现]
- JS 库选择：原生 SVG（简单几何图形首选，无需额外库）
- 画布尺寸：800×500px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |     压强标注          玻璃管          尺寸标注    |
  |     P₃(340,180)   ┌───────┐        l₁=35cm      |
  |                   │#######│  上端气体            |
  |                   │#######│                     |
  |     P₄(340,365)   │~~~~~~~│  水银柱    h=5cm    |
  |                   │.......│  下端气体            |
  |                   │.......│                     |
  |                   ├───────┤  活塞      d        |
  |     P₀(340,445)   └───────┘                     |
  |                                                  |
  |  [方程展示区 y=450~490]                          |
  |  [控件栏：◀上一步  步骤X/5  下一步▶]             |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0~5) 跟踪当前步骤，数组 stepStates 存储每步的可见元素ID列表
  2. 坐标计算：所有元素坐标硬编码，确保与布局坐标表一致
  3. 动画曲线：步骤切换使用 CSS transition，opacity 从0到1，duration=300ms
  4. 事件绑定：按钮点击事件绑定到 stepChange 函数，更新 currentStep 并刷新可见性
  5. 方程渲染：使用<tspan>换行，或预渲染为多行text元素
- ID 命名规范：所有交互元素 ID 必须以 scene2- 为前缀
  - scene2-tube（玻璃管）
  - scene2-gas-upper（上端气体）
  - scene2-mercury（水银柱）
  - scene2-gas-lower（下端气体）
  - scene2-piston（活塞）
  - scene2-label-l1（l₁标签）
  - scene2-label-h（h标签）
  - scene2-label-l4（l₄标签）
  - scene2-label-d（d标签）
  - scene2-pressure-p3（P₃标注）
  - scene2-pressure-p4（P₄标注）
  - scene2-pressure-p0（P₀标注）
  - scene2-dim-l1（l₁尺寸线）
  - scene2-dim-h（h尺寸线）
  - scene2-dim-l4（l₄尺寸线）
  - scene2-dim-d（d尺寸线）
  - scene2-equation（方程区）
  - scene2-btn-prev（上一步按钮）
  - scene2-btn-next（下一步按钮）
  - scene2-step-indicator（步骤指示器）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
- 多场景合并兼容：使用 getElementById('scene2-xxx') 精确选择，不使用全局 class 选择器
