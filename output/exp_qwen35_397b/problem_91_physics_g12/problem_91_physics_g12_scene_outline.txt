    **题目原文：**

    如图所示，光滑绝缘水平面上固定着 A、B、C 三个带电小球，它们的质量为 m，间距均为 r，A、B 带正电，电荷量均为 q。现对 C 施一水平力 F 的同时放开三个小球，欲使三小球在运动过程中保持间距 r 不变，求：
    （1）C 球的电性和电荷量；
    （2）水平力 F 的大小。

    **题目分析：**

    本题是库仑定律与牛顿第二定律的综合应用题。关键条件是"三小球在运动过程中保持间距 r 不变"，这意味着三球必须以相同的加速度一起运动，相对位置保持不变。

    **整体讲解思路：**

    1. 首先分析 C 球的电性：由于 A、B 带正电，相互排斥，要使三球保持等边三角形构型，C 必须对 A、B 有吸引力，故 C 带负电

    2. 对 A 球（或 B 球）进行受力分析：受到 B 的斥力、C 的引力，合力方向水平向右（与加速度方向一致）

    3. 利用对称性和几何关系，求出 C 的电荷量

    4. 对整体或单个小球应用牛顿第二定律，求出加速度 a 和力 F

    **图示规划说明：**

    - SCENE_1：三球位置与受力分析整合图，展示库仑力方向与合力方向
    - SCENE_2：A 球受力分解图，展示力的矢量合成与几何关系

    </TEXT_1>

    **教学要点：**

    本图示展示三球系统的整体受力情况。教师应引导学生观察：

    1. 由于 A、B 带正电，它们之间相互排斥（F_AB、F_BA 为斥力）

    2. 要使三球保持等边三角形构型一起向右加速，C 必须对 A、B 产生吸引力，因此 C 带负电

    3. 三球相对位置不变，说明它们具有相同的加速度 a，方向水平向右

    4. 对 A 球：F_BA（B 对 A 的斥力，沿 BA 向上）与 F_CA（C 对 A 的引力，沿 AC 指向 C）的合力必须水平向右

    5. 对 B 球：受力情况与 A 球对称

    6. 对 C 球：受到 A、B 的引力（沿 CA、CB 指向 A、B）和外力 F，合力水平向右

    **关键公式：**

    库仑定律：$F = k\frac{q_1 q_2}{r^2}$

    牛顿第二定律：$F_{合} = ma$

    **教学要点：**

    本图示聚焦 A 球的受力分解，是求解 C 球电荷量的关键。教师应引导学生：

    1. 观察 F_BA 方向：沿 BA 连线，因 A、B 同为正电，故为斥力，方向竖直向上

    2. 观察 F_CA 方向：沿 AC 连线，因 C 带负电，故为引力，方向指向 C（右下）

    3. 由于三球保持等边三角形，A 球竖直方向合力为零（否则会有竖直加速度，破坏构型）

    4. 利用几何关系：等边三角形内角为 60°，F_CA 与水平方向夹角为 60°

    **推导步骤：**

    1. 竖直方向平衡：$F_{BA} = F_{CA} \sin 60°$

    2. 代入库仑定律：$k\frac{q^2}{r^2} = k\frac{qQ}{r^2} \cdot \frac{\sqrt{3}}{2}$

    3. 解得：$Q = \frac{2q}{\sqrt{3}} = \frac{2\sqrt{3}}{3}q$

    4. 水平方向合力：$F_{CA} \cos 60° = ma$

    5. 代入得：$k\frac{qQ}{r^2} \cdot \frac{1}{2} = ma$

    6. 对整体：$F = 3ma$

    7. 联立解得：$F = \frac{3kqQ}{2r^2} = \frac{3kq}{2r^2} \cdot \frac{2\sqrt{3}q}{3} = \frac{\sqrt{3}kq^2}{r^2}$

    <TEXT_4>
    **教学要点：**

    本图示展示求解外力 F 的两种方法，教师应引导学生对比理解：

    **方法一：隔离法（分析 C 球）**

    1. C 球受 A、B 的引力 F_AC、F_BC，方向分别指向 A、B

    2. 由对称性，F_AC = F_BC = $k\frac{qQ}{r^2}$

    3. 两力在竖直方向分量抵消，水平方向分量相加

    4. 水平合力：$2F_{AC} \cos 60° = 2 \cdot k\frac{qQ}{r^2} \cdot \frac{1}{2} = k\frac{qQ}{r^2}$

    5. 对 C 球：$F - k\frac{qQ}{r^2} = ma$

    **方法二：整体法（分析三球系统）**

    1. 三球作为整体，内力（库仑力）相互抵消

    2. 整体仅受外力 F

    3. 整体质量：3m

    4. 由牛顿第二定律：$F = 3ma$

    **最终答案：**

    （1）C 球带负电，电荷量 $Q = \frac{2\sqrt{3}}{3}q$

    （2）水平力 $F = \frac{\sqrt{3}kq^2}{r^2}$

    **课堂讲解建议：**

    - 先让学生判断 C 的电性（定性分析）
    - 再用 SCENE_2 分析 A 球受力求电荷量（定量计算）
    - 最后用 SCENE_3 对比两种方法求 F，强调整体法的简洁性
