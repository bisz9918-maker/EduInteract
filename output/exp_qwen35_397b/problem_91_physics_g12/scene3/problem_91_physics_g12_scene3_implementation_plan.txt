[分步序列]
- 初始状态（状态 0）：显示左侧 C 球隔离受力图
  - 显示元素：C 球、C 标签、-Q 标签、F_AC 箭头及标签、F_BC 箭头及标签、F 外力箭头及标签
  - 隐藏元素：右侧整体图、方程框
  - 视觉：C 球位于左侧中央，三个力箭头从 C 球中心发出

- 状态 1：点击「整体法」→ 显示右侧三球整体图
  - 显示元素：A/B/C 三球、虚线三角形、整体虚线框、F 外力箭头（绿色）、a 加速度箭头及标签
  - 隐藏元素：左侧隔离图、方程框
  - 视觉：三球构成等边三角形，被虚线框包围，整体受外力 F 向右加速

- 状态 2：点击「对比」→ 显示两种方法的方程对比
  - 显示元素：隔离法方程框（左侧）、整体法方程框（右侧）
  - 隔离法方程：F_AC = F_BC = kqQ/r², F_x = F - 2F_AC·cos60° = ma
  - 整体法方程：F_合 = 3ma, 故 F = 3ma
  - 结论高亮：两种方法结果一致 F = 3ma

[交互方案]
- 交互类型：多状态切换（3 个按钮）
- 控件说明：
  - 按钮 1「隔离法」：位置 (150, 460)，显示状态 0（C 球隔离受力图）
  - 按钮 2「整体法」：位置 (300, 460)，显示状态 1（三球整体图）
  - 按钮 3「对比」：位置 (450, 460)，显示状态 2（方程对比）
- 教师操作流程：
  1. 点击「隔离法」：讲解 C 球受力分析，F_AC 和 F_BC 是 A、B 对 C 的库仑引力，外力 F 向右
  2. 点击「整体法」：讲解将三球视为整体，内力抵消，仅受外力 F，加速度为 a
  3. 点击「对比」：展示两种方法的方程，说明结果一致 F = 3ma，帮助学生理解方法等价性

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |   [状态 0: C 球隔离图]    [状态 1: 整体图]       |
  |        (左侧)              (右侧)                |
  |         C●←F_AC            A●  ●C→F             |
  |          ↑                 |  /                  |
  |         F_BC↓              | /                   |
  |          |                 |/                    |
  |         F→                 B●                    |
  |                                                  |
  |   [状态 2: 方程对比]                             |
  |   +----------------+    +----------------+       |
  |   | 隔离法方程     |    | 整体法方程     |       |
  |   | F_AC=kqQ/r²    |    | F=3ma          |       |
  |   +----------------+    +----------------+       |
  |                                                  |
  |   [○隔离法]  [○整体法]  [○对比]   ← 控件栏 y=450 |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用 currentState 变量跟踪（0/1/2），切换时隐藏/显示对应元素组
  2. 元素分组：将状态 0、1、2 的元素分别放入<g>组，用 display 控制显示
  3. 箭头绘制：用<line>+<polygon>组合，或 SVG marker-end
  4. 虚线样式：stroke-dasharray="5,5"
  5. 按钮高亮：当前激活状态按钮添加高亮样式
- ID 命名规范：所有元素 ID 以 scene3- 为前缀
  - scene3-c-ball-iso, scene3-f-ac, scene3-f-bc, scene3-f-iso
  - scene3-a-ball, scene3-b-ball, scene3-c-ball-whole, scene3-f-whole, scene3-a-arrow
  - scene3-iso-eq-box, scene3-whole-eq-box
  - scene3-btn-iso, scene3-btn-whole, scene3-btn-compare
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
