    **题目原文：**

    如图所示，两平行金属板A、B长l=8cm，两板间距离d=8cm，A板比B板电势高300V，即U_AB=300V．一带正电的粒子电量q=10^-10C，质量m=10^-20kg，从R点沿电场中心线垂直电场线飞入电场，初速度v_0=2×10^6m/s，粒子飞出平行板电场后经过界面MN、PS间的无电场区域后，进入固定在中心线上的O点的点电荷Q形成的电场区域（设界面PS右边点电荷的电场分布不受界面的影响）．已知两界面MN、PS相距为L=12cm，粒子穿过界面PS最后垂直打在放置于中心线上的荧光屏EF上．不计粒子重力．（静电力常数k=9×10^9 N•m^2/C^2）求：
    （1）粒子穿过界面PS时偏离中心线RO的距离多远；
    （2）粒子从电场中飞出时的速度方向与水平方向的夹角θ；
    （3）点电荷的电量．

    **题目分析：**

    本题是带电粒子在复合电场中运动的综合问题，包含三个运动阶段：
    1. 平行板电场中的类平抛运动（匀强电场）
    2. MN-PS间无电场区域的匀速直线运动
    3. 点电荷Q电场中的匀速圆周运动（库仑力提供向心力）

    **整体讲解思路：**

    采用"分段分析→整体整合"的策略。先分析每个阶段的运动规律和物理量，再将三段运动整合为完整轨迹。关键在于理解"垂直打在荧光屏上"意味着粒子在点电荷电场中做圆周运动，速度方向始终与半径垂直。

    **图示规划说明：**

    - SCENE_1：完整运动轨迹图，整合三段运动的连续轨迹
    - SCENE_2：平行板电场中的类平抛运动分解（速度矢量分析）
    - SCENE_3：点电荷电场中的圆周运动几何关系

    本图示展示粒子运动的完整空间轨迹，教师应引导学生：
    1. 观察轨迹的三段特征：抛物线（匀强电场中类平抛）→直线（无电场匀速）→圆弧（点电荷电场圆周运动）
    2. 理解"垂直打在荧光屏上"的几何含义：粒子速度方向与中心线垂直，说明在点电荷电场中做圆周运动

    **关键公式推导：**

    1. 平行板电场中的加速度：
       a = qE/m = qU/(md)

    2. 电场中运动时间：
       t_1 = l/v_0

    3. 飞出电场时竖直分速度：
       v_y = at_1 = qUl/(mdv_0)

    4. 速度偏转角：
       tanθ = v_y/v_0 = qUl/(mdv_0^2)

    5. 电场中竖直位移：
       y_1 = (1/2)at_1^2 = qUl^2/(2mdv_0^2)

    6. 无电场区域竖直位移：
       y_2 = L·tanθ = qUlL/(mdv_0^2)

    7. PS界面处总偏离：
       y = y_1 + y_2 = qUl/(2mdv_0^2)·(l + 2L)

    **教学说明：**

    本图示聚焦平行板电场出口处的速度分析，教师应强调：
    1. 类平抛运动的分解思想：水平方向匀速直线运动，竖直方向匀加速直线运动
    2. 速度偏转角θ的正切值等于竖直分速度与水平分速度之比
    3. 该θ角也是粒子进入无电场区域后轨迹与水平方向的夹角

    **计算过程：**

    代入数据计算：
    - q = 10^-10 C
    - U = 300 V
    - l = 0.08 m
    - m = 10^-20 kg
    - d = 0.08 m
    - v_0 = 2×10^6 m/s

    tanθ = (10^-10 × 300 × 0.08) / (10^-20 × 0.08 × (2×10^6)^2)
         = (2.4×10^-9) / (3.2×10^-9)
         = 0.75

    θ = arctan(0.75) ≈ 37°

    v_y = v_0·tanθ = 2×10^6 × 0.75 = 1.5×10^6 m/s

    合速度：v = √(v_0^2 + v_y^2) = 2.5×10^6 m/s

    <TEXT_4>
    **教学说明：**

    本图示揭示点电荷电场中圆周运动的物理本质，教师应强调：
    1. "垂直打在荧光屏上"说明粒子速度方向与中心线垂直，即粒子做圆周运动
    2. 库仑力提供向心力：F_库 = F_向
    3. 轨道半径r由几何关系确定

    **几何关系分析：**

    粒子在PS界面处：
    - 竖直偏离：y = y_1 + y_2
    - 速度方向与水平夹角：θ（tanθ = 0.75）

    由几何关系，轨道半径r满足：
    r·cosθ = 水平距离（粒子入射点到O点）
    r·sinθ = y（竖直偏离）

    因此：r = y/sinθ

    **向心力方程：**

    kQq/r^2 = mv^2/r

    解得：Q = mv^2·r/(kq)

    代入数据即可求得点电荷电量Q。

    **完整解答总结：**

    （1）y = qUl(l+2L)/(2mdv_0^2) = 0.12 m = 12 cm

    （2）θ = arctan(0.75) ≈ 37°

    （3）由r = y/sinθ ≈ 0.12/0.6 = 0.2 m
        v = 2.5×10^6 m/s
        Q = mv^2·r/(kq) ≈ 1.39×10^-8 C
