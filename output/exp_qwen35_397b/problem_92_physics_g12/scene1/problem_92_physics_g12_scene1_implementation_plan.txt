[图示主题与整合说明]
- 本图示主题：带电粒子在三段电场区域的完整运动轨迹
- 整合的步骤/概念：平行板电场偏转轨迹（抛物线）+ 无电场区域直线轨迹 + 点电荷电场圆周轨迹 + 关键位置标注（y、θ、r）
- 教学价值：教师可分步展示粒子运动的三个阶段，帮助学生理解每段运动的物理规律（类平抛→匀速直线→圆周运动），最后整合为完整轨迹形成整体认知。通过动态轨迹展示，学生可直观理解速度方向变化、偏离距离计算等关键概念。

[分步序列]
步骤0（初始状态）：仅显示装置结构
- 显示：金属板A/B、界面MN/PS、中心线RO、点电荷Q、荧光屏EF、入射点R
- 显示尺寸标注：l=8cm、d=8cm、L=12cm
- 显示标签：A、B、M、N、P、S、R、O、E、F、v0
- 隐藏：粒子轨迹、偏离距离y、角度θ

步骤1：平行板电场中的抛物线轨迹
- 新增：红色抛物线轨迹从R(50,250)到MN界面(280,265)
- 新增：入射速度v0箭头（水平向右，从R点出发）
- 高亮：金属板A/B区域
- 教师讲解：粒子在平行板电场中做类平抛运动，轨迹为抛物线

步骤2：无电场区域的直线延伸
- 新增：红色直线轨迹从MN(280,265)到PS(520,300)
- 新增：角度θ标注（在MN界面出射点处，红色小弧线）
- 高亮：MN到PS区域
- 教师讲解：粒子离开电场后做匀速直线运动，速度方向与水平成θ角

步骤3：点电荷电场中的圆弧轨迹
- 新增：红色圆弧轨迹从PS(520,300)到荧光屏(700,250)
- 新增：偏离距离y标注（PS界面处蓝色双箭头，从中心线到出射点）
- 高亮：点电荷Q区域、荧光屏
- 教师讲解：粒子在点电荷电场中做圆周运动，最终垂直打在荧光屏上

步骤4：完整轨迹+关键位置标注
- 显示：完整红色轨迹（三段连续）
- 显示：所有标注（y、θ、l、d、L）
- 高亮：整个运动路径
- 教师讲解：整合三段运动，总结解题思路

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 按钮"◀上一步"：位置(320,460)，尺寸80×30px，点击后退到前一状态
  - 按钮"下一步▶"：位置(400,460)，尺寸80×30px，点击前进到下一状态
  - 步骤指示器：位置(420,465)，显示"步骤X/4"
- 教师操作流程：
  1. 初始展示装置结构（步骤0），介绍题目条件
  2. 点击"下一步"展示抛物线轨迹（步骤1），讲解类平抛运动
  3. 点击"下一步"展示直线轨迹（步骤2），讲解匀速直线运动及θ角
  4. 点击"下一步"展示圆弧轨迹（步骤3），讲解圆周运动及偏离距离y
  5. 点击"下一步"展示完整轨迹（步骤4），整合三段运动总结解题思路
  6. 可随时点击"上一步"回退复习

[技术实现]
- JS库选择：原生SVG（简单几何图形首选，无需额外库）
- 画布尺寸：800×500px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                    L=12cm                        |
  |  A板=====[MN]=============[PS]    Q  E====F      |
  |        |  抛物线  |  直线  |  圆弧  |           |
  |  B板=====|========|========|=======|            |
  |        d=8cm      |        y      θ            |
  |     l=8cm         |                            |
  |  R→v0_____________中心线_______________________|
  |                                                  |
  |              [◀上一步][下一步▶] 步骤X/4         |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用currentState变量(0-4)跟踪当前步骤，steps数组存储每步显示的元素ID列表
  2. 轨迹绘制：抛物线用SVG path二次贝塞尔曲线，直线用line元素，圆弧用path弧线段
  3. 动画曲线：轨迹显示用stroke-dasharray+stroke-dashoffset实现绘制动画（duration: 800ms）
  4. 事件绑定：按钮点击事件切换状态，调用updateScene()函数更新显示
  5. 元素显隐：每步调用setVisibility(elementId, visible)控制元素显示

- ID命名规范（所有ID以scene1-为前缀）：
  - 金属板：scene1-plate-A, scene1-plate-B
  - 界面：scene1-boundary-MN, scene1-boundary-PS
  - 中心线：scene1-center-line
  - 点电荷：scene1-charge-Q
  - 荧光屏：scene1-screen-EF
  - 入射点：scene1-point-R
  - 轨迹：scene1-trajectory-parabola, scene1-trajectory-line, scene1-trajectory-arc
  - 标注：scene1-label-y, scene1-label-theta, scene1-dim-l, scene1-dim-d, scene1-dim-L
  - 标签文本：scene1-text-A, scene1-text-B, ..., scene1-text-v0
  - 控件：scene1-btn-prev, scene1-btn-next, scene1-step-indicator

- IIFE隔离：所有JS代码包在(function() { ... })()中，避免全局变量污染
