[图示主题与整合说明]
- 本图示主题：平行板电场中类平抛运动的速度矢量分解
- 整合的内容：初速度 v₀、竖直分速度 v_y、合速度 v、偏转角θ的矢量关系 + 运动分解示意
- 教学价值：教师可通过分步展示矢量合成过程，帮助学生建立速度矢量叠加的直观认识，理解带电粒子在匀强电场中做类平抛运动时速度方向的变化规律，掌握偏转角的计算方法 tanθ=v_y/v₀

[技术实现]
- JS 库选择：原生 SVG（简单几何矢量图，无需额外库）
- 画布尺寸：800×500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |                    数值框区                       |
  |              (580,150) - (760,380)               |
  |                                                  |
  |         v₀                                       |
  |         →───────────────┐                        |
  |         │               │                        |
  |         │               ↓ v                      |
  |         │              ↗                         |
  |       原点 O'          /                         |
  |         │            / θ                         |
  |         ↓ v_y      /                            |
  |         │        /                              |
  |         └───────┘                               |
  |                                                  |
  |              tanθ=v_y/v₀                         |
  |                                                  |
  |     [◀上一步]        步骤 X/4        [下一步▶]   |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-4) 跟踪当前步骤
  2. 每个步骤对应一组 SVG 元素的显示/隐藏（通过 display 属性或 opacity）
  3. 箭头绘制：使用 SVG <marker> 定义箭头，<line> 或 <path> 绘制矢量
  4. 平行四边形辅助线：虚线 stroke-dasharray="5,5"
  5. 角度弧线：SVG <path> 绘制圆弧，使用圆弧命令 A
  6. 按钮事件：点击上一步 currentStep--，点击下一步 currentStep++，边界检查
  7. 每步更新后调用 updateDisplay() 函数刷新各元素可见性
- ID 命名规范：所有交互元素 ID 必须以 scene2- 为前缀（如 scene2-vec-v0、scene2-vec-vy、scene2-vec-v、scene2-btn-prev、scene2-btn-next）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
