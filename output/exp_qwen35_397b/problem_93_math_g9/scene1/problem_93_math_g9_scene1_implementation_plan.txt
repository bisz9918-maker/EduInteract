[图示主题与整合说明]
- 本图示主题：等边三角形构造与相似三角形识别
- 整合内容：等边三角形 ACD 和 BCE 的构造、点 P/F/G/H 的定义、第 (1) 问所有相似三角形的高亮展示

[视觉元素清单]
- 线段 AB：黑色实线，线宽 2px，位置 (100,380)-(700,380)
- 等边三角形 ACD：蓝色边框 #1565c0，线宽 2.5px，顶点 A(100,380), C(300,380), D(200,207)
- 等边三角形 BCE：蓝色边框 #1565c0，线宽 2.5px，顶点 B(700,380), C(300,380), E(500,34)
- 线段 DE：黑色实线，线宽 2px，连接 D(200,207) 和 E(500,34)
- 点 P：黑色实心圆 r=4，位置 (350,120)，标签"P"在上方 (350,108)
- 点 F：黑色实心圆 r=4，位置 (600,207)，标签"F"在右侧 (612,210)
- 线段 AF：黑色实线，线宽 2px，连接 A(100,380) 和 F(600,207)
- 点 G：黑色实心圆 r=4，AF 与 DC 交点，标签"G"在左侧 (228,300)
- 点 H：黑色实心圆 r=4，AF 与 CE 交点，标签"H"在右侧 (440,263)
- 顶点标签 A/B/C/D/E：黑色 text，位置见布局坐标表
- AB=8 标注：黑色 text，位置 (400,405)，表示线段 AB 长度为 8
- 相似三角形高亮层：半透明填充，透明度 20%，分三对用不同颜色

颜色规格：

- 主线（AB、DE、AF 等）：#000000，线宽 2px

[分步序列]
步骤 0（初始状态/基础图形）：
- 显示：线段 AB、等边三角形 ACD 和 BCE（蓝色边框）、线段 DE、点 P（DE 中点）、点 F（BE 中点）、线段 AF、点 G（AF∩DC）、点 H（AF∩CE）
- 显示所有顶点标签：A、B、C、D、E、P、F、G、H
- 显示 AB=8 标注
- 无高亮填充

步骤 1（高亮第一对相似三角形：△DGP∽△EHP）：
- 在步骤 0 基础上，添加蓝色半透明填充（#1565c0，透明度 20%）
- 填充区域：△DGP 和△EHP
- 边框加粗或变色提示（可选）

步骤 2（高亮第二对相似三角形：△AGC∽△FHB）：
- 清除步骤 1 的高亮
- 添加红色半透明填充（#c62828，透明度 20%）
- 填充区域：△AGC 和△FHB

步骤 3（高亮第三对相似三角形：△ADG∽△BEH）：
- 清除步骤 2 的高亮
- 添加绿色半透明填充（#2e7d32，透明度 20%）
- 填充区域：△ADG 和△BEH

步骤 4（显示所有相似三角形结论）：
- 清除所有高亮
- 在画布顶部或底部显示结论文本（简洁）：
  "相似三角形：△DGP∽△EHP，△AGC∽△FHB，△ADG∽△BEH"
- 或用三种颜色同时半透明显示三对三角形（透明度降至 10% 避免过深）

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 按钮"◀ 上一步"：位置 (320, 465)，点击后切换到前一个步骤（步骤 0 时禁用）
  - 按钮"下一步 ▶"：位置 (480, 465)，点击后切换到下一个步骤（步骤 4 时禁用）
  - 步骤指示器：位置 (420, 465)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始加载显示基础图形（步骤 0），教师引导学生观察图形结构
  2. 点击"下一步"进入步骤 1，高亮第一对相似三角形△DGP∽△EHP，提问学生为何相似
  3. 点击"下一步"进入步骤 2，高亮第二对相似三角形△AGC∽△FHB，引导学生分析对应角
  4. 点击"下一步"进入步骤 3，高亮第三对相似三角形△ADG∽△BEH
  5. 点击"下一步"进入步骤 4，显示全部结论，总结三对相似三角形
  6. 可随时点击"上一步"回退复习

[技术实现]
- JS 库选择：原生 SVG（简单几何图形首选，无需额外库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |                    D         E                   |
  |                     \       /                    |
  |                      \  P  /                     |
  |                       \   /                      |
  |                        \ /                       |
  |              G----------H-----------------F      |
  |             / \        / \                /      |
  |            /   \      /   \              /       |
  |           /     \    /     \            /        |
  |          A-------C---------B--------------------  |
  |                  AB=8                            |
  |                                                  |
  |          [◀上一步] [步骤 X/5] [下一步▶]          |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 currentStep (0-4) 跟踪当前步骤，数组 steps 存储每步的显示配置
  2. 坐标计算：G 和 H 为直线交点，需用 JS 动态计算（直线 AF 与 DC/CE 的交点公式）
  3. 动画曲线：步骤切换使用 CSS transition，透明度变化 duration 300ms ease-in-out
  4. 事件绑定：按钮点击事件切换步骤，更新 SVG 元素显示状态
  5. 高亮层管理：用 <polygon> 元素绘制三角形填充，通过 display 或 opacity 控制显示
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀
  - scene1-line-ab, scene1-tri-acd, scene1-tri-bce, scene1-line-de
  - scene1-point-p, scene1-point-f, scene1-line-af
  - scene1-point-g, scene1-point-h
  - scene1-label-a, scene1-label-b, ..., scene1-label-h
  - scene1-highlight-1, scene1-highlight-2, scene1-highlight-3（三对相似三角形高亮层）
  - scene1-btn-prev, scene1-btn-next, scene1-step-indicator
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
- 直线交点计算函数：
  ```javascript
  function getIntersection(p1, p2, p3, p4) {
    // 直线 p1-p2 与 p3-p4 的交点
    // 使用参数方程或行列式方法计算
  }
  ```
