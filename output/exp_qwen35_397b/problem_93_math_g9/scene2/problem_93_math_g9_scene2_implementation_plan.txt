[分步序列]
- 初始状态（步骤 0）：显示线段 AB=8，点 C 为中点，AC=CB=4 标注，两个等边三角形 ACD 和 BCE（蓝色边框），点 D、E 标签
- 步骤 1：点击「下一步」→ 显示 DE 连线（黑色），高亮 DE 平行于 AB（添加平行符号），显示 P 为 DE 中点，显示 CP 垂线段（红色加粗），标注 CP⊥AB
- 步骤 2：点击「下一步」→ 标注 CP 长度计算过程：CP = 4×sin(60°) = 2√3，在 CP 右侧显示"CP=2√3"
- 步骤 3：点击「下一步」→ 显示 F 为 BE 中点，显示 AF 连线（绿色），显示交点 G（AF∩DC）和 H（AF∩CE），AF 分段显示：AG 实线、GH 虚线、HF 点线
- 步骤 4：点击「下一步」→ 在 AF 右侧显示比例"AG:GH:HF=2:1:1"，显示完整解答结论

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位于 SVG 内底部左侧 (x=320, y=455)，返回上一状态
  - 「下一步」按钮：位于 SVG 内底部右侧 (x=460, y=455)，进入下一状态
  - 步骤指示器：位于两按钮中间 (x=400, y=455)，显示"步骤 X/4"
- 教师操作流程：
  1. 初始状态展示基础图形，讲解 C 为中点条件
  2. 点击「下一步」展示 DE 和 CP，讲解对称性和垂直关系
  3. 点击「下一步」展示 CP 长度计算，讲解等边三角形高的计算
  4. 点击「下一步」展示 AF 及交点，讲解线段相交
  5. 点击「下一步」展示比例结论，完成比例推导

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  ┌────────────────────────────────────────────┐
  │                                            │
  │         D          P          E            │
  │        / \         |         / \           │
  │       /   \        |        /   \          │
  │      /  G  \       |       /  H  \         │
  │     /       \      |      /       \        │
  │    A---------C-----|-----F---------B       │
  │                                            │
  │              [CP=2√3]                      │
  │                                            │
  │         [AG:GH:HF=2:1:1]                   │
  │                                            │
  │    [◀上一步]  步骤 X/4  [下一步▶]          │
  └────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量 (0-4)，每个状态对应一组可见元素
  2. 所有元素预先生成，通过 display/opacity 控制可见性
  3. CP 线段使用红色 #c62828，线宽 3px
  4. AF 线段分段绘制：AG 实线、GH 虚线 (stroke-dasharray="5,5")、HF 点线 (stroke-dasharray="2,2")
  5. 按钮事件绑定：点击更新 currentState，调用 updateView() 刷新可见性
  6. 坐标计算：G 点为 AF 与 DC 交点，H 点为 AF 与 CE 交点，需预先计算
- ID 命名规范：所有元素 ID 以 scene2- 为前缀（如 scene2-ab、scene2-cp、scene2-af-ag）
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
