[分步序列]
- 初始状态（步骤 0）：显示左侧立体三棱柱（完整），右侧展开区空白，仅显示标题"三棱柱展开过程"
  - 可见元素：立体三棱柱（上底面、下底面、三个侧面）、上底面标签、下底面标签、侧面标签
  - 展开区：空白，等待展开

- 步骤 1：点击「下一步」→ 侧面展开成矩形带
  - 视觉变化：立体三棱柱淡出至透明度 50%，右侧出现三个并排矩形（侧面 1、2、3）
  - 新增元素：展开区-矩形 1(420,100)、矩形 2(480,100)、矩形 3(540,100)
  - 新增标签：①、②、③分别在矩形中心
  - 展开轨迹箭头 1 显示：从立体图指向展开区

- 步骤 2：点击「下一步」→ 上底面三角形展开
  - 视觉变化：立体图上底面淡出，展开区矩形 1 上方出现上三角形
  - 新增元素：展开区-上三角形 (420,100)-(450,50)-(480,100)
  - 展开轨迹箭头 2 显示：从上底面位置指向展开后的上三角形位置
  - 高亮：上三角形边框 #1565c0 加粗

- 步骤 3：点击「下一步」→ 下底面三角形展开
  - 视觉变化：立体图下底面淡出，展开区矩形 3 下方出现下三角形
  - 新增元素：展开区-下三角形 (540,200)-(570,250)-(600,200)
  - 展开轨迹箭头 3 显示：从下底面位置指向展开后的下三角形位置
  - 高亮：下三角形边框 #1565c0 加粗

- 步骤 4：点击「下一步」→ 完整展开图，与选项 A 对比
  - 视觉变化：立体图完全淡出，完整展开图高亮显示
  - 新增元素：选项 A 参考图 (620,320)-(750,420)，与当前展开图一致
  - 高亮：完整展开图所有边框 #1565c0 加粗
  - 显示结论文字："选项 A 正确"（绿色 #2e7d32）

- 最终步骤：展示所有结论，教师可点击「上一步」回退复习

冲突检查：
- "上底面"(170,45) 与 "下底面"(170,255)：垂直距离 210px → 无冲突
- "上底面"(170,45) 与 "侧面"(250,155)：距离 √(80²+110²)≈136px → 无冲突
- "侧面"(250,155) 与 "①"(450,160)：水平距离 200px → 无冲突
- "①"(450,160) 与 "②"(510,160)：水平距离 60px → 无冲突（≥20px）
- "②"(510,160) 与 "③"(570,160)：水平距离 60px → 无冲突（≥20px）
- 所有标签与图形元素：标签均放在图形外侧，最小间距 15px → 无冲突

解决方案：所有标签间距均≥20px，无冲突，无需调整

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于 (250,455)，点击后退到前一步状态
  - 「下一步 ▶」按钮：位于 (470,455)，点击前进到下一步状态
  - 步骤指示器：位于 (380,465)，显示当前步骤序号 "步骤 X/4"
- 教师操作流程：
  1. 初始展示立体三棱柱，讲解三棱柱的基本结构（两个三角形底面 + 三个矩形侧面）
  2. 点击「下一步」展示侧面展开，讲解侧面如何从立体变为平面矩形带
  3. 点击「下一步」展示上底面展开，讲解上底面三角形如何翻折到平面
  4. 点击「下一步」展示下底面展开，讲解下底面三角形如何翻折到平面
  5. 点击「下一步」展示完整展开图与选项 A 对比，确认正确答案
  6. 可随时点击「上一步」回退复习关键步骤

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单，SVG 矢量图适合精确坐标控制，无需额外库
  - 动画使用 CSS transition 和 JavaScript 控制 opacity/display

- 画布尺寸：800 × 500 px（固定）

- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +----------------------------------------------------------+
  |  [立体三棱柱]           [展开过程]                        |
  |     y=60~250            y=50~250                         |
  |     x=100~250           x=420~600                        |
  |                                                            |
  |                                          [选项 A 参考]    |
  |                                          (步骤 4 显示)    |
  |                                                            |
  |  [展开轨迹箭头]  ==========================>              |
  |                                                            |
  |  +------------------------------------------------------+  |
  |  |  [◀ 上一步]   步骤 X/4   [下一步 ▶]                  |  |
  |  +------------------------------------------------------+  |
  +----------------------------------------------------------+
  ```

- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0~4），每个状态对应一组可见元素
  2. 坐标计算：所有元素使用绝对坐标（SVG viewBox="0 0 800 500"）
  3. 动画曲线：使用 CSS transition: opacity 0.5s ease-in-out 实现淡入淡出
  4. 事件绑定：按钮点击事件切换 currentState，调用 updateScene() 更新可见性
  5. 元素分组：使用 SVG <g> 元素按步骤分组，通过 display 属性控制显示/隐藏

- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀
  - scene1-prism-top（立体图上底面）
  - scene1-prism-bottom（立体图下底面）
  - scene1-prism-side1/2/3（立体图侧面）
  - scene1-unfold-rect1/2/3（展开区矩形）
  - scene1-unfold-top-tri（展开区上三角形）
  - scene1-unfold-bottom-tri（展开区下三角形）
  - scene1-arrow1/2/3（展开轨迹箭头）
  - scene1-btn-prev（上一步按钮）
  - scene1-btn-next（下一步按钮）
  - scene1-step-indicator（步骤指示器）

- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
