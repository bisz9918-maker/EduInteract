  3. 点击"下一步"高亮甲船 B→C 段，讲解甲船从 B 港到 C 港的过程，强调(6,200)表示 6 小时后距 B 港 200km

  5. 点击"下一步"显示速度计算，验证题目中的说法①②③④

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单（线段、圆点、文本），无需复杂库；原生 SVG 便于精确控制坐标和样式
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  y 轴标签                                         |
  |  |                                               |
  |  | 400 + - - - - - - - - - - - - - - - - - - -+  |
  |  |     |                                     |  |
  |  |     |  甲船折线 (A→B→C)                    |  |
  |  |     |  /                               \   |  |
  |  | 200 | /                                 \  |  |
  |  |     |/                                   \ |  |
  |  |     + - - - - - - - - - - - - - - - - - - -+  |
  |  |    /|                                       |  |
  |  |   / | 乙船虚线 (B→A)                        |  |
  |  |  /  |                                       |  |
  |  +-------------------------------------------  |  |
  |  O    1       4           6       x 轴标签      |  |
  |                                                 |
  |              [◀上一步] 步骤 X/4 [下一步▶]       |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-4) 跟踪当前步骤
  2. 坐标计算：建立像素坐标与数据坐标的映射函数 dataToPixel(x, y)
  3. 动画曲线：使用 CSS transition 实现 300ms 线性过渡
  4. 事件绑定：按钮点击事件触发 stepChange 函数，更新 DOM 元素样式
  5. 元素 ID 规范：所有元素 ID 以 scene1- 为前缀，如 scene1-line-甲-AB、scene1-point-0-400
  6. IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局污染
- ID 命名示例：
  - scene1-coord-x-axis, scene1-coord-y-axis
  - scene1-line-甲-AB, scene1-line-甲-BC, scene1-line-乙-BA
  - scene1-point-0-400, scene1-point-4-0, scene1-point-6-200, scene1-point-1-0, scene1-point-6-400
  - scene1-label-A 港，scene1-label-B 港，scene1-label-C 港方向，scene1-label-A 港方向
  - scene1-btn-prev, scene1-btn-next, scene1-step-indicator
  - scene1-speed-box, scene1-speed-text
