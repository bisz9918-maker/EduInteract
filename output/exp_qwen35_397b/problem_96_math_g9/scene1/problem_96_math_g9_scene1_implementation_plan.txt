[图示主题与整合说明]
- 本图示主题：正方体展开图折叠过程动态演示
- 整合的步骤/概念：展开图初始状态 → 折叠动画 → 完成立体图 → 标注各面位置关系
- 教学价值：教师可通过分步动画展示正方体折叠过程，帮助学生建立空间想象能力，理解展开图与立体图的对应关系，从而判断哪个选项是正确的折叠结果

[分步序列]
- 初始状态（步骤0）：展示完整十字形展开图，6个正方形面全部显示，标注三个特征面（圆圈面、阴影面A、阴影面B），正方体区域显示虚线轮廓
- 步骤1：左右两个阴影面向上折叠90度动画（绕中间面边缘旋转），红色虚线箭头指示折叠方向，展开图中左/右阴影面变为半透明
- 步骤2：顶部圆圈面向下折叠90度动画，红色虚线箭头指示折叠方向，展开图顶部面变为半透明
- 步骤3：底部空白面向上折叠90度动画，展开图底部面变为半透明
- 步骤4：展示完整正方体（三维透视），顶面显示蓝色圆圈，右面显示绿色阴影三角形，前面为空白，标注"相邻"和"相对"关系说明

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于底部左侧 (280, 455)，返回上一状态
  - 「下一步」按钮：位于底部右侧 (440, 455)，进入下一状态
  - 步骤指示器：位于底部中央 (380, 475)，显示"步骤 X/5"
- 教师操作流程：
  1. 初始展示展开图，讲解6个面的位置关系
  2. 点击「下一步」展示左右阴影面折叠，强调折叠方向
  3. 点击「下一步」展示顶面圆圈面折叠，说明圆圈面位置
  4. 点击「下一步」展示底面折叠，完成正方体封闭
  5. 点击「下一步」展示最终正方体，对比选项判断正确答案
  6. 可随时点击「上一步」回退复习关键步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（简单几何动画，无需重型库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  [展开图区 400×300]    |  [正方体区 350×300]    |
  |       十字形            |      三维正方体        |
  |      折叠动画           |      标注关系          |
  |                          |                        |
  +--------------------------------------------------+
  |  [控件栏 y=440~490]                             |
  |     [◀上一步]  步骤 3/5  [下一步▶]              |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-4），存储每个状态的 DOM 元素可见性
  2. 折叠动画：使用 SVG transform 的 rotate 属性，配合 CSS transition 实现平滑旋转
  3. 正方体绘制：使用 SVG polygon 绘制三个可见面（顶面、前面、右面）的平行四边形
  4. 事件绑定：按钮点击事件切换状态，更新所有元素的 display/opacity/transform
  5. 动画序列：每个折叠步骤使用 setTimeout 或 requestAnimationFrame 控制动画时序
- ID 命名规范：所有交互元素 ID 必须以 scene1- 为前缀
  - scene1-net-top（展开图顶部面）
  - scene1-net-left（展开图左面）
  - scene1-net-right（展开图右面）
  - scene1-net-bottom（展开图底面）
  - scene1-cube（正方体组）
  - scene1-btn-prev（上一步按钮）
  - scene1-btn-next（下一步按钮）
  - scene1-step-indicator（步骤指示器）
- IIFE 隔离：所有 JS 包在 (function() { ... })() 中，避免全局变量污染
