[分步序列]
- 初始状态（步骤0）：并排显示四个选项立方体A、B、C、D，每个立方体下方显示对应标签，判断依据区显示"请分析各选项与展开图的对应关系"，无高亮框和标记
- 步骤1：点击「下一步」→ 高亮框A显示(蓝色边框)，判断依据区显示"选项A：顶面有圆圈，但展开图中圆圈面与两个阴影面不相邻，错误"，错误标记A显示(红色叉号)
- 步骤2：点击「下一步」→ 高亮框A隐藏、高亮框B显示，判断依据区显示"选项B：顶面空白，正面和右侧面阴影方向与展开图一致，符合"，无标记（保持待确认状态）
- 步骤3：点击「下一步」→ 高亮框B隐藏、高亮框C显示，判断依据区显示"选项C：正面有圆圈，但展开图中圆圈面应在顶部而非正面，错误"，错误标记C显示(红色叉号)
- 步骤4：点击「下一步」→ 高亮框C隐藏、高亮框D显示，判断依据区显示"选项D：顶面有阴影，但展开图中顶面应为空白面，错误"，错误标记D显示(红色叉号)
- 步骤5：点击「下一步」→ 高亮框D隐藏、高亮框B显示，判断依据区显示"结论：选项B正确！阴影面位置与展开图完全匹配"，正确标记B显示(绿色勾号)，步骤指示器显示"步骤 5/5"

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位置(280,450)，返回上一分析步骤，灰色背景
  - 「下一步」按钮：位置(420,450)，进入下一分析步骤，蓝色背景#1565c0
  - 步骤指示器：位置(400,490)，显示当前步骤进度"步骤 X/5"
- 教师操作流程：
  1. 初始展示四个选项，让学生观察
  2. 点击「下一步」分析选项A，指出错误原因
  3. 点击「下一步」分析选项B，说明符合特征
  4. 点击「下一步」分析选项C，指出圆圈位置错误
  5. 点击「下一步」分析选项D，指出顶面错误
  6. 点击「下一步」显示最终结论，确认选项B正确
  7. 可随时点击「上一步」回退复习

[技术实现]
- JS库选择：原生SVG（简单几何图形首选，无需额外库）
- 画布尺寸：800×500px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |  [A]    [B]    [C]    [D]     ← 四个立方体并排    |
  |   ↓      ↓      ↓      ↓       ← 选项标签        |
  |                                                  |
  |  +--------------------------------------------+  |
  |  |         判断依据文字显示区                  |  |
  |  +--------------------------------------------+  |
  |                                                  |
  |              [◀上一步] [下一步▶]                |
  |                  步骤 X/5                        |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：currentStep变量(0-5)，每步对应不同的视觉状态
  2. 立方体绘制：使用SVG polygon绘制等轴测立方体的三个可见面（顶面、正面、右侧面）
  3. 高亮框：使用rect元素，opacity控制显示/隐藏
  4. 标记符号：叉号用两条line交叉，勾号用polyline绘制
  5. 事件绑定：按钮click事件触发stepChange函数，更新currentStep并重绘相关元素
  6. 按钮状态：步骤0时「上一步」禁用，步骤5时「下一步」禁用
- ID命名规范：所有元素ID以scene2-为前缀
  - scene2-cube-a, scene2-cube-b, scene2-cube-c, scene2-cube-d
  - scene2-highlight-a, scene2-highlight-b, scene2-highlight-c, scene2-highlight-d
  - scene2-mark-wrong-a, scene2-mark-wrong-c, scene2-mark-wrong-d
  - scene2-mark-correct-b
  - scene2-btn-prev, scene2-btn-next, scene2-step-indicator
  - scene2-reason-text
- IIFE隔离：所有JS代码包裹在(function() { ... })()中，避免全局污染
