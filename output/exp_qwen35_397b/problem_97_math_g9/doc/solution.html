题目原文：

已知二次函数 y = ax² + bx + 1 的大致图象如图所示，那么一次函数 y = ax + b 的图象不经过（ ）

A. 第一象限 B. 第二象限 C. 第三象限 D. 第四象限

题目分析：

本题需要从二次函数图像推断系数 a、b 的符号，再据此判断一次函数 y = ax + b 的图像位置。

关键信息提取：

  1. 抛物线开口向下 → a < 0
  2. 对称轴在 y 轴左侧 → -b/(2a) < 0
  3. 与 y 轴交点为 (0, 1) → 常数项为 1（与题目一致）

整体讲解思路：

  1. 首先分析二次函数图像的三个关键特征
  2. 由开口方向确定 a 的符号
  3. 由对称轴位置确定 b 的符号
  4. 根据 a、b 的符号画出一次函数 y = ax + b 的大致图像
  5. 判断直线经过的象限

图示规划说明：

  • SCENE_1：二次函数图像分析，分步高亮开口方向、对称轴、系数符号
  • SCENE_2：一次函数图像绘制，展示 y = ax + b 的图像及其经过的象限
步骤 0/3

教学说明：

本图示用于引导学生从二次函数图像提取系数信息。

讲解要点：

  1. 开口方向：抛物线开口向下，说明二次项系数 a < 0
  2. 对称轴位置：对称轴公式为 x = -b/(2a)，从图中可见对称轴在 y 轴左侧，即 -b/(2a) < 0
  3. 符号推导：因为 a < 0，所以 2a < 0，要使 -b/(2a) < 0，分子 -b 必须与分母 2a 同号，即 -b < 0，故 b > 0？不对，重新推导：
  • -b/(2a) < 0
  • 因为 a < 0，所以 2a < 0
  • 要使分式为负，分子 -b 必须为正（负/负=正，正/负=负）
  • 所以 -b > 0，即 b < 0
  1. 验证：与 y 轴交点为 (0, 1)，代入 x = 0 得 y = 1，与题目一致

引导学生观察：

  • 让学生先独立观察图像，说出能看到的信息
  • 逐步点击按钮，验证学生的发现
  • 重点讲解对称轴位置与 b 符号的关系
步骤 1/4

教学说明：

本图示用于展示如何根据系数符号绘制一次函数图像并判断经过的象限。

讲解要点：

  1. 截距分析：b < 0 表示直线与 y 轴交于负半轴，即点 (0, b) 在 y 轴负方向
  2. 斜率分析：a < 0 表示直线从左上向右下倾斜
  3. 图像绘制：结合截距和斜率，直线从第二象限出发，穿过第三象限，延伸到第四象限
  4. 象限判断：直线经过第二、三、四象限，不经过第一象限

完整解答：

  • 由二次函数图像得：a < 0，b < 0
  • 一次函数 y = ax + b 中，斜率 a < 0，截距 b < 0
  • 因此直线经过第二、三、四象限
  • 答案：A. 第一象限

课堂讲解建议：

  • 先让学生根据 a、b 的符号猜想直线位置
  • 点击按钮逐步验证，强化数形结合思想
  • 总结：一次函数 y = kx + m 中，k 决定倾斜方向，m 决定与 y 轴交点位置
