[图示主题与整合说明]
- 本图示主题：圆内接三角形的角度关系与边长求解
- 整合的步骤/概念：原图结构展示 → 已知条件标注 → 弧与圆周角关系推导 → 直径所对圆周角为直角 → 直角三角形边角关系求解
- 教学价值：教师可通过分步导航控制讲解节奏，从图形结构到条件标注，再到角度推导，最后求解边长，帮助学生理解圆内接三角形的几何性质和解题思路

[分步序列]
- 初始状态（步骤 0）：显示基础图形
  - 圆 O（黑色）
  - 点 A、B、C、D、O 及标签
  - 线段 AD、AB、BC、AC、BD（黑色）
  - 等待教师触发交互

- 步骤 1：高亮已知条件 AB=BC，标注∠ABC=120°
  - 在 AB 中点和 BC 中点显示蓝色双短线等长标记
  - 在 B 点处绘制蓝色弧线标注∠ABC
  - 显示文本"∠ABC=120°"（蓝色 #1565c0）于 (410,400)

- 步骤 2：高亮直径 AD，标注 AD=6，显示∠ABD=90°
  - 直径 AD 加粗或变为蓝色 #1565c0
  - 在 AD 中点上方显示"AD=6"（蓝色）
  - 在 B 点处绘制直角符号（绿色 #2e7d32）
  - 显示文本"∠ABD=90°"（绿色）于 (450,380)

- 步骤 3：用蓝色弧线标注弧 AC（优弧），显示弧 AC=240°
  - 绘制从 A 到 C 逆时针方向的灰色虚线弧（优弧）
  - 在弧外侧 (400,100) 显示"弧 AC=240°"（灰色 #888888）
  - 说明：圆周角∠ABC=120°，对应优弧 AC=2×120°=240°

- 步骤 4：用绿色弧线标注弧 AB 和弧 BC，显示弧 AB=弧 BC=60°
  - 绘制弧 AB（绿色虚线）和弧 BC（绿色虚线）
  - 在弧 AB 外侧 (300,400) 显示"弧 AB=60°"（绿色 #2e7d32）
  - 在弧 BC 外侧 (500,400) 显示"弧 BC=60°"（绿色）
  - 说明：优弧 AC=240°，劣弧 AC=360°-240°=120°，AB=BC 故弧 AB=弧 BC=60°

- 步骤 5：标注∠ADB=30°，在 Rt△ABD 中显示 AB=AD×sin30°=3
  - 在 D 点处绘制红色弧线标注∠ADB
  - 显示文本"∠ADB=30°"（红色 #c62828）于 (540,200)
  - 说明：弧 AB=60°，圆周角∠ADB=60°/2=30°
  - 在 (300,390) 显示"AB=AD×sin30°=6×0.5=3"（红色）

- 步骤 6：显示最终答案 AB=3，对应选项 A
  - 在 (400,80) 显示大号红色文本"AB=3"（#c62828, font-size 24px）
  - 在 (400,110) 显示"答案：A"（红色）
  - 所有推导元素保持显示

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于 (280,455)，点击后退到前一状态
  - 「下一步 ▶」按钮：位于 (420,455)，点击前进到下一状态
  - 步骤指示文本：位于 (400,475)，显示当前步骤"步骤 X/6"
- 教师操作流程：
  1. 初始状态展示基础图形，让学生观察结构
  2. 点击「下一步」显示 AB=BC 等长标记和∠ABC=120°，强调已知条件
  3. 点击「下一步」显示直径 AD 和∠ABD=90°，引出直径所对圆周角性质
  4. 点击「下一步」显示优弧 AC=240°，建立圆周角与弧的关系
  5. 点击「下一步」显示弧 AB=弧 BC=60°，推导等弦对等弧
  6. 点击「下一步」显示∠ADB=30°和计算过程，完成求解
  7. 点击「下一步」显示最终答案，可点击「上一步」回顾关键步骤

[技术实现]
- JS 库选择及原因：原生 SVG + 原生 JavaScript
  - 原因：几何图形简单，无需复杂库；SVG 原生支持圆、线段、弧线、文本等元素；代码轻量易维护
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  +--------------------------------------------------+
  |                                                  |
  |                    弧 AC=240°                     |
  |                   最终答案 AB=3                   |
  |                                                  |
  |              D(560,180)                          |
  |                 *                                |
  |               /   \                              |
  |             /       \                            |
  |      A(240,320)*---------*C(540,320)             |
  |             \ \       / /                        |
  |               \ \   / /                          |
  |                 \ * /                            |
  |                  B(400,430)                      |
  |                                                  |
  |                                                  |
  |              [◀ 上一步]  [下一步 ▶]               |
  |                   步骤 X/6                       |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-6），数组存储每步需显示的元素 ID 列表
  2. 坐标计算：各点坐标预先计算好，弧线使用 SVG path 的 A 命令绘制
  3. 动画曲线：元素显示使用 opacity 过渡（0.3s ease-in-out）
  4. 事件绑定：按钮点击事件切换状态，更新显示元素和步骤指示
  5. 等长标记：在 AB、BC 中点处绘制垂直于线段的短线，每组两条间距 4px
  6. 角度弧线：使用 SVG path 绘制圆弧，起点和终点根据角度计算
- ID 命名规范：所有元素 ID 以 scene1- 为前缀
  - scene1-circle-o, scene1-point-a, scene1-point-b, scene1-point-c, scene1-point-d, scene1-point-o
  - scene1-line-ad, scene1-line-ab, scene1-line-bc, scene1-line-ac, scene1-line-bd
  - scene1-label-a, scene1-label-b, scene1-label-c, scene1-label-d, scene1-label-o
  - scene1-mark-equal-ab, scene1-mark-equal-bc（等长标记）
  - scene1-angle-abc, scene1-angle-abd, scene1-angle-adb（角度弧线）
  - scene1-arc-ac, scene1-arc-ab, scene1-arc-bc（弧度数标注）
  - scene1-text-ad6, scene1-text-abc120, scene1-text-abd90, scene1-text-adb30
  - scene1-text-arc-ac, scene1-text-arc-ab, scene1-text-arc-bc
  - scene1-text-ab3, scene1-text-answer
  - scene1-btn-prev, scene1-btn-next, scene1-text-step
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
