[图示主题与整合说明]
- 本图示主题：折叠过程的动态演示及对称性质展示
- 整合内容：C点沿EF折叠到D点的动画、CE=DE和CF=DF的等量关系、EF垂直平分CD

[分步序列]
共6个状态（步骤0-5），教师点击「下一步」/「上一步」切换：

- 步骤0（初始状态）：
  · 显示△ABC完整框架（A-B-C-A）
  · 显示点D在AB上（AD:DB=1:2位置）
  · 显示点E在AC上、点F在BC上
  · 显示折痕EF（绿色加粗）
  · 显示CE线段（蓝色）、CF线段（红色）
  · 显示标签A/B/C/D/E/F
  · 显示数值标注AD=1, BD=2, BF=1.25
  · 隐藏：DE, DF, CD, M, 直角符号, CE=DE标注, CF=DF标注, EF⊥CD标注

- 步骤1（开始折叠）：
  · C点开始沿弧线向D点移动（动画过渡，移动50%距离）
  · CE/CF线段跟随C点缩短
  · 半透明显示△CEF的折叠轨迹（10%透明度填充）
  · 其他元素同步骤0

- 步骤2（折叠完成）：
  · C点与D点完全重合（C点隐藏或淡出）
  · 显示DE线段（蓝色）、DF线段（红色）
  · CE/CF线段淡出或变为虚线
  · 显示标签"CE=DE"（左侧，蓝色#1565c0）
  · 显示标签"CF=DF"（右侧，红色#c62828）
  · 隐藏：CD连线, M点, 直角符号, EF⊥CD标注

- 步骤3（高亮CE=DE）：
  · 同步骤2
  · CE和DE线段加粗高亮（线宽3px，闪烁动画1次）
  · "CE=DE"标注放大1.1倍并高亮显示
  · CF/DF线段恢复正常线宽

- 步骤4（高亮CF=DF）：
  · 同步骤2
  · CF和DF线段加粗高亮（线宽3px，闪烁动画1次）
  · "CF=DF"标注放大1.1倍并高亮显示
  · CE/DE线段恢复正常线宽

- 步骤5（显示垂直平分）：
  · 显示CD连线（灰色虚线#888888）
  · 显示交点M（CD与EF交点）及标签"M"
  · 显示直角符号（M点处，表示EF⊥CD）
  · 显示标注"EF⊥CD"（底部中央）
  · CE/DE/CF/DF线段恢复正常显示
  · 所有等量关系标注保持显示

- 所有标签间距均≥20px，无直接冲突
- "CE=DE"和"CF=DF"分置左右两侧，避免重叠
- 数值标注均位于三角形外侧，不压在线段上
- 点标签均位于顶点外侧空白区域

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  · 「上一步」按钮：位于(320,460)，80×30px，灰色背景#757575，点击返回上一状态
  · 「下一步」按钮：位于(400,460)，80×30px，绿色背景#2e7d32，点击进入下一状态
  · 步骤指示器：显示"步骤 X/5"，位于两按钮之间(480,465)
- 教师操作流程：
  1. 初始展示步骤0，讲解题目条件（等边△ABC，AD=1, BD=2, BF=1.25）
  2. 点击「下一步」到步骤1，演示C点开始折叠的运动轨迹
  3. 点击「下一步」到步骤2，展示折叠完成后C与D重合，引出CE=DE, CF=DF
  4. 点击「下一步」到步骤3，高亮CE=DE，强调对应线段相等
  5. 点击「下一步」到步骤4，高亮CF=DF，强化对称性质
  6. 点击「下一步」到步骤5，显示EF⊥CD，总结折痕垂直平分对应点连线
  7. 可随时点击「上一步」回退复习关键步骤

[技术实现]
- JS库选择：原生SVG + 原生JavaScript
  · 原因：几何图形简单，无需复杂库；SVG便于精确坐标控制和动画
- 画布尺寸：800×500px（固定）
- 布局草图：
  ```
  [图示区 800×440]
  ┌────────────────────────────────────────────────────┐
  │                    C(400,54)                       │
  │                   / \                              │
  │                  /   \                             │
  │              E  /     \  F                         │
  │                /_______\  ← 折痕EF(绿色)           │
  │               /    |    \                          │
  │              /     |M    \                         │
  │             /______|______\                        │
  │           A(200)  D(333)  B(600)                   │
  │                                                    │
  │   [CE=DE]                    [CF=DF]               │
  │                                                    │
  │              [EF⊥CD]                               │
  └────────────────────────────────────────────────────┘
  [控件栏 y=450~490]
  ┌────────────────────────────────────────────────────┐
  │        [◀上一步] [下一步▶]  步骤 X/5               │
  └────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用currentState变量(0-5)跟踪当前步骤，steps数组存储每步的显示配置
  2. 坐标计算：所有顶点坐标预先计算好，存储为常量对象
  3. 动画曲线：C点折叠动画使用easeInOut二次曲线，duration=800ms
  4. 事件绑定：按钮点击事件绑定到stepForward()/stepBackward()函数
  5. 元素显隐：每步通过display属性或opacity控制元素显示/隐藏
  6. 高亮效果：通过stroke-width和stroke颜色变化实现
- ID命名规范：
  · 所有元素ID以"scene2-"为前缀
  · 示例：scene2-tri-abc, scene2-line-ef, scene2-point-c, scene2-label-ce-de
  · JS中使用document.getElementById('scene2-xxx')直接获取
- IIFE隔离：
  ```javascript
  (function() {
    // 所有代码包裹在此
    const currentState = 0;
    // ...
  })();
  ```
- CDN引入：无需额外库，使用原生SVG和JS
