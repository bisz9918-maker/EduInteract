[分步序列]
- 步骤0（初始状态）：显示等边△ABC框架、点D、折痕EF、虚线EC和FC、所有点标签(A/B/C/D/E/F)、已知长度标注(AD=1, BD=2, BF=1.25)、∠A=60°标注
- 步骤1：点击「下一步」→ △ADE区域蓝色高亮填充出现、CE=x标注(红色)出现在EC虚线旁
- 步骤2：点击「下一步」→ AE=3-x标注(红色)出现在AE线段左侧、DE=x标注(红色)出现在DE线段右侧
- 步骤3：点击「下一步」→ ∠A=60°标注高亮(加粗显示)，强调已知角度条件
- 步骤4：点击「下一步」→ 方程框出现在右侧，显示「在△ADE中，由余弦定理：DE² = AD² + AE² - 2·AD·AE·cos∠A」
- 步骤5：点击「下一步」→ 方程框更新显示「x² = 1² + (3-x)² - 2·1·(3-x)·cos60°」→ 继续显示「x² = 1 + 9 - 6x + x² - (3-x)」→ 最终显示「x = 5/6」(绿色高亮)

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于SVG底部左侧(x=350, y=470)，灰色背景，步骤0时禁用
  - 「下一步」按钮：位于SVG底部右侧(x=450, y=470)，蓝色背景，步骤5时禁用
  - 步骤指示器：位于两按钮之间，显示「步骤 X/5」
- 教师操作流程：
  1. 步骤0：展示基础图形，讲解题目已知条件
  2. 步骤1：引入未知数x，说明折叠后CE=DE
  3. 步骤2：标注△ADE三边，为余弦定理做准备
  4. 步骤3：强调∠A=60°是关键已知条件
  5. 步骤4：展示余弦定理公式
  6. 步骤5：代入数值求解，得出CE=5/6

[技术实现]
- JS库选择：原生SVG + 原生JavaScript
  - 原因：几何图形简单，无需复杂库；SVG便于精确坐标控制和动画
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────┐
  │                    C(350,140)                       │
  │                   /  \                              │
  │                  /    \                             │
  │              E  /      \  F                          │
  │                /        \                            │
  │               /__________\                           │
  │              A(200,400)  B(500,400)                  │
  │                                                     │
  │  [△ADE蓝色高亮]              [方程框 580,150]        │
  │                                                     │
  │  [AD=1]  [D]  [BD=2]                                │
  │                                                     │
  │         [◀上一步]  步骤X/5  [下一步▶]               │
  └─────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量currentStep(0-5)跟踪当前步骤，steps数组存储每步显示的元素ID列表
  2. 坐标计算：所有点坐标预先计算好，硬编码在SVG中
  3. 动画曲线：元素出现使用fade-in动画(300ms)，方程使用typewriter效果
  4. 事件绑定：按钮点击事件切换步骤，更新display属性
  5. ID命名规范：所有元素ID以scene3-为前缀（如scene3-tri-ade、scene3-label-ce）
  6. IIFE隔离：所有JS代码包在(function() { ... })()中，避免全局污染
  7. 方程框内容：用<tspan>分行显示，步骤5时逐步替换内容
