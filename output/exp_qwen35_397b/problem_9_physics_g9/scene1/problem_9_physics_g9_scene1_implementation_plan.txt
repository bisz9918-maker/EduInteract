[视觉元素清单]
- 电源：电池符号（长短线表示正负极），位置(400,420)，标签"3V"在下方(400,470)
- L₁ 灯泡：圆形内画×，位置(200,250)，标签"L₁ 6V 6W"在上方(200,190)
- L₂ 灯泡：圆形内画×，位置(500,250)，标签"L₂ 3V 3W"在上方(500,190)
- S₂ 开关：顶部闸刀开关，位置(350,120)，默认断开状态
- S₁ 开关：单刀双掷开关，位置(600,350)，触点 a(650,320)、b(650,380)
- 导线：黑色实线#000000，线宽 3px，构成电路框架
- 电流路径：蓝色#1565c0 粗线（5px），带箭头指示方向，仅在对应步骤显示
- 短路路径：红色#c62828 虚线，表示短路状态
- 高亮元件：绿色#2e7d32 填充（透明度 20%），表示发光/工作状态
- 状态说明区：右侧白色背景框，显示当前开关状态和电路分析

[分步序列]
步骤 0（初始状态 - 原图）：
- 显示完整电路图，所有元件和标签
- S₂ 显示为断开状态（闸刀翘起）
- S₁ 显示为中间位置（未接 a 也未接 b）
- 无电流路径高亮
- 状态说明："原图：开关初始状态"

步骤 1（S₂断开，S₁接 a）：
- S₂ 保持断开
- S₁ 闸刀连接到触点 a
- 电流路径高亮：电源正极 → S₁-a → L₂ 右侧 → L₂ → L₁ → 电源负极（串联）
- L₁ 和 L₂ 均显示绿色半透明填充（表示有电流通过）
- 状态说明："S₂断开，S₁接 a：L₁与 L₂串联，总电阻大，电流小"

步骤 2（S₂断开，S₁接 b）：
- S₂ 保持断开
- S₁ 闸刀连接到触点 b
- 电流路径高亮：电源正极 → S₁-b → L₁与 L₂ 之间节点 → L₁ → 电源负极
- L₁ 显示绿色半透明填充，L₂ 无高亮（L₂ 被断路）
- 状态说明："S₂断开，S₁接 b：只有 L₁ 接入电路，L₂ 断路"

步骤 3（S₂闭合，S₁接 a）：
- S₂ 闭合（闸刀放平）
- S₁ 闸刀连接到触点 a
- 电流路径高亮：电源正极 → S₁-a → L₂ 右侧节点 → 分两路：①经 L₂ → L₁ → 负极 ②经 S₂ → L₁ 左侧 → 负极
- 实际为 L₁ 与 L₂ 并联（S₂ 将 L₂ 右侧与 L₁ 左侧连通）
- L₁ 和 L₂ 均显示绿色半透明填充
- 状态说明："S₂闭合，S₁接 a：L₁与 L₂并联，各支路电压等于电源电压 3V"

步骤 4（S₂闭合，S₁接 b）：
- S₂ 闭合
- S₁ 闸刀连接到触点 b
- 电流路径高亮：电源正极 → S₁-b → L₁与 L₂ 之间节点
- L₂ 被短路（S₂ 闭合使 L₂ 两端等电位），红色虚线表示短路
- L₁ 显示绿色半透明填充，L₂ 显示红色斜线填充（短路不工作）
- 状态说明："S₂闭合，S₁接 b：L₂ 被短路，只有 L₁ 工作"

步骤 5（结论总结）：
- 显示表格对比四种状态
- 列出每种状态下 L₁、L₂ 的工作情况和亮度比较
- 高亮正确选项（根据计算：D 选项正确 - S₂闭合 S₁接 b 时 L₁ 两端电压 3V 正常发光，L₂ 短路不亮）

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于(280,465)，点击后切换到前一状态，步骤 0 时禁用
  - 「下一步 ▶」按钮：位于(420,465)，点击后切换到下一状态，步骤 5 时禁用
  - 当前步骤指示器：显示"步骤 X/5"，位于两按钮之间
- 教师操作流程：
  1. 初始展示原图，让学生观察电路结构
  2. 点击「下一步」逐步展示四种开关状态
  3. 每步暂停讲解电流路径和元件工作状态
  4. 最后展示结论，引导学生分析各选项正误
  5. 可随时点击「上一步」回退复习

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript
  - 原因：电路图由简单几何图形（线段、圆形、路径）构成，原生 SVG 足够胜任，无需引入重型库
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────────────────┐
  │                              800px                                  │
  │  ┌─────────────────────────────────────────┐  ┌──────────────────┐ │
  │  │                                         │  │   状态说明区    │ │
  │  │           S₂ (顶部开关)                 │  │                  │ │
  │  │    ┌───────────┐    ┌───────────┐       │  │  当前开关状态   │ │
  │  │    │    L₁     │    │    L₂     │       │  │  电路连接方式   │ │
  │  │    └───────────┘    └───────────┘       │  │  元件工作状态   │ │
  │  │                                         │  │                  │ │
  │  │              S₁ (单刀双掷)              │  │                  │ │
  │  │                                         │  │                  │ │
  │  │           ─────[电源]─────              │  │                  │ │
  │  │                                         │  └──────────────────┘ │
  │  └─────────────────────────────────────────┘                        │
  │                    ┌─────────────────────┐                          │
  │                    │ ◀上一步 | 3/5 | 下一步▶ │                          │
  │                    └─────────────────────┘                          │
  └─────────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用 currentState 变量（0-5），switch 语句控制各状态显示
  2. S₁ 开关动画：使用 SVG transform rotate 实现闸刀转动，接 a 时旋转 -15°，接 b 时旋转 +15°
  3. S₂ 开关动画：使用 SVG transform rotate 实现闸刀开合，闭合时旋转至水平
  4. 电流路径：使用 SVG path 元素，stroke-dasharray 实现流动动画效果
  5. 元件高亮：使用 SVG filter 或 opacity 填充实现绿色半透明效果
  6. 事件绑定：按钮点击事件绑定到 stateChange 函数，更新视图
- ID 命名规范：
  - 所有元素 ID 以 scene1- 为前缀
  - 示例：scene1-power、scene1-l1、scene1-l2、scene1-s1、scene1-s2、scene1-path-current、scene1-btn-prev、scene1-btn-next
- IIFE 隔离：所有 JS 代码包在 (function() { ... })() 中，避免全局变量污染
- 状态数据对象：
  ```javascript
  const states = [
    { s2: 'open', s1: 'mid', path: [], highlight: [] },
    { s2: 'open', s1: 'a', path: ['path1'], highlight: ['l1', 'l2'] },
    // ...
  ];
  ```
