[图示主题与整合说明]
- 本图示主题：杠杆初始平衡状态及力臂关系分析
- 整合的步骤/概念：从直观的物理场景（大人小孩坐跷跷板）抽象出力学模型（力、力臂、力矩），通过分步标注引导学生理解杠杆平衡条件 $G_{大人} \times L_{大人} = G_{小孩} \times L_{小孩}$，并推导出力臂大小关系 $L_{大人} < L_{小孩}$。
- 教学价值：教师可通过分步按钮控制信息呈现节奏，先建立直观印象，再叠加物理量标注，最后聚焦数学关系，符合认知递进规律，避免一次性信息过载。

[分步序列]
- 初始状态（步骤0）：
  - 显示：杠杆、支点、大人、小孩。
  - 隐藏：所有箭头、力臂、文本框、高亮区域。
  - 视觉：杠杆水平静止，人物站立姿态。
- 步骤1（点击「下一步」）：
  - 新增：G大人箭头（蓝）、G小孩箭头（红）、L大人力臂（灰虚线）、L小孩力臂（灰虚线）。
  - 新增标签：$G_{大人}$、$G_{小孩}$、$L_{大人}$、$L_{小孩}$、$G_{大人} > G_{小孩}$（置于大人箭头左侧(160,280)）。
  - 动画：箭头和力臂从0长度平滑展开至目标长度（duration 0.4s）。
- 步骤2（点击「下一步」）：
  - 新增：平衡方程文本框（顶部居中），显示 $G_{大人} \times L_{大人} = G_{小孩} \times L_{小孩}$。
  - 新增：大人端力矩高亮（蓝20%）、小孩端力矩高亮（红20%），位于杠杆下方紧贴处。
  - 动画：文本框淡入（opacity 0→1），高亮区域缩放显现。
- 步骤3（点击「下一步」）：
  - 新增：力臂关系文本框（底部居中），显示 $L_{大人} < L_{小孩}$（因为 $G_{大人} > G_{小孩}$）。
  - 变化：L大人和L小孩力臂线段颜色变为绿色`#2e7d32`，线宽加粗至2px。
  - 动画：关系框淡入，力臂颜色渐变过渡。
- 回退机制：点击「上一步」可逆序隐藏/恢复各步骤元素，状态完全可逆。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位置(300, 455)，尺寸(100×30)，灰色背景，点击回退至上一状态。步骤0时禁用。
  - 「下一步」按钮：位置(400, 455)，尺寸(100×30)，蓝色背景`#1565c0`，点击推进至下一状态。步骤3时禁用。
- 教师操作流程：
  1. 展示初始跷跷板场景，提问“为什么大人小孩能平衡？”
  2. 点击「下一步」引出力和力臂概念，结合标注讲解 $G_{大人} > G_{小孩}$。
  3. 点击「下一步」展示平衡方程，用高亮区域直观对比两侧力矩。
  4. 点击「下一步」得出结论 $L_{大人} < L_{小孩}$，完成本场景教学闭环。

[技术实现]
- JS 库选择：原生 SVG + Vanilla JavaScript。无需重型库，SVG 原生支持矢量图形、动画（CSS transitions/SMIL）和事件绑定，性能最优且代码轻量。
- 画布尺寸：800 × 500 px（固定 viewBox="0 0 800 500"）
- 布局草图（ASCII）：
  ```
  [ 800×500 Canvas ]
  y=80~120 : [ 平衡方程文本框 (步骤2+) ]
  y=190~250: [ 大人火柴人 ]       [ 小孩火柴人 ]
  y=250~270: [================杠杆================]
  y=270~300: [支点▲] [蓝高亮] [红高亮]
  y=350~380: [ 重力箭头↓ ]       [ 重力箭头↓ ]
  y=370~380: [---L大人---] [--------L小孩--------]
  y=410~440: [ 力臂关系文本框 (步骤3+) ]
  y=455~485: [ ◀上一步 ] [ 下一步▶ ]
  ```
- 关键实现要点：
  - 状态机：使用变量 `currentStep` (0~3) 管理状态。每个步骤对应一个渲染函数 `renderStep(n)`，根据 n 切换元素的 `display` 或 `opacity`。
  - 动画：使用 CSS `transition: all 0.4s ease` 实现平滑显现。力臂长度动画通过修改 `x1`/`x2` 属性实现。
  - 事件绑定：按钮绑定 `click` 事件，更新 `currentStep` 后调用 `renderStep()`。边界检查防止越界。
  - ID 命名规范：所有元素 ID 以 `scene1-` 开头，如 `scene1-lever`, `scene1-fulcrum`, `scene1-adult`, `scene1-child`, `scene1-g-adult`, `scene1-l-child`, `scene1-eq-box`, `scene1-rel-box`, `scene1-btn-prev`, `scene1-btn-next`。
  - IIFE 隔离：全部代码包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染。
  - 数学公式渲染：使用 SVG `<tspan>` 实现下标，避免引入 MathJax 增加加载负担。示例：`G<tspan baseline-shift="sub" font-size="0.7em">大人</tspan>`。
