[图示主题与整合说明]
- 本图示主题：两人向支点移动过程中的力矩动态变化与结论
- 整合的步骤/概念：初始平衡状态 → 同步移动过程 → 新力臂标注 → 力矩变化量对比（柱状图） → 杠杆倾斜结论
- 教学价值：通过分步动画直观展示“等速靠近支点时，重力大的一方力矩减小更多”的物理规律，帮助学生理解力矩动态平衡的破坏过程，强化 $M=F \times L$ 的定量分析能力。

[视觉元素清单]
- 杠杆：`<rect>`，初始水平，步骤4绕(350,250)顺时针旋转15°。填充#f5f5f5，描边#000000。
- 支点：`<polygon>`，固定。填充#e0e0e0，描边#000000。
- 火柴人：`<g>`组合（`<circle>`头+`<line>`躯干四肢）。初始位置用stroke-dasharray="4,2"灰色#888888；新位置实线黑色#000000。
- 移动箭头：`<path>`带箭头标记，橙色#ff6f00，标注速度v。

- 柱状图：`<rect>`，高度严格按力矩变化量比例（蓝柱80px，红柱56px），透明度0.6。

- 标签：仅含物理量符号（$G_{大人}$、$G_{小孩}$、$\Delta L$、$L_{大人}-\Delta L$、$L_{小孩}-\Delta L$、$\Delta M_{大人}$、$\Delta M_{小孩}$），无解释性长句（结论框除外）。

[分步序列]
- 初始状态（步骤0）：显示水平杠杆、支点、大人(160)、小孩(620)实线轮廓。标注$G_{大人}$、$G_{小孩}$、初始力臂$L_{大人}$、$L_{小孩}$。系统处于平衡状态。
- 步骤1（移动过程）：原位置小人变为灰色虚线。新位置小人(230/550)黑色实线出现。上方出现橙色移动箭头及$\Delta L$标注。杠杆保持水平。
- 步骤2（新力臂）：从支点向新位置绘制蓝色/红色虚线力臂。下方标注$L_{大人}-\Delta L$和$L_{小孩}-\Delta L$。柱状图区域隐藏。
- 步骤3（力矩变化量对比）：画布下半部出现柱状图。左侧蓝柱($\Delta M_{大人}=G_{大人}\times\Delta L$)明显高于右侧红柱($\Delta M_{小孩}=G_{小孩}\times\Delta L$)。直观展示大人端力矩减小更多。
- 步骤4（结论）：柱状图淡出。杠杆绕支点顺时针倾斜15°（右端下沉）。画布下方居中弹出浅绿结论框：“因为 $G_{大人}\times\Delta L > G_{小孩}\times\Delta L$，大人端力矩减小更多，所以小孩端下沉”。

[技术实现]
- JS 库选择：原生 SVG + Vanilla JS。无需重型库，SVG 原生支持旋转、虚线、透明度、文本渲染，性能最优且代码轻量。
- 画布尺寸：800 × 500 px（固定 viewBox）
- 布局草图：
  ```
  [ 800 × 500 SVG ]
  y=0~200  : 空白/顶部标签区
  y=200~250: 移动箭头/速度标注
  y=250    : 杠杆主线
  y=250~300: 支点/力臂标注
  y=300~410: 柱状图区(步骤3) 或 结论框(步骤4)
  y=440~490: 控件栏(绝对定位覆盖)
  ```
- 关键实现要点：
  - 状态机：`currentStep` 变量控制显示/隐藏 `<g>` 组。使用 CSS class `.step-0`, `.step-1` 等控制 visibility/opacity。
  - 动画：步骤4杠杆倾斜使用 CSS `transform: rotate(15deg)` + `transform-origin: 350px 250px`，配合 `transition: transform 0.6s ease-in-out`。
  - 柱状图高度严格按比例计算，确保视觉对比准确。
  - 文本渲染：使用 `<text>` 元素，复杂下标使用 `<tspan baseline-shift="sub">`。
- ID 命名规范：所有元素 ID 以 `scene2-` 开头（如 `scene2-lever`, `scene2-adult-new`, `scene2-bar-blue`, `scene2-btn-next`）。
- IIFE 隔离：全部 JS 逻辑包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染。
- 事件绑定：使用 `document.getElementById` 获取控件，绑定 `click` 事件更新 `currentStep` 并切换 CSS class。
