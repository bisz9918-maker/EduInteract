[图示主题与整合说明]
- 本图示主题：正方形沿对角线折叠、挖洞、展开的轴对称变换全过程
- 整合的步骤/概念：正方形几何结构 → 沿对角线折叠形成等腰直角三角形 → 在三角形三顶点挖洞（区分折痕上/非折痕上） → 展开后利用轴对称性质推导圆洞分布 → 匹配正确选项
- 教学价值：教师可通过分步按钮控制演示节奏，直观展示“折叠-挖洞-展开”的几何变换过程，重点突出折痕上的点展开后位置不变、非折痕上的点展开后产生对称镜像的核心规律，帮助学生理解轴对称变换的空间对应关系。

[分步序列]
- 初始状态（步骤0）：显示正方形ABCD轮廓，虚线对角线AC，四个顶点标签，折痕标注。说明文字：“步骤0/4：正方形纸片，沿对角线AC折叠”。按钮：上一步禁用，下一步可用。
- 步骤1（折叠）：三角形ADC区域填充10%黑色半透明，表示被折叠覆盖。对角线AC变为实线。说明文字：“步骤1/4：沿对角线AC折叠，得到等腰直角三角形ABC”。
- 步骤2（挖洞）：在A、B、C三处渐显圆洞。A、C为蓝色，B为红色。出现标注“在折痕上”（蓝洞旁）、“不在折痕上”（红洞旁）。说明文字：“步骤2/4：在三角形三个角上各挖去一个圆洞”。
- 步骤3（展开）：ADC区域透明度恢复为0，正方形轮廓完整。D处渐显红色圆洞（B的镜像）。显示BD虚线及“对称点”标注。说明文字：“步骤3/4：展开纸片，B处圆洞对称生成D处圆洞”。
- 步骤4（结论）：正方形边框渐变为绿色 `#2e7d32` 高亮。所有圆洞保留。说明文字：“步骤4/4：结论——四个顶点各有一个圆洞，对应选项A”。按钮：下一步禁用。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」：位于(280,450)，点击返回上一状态，步骤0时禁用
  - 「下一步 ▶」：位于(420,450)，点击进入下一状态，步骤4时禁用
- 教师操作流程：教师点击「下一步 ▶」逐步演示折叠→挖洞→展开过程，配合口头讲解轴对称性质；可随时点击「◀ 上一步」回退至任意步骤进行对比或重复强调；到达步骤4后自动锁定，完成教学演示。

[技术实现]
- JS 库选择：原生 SVG + Vanilla JS（无需外部库，轻量高效，适合几何变换与状态切换）
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [图示区 800×440]
  ┌──────────────────────────────────────────────┐
  │              A(260,85)        B(540,85)       │
  │         ┌──────────────────────────────┐      │
  │         │                              │      │
  │         │        正方形 240×240        │      │
  │         │                              │      │
  │         └──────────────────────────────┘      │
  │              D(260,365)      C(540,365)       │
  │              步骤说明文字 (400,420)            │
  └──────────────────────────────────────────────┘
  [控件栏 y=440~490]
  ┌──────────────────────────────────────────────┐
  │        [◀ 上一步]          [下一步 ▶]         │
  └──────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：维护 `currentStep` (0~4)，`renderStep(step)` 函数根据当前步骤更新 SVG 元素的 `opacity`、`stroke`、`display` 属性。
  2. 动画过渡：使用 CSS `transition: all 0.4s ease` 实现圆洞渐显、区域淡入淡出、边框变色等平滑效果。
  3. 坐标计算：所有元素坐标硬编码写入 SVG，避免运行时计算误差；对称点D坐标由B关于AC的镜像公式验证 `(280,340)`。
  4. 事件绑定：按钮绑定 `click` 事件，更新 `currentStep` 后调用 `renderStep()`，并动态切换按钮 `disabled` 状态。
- ID 命名规范：所有交互元素及 SVG 节点 ID 均以 `scene1-` 为前缀（如 `scene1-square`, `scene1-diag-ac`, `scene1-hole-a`, `scene1-btn-next`）。
- IIFE 隔离：全部 JS 逻辑包裹在 `(function() { 'use strict'; ... })();` 中，避免全局变量污染，支持多场景合并渲染。
