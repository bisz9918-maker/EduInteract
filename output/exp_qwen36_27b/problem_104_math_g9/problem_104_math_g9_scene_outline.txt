    在平面直角坐标系中，正方形A₁B₁C₁D₁、D₁E₁E₂B₂、A₂B₂C₂D₂、D₂E₃E₄B₃、A₃B₃C₃D₃…按如图所示的方式放置，其中点B₁在y轴上，点C₁、E₁、E₂、C₂、E₃、E₄、C₃…在x轴上．已知正方形A₁B₁C₁D₁的边长为1，∠C₁B₁O=30°，B₁C₁∥B₂C₂∥B₃C₃…则正方形A₂₀₁₆B₂₀₁₆C₂₀₁₆D₂₀₁₆的边长是（  ）

    **题目分析：**

    本题核心是找出正方形边长的递推规律。关键几何关系：
    1. 所有正方形的对应边互相平行（B₁C₁∥B₂C₂∥B₃C₃…），意味着所有正方形倾斜角度相同
    2. 相邻正方形之间通过矩形连接（如D₁E₁E₂B₂），矩形的高等于前一个正方形顶点D的纵坐标
    3. 后一个正方形的顶点B的纵坐标等于前一个正方形顶点D的纵坐标

    首先让学生观察整体图形，理解正方形的排列方式和已知条件。然后聚焦于前两个正方形的连接关系，通过几何推导找出边长的递推公式。最后推广到第n个正方形，代入n=2016得到答案。

    **Scene 2 教学说明：**

    本图示是解题的核心，教师应按以下步骤详细讲解：

    **第一步：分析第一个正方形**

    在Rt△OB₁C₁中：
    - ∠C₁B₁O = 30°（已知）
    - ∠B₁OC₁ = 90°（坐标轴垂直）
    - 所以∠B₁C₁O = 60°
    - B₁C₁ = 1（已知边长）

    **第二步：求D₁的纵坐标**

    - C₁D₁是正方形的一边，长度为1，且C₁D₁⊥B₁C₁
    - 因为B₁C₁与x轴夹角为60°，所以C₁D₁与x轴夹角为30°
    - D₁到x轴的垂线D₁E₁，长度为：D₁E₁ = C₁D₁·sin(30°) = 1 × 1/2 = 1/2

    **第三步：求第二个正方形的边长**

    - 因为D₁E₁E₂B₂是矩形，所以B₂E₂ = D₁E₁ = 1/2
    - B₂C₂∥B₁C₁，所以∠B₂C₂E₂ = ∠B₁C₁O = 60°
    - 在Rt△B₂E₂C₂中：B₂C₂ = B₂E₂/sin(60°) = (1/2)/(√3/2) = √3/3
    - 即 a₂ = √3/3

    **第四步：归纳递推规律**

    - 同理可求：a₃ = a₂ × (√3/3) = (√3/3)²
    - 一般地：aₙ = a₁ × (√3/3)^(n-1) = (√3/3)^(n-1)
    - 所以 a₂₀₁₆ = (√3/3)^2015

    **关键教学点：**
    1. 强调"高度传递"的思想：前一个正方形的D点高度 = 后一个正方形的B点高度
    2. 强调平行关系的作用：所有正方形倾斜角度相同，保证了递推比例恒定
    3. 引导学生自己验证a₃的计算，确认规律的正确性

    **课堂练习建议：**
    让学生计算a₄的值，验证递推公式的正确性。

    **完整解答总结：**

    **已知条件：**
    - 正方形A₁B₁C₁D₁边长a₁ = 1
    - ∠C₁B₁O = 30°
    - B₁C₁∥B₂C₂∥B₃C₃…

    **推导过程：**

    1. 在Rt△OB₁C₁中，∠B₁C₁O = 60°

    2. C₁D₁与x轴夹角为30°，D₁的纵坐标 = a₁·sin(30°) = 1/2

    3. B₂的纵坐标 = D₁的纵坐标 = 1/2（矩形性质）

    4. 在Rt△B₂E₂C₂中，∠B₂C₂E₂ = 60°，a₂ = B₂C₂ = (1/2)/sin(60°) = √3/3

    5. 递推关系：aₙ₊₁ = aₙ × (√3/3)

    6. 通项公式：aₙ = (√3/3)^(n-1)

    7. 代入n = 2016：a₂₀₁₆ = (√3/3)^2015

    **答案：C**

    **教学建议：**
    - 本题难度在于发现"高度传递"的几何关系
    - 建议教师在黑板上配合图示，手动推导一遍，加深学生印象
    - 可延伸提问：如果∠C₁B₁O改为其他角度，递推比例会如何变化？
    - 可延伸提问：所有正方形面积之和是否有极限？（等比数列求和）
