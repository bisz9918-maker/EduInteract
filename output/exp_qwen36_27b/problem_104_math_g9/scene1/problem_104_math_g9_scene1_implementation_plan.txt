[图示主题与整合说明]
- 本图示主题：正方形序列递减排列的几何结构展示
- 整合的步骤/概念：平面直角坐标系中，正方形A₁B₁C₁D₁、A₂B₂C₂D₂、A₃B₃C₃D₃…依次排列，通过连接矩形相连，边长按等比数列递减（公比√3/3）。逐步揭示已知条件（边长=1、∠C₁B₁O=30°、平行关系），引导学生发现边长递推规律。
- 教学价值：教师通过分步按钮逐步展示图形结构，从坐标系→第一个正方形→已知条件→后续正方形→平行关系→问题提出，帮助学生理解几何递推关系，最终求解第2016个正方形的边长。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于控件栏左侧（x=200, y=455），点击回退到上一步骤
  - 「步骤 X/6」文字：位于控件栏中央（x=400, y=465），显示当前步骤
  - 「下一步 ▶」按钮：位于控件栏右侧（x=580, y=455），点击进入下一步骤
- 教师操作流程：
  1. 图示加载后显示步骤0（仅坐标系），教师可开始讲解
  2. 点击「下一步▶」逐步展示正方形序列和已知条件
  3. 每步展示后，教师可结合图形讲解对应知识点
  4. 如需回顾，点击「◀上一步」回退
  5. 到达步骤6后，「下一步▶」按钮禁用

[技术实现]
- JS 库选择：原生 SVG（简单几何图形绘制，无需额外库，性能好）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×440]
  ┌──────────────────────────────────────────────────────────┐
  │ y                                                         │
  │ ↑    A₁                                                   │
  │ │   /│\                                                  │
  │ │  / │ \      A₂      A₃                                 │
  │ │ B₁  │  D₁   /│\    /│\                                 │
  │ │  \  │ /    / │ \  / │ \                                │
  │ │   \ │/ B₂  /  │  \/  │  \                              │
  │ │    D₁E₁E₂ C₂  D₂E₃E₄ C₃                               │
  │ O─────────────────────────────────────────────────────→ x │
  │  C₁  E₁ E₂ C₂ E₃ E₄ C₃  ...                             │
  └──────────────────────────────────────────────────────────┘
  [控件栏 y=440~490]
  ┌──────────────────────────────────────────────────────────┐
  │         ◀ 上一步     步骤 0/6     下一步 ▶               │
  └──────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. **状态机设计**：用变量`currentStep`（0~6）跟踪当前步骤，每个步骤对应一组可见元素
  2. **元素显隐控制**：每个SVG元素添加`data-step`属性，切换步骤时根据`data-step`值设置`opacity`或`display`
  3. **坐标计算**：所有顶点坐标预先计算好，硬编码在JS中（基于数学推导）
  4. **动画曲线**：元素出现时使用CSS transition（opacity 0→1，duration 0.4s，ease-in）
  5. **角度弧线绘制**：使用SVG `<path>`的弧命令`A`，圆心B₁(40,247)，从y轴方向到B₁C₁方向画30°弧
  6. **平行标记**：在B₁C₁、B₂C₂、B₃C₃中点处绘制垂直于线段的小短线（长度8px）
  7. **事件绑定**：按钮点击事件更新`currentStep`并调用`renderStep()`函数
  8. **边界处理**：步骤0时「上一步」禁用，步骤6时「下一步」禁用

- **ID 命名规范**：所有交互元素ID以`scene1-`为前缀
  - 按钮：`scene1-prev-btn`、`scene1-next-btn`
  - 步骤指示：`scene1-step-indicator`
  - SVG容器：`scene1-svg`
  - 图形元素：`scene1-square1`、`scene1-rect1`、`scene1-square2`等
  - 标签元素：`scene1-label-A1`、`scene1-label-B1`等
  - 标注元素：`scene1-angle-arc`、`scene1-length-label`、`scene1-parallel-marks`

- **IIFE 隔离**：所有JS代码包裹在`(function() { 'use strict'; ... })();`中，避免全局污染

- **SVG元素层级**（从下到上）：
  1. 坐标轴（始终可见）
  2. 正方形和矩形（按步骤出现）
  3. 角度弧线和边长标注（步骤2出现）
  4. 平行标记（步骤5出现）
  5. 省略号和问题文字（步骤6出现）
  6. 顶点标签（随对应图形出现）
  7. 控件栏按钮（始终可见，叠在最上层）
