[图示主题与整合说明]
- 本图示主题：等腰直角三角形中的全等变换与结论验证——逐步展示四个结论的证明过程
- 整合的步骤/概念：①基础图形与已知条件标注；②证明△AED≌△AEF（SAS）；③证明△ABF≌△ACD（SAS）；④验证结论③BE+DC＞DE（三角形三边关系）；⑤验证结论④BE²+DC²=DE²（勾股定理）；⑥结论②的反例说明（相似条件不满足）
- 教学价值：教师可通过分步导航引导学生逐步观察图形变换与全等关系，直观理解几何证明中的旋转全等模型、勾股定理应用及相似判定条件，支持回退复习关键推导步骤。

[分步序列]
- 初始状态（步骤0）：
  - 显示完整基础图形：所有线段黑色2px，顶点标签A~F
  - 标注已知条件：∠BAC=90°、∠DAF=90°（红色直角符），AB=AC、AD=AF（绿色等长标记），∠DAE=45°（灰色弧线）
  - 推导说明框显示：“已知：∠BAC=∠DAF=90°，AB=AC，AD=AF，∠DAE=45°”
- 步骤1（证明结论① △AED≌△AEF）：
  - 高亮△AED和△AEF（蓝色填充20%）
  - 标注AD=AF、AE=AE（公共边）、∠DAE=∠FAE=45°（红色文字）
  - 显示判定：“SAS → △AED≌△AEF”
  - 新增等长标记DE=EF（绿色）
  - 推导说明框：“① △AED≌△AEF (SAS) ⇒ DE=EF”
- 步骤2（证明△ABF≌△ACD）：
  - 高亮△ABF和△ACD（蓝色填充20%）
  - 标注AB=AC、AF=AD、∠BAF=∠CAD（推导：90°-∠FAC）
  - 显示判定：“SAS → △ABF≌△ACD”
  - 新增等长标记BF=DC（绿色）
  - 推导说明框：“② △ABF≌△ACD (SAS) ⇒ BF=DC”
- 步骤3（验证结论③ BE+DC＞DE）：
  - 高亮△BEF三边BE、BF、EF（蓝色实线3px）
  - 标注BF=DC、EF=DE（绿色文字）
  - 显示不等式：“BE+BF＞EF ⇒ BE+DC＞DE”
  - 推导说明框：“③ 在△BEF中，BE+BF＞EF ⇒ BE+DC＞DE ✓”
- 步骤4（验证结论④ BE²+DC²=DE²）：
  - 高亮∠EBF（红色直角符出现）
  - 标注∠EBF=∠ABF+∠ABC=45°+45°=90°
  - 显示勾股定理：“BE²+BF²=EF² ⇒ BE²+DC²=DE²”
  - 推导说明框：“④ ∠EBF=90°，勾股定理 ⇒ BE²+DC²=DE² ✓”
- 步骤5（结论②分析 △ABE∽△ACD）：
  - 高亮△ABE和△ACD轮廓（红色虚线2px，无填充）
  - 标注∠ABE=∠ACD=45°，但∠BAE≠∠CAD（一般情况）
  - 显示结论：“对应角不全相等 ⇒ 不相似”
  - 推导说明框：“② ∠BAE≠∠CAD（一般情况）⇒ △ABE与△ACD不相似 ✗”

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于控件栏左侧 (x=100, y=455)，点击回退到上一状态，步骤0时禁用
  - 「下一步 ▶」按钮：位于控件栏右侧 (x=600, y=455)，点击进入下一状态，步骤5时禁用
  - 步骤指示器：位于控件栏中央 (x=300, y=465)，显示“步骤 0 / 5”，点击可跳转（可选）
- 教师操作流程：
  1. 初始展示基础图形与已知条件，引导学生观察
  2. 点击「下一步」逐步触发全等证明、边长关系、勾股定理验证
  3. 每步配合推导说明框讲解逻辑，高亮元素辅助视觉聚焦
  4. 可随时点击「上一步」回退复习关键步骤
  5. 步骤5展示反例，完成全部结论判定

[技术实现]
- JS 库选择：原生 SVG + Vanilla JavaScript（无需外部库，轻量且精确控制几何元素）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |                  (A)                             |
  |               /   |   \                          |
  |             /     |     \                         |
  |           (F)     |      \                        |
  |            |      |       \                       |
  |            |  /   |  \     \                      |
  |            | /    |   \     \                     |
  |      (B)---E------D-------(C)                    |
  |                                                  |
  |                                                  |
  |                                                  |
  |                                                  |
  |                                  +-------------+ |
  |                                  | 推导说明框   | |
  |                                  +-------------+ |
  |                                                  |
  |  [◀ 上一步]    步骤 0 / 5    [下一步 ▶]          |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  - 状态机设计：`currentStep` 变量 (0~5)，`updateScene(step)` 函数根据步骤切换元素显隐、颜色、填充透明度
  - 坐标计算：所有点坐标硬编码为精确值，线段/弧线使用 SVG `<line>`, `<path>`, `<polygon>`
  - 动画曲线：元素显隐使用 CSS `transition: opacity 0.3s ease, fill 0.3s ease`
  - 事件绑定：按钮 `click` 事件调用 `step++` / `step--` 并调用 `updateScene()`
  - ID 命名规范：所有交互元素及关键图形 ID 以 `scene1-` 为前缀（如 `scene1-tri-aed`, `scene1-btn-next`, `scene1-step-indicator`）
  - JS 隔离：全部代码包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染
  - 文本渲染：使用 `<text>` 元素，`font-family="sans-serif"`, `font-size="14px"`，关键结论加粗
  - 响应式：SVG 设置 `viewBox="0 0 800 500"`，容器宽度100%自适应，高度按比例
