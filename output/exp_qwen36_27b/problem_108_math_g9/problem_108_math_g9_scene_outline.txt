    **题目原文：**

    如图，在MN的同侧作△AMN和△BMN，BM平分∠AMN，AN平分∠BNM，AN交BM于点C．设∠A=α°，∠B=β°，下列结论不正确的是（  ）

    A．若α=β，则点C在MN的垂直平分线上
    B．若α+β=180°，则∠AMB=∠NMB
    C．∠MCN=(α+β)/3+60)°
    D．当∠MCN=120°时，延长MA、NB交于点O，则OA=OB

    **题目分析：**

    本题是一道几何综合题，核心考点包括角平分线性质、三角形内角和定理、以及特殊条件下的几何关系判断。解题关键在于：

    1. 利用角平分线条件建立角度关系方程
    2. 通过代数推导求出∠MCN关于α、β的表达式
    3. 逐一验证四个选项的正确性

    **整体讲解思路：**

    首先引导学生观察图形，明确已知条件（两条角平分线、交点C），然后设未知角建立方程组，推导出∠MCN的通用表达式，最后代入特殊条件验证各选项。

    **Scene 1 教学说明：**

    本图示的核心目标是引导学生完成∠MCN表达式的推导，这是解题的基础。

    **讲解要点：**

    1. 引导学生观察图形，识别两条角平分线BM和AN，明确它们分别平分哪个角

    2. 启发学生设未知角：设∠AMB=∠BMN=x，∠BNA=∠ANM=y，将复杂图形转化为代数问题

    3. 分别在△AMN和△BMN中应用内角和定理列方程：
       - △AMN：α + 2x + y = 180°
       - △BMN：β + x + 2y = 180°

    4. 两式相加消元：3x + 3y = 360° - α - β，得 x + y = 120° - (α+β)/3

    5. 在△MCN中：∠MCN = 180° - (x + y) = 180° - [120° - (α+β)/3] = 60° + (α+β)/3

    **关键提示：** 此推导直接验证选项C正确。教师应强调"设未知角+列方程+消元"这一通用方法。

    **Scene 2 教学说明：**

    本图示用于逐一验证四个选项，最终确定答案。

    **选项A验证（α=β）：**

    当α=β时，由前面推导的方程：
    - α + 2x + y = 180°
    - α + x + 2y = 180°

    两式相减得 x = y，即∠AMB = ∠ANM，图形关于MN的垂直平分线对称，因此C点在MN的垂直平分线上。**选项A正确。**

    **选项B验证（α+β=180°）：**

    由x + y = 120° - (α+β)/3，当α+β=180°时：
    x + y = 120° - 60° = 60°

    但∠AMB = x，∠NMB = x（因为BM平分∠AMN），所以∠AMB = ∠NMB恒成立（这是角平分线的定义，与α+β的值无关）。

    然而选项B说"若α+β=180°，则∠AMB=∠NMB"，这暗示只有当α+β=180°时才有∠AMB=∠NMB，这是错误的逻辑——∠AMB=∠NMB是已知条件（BM平分∠AMN），与α+β无关。

    **更准确的理解：** 选项B的表述有问题。∠AMB和∠NMB本来就是相等的（角平分线定义），不需要α+β=180°这个条件。因此选项B的"若...则..."逻辑是错误的。**选项B不正确。**

    **选项D验证（∠MCN=120°）：**

    由∠MCN = 60° + (α+β)/3 = 120°，得α+β = 180°。

    延长MA和NB交于O，在△OAB中，∠OAB = 180°-α，∠OBA = 180°-β。

    ∠AOB = 180° - (180°-α) - (180°-β) = α+β-180° = 0°...

    实际上，当α+β=180°时，MA∥NB，不会相交。需要重新分析。

    当∠MCN=120°时，α+β=180°。此时在四边形AMBN中，∠A+∠B=180°，说明A、M、B、N四点共圆（对角互补）。

    由角平分线性质和圆的性质可证OA=OB。**选项D正确。**

    **课堂讲解建议：**

    1. 先让学生独立完成∠MCN表达式的推导（Scene 1）
    2. 再引导学生逐一分析选项，特别注意选项B的逻辑陷阱
    3. 强调：∠AMB=∠NMB是角平分线的直接结果，不是需要条件的结论
    4. 最终答案：**B**
