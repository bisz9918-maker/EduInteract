[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库）
- 画布尺寸：800×500px
- 布局草图：
  ```
  ┌─────────────────────────────────────────────────────┐
  │  [选项A]  [选项B]  [选项D]  [总结]                  │ ← 顶部按钮区 y=20~50
  │                                                     │
  │                    A         B                      │
  │                   / \       / \                     │
  │                  /   \     /   \                    │
  │                 /     \   /     \                   │
  │                /       \ /       \                  │
  │               /         C         \                 │
  │              /         / \         \                │
  │             /         /   \         \               │
  │            M─────────N───────────────               │ ← 底边 y=380
  │                                                     │
  │                                                     │
  │         ┌───────────────────────┐                   │
  │         │   ✓ 正确 / ✗ 不正确   │                   │ ← 结论区 y=445~485
  │         └───────────────────────┘                   │
  └─────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：4个状态（state1~state4），每个状态对应一组SVG元素
  2. 状态切换：点击按钮时，隐藏当前状态元素，显示目标状态元素（使用CSS class控制显示/隐藏）
  3. 坐标计算：每个状态的点坐标预计算好，直接设置SVG元素的x/y属性
  4. 动画过渡：状态切换时使用CSS transition实现淡入淡出效果（0.3s）
  5. 事件绑定：4个按钮分别绑定click事件，调用switchState(stateNum)函数
  6. 按钮高亮：激活状态的按钮添加active class，改变背景色和边框色
- ID 命名规范：所有交互元素ID以 `scene2-` 为前缀
  - 按钮：scene2-btn-optionA, scene2-btn-optionB, scene2-btn-optionD, scene2-btn-summary
  - 图形组：scene2-group-state1, scene2-group-state2, scene2-group-state3, scene2-group-state4
  - 结论文字：scene2-conclusion-text
  - 基础图形：scene2-base-mn, scene2-point-m, scene2-point-n
- IIFE 隔离：所有JS代码包裹在 (function() { ... })() 中，避免全局污染
- SVG元素使用 `<g>` 分组管理，每个状态的元素放在独立的 `<g>` 中，通过class控制显示/隐藏
