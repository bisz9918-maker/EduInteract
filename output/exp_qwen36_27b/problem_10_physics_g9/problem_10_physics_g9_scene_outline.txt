    **题目原文：**

    如图，两个用同一种材料制成且完全相同的密闭圆台形容器一正一反放置在同一水平桌面上，容器内装有质量和深度均相同的液体，密度分别为ρ₁和ρ₂，若它们分别在水平方向拉力F₁和F₂的作用下沿桌面做匀速直线运动，速度分别为v和2v，容器底部受到液体的压强分别为P₁和P₂，容器底部受到液体的压力分别为N₁和N₂，现对这些物理量做出如下判断：①ρ₁＞ρ₂；②F₁=F₂；③P₁＞P₂；④N₁＜N₂，其中正确的是（  ）

    A．①②  B．①②③  C．①②④  D．①②③④

    **题目分析：**

    本题是一道综合性的初中物理题，涉及密度、摩擦力、液体压强和液体压力四个知识点。题目给出两个完全相同的圆台形容器一正一反放置，装有质量和深度均相同的液体，在水平拉力作用下做匀速直线运动。需要判断四个命题的正误。

    **整体讲解思路：**

    1. **密度比较（①）**：两容器完全相同但放置方向不同，在液体深度相同的情况下，甲容器（上宽下窄）中液体体积小于乙容器（上窄下宽）中液体体积。由质量相同、ρ=m/V 可得 ρ₁ > ρ₂。

    2. **拉力比较（②）**：匀速直线运动时拉力等于滑动摩擦力。滑动摩擦力 f = μN，其中 N 为容器对桌面的压力（等于容器重力+液体重力）。两容器相同、液体质量相同，故对桌面压力相同，摩擦力相同，拉力相同。速度不影响摩擦力大小。

    3. **压强比较（③）**：液体压强 P = ρgh，深度 h 相同，ρ₁ > ρ₂，故 P₁ > P₂。

    4. **压力比较（④）**：甲容器上宽下窄，液体对底部压力 N₁ < 液体重力 G（侧壁承担部分液体重量）；乙容器上窄下宽，液体对底部压力 N₂ > 液体重力 G（侧壁对液体有向下的挤压）。故 N₁ < N₂。

    **答案：D（①②③④均正确）**

    **Scene 2 教学说明：**

    本图示整合了三个物理量的比较，是本题的核心难点。

    **拉力比较（判断②）：**

    1. 匀速直线运动 → 合力为零 → 拉力 = 摩擦力

    2. 滑动摩擦力 f = μN，其中：
       - μ 为动摩擦因数，两容器材料相同、桌面相同，故 μ 相同
       - N 为容器对桌面的压力 = G_容 + G_液
       - 两容器相同（G_容 相同），液体质量相同（G_液 相同）
       - 故 N₁ = N₂，f₁ = f₂

    3. 因此 F₁ = F₂

    4. **易错点提醒**：速度 v 和 2v 不同，但滑动摩擦力与速度无关（在初中物理范围内），学生容易误认为速度大的摩擦力大

    **压强比较（判断③）：**

    1. 液体压强公式：P = ρgh

    2. 已知 h 相同，ρ₁ > ρ₂（由 Scene 1 得出）

    3. 故 P₁ > P₂

    **压力比较（判断④）：**

    这是本题的难点，需要定性分析：

    1. 甲容器（上宽下窄）：
       - 液体对容器底部的压力 N₁ = P₁ × S₁
       - 但从受力角度：容器侧壁对液体有**斜向下**的支持力分量
       - 液体的重力 G_液 = N₁ + 侧壁支持力的竖直分量
       - 故 N₁ < G_液

    2. 乙容器（上窄下宽）：
       - 容器侧壁对液体有**斜向上**的支持力分量（侧壁"压"液体）
       - 液体的重力 G_液 + 侧壁压力的竖直分量 = N₂
       - 故 N₂ > G_液

    3. 因此 N₁ < G_液 < N₂，即 N₁ < N₂

    **课堂讲解建议：**

    - 压力比较是学生的最大难点，建议用"侧壁作用力"的定性分析而非纯公式推导
    - 可以类比：窄口瓶（乙型）底部受到的压力确实比液体重力大，宽口杯（甲型）底部受到的压力比液体重力小
    - 强调四个判断都正确，答案为 D
    </TEXT_3>

    **完整解答总结：**

    1. **判断① ρ₁ > ρ₂**：✓ 正确
       - 两容器完全相同，液体深度 h 相同
       - 甲容器（上宽下窄）中液体体积 V₁ < 乙容器（上窄下宽）中液体体积 V₂
       - 质量相同 m₁ = m₂，由 ρ = m/V 得 ρ₁ > ρ₂

    2. **判断② F₁ = F₂**：✓ 正确
       - 匀速直线运动，F = f（滑动摩擦力）
       - f = μN，N = G_容 + G_液，两容器和液体均相同
       - 故 F₁ = F₂（与速度无关）

    3. **判断③ P₁ > P₂**：✓ 正确
       - P = ρgh，h 相同，ρ₁ > ρ₂
       - 故 P₁ > P₂

    4. **判断④ N₁ < N₂**：✓ 正确
       - 甲容器侧壁"托"液体：N₁ < G_液
       - 乙容器侧壁"压"液体：N₂ > G_液
       - 故 N₁ < N₂

    **答案：D（①②③④）**

    **教学建议：**
    - 本题综合性强，建议按"密度→拉力→压强→压力"的顺序逐步讲解
    - 重点突破压力比较的难点，用侧壁作用力的定性分析帮助学生理解
    - 提醒学生注意：滑动摩擦力与速度无关这一易错点
