[图示主题与整合说明]
- 本图示主题：圆台形容器正放与倒放的体积对比及密度推导
- 整合的步骤/概念：容器几何形状展示 → 液体深度相同 → 体积比较（V₁ < V₂） → 密度关系推导（ρ₁ > ρ₂）
- 教学价值：教师通过分步按钮引导学生从直观几何观察出发，逐步理解"相同质量、不同体积→密度不同"的物理推理过程，为后续压强和压力判断奠定基础

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于控件栏左侧 (x=260, y=455)，点击回退到上一步骤
  - 「步骤 X/4」指示文字：位于控件栏中央 (x=400, y=470)，显示当前步骤编号
  - 「下一步 ▶」按钮：位于控件栏右侧 (x=470, y=455)，点击进入下一步骤
- 教师操作流程：
  1. 图示加载后显示步骤0（容器基本形状+已知条件标注）
  2. 教师讲解容器形状差异后，点击「下一步」进入步骤1（体积比较）
  3. 教师引导学生观察体积差异后，点击「下一步」进入步骤2（密度推导）
  4. 教师讲解密度公式后，点击「下一步」进入步骤3（结论总结）
  5. 教师可随时点击「上一步」回退到任意步骤复习
  6. 第一步时「上一步」按钮禁用，最后一步时「下一步」按钮禁用

- 关键实现要点：
  1. **状态机设计**：用变量 `currentStep`（0~3）管理当前步骤，每个步骤对应一组元素的显示/隐藏/样式变化
  2. **元素显隐**：步骤1~3新增的元素初始 `opacity="0"`，通过 JS 设置 `opacity="1"` 实现淡入（CSS transition 0.5s）
  3. **容器高亮**：步骤3中容器轮廓线颜色从 #000000 变为 #2e7d32，线宽从 2px 变为 3px
  4. **液体透明度变化**：步骤0 fill-opacity=0.2，步骤1 fill-opacity=0.35
  5. **按钮状态管理**：步骤0时「上一步」按钮 disabled（灰色），步骤3时「下一步」按钮 disabled
  6. **圆台几何计算**：
     - 甲左侧边：x = 155 + (2/9)*(y-360)，右侧边：x = 225 - (2/9)*(y-360)
     - 乙左侧边：x = 545 - (1/6)*(y-360)，右侧边：x = 685 + (1/6)*(y-360)
     - 液面 y=260 时，甲液面端点(133,260)-(247,260)，乙液面端点(562,260)-(668,260)
  7. **箭头绘制**：使用 SVG `<marker>` 定义箭头头部，`<line>` 设置 `marker-end`
  8. **桌面斜线阴影**：用 SVG `<pattern>` 定义45°斜线图案，填充桌面下方矩形区域
- ID 命名规范：所有交互元素 ID 以 `scene1-` 为前缀
  - 容器：`scene1-container-jia`、`scene1-container-yi`
  - 液体：`scene1-liquid-jia`、`scene1-liquid-yi`
  - 液面：`scene1-surface-jia`、`scene1-surface-yi`
  - 标注：`scene1-label-h-left`、`scene1-label-h-right`、`scene1-label-v`、`scene1-label-2v`、`scene1-label-f1`、`scene1-label-f2`
  - 体积：`scene1-label-v1`、`scene1-label-v2`、`scene1-label-v-compare`
  - 密度：`scene1-label-m-equal`、`scene1-label-rho-formula`、`scene1-label-rho-result`、`scene1-label-rho1`、`scene1-label-rho2`
  - 结论：`scene1-label-conclusion`
  - 按钮：`scene1-btn-prev`、`scene1-btn-next`、`scene1-step-indicator`
- IIFE 隔离：所有 JS 代码包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染
