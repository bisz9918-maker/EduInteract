[图示主题与整合说明]
- 本图示主题：台球反弹的几何分析——利用反射定律与互余角求角度
- 整合的步骤/概念：台球桌结构展示 → 球的运动轨迹 → 反射定律（∠1=∠2） → 互余角关系（∠2+∠3=90°） → 最终计算结果（∠1=60°）
- 教学价值：教师通过分步导航控制信息呈现节奏，引导学生从认识图形出发，逐步理解反射定律和互余角关系，最终独立推导出答案。每一步都有明确的视觉变化，帮助学生建立几何直觉。

[分步序列]

- 不显示：任何角度、轨迹、公式
- 视觉：干净的台球桌布局，教师可先让学生观察球的初始位置

步骤1（点击「下一步▶」）：
- 新增：运动轨迹（入射段+反射段，带箭头）、法线（灰色虚线）

步骤2（点击「下一步▶」）：

[标签冲突检查]
- 标签"1"：坐标(490, 105)
- 标签"2"：坐标(565, 105)
- 标签"3"：坐标(675, 355)
- 标签"∠3=30°"：坐标(630, 340)
- 标签"∠1=∠2"：坐标(527, 50)
- 标签"∠2+∠3=90°"：坐标(300, 410)
- 标签"∠2=60°"：坐标(500, 410)
- 标签"∠1=60°，选B"：坐标(400, 430)

逐对检查间距：
- "1"(490,105) 与 "2"(565,105)：间距75px → 无冲突 ✓
- "1"(490,105) 与 "∠1=∠2"(527,50)：间距√(37²+55²)≈66px → 无冲突 ✓
- "2"(565,105) 与 "∠1=∠2"(527,50)：间距√(38²+55²)≈67px → 无冲突 ✓
- "3"(675,355) 与 "∠3=30°"(630,340)：间距√(45²+15²)≈47px → 无冲突 ✓
- "∠2+∠3=90°"(300,410) 与 "∠2=60°"(500,410)：间距200px → 无冲突 ✓
- "∠2+∠3=90°"(300,410) 与 "∠1=60°，选B"(400,430)：间距√(100²+20²)≈102px → 无冲突 ✓
- "∠2=60°"(500,410) 与 "∠1=60°，选B"(400,430)：间距√(100²+20²)≈102px → 无冲突 ✓
- "∠3=30°"(630,340) 与 台球桌右下角(700,380)：间距√(70²+40²)≈81px → 无冲突 ✓
- 所有标签与台球桌边框间距 ≥ 20px → 无冲突 ✓
- 所有标签与控件按钮间距 ≥ 30px → 无冲突 ✓

结论：所有标签之间间距均 ≥ 47px，无重叠风险。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于(250,460)，尺寸120×36px，点击回退到上一步骤，步骤0时禁用
  - 「下一步 ▶」按钮：位于(430,460)，尺寸120×36px，点击进入下一步骤，步骤5时禁用
- 教师操作流程：
  1. 页面加载后显示步骤0（台球桌+球），教师可先让学生观察
  2. 点击「下一步▶」逐步展示轨迹、角度、定律、推导、结论
  3. 可随时点击「◀ 上一步」回退到任意步骤复习
  4. 每步有明确的视觉变化，配合口头讲解

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库，性能好，易于动画控制）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────┐
  │  (80,80)                                          (700,80)  │
  │  ┌────────────────────────────────────────────────┐  │
  │  │  ○                    ○                    ○  │  │
  │  │                                                  │  │
  │  │              白球○                               │  │
  │  │               ╲    ╱  ∠1  ∠2                    │  │
  │  │                ╲  ╱    1   2                    │  │
  │  │                 ╲╱     ↕                        │  │
  │  │                  ∨    法线                      │  │
  │  │                   ╲                             │  │
  │  │                    ╲  ●黑球                     │  │
  │  │                     ╲                           │  │
  │  │                      ╲                          │  │
  │  │                       ╲  3                      │  │
  │  │                        ╲ ∠3=30°                 │  │
  │  │                         ╲                       │  │
  │  │                          ○                      │  │
  │  └────────────────────────────────────────────────┘  │
  │  (100,380)                                      (700,380)│
  │                                                       │
  │  ∠2+∠3=90°          ∠2=60°                           │
  │  ∠1=60°，选B                                            │
  │                                                       │
  │         [◀ 上一步]          [下一步 ▶]                 │
  └─────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 `currentStep`（0~5）跟踪当前步骤，每个步骤对应一组可见元素
  2. 元素管理：所有 SVG 元素初始创建但设置 `opacity="0"` 或 `display="none"`，通过步骤切换控制显隐
  3. 动画实现：使用 CSS transition 和 SVG animate 实现淡入、线条绘制、颜色变化效果
  4. 角度弧线计算：使用 SVG `<path>` 的 arc 命令，根据入射/反射光线方向计算起止角度
     - ∠1弧线：从入射光线方向（约223°）到上边左方向（180°），逆时针
     - ∠2弧线：从上边右方向（0°）到反射光线方向（约60°），顺时针
     - ∠3弧线：从反射光线方向（约-120°）到右边上方向（-90°），顺时针
  5. 箭头实现：使用 SVG `<marker>` 定义箭头，在线段末端引用
  6. 按钮状态：步骤0时"上一步"禁用（灰色），步骤5时"下一步"禁用
  7. 事件绑定：按钮点击事件更新 `currentStep`，调用 `renderStep(currentStep)` 重绘

- ID 命名规范：所有交互元素 ID 以 `scene1-` 为前缀
  - `scene1-table`（台球桌外框）
  - `scene1-table-inner`（台球桌内框）

  - `scene1-known`（已知条件文本）
