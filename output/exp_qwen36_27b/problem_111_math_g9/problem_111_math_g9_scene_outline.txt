    **题目原文：**

    如图，△ABC中，AB=AC=4，∠C=72°，D是AB中点，点E在AC上，DE⊥AB，则cosA的值为（  ）

    A. $\frac{\sqrt{5}-1}{2}$ B. $\frac{\sqrt{5}-1}{4}$ C. $\frac{\sqrt{5}+1}{4}$ D. $\frac{\sqrt{5}+1}{2}$

    **题目分析：**

    本题综合考查等腰三角形性质、垂直平分线性质、相似三角形判定与性质，以及三角函数计算。核心思路是：先由等腰三角形求出∠A=36°，再利用垂直平分线性质推出AE=BE=BC，然后通过△ABC∽△BCE建立黄金分割比例求出AE的长度，最后在Rt△ADE中用定义求cosA。

    **整体讲解思路：**

    本题的讲解分为两个核心阶段：第一阶段是几何关系的推导（角度计算、垂直平分线性质、等腰三角形的发现），第二阶段是代数计算（相似三角形比例、方程求解、三角函数值计算）。两个阶段分别对应两个图示场景。

    - SCENE_2：相似三角形与cosA计算图示——整合相似比例建立、方程求解、最终cosA的计算

    **SCENE_1 教学说明：**

    本图示展示了几何关系推导的完整过程，教师应按以下步骤引导学生：

    1. **步骤0-1：展示题目条件**
       - 引导学生观察图形，识别已知条件：AB=AC=4（等腰三角形），∠C=72°，D是AB中点，DE⊥AB
       - 强调DE⊥AB且D为中点，意味着DE是AB的**垂直平分线**

    2. **步骤2：角度推导**
       - 提问：等腰三角形中，底角相等，∠B等于多少？（72°）
       - 提问：顶角∠A等于多少？（180°-72°-72°=36°）
       - 板书：$\angle A = 36^\circ$

    3. **步骤3-4：垂直平分线性质**
       - 提问：DE是AB的垂直平分线，E在DE上，那么EA和EB有什么关系？
       - 引导学生回忆：垂直平分线上的点到线段两端距离相等
       - 结论：$AE = BE$

    4. **步骤5-7：发现隐藏等腰三角形**
       - 由AE=BE得$\angle EBA = \angle A = 36^\circ$
       - $\angle EBC = \angle ABC - \angle EBA = 72^\circ - 36^\circ = 36^\circ$
       - $\angle BEC = 180^\circ - 72^\circ - 36^\circ = 72^\circ$
       - 因为$\angle BEC = \angle C = 72^\circ$，所以$BE = BC$
       - 最终得到关键结论：$AE = BE = BC$

    **教学提示：** 这一步是本题的核心突破点。学生需要发现△BCE也是等腰三角形，从而建立AE=BC的桥梁关系。如果学生卡住，可以提示他们计算△BCE的各个角度。

    **SCENE_2 教学说明：**

    本图示展示了从几何关系到代数计算的完整推导过程，教师应按以下步骤讲解：

    1. **步骤0-1：相似三角形判定**
       - 引导学生观察△ABC和△BCE
       - 提问：这两个三角形有什么共同特征？
       - 指出：$\angle C$是公共角，$\angle A = \angle EBC = 36^\circ$
       - 由AA判定：$\triangle ABC \sim \triangle BCE$

    2. **步骤2-4：建立比例方程**
       - 由相似得对应边成比例：$\frac{AB}{BC} = \frac{BC}{EC}$
       - 设$AE = x$，由前一步结论$AE = BC$，得$BC = x$
       - $EC = AC - AE = 4 - x$
       - 代入比例式：$\frac{4}{x} = \frac{x}{4-x}$

    3. **步骤5：解方程**
       - 交叉相乘：$x^2 = 4(4-x) = 16 - 4x$
       - 整理：$x^2 + 4x - 16 = 0$
       - 求根公式：$x = \frac{-4 \pm \sqrt{16 + 64}}{2} = \frac{-4 \pm 4\sqrt{5}}{2} = -2 \pm 2\sqrt{5}$
       - 因为$x > 0$，取正根：$x = 2\sqrt{5} - 2$
       - 即$AE = 2\sqrt{5} - 2$

    4. **步骤6-7：计算cosA**
       - 在Rt△ADE中，$\angle ADE = 90^\circ$
       - $AD = \frac{1}{2}AB = 2$（D是中点）
       - $\cos A = \frac{AD}{AE} = \frac{2}{2\sqrt{5}-2}$
       - 分母有理化：$\frac{2}{2\sqrt{5}-2} = \frac{1}{\sqrt{5}-1} = \frac{\sqrt{5}+1}{(\sqrt{5}-1)(\sqrt{5}+1)} = \frac{\sqrt{5}+1}{4}$
       - 答案选 **C**

    **教学提示：**
    - 本题出现的$\frac{\sqrt{5}+1}{4}$与黄金分割比$\frac{\sqrt{5}-1}{2}$密切相关，可以顺便提及36°-72°-72°三角形是"黄金三角形"
    - 分母有理化是易错点，建议板书详细步骤
    - 可以追问学生：为什么舍去负根？（因为长度必须为正）

    **课堂总结建议：**
    1. 回顾本题用到的知识点：等腰三角形性质、垂直平分线性质、相似三角形判定与性质、三角函数定义
    2. 强调解题思路：几何关系推导 → 建立代数方程 → 求解 → 三角函数计算
    3. 拓展：36°角的三角函数值与黄金分割的关系
