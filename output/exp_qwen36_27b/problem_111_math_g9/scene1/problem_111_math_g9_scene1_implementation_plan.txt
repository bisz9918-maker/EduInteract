[图示主题与整合说明]
- 本图示主题：等腰三角形中的角度推导与垂直平分线性质揭示
- 整合的步骤/概念：①题目原图展示 ②已知条件标注 ③角度推导（∠B=72°，∠A=36°） ④垂直平分线性质（AE=BE） ⑤等腰三角形推导（BE=BC，AE=BE=BC）

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于SVG内底部左侧(x=200, y=460)，宽120px，高36px，步骤0时禁用
  - 「下一步 ▶」按钮：位于SVG内底部右侧(x=480, y=460)，宽120px，高36px，步骤7时禁用
  - 步骤指示器：位于SVG内底部中央(x=400, y=460)，显示"步骤 X/7"
- 教师操作流程：
  1. 图示加载后显示步骤0（基础图形），教师可先让学生观察图形
  2. 点击「下一步」逐步展示已知条件、角度推导、垂直平分线性质、相等关系
  3. 每步都有提示文字辅助讲解，教师可配合提示文字进行口头讲解
  4. 可随时点击「上一步」回退到之前的步骤复习
  5. 到达步骤7后展示完整结论AE=BE=BC

[技术实现]
- JS 库选择：原生SVG（简单几何图形，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×400]
  ┌──────────────────────────────────────────────┐
  │                                              │
  │              A(400,80)                       │
  │              /\                               │
  │             /  \                              │
  │            /    \                             │
  │      D(354,223)  \                            │
  │     /|           \ E(458,257)                 │
  │    / |            \                           │
  │   /  |             \                          │
  │  /   |              \                         │
  │ B(307,365)----------C(493,365)               │
  │                                              │
  └──────────────────────────────────────────────┘
  [提示文字区 800×40]  y=400~440
  ┌──────────────────────────────────────────────┐
  │           提示文字（居中显示）                │
  └──────────────────────────────────────────────┘
  [按钮区 800×50]  y=440~490
  ┌──────────────────────────────────────────────┐
  │   [◀ 上一步]    步骤 X/7    [下一步 ▶]       │
  └──────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：当前步骤currentStep(0~7)，每个步骤对应一组SVG元素的显示/隐藏/样式变化
  2. 元素管理：所有SVG元素预先创建，通过CSS类控制显示/隐藏（opacity过渡动画）
  3. 角度弧线绘制：使用SVG <path>的arc命令，根据顶点坐标和半径计算起止角度
  4. 直角符号：在D点处绘制10×10px小方块，一边沿AB方向，一边沿DE方向
  5. 等长标记：在AD和DB中点处绘制垂直于AB的短线（8px）
  6. 高亮效果：通过改变stroke/stroke-width实现线段高亮，通过fill-opacity实现区域填充
  7. 提示文字：使用<text>元素，text-anchor="middle"居中，每步切换内容
  8. 按钮事件：点击时更新currentStep，调用renderStep(currentStep)刷新视图
  9. 动画：元素出现时使用CSS transition（opacity 0→1，duration 0.3s）
- ID 命名规范：所有SVG元素和按钮ID以 scene1- 为前缀
  - 三角形：scene1-tri-ab, scene1-tri-ac, scene1-tri-bc
  - 线段：scene1-line-de, scene1-line-be
  - 顶点标签：scene1-label-a, scene1-label-b, scene1-label-c, scene1-label-d, scene1-label-e
  - 角度标注：scene1-angle-c, scene1-angle-b, scene1-angle-a, scene1-angle-eba, scene1-angle-ebc, scene1-angle-bec
  - 角度弧线：scene1-arc-c, scene1-arc-b, scene1-arc-a, scene1-arc-eba, scene1-arc-ebc, scene1-arc-bec
  - 边长标注：scene1-len-ab, scene1-len-ac
  - 等长标记：scene1-mark-ad, scene1-mark-db
  - 直角符号：scene1-right-angle
  - 关系标注：scene1-rel-ae-be, scene1-rel-be-bc
  - 填充区域：scene1-fill-bce
  - 提示文字：scene1-hint-text
  - 按钮：scene1-btn-prev, scene1-btn-next
  - 步骤指示器：scene1-step-indicator
- IIFE 隔离：所有JS代码包在 (function() { 'use strict'; ... })() 中，避免全局污染
