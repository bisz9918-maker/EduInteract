[分步序列]
- 初始状态（状态0，基础图）：
  显示元素：极点O、经线OP和OQ、P点和Q点、纬线L、自转箭头
  标签：O、P、Q、L、"15°E"(Q下方)、"45°"(P下方)
  底部提示文字："已知：Q=15°E，P=45°（东西经待定）"
  不显示：半球分界线、半球填充、高亮光晕、计算过程、结论

- 状态1（经度差30°）：
  视觉变化：
  - P点下方标签变为"45°E"
  - 显示20°W经线（灰色虚线）和160°E经线（灰色虚线）

- 状态2（经度差60°）：
  视觉变化：
  - P点下方标签变为"45°W"
  - 显示20°W经线（灰色虚线）和160°E经线（灰色虚线）
  - 显示东半球绿色半透明填充（160°E到20°W之间扇形区域）
  - 显示西半球红色半透明填充（20°W到160°E之间扇形区域）

  - 显示"西半球"标签（红色，位置(680,200)）
  - 底部计算过程："经度差 = |45°W - 15°E| = 60°"
  - 底部结论："P在西半球，Q在东半球"（绿色加粗）

[交互方案]
- 交互类型：多状态切换（3个按钮）
- 控件说明：
  - "基础图"按钮：位置(200,455)，大小80×30，点击切换到状态0
  - "经度差30°"按钮：位置(360,455)，大小80×30，点击切换到状态1
  - "经度差60°"按钮：位置(520,455)，大小80×30，点击切换到状态2
- 教师操作流程：
  1. 初始显示基础图（状态0），教师介绍极地投影图的基本结构，指出O为极点、L为纬线、P和Q为经线上的点
  2. 点击"经度差30°"按钮，切换到状态1，教师讲解经度差30°时P点经度推断为45°E，P和Q都在东半球
  3. 点击"经度差60°"按钮，切换到状态2，教师讲解经度差60°时P点经度推断为45°W，P在西半球、Q在东半球
  4. 可自由切换三个状态进行对比讲解

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |                    O (400,100)                    |
  |                   /    \                          |
  |                  /      \                         |
  |                 /        \                        |
  |                /          \                       |
  |               P(260,310)  Q(540,310)              |
  |              /  \__________/  \                   |
  |             /    L (纬线圆弧)    \                 |
  |            /                      \               |
  |          45°                      15°E            |
  |                                                   |
  |          [160°E]    东半球    [20°W]              |
  |                                                   |
  |              计算过程文字区                        |
  |              结论文字区                            |
  |                                                   |
  |    [基础图]  [经度差30°]  [经度差60°]             |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 currentScene 记录当前状态（0/1/2），切换时更新 SVG 元素
  2. 纬线L绘制：使用 SVG <path> 的 arc 命令，以O(400,100)为圆心、半径220px，从P到Q绘制向下凸的圆弧
  3. 半球填充：使用 SVG <path> 绘制扇形区域，东半球为160°E到20°W之间，西半球为20°W到160°E之间
  4. 高亮光晕：使用 SVG <circle> 设置 fill-opacity="0.4" 实现半透明光晕效果
  5. 按钮样式：使用 CSS 类切换选中/未选中状态，选中态背景#1565c0文字#ffffff，未选中态背景#e0e0e0文字#333333
  6. 文字切换：状态切换时更新底部计算过程和结论文字的文本内容
  7. 元素显隐：状态0隐藏半球分界线、填充、光晕、计算过程、结论；状态1/2显示对应元素
- ID 命名规范：所有交互元素 ID 以 scene1- 为前缀，如 scene1-btn-base、scene1-btn-30、scene1-btn-60、scene1-p-point、scene1-q-point、scene1-hemisphere-east 等
- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
