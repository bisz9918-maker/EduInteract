    **题目原文：**

    如图所示的电路中，电源电压恒定；闭合开关S，电流表A、电压表V₁和V₂的示数分别用I、U₁和U₂表示；当滑动变阻器R₂的滑片P由如图位置向左滑动时，这三个电表示数变化量的大小分别用△I、△U₁和△U₂表示．下列判断正确的是（  ）

    A. U₂/I 的值变小

    B. (U₂−U₁)/I 的值不变

    C. △U₁/△I 的值不变

    D. △U₁和△U₂的大小相同

    **题目分析：**

    本题是一道初中物理电路动态分析题，核心考查串联电路中滑动变阻器滑片移动时各电表示数的变化规律，以及比值关系的推导。

    **电路结构：** R₁ 与 R₂（滑动变阻器）串联。电流表 A 测串联电路总电流 I。电压表 V₁ 并联在 R₂ 两端，测 R₂ 的电压 U₁。电压表 V₂ 并联在电源两端，测电源电压 U₂（恒定不变）。

    **关键关系：**
    - U₂ = U₁ + I·R₁（串联电路电压关系）
    - U₂ 恒定，R₁ 为定值电阻
    - 滑片 P 向左滑动 → R₂ 减小 → 总电阻减小 → I 增大 → U₁ = U₂ - I·R₁ 减小

    **选项分析：**
    - A：U₂/I = R₁ + R₂，R₂ 减小 → U₂/I 减小 ✓
    - B：(U₂-U₁)/I = R₁，R₁ 不变 → 比值不变 ✓
    - C：由 U₁ = U₂ - I·R₁，得 △U₁ = -R₁·△I，|△U₁/△I| = R₁，不变 ✓
    - D：U₂ 恒定，△U₂ = 0，而 △U₁ ≠ 0 → 不相同 ✗

    **整体讲解思路：** 先引导学生识别电路结构和各电表测量对象（Scene 1），再通过动态演示滑片移动时各物理量的变化，结合公式推导分析各选项（Scene 2）。

    **图示规划：** 共 2 个场景。Scene 1 用分步按钮导航展示电路结构分析；Scene 2 用连续拖拽滑块模拟滑片移动，实时观察各物理量及比值变化。
    </TEXT_1>

    本图示帮助学生建立对电路结构的清晰认知，是后续动态分析的基础。

    **引导步骤：**

    1. 展示原始电路图后，先让学生观察并回答：这是一个什么类型的电路？（串联）

    2. 点击"下一步"高亮电流路径时，引导学生沿电流方向追踪，确认 R₁ 与 R₂ 是串联关系。强调：串联电路中电流处处相等，电流表 A 测的就是这个电流 I。

    5. 最后展示核心关系式 U₂ = U₁ + I·R₁，这是串联电路的电压分配关系。让学生理解：电源电压等于各电阻分压之和。这个关系式是分析所有选项的基础。

    **Scene 2 教学说明：**

    本图示是本题讲解的核心，通过动态交互让学生直观感受滑片移动时各物理量的变化规律，并验证各选项的正确性。

    **引导步骤：**

    1. **初始状态观察**：先让学生读取初始值（R₂=6Ω，I=1A，U₁=6V，U₂=10V），验证 U₂ = U₁ + I·R₁，即 10 = 6 + 1×4，确认关系式成立。

    2. **拖拽滑片向左**：让学生缓慢拖拽滑片P向左移动，观察：
       - R₂ 的数值逐渐减小
       - I 的数值逐渐增大（总电阻减小，电流增大）
       - U₁ 的数值逐渐减小（U₁ = U₂ - I·R₁，I增大导致U₁减小）
       - U₂ 始终保持 10V 不变（电源电压恒定）

    3. **观察变化量**：拖拽过程中，右侧显示 △I、△U₁、△U₂。让学生注意：
       - △I > 0（电流增大）
       - △U₁ < 0（U₁减小）
       - △U₂ = 0（U₂不变）

    4. **逐项验证选项**：
       - **A选项 U₂/I**：初始值为 10/1 = 10Ω，滑片左移后 I 增大，U₂/I 减小。让学生理解 U₂/I = R₁ + R₂，R₂减小所以比值减小。→ **正确**
       - **B选项 (U₂-U₁)/I**：始终等于 R₁ = 4Ω，不变。引导学生推导：U₂ - U₁ = I·R₁，所以 (U₂-U₁)/I = R₁。→ **正确**
       - **C选项 △U₁/△I**：始终等于 R₁ = 4Ω，不变。推导：由 U₁ = U₂ - I·R₁，两边取变化量得 △U₁ = -R₁·△I，所以 |△U₁/△I| = R₁。→ **正确**
       - **D选项 △U₁ 与 △U₂**：△U₂ = 0（U₂恒定），而 △U₁ ≠ 0，两者不相同。→ **错误**

    5. **总结规律**：
       - 在串联电路中，定值电阻 R₁ 两端的电压变化量与电流变化量之比等于 R₁ 本身，即 △U_R₁/△I = R₁
       - 本题中 U₁ 是 R₂ 的电压，但 △U₁ = -△(I·R₁) = -R₁·△I，所以 |△U₁/△I| = R₁
       - 这是一个重要的结论：在串联电路中，一个电阻的电压变化量与电流变化量之比等于另一个电阻的阻值

    **正确答案：A、B、C**

    **课堂讲解建议：**
    - 先让学生独立分析，再借助图示验证
    - 重点讲解 C 选项的推导过程，这是本题的难点
    - 可以让学生尝试拖拽滑片到不同位置，验证比值是否真的不变，培养实证意识
    - 延伸思考：如果 R₁ 也换成滑动变阻器，结论还成立吗？（不成立，因为 R₁ 不再是定值）
