[图示主题与整合说明]
- 本图示主题：滑片移动时各物理量变化及选项比值分析
- 整合的步骤/概念：串联电路中滑动变阻器滑片移动 → R₂接入电阻变化 → 电流I变化 → U₁变化 → 各选项比值（U₂/I、(U₂-U₁)/I、△U₁/△I）的恒定性分析
- 教学价值：教师通过拖拽滑片P，让学生直观感受"R₂变化→I变化→U₁变化"的因果链条，同时观察各比值是否恒定，从而理解选项A、B、C正确而D错误的物理本质。拖拽操作比静态分步更符合物理过程的连续性。

[分步序列]
本场景为连续拖拽交互，无分步按钮。状态变化如下：

- 初始状态（加载完成）：
  * 左侧电路图完整显示：电源、R₁、R₂、A、V₁、V₂、开关S
  * 滑片P位于R₂中间位置（对应R₂=6Ω）
  * 各物理量显示初始值：R₂=6.0Ω（橙色）、I=1.00A（蓝色）、U₁=6.00V（红色）、U₂=10.00V 恒定（绿色）
  * 右侧变化量区：△I=0.00A、△U₁=0.00V、△U₂=0.00V
  * 四个选项卡片：显示当前比值，判断状态为灰色"——"（未判定）
    - A: U₂/I = 10.00
    - B: (U₂-U₁)/I = 4.00
    - C: △U₁/△I = —（未移动，无法计算）
    - D: △U₁ vs △U₂

- 拖拽滑片向左（R₂减小，如R₂=4Ω）：
  * 滑片P在R₂上向左移动，底部滑块手柄同步左移
  * R₂值实时更新（橙色），如 "R₂ = 4.0 Ω"
  * I 增大：I = 10/(4+4) = 1.25A（蓝色数值增大）
  * U₁ 减小：U₁ = 1.25×4 = 5.00V（红色数值减小）
  * U₂ 保持 10.00V（绿色，标注"恒定"）
  * 变化量更新：△I = +0.25A（蓝色）、△U₁ = -1.00V（红色）、△U₂ = 0.00V（绿色）
  * 选项卡片更新：
    - A: U₂/I = 8.00，判断"变小 ✓"（绿色边框+文字）
    - B: (U₂-U₁)/I = 4.00，判断"不变 ✓"（绿色边框+文字）
    - C: △U₁/△I = 4.00，判断"不变 ✓"（绿色边框+文字）
    - D: △U₁=1.00V vs △U₂=0V，判断"不相同 ✗"（红色边框+文字）

- 拖拽滑片向右（R₂增大，如R₂=8Ω）：
  * 滑片P在R₂上向右移动，底部滑块手柄同步右移
  * R₂值实时更新，如 "R₂ = 8.0 Ω"
  * I 减小：I = 10/(4+8) = 0.83A
  * U₁ 增大：U₁ = 0.83×8 = 6.67V
  * U₂ 保持 10.00V
  * 变化量更新：△I = -0.17A、△U₁ = +0.67V、△U₂ = 0.00V
  * 选项卡片更新：
    - A: U₂/I = 12.00，判断"变大 ✗"（红色边框+文字，因为选项说"变小"）
    - B: (U₂-U₁)/I = 4.00，判断"不变 ✓"（绿色）
    - C: △U₁/△I = 4.00，判断"不变 ✓"（绿色）
    - D: 判断"不相同 ✗"（红色）

- 拖拽回初始位置（R₂=6Ω）：
  * 所有数值恢复初始值
  * 变化量归零
  * 选项判断恢复灰色"——"

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：
  1. 电路图中滑片P：蓝色箭头，可在R₂电阻体上方水平拖拽（x范围：80~460），直接改变R₂接入电阻
  2. 底部滑块手柄：蓝色圆形，可在轨道上水平拖拽（x范围：520~760），与滑片P联动
  3. 两个控件双向联动：拖拽任一控件，另一个同步移动
- 教师操作流程：
  1. 初始状态展示题目条件，各物理量显示初始值
  2. 教师向左拖拽滑片P（或底部滑块），R₂减小，观察I增大、U₁减小、U₂不变
  3. 同时观察右侧选项卡片的比值变化和判断结果
  4. 教师可向右拖拽验证反向变化
  5. 拖拽回初始位置，所有数值和判断恢复初始状态
  6. 通过反复拖拽，让学生理解各比值的物理意义和恒定性

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无需外部库，电路图为简单几何图形，拖拽交互用原生事件即可实现）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────┬─────────────────────────────────┐
  │                                 │  变化量: △I  △U₁  △U₂           │
  │    V₁         P↓        A       │  ─────────────────────────────  │
  │   ──○──┬──────▼──────┬──○──     │  [A. U₂/I = 10.00    ——]       │
  │        │              │         │  [B. (U₂-U₁)/I = 4.00  ——]     │
  │       R₂ (380×20)     │         │  [C. △U₁/△I = —       ——]      │
  │        │              │         │  [D. △U₁ vs △U₂      ——]       │
  │       R₁              │         │  ─────────────────────────────  │
  │        │              │         │  ← R₂减小  [====O====] R₂增大→ │
  │        │              │         │        R₂ = 6.0 Ω              │
  │        └── 电源 ── S ─┘         │                                 │
  │              V₂                  │                                 │
  └─────────────────────────────────┴─────────────────────────────────┘
  ```
- 关键实现要点：
  1. **状态管理**：维护当前R₂值、初始R₂值、初始I/U₁/U₂值。每次拖拽更新R₂后，重新计算I=U₂/(R₁+R₂)、U₁=I×R₂、△I=I-I₀、△U₁=U₁-U₁₀、△U₂=0
  2. **坐标映射**：滑块x坐标 → R₂值：R₂ = 2 + (x - x_min) / (x_max - x_min) × (10 - 2)。电路图滑片P与底部滑块双向映射
  3. **拖拽事件**：mousedown/mousemove/mouseup（桌面端）+ touchstart/touchmove/touchend（移动端）。拖拽时限制x范围，实时更新所有数值显示
  4. **选项判断逻辑**：
     - A: 比较当前U₂/I与初始U₂/I₀，若减小则"变小 ✓"（绿），若增大则"变大 ✗"（红）
     - B: 始终"不变 ✓"（绿），因为(U₂-U₁)/I = R₁ = 4Ω
     - C: 若|△I| > 0.01则显示△U₁/△I值并标注"不变 ✓"（绿），否则显示"—"
     - D: 若|△U₁| > 0.01则"不相同 ✗"（红），否则"—"
  5. **数值格式化**：保留2位小数，如 "1.00 A"、"6.00 V"
  6. **动画**：拖拽时数值变化无动画（实时刷新），选项卡片边框颜色变化用CSS transition 0.3s
  7. **SVG元素ID命名**：所有交互元素ID以 `scene2-` 为前缀，如 `scene2-slider-handle`、`scene2-p-arrow`、`scene2-card-a`、`scene2-val-i` 等
  8. **IIFE 隔离**：所有JS代码包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染
  9. **防抖/节流**：拖拽事件高频触发，数值更新用 requestAnimationFrame 节流，避免过度重绘
