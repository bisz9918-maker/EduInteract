[分步序列]
本场景为连续拖拽交互，无分步按钮，但有三个关键状态：

- 初始状态（滑片P在最左端）：
  - 滑片P位于(150,170)，变阻器接入电阻最大 R_P = 20Ω
  - L₂支路电流最小 I₂ = U/(R₂+R_P) = 6/(10+20) = 0.20A，L₂最暗（光晕透明度10%）
  - L₁支路电流 I₁ = U/R₁ = 6/10 = 0.60A，L₁正常发光（光晕透明度25%）
  - 数据面板显示：U=6.0V, I₁=0.60A, I₂=0.20A, R_P=20Ω
  - 提示文字："拖拽滑片P观察电路变化"

- 拖拽过程中（滑片P向右移动）：
  - 滑片P位置x从150向350移动
  - R_P = 20 × (1 - (x-150)/200)，实时减小
  - I₂ = U/(R₂+R_P) 实时增大
  - L₂光晕透明度从10%逐渐增大到30%
  - L₁电流和亮度始终保持不变
  - 数据面板数值实时更新

- 最终状态（滑片P在最右端）：
  - 滑片P位于(350,170)，变阻器接入电阻最小 R_P = 0Ω
  - L₂支路电流最大 I₂ = U/R₂ = 6/10 = 0.60A，L₂最亮（光晕透明度30%）
  - L₁支路电流 I₁ = 0.60A，L₁亮度始终不变
  - 数据面板显示：U=6.0V, I₁=0.60A, I₂=0.60A, R_P=0Ω
  - 结论：滑片右移→R_P减小→I₂增大→L₂变亮；L₁不受影响

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：
  - 滑片P：绿色箭头，位于滑动变阻器上方，可沿水平方向从x=150拖拽至x=350
  - 拖拽范围：(150,170) 到 (350,170)，对应电阻从20Ω到0Ω
  - 拖拽时实时更新：R_P数值、I₂数值、L₂亮度（光晕透明度）
  - L₁电流和亮度始终保持不变
- 教师操作流程：
  1. 初始状态：滑片在最左端，L₂最暗，L₁正常发光，数据面板显示初始值
  2. 教师拖拽滑片P向右移动，学生观察：
     - R_P数值逐渐减小
     - I₂数值逐渐增大
     - L₂灯泡逐渐变亮
     - L₁灯泡亮度始终不变
  3. 滑片到达最右端：R_P=0Ω，I₂最大，L₂最亮
  4. 教师可来回拖拽，反复演示因果关系
  5. 引导学生得出结论：并联电路中，一条支路电阻变化不影响另一支路

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无需额外库，SVG适合电路图绘制，交互简单）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────┐
  │                                                      │
  │        S              电源                           │
  │     ──/ ────────────||───                            │
  │     │                  │                             │
  │     │                  │                             │
  │     ├─[R]──(L₂)───────┤    A(左)          B(右)      │
  │     │                  │                             │
  │     ├──────(L₁)────────┤                             │
  │     │                  │                             │
  │     └──────────────────┘                             │
  │                                                      │
  │                                    ┌──────────────┐  │
  │                                    │ 实时数据      │  │
  │                                    │ U=6.0V        │  │
  │                                    │ I₁=0.60A      │  │
  │                                    │ I₂=0.20A      │  │
  │                                    │ R_P=20Ω       │  │
  │                                    └──────────────┘  │
  │                                                      │
  │  拖拽滑片P观察电路变化                               │
  └─────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. **SVG 结构**：使用 `<svg>` 绘制所有电路元件，导线用 `<line>` 和 `<polyline>`，灯泡用 `<circle>` + `<line>`（叉），电源用两条 `<line>`（长短不同），开关用 `<line>`，滑动变阻器用 `<rect>`，滑片用 `<polygon>`（箭头）
  2. **拖拽实现**：滑片P绑定 mousedown/mousemove/mouseup 事件（以及 touchstart/touchmove/touchend），限制拖拽范围为 x∈[150,350]，y固定为170
  3. **电阻计算**：R_P = 20 × (1 - (sliderX - 150) / 200)，sliderX为滑片当前x坐标
  4. **电流计算**：I₁ = U/R₁ = 6/10 = 0.60A（恒定），I₂ = U/(R₂+R_P) = 6/(10+R_P)
  5. **灯泡亮度**：L₁光晕透明度恒定为25%，L₂光晕透明度 = 10% + 20% × (I₂ - 0.20) / (0.60 - 0.20)，范围10%~30%
  6. **数据面板更新**：每次拖拽时更新 I₂ 和 R_P 的文本内容，使用 `textContent` 或 `innerHTML`
  7. **光晕效果**：使用 SVG `<circle>` 带 `opacity` 属性，或 CSS `filter: blur()` 实现发光效果
  8. **电流方向箭头**：使用 SVG `<marker>` 定义箭头，在导线上放置带箭头的线段
  9. **状态机**：无需复杂状态机，拖拽事件直接触发计算和渲染
  10. **防抖**：拖拽时使用 `requestAnimationFrame` 优化渲染性能

- **ID 命名规范**：所有交互元素 ID 以 `scene1-` 为前缀
  - `scene1-power`：电源
  - `scene1-switch`：开关S
  - `scene1-node-a`：左侧节点A
  - `scene1-node-b`：右侧节点B
  - `scene1-rheostat`：滑动变阻器电阻体
  - `scene1-slider`：滑片P（可拖拽）
  - `scene1-slider-label`：滑片标签"P"
  - `scene1-lamp-l2`：L₂灯泡
  - `scene1-lamp-l2-glow`：L₂光晕
  - `scene1-lamp-l1`：L₁灯泡
  - `scene1-lamp-l1-glow`：L₁光晕
  - `scene1-data-panel`：数据面板
  - `scene1-data-u`：电压显示
  - `scene1-data-i1`：I₁显示
  - `scene1-data-i2`：I₂显示
  - `scene1-data-rp`：R_P显示
  - `scene1-hint`：提示文字

- IIFE 隔离：所有 JS 包在 `(function() { ... })()` 中，避免全局污染
