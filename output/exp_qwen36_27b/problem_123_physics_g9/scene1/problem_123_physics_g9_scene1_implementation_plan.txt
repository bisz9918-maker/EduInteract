[分步序列]
- 初始状态（步骤0）：
  显示元素：三个容器轮廓（黑色实线）、容器名称标签"甲""乙""丙"
  不显示：管道、水位线、气体空间、开关M
  视觉效果：容器轮廓清晰，标签醒目

- 步骤1：点击「下一步」→
  新增元素：右侧水连通管（蓝色实线，U形路径）、标签"甲丙水连通管"
  高亮效果：水连通管线宽加粗至3px，添加淡蓝色发光效果
  管内显示水体填充（蓝色15%透明）
  其他元素保持不变

- 步骤2：点击「下一步」→
  新增元素：左侧气体连通管（红色实线，折线路径）、标签"乙丙气体连通管"
  高亮效果：气体连通管线宽加粗至3px，添加淡红色发光效果
  步骤1元素保持显示但取消高亮（恢复线宽2px）

- 步骤3：点击「下一步」→
  新增元素：中间管子（绿色实线，垂直线段）、开关M（红色圆形）、标签"中间管子"和"M"
  高亮效果：中间管管线宽加粗至3px，添加淡绿色发光效果
  步骤1、2元素保持显示但取消高亮

- 步骤4：点击「下一步」→
  新增元素：三条水位线（蓝色虚线）、三个水体填充区域（蓝色15%透明）、两个气体空间（灰色斜线阴影10%透明）、标签"P₀"
  所有管道取消高亮，恢复线宽2px
  最终展示完整的装置初始状态

（教师可随时点击「上一步」回退到任意步骤复习）

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位置(290,455)-(390,485)，点击返回上一步骤，步骤0时禁用
  - 「下一步 ▶」按钮：位置(410,455)-(510,485)，点击进入下一步骤，步骤4时禁用
- 教师操作流程：
  1. 图示加载后显示步骤0（三个容器轮廓+名称），教师介绍整体布局
  2. 点击「下一步」进入步骤1，高亮水连通管，教师讲解甲丙水连通关系
  3. 点击「下一步」进入步骤2，高亮气体连通管，教师讲解乙丙气体连通关系
  4. 点击「下一步」进入步骤3，高亮中间管子和开关M，教师讲解中间管子结构
  5. 点击「下一步」进入步骤4，显示水位线和气体空间，教师讲解初始状态
  6. 可随时点击「上一步」回退复习任意步骤

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库，轻量高效）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────┐
  │                    (800×500)                        │
  │                                                     │
  │              P₀                                     │
  │              │                                      │
  │         ┌─────────┐                                 │
  │    甲   │  甲容器  │         甲丙水连通管            │
  │         │~~水位~~ │        ┌───┐                    │
  │         └─────────┘        │   │                    │
  │           │  M │           │   │                    │
  │         ┌─┴─────┴─┐        │   │                    │
  │    乙   │  乙容器  │ 乙丙气体│   │                    │
  │         │~~水位~~ │ 连通管 │   │                    │
  │         └─────────┘        │   │                    │
  │                             │   │                    │
  │         ┌─────────┐        │   │                    │
  │    丙   │  丙容器  │        └───┘                    │
  │         │~~水位~~ │                                 │
  │         └─────────┘                                 │
  │                                                     │
  │         ┌──────────┐  ┌──────────┐                 │
  │         │◀ 上一步  │  │ 下一步 ▶│                 │
  │         └──────────┘  └──────────┘                 │
  └─────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用当前步骤索引 currentStep（0~4），每个步骤对应一组可见元素
  2. 元素显隐控制：通过 CSS class `.step-N-visible` 控制各步骤元素的显示/隐藏
  3. 高亮效果：通过 CSS transition 实现线宽变化和发光效果（filter: drop-shadow）
  4. 按钮状态：步骤0时「上一步」禁用（opacity=0.5, pointer-events:none），步骤4时「下一步」禁用
  5. 气体空间斜线阴影：使用 SVG `<pattern>` 定义斜线图案，应用于气体空间矩形
  6. 水位线虚线：使用 SVG `stroke-dasharray="8,4"` 实现虚线效果
  7. 中间管子穿过容器底部：先绘制容器轮廓，再绘制管子，利用 SVG 绘制顺序确保管子覆盖容器底部
  8. 开关M绘制：在中间管子上叠加红色圆形，内部可加白色"M"文字或单独标注
- ID 命名规范：所有交互元素 ID 以 `scene1-` 为前缀
  - 容器：`scene1-container-jia`, `scene1-container-yi`, `scene1-container-bing`
  - 管道：`scene1-water-pipe`, `scene1-gas-pipe`, `scene1-middle-pipe`
  - 开关：`scene1-valve-m`
  - 水位线：`scene1-waterline-jia`, `scene1-waterline-yi`, `scene1-waterline-bing`
  - 水体填充：`scene1-water-fill-jia`, `scene1-water-fill-yi`, `scene1-water-fill-bing`
  - 气体空间：`scene1-gas-space-yi`, `scene1-gas-space-bing`
  - 按钮：`scene1-btn-prev`, `scene1-btn-next`
  - 标签：`scene1-label-jia`, `scene1-label-yi`, `scene1-label-bing`, `scene1-label-p0`, `scene1-label-m`, `scene1-label-water-pipe`, `scene1-label-gas-pipe`, `scene1-label-middle-pipe`
- IIFE 隔离：所有 JS 代码包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染
