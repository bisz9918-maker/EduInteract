[图示主题与整合说明]
- 本图示主题：四个选项光路图对比分析
- 整合的步骤/概念：选项A分析 → 选项B分析 → 选项C分析 → 选项D分析 → 总结正确答案
- 教学价值：教师可通过分步导航逐个剖析各选项光路图的折射规律，直观对比入射/出射光线与法线的偏折关系，强化学生对“光从空气斜射入玻璃向法线偏折，从玻璃斜射入空气远离法线偏折，且平行玻璃砖出射光线与入射光线平行”这一核心知识点的理解。

[分步序列]
- 初始状态（步骤0）：显示四个选项光路图（玻璃砖、光线、法线、标签A/B/C/D），整体灰色显示（opacity: 0.4），无标注，无高亮边框。
- 步骤1：点击「下一步」→ 选项A恢复彩色(opacity: 1)，添加黄色高亮边框。显示顶部绿色标注“向法线偏折✓”(60,120)，显示底部红色标注“仍向法线偏折✗”(160,250)。其余选项保持灰色。
- 步骤2：点击「下一步」→ 选项A恢复灰色，选项B恢复彩色并高亮。显示顶部绿色标注“向法线偏折✓”(260,120)，底部绿色标注“远离法线偏折✓”(360,250)，下方绿色标注“出射∥入射✓”(300,360)。
- 步骤3：点击「下一步」→ 选项B恢复灰色，选项C恢复彩色并高亮。显示顶部红色标注“远离法线偏折✗”(460,120)，底部红色标注“向法线偏折✗”(560,250)。
- 步骤4：点击「下一步」→ 选项C恢复灰色，选项D恢复彩色并高亮。显示中部红色标注“无折射✗”(700,190)。
- 步骤5（总结）：点击「下一步」→ 所有选项恢复灰色。选项B绿色高亮边框(#2e7d32)，显示“✓ 正确答案”(300,360)。选项A/C/D显示红色“✗”(100,360)/(500,360)/(700,360)。

[标签冲突检查]
- 标签"A"：(100,320)
- 标签"B"：(300,320)
- 标签"C"：(500,320)
- 标签"D"：(700,320)
- 顶部标注组：y=120，x间隔200px → 间距充足，无冲突
- 底部标注组：y=250，x间隔200px → 间距充足，无冲突
- 总结标注组：y=360，x间隔200px → 间距充足，无冲突
- 选项标签与总结标注：y差40px，同x → 垂直间距≥40px，无冲突
- 标注与光线：顶部标注y=120，光线最高y=80，法线y=130起 → 垂直错开≥10px，无遮挡
- 标注与玻璃砖：底部标注y=250，玻璃砖底y=210 → 垂直间距≥40px，无遮挡
- 结论：所有标签与图形元素间距均≥12px，布局安全，无重叠风险。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于底部左侧(x=250)，点击返回上一状态，步骤0时禁用
  - 「下一步 ▶」按钮：位于底部右侧(x=450)，点击进入下一状态，步骤5时禁用
- 教师操作流程：教师点击「下一步」逐步引导学生观察每个选项的光路特征，配合标注讲解折射规律；到达步骤5后总结正确答案；可随时点击「上一步」回退复习特定选项。

[技术实现]
- JS 库选择：原生 SVG + CSS + Vanilla JS（无需外部库，轻量高效，适合静态图示+状态切换）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×440]
  ┌──────────┬──────────┬──────────┬──────────┐
  │  选项A   │  选项B   │  选项C   │  选项D   │
  │ (光路图) │ (光路图) │ (光路图) │ (光路图) │
  │  标签A   │  标签B   │  标签C   │  标签D   │
  └──────────┴──────────┴──────────┴──────────┘
  [控件栏 800×50 (y=440~490)]
  ┌──────────────────────────────────────────────┐
  │         [◀ 上一步]          [下一步 ▶]        │
  └──────────────────────────────────────────────┘
  ```
- 关键实现要点：
  - 状态机：`currentStep` (0~5)，`updateStep(step)` 函数根据步骤切换 CSS class（`.dimmed`, `.highlighted`, `.visible`）
  - 元素分组：每个选项独立 `<g id="scene2-opt-A">`，内部包含玻璃砖、光线、法线、标注文本
  - 标注显隐：默认 `opacity="0"`，通过 class `.annot-visible` 切换为 `opacity="1"`
  - 高亮边框：独立 `<rect>` 元素，步骤1-4显示黄色，步骤5选项B显示绿色，其余隐藏
  - 按钮状态：步骤0禁用「上一步」，步骤5禁用「下一步」，通过 `pointer-events: none` 和样式区分
  - 箭头标记：SVG `<marker>` 定义 `scene2-arrow`，光线 `marker-end="url(#scene2-arrow)"`
- ID 命名规范：所有交互元素及关键图形 ID 以 `scene2-` 为前缀（如 `scene2-opt-A`, `scene2-btn-next`, `scene2-annot-A-top`）
- IIFE 隔离：全部 JS 逻辑包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染
