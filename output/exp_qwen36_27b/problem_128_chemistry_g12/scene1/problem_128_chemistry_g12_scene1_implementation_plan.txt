[图示主题与整合说明]
- 本图示主题：正三棱柱晶胞均摊法空间共用关系可视化
- 整合的步骤/概念：晶胞结构识别 → 顶点均摊(1/6) → 水平棱均摊(1/3) → 竖直棱均摊(1/2) → 体心归属(1) → 比例计算汇总
- 教学价值：教师通过分步导航，逐步展示微粒的共用关系和均摊系数，帮助学生理解空间晶胞的均摊法计算逻辑，避免一次性信息过载，便于控制讲解节奏和回退复习。

[分步序列]
- 初始状态（步骤0）：
  - 显示完整正三棱柱晶胞线框
  - 显示6个微粒A（蓝色）、9个微粒B（红色）、1个微粒C（绿色）
  - 右侧显示图例（A/B/C说明）
  - 左侧面板空白
  - 右侧计算面板空白
  - 底部导航按钮可用，步骤指示器高亮第1个点

- 步骤1（顶点A）：
  - 点击「下一步」
  - 中央晶胞：6个微粒A高亮（发光描边），其他微粒淡化
  - 左侧面板：显示6个三棱柱共用1个顶点的示意图，中心顶点高亮，标注系数 1/6
  - 右侧计算面板：显示 N(A) = 6 × 1/6 = 1
  - 步骤指示器高亮第2个点

- 步骤2（水平棱B）：
  - 点击「下一步」
  - 中央晶胞：6个水平棱上的微粒B高亮，其他微粒淡化
  - 左侧面板：显示3个三棱柱共用1条水平棱的示意图，中心棱高亮，标注系数 1/3
  - 右侧计算面板：追加 N(B水平) = 6 × 1/3 = 2
  - 步骤指示器高亮第3个点

- 步骤3（竖直棱B）：
  - 点击「下一步」
  - 中央晶胞：3个竖直棱上的微粒B高亮，其他微粒淡化
  - 左侧面板：显示2个三棱柱共用1条竖直棱的示意图，中心棱高亮，标注系数 1/2
  - 右侧计算面板：追加 N(B竖直) = 3 × 1/2 = 1.5，汇总 N(B) = 3.5
  - 步骤指示器高亮第4个点

- 步骤4（体心C）：
  - 点击「下一步」
  - 中央晶胞：体心微粒C高亮，其他微粒淡化
  - 左侧面板：显示1个三棱柱内部体心示意图，体心高亮，标注系数 1
  - 右侧计算面板：追加 N(C) = 1 × 1 = 1
  - 步骤指示器高亮第5个点

- 步骤5（结论汇总）：
  - 点击「下一步」
  - 中央晶胞：所有微粒恢复清晰显示
  - 左侧面板：空白
  - 右侧计算面板：显示最终比例 A:B:C = 1 : 3.5 : 1 = 2 : 7 : 2
  - 底部显示「核对选项」提示
  - 步骤指示器高亮第6个点
  - 「下一步」按钮禁用

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于(350, 460)，点击回退到上一步
  - 「下一步 ▶」按钮：位于(450, 460)，点击进入下一步
  - 步骤指示器：6个圆点位于(400, 445)，当前步骤高亮显示
- 教师操作流程：
  - 教师从步骤0开始，点击「下一步」逐步展示微粒的共用关系和均摊计算
  - 可随时点击「上一步」回退复习
  - 在步骤5展示最终比例，核对选项

[技术实现]
- JS 库选择：原生 SVG（适合几何图形绘制和交互）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [左侧面板 140px] [中央面板 440px] [右侧面板 140px]
  |               |                |               |
  |  共用示意图   |   正三棱柱晶胞   |  图例+计算    |
  |               |                |               |
  |_______________|________________|_______________|
  [底部控件栏 50px: ◀上一步 | 步骤指示器 | 下一步▶]
  ```
- 关键实现要点：
  - 状态机设计：6个状态（0-5），每个状态对应不同的视觉元素显示和高亮
  - 坐标计算：晶胞顶点、棱中点、体心坐标精确计算
  - 动画曲线：高亮效果使用 CSS transition 实现平滑过渡
  - 事件绑定：按钮点击事件触发状态切换
  - ID 命名规范：所有交互元素 ID 以 `scene1-` 为前缀（如 `scene1-btn-next`, `scene1-particle-a-1`）
  - IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
  - SVG 元素使用 `<g>` 分组管理，便于整体显示/隐藏和高亮控制
