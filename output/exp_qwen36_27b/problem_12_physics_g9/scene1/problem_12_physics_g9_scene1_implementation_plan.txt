[图示主题与整合说明]
- 本图示主题：两个弹簧测力计挂钩相连的受力分析与牛顿第三定律应用
- 整合的步骤/概念：题目原图展示 → 已知条件标注（A读数8N） → 相互作用力分析（牛顿第三定律） → 测力计A受力平衡 → 测力计B受力平衡 → 综合结论
- 教学价值：教师可通过分步按钮控制讲解节奏，逐步引导学生从已知条件推导未知量，直观展示作用力与反作用力的关系及二力平衡条件，强化物理模型构建能力。

[分步序列]
- 初始状态（步骤0）：显示测力计A、B外壳，内部弹簧，挂钩连接，左右圆环，标签"A/甲"、"B/乙"。无受力箭头与数值标注。
- 步骤1：点击「下一步」→ 测力计A外壳高亮(蓝色20%)，上方显示"读数 = 8N"，A挂钩处出现蓝色向右箭头，上方标注"F_B对A = 8N"，右侧提示"弹簧测力计读数 = 挂钩处受力"。
- 步骤2：点击「下一步」→ 测力计B外壳高亮(红色20%)，上方显示"读数 = 8N"，B挂钩处出现红色向左箭头，上方标注"F_A对B = 8N"，连接处上方显示"牛顿第三定律：作用力与反作用力大小相等、方向相反"。
- 步骤3：点击「下一步」→ A左端圆环处出现绿色向左箭头，上方标注"F_手对A = 8N"，A下方显示"A静止 → 合力为0 → F_手对A = F_B对A = 8N"。
- 步骤4：点击「下一步」→ B右端圆环处出现绿色向右箭头，上方标注"F_手对B = 8N"，B下方显示"B静止 → 合力为0 → F_手对B = F_A对B = 8N"。
- 步骤5（结论）：点击「下一步」→ 底部出现结论框"B的读数 = 8N，手对测力计的拉力 = 8N，故选A"，所有箭头与标注保持显示，形成完整受力分析图。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于控件栏左侧(x=250)，点击回退至上一状态，隐藏当前步骤新增元素
  - 「下一步 ▶」按钮：位于控件栏右侧(x=450)，点击推进至下一状态，显示/高亮对应元素
  - 步骤指示器：位于两按钮中间(x=350)，显示"1/5"等进度
- 教师操作流程：教师点击「下一步」逐步展示受力分析过程，配合口头讲解；可随时点击「上一步」回顾前序步骤；最终步骤展示完整结论，便于学生对照笔记。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无需外部库，轻量且完全满足几何绘图与状态切换需求）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×440]
  y=110: 牛顿第三定律说明
  y=140: F_手对A | F_B对A | F_A对B | F_手对B 标签
  y=175: A | B 标签
  y=190-250: 测力计A外壳 | 挂钩连接 | 测力计B外壳
  y=220: 弹簧与箭头水平线
  y=275: 甲 | 乙 标签
  y=310: A平衡说明 | B平衡说明
  y=360-420: 结论框
  [控件栏 y=440-490]
  [◀ 上一步] [1/5] [下一步 ▶]
  ```
- 关键实现要点：
  - 状态机设计：使用 `currentStep` 变量(0-5)控制显示，每个步骤对应一个 `renderStep(step)` 函数，通过 CSS `opacity` 或 `display` 控制元素显隐
  - 坐标计算：所有元素坐标预计算并硬编码，避免运行时动态布局导致偏移
  - 动画曲线：元素出现使用 `transition: opacity 0.3s ease-in-out`，箭头绘制使用 `stroke-dasharray` 动画模拟延伸效果
  - 事件绑定：按钮绑定 `click` 事件，更新 `currentStep` 后调用 `renderStep()`
  - ID 命名规范：所有交互元素与SVG节点 ID 均以 `scene1-` 为前缀（如 `scene1-dynA`, `scene1-arrow-blue`, `scene1-btn-next`）
  - IIFE 隔离：全部 JS 代码包裹在 `(function() { 'use strict'; ... })();` 中，防止全局污染
  - 防重叠保障：严格按布局坐标表实现，标签使用 `text-anchor="middle"` 居中，箭头使用 `<marker>` 定义，确保视觉对齐
