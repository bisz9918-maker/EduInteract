[图示主题与整合说明]
- 本图示主题：原电池-电解池组合装置的电极判断与反应分析
- 整合的步骤/概念：装置结构展示 → 原电池与电解池区域区分 → 电极极性标注与电子流向 → 离子迁移方向 → 电极反应式与选项正误判定
- 教学价值：教师可通过分步按钮逐步引导学生从宏观装置识别过渡到微观粒子行为分析，清晰展示电化学组合装置的工作原理，辅助讲解高考/会考常见题型，强化“电子流向-离子流向-电极反应”的逻辑链条。

[分步序列]
- 初始状态（步骤0）：显示两烧杯、四电极、导线、电流表、断开状态的开关、溶液名称标签。无任何高亮或分析标注。
- 步骤1：点击「下一步」→ 开关闭合动画；左烧杯区域叠加红色半透明高亮，显示“电解池”标签；右烧杯区域叠加蓝色半透明高亮，显示“原电池”标签。
- 步骤2：点击「下一步」→ 四个电极上方分别出现“阴极/阳极/负极/正极”标签；沿导线绘制蓝色实线箭头表示电子流向（下导线：Zn→Cu；上导线：Pt→C）；箭头带流动动画。
- 步骤3：点击「下一步」→ 烧杯溶液内部出现绿色虚线箭头：左烧杯Na⁺→Pt、Cl⁻→Cu；右烧杯H⁺→C；箭头旁标注离子符号。
- 步骤4：点击「下一步」→ 各电极下方弹出反应式文本框（Pt: 2H₂O+2e⁻→H₂↑+2OH⁻；Cu: Cu-2e⁻→Cu²⁺；Zn: Zn-2e⁻→Zn²⁺；C: 2H⁺+2e⁻→H₂↑）；底部居中显示选项分析，C项绿色加粗打√，其余红色打×。
- 教师可随时点击「上一步」回退至任意步骤，所有元素按逆序淡出/移除。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「上一步」按钮：位于控件栏左侧(x=300, y=460)，点击回退至上一状态，禁用时置灰
  - 「下一步」按钮：位于控件栏右侧(x=470, y=460)，点击推进至下一状态，最终步禁用
  - 步骤指示器：控件栏居中显示“步骤 0 / 4”，字体14px
- 教师操作流程：
  1. 初始展示装置全貌，提问学生识别组件
  2. 点击「下一步」闭合开关，引导学生判断哪边是原电池/电解池
  3. 再次点击，展示电极极性与电子流向，讲解“负接阴、正接阳”规律
  4. 继续点击，展示离子迁移方向，强化“阳离子向阴极、阴离子向阳极”记忆
  5. 最后点击，呈现电极反应式与选项判定，完成题目解析
  6. 可随时回退复习任意环节

[技术实现]
- JS 库选择：原生 SVG + Vanilla JavaScript。理由：本场景为静态几何结构+分步显隐/路径动画，SVG 原生支持矢量缩放、CSS 动画与 DOM 事件，无需重型库，加载快且兼容性好。
- 画布尺寸：800 × 500 px（固定 viewBox）
- 布局草图（ASCII）：
  ```
  [y=0~120]  空白/标题预留
  [y=130]    ────(A)──── 上导线(电流表)
  [y=160]    ────[S]──── 下导线(开关)
  [y=175]    电解池      原电池
  [y=190]    |Pt| |Cu|   |Zn| |C|  电极棒
  [y=250~380] [左烧杯]   [右烧杯]
  [y=405]    NaCl溶液    稀H₂SO₄
  [y=425]    选项分析文本
  [y=440~490] [◀上一步] 步骤 0/4 [下一步▶] 控件栏
  ```
- 关键实现要点：
  1. 状态机：`let currentStep = 0; const maxStep = 4;` 使用 `renderStep(step)` 函数统一控制显隐与动画触发。
  2. 元素显隐：通过 CSS class `.step-0`, `.step-1`... 控制 `opacity` 与 `visibility`，配合 `transition: opacity 0.4s ease` 实现平滑过渡。
  3. 箭头动画：电子流向使用 `stroke-dasharray` + `@keyframes dash` 实现流动效果；离子迁移使用 `opacity` 渐显。
  4. 开关动画：步骤0→1时，旋转开关杠杆 `<line>` 的 `transform: rotate()` 实现闭合效果。
  5. 事件绑定：按钮绑定 `click` 事件，更新 `currentStep` 后调用 `renderStep()`，并更新按钮禁用状态与步骤指示器文本。
  6. ID 命名规范：所有交互元素与关键图形 ID 均以 `scene1-` 开头，如 `scene1-beaker-left`, `scene1-btn-next`, `scene1-elec-flow-top`。
  7. IIFE 隔离：全部逻辑包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染，支持多场景同页共存。
  8. 防抖/边界：步骤0禁用「上一步」，步骤4禁用「下一步」，点击无效状态不触发逻辑。
