[图示主题与整合说明]
- 本图示主题：罂粟碱分子结构分解、原子计数与燃烧耗氧量计算
- 整合的步骤/概念：分子结构整体展示 → 分步高亮各结构单元（左侧二甲氧基苯环、异喹啉含氮杂环、亚甲基桥、右侧二甲氧基苯环）→ 逐步统计C/H/O/N原子数 → 展示燃烧反应方程式与耗氧量计算
- 教学价值：教师可通过分步按钮引导学生按"识别结构→计数原子→写出分子式→配平燃烧方程式→计算耗氧量"的递进逻辑逐步讲解，每一步都有明确的视觉高亮和原子计数标注，帮助学生理解复杂有机分子的组成与燃烧反应计算

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于(260,455)，100×36px，#1565c0背景，#ffffff文字，点击回到上一步
  - 「下一步 ▶」按钮：位于(440,455)，100×36px，#1565c0背景，#ffffff文字，点击进入下一步
  - 步骤0时「上一步」按钮禁用（灰色），步骤7时「下一步」按钮禁用（灰色）
- 教师操作流程：
  1. 图示加载后显示完整分子结构（步骤0），教师可先整体介绍罂粟碱分子
  2. 点击「下一步」逐步高亮各结构单元，配合讲解各部分的原子组成
  3. 到达步骤5后，分子式出现，教师可引导学生验证原子总数
  4. 步骤6展示燃烧方程式和计算过程，教师可逐步讲解氧平衡
  5. 步骤7显示最终答案，教师可总结
  6. 随时点击「上一步」回退复习任意步骤

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无需额外库，化学结构图用SVG绘制最精确，交互逻辑简单）
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  ┌──────────────────────────────────────────────┐
  │                                              │
  │         OCH₃                                 │
  │          |                                    │
  │     OCH₃-苯环-CH₂-苯环-OCH₃                 │
  │          |         |                          │
  │     异喹啉环（含N） OCH₃                      │
  │                                              │
  │                                              │
  │   [标注框]                    [标注框]       │
  │                                              │
  │              C₂₀H₂₁NO₄                       │
  │           燃烧方程式区域                      │
  │                                              │
  │                                              │
  │         [◀ 上一步]    [下一步 ▶]             │
  └──────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：用变量 `currentStep`（0-7）管理当前步骤，`goToStep(n)` 函数切换步骤
  2. 每个步骤对应一组SVG元素的显示/隐藏/高亮状态变化
  3. 高亮区域用SVG `<polygon>`（苯环）和 `<ellipse>`（亚甲基桥），设置 `fill` 颜色和 `opacity="0.1"`
  4. 标注框用 `<rect rx="6">` + `<text>` 组合，白色背景带阴影效果（用 `<filter>` 实现）
  5. 化学式中的下标用 `<tspan baseline-shift="sub" font-size="0.7em">` 实现
  6. 按钮禁用状态用 `opacity="0.4"` 和移除点击事件实现
  7. 动画过渡：高亮区域出现时用CSS `transition` 或SVG `<animate>` 实现淡入效果（0.3s）
  8. 苯环双键用两条平行线段表示，间距2px
  9. 所有化学键用 `<line stroke="#000" stroke-width="1.5">` 绘制
- ID 命名规范：所有交互元素ID以 `scene1-` 为前缀
  - 分子结构：`scene1-left-ring`, `scene1-n-ring`, `scene1-right-ring`, `scene1-bridge`
  - 高亮区域：`scene1-highlight-left`, `scene1-highlight-n`, `scene1-highlight-bridge`, `scene1-highlight-right`
  - 标注框：`scene1-label-step1`, `scene1-label-step2`, `scene1-label-step3`, `scene1-label-step4`
  - 分子式：`scene1-formula`
  - 方程式：`scene1-equation`, `scene1-balance`, `scene1-solution`
  - 结论：`scene1-conclusion`
  - 按钮：`scene1-prev-btn`, `scene1-next-btn`
- IIFE 隔离：所有JS代码包在 `(function() { 'use strict'; ... })();` 中，避免全局污染
- 苯环双键绘制：每条双键用两条平行 `<line>`，偏移方向垂直于键方向，偏移量1px
- 含N环中的双键：V3-V7双键，V8-V9双键，V10-V2双键（与苯环共用的V2-V3为单键）
