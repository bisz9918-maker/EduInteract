[视觉元素清单]
- 主分子结构：罂粟碱简化骨架，左侧异喹啉苯环（带两个-OCH3），右侧苯环（带两个-OCH3，经-CH2-桥连接）。非苯环部分（N杂环、桥键、甲氧基）用#cccccc淡化。
- 苯环高亮：两个苯环用#1565c0蓝色3px实线描边突出。
- 放大视图：正六边形（边长50px），内部画同心圆表示芳香性。取代基用短线+文字（-OCH3, -CH2-）标注在对应顶点外侧。
- 氢原子标记：红色实心圆（r=4），带H标签（Ha~He）。
- 等价性文字：“不等价”、“互不等价”，红色16px粗体。
- 计数结果：“5种”，绿色36px粗体，居中显示。
- 一溴代物简图：5个小型苯环结构（边长20px），对应位置用蓝色“Br”替换H，其余取代基简化为短线。
- 颜色/样式：严格遵循 `<SCENE_2>` 配色规格。

[分步序列]

- 步骤1：点击「下一步」→ 右侧出现左侧苯环放大视图，虚线连接原图对应位置。放大环上显示2个红色H标记点（Ha、Hb），标签径向向外偏移10px。
- 步骤2：点击「下一步」→ 放大视图下方出现红色粗体文字“不等价”，Ha/Hb标记点轻微脉冲动画强调。
- 步骤3：点击「下一步」→ 切换放大视图为右侧苯环，虚线更新连接。显示3个红色H标记点（Hc、Hd、He），标签径向向外。
- 步骤4：点击「下一步」→ 放大视图下方出现红色粗体文字“互不等价”，Hc/Hd/He标记点脉冲强调。
- 步骤5：点击「下一步」→ 隐藏放大视图、虚线、H标记及等价性文字。画布中心显示绿色大号文字“5种”，背景轻微淡蓝高亮框衬托。
- 步骤6：点击「下一步」→ 隐藏“5种”文字。底部横向排列5种一溴代物结构简图（①~⑤），每个结构下方带编号。Br原子用蓝色标注在对应取代位点。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「◀ 上一步」：位于底部左侧，点击回退至上一状态，步骤0时禁用
  - 「下一步 ▶」：位于底部右侧，点击推进至下一状态，步骤6时禁用
  - 步骤指示器：按钮中间显示“步骤 X / 6”
- 教师操作流程：教师点击「下一步」逐步引导学生观察苯环位点→标记氢→分析等价性→得出结论→验证异构体结构。可随时点击「上一步」回顾关键推理节点。

[技术实现]
- JS 库选择：原生 SVG + Vanilla JS（无需重型库，结构图静态坐标+CSS过渡动画即可满足需求，性能最优）
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  ┌──────────────────────────────────────────────────────────────┐
  │  [主分子图]          [放大视图区]                             │
  │  (x:120~380)         (x:520~720)                             │
  │  左侧苯环●──虚线──→  正六边形+H标记                          │
  │  右侧苯环●──虚线──→  正六边形+H标记                          │
  │                                                             │
  │  [结论区] (步骤5居中显示"5种")                               │
  │                                                             │
  │  [异构体区] (步骤6底部横向排列①~⑤)                           │
  │  ┌──┐ ┌──┐ ┌──┐ ┌──┐ ┌──┐                                  │
  │  │① │ │② │ │③ │ │④ │ │⑤ │                                  │
  │  └──┘ └──┘ └──┘ └──┘ └──┘                                  │
  │                                                             │
  │  [控件栏] ◀ 上一步  |  步骤 X/6  |  下一步 ▶                │
  └──────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：`currentStep` 变量（0~6），`renderStep(step)` 函数根据步骤显示/隐藏对应 SVG Group，使用 `opacity` 和 `transform` 实现平滑过渡（transition: all 0.4s ease）。
  2. 坐标计算：苯环顶点使用极坐标公式 `x = cx + r*cos(θ)`, `y = cy + r*sin(θ)` 生成，θ 从 -90° 开始每 60° 递增，确保化学结构标准朝向。
  3. 动画曲线：H标记点出现使用 `scale(0)→scale(1)` 弹性动画，等价性文字使用 `translateY(10px)→0` 淡入。
  4. 事件绑定：按钮点击触发 `step++`/`step--` 并调用 `renderStep()`，边界检查防止越界。
- ID 命名规范：所有交互元素及 SVG Group 均以 `scene2-` 为前缀（如 `scene2-main-molecule`, `scene2-zoom-left`, `scene2-ha`, `scene2-btn-next`, `scene2-isomer-1`）。
- IIFE 隔离：全部 JS 逻辑封装在 `(function() { 'use strict'; ... })();` 中，避免全局污染。
- 防重叠保障：所有元素按布局坐标表绝对定位，标签偏移方向严格遵循径向向外或下方居中规则，CSS `pointer-events: none` 应用于纯展示层，确保交互层不遮挡。
