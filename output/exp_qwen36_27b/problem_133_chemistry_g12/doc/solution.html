场景导航：Scene 1

题目原文：

标准状况下，密闭容器内分别充入空气和H$_{2}$、O$_{2}$的混合气体在可移动的活塞两边，充入时体积如图所示，若将装置右边H$_{2}$、O$_{2}$的混合气体点燃引爆，活塞先左弹，恢复至原温度后，活塞右滑最终停在容器的正中央，则原来H$_{2}$、O$_{2}$的体积比最接近于（ ）

①2：7 ②5：4 ③4：5 ④7：2．

A．①② B．②④ C．③④ D．①③

题目分析：

本题是一道化学与物理结合的综合题，核心考点包括：

  1. 氢气与氧气的燃烧反应：2H$_{2}$ + O$_{2}$ → 2H$_{2}$O
  2. 标准状况下水为液态，体积可忽略
  3. 可移动活塞意味着两边压强始终相等
  4. 同温同压下，气体体积比等于物质的量比（阿伏伽德罗定律）

整体讲解思路：

  1. 首先引导学生观察初始状态：左边空气体积为1，右边H$_{2}$和O$_{2}$混合气体体积为3
  2. 理解活塞可移动的含义：两边压强始终相等
  3. 分析反应过程：点燃后H$_{2}$和O$_{2}$反应生成H$_{2}$O（液态），气体物质的量减少
  4. 分析最终状态：活塞停在正中央，左右体积各为2
  5. 利用阿伏伽德罗定律建立方程，分两种情况讨论（H$_{2}$过量或O$_{2}$过量）
  6. 解方程得出两种可能的体积比

图示规划说明：

本规划包含一个核心图示，展示容器从初始状态到最终状态的完整变化过程，通过分步导航帮助学生直观理解体积变化和气体反应的关系。

步骤 0 / 4

本图示教学说明：

步骤0（初始状态）的引导要点：

  1. 请学生观察容器被活塞分为左右两部分
  2. 强调左侧空气体积为1，右侧H$_{2}$和O$_{2}$混合气体体积为3
  3. 提问：活塞为什么停在这个位置？引导学生理解"两边压强相等"
  4. 根据阿伏伽德罗定律：同温同压下，V$_{1}$:V$_{2}$ = n$_{1}$:n$_{2}$，所以右侧气体物质的量是左侧的3倍

步骤1（反应过程）的引导要点：

  1. 展示点燃引爆的效果，吸引学生注意力
  2. 写出反应方程式：2H$_{2}$ + O$_{2}$ → 2H$_{2}$O
  3. 强调关键条件：标准状况下，水为液态，其体积可忽略不计
  4. 解释"活塞先左弹"的原因：反应放热导致气体膨胀，压强增大，推动活塞向左

步骤2（最终状态）的引导要点：

  1. 活塞最终停在正中央，说明左右体积各为2
  2. 左侧空气的物质的量没有变化，但体积从1变为2
  3. 由于两边压强相等、温度相同，体积比等于物质的量比
  4. 因此，右侧剩余气体的物质的量 = 左侧空气的物质的量
  5. 设左侧空气为n mol，则初始右侧为3n mol，反应后右侧剩余n mol

步骤3-4（分类讨论推导）的引导要点：

设H$_{2}$体积为x，O$_{2}$体积为y，则：

  1. x + y = 3（初始体积关系）

情况一：H$_{2}$过量

  1. O$_{2}$完全反应，消耗H$_{2}$为2y
  2. 剩余H$_{2}$ = x - 2y
  3. 剩余气体体积 = 1（等于左侧空气的"1"份）
  4. 即 x - 2y = 1
  5. 联立方程：x + y = 3，x - 2y = 1
  6. 解得：y = 2/3，x = 7/3
  7. H$_{2}$:O$_{2}$ = 7:2（对应选项④）

情况二：O$_{2}$过量

  1. H$_{2}$完全反应，消耗O$_{2}$为x/2
  2. 剩余O$_{2}$ = y - x/2
  3. 剩余气体体积 = 1
  4. 即 y - x/2 = 1
  5. 联立方程：x + y = 3，y - x/2 = 1
  6. 解得：x = 4/3，y = 5/3
  7. H$_{2}$:O$_{2}$ = 4:5（对应选项③）

课堂讲解建议：

  • 在步骤0时，可让学生先猜测反应后活塞的位置
  • 在步骤1时，重点强调"标准状况下水为液态"这一隐含条件，这是解题关键
  • 在步骤2时，引导学生思考为什么需要分类讨论（H$_{2}$可能过量，O$_{2}$也可能过量）
  • 在步骤3-4时，可在黑板上同步书写推导过程，帮助学生理解代数运算
  • 最后总结：答案为③④，选C
