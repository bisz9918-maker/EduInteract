[图示主题与整合说明]
- 本图示主题：三种笼状烃（正四面体烷、棱柱烷、立方烷）的立体结构展示与分子式推导
- 整合的步骤/概念：①展示A、B、C三个分子的骨架结构 ②标注碳原子和氢原子 ③推导分子式和最简式 ④对比三个分子的共同特征
- 教学价值：教师如何使用此图示进行课堂讲解
  教师可通过分步按钮引导学生从观察三维骨架出发，逐步识别顶点为碳原子、推导氢原子数量，最终得出分子式与最简式。分步呈现避免信息过载，配合高亮与提示文本，帮助学生建立“结构→价键→分子式”的化学思维链条，直观理解笼状烃的对称性与最简式规律。

[视觉元素清单]

- 氢原子：SVG `<circle>`，半径 6px，填充 `#e0e0e0`，描边 `#000000` 1px，位于碳原子外侧径向偏移 18px 处

[分步序列]
- 初始状态（步骤0）：
  - 显示 A、B、C 三个分子的骨架线框图（实线/虚线区分前后）
  - 显示下方标签 A、B、C
  - 提示文本：空或显示“观察三种笼状烃的骨架结构”
- 步骤1：点击「下一步 ▶」
  - 视觉变化：所有顶点处淡入红色碳原子球体（半径8px）
  - 提示文本更新：“每个顶点 = 1个碳原子”
  - 新增元素坐标：A(4个), B(6个), C(8个) 碳原子精确覆盖骨架顶点
- 步骤2：点击「下一步 ▶」
  - 视觉变化：每个碳原子外侧淡入白色氢原子球体（半径6px，带黑边）
  - 提示文本更新：“每个碳原子：3个C-C键 + 1个C-H键”
  - 新增元素坐标：H原子沿顶点外法线方向偏移18px，避开骨架线与标签
- 步骤3：点击「下一步 ▶」
  - 视觉变化：各分子下方淡入分子式文本框（C₄H₄、C₆H₆、C₈H₈）
  - 提示文本更新：“数清C、H原子个数，写出分子式”
  - 文本框位置：y=345~375，水平居中对齐各分子
- 步骤4：点击「下一步 ▶」
  - 视觉变化：分子式下方淡入最简式文本框（CH、CH、CH），绿色边框高亮
  - 提示文本更新：“三者最简式相同，均为 CH”
  - 文本框位置：y=385~415，绿色样式强调结论
  - 按钮状态：「下一步 ▶」禁用，「◀ 上一步」可用

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「◀ 上一步」：位于控件栏左侧 (300,445)，点击回退至上一状态，步骤0时禁用
  - 「下一步 ▶」：位于控件栏右侧 (420,445)，点击推进至下一状态，步骤4时禁用
- 教师操作流程：
  1. 初始展示骨架，提问学生观察空间结构
  2. 点击下一步，揭示碳原子位置，讲解顶点与原子对应关系
  3. 点击下一步，添加氢原子，结合碳四价规则推导H数量
  4. 点击下一步，展示分子式，核对计数结果
  5. 点击下一步，展示最简式，总结规律并强调绿色高亮结论
  6. 可随时点击上一步回顾任意阶段，配合板书或口述解析

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无需重型库，DOM操作轻量高效，适合静态结构分步展示）
- 画布尺寸：800 × 500 px（固定 viewBox）
- 布局草图（ASCII）：
  ```
  [ 提示文本区 y=60 ]
  [ A骨架 ] [ B骨架 ] [ C骨架 ]  y=100~260
  [  标签A ] [ 标签B ] [ 标签C ]  y=310
  [ 分子式A ] [ 分子式B ] [ 分子式C ] y=360
  [ 最简式A ] [ 最简式B ] [ 最简式C ] y=400
  [ ◀ 上一步 | 下一步 ▶ ]        y=445~485
  ```
- 关键实现要点：
  - 状态机：`let currentStep = 0;` 控制 `renderStep(step)` 函数
  - 元素显隐：使用 CSS `opacity` 与 `transition` 实现淡入淡出，避免突兀跳变
  - 坐标计算：骨架顶点硬编码为常量数组，H原子坐标通过顶点+单位外法线×18px 动态生成
  - 事件绑定：按钮 `click` 事件触发 `step++` / `step--`，边界检查后调用 `renderStep()`
  - 文本渲染：分子式/最简式使用 Unicode 下标字符（₄₆₈）确保跨平台兼容，无需 MathJax
- ID 命名规范：所有交互元素与容器 ID 以 `scene1-` 为前缀（如 `scene1-canvas`, `scene1-btn-next`, `scene1-step1-carbons`）
- IIFE 隔离：全部 JS 逻辑包裹在 `(function() { 'use strict'; ... })();` 中，防止全局污染
- 防重叠保障：严格按布局坐标表实现，标签与图形垂直分层，水平均分，代码 agent 可直接映射坐标至 SVG 属性
