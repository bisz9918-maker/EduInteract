[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀上一步"按钮：位置(220,455)，尺寸100×25px，点击后回退到上一步骤，步骤0时禁用（灰色）
  - "下一步▶"按钮：位置(480,455)，尺寸100×25px，点击后进入下一步骤，步骤3（最后一步）时禁用（灰色）
  - 步骤指示文字：位置(370,462)，显示"步骤 X / 4"，X为当前步骤号（1-4）
- 教师操作流程：
  1. 图示加载后显示步骤0（完整装置），教师可先整体介绍实验装置
  2. 点击"下一步▶"进入步骤1，讲解电路回路和电流方向
  3. 点击"下一步▶"进入步骤2，讲解溶液中离子的定向移动
  4. 点击"下一步▶"进入步骤3，讲解离子浓度与灯泡亮度的对应关系
  5. 随时点击"◀上一步"回退复习前面步骤
  6. 讲解完毕后，可反复切换步骤进行对比说明

- 关键实现要点：
  1. **状态机设计**：使用变量 `currentStep`（0-3）管理当前步骤，每个步骤对应一组视觉状态
  2. **SVG 元素管理**：
     - 基础元素（电池、灯泡、广口瓶、电极、导线）始终显示
     - 电流箭头组（`scene1-current-arrows`）：步骤1-3显示，步骤0隐藏
     - 离子组（`scene1-ions`）：步骤2-3显示，步骤0-1隐藏
     - 关系说明文字（`scene1-conclusion`）：步骤3显示，步骤0-2隐藏
  3. **灯泡亮度动画**：使用 CSS transition 或 JavaScript 渐变，从 #9e9e9e 到 #ffeb3b，过渡时间 1s
  4. **离子移动动画**：使用 `requestAnimationFrame` 实现正离子向左、负离子向右的循环移动
     - 正离子 x 坐标在 [560, 600] 范围内往复运动
     - 负离子 x 坐标在 [550, 590] 范围内往复运动
     - 速度：约 20px/s
  5. **电流箭头动画**：使用 CSS animation 实现箭头沿导线方向的流动效果（opacity 闪烁或位置移动）
  6. **事件绑定**：按钮点击事件绑定到 `handlePrevStep()` 和 `handleNextStep()` 函数
  7. **按钮状态管理**：步骤0时"上一步"按钮禁用（opacity=0.5, pointer-events=none），步骤3时"下一步"按钮禁用
- ID 命名规范：所有交互元素 ID 以 `scene1-` 为前缀
  - `scene1-battery`：电池组
  - `scene1-bulb`：灯泡玻璃
  - `scene1-bulb-glow`：灯泡光晕
  - `scene1-bottle`：广口瓶
  - `scene1-solution`：溶液
  - `scene1-electrode-left`：左电极
  - `scene1-electrode-right`：右电极
  - `scene1-wire-1`：导线1（电池正极→电极2）
  - `scene1-wire-2`：导线2（电极1→灯泡）
  - `scene1-wire-3`：导线3（灯泡→电池负极）
  - `scene1-current-arrows`：电流箭头组
  - `scene1-ions`：离子组
  - `scene1-ions-positive`：正离子子组
  - `scene1-ions-negative`：负离子子组
  - `scene1-conclusion`：关系说明文字
  - `scene1-btn-prev`：上一步按钮
  - `scene1-btn-next`：下一步按钮
  - `scene1-step-indicator`：步骤指示文字
- IIFE 隔离：所有 JS 代码包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染
