[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位置(180,455)，尺寸80×30px，步骤0时禁用，点击返回上一步
  - 「步骤 X/5」指示：位置(380,465)，显示当前步骤编号
  - 「下一步 ▶」按钮：位置(540,455)，尺寸80×30px，步骤5时禁用，点击进入下一步
- 教师操作流程：
  1. 图示加载后显示步骤0（四个灰色选项），教师可先让学生猜测答案
  2. 点击「下一步」逐一分析每个选项（步骤1-4），观察方程式、离子变化、曲线趋势
  3. 到达步骤5时，四条曲线叠加对比，正确答案标记出现，教师可总结讲解
  4. 可随时点击「上一步」回退到任意步骤复习

[技术实现]
- JS 库选择：原生 SVG（简单几何图形、曲线、灯泡示意均可用SVG实现，无需额外库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌──────────────────────────────────────────────────────────────┐
  │ A.向醋酸...  B.向AgNO₃...  C.向盐酸...  D.向H₂SO₄...        │ y:15-55
  ├──────────────────────────┬───────────────────────────────────┤
  │ 化学反应方程式           │  曲线图坐标系                      │ y:65-340
  │ 离子方程式               │  ┌─────────────────┐              │
  │                          │  │                 │              │
  │ 离子微观示意图           │  │   曲线绘制区    │              │
  │  ○○ ○○ ○○  →  ●●●●●●   │  │                 │              │
  ├──────────────────────────┤  └─────────────────┘              │
  │ 灯泡亮度示意             │  x轴标签: 加入试剂体积 →          │
  │  ⊗ → ⊗ → ⊗              │  y轴标签: 离子浓度/导电性 ↑       │
  │  暗   中   亮            │                                   │
  ├──────────────────────────┴───────────────────────────────────┤
  │                    ✓ 正确答案：A（步骤5显示）                 │ y:410
  ├──────────────────────────────────────────────────────────────┤
  │         ◀ 上一步        步骤 X/5        下一步 ▶             │ y:440-490
  └──────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. **状态机设计**：用变量 `currentStep`（0-5）管理当前步骤，每个步骤对应一组视觉元素的显示/隐藏/高亮状态
  2. **曲线绘制**：使用SVG `<path>` 元素，用贝塞尔曲线或折线模拟离子浓度变化趋势
     - A曲线：先升后降，控制点设计为抛物线形
     - B曲线：单调下降
     - C曲线：基本水平或微升
     - D曲线：单调下降
  3. **动画曲线**：曲线出现时使用 `stroke-dasharray` + `stroke-dashoffset` 动画，从起点逐步绘制到终点
  4. **灯泡亮度**：用SVG `<circle>` + `<line>`（光芒）实现，通过改变填充颜色和光芒数量表示亮度
  5. **离子微观示意图**：用多个 `<circle>` 表示离子，反应前/后两组对比，中间用 `<path>` 箭头连接
  6. **事件绑定**：按钮点击事件绑定到 `prevStep()` 和 `nextStep()` 函数，更新 `currentStep` 并刷新视图
  7. **高亮切换**：选项标签通过CSS class切换颜色（.option-a-active, .option-b-active等）
- ID 命名规范：所有交互元素ID以 `scene2-` 为前缀
  - 按钮：`scene2-prev-btn`、`scene2-next-btn`
  - 步骤指示：`scene2-step-indicator`
  - 选项标签：`scene2-opt-a`、`scene2-opt-b`、`scene2-opt-c`、`scene2-opt-d`
  - 方程式：`scene2-equation`、`scene2-ionic-equation`
  - 曲线：`scene2-curve-a`、`scene2-curve-b`、`scene2-curve-c`、`scene2-curve-d`
  - 灯泡：`scene2-bulb-1`、`scene2-bulb-2`、`scene2-bulb-3`
  - 正确答案：`scene2-answer`
  - 离子微观图：`scene2-ion-diagram`
  - 坐标轴：`scene2-axis-x`、`scene2-axis-y`
- IIFE 隔离：所有JS代码包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染
