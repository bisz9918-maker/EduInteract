[技术实现]
- JS 库选择：原生 SVG（首选原因：有机分子结构由精确的线段和文本组成，SVG 矢量绘图最适合此类几何图形，且支持CSS动画和交互）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+------------------+
  |                                                  |                  |
  |              分子结构区 (x:30-500)                |   信息面板区     |
  |                                                  |   (x:510-770)    |
  |    酯基1  C=C1   手性碳    C=C2 C=C3 C=C4       |                  |
  |   (蓝色)  (红色)  ★(绿色)  (红色)               |   标题           |
  |     |      |      /|\      |      |      |       |                  |
  |     |      |     / | \     |      |      |       |   分析内容       |
  |   酯基2   酯基3 /  |  \   右侧    |      |       |   逐项显示       |
  |   (蓝色)  (蓝色) /   |   \  碳链   |      |       |                  |
  |                      |                    |       |   图例(步骤1)    |
  |                                                  |                  |
  |                    "化合物A"                      |                  |
  |                                                  |                  |
  +--------------------------------------------------+------------------+
  |                          控件栏 (y:440-490)                          |
  |           [◀ 上一步]          0/6          [下一步 ▶]                |
  +-----------------------------------------------------------------------+
  ```
- 关键实现要点：
  1. **状态机设计**：使用全局变量 `currentStep`（0-6）跟踪当前步骤。每个步骤对应一个渲染函数 `renderStep(n)`，负责清除旧高亮、绘制新高亮、更新信息面板内容
  2. **分子结构绘制**：
     - 使用 SVG `<line>` 绘制所有C-C单键（黑色，线宽2px）
     - 使用 SVG `<line>` 绘制C=C双键（两条平行线，间距3px）
     - 使用 SVG `<line>` + `<text>` 绘制C=O双键（短线指向O原子标签）
     - 使用 SVG `<text>` 标注所有O原子（红色，加粗）
     - 分子骨架作为底层始终显示，高亮层叠加在上层
  3. **高亮实现**：
     - 酯基高亮：SVG `<rect>` 半透明蓝色填充（#1565c0, opacity=0.2），覆盖酯基区域
     - 双键高亮：将双键line的stroke改为红色# c62828，线宽加粗至3px
     - 手性碳高亮：SVG `<circle>` 绿色半透明（#2e7d32, opacity=0.3, r=10）+ `<text>` "★"
     - 原子计数高亮：SVG `<circle>` 橙色半透明（#ff9800, opacity=0.3, r=4），逐个碳原子位置显示
  4. **动画曲线**：
     - 步骤切换使用 CSS transition（0.3s ease-in-out）
     - 步骤2原子计数使用 setTimeout 逐个显示（每50ms显示一个碳原子圆点）
     - 高亮出现使用 opacity 从0到0.2的过渡动画
  5. **事件绑定**：
