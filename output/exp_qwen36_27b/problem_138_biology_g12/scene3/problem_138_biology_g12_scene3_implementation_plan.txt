[图示主题与整合说明]
- 本图示主题：单倍体育种流程——花药离体培养与染色体加倍
- 整合的步骤/概念：植株乙(AABB)产生花粉(花药AB)→花药离体培养→单倍体植株(AB)→秋水仙素处理→二倍体植株(AABB)
- 教学价值：教师通过分步按钮逐步展示单倍体育种的完整流程，帮助学生理解花药离体培养和秋水仙素处理两个关键步骤的原理与结果，配合讲解处理③和处理④的生物学意义

[技术实现]
- JS 库选择：原生 SVG（简单流程图，无需复杂库，轻量高效）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌──────────────────────────────────────────────────────────────────────┐
  │                                                                      │
  │   ┌─────────┐     ┌─────────┐     ┌─────────┐     ┌─────────┐      │
  │   │ 植株乙  │────▶│  花药   │────▶│单倍体植株│────▶│二倍体植株│      │
  │   │  AABB   │ ①  │   AB    │ ①  │   AB    │ ②  │   AABB   │      │
  │   │  🌱🌱🌱  │     │   🟦   │     │   🌱   │     │  🌱🌱🌱  │      │
  │   └─────────┘     └─────────┘     └─────────┘     └─────────┘      │
  │       ▲              ▲              ▲                              │
  │       │花药离体培养   │花药离体培养   │秋水仙素处理                   │
  │                                                                      │
  │                              ┌──────────────────┐                    │
  │                              │原理：抑制纺锤体形成│                    │
  │                              │染色体数目加倍    │                    │
  │                              └──────────────────┘                    │
  │                                                                      │
  │                    ◀ 上一步       1/3       下一步 ▶                 │
  │                                                                      │
  └──────────────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. **状态机设计**：用变量 `currentStep`（0~3）管理当前步骤，每个步骤对应一组可见元素
  2. **元素显隐控制**：通过 CSS class `.hidden { opacity: 0; pointer-events: none; }` 和 `.visible { opacity: 1; }` 控制元素显示/隐藏
  3. **动画实现**：使用 CSS transition（opacity 0.4s ease, transform 0.4s ease）实现淡入滑入效果
     - 步骤1元素：从左侧滑入 `transform: translateX(-30px)` → `translateX(0)`
     - 步骤2元素：从右侧滑入 `transform: translateX(30px)` → `translateX(0)`
     - 步骤3元素：从下方滑入 `transform: translateY(20px)` → `translateY(0)`
  4. **箭头绘制**：使用 SVG `<line>` + `<marker>` 实现带箭头的连线，箭头颜色随步骤变化
  5. **按钮状态管理**：步骤0时上一步按钮 `disabled`，步骤3时下一步按钮 `disabled`
  6. **豌豆植株简图**：用 SVG path 绘制简化的茎（竖线）、叶（椭圆/弧线）、豆荚（弯曲椭圆）
  7. **花药简图**：用 SVG ellipse 绘制椭圆形花药
  8. **事件绑定**：按钮点击事件绑定 `prevStep()` 和 `nextStep()` 函数，更新 `currentStep` 并切换元素显隐
- **ID 命名规范**：所有交互元素 ID 以 `scene3-` 为前缀
  - `scene3-plant-b`（植株乙方框）
  - `scene3-pollen`（花药方框）
  - `scene3-haploid`（单倍体方框）
  - `scene3-diploid`（二倍体方框）
  - `scene3-arrow1`、`scene3-arrow2`、`scene3-arrow3`（三个箭头）
  - `scene3-principle-box`（原理说明框）
  - `scene3-btn-prev`、`scene3-btn-next`（按钮）
  - `scene3-step-indicator`（步骤指示）
- IIFE 隔离：所有 JS 代码包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染
