[图示主题与整合说明]
- 本图示主题：基因控制花色的生化代谢途径及基因型与表现型的对应关系
- 整合的步骤/概念：基因表达过程（转录①+翻译②）、酶催化代谢途径、A/B共存时mRNA结合抑制机制、四种基因型组合对应的花色表现
- 教学价值：教师通过分步按钮逐步揭示基因→mRNA→酶→代谢产物→花色的完整因果链，帮助学生理解基因如何通过控制酶的合成来间接控制生物性状，以及基因互作（mRNA互补结合抑制）的特殊机制

[技术实现]
- JS 库选择：原生 SVG（本图为流程图/代谢途径图，元素为矩形、线条、文字，无需复杂动画库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌──────────────────────────────────────────────────────┐
  │  [基因B]                              [基因A]         │ y=30~60
  │    ↓①                                   ↓①            │ y=60~90
  │  [mRNA] ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ [mRNA]         │ y=95~120
  │          ↘                    ↗                      │
  │          抑制机制文字区（步骤3）                      │ y=95~140
  │          ↗                    ↘                      │
  │    ↓②                                   ↓②            │ y=120~160
  │  [酶B]                                [酶A]           │ y=165~190
  │    ↘                                   ↙              │
  │              [白色前体物质]                          │ y=240~275
  │              ↙              ↘                        │
  │  [蓝色色素]                    [紫色色素]             │ y=310~340
  │                                                      │
  │  [A_B_白花][A_bb紫花][aaB_蓝花][aabb白花]            │ y=370~420
  │                                                      │
  │  [◀上一步]    步骤 X/4    [下一步▶]                   │ y=455~490
  └──────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. **状态机设计**：用变量 `currentStep`（0~4）管理当前步骤，每个步骤对应一组SVG元素的显示/隐藏/样式变化
  2. **元素显隐**：使用CSS类 `.step-hidden`（opacity=0, visibility=hidden）和 `.step-visible`（opacity=1, visibility=visible）控制元素显示
  3. **淡入动画**：使用CSS transition `opacity 0.5s ease` 实现平滑过渡
  4. **箭头绘制**：使用SVG `<line>` 元素配合 `<marker>` 定义箭头头部
  5. **红色"×"标记**：使用SVG `<text>` 元素，内容为"✕"（Unicode U+2715），字号24px，#c62828颜色
  6. **按钮状态**：步骤0时"上一步"按钮disabled（opacity=0.4, pointer-events=none），步骤4时"下一步"按钮disabled
  7. **坐标计算**：所有元素坐标已在布局坐标表中精确规划，直接硬编码，无需动态计算
  8. **事件绑定**：按钮点击事件绑定到 `handlePrev()` 和 `handleNext()` 函数，更新 `currentStep` 后调用 `renderStep()` 重绘
- ID 命名规范：所有交互元素 ID 以 `scene1-` 为前缀
  - `scene1-btn-prev`、`scene1-btn-next`、`scene1-step-indicator`
  - `scene1-gene-b`、`scene1-gene-a`、`scene1-mrna-left`、`scene1-mrna-right`
  - `scene1-enzyme-b`、`scene1-enzyme-a`
  - `scene1-substrate`、`scene1-pigment-blue`、`scene1-pigment-purple`
  - `scene1-inhibition-text`、`scene1-inhibition-x-b`、`scene1-inhibition-x-a`
  - `scene1-table-group`、`scene1-table-cell-1`~`scene1-table-cell-4`
- IIFE 隔离：所有 JS 代码包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染
