[图示主题与整合说明]
- 本图示主题：基因位置与显隐性推断——假设对比分析
- 整合的步骤/概念：常染色体假设推导（排除）→ X染色体假设推导（成立）→ 得出结论（基因在X染色体上，圆眼为显性，棒眼为隐性）
- 教学价值：教师通过分步导航逐步展示两种假设的推理过程，引导学生理解为何常染色体假设被排除、X染色体假设成立，最终得出基因位置和显隐性关系的结论。分步设计便于教师控制讲解节奏，配合课堂互动。

  - 「◀ 上一步」按钮：位置(260,455)-(360,485)，点击返回上一步骤，步骤0时禁用

  3. 点击「下一步」进入步骤2，收起假设A，展示X染色体假设的推导过程（含棋盘格），教师讲解为何1:1:1:1与实际吻合

  5. 可随时点击「上一步」回退到任意步骤复习

[技术实现]
- JS 库选择：原生 SVG（本场景为遗传学推导图示，主要是文本、矩形、线条等简单图形，无需复杂库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌──────────────────────────────────────────────────────────────┐
  │  [假设A：基因在常染色体上]    [假设B：基因在X染色体上]       │ y=25~60
  │  ┌─────────────────────┐    ┌─────────────────────┐          │
  │  │ P: ♀bb×♂BB          │    │ P: ♀X^bX^b×♂X^BY   │          │ y=70~110
  │  │       ↓              │    │       ↓              │          │ y=110~130
  │  │ F₁: Bb               │    │ F₁: ♀X^BX^b ♂X^bY  │          │ y=130~160
  │  │       ↓              │    │ ┌──────────────┐    │          │ y=175~285
  │  │ F₂: 1:2:1            │    │ │  棋盘格      │    │          │
  │  │ 表型比 3:1           │    │ │  2×2格子    │    │          │
  │  │                      │    │ └──────────────┘    │          │
  │  │         ✗            │    │ F₂: 1:1:1:1         │          │ y=300~330
  │  │  与实际不符           │    │         ✓           │          │ y=335~390
  │  └─────────────────────┘    └─────────────────────┘          │
  │              [结论框：基因位于X染色体上...]                    │ y=390~430
  │                                                               │
  │         [◀上一步]   [1/3]   [下一步▶]                         │ y=440~490
  └──────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用当前步骤变量 `currentStep`（0~3），每个步骤对应一组可见/隐藏的元素集合
  2. 元素显隐控制：通过 CSS class `.scene2-hidden { opacity: 0; pointer-events: none; }` 和 `.scene2-visible { opacity: 1; }` 控制，配合 transition 实现淡入淡出动画
  3. 棋盘格绘制：使用 SVG `<rect>` 绘制格子边框，`<line>` 绘制网格线，`<text>` 放置基因型标签
  4. 上标处理：使用 `<tspan baseline-shift="super" font-size="0.75em">` 实现基因型上标（如 X^B 中的 B）
  5. 按钮状态管理：步骤0时"上一步"禁用，步骤3时"下一步"禁用，通过 `disabled` 属性和 CSS 样式控制
