[图示主题与整合说明]
- 本图示主题：系谱图展示与甲、乙两种遗传病的遗传方式逐步推导
- 整合的步骤/概念：①展示完整系谱图及图例；②推导甲病为常染色体显性遗传；③推导乙病为伴X隐性遗传；④标注各成员基因型；⑤展示最终结论
- 教学价值：教师可通过分步按钮逐步引导学生从表型观察→排除法推理→得出结论，每一步都有明确的视觉高亮和推理提示，帮助学生理解遗传病推导的逻辑链条

[技术实现]
- JS 库选择：原生 SVG（简单几何图形和系谱图最适合SVG，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+ 800px
  | Ⅰ  [■]──[○]                          图例       |
  |     1    2                        ┌──────────┐  |
  |     Aa   aa                       │患甲病男性 │  |
  |       │                            │患乙病女性 │  |
  |       ├───────────────┐            │正常男、女 │  |
  | Ⅱ  [■]──[○]  [●]  [○]──[■]        └──────────┘  |
  |     3    4    5    6    7                    |
  |     │    │    │    │    │                    |
  |     └────┘    │    └────┘                    |
  | Ⅲ  [?]       [■]              推理提示框     |
  |     8         9              ┌──────────┐    |
  |                              │ 推理内容  │    |
  |                              └──────────┘    |
  |                    ┌──────────────────┐      |
  |                    │   结论卡片        │      |
  |                    └──────────────────┘      |
  |              [◀上一步] 步骤X/4 [下一步▶]      |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. **状态机设计**：使用全局变量 `currentStep`（0-4）管理当前步骤，每个步骤对应一个渲染函数 `renderStep(step)`
  2. **SVG元素管理**：所有SVG元素按步骤分组（g标签），通过显示/隐藏控制可见性
     - `#scene1-base`：基础系谱图（始终显示）
     - `#scene1-step1`：步骤1高亮和推理框
     - `#scene1-step2`：步骤2高亮和推理框
     - `#scene1-step3`：步骤3基因型标签
     - `#scene1-step4`：步骤4结论卡片
  3. **高亮效果**：使用SVG `<filter>` 实现外发光效果
     ```xml
     <filter id="scene1-glow-blue">
       <feGaussianBlur stdDeviation="4" result="blur"/>
       <feFlood flood-color="#1565c0" flood-opacity="0.6"/>
       <feComposite in2="blur" operator="in"/>
       <feMerge><feMergeNode/><feMergeNode in="SourceGraphic"/></feMerge>
     </filter>
     ```
  4. **填充图案**：使用SVG `<pattern>` 实现斜线和网格填充
     - 斜线填充（患甲病）：45度斜线，间距6px，颜色#1565c0
     - 网格填充（患乙病）：十字交叉线，间距6px，颜色#c62828
  5. **动画过渡**：使用CSS transition实现淡入效果（opacity 0→1，duration 0.4s）
  6. **事件绑定**：按钮点击事件绑定到 `prevStep()` 和 `nextStep()` 函数
  7. **基因型上标**：使用SVG `<tspan baseline-shift="super" font-size="10">` 实现上标效果（如X^B）

- **ID 命名规范**：所有交互元素 ID 以 `scene1-` 为前缀
  - `scene1-svg`：主SVG容器
  - `scene1-individual-1` 到 `scene1-individual-9`：9个个体符号
  - `scene1-mating-1-2`：Ⅰ-1×Ⅰ-2婚配线
  - `scene1-mating-3-4`：Ⅱ-3×Ⅱ-4婚配线
  - `scene1-mating-6-7`：Ⅱ-6×Ⅱ-7婚配线
  - `scene1-step1-group`：步骤1元素组
  - `scene1-step2-group`：步骤2元素组
  - `scene1-step3-group`：步骤3元素组
  - `scene1-step4-group`：步骤4元素组
  - `scene1-reasoning-box`：推理提示框
  - `scene1-conclusion-card`：结论卡片
  - `scene1-btn-prev`：上一步按钮
  - `scene1-btn-next`：下一步按钮
