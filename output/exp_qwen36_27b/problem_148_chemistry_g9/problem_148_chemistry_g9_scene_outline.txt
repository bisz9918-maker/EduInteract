    **题目原文：**

    甲烷和水反应可以制水煤气（混合气体），其反应的微观示意图如图所示．根据微观示意图得出的结论正确的是（  ）

    A. 反应前后各元素的化合价均不变
    B. 该反应中含氢元素的化合物有3种
    C. 该反应中乙和丁的质量比为3：1
    D. 该反应中丙和丁的分子个数比为1：3

    **题目分析：**

    本题是一道化学微观示意图题，考查学生从微观粒子模型推断化学反应的能力。核心考点包括：分子结构识别、化学方程式书写与配平、化合价判断、化合物与单质的区分、质量比与分子个数比的计算。

    **图示解读：**
    - 图例：白色小球 = 氢原子，黑色大球 = 氧原子，斜线大球 = 碳原子
    - 甲：1个碳原子 + 4个氢原子 → CH₄（甲烷）
    - 乙：1个氧原子 + 2个氢原子 → H₂O（水）
    - 丙：1个碳原子 + 1个氧原子 → CO（一氧化碳）
    - 丁：2个氢原子 → H₂（氢气）

    **配平后的化学方程式：** CH₄ + H₂O $\xrightarrow{\text{高温}}$ CO + 3H₂

    **选项分析：**
    - A：错误。C从-4价变为+2价，H从+1价变为0价，化合价发生变化
    - B：错误。含氢元素的化合物只有CH₄和H₂O两种，H₂是单质不是化合物
    - C：乙(H₂O)与丁(H₂)的质量比 = 18 : (3×2) = 18:6 = 3:1，此选项正确
    - D：丙(CO)与丁(H₂)的分子个数比 = 1:3，此选项正确

    **注意：** 经分析C和D两个选项均正确。若为单选题，标准答案通常为D。教学中可引导学生讨论C选项的表述是否严谨。

    **图示规划说明：**

    本教学图示集合包含两个场景：
    1. **SCENE_1**：微观粒子识别与化学方程式推导——帮助学生从微观模型识别分子、推导并配平化学方程式
    2. **SCENE_2**：选项逐一分析——引导学生逐项判断，理解各考点

    两个场景形成递进关系：先建立对反应的整体认识，再进行细节分析。

    **SCENE_1 教学说明：**

    本图示的核心目标是帮助学生从微观粒子模型出发，识别各物质的化学式，并推导出配平的化学方程式。

    **讲解步骤：**

    1. **引导学生观察图例**：先让学生识别三种原子——白色小球是氢原子、黑色大球是氧原子、斜线大球是碳原子。这是解读微观示意图的基础。

    2. **识别分子结构**：
    - 甲分子：1个碳原子 + 4个氢原子 = CH₄（甲烷），正四面体结构
    - 乙分子：1个氧原子 + 2个氢原子 = H₂O（水），V形结构
    - 丙分子：1个碳原子 + 1个氧原子 = CO（一氧化碳），直线形
    - 丁分子：2个氢原子 = H₂（氢气），直线形

    3. **书写化学方程式**：根据反应前后物质，写出 CH₄ + H₂O → CO + H₂

    4. **配平方程式**：
    - 碳原子：左边1个，右边1个 ✓
    - 氧原子：左边1个，右边1个 ✓
    - 氢原子：左边4+2=6个，右边2个 ✗
    - 在H₂前加系数3，使右边氢原子数为6个
    - 最终：CH₄ + H₂O $\xrightarrow{\text{高温}}$ CO + 3H₂

    **教学提示：**
    - 注意原图中丁只画了1个H₂分子，但实际反应生成3个H₂分子，这是学生容易忽略的点
    - 强调配平是解题的关键前提，后续选项分析都依赖配平后的方程式
    - 可让学生先自行尝试配平，再点击"下一步"验证

    **SCENE_2 教学说明：**

    本图示的核心目标是引导学生逐项分析四个选项，理解每个选项涉及的化学概念和计算方法。

    **讲解步骤：**

    1. **选项A分析——化合价变化**
    - 引导学生回忆化合价规则：H通常为+1价，O通常为-2价
    - CH₄中：H为+1价，则C为-4价（4×(+1) + x = 0，x = -4）
    - H₂O中：H为+1价，O为-2价
    - CO中：O为-2价，则C为+2价
    - H₂中：H为0价（单质）
    - 结论：C从-4变为+2，H从+1变为0，化合价发生变化，A错误

    2. **选项B分析——化合物与单质的区分**
    - 含氢元素的物质有：CH₄、H₂O、H₂
    - CH₄和H₂O是化合物（由不同种元素组成）
    - H₂是单质（由同种元素组成）
    - 结论：含氢元素的化合物只有2种，B错误
    - **关键概念**：化合物必须由两种或以上不同元素组成

    3. **选项C分析——质量比计算**
    - 乙是H₂O，相对分子质量 = 1×2 + 16 = 18
    - 丁是H₂，相对分子质量 = 1×2 = 2
    - 从配平方程式可知：1个H₂O生成3个H₂
    - 质量比 = 18 : (3×2) = 18:6 = 3:1
    - 结论：C正确

    4. **选项D分析——分子个数比**
    - 从配平方程式 CH₄ + H₂O → CO + 3H₂ 直接读取系数
    - 丙(CO)的系数为1，丁(H₂)的系数为3
    - 分子个数比 = 1:3
    - 结论：D正确

    **教学总结：**

    经分析，C和D两个选项均正确。若题目为单选题，标准答案通常为D。教学中可引导学生讨论：
    - C选项的表述"乙和丁的质量比为3:1"是否严谨？（乙是反应物，丁是生成物，质量比指反应中消耗与生成的质量比）
    - 有些资料认为C选项正确，有些认为D选项正确，这道题可能存在争议
    - 无论答案如何，解题过程才是最重要的——学生应掌握从微观示意图推导方程式、分析各选项的能力

    **课堂讲解建议：**
    - 先让学生独立分析，再逐项讨论
    - 重点强调配平方程式的重要性——所有计算都基于配平后的方程式
    - 对于化合价计算，可补充练习巩固
    - 对于化合物与单质的区分，可举更多例子帮助理解
