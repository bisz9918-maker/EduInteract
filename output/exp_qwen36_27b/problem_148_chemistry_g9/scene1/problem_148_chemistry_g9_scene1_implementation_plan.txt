[分步序列]
- 初始状态（步骤0）：
  显示元素：反应前框(含甲、乙分子模型)、反应后框(含丙、丁分子模型)、反应箭头(上方标注"高温")、原子图例区(氢/氧/碳原子图例)、"反应前"/"反应后"标签、甲/乙/丙/丁标签
  不显示：化学式标签、化学方程式、新增H₂分子
  教师操作：点击"下一步▶"进入步骤1

- 步骤1：点击「下一步▶」
  视觉变化：在甲/乙/丙/丁分子下方分别淡入化学式标签 CH₄、H₂O、CO、H₂（蓝色#1565c0，18px粗体）
  新增元素坐标：CH₄(120,220)、H₂O(220,220)、CO(520,220)、H₂(620,220)
  动画：化学式标签从opacity=0到opacity=1，duration=0.4s

- 步骤2：点击「下一步▶」
  视觉变化：化学方程式区淡入未配平方程式 "CH₄ + H₂O → CO + H₂"（蓝色#1565c0，20px）
  新增元素坐标：方程式文本居中(400,370)
  动画：方程式从opacity=0到opacity=1，duration=0.5s

- 步骤3：点击「下一步▶」
  视觉变化①：反应后框内淡入2个新增H₂分子（白色小球对），位置(612,245)/(628,245)和(612,285)/(628,285)
  视觉变化②：化学方程式中H₂前添加系数"3"（红色#c62828，22px粗体），方程式变为 "CH₄ + H₂O → CO + 3H₂"
  动画：新增H₂分子从opacity=0到opacity=1，duration=0.4s；系数"3"从scale(0)到scale(1)弹入，duration=0.3s

- 步骤4（最终步骤）：点击「下一步▶」
  视觉变化：化学方程式变为最终配平形式 "CH₄ + H₂O →(高温) CO + 3H₂"，所有系数(1,1,1,3)用绿色#2e7d32高亮显示，箭头上方标注"高温"条件
  动画：方程式颜色从蓝色/红色渐变到绿色，duration=0.5s
  教师操作：点击「◀上一步」可回退到任意步骤

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位置(280,460)，100×40px，#1565c0背景白色文字，点击回退到上一步骤，步骤0时禁用(灰色)
  - 「下一步 ▶」按钮：位置(420,460)，100×40px，#1565c0背景白色文字，点击进入下一步骤，步骤4时禁用(灰色)
  - 步骤指示器：位置(400,450)，显示"步骤 X / 4"文字，#888888色14px
- 教师操作流程：
  1. 图示加载后显示步骤0（原始微观示意图），教师可讲解分子结构和原子组成
  2. 点击「下一步▶」逐步推进，每步有明确的视觉变化配合讲解
  3. 到达步骤4后展示完整配平方程式，总结反应要点
  4. 可随时点击「◀上一步」回退复习任意步骤

[技术实现]
- JS 库选择：原生 SVG（简单几何图形和分子模型最适合SVG实现，无需额外库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +------------------------------------------------------------------+
  |  [反应前框]    →(高温)→    [反应后框]    [原子图例区]             |
  |  +--------+              +--------+    +--------+                |
  |  |  甲    |              |  丙    |    | ○ 氢原子|                |
  |  |  CH₄   |              |  CO    |    | ● 氧原子|                |
  |  |  乙    |              |  丁    |    | ◧ 碳原子|                |
  |  |  H₂O   |              |  H₂    |    +--------+                |
  |  +--------+              +--------+                              |
  |                                                                  |
  |                    化学方程式展示区                               |
  |                  CH₄ + H₂O → CO + 3H₂                            |
  |                                                                  |
  |              [◀ 上一步]    [下一步 ▶]                             |
  |                          步骤 X/4                                 |
  +------------------------------------------------------------------+
  ```
- 关键实现要点：
  1. **状态机设计**：使用变量 `currentStep` (0~4) 管理当前步骤，每个步骤对应一个 `renderStep(n)` 函数
  2. **SVG元素管理**：所有SVG元素通过 `document.createElementNS('http://www.w3.org/2000/svg', 'tag')` 创建，按步骤分组管理
  3. **斜线填充**：使用SVG `<pattern>` 定义45度斜线填充，碳原子circle引用此pattern
  4. **动画实现**：使用CSS transition实现淡入效果（opacity 0→1），系数"3"使用CSS transform scale(0)→scale(1)弹入
  5. **箭头标记**：使用SVG `<marker>` 定义箭头末端标记
  6. **化学方程式渲染**：使用SVG `<text>` 元素，通过 `<tspan>` 实现不同颜色/字号的混合文本
  7. **按钮状态管理**：步骤0时"上一步"按钮disabled(灰色#cccccc)，步骤4时"下一步"按钮disabled
  8. **事件绑定**：按钮点击事件绑定到 `prevStep()` 和 `nextStep()` 函数，更新 `currentStep` 后调用 `renderStep(currentStep)`
- ID 命名规范：所有交互元素ID以 `scene1-` 为前缀，如 `scene1-btn-prev`、`scene1-btn-next`、`scene1-eq-text`、`scene1-h2-extra-1`、`scene1-h2-extra-2`、`scene1-coeff-3`
- IIFE 隔离：所有JS代码包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染
- 化学式下标处理：使用SVG `<tspan baseline-shift="sub" font-size="0.7em">` 实现下标效果（如H₂中的"2"）
- 高温箭头标注：步骤4在方程式箭头上方添加"高温"文字，使用 `<tspan>` 定位
