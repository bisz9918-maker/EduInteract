    **题目原文：**

    现有氢气、氮气、氯化氢、水蒸汽、一氧化碳和二氧化碳混合气体，依次通过下图A、B、C、D装置（假设每步都充分反应），各装置依次除去的气体和最后得到的气体分别是（ ）

    A．HCl、CO、H₂、CO₂、H₂O、N₂
    B．CO₂、CO、H₂、HCl、H₂O、N₂
    C．HCl、CO、H₂、H₂O、CO₂、N₂
    D．H₂、CO、CO₂、HCl、N₂、H₂O

    **题目分析：**

    本题是一道化学实验装置分析题，考查学生对常见气体除杂原理和化学反应的理解。混合气体包含6种成分：H₂、N₂、HCl、H₂O（蒸汽）、CO、CO₂，依次通过4个装置。

    **核心知识点：**
    1. 碳酸氢钠溶液吸收酸性气体（HCl）
    2. 氧化铜在加热条件下与还原性气体（H₂、CO）反应
    3. 澄清石灰水吸收CO₂
    4. 浓硫酸的吸水性

    **整体讲解思路：**

    通过交互式装置图，分步演示混合气体通过每个装置时发生的化学反应和气体成分变化。从初始混合气体开始，逐步追踪每种气体的去向，最终得出各装置除去的气体顺序和剩余气体。

    **图示规划：**

    本大纲规划2个图示：
    - SCENE_1：完整装置流程图 + 分步反应演示（核心图示）
    - SCENE_2：气体成分变化追踪表（辅助总结）

    **SCENE_1 教学说明：**

    本图示是讲解本题的核心工具，通过分步演示帮助学生理解混合气体通过各装置时的化学变化过程。

    **引导步骤：**

    1. **步骤0（初始状态）**：引导学生观察完整装置图，识别4个装置及其内装试剂。提问："这6种气体中，哪些是酸性气体？哪些是还原性气体？哪些是中性气体？"让学生预测各装置可能除去的气体。

    2. **步骤1（A装置）**：强调碳酸氢钠溶液的作用——吸收酸性气体HCl。反应方程式：
       $$\text{NaHCO}_3 + \text{HCl} \rightarrow \text{NaCl} + \text{H}_2\text{O} + \text{CO}_2\uparrow$$
       注意：此步会生成CO₂和水蒸气，但题目关注的是"除去"的气体。

    3. **步骤2（B装置）**：强调氧化铜在加热条件下与还原性气体反应。两个反应方程式：
       $$\text{H}_2 + \text{CuO} \xrightarrow{\Delta} \text{Cu} + \text{H}_2\text{O}$$
       $$\text{CO} + \text{CuO} \xrightarrow{\Delta} \text{Cu} + \text{CO}_2$$
       此步同时除去H₂和CO，生成H₂O和CO₂。

    4. **步骤3（C装置）**：澄清石灰水吸收CO₂。反应方程式：
       $$\text{Ca(OH)}_2 + \text{CO}_2 \rightarrow \text{CaCO}_3\downarrow + \text{H}_2\text{O}$$
       注意：此步除去的是原有的CO₂加上B装置生成的CO₂。

    5. **步骤4（D装置）**：浓硫酸具有强吸水性，除去所有水蒸气（包括原有的和前面反应生成的）。

    6. **步骤5（最终结果）**：只有N₂不参与任何反应，最终剩余。

    **关键教学点：**
    - 气体除杂的顺序很重要，必须先除酸性气体，再除还原性气体，最后干燥
    - N₂是惰性气体，不与任何试剂反应
    - 答案A的顺序对应：A除HCl → B除CO和H₂ → C除CO₂ → D除H₂O → 剩余N₂
    </TEXT_2>

    **完整解答：**

    各装置依次除去的气体为：
    - A装置（碳酸氢钠）：除去 **HCl**
    - B装置（氧化铜加热）：除去 **H₂、CO**
    - C装置（澄清石灰水）：除去 **CO₂**
    - D装置（浓硫酸）：除去 **H₂O**
    - 最终剩余：**N₂**

    对应选项 **A．HCl、CO、H₂、CO₂、H₂O、N₂**

    **课堂讲解建议：**
    - 可让学生先独立分析每个装置的作用，再对照图示验证

    - 可拓展提问：如果装置顺序调换，结果会怎样？
