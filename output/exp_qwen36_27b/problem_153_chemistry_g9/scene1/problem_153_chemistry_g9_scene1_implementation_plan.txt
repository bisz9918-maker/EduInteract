[图示主题与整合说明]
- 本图示主题：混合气体依次通过A、B、C、D装置的完整流程与分步反应演示
- 整合的步骤/概念：初始混合气体6种成分展示 → A装置(NaHCO₃溶液)除HCl → B装置(CuO+加热)除H₂和CO → C装置(澄清石灰水)除CO₂ → D装置(浓硫酸)除H₂O → 最终剩余N₂
- 教学价值：教师可按装置顺序逐步讲解每个装置的化学反应原理和气体成分变化，分步导航配合气泡颜色变化直观展示"哪些气体被除去"，帮助学生理解气体除杂的顺序逻辑

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位置(280,455)-(380,485)，点击返回上一步，步骤0时禁用
  - 「下一步 ▶」按钮：位置(420,455)-(520,485)，点击进入下一步，步骤5时禁用
- 教师操作流程：
  1. 图示加载后显示初始状态（步骤0），6种气体彩色气泡+完整装置图
  2. 教师点击「下一步 ▶」，依次激活A→B→C→D装置，每步展示对应反应方程式和气体除去情况
  3. 到达步骤5后显示最终结果和答案
  4. 教师可随时点击「◀ 上一步」回退到任意步骤进行复习讲解
  5. 气泡颜色变化（彩色→灰色）直观展示气体被除去的过程

[技术实现]
- JS 库选择：原生SVG（简单几何图形绘制首选，无需额外库）+ 原生JavaScript（状态管理和交互控制）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌──────────────────────────────────────────────────────────────┐
  │  H₂  N₂  HCl  H₂O  CO  CO₂          ← 气体气泡 y=50        │
  │                                                              │
  │  ┌──┐    ════    ┌──────────────┐    ════    ┌──┐    ════   │
  │  │A │───────────▶│  B(CuO+△)   │───────────▶│C │───────────▶│D│
  │  └──┘            └──────────────┘            └──┘            │
  │  NaHCO₃              CuO+酒精灯         Ca(OH)₂      H₂SO₄浓 │
  │                                                              │
  │  ┌──────────────────────────────────────────────┐            │
  │  │         反应方程式 / 说明文字                 │ y=375~425  │
  │  └──────────────────────────────────────────────┘            │
  │                                                              │
  │              [◀ 上一步]    [下一步 ▶]                        │ y=455~485│
  └──────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：currentStep变量(0~5)，每个步骤对应一组视图状态
  2. 视图更新函数renderStep(step)：根据步骤号更新装置高亮、气泡颜色、方程式文本、说明文字
  3. 装置高亮：通过切换SVG元素的stroke和stroke-width属性实现
  4. 气泡状态：通过切换fill、stroke、text-decoration属性实现
  5. 气体流动动画：使用SVG `<animateMotion>` 或JavaScript requestAnimationFrame实现小圆点沿导管路径移动
  6. 按钮状态：步骤0时禁用上一步，步骤5时禁用下一步，通过opacity和pointer-events控制
  7. 过渡动画：CSS transition实现颜色和高亮的平滑过渡（0.3s ease）
- ID 命名规范：所有交互元素ID以 `scene1-` 为前缀
  - 气泡：scene1-bubble-h2, scene1-bubble-n2, scene1-bubble-hcl, scene1-bubble-h2o, scene1-bubble-co, scene1-bubble-co2
  - 装置：scene1-device-a, scene1-device-b, scene1-device-c, scene1-device-d
  - 方程式：scene1-equation-box, scene1-equation-text
  - 说明文字：scene1-description-text
  - 按钮：scene1-btn-prev, scene1-btn-next
  - 气体流动点：scene1-gas-particle
- IIFE 隔离：所有JS代码包裹在 (function() { ... })() 中，避免全局污染
- 事件绑定：使用 getElementById 获取元素，addEventListener 绑定点击事件
