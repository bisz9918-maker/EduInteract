[图示主题与整合说明]
- 本图示主题：可逆反应的温度依赖性与选项辨析——理解反应方向与温度的关系
- 整合的步骤/概念：可逆反应方程式展示、温度对反应方向的影响、四个选项的逐一辨析、正确答案确认
- 教学价值：教师可通过分步导航逐步引导学生理解 Co + 2HCl ⇌ CoCl₂ + H₂ 这一可逆反应在不同温度下的反应方向，并逐一辨析四个选项的正误，帮助学生掌握化学平衡移动原理和物质提纯方法

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  * 「◀ 上一步」按钮：位于底部左侧 (200,475-320,495)，点击返回上一步，步骤0时禁用
  * 「下一步 ▶」按钮：位于底部右侧 (480,475-600,495)，点击进入下一步，步骤5时禁用
  * 步骤指示器：位于底部中央 (300,450-500,470)，6个圆点表示步骤0-5，当前步骤高亮显示
- 教师操作流程：
  1. 图示加载后显示步骤0（方程式），教师可先讲解可逆反应方程式
  2. 点击「下一步」进入步骤1，讲解温度对反应方向的影响
  3. 继续点击「下一步」逐步展示选项A、B、C、D的辨析过程
  4. 教师可在任意步骤点击「上一步」回退复习
  5. 到达步骤5后展示正确答案D，完成教学

[技术实现]
- JS 库选择：原生 SVG（简单几何和文本展示首选，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────────┐
  │                                                             │
  │           Co(固) + 2HCl(气) ⇌ CoCl₂(气) + H₂(气)            │  ← 步骤0-1：方程式居中
  │                        900℃                                 │
  │                        600℃                                 │
  │                                                             │
  │         → 高温→正向反应    低温→逆向反应 ←                   │  ← 步骤1：方向箭头
  │                                                             │
  │  ┌──────────┐                                              │
  │  │ 选项文本  │     分析图示区（变化路径/组成/温度等）         │  ← 步骤2-5：选项辨析
  │  │          │     Co→CoCl₂→Co / 堆叠图 / 温度对应           │
  │  └──────────┘                                              │
  │                                                             │
  │                    解释文字                                  │
  │                                                             │
  │              ● ○ ○ ○ ○ ○  步骤指示器                        │
  │         [◀ 上一步]              [下一步 ▶]                   │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：6个状态（步骤0-5），每个状态对应一组SVG元素的显示/隐藏
  2. 状态切换：使用 CSS class 控制元素可见性，当前步骤元素 class="scene2-step-N scene2-active"，其他 class="scene2-step-N scene2-hidden"
  3. 坐标计算：所有元素使用绝对坐标定位，确保不重叠
  4. 动画曲线：步骤切换使用 0.3s ease-in-out 淡入淡出过渡
  5. 事件绑定：按钮点击事件绑定到状态切换函数，步骤0时禁用上一步，步骤5时禁用下一步
  6. 化学式渲染：使用 HTML 下标标签 <sub> 或 SVG <tspan baseline-shift="sub"> 实现化学式下标
  7. 可逆符号：使用 Unicode 字符 ⇌ (U+21CC) 或 SVG path 绘制双向箭头
- ID 命名规范：所有交互元素 ID 以 `scene2-` 为前缀，如：
  * `scene2-equation`：方程式文本
  * `scene2-temp-high`：900℃标注
  * `scene2-temp-low`：600℃标注
  * `scene2-arrow-forward`：正向反应箭头
  * `scene2-arrow-backward`：逆向反应箭头
  * `scene2-option-box`：选项文本框
  * `scene2-analysis-area`：分析图示区
  * `scene2-mark`：对错标记
  * `scene2-explanation`：解释文字
  * `scene2-step-indicator`：步骤指示器
  * `scene2-btn-prev`：上一步按钮
  * `scene2-btn-next`：下一步按钮
  * `scene2-step0` ~ `scene2-step5`：各步骤容器
- IIFE 隔离：所有 JS 代码包裹在 (function() { 'use strict'; ... })() 中，避免全局污染
