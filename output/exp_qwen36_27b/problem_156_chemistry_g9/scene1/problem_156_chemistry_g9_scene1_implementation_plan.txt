[图示主题与整合说明]
- 本图示主题：化学反应微观过程的动态展示——从反应物到生成物的分子重组
- 整合的步骤/概念：反应前分子展示 → 高亮参与反应的分子 → 分子拆解为原子 → 原子重组为生成物 → 标注未反应分子 → 总结反应实质（化学方程式）
- 教学价值：教师通过分步按钮控制讲解节奏，逐步展示"分子拆解→原子重组"的微观本质，帮助学生理解化学反应中"原子不变、分子改变"的核心概念。步骤0展示完整对比，步骤1-3聚焦反应机理，步骤4总结方程式。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无需外部库）。原因：本场景为静态几何图形+简单状态切换，原生SVG足以实现，无需引入D3/Three.js等重型库，保持轻量。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +------------------------------------------------------------------+
  |  [反应前容器 240×300]    →    [反应后容器 240×300]               |
  |  (40,50)-(280,350)       (300-500,200)  (520,50)-(760,350)      |
  |                                                                  |
  |  4×A₂ + 1×B₂             中间过渡区          2×A₂ + 2×AB₂       |
  |                                                                  |
  |  "反应前"                    "反应后"                            |
  |  (160,372)                   (640,372)                           |
  |                                                                  |
  |                    2A₂ + B₂ → 2AB₂                               |
  |                         (400,395)                                |
  |                    ○=A原子  ●=B原子                              |
  |                         (400,418)                                |
  |  ──────────────────────────────────────────────────────────────  |
  |  [◀ 上一步]        步骤 X/4        [下一步 ▶]                    |
  |  (250,458)          (400,478)         (450,458)                  |
  +------------------------------------------------------------------+
  ```
- 关键实现要点：
  1. **状态机设计**：使用 `currentStep` 变量（0~4）管理当前步骤。`updateStep(step)` 函数根据步骤值更新所有SVG元素的显示/隐藏/高亮状态。
  2. **元素分组**：每个分子用 `<g>` 分组，包含原子 `<circle>` 和化学键 `<line>`。高亮边框用独立的 `<rect>` 包裹在 `<g>` 外层。
  3. **显示控制**：使用 CSS 类 `.hidden { opacity: 0; }` 和 `.visible { opacity: 1; }` 控制元素显隐，配合 `transition: opacity 0.4s ease` 实现平滑过渡。
  4. **高亮控制**：参与反应高亮用 `.highlight-reactant { stroke: #1565c0; stroke-width: 3; stroke-dasharray: 6,3; }`，生成物高亮用 `.highlight-product { stroke: #2e7d32; stroke-width: 3; stroke-dasharray: 6,3; }`。
  5. **灰色控制**：未反应分子用 `.inactive { opacity: 0.4; }`。
  6. **按钮状态**：步骤0时上一步按钮 `pointer-events: none; fill: #ccc;`，步骤4时下一步按钮同理。
  7. **化学方程式下标**：使用 `<tspan baseline-shift="sub" font-size="14">` 实现下标效果。
  8. **箭头标记**：使用 `<marker>` 定义箭头头部，`<line>` 绘制箭身。
  9. **事件绑定**：按钮使用 `addEventListener('click', ...)` 绑定点击事件，调用 `updateStep(currentStep ± 1)`。
- ID 命名规范：所有交互元素 ID 以 `scene1-` 为前缀：
  - 容器：`scene1-container-before`, `scene1-container-after`
  - 左侧分子：`scene1-a2-1-before`, `scene1-a2-2-before`, `scene1-a2-3-before`, `scene1-a2-4-before`, `scene1-b2-before`
  - 右侧分子：`scene1-a2-1-after`, `scene1-a2-2-after`, `scene1-ab2-1-after`, `scene1-ab2-2-after`
  - 高亮边框：`scene1-highlight-a2-1-before`, `scene1-highlight-a2-2-before`, `scene1-highlight-b2-before` 等
  - 中间原子：`scene1-atom-w1`, `scene1-atom-w2`, `scene1-atom-w3`, `scene1-atom-w4`, `scene1-atom-b1`, `scene1-atom-b2`
  - 中间AB₂：`scene1-ab2-1-middle`, `scene1-ab2-2-middle`
  - 标签：`scene1-label-before`, `scene1-label-after`, `scene1-label-unreacted`, `scene1-label-equation`, `scene1-legend`
  - 箭头：`scene1-arrow`
  - 按钮：`scene1-btn-prev`, `scene1-btn-next`
  - 步骤指示器：`scene1-step-indicator`
- IIFE 隔离：所有 JS 代码包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染。
- DOM 操作：使用 `document.getElementById()` 获取元素，不使用 `querySelectorAll` 配合全局 class。
