[分步序列]

- 初始状态（步骤0）：
  - 显示：坐标系、溶解度曲线、t₁/t₂/t₃标记、S₁/S₂标记
  - 不显示：A/B/M三点及其虚线、信息面板内容为空或显示"点击「下一步」开始"
  - 所有元素默认灰色/黑色，无高亮

- 步骤1（A点含义）：
  - 新增：A点(320,140)蓝色圆点、A点标签"A"(335,130)、A点虚线
  - 高亮：A点脉冲动画（半径从5到8再回到5，循环）
  - 信息面板显示：
    ```
    步骤1：A点含义
    ──────────────
    坐标：(t₂, S₂)
    
    A点在溶解度曲线上
    → t₂℃时的饱和溶液
    
    溶质质量分数：
    S₂/(100+S₂) × 100%
    ```

- 步骤2（B点含义）：
  - 保留：A点及其标注（保持显示但降低透明度至60%）
  - 新增：B点(440,260)红色圆点、B点标签"B"(455,250)、B点虚线
  - 高亮：B点脉冲动画
  - 信息面板显示：
    ```
    步骤2：B点含义
    ──────────────
    坐标：(t₃, S₁)
    
    B点在曲线下方
    → t₃℃时的不饱和溶液
    
    溶质质量分数：
    S₁/(100+S₁) × 100%
    ```

- 步骤3（M点含义）：
  - 保留：A点、B点（均保持60%透明度）
  - 新增：M点(320,260)绿色圆点、M点标签"M"(335,250)、M点虚线
  - 高亮：M点脉冲动画
  - 信息面板显示：
    ```
    步骤3：M点含义
    ──────────────
    坐标：(t₂, S₁)
    
    M点在曲线下方
    → t₂℃时的不饱和溶液
    
    对比A点：同温度t₂
    但M点溶质更少(S₁<S₂)
    ```

- 步骤4（加水影响）：
  - 高亮：A点和B点同时脉冲动画（恢复100%透明度）
  - 新增：A点和B点周围出现半透明蓝色扩散效果（表示加水稀释）
  - 信息面板显示：
    ```
    步骤4：加水影响
    ──────────────
    各加20g水后：
    
    溶解度：不变（只与温度有关）
    
    A点溶质质量分数：
    S₂/(120+S₂) < S₂/(100+S₂)
    
    B点溶质质量分数：
    S₁/(120+S₁) < S₁/(100+S₁)
    
    结论：都减小，但A仍>B
    ```

- 步骤5（降温影响）：
  - 高亮：A点蓝色脉冲动画
  - 新增：从A点(320,140)沿曲线向左下方的蓝色箭头，指向约(200,260)方向
  - 新增：箭头路径上的小晶体图标（表示析出）
  - 信息面板显示：
    ```
    步骤5：降温影响
    ──────────────
    A点降温过程：
    
    温度↓ → 溶解度↓
    
    饱和溶液→过饱和
    → 晶体析出
    
    溶质质量分数：减小
    
    A点沿曲线向左下方移动
    ```

- 步骤6（M点变饱和）：
  - 高亮：M点绿色脉冲动画
  - 新增：
    ① 从M点(320,260)水平向左的绿色箭头，指向曲线上的(t₁,S₁)点，标注"降温至t₁℃"
    ② 从M点(320,260)垂直向上的绿色箭头，指向A点(320,140)，标注"加(S₂-S₁)g溶质"
    ③ 从M点向右下方的绿色箭头，标注"蒸发溶剂"
  - 信息面板显示：
    ```
    步骤6：M点变饱和
    ──────────────
    三种方法：
    
    ① 降温至 t₁℃
       M点水平左移至曲线
    
    ② 增加溶质 (S₂-S₁)g
       M点垂直上移至A点
    
    ③ 蒸发溶剂
       减少溶剂至饱和
    ```

- "M"(335,250) 与 "B"(455,250)：水平距离120px → 无冲突 ✓
- "t₁"(200,398) 与 "t₂"(320,398)：水平距离120px → 无冲突 ✓
- "t₂"(320,398) 与 "t₃"(440,398)：水平距离120px → 无冲突 ✓
- "S₁"(62,265) 与 "S₂"(62,145)：垂直距离120px → 无冲突 ✓
- "A"(335,130) 与 "S₂"(62,145)：距离√(273²+15²)≈273px → 无冲突 ✓
- "M"(335,250) 与 "S₁"(62,265)：距离√(273²+15²)≈273px → 无冲突 ✓
- "B"(455,250) 与 "t₃"(440,398)：距离√(15²+148²)≈149px → 无冲突 ✓
- "溶解度（克）"(30,210) 与 "S₁"(62,265)：距离√(32²+55²)≈64px → 无冲突 ✓
- "溶解度（克）"(30,210) 与 "S₂"(62,145)：距离√(32²+65²)≈73px → 无冲突 ✓

[交互方案]

[技术实现]
- JS 库选择：原生 SVG（简单几何图形和坐标图的首选，无需额外库）
  - 原因：本场景主要涉及坐标系、曲线、点、虚线、箭头等基础SVG元素，原生SVG完全满足需求，无需引入D3.js等重型库
  - 数学公式使用简单的HTML文本渲染（S₂/(100+S₂)×100%等），无需MathJax

- 画布尺寸：800 × 500 px（固定）

- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+------------------+
  |                                                  |                  |
  |  溶解度                                          |   信息面板       |
  |  （克）|                                        |                  |
  |        |         / A                            |   步骤X：标题    |
  |   S₂   |-------*                                |   ────────────   |
  |        |      /  |                               |                  |
  |        |     /   |                               |   内容说明       |
  |   S₁   |----*M---*B                              |   公式/结论      |
  |        |   /    |  |                             |                  |
  |        |  /     |  |                             |                  |
  |        | /      |  |                             |                  |
  |        |/       |  |                             |                  |
  |        *--------*--*-----------------------------*------------------|
  |        O   t₁   t₂  t₃                           温度（℃）          |
  |                                                  |                  |
  +--------------------------------------------------+------------------+
  |                        控件栏                     |
  |          [◀ 上一步]    步骤 X/6    [下一步 ▶]     |
  +--------------------------------------------------+
  ```

- 关键实现要点：
  1. **状态机设计**：使用全局变量 `currentStep`（0-6）管理当前步骤，每个步骤对应一个渲染函数 `renderStep(n)`
  2. **SVG元素管理**：
     - 基础元素（坐标轴、曲线、刻度）始终显示
     - A/B/M点及其虚线根据步骤条件显示/隐藏（使用CSS class控制opacity）
     - 信息面板内容通过innerHTML动态更新
  3. **曲线绘制**：使用SVG `<path>` 元素，通过cubic bezier曲线实现光滑溶解度曲线
     - 路径数据：`M 80,340 C 120,320 160,290 200,260 C 240,220 280,170 320,140 C 360,110 400,80 440,65 C 460,55 470,52 480,50`
  4. **动画效果**：
     - 脉冲动画：使用CSS `@keyframes` 实现圆点半径和阴影的周期性变化
     - 箭头动画：步骤5和步骤6中的移动箭头使用CSS transition实现淡入效果
  5. **事件绑定**：
     - 按钮点击事件绑定到 `handlePrev()` 和 `handleNext()` 函数
     - 步骤切换时调用 `renderStep(currentStep)` 重新渲染
  6. **响应式考虑**：虽然画布固定800×500，但使用viewBox确保在不同容器中正确缩放

- **ID 命名规范**：所有交互元素ID以 `scene1-` 为前缀
  - `scene1-svg`：主SVG容器
  - `scene1-axis-x`：横轴

  - `scene1-dash-b-x`：B点横向虚线

  - `scene1-dash-m-x`：M点横向虚线
