    **题目原文：**

    下列各组变化中，每一步转化在一定条件下均能一步实现的是

    ① CaCO₃ → CaO → Ca(OH)₂ → CaCO₃

    ② Fe → Fe₂O₃ → FeSO₄ → Fe

    ③ H₂O → O₂ → MgO → H₂O

    A．①②  B．①③  C．②③  D．①②③

    **题目分析：**

    本题考察初中化学中常见物质的转化关系，要求学生判断每组物质之间的转化是否都能通过一步化学反应实现。解题关键是逐一分析每个转化步骤，写出对应的化学反应方程式，判断是否可行。

    **整体讲解思路：**

    1. 先展示三组转化关系图，让学生整体感知题目结构
    2. 逐组分析：对每组中的三个转化步骤，写出反应方程式，判断是否可一步实现
    3. 第①组：全部可行（碳酸钙高温分解、氧化钙与水反应、氢氧化钙与二氧化碳反应）
    4. 第②组：Fe₂O₃→FeSO₄ 不可一步实现（氧化铁与硫酸反应生成的是硫酸铁Fe₂(SO₄)₃，不是硫酸亚铁FeSO₄）
    5. 第③组：全部可行（水电解、镁燃烧、氧化镁与酸反应）
    6. 得出结论：①③可行，选B

    **图示规划说明：**

    规划一个综合交互式图示，将三组转化关系并列展示，通过分步按钮导航逐组分析。每组分析时高亮该组，标注反应方程式和可行性判断，最后汇总得出结论。
    </TEXT_1>

    **本图示教学说明：**

    本图示通过分步导航的方式，引导学生逐组分析物质转化的可行性。

    **步骤0：整体感知**
    展示三组转化关系图，让学生先观察每组物质的转化路径，形成整体印象。

    **步骤1：分析第①组（CaCO₃循环）**
    引导学生逐一写出三个转化的反应方程式：
    1. CaCO₃ $\xrightarrow{\text{高温}}$ CaO + CO₂↑（碳酸钙高温分解，可行）
    2. CaO + H₂O → Ca(OH)₂（氧化钙与水反应，可行）
    3. Ca(OH)₂ + CO₂ → CaCO₃↓ + H₂O（氢氧化钙与二氧化碳反应，可行）
    结论：第①组全部可一步实现。

    **步骤2：分析第②组（Fe循环）**
    重点讲解 Fe₂O₃ → FeSO₄ 这一步为何不可行：
    1. Fe → Fe₂O₃（铁生锈可生成氧化铁，可行）
    2. Fe₂O₃ + 3H₂SO₄ → Fe₂(SO₄)₃ + 3H₂O（生成的是硫酸铁，不是硫酸亚铁，**不可一步实现**）
    3. FeSO₄ + Zn → ZnSO₄ + Fe（置换反应，可行）
    结论：第②组不能全部一步实现。

    **步骤3：分析第③组（H₂O循环）**
    1. 2H₂O $\xrightarrow{\text{通电}}$ 2H₂↑ + O₂↑（水电解，可行）
    2. 2Mg + O₂ $\xrightarrow{\text{点燃}}$ 2MgO（镁燃烧，可行）
    3. MgO + 2HCl → MgCl₂ + H₂O（金属氧化物与酸反应，可行）
    结论：第③组全部可一步实现。

    **步骤4：汇总结论**
    ①可行，②不可行，③可行 → 选 **B．①③**

    **课堂讲解建议：**
    - 在第②组的分析中，要特别强调 Fe₂O₃ 与酸反应生成的是三价铁盐（Fe³⁺），而非二价铁盐（Fe²⁺），这是本题的关键陷阱
    - 可引导学生思考：若要将 Fe₂O₃ 转化为 FeSO₄，需要几步？（需先将 Fe₂O₃ 还原为 Fe，再用 Fe 与稀硫酸反应）
