    **题目原文：**

    A、B是完全相同的两块木块．如图（甲）所示，将它们叠放在水平桌面上，用作用在A上的水平力F₁推它们以速度V₁=1m/s匀速直线运动，测得推力F₁=100N；若按图（乙）所示将它们靠着放在同样的水平桌面上，用作用在A上的水平力F₂推它们以速度V₂=2m/s匀速直线运动，则F₂的大小为（  ）

    A．F₂=50N
    B．F₂=100N
    C．F₂＞200N
    D．100N＜F₂＜200N

    **题目分析：**

    本题核心考查**滑动摩擦力的影响因素**以及**二力平衡**的应用。

    关键知识点：
    1. 滑动摩擦力公式：f = μN，其中μ为动摩擦因数（取决于接触面材料和粗糙程度），N为正压力
    2. 滑动摩擦力**与接触面积无关**，**与运动速度无关**
    3. 物体做匀速直线运动时，水平方向推力与摩擦力二力平衡，即 F = f

    解题思路：
    - 图甲中，A、B叠放，整体对地面的压力 N₁ = G_A + G_B = 2mg，匀速运动时 F₁ = f₁ = μ × 2mg = 100N
    - 图乙中，A、B并排，整体对地面的压力 N₂ = G_A + G_B = 2mg（总重力不变），匀速运动时 F₂ = f₂ = μ × 2mg
    - 因为μ相同、N相同，所以 f₁ = f₂，即 F₂ = F₁ = 100N
    - 速度不同（V₁=1m/s，V₂=2m/s）不影响摩擦力大小

    **图示规划说明：**

    本题设计一个核心图示场景，整合图甲和图乙的对比展示与受力分析。通过分步按钮导航，引导学生从观察两种放置方式 → 进行受力分析 → 对比得出结论，完整呈现解题逻辑。

    **本图示教学说明：**

    **步骤0——观察与理解题意：**

    引导学生观察两幅图的异同：
    - 相同点：都是A、B两块完全相同的木块，都在同样的水平桌面上，都做匀速直线运动
    - 不同点：放置方式不同（叠放 vs 并排）、速度不同（1m/s vs 2m/s）
    - 提问：放置方式变了，速度变了，推力F₂会怎么变？

    **步骤1——图甲受力分析：**

    引导学生用**整体法**分析图甲：
    1. 将A、B视为一个整体，整体做匀速直线运动，处于平衡状态
    2. 竖直方向：总重力 G = G_A + G_B = 2mg，支持力 N₁ = 2mg
    3. 水平方向：推力 F₁ 与摩擦力 f₁ 二力平衡，F₁ = f₁
    4. 由滑动摩擦力公式：f₁ = μN₁ = μ × 2mg
    5. 已知 F₁ = 100N，所以 μ × 2mg = 100N

    **步骤2——图乙受力分析：**

    引导学生用同样的整体法分析图乙：
    1. 将A、B视为一个整体，整体做匀速直线运动，处于平衡状态
    2. 竖直方向：总重力 G = G_A + G_B = 2mg（总重力不变），支持力 N₂ = 2mg
    3. 水平方向：推力 F₂ 与摩擦力 f₂ 二力平衡，F₂ = f₂
    4. 由滑动摩擦力公式：f₂ = μN₂ = μ × 2mg
    5. 注意：虽然接触面积变大了（从一块木块的底面积变为两块），但滑动摩擦力与接触面积无关

    **步骤3——对比得出结论：**

    引导学生对比两个情景：
    1. 压力相同：N₁ = N₂ = 2mg（都是两块木块的总重力）
    2. 摩擦系数相同：μ 不变（同样的木块、同样的桌面）
    3. 因此摩擦力相同：f₁ = f₂ = μ × 2mg
    4. 推力相同：F₂ = f₂ = f₁ = F₁ = 100N
    5. 速度不同（V₁=1m/s，V₂=2m/s）不影响滑动摩擦力的大小

    **步骤4——易错点提醒：**

    强调两个常见误区：
    1. **误区一**：认为接触面积变大，摩擦力变大。实际上滑动摩擦力 f = μN，与接触面积无关。
    2. **误区二**：认为速度变大，摩擦力变大。实际上滑动摩擦力与速度大小无关。

    **最终答案：B．F₂=100N**

    **课堂讲解建议：**
    - 在步骤0时，可先让学生猜测F₂的大小，激发思考
    - 在步骤1和步骤2中，强调"整体法"的思想——将A、B看作一个整体来分析
    - 在步骤3中，用高亮对比强化"压力相同→摩擦力相同"的逻辑链
    - 在步骤4中，可追问学生"如果接触面更粗糙会怎样""如果木块质量不同会怎样"，加深理解
