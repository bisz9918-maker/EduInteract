problem_160_math_g6

场景导航：Scene 1

题目原文：

如图是一座楼房的平面图，图中不同字母表示长度不同的各条边长，若b=50米，c=30米，g=10米，则这座楼房平面图的周长是（ ）
A．90米 B．150米 C．180米

题目分析：

本题考察的是利用平移法求不规则多边形周长的能力。图形是一个阶梯状的多边形，有8条边，分别用字母 a, b, c, d, e, f, g, h 标注。

已知条件：b=50米，c=30米，g=10米。

核心思路：

  • 将所有水平方向的边平移对齐，可得 h + f + d = b
  • 将所有垂直方向的边平移对齐，可得 a + e = c + g
  • 周长 = a + h + g + f + e + d + c + b = (a+e) + (h+f+d) + g + c + b = (c+g) + b + g + c + b = 2(b + c + g) = 2×(50+30+10) = 180米

图示规划说明：

本题设计一个交互式图示，通过分步动画展示平移法求周长的完整过程。从展示原图开始，逐步引导学生观察水平边和垂直边的平移关系，最终得出周长公式。

教学说明：

本图示通过分步动画展示平移法求周长的完整过程，教师可按以下步骤引导学生：

步骤0：观察图形

  • 引导学生数出图形共有8条边，分别用 a, b, c, d, e, f, g, h 标注
  • 强调题目给出的已知条件：b=50米, c=30米, g=10米
  • 提问：直接求周长需要知道所有8条边的长度，但我们只知道3条，怎么办？

步骤1：水平边的平移关系

  • 引导学生观察水平方向的边：顶部有 h, f, d 三条，底部有 b 一条
  • 通过蓝色虚线平移动画，将 h, f, d 向下平移到与 b 同一水平线
  • 关键结论：h + f + d = b = 50米
  • 强调：无论阶梯如何变化，所有水平线段之和等于底边长度

步骤2：垂直边的平移关系

  • 引导学生观察垂直方向的边：左侧有 a，中间有 g（向下）和 e（向上），右侧有 c
  • 通过红色虚线平移动画，将 a 和 e 向右平移
  • 关键结论：a + e = c + g = 30 + 10 = 40米
  • 强调：向上走的总长度等于向下走的总长度

步骤3：周长计算

  • 综合以上关系：
  1. 周长 = a + h + g + f + e + d + c + b
  2. 重新分组 = (a + e) + (h + f + d) + g + c + b
  3. 代入关系 = (c + g) + b + g + c + b
  4. 化简 = 2(b + c + g)
  5. 代入数值 = 2 × (50 + 30 + 10) = 2 × 90 = 180米
  • 答案：C. 180米

课堂讲解建议：

  • 平移法是解决此类问题的核心技巧，可类比"将阶梯拉直"的直观理解
  • 可进一步提问：如果 g 的长度改变，周长会如何变化？引导学生发现周长只与 b, c, g 有关
  • 可拓展：类似方法可用于更复杂的阶梯图形，关键是分别处理水平和垂直方向
