[图示主题与整合说明]
- 本图示主题：三视图与立体图形的对应关系验证
- 整合的步骤/概念：通过分步投影验证，将图1的三视图（正面、侧面、上面）与选项①的立体结构逐一匹配，并排除选项②③，最终得出结论。
- 教学价值：教师可引导学生从“观察已知视图→假设验证→对比排除→得出结论”的逻辑链条进行空间想象训练，强化三视图与立体图形的映射关系。

[分步序列]
- 初始状态（步骤0）：
  - 显示左侧三个视图及标签。
  - 显示右侧选项①及标签，②③隐藏。
  - 按钮显示"观察①"。
- 步骤1（点击"观察①"）：
  - 选项①高亮（边框#1565c0）。
  - 生成蓝色虚线从①指向正面视图。
  - 正面视图高亮（边框#1565c0）。
  - 正面视图右侧出现绿勾。
  - 按钮变为"下一步"。
- 步骤2（点击"下一步"）：
  - 清除正面投影线及高亮。
  - 生成蓝色虚线从①指向侧面视图。
  - 侧面视图高亮，右侧出现绿勾。
  - 按钮保持"下一步"。
- 步骤3（点击"下一步"）：
  - 清除侧面投影线及高亮。
  - 生成蓝色虚线从①指向上面视图。
  - 上面视图高亮，右侧出现绿勾。
  - 按钮变为"对比②③"。
- 步骤4（点击"对比②③"）：
  - 清除上面投影线及高亮。
  - 显示选项②和③。
  - ②和③上方/右侧出现红叉，并显示简化的正面投影（矩形无中线或形状不符）。
  - 按钮变为"结论"。
- 步骤5（点击"结论"）：
  - 隐藏②③及红叉。
  - 选项①显示绿色粗边框(#2e7d32)。
  - 画布中央显示文字"正确答案：①"。
  - 按钮变为"重置"。

[标签冲突检查]
- "正面"(100,215) 与 "侧面"(220,215)：间距120px → 无冲突。
- "上面"(160,335) 与 视图底部(310)：间距25px → 无冲突。
- 标签①(460,340) 与 标签②(610,335)：间距150px → 无冲突。
- 验证标记(视图右侧x≈140/260) 与 相邻视图：间距≥20px → 无冲突。
- 按钮区(y=445) 与 最下方标签(y≈340)：间距105px → 无冲突。
- 所有标签与图形边缘间距≥10px，满足防重叠要求。

[交互方案]
- 交互类型：分步按钮导航
- 控件说明：
  - 底部4个按钮位，实际通过JS动态切换文本和点击事件，保持UI简洁。
  - 按钮位置：x=150, 300, 450, 600，y=445，宽100，高36。
- 教师操作流程：
  1. 展示初始视图，提问学生猜测。
  2. 点击"观察①"，逐步验证三个视图，引导学生理解投影原理。
  3. 点击"对比②③"，展示错误选项的排除理由。
  4. 点击"结论"，确认答案，强化记忆。
  5. 可随时点击"重置"回到初始状态重新讲解。

[技术实现]
- JS 库选择：原生 SVG + Vanilla JS。无需外部库，轻量且易于控制动画和状态。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图：
  ```
  +--------------------------------------------------+
  |  已知视图              选项                      |
  |  [正面] [侧面]      ①   ②   ③                  |
  |    上    上          ▲   ▲   ▲                  |
  |  [上面]              │   │   │                  |
  |                      │   │   │                  |
  |                      ▼   ▼   ▼                  |
  |  [观察①] [下一步] [对比②③] [结论]              |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  - 状态机：`let currentStep = 0;` 控制显示/隐藏/高亮逻辑。
  - 投影线动画：使用 `stroke-dasharray` 和 CSS `transition` 实现绘制效果。
  - 元素显隐：通过 `opacity` 和 `visibility` 控制，避免DOM重排。
  - 坐标计算：投影线起点为立体图中心，终点为对应视图中心，使用SVG `<line>` 动态生成。
  - 标记图标：预定义SVG `<path>` 绿勾和红叉，通过 `transform` 定位。
- ID 命名规范：所有元素ID以 `scene1-` 开头，如 `scene1-front-view`, `scene1-obj1`, `scene1-btn-next`。
- IIFE 隔离：`(function() { 'use strict'; ... })();` 包裹所有逻辑，防止全局污染。
- 事件绑定：按钮点击触发 `handleStep()`，根据 `currentStep` 执行对应视觉更新。
