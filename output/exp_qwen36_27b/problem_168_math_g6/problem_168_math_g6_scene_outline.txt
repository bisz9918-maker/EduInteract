    **题目原文：**

    图中的两个小圆的周长的和与大圆的周长比较，（  ）
    A．一样长
    B．大圆的周长长
    C．大圆的周长短
    D．无法比较

    **题目分析：**

    本题考察圆周长公式 $C = \pi d$ 的应用以及直径之间的线性关系。图中一个大圆内有两个小圆，两个小圆的直径共线且恰好铺满大圆的一条直径，即两个小圆直径之和等于大圆直径。由周长公式可知，两个小圆周长之和 $\pi d_1 + \pi d_2 = \pi(d_1 + d_2) = \pi D$，恰好等于大圆周长。答案为 **A．一样长**。

    **整体讲解思路：**

    1. 引导学生观察图形，发现两个小圆的直径都在大圆的同一条直径上，且首尾相接
    2. 标注直径，建立 $d_1 + d_2 = D$ 的关系
    3. 代入周长公式推导，得出结论
    4. 通过拖拽交互验证：改变两个小圆大小（保持直径和不变），周长和始终等于大圆周长

    **图示规划：**

    本题核心知识点单一（圆周长与直径的线性关系），规划为 **1 个交互式图示**，整合"图形观察→直径关系→公式推导→动态验证"完整认知链条。

    **教学说明：**

    本图示覆盖从观察图形到得出结论的完整教学过程，教师可按以下步骤引导学生：

    **步骤0：观察图形**
    - 请学生描述图中有哪些圆，它们的位置关系如何
    - 引导学生注意：两个小圆的直径都在大圆的同一条直径上，且首尾相接

    **步骤1：标注直径，建立关系**
    - 点击「下一步」后，直径标注出现
    - 提问：$d_1$、$d_2$、$D$ 之间有什么关系？
    - 引导学生得出：$d_1 + d_2 = D$

    **步骤2：公式推导**
    - 点击「下一步」后，公式推导逐步显示
    - 强调关键步骤：$\pi d_1 + \pi d_2 = \pi(d_1 + d_2)$（提取公因式 $\pi$）
    - 代入 $d_1 + d_2 = D$，得到 $C_1 + C_2 = \pi D = C$
    - 结论：两个小圆的周长之和 **等于** 大圆的周长

    **步骤3：拖拽验证**
    - 点击「下一步」进入拖拽模式
    - 教师拖动切点，改变两个小圆的相对大小
    - 引导学生观察：无论怎么拖动，$d_1 + d_2$ 始终不变，周长和也始终不变
    - 可尝试极端情况：将一个小圆拖到极小，另一个接近大圆大小，结论依然成立
    - 这一环节帮助学生从"特例"上升到"一般规律"的理解

    **核心公式：**
    1. 圆周长公式：$C = \pi d = 2\pi r$
    2. 直径关系：$d_1 + d_2 = D$
    3. 周长关系：$C_1 + C_2 = \pi d_1 + \pi d_2 = \pi(d_1 + d_2) = \pi D = C$

    **课堂讲解建议：**
    - 本题易错点在于学生可能凭直觉认为"大圆更大所以周长更长"，拖拽验证环节能有效打破这种直觉误区
    - 可进一步拓展提问：如果有三个小圆呢？$n$ 个小圆呢？引导学生发现更一般的规律——只要小圆直径之和等于大圆直径，周长之和就相等
    - 本题本质揭示了圆周长的线性性质：周长与直径成正比，因此直径可加性直接导致周长可加性
