[图示主题与整合说明]
- 本图示主题：方向与距离定位——从雷达站确定巡洋舰的位置
- 整合的步骤/概念：方向坐标系的展示、北偏东40°角度的标注、比例尺的使用与距离测量
- 教学价值：教师通过分步导航，先引导学生理解"北偏东40°"的方向含义，再引导学生通过比例尺测量距离，最终得出完整定位结论"北偏东40°方向100km"，对应选项C。分步呈现避免信息过载，帮助学生逐步建立方向与距离的空间认知。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - "上一步"按钮：位于控件区左侧 (250,455)→(350,480)，点击回退到上一步，步骤0时禁用
  - "下一步"按钮：位于控件区右侧 (450,455)→(550,480)，点击进入下一步，步骤3时禁用
  - 步骤指示器：位于控件区中央 (400,467)，显示"当前步 / 总步数"（如"1 / 3"）
- 教师操作流程：
  1. 图示加载后显示步骤0（基础图形），教师引导学生观察整体布局
  2. 点击「下一步」进入步骤1，蓝色高亮方向相关元素，教师讲解"北偏东40°"的含义
  3. 点击「下一步」进入步骤2，绿色标注距离分段，教师讲解比例尺测量方法
  4. 点击「下一步」进入步骤3，显示完整结论，教师总结并对应选项C
  5. 可随时点击「上一步」回退到任意步骤进行复习

[技术实现]
- JS 库选择：原生 SVG（本场景为简单几何图形，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────┐
  │                    北                                │
  │                     ↑                                │
  │                     │                                │
  │                     │  40°  ● 巡洋舰                  │
  │                     │ /                              │
  │                     |/                               │
  │  西 ←───────────────●───────────────→ 东             │
  │                     │  雷达站                         │
  │                     │                                │
  │                     │                                │
  │                     │                                │
  │                     ↓                                │
  │                    南              ─── 50 km         │
  │                                                  │
  │  ┌──────────────────────────────────────────┐    │
  │  │         步骤提示文字区域                  │    │
  │  └──────────────────────────────────────────┘    │
  │  ┌──────────┐        ┌──────────┐                │
  │  │ ◀ 上一步  │  1/3   │  下一步 ▶ │                │
  │  └──────────┘        └──────────┘                │
  └─────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 `currentStep`（0~3）管理当前步骤，每个步骤对应一组 SVG 元素的显示/隐藏/样式切换
  2. 步骤切换函数 `goToStep(step)`：根据目标步骤更新所有相关元素的 class 和属性
  3. 高亮实现：通过 CSS class 切换（如 `.highlight-blue`、`.highlight-green`）控制元素颜色和线宽
  4. 动画：使用 CSS transition（0.3s ease）实现颜色变化和元素淡入效果
  5. 按钮事件绑定：`scene1-prev-btn` 和 `scene1-next-btn` 分别绑定点击事件，调用 `goToStep(currentStep - 1)` 和 `goToStep(currentStep + 1)`
  6. 按钮禁用逻辑：步骤0时禁用"上一步"，步骤3时禁用"下一步"，通过添加 `.disabled` class 实现
  7. 40°弧线绘制：使用 SVG `<path>` 的 `A`（椭圆弧）命令，从(400,205)到(422.5,213.2)，半径35，大弧标志0，顺时针标志1
  8. 箭头实现：使用 SVG `<marker>` 定义箭头，在轴线末端引用
- ID 命名规范：所有交互元素 ID 以 `scene1-` 为前缀
  - `scene1-svg`：主 SVG 容器
  - `scene1-north-axis`：北轴线
  - `scene1-south-axis`：南轴线
  - `scene1-west-axis`：西轴线
  - `scene1-east-axis`：东轴线
  - `scene1-radar`：雷达站圆点
  - `scene1-cruiser`：巡洋舰圆点
  - `scene1-angle-arc`：40°弧线
  - `scene1-connection-line`：雷达站-巡洋舰连线
  - `scene1-scale-line`：比例尺线段
  - `scene1-step-hint`：步骤提示文字
  - `scene1-step-indicator`：步骤指示器
  - `scene1-prev-btn`：上一步按钮
  - `scene1-next-btn`：下一步按钮
  - `scene1-midpoint`：连线等分点
  - `scene1-seg-mark1`：第一段标记线
  - `scene1-seg-mark2`：第二段标记线
  - `scene1-seg-label1`：第一段距离标签
  - `scene1-seg-label2`：第二段距离标签
  - `scene1-conclusion-box`：结论框
- IIFE 隔离：所有 JS 代码包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染
