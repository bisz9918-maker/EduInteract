[图示主题与整合说明]
- 本图示主题：交互式串联电路图——滑片移动对电路各物理量的动态影响
- 整合的步骤/概念：完整串联电路拓扑展示 + 滑动变阻器实时拖拽交互 + 电表示数动态计算 + 灯泡亮度视觉反馈 + 电压守恒验证
- 教学价值：教师可通过拖拽滑片直观演示“电阻变化→电流变化→分压变化”的因果链，帮助学生理解欧姆定律与串联分压原理，特别是发现 V1+V2=U 的不变量规律，突破动态电路分析难点。

[分步序列]
- 初始状态（步骤0）：
  - 滑片位于变阻器中点（x=500），R_变 = 10Ω
  - 开关 S 闭合
  - 计算：I = 6/(10+10) = 0.3A，U_灯 = 3.0V，U_变 = 3.0V
  - 灯泡中等亮度（透明度 0.65）
  - 所有电表显示初始值，面板显示 "V1 + V2 = 6.0V（恒定）"
- 交互过程（连续拖拽）：
  - 教师/学生按住滑片左右拖动
  - 滑片右移（x:500→560）：R_变 10→20Ω → I 0.3→0.2A → U_灯 3.0→2.0V ↓ → U_变 3.0→4.0V ↑ → 灯泡变暗
  - 滑片左移（x:500→440）：R_变 10→0Ω → I 0.3→0.6A → U_灯 3.0→6.0V ↑ → U_变 3.0→0.0V ↓ → 灯泡变亮
  - 数值实时刷新，灯泡亮度平滑过渡，V1+V2 始终显示 6.0V
- 最终状态：无固定终点，保持拖拽结束时的状态，便于教师定格讲解

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：
  - 滑片箭头（#c62828）：位于变阻器上方，可水平拖拽范围 x=440~560
  - 底部数据面板：只读显示区，实时更新 I、U_灯、U_变、V1+V2
- 教师操作流程：
  1. 初始状态展示电路结构与基础读数
  2. 拖拽滑片向右，引导学生观察：电流表↓、V1↓、V2↑、灯泡变暗
  3. 拖拽滑片向左，观察反向变化
  4. 强调面板中 V1+V2 始终等于电源电压 6V，总结串联电路电压规律
  5. 可配合提问：“滑片移到最右端时，灯泡两端电压是多少？”

[技术实现]
- JS 库选择：原生 SVG + Vanilla JS（无需外部库，轻量高效，适合电路拓扑与实时交互）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [y=50]  V1(500,50)
  [y=120] S(300,120) --------- Bulb(500,120)
           |                       |
  [y=250] Power(180,250)         V2(680,380)
           |                       |
  [y=380] Ammeter(300,380) -- Rheostat(500,380) <-- Slider
  [y=440] ================================================
           [ 数据面板: I=?.?A | U_灯=?.?V | U_变=?.?V | Sum=6.0V ]
  ```
- 关键实现要点：
  - 状态机：无需复杂状态机，采用事件驱动实时更新（dragstart/drag/dragend）
  - 坐标计算：滑片 x 坐标映射到电阻值 R_变 = (x - 440) / 120 * 20
  - 物理计算：I = 6 / (10 + R_变)，U_灯 = I * 10，U_变 = I * R_变
  - 动画曲线：灯泡透明度使用线性插值 map(I, 0.2, 0.6, 0.3, 1.0)，数值更新无延迟
  - 事件绑定：滑片绑定 mousedown/mousemove/mouseup 及 touch 事件，限制拖拽范围
  - ID 命名规范：所有元素 ID 以 `scene1-` 开头（如 `scene1-slider`, `scene1-bulb`, `scene1-panel-i`）
  - IIFE 隔离：全部 JS 逻辑包裹在 `(function() { ... })();` 中，避免全局污染
  - 防抖/节流：数值更新频率限制为 60fps，避免过度重绘
