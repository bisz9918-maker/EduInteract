- 本图示主题：突触结构识别与兴奋传递路径分析（含电流计偏转演示）

[分步序列]
- 初始状态（步骤0）：显示完整的突触结构图（神经元A、B、C，轴突，胞体，突触小泡），标注点a、b、c、d，显示灵敏电流计及连接导线。无高亮，无动画。底部提示："观察突触结构，识别神经元与突触数量"。
- 步骤1（结构识别）：神经元A轮廓变为蓝色(#1565c0)，神经元B轮廓变为绿色(#2e7d32)，神经元C轮廓变为红色(#c62828)。两个突触位置出现灰色虚线框。底部提示："3个神经元，2个突触（①错误）"。
- 步骤2（刺激b点）：
    - 在b点显示橙色闪电⚡。
    - 动画1：蓝色箭头从b向左沿轴突移动到a（表示兴奋传到a）。
    - 动画2：蓝色箭头从b向右沿轴突移动到B末梢，突触间隙出现移动的小黑点（递质），蓝色箭头从C胞体向右沿轴突移动到d（表示兴奋传到d）。
    - 电流计指针：先向左偏转（a点兴奋），回正，再向右偏转（d点兴奋），共2次。
    - 底部提示："刺激b：兴奋双向传导，电流计偏转2次"。
- 步骤3（刺激c点）：
    - 在c点显示橙色闪电⚡。
    - 动画1：蓝色箭头从c向右沿轴突移动到d（表示兴奋传到d）。
    - 动画2：在B→C突触处显示红色"×"，表示兴奋不能从C逆向传到B。
    - 电流计指针：只向右偏转1次（d点兴奋，a点无兴奋）。
    - 底部提示："刺激c：兴奋单向传递，电流计偏转1次"。
- 步骤4（总结对比）：
    - 左侧显示刺激b的传递路径（b→a，b→d），标注"偏转2次"。
    - 右侧显示刺激c的传递路径（c→d，c→B阻断），标注"偏转1次"。
    - 底部提示："②错误：刺激b偏转2次，刺激c偏转1次"。

[技术实现]
- JS 库选择：原生 SVG + Vanilla JS（无需外部库，轻量高效）。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  [灵敏电流计 (400,40)]
  |          |
  |          |
  a----------b----------c----------d
  |    B     |    C     |
  |          |          |
  A(左下)    突触B→C    轴突
  [底部提示文字 (400,420)]
  [◀ 上一步] [下一步 ▶] (400,465)
  ```
- 关键实现要点：
    - 状态机：使用变量 `currentStep` (0-4) 管理当前步骤。
    - 动画：使用 CSS `@keyframes` 或 JS `requestAnimationFrame` 实现箭头移动、递质扩散、指针偏转。
    - 指针偏转：SVG `<line>` 元素，通过 `transform="rotate(angle, 400, 40)"` 控制角度。
    - 高亮：切换 SVG 元素的 `stroke` 属性颜色。
    - 事件绑定：按钮点击事件更新 `currentStep` 并调用 `renderStep()`。
- ID 命名规范：所有交互元素 ID 以 `scene1-` 为前缀（如 `scene1-btn-next`, `scene1-neuron-b`, `scene1-meter-needle`）。
- IIFE 隔离：所有 JS 代码包裹在 `(function() { ... })();` 中，避免全局污染。
