[分步序列]

初始状态（步骤0）：展示完整的突触结构图
- 显示神经元A（轴突+末梢+突触小泡）、神经元B（细胞体+轴突+末梢+突触小泡）、神经元C（细胞体+轴突）
- 显示电流计（表盘+指针垂直向上+连接导线a-d）
- 显示标注点a、b、c、d及对应标签

- 底部提示文字："观察突触结构，点击「下一步」开始分析"
- 所有元素静态显示，无动画

步骤1：B单独受刺激 → C兴奋
- 触发：点击「下一步」
- 视觉变化：
  1. 在B细胞体上方(310,165)显示橙色⚡电刺激符号（闪烁动画，持续1秒）
  2. B的轴突末梢(420,220)-(460,280)释放蓝色小圆点（兴奋性递质），动画：从B末梢向C细胞体移动（沿(440,250)→(500,250)路径，持续1.5秒）
  3. 蓝色递质到达C细胞体后，C细胞体周围出现蓝色光晕效果（径向渐变，半径40px，透明度从0到30%渐变，持续0.5秒）
  4. C的轴突上出现蓝色箭头(620,280)→(760,280)，表示兴奋信号传出（持续1秒）
  5. 电流计指针偏转：从垂直向上偏转到右侧约30°（模拟电位变化，持续0.5秒）
  6. 底部提示文字变为："B单独刺激 → C兴奋（B释放兴奋性递质）"
- 新增元素坐标：
  - ⚡符号：(310,165)，大小20×20
  - 蓝色递质圆点×6：从(440,250)沿路径到(500,250)
  - 蓝色光晕：中心(560,260)，半径40px
  - 蓝色箭头：(620,280)→(760,280)

步骤2：A、B同时受刺激 → C不兴奋
- 触发：点击「下一步」
- 视觉变化：
  1. 在A末梢(250,350)和B细胞体(310,165)同时显示橙色⚡电刺激符号（闪烁动画）
  2. A的轴突末梢释放红色小圆点（抑制性递质），动画：从A末梢(260,350)向B细胞体(300,280)移动（持续1秒）
  3. 红色递质到达B细胞体后，B细胞体显示灰色淡化效果（#888888，透明度50%，覆盖细胞体区域，持续0.5秒）
  4. B试图释放兴奋性递质到C，但递质数量明显减少（仅2个蓝色小圆点，且移动缓慢），C细胞体不发光
  5. 电流计指针：先偏转后回到接近垂直位置（模拟电位变化被抑制，持续1秒）
  6. 底部提示文字变为："A、B同时刺激 → A释放抑制性递质 → B被抑制 → C不兴奋"
- 新增元素坐标：
  - ⚡符号×2：(250,350)和(310,165)
  - 红色递质圆点×5：从(260,350)沿路径到(300,280)
  - 灰色淡化层：覆盖(300,200)-(420,340)
  - 蓝色递质圆点×2（减少）：从(440,250)沿路径到(490,250)（未完全到达C）

步骤3：结论
- 触发：点击「下一步」
- 视觉变化：
  1. 清除步骤2的动画元素（⚡符号、递质圆点、光晕、淡化效果）
  2. 在因果链区域(100,390)-(700,410)显示因果链：

     - 箭头→：(160,400)-(200,400)

     - 文本"B被抑制"：(390,400)
     - 箭头→：(460,400)-(500,400)
     - 文本"C不兴奋"：(510,400)
  3. 底部提示文字变为绿色加粗："③正确：A释放的是抑制性递质"
  4. 因果链文本和箭头依次出现（每个元素延迟0.3秒，持续0.5秒淡入）

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位置(310,450)，大小(80×30)，点击返回上一步骤，步骤0时禁用
  - 「下一步 ▶」按钮：位置(410,450)，大小(80×30)，点击进入下一步骤，步骤3时禁用
  - 步骤指示器：位置(400,445)，文本"步骤 X/3"，居中显示
- 教师操作流程：
  1. 初始状态展示完整突触结构，教师可先讲解神经元A、B、C的结构和电流计的连接方式
  2. 点击「下一步」进入步骤1，教师讲解B单独受刺激时兴奋性递质的传递过程和C的兴奋反应
  3. 点击「下一步」进入步骤2，教师对比讲解A、B同时受刺激时抑制性递质的作用，B被抑制导致C不兴奋
  4. 点击「下一步」进入步骤3，教师总结因果链，强调③的正确性
  5. 可随时点击「上一步」回退到任意步骤进行复习

[技术实现]
- JS 库选择：原生 SVG（简单几何图形和动画，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  ┌─────────────────────────────────────────────────────────────┐
  │                                                             │
  │                    ┌───电流计───┐                           │
  │                    │  (400,70)  │                           │
  │                    └─────┬──────┘                           │
  │                          │                                  │
  │  a(120)                  │                  d(680)          │
  │  ●───────────────────────┼──────────────────────●           │
  │  │  B轴突    B细胞体     │     C细胞体    C轴突             │
  │  │  ────────(360,270)    │    (560,260)  ────────           │
  │  │          B            │        C                        │
  │  │                       │                                 │
  │  A末梢                   │                                 │
  │  (250,350)               │                                 │
  │   A                      │                                 │
  │  (200,420)               │                                 │
  │                          │                                 │
  │  [步骤提示文字区域 (400,420)]                               │
  │  [因果链区域 (100,390)-(700,410) - 步骤3显示]              │
  │                                                             │
  │  [◀ 上一步]  [步骤 X/3]  [下一步 ▶]  (y=450~480)           │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：4个状态（步骤0~3），用全局变量 `currentStep` 跟踪当前步骤
  2. 神经元绘制：使用 SVG `<path>` 绘制不规则细胞体轮廓，`<line>` 绘制轴突
  3. 递质动画：使用 `<animate>` 或 JS `requestAnimationFrame` 实现小圆点沿路径移动
  4. 光晕效果：使用 SVG `<radialGradient>` 实现蓝色径向渐变，通过 JS 控制 opacity
  5. 淡化效果：在B细胞体上方叠加 `<rect>` 填充灰色，通过 JS 控制 opacity
  6. 电流计指针：使用 `<line>` 绘制指针，通过 JS 旋转 transform 实现偏转
  7. 电刺激符号：使用 SVG `<text>` 显示"⚡"，配合 `<animate>` 实现闪烁
  8. 因果链动画：步骤3中各元素依次淡入，使用 CSS `opacity` 过渡或 JS 延迟添加
  9. 按钮状态管理：步骤0时「上一步」禁用，步骤3时「下一步」禁用
  10. 元素清理：切换步骤时清除上一步的动画元素（递质圆点、光晕、淡化层等）
- ID 命名规范：所有交互元素 ID 以 `scene2-` 为前缀
  - 神经元：`scene2-neuron-a`、`scene2-neuron-b`、`scene2-neuron-c`
  - 电流计：`scene2-gauge`、`scene2-gauge-needle`
  - 标注点：`scene2-point-a`、`scene2-point-b`、`scene2-point-c`、`scene2-point-d`
  - 标签：`scene2-label-a`、`scene2-label-b`、`scene2-label-c`、`scene2-label-d`、`scene2-label-neuron-a`、`scene2-label-neuron-b`、`scene2-label-neuron-c`
  - 动画元素：`scene2-stimulus-b`、`scene2-stimulus-a`、`scene2-neurotransmitter-excitatory`、`scene2-neurotransmitter-inhibitory`、`scene2-glow-c`、`scene2-inhibit-b`、`scene2-chain-text-*`、`scene2-chain-arrow-*`
  - 控件：`scene2-btn-prev`、`scene2-btn-next`、`scene2-step-indicator`、`scene2-hint-text`
- IIFE 隔离：所有 JS 代码包在 `(function() { ... })()` 中，避免全局污染
