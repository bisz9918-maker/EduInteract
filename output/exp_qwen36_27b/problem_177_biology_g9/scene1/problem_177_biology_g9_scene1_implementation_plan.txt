[图示主题与整合说明]
- 本图示主题：染色体、DNA、基因三者的结构层次与包含关系
- 整合的步骤/概念：图甲各标号的结构识别（染色体→DNA→蛋白质→基因）+ 图乙同心圆的包含关系对应 + 选项A的关键辨析点（蛋白质不含遗传信息）
- 教学价值：教师通过分步导航，从宏观的染色体结构逐步深入到微观的基因片段，同步展示概念间的包含关系（图乙同心圆），最终聚焦选项A的错误辨析，帮助学生理解"蛋白质不含遗传信息"这一关键知识点

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位置(250, 455)，尺寸(100×30)，步骤0时禁用
  - 「步骤 X/6」文字：位置(390, 460)，尺寸(100×20)，居中显示当前步骤
  - 「下一步 ▶」按钮：位置(530, 455)，尺寸(100×30)，步骤6时禁用
- 教师操作流程：
  1. 初始展示线稿，引导学生观察整体结构
  2. 点击「下一步」逐步揭示各结构名称（染色体→DNA→蛋白质→基因）
  3. 步骤5展示包含关系，帮助学生理解概念层次
  4. 步骤6聚焦选项A辨析，突出蛋白质不含遗传信息的关键点
  5. 可随时点击「上一步」回退复习任意步骤

[技术实现]
- JS 库选择：原生 SVG（简单几何图形绘制，无需额外库，轻量高效）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  +---------------------------------------------------+
  |  [图甲区域 x:20-460]       [图乙区域 x:480-800]   |
  |                                                   |
  |    X形染色体[1]                                    |
  |     (130,100)          同心圆①②③                  |
  |        |                (640,200)                  |
  |     解螺旋线                                         |
  |        |                ①                         |
  |     蛋白质[3]              ②                       |
  |     (130,265)              ③                       |
  |        |                                          |
  |  DNA[2]→基因[4]                                    |
  |  (185,100)-(380,100)                               |
  |                                                   |
  |   甲                        乙                     |
  |                                                   |
  |  ┌───────────────────────────────────────────┐   |
  |  |  ◀上一步    步骤 X/6    下一步▶           |   |
  |  └───────────────────────────────────────────┘   |
  +---------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：6个步骤（0-6），每个步骤定义各元素的可见性、颜色、描边宽度、填充透明度
  2. 状态数据表：用JS对象数组存储每个步骤的视觉状态，切换时遍历更新
  3. 动画曲线：步骤切换使用CSS transition（0.3s ease），高亮变化平滑过渡
  4. 事件绑定：按钮点击触发步骤切换函数，更新SVG元素属性
  5. 箭头绘制：步骤5使用SVG `<line>` + `<marker>` 绘制虚线箭头
  6. DNA双螺旋：用SVG `<path>` 绘制正弦波浪路径模拟双螺旋
  7. X形染色体：用SVG `<path>` 绘制交叉两臂
  8. 解螺旋线：用SVG `<path>` 绘制螺旋/波浪路径
- ID 命名规范：所有交互元素ID以 `scene1-` 为前缀
  - 按钮：`scene1-prev-btn`、`scene1-next-btn`
  - 步骤指示：`scene1-step-label`
  - 染色体：`scene1-chromosome`
  - DNA：`scene1-dna`
  - 蛋白质：`scene1-protein`
  - 基因：`scene1-gene`
  - 解螺旋线：`scene1-unwinding`
  - 同心圆：`scene1-circle1`、`scene1-circle2`、`scene1-circle3`
  - 标签：`scene1-label1`、`scene1-label2`、`scene1-label3`、`scene1-label4`
  - 说明文字：`scene1-note-protein`、`scene1-note-gene`、`scene1-note-conclusion`
  - 箭头：`scene1-arrow1`、`scene1-arrow2`、`scene1-arrow3`
- IIFE 隔离：所有JS代码包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染
