    **题目原文：**

    南瓜的花色由一对等位基因控制。相关杂交实验及结果如右图所示。下列说法中错误的是

    A．F₁的表现型及其比例可验证基因的分离定律
    B．由过程③可知白色是显性性状
    C．F₂中黄花与白花的比例是5∶3
    D．F₁与F₂中白花个体的基因型相同

    **题目分析：**

    本题是一道经典的遗传学选择题，考查学生对孟德尔分离定律的理解和应用能力。题目给出了南瓜花色遗传的杂交实验图解，要求学生根据图解判断四个选项的正误。

    **核心知识点：**
    - 显隐性性状的判断方法（自交出现性状分离）
    - 基因型的推导
    - 分离定律的验证（测交比例）
    - 后代比例的计算

    **解题思路：**
    1. 首先从过程③入手：F₁白花自交产生黄花和白花，说明白花为显性性状（杂合子自交出现性状分离）
    2. 设白花基因为A（显性），黄花基因为a（隐性）
    3. 推导各代基因型：
       - P：黄花(aa) × 白花(Aa)
       - F₁：黄花(aa)、白花(Aa)
       - 过程②：F₁黄花(aa)自交 → F₂全部黄花(aa)
       - 过程③：F₁白花(Aa)自交 → F₂：AA:Aa:aa = 1:2:1，即白花:黄花 = 3:1
    4. 计算F₂总体比例：黄花:白花 = 5:3
    5. 分析各选项，找出错误项

    **图示规划说明：**

    本题设计一个交互式遗传图解场景，通过分步按钮导航，逐步展示：
    - 原始杂交图解（表现型）
    - 显隐性判断依据
    - 各代基因型推导
    - F₂比例计算
    - 选项分析

    这种递进式设计帮助学生从直观到抽象，逐步理解遗传规律。

    **教学说明：**

    本图示通过分步交互，帮助学生逐步理解南瓜花色遗传的完整推导过程。

    **引导观察要点：**

    1. **步骤0→1：显隐性判断**
       - 引导学生观察过程③：F₁白花自交后，F₂中出现了黄花和白花
       - 提问："为什么白花自交会出现黄花？"
       - 结论：白花为杂合子，白色为显性性状

    2. **步骤2：基因型推导**
       - 根据显隐性关系，设白花基因为A，黄花基因为a
       - P代黄花为隐性纯合子aa
       - P代白花与黄花杂交产生1:1的F₁，说明P代白花为杂合子Aa
       - F₁中黄花为aa，白花为Aa

    3. **步骤3：F₂代分离比**
       - 过程②：aa自交→全部aa（黄花），无性状分离
       - 过程③：Aa自交→AA:Aa:aa = 1:2:1，即白花:黄花 = 3:1

    4. **步骤4：总体比例计算**
       - F₁中黄花和白花各占1/2
       - F₂黄花比例 = 1/2 × 1 + 1/2 × 1/4 = 5/8
       - F₂白花比例 = 1/2 × 0 + 1/2 × 3/4 = 3/8
       - 黄花:白花 = 5:3

    5. **步骤5：选项分析**
       - A正确：F₁中黄花:白花 = 1:1，符合测交比例，可验证分离定律
       - B正确：过程③中白花自交出现性状分离，证明白色为显性
       - C正确：F₂中黄花:白花 = 5:3
       - D错误：F₁白花基因型为Aa，F₂白花基因型为AA或Aa，两者不相同

    **课堂讲解建议：**

    - 在步骤1时，可暂停让学生思考显隐性判断的依据
    - 在步骤4时，可让学生自行计算比例，再与图示对比
    - 在步骤5时，重点讲解D选项的错误原因，强调基因型与表现型的区别
    - 可补充提问："如果P代白花是纯合子AA，结果会怎样？"引导学生理解测交的意义

    **完整解答：**

    本题正确答案为 **D**。

    **详细解析：**

    1. **显隐性判断**：由过程③可知，F₁白花自交产生黄花和白花，出现性状分离，说明白花为显性性状，黄花为隐性性状。

    2. **基因型推导**：
       - 设白花基因为A（显性），黄花基因为a（隐性）
       - P：黄花(aa) × 白花(Aa)
       - F₁：黄花(aa)、白花(Aa)，比例为1:1
       - 过程②：F₁黄花(aa)自交 → F₂全部为黄花(aa)
       - 过程③：F₁白花(Aa)自交 → F₂：AA(白花):Aa(白花):aa(黄花) = 1:2:1

    3. **F₂比例计算**：
       - 假设F₁中黄花和白花各占1/2
       - F₂中黄花 = 1/2 × 1 + 1/2 × 1/4 = 5/8
       - F₂中白花 = 1/2 × 0 + 1/2 × 3/4 = 3/8
       - 黄花:白花 = 5:3

    4. **选项分析**：
       - A正确：F₁中黄花:白花 = 1:1，符合测交比例，可验证基因的分离定律
       - B正确：过程③中白花自交出现性状分离，说明白色为显性性状
       - C正确：F₂中黄花与白花的比例为5:3
       - D错误：F₁中白花个体的基因型为Aa，而F₂中白花个体的基因型为AA或Aa，两者不相同
