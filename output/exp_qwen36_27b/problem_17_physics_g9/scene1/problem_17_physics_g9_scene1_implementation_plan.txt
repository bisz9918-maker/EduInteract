[分步序列]
- 初始状态（步骤0）：

  提示文字："点击「下一步」追踪电流路径"

  高亮导线1（电源正极→开关S）：#1565c0蓝色，线宽3px，添加电流方向箭头
  提示文字："电流从电源正极出发，经过开关S"

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀上一步」按钮：坐标(280,445)-(360,475)，点击回退到上一步
  - 步骤指示文字：坐标(370,450)-(430,470)，显示"步骤 X / 6"
  - 「下一步▶」按钮：坐标(440,445)-(520,475)，点击进入下一步
- 教师操作流程：
  1. 图示加载后显示完整电路图（步骤0），教师介绍题目
  2. 点击「下一步」逐步高亮电流路径，配合讲解电流走向
  3. 每步有提示文字辅助说明，教师可结合提示文字展开讲解
  4. 到达步骤6后显示三个结论标签，教师总结电路结构
  5. 可随时点击「上一步」回退复习任意步骤

[技术实现]
- JS 库选择：原生 SVG（简单几何图形和电路元件绘制，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：

  ```
  +--------------------------------------------------+
  |                    电源 (+ -)                     |
  |              (320,40)--------(480,75)             |

  |                 \              /                 |
  |                  \            /                  |
  |                   开关 S     分支点●              |
  |                  (580,115)  (560,180)            |
  |                       \        |                 |
  |                        \       | 导线3(绿)       |

  |                          \     v                 |
  |                           \  L₂(540,275)         |
  |                            \   |                  |
  |  电流表A    导线5(红)-------导线4(绿)             |
  |  (80,100)  (560,180)→(400,180)→(390,325)        |
  |    | A       |                    |              |
  |    |         L₁(300,295)          |              |
  |    |导线6(红)  |                  |              |

  |  [结论标签2: 电流表测L₁]                          |
  |                                                  |
  |         [◀上一步]  步骤 X/6  [下一步▶]            |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：6个步骤（0-6），当前步骤用变量 `currentStep` 记录
  2. 导线高亮：每个导线段用独立 `<path>` 元素，通过 class 切换颜色/线宽
  3. 箭头绘制：在导线中点位置绘制 `<polygon>` 三角形箭头，方向沿导线走向
  4. 动画过渡：导线高亮使用 CSS transition（0.3s ease），颜色/线宽平滑变化
  5. 元素显隐：分流点/汇合点/结论标签用 opacity 控制显隐，配合 transition
  6. 事件绑定：按钮点击事件更新 `currentStep`，调用 `renderStep(currentStep)` 重绘
  7. 提示文字更新：每步切换时更新底部提示文字内容
- ID 命名规范：所有交互元素 ID 以 `scene1-` 为前缀
  - 导线：`scene1-wire1` ~ `scene1-wire8`
  - 元件：`scene1-battery`, `scene1-switch`, `scene1-l1`, `scene1-l2`, `scene1-ammeter`
  - 标记点：`scene1-branch-point`, `scene1-merge-point`
  - 标签：`scene1-label-branch`, `scene1-label-merge`, `scene1-label-series`
  - 结论：`scene1-conclusion1`, `scene1-conclusion2`, `scene1-conclusion3`
  - 控件：`scene1-btn-prev`, `scene1-btn-next`, `scene1-step-indicator`, `scene1-hint-text`
  - 箭头：`scene1-arrow1` ~ `scene1-arrow8`
- IIFE 隔离：所有 JS 代码包在 `(function() { ... })()` 中，避免全局污染
- SVG 结构：
  - `<defs>`：定义箭头 marker、渐变等
  - `<g id="scene1-wires-default">`：默认灰色导线
  - `<g id="scene1-wires-highlight">`：高亮导线（初始隐藏）
  - `<g id="scene1-components">`：所有电路元件
  - `<g id="scene1-markers">`：分流点/汇合点标记
  - `<g id="scene1-labels">`：所有标签
  - `<g id="scene1-conclusions">`：结论标签（初始隐藏）
  - `<g id="scene1-controls">`：控件栏（按钮+提示文字）
