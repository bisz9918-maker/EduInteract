[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位置(320,460)，点击返回上一步状态
  - 「步骤 0/4」指示器：位置(400,460)，显示当前步骤
  - 「下一步 ▶」按钮：位置(480,460)，点击进入下一步状态
- 教师操作流程：
  1. 初始显示基础图形，教师讲解极地俯视图结构
  2. 点击「下一步」，高亮风向，引导学生观察偏转方向，得出北半球结论
  3. 点击「下一步」，显示气压带名称，教师逐一指认
  4. 点击「下一步」，显示风带名称，教师讲解风带分布
  5. 点击「下一步」，展示季节性移动，教师对比正常与当前位置，得出冬季结论
  6. 可随时点击「上一步」回退复习任意步骤

[技术实现]
- JS 库选择：原生 SVG（简单几何图形首选，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  +----------------------------------------+
  |            0°                           |
  |      90°E         90°W                 |
  |    +----+     (400,230)     +----+     |
  |   /      \                   /      \   |
  |  |  60°   |      极地       |  30°   |  |
  |   \      /     俯视图       \      /   |
  |    +----+                   +----+     |
  |      90°E         90°W                 |
  |            180°                         |
  |                                         |
  |  [标注区：分散在图形外侧]                |
  |                                         |
  |  ┌──────────────────────────────────┐   |
  |  |  ◀上一步  步骤 0/4  下一步▶      |   |
  |  └──────────────────────────────────┘   |
  +----------------------------------------+
  ```
- 关键实现要点：
  - 状态机设计：使用变量 `currentStep` (0-4) 控制显示状态
  - 元素显隐：通过 CSS class `.step-0`, `.step-1` 等控制 `display` 或 `opacity`
  - 动画曲线：步骤切换使用 `transition: opacity 0.3s ease`
  - 事件绑定：按钮点击更新 `currentStep`，重新渲染对应状态
  - ID 命名规范：所有元素 ID 以 `scene2-` 为前缀，如 `scene2-center`, `scene2-meridian-0`, `scene2-wind-a`, `scene2-btn-next`
  - IIFE 隔离：所有 JS 代码包裹在 `(function() { ... })()` 中，避免全局污染
  - SVG 绘制：使用 `<circle>`, `<line>`, `<ellipse>`, `<path>`, `<text>` 元素
  - 风带箭头：使用 `<path>` 绘制曲线，`<marker>` 定义箭头
  - 虚线样式：`stroke-dasharray="5,5"`
