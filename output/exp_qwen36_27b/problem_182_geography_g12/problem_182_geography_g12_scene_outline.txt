    **题目原文：**

    如图为世界经纬网示意图．读图回答以下问题。(12分)

    (1)若某日A点和B点的正午太阳高度相同，则太阳直射点位于____(纬度)，A点位于 B点的___方向。

    (2)如果一架飞机从B点上空于地方时12：00出发向北飞行，3小时后到达C点上空。飞机飞行距离约(   )
    A．2580千米    B．3330千米    C．6660千米    D．2266千米

    (3)若另一架飞机同时以相同的速度从D点上空开始沿纬线向E点上空飞行．则该飞机全程飞行需要________小时．到达E地上空时，E地的地方时为________________。

    (4)若A点某日昼夜平分，且时刻为14 :00，在图中用阴影西出这一时刻夜半球的范围。

    **各点坐标（从图中读取）：**
    - A点：(60°W, 30°N)
    - B点：(0°, 30°S)
    - C点：(0°, 0°)
    - D点：(60°E, 60°N)
    - E点：(120°E, 60°N)

    本图示对应第(1)问，教师可按以下步骤引导学生：

    - 引导学生观察经纬网图，确认各点坐标
    - 强调经度从左到右：180°W→120°W→60°W→0°→60°E→120°E→180°E
    - 纬度从上到下：90°N→60°N→30°N→0°→30°S→60°S→90°S
    - A点坐标：60°W, 30°N；B点坐标：0°, 30°S

    2. **步骤1：方向判断**
    - 纬度方向：A在30°N，B在30°S → A在B的北方
    - 经度方向：A在60°W，B在0° → A在B的西方
    - 综合：A位于B的**西北方向**

    3. **步骤2→步骤3：正午太阳高度推导**
    - 回顾公式：H = 90° - |φ - δ|
    - A点：H_A = 90° - |30° - δ|
    - B点：H_B = 90° - |-30° - δ| = 90° - |30° + δ|
    - 由H_A = H_B得：|30° - δ| = |30° + δ|
    - 解得：δ = 0°，即太阳直射**赤道**
    - 直观理解：A、B关于赤道对称，只有直射赤道时两者正午太阳高度才相等

    **关键提醒：** 学生容易混淆经度东西方向的判断，需强调"劣弧原则"——两点间经度差小于180°时，东经在东、西经在西。

    **本图示教学说明：**

    本图示整合第(2)(3)问，教师可按以下步骤讲解：

    1. **步骤0→步骤1：第(2)问——经线距离计算**
    - B点(0°, 30°S)向北飞到C点(0°, 0°)，沿经线飞行
    - 纬度差 = 30°
    - 经线上每1°纬度 ≈ 111 km
    - 距离 = 30° × 111 km/° = **3330 km**
    - 飞行3小时，速度 = 3330 ÷ 3 = **1110 km/h**
    - 答案选 **B**

    2. **步骤2→步骤3：第(3)问——纬线距离计算**
    - D点(60°E, 60°N)沿纬线飞到E点(120°E, 60°N)
    - 经度差 = 60°
    - 纬线上每1°经度距离 = 111 × cos(纬度) km
    - 在60°N纬线上：1°经度 = 111 × cos(60°) = 111 × 0.5 = 55.5 km
    - 距离 = 60° × 55.5 km/° = **3330 km**
    - 速度相同（1110 km/h），飞行时间 = 3330 ÷ 1110 = **3小时**
    - 强调：虽然距离相同，但这是巧合（30°经线差 × cos60°恰好等于30°纬度差）

    3. **步骤4：地方时计算**
    - 飞机从D点地方时12:00出发
    - E点在D点东边60°，时差 = 60° ÷ 15°/h = **4小时**
    - 到达E地上空时，E地的地方时 = 12:00 + 4h = **16:00**
    - 注意区分：飞机飞行3小时是"经过的时间"，而E地与D地的时差是"空间位置决定的时间差"
    - 验证：飞机到达时D点地方时为15:00，E点比D点早4小时，即15:00 + 4h = 19:00？不对！
    - 正确理解：出发时D点12:00，此时E点已是16:00（时差4h）。飞机飞3小时后到达E地上空，此时E地地方时 = 16:00 + 3h = **19:00**
    - 但题目问的是"到达E地上空时E地的地方时"，即飞机到达那一刻E地的时间
    - D点12:00出发，飞3小时，到达时D点地方时为15:00
    - E点比D点早4小时，所以E地地方时 = 15:00 + 4h = **19:00**

    **更正：** 重新审题——"到达E地上空时，E地的地方时"。飞机从D点12:00出发，飞行3小时到达E地上空。此时D点地方时为15:00，E点在D点东边60°，地方时比D点早4小时，故E地地方时 = 15:00 + 4h = **19:00**。

    **关键提醒：** 学生常混淆"飞行时间"和"时差"。需强调：时差由经度差决定，与飞行时间无关。

    本图示对应第(4)问，教师可按以下步骤讲解：

    1. **步骤0：理解题意**
    - A点昼夜平分 → 太阳直射赤道（春分或秋分）
    - A点地方时14:00
    - 目标：标出夜半球范围

    2. **步骤1：确定18:00经线（昏线）**
    - A点(60°W)地方时14:00
    - 18:00经线在A点东边：18:00 - 14:00 = 4小时 = 60°
    - 60°W + 60° = 0°经线
    - 0°经线即为18:00经线（昏线）

    3. **步骤2：确定6:00经线（晨线）**
    - 6:00经线在A点西边：14:00 - 6:00 = 8小时 = 120°
    - 60°W + 120°（向西）= 180°经线
    - 180°经线即为6:00经线（晨线）

    4. **步骤3：标注夜半球范围**
    - 夜半球：地方时18:00到次日6:00的区域
    - 即从0°经线向东到180°经线的半个地球
    - 用灰色阴影填充该区域
    - 昼半球：从180°经线向东到0°经线的区域（白色）

    5. **步骤4：补充说明**
    - 昼夜平分时，晨昏线与经线圈重合
    - 18:00经线 = 昏线（由昼入夜）
    - 6:00经线 = 晨线（由夜入昼）
    - 夜半球范围 = 0°经线以东至180°经线

    **关键提醒：** 学生需掌握"已知某地时间求其他经线时间"的方法：东加西减，15°/小时。夜半球范围始终是18:00经线向东到6:00经线。
