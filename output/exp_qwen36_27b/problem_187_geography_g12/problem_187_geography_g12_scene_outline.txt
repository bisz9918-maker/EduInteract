    **题目原文：**

    下图为北半球四地点在6月22日不同时刻测到的当地太阳位于正南方时的太阳能热水器倾角示意图。

    （1）该日四地点中正午太阳高度由大到小的排序是________，该日四地点中昼长时间由长到短的排序是________。

    （2）②地的地理坐标是________，④地在①地________方向。

    （3）若①地在大陆上，其附近的著名工业基地是________工业基地，若④地为陆地，其附近的著名工业基地是________。

    （4）③国附近的著名渔场是________渔场，该国的气候深受________洋流影响。

    **题目分析：**

    本题综合考查正午太阳高度计算、经纬度推算、昼夜长短变化规律及区域地理知识。核心解题逻辑如下：

    1. **太阳能热水器倾角与正午太阳高度的关系**：倾角 α + 正午太阳高度 H = 90°（热水器集热板需与太阳光线垂直）
    2. **正午太阳高度公式**：H = 90° - |φ - δ|，其中 φ 为当地纬度，δ 为太阳直射点纬度（6月22日 δ = 23°26'N）
    3. **经度推算**：当地太阳位于正南方即地方时12:00，与世界时的时差可推算经度（1小时 = 15°）
    4. **昼长规律**：6月22日北半球纬度越高昼越长
    5. **区域地理**：根据坐标定位，关联工业基地、渔场、洋流等知识

    **各地点计算结果：**

    - ①地（A）：倾角6°34' → H=83°26' → φ=30°N；世界时4时 → 经度120°E → 坐标(30°N, 120°E)
    - ②地（B）：倾角26°34' → H=63°26' → φ=50°N；世界时8时 → 经度60°E → 坐标(50°N, 60°E)
    - ③地（C）：倾角28°34' → H=61°26' → φ=52°N；世界时12时 → 经度0° → 坐标(52°N, 0°)
    - ④地（D）：倾角13°34' → H=76°26' → φ=37°N；世界时24时 → 经度180° → 坐标(37°N, 180°)

    本题规划为两个图示场景：
    - **Scene 1**：聚焦太阳能热水器倾角与正午太阳高度的计算关系，通过分步交互展示四个地点的角度计算与排序
    - **Scene 2**：聚焦经纬度推算与地理定位，在地球模型和世界地图上标注四地点，关联区域地理知识

    **Scene 2 教学说明：**

    本图示完成从坐标计算到区域地理知识关联的完整推导链条，是本题的核心讲解环节。

    **讲解要点：**

    1. **纬度推算**：
    - 回顾正午太阳高度公式 H = 90° - |φ - δ|
    - 6月22日太阳直射北回归线，δ = 23°26'N
    - 以①地为例：83°26' = 90° - |φ - 23°26'|，解得 |φ - 23°26'| = 6°34'
    - 因题目限定北半球，且①地正午太阳在正南方（说明在直射点以北），故 φ = 23°26' + 6°34' = 30°N
    - 同理：②地 φ = 50°N、③地 φ = 52°N、④地 φ = 37°N

    2. **经度推算**：
    - 当地太阳位于正南方 = 地方时12:00
    - 经度差 = 时差 × 15°/h
    - ①地：12:00 - 4:00 = 8h → 120°E
    - ②地：12:00 - 8:00 = 4h → 60°E
    - ③地：12:00 - 12:00 = 0h → 0°
    - ④地：12:00 - 0:00 = 12h → 180°

    3. **昼长排序**：
    - 6月22日北半球夏至，纬度越高昼越长
    - 纬度排序：③(52°N) > ②(50°N) > ④(37°N) > ①(30°N)
    - 昼长排序：③ > ② > ④ > ①

    4. **相对方向**：
    - ④地(37°N, 180°)在①地(30°N, 120°E)的东北方向
    - 纬度更高→偏北，经度更东→偏东

    5. **区域地理知识**：
    - ①地(30°N, 120°E)：中国东部沿海，沪宁杭（长江三角洲）工业基地
    - ④地(37°N, 180°)：若为陆地，附近为日本，日本太平洋沿岸工业地带
    - ③国(52°N, 0°)：英国附近，北海渔场（北大西洋暖流与北冰洋南下冷水交汇形成），气候受北大西洋暖流影响（温带海洋性气候）

    - 步骤5切换到世界地图时，引导学生观察四地点的分布规律
    - 步骤6的区域地理标注可结合世界地图册或Google Earth增强直观性

    **完整答案汇总：**

    （1）正午太阳高度由大到小：**① > ④ > ② > ③**（或 A > D > B > C）
    昼长时间由长到短：**③ > ② > ④ > ①**（或 C > B > D > A）

    ④地附近工业基地：**日本太平洋沿岸工业地带**（或京滨工业基地）

    洋流：**北大西洋暖流**

    **教学总结：**

    本题是一道典型的地理综合题，考查了从天文地理（正午太阳高度、昼夜长短）到区域地理（工业基地、渔场、洋流）的多层次知识。教学中应强调以下思维方法：

    1. **数据转化思维**：热水器倾角 → 正午太阳高度 → 纬度；世界时 → 经度
    2. **公式应用思维**：熟练掌握 H = 90° - |φ - δ| 的正向和逆向运用
    3. **空间定位思维**：从抽象坐标到具体地理位置的映射
    4. **综合分析思维**：将天文现象与区域地理特征有机结合
