[图示主题与整合说明]
- 本图示主题：太阳直射点回归运动示意图——四节气关键点的交互式分步讲解
- 整合的步骤/概念：①四节气日期与直射点位置的对应关系；②昼夜长短变化规律；③正午太阳高度的纬度分布规律；④极昼极夜范围判定；⑤直射点移动方向判断
- 教学价值：教师可通过分步导航逐一讲解四个关键节气（春分、夏至、秋分、冬至），每步高亮对应点并展示相关知识点（日期、直射纬度、昼夜情况、正午太阳高度、极昼极夜范围），最后通过综合对比表格总结全貌。支持随时回退复习，避免信息过载。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：(300,450)-(410,480)，点击返回上一步，步骤0时禁用
  - 「下一步 ▶」按钮：(420,450)-(530,480)，点击进入下一步，步骤5时禁用
  - 步骤指示器：(360,435)-(440,448)，显示"步骤 X/5"
- 教师操作流程：
  1. 图示加载后显示步骤0（基础回归运动图），教师可先整体介绍太阳直射点回归运动
  2. 点击「下一步 ▶」进入步骤1，高亮①点（春分），讲解春分日的直射点位置、昼夜情况
  3. 继续点击「下一步 ▶」依次进入步骤2-4，分别讲解夏至、秋分、冬至
  4. 点击「下一步 ▶」进入步骤5，展示综合对比表格，总结四节气特征
  5. 随时点击「◀ 上一步」回退到任意步骤复习
  6. 讲解过程中可反复切换步骤，配合题目各小问进行针对性讲解

[技术实现]
- JS 库选择：原生 SVG（简单几何图形、折线图、文本标注，无需额外库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：

  │               ↗                                          │

  [步骤5：图缩小+表格]

  │                      步骤 5/5                              │
  └────────────────────────────────────────────────────────────┘

- 关键实现要点：
  1. 状态机设计：使用全局变量 `currentStep`（0~5）管理当前步骤，每个步骤对应一组可见/隐藏/高亮的元素
  2. SVG 元素管理：所有动态元素（高亮点、标签、提示框、箭头、表格）初始创建但设置 `opacity="0"` 或 `display="none"`，通过 JS 控制显隐
  3. 高亮动画：点放大使用 CSS transition（r 从6到9，0.3s ease），颜色填充使用 opacity 渐变
  4. 步骤5缩放：回归运动图整体使用 SVG `<g>` 包裹，通过 `transform="translate(0,20) scale(0.39,0.39)"` 实现缩小（注意 scale 中心点调整）
  5. 表格实现：使用 SVG `<rect>` 和 `<text>` 绘制表格，而非 HTML table，保持纯 SVG 实现
  6. 按钮事件：点击「上一步」/「下一步」触发 `changeStep(-1)` / `changeStep(1)`，更新 `currentStep` 并调用 `renderStep(currentStep)`
  7. 按钮禁用状态：步骤0时「上一步」按钮 `pointer-events="none"` 且灰色；步骤5时「下一步」按钮同理
  8. 箭头绘制：使用 SVG `<marker>` 定义箭头头部，折线轨迹使用 `<polyline>` 配合 `marker-end`
  9. 方向箭头：步骤2和步骤4的绿色箭头使用 `<line>` + `<marker>` + `<text>` 组合
- ID 命名规范：所有交互元素 ID 以 `scene1-` 为前缀
  - 按钮：`scene1-prev-btn`、`scene1-next-btn`
  - 步骤指示器：`scene1-step-indicator`
  - 四个点：`scene1-point-1`、`scene1-point-2`、`scene1-point-3`、`scene1-point-4`
  - 高亮标签：`scene1-label-1`、`scene1-label-2`、`scene1-label-3`、`scene1-label-4`
  - 提示框：`scene1-tip-1`、`scene1-tip-2`、`scene1-tip-3`、`scene1-tip-4`
  - 方向箭头：`scene1-arrow-south`、`scene1-arrow-north`
  - 表格：`scene1-table`
  - 回归运动图组：`scene1-diagram`
  - 参考线：`scene1-tropic-n`、`scene1-equator`、`scene1-tropic-s`
  - 折线：`scene1-path`
- IIFE 隔离：所有 JS 代码包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染
- 事件绑定：使用 `document.getElementById` 获取元素，避免 `querySelectorAll` 配合全局 class 导致多场景合并时跨场景污染
