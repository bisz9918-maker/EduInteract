[图示主题与整合说明]
- 本图示主题：定滑轮装置的整体受力分析与浮力计算
- 整合的步骤/概念：①装置整体结构展示 ②物体B的二力平衡分析 ③物体A的三力平衡分析 ④浮力与排开体积计算 ⑤选项判断总结

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：位置(280,450)-(385,480)，点击回退到上一步骤，步骤0时禁用
  - "下一步 ▶"按钮：位置(405,450)-(520,480)，点击进入下一步骤，步骤4时禁用
  - 步骤指示器：位置(395,455)-(405,475)，显示"1/4""2/4""3/4""4/4"
- 教师操作流程：
  1. 图示加载后显示完整装置图（步骤0），教师可先介绍装置结构
  2. 点击"分析B"→显示B的受力分析和二力平衡计算
  3. 点击"分析A"→显示A的受力分析和三力平衡计算
  4. 点击"计算V排"→显示阿基米德原理计算过程
  5. 点击"判断选项"→显示四个选项的判断结果
  6. 随时点击"上一步"回退复习任意步骤

[技术实现]
- JS 库选择：原生 SVG（简单几何图示首选，无需额外库，精确坐标控制，矢量清晰）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +-------------------------------------------------------------+
  |  ===固定支架===                                              |
  |     (O) 定滑轮                                               |
  |    /   \                                                     |
  |   B     弹簧测力计                                           |
  |   |       |                                                  |
  |   |       A                                                  |
  |  ~~~~~~~~~~  烧杯+水位线                                      |
  |                                                     [分析框1]|
  |                                                     [分析框2]|
  |                                                     [分析框3]|
  |                    [◀上一步] [1/4] [下一步▶]                  |
  +-------------------------------------------------------------+
  左侧x=0~460: 装置图    右侧x=490~770: 分析文本框    底部y=450~480: 控件
  ```
- 关键实现要点：
  1. 状态机设计：全局变量 `currentStep`（0~4），每个步骤对应一组元素的显示/隐藏
  2. 元素管理：所有动态元素（受力箭头、标签、文本框）初始 `opacity="0"`，通过 JS 设置 `opacity="1"` 显示
  3. 动画曲线：使用 CSS `transition: opacity 0.4s ease-in-out` 实现平滑淡入淡出
  4. 事件绑定：两个按钮分别绑定 `prevStep()` 和 `nextStep()` 函数，检查边界条件
  5. 文本框内容：使用 SVG `<text>` 元素，`text-anchor="start"` 左对齐，行间距20px
  6. 弹簧测力计绘制：使用 `<polyline>` 绘制锯齿形弹簧，坐标序列：
     (325,220)-(355,225)-(325,230)-(355,235)-(325,240)-(355,245)-(325,250)-(355,255)-(325,260)-(355,265)-(325,270)-(355,275)-(325,280)
  7. 箭头绘制：使用 `<line>` + `<polygon>` 箭头头部，或 SVG `<marker>` 定义箭头
  8. 水位线：使用 `<line>` 元素，`stroke-dasharray="8,4"` 虚线样式
- ID 命名规范：所有交互元素 ID 以 `scene1-` 为前缀
  - 按钮：`scene1-prev-btn`、`scene1-next-btn`
  - 步骤指示器：`scene1-step-indicator`
  - 受力箭头组：`scene1-forces-b`、`scene1-forces-a`
  - 文本框：`scene1-analysis-box1`、`scene1-analysis-box2`、`scene1-analysis-box3`
  - 装置元素：`scene1-pulley`、`scene1-object-a`、`scene1-object-b`、`scene1-spring`、`scene1-beaker`
- IIFE 隔离：所有 JS 代码包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染
