[图示主题与整合说明]
- 本图示主题：从三视图还原几何体——识别半圆锥与三棱锥的组合结构
- 整合的步骤/概念：三视图展示 → 俯视图分解（半圆+三角形）→ 三维几何体还原 → 标注关键尺寸 → 强调公共结构
- 教学价值：教师通过分步导航，引导学生从二维三视图逐步过渡到三维几何体的认知，理解"半圆锥+三棱锥"的组合结构，为后续体积计算（(π+2)/6）建立直观基础

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：位置(200,450)，尺寸100×32px，点击返回上一步，步骤0时禁用（灰色）
  - "下一步 ▶"按钮：位置(500,450)，尺寸100×32px，点击进入下一步，步骤4时禁用（灰色）
  - 步骤说明文字：位置(400,478)，显示当前步骤说明
- 教师操作流程：
  1. 图示加载后显示步骤0（三视图），教师引导学生观察三视图
  2. 点击"下一步"进入步骤1，蓝色高亮半圆/半圆锥，讲解对应关系
  3. 点击"下一步"进入步骤2，绿色高亮三角形/三棱锥，讲解对应关系
  4. 点击"下一步"进入步骤3，标注所有关键尺寸，为体积计算做准备
  5. 点击"下一步"进入步骤4，强调公共顶点和高度，完成几何体还原
  6. 可随时点击"上一步"回退复习任意步骤

[技术实现]
- JS 库选择：原生 SVG（本场景为几何图形绘制，无需复杂动画库，原生 SVG 足够且轻量）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  +--------------------------------------------------+
  |  正视图    |    侧视图    |                       |
  |  △        |      △       |                       |
  |  1  1     |    1   1     |                       |
  |           |              |         · 顶点        |
  |           |              |        /|\            |
  |  半圆     |              |       / | \           |
  |  ─────    |              |      /  |  \          |
  |  △△△     |              |     /___|___\         |
  |  1  1    |              |    /    |    \        |
  |           |              |   /_____|_____\       |
  |  俯视图   |              |                       |
  |           |              |                       |
  |           |              |                       |
  |-----------|--------------|-----------------------|
  |           |              |                       |
  |           |              |                       |
  |           |              |                       |
  |◀ 上一步   |  步骤说明文字  |   下一步 ▶            |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. **状态机设计**：使用变量 `currentStep`（0~4）管理当前步骤，每个步骤对应一组视觉状态
  2. **SVG 元素管理**：所有 SVG 元素通过 `document.createElementNS` 创建，用 `id` 精确引用
  3. **高亮效果**：通过修改 SVG 元素的 `fill` 和 `fill-opacity` 属性实现，蓝色 `#1565c0` 20% 透明度，绿色 `#2e7d32` 20% 透明度
  4. **标注出现/消失**：通过 `opacity` 属性控制（0→1 淡入，1→0 淡出），使用 CSS transition 实现平滑过渡
  5. **按钮状态**：步骤0时"上一步"按钮 `disabled`（灰色 #cccccc），步骤4时"下一步"按钮 `disabled`
  6. **三维几何体绘制**：
     - 半圆锥底面：`<ellipse cx="560" cy="285" rx="85" ry="38" clip-path="半圆裁剪">` 或用 `<path>` 绘制椭圆上半弧
     - 三棱锥底面：`<polygon points="475,285 645,285 560,375">`
     - 侧面轮廓：`<line>` 从顶点到底面各关键点
  7. **俯视图半圆裁剪**：使用 `<clipPath>` 定义上半圆区域，用于蓝色高亮填充
  8. **俯视图三角形区域**：直接用 `<polygon>` 定义三角形区域，用于绿色高亮填充
- ID 命名规范：所有交互元素 ID 以 `scene1-` 为前缀
  - 按钮：`scene1-prev-btn`, `scene1-next-btn`
  - 步骤说明：`scene1-step-info`
  - 三视图元素：`scene1-front-view`, `scene1-side-view`, `scene1-top-view`
  - 俯视图高亮区域：`scene1-top-semicircle-highlight`, `scene1-top-triangle-highlight`
  - 三维几何体：`scene1-3d-geometry`, `scene1-3d-semicone-highlight`, `scene1-3d-triprism-highlight`
  - 标注元素：`scene1-label-semicone`, `scene1-label-triprism`, `scene1-label-r1`, `scene1-label-base2`, `scene1-label-h1`, `scene1-label-a3d`
  - 步骤4元素：`scene1-symmetry-plane`, `scene1-common-base`, `scene1-vertex-highlight`
- IIFE 隔离：所有 JS 代码包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染
