[图示主题与整合说明]
- 本图示主题：铅笔芯并联电路的交互式演示——滑片P位置与两支路电流的关系
- 整合的概念：
  1. 电路结构：电源→开关→滑片P，AP段与PB段并联，A₁测AP支路电流，A₂测PB支路电流
  2. 电阻与长度成正比：R_AP ∝ L_AP，R_PB ∝ L_PB
  3. 并联电压相等：I₁ = U/R_AP，I₂ = U/R_PB，故 I₁/I₂ = L_PB/L_AP
  4. 量程限制：电流表量程决定了滑片P的允许滑动范围
  5. 不同量程对比：0-0.6A时cd=12cm、最大比值3:1；0-3A时c'd'=21.6cm、最大比值19:1
- 教学价值：教师通过拖动滑片P，让学生直观观察两支路电流随滑片位置的变化规律，理解电阻与长度的正比关系，以及量程对滑动范围的限制作用。切换量程按钮可对比两种量程下的差异，帮助学生理解题目中"最大比值"和"允许滑动范围"的物理含义。

[分步序列]
- 初始状态（步骤0）：
  * 显示完整电路图：电源、开关（闭合）、导线、电流表A₁/A₂、铅笔芯AB
  * 滑片P位于铅笔芯中点（x=345），AP段和PB段等长
  * AP段显示蓝色高亮，PB段显示红色高亮
  * 数据面板显示：I₁ = 0.30A，I₂ = 0.30A，I₁:I₂ = 1:1，量程：0-0.6A，范围：12.0cm
  * c点和d点标记显示在铅笔芯上，cd范围标记线（绿色）显示
  * 底部显示两个量程按钮，"0-0.6A"按钮为选中状态（蓝色）
  * 底部显示拖动提示文字

- 交互步骤1（拖动滑片P）：
  * 教师用鼠标拖动滑片P沿铅笔芯AB左右移动
  * AP段蓝色高亮区域随P移动而伸缩
  * PB段红色高亮区域随P移动而伸缩
  * 数据面板实时更新：I₁、I₂数值变化，比值变化
  * 当P在cd范围内移动时，无警告
  * 当P超出cd范围时，数据面板底部显示红色警告："⚠ 电流超出量程！"
  * 超出量程时，对应电流表圆圈变为红色描边

- 交互步骤2（到达极限位置）：
  * 当P到达c点（左极限）：I₁达到量程上限，A₁电流表红色高亮，c点标记闪烁
  * 当P到达d点（右极限）：I₂达到量程上限，A₂电流表红色高亮，d点标记闪烁
  * 此时比值达到最大值3:1（0-0.6A量程下）

- 交互步骤3（切换量程）：
  * 点击"0-3A"按钮，量程切换为0-3A
  * c点和d点标记移动到新位置（c'≈125, d'≈566），cd范围标记线更新
  * 数据面板更新：量程显示"0-3A"，范围显示"21.6cm"
  * 滑片P当前位置如果在新范围内，无警告；如果在新范围外，显示警告
  * 拖动P到新极限位置时，比值达到最大值19:1
  * 点击"0-0.6A"按钮可切回原量程

[交互方案]
- 交互类型：连续拖拽滑块 + 多状态切换（量程按钮）
- 控件说明：
  1. 滑片P（三角形箭头）：可沿铅笔芯AB水平拖动，拖动范围x=100到x=590
  2. "0-0.6A"按钮：点击切换为0-0.6A量程，cd范围12cm，最大比值3:1
  3. "0-3A"按钮：点击切换为0-3A量程，c'd'范围21.6cm，最大比值19:1
- 教师操作流程：
  1. 初始状态展示电路结构，滑片在中点，两支路电流相等
  2. 拖动滑片P向左/右移动，观察I₁、I₂数值变化和比值变化
  3. 拖动到c点或d点，观察电流表达到量程上限，比值达到最大值
  4. 点击量程切换按钮，对比两种量程下的滑动范围和最大比值差异
  5. 引导学生理解：量程越大，允许滑动范围越大，最大比值也越大

[技术实现]
- JS 库选择：原生 SVG（简单电路几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │  y=40:  ───────────●───────────  (顶部导线)                  │
  │              │ 电源 │                                         │
  │              │ 开关 │                                         │
  │              │      │                                         │

  │              │      │         │  实时数据     │               │
  │              │      │         │  I₁=0.30A    │               │
  │              │      │         │  I₂=0.30A    │               │
  │              │      │         │  I₁:I₂=1:1   │               │
  │              │      │         │  量程:0-0.6A │               │
  │              │      │         │  范围:12.0cm │               │

  │  y=450:   [ 0-0.6A ] [ 0-3A ]                                 │
  └─────────────────────────────────────────────────────────────┘
  ```

- 关键实现要点：

  1. **状态机设计**：
     - 状态变量：`range`（'0.6'或'3'）、`pPos`（滑片P的x坐标，100~590）
     - 计算函数：根据pPos和range计算I₁、I₂、比值、是否超限
     - 物理模型：
       * 铅笔芯总长 L=24cm，对应490px，比例 k=490/24≈20.42px/cm
       * 设 U/(k·L) = 0.15（由0-0.6A量程下最大电流推导）
       * I₁ = 0.15 × L / x_cm = 3.6 / x_cm
       * I₂ = 0.15 × L / (L - x_cm) = 3.6 / (L - x_cm)
       * x_cm = (pPos - 100) / k

  2. **坐标计算**：
     * 0-0.6A量程：c点x=100+6×k≈222，d点x=100+18×k≈468
     * 0-3A量程：c'点x=100+1.2×k≈125，d'点x=100+22.8×k≈566
     * 滑片P拖动范围：x=100到x=590（整个铅笔芯）
     * 允许范围判断：pPos是否在[c_x, d_x]区间内

  3. **拖拽实现**：
     * mousedown/mousemove/mouseup 事件绑定到滑片P
     * 拖动时限制x坐标在100~590范围内
     * 实时更新AP/PB段高亮、数据面板数值、超限警告

  4. **动画曲线**：
     * 滑片P拖动：无动画，实时跟随鼠标
     * 量程切换：c/d标记点平滑移动到新位置（transition 0.3s ease）
     * 超限警告：淡入效果（opacity 0→1，0.2s）

  5. **事件绑定**：
     * 滑片P：mousedown开始拖动，mousemove更新位置，mouseup结束拖动
     * 量程按钮：click切换量程，更新c/d位置和显示数据
     * 全局mouseup：结束拖动（防止鼠标移出SVG后仍拖动）

- **ID 命名规范**：所有交互元素ID以 `scene1-` 为前缀
  * `scene1-pen-rod`：铅笔芯AB

  * `scene1-data-panel`：数据面板

  * `scene1-display-ratio`：比值显示
