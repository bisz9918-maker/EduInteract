[分步序列]
- 初始状态（步骤0）：
  - 显示完整电路图（导线、电池、开关、A1、A2、铅笔芯AB、滑片P）
  - 显示绿色cd范围（c在6cm处，d在18cm处），标注cd=12cm
  - 公式区显示："已知条件（0-0.6A量程）"
    - 最大比值 I₁/I₂ = 3:1
    - 滑动范围 cd = 12cm
    - 推导得 L = 24cm，U/(ρL) = 0.15A
  - 选项区：四个选项均显示，无高亮

- 步骤1：点击「下一步」→
  - 公式区更新："步骤1：计算0-3A量程下 x_min'"
    - I₁ ≤ 3A → x_min' = U/(3ρ)
    - = (U/(ρL)) × L / 3
    - = 0.15 × 24 / 3 = 1.2cm
  - 铅笔芯上出现蓝色c'点标记（1.2cm处），蓝色虚线参考线
  - 选项区：无变化

- 步骤2：点击「下一步」→
  - 公式区更新："步骤2：计算0-3A量程下 x_max'"
    - I₂ ≤ 3A → x_max' = L - U/(3ρ)
    - = 24 - 1.2 = 22.8cm
  - 铅笔芯上出现蓝色d'点标记（22.8cm处），蓝色虚线参考线
  - 蓝色cd'范围填充出现（c'到d'之间）
  - 选项区：无变化

- 步骤3：点击「下一步」→
  - 公式区更新："步骤3：计算最大比值"
    - (I₁/I₂)max = (L - x_min') / x_min'
    - = (24 - 1.2) / 1.2
    - = 22.8 / 1.2 = 19
    - 即 最大比值 = 19:1
  - 铅笔芯上蓝色cd'范围高亮闪烁
  - 选项区：选项A（19:1）开始绿色高亮，选项B（29:1）红色标记打叉

- 步骤4：点击「下一步」→
  - 公式区更新："步骤4：计算滑动范围"
    - cd' = x_max' - x_min'
    - = 22.8 - 1.2 = 21.6cm
  - 铅笔芯上标注cd' = 21.6cm（蓝色文字）
  - 选项区：选项D（21.6cm）开始绿色高亮，选项C（22.4cm）红色标记打叉

- 步骤5（最终步骤）：点击「下一步」→
  - 公式区更新："结论对比"
    - 0-0.6A量程：最大比值3:1，cd=12cm
    - 0-3A量程：最大比值19:1，cd'=21.6cm
    - ✓ 正确答案：A、D
  - 铅笔芯上同时显示绿色cd和蓝色cd'范围，对比清晰
  - 选项区：A和D绿色背景白色文字（正确），B和C红色背景白色文字（错误）

- "A₂"(400,165)与"d'"(352,295)：距离≈135px → 无冲突

- "c'"(64,295)与"c"(132,295)：距离=68px → 无冲突

- "cd=12cm"(220,295)与"L=24cm"(220,310)：距离=15px → 轻微接近，但cd=12cm在步骤0-3显示，L=24cm始终显示，且cd=12cm为绿色、L=24cm为黑色，视觉可区分。将L=24cm下移至(220,318)，间距=23px → 无冲突

- "P"(230,200)与所有下方标签：最近为"c"(132,295)，距离≈110px → 无冲突
- 所有标签间距均≥20px，无重叠冲突

[技术实现]
- JS 库选择：原生 SVG（简单几何图形和电路图首选，无需额外库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |  [电路图]              [公式展示区]              |
  |  A1───电池───A2       ┌──────────────┐          |
  |   │    │    │         │  步骤内容     │          |
  |   │    P    │         │  计算公式     │          |
  |   │   ↓     │         │  关键结论     │          |
  |   A──c'dcd'B           └──────────────┘          |
  |  (铅笔芯AB)                                       |
  |                                                  |
  |  [选项A]  [选项B]  [选项C]  [选项D]              |
  |                                                  |
  |           ◀上一步    下一步▶                      |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：6个状态（步骤0-5），每个状态对应一组视觉元素显示/隐藏/高亮
  2. 状态数据：用数组存储每步的公式区HTML内容、选项高亮状态、铅笔芯上显示的标记
  3. 坐标计算：铅笔芯320px代表24cm，比例尺13.33px/cm，各点位置按此比例计算
  4. 动画曲线：元素出现使用CSS transition 0.3s ease-in-out，高亮使用opacity变化
  5. 事件绑定：按钮点击触发状态切换函数，更新SVG内容和CSS类
  6. 公式区内容：使用SVG text元素或foreignObject嵌入HTML，支持多行文本
  7. 选项高亮：通过切换CSS类实现背景色和文字颜色变化
- ID 命名规范：所有交互元素ID以 `scene2-` 为前缀
  - 电路图元素：`scene2-wire-top`, `scene2-battery`, `scene2-switch`, `scene2-a1`, `scene2-a2`, `scene2-penlead`
  - 标记点：`scene2-point-c`, `scene2-point-d`, `scene2-point-cp`, `scene2-point-dp`
  - 范围填充：`scene2-range-cd`, `scene2-range-cdp`
  - 公式区：`scene2-formula-area`, `scene2-formula-content`
  - 选项：`scene2-opt-a`, `scene2-opt-b`, `scene2-opt-c`, `scene2-opt-d`
  - 按钮：`scene2-btn-prev`, `scene2-btn-next`
  - 步骤指示：`scene2-step-indicator`
- IIFE 隔离：所有JS代码包裹在 `(function() { ... })()` 中，避免全局污染
- SVG结构：使用 `<svg viewBox="0 0 800 500">` 作为根容器，所有元素在SVG内定位
- 公式区实现：使用 `<foreignObject>` 嵌入HTML div，支持多行文本和样式
