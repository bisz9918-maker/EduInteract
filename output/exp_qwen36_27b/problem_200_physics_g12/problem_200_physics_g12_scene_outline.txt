## 题目原文

如图，圆柱形容器竖直放置，上方A管的横截面积是下方B管的4倍，中间有水银．B管下方封有一段长L=112cm的空气柱，A内水银高h₁=5cm，B内水银高h₂=10cm，水银上方有一活塞（活塞重力及摩擦都不计），大气压p=75cmHg．

（1）封闭气体的压强为多少厘米汞柱？

（2）现用一竖直向上的力F缓慢拉活塞，求活塞向上移动1cm时气体的压强为多少厘米汞柱；

（3）向上缓慢拉活塞的过程中发现拉力F的大小会相应变化，求活塞向上移动多少厘米时拉力F变为零．

（4）试通过计算，分析说明向上缓慢拉活塞的过程中，拉力F的大小应如何变化？（设向上缓慢拉活塞的过程中，B管中总有水银）

## 题目分析

本题核心知识点：
- **连通器原理与压强传递**：水银柱产生的压强叠加
- **玻意耳定律**：等温过程中pV=常数
- **力学平衡**：活塞受力分析
- **体积守恒**：水银总体积不变

解题关键关系：
- 初始压强：p₁ = p₀ + h₁ + h₂ = 75 + 5 + 10 = 90 cmHg
- 水银体积守恒：S_A·h₁ + S_B·h₂ = 常数，即 4h₁' + h₂' = 30
- 活塞上移x后：h₁' = 5 + x，h₂' = 10 - 4x
- 空气柱长度：L' = 112 + 4x
- 玻意耳定律：p₁L = p₂L'，即 90×112 = p₂(112+4x)
- 拉力：F = (p_gas - h₁' - h₂' - p₀)·S_A = (10080/(112+4x) + 3x - 90)·S_A

## Scene 2 教学说明

**教学目标**：通过动态演示，让学生直观理解活塞上移过程中各物理量的变化规律，特别是拉力F先增大后减小的非单调变化。

**核心公式推导**：

1. **水银体积守恒**：
   S_A·h₁ + S_B·h₂ = S_A·h₁' + S_B·h₂'
   4S_B·5 + S_B·10 = 4S_B·h₁' + S_B·h₂'
   30 = 4h₁' + h₂'

2. **活塞位移与水银高度的关系**：
   活塞上移x，A管水银顶部上移x，A管底部固定
   h₁' = 5 + x
   代入体积守恒：h₂' = 30 - 4(5+x) = 10 - 4x

3. **空气柱长度**：
   L' = 122 - h₂' = 122 - (10-4x) = 112 + 4x

4. **玻意耳定律**：
   p₁L = pL'
   90 × 112 = p × (112 + 4x)
   p = 10080 / (112 + 4x)

5. **拉力F的计算**：
   活塞受力平衡：F + p₀·S_A = p_水银顶部·S_A
   p_水银顶部 = p - h₁' - h₂' = p - (5+x) - (10-4x) = p - 15 + 3x
   F = (p - 15 + 3x - 75)·S_A = (p + 3x - 90)·S_A
   F/S_A = 10080/(112+4x) + 3x - 90

**引导步骤**：

1. **初始状态（x=0）**：确认F=0，p=90cmHg，与Scene 1结论一致。

2. **缓慢拖动滑块**：让学生观察：
   - 活塞上移，A管水银变高，B管水银变矮（水银从B管流向A管）
   - 空气柱膨胀，压强减小
   - 拉力F从0开始增大

3. **到达F最大值（x≈0.98cm）**：提问"为什么F会达到最大值后开始减小？"引导学生分析：
   - 一方面，气体膨胀导致压强减小，需要更大的拉力维持活塞位置
   - 另一方面，水银重新分布导致水银柱总高度减小（h₁'+h₂' = 15-3x），抵消了部分压强差
   - 两个因素竞争，导致F先增后减

4. **到达F=0（x=2cm）**：提问"为什么F会再次变为0？"引导学生计算验证：
   - x=2时，p = 10080/120 = 84 cmHg
   - h₁' = 7cm，h₂' = 2cm
   - p_水银顶部 = 84 - 7 - 2 = 75 cmHg = p₀
   - 所以F = 0

5. **回答问题（2）**：x=1cm时，p = 10080/116 ≈ 86.9 cmHg

6. **回答问题（4）**：F在0<x<2范围内先增大后减小，在x≈0.98cm处达到最大值。

**第（2）问答案**：p = 10080/116 = 2520/29 ≈ 86.9 cmHg

**第（3）问答案**：x = 2 cm

**第（4）问答案**：向上缓慢拉活塞的过程中，拉力F先增大后减小。在x≈0.98cm处F达到最大值，之后F逐渐减小，到x=2cm时F=0。

**注意事项**：
- 强调"缓慢"意味着等温过程，适用玻意耳定律
- 强调"B管中总有水银"意味着h₂' > 0，即10-4x > 0，x < 2.5cm
- F-x曲线的形状反映了气体膨胀效应与水银重新分布效应的竞争

## 完整解答总结

**（1）封闭气体的压强**：
p₁ = p₀ + h₁ + h₂ = 75 + 5 + 10 = **90 cmHg**

**（2）活塞向上移动1cm时气体的压强**：
x = 1cm，L' = 112 + 4×1 = 116cm
p = 10080/116 = 2520/29 ≈ **86.9 cmHg**

**（3）拉力F变为零时活塞上移距离**：
由F = 0得：10080/(112+4x) + 3x - 90 = 0
解得x = 0（初始状态）或 x = **2 cm**

**（4）拉力F的变化规律**：
F/S_A = 10080/(112+4x) + 3x - 90
求导得极值点x ≈ 0.98cm
**F先增大后减小**：从x=0到x≈0.98cm，F增大；从x≈0.98cm到x=2cm，F减小。

3. 拖动滑块时，适时暂停，引导学生计算验证当前状态的各物理量。
4. 重点讨论F先增大后减小的物理原因，培养学生的物理直觉。
