    **题目原文：**

    如图所示，质量为m，带电量为q的粒子，以初速度v$_{0}$，从A点竖直向上射入真空中的沿水平方向的匀强电场中，粒子通过电场中B点时，速率v$_{B}$=2v$_{0}$，方向与电场的方向一致，问：
    （1）水平方向和竖直方向分别作什么运动？
    （2）从A到B竖直方向位移是多少？
    （3）从A到B重力做的功是多少？
    （4）从A到B电场力做的功是多少？
    （5）A，B两点的电势差是多少？

    **题目分析：**

    本题是带电粒子在重力场和电场复合场中的运动问题，核心考点包括：
    - 运动的分解与合成（水平方向匀加速、竖直方向竖直上抛）
    - 动能定理的应用
    - 电场力做功与电势差的关系

    **关键物理图像：**
    - 粒子从A点竖直向上射出，同时受水平向右的电场力
    - 轨迹为抛物线，从A到B
    - 在B点速度完全水平（竖直分速度减为0），说明B点恰好是竖直方向的最高点
    - 利用B点速度方向水平这一条件，可求出竖直位移

    **整体讲解思路：**
    1. 先引导学生观察题目原图，理解粒子的运动情景
    2. 通过运动分解，分析水平和竖直方向的运动性质（第1问）
    3. 利用B点速度方向水平（竖直分速度为0）这一关键条件，求竖直位移（第2问）
    4. 由竖直位移求重力做功（第3问）
    5. 用动能定理求电场力做功（第4问）
    6. 由电场力做功与电势差关系求U$_{AB}$（第5问）

    **图示规划：**
    - Scene 1：运动分解与轨迹分析图——整合运动情景展示、速度分解、受力分析、运动性质判断
    - Scene 2：动能定理与做功计算图——整合动能变化、各力做功、电势差计算

    **Scene 1 教学说明：**

    本图示帮助学生建立带电粒子在复合场中运动的物理图像，核心是**运动的分解**。

    **讲解要点：**

    1. **引导学生观察原图**：电场水平向右，粒子从A竖直向上射出，轨迹是抛物线，到达B点时速度完全水平。

    2. **关键突破口——B点速度方向**：
    - 题目说B点速度"方向与电场方向一致"，即水平向右
    - 这意味着B点竖直分速度为0
    - 说明B点恰好是竖直方向运动的最高点

    3. **运动分解**：
    - 水平方向：只受电场力qE，初速度为0，做**匀加速直线运动**
    - 竖直方向：只受重力mg，初速度为v$_{0}$，做**竖直上抛运动**（匀减速）

    4. **受力分析**：
    - 重力mg竖直向下，电场力qE水平向右
    - 两个力互相垂直，互不影响，体现了运动的独立性原理

    **教师引导话术建议：**
    - "同学们，B点速度方向水平，这意味着什么？"——引导学生发现竖直分速度为0
    - "竖直方向只受什么力？做什么运动？"——引导学生回答竖直上抛
    - "水平方向只受什么力？初速度是多少？"——引导学生回答匀加速、初速为0

    **Scene 2 教学说明：**

    本图示完整展示从运动分析到能量求解的推导过程，覆盖第2至第5问。

    **逐问讲解要点：**

    **第2问：竖直位移**
    - 关键条件：B点竖直分速度为0（因为B点速度完全水平）
    - 竖直方向为竖直上抛运动，用运动学公式：
    - v$_{By}^2$ - v$_{Ay}^2$ = 2(-g)h
    - 0 - v$_{0}^2$ = -2gh
    - **h = v$_{0}^2$/(2g)**

    **第3问：重力做功**
    - 重力做功 W$_{G}$ = -mgh（重力向下，位移向上，做负功）
    - 代入h得：**W$_{G}$ = -mv$_{0}^2$/2**

    **第4问：电场力做功（核心难点）**
    - 用动能定理：W$_{合}$ = ΔE$_{k}$
    - W$_{G}$ + W$_{电}$ = $\frac{1}{2}$mv$_{B}^2$ - $\frac{1}{2}$mv$_{A}^2$
    - W$_{G}$ + W$_{电}$ = $\frac{1}{2}$m(2v$_{0}$)$^2$ - $\frac{1}{2}$mv$_{0}^2$
    - W$_{G}$ + W$_{电}$ = 2mv$_{0}^2$ - $\frac{1}{2}$mv$_{0}^2$ = $\frac{3}{2}$mv$_{0}^2$
    - W$_{电}$ = $\frac{3}{2}$mv$_{0}^2$ - W$_{G}$ = $\frac{3}{2}$mv$_{0}^2$ + $\frac{1}{2}$mv$_{0}^2$
    - **W$_{电}$ = 2mv$_{0}^2$**

    **第5问：电势差**
    - 电场力做功与电势差关系：W$_{电}$ = qU$_{AB}$
    - **U$_{AB}$ = W$_{电}$/q = 2mv$_{0}^2$/q**

    **教师引导话术建议：**
    - "求电场力做功，直接求困难，有没有间接方法？"——引导学生想到动能定理
    - "动能定理中，合力做功等于哪些力做功之和？"——引导学生列出W$_{G}$ + W$_{电}$
    - "电势差和电场力做功有什么关系？"——引导学生回忆W = qU

    **易错点提醒：**
    - 重力做功的正负号：位移向上，重力向下，做负功
    - 动能定理中ΔE$_{k}$ = E$_{k末}$ - E$_{k初}$，不要搞反
    - 电势差U$_{AB}$ = W$_{AB}$/q，注意是A到B的电场力做功
    </TEXT_3>

    **完整答案汇总：**

    （1）水平方向：初速度为0的匀加速直线运动；竖直方向：初速度为v$_{0}$的匀减速直线运动（竖直上抛运动）

    （2）竖直位移：h = v$_{0}^2$/(2g)

    （3）重力做功：W$_{G}$ = -mv$_{0}^2$/2

    （4）电场力做功：W$_{电}$ = 2mv$_{0}^2$

    （5）电势差：U$_{AB}$ = 2mv$_{0}^2$/q

    **课堂讲解建议：**

    1. **先画图再解题**：让学生先在草稿纸上画出粒子的运动轨迹和受力情况，建立物理图像
    2. **抓住关键条件**：B点速度方向水平是解题的突破口，由此可知竖直分速度为0
    3. **运动分解思想**：水平和竖直方向互相独立，分别分析
    4. **动能定理是桥梁**：连接运动学和能量，是解决第4问的关键
    5. **注意正负号**：重力做功为负，动能变化为正，电场力做功为正

    **拓展思考：**
    - 如果粒子带负电，轨迹和结果会怎样变化？
    - 如果电场方向竖直向上，粒子运动将如何？
    - 本题中能否求出电场强度E的大小？（需要知道水平位移）
