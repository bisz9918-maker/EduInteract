题目原文：

如图所示，匀速转动的水平圆盘上，沿半径方向放置两个用细线相连的质量均为m的小物体A、B，它们到转轴距离分别为rA=20cm、rB=10cm，A、B与盘面间的最大静摩擦力均为重力的0.5倍，连接OB以及AB的两根细绳所能承受的最大张力均为2mg，试求：
（1）当AB之间的细线上开始有弹力时，圆盘的角速度ω_0；
（2）当OB之间的细线上开始有弹力时，圆盘的角速度ω_1；
（3）当物体A刚开始滑动时，圆盘的角速度ω_2。

题目分析：

本题核心是圆周运动中向心力的来源分析，涉及静摩擦力和绳子拉力的临界条件判断。两个物体A、B质量相同但转动半径不同（rA = 2rB），因此A所需向心力始终大于B。随着角速度增大，系统经历三个阶段：

  1. 阶段一（ω < ω_0）：A、B的向心力均由静摩擦力单独提供
  2. 阶段二（ω0 < ω < ω1）：A的静摩擦力已达最大值，AB绳开始提供拉力；B的静摩擦力尚未达最大值
  3. 阶段三（ω > ω_1）：A、B的静摩擦力均达最大值，OB绳也开始提供拉力

关键临界条件：

  • ω_0：A的静摩擦力达到μmg = 0.5mg，AB绳开始有弹力
  • ω_1：B的静摩擦力也达到μmg = 0.5mg，OB绳开始有弹力
  • ω_2：AB绳拉力达到最大值2mg，A即将滑动

答案：

  • ω_0 = 5 rad/s
  • ω_1 = 10/√3 ≈ 5.77 rad/s
  • ω_2 = 5√5 ≈ 11.18 rad/s

Scene 1 教学说明：

本图示整合了圆盘系统的整体构型和分步受力分析，帮助教师引导学生理解三个临界状态的物理本质。

讲解思路：

  1. 步骤0（初始状态）：引导学生观察题目条件——两个质量相同的物体，A的转动半径是B的两倍。提问：谁需要的向心力更大？（A，因为F = mω²r，rA > rB）
  1. 步骤1（ω = ω_0）：
  • 讲解：当ω增大时，A的静摩擦力先达到最大值（因为A需要更大的向心力）
  • 关键公式：$m\omega_0^2 r_A = \mu mg = 0.5mg$
  • 计算：$\omega_0^2 = \frac{0.5g}{r_A} = \frac{0.5 \times 10}{0.2} = 25$，$\omega_0 = 5\text{ rad/s}$
  • 引导学生注意：此时AB绳开始有拉力，但OB绳仍无张力
  1. 步骤2（ω = ω_1）：
  • 讲解：随着ω继续增大，AB绳拉力增大，B受到向外的拉力，B的静摩擦力也逐渐增大
  • 对A：$T_{AB} + \mu mg = m\omega^2 r_A$
  • 对B：$f_B - T_{AB} = m\omega^2 r_B$
  • 当f_B也达到μmg时，OB绳开始有张力
  • 联立得：$2\mu mg = m\omega_1^2(r_A + r_B)$
  • 计算：$\omega_1^2 = \frac{2 \times 0.5 \times 10}{0.3} = \frac{100}{3}$，$\omega_1 = \frac{10}{\sqrt{3}}\text{ rad/s}$
  1. 步骤3（ω = ω_2）：
  • 讲解：当AB绳拉力达到最大值2mg时，A即将滑动
  • 关键公式：$T_{AB,\text{max}} + \mu mg = m\omega_2^2 r_A$
  • 计算：$2mg + 0.5mg = m\omega_2^2 \times 0.2$，$\omega_2^2 = 125$，$\omega_2 = 5\sqrt{5}\text{ rad/s}$
  • 补充说明：此时需检查OB绳是否断裂（T_OB = 27.5m > 20m，实际上OB绳会先断，但题目仅要求A滑动的理论值）

教学提示：

  • 强调向心力不是独立的力，而是由其他力（摩擦力、拉力）提供的合力
  • 引导学生理解"临界条件"的含义：某个力达到最大值，即将发生质变
  • 可让学生思考：如果rA和rB互换，结果会如何变化？

Scene 2 教学说明：

本图示通过向心力-角速度平方关系图，帮助学生从函数图像的角度理解三个临界角速度的物理意义。

讲解思路：

  1. 图像解读：
  • 横轴为ω²，纵轴为力（以mg为单位）
  • 红色线FA = 0.2mω²表示A所需向心力，蓝色线FB = 0.1mω²表示B所需向心力

  • ω0² = 25：FA曲线与f_max = 0.5mg水平线的交点。此时A的静摩擦力达到最大值，AB绳开始有弹力
  • ω_1² = 100/3 ≈ 33.3：此时B的静摩擦力也达到最大值，OB绳开始有弹力。可通过联立方程理解
  • ω2² = 125：FA曲线与fmax + TAB_max = 2.5mg水平线的交点。此时AB绳拉力达到最大值，A即将滑动
  1. 交互操作建议：
  • 让学生拖动滑块，观察ω²增大时FA和FB的变化
  • 当滑块经过ω_0²时，提问：此时A的静摩擦力达到多少？AB绳是否有拉力？
  • 当滑块经过ω_1²时，提问：此时B的受力情况如何？OB绳是否有拉力？
  • 当滑块经过ω_2²时，提问：此时A的向心力由什么提供？如果ω继续增大，A会怎样？

教学提示：

  • 强调F = mω²r中，F与ω²成正比，所以图像是过原点的直线
  • 引导学生理解：临界条件对应图像上的交点
  • 可让学生思考：如果μ增大，三条临界线会如何移动？ω0、ω1、ω_2会如何变化？

完整解答总结：

已知条件：

  • mA = mB = m
  • rA = 20cm = 0.2m，rB = 10cm = 0.1m
  • μ = 0.5，f_max = μmg = 0.5mg
  • T_max = 2mg（两根绳的最大张力相同）
  • g = 10 m/s²

（1）求ω_0：AB绳开始有弹力

当A的静摩擦力达到最大值时，AB绳开始有弹力：
$$m\omega_0^2 r_A = \mu mg = 0.5mg$$
$$\omega_0^2 = \frac{0.5g}{r_A} = \frac{0.5 \times 10}{0.2} = 25$$
$$\omega_0 = 5\text{ rad/s}$$

（2）求ω_1：OB绳开始有弹力

当B的静摩擦力也达到最大值时，OB绳开始有弹力。此时：

  • 对A：$T_{AB} + \mu mg = m\omega_1^2 r_A$
  • 对B：$\mu mg - T_{AB} = m\omega_1^2 r_B$

两式相加消去T_AB：
$$2\mu mg = m\omega_1^2(r_A + r_B)$$
$$\omega_1^2 = \frac{2\mu g}{r_A + r_B} = \frac{2 \times 0.5 \times 10}{0.2 + 0.1} = \frac{10}{0.3} = \frac{100}{3}$$
$$\omega_1 = \frac{10}{\sqrt{3}}\text{ rad/s} \approx 5.77\text{ rad/s}$$

（3）求ω_2：A刚开始滑动

当AB绳拉力达到最大值2mg时，A即将滑动：
$$T_{AB,\text{max}} + \mu mg = m\omega_2^2 r_A$$
$$2mg + 0.5mg = m\omega_2^2 \times 0.2$$
$$\omega_2^2 = \frac{2.5g}{0.2} = \frac{2.5 \times 10}{0.2} = 125$$
$$\omega_2 = 5\sqrt{5}\text{ rad/s} \approx 11.18\text{ rad/s}$$

课堂讲解建议：

  1. 先用Scene 1展示系统构型，让学生建立空间想象
  2. 逐步推进三个临界状态，每步讲解受力分析和计算公式
  3. 用Scene 2的图像帮助学生从函数角度理解临界条件
  4. 最后总结：临界条件的本质是某个力达到最大值，系统即将发生质变
  5. 拓展思考：如果改变μ、rA、rB等参数，临界角速度如何变化？
