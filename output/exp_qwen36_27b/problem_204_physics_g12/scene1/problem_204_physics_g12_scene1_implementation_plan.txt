[图示主题与整合说明]
- 本图示主题：圆盘系统俯视图与分步受力分析——展示三个临界角速度下的系统状态和物体受力
- 整合的步骤/概念：
  1. 题目初始条件的可视化（圆盘、转轴、物体A/B、两根细线、半径标注）
  2. 三个临界状态（ω₀、ω₁、ω₂）的系统构型变化
  3. 每个状态下物体A和B的受力矢量图（静摩擦力、绳子拉力、向心力方向）
  4. 关键物理量的数值标注与公式推导
- 教学价值：教师可通过分步按钮逐步推进讲解，帮助学生理解每个阶段力的变化过程。从初始状态（细线无张力）到AB绳出现张力，再到OB绳出现张力，最后到AB绳达到最大张力、A即将滑动的完整物理过程。每一步都配有受力分析图和关键公式，便于教师对照讲解。

  - 物体A旁的静摩擦力箭头变为红色(#c62828)，线宽2.5px（达到最大值0.5mg）
- 右侧受力分析区更新：
  - A受力图：f_A箭头(红色，向左，长度50px) + T_AB箭头(蓝色，向左，长度35px)

步骤2（ω = ω₁ = 10/√3 rad/s）：

  - 物体B旁的静摩擦力箭头变为红色(#c62828)，线宽2.5px（达到最大值0.5mg）

    - f_A从(623,135)出发，标签"f_A=0.5mg"(560,130)
    - T_AB从(623,145)出发，标签"T_AB"(570,150)
  - B受力图：f_B(红色，向左，长度50px) + T_OB(蓝色，向左，长度35px) + T_AB(蓝色，向右，长度35px)
    - f_B从(623,255)出发，标签"f_B=0.5mg"(560,250)
    - T_OB从(623,265)出发，标签"T_OB"(570,270)
    - T_AB从(647,260)出发向右，标签"T_AB"(685,255)
- 公式框：显示"2μmg = mω₁²(r_A + r_B) → ω₁ = √(2μg/(r_A+r_B)) = 10/√3 rad/s"
- 步骤指示器：第3个圆点高亮

步骤3（ω = ω₂ = 5√5 rad/s）：

    - T_AB从(623,145)出发，标签"T_AB=2mg"(535,150)
    - 滑动趋势从(647,140)出发向右，标签"滑动"(680,135)
  - B受力图：f_B(红色，向左，长度50px) + T_OB(蓝色，向左，长度45px) + T_AB(红色，向右，长度50px)
    - f_B从(623,255)出发，标签"f_B=0.5mg"(560,250)
    - T_OB从(623,265)出发，标签"T_OB"(565,270)
    - T_AB从(647,260)出发向右，标签"T_AB=2mg"(695,255)
- 公式框：显示"T_AB_max + μmg = mω₂²r_A → ω₂ = √((2mg+0.5mg)/(m×0.2)) = 5√5 rad/s"
- 步骤指示器：第4个圆点高亮

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  1. 「◀ 上一步」按钮：位于(250,455)，宽100×高35px，点击后回到上一步骤（步骤0时禁用）
  2. 「下一步 ▶」按钮：位于(450,455)，宽100×高35px，点击后进入下一步骤（步骤3时禁用）
  3. 步骤指示器：四个圆点(cx=340/365/390/415, cy=475, r=6)，当前步骤圆点填充蓝色(#1565c0)，其余灰色(#cccccc)
- 教师操作流程：
  1. 页面加载后显示步骤0（初始状态），教师可先介绍题目条件
  2. 点击「下一步 ▶」进入步骤1，讲解AB绳开始出现张力的临界条件
  3. 继续点击「下一步 ▶」进入步骤2，讲解OB绳开始出现张力的临界条件
  4. 继续点击「下一步 ▶」进入步骤3，讲解A即将滑动的临界条件
  5. 可随时点击「◀ 上一步」回退到任意步骤复习
  6. 每一步的公式框同步更新，教师可对照公式讲解推导过程

[技术实现]
- JS 库选择：原生 SVG（简单几何图形、箭头、文本标注，无需额外库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+  y=0
  |                                                  |
  |     [圆盘俯视图区]      [受力分析区]              |
  |                                                  |
  |         ___________                              |
  |       /    O  B  A  \                            |
  |      |   (240,210)   |  A的受力                  |
  |       \___________/  |  [方块]←f_A               |
  |         |           |  [方块]←T_AB               |
  |         |           |                            |
  |         |           |  B的受力                    |
  |         |           |  [方块]←f_B  T_AB→[方块]   |
  |         |           |  [方块]←T_OB               |
  |                                                  |
  +--------------------------------------------------+  y=370
  |  [公式框: mω₀²r_A = μmg → ω₀ = 5 rad/s]          |  y=385
  +--------------------------------------------------+  y=425
  |           [◀ 上一步]  ●○○○  [下一步 ▶]            |  y=455
  +--------------------------------------------------+  y=490
  ```
- 关键实现要点：
  1. **状态机设计**：全局变量 `currentStep` (0~3)，`updateScene(step)` 函数根据步骤更新所有SVG元素的样式和可见性
  2. **细线状态管理**：
     - OB细线：步骤0灰色→步骤2蓝色
     - AB细线：步骤0灰色→步骤1蓝色→步骤3红色
  3. **受力箭头管理**：每个力箭头作为独立SVG元素，根据步骤设置颜色、线宽、长度和可见性
  4. **公式文本更新**：`scene1-formula-text` 的textContent根据步骤切换
  5. **按钮状态**：步骤0时"上一步"禁用，步骤3时"下一步"禁用
  6. **CSS transition**：细线颜色和线宽变化使用0.3s过渡动画
  7. **箭头绘制**：使用SVG `<marker>` 定义箭头头部，力箭头用 `<line>` + marker-end
  8. **滑动趋势箭头**：使用 `stroke-dasharray="5,3"` 实现虚线效果
- ID 命名规范：所有交互元素ID以 `scene1-` 为前缀
  - scene1-disk, scene1-axis, scene1-rotation-arrow
  - scene1-object-a, scene1-object-b
  - scene1-line-ob, scene1-line-ab
  - scene1-label-o, scene1-label-a, scene1-label-b
  - scene1-label-ra, scene1-label-rb, scene1-label-ma, scene1-label-mb
  - scene1-force-a-f, scene1-force-a-tab, scene1-force-a-slide
  - scene1-force-b-f, scene1-force-b-tob, scene1-force-b-tab
  - scene1-formula-box, scene1-formula-text
  - scene1-btn-prev, scene1-btn-next
  - scene1-indicator-0, scene1-indicator-1, scene1-indicator-2, scene1-indicator-3
- IIFE 隔离：所有JS代码包在 `(function() { 'use strict'; ... })();` 中，避免全局污染
- 箭头marker定义：在 `<defs>` 中定义三种marker（灰色、蓝色、红色），分别对应不同状态的力箭头
