[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「上一步」按钮：位置(250,460)，大小80×30，点击返回上一步骤，步骤0时禁用
  - 「下一步」按钮：位置(470,460)，大小80×30，点击进入下一步骤，步骤4时禁用
  - 步骤指示文本：位置(400,475)，显示"步骤 X/4"
- 教师操作流程：
  1. 图示加载后显示步骤0（基础场景），教师介绍物理场景和已知条件
  2. 点击「下一步」进入步骤1，讲解水平轨道上的受力分析（电场力、摩擦力、重力、支持力）
  3. 点击「下一步」进入步骤2，讲解P点（半圆中点）的受力分析
  4. 点击「下一步」进入步骤3，讲解L点（最高点）的受力分析
  5. 点击「下一步」进入步骤4，讲解L点临界条件（支持力为零，重力提供向心力）
  6. 可随时点击「上一步」回退到任意步骤复习

- 关键实现要点：
  1. 状态机设计：用变量 `currentStep`（0~4）管理当前步骤，每个步骤对应一组可见元素
  2. 元素管理：所有动态元素（物块、受力箭头、运动轨迹、高亮框）用 `<g>` 分组，通过 `display` 或 `opacity` 控制显隐
  3. 物块移动：用 SVG `<animate>` 或 JS 修改 `transform` 属性实现平滑移动，duration=0.5s，ease-in-out
  4. 受力箭头：用 `<line>` + `<marker-end>` 实现箭头，不同颜色区分力类型
  5. 运动轨迹：用 `<path>` 绘制，`stroke-dasharray="5,5"` 实现虚线效果
  6. 半圆轨道：用 `<path d="M 200 360 A 130 130 0 0 1 200 100"/>` 绘制左凸半圆
  7. 电场箭头：用 `<marker>` 定义左向箭头，`marker-end` 附加到电场线左端
  8. 临界状态物块：用虚线描边矩形 `<rect stroke-dasharray="3,3">` 表示
  9. 按钮禁用：步骤0时"上一步"按钮 `opacity=0.4` 且不可点击，步骤4时"下一步"同理
- ID 命名规范：所有交互元素 ID 以 `scene1-` 为前缀
  - 按钮：`scene1-prev-btn`, `scene1-next-btn`
  - 物块：`scene1-block`
  - 运动轨迹：`scene1-trajectory`
  - 受力箭头组：`scene1-forces-step1`, `scene1-forces-step2`, `scene1-forces-step3`
  - 临界条件框：`scene1-critical-box`
  - 步骤指示：`scene1-step-label`
- IIFE 隔离：所有 JS 代码包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染
- SVG marker 定义：在 `<defs>` 中定义蓝色、红色、绿色、橙色箭头 marker，分别对应不同力的箭头
