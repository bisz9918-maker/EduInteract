    **题目原文：**

    在光滑绝缘的水平面上，存在平行于水平面向右的匀强电场，电场强度为E．水平面上放置两个静止的小球A和B（均可看作质点），两小球质量均为m，A球带电荷量为+q，B球不带电，A、B连线与电场线平行．开始时两球相距L，在电场力作用下，A球开始运动（此时为计时零点，即t=0），后与B球发生对心碰撞，碰撞过程中A、B两球总动能无损失．设在各次碰撞过程中，A、B两球间无电量转移，且不考虑两球碰撞时间及两球间的万有引力．求：
    （1）第一次碰撞结束瞬间A、B两球的速度各为多大？
    （2）从计时零点到即将发生第三次碰撞这段过程中，共经过多长时间？
    （3）从计时零点到即将发生第n次碰撞这段过程中，小球A经过的位移大小为多少？

    **题目分析：**

    本题核心物理过程为：带电小球A在匀强电场中受恒力F=qE作用做匀加速运动，与静止的不带电小球B发生多次弹性碰撞。由于两球质量相等，弹性碰撞时两球速度交换。碰撞后A从较低速度（或静止）重新加速追赶B，形成周期性追赶-碰撞过程。

    **关键物理规律：**
    - A球加速度恒定：a = qE/m
    - 质量相等弹性碰撞：两球速度交换
    - 每次碰撞间隔时间相等：Δt = 2v₀/a（v₀为第一次碰撞前A的速度）
    - 第k次碰撞前A的速度为kv₀，B的速度为(k-1)v₀

    **整体讲解思路：**

    本题讲解分三个层次：
    1. **物理过程可视化**：通过动画展示A、B两球的运动轨迹和碰撞过程，帮助学生建立直观认识
    2. **速度-时间图像分析**：通过v-t图展示速度变化规律，发现碰撞间隔时间相等的不变量
    3. **代数推导总结**：归纳第n次碰撞的通用公式

    **图示规划说明：**

    规划两个互补的交互式图示：
    - **Scene 1（物理运动动画）**：展示电场中两球的实际运动过程，分步演示从初始状态到多次碰撞的完整过程，配合速度矢量箭头和关键数据标注
    - **Scene 2（速度-时间图像）**：展示A、B两球速度随时间的变化曲线，碰撞时刻用竖线标记，帮助学生发现速度交换规律和时间间隔规律
    </TEXT_1>

    **Scene 1 教学说明：**

    本图示通过分步动画展示两球在电场中的完整运动过程，帮助教师引导学生逐步理解碰撞规律。

    **引导步骤：**

    1. **步骤0→步骤1（第一次碰撞前）**：引导学生观察A球在电场力作用下从静止开始匀加速运动，B球保持静止。提问："A球受什么力？加速度多大？"引导学生写出a=qE/m，并由运动学公式v²=2aL推导出碰撞前速度v₀=√(2qEL/m)。

    2. **步骤2→步骤3（第一次碰撞）**：强调"质量相等的弹性碰撞，两球速度交换"这一核心结论。碰撞前v_A=v₀、v_B=0，碰撞后v_A=0、v_B=v₀。可让学生用动量守恒mv₀=mv_A'+mv_B'和能量守恒½mv₀²=½mv_A'²+½mv_B'²自行验证。

    3. **步骤4→步骤5（第二次碰撞）**：引导学生分析碰撞后A从静止重新加速追赶B的过程。设经过时间t₁追上，由½at₁²=v₀t₁得t₁=2v₀/a。此时A的速度v_A=at₁=2v₀，B的速度仍为v₀。碰撞后速度交换：v_A=v₀、v_B=2v₀。

    4. **步骤6→步骤7（第三次碰撞及规律）**：同理分析第三次碰撞过程，发现碰撞间隔时间仍为2v₀/a。引导学生归纳通式：第k次碰撞前v_A=kv₀、v_B=(k-1)v₀，碰撞间隔Δt=2v₀/a为定值。

    **关键公式推导：**

    - 加速度：a = qE/m
    - 第一次碰撞前速度：v₀ = √(2aL) = √(2qEL/m)
    - 碰撞间隔时间：Δt = 2v₀/a = 2√(2mL/qE)
    - 第k次碰撞前：v_A = kv₀，v_B = (k-1)v₀

    **Scene 2 教学说明：**

    本图示通过v-t图像将抽象的速度变化规律可视化，是本题解题的核心工具。

    **引导步骤：**

    1. **步骤0→步骤1（建立坐标系）**：在v-t图中，A球从静止开始匀加速，图线为过原点的斜线，斜率等于加速度a=qE/m。B球静止，图线为t轴上的水平线。两线交点对应第一次碰撞时刻t₁。由v₀=at₁和v₀²=2aL得t₁=√(2L/a)。

    2. **步骤2（第一次碰撞）**：碰撞瞬间两球速度交换，在v-t图上表现为A的图线从v₀垂直下降到0，B的图线从0垂直上升到v₀。强调碰撞时间极短，在图上用垂直线表示。

    3. **步骤3→步骤4（第二次碰撞）**：碰撞后A从0重新加速（斜线斜率仍为a），B以v₀匀速（水平线）。两线再次交于t₂时刻。由运动学分析可知t₂-t₁=2v₀/a。碰撞时A速度2v₀、B速度v₀，交换后A为v₀、B为2v₀。

    4. **步骤5→步骤6（第三次碰撞及规律）**：同理分析，发现t₃-t₂=2v₀/a，碰撞间隔为定值。引导学生观察：每次碰撞前A的速度比B多v₀，碰撞后交换。

    **关键结论：**

    - 碰撞间隔时间：Δt = 2v₀/a = 2√(2mL/qE)
    - 第k次碰撞时刻：t_k = t₁ + (k-1)Δt = √(2L/a) + (k-1)·2√(2L/a) = (2k-1)√(2L/a)
    - 第n次碰撞前A的总位移：S_n = L(2n² - 2n + 1)

    **第(2)问解答：**
    到第三次碰撞的时间 T = t₃ = (2×3-1)√(2L/a) = 5√(2mL/qE)

    **第(3)问解答：**
    第k次碰撞到第k+1次碰撞期间，A的位移为s_k = 4kL（k≥1），第一次碰撞前位移s₀=L。
    到第n次碰撞前总位移：S_n = L + Σ(k=1到n-1) 4kL = L + 4L·n(n-1)/2 = L(2n²-2n+1)
    </TEXT_3>

    **完整解答总结：**

    **第(1)问：** 第一次碰撞结束瞬间，由质量相等弹性碰撞的速度交换规律：
    - v_A = 0
    - v_B = v₀ = √(2qEL/m)

    **第(2)问：** 从t=0到即将发生第三次碰撞：
    - 第一次碰撞时刻：t₁ = √(2L/a) = √(2mL/qE)
    - 碰撞间隔：Δt = 2v₀/a = 2√(2mL/qE)
    - 第三次碰撞时刻：t₃ = t₁ + 2Δt = 5√(2mL/qE)
    - 答案：T = 5√(2mL/qE)

    **第(3)问：** 到第n次碰撞前A的总位移：
    - S_n = L(2n² - 2n + 1)

    **课堂讲解建议：**

    1. 先用Scene 1的物理动画建立直观认识，让学生理解"追赶-碰撞-再追赶"的过程
    2. 再用Scene 2的v-t图进行定量分析，引导学生从图像中发现碰撞间隔相等的规律
    3. 最后进行代数推导，归纳出第n次碰撞的通用公式
    4. 强调"质量相等弹性碰撞速度交换"这一核心结论，它是解题的关键
    5. 可让学生思考：如果两球质量不等，碰撞规律会如何变化？作为拓展思考题
