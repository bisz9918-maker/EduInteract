[图示主题与整合说明]
- 本图示主题：A、B两球速度-时间（v-t）图像，展示多次碰撞的速度变化规律
- 整合的步骤/概念：v-t坐标系建立 → 第一次碰撞前A的匀加速线段 → 碰撞时刻速度交换的竖直线 → 后续各次碰撞的速度变化 → 时间间隔规律标注 → 位移面积标注
- 教学价值：教师通过分步按钮逐步揭示v-t图中的关键特征（碰撞时刻、速度交换、时间间隔相等），帮助学生从图像中发现"等间隔碰撞"和"速度逐次递增"的规律，最终推导出总位移公式 S_n = L(2n²-2n+1)

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  * 「◀ 上一步」按钮：位于控件栏左侧(x=250, y=455)，点击返回上一步骤
  * 「步骤X/6」文字：位于控件栏中央(x=400, y=465)，显示当前步骤编号
  * 「下一步 ▶」按钮：位于控件栏右侧(x=550, y=455)，点击进入下一步骤
- 教师操作流程：
  1. 图示加载后显示空白坐标系（步骤0），教师可先介绍v-t图的基本概念
  2. 点击「下一步▶」逐步展示A、B两球的运动过程
  3. 每步展示后，教师可暂停讲解当前阶段的物理意义
  4. 点击「◀上一步」可回退到任意步骤进行复习
  5. 到达步骤6后，教师可结合规律总结框讲解碰撞间隔公式和总位移公式
  6. 按钮在首尾步骤自动禁用（步骤0时「上一步」禁用，步骤6时「下一步」禁用）

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无需外部库，v-t图为简单几何图形，SVG最适合）
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  +---------------------------------------------------+
  |                                                    |
  |  v  |                                              |
  |  ^  |              A(蓝)  B(绿)                     |
  |  |  |           /---\    /---\    /---\             |
  |  |  |          /     \  /     \  /     \            |
  |  |  |         /       \/       \/       \           |
  |  |  |        /        /\       /\       \           |
  |  |  |       /        /  \     /  \      \          |
  |  |  |      /        /    \   /    \     \          |
  |  |  |     /        /      \ /      \    \          |
  |  |  |    /        /        X        X   \          |
  |  |  |   /        /        |        |    \         |
  |  |  |  /        /         |        |     \        |
  |  |  | /        /          |        |      \       |
  |  O--+--------/-----------+---------+-------+-----> t
  |     t1      t2          t3        Δt      Δt      |
  |                                                    |
  |                              [规律总结框]           |
  |                                                    |
  |         [◀上一步]  [步骤X/6]  [下一步▶]            |
  +---------------------------------------------------+
  ```
- 关键实现要点：
  1. **状态机设计**：用变量 `currentStep`（0~6）管理当前步骤，每个步骤对应一组可见元素
  2. **元素显隐控制**：每个SVG元素设置 `data-step` 属性表示其首次出现的步骤号，切换步骤时根据 `data-step <= currentStep` 控制 `opacity` 或 `display`
  3. **动画效果**：图线绘制使用 `stroke-dasharray` + `stroke-dashoffset` 动画，从起点向终点逐步绘制，持续0.6s
  4. **坐标计算**：所有坐标已精确规划，直接硬编码在SVG元素中
  5. **事件绑定**：按钮点击事件更新 `currentStep` 并调用 `updateView()` 函数刷新显示
  6. **按钮状态**：步骤0时「上一步」按钮 `disabled=true`，步骤6时「下一步」按钮 `disabled=true`
- ID 命名规范：所有交互元素ID以 `scene2-` 为前缀，如 `scene2-btn-prev`、`scene2-btn-next`、`scene2-step-label`、`scene2-svg`、`scene2-line-a-1` 等
- IIFE 隔离：所有JS代码包裹在 `(function() { ... })()` 中，避免全局污染
- 位移面积填充：使用 `<polygon>` 元素，`fill="#1565c0"`，`fill-opacity="0.15"`，在步骤6时显示
- 规律总结框：使用 `<rect>` + `<text>` 组合，`rect` 设置 `fill="#fff3e0"`、`stroke="#c62828"`、`stroke-width="1"`、`rx="4"`（圆角）
