    **题目原文：**

    如图所示，两平行金属板水平放置，板间存在垂直纸面的匀强磁场和电场强度为E的匀强电场。金属板右下方以MN为上边界，PQ为下边界，MP为左边界的区域内，存在垂直纸面向外的匀强磁场，磁场宽度为d，MN与下极板等高，MP与金属板右端在同一竖直线。一个电荷量为q、质量为m的正离子以初速度v₀在两板间沿平行于金属板的虚线射入金属板间。不计粒子重力。

    (1) 已知离子恰好做匀速直线运动，求金属板间的磁感应强度B₀；

    (2) 若撤去板间磁场B₀，离子恰好从下极板的右侧边缘射出电场，方向与水平方向成30°角，离子进入磁场运动后从磁场边界点射出，求该磁场的磁感应强度B的大小。

    **题目分析：**

    本题是带电粒子在复合场中运动的经典题目，涉及两个核心物理过程：

    1. **速度选择器原理（第1问）**：电场力与洛伦兹力平衡，粒子做匀速直线运动。
    2. **类平抛运动 + 磁场中圆周运动（第2问）**：撤去磁场后粒子在电场中做类平抛运动，射出后进入磁场做匀速圆周运动。

    **整体讲解思路：**

    - 首先引导学生观察题目原图，明确两个区域的场分布：板间区域（电场+磁场）和右下方区域（仅磁场）。
    - 第1问：通过受力分析，利用平衡条件求解B₀。
    - 第2问：先分析类平抛运动求出射出速度，再分析磁场中圆周运动，利用几何关系求解B。

    **图示规划：**

    规划两个交互式图示：
    - **图示1**：板间运动分析——整合第1问（匀速直线）和第2问前半部分（类平抛运动），通过分步切换展示两种情景。
    - **图示2**：磁场中圆周运动——展示离子进入磁场后的轨迹及几何关系推导。
    </TEXT_1>

    **图示1教学说明：**

    本图示通过三种状态的切换，帮助学生理解带电粒子在复合场中的两种典型运动。

    **状态1讲解要点（匀速直线运动）：**

    1. 引导学生观察：上极板带正电，下极板带负电，电场方向竖直向下
    2. 正离子受电场力 $F_E = qE$，方向向下（与电场方向相同）
    3. 离子同时受洛伦兹力 $F_B = qv_0B_0$，方向需向上才能与电场力平衡
    4. 由左手定则判断：正电荷向右运动，洛伦兹力向上，则磁场方向垂直纸面向里（用"×"表示）
    5. 平衡条件：$qE = qv_0B_0$，解得 $B_0 = \frac{E}{v_0}$

    **状态2讲解要点（类平抛运动）：**

    1. 撤去磁场后，离子仅受电场力，做类平抛运动
    2. 水平方向：匀速运动，速度保持 $v_0$
    3. 竖直方向：匀加速运动，加速度 $a = \frac{qE}{m}$
    4. 离子从下极板右边缘M点射出，速度方向与水平方向成30°角
    5. 速度分解：射出速度大小 $v = \frac{v_0}{\cos 30°} = \frac{2v_0}{\sqrt{3}}$，竖直分速度 $v_y = v_0 \tan 30° = \frac{v_0}{\sqrt{3}}$

    **状态3讲解要点（对比）：**

    引导学生对比两种情景：有磁场时粒子沿直线通过，无磁场时粒子向下偏转。这体现了磁场对带电粒子的"约束"作用，也是速度选择器的工作原理。

    **图示2教学说明：**

    本图示逐步展示离子在磁场中的圆周运动及求解过程。

    **步骤0-1讲解要点（进入磁场与轨迹）：**

    1. 离子从M点以速度v、与水平方向成30°角进入磁场
    2. 磁场方向垂直纸面向外（用"·"表示）
    3. 由左手定则：正电荷斜向右下运动，磁场向外，洛伦兹力指向轨迹的凹侧（左上方）
    4. 离子做匀速圆周运动，轨迹为圆弧

    **步骤2讲解要点（确定圆心）：**

    1. 洛伦兹力始终垂直于速度方向，指向圆心
    2. 过入射点M作速度v的垂线，该线过圆心
    3. 过出射点作出射速度的垂线，该线也过圆心
    4. 两垂线的交点即为圆心O

    **步骤3讲解要点（几何关系推导）：**

    1. 离子从M点以30°角入射，轨迹为圆弧
    2. 由几何关系分析：入射速度方向与MN成30°角，速度垂线与MN成60°角
    3. 关键几何关系：从图中可看出，离子从M点进入，从磁场边界射出
    4. 由几何分析可得半径R与磁场宽度d的关系

    **步骤4讲解要点（求解B）：**

    1. 洛伦兹力提供向心力：$qvB = m\frac{v^2}{R}$
    2. 解得：$R = \frac{mv}{qB}$，即 $B = \frac{mv}{qR}$
    3. 代入 $v = \frac{2v_0}{\sqrt{3}}$ 和几何关系求得的R，即可求出B

    **完整解答：**

    **第(1)问：**
    由平衡条件 $qE = qv_0B_0$，得 $B_0 = \frac{E}{v_0}$，方向垂直纸面向里。

    **第(2)问：**
    离子射出电场时速度 $v = \frac{v_0}{\cos 30°} = \frac{2v_0}{\sqrt{3}}$。
    在磁场中：$qvB = m\frac{v^2}{R}$，得 $R = \frac{mv}{qB}$。
    由几何关系确定R与d的关系后代入求解B。

    **课堂讲解建议：**

    1. **先整体后局部**：先让学生观察全图，明确两个区域的场分布，再分别分析。
    2. **受力分析是关键**：第1问的核心是受力平衡，第2问的核心是洛伦兹力提供向心力。
    3. **几何关系要画图**：圆周运动的几何分析必须借助图示，让学生亲手画圆心、半径、辅助线。
    4. **速度选择器拓展**：第1问实际上是速度选择器原理，可拓展讲解其应用（如质谱仪）。
    5. **注意方向判断**：左手定则是本题的关键工具，需反复练习。
