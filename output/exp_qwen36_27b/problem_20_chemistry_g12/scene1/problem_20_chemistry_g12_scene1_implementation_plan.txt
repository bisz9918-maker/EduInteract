[图示主题与整合说明]
- 本图示主题：饱和NaCl溶液中C-Fe电化学装置的原电池与电解池模式对比
- 整合的步骤/概念：装置结构展示、原电池模式（闭合K₁）的电极反应与电子/离子流向、电解池模式（闭合K₂）的电极反应与电子/离子流向、两种模式的对比分析
- 教学价值：教师通过三个状态切换按钮，依次展示装置初始结构、原电池工作原理（吸氧腐蚀）、电解池工作原理（电解饱和食盐水），帮助学生理解同一装置在不同电路配置下呈现完全不同的电化学行为，强化"有无外接电源决定原电池/电解池"的核心概念

[分步序列]
- 初始状态（状态0）：
  显示元素：烧杯、溶液、C棒、Fe棒、全部导线、K₁开关（断开灰色）、K₂开关（断开灰色）、电源符号、"C"标签、"Fe"标签、"K₁"标签、"K₂"标签、"+"标签、"-"标签、"饱和NaCl溶液"标签
  不显示：电极极性标签、电子流向箭头、离子迁移箭头、离子标签、电极反应式文本框
  教师引导：观察装置结构，识别电源极性（左正右负），两个开关均断开

- 状态1（闭合K₁，原电池模式）：
  视觉变化：
  - K₁开关闭合高亮（#1565c0蓝色），K₂保持断开灰色
  - 新增电极极性标签：C上方显示"正极"，Fe上方显示"负极"（#e8f5e9背景）
  - 新增电子流向箭头（蓝色#1565c0）：从Fe棒顶部(515,170)→节点B(515,120)→节点A(285,120)→C棒顶部(285,170)，箭头方向Fe→C
  - 新增"e⁻"标签：沿导线约(400,100)位置
  - 新增离子迁移箭头（红色#c62828虚线）：
    - 阴离子箭头：从溶液中部(400,320)指向Fe极(500,320)，标注"Cl⁻"、"OH⁻"
    - 阳离子箭头：从溶液中部(400,350)指向C极(300,350)，标注"Na⁺"
  - 新增电极反应式文本框：
    - C极左侧(60,250)-(240,300)："O₂ + 2H₂O + 4e⁻ = 4OH⁻"
    - Fe极右侧(560,250)-(740,300)："Fe - 2e⁻ = Fe²⁺"
  教师引导：无外接电源构成原电池，活泼金属Fe作负极被氧化，中性溶液中C极发生吸氧腐蚀

- 状态2（闭合K₂，电解池模式）：
  视觉变化：
  - K₂开关闭合高亮（#1565c0蓝色），K₁保持断开灰色
  - 电源显示电流方向（可在电源旁加小箭头指示）
  - 新增电极极性标签：C上方显示"阳极"，Fe上方显示"阴极"（#e8f5e9背景）
  - 新增电子流向箭头（蓝色#1565c0）：
    - 从电源负极(465,120)→节点B(515,120)→Fe棒(515,170)，箭头指向Fe
    - 从C棒(285,170)→节点A(285,120)→电源正极(455,120)，箭头指向电源
  - 新增"e⁻"标签：沿导线约(400,135)位置
  - 新增离子迁移箭头（红色#c62828虚线）：
    - 阴离子箭头：从溶液中部(400,320)指向C极(300,320)，标注"Cl⁻"
    - 阳离子箭头：从溶液中部(400,350)指向Fe极(500,350)，标注"Na⁺"、"H⁺"
  - 新增电极反应式文本框：
    - C极左侧(60,250)-(240,300)："2Cl⁻ - 2e⁻ = Cl₂↑"
    - Fe极右侧(560,250)-(740,300)："2H⁺ + 2e⁻ = H₂↑"
  教师引导：有外接电源构成电解池，阳极C发生氧化反应（Cl⁻放电），阴极Fe发生还原反应（H⁺放电）

[交互方案]
- 交互类型：多状态切换（3个按钮）
- 控件说明：
  - 按钮1"初始状态"：位于(180,450)-(290,480)，点击后切换到状态0，显示完整装置结构，无电流流动
  - 按钮2"闭合K₁（原电池）"：位于(310,450)-(490,480)，点击后切换到状态1，展示原电池模式
  - 按钮3"闭合K₂（电解池）"：位于(510,450)-(650,480)，点击后切换到状态2，展示电解池模式
- 教师操作流程：
  1. 默认显示状态0（初始状态），教师引导学生观察装置结构
  2. 点击"闭合K₁（原电池）"按钮，图示切换为原电池模式，教师讲解Fe作负极被氧化、C极吸氧腐蚀
  3. 点击"闭合K₂（电解池）"按钮，图示切换为电解池模式，教师讲解阳极Cl⁻放电、阴极H⁺放电
  4. 可随时点击"初始状态"按钮回到初始状态重新讲解
  5. 三个按钮互斥，当前激活按钮以蓝色高亮显示

[技术实现]
- JS 库选择：原生 SVG（本场景为简单几何图形+标注，无需复杂库，原生SVG足以实现所有视觉元素和交互）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌────────────────────────────────────────────────────┐
  │                                                    │
  │              K₁                                     │
  │            ┌──────┐                                │
  │            │      │                                │
  │     ┌──────┤      ├──────┐                        │
  │     │      │      │      │                        │
  │     │  K₂  │  +|- │      │                        │
  │     │      │      │      │                        │
  │     └──────┴──────┴──────┘                        │
  │     │                  │                          │
  │     │ C                │ Fe                       │
  │     │                  │                          │
  │  ┌──┴──────────────────┴──┐                       │
  │  │  ~~~ 饱和NaCl溶液 ~~~  │  饱和NaCl溶液          │
  │  │  ~~~  (溶液区域) ~~~   │                       │

  └────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：定义3个状态（0/1/2），每个状态对应一组SVG元素的显示/隐藏/样式变化
  2. 状态切换函数：switchState(stateNum)，根据stateNum更新：
     - K₁/K₂开关的闭合/断开样式（颜色、连线）
     - 电极极性标签的显示/隐藏和文本内容
     - 电子流向箭头的显示/隐藏和路径
     - 离子迁移箭头的显示/隐藏和方向
     - 电极反应式文本框的显示/隐藏和文本内容
     - 按钮激活状态（当前按钮蓝色高亮，其余灰色）
  3. 开关符号绘制：断开时用断开的线段表示，闭合时用连通的线段表示
  4. 电源符号绘制：长线（正极）+ 短线（负极），标注"+"和"-"
  5. 箭头绘制：使用SVG <marker>定义箭头头部，<line>或<path>绘制箭身
  6. 动画过渡：状态切换时使用CSS transition实现淡入淡出效果（opacity 0→1，duration 0.3s）
  7. 事件绑定：三个按钮分别绑定click事件，调用switchState(0/1/2)
- ID 命名规范：所有交互元素ID以 scene1- 为前缀
  - scene1-btn-initial、scene1-btn-k1、scene1-btn-k2
  - scene1-switch-k1、scene1-switch-k2
  - scene1-electrode-c、scene1-electrode-fe
  - scene1-label-c、scene1-label-fe
  - scene1-label-k1、scene1-label-k2
  - scene1-power、scene1-label-plus、scene1-label-minus
  - scene1-label-solution
  - scene1-polarity-c、scene1-polarity-fe
  - scene1-reaction-c、scene1-reaction-fe
  - scene1-electron-flow、scene1-electron-label
  - scene1-ion-arrows、scene1-ion-labels
  - scene1-beaker、scene1-solution-fill、scene1-liquid-line
  - scene1-wire-group
- IIFE 隔离：所有 JS 代码包裹在 (function() { 'use strict'; ... })() 中，避免全局污染
- SVG 结构：使用 <g> 分组管理不同状态的元素，通过 class 控制显示/隐藏
  - .state-only-0：仅在状态0显示的元素
  - .state-only-1：仅在状态1显示的元素
  - .state-only-2：仅在状态2显示的元素
  - .always-visible：始终显示的元素
  - 状态切换时通过切换 SVG 容器的 class（如 scene1-state-0/1/2）来控制子元素显示
