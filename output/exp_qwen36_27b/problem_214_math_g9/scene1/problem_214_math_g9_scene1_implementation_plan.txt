[图示主题与整合说明]
- 本图示主题：△ABC中垂直平分线性质与∠EAF的角度推导
- 整合的步骤/概念：①展示△ABC及已知条件∠BAC=110°；②添加AB的垂直平分线EG，推导EA=EB及∠EAB=∠B；③添加AC的垂直平分线FH，推导FA=FC及∠FAC=∠C；④连接AE、AF，计算∠EAF=40°
- 教学价值：教师通过分步导航逐步展示几何推导过程，从已知条件出发，利用垂直平分线性质（点到线段两端距离相等）推导等腰三角形底角相等，最终通过角度差计算得出∠EAF=40°。分步呈现可帮助学生理解每一步的逻辑依据，教师可随时回退复习关键步骤。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位置(250,450)，宽100px，高30px，步骤0时禁用，其他步骤启用
  - 「下一步 ▶」按钮：位置(450,450)，宽100px，高30px，步骤3时禁用，其他步骤启用
  - 步骤指示器：位置(370,455)，显示"步骤 X/3"
- 教师操作流程：
  1. 图示加载后显示步骤0（△ABC及已知条件）
  2. 教师点击「下一步 ▶」逐步展示推导过程
  3. 每步新增元素以淡入动画出现（0.3s ease-in）
  4. 教师可随时点击「◀ 上一步」回退到前一步
  5. 到达步骤3后显示最终答案和结论框

- 关键实现要点：
  1. 状态机设计：当前步骤currentStep（0~3），每个步骤对应一组可见元素
  2. 元素显隐控制：使用SVG元素的display属性或opacity动画控制显隐
  3. 动画曲线：新增元素使用0.3s ease-in淡入动画
  4. 事件绑定：按钮点击事件切换currentStep，更新可见元素集合
  5. 角弧绘制：使用SVG path的A命令绘制圆弧，根据角度计算起点和终点坐标
  6. 垂直平分线延长：从交点经中点向外延长约30px，确保视觉上穿过线段
  7. 等长标记：在线段中点附近绘制垂直于线段的短划线
- ID 命名规范：所有交互元素ID以`scene1-`为前缀（如`scene1-btn-next`、`scene1-btn-prev`、`scene1-triangle`、`scene1-perp-bisector-ab`等）
- IIFE 隔离：所有JS代码包裹在`(function() { ... })()`中，避免全局污染
- 推导文字面板使用SVG text元素，每行文字用tspan分行，逐步显示时控制opacity
