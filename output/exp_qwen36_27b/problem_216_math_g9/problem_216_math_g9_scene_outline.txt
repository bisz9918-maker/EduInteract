    **题目原文：**

    如图，抛物线 $y = ax^2 + bx + c$（$a \neq 0$）的对称轴为直线 $x = 1$，与 $x$ 轴的一个交点坐标为 $(-1, 0)$，其部分图象如图所示，下列结论：① $4ac < b^2$；② $3a + c > 0$；③ 当 $x > 0$ 时，$y$ 随 $x$ 的增大而减小；④ 当 $y > 0$ 时，$x$ 的取值范围是 $-1 < x < 3$；⑤ 方程 $ax^2 + bx + c = 0$ 的两个根是 $x_1 = -1$，$x_2 = 3$；其中结论正确的个数是（  ）

    A．4个  B．3个  C．2个  D．1个

    **题目分析：**

    本题是一道二次函数图像性质的综合判断题。已知条件包括：对称轴 $x = 1$、一个 $x$ 轴交点 $(-1, 0)$、从图像可读出 $y$ 轴交点 $(0, 3)$。需要利用这些信息逐一验证五个结论。

    核心解题思路：
    1. 从图像中提取已知信息：对称轴 $x = 1$，即 $-b/(2a) = 1$，得 $b = -2a$
    2. 利用对称性求另一个 $x$ 轴交点：$(-1, 0)$ 关于 $x = 1$ 的对称点为 $(3, 0)$
    3. 由过点 $(0, 3)$ 得 $c = 3$
    4. 由过点 $(-1, 0)$ 得 $a - b + c = 0$，代入 $b = -2a$、$c = 3$，得 $3a + 3 = 0$，即 $a = -1$，$b = 2$
    5. 抛物线解析式为 $y = -x^2 + 2x + 3$
    6. 逐一验证五个结论

    **图示规划说明：**

    本题规划为两个图示场景：
    - **Scene 1**：抛物线图像分析与隐含条件推导——从题目原图出发，逐步标注已知条件，利用对称性推导出另一个交点和顶点坐标，帮助学生建立完整的图像认知。
    - **Scene 2**：五个结论的逐一验证——基于完整的抛物线图像，分步验证每个结论，用颜色区分正确与错误，最终统计正确个数。

    **Scene 1 教学说明：抛物线图像分析与隐含条件推导**

    本图示的核心目标是帮助学生从题目给出的部分图像中，提取全部可用信息，为后续验证结论做准备。

    **讲解要点：**

    1. **步骤 0→1：识别已知条件**
    引导学生观察原图，找出所有已知信息：
    - 对称轴为 $x = 1$（虚线标注）
    - 抛物线过点 $(-1, 0)$（$x$ 轴交点）
    - 抛物线过点 $(0, 3)$（$y$ 轴交点，即 $c = 3$）
    - 抛物线开口向下，说明 $a < 0$

    2. **步骤 1→2：利用对称性**
    这是本题的关键技巧。教师应强调：
    - 抛物线关于对称轴对称
    - 点 $(-1, 0)$ 到对称轴 $x = 1$ 的距离为 $2$
    - 所以对称点到对称轴的距离也为 $2$，即 $x = 1 + 2 = 3$
    - 另一个 $x$ 轴交点为 $(3, 0)$

    3. **步骤 2→3：求解析式**
    利用已知条件列方程：
    - 对称轴：$-b/(2a) = 1$，得 $b = -2a$
    - 过 $(-1, 0)$：$a - b + c = 0$
    - 过 $(0, 3)$：$c = 3$
    - 代入得 $a - (-2a) + 3 = 0$，即 $3a = -3$，$a = -1$
    - 所以 $b = 2$，$c = 3$
    - 解析式：$y = -x^2 + 2x + 3$
    - 顶点：$x = 1$ 时，$y = -1 + 2 + 3 = 4$，顶点 $(1, 4)$

    4. **步骤 3→4：完整视图**
    展示所有信息，让学生对抛物线有完整认知，为下一步验证结论做准备。

    **Scene 2 教学说明：五个结论的逐一验证**

    本图示的核心目标是引导学生利用 Scene 1 中推导出的全部信息，逐一判断五个结论的正误。

    **讲解要点：**

    1. **结论① $4ac < b^2$（正确 ✓）**
    - 思路：$b^2 - 4ac$ 是二次方程的判别式 $\Delta$
    - 从图像看，抛物线与 $x$ 轴有两个交点，说明 $\Delta > 0$
    - 即 $b^2 - 4ac > 0$，所以 $b^2 > 4ac$，即 $4ac < b^2$
    - 验证：$a = -1$，$b = 2$，$c = 3$，$4ac = -12$，$b^2 = 4$，$-12 < 4$ ✓

    2. **结论② $3a + c > 0$（错误 ✗）**
    - 思路：利用已知条件 $a - b + c = 0$ 和 $b = -2a$
    - 代入得 $a - (-2a) + c = 0$，即 $3a + c = 0$
    - 所以 $3a + c > 0$ 不成立（等于 0，不是大于 0）
    - 验证：$3 \times (-1) + 3 = 0$，$0 > 0$ 不成立 ✗

    3. **结论③ 当 $x > 0$ 时，$y$ 随 $x$ 的增大而减小（错误 ✗）**
    - 思路：观察图像或利用解析式
    - 抛物线开口向下，对称轴 $x = 1$
    - 在 $x < 1$ 时，$y$ 随 $x$ 增大而增大；在 $x > 1$ 时，$y$ 随 $x$ 增大而减小
    - 所以当 $0 < x < 1$ 时，$y$ 是递增的，结论说"当 $x > 0$ 时 $y$ 减小"不准确
    - 图示中用蓝色高亮 $0 < x < 1$ 递增区间，红色高亮 $x > 1$ 递减区间

    4. **结论④ 当 $y > 0$ 时，$-1 < x < 3$（正确 ✓）**
    - 思路：$y > 0$ 即抛物线在 $x$ 轴上方的部分
    - 两个 $x$ 轴交点为 $x = -1$ 和 $x = 3$
    - 开口向下，所以 $x$ 轴上方的部分在两个交点之间
    - 即 $-1 < x < 3$ ✓
    - 图示中用绿色半透明填充该区域

    5. **结论⑤ 方程 $ax^2 + bx + c = 0$ 的根是 $x_1 = -1$，$x_2 = 3$（正确 ✓）**
    - 思路：方程的根即抛物线与 $x$ 轴交点的横坐标
    - 两个交点为 $(-1, 0)$ 和 $(3, 0)$
    - 所以 $x_1 = -1$，$x_2 = 3$ ✓

    **总结：**

    正确的结论有 3 个：①、④、⑤，答案为 **B**。

    **课堂讲解建议：**

    - 在 Scene 1 中，重点强调"对称性"这一核心技巧，这是解决本题的关键
    - 在 Scene 2 中，引导学生区分"代数验证"和"图像观察"两种方法：结论①②适合代数验证，结论③④⑤适合图像观察
    - 提醒学生注意结论③的陷阱：$x > 0$ 包含了递增和递减两个区间，不能一概而论
    - 结论②也是一个常见陷阱：$3a + c = 0$ 而不是 $> 0$，学生容易忽略等号的情况
