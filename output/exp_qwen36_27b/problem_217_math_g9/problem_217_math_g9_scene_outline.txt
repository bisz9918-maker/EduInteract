    **题目原文：**

    如图，二次函数 $y=x^2-2x-3$ 的图像与 $x$ 轴交于 $A,B$ 两点，与 $y$ 轴交于点 $C$，下列说法：① $AB=4$；② $\angle ABC=45^\circ$；③ 当 $0<x<2$ 时，$-4\le y<-3$；④ 当 $x>1$ 时，$y$ 随 $x$ 的增大而增大，其中结论正确的个数有（ ）

    A．1个    B．2个    C．3个    D．4个

    **题目分析：**

    本题是一道二次函数综合判断题，考查学生对二次函数图像性质的理解，包括：
    - 与坐标轴交点的求法（解方程）
    - 线段长度的计算
    - 角度计算（利用等腰直角三角形）
    - 函数在给定区间的值域
    - 函数的单调性

    **整体讲解思路：**

    1. 首先求出 A、B、C 三点的坐标，这是后续所有判断的基础
    2. 逐一验证四个结论
    3. 通过交互式图示，让学生直观看到每个结论对应的图像特征

    **教学说明：**

    本图示通过分步导航，引导学生逐步验证四个结论。教师可按以下思路讲解：

    **步骤1：求交点坐标，验证 AB=4**

    1. 令 $y=0$，解方程 $x^2-2x-3=0$
    2. 因式分解：$(x-3)(x+1)=0$，得 $x_1=-1, x_2=3$
    3. 所以 $A(-1,0), B(3,0)$
    4. $AB = 3-(-1) = 4$，结论①正确

    **步骤2：验证 ∠ABC=45°**

    1. 令 $x=0$，得 $y=-3$，所以 $C(0,-3)$
    2. 连接 BC，观察 Rt△OBC
    3. $OB = 3, OC = 3$，即 $OB = OC$
    4. 在 Rt△OBC 中，$OB = OC$，所以 △OBC 是等腰直角三角形
    5. 因此 $\angle OBC = 45^\circ$，即 $\angle ABC = 45^\circ$，结论②正确

    **步骤3：验证当 0<x<2 时，-4≤y<-3**

    1. 求顶点坐标：$x = -\frac{b}{2a} = \frac{2}{2} = 1$
    2. 代入得 $y = 1-2-3 = -4$，顶点为 $(1,-4)$
    3. 当 $x=0$ 时，$y=-3$；当 $x=2$ 时，$y=4-4-3=-3$
    4. 在区间 $(0,2)$ 内，$x=1$ 时取得最小值 $y=-4$
    5. 端点处 $y=-3$ 但不包含（因为 $0<x<2$ 是开区间）
    6. 所以 $-4 \le y < -3$，结论③正确

    **步骤4：验证当 x>1 时，y 随 x 增大而增大**

    1. 对称轴为 $x=1$
    2. 抛物线开口向上（$a=1>0$）
    3. 在对称轴右侧（$x>1$），函数单调递增
    4. 结论④正确

    **总结：**

    四个结论全部正确，答案为 **D．4个**。

    **课堂讲解建议：**

    - 在步骤1时，引导学生回忆求二次函数与 x 轴交点的方法（令 y=0 解方程）
    - 在步骤2时，强调等腰直角三角形的判定和性质
    - 在步骤3时，提醒学生注意开区间和闭区间的区别，以及顶点在区间内的情况
    - 在步骤4时，复习二次函数的单调性与对称轴的关系
    - 最后总结：四个结论都正确，这道题考查了二次函数的多个核心性质
