[图示主题与整合说明]
- 本图示主题：二次函数 y=x²-2x-3 的图像及其四个结论的逐步验证
- 整合的步骤/概念：
  1. 绘制抛物线图像，标注与坐标轴交点 A、B、C
  2. 验证结论① AB=4（计算 A、B 间距）
  3. 验证结论② ∠ABC=45°（利用等腰直角三角形 OBC）
  4. 验证结论③ 当 0<x<2 时 -4≤y<-3（高亮区间与值域）
  5. 验证结论④ 当 x>1 时 y 随 x 增大而增大（对称轴与单调性）
  6. 总结四个结论均正确，答案为 D
- 教学价值：教师可按节奏逐步推进每个结论的验证，配合图形高亮直观展示推理过程，也可随时回退复习。右侧结论标记区逐步打勾，帮助学生跟踪验证进度。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：画布(250,460)，宽100px高30px，步骤0时禁用（灰色不可点击）
  - 「下一步 ▶」按钮：画布(550,460)，宽100px高30px，步骤5时禁用
  - 步骤说明文字：画布(400,430)，居中显示当前步骤的验证说明
- 教师操作流程：
  1. 图示加载后显示步骤0（仅坐标系和抛物线），教师引导学生观察图像
  2. 点击「下一步」逐步验证每个结论，图形元素逐步出现并高亮
  3. 右侧结论标记区逐步打勾，帮助学生跟踪进度
  4. 可随时点击「上一步」回退到之前的步骤复习
  5. 步骤5显示最终答案 D，完成讲解

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无需外部库）
  - 原因：本场景为静态几何图形+分步显示，SVG 原生元素足以实现所有视觉需求，无需 D3.js 或 Canvas
- 画布尺寸：800 × 500 px（SVG viewBox="0 0 800 500"）
- 布局草图（ASCII）：
  ```
  +-------------------------------------------------------------+
  |  y                                                         |
  |  |    抛物线                                              |
  |  |   /  \              结论验证区                         |
  |  |  /    \             ① AB=4 ✓                          |
  |  | A------O------B----x       ② ∠ABC=45° ✓              |
  |  |  \    /              ③ -4≤y<-3 ✓                      |
  |  |   \  /               ④ x>1递增 ✓                      |
  |  |    \/                答案：D                           |
  |  |    C  顶点                                                |
  |  |                                                          |
  |  +---------------------------------------------------------+
  |  [◀ 上一步]    步骤说明文字    [下一步 ▶]                   |
  +-------------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：
     - 全局变量 `currentStep`（0~5）
     - `showStep(n)` 函数：根据 n 显示/隐藏对应元素
     - 每个步骤的元素用 CSS class `.step-N` 标记，初始 `display:none`
     - `showStep(n)` 将所有 `.step-0` 到 `.step-n` 的元素设为 `display:block`，其余 `display:none`
  2. 抛物线绘制：
     - JavaScript 循环 x 从 -2 到 4，步长 0.05
     - 计算 y = x² - 2x - 3
     - 画布坐标：cx = 220 + x*35, cy = 250 - y*35
     - 过滤 cy < 40 或 cy > 425 的点（画布边界截断）
     - 用 SVG `<path d="M... L... L..."/>` 连接所有点
  3. 区间色块绘制（步骤3）：
     - 用 SVG `<rect>` 覆盖 (220,355) 到 (290,390)，填充 #2e7d32 透明度 15%
     - 抛物线在色块上方绘制（DOM 顺序在后），视觉上色块只在抛物线下方可见
  4. 单调递增箭头（步骤4）：
     - SVG `<line>` 从 (307,290) 到 (335,220)，蓝色 #1565c0
     - SVG `<polygon>` 箭头头部在终点 (335,220) 处，三角形指向右上方
  5. 事件绑定：
     - 按钮点击事件调用 `prevStep()` / `nextStep()`
     - 边界检查：步骤0时上一步禁用，步骤5时下一步禁用
     - 按钮样式切换：禁用时灰色，可用时蓝色边框
  6. 步骤说明文字更新：
     - 预定义 6 条说明文字数组
     - 切换步骤时更新 SVG `<text>` 元素的 `textContent`
- ID 命名规范：所有交互元素 ID 以 `scene1-` 为前缀
  - `scene1-btn-prev`、`scene1-btn-next`、`scene1-step-info`
  - `scene1-parabola`、`scene1-axis-x`、`scene1-axis-y`
  - `scene1-point-a`、`scene1-point-b`、`scene1-point-c`、`scene1-point-vertex`
  - `scene1-label-a`、`scene1-label-b`、`scene1-label-c`、`scene1-label-vertex`
  - `scene1-label-ab`、`scene1-label-ob`、`scene1-label-oc`、`scene1-label-angle`
  - `scene1-label-range`、`scene1-label-interval`、`scene1-label-axis`
  - `scene1-line-bc`、`scene1-triangle-obc`、`scene1-interval-block`
  - `scene1-symmetry-axis`、`scene1-arrow-increase`
  - `scene1-conclusion-1`、`scene1-conclusion-2`、`scene1-conclusion-3`、`scene1-conclusion-4`
  - `scene1-answer`
- IIFE 隔离：所有 JS 代码包裹在 `(function() { ... })()` 中，避免全局污染
- JS 中用 `document.getElementById('scene1-xxx')` 获取元素，不用 `querySelectorAll` 配合全局 class
