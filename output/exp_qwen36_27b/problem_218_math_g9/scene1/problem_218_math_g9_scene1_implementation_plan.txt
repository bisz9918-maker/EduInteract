[图示主题与整合说明]
- 本图示主题：两个直角三角板摆放的角度推导——从已知条件到求解∠CDF的完整过程
- 整合的步骤/概念：
  1. 展示△ABC（等腰直角三角板）和△DEF（30°-60°-90°三角板）的摆放关系
  2. 标注所有已知条件（∠A=90°、AB=AC、∠EDF=90°、∠E=30°、∠BCE=40°）
  3. 逐步推导：∠ACB=45° → ∠ACE=85° → ∠ACF=95° → ∠F=60° → ∠CDF=25°
  4. 最终结论高亮显示
- 教学价值：教师可通过分步按钮引导学生跟随推导思路，每一步展示一个关键角度计算，学生可清晰看到角度之间的依赖关系。教师可随时回退复习任意步骤。

[技术实现]

- JS 库选择：原生 SVG（简单几何图形首选，无需额外库，性能好，易于操作单个元素）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |                    图示区 800×440                 |
  |                                                  |
  |         B                          A             |
  |        (180,220)                (420,140)        |
  |           \                      /               |

  |             \              /   /                 |
  |              \     △DEF  /   /  △ABC            |
  |               \        /   /                    |
  |                \      /   /                     |
  |                 \    /   /                      |
  |                  \  /   /                       |
  |                   \/   /                        |
  |  E(100,380)-------C(500,380)-------F(660,380)  |
  |                                                  |
  |  推导公式区：x=620~740, y=180~330               |
  |  (620,180) ∠ACB=45°                             |

  +--------------------------------------------------+
  ```

- 关键实现要点：

  1. **状态机设计**：
     - 使用全局变量 `currentStep`（0~5）跟踪当前步骤
     - 每个步骤对应一组SVG元素的显示/隐藏/样式变化
     - `renderStep(step)` 函数根据step值更新所有元素状态
     - 元素使用 `opacity` 或 `display` 控制显隐，避免DOM操作开销

  2. **SVG元素组织**：
     - 使用 `<g>` 分组管理：`scene1-tri-abc`、`scene1-tri-def`、`scene1-line-ef`
     - 角度弧线使用 `<path>` 绘制圆弧
     - 直角符号使用 `<rect>` 绘制小正方形
     - 等长标记使用 `<line>` 绘制短划线
     - 推导公式使用 `<text>` 元素

  3. **角度弧线绘制**：
     - 使用SVG `<path>` 的 `A`（椭圆弧）命令
     - 计算弧线的起始点和结束点（基于角度和半径）
     - 例如∠ACB：以C(500,380)为圆心，r=30px，从CA方向到CB方向画弧
     - CA方向角度：atan2(140-380, 420-500) = atan2(-240, -80) ≈ -108.4°
     - CB方向角度：atan2(220-380, 180-500) = atan2(-160, -320) ≈ -153.4°
     - 弧线从-108.4°到-153.4°（顺时针）

  4. **动画效果**：
     - 元素出现时使用CSS `transition: opacity 0.4s ease`
     - 高亮效果使用CSS `stroke-width` 和 `stroke` 变化
     - 结论文字出现时使用缩放动画（`transform: scale(1.1)`）

  5. **事件绑定**：
     - 按钮使用 `addEventListener('click', ...)` 绑定
     - 步骤切换时调用 `renderStep(newStep)` 更新视图
     - 按钮禁用状态使用 `disabled` 属性和CSS样式

  6. **ID 命名规范**：
     - 所有交互元素ID以 `scene1-` 为前缀
     - 示例：`scene1-btn-prev`、`scene1-btn-next`、`scene1-step-indicator`
     - 图形元素：`scene1-tri-abc`、`scene1-tri-def`、`scene1-line-ef`
     - 角度元素：`scene1-angle-acb`、`scene1-angle-bce`、`scene1-angle-cdf`
     - 公式元素：`scene1-formula-1` ~ `scene1-formula-5`

  7. **IIFE 隔离**：
     - 所有JS代码包裹在 `(function() { 'use strict'; ... })();` 中
     - 避免全局变量污染
     - 使用 `document.getElementById` 而非 `querySelectorAll`

  8. **响应式考虑**：
     - SVG使用 `viewBox="0 0 800 500"` 固定比例
     - 外层容器使用 `width: 100%; max-width: 800px` 自适应
