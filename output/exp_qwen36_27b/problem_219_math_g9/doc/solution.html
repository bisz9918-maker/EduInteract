场景导航：Scene 1

题目原文：

如图，已知$A$、$B$两点是反比例函数$y=\frac{k}{x}$的图像上的任意两点（$x>0$，$k>0$），过点$A$、$B$分别作$y$轴的垂线，垂足分别是$D$、$C$，记梯形$ABCD$的面积是${{S}_{1}}$，$\vartriangle OAB$的面积是${{S}_{2}}$，则${{S}_{1}}:{{S}_{2}}$的值是（ ）。

A．1：1 B．1：2 C．2：1 D．2：3

题目分析：

本题是反比例函数与平面几何结合的经典题目，核心考点是利用坐标法计算图形面积，并发现反比例函数图像上任意两点所构造的梯形与三角形的面积关系。

关键几何元素：

  • 反比例函数 $y=\frac{k}{x}$ 在第一象限的图像
  • 点 $A$、$B$ 在曲线上，设 $A(a,\frac{k}{a})$，$B(b,\frac{k}{b})$，其中 $0 < a < b$
  • 垂线段 $AD \perp y$ 轴，$BC \perp y$ 轴，垂足 $D(0,\frac{k}{a})$、$C(0,\frac{k}{b})$
  • 梯形 $ABCD$（由 $AD$、$BC$、$CD$、$AB$ 围成）
  • 三角形 $OAB$（由 $OA$、$OB$、$AB$ 围成）

整体讲解思路：

  1. 引导学生观察图形，识别梯形 $ABCD$ 和三角形 $OAB$
  2. 引入参数化坐标：设 $A(a,\frac{k}{a})$，$B(b,\frac{k}{b})$
  3. 计算梯形面积 $S_1 = \frac{(a+b)(\frac{k}{a}-\frac{k}{b})}{2} = \frac{k(b^2-a^2)}{2ab}$
  4. 计算三角形面积 $S_2 = \frac{|a\cdot\frac{k}{b}-b\cdot\frac{k}{a}|}{2} = \frac{k(b^2-a^2)}{2ab}$
  5. 得出结论 $S_1 = S_2$，即 $S_1:S_2 = 1:1$

图示规划说明：

本题所有视觉元素均位于同一坐标系中，因此规划为 1 个交互式图示场景，通过分步按钮导航逐步展示：基础图形 → 坐标标注 → 梯形面积计算 → 三角形面积计算 → 结论。这种设计让教师在一个视图中完成完整讲解，避免频繁切换视图。

$$S_1 = \frac{(AD+BC)\cdot CD}{2}$$
$$= \frac{(a+b)\left(\frac{k}{a}-\frac{k}{b}\right)}{2}$$
$$= \frac{k(b^2-a^2)}{2ab}$$
$$S_2 = \frac{|x_A y_B - x_B y_A|}{2}$$
$$= \frac{\left|a\cdot\frac{k}{b}-b\cdot\frac{k}{a}\right|}{2}$$
$$= \frac{k(b^2-a^2)}{2ab}$$
$$S_1 : S_2 = 1 : 1$$

教学说明：

本图示通过分步导航，帮助教师引导学生从直观图形观察过渡到代数计算，最终发现面积相等的结论。

步骤0：展示基础图形

教师引导学生观察图形，提问：

  • 图中有哪些几何图形？（反比例函数曲线、梯形ABCD、三角形OAB）
  • 梯形ABCD由哪些线段围成？（AD、BC、CD、AB）
  • 三角形OAB由哪些线段围成？（OA、OB、AB）

步骤1：标注坐标

教师引入参数化方法：

  • 设点 $A$ 的横坐标为 $a$，由于 $A$ 在 $y=\frac{k}{x}$ 上，故 $A(a,\frac{k}{a})$
  • 设点 $B$ 的横坐标为 $b$，由于 $B$ 在 $y=\frac{k}{x}$ 上，故 $B(b,\frac{k}{b})$
  • 由图可知 $0 < a < b$
  • 垂足 $D$ 在 $y$ 轴上且与 $A$ 同高，故 $D(0,\frac{k}{a})$
  • 垂足 $C$ 在 $y$ 轴上且与 $B$ 同高，故 $C(0,\frac{k}{b})$

步骤2：计算梯形面积 $S_1$

梯形面积公式：$S = \frac{(\text{上底}+\text{下底})\times\text{高}}{2}$

  • 上底 $AD = a$（$A$ 到 $y$ 轴的水平距离）
  • 下底 $BC = b$（$B$ 到 $y$ 轴的水平距离）
  • 高 $CD = \frac{k}{a} - \frac{k}{b}$（$D$ 和 $C$ 在 $y$ 轴上的距离，因为 $a < b$，所以 $\frac{k}{a} > \frac{k}{b}$）

推导：
$$S_1 = \frac{(a+b)(\frac{k}{a}-\frac{k}{b})}{2} = \frac{(a+b)\cdot\frac{k(b-a)}{ab}}{2} = \frac{k(a+b)(b-a)}{2ab} = \frac{k(b^2-a^2)}{2ab}$$

步骤3：计算三角形面积 $S_2$

利用坐标法求三角形面积（三点 $O(0,0)$、$A(a,\frac{k}{a})$、$B(b,\frac{k}{b})$）：

$$S_2 = \frac{|x_A y_B - x_B y_A|}{2} = \frac{|a\cdot\frac{k}{b}-b\cdot\frac{k}{a}|}{2} = \frac{|\frac{ka}{b}-\frac{kb}{a}|}{2} = \frac{|\frac{k(a^2-b^2)}{ab}|}{2} = \frac{k(b^2-a^2)}{2ab}$$

（因为 $b > a$，所以 $b^2 > a^2$，绝对值可直接去掉）

步骤4：得出结论

对比两个面积：
$$S_1 = \frac{k(b^2-a^2)}{2ab}, \quad S_2 = \frac{k(b^2-a^2)}{2ab}$$

显然 $S_1 = S_2$，故 $S_1:S_2 = 1:1$。

课堂讲解建议：

  1. 强调本题的关键在于坐标法——将几何问题转化为代数计算
  2. 引导学生注意反比例函数的性质：$xy = k$（常数），这是面积计算中消去参数的关键
  3. 可以进一步提问：如果 $A$、$B$ 位置互换（$a > b$），结论是否仍然成立？（答案是肯定的，因为面积公式中 $b^2-a^2$ 取绝对值）
  4. 拓展思考：这个结论是否对反比例函数图像上任意两点都成立？（是的，这是反比例函数的一个重要几何性质）

答案：A．1：1
