[图示主题与整合说明]
- 本图示主题：反比例函数中梯形ABCD与三角形OAB面积关系的坐标法证明
- 整合的步骤/概念：
  1. 展示题目基础图形（坐标系、反比例函数曲线、点A/B/C/D/O、垂线段、梯形、三角形）
  2. 各点坐标参数化标注（A(a,k/a)、B(b,k/b)、C(0,k/b)、D(0,k/a)、O(0,0)）
  3. 梯形ABCD面积公式推导与高亮（蓝色）
  4. 三角形OAB面积公式推导与高亮（红色）
  5. 面积相等结论展示（S₁:S₂=1:1，绿色）

[技术实现]
- JS 库选择：
  - 原生 SVG：用于绘制坐标系、曲线、点、线段、多边形等所有图形元素（轻量、精确控制）
  - MathJax 3（CDN）：用于渲染右侧的数学公式（分式、绝对值、下标等复杂排版）
  - 无需D3/Three.js/p5.js（本场景为静态几何图+分步展示，无需复杂动画或3D）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  ┌──────────────────────────────────────────────────────────────┐
  │  y                                                          │
  │  │    y=k/x                                                 │
  │  │   /   A(a,k/a)                                          │
  │  D├───A                                                    │
  │  │  /    \                                                 │
  │  C├───────B(b,k/b)                                         │
  │  │ /       \              S₁公式区                          │
  │  O/─────────┼──────x     S₂公式区                          │
  │  │          │         结论区                                │
  │  │          │                                              │
  │  │          │                                              │
  │  │          │                                              │
  │  │◀上一步│ 步骤X/5 │  下一步▶│                               │
  └──────────────────────────────────────────────────────────────┘
  左60%图形区              右40%公式区
  底部控件栏(y=440~490)
  ```
- 关键实现要点：
  1. **状态机设计**：用变量 `currentStep`（0-4）管理当前步骤。每个步骤对应一组元素的显示/隐藏/样式变化。
     - stepData数组存储每步的状态：哪些元素visible、哪些元素highlighted、哪些公式显示
     - 切换步骤时，遍历stepData，更新对应SVG元素的style属性
  2. **曲线生成**：JavaScript动态生成SVG path数据
     - k=14400，math_x从40到420，步长5
     - SVG_x = 80 + math_x，SVG_y = 400 - 14400/math_x
     - 用" M x0,y0 L x1,y1 L x2,y2 ..."构建path的d属性
  3. **动画曲线**：CSS transition，duration 300ms，ease-in-out
     - 元素淡入：opacity 0→1
     - 填充/边框变化：fill和stroke属性transition
  4. **事件绑定**：按钮点击事件绑定到stepNext()和stepPrev()函数
     - stepNext()：currentStep++，更新视图，更新按钮状态
     - stepPrev()：currentStep--，更新视图，更新按钮状态
  5. **MathJax公式渲染**：
     - 公式用HTML div包裹，初始display:none
     - 步骤切换时，设置display:block并调用MathJax.typesetPromise()重新渲染
     - 公式div用position:absolute定位在容器内
  6. **梯形和三角形SVG多边形**：
     - 梯形：polygon points="140,160 320,340 80,340 80,160"
     - 三角形：polygon points="80,400 140,160 320,340"
     - 步骤0：stroke="#cccccc" stroke-width="1" fill="none"
     - 步骤2+（梯形）：stroke="#1565c0" stroke-width="3" fill="#1565c0" fill-opacity="0.2"
     - 步骤3+（三角形）：stroke="#c62828" stroke-width="3" fill="#c62828" fill-opacity="0.2"
- ID 命名规范：所有交互元素ID以 `scene1-` 为前缀
  - scene1-btn-prev、scene1-btn-next、scene1-step-indicator
  - scene1-trapezoid、scene1-triangle
  - scene1-label-s1、scene1-label-s2
  - scene1-coord-a、scene1-coord-b、scene1-coord-c、scene1-coord-d、scene1-coord-o
  - scene1-annotation-ab、scene1-formula-s1、scene1-formula-s2、scene1-conclusion
  - scene1-curve、scene1-line-ad、scene1-line-bc、scene1-line-oa、scene1-line-ob、scene1-line-ab
- IIFE 隔离：所有JS代码包裹在 (function() { 'use strict'; ... })() 中，避免全局污染
- 公式HTML结构（在SVG容器外部，用绝对定位叠加）：
  ```html
  <div id="scene1-formula-s1" style="position:absolute;left:520px;top:120px;display:none;font-size:15px;">
    <div>$$S_1 = \frac{(AD+BC)\cdot CD}{2}$$</div>
    <div>$$= \frac{(a+b)\left(\frac{k}{a}-\frac{k}{b}\right)}{2}$$</div>

  <div id="scene1-formula-s2" style="position:absolute;left:520px;top:250px;display:none;font-size:15px;">

    <div>$$= \frac{\left|a\cdot\frac{k}{b}-b\cdot\frac{k}{a}\right|}{2}$$</div>
  ```
