[分步序列]

- 初始状态（步骤0）：
  显示完整装置结构：
  - 烧杯+稀硫酸溶液（浅蓝色半透明）
  - 锌电极（灰色）+ 铜电极（红棕色）
  - 滤纸（白色椭圆）+ 石墨棒a/b（深灰色）
  - 连接导线（锌→b，铜→a）
  - 基础标签："锌"、"铜"、"a"、"b"、"稀硫酸"、"用饱和食盐水浸湿的滤纸"

- 步骤1：点击「下一步」→ 高亮原电池部分
  - 烧杯区域添加蓝色(#1565c0)半透明光晕效果
  - 锌电极左侧出现"负极"标签
  - 铜电极右侧出现"正极"标签
  - 锌电极底部出现溶解气泡动画（小圆逐渐上升消失）
  - 铜电极底部出现冒气泡动画（小圆逐渐上升消失）

- 步骤2：点击「下一步」→ 高亮电解池部分
  - 滤纸区域添加红色(#c62828)半透明光晕效果
  - 石墨棒a左侧出现"阳极"标签
  - 石墨棒b右侧出现"阴极"标签
  - a极底部出现黄绿色气体气泡（表示Cl₂）
  - b极底部出现无色气体气泡（表示H₂）

- 步骤3：点击「下一步」→ 标注电子流向与离子移动
  - 沿导线锌→b段出现红色箭头（电子流向：锌→b）
  - 沿导线a→铜段出现红色箭头（电子流向：a→铜）
  - 溶液中出现蓝色箭头：H⁺向铜极移动（从左向右）
  - 滤纸中出现蓝色箭头：Cl⁻向a极移动（从右向左）

- 步骤4：点击「下一步」→ 显示电极反应方程式
  - 锌电极下方出现：Zn - 2e⁻ → Zn²⁺（带虚线指向锌电极）
  - 铜电极下方出现：2H⁺ + 2e⁻ → H₂↑（带虚线指向铜电极）
  - 石墨棒a下方出现：2Cl⁻ - 2e⁻ → Cl₂↑（带虚线指向a）
  - 石墨棒b下方出现：2H₂O + 2e⁻ → H₂↑ + 2OH⁻（带虚线指向b）

- 步骤5：点击「下一步」→ 酚酞变色与选项判断
  - b极附近出现粉红色半透明圆形区域（表示OH⁻使酚酞变红）
  - 变色区域下方出现"滴加酚酞变红"标签
  - 右下角出现选项判断：
    A．a为阳极，发生氧化反应：锌为负极被还原 ×
    B．电路中电子流动方向：锌→b→a→铜 ×
    C．电路中通过0.2mol电子，铜片上产生2.24L气体 ×
    D．往滤纸上滴加酚酞，b极附近颜色变红 √（绿色高亮）

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于 SVG 内底部左侧 (x=280, y=455)，点击回退到上一步
  - 「步骤 X/5」指示器：位于 SVG 内底部居中 (x=400, y=460)，显示当前步骤
  - 「下一步 ▶」按钮：位于 SVG 内底部右侧 (x=520, y=455)，点击进入下一步
- 教师操作流程：
  1. 初始状态展示完整装置，教师介绍题目背景
  2. 点击「下一步」逐步引导学生分析原电池部分（正负极判断）
  3. 继续点击分析电解池部分（阴阳极判断）
  4. 再点击展示电子流向和离子移动方向
  5. 再点击显示各电极反应方程式
  6. 最后展示酚酞变色现象和选项判断，完成题目讲解
  7. 可随时点击「上一步」回退复习任意步骤

[技术实现]
- JS 库选择：原生 SVG（简单几何图形为主，无需复杂库，轻量高效）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  ┌──────────────────────────────────────────────────────────────┐
  │                                                              │
  │         锌→b 导线 (y=70)                                     │
  │    ┌────┐                                                    │
  │    │锌  │              铜→a 导线 (y=90)                      │
  │    │    │                                                    │
  │  ┌─┴────┴────────────────────────────────────────┐          │
  │  │  烧杯(稀硫酸)        滤纸(饱和食盐水)          │          │
  │  │  ┌──┐ ┌──┐         ┌──┐ ┌──┐                 │          │
  │  │  │锌│ │铜│         │a │ │b│                 │          │
  │  │  │  │ │  │         │  │ │  │                 │          │
  │  │  └──┘ └──┘         └──┘ └──┘                 │          │
  │  └───────────────────────────────────────────────┘          │
  │                                                              │
  │  Zn-2e⁻→Zn²⁺   2H⁺+2e⁻→H₂↑   2Cl⁻-2e⁻→Cl₂↑  2H₂O+2e⁻→...  │
  │                                                              │
  │                              A× B× C× D√                    │
  │                                                              │
  │  ┌──────────┐  ┌──────────┐  ┌──────────┐                   │
  │  │◀ 上一步  │  │ 步骤 X/5 │  │ 下一步 ▶ │                   │
  │  └──────────┘  └──────────┘  └──────────┘                   │
  └──────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. **状态机设计**：使用全局变量 `currentStep`（0~5）管理当前步骤，每个步骤对应一组可见元素
  2. **元素显隐控制**：每个步骤新增元素通过 `opacity` 动画过渡（0.3s ease-in-out），避免突兀出现
  3. **气泡动画**：使用 SVG `<animate>` 实现气泡上升并逐渐消失的效果（cy递减，opacity递减）
  4. **电子流向箭头**：使用 SVG `<marker>` 定义箭头头部，沿导线路径绘制 `<line>` 或 `<path>`
  5. **离子移动箭头**：蓝色细箭头，带 `<marker-end>` 箭头头部
  6. **酚酞变色区域**：半透明圆形 `<circle>`，opacity=0.3，叠加在滤纸区域
  7. **选项判断**：正确选项D用绿色(#2e7d32)高亮，错误选项用红色(#c62828)标记×
  8. **按钮事件绑定**：使用 `addEventListener('click', ...)` 绑定按钮点击事件，更新 `currentStep` 并调用 `renderStep()`
  9. **renderStep() 函数**：根据 `currentStep` 值设置各元素的 `opacity` 属性，控制显隐
  10. **边界检查**：第一步时禁用「上一步」按钮，最后一步时禁用「下一步」按钮

- **ID 命名规范**：所有交互元素 ID 以 `scene1-` 为前缀
  - 按钮：`scene1-prev-btn`、`scene1-next-btn`、`scene1-step-indicator`
  - 原电池元素：`scene1-beaker`、`scene1-zinc`、`scene1-copper`、`scene1-solution`
  - 电解池元素：`scene1-filter-paper`、`scene1-rod-a`、`scene1-rod-b`
  - 导线：`scene1-wire-zn-b`、`scene1-wire-cu-a`
  - 标签：`scene1-label-zinc`、`scene1-label-copper`、`scene1-label-a`、`scene1-label-b`
  - 步骤1元素：`scene1-label-anode`、`scene1-label-cathode`、`scene1-label-negative`、`scene1-label-positive`
  - 步骤3元素：`scene1-e-flow-zn-b`、`scene1-e-flow-a-cu`、`scene1-ion-h`、`scene1-ion-cl`
  - 步骤4元素：`scene1-eq-zinc`、`scene1-eq-copper`、`scene1-eq-a`、`scene1-eq-b`
  - 步骤5元素：`scene1-phenolphthalein`、`scene1-label-phenol`、`scene1-options`

- **IIFE 隔离**：所有 JS 代码包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染
