    (2010上海地理, 44—48,8分) 下图为某日部分地区昼夜示意图, 阴影部分表示黑夜, 其余部分表示白昼。读图回答问题。

    部分地区昼夜示意图
    (1) 按东、西半球划分, 图上阴影部分主要位于______半球, 此时甲地地方时是______点。
    (2) 按南、北半球划分, 此时太阳直射点位于______半球, 太阳直射点的经度是______。
    (3) 该日乙地的白昼时间长约______小时。
    (4) 如果这一天是农历十五, 上海地区人们还需要等待约______小时才能看到东边天际升起的一轮圆月。
    (5) 如果晨昏线与甲地所在经线的夹角为10°, 则该日正午时分上海(31°N) 世博园场馆的太阳能电池板与建筑物外墙面(墙面与地面垂直) 之间最合适的夹角约为______。

    本题以昼夜分布图为载体，综合考查地球运动相关的多个知识点：东西半球划分、地方时计算、太阳直射点位置判断、昼长计算、月相与时间关系、太阳能电池板角度计算。

    图示为圆柱投影的昼夜分布图，关键信息：
    - 纬度线：23.5°N（北回归线）、0°（赤道）、23.5°S（南回归线）

    **图示1教学说明：**

    本图示整合了第(1)(2)(3)问的讲解，教师应按以下步骤引导学生：

    **步骤0：读图基础**
    - 引导学生观察：这是一张圆柱投影的昼夜分布图
    - 识别关键元素：阴影=黑夜，白色=白昼，斜线=晨昏线
    - 确认甲在赤道晨线上，乙在南回归线白昼区

    **步骤1：东西半球与地方时（第1问）**
    - 东西半球划分：20°W向东至160°E为东半球，其余为西半球
    - 图中经度37.5°W和22.5°W均在20°W以西，属于西半球
    - 阴影部分在37.5°W以西，主要位于西半球
    - 甲在赤道晨线上，赤道全年日出地方时6点，所以甲地地方时=6点
    - 答案：西半球，6点

    **步骤2：太阳直射点位置（第2问）**
    - 从晨昏线倾斜方向判断：北半球昼短夜长（阴影面积大），南半球昼长夜短（白昼面积大）→太阳直射南半球
    - 太阳直射点经度=地方时12点的经度
    - 甲在37.5°W，地方时6点，UTC = 6 + 37.5/15 = 8.5
    - 12点经度：12 = 8.5 + 经度/15，经度 = 52.5°E
    - 答案：南半球，52.5°E

    **步骤3：乙地昼长（第3问）**
    - 晨线与23.5°S交点X为乙地日出点
    - X的经度约45°W，地方时 = 8.5 - 45/15 = 5.5点（日出时刻）
    - 乙地昼长 = 24 - 2 × 日出时间 = 24 - 2 × 5.5 = 13小时
    - 答案：13小时

    **图示2教学说明：**

    本图示讲解第(4)问，核心知识点是月相与时间的关系。

    **步骤0：月相规律**
    - 农历十五为满月（圆月），此时日-地-月近似在一条直线上，地球在中间
    - 月球被太阳完全照亮的一面朝向地球，所以看到圆月

    **步骤1：圆月升起规律**
    - 圆月在日落时从东方地平线升起，在日出时从西方落下
    - 这是因为满月时月球与太阳相对（相差180°），太阳落下时月球升起
    - 当前上海地方时计算：UTC = 8.5，上海经度121°E，上海地方时 = 8.5 + 121/15 ≈ 16.57 ≈ 16:34

    **步骤2：等待时间计算**
    - 上海纬度31°N，太阳直射约17°S
    - 上海昼长 ≈ 10.5小时（北半球冬半年昼短夜长）
    - 日出 ≈ (24-10.5)/2 = 6.75 ≈ 6:45
    - 日落 ≈ 6:45 + 10.5 = 17:15
    - 等待时间 = 日落时间 - 当前时间 = 17:15 - 16:34 ≈ 41分钟 ≈ 1小时
    - 答案：约1小时

    **图示3教学说明：**

    本图示讲解第(5)问，核心是太阳能电池板角度的计算。

    **步骤0：晨昏线夹角与太阳直射点纬度**
    - 晨昏线与经线的夹角等于太阳直射点的纬度
    - 题目给定夹角为10°，所以太阳直射点纬度为10°S（因为图中南半球昼长夜短，太阳直射南半球）

    **步骤1：正午太阳高度计算**
    - 公式：H = 90° - |φ - δ|
    - 其中φ为当地纬度，δ为太阳直射点纬度
    - 上海φ = 31°N，δ = 10°S = -10°
    - H = 90° - |31° - (-10°)| = 90° - 41° = 49°

    **步骤2：电池板角度确定**
    - 太阳能电池板应与太阳光线垂直，以最大化接收太阳辐射
    - 太阳光线与地面夹角 = 正午太阳高度 = 49°
    - 电池板与地面夹角 = 90° - 49° = 41°
    - 建筑物外墙面与地面垂直（夹角90°）
    - 电池板与墙面夹角 = 90° - 41° = 49°
    - 或者直接理解：电池板与墙面夹角 = 太阳高度角 = 49°
    - 答案：49°

    **完整答案汇总：**
    (1) 西半球，6点
    (2) 南半球，52.5°E
    (3) 13小时
    (4) 约1小时
    (5) 49°

    **课堂讲解建议：**
    - 第(1)(2)(3)问是本题核心，需重点讲解读图方法和推导过程
    - 第(4)问考查月相知识，可简要回顾月相变化规律
    - 第(5)问是假设条件，注意区分图中实际情况与题目假设
    - 强调晨昏线与经线夹角 = 太阳直射点纬度这一重要结论
