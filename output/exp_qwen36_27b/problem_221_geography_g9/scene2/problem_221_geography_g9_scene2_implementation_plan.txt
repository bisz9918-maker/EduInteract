[图示主题与整合说明]
- 本图示主题：农历十五圆月升起时间推算
- 整合的步骤/概念：第(4)问——月相规律与上海地区圆月升起时间计算。从日-地-月位置关系出发，理解满月升起规律（日落时升起），再结合上海当前地方时推算等待时间。
- 教学价值：教师通过三步递进式动画，先展示月相成因（日-地-月一线），再揭示圆月升起规律（日落时从东方升起），最后代入具体数值计算等待时间，帮助学生建立从原理到应用的完整逻辑链条。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位置(280,455)，100×30px，点击返回上一步骤，步骤0时禁用
  - 「下一步 ▶」按钮：位置(420,455)，100×30px，点击进入下一步骤，步骤2时禁用
- 教师操作流程：
  1. 页面加载显示步骤0（日-地-月位置关系），教师讲解满月成因
  2. 点击「下一步 ▶」进入步骤1，右侧出现地球侧视图和圆月升起示意，教师讲解圆月升起规律
  3. 点击「下一步 ▶」进入步骤2，出现时间计算标注，教师讲解等待时间推算
  4. 可随时点击「◀ 上一步」回退到任意步骤复习

[技术实现]
- JS 库选择：原生 SVG（简单几何图形绘制，无需额外库，轻量高效）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +-------------------------------------------------------------+
  |  [太阳]----光线----[地球]----光线----[月球]                  |
  |   (120)         (260)         (380)                         |
  |        "农历十五：满月"  (250,145)                           |
  |        "日-地-月一线"  (250,290)                             |
  |                                                             |
  |              [地球侧视图]  [上海●]                           |
  |              (590,220)    (615,188)                          |
  |              ~~~~~~~~~地平线~~~~~~~~~  [圆月↑]               |
  |              "圆月：日落时升起"                               |
  |              "当前地方时：约16:34"                            |
  |              "日落时间：约17:15"                              |
  |              ----等待时间箭头----                             |
  |              "等待时间：约1小时"                              |
  |                                                             |
  |         [◀ 上一步]      [下一步 ▶]                           |
  |              (280,455)    (420,455)                          |
  +-------------------------------------------------------------+
  ```
- 关键实现要点：
  1. **状态机设计**：用变量 `currentStep`（0/1/2）管理当前步骤，每个步骤对应一组 SVG 元素的显示/隐藏
  2. **元素显隐**：步骤0元素始终显示；步骤1元素在 currentStep≥1 时显示（opacity 0→1 过渡动画，duration 0.5s）；步骤2元素在 currentStep≥2 时显示
  3. **动画曲线**：新增元素使用 CSS transition `opacity 0.5s ease-in-out`，圆月升起使用 `transform: translateY()` 从地平线下方移动到上方
  4. **事件绑定**：两个按钮分别绑定 click 事件，调用 `goToStep(currentStep - 1)` 和 `goToStep(currentStep + 1)`，边界检查防止越界
  5. **按钮禁用状态**：步骤0时"上一步"按钮设置 `disabled=true` 且样式变灰；步骤2时"下一步"按钮同理
  6. **地球侧视图绘制**：用 SVG `<circle>` 绘制地球轮廓，`<line>` 绘制赤道和经线辅助线，`<circle>` 绘制上海标记点
  7. **光线箭头**：用 SVG `<line>` + `<marker>` 实现箭头效果，虚线用 `stroke-dasharray="5,5"`
- ID 命名规范：所有交互元素 ID 以 `scene2-` 为前缀
  - `scene2-sun`：太阳圆形
  - `scene2-earth-main`：日地月图中的地球
  - `scene2-moon-main`：日地月图中的月球
  - `scene2-light-rays`：光线箭头组
  - `scene2-label-fullmoon`：农历十五标签
  - `scene2-label-alignment`：日地月一线标签
  - `scene2-earth-side`：地球侧视图组
  - `scene2-shanghai-dot`：上海标记点
  - `scene2-label-shanghai`：上海标签
  - `scene2-horizon`：地平线
  - `scene2-label-horizon`：东方地平线标签
  - `scene2-moon-rise`：圆月升起示意
  - `scene2-rise-arrow`：升起箭头
  - `scene2-label-rise-rule`：圆月升起规律标签
  - `scene2-label-current-time`：当前地方时标签
  - `scene2-label-sunset`：日落时间标签
  - `scene2-wait-arrow`：等待时间箭头
  - `scene2-label-wait`：等待时间标签
  - `scene2-btn-prev`：上一步按钮
  - `scene2-btn-next`：下一步按钮
- IIFE 隔离：所有 JS 代码包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染
