[图示主题与整合说明]
- 本图示主题：遗传系谱图分析——甲病与乙病的遗传方式判断及概率计算
- 整合的步骤/概念：系谱图整体结构展示、甲病隐性遗传推导（无中生有）、乙病显性遗传推导（有中生无）、关键个体基因型标注（Aa/aa）、后代患病概率计算关系可视化
- 教学价值：教师可通过分步导航引导学生从观察系谱现象出发，逐步推导遗传方式，标注基因型，并最终完成概率计算。分步高亮与标注能有效降低认知负荷，帮助学生建立“现象→规律→计算”的逻辑链条。

[标签冲突检查]
- 代际标记(I/II/III)：x=25，与最近个体II1(x=80)间距55px → 无冲突。
- 个体编号标签：位于符号下方15px（y+25），与下方符号（如有）间距≥80px → 无冲突。
- 基因型标注：位于编号下方15px（y+40），与下方连线/符号间距≥60px → 无冲突。
- 提示文字：位于父代上方20px（y=35/50），与图例(y=10~110)在x方向错开（图例x=640+，提示x=205/605）→ 无冲突。
- 概率计算式：y=370/390，与控件栏(y=450)间距≥60px，与上方个体(y=320+24=344)间距≥26px → 无冲突。
- 图例：x=640~770，y=10~110。与I3/I4(x=580/630, y=80)在x方向有重叠风险。调整图例x起始为660，确保与I4(x=630)间距≥30px → 无冲突。
- 结论：所有标签与图形元素间距均≥20px，无重叠遮挡。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于(250, 450)，宽80px，高36px。点击回退到上一状态，隐藏当前步骤新增元素。
  - 「下一步 ▶」按钮：位于(470, 450)，宽80px，高36px。点击进入下一状态，显示当前步骤新增元素。
  - 步骤指示器：位于(370, 460)，显示"步骤 X / 5"，12px，#666666。
- 教师操作流程：
  1. 初始展示系谱图，引导学生观察整体结构。
  2. 点击「下一步」逐步揭示甲病/乙病遗传方式，配合提示文字讲解判断依据。
  3. 继续点击展示基因型推导与概率计算，利用高亮与箭头聚焦关键个体。
  4. 可随时点击「上一步」回顾前序推导过程。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript。系谱图由规则几何图形与直线构成，SVG 可保证高清渲染与精确坐标控制，无需引入重型库。
- 画布尺寸：800 × 500 px（固定 viewBox）。
- 布局草图（ASCII）：
  ```
  +-------------------------------------------------------------+
  | I   I1 ○──□ I2          I3 ■──● I4          [图例]          |
  |       |         |           |         |                      |
  | II  II1○ II2□ II3■ II4◎ II5○ II6□   II7○ II8□ II9● II10□ II11○ |
  |       |   |       |   |       |       |   |   |   |   |      |
  | III III1○       III2■──● III3       III4■   III5○            |
  |                     ?                                    |
  |                  [概率公式区]                              |
  |                                                       |
  |          [◀ 上一步]   步骤 X/5   [下一步 ▶]              |
  +-------------------------------------------------------------+
  ```
- 关键实现要点：
  - 状态机设计：使用 `currentStep` 变量（0~5）管理当前状态。每个步骤对应一个 `renderStep(step)` 函数，控制对应 SVG 元素的 `display` 或 `opacity`。
  - 坐标计算：所有元素坐标硬编码写入 SVG `x`/`y`/`cx`/`cy` 属性，确保像素级对齐。
  - 动画曲线：步骤切换使用 CSS `transition: opacity 0.3s ease-in-out` 实现平滑淡入淡出。
  - 事件绑定：按钮绑定 `click` 事件，更新 `currentStep` 并调用 `renderStep()`。边界检查（步骤0禁用上一步，步骤5禁用下一步）。
- ID 命名规范：所有交互元素与关键 SVG 元素 ID 以 `scene1-` 为前缀（如 `scene1-btn-next`, `scene1-indiv-II5`, `scene1-label-prob4`）。
- IIFE 隔离：所有 JS 代码包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染。
- 样式隔离：CSS 类名以 `scene1-` 为前缀（如 `.scene1-pedigree-line`, `.scene1-highlight-a`）。
