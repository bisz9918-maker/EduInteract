[技术实现]
- JS 库选择：原生SVG（无需额外库）。原因：本场景为简单几何图形（椭圆、路径、圆、虚线、文字），原生SVG完全满足需求，无需引入D3.js等重型库。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────┐
  │                    细胞分裂图                        │
  │                                                     │
  │              ┌───────────────────┐                  │
  │              │    细胞轮廓(椭圆)   │                  │
  │              │                   │                  │
  │  染色体  ───→│   X     X     X   │←── 纺锤丝        │
  │  姐妹染色单体│  / \   / \   / \  │←── 赤道板        │
  │  着丝粒  ───→│  A    a   B  b   │                  │
  │              │                   │                  │
  │              └───────────────────┘                  │
  │                                                     │
  │              [有丝分裂中期]                          │
  │              [II10基因型 = AaBb]                     │
  │                                                     │
  │         [◀ 上一步]        [下一步 ▶]                │
  └─────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. **状态机设计**：使用变量 `currentStep`（0~4）管理当前步骤。每个步骤对应一个 `renderStep(step)` 函数，根据step值控制各元素的显示/隐藏/高亮状态。
  2. **元素显隐控制**：使用SVG元素的 `opacity` 属性配合CSS `transition` 实现淡入淡出动画。初始状态所有标注元素 `opacity="0"`，进入对应步骤时设为 `opacity="1"`。
  3. **染色体X形绘制**：使用SVG `<path>` 元素绘制X形。以左侧染色体为例：
     - 路径：`M 285 195 L 300 220 L 315 195`（上臂）+ `M 285 245 L 300 220 L 315 245`（下臂）
     - 或合并为：`M 285 195 L 300 220 L 315 245 M 315 195 L 300 220 L 285 245`
  4. **纺锤丝绘制**：使用多条 `<line>` 元素，`stroke-dasharray="4,4"` 实现虚线效果。从(400,100)和(400,340)分别连接到3个着丝粒(300,220)、(400,220)、(500,220)。
  5. **箭头绘制**：使用SVG `<marker>` 定义箭头头部，在 `<line>` 元素上设置 `marker-end="url(#arrowhead)"`。
  6. **高亮效果**：步骤3染色体高亮通过修改 `stroke` 颜色和 `stroke-width` 实现；步骤4基因文字高亮通过添加 `<rect>` 背景框和放大 `font-size` 实现。
  7. **按钮状态管理**：步骤0时"上一步"按钮 `pointer-events="none"` 且灰色；步骤4时"下一步"按钮同理。
  8. **事件绑定**：使用 `addEventListener('click', ...)` 绑定按钮点击事件，更新 `currentStep` 后调用 `renderStep(currentStep)`。

- **ID 命名规范**：所有交互元素ID以 `scene2-` 为前缀：
  - 按钮：`scene2-prev-btn`、`scene2-next-btn`
  - 染色体：`scene2-chr-left`、`scene2-chr-mid`、`scene2-chr-right`
  - 基因标签：`scene2-gene-A`、`scene2-gene-a`、`scene2-gene-B`、`scene2-gene-b`
  - 结构标注：`scene2-label-chromosome`、`scene2-label-sister`、`scene2-label-centromere`、`scene2-label-spindle`、`scene2-label-equator`
  - 时期判断：`scene2-period-text`
  - 基因型推导：`scene2-genotype-text`
  - 细胞轮廓：`scene2-cell-outline`
  - 纺锤丝组：`scene2-spindle-upper`、`scene2-spindle-lower`
  - 赤道板：`scene2-equator-line`
  - 着丝粒：`scene2-centro-left`、`scene2-centro-mid`、`scene2-centro-right`

- **IIFE 隔离**：所有JS代码包裹在 `(function() { 'use strict'; ... })();` 中，避免全局变量污染。
