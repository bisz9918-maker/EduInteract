[图示主题与整合说明]
- 本图示主题：木块受力分析图，区分平衡力与作用力-反作用力
- 整合的步骤/概念：木块静止在水平木板上的受力状态、重力与支持力的平衡关系、压力与支持力的相互作用关系、两类力的对比总结
- 教学价值：教师可通过分步交互，先引导学生观察单一物体的受力平衡，再引入相互作用力的概念，最后通过左右对比与表格归纳，帮助学生突破“平衡力 vs 作用力-反作用力”的易混淆点，配合课堂讲解清晰直观。

[分步序列]
- 初始状态（步骤0）：
  - 显示中央木板与木块，无力的箭头与标注。
  - 底部控件栏显示“步骤0/3：初始状态”。
- 步骤1（木块受力-平衡力）：
  - 点击「下一步」→ 中央木块上出现蓝色箭头：重力G（向下，作用点木块中心）、支持力N（向上，作用点接触面）。
  - 右侧出现蓝色标注框：“作用在同一物体上 → 平衡力”。
  - 控件栏更新为“步骤1/3：木块受力分析”。
- 步骤2（相互作用力）：
  - 点击「下一步」→ 中央图切换为红色箭头：压力F压（向下，作用点接触面，指向木板内部）、支持力N（向上，作用点接触面，指向木块）。
  - 右侧出现红色标注框：“作用在不同物体上 → 作用力与反作用力”。
  - 控件栏更新为“步骤2/3：相互作用力分析”。
- 步骤3（对比总结）：
  - 点击「下一步」→ 画面切换为左右分栏布局。
  - 左侧（蓝色虚线框）：显示木块受G和N，标注“平衡力”。
  - 右侧（红色虚线框）：显示接触面受F压和N，标注“作用力与反作用力”。
  - 底部出现对比表格（特征/平衡力/作用力与反作用力）。
  - 控件栏更新为“步骤3/3：概念对比总结”。
- 教师可随时点击「上一步」回退至任意步骤。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 步骤说明 / 下一步▶）
- 控件说明：
  - `scene2-btn-prev`：位于(250, 460)，点击返回上一步，步骤0时禁用。
  - `scene2-btn-next`：位于(550, 460)，点击进入下一步，步骤3时禁用。
  - `scene2-step-text`：位于(400, 460)，显示当前步骤标题与简要说明。
- 教师操作流程：教师点击「下一步」逐步展示受力情况，配合口头讲解力的作用点、方向与性质。在步骤3时，引导学生观察左右对比图与表格，总结两类力的核心区别。可随时回退复习。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无需外部库，轻量高效，适合静态分步图示）
- 画布尺寸：800 × 500 px（固定 viewBox）
- 布局草图：
  ```
  [图示区 800×440]
  ├─ 步骤0-2：中央木块+木板，力的箭头居中，右侧文字标注
  ├─ 步骤3：左侧平衡力图 | 右侧相互作用力图
  └─ 底部对比表格 (y=380~430)
  [控件栏 800×50 (y=440~490)]
  └─ ◀ 上一步 | 步骤说明文本 | 下一步 ▶
  ```
- 关键实现要点：
  - 状态机：`let currentStep = 0;`，`updateStep(step)` 函数控制各 `<g>` 的 `display` 属性。
  - 元素分组：`<g id="scene2-step0">`, `<g id="scene2-step1">`, `<g id="scene2-step2">`, `<g id="scene2-step3">`，初始仅 step0 可见。
  - 箭头绘制：使用 `<line>` + `<polygon>` 箭头头部，或 `<marker>` 定义统一箭头样式。
  - 动画过渡：步骤切换时添加 `opacity` 淡入淡出（CSS transition 0.3s），提升视觉流畅度。
  - 事件绑定：按钮 `click` 事件调用 `currentStep++/--` 并调用 `updateStep()`，边界检查禁用按钮。
- ID 命名规范：所有交互元素与关键图形 ID 均以 `scene2-` 为前缀（如 `scene2-block-center`, `scene2-arrow-g`, `scene2-btn-prev`）。
- IIFE 隔离：全部 JS 代码包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染。
- 表格实现：使用 SVG `<rect>` 绘制单元格背景与边框，`<text>` 居中排版，确保跨浏览器一致性。
