[图示主题与整合说明]
- 本图示主题：基于反应关系图的物质推断与选项验证
- 整合的步骤/概念：
  1. 展示五种物质（铁、氧化铁、稀盐酸、氢氧化钙、碳酸钠）之间的反应关系图
  2. 从铁的反应特性逐步推断各未知物质（X、Y、M、N）的身份
  3. 验证选项D（X、Y、M两两复分解反应）的正确性
  4. 分析选项C（N→铁的反应类型）的错误原因
- 教学价值：教师可通过分步按钮引导学生逐步推理，每一步基于上一步结论推进，清晰展示化学推断的逻辑链条。教师可随时回退复习任意步骤。

[技术实现]
- JS 库选择：原生 SVG（简单几何图形和关系图，无需额外库）
  - 原因：本场景仅需绘制圆角矩形、直线、箭头和文字，原生 SVG 完全满足需求，无需引入 D3.js 等重型库
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────────────┐
  │                    物质推断关系图                                   │ y=28
  │              铁、氧化铁、稀盐酸、氢氧化钙、碳酸钠                     │ y=52
  │                                                                    │
  │ ┌──────────┐   X ─────────────── Y ──────── 铁  ┌──────────────┐  │
  │ │          │  / \                    \          │              │  │ y=80
  │ │  推理    │ /   \                     \        │  方程式      │  │
  │ │  文字框  │X     M                     N ──→   │    框        │  │
  │ │          │   (300,260)              (500,260) │              │  │
  │ │          │                                    │              │  │
  │ │          │                                    │              │  │
  │ │          │                                    │              │  │
  │ └──────────┘                                    └──────────────┘  │ y=400
  │                                                                    │
  │              选项验证标注（✓D正确 / ✗C错误）                        │ y=422
  │                                                                    │
  │              [◀上一步]    [下一步▶]                                │ y=458
  └────────────────────────────────────────────────────────────────────┘
    x=0       x=150      x=300    x=400    x=500    x=610    x=788  x=800
  ```
- 关键实现要点：
  1. **状态机设计**：使用全局变量 `currentStep`（0~6）控制当前显示状态。每个步骤对应一个渲染函数 `renderStep(step)`，根据步骤索引更新节点样式、连线样式、标签显示、推理框内容、方程式框内容、选项验证标注。
  2. **SVG 元素管理**：所有 SVG 元素使用 `document.createElementNS` 创建，通过 ID 精确引用。节点使用 `<rect>` + `<text>` 组合，连线使用 `<line>`，箭头使用 `<line>` + `<marker>`。
  3. **样式切换**：使用 CSS class 切换实现高亮效果（如 `.node-highlight-blue`、`.line-highlight-red`、`.line-highlight-green`），避免内联样式频繁修改。
  4. **动画过渡**：节点填充颜色变化使用 CSS `transition: fill 0.3s ease`，连线颜色变化使用 `transition: stroke 0.3s ease`，标签出现使用 `opacity` 从 0 到 1 的过渡。
  5. **事件绑定**：导航按钮使用 `addEventListener('click', ...)` 绑定点击事件，更新 `currentStep` 后调用 `renderStep(currentStep)`。
  6. **箭头实现**：使用 SVG `<marker>` 定义箭头，`<defs><marker id="scene1-arrow" viewBox="0 0 10 10" refX="9" refY="5" markerWidth="6" markerHeight="6" orient="auto"><path d="M 0 0 L 10 5 L 0 10 z" fill="#000000"/></marker></defs>`。
  7. **文字框实现**：推理框和方程式框使用 SVG `<rect>` + `<text>` 组合，文字使用 `xml:space="preserve"` 保持换行。
- ID 命名规范：所有交互元素 ID 以 `scene1-` 为前缀：
  - 节点：`scene1-node-x`、`scene1-node-y`、`scene1-node-m`、`scene1-node-n`、`scene1-node-tie`
  - 连线：`scene1-line-xy`、`scene1-line-xm`、`scene1-line-ym`、`scene1-line-yn`、`scene1-line-ytie`、`scene1-line-ntie`
  - 推断标签：`scene1-label-y`、`scene1-label-n`、`scene1-label-xm`、`scene1-label-candidates`
  - 推理框：`scene1-reason-box`、`scene1-reason-text`
  - 方程式框：`scene1-eq-box`、`scene1-eq-text`
  - 选项验证：`scene1-verify-text`
  - 按钮：`scene1-btn-prev`、`scene1-btn-next`
  - SVG 容器：`scene1-svg`
- IIFE 隔离：所有 JS 代码包裹在 `(function() { 'use strict'; ... })();` 中，避免全局变量污染。
- 步骤数据定义：使用数组存储每个步骤的配置数据（节点样式、连线样式、标签内容、推理文字、方程式内容、验证文字），渲染函数根据配置数据更新 DOM。
