    **题目原文：**

    910℃以下纯铁晶体的基本结构单元如图1所示，910℃以上转变为图2所示的结构单元，在两种晶体中最邻近的铁原子间距离相同．

    （1）在910℃以下的纯铁晶体中，与铁原子等距离且最近的铁原子数为 ______ 个，在910℃以上的纯铁晶体中，与铁原子等距离且最近的铁原子数为 ______ 个．

    （2）纯铁晶体在晶型转变前后，二者基本结构单元的边长之比为（910℃以下与910℃以上之比） ______ ．

    （3）转变温度前后两者的密度之比（910℃以下与910℃以上之比） ______ ．

    **题目分析：**

    本题考察金属晶体结构的基本知识，涉及体心立方（BCC）和面心立方（FCC）两种晶胞。核心考点包括：配位数的确定、晶胞参数与原子间距的关系、晶胞密度的计算。

    图1为体心立方（BCC）结构：8个顶点各有一个铁原子，体心有一个铁原子。图2为面心立方（FCC）结构：8个顶点各有一个铁原子，6个面心各有一个铁原子。

    关键已知条件：**两种晶体中最邻近的铁原子间距离相同**，这是连接两问的桥梁。

    **整体讲解思路：**

    1. 首先展示两种晶体结构，引导学生识别BCC和FCC
    2. 通过交互式高亮，帮助学生直观理解配位数的概念（BCC为8，FCC为12）
    3. 通过几何推导，建立晶胞边长与最近邻距离的关系，求出边长比
    4. 利用晶胞含原子数和边长关系，推导密度比

    **图示规划：**

    - Scene 1：两种晶体结构对比展示 + 配位数交互式确定
    - Scene 2：晶胞边长与最近邻距离的几何关系推导 + 密度比计算
    </TEXT_1>

    **Scene 1 教学说明：**

    本图示帮助学生直观理解两种晶体结构及配位数的概念。

    **引导步骤：**

    1. **识别结构**：先让学生观察两种晶胞的区别——图1体心有一个原子（体心立方BCC），图2每个面心有一个原子（面心立方FCC）

    2. **理解配位数**：配位数指与某原子等距离且最近的原子个数
    - 对于BCC：以体心原子为参考，它到8个顶点原子的距离相等且最近，所以配位数为8
    - 对于FCC：以一个顶点原子为参考，它到相邻面心原子的距离最近。每个顶点原子被8个晶胞共享，每个面心原子被2个晶胞共享。从一个顶点出发，有3个相邻面（每个面一个面心原子），但考虑到相邻晶胞，实际上有12个最近邻面心原子（3个方向×4个 = 12个）

    3. **关键记忆**：BCC配位数=8，FCC配位数=12，这是金属晶体结构的基础知识

    **教师提示：**
    - FCC配位数12的推导是难点，建议用交互式图示逐步展示：先标出当前晶胞内的3个面心原子，再展示相邻晶胞中的9个面心原子，帮助学生建立空间想象
    - 强调"等距离且最近"的含义：不是所有相邻原子都算，必须是距离相等且最短的那些

    **Scene 2 教学说明：**

    本图示完整展示从几何关系到最终答案的推导过程。

    **核心推导步骤：**

    1. **BCC中最近邻距离与边长的关系**
    - 体心原子到顶点原子的距离为体对角线的一半
    - 体对角线 = √(a₁² + a₁² + a₁²) = √3·a₁
    - 最近邻距离 d = (√3·a₁)/2

    2. **FCC中最近邻距离与边长的关系**
    - 顶点原子到面心原子的距离为面对角线的一半
    - 面对角线 = √(a₂² + a₂²) = √2·a₂
    - 最近邻距离 d = (√2·a₂)/2

    3. **边长比推导**
    - 由已知条件：(√3·a₁)/2 = (√2·a₂)/2
    - 得：a₁/a₂ = √2/√3 = √6/3

    4. **密度比推导**
    - BCC晶胞含原子数：8×(1/8) + 1 = 2
    - FCC晶胞含原子数：8×(1/8) + 6×(1/2) = 4
    - 密度 ρ = (n·M)/(N_A·a³)，其中n为晶胞含原子数，M为摩尔质量，N_A为阿伏伽德罗常数
    - ρ₁/ρ₂ = (2/a₁³)/(4/a₂³) = (2/4)×(a₂/a₁)³ = (1/2)×(√3/√2)³
    - (√3/√2)³ = 3√3/(2√2) = 3√6/4
    - ρ₁/ρ₂ = (1/2)×(3√6/4) = 3√6/8

    **教师提示：**
    - 强调"最邻近铁原子间距离相同"这个条件的关键作用——它是连接两个晶胞的桥梁
    - 晶胞含原子数的计算是基础但易错点，建议让学生自己计算验证
    - 密度比计算中，摩尔质量和阿伏伽德罗常数会约掉，只需关注原子数和体积比
    - 最终答案：(1) 8，12；(2) √6/3；(3) 3√6/8
    </TEXT_3>

    **完整答案总结：**

    （1）910℃以下（BCC）配位数 = **8**，910℃以上（FCC）配位数 = **12**

    （2）边长比 a₁/a₂ = **√6/3**

    （3）密度比 ρ₁/ρ₂ = **3√6/8**

    **课堂讲解建议：**

    1. 先让学生观察原图，识别两种晶体结构的差异
    2. 用Scene 1交互式展示配位数的确定过程，重点讲解FCC配位数12的空间分布
    3. 用Scene 2逐步推导边长比和密度比，每一步都让学生先思考再展示答案
    4. 最后总结：金属晶体结构转变时，原子间距不变但排列方式改变，导致密度变化
    5. 可延伸提问：为什么FCC结构更致密？（因为FCC配位数更高，原子排列更紧密）
