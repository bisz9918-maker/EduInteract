    **题目原文：**

    如图所示，用三种方法拉动同一物体在相同的水平地面上做匀速直线运动，所用的拉力分别是F₁、F₂、F₃，则（）

    A. F₁＞F₂＞F₃
    B. F₁＜F₂＜F₃
    C. F₂＞F₁＞F₃
    D. F₂＜F₁＜F₃

    **题目分析：**

    本题考查滑轮组中定滑轮与动滑轮的受力分析。三种装置中，物体相同、地面相同，因此物体受到的滑动摩擦力f相同。物体做匀速直线运动，处于平衡状态，拉力与摩擦力之间存在特定关系。

    - **图(1)**：定滑轮，滑轮轴固定在墙上，绳子一端连物体，另一端受拉力F₁。定滑轮不省力，只改变力的方向，故 F₁ = f。
    - **图(2)**：动滑轮，绳子一端固定在墙上，绕过动滑轮后受拉力F₂，动滑轮轴连接物体。动滑轮省一半力，故 F₂ = f/2。
    - **图(3)**：动滑轮的特殊用法，物体连绳子一端，绳子绕过动滑轮后固定在墙上，拉力F₃作用在动滑轮轴上。此时拉力需克服两段绳子的张力（每段张力等于f），故 F₃ = 2f。

    综上：F₂ = f/2 < F₁ = f < F₃ = 2f，即 F₂ < F₁ < F₃，选 **D**。

    **整体讲解思路：**

    1. 先引导学生观察三种装置的异同，识别定滑轮和动滑轮。
    2. 明确物体做匀速直线运动，受力平衡。
    3. 逐一对三种情况进行受力分析，建立拉力与摩擦力的关系。
    4. 比较三者大小，得出结论。

    **图示规划说明：**

    规划一个综合图示场景，整合三种滑轮装置的展示与受力分析，通过分步按钮导航逐步讲解每种情况的受力关系，最后比较得出结论。

    **本图示的教学说明：**

    **步骤0（初始观察）：**
    引导学生观察三种装置的共同点和不同点：
    - 共同点：同一物体、相同地面、都做匀速直线运动
    - 不同点：滑轮类型不同（定滑轮vs动滑轮）、拉力作用位置不同

    **步骤1（图1分析）：**
    - 强调这是**定滑轮**，滑轮轴固定不动
    - 定滑轮的特点是**不省力、不费力，只改变力的方向**
    - 物体匀速运动，水平方向受力平衡：绳子拉力 = 摩擦力f
    - 绳子两端张力相等，故 F₁ = f

    **步骤2（图2分析）：**
    - 强调这是**动滑轮**，滑轮随物体一起运动
    - 动滑轮的特点是**省一半力**
    - 绳子两段共同承担物体的摩擦力f，每段张力为f/2
    - 拉力F₂等于绳子张力，故 F₂ = f/2

    **步骤3（图3分析）：**
    - 这也是**动滑轮**，但拉力作用在滑轮轴上（非常规用法）
    - 此时拉力F₃需要克服两段绳子的张力
    - 每段绳子的张力等于物体的摩擦力f
    - 故 F₃ = f + f = 2f，这是**费力**的用法

    **步骤4（比较结论）：**
    - 汇总三个关系式：F₁ = f，F₂ = f/2，F₃ = 2f
    - 比较大小：f/2 < f < 2f，即 F₂ < F₁ < F₃
    - 对应选项 **D**

    **关键公式：**
    1. 定滑轮：F = f（不省力）
    2. 动滑轮（常规）：F = f/2（省一半力）
    3. 动滑轮（拉力在轴上）：F = 2f（费力）

    **课堂讲解建议：**
    - 在步骤3处学生容易出错，需重点强调拉力作用位置不同导致受力关系不同
    - 可提问学生：为什么图(3)中拉力是2f而不是f/2？引导学生从力的平衡角度思考
    - 最后可总结：判断滑轮省力与否，关键是看拉力作用在绳子自由端还是滑轮轴上
