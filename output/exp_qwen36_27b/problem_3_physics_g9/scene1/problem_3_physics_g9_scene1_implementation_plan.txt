[图示主题与整合说明]
- 本图示主题：三种滑轮装置的受力分析与拉力比较
- 整合的步骤/概念：三种滑轮装置的原图展示 → 逐种分析受力情况（标注拉力与摩擦力）→ 推导拉力与摩擦力的关系式 → 三者大小比较得出结论
- 教学价值：教师可通过分步导航，按顺序讲解每种滑轮装置的受力特点，避免信息过载；支持回退复习，便于对比三种装置的差异；最终直观展示 F₂ < F₁ < F₃ 的排序关系，帮助学生理解定滑轮不省力、动滑轮可省力或费力的原理

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位置(280,455)，尺寸(100,30)，步骤0时禁用（灰色）
  - 「下一步 ▶」按钮：位置(420,455)，尺寸(100,30)，步骤4时禁用（灰色）
  - 步骤指示器：位置(390,460)，文字"步骤 X / 4"，居中显示
- 教师操作流程：
  1. 图示加载后显示步骤0（三种装置原图），教师让学生观察三种装置的差异
  2. 点击「下一步」进入步骤1，高亮图(1)，讲解定滑轮受力分析，推导F₁=f
  3. 点击「下一步」进入步骤2，高亮图(2)，讲解动滑轮省力原理，推导F₂=f/2
  4. 点击「下一步」进入步骤3，高亮图(3)，讲解动滑轮费力原理，推导F₃=2f
  5. 点击「下一步」进入步骤4，三种装置同时高亮，展示排序结论F₂<F₁<F₃和答案D
  6. 可随时点击「上一步」回退到任意步骤复习

[技术实现]
- JS 库选择：原生 SVG（简单几何图形绘制，无需额外库，轻量高效）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |  [步骤4结论区: F₂<F₁<F₃ / 答案:D]               | y=0~60
  +--------------------------------------------------+
  |  (1) 墙壁|定滑轮====F₁→         物体□            | y=60~180
  |       绳子绕过定滑轮                    f←        |
  |                                  [F₁=f]           |
  +--------------------------------------------------+
  |  (2) 墙壁====绳子→动滑轮←F₂         物体□        | y=190~310
  |       f/2标注                        f←           |
  |                                  [F₂=f/2]         |
  +--------------------------------------------------+
  |  (3) 墙壁====绳子→动滑轮→F₃    物体□              | y=320~440
  |       f张力标注    f摩擦←                       |
  |                                  [F₃=2f]          |
  +--------------------------------------------------+
  |         [◀上一步]  步骤 X/4  [下一步▶]            | y=440~490
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：当前步骤currentStep（0~4），每个步骤对应一组可见/隐藏元素和高亮状态
  2. 状态切换函数：renderStep(step) 根据步骤编号更新所有元素的可见性、透明度、高亮状态
  3. 元素分组：每个子图的元素用<g>分组，方便整体设置opacity
  4. 高亮外框：用<rect>元素，stroke-dasharray="8,4"，仅在对应步骤显示
  5. 关系式文本框：用<rect>+<text>组合，浅蓝背景#e3f2fd
  6. 箭头绘制：用<line>+<polygon>（箭头头部），箭头头部尺寸10×8
  7. 滑轮绘制：用<circle>，内部可加小圆表示轴心
  8. 地面阴影：用多条平行斜线（<line>），间距8px，角度45°
  9. 墙壁阴影：用多条平行斜线（<line>），间距8px，角度45°，在墙壁左侧
  10. 按钮事件绑定：click事件触发step++/step--，边界检查（0≤step≤4）
  11. 按钮禁用状态：步骤0时「上一步」disabled，步骤4时「下一步」disabled，样式变灰
- ID 命名规范：所有交互元素 ID 以 `scene1-` 为前缀
  - scene1-btn-prev、scene1-btn-next、scene1-step-indicator
  - scene1-group-fig1、scene1-group-fig2、scene1-group-fig3
  - scene1-highlight-fig1、scene1-highlight-fig2、scene1-highlight-fig3
  - scene1-friction-fig1、scene1-friction-fig2、scene1-friction-fig3
  - scene1-formula-fig1、scene1-formula-fig2、scene1-formula-fig3
  - scene1-conclusion、scene1-answer
- IIFE 隔离：所有 JS 代码包裹在 (function() { 'use strict'; ... })() 中，避免全局污染
- 动画过渡：使用 CSS transition 实现 opacity 和 transform 的平滑过渡（0.3s ease）
