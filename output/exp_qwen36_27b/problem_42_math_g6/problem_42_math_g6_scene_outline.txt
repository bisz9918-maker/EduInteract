    **题目原文：**

    如图是由一些相同的小正方形构成的几何体的三视图．
    有几个正方体（  ）
    A．4    B．5    C．6    D．7

    **题目分析：**

    本题考查"由三视图还原几何体"的核心能力。题目给出了一个由相同小正方体堆叠而成的几何体的三个视图：
    - **主视图（从正面看）**：左列2层高，中列1层高，右列1层高，共3列
    - **左视图（从左边看）**：左列2层高，右列1层高，共2列
    - **俯视图（从上面看）**：L形，共4个小正方形

    **整体讲解思路：**

    1. 先引导学生观察三视图，理解每个视图反映的信息
    2. 以俯视图为"地基"，确定底面有4个位置放了正方体
    3. 结合主视图和左视图，推断每个位置的正方体层数
    4. 最后汇总计算总数

    **图示规划说明：**

    共规划3个图示场景：
    - SCENE_1：三视图交互标注——帮助学生理解三视图与几何体的对应关系
    - SCENE_2：俯视图定位法——在俯视图上标注每个位置的正方体数量
    - SCENE_3：3D几何体逐步还原——从底面开始逐层堆叠，直观展示最终结果
    </TEXT_1>

    **教学要点：**

    本图示帮助学生建立三视图与几何体之间的对应关系。

    1. 引导学生观察：主视图反映几何体的"列"和"高"，左视图反映几何体的"行"和"高"，俯视图反映几何体的"列"和"行"

    2. 关键对应关系：
    - 主视图的列数 = 俯视图的列数（都是3列）
    - 左视图的列数 = 俯视图的行数（都是2行）
    - 主视图每列的高度 = 该列所有位置中最高的层数
    - 左视图每列的高度 = 该行所有位置中最高的层数

    3. 通过虚线箭头的连接，让学生直观看到三视图之间的信息关联，为下一步在俯视图上标注层数做铺垫

    **教学要点：**

    本图示演示"俯视图定位法"的具体操作过程，是解题的核心步骤。

    1. 推理逻辑讲解：
    - 左上角位置：主视图左列高2层，左视图左列（对应俯视图第一行）高2层 → 该位置有2个正方体
    - 中上位置：主视图中列高1层 → 该位置有1个正方体
    - 右上位置：主视图右列高1层 → 该位置有1个正方体
    - 左下位置：左视图右列（对应俯视图第二行）高1层 → 该位置有1个正方体

    2. 强调关键推理规则：每个位置的层数 = min(主视图该列高度, 左视图该行高度)

    3. 汇总：2 + 1 + 1 + 1 = 5，答案为B选项

    4. 可引导学生思考：为什么左上角一定是2层而不是其他位置？（因为主视图左列和左视图左列都显示2层，只有左上角同时属于左列和第一行）
    </TEXT_3>

    <TEXT_4>
    **教学要点与课堂总结：**

    本图示将抽象的三视图还原为直观的3D几何体，帮助学生建立空间想象能力。

    1. 构建过程讲解：
    - 从俯视图确定底面布局（4个位置）
    - 根据各位置层数逐层堆叠
    - 左上角位置堆2层，其余3个位置各堆1层
    - 最终得到由5个正方体组成的几何体

    2. 验证环节（步骤6）：
    - 从正面看：左列2层、中列1层、右列1层 ✓
    - 从左边看：左列2层、右列1层 ✓
    - 从上面看：L形4个位置 ✓
    - 三视图全部吻合，验证答案正确

    3. 课堂总结建议：
    - 方法总结：由三视图还原几何体，常用"俯视图定位法"
    - 核心规则：每个位置的层数 = min(主视图该列高度, 左视图该行高度)
    - 易错提醒：不要只数俯视图的小正方形个数（那是底面数量，不是总数）
    - 拓展思考：如果改变某个位置的层数，三视图会如何变化？

    4. 答案：B．5
    </TEXT_4>
