[分步序列]
本场景为多状态切换交互，共4个状态（对应4个选项），默认选中状态2（肺）：

- 初始状态（状态2：肺，默认选中）：
  - 血管a：蓝色填充（静脉血），标签"肺动脉"（上方）、"静脉血"（下方）
  - 器官b：圆形，标签"肺"，内部显示O₂箭头（红色，从外部指向血管）和CO₂箭头（蓝色，从血管指向外部）
  - 血管c：红色填充（动脉血），标签"肺静脉"（上方）、"动脉血"（下方）
  - 结论面板：选项"B."，✗ 错误，"血液流经肺后，肺静脉中流动脉血"
  - 按钮"肺"为激活态（蓝色背景）

- 状态1（心脏）：点击「心脏」按钮
  - 血管a：蓝色填充（静脉血），标签"静脉"（上方）、"静脉血"（下方）
  - 器官b：圆形，标签"心脏"，内部显示简化的四腔室示意（上下左右四个小区域）
  - 血管c：红色填充（动脉血），标签"动脉"（上方）、"动脉血"（下方）
  - 结论面板：选项"A."，✗ 错误，"心脏不同腔室输出血液类型不同，主动脉流动脉血"
  - 按钮"心脏"为激活态

- 状态3（小肠）：点击「小肠」按钮
  - 血管a：红色填充（动脉血），标签"肠动脉"（上方）、"动脉血"（下方）
  - 器官b：圆形，标签"小肠"，内部显示营养物质箭头（灰色虚线，从外部指向血管）和O₂消耗箭头
  - 血管c：蓝色填充（静脉血），标签"肠静脉"（上方）、"静脉血"（下方）
  - 结论面板：选项"C."，✗ 错误，"血液流经小肠后，肠静脉中流静脉血（含营养物质）"
  - 按钮"小肠"为激活态

- 状态4（组织细胞）：点击「组织细胞」按钮
  - 血管a：红色填充（动脉血），标签"动脉"（上方）、"动脉血"（下方）
  - 器官b：圆形，标签"组织细胞"，内部显示O₂箭头（红色，从血管指向细胞）和CO₂箭头（蓝色，从细胞指向血管）
  - 血管c：蓝色填充（静脉血），标签"静脉"（上方）、"静脉血"（下方）
  - 结论面板：选项"D."，✓ 正确，"血液流经组织细胞后，静脉中流静脉血"
  - 按钮"组织细胞"为激活态

[交互方案]
- 交互类型：多状态切换 — 4个按钮对应4个选项情境
- 控件说明：
  - 「心脏」按钮：(160,452)→(270,488)，点击切换至状态1（选项A情境）
  - 「肺」按钮：(290,452)→(400,488)，点击切换至状态2（选项B情境），默认激活
  - 「小肠」按钮：(420,452)→(530,488)，点击切换至状态3（选项C情境）
  - 「组织细胞」按钮：(550,452)→(660,488)，点击切换至状态4（选项D情境）
- 教师操作流程：
  1. 图示加载后默认展示「肺」的情境（选项B），教师可先讲解肺循环中血液成分的变化
  2. 教师点击其他按钮切换情境，对比不同器官中血液类型的变化
  3. 右侧结论面板实时显示当前选项的判断结果和依据
  4. 教师可引导学生观察：哪些情境下出血管流静脉血？最终得出正确答案D
  5. 按钮激活态用蓝色背景高亮，方便学生识别当前展示的情境

[技术实现]
- JS 库选择：原生 SVG（简单几何图形：圆形、线段、箭头、矩形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  +------------------------------------------------------------------+
  |  图示区(70%)                              结论面板(30%)           |
  |                                                                  |
  |     a血管                    器官b                    c血管      |
  |   ────────→    ╭──────────────╮    ←───────    +-----------+     |
  |   静脉血/      │              │    动脉血/     |  B.       |     |
  |   动脉血       │     肺       │    静脉血      |  ✗ 错误   |     |
  |   ────────→    ╰──────────────╮    ←───────    |  肺静脉   |     |
  |                               │                |  流动脉血 |     |
  |                               │                +-----------+     |
  |                                                                  |
  |                                                                  |
  |  ┌──────┐  ┌──────┐  ┌──────┐  ┌──────────┐                     |
  |  │心脏  │  │  肺  │  │ 小肠 │  │组织细胞  │  ← 底部按钮栏       |
  |  └──────┘  └──────┘  └──────┘  └──────────┘                     |
  +------------------------------------------------------------------+
  ```
- 关键实现要点：
  1. **状态机设计**：定义4个状态对象，每个状态包含：
     - a血管颜色（红/蓝）、a血管类型标签、a血液类型标签
     - b器官名称、b内部交换箭头配置（O₂/CO₂/营养物质）
     - c血管颜色（红/蓝）、c血管类型标签、c血液类型标签
     - 结论面板内容（选项字母、判断结果、依据文字）
  2. **切换逻辑**：点击按钮时，清除当前状态的所有动态元素，根据新状态配置重新渲染
  3. **动画过渡**：血管颜色切换使用CSS transition（0.3s ease），交换箭头出现使用opacity动画
  4. **事件绑定**：4个按钮分别绑定click事件，调用统一的switchState(stateIndex)函数
  5. **默认状态**：页面加载时自动调用switchState(1)（肺，索引从0开始则为1）
- ID 命名规范：所有交互元素 ID 以 `scene2-` 为前缀
  - 按钮：`scene2-btn-heart`、`scene2-btn-lung`、`scene2-btn-intestine`、`scene2-btn-tissue`
  - 血管a填充：`scene2-vessel-a-fill`
  - 血管c填充：`scene2-vessel-c-fill`
  - 器官b：`scene2-organ-b`
  - 交换箭头组：`scene2-exchange-arrows`
  - 结论面板：`scene2-conclusion-panel`
  - 结论文字：`scene2-conclusion-text`
  - 各标签：`scene2-label-a-type`、`scene2-label-a-blood`、`scene2-label-b-name`、`scene2-label-c-type`、`scene2-label-c-blood`
- IIFE 隔离：所有 JS 代码包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染
