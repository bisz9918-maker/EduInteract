[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位置(280,455) 100×36，点击返回上一步骤，步骤0时禁用
  - 步骤指示文字：位置(400,470)，显示当前步骤"X/5"
  - 「下一步 ▶」按钮：位置(520,455) 100×36，点击进入下一步骤，步骤5时禁用
- 教师操作流程：
  1. 教师展示步骤0（待填流程图），提问学生"甲、乙、a、b分别是什么？"
  2. 点击"下一步"逐步揭示答案，每步配合讲解（滤过→原尿→重吸收→尿液）
  3. 步骤4时重点讲解原尿与尿液成分差异（葡萄糖被重吸收）
  4. 步骤5展示完整流程，箭头动画帮助学生理解液体流动方向
  5. 可随时点击"上一步"回退复习

[技术实现]
- JS 库选择：原生 SVG（简单流程图，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌──────────────────────────────────────────────────────────────┐
  │                                                              │
  │  ┌──────────────┐  →  ┌──┐  形成  ┌──┐  →  ┌──┐  形成  ┌──┐│
  │  │血液流进       │     │甲 │──────→│a │────→│乙 │──────→│b ││
  │  │肾小球中       │     └──┘       └──┘     └──┘        └──┘│
  │  └──────────────┘                                          │
  │                    滤过         重吸收                      │
  │                         ┌──────────┐    ┌──────────┐       │
  │                         │原尿成分   │    │尿液成分   │       │
  │                         │水、无机盐 │    │水、无机盐 │       │
  │                         │葡萄糖、尿素│    │尿素       │       │
  │                         └──────────┘    └──────────┘       │
  │                              葡萄糖被重吸收                 │
  │                                                              │
  │                                                              │
  │              ┌──────────┐  ┌──────┐  ┌──────────┐          │
  │              │◀ 上一步  │  │ 1/5  │  │ 下一步 ▶ │          │
  │              └──────────┘  └──────┘  └──────────┘          │
  └──────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. **状态机设计**：维护全局变量 `currentStep`（0~5），每个步骤对应一组视觉状态（框颜色、文字内容、显示/隐藏元素）
  2. **SVG 元素管理**：使用 `<g>` 分组管理各步骤专属元素（如步骤1的"滤过"标注、步骤2的原尿成分框等），通过 `display: none/block` 控制显隐
  3. **框状态切换**：甲/a/乙/b 四个框各有两种状态（待填/已填），通过切换 fill/stroke 颜色和内部文字实现
  4. **箭头流动动画**：步骤5时，使用 SVG `<animate>` 或 CSS `@keyframes` 实现箭头沿线段方向的脉冲高亮效果（opacity 0.3→1→0.3 循环）
  5. **删除线效果**：步骤4时，原尿成分框中"葡萄糖"项添加 `<tspan text-decoration="line-through">` 或 CSS `text-decoration: line-through`
  6. **按钮状态管理**：步骤0时"上一步"按钮 disabled（灰色），步骤5时"下一步"按钮 disabled
  7. **事件绑定**：按钮点击事件绑定 `prevStep()` 和 `nextStep()` 函数，更新 `currentStep` 后调用 `renderStep(currentStep)` 重绘
- ID 命名规范：所有交互元素 ID 以 `scene1-` 为前缀
  - `scene1-box-blood`（起点框）
  - `scene1-box-jia`（甲框）
  - `scene1-box-a`（a框）
  - `scene1-box-yi`（乙框）
  - `scene1-box-b`（b框）
  - `scene1-arrow-1` ~ `scene1-arrow-4`（4条连接箭头）
  - `scene1-label-form1`、`scene1-label-form2`（"形成"标签）
  - `scene1-label-filtra`（"滤过"标注）
  - `scene1-label-reabsorb`（"重吸收"标注）
  - `scene1-panel-urine-pre`（原尿成分框）
  - `scene1-panel-urine-final`（尿液成分框）
  - `scene1-label-glucose`（"葡萄糖被重吸收"标注）
  - `scene1-btn-prev`（上一步按钮）
  - `scene1-btn-next`（下一步按钮）
  - `scene1-step-indicator`（步骤指示文字）
- IIFE 隔离：所有 JS 代码包裹在 `(function() { ... })()` 中，避免全局污染
