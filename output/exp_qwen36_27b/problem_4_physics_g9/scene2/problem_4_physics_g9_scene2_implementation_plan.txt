[视觉元素清单]

- 接线柱A、B、C、D：黑色小圆点，半径4px

  - 状态2：绿色#2e7d32（串联路径）

- 状态切换按钮：3个并排按钮，当前选中按钮高亮（填充色对应状态色），未选中按钮灰色

[分步序列]
- 初始状态（状态1：原始电路）：
  - 显示所有电路元件（电池组、开关S、L₁、L₂、导线a、b、M、固定导线）
  - 开关S处于闭合状态
  - 红色#c62828高亮短路路径：正极→D→导线b→B→导线M→S→负极
  - 短路路径上添加红色箭头指示电流方向
  - 底部标签："原始电路：S 闭合后短路"
  - 按钮1高亮

- 状态2（去掉导线b）：
  - 导线b变为灰色#888888虚线，并在其位置添加红色叉号标记
  - 绿色#2e7d32高亮串联路径：正极→D→L₂→C→导线a→A→L₁→B→导线M→S→负极
  - 串联路径上添加绿色箭头指示电流方向
  - 灯泡L₁、L₂填充绿色#2e7d32，透明度20%
  - 底部标签："去掉导线 b：L₁、L₂ 串联"
  - 按钮2高亮

- 状态3（M改接A）：
  - 导线b恢复为黑色实线
  - 导线M从B改接到A（导线M连接点从B(630,265)变为A(530,265)）
  - 蓝色#1565c0高亮两条并联支路：
    - 支路1：正极→D→L₂→C→导线a→A→导线M→S→负极
    - 支路2：正极→D→导线b→B→L₁→A→导线M→S→负极
  - 两条支路上添加蓝色箭头指示电流方向
  - 灯泡L₁、L₂填充蓝色#1565c0，透明度20%
  - 底部标签："M 改接 A：L₁、L₂ 并联"
  - 按钮3高亮

[交互方案]
- 交互类型：多状态切换（3个状态按钮）
- 控件说明：
  - 按钮1"原始电路"：点击后切换到状态1，显示原始短路电路
  - 按钮2"去掉导线b"：点击后切换到状态2，显示串联电路
  - 按钮3"M改接A"：点击后切换到状态3，显示并联电路
- 教师操作流程：
  1. 图示加载后默认显示状态1（原始电路），教师讲解短路现象
  2. 点击"去掉导线b"按钮，切换到状态2，讲解串联电路的形成
  3. 点击"M改接A"按钮，切换到状态3，讲解并联电路的形成
  4. 可随时点击任意按钮回退到之前的状态进行对比
  5. 配合题目选项A/B/C/D逐一分析

[技术实现]
- JS 库选择：原生 SVG（电路图为简单几何图形+曲线，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：

  ```
  └──────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. **状态机设计**：使用变量 `currentState`（1/2/3）管理当前状态，切换时清除旧状态的高亮元素，渲染新状态的高亮元素
  2. **SVG 元素分组**：
     - `scene2-base`：基础电路元件（始终显示）
     - `scene2-highlight`：电流路径高亮（随状态切换）
     - `scene2-arrows`：电流方向箭头（随状态切换）
     - `scene2-bulb-fill`：灯泡填充（随状态切换）
     - `scene2-controls`：控件栏（始终显示）
  3. **导线绘制**：使用 SVG `<path>` 的贝塞尔曲线（`C` 或 `Q` 命令）绘制弯曲导线
  4. **电流箭头**：使用 SVG `<marker>` 定义箭头，在路径上通过 `marker-mid` 或 `marker-end` 添加
  5. **状态切换动画**：使用 CSS transition 实现高亮路径的淡入淡出效果（0.3s ease）
  6. **按钮样式**：选中按钮填充对应状态色，未选中按钮灰色#e0e0e0，hover 效果加深
  7. **导线M改接动画**：状态3中导线M的终点从B(630,265)平滑移动到A(530,265)，使用 SVG `<animate>` 或 JS 动态修改 `d` 属性
  8. **删除标记**：状态2中导线b位置绘制灰色虚线+红色叉号（两条交叉线段）
- ID 命名规范：所有交互元素 ID 以 `scene2-` 为前缀
  - `scene2-btn-state1`、`scene2-btn-state2`、`scene2-btn-state3`
  - `scene2-highlight-group`、`scene2-arrow-group`、`scene2-bulb-fill-group`
  - `scene2-status-label`、`scene2-wire-b`、`scene2-wire-m`
- IIFE 隔离：所有 JS 代码包在 `(function() { 'use strict'; ... })();` 中
