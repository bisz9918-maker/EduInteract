    **题目原文：**

    下图中阴影部分为黑夜，虚线表示回归线和极圈，读图完成下列问题。

    （1）此时北京时间是________月________日________时________分。

    （2）此时太阳直射点的地理坐标是________、_______。

    （3）A、B、C三点地转偏向力最小的是________；自转线速度最快的是________。

    （4）此时新一天范围占全球范围的________（分数）。

    **题目分析：**

    本题是一道典型的地球光照图综合题，考查极地俯视图的判读能力。图中阴影部分为黑夜，虚线表示回归线和极圈，0°经线在左侧，A、B、C三点位于右侧同一条经线上，O点在最右侧表示太阳直射方向。

    **核心知识点：**
    - 极地俯视图的判读（北极/南极、自转方向）
    - 晨昏线的识别与地方时计算
    - 太阳直射点坐标的确定
    - 地转偏向力与自转线速度的纬度变化规律
    - 日期范围的计算（新旧一天分界线）

    **整体讲解思路：**

    本题所有小问都基于同一幅极地俯视图，因此规划为**一个综合图示**，通过分步按钮导航逐步展开五个认知阶段：①基础图形识别 → ②晨昏线与地方时 → ③太阳直射点坐标 → ④A/B/C三点比较 → ⑤日期范围计算。这样既避免了相似图示的重复，又形成了从图形判读到综合计算的完整教学递进。

    **图示规划说明：**

    共规划 1 个场景（SCENE_1），整合全部四个小问的图示需求。采用分步按钮导航交互，教师可逐步引导学生从图形识别到计算推导。

    **SCENE_1 教学说明：**

    **步骤0 → 步骤1：图形识别与晨昏线判读**

    教师引导学生观察基础图形：

    1. 首先确认这是**北极俯视图**——依据是地球自转方向为逆时针（从北极上空看）
    2. 识别阴影部分为**黑夜**，白色部分为**白昼**
    3. 找到晨昏线（昼夜分界线），判断0°经线位于晨线上（从黑夜进入白昼的方向为自转方向，即向东）
    4. 晨线上的地方时为**6:00**，所以0°经线的地方时是6:00
    5. 观察北极圈内全部为黑夜（极夜现象），说明太阳直射南半球，此时为**冬至日（12月22日）**

    **步骤1 → 步骤2：北京时间计算**

    引导学生进行地方时换算：

    1. 已知0°经线地方时为6:00
    2. 北京时间 = 120°E的地方时
    3. 120°E比0°经线靠东120°，时间差 = 120° ÷ 15°/h = 8小时
    4. 北京时间 = 6:00 + 8h = **14:00**
    5. 日期为**12月22日**

    **步骤2 → 步骤3：太阳直射点坐标确定**

    引导学生推导太阳直射点位置：

    1. **纬度**：北极圈出现极夜 → 太阳直射南回归线 → **23°26'S**
    2. **经度**：太阳直射点所在经线地方时为12:00
    3. 0°经线为6:00，12:00的经线比0°经线靠东6小时 = 90°
    4. 所以太阳直射点经度为**90°E**
    5. 太阳直射点坐标：**(23°26'S, 90°E)**

    **步骤3 → 步骤4：A/B/C三点比较**

    引导学生理解纬度对地转偏向力和线速度的影响：

    1. **地转偏向力**：与纬度成正比，纬度越高，地转偏向力越大；纬度越低，地转偏向力越小
    2. **自转线速度**：与纬度成反比，纬度越高，线速度越小；纬度越低，线速度越大
    3. A、B、C三点中，**C点纬度最低**（最靠近赤道方向）
    4. 所以地转偏向力最小的是**C**，自转线速度最快的也是**C**

    **步骤4 → 步骤5：日期范围计算**

    引导学生计算新旧一天范围：

    1. 新一天的起点是地方时**0:00**的经线
    2. 0°经线为6:00，0:00的经线比0°经线靠西6小时 = 90°
    3. 所以0:00的经线是**90°W**
    4. 新一天范围：从90°W向东到180°，跨度 = 90° + 180° = **270°**
    5. 占全球比例 = 270°/360° = **3/4**

    **课堂讲解建议：**

    - 在步骤1强调晨昏线判读的关键：顺着自转方向，从黑夜进入白昼为晨线，从白昼进入黑夜为昏线
    - 在步骤3提醒学生：太阳直射点的经度永远是地方时12:00的经线，这是一个重要规律
    - 在步骤5可以用扇形图直观展示3/4的范围，帮助学生建立空间概念
    - 整道题的核心是**先判图，再计算**，图形判读正确是后续所有计算的基础
