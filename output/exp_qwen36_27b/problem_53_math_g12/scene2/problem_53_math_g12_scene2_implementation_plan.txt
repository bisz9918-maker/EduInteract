[图示主题与整合说明]
- 本图示主题：将空间比例问题降维到平面三角形中，通过平行线分线段成比例定理完成计算
- 整合的步骤/概念：
  ① 将四棱锥 P-ABCD 中的空间关系分解为两个平面三角形 △ACD（底面）和 △PCD（侧面）
  ② 在 △ACD 中，利用 ME ∥ AD 推导 CE:ED = CM:MA = 1:4
  ③ 在 △PCD 中，利用 NE ∥ PD 推导 NC:NP = CE:ED = 1:4
  ④ 通过 CE:ED 作为"公共比例桥梁"，完成从已知 CM:MA 到未知 NC:NP 的比例传递
- 教学价值：教师可通过分步导航，逐步展示空间几何问题如何降维为平面几何问题，清晰呈现"平行线分线段成比例"定理在两个三角形中的应用，以及比例关系的传递链条。每一步都有明确的视觉变化，帮助学生理解推理过程。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位置(150,450)，宽100px，高36px，步骤0时禁用
  - 「下一步 ▶」按钮：位置(550,450)，宽100px，高36px，步骤3时禁用
  - 步骤指示器：位置(350,455)，显示"步骤 X/3"，居中
- 教师操作流程：
  1. 图示加载后显示步骤0（基础条件），教师可讲解题目已知条件
  2. 点击「下一步 ▶」进入步骤1，展示左侧△ACD中的比例推导
  3. 点击「下一步 ▶」进入步骤2，展示右侧△PCD中的比例推导
  4. 点击「下一步 ▶」进入步骤3，展示最终结论
  5. 可随时点击「◀ 上一步」回退到前一步复习
  6. 步骤指示器实时显示当前步骤，帮助教师定位讲解进度

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  [图示区 800×500]
  ┌──────────────────────────────────────────────────────────────┐
  │                                                              │
  │         △ACD                              △PCD               │
  │                                                              │
  │              D                                  D             │
  │             / \                                / \            │
  │            /   \                              /   \           │
  │           / M   \          ME∥AD            / N   \          │
  │          /  \   \                          /  \   \          │
  │         /    \  \                        /    \   \          │
  │        /  E   \ \                      /  E   \   \          │
  │       /        \ \                    /        \   \          │
  │      /          \ \                  /          \   \          │
  │     A────────────C                   C───────────D           │
  │     CM:MA=1:4    CE:ED=1:4           NC:NP=CE:ED  P           │
  │                                                              │
  │                    ←公共比例桥梁→                             │
  │                                                              │
  │              NC:NP = CE:ED = CM:MA = 1:4                     │
  │                                                              │
  │           [◀ 上一步]    步骤 X/3    [下一步 ▶]               │
  └──────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：使用变量 currentStep (0-3) 跟踪当前步骤，每个步骤对应一组可见/隐藏的元素
  2. 元素显示/隐藏：通过 SVG 元素的 visibility 或 opacity 属性控制，步骤切换时更新
  3. 高亮效果：通过叠加加粗线段（stroke-width: 3px）实现，而非修改原有线段
  4. 动画过渡：步骤切换时使用 CSS transition (opacity 0.3s ease) 实现淡入淡出效果
  5. 事件绑定：按钮点击事件绑定到 showStep(step) 函数，更新 currentStep 并刷新视图
  6. 按钮禁用状态：步骤0时「上一步」disabled，步骤3时「下一步」disabled
- ID 命名规范：所有交互元素 ID 以 `scene2-` 为前缀
  - 按钮：scene2-prev-btn、scene2-next-btn
  - 步骤指示器：scene2-step-indicator
  - 三角形：scene2-tri-acd、scene2-tri-pcd
  - 辅助线：scene2-line-me、scene2-line-ne
  - 高亮线段：scene2-highlight-ce-left、scene2-highlight-ed-left、scene2-highlight-nc、scene2-highlight-np
  - 标签组：scene2-label-cm-ma、scene2-label-ce-ed-left、scene2-label-nc-np 等
- IIFE 隔离：所有 JS 代码包裹在 (function() { ... })() 中，避免全局污染
