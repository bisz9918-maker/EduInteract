[图示主题与整合说明]
- 本图示主题：相邻两层圆半径递推关系的几何推导
- 整合的步骤/概念：通过放大展示“外接圆→内接正六边形→内切圆”的局部结构，利用直角三角形边角关系，逐步推导相邻圆半径的递推公式 $R_{n+1} = R_n \cdot \frac{\sqrt{3}}{2}$，并引出通项公式。
- 教学价值：教师可通过分步按钮控制信息呈现节奏，先展示基础几何结构，再逐步添加辅助线与标注，引导学生观察直角三角形中的角度与边长关系，自然得出递推结论，避免一次性灌输过多信息，符合认知规律。

[分步序列]
- 初始状态（步骤0）：显示外接圆、正六边形、圆心O、顶点A、边中点M。图形居中偏左，右侧留白。
- 步骤1：点击「下一步」→ 出现半径OA（蓝色），左侧标注"Rₙ"。OA线段带动画绘制效果（stroke-dashoffset过渡）。
- 步骤2：点击「下一步」→ 出现半径OM（红色），上方标注"Rₙ₊₁"；出现角度弧（蓝色）及标签"30°"。OM线段带动画绘制效果。
- 步骤3：点击「下一步」→ 出现辅助线AM（灰色虚线）及M点直角标记；右侧出现递推关系文本框，高亮显示 $R_{n+1} = R_n \cdot \cos 30° = R_n \cdot \frac{\sqrt{3}}{2}$。
- 步骤4：点击「下一步」→ 以O为圆心、OM为半径绘制内切圆（绿色实线），覆盖在六边形内部，直观展示内切关系。
- 步骤5：点击「下一步」→ 右侧公式文本框更新/展开，显示最终递推公式 $R_{n+1} = \frac{\sqrt{3}}{2} R_n$ 与通项公式 $R_n = \left(\frac{\sqrt{3}}{2}\right)^{n-1}$。步骤3的临时文本淡出。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于底部左侧 (150,460)，点击返回上一状态，元素按逆序隐藏/还原。
  - 「下一步 ▶」按钮：位于底部右侧 (550,460)，点击进入下一状态，新元素按动画序列出现。
  - 步骤指示器：位于底部居中 (350,460)，显示当前步骤 "0/5" ~ "5/5"。
- 教师操作流程：教师讲解时，初始展示基础图形（步骤0）。每讲解完一个几何关系，点击「下一步」逐步添加半径、角度、辅助线及公式。若学生未理解，可点击「上一步」回退至关键步骤重新强调。按钮状态随步骤禁用/启用（步骤0禁用上一步，步骤5禁用下一步）。

[技术实现]
- JS 库选择：原生 SVG（几何图形绘制与动画性能最佳） + MathJax（公式文本框内数学公式渲染，确保分数、根号、下标排版专业）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |                  图示区 (800×440)                |
  |  [外接圆+六边形]      [公式文本框]               |
  |      O A M Rₙ Rₙ₊₁ 30°                          |
  |                                                  |
  +--------------------------------------------------+
  |  [◀ 上一步]   [0/5]   [下一步 ▶]   (y=450~490)   |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  - 状态机设计：维护 `currentStep` (0~5)，每个步骤对应一组 SVG 元素的 `visibility` 或 `opacity` 控制。使用 CSS transition 实现淡入/绘制动画。
  - 坐标计算：所有顶点、中点、标签位置预计算并硬编码，避免运行时动态计算导致偏移。
  - 动画曲线：线段绘制使用 `stroke-dasharray` 与 `stroke-dashoffset` 配合 `transition: all 0.6s ease`；文本/公式框使用 `opacity` 0→1 过渡。
  - 事件绑定：按钮点击触发 `updateStep(delta)` 函数，更新 `currentStep` 并调用 `renderStep(step)` 切换元素状态。
  - ID 命名规范：所有交互元素及关键图形 ID 以 `scene2-` 为前缀，如 `scene2-circle-outer`, `scene2-line-oa`, `scene2-btn-next`, `scene2-formula-box`。
  - JS 隔离：全部代码包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染。MathJax 配置通过 `MathJax.typesetPromise()` 异步渲染公式区域。
  - 防重叠保障：严格按布局坐标表定位，标签使用 `text-anchor` 和 `dominant-baseline` 精确对齐，确保视觉居中且不压线。
