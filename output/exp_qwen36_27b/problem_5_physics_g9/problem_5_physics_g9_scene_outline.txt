    **题目原文：**

    如图所示的电路中，电流表测量的是（）

    A. 通过灯L₁的电流
    B. 通过灯L₂的电流
    C. 通过灯L₁和灯L₂的电流之和
    D. 电源供给电路的总电流

    **题目分析：**

    本题考察初中物理电路分析能力，核心知识点包括：
    1. 实物连接图与电路图的对应关系
    2. 串并联电路的识别
    3. 电流表的正确使用方法（电流表与被测用电器串联）
    4. 电流路径的追踪方法

    **电路分析（教师参考）：**

    从实物连接图追踪电流路径：
    - 电源正极 → 开关 → 电流表正接线柱
    - 从电流表正接线柱处分出两条支路：
      - 支路1：电流表负接线柱 → 灯L₁ → 电源负极
      - 支路2：灯L₂ → 电源负极
    - 因此L₁与L₂并联，电流表与L₁串联，测量的是通过L₁的电流

    **正确答案：A**

    **整体讲解思路：**

    1. 首先引导学生观察实物连接图，识别电路中的元件（电源、开关、电流表、两个灯泡）
    2. 将实物连接图转换为标准电路图，这是解题的关键步骤
    3. 在电路图上用"电流路径法"追踪电流流向
    4. 判断电路连接方式（并联）
    5. 确定电流表与哪个用电器串联，从而得出测量对象
    6. 总结：电流表测量的是与它串联的用电器所在支路的电流

    **图示规划说明：**

    本规划包含两个图示场景：
    - Scene 1：实物图→电路图转换 + 电流路径追踪（核心分析过程）
    - Scene 2：电路结构总结与电流表测量原理（知识巩固）
    </TEXT_1>

    **Scene 1 教学说明：**

    **如何引导学生观察：**

    1. **步骤0→步骤1（实物图→电路图）：**
    - 提问学生："图中有哪些电路元件？"引导学生识别电源、开关、电流表、两个灯泡
    - 提问："谁能试着画出这个电路的电路图？"
    - 展示电路图时，用虚线对应关系帮助学生理解实物与符号的对应
    - 强调：画电路图是分析电路问题的基本功

    2. **步骤1→步骤2（电流方向标注）：**
    - 讲解电流路径追踪方法："从电源正极出发，顺着导线走"
    - 引导学生观察："电流走到哪里分叉了？"——找到分流点
    - 提问："分叉后有几条路？"——两条，说明是并联
    - 标注I总、I₁、I₂，建立电流关系：I总 = I₁ + I₂

    3. **步骤2→步骤3（高亮L₁支路）：**
    - 提问："电流表在哪个位置？"——在L₁支路上
    - 强调关键知识点："电流表与被测用电器串联"
    - 引导学生得出结论："电流表和L₁串联，所以测量的是L₁的电流"

    4. **步骤3→步骤4（高亮L₂支路）：**
    - 提问："L₂的电流经过电流表吗？"——不经过
    - 对比两条支路，强化理解：电流表只测它所在支路的电流

    5. **步骤4→步骤5（结论）：**
    - 总结解题方法：实物图→电路图→追踪电流→判断串并联→确定电流表测量对象
    - 给出答案：A. 通过灯L₁的电流

    **关键公式/知识点：**
    - 并联电路电流关系：I总 = I₁ + I₂
    - 电流表使用规则：电流表与被测用电器串联
    - 电流表测量的是与它串联的支路电流，不是干路电流

    **常见错误分析：**
    - 错误1：认为电流表测总电流（选D）——没有正确追踪电流路径
    - 错误2：认为电流表测L₂电流（选B）——没有看清电流表与哪个灯泡串联
    - 错误3：认为电流表测两灯电流之和（选C）——混淆了电流表的位置
    </TEXT_2>

    **Scene 2 教学说明：**

    **如何引导学生观察：**

    1. **状态1（测L₁电流）：**
    - 回顾原题情境："这就是我们刚才分析的题目，电流表和L₁串联"
    - 强调："电流表测的是它所在支路的电流"

    2. **状态2（测L₂电流）：**
    - 提问："如果电流表移到L₂支路上，它测谁的电流？"
    - 引导学生观察电流表位置变化，理解"串联决定测量对象"

    3. **状态3（测总电流）：**
    - 提问："如果电流表放在干路上呢？"
    - 强调："干路电流 = 各支路电流之和"
    - 公式：I总 = I₁ + I₂

    **知识总结：**

    电流表在并联电路中的测量规律：
    - 电流表与哪个用电器串联，就测哪个用电器的电流
    - 电流表在干路上，测的是总电流
    - 判断方法：追踪电流路径，看电流表在哪个位置

    **解题方法总结（板书建议）：**

    1. 识别电路元件
    2. 画出电路图
    3. 追踪电流路径（从正极出发）
    4. 判断串并联
    5. 确定电流表位置→确定测量对象

    **课堂练习建议：**

    可以在此基础上变式训练：
    - 改变电流表位置，让学生判断测量对象
    - 给出电路图，让学生画出对应的实物连接图
    - 增加电压表，让学生同时判断电流表和电压表的测量对象
