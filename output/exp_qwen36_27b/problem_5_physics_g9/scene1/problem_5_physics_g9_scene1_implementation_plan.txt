[图示主题与整合说明]
- 本图示主题：从实物连接图到电路图的分析，追踪电流路径判断电流表测量对象
- 整合的步骤/概念：实物图展示 → 电路图绘制 → 电流方向标注 → 支路高亮 → 结论得出

[技术实现]

- JS 库选择：原生 SVG（本场景为几何图形和电路符号，SVG 最适合精确绘制线条、圆圈、箭头等元素，且支持 CSS 动画和交互）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │  [左侧实物图区域 x:20~320]    [右侧电路图区域 x:340~780]    │
  │                                                             │
  │   电池组(+) ─── 开关(右上)                                    │
  │      │          │                                            │
  │      │    电流表 │                                            │
  │      │      │    │                                            │
  │   L₁(左下)  L₂(右下)                                      │
  │                                                             │
  │   电源  开关  分流点                                         │
  │    │    │    │                                               │
  │    │    │  电流表  L₁                                        │
  │    │    │    │    │                                          │
  │    │    └────┤    │                                          │
  │    │         │    │                                          │
  │    │         └── L₂                                          │
  │    │                                                         │
  │    └─────────────────────────────────────────────────────────┘
  │                                                             │
  │  ┌──────────┐  步骤 X/5: xxxxx  ┌──────────┐               │
  │  │ ◀ 上一步  │                   │ 下一步 ▶  │               │
  │  └──────────┘                   └──────────┘               │
  └─────────────────────────────────────────────────────────────┘
  ```

- 关键实现要点：

  1. **状态机设计**：
     - 使用全局变量 `currentStep`（0-5）跟踪当前步骤
     - 每个步骤对应一个渲染函数 `renderStep(step)`，根据 step 值决定显示哪些元素
     - 状态转换：点击按钮 → 更新 currentStep → 调用 renderStep → 更新按钮状态

  2. **SVG 元素管理**：
     - 所有 SVG 元素按步骤分组（group），用 `<g id="scene1-step0">`、`<g id="scene1-step1">` 等
     - 每个步骤的元素在对应 group 中，通过 CSS class 控制显隐
     - 步骤0元素始终显示，步骤1+元素初始 hidden，逐步显示

  3. **实物图绘制**：
     - 电池组：`<rect>` + 内部 `<line>` 表示三节电池
     - 开关：`<line>` + `<circle>` 表示刀开关和接线柱
     - 电流表：`<rect>` + `<circle>`（表盘）+ `<line>`（指针）+ `<text>`（A）
     - 灯泡：`<circle>` + `<line>`（灯丝）+ `<rect>`（底座）
     - 导线：`<path>` 使用贝塞尔曲线模拟真实连线走向

  4. **电路图绘制**：
     - 电源：两条 `<line>`（长线和短线）
     - 开关：`<line>` + `<line>`（刀开关）
     - 电流表/灯泡：`<circle>` + `<text>`
     - 导线：`<polyline>` 直角转折
     - 节点：`<circle>` 实心小圆

  5. **动画效果**：
     - 步骤切换时使用 CSS transition（opacity 0.3s ease）实现淡入淡出
     - 电流箭头使用 SVG `<marker>` 定义箭头形状
     - 支路高亮使用 `<path>` 描边 + `<polygon>` 半透明填充

  6. **坐标计算**：
     - 所有坐标已在布局坐标表中精确规划
     - 电流箭头位置根据导线中点计算
     - 对应虚线从实物图元件中心水平延伸到电路图对应元件

  7. **事件绑定**：
     - 按钮点击事件：`document.getElementById('scene1-prev').addEventListener('click', ...)`
     - 使用 `getElementById` 而非 `querySelectorAll`，配合 `scene1-` 前缀避免多场景污染

  8. **ID 命名规范**：
     - 所有交互元素 ID 以 `scene1-` 为前缀
     - 示例：`scene1-prev`（上一步按钮）、`scene1-next`（下一步按钮）、`scene1-step-info`（步骤提示）、`scene1-circuit-svg`（SVG容器）、`scene1-conclusion-box`（结论文本框）

  9. **IIFE 隔离**：
