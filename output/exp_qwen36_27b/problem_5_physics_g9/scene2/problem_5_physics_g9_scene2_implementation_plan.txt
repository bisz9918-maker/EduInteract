[图示主题与整合说明]
- 本图示主题：并联电路电流表测量原理总结与变式对比
- 整合的步骤/概念：电流表在并联电路中不同位置（L₁支路、L₂支路、干路）的测量对象对比，强化“电流表与谁串联就测谁的电流”的核心规律
- 教学价值：教师可通过三种状态的自由切换，直观展示电流表位置变化与测量对象变化的对应关系。高亮区域与电流标注同步切换，帮助学生建立完整的认知框架，突破“电流表测哪段电路”的易错点，适用于课堂讲解与随堂提问。

[视觉元素清单]
- 电路骨架：电源（电池符号）、开关S、分流/汇流节点、导线（黑色2px折线）
- 负载元件：灯泡L₁、L₂（直径30px圆圈，内含黑色×号）
- 测量元件：电流表A（直径36px圆圈，内含大写字母A，白底黑边）
- 高亮区域：三个半透明矩形（20%透明度），分别对应L₁支路、L₂支路、干路，默认隐藏，随状态显示
- 电流标注：I₁（蓝色）、I₂（绿色）、I总（红色），仅在当前激活状态显示
- 电流方向箭头：蓝色实心小三角，标注在导线中点，指示电流从正极流出方向
- 控件：3个圆角矩形按钮（rx=6），未选中态白底灰边(#cccccc)，选中态对应颜色底白字
- 结论框：白色背景矩形，边框颜色随状态切换（蓝/绿/红），内部显示当前测量结论
- 颜色/样式严格沿用 `<SCENE_2>` 声明：背景#ffffff，主线#000000(2px)，蓝#1565c0，绿#2e7d32，红#c62828，辅助#888888，按钮边框#cccccc

[分步序列]
- 初始状态（状态1，默认加载）：
  - 显示完整并联电路骨架（电源、开关、导线、L₁、L₂）
  - 电流表A位于L₁支路 (520,230)
  - L₁支路高亮区显示（蓝色20%透明），L₁灯泡描边变蓝
  - 显示标签"I₁"（蓝色），隐藏"I₂"和"I总"
  - 按钮"测L₁电流"为选中态（蓝底白字），其余为未选中态
  - 结论框显示："电流表测量：通过L₁的电流（I₁）"，边框蓝色
- 切换至状态2（点击"测L₂电流"）：
  - 电流表A平滑移动至L₂支路 (520,280)（0.3s ease-in-out）
  - L₁高亮区/描边恢复默认，L₂支路高亮区显示（绿色20%透明），L₂灯泡描边变绿
  - 隐藏"I₁"，显示"I₂"（绿色）
  - 按钮"测L₂电流"变为选中态（绿底白字）
  - 结论框更新："电流表测量：通过L₂的电流（I₂）"，边框绿色
- 切换至状态3（点击"测总电流"）：
  - 电流表A平滑移动至干路 (400,180)
  - L₂高亮区/描边恢复默认，干路高亮区显示（红色20%透明）
  - 隐藏"I₂"，显示"I总"（红色）
  - 按钮"测总电流"变为选中态（红底白字）
  - 结论框更新："电流表测量：总电流（I总 = I₁ + I₂）"，边框红色
- 任意状态间可自由切换，视觉元素同步平滑过渡，无闪烁

[交互方案]
- 交互类型：多状态切换（3个按钮）
- 控件说明：
  - 「测L₁电流」：位于(200,400)，点击切换至状态1，高亮L₁支路，电流表移至L₁串联位置
  - 「测L₂电流」：位于(340,400)，点击切换至状态2，高亮L₂支路，电流表移至L₂串联位置
  - 「测总电流」：位于(480,400)，点击切换至状态3，高亮干路，电流表移至干路位置
- 教师操作流程：
  1. 页面加载默认显示状态1（测L₁），教师可先提问“此时电流表测谁的电流？”
  2. 点击「测L₂电流」，观察电流表位置变化与高亮区域切换，引导学生对比
  3. 点击「测总电流」，展示干路测量情形，总结 I总 = I₁ + I₂
  4. 可反复切换任意状态，配合板书或口头讲解强化“串联测电流”的核心规律
  5. 结论框实时同步显示测量对象，便于学生记录笔记

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无需第三方库，轻量高效，完全满足几何图形绘制与状态切换需求）
- 画布尺寸：800 × 500 px（固定 viewBox）
- 布局草图（ASCII）：
  ```
  [ 800×500 SVG 画布 ]
  ┌─────────────────────────────────────────────────────────────┐
  │  (150,180)电源  ──────────────── S ──────────────── (650,180)│
  │  │                                                       │  │
  │  │                                              分流点●   │  │
  │  │                                                       │  │
  │  │  ──── L₁ ──── A ──── (状态1高亮蓝)                    │  │
  │  │  ──── L₂ ──── (状态2高亮绿)                           │  │
  │  │                                                       │  │
  │  (150,280)◄───────────────────────────────────────────────┘  │
  │                                                             │
  │  [测L₁电流]   [测L₂电流]   [测总电流]                       │
  │  ┌─────────────────────────────────────────────────────┐   │
  │  │ 电流表测量：通过L₁的电流（I₁）                       │   │
  │  └─────────────────────────────────────────────────────┘   │
  └─────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：维护全局变量 `currentState = 1/2/3`，点击按钮时调用 `switchState(n)`
  2. 坐标计算：电流表位置预定义为 `posMap = {1: {cx:520, cy:230}, 2: {cx:520, cy:280}, 3: {cx:400, cy:180}}`
  3. 动画曲线：使用 CSS `transition: all 0.3s ease-in-out` 作用于电流表 `<g>` 的 `transform` 属性，或 JS 直接修改 `cx`/`cy` 配合 `<animate>` 实现平滑移动
  4. 高亮切换：通过切换 SVG 元素的 `class`（如 `.hl-blue`, `.hl-green`, `.hl-red`）控制透明度、描边颜色与显示/隐藏（`opacity` 或 `display`）
  5. 事件绑定：按钮绑定 `click` 事件，阻止默认行为，触发状态更新函数
  6. 防抖/节流：无需，状态切换频率低，直接响应即可
- ID 命名规范：所有交互元素与关键图形 ID 均以 `scene2-` 为前缀，例如：
  `scene2-battery`, `scene2-switch`, `scene2-node-split`, `scene2-node-merge`,
  `scene2-wire-main`, `scene2-wire-l1`, `scene2-wire-l2`,
  `scene2-bulb-l1`, `scene2-bulb-l2`, `scene2-ammeter`,
  `scene2-hl-l1`, `scene2-hl-l2`, `scene2-hl-main`,
  `scene2-label-i1`, `scene2-label-i2`, `scene2-label-itotal`,
  `scene2-btn-l1`, `scene2-btn-l2`, `scene2-btn-total`,
  `scene2-conclusion-box`, `scene2-conclusion-text`
- IIFE 隔离：全部 JS 逻辑包裹在 `(function() { 'use strict'; ... })();` 中，避免全局变量污染，多场景合并时互不干扰
- 兼容性：SVG 2D 原生支持，CSS transition 广泛兼容，无需 polyfill
