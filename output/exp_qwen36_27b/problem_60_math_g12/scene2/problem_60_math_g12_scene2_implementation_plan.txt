[图示主题与整合说明]
- 本图示主题：椭圆中切线性质 PC·PD = PF₁·PF₂ 的类比演示（Scene 2）
- 整合的步骤/概念：
  1. 展示椭圆的完整几何结构（长轴、焦点、切线）
  2. 通过滑块拖动点 P 沿椭圆移动，实时观察各线段长度变化
  3. 数值面板实时验证 PC·PD = PF₁·PF₂ 恒成立
  4. 底部类比提示：圆中 PO² → 椭圆中 PF₁·PF₂
- 教学价值：教师可通过拖动滑块展示"无论 P 点在椭圆上何处，PC·PD 始终等于 PF₁·PF₂"，直观验证椭圆切线性质，并与 Scene 1（圆的情况）形成类比对比，帮助学生理解从圆到椭圆的推广。

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：
  1. 滑块（HTML `<input type="range">`）：
     - 位置：SVG 内底部，x=150~650，y=460
     - 范围：0~360（对应椭圆参数角 0°~360°）
     - 初始值：60（对应 P 点在第一象限）
     - 作用：拖动滑块改变 P 点在椭圆上的位置
  2. 滑块标签：
     - 位置：(400, 445)
     - 内容："拖动滑块改变 P 点位置"
- 教师操作流程：
  1. 图示加载后，展示完整的椭圆几何结构和初始数值
  2. 教师拖动滑块，P 点沿椭圆移动
  3. 切线 CD、交点 C/D、线段 PF₁/PF₂ 实时更新
  4. 数值面板实时显示各线段长度及乘积
  5. 教师可引导学生观察：无论 P 点在哪，PC·PD 始终等于 PF₁·PF₂
  6. 教师可将 P 点拖到特殊位置（如顶点、短轴端点）验证结论
  7. 结合 Scene 1（圆的情况），引导学生理解从圆到椭圆的类比推广

[技术实现]
- JS 库选择：原生 SVG + JavaScript（无需额外库，几何计算简单，原生 SVG 足够）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  +------------------------------------------------------------------+
  |  [几何图形区 x=20~560]        |  [数值面板 x=570~770]            |
  |                              |                                  |
  |        C ●                   |  ┌──────────────────────┐         |
  |         |\                   |  │   线段长度           │         |
  |          | \ P ●             |  │   PC = 289.3         │         |
  |           |  |\              |  │   PD = 96.4          │         |
  |            |   | \           |  │   PF₁ = 112.9        │         |
  |      A ●---F₂--O--F₁---B ●  |  │   PF₂ = 246.9        │         |
  |            |   |  /          |  │   ──────────────     │         |
  |             |  | /           |  │   PC·PD = 27889      │         |
  |              | /             |  │   PF₁·PF₂ = 27875    │         |
  |               D ●            |  └──────────────────────┘         |
  |                              |                                  |
  |              PC·PD = PF₁·PF₂|                                  |
  |         圆中PO²→椭圆中PF₁·PF₂|                                  |
  +------------------------------------------------------------------+
  |  拖动滑块改变 P 点位置                                            |
  |  |================o================|                             |
  +------------------------------------------------------------------+
  ```
- 关键实现要点：
  1. **椭圆参数**：中心 O(290,220)，a=180，b=120，c=√(a²-b²)≈134
  2. **P 点坐标计算**：给定参数角 θ，P = (290 + a·cosθ, 220 - b·sinθ)
  3. **切线方程计算**：椭圆 (x-h)²/a² + (y-k)²/b² = 1 在点 P(x₀,y₀) 处的切线为 (x₀-h)(x-h)/a² + (y₀-k)(y-k)/b² = 1
  4. **交点 C/D 计算**：
     - C：切线与 x=110（AC 线）的交点
     - D：切线与 x=470（BD 线）的交点
  5. **线段长度计算**：dist(P1,P2) = √((x₁-x₂)² + (y₁-y₂)²)
  6. **滑块事件绑定**：监听 input 事件，更新 θ 值，重新计算所有坐标并重绘
  7. **重绘策略**：每次滑块变化时，更新 SVG 元素的属性（x1,y1,x2,y2 等），而非销毁重建
  8. **数值面板更新**：使用 SVG `<text>` 元素的textContent 更新数值
  9. **动画平滑**：滑块拖动时无额外动画，直接更新（实时响应）
  10. **特殊位置处理**：当 P 接近 A 或 B 时，切线趋于水平，C/D 可能趋于无穷远，需做边界处理（限制 θ 范围在 5°~175° 和 185°~355°，避免 P 在长轴端点）

- **ID 命名规范**：所有交互元素 ID 以 `scene2-` 为前缀
  - `scene2-ellipse`：椭圆元素
  - `scene2-axis-ab`：长轴 AB
  - `scene2-point-o`、`scene2-point-a`、`scene2-point-b`：点 O/A/B
  - `scene2-point-f1`、`scene2-point-f2`：焦点 F₁/F₂
  - `scene2-point-p`：点 P
  - `scene2-tangent-ac`、`scene2-tangent-bd`：切线 AC/BD
  - `scene2-tangent-cd`：切线 CD
  - `scene2-point-c`、`scene2-point-d`：点 C/D
  - `scene2-seg-pf1`、`scene2-seg-pf2`：线段 PF₁/PF₂
  - `scene2-label-*`：所有标签元素
  - `scene2-panel-*`：数值面板元素
  - `scene2-slider`：滑块控件
  - `scene2-conclusion`：结论公式
  - `scene2-analogy`：类比提示

- **IIFE 隔离**：所有 JS 代码包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染

- **边界处理**：
  - 滑块范围限制为 5°~175° 和 185°~355°（跳过长轴端点附近 ±5°）
  - 当 P 接近长轴端点时，切线趋于水平，C/D 坐标可能超出画布，需做裁剪或提示
  - 数值显示保留 1 位小数
