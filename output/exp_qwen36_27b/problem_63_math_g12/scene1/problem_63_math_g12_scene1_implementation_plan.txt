[图示主题与整合说明]
- 本图示主题：双曲线与圆的综合几何关系——利用中位线定理求渐近线方程
- 整合的步骤/概念：
  1. 展示题目基础几何结构（双曲线、圆、切线、焦点、交点）。
  2. 利用切线性质构建直角三角形，推导 |MF| = a。
  3. 利用中点条件得出 |PF| = 2a。
  4. 引入左焦点构造中位线，得出 |PF'| = 2b。
  5. 应用双曲线定义建立方程，解得 b = 2a。
  6. 绘制渐近线并展示最终方程 y = ±2x。
- 教学价值：教师可通过分步按钮控制讲解节奏，逐步揭示几何关系与代数推导的对应，帮助学生理解双曲线定义、中位线定理及渐近线方程的求解过程。

[分步序列]
- 初始状态（步骤 0）：
  - 显示：坐标轴、双曲线两支、圆、直线 l、点 O/F/M/P。
  - 标签：x, y, O, F, M, P, l。
  - 公式面板：空或显示题目条件 "已知：M 为 PF 中点，l 切圆于 M"。

- 步骤 1（切线性质）：
  - 视觉变化：线段 OM 高亮为蓝色。M 处出现蓝色直角符号。
  - 新增标签：|OM| = b（蓝色，位于 M 左侧），|OF| = c（黑色，位于 F 下方）。
  - 公式面板：显示 "∵ l 切圆于 M ∴ OM ⊥ l"。

- 步骤 2（计算 MF）：
  - 视觉变化：Rt△OMF 区域填充蓝色半透明（20%）。线段 MF 高亮蓝色。
  - 新增标签：|MF| = a（蓝色，位于 MF 中点下方）。
  - 公式面板：显示 "|MF| = √(|OF|² - |OM|²) = √(c² - b²) = a"。

- 步骤 3（中点条件）：
  - 视觉变化：线段 PF 高亮红色。PM 和 MF 中点处出现红色等长标记（短划线）。
  - 新增标签：|PF| = 2a（红色，位于 PF 中点右侧）。
  - 公式面板：显示 "∵ M 为 PF 中点 ∴ |PF| = 2|MF| = 2a"。

- 步骤 4（引入左焦点与中位线）：
  - 视觉变化：出现左焦点 F'（绿色）。连接 PF'（绿色实线）。线段 OM 再次高亮绿色（或保持蓝色但添加绿色虚线辅助线 F'F）。
  - 新增标签：|PF'| = 2b（绿色，位于 PF' 中点左侧）。标注 "OM 为中位线"。
  - 公式面板：显示 "O 为 FF' 中点，M 为 PF 中点 ⇒ OM ∥ PF' 且 |PF'| = 2|OM| = 2b"。

- 步骤 5（双曲线定义）：
  - 视觉变化：高亮 |PF'|（绿色）和 |PF|（红色）。
  - 公式面板：显示 "双曲线定义：|PF'| - |PF| = 2a ⇒ 2b - 2a = 2a ⇒ b = 2a"。

- 步骤 6（渐近线结论）：
  - 视觉变化：绘制两条灰色虚线渐近线（过原点，斜率 ±2）。
  - 新增标签：渐近线方程 "y = ±2x"（灰色，位于渐近线末端）。
  - 公式面板：显示最终答案框 "∴ 渐近线方程为 y = ±2x"（加粗，绿色边框）。

[交互方案]

- 控件说明：
  - 「◀ 上一步」按钮：位于控件栏左侧，点击返回上一步。步骤 0 时禁用。

  3. 每步可暂停讲解，配合公式面板内容。
  4. 可随时点击「上一步」回顾。
  5. 最终步骤展示结论，教师可强调渐近线方程。

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript。原因：几何图形固定，无需复杂动画库；SVG 便于样式控制和缩放；原生 JS 足够处理简单的步骤状态切换。
- 画布尺寸：800 × 500 px。
- 布局草图：
  ```
  +--------------------------------------------------+
  |  [公式面板 300x100]                              |
  |  (50,50)--------------------------------(350,150)|
  |                                                  |
  |          y                                        |
  |          |                                       |
  |          |      P                               |
  |          |     / \                              |
  |          |    /   \                             |
  |          |   / M   \                            |
  |          |  /|     \                           |
  |          | / |      \                          |
  |  --------O---F'-----F-------- x                |
  |          | \      /                            |
  |          |  \    /                             |
  |          |   \  /                              |
  |          |    \/                               |
  |                                                  |
  |                                                  |
  |                    [◀ 上一步] [步骤 0/6] [下一步 ▶]|
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. **状态机**：使用变量 `currentStep` (0-6) 管理状态。每个步骤对应一个函数 `renderStep(step)`，根据 step 值更新 SVG 元素的可见性、颜色、填充等属性。
  2. **SVG 结构**：
     - `<g id="scene1-axes">`：坐标轴。
     - `<g id="scene1-hyperbola">`：双曲线路径。
     - `<g id="scene1-circle">`：圆。
     - `<g id="scene1-line-l">`：直线 l。
     - `<g id="scene1-points">`：点 O, F, F', M, P。
     - `<g id="scene1-labels">`：所有文本标签。
     - `<g id="scene1-highlights">`：高亮元素（OM, PF, PF', 直角符号, 等长标记, 填充区域）。
     - `<g id="scene1-asymptotes">`：渐近线（步骤 6 显示）。
     - `<g id="scene1-formula-panel">`：公式面板及文本。
     - `<g id="scene1-controls">`：按钮组。
  3. **坐标计算**：所有坐标基于原点 (400, 250) 和比例 a=50, b=100, c=112 预计算。
  4. **动画**：使用 CSS `transition` 实现颜色和高亮变化的平滑过渡（0.3s ease）。
  5. **事件绑定**：按钮点击事件更新 `currentStep` 并调用 `renderStep`。
  6. **ID 命名规范**：所有元素 ID 以 `scene1-` 开头，如 `scene1-btn-next`, `scene1-point-f`, `scene1-label-om`。
  7. **IIFE 隔离**：所有 JS 代码包裹在 `(function() { ... })();` 中，避免全局污染。
  8. **公式渲染**：使用 SVG `<text>` 和 `<tspan>` 实现上标/下标，无需引入 MathJax 以保持轻量。
