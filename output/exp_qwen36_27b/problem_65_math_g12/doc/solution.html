problem_65_math_g12

场景导航：Scene 1

题目原文：

如图，已知Rt△ABC的两条直角边AC，BC的长分别为6cm，8cm，以AC为直径的圆与AB交于点D，则BD=__cm．

题目分析：

本题是一道综合了直角三角形、圆的性质的几何题。核心考点包括：

  • 勾股定理求斜边
  • 直径所对的圆周角是直角
  • 射影定理（或相似三角形）求线段长度

整体讲解思路：

  1. 首先引导学生观察图形，识别已知条件：Rt△ABC中，AC=6cm，BC=8cm，AC为圆的直径
  2. 关键突破点：连接CD，利用"直径所对的圆周角是直角"得出CD⊥AB
  3. 利用射影定理 BC² = BD × AB 求解，或用相似三角形 △BCD ∽ △BAC
  4. 计算：AB = √(6²+8²) = 10cm，BD = 64/10 = 6.4cm

图示规划说明：

本题只需一个交互式图示，整合题目原图展示、辅助线添加、关键关系标注和最终求解全过程。通过分步按钮导航，教师可逐步引导学生从观察图形到得出结论。

步骤 0/4

本图示教学说明：

步骤0——展示原图：
教师引导学生观察图形，提问："图中有哪些已知条件？"让学生回答AC=6cm、BC=8cm、∠C=90°、AC是圆的直径。

步骤1——连接辅助线CD：
教师提问："AC是圆的直径，点D在圆上，那么∠ADC等于多少度？"引导学生回忆"直径所对的圆周角是直角"这一重要定理，得出CD⊥AB。这是本题的关键突破口。

步骤2——计算斜边AB：
在Rt△ABC中，由勾股定理：
AB = √(AC² + BC²) = √(6² + 8²) = √(36 + 64) = √100 = 10cm

步骤3——应用射影定理：
因为CD⊥AB，在Rt△ABC中，CD是斜边上的高，根据射影定理：
BC² = BD × AB

或者用相似三角形方法：

  • ∠B为公共角
  • ∠BDC = ∠BCA = 90°
  • 所以△BCD ∽ △BAC
  • 对应边成比例：BD/BC = BC/AB
  • 即 BD = BC²/AB

步骤4——代入求解：
BD = 64/10 = 6.4cm

课堂讲解建议：

  • 强调"直径所对圆周角是直角"是解题的关键桥梁，将圆的性质与直角三角形联系起来
  • 射影定理可由相似三角形推导，如果学生不熟悉射影定理，直接用相似三角形讲解
  • 本题也可用面积法验证：S△ABC = ½×6×8 = 24，同时S△ABC = ½×AB×CD，可求出CD=4.8cm，再用勾股定理求BD
