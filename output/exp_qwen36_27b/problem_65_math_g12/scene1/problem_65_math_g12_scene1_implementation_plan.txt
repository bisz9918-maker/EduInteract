[图示主题与整合说明]
- 本图示主题：Rt△ABC中以AC为直径的圆与斜边AB交点D的求解过程
- 整合的步骤/概念：题目原图展示 → 连接辅助线CD并标注直角 → 计算斜边AB → 利用射影定理/相似三角形求BD → 展示最终答案
- 教学价值：教师可通过分步按钮控制讲解节奏，逐步揭示辅助线作法、定理应用和计算过程，帮助学生理解射影定理的推导逻辑。每一步都有明确的视觉变化和公式提示，便于课堂互动。

[技术实现]
- JS 库选择：原生SVG（无需额外库）。原因：本题为纯几何图形，SVG原生支持圆、线段、多边形、文本等元素，且CSS transition可轻松实现淡入淡出动画，无需引入D3.js等重型库。

- 关键实现要点：
  1. 状态机设计：全局变量currentStep（0~4），updateStep()函数根据currentStep更新所有元素的显示状态
  2. 步骤元素分组：每个步骤的视觉元素放在独立的<g>组中（id="scene1-step1"~"scene1-step4"），通过display和opacity控制显隐
  3. 公式框动态更新：公式框始终存在但初始隐藏，根据currentStep更新<text>内容
  4. 按钮状态管理：步骤0时上一步按钮禁用（灰色），步骤4时下一步按钮禁用（灰色）
  5. 淡入动画：CSS transition: opacity 0.3s ease，切换步骤时新增元素淡入
  6. 绘制顺序：背景 → 相似三角形填充 → 圆 → 三角形边 → 辅助线 → 直角符号 → 点 → 标签 → 公式框 → 控件栏
  7. 坐标计算：D点通过射影定理BD=BC²/AB=6.4cm计算得出，画布坐标D(385,226)
- ID 命名规范：所有交互元素ID以scene1-为前缀（如scene1-btn-prev、scene1-step-indicator、scene1-step1、scene1-formula-box等）
- IIFE 隔离：所有JS代码包裹在(function() { ... })()中，避免全局污染
