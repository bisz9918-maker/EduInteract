[分步序列]
本场景为连续拖拽交互，无分步导航。状态由滑块控制：

- 初始状态（θ=0°）：
  - 显示正三角形ABC（黑色实线）
  - 显示中线AF、中位线DE（灰色虚线）
  - 显示交点G
  - △A'ED与△AED完全重合（A'=A），蓝色高亮
  - 射影点H与A重合
  - A'轨迹圆弧完整显示（绿色虚线）
  - 角度显示：θ = 0°

- 拖动滑块（θ从0°到360°连续变化）：
  - △A'ED绕DE轴实时旋转
  - A'沿圆弧轨迹运动
  - 射影点H在线段AF上移动
  - 垂线A'H实时更新
  - 角度显示实时更新

- 关键角度状态：
  - θ=0°：A'=A，H=A（初始重合）
  - θ=90°：A'在G正上方（z=103.9），H=G
  - θ=180°：A'=F，H=F（A'到达BC中点）
  - θ=270°：A'在G正下方（z=-103.9），H=G
  - θ=360°：回到初始状态

[标签冲突检查]
3D场景中标签由CSS2DRenderer自动投影，以下为3D空间中的标签位置检查：

- 标签"A"：(0, 222, 0)
- 标签"B"：(-135, -12, 0)
- 标签"C"：(135, -12, 0)
- 标签"D"：(-75, 118, 0)
- 标签"E"：(75, 118, 0)
- 标签"F"：(0, -18, 0)
- 标签"G"：(18, 118, 0)
- 标签"A'"：动态，A'点上方偏移
- 标签"H"：动态，H点下方偏移
- 标签"θ"：(25, 118, 15)
- 标签"a/2"：(0, 103.9, 12)
- 标签"a√3/4"(AG)：(12, 155.8, 0)
- 标签"a√3/4"(GF)：(12, 51.9, 0)

静态标签间距检查：
- "A"(0,222)与"a√3/4"(12,155.8)：间距≈66px → 无冲突
- "D"(-75,118)与"G"(18,118)：间距≈93px → 无冲突
- "E"(75,118)与"G"(18,118)：间距≈57px → 无冲突
- "D"(-75,118)与"θ"(25,118)：间距≈100px → 无冲突
- "a/2"(0,103.9)与"G"(18,118)：间距≈20px → 临界，但z坐标不同（12 vs 0），投影后不重叠
- "a√3/4"(AG)(12,155.8)与"A"(0,222)：间距≈66px → 无冲突
- "a√3/4"(GF)(12,51.9)与"F"(0,-18)：间距≈70px → 无冲突
- "B"(-135,-12)与"F"(0,-18)：间距≈135px → 无冲突
- "C"(135,-12)与"F"(0,-18)：间距≈135px → 无冲突

动态标签检查：
- "A'"与"H"：A'在z方向偏移，H在z=0平面，投影后上下分布，不重叠
- "A'"与"A"：θ≠0时A'远离A，不重叠
- "H"与"G"：H在AF上移动，G标签在G点右上方，H标签在H点下方，方向不同不重叠

结论：所有标签间距≥20px，无冲突。

- 控件说明：
  1. 滑块（range input）：位于SVG底部中央，范围0°~360°，初始值0°
     - ID: scene1-slider
     - 位置：x=200, y=455（SVG内绝对定位）
     - 宽度：400px
  2. 角度显示文本：位于滑块下方
     - ID: scene1-angle-display
     - 位置：x=350, y=485（SVG内绝对定位）
     - 格式："旋转角 θ = XX°"
- 教师操作流程：
  1. 图示加载后显示初始状态（θ=0°，△A'ED与△AED重合）
  2. 教师拖动滑块，观察△A'ED绕DE轴旋转
  3. 观察A'沿圆弧轨迹运动，射影点H始终在线段AF上
  4. 在关键角度（0°、90°、180°、270°、360°）暂停讲解
  5. 通过射影点H始终在AF上来验证命题(1)的正确性

[技术实现]
- JS 库选择：Three.js（CDN引入）
  - 原因：需要3D透视视图展示旋转过程，Three.js是成熟的3D WebGL库
  - 额外使用：CSS2DRenderer（Three.js内置模块）用于标签渲染
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  +--------------------------------------------------+
  |                    3D 场景区域                    |
  |                                                  |
  |              A (顶点)                            |
  |             /  \                                 |
  |            /    \                                |
  |      D---G------E  (中位线DE，旋转轴)             |
  |          /  \                                   |
  |         /    \                                  |
  |    B---F------C  (底边BC)                        |
  |                                                  |
  |  [A'轨迹圆弧 - 绿色虚线]                          |
  |  [△A'ED - 蓝色高亮]                              |
  |  [H - 红色射影点]                                |
  |  [A'H - 红色虚线]                                |
  |                                                  |
  |  ┌──────────────────────────────────────┐        |
  |  │  旋转角 θ = 0°  [========|========]  │        |
  |  │         0°        180°      360°     │        |
  |  └──────────────────────────────────────┘        |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. **场景初始化**：
     - 创建Scene、PerspectiveCamera（FOV=45°，位置(200,150,300)，看向(0,100,0)）
     - 创建WebGLRenderer（800×500，antialias=true，alpha=true）
     - 创建CSS2DRenderer叠加层（用于标签）
  
  2. **几何体创建**：
     - 平面ABC：PlaneGeometry(300, 280)，半透明灰色材质
     - 三角形ABC边：LineSegments，黑色材质
     - 中线AF：Line，黑色材质
     - 中位线DE：Line，灰色虚线材质（使用LineDashedMaterial）
     - 交点G：SphereGeometry(4)，黑色材质
     - △AED：BufferGeometry三角形，半透明填充
     - △A'ED：BufferGeometry三角形，蓝色半透明填充（动态更新顶点）
     - A'轨迹：BufferGeometry圆弧（72个采样点），绿色虚线
     - 射影点H：SphereGeometry(5)，红色材质（动态更新位置）
     - 垂线A'H：Line，红色虚线（动态更新顶点）
  
  3. **旋转动画**：
     - 滑块事件监听：input事件触发更新
     - A'坐标计算：A' = (0, 103.9 + 103.9·cos(θ), 103.9·sin(θ))
     - H坐标计算：H = (0, 103.9 + 103.9·cos(θ), 0)
     - 更新△A'ED的顶点、A'标签位置、H位置、A'H线段
     - 使用requestAnimationFrame确保平滑渲染
  
  4. **标签渲染**：
     - 使用CSS2DRenderer创建HTML标签元素
     - 静态标签：A, B, C, D, E, F, G, a/2, a√3/4
     - 动态标签：A', H（随旋转更新3D位置）
     - 标签样式：14px字体，黑色，白色背景圆角
  
  5. **滑块控件**：
     - HTML range input，绝对定位在SVG底部
     - 范围：0~360，步长：1
     - 实时更新角度显示文本
     - 滑块样式：自定义CSS，蓝色进度条
  
  6. **相机设置**：
     - PerspectiveCamera(45°, 800/500, 1, 1000)
     - 位置：(200, 150, 300)
     - 看向：(0, 100, 0)
     - up向量：(0, 1, 0)
  
  7. **ID命名规范**：
     - 所有交互元素ID以 scene1- 为前缀
     - scene1-slider：滑块控件
     - scene1-angle-display：角度显示
     - scene1-container：3D容器
     - scene1-label-A, scene1-label-B, ...：各标签元素
  
  8. **IIFE隔离**：
     - 所有JS代码包裹在 (function() { ... })() 中
     - 使用getElementById而非querySelectorAll
     - 变量作用域限制在IIFE内部

- 依赖CDN：
  - Three.js r128+: https://cdn.jsdelivr.net/npm/three@0.128.0/build/three.min.js
  - CSS2DRenderer: https://cdn.jsdelivr.net/npm/three@0.128.0/examples/js/renderers/CSS2DRenderer.js
