[图示主题与整合说明]
- 本图示主题：命题(2)(3)(4)的几何关系验证
- 整合的步骤/概念：
  1. 三棱锥A'-FED体积分析（命题2）：展示体积随二面角θ变化的规律，验证最大值存在性。
  2. 平面A'GF⊥平面BCED验证（命题3）：通过线面垂直关系推导面面垂直。
  3. 异面直线A'E与BD夹角分析（命题4）：展示两直线夹角随θ变化，验证垂直可能性。
- 教学价值：教师可通过分步导航引导学生逐一验证三个命题，结合滑块交互直观感受几何量的动态变化，突破立体几何空间想象难点。

[分步序列]
- 初始状态（步骤0 - 命题2）：
  - 显示梯形BCED和三棱锥A'-FED。
  - A'位于θ=60°位置（y=215）。
  - 右侧显示体积-角度曲线图，曲线为 $V(\theta) = k|\sin\theta|$，标记最大值点（θ=90°）。
  - 滑块θ可用，拖动时A'位置更新，曲线图上显示当前点。
  - 标签：$V_{max} = \frac{a^3}{64}$（θ=90°）。
- 步骤1（命题3）：
  - 点击「下一步」→ 切换至步骤1。
  - 高亮平面A'GF（蓝色半透明）和平面BCED（灰色半透明）。
  - 显示直角符号：DE⊥A'G，DE⊥GF。
  - 右侧显示证明文本：
    - "DE⊥A'G，DE⊥GF"
    - "∴ DE⊥平面A'GF"
    - "∴ 平面A'GF⊥平面BCED"
  - 滑块θ固定或隐藏。
- 步骤2（命题4）：
  - 点击「下一步」→ 切换至步骤2。
  - 高亮直线A'E（蓝色）和BD（红色）。
  - 显示公垂线（绿色虚线）。
  - 右侧显示夹角信息：
    - "$\vec{A'E} \cdot \vec{BD} = \frac{a^2}{16}(1-3\cos\theta)$"
    - "当 $\cos\theta=1/3$ 时，A'E⊥BD"
  - 滑块θ可用，拖动时显示当前夹角值，当θ≈70.5°时高亮垂直状态。
- 回退：点击「上一步」可返回前一步，状态恢复。

[标签冲突检查]
- 标签"A'"：(250, 195) → 上方
- 标签"B"：(125, 310) → 左侧
- 标签"C"：(375, 310) → 右侧
- 标签"D"：(190, 230) → 左上
- 标签"E"：(310, 230) → 右上
- 标签"F"：(250, 335) → 下方
- 标签"G"：(270, 270) → 右下
- 间距检查：
  - "A'"与"D"：$\sqrt{(250-190)^2 + (195-230)^2} = \sqrt{3600+1225} = 69.8$px → 无冲突
  - "A'"与"E"：$\sqrt{(250-310)^2 + (195-230)^2} = 69.8$px → 无冲突
  - "D"与"G"：$\sqrt{(190-270)^2 + (230-270)^2} = \sqrt{6400+1600} = 89.4$px → 无冲突
  - "E"与"G"：$\sqrt{(310-270)^2 + (230-270)^2} = 56.6$px → 无冲突
  - "F"与"G"：$\sqrt{(250-270)^2 + (335-270)^2} = \sqrt{400+4225} = 68.4$px → 无冲突
  - 所有标签间距 > 20px，无重叠。

[交互方案]
- 交互类型：分步按钮导航 + 滑块
- 控件说明：
  - 「◀ 上一步」按钮：(250,450)，返回前一步。
  - 「下一步 ▶」按钮：(450,450)，进入下一步。
  - 滑块θ：(560,360)-(740,380)，范围0°~180°，默认60°。步骤0和2可用，步骤1禁用。
- 教师操作流程：
  1. 初始显示步骤0，拖动滑块展示体积变化，指出最大值位置。
  2. 点击「下一步」进入步骤1，讲解面面垂直证明。
  3. 点击「下一步」进入步骤2，拖动滑块展示异面直线夹角变化，指出垂直条件。
  4. 可随时点击「上一步」回顾。

[技术实现]
- JS 库选择：原生 SVG + Vanilla JS（无需外部库，轻量高效）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  +--------------------------------------------------+
  |  主视图区 (几何体)        |  辅助信息区 (图表/文本) |
  |  (50,50)-(500,430)       |  (520,50)-(780,430)   |
  |                          |                        |
  |      A'                  |   [体积曲线]           |
  |     /  \                 |   或                   |
  |    /    \                |   [证明文本]           |
  |   D------E               |   或                   |
  |  /      \                |   [夹角信息]           |
  | B--------C               |                        |
  |    F    G                |   [滑块θ]              |
  +--------------------------------------------------+
  |              [◀ 上一步] [下一步 ▶]                |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  - 状态机：`currentStep` (0/1/2)，切换时更新SVG元素可见性和样式。
  - 坐标计算：A'位置 $y = 250 - 70\cos\theta$，θ由滑块控制。
  - 动画：步骤切换时高亮元素淡入（opacity 0→1，300ms）。
  - 事件绑定：按钮点击切换步骤，滑块拖动更新A'位置和图表。
  - ID命名：所有元素ID以 `scene2-` 开头（如 `scene2-point-Ap`, `scene2-slider-theta`）。
  - IIFE隔离：`(function() { ... })();` 包裹所有JS代码。
  - 体积曲线：使用SVG `<path>` 绘制正弦曲线，动态更新当前点位置。
  - 直角符号：步骤1显示，使用SVG `<path>` 绘制小正方形。
