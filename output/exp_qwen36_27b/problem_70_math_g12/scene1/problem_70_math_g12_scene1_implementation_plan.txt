[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位置(280,455)，尺寸120×30px，点击回退到上一步骤，步骤0时禁用
  - 「下一步 ▶」按钮：位置(480,455)，尺寸120×30px，点击前进到下一步骤，步骤6时禁用
  - 步骤指示器：位置(400,455)，显示"步骤 X/6"
- 教师操作流程：
  1. 图示加载后显示步骤0（四棱锥基本结构+已知条件）
  2. 教师点击「下一步▶」逐步展示推导过程
  3. 每步底部提示文字同步更新，辅助讲解
  4. 可随时点击「◀ 上一步」回退复习
  5. 到达步骤6展示最终结论

[技术实现]
- JS 库选择：原生SVG（简单几何图形绘制，支持半透明填充、虚线、动画，无需额外库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  ┌──────────────────────────────────────────────────────┐
  │                                                      │
  │              P(225,80)                               │
  │              *                                       │
  │             /|\                                      │
  │            / | \                                     │
  │           /  |  \                                    │
  │          /   |   \                                   │
  │         D(325,280)  M(387,172)                       │
  │        *--------*--------* C(575,280)                │
  │         \      / \      /                            │
  │          \    /   \    /                             │
  │           \  / O   \  /                              │
  │            \/       \/                               │
  │     A(225,380)    B(475,380)                         │
  │                                                      │
  │         [条件标签区域]                                │
  │                                                      │
  │              [步骤提示文字]                           │
  │                                                      │
  │     [◀上一步]  [步骤X/6]  [下一步▶]                  │
  └──────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. **状态机设计**：用变量`currentStep`（0-6）管理当前步骤，每个步骤对应一个渲染函数`renderStep(n)`
  2. **SVG元素管理**：所有SVG元素用`document.createElementNS`创建，按步骤分组（group），通过显示/隐藏控制可见性
  3. **M点位置计算**：PC参数方程x=225+350t, y=80+200t，步骤4时t=0.3，步骤5时t=6/13≈0.462
  4. **动画实现**：步骤5中M点移动用CSS transition或requestAnimationFrame实现平滑过渡（duration=500ms）
  5. **直角符号绘制**：用SVG `<polyline>`绘制12×12的小正方形折线，根据线段方向旋转
  6. **平面填充**：用SVG `<polygon>`绘制三角形，设置fill和opacity
  7. **按钮状态**：步骤0时"上一步"禁用（opacity=0.5），步骤6时"下一步"禁用
- ID 命名规范：所有交互元素ID以`scene1-`为前缀，如`scene1-btn-prev`、`scene1-btn-next`、`scene1-step-indicator`、`scene1-pyramid`、`scene1-point-M`、`scene1-plane-PAC`等
- IIFE 隔离：所有JS代码包裹在`(function() { 'use strict'; ... })();`中，避免全局污染
- 事件绑定：按钮点击事件用`addEventListener('click', handler)`绑定，handler中更新`currentStep`并调用`renderStep(currentStep)`
