[分步序列]

步骤0（初始状态）：展示三视图
- 左侧显示三个视图：主视图（等腰三角形，底6高4）、侧视图（直角三角形，底2高4）、俯视图（6×2矩形+内部三角形）
- 所有视图用 #000000 实线绘制，线宽2px
- 标注各尺寸：主视图底边"3"+"3"、高"4"；侧视图底边"2"、高"4"；俯视图长"6"、宽"2"
- 视图名称标签："主视图"、"侧视图"、"俯视图"
- 右侧立体图区域空白（或显示淡灰色提示文字"点击「下一步」开始还原"）
- 三视图区域背景填充 #f5f5f5

步骤1：高亮俯视图，提取底面矩形
- 俯视图边框变为蓝色 #1565c0，线宽3px，表示激活
- 右侧立体图区域出现底面矩形 ABCD（透视画法）
- 底面边用绿色 #2e7d32 绘制，线宽2px
- 标注顶点 A、B、C、D（黑色文字）
- 标注底面尺寸：AB=6（下方）、AD=2（左侧）
- 主视图和侧视图保持原样

步骤2：结合主视图，确定顶点P的x方向位置
- 主视图边框变为蓝色 #1565c0，线宽3px，表示激活
- 右侧立体图区域出现投影点 O（AB边中点），用黑色小圆点表示
- 画出辅助虚线 PO（#888888，虚线，线宽1px），从O垂直向上延伸
- 标注 O 点（黑色文字，O(460,345)下方）
- 标注 AO=3（AO下方）
- 用虚线表示P点在x方向位于底边中点上方

步骤3：结合侧视图，确定顶点P的y方向位置和高
- 侧视图边框变为蓝色 #1565c0，线宽3px，表示激活
- 右侧立体图区域出现顶点 P（红色 #c62828 圆点，(460,120)）
- 标注 P 点（红色文字，P(450,115)左侧）
- 标注高 PO=4（红色文字，PO左侧(445,220)）
- 虚线 PO 变为红色 #c62828，线宽2px

步骤4：完整四棱锥 P-ABCD
- 画出所有棱 PA、PB、PC、PD（黑色实线，线宽2px）
- 完整四棱锥用蓝色 #1565c0 高亮轮廓（线宽3px）
- 所有顶点 P、A、B、C、D、O 全部标注
- 所有关键长度标注：AB=6、AD=2、PO=4、AO=3
- 三视图区域所有视图恢复为黑色 #000000
- 右侧立体图区域显示完整四棱锥，为后续表面积计算做准备

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位置(200,455)，尺寸100×36px，点击返回上一步骤，步骤0时禁用
  - 「下一步 ▶」按钮：位置(500,455)，尺寸100×36px，点击进入下一步骤，步骤4时禁用
  - 步骤指示器：位置(380,465)，显示"步骤 X / 4"，X为当前步骤编号（0-4）
- 教师操作流程：
  1. 初始显示三视图，教师讲解三视图的基本概念
  2. 点击「下一步」，高亮俯视图，讲解如何从俯视图提取底面矩形信息
  3. 点击「下一步」，高亮主视图，讲解如何确定顶点P的x方向位置
  4. 点击「下一步」，高亮侧视图，讲解如何确定顶点P的y方向位置和高
  5. 点击「下一步」，展示完整四棱锥，为后续表面积计算做铺垫
  6. 可随时点击「上一步」回退复习任意步骤

[技术实现]
- JS 库选择：原生 SVG（简单几何图形首选，无需额外库，性能好，易于动画控制）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |  主视图    |    侧视图    |                       |
  |  (等腰△)  |   (直角△)    |                       |
  |           |              |                       |
  |-----------|--------------|      立体图区域       |
  |  俯视图   |              |                       |
  |  (矩形+△) |              |    P                  |
  |           |              |    |\                 |
  |           |              |    | \                |
  |           |              |    |  \               |
  |           |              |    O---A              |
  |           |              |     /   \             |
  |           |              |    D-----B            |
  |           |              |                       |
  |           |              |                       |
  |           |              |                       |
  |           |              |                       |
  +-----------+--------------+-----------------------+
  |           |              |                       |
  |  ◀上一步  |  步骤 0/4    |     下一步▶           |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：5个状态（步骤0-4），每个状态定义哪些元素可见、哪些元素高亮、颜色变化
  2. 坐标计算：所有元素坐标预先计算好，步骤切换时通过 CSS class 切换或 SVG 属性修改实现
  3. 动画曲线：步骤切换时使用 0.3s ease-in-out 过渡动画，元素出现使用 fade-in 效果
  4. 事件绑定：按钮点击事件绑定到状态切换函数，步骤指示器实时更新
  5. 元素分组：三视图区域和立体图区域分别用 <g> 标签分组，便于整体控制
  6. 高亮效果：通过修改 stroke 颜色和 stroke-width 实现，激活视图边框变蓝加粗
  7. 虚线效果：使用 stroke-dasharray="5,5" 实现辅助虚线
- ID 命名规范：所有交互元素 ID 以 `scene1-` 为前缀
  - 按钮：`scene1-prev-btn`, `scene1-next-btn`
  - 步骤指示器：`scene1-step-indicator`
  - 三视图组：`scene1-front-view`, `scene1-side-view`, `scene1-top-view`
  - 立体图元素：`scene1-base-abcd`, `scene1-vertex-p`, `scene1-point-o`, `scene1-edge-pa`, `scene1-edge-pb`, `scene1-edge-pc`, `scene1-edge-pd`, `scene1-height-po`
  - 标签：`scene1-label-a`, `scene1-label-b`, `scene1-label-c`, `scene1-label-d`, `scene1-label-p`, `scene1-label-o`
- IIFE 隔离：所有 JS 代码包裹在 (function() { 'use strict'; ... })() 中，避免全局污染
