[图示主题与整合说明]
- 本图示主题：四棱锥表面积的分步计算
- 整合的步骤/概念：从三视图还原立体几何体 → 底面面积计算 → 前侧面PAB面积 → 后侧面PCD面积 → 左右侧面PAD/PBC面积 → 总表面积汇总
- 教学价值：教师可通过分步导航，引导学生逐一分析每个面的几何特征与面积算法，避免一次性展示过多信息造成认知负荷。右侧公式区与左侧立体图联动高亮，强化“形数结合”的直观理解。

[分步序列]
- 初始状态（步骤0）：
  - 显示完整四棱锥立体图（线框+极浅灰填充）
  - 显示所有点名(P,A,B,C,D,O,M)和已知长度(AB=6, AD=2, PO=4, AO=3, OB=3)
  - 右侧公式区空白
  - 控件显示「步骤 0/5」
- 步骤1：点击「下一步」→
  - 底面ABCD填充绿色半透明(#2e7d32, 20%)
  - 右侧显示：「底面 ABCD：S_底 = 6 × 2 = 12」（绿色文字）
  - 控件更新「步骤 1/5」
- 步骤2：点击「下一步」→
  - 侧面△PAB填充蓝色半透明(#1565c0, 20%)
  - 右侧显示：「侧面 △PAB：等腰△，底AB=6，高PO=4」
  - 新增推导：「PA = PB = √(3²+4²) = 5」（红色数值）
  - 新增面积：「S_△PAB = ½ × 6 × 4 = 12」（蓝色文字）
  - 控件更新「步骤 2/5」
- 步骤3：点击「下一步」→
  - 侧面△PCD填充蓝色半透明
  - 右侧显示：「侧面 △PCD：取CD中点M，PM⊥CD」
  - 新增推导：「PM = √(PO²+OM²) = √(4²+2²) = 2√5」（红色数值）
  - 新增面积：「S_△PCD = ½ × 6 × 2√5 = 6√5」（蓝色文字）
  - 控件更新「步骤 3/5」
- 步骤4：点击「下一步」→
  - 侧面△PAD和△PBC填充蓝色半透明
  - 右侧显示：「侧面 △PAD：PA=5, AD=2, PD=√29」
  - 新增推导：「PA²+AD²=25+4=29=PD² ⇒ ∠PAD=90°」（红色标记）
  - 新增面积：「S_△PAD = S_△PBC = ½ × 5 × 2 = 5」（蓝色文字）
  - 控件更新「步骤 4/5」
- 步骤5：点击「下一步」→
  - 所有面恢复线框，整体轻微高亮
  - 右侧显示：「总表面积 S = 12 + 12 + 6√5 + 5 + 5」
  - 底部中央出现红色大字：「S_总 = 34 + 6√5」
  - 控件更新「步骤 5/5」，「下一步」按钮禁用

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「◀ 上一步」：返回上一状态，恢复对应面的填充与公式显示
  - 「下一步 ▶」：进入下一状态，触发新的高亮与公式渲染
  - 步骤指示器：显示当前步骤 "X/5"
- 教师操作流程：
  1. 初始展示立体图与已知条件，提问学生观察几何特征
  2. 逐次点击「下一步」，引导学生计算每个面的面积
  3. 在关键步骤（如勾股定理推导、直角验证）暂停讲解
  4. 步骤5展示最终答案，可点击「上一步」回顾任意中间过程

[技术实现]
- JS 库选择：原生 SVG + Vanilla JS（无需外部依赖，轻量高效，适合几何分步动画）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +------------------------------------------------------------+
  |  [四棱锥立体图 P-ABCD]          |  [公式推导区]             |
  |  P(280,160)                    |  580,100: 底面面积         |
  |   /|\                          |  580,160: △PAB面积         |
  |  / | \                         |  580,220: △PCD面积         |
  | D-----C                        |  580,280: △PAD/PBC面积     |
  | /  |  \                        |  580,340: 汇总计算         |
  |A-----O-----B                   |                            |
  | 180,320   380,320              |                            |
  +------------------------------------------------------------+
  |                     [最终答案 34+6√5]                       |
  |  [◀ 上一步]   步骤 X/5   [下一步 ▶]                        |
  +------------------------------------------------------------+
  ```
- 关键实现要点：
  - 状态机：`let currentStep = 0; const maxStep = 5;`
  - 渲染函数 `renderStep(step)`：根据 step 值切换 SVG 元素的 `fill`, `opacity`, `display` 属性
  - 面元素使用 `<polygon>`，通过 `id="scene2-face-abcd"` 等命名，JS 直接 `getElementById` 控制
  - 公式文本使用 `<text>` + `<tspan>` 实现多色排版，初始 `opacity="0"`，激活时过渡到 `opacity="1"`
  - 动画：CSS `transition: opacity 0.3s ease, fill 0.3s ease` 实现平滑高亮切换
  - 事件绑定：按钮点击触发 `currentStep++/--` 并调用 `renderStep()`，边界检查防止越界
- ID 命名规范：所有交互元素及关键图形元素以 `scene2-` 为前缀（如 `scene2-pyramid`, `scene2-face-pab`, `scene2-btn-next`, `scene2-formula-row1`）
- IIFE 隔离：全部 JS 逻辑包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染
