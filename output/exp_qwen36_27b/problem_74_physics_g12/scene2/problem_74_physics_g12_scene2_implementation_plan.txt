[图示主题与整合说明]
- 本图示主题：匀速运动时的受力平衡分析与速度计算
- 整合的步骤/概念：线圈与砝码的受力分析 → 平衡方程建立 → 安培力公式推导 → 速度公式推导 → 数值代入计算
- 教学价值：教师通过分步按钮引导学生逐步理解电磁感应中的受力平衡问题。每一步聚焦一个物理概念（装置概览→砝码受力→线圈受力→平衡方程→速度计算），帮助学生建立从受力分析到公式推导的完整逻辑链条。

[技术实现]

- JS 库选择：原生 SVG + 原生 JavaScript（无需外部库，几何图形和箭头用SVG原生元素即可实现）
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  +---------------------------------------------------+
  |  [左侧装置图 40%]  |  [右侧受力分析 60%]          |
  |  固定面 ────       |  砝码m₂受力  线圈m₁受力      |
  |  滑轮  滑轮        |  (蓝色箭头)  (绿+红箭头)     |
  |  磁场×××           |                              |
  |  线圈abcd          |  公式推导区                  |
  |  绳子  砝码m₂      |  (平衡方程/速度公式)         |
  |                    |                              |
  +---------------------------------------------------+
  |  [控件栏 y=440~490]                               |
  |  ◀上一步  ●○○○○  下一步▶                         |
  +---------------------------------------------------+
  ```
- 关键实现要点：
  1. **状态机设计**：用变量 `currentStep` (0~4) 管理当前步骤，每个步骤对应一组可见/隐藏的元素
  2. **元素显隐控制**：用CSS类 `.scene2-hidden { opacity: 0; }` 和 `.scene2-visible { opacity: 1; }` 配合 `transition: opacity 0.4s ease` 实现淡入淡出
  3. **SVG箭头**：使用 `<marker>` 定义箭头头部，`<line>` 绘制箭头线段
  4. **磁场×符号**：用 `<text>` 元素在磁场区域内3×3网格位置放置"×"字符
  5. **绳子路径**：用 `<path>` 元素，包含垂直线段、水平线段和上半圆弧（`A` 命令）
  6. **公式文本**：用 `<text>` 元素，`text-anchor="middle"` 居中对齐，关键结果用 `<tspan>` 设置颜色和字号
  7. **步骤指示器**：5个 `<circle>` 元素，当前步骤填充#1565c0，其余#cccccc，点击可跳转
  8. **按钮禁用状态**：步骤0时"上一步"按钮 `pointer-events="none"` 且灰色，步骤4时"下一步"按钮同理
- ID 命名规范：所有交互元素ID以 `scene2-` 为前缀
  - 按钮：`scene2-prev-btn`、`scene2-next-btn`
  - 步骤指示器：`scene2-step-0` ~ `scene2-step-4`
  - 受力图组：`scene2-weight-forces`、`scene2-coil-forces`
  - 公式区：`scene2-formula-area`
  - 装置图：`scene2-apparatus`
- IIFE 隔离：所有JS代码包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染
- SVG namespace：`http://www.w3.org/2000/svg`
- 箭头marker定义：在 `<defs>` 中定义蓝色、绿色、红色三种箭头marker，分别用于不同受力箭头
