[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  * "◀ 上一步" 按钮：位置(260,455)，宽100×高30，点击回退到上一步，步骤0时禁用

  2. 点击「下一步 ▶」进入步骤1，高亮位移标注，讲解位移分析
  3. 点击「下一步 ▶」进入步骤2，展示能量转化关系
  4. 点击「下一步 ▶」进入步骤3，列出能量守恒方程
  5. 点击「下一步 ▶」进入步骤4，展示计算结果
  6. 可随时点击「◀ 上一步」回退复习任意步骤
  7. 内容累积显示，后续步骤保留前面步骤的内容

[技术实现]
- JS 库选择：原生 SVG（本场景为简单几何图形+文本标注，无需复杂库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +------------------------------------------------------------------+
  |  [左侧 45%: 过程示意图]          |  [右侧 55%: 能量分析]          |
  |                                |                                  |
  |        ┌──────────┐            |                                  |
  |        │  B⊗ ×××  │ ←磁场区域  |  总位移 2l = 0.40m              |
  |        │  ××××××  │            |                                  |
  |   ┌────┤  ××××××  ├───────────┼──────────────────────────────────┤
  |   │    └──────────┘            |  第一阶段: 位移 l = 0.20m       |
  |   │  ┌────┐                    |  第二阶段: 位移 l = 0.20m       |
  |   │  │    │ ←位置3(实线)       |                                  |
  |   │  └────┘                    |  能量转化                       |
  |   │  ┌────┐                    |  重力势能减少 ──→ 热量 Q        |
  |   │  │    │ ←位置2(虚线)       |                                  |
  |   │  └────┘                    |  能量守恒方程                   |
  |   │  ┌────┐                    |  (m₂-m₁)g × 2l = Q             |
  |   │  │    │ ←位置1(虚线)       |                                  |
  |   │  └────┘                    |  计算结果                       |
  |   │                            |  Q = 0.16 J                     |
  |   l  l    2l                   |                                  |
  |                                |                                  |
  |                                |                                  |
  |                                |                                  |
  |  ──────────────────────────────────────────────────────────────── |
  |              ◀ 上一步    0/4    下一步 ▶                          |
  +------------------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：用变量 `currentStep` (0~4) 管理当前步骤，每个步骤对应一组可见元素
  2. 元素显隐控制：右侧文本元素初始 `opacity="0"`，进入对应步骤时渐变为 `opacity="1"`（transition: opacity 0.4s）
  3. 位移高亮：步骤1时，第一阶段箭头/标签 stroke-width 从2px变为3px，第二阶段同理
  4. 按钮状态：步骤0时"上一步"按钮 disabled（灰色），步骤4时"下一步"按钮 disabled
  5. 步骤指示器：显示 "currentStep/4"，当前数字用粗体
  6. 事件绑定：按钮 click 事件调用 `goToStep(step)` 函数，更新 `currentStep` 并刷新视图
  7. 动画：元素出现使用 CSS transition opacity 0.4s ease-in，高亮使用 stroke-width 过渡
- ID 命名规范：所有交互元素 ID 以 `scene3-` 为前缀
  * `scene3-btn-prev`：上一步按钮
  * `scene3-btn-next`：下一步按钮
  * `scene3-step-indicator`：步骤指示器
  * `scene3-coil-pos1`：位置1线圈
  * `scene3-coil-pos2`：位置2线圈
  * `scene3-coil-pos3`：位置3线圈
  * `scene3-magnetic-field`：磁场区域
  * `scene3-disp-l1`：第一阶段位移标注
  * `scene3-disp-l2`：第二阶段位移标注
  * `scene3-disp-2l`：总位移标注
  * `scene3-text-step0`~`scene3-text-step4`：各步骤右侧文本组
- IIFE 隔离：所有 JS 代码包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染
- SVG 结构：使用 `<svg viewBox="0 0 800 500">`，所有元素用 `<g>` 分组管理，便于批量显隐
