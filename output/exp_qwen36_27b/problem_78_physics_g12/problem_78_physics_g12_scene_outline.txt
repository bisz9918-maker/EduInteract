    **题目原文：**

    如图所示，电阻忽略不计的、两根平行的光滑金属导轨竖直放置，其上端接一阻值为3Ω的定值电阻R。在水平虚线L₁、L₂间有一与导轨所在平面垂直的匀强磁场B，磁场区域的高度为d=0.5m。导体棒a的质量mₐ=0.2kg、电阻Rₐ=3Ω；导体棒b的质量mᵦ=0.1kg、电阻Rᵦ=6Ω，它们分别从图中M、N处同时由静止开始在导轨上无摩擦向下滑动，且都能匀速穿过磁场区域，当b刚穿出磁场时a正好进入磁场。已知金属棒始终与导轨接触良好且导轨足够长，设重力加速度为g=10m/s²。（不计a、b之间的作用）求：

    （1）a、b两棒在磁场中运动的速度大小之比；
    （2）b棒穿过磁场过程，电阻R上产生的焦耳热。

    **题目分析：**

    本题是电磁感应中的经典"双棒模型"，核心考点包括：
    - 导体棒切割磁感线产生感应电动势 ε = BLv
    - 安培力公式 F = BIL = B²L²v/R_总
    - 匀速运动时重力与安培力平衡：mg = B²L²v/R_总
    - 能量守恒：重力势能减少量 = 焦耳热总量
    - 串联电路中热量按电阻比例分配

    **整体讲解思路：**

    1. 先通过场景图示让学生建立物理图像，理解两棒的运动时序关系
    2. 再通过电路与受力分析图示，推导速度比（第1问）
    3. 最后通过能量分析图示，计算焦耳热（第2问）

    **图示规划：** 共设计2个交互式图示场景。Scene 1 展示物理场景与运动过程动画；Scene 2 整合电路分析、受力平衡推导和能量计算。
    </TEXT_1>

    本图示用于帮助学生建立完整的物理场景认知。

    **引导步骤：**

    1. **步骤0（初始状态）**：引导学生观察装置结构——竖直导轨、顶部电阻、磁场区域、两棒初始位置。提问："两棒从何处开始运动？磁场区域在哪里？"

    3. **步骤2（b匀速穿场）**：这是第一个关键物理过程。b进入磁场后切割磁感线产生感应电流，受到向上的安培力。题目告知b"匀速穿过"，说明安培力与重力平衡。提问："为什么b能匀速运动？受力情况如何？"

    **过渡到下一场景：** 引导学生思考："既然两棒都匀速穿过磁场，那么它们的速度有什么关系？"自然过渡到受力分析和速度比推导。

    **Scene 2 教学说明：**

    本图示整合了第1问和第2问的完整推导过程。

    **第1问讲解（步骤0→步骤3）：**

    1. **步骤0（等效电路）**：引导学生画出b棒在磁场中的等效电路。b棒切割磁感线相当于电源，电动势 ε = BLvᵦ。外电路为R与Rᵦ串联，总电阻 R_总 = R + Rᵦ = 3 + 6 = 9Ω。

    2. **步骤1（b棒受力平衡）**：b棒匀速运动，合力为零。
       - 向下的重力：Gᵦ = mᵦg = 0.1 × 10 = 1 N
       - 向上的安培力：Fᵦ = BIᵦL = B × (BLvᵦ/(R+Rᵦ)) × L = B²L²vᵦ/(R+Rᵦ)
       - 平衡方程：**mᵦg = B²L²vᵦ/(R+Rᵦ)**

    3. **步骤2（a棒受力平衡）**：同理，a棒也匀速运动。
       - 平衡方程：**mₐg = B²L²vₐ/(R+Rₐ)**

    4. **步骤3（速度比推导）**：将两式相除：
       vₐ/vᵦ = (mₐ/mᵦ) × (R+Rᵦ)/(R+Rₐ) = (0.2/0.1) × (3+6)/(3+3) = 2 × 9/6 = 3
       **答案：vₐ : vᵦ = 3 : 1**

    **第2问讲解（步骤4→步骤5）：**

    5. **步骤4（能量分析）**：b棒匀速穿过磁场，动能不变。重力势能全部转化为焦耳热。
       - 重力势能减少：ΔEₚ = mᵦgd = 0.1 × 10 × 0.5 = 0.5 J
       - 总焦耳热：Q_总 = 0.5 J

    6. **步骤5（热量分配）**：串联电路中，热量按电阻比例分配。
       - R上产生的热量：Q_R = Q_总 × R/(R+Rᵦ) = 0.5 × 3/9 = **1/6 J ≈ 0.167 J**
       - Rᵦ上产生的热量：Q_Rb = Q_总 × Rᵦ/(R+Rᵦ) = 0.5 × 6/9 = 1/3 J

    **课堂讲解建议：**
    - 在步骤3推导速度比时，强调"两式相除可以消去未知的B和L"，这是解题的关键技巧
    - 在步骤5热量分配时，可补充说明：串联电路中 Q ∝ R，因为电流相同，Q = I²Rt
    - 可引导学生思考：如果题目要求a棒穿过磁场时R上的热量，计算方法类似，只需将mᵦ换成mₐ，Rᵦ换成Rₐ

    <TEXT_4>
    **完整解答总结：**

    **第（1）问：**
    导体棒在磁场中匀速运动时，重力与安培力平衡：
    - 对a棒：mₐg = B²L²vₐ/(R+Rₐ)
    - 对b棒：mᵦg = B²L²vᵦ/(R+Rᵦ)
    两式相除得：vₐ/vᵦ = (mₐ/mᵦ)×(R+Rᵦ)/(R+Rₐ) = (0.2/0.1)×(3+6)/(3+3) = 3
    **答：a、b两棒在磁场中运动的速度大小之比为 3:1。**

    **第（2）问：**
    b棒匀速穿过磁场，由能量守恒：
    - 总焦耳热 Q_总 = mᵦgd = 0.1 × 10 × 0.5 = 0.5 J
    - R上产生的热量 Q_R = Q_总 × R/(R+Rᵦ) = 0.5 × 3/(3+6) = 1/6 J
    **答：b棒穿过磁场过程，电阻R上产生的焦耳热为 1/6 J（约0.167 J）。**

    **教学要点回顾：**
    - 导体棒切割磁感线的受力平衡条件是解题核心
    - 两式相除消去未知量（B、L）是常用技巧
    - 能量守恒结合串联电路热量分配是第2问的关键
    - "当b刚穿出磁场时a正好进入磁场"这一条件在本题两问中未直接用到，但它是题目自洽性的保证，也可用于拓展讨论（如求M、N间距等）
