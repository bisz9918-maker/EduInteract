[图示主题与整合说明]
- 本图示主题：两种浮力情景的对比展示，突出甲上表面与水面齐平的关键条件
- 整合的步骤/概念：左图（甲+绳+乙）与右图（甲+丙）并排对比，通过5步递进高亮引导学生观察水面齐平、乙浸没、丙在水面上等关键差异，最终推导出"甲排开水的体积相同→甲所受浮力相等"的结论
- 教学价值：教师可通过分步按钮逐步揭示两种情景的共同点（甲上表面齐平）和差异点（乙浸没 vs 丙在水面上），配合底部推导提示完成浮力相等结论的讲解

[分步序列]
- 初始状态（步骤0）：显示左右两图的基础图形——水面线（黑色）、甲/乙/丙物块（含标签）、绳子、水虚线、中间分隔线。无高亮，无额外标注。
- 步骤1：点击「下一步」→ 左右水面线变为蓝色加粗（#1565c0, 3px），显示"水面"标签（左(70,135)、右(470,135)），强调两种情况水面在同一水平高度。
- 步骤2：点击「下一步」→ 在左右甲的上表面各绘制一条绿色加粗线（#2e7d32, 3px），显示"甲上表面与水面相平"标签（(400,120)），强调这是关键条件。
- 步骤3：点击「下一步」→ 乙的轮廓变为红色加粗（#c62828, 3px），丙的轮廓变为红色加粗（#c62828, 3px），显示"乙浸没"标签（(265,295)）和"丙在水面上"标签（(665,125)），突出两种情景的差异。
- 步骤4：点击「下一步」→ 底部显示推导提示文字"甲排开水的体积相同 → 甲所受浮力相等"（(400,420)，#1565c0, 16px, 加粗），完成结论展示。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - "◀ 上一步"按钮：位于(290,455)，110×36px，点击后currentStep减1，更新显示
  - "下一步 ▶"按钮：位于(400,455)，110×36px，点击后currentStep加1，更新显示
  - 步骤0时"上一步"按钮禁用（灰色），步骤4时"下一步"按钮禁用（灰色）
- 教师操作流程：
  1. 图示加载后显示步骤0（基础图形），教师介绍题目背景
  2. 点击"下一步"进入步骤1，讲解水面在同一水平高度
  3. 点击"下一步"进入步骤2，强调甲上表面与水面齐平的关键条件
  4. 点击"下一步"进入步骤3，对比乙浸没与丙在水面上的差异
  5. 点击"下一步"进入步骤4，展示浮力相等的推导结论
  6. 可随时点击"上一步"回退到任意步骤复习

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需额外库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌──────────────────────────────────────────────────────────────┐
  │                                                              │
  │   左图区域(30-370)          │          右图区域(430-770)     │
  │                            │                                │
  │      水面线 y=150 ─────────┼──────── 水面线 y=150           │
  │   ┌────┐                   │    ┌────┐                      │
  │   │ 甲 │                   │    │ 丙 │                      │
  │   └────┘                   │    └────┘                      │
  │    ││                      │   ┌────┐                      │
  │    ││ 绳子                  │   │ 甲 │                      │
  │    ││                      │   └────┘                      │
  │   ┌────┐                   │                                │
  │   │ 乙 │                   │   ~~~ 水虚线 ~~~               │
  │   └────┘                   │   ~~~ 水虚线 ~~~               │
  │   ~~~ 水虚线 ~~~           │   ~~~ 水虚线 ~~~               │
  │   ~~~ 水虚线 ~~~           │   ~~~ 水虚线 ~~~               │
  │   ~~~ 水虚线 ~~~           │   ~~~ 水虚线 ~~~               │
  │                            │                                │
  │                            │                                │
  │   ← 底部提示文字区 y=400-440 →                              │
  │                                                              │
  │   [◀ 上一步]  [下一步 ▶]   y=455                            │
  │                            控件栏 y=440-490                  │
  └──────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. **状态机设计**：使用全局变量 `currentStep`（0-4）跟踪当前步骤，每个步骤对应一组元素的显示/隐藏/样式变化
  2. **元素分组**：使用 `<g>` 标签将步骤1-4的专属元素分组，通过 `display="none"` / `display=""` 控制显隐
  3. **样式切换**：水面线高亮通过修改 `stroke` 和 `stroke-width` 属性实现；乙/丙高亮同理
  4. **按钮事件绑定**：使用 `addEventListener('click', ...)` 绑定按钮点击事件，更新 `currentStep` 后调用 `updateDisplay()` 函数
  5. **按钮禁用逻辑**：步骤0时"上一步"按钮 `pointer-events="none"` 且填充灰色；步骤4时"下一步"按钮同理
  6. **动画过渡**：元素出现时使用 CSS `opacity` 从0到1的过渡效果（0.3s ease-in），增强视觉引导
- ID 命名规范：所有交互元素 ID 以 `scene1-` 为前缀
  - `scene1-waterline-left`、`scene1-waterline-right`（水面线）
  - `scene1-block-jia-left`、`scene1-block-jia-right`（甲物块）
  - `scene1-block-yi`（乙物块）
  - `scene1-block-bing`（丙物块）
  - `scene1-rope`（绳子）
  - `scene1-label-water-left`、`scene1-label-water-right`（水面标签）
  - `scene1-highlight-jia-top-left`、`scene1-highlight-jia-top-right`（甲上表面绿线）
  - `scene1-label-jia-flat`（甲上表面与水面相平标签）
  - `scene1-label-yi-submerged`（乙浸没标签）
  - `scene1-label-bing-above`（丙在水面上标签）
  - `scene1-conclusion-text`（底部提示文字）
  - `scene1-btn-prev`、`scene1-btn-next`（导航按钮）
- IIFE 隔离：所有 JS 代码包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染
