[图示主题与整合说明]
- 本图示主题：初始静止状态下 A、B 系统的受力分析，推导振幅
- 整合的步骤/概念：展示系统初始结构 → 对 B 受力分析 → 对 A 受力分析 → 得出弹簧伸长量即振幅
- 教学价值：教师通过分步按钮逐步展开受力分析，从整体到局部，从 B 到 A，逻辑递进清晰。每一步高亮不同颜色的受力箭头，帮助学生理解力的传递关系和平衡条件，最终推导出振幅表达式。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位置 (200,450)，尺寸 100×35，灰色背景，点击回到上一步
  - 「下一步 ▶」按钮：位置 (500,450)，尺寸 100×35，蓝色#1565c0背景，白色文字，点击进入下一步
  - 步骤指示器：位置 (350,460)，显示 "步骤 X/3"，#000000 文字
- 教师操作流程：
  1. 页面加载显示步骤0（系统初始结构），教师介绍题目背景
  2. 点击「下一步」进入步骤1，蓝色受力箭头出现，教师讲解B的受力平衡 T=mg
  3. 点击「下一步」进入步骤2，红色受力箭头出现，教师讲解A的受力平衡 F_弹=T·cos30°
  4. 点击「下一步」进入步骤3，公式框更新为完整推导，教师总结振幅表达式
  5. 可随时点击「上一步」回退到任意步骤复习

[技术实现]
- JS 库选择：原生 SVG（简单几何图形首选，无需额外库，性能好）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  ┌──────────────────────────────────────────────────────────────┐
  │                                                              │
  │  ║  ~~~~ A ──────────────────────────╭──╮                   │
  │  ║  │   │    30°                     │  │                   │
  │  ║  │   │                            │  │                    │
  │  ║  └───┼────────────────────────────╯  │                   │
  │  │      │                               │  B                │
  │  │      │                               │  ┌──┐             │
  │  │  桌面 │                               │  │B│             │
  │  │      │                               │  └──┘             │
  │  │      │                               │                   │
  │  │      └───────────────────────────────┘                   │
  │                                                              │
  │                                          ┌──────────┐       │
  │                                          │ 公式浮框  │       │
  │                                          └──────────┘       │
  │                                                              │
  │              ◀ 上一步         步骤 X/3        下一步 ▶       │
  │                                          (y=445~485)        │
  └──────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. **状态机设计**：4个状态（步骤0~3），用全局变量 `currentStep` 记录当前步骤
  2. **元素显隐控制**：每个步骤的元素用 SVG `<g>` 分组，通过 `display: none/block` 或 `opacity` 控制显隐
  3. **弹簧绘制**：用 SVG `<path>` 绘制锯齿形，M 65,260 L 72.5,250 L 80,270 L 87.5,250 ... 交替上下
  4. **细线绘制**：三段 path，直线 + 圆弧（A 命令）+ 直线
  5. **箭头绘制**：SVG `<marker>` 定义箭头头部，line 元素引用 marker-end
  6. **公式框更新**：步骤1~3 更新公式框内的 `<text>` 内容，使用 tspan 实现多行
  7. **按钮事件绑定**：click 事件切换 currentStep，更新各元素组的显隐状态
  8. **按钮禁用逻辑**：步骤0时「上一步」禁用，步骤3时「下一步」禁用
- ID 命名规范：所有交互元素 ID 以 `scene1-` 为前缀
  - `scene1-step0-group`：步骤0元素组（系统结构）
  - `scene1-step1-group`：步骤1元素组（B受力）
  - `scene1-step2-group`：步骤2元素组（A受力）
  - `scene1-step3-group`：步骤3元素组（公式更新）
  - `scene1-prev-btn`：上一步按钮
  - `scene1-next-btn`：下一步按钮
  - `scene1-step-indicator`：步骤指示器
  - `scene1-formula-box`：公式浮框
  - `scene1-formula-text`：公式文本
- IIFE 隔离：所有 JS 代码包裹在 `(function() { ... })()` 中，避免全局污染
- 动画：步骤切换时使用 CSS transition（opacity 0.3s ease-in-out），受力箭头淡入效果
