[图示主题与整合说明]
- 本图示主题：子弹射入滑块并压缩弹簧的物理过程动态演示
- 整合的步骤/概念：初始匀速运动状态 → 子弹射入滑块的碰撞瞬间 → 弹簧压缩过程 → 弹簧压缩到最短的锁定状态
- 教学价值：教师可通过分步按钮逐步展示物理过程的四个关键状态，配合速度矢量、质量标注、压缩量标注，帮助学生理解动量守恒和能量守恒在碰撞与弹簧压缩中的应用

[分步序列]

初始状态（步骤0）：

- 显示滑块在小车上表面右侧(480,240)-(560,280)，标注"m=1.8kg"在滑块上方(520,228)
- 显示弹簧（原长，线圈均匀分布）连接挡板与滑块
- 显示子弹在右侧(650,255)，标注"m₀=0.2kg"在子弹上方(665,238)
- 显示v₁=10m/s蓝色箭头向右，位于小车上方(250,200)-(350,200)，文本(275,188)
- 显示v₀=50m/s红色箭头向左，位于子弹上方(600,200)-(650,200)，文本(590,188)

步骤1（子弹射入瞬间）：
- 子弹消失（射入滑块），滑块高亮（边框加粗或闪烁效果）
- 移除v₀箭头和m₀标注
- 新增v₂=4m/s蓝色箭头向右，位于滑块上方(490,200)-(540,200)，文本(495,188)
- v₁=10m/s蓝色箭头仍显示在小车上方
- 弹簧仍为原长状态
- 步骤标题："子弹射入瞬间"
- 标题文本："子弹射入滑块，共同速度v₂=4m/s向右"

步骤2（弹簧压缩过程）：
- 滑块向左移动至(460,240)-(540,280)（中间状态）
- 弹簧压缩至(140,250)-(460,260)，线圈变密集
- v₂=4m/s箭头仍显示在滑块上方（位置随滑块移动）
- v₁=10m/s箭头仍显示在小车上方
- 新增摩擦力虚线箭头标注在滑块下方(460,285)-(500,285)，方向向左（滑块相对小车向右运动，摩擦力向左）
- 步骤标题："弹簧压缩过程"
- 标题文本："滑块速度小于小车，弹簧逐渐压缩"

步骤3（弹簧压缩到最短）：
- 滑块移动至(430,240)-(510,280)（最终位置）
- 弹簧压缩至最短(140,250)-(430,260)，线圈最密集
- 移除v₁和v₂箭头
- 新增v₃=7m/s绿色箭头向右，位于整体上方(250,200)-(350,200)，文本(275,188)

- 步骤标题："弹簧压缩到最短"
- 标题文本："弹簧锁定，压缩量d=0.50m，共同速度v₃=7m/s"

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位置(250,455)-(370,480)，点击返回上一步骤，步骤0时禁用
  - 「下一步 ▶」按钮：位置(430,455)-(550,480)，点击进入下一步骤，步骤3时禁用
  - 步骤指示器：4个圆点，位置(350,488)-(450,498)，当前步骤圆点高亮（蓝色#1565c0），其余灰色#cccccc
- 教师操作流程：
  1. 图示加载后显示步骤0（初始状态），教师可讲解系统初始条件
  2. 点击「下一步 ▶」进入步骤1，讲解子弹射入滑块的碰撞过程
  3. 点击「下一步 ▶」进入步骤2，讲解弹簧压缩过程
  4. 点击「下一步 ▶」进入步骤3，讲解弹簧压缩到最短的锁定状态
  5. 可随时点击「◀ 上一步」回退到任意步骤复习

[技术实现]
- JS 库选择：原生 SVG（简单几何图形，无需复杂库，性能好且易于动画控制）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────┐
  │                    步骤标题                          │  y=30~60
  │                                                     │
  │         v₁→                    v₀←                  │  y=180~210
  │      ┌──────┐              ┌────┐  ●               │  y=220~280
  │      │  M   │~~~~弹簧~~~~~~│ m  │  m₀              │
  │      └──┬───┘              └────┘                  │
  │         ●           ●                              │  y=360 轮子
  │  ────────────────────────────────────────────────   │  y=380 地面
  │  //////// 地面阴影  ////////  μ=0.2                 │  y=380~420
  │                                                     │
  │     [◀ 上一步]    ●●●○    [下一步 ▶]               │  y=455~490
  └─────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. **状态机设计**：定义4个状态（step=0,1,2,3），每个状态对应一组SVG元素的显示/隐藏/位置变化
  2. **弹簧绘制**：使用SVG `<path>` 绘制螺旋线，通过JavaScript动态生成路径数据。原长时线圈间距均匀（约20px间距），压缩时线圈间距缩小（约10px间距）
  3. **滑块动画**：步骤2和步骤3中滑块位置变化使用CSS transition实现平滑移动（transition: transform 0.5s ease-in-out）
  4. **弹簧压缩动画**：步骤切换时弹簧路径变化使用CSS transition或requestAnimationFrame实现平滑过渡
  5. **速度箭头**：使用SVG `<line>` + `<polygon>`（箭头头部）绘制，不同颜色区分不同速度
  6. **高亮效果**：步骤1中滑块射入瞬间，使用CSS动画（边框闪烁或阴影脉冲）高亮滑块
  7. **事件绑定**：按钮点击事件绑定到状态切换函数，更新SVG元素状态
  8. **步骤指示器**：4个圆点，当前步骤圆点填充蓝色#1565c0，其余灰色#cccccc

- ID 命名规范：所有交互元素ID以 `scene1-` 为前缀
  - `scene1-btn-prev`：上一步按钮
  - `scene1-btn-next`：下一步按钮
  - `scene1-indicator-0` ~ `scene1-indicator-3`：步骤指示器圆点
  - `scene1-title`：步骤标题文本
  - `scene1-subtitle`：步骤副标题文本
  - `scene1-cart`：小车组
  - `scene1-block`：滑块组
  - `scene1-spring`：弹簧路径
  - `scene1-bullet`：子弹组
  - `scene1-v1`：v₁速度箭头组
  - `scene1-v0`：v₀速度箭头组
  - `scene1-v2`：v₂速度箭头组
  - `scene1-v3`：v₃速度箭头组
  - `scene1-d-label`：压缩量标注组
  - `scene1-friction`：摩擦力标注组
  - `scene1-ground`：地面组

- IIFE 隔离：所有JS代码包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染
