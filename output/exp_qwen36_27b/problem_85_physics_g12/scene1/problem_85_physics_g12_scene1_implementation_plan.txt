[图示主题与整合说明]
- 本图示主题：双气缸连通系统中氮气加热膨胀、氧气被压缩的三阶段动态演示
- 整合的步骤/概念：
  1. 初始状态：两气缸结构、活塞位置（a离顶1/4H，b在中央1/2H）、气体分布（氮气在活塞下方连通区域，氧气在活塞a上方）、温度T₀=280K、大气压P₀
  2. 第(1)问：缓慢加热氮气，活塞b升至顶部（氮气等压膨胀），求氮气温度T₁=320K
  3. 第(2)问：继续加热，活塞a上升1/16H（氧气等温压缩），求氧气压强P_O2'=4/3P₀
- 教学价值：教师可通过分步按钮控制讲解节奏，每步展示对应状态的气体参数（压强、温度、体积）和关键推导结果，帮助学生理解理想气体状态方程在连通器中的应用

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  · 「◀ 上一步」按钮：位置(280,455)，尺寸(100×30)，点击回退到上一步骤，步骤0时禁用（灰色）
  · 「下一步 ▶」按钮：位置(420,455)，尺寸(100×30)，点击前进到下一步骤，步骤2时禁用（灰色）
  · 步骤指示器：位置(350,475)，文字"步骤 X / 2"，居中显示
- 教师操作流程：
  1. 图示加载后显示初始状态（步骤0），教师可先讲解气缸结构和初始条件
  2. 点击「下一步▶」进入步骤1，活塞b上移至顶部，教师讲解氮气等压膨胀过程及温度计算
  3. 点击「下一步▶」进入步骤2，活塞a上移，教师讲解氧气等温压缩过程及压强计算
  4. 随时点击「◀上一步」回退复习任意步骤
  5. 状态面板实时显示当前步骤的气体参数和关键推导结果

[技术实现]
- JS 库选择：原生 SVG（简单几何图形、矩形、线段、箭头、波浪线均可用SVG原生元素实现，无需额外库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +------------------------------------------------------------+
  |  气缸A(宽)                    气缸B(窄)    状态面板         |
  |  +--------+                  +------+    +--------+        |
  |  |  氧气  |                  |      |    | 状态   |        |
  |  |--------|  a              |  b   |    | 参数   |        |
  |  |        |                  |------|    | 面板   |        |
  |  |  氮气  |                  |      |    |        |        |
  |  |   A    |                  |   B  |    | P,T,V  |        |
  |  |        |                  |      |    | 信息   |        |
  |  |  ~~~R  |                  |      |    |        |        |
  |  +---+----+                  +--+---+    +--------+        |
  |      |                           |                         |
  |      +-------------+-------------+                         |
  |                      |                                      |
  |              连通管                                    |
  |                                                       |
  |              [◀上一步]  [下一步▶]                      |
  |                      步骤 X/2                          |
  +------------------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：3个状态（0、1、2），用全局变量`currentStep`跟踪，每个状态对应一组SVG属性
  2. 坐标计算：
     · 气缸高度H=300px（y=60~360）
     · 1/4H=75px，1/2H=150px，1/16H=18.75px
     · 活塞a初始y=60+75=135，步骤2y=135-18.75=116.25≈116
     · 活塞b初始y=60+150=210，步骤1y=60
  3. 动画曲线：活塞移动使用CSS transition或requestAnimationFrame，时长800ms，缓动ease-in-out
  4. 事件绑定：按钮click事件触发stepForward()/stepBackward()函数
  5. 状态面板更新：每步切换时更新面板内文字内容
  6. 电阻丝颜色切换：步骤0为#888888，步骤1-2为#c62828
  7. 高度标注线动态显示/隐藏：用SVG元素的visibility或opacity控制
- ID 命名规范：所有交互元素ID以`scene1-`为前缀
  · `scene1-piston-a`：活塞a元素
  · `scene1-piston-b`：活塞b元素
  · `scene1-nitrogen-a`：氮气区域A
  · `scene1-nitrogen-b`：氮气区域B
  · `scene1-oxygen`：氧气区域
  · `scene1-heater`：电阻丝
  · `scene1-panel`：状态面板
  · `scene1-btn-prev`：上一步按钮
  · `scene1-btn-next`：下一步按钮
  · `scene1-step-indicator`：步骤指示器
  · `scene1-label-14h`：1/4H标注
  · `scene1-label-12h`：1/2H标注
  · `scene1-label-316h`：3/16H标注（步骤2显示）
- IIFE 隔离：所有JS代码包裹在`(function() { 'use strict'; ... })();`中，避免全局污染
