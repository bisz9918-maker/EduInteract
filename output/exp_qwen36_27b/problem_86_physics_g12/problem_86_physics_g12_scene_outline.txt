    **题目原文：**

    如图所示，水平放置的平行板电容器，原来$AB$两板不带电，$B$极板接地，它的极板长$L=0.1m$，两板间距离$d=0.4cm$，现有一微粒质量$m=2.0×10^{−6}kg$，带电量$q=+1.0×10^{−8}C$，以一定初速度从两板中央平行于极板射入，由于重力作用微粒恰好能落到$A$板上中点$O$处，取$g=10m⋅s^{−2}$，试求：

    （$1$）带电粒子入射初速度的大小；

    （$2$）现使电容器带上电荷，使带电微粒能从平行板电容器的右侧射出，则带电后$A$板的电势范围为多少？

    **题目分析：**

    本题考察带电粒子在重力场和电场中的运动，分为两个子问题：

    - **第（1）问**：电容器不带电时，粒子仅受重力，做平抛运动。粒子从两板中央射入，落到$A$板中点$O$，即竖直下落距离为$d/2$，水平位移为$L/2$。利用平抛运动规律可求初速度$v_0$。

    - **第（2）问**：电容器带电后，粒子同时受重力和电场力。要使粒子从右侧射出，需电场力向上抵消部分重力。存在两个临界状态：①粒子刚好从下板右边缘射出（电场力最小）；②粒子刚好从上板右边缘射出（电场力最大）。由此确定$A$板电势范围。

    **第（1）问教学说明：**

    本图示展示粒子在无电场电容器中的平抛运动。教师可按以下步骤引导：

    1. **步骤0——理解题意**：引导学生观察电容器结构，确认粒子从两板中央射入，初速度水平。强调此时电容器不带电，粒子仅受重力。

    竖直方向：$\frac{d}{2} = \frac{1}{2}gt^2$

    代入数据：$0.002 = \frac{1}{2} \times 10 \times t^2$，解得$t = 0.02\text{ s}$

    水平方向：$\frac{L}{2} = v_0t$

    代入数据：$0.05 = v_0 \times 0.02$，解得$v_0 = 2.5\text{ m/s}$

    **关键提醒**：注意单位换算，$d = 0.4\text{ cm} = 0.004\text{ m}$。

    **第（2）问教学说明：**

    本图示通过滑块交互展示电场力变化对粒子轨迹的影响，帮助学生直观理解临界条件。

    **引导步骤：**

    1. **电场方向分析**：粒子带正电（$q > 0$），要使粒子不落到$A$板，需电场力向上。电场方向从$A$指向$B$（向上），故$A$板电势$φ_A > 0$。

    2. **受力分析**：粒子受两个力——重力$mg$向下，电场力$F_e = qE = q\frac{φ_A}{d}$向上。

    3. **运动时间**：粒子水平速度不变，$v_0 = 2.5\text{ m/s}$，通过极板的时间$t = \frac{L}{v_0} = \frac{0.1}{2.5} = 0.04\text{ s}$。

    4. **临界条件1——刚好从下板右边缘射出**（拖动滑块至φ_A = 6V）：

    竖直位移$y = -\frac{d}{2} = -0.002\text{ m}$

    由$y = \frac{1}{2}a_1t^2$，得$a_1 = \frac{2y}{t^2} = \frac{2 \times (-0.002)}{0.0016} = -2.5\text{ m/s}^2$

    由牛顿第二定律：$\frac{F_{e1}}{m} - g = a_1$，即$\frac{F_{e1}}{m} = g + a_1 = 7.5\text{ m/s}^2$

    $F_{e1} = 7.5 \times 2.0 \times 10^{-6} = 1.5 \times 10^{-5}\text{ N}$

    $φ_{A1} = \frac{F_{e1} \cdot d}{q} = \frac{1.5 \times 10^{-5} \times 0.004}{1.0 \times 10^{-8}} = 6\text{ V}$

    5. **临界条件2——刚好从上板右边缘射出**（拖动滑块至φ_A = 10V）：

    竖直位移$y = \frac{d}{2} = 0.002\text{ m}$

    $a_2 = \frac{2 \times 0.002}{0.0016} = 2.5\text{ m/s}^2$

    $\frac{F_{e2}}{m} = g + a_2 = 12.5\text{ m/s}^2$

    $F_{e2} = 12.5 \times 2.0 \times 10^{-6} = 2.5 \times 10^{-5}\text{ N}$

    $φ_{A2} = \frac{2.5 \times 10^{-5} \times 0.004}{1.0 \times 10^{-8}} = 10\text{ V}$

    6. **结论**：$A$板电势范围为$6\text{ V} \leq φ_A \leq 10\text{ V}$。

    **教学建议**：让教师先让学生猜测电势范围，再通过滑块拖动验证。强调两个临界状态对应的物理意义——电场力太小粒子会落到下板，电场力太大粒子会碰到上板。

    **完整解答总结：**

    **第（1）问：**

    粒子仅受重力，做平抛运动。

    竖直方向：$\frac{d}{2} = \frac{1}{2}gt^2$，代入$d = 0.004\text{ m}$，$g = 10\text{ m/s}^2$，得$t = 0.02\text{ s}$

    水平方向：$\frac{L}{2} = v_0t$，代入$L = 0.1\text{ m}$，$t = 0.02\text{ s}$，得$v_0 = 2.5\text{ m/s}$

    **答案：$v_0 = 2.5\text{ m/s}$**

    **第（2）问：**

    粒子受重力$mg$和电场力$F_e = q\frac{φ_A}{d}$。

    粒子通过极板时间$t = \frac{L}{v_0} = 0.04\text{ s}$。

    临界1（从下板右边缘射出）：$φ_{A\text{min}} = 6\text{ V}$

    临界2（从上板右边缘射出）：$φ_{A\text{max}} = 10\text{ V}$

    **答案：$6\text{ V} \leq φ_A \leq 10\text{ V}$**
