[图示主题与整合说明]
- 本图示主题：加电场后带电粒子轨迹随A板电势变化的临界分析（第2问）
- 整合的步骤/概念：电场力方向分析 → 滑块调节A板电势 → 实时显示粒子轨迹变化 → 标注两个临界状态（刚好从下板右边缘射出φ_A=6V / 刚好从上板右边缘射出φ_A=10V） → 确定电势范围
- 教学价值：教师通过拖动滑块改变A板电势，学生可直观观察电场力大小变化对粒子轨迹的影响，理解"刚好射出"的临界条件，从而确定A板电势的取值范围[6V, 10V]。滑块上的绿色标记线帮助学生快速定位临界值。

[分步序列]
本场景为连续拖拽交互，无分步导航。状态由滑块位置连续决定：

- 初始状态（φ_A = 0V，滑块在中心675px）：
  * 显示完整电容器结构（极板A/B、接地符号、尺寸标注L/d）
  * 粒子⊕在(100,240)，v₀箭头水平向右
  * mg箭头向下（30px），F_e箭头不显示（电场力为零）
  * 无电场线
  * 轨迹为抛物线：从(100,240)到(320,350)，即落到A板中点O
  * 轨迹终点标记在(320,350)
  * 信息面板：φ_A=0.0V，F_e=0.00×10⁻⁵N，合力方向：向下，射出状态：落在A板上
  * 临界1/2参考点始终可见（红色小圆点）

- 拖动滑块增大φ_A（0V → 6V）：
  * F_e箭头逐渐变长（向上），电场线出现（3条向上虚线箭头）
  * 轨迹逐渐变平，终点从(320,350)向右移动
  * 信息面板实时更新φ_A、F_e值
  * 当φ_A接近6V（±0.5V内）：滑块手柄变为绿色#2e7d32
  * φ_A=6V时：轨迹终点到达(540,350)，刚好从下板右边缘射出
  * 射出状态变为"刚好从下板右边缘射出"

- 继续增大φ_A（6V → 8V）：
  * F_e继续增大，轨迹继续变平
  * 粒子从两板之间射出，射出点在右边缘y=350~240之间
  * φ_A=8V时：a_net=0，F_e=mg，轨迹为水平直线(100,240)-(540,240)
  * 合力方向：为零
  * 射出状态："从两板之间射出"

- 继续增大φ_A（8V → 10V）：
  * F_e > mg，合力向上，轨迹开始向上弯曲
  * 射出状态："从两板之间射出"
  * 当φ_A接近10V（±0.5V内）：滑块手柄变为绿色#2e7d32
  * φ_A=10V时：轨迹终点到达(540,130)，刚好从上板右边缘射出
  * 射出状态变为"刚好从上板右边缘射出"

- 继续增大φ_A（>10V）：
  * 轨迹向上弯曲更明显，粒子撞上B板
  * 射出状态："撞上B板"

- 拖动滑块减小φ_A（负值）：
  * F_e箭头向下（与mg同向），电场线向下
  * 粒子更快落到A板上，落点更靠近左侧
  * 射出状态："落在A板上"

- 点击"重置"按钮：
  * 滑块回到0V位置，所有元素恢复初始状态

- 关键实现要点：

  1. **轨迹计算公式**（像素坐标系）：
     - 粒子入口：(100, 240)
     - 净加速度：a_net = g - q·φ_A/(m·d) = 10 - 1.25·φ_A（m/s²，向下为正）
     - 轨迹方程：y(x) = 240 + a_net · (x - 100)² / 4400
     - 推导：水平方向x = 100 + 4400·v₀·t，竖直方向y = 240 + 55000·0.5·a_net·t²
       消去t得 y = 240 + a_net·(x-100)²/4400
     - 验证：φ_A=0时a_net=10，x=320→y=240+10·220²/4400=240+110=350 ✓（中点O）
     - 验证：φ_A=6时a_net=2.5，x=540→y=240+2.5·440²/4400=240+110=350 ✓（下板右边缘）
     - 验证：φ_A=10时a_net=-2.5，x=540→y=240-2.5·440²/4400=240-110=130 ✓（上板右边缘）

  2. **轨迹终点计算**：
     - φ_A < 6V（a_net > 2.5）：粒子落到A板，x_hit = 100 + √(484000/a_net)，终点(x_hit, 350)
     - φ_A > 10V（a_net < -2.5）：粒子撞到B板，x_hit = 100 + √(-484000/a_net)，终点(x_hit, 130)
     - 6V ≤ φ_A ≤ 10V：粒子从右边缘射出，终点(540, y_exit)，y_exit = 240 + a_net·44

  3. **轨迹绘制**：
     - 以2px为步长采样x坐标，计算对应y值
     - 构建SVG path字符串："M 100 240 L x1 y1 L x2 y2 ..."
     - 在终点处绘制红色小圆(r=3)

  4. **F_e箭头长度计算**：
     - F_e = q·φ_A/d = 2.5×10⁻⁶·φ_A（N）
     - 像素长度 = 30 · |F_e| / (2.0×10⁻⁵) = 3.75 · |φ_A|（px）
     - φ_A > 0时箭头向上，φ_A < 0时箭头向下，φ_A = 0时不显示

  5. **信息面板更新**：
     - φ_A值：直接读取滑块位置换算
     - F_e值：F_e / 10⁻⁵ = 0.25 · φ_A
     - 合力方向：a_net > 0 → "向下"；a_net < 0 → "向上"；a_net = 0 → "为零"
     - 射出状态：根据φ_A范围判断（<6V/6V/6~10V/10V/>10V）
