[图示主题与整合说明]
- 本图示主题：等效电路分析与能量守恒关系
- 整合的步骤/概念：将金属棒在磁场中运动产生的电磁感应问题转化为等效电路模型（金属棒作为电源，电动势E=BLv₀cosθ，内阻r_内=R/3），通过串联电路分析求解路端电压、焦耳热积分、以及利用能量守恒求解拉力做功。三个小问层层递进，从电路分析到积分计算再到能量守恒。
- 教学价值：教师可通过分步按钮逐步展示解题思路，先建立等效电路模型，再依次求解三个小问。每一步的视觉高亮和计算文本框帮助学生在课堂上跟随推导过程，理解物理量之间的关系。

[分步序列]

步骤0（初始状态 - 等效电路）：
- 显示完整等效电路图：电源（电池符号，红）、内阻R/3（红框）、外电阻R（蓝框）、导线（黑）
- 显示电流方向箭头（绿），标注I
- 标注E=BLv₀cosθ（电源左侧）、r_内=R/3（内阻下方）、R（外电阻右侧）
- 计算文本框显示标题"等效电路分析"
- 能量守恒区域隐藏
- 步骤标题："步骤1/4：等效电路模型"

步骤1（第1问：cd两端电压）：
- 电路图中路端电压U_cd高亮（红#c62828背景10%透明度覆盖外电阻R区域）
- 计算文本框显示：
  "第(1)问：cd两端电压"
  "R_总 = R + R/3 = 4R/3"
  "I = E / R_总 = 3E/(4R)"
  "U_cd = I × R = 3E/4 = 3BLv₀/4"
- 关键结果"U_cd = 3BLv₀/4"用红背景高亮
- 能量守恒区域隐藏
- 步骤标题："步骤2/4：路端电压计算"

步骤2（第2问：R上热量）：
- 电路图中外电阻R闪烁高亮（蓝#1565c0边框加粗）
- 计算文本框显示：
  "第(2)问：R上产生的热量"
  "瞬时电动势 E = BLv₀cosθ"
  "瞬时电流 I = 3BLv₀cosθ/(4R)"
  "瞬时功率 P_R = I²R = [3BLv₀cosθ/(4R)]² × R"
  "时间元 dt = r·dθ/v₀"
  "Q_R = ∫₀^{π/2} P_R · dt"
  "Q_R = 9πB²L²v₀r/(64R)"
- 关键结果"Q_R = 9πB²L²v₀r/(64R)"用红背景高亮
- 能量守恒区域隐藏
- 步骤标题："步骤3/4：焦耳热积分计算"

步骤3（第3问：拉力做功 - 最终状态）：
- 电路图保持显示但淡化（透明度60%）
- 计算文本框显示：
  "第(3)问：拉力做的功"
  "能量守恒：W_F = mgr + Q_总"
  "Q_总 = Q_R × (4R/3)/R = 4Q_R/3"
  "Q_总 = 3πB²L²v₀r/(16R)"
  "W_F = mgr + 3πB²L²v₀r/(16R)"
- 关键结果"W_F = mgr + 3πB²L²v₀r/(16R)"用红背景高亮
- 能量守恒树状图显示：
  - 根节点"W_F"（蓝框蓝底）
  - 分支"mgr"（蓝框蓝底）
  - 分支"Q_总"（蓝框蓝底）
  - 连接线（灰）
- 步骤标题："步骤4/4：能量守恒与拉力做功"

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于控件栏左侧(300,455)，点击返回上一步骤，第一步时禁用
  - 「步骤指示」文本：位于控件栏中央(400,465)，显示"步骤 X/4"
  - 「下一步 ▶」按钮：位于控件栏右侧(420,455)，点击进入下一步骤，最后一步时禁用
- 教师操作流程：
  1. 图示加载后显示步骤0（等效电路），教师可先讲解电路模型
  2. 点击「下一步」进入步骤1，展示路端电压计算，教师配合讲解公式推导
  3. 点击「下一步」进入步骤2，展示热量积分计算，教师讲解积分过程
  4. 点击「下一步」进入步骤3，展示能量守恒关系，教师总结全题
  5. 可随时点击「上一步」回退到任意步骤复习

[技术实现]
- JS 库选择：原生 SVG（简单几何图形和电路图最适合SVG实现，无需额外库）
- 画布尺寸：800 × 500 px
- 布局草图（ASCII）：
  ```
  ┌─────────────────────────────────────────────────────┐
  │              步骤标题（居中）                         │ y=20~45
  ├─────────────────────────────────────────────────────┤
  │                                                     │
  │  ┌──────┐    ┌──────────────────────────────┐       │
  │  │ 电源 │───→│     计算文本框                │       │ y=50~270
  │  │ (E,r)│    │  (分步显示计算过程)           │       │
  │  └──────┘←───└──────────────────────────────┘       │
  │  外电阻R                                             │
  │  电流箭头(绿)                                        │
  │                                                     │
  ├─────────────────────────────────────────────────────┤
  │                                                     │
  │  [W_F] ──→ [mgr]    (步骤3显示)                     │ y=300~440
  │       └───→ [Q_总]                                  │
  │                                                     │
  ├─────────────────────────────────────────────────────┤
  │         [◀上一步]  步骤X/4  [下一步▶]                │ y=440~490
  └─────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. **状态机设计**：4个状态（步骤0~3），用全局变量`currentStep`记录当前步骤，每个步骤对应一组显示/隐藏/高亮操作
  2. **SVG元素管理**：所有SVG元素用`<g>`分组，按步骤控制`opacity`和`display`属性
  3. **动画效果**：步骤切换时使用CSS transition（0.3s ease）实现淡入淡出
  4. **高亮效果**：关键结果用半透明红色矩形覆盖（`<rect fill="#c62828" opacity="0.1">`）
  5. **电池符号绘制**：用两条不等长平行线表示（长线正极，短线负极）
  6. **箭头绘制**：用SVG `<marker>`定义箭头头部，在线段末端引用
  7. **事件绑定**：按钮点击事件绑定到`prevStep()`和`nextStep()`函数，边界检查（步骤0不能上一步，步骤3不能下一步）
  8. **公式渲染**：使用HTML文本+Unicode字符显示公式（如²、π、∫、θ等），避免引入MathJax增加复杂度
- ID 命名规范：所有交互元素ID以`scene2-`为前缀
  - `scene2-circuit-group`：电路回路分组
  - `scene2-battery`：电源符号
  - `scene2-internal-resistor`：内阻矩形
  - `scene2-external-resistor`：外电阻矩形
  - `scene2-current-arrows`：电流箭头分组
  - `scene2-calc-box`：计算文本框
  - `scene2-calc-text`：计算文本内容
  - `scene2-energy-group`：能量守恒图分组
  - `scene2-energy-wf`：W_F节点
  - `scene2-energy-mgr`：mgr节点
  - `scene2-energy-qtotal`：Q_总节点
  - `scene2-step-title`：步骤标题
  - `scene2-btn-prev`：上一步按钮
  - `scene2-btn-next`：下一步按钮
  - `scene2-step-indicator`：步骤指示
- IIFE 隔离：所有JS代码包裹在`(function() { 'use strict'; ... })();`中，避免全局污染
