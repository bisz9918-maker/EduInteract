**题目原文：**

如图所示，在直角坐标系xoy中，虚线ab将第一象限分成两块区域，左边区域匀强电场沿x轴正方向，电场强度E₁，右边区域匀强电场方向沿y轴负方向，电场强度E₂。现一个质量为m（重力忽略不计），电荷量为q的正粒子静止放在y轴上的P（0，h）点，粒子在电场力的作用下运动，最后从x轴上的Q点离开电场区域，已知虚线ab距y轴的距离L，求：

（1）粒子穿过E₁电场区域的速度；

（2）粒子经过Q点的速度大小；

（3）Q点的坐标。

**题目分析：**

本题考察带电粒子在复合电场中的运动，涉及两个阶段的运动分析：

1. **E₁区域（0 < x < L）**：粒子从P(0,h)静止出发，受沿x轴正方向的电场力F = qE₁，做**匀加速直线运动**，到达虚线ab时获得沿x轴方向的速度。

2. **E₂区域（x > L）**：粒子以E₁区域获得的速度进入，受沿y轴负方向的电场力F = qE₂，做**类平抛运动**（x方向匀速，y方向匀加速），最终到达x轴上的Q点。

**整体讲解思路：**

- 先引导学生观察题目图片，识别两个电场区域的方向和粒子的初始位置
- 分阶段分析粒子的运动：E₁区域的匀加速直线运动 → E₂区域的类平抛运动
- 每个阶段分别进行受力分析、运动学分析
- 最后在Q点进行速度合成，并计算Q点坐标

**SCENE_1 教学说明：粒子在E₁电场中的匀加速直线运动**

本图示展示粒子在E₁电场区域中的运动过程，对应题目第（1）问。

**引导步骤：**

1. **步骤0（初始状态）**：引导学生观察坐标系和两个电场区域，确认粒子初始位置P(0,h)和初始状态（静止）。提问：粒子将向哪个方向运动？为什么？

2. **步骤1（受力分析）**：引导学生分析粒子在E₁区域所受的力。正电荷q在电场E₁中受电场力F=qE₁，方向与电场方向相同（沿x轴正方向）。由牛顿第二定律，加速度a₁=F/m=qE₁/m。

3. **步骤2（运动过程）**：粒子从静止开始，沿x轴正方向做匀加速直线运动。位移为L（从y轴到虚线ab）。提问：可以用哪个运动学公式？

4. **步骤3（速度计算）**：由匀加速直线运动公式v²-v₀²=2a₁s，代入v₀=0、a₁=qE₁/m、s=L，得：

v² = 2·(qE₁/m)·L

v = √(2qE₁L/m)

方向沿x轴正方向。

**关键公式：**

- 电场力：F = qE₁
- 加速度：a₁ = qE₁/m
- 速度公式：v = √(2qE₁L/m)

**教学提示：**

- 强调粒子在E₁区域只受x方向的电场力，y方向不受力，所以y坐标保持不变（始终为h）
- 粒子到达ab线时，速度方向沿x轴正方向，大小为√(2qE₁L/m)
- 这个速度将作为粒子进入E₂区域的初速度

**SCENE_2 教学说明：粒子在E₂电场中的类平抛运动与Q点分析**

本图示展示粒子在E₂电场区域中的运动过程，对应题目第（2）问和第（3）问。

**引导步骤：**

1. **步骤0（进入E₂区域）**：引导学生回顾粒子在ab线处的状态：位置(L,h)，速度v=√(2qE₁L/m)沿x轴正方向。提问：粒子进入E₂区域后，受力情况如何变化？

2. **步骤1（受力分析与运动分解）**：粒子在E₂区域受电场力F=qE₂，方向沿y轴负方向。由于初速度沿x轴方向，与电场力方向垂直，粒子做**类平抛运动**：
   - x方向：不受力，做匀速直线运动，vx = v = √(2qE₁L/m)
   - y方向：受恒力F=qE₂，做匀加速直线运动，加速度a₂ = qE₂/m

3. **步骤2（运动轨迹与时间计算）**：粒子从y=h处运动到y=0（x轴），y方向位移为h。由匀加速运动公式：

h = (1/2)·a₂·t² = (1/2)·(qE₂/m)·t²

解得运动时间：

t = √(2mh/qE₂)

x方向位移：

Δx = vx·t = √(2qE₁L/m)·√(2mh/qE₂) = 2√(E₁Lmh/E₂)

4. **步骤3（Q点速度与坐标）**：
   - y方向速度：vy = a₂·t = (qE₂/m)·√(2mh/qE₂) = √(2qE₂h/m)
   - Q点速度大小：vQ = √(vx² + vy²) = √(2qE₁L/m + 2qE₂h/m) = √[2q(E₁L + E₂h)/m]
   - Q点x坐标：xQ = L + Δx = L + 2√(E₁Lmh/E₂)
   - Q点坐标：Q(L + 2√(E₁Lmh/E₂), 0)

**关键公式：**

- 电场力：F = qE₂
- 加速度：a₂ = qE₂/m
- 运动时间：t = √(2mh/qE₂)
- x方向位移：Δx = 2√(E₁Lmh/E₂)
- Q点速度：vQ = √[2q(E₁L + E₂h)/m]
- Q点坐标：Q(L + 2√(E₁Lmh/E₂), 0)

**教学提示：**

- 强调类平抛运动的分解思想：x方向匀速、y方向匀加速
- 速度合成用平行四边形法则（或勾股定理）
- Q点坐标由两部分组成：E₁区域的位移L + E₂区域的位移Δx

**完整解答总结：**

**第（1）问：粒子穿过E₁电场区域的速度**

粒子在E₁区域做匀加速直线运动：
- 加速度：a₁ = qE₁/m
- 由v² = 2a₁L，得：v = √(2qE₁L/m)
- 方向：沿x轴正方向

**第（2）问：粒子经过Q点的速度大小**

粒子在E₂区域做类平抛运动：
- x方向速度：vx = v = √(2qE₁L/m)（不变）
- y方向速度：vy = √(2qE₂h/m)
- Q点速度大小：vQ = √(vx² + vy²) = √[2q(E₁L + E₂h)/m]

**第（3）问：Q点的坐标**

- 运动时间：t = √(2mh/qE₂)
- x方向位移（E₂区域）：Δx = vx·t = 2√(E₁Lmh/E₂)
- Q点x坐标：xQ = L + Δx = L + 2√(E₁Lmh/E₂)
- Q点坐标：Q(L + 2√(E₁Lmh/E₂), 0)

**课堂讲解建议：**

1. **先整体后局部**：先让学生观察题目图片，理解两个电场区域的分布和粒子的运动路径，再分阶段详细分析。

2. **强调运动分解思想**：E₁区域是单向匀加速直线运动，E₂区域是类平抛运动（两个方向的独立运动），这是解题的关键。

3. **注意物理量的传递**：粒子在E₁区域获得的速度是E₂区域运动的初速度，两个阶段通过速度联系起来。

4. **引导学生自主推导**：在每个步骤暂停，让学生先思考再展示答案，培养推导能力。

5. **总结规律**：带电粒子在匀强电场中的运动，关键是受力分析和运动分解，这是处理此类问题的通用方法。
