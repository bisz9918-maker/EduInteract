[图示主题与整合说明]
- 本图示主题：展示题目基础几何结构，分步识别三对相似三角形
- 整合的步骤/概念：基础图形构建（线段AB、等边△ACD与△BCE、连线DE/AF及交点G/H/P/F）→ 逐对高亮相似三角形（△ADG∽△AFB → △CHE∽△CFA → △DCE∽△ACF）→ 对应角弧线标注与等号标记
- 教学价值：教师可通过「下一步」按钮逐步引导学生观察图形特征，从整体结构聚焦到局部相似关系，配合颜色高亮与角度标注强化对应顶点与对应角的认知，避免一次性展示全部信息造成的认知负荷。

[分步序列]
- 初始状态（步骤0）：显示完整基础图形。线段AB、等边△ACD、等边△BCE、DE、AF、交点G/H、中点P/F全部以标准黑色实线/圆点呈现。标签A/B/C/D/E/P/F/G/H及AB=8可见。无高亮，无角度弧线。步骤提示显示：“基础图形：等边△ACD与△BCE，连线DE、AF及交点G、H、P、F”。
- 步骤1：点击「下一步」→ 高亮第一对相似三角形△ADG ∽ △AFB。
  - △ADG区域填充蓝色半透明（#1565c0, 20%），边框加粗2.5px
  - △AFB区域填充红色半透明（#c62828, 20%），边框加粗2.5px
  - 出现绿色角度弧线：∠DAG与∠FAB（顶点A处，半径30px），∠ADG与∠ABF（顶点D和B处，半径25px），弧线旁标注“60°”及等号标记
  - 步骤提示更新：“第一对相似：△ADG ∽ △AFB（公共角+60°对应角）”
- 步骤2：点击「下一步」→ 清除步骤1高亮，高亮第二对相似三角形△CHE ∽ △CFA。
  - △CHE区域填充蓝色半透明，△CFA区域填充红色半透明
  - 出现绿色角度弧线：∠HCE与∠FCA（顶点C处），∠CEH与∠CAF（顶点E和A处），标注“60°”及等号
  - 步骤提示更新：“第二对相似：△CHE ∽ △CFA（公共角+60°对应角）”
- 步骤3：点击「下一步」→ 清除步骤2高亮，高亮第三对相似三角形△DCE ∽ △ACF。
  - △DCE区域填充蓝色半透明，△ACF区域填充红色半透明
  - 出现绿色角度弧线：∠DCE与∠CAF（顶点C和A处），∠CDE与∠ACF（顶点D和C处），标注对应关系
  - 步骤提示更新：“第三对相似：△DCE ∽ △ACF（60°对应角+夹角相等）”
- 回退机制：点击「◀ 上一步」可逐级返回至步骤0，所有高亮与标注按逆序消失。

[交互方案]
- 交互类型：分步按钮导航（◀上一步 / 下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位于(250,460)，宽120px，高30px，点击返回上一状态（步骤0时禁用）
  - 「下一步 ▶」按钮：位于(430,460)，宽120px，高30px，点击进入下一状态（步骤3时禁用）
  - 步骤提示文本：位于(400,435)，动态更新当前高亮对说明
- 教师操作流程：教师点击「下一步」逐对展示相似三角形，配合口头讲解对应角与对应边；可随时点击「上一步」回退复习或重新演示某一对；步骤3完成后图形保持最终高亮状态供板书对照。

[技术实现]
- JS 库选择：原生 SVG + Vanilla JS。理由：几何图形固定、交互为简单状态切换，无需重型框架；SVG 矢量缩放清晰，CSS/JS 控制 fill-opacity 与 stroke 切换性能极佳。
- 画布尺寸：800 × 500 px（固定 viewBox）
- 布局草图（ASCII）：
  ```
  [ 图示区 800×440 ]
  D(240,224)          E(490,103)
     \   P(365,164)  /
      \   /   \    /
       \ /     \  /
  A----C--------B  (y=380)
  (150) (330)  (650)
         G H F
  [ 提示文本 y=435 ]
  [ ◀上一步(250)   下一步▶(430) y=460~485 ]
  ```
- 关键实现要点：
  1. 状态机设计：`let currentStep = 0; const maxStep = 3;` 按钮点击触发 `updateScene(step)`，根据 step 值切换 SVG 元素的 `class` 或内联样式（opacity, stroke, display）。
  2. 高亮实现：使用 `<polygon>` 定义三个高亮对，初始 `opacity="0"`，激活时 `opacity="0.2"` + `stroke-width="2.5"`，配合 CSS transition `0.3s ease` 实现平滑淡入。
  3. 角度标注：使用 `<path>` 绘制圆弧（`A rx ry x-axis-rotation large-arc-flag sweep-flag x y`），初始 `display="none"`，对应步骤激活时 `display="block"`。等号标记用 `<text>` 定位在弧线中点外侧。
  4. 事件绑定：`document.getElementById('scene1-prev').addEventListener('click', ...)`，`document.getElementById('scene1-next').addEventListener('click', ...)`。边界检查：step=0 时 prev 按钮 `disabled`，step=3 时 next 按钮 `disabled`。
  5. ID 命名规范：所有交互元素及关键图形 ID 以 `scene1-` 开头，如 `scene1-poly-adg`, `scene1-arc-a1`, `scene1-prev`, `scene1-next`, `scene1-hint`。
  6. IIFE 隔离：全部 JS 逻辑包裹在 `(function() { 'use strict'; ... })();` 中，避免全局变量污染，支持多场景合并渲染。
