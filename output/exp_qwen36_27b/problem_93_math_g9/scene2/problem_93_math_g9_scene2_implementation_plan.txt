[图示主题与整合说明]
- 本图示主题：C在AB中点时的特殊情况——计算CP长度与AG:GH:HF比值
- 整合的步骤/概念：中点状态图形展示 → CP长度计算（等边三角形高） → 线段比AG:GH:HF的坐标法计算
- 教学价值：教师通过分步导航，先展示C在中点时的对称图形，再逐步引导学生理解CP作为等边三角形高的计算，最后通过坐标法求出AF被DC、CE分割的三段比值。分步展示帮助学生跟随推导思路，避免信息过载。

[技术实现]
- JS 库选择：原生 SVG（无需外部库）
  原因：本场景为纯几何图形（线段、圆、多边形、文字），SVG原生支持所有需要的形状和CSS过渡动画，无需引入D3.js等重型库，保持轻量。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [图示区 800×500]
  y=120:          D         P         E
                  /\        |        /|\
                 /  \       |       /  | \
                /    \      |      /   |  \
               /      \     |     /    |   \
              /        \    |    /     |    \
             /          \   |   /      |     \
            /            \  |  /       |      \
           /              \ | /        |       \
          /                \|/         |        \
         /                  P          |         \
        /                              |          \
       /                               |           \
      /                                |            \
     /                                 |             \
    /                                  |              \
   /                                   |               \
  A──────────────────C─────────────────B
   AC=4              |              CB=4
                     |
              [AG:GH:HF=3:1:2]
  ┌──────────────────────────────────────────────────┐
  │ 坐标: A(0,0) C(4,0) D(2,2√3) E(6,2√3) F(7,√3)  │
  │ AF: y=(√3/7)x → G(3.5,√3/2) H(14/3,2√3/3)      │
  └──────────────────────────────────────────────────┘
  ┌──────────────────────────────────────────────────┐
  │         ◀ 上一步    步骤 2/3    下一步 ▶         │
  └──────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：currentStep变量（0/1/2），每个步骤对应一组SVG元素的显示/隐藏/样式变化
  2. 步骤切换函数：goToStep(n)，根据n值更新所有相关元素的属性
  3. 动画过渡：使用CSS transition（0.5s ease-in-out）实现淡入/颜色变化
  4. 元素可见性控制：通过opacity属性（0→1）实现淡入效果，而非display:none
  5. 坐标计算：数学坐标→像素坐标的转换函数 px(x,y) = (100+x*75, 380-y*75)
  6. 线段分段绘制：步骤2中AF被分为AG/GH/HF三段，分别用不同颜色绘制
  7. 按钮状态管理：步骤0时"上一步"禁用（opacity=0.5, pointer-events:none），步骤2时"下一步"禁用
  8. 事件绑定：按钮click事件触发goToStep(currentStep±1)
- ID 命名规范：所有交互元素ID以 `scene2-` 为前缀
  示例：scene2-svg、scene2-btn-prev、scene2-btn-next、scene2-step-indicator、
        scene2-tri-acd-fill、scene2-line-cp、scene2-box-cp-result、
        scene2-line-ag、scene2-line-gh、scene2-line-hf、
        scene2-box-ratio、scene2-box-calc
- IIFE 隔离：所有 JS 代码包裹在 (function() { 'use strict'; ... })() 中，避免全局污染
- MathJax：用于渲染√3等数学符号，在文本标签中使用 `<tspan>` 内嵌 MathJax 或直接用 Unicode 字符 √（U+221A）
