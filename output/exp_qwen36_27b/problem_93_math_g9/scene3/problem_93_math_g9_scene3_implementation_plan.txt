[图示主题与整合说明]
- 本图示主题：点C从M运动到N时，点P的轨迹为水平线段，路径长度为2
- 整合的步骤/概念：M、N位置标注 + C的拖拽运动 + P的轨迹实时追踪 + 路径长度计算 + 不变量纵坐标高亮
- 教学价值：教师通过滑块连续拖动点C，直观展示动态几何中“动点轨迹”的形成过程。学生可实时观察P点纵坐标恒为2√3的不变量性质，理解轨迹为何是水平线段，并直接读取路径长度，将抽象的动点问题转化为可视化的几何运动规律。

[分步序列]
- 初始状态（步骤0）：
  - 显示线段AB、点A/B/M/N、等边△ACD/△BCE（C位于M点）、线段DE、点P（位于轨迹起点(350,187)）
  - 显示灰色参考线y=2√3及右侧标签
  - 显示实时坐标框：P(3, 2√3) ≈ P(3, 3.46)
  - 滑块位于最左端（对应C=M）
  - 轨迹线仅显示起点绿色圆点
- 拖拽交互（步骤1~N）：
  - 教师拖动滑块向右，C从M向N平滑移动
  - △ACD边长增大，△BCE边长减小，D、E位置实时更新
  - P点沿水平参考线向右移动，绿色轨迹线从起点逐步绘制至当前P点
  - 实时坐标框动态更新：P(t/2+2, 2√3)，t为C当前单位坐标(2~6)
  - 纵坐标2√3在坐标框中高亮显示（绿色背景或加粗），强调不变量
- 最终状态（步骤终）：
  - 滑块拖至最右端（C=N）
  - 轨迹线完整显示为(350,187)到(450,187)的水平线段
  - 轨迹线上方出现红色标注"路径长度 = 2"
  - 坐标框显示P(5, 2√3)
  - 教师可回退滑块复习任意中间状态

[交互方案]
- 交互类型：连续拖拽滑块
- 控件说明：
  - 滑块（HTML `<input type="range">`）：位于SVG底部绝对定位区域，范围0~100，映射C的单位坐标t∈[2,6]
  - 实时坐标框：右上角静态定位，内容随滑块事件动态更新
  - 路径长度标注：初始隐藏，滑块值=100时淡入显示
- 教师操作流程：
  1. 初始展示基础图形，指出M、N位置及C的起始点
  2. 缓慢拖动滑块，引导学生观察P点沿水平线移动，强调纵坐标不变
  3. 拖动至终点，展示完整轨迹，揭示路径长度=2的结论
  4. 可反复拖动对比不同位置，巩固动点轨迹概念

[技术实现]
- JS 库选择：原生 SVG + 原生 JavaScript（无需外部库，轻量高效，适合几何动态更新）
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  [图示区 800×500]
  ┌──────────────────────────────────────────────────────────────┐
  │                                                              │
  │                  D           P          E                   │
  │                   \         / \        /                    │
  │                    \       /   \      /                     │
  │                     \     /     \    /                      │
  │                      \   /       \  /                       │
  │                       \ /         \/                        │
  │  A      M      C      N      B                               │
  │  ●      □      ●      □      ●                               │
  │  |      |      |      |      |                               │
  │  └──────┴──────┴──────┴──────┘  y=2√3 (虚线)                │
  │                          └── 路径长度=2 (红)                 │
  │                                                              │
  │                                          ┌──────────────┐   │
  │                                          │ P(t/2+2, 2√3)│   │
  │                                          │  ≈ (3.0,3.46)│   │
  │                                          └──────────────┘   │
  │                                                              │
  │              C的位置：M ←[████████░░░░░░]→ N                │
  └──────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  - 坐标映射函数：`unitToPx(t)` 将单位坐标转为像素，1单位=50px，原点A(200,360)
  - 几何计算：实时根据滑块值t计算C、D、E、P坐标，更新SVG元素属性（`x1,y1,x2,y2`, `points`, `cx,cy`）
  - 轨迹绘制：使用SVG `<polyline>` 或动态追加 `<line>`，记录P的历史位置或直接用起点到当前P画线（因轨迹为直线）
  - 事件绑定：`input` 事件监听滑块，节流更新DOM；`change` 事件检测终点触发路径标注显示
  - 动画曲线：无缓动，实时跟随（linear），保证几何关系精确
- ID 命名规范：所有交互元素及SVG节点以 `scene3-` 为前缀（如 `scene3-slider`, `scene3-point-c`, `scene3-trajectory`, `scene3-coord-box`）
- IIFE 隔离：全部JS逻辑封装在 `(function() { 'use strict'; ... })();` 中，避免全局污染
- 数学符号：坐标框内使用 Unicode `√` 和 HTML 实体，避免引入 MathJax 增加加载负担
