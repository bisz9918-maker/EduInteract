[图示主题与整合说明]
- 本图示主题：三棱柱的立体结构及其表面展开过程
- 整合的步骤/概念：三棱柱立体展示 → 标注底面和侧面 → 沿棱剪开 → 逐步展开为平面图形 → 与选项A对比确认
- 教学价值：教师通过分步按钮引导学生观察三棱柱从立体到平面的展开过程，帮助学生建立空间想象能力，理解三棱柱表面展开图的特征（三个矩形并排，两个三角形分别连接在上下两侧），从而判断选项A为正确答案

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」按钮：位置(200, 465)，尺寸120×36px，点击回退到上一步骤，步骤0时禁用
  - 「下一步 ▶」按钮：位置(480, 465)，尺寸120×36px，点击进入下一步骤，步骤5时禁用
  - 步骤指示器：位置(400, 455)，显示"步骤 X / 6"（X=0~5）
  - 步骤标题：位置(400, 30)，显示当前步骤标题
- 教师操作流程：
  1. 页面加载显示步骤0（三棱柱立体图），教师介绍三棱柱的基本结构
  2. 点击「下一步」进入步骤1，教师讲解底面和侧面的标注
  3. 点击「下一步」进入步骤2，教师指出沿哪条侧棱剪开
  4. 点击「下一步」进入步骤3，教师讲解侧面展开为矩形条的过程
  5. 点击「下一步」进入步骤4，教师讲解底面如何连接到矩形条
  6. 点击「下一步」进入步骤5，教师对比展开图与选项A，确认答案
  7. 可随时点击「上一步」回退复习任意步骤

[技术实现]
- JS 库选择：原生 SVG + JavaScript（无需外部库）
  - 原因：几何图形简单（三角形、矩形、线段），动画为淡入淡出和位置移动，CSS transition 即可满足
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +--------------------------------------------------+
  |  [步骤标题：三棱柱立体图]                         | y=30
  |                                                  |
  |         /\          (步骤0-2: 三棱柱立体图)       |
  |        /  \                                             |
  |       /____\                                            |
  |       |    |                                            |
  |       |    |                                            |
  |       |____|                                            |
  |                                                  |
  |  (步骤3-4: 展开图居中)                               |
  |    /\       /\       /\                               |
  |   |__|_____|__|_____|__|                              |
  |                                          \  /         |
  |                                           \/          |
  |                                                  |
  |  (步骤5: 左右对比)                                 |
  |  [展开图]          →          [选项A ✓]            |
  |                                                  |
  |  ┌──────────┐  步骤 3/6  ┌──────────┐            | y=440~490
  |  │◀ 上一步  │             │ 下一步 ▶│            |
  |  └──────────┘             └──────────┘            |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. **状态机设计**：用数组定义6个状态（步骤0-5），每个状态包含：
     - title：步骤标题文本
     - visibleElements：当前可见的元素ID列表
     - hiddenElements：当前隐藏的元素ID列表
     - highlightElements：需要高亮的元素ID列表
     - labelPositions：当前步骤的标签位置映射
  2. **坐标计算**：
     - 步骤0-2：三棱柱居中(400,250)
     - 步骤3-4：展开图居中(400,250)
     - 步骤5：展开图移至(250,250)，选项A在(550,250)
     - 步骤4→5的平移用CSS transform: translateX(-150px)实现
  3. **动画曲线**：
     - 淡入淡出：opacity 0→1 / 1→0，duration 400ms，ease-in-out
     - 位置移动：transform translate，duration 600ms，ease-in-out
     - 侧棱高亮：stroke-color 变化 + stroke-dasharray 虚线，duration 300ms
  4. **事件绑定**：
     - 按钮点击事件触发状态切换
     - 步骤0时禁用「上一步」，步骤5时禁用「下一步」
     - 按钮禁用样式：opacity 0.4，cursor not-allowed
  5. **SVG元素管理**：
     - 所有元素初始创建，通过CSS class控制显隐（.hidden { opacity: 0; pointer-events: none; }）
     - 高亮通过切换CSS class实现（.highlight { stroke: #c62828; stroke-width: 3; stroke-dasharray: 8,4; }）
- ID 命名规范：所有交互元素ID以 `scene1-` 为前缀
  - 三棱柱组：`scene1-prism-group`
  - 底面三角形：`scene1-base-tri`
  - 顶面三角形：`scene1-top-tri`
  - 侧棱AA'：`scene1-edge-aa`
  - 侧棱BB'：`scene1-edge-bb`
  - 侧棱CC'：`scene1-edge-cc`
  - 展开图组：`scene1-net-group`
  - 矩形1/2/3：`scene1-net-rect1`, `scene1-net-rect2`, `scene1-net-rect3`
  - 上三角形：`scene1-net-tri-top`
  - 下三角形：`scene1-net-tri-bottom`
  - 选项A组：`scene1-optiona-group`
  - 选项A矩形1/2/3：`scene1-opta-rect1`, `scene1-opta-rect2`, `scene1-opta-rect3`
  - 选项A上/下三角形：`scene1-opta-tri-top`, `scene1-opta-tri-bottom`
  - 标签：`scene1-label-xxx`
  - 按钮：`scene1-btn-prev`, `scene1-btn-next`
  - 标题：`scene1-step-title`
  - 指示器：`scene1-step-indicator`
- IIFE 隔离：所有JS代码包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染
- CSS过渡：所有动画元素添加 `transition: all 0.4s ease-in-out;`，位置移动元素添加 `transition: transform 0.6s ease-in-out, opacity 0.4s ease-in-out;`
