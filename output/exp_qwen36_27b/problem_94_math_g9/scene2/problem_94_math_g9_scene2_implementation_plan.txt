- 本图示主题：四个选项的逐一分析与判定 — 判断哪个是三棱柱的表面展开图
- 整合的步骤/概念：展示四个选项A/B/C/D的平面展开图 → 逐一验证每个选项能否折叠成三棱柱 → 高亮正确答案A

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  1. 「◀ 上一步」按钮：位于(250,455)，尺寸120×36px，白色背景#ffffff，边框#1976d2线宽2px，文字#1976d2。点击后回到上一步状态。步骤0时禁用（灰色）。
  2. 「步骤 X/5」指示文字：位于(400,473)，字号16px，颜色#333333。显示当前步骤编号。
  3. 「下一步 ▶」按钮：位于(430,455)，尺寸120×36px，蓝色背景#1976d2，文字#ffffff。点击后进入下一步状态。步骤5时禁用（灰色）。
- 教师操作流程：
  1. 图示加载后显示步骤0（四个选项），教师可先让学生观察并猜测答案
  2. 点击「下一步」逐一分析每个选项，每步聚焦一个选项，展示判定结果和原因
  3. 到达步骤5后展示总结，确认正确答案
  4. 可随时点击「上一步」回退到任意步骤进行复习或重新讲解
  5. 按钮在首尾步骤自动禁用，防止越界

[技术实现]
- JS 库选择：原生 SVG（简单几何图形绘制，无需额外库，性能好，易于交互控制）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  ┌────────────────────────────────────────────────────────────┐
  │                    标题区 (y=10~50)                        │
  │              "下列四个图形中是..."                         │
  ├────────────────────────────────────────────────────────────┤
  │                                                            │
  │   选项A        选项B        选项C        选项D             │
  │   ┌──┐        ┌──┐        ┌──┐        ┌──┐               │
  │   △│  │        △│  │△      │  │        │  │               │
  │   └──┘        └──┘        └──┘        └──┘               │
  │   ┌──┐        ┌──┐        ┌──┐        ┌──┐               │
  │   │  │        │  │        │  │        │  │               │
  │   │  │        │  │        │  │        │  │               │
  │   └──┘        └──┘        └──┘        └──┘               │
  │   ┌──┐        ┌──┐        ┌──┐        ┌──┐               │
  │   │  │        │  │        │  │        │  │               │
  │   │  │        │  │        │  │        │  │               │
  │   └──┘        └──┘        └──┘        └──┘               │
  │   △              △              △                         │
  │   A              B              C              D          │
  │   (判定)         (判定)         (判定)         (判定)      │
  │   (原因)         (原因)         (原因)         (原因)      │
  │                                                            │
  ├────────────────────────────────────────────────────────────┤
  │              控件栏 (y=440~490)                            │
  │         [◀ 上一步]   步骤 0/5   [下一步 ▶]                 │
  └────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. **状态机设计**：定义6个状态（步骤0~5），每个状态对应一组SVG元素的显示/隐藏/样式变化。使用全局变量 `currentStep` 追踪当前步骤。
  2. **SVG元素分组**：每个选项的图形元素用 `<g>` 标签分组，ID分别为 `scene2-optA`、`scene2-optB`、`scene2-optC`、`scene2-optD`，便于整体控制高亮样式。
  3. **判定标记动态显示**：每个选项的判定标记和原因文字初始 `display="none"`，在对应步骤通过 JS 切换为 `display="block"`。
  4. **高亮效果**：通过切换 `<g>` 元素的 `stroke`、`stroke-width`、`stroke-dasharray` 属性实现边框高亮。步骤5中非正确选项通过 `opacity="0.5"` 和 `stroke="#999999"` 变灰。
  5. **按钮事件绑定**：使用 `addEventListener('click', ...)` 绑定按钮点击事件，更新 `currentStep` 后调用 `renderStep(currentStep)` 函数刷新画面。
  6. **按钮禁用逻辑**：步骤0时「上一步」按钮 `disabled=true`（灰色样式），步骤5时「下一步」按钮 `disabled=true`。
  7. **标题动态更新**：每个步骤对应不同的标题文字，通过修改 SVG `<text>` 元素的 `textContent` 实现。
  8. **动画过渡**：使用 CSS `transition` 为边框颜色变化和透明度变化添加 0.3s 平滑过渡效果。

- **ID 命名规范**：所有交互元素 ID 以 `scene2-` 为前缀：
  - `scene2-svg`：主 SVG 容器
  - `scene2-optA`、`scene2-optB`、`scene2-optC`、`scene2-optD`：四个选项的 `<g>` 分组
  - `scene2-title`：标题文字
  - `scene2-judgeA`、`scene2-judgeB`、`scene2-judgeC`、`scene2-judgeD`：判定标记文字
  - `scene2-reasonA`、`scene2-reasonB`、`scene2-reasonC`、`scene2-reasonD`：原因文字
  - `scene2-summary`：总结文字
  - `scene2-btn-prev`：上一步按钮
  - `scene2-btn-next`：下一步按钮
  - `scene2-step-indicator`：步骤指示文字

- IIFE 隔离：所有 JS 代码包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染。
- JS 中统一使用 `document.getElementById('scene2-xxx')` 获取元素，不使用 `querySelectorAll` 配合全局 class。
