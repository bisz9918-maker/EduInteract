    **题目原文：**

    笔直的海岸线上依次有A、B、C三个港口，甲船从A港口出发，沿海岸线匀速驶向C港，1小时后乙船从B港口出发，沿海岸线匀速驶向A港，两船同时到达目的地。甲船的速度是乙船的1.25倍，甲、乙两船与B港的距离y（km）与甲船行驶时间x（h）之间的函数关系如图所示，下列说法：①A、B港口相距400km；②甲船的速度为100km/h；③B、C港口相距200km；④乙出发4h时两船相距220km，其中正确的个数是（）

    A.4个  B.3个  C.2个  D.1个

    **题目分析：**

    本题是一道函数图像应用题，核心在于从距离-时间图像中提取关键信息，并结合行程问题的基本关系（路程=速度×时间）进行推理计算。

    **关键信息提取：**
    - 海岸线排列：A—B—C（依次）
    - 甲船：A→C，x=0出发
    - 乙船：B→A，x=1出发（晚1小时）
    - 两船同时到达目的地
    - 甲船速度 = 1.25 × 乙船速度
    - 图像纵轴y表示"与B港的距离"

    **图像解读：**
    - 甲船折线：(0,400)→(4,0)→(6,200)，表示甲船先从A到B（距离B从400减到0），再从B到C（距离B从0增到200）
    - 乙船线段：(1,0)→(6,400)，表示乙船从B到A（距离B从0增到400）

    **计算过程：**
    1. AB距离 = 400km（甲船起点y值）
    2. 甲船速度 = 400÷4 = 100km/h
    3. 乙船速度 = 100÷1.25 = 80km/h
    4. 乙船用时 = 400÷80 = 5h，到达时间x=1+5=6
    5. 甲船从B到C用时 = 6-4 = 2h，BC = 100×2 = 200km
    6. 乙出发4h时（x=5）：甲船距B港100km（向C），乙船距B港320km（向A），两船相距100+320=420km≠220km

    **结论：** ①②③正确，④错误，选B（3个）

    **图示规划说明：**

    本题需要两个图示：
    - **SCENE_1：函数图像分析图** — 展示完整的距离-时间图像，分步标注关键点、计算速度、验证四个说法
    - **SCENE_2：海岸线运动模拟图** — 展示港口位置和两船运动过程，通过时间滑块直观理解两船相对位置变化

    **教学说明：**

    本图示是解题的核心工具，教师应按以下步骤引导学生：

    **步骤0-2：图像识别**
    - 引导学生观察图像中有两条线，分别对应甲船和乙船
    - 提问：为什么甲船是折线而乙船是线段？（因为甲船经过B港，距离先减后增；乙船从B出发远离，距离一直增加）

    **步骤3：关键点提取**
    - 引导学生读取关键点坐标
    - 强调(0,400)表示甲船出发时在A港，距B港400km
    - 强调(4,0)表示甲船4h后到达B港

    **步骤4-6：计算推导**
    - 甲船速度：从A到B，400km用时4h，v=100km/h
    - 乙船速度：利用倍数关系v_乙=100÷1.25=80km/h
    - BC距离：两船同时到达，乙船用时5h（x=6到达），甲船从B到C用时2h，BC=200km

    **步骤7-8：验证结论**
    - 重点讲解说法④：乙出发4h即x=5，此时甲船距B港100km（向C），乙船距B港320km（向A），两船在B港两侧，相距420km
    - 总结四个说法的正误，得出答案B

    **易错点提醒：**
    - 学生容易混淆"乙出发4h"与"x=4"，需强调乙晚1h出发
    - 学生可能忘记两船在B港两侧，直接用|320-100|=220km，需强调方向

    本图示将抽象的函数图像转化为直观的运动场景，帮助学生建立数形结合的思想。

    2. **拖动滑块的引导问题：**

       - x=1时发生了什么？（乙船出发）

       - x=5时两船相距多远？（重点验证说法④）

    3. **重点强调x=5时刻：**
       - 拖动滑块到x=5，观察两船位置
       - 甲船在B港右侧100km处（向C方向）
       - 乙船在B港左侧320km处（向A方向）
       - 两船在B港两侧，相距100+320=420km
       - 这与说法④的220km不符，说明④错误

    4. **数形结合：**
       - 引导学生对比SCENE_1的函数图像和SCENE_2的运动场景
       - 函数图像中的y值对应船只与B港的距离
       - 函数图像中的交点对应两船与B港距离相等的时刻

    **完整解答：**

    由图像可知：
    - AB = 400km（说法①正确）
    - 甲船速度 = 400÷4 = 100km/h（说法②正确）
    - 乙船速度 = 100÷1.25 = 80km/h
    - 乙船用时 = 400÷80 = 5h，到达时间x=6
    - BC = 100×(6-4) = 200km（说法③正确）
    - 乙出发4h时（x=5）：甲船距B港100km，乙船距B港320km，两船相距420km≠220km（说法④错误）
