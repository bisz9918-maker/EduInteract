[技术实现]
- JS 库选择：原生 SVG（简单几何图形和函数图像，无需复杂库）
- 画布尺寸：800 × 500 px
- 布局草图：
  ```
  ┌────────────────────────────────────────────────────────────┐
  │  y/km ↑                                                    │
  │    400 │  *甲船(0,400)                              计算区  │
  │        │  / \                                     ┌──────┐ │
  │    200 │ /   \  *乙船(6,400)                      │v_甲= │ │
  │        |/     \/      \                          │100   │ │
  │        O-----1----4----6----7→ x/h               │v_乙= │ │
  │        (0)   (1)  (4)  (6)                       │80    │ │
  │                                              │BC=200│ │
  │                                              │④ ✗   │ │
  │                                              │①✓②✓│ │
  │                                              │③✓④✗│ │
  │                                              └──────┘ │
  │                                                       │
  │              ◀上一步  [0/8]  下一步▶                   │
  └────────────────────────────────────────────────────────────┘
  ```
- 关键实现要点：
  1. 状态机设计：8个步骤（0~8），当前步骤用变量currentStep记录
  2. 每个步骤对应一个renderStep(step)函数，根据step值决定显示哪些元素
  3. 坐标映射函数：dataXToPixel(x) = 100 + x * 66，dataYToPixel(y) = 420 - y * 0.68
  4. 动画曲线：折线/线段绘制使用stroke-dasharray和stroke-dashoffset动画，0.8秒线性过渡
  5. 事件绑定：按钮点击事件绑定到handleNext()和handlePrev()函数
  6. 高亮效果：通过修改stroke-width和添加filter实现
  7. 文本框动态扩展：根据步骤内容动态调整rect高度
- ID 命名规范：所有交互元素ID以scene1-为前缀
  - scene1-svg：主SVG容器
  - scene1-axis-x：x轴
  - scene1-axis-y：y轴
  - scene1-line-jia：甲船折线
  - scene1-line-yi：乙船线段
  - scene1-point-0400、scene1-point-40、scene1-point-6200、scene1-point-10、scene1-point-6400：关键点
  - scene1-label-jia、scene1-label-yi：曲线标签
  - scene1-calc-box：计算文本框
  - scene1-calc-text：计算文本内容
  - scene1-summary：总结区域
  - scene1-btn-prev：上一步按钮
  - scene1-btn-next：下一步按钮
  - scene1-step-indicator：步骤指示器
  - scene1-dash-*：辅助虚线
  - scene1-highlight-*：高亮元素
- IIFE 隔离：所有JS代码包裹在(function(){ ... })()中，避免全局污染
