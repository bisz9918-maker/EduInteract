[图示主题与整合说明]
- 本图示主题：展开图折叠成正方体的动态过程与多角度观察验证
- 整合的步骤/概念：十字形展开图 → 逐步折叠动画 → 3D正方体成型 → 旋转观察不同视角 → 与选项C匹配验证
- 教学价值：教师可通过分步按钮控制折叠节奏，直观展示空间几何体的展开与折叠关系；通过旋转正方体模拟实际观察过程，帮助学生理解三视图与空间位置对应关系，最终验证正确答案。

[视觉元素清单]
- 展开图（步骤0）：6个正方形组成的十字形展开图，居中显示。各面按题意绘制图案：面1左上角阴影三角形、面4右上角阴影三角形、圆圈面中心圆圈、其余空白。边框#000000，线宽2px。
- 折叠动画（步骤1~5）：各面沿交界线逐步折叠90度。使用CSS 3D transform实现透视折叠效果。正在折叠的面高亮#1565c0，线宽3px。
- 3D正方体（步骤6~10）：等轴测投影或CSS 3D立方体，边长60px。各面图案准确映射：前面(面2)空白、左面(面1)左上阴影、右面(面3)空白、后面(面4)右上阴影、上面(圆圈面)圆圈、下面(底面)空白。
- 面标注：折叠后在各面中心显示面编号（面1~面4、圆圈面、底面），文字#000000，12px。
- 视角指示：步骤7~9在正方体上方显示观察方向文字（#333333，14px，加粗）。
- 选项对比（步骤10）：右侧显示选项C的2D立方体图形（前面圆圈、右面右上阴影、上面空白），边框#2e7d32，线宽2px。
- 匹配标记：绿色勾选符号✓（#2e7d32，24px）位于选项C下方。
- 控件栏：底部两个按钮（◀ 上一步 / 下一步 ▶），步骤指示器居中。

[分步序列]
- 初始状态（步骤0）：显示完整展开图，各面平铺。标注面编号和图案。无高亮。
- 步骤1：点击「下一步」→ 面1沿与面2交界线向左折叠90度，成为左面。面1高亮#1565c0，动画时长0.6s。
- 步骤2：点击「下一步」→ 面3沿与面2交界线向右折叠90度，成为右面。面3高亮，动画时长0.6s。
- 步骤3：点击「下一步」→ 面4沿与面3交界线继续向右折叠90度，成为后面。面4高亮，动画时长0.6s。
- 步骤4：点击「下一步」→ 圆圈面沿与面2交界线向上折叠90度，成为上面。圆圈面高亮，动画时长0.6s。
- 步骤5：点击「下一步」→ 底面沿与面2交界线向下折叠90度，成为下面。底面高亮，动画时长0.6s。
- 步骤6：点击「下一步」→ 折叠完成，展示完整3D正方体。面2为前面（空白）。所有面恢复#000000边框。显示面编号标注。
- 步骤7：点击「下一步」→ 正方体绕竖直轴旋转-30度，展示左前方视角。可见左面(面1)、前面(面2)、上面(圆圈)。上方显示"从左前方观察"。
- 步骤8：点击「下一步」→ 正方体继续旋转至+30度，展示右前方视角。可见右面(面3)、前面(面2)、上面(圆圈)。上方显示"从右前方观察"。
- 步骤9：点击「下一步」→ 正方体旋转至关键视角（前面=圆圈面、上面=面3、右面=面4）。正方体边框高亮#2e7d32，线宽3px。上方显示"关键视角"。
- 步骤10：点击「下一步」→ 画布右侧出现选项C图形，与正方体并排。中间显示绿色箭头连接。下方显示"与选项C匹配 ✓"。正方体与选项C同步高亮。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  - 「◀ 上一步」：位于(150,460)，点击返回上一步状态，动画反向播放。
  - 「下一步 ▶」：位于(550,460)，点击进入下一步状态，播放折叠/旋转动画。
  - 步骤指示器：位于(400,475)，显示"步骤 X / 10"。
- 教师操作流程：教师点击「下一步」逐步展示折叠过程，每步停顿讲解空间关系；到达步骤6后，通过旋转展示不同视角，引导学生观察；步骤9高亮关键视角，步骤10对比选项C，确认答案。可随时点击「上一步」回退复习。

[技术实现]
- JS 库选择：原生HTML/CSS/JS + CSS 3D Transforms（无需外部库，轻量高效）。使用CSS `transform-style: preserve-3d` 和 `rotateX/Y/Z` 实现折叠与旋转动画。
- 画布尺寸：800 × 500 px（固定）。
- 布局草图（ASCII）：
  ```
  [展开图/3D正方体区 800×440]
  +--------------------------------------------------+
  |                                                  |
  |           [视角标注文字]                         |
  |                                                  |
  |              [展开图/3D正方体]                   |
  |                                                  |
  |   (步骤10时)  [正方体]  →  [选项C]               |
  |                          [匹配提示]               |
  |                                                  |
  +--------------------------------------------------+
  [控件栏 800×60]
  +--------------------------------------------------+
  |  [◀ 上一步]        步骤 X/10        [下一步 ▶]   |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  - 状态机：使用数组存储11个状态（0~10），每个状态定义各面的transform值、高亮样式、显示元素。
  - 折叠动画：CSS `transition: transform 0.6s ease-in-out`，通过修改class触发。
  - 3D正方体：6个div面，使用`transform: translateZ(30px) rotateX/Y(...)`定位。旋转通过修改容器`transform: rotateY(angle)`实现。
  - 事件绑定：按钮点击更新当前步骤索引，调用`renderStep(index)`重绘。
  - 防抖：按钮点击后0.6s内禁用，防止动画未完成时重复触发。
- ID 命名规范：所有交互元素ID以`scene2-`为前缀，如`scene2-btn-prev`、`scene2-btn-next`、`scene2-cube-container`、`scene2-face-1`等。JS中使用`document.getElementById`精确获取，避免class全局污染。
- IIFE 隔离：所有JS代码包裹在`(function() { 'use strict'; ... })();`中，确保多场景合并时无变量冲突。
