[图示主题与整合说明]
- 本图示主题：根据 a<0、b<0 判断一次函数 y=ax+b 的图象经过的象限
- 整合的步骤/概念：从已知条件（a<0、b<0）出发 → 绘制一次函数 y=ax+b 的直线图象 → 标注直线经过的象限（第二、三、四象限） → 得出结论：不经过第一象限，答案选 A
- 教学价值：教师通过分步按钮引导学生逐步推理，从已知条件到图象绘制再到结论，帮助学生理解一次函数系数与图象位置的关系，强化数形结合思想

[分步序列]

  * 直线从 (160,190) 到 (620,390)，斜率为负，y轴截距为负

- 步骤2：点击「下一步」→

  * 第一象限中心 (550,150) 标注"不经过"（#c62828，18px，加粗）
  * 按钮：「上一步」、「下一步」

- 步骤3（最终步骤）：点击「下一步」→
  * 右下角显示绿色结论框（#2e7d32 边框，浅绿背景）
  * 结论框内容："一次函数 y=ax+b 的图象不经过第一象限"
  * 下方显示："答案：A. 第一象限"

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  * 「◀ 上一步」按钮：位于控件栏左侧 (100,455)，尺寸 100×36，点击回退到上一步骤，步骤0时禁用
  * 「步骤 0/3」指示器：位于控件栏中央 (350,455)，显示当前步骤编号
  * 「下一步 ▶」按钮：位于控件栏右侧 (600,455)，尺寸 100×36，点击进入下一步骤，步骤3时禁用
- 教师操作流程：
  1. 教师展示步骤0，引导学生观察已知条件 a<0、b<0
  2. 点击「下一步」进入步骤1，展示一次函数图象，讲解斜率和截距的含义
  3. 点击「下一步」进入步骤2，高亮经过和不经过的象限，引导学生观察
  4. 点击「下一步」进入步骤3，展示结论和答案
  5. 可随时点击「上一步」回退复习任意步骤

[技术实现]
- JS 库选择：原生 SVG（简单几何图形和坐标系绘制，无需额外库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  +---------------------------------------------------+  y=0
  |  [已知：a<0,b<0]              y↑                  |  y=50
  |                       Ⅱ|Ⅰ                         |  y=100
  |                  Ⅱ  |  Ⅰ  y=ax+b                  |  y=150
  |                     |                             |  y=200
  |                     |                             |  y=250
  |  ←--------x←O→--------→x                          |  y=250 (x轴)
  |                     |                             |  y=300
  |                  Ⅲ  |  Ⅳ                          |  y=350
  |                  Ⅲ  |  Ⅳ  [结论框]                |  y=400
  |                     |                             |  y=430
  +---------------------------------------------------+  y=440
  |  [◀上一步]    步骤 0/3    [下一步▶]               |  y=455
  +---------------------------------------------------+  y=490
  ```
- 关键实现要点：
  1. **状态机设计**：用变量 `currentStep`（0~3）管理当前步骤，每个步骤对应一组 SVG 元素的显示/隐藏状态
  2. **SVG 元素管理**：
     * 坐标系（x轴、y轴、原点、箭头）：始终显示
     * 象限标注（Ⅰ~Ⅳ）：始终显示
     * 已知条件框：步骤0~3始终显示
     * 直线 y=ax+b：步骤1~3显示（opacity 0→1 过渡动画）
     * 象限填充：步骤2~3显示（opacity 0→1 过渡动画）
     * "不经过"标注：步骤2~3显示
     * 结论框：步骤3显示（opacity 0→1 过渡动画）
  3. **坐标计算**：
     * 直线方程：从 (160,190) 到 (620,390)，斜率 = (390-190)/(620-160) = 200/460 ≈ 0.435（像素斜率，对应数学斜率 a<0）
     * 与 y 轴交点：x=400 时，y = 190 + 0.435*(400-160) = 190 + 104.4 ≈ 294 → 调整为 (400,310) 使截距更明显
     * 与 x 轴交点：y=250 时，x = 160 + (250-190)/0.435 ≈ 160 + 138 ≈ 298 → 调整为 (280,250)
  4. **动画曲线**：元素出现使用 CSS transition，opacity 从 0 到 1，duration 0.5s，ease-in-out
  5. **事件绑定**：按钮点击事件绑定到 `handleStepChange(direction)` 函数，direction 为 +1 或 -1
  6. **象限填充区域**：
     * 第一象限：rect x=400 y=50 width=300 height=200
     * 第二象限：rect x=100 y=50 width=300 height=200
     * 第三象限：rect x=100 y=250 width=300 height=180
     * 第四象限：rect x=400 y=250 width=300 height=180
- ID 命名规范：所有交互元素 ID 以 `scene2-` 为前缀
  * `scene2-svg`：主 SVG 容器
  * `scene2-axis-x`：x 轴
  * `scene2-axis-y`：y 轴
  * `scene2-origin`：原点
  * `scene2-quadrant-1` ~ `scene2-quadrant-4`：四个象限标注
  * `scene2-quadrant-fill-1` ~ `scene2-quadrant-fill-4`：四个象限填充
  * `scene2-condition-box`：已知条件框
  * `scene2-line`：直线 y=ax+b
  * `scene2-line-label`：直线标注
  * `scene2-not-pass-label`："不经过"标注
  * `scene2-conclusion-box`：结论框
  * `scene2-btn-prev`：上一步按钮
  * `scene2-btn-next`：下一步按钮
  * `scene2-step-indicator`：步骤指示器
- IIFE 隔离：所有 JS 代码包裹在 `(function() { 'use strict'; ... })();` 中，避免全局污染
