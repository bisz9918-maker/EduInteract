[图示主题与整合说明]
- 本图示主题：圆内接等腰三角形与直径性质的逐步推导——从已知条件到求出AB=3
- 整合的步骤/概念：
  1. 展示题目原图（圆O、内接△ABC、直径AD、连线BD和CD）
  2. 标注已知条件：AB=BC（等长标记）、∠ABC=120°、AD=6
  3. 推导等腰三角形底角：∠BAC=∠BCA=30°
  4. 利用直径性质标注∠ABD=90°
  5. 利用同弧圆周角相等标注∠ADB=30°
  6. 在Rt△ABD中计算AB=3
- 教学价值：教师通过分步导航逐步展示几何推导过程，每一步在前一步基础上添加新标注，学生可清晰跟随逻辑递进。教师可随时回退复习。

[交互方案]
- 交互类型：分步按钮导航（◀上一步/下一步▶）
- 控件说明：
  1. "◀ 上一步"按钮：SVG内底部左侧(30,452)-(190,482)，灰色圆角矩形，步骤0时禁用（opacity=0.4）
  2. 步骤指示器：SVG内底部中央(360,458)-(440,478)，显示"0/5"~"5/5"
  3. "下一步 ▶"按钮：SVG内底部右侧(610,452)-(770,482)，蓝色圆角矩形，步骤5时禁用
  4. 文字提示区：SVG内(40,395)-(760,430)，居中显示当前步骤推理说明
- 教师操作流程：
  1. 图示加载后显示步骤0（图形骨架），教师可开始讲解题目
  2. 点击"下一步"逐步展示已知条件→推导底角→直径性质→同弧圆周角→最终结论
  3. 可随时点击"上一步"回退到任意步骤
  4. 每步切换时，新增元素以淡入动画出现（0.3s ease-in），被替换元素以淡出动画消失

[技术实现]
- JS 库选择：原生 SVG（本场景为纯几何图形，无需额外库）
- 画布尺寸：800 × 500 px（固定）
- 布局草图：
  ```
  +--------------------------------------------------+
  |                    圆O                           |
  |           D(510,125)                             |
  |         /   O(380,200)  \                        |
  |       /                   \                      |
  |   A(250,275)-----------C(510,275)               |
  |       \                   /                      |
  |        \       B(380,350)/                       |
  |                                              |
  |  [文字提示区：当前步骤推理说明 y=395~430]       |
  |  [◀上一步]    [0/5]    [下一步▶]  y=452~482     |
  +--------------------------------------------------+
  ```
- 关键实现要点：
  1. 状态机设计：currentStep变量(0~5)，每个步骤对应一个renderStep(step)函数
  2. renderStep函数根据step值决定显示哪些元素（通过SVG元素的display/opacity控制）
  3. 元素分组：将每步新增元素放在独立的<g>组中，通过控制组的visibility实现显示/隐藏
  4. 动画：CSS transition实现淡入淡出效果（opacity: 0→1，duration: 0.3s）
  5. 按钮事件：click事件绑定到上一步/下一步按钮，更新currentStep并调用renderStep
  6. 边界处理：步骤0时禁用"上一步"，步骤5时禁用"下一步"
  7. 角度弧绘制：使用SVG <path>的A命令绘制圆弧
  8. 直角符号：使用SVG <polyline>绘制小"L"形
  9. 等长标记：在AB和BC中点处绘制两条平行短线（垂直于线段方向）
  10. 弧AB高亮：使用SVG <path>的A命令绘制虚线弧（stroke-dasharray="6,4"）
- ID 命名规范：所有交互元素ID以 scene1- 为前缀
  - scene1-svg：主SVG容器
  - scene1-circle：圆O
  - scene1-point-o / scene1-point-a / scene1-point-b / scene1-point-c / scene1-point-d：各点
  - scene1-label-o / scene1-label-a / scene1-label-b / scene1-label-c / scene1-label-d：各点标签
  - scene1-line-ab / scene1-line-bc / scene1-line-ac / scene1-line-ad / scene1-line-bd / scene1-line-cd：各线段
  - scene1-step1-group：步骤1新增元素组（等长标记+120°+AD=6）
  - scene1-step2-group：步骤2新增元素组（30°×2）
  - scene1-step3-group：步骤3新增元素组（直角符号+90°+BD加粗）
  - scene1-step4-group：步骤4新增元素组（弧AB高亮+30°(D)）
  - scene1-step5-group：步骤5新增元素组（△ABD高亮+AB=3）
  - scene1-hint-text：文字提示
  - scene1-btn-prev / scene1-btn-next：导航按钮
  - scene1-step-indicator：步骤指示器
- IIFE 隔离：所有JS代码包裹在 (function() { ... })() 中，避免全局污染
