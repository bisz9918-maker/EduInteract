    **题目原文：**

    如图，D是等边△ABC边AB上的一点，且AD=1，BD=2，现将△ABC折叠，使点C与D重合，折痕EF，点E、F分别在AC和BC上，若BF=1.25，则CE=（  ）

    A．7/5  B．2/3  C．5/6  D．1/2

    **题目分析：**

    本题是一道等边三角形折叠问题，核心考点包括：
    1. 等边三角形的性质（三边相等，三角均为60°）
    2. 折叠的几何性质（折痕是对应点连线的垂直平分线；折叠前后对应线段相等）
    3. 余弦定理的应用

    已知 AB = AD + BD = 1 + 2 = 3，因△ABC为等边三角形，故 AC = BC = AB = 3。

    由折叠性质：CE = DE，CF = DF。

    设 CE = x，则 AE = 3 - x，DE = x。在△ADE中，∠A = 60°，由余弦定理：
    DE² = AD² + AE² - 2·AD·AE·cos60°
    x² = 1² + (3-x)² - 2·1·(3-x)·(1/2)
    x² = 1 + 9 - 6x + x² - 3 + x
    0 = 7 - 5x
    x = 7/5

    验证：CF = BC - BF = 3 - 5/4 = 7/4，DF = CF = 7/4。在△BDF中用余弦定理验证：DF² = 4 + 25/16 - 5/2 = 49/16，DF = 7/4，一致。

    **整体讲解思路：**

    先引导学生观察图形，理解折叠的含义——C点沿EF翻折到D点。然后强调折叠的核心性质：折痕上的点到C和D的距离相等，即CE=DE，CF=DF。最后设未知数，在△ADE中利用余弦定理列方程求解。

    **本图示教学说明：**

    **步骤0→步骤1：引导学生观察图形，标注已知条件**

    教师操作：点击「下一步」进入步骤1。

    引导学生注意：
    1. △ABC是等边三角形，三边相等
    2. D在AB上，AD=1，BD=2，所以AB=3，进而AC=BC=3
    3. BF=1.25=5/4

    **步骤1→步骤2：理解折叠的几何性质**

    教师操作：点击「下一步」进入步骤2，观察C点沿EF翻折到D点的动画。

    关键讲解点：
    1. 折叠的本质：折痕EF是CD的垂直平分线
    2. 折痕上的任意一点到C和D的距离相等
    3. 因此 CE = DE，CF = DF（这是解题的关键桥梁）

    提问学生：为什么CE=DE？（因为E在折痕EF上，折叠后C与D重合，所以E到C的距离等于E到D的距离）

    **步骤2→步骤3：设未知数，建立方程**

    教师操作：点击「下一步」进入步骤3。

    讲解思路：
    1. 设 CE = x（这是我们要求的量）
    2. 则 AE = AC - CE = 3 - x
    3. 由折叠性质，DE = CE = x
    4. 在△ADE中，已知 AD=1，AE=3-x，DE=x，∠A=60°

    **步骤3→步骤4：应用余弦定理列方程**

    教师操作：点击「下一步」进入步骤4，观察△ADE被高亮。

    余弦定理：在△ADE中，
    DE² = AD² + AE² - 2·AD·AE·cos∠A

    代入：x² = 1² + (3-x)² - 2×1×(3-x)×cos60°

    因为 cos60° = 1/2，所以：
    x² = 1 + (3-x)² - (3-x)

    **步骤4→步骤5：化简求解**

    教师操作：点击「下一步」进入步骤5，展示最终答案。

    化简过程：
    x² = 1 + (9 - 6x + x²) - 3 + x
    x² = 7 - 5x + x²
    0 = 7 - 5x
    x = 7/5

    所以 CE = 7/5，选A。

    **课堂讲解建议：**
    - 在步骤2处停顿，让学生自己说出折叠的性质
    - 在步骤4处，可以先让学生尝试列方程，再展示答案
    - 可以补充验证：CF = 3 - 5/4 = 7/4，在△BDF中用余弦定理验证DF = 7/4，与CF相等，验证正确
    - 强调本题的关键是"折叠→等距"这一转化思想

    **完整解答总结：**

    **已知：**
    - △ABC为等边三角形
    - D在AB上，AD=1，BD=2，故AB=AC=BC=3
    - 折叠使C与D重合，折痕为EF，E在AC上，F在BC上
    - BF=1.25=5/4

    **求解：CE = ?**

    **解：**

    1. 由折叠性质，CE = DE，CF = DF

    2. 设 CE = x，则 AE = 3 - x，DE = x

    3. 在△ADE中，∠A = 60°，由余弦定理：
    DE² = AD² + AE² - 2·AD·AE·cos60°
    x² = 1 + (3-x)² - (3-x)
    x² = 1 + 9 - 6x + x² - 3 + x
    0 = 7 - 5x
    x = 7/5

    **答案：CE = 7/5，选A**

    **验证：**
    CF = BC - BF = 3 - 5/4 = 7/4
    在△BDF中，∠B = 60°，由余弦定理：
    DF² = BD² + BF² - 2·BD·BF·cos60°
    = 4 + 25/16 - 2×2×(5/4)×(1/2)
    = 4 + 25/16 - 5/2
    = 64/16 + 25/16 - 40/16
    = 49/16
    DF = 7/4 = CF ✓

    **教学要点回顾：**
    - 折叠问题的核心：折痕上的点到折叠前后对应点的距离相等
    - 等边三角形提供60°角，为余弦定理创造条件
    - 设未知数→找关系→列方程→求解，是几何代数化的标准流程
