[图示主题与整合说明]
- 本图示主题：不同开关状态下电路连接方式与灯泡功率对比
- 整合的步骤/概念：原始电路图展示、三种开关组合的电路状态切换（串联/单灯/并联）、电流路径动态高亮、各灯泡电压/电流/功率实时计算显示、灯泡亮度可视化（发光透明度映射实际功率）
- 教学价值：教师可通过底部状态切换按钮，直观对比三种电路结构下的电流走向与灯泡实际功率，帮助学生理解串并联电路特点、额定电压与实际功率的关系，以及开关控制对电路拓扑的影响。配合数据面板的实时数值，便于定量分析与定性观察相结合。

[分步序列]
- 初始状态（步骤0）：显示完整电路图。S₂断开，S₁动触点悬空(指向a与b中间)。灯泡无发光填充。数据面板显示"请选择状态"。无电流高亮。
- 步骤1（点击按钮1）：S₂保持断开，S₁动触点转向a。蓝色粗线高亮串联路径：电源正→左竖线→L₁→中间节点→L₂→右竖线→触点a→S₁→负极。L₁发光透明度20%，L₂发光透明度10%。数据面板更新：标题"状态1：S₂断开，S₁接a（串联）"，L₁: U=2V, I=0.33A, P=0.67W；L₂: U=1V, I=0.33A, P=0.33W。
- 步骤2（点击按钮2）：S₂保持断开，S₁动触点转向b。蓝色粗线高亮单灯路径：电源正→左竖线→L₁→中间节点→b点连线→触点b→S₁→负极。L₂无电流/无发光。L₁发光透明度30%。数据面板更新：标题"状态2：S₂断开，S₁接b（仅L₁）"，L₁: U=3V, I=0.5A, P=1.5W；L₂: 断开。
- 步骤3（点击按钮3）：S₂闭合，S₁动触点转向b。蓝色粗线高亮两条并联路径：路径1同步骤2；路径2：电源正→左竖线→上横线→S₂→右竖线→L₂→中间节点→b点连线→触点b→S₁→负极。L₁发光透明度30%，L₂发光透明度40%。数据面板更新：标题"状态3：S₂闭合，S₁接b（并联）"，L₁: U=3V, I=0.5A, P=1.5W；L₂: U=3V, I=1A, P=3W。

[交互方案]
- 交互类型：多状态切换（3个按钮）
- 控件说明：
  - 按钮1（状态1：串联）：触发S₂断开、S₁接a，显示串联电路高亮与参数
  - 按钮2（状态2：仅L₁）：触发S₂断开、S₁接b，显示单灯电路高亮与参数
  - 按钮3（状态3：并联）：触发S₂闭合、S₁接b，显示并联电路高亮与参数
- 教师操作流程：教师点击对应按钮切换电路状态，观察电流路径蓝色高亮变化、灯泡发光亮度差异，并结合右侧数据面板讲解实际电压/电流/功率的计算与比较。可随时切换回任意状态进行对比。

[技术实现]
- JS 库选择：原生 SVG + Vanilla JavaScript。原因：电路图为标准几何线条与符号，SVG 矢量绘制清晰、易于路径高亮与样式切换，无需重型库即可实现流畅交互。
- 画布尺寸：800 × 500 px（固定）
- 布局草图（ASCII）：
  ```
  [ 800×500 画布 ]
  y=100: ────────S₂───────────
           |               |
  y=250: ──L₁──●──L₂───────a●
                |           |
  y=310:        └────b●     |
                (350,310)   |
  y=330:                   S₁●(550,330)
  y=380: ────────(3V)───────┘
           150      550
  [数据面板] x=620~760, y=100~240
  [按钮栏]   y=455~485, x=220~560
  ```
- 关键实现要点：
  1. 状态机设计：定义 `currentState = 0/1/2/3`。点击按钮时更新状态，调用 `renderState(state)` 重绘。
  2. 路径高亮：预定义3条 `<path>` 元素（对应3种状态），默认 `opacity="0"`。切换状态时目标路径 `opacity="1"`，其余归零。使用 `stroke-dasharray` 或箭头标记 `<marker>` 指示电流方向。
  3. 开关动画：S₁动触点为 `<line>`，通过修改 `x2, y2` 坐标实现转向a或b。S₂为 `<line>`，闭合时水平，断开时倾斜。使用 CSS `transition: all 0.3s ease` 实现平滑过渡。
  4. 灯泡发光：每个灯泡下方放置 `<circle>` 作为发光层，`fill="#ffd600"`，通过 JS 动态修改 `opacity` 属性映射功率值。
  5. 数据面板更新：使用 `<text>` 元素，通过 `textContent` 或 `innerHTML` 替换数值。功率值用 `<tspan fill="#c62828">` 突出。
  6. 事件绑定：按钮添加 `click` 监听器，触发状态切换函数。
- ID 命名规范：所有交互元素与关键图形 ID 均以 `scene1-` 为前缀，如 `scene1-btn-1`, `scene1-path-series`, `scene1-bulb-l1-glow`, `scene1-panel-text`。JS 中严格使用 `document.getElementById()` 获取元素，避免 `querySelectorAll` 全局匹配导致多场景合并时污染。
- IIFE 隔离：全部 JS 逻辑封装在 `(function() { 'use strict'; ... })();` 中，确保变量与函数不泄露至全局作用域。
